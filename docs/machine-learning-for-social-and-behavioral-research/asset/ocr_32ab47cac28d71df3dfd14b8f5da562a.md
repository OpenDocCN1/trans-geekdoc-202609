The main limitation of bagging is shared with random forests. Specifically, random forests lack interpretability because a single decision tree is no longer available. Variable importance measures discussed for bagging are also available for random forests and used to highlight which variables contribute more to the prediction of the outcome. The permutation approach to variable importance discussed earlier is the most common approach to documenting variable importance; however, the partykit package offers an alternative approach based permuting the data, which has been found to reduce bias. The way of permuting x values discussed above is referred to as a marginal approach and is used in the randomForest package by default. The marginal approach to evaluating variable importance has been found to be correlated with predictors of predictors. As a result, Strobl et al. (2008) developed a conditional approach. In discussing the conditional approach, we refer to the set of predictors that do not include the variable x as Z. For each tree, we calculate the importance for x by extracting the cutpoints for Z variables used in the tree and setting up a grid corresponding to these cutpoints. Then, for each subset of the bootstrap (subsample) sample created by the cutpoints on Z, we permute the values of x and the prediction performance is calculated after each permutation. This approach to variable importance is available in the partykit package when estimating random forests using conditional inference trees (cforest function).
