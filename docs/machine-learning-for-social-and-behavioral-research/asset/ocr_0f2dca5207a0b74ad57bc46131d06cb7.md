# Ensembles

For random forests, there are two tuning parameters, the number of trees $B$ (in bagging) and $m$ the variable subset size when making a partition of the data. Typically $B$ is fairly large (i.e., 500 to 2,000) and larger than the number of trees needed when bagging because the prediction from each decision tree is somewhat poor with random forests. Oftimes, the variable subset size $m$, often referred to as $mtry$, is a fairly small number (e.g., $\sqrt{p}$, where $p$ is the number of predictor variable). Predictor variables are highly correlated, a smaller value of $m$ typically leads to superior performance.

The optimal value of $m$ can be determined using a grid search, whereas the optimal value of $B$ is first examined using the out-of-bag (OOB) prediction error. Whereas observations that are left out of the bootstrap sample. Recall that bootstrapping is resampling with replacement. Thus, a single observation can appear multiple times in a bootstrap sample, whereas another observation can be left out of a bootstrap sample entirely. These left-out observations are the OOB observations and the prediction error on these OOB observations are a decent approximation of the out-of-sample prediction error (Breiman, 1996a). Although the number of trees and variable subset size are treated as tuning parameters, the size of each decision tree is typically not controlled or varied. Although there is some research on this topic (e.g., Segal, 2004), most software programs utilize defaults for the decision tree size, mainly specifying the minimum number of cases in a terminal node.

In comparison to bagging, random forests is able to model more nuanced relationships in the data, resulting in improved fit. This increased degree of flexibility can lead to a propensity to overfit the training dataset, resulting in less dramatic improvements in fit in the test set. Random forests were also applied to the ECLS-K data as demonstrated in section 6.2, with a sequence of trees and their corresponding training and test datasets displayed in 6.3. Relative to both decision trees and bagging, random forests demonstrated striking improvements in the training dataset, while only incremental improvements are seen in the test dataset. Additionally, we can see that random forests required a larger number of trees to achieve a minimum misfit in test dataset, which can be attributed to the random selection of predictors when partitioning the data.
