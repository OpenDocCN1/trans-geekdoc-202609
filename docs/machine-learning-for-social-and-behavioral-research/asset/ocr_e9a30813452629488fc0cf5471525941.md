# Ensembles

To provide an example of interpreting variable importance, we used the ECLS-K data and 100 trees with the randomForest and partykit packages. As noted, the randomForest package uses the marginal approach to calculating variable importance, whereas the partykit uses the conditional approach to variable importance. Note that conditional variable importance is not the default in the partykit package (varimp(conditional=TRUE)) because it is computationally intense and therefore only recommended when using a small number of variables.

We report the variable importance values from randomForest and partykit packages (both the marginal and conditional) in Table 6.2 and contrast these values with those from a decision tree created with rpart.

# TABLE 6.2. Variable Importance Metrics Across Four Methods

| randomForest | rpart | partykit | conditional | partykit |
|---|---|---|---|-|
| math | 17.29 | 13 | 2.50 | 13.91 |
| knowledge | 28.14 | 13 | 1.23 | 15.6 |
| weight | 1.37 | 0 | 0.18 | 0.61 |
| height | 0.00 | 0 | -0.37 | -0.01 |
| income | 10.95 | 6 | -0.10 | 3.28 |
| SES | 10.94 | 8 | 0.28 | 4.89 |
| read | 100.00 | 6 | 44.61 | 108.6 |

In assessing the values in Table 6.2, the first thing to note is the different scales of the values, with the values from rpart summing to 100, randomForest setting the importance of the most important variable to 100, and partykit is the mean decrease in accuracy which is on a different scale across the marginal and conditional metrics. Also note that these values are only unbiased when subsampling is used (the default in partykit). In comparing the marginal and conditional results from cforest, we note the lower values for all variables other than reading in the conditional results. This is due to the correlations between reading and the other variables, with the conditional approach controlling for this correlation and the marginal approach not controlling for it. This colors our picture specifically of the math and knowledge scales, as the marginal approach points to these values contributing in a non-negligible way (VI values > 0), while the conditional approach results in values of nearly zero. Lastly, all three of the random forest methods result in negligible values for height, income, SES, and weight, leading to the conclusion that their inclusion changes little regarding the predictions of the outcome. See Groëning (2009) or Fisher, Rudin, and Dominici (2019) for more general discussions of variable importance.
