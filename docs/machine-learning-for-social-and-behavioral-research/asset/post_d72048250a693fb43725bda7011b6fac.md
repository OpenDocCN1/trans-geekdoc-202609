
## 3.5 Resampling

To answer the question “How well will my model fit on a holdout sample?”, there are a number of methods that were developed to provide answers without the need for a second dataset. Before detailing these methods, it is important to note that this question reflects model assessment, which is distinct from model selection. Both concepts can be roughly defined as (Hastie, Tibshirani, & Friedman, 2009):

- Model assessment: Estimating the performance of a single model, or after choosing a final new data or data that it would be on new data.
- Model selection: Estimating the performance of multiple algorithms/models and choosing a final model among these.

Model assessment can involve the use of only one machine learning or traditional statistical method, whereas model selection involves choosing methods. In the first example, we may use model assessment to determine how well a quadratic regression model fits. Particularly in small sample sizes, assessing the model on the entire sample may result in an overly optimistic assessment of fit, whereas the use of resampling, could result in a more realistic assessment of fit. Further, when testing on a partition not seen by the model, more complex machine learning algorithms such as ensembles (e.g., random forests) have high propensity to overfit the data when safeguards for both model assessment and selection are not used.

To determine how well our model's predictions will generalize and to select competing models, there are three general strategies: cross-validation (CV; e.g., Browne, 2000), bootstrapping (Efron & Tibshirani, 1986), and the use of different forms of fit indices that penalize for model complexity. The goal of resampling methods (CV and bootstrapping) is to estimate how well our method will perform on independent data with the same characteristics as our original. There are multiple variants of cross-validation and bootstrapping, but we focus on two approaches. The first is referred to as the validation set approach (see Table 3.1; e.g., Harrell, 2015; James, Witten, Hastie, & Tibshirani, 2013), also referred to as the Learn Test paradigm (McArdle, 2012). The validation set approach is a strategy not unique to machine learning, but has been advocated by social and behavioral scientists for decades. The issue with this approach is the loss in power by splitting the sample into two. A further variant on this approach involves splitting the data into three partitions, train, validation, and test (e.g., Hastie et al., 2009).

In general, this strategy can only be advocated for if the starting sample size is large (e.g., $N > 5000$), but it also depends on other characteristics of the data. Therefore, we do not recommend using the validation set approach, or further splitting into three partitions as there are very few data environments in social and behavioral research that can afford such a loss of data for the models. Instead, we discuss other strategies for both model assessment and selection, namely, variants on repeated resampling methods.

### 3.5.1 k-Fold CV

By keeping the original sample intact, one can perform numerous variants of CV, with the most common being k-fold CV. This involves repeatedly splitting the sample into $k$ partitions (i.e., 5 or 10), running the model on $k-1$ combined partitions of the data, and then testing the model on the single partition that is held out. To make this more concrete, the general strategy is displayed in Figure 3.8 using the 5-fold CV as an example. Before starting, we randomly partition the dataset into 5 subsets. In the first step of 5-fold CV, we run the model on 4 randomly selected and combined subsets (dark grey blocks), take this model and create predictions on the 1 holdout subset (light grey block). This gives us a first estimate of holdout performance, using a group of observations the model "did not see." In the second step, this procedure is repeated by selecting an additional 4 subsets to run the model and then creating predictions using the holdout subset (each holdout subset can only be used once). This is 3 more times, resulting in 5 estimates of model performance. These 5 metrics are aggregated to create a 5-fold CV metric. One point in this procedure is that reiterating, and is common to other forms of CV (and bootstrapping), while the model is run on the k-1 partitions of the dataset, it is not rerun on the holdout partition. Instead the model is kept fixed and to create predicted responses for the observations. Using the MSE as an example, this manifests itself as

$$
