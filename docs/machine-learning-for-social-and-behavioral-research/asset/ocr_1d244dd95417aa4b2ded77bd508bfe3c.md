Oftentimes researchers may have some degree of uncertainty as to which approach is best. In this, we recommend running both mixtures and trees, using primarily theoretical judgment to discern which solution is chosen for interpretation. It is tricky to use free criteria to compare the results from mixtures and trees, as the resulting models are not nested. While trees are constrained to only finding groups based on the unique values of covariates, mixtures are only constrained by the number of groups, making them inherently more flexible. It is expected that mixture models will evidence better fitting values of information criteria. We can summarize the benefits and limitations to each approach in a manner of ways. As alluded to this chapter, a number of algorithms are available to researchers for the identification or testing of heterogeneity. We notably omitted a number of these, specifically cluster analysis, which can be used in a very similar way to that of mixtures (see Faley & Rafferty, 1999, for generalizations of cluster analysis to incorporate outcome models), with the distinction being whether class membership is probabilistic (mixtures) or deterministic (cluster analysis). Additionally, while it was mentioned that decision trees specifically assign group membership on covariates, similar processes can be done with regression models (using a grouping variable in ANOVA or logistic regression instance).
