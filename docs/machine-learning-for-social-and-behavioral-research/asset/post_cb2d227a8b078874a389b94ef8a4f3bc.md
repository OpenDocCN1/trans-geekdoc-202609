# 7.4.3 Factor Analysis-Based Reliability

A common recommendation is to use factor analysis (Schmitt, 1996). Using a model, we can get

$$\omega_{Total} = \frac{(\sum_{i=1}^k \lambda_i)^2}{\sum_{i=1}^k \theta_{ii}}$$

where $\lambda_i$ is the factor loading and $\theta_{ii}$ is the residual. One of the consistent findings is that omega, and Cronbach's alpha, does not constrain each to be equal.

# 7.4.4 Factor Scores

Within the general latent variable framework, a common goal is often to use a model with one or more variables to estimate factor scores for each observation, and then use these scores as a predictor or outcome.

There are many proposed methods for factor score estimates. We just cover one, the ordinary least squares (also referred to as Thompson’s or Thorne’s method). This involves the use of SEM matrices, as well as the data matrix ($x_t$)

$f_{regression} = (I + \Lambda\Phi^{-1})^{-1}\Lambda^\Phi^{-1}x_t$

where $\Lambda$ is the full loading matrix and $\Phi$ is the variance-covariance matrix of the latent variables. Alternative factor score estimation methods, such as the Bartlett’s, have similar forms and typically result in factor scores that are highly correlated with one another. One caveat in the cave of factor scores is that using two-step procedures, such as creating factor scores in a first step and then entering these scores into SEM, can result in inaccurate parameter estimates and standard (e.g., Devlieger & Rossel, 2017).
