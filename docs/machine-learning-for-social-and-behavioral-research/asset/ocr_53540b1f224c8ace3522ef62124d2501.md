# 5.5.2 Pathways

Beyond identifying main and interaction effects present in the trees, trees have also been used to describe the various pathways that cases can take end up receiving predictions. More formally, we can describe this as equinality and multfinality, following Scott, Whitehead, Bergman, and Pitzer (2013). In the context of data analysis and tree models, equinality refers to cases having different responses to predictor variables, but similar values on the outcome. On the other hand, multfinality refers to cases having similar values on predictor variables, but different outcome values. As an example of how both of these concepts can be represented in a tree structure, see the tree displayed in Figure 5.18.
