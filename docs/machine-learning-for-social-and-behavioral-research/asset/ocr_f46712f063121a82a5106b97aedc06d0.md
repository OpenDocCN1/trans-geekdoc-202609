# Determining the Number of Topics

In topic modeling, the number of topics was often unknown. Before estimating a topic model, we first need to empirically choose the best number of topics. To do it, we can use cross-validation (CV). For example, a $c$-fold cross-validation can be used. The basic idea of CV is to divide the data into $c$ folds, or $c$ subsets. Each time, we use $c-1$ folds of data to fit a model and then use the left one of data to evaluate the model fit. This can be done for a given number of topics. Then, we can select the optimal number of topics based on a certain measure of the model fit.

In topic models, we use a statistic (e.g., perplexity) to measure the model fit. The perplexity is the geometric mean of word likelihood. In $c$-fold CV, we first estimate the model, usually called the training model, for a given number of topics using $c-1$ folds of the data and then use the left one of the data to calculate the perplexity.
