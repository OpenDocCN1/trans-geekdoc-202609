## 7.2 定义测量误差

测量误差的概念可以在广义和狭义的语境下定义，通常取决于该特定学科中通常遇到的误差类型。更广义地说，遵循经典检验理论（可选性表述请参阅 Kroc & Zumba, 2020），我们可以将变量的观测得分定义为真分数和某种程度误差之和：

```
X = T + E, (7.1)
```

其中 X 是*观测得分*，T 是*真分数*，E 是均值为零的*误差得分*，这意味着 X 与 T 之间没有系统性差异.^1此外，还有许多不符合此假设的更复杂的测量误差模型可用。

这种公式基于经典检验理论，T 通常被认为代表一个未观测的潜分数。在社会和行为研究的大部分范围内，评估测量误差的必要性是因为无法直接测量构念。例如，抑郁症本身是不可直接观测的，因此它们被视为潜变量。我们通过多个指标（量表的形式）推断出个体在这些潜变量上的某些得分，每个项目的创建都是为了直接评估感兴趣的潜构念（例如，贝克抑郁自量表）。为了理解 $X^2$ 的精确程度（precision），我们分解了方程 7.1 中每个分量的方差，以获得可靠性的概念：

