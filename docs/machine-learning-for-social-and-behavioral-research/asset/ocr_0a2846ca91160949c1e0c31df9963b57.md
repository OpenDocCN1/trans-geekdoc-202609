# The Principles of Machine Learning Research

**TABLE 2.1.** Differentiation between Theory-Based and Non-Theory-Based Components of the Study. This is not meant to be comprehensive but to implore researchers to add additional detail to the degree of theory imparting the many decisions that go into planning and executing an analysis.

| | Theory Based | Non-Theory Based |
| --- | --- | --- |
| Algorithm | Algorithm inclusion based on hypothesized relationships in data | Algorithm inclusion based on convenience or maximizing prediction |
| Hyperparameters | Set to be single predictor or a small set | Based on software defaults or test a wide range |
| Variable inclusion | Each predictor is justified | Variables are chosen based on convenience |
| Functional form | All or a subset of relationships are specified | Using ensembles to derive variable importance |
| Model choice for interpretation | Prefer parsimony | Prefer best fit |

What we see in Table 2.1 is the multiple facets to the role of theory in an analysis. Perhaps the use of exploratory or confirmatory to describe each aspect is wanted; however, we chose to use the distinction of theory versus nonempty to better remove obstacles from tradition. Our goal here is to not further complicate an already complex process. Instead, we hope for a culture change, one that doesn't require every paper that uses some form of machine learning to be labeled as exploratory.
