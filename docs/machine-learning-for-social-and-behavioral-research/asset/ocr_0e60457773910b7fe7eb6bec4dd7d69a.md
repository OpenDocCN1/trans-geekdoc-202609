There are both informal and formal ways to accomplish this. Informally, one may examine the $R^2$ or AUC (or others) as assessed with some random forests, choosing the best fit. If the fit values are relatively close, or there is no clear winner, then it is best to choose the most parsimonious model among the best fitting.

A formal way to assess the correspondence between results is to examine the correlation between the predictions with a global surrogate model (such as Molnar, 2019). First, use a less interpretable algorithm to predict an outcome, such as random forests. From these, create predictions for each observation. These predictions are then used in a second step, when a more interpretable algorithm (e.g., linear regression or decision trees) is used to predict the predictions from step one, using the same predictors. Then, the prediction performance can be used to determine how much is lost by using a simpler algorithm. In the ECLS-K, we used a linear regression to model the predictions from random forests, producing a model well, although a linear regression approximates the random forests model well, it is far from perfect, meaning that we are probably missing some degree of nonlinearity or interactions in the linear regression model. We will detail this approach using the ECLS-K data.

Although measures of fit should only be reported either resampling or on a validation set, it sometimes be useful to assess fit on the original sample. For instance, if pairing random forests with a small sample size, it can be common to fit the data perfectly (i.e., AUC or $R^2$ of 1). When this occurs, it would probably be beneficial to consider a less flexible model, as the random forests model is overfitting to a degree that the conclusion and predictions will be unlikely to generalize. Again, in cases such as this, if random forests are too flexible for the size of the data, it will be common to see similar performance using both a linear model and random forests with the resampled metrics. In this case, although a linear model limits the amount that can be gleaned from the data, the dataset is not of sufficient size to allow for more complex conclusions regarding interactions and nonlinear relationships.
