To see the effect of varying *mtry*, we completed an additional SEM forests run, this time setting *mtry* to 2, while also increasing the number of trees to 500. These results are displayed in Figure 10.7.

Here, there is a much more even distribution of importance values, the smaller values depicted on the X-axis. This can be attributed to only two variables being considered for the creation of each tree, which allows for the inclusion of many more variables. We wish to note that this is in line with a marginal, as opposed to conditional, interpretation of variable importance. If researchers wish to give preference to variables that show effects given the testing of other covariates, using higher values of *mtry* may be preferable.
