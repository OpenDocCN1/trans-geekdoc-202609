In ERGM, many other terms can be included on the right-hand side of the model. Here, we discuss some of the terms related to the network, node covariates, and edge covariates. Note that the statistical terms are typically not independent, which can pose serious challenges in estimating ERGM (Robins et al., 2007).

# 12.6.4 Terms Related to the Network

In addition to the number of edges, many other statistics related to the network can be used in an ERGM. We list a few here.

+   * K-Star. Edge is a special case of a network structure called *stars* in which several nodes connect to a central node. We can include an item $S_k$, with one central node and k other nodes connecting to it. Clearly, an edge is $S_1$.
* Degree and density as defined earlier.
* Transitivity. It is equal to the number of triads in the network that are transitive.
* Triangle. The number of triangles in the network.

As an example, we fit a model with three terms—edge, $S_2$, and triangle—to the WeChat network. The results are given in Table 12.7. As in the earlier example simple, the results can be interpreted in terms of logistic regression. The log odds of two students to be WeChat friends is

```
logit(p(a_{ij} = 1)) = -3.458 \times$ the number of edges
$- 0.019 \times$ the number of 2-stars
$+ 0.473 \times$ the number of triangles.
```

For the coefficient for the 2-star, the odds ratio $\exp(-0.019) = 0.982$. It indicates that if adding an edge to the WeChat network, the number of 2-stars increases by 1, while not adding any triangle, the odds for two students to be WeChat friends will decrease by about 1.8% $(0.982 - 1)$. But if it increases one triangle in the network, the odds for two students to be WeChat friends will increase by about 60.6% $(1.606 - 1)$.
