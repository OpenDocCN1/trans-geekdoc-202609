For example, for h = 1, when both students are male or female, otherwise, h = 0. In contrast, for the differential homophily effect, the statistic is defined as

```
$h_{ij}=h(x_i,x_j)=\begin{cases} 1 & \text{if both } i \text{ and } j \text{ have the specific factor level} \ 0 & \text{otherwise.} \end{cases} \quad (12.6)$
```

For instance, if both nodes $i$ and $j$ are males, then $h_{ij}$ is 1, otherwise it is 0. Note that for a categorical covariate with $m$ such maximum effects can be defined.

For the WeChat network, we consider four covariates—GPA, BMI, gender, and whether a student smokes or not. For age, the main effect is used; for BMI, the absolute difference factor effect is considered; for gender, the uniform homophily effect is modeled; for smoking, the differential homophily is included. The results for the analysis are given in Table 12.8.

First, the estimated coefficient of GPA is 0.088 and significant. Since the main factor effect of GPA of two students is higher, the probability for the two students to be WeChat friends is higher. Second, for BMI, the effect is not significant. Therefore, if two students have similar BMI, the likelihood for them to become friends does not significantly change. Third, for gender, the effect is positive and significant. This implies that if two students are both male or female, they are more likely to become WeChat friends. Fourth, for smoking, we evaluate the differential homophily effect. For the effect of both students smoking, it is not significant. However, the effect of both students smoking is positive and significant. Therefore, if both students smoke, the probability for them to be WeChat friends is greater. However, if neither student smokes, it does not increase or decrease the likelihood for them to be WeChat friends.
