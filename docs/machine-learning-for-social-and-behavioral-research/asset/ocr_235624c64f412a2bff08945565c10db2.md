Note is inherent randomness to the variable importance values, which is why setting a seed and using a sufficiently large number of trees is recommended (e.g., using 2,000 trees when 500 achieve the same prediction performance). The actual number of necessary trees varies by application and number of predictors used. Irrelevant variables will importance values randomly around zero, sometimes producing negative estimates. We note, however, that the ranking of variable importance is more important than the values themselves. This is outside of importance values close to zero, as they can be interpreted as this variable contributing little to the prediction of the outcome.

A limit of bagging is that the decision trees created in the bootstrap samples are somewhat related. More specifically, imagine two correlated variables, $x_1$ and $x_2$, with $x_1$ having a slightly stronger association with the outcome $y$. Across bootstrap samples, $x_1$ is going to be selected into the decision tree at a much higher frequency than $x_2$ even though $x_1$ and $x_2$ are highly correlated. This can lead to decision trees that are more similar to one another because of their overreliance on $x_1$ and disregard for $x_2$. To overcome this issue, Breiman (2001a) proposed random forests, discussed subsequently, which randomly sample predictor variables when partitioning the data.
