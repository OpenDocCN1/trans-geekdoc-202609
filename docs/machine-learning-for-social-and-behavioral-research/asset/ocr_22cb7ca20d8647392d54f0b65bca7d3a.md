# 11.4.1 Extracting Text Information

Depending on how the text data are obtained, they might not be in a format that is immediately useful. In this situation, the first step is to extract the useful information. For example, the text below contains information about a typical web page with hypertext written in hypertext markup language (HTML). Although a typical web browser can easily interpret it, the essential text "Incredibly insightful man I have ever had." includes the HTML tags as `<body>` and `</p>`. Therefore, we first need to remove tags and extract the text information we need. Many programs are available to strip HTML tags such as the XML package in R.

```
<body><p class="commentsParagraph>
Incredibly insightful man who will open your mind and eyes to so much. May not get an A but well worth taking his class nonetheless---without a doubt the best professor I have ever had.</p></html>
```

The text below is in the widely used JSON (JavaScript Object Notation) format, a lightweight data-change format. Although it might not appear easy to read for humans, it is easy for computers to parse and generate. For example, both Twitter and Facebook provide APIs (application programming interface) to scrape data from their websites. The scraped data are often stored in the JSON format. For example, below is a tweet from former President Trump. The JSON format data can be parsed into more readable text by software programs as the R package jsonlite.

```
[{"source": "iPhone", "id_str": "107988208535115472", "text": "HAPPY NEW YEAR! https://twitter.com/bHoDPQ7G6_, "created_at": "Mon Dec 21 23:53:06 +0000 2018", "retweet_count": 33548, "in_reply_to_user_id_str": null, "favorite_count": 136012, "is_retweet": false}]
```
