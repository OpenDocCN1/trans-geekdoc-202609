The purpose of this demonstration is not necessarily to dissuade researchers from the use of decision trees, but instead to impart a degree of skepticism regarding the optimality of a single tree. Instability is not necessarily problematic for inferences within the sample, but instead for the assumption that a tree structure derived from this sample is likely to be the same or highly similar to a tree structure created on an alternative sample. Each tree structure should be interpreted with some apprehension, as alternative structures exist that may represent the data just well.

# 5.5.4 Missing Data

Significant research exists evaluates various strategies for handling missing data in decision trees (e.g., Ding & Simonoff, 2010; He, 2006). Some decision tree methods have options for using surrogate splits in the presence of missing data. Surrogate splits work in the following way. After a primary split is found for a given node, surrogate splits can be found by reapplying the partitioning algorithm to predict the primary split. For example, if the primary split on education is between ≤ 12 and > 12 years, then this new variable becomes the outcome, with the remaining variables used as predictors. Those variables that perform best in predicting the primary split are retained (default is five in rpart) and used for those cases that had missing values on the primary split variable. In the sample detailed earlier, if cognitive score is the first surrogate variable, with high values (predicted > 12 years of education) and low values (< 12 years of education), then with high cognitive score (and missing on education) would be given values of > 12 years of education in the tree.

The use of surrogate splits is implemented in both the rpart and partykit packages, however, in partykit, surrogate splits is only implemented for cases when both variables are ordered. If researchers wish to use CART algorithm, then we recommend the use of surrogate splits. However, with other decision tree algorithms, multiple imputation may be the only option for handling missingness. Unfortunately this does not result in a single tree structure, however the K is the number of imputations, where K could be used for high-level inferences, such as which variables were split on and, as well as the stability of the results.
