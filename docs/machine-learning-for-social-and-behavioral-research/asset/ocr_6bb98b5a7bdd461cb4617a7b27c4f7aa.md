# 4.6 Bayesian Regression

The use of Bayesian estimation is becoming increasingly popular in the social and behavioral sciences. As such, researchers often wonder whether the same types of methods that they have utilized in Frequentist estimation also exist in the Bayesian framework. A full description of Bayesian estimation is well beyond the scope of this book. Instead we present a simple applied example of how lasso regression can be applied in a similar manner using Bayesian estimation.

In Bayesian estimation, results similar to ordinary least squares regression can be achieved by using a noninformative (diffuse) normal prior on the regression coefficients. Extending this to ridge and lasso regularization, the ridge has been shown to be equivalent to the use of a more restrictive normal distribution prior, while the lasso is equivalent to a Laplace distribution prior (Tibshirani, 1996). The lasso estimate is the mode of the posterior while the ridge is the mean. To perform variable selection, it is generally preferable to use sparse extensions of these two methods. In contrast to the comparison of testing 100 values of $\Lambda$ in ridge or lasso regression, in Bayesian regularization it is preferable to use a hierarchical representation of a sparse prior, which only requires running one model that implicitly selects an ideal degree of prior variance. Hierarchical Bayesian currently includes methods such as the Bayesian adaptive lasso, the spike and slab prior, and the horseshoe. We provide a brief application of the horseshoe prior. For more detail, see Van Erp, Oberki, and Mulder (2018).
