# Edge Covariates

In network data, edges may have their covariates, too. In the WeChat network, there is no edge covariate. However, in addition to the information on whether two students are WeChat friends, one also asks how frequently they interact on WeChat, the frequency is an edge covariate. For a network, multiple edge covariates can be available and used to define the properties of the edges. The edge covariates can be represented using an adjacency matrix or an edge list matrix.
