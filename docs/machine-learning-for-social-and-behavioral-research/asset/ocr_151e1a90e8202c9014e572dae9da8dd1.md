# 10.2.4 Incorporating Covariates

In applying mixture models it is relatively straightforward to incorporate covariates. The complication is whether it is desirable for the covariates to drive the class creation, or whether effects should just be examined after the classes have been created. To be more concrete, we'll use FMMs as an example. If we wanted to incorporate covariates into the two-factor CFA model detailed in the first section, letting them drive the composition of each latent class, it would probably be most natural to include the covariates as predictors of each latent class, turning the CFA into MIMIC. Running this model, the forming of the latent classes could be a result of any part of the MIMIC model. In contrast, a number of methods have been developed to allow researchers to assess differences on covariates after the class composition has been set. Chief among these are the three-step approach of Asparhouhov and Muthén (2014), which first estimates the latent classes in Step 1. Uncertainty rates are calculated for each class in Step 2, then these are used as an outcome in a multinomial logistic regression with the covariates of interest as predictors in the Step 3.
