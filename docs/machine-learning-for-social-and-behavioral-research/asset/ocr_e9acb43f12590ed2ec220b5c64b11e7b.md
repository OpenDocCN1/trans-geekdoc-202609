After creating a logistic regression model, we output the predicted probabilities and then converted to these predicted labels (using 0.5). To visualize our performance, we first create a comparison table between actual and predicted class labels, or better known as a "confusion matrix."

| Predicted Outcome | Positive Outcome | Negative Outcome | Total |
| --- | --- | --- | --- |
| | Positive TP | Negative FP (α) | PPV |
| | Negative FN (β) | TN | NPV |
| | Total Sens | Spe | N |

From the table, we can calculate the following metrics:

```
$Sensitivity(Sens), Recall = \frac{TP}{TP+FN}$
```

```
$Specificity(Spe) = \frac{TN}{TN+FP}$
```

```
$Precision, PPV = \frac{TP}{TP+FP}$
```

```
$Negative Predictive Value (NPV) = \frac{TN}{TN+FN}$
```

The cells in the table can be broken into four different terms: true positives (TP), true negatives (TN), false positives (FP), and false negatives
