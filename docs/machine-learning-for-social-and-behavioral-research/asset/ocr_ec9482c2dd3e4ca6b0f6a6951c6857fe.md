# 7.6 Alternative Methods

# 7.6.1 Principal Components

Principal components analysis (PCA) is often given coverage in many machine learning books. Like factor analysis (FA), PCA is a dimension reduction technique, simplifying what is often a high-dimensional dataset (number of variables or columns) into a much smaller number of components. To demonstrate the contrast between FA and PCA, we will work with the covariance among a set of variables, which we denote as C. As detailed above, FA decomposes C into two new matrices, the factor loadings matrix and unique variance matrix.

> $C \equiv \Lambda \Phi^T + \Psi^2$.

In contrast, PCA does not model unique forms of variance to each variable
