# 12.6.3 Exponential Random Graph Model

The exponential random graph models are a class of models that allow individual probabilities for edges and the inclusion of network covariates (Harris, 2013). It includes the Erdos-Rényi model as a special case and is probably the most widely used model for network modeling. Instead of working with individual edges, ERGM treats the whole network as a random variable.

Let $Y$ represent a random network with $N$ nodes, and $A$ be an observed network. Both $Y$ and $A$ are $N 	imes N$ matrix. The original ERGM can be expressed as

```
Pr(Y = A) = \frac{\exp[\beta^T s(A)]}{c(\beta)} \propto \exp[\beta^T s(A)] (12.1)
```

where $s(A)$ is a vector of statistics that can be derived from the observed network/or the associated node and edge covariates. For example, the statistics can be number of edges and triangles of a network, and can also be gender and age of the nodes in the network. $\beta$ is a vector of coefficients associated with the statistics to be estimated. Finally, $c(\beta)$ is a normalizing constant.
