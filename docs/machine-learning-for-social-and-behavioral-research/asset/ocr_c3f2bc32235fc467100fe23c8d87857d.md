# 7.4.2 Factor Analysis

The basics for methods such as exploratory factor analysis, confirmatory factor analysis, and structural equation modeling is the assumption of the existence of latent factors. In essence, what we are saying is some "construct" underlies a set of observed variables. The simplest case is that of intelligence. Every (valid) IQ test is the result of some form of factor analysis. By measuring a host of scales, as picture completion, vocabulary, arithmetic, and others, we are saying that the correlation between these variables is not a result of change occurrence, but the overlap between scales can be attributed to a "common factor.\ The use of factor analysis is to see whether there are latent factors underlying correlation matrix (set of variables). The general model can be posed as, decomposing a set of variables, x, into two components

```
x = Λf + e,
```

where the Λ matrix of factor loadings acts as a set of weights for the contribution of single or multiple latent factors, f, on the amount of variability in each observed variable. e is the part of x that is not directly attributable to e. There is a direct relationship between the decomposition of x in Equations 7.1 and 7.5 in that T = f and E = e. Equation 7.5 just adds a weighting component to f which can be equivalently done for T (e.g., see Bollen, 1989). Instead of working directly with the casewise scores for each observed variable, it is common in factor analysis to model the covariance between each x, Σ. In this, we can translate Equation 7.5 into

```
Σ = ΛΦΛ' + Ψ²,
```

where factor loading matrix stays the same, Φ represents the variance-covariance matrix of the latent factors, and Ψ² is the residual covariance matrix. Graphically speaking, we can represent this model in Figure 7.3 using our empirical example.
