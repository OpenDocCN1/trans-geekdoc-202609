# TABLE 10.5. Summarization of Techniques for Identifying or Testing Heterogeneity

| Method | Heterogeneity Source | Outcome Model | Heterogeneity Theory |
| --- | --- | --- | --- |
| Latent class analysis | Unobserved | Categorical variables | Atheoretical |
| Latent profile analysis | Unobserved | Continuous variables | Atheoretical |
| Factor mixture model | Unobserved | Continuous and/or categorical variables constrained in a latent factor model | Atheoretical |
| Decision trees | Observed | A single continuous or categorical variable | Atheoretical |
| Multiple group SEM | Observed | Continuous and/or categorical variables in an SEM | Theoretical |
| SEM trees | Observed | Continuous and/or categorical in an SEM | Atheoretical |
