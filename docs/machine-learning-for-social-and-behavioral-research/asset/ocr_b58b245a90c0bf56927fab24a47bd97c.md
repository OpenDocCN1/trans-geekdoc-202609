Ultimately, when performing a statistical analysis within a hypothesis-driven framework, theoretical considerations influence the model selection to a large extent.

In an alternative research scenario, we may not have any hypotheses regarding the ordering of variable sets. In this, we may wish to explore and identify which sets of variables contribute to the prediction of agree. Using a regularization method such as the lasso, we would select predictors without reference to what set or group of variables belong. If instead wished to select groups of variables, we could use the abovementioned group lasso to apply the group lasso to the same data example we used in the grprg package (Breheny & Huang, 2015). Within this package there is an option to pair the group lasso with cross-validation, using the lowest cross-validated model to fit a select model. The results from the best fitting model are displayed in Table 4.4.

Additionally, we applied a variant of the sparse group lasso, the composite MCP, an even sparser form of bi-level penalization. In Table 4.4, we can see that this resulted in a different number of variables selected in each group, shedding a different light on which variables may be important. For instance, the group lasso selected the set of conscientiousness items while the composite MCP only selected one item. This was the second item, "continue until everything is perfect," answering from "very inaccurate" to "very accurate" with four options in between. Of the conscientiousness items, the second item had the highest correlation with agreeableness (0.26), as well as the highest correlations with other conscientiousness items. As a whole group, conscientiousness predicted agreeableness, but the intercorrelation among items might have made it less clear which variable or variables agreeableness to the greatest degree until the use of variable selection (it was also the only conscientiousness item that was significant in the linear regression).
