## 9.5.2 glmertree

The lmtree function from the glmertree package was specified with a minimum number of observations to partition a node set to 500 and an alpha level set to 1 × 10⁻¹⁶. The small alpha level was used to limit the number of partitions given the large sample size. This alpha level leads to a necessary improvement in model (a likelihood ratio test) equal to $\chi^2$ ≈ 73.5 to retain a partition.

The resulting decision tree from lmtree is contained in Figure 9.4. This figure contains the partitioning value in the node and the partitioning values on the connections between the nodes. Also contained in the node is a probability value for the partition. These probability values are based on permutation tests following the conditional inference approach (Hothorn et al., 2006), and all p < 0.001 because of our stopping rule alpha. The first set of partitions from lmtree were highly similar to those made by longPart2 with the first few partitions based on father's education, poverty status, and mother's education.

The text output of the decision tree is contained in Algorithm 4. In this output, the node number is listed along with the partitioning variable and value. For each terminal node, the sample size is reported along with the estimate for the fixed effect of intercept and slope for the node.
