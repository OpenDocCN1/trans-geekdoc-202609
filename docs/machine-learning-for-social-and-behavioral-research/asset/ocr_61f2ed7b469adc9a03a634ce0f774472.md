#  12.6.2 Stochastic Block Model

The stochastic block model (Holland, Laskey, Leinhardt, 1983) can be viewed as an extension of the Erdos–Rényi model. In a stochastic block model, the nodes are divided into disjoint groups or blocks. The blocks are often called communities. For any node, it can only belong to one block. The number of nodes in each block can be different.

Formally, the N nodes of a network are assigned to each of the K blocks C₁, C², ..., Cₖ with size n₁, n₂, ..., nₖ Each block follows an Erdos–Rényi model so that

```
$$d_{ij}^k \sim \text{Bernoulli}(p_{kk})$$
```

where $d_{ij}^k$ is the edge between $i$ and $j$ in the same block $C_k$ and $p_{kk}$ is the probability for $d_{ij}^k = 1$. For a node $i$ in block $C_k$ and a node $j$ in block $C_l$, the edge also follows a Bernoulli distribution

```
$$d_{ij}^k \sim \text{Bernoulli}(p_{kl})$$$
```

where $p_{kl}$ is the probability of having an edge between node $i$ and node $j$. Therefore, within a block, two nodes have the same probability to be connected and for nodes across two blocks, they also have the same probability to be connected. Overall, we have a probability matrix for the K blocks as

$$P = \begin{pmatrix} P_{11} & P_{12} & \dots & P_{1K} \ P_{21} & P_{22} & \dots & P_{2K} \ \vdots & \vdots & \ddots & \vdots \ P_{K1} & P_{K2} & \dots & P_{KK} \end{pmatrix}$$$

The probability matrix can be estimated with MLE. If the membership is known, the estimation is straightforward. For example, for the WeChat network, we form two block according to the gender of the students, we can get the following probability matrix

```
$$P = \begin{pmatrix} Male & Female \ Male 0.18 & 0.084 \ Female 0.084 & 0.15 \end{pmatrix}$$$
```

Therefore, assuming the edges are random, two male students have a probability of 0.18 to be WeChat friends, and two female students have a probability of 0.15 to be WeChat friends. For a male student and a female student, the probability for them to be WeChat friends is only 0.084.
