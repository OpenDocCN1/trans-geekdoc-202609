# 3-gram

As the 2-gram, we can conduct 3-gram analysis by tokenizing the text into three words. Figure 11.13 shows the top 100 most frequently used three-word phrases. The most used three-word phrase is "very good teacher." 3-gram analysis can provide some information that cannot be observed in unigram and bigram analysis. For example, we can see that "extra credit opportunities" is clearly important to students. In addition, the phrases "not helpful" and "not very clear" would be characterized very differently if using 2-gram analysis.
