To demonstrate this, we provide a simple simulation where we simulated 30,000 samples with a moderately strong relationship between two predictors and one continuous outcome. The $R^2$ in this sample was 0.33. From this, we repeatedly sampled (repeated 200 times) two datasets, each with 100 samples. For both of these datasets, we ran a linear regression models, using 10-fold CV to assess the $R^2$ of each mean. Across these 200 replications, the first set of models had a mean $R^2$ of 0.37 ($SD=0.07$), the second set of models had a mean $R^2$ of 0.35 ($SD=0.07$). Even though no model selection was performed, there was still a bias to the estimates using 10-fold CV, which만이 be attributed to the smaller training sample size.

To elucidate the effect of conflicting model selection and assessment, we chose the highest $R^2$ value across the 200 repetitions, averaged these values, and treated this as our. This process resulted in a mean $R^2$ of 0.41, much higher than the mean of both sets of models. However, we separate the process of model selection and assessment with nested CV, pairing 5-fold CV for the outer loop with 10-fold CV for the inner loop, and repeating this process 200 times (done only for demonstration purposes), we get a mean $R^2$ estimate of 0.34, which was much closer to the estimate from the full sample of 0.33 than any of the other estimates. This highlights the importance of separating the process of model selection and assessment to come up with more realistic estimates of model performance.

Nested CV by creating two loops, one for model selection, and one for model assessment, can be seen as a repeated extension of the training-validation-test paradigm displayed in Table 3.1. This general process is displayed in Figure 3.9.

To give an example of how nested CV would work, we used polynomial regression as an example, using the tuning parameter of degree, with values of 2 and 3. For outer loop number (80% of the sample), we run the inner loop, 5-fold CV to test both polynomial models. For instance, we get a 5-fold estimate of $R^2$ of 0.57 for degree 2 and 0.49 for degree 3. Given that the degree 2 model fit best, we can test this model (with the model being rerun on the training partition of the outer loop) on the test set from the outer loop, thus giving a better estimate of the true $R^2$. This process is repeated four more times (outer loop), each time coming up with an estimate of model fit (5 total).
