# 6.3 Random Forests

Random forests are an extension of bagging that attempts to reduce the similarity between the decision trees estimated on each bootstrap sample. Simply stated, random forests proceeds in the same way as bagging by bootstrapping the data and fitting a decision tree to each bootstrapped dataset. However, decision tree construction does not proceed as usual. In random forests, a subset of the predictors, as opposed to all predictors in bagging, are considered when partitioning the data. This added level of randomness encourages the decision trees to differ more from one another, which allows for a more diverse predictor space. That is, the decision trees are less likely to pigeonhole the prediction space. Once the decision trees are fit to each bootstrapped sampled, predictions are made by averaging predictions from the decision trees.

Selecting a random subset of predictors for variables that have high correlations with other variables to be included in the tree, along with allowing weaker variables to exert an influence. This accounts for the main distinction with bagging, and typically results in superior performance. More formally, the random forests algorithm is explicated in Algorithm 1.

# Algorithm 1 Random Forests Algorithm

+   1. Set $B$, the number of trees
2. Set $m$, the number of variables to consider when making a partition
3. For $b = 1$ to $B$ repeat
   (a) Draw a bootstrap sample of size $N$ from the data
   (b) Grow a decision tree $T_b$ on the bootstrap sample using a random set of $m$ variables for each partition
   (c) Use the out-of-bag samples to create predictions from the decision tree

+   4. Output the ensemble of trees $\{T_b\}_1^B$

+   5. Calculate the final predicted values for each individual

```
$f_{rf}^B(x) = \frac{1}{B} \sum_{b=1}^B T_b(x)$
```
