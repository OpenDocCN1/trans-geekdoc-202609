## 12.6.3. Exponential Random Graph Model

The exponential random graph models are a class of models that allow individual probabilities for edges and the inclusion of network covariates (Harris, 2013). It includes the Erdos-Rényi model as a special case and is probably the most widely used model for network modeling. Instead of working with individual edges, ERGM treats the whole network as a random variable.

Let $Y$ represent a random network with $N$ nodes, and $A$ be an observed network. Both $Y$ and $A$ are $N \times N$ matrix. The original ERGM can be expressed as

```
Pr(Y = A) = \frac{\exp[\beta^T s(A)]}{c(\beta)} \propto \exp[\beta^T s(A)] (12.1)
```

where $s(A)$ is a vector of statistics that can be derived from the observed network/or the associated node and edge covariates. For example, the statistics can be number of edges and triangles of a network, and can also be gender and age of the nodes in the network. $\beta$ is a vector of coefficients associated with the statistics to be estimated. Finally, $c(\beta)$ is a normalizing constant.

## 12.6.4. Terms Related the Network

In addition to the number of edges, many other statistics related to the network can be used in ERGM. We list a few here:

- K-Star. Edge is a special case of network structure called stars in which several nodes connect to a central node. We can include $S_k$, with one central node and $k$ other nodes connecting to it. Clearly, an edge is $S_1$.
- Degree and density defined earlier.
- Transitivity. It is equal to the number of triads in the network that are transitive.
- Triangle. The number of triangles in the network.

## 12.6.5. Terms Related to Node Covariates

The ERGM can be used to investigate how node covariates are related to a network. Like the use of statistics for the network, we can also include the terms derived from the node covariates in the model. For a node covariate $x_i, i = 1, \dots, N$, we can define a function $h_{ij}(x_i, x_j)$ to use in ERGM (Hunter et al., 2008). The function $h$ can be chosen for different types of node covariates (continuous vs. categorical) and the specific effects of interest.

For a continuous covariate $x_i$, the function defines the *main factor effect* as the sum of the covariate of two nodes $i$ and $j$,

```
$h_{ij} = h(x_i, x_j) = x_i + x_j$, (12.2)
```

It can be used to investigate the effect of the total attributes of two nodes on the network such as the sum of GPA on friendship.

Another widely used function for a continuous covariate is called the *absolute difference effect*,

```
$h_{ij} = h(x_i, x_j) = |x_i - x_j|$, (12.3)
```

It describes the *similarity* of two nodes using the Manhattan distance. Because it is expected that similar nodes tend to connect to each other, the *homophily principle* (McPherson, Smith-Lovin, & Cook, 2001), this effect is often used in network analysis.

For a categorical covariate, we define the *nodal factor effect* according to the levels of the covariate as

```
$h_{ij} = h(x_i, x_j) = \begin{cases} 2 & \text{if both nodes $i$ and $j$ have the specific factor level \\ 1 & \text{if exactly one of, $i$, $j$ has the specific factor level \\ 0 & \text{if neither $i$ and $j$ has the specific factor level.} \end{cases}$ (12.4)
```

For example, a nodal factor effect may be a female-female effect.

Other types of effects for categorical data can be defined based on the homophily of covariates. For the *uniform homophily effect*, it can use

```
$h_{ij} = h(x_i, x_j) = \begin{cases} 1 & \text{if $i$ and $j$ have the same factor level \\ 0 & \text{otherwise,} \end{cases}$ (12.5)
```
