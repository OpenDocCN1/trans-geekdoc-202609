# Regularized Regression

To make this form of modeling more concrete, we include a simple example using 150 observations from the bfi dataset. Across 20 variables, there are four groups of variables: demographics, and items measuring conscientiousness, openness, and neuroticism. We could specify a hierarchical sequence of five models:

```
$Model_0 : agree = b_0$
$Model_1 : agree = b_0 + A * demo$
$Model_2 : agree = b_0 + A * demo + B * const$
$Model_3 : agree = b_0 + A * demo + B * const + C * open$
$Model_4 : agree = b_0 + A * demo + B * const + C * open + D * neur$
```

where a is a score of agreeableness, demo refers to a set of gender (0 male; 1 female) and three dummy variables for age, const are five items measuring conscientiousness, open are five items measuring openness, and. Each predictor set addition is based on a specific theoretical relationship. For instance, in the first model, we test whether the addition of demographic variables contributes a significant degree to the prediction of agreeableness and above a null model. In the second model, we similarly test the addition of conscientiousness items and above demographic variables. In this model sequence, we can estimate the increase in $\Delta R^2$ solely due to the addition of a set of variables, resulting in

> $R^2(Model_4) = \Delta R^2(Model_4) + \Delta R^2(Model_3) + \Delta R^2(Model_2) + \Delta R^2(Model_1)$
