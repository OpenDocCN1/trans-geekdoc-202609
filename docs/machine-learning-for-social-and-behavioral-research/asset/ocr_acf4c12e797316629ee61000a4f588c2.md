# 12.3.2 Network Plot

The network plot portrays the network in a graph. In a network plot, the nodes are placed in a two-dimensional space in a certain way. Two nodes are connected using a line if they are related. For example, the plot of the WeChat network is given in Figure 12.3. From the plot, we can see three clusters of nodes (top, bottom left, and bottom right) in the network.

The critical issue in a network plot is to determine the position or layout of the nodes. Many methods have been developed for such a purpose (e.g., Brandes, Kenis, & Wagner, 2003; Fruchter & Reingold, 1991; Kamada & Kawai, 1989). In general, a good method should minimize crossings between edges and maximize the symmetries (Di Battista, Eades, Tamassia, & Tollis, 1994).
