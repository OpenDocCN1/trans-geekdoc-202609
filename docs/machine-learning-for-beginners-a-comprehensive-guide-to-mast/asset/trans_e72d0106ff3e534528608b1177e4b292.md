# 第三章：数据驱动的发现

机器学习（ML）这一蓬勃发展的领域以其在海量数据集中发现隐藏模式的出色能力吸引了科技界。但如何开始揭开 ML 神秘算法的面纱并利用其力量呢？本章旨在通过易于遵循的示例和逐步说明阐明 ML 的基本概念。准备好踏入引人入胜的 ML 世界的第一步吧！

## 什么是机器学习？

机器学习是人工智能的一个子集，使机器能够从数据中学习。简单来说，它是通过训练模型（现实世界过程的数学表示）来做出准确的预测或决策，而无需显式编程执行该任务的过程。

## 机器学习入门

为说明这一点，让我们考虑一个假设场景。你需要根据房屋大小（平方英尺）预测房价。在经典编程中，你可能会创建基于规则的系统：如果大小为 X，则价格为 Y。但如果关系不是线性的，或者需要考虑其他因素，如房间数量或社区怎么办？

这就是机器学习发挥作用的地方。与其编写代码，你可以向模型输入大量数据（例如，许多不同房屋的大小、房间数量、社区和价格）。模型随后会“学习”这些变量之间的关系，并在训练完成后，根据房屋的大小、房间数量和社区预测新房屋的价格。

Python 是一种高级编程语言，以其易于理解和简洁直观而著称。

得益于其专用于机器学习（ML）和数据科学的强大库和框架，它是 AI 领域最受欢迎的语言之一。

要开始使用 Python，你需要安装它。从 [官方 Python 网站](https://www.python.org/downloads/) 下载。安装完成后，你可以在终端或命令提示符中输入 `python --version` 来检查是否安装成功。

你可以用 Python 做的一个小项目是编写一个对数字列表进行排序的程序。下面是一个简单的 Python 代码，使用内置的 `sort()` 函数对列表进行排序：

```python
numbers = \[34, 12, 89, 1, 20, 56\] numbers.sort() print(numbers)
```

运行上述代码后，你将看到排序后的列表作为输出：`[1, 12, 20, 34, 56, 89]`。
