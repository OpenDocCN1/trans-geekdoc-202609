# Littoral Combat Ship-Mission Modules (LCS Packages)

Littoral Combat Ship (LCS) packages—weapons, helicopters, boats, and sensors launched and recovered from LCS seaframes—will provide mine countermeasure (MCM), surface warfare (SUW), and antisubmarine warfare (ASW) capabilities to the LCS seaframe. The Navy plans to deliver these capabilities incrementally and has set interim requirements that are below the baseline requirements for some increments. We assessed the progress of these mission packages against the threshold requirements that define the baseline capabilities currently expected for each one.
