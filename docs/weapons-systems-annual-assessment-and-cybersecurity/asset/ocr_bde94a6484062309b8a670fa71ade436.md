# Attack Sequence: Discover → Implement → Exploit

A cyber attacker looks for ways to get around security controls in order to obtain full or partial control of the system. An attacker typically starts by learning as much as possible about the system—potentially through cyber reconnaissance—to identify vulnerabilities in the system. The more attackers know about the system, the more options they have when designing an attack. An attacker may identify a previously unknown vulnerability that the system owner is unaware of.
