you may instruct the implicit binding to retrieve these models by chaining the withTrashed method onto your route's definition:

```
use App\Models\User;

Route::get('/users/{user}', function (User $user) {
    return $user->email;
})->withTrashed();
```

# Customizing The Key

Sometimes you may wish to resolve Eloquent models using a column other than id . To do so,

you may specify the column in the route parameter definition:

```
use App\Models\Post;

Route::get('/posts/{post:slug}', function (Post $post) {
    return $post;
});
```
