# The Policies Directory

This directory does not exist by default, but will be created for you if you execute the make:policy Artisan command. The Policies directory contains the authorization policy classes for your application. Policies are used to determine if a user can perform a given action against a resource.

# The Providers Directory

The Providers index contains all of the specialist organizations for your application. Specialist organizations bootstrap your application by restricting administrations in the assistance compartment, enrolling occasions, or carrying out some other errands to set up your application for approaching solicitations. In a new Laravel application, this index will, as of now, contain a few suppliers. You are allowed to add your own suppliers to this catalog on a case-by-case basis.
