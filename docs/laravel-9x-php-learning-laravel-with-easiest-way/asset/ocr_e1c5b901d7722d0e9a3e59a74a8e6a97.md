Since we have bound all {user} parameters to the App\Models\User model, an instance of that class will be injected into the route. So, for example, a request to users/1 will inject the User instance from the database which has an ID of 1 . If a matching model instance is not found in the database, a 404 HTTP response will be automatically generated.
