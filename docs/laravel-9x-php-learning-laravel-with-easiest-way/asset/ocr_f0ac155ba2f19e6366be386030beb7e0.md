# Configuration Caching

To give your application a speed help, you ought to reserve all of your design documents into a single document utilizing the config:cache Artisan order. This will consolidate the entirety of the setup choices for your application into a solitary document which can be immediately stacked by the system. You ought to regularly run the php artisan config:cache order as a feature of your creation sending process. The order ought not be run during nearby improvement as arrangement choices will often should be altered during the direction of your application's turn of events.

> {note} If you execute the config:cache command during your deployment process, you should be sure that you are only calling the env function from within your configuration files. Once the configuration has been cached, the .env file will not be loaded; therefore, the env function will only return external, system level environment variables.
