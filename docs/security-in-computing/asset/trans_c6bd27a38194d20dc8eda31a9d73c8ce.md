
我们在[第2章](#ch02.html#ch02)中介绍了数字签名。回顾一下，数字签名就像手写签名一样，是一种将个人独有的标记与一段文本关联起来的方法。该标记应具有**不可伪造性**，意味着只有发起人能够计算签名值。但该标记应具有**可验证性**，意味着其他人应该能够检查签名是否来自声称的发起人。

计算数字签名的通用方法是使用公钥加密；签名者使用私钥计算签名值，其他人可以使用公钥来验证签名是否来自相应的私钥。

正如我们在[第2章](#ch02.html#ch02)中指出的，数字签名必须满足两项要求，理想情况下还应满足另外两项：

*   **不可伪造性（强制）**。除签名者外，无人能在没有签名者私钥的情况下生成该签名。
*   **真实性（强制）**。接收者能够确定签名确实来自签名者。
*   **不可篡改性（期望）**。签名者、接收者或任何拦截者均无法在篡改不被察觉的情况下修改签名。
*   **不可重用性（期望）**。任何重用先前签名的尝试都将被接收者检测到。

为了支持数字签名，我们需要强健的公钥算法。本章前面描述的RSA算法适用于数字签名，但它并非唯一的选择。

### 椭圆曲线密码系统

椭圆曲线密码学（ECC）由Victor Miller（IBM）和Neil Koblitz（华盛顿大学）于1985年发现[[MIL85](#bib01.html#bib_409), [KOB87](#bib01.html#bib_339)]，作为实现公钥密码学的一种替代机制。与RSA不同，ECC基于有限域中的对数；ECC的一个优势是可以用比RSA更短的密钥长度获得同等的安全性。

RSA自诞生以来的一个问题是其开发者为该算法申请了专利。因此，算法的使用者可能需要支付许可费。ECC算法的开发者将其置于公共领域，从而避免了许可和费用。（其他开发者已为结合ECC的技术申请了专利，因此并非所有涉及ECC的内容都免专利。）

椭圆曲线密码学背后的数学原理非常复杂，远超我们在此所能呈现的范围。椭圆曲线是满足诸如`y² = x³ + a*x + b`（其中`a`和`b`为常数）等方程的点的`(x,y)`坐标。Nick Sullivan [[SUL13](#bib01.html#bib_598)] 指出，任意非垂直直线最多通过曲线上的三个点。并且，给定任意两点`P`和`Q`，我们可以找到直线`PQR`所通过的第三点`R`。当`P = (x[P],y[P])`且`Q = (x[Q],y[Q])`时：

```
P + Q = R
```

其中

```
s = (y[P] – y[Q]) / (x[P] – x[Q])
x[R] = s² – x[P] – x[Q]
```

以及

```
y[R] = –y[P] + s(x[P] – x[R])
```

注意`s`是通过`P`和`Q`的直线的斜率。因此，给定`P`和`Q`，我们可以代数地找到直线`PQR`上的第三个点。这意味着我们也可以找到`QRT`上的下一点`T`，然后是`RTV`上的`V`，以此类推。还有一个公式让我们可以从单个点开始推导出第二个点：一个点可得第二点，两点可得第三点。

椭圆曲线密码系统增加了一个转折，这应当从RSA算法的数学原理中耳熟能详：ECC运算在一个有限群中进行，即对某个素数`p`取模`p`的整数。因此，虽然在基本ECC方程中`x`和`y`值无界增长，但将算术限制在有限域内才使得密码学问题难以逆向。给定起点`P`和终点`Z`，并将结果约束在有限域内，问题在于从`P`到`Z`需要多少步。更正式地说，找到使`P^(k) = Z`成立的值`k`。换句话说，找到`k`，即`Z`以`P`为底的对数。事实证明，目前已知最快的回答该问题的方法是从`P`开始生成所有中间点，直到获得`Z`。

椭圆曲线密码学很少单独用于公钥加密。然而，它常被用作数字签名的组件。2005年，美国国家安全局（NSA）发布了其保护美国政府敏感和非机密通信的战略和建议。该战略包括一套推荐的高级密码算法，称为Suite B。Suite B中包含的协议有：用于密钥交换和协商的椭圆曲线Diffie-Hellman（ECDH）和椭圆曲线Menezes-Qu-Vanstone（ECMQV）；用于数字签名的椭圆曲线数字签名算法（ECDSA）；用于对称加密的高级加密标准（AES）；以及安全哈希算法（SHA）。吸引NSA采用ECC的特点是其相对于公钥密码算法而言强大的安全性、高效性和可扩展性。

### El Gamal和数字签名算法

另一种公钥算法由Taher El Gamal于1984年设计[[ELG85](#bib01.html#bib_180), [ELG86](#bib01.html#bib_181)]。虽然该算法不广泛直接使用，但它在美国数字签名标准（DSS）[[NIS92](#bib01.html#bib_451), [NIS94](#bib01.html#bib_452)]中具有重要意义。该算法依赖于在有限域上计算离散对数的困难性。因为它基于有限域中的算术运算，正如RSA一样，所以它与RSA有一些相似之处。

#### El Gamal签名算法

在El Gamal算法中，要生成密钥对，首先选择一个素数`p`和两个整数`a`和`x`，使得`a < p`且`x < p`，并计算`y = a^x mod p`。素数`p`的选择应使得`(p - 1)`有一个大的素因子`q`。私钥是`x`，公钥是`y`，连同参数`p`和`a`。

要对消息`m`签名，选择一个随机整数`k`，`0 < k < p - 1`，该整数以前未使用过且与`(p - 1)`互质，并计算

```
r = a^(k) mod p
```

和

```
s = k^(–1) (m – xr) mod (p – 1)
```

其中`k^(–1)`是`k`模`(p - 1)`的乘法逆元，使得`k * k^(–1) = 1 mod (p - 1)`。消息签名随后为`r`和`s`。接收者可以使用公钥`y`计算`y^r r^s mod p`，并确定其等价于`a^(m) mod p`。要破解此加密并根据`r`、`s`和`m`推断`x`和`k`的值，入侵者必须找到一种计算离散对数的方法来求解`y = a^x`和`r = a^k`。

#### 数字签名算法

美国数字签名算法（DSA）（也称为数字签名标准或DSS）[[NIS94](#bib01.html#bib_452)]是带有一些限制的El Gamal算法。首先，`p`的大小被专门固定为`2^(511) < p < 2^(512)`（因此`p`大约有170位十进制数字）。其次，`(p - 1)`的大素因子`q`的选择使得`2^(159) < q < 2^(160)`。该算法显式地使用哈希值`H(m)`，而不是完整的消息文本`m`。最后，`r`和`s`的计算取模`q`。一种解释是这些变化使得不想或不需要理解底层数学的人也能轻松使用该算法。然而，这些变化也通过减少攻击者的不确定性而削弱了加密的潜在强度。
