
我们描述此问题旨在展示攻击者如何有效地规划和实施攻击。表面上插入的缺陷之微妙，再次印证了我们在本书其他地方所述：开发密码学非业余爱好者所为，因为即便是专业人士也难以洞察潜在缺陷。

## 12.6 量子密码学

我们现在转向一种基于物理学进步的新兴密码学形式。一些分析师称这种密码学有可能彻底改变加密和密码分析，尽管其他人怀疑它短期内不太可能变得实用。

我们已见研究人员如何依赖数学层面生成难题并设计算法。本节我们将探讨未来密码学可能的另一种实现视角。文中描述的方法目前尚未上市，未来几年内也大概率不会上市。但它阐释了在发明新加密技术时进行创造性思考的必要性。尽管该方法背后的科学原理深奥，但方法本身其实相当简单。

这种新方法——量子密码学，在某种程度上是一次性密码本思想的变体。回顾本章前文，一次性密码本是唯一可被证明不可破解的加密方案。一次性密码本需要一长串不可预测数字的两份副本，发送方和接收方各持一份。发送方将一个数字与一单元明文结合生成密文。若数字*真正*不可预测（即绝无可辨识模式），攻击者便无法将数字与密文分离。

该方法的难点在于鲜有可共享的随机数字串来源。许多自然现象可产生不可预测的数字串，但随之而来的问题是如何将该串传递给接收方，使截获者无法获取。量子密码学同时解决了生成和通信数字的问题。Wiesner 在 1980 年代首次探索了此思路 [[WIE83]](#bib01.html#bib_658)；十年后 Bennett 进一步发展了该想法 [[BEN92a]](#bib01.html#bib_56), [[BEN92b]](#bib01.html#bib_57)。

### 量子物理学

与其他密码学方法不同，量子密码学基于物理学而非数学。它利用我们对光粒子行为的认知。光粒子称为光子。它们在空间传播，向各方向振动；我们称其具有主振动的方向取向。尽管光子方向取向可为 0° 至 360° 任意值，为便于解释，我们假设仅有四种方向取向（将实际取向四舍五入至最近的 90°）。我们用四个符号表示这四种取向：`↔`、`![Image](graphics/center-arrow.jpg)`、`![Image](graphics/left-arrow.jpg)` 和 `![Image](graphics/right-arrow.jpg)`。`↔` 和 `![Image](graphics/center-arrow.jpg)` 光子可高确定性区分。然而，`![Image](graphics/left-arrow.jpg)` 和 `![Image](graphics/right-arrow.jpg)` 光子有时会呈现为 `↔` 或 `![Image](graphics/center-arrow.jpg)`。同理，`![Image](graphics/left-arrow.jpg)` 和 `![Image](graphics/right-arrow.jpg)` 可相互区分，但有时 `↔` 和 `![Image](graphics/center-arrow.jpg)` 会被识别为 `![Image](graphics/left-arrow.jpg)` 或 `![Image](graphics/right-arrow.jpg)`。幸运的是，这些缺陷实则为密码算法提供了部分混淆性。

**偏振滤波器** 是一种接受任意光子为输入、仅输出特定种类光子的设备或过程。光子滤波器有两类：`+` 和 `×`。`+` 滤波器能准确区分 `↔` 和 `![Image](graphics/center-arrow.jpg)` 光子，但有 50% 几率将 `![Image](graphics/left-arrow.jpg)` 或 `![Image](graphics/right-arrow.jpg)` 误判为 `↔` 或 `![Image](graphics/center-arrow.jpg)`；反之，`×` 滤波器能区分 `![Image](graphics/left-arrow.jpg)` 和 `![Image](graphics/right-arrow.jpg)`，但也可能接受一半的 `↔` 和 `![Image](graphics/center-arrow.jpg)` 光子。可将 `+` 滤波器类比为窄水平狭缝：`↔` 光子易滑过，`![Image](graphics/center-arrow.jpg)` 光子总被阻挡。有时（约一半概率），`![Image](graphics/left-arrow.jpg)` 或 `![Image](graphics/right-arrow.jpg)` 光子因振动方式得以穿过狭缝。`×` 滤波器则类似垂直狭缝。

### 光子接收

量子密码学通过从发送方向接收方发送光子流运作。发送方使用偏振滤波器控制发送光子种类。接收方任选一滤波器并记录接收光子的取向。接收方是否选用与发送方相同滤波器无关紧要；关键在于接收方是否碰巧选用了与发送方同类型的滤波器。

量子密码学最重要的特性是：任何人窃听通信都会影响通信本身。借助简单的错误检测编码，发送方和接收方即可轻松判断是否存在窃听者。海森堡不确定性原理指出：我们无法同时知晓粒子在任一时刻的速度与位置；一旦测量速度，位置已改变；一旦测量位置，速度已改变。基于此原理，测量粒子任一属性都会影响其他属性。例如，测量光子取向会影响该光子。水平狭缝滤波器阻挡所有 `![Image](graphics/center-arrow.jpg)` 及一半 `![Image](graphics/left-arrow.jpg)` 和 `![Image](graphics/right-arrow.jpg)` 光子，从而影响透过的光子流。发送方知晓发送内容，接收方知晓接收内容，但窃听者会极大地改变光子流，使发送方和接收方极易察觉有人在监听。

让我们看看这种非同寻常的方法如何用于密码学。
