
Kaminsky 发现了这一过程中的缺陷：即这些查询会保持开放状态直到获得回答，且与查询 ID 编号匹配的响应会被缓存。如果攻击者能够猜测查询 ID 编号的序列，攻击者就可以伪造一个满足开放查询 ID 的响应；该伪造的回复可以提供任意地址作为响应。在该响应从缓存中移除之前，针对所请求地址的所有流量都将被定向到伪造回复中给出的地址。因此，通过正确预测序列号并向特定名称服务器生成网络流量，攻击者可以悄无声息地将流量重定向到选定的地址。

---

**在缓存投毒攻击中，一个不正确的名称到地址的 DNS 转换被放入转换缓存并保留在那里。**

---

此例展示了可预测序列号的脆弱性。针对此类攻击的对策是使用*不可预测*的序列号系列，最好从大范围的可能性中选取。

多年来，互联网管理机构一直在致力于实施针对此类重放和劫持攻击的防护措施。这一目标通过 **DNSSEC**（DNS 安全扩展，RFC 4033 [[ARE05](#bib01.html#bib_33)]）得以实现。2010 年 6 月，第一台根 DNS 服务器被分配了一个用于签署 DNS 记录的私钥；其他根服务器也将被分配密钥。根级别的每条 DNS 记录都将被签署并发布，连同根管理员的公钥，一起发布在 DNS 本身中。随着根名称服务器记录被签署，其他名称服务器将逐步获取公钥并签署其记录。最终，客户端的地址请求也将意味着获取并检查名称解析路径上所有记录的签名。

### 利用已知漏洞

攻击者拥有大量工具来发起攻击。黑客工具通常从已知漏洞入手，有时是早已有补丁可用的著名漏洞；人们习惯于不给旧系统或远程位置的系统打补丁。由于漏洞公开与首次被利用之间的时间间隔，未打补丁的系统正成为一个严重问题。Symantec [[SYM10](#bib01.html#bib_605)] 报告称，2009 年，对于微软在 Internet Explorer 中修补的 28 个漏洞，披露与利用之间的平均窗口期不到一天；漏洞公开后平均两天就会出现利用代码。补丁发布之日至漏洞首次被利用之日的窗口期确实非常短。此外，2009 年 Symantec 识别出了 12 个零日漏洞利用。**零日漏洞利用** 是指在漏洞公开之前就发生利用，因此在补丁可用之前就已被利用的漏洞。

一些工具，如 `R-U-Dead-Yet` 和 `EvilGrade`，会检查多种漏洞。特洛伊木马、病毒和其他类型的恶意软件可形成拒绝服务攻击的基础。一种流行但特别有效的攻击工具包是 `Zeus`，成本不到 700 美元，但在黑客地下世界也免费流通。安全公司 Symantec 已记录了超过 90,000 种 `Zeus` 变体 [[SYM10](#bib01.html#bib_605)]。在这些工具中，拒绝服务有时是副产品；该工具利用最终导致系统崩溃的漏洞，从而拒绝服务，或至少干扰服务。正如我们在本章后面所述，利用漏洞通常是攻击者夺取计算机控制权的第一步，被控计算机随后会被征召进攻击者的“僵尸网络”。

### 物理断连

最后，我们来看看导致拒绝服务的最后一个原因：物理故障。网络由设备、连接器和传输媒介组成，其中任何一项都可能发生故障。一根断裂的电缆、故障的电路板、或故障的交换机或路由器，造成的拒绝服务危害不亚于黑客攻击。正如攻击者在毫无预警且往往无明显原因的情况下发动攻击一样，硬件故障也是意料之外的。

#### 传输故障

通信失败的原因有很多。例如，线路被切断。或网络噪声导致数据包无法识别或无法投递。传输路径上的某台机器因硬件或软件原因发生故障。设备为维修或测试而退出服务。设备饱和，在清除过载前拒绝接收传入数据。其中许多问题在包括互联网在内的主要网络中是暂时的或会自动修复（绕过）。

然而，一些故障无法轻易修复。通往您计算机的单条通信线路发生断裂（例如，从网络到您的网络接口卡，或电话线到您的调制解调器），只能通过建立替代链路或修复受损线路来解决。网络管理员会说“网络其余部分的服务未受影响”，但这对您来说毫无安慰作用。

#### 组件故障

组件（例如路由器、电路板、防火墙、监控设备、存储设备和交换机）会因不明原因发生故障。老化、出厂缺陷、电源浪涌、过热和人为破坏都会影响硬件。网络往往是一个脆弱的组件链，所有组件都是维持网络运行所必需的。在最坏的情况下，任何单个组件的故障都会导致整个网络瘫痪。在 [Sidebar 6-18](#ch06.html#ch06sb18) 中，我们描述了一两块电路板的故障如何影响弗吉尼亚州。

硬件故障几乎总是自然发生的。虽然人为诱导的硬件损坏不常见，但并非不可能。例如，前文 [Sidebar 6-7](#ch06.html#ch06sb07) 中描述的 `Stuxnet` 蠕虫可使机械设备过度运转直至故障。

我们探讨了可称为个体拒绝服务攻击的行为，即使单个主机瘫痪或拒绝为单个地址或网段提供服务。这种情况对受影响的主机或地址而言是令人遗憾的。虽然这种危害会使普通用户丧失能力，但大型装置（如企业或主要政府机构）却无动于衷，因为它们拥有巨大的容量和弹性。然而，研究这些攻击更严重的原因在于，它们可作为可重复的组件用于规模大得多的攻击中，而这类攻击能够并确实严重影响主要用户。在下一节中，我们将研究这些分布式拒绝服务攻击。

---

**拒绝服务攻击将一名对手与一个目标对立起来；资源充足的目标通常能比装备较差的攻击者坚持更久。**

### Sidebar 6-18 弗吉尼亚州因 IT 故障陷入瘫痪

2010 年 8 月 25 日，弗吉尼亚州 89 个机构中的 26 个机构的计算机服务瘫痪，影响了该州 13% 的文件服务器。州政府机构无法访问为客户提供服务所需的数据。受影响最明显的是该州的机动车管理部门，无法签发驾照或身份证。州税务部和州选举委员会也受到严重影响，近一周无法访问数据库；其他州政府机构受影响长达三天。在瘫痪期间，税务部无法访问纳税人账户，州政府无法发放失业救济金，福利金之所以能发放，仅靠员工周末加班的巨大努力。
