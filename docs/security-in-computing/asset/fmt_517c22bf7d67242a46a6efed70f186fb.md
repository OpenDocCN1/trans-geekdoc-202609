用户手册描述了软件产品的接口和功能。如果你真的想了解一款软件是如何构建的、如何工作的、如何将其嵌入另一款软件，或其详细规格是什么，你需要另一种文档。然而，正常使用软件并不需要这些高级主题。

本章补充了 [第 2 章](#ch02.html#ch02) 中介绍的加密讨论。在前面的章节中，我们将密码学作为一种工具介绍，并在后续章节中多次使用。对许多人来说，密码学的用户手册已足够。但对于想要或需要了解更多细节的人，我们在本章中对密码学进行了扩展阐述。

我们从密码分析简介开始。尽管全书我们都展示了技术如何失效或被导致失效，但我们尚未深入探讨克服密码学保护这一丰富主题。在描述失效类型后，我们将探讨知名加密算法和实现的潜在及实际缺陷。最后，我们将介绍密码学嵌入应用的实例：哈希码和数字签名。

你不应指望本章能让你领会密码学的细微之处，更别说设计自己的加密算法了。密码学是一个专门领域，依赖数学和理论计算机科学的多个分支，包括数论、有限域代数、计算复杂性和逻辑。读完此概览后，你仍需建立大量背景知识才能深入研究密码学。我们强烈警告你：不要学一点密码学就自以为能设计自己的安全密码系统。密码学领域充斥着甚至专家设计的失败方案，因此非专家最好“把驾驶交给专业人士”。例如，请参阅 [侧边栏 12-1](#ch12.html#ch12sb01) 了解自创密码学的危害。
