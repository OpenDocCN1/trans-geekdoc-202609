
# 创建标签

一旦你识别出了模式，请相应地标记数据。例如，你可以将每个周期标记为“双底”或“非双底”。

## 创建平衡标签

确保你拥有一个平衡的数据集。如果你的数据包含过多的“非双底”标签，而“双底”标签过少，模型可能会产生偏见，并在未来难以识别该模式。请尝试保持正例（模式存在）与反例（模式不存在）的良好比例。

标记至关重要，因为它有助于模型理解它在寻找什么。如果没有正确标记的数据，模型将无法有效地区分不同的图表模式。

# 特征选择：从数据中提取什么

一旦你的数据已获取并标记，下一步就是特征选择。特征是你的机器学习模型用来进行预测的变量或属性。在图表模式识别中，特征是描述价格走势和市场状况的关键要素。

## 交易数据中的关键特征

以下是交易者通常为机器学习模型提取的一些常见特征：

*   **价格水平**：开盘价、最高价、最低价和收盘价是描述市场价格行为的基本特征。
*   **移动平均线**：计算短期和长期移动平均线有助于捕捉趋势和市场动能。常用的选项包括 50 日或 200 日移动平均线。
*   **成交量数据**：交易量是市场强弱的重要指标。成交量的显著变化通常伴随着关键图表模式的形成。
*   **价格差值**：开盘价与收盘价之间的差值，或连续 K 线之间的差值，能提供关于价格动能的有价值信息。
*   **指标**：技术指标如 `Relative Strength Index (RSI)`、`Bollinger Bands` 和 `Moving Average Convergence Divergence (MACD)` 常被用来增强模型的预测能力。

## 选择合适的特征

特征选择至关重要，因为无关或冗余的特征会干扰模型并降低其准确性。你需要选择与图表模式最相关的特征。例如，如果你专注于三角形或旗形等模式，纳入成交量和波动率数据将非常重要，因为这些模式通常依赖于交易活动的变化。

关键在于在包含足够相关特征以让模型全面了解市场状况，与避免用不必要的信息过度加载模型从而阻碍其学习过程之间取得平衡。

# 为机器学习预处理数据

原始交易数据很少能直接用于机器学习。在将其输入模型之前，通常需要对其进行清洗和转换。这一过程称为数据预处理，旨在确保你的数据采用一致的、机器可读的格式。

## 归一化

在机器学习中，归一化是一种将特征缩放至相似数值范围的技术。这一点很重要，因为交易数据的量级差异可能很大；想想低价股和蓝筹股之间的价格差异。如果不进行归一化，数值较大的特征可能会主导模型的学习过程，导致预测不准确。

例如，如果你的数据集同时包含价格水平和成交量数据，你可能会将这些特征归一化，使它们落在同一范围内（例如 0 到 1 之间）。这确保了模型在进行预测时对所有特征赋予同等权重。

## 处理缺失数据

在交易数据中，你经常会因假日、盘后交易或数据源技术问题而遇到缺失值。缺失数据会给机器学习模型带来麻烦，因为它们依赖完整信息来做出准确预测。

处理缺失数据有几种策略：

*   **移除缺失数据**：如果缺失数据量很小，你可以直接移除不完整的行。
*   **插补**：如果无法移除数据，你可以用平均值、中位数，甚至最近的可用数据点来填补缺失值。
*   **高级方法**：对于更复杂的模型，你可以使用插值或回归等技术，根据周围数据点来估算缺失值。

## 将数据拆分为训练集和测试集

数据清洗完成后，最后一步是将其拆分为训练集和测试集。训练集用于训练模型，而测试集用于评估模型在未见数据上的表现。常见的拆分比例是 80/20，即 80% 的数据用于训练，20% 保留用于测试。

# 第四章

## 用于图表模式识别的机器学习算法

既然我们已经介绍了准备数据的要点，现在是时候深入机器学习的核心：算法了。就像在交易中，不同的策略适用于不同的市场条件一样，各种机器学习算法也各有优劣。

### 决策树和随机森林

#### 决策树

决策树是最简单、最易解释的机器学习算法之一。想象你站在十字路口，决定向左还是向右。决策树模仿这种思维：在每一步（或“节点”），它提出一个是非问题，例如“收盘价是否高于开盘价？”根据答案，它分支进入不同路径，直到得出结论，即“叶子节点”。每个叶子代表一个预测，如识别出特定的图表模式。

例如，决策树可能会分析股票图表并判断：“如果价格连续三天上涨，且成交量增加，则我们有一个看涨三角形模式。”虽然决策树易于理解且在小数据集上效果良好，但它们在处理更复杂的模式时可能会吃力，且容易过拟合，意味着它们可能在训练数据上表现良好，但在新的、未见过的数据上表现不佳。

#### 随机森林

这就是随机森林发挥作用的地方。随机森林就像让多棵决策树协同工作，形成一个树的集成。每棵树在略有不同的数据子集上训练，当需要预测时，所有树对结果进行“投票”。最终预测基于多数表决。

这种方法减少了过拟合，并带来更准确的预测。在交易中，随机森林对于在嘈杂和波动的市场中识别模式特别有用。例如，随机森林可能会分析多个资产的价格走势、成交量和时间框架，比单棵决策树更准确地预测双顶模式的出现。

### 支持向量机 (SVM)

支持向量机 (SVM) 是另一种用于图表模式识别的强大工具，特别是在你需要将数据分类到不同类别时。SVM 通过寻找最佳“超平面”来分离不同类别的数据。想象你在图上绘制点；每个点代表一根 K 线或一次价格波动。SVM 算法画出一条线（或在高维空间中的一个平面），最好地将数据分成不同的组。目标是使类别之间的间隔尽可能宽，确保清晰的区分。

在图表模式识别的背景下，SVM 特别适用于对市场状况进行分类，例如识别某个价格走势类似于看涨旗形还是看跌旗形。SVM 擅长处理复杂的高维数据，这使得它们在涉及多个变量（价格、成交量、移动平均线等）时非常有效。
