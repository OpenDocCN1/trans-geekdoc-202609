# 9.2.1 Quadratic decision boundaries

From Eq. (9.3), we see that the unnormalized log posterior over class labels is given by

log p(y = c|x, θ) = log π_c − ½ log |2π Σ_c| − ½ (x − μ_c)^T Σ_c^{−1} (x − μ_c) + const (9.4)

This is called the discriminant function. We see that the decision boundary between any two classes, say c and c′, will be a quadratic function of x. Hence this is known as quadratic discriminant analysis (QDA).

For example, consider the 2d data from 3 different classes in Fig. 9.1a. We fit full covariance Gaussian class-conditionals (using the method explained in Sec. 9.2.4), and plot the results in Fig. 9.1b. We see that the features for the blue class are somewhat correlated, whereas the features for the green class are independent, and the features for the red class are independent and isotropic (spherical covariance). In Fig. 9.2a, we see that the resulting decision boundaries are quadratic functions of x.
