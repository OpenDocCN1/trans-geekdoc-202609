# Algorithm 3: Iterative algorithm for computing λ(a) in Eq. (10.111). From [AWS19].

+   1 Input: logits a, temperature t > 1 ;
+   2 μ := max(a) ;
+   3 a := a − μ ;
+   4 while a not converged do
+   5   Z(a) := Σ_{c=1}^C exp_t(a_c) ;
+   6   a := Z(a)^{1−t} (a − μ1) ;
+   7 Return − log_t 1/Z(a) + μ
