model using a Gaussian prior, where $D_{1:t} = \{(x_n, y_n) : n = 1 : t\}$ is all the data we have seen so far. This is particularly useful in cases where the data is arriving in a continual stream, such as online advertising (see e.g., [Gra+10]) and recommender systems (see e.g., [Aga+14]). We follow the presentation of [Zoc07].

We assume our model has the following form:

$p(y_t | x_t, w_t) = \text{Ber}(y_t | \sigma(x_t^\top w_t))$ (10.166)
$p(w_t | w_{t-1}) = \mathcal{N}(w_t | w_{t-1}, \sigma^2 I)$ (10.167)

where $\sigma^2$ is some process noise which allows the parameters to change slowly over time. (This can be set to 0, as in the recursive least squares method (Sec. 11.6.7), if desired.) See Fig. 10.18 for an illustration. As our approximating family, we will use diagonal Gaussians, for computational efficiency. Thus the prior is the posterior from the previous timestep, and has the form

$q_{t-1}(w_{t-1}) = \prod_j \mathcal{N}(w_{t-1,j} | \mu_{t-1,j}, \tau_{t-1,j})$ (10.168)

Now we discuss how to update this prior.

Define the logits as $a_t = w_t^\top x_t$. If $q_{t|t-1}(w_t) = \prod_j \mathcal{N}(w_{t,j} | \mu_{t|t-1,j}, \tau_{t|t-1,j})$, then we can compute the predictive distribution for $a_t$ as follows:

$q_{t|t-1}(a_t) = \mathcal{N}(a_t | m_{t|t-1}, v_{t|t-1})$ (10.169)
$m_{t|t-1} = \sum_j x_{t,j} \mu_{t|t-1,j}$ (10.170)
$v_{t|t-1} = \sum_j x_{t,j}^2 \tau_{t|t-1,j}$ (10.171)

The posterior for $a_t$ is given by

$$q_t(a_t)=\mathcal{N}(a_t\mid m_t,v_t) \tag{10.172}$$

$$m_t=\int a_t\frac{1}{Z_t}p(y_t\mid a_t)q_{t\mid t-1}(a_t)\,da_t \tag{10.173}$$

$$v_t=\int a_t^2\frac{1}{Z_t}p(y_t\mid a_t)q_{t\mid t-1}(a_t)\,da_t-m_t^2 \tag{10.174}$$

$$Z_t=\int p(y_t\mid a_t)q_{t\mid t-1}(a_t)\,da_t \tag{10.175}$$

where $p(y_t\mid a_t)=\text{Ber}(y_t\mid a_t)$. These integrals are one dimensional, and so can be computed using Gaussian quadrature, as explained in [Zoe07].

Having inferred $q_t(a_t)$, we need to compute $q_t(\mathbf{w}\mid a_t)$. This can be done as follows. Define $\delta_m$ as the change in the mean and $\delta_v$ as the change in the variance:

$$m_t=m_{t\mid t-1}+\delta_m,\quad v_t=v_{t\mid t-1}+\delta_v \tag{10.176}$$

Then one can show that the new factored posterior over the model parameters is given by

$$q_t(w_{t,j})=\mathcal{N}(w_{t,j}\mid\mu_{t,j},\tau_{t,j}) \tag{10.177}$$

$$\mu_{t,j}=\mu_{t\mid t-1,j}+a_j\delta_m \tag{10.178}$$

$$\tau_{t,j}=\tau_{t\mid t-1,j}+a_j^2\delta_v \tag{10.179}$$

$$a_j\triangleq\frac{x_{t,j}\tau_{t\mid t-1,j}}{\sum_{j'}x_{t,j'}^2\tau_{t\mid t-1,j'}} \tag{10.180}$$

Thus we see that the parameters which correspond to inputs with larger magnitude (big $|x_{t,j}|$) or larger uncertainty (big $\tau_{t\mid t-1,j}$) get updated most, which makes intuitive sense.

Note that the whole algorithm only takes $O(D)$ time and space per step, the same as SGD. However, unlike SGD, there are no step-size parameters, since the diagonal covariance implicitly specifies the size of the update for each dimension. Furthermore, we get a posterior approximation, not just a point estimate.
