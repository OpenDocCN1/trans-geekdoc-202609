# 1.2.2.1 Linear regression

As an example, consider the 1d data in Fig. 1.6a. We can fit this data using a simple linear regression model of the form

f(x; θ) = b + w x   (1.12)

where w is the slope, b is the offset, and θ = (w, b) are all the parameters of the model. By adjusting θ, we can minimize the sum of squared errors, shown by the vertical lines in Fig. 1.6b. until we find the least squares solution

θ̂ = argmin_θ MSE(θ)   (1.13)

See Sec. 11.2.2.1 for details.
