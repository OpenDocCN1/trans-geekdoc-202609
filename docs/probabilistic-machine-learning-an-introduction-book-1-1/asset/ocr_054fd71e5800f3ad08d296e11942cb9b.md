We compute the output by convolving channel c of the input with kernel W_{:,:,c}, and then summing over channels:

z_{i,j} = b + \sum_{u=0}^{H-1} \sum_{v=0}^{W-1} \sum_{c=0}^{C-1} x_{s i + u, s j + v, c} w_{u, v, c} \quad (14.13)

where s is the stride (which we assume is the same for both height and width, for simplicity), and b is the bias term. This is illustrated in Fig. 14.7.
