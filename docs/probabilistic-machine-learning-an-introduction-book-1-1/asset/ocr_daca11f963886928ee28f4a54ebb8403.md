# 12.2. The exponential family

We can put this into exponential family form by defining

```
η = log(μ / (1 - μ))

t(y) = y

A(η) = -log(1 - μ) = log(1 + e^η)

h(y) = 1
```

We can recover the mean parameter μ from the canonical parameter η using

```
μ = σ(η) = 1 / (1 + e^{-η})
```

# 12.2.2.2 Categorical distribution

We can represent the discrete distribution with K categories as follows (where y_k = I(y = k)):

```
Cat(y|μ) = ∏_{k=1}^K μ_k^{y_k} = exp [ ∑_{k=1}^K y_k log μ_k ]

= exp [ ∑_{k=1}^{K-1} y_k log μ_k + (1 - ∑_{k=1}^{K-1} y_k) log(1 - ∑_{k=1}^{K-1} μ_k) ]

= exp [ ∑_{k=1}^{K-1} y_k log (μ_k / (1 - ∑_{j=1}^{K-1} μ_j)) + log(1 - ∑_{k=1}^{K-1} μ_k) ]

= exp [ ∑_{k=1}^{K-1} y_k log (μ_k / μ_K) + log μ_K ]
```

where μ_K = 1 - ∑_{k=1}^{K-1} μ_k. We can write this in exponential family form as follows:

```
Cat(y|η) = exp(η^T t(y) - A(η))

η = [log μ_1, ..., log μ_{K-1}]

A(η) = -log(μ_K)

t(y) = [I(y = 1), ..., I(y = K-1)]

h(y) = 1
```

We can recover the mean parameters from the canonical parameters using

```
μ_k = e^{η_k} / (1 + ∑_{j=1}^{K-1} e^{η_j})
```
