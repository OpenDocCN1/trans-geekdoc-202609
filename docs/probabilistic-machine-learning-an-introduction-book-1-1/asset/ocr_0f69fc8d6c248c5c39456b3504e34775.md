Alternatively, we could have decomposed the matrix M in terms of E and M/E = (H - G E^{-1} F), yielding

(E F; G H)^{-1} = (E^{-1}+E^{-1}F(M/E)^{-1}GE^{-1}  -E^{-1}F(M/E)^{-1}; -(M/E)^{-1}GE^{-1}  (M/E)^{-1})  (C.120)

# C.3.3 The matrix inversion lemma

Equating the top left block of the first matrix in Eq. (C.118) with the top left block of the matrix in Eq. (C.119)

(E - F H^{-1} G)^{-1} = E^{-1} + E^{-1} F (H - G E^{-1} F)^{-1} G E^{-1}  (C.121)

This is known as the matrix inversion lemma or the Sherman-Morrison-Woodbury formula.

A typical application in machine learning is the following. Let X be an N × D data matrix, and Σ be N × N diagonal matrix. Then we have (using the substitutions E = Σ, F = G^T = X, and H^{-1} = -I) the following result:

(Σ + X X^T)^{-1} = Σ^{-1} - Σ^{-1} X (I + X^T Σ^{-1} X)^{-1} X^T Σ^{-1}  (C.122)

The LHS takes O(N^3) time to compute, the RHS takes time O(D^3) to compute.

Another application concerns computing a rank one update of an inverse matrix. Let E = A, F = u, G = v^T, and H = -1. Then we have

(A + u v^T)^{-1} = A^{-1} + A^{-1} u (-1 - v^T A^{-1} u)^{-1} v^T A^{-1}  (C.123)

= A^{-1} - (A^{-1} u v^T A^{-1})/(1 + v^T A^{-1} u)  (C.124)

This is known as the Sherman-Morrison formula.

# C.3.4 Matrix determinant lemma

We now use the above results to derive an efficient way to compute the determinant of a block-structured matrix.

From Eq. (C.114), we have |X||M||Z| = |W| = |E - F H^{-1} G||H|  (C.125)

|(E F; G H)| = |E - F H^{-1} G||H|  (C.126)

|M| = |M/H||H|  (C.127)

|M/H| = |M|/|H|  (C.128)

So we can see that M/H acts somewhat like a division operator.
