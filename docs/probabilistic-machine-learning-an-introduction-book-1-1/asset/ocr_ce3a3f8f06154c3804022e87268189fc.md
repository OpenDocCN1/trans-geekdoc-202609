where η(x) ∈ ℝ^M is a random feature vector derived from x, either based on trigonometric functions Eq. (17.97) or exponential functions Eq. (17.98). (The latter has the advantage that all the features are positive, which gives much better results [Cho+20b].) Therefore for the regular softmax attention, A_{i,j} can be rewritten as

A_{i,j} = 𝔼[φ(q_i)^⊤ φ(k_j)]  (15.42)

where φ is defined as:

φ(x) ≜ exp( ‖x‖₂² / (2√D) ) η( x / D^{1/4} ).  (15.43)

We can write the full attention matrix as follows

A = 𝔼[Q' (K')^⊤]  (15.44)

where Q', K' ∈ ℝ^{N×M} have rows encoding random feature maps corresponding to the queries and keys. (Note that we can get better performance if we ensure these random features are orthogonal, see [Cho+20a] for the details.) See Fig. 15.23 for an illustration.

We can create an approximation to A by using a single sample of the random features φ(q_i) and φ(k_j), and using a small value of M, say M = O(D log(D)). We can then approximate the entire attention operator in O(N) time using

widehat{attention}(Q, K, V) = diag^{-1}( Q' ((K')^⊤ 1_N) ) ( Q' ((K')^⊤ V) )  (15.45)

This can be shown to be an unbiased approximation to the exact softmax attention operator. See Fig. 15.24 for an illustration. (For details on how to generalize this to masked (causal) attention, see [Cho+20a].)
