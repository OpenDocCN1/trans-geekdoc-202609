As a simple example, Fig. 13.21 shows a 5 layer MLP which has been fit to some 1d regression data using an l1 regularizer on the weights. We see that the resulting graph topology is sparse. Of course, many other approaches to sparse estimation are possible.

Despite the intuitive appeal of sparse topology, in practice these methods are not widely used, since modern GPUs are optimized for dense matrix multiplication, and there are few computational benefits to sparse weight matrices. However, if we use methods that encourage group sparsity, we can prune out whole layers of the model. This results in block sparse weight matrices, which can result in speedups and memory savings (see e.g., [Sca+17; Wen+16; MAV17; LUW17]).



Suppose that we randomly (on a per-example basis) turn off all the outgoing connections from each neuron with probability p, as illustrated in Fig. 13.22. This technique is known as dropout [Sri+14].

Dropout can dramatically reduce overfitting and is very widely used. Intuitively, the reason dropout works well is that it prevents complex co-adaptation of the hidden units. In other words, each unit must learn to perform well even if some of the other units are missing at random. This prevents the units from learning complex, but fragile, dependencies on each other.4 A more formal explanation, in terms of Gaussian scale mixture priors, can be found in [NHLS19].

We can view dropout as estimating a noisy version of the weights, θij = wijεij, where εij ~ Ber(1 − p) is a Bernoulli noise term. (So if we sample εij = 0, then all of the weights going out of unit i in layer l − 1 into any j in layer l will be set to 0.) At test time, we usually turn the noise off; this is equivalent to setting εij = 1. To derive the corresponding estimate for the non-noisy weights, we should use wij = θij / E[εij], so the weights have the same expectation at test time as they did

> Geoff Hinton, who invented dropout, said he was inspired by a talk on sexual reproduction, which encourages genes to be individually useful (or at most depend on a small number of other genes), even when combined with random other genes.
