# 3.7 Mixture models

One way to create more complex probability models is to take a convex combination of simple distributions. This is called a mixture model. This has the form p(y|θ) = ∑k=1K πk pk(y) where pk is the k'th mixture component, and πk are the mixture weights which satisfy 0 ≤ πk ≤ 1 and ∑k=1K πk = 1.

We can re-express this model as a hierarchical model, in which we introduce the discrete latent variable z ∈ {1,…,K}, which specifies which distribution to use for generating the output y. The prior on this latent variable is p(z = k) = πk, and the conditional is p(y|z = k) = pk(y) = p(y|θk). That is, we define the following joint model: p(z|θ) = Cat(z|π) p(y|z = k, θ) = p(y|θk)
