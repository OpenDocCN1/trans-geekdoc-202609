The optimistic function \tilde{R} can be obtained in different ways, sometimes in closed forms. One approach is to use a **concentration inequality** [BLM16] to derive a high-probability upper bound of the estimation error: |\hat{R}_t(s,a) - R_t(s,a)| \le \delta_t(s,a), where \hat{R}_t is a usual estimate of R (often the MLE), and \delta_t is a properly selected function. An optimistic reward is then obtained by setting \tilde{R}_t(s,a) = \hat{R}_t(s,a) + \delta_t(s,a).

As an example, consider again the context-free Bernoulli bandit, R(a) ~ Ber(\mu(a)). The MLE \hat{R}_t(a) = \hat{\mu}_t(a) is given by Eq. (8.63). (For simplicity we will assume N_t(a) > 0 for all a.) Then the **Chernoff-Hoeffding inequality** [BLM16] leads to \delta_t(a) = c / \sqrt{N_t(a)} for some proper constant c, so

\begin{equation}
\tilde{R}_t(a) = \hat{\mu}_t(a) + \frac{c}{\sqrt{N_t(a)}}
\tag{8.74}
\end{equation}

We may also derive \tilde{R} from Bayesian inference. If we use a beta prior, we can compute the posterior in closed form, as shown in Eq. (8.66). The posterior mean is \hat{\mu}_t(a) = \mathbb{E}[\mu(a)|\mathcal{D}_t] = \frac{\alpha_t}{\alpha_t + \beta_t}. From Eq. (7.23), the posterior standard deviation is approximately

\begin{equation}
\hat{\sigma}_t(a) = \sqrt{\mathbb{V}[\mu(a)|\mathcal{D}_t]} \approx \sqrt{\frac{\hat{\mu}_t(a)(1 - \hat{\mu}_t(a))}{N_t(a)}}
\tag{8.75}
\end{equation}

We then pick the action
\begin{equation}
a_t = \argmax_a \hat{\mu}_t(a) + c\hat{\sigma}_t(a)
\tag{8.76}
\end{equation}
for some constant c that controls how greedy the policy is. We see that this is similar to the frequentist method based on concentration inequalities.
