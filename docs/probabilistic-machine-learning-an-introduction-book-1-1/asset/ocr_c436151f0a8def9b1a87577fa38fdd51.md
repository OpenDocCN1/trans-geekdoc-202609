We can marginalize out z_n to get p(y_n|x_n). If y_n is a scalar, this becomes

p(y_n|x_n, θ) = N(y_n | x_n^T v, w_y^T C w_y + σ_y^2) (20.78)
C = (I + σ_x^{-2} W_x^T W_x)^{-1} (20.79)
v = σ_x^{-2} W_x C w_y (20.80)

To apply this to the classification setting, we can use supervised ePCA [Guo09], in which we replace the Gaussian p(y|z) with a logistic regression model.

This model is completely symmetric in x and y. If our goal is to predict y from x via the latent bottleneck z, then we might want to upweight the likelihood term for y, as proposed in [Ris+08]. This gives

p(X, Y, Z|θ) = p(Y|Z, W_y) p(X|Z, W_x)^α p(Z) (20.81)

where α ≤ 1 controls the relative importance of modeling the two sources. The value of α can be chosen by cross-validation.

# 20.2.8.2 Partial least squares

Another way to improve the predictive performance in supervised tasks is to allow the inputs x to have their own “private” noise source that is independent on the target variable, since not all variation in x is relevant for predictive purposes. We can do thus by introducing an extra latent variable z_n^x just for the inputs, that is different from z_n^s that is the shared botteleneck between x_n and y_n. In the Gaussian case, the overall model has the form
p(z_n) = N(z_n^s|0,I) N(z_n^x|0,I) (20.82)
p(x_n|z_n, θ) = N(x_n|W_x z_n^s + B_x z_n^x, σ_x^2 I) (20.83)
p(y_n|z_n, θ) = N(y_n|W_y z_n^s, σ_y^2 I) (20.84)

See Fig. 20.15b. MLE for θ in this model is equivalent to the technique of partial least squares (PLS) [Gus01; Nou+02; Sun+09].
