# 4.5.1 Example: MOM for the univariate Gaussian

For example, consider the case of a univariate Gaussian distribution. From Sec. 4.2.5, we have

μ₁ = μ = ȳ  (4.91)
μ₂ = σ² + μ = s²  (4.92)

where ȳ is the empirical mean and s² is the empirical average sum of squares. so \hat{μ} = ȳ and \hat{σ}² = s² - ȳ². In this case, the MOM estimate is the same as the MLE, but this is not always the case.

# 4.5.2 Example: MOM for the uniform distribution

In this section, we give an example of the MOM applied to the uniform distribution. Our presentation follows the wikipedia page.² Let Y ~ Unif(θ₁,θ₂) be a uniform random variable, so

p(y|θ) = 1/(θ₂ - θ₁) 𝕀(θ₁ ≤ y ≤ θ₂)  (4.93)

The first two moments are

μ₁ = 𝔼[Y] = ½(θ₁ + θ₂)  (4.94)
μ₂ = 𝔼[Y²] = ⅓(θ₁² + θ₁θ₂ + θ₂²)  (4.95)

Inverting these equations gives

(θ₁, θ₂) = ( μ₁ - √[3(μ² - μ₁²)], 2μ₁ - θ₁ )  (4.96)

Unfortunately this estimator can give sometimes give invalid results. For example, suppose 𝒟 = {0,0,0,0,1}. The empirical moments are \hat{μ}₁ = 1/5 and \hat{μ}₂ = 1/5, so the estimated parameters are \hat{θ}₁ = 1/5 - 2√3/5 = -0.493 and \hat{θ}₂ = 1/5 + 2√3/5 = 0.893. However, these cannot possibly be the correct parameters, since if θ₂ = 0.893, we cannot generate a sample as large as 1.
