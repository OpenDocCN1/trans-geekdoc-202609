Suppose we choose a Gaussian posterior approximation, $q(\mathbf{f}_Z)=\mathcal{N}(\mathbf{f}_Z|\mathbf{m},\mathbf{S})$. Since $p(\mathbf{f}_Z)=\mathcal{N}(\mathbf{f}_Z|\mathbf{0},\mathcal{K}(\mathbf{Z},\mathbf{Z}))$, we can compute the KL term in closed form using the formula for KL divergence between Gaussians (Eq. (6:31)) to get

$\mathbb{KL}(q(\mathbf{f}_Z)||p(\mathbf{f}_Z))=\frac{1}{2}\left[\operatorname{tr}(\mathbf{K}_{Z,Z}^{-1}\mathbf{S})+\mathbf{m}^\top\mathbf{K}_{Z,Z}^{-1}\mathbf{m}-M+\log\left(\frac{\det\mathbf{K}_{Z,Z}}{\det\mathbf{S}}\right)\right]$ (17.80)

This term and its gradient can be computed in $O(M^3)$ time.

As for the expected log-likelihood term, we have

$\mathbb{E}_{q(\mathbf{f}_X)}[\log p(\mathbf{y}|\mathbf{f}_X)]=\sum_{n=1}^{N}\mathbb{E}_{q(f_n)}[\log p(y_n|f_n)]$ (17.81)

where $q(f_n)$ is derived in Sec. 17.4.1.1 (setting the query set to $T=\mathbf{x}_n$). For Gaussian likelihoods, we can compute each of these terms exactly (see Sec. 17.4.1.3. For logistic likelihoods, we can use 1d integration to compute these terms.

To compute the gradients of the expected log likelihood, we leverage the following result [OA09]:

$\frac{\partial}{\partial\mu}\mathbb{E}_{\mathcal{N}(x|\mu,\sigma^2)}[h(x)]=\mathbb{E}_{\mathcal{N}(x|\mu,\sigma^2)}\left[\frac{\partial}{\partial x}h(x)\right]$ (17.82)
$\frac{\partial}{\partial\sigma^2}\mathbb{E}_{\mathcal{N}(x|\mu,\sigma^2)}[h(x)]=\frac{1}{2}\mathbb{E}_{\mathcal{N}(x|\mu,\sigma^2)}\left[\frac{\partial^2}{\partial x^2}h(x)\right]$ (17.83)

We then substitute $h(x)$ with $\log p(y_n|f_n)$.

The total cost of computing $\mathcal{L}(q,\mathbf{Z})$ and its gradient is $O(M^3+N M^2)$. We discuss stochastic approximations to this (for large $N$) below. We can then optimize the ELBO $\mathcal{L}(q,\mathbf{Z})$ wrt $\mathbf{m}$, $\mathbf{S}$ and $\mathbf{Z}$ using gradient methods. (In practice, we write $\mathbf{S}=\mathbf{L}\mathbf{L}^\top$ and optimize wrt $\mathbf{L}$.)

# 17.4.1.3 Gaussian likelihoods

If we have a Gaussian observation model, we can compute the expected log likelihood in closed form. In particular, if we assume $m(\mathbf{x})=\mathbf{0}$, we have (from [HFL13, Eq.4]) the following:

$\mathbb{E}_{q(f_n)}[\log\mathcal{N}(y_n|f_n,\beta^{-1})]=\log\mathcal{N}(y_n|\mathbf{k}_n^\top\mathbf{K}_{Z,Z}^{-1}\mathbf{m},\beta^{-1})-\frac{1}{2}\beta\tilde{k}_{nn}-\frac{1}{2}\operatorname{tr}(\mathbf{S}\mathbf{\Lambda}_n)$ (17.84)

where $\tilde{k}_{nn}=k_{nn}-\mathbf{k}_n^\top\mathbf{K}_{Z,Z}^{-1}\mathbf{k}_n$, $\mathbf{k}_n$ is the $n$'th column of $\mathbf{K}_{Z,X}$ and $\mathbf{\Lambda}_n=\beta\mathbf{K}_{Z,Z}^{-1}\mathbf{k}_n\mathbf{k}_n^\top\mathbf{K}_{Z,Z}^{-1}$. We can plug this into Eq. (17.79) to derive the ELBO $\mathcal{L}(q)$.

One can show that
$\nabla_{\mathbf{m}}\mathcal{L}(q,\mathbf{Z})=\beta\mathbf{K}_{Z,Z}^{-1}\mathbf{K}_{Z,X}\mathbf{y}-\mathbf{\Lambda}\mathbf{m}$ (17.85)
$\nabla_{\mathbf{S}}\mathcal{L}(q,\mathbf{Z})=\frac{1}{2}\mathbf{S}^{-1}-\frac{1}{2}\mathbf{\Lambda}$ (17.86)

where
$\mathbf{\Lambda}=\mathbf{K}_{Z,Z}^{-1}+\sum_{n=1}^{N}\mathbf{\Lambda}_n=\beta\mathbf{K}_{Z,Z}^{-1}\mathbf{K}_{Z,X}\mathbf{K}_{X,Z}\mathbf{K}_{Z,Z}^{-1}+\mathbf{K}_{Z,Z}^{-1}$ (17.87)
