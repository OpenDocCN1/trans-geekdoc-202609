The posterior predictive mean is given by μ∗=k∗⊤K−1X,Xy. For reasons of numerical stability, it is unwise to directly invert KX,X. A more robust alternative is to compute a Cholesky decomposition, KX,X=LL⊤, which takes O(N3) time. Then we compute α=L⊤∖(L⊤∖y), where we have used the backslash operator to represent backsubstitution (Sec. C.7.1). Given this, we can compute the posterior mean for each test case in O(N) time using μ∗=k∗⊤K−1X,Xy=k∗⊤L−T(L−Ty)=k∗⊤α (17.56) We can compute the variance in O(N2) time for each test using σ2∗=k∗∗−k∗⊤K−1X,XkX∗,X=k∗∗−v⊤v (17.57) where v=L⊤∖k∗,X. Finally, the log marginal likelihood (needed for kernel learning, Sec. 17.3.6) can be computed using logp(y|X)=−12y⊤α−∑Nn=1logLnn−N2log(2π) (17.58)



Most kernels have some free parameters, which can have a large effect on the predictions from the model. For example, suppose we are performing 1d regression using a GP with an RBF kernel. Since the data has observation noise, the kernel has the following form: Ky(xp,xq)=σ2f exp(−12ℓ2(xp−xq)2)+σ2yδpq (17.59) Here ℓ is the horizontal scale over which the function changes, σ2f controls the vertical scale of the function, and σ2y is the noise variance.
