# B.4.7 Conjugate duality

In this section, we briefly discuss conjugate duality, which is a useful way to construct linear lower bounds to non-convex functions, which we can then easily maximize. We follow the presentation of [Bis06, Sec.10.5].

# B.4.7.1 Introduction

Consider an arbitrary continuous function f(x), and suppose we create a linear lower bound on it of the form

$$\mathcal{L}(\mathbf{x}, \lambda) \triangleq \lambda^{\top} \mathbf{x} - f^{*}(\lambda) \le f(\mathbf{x}) \tag{B.69}$$

where λ is the slope, which we choose, and f*(λ) is the intercept, which we solve for below. See Fig. B.13(a) for an illustration.

For a fixed λ, we can find the point x_λ where the lower bound is tight by “sliding” the line upwards until it touches the curve at x_λ, as shown in Fig. B.13(b). At x_λ, we minimize the distance between the function and the lower bound:

$$\mathbf{x}_{\lambda} \triangleq \arg\min_{\mathbf{x}} f(x) - \mathcal{L}(\mathbf{x}, \lambda) = \arg\min_{\mathbf{x}} f(\mathbf{x}) - \lambda^{\top} \mathbf{x} \tag{B.70}$$

(We assume this minimum exists and is unique.) Since the bound is tight at this point, we have

$$f(\mathbf{x}_{\lambda}) = \mathcal{L}(\mathbf{x}_{\lambda}, \lambda) = \lambda^{\top} \mathbf{x}_{\lambda} - f^{*}(\lambda) \tag{B.71}$$

and hence

$$f^{*}(\lambda) = \lambda^{\top} \mathbf{x}_{\lambda} - f(\mathbf{x}_{\lambda}) = \max_{\mathbf{x}} \lambda^{\top} \mathbf{x} - f(\mathbf{x}) \tag{B.72}$$

The function f* is called the conjugate of f, also known as the Fenchel transform of f. For the special case of differentiable f, f* is called the Legendre transform of f.
