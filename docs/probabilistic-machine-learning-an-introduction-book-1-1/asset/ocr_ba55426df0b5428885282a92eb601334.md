We can perform approximate posterior inference in this model using a variety of methods. We will use a method called HMC (see Sec. 7.7.4), which combines gradient based methods with Monte Carlo sampling, and which is implemented in many software libraries. The result is a set of samples from the posterior, (φ^s, θ^s) ~ p(φ, θ|D) from which we can compute any quantity of interest. (See Sec. 7.5.1 for a faster approximate inference method.)
