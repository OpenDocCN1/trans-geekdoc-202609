The existence of adversarial examples is best viewed as a symptom of the more general problem of lack of robustness to distribution shift. A model's accuracy drops on some shifted distribution of inputs q(x) that differs from the training distribution p(x), then the model will necessarily be vulnerable to an adversarial attack: if errors exist, there must be a nearest such error. Furthermore, if the input distribution is high dimensional, then we should expect the nearest error to be significantly closer than errors which are sampled randomly from some out-of-distribution q(x).
