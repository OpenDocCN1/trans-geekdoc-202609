This is similar to a Newton update, except we use **B**, which is a fixed matrix, rather than **H**($\boldsymbol{\theta}^t$), which changes at each iteration. This can give us some of the advantages of second order methods at lower computational cost.

Let us now apply this to logistic regression, following [Kri+05]. Let $\boldsymbol{\mu}_n(\mathbf{w}) = [p(y_n = 1 \mid \mathbf{x}_n, \mathbf{w}), \ldots, p(y_n = C \mid \mathbf{x}_n, \mathbf{w})]$ and $\mathbf{y}_n = [\mathbb{I}(y_n = 1), \ldots, \mathbb{I}(y_n = C)]$. We want to *maximize* the log-likelihood, which is as follows:

$$L(\mathbf{w}) = \sum_{n=1}^{N} \left[\sum_{c=1}^{C} y_{nc}\mathbf{w}_c^\top \mathbf{x}_n - \log \sum_{c=1}^{C} \exp(\mathbf{w}_c^\top \mathbf{x}_n)\right] \tag{10.73}$$

The gradient is given by the following (see Sec. [10.3.2.3] for details of the derivation):

$$\mathbf{g}(\mathbf{w}) = \sum_{n=1}^{N}(\mathbf{y}_n - \boldsymbol{\mu}_n(\mathbf{w})) \otimes \mathbf{x}_n \tag{10.74}$$

where $\otimes$ denotes kronecker product (which, in this case, is just outer product of the two vectors). The Hessian is given by the following (see Sec. [10.3.2.4] for details of the derivation):

$$\mathbf{H}(\mathbf{w}) = -\sum_{n=1}^{N}\left(\operatorname{diag}(\boldsymbol{\mu}_n(\mathbf{w})) - \boldsymbol{\mu}_n(\mathbf{w})\boldsymbol{\mu}_n(\mathbf{w})^\top\right) \otimes (\mathbf{x}_n\mathbf{x}_n^\top) \tag{10.75}$$

We can construct a lower bound on the Hessian, as shown in [Boh92]:

$$\mathbf{H}(\mathbf{w}) \succeq -\frac{1}{2}\left[\mathbf{I} - \frac{1\,1^\top}{C}\right] \otimes \left(\sum_{n=1}^{N}\mathbf{x}_n\mathbf{x}_n^\top\right) \triangleq \mathbf{B} \tag{10.76}$$

where $\mathbf{I}$ is a $C$-dimensional identity matrix, and $\mathbf{1}$ is a $C$-dimensional vector of all 1s.¹ In the binary case, this becomes

$$\mathbf{H}(\mathbf{w}) \succeq -\frac{1}{2}\left(1-\frac{1}{2}\right)\left(\sum_{n=1}^{N}\mathbf{x}_n\mathbf{x}_n^\top\right) = -\frac{1}{4}\mathbf{X}^\top\mathbf{X} \tag{10.77}$$

This follows since $\mu_n \leq 0.5$ so $-(\mu_n - \mu_n^2) \geq -0.25$.

We can use this lower bound to construct an MM algorithm to find the MLE. The update becomes

$$\mathbf{w}^{t+1} = \mathbf{w}^{t} - \mathbf{B}^{-1}\mathbf{g}(\mathbf{w}^{t}) \tag{10.78}$$

This iteration can be faster than IRLS (Sec. [10.2.6]) since we can precompute $\mathbf{B}^{-1}$ in time independent of $N$, rather than having to invert the Hessian at each iteration. For example, let us consider the binary case, so $\mathbf{g}^{t} = \nabla L(\mathbf{w}^{t}) = \mathbf{X}^\top(\mathbf{y} - \boldsymbol{\mu}^{t})$, where $\boldsymbol{\mu}^{t} = [p_n(\mathbf{w}^{t}), (1-p_n(\mathbf{w}^{t}))]_{n=1}^{N}$. The update becomes

$$\mathbf{w}^{t+1} = \mathbf{w}^{t} - 4(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{g}^{t} \tag{10.79}$$

Compare this to Eq. (10.37), which has the following form:

$$\mathbf{w}^{t+1} = \mathbf{w}^{t} - \mathbf{H}^{-1}\mathbf{g}(\mathbf{w}^{t}) = \mathbf{w}^{t} - (\mathbf{X}^\top\mathbf{S}^{t}\mathbf{X})^{-1}\mathbf{g}^{t} \tag{10.80}$$

where $\mathbf{S}^{t} = \operatorname{diag}(\boldsymbol{\mu}^{t} \odot (1-\boldsymbol{\mu}^{t}))$. We see that Eq. (10.79) is faster to compute, since we can precompute the constant matrix $(\mathbf{X}^\top\mathbf{X})^{-1}$.

¹ If we enforce that $w_C = 0$, we can use $C-1$ dimensions for these vectors / matrices.
