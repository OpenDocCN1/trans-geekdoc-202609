As another example, consider transforming a density from Cartesian coordinates x = (x1, x2) to polar coordinates y = f(x1, x2), so g(r, θ) = (r cos θ, r sin θ). Then

J_g = (∂x1/∂r ∂x1/∂θ; ∂x2/∂r ∂x2/∂θ) = (cos θ -r sin θ; sin θ r cos θ) (D.60)
|det(J_g)| = |r cos² θ + r sin² θ| = |r| (D.61)

Hence
p_{r,θ}(r,θ) = p_{x1,x2}(r cos θ, r sin θ) r (D.62)
