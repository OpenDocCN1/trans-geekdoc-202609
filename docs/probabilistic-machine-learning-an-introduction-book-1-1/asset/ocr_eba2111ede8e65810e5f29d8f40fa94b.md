# 11.6.3 Uninformative priors

A common criticism of Bayesian inference is the need to use a prior. This is sometimes thought to “pollute” the inferences one makes from the data. We can minimize the effect of the prior by using an uninformative prior, as we discussed in Sec. 7.3. We give some examples below.

# 11.6.3.1 Jeffreys prior for linear regression

From Sec. 7.3.1.3, we know that the Jeffreys prior for the location parameter has the form $p(\mathbf{w}) \propto 1$, and from Sec. 7.3.1.4, we know that the Jeffreys prior for the scale factor has the form $p(\sigma) \propto \sigma^{-1}$. We can emulate these priors using an improper NIG prior with $\tilde{\mathbf{w}}=\mathbf{0}$, $\tilde{\mathbf{\Sigma}}=\infty\mathbf{I}$, $\tilde{a}=-D/2$ and $\tilde{b}=0$. The corresponding posterior is given by

$p(\mathbf{w},\sigma^2|\mathcal{D}) = \text{NIG}(\mathbf{w},\sigma^2|\hat{\mathbf{w}},\hat{\mathbf{\Sigma}},\hat{a},\hat{b})$  (11.147)
$\hat{\mathbf{w}} = \hat{\mathbf{w}}_{\text{mle}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$  (11.148)
$\hat{\mathbf{\Sigma}} = (\mathbf{X}^\top\mathbf{X})^{-1}$  (11.149)
$\hat{a} = \frac{N - D}{2}$  (11.150)
$\hat{b} = \frac{s^2}{2}$  (11.151)
$s^2 \triangleq (\mathbf{y} - \mathbf{X}\hat{\mathbf{w}}_{\text{mle}})^\top(\mathbf{y} - \mathbf{X}\hat{\mathbf{w}}_{\text{mle}})$  (11.152)

Hence the posterior distribution of the weights is given by

$p(\mathbf{w}|\mathcal{D}) = \mathcal{T}\left(\mathbf{w}|\hat{\mathbf{w}}, \frac{s^2}{N - D}\hat{\mathbf{\Sigma}}, N - D\right)$  (11.153)

where $\hat{\mathbf{\Sigma}} = (\mathbf{X}^\top\mathbf{X})^{-1}$ and $\hat{\mathbf{w}}$ is the MLE. The marginals for each weight have the form

$p(w_d|\mathcal{D}) = \mathcal{T}\left(w_d|\hat{w}_d, \frac{\hat{\Sigma}_{dd} s^2}{N - D}, N - D\right)$  (11.154)

Interestingly, this is equivalent to the frequentist sampling distribution of the MLE (see Sec. E.3.1.3).
