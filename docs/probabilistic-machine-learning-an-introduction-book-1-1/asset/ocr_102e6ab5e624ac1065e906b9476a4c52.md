where π = 1 means choose action A, and π = 0 means choose action B. In the fully symmetric case, where n₁ = n₀, m₁ = m₀ and τ₁ = τ₀, we find that the optimal policy is to simply “pick the winner”:

π*(y₁,y₀) = 𝕀( m/τ² + ȳ₁/σ² > m/τ² + ȳ₀/σ² ) = 𝕀(ȳ₁ > ȳ₀) (8.48)

This makes intuitive sense. When the problem is asymmetric, we need to take into account the different sample sizes and prior beliefs.

# 8.2.1.2 Expected reward

If the total population size is N, and we cannot reuse people from the testing phase, the expected reward from the roll stage is

𝔼[R_roll] = ∫_{μ₁} ∫_{μ₀} ∫_{y₁} ∫_{y₀} (N − n₁ − n₀)(π(y₁,y₀)μ₁ + (1 − π(y₁,y₀))μ₀) (8.49) × p(y₀)p(y₁)p(μ₀)p(μ₁) dy₀ dy₁ dμ₀ dμ₁ (8.50)

One can show that this equals

𝔼[R_roll] = (N − n₁ − n₀) ( m₁ + e Φ(e/v) + v φ(e/v) ) (8.51)

where φ is the Gaussian pdf, Φ is the Gaussian cdf, e = m₀ − m₁ and

v = √[ τ₁⁴/(τ₁² + σ₁²/n₁) + τ₀⁴/(τ₀² + σ₀²/n₀) ] (8.52)

In the fully symmetric case, where m_j = m, τ_j = τ, σ_j = σ, and n_j = n, Eq. (8.51) simplifies to

𝔼[R_roll] = (N − 2n) ( m + √2 τ² / [ √π √(2τ² + 2/n σ²) ] ) (8.53)

The second term inside the brackets is the incremental gain we expect to see (beyond the prior) per person by virtue of picking the optimal action to deploy. We see that the incremental gain increases with n (because we are more likely to pick the correct action); however, this gain can only be accrued for a smaller number, N − 2n, of the population. Not suprisingly, we see that the incremental gain decreases with measurement noise, σ. We also see that the incremental gain increases with prior uncertainty, τ, since there is more to be learned by doing an experiment in this case.

The total expected reward is given by adding Eq. (8.43) and Eq. (8.53):

𝔼[R] = 𝔼[R_test] + 𝔼[R_roll] = N m + (N − 2n) ( √2 τ² / [ √π √(2τ² + 2/n σ²) ] ) (8.54)
