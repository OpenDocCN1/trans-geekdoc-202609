where ηₙ = wᵀ xₙ. We can write this in GLM form as follows:

log p(yₙ|xₙ, w, σ²) = (yₙ ηₙ - ηₙ²/2)/σ² - ½( yₙ²/σ² + log(2πσ²) )  (12.89)

We see that A(ηₙ) = ηₙ²/2 and hence

𝔼[yₙ] = ηₙ = wᵀ xₙ  (12.90)
𝕍[yₙ] = σ²  (12.91)

# 12.3.1.2 Binomial regression

If the response variable is the number of successes in Nₙ trials, yₙ ∈ {0,…,Nₙ}, we can use binomial regression, which is defined by

p(yₙ|xₙ, Nₙ, w) = Bin(yₙ|σ(wᵀ xₙ), Nₙ)  (12.92)

We see that binary logistic regression is the special case when Nₙ = 1.

The log pdf is given by

log p(yₙ|xₙ, Nₙ, w) = yₙ log μₙ + (Nₙ - yₙ) log(1 - μₙ) + log (Nₙ choose yₙ)  (12.93)

= yₙ log( μₙ/(1 - μₙ) ) + Nₙ log(1 - μₙ) + log (Nₙ choose yₙ)  (12.94)

where μₙ = σ(ηₙ). To rewrite this in GLM form, let us define

ηₙ ≜ log[ μₙ/(1 - μₙ) ] = log[ 1/(1+e^{-wᵀxₙ}) * (1+e^{-wᵀxₙ})/e^{-wᵀxₙ} ] = log 1/e^{-wᵀxₙ} = wᵀ xₙ  (12.95)

Hence we can write binomial regression in GLM form as follows
log p(yₙ|xₙ, Nₙ, w) = yₙ ηₙ - A(ηₙ) + h(yₙ)  (12.96)

where h(yₙ) = log (Nₙ choose yₙ) and
A(ηₙ) = -Nₙ log(1 - μₙ) = Nₙ log(1 + e^{ηₙ})  (12.97)

Hence
𝔼[yₙ] = dA/dηₙ = Nₙ e^{ηₙ}/(1+e^{ηₙ}) = Nₙ/(1+e^{-ηₙ}) = Nₙ μₙ  (12.98)

and
𝕍[yₙ] = d²A/dηₙ² = Nₙ μₙ(1 - μₙ)  (12.99)
