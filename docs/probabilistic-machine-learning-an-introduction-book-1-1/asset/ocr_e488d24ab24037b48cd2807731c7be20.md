# E.2. Fisher information matrix (FIM)

Lemma 1. The expected value of the score function is zero, i.e.,

E_{p(x|θ)} [∇ log p(x|θ)] = 0

(E.6)

We will prove this lemma in the scalar case. First, note that since ∫ p(x|θ)dx = 1, we have

∂/∂θ ∫ p(x|θ)dx = 0

(E.7)

Combining this with the identity

∂/∂θ p(x|θ) = [∂/∂θ log p(x|θ)] p(x|θ)

(E.8)

we have

0 = ∫ ∂/∂θ p(x|θ)dx = ∫ [∂/∂θ log p(x|θ)] p(x|θ)dx = E [s(θ)]

(E.9)

Now we return to the proof of our main theorem. For simplicity, we will focus on the scalar case, following the presentation of [Ric95, p263].

Proof. Taking derivatives of Eq. (E.9), we have

0 = ∂/∂θ ∫ [∂/∂θ log p(x|θ)] p(x|θ)dx

(E.10)

= ∫ [∂²/∂θ² log p(x|θ)] p(x|θ)dx + ∫ [∂/∂θ log p(x|θ)] [∂/∂θ p(x|θ)] dx

(E.11)

= ∫ [∂²/∂θ² log p(x|θ)] p(x|θ)dx + ∫ [∂/∂θ log p(x|θ)]² p(x|θ)dx

(E.12)

and hence

- E_{x~θ} [ ∂²/∂θ² log p(x|θ) ] = E_{x~θ} [ (∂/∂θ log p(x|θ))² ]

(E.13)
as claimed. □

Now consider the Hessian of the NLL given N iid samples D = {x_n : n = 1 : N}:

H_ij ≜ -∂²/∂θ_i ∂θ_j log p(D|θ) = - ∑_{n=1}^N ∂²/∂θ_i ∂θ_j log p(x_n|θ)

(E.14)

From the above theorem, we have

E_{p(D|θ)} [H(D)|_θ] = N F(θ)

(E.15)

We will use this result later in this chapter.
