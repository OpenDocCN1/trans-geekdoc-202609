One reason conjugate functions are useful is that they can be used to create convex lower bounds to non-convex functions. That is, we have L(x, λ) ≤ f(x), with equality at x = x_λ, for any function f : ℝ^D → ℝ. For any given x, we can optimize over λ to make the bound as tight as possible, giving us a fixed function L(x); this is called a variational approximation. We can then try to maximize this lower bound wrt x instead of maximizing f(x). This method is used extensively in approximate Bayesian inference, as we discuss in Sec. 7.7.3.

# B.4.7.2 Example: exponential function

L(x, λ) = λx − f*(λ) (B.73)

where the conjugate function is given by

f*(λ) = max_x λx − f(x) = −λ log(−λ) + λ (B.74)
