# B.4.6 Bregman divergence

Let f : Ω → ℝ be a continuously differentiable, strictly convex function defined on a closed convex set Ω. We define the Bregman divergence associated with f as follows [Brc67]:

D_f(w, v) = f(w) − f(v) − (w − v)ᵀ ∇f(v)  (B.66)

To understand this, let

f̂_v(w) = f(v) + (w − v)ᵀ ∇f(v)  (B.67)

be a first order Taylor series approximation to f centered at v. Then the Bregman divergence is the difference from this linear approximation:

D_f(w, v) = f(w) − f̂_v(w)  (B.68)

See Fig. B.12 for an illustration. Since f is convex, we have D_f(v, w) ≥ 0, since f̂_v is a linear lower bound on f (see also Fig. B.7b).

Below we mention some important special cases of Bregman divergences.

+   - If f(w) = ||w||², then D_f(w, v) = ||w − v||² is the squared Euclidean distance.
+   - If f(w) = wᵀ Q w, then D_f(w, v) is the squared Mahalanobis distance (Sec. 3.5.2).
+   - If w are the natural parameters of an exponential family distribution, and f(w) = log Z(w) is the log normalizer, then the Bregman divergence is the same as the Kullback Leibler divergence (Sec. 6.2).
