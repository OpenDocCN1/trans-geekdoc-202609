Sometimes it is more convenient to work with the correlation matrix defined in Eq. (D.50). This can be computed using

corr(Y) = (diag(Σ))^{-½} Σ (diag(Σ))^{-½}  (4.51)

where diag(Σ)^{-½} is a diagonal matrix containing the entries 1/σ_i. See Fig. 4.1b for an example.

Note, however, that the MLE may overfit or be numerically unstable, especially when the number of samples N is small compared to the number of dimensions D. The main problem is that Σ has O(D²) parameters, so we may need a lot of data to reliably estimate it. In particular, as we see from Eq. (4.50), the MLE for a full covariance matrix is singular if N < D. And even when N > D, the MLE can be ill-conditioned, meaning it is close to singular. We discuss solutions to this problem in Sec. 4.4.2.

# 4.2.7 Example: MLE for linear regression

We briefly mentioned linear regression in Sec. 3.3.3. Recall that it corresponds to the following model:

p(y|x;θ) = N(y|wᵀx, σ²)  (4.52)

where θ = (w, σ²). Let us assume for now that σ² is fixed, and focus on estimating the weights w.

The negative log likelihood or NLL is given by

NLL(w) = - Σ_{n=1}^N log[ (1/(2πσ²))^{½} exp( -1/(2σ²) (y_n - wᵀx_n)² ) ]  (4.53)

Dropping the irrelevant additive constants gives the following simplified objective, known as the residual sum of squares or RSS:

RSS(w) ≜ Σ_{n=1}^N (y_n - wᵀx_n)² = Σ_{n=1}^N r_n²  (4.54)
