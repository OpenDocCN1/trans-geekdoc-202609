where Ñ = β̃ + α̃ is the strength (equivalent sample size) of the posterior. We will now show that the posterior mean is a convex combination of the prior mean, m = α̃ / Ñ (where Ñ = α̃ + β̃ is the prior strength), and the MLE: θ̂ₘₗₑ = N₁ / N.

E[θ|D] = (α̃ + N₁) / (α̃ + N₁ + β̃ + N₀) = (Ñm + N₁) / (N + Ñ) = Ñ / (N + Ñ) m + N / (N + Ñ) · N₁ / N = λm + (1 − λ)θ̂ₘₗₑ  (7.19)

where λ = Ñ / N is the ratio of the prior to posterior equivalent sample size. So the weaker the prior, the smaller is λ, and hence the closer the posterior mean is to the MLE.

To capture some notion of uncertainty in our estimate, a common approach is to compute the standard error of our estimate, which is just the posterior standard deviation:

se(θ) = √V[θ|D]  (7.20)

In the case of the Bernoulli model, we showed that the posterior is a beta distribution. The variance of the beta posterior is given by

V[θ|D] = α̂β̂ / ((α̂ + β̂)²(α̂ + β̂ + 1))  (7.21)

where α̂ = α̃ + N₁ and β̂ = β̃ + N₀. If N ≫ α̃ + β̃, this simplifies to

V[θ|D] ≈ N₁N₀ / N³ = θ̂(1 − θ̂) / N  (7.22)

where θ̂ is the MLE. Hence the standard error is given by

σ = √V[θ|D] ≈ √(θ̂(1 − θ̂) / N)  (7.23)

We see that the uncertainty goes down at a rate of 1/√N. We also see that the uncertainty (variance) is maximized when θ̂ = 0.5, and is minimized when θ̂ is close to 0 or 1. This makes sense, since it is easier to be sure that a coin is biased than to be sure that it is fair.

# 7.2.1.4  Posterior predictive

Suppose we want to predict future observations. A very common approach is to first compute an estimate of the parameters based on training data, θ̂(D), and then to plug that parameter back into the model and use p(y|θ̂) to predict the future; this is called a plug-in approximation. However, this can result in overfitting. As an extreme example, suppose we have seen N = 3 heads in a row. The MLE is θ̂ = 3/3 = 1.0. However, if we use this estimate, we would predict that tails are impossible.
