If the events are mutually exclusive (so they cannot happen at the same time), we get

Pr(A ∨ B) = Pr(A) + Pr(B) (D.4)

For example, suppose X is chosen uniformly at random from the set X = {1,2,3,4}. Let A be the event that X ∈ {1,2} and B be the event that X ∈ {3}. Then we have Pr(A ∨ B) = 2/4 + 1/4.

# D.1.3.4 Conditional probability of one event given another

We define the conditional probability of event B happening given that A has occurred as follows:

Pr(B|A) ≜ Pr(A,B)/Pr(A) (D.5)

This is not defined if Pr(A) = 0, since we cannot condition on an impossible event.

# D.1.3.5 Conditional independence of events

We say that event A is conditionally independent of event B if

Pr(A|B) = Pr(A) (D.6)

Of course, this is a symmetric relationship, so we also have Pr(B|A) = Pr(B). Hence Pr(A,B) = Pr(A)Pr(B). We use the notation A ⊥ B to denote this property.

Two events, A and B, are conditionally independent given a third event C if Pr(A|B,C) = Pr(A|C). Equivalently, we can write this as Pr(A,B|C) = Pr(A|C)Pr(B|C). This is written as A ⊥ B|C.

For example, let A be the event “the smoke detector is on”, B be the event “there is a fire nearby”, and C be the event “there is smoke nearby”. Clearly A and B depend on each other, but A ⊥ B|C, since if there is smoke nearby (i.e., event C is true), the detector will turn on, regardless of whether there is a fire. Events are often dependent on each other, but may be rendered independent if we condition on the relevant intermediate variables, as we discuss in more detail later in this chapter.

# D.2 Random variables

Suppose X represents some unknown quantity of interest, such as which way a dice will land when we roll it, or the temperature outside your house at the current time. If the value of X is unknown and/or could change, we call it a random variable or rv. We can represent our beliefs about its possible values using a probability distribution, as we explain below.

# D.2.1 Discrete random variables

The set of values an rv X can take on, denoted X, is called the state space. If this is finite or countably infinite, X is called a discrete random variable. In this case, we denote the probability of the event that X has value x by Pr(X = x). We define the probability mass function or pmf as a function which computes the probability of events which correspond to setting the rv to each possible value:

p(x) ≜ Pr(X = x) (D.7)
