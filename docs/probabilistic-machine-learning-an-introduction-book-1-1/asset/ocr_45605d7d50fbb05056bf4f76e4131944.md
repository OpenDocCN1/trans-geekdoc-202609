# 13.2.4.4 MLP for heteroskedastic regression

We can also use MLPs for regression. Fig. 13.7 shows how we can make a model for heteroskedastic nonlinear regression. (The term “heteroskedastic” just means that the predicted output variance is input-dependent, as discussed in Sec. 3.3.3.) This function has two outputs which compute f_μ(x) = 𝔼[y|x,θ] and f_σ(x) = √Var[y|x,θ]. We can share most of the layers (and hence parameters) between these two functions by using a common “backbone” and two output “heads”, as shown in Fig. 13.7. For the μ head, we use a linear activation, φ(a) = a. For the σ head, we use a softplus activation, φ(a) = σ₊(a). If we use linear heads and a nonlinear backbone, the overall model is given by
