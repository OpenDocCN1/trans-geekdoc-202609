# 10.6.4  Variational inference

As we discuss in Sec. 7.7.3, variational inference converts approximate inference into an optimization problem. It does this by choosing an approximate distribution $q(\mathbf{w};\boldsymbol{\xi})$ and optimizing the variational parameters $\boldsymbol{\xi}$ to maximize the evidence lower bound (ELBO). This has the effect of making $q(\mathbf{w};\boldsymbol{\xi}) \approx p(\mathbf{w}|\mathcal{D})$ in the sense that the KL divergence is small.

# 10.6.4.1  Binary case

In this section, we consider variational inference for the parameters of a binary logistic regression model using a Gaussian prior, $p(\mathbf{w}) = \mathcal{N}(\mathbf{w}|\boldsymbol{\mu}_0, V_0)$. We also also assume a Gaussian posterior of the form $q(\mathbf{w}) = \mathcal{N}(\mathbf{w}|\boldsymbol{\mu}_N, V_N)$, which we fit by optimizing the ELBO. Our derivation of this posterior follows the presentation of [Bisi06, Sec 10.6].

Let us rewrite the likelihood for a single observation as follows:

$$p(y_n|\mathbf{x}_n,\mathbf{w}) = \sigma(\eta_n)^{y_n}(1-\sigma(\eta_n))^{1-y_n} \tag{10.125}$$

$$= \left(\frac{1}{1+e^{-\eta_n}}\right)^{y_n}\left(1-\frac{1}{1+e^{-\eta_n}}\right)^{1-y_n} \tag{10.126}$$

$$= e^{-\eta_n y_n}\frac{e^{-\eta_n}}{1+e^{-\eta_n}} = e^{-\eta_n y_n}\sigma(-\eta_n) \tag{10.127}$$

where $\eta_n = \mathbf{w}^{\mathsf{T}}\mathbf{x}_n$ are the logits. This is not conjugate to the Gaussian prior. So we will use the following “Gaussian-like” variational lower bound to the sigmoid function, proposed in [J96; J00]:

$$\sigma(\eta_n) \geq \sigma(\xi_n)\exp\left[(\eta_n-\xi_n)/2 - \lambda(\xi_n)(\eta_n^2-\xi_n^2)\right] \tag{10.128}$$

where $\xi_n$ is the variational parameter for datapoint $n$, and

$$\lambda(\xi) \triangleq \frac{1}{4\xi}\tanh(\xi/2) = \frac{1}{2\xi}\left[\sigma(\xi)-\frac{1}{2}\right] \tag{10.129}$$

We shall refer to this as the **JJ bound**, after its inventors, Jaakkola and Jordan. See Fig. 10.17(a) for a plot.

Using this bound, we can write

$$p(y_n|\mathbf{x}_n,\mathbf{w}) = e^{-\eta_n y_n}\sigma(-\eta_n) \geq e^{-\eta_n y_n}\sigma(\xi_n)\exp\left[(-\eta_n+\xi_n)/2 - \lambda(\xi_n)(\eta_n^2-\xi_n^2)\right] \tag{10.130}$$
