# **Exercise 11.10** [GSM representation of group lasso]

Consider the prior $\tau_j^2 \sim \text{Ga}(\delta, \rho^2/2)$, ignoring the grouping issue for now. The marginal distribution induced on the weights by a Gamma mixing distribution is called the **compound normal Gamma** distribution and is given by

$p(w_j|\delta,\rho)=\int \mathcal{N}(w_j|0,\tau_j^2)\text{Ga}(\tau_j^2|\delta,\rho^2/2)d\tau_j^2 \tag{11.206}$

$=\frac{1}{Z}|w_j|^{\delta-1/2}\mathcal{K}_{\delta-\frac12}(\rho|w_j|) \tag{11.207}$

$1/Z=\frac{\rho^{\delta+\frac12}}{\sqrt{\pi}\,2^{\delta-1/2}\rho(\delta)} \tag{11.208}$

where $\mathcal{K}_\alpha(x)$ is the modified Bessel function of the second kind (the besselk.m function in Matlab).

Now suppose we have the following prior on the variances

$p(\sigma_{1:D}^2)=\prod_{g=1}^{G}p(\sigma_{1:d_g}^2),\;p(\sigma_{1:d_g}^2)=\prod_{j\in g}\text{Ga}(\tau_j^2|\delta_g,\rho^2/2) \tag{11.209}$

The corresponding marginal for each group of weights has the form

$p(\mathbf{w}_g)\propto |u_g|^{\delta_g-d_g/2}\,\mathcal{K}_{\delta_g-d_g/2}(\rho u_g) \tag{11.210}$

where

$u_g \triangleq \sqrt{\sum_{j\in g}w_{g,j}^2}=\|\mathbf{w}_g\|_2 \tag{11.211}$

Now suppose $\delta_g=(d_g+1)/2$, so $\delta_g-d_g/2=\tfrac12$. Conveniently, we have $\mathcal{K}_{1/2}(z)=\sqrt{\tfrac{\pi}{2z}}\exp(-z)$. Show that the resulting MAP estimate is equivalent to group lasso.
