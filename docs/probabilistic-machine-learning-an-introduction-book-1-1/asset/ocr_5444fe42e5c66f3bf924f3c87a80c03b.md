# 7.2 Conjugate priors

In this section, we consider a set of (prior, likelihood) pairs for which we can compute the posterior in closed form. In particular, we will use priors that are “conjugate” to the likelihood. We say that a prior p(θ) ∈ F is a conjugate prior for a likelihood function p(D|θ) if the posterior is in the same parameterized family as the prior, i.e., p(θ|D) ∈ F. In other words, F is closed under Bayesian updating. If the family F corresponds to the exponential family (defined in Sec. 12.2), then the computations can be performed in closed form.
