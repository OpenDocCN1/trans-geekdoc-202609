Hence every setting of the prior hyperparameters specifies the following random function:

f(x; α, β) = α_L η_L (⋯ φ(α₁ η₁ x + β₁ ε₁)) + β_L ε_L  (13.99)

To get a feeling for the effect of these hyperparameters, we can sample MLP parameters from this prior and plot the resulting random functions. We use a sigmoid nonlinearity, so φ(a) = σ(a). We consider L = 2 layers, so W₁ are the input-to-hidden weights, and W₂ are the hidden-to-output weights. We assume the input and output are scalars, so we are generating random nonlinear mappings f : ℝ → ℝ.

Fig. 13.20(a) shows some sampled functions where α₁ = 5, β₁ = 1, α₂ = 1, β₂ = 1 in the top left In Fig. 13.20(b) we increasing α₁; this allows the first layer weights to get bigger, making the sigmoid-like shape of the functions steeper (compare to Fig. 10.2). In Fig. 13.20(c), we increase β₁; this allows the first layer biases to get bigger, which allows the center of the sigmoid to shift left and right more, away from the origin. In Fig. 13.20(d), we increase α₂; this allows the second layer linear weights to get bigger, making the functions more “wiggly” (greater sensitivity to change in the input, and hence larger dynamic range).
