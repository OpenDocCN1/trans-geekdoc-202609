The posterior marginal for $\sigma^2$ is just

$$p(\sigma^2|\mathcal{D}) = \int p(\mu,\sigma^2|\mathcal{D}) d\mu = \chi^{-2}(\sigma^2| \hat{\nu}, \hat{\tau}^2) \tag{7.91}$$

with the posterior mean given by $\mathbb{E}[\sigma^2|\mathcal{D}] = \frac{\hat{\nu}}{\hat{\nu}-2} \hat{\tau}^2$.

The posterior marginal for $\mu$ has a Student distribution, which follows from the fact that the Student distribution is a (scaled) mixture of Gaussians:

$$p(\mu|\mathcal{D}) = \int p(\mu,\sigma^2|\mathcal{D}) d\sigma^2 = \mathcal{T}(\mu| \hat{m}, \hat{\tau}^2 / \hat{\kappa}, \hat{\nu}) \tag{7.92}$$

with the posterior mean given by $\mathbb{E}[\mu|\mathcal{D}] = \hat{m}$.

### 7.2.3.4 Posterior of $\mu$ and $\sigma^2$: uninformative prior

If we “know nothing” about the parameters a priori, we can use an uninformative prior. We discuss how to create such priors in Sec. 7.3. A common approach is to use a Jeffreys prior. In Sec. 7.3.1.2, we show that the Jeffreys prior for a location and scale parameter has the form

$$p(\mu,\sigma^2) \propto p(\mu)p(\sigma^2) \propto \sigma^{-2} \tag{7.93}$$

We can simulate this with a conjugate prior by using

$$p(\mu,\sigma^2) = \text{NI}\chi^2(\mu,\sigma^2| \tilde{m}=0, \tilde{\kappa}=0, \tilde{\nu}=-1, \tilde{\tau}^2=0) \tag{7.94}$$

With this prior, the posterior has the form

$$p(\mu,\sigma^2|\mathcal{D}) = \text{NI}\chi^2(\mu,\sigma^2| \hat{m}= \bar{y}, \hat{\kappa}= N, \hat{\nu}= N-1, \hat{\tau}^2= s^2) \tag{7.95}$$

where

$$s^2 \triangleq \frac{1}{N-1}\sum_{n=1}^{N}(y_n - \bar{y})^2 = \frac{N}{N-1}\hat{\sigma}_{\text{mle}}^2 \tag{7.96}$$

$s$ is known as the **sample standard deviation**. (In Sec. E.4.1, we show that this is an unbiased estimate of the variance.) Hence the marginal posterior for the mean is given by

$$p(\mu|\mathcal{D}) = \mathcal{T}(\mu|\bar{y}, \frac{s^2}{N}, N-1) = \mathcal{T}\left(\mu|\bar{y}, \frac{\sum_{n=1}^{N}(y_n - \bar{y})^2}{N(N-1)}, N-1\right) \tag{7.97}$$

Thus the posterior variance of $\mu$ is

$$\mathbb{V}[\mu|\mathcal{D}] = \frac{\hat{\nu}}{\hat{\nu}-2}\hat{\tau}^2 = \frac{N-1}{N-3}\frac{s^2}{N} \to \frac{s^2}{N} \tag{7.98}$$

The square root of this is called the **standard error of the mean**:

$$\text{se}(\mu) \triangleq \sqrt{\mathbb{V}[\mu|\mathcal{D}]} \approx \frac{s}{\sqrt{N}} \tag{7.99}$$

Thus we can approximate the 95% **credible interval** for $\mu$ using

$$I_{0.95}(\mu|\mathcal{D}) = \bar{y} \pm 2\frac{s}{\sqrt{N}} \tag{7.100}$$

(Note that a Bayesian credible interval is not the same as a frequentist confidence interval, as explained in Sec. E.3.4, although in practice they are often numerically similar, and sometimes identical.)

### 7.2.3.5 Half Cauchy prior

In Sec. 7.3.1.4, we show that the Jeffreys uninformative prior for a variance term is given by $p(\sigma^2)=\text{IG}(\sigma^2|0,0)$, Unfortunately, this is not a proper prior. One solution to this is to use a **weakly informative** proper prior such as $\text{IG}(\epsilon,\epsilon)$ for small $\epsilon$. However, this turns out to not work very well, for reasons that are explained in [Gel06; PS12]. Instead, it is recommended to use the half Cauchy distribution defined in Sec. 3.4.2. (Another common choice is the half normal defined in Sec. 3.3.5.)

## 7.2.4 The multivariate Gaussian-Gaussian model

In this section, we derive the posterior $p(\boldsymbol{\mu}, \boldsymbol{\Sigma}|\mathcal{D})$ for a multivariate Gaussian. For simplicity, we consider this in three steps: inferring just $\boldsymbol{\mu}$, inferring just $\boldsymbol{\Sigma}$, and then inferring both.

### 7.2.4.1 Posterior of $\boldsymbol{\mu}$ given $\boldsymbol{\Sigma}$

The likelihood has the form

$$p(\mathcal{D}|\boldsymbol{\mu}) = \mathcal{N}(\bar{\mathbf{y}}|\boldsymbol{\mu}, \frac{1}{N}\boldsymbol{\Sigma}) \tag{7.101}$$

For simplicity, we will use a conjugate prior, which in this case is a Gaussian. In particular, if $p(\boldsymbol{\mu}) = \mathcal{N}(\boldsymbol{\mu}|\tilde{\mathbf{m}}, \tilde{\mathbf{V}})$ then we can derive a Gaussian posterior for $\boldsymbol{\mu}$ based on the results in Sec. 3.6 We get

$$p(\boldsymbol{\mu}|\mathcal{D}, \boldsymbol{\Sigma}) = \mathcal{N}(\boldsymbol{\mu}|\hat{\mathbf{m}}, \hat{\mathbf{V}}) \tag{7.102}$$
$$\hat{\mathbf{V}}^{-1} = \tilde{\mathbf{V}}^{-1} + N\boldsymbol{\Sigma}^{-1} \tag{7.103}$$
$$\hat{\mathbf{m}} = \hat{\mathbf{V}} \left( \boldsymbol{\Sigma}^{-1}(N\bar{\mathbf{y}}) + \tilde{\mathbf{V}}^{-1}\tilde{\mathbf{m}} \right) \tag{7.104}$$

### 7.2.4.2 Posterior of $\Sigma$ given $\mu$

We now discuss how to compute $p(\boldsymbol{\Sigma}|\mathcal{D}, \boldsymbol{\mu})$.

#### Likelihood

Following Sec. 4.2.6, we can rewrite the likelihood as follows:

$$p(\mathcal{D}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) \propto |\boldsymbol{\Sigma}|^{-\frac{N}{2}} \exp\left(-\frac{1}{2}\operatorname{tr}(\mathbf{S}_{\mu} \boldsymbol{\Sigma}^{-1})\right) \tag{7.105}$$

where $\mathbf{S}_{\mu} \triangleq \sum_{n=1}^{N} (\mathbf{y}_n - \boldsymbol{\mu})(\mathbf{y}_n - \boldsymbol{\mu})^\top$ $\tag{7.106}$ is the scatter matrix around $\boldsymbol{\mu}$.

#### Prior

The conjugate prior is known as the **inverse Wishart** distribution, which is a distribution over positive definite matrices. This has the following pdf:

$$\text{IW}(\Sigma | \breve{S}, \breve{\nu}) \propto |\Sigma|^{-(\breve{\nu}+D+1)/2} \exp( -\tfrac{1}{2} \text{tr}(\breve{S} \Sigma^{-1}) ) \tag{7.107}$$

Here $\breve{\nu} > D - 1$ is the degrees of freedom (dof), and $\breve{S}$ is a symmetric pd matrix. We see that $\breve{S}$ plays the role of the prior scatter matrix, and $N_0 \equiv \breve{\nu} + D + 1$ controls the strength of the prior, and hence plays a role analogous to the sample size $N$.

If $D = 1$, the inverse Wishart reduces to the inverse Gamma:

$$\text{IW}(\sigma^2 | s^{-1}, \nu) = \text{IG}(\sigma^2 | \nu/2, s/2) \tag{7.108}$$

If $s = 1$, this reduces to the inverse chi-squared distribution.

#### Posterior

Multiplying the likelihood and prior we find that the posterior is also inverse Wishart:

$$p(\Sigma | \mathcal{D}, \mu) \propto |\Sigma|^{-N/2} \exp( -\tfrac{1}{2} \text{tr}(\Sigma^{-1} S_{\mu}) ) |\Sigma|^{-(\breve{\nu}+D+1)/2} \exp( -\tfrac{1}{2} \text{tr}(\Sigma^{-1} \breve{S}) ) \tag{7.109}$$
$$= |\Sigma|^{-(N+(\breve{\nu}+D+1))/2} \exp( -\tfrac{1}{2} \text{tr}[ \Sigma^{-1} (S_{\mu} + \breve{S}) ] ) \tag{7.110}$$
$$= \text{IW}(\Sigma | \hat{S}, \hat{\nu}) \tag{7.111}$$
$$\hat{\nu} = \breve{\nu} + N \tag{7.112}$$
$$\hat{S} = \breve{S} + S_{\mu} \tag{7.113}$$

In words, this says that the posterior strength $\hat{\nu}$ is the prior strength $\breve{\nu}$ plus the number of observations $N$, and the posterior scatter matrix $\hat{S}$ is the prior scatter matrix $\breve{S}$ plus the data scatter matrix $S_{\mu}$.

The posterior mode of the inverse Wishart can be used to derive the shrinkage estimate for $\Sigma$ discussed in Sec. 4.4.2.

### 7.2.4.3 LKJ prior

The conjugate prior for a covariance matrix is the inverse Wishart. However, this distribution is hard to sample from. Consequently it is common to use the **LKJ distribution** as a prior instead (this is named after the authors of [LKJ09]). This is a prior on correlation matrices $C$ of the form $p(C | \eta) \propto |C|^{\eta-1}$, so $\eta = 1$ leads to a uniform a distribution. We can combine this with a suitable prior for the standard deviation, such as half-Cauchy prior (Sec. 7.2.3.5), to derive a prior for $\Sigma = \sigma C$.

### 7.2.4.4 Posterior of $\Sigma$ and $\mu$

In this section, we compute $p(\mu, \Sigma | \mathcal{D})$ using a conjugate prior.

#### Likelihood

The likelihood is given by

$$p(\mathcal{D}|\boldsymbol{\mu},\boldsymbol{\Sigma}) \propto |\boldsymbol{\Sigma}|^{-\frac{N}{2}} \exp\left(-\frac{1}{2}\sum_{n=1}^{N}(\mathbf{y}_n - \boldsymbol{\mu})^{\top}\boldsymbol{\Sigma}^{-1}(\mathbf{y}_n - \boldsymbol{\mu})\right)\tag{7.114}$$

One can show that

$$\sum_{n=1}^{N}(\mathbf{y}_n - \boldsymbol{\mu})^{\top}\boldsymbol{\Sigma}^{-1}(\mathbf{y}_n - \boldsymbol{\mu}) = \operatorname{tr}(\boldsymbol{\Sigma}^{-1}\mathbf{S}_{\bar{\mathbf{y}}}) + N(\bar{\mathbf{y}} - \boldsymbol{\mu})^{\top}\boldsymbol{\Sigma}^{-1}(\bar{\mathbf{y}} - \boldsymbol{\mu})\tag{7.115}$$

where

$$\mathbf{S}_{\bar{\mathbf{y}}}\triangleq\sum_{n=1}^{N}(\mathbf{y}_n - \bar{\mathbf{y}})(\mathbf{y}_n - \bar{\mathbf{y}})^{\top}=\mathbf{Y}^{\top}\mathbf{C}_N\mathbf{Y}\tag{7.116}$$

is empirical scatter matrix, and $\mathbf{C}_N$ is the centering matrix defined in Eq. (4.47).

Hence we can rewrite the likelihood as follows:

$$p(\mathcal{D}|\boldsymbol{\mu},\boldsymbol{\Sigma}) \propto |\boldsymbol{\Sigma}|^{-\frac{N}{2}} \exp\left(-\frac{N}{2}(\boldsymbol{\mu} - \bar{\mathbf{y}})^{\top}\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu} - \bar{\mathbf{y}})\right) \exp\left(-\frac{1}{2}\operatorname{tr}(\boldsymbol{\Sigma}^{-1}\mathbf{S}_{\bar{\mathbf{y}}})\right)\tag{7.117}$$

We will use this form below.

#### Prior

The obvious prior to use is the following

$$p(\boldsymbol{\mu},\boldsymbol{\Sigma}) = \mathcal{N}(\boldsymbol{\mu}|\breve{\mathbf{m}},\breve{\mathbf{C}})\mathrm{IW}(\boldsymbol{\Sigma}|\breve{\mathbf{S}},\breve{\nu})\tag{7.118}$$
