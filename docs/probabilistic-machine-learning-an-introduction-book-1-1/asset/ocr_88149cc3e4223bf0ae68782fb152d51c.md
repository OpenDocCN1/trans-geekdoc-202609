The “generative story” for the data is that we first sample a specific component z, and then we generate the observations y using the parameters chosen according to the value of z. By marginalizing out z, we recover Eq. (3.112):

p(y|θ) = Σ_{k=1}^K p(z = k|θ) p(y|z = k, θ) = Σ_{k=1}^K π_k p(y|θ_k)  (3.115)

We can create different kinds of mixture model by varying the base distribution p_k, as we illustrate below.

# 3.7.1 Gaussian mixture models

A Gaussian mixture model or GMM, also called a mixture of Gaussians (MoG), is defined as follows:

p(y) = Σ_{k=1}^K π_k N(y|μ_k, Σ_k)  (3.116)

In Fig. 3.16 we show the density defined by a mixture of 3 Gaussians in 2d. Each mixture component is represented by a different set of elliptical contours. If we let the number of mixture components grow sufficiently large, a GMM can approximate any smooth distribution over ℝ^D.

# 3.7.1.1 Using GMMs for clustering

GMMs are often used for unsupervised clustering of real-valued data samples y_n ∈ ℝ^D. This works in two stages. First we fit the model e.g., by computing the MLE θ̂ = argmax log p(D|θ), where D = {y_n : n = 1 : N}. (We discuss how to compute this MLE in Sec. 5.7.3.)
