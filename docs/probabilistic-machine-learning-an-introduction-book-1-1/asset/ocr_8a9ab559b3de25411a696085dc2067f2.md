We can now lower bound the log joint as follows:

log p(y|X, w) + log p(w) ≥ -½ (w - μ₀)ᵀ V₀⁻¹ (w - μ₀)   (10.131)
+ Σ_{n=1}^N [η_n (y_n - 1/2) - λ(ξ_n) wᵀ (x_n x_nᵀ) w]   (10.132)

Since this is a quadratic function of w, we can derive a Gaussian posterior approximation as follows:

q(w|ξ) = N(w|μ_N, V_N)   (10.133)
μ_N = V_N ( V₀⁻¹ μ₀ + Σ_{n=1}^N (y_n - 1/2) x_n )   (10.134)
V_n⁻¹ = V₀⁻¹ + 2 Σ_{n=1}^N λ(ξ_n) x_n x_nᵀ   (10.135)

This is more flexible than a Laplace approximation, since the variational parameters ξ can be used to optimize the curvature of the posterior covariance. To find the optimal ξ, we can maximize the ELBO, which is given by

log p(y|X) = log ∫ p(y|X, w) p(w) dw ≥ log ∫ h(w, ξ) p(w) dw = L(ξ)   (10.136)

where

h(w, ξ) = ∏_{n=1}^N σ(ξ_n) exp[ η_n y_n - (η_n + ξ_n)/2 - λ(ξ_n)(η_n² - ξ_n²) ]   (10.137)

We can evaluate the lower bound analytically to get

L(ξ) = ½ log |V_N|/|V₀| + ½ μ_Nᵀ V_N⁻¹ μ_N - ½ μ₀ᵀ V₀⁻¹ μ₀ + Σ_{n=1}^N [ log σ(ξ_n) - ½ ξ_n + λ(ξ_n) ξ_n² ]   (10.138)
