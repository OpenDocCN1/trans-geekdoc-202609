# 3.5.3 Marginals and conditionals of an MVN

Suppose we have two discrete random variables, Y1 and Y2. We can represent their joint distribution as a 2d table, all of whose entries sum to one. For example, consider the following example with two binary variables:

| p(Y1,Y2) | Y1 = 0 | Y2 = 1 |
|---|---|---|
| Y1 = 0 | 0.2 | 0.3 |
| Y2 = 1 | 0.3 | 0.2 |

Given a joint distribution, we define the marginal distribution as follows:

p(Y2 = y2) = Σ_{y1} p(Y1 = y1, Y2 = y_y)  (3.93)

We define the conditional distribution as follows:

p(Y1 = y1 | Y2 = y2) = p(Y1 = y1, Y2 = y2) / p(Y2 = y2)  (3.94)

We now discuss how to extend these results to jointly Gaussian random variables, where we replace sums with integrals. We will parition our vector of random variables y into two parts, y1 and y2, where y2 are the variables of interest, and y1 are called nuisance variables. The marginal distribution for y2 can be computed by integrating out y1 as follows:

p(y2) = ∫ N(y|μ, Σ) dy1 = N(y2|μ2, Σ22)  (3.95)

where we have defined the following partition of the (moment) parameters:

μ = (μ1 \ μ2),  Σ = ( Σ11 Σ12 \ Σ21 Σ22 )  (3.96)

Now suppose we observe the value of y2, and we want to predict the value of y1 conditional on this observation. That is, we want to transform the prior distribution p(y1), which represents our beliefs about the values of y1 before we have seen any observations, into the posterior distribution p(y1|y2), which represents our beliefs about the values of y1 after (posterior to) seeing y2. Exercise 3.8 asks you to derive the following important result:

p(y1|y2) = N(y1| μ1 + Σ12 Σ22^{-1} (y2 - μ2), Σ11 - Σ12 Σ22^{-1} Σ21 )  (3.97)

Note that the posterior mean is a linear function of y2, but the posterior covariance is independent of y2. See Exercise 3.5 for a simple example.

# 3.5.4 Example: Imputing missing values

As an example application of the above results, suppose we observe some parts (dimensions) of y, with the remaining parts being missing or unobserved.
