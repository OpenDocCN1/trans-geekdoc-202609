
Hence

$$\frac{\partial z}{\partial x_i}=\frac{\partial}{\partial x_i}\log\sum_j e^{x_j}-\frac{\partial}{\partial x_i}x_c=\frac{e^{x_i}}{\sum_j e^{x_j}}-\frac{\partial}{\partial x_i}x_c=p_i-\mathbb{I}(i=c)$$ (13.40)

If we define $\mathbf{y}=[\mathbb{I}(i=c)]$, we recover Eq. (13.38).

Note that the Jacobian of this layer is a row vector, since the output is a scalar. We define $\boldsymbol{\delta}=\mathbf{J}^\top$ to be the corresponding column vector.

### 13.3.2.2 Elementwise nonlinearity

Consider a layer that applies an elementwise nonlinearity, $\mathbf{z}=\mathbf{f}(\mathbf{x})=\varphi(\mathbf{x})$, so $z_i=\varphi(x_i)$. The $(i,j)$ element of the Jacobian is given by

$$\frac{\partial z_i}{\partial x_j}=\begin{cases}\varphi'(x_i)&\text{if }i=j\\0&\text{otherwise}\end{cases}$$ (13.41)

where $\varphi'(a)=\frac{d}{da}\varphi(a)$. In other words, the Jacobian wrt the input is

$$\mathbf{J}=\frac{\partial\mathbf{f}}{\partial\mathbf{x}}=\operatorname{diag}(\varphi'(\mathbf{x}))$$ (13.42)

We can compute $\boldsymbol{\delta}^\top\mathbf{J}$ by elementwise multiplication of $\boldsymbol{\delta}$.

For example, if

$$\varphi(a)=\operatorname{ReLU}(a)=\max(a,0)$$ (13.43)

we have

$$\varphi'(a)=\begin{cases}0& a<0\\1& a>0\end{cases}$$ (13.44)

The subderivative (Sec. B.4.4) at $a=0$ is any value in $[0,1]$. It is often taken to be $0$. Hence

$$\operatorname{ReLU}'(a)=H(a)$$ (13.45)

where $H$ is the Heaviside step function.

### 13.3.2.3 Linear layer

Now consider a linear layer, $\mathbf{z}=\mathbf{f}(\mathbf{x},\mathbf{W})=\mathbf{Wx}$, where $\mathbf{W}\in\mathbb{R}^{m\times n}$, so $\mathbf{x}\in\mathbb{R}^n$ and $\mathbf{z}\in\mathbb{R}^m$. We can compute the Jacobian wrt the input vector, $\mathbf{J}=\frac{\partial\mathbf{z}}{\partial\mathbf{x}}$, as follows. Note that

$$z_i=\sum_{k=1}^n W_{ik}x_k$$ (13.46)

So the $(i,j)$ entry of the Jacobian will be

$$\frac{\partial z_i}{\partial x_j}=\frac{\partial}{\partial x_j}\sum_{k=1}^n W_{ik}x_k=\sum_{k=1}^n W_{ik}\frac{\partial}{\partial x_j}x_k=W_{ij}\tag{13.47}$$

since $\frac{\partial}{\partial x_j}x_k=\mathbb{I}(k=j)$. Hence the Jacobian wrt the input is

$$\mathbf{J}=\frac{\partial\mathbf{z}}{\partial\mathbf{x}}=\mathbf{W}\tag{13.48}$$

If $\boldsymbol{\delta}=\nabla_{\mathbf{z}}\mathcal{L}\in\mathbb{R}^m$, then we have

$$\frac{\partial\mathcal{L}}{\partial\mathbf{x}}=\frac{\partial\mathcal{L}}{\partial\mathbf{z}}\frac{\partial\mathbf{z}}{\partial\mathbf{x}}=\boldsymbol{\delta}^\top\mathbf{W}\tag{13.49}$$

Now consider the Jacobian wrt the weight matrix, $\mathbf{J}=\frac{\partial\mathbf{z}}{\partial\mathbf{W}}$. This is an $m\times m\times n$ tensor, which is complex to deal with. So instead, let us focus on taking the gradient wrt a single weight, $W_{ij}$. This is easier to compute, since $\frac{\partial\mathbf{z}}{\partial W_{ij}}$ is a vector. To compute this, note that

$$z_k=\sum_{l=1}^m W_{kl}x_l\tag{13.50}$$

$$\frac{\partial z_k}{\partial W_{ij}}=\sum_{l=1}^m x_l\frac{\partial}{\partial W_{ij}}W_{kl}=\sum_{l=1}^m x_l\mathbb{I}(i=k\text{ and }j=l)\tag{13.51}$$

Hence

$$\frac{\partial\mathbf{z}}{\partial W_{ij}}=\begin{pmatrix}0\\\vdots\\0\\x_j\\0\\\vdots\\0\end{pmatrix}\tag{13.52}$$

where the non-zero entry occurs in location $i$. If $\boldsymbol{\delta}=\nabla_{\mathbf{z}}\mathcal{L}\in\mathbb{R}^m$, then we have

$$\frac{\partial\mathcal{L}}{\partial W_{ij}}=\frac{\partial\mathcal{L}}{\partial\mathbf{z}}\frac{\partial\mathbf{z}}{\partial W_{ij}}=\boldsymbol{\delta}^\top\frac{\partial\mathbf{z}}{\partial W_{ij}}=\sum_{k=1}^m\delta_k\frac{\partial z_k}{\partial W_{ij}}=\delta_i x_j\tag{13.53}$$

Thus the matrix-shaped loss wrt each weight is given by the outer product

$$\frac{\partial\mathcal{L}}{\partial\mathbf{W}}=\boldsymbol{\delta}\mathbf{x}^\top\tag{13.54}$$

## 13.3.3 Computation graphs

MLPs are a simple kind of DNN in which each layer feeds directly into the next, forming a chain structure, as shown in Fig. 13.12. However, sometimes we add skip connections, in which one layer connects to another layer that is multiple steps ahead in the ordering. In general, we can use any kind of computation graph, so long as it corresponds to a directed acyclic graph (DAG), where each node is a differentiable function of all its inputs.

For example, consider the function

$f(x_1, x_2) = x_2 e^{x_1} \sqrt{x_1 + x_2 e^{x_1}}$ (13.55)

We can compute this using the DAG in Fig. 13.13, where we number the intermediate functions as follows:

$x_3 = f_3(x_1) = e^{x_1}$ (13.56)
$x_4 = f_4(x_2, x_3) = x_2 x_3$ (13.57)
$x_5 = f_5(x_1, x_4) = x_1 + x_4$ (13.58)
$x_6 = f_6(x_5) = \sqrt{x_5}$ (13.59)
$x_7 = f_7(x_4, x_6) = x_4 x_6$ (13.60)

∂o/∂x7 = ∂x7/∂x7 = I_m (13.62)
∂o/∂x6 = ∂o/∂x7 ∂x7/∂x6 (13.63)

∂o/∂x_j = Σ_{k∈children(j)} ∂o/∂x_k ∂x_k/∂x_j (13.66)

where the sum is over all children k of node j, as shown in Fig. 13.14. The ∂o/∂x_k gradient vector has already been computed for each child k; this quantity is called the adjoint. This gets multiplied by the Jacobian ∂x_k/∂x_j of each child.

The computation graph can be computed ahead of time, by using an API to define a static graph. (This is how Tensorflow 1 worked.) Alternatively, the graph can be computed “just in time”, by tracing the execution of the function on an input argument. (This is how Tensorflow eager mode works, as well as JAX and PyTorch.) The latter approach makes it easier to work with a dynamic graph, whose shape can change depending on the values computed by the function.

## 13.3.4 Forwards vs reverse mode differentiation

So far, we have focused on reverse-mode differentiation, since the method works in reverse topological order. However, we can also use forwards-mode differentiation, which can sometimes be more efficient.

To understand the difference, consider a mapping of the form **o = f(x)**, where **x ∈ ℝⁿ** and **o ∈ ℝᵐ**. We assume that **f** is defined as a composition of functions:

**f = f₄ ∘ f₃ ∘ f₂ ∘ f₁**  (13.67)

where **f₁ : ℝⁿ → ℝᵐ¹**, **f₂ : ℝᵐ¹ → ℝᵐ²**, **f₃ : ℝᵐ² → ℝᵐ³**, and **f₄ : ℝᵐ³ → ℝᵐ**. We can compute **J_f(x) = ∂o/∂x ∈ ℝᵐˣⁿ** using the chain rule:

∂o/∂x = ∂o/∂x₄ ∂x₄/∂x₃ ∂x₃/∂x₂ ∂x₂/∂x = ∂f₄(x₃)/∂x₄ ∂f₃(x₂)/∂x₃ ∂f₂(x₁)/∂x₂ ∂f₁(x)/∂x  (13.68)

= **J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁)**  (13.69)

We now discuss how to efficiently compute **J_f(x)**. Note that

**J_f(x) = ( ∂f₁/∂x₁ … ∂f₁/∂xₙ ; ⋮ ⋱ ⋮ ; ∂fₘ/∂x₁ … ∂fₘ/∂xₙ ) = ( ∇f₁(x)ᵀ ; ⋮ ; ∇fₘ(x)ᵀ ) = ( ∂f/∂x₁ , … , ∂f/∂xₙ )**  (13.70)

where **∇f_i(x)ᵀ ∈ ℝⁿ** is the *i*’th row (for *i = 1 : m*) and **∂f/∂x_j ∈ ℝᵐ** is the *j*’th column (for *j = 1 : n*). Hence we can extract the *i*’th row from **J** by using a vector Jacobian product of the form **e_iᵀ J**, where **e_i ∈ ℝᵐ** is the unit vector. Similarly, we can extract the *j*’th column from **J** by using a Jacobian vector product of the form **J e_j**, where **e_j ∈ ℝⁿ**.

If *n < m*, it is more efficient to compute **J** for each column *j = 1 : n* by using JVPs in a right-to-left manner:

**J_f(x) v = J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁) v**  with dimensions *m×m₃, m₃×m₂, m₂×m₁, m₁×n, n×1*  (13.71)

This can be using the forwards differentiation algorithm in Algorithm 6.

**Algorithm 6: Forwards autodiff**
1 **x₁ := x**
2 **v_j := e_j**, *j = 1 : n* where **e_j ∈ ℝⁿ**
3 **for k = 1 : K do**
4   **x_{k+1} := f_k(x_k)**
5   **v_j := J_{f_k}(x_k) v_j** for *j = 1 : n*
6 **Return o = x_{K+1}, v_j = [J_f(x)]_{:,j}** for *j = 1 : n*

If *n > m* (e.g., if the output is a scalar), it is more efficient to compute **J** for each row *i = 1 : m* by using VJPs in a left-to-right manner:

**uᵀ J_f(x) = uᵀ J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁)**  with dimensions *1×m, m×m₃, m₃×m₂, m₂×m₁, m₁×n*  (13.72)

This can be using the backwards differentiation algorithm in Algorithm 7.
