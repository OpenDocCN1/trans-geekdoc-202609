## 10.6.3 MCMC approximation

Markov chain Monte Carlo, or MCMC, is often considered the “gold standard” for approximate inference, since it makes no explicit assumptions about the form of the posterior. Instead, it just approximates it non-parametrically using a set of S samples:

$$q(\theta|\mathcal{D}) \approx \frac{1}{S}\sum_{s=1}^{S} \delta(\theta - \boldsymbol{\theta}^s) \tag{10.123}$$

where $\boldsymbol{\theta}^s \sim p(\boldsymbol{\theta}|\mathcal{D})$ are samples from the posterior.

To efficiently compute these samples, we can use the method of Hamiltonian Monte Carlo or HMC, which we briefly describe in Sec. 7.7.4. There are many good software libraries for HMC. Here we will use PyMC3.³ They all rely on our ability to compute the gradient of the log joint, $\nabla_{\boldsymbol{\theta}} \log p(\mathcal{D}, \boldsymbol{\theta})$; we can use automatic differentiation for this, or use the explicit derivation we discussed in Sec. 10.2.3 for the binary case and Sec. 10.3.2 for the multiclass case.

Let us apply HMC to a 2d version of the binary iris classification problem that we discussed in Sec. 2.4.3, where we just use two input features, sepal length and sepal width. The decision boundary is the set of points $(x_1^*, x_2^*)$ such that $\sigma(b + w_1 x_1^* + w_2 x_2^*) = 0.5$. Such points must lie on the following line:

$$x_2^* = -\frac{b}{w_2} + \left(-\frac{w_1}{w_2}x_1^*\right) \tag{10.124}$$

We can therefore compute an MC approximation to the posterior over decision boundaries by sampling the parameters from the posterior, $(w_1, w_2, b) \sim p(\boldsymbol{\theta}|\mathcal{D})$, and plugging them into the above equation, to get $p(x_1^*, x_2^* |\mathcal{D})$, similar to Eq. (2.47). The results of this method (using a vague Gaussian prior for the parameters) are shown in Fig. 10.16a. The solid line is the posterior mean, and the shaded interval is a 95% credible interval. As before, we see that the uncertainty about the location of the boundary is higher as we move away from the training data.

In Fig. 10.16b, we show what happens to the decision boundary when we have unbalanced classes. We notice two things. First, the posterior uncertainty increases, because we have less data from the blue class. Second, we see that the posterior mean of the decision boundary shifts towards the class with less data. This follows from the analysis of Sec. 9.2.3, where we showed that changing the class prior changes the location of the decision boundary, so that more of the input space gets mapped to the class which is higher a priori.

## 10.6.4 Variational inference

As we discuss in Sec. 7.7.3, variational inference converts approximate inference into an optimization problem. It does this by choosing an approximate distribution $q(\mathbf{w};\boldsymbol{\xi})$ and optimizing the variational parameters $\boldsymbol{\xi}$ to maximize the evidence lower bound (ELBO). This has the effect of making $q(\mathbf{w};\boldsymbol{\xi}) \approx p(\mathbf{w}|\mathcal{D})$ in the sense that the KL divergence is small.

### 10.6.4.1 Binary case

In this section, we consider variational inference for the parameters of a binary logistic regression model using a Gaussian prior, $p(\mathbf{w}) = \mathcal{N}(\mathbf{w}|\boldsymbol{\mu}_0, V_0)$. We also assume a Gaussian posterior of the form $q(\mathbf{w}) = \mathcal{N}(\mathbf{w}|\boldsymbol{\mu}_N, V_N)$, which we fit by optimizing the ELBO. Our derivation of this posterior follows the presentation of [Bisi06, Sec 10.6].

Let us rewrite the likelihood for a single observation as follows:

$$p(y_n|\mathbf{x}_n,\mathbf{w}) = \sigma(\eta_n)^{y_n}(1-\sigma(\eta_n))^{1-y_n} \tag{10.125}$$

$$= \left(\frac{1}{1+e^{-\eta_n}}\right)^{y_n}\left(1-\frac{1}{1+e^{-\eta_n}}\right)^{1-y_n} \tag{10.126}$$

$$= e^{-\eta_n y_n}\frac{e^{-\eta_n}}{1+e^{-\eta_n}} = e^{-\eta_n y_n}\sigma(-\eta_n) \tag{10.127}$$

where $\eta_n = \mathbf{w}^{\mathsf{T}}\mathbf{x}_n$ are the logits. This is not conjugate to the Gaussian prior. So we will use the following “Gaussian-like” variational lower bound to the sigmoid function, proposed in [J96; J00]:

$$\sigma(\eta_n) \geq \sigma(\xi_n)\exp\left[(\eta_n-\xi_n)/2 - \lambda(\xi_n)(\eta_n^2-\xi_n^2)\right] \tag{10.128}$$

where $\xi_n$ is the variational parameter for datapoint $n$, and

$$\lambda(\xi) \triangleq \frac{1}{4\xi}\tanh(\xi/2) = \frac{1}{2\xi}\left[\sigma(\xi)-\frac{1}{2}\right] \tag{10.129}$$

We shall refer to this as the **JJ bound**, after its inventors, Jaakkola and Jordan. See Fig. 10.17(a) for a plot.

Using this bound, we can write

$$p(y_n|\mathbf{x}_n,\mathbf{w}) = e^{-\eta_n y_n}\sigma(-\eta_n) \geq e^{-\eta_n y_n}\sigma(\xi_n)\exp\left[(-\eta_n+\xi_n)/2 - \lambda(\xi_n)(\eta_n^2-\xi_n^2)\right] \tag{10.130}$$

We can now lower bound the log joint as follows:

log p(y|X, w) + log p(w) ≥ -½ (w - μ₀)ᵀ V₀⁻¹ (w - μ₀)   (10.131)
+ Σ_{n=1}^N [η_n (y_n - 1/2) - λ(ξ_n) wᵀ (x_n x_nᵀ) w]   (10.132)

Since this is a quadratic function of w, we can derive a Gaussian posterior approximation as follows:

q(w|ξ) = N(w|μ_N, V_N)   (10.133)
μ_N = V_N ( V₀⁻¹ μ₀ + Σ_{n=1}^N (y_n - 1/2) x_n )   (10.134)
V_N⁻¹ = V₀⁻¹ + 2 Σ_{n=1}^N λ(ξ_n) x_n x_nᵀ   (10.135)

This is more flexible than a Laplace approximation, since the variational parameters ξ can be used to optimize the curvature of the posterior covariance. To find the optimal ξ, we can maximize the ELBO, which is given by

log p(y|X) = log ∫ p(y|X, w) p(w) dw ≥ log ∫ h(w, ξ) p(w) dw = L(ξ)   (10.136)

where

h(w, ξ) = ∏_{n=1}^N σ(ξ_n) exp[ η_n y_n - (η_n + ξ_n)/2 - λ(ξ_n)(η_n² - ξ_n²) ]   (10.137)

We can evaluate the lower bound analytically to get

L(ξ) = ½ log |V_N|/|V₀| + ½ μ_Nᵀ V_N⁻¹ μ_N - ½ μ₀ᵀ V₀⁻¹ μ₀ + Σ_{n=1}^N [ log σ(ξ_n) - ½ ξ_n + λ(ξ_n) ξ_n² ]   (10.138)

Note that $\mathbf{A}_i$ is independent of $\psi_i$; however, we still write it as $\mathbf{A}_i$ (rather than dropping the $i$ subscript), since other bounds that we consider below will have a data-dependent curvature term. The upper bound on lse therefore becomes

$$\text{lse}(\boldsymbol{\eta}_i) \le \frac{1}{2}\boldsymbol{\eta}_i^\top \mathbf{A}_i \boldsymbol{\eta}_i - \mathbf{b}_i^\top \boldsymbol{\eta}_i + c_i \tag{10.147}$$ $$\mathbf{A}_i = \frac{1}{2}\left[\mathbf{I}_M - \frac{1}{M+1}\mathbf{1}_M\mathbf{1}_M^\top\right] \tag{10.148}$$ $$\mathbf{b}_i = \mathbf{A}_i\psi_i - \mathbf{g}(\psi_i) \tag{10.149}$$ $$c_i = \frac{1}{2}\psi_i^\top \mathbf{A}_i\psi_i - \mathbf{g}(\psi_i)^\top\psi_i + \text{lse}(\psi_i) \tag{10.150}$$

where $\psi_i \in \mathbb{R}^M$ is a vector of variational parameters. (This is the same bound as used in Sec. 10.3.4.)$^4$

We can use the above result to get the following lower bound on the softmax likelihood:

$$\log p(y_i = c\mid\mathbf{x}_i,\mathbf{w}) \ge \left[\mathbf{y}_i^\top \mathbf{X}_i\mathbf{w} - \frac{1}{2}\mathbf{w}^\top \mathbf{X}_i^\top \mathbf{A}_i \mathbf{X}_i\mathbf{w} + \mathbf{b}_i^\top \mathbf{X}_i\mathbf{w} - c_i\right]_c \tag{10.151}$$

To simplify notation, define the pseudo-measurement

$$\tilde{\mathbf{y}}_i \triangleq \mathbf{A}_i^{-1}(\mathbf{b}_i + \mathbf{y}_i) \tag{10.152}$$

Then we can get a “Gaussianized” version of the observation model:

$$p(\mathbf{y}_i\mid\mathbf{x}_i,\mathbf{w}) \ge f(\mathbf{x}_i,\psi_i)\,\mathcal{N}(\tilde{\mathbf{y}}_i\mid\mathbf{X}_i\mathbf{w},\mathbf{A}_i^{-1}) \tag{10.153}$$

where $f(\mathbf{x}_i,\psi_i)$ is some function that does not depend on $\mathbf{w}$. Given this, it is easy to compute the posterior $q(\mathbf{w}) = \mathcal{N}(\mathbf{m}_N,\mathbf{V}_N)$, using Bayes rule for Gaussians.

Given the posterior, we can write the ELBO as follows:

$$\mathcal{L}(\boldsymbol{\xi}) \triangleq -\mathbb{KL}(q(\mathbf{w})\|p(\mathbf{w})) + \mathbb{E}_q\left[\sum_{i=1}^{N}\log p(y_i\mid\mathbf{x}_i,\mathbf{w})\right] \tag{10.154}$$ $$= -\mathbb{KL}(q(\mathbf{w})\|p(\mathbf{w})) + \mathbb{E}_q\left[\sum_{i=1}^{N}\mathbf{y}_i^\top \boldsymbol{\eta}_i - \text{lse}(\boldsymbol{\eta}_i)\right] \tag{10.155}$$ $$= -\mathbb{KL}(q(\mathbf{w})\|p(\mathbf{w})) + \sum_{i=1}^{N}\mathbf{y}_i^\top \mathbb{E}_q[\boldsymbol{\eta}_i] - \sum_{i=1}^{N}\mathbb{E}_q[\text{lse}(\boldsymbol{\eta}_i)] \tag{10.156}$$

where $p(\mathbf{w}) = \mathcal{N}(\mathbf{w}\mid\mathbf{m}_0,\mathbf{V}_0)$ is the prior and $q(\mathbf{w}) = \mathcal{N}(\mathbf{w}\mid\mathbf{m}_N,\mathbf{V}_N)$ is the approximate posterior. The first term is just the KL divergence between two Gaussians, which is given by

$$-\mathbb{KL}(\mathcal{N}(\mathbf{m}_N,\mathbf{V}_N)\|\mathcal{N}(\mathbf{m}_0,\mathbf{V}_0)) = -\frac{1}{2}\left[\operatorname{tr}(\mathbf{V}_N\mathbf{V}_0^{-1}) - \log|\mathbf{V}_N\mathbf{V}_0^{-1}| + (\mathbf{m}_N - \mathbf{m}_0)^\top\mathbf{V}_0^{-1}(\mathbf{m}_N - \mathbf{m}_0) - D M\right] \tag{10.157}$$

4. If we have binary data, the Bohning bound becomes $\log(1+e^{\eta}) \le \tfrac12 a\eta^2 - b\eta + c$, where $a = \tfrac14$, $b = a\psi - (1+e^{-\psi})^{-1}$, $c = \tfrac12 a\psi^2 - (1+e^{-\psi})^{-1}\psi + \log(1+e^{\psi})$. This is less accurate than the JJ bound, which has an adaptive curvature term, since $a$ depends on $\boldsymbol{\xi}$.
