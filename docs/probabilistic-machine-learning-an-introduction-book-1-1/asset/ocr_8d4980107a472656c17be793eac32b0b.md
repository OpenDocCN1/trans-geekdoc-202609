# 13.6.2.1 Mixture of linear experts

In this section, we consider a simple example in which we use linear regression experts and a linear classification gating function, i.e., the model has the form:

p(y|x, z = k, θ) = N(y|w_k^T x, σ_k^2) (13.112)
p(z|x, θ) = Cat(z|S(Vx)) (13.113)

The individual weighting term p(z = k|x) is called the responsibility for expert k for input x. In Fig. 13.25b, we see how the gating networks softly partitions the input space amongst the K = 3 experts. Each expert p(y|x, z = k) corresponds to a linear regression model with different parameters. These are shown in Fig. 13.25c. If we take a weighted combination of the experts as our output, we get the red curve in Fig. 13.25a, which is clearly is a bad predictor. If instead we only predict using the most active expert (i.e., the one with the highest responsibility), we get the discontinuous black curve, which is a much better predictor.
