Fig. 3.11 and Fig. 3.12 plot some MVN densities in 2d for three different kinds of covariance matrices. A full covariance matrix has D(D + 1)/2 parameters, where we divide by 2 since Σ is symmetric. (The reason for the elliptical shape is explained in Sec. C.4.4, where we discuss the geometry of quadratic forms.) A diagonal covariance matrix has D parameters, and has 0s in the off-diagonal terms. A spherical covariance matrix, also called isotropic covariance matrix, has the form Σ = σ²I_D, so it only has one free parameter, namely σ².
