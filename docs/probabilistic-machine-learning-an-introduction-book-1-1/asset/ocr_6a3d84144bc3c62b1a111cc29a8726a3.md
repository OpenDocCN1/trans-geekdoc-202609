To understand the difference, consider a mapping of the form **o = f(x)**, where **x ∈ ℝⁿ** and **o ∈ ℝᵐ**. We assume that **f** is defined as a composition of functions:

**f = f₄ ∘ f₃ ∘ f₂ ∘ f₁**  (13.67)

where **f₁ : ℝⁿ → ℝᵐ¹**, **f₂ : ℝᵐ¹ → ℝᵐ²**, **f₃ : ℝᵐ² → ℝᵐ³**, and **f₄ : ℝᵐ³ → ℝᵐ**. We can compute **J_f(x) = ∂o/∂x ∈ ℝᵐˣⁿ** using the chain rule:

∂o/∂x = ∂o/∂x₄ ∂x₄/∂x₃ ∂x₃/∂x₂ ∂x₂/∂x = ∂f₄(x₃)/∂x₄ ∂f₃(x₂)/∂x₃ ∂f₂(x₁)/∂x₂ ∂f₁(x)/∂x  (13.68)

= **J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁)**  (13.69)

We now discuss how to efficiently compute **J_f(x)**. Note that

**J_f(x) = ( ∂f₁/∂x₁ … ∂f₁/∂xₙ ; ⋮ ⋱ ⋮ ; ∂fₘ/∂x₁ … ∂fₘ/∂xₙ ) = ( ∇f₁(x)ᵀ ; ⋮ ; ∇fₘ(x)ᵀ ) = ( ∂f/∂x₁ , … , ∂f/∂xₙ )**  (13.70)

where **∇f_i(x)ᵀ ∈ ℝⁿ** is the *i*’th row (for *i = 1 : m*) and **∂f/∂x_j ∈ ℝᵐ** is the *j*’th column (for *j = 1 : n*). Hence we can extract the *i*’th row from **J** by using a vector Jacobian product of the form **e_iᵀ J**, where **e_i ∈ ℝᵐ** is the unit vector. Similarly, we can extract the *j*’th column from **J** by using a Jacobian vector product of the form **J e_j**, where **e_j ∈ ℝⁿ**.

If *n < m*, it is more efficient to compute **J** for each column *j = 1 : n* by using JVPs in a right-to-left manner:

**J_f(x) v = J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁) v**  with dimensions *m×m₃, m₃×m₂, m₂×m₁, m₁×n, n×1*  (13.71)

This can be using the forwards differentiation algorithm in Algorithm 6.

**Algorithm 6: Forwards autodiff**
1 **x₁ := x**
2 **v_j := e_j**, *j = 1 : n* where **e_j ∈ ℝⁿ**
3 **for k = 1 : K do**
4   **x_{k+1} := f_k(x_k)**
5   **v_j := J_{f_k}(x_k) v_j** for *j = 1 : n*
6 **Return o = x_{K+1}, v_j = [J_f(x)]_{:,j}** for *j = 1 : n*

If *n > m* (e.g., if the output is a scalar), it is more efficient to compute **J** for each row *i = 1 : m* by using VJPs in a left-to-right manner:

**uᵀ J_f(x) = uᵀ J_f₄(x₄) J_f₃(x₃) J_f₂(x₂) J_f₁(x₁)**  with dimensions *1×m, m×m₃, m₃×m₂, m₂×m₁, m₁×n*  (13.72)
