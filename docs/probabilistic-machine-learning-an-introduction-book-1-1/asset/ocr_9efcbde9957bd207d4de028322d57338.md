# 7.2.1 The beta-binomial model

Suppose we toss a coin N times, and want to infer the probability of heads. Let y_n = 1 denote the event that the n’th trial was heads, y_n = 0 represent the event that the n’th trial was tails, and let D = {y_n : n = 1 : N} be all the data. We assume y_n ~ Ber(θ), where θ ∈ [0, 1] is the rate parameter (probability of heads). In this section, we discuss how to compute p(θ|D).

# 7.2.1.1 Likelihood

We assume the data are iid or independent and identically distributed. Thus the likelihood has the form

p(D|θ) = ∏_{n=1}^N θ^{y_n} (1 - θ)^{1 - y_n} = θ^{N_1} (1 - θ)^{N_0}  (7.11)

where we have defined N_1 = ∑_{n=1}^N 𝕀(y_n = 1) and N_0 = ∑_{n=1}^N 𝕀(y_n = 0), representing the number of heads and tails. These counts are called the sufficient statistics of the data, since this is all we need to know about D to infer θ. The total count, N = N_0 + N_1, is called the sample size.

Note that we can also consider a Binomial likelihood model, in which we perform N trials and observe the number of heads, y, rather than observing a sequence of coin tosses. Now the likelihood has the following form:

p(D|θ) = Bin(y|N,θ) (N choose y) θ^{y} (1 - θ)^{N - y}  (7.12)

The scaling factor (N choose y) is independent of θ, so we can ignore it. Thus this likelihood is proportional to the Bernoulli likelihood in Eq. (7.11), so our inferences about θ will be the same for both models.

# 7.2.1.2 Prior

To simplify the computations, we will assume that the prior p(θ) ∈ F is a conjugate prior for the likelihood function p(y|θ). This means that the posterior is in the same parameterized family as the prior, i.e., p(θ|D) ∈ F.

To ensure this property when using the Bernoulli (or Binomial) likelihood, we should use a prior of the following form: p(θ) ∝ θ^{α̃ - 1} (1 - θ)^{β̃ - 1}  (7.13)

# 7.2.1.3 Posterior

If we multiply the Bernoulli likelihood in Eq. (7.11) with the beta prior in Eq. (3.66) we get a beta posterior:

p(θ|D) ∝ θ^{N_1} (1 - θ)^{N_0} θ^{α̃ - 1} (1 - θ)^{β̃ - 1}  (7.14) ∝ Beta(θ| α̃ + N_1, β̃ + N_0)  (7.15) = Beta(θ| α̂, β̂)  (7.16)
