The corresponding joint distribution, $p(z,y) = p(z)p(y|z)$, is a $D + K$ dimensional Gaussian, with mean and covariance given by

$$
\begin{aligned}
\mu &= \begin{pmatrix} \mu_z \\ W\mu_z + b \end{pmatrix} \\
\Sigma &= \begin{pmatrix} \Sigma_z & \Sigma_z W^T \\ W \Sigma_z & \Sigma_z + W \Sigma_z W^T \end{pmatrix}
\end{aligned}
$$

By conditioning on y, we can compute the posterior $p(z|y)$ using Bayes' rule for Gaussians, which is as follows:

$$
\begin{aligned}
p(z|y) &= \frac{p(y|z)p(z)}{p(y)} = N(z | \mu_{z|y}, \Sigma_{z|y}) \\
\Sigma_{z|y}^{-1} &= \Sigma_z^{-1} + W^T \Sigma_y^{-1} W \\
\mu_{z|y} &= \Sigma_{z|y} [W^T \Sigma_y^{-1} (y - b) + \Sigma_z^{-1} \mu_z]
\end{aligned}
$$

The normalization constant is given by

$$
p(y) = \int N(z|\mu_z, \Sigma_z) N(y|Wz + b, \Sigma_y) dz = N(y | W\mu_z + b, \Sigma_y + W \Sigma_z W^T)
$$

This result follows by applying the Gaussian conditioning formula, Eq. (3.97), to the joint $p(y,z)$. We see that the Gaussian prior $p(z)$, combined with the Gaussian likelihood $p(y|z)$, results in a Gaussian posterior $p(z|y)$. Thus Gaussians are closed under Bayesian conditioning. To describe this more generally, we say that the Gaussian prior is a conjugate prior for the Gaussian likelihood, since the posterior distribution has the same type as the prior. We discuss the notion of conjugate priors in more detail in Sec. 7.2. In the sections below, we give various applications of this result.

## 3.6.1 Example: inferring a latent vector from a noisy sensor

Suppose we have an unknown quantity of interest, $z \in \mathbb{R}^D$, which we endow with a Gaussian prior, $p(z) = N(\mu_z, \Sigma_z)$. If we “know nothing” about $z$ a priori, we can set $\Sigma_z = \infty I$, which means we are completely uncertain about what the value of $z$ should be. (In practice, we can use a large but finite value for the covariance.) By symmetry, it seems reasonable to set $\mu_z = 0$.

Now suppose we make $N$ noisy but independent measurements of $z$, $y_n \sim N(z, \Sigma_y)$, each of size $K$. We can represent the likelihood as follows:

$$
p(D|z) = \prod_{n=1}^N N(y_n | z, \Sigma_y) = N(\bar{y} | z, \frac{1}{N} \Sigma_y)
$$

Note that we can replace the $N$ observations with their average, $\bar{y}$, provided we scale down the covariance by 1/N to compensate. Setting $W = I$, $b = 0$, we can then use Bayes rule for Gaussian to compute the posterior over $z$:

$$
\begin{aligned}
p(z | y_1, \dots, y_N) &= N(z | \hat{\mu}, \hat{\Sigma}) \\
\hat{\Sigma}^{-1} &= \Sigma_z^{-1} + N \Sigma_y^{-1} \\
\hat{\mu} &= \hat{\Sigma} (\Sigma_y^{-1} (N \bar{y}) + \Sigma_z^{-1} \mu_z)
\end{aligned}
$$

## 3.6.2 Example: inferring a latent vector from multiple noisy sensors

In this section, we extend Sec. 3.6.1, to the case where we have multiple measurements, coming from different sensors, each with different reliabilities. That is, the model has the form

$$
p(z, y) = p(z) \prod_{m=1}^{M} \prod_{n=1}^{N_m} N(y_{n,m} | z, \Sigma_m) \quad (3.110)
$$

where M is the number of sensors (measurement devices), and $N_m$ is the number of observations from sensor m, and $y = y_{1:N,1:M} \in \mathbb{R}^K$. Our goal is to combine the evidence together, to compute $p(z|y)$. This is known as sensor fusion.

We now give a simple example, where there are just two sensors, so $y_1 \sim N(z, \Sigma_1)$ and $y_2 \sim N(z, \Sigma_2)$. Pictorially, we can represent this example as $y_1 \leftarrow z \rightarrow y_2$. We can combine $y_1$ and $y_2$ into a single vector $y$, so the model can be represented as $z \rightarrow [y_1, y_2]$, where $p(y|z) = N(y|Wz, \Sigma_y)$, where $W = [I; I]$ and $\Sigma_y = [\Sigma_1, 0; 0, \Sigma_2]$ are block-structured matrices. We can then apply Bayes’ rule for Gaussians to compute $p(z|y)$.

Fig. 3.15(a) gives a 2d example, where we set $\Sigma_1 = \Sigma_2 = 0.01 I_2$, so both sensors are equally reliable.

# 3.7 Mixture models

One way to create more complex probability models is to take a convex combination of simple distributions. This is called a mixture model. This has the form $p(y|\theta) = \sum_{k=1}^K \pi_k p_k(y)$ where $p_k$ is the k'th mixture component, and $\pi_k$ are the mixture weights which satisfy $0 \le \pi_k \le 1$ and $\sum_{k=1}^K \pi_k = 1$.

We can re-express this model as a hierarchical model, in which we introduce the discrete latent variable $z \in \{1,\dots,K\}$, which specifies which distribution to use for generating the output y. The prior on this latent variable is $p(z = k) = \pi_k$, and the conditional is $p(y|z = k) = p_k(y) = p(y|\theta_k)$. That is, we define the following joint model: $p(z|\theta) = \text{Cat}(z|\pi)$, $p(y|z = k, \theta) = p(y|\theta_k)$.

Figure 3.16: A mixture of 3 Gaussians in 2d. (a) We show the contours of constant probability for each component in the mixture. (b) A surface plot of the overall density. Adapted from Figure 2.23 of [Bis06]. Generated by mixGaussPlotDemo.m.

The “generative story” for the data is that we first sample a specific component z, and then we generate the observations y using the parameters chosen according to the value of z. By marginalizing out z, we recover Eq. (3.112):

$$
p(y|\theta) = \sum_{k=1}^K p(z = k|\theta) p(y|z = k, \theta) = \sum_{k=1}^K \pi_k p(y|\theta_k) \quad (3.115)
$$

We can create different kinds of mixture model by varying the base distribution $p_k$, as we illustrate below.

## 3.7.1 Gaussian mixture models

A Gaussian mixture model or GMM, also called a mixture of Gaussians (MoG), is defined as follows:

$$
p(y) = \sum_{k=1}^K \pi_k N(y|\mu_k, \Sigma_k) \quad (3.116)
$$

In Fig. 3.16 we show the density defined by a mixture of 3 Gaussians in 2d. Each mixture component is represented by a different set of elliptical contours. If we let the number of mixture components grow sufficiently large, a GMM can approximate any smooth distribution over $\mathbb{R}^D$.
