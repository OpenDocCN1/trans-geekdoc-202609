We can also compute the pdf of the sum of two continuous rv's. For example, in the case of Gaussians, where x1 ~ N(μ1,σ1^2) and x2 ~ N(μ2,σ2^2), one can show (Exercise D.9) that if y = x1 + x2 then

p(y) = N(x1|μ1,σ1^2) ⊗ N(x2|μ2,σ2^2) = N(y|μ1 + μ2,σ1^2 + σ2^2) (D.79)

Hence the convolution of two Gaussians is a Gaussian.
