# # Appendix E. Frequentist statistics

Sec. E.3.2.



A natural question is: what is the connection between the parameter estimates $\hat{	heta}^s = \pi(\mathcal{D}^{(s)})$ computed by the bootstrap and parameter values sampled from the posterior, $	heta^s \sim p(\cdot|\mathcal{D})$? Conceptually they are quite different. But in the common case that the estimator is MLE and the prior is not very strong, they can be quite similar. For example, Fig. E.1(c-d) shows an example where we compute the posterior using a uniform Beta(1,1) prior, and then sample from it. We see that the posterior and the sampling distribution are quite similar. So one can think of the bootstrap distribution as a “poor man’s” posterior [HTF01, p235].

However, perhaps surprisingly, bootstrap sampling can be slower than posterior sampling. The reason is that the bootstrap has to generate $S$ sampled datasets, and then fit model to each one. By contrast, in posterior sampling, we only have to “fit” a model once given a single dataset. (Some methods for speeding up the bootstrap when applied to massive data sets are discussed in [Kle+11].)



In frequentist statistics, we use the variability induced by the sampling distribution as a way to estimate uncertainty of a parameter estimate. More precisely, we define a 100(1 − α)% confidence interval for a parameter estimate θ as any interval I(D̃) = (ℓ(D̃), u(D̃)) derived from a hypothetical dataset D̃ such that

```
Pr(θ ∈ I(D̃)|D̃ ∼ θ) = 1 − α		(E.51)
```

It is common to set α = 0.05, which yields a 95% CI. This means that, if we repeatedly sampled data, and compute I(D̃) for each such dataset, then about 95% of such intervals will contain the true parameter θ.

Note, however, that Eq. (E.51) does not mean that for any particular dataset that θ ∈ I(D) with 95% probability; this is what a Bayesian credible interval computes (Sec. 7.1.2.2), but is not what a frequentist confidence interval computes. For more details on this important distinction, see Sec. E.8.1.

Let us put aside such “philosophical” concerns, and discuss how to compute a confidence interval. Suppose that θ̂ is an estimate of the parameter θ. Let θ∗ be its true but unknown value. Also, suppose that the sampling distribution of Δ = θ̂ − θ∗ is known. Let δ and δ̄ denote its α/2 and 1 − α/2 quantiles. Hence

```
Pr(δ ≤ θ̂ − θ∗ ≤ δ̄) = 1 − α		(E.52)
```

Rearranging we get

```
Pr(θ̂ − δ̄ ≤ θ∗ ≤ θ̂ − δ) = 1 − α		(E.53)
```

And hence

```
I(D̃) = (θ̂(D̃) − δ̄(D̃), θ̂(D̃) + δ(D̃)) 		(E.54)
```
