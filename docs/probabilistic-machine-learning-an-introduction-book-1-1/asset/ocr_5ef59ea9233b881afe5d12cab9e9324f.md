For example, consider the family tree of the Simpsons, shown in Fig. B.4. Let $\mathcal{V}_m$ be the set of males, $\mathcal{V}_f$ be the set of females, and $\mathcal{V} = \mathcal{V}_m \cup \mathcal{V}_f$ be all the members of the family. The diagram encodes several binary relations. For example, the symmetric relation “married-to” can be represented as the set of pairs

$R_{\text{married}} = \{(\text{Clancy}, \text{Jackie}), (\text{Jackie}, \text{Clancy}), (\text{Homer}, \text{Marge}), (\text{Marge}, \text{Homer})\}$ (B.18)

We see that $R_{m} \subseteq \mathcal{V} \times \mathcal{V}$.

The binary one-to-many relation “father-of” can be represented as the set of pairs

$R_{\text{father-of}} = \{(\text{Clancy}, \text{Marge}), (\text{Clancy}, \text{Selma}), (\text{Homer}, \text{Bart}), (\text{Homer}, \text{Lisa}), (\text{Homer}, \text{Maggie})\}$ (B.19)

We see that $R_{\text{father-of}} \subseteq \mathcal{V}_m \times \mathcal{V}$.

We can represent binary relations as **graphs**, where each node is an object in the domain, and there is an $i \to j$ edge if $(i,j) \in R$. For example, Fig. B.5(a) represents the symmetric married-to relation as an undirected **bipartite graph**, with males on one side and females on the other. Fig. B.5(b) shows the asymmetric relation “father-of” using a directed graph. Each graph can be represented as $N \times N$ **adjacency matrix** $\mathbf{M}$, where $N = |\mathcal{V}|$ is the number of nodes, and $M_{ij} = 1$ iff there is an $i - j$ edge. Sparse matrices (with many zeros) correspond to sparse graphs (with many missing edges) and vice versa. Also, block structure in the matrix corresponds to structure in the graph.

We can also have higher order relations. Formally, a $k$-ary relation is a set of $k$-tuples, $R \subseteq \mathcal{V} \times \mathcal{V} \cdots \mathcal{V}$. These can be represented graphically using **hypergraphs**.
