where v_k and i are linear correlation coefficients.

Combining Equations (13) and (15), we can obtain

$\mu_k \sum_{i=1}^{N} v_{k,i} K_{k,i} = \frac{1}{N-1} \sum_{i=1}^{N} v_{k,i} \sum_{j=1}^{N} K_{k,j} K_{j,i}$

Further simplification results in:

$\lambda_k v_k = K v_k$

where $\lambda_k = (N-1)\mu_{k,i}$, $K \in R^{N \times N}$ is a kernel matrix, whose eigenvalues are $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_N$, and the corresponding eigenvectors are $v_1, v_2, \cdots, v_N$. In the feature space $H$, the eigenvector $V_k$ of the covariance matrix Q in Equation (15) forms a matrix $\hat{V}_f = [V_1 \quad V_2 \quad \cdots \quad V_f \quad V_{f+1} \quad \cdots \quad V_N]$. One principal element (PC) is selected, and we obtain $\hat{V}_f = [V_1 \quad V_2 \quad \cdots \quad V_f] \in R^{N \times f}$ in the principal element space, since the eigenvector $V_k$ should meet the normal constraint in the feature space $H$, that is, $\langle V_k, V_k \rangle = 1$. Thus, the eigenvectors $v_1, v_2, \cdots, v_N$ of the kernel matrix $K$ can be expressed as:

$\langle v_k, v_k \rangle = \frac{\langle V_k, V_k \rangle}{\lambda_k}$

The norm of $\frac{1}{\sqrt{\lambda_k}}$ is taken as the eigenvector, so we have

$v_k = \frac{1}{\sqrt{\lambda_k}} v^k$

$\hat{V}_f$ in feature space H is expressed as

$\hat{V}_f = \left[ \frac{1}{\sqrt{\lambda_1}} X^{T} v^1 \right] = X^T \hat{V} \Lambda^{-1/2}$

where $\Lambda = diag(\lambda_1, \lambda_2, \cdots, \lambda_f)$; $\hat{V} = [v^1 \quad v^2 \quad \cdots \quad v^f]$; $X = [\phi(x_1) \quad \phi(x_2) \quad \phi(x_N)]^T$.

# 5. Basic Theory of SVM

SVM can provide good generalization performance, and it has been widely used in small-sample classification [15]. As a classical nonlinear problem in the area of fault-location problems, SVM cannot find the classification hyperplane in the original sample space, so it is necessary to introduce a kernel function $K(x_i, x_j)$ to map to a linearly separable high-dimensional space. In this paper, a Gaussian kernel function mapping transformation is used, and the expression is as follows:

$K(x_i, x_j) = \exp\left(-\gamma \| x_i - x_j \|^2\right)$

where, $\| x_i - x_j \|^2$ is the square of the distance between $x_i$ and $x_j$, and r is the super parameter of the kernel function itself:

$\min_{\omega, b^*, \xi} \frac{1}{2} \omega^T \omega + c \sum_{i=1}^{N} \xi_i$

s.t. $y_i (\omega^T \phi(x_i)) \geq 1 - \xi_i, \quad i = 1, 2, \cdots N$
$\xi_i \geq 0, \quad i = 1, 2, \cdots N$

where $\xi_i$ is the relaxation variable, $c$ is the penalty factor, $x_i$ is the input $i$ sample, and $y_i$ is the sample type.
