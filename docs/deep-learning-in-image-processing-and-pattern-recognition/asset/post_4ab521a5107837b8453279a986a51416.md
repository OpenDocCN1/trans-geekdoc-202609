
When a suitable $B_k$ has been constructed, $H_k$ satisfies the condition $B_{k+1}=H_{k+1}^{-1}$. The Sherman-Morrison Woodbury [19] formula is used twice to obtain the updated formula of the matrix $H_k$ is:

$H_{k+1}=(I-\frac{s_k u_k^T}{u_k^T s_k})H_k(I-\frac{u_k s_k^T}{u_k^T s_k})+\frac{s_k s_k^T}{u_k^T s_k},$ (8)

where $H_k$ is the approximation of the inverse of the Hessian matrix and $I$ is the identity matrix of order $n$, $H_k$ should satisfy the following conditions:

- (1) $H_k$ satisfies the Quasi-Newton equation:
$B_{k+1}s_k=y_k$ or $H_{k+1}y_k=s_k;$
- (2) $H_k$ is a positive definite symmetric matrix;
- (3) The update from $H_k$ to $H_{k+1}$ is a low-rank update.

The specific process of the BFGS algorithm is shown in the literature [13]. It is known that the curvature condition $u_k^T s_k>0$ can guarantee the positive definiteness of $H_{k+1}$ when $H_k$ is positive definite. From Formula (8), an efficient recursive procedure is derived to compute the matrix-vector product $H_k r$. For completeness, we describe the L-BFGS recursive procedure for $H_k$ in Algorithm 1.

### Algorithm 1: L-BFGS two-loop recursion

1. Input: $s_k=[s_{k-m},s_{k-m+1},\cdots,s_{k-1}]$ and $u_k=[u_{k-m},u_{k-m+1},\cdots,u_{k-1}]$
2. $q\leftarrow g_k$
3. **for** $i=k-1;~k-m$ **do**
4. $\quad\alpha\leftarrow \rho s_k^T q$
5. $\quad q=q-\alpha u_i$
6. **end**
7. $r \leftarrow H_{m}^{\circ} q$
8. **for** $i=k-1;~k-m$ **do**
9. $\quad\beta\leftarrow\rho u_i^T d_i$
10. $\quad r \leftarrow r+s_i(\alpha-\beta)$
11. **end** $\quad\quad r \leftarrow r-I H_m g_k$
12. Return the result

The two-loop recursive scheme can find the descent direction only through a simple calculation. Hence, it is cheap to generate the search direction by using Algorithm 1.

## 4. Algorithm

In the L-BFGS method, $H_k$ no longer needs to be calculated and stored directly. Instead, the $m$ latest vectors $(s_k,u_k)$ saved in the memory are used to update the $H_k$, which only needs to store matrices of the size $m \times n$, saving a lot of computation cost and improving the reconstruction rate. The specific step of the L-BFGS algorithm is Algorithm 2.

In the L-BFGS algorithm, the Wolfe line search is used to obtain the step size $\alpha_k$. Wolfe line search belongs to a kind of inexact linear search. When using Wolfe line search to find the step size $\alpha_k$, $\alpha_k$ is required to satisfy the following:

$f(x_k + \alpha_k d_k) - f(x_k) \leq \rho_1 \alpha_k g_k^T d_k.$ (9)

To make (9) flexible, we employ the non-monotone reduction condition on the:

$g(x_k+\alpha_k d_k)^T d_k \geq \rho_2 g_k^T d_k,$ (10)

the parameter $\rho_1$ and $\rho_2$ satisfies the conditions $(0<\rho_1<\rho_2<1)$.

### Algorithm 2: Limit memory BFGS Algorithm (L-BFGS)

| Step | Description |
| :--- | :--- |
| 1. **Given:** | $\varepsilon > 0,\ k=0,\ c_1 \in (0, \frac{1}{2}),\ \rho_1 \in (0, 1),\ t \in (0, 1)$; |
| 2. **Initialization:** | $x_0 \in R^n,\ H_0 = I$. |
| 3. **while** | $\|s_k\| > \varepsilon$ **do** |
| 4. | Calculate the gradient $g_k$ |
| 5. | Compute $d_k = -H_k g_k$ from Algorithm 1 |
| 6. **while** | $f(x_k + \alpha_k d_k) - f(x_k) \leq \rho_1 \alpha_k g_k^T d_k$ **do** |
| 7. | $\alpha = t\alpha$ |
| 8. **end** | |
| 9. | $\alpha_k = \alpha,\ x_{k+1} = x_k + \alpha_k d_k$ |
| 10. | Update $H_{k+1}$ by $s_k$ and $u_k$ |
| 11. | Set $k = k + 1$ |
| 12. **end** | |

Finally, compared with the BFGS algorithm, the L-BFGS algorithm does not need to calculate and store $H_k$ directly; it only needs to store matrices of the size $m \times d$ and calculate $H_k$ by matrices of storage. The high reconstruction rate is improved by discarding some vectors and sacrificing a little reconstruction accuracy. Therefore, compared with the BFGS quasi-Newton method, the L-BFGS quasi-Newton method greatly reduces the computational complexity and makes the reconstruction rate of a sparse signal faster.

## 5. Verify the Feasibility of the L-BFGS Algorithm

According to Section 2, the sparse signal reconstruction problem of wireless sensor networks can be transformed into the $L_1$ norm minimization problem. When the solution is the optimal solution to the $L_1$ norm minimization problem, the sparse signal can be accurately reconstructed. In other words, when algorithm 2 meets global convergence, it is feasible.

First, we give some useful inequalities in the following lemma.

**Lemma 1.** Let $B_k$ be symmetric and positive definite, and $B_{k+1}$ is determined by the L-BFGS correction Equation (7), then the necessary and sufficient condition for $B_{k+1}$ symmetric and positive definite is $u_k^T s_k > 0$.

Lemma 1 shows that, if the initial matrix $B_0$ is symmetric and positive definite and maintains $u_k^T s_k > 0\ (\forall k \ge 0)$ during the iteration. Then, the matrix sequence $\{B_{k+1}\}$ generated by the L-BFGS correction formula is symmetric and positive definite, so that the equation $B_k d_k = -g_k$ has a unique solution $d_k$. It is easy to deduce that

$d_k^T B_k d_k = -g_k^T d_k$.

Since $d_k^T B_k d_k > 0$, so $g_k^T d_k < 0$. $d_k$ is the descending direction of the target function $f(x)$ at $x_k$.

**Lemma 2.** If the Wolfe search criterion is adopted in the L-BFGS corrected quasi-Newton algorithm, there is $u_k^T s_k > 0$.

**Proof.** Since $u_{k+1}^T s_k = (g_{k+1} - g_k)^T a_k d_k = a_k (g_{k+1}^T d_k - g_k^T d_k)$, according to step 5 of algorithm 2, we have

$g_{k+1}^T d_k \ge \rho_2 g_k^T d_k$,

it is easy to deduce that

$u_k^T s_k \ge a_k (\rho_2 - 1) g_k^T d_k$.

Since $\rho_2 < 1$ and $g_k^T d_k < 0$, so $u_k^T s_k > 0$. $B_{k+1}$ is positively definite. The search direction generated by the algorithm is guaranteed to be the descending direction of the objective function $F(x)$ at $x_k$, making the algorithm work normally.$\square$

**Lemma 3.** If the smooth function of the $L_1$ norm $\|x\|_1$ obtained by the smoothing technique is:

$f(x) = \sum_{i=1}^{n} H(x(i)),$

where:

$H(x(i)) = \begin{cases} \frac{x^2(i)}{2\tau}, & |x(i)| \le \tau\ \\ \ |x(i)| - \frac{\tau}{2}, & |x(i)| > \tau\ \end{cases}$

then it can be proven that $f(x) \le \|x\|_1$.

**Proof.** when $|x(i)| \le \tau_r f(x) = \sum_{i=1}^{n} \frac{x^2(i)}{2\tau} = \frac{1}{2\tau} \sum_{i=1}^{n} x^2(i) \le \frac{1}{2\tau}\tau \sum_{i=1}^{n} |x(i)| = \frac{1}{2}\|x\|_1 \le \|x\|_1$,

when $|x(i)| > \tau_r f(x) = \sum_{i=1}^{n} (|x(i)| - \frac{\tau}{2}) = \|x\|_1 - \frac{n\tau}{2} \le \|x\|_1$, we have that: $f(x) \le \|x\|_1.$$\square$

From Lemma 3 and the mechanism of Algorithm 2, we immediately obtain the following theorem.

**Theorem 1.** Let $\{x_k\}$ denote the sequence generated by L-BFGS quasi-Newton method iteration. When the smoothing parameter of $\|x\|_1$ satisfies $\tau_k \to 0$, then $\{x_k\}$ is a bounded sequence. Let $x^*$ denote any limit point of $\{x_k\}$, then $x^*$ is the optimal solution to the $L_1$ norm minimization problem.

Prove the smooth parameter $\tau_k$ for the step $k$, make $x_k^* = \underset{x}{\arg \min} f(x)$ denotes the minimum point of the objective function $F_k(x)$ at step $k$, and $z$ denote any vector satisfying $Az = y$.

Because $x_k^* = \underset{x}{\arg \min} F_k(x)$, so $F_k(x_k^*) \le F_k(z)$, also because $Az = y$, so:

$F_k(z) = \lambda f_k(z) + \frac{1}{2}\|Av - y\|_2^2 = \lambda f_k(z)$. (11)

And from Lemma 3, $f_k(z) \le \|z\|_1$, then:

$F_k(x_k^*) \le F_k(z) = \lambda f_k(z) \le \lambda \|z\|_1$. (12)

Since $F_k(x) = \lambda f_k(x) + \frac{1}{2}\|Ax - y\|_2^2$, $\|Ax - y\|_2^2 \ge 0$, so:

$F_k(x) \ge \lambda f_k(x)$. (13)

In combination with Equations (11) and (12), the smoothness of $f_k(x)$ is:

$\|x_k\|_1 \le f_0(x_k) + \frac{n\tau_k}{2} \le \frac{1}{\lambda}F_k(x_k) + \frac{n\tau_k}{2} \le \frac{1}{\lambda}\lambda\|z\|_1 + \frac{n\tau_k}{2} = \|z\|_1 + \frac{n\tau_k}{2}$.

In addition, when the smoothing parameter $\tau_k \to 0$, $\{x_k\}$ is a bounded sequence. On the other hand, it can also be proved that the limit point $x^*$ of the sequence $\{x_k\}$ is feasible. The limit point $x^*$ is the KKT point of the $L_1$ norm minimization problem. Since $\|x\|_1$ is convex and problem (3) is a convex programming problem, the KKT condition is sufficient for optimality, so $x^*$ is the optimal solution to the $\|x\|_1$ norm minimization problem (3). It can be seen that the sparse signal of the wireless sensor network can be accurately reconstructed by the L-BFGS quasi-Newton method.
