# 4. Kernel Principal Component Analysis

The KPCA method is used to represent the nonlinear relationship between modeling data. It can effectively project linearly indivisible input data into a high-dimensional space that can be linearly separated, and then execute linear PCA in feature space H. Assume that the sample set is x<sub>1</sub>, x<sub>2</sub>, ..., x<sub>N</sub> ∈ R<sup>m</sup>, where: N is the number of samples and m is the number of variables. These samples are projected into the feature space H through a nonlinear mapping φ, which can be expressed as:

```
$\phi:x_{i}\in R^{m}\to\phi(x_{i})\in R^{h}$ (12)
```

where h is the dimension of the feature space.

The dot product of vector φ(x<sub>i</sub>) and φ(x<sub>j</sub>) (i , j = 1 , 2 , ··· , N) in feature space H is:

```
$\phi(x_{i})^{T}\phi(x_{j})=\langle\phi(x_{i}),\phi(x_{j})\rangle=k(x_{i},x_{j})$ (13)
```

where: k is the kernel function.

The covariance matrix of samples in the high-dimensional feature space H is:

```
$Q=\frac{1}{N-1}\sum_{j=1}^{N}\phi(x_{j})\phi(x_{j})^{T}$ (14)
```

Similar to linear PCA, KPCA in the feature space is equivalent to solving the eigenvalue problem. Let the eigenvector be V<sub>k</sub>, the eigenvalue be *μ*<sub>k</sub>, and its characteristic equation be:

```
$\mu_{k}V_{k}=QV_{k}=\frac{1}{N-1}\sum_{j=1}^{N}\phi(x_{j})\phi(x_{j})^{T}V_{k}=\frac{1}{N-1}\sum_{j=1}^{N}\langle\phi(x_{j}),V_{k}\rangle\phi(x_{j})$ (15)
```

In Equation (15), each eigenvector V<sub>k</sub> in the covariance matrix Q can be regarded as a linear combination of φ(x<sub>1</sub>), φ(x<sub>2</sub>), ..., φ(x<sub>N</sub>) [14], that is:

```
$V_{k}=\sum_{i=1}^{N}v_{ki}\phi(x_{i}),\qquad k=1,2,\cdots,N$ (16)
```
