(3) In order to obtain the optimal solution more efficiently, the constrained problem is transformed into an unconstrained problem by using a Lagrangian operator $\tau(t)$ and penalty factor $\alpha$. The expanded Lagrangian function expression is:

```
$$\begin{aligned} L(\{v_k\}, \{\omega_k\}, \tau) = & \alpha \sum_{k=1}^{K} \left\| \partial_{\mathbf{l}} \left( \delta(t) + \frac{j}{\pi t} * v_k(t) \right) e^{-j \omega_k t} \right\|_2^2 \\[0.5em] & + \left\| f(t) - \sum_{k=1}^{K} v_k(t) \right\|_2^2 + \left[ \tau(t), f(t) - \sum_{k=1}^{K} v_k(t) \right] \end{aligned} \tag{3}$$
```

(4) The alternating direction multiplier method is used to iteratively update each modal component and the center frequency, and the saddle point of the unconstrained function is obtained, which is the best solution to the problem. The iterative update expression of $\overline{v_l}, \omega_k, \tau$ is as follows:

```
$$\hat{v}_k^{n+1}(\omega) = \frac{\hat{f}(\omega) - \sum_{i \neq k} \hat{v}_i(\omega) + \frac{\hat{\tau}(\omega)}{2}}{1 + 2\alpha(\omega - \omega_k)^2} \tag{4}$$
```

```
$$\omega_k^{n+1} = \frac{\int_{0}^{\infty} \omega |\hat{\partial}_k(\omega)|^2 d\omega}{\int_{0}^{\infty} |\hat{\partial}_k(\omega)|^2 d\omega} \tag{5}$$
```

```
$$\hat{\tau}^{n+1}(\omega) = \hat{\tau}^n(\omega) + \gamma \left[ \hat{f}(\omega) - \sum_{k=1}^{K} \hat{v}_k^{n+1}(\omega) \right] \tag{6}$$
```

In Equation (6) $n$ is the number of iterations and $\gamma$ is the noise tolerance parameter.

(5) Judgment of the iteration termination condition.

```
$$\sum_{k=1}^{K} \left\| \frac{\hat{v}_k^{n+1} - \hat{v}_k^n}{\|\hat{v}_k^n\|} \right\|_2^2 < \varepsilon \tag{7}$$
```
