min$_{x}$ ||x||$_{1}$, s.t. $Ax = y$.

The $L_1$ norm minimization problem is a convex optimization problem. There are many methods to solve convex optimization problems, and Newton's method is one of them. Newton's method uses the first-order matrix and second-order Hessian matrix to approximate the objective function quadratic, and the result is faster than other convex optimization algorithms.

In practice, it is difficult to directly solve the linear programming problem (3). Since matrix $A$ is very large and complex to calculate. To simplify the calculation, problem (3) can be transformed into an $L_1$ regularized least squares problem [16].

min$_{x}\lambda||x||_1 + \frac{1}{2}||y - Ax||_2^2$

where $\lambda$ is a regularization parameter.

Since $||x||_1$ is a nonsmooth convex function for $x$, the subgradient basic approach is not effective in solving the problem (4). The $L_1$ minimization problem (3) can be solved by solving a suitable smooth form of problem (4).

According to the literature [17], using the Nesterov smoothing technique, $||x||_1$ is smoothed into the following smooth function:

$f(x) = \sum_{i=1}^{n} H(x(i)),$

where:

$H(u) = \begin{cases} \frac{u^2}{2\tau}, & |u| \le \tau; \\ |u| - \frac{\tau}{2}, & |u| > \tau, \end{cases}$

$H(u)$ is the Huber penalty function, $\tau$ is a smooth parameter, see literature [18] for relevant research.

The smooth function $f(x)$ is convex, the gradient $\nabla f(x)$ is Lipchitz continuous, and its components are:

$\nabla f(x(i)) = \begin{cases} \frac{x(i)}{\tau}, & |x(i)| \le \tau \\ sign(x(i)), & |x(i)| > \tau \end{cases} \quad (i = 1, 2, 3, \dots, n),$

which is:

$sign(x) = \begin{cases} 1, & x > 0; \\ 0, & x = 0; \\ -1, & x < 0. \end{cases}$

For ease of calculation, let $F(x) = \lambda||x||_1 + \frac{1}{2}||y - Ax||_2^2$. Convert the $L_1$ regularized least squares problem (4) into an unconstrained smooth convex programming problem:

$minF(x) = min_x\lambda||x||_1 + \frac{1}{2}||y - Ax||_2^2,$

where $F(x)$ is differentiable when Newton's method is adopted, the search direction of $F(x)$ is:

$d_k = -\left[\nabla^2F(x)\right]^{-1}\nabla F(x)$.

The gradient of $F(x)$ is:

$\nabla F(x) = \lambda\nabla f(x) + A^T(Ax - y)$.
