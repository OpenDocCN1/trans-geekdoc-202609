# 3.3.1. Multi-BSCConv Head Transposed Attention (MBTA)

The computational cost in a traditional transformer mainly comes from the self-attention layer. The time and memory complexity of the key–query dot-product interaction grows quadratically with the spatial resolution of the input. MBTA, on the other hand, greatly reduces the computational overhead by using cross-channel rather than cross-space self-attention; the specific structure is shown in Figure 5a. The MBTA process is described below: for the input nominal $X \in R^{H \times W \times C}$, we first achieve cross-channel pixel-level feature aggregation by 1 $\times$ 1 point-wise convolution, and subsequently, we use 3 $\times$ 3 BSCConv to extract channel contextual information. The advantage of using deep convolution is that it can better focus on the local context before generating the global feature map. The query (Q), key (K), and value (V) are generated from the above process. This process can be formulated as:

```
Q = $H^{q}_{BSCconv}(H^{q}_{p}(\text{LN}(X)))$
K = $H^{k}_{BSCconv}(H^{k}_{p}(\text{LN}(X)))$
V = $H^{v}_{BSCconv}(H^{v}_{p}(\text{LN}(X)))$
(7)
```

where $H_{BSCconv}(\cdot)$ denotes the BSCConv, $H_{p}(\cdot)$ denotes the 1 $\times$ 1 point-wise convolution, and $LN$ denotes the layer normalization.

Next, a transposed attention map of size $R^{C \times C}$ is generated by reshaping the query and key projection via their dot product. This process can be formulated as:

```
Attention(Q,K,V) = V $\cdot$ Softmax(K $\cdot$ Q/a)
$\hat{X}$ = $H_{p}(Attention(Q,K,V))$ + X
(8)
```

where *Softmax* denotes the function of softmax to generate the probability map, *a* is a learnable scaling parameter to control the size of the dot product of K and Q before applying the softmax function, and $H_{p}(\cdot)$ indicates the point-wise 1 $\times$ 1 convolution.
