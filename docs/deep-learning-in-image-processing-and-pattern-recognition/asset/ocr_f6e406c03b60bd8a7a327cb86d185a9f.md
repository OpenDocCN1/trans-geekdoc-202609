γ = 2 − Λ (10)

The shape cost Ω is defined as follows:

Ω = \sum_{t=w,h} (1 - e^{-w\theta}) \theta (11)

w_w = \frac{|w - w_{gt}|}{\max(w - w_{gt})} (12)

w_h = \frac{|h - h_{gt}|}{\max(h - h_{gt})} (13)

θ controls the degree of attention to shape error, and its selection is related to the specific dataset. If θ = 1, shape error will be optimized, thereby reducing the free movement of the predicted box and the actual box shape. The regression loss of the target box is written as follows:

$L_{SIoU} = 1 - IoU + (\Delta + \Omega)/2$ (14)
