The GC first groups the input data, and then convolves each group of data separately. The input feature map size of $C_1$ are divided into $G$ groups as follows:

```
$$
\begin{bmatrix}
H_1(x) \\
H_2(x) \\
\vdots \\
H_G(x)
\end{bmatrix}
=
\begin{bmatrix}
W_{11}^{P} & 0 & 0 & 0 \\
0 & W_{11}^{P} & 0 & 0 \\
\vdots & \vdots & \vdots & \vdots \\
0 & 0 & 0 & W_{GG}^{P}
\end{bmatrix}
=
\begin{bmatrix}
x_1 \\
x_2 \\
\vdots \\
x_G
\end{bmatrix}\tag{1}
$$

$$F(x)=\sum_{i=1}^{G}H_i(x)\tag{2}$$
```

where, $[x_1, x_2, \cdots, x_G]$ is the input feature map which is divided into groups size of $G$, each group has $G_1/G$ feature map size of $H_1 \times W_1$; $W_{11}^{P}$ is the convolution kernel of each group with the number of $P = C_2/G$ and size of $h \times w$; $H_i(x)$ is the output feature maps of each group size of $H_2 \times W_2$. Then, all the output feature maps are merged by channel to get the final output of the convolution layer.

If $C_1 = C_2 = C$ which means the input and output feature maps of the above GC are equal, $T_{GC}$ is the number of parameters, which can be calculated as follows:

```
$$T_{GC}=G \times \bigg(\frac{C}{G} \times h \times w \times \frac{C}{G}\bigg)=\frac{h \times w \times C^2}{G}\tag{3}$$
```

In the same case, the number of parameters of ordinary convolution named as $T_{RC}$ can be calculated as follows:

```
$$T_{RC}=C \times h \times w \times C=h \times w \times C^2\tag{4}$$
```

By comparison of $T_{GC}$ and $T_{RC}$, the parameter amount of the group convolution is $1/G$ of the standard convolution, which means G is larger, the complexity is lower and the parameter efficiency is higher.

# 2.2. Depthwise Over-Parameterized Convolution
