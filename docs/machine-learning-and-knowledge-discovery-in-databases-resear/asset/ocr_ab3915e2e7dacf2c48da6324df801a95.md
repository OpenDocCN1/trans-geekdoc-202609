For each pair of starting and target representations \((\mathbf{z}^m_{\text{start}}, \mathbf{z}^m_{\text{target}})\), we define an interpolated representation, \(\mathbf{z}^m_{\alpha=1}\), where only the \(N\) most important dimensions (those with the greatest average difference over 64 time frames) are altered to match \(\mathbf{z}^m_{\text{target}}\). The similarity between the decoded \(\mathbf{z}^m_{\alpha=1}\) and \(\mathbf{z}^m_{\text{target}}\) measures how many dimensions are needed to transform the signal. The relative error is computed as:

\(\delta = \frac{\text{MAE}\left(D(\mathbf{z}^m_{\text{target}}), D(\mathbf{z}^m_{\alpha=1})\right)}{\text{MAE}\left(D(\mathbf{z}^m_{\text{start}}), D(\mathbf{z}^m_{\alpha=1})\right)}\) (12)

Here, \(\delta\) ranges from 0 (exact match to target) to 1 (no effect from altering dimensions).

**Decoder Details.** Each decoder \(D(\mathbf{z}^m_t)\) is trained for 50 epochs on representations from a specific module \(g^m_{enc}(\cdot)\), using the MSE loss, a learning rate of \(2 \times 10^{-4}\), and batch size 8. The decoder mirrors the encoder architecture, but for the first module, two additional layers (kernel size 3, padding 1, stride 1) were added to improve reconstruction.

**Results.** Table 2 shows the relative errors. Across all depths, SIM reconstructs the target signal using fewer dimensions than GIM. For the artificial dataset, GIM needs at least half of the dimensions for successful reconstruction, whereas SIM achieves similar results with just 1/8th. Given the limited information in this dataset, which theoretically requires far fewer than 512 dimensions, multiple of GIM’s dimensions seem sensitive to similar attributes. This implies a more entangled representation, which aligns with earlier findings in Fig. 3. For LibriSpeech, SIM consistently requires fewer dimensions, averaging around half the number used by GIM, showing potential to scale well to more complex datasets.
