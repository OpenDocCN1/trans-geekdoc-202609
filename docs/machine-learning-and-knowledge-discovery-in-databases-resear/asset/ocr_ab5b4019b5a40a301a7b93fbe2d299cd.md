identity matrix and $k$ being the number of AA types and $\mathbf{1}$ being the one vector of dimension $k$, i.e.,

```
p ( s_t | s_{t-1} ) = Q_t \cdot s_{t-1}, \quad (3)
```

where $s_t$ and $s_{t-1}$ represent node's noise AA type in step $t$ and $t-1$, respectively. Similar to DDPM [11], we can compute node's noise AA type in step $t$ from initial step, denoted as follows:

```
p ( s_t | s_0 ) = \bar{Q}_t \cdot s_0. \quad (4)
```

$\bar{Q}_t$ denotes transition probability from initial step to $t$ directly, and $s_0$ represents node's original AA type.

*Denoising Process.* In the denoising process, each node's noise AA type is sampled from the uniformly prior distribution and iterated back to the initial distribution. The transformation between distributions is sketched as follows:

```
p_\theta ( s_{t-1} | s_t, \mathcal{G} ) = \sum_{\hat{s}_0} q ( s_{t-1} | \hat{s}_0, s_t, \mathcal{G} ) p_\theta ( \hat{s}_0 | s_t, \mathcal{G} ) , \quad (5)
```

where $\hat{s}_0$ is predicted AA type and $q ( s_{t-1} | \hat{s}_0, s_t, \mathcal{G} )$ represent posterior that can be computed as follows:

```
q ( s_{t-1} | \hat{s}_0, s_t, \mathcal{G} ) = \text{DIST} \left( s_{t-1} \middle| \frac{ Q_t^T s_{t-1} \odot Q_{t-1}^T \hat{s}_0 }{ s_t^T Q_t s_{t-1} } \right) , \quad (6)
```

where DIST is a categorical distribution over 20 AA types with probabilities computed by the posterior distribution [42].
