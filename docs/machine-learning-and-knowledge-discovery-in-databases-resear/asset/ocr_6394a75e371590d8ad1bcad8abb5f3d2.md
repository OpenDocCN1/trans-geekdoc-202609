Global Graph Construction. For all regions \(U_i \in \mathcal{U}, i = 1, 2, \dots, N\), we construct a global graph \(\mathcal{G} = (\mathcal{V}, \mathcal{E})\), which includes all nodes and edges from the local graphs \(\mathcal{G}_1, \dots, \mathcal{G}_N\). Additionally, it introduces four extra types of edges that capture inter-region relationships, based on region nodes \(\mathcal{U}\) and coarse-grained modalities: POI (\(\mathcal{P}\)), Taxi Flow (\(\mathcal{TF}\)), and Remote Sensing (\(\mathcal{RS}\)). Fine-grained modalities Street View (\(\mathcal{SV}\)) and Road Network (\(\mathcal{RN}\)), do not establish inter-region edges, as they primarily capture local environmental and topological features within a region. The four types are:

+   - **\(\mathcal{U}\)\_sim\_\(\mathcal{U}\)**: A set of edges \((U_i, U_j)\) connecting region nodes whose geographical boundaries are adjacent, where \(i, j = 1, 2, \dots, N\) and \(i \neq j\).
+   - **\(\mathcal{P}\)\_sim\_\(\mathcal{P}\)**: A set of edges \((P_i, P_j)\) connecting POI nodes based on cosine semantic similarity across regions, where \(i, j = 1, 2, \dots, N\) and \(i \neq j\).
+   - **\(\mathcal{TF}\)\_sim\_\(\mathcal{TF}\)**: A set of edges \((\mathcal{TF}_i, \mathcal{TF}_j)\) connecting taxi flow nodes based on cosine mobility similarity across regions, where \(i, j = 1, 2, \dots, N\) and \(i \neq j\).
+   - **\(\mathcal{RS}\)\_sim\_\(\mathcal{RS}\)**: A set of edges \((\mathcal{RS}_i, \mathcal{RS}_j)\) connecting remote sensing nodes based on cosine satellite similarity across regions, where \(i, j = 1, 2, \dots, N\) and \(i \neq j\).

# ### 4.2 Graph Node Representation

This subsection introduces the initialization of node representations for different modalities, followed by our designed message passing mechanisms for iterative updates.

# **Node Initialization for Each Modality**

+   - **Region (\(\mathcal{U}\))**: An undirected graph is constructed with all region geographic boundary \(U_i, i = 1, 2, \dots N\) and edges connecting adjacent regions. The initialization vector \(\mathbf{u}_i^{(0)} \in \mathbb{R}^{d_{in}}\) for \(U_i\) is derived using the Node2Vec algorithm [3].
+   - **Remote Sensing Imagery (\(\mathcal{RS}\))**: The initialization vector \(\mathbf{r}\mathbf{s}_i^{(0)} \in \mathbb{R}^{d_{in}}\) for each \(RS_i\) is obtained by applying the EfficientNet-B4 model [16].
+   - **Point-of-Interest (POI) (\(\mathcal{P}\))**: The initialization vector \(\mathbf{p}_i^{(0)} \in \mathbb{R}^{d_{in}}\) for each \(P_i\) is generated by setting \(K = d_{in}\).
+   - **Taxi Flow (\(\mathcal{TF}\))**: The initialization vector \(\mathbf{t}\mathbf{f}_i^{(0)} \in \mathbb{R}^{d_{in}}\) for each \(\mathcal{TF}_i\) is computed by setting \(T = d_{in}\).
+   - **Street View Imagery (\(\mathcal{SV}\))**: The initialization vector \(\mathbf{s}\mathbf{v}_{i,j}^{(0)} \in \mathbb{R}^{d_{in}}\) is obtained for each street view image \(SV_{i,j}\), where \(j = 1, 2, \dots, |\mathcal{SV}_i|\), by leveraging the CLIP-ViT-B/32 model [13].
+   - **Road Network (\(\mathcal{RN}\))**: The initialization vector \(\mathbf{r}\mathbf{n}_{i,j}^{(0)} \in \mathbb{R}^{d_{in}}\) is generated for each road network element \(RN_{i,j}\), where \(j = 1, 2, \dots, |\mathcal{RN}_i|\), by employing an embedding technique [12].
