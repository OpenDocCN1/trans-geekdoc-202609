```
Algorithm 1. Hierarchical Mesh Coarsening with Constrained Delaunay Triangulation

Require: Mesh M, Positions P, Levels L, Coarsening Ratios U, Neighbor Counts K
Ensure: Coarsened Meshes {M_l}_{l=1}^L, Positions {P_l}_{l=1}^L, Sampling Indices {I_l}_{l=1}^L, Neighbor Indices {N_l}_{l=1}^L Initialize coarse mesh parameters;
1: while not converged do
2:   Sample nodes from mesh M based on ratio U;
3:   for each level l = 1, ..., L do
4:     Generate sampling indices I_l;
5:     Update positions P_l;
6:     Construct coarse mesh M_l via Constrained Delaunay triangulation;
7:     Compute neighbor indices N_l using fixed-size K;
8:   end for
9:   Update coarse mesh and parameters;
10: end while
```

where \(n = |\mathcal{V}|\) denote the number of nodes in the mesh and \(\mathcal{N}'(v)\) denote the set of neighbors of node \(v\). Nodes are classified as \(\mathcal{V}_\text{d}\) if \(d'(v) > \bar{d}\), and \(\mathcal{V}_\text{s}\) otherwise.

Given a coarsening ratio \(U\) (e.g., \(U = 0.5\) for 50% downsampling) and a sampling proportion \(m\) for dense regions, we define the number of sampled nodes in dense and sparse regions as:

```
\(k_d = \lfloor U \cdot m \cdot n \rfloor,\quad k_s = \lfloor U \cdot (1 - m) \cdot n \rfloor,\)
(3)
```

where \(k_d\) and \(k_s\) represent the number of nodes sampled from dense and sparse regions, respectively. The combined sampled node set is then defined as:

```
\(\left\{\begin{array}{l l}
V_d = \{v_i \mid v_i \sim \mathcal{U}(\mathcal{V}_\text{d})\}, & |V_d| = k_d, \\
V_s = \{v_i \mid v_i = \text{FPS}(\mathcal{V}_\text{s})\}, & |V_s| = k_s,
\end{array}\right.\)
(3)
```

Here, \(\mathcal{U}(\mathcal{V}_\text{d})\) denotes random sampling from dense regions, and FPS(\(\mathcal{V}_\text{s}\)) denotes farthest point sampling based on Euclidean distance. Finally, the full sampling set is \(S_i = V_d \cup V_s\). As illustrated in Fig. 3, our hierarchical sampling strategy effectively distinguishes regions requiring detailed local representation from those reflecting global mesh structure, preserving critical geometric details and avoiding errors during coarsening.
