**Step 4: Multi-Head Local-Global (LG) Attention Computation.** We now apply a multi-head attention mechanism. For $H$ attention heads, we split the embedding dimension $D$ into $H$ sub-dimensions of size $D_h = D/H$:

```
$\mathbf{Q}_h \in \mathbb{R}^{B \times M \times D_h}, \quad \mathbf{K}_h, \mathbf{V}_h \in \mathbb{R}^{B \times N \times D_h}, \quad h = 1, \dots, H. \quad (11)$
```

For each head $h$, the scaled dot-product attention scores are computed as:

```
$\mathbf{A}_h = \text{softmax}\left( \frac{\mathbf{Q}_h \mathbf{K}_h^\top}{\sqrt{D_h}} \right) \in \mathbb{R}^{B \times M \times N}. \quad (12)$
```

Subsequently, we calculate the features as a weighted sum of values:

```
$\mathbf{O}_h = \mathbf{A}_h \mathbf{V}_h \in \mathbb{R}^{B \times M \times D_h}. \quad (13)$
```

Concatenating across all heads, we get the combined multi-head attention output:

```
$\mathbf{O} = \text{concat}(\mathbf{O}_1, \dots, \mathbf{O}_H) \in \mathbb{R}^{B \times M \times D}. \quad (14)$
```
