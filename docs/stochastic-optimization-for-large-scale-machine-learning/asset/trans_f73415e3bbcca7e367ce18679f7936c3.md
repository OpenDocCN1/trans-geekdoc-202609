

# 第 2 章 优化问题、求解器、挑战与研究方向

DOI: [10.1201/9781003240167-2](http://doi.org/10.1201/9781003240167-2)

幕后，机器学习问题实际上是优化问题。因此，优化问题的表述和选择合适的求解器对于机器学习模型的最终性能至关重要。我们以 SVM 为例，说明一个问题可以以多种方式表述，以及每种表述如何使用多种求解器来求解。SVM 是一种二元线性分类器，已通过核函数扩展到非线性数据，并通过一对一、一对其余和 Crammer Singer SVM 等各种技术扩展到多类数据。带有线性核的 SVM 称为线性 SVM，带有非线性核的 SVM 称为非线性 SVM。线性 SVM 是一种高效的技术，适用于文档分类、词义消歧、药物设计等高维数据应用，因为在这些数据应用中，线性 SVM 的测试精度接近非线性 SVM，而其训练速度远快于非线性 SVM。自诞生以来，SVM 不断发展，研究人员提出了许多用于求解 SVM 的问题表述、求解器和策略。此外，由于技术的进步，数据已呈现为“大数据”形式，这给机器学习在大规模数据上训练分类器带来了挑战。在本章中，我们对线性支持向量机分类的演进、其求解器、改进求解器的策略、实验结果、当前挑战和研究方向进行了综述。

## 2.1 引言

有关 SVM 的基本介绍，请参阅 [第 1.3.1 节](#02chap_01.xhtml#sec1_3_1)。线性 SVM 涉及问题表述、求解问题的求解器以及使求解器高效的优化策略。通常，SVM 问题表述为凸问题 \[[33](#bib.xhtml#refbib_33), [31](#bib.xhtml#refbib_31)]，因为凸问题中不存在局部最优问题，因为每个局部最优都是全局最优。在表述问题时，通常使用 L1 (`∥w∥`) 和 L2 正则化 (`∥w∥²`)、L1 和 L2 损失函数，如下所示。因此，考虑 L1 和 L2 正则化、L1 和 L2 损失函数以及线性核，线性 SVM 有八种不同的表述，如 [图 2.1](#03chap_02.xhtml#f2_1) 所示，这表明了可能的问题表述范围很广。参数向量 `w` 和数据点 (`x[i]`, `y[i]`) 的 L1 和 L2 损失函数如下：

对于特定的 SVM，可以求解原始问题或对偶问题。通常，当特征数量 (`n`) 远少于训练点数量 (`l`) 时，求解 SVM 的原始表述 \[[85](#bib.xhtml#refbib_85)]; 否则，求解对偶表述 \[[53](#bib.xhtml#refbib_53)]。这是因为问题中的变量越少，问题越容易求解。

如今，SVM（与机器学习共享）的主要挑战是处理“大数据”问题，为了处理此类问题，研究人员正在尝试利用平台/框架结构（如并行和分布式计算），并提出新的问题表述、求解器、优化策略和算法等。机器学习中处理大数据问题的当前研究方向是：首先，随机近似算法 \[[63](#bib.xhtml#refbib_63), [71](#bib.xhtml#refbib_71), [35](#bib.xhtml#refbib_35), [115](#bib.xhtml#refbib_115)]，它通过在算法的每次迭代中仅使用一个数据点，消除了算法对数据点数量的依赖，从而使学习算法具有可扩展性。在过去五年中，提出了多种随机近似变体，例如小批量方法 \[[128](#bib.xhtml#refbib_128), [119](#bib.xhtml#refbib_119)]。其次，坐标下降算法 \[[130](#bib.xhtml#refbib_130), [100](#bib.xhtml#refbib_100), [6](#bib.xhtml#refbib_6), [112](#bib.xhtml#refbib_112), 137, [90](#bib.xhtml#refbib_90), [122](#bib.xhtml#refbib_122)]，它通过将一个特征作为变量，其余作为常数，将大问题减小为较小的子问题。在过去几年中，在这个方向上进行了大量研究，研究人员提出了其多种变体。第三，近端算法 \[[104](#bib.xhtml#refbib_104)]，用于一阶和二阶方法。这些算法适用于具有可分组件的非光滑问题。第四，并行和分布式计算 \[[141](#bib.xhtml#refbib_141)]，它利用计算资源。如今，由于数据集大小超出了单台计算机的容量，其他方法似乎已趋于饱和，因此在并行和分布式计算方面进行了大量研究。除了这些研究方向外，它们的混合版本也正在被广泛研究，例如，\[[140](#bib.xhtml#refbib_140), 23]。

### 2.1.1 贡献

本章的贡献如下：

*   我们讨论了不同的问题表述，即 SVM 的优化问题以及求解优化问题的一些通用求解器。

*   机器学习中的大数据挑战已得到表征，这突出了开发高效且可扩展的优化技术来应对该挑战的必要性。
