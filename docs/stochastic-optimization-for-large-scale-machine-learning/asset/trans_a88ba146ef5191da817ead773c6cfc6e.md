## 2.6.2 改进领域

分类是机器学习中的一种技术，用于在预定义值集合的帮助下，通过在标记数据上训练的模型为测试数据点分配标签。从数学上讲，分类问题是一个优化问题，即在最大化不同类别之间边界的同时，将分类错误降至最低。在解决分类问题时，有两个目标：第一，训练数据集上 `SVM` 模型的训练速度；第二，测试数据集上标签预测的准确性。因此，在解决分类问题时，速度和准确性是两个目标，但算法的速度和准确性之间存在权衡。如果使用简单的算法来提高速度，则无法获得良好的分类准确性。另一方面，当使用复杂的算法来训练模型时，它会提高准确性，但训练速度会降低，例如，最速下降法速度快，但与牛顿法相比，其收敛速度较慢。这取决于应用程序，是牺牲速度还是准确性。算法的训练速度和测试准确性都取决于这些因素：问题公式、问题求解器、框架/平台利用和优化策略，如 [图 2.9](#03chap_02.xhtml#f2_9) 所示。因此，为了使线性 `SVM` 分类高效且可扩展，挑战在于有效处理这些因素。

### 2.6.2.1 问题公式

问题公式在 `SVM` 中非常重要，`SVM` 问题中使用的求解器在一定程度上也取决于问题公式。`SVM` 可以表述为凸优化问题 \[77\]，也可以表述为非凸优化问题 \[126\]。通常，`SVM` 被表述为凸优化问题，因为不存在局部最小值问题，因为每个局部最小值都是全局最小值。`SVC` 优化问题有两个组成部分：边界和损失函数/错误。边界和错误之间的权衡由参数 `C` 控制。

1. 边界：

    该组件用于控制分离超平面之间的距离。边界越大，分类器的泛化能力越好。目前，L1R (`∥w∥`, \[[153](#bib.xhtml#refbib_153)\]) 和 L2R (`∥w∥²`, \[29\]) 在文献中被广泛用于表示 `SVM` 问题中的边界。

2. 损失函数：

    该组件作为松弛变量引入软边界 `SVM` 中。它有助于最小化分类器的误分类错误。通常，L1 损失 \[118\] 和 L2 损失 \[[76](#bib.xhtml#refbib_76)\] 函数（参见，公式 2.1）在文献中被广泛使用。其他损失函数（例如，\[[88](#bib.xhtml#refbib_88)\]）也可以使用，这取决于问题公式（有关损失函数的完整列表，请参见 \[[129](#bib.xhtml#refbib_129)\]）。

    这两个组件结合在一起构成了 `SVM` 问题（有关不同问题公式，请参见 [第 2.3 节](#03chap_02.xhtml#sec2_3)）。因此，当前的挑战是为边界和错误做出适当选择，或提出新的组件，以构建有效的 `SVM` 问题。不当的公式可能导致局部最小值问题、可微性问题以及速度较慢且准确性较低的方法。

### 2.6.2.2 问题求解器

问题求解器同样在获得更快、更准确的结果方面发挥着重要作用。有许多方法可用于解决优化问题，如 [第 2.4 节](#03chap_02.xhtml#sec2_4) 中所讨论。这取决于问题公式（在一定程度上），即应使用哪种方法来求解它。从文献中可以观察到，不同的研究人员使用不同的求解器解决了相同的问题，导致了不同的结果（\[85, 65\] 解决了相同的问题）。当前的挑战是寻找能够产生准确且更快结果的高效求解器。

### 2.6.2.3 问题求解策略/方法

方法在使用 `SVM` 求解器解决 `SVM` 问题中起着关键作用。问题公式可能非常好，问题求解器也可能非常高效，但由于缺乏合适的优化策略，我们的算法可能仍然表现不佳。例如，假设存在大规模稀疏数据问题，如果不利用问题的稀疏性，那么这种优化技术的训练可能会非常慢。同样，使用分解方法、随机逼近和问题缩减等，可以加快问题求解过程。机器学习（`SVM`）问题的一些策略如下：

1. 利用问题结构：

    可以利用问题结构（例如问题的稀疏性 \[[125](#bib.xhtml#refbib_125)\]）来使学习更高效。存在许多问题，如文档分类，其中大多数特征为零。因此，问题求解器在训练模型时应利用这一特征，这有助于加快问题的训练速度。同样，在内存中处理数据也会影响 `SVM` 求解器，例如按特征存储数据 \[38\] 或按实例存储数据。

2. 分解方法：

    根据这种方法，问题被分解为较小的问题，然后使用某些求解器求解子问题，以得到原问题的解 \[[64](#bib.xhtml#refbib_64)\]。例如，假设一个问题中有 10,000 个参数，那么可以先取前 100 个参数，固定其余参数并求解这个子问题，然后求解接下来的 100 个参数，重复此过程直到所有参数都被求解。这构成一次迭代，该过程可以重复直到收敛。分解方法的一种极端情况是坐标下降法 \[137\]，根据这种方法，在保持所有其他变量固定的情况下，对一个变量求解问题。这种优化方法有助于克服内存和 CPU 的实现问题。毫无疑问，这种方法需要更多的迭代且收敛较慢，但它使问题的实现成为可能，因为在特征（变量）数量较多的情况下，由于内存和 CPU 要求较大，可能无法处理该算法。

    坐标下降法 \[38, 137\]、`SMO` \[[106](#bib.xhtml#refbib_106)\] 和块优化 \[23\] 是分解方法的三个示例。这种方法有助于解决大规模问题。坐标下降法的通用算法在 [算法 6](#03chap_02.xhtml#algorithm_6) 中给出。

    坐标下降法的优点：有并行版本可用；不需要额外的存储向量；不需要其他烦人的参数；它对非常大的问题效果良好且易于实现。坐标下降法的缺点：如果单变量优化很困难，则比较棘手；收敛理论可能非常复杂；在接近最优解时可能较慢。

3. 随机逼近方法：

    通常，参数在每次迭代中对所有数据实例进行优化，但在随机逼近 \[113\] 中，参数一次只对一个实例进行优化。随机逼近方法使每次迭代独立于数据点并降低了迭代复杂度。因此，这种方法在解决大规模问题时非常有帮助。这是因为，它不是遍历数据集中的所有实例，而是在每次迭代中只取一个实例。这种方法还有其他变体，例如“小批量”方法 \[29\]，即在每次迭代中不取一个实例，而是取一部分训练实例。
