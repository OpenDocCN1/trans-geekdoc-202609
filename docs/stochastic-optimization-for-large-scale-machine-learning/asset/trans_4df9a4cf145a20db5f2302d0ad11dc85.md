### 7.1.3 贡献

本章的贡献如下：

*   本章强调了随机方法从一阶方法向二阶方法的近期转变，并提出了一个开放问题：我们需要具有二次收敛率的随机二阶方法来解决大规模机器学习问题。

*   我们提出了一种新型的子采样信赖域不精确牛顿方法，称为 `STRON`，它是信赖域不精确牛顿方法的第一个随机变体。`STRON` 对梯度和黑塞矩阵计算使用渐进式子采样方案，以兼顾随机和全批模式的优势。`STRON` 可以达到二次收敛率，并回答了上述开放问题。

*   `STRON` 已使用现有的方差缩减技术进行扩展，以处理梯度计算中的噪声近似。扩展方法使用随机方差缩减梯度 (`SVRG`) 进行方差缩减，并结合梯度计算的静态批处理和黑塞矩阵计算的渐进式批处理。实证结果表明，这在大规模学习中并未按预期工作。

*   我们进一步扩展 `STRON`，并使用 `PCG` 而不是 `CG` 方法来不精确求解牛顿系统。我们使用单位矩阵和对角矩阵的加权平均作为预条件子。但即使这样，对于大规模学习也未能按预期工作。

*   最后，我们的实证实验证明了 `STRON` 在基准数据集上相对于现有技术的有效性。

## 7.2 文献综述

随机近似方法对于处理大规模学习问题非常有效，因为它们每次迭代的成本较低，例如，`SGD` \[113\]，但由于噪声近似，它们会导致收敛速度缓慢。为了解决噪声问题，已提出了许多技术，其中一些重要技术（如 \[34\] 所述）是：(a) 降低学习率 \[118\]，(b) 使用小批量 \[26\]，(c) 重要性采样 \[34\]，以及 (d) 方差缩减 \[115\]。方差缩减方法可以进一步分为三类：原始方法 \[115\]、对偶方法 \[120\] 和原始-对偶方法 \[149\]。方差缩减技术对于处理大规模学习问题很有效，因为它们每次迭代的复杂度低，类似于 `SGD`，并且具有快速的线性收敛，类似于 `GD`。这些技术结合了 `SGD` 和 `GD` 的优点，但对于这些一阶方法的随机变体，收敛仅限于线性速率，而二阶方法可以达到二次收敛率。

二阶方法利用曲率信息来引导步进方向趋向解，并表现出比一阶方法更快的收敛速度。但是，由于巨大的黑塞矩阵及其逆矩阵导致的巨大每次迭代成本，使得大规模问题的模型训练变慢。因此，已开发出某些技术来处理与黑塞矩阵相关的问题，例如，拟牛顿方法和不精确牛顿方法是处理牛顿方法巨大计算成本的两个主要方向。拟牛顿方法在每次迭代中近似黑塞矩阵，例如，`BFGS` \[42\] 及其有限内存变体，称为 `L-BFGS` \[[89](#bib.xhtml#refbib_89)\]，是拟牛顿类的示例，它们使用前一次迭代的梯度和参数值来近似黑塞逆矩阵。`L-BFGS` 仅使用前 `M` 次迭代的最近信息。另一方面，不精确牛顿方法试图近似求解牛顿系统，例如，`Newton-CG` \[124\]。

最近，已提出了几种 `BFGS` 和 `L-BFGS` 的随机变体来处理大规模问题。\[[117](#bib.xhtml#refbib_117)\] 提出了 `BFGS` 和 `L-BFGS` 的随机变体，用于在线设置，称为 `oBFGS`。\[[98](#bib.xhtml#refbib_98)\] 通过添加正则化扩展了 `oBFGS`，该正则化对近似黑塞矩阵的特征值施加上界，称为 `RES`（正则化随机 BFGS）。随机拟牛顿 (`SQN`) \[19\] 是 `L-BFGS` 的另一种随机变体，它在定期间隔而不是每次迭代时收集曲率信息。方差缩减随机牛顿 (`VITE`) \[[91](#bib.xhtml#refbib_91)\] 扩展了 `RES`，并提出对子采样梯度值使用方差缩减来求解光滑强凸问题。\[[69](#bib.xhtml#refbib_69)\] 提供了另一种使用 `SVRG`（称为 `SVRG-LBFGS`）进行方差缩减的随机 `L-BFGS` 方法。\[99\] 提出了随机 `L-BFGS` (`SLBFGS`)，使用 `SVRG` 进行方差缩减，并使用黑塞-向量积来近似梯度差异以计算黑塞近似，也称为 `SVRG-SQN`。`SVRG-LBFGS` 和 `SVRG-SQN` 在曲率近似方式上有所不同（即黑塞近似方式），前者在每个时代（外部迭代）中使用梯度差异一次收集曲率信息，而后者在内部迭代中定期间隔使用黑塞-向量积收集曲率信息。\[[9](#bib.xhtml#refbib_9)\] 将多批方案引入随机 `L-BFGS`，其中批样本与前一次迭代有一些重叠。\[11\] 提出了渐进式批处理、随机线搜索和稳定的牛顿更新用于 `L-BFGS`。\[10\] 研究了子采样大小的条件，以获得不同的收敛速率。

随机不精确牛顿方法也得到了广泛研究。\[18\] 提出了 `Newton-CG` 的随机变体，并结合 `L-BFGS` 方法。\[10\] 研究了子采样牛顿方法，并找出子采样大小和强制项（与残差条件一起使用的常数）的条件，以实现 `Newton-CG` 方法的线性收敛。\[8\] 研究了强制项和线搜索的效果，以找到 `Newton-CG` 方法的线性和超线性收敛。`Newton-SGI`（随机梯度迭代）是另一种近似求解线性系统的方法，并在 \[[3](#bib.xhtml#refbib_3)\] 中进行了研究。

信赖域牛顿 (`TRON`) 方法是求解大规模线性分类问题最有效的求解器之一 \[85\]。这是一种信赖域不精确牛顿方法，不使用任何子采样，并且存在于 `LIBLINEAR` 库 \[38\] 中。\[[52](#bib.xhtml#refbib_52)\] 通过改进信赖域半径值扩展了 `TRON`。\[[51](#bib.xhtml#refbib_51)\] 进一步扩展了 `TRON`，并使用预条件共轭梯度 (`PCG`)，该方法使用单位矩阵和对角矩阵的加权平均作为预条件子，来求解信赖域子问题。由于子采样是处理大规模问题的有效方法，因此在本章中，我们提出了一种信赖域不精确牛顿方法的随机变体，据我们所知，此前未得到研究。

## 7.3 信赖域不精确牛顿方法
