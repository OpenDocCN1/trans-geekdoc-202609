

*   提出了 SAAG-I 和 II 的新变体，分别称为 SAAG-III 和 SAAG-IV。与 SAAG-I 不同，对于 SAAG-III，起始点设置为上一时代迭代的平均值（第一个除外），$w\_{0}^{s + 1} = 1/m{\\sum\\limits\_{i = 1}^{m}w\_{i}^{s}}$，其中 `m` 是内部迭代次数。与 SAAG-II 不同，对于 SAAG-IV，起始点和快照点分别设置为上一时代的最后一次迭代和平均值（第一个除外），`w[0]^(s + 1) = w[m]^(s)` 和 `${\\widetilde{w}}\_{0}^{s} = 1/m{\\sum\\limits\_{i = 1}^{m}w\_{i}^{s}}$。

*   SAAG-I 和 II（包括 SAAG-III 和 IV）已扩展，通过引入平滑和非平滑情况的两种不同更新规则来解决具有非平滑正则化器的问题（详情请参阅 [第 4.3 节](#06chap_04.xhtml#sec4_3) 和 [4.4](#06chap_04.xhtml#sec4_4)）。

*   理论结果证明，SAAG-IV 在平滑性和强凸性的所有四种组合情况下均具有期望线性收敛性。

*   最后，实证结果证明了所提方法相对于最先进的方法（如 SVRG 和 VR-SGD）的有效性。

## 4.2 符号与相关工作

本节讨论本章中使用的符号和相关工作。

### 4.2.1 符号

训练数据集表示为 `{(*x*[1],*y*[1]),(*x*[2],*y*[2]),...,(*x*[*n*],*y*[*n*])}`，其中 `n` 是数据点的数量，`x[i] ∈ ℝ^(d)`，`d` 是特征的数量。`w` 表示参数向量，`λ[i]`，`i = 1, 2` 表示正则化参数。`∥ ⋅ ∥` 表示欧几里得范数，也称为 `l[2]-norm`，`∥ ⋅ ∥[1]` 表示 `l[1]-norm`。`L` 和 `μ` 分别用于表示问题的 `L-smoothness` 和 `μ-strong convexity`。`η[k]^(s)` 表示学习率，`s ∈ {1,2,...,S}` 表示时代编号，`S` 是时代总数。`b` 表示小批量大小，`k ∈ {1,2,...,m}` 表示内部迭代次数，即 `n = m*b`。在 `(x[i], y[i])` 处的损失函数值由分量函数 `f[i]` 表示。`w^(*) = arg min[w]F(w)`，`F(w^(*)` 是最优目标函数值，有时也表示为 `F^(*)`。

### 4.2.2 相关工作

为了求解平滑正则化器的问题 (4.1)，一种简单的方法是 GD，由 `[20]` 给出，对于强凸和平滑问题，它具有线性收敛性。对于非平滑正则化器，通常将近端步应用于 GD 步，称为 PGD 方法，对于非强凸问题，其收敛速率为 `O(1/k²)`。GD 和 PGD 的每次迭代复杂度为 `O(n*d)`，对于大规模学习问题来说非常大，导致模型训练缓慢。随机近似是应对这一挑战的一种方法。它最初由 Robbins 和 Monro `[113]` 引入，对于处理数据点数量非常多的问题非常有效，因为每次迭代只使用一个（或少数几个）数据点，如 SGD `[14]` 中所示。在 SGD 中，每次迭代比 GD 快 `n` 倍，因为它们的每次迭代复杂度分别为 `O(d)` 和 `O(n*d)`。由于梯度的方差，SGD 需要递减学习率，即 `k^(t*h)` 次迭代的 `η_k ∝ 1/√k`，因此即使对于强凸问题，其收敛速度也比 GD 慢，收敛速率为次线性 `O(1/T)` `[[110](#bib.xhtml#refbib_110)]`。有几种方法可以处理随机噪声，但其中最重要的是（如 `[[34](#bib.xhtml#refbib_34)]` 中所讨论）：(a) 使用小批量 `[142]`，(b) 递减学习率 `[118]`，(c) 方差减少 `[74]`，以及 (d) 重要性采样 `[34]`。

方差减少技术最初由 `[74]` 引入，称为 SAG，对于强凸和平滑问题，它像 GD 一样具有线性收敛性，并且在每次迭代中使用一个随机选择的数据点，类似于 SGD。SAG 兼具 GD 和 SGD 的优点，因为它像 GD 一样在强凸和平滑情况下具有线性收敛性，但其每次迭代复杂度与 SGD 相同。后来，提出了许多方差减少方法，如 SVRG `[63]`、SAGA `[35]`、S2GD `[71]`、SDCA `[120]`、SPDC `[[149](#bib.xhtml#refbib_149)]`、Katyusha `[4]`、Catalyst `[[87](#bib.xhtml#refbib_87)]`、SAAG-I, II `[23]`、VR-SGD `[39]` 等。这些方差减少方法可以使用恒定学习率，并可分为三类（如 `[39]` 中所讨论）：(a) 可应用于原始优化问题的原始方法，如 SAG、SAGA、SVRG 等，(b) 可应用于对偶问题的对偶方法，如 SDCA，以及 (c) 涉及原始和对偶变量的原始-对偶方法，如 SPDC 等。

在本章中，我们提出了 SAAG-I 和 II 的新变体，分别命名为 SAAG-III 和 SAAG-IV。与 SAAG-I 不同，对于 SAAG-III，起始点设置为上一时代迭代的平均值（第一个除外），$w\_{0}^{s + 1} = 1/m{\\sum\\limits\_{i = 1}^{m}w\_{i}^{s}}$，其中 `m` 是内部迭代次数。与 SAAG-II 不同，对于 SAAG-IV，起始点和快照点分别设置为上一时代的最后一次迭代和平均值（第一个除外），`w[0]^(s + 1) = w[m]^(s)` 和 `${\\widetilde{w}}\_{0}^{s} = 1/m{\\sum\\limits\_{i = 1}^{m}w\_{i}^{s}}$。`[23]` 提出了批量块优化框架（BBOF）来应对机器学习中的大数据（大规模学习）挑战，并附带两种方差减少方法 SAAG-I 和 II。BBOF 基于随机近似（SA）的最佳方法和坐标下降（CD）的最佳方法（另一种非常有效的方法，用于处理大规模学习问题，尤其是高维问题）。基于 SA 和 CD 方法的最佳思想也用于 `[133, 140, [146](#bib.xhtml#refbib_146), 152]`，`[146]` 将其称为双随机，因为在每次迭代中都会对数据点和坐标进行采样。观察到，对于 ERM，在实践中很难获得 BBOF 的优势，因为 CD 或 SGD 的结果比 BBOF 设置更快，因为 BBOF 在采样和更新坐标块时需要额外的计算。当更新一组坐标并移动到另一组时，部分梯度需要参数向量（`w`）和数据点（如逻辑回归）的点积。由于每次更新都会改变 `w`，因此每组更新都需要计算点积。另一方面，如果一次性更新所有坐标，如在 SGD 中，则只需计算一次点积。尽管类似高斯-赛德尔的参数更新有助于比 SGD 更快的收敛，但由于额外的计算负载，总体收益较小。此外，SAAG-I 和 II 已被提出用于 BBOF（小批量和块坐标）设置以及小批量（考虑所有坐标）设置。由于 BBOF 对 ERM 帮助不大，因此 SAAG-III 和 IV 仅针对小批量设置提出。SAAGs（I、II、III 和 IV）可以扩展到随机设置（每次迭代考虑一个数据点），但 SAAG-I 和 II 在随机设置下不稳定，而 SAAG-III 和 IV 在随机设置下无法击败现有方法。SAAGs 已扩展到处理平滑和非平滑正则化器，如我们使用了两种不同的更新规则，类似于 `[39]`（详情请参阅 [第 4.3 节](#06chap_04.xhtml#sec4_3)）。
