

### 3.1.2 批量块优化框架 (BBOF)

SA 方法通过在每次迭代中考虑一个或一些数据点来解决优化问题，这有助于降低迭代复杂度，但会影响解的精度。但是，通过在每次迭代中考虑合适的数据点小批量 [81] 或使用方差缩减技术，如 SAG [74]、SAGA [35]、S2GD [71] 和 SVRG [63] 等，可以改进解。另一方面，CD 通过考虑一个或一些特征/变量来构建缩减子问题，从而用于解决优化问题，这有助于降低迭代复杂度。在 CD 中，通过在学习算法的每次迭代中考虑合适的坐标/变量块，可以提升性能。现在，将小批量 SA 方法与块 CD 方法相结合，形成一个优化框架，该框架用于在学习算法的每次迭代中，对数据点小批量上的变量块求解子问题。该框架可称为批量块优化框架 (BBOF)，是一个高效且可扩展的框架，由于其低迭代复杂度，可用于解决大数据问题。BBOF 由 [Algorithm 7](#05chap_03.xhtml#algorithm_7) 给出。假设 {(`x`[1],`y`[1]),(`x`[2],`y`[2]),...,(`x`[`l`],`y`[`l`])} 是包含 `l` 个数据点的训练集，其中 `x`[`i`] ∈ ℝ^(`p`)，`y`[`i`] ∈ {−1,+1} 对所有 `i` 成立，`X` = (`x`[1],`x`[2],...`x`[`l`])，`Y` = (`y`[1],`y`[2],...`y`[`l`])。假设 `w` ∈ ℝ^(`p`) 被划分为 (`v`[1],`v`[2],...`v`[`s`])，即 `s` 个块，`v`[`j`] ∈ ℝ^(`p`[`j`])，满足 ${\\sum\\limits\_{j = 1}^{s}p\_{j}} = p$，且 `X` 被划分为 `m` 个小批量 (`B`[1],`B`[2],...`B`[`m`])，每个大小为 |`B`[`i`]|，满足 $\\left. \\left. \\sum\\limits\_{i = 1}^{m} \\right|B\_{i} \\middle| = l \\right.$。

![](Images/algo7.jpg)

BBOF 将给定的训练集划分为 `m` 个小批量，将特征划分为 `s` 个特征块，并运行 `n` 个 epoch，每个 epoch 遍历所有数据点，即遍历所有批次，并为每个小批量覆盖所有特征块，以避免反复读取数据的开销。它不放回地随机选择一个数据点小批量 `B`[`i`]，并循环选择一个特征块 `v`[`j`]。可以尝试其他采样方案来在此框架中对小批量和特征块进行采样。但对于特征块，使用循环采样 (CS)，因为否则难以使用稀疏实现。此外，如 [[152](#bib.xhtml#refbib_152)] 所指出，像 SAG、SAGA、SAAG-I 等使用随机平均方案（即保留前几次迭代的完整梯度）的方法，不能与块和小批量的随机采样一起使用。通过将选定的坐标块作为变量，固定其余坐标的值，并在选定的数据点小批量上，按如下方式构建子问题：

$$
\\begin{array}{l} \\begin{array}{l} {\\underset{w\_{v\_{j}}}{min}\\quad\\frac{1}{\\left| B\_{i} \\right|}{\\sum\\limits\_{h \\in B\_{i}}L\_{h}}(w\_{v\_{j}},w\_{/v\_{j}}),\quad j = 1,2,...,s,\\, i = 1,2,...,m,} \\\\ \\end{array} \\\\ \\end{array}
$$

(3.8)

其中 `w`[`v`[`j`]] 表示坐标块 `v`[`j`]，`w`[/`v`[`j`]] 表示排除 `v`[`j`] 的坐标。小批量和块的大小以这种方式选择，以允许在实验所用计算机上高效处理的迭代复杂度。求解子问题后，选定的坐标块被更新，但其他坐标保持不变。这运行预定数量的 epoch `n`，但可以尝试其他退出标准，具体取决于求解子问题所用的方法以及需求。在此之前，少数研究者如 [[133](#bib.xhtml#refbib_133), 152] 和 [140] 曾使用梯度/近端梯度方法研究过小批量和块坐标的概念，但我们将小批量和块坐标设置作为一个独立于任何方法的优化框架 (BBOF)，作为解决大数据问题的高效且可扩展的框架。BBOF 是一个可调框架，可以通过更改 `m`（小批量数量）和 `s`（块数量）的值调整为八种不同的设置，例如，在 BBOF 中使用梯度下降法作为求解器，可以调整以下不同方法：

1. i) `m` = 1，即一个批次包含所有数据点，`s` = 1，即一个块包含所有坐标，则方法为 GD。

2. ii) `m` = `l`，即一个批次仅包含一个数据点，`s` = 1，则方法为 SGD。

3. iii) `m` = 1，`s` = `p`，即一个块仅包含一个坐标，则方法为 CGD。

4. iv) `m` = `B`，1 < `B` < `l`，`s` = 1，则方法为小批量 SGD。

5. v) `m` = `B`，1 < `B` < `l`，`s` = `p`，则方法为小批量 CGD。

6. vi) `m` = 1，`s` = `v`，1 < `v` < `p`，则方法为 BCD（块坐标梯度下降）。

7. vii) `m` = `l`，`s` = `v`，1 < `v` < `p`，则方法为随机 BCD。

8. viii) `m` = `B`，1 < `B` < `l`，`s` = `v`，1 < `v` < `p`，则方法为小批量块坐标 GD (MBGD)。

### 3.1.3 简要文献综述

随机近似 (SA) 方法 [113, 67] 与 GD 方法结合得到 SGD 方法 [148]，由于梯度的噪声近似，SGD 方法在梯度值中引入了方差。可以通过使用合适的小批量 [81] 而不是一个数据点，或使用一些方差缩减技术，如 SAG [74]、SAGA [35]、SVRG [63] 和 S2GD [71] 等，来降低这种方差，这些方法与 GD 具有相同的收敛性，但迭代复杂度几乎等于 SGD 方法。CD 方法与块坐标下降 (BCD) 方法在文献中已被广泛研究，例如 [100, 137, 122] 等。BCD 与小批量 SA 方法结合 GD/近端 GD (PGD) 方法的组合最近在 MRBCD [152]、ORBCD [133] 和 BSG [140] 中被研究，这些是 BBOF 与 GD/PGD 方法的特定情况，用于解决不同问题。MRBCD 和 ORBCD 具有相似的思想和理论结果。BSG 求解凸和非凸问题，而 MRBCD 仅求解凸问题。两种方法都使用方差缩减技术。MRBCD 和 BSG 使用 SVRG 的扩展来在小批量和块坐标设置中进行方差缩减。本章将 BBOF 与 GD 方法结合使用，即将 GD 作为求解器的小批量和块坐标设置，并提出两种新的方差缩减方法（参见 [第 3.2 节](#05chap_03.xhtml#sec3_2)），此外还将 SAG、SAGA 和 S2GD 扩展到此设置。

### 3.1.4 贡献

本章的贡献总结如下：

* 小批量和块坐标设置，即随机近似 (SA) 和坐标下降 (CD) 方法的组合，已被提出为一种高效且可扩展的优化框架，即批量块优化框架 (BBOF)，独立于任何求解器，用于解决大数据问题。BBOF 是一个可调框架，可以通过更改 `m`（小批量数量）和 `s`（块数量）的值生成八种不同的方法（参见 [子节 3.1.2](#05chap_03.xhtml#sec3_1_2)）。

* 提出了两种新方法，即 SAAG-I 和 SAAG-II（参见 [第 3.2 节](#05chap_03.xhtml#sec3_2)），作为在 GD 方法下的小批量和块坐标设置中的方差缩减方法，用于求解强凸和光滑问题。SAAGs 也可用于小批量随机梯度设置。理论分析证明了 SAAG-II 方法具有线性收敛性。

* 将方差缩减方法 SAG、SAGA、SVRG 和 S2GD 扩展到小批量和块坐标设置，并与所提方法进行了比较。
