
where `w`, `γ` are parameters, `A` is `l × n` matrix representing `l` data points in `n`-dimensional real space `ℝ^(n)`, according to the membership of each point `A[i]` in the class `A+` or `A−` as specified by a given `l × l` diagonal matrix `D` with `+1` or `−1` along its diagonal. `ν > 0`, `1` = unit vector, `y` represents errors. The solution of this problem can be written directly in terms of problem data.

The planes `x^(T)w − γ = ±1` are not boundary planes anymore but can be thought as proximal planes around which the points of each class are clustered and which are pushed as far apart as possible by the term `(w^(T)w + γ²)` in the objective function. The decision function for Proximal SVM `sign(w^(T)x − γ)`. Lagrangian with coefficient `u` is given by

$$
\begin{array}{l} 
\begin{array}{l} 
{L(w,\gamma,y,u) = \frac{\nu}{2}\| y\|^{2} + \frac{1}{2}\left\| \left\lbrack \begin{array}{l} w \\\\ \gamma \\\\ \end{array} \right\rbrack \right\|^{2} - u^{T}\left( {D\left( {Aw - \mathbf{1}\gamma} \right) + y - \mathbf{1}} \right)} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.24)

Solving using Karush–Kuhn–Tucker (KKT) conditions gives

$$
\begin{array}{l} 
{w = A^{T}Du,\quad\gamma = - \mathbf{1}^{T}Du,\quad y = \frac{u}{\nu}} \\\\ 
\end{array}
$$

$$
\begin{array}{l} 
\begin{array}{l} 
{u = \left( {\frac{I}{\nu} + D\left( {AA^{T} + \mathbf{1}\mathbf{1}^{T}} \right)D} \right)^{- 1}\mathbf{1} = \left( {\frac{I}{\nu} + HH^{T}} \right)^{- 1}\mathbf{1}} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.25)

where `H = D[A − 1]`. Equation (2.25) gives the explicit solution to eq. (2.23).

### 2.3.9 Crammer Singer SVM (2002)

[33], proposed a multi-class SVM (CSSVM) which unlike OVR [132] and OVO [72] trains a single SVM classifier and evaluates `m` (number of classes) decision functions to classify a test data point. The problem formulations are:

$$
\begin{array}{l} 
\begin{array}{ll} 
& {\underset{w_{k},\xi_{i}}{\min}\quad\frac{1}{2}{\sum\limits_{k = 1}^{m}w_{k}^{T}}w_{k} + C{\sum\limits_{i = 1}^{l}\xi_{i}}} \\\\ 
{\text{s.t.}} & {w_{y_{i}}^{T}x_{i} - w_{k}^{T}x_{i} \geq e_{i}^{k} - \xi_{i},\quad i = 1,...,l,} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.26)

$$
\begin{array}{l} 
{\text{where}\quad e_{i}^{k} \equiv 1 - \delta_{y_{i},k}\text{~and~}\delta_{y_{i},k} = \left\{ \begin{array}{l} {1\quad\text{if}\quad y_{i} = k} \\\\ {0\quad\text{if}\quad y_{i} \neq k} \\\\ \end{array}~ \right.} \\\\ 
\end{array}
$$

Decision function is

$$
\begin{array}{l} 
\begin{array}{l} 
{\underset{k = 1,2,...,m}{argmax}\quad w_{k}^{T}x.} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.27)

The main difference between Crammer Singer SVM (CSSVM) and other problems is that CSSVM does not need to explicitly write down constraints `ξ[i] ≥ 0` as when `y[i] = k`, `e[i]^(k) = 0`, so eq. (2.26) becomes `0 ≥ 0 − ξ[i]` which is exactly `ξ[i] ≥ 0`. It contains only `ξ[i]`, `i = 1, 2, ..., l`, `l` slack variables, instead of using `ξ[i]^(k)` as the gap between each pair of decision planes. Dual problem of CSSVM is:

$$
\begin{array}{l} 
\begin{array}{ll} 
& {\underset{\alpha}{\min}\quad\frac{1}{2}{\sum\limits_{k = 1}^{m}{\| w_{k}\|^{2}}} + {\sum\limits_{i = 1}^{l}{\sum\limits_{k = 1}^{m}e_{i}^{k}}}\alpha_{i}^{k}} \\\\ 
{\text{s.t.}} & {{\sum\limits_{k = 1}^{m}\alpha_{i}^{k}} = 0,\quad i = 1,...,l,} \\\\ 
& {\alpha_{i}^{k} \leq C_{y_{i}}^{k},\quad i = 1,..,l,\ k = 1,...,m,} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.28)

where $w_{k} = {\sum\limits_{i = 1}^{l}\alpha_{i}^{k}}x_{i},\forall k$ and $C_{y_{i}}^{k} = \left\{ \begin{array}{l} {C\quad\text{if}\quad y_{i} = k} \\\\ {0\quad\text{if}\quad y_{i} \neq k} \\\\ \end{array}~ \right.$.

### 2.3.10 Eν-SVM (2003)

The `ν`-SVM[116] for classification (`ν`-SVC) has proposed a different formulation for solving SVM in which a new parameter `ν` has been introduced. `ν` gives an upper bound on the number of support vectors. `ν` also removes `C` which is a measure of trade-off between the margin size and training errors. This is difficult to choose `C` priori. The value of `ν` cannot always take all possible values between 0 and 1 which limits the range of possible solutions. Either because the training set is non-separable or because the classes are unbalanced. So, `ν`-SVM [116] is extended to `Eν`-SVM [109], where a new problem is constructed using `ν` that helps to control the margin, errors and the support vectors. In `Eν`-SVM, the value of `ν` cannot take full range of values from 0 to 1. For `l` training points, the value of `ν` can be defined as:

$$
\begin{array}{l} 
\begin{array}{l} 
{\nu_{*} = \underset{C\rightarrow\infty}{lim}\quad\frac{1}{lC}{\sum\limits_{i = 1}^{l}\alpha_{i}^{C}},\quad\nu_{*} = \underset{C\rightarrow 0}{lim}\quad\frac{1}{lC}{\sum\limits_{i = 1}^{l}\alpha_{i}^{C}}} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.29)

where `ν[*]` > 0 and `ν[*]` ≤ 1. Primal problem is given below:

$$
\begin{array}{l} 
\begin{array}{ll} 
& {\underset{\rho,w,b,\xi_{i}}{\min}\quad - l\nu\rho + {\sum\limits_{i = 1}^{l}\xi_{i}}} \\\\ 
{\text{s.t.}} & {y_{i}\left( {x_{i}^{T}w + b} \right) \geq \rho - \xi_{i},\,\,\,\xi_{i} \geq 0,\,\,\forall i} \\\\ 
& {\frac{1}{2}\| w\|^{2} = 1} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.30)

Dual problem is:

$$
\begin{array}{l} 
\begin{array}{l} 
{\underset{\alpha_{i},\lambda}{\max}\quad L_{D} = - \frac{1}{2\lambda}{\sum\limits_{i = 1}^{l}{\sum\limits_{j = 1}^{l}y_{i}}}y_{j}\alpha_{i}\alpha_{j}x_{i}^{T}x_{j} - \lambda} \\\\ 
{\text{s.t.}\quad\nu = - \frac{1}{l}{\sum\limits_{i = 1}^{l}\alpha_{i}},\quad{\sum\limits_{i = 1}^{l}\alpha_{i}}y_{i} = 0,\quad 0 \leq \alpha_{i} \leq 1,\,\,\forall i} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.31)

$$
\begin{array}{l} 
\begin{array}{l} 
{\lambda = + \sqrt{\frac{1}{2}{\sum\limits_{i = 1}^{l}{\sum\limits_{j = 1}^{l}y_{i}}}y_{j}\alpha_{i}\alpha_{j}x_{i}^{T}xj}.} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.32)

### 2.3.11 Twin SVM (2007)

Twin SVM (TWSVM, [56]) is an extension of PSVM [45] via generalized eigen values. As the name suggests, TWSVM is a binary classifier that solves two related small sized SVM problems and gives two non-parallel planes. A new test point is classified as per the closest plane. TWSVM is faster than standard SVM and gives good generalization results [56]. It helps in automatically discovering two-dimensional projections of the data. Each of the non-parallel planes is closer to one of class and is as far as possible from the other class. TWSVM is comprised of two quadratic programming problems in which the objective function of one problem is represented by the data points of one class and constraints are represented by the data points of other class. This leads to two smaller SVM problems given below.

$$
\begin{array}{l} 
\begin{array}{ll} 
\text{(TWSVM~1)} & {\underset{w^{(1)},b^{(1)},q}{\min}\,\,\frac{1}{2}\left( {Aw^{(1)} + \mathbf{1}_{1}b^{(1)}} \right)^{T}\left( {Aw^{(1)} + \mathbf{1}_{1}b^{(1)}} \right) + C_{1}\mathbf{1}_{2}^{T}q} \\\\ 
{\text{s.t.}} & {- \left( {Bw^{(1)} + \mathbf{1}_{2}b^{(1)}} \right) + q \geq \mathbf{1}_{2},\quad q \geq 0} \\\\ 
\text{(TWSVM~2)} & {\underset{w^{(2)},b^{(2)},q}{\min}\,\,\frac{1}{2}\left( {Bw^{(2)} + \mathbf{1}_{2}b^{(2)}} \right)^{T}\left( {Bw^{(2)} + \mathbf{1}_{2}b^{(2)}} \right) + C_{2}\mathbf{1}_{1}^{T}q} \\\\ 
{\text{s.t.}} & {\left( {Aw^{(2)} + \mathbf{1}_{1}b^{(2)}} \right) + q \geq \mathbf{1}_{1},\quad q \geq 0} \\\\ 
\end{array} \\\\ 
\end{array}
$$

(2.33)
