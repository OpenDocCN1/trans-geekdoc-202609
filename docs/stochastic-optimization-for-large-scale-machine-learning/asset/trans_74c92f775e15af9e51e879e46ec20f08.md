

Linear SVM 在高维数据应用中非常高效。虽然其在测试集上的准确率与非线性 SVM 接近，但对于此类应用，其训练速度要快得多。例如，文档分类应用具有高维输入空间，无需向输入空间添加更多特征，因为这对性能影响不大。因此，线性 SVM 的测试准确率与非线性 SVM 接近（参见，\[[46](#bib.xhtml#refbib_46)\]），但与此同时，由于计算复杂度的差异，线性 SVM 的训练速度远快于非线性 SVM。

L2-正则化软间隔 SVM 是最常用的 SVM 表述形式，如下所示。SVM 的不同问题表述将在 [第 2.3 节](#03chap_02.xhtml#sec2_3) 中详细讨论。

```
$$\begin{array}{l} \begin{array}{l} {\underset{w}{\min}\, F(w) = \frac{1}{2}\| w\|^{2} + C{\sum\limits_{i = 1}^{l}{\max}}{(0,1 - y_{i}w^{T}x_{i})}^{2},} \\ \end{array} \\ \end{array}$$
```

(1.5)

其中 `C` 是正则化系数。

### 1.3.2  逻辑回归

这是一种基于逻辑损失函数（也称为 Sigmoid 函数）的二元分类技术，其输出值在 0 到 1 之间。这是一个平滑且强凸（通过添加 `l[2]` 正则化）问题，具有良好的理论特性。其可表示如下：

```
$$\begin{array}{l} {\underset{w}{\min}\, F(w) = \frac{1}{l}{\sum\limits_{i = 1}^{l}{\log}}\left( {1 + \exp\left( {- y_{i}w^{T}x_{i}} \right)} \right) + \frac{\lambda}{2}\| w\|^{2}.} \\ \end{array}$$
```

(1.6)

### 1.3.3  一阶和二阶方法

优化问题可以使用解析方法和数值方法求解。解析方法适用于求解简单问题，具有直接计算精确解的公式。另一方面，数值方法用于迭代且近似地求解复杂问题。由于机器学习问题是数据密集型的复杂问题，因此使用数值方法来求解。

求解问题 (7.2) 的一般迭代方法可写为：

```
$$\begin{array}{l} {w_{k + 1} = w_{k} - \alpha_{k}s_{k},} \\ \end{array}$$
```

(1.7)

其中 `k` 是迭代次数，`α[k]` 是学习率（也称为步长），`s[k]` 是步长方向。

#### 1.3.3.1  一阶方法

当 `s[k] = ∇F(w[k])` 时，该方法称为梯度下降（GD）。GD 及其仅涉及一阶导数的修改方法称为一阶方法。我们提出了 SAAGs，它们是方差缩减技术，用于处理由梯度近似引入的噪声。这些是一阶方法，将在 [第二部分](#04part_02.xhtml) 中讨论。

#### 1.3.3.2  二阶方法

当 `s[k] = ∇²F(w[k])^(−1)∇F(w[k])` 时，该方法称为牛顿法。牛顿法及其涉及二阶导数的修改方法称为二阶方法。这些方法使用曲率信息来引导步长方向朝向解。我们提出了 MBN 和 STRON 方法，它们基于二阶信息。这些是子采样牛顿方法，将在 [第三部分](#08part_03.xhtml) 中讨论。

## 1.4  随机逼近方法

随机逼近（SA）\[[113](#bib.xhtml#refbib_113)\] 是一种迭代优化方法，用于求解无法直接求解但可使用近似方法求解的优化问题。在机器学习问题中，在学习算法的每次迭代中使用所有数据点在计算上非常昂贵，在某些情况下可能不可行。因此，使用 SA，它通过考虑一个数据点或数据点的小批量，使每次迭代与数据点数量（`l`）无关，即，不遍历所有数据点，而是在每次迭代中只处理一个数据点或数据点的小批量，这对于较大的 `l` 值会产生巨大的计算差异。同样，剩余数据点可以在其他迭代中以小批量形式使用。因此，SA 是一种计算效率非常高的优化方法，用于处理大规模问题。毫无疑问，这可能会影响学习算法的收敛性，这可以通过使用更大的小批量和其他技术（如方差缩减，例如 SAAGs \[23, [28](#bib.xhtml#refbib_28)\]）来补偿。

## 1.5  坐标下降方法

坐标下降（CD）\[[137](#bib.xhtml#refbib_137)\] 是一种递归方法，通过沿坐标方向或坐标超平面进行近似最小化来求解优化问题，即，它递归地求解仅包含一个或几个变量的小子问题。与 SA 使迭代复杂度与 `l` 无关类似，CD 通过将一个特征或特征块作为变量，固定其余特征并求解由此形成的缩减子问题，使迭代复杂度与特征数量（`n`）无关。然后，选择新的一个特征或特征块作为变量，固定其余特征，并求解得到的子问题。此过程重复，直到覆盖所有特征的所有子问题都求解完毕，然后重复整个过程直到收敛。因此，CD 是解决具有大量特征的大规模问题的良好方法。

本部分包含两章，介绍使用二阶方法求解大规模学习问题的技术：

[**第 6 章**](#09chap_06.xhtml)：本章将随机逼近和坐标下降方法的优点与二阶方法相结合，提出了小批量块坐标牛顿法（MBN）。
