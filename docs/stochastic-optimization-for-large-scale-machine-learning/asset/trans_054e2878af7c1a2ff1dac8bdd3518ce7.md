

$$\\begin{array}{l} {\\underset{w}{\\min}\\quad f(w) = \\frac{1}{2}\\| w\\|^{2} + C\\sum\\limits\_{i = 1}^{l}{\\lbrack\\max(0,1 - y\_{i}w^{T}x\_{i})\\rbrack}^{2}} \\\\ \\end{array}$$  

(2.63)

令 `f(w)` 的二次模型为：

$$\\begin{array}{l} {m(s) = \\nabla f{(w)}^{T}s + \\frac{1}{2}s^{T}\\nabla^{2}f(w)s} \\\\ \\end{array}$$  

(2.64)

TRON 使用信赖区域半径 △ 来近似 `m(s)`：

$$\\begin{array}{l} {\\underset{\\| s\\| \\leq \\bigtriangleup}{\\min}\\quad m(s)} \\\\ \\end{array}$$  

(2.65)

它使用以下比率来更新信赖区域半径：

$$\\begin{array}{l} {\\mu = \\frac{f(w + s) - f(w)}{m(s)}} \\\\ \\end{array}$$  

(2.66)

TRON 在每次迭代中使用结合共轭梯度法和信赖区域法的修正牛顿法。TRON 的算法如 [算法 5](#03chap_02.xhtml#algorithm_5) 所示。

## 2.5 比较研究

在本节中，我们讨论了不同 SVM 的比较研究。结果从文献和我们的实验研究两方面进行了讨论。

### 2.5.1 文献中的结果

根据文献，`LIBLINEAR` \[38\]、`Pegasos` \[118\] 和 `SVM^(perf)`\[[62](#bib.xhtml#refbib_62)\] 是最先进的求解器，其中 `LIBLINEAR` 是最有效 \[38\]、最流行且使用最广泛的。`LIBLINEAR` 使用 `TRON`（信赖区域牛顿法，\[85\]）来求解 L2 正则化 L2 损失原始 SVM，使用 `PCD`（原始坐标下降法，\[22\]）来求解 L1 正则化 L2 损失原始 SVM，并使用 `DCD`（对偶坐标下降法，\[53\]）算法来求解 L2 正则化 L1- 和 L2-损失对偶 SVM。`SVM^(perf)` 使用切割平面技术来求解 L2 正则化 L1 损失原始 SVM，而 `Pegasos` 使用一种在梯度下降步骤和投影步骤之间交替的算法来求解 L2 正则化 L1 损失原始 SVM。这些最先进求解器的比较已在 \[38\]（请参阅最新版本）的 [第 4 节](#11part_04.xhtml) 中的 Fig. 1 中给出，该图比较了不同线性求解器的训练时间与测试准确率。最近，\[101\] 提出了一种 `SVM-ALM`（增广拉格朗日乘数）算法，用于求解具有线性计算成本的 L2 正则化 L1-、L2- 和 L*p* 范数损失原始问题，以应对大数据挑战。`SVM-ALM` 比 `LIBLINEAR` 更快，实验结果在 \[101\] 的第 4 节中的表 1 和表 2 中报告。`SVM-ALM` 使用梯度下降法来寻找步长方向，并使用精确线搜索来寻找步长。`SVM-ALM` 算法的精妙之处在于利用增广拉格朗日乘数将 L*p* 损失原始 SVM 问题转换为一种非常容易求解的形式。这强调了这样一个观点：不仅是一种方法，还有许多其他因素（请参阅 [第 2.4 节](#03chap_02.xhtml#sec2_4) 的开头以了解此类因素）使算法高效。

### 2.5.2 实验研究中的结果

#### 2.5.2.1 实验设置和实现细节

实验在两个数据集上进行，即 `mushroom` 和 `rcv1`，在单节点 MacBook Air（8 GB 1600 MHz DDR3，1.6 GHz Intel Core i5，256 SSD）上。每个数据集被随机分为 80% 和 20%，分别用于训练数据和测试数据。实验比较了七种著名的 SVM 变体，分别是软 SVM、平滑 SVM、最小二乘 SVM、双 SVM、E*ν*-SVM、近点 SVM 和封顶 SVM，使用两个标准：测试准确率与时代（一个时代指一次遍历数据集）以及测试准确率与训练时间（以秒为单位）。为了公平比较，SVM 的原始公式使用了相同的算法结构/框架来求解，仅在问题公式和相应的梯度值上有所不同。训练算法使用小批量 `SGD`（随机梯度下降）方法 \[[148](#bib.xhtml#refbib_148)\] 来确定步长方向，步长大小递减，由 `d[0]/(1 + d[0]C^k)` 确定，用于第 `k^(th)` 个时代，初始步长为 `d[0]`，正则化参数为 `C`。训练算法使用五个随机选择的数据点的小批量大小。每个 SVM 的问题公式使用平方松弛变量，即平方误差，以便公平比较，例如，在软 SVM 中使用 L2 损失而不是 L1 损失。此外，正则化参数（`C`）对所有 C-SVM 都设置为 0.1，包括双 SVM 的两个子问题，参数 `ν` 对 `ν`-SVM 设置为 0.06（mushroom）和 0.006（rcv1.binary）。对于平滑 SVM，平滑参数（`α`）设置为五，对于封顶 L*p* 范数 SVM，`p` 设置为二，封顶值 `ϵ` 设置为一。由于双 SVM 有两个子问题，因此双 SVM 的训练时间和时代分别取子问题所用时间的总和和所用时代的总和。

#### 2.5.2.2 结果与讨论

首先，应当注意，不同 SVM 的比较研究存在几个挑战，即：(a) 不同 SVM 的范围和应用领域不同，例如，`SloppySVM` 适用于数据标记不严谨的应用；跨导 SVM 专门为文本分类问题提出；`Fuzzy SVM` 和 `CappedSVM` 适用于数据包含噪声和异常值的应用；结构化 SVM 适用于输出标签为结构化（如字符串）的应用；`MVSVM` 和 `MTSVM` 分别用于多视图学习和多任务学习等；(b) 一个对另一个的直接改进，例如，软 SVM 是对硬 SVM 的改进，`E*ν*-SVM` 是对 `ν`-SVM 的改进等；(c) 二元和多类数据，例如，软 SVM、最小二乘 SVM 和平滑 SVM 主要是二元分类器，已通过一对一、一对其余等方法扩展到多类数据；以及 (d) 并非每个问题都可以用每个求解器求解。关于求解特定 SVM 问题公式的一个有趣观点是，作为优化问题，每个问题都可以用多种方法求解。在为特定 SVM 选择求解器时，不同因素起着作用，如 [第 2.4 节](#03chap_02.xhtml#sec2_4) 开头所讨论。因此，仅对著名的二元原始 SVM 变体使用小批量 `SGD` 方法进行了实验研究。关于多类 SVM 的比较研究，请参阅 \[[55](#bib.xhtml#refbib_55)\] 第 V 节中的表 V.2 至 V.4。另一个有趣的观点是，从实验结果来看，我们不能概括某个特定的 SVM 是最好的。这符合“无免费午餐”定理，以及在求解 SVM 时必须考虑多种权衡和因素（参见 [第 2.4 节](#03chap_02.xhtml#sec2_4)）的观点。

## 2.6 当前挑战与研究方向

### 2.6.1 大数据挑战

随着技术的进步，数据已采取“大数据”的形式，大数据中“大”的含义在不断变化，并将继续变化。早期，由于计算资源有限和当时可用数据有限，几百个实例被视为大数据集。后来，大数据集的含义变为数千个实例。现在，大数据集指数百万个实例。为了利用这些海量数据，需要高效的机器学习算法来处理这些大数据集。此外，这些算法还需要具备可扩展性，以应对数据集规模的不断增加。因此，如今，`SVC`（与机器学习共享）面临的最大挑战是开发高效且可扩展的学习算法来处理大数据。
