

*Example:* 假设训练数据集由 *S* = {1,2,3,....,20} 给出，要选择的小批量大小为 *m* = 5，则可以使用不同的采样技术从 *S* 中选择/抽取四个小批量，如下所示：使用有放回随机采样选择的小批量为 – *B*[1] = {15,2,20,2,1}，*B*[2] = {3,10,20,6,1}，*B*[3] = {5,9,19,2,7} 和 *B*[4] = {1,11,18,3,16}；使用无放回随机采样选择的小批量为 – *B*[1] = {15,2,20,11,6}，*B*[2] = {3,10,8,14,1}，*B*[3] = {16,4,17,7,19} 和 *B*[4] = {9,5,12,18,13}；使用循环采样选择的小批量为 – *B*[1] = {1,2,3,4,5}，*B*[2] = {6,7,8,9,10}，*B*[3] = {11,12,13,14,15} 和 *B*[4] = {16,17,18,19,20}；以及使用系统采样选择的小批量为 – *B*[1] = {16,17,18,19,20}，*B*[2] = {1,2,3,4,5}，*B*[3] = {6,7,8,9,10} 和 *B*[4] = {11,12,13,14,15}。从上述示例中可以清楚地看出，在有放回随机采样中，点在小批量内部或小批量之间被随机选择并允许重复。CS 是最简单且非概率性的采样，按顺序选择点。对于系统采样，首先随机选择第一个点，然后其余点依次选择，有放回采样和无放回采样的思想可以在小批量之间应用，但仅在小批量内部演示了无放回采样。

值得注意的是，对于 RS，小批量的数据点分散在磁盘的不同扇区，因此每个数据点都需要自己的寻道时间和延迟时间。由于数据是按块读取而不是按内容读取，因此每个数据点可能位于不同的块中，因此也需要自己的传输时间。对于 CS，一个小批量只需要一次寻道时间，因为它从第一个数据点开始并一直移动到末尾；对于 SS，一个小批量只需要一次寻道时间，因为只有第一个元素是随机确定的，但小批量的其余点存储在连续的内存位置。因此，CS 的寻道时间最少，RS 最多。CS 和 SS 的传输时间几乎相等，但都少于 RS，因为在 RS 中，通常每个数据点需要单独的传输时间，但对于其他情况，它需要与适合数据点小批量所需的块数量相同的传输时间。因此，访问一个小批量数据点的总访问时间在 CS 中最小，在 RS 中最大。观察到，对于给定的时代数，RS 相比于 CS 给出了最佳解，但 RS 的访问时间最多。另一方面，对于 CS，在给定的时代数下访问时间最少，但收敛最慢。因此，在减少数据访问时间和学习算法收敛之间存在权衡。SS 平衡了这种权衡，因为 SS 兼具两种技术的优点，像 CS 一样，数据点存储在连续的内存位置，像 RS 一样，它具有一定的随机性，因为它随机抽取第一个点。总体而言，使用 CS 和 SS 的方法比使用 RS 的方法收敛更快，如在 [第 5.4 节](#07chap_05.xhtml#sec5_4) 中讨论。

### 5.2.2 使用系统采样的学习

用于解决大规模问题的带有系统采样的通用学习算法由 [算法 14](#07chap_05.xhtml#algorithm_14) 给出。可以通过在算法 14 的第 14 步中使用相应的采样技术来选择小批量，从而为循环和随机采样技术获得类似的学习算法。算法从初始解开始。它使用系统采样将数据集划分为 *m* 个小批量以选择小批量。在内层循环中，它取一个小批量 *B*[*j*]，在 *B*[*j*] 上制定一个子问题并求解由此形成的子问题。此过程重复，直到所有 *m* 个小批量上的所有子问题都求解完毕。然后，此求解过程针对给定的时代数重复，或者算法中可以使用其他停止准则。在算法 14 的第 14 步，可以使用不同的求解器来更新解，例如，SAG（随机平均梯度）\[115\]、SAGA \[35\]、SVRG（随机方差降低梯度）\[63\]、SAAG-II（随机平均调整梯度）\[23\] 和 MBSGD（小批量随机梯度下降）\[23, [32](#bib.xhtml#refbib_32)\]。

## 5.4 实验

### 5.4.1 实验设置

实验使用了五种方法，即 SAG、SAGA、SAAG-II、SVRG 和 MBSGD，以及八个基准数据集（详情见表 1.1）。每种方法都运行了两个大小为 500 和 1000 个数据点的小批量，以及两种寻找步长的技术，即恒定步长方法和回溯线搜索（LS）方法，用于预定义的时代数。恒定步长方法使用 Lipschitz 常数 *L*，并对所有方法将步长取为 1/*L*。回溯线搜索仅使用选定的小批量数据点近似执行，因为在整个数据集上执行回溯线搜索可能会因耗费大量时间而损害大规模问题的学习算法收敛。对于一个数据集，一种方法运行 12 次（3（采样技术）× 2（小批量）× 2（寻找步长的技术）），对于一个数据集，三种采样技术在 20 种不同设置下进行比较（5（方法）× 2（小批量）× 2（寻找步长的技术））。因此，使用了 160（20 × 8（数据集））个设置来比较三种采样技术的结果。由于训练时间取决于执行实验的机器配置，因此需要注意的是，所有实验均在 MacBook Air（8GB 1600 MHz DDR3，256GB SSD，1.6 GHz Intel Core i5）上进行。
