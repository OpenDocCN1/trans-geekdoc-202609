## 2.2 文献综述

支持向量机（SVMs，\[12, 31\]）是机器学习中的一种分类技术。SVM 中使用的概念，如超平面、最优间隔和核等，已有数十年的历史，但在当前形式中，SVM 的发展始于 \[12》，即 1992 年在 COLT 上发表的《最优间隔分类器的训练算法》。这种 SVM 公式也被称为“硬间隔 SVM”。\[31\] 改进了硬间隔 SVM。他们考虑了异常值和噪声，并通过引入松弛变量来放宽间隔以误分类某些数据点。这导致了“软间隔 SVM”。直到这时，SVM 被用作二分类器，当 \[132\] 提出使用一对其余（OVR）技术的多类 SVM 时。\[[61](#bib.xhtml#refbib_61)\] 提出了用于文本分类的传导 SVM。\[[127](#bib.xhtml#refbib_127)\] 提出了 SVM 的最小二乘版本。后来，\[72\] 提出了另一种使用一对一（OVO）技术的多类 SVM，但 OVR 和 OVO 都基于二分类问题。\[[135](#bib.xhtml#refbib_135)\] 提出了第一个多类 SVM（WWSVM），它求解单个 SVM 问题，并且不基于多个二分类问题。\[107\] 提出了用于多类分类问题的有向无环图 SVM（DAGSVM），它在求解 SVM 问题时与 OVO 技术类似，但它使用高效的根有向无环二叉树来查找测试数据的标签。\[[116](#bib.xhtml#refbib_116)\] 提出了一种新的 *ν*-SVM，它移除了参数 *C* 并引入了参数 *ν*，该参数大约给出支持向量的比例。\[[45](#bib.xhtml#refbib_45)\] 提出了近端 SVM（PSVM），它使用数据点到近端平面的接近程度来对数据点进行分类。PSVM 用近端平面替换了标准 SVM 的边界平面，并使用近端平面进行分类，而不是使用分离超平面。\[[77](#bib.xhtml#refbib_77)\] 引入了平滑 SVM，它处理了标准 SVM 的不可微问题。\[[95](#bib.xhtml#refbib_95)\] 提出了拉格朗日 SVM。\[33\] 提出了另一种多类分类 SVM，与 OVO 和 OVR 技术不同，它求解单个 SVM 问题。后来 \[[86](#bib.xhtml#refbib_86)\] 提出了一种称为模糊 SVM（FSVM）的新公式，该公式进一步由 \[[2](#bib.xhtml#refbib_2)\] 和 \[[1](#bib.xhtml#refbib_1)\] 扩展。模糊 SVM 将数据点对每个类别的模糊隶属度引入，并使用这些点的贡献来查找分离平面。模糊 SVM 在减少异常值和噪声的影响方面非常有用。\[[109](#bib.xhtml#refbib_109)\] 将 *ν*-SVM \[116\] 扩展到 *E**ν* -SVM，并帮助控制间隔、错误以及相应的支持向量。\[[57](#bib.xhtml#refbib_57)\] 结合了 FSVM \[86\] 和 PSVM \[45\] 的思想，并提出了模糊近端 SVM（FPSVM）。在这里，模糊隶属度被分配给数据点，并且根据点到两个平行平面的接近程度对点进行分类，这两个平行平面尽可能彼此远离。\[[131](#bib.xhtml#refbib_131)\] 提出了结构化 SVM，它将多类 SVM（即 WWSVM 和 CSSVM）推广到一种新的公式，该公式具有结构化输出，如序列、字符串、图、标记树或格等。\[[37](#bib.xhtml#refbib_37)\] 扩展了标准 SVM，即单任务学习 SVM，并提出了一种用于多任务学习的新二进制 SVM。\[[49](#bib.xhtml#refbib_49)\] 提出了一种称为级联 SVM 的并行 SVM，它部署分治策略来求解 SVM 问题。级联 SVM 将数据集划分为子集，并在每个子集上并行训练多个 SVM。\[[96](#bib.xhtml#refbib_96)\] 提出了具有两个非平行超平面的广义特征值近端 SVM（GEPSVM），数据点根据其到两个非平行平面之一的接近程度进行分类。\[[40](#bib.xhtml#refbib_40)\] 将多视角学习的思想扩展到 SVM，并提出了多视角 SVM。\[[56](#bib.xhtml#refbib_56)\] 将近端 SVM 扩展到双 SVM，它求解两个小规模 SVM 问题并给出两个非平行超平面。\[[126](#bib.xhtml#refbib_126)\] 提出了 SloppySVM，它可以从标记松散的数据中学习。\[[102](#bib.xhtml#refbib_102)\] 提出了 CappedSVM，使用基于截断 *l*[*p*]-范数的损失函数，以应对数据异常值的挑战。

```
\begin{array}{l} \left. x\_{1}^{T}x\_{2}\mapsto K\left( {x\_{1},x\_{2}} \\right), \right. \\\\ \end{array}
```

其中 `x[1]` 和 `x[2]` 表示数据点，`K` 表示核函数。

## 2.3 问题公式

### 2.3.1 硬间隔 SVM（1992）

虽然超平面、最优间隔和核等概念已使用数十年，但 \[12] 是第一个以当前形式公式化 SVM 的。这种 SVM 是一个二分类器，只能处理线性可分的数据应用，任何噪声或异常值的存在都会强烈影响间隔。它不允许误分类错误，这就是为什么它被称为硬间隔 SVM。硬间隔 SVM 由图 1.1 表示。
