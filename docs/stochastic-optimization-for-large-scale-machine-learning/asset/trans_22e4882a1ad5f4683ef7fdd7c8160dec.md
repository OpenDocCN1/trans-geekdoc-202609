

STRON 由 [算法 16](#10chap_07.xhtml#algorithm_16) 提出。它随机选择子样本 `S[k]` 和 `X[k]` 用于第 *k* 次迭代（外层迭代）。`X[k]` 和 `S[k]` 分别用于计算梯度和海森值。然后它使用 CG 求解器（内层迭代）求解信任区域子问题，该求解器在计算海森-向量乘积时使用子样本海森。当残差条件（与 (7.17) 相同）满足，或达到最大 #CG 迭代次数，或达到信任区域边界时，CG 停止。实际减少量与预测减少量的比率计算方式类似于 (7.12)，但使用子样本函数，并用于按 (7.13) 给出的方式更新参数。然后信任区域半径 `△[k]` 按 (7.14) 给出的方式根据 `ρ[k]` 更新，这些步骤在给定的迭代次数内重复，或直到收敛。

STRON 使用渐进式子采样，即动态子采样来计算函数、梯度和海森值，并近似求解牛顿系统。它对处理大规模问题很有效，因为它使用子采样并近似求解子问题，而无需形成海森矩阵，只使用海森-向量乘积。因此，它处理了与牛顿方法相关的复杂性问题。

### 7.4.1 复杂度

信任区域不精确牛顿（TRON）方法的复杂度取决于函数、梯度和 CG 子问题求解器。这主要由 CG 子问题求解器主导，其复杂度为 `O(n*l)` × #CG 迭代次数，对于稀疏数据，则为 `O(#n*nz)` × #CG 迭代次数，其中 #`n*nz` 是数据集中非零值的数量。对于子采样信任区域不精确牛顿（STRON）方法，每次迭代的复杂度为 `O(n|S[k]|)` × #CG 迭代次数，对于稀疏数据，则为 `O(#n*nz[S[k]])` × #CG 迭代次数，其中 #`n*nz[S[k]]` 是子样本 `S[k]` 中非零值的数量。由于 TRON 和 STRON 所需的 #CG 迭代次数差别不大，因此 STRON 在初始迭代中的每次迭代复杂度小于 TRON，但后来由于渐进式子采样（即当 `|S[k]|=N` 时）变得与 TRON 相等。

### 7.4.2 分析

STRON 方法使用渐进式子采样，假设最终小批量大小等于整个数据集，即对于某个 $k \\geq \\overline{k} > 0$ 的值，STRON 变为 TRON。因此，我们可以遵循 TRON 给出的理论结果，而 TRON 本身又引用了 \[83\] 的结果。对于 $k \\geq \\overline{k}$，根据 `η[k]^(^′)` 的值，我们得到不同的收敛性：如果 `η[k]^(^′)` < 1，则 STRON Q-线性收敛；如果 `η[k]^(^′)` → 0 当 *k*→∞，则 STRON 具有 Q-超线性收敛；当 `η[k]^(^′)` ≤ `κ[0]∥∇F(w[k])∥` 对于 `κ[0]` > 0 时，STRON 以二次速率收敛。

## 7.5 实验结果

在本节中，我们讨论实验设置和结果[⁷](#fn7)

**TRON** \[51\]: 这是一种不带任何子采样的信任区域不精确牛顿方法。它使用预条件化 CG 方法求解信任区域子问题，并且存在于 LIBLINEAR 库 \[38\] 的当前版本中。

**STRON**: 这是所提出的带有渐进式子采样技术的随机信任区域不精确牛顿方法，用于梯度和海森计算。它使用 CG 方法求解信任区域子问题。

**STRON-PCG**: 这是 STRON 的扩展，使用 PCG 求解信任区域子问题，如 [子节 7.6.1](#10chap_07.xhtml#sec7_6_1) 中讨论。

**STRON-SVRG**: 这是 STRON 的另一个扩展，使用方差减少来进行子样本梯度计算，如 [子节 7.6.2](#10chap_07.xhtml#sec7_6_2) 中讨论。 **Newton-CG** \[18\]: 这是一种随机不精确牛顿方法，使用 CG 方法求解子问题。它使用类似于 STRON 的渐进式子采样。

**SVRG-SQN** \[99\]: 这是一种带有方差减少的随机 L-BFGS 方法，用于梯度计算。

**SVRG-LBFGS** \[69\]: 这是另一种带有方差减少的随机 L-BFGS 方法。它与 SVRG-SQN 方法在海森信息采样的方法上有所不同。

### 7.5.1 实验设置

数据集已分为 80% 和 20%，分别用于训练和测试数据集，以绘制收敛图，并使用 5 折交叉验证来呈现 [表 7.1](#10chap_07.xhtml#t7_1) 中的结果。我们对所有方法都使用了 `λ = 1/l`，因为它通常能给出良好的结果，同时有助于减少可调超参数的数量。#CG 迭代次数已设置为足够大的值 25，因为所有不精确牛顿方法都使用 5–10 次迭代，很少超过 20 次迭代。渐进式批处理方案对所有数据集（除了 ijcnn，它使用数据集的 10%）都使用初始批量大小为 1%，并且子样本大小对所有数据集（除了 covtype，它使用指数速率）都线性增加。此外，我们设置速率，使得子样本大小在 5 个时代内等于数据集大小，因为一般来说二阶方法在 4–5 个时代内达到解区域，并在 8–10 个时代内收敛。为了简单起见并避免额外采样，我们对海森和梯度计算使用相同的子样本，即 `S[k] = X[k]`。拟牛顿方法（SVRG-SQN 和 SVRG-LBFGS）使用 10% 的小批量大小和随机回溯线搜索来找到步长，并且对梯度和海森子采样使用相同大小的小批量。拟牛顿方法中使用了 `M = 5` 的内存，并将 `L = 5` 作为 SVRG-SQN 方法中海森逆近似的更新频率。所有算法都使用类似的退出标准，即梯度值的减少，我们在 `w[0]` 处计算梯度（`∥g[0]∥`），并运行算法直到 `∥g[k]∥ ≤ ϵ∥g[0]∥`，其中 `∥g[k]∥` 是第 k 次迭代处的梯度值，`ϵ` 是给定的容忍水平。此外，所有方法都在 C++[⁸](#fn8) 中实现。
