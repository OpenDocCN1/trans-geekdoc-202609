

## 4. 问题缩减策略

在优化不同变量（参数）时，观察到有些变量不变或保持为零。此类变量可以在优化过程中暂时排除，直到其余变量达到近似最优值。这被称为缩减策略 \[38, [66](#bib.xhtml#refbib_66)\]。这样一来，中间迭代过程中需要最小化的变量数量减少了。这使得训练速度更快。

因此，挑战在于设计新方法，并在问题求解器中使用现有方法，以使学习更快、更准确。

## 2.6.2.4 平台/框架

平台/框架代表支持 SVM 问题执行的环境。通过利用此环境，可以进一步改进 SVM 问题。从图 2.9 可以清楚地看出，对于大规模问题，速度和准确性也取决于计算框架/平台。以下是使用平台/框架的一些示例 \[[84](#bib.xhtml#refbib_84)\]：

### 1. 并行和分布式计算

借助并行计算 \[[136](#bib.xhtml#refbib_136)\]，某些任务可以在系统的多个核心或计算机集群上并行执行。这使得训练过程更快，但显然，不同处理单元之间的通信在这里是一个瓶颈。

### 2. 原位内存计算

读取和写入数据所需的时间比数据处理更长。因此，对于需要多阶段处理的问题，与其在每个阶段后将数据读写到磁盘，不如在内存中进行连续计算，这样在处理非常大的数据问题时可以加快进程。Apache Spark \[84\] 使用原位内存计算的概念，使其比 Hadoop 快大约 100 倍。

因此，当今的挑战是利用现有框架使算法更高效。

## 2.6.3 研究方向

根据图 2.9，有四个改进领域可以帮助我们解决大数据问题。在这些领域中，线性 SVM 分类（与机器学习共享）的当前研究方向是：

### 2.6.3.1 随机近似算法

过去五年中，该领域进行了大量研究（关于随机近似方法，请参阅 [小节 2.6.2.3](#03chap_02.xhtml#sec2_6_2_3)）。研究人员提出了大量使用随机近似（SA）的算法，特别是使用一阶方法，如梯度下降（GD）方法 \[[120](#bib.xhtml#refbib_120), 115\] 作为求解器。此外，SA 还与二阶方法（如拟牛顿法 \[[19](#bib.xhtml#refbib_19)\]）一起使用。SA 与 GD 构成随机梯度下降（SGD）方法，并导致梯度值中的方差问题。因此，围绕 SGD 的研究集中在减少方差（例如，\[23\]）。另一方面，围绕 SA 与二阶方法的研究集中在将曲率信息纳入方法以实现更快的收敛。这种方法适合解决包含大量数据点的问题。

### 2.6.3.2 坐标下降算法

这是一种分解方法（关于分解方法，请参阅 [小节 2.6.2.3](#03chap_02.xhtml#sec2_6_2_3)），用于处理大数据问题。过去几年中，该领域也取得了良好的工作成果。坐标下降（CD）方法通过将一个参数作为变量，其余参数作为常数来构建子问题，该子问题规模更小，因此更容易求解。已提出大量使用 CD 方法 \[137\] 及其变体（如块坐标下降 \[90\]）的算法，并结合一阶和二阶方法。这通常应用于高维原始或对偶问题。

### 2.6.3.3 近端算法

近端算法（PA）\[104\] 适用于非光滑、受约束、大规模或分布式凸问题，最近，它们在高维优化问题上取得了良好效果。使用 PA 时，主要操作是计算近端算子（关于近端算子，请参阅 [小节 2.4.14](#03chap_02.xhtml#sec2_4_14)），其中我们求解一个小优化问题。当前研究涉及将 PA 用于一阶方法（如近端梯度方法 \[28\]）、二阶方法（如拟牛顿方法 \[[7](#bib.xhtml#refbib_7)\]）及其加速版本 \[[147](#bib.xhtml#refbib_147)\]。

### 2.6.3.4 并行/分布式算法

并行和分布式算法 \[84\] 利用计算资源来处理大数据问题（如系统的 CPU 核心和计算机集群），并可以处理数据集极大且无法装入单台机器的问题。这些算法的主要瓶颈是通信开销。研究人员长期致力于此，但该领域仍有很大的发展空间。这似乎是机器学习中处理大数据问题的最热门领域，在未来，研究可能会朝这个方向发展，因为数据集的规模不断增加，最终可能超出单台机器的能力。

### 2.6.3.5 混合算法

混合算法结合了上述两种或多种方法。很明显，如果我们想要开发高效且可扩展的算法来解决大数据问题，所有这些方法都必须结合起来。该方向已经有大量研究，例如，随机近似和坐标下降方法的组合已在 \[23\] 中得到研究。

## 2.7 结论

线性 SVM 是机器学习中一个非常好的工具，因为它比非线性核 SVM 快得多，同时为高维问题（如文档分类）提供相似的准确性。研究人员提出了各种 SVM 问题公式，以及求解器和优化策略来求解它们。其中一些是对其他方法的改进，例如，“软 SVM”是对“硬 SVM”的改进。一些 SVM 有不同的应用场景，例如，SloppySVM 适用于数据标记松散的应用；Transductive SVM 专门针对文本分类问题提出；Fuzzy SVM 和 CappedSVM 适用于数据包含噪声和异常值的应用；Structured SVM 适用于输出标签为结构化（如字符串）的应用；MVSVM 和 MTSVM 分别用于多视图学习和多任务学习，等等。一些 SVM 是二元分类器，需要使用一对一和一对其余等技术来处理多类问题，例如，Soft SVM、Fuzzy SVM 和 Twin SVM 等。一些 SVM 可以使用直接公式处理多类数据，例如 Crammer Singer SVM 和 Weston Watkins SVM。在所有 SVM 中，软间隔 SVM 或 Soft SVM 是最流行且最广泛使用的 SVM 公式，因为训练速度快且泛化效果更好。这就是为什么当人们提到 SVM 时，指的就是 Soft SVM。根据文献，SVM-ALM 是最快的原始求解器，LIBLINEAR 是最流行且最广泛使用的工具，它提供原始和对偶两种求解器，并使用 TRON、PCD（原始坐标下降）和 DCD（对偶坐标下降）方法。
