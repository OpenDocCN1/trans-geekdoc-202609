# C# code explained

+   1. Generate a Datatable and bind datasource of Datalist to get the input of the matrix elements.
+   2. Store the Value of the datalist into the datatable (dtMain).
+   3. Open a for loop for the steps.
+   4. Find the Min value and coordinates of that min value.
+   5. Show them in a Label and add the Label to Div to show the step output.
+   6. Now reconstruct the matrix with new elements. Merge the element's corresponding coordinates of min value. Compute the mean of all the corresponding distances.
+   7. Now bind the datatable to the gridview and add the gridview to Div to show the step output.
+   8. Loops execute as per size of the matrix.
+   9. The output of each step will be available on the aspx page.
