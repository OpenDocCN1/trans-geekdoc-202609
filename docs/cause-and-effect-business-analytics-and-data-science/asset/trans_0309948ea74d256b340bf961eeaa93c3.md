### 8.5.3 随机规划 (SP)

`Stochastic Programming` (`SP`) 直接通过概率分布处理任何不确定性，而非像 `RO` 中采用悲观情景，或像 `MVO` 中管理方差。由于其应用范围广泛且理论强劲且已确立，`SP` 本身是优化理论和运筹学的一个关键子领域，并且已有数十年的历史——最早的贡献之一来自 [丹齐格 (1955)](#chapter8.xhtml#ref8_8)。欲进一步学习，请参阅 [Wallace 和 Ziemba (2005)](#chapter8.xhtml#ref8_36)、[Cornuejols 和 Tutuncu (2007)](#chapter8.xhtml#ref8_7)、[Zenios (2007)](#chapter8.xhtml#ref8_38) 或 [King 和 Wallace (2012)](#chapter8.xhtml#ref8_20) 以获得实用的介绍和应用，以及 [Birge 和 Louveaux (1997)](#chapter8.xhtml#ref8_4) 或 [Shapiro 等 (2014)](#chapter8.xhtml#ref8_30) 以满足数学倾向更强者。我们将讨论与提升优化最相关且实用的来自 `SP` 的技术。

再次考虑 [`第 8.2.2 节`](#chapter8.xhtml#sec8_2_2) 中的 `model (8.7)`，可以施加一个额外的概率约束，以“保证”在一定概率下实现给定结果（称为机会约束优化，是 `SP` 的一个分支）：

$$Maximize~{\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m}{{~ \\bigtriangleup \\hat{p}}\_{cj~}x\_{cj}}}}$$  

(8.13)

Page 239约束条件：

1.  $P\\left( {{\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m}{{~ \\bigtriangleup p}\_{cj~}x\_{cj}}}}~ \\geq a} \\right) \\geq b,$ 概率约束 (0≤*b*≤1)，
2.  ${\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m~}{{c\_{j}x}\_{cj~} \\leq Budget,}}}~预算约束，$
3.  ${\\sum\\limits\_{j = 1}^{m}{x\_{cj~} \\leq N\_{c},~for~c = 1,\\ldots,C,~}}~集群规模约束，~and$
4.  *x*[*c**j* ] ≥ 0, *c* = 1, …, *C*; *j* = 1, …, *m*.

 alternatively, rather than maximizing the estimated (mean) number of incremental responders, one may be interested in maximizing the probability of achieving a given number of incremental responders:

$$Maximize~P\\left( {{\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m}{{~ \\bigtriangleup p}\_{cj~}x\_{cj}}}}~ \\geq ~z\_{0}} \\right)$$  

(8.14)

subject to (as before):

1.  ${\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m~}{{c\_{j}x}\_{cj~} \\leq Budget,}}}~预算约束，$
2.  ${\\sum\\limits\_{j = 1}^{m}{x\_{cj~} \\leq N\_{c},~for~c = 1,\\ldots,C,~}}~集群规模约束，~and$
3.  *x*[*c**j* ] ≥ 0, *c* = 1, …, *C*; *j* = 1, …, *m*.

Furthermore, one may even change the objective function to another probability-related function, such as an *α*th 百分位数 (also known as Value-at-Risk or `VaR`

$$Maximize~the~\\alpha~th~percentile~of~{\\sum\\limits\_{c = 1}^{C}{\\sum\\limits\_{j = 1}^{m}{{~ \\bigtriangleup p}\_{cj~}x\_{cj}}}},$$  

(8.15)

while keeping the same set of constraints in `Eqn. (8.14)`.

Page 240表面上，`model (8.15)` 看起来与鲁棒优化 (`RO`) `model (8.11)` 相似。事实上，它们是不同的，因为 `model (8.11)` 忽略了提升值   △ *p*[*c**j* ] 之间的依赖结构（相关性）。例如，如果两个提升值非常负相关，它们各自达到各自下限（例如，第5百分位数）的同时发生的几率非常低。因此，`model (8.11)` 比 `model (8.15)` 更保守，因为后者考虑了提升值的依赖结构。

Note that, unlike `LP` problems for deterministic optimization or even quadratic programming problems for `MVO`, `models`, `Eqns. (8.13)–(8.15)` may not satisfy the convexity property (see [`附录 8.1`](#chapter8.xhtml#app8_1)) and thus cannot guarantee global optima. Nevertheless, good heuristics are available to solve them, attempting to achieve some “good enough” solutions even though global optima are not guaranteed. See [`附录 8.2`](#chapter8.xhtml#app8_2) for A Brief Introduction to Simulation Optimization, a relatively simple technique employed in [`例 8.3c`](#chapter8.xhtml#sec8_5_3_1).
