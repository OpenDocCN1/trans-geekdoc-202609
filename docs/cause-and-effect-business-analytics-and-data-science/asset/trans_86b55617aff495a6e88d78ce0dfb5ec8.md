
## 非平稳性和协整

非平稳性的一个常见解决方案是剔除序列中的时间趋势，通常通过取差分来实现（“一阶积分”）（[Enders 2010](#chapter10.xhtml#ref10_2)）。现在，我们不再对 `y[t]` 回归 `x[t]`，而是对 `y[t]−y[t−1]` 回归 `x[t]−x[t−1]`。当对俄亥俄海狸和爱尔兰人均实际GDP进行此操作时，任何相关性都消失了！

在此背景下，检验时间序列是否平稳是有帮助的。这通常使用增广 Dickey-Fuller 检验来完成，尽管有时也会应用其他检验（[Enders 2010](#chapter10.xhtml#ref10_2)）。该检验的最简单版本包括估计如下形式的方程

`ΔX[t] = φ[0] + φ[1]t + φ[2]X[t−1] + ε[t]`

(10.8)

如果 `φ[2]` 的估计值显著为负，则拒绝“单位根”假设的存在，意味着可以合理地认为序列 `X[t]` 是平稳的。对我们示例中的四个变量加上消费者价格指数进行平稳性检验，给出的结果如[表10.3](#chapter10.xhtml#tbl10_3)所示。看起来汽油价格和人均实际GDP并不平稳第297页但仍显示出随时间推移的某种系统性运动，正如（当然！）消费者价格指数一样。

我们的变量中有一部分是非平稳的，这表明估计 Engle-Granger 误差修正模型可能是有用的。有两个步骤：
1. 步骤1：估计水平形式的线性方程（如式(10.1)）。如果方程在统计上显著且残差平稳，我们就有一个协整向量，它给出了变量之间的长期关系（在我们的案例中，是长期弹性）。
2. 步骤2：以差分形式估计关系，并纳入步骤1的滞后残差（通常还包括被解释变量的滞后值）。其最简单形式如下：

`Δln(Y[t]) = a + b Δln(Y[t−1]) + c Δln(X[t−1]) + d e[t]`

(10.9)

该方程还应包括平稳的变量，因为它们可能对结果变量产生短期影响，即使它们不能对其产生永久性影响。系数 `d` 的估计值衡量结果变量向其长期水平调整的速度。

我们示例中此估计的结果显示在[表10.2](#chapter10.xhtml#tbl10_2)的第(12)列中。误差修正系数为 -0.68，因此如果我们偏离长期需求曲线，汽油消费将调整回其长期水平，约有三分之二的调整在第一年内完成。

在遵循这些程序时，我们假设了因果方向，并认为模型是完整的。这就是判断发挥作用的地方，需要一个模型，或至少一个清晰的结构。在[图10.2](#chapter10.xhtml#fig10_2)中，我们创建了一个包含节点和边的路径图，以努力捕捉相关的关系。我们专注于汽油价格与汽油销售数量之间的关系。很可能原油价格会影响汽油价格和柴油燃料价格，因为原油构成了生产汽油第298页和柴油燃料成本的绝大部分。为了阻断这种后门效应，我们需要在回归中纳入柴油燃料的价格；否则，汽油价格对汽油销售的衡量效应也会带上柴油价格的一些效应，而我们希望改变其中一个而不改变另一个——也就是说，“使”汽油价格发生变化。

当然，我们的模型很可能过于简单。其他变量可能会影响汽油购买量，例如汽车价格、技术变化（如电动汽车的开发），或其他冲击如飓风。如果这些与汽油价格完全无关，那么我们仍可能识别出汽油价格对销售的影响，但完全独立的情况很少见。我们在[第5章](#chapter5.xhtml)更全面地讨论了贝叶斯网络。

还有严重的内生性问题。虽然逻辑上汽油价格越高，需求量预计会减少，但也可能存在汽油需求的外生增加会为供应商提供提高价格的机会或需要——实际上逆转了假设的因果方向，使我们沿着供给曲线向上移动。关于在成功识别需求和供给曲线所需的条件，尤其是在广阔或部分非竞争性市场中，存在大量文献（[MacKay and Miller 2024](#chapter10.xhtml#ref10_6)）。

## 10.4 格兰杰因果

考虑一个变量，例如黄金价格，我们随时间拥有其数据。我们想知道石油价格是否有助于驱动（“导致”）黄金价格。例如，如果更高的石油价格是不确定性的信号，进而推动投资者持有黄金，就会发生这种情况。敏捷的资产管理者会对其感兴趣，因为他们可能会因此对石油价格上涨做出反应而买入黄金。

遵循 Clive Granger（1969）的开创性论文，我们首先将黄金价格（`y[t]`）建模为主要由其先前值驱动。线性自回归形式给出

$$y_{t} = a_{0} + {\sum\limits_{i = 1}^{n}{a_{i}y_{t - i}}} + \varepsilon_{t}$$

(10.10)

其中我们允许 `n` 个滞后价格值影响当前价格，且 `ε[t]` 是均值为零的随机误差。

现在将式(10.10)中的模型扩展以包含石油价格（`x[t]`）的滞后值，如下所示：

$$y_{t} = a_{0} + {\sum\limits_{i = 1}^{n}{a_{i}y_{t - i}}} + {\sum\limits_{i = 1}^{n}{b_{i}x_{t - 1}}} + \varepsilon_{t}$$

(10.11)

第299页如果 `x[t−1]` 项中至少有一些在统计上显著不同于零，则该方程比式(10.10)更能拟合数据，我们拒绝石油价格不“格兰杰导致”黄金价格的原假设。

这里的直觉是，如果 `x` 的过去值包含有助于预测 `y` 的信息，那么我们可能认为 `x` 在某种意义上“导致” `y`。使用滞后值在这里很重要，因为假设“原因不能在结果之后”。

该模型捕捉到先后效应的影响，但这不一定与有意义的因果相同。一些作者更喜欢将其视为“预测因果”，当 `x` 的滞后值有助于预测 `y` 时；更常见的是，我们说在这种情况下，`x`“格兰杰导致”`y`。

我们通常感兴趣的不仅是 `x` 是否格兰杰导致 `y`，而且 `y` 是否格兰杰导致 `x`。如果两者都存在，我们就有双向格兰杰因果。对于两个变量，我们有一个二维向量自回归（`VAR`）模型（[Enders 2010](#chapter10.xhtml#ref10_2)），它看起来像这样：
