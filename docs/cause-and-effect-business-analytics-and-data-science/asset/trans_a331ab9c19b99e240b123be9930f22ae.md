
这种情况下，存在随机分配且处理为二元的，通常被称为 A/B 测试，尤其是在商业应用中。如果我们有多个待测试的处理，则需要进行 A/B/n 测试（比较两个以上处理）或进行多变量测试（有关进一步细节，请参阅[第7.2.5章](#chapter7.xhtml#sec7_2_5)）。虽然我们迄今为止假设结果 `Y[i]` 是一个连续变量，例如支出，但同样的原理也适用于结果为二元的情况——例如，结果是个人是否报名新的信用卡或选择留在公司。在这种情况下，相关的回归通常为 `logit` 或 `probit`。关于 A/B 测试在实践中如何运作的一些示例，见于[框3.1](#chapter3.xhtml#box3_1)。

### 3.3.1 分层随机化

简单随机抽样很少见，因为它通常效率低下。例如，如果我们试图衡量针对女性的化妆品宣传活动的影响，抽样男性可能没有意义。但我们可能有兴趣了解不同年龄组的女性对该活动的反应是否不同——例如，20–30岁或30–40岁的人。这些构成 *strata* 或区块，并且在这些分层内，个体被随机选入干预仍然至关重要。这被称为分层随机化或随机区组设计。通常，我们故意对某些分层进行过度抽样，以便在该区块中拥有足够的观察值；通过使用样本权重，我们可以在分析阶段对过度或不足抽样进行调整。

形式上，我们现在有了 *conditional exogeneity of program placement*。如果我们愿意假设控制变量（即 `X[i]`）以线性方式运作，仍然可以通过估计回归模型来估计处理的冲击。假设对于接受处理的 `n[T]` 人，

`Y[i]^(T) = α^(T) + X[i]β^(T) + v[i]^(T), i = 1, …, n[T]`

(3.6)

对于未接受处理（即对照组）的 `n[C]` 人

`Y[i]^(C) = α^(C) + X[i]β^(C) + v[i]^(C), i = 1, …, n[C]`.

(3.7)

这两个组的数据可以合并以创建 `Y[i]`，它是观察到的潜在结果，给定为

`Y[i] = T[i]Y[i]^(T) + (1−T[i])Y[i]^(C)`.

(3.8)

其中，如通常一样，`T[i] = 1` 表示个体接受处理，0 表示未接受

使用 `n` (= `n[T]+n[C]`) 个观测值的合并数据，我们可以估计形式为“切换”回归

`Y[i] = α^(C) + (α^(T)−α^(C))T[i] + X[i]β^(C) + X[i](β^(T)−β^(C))T[i] + ε[i], i = 1, …, n`,

(3.9)

误差项由 `ε[i] = T[i](v[i]^(T)−v[i]^(C)) + v[i]^(C)` 给出。误差项捕捉到对连续结果变量 `Y[i]` 的任何“潜在”（未观察到或遗漏）影响。如果误差与谁接受处理 (`T[i]`) 或其他控制变量 (`X[i]`) 无关，则方程 (3.9) 可以简单地使用普通最小二乘法估计。观测 i 的处理效应由下式给出

`G[i]^(ATE) = Pr(T=1)E(Y[i]^(T)−Y[i]^(C)|T[i]=1) + Pr(T=0)E(Y[i]^(T)−Y[i]^(C)|T[i]=0)`

`= E(Y[i]^(T)−Y[i]^(C)) = (α^(T)−α^(C)) + X[i](β^(T)−β^(C)) + E(v[i]^(T)−v[i]^(C))`

将此在所有观测值上平均得到 ATE，即

$$\\left. G^{ATE} = \\left( \\alpha \\right.^{T} - \\alpha^{C} \\right) + \\overset{-}{X}\\left( \\beta^{T} - \\beta^{C} \\right).$$

(3.10)

如果我们进一步假设（大胆地）`β^(T) = β^(C)`，则简化为常见的影响模型，因此 `G^(ATE) = α^(T) − α^(C)`。

分层随机化是提升建模的基础（[第6至9章](#chapter9.xhtml)），它首先衡量因果处理效应，将其与个体的特征（如年龄、性别或教育）联系起来，然后利用这些结果来识别和定位处理的良好前景。

### 3.3.2 随机化：黄金标准？

随机化通常被认为是对科学实验的黄金标准。2019年诺贝尔经济学奖授予了三位研究人员（Abhijit Banerjee、Esther Duflo 和 Michael Kremer），他们推广了将随机对照试验应用于识别发展中国家（如驱虫、微型信贷、性教育以及激励教师出勤）等处理的冲击。在2020年，用于保护免受COVID-19侵害的疫苗首先必须使用随机对照试验进行测试，然后才被认为足够安全供公众使用。

随机化在实践中可能很困难，有时也不道德。[Haughton 和 Kelly (2014)](#chapter3.xhtml#ref3_8) 想要评估翻转混合教学法是否能产生更好的基础统计教学成果，以考试成绩衡量。最强大的方法是随机分配学生到混合和非混合班级。但这在实践中不可行，因为学生必须安排课程以配合其他课程。这也将被认为不可接受，因为强迫学生注册他们不想上的班级。同样，对吸烟影响的研究如果将受试者分配为吸烟或不吸烟，显然是不可行且不道德的。

即使随机分配是可能的，也可能存在选择性接受和非随机流失。考虑一名民意调查员想要测试注册选民对州长候选人的态度的情况。选民名单可能不准确；一些选民可能没有（已知）电话号码；大多数人不会回应民意调查电话——例如，据 Pew Research Center 调查，94% 的样本未回应 ([Kennedy 和 Hartig 2019](#chapter3.xhtml#ref3_17))；而且回应的人可能不会去投票。这些问题之所以存在，是因为在每个阶段都可能存在偏差。例如，没有电话的人可能很贫穷或担心保护隐私；回应电话的人可能年纪较大或更孤独；投票的人可能受教育程度更高。偏差的程度未知，因此从随机样本开始的民调结果可能无法使用。例如在2020年秋季，大多数民调高估了乔·拜登预计获得的选票数量，并低估了唐纳德·特朗普获得的选票数量 ([Keeter 2021](#chapter3.xhtml#ref3_16))。

RCTs 还有其他问题。它们可能很昂贵；可能难以获得足够大的样本；可能存在泄漏（例如，如果针对纽约的电视广告活动被许多其他地区的人看到）；而且通常存在重要问题，例如企业在经济衰退时期应如何反应，它们无法解决。

## 3.4 准实验方法

当随机实验不可行时，可以做什么？重申一下，需要解决的问题是选择偏差。

例如，假设我们开发了一种新型大豆品种，并希望在美国中西部几个县的小规模测试市场。销售团队已确定了一些有希望的测试区域，但这可能会导致非随机项目安置，这将以难以预测的方式影响我们的结果（由于 *unobserved area heterogeneity*）。产品推出后，可能会出现项目参与的自我选择，因此更具动态性或信息更充分的个人会首先报名。这种 *unobserved individual heterogeneity* 使评估更强力推广大豆的效果变得困难，因为其他农民可能不会那么快地站出来。
