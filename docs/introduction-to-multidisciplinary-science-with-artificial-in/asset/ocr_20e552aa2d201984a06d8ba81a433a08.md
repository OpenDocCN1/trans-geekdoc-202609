In the multipartite setting, separability and entanglement are defined in a similar way, using product tensors.

# The Schmidt decomposition.

Let us assume that H = H1 ⊗ H2 is a Hilbert space of a m × n-vectors made of complex values, H1 a Hilbert space of a m-vectors made of complex values, and H2 Hilbert space of a n-vectors made of complex values. If we have orthonormal sets of bases {(ai)}i=1r of H1 and {(bi)}i=1 of H2, a unit vector |v> of H can be written v as follows:

```
|v> = ∑_{i=1}^r γ_i |a_i> ⊗ |b_i> , (4.94)
```

where γ_i are strictly positive real scalars and ∑_{i=1}^r γ_i^2 = 1. A pure state |v> is called separable (or sometimes a product state) if it can be reduced to

```
|v> = |a> ⊗ |b> , (4.95)
```

where |a> pertains to H1 and |b> pertains to H2. Otherwise, |v> is called entangled. Another words, state |v> is separable iff its Schmidt coefficients, {γ1, γ2, γ3, ...}, are {1,0,0,...}.

Let us look at some specific examples. For a quantum systems with n = m = 2, the following state

```
|v> = 1/√2 (|u1|d2 - |u1|d2) (4.96)
```

is entangled. This state is the most famous of all entangled states and is usually known as the singlet state or an EPR pair, after Einstein, Podolsky, and Rosen (1935). Note that this state is a sum over states and cannot be written in a simpler form; this is what makes it entangled.

The following two states

```
|v> = 1/√2 (|ud) + |du) and |w> = 1/√2 (|uu) + |dd) (4.97)
```

are also entangled. For example, in |w>, if one electron is measured to have spin up, then the other electron will also have spin up simply because they were entangled in such a way that their spins are correlated. However, just because a state is written as a sum of terms of the bases does not necessarily mean that it is entangled. Consider, for example,

```
|v> = 1/√2 (|u1|d2 + |d1|d2) = 1/√2 (|u1 + |d1|) |d2 = |h1 |d2
```

where |h1> = |u1 + |d1>. This state is not entangled. In more general terms, a state is said to be entangled if it cannot be written in the form in (4.95). For example, |v> = |u1 ⊗ |d2 is not entangled.

Let us now describe a way to check whether or not a state is entangled later. Consider a linear map between H = H1 ⊗ H2 and a matrix space of m × n matrices, M. This mapping can be defined as

```
Γ(|v>) = ∑_{i=1}^r γ_i |a_i> (|b_i>)* = UDV , (4.98)
```
