# Formelsammlung

Dieser Text enthält eine Übersicht über die wichtigsten Formeln aus verschiedenen Bereichen der Mathematik und Physik.

Aus dem Inhalt:

+   - Arithmetik
+   - Algebra
+   - Geometrie
+   - Trigonometrie

1. Arithmetik und Algebra

```
a + b = b + a
a · b = b · a
(a + b)² = a² + 2ab + b²
a² − b² = (a + b)(a − b)
```

2. Geometrie

```
Fläche: A = πr²
Umfang: U = 2πr
Volumen: V = a³
```
