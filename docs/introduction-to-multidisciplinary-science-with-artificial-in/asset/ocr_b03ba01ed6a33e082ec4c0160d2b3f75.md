In summary, there are two types of resistivity well-logging tools: induction tools and electrode tools. In the latter, electric current is sent into the formations by an array of electrodes. These tools work with brine-based muds. In the former, tools generate a magnetic field that induces an electric current in the formation. These tools are generally used with oil-, air-, or fresh-water-based muds.
