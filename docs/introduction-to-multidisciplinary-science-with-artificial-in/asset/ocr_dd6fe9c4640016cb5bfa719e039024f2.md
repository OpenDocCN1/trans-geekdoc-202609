# **Proof of the first law.**

Our next task is to prove the first law, which says that the planets move in elliptical orbits with the Sun being at one of the focuses. By using the heliocentric diagram with the polar coordinates, in Figure 1.12a, and the definition of the velocity vector of the orbiting planet, in (1.37), we can define the acceleration vector, $\gamma = d\mathbf{v}/dt$, which is the second time derivative of the vector position, as

$$\gamma = \left[\frac{d^2 r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2\right] \mathbf{i}_r + \left[2\frac{dr}{dt}\frac{d\theta}{dt} + r\frac{d^2\theta}{dt^2}\right] \mathbf{i}_\theta$$

$$= -\frac{G m_1}{r^2} \mathbf{i}_r + 0 \mathbf{i}_\theta. \tag{1.42}$$

Because the gravity force $\mathbf{F} = m_2 \gamma = -G m_2 m_1 / r^2 \mathbf{i}_r$ is collinear with the position vector of the orbiting planet, $\mathbf{x} = r \mathbf{i}_r$, the $\theta$-component of the acceleration vector of the orbiting planet is zero and the radial component of the acceleration vector of the orbiting planet is nonzero; i.e.,

$$\frac{d^2 r}{dt^2} = r\left(\frac{d\theta}{dt}\right)^2 - \frac{G m_1}{r^2} = \frac{L^2}{m_2 r^3} - \frac{G m_1}{r^2} \tag{1.43}$$

$$2\frac{dr}{dt}\frac{d\theta}{dt} + r\frac{d^2\theta}{dt^2} = \frac{d}{dt}\left(r^2\frac{d\theta}{dt}\right) = 0 \Longrightarrow \frac{L}{m_2} = r^2\frac{d\theta}{dt}. \tag{1.44}$$

We can see from equation (1.43) that $\theta$-component of the acceleration vector provides an alternative way of showing that the magnitude of the angular momentum vector of the orbiting planet is constant. Our focus here is on equation (1.44). As we will see later the solution to this equation is an ellipse and therefore useful in the proof of the first Kepler’s law.
