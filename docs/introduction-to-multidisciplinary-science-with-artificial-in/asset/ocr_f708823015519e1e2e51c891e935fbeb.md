# # 数字病理学扫描仪 NanoZoomer S360

数字病理学扫描仪是一种将玻璃切片转换为高分辨率数字图像的设备。NanoZoomer S360 支持最多360张切片的自动连续扫描，提供高速、高画质的病理图像。

+   - 最多360张切片连续扫描
+   - 高速扫描模式（20倍/40倍）
+   - 高亮LED光源和自动对焦
+   - 紧凑机身，操作简便

| 项目 | 规格 |
|------|------|
| 型号 | C13220-01 |
| 扫描时间 | 约40秒（20倍）/ 约150秒（40倍） |
| 分辨率 | 0.46µm/像素（20倍）/ 0.23µm/像素（40倍） |
| 光源 | LED |
