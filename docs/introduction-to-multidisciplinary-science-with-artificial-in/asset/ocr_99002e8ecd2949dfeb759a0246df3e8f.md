# **Properties of the density matrix.**

The density matrix satisfies a number of properties. First, the density matrix is a Hermitian operator: $\rho^\dagger = \rho$ are the result of the fact that the probabilities $p_i$ are real. The consequence of hermiticity of $\rho$ means that all of the eigenvalues of density matrix are real.

Second, $\mathrm{Tr}(\rho) = 1$, which implies that some probability adds up to one. Actually $\mathrm{Tr}(\rho)$ is the sum of eigenvalues of $\rho$. These eigenvalues themselves can be taught as probabilities for different states. The eigenvalues go with the eigenstates (i.e., eigenvectors). Because $\rho$ is hermitian matrix, its eigenstates are all mutually orthogonal. As mentioned above example, when $\lambda_1 = \lambda_2 = ... = \lambda_n = 1/n$, we have a complete ignorance and a maximal knowledge when we are dealing with a pure state (i.e., $n = 1$ and $p = 1$ hence $\rho = |\psi\rangle\langle\psi|$). In addition, a mixed state can be defined as a density matrix that has more than one nonzero eigenvalue.

Third, the density matrix is positive semi-definite; i.e., if $|\phi\rangle$ is an arbitrary quantum state then

$$\langle\phi|\rho|\phi\rangle = \sum_i p_i |\langle\phi|\psi_i\rangle|^2 \ge 0 \tag{4.105}$$

An equivalent definition of a positive semi-definite operator is one whose eigenvalues are always non-negative.

# **Entropy of a quantum system.**

In Chapter 2, we introduce the entropy of classical systems. It is given by:

$$S = - \sum_i^n p_i \log p_i \tag{4.106}$$

If only one $p_i$ (i.e., $n = 1$ and $p_1 = 1$) is non-zero, we know exactly the state that the system is in and the entropy (lack of information) is zero; $S = 1 \log 1 = 0$. If there is equal probability $p_1 = p_2 = ... = p_n = 1/n$ then:

$$S = - \sum_{i=1}^n \frac{1}{n} \log(1/n) = \log n = S_{\max} \tag{4.107}$$

where $S_{\max} = \log n$ is the maximum entropy of this system. For a quantum system, entropy is $$S = -\mathrm{Tr}(\rho \log \rho) \tag{4.108}$$ As for the classical case, if the system is definitely in one state, then $S = 1 \log 1 = 0$.
