particle-velocity field under the assumptions (i) that the stiffness tensor is isotropic, (ii) that nonzero components of the stiffness tensor are constant, and (iii) that the source terms are zero. So by substituting the stress-strain equations (A.44) into the velocity-stress equations in (A.43) under these assumptions, we arrive at

```
$$\frac{\partial^{2}v_{p}(\mathbf{x},t)}{\partial t^{2}} = \eta_{pqrs}\frac{\partial^{2}v_{r}(\mathbf{x},t)}{\partial x_{q}\partial x_{s}}\,\qquad\text{(A.69)}$$
```

with

```
$$\eta_{pqrs} = \left(V_{P}^{2} - 2V_{S}^{2}\right)\delta_{pq}\delta_{rs} + V_{S}^{2}\left(\delta_{pr}\delta_{qs} + \delta_{ps}\delta_{qr}\right)\,,\qquad\text{(A.70)}$$
```

where $V_{P}$ and $V_{S}$ are P-wave and S-wave velocities, respectively. As is well known, an arbitrary wave can be expanded in terms of a spectrum of plane waves, which can also be viewed as the eigenmodes of the wave equation. So the finite-difference methods must be stable for an arbitrary plane wave. Consequently, our derivations of the stability condition can be based on the following trial plane-wave solution,

```
$$v_{p}(\mathbf{x},t)=\zeta_{p}\exp\left[i\left(\mathbf{k}\cdot\mathbf{x}-\omega t\right)\right]=\zeta_{p}\exp(-i\omega t)\exp\left[i\left(k_{1}x_{1}+k_{2}x_{2}+k_{3}x_{3}\right)\right],\qquad\text{(A.71)}$$
```

where $\mathbf{k}=k_{j}\mathbf{a}_{j}$ and $\{\mathbf{a}_{1},\mathbf{a}_{2},\mathbf{a}_{3}\}$ are three mutually perpendicular base vectors of unit length for each base vector, with $\mathbf{a}_{3}$ pointing vertically downward. If we assume that the time dependence of this solution is such that

```
$$v_{p}(\mathbf{x},t+\Delta t)=\alpha v_{p}(\mathbf{x},t)\,,\qquad\text{(A.72)}$$
```

where $\alpha$ is the so-called growth factor, then, for a finite-difference scheme to be stable, we must have a growth factor $|\alpha|\le 1$ for all the values of $k_{j}$. Our next task is to make this condition more user-friendly by explicitly writing it in terms of the P-wave velocity and timestep. By using the fact that any plane wave with a representation given in (A.71) satisfies the divergence-free condition for the propagation of P-waves, which is our concern in the mathematics of dispersion and stability conditions, (A.69) reduces to

```
$$\frac{1}{V_{P}^{2}}\frac{\partial^{2}\mathbf{v}(\mathbf{x},t)}{\partial t^{2}}=\langle\nabla,\nabla\rangle\mathbf{v}(\mathbf{x},t)\,,\qquad\text{(A.73)}$$
```

where the gradient operator is

```
$$\nabla = \frac{\partial}{\partial x_{q}}\mathbf{a}_{q}\,.$$
\qquad\text{(A.74)}
```
