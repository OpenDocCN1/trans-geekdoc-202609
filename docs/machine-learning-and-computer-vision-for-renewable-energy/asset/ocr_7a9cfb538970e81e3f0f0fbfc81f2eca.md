Each regression method has several assumptions that must be met in order for the equation to be considered reliable. Assumptions, for example, for Method of Least Squares (MLS), must be tested when building a regression model. The following assumptions must be verified and satisfied when using the MLS method.

# The model must be linear.

MLS regression is used only when building a linear model. The linear relationship between the dependent and independent variables can be checked using a dot (scatter) diagram. The dot plot matrix can test all variables, provided that no more than 5 variables are used in total. In the case of multiple regression of each pair of variables, scatter diagrams should be constructed. In Figure 6 shown how a data set of linear relationships would appear on a scatterplot. If such a graph is obtained, as in Figure 7, which has an exponential form, then logarithmic transformation into a linear one can be used. In the absence of a linear relationship between the data points or if the data cannot be transformed into a linear one, it is necessary to perform a non-linear regression analysis, which will be discussed in detail in the following lectures.

# The data must be randomly distributed.

The data used in the regression analysis must be randomly distributed, that is, the data samples must not depend on an external factor. Arbitrary distribution can be tested by using discontinuities in the regression model. Covariances calculated as output from a regression model should not be correlated when plotted on a scatterplot or scatterplot matrix with the independent variables. In this case, the concept of the absence of heteroskedasticity is considered. For a linear relationship, if the variance is not constant and increases as the predictor (X) increases, this is called heteroskedasticity. In such cases, the standard error of the derivation cannot be relied upon, but the coefficients will still be unbiased.
