The user interface can be presented in a separate Microsoft Excel file. The choice of this software as the environment for using the decision support model is reasonable because of the ease of use for the end user-decision maker. Also, an important advantage of this approach is the absence of the need to create a separate software product with a graphical interface for integrating the trained model into it. Data entry and model management functions are developed using the built-in Visual Basic for Applications (VBA). A Microsoft Excel workbook has two user-accessible worksheets used for data input and output.

The data entry interface is a series of tables on an Excel sheet containing parameter names, divided by category, and fields for data entry. Each of the tables, therefore, each of the parameter categories is highlighted in a separate color for ease of use. Within each of the tables are common parameters and parameters unique to each type of energy generation facility. After successfully passing the predicted value of the objective function, the data entered by the user is passed to the Data Output sheet. The interface of the data output sheet is shown in Figure 5.
