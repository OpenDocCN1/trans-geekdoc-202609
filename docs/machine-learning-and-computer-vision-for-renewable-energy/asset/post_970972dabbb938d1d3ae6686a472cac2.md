Accuracy determines the overall performance of the forecasted model. It calculates the percentage of the sum difference between the actual and forecasted values to the total number of the actual value (Muhammad et al., 2021). The accuracy is determined by the equation as

```
$Accuracy = \frac{Tdiff}{Tactual} \times 100$
```

Mean Square Error (MSE) determines the squared difference between the forecasted values and observed parameters in terms of the mean Muhammad et al. (2021) as shown in the equation below. The smaller the value of the MSE of the model, the better performance of the forecasting model.

```
$MSE = \frac{1}{n} \sum_{i=1}^{n} \left( x_i - \hat{x}_i \right)^2$
```

Mean Absolute Error (MAE) determines the closeness of the forecasted electricity demand (Muhammad et al., 2022). The MAE is determined with the equation as follows:

```
$MAE = \frac{1}{n} \sum_{i=1}^{n} \left| x_i - \hat{x}_i \right|$
```

Root Mean Squared Error (RMSE) shows the standard deviation of the difference between the forecasted electricity demand. The RMSE is determined with the equation as follows:

### Application to Hourly Electricity Demand

The hourly average demand that needs to be supplied by all resources that can be dispatched by Eskom National Control for seven days is depicted in Figure 5. The series clearly shows a declining trend every seven days. The cause of this decline might be the inevitable result of the chaos inside Eskom, as its fleet of mostly aging power stations is hit by maintenance problems, sabotage, and corruption. It is worth revealing that Minerals and Energy (1998) predicted that Eskom would run out of electrical power reserves by 2007 unless action is taken to prevent it. To improve power supply and reliability, it was recommended that Eskom be restructured into separate electricity generation and power transmission businesses. Despite these warnings and requests by Eskom to be allowed to increase capacity, the national government took no action. Hence the current decline in electricity demand (Phaahla, 2023). Due to a reduction in electricity production, imported electricity went up markedly in 2014 by 18.6% compared with 2013. Likewise, electricity exports also went down slightly by 0.7% in 2014 compared with the previous year. Nevertheless, Phaahla (2023) has emphasized that even though the production of electricity by Eskom showed a declining trend, so did distribution. ### Combined Forecast Model Using Minimum Score Combining

Eskom hourly data is split into the training, validation, and test data sets as described in the previous section in Figure 1. We therefore proceed and fit a TBATS, and the selection of the best TBATS model is done automatically by using the TBATS function in Python for hourly electricity demand load. The parameters of the fitted model are \(\hat{\lambda}=0.027603, \hat{\alpha}=1.890744, \hat{\beta} = -0.374124\) and the damping parameter is \(\hat{\phi}=0.800000\).

Using the minimum score combination proposed by Trucíos and Taylor (2020), CNN and LSTM are combined with the TBATS. Based on the estimates of combined models, an out-of-sample analysis evaluates the ability of deep learning methods coupled with Box-Cox transformations, Fourier representations that have time-varying coefficients, and autoregressive moving average (ARMA) error correction. Figure 6 presents the loss predicted by individual models. It can be seen that the TBATS-CNN-LSTM has less loss function compared to counterpart models. ### Short- and Medium-Term Forecasting Results

To check the model performance on short (i.e., accuracy) and medium-term (i.e., stability) horizons, a random sample of 700 data points were selected uniformly from various time ranges from one week to several months, as shown in Table 3. The mean of the performance metrics values is computed for each range. Results show that error values are consistent with a low standard deviation. The accuracy measured by CV (RMSE) is 0.60% for the short term and an average of 0.56% for the medium term. With very comparable performances for both the short-term and medium-term horizons, it is obvious that the estimated TBATS-CNN-LSTM is accurate and stable.

The second threat is concerned with the algorithms used in the different steps and components of the methodology, which could use some unrealistic assumptions inappropriate for the current chapter's case context. To avoid such a threat, all the algorithms are developed in this chapter.

The internal validity in the case of this chapter is concerned with three main threats. The first one is related to how much the data set is suitable to train a TBATS-CNN-LSTM model that needs a large amount of data to mine historical patterns. The ESKOM hourly electricity demand load data set ranges from April 2019 until October 2023. This data set is large enough to allow deep learning, which is particularly targeted by TBATS-CNN-LSTM. The second threat is that the TBATS-CNN-LSTM error starts increasing while the training error still decreases. Too much training with a complex forecasting model leads to bad generalizations. To prevent overfitting for the TBATS-CNN-LSTM model, the training examples at each epoch were randomly shuffled. This helps to improve generalization. Furthermore, early stopping is also used, whereby training is stopped at the lowest error achieved on the test set. This approach is highly effective in reducing overfitting.
