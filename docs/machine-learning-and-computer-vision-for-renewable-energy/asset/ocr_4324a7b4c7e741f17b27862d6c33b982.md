The best way to detect heteroskedasticity is to use a scatterplot of the residuals against the value of
X. Heteroscedasticity can be avoided by performing a log transformation or by examining the bias of
the omitted variables, or by identifying outliers and trying to remove them.

**Independent variables should not be collinear**. Collinearity is a linear relationship between independent
variables that creates redundancy in the model. In some cases, the model is created with collinearity.
However, if one of the collinear variables depends on the other, it may be worth removing it from
the model. Collinearity can be estimated using a dot plot or dot plot matrix of independent variables.
Predictors should not be correlated with the error term. This can be represented by the equation below:

\(\sigma X \epsilon = 0: \forall x, \epsilon.\)

If the predictors are correlated, this is called omitted variable elimination. This occurs when a predictor
is excluded, and this is reflected in the error term, leading to biased and counterintuitive estimates. It can
be found by examining the correlation between predictors. Thus, when estimating the amount of wages
based only on the number of years of education, the variable error is not taken into account. Because the
salary depends on many other factors, such as the type of education, additional socio-economic status.
But still, it can be used for predictions.

A concomitant feature of the correctness of regression analysis is the absence of multicollinearity.
If the multiple linear regression is represented as

\(Y = \beta_0 + \beta_1(X_1) + \beta_2(X_2) + \beta_3(X_3) + \beta_4(X_4) + \varepsilon ,\)

then ideally no predictor should be explained by another predictor.

Multicollinearity occurs when the predictors themselves are correlated. To determine whether multi-
collinearity exists between predictors, the correlation between all pairs of predictors must be examined.
