Since the distribution of power at one rung of the hierarchy depends on the proper quantity being supplied from the rung above, coherence is therefore crucial. Consequently, we produce probabilistic forecasts in wind power (i.e., electricity) generating situations in this chapter. By looking at how the hierarchy of wind power generation might be used for forecasting, an alternative to the conventional methods of bottom-up versus top-down forecasting is presented. We investigate the possibility of using all the series for forecasting as opposed to picking series from certain areas of the hierarchy. Furthermore, we view the hierarchical structure as a distinguishing characteristic of the data generating process and use it to instantly construct forecasts for every level of the hierarchy, rather than using it after the initial forecasts are generated. This integrated technique uses the Kalman filter to explicitly address hourly demand load dependencies, such as complementarity of products and energy substitution which are normally ignored.

We anticipate that our suggested approach provides reliable and accurate estimations of trends in energy consumption. We give crucial information to all parties involved, including Eskom, by doing this. These insights enable the development of strategic infrastructure, resource allocation, and the smooth integration of environmentally friendly power suppliers into the national grid. To guarantee that South Africa has a future dependable and sustainable energy, this cooperative effort is crucial. There are four benefits to our method:

- Firstly, a density forecast is generated for each series in the hierarchy, and this is taken together to meet the requirements of coherence.
- Second, all estimated densities and dependence structures are the products of an integration of data from various hierarchy levels.
- Third, the assumptions of a distribution are not required.
- Fourth, the problem is decomposed into lower-dimension sub problems, enabling the approach to be scalable to large hierarchies.

## Problem Definition

Assuming that original time series is denoted as $\{r_1, r_2, ..., r_n\}$, a Kalman filter is used to reduce the noise of this series, thus obtaining a smoothed time series as $\{x_1, ..., x_n\}$ (Gupta et al., 2018). Given this smoothed time series, all its sliding windows is computed by $SW_i^L = \{x_i, x_{i+1}, \dots, x_{i+L-1}\}$, for $i=1, 2, ..., n-L$ and the training dataset along with the training labels as $\{\ell_1, ..., \ell_{n-L}\}$, where $L$ is the length of each time series. The algorithm needs to learn a function $f$ which is defined as

```
\(\ell_i = f\left(SW_i^L\right).\)
```

So, the solution is formally defined as

$$ \arg \min_{\Omega} \sum_{i=1}^{N} \left( \ell_i - f \left( SW_i^L \right) \right)^2 $$

where $\Omega$ is the set of parameters for model $f$ and $N$ is the size of the training set. In this chapter, we use gradient boosting decision tree (GBDT) to interpret model $f$. It outperforms other models such as deep learning techniques in terms of time complexity, while the accuracy of them remains almost the same.

## Proposed Gradient Boosting Decision Tree-Kalman Filter Algorithm

While gradient boosting decision tree performs remarkably well in time series forecasting, overfitting is a real issue with its applications in real-world. Noisy data in the training set is typically the reason for this decline in its performance. Thus, by pre-processing the data with the use of a Kalman filter and thereby reducing the noise in the initial training set, overfitting issue of GBDT is resolved. Hence, the Kalman filter addresses the general problem by trying to estimate the state $X \in \Re^n$ of a discrete-time stochastic process that is governed by a linear stochastic difference equation that is given by

$X_t = F_t X_{t-1} + B_t u_t + e_t$

with a measurement $Z \in \Re^m$ that is computed by

$Z_t = H_t X_t + v_t.$

On the other hand, Li et al. (2020) declared that $Z_t$ is the vector of measurements and $H_t$ is the transformation matrix that maps the state vector into the measurement space. Here, $W_t$ and $v_t$ are random variables that represent the process and measurement noise respectively. According to Kumar (2017), the state space representations and the associated Kalman filter have a profound impact on many applications. A state space model is generally represented in two equations: the first equation is called the state equation which finds the state $X_{t+1}$ in time (t+1) using the previous state $X_t$ and a noise term as shown in model (5) as

$X_{t+1} = \alpha_t X_t + \varpi_t, t=1, 2 \cdots$

At this juncture, $\alpha_t$ is a sequence of B×B matrix and $\varpi_t$ is the error term that follows a normal distribution with parameters (0, $Q_t$) respectively. The second equation is the observation equation which expresses a $w$-dimensional observation $Z_t$ as a function of a $v$-dimensional state variable $X_t$ and the noise. Thus,

$Z_t = G_t X_t + V_t, t = 1, 2, \cdots$

where $V_t$ is the measurement noise and $G_t$ is a sequence of $w \times v$ matrix and, the correlation between $W_t$ and $v_t$ is zero. For that reason, this chapter employs previous hourly wind power generation from 1st April 2019 to 29th December 2023 as input for predicting the next 61 days generation load values (30th December 2023 to 29 February 2024) using the prediction scheme developed using KFT; and, the standard Kalman filter equations for the prediction stage are given as

\(\widehat{X}_{t|t-1} = F_t \widehat{X}_{t-1|t-1} + B_t u_t\) (7)

$P_{t|t-1} = F_t P_{t-1|t-1} F_t^T + Q_t$ (8)

where \(\widehat{X}_t\) is an estimate of \(X_t\) and \(u_t\) is the vector that contains any control input. \(F_t\) is the transition matrix which applies the effect of each state parameter at time \(t-1\) on system state at time \(t\). Additionally, \(B_t\) is the control input matrix that applies the effect of each control input parameter in the vector \(u_t\) for the state vector; and, the terms of \(P_t\) in this case provide a covariance of the estimated state vector \(X_t'\). Finally, \(Q_t\) is the covariance matrix of the noise process that is associated with a noisy control input variable. The measurement update equations are

\(\widehat{X}_{t|t} = \widehat{X}_{t|t-1} + K_t \left( Z_t - H_t \widehat{X}_{t|t-1} \right)\) (9)

$P_{t|t} = P_{t|t-1} - K_t H_t P_{t|t-1}$ (10)

$K_t = P_{t|t-1} H_t^T \left( H_t P_{t|t-1} H_t^T + R_t \right)^{-1}$ (11)

The parameters of a Kalman filter can be obtained by means of expectation–maximization (EM) algorithm or can be decided according to physical models in advance (Carey and Ramsay, 2021).

A gradient boosting decision tree is a kind of ensemble learning method. By creating multiple weak prediction models, the decisions made by these weak learners are combined and a single stronger model is generated iteratively. The GBDT uses classification and regression trees (CART) as base learners. Assuming that there are \(K\) trees, the estimation with respect to the input feature \(x_i\) is defined in additive form as

\(\hat{y}_i = \sum_{t=1}^K f_t(x_i), f_t \in \mathcal{F}\) (12)

where \(K\) denotes the number of base functions, \(\mathcal{F}\) is the space of functions containing all regression trees.
