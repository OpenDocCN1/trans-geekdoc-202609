## VISION-BASED SOLAR ENERGY USING DEEP LEARNING TECHNIQUES

In this section, various deep learning techniques for vision-based solar energy modelling are presented. These methodologies concentrate on different facets of general modelling, quality assurance, data processing, and data augmentation.

Many architectural design decisions, such as the number of layers, convolutional filter size, and neuron count, as well as alternative learning configurations, such as batch size and learning rate, are frequently involved in the implementation of deep learning models (Lansberry et al., 1992; Lauret et al., 2015; Leholo et al., 2019). It takes work to adjust these hyperparameters so that deep learning models perform better. Generally, there is a defined range of values for every hyperparameter. Due to time and computational resource limitations, a comprehensive search (also known as a grid search) incorporating all possible combinations of these parameters is frequently unfeasible. Grid search is ineffective for finding hyperparameters since hyperparameters can also vary depending on the dataset. Put differently, the hyperparameter values that work best for one dataset might not work well for another. Sampling techniques are usually used in light of these issues. Rather than designating a distinct range of values for every hyperparameter, a statistical distribution is established, from which values can be selected at random. Not all hyperparameters have the same importance. While grid search can focus on finding the best values for the crucial hyperparameters, random search has more exploratory power and may spend less time looking into unimportant parameters. Besides random search, Bayesian optimisation has recently gained strength as a hyperparameter tuning tool (Rodriguez et al., 2018; Salcedo-Sanz et al., 2014; Saloux et al., 2014). The optimal hyperparameter settings can be found automatically using a machine learning algorithm called Bayesian optimisation. This is in contrast to random search, which requires numerous separate but concurrent experiments. Several iterations are used by the algorithm to determine the ideal hyperparameter settings. Preliminary probability estimation of model performance throughout the hyperparameter range is a common application of the Gaussian process. The sampling strategy for the subsequent iteration can be chosen based on the outcomes of the preceding iterations, utilising an acquisition function until an optimal solution is reached (Wang et al., 2017; Welch et al., 2009; Wen et al., 2019).

Together with model-centric methods that concentrate on enhancing the model, such as the model architecture or training plan, other works attempt to facilitate modelling by improving the data. These data-centric methods include data augmentation and feature engineering, among others. Feature engineering seeks to create new features from unprocessed data by applying domain expertise. One common pre-processing step in vision-based solar forecasting, for example, is to unwrap fish-eye lens images of the sky, which severely distort the scene. Clouds can be projected onto a rectangular grid, as proposed by (Leva et al., 2017; Li S, 2003; Yang et al., 2018), to achieve this. This technique was used in deep learning studies to help predict distant cloud displacement or to give object trajectory consistency. On the other hand, it was shown that the original lens distortion enhanced solar predictions by adding more information to the area in the image centre where the sun and surrounding clouds are visible during high solar flux.

By creating altered versions of pre-existing samples, data augmentation seeks to artificially expand a dataset. By utilising existing data more effectively, data augmentation attempts to increase a model's generalizability without the need for costly or impractical additional data collection. In actual use, synthetic data can be produced by applying visual transformations like noise addition, cropping, rotation, or flipping to pre-existing samples or by using generative models like GANs (Nazaripouya et al., 2018; Meng et al., 2016; Mohandes et al., 2004). For vision-based solar forecasting, a variety of data augmentation techniques have been used. To perform noise injection, for example, pixel values were subjected to the addition of Gaussian noise. An alternative method of colour space transformation is to independently adjust each of the three RGB channels’ intensity level at random. An alternative is to simultaneously change the values of each of the three channels’ pixels by a constant amount (Wang et al., 2018; Yu et al., 2011; Zhen et al., 2015). When used for solar modelling from sky images, these methods have been demonstrated to help with the nowcasting task of matching a picture to a solar value; however, they have little effect on the forecasting task. Combining images is another type of data augmentation technique. One of the k-nearest neighbours or a random sample can be combined with the original images. It was shown that mixing images made the greatest difference in nowcasting predictions, much like colour space transformation techniques (Will et al., 2011; Williams et al., 1989; Yousif et al., 2019).

Deep learning methods for solar energy based on vision also require careful consideration of the sampling strategy (Lin et al., 2018; Liu et al., 2018; Zhai et al., 2019). Sky image datasets and satellite observations are uneven in various ways, just like a lot of real-world datasets. For example, the distribution of cloud types at a given geographic location is highly dependent on the local weather. As a result, certain cloud patterns in the original dataset were either overrepresented or underrepresented. Thus, uniformly sampled mini-batches from a training set that is indicative of the dataset will teach the model a site-specific distribution, which may affect how well it performs in various climates.

A dataset’s quality, in addition to its size, can significantly affect the model’s performance and generalisation qualities. Incorrectly labelled samples or mismeasured irradiance, for example, can cause an incorrect supervision signal during model training, and they can also negatively impact the model’s exploitation if it is used in untested environments. These factors make quality control a crucial component of machine learning initiatives (Coimbra et al., 2018; Qing et al., 2018; Rana et al., 2020). The causes of anomalies in vision-based solar power monitoring include operational disturbances like dust, snow, dew, and temperature response, as well as equipment failures like misaligned shade rings, spectral selectivity, and temperature response. Rain, snow, animals, and soiling are just a few of the external hazards that sky cameras are subject to, which can hinder the collection of cloud cover observations (Yu et al., 2019; Zambrano et al., 2020). One common method to filter these anomalies in a dataset is to inspect the outliers. Outliers can be defined, for instance, as samples that are significantly limited in the large original RGB feature space due to the curse of dimensionality. One way to accomplish this is to gauge the separation between samples within a feature space. To circumvent this issue, a filtering method based on the CVAE model was developed (Sapitang et al., 2010; Senthil et al., 2019; Shimray et al., 2017). An autoencoder was trained to reconstruct sky images using a feature space with low dimensions. Outliers that result from this low-dimensional representation are then manually verified to facilitate the separation of real anomalies from visually uncommon sky images. However, this filtering technique may miss common anomalies, like rain or dust in sandy areas. Visual tools were created more recently to complement the different approaches to quality control (Zhang et al., 2016; Peng et al., 2017).
