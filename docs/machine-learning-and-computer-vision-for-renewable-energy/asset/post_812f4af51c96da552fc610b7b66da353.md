## Convolutional Neural Networks

In the machine learning field, not only deep learning becomes more and more popular, but also convolutional neural network (CNN) has attracted attention recently. To feed N-dimensional data as input, and process with multi-layer of convolution. Each layer of convolution will receive the output of the previous layer of convolution as the input. CNN keeps pooling and convolution to extract useful features for each layer and finally obtain high-quality features, which can get a favorable ability of image classification.

A few research using CNNs for time series forecasting tasks have been conducted recently (Kranjc et al., 2015). These authors suggested a novel method that combines CNN with an autoregressive model and demonstrated that it performs better than both CNN and LSTM NNs. Four artificially generated datasets in addition to two real datasets (household electricity and money use) were used in the evaluation. The single CNN fared better than the LSTM on the electrical data. We observe that the electrical data utilized in Kranjc et al. (2015) includes the values of ten variables at each time step, but our data is univariate. A CNN known as Wave Net was used to analyze univariate and bivariate financial and artificial time series in the work of Hagenau et al. (2013). It is demonstrated to be a successful approach, yielding encouraging outcomes and surpassing LSTM and the other comparative methodologies.

Convolutional and max pooling layers make up the two primary types of layers found in convolutional neural networks. The two primary techniques used by convolutional layers are weight distribution and local connections. Local connections refer to the fact that, as opposed to all inputs as in a typical MLP NN, each convolutional node is linked to a small subset of inputs (corresponding to a local region of the inputs and called the node's receptive field). Furthermore, a convolution is used in place of the weighted sum of a conventional NN. In particular, each convolutional layer convolves the input with a weight matrix (also known as a filter or sliding window) of a preset size in order to compute a feature map. To accomplish this, move the weight matrix over the input and compute the input-weight dot product.

Convolutional neurons in the same layer detect the same pattern in various regions of the input because they share the same weights. Training happens more quickly when weight sharing and local connectivity are used to minimize the amount of weights that must be learnt and stored. The number of nodes that share weights is determined by the filter's kernel size, which is used to implement the convolution and weight sharing. A max pooling layer, which calculates the maximum value of the chosen pool of nearby neurons from the convolutional layer, usually comes after a convolutional layer (Wang and Oates, 2015). The combination of a convolutional and max-pooling layer ensures that the output of the max-pooling layer is invariant to shifts in the input data, which is a very useful property for processing natural data. A fully connected output layer computes the final prediction.

In our experiment we used CNNs with Conv1D layer with a kernel size of 3, followed by a Flatten layer to transition from convolutional to dense layers. Then, two dense layers with ReLU activation and a final dense layer with linear activation. The training is done with the Adam optimizer, minimizing the mean squared error. To avoid overfitting, a dropout (Huang and Pan, 2015) is employed during the weight optimization at all layers. Dropout is a technique that includes randomly selecting a fraction of neurons at each training epoch and not including them in the weight optimization. We also applied batch normalization which normalizes the layer inputs for each training mini-batch. This technique has been shown to speed up the training and reduce the dependence of gradients on the scale of the parameters and also the sensitivity of CNN to the initial parameter values Huang and Pan (2014).

### Parameters

To select an appropriate CNN architecture and parameters for each time series, we evaluated the performance of different architectures and parameter combinations on the validation set and selected the best one. For example, for the solar data, we considered CNN architectures with two convolutional layers with (20, 8) and (64, 32) nodes in the first and second layer respectively; with and without max pooling layers; with a batch size of 1, 4, 8 and 16, and a number of training epochs 10, 50 and 250.

## Stacking Ensemble Learning Method

In recent years, overall models have become more important due to improved performance. It is derived from various tasks such as classification or regression problems. It consists of techniques that combine different learning models to improve the results of each model. Two steps are typically used: In the first step, a set of base learners is obtained from the training data, and in the second step, the learners from the first step are combined to create a single prediction model. Therefore, multiple predictions based on different base learners are built and combined into a composite model that is more improved than the individual base models. Combining the best individual models into a single improved composite model usually results in higher accuracy.
