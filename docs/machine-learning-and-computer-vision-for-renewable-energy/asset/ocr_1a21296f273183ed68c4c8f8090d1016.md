Exploratory analysis begins when the independent variables are chosen and before the regression model is constructed. Since MLS is a linear regression method, the main assumption is that the model should be linear. A scatter plot (scatter) and a scatter plot matrix can be used to analyze the linear relationship between the dependent variable and the independent variables. A scatterplot matrix can display up to 4 independent variables with a dependent variable, allowing comparisons between all variables at once. A simple scatter plot can display only two variables: one dependent and one independent. Viewing a scatterplot with one dependent variable and one independent variable allows for a more accurate estimate of the relationship between the variables. Linearity can be tested before building a regression model to determine which independent variables should be used to create a suitable model. Several output statistics are also available after creating the regression model, including:

+   - egression equation;
+   - value \(R^2\);
+   - Durbin-Watson criterion.

After creating the regression model, it is needed to use the output, as well as charts and tables, to test other assumptions of the MLS regression. If the created model satisfies the assumptions, the research analysis can be continued. The regression equation makes it possible to estimate the effect of each independent variable on the predicted values, including the regression coefficient of each independent variable. It is possible to compare the values of the slope of determining the impact of each independent variable on the dependent variable: the farther from zero the value of the slope (no matter whether in the positive or negative direction) – the greater the impact. A regression equation can also be used to predict the values of the dependent variable through the values of each independent variable.

The coefficient of determination, denoted as \(R^2\), measures how well the regression equation models the actual data points. The \(R^2\) value is a number in the range from 0 to 1, and the closer the value is to 1, the more accurate the model. If \(R^2\) is 1, this indicates a perfect model, which is highly unlikely in real-world situations given the complexity of interactions between various factors and unknown variables. Therefore, one should strive to create a regression model with the maximum possible value of \(R^2\), understanding that the value cannot be equal to 1.

When performing regression analysis, there is a risk of creating a regression model that has an acceptable \(R^2\) value by adding independent variables that randomly show a good fit. The adjusted \(R^2\) value, which should also be between 0 and 1, considers additional independent variables, reducing the role of randomness in the calculation. Adjusted \(R^2\) should be used in a model with many independent variables or when comparing models with different numbers of independent variables.
