RNNs can theoretically solve these long dependency problems, but (the weight matrix) keeps getting multiplied by the previous results as the time interval gets longer (reference data is at longer time points). This causes problems with vanishing and exploding gradients. To solve this problem, we use long short-term memory (LSTM) networks.

# Long Short-Term Memory
