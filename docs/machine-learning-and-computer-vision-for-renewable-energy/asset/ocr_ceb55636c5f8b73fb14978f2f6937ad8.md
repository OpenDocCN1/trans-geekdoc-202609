# D. XGBoost (XGB)

XGBoost (XGB) (Abadi et al., 2016) stands out as a robust machine learning model comprising an ensemble of decision trees. The architecture of these trees is determined using a quality score, akin to the impurity score employed by other tree-based models through greedy algorithms. Operating as a boosting algorithm, XGBoost constructs each tree based on the performance of the preceding tree, minimizing the objective function outlined in equation (9). This iterative process leads to successive trees addressing smaller residuals.

```
\(\mathcal{L}(\theta) = \sum_{i=1}^n \mathcal{L}(y_i, \hat{yi}) + \sum_{j=1}^T \Omega(f_j)\) (9)
```

```

```

What sets XGBoost (XGB) apart from traditional gradient tree boosting techniques is its incorporation of diverse regularization techniques, denoted by the term \(\square\). Regularization aims to diminish model variance by introducing slight bias, reducing reliance on observations and enhancing the accuracy of long-term predictions. The number of leaf nodes is indicated by T.

Within equation (10), \(\gamma\) facilitates pruning, diminishing complexity in ensemble trees, wj denotes the leaf weight, and \(\lambda\) is another user-defined parameter governing the magnitude of the regularization-induced penalty.
