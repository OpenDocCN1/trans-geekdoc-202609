Besides random search, Bayesian optimisation has recently gained strength as a hyperparameter tuning tool. (Rodriguez et. al, 2018; Salcedo-Sanz et. al, 2014; Saloux et. al, 2014). The optimal hyperparameter settings can be found automatically using a machine learning algorithm called Bayesian optimisation. This is in contrast to random search, which requires numerous separate but concurrent experiments. Several iterations are used by the algorithm to determine the ideal hyperparameter settings. Preliminary probability estimation of model performance throughout the hyperparameter range is a common application of the Gaussian process. The sampling strategy for the subsequent iteration can be chosen based on the outcomes of the preceding iterations, utilising an acquisition function until an optimal solution is reached.
