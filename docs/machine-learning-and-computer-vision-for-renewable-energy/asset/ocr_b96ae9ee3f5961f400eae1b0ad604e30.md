# FEATURES OF REGRESSION ANALYSIS IN MACHINE LEARNING

When forming the structure of the experiment in the Microsoft AML studio, the predicative analysis algorithm block is added to the “Train Model” block. Available algorithms include neural networks, search trees, clusters, and various types of regression algorithms. In this work, among a number of proposed ones, we focused on the multiple regression algorithm. First, as it can be seen from the name of multiple linear regression, it is assumed that the relationship between the variables is linear. In fact, this conjecture can, in fact, be proven at any time. Multiple regression analysis procedures are slightly affected by small deviations from this assumption. However, it always makes sense to look at two-dimensional scatterplots of the variables of interest. If the non-linearity of the relationship is obvious, it is possible to consider whether the transformation of the variables or explicitly allow the inclusion of non-linear terms. In multiple regression, it is assumed that the residuals (predicted values minus the observed values) are normally distributed (that is, follow the law of normal distribution).
