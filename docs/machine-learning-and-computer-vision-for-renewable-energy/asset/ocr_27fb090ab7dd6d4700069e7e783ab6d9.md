# Designing a Framework for Data Pre-Processing

This constituent is legally obligated to use big data efficiently and submit it to the analytical server for predictive modelling (Patil et al., 2018). The system’s configuration is primarily comprised of the Hadoop network, which stores data from various sources in the Hadoop distributed file system (HDFS). These authors read the data and converted it into a raw data file using the Statistical Analysis System (SAS). The current chapter uses Python to read data from Hadoop. A comma delimiter is used to separate fields in a raw data file. To build a data model, the analytical model receives the raw data file. This increases the system’s versatility and aids in the development of a solid self-learning analytical model in real-time. It also helps to develop a strong self-learning analytical model and makes the system highly scalable (Patil et al. 2018).

# Trigonometric Seasonality Box-Cox Transformation ARMA Errors Trend Seasonal Components

The TBATS uses Box-Cox transformation for non-linearity and an ARMA representation for capturing any autocorrelation in the residuals (Naim et al., 2018). In the TBATS model, T stands for trigonometric terms for seasonality, B for Box-Cox transformations for heterogeneity, A for ARMA errors for short-term dynamics, T for trend, and finally S for seasonal periods.
