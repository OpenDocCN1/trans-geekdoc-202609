Exploratory analysis begins when the independent variables are chosen and before the regression model is constructed. Since MLS is a linear regression method, the main assumption is that the model should be linear. A scatter plot (scatter) and a scatter plot matrix can be used to analyze the linear relationship between the dependent variable and the independent variables. A scatterplot matrix can display up to 4 independent variables with a dependent variable, allowing comparisons between all variables at once. A simple scatter plot can display only two variables: one dependent and one independent. Viewing a scatterplot with one dependent variable and one independent variable allows for a more accurate estimate of the relationship between the variables. Linearity can be tested before building a regression model to determine which independent variables should be used to create a suitable model. Several output statistics are also available after creating the regression model, including:

- regression equation;
- value \(R^2\);
- Durbin-Watson criterion.

After creating the regression model, it is needed to use the output, as well as charts and tables, to test other assumptions of the MLS regression. If the created model satisfies the assumptions, the research analysis can be continued. The regression equation makes it possible to estimate the effect of each independent variable on the predicted values, including the regression coefficient of each independent variable. It is possible to compare the values of the slope of determining the impact of each independent variable on the dependent variable: the farther from zero the value of the slope (no matter whether in the positive or negative direction) – the greater the impact. A regression equation can also be used to predict the values of the dependent variable through the values of each independent variable.

The coefficient of determination, denoted as \(R^2\), measures how well the regression equation models the actual data points. The \(R^2\) value is a number in the range from 0 to 1, and the closer the value is to 1, the more accurate the model. If \(R^2\) is 1, this indicates a perfect model, which is highly unlikely in real-world situations given the complexity of interactions between various factors and unknown variables. Therefore, one should strive to create a regression model with the maximum possible value of \(R^2\), understanding that the value cannot be equal to 1.

When performing regression analysis, there is a risk of creating a regression model that has an acceptable \(R^2\) value by adding independent variables that randomly show a good fit. The adjusted \(R^2\) value, which should also be between 0 and 1, considers additional independent variables, reducing the role of randomness in the calculation. Adjusted \(R^2\) should be used in a model with many independent variables or when comparing models with different numbers of independent variables.

The standard error of the variance measures the accuracy with which a regression model can predict values with new data. The smallest values indicate a more accurate model, respectively, when comparing several models, the one where this value is the smallest of all is the model in which the standard error of the discrepancy is minimized. A scatterplot can be used to analyze the independent variables to identify clustering or outliers that may affect model accuracy.

### Confirmatory analysis

Confirmatory analysis is the process of evaluating a model against the null hypothesis. In regression analysis, the null hypothesis states that there is no relationship between the dependent and independent variables. For a model with no relationships, the value of the slope is 0. If the elements of the confirmation analysis are statistically significant, the null hypothesis can be rejected (in other words, the existence of a relationship between the dependent and independent variables is statistically confirmed). The following statistical indicators are used to determine significance as a component of the analysis:

- F-statistics and the associated p-value;
- t-statistics and the associated p-value;
- confidence intervals.

The F-statistic is a global statistic returned by the F-test that shows the predictive power of the model by calculating regression coefficients in the model that are significantly different from 0. The F-test analyzes the combined effect of independent variables rather than evaluating each one individually. Associated with the F-statistic is the corresponding p-value, which is a measure of the probability that the deterministic relationship between the variables is due to chance. A small p-value, usually 0.05 or less, indicates that there are real relationships between variables in the model (that is, the revealed regularity is not random), which gives the right to reject the null hypothesis. In this case, the probability that the relationship in the model is random is 0.05, or 1 in 20. Or the probability that the relationship is real is 0.95, or 19 in 20.

The t-statistic is a local statistic returned by the t-test that shows the predictive power of each independent variable separately. Like the F-test, the t-test analyzes regression coefficients in a model that are significantly different from 0. Because the t-test is applied to each independent variable, the model will return a t-statistic value for each independent variable, rather than a single value for the entire model. Each t-statistic value has an associated p-value that indicates the significance of the independent variable.

As with the F-test, the p-value for each t-test must be 0.05 or less to reject the null hypothesis. If the p-value for an independent variable is greater than 0.05, that variable should not be included in the model and a new model should be built, even if the global probability value for the original model indicates statistical significance.

Confidence intervals visualize the regression coefficients for each independent variable and can be 90, 95, and 99 percent. Therefore, confidence intervals can be used alongside t-test p-values to assess the significance of the null hypothesis for each independent variable. The regression coefficients must be equal to 0, only in this case you can reject the null hypothesis and continue using the model. Therefore, for each independent variable, the regression coefficient and the associated confidence interval cannot overlap with 0. If the 99% or 95% confidence intervals for this independent variable overlap with 0, this independent variable does not allow us to reject the null hypothesis. Including this model variable may negatively affect the overall significance of your model. If only the 90% confidence interval overlaps 0, the variable can be included in a model with satisfactory overall statistical significance. Ideally, the confidence intervals for all independent variables should be as far from 0 as possible.

Expected values are calculated based on the regression equation and the values of each independent variable. Ideally, the expected values should match the observed (actual values of the dependent variable). The expected values, along with the observed values, are used to calculate the correlations. The main conceptual limitation of all considered methods of regression analysis is that they allow to reveal only numerical dependencies, and not the causal relationships underlying them. For example, a strong positive relationship (correlation) can be found between the destruction caused by fire and the number of firefighters involved in fighting the fire. Of course, the most likely explanation for this correlation is that the size of the fire (an extraneous variable neglected to include in the study) affects both the extent of destruction and the number of firefighters required (i.e., the larger the fire, the more firefighters are called from it quenching). Although this example is quite transparent, for correlations, alternative causal explanations are often even considered.
