# Combined Forecast Model Using Minimum Score Combining

Eskom hourly data is split into the training, validation, and test data sets as described in the previous section in Figure 1. We therefore proceed and fit a TBATS, and the selection of the best TBATS model is done automatically by using the TBATS function in Python for hourly electricity demand load. The parameters of the fitted model are \(\hat{\lambda}=0.027603, \hat{\alpha}=1.890744, \hat{\beta} = -0.374124\) and the damping parameter is \(\hat{\phi}=0.800000\).

Using the minimum score combination proposed by Trucíos and Taylor (2020), CNN and LSTM are combined with the TBATS. Based on the estimates of combined models, an out-of-sample analysis evaluates the ability of deep learning methods coupled with Box-Cox transformations, Fourier representations that have time-varying coefficients, and autoregressive moving average (ARMA) error correction. Figure 6 presents the loss predicted by individual models. It can be seen that the TABTS-CNN-LSTM has less loss function compared to counterpart models. We therefore conclude that the best model is the TBATS-CNN-LSTM. This model's key performance indicators are significantly lower than the others. In contrast to Gasparin et al. (2022), who used three error metrics in their deep learning for time series forecasting: in the electric load case study, we employ four error metrics in this study. Each model's performance is assessed using these metrics, and the results are summarized in Table 2. This table leads to a few speculative inferences. The findings demonstrate that combining point forecasts from various models enhances the model's predictive capability. The best model is in Table 2.
