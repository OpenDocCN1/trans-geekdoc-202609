Other inputs, such as predicted values and lags, are also important for MLS regression assumptions. Expected values are calculated based on the regression equation and the values of each independent variable. Ideally, the expected values should match the observed (actual values of the dependent variable). The expected values, along with the observed values, are used to calculate the correlations. Bias in regression analysis is the difference between the values in the observed data set and the expected values calculated using the regression equation (Figure 8).

The inconsistencies A and B for the relations above are calculated as follows:

```
varianceA = observationA – expectedA · variance
```

```
varianceB = observationB – expectedB · varianceB
```

The residuals are used to calculate the error of the regression equation, as well as to test some assumptions. The main conceptual limitation of all considered methods of regression analysis is that they allow to reveal only numerical dependencies, and not the causal relationships underlying them. For example, a strong positive relationship (correlation) can be found between the destruction caused by fire and the number of firefighters involved in fighting the fire. Of course, the most likely explanation for this correlation is that the size of the fire (an extraneous variable neglected to include in the study) affects both the extent of destruction and the number of firefighters required (i.e., the larger the fire, the more firefighters are called from it quenching). Although this example is quite transparent, for correlations, alternative causal explanations are often even considered.
