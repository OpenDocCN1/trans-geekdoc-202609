The parameters of the neural network used in these models are listed in Table 1. The neural network parameters specified in the Table 1 are used in the AML Studio for advanced configuration of the module responsible for the prediction algorithm using a neural network. The feedforward neural network that is used in Microsoft AML Studio is the simplest type of artificial neural network. In a feedforward network, information moves in only one direction from input layer to output layer. Feedforward neural networks transform an input by putting it through a series of hidden layers. Every layer is made up of a set of neurons, and each layer is fully connected to all neurons in the layer before. The last fully connected layer (the output layer) represents the generated predictions.

After training the model using the “Train Model” block and testing it using the “Score Model”, it is evaluated in the “Evaluate Model” block. Also, from the “Score Model” block, data is fed to the six inputs of “Execute Python Script” block, which are responsible for generating graphs of the dependence of the values of the objective function on the values of some basic constraints. After completion of training, testing and evaluation, the web service is set up based on the model using the option “Set Up Web Service” – “Predictive Web Service”. The architecture of the created web service is shown in Figure 2.

To use the prediction model outside the Azure ML website service and to get this model ready for deployment, it is needed to convert the training experiment to a predictive one. To get this model ready for deployment. This involves three steps:

- 1. Save the model you’ve trained and then replace our training modules
- 2. Trim the experiment to remove modules that were only needed for training
- 3. Define where the web service will accept input and where it generates the output

One could do this manually, but fortunately all three steps can be accomplished by clicking Set Up Web Service at the bottom of the experiment canvas (and selecting the Predictive Web Service option).

Appropriate simplification of the architecture by removing some blocks and adding a transformed dataset. The simplified architecture of the web service is shown in Figure 3. The service includes: a trained model, a transformed dataset, a model testing block, as well as the input and output of the web service. The transformed dataset is the input dataset to which all data processing operations have been applied. The saved trained model is added back into the experiment. Web service input and Web service output modules are added (these identify where the user’s data will enter the model, and what data is returned, when the web service is accessed).

When the web service is accessed, the user’s data enters through the Web service input module where it’s passed to the Score Model module and scored. The way you’ve set up the predictive experiment, the model expects data in the same format as the original credit risk dataset. The results are returned to the user from the web service through the Web service output module.

## FEATURES OF REGRESSION ANALYSIS IN MACHINE LEARNING

When forming the structure of the experiment in the Microsoft AML studio, the predictive analysis algorithm block is added to the “Train Model” block. Available algorithms include neural networks, search trees, clusters, and various types of regression algorithms. In this work, among a number of proposed ones, we focused on the multiple regression algorithm. First, as it can be seen from the name of multiple linear regression, it is assumed that the relationship between the variables is linear. In fact, this conjecture can, in fact, be proven at any time. Multiple regression analysis procedures are slightly affected by small deviations from this assumption. However, it always makes sense to look at two-dimensional scatterplots of the variables of interest. If the non-linearity of the relationship is obvious, it is possible to consider whether the transformation of the variables or explicitly allow the inclusion of non-linear terms. In multiple regression, it is assumed that the residuals (predicted values minus the observed values) are normally distributed (that is, follow the law of normal distribution).
