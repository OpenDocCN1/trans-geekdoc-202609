This is due to the limitations of the machine learning technology used and the Microsoft AML Studio. The input data for training the model is provided as a dataset created in csv format. The data of the dataset is fed to the input of the block that implements the selection of columns used for further training. In this case, the block selects all columns except the first one, which contains the serial numbers of the objects. Columns are selected using the “Column selector” tool, the interface of which is shown in Figure 1. With the help of a script written in the Python programming language, columns of the dataset containing parameters of objects of a type that are not considered in a particular experiment are removed. For example, in the current task there was a deletion from further studies, the columns that related to the production of energy by wind and solar power plants, the analysis of which was transferred to the second stage of studies.

The “Clean Missing Data” block deletes the terms of the dataset in which there are empty values.

The cleaned dataset enters the input of the “Split Data” block, which divides the dataset into data for training the model and data for testing. In this model, 75% of the time is allocated for model training.

Regression using a neural network is used to predict the output values. The neural network approach has advantages over traditional methods in three cases:

+   - when the task under consideration due to specific features does not lend itself to adequate formalization, as it contains elements of uncertainty that cannot be formalized by traditional mathematical methods;
+   - when the task under consideration is formalized, but there is currently no apparatus for solving it;
+   - when there is a suitable mathematical apparatus for the considered, well-formalized problem, but the implementation of calculations with its help on the basis of computer systems does not satisfy the requirements for obtaining solutions in terms of time, size, weight, energy consumption, etc.
