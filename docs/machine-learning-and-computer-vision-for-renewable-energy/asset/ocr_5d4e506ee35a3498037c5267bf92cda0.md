If the correlation coefficient is very high, it clearly indicates that that the predictor is explained by another predictor. Multicollinearity can also be detected using the variance inflation factor (VIF). To find the VIF, it is necessary to perform an auxiliary regression on all predictors. For the above equation, the auxiliary regression equation for \(X_1\)

```
\(X_1 = \beta_0^* + \beta_2^*(X_2) + \beta_3^*(X_3) + \beta_4^*(X_4) + \varepsilon^*\) .
```

This will help to understand how much \(X_1\) is explained by other predictors. If the \(R^2\) of this model is equal to \(RX_1\), then the variance inflation factor,

```
\(VIF = \frac{1}{1 - R - X_1^2}\) .
```

This means that the higher \(R - X_1^2\), the higher it will be VIF. A larger VIF value indicates that \(X_1\) is explained by other predictors. Likewise, the VIF of all other predictors should be calculated to test whether this predictor is explained by another predictor. To overcome this, it will be necessary to find out whether two predictors give the same information, in which case one of them is removed. When deleting, care must be taken to eliminate missing variables. Another method is to convert correlated predictors into a single predictor.

**Independent variables should have a small measurement error.** The accuracy of the regression model corresponds to the accuracy of the input data. If the independent variables have many errors, the model cannot be considered accurate. When performing regression analysis, it is very important to use data sets only from known and trusted sources to be sure that errors are small. It is assumed that the error e has a normal distribution, that is, the mean value is zero (the sum of all errors will be zero (0) or almostly 0), and the variance \(\sigma2\) error terms is equal to e~ N(0,2).

Normality is violated when the error variance is not consistent across observations. For example, when a linear regression model is used to express the insurance payout as a function of the customer's age. Insurance will not be claimed by all individuals who have chosen insurance. So there will be a lot of zero claims alongside a few very high claims. If the sample size is very large, the central limit theorem will apply and the error variance will be consistent across all observations. But for a small sample size, this will affect the standard errors of the inference. This can be easily detected by constructing a histogram of residuals.

**The expected sum of non-connections should be equal to zero.** The variance is the difference between the expected and observed values in a regression analysis. Values observed above the regression curve have a positive lag value, and values below the regression curve have a negative value. The regression curve should pass through the center of the data points. Accordingly, the sum of non-connections should tend to zero. The sum of the values can be determined in the summary table.

**Disjoints must have uniform variability.** The value of the variability must be the same for all non-connections. This assumption is tested using a scatterplot of correlations (y-axis) and estimated values (x-axis). The final dot plot is displayed as a horizontal bar with randomly scattered points across the area.

**The distribution of non-connections should be normal.** The normal distribution – a curve in the form of a parabola – is a natural distribution, where a high frequency of the phenomenon is observed
