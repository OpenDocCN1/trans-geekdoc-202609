### One-Class SVM With Distance Substitution Kernels

Under normal circumstances, one ought to use exogenous subsequences as a benchmark for normality in various applications. In One-class support vector machines, literature advises on the use of a semi-supervised learning approach to learn the normal regions of space. Any instance that does not belong to the hypersurface is rejected by the One-Class SVM once it has learned the bounds of the encompassed hypersurface having the normal data set. Formally speaking, the approach strives for high-dimensional data distribution support (Harrou et al., 2019).

It is vital to use extrinsic subsequences as a standard of normality in many applications. One-Class Support Vector Machine, a semi-supervised learning algorithm, can be used to acquire knowledge of the normal regions of space. The One-Class SVM eliminates any scenario that is not related to the hypersurface after learning the bounds included hypersurface, which includes the normal data class. Formally speaking, the approach looks for a high-dimensional data distribution's support (Harrou et al., 2019). The sustenance of a random variable distribution X: \(\Omega \rightarrow R^n\) in the probability space \((\Omega, A, P)\) is the smallest subset \(R_x^n \subseteq R^n\) such that \(P(x \in R_x^n) = 1\). This study as such uses the One-Class SVM recommended by (Melakhssou et al. 2023) expressed by the quadratic optimization problem

```
min \frac{1}{2} \omega^2 - \rho + \frac{2}{\nu N} \sum_{i=1}^N \xi_i ;
s.t : \omega, x_i \ge \rho - \xi_i, \xi_i \ge 0
(1.1)
```

Melakhssou et al. (2023) state that \(\omega\) is the distance between the origin and the hyperplane, and \(\omega\) is a vector normal to the hyperplane. In addition, \(\nu \in [0,1]\) is a slack variable that accounts for outliers and represents the proportion of aberrations in the training set. \(\xi\) represents the extra variables needed to correct for outliers; it is a proportion of anomalous in the training set.
“The objective of the One-Class SVM (left panel of Figure 1) is to identify a hyperplane that optimizes the disparity between the space origin and the typical training data” Melakhssou et al. (2023) The percentage of anomalies in the training data, which serves as both an upper bound and a lower limit on the percentage of support vectors, controls the soft-margin problem. To train the One-Class SVM to recognize nonlinear decision boundaries in Figure 1’s right panel, the dual problem projects the input data into a high-dimensional space where it is linearly separable using a nonlinear kernel. The following is the twofold problem;

```
min \sum_{i=1}^N \alpha_i \alpha_j k(x_i, x_j)
s.t : 0 \le \alpha_i \le \frac{1}{\nu N},\sum_i^N \alpha_i = 1
(1.2)
```

where \(\alpha_i\) represents Lagrange multipliers, \(k\)th kernel function, and \(N\) the quantity of training data. One-Class SVM employs a decision function, which is defined below, to decide whether an instance \(x^T\) is normal by determining whether it corresponds to the typical data hypersphere;

```
F(x^T) = \left( \omega \phi(x^T) - \rho \right) = \left( \sum_i^N \alpha_i k(x^T, x_i) - \rho \right),
(1.3)
```

and the forecast is calculated as;

```
\left\{ \begin{array}{l} Normal, F(x^T) > 0 \\ Abnormal \end{array} \right.
(1.4)
```

The decision function \(F(x^t)\), which yields the anomaly score, has a value of smaller when the instance is more anomalous. In contrast to prior approaches requiring proximity to all training data, equation (1.4) computes the decision function just using the support vectors, i.e., the training instance \(x_i\) with \(0 \le \alpha_i \le \frac{1}{\nu N}\). This allows for a faster prediction. Originally, the One-Class SVM was developed for vector data. As such, its application to direct learning from structured sequences, like time series sub-sequences, has not received much attention (Aggarwal and Aggarwal, 2017). Prior research employing this approach converts each sequence into vector information. However, one needs to figure out how to turn the time series into vectors to employ One-Class SVM.

Indeed, to process raw subsequences or time series, a way must be found to incorporate the dissimilarity measure into the kernel instead of having to convert the subsequence into a set of vectors. According to research by Harrou et al. (2019), a class of kernels exists that enables the integration of dissimilarity measures and the conversion of methodological kernels into dissimilarity-based techniques. In One-Class SVM, we use these kernels, sometimes referred to as Distance Substitution (DS) kernels, to immediately acquire normal areas from the original sub-sequences. The DS kernels are determined by the relationship provided between the scalar product and the distance \(d\) given as;

```
\(x,x^T = -\frac{1}{2}(d(x,x^T) - d(x,0) - d(x^T,0)).\) (1.5)
```

The kernels are defined according to the equations incorporating the identity in equation (1.5)

```
\(K_{linear} = x,x^T\)
```

```
\(K_{polynomial} = (1 + x,x^T) p\)
```

For the distance to be a metric and the kernel to be definitively positive and so a Mercer kernel, it must meet the following requirements to guarantee that the problem of optimization is convex.

- **Symmetry:** \( d\left(x, x^T\right) = d\left(x^T, x\right) \)

- **Separation:** \( d\left(x, y\right) = 0 \Rightarrow x = y \)

- **Positivity:** \( d\left(x, y\right) > 0 \)

The triangular inequality: \(\forall x,y,z,d(x,z)\le d(x,y)+d(y,z)\).

“For any given metric, the linear, polynomial, and RBF DS kernels guarantee the presence of a domain A to where the data X has been projected from the starting point by \(\phi: X\rightarrow A, x\rightarrow\phi(x)\). The similarities in A are computed with the kernel trick without going through the projection: \(K(x,x^T)=\phi(x)\cdot\phi(x^T)\). The new objective function that replaces the one in equation (1.2) is given in equation (1.6) as;

```
\(\min \sum_{i,j}^N \alpha_i \alpha_j DSK\left(S^i, S^j\right), \quad (1.6)\)
```

where S is the collection of training sub-sequences and DSK is a DS kernel. Therefore, convexity may be guaranteed with a DS kernel using any metric dissimilarity” (Melakhssou et al., 2023).
