# Class Diagram

A class diagram is a static structure diagram in the Unified Modelling Language (UML) used to depict the structure of a software system as shown in figure 4. It presents the system’s classes, their attributes, operations (or methods), and the relationships between the classes, showing which class holds particular information.

# 4. SEQUENCE DIAGRAM

A sequence diagram is a type of diagram that illustrates the interactions between objects in a particular scenario in a time-based order. The diagram shows the objects and classes involved in the scenario and the messages they exchange to achieve the desired functionality. Sequence diagrams are usually related to the implementation of use cases in the system, and they may also be referred to as event diagrams or event scenarios.
