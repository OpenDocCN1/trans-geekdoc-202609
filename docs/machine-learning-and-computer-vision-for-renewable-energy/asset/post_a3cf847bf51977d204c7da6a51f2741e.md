
arg min_{f \in \mathcal{F}} \sum_{i=1}^N L \left( y_i, \hat{y}_i \right). \quad (13)

In equation (13), N denotes the total training sample. If the CART algorithm is used as base learner, then the base function is now given by

f_i \left( x_i \right) = w_{c(x_i)} \quad (14)

where w \in R^T, c: R^d \mapsto \{1, 2, ..., T\}. Here, T is the number of leaves. For an input x \in R^d, the outputs c(x) are the corresponding estimation values of the leaf node for a decision tree and, Moroke and Makatjane (2022) declared that gradient boosting aims to minimize the loss function L(y, f(x)) in every iteration. When the loss function is estimated by L(y, f(x)) = 1/2(y - f(x))^2, the gradient itself becomes a residue. Consequently, the decision trees fit this residue of all previous stages each time, and from this time,

\tilde{y} = \frac{\partial L \left( y, f \left( x \right) \right)}{\partial f \left( x \right)} = \frac{1}{2} \frac{\partial \left( y - f \left( x \right) \right)^2}{\partial f \left( x \right)} = y - f \left( x \right). \quad (15)

In summary, the pseudo-code of GBDT algorithm is presented in Algorithm 1.

```
**Algorithm 1:** *Gradient Boosting Decision tree*
Initialize: f_0(X)=0, \eta, d0 = 0
for j=1,...,M do
\omega_i = exp \left( -y_i f_{j-1} \left( x_i \right) \right), i=1, \cdots, N
r_i = -y_i, i=1, ..., N
S = \left\{ \left( x_i, \omega_i, r_i \right) \right\}_{1, ..., N} and v = \left\{ x | x \in \Re \right\} here, v is a shrinkage factor to training data and the classifier.
R = GROWTREE(s, v, \eta \theta d0)
f_j \left( x \right) = f_{j-1} \left( x \right) - v \cdot \sum_{k=1}^{|\Re|} \eta_k \delta \left( x \in \Re_k \right),
where \Re_k, \eta_k \in R
end
Procedure SPLITLEARNING(S)
\left( \eta^{t_\epsilon}, \eta^{t_\epsilon *} \right) = arg min_{\eta^{t_\epsilon}, t_\epsilon} \varepsilon \left( \tau \right) \text{ in equation 13 }
Return \left( \eta^{t_\epsilon}, \eta^{t_\epsilon *} \right)
```

There is a trade-off between time complexity and precision when using a Kalman filter. The GBDT algorithm is trained in batch mode, which eliminates multiple hidden layers in deep learning. It turned out to be rather simple to train for the decision trees because this method no longer has any deep hidden layers. However, the accuracy of such a method slightly decreases due to lack of deep nonlinear mappings. But, given its time-saving feature, we contend that the suggested method is useful as long as the accuracy decline is acceptable.

## Forecasting Performance of Hourly Wind Power Generation

Firstly, the performance of our proposed GBDT-KF algorithm under different number of decision trees is compared. The processing scale and centre of the algorithm are set to 450 and re-sampling is cross-validated at 10 fold which is repeated 3 times. Tuning parameter ‘shrinkage’ is held constant at a value of 0.01; while, tuning parameter ‘n.minobsinnode’ is held constant at a value of 50. The performance is measured using mean square error (MSE), root mean square error (RMSE), mean absolute error (MAE) and mean absolute percentage error (MAPE) of GBDT-KF with different number of CART regressors. Grid search is used to determine the initial parameters for Kalman filter, and the maximum depth of a single regression tree is set to one, two and three. The final values used for the model are n.trees = 450, interaction.depth = 3, shrinkage = 0.01 and n.minobsinnode = 10. As recommended by Tien et al. (2016) and Subramani et al. (2023), all the condition factors are removed with null predictive values. Experimental results show that the error matrices used decrease as the number of trees grows. In general, the more the base learners (CART), the better the prediction precision in the test dataset. However, as the number of regression trees exceeds 2000, we find that the performance drops due to overfitting of the model.

An alternative perspective holds that the GBDT-KF ensemble’s performance and that of each base learners are influenced by the depth of the regression tree. Regression trees with more depth according to Hu et al. (2023) are typically predicted to better suit training sets. In this chapter, we keep hourly wind power generation to 1500 gigawatts and altered the depth of regression tree from 1 to 10. Thus, we assess the performance of GBDT-KF model. Figure 3 outlines this procedure and shows that, for an hourly wind power generation dataset, performance peaks when the depth equals 6 and thereafter declines beyond depth of 7. Similar results are found in the work of Li et al. (2020) who found that at depth 7, the model begins to produce worse results.
