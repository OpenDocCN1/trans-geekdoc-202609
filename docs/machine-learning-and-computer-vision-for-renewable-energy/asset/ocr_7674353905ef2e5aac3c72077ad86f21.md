The Date column contains data in the following format: time – “dash” – date. Thus, there are 24 measurements for each date. For 2018, the table contains 8,760 rows of measurement data. To use Excel data in ML Studio, the xlsx file must be saved as a csv (comma separated data) file. But, due to the European localization, such file does not contain commas as data separators, but semicolons (Figure 10), which is a common problem in programming when converting data from a graphic user interface into a program code.

This file can be opened in Windows Notepad and automatically replace the “semicolon” symbol with “comma”. The result of such replacement is shown in Figure 11.

The generated data is added as a dataset to the ML studio (Figure 12). The next step is to create a new experiment in Microsoft AML Studio. The first block of such experiment is the dataset input data in the My Datasets category, which was prepared earlier. It is enough to drag the dataset from the side menu to the model field (Figure 13).

If to preview the table data (Figure 14), it contains 653 missing values (empty cells or rows). To automatically extract such data, the Clean Missing Data block is used, with the settings shown in Figure 15.
