# B. Random Forest (RF)

RandomForest (RF) is a widely adopted machine learning technique designed to address the high variance associated with Decision Trees (DT). It functions as an ensemble of numerous unpruned independent decision trees, each fitted on training data using the bagging method to capture non-linear relationships effectively (Sing et al., 2019). The learning process initiates by creating a bootstrapped dataset through random sampling from the original one, allowing each observation to be selected multiple times. Typically, about two-thirds of the training data constitutes the bootstrapped dataset, while the remaining portion forms an “out-of-bag” (OOB) set utilized for evaluation purposes.

When dealing with an input featuring a total of m features, each decision tree is constructed by randomly selecting a subset of k from the m features (where k belongs to m). Each tree is allowed to grow to its full extent. In the context of regression analysis, the final output ŷ(x) represents the average prediction across all trees, as indicated in equation (4), where K denotes the number of trees, and hi(x) signifies the output prediction for the ith tree. In the case of classification tasks, RF employs the majority vote from all trees as its ultimate output.

```
\hat{y}(x) \frac{1}{K} \times \sum_{i=1}^{k} h_i(x) \quad (4)
```

# C. Gradient Boosted Decision Tree (GBDT)

Gradient Boosted Decision Tree (GBDT) is an additional ensemble machine learning algorithm based on trees, employing hundreds of Decision Trees (DTs) as base learners (Kaya et al., 2020). These trees are constructed sequentially, with each tree giving more emphasis to the misclassifications made by the preceding one. GBDT is a highly popular method extensively utilized in both regression and classification tasks. Given a set of n input observations, (xi, yi) where i ranges from 1 to n, and a differential loss function L, GBDT begins by making an initial prediction, as depicted in equation (5). This equation aims to determine an initial value γ that minimizes the sum of the loss function across all observations before commencing the training iterations.

```
F_0(x) = argmin_\gamma \sum_{i=1}^N \mathcal{L}(y_i, \gamma_i) \quad (5)
```
