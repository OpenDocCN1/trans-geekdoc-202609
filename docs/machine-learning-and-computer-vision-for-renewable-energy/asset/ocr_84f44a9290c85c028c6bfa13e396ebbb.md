# ## Blackbox Testing

The Black-box testing is a testing technique in which the tester does not have access to the internal workings or source code of the application. Instead, the tester interacts with the system’s user interface by providing inputs and examining outputs, without any knowledge of how the system processes the inputs.

# ## Whitebox Testing

White-box testing is a method of examining the internal structure and logic of software code. It is also known as open-box testing or glass-box testing. To conduct white-box testing, a tester should have knowledge of the application’s internal operations. They need to examine the source code and identify which part of the code is not performing as expected.
