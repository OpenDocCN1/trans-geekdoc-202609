# Short- and Medium-Term Forecasting Results

To check the model performance on short (i.e., accuracy) and medium-term (i.e., stability) horizons, a random sample of 700 data points were selected uniformly from various time ranges from one week to several months, as shown in Table 3. The mean of the performance metrics values is computed for each range. Results show that error values are consistent with a low standard deviation. The accuracy measured by CV (RMSE) is 0.60% for the short term and an average of 0.56% for the medium term. With very comparable performances for both the short-term and medium-term horizons, it is obvious that the estimated TBATS-CNN_LSTM is accurate and stable.
