# Activity Diagram

An Activity Diagram is a visual representation that depicts a sequence of actions or steps in a process as shown in figure 5. It includes various elements that support decision-making, repetition, and simultaneous execution. In the Unified Modeling Language (UML), Activity Diagrams are designed to model workflows and processes, including the flow of data associated with these activities. While the primary focus of Activity Diagrams is to illustrate the overall flow of control, it can also contain elements that show the movement of data between activities via one or more data stores.
