- Mean Absolute Error (MAE) – defines the average absolute value of the error between the actual and predicted values.
- The Root Mean Square Error (RMSE) is the root mean square error, which takes into account the deviation of each point from the mean multiplied by the number of observations.
- Relative Absolute Error (RAE) is the relative absolute error that determines the relative accuracy of the forecast compared to the output.
- Relative Squared Error (RSE) is the relative squared error that takes into account the deviation of each point from the mean multiplied by the number of observations.
- Coefficient of determination (R-squared) is a coefficient of determination that indicates how well the model explains the variance of the original data. The overall rating for each source of electricity is presented in the Table 2.

The general trend is that the models for AES, TES, and Block TES proved to be quite accurate and efficient in predicting energy parameters. In contrast, the model for GES appears to be less efficient, possibly due to a greater dependence on variational wind conditions.

## CONCLUSION

In the course of the work, an attempt was made to apply ML technology to forecasting the consumption of electrical energy produced within the country by various types of power plants. The obtained results showed a high convergence of real historical data and those found through predictive analytics of the Microsoft Azure Machine Learning service. This provides grounds for further research development and improvement of the developed model. The set of standard blocks of the Microsoft Azure Machine Learning Studio is not fully able to meet the needs for a large variety of problems that are solved. This paper demonstrated how to implement user blocks with Python scripts for initial, intermediate and final data processing, including graphing.

In this paper, in addition to a detailed description of the method of building a model based on the machine learning service, it was shown how to deploy the project for its further use without the Microsoft Azure web service. The API service has been integrated into a Microsoft Excel spreadsheet and allows to perform predictive calculations even in the absence of an Internet connection. The results of the forecast show a very high convergence with real data, and the accuracy of the forecast (coefficient of determination) does not fall below 0.8.

The authors' next research will consist in improving the developed model and adding to the dataset data of various categories of electricity consumers, considering periodic shutdowns and startups of power units, emergency modes, etc. Another related line of work is the development of VBA scripts for Microsoft Excel to improve the interactivity for the end user, the machine learning unit and the results of the forecast execution and their interpretation.
