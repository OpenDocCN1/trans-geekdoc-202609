Each regression method has several assumptions that must be met in order for the equation to be considered reliable. Assumptions, for example, for Method of Least Squares (MLS), must be tested when building a regression model. The following assumptions must be verified and satisfied when using the MLS method.

## The model must be linear.

MLS regression is used only when building a linear model. The linear relationship between the dependent and independent variables can be checked using a dot (scatter) diagram. The dot plot matrix can test all variables, provided that no more than 5 variables are used in total. In the case of multiple regression of each pair of variables, scatter diagrams should be constructed. Figure 6 shows how a data set of linear relationships would appear on a scatterplot. If such a graph is obtained, as in Figure 7, which has an exponential form, then logarithmic transformation into a linear one can be used. In the absence of a linear relationship between the data points or if the data cannot be transformed into a linear one, it is necessary to perform a non-linear regression analysis, which will be discussed in detail in the following lectures.

## The data must be randomly distributed.

The data used in the regression analysis must be randomly distributed, that is, the data samples must not depend on an external factor. Arbitrary distribution can be tested by using discontinuities in the regression model. Covariances calculated as output from a regression model should not be correlated when plotted on a scatterplot or scatterplot matrix with the independent variables. In this case, the concept of the absence of heteroskedasticity is considered. For a linear relationship, if the variance is not constant and increases as the predictor (X) increases, this is called heteroskedasticity. In such cases, the standard error of the derivation cannot be relied upon, but the coefficients will still be unbiased.

The best way to detect heteroskedasticity is to use a scatterplot of the residuals against the value of X. Heteroscedasticity can be avoided by performing a log transformation or by examining the bias of the omitted variables, or by identifying outliers and trying to remove them.

- **Independent variables should not be collinear**. Collinearity is a linear relationship between independent variables that creates redundancy in the model. In some cases, the model is created with collinearity. However, if one of the collinear variables depends on the other, it may be worth removing it from the model. Collinearity can be estimated using a dot plot or dot plot matrix of independent variables. Predictors should not be correlated with the error term. This can be represented by the equation below:

\(\sigma X \epsilon = 0: \forall x, \epsilon.\)

If the predictors are correlated, this is called omitted variable elimination. This occurs when a predictor is excluded, and this is reflected in the error term, leading to biased and counterintuitive estimates. It can be found by examining the correlation between predictors. Thus, when estimating the amount of wages based only on the number of years of education, the variable error is not taken into account. Because the salary depends on many other factors, such as the type of education, additional socio-economic status. But still, it can be used for predictions.

A concomitant feature of the correctness of regression analysis is the absence of multicollinearity. If the multiple linear regression is represented as

\(Y = \beta_0 + \beta_1(X_1) + \beta_2(X_2) + \beta_3(X_3) + \beta_4(X_4) + \varepsilon ,\)

then ideally no predictor should be explained by another predictor.

Multicollinearity occurs when the predictors themselves are correlated. To determine whether multicollinearity exists between predictors, the correlation between all pairs of predictors must be examined.

If the correlation coefficient is very high, it clearly indicates that the predictor is explained by another predictor. Multicollinearity can also be detected using the variance inflation factor (VIF). To find the VIF, it is necessary to perform an auxiliary regression on all predictors. For the above equation, the auxiliary regression equation for \(X_1\)

\(X_1 = \beta_0^* + \beta_2^*(X_2) + \beta_3^*(X_3) + \beta_4^*(X_4) + \varepsilon^*\) .

This will help to understand how much \(X_1\) is explained by other predictors. If the \(R^2\) of this model is equal to \(R_{X_1}^2\), then the variance inflation factor,

\(VIF = \frac{1}{1 - R_{X_1}^2}\) .

This means that the higher \(R_{X_1}^2\), the higher it will be VIF. A larger VIF value indicates that \(X_1\) is explained by other predictors. Likewise, the VIF of all other predictors should be calculated to test whether this predictor is explained by another predictor. To overcome this, it will be necessary to find out whether two predictors give the same information, in which case one of them is removed. When deleting, care must be taken to eliminate missing variables. Another method is to convert correlated predictors into a single predictor.

- **Independent variables should have a small measurement error.** The accuracy of the regression model corresponds to the accuracy of the input data. If the independent variables have many errors, the model cannot be considered accurate. When performing regression analysis, it is very important to use data sets only from known and trusted sources to be sure that errors are small. It is assumed that the error e has a normal distribution, that is, the mean value is zero (the sum of all errors will be zero (0) or almost 0), and the variance \(\sigma^2\) error terms is equal to e~ N(0,2).

Normality is violated when the error variance is not consistent across observations. For example, when a linear regression model is used to express the insurance payout as a function of the customer's age. Insurance will not be claimed by all individuals who have chosen insurance. So there will be a lot of zero claims alongside a few very high claims. If the sample size is very large, the central limit theorem will apply and the error variance will be consistent across all observations. But for a small sample size, this will affect the standard errors of the inference. This can be easily detected by constructing a histogram of residuals.

- **The expected sum of non-connections should be equal to zero.** The variance is the difference between the expected and observed values in a regression analysis. Values observed above the regression curve have a positive lag value, and values below the regression curve have a negative value. The regression curve should pass through the center of the data points. Accordingly, the sum of non-connections should tend to zero. The sum of the values can be determined in the summary table.

- **Disjoints must have uniform variability.** The value of the variability must be the same for all non-connections. This assumption is tested using a scatterplot of correlations (y-axis) and estimated values (x-axis). The final dot plot is displayed as a horizontal bar with randomly scattered points across the area.

- **The distribution of non-connections should be normal.** The normal distribution – a curve in the form of a parabola – is a natural distribution, where a high frequency of the phenomenon is observed close to the mean value, where the frequency decreases as the distance from the mean increases. In statistical analysis, the normal distribution is often used as a null hypothesis. If the distribution of linkage disequilibrium is normal, the line of best fit passes through the center of the observed data points, rather than diverging, approaching some and deviating from others. This assumption can be checked by constructing a histogram of the connections. The normal distribution curve may not fit on the card and the skewness and kurtosis are carried over to the back of the histogram card.

- **Adjacent lags should not exhibit autocorrelation.** This assumption is based on the chronology of the data. If the data follows a timeline, each data point must be independent of the previous or subsequent data point. Therefore, when performing regression analysis, it is important to make sure that the chronological order of the data corresponds to the normal course of time. This assumption is calculated using the Durbin-Watson test.

The Durbin-Watson test measures the autocorrelation of the lags in a regression model. The Durbin-Watson test uses a scale from 0 to 4 where values from 0 to 2 indicate positive autocorrelation, 2 indicates no autocorrelation, and 2 to 4 indicates negative autocorrelation. That is, to meet the assumption of no autocorrelation of the links, a value close to 2 should be obtained. In general, values between 1.5 and 2.5 are considered acceptable, and values less than 1.5 or greater than 2.5 indicate that the model does not meet the assumption of no autocorrelation. The values of the error terms must not have any identifiable relationship: \(\sigma \epsilon_i \epsilon_j = 0, \forall i \neq j.\)

If there is any relationship between the values of the error term, then autocorrelation appears. Autocorrelation is also known as serial correlation, which affects the standard errors without affecting the coefficients, which will be unbiased. This is not observed in cross-sectional data, but is reflected in time-series data such as stock prices. For stock price analysis, the phenomenon of the day of the week effect suggests high returns on Fridays and low returns on Mondays. Monday’s errors will be shifted down, and Friday’s errors will be shifted up.

The main cause of autocorrelation is related to missing variables or incorrect functional forms. A common way to detect autocorrelation is to plot a scatterplot of all residuals and look for patterns. If there are no patterns, it means there is no autocorrelation. The Durbin-Watson test method can be used to find autocorrelation. If there is a pattern, autocorrelation exists and it is better to avoid linear regression models and use an autoregressive model, or a moving average model, or an autoregressive moving average model, or an autoregressive integrated moving average model.

## Suitability of the model.

The accuracy of the regression equation is the basis of regression analysis. All models will have some error, but understanding these statistics will help you determine whether the model can be used for your analysis, or whether additional transformations are necessary. There are two methods of testing the correctness of a regression model: **exploratory analysis** and **confirmatory analysis**.

**Exploratory analysis** is the technology of data analysis using various statistical and visual methods. As part of the exploratory analysis, the MLS regression assumption is tested and the performance of various independent variables is compared. Exploratory analysis allows to compare the performance and accuracy of different models, but it cannot determine whether you should use or reject a particular model. Exploratory analysis must be conducted before the analysis of confirmation of each regression model, possibly several times, comparing different models.
