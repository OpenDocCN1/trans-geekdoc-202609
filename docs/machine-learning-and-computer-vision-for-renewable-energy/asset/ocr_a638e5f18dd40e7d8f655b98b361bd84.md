+   2) **Input gate**: In Figure 2, the input gate determines which new information to remember in cell state. By entering the output \( h_{t-1} \) at the previous time \( t-1 \) and adding the current time \( t \) and an input \( X_t \) into a \( Sigmois \) function as defined in equation (4) a value \( i_t \) in equation (5) that is between 0 and 1 is generated to decide how much new information cell state need to be remembered. At the same time, a tanh in Figure 3 layer obtains an election message \( \tilde{C}_t \) defined in equation (6) to be added to the cell state by inputting the output \( h_{t-1} \) at the previous time \( t-1 \) and adding the current time \( t \) and an input information \( X_t \). Multiply the values \( i_t \) and \( \tilde{C}_t \) just obtained by the \( Sigmoid \) function to get the updated information that we really want to add to the cell state \( C_t \) in equation (7).
