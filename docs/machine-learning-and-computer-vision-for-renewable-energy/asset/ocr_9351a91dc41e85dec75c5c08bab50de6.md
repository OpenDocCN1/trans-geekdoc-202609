# 4.2 MNIST Database

A training set of 60,000 samples and a test set of 10,000 examples comprise the MNIST database of handwritten digits. This is part of a bigger set that NIST is making public. In a fixed-size image the digits have been centered and size-normalized. With little effort required for formatting and preprocessing, it's a useful database for those wishing to test learning strategies and pattern recognition algorithms on actual data. NIST's Special Databases 3 and 1, which include binary images of handwritten numbers, were used to build the MNIST database. At first, NIST used SD-3 as a training set and SD-1 as a test set. Nonetheless, SD-3 is far more recognizable and cleaner than SD-1. The distinction between the SD-3 and SD-1 surveys—which were conducted among Census Bureau employees and high school students, respectively—explains why this is the case. In order to make sense of learning studies, the outcome must be unaffected by the training set and test that are selected from the entire set of samples. As a result, combining several NIST datasets to create a new database was required. Thirty thousand SD-1 patterns and thirty thousand SD-3 patterns make up the MNIST training set. Five thousand patterns each from SD-1 and SD-3 made up our test set. Examples from roughly 250 writers were included in the 60,000-pattern training set (Badi & Shimura, 1982).
