# 4.12 MSRA Text Detection

Developed and made available to the public the MSRA Text Detection 500 Database (MSRA-TD500) serves as a benchmark for assessing text detection algorithms. It is intended to monitor the latest developments in the field of text detection in natural image particularly the progress made in identifying texts with variable orientations. 500 natural photos from interior (office and mall) and outdoor (street) settings were captured with a pocket camera and are included in the MSRA Text Detection 500 Database (MSRA-TD500). The training set and test set comprise the two halves of the dataset for the character set of this language. Out of the original dataset 300 photographs were randomly picked to form the training set, and the remaining 200 images were designated as the test set (Yao et al., 2012).

# 4.14 Chars74K Data

The objective is to investigate techniques for segmented handwritten character recognition from matching image files. The 64 classes (a-z,A-Z,0-9) in the Chars74K dataset are made up of 7705 characters that were taken from natural photos and 3410 characters that were hand-drawn on a tablet PC and 62992 characters that were substituted using computer typefaces. This yields more than 74K photos in total which accounts for the dataset’s name. Hindu-Arabic numbers and Latin letters use sans accents which are utilized in the English language. This is referred to as the English character set for simplicity. This dataset attempts to address three main sub-problems i.e., pre-processing photos, obtaining pertinent characteristics from the images and training an artificial neural network model to categorize the data points into classes (Lee et al., 2010).
