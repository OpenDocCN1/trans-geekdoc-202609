The second threat is concerned with the algorithms used in the different steps and components of the methodology, which could use some unrealistic assumptions inappropriate for the current chapter's case context. To avoid such a threat, all the algorithms are developed in this chapter.

The internal validity in the case of this chapter is concerned with three main threats. The first one is related to how much the data set is suitable to train a TBATS-CNN-LSTM model that needs a large amount of data to mine historical patterns. The ESKOM hourly electricity demand load data set ranges from April 2019 until October 2023. This data set is large enough to allow deep learning, which is particularly targeted by TABTS-CNN-LSTM. The second threat is that the TBATS-CNN-LSTMS error starts increasing while the training error still decreases. Too much training with a complex forecasting model leads to bad generalizations. To prevent overfitting for the TBATS-CNN-LSTM model, the training examples at each epoch were randomly shuffled. This helps to improve generalization. Furthermore, early stopping is also used, whereby training is stopped at the lowest error achieved on the test set. This approach is highly effective in reducing overfitting.
