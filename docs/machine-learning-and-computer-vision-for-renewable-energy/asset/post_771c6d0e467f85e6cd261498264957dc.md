
## Box-Cox Transformation

$$X_t^{(\omega)} = \begin{cases} \frac{X_t^\omega - 1}{\omega}, & \omega \neq 0 \\ \log(X_t), & \omega = 0 \end{cases}$$ (1)

## Seasonal Periods

$$X_t^{(\omega)} = l_{t-1} + \phi b_{t-1} + \sum_{i=1}^M S_{t-m_i}^{(i)} + d_t,$$ (2)

## Global and Local Trend

$$l_t = l_{t-1} + \phi b_{t-1} + \alpha d_t$$
$$b_t = \phi b_{t-1} + \beta d_t,$$ (3)

## ARMA Error

$$d_t = \sum_{i=1}^p \phi_i d_{t-i} + \sum_{j=1}^q \theta_j \iota_{t-j} + \iota_t$$ (4)

## Fourier Seasonal Terms

$$S_t^{(i)} = \sum_{j=1}^{k_i} S_{j,t}^{(i)}$$
$$S_{j,t}^{(i)} = S_{j,t-1}^{(i)} \cos \lambda_j^{(i)} + S_{j,t-1}^{*(i)} \sin \lambda_j^{(i)} + \gamma_1^{(i)} d_t$$
$$S_{j,t}^{*(i)} = -S_{j,t-1}^{(i)} \sin \lambda_j^{(i)} + S_{j,t-1}^{*(i)} \cos \lambda_j^{(i)} + \gamma_2^{(i)} d_t$$ (5)

Here, \(X_t\) is a time series (i.e., electricity load demand). Now, let \(X_t^{(\omega)}\) represents the Box-Cox transformation of \(X_t\) with the parameter \(\omega\), \(l_t\) being the local level in time t, then \(b_t\) is the short-term trend in time t, where \(\phi\) is the trend damping parameter. Furthermore, \(S_t^{(i)}\) denotes the \(i^{th}\) seasonal component at time t, and \(m_1, ..., m_T\) refers to seasonal periods, while \(d_t\) represents an ARMA (p, q) process and \(\iota_t\) a Gaussian white noise process with zero mean and constant variance. According to Munim (2022), \(\alpha, \beta, \text{and } \gamma\) are smoothing parameters for \(i=1,...,T\). Hence, \(\lambda_j^{(i)} = 2\pi j / m_i\), \(S_{j,t}^{(i)}\) represents the stochastic level of \(i^{th}\) seasonal component and \(S_{j,t}^{*(i)}\) represents the change (or growth) in the stochastic level of \(i^{th}\) seasonal component over time. ### Convolutional Neural Network

According to Badi et al. (2022) and Hussain et al. (2019), a convolutional neural network (CNN) is one of the most discriminatory algorithms. It uses layers made up of pooling layers and convolutional layers. Layers are stacked one on top of the other. The composite layers soften the convolutional layer release, which in turn lowers the amount of data rate from the lower layer (Alsayed et al., 2021). The CNN has given some invariance properties by the weight distribution in the convolutional layer and the appropriate selection of pooling schemes (Muhammad et al., 2021). Therefore, the CNN is one of the most effective deep learning (DL) vision algorithms used for image recognition and computer vision (Islam et al., 2020). In convolutional layer of the CNN, Abdul Majid and Ibrahim (2021) and Muhammad et al. (2020) showed that convolutional feature mapping from the previous layer is convolved with learnable kernels with non-linear or linear activation functions such as hyperbolic tangent, sigmoid, and softmax, among others, to output feature activation maps. As such, each feature map output combined with more than one input feature map is given by

$$x_j^i = f \left( \sum_{i \in M_j} x_i^{l-1} k_{ij}^l + b_j^l \right),$$ (6)

where \(x_j^i\) represent the output of the current layer, \(x_i^{l-1}\) is the previous layer output, \(k_{ij}^l\) is the kernel for the present layer, and \(b_j^l\) is biases for the current layer. \(M_j\) is the selection input maps while an additive bias \(b\) is each output map. At the pooling layer of the CNN, the number of input and output feature maps cannot change because if there are \(n\) input maps, then there must be exactly \(n\) output maps (Seetha and Raja, 2018). However, the size of each dimension of the output map will be reduced due to a down-sampling operation. The operation can be formulated with model (6) as

$$x_j^i = down \left( x_j^{l-1} \right).$$ (7)

### Long Short-Term Memory

Long short-term memory (LSTM) is used to solve learning models for recurrent neural networks (RNNs), yielding promising results on a variety of tasks, including building prediction and language models (Zhang et al., 2020). Recurrent neural network algorithms have never been able to solve complex long-time-lag tasks like those solved by the LSTM (Muhammad, et al., 2021). By substituting memory cells for the RNN hidden layer, the LSTM learning algorithm can learn long-term relationships (Li and Lima, 2021), making the algorithm to add or remove information to the cell state called gate. An input gate (\(i_t\)), forget gate (\(f_t\)) and output gate (\(o_t\)) can be defined as

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$ (8)

$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i),$$ (9)

$$\tilde{C}_t = \tanh(W_c [h_{t-1}, x_t] + b_c),$$
$$C_t = f_t C_{t-1} + i_t \tilde{C}_t,$$
$$O_t = \sigma(W_o [h_{t-1}, x_t] + b_o),$$
$$h_t = O_t \tanh(C_t)$$ (10)

### Convolutional Neural Network-Long Short-Term Memory

A potent combination of CNN-LSTM (Convolutional Neural Network-Long Short-Term Memory) has been proposed to limit the employment of CNN for getting invaluable knowledge and learning ability with greater efficiency of the LSTM algorithm in a time-series-internal-representation-dependent manner to dramatically detect as well as model the short- and long-term temporal interrelationships confided in the dataset order. To achieve the above mentioned aim, we propose a combined CNN-LSTM using two primary basic components, as follows:

- a one-dimensional CNN, which is made up of convolutional and pooling layers, and we then performs the mathematical procedure on the input data and thus generates the features.
- To make use of the generated features with the use of LSTM and dense layers.

Our proposed CNN-LSTM algorithm uses CNN as an encoder, while LSTM serves as the decoder. The encoder learns a feature from the input data and feeds it into a decoder (LSTM). The decoder then identifies and models both short and long-term temporal relationships that are inherent in the dataset. The sequence of events for each step is briefly given as follows:

- Input layer: receives the input data.
- First Convolution Layers: scans through the input information of the input layers prior to subjecting the outcomes to the feature maps.
- Second Convolution Layer: finds the feature maps again; in order to enhance any noteworthy features, 32 feature maps per convolution layer and a kernel size of three time steps to read the input sequence would be utilized.
- Max pooling layer: removes specific features from second convolution layer, thereby oversimplifying the feature maps and producing matrices with a small dimension.
- Dropout layer: enhances the learning network for securing the model from overfitting.
- Flatten layer: flattens the distilled feature maps into a single long vector that could be harnessed as input for decoding purposes.
- Repeat Vector Layer: the internal representation of the input sequence is repeated once for each time step in the output sequence.
- LSTM decoder: has a 100-unit hidden layer capable of outputting the full arrangement, each of which has 100 units providing a value on a daily basis, serving as the foundation for forecasting what would happen in the next few days in the output order.
- Fully connected layer: comprehends each step in the output sequence in order to end up having similar layers for forecasting a single sequence output, indicating that the LSTM decoder is capable of operating at any given time, akin to both output and fully connected layers.
- Output layer: electricity demand forecast for 10 days is forecasted. The reader is referred to Figure. 4 for more illustration.
