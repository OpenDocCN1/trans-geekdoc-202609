To achieve the above mentioned aim, we propose a combined CNN-LSTM using two primary basic components, as follows: (1) a one-dimensional CNN, which is made up of convolutional and pooling layers, and we then performs the mathematical procedure on the input data and thus generates the features. Our proposed CNN-LSTM algorithm uses CNN as an encoder, while LSTM serves as the decoder. The encoder learns a feature from the input data and feeds it into a decoder (LSTM). The decoder then identifies and models both short and long-term temporal relationships that are inherent in the dataset. The sequence of events for each step is briefly given as follows: Input layer: receives the input data. First Convolution Layers: scans through the input information of the input layers prior subjecting the outcomes to the feature maps. Second Convolution Layer: finds the feature maps again; in order to enhance any noteworthy features, 32 feature maps per convolution layer and a kernel size of three times steps to read the input sequence would be utilized. Max pooling layer: removes specific features from second convolution layer, thereby oversimplifying the feature maps and producing matrices with a small dimension; Dropout layer: enhances the learning network for securing the model from overfitting. Flatten layer: flattens the distilled feature maps into a single long vector that could be harnessed as input for decoding purposes. Repeat Vector Layer: the internal representation of the input sequence is repeated once for each time step in the output sequence; LSTM decoder: has a 100-unit hidden layer capable of outputting the full arrangement, each of which has 100 units providing a value on a daily basis, serving as the foundation for forecasting what would happen in the next few days in the output order; Fully connected layer: comprehends each step in the output sequence in order to end up having similar layers for forecasting a single sequence output, indicating that the LSTM decoder is capable of operating at any given time, akin to both output and fully connected layers.
