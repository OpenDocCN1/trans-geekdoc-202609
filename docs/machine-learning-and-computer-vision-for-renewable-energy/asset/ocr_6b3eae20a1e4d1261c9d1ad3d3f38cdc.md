**Confirmatory analysis** is the process of evaluating a model against the null hypothesis. In regression analysis, the null hypothesis states that there is no relationship between the dependent and independent variables. For a model with no relationships, the value of the slope is 0. If the elements of the confirmation analysis are statistically significant, the null hypothesis can be rejected (in other words, the existence of a relationship between the dependent and independent variables is statistically confirmed). The following statistical indicators are used to determine significance as a component of the analysis:

+   * F-statistics and the associated p-value;
+   * t-statistics and the associated p-value;
+   * confidence intervals.

The F-statistic is a global statistic returned by the F-test that shows the predictive power of the model by calculating regression coefficients in the model that are significantly different from 0. The F-test analyzes the combined effect of independent variables rather than evaluating each one individually. Associated with the F-statistic is the corresponding p-value, which is a measure of the probability that the deterministic relationship between the variables is due to chance. A small p-value, usually 0.05 or less, indicates that there are real relationships between variables in the model (that is, the revealed regularity is not random), which gives the right to reject the null hypothesis. In this case, the probability that the relationship in the model is random is 0.05, or 1 in 20. Or the probability that the relationship is real is 0.95, or 19 in 20.

The t-statistic is a local statistic returned by the t-test that shows the predictive power of each independent variable separately. Like the F-test, the t-test analyzes regression coefficients in a model that are significantly different from 0. Because the t-test is applied to each independent variable, the model will return a t-statistic value for each independent variable, rather than a single value for of the entire model. Each t-statistic value has an associated p-value that indicates the significance of the independent variable.

As with the F-test, the p-value for each t-test must be 0.05 or less to reject the null hypothesis. If the p-value for an independent variable is greater than 0.05, that variable should not be included in the model and a new model should be built, even if the global probability value for the original model indicates statistical significance.

Confidence intervals visualize the regression coefficients for each independent variable and can be 90, 95, and 99 percent. Therefore, confidence intervals can be used alongside t-test p-values to assess the significance of the null hypothesis for each independent variable. The regression coefficients must be equal to 0, only in this case you can reject the null hypothesis and continue using the model. Therefore, for each independent variable, the regression coefficient and the associated confidence interval cannot overlap with 0. If the 99% or 95% confidence intervals for this independent variable overlap with 0, this independent variable does not allow us to reject the null hypothesis. Including this model variable may negatively affect the overall significance of your model. If only the 90% confidence interval overlaps 0, the variable can be included in a model with satisfactory overall statistical significance. Ideally, the confidence intervals for all independent variables should be as far from 0 as possible.
