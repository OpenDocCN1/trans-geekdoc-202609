
## Electricity Production Prediction by Microsoft Azure

### EXPERIMENT DEVELOPMENT IN THE MICROSOFT AZURE MACHINE LEARNING STUDIO

ML is the use of mathematical models of data to help a computer learn without instructions. It is considered one of the forms of artificial intelligence (AI). In ML with the help of algorithms, data patterns are revealed. Based on these regularities, a data model for forecasting is created. The more data such a model processes and the longer it is used, the more accurate the results become. This is very similar to how a person hones skills in practice. The adaptive nature of ML makes it great for scenarios where data is constantly changing, query or problem properties are unstable, or writing code to solve is virtually impossible.

Usually, when solving complex problems of predictive analytics with a large amount of both input data and data categories, a problem arises in the need for large computing capacities. One of the solutions to the problem arising from complex calculations is the use of the computing power of the Microsoft cloud cluster and machine learning technology based on the Microsoft Azure service.

The result of this work is an independent service built into Excel, which allows to perform a consumption forecast by the specified date. Separate results of the forecast are the assessment of the quality of the obtained indicators of electricity consumption.

Any predictive experiment in AML studio is based on a set of input data. The more of them and the more diverse they are in determining the target parameter, the more accurate the forecasting results will be. The Excel file for this work was provided by the forecasting department of NEC “Ukrenergo”, Ukraine (Pliuhin et al., 2021) and contains data¹ on the time and date of readings, energy production by various types of power plants (Figure 9): AES is the nuclear power plant (spells as Atomic Electric Station); TES – is the thermal power plant (spells as Thermo Electric Station); Block TES is the block thermal power plant (spells as Block Thermo Electric Station); HES is the hydroelectric power station (spells as Hydro Electric Station).

In the data table, as indicated above, one date has 24 measurements, that is, every hour. The use of such format is atypical and cannot be properly analyzed. There are no library units in the AML studio to solve such kind of problem. For such cases, a common issue is to include existing Python scripts in AML Studio experiments. The Execute Python Script module accepts a zip file containing Python modules on the third input port. The Anaconda environment installed in AML Studio includes common packages such as NumPy, SciPy, and Scikit-Learn. These packages can be effectively used to process data in a machine learning pipeline.

```
import pandas as pd
#Remove time characters up to '.' from the date column
def azurel_main(dataframe1):
    d = []
    dates = dataframe1.loc[:, "Date"]
    for item in dates:
        if item is not None:
            temp = item.split('.', 1)
            d.append(temp[1])
    data = {'Date': d}
    df = pd.DataFrame(data)
    #Replace old Date column with the new one
    dataframe1['Date'] = df['Date']
    return dataframe1,
```

- 1) create a new column in which to automatically determine the name of the month by date - this will improve the identification of data by an additional feature (or marker);
- 2) combine readings within one date, as shown in Figure 19. Thus, the dates will not be repeated, and the consumption value for each date is defined as the arithmetic mean of measurements for 24 hours.
