# VISION-BASED SOLAR ENERGY USING DEEP LEARNING TECHNIQUES

In this section, various deep learning techniques for vision-based solar energy modelling are presented. These methodologies concentrate on different facets of general modelling, quality assurance, data processing, and data augmentation.

Many architectural design decisions, such as the number of layers, convolutional filter size, and neuron count, as well as alternative learning configurations, such as batch size and learning rate, are frequently involved in the implementation of deep learning models. (Lansberry et al., 1992; Lauret et.al., 2015; Leholo et. al, 2019) It takes work to adjust these hyperparameters so that deep learning models perform better. Generally, there is a defined range of values for every hyperparameter. Due to time and computational resource limitations, a comprehensive search (also known as a grid search) incorporating all possible combinations of these parameters is frequently unfeasible. Grid search is ineffective for finding hyperparameters since hyperparameters can also vary depending on the dataset. Put differently, the hyperparameter values that work best for one dataset might not work well for another. Sampling techniques are usually used in light of these issues.
