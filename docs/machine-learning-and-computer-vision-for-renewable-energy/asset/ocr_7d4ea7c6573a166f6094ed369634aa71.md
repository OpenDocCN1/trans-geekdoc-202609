# Box-Cox Transformation

$X_t^{(\omega)} = \begin{cases} \frac{r_t^\omega - 1}{\omega}, \omega \neq 0 \\ r_t, \omega = 0 \end{cases},$ (1)

# Seasonal Periods

$X_t^{(\omega)} = l_{t-1} + \phi b_{t-1} + \sum_{i=1}^M S_{t-m_i}^{(i)} + d_t,$ (2)

# Global and Local Trend

$l_t = l_{t-1} + \phi b_{t-1} + ad_t$
$b_t = (1-\phi)b + \phi b_{t-1} + \beta d_t,$ (3)

# ARMA Error

$d_t = \sum_{i=1}^p \phi_i d_{t-i} + \sum_{j=1}^q \theta_i t_{t-j} + \iota_t$ (4)

# Fourier Seasonal Terms

$S_t^{(i)} = \sum_{j=1}^{k_i} S_{j,t}^{(i)}$
$S_{j,t}^{(i)} = S_{j,t-1}^{(i)} \cos \lambda_j^{(i)} + S_{j,t-1}^{*(i)} \sin \lambda_j^{(i)} + \gamma_1^{(i)} d_t .$
$S_{j,t-1}^{*(i)} = S_{j,t-1}^{(i)} \sin \lambda_j^{(i)} + S_{j,t-1}^{*(i)} \cos \lambda_j^{(i)} + \gamma_2^{(i)} d_t$ (5)

Here, \(X_t\) is a time series (i.e., electricity load demand). Now, let \(X_t^{(\omega)}\) represents the Box-Cox transformation of \(X_t\) with the parameter \(\omega\), \(l_t\) being the local level in time t, then \(b_t\) is the short-term trend in time t, where \(\phi\) is the trend damping parameter. Furthermore, \(S_t^{(i)}\) denotes the \(i^{th}\) seasonal component at time t, and \(m_1, ..., m_T\) refers to seasonal periods, while \(d_t\) represents an ARMA (p, q) process and \(\iota_t\) a Gaussian white noise process with zero mean and constant variance. According to Munim (2022), \(\alpha, \beta, \text{and } \gamma\) are smoothing parameters for \(i=1,...,T\). Hence, \(\lambda_j^{(i)} = 2\pi j / m_i\), \(S_{j,t}^{(i)}\) represents the stochastic level of \(i^{th}\) seasonal component and \(S_{j,t}^{*(i)}\) represents the change (or growth) in the stochastic level of \(i^{th}\) seasonal component over time.
