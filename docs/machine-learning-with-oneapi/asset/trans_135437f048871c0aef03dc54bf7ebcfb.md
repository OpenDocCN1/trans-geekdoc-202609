
# OneAPI Base Toolkit 安装指南

## 下载和系统要求

可以从以下链接下载 oneAPI Base Toolkit：[https://www.intel.com/content/www/us/en/developer/tools/oneapi/base-toolkit-download.html](https://www.intel.com)。

但在进行安装前，了解用户系统是否满足要求非常重要。可以从以下链接了解要求：[https://www.intel.com/content/www/us/en/developer/articles/system-requirements/intel-oneapi-base-toolkit-system-requirements.html](https://www.intel.com)。

## 操作系统支持

oneAPI Base Toolkit 可用于 MacOS、Windows 和 Linux（[图 2.3](#c2.xhtml#f2.3)）。根据用户的操作系统，可以开始下载。

![图 2.3 操作系统支持。](images/fig2.3.jpg)

[**图 2.3**](#c2.xhtml#re_f2.3) 操作系统支持。

## 安装选项

可以根据需要选择在线或离线分发。下面是截图（[图 2.4](#c2.xhtml#f2.4)），展示了选项（所有受支持的操作系统均提供在线或离线选项）。

![图 2.4 安装选项。](images/fig2.4.jpg)

[**图 2.4**](#c2.xhtml#re_f2.4) 安装选项。

如果选择在线安装模式，可立即下载可执行文件，且文件很轻量（13 MB）。如果选择离线选项，可执行文件较大（6 GB），下载完成可能需要更多时间。这两种选项都可以，用户可根据自身需求选择。下载时可能需要注册。可以查看离线和在线模式的安装文件大小，见[图 2.5](#c2.xhtml#f2.5)。

![图 2.5 安装选项。](images/fig2.5.jpg)

[**图 2.5**](#c2.xhtml#re_f2.5) 安装选项。

## 相关工具包

1. b. *Intel oneAPI HPC（高性能计算）工具包*：名字说明了一切。正如您所理解的，该工具包是特定领域的。使用该工具包，您可以构建和交付快速的 Fortran、OpenMP 和 MPI 应用程序，将高性能计算应用与前沿技术相结合。

该工具包包含一组工具和库，下面列出供读者快速参考：

* C++ 编译器
* 集群检查器
* Fortran 编译器
* Intel Inspector
* Intel MPI 库
* Intel Trace Analyzer 和 Collector

安装过程与 Intel oneAPI Base Toolkit 部分讨论的几乎相同。但是，可安装程序需从以下链接下载：[https://www.intel.com/content/www/us/en/developer/tools/oneapi/hpc-toolkit-download.html](https://www.intel.com)。其余指南保持不变。一些工具包可能要求将 Base Toolkit 作为先决条件进行安装，安装开始时检查器会明确指出。

2. c. *Intel oneAPI 物联网（IoT）工具包*：这也是一个特定领域的工具包。使用此 IoT 工具包，可加速智能互联设备的开发，从而带来无限创新。该工具包捆绑了：

* Intel Inspector
* Intel oneAPI DPC++/C++ 编译器
