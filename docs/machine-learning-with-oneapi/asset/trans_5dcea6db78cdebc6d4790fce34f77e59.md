
例如，假设你有一个动物数据集，如[图 8.11](#c8.xhtml#f8.11)所示，你的任务是使用随机森林算法正确地对动物进行分类。随机森林算法使用其数据集并从给定的动物数据集中创建随机样本。它被输入到各种决策树模型中。在这里，每棵决策树都使用给定的不同条件来创建其预测结果。例如，决策树 1 使用 `color = yellow` 作为初始条件，并使用熵和信息增益继续构建树。也许决策树 2 发现条件 `height ≥20` 的信息增益更大，并继续构建树，等等。因此，每种决策树模型在初始属性选择时可能会使用不同的条件。一旦决策树形成，接下来就是集成部分，使用多数投票。假设在我们的示例中，给出在[图 8.11](#c8.xhtml#f8.11)中，两棵决策树预测为 `class 1`，即巨嘴鸟（一种色彩鲜艳、喙大弯曲的鸟），而一棵决策树预测为 `class 2`，即 Gouldian finch（一种体型小、色彩鲜艳夺目的鸟）。根据所使用的多数投票概念，我们将最终预测保持为 `class 1`，即巨嘴鸟。希望随机森林分类器的运作原理现在更清晰了。

## 8.5 决策树和随机森林的优势
决策树的主要特点是简单，易于可视化并从中推断结果。决策树也能很好地工作并提供相当不错的结果，即使在数据较少、清洗程度较低的情况下。它们既能处理数值数据也能处理分类数据。
随机森林的主要特点包括采用各种决策树，以独特的方式进行属性选择，不受维度灾难的影响（或简单地说，特征或维度的数量），并使用并行执行来构建随机森林。最终预测比决策树更可靠，因为随机森林使用集成模型 bagging 进行最佳预测。这使得随机森林算法比决策树算法更稳定。
决策树的主要缺点是可能迅速过拟合，而随机森林的主要缺点是对计算资源需求很大。

## 8.6 决策树和随机森林的应用
决策树和随机森林都可用于金融、医疗保健、客户流失率、银行业、电子商务、股票预测、客户贷款偿还预测等实时应用。
