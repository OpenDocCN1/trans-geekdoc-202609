## 5.4 让我们可视化

没有理解的数据或结果不会提供任何有用的见解。适当的视觉化将使用户获得有用的见解。“图像胜于言表”是一句谚语，在数据分析中它 100% 成立！

这是学习的令人兴奋的部分。输出可视化可以通过多种方式创建，例如 `matplotlib` 和 `seaborn`。

*   `Matplotlib` 是用于创建绘图和图形的主要库之一。它有很多功能。`Matplotlib` 是一个用于在 Python 中创建静态、动画和交互式可视化的综合库。由于 `Pandas` 提供了围绕 `matplotlib` API 的非常易于使用和方便的包装，因此更易于为某人创建绘图。

*   `Seaborn` 是一个基于 `matplotlib` 的 Python 数据可视化库。它提供了一个高级接口来绘制有吸引力且信息丰富的统计图形。

1.  a. *柱状图 – 从这里开始*：柱状图是用矩形条表示分类数据的图形，其高度或长度与所代表的值成比例。

    条形图可以垂直或水平绘制。我们现在可以通过简单的代码片段呈现柱状图吗？可以清楚地看到针对所考虑数据集的柱状图绘制。`sea.barplot` 方法足以获得清晰的可视化。

    也可以使用 Hue 来完成。可以在[图5.28](#c5.xhtml#f5.28)中可视化相同内容。

2.  b. *直方图*：直方图是使用不同高度的条形显示数据的图形显示。它类似于柱状图，但直方图将数字分组为范围。可以从代码片段和[图5.29](#c5.xhtml#f5.29)所示的输出中了解如何获取直方图以及绘图的样子。

    作为扩展，可以使用箱获取直方图。直方图中的箱是你在获得频率之前用来组合值的块（或分组）。例如，如果你正在创建年龄的直方图，箱可能是 0–5、6–10、11–15，等等，直到 85 等等。可以参考[图5.30](#c5.xhtml#f5.30)以更好地理解概念。

3.  c. *密度图*：密度图可视化数据在连续区间或时间段上的分布。该图表是直方图的变体，通过平滑噪声获得更平滑的分布。密度图的峰值有助于显示区间上集中的值。代码片段和由此开发的密度图以[图5.31](#c5.xhtml#f5.31)呈现，供读者快速浏览。

4.  d. *箱线图*：箱线图是给定数据集的统计五数概括的视觉表示。五数概括包括：# 最小值，第一四分位数，中位数（第二四分位数），第三四分位数，最大值。可以从[图5.32](#c5.xhtml#f5.32)看到它是什么样子，其中也呈现了代码片段。

5.  e. *散点图*：这有助于通过绘图揭示两个变量之间的关系。`import matplotlib.pyplot as plot`。我们可以看代码吗？（参考[图5.33](#c5.xhtml#f5.33)）。

6.  f. 配对图：当你需要比较许多变量时，配对图是最好的选择。可以看到编码多么简单以及获得良好的结果（[图5.34](#c5.xhtml#f5.34)）。
