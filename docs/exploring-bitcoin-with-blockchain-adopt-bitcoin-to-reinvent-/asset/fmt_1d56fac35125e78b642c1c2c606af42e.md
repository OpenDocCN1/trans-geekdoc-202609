# Tumbler 服务

Tumbler 服务由匿名交易所提供，且不可追踪，因为它们大多使用 TOR 网络。它们会对混币交易收取费用。Tumbler 服务接收发送方的比特币并将其转发给接收方，但在中间过程中，它们会将这些比特币与其他交易或自身的交易混合，并在多个地址之间移动。这使得追踪变得不可能。

这可以从下图理解：

![](images/Figure-8.15.jpg)

**图 8.15：** Tumbler 服务示例

在上图中，无法知道 Alice 是在支付 Bob，还是 Carol 在支付 Dave，又或是 John 在支付 Kirsten，因为所有交易都是完全混合、分离且互不相关的。

与某些流行钱包提供的 CoinJoin 不同，Tumbler 服务不由任何已知实体提供。这是其运作的本质。因此，此类服务存在风险，因为它们可能窃取您的币。

因此，大型矿工大多位于电力受补贴的国家。此外，许多发电公司和化石燃料公司也在挖掘比特币，以利用其过剩电力和燃料。天然气和石油钻探公司利用废气进行比特币挖矿，这对环境特别有益，因为甲烷比二氧化碳是强得多的温室气体。

风能和太阳能的燃料效率优于不可再生能源，天然气和核能除外。此外，离网电力节省了输电过程中的能源浪费，进一步提高了挖矿盈利能力。这使得离网可再生能源成为非补贴挖矿的首选能源。

而对于补贴比特币挖矿电力的政府而言，成本高昂，因为这几乎不创造就业岗位，所以政府倾向于打击此类设施，如在中国和伊朗所见。

因此，与当代观点相反，我们了解到比特币挖矿对环境有益，原因如下：

*   矿工倾向于将离网可再生能源作为电力来源。
*   由最强效温室气体组成的废弃燃料被用于比特币挖矿，并转化为效力较弱的温室气体——二氧化碳。
*   比特币挖矿阻碍政府向挖矿公司补贴电力。

# 对个人和网络的威胁

到目前为止在本章中，您了解了设计局限性以及比特币开发者社区如何努力克服这些局限。您还了解了比特币挖矿的大量能耗并非环境的大问题。

比特币作为一个去中心化的点对点开放价值转移网络，既是攻击者的利益目标，也被视为对现有全球货币体系的威胁。因此，比特币网络和比特币投资者可能不得不应对各种攻击，如来自政府、央行、恶意黑客、欺诈者或抢劫的攻击。

然而，威胁并不总是源于各种类型的攻击，也可能源于当前存在或未来可能出现的风险和潜在漏洞。

# 来自政府的威胁

正如我们在*第 4 章 现实世界中的比特币*中“比特币与加密货币监管”主题下所见，在世界上大多数国家，加密货币法律不明确或不存在。这赋予了当局处理加密货币的准司法权力，有时涉及威胁和腐败。有时需要缴税，但缴税条款不明确。这在印度和许多其他国家都是一个问题。这影响了交易所、交易者、投资者和商家，导致加密货币及相关服务价格虚高，并面临投资或业务损失的风险。

也没有法律保护，这有时被不法分子通过勒索和欺诈滥用。

禁止比特币交易是潜在风险，一些国家确实采取了这条路线，意味着任何从事加密货币交易的人都会受到惩罚。然而，这样做的国家非常少。
