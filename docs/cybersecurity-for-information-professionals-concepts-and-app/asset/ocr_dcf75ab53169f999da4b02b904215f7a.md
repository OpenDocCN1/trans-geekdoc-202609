# Threats in Mobile Technology Stack (Operating System/Firmware/Hardware)

As shown in Figure 10.3, mobile technology stack represents a mobile device’s multiple technology layers consisting of the hardware, firmware, mobile operating system, mobile applications, and embedded components (e.g., sensors and SIM card). Vulnerabilities in any of these components may be targeted by threats. For instance, the memory corruption defects in firmware could be manipulated by the attackers to gain administrative access (Veracode 2013); therefore, the user must regularly update firmware to ensure the device remains up to date. Like desktops or laptops, the mobile devices have operating systems, such as iPhone OS (iOS), Android, Blackberry, and Windows.
