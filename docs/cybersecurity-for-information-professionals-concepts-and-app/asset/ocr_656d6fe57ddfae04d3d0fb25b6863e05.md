That being said, some security experts argue that the more policies there are, the harder it becomes for a user to use the mobile device; hence that argument for the eradication of passwords completely. There has been support for other means of authentication that are considered more secure like biometrics (fingerprint, facial recognition, voice recognition, and so on) and pattern recognition. The good news is that modern day mobile devices provide an alternative to passwords as a primary means of authentication. Users just need to enable the features and start using them. Research has shown that while authenticating using biometrics provides a unique authentication mechanism and better security, they aren't totally foolproof. Combining more than one authentication method based on the value of the asset is a common practice especially with organizations that want to protect their assets. For example, some organizations implement multifactor authentication on some of their assets such that whenever an employee wants to access a corporate asset, the employee will be asked for an additional layer of authentication like the code from a hardware token, a phone call, or a fingerprint.
