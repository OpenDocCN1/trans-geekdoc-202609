
当同一图像的动态范围发生扩展时，该算法成功地增加了图像的对比度。此方法不仅极大地有助于增强图像对比度，但也引入了一些伪影、冲淡的外观、视频系统中的脉冲视觉感知以及图像细节的丢失（[Jaya & Gopikakumari, 2013](#ch13.xhtml#r171)）。此外，该技术不保留图像的平均亮度，导致某些局部区域过度变亮。

### 5.4.3 自适应直方图均衡化 (AHE)

为克服上段已讨论的直方图均衡化方法的缺点，开发了该技术（[Jaya & Gopikakumari, 2013](#ch13.xhtml#r171)）。该技术通过将输入图像划分为许多子块或图块来运作。随后，针对每个给定的图块计算其所含像素的直方图。最后一步涉及利用该图块的累积分布函数 (CDF)，基于邻域内的像素值，对中心像素应用直方图均衡化方法。自适应直方图均衡化和普通直方图均衡化都对每个图块执行相同的推导函数，以获取变换函数。然而，它是一种局部操作，因此具有不同灰度范围的区域可以同时得到增强。因此，证明了借助该技术可以克服直方图均衡化过程的缺点。此外，可使用滤波过程或插值方法，以减少因将图像划分为图块而引入的伪影。尽管如此，自适应直方图均衡化方法也有其缺点。首先，它会过度放大均匀区域中的背景噪声。其次，计算成本相当高昂（[Saenpaen et al., 2018](#ch13.xhtml#r183)），因为使用完美的块大小并非一项简单直接的任务，因为这会增加图像的所有部分。

### 5.4.4 对比度受限自适应直方图均衡化 (CLAHE)

对比度受限自适应直方图均衡化（[Irmak & Ertas, 2016](#ch13.xhtml#r169)）利用裁剪限制的新概念来处理 AHE 的噪声问题。该方法有助于限制图像的放大。这是通过在计算累积分布函数 (CDF) 之前，在预定义值处裁剪直方图来完成的。此外，裁剪限制完全取决于直方图的归一化和邻域的区域大小（[Saenpaen et al., 2018](#ch13.xhtml#r183)）。此后，位于裁剪限制之上的像素值会在低于裁剪限制的直方图值之间重新分配。这种重新分配过程会再次将像素值推向裁剪限制之上。所有这些导致了一个有效的裁剪限制，它比先前决定的要大得多。因此，这种重新分配过程会重复进行，直到所有超出的像素值都降至裁剪限制之下。再次执行插值函数，以便生成最终的 CLAHE 图像。

以下数学表达式（[Jaya & Gopikakumari, 2013](#ch13.xhtml#r171)）基于均匀分布，可用于表示具有变换灰度级的标准 CLAHE：

```
g = [g[max] - g[min]] * P(f) + g[min] (5.2)
```

其中，`g[max]` 被视为最大像素值，`g[min]` 被视为最小像素值。`P(f)` 被视为累积概率分布，而 `g` 被视为计算出的像素值。

### 5.4.5 亮度保持双直方图均衡化 (BBHE)

在该技术中，首先根据输入图像的均值将其直方图分成两个分区（[Rivera et al., 2012](#ch13.xhtml#r182)）。第一部分包含从最小灰度级到均值的范围，第二部分包含从均值到最大灰度级的范围。然后，独立地对这两个直方图进行均衡化。包含 0 到 K-1 范围的直方图被分成两个具有不同强度 `X[T]` 的部分。因此，这种分离产生了两个直方图。其中第一个直方图包含 0 到 `X[T]` 的范围，第二个包含 `X[T+1]` 到 `X[K-1]` 的范围。从数学和实验上都已证明，该技术在更大程度上维持原始亮度方面无可匹敌。

### 5.4.6 对偶子图像直方图均衡化 (DSHIE)

我们已经了解了 BBHE 方法如何将原始图像分解为两个子图像，并分别均衡化子图像的直方图。但另一方面，对偶子图像直方图均衡化 (DSHIE) 并非基于均值划分图像，而是基于 0.5 的累积分布函数 (CDF) 将图像分成两部分（[Rivera et al., 2012](#ch13.xhtml#r182)）。这样做是为了使输出图像产生最高的熵。

### 5.4.7 最小均值亮度误差双直方图均衡化 (MMBEBHE)

最小均值亮度误差双直方图均衡化方法（[Rivera et al., 2012](#ch13.xhtml#r182)）被认为优于 BBHE 方法。其优于前一方法的主要原因在于，它能比 BBHE 和 DSIHE 更好地保证亮度的保持。前几种方法与 MMBEBHE 方法的另一个主要区别在于，后者提出寻找一个阈值水平。该阈值水平进一步用于将图像 `I` 分解为两个子图像。第一幅图像用 `I[0,1t]` 表示，第二幅图像用 `I[1t+1, K-1]` 表示。因此，它有助于区分输入图像和输出图像之间的最小亮度差异，这是前几种方法未考虑的。

### 5.4.8 背景亮度保持直方图均衡化 (BBPHE)

观察到平坦图像包含的背景电平密度比其他电平高得多。不仅如此，在平坦图像中，背景电平的总密度可能超过总像素的一半。因此，在 BBPHE（[Rivera et al., 2012](#ch13.xhtml#r182)）中，输入图像基于背景电平和非背景电平范围分解为子图像。然后，下一步涉及独立地均衡化每个子图像，并将它们组合成最终输出图像。因此，该过程通过在原始范围内拉伸背景电平，缓解了过度增强的问题。此外，背景亮度保持直方图均衡化技术能够通过归一化，将其他子图像中相对较低密度的灰度级扩展到一个宽范围内。

## 5.5 图像增强技术的性能指标

如下所述，图像增强技术有多种性能指标可用：

### 5.5.1 均方误差 (MSE)

```
MSE = \frac{1}{MN}\sum\limits_{j = 1}^{M}\sum\limits_{k = 1}^{N}\left( {I_{j,k} - O_{j,k}} \right)^{2} (5.3)
```

在上述表达式中，`M` 和 `N` 分别代表图像的行和列。此处 `I[j,k]` 代表原始输入图像，`O[j,k]` 代表相应的输出图像。为了减小均方误差（[Yadav et al., 2016](#ch13.xhtml#r187)），输入图像和输出图像之间应具有接近的像素强度。
