

# INC MPPT 技术

INC 是一种广泛使用的 MPPT 技术，它将瞬时电导（即 `I/V`）与增量电导（即 `dI/dV`）进行比较。它还基于光伏组件功率对电压的公式推导，从而实现零平衡（Gil-Antonio 2016）。当增量电导等同于即时电导但极性相反时，可从[图 10.2](#ch18.xhtml#f88)获得最大功率点（MPP）。为了达到 MPP，服务周期通过一个微小因子被延长或缩短（[Gupta and Saxena 2016](#ch18.xhtml#r404)）。INC MPPT 算法的优势在于其实施简单，具有更高的跟踪速度和性能（[Karami 2017](#ch18.xhtml#r406)）。

作为太阳能光伏源，采用 I-V 曲线法对各种 PSC 模式进行编程。为了将光伏源的输出提供给阻性负载，使用由 PWM 信号驱动的 DC-DC 升压变换器。升压变换器的规格在[表 10.2](#ch18.xhtml#t17)中描述。使用 `MATLAB/SIMULINK` 平台对 MPPT 技术进行仿真和实施以供评估。虚拟平台上的电压和电流传感器用于测试升压变换器的输入/输出电压和电流。使用 `MATLAB/SIMULATION` 编写的 PC 软件程序执行和监控所有评估实验。[图 10.5](#ch18.xhtml#f91)和[10.6](#ch18.xhtml#f92)展示了带有局部阴影的光伏组件的 MPPT 控制器。DC-DC 功率变换器的转换速率约为 `0.112 V/ms`。此外，两种实验算法切换工作点所需的最大电压变化为最大值。作为输出结果，达到稳态所需的总过渡时间为 `0.01 秒`。因此，每次电压变化存在 `0.02 ms` 的延迟时间。实验算法单次迭代的执行过程如[图 10.2](#ch18.xhtml#f88)（流程图）所示。算法在每次迭代开始时测量各个工作电压。然后修改每个 PWM 信号的占空比，使光伏阵列处于固定电压。由于转换速度的差异，我们将算法的净计算时间相加作为比较的执行时间。变换器的时间常数会对总体 MPPT 时间产生重大影响。

尽管传统 P&O 可以在 PSC 下精确提取 MPP，但复杂的计算使得实施困难。虽然测量可以简化，但随着处理时间的减少，精度会下降。此外，更简单的计算过程可能导致搜索结果卡在 MPP 处。为了解决这个问题，本章提出了一种基于 INC 的 MPPT 算法，在响应时间方面优于传统的基于 P&O 的 MPPT 技术。
