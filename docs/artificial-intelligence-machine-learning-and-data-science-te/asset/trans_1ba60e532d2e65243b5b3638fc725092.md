
# 机器学习算法与性能评估指标

机器学习算法协助人和动物像自然一样学习。这些算法被用于研究原始数据以供您的计算机处理，而在不采用预设模型机器的情况下，可用于学习性能的试验次数。这些模型可以通过提供洞察来识别自然现象，并帮助做出更明智的重大决策，如预测、医学诊断、库存管理、交易、能源消耗评估等。媒体网站专注于计算机的教学，并提出数百万种可能的方式来推荐电影或歌曲。企业通过倾听消费者的购物模式来实现这一点。它包含两种方法：监督学习，它通过已知的输入和输出数据构建框架以预测未来结果；以及无监督学习，它包含具有隐藏模式或内在结构的输入信息。

到目前为止，作者已经介绍了各种类型的机器学习，其中许多算法都有其优势和局限性，这使它们非常适合用于相关领域。此类算法的增强版本被定义为深度学习算法，近期已变得极其流行。然而，这些方法源于多年前的生物神经网络，早于它们对数据科学的贡献。作者在本研究中仅使用了机器学习和深度学习算法，以及一些最广泛使用的 `LIDC-IDRI` 数据集进行研究 [[Pradhan et al., 2020](#ch11.xhtml#r091)]。本深度研究的输出分析及发现将帮助同类领域的研究人员和专家获得改进的信息和经验，以根据不同肺癌数据集的数据，在这大量算法中创建最适合其挑战的最佳算法。本章讨论的机器学习算法包括 `Logistical Regression (LR)`、`K-Nearest Neighbors (KNN)`、`Gaussian Naive (GNB)`、`Decision Trees (DT)`、`Random Forestry (RF)`。作为深度学习中人工神经网络的主要类别，`Bidirectional Long Term Memory (BLSTM)` 和 `Long Short Term Memory (LSTM)` 也进行了分析。

## 3.7 性能评估指标

在实施机器学习算法后，需要这些工具来了解和理解它们在工作中取得了什么成果。这些指标被称为性能评估指标。在本研究中，作者发现了算法效率的各种要素，并引入了许多指标。然后，我们需要一套可接受的指标集合，用于每个学习任务的性能评估。在本章中，作者采用了许多标准指标来获取关于算法效率的有价值数据，并对分类问题执行类似的分析。这些指标包括精确率、召回率、混淆矩阵、准确率和 ROC-AUC 排序。这些测试如下。

### 3.7.1 精确率 / 阳性预测值 (PPV)

“所需数据中有多少是可接受的。”这意味着根据算法预期为支持性的发现，其中许多似乎是正确和准确的 [[Shakeel et al., 2020](#ch11.xhtml#r100)]。根据公式，真阳性的数量除以真阳性数量与假阳性数量之和。

$$PPV = \frac{TP}{TP + FP}$$
*公式 3.16：精确率计算*

### 3.7.2 阴性预测值 (NPV)

$$NPV = \frac{TN}{TN + FN}$$
*公式 3.17：NPV 计算*

### 3.7.3 召回率 / 灵敏度 / 检出概率 / 命中率 / 真阳性率 (TPR)

它评估测试对于被准确诊断并被归类为疾病真阳性率的患者来说，是否做出了一个好的选择。一个极其困难的测试可能会击中那些具有最多错误阴性结果的人，因此可能不会显示最多的假阴性结果：90% 的肺癌患者能够获得阳性结果，而 10% 被测试为阳性的人将呈现阴性结果，且阳性者将呈现阴性结果，宣称错误的阴性方面。该测试的结果高度敏感。它包含“选择了多少类型的数据。”确实，有多少是根据真阳性发现由算法估计的 [[Shakeel et al., 2020](#ch11.xhtml#r100)]。预计在怀疑疾病时，发现分析也将呈阳性。召回率是模型准确识别真阳性的度量。因此，请记住在所有真正患有肺癌的人中，有多少患者被识别为患有肺部疾病。

$$TPR = \frac{TP}{TP + FN}$$
*公式 3.18：灵敏度计算*

### 3.7.4 特异性 / 选择性 / 真阴性率 (TNR)

它衡量测试精确地为未患有被测试感染的个体获得阴性结果的能力，这通常被称为“真阴性率”。高特异性测试将适当地发现几乎所有不患病的人，且不会产生大量假阳性结果。

预计当疾病不存在时，测试结果本应为阴性 [[Shakeel et al., 2020](#ch11.xhtml#r100)]。根据公式，真阴性的数量除以真阴性数量与假阳性数量之和。

$$TNR = \frac{TN}{TN + FP}$$
*公式 3.19：特异性计算*

### 3.7.5 假警率 / 假阳性率 (FPR)

疾病可能发生的阳性情况与疾病不存在的假设之间的关系，因此就该测试的结果而言是阳性的。

$$FPR = \frac{FP}{FP + TN}$$
*公式 3.20：FPR 计算*

### 3.7.6 漏诊率 / 假阴性率 (FNR)

疾病发现为阴性的概率与疾病检测结果为阴性的可能性之间的关系。

$$FNR = \frac{FN}{FN + TP}$$
*公式 3.21：FNR 计算*

### 3.7.7 假发现率 (FDR)

$$FDR = \frac{FP}{FP + TP}$$
*公式 3.22：FDR 计算*

### 3.7.8 假遗漏率 (FOR)

$$FOR = \frac{FN}{FN + TN}$$
*公式 3.23：FOR 计算*

### 3.7.9 F1-Score / F-Measure / Sørensen–Dice 系数 / Dice 相似性系数 (DSC)

在衡量算法性能时，这种指标通常称为 F-Score 或 F-Measure，它同时考虑了精确率和召回率。在一种情况下对召回率和精确率进行估计起着至关重要的作用，这样可以通过识别低召回高精确率或反之的模型来消除该问题 [[Dong et al., 2020](#ch11.xhtml#r066)]。精确率和召回率的关系平均值在数学上描述如下：

$$F1 - Score = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

$$F1 - Score = \frac{2TP}{2TP + FN + FP}$$
*公式 3.24：F1-Score 计算*

F1-Score 是精确率和召回率的加权平均值。必须考虑假阳性和假阴性。存在低假阳性和低假阴性，能正确识别真实威胁，使得误报不会打扰它们。预计会有两个截然不同的警告，并应随后计算性能。
