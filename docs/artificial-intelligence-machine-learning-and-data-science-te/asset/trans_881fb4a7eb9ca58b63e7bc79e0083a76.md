
一个常见的例子是，主机标识协议（HIP）中使用的主机标识符可以作为一种不同于 IP 地址的身份识别和命名方案，用于物联网应用（[Zhicheng, 2018](#ch23.xhtml#r606)）。物联网设备的链接需要使用主机标识而非 IP 地址，以实现这种覆盖层身份识别和命名方案。在两个实体能够相互通信之前，它们需要创建一个用于交换加密协议的绑定。如果不实施严格的安全协议，这将防止外部世界直接入侵敏感的物联网设备和网络。同样，一种独立于 IP 且受保护的身份识别和命名方案，在未来的“边缘计算 + 物联网”环境中将非常有用，特别是对于那些需要额外安全保护的敏感系统中资源匮乏的物联网设备。在这方面，我们假设将会有相当多的研究机会（[Zhicheng, 2018](#ch23.xhtml#r594)）。

## 15.7 结论

对于几种潜在的物联网实现而言，向物联网（IoT）的范式转变以及边缘计算的出现提供了巨大的益处。但这也给网络安全带来了必要的挑战。在本报告中，我们识别并探讨了与这一愿景相关的五个网络安全问题和五个潜在的网络安全前景。“边缘计算 + 物联网”平台与不断发展的区块链和人工智能技术之间的某些融合发展，理论上可以创造许多有益的机会。

总体而言，我们得出的结论是：未来仍存在待解决的挑战，而机遇也在不断涌现，我们可以用有用且可持续的方式加以利用。
