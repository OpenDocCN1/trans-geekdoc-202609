
目标凸区域是凸包的周围区域。凸包揭示了包含肺部肿瘤分割区域的最小凸多边形。该凸多边形给出了凸区域内的像素数量。该值为标量。

### 3.5.4 周长

周长似乎是目标边界上的像素数量。它一直是肺内连接肿瘤区域的总和。这是周长的一个标量值。如果边界列表为 `x[1],…,x[N]`，则周长由下式给出：

```
Perimeter = \sum_{i = 1}^{N - 1} d_i = \sum_{i = 1}^{N - 1} |x_i - x_{i + 1}|
```
*公式 3.5：周长计算*

距离 `d[i]` 对于四连通边界等于 1，对于八连通边界等于 1 或 `\sqrt{2}`。正如[表 3.1](#ch11.xhtml#t8)所述，在八相关边界内，`N[4] - N[8]` 之间的对角连接数量长度有一个像素，以及一个 `N[8] - (N[4] - N[8])` 连接。因此完整周长为：

```
Perimeter = (\sqrt{2} - 1)N_4 + (2 - \sqrt{2})N_8
```
*公式 3.6：周长计算*

### 3.5.5 凸周长

此类目标的凸周长就是覆盖该目标的凸包。这意味着覆盖球体的凸包的凸边界即为目标的凸周长。

### 3.5.6 轴长

目标的主轴是最长线的 `(x, y)` 端点，主要可通过计算目标边界内每个边界像素组合的距离来识别，主轴端点像素 `(x1, y1)` 和 `(x2, y2)` 的最大长度见[[Wang et al., 2018](#ch11.xhtml#r104)]，如[表 3.1](#ch11.xhtml#t8)所示。

#### 3.5.6.1 主轴长度

目标的主轴长度由主轴端点之间的像素距离组成：

```
MajorAxisLength = \sqrt{(x_2 - x_2)^2 + (y_2 - y_1)^2}
```
*公式 3.7：主轴*

结果为目标长度估计值。

#### 3.5.6.2 次轴长度

次轴是目标所能形成的、且与主轴垂直的最长线的 `(x, y)` 端点。通过测量从边界像素两端点出发的像素间隙，可以找到次轴端点 `(x[1], y[1])` 和 `(x[2], y[2])`。

```
MajorAxisLength = \sqrt{(x_2 - x_2)^2 + (y_2 - y_1)^2}
```
*公式 3.8：次轴*

此处结果为目标宽度估计值。

### 3.5.7 紧凑度

紧凑度是目标面积与具有相同周长的圆面积之比[[Riti et al., 2016](#ch11.xhtml#r094)]。选择圆是因为它是最紧凑的物体。圆的最大值为 1。正方形的紧凑度为 `\frac{\pi}{4}`

```
Compactness = \frac{4\pi.Area}{(Perimeter)^2}.
```
*公式 3.9：紧凑度计算*

该计算将降低具有椭圆形或非平滑不规则边界的目标的值。对于圆，测量值取最小值 1。正如[表 3.1](#ch11.xhtml#t8)所述，目标复杂、不规则的边界更为紧凑。

```
Compactness = \frac{(Perimeter)^2}{4\pi.Area}.
```
*公式 3.10：紧凑度计算*

### 3.5.8 偏心率

偏心率是次（短）轴长度与目标主（长）轴长度之比[[Kavitha et al., 2019](#ch11.xhtml#r072)]。因此，目标偏心率测量值在 0 到 1 之间给出。偏心率有时称为第一偏心率，以区别于第二和第三偏心率。

```
Eccentricity = \frac{AxisLength_{short}}{AxisLength_{long}}.
```
*公式 3.11：偏心率计算*

这用于确定肿瘤的圆度，如[表 3.1](#ch11.xhtml#t8)所述。对于规则目标，偏心率值等于 1，而在不规则形态中，该值超过 1。

### 3.5.9 标准差

它计算灰度像素尺度值均值的均方差。

### 3.5.10 偏度

它是指定 ROI 内像素分布围绕平均值的不对称度评级。

### 3.5.11 峰度

它测试分布与正态分布的峰度和平坦度的对比。

### 3.5.12 熵

它是分割 ROI 内容最大可能量的度量。

### 3.5.13 圆度

通常，仅对偏离特定圆度形式敏感的步骤才有用，例如凸度（测量不规则性）和圆度（排除局部不规则性）[[Riti Yosefina Finsensia et al., 2016](#ch11.xhtml#r094)] [[Kavitha et al., 2019](#ch11.xhtml#r072)]。圆度计算（面积与周长之比）可通过目标面积与具有相同凸周长的圆面积之比来实现，从而排除局部不规则性，详见[表 3.1](#ch11.xhtml#t8)。

```
Roundness = \frac{4\pi.Area}{(ConvexPerimeter)^2}.
```
*公式 3.12：圆度计算*

对于圆形目标，该数值为 1；对于偏离圆形的目标，该值小于 1，且对不规则边界相对不敏感，但对于偏离圆形的目标，它对不规则边界合理地不敏感。

### 3.5.14 凸度

凸度是目标与凸目标之间差异的比例[[Wang et al., 2018](#ch11.xhtml#r105)]。可测量目标凸包周长与目标自身周长之比，如[表 3.1](#ch11.xhtml#t8)所述。

```
Convexity = \frac{ConvexPerimeter}{Perimeter}.
```
*公式 3.13：凸度计算*

对于凸目标，此值为 1。如果目标非凸（例如边界不规则），则小于 1。

### 3.5.15 实心度

目标的密度由实心度测量。作为目标面积与目标凸包面积之比，可获得实心度度量，见[表 3.1](#ch11.xhtml#t8)。

```
Solidity = \frac{Area}{ConvexArea}.
```
*公式 3.14：实心度计算*

值为 1 表示实心目标；具有不规则边界或空洞的目标值低于 1，表示边界不规则。

### 3.5.16 边界框

限制目标的矩形即为目标的边界框或矩形[[Wang et al., 2018](#ch11.xhtml#r105)]。边界框的比例为长轴和短轴，如[表 3.1](#ch11.xhtml#t8)所述。边界框面积为

```
BoundingBoxArea = (MajorAxisLength) \times (MinorAxisLength)
```
*公式 3.15：边界框计算*

限制形状的最小边界面积即为最小边界框。

### 3.5.17 平均强度

该值为标量。它确定感兴趣区域（即肿瘤部分）内的平均像素强度[[Riti Yosefina Finsensia et al., 2016](#ch11.xhtml#r094)]。
