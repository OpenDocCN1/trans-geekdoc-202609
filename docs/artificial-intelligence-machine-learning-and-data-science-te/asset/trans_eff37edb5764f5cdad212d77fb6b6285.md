

# 建筑材料中的可持续性概念

建筑材料中的可持续性概念促使人们从天然和可回收来源开发保温材料（[Asdrubali 等人 2015](#ch17.xhtml#r302)）。木材、稻草、椰子、木纤维、纤维素和木质材料等天然材料均为可持续材料，它们对环境的影响极小，且隐含能量低。天然材料的隐含能量可在极短的时间内恢复（[Rojas 等人 2019](#ch17.xhtml#r375)）。近期在生物保温材料领域取得了显著进展；针对木材、稻草和椰子等材料开展了大量研究（[Liu 等人 2017](#ch17.xhtml#r353)）。特别是由木纤维制成的天然保温材料可替代矿棉等保温材料，因为其具有可比拟的导热系数，稍厚的层即可获得相同的热阻，并能为建筑内部提供热舒适性（[Volf 等人 2015](#ch17.xhtml#r381)）。木纤维是一种天然且可回收的材料，其性能与合成材料相似，且已实现商业化，有进一步扩大应用的前景（[Asdrubali 等人 2015](#ch17.xhtml#r302)）。随着有机保温材料具有可再生、可回收和环保的特性，人们对其的兴趣日益浓厚（[Kymäläinen 和 Sjöberg 2008](#ch17.xhtml#r346)）。木纤维、木棉和纤维素等有机保温材料源自可再生的天然植被，而矿棉、气泡混凝土和珍珠岩等无机材料则由不可再生材料制成（[Aditya 等人 2017](#ch17.xhtml#r294)）。有机保温材料具有可持续、可回收和可重复使用的特点。无机化合物提供的热绝缘性能更高，且价格更便宜、防火性能更好（[Aditya 等人 2017](#ch17.xhtml#r294)）。纤维素纤维是一种源自天然材料的可再生、可回收和环保材料。与玻璃棉和岩棉等其他保温材料相比，纤维素纤维保温材料的制造所需能量最低；与岩棉相比，使用纤维素纤维保温可将一次能源消耗降低 6–7%（[Tettey 等人 2014](#ch17.xhtml#r377)）。木材也可用作建筑保温材料，因其具有良好的保温性能。据报告，木材的二氧化碳排放较少，隐含能量较低，也是一种可持续材料（[Falk 2009](#ch17.xhtml#r321)）。天然木材资源可用作可持续建筑材料（[Kosny 等人 2014](#ch17.xhtml#r344)）。只要保持木材利用与培育之间的平衡，木材就是一种可再生和可持续的材料。它可重复用于家具制造或燃烧，从而减少对环境的影响；且木质材料的隐含能量低于混凝土和钢材（[Asdrubali 等人 2017](#ch17.xhtml#r303)）。利用木材作为建筑施工材料是大幅减少碳排放的更好选择，但木材用量的增加应伴随森林面积的增长以保证可持续性（[Buchanan 和 Levine 1999](#ch17.xhtml#r312)）。值得注意的是，木结构房屋的预期寿命远低于混凝土房屋，若木材需从远距离进口，可能会造成更多污染（[Guardigli 2014](#ch17.xhtml#r325)）。树木生长过程中吸收的二氧化碳会一直储存在实木中直到报废，而总排放量的大部分发生在纸和板材的制造过程中（[Asdrubali 等人 2017](#ch17.xhtml#r303)）。某些木质材料（如矿化木纤维）具有与膨胀聚苯乙烯和玻璃棉等合成材料相当的高隐含能量（[Asdrubali 2009](#ch17.xhtml#r301)）。与木质结构相比，钢筋混凝土建筑对环境的影响更大（[Gerilla 等人 2007](#ch17.xhtml#r323)）。使用椰子纤维作为保温材料可显著减少混凝土建筑的热流，并能维持显著更低的室内温度（[Rodríguez 等人 2011](#ch17.xhtml#r374)）。通过增加木质天然建筑材料的比例并替代混凝土，可实现二氧化碳净排放量的下降（[Gustavsson 等人 2006](#ch17.xhtml#r327)）。高吸水性和防火性差是天然基热绝缘材料的主要缺点，但通过向天然绝缘材料施用疏水剂，可减缓天然基热绝缘材料的降解（[Zach 等人 2013](#ch17.xhtml#r391)）。

## 9.3.3 天然保温材料的环境影响

建筑施工在原材料利用、翻新、维护及建筑全生命周期中均会对环境产生影响（[Balaras 等人 2005](#ch17.xhtml#r304)）。建筑施工会产生温室气体，严重破坏环境，并导致自然资源枯竭（[Ding 2014](#ch17.xhtml#r317)）。保温材料对环境的影响是当前选择保温材料的一个主要参数。应选择对环境影响较小的保温材料，因为它既能提供热舒适性，又能对环境友好。如前所述，常用的保温材料通常由聚苯乙烯、聚氨酯和聚乙烯等石油化工产品制成。这些材料的生产过程会向环境排放大量污染物。岩棉、珍珠岩和蛭石等热绝缘材料在生产过程中也会产生大量污染。天然保温材料可回收利用，且能提供热舒适性。基于天然资源的保温材料环保、对健康影响较小，且生产过程节能（[Ahmed 等人 2019](#ch17.xhtml#r296)；[Ali 等人 2020](#ch17.xhtml#r299)；[Florea 和 Manea 2019](#ch17.xhtml#r322)；[Liu 等人 2019](#ch17.xhtml#r354)）。生命周期评估表明，与砖房建筑材料相比，木房建筑材料对环境的有害影响更小（[Mitterpach 和 Štefko 2016](#ch17.xhtml#r359)）。砖房建筑材料的碳足迹是木房建筑材料的两倍（[Mitterpach 和 Štefko 2016](#ch17.xhtml#r359)）。与岩棉相比，使用纤维素纤维保温可减少 6–8% 的二氧化碳排放（[Tettey 等人 2014](#ch17.xhtml#r377)）。因此，使用木质材料对建筑进行保温，在获得热舒适性的同时，可大幅降低环境影响。研究表明，在某些特定结构中，通过更换建筑材料可将环境影响降低约 60%（[Eštoková 和 Porhinčák 2015](#ch17.xhtml#r320)）。
