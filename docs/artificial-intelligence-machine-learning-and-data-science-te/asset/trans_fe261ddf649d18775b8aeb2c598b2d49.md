## [3.4 图像分割](#ch11.xhtml#h1-021b)

将灰度信息隔离为目标灰度数据的最佳方法是通过分割阈值处理，即局部或全局阈值处理。最广泛使用的是 `Otsu` 算法。最初应用一个初始种子值，该值合并徽章外部所有相同的像素。其优点在于通常能将相同特征与相关特征区分开来，并可靠地提供更好的数据，尽管它也会产生噪声或失真。其益处在于通常将相同特征从相关区域中分离出来，并提供改进的分割输出信息；其缺点在于计算资源成本较高，这会导致严重的噪声或规则性斑点。预滤波图像被转换为另一种格式，这在一定程度上消除了主要位于边缘处的前景像素的复杂性。肺部分割过程要经历多个阶段，而肺分割策略则要经历预处理、中值滤波器实现、高斯滤波器、`Gabor` 函数播种等各种步骤，然后开始新的过程，如[图 3.4(a)](#ch11.xhtml#f15)、[3.4(b)](#ch11.xhtml#f15)、[3.4(c)](#ch11.xhtml#f15) 和 [3.4(d)](#ch11.xhtml#f15) 所示，以将肺叶与上叶和下叶分离。

### [3.4.2 Otsu 阈值处理](#ch11.xhtml#h2-023b)

阈值处理是将像素从前景移除至背景的方法。有多种方法可确定阈值，由 Nobuyuki Otsu 提出的 `Otsu` 过程便是其中之一。`Otsu` 方法是一种比较阈值值的技术，其中背景和前景像素之间的加权差异最小。基本概念是获取所有可行的阈值，并计算前景和背景像素的分布。然后寻找最小离散程度。在特定阈值 `t` 下确定类内方差的公式定义为：

```
σ²(t) = ω[bg](t)σ[bg]²(t) + ω[fg](t)σ[fg]²(t)
```
*公式 3.3：二维 Otsu 阈值处理*

该算法 [[Li et al., 2018](#ch11.xhtml#r078)] 寻找使加权总和（背景和前景）指定的两类方差的内部方差最小化的阈值。灰度颜色通常在 0–255 之间变化（浮点数为 0–1）。因此，如果该阈值为 100，所有低于 100 的像素将成为背景，所有高于或等于 100 的像素将成为同一图像的前景。

其中 `ω[bg](t)` 和 `ω[fg](t)` 描述了由阈值 `t` 决定的像素数量概率，`σ²` 为像素值的方差。`P[all]` = 图像中像素总数，`P[bg](t)` = 阈值 `t` 下的背景像素数，`P[fg](t)` = 阈值 `t` 下的前景像素数。因此，权重表示为

```
ω_bg(t) = P_bg(t) / P_all, ω_fg(t) = P_fg(t) / P_all
```

方差可通过公式 `σ²(t) = (∑(x_i - x̄)) / (N - 1)²` 确定，其中 `x_i` 为类别（`bg` 或 `fg`）中位置 `i` 处像素的值，`x̄` = 类别（`bg` 或 `fg`）中像素值的均值，`N` 为像素数量。
