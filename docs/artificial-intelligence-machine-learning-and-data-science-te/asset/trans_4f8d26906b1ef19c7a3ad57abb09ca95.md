
# 可持续建筑保温材料

应在建筑保温中采用环境友好且隐含能量低的可持续建筑材料。建筑施工消耗了全球总资源消耗的主要份额。保温材料和墙体材料是建筑材料的主要组成部分。研究表明，建筑施工消耗了全球约 24% 的原材料（[Bribian 等 2011](#ch17.xhtml#r311)）。原材料开采对开采场地附近居民的健康有严重影响，且开采过程消耗大量一次能源，这被计入原材料的初级隐含能量（[Ding 2014](#ch17.xhtml#r317)）。过去，在选择建筑材料时，通常不考虑材料的环境特性（[Guggemos 和 Horvath 2005](#ch17.xhtml#r326)）。最近，对可持续建筑材料的研究兴趣日益增加，旨在使建筑施工实现可持续（[Ding 2014](#ch17.xhtml#r317)）。在其生命周期内能改善人类健康、舒适度且环境友好的可再生天然材料被称为可持续材料（[Ding 2014](#ch17.xhtml#r317)）。建筑材料在其生命周期内的环境影响及过度资源利用等问题，采用生命周期评价法进行评估（[Ahn 等 2010](#ch17.xhtml#r297)）。生命周期评价中建筑产品主要考虑的环境影响包括气候变化、富营养化、酸化、光化学臭氧消耗、平流层臭氧消耗，其他测量指标包括水消耗、可再生和不可再生一次能源、资源枯竭等（[Cao 2017](#ch17.xhtml#r313)）。生命周期分析也可用于生成缺乏环境品质对生命周期的影响（[Puetmann 和 Wilson 2005](#ch17.xhtml#r373)）。除了性能参数外，可持续建筑材料应具有低环境影响（[Ip 和 Miller 2012](#ch17.xhtml#r332)）。隐含能量研究如今变得愈发重要（[Dixit 等 2012](#ch17.xhtml#r318)）。用于建筑保温的材料应具有低隐含能量。高隐含能量材料在生产过程中消耗大量能源并产生温室气体（[Bribian 等 2011](#ch17.xhtml#r311)）。利用低隐含能量的天然材料可使最终产品具有可持续性（[John 等 2005](#ch17.xhtml#r334)）。建筑保温应使用可持续材料，以便降低环境影响。
