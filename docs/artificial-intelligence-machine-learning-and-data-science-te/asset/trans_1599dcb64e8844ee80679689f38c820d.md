
然而，与完全集成的多层架构相比，他们的整体模型提升了性能[[Liu et al., 2018](#ch11.xhtml#r079); [Nie et al., 2018](#ch11.xhtml#r088)]。MAP 分析技术的应用说明了并行 SVM 在肺癌预测和诊断中的有效性（参见[图 3.1](#ch11.xhtml#f12)）。

本章的主要目的是提升性能、缩短诊断时间、识别结节，并对特征和功能进行分类。已完成多项研究以确定最危险和最常见的肺癌类型。随后对这些肺结节及其提高的灵敏度、精确度和准确率进行分析。本章的关键目标是评估肺癌诊断方法并改进该策略。

动机：关键目标是提高性能、缩短诊断时间，并确定结节和特征的位置。从那时起，进行了大量研究以评估肺癌是否为最危险和最有害的类型。因此，所有肺结节的灵敏度、精确度和准确率被一起分析。肺癌的诊断应得到加强和改进。

## [3.3 提出的模型](#ch11.xhtml#h1-020b)

模型的总体轮廓如[图 3.2](#ch11.xhtml#f13)所示，包含五个常规步骤。第一步是根据 CT 图像的平滑度，使用不同的滤波器读取和处理图像。下一步是分割图像以提取正确的区域。生成一个结节以提取若干特征。收集多个特征后，选择每个特征的作用。同时也使用了广泛的机器专用分类器和深度学习分类器。第二层接着对一半高质量图像进行分类，这些图像似乎适用于大多数像素值超过 150 的情况，其余切片被移除。第三种方法基于提出的 BLSTM 和 SVM 进行特征消除和分类。在随后的步骤中，少数服从多数投票指示标题的形状，并最终显示标题状态。

### [3.3.1 数据集 (LIDC-IDRI)](#ch11.xhtml#h2-019b)

在每个人工智能范式中，数据集都是重要组成部分。相关数据的准确性带来分析增长、准备和进展。为使该开发有所裨益，所获取的证据应经计算机视觉专家验证和标注。本节包含用于肺癌识别的早期人工智能工作的信息[[Rabbani et al., 2018](#ch11.xhtml#r092)]。该数据集包含来自七个研究中心和八家医疗诊断公司的 1018 个病例。每个病例均提供一份 CT 扫描标注的 XML 文档[[Chen et al., 2020](#ch11.xhtml#r062)]。四位经验丰富的胸部放射科医生通过两阶段流程进行特定标注。每位放射科医生将结果单独分为三组（“结节 ≥ 3 mm”、“结节 < 3 mm”和“结节 ≥ 3 mm”）[[Kim et al., 2018](#ch11.xhtml#r074)]。然后，在第二步中，任意一位放射科医生匿名调查其自身的分类以及其他放射科医生的分类。四位放射科医生分别分析每个结节标注。平均值高于三归类为恶性结节，低于三归类为良性结节。四位放射科医生中的一位验证了总分为三且存在特定不一致性及其身份的情况，且一些结节被排除在分析之外。通过筛选和可视化，DCM 文件也能更容易地被解读，如[图 3.3(a)](#ch11.xhtml#f14)所示，由三到五位放射科医生呈现癌症的恶性或良性分期。使用 `Pylidc-tool` [[Loyman et al., 2020](#ch11.xhtml#r080)] 进行浏览，如[图 3.3(b)](#ch11.xhtml#f14)所示，显示了 LIDC-IDRI-0082 CT 图像中的结节，详情如下：CT 层厚：1.250 mm，像素间距：0.703，结节数：1，第 173 层附近有三个标注，标注信息（隐匿性-4，内部结构-1，钙化-6，球形度-3，边缘-4，叶状-2，毛刺-5，人工智能纹理-5，恶性度-5）[[Wu et al., 2019](#ch11.xhtml#r108)]。

### [3.3.3 图像增强](#ch11.xhtml#h2-021b)

图像平滑消除整个图像中的失真或其他微小干扰，这意味着边缘失真，并迭代地减少噪声。输入首选图像，并使用一些滤波器进行分析。如[图 3.2](#ch11.xhtml#f13)所示，中值、高斯和 Gabor 滤波器被添加在预处理阶段，当前最佳解决方案被更新并提出了一个新方案。中值滤波器是一种非线性 3 × 3 尺度特征[[Shah et al., 2020](#ch11.xhtml#r099)]，通过最小化脉冲噪声来改善图像。

```
g(x,y) = \frac{1}{2\pi\sigma^{2}}\exp\left\lbrack \frac{- \left( {x^{2} + y^{2}} \right)}{2\sigma^{2}} \right\rbrack
```
*公式 3.1：二维高斯滤波器*

高斯滤波器对于消除高频元素以消除图像中的波动也很有用。这意味着 `medfilt2` 仅用于减少噪声。该低通滤波器消除湍流，增加表面的平滑度和精确强度。高斯分布的标准差是轴心到中心的距离以及 y 轴到轴心中心的距离[[Tabish et al., 2017](#ch11.xhtml#r101)]。预处理后，处理过的图像通过分水岭分割进行分割。该图像显示识别出的癌症结节。

Gabor 函数是一种当前有用的图像评估线性滤波器。可使用高斯和谐波功能。它还增加了目标（如结节）周围区域之间的压缩/对比度。公式 3.2 给出了二维 Gabor 滤波器的表达式[[Albu et al., 2019](#ch11.xhtml#r059)]。在此公式中，λ 为波长；θ 用于方向，从标准到平行切片；φ 为相位偏移；σ 为标准差；γ 为空间纵横比。在癌症检测开发阶段，还开发了其他特征，包括表面积、周长和离心率，以及质心、直径和主要强度像素等特征。此后，提取了特征并准确评估了癌症结节。此后，良性或恶性并不明显。

```
\begin{array}{l} {g\left( {x,y} \right) = \exp\left( \frac{{x^{\prime}}^{2} + \gamma^{2}{y^{\prime}}^{2}}{2\sigma^{2}} \right)\cos\left( {2\pi\frac{x^{\prime}}{\lambda} + \phi} \right)} \\ {x^{\prime} = x\cos\theta + y\sin\theta} \\ {y^{\prime} = - x\sin\theta + y\cos\theta} \\ \end{array}
```
