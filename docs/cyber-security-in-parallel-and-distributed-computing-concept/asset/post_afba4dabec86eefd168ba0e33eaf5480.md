## 9.2 Background Work Related to Domain

### 9.2.1 Basics on Cloud computing

The basic idea of distributed computing is to provide computational resources as services over the cloud. Users are not required to invest in a powerful PC to conduct their business; rather, they can obtain distributed computing services based on their demands [8]. The basic hardware is largely hosted in large data centers using complex virtualization techniques to achieve elastic resource provisioning, flexibility, and accessibility. As mentioned above, the ease of use of servers depends on the flexibility which doesn’t need money for hosting in servers. In this regard, it is required to provision the things and utilize the things in the provisioning way [13].

The servers in the cloud depend on the budget we are investing in the server with 3 different modes i.e., PaaS, SaaS, IaaS [17]. For the different services of the cloud, there are multiple frameworks which are provided by Amazon such as EC2, S3, etc. EC2 is a service which provides better service with best availability nature with 99.99%. Efficiency. The availability of server depends on the budget we are investing in server and availability. Mostly such type of servers were used for private cloud services means it is used in case of specific organizations etc [1, 3-5].

### 9.2.2 Clouds Which are Federated

In the standard environment of the cloud, the cloud service depends on the cloud service provider (CSP). The cloud service provider depends on the service provider and their service. In the case of a single cloud, the overall cloud should be stored in the single cloud. The CSP should give good service, flexibility, ease of use, easy access, availability all the time, etc. The output of CSP results in good quality of service (QoS). The application programming interface (API) is the basic fundamental need for the service.
