
## 16.6 结论与未来工作

可以得出结论，数字支付的未来前景非常光明。印度也在数字支付方式方面经历了显著增长。2015-2016年，通过移动银行交易总额达4018亿卢比，而2012-2013年为60亿卢比。通过其他方式进行的数字支付比例也在显著速度增长中[17]。也可以得出结论，印度即将发展成为未来几年世界上增长最快的经济体，超越中国。半封闭钱包具有巨大的潜力，可为整体GDP增加价值，推动国家实现无现金经济。
