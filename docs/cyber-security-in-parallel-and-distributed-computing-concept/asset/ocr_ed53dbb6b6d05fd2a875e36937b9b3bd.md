# 16.4 Research Methodology

Based on PPI Literature and RBI Guidelines category of wallets are identified as i) Open e-wallets ii) Closed E-wallets iii) Semi- closed E-wallets. The major features of the e-wallets are: i) Technical Features ii) Operational Features iii) Legal Features iv) Security Features. Further, each category of feature is expanded to elaborate the availability of different features in various e-wallets.
