EX 6.5. The log likelihood (after applying Jensen’s inequality and omitting terms not featuring μ_kd) is:

ℒ ≥ − 1/(2s²) (μ_kd − m)² − Σ_n Σ_k q_nk Σ_d 1/(2σ_kd²) (x_nd − μ_kd)² + …

Taking partial derivatives with respect to μ_kd, equating to zero and re-arranging gives:

∂ℒ/∂μ_kd = − 1/s² (μ_kd − m) + 1/σ_kd² Σ_n q_nk (x_nd − μ_kd) = 0
μ_kd = [ 1/s² m + 1/σ_kd² Σ_n q_nk x_nd ] / [ 1/s² + 1/σ_kd² Σ_n q_nk ].

EX 6.6. The log likelihood is given by:

ℒ = Σ_n log Σ_k π_k λ_k^{x_n} exp{−λ_k} / x_n!

Incorporating variational parameteres q_nk and applying Jensen’s inequality gives:

ℒ ≥ Σ_n Σ_k q_nk log π_k + Σ_n Σ_k q_nk log [ λ_k^{x_n} exp{−λ_k} / x_n! ] − Σ_n Σ_k q_nk log q_nk.

We shall first derive an update for π_k. The relevant terms in the bound, incorporating a Lagrangian term to ensure Σ_k π_k = 1 are:

Σ_n Σ_k q_nk log π_k − λ ( Σ_k π_k − 1 ).

Taking partial derivatives with respect to π_k gives:

∂/∂π_k = 1/π_k Σ_n q_nk − λ.

Equating to zero:

λ π_k = Σ_n q_nk.

To compute λ we sum both sides over k:

λ Σ_k π_k = Σ_n Σ_k q_nk
λ = N.

Therefore:

π_k = 1/N Σ_n q_nk.
