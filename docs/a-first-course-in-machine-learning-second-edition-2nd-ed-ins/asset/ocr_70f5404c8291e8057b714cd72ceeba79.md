This has the form of a Gaussian, $Q_{\mathbf{x}_n}(\mathbf{x}_n)=\mathcal{N}(\boldsymbol{\mu}_{\mathbf{x}_n},\boldsymbol{\Sigma}_{\mathbf{x}_n})$. Equating coefficients, we get the following:

$$\boldsymbol{\Sigma}_{\mathbf{x}_n} = \left(\mathbf{I} + \langle\tau\rangle \sum_m z_{nm} \langle\mathbf{w}_m\mathbf{w}_m^{\mathsf{T}}\rangle\right)^{-1}$$\n$$\boldsymbol{\mu}_{\mathbf{x}_n} = \langle\tau\rangle \boldsymbol{\Sigma}_{\mathbf{x}_n} \sum_m z_{nm} y_{nm} \langle\mathbf{w}_m\rangle.$$

The expression for $Q_{\mathbf{w}_m}(\mathbf{w}_m)$ follows an almost identical argument so we omit it here. Finally, the expression for $Q_{\tau}(\tau)$:

$Q_{\tau}(\tau) \propto \exp\left(\mathbf{E}_{Q_{\mathbf{W}}(\mathbf{W})Q_{\mathbf{X}}(\mathbf{X})}\{\log p(\mathbf{Y},\mathbf{W},\mathbf{X},\tau|\mathbf{Z})\}\right)$\n$\propto \exp\left(\mathbf{E}_{Q_{\mathbf{W}}(\mathbf{W})Q_{\mathbf{X}}(\mathbf{X})}\left\{\log\Gamma(a,b)+\sum_{n,m}z_{nm}\log p(y_{nm}|\mathbf{x}_n,\mathbf{w}_m,\tau)\right\}\right)$\n$\propto \exp\left(-b\tau+(a-1)\log\tau-\frac{\sum_{n,m}z_{nm}}{2}\log\tau-\frac{1}{2}\tau\sum_{n,m}z_{nm}\mathbf{E}_{Q_{\mathbf{W}}(\mathbf{W})Q_{\mathbf{X}}(\mathbf{X})}\left\{(y_{nm}-\mathbf{w}_m^{\mathsf{T}}\mathbf{x}_n)^2\right\}\right)$\n$\propto \exp\left(-b\tau+(a-1)\log\tau-\frac{\sum_{n,m}z_{nm}}{2}\log\tau-\frac{1}{2}\tau\sum_{n,m}z_{nm}\left\langle(y_{nm}-\mathbf{w}_m^{\mathsf{T}}\mathbf{x}_n)^2\right\rangle\right).$

This has the form of another Gamma distribution, with parameters:

$e = a + \frac{1}{2}\sum_{n,m}z_{nm}$\n$f = b + \frac{1}{2}\sum_{n,m}z_{nm}\left\langle(y_{nm}-\mathbf{w}_m^{\mathsf{T}}\mathbf{x}_n)^2\right\rangle.$
