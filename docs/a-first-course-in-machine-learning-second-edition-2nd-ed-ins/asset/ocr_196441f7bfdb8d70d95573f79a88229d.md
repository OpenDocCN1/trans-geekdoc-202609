Finally, pre-multiplying this by $\mathbf{w}^{\mathrm{T}}$ gives:

$$\mathbf{w}^{\mathrm{T}}\mathbf{X}^{\mathrm{T}}\mathbf{X}\mathbf{w}=w_0\left(w_0\sum_{n=1}^{N}x_{n1}^{2}+w_1\sum_{n=1}^{N}x_{n1}x_{n2}\right)+w_1\left(w_0\sum_{n=1}^{N}x_{n2}x_{n1}+w_1\sum_{n=1}^{N}x_{n2}^{2}\right)$$

$$=w_0^2\sum_{n=1}^{N}x_{n1}^{2}+2w_0w_1\sum_{n=1}^{N}x_{n1}x_{n2}+w_1^2\sum_{n=1}^{N}x_{n2}^{2}$$

as required.

**EX 1.4.** Let’s first work out $\mathbf{X}\mathbf{w}$:

as required.
