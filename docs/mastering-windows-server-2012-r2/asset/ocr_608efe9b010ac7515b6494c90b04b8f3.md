# AUTOMATICALLY ADD SERVERS TO THE CORRECT SITE

One of the actions promoting a server to a domain controller is to place the server object into a site. It will be placed in the Default-First-Site-Name by default. However, if another site exists with subnets defined and the server you are promoting has an IP address in a defined subnet, the server object will be placed into the appropriate site.

The following are the steps and requirements to set up AD's site topology:

+   1. Define each site.
A refers to a well-connected location. The terms *site* and *location* are often used interchangeably. Within Active Directory, a site is an Active Directory object that refers to a well-connected location.
2. Define each subnet.
For each subnet that has been created in your physical environment, a subnet object needs to be created in Active Directory.
3. Assign each subnet to a site.
Each subnet is linked to the actual location by linking the subnet object with the site object.
4. Create site links to connect the sites.
Physical locations are connected with WAN links. These WAN links are represented by site link objects. Each site link object includes two or more sites.
