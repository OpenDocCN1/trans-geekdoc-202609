# Managing Print Jobs

Managing jobs is pretty straightforward. You can use the Print Management console and
 Printers for the printer server. You can then right-click the printer you're interested in
and select Open Printer Queue.
Figure 16.40 shows the printer queue open for a printer named, HP Officejet 5600 series#6.
Notice in the Printers that the printer node also shows the queue status and the number of jobs in
queue. We paused the printer so that the printer could build up as we sent several print jobs
to the printer.
