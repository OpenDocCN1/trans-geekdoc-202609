# 1484 CHAPTER 30 MONITORING WINDOWS SERVER 2012 R2

Server 2012 R2 can be easily launched from the Server console under each specific role. Here's how to do it:

+   1. Log on to your Windows Server 2012 R2 computer with an elevated account that has administrative permissions.

+   2. Open Server Manager and then click a specific role in the navigation bar on the left. We'll use DNS for this example.

+   3. Scroll down to the Best Practices analyzer pane, click the Tasks button, and then choose Start BPA Scan, as shown in Figure 30.6.

# Figure 30.6nRunning the BPA

![](bbox=[0.313, 0.287, 0.866, 0.483])

+   4. Choose the server (or multiple servers) that you want to scan, then click the Start button to begin.

Once the scan has completed, you will be presented with the results giving you an insight into any errors, warnings, or informational items that Microsoft deems to be not concurrent with best practices. The results of our BPA scan on the DNS role are shown in Figure 30.7.
