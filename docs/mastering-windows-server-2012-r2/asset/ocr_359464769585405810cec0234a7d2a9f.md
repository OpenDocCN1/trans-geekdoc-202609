You can move all contents of Documents in the profile when the redirection policy applies. This is on by default and probably what you will want to do. However, you have the option to turn this behavior off.

You can change what will happen when the policy you are configuring no longer applies to a user. The default is that the redirected folder and contents are left where they are redirection is disabled. You can redirect the folder and contents back to the profile in this situation.
