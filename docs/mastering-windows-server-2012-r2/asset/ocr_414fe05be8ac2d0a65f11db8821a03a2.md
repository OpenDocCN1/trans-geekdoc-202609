# UNDERSTANDING NEW USER POLICY

You are not actually creating a new user when you select the New > User option for GPP. Instead, think about it as creating a new user policy! You can create a new user, but there are more options than just creating a new user. Use this "XYZ policy" mentality when you create any GPP setting, and it will help you figure out what you want to do with the setting.
