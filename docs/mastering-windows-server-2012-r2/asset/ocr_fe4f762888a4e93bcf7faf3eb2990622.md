You can also recover a single folder from the command line. The following example shows the C:\ Library folder:

```
wbadmin.exe START RECOVERY -version:05/12/2013-18:39
-items:C:\Library -itemtype:file -backupTarget:E -recursive
```

START RECOVERY This switches wbadmin.exe to begin a restore operation.
-version The switch defines the backup version used for the restore. It is specified in a MM/DD/YYYY-HH:MM format. Use the wbadmin.exe GET VERSIONS command to list all available backup versions.

-items This provides a comma-delimited list of items to restore.
-itemtype This option specifies the type of objects in the -items list can include FILE, APP, and VOLUME. Use separate switches to specify more than one type in a restore operation.

-backupTarget This specifies the location of the backup file you want to use for the restore operation.
