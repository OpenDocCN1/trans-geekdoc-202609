# MIGRATING TO THE REDIRECTED STATE

To migrate the domain to the redirected state, you will perform the following tasks:

+   1. Type the following command at the command line:

```
dfrmig /setglobalstate 2
```

See Figure 7.38 for the output.

FIGURE 7.38
Output of the setglobalstate 2 command

![](bbox=[0.336, 0.27, 0.859, 0.483])

+   2. Type the following command at the command line:

```
dfrmig /getglobalstate
```
