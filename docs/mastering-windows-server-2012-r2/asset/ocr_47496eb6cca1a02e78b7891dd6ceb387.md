# Adding a Printer Active Directory Search

Active Directory is a huge database of objects that can be searched by end users and administrators. Many objects are automatically published in Active Directory (such as users, computers, groups, and shares), allowing users to easily search for what they want. However, printers are not published in Active Directory by default. It's not hard to do so, and once they are listed in Active Directory, users can easily find them with a search

Any printer that has been shared can also be listed in Active Directory as long as it is hosted on a server that is a member of the domain. In other words, printers that are not managed by a print server cannot, right-click the printer,
