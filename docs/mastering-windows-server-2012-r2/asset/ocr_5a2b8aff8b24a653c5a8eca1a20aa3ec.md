# Retrieving Data

With servers now managed and unblocked, you're just ready to go. The last thing that you need to do is to right-click these servers and Retrieve All Server Data from the context menu. This will populate the IPAM console with your IP scopes and zones.

# IPAM DATA REFRESH

If you've followed all these steps correctly but don't see the DHCP or DNS data populating the IPAM console, make sure to click the Refresh icon to the left of the Notifications flag at the top of the IPAM server console. We've found that data sometimes take a little longer than expected to come into IPAM the first time a server comes under management, so it doesn't hurt to help it a little by manually refreshing the console.

When the IPAM server configuration has been completed, you can see a new few scheduled tasks configured and to run at different intervals from the Task Scheduler (Local) > Task Scheduler Library > Microsoft > Windows > IPAM view, as shown in Figure 5.14.
