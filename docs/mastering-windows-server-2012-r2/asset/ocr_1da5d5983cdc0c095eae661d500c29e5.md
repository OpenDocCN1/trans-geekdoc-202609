# WHAT'S NEW IN AD CS

Let's discuss the new and enhanced features that come out in this version of Active Directory Certificate Services (AD CS). First off, let's go briefly over what AD CS is. This important security tool provides services for managing and distributing public key certificates. This is primarily used on software security systems that use public key technologies. These services are customizable to enhance your security by binding the identity of a device, person, or service to a certificate.

# Integration with Server Manager

You can install AD CS and its associated roles using Server Manager. So just like we did earlier in the "Adding a Role Section," you can easily add AD CS using the Roles and Features Wizard. It will then appear in the Server Manager dashboard like any other role. And just like any other, you can manage it on multiple servers from one location.

# Deployment and Management Using Windows PowerShell

+   - Install-AdcsCertificationAuthority Certification Authority role service

- Install-AdcsEnrollmentWebService Certificate Enrollment Web role service
