# Adjusting Print Server Settings

Several settings apply at the server level and can be configured to apply to all resources (drivers, forms, ports, and printers) managed by that server. You can also export and import printers to files and set notifications.

To edit server-wide printer settings, launch the Print Management console, browse right-click the server to view the context menu and access these choices.

# Server Properties
