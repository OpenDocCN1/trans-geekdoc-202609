# # Active Directory Federation Services

Active Directory has made managing domains so much easier for administrators over the years. We can share with and connect to multiple applications and organizations rather easily in a secure manner. One of the great services offered to us by the Windows Server family ever since Server 2003 R2 is Active Directory Federation Services (AD FS). AD FS is a software component developed by Microsoft that can be installed on Windows Server to provide users with single sign-on (SSO) to applications and services across boundaries that were previously unreachable with a single login account. AD FS issues a secure token to an entity, allowing it to cross organizational boundaries while maintaining application security. This technology gives us the freedom to cross multiple forests and authenticate into a-based applications and websites using a single trusted account to log everything.

Windows Server 2012 R2 has taken the AD FS abilities to include the ability to federate multiple AD forests and expanded functionality to now federate between two or more Active Directory Domain Services (AD DS) systems. The newest version, AD FS 2.1, is automatically included with this server edition, allowing us to manage identities across multiple platforms, including non-Microsoft environments. This added benefit allows organizations with multiple subsidiaries that house their own Active Directory Directories to share and exchange directory information among themselves. We can extend this ability even further by providing access to cloud services, allowing an SSO to use one login to reach multiple services and applications outside the corporate network. As you can imagine, trying to manage all identities across a large realm of directories can be difficult. Luckily for us, Microsoft continues to provide excellent directory synchronization tools like Frontend Identity Manager (FIM). FIM allows organizations to synchronize identity information across a multitude of heterogeneous directory stores. AD FS and FIM work in hand to provide both users and administrators with the proper functionality and ease-of-use to securely provide SSO access to resources across multiple environments around the world.
