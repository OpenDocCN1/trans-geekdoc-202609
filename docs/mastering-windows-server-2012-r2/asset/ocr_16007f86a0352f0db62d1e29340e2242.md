To create a virtual disk you need to use the cmdlet New-VirtualDisk. But you need to know the storage pool name before you start. You do remember the command for getting the storage pool friendly name?

Once you have the friendly name, follow these steps:

+   1. Use the following syntax to store the storage pool in a variable:

```
$sp = (get-storagepool).friendlyname
```

The next step is to create the virtual disk, but we'll show you the full syntax first:
nNew-VirtualDisk -StoragePoolFriendlyName $sp[1]-ResiliencySettingName -Size 50GB -FriendlyName TestDisk -ProvisioningType Thin -NumberOfDataCopies 2

As you can see, there are a few more options to select. Let's look at them:

**ResiliencySettingName** Equivalent to the storage layout options of Simple, Mirror, Parity.

**NumberOfDataCopies** The number of copies of the disk you want to keep: is directly related to ResiliencySettingName. If you choose Simple, for example, NumberOfDataCopies can only be 1. If you choose Mirror, the NumberOfDataCopies will be at least 2, depending on the amount of disk space you have in the system.

**NumberOfColumns** Directly associated with the disks but you may want to stripe or mirror or parity A storage pool may have hundreds of disks but you may want to stripe or mirror or parity only five disks. This option gives you the choice. This option is also related to both ResiliencySettingName and NumberOfDataColumns.

The values selected for NumberOfDataCopies and NumberOfColumns are related to the options we select. For example if we want to mirror our data the NumberOfDataCopies and if we can span our Vdisk across multiple disks increase the NumberOfColumns. In our case we will want 1 copy of the data and we to write the data across 2 disks.

+   2. The $sp[1] option selects element out of all the storage pools we captured using the get-storagepool command. If we have 5 storage the get-storagepool command will return all 5, this is not good so using [1] allows us to select the storage pool which is number 2 out of 5 we captured. So the first storage pool can be retrieved with $sp[0].

In our environment we have multiple storage pools. If we just referred $sp, the command would fail if it tried to insert (in case) the storage pool friendly names.
