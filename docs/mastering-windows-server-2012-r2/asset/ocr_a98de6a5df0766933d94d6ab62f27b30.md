# CONNECTING TO SHARES

Once the operating system connects, retrieves a list of shares that are available. On this server are currently four shares, well, four shares that aren't hidden. Chapter 14 will show you how additional hidden shares are available. You could type in Apps to connect to the \BFI\Apps, or simply connect the Apps share from the menu in Figure 13.19 and click OK to connect the shares.

Besides using the Search, you can connect a drive to a share in the following ways:

+   **Mapping a Drive** You can map a drive to a share on your network. For example, users may need access to a share each they boot. You can right-click either Computer or Network from the Windows Explorer and select Map Drive. Take a moment to enjoy the new feel of the Server 2012 R2 interface. When you open, select Computer, and then select the Computer option from the top bar. A new ribbon will be displayed similar to the ones you are familiar with in programs like Microsoft Word. New many options are available from the ribbon, including Map a Network Drive. Figure 13.20 shows the Map Drive dialog box. With "Reconnect at sign-in", the user will always have the Z drive mapped to the share when they boot.
