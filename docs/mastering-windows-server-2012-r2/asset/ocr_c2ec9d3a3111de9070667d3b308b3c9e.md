# # Creating and Managing User Accounts

Probably one of the most common tasks an administrator will do, not only during deployment but also during the life of a Windows Server environment, is to create and manage user accounts. This sounds like a pretty simple task, but it is a very important one of the time management and security implications. It's important for server administrators or consultants to understand the process. They might think they can ignore it because they don't create user accounts in normal operations. That may be true, but they are usually the people responsible for creating the first users in a new network, defining the processes, and handling over the operation to another team, department, or customers. The same senior staff members also need to be able to create and manage user accounts for services and applications on their servers by following best practices.

We'll cover the basics of creating and managing user accounts so that everyone has something to gain from this chapter. In any situation where you need the skills to manage your situation. We will create and manage user accounts from the command prompt and PowerShell. Don't let that scare you, you've already seen in previous chapters that the keyboard alternative can sometimes be a real-time and effort-saver; you'll see this trend continues here.

We will discuss some of the common properties and settings that you can configure for user accounts. We will also discuss why you would use them, how to add/remove users to from groups, and best practices for group membership assignment. We'll cover all of these subjects in environment: a stand-alone Windows server management, a Core installation, and Active Directory.

We will show you the Windows Server 2012 options, most of which are identical to Windows Server 2008 R2. It has new wrinkles, in the form of a new task and PowerShell-driven management tool called the Active Directory Center, which is totally built on top of PowerShell. Microsoft has added many more Active Directory modules for management via PowerShell, its shell and scripting language. So, we'll wrap up the chapter with a section covering those subjects. We believe that you will finish this chapter thinking that those will be a major time-saver.

In this chapter, you'll learn:

+   - Manage users and groups

+   - Use the Active Directory Administrative Center in Windows Server 2012

+   - Manage users and groups with PowerShell
