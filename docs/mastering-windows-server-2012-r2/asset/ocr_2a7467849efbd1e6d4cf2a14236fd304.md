Before leaving this topic, we'll make a few points about using AD DS to build domains. AD DS is kind of rigid about the order in which you create domains:

+   1. The first domain that you create in a forest is the root domain, and there's no changing that.
2. You should create at least one additional domain controller for the new domain. This provides fault tolerance for the domain.
3. You have to add domains by creating them through AD DS in relation to the existing

domain, you can't create a domain named Green.com and another named Yellow .com separately and later decide to merge them into a forest. Instead, you must create Green.com as the first domain in a forest and create Yellow.com as the first domain in a new tree in an existing forest.
After the reboot, you should examine your fully outfitted Ec1.Test.com. Check its IP configurations with ipconfig /all, and verify that it lists the DNS server (:) for IPv6 and 127.0.0.1 for IPv4.
