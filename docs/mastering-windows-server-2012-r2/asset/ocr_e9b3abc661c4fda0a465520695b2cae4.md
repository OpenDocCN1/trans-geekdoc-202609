Use deduplication techniques to reduce file size. Part of the reason behind data growth
today's environments is the availability of storage, but storage will become a problem sooner
rather than later. A high percentage of these files contain a large degree of identical data patterns,ut using deduplication techniques can dramatically reduce the disk space required and\make better use of the storage in place.

Master It In your lab copy an ISO multiple into different times, and repeat for
office documents that are not located on your System volume. Enable Deduplication on
the drive, and exclude a share of importance in your environment.

Solution Deduplication in Windows Server 2012 R2 can be managed via PowerShell.
Here we outline the steps you will take to work with deduplication and some of the cmd-
ents you would use.

+   1. From PowerShell type,
Enable-DedupeVolume -Volume E:\where E: is the volume you are trying to dedup.

+   2. Exclude a folder using PowerShell:
Set-DedupeVolume -Volume E:-ExcludeFolder E:\shares

+   3. Verify all the information using:
Get-DedupeVolume -Volume E:|fl *

+   4. Change the file age to 0 days so all files are immediately considered for dedup:
Set-DedupeVolume -Volume E:-MinimumFileAgeDays 0

+   5. Start an optimization job:
Start-Dedupjob -Type Optimization -Volume E:

+   6. Verify that space savings have been made:
Get-DedupeStatus -Volume E:
