# CHAPTER 3 INTRODUCTION TO SERVER CORE

Now that you know the parameters required to create an inbound rule, we'll look at the leatherneck method. The embedded help information provides the following syntax for creating a firewall rule. Note that this was performed in the netsh interactive shell. It could be done as one command line well:

```
netsh advfirewall firewall=add rule ?
```

```
Usage: add name=<string>
dir=inout
action=allow|block|bypass
program=<program path>
service=<service name> any
description=<string>
enable=yes|no (default=yes)
profile=[public|private|domain](...
localip=<IPv4 address|<IPv6 address><subnet>|<range>|list>
rememoteip=<localsubnet|dhcp|wins|defaultgateway>
IPv4 address|<IPv6 address><subnet>|<range>|list>
localport=0-65535|<port range>[...]|RPC-EPC-PM|IPHTPS|any (default=any)
remotport=<port range>[...]|any (default=any)
protocol=0-255|icmpv4|icmpv6|icmpv4:type,icmpv6:type,code
tcp|udp|any (default=any)
interface=wireless|lan|any
rmtsusgrp=<SDL string>
edges=yes|deferrer|deferral|no (default=no)
security=authenticate|authencate|authynenc|authnoenc|notrequired (default=required)
```

The list of parameters is long and intimidating. However, the "Server Core Survival Guide" section you could look for at the end of the embedded help. You can edit this in Notepad to create what you need. Notice that the command line doesn't give you much fanfare for your accomplishment:

```
PS C:\Users\administrator> netsh advfirewall firewall add rule name="Windows Remote Management HTTPS"
description="Opens Port 5986 for remote management using WinRM protocol=TCP
dir=in localport=5986 profile=domain action=allow
Ok
```

Here's an explanation of the parameters that translate to the wizard guides:
**Add rule** In the snap-in, we had to right-click the Inbound Rules object and select New.
Name&description=** This is the information on the last page of the wizard, as shown in Figure 3.18.

**Protocol= localport=** This information was added in Figure 3.15.
**Dir=** This indicates the inbound part of the rule. The direction was set by selecting the New Inbound Rule Wizard.
