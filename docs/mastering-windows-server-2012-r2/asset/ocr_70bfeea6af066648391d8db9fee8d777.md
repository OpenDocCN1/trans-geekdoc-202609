# CHAPTER 1 WHAT'S NEW IN WINDOWS SERVER 2012 R2

What being command-line-centric does for the Unix/Linux world, however, is to make automating tasks easier in Unix/Linux than it would be to automate many Windows administrative tasks. (You can put a command-line instruction in a batch file, which can then automate whatever you are trying to accomplish. You can't put mouse clicks in a batch file.) So, Microsoft is trying to give Windows the “automation ability” that it lacks and Unix and Linux have with a command called PowerShell. It's designed to let you take baking tasks and automate them. Until the learning curve to use PowerShell was quite steep.
