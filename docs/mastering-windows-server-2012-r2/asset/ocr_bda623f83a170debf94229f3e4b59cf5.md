# XML Paper SPECIFICATION

XML Paper Specification (XPS) is based on Extensible Markup Language (XML), an industry standard that has been steadily creeping into many current technologies including databases, web services, and printing. HTML (used for web pages) is based on XML. XML data is contained in a simple text document that can be read with simple applications such as Notepad, and can be used to hold a significant amount of data and metadata.

# XPS ON THE INTERNET

Microsoft has embraced XPS and has published a lot of material detailing how it is used in Microsoft products. The XPS home page is at www.microsoft.com/whc/xps/default.aspx. Additionally, ECMA is the driving force for standardizing XPS across platforms. You can access details from meetings and available documents at www.ecma-international.org/memento/TC46-N.htm.

Metadata is used to describe the data. For example, metadata within a print document might be used to identify all the data on page 1, 2, and so on. It could also be used to describe how the data should be displayed as the font style or size.

Microsoft has embraced the XPS document format based on the Open Markup Compatibility specifications and Open Packaging Conventions (OPC). The version is for much better efficiency, compatibility with applications, and higher quality when XPSdriv drivers are used.

XPS is similar to the Portable Document Format (PDF) created by Adobe Systems for document exchange. We're betting that you've opened a PDF document during your travels since PDF documents are so widely used. The cool thing is that the person who creates the document can control what it looks like when it prints. Compare this to a simple Word document that may print one by one on one printer but another on another.

You can create XPS documents from Microsoft Office 2012, and these documents can be shared as PDF files. Select As ➢ XPS Document to save your document in this format. Users who have an XPS view can view the documents, as users can view PDF files if they have a matching version of Adobe Reader. In addition to saving files as XPS, the documents can be translated to the XPS format so they can be used by XPSdrv drivers.

# XPSDRIV: THE NEW PRINTER DRIVER MODEL

Print drivers created advantage of the new XPS format are referred to as XPSdrv drivers. These drivers provide greater flexibility than the older Graphics Device Interface (GDI) graphics processing functions that were used before XPSdrv drivers.

XPSdrv drivers use the XPS document format to provide a better-what-you-see-is-what-you-get (WYSIWYG) output from printers. A greater range of colors can be used, and other graphic outputs such as transparent areas and gradients are possible.

Since the XPSdrv printer uses the XPS format and the XPS format produces smaller spooled files than the GDI, the overall size of spooled printer files is reduced.
