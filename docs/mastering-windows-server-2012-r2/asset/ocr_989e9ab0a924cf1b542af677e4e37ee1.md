The best thing to do is to develop a pilot environment and generate loads on your “proof-of-concept” servers monitoring the performance and responsiveness of the servers and applications. # AUDITING YOUR CURRENT INFRASTRUCTURE

It is critical that you accurately audit your existing infrastructure if planning a major change such as a server operating system deployment. Microsoft has provided a free suite of tools in the Microsoft Assessment and Planning Toolkit for Windows Server 2012 R2 (http://tinyurl.com/ycpuk3). This easy-to-use toolkit can audit your servers as well as check hardware and driver compatibility. From this you can create reports to plan any changes.
