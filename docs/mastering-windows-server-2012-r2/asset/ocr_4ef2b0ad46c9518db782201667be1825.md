If you look at the Windows Services console, you will see that the File Replication Service has been set to Disabled (Figure 747).

With that, you have migrated your SYSVOL replication from FRS to DFS-R and gathered all the benefits of remote differentiation compression. You have taken something that is truly old in the SYSVOL folder and DFS replication migrated it to something new in SYSVOL_DFSR and DFS replication.
