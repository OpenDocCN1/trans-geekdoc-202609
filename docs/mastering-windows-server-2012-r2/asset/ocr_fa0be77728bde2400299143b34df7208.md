Next, under Share Permissions click Add. Then in the Add Permissions dialog, select All Machines, and for “Language encoding” select ANSI. Choose Read / Write for “Share permissions,” as shown in Figure 12.68.

On the “Specify permissions to control access” screen, verify that the Everyone exists and has been assigned Full control, as shown in Figure 12.69.

Confirm the details and click Create to create the new NFS share.

Verify that it was successful and click Close.
