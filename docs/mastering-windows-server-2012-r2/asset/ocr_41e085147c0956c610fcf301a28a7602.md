# Site Uniqueness

Earlier in this chapter we discussed multiple sites within a single instance of IIS by employing unique site bindings, selecting a particular IP address configured on one or more NIC interfaces, specifying a custom "non-80" TCP port number, or adding a custom host header to the new site. They assist in correctly routing requests, TCP/IP bindings are not the only way to differentiate a site from other sites on the same server.

Recall that the creation of a new website automatically creates an application pool for the new site and application pools share the same name as the site. Keeping in mind that new application pools mentioned in this chapter, you can affect the identity of all application pools by editing the Identity property in the Application Pool Defaults (Figure 19.17). The Identity value in IIS 8 is the default, which can be altered to LocalService, LocalSystem, NetworkService, or a named account of your choice.
