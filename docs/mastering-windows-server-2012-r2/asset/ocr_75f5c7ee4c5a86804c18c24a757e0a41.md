write network addresses using "10.0.0.0-10.0.0.255" or "10.0.0.0 with netmask of 255.255.255.0", network
administrators used a shorthand notation, writing a slash after the network number and then

would be noted by describing it as "10.0.0.0/8".

The Internet is ruled by RFCs, which we've already mentioned, and this shorthand notation
was no exception. RFC 1198 defined the original solution as Classless Inter-Domain Routing
(CIDR), and the name has held up.

In fact, the shortcut has been carried over into IPv6; you will see that IPv6 network
