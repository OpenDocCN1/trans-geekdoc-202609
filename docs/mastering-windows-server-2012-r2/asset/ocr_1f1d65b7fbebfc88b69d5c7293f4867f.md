You cannot directly change a group from a domain local group to a global group, or vice versa. However you can change either scope to be a universal group. From there, you can change it back to a domain local or a global group. Make sure that the member list does not conflict with your referred group-scope. You need to be sure that your group is not used in another domain if you are migrating a domain local group. This would cause loss of access to secured members of the group. Administrators in larger forest enrollments need to be aware that they are potentially adding new traffic to catalog replication when converting an existing group into a universal group.

The member functionality for domain-based groups works just like that of local groups. Open the properties of a group, as shown in Figure 8.57. You can add and remove members using the Add and Remove buttons.
