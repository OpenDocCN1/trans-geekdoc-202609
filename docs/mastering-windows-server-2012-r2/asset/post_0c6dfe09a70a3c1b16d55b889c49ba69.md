## Monitoring Windows Server 2012 R2

The best time to know about a problem before it happens. This is as true in the IT world anywhere else. If you want to know about potential problems with servers before they morph into a full-blown crisis, you have to monitor them.

With a bit of proactive monitoring and the right tools, you can identify minor errors and negative trends before they turn into hardcore problems.

In this chapter, we will first discuss some of the basic tools that come into Windows Server 2012 R2 that help you gain an understanding of any errors or performance issues. These monitoring tools are the Server console, Best Practices Analyzer, Event Viewer, Performance Monitor, and Resource Monitor. Once you understand how to use these, we will talk about two additional (and little-known) external tools—PAL and PerfView—that can be used to deliver deeper performance analysis. Finally, we'll discuss Microsoft's recommended solution—System Center 2012 R2 Operations Manager—and how it can help you quickly analyze the root cause of problems on your Windows Server 2012 R2 workloads.

In this chapter, you will learn to:

- Use Server Manager to monitor multiple servers
- Understand how to use Event Viewer
- Explore Performance Monitor
- Explore the PAL and PerfView tools
- Understand System Center 2012 R2 Operations Manager

## Using Server Manager to Monitor Multiple Servers

The new Server Manager console in Windows Server 2012 R2 delivers out-of-the-box monitoring and health checks of your local and remote infrastructure. In the “Troubleshooting Roles and Features” section from Chapter 2, you learned how Server Manager can monitor a single server and its associated roles. This section will elaborate on that information and will discuss how to utilize Server Manager to monitor multiple servers and the roles they are responsible for, all from one central console.

## Adding Servers to Manage

You can add additional servers to manage and monitor with Server Manager by following these steps:

- 1. Log on to your Windows Server 2012 R2 computer with an elevated account that has administrative permissions.
- 2. Click Server Manager ➢ Dashboard.
- 3. Choose the “Add other servers to manage” option from the Quick Start tab.
- 4. From the Servers dialog box and in the Active Directory tab, filter by location and operating system; either type the beginning of a name for the servers you want to add or click the Find Now button to display all servers for your chosen options.
- 5. Double-click (or Ctrl+click) each server you want to add to the Selected column; then click OK.

Now in the Dashboard, you can see the “Servers total” value under Servers reflect the number of servers you’ve added.

- 6. Click the View menu from Server Manager, then choose All to see the individual server status (green for healthy and red for unhealthy).

## Creating a Server Group for Monitoring

When you add multiple servers to the Server Manager console, you are presented with a view of each server, and this is where groups can come in. To create a server group that contains all the servers you wish to monitor, do the following:

1. Log on to your Windows Server 2012 R2 computer with an elevated account that has administrative permissions.
2. Click Server Manager ➢ Dashboard.
3. Choose the “Create server group” option from the Quick Start tab.
4. In the Create server group dialog box, type a server group name in the field; select multiple servers to add to the group from the Server Pool, then click OK.

## Monitoring with Server Groups

When you have configured your server groups, you can quickly identify if there's a problem with any servers within:

- Manageability: Here you can see some standard monitoring metrics that determine if a server’s manageability error criteria have been met.
- Events: This area gives you a centralized view of all the Critical, Error, and Warning events that occur on your servers.
- Services: Here you get an overview of the services that are running (or not running) on your chosen servers.
- Performance: The Performance area gives you a monitored view of the CPU and memory resources that use on your chosen servers.
- BPA Results: This area shows the different security levels (Information, Warning, and Error) that are generated by the Best Practices Analyzer (BPA) has run.
