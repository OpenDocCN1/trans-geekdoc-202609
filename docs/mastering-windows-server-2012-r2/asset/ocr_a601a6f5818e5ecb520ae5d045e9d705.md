# Local Groups

Just like a user, a local group exists within a member or stand-alone computer, it be a server, laptop, or desktop. It can contain local user accounts that exist on the server. It can also contain users or groups from the Active Directory that the server is a member of. You can manage groups using the GUI tools to manage local groups. Figure 8.35 shows how you manage groups on a server. You can see that there are a number of them by default. Windows will also add more groups if you create roles.
