There are a few server requirements to keep in mind when deploying a federation server proxy.

+   * There must be a federation server on the internal corporate network to communicate with.
* The proxy server must have a trusted SSL certificate with a subject name that matches the federation server name.
* Proper DNS entries will need to be configured.

The steps for adding the Federation Server Proxy role are similar to configuring a new federation server role discussed previously in this chapter:

+   1. Launch Server Manager, and from the Dashboard tab, select the link Add Roles and Features, or select the same function from the Manage drop-down.

+   2. Navigate through the wizard as you normally would by selecting the installation layer type and select options.

+   3. When you get to the Server Roles page, select the Federation Service Proxy role, as shown in Figure 10.18.

![](bbox=[0.163, 0.433, 0.904, 0.753])

Please note the Federation Service Proxy role and the Federation Service role cannot be installed on the same server.

+   4. If you need or want any additional features on this server, make sure to add them on the Features page of the wizard.

+   5. Continue through the Confirmation and Results pages to complete the steps for installing the Federation Server Proxy role.
