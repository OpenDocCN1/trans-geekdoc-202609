You can also see that roles and features are installed. You may remember that a Windows Server 2012 R2 installation has nothing installed by default. That's true. In this example we just upgraded a server. The server that we upgraded had no additional components installed. But Windows Server 2012 R2 saw it differently. It saw important functionality that it believed should be retained in case it is being used. You'll later learn how to use Server Manager or PowerShell to add or remove roles and features.

You will probably want to ensure at this point that you follow the following:

+   - Check the logs in Event Viewer to see whether there are any problems that need to be resolved.
- Join a domain, if required, and make sure all applicable policies are applied.
- Install all available security updates.
- Install any security software as antivirus software, and apply any required security configurations.
- You may have third-party software to install, configure, or diagnose.
