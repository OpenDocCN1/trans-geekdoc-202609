### Joining the Domain

To join a domain from any Windows operating system, you'll need the following information:

- The fully qualified domain name or NetBIOS name of the domain
- The name and password of an account with permission to join the domain

Joining a domain is easy. The main places you're likely to run into trouble are not knowing the right domain credentials and supplying the wrong computer name. Local administrators can't join computers to the domain, and shouldn't join a computer to the domain using the same name as a different computer that previously joined and has a computer object in Active Directory. In replacement scenarios, utilizing the same computer account is acceptable; for example, if a laptop has hard drive replaced, using the Active Directory Users and Computers to properly delete the old computer object is the best practice for this. Additionally, making sure you have given enough time to replicate to other controllers so you have no conflict in the name. Make sure the computer name is unique and that you have the credentials to join the domain.

By default, Windows Server 2012 allows regular users to join up to 10 computers to a domain. By default, domain admins can also delegate this right to other users via Group Policy. For information on how to delegate this right, see: http://technet.microsoft.com/library/dd9267. Client computers always start out belonging to WORKGROUP. That's the beginning for all operating systems discussed in this chapter.

### ADDING DOMAIN ACCOUNTS TO LOCAL GROUPS

When on a domain, domain accounts have to be added to a local group on the computer. This is true for all Windows 8, Windows 7, and older versions back to Windows 2000/XP. When a computer is joined to a domain, the Domain Admins group gets added to the local group on the computer. Domain admins fully manage the machine (add or remove hardware, install software, and so on). Likewise, the Domain Users group gets added to the local group on the computer. Domain users are now afforded normal user rights on the computer (management tasks, such as using software, accessing network resources, and so on).

### Joining a Domain from Windows 8

Typically, you'll join the domain from a computer connected to it, but Windows 7 and Windows 8 support both online and offline joins.

## WINDOWS RT AND ACCESSING RESOURCES

Windows RT is a different type of operating system than Windows 8, but it carries many of the same feature sets and access capabilities. While you cannot join an Active Directory domain, as stated earlier, you can access resources on the network.

Microsoft's System Center Configuration Manager 2012 SP1 supports the management and configuration of Windows devices through its advanced mobile device management (MDM) configurations.

The more common way of accessing resources is via Windows File Explorer; you can use this tool to manage files and folders as you can on the non-RT OSs. Through File Explorer you can map your network devices, access shares, and ever storage devices. To access the network, Windows RT fully supports many connection types:

- Wireless Networks: You must manually set the connection and configurations on networks, having the appropriate SSID, connection accounts, and security details for connection is imperative. Depending on your organization's security practices, you may have limited access to resources.
- Wired Networks: Many manufacturers provide an Ethernet port. Most organizations use DHCP, so you will not need to configure your network. If you need to configure an IP address and subnet, you can do so following the same steps you did for Windows 8 via Control Panel.
- Proxy Servers: Since no policies are applied because of the lack of domain joining, you have to manually configure your proxy settings. If you need to detect of internal proxy server you must use the Web Autodiscovery Protocol on your network. This involves configuring specific DHCP options as well as a web server, but as people move to bring-own-device (BYOD) scenarios, you might consider this as an option.
- VPN Connectivity: Windows RT devices can utilize VPN connections to establish a more connected feel to your organization's network. Many IT pros like to utilize this option because it helps with security and access control. Since many VPN options are available for Windows RT, you should review the RT VPN overview provided by Microsoft at http://tinyurl.com/c18tVPN
