从设置对话框管理虚拟机参数

几秒钟后你将拥有一个新的虚拟机。在 Hyper-V 管理器中，你应该能看到第一个虚拟机。

- 13. 选择此虚拟机，操作面板将展开并显示虚拟机的特定选项（在我们的示例中命名为 WS2012R2-SRV），如图 27.29 所示。

这取决于虚拟机的性能等因素。

- 14. 点击“设置”按钮查看虚拟机配置，如图 27.30 所示。

设置对话框是你以后会经常看到的界面。左侧窗格有两个部分：硬件和管理。

硬件部分管理所有虚拟硬件。以下是你在第2 代虚拟机上看到的每个选项的解释：

**添加硬件**：在这里，你可以添加一个 SCSI 控制器，可以使用它可以添加虚拟驱动器。正如我们之前讨论的，在此版本的 Hyper-V 中，你现在可以直接从 SCSI 控制器启动虚拟机，这是唯一的可用选项。

**固件**：这里是新的可扩展固件接口 (UEFI) BIOS 交付启用或禁用安全启动的功能。你还可以选择：DVD 驱动器、网络适配器的启动顺序。

**内存**：图 27.31 显示了虚拟机的内存部分。在图中，你可以看到选定的 512 MB 启动内存，并启用了动态内存来管理由主机分配给虚拟机的内存。最小内存设置允许你指定一个低于实际启动内存（启动虚拟机所需的内存）的内存量，这对于长时间空闲状态的虚拟机非常有用。

# 开始使用虚拟机

# 图 27.31
配置动态内存

![](img/41a83208e6906a3732620203b836cea7_1418_0.png)

通过“最大内存”设置，你可以确定从主机分配给虚拟机的内存量，上限为 2 TB。有用的是，你可以在虚拟机运行时修改此值，但你永远无法分配比物理主机可用更多的内存。你可以通过在此处阅读 Aidan Finn 的白皮书来了解更多关于动态内存的信息：http://www.aidanfinn.com/?p=128

处理器：在这里你可以为此特定虚拟机指定处理器的数量，最多 64 个。启动时，虚拟机将具有指定数量的处理器；当然，它们默认不是启用的。虚拟机程序是处理器的唯一所有者，并决定哪个虚拟机获得多少。在 27.32 中，你使用“资源控制”设置，在其中指定应为此虚拟机保留所选处理器的百分比。上限由...设置，虚拟机永远不会超过此百分比。此功能对于使用 CPU 资源的应用程序非常有用。

兼容性提供了“迁移到具有不同版本处理器的物理计算机”选项，用于 Hyper-V 主机 CPU 略有不同的情况。该功能通过禁用某些 CPU 指令来工作，性能取决于你的工作负载。

# 使用 Hyper-V 进行服务器虚拟化

图 27.32
在 Hyper-V 中配置处理器

![](img/41a83208e6906a3732620203b836cea7_1419_0.png)

NUMA 非均匀内存访问通过主板为虚拟机提供可扩展性。这与 NUMA 选项结合工作。

SCSI 控制器：列表中的下一项是用于向虚拟机的硬盘，它是自动添加的。你可以向虚拟机添加最多 4 个 SCSI 控制器，每个控制器可达 64 TB。如果你计算一下，Windows Server 2012 可以拥有这些。

在 SCSI 控制器部分，你还可以挂载 DVD 驱动器用于挂载 ISO 文件。与早期的 Hyper-V 版本不同，第 2 代虚拟机默认不再可用，这就是为什么在运行新建向导时没有该选项。

当你向 SCSI 控制器挂载虚拟驱动器时，可以点击驱动器旁边的符号以访问高级功能区域。在这里，你可以为虚拟磁盘开启服务质量管理，以 8 KB 为单位确定 IOPS 的最大值。你还可以在此处启用磁盘共享，将特定磁盘用于聚类场景。这些高级选项如图 27.33 所示。

高级虚拟硬盘功能

网络适配器虚拟连接由网络适配器对话框管理。对于网卡，你可以从下拉菜单选择任何虚拟交换机。你可以在虚拟机运行时更改绑定，这是一个非常强大的功能。从虚拟机的角度来看，这就像是将电缆从一个交换机拔出并插入另一个。一种方法是安装操作系统、通过 Windows 更新进行，并连接到另一个交换机。

扩展网络适配器选项提供以下设置，如图 27.34 所示：

硬件加速：在这里你可以执行卸载到物理网络适配器。首先是“虚拟机队列”，它将虚拟网卡的 MAC 地址绑定到物理网卡的队列上，优化虚拟机的网络流量。

列表下一个是“IPSec 流量负载”。它允许将 IPSec 流量加密和解密的处理卸载到硬件，以释放主机资源。

最后一个（也是最吸引人的）加速选项是“单根 I/O 虚拟化 (SR-IOV)”。此功能需要专用硬件，但如果你愿意投入时间和资金，回报是值得的。SR-IOV 的理念是替换虚拟机连接中的虚拟交换机，并将流量直接路由到连接主机的特殊 SR-IOV 物理网卡。这意味着 CPU 利用率、网络延迟和网络吞吐量将获得巨大的提升。
