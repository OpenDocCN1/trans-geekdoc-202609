# The Case for an Empty Root

Refer to Figure 24.1. In that figure, you see an extra root domain, Consolidated.com, in addition to Test.com, and as Test's child domain, Eastcoast.Test.com. We did to make the diagram "look"—right but we use to see domain hierarchies up at a single point.

In a tree, it simpel to see which domain is the root or top-level domain—Consolidated.com is the top of the Consolidated.com tree, and Test.com is the top of the Test.com tree. But when you build two trees (Consolidated.com and Test.com) into one, then which domain is the top, or root, domain? There isn't a right and all trees are equal?

In an Active Directory forest built of several trees, there is a single-forest domain root. It's just not obvious one it is.

So suppose you come across an AD forest that contains three domains—Test.com, Apex.com, and Consolidated.com. Which domain is the root? The answer isn't obvious because the three seem to sit at the same level. We don't know of any way to find out which domain is the root, but it's a slightly slower one. Remember that only the root domain contains a group named Enterprise Admins; > Active Directory Users and Computers. In the left pane of the MMC snap-in, you'll see icon representing a domain; it looks like three power PCs clustered together. Right-click that icon, and choose Find. In the dialog box, there's a drop-down list labeled In, which lets you to search any one of your forest's domains. Click it, and you'll see that you have the ability to search your top-level domains. Then notice the field labeled Name: enter "enterprise", and press Enter. If the search finds a group labeled Enterprise Admins, then you've found the first one. Open the In list, and try another domain until you locate the one with Enterprise Admins.

Suppose Test.com turns out to be the root domain in your Test/Eastcoast/Consolidated example. There are probably three domains because there are, or at some time, three different business entities that for some reason are one firm now. Who cares if the Test guys have to be the forest root?
