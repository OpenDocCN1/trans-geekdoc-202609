

# 克隆的多个主机要求

如果您正将 DC 从一个 Hyper-V 主机克隆并放置在另一个主机上，则需要确保在导出和导入的节点上，虚拟网络交换机的名称完全相同。例如，如果您在 Host1 上有一个名为 VMEXT 的虚拟交换机，那么您在 Host2 上也需要有一个名为 VMEXT 的虚拟交换机。此外，如果您的处理器不同，请确保在您计划首先导出的虚拟 DC 上勾选“迁移到具有不同处理器版本的物理计算机”选项。

# 克隆虚拟 DC

一旦准备好所有先决条件，您就可以按照本节中的步骤操作并完成第一个虚拟 DC 的克隆：

- 1. 使用域管理员帐户登录托管 PDC 模拟器的 DC，并选择“服务器管理器 > 工具 > Active Directory 用户和计算机”。
- 2. 展开域根节点，然后点击“用户”组织单元。

您应该看到“域控制器”安全组，如图 28.2 所示。

图 28.2
可克隆的域控制器安全组

![](img/41a83208e6906a3732620203b836cea7_1438_0.png)

此组由 Active Directory 团队管理，用于控制哪些 DC 被克隆。在低安全性环境中，Active Directory 团队和虚拟化团队是独立的实体，确保对 DC 等关键服务器的授权由 AD 团队管理。如果您没有看到此组，说明您没有如前所述使用 Windows Server 2012 DC 作为 Active Directory 模拟器。

# 第 28 章 管理虚拟机

- 3. 双击“可克隆的域控制器”组，选择“成员”选项卡，然后点击“添加”按钮。
- 4. 更改“对象类型”以搜索类型为计算机的的对象；然后输入您的模板虚拟 DC 名称 (WS2012R2-DC2)，点击“添加”按钮。
- 5. 点击“确定”关闭窗口，并确认模板虚拟 DC 已添加到组中。

现在模板虚拟 DC 已授权克隆，您必须确保运行其上的所有实例（如果有）都能被安全地克隆。

- 6. 为此，使用具有管理权限的帐户登录虚拟 DC，并运行 `Get-ADDCloneExcludedApplicationList` 命令行。
- 7. 在生成的应用程序列表中，检查相关的软件供应商，以确定它们是否支持克隆（如果适用）。
- 8. 要提供这些应用程序，在特权 PowerShell 提示符中运行 `Get-ADDCloneExcludedApplicationList -generateXML`。

这将创建一个位于 %wind%\NTDS\CustomCloneAllowedList.xml 的新 XML 文件，如图 28.3 所示。

- 9. 继续在模板虚拟 DC 上使用 PowerShell，现在需要运行 `New-ADDCloneConfig` 命令，并带上新 DC 需要的所有相关参数（主机名、TCP/IP 等）。

运行此命令将创建 `CloneConfig.xml` 文件，该文件用于触发并确保克隆。您可以获取此命令的完整语法选项：http://technet.microsoft.com/en-us/library/jj15894。

> 图 28-3 为克隆准备应用程序

![](img/41a83208e6906a3732620203b836cea7_1439_0.png)

- 10. 输入以下内容以创建 DCCCloneConfig 文件（替换适用于您环境的参数）：

```
New-ADCCCloneCloneConfig -Static -IPv4Address "192.168.0.210" -IPv4DNSResolver "192.168.0.108" -IPv4SubnetMask "255.255.255.0" -CloneComputerNameWS2012R2-DC3" -IPv4DefaultGateway "192.168.0.254" -STName "DUBLIN"
```

- 11. 现在显示虚拟模板 DC（示例中为 WS2012R2 DC），并在继续之前删除可能创建的任何检查点。
- 12. 从 Hyper-V 管理器中选中关闭状态的虚拟模板 DC，点击“操作”窗格中的“导出”打开“导出虚拟机”对话框，选择虚拟存放的位置（如图 28.4 所示），并点击“导出”按钮。

导出过程完成后，您可以将导出的文件复制到另一个 Hyper-V 主机（如果您想在那里部署新的克隆 DC），或者如果只有一个主机可以工作，只需将其留在原处。

- 13. 无论您选择在 Hyper-V 主机的何处存放导出的文件，请在此部署新的克隆 DC，打开 Hyper-V 管理器，并从“操作”窗格选择“导入虚拟机”选项。

图 28.4
导出虚拟模板 DC

![](img/41a83208e6906a3732620203b836cea7_1440_0.png)

- 14. 在“导入虚拟机”向导中，点击“下一步”进入“定位”对话框，然后浏览到导出文件的位置。
- 15. 点击“下一步”。
- 16. 在“选择虚拟机”对话框中，确保选择了模板虚拟 DC。
- 17. 在“选择类型”对话框中，确保选择了虚拟机，然后点击“下一步”。
- 18. 在“导入设置”对话框中，为文件选择位置（如图 28.4 所示），并点击“下一步”。
- 19. 点击“下一步”进入“摘要”页面。
- 20. 导入完成后，点击“完成”。
