# CHAPTER 7 ACTIVE DIRECTORY IN WINDOWS SERVER 2012

Make sure you document the password you set here. Many organizations document critical passwords by writing them down and storing them in a safe. You won't be to access DSRM command without this. The DSRM administrator account password is sometimes confused with the regular administrator password you set for the Domain Adm account, but it is different. From a security standpoint, this DSRM password is critical in that you can locally log onto a domain controller and use it to gain access to the Active Directory database. If you realize all passwords are stored in this database, you will think twice about where you store the DSRM password.

# CHANGING THE DSRM PASSWORD

If you have 100 domain controllers, it is somewhat difficult to control each DSRM password, or you might need to change a DSRM password, by running the DSGMNT or NTDSUTIL on a running domain controller. You don't need to enter DSRM mode to change the DSRM password. You can find more about this TechNet:

http://tech.microsoft.com/en-us/library/cc75334.aspx

One geeky to keep your DSRM password known to you is to synchronize the password with a domain account. How does this work? First, you need to create a domain user account, let's say DSRMaccount. This can be a regular domain user account. Next, start an elevated prompt and type the following command:

```
NTDSUTIL
Set password
SYNC FROM DOMAIN ACCOUNT DSRMaccount
Q
```

![](bbox=[0.274, 0.574, 0.755, 0.672])

Your DSRM account is synchronized with the DSRM Account in Active Directory. This does not permanently synchronize the password; it synchronizes it for the moment. Therefore, if you change the DSRM Account password, you'll need to execute the command again. What could either apply a GPO to all domain controllers or write a PowerShell script to execute this command on all domain controllers. You would just to call C:\Windows\System32\NTDSUTIL.exe and submit the parameters as shown:

```
"SET DSRM PASSWORD" "SYNC FROM DOMAIN ACCOUNT DSRMaccount" Q Q
```
