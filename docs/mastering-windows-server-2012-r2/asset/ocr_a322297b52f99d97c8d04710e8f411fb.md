Before you now, we should quickly address a question that might be popping up at this point. What is something like My Documents if it is redirected to a file server and you are a user who travels without a laptop? By default, redirected folders are replicated to the local computer using Offline Files. Offline Files create a secure cache of the files When connected to the network, the computer will synchronize the Offline files cache with the shares on the file server(s).
