# The Bottom Line

Create a site. Site objects are added to Active Directory to represent well-connected physical locations that will host domain controllers. Once a decision has been made to place a DC in a physical location, you need to add a site.

Master It Create a site to represent a new business location in Virginia Beach.

Add subnets to sites. Active Directory uses clients' subnets to determine which site they are in. For this work, subnet objects need to be created and associated with sites.

Master It Create a subnet object to represent the 10.15.00/16 subnet that exists in the Virginia Beach area. Associate the subnet object with the VB site.

Configure site to replicate only during certain times. It often often desirable to restrict replication between sites. If the defaults are used, replication will occur every 180 minutes. If the WAN is heavily used during certain periods, you can configure the schedule so that it replicates only during certain times.

Master It Configure the Default-First-Site name (or another site) to replicate only between midnight and 5 A.M.

Configure Group Policy for the next site. If a domain controller can't be reached in a client's site, the client will look for any domain controller without regard to how close it is. This can negatively impact logins for enterprises with several locations connected with different speed WAN links. You can configure Windows Vista (and newer) clients to locate and log on to a DC in the next site if a DC can't be located in their site. This can be done using Group Policy or the Registry Editor.

+   2. Computer Configuration > Policies > Administrative Templates > System > Net Logon DC Locator DNS Records

+   3. User Configuration > Policies > Administrative Templates > System > Logon > DC Locator DNS Records

+   4. User Configuration > Policies > Administrative Templates > System > Net Logon DC Locator DNS Records
