# DIAL-IN TAB

The Dial-in tab, as shown in Figure 8.16, allows an administrator to control if and how a user connect remotely to server, by initiating a VPN tunnel or using a modem to dial in.

FIGURE 8.16
Local dial-in tab

![](bbox=[0.296, 0.253, 0.638, 0.581])

Changing any of the properties in this dialog is relatively easy using Active Directory Users and Computers, which you've probably realized by now. You can control some of these settings by using the net user command. Let's take a look at one or two. This command will change the full name of the local user account:

net user SRed /fullname:"Steve Red"

This will set the home folder path to that of your choosing:

net user SRed /homedir:"D:\Home\SRed"

You should make sure that the path is valid before you run the command does not check it. You should also verify that the permissions are OK for the user. This configures the profile path setting for the user:

net user SRed /profilepath:"D:\Profiles\SRed"

Again, there is no error-checking built into the command, so you should first make sure that the path and permissions are valid.
