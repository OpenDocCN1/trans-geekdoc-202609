to add a scope, you need to switch to the netsh dhcp server prompt and use the scope command. The required parameters are the subnet and subnet mask that the scope represents, the scope name, and any comments:

```
netsh dhcp>server
netsh dhcp server>add scope 192.168.1.0 255.255.255.0 "Branch Office 1"
"Sample Dhcp scope"
```

Command completed successfully.

Command completed successfully.
The scope needs a range of IP addresses to serve to DHCP clients and the standard scope options. The options are identified with the option code, a three-digit identifier. You can see the identifiers in the DHCP Management Console. The options have values in byte, word, string, or IP address format. For our example, we have the following options, identifiers, and values:

+   * IP range: 192.168.1.50-100
* Default gateway: 003, 192.168.1.254
* DNS server: 006, 192.168.1.11
* DNS domain name: 015, bigfirm.com

```
netsh dhcp server>scope 192.168.1.0
```

Changed the current scope context to 192.168.1.0 scope.
