# Online Checkpoint Merging

What you knew as snapshots in Hyper-V 2008 R2 are now called checkpoints in Windows Server 2012 (RTM) onward, and they allow you to take a point-in-time checkpoint of your VM while it's running. Hyper-V 2008 created a new differing disk (.avhd) that was linked to the original VHD but was a completely separate file. This was a useful feature, for example, when you wanted to apply a new service package or hotfix to a server and ensure you could quickly roll back to its original state if things went wrong.

The negatives outweighed the benefits, though, and before Windows Server 2012, if you wanted to delete point-in-time checkpoint, you had to shut down the VM and merge the AVHD file back into the parent VHD. This could take a considerable amount of time to complete if the AVHD was large—all down with the VM. You can now perform checkpoint merging with Windows Server 2012 R2, so if you need to checkpoints for your VMs, you can safely merge them without any downtime. There will be a small performance overhead on the VM while the checkpoint is being merged, so be aware that this will have an effect on your production systems and must be carried out after business hours.

# Windows Server Gateway

Windows Server Gateway (WSG) is a new addition in Windows Server 2012. It operates as a virtual software router that enables datacenter and cloud service providers to route traffic between their physical and virtual networks as well as the Internet. It integrates into Hyper-V and utilizes the Network Virtual Encapsulation (NVRE) standard that allows true datacenter space isolation for multi-tenant environments. Deep into this technology is out of scope for this book, but you can find more information here: http://microsoft.com/en-us/library/dd31301.aspx

# Enhanced Linux Support

If you are running Linux VMs in your Hyper-V 2012 R2 environment, you can now use of dynamic memory support, which allows you to configure the RAM and how much it can dynamically expand in times of high usage. Also, if you've tried to manage a Linux VM from older versions of the Hyper-V management console, you'll recall that the performance and mouse support weren't to scratch. Hyper-V 2012 R2 provides enhanced drivers to improve video and mouse performance, and ultimately, your management experience. Finally, for Linux VMs, Windows Server 2012 R2 enables online with no backup, as is the case with previous versions of Hyper-V.

# Extended Hyper-V Replica

It is essentially used as a disaster-recovery solution that replicates VMs from a host on to another site. In Windows Server 2012 R2, Hyper-V Replica is extended to allow you to replicate your VMs to a third site. This functionality brings additional flexibility to how you manage your offline replicas for disaster recovery or even basic backup. For example, you might want to have one replica copy in your local site and another one in the cloud or with a third-party provider.
