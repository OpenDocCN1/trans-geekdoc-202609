# PREREQUISITES

Before you install PAL, make sure that you are running it on a client with at least Windows 7 64-bit edition—this is the only OS that the latest release of this tool was tested on by its developer, you've successfully run it on Windows 8 and Windows Server 2012 R2 without issue. You'll also need to ensure you have the following products installed on the computer running it:

+   - PowerShell v2.0 or greater
- Microsoft .NET Framework 3.5 Service Pack 1
- Microsoft Chart Controls for Microsoft .NET Framework 3.5

# INSTALLATION

Once you've met the prerequisites and downloaded the tool, follow these steps to get it installed:

+   1. Log on to the computer where you wish to install PAL with an administrative account.
2. Browse to the location where you've downloaded the binaries, right-click setup. exe, and choose "Run as administrator" to begin the installation.
3. Acknowledge the initial warning message at the Welcome dialog box about the PowerShell execution policy setting, and then click Next.
4. Choose the installation folder location; then click twice.
5. From the Installation Complete dialog box, click the Close button to finish the wizard.

# USING PAL

Now that you've installed PAL, it's time to put it to use! This section will walk you through the initial configuration steps to generate your first report. If you've worked through the tasks in the "System Data Collector Sets" section, then now would be a good time to use them because we use the performance logger file that is generated for the PAL tool.

+   1. Log on to the computer where you've installed PAL with an administrative account, and launch PAL from the Start screen or menu.
2. When the tool runs, you will be presented with the PAL Wizard, as shown in Figure 30.27. This wizard will take you through the configuration of the tool in no time.
3. Click Next.
4. At the Counter Log tab, specify the location of the counter logs that you want to use for analysis.

We're going to use the System Performance counter that we generated earlier, which is located at c:\Perflogs\System\Performance. Figure 30.28 shows an example of what it should look like. You can also choose the date and time range that the report will focus from here.
