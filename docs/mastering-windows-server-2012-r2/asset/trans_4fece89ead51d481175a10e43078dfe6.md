在安装 Hyper-V 角色之前，你唯一需要决定的似乎是使用哪块网卡（NIC）来管理 Hyper-V 主机。想法是主机中至少要有两个网卡，尽管你可以用两个可用的网卡来应付，将其中一个专门用于管理主机，第二个用于虚拟机网络流量。为了让这一点一目易见，一个技巧是重命名网络连接，如图 27.10 所示。

让我们开始安装 Hyper-V 角色：

- 1. 参考表 27.5 中的参数作为服务器、服务器名称、IP 配置等的指南来安装服务器。
- 2. 如果你想遵循后面的某些示例，请将计算机加入域。书中一直使用了 bigform 域。

安装完 Hyper-V 主机服务器操作系统后，你就准备好安装 Hyper-V 角色了。在安装过程中，由于网络组件的升级，网络连接可能会中断两次。

- 3. 使用具有域管理员权限的账户登录你的 Windows Server 2012 R2，并从“服务器管理器 > 本地服务器 > 管理”菜单选择“角色和功能”选项。
- 4. 在“开始之前”对话框中，点击“下一步”。
- 5. 确保在“选择安装”对话框中选择了“基于角色或基于功能的安装”，然后点击“下一步”。
- 6. 在“选择目标”下，保持默认选项勾选“从服务器池中选择”，确认你的服务器在“服务器池”部分被高亮，然后点击“下一步”继续。
- 7. 当你到达“选择角色”对话框时，向下滚动直到在角色列表中找到 Hyper-V ，并勾选旁边的复框。

随后你将被提示在此处添加一些所需的功能，例如 Hyper-V 管理工具。

- 8. 点击弹出窗口中的“添加功能”。
- 9. 点击“下一步”继续。
- 10. 在“选择功能”对话框中保持功能原样；然后点击“下一步”。
- 11. 在图 27.11 所示的“创建虚拟交换机”对话框中，为你将要与虚拟机使用的虚拟交换机选择每个网卡。

你将在本章后面找到详细信息，但简而言之，对于你选择的每个网卡，将创建一个虚拟交换机。如果你有两个或更多网卡，你应该留一个空——我们在这里留下了我们的 MGMN。未选的网卡将不会与任何交换机关联，并可用于管理主机。如果你只有一个网卡，请选择它。如果你不选择任何网卡，你的虚拟机将无法与外部世界通信，尽管你以后可以纠正这一点。由于我们记得给网络连接赋予了合理的名称，现在很容易选择我们将用于虚拟机网络流量的某一个。

- 12. 点击“下一步”，你将看到“虚拟机迁移”。
