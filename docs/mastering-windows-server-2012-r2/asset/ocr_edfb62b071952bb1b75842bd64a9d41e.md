# CHAPTER 25 MIGRATING, MERGING, AND MODIFYING YOUR ACTIVE DIRECTORY

AD DS will walk you through the process as DCPromo did previously in helping you connect to your DNS servers, namespaces, and domain controllers.

Before joining a domain, you must complete the basic feature installations that are required; the Add Roles and Features Wizard will walk you through this process. It will take a few minutes to get all of the components installed, and then you will be given the option "Promote this server to a domain controller," as shown in Figure 25.2.

FIGURE 25.2.
Promoting a member server to a domain controller

When you select this option, the AD DS Configuration Wizard will start. Following these steps to work through the process of making your Windows Server 2012 member server to a domain controller in an existing Windows Server 2008 R2 domain. The domain you will be working with in this example is Oldfirm.com.

+   1. On the first AD Configuration Wizard screen, leave the default radio button selected, "Add a domain controller to an existing domain."
2. Under "Specify the domain information for this operation," set Domain to Oldfirm.com.
3. Under "Supply the credentials you need to perform this operation," enter Oldfirm-oldadmin.
4. Once you have provided this information (shown in Figure 25.3), click Next.
