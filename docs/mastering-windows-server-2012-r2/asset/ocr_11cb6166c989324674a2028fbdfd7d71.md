# Unattended Installations

We bet you that you were finally getting to the end of this chapter. Surely, there is no more
we could discuss about installing Windows Server 2012 R2, right? Well, think again.

Smaller organizations will be happy with the manual approach for installing or upgrading
Windows Server 2012 R2 that we discussed earlier in the chapter. However, you may want to
in some effort into alternative approaches. You could use a cloning solution such as Windows
Deployment Sets, as found in Windows Server since Service Pack 2 for Windows Server
2003, or the free Microsoft Deployment Toolkit. Maybe you already use a third-party
solution. There is another way that might be of interest for you that does not require a server to
manage the process.

Unattended Installations extend the installation media by customizing your
installation. Part of the process is to answer those questions that you probably get sick
answering all the time. The idea is that you can setup an installation and walk away knowing
that you will not have to answer any questions. The new server will be installed by itself
according to your predefined answers. The new installation routine for Windows 8 and Server
2012 R2 is quite small, but if you are building lots of machines, you will soon get to
entering product keys, setting OS options, and so on. The other more powerful part is the
ability to tweak the installation in ways that are not revealed in the installation process.
How would you like to install some components of the operating system that are not revealed
in the GUI? You could simplify your post-installation customization and streamline your deployments

All of this is possible by using an answer file that you supply to the installation routine. This
approach might be familiar to engineers who have deployed older versions of Windows. In the
past might have used a tool called Setup Manager to create a simple text-based answer file,
which you probably had to customize a fair bit in Notepad.

The release of Windows Vista changed all. With Vista have come the release of the Windows
Automated Installation Kit (WAIK), which has seen some updates including support for
Windows Server 2008, Windows 7, and Windows Server 2008 R2. With the release of Windows
Server 2012 R2, this kit has changed name to Windows Assessment and Deployment Kit
(Windows ADK). ADK is a very powerful set of tools that include the ability to create a boot
DVD. This is boot using Windows PE, a trimmed-down version of Windows that you can use
for many tasks including deployment and troubleshooting. More important for this chapter,
ith includes Windows System Image Manager (WSIM). WSWIM is the replacement for Setup
Manager and is used to create answer files for Windows 8 and Windows Server 2012 R2.

The other big change you will see is the format of the answer files that you are going to use. It
used to be pretty simple to edit files but XML is actually harder to set than
the skeleton of the answer file. You generally had to do more work on the answer file in
Notepad. WSIM creates XML files. Uh-oh! There that word: XML! Do not let scare you.
smany administrators at first because they are far from being programmers. But the WSIM
interface provides pretty everything you need. You can still go in and edit the file by
Notepad or whatever your XML editor is. The only time you might really do is to
jump in and change a product key.
