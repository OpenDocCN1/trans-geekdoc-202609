The dialog box in Figure 2.18 provides you with the option to either do an upgrade or a clean installation of Windows Server 2012 R2. If you have followed the instructions correctly so far, both options will be available to you. However, if you selected an invalid edition of Windows Server 2012 R2 to install, you will not be able to upgrade.

In this example, we are upgrading from Windows 2008 R2 Standard edition to Windows 2012 R2 Standard edition with GUI, so click Upgrade.

The installer now scans the installation to see whether there are any known incompatibilities with Windows Server 2012 R2.

The installer will check whether the existing server is compatible. If it isn't, you will get a reason why a compatibility report, as an error when trying to upgrade an evaluation version of Windows Server 2008 R2, as shown in Figure 2.19, and you will have to start the upgrade from the beginning before resolving any issues.

You have now arrived at the "Last-chance gas station." You had better pull in here and fill up before proceeding. The installer is now giving you your last opportunity to confirm that all the hardware, software, and drivers on the existing server installation will work when you have completed the upgrade. After clicking Next, there is no going back! But seriously, any incompatibilities with Windows Server will be listed here.
