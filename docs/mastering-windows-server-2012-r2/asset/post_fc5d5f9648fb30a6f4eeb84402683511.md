# THE SECOND STAGE OF INSTALLING A PRESTAGED RODC

The local administrator can use the following steps to complete the installation of a prestaged RODC. The name of the computer where DCPromo is run must be the same name as the prestaged account.

> DON'T JOIN THE DOMAIN

The prestaged account creates an actual computer account in the Domain Controllers OU. Since any computer can have only one account, the prestaged RODC cannot be a member of the domain before it is promoted. Instead, it starts as a member of a workgroup and is added to the domain part of the AD DS Configuration process.

- 1. Log on the server using the local Administrator account.
- 2. If not already installed, add the AD DS role and reboot the server.
- 3. After the reboot has completed, launch Server Manager, and click the Notifications button.

You will notice a warning icon telling you that the post-deployment task of promoting this server to a domain controller is available.
- 4. Click "Promote this server to a domain controller" to start the Active Directory Domain Services Configuration Wizard.
- 5. On the Choose a Deployment Configuration page, ensure that "Add a domain controller to an existing domain" is selected.

## Active Directory Integrated

If other servers are configured as Active Directory integrated (ADI), the RODC will be set. When the sites are configured, Active Directory replication is optimized.

- All replication traffic is compressed to 10–15 percent of its size.
- It can be scheduled to occur during nonpeak hours.

## Read-only DNS

Traditional DNS works with a single DNS server hosting the primary DNS data. You can add multiple DNS servers hosting secondary zones. The secondary DNS servers are read-only and receive their updates from the primary DNS server. However, the biggest difference is that you don't need to manage the zone transfers as you would with traditional DNS. Zone transfers are managed through Active Directory replication.

## The Bottom Line

Prepare a forest and a domain for RODCs. RODCs are an excellent infrastructure asset in Windows Server 2012 and can not be added until the forest and domain are prepared. The preparation will modify the schema and permissions.

- **Master It:** Identify the command that need to be executed to prepare the forest for RODCs.
- **Prepare the domain.** In preparing the forest, you must also prepare the domain before RODCs can be added.
- **Master It:** Identify the command that need to be executed to prepare the domain to support RODCs.

**Allow passwords on any RODC.** The RODC can cache passwords for users based on how it's configured. When a user's password is cached on the RODC, the authentication process doesn't have to traverse the WAN link and is quicker. However, a cached password is susceptible to an attack, so privileged accounts should not be cached on the server.

- **Master It:** What should you modify to allow users to have their passwords cached on any RODC in the domain?
  - The Allowed RODC Password Replication group
  - The Denied RODC Password Replication group
  - The password replication policy

**Allow passwords on a single RODC.** It's possible to configure the environment as members of a group can have their passwords replicated and cached to any RODC in the domain. It's also possible to configure the environment so that the passwords be replicated or cached only to a single RODC.

- **Master It:** What should you modify to allow users to have their passwords cached on specific RODC in the domain?
  - The Allowed RODC Password Replication group
  - The Denied RODC Password Replication group
  - The password replication policy
