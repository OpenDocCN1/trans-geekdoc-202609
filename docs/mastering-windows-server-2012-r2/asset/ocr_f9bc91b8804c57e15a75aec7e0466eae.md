# Configuring a DirectAccess Client

Now you've installed DirectAccess on the server, you can go ahead and connect your clients. You'll test your connection on a Windows 8 Enterprise mobile computer. Here's all you need to:

+   1. In Active Directory, add your Windows 8 Enterprise computer account to the security group that you specified in Step 1, Remote Clients, of the DirectAccess configuration diagram.

+   2. Ensure the Windows Firewall is turned on, as discussed in the "DirectAccess Requirements" earlier.

+   3. With the Windows 8 computer connected to the corporate Active Directory environment, update Group Policy by opening a command prompt and typing gpupdate /force or by simply restarting the computer and logging back onto the domain.

+   4. To quickly check that Group Policy has been updated on your client, open Windows Firewall and click the Connection Security Rules view.

You should see the DirectAccess rules applied, similar to Figure 21.37.

+   5. If all the requirements have been met and the GPOs have been updated to your computer, click the Charms bar in Windows 8 to see the new DirectAccess connection automatically connected along your normal Wi-Fi or LAN connection, as shown in Figure 21.38.

+   6. If you want to review your DirectAccess client configuration from Windows 8, open Windows PowerShell and type the following:

```
Get-DACLientExperienceConfiguration
```

+   7. To confirm that you're connected remotely to the corporate environment through your DirectAccess connection, in PowerShell type Get-DAConnectionStatus.
