# What's Inside?

Chapter 1 starts out with an overview of what's new in Windows Server 2012 R2 (let's hence-abbreviate that to "Server 2012 R2\ and Chapter 2 shows how to install it on your servers and how to begin it with your existing network, if you have one.

Veterans of Windows networking will expect Server 2012 R2 to look like other versions of Windows, with a default, a Start menu, and a host of graphically built tools, but that which you will quickly learn, there's a new GUI to get to grips with. Chapter 3 shows you you started on Server Core, and we recommend that you spend time learning it. Chapter 4 looks at the networking enhancements in Windows Server 2012 R2, and Chapter 5 introduces you to some new functionality around IAM and DHCP Failure. Chapter 6 shows how to do DNS, answering the question, "How do I build an infrastructure that is both secure and crafted to serve an Active Directory beast?

Speaking of AD Chapter 7 is the first chapter to address Windows Server technology, with an explanation of how to build the most common, simplest, type of Active Directory: one that contains just domain and one location. If you're going to build huge-spanning ADs, this first look provides a necessary foundation, so skip it. Then, once you have your AD, you'll need to create and manage user accounts, and Chapter 8 shows you. Once you have a working AD in place, then its time to get payback from all your design and setup work, and the tool for that is Group Policy. The good news is that Group Policy is a way to control 10 or 10 machines and user accounts centrally; the AD-related chapter, Chapter 10 covers Active Directory Federation Services, which is a way to provide single sign-on to your resources across organizational boundaries.

Chapter 11 and Chapter 12 introduce you to shared storage and clustering, which are the pillar components of delivering highly available IT infrastructure to the business, along with an introduction to the new "Sannish" capabilities of Server 2012 R2 using Storage Spaces.

Chapter 13 introduce you to a three-part series on sharing folders and files using Windows' security to control who can get to particular files. You will then be walked through Dynamic Access Control, which is a new way of controlling and auditing your file share access. Many servers will not only share files but printers, and Chapter 16 shows you how to accomplish this with Server 2012 R2.

Following that, Chapter 17 shows you how to maintain and control your servers remotely using a number of built-in technologies, including Remote Desktop. Now, you have working servers (which is nice) but clients to use those services (which makes the whole thing sort of), so Chapter 18 shows you how to hook up the various varieties of Windows created in the past to a Windows Server 2012 R2 network. That's,, say? You've got a Mac? No problem, you'll learn to connect to that up.

Chapter 19 gets you up and running with one of Windows' most complex server add-ons, Microsoft's Internet Information Services (IIS), better known as the web server. You will learn how to get IIS running, how to set up a simple website, and how to find your way around the IIS management tools built into Server 2012 R2.
