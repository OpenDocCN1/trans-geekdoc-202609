# Multimaster vs. Single-Master Replication

As we've mentioned, one of the things that differentiates AD domains and DCs from NT 4 and earlier domains is multimaster replication rather than single-master replication. Any DC can accept changes to the user account, so a local Tulsa admin could start an administration tool through Active Directory Users and Computers and make a change to a user's account on an available domain controller. Any DC can accept changes, any DC is a "master", which is why it's called multimaster.

# But Everything Is Multimaster

In general, Active Directory tries to carry this notion of decentralized control throughout its structure. In general, all DCs are equal, but to paraphrase George Orwell, some DCs are more than others. These DCs are the ones that serve in five roles called either Operations Master or Flexible Master of Operations; they gets shortened to the acronym FSMO and is known as "fizz-mo". Strictly speaking, FSMOS was the phrase that Microsoft used through most of Windows 2000's development process, and it renamed FSMOS to Operations Masters in the beta process. As a result, you'll hear some people say Operations Master, the FSMOS has such name with many, even now in the days of Windows Server 2012 R2 probably because it's quicker to say "fizz-mo" (and fun). So, for example, the phrases Domain-Naming Operations Master and Domain-Naming FSMOS refer to the same thing.
