# CREATING MULTIPLE DOMAINS

On the Domain Controller Options page, "Domain functional level" will be defaulted to the operating system used to deploy this primary domain controller for the new domain. In this example, the domain functional level is Windows Server 2012 R2. We will discuss functional levels in the next section. Few other options are available on this page of the wizard; make sure DNS server is selected, whether or not to make this domain controller a GC server, place the domain controller in the site created prior to this task, and set Directory Services Restore Mode (DSRM) password. Your screen should look similar to Figure 24.3. Next to continue.

Verify that the "Create DNS delegation" check box and proper credentials are provided on the DNS Options page, and continue on to the Additional Options page of this wizard. This page is an important one. Here you will use the NetBIOS name of your new child domain, as shown in Figure 24.4. The name will be defaulted from the name you entered on the Deployment Configuration page. Ours reads COAST. Remember that this is a child domain, it will take the suffix of the parent domain. Even though we only use ECOAST here, the full domain name will read Ecoast.Test.com, and this domain controller's Fully Qualified Domain Name (FQDN) will read Ec1.Ecoast.Test.com.
