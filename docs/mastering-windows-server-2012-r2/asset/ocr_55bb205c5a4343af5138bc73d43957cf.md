+   Standards based—Because it runs on HTTP and is based on the HTTP standard, Windows AD Graph can be used on any platform.

+   Easily manageable—Firewalls can be easily configured to allow HTTP traffic.

# TESTING WINDOWS AZURE ACTIVE DIRECTORY GRAPH

In order to get an idea of how the Graph API works, you can try it out. Microsoft provides a test application in Windows Azure called Graph Explorer that lets you run queries against your tenant. Go to http://graphexplorer.cloudapp.net/ and sign in with your Microsoft account; then Use Demo Company in the top-right corner. This will send you to a test tenant (GraphDir1) at https://graph.windows.net/GraphDir1.OnMicrosoft.com where you can get a look and feel for this technology.

If example, you want to run a query to all users from your tenant, you simply add the expression users at the end of the URL, like this: https://graph.windows.net/GraphDir1.OnMicrosoft.com. Or if you want to return the attributes from a single user called Daniel@GraphDir1.Onmicrosoft.com, you would run https://graph.windows.net/GraphDir1.Onmicrosoft.com/users/Daniel@GraphDir1.Onmicrosoft.com.
