每个参数都显示其当前设置。正如我们之前提到的，最重要的参数是虚拟硬盘和虚拟机配置的默认路径。在 Hyper-V 的设计设计理念中，虚拟磁盘文件与虚拟机设置是分开的。请确保你将它们设置为合理且互不相同的路径。我们已经讨论过增强会话模式策略（Enhanced Session Mode Policy），在接下来的章节中，我们将深入研究实时迁移、存储迁移和复制。

**物理 GPU (Physical GPUs)** 此选项仅在在你安装了“远程桌面虚拟化主机”角色时可启用。它允许你从图形处理器（GPU）显卡（如 NVIDIA）中进行选择，并配合名为 RemoteFX 的远程桌面 (RDP) 解决方案使用它们。

**NUMA 跨越 (NUMA Spanning)** 此选项默认启用，并允许虚拟机跨越非均匀内存架构（NUMA）节点。如果主机有可用的 NUMA 节点，启用此选项将为你的虚拟机带来额外的性能优势，并允许你比没有 NUMA 的时候同时运行更多的虚拟机。

其余设置都与你如何使用 Hyper-V 以及访问虚拟机有关：虚拟机控制台 (VM console)。

**键盘 (Keyboard)** 指定特殊键（例如 Alt+Tab）在虚拟机控制台中的行为。

**鼠标释放键 (Mouse Release Key)** 在在未安装集成组件或虚拟驱动程序的情况下，指定使用哪种组合键来从虚拟机控制台释放输入焦点。默认是按下 `Ctrl+Alt+左箭头`。

**增强会话模式 (Enhanced Session Mode)** 与此前讨论的并在图 27.4 所示的“服务器设置”中的增强会话模式类似（但依赖于它），此设置的用户版本决定了当客户操作系统支持增强会话时，是否使用增强会话模式连接。支持的客户操作系统是 Windows Server 2012 R2 以及 Windows 8.1 或更高版本。

**重置复选框 (Reset Check Boxes)** 在 Hyper-V 控制台的某些位置，你可以勾选复选框，表示你永远不想选择某个特定的对话框。此选项将它们全部恢复到开始更改之前的状态。

继续对“操作 (Actions pane)”面板的概述，我们还有三个向导需要简要讨论。虚拟交换机管理器 (Virtual Switch Manager) 是虚拟交换机（或网络）的核心管理点。使用此向导，你可以查看、配置和编辑网络。外部交换机可以分配给物理网卡 (NIC)。我们将在稍后详细讨论此向导。

虚拟 SAN 向导 (Virtual SAN Manager Wizard) 仅在向导检测到物理光纤端口时才允许你配置虚拟光纤 SAN。你可以在你的 Hyper 主机上创建虚拟光纤 SAN，在尝试将其连接到虚拟机之前，请确保它们已启动且主机可以访问。如图 27.15 所示，可以通过此向导定义全球端口名称 (WWPN) 和全球名称 (WWN) 地址。

令人惊讶的是，“编辑磁盘向导 (Edit Disk Wizard)”不能用于创建虚拟磁盘。该操作被留给了“新建向导 (New Wizard)”。编辑磁盘向导允许将磁盘从 VHD 更改为 VHDX，从动态更改为固定，你将在下一节中学习。它还允许你扩展磁盘大小并删除虚拟磁盘文件中的空白空间。最后，“检查磁盘 (Inspect Disk)”框会检查虚拟磁盘的一致性并显示属性，如格式、类型、位置和大小。

# 理解虚拟磁盘

当你创建虚拟机时，你会为网络、视频等分配虚拟磁盘。当然，你的虚拟机也需要一个虚拟磁盘。问题是，什么种类型的磁盘？物理磁盘正在被主机使用！解决方案简单而易见：因为你正在进行虚拟化和仿真，请使用一个空文件而不是将虚拟机作为磁盘。虚拟磁盘仅仅是一个非常大的文件——不要忘记如果需要，它可以扩展到 64 TB！

Hyper-V 为你提供了多种口味的虚拟磁盘，以应对你可能想要使用每种磁盘的各种场景：

**动态扩展磁盘 (Dynamically Expanding Disk)** 这种格式的虚拟磁盘将分配它所需的物理磁盘空间且不再更多。例如，你可能会为一个 Windows Server 2012 虚拟机分配 127 GB，而在基础安装后它使用少于 10 GB。虚拟机会扩展。扩展的虚拟磁盘充分利用了主机上的可用磁盘空间。但正如你想象的，当需要扩展时可能会产生性能开销，并且你面临碎片化的风险。

此外，一个明显的缺点是，当动态虚拟磁盘扩展超出可用空间时，你可能会耗尽主机上的磁盘空间。当发生时，Hyper-V 会冻结所有虚拟机，事件日志会变红——这并不是一个理想的处境！此问题仅限于 Hyper-V，且在 VMware 中使用预留磁盘 (provisioned disks) 时情况也是的。

**固定大小磁盘 (Fixed-size Disk)** 为了消除扩展磁盘的开销，你可以选择使用固定大小磁盘。虚拟磁盘的完整大小会在创建磁盘时分配，因此你可以轻松地跟踪为虚拟机占用了多少物理空间。这通常是大多数生产环境推荐的格式。

当你创建此类磁盘时，会创建一个完整大小的文件。在创建期间，文件会被填充零。

**差异磁盘 (Differencing Disk)** 这是一个有趣的功能，具有父子关系。父级磁盘是只读的。

**透通过磁盘 (Pass-through Disk)** 这种磁盘允许你在在需要时直接在物理主机上使用透通过磁盘。
