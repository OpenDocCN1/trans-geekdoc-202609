The logs are the traditional logs that have been available in past versions of Windows plus the Setup and Forwarded Events logs:

- Application The Application log is used to log events from applications. The application developer can choose to log events in this log or create an application log specifically for the application. As example, SQL Server will log applications into this log, but the Windows PowerShell will log events into the Windows PowerShell and Applications Services log.
- Security The Security log will show all audited events. Audited events include logs, files, and other object usage, as well as any other auditing events the administrator has enabled. Audited events can be specified to include both success and failure events. Windows Server 2012 R2 enables auditing of specific events by default, these logs will have events even if the administrator has not modified auditing.
- The Setup log includes events related to the setup of the operating system or installed applications. These logs include the addition or removal of any rules or features.

The System log records events related to the operating system. It includes information related to system drivers and system services.
