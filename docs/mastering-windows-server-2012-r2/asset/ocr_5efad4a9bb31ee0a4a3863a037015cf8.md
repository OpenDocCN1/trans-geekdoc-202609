# Creating a Security Database

To see how this template will modify a system or to apply the template setting using the MMC snap-in, you must create a security database. To do this, you have to compile it from its simple ASCII to a binary format called a database. You do that from the other snap-in, Security Configuration and Analysis.

+   1. Right-click Security Configuration and Analysis and choose Open Database to open the Open Database dialog box

Within the Open Database dialog box, you want to create a new database, but there's no option for that; instead, just type the name of the new database.

+   2. Using this example

Typing in name of new database causes the snap-in to realize that you want to create a new database, so then it asks which template to build out of. (Yup, it's nonintuitive). By default, dialog box shows you the .inf extensions in the Windows\Security\Templates folder.

+   3. If you're following this example, click simple .inf.

Before you click enter, notice the Clear This Database Before Importing box.

+   4. Select that option.

Otherwise, when you're experimenting with a template, the snap-in makes your changes cumulative (which might well be your intention, but it's not usually ours) rather than wiping the slate state and starting from scratch.

+   5. Choose the template, and click Open.

Nothing obvious has happened, but the snap-in has now "compiled" (which is our word, not Microsoft's, but it seems a good shorthand for the process of converting your ASCII into a binary database) the template named simple.sdb in My Documents\Security\Database. In the details pane, you'll see the Configure and Analyze options.

+   6. Right-click Security Configuration and Analysis, and you'll see two options: Analyze Computer Now and Configure Computer Now.

Analyze doesn't change the computer. Instead, it shows you—the computer's state to the one you want to create with the template. It then saves a log file that explains—how your system varies from what the template installs. The log file is written to\Documents\Security\Logs.

+   7. To see how your computer measures up to the settings in the database, select Analyze Computer Now, and see what the current settings are compared to what you want them to be.

+   8. If you want to jump in headfirst and apply the settings, instead of choosing Analyze Computer Now, select Configure Computer Now to modify the system's settings to fall in line with the template.
