Configure and install a virtual machine. Conceptually, it takes two steps to create a VM from scratch. First you configure the virtual hardware of the VM, then you boot the VM and start installing the operating system. Once those two steps have been completed, you can use either Hyper-V Manager or PowerShell to manage the VM.

When using the GUI to manage your VM, the console can "capture" the keyboard and mouse. When they've been captured, all input from the keyboard and mouse are sent to the VM. Initially, you can't release control from the VM by moving the mouse. What keyboard combination is configured by default to release control of the keyboard and mouse back to the host OS?

Press the key Ctrl+Alt+Left to release control. In a fully running VM with Integration Services, the experience is better: you can move the mouse out of the virtual screen onto the desktop, and when that happens, the host takes control of the keyboard and mouse again. There is one special case: the Ctrl+Alt+Del sequence. Even when the VM has control, the host will process it. To send the Ctrl+Alt+Del sequence to a VM, you can either Ctrl+Alt+End or use the console menu action (Ctrl+Alt+Del).

Virtual domain controllers. Windows Server 2012 includes a new method of deploying any number of virtual DCs through virtual domain controller cloning. This gives administrators a supported to rapidly spin up domain controllers using an existing template DC for reference. Virtual DC cloning can be beneficial to organizations that want to quickly deploy multiple DCs into new domains as well as a helpful feature in cloud environments to meet scalability requirements.

What is the minimum supported version of Active Directory that you can use with virtual DC cloning?

A virtual DC running Windows Server 2012 or higher is a member of the same domain as a PDC emulator also running Windows Server 2012 or higher is required for virtual DC cloning.
