# CHAPTER 7 ACTIVE DIRECTORY IN WINDOWS SERVER 2012

Disaster Recovery Active Directory is a very complex beast in terms of domain or even-forest recovery. It is always easier to recover one domain than two or more.

Windows Server 2008 introduced fine-grained password policies. This solved a long-term problem that for you also to create a separate domain. Fine-grained password policies allow you to create multiple password policies. In earlier versions of Active Directory there could be only one password policy. In Windows Server 2012 fine-grained password policies are the same as they were in Windows Server 2008, but it offers a user-friendly interface to easily manage and control.

# WHICH WINDOWS SERVER 2012 VERSION

Microsoft simplified the windows jungle and offers two Windows Server 2012 versions you can consider for setting up domain controllers: Windows Server 2012 Standard or Datacenter edition. There is no difference in functionality, availability, or features. The difference is in terms of licensing and the number of virtual machines you can run top of each edition. At the beginning of this book, we explained the differences between the two versions. If you need to install a domain controller, you can always choose Windows Server 2012 Datacenter edition, and if your license allows, you must be aware of that Windows Server 2012 is available only in 64-bit versions; there is no 32-bit version. This comes into play when you are thinking about upgrading your domain controllers. You cannot perform an in-place upgrade from a 32-bit system to a 64-bit system.
