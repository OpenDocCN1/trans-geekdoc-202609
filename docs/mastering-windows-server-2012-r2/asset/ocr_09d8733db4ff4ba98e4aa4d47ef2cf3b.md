# Understand how to move your VMs around. Hyper-V in Windows Server 2012 gives you the option to export and import VMs between hosts with relative simplicity. This is made possible by the fact that all Hyper-V hosts offer almost identical hardware to the VMs through the integration components and synthetic drivers. If you wanted to move OS installations around the physical server world, you would at the very least need to move the physical disks, which works only if the hardware is similar enough and isn't always a guaranteed success.
