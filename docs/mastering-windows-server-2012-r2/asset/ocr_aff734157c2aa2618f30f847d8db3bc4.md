# Virtual Desktop Infrastructure

Virtual Desktop Infrastructure (VDI) has been around a long time. There are many different implementations and approaches on how to implement it. VDI is a pooled collection of operating systems (usually Windows XP, Windows Vista, Windows 7, or Windows 8) hosted on a virtualization platform. Connections to this pool control the asset's lifecycle throughout their enterprise and centralize their core operations in the datacenter. In Windows Server 2012 is considered part of the Remote Desktop with a mix of App-V.
A key improvement in Windows Server 2012 R2—which has more to do with storage benefits VDI as well—VHDX file, you can use Dedup and save without impacting performance. Dedup is supported only with VHDX scenarios.

+   * RD Connection Broker

+   * RD Web Access
