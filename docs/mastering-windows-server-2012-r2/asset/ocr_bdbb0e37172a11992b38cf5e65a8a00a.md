The Settings dialog box is one you will see a lot in the future. The left pane has two sections, Hardware, and Management.

The Hardware section manages all virtual hardware. Here's an explanation of each option that you will see on a Generation 2 VM:

**Add Hardware** Here you can add a SCSI controller that you can use to add virtual SCSI drives. As we discussed earlier, with this release of Hyper-V, you can now boot your VMs directly from a SCSI controller, and this is the only controller option available when configuring GenVMs.

**Firmware** This is where the new Unified Extensible Firmware Interface (UEFI) BIOS feature delivers the ability to enable or disable secure-boot functionality. You can also select the order of boots: DVD drive, network adapter, or hard drive.

**Memory** Figure 27.31 shows the Memory section of the VM Settings. In the figure, you can see we selected a startup RAM of 512 MB and enabled the Dynamic Memory feature to manage the RAM of our VM gets allocated by the host demanding on its utilization.

The Minimum RAM setting allows you to specify an amount of memory that is lower than the actual startup RAM (which, of course, the minimum required to start up the VM in the first place), and this can be useful in VMs that are left idle with very utilization over long periods of time.
