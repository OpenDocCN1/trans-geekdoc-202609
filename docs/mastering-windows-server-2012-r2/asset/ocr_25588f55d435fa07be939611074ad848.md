# # Troubleshooting Group Policies

In it's not clear by now, group policies are powerful...and also complex. And they can be
kind of opaque—sometimes you create a bunch of policy settings for a domain controller
ywant to control some and then restart the desktop, log in, and wait to see
the effects of the new...but nothing happens.

A few troubleshooting tools are included in troubleshooting Group Policies.
The Resultant Set of Policy (RSOP) snap-in and console tool provides a graphical interface, and
gresult.exe performs equivalent functions from the command line. gptool.exe is a
Windows Resource Kit tool, and it looks for inconsistencies between GPOs that are stored on
domain controllers. This little utility can help identify issues that are causing a
problem with Group Policy application.
