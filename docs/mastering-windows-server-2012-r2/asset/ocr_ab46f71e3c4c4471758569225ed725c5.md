# CREATING TRUSTS WITH THE NEW TRUST WIZARD

Let's cover forest trusts. As far as we can see, you can't get around to create the really cool
transitive trusts between forests. For that, you'll need Active Directory Domains and Trusts
(ADDT). However, in our experience, we've relied on external trusts. They're effective in getting
t job done for trusts between one domain and another, which is the predominant requirement
in Active Directory environments. The forest trust applies to much larger organizations than the
typical IT shop.

Creating trusts with the ADDT's New Wizard is the same for each of the trusts, and
they require the same changes and information.

+   1. First, as there are different ways with a few DNSLookup commands to see that the folks in each
forest, realm, or domain will be able to find domain controllers in the other forest.

Although there are different ways of setting up the names in a different
domain, we prefer setting up DNS stub zones. The stub zone be configured as Active
Directory integrated, so it will be automatically replicated to other domain controllers in
the domain. It doesn't require modifications of the primary zone like a secondary zone
would. Conditional forwarders accomplish the same thing.

+   2. Then, make sure that both of the forests are at the Windows Server 2012 R2 forest func-
tional level.
