# LOCAL AREA CONNECTIONS IN WINDOWS 7

To locate the local area connections on a Windows 7 client, select Start > Control Panel > Network and Internet, and go to the Network and Sharing Center (shown in Figure 18.8). To get there, type the word Network in the search area at the top of the Start menu, and then click Network and Sharing Center in the top portion of the Programs menu.
