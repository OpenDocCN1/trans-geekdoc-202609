# Teredo Tunneling

With Tered, you can perform address assignment and host-to-host automatic tunnelling from behind network address translation (NAT) devices such as home routers. These devices have no direct connection to IPv6 networks. Tered has been designed as a last-resort technology for IPv6 connectivity. Tered will not be used if native IPv6, ISATAP, or e64 connectivity is present between communicating nodes. If e64 support more prevalent than IPv4 edge devices and IPv6 connectivity becomes the norm, Tered be used less and less until it is not used at all.

# Better Networking Manageability with PowerShell

Windows PowerShell was first introduced as a built-in operating system feature in Windows Server 2008 and is used by many Applications, such as Exchange Server, SQL Server, SharePoint, and System Center, to expose their management interfaces and take administration and automation of tasks to the next level. Windows Server 2012 R2 has PowerShell 4.0 built in, and with an extensive set of PowerShell cmdlets—many referred to as "command lets”—to perform command and script-based configuration of IPv6 and other network protocols.

Historically, the Netsh. exe (Network Shell) command-line utility was used for managing IPv6, and although using Netsh commands for IPv6 configuration is still supported, it is recommended to use Windows PowerShell when managing your network configurations in Windows Server 2012 R2. This section will discuss how to leverage PowerShell to get the most out of your networking capabilities.

# Networking Cmdlets and Modules

Whereas Windows Server 2008 had approximately 200 PowerShell cmdlets, Windows Server 2012 R2 has close to 2500! From this enormous pool of new cmdlets, you can literally view, configure, and monitor all of the different networking components and services that feature in Windows Server 2012. You can perform a variety of tasks using these cmdlets from simple IP address configuration to more specialized functions like configuring Quality of Service and virtualization networking parameters. Learning PowerShell is the key to managing and automating your services in your datacenter and ensuring a simplified Windows Server 2012 networking experience.
