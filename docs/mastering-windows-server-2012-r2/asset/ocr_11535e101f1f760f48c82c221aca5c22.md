# CHAPTER 1 WHAT'S NEW IN WINDOWS SERVER 2012 R2

Now let's briefly talk about the enhancements made to existing Hyper-V technology that many administrators find useful.

+   - Dynamic memory allows you to configure Smart Paging so your virtual machines can more efficiently restart. If a virtual machine has less startup memory, dynamic memory can be configured to support it.

+   - Importing virtual machines has received a tune-up to better handle problems that would normally prevent an import. Until now the process copying a virtual machine but never checked for configuration issues.

+   - Live migrations make it possible to complete a live migration in a nonclustered environment. This improvement will make moving a virtual machine much faster.

+   - Larger storage resources, increased scale, and better hardware error-handling are offered in this version. The intention is to help you configure large, high-performance virtual machines with the ability to scale.

+   - Virtual Disk Format (VHDX) increases the maximum storage size of each virtual hard disk. The new format supports up to 64 terabytes of storage. It also comes with hardware protection against power failures. This format will also prevent performance payoff on large-scale physical disks.

+   - You no longer need to shut down the live virtual machine to recover deleted storage space. Virtual machine snapshots will now free up the space consumed once it is deleted.

You can read more about this in Chapter 27, "Virtualization with Hyper-V"

REMOVED OR DEPRECATED ITEMS IN WINDOWS SERVER 2012 R2
VM chimney, also referred to as TCP offload, has been removed and no longer be available to guest operating systems. The WMI root/virtualization namespace is changed to just root/virtualization/w2 and will eventually be taken out completely in future Server versions. Authorization Manager (AzMan) has also been deprecated in this version and will be phased out in future releases. The new management tools for virtual machines will be the new standard.

# Virtual Desktop Infrastructure

In Windows Server 2012 R2, Microsoft has made vast improvements to the virtual desktop infrastructure (VDI), with simpler administration, increased value, and better overall experience.

Supporting mobile devices is a must in today's market. Virtual desktop infrastructure helps bridge the compatibility gap between devices by virtualizing resources. VDI provides stronger security and higher efficiency that improves productivity with a UI that the user is familiar with. Windows Server 2012 R2 and VDI make it a snap to deploy virtual resources across devices.
