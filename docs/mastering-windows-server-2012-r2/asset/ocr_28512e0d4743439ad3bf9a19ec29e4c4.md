A forwarder is another DNS server to request a level query. When a server cannot resolve the name, it can forward the request to another DNS server rather than going through the root hints. In an internal DNS environment, forwarders can be used to resolve other namespaces, for example the DNS server E1.Eastcoast.Bigfirm.com needs to resolve Bigfirm.com servers and other namespaces, so a forwarder is entered in its properties, as shown in Figure 6.10.
