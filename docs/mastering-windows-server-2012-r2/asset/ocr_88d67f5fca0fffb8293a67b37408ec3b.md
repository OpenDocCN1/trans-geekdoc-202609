6. Specify a startup memory value of 512 MB and use the “Use Dynamic Memory for this virtual machine” option, as shown in Figure 27.27.

Dynamic Memory is a feature that optimizes how physical memory from the Hyper-V host is allocated to VMs by the operating system. We will explain this feature in a little more detail later. Click Next, to continue.

The Configure Networking dialog box is used to specify the virtual switch to use. The default is not Connected, which is a safe but not very useful option.
