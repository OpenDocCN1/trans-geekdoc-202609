# USING SERVER MANAGER TO CONFIGURE YOUR SERVERS

```
Install-WindowsFeature -ConfigurationFilePath
$using:ConfigurationFilePath -ComputerName $using:ComputerName -Restart
}
```

```
Receive-Job -Job $jobs -Wait | Select-Object Success, RestartNeeded
ExitCode, FeatureResult
}
```

As you can see, this function is expecting a few parameters, a list of computer names that will remove the Remote Desktop role, and the path of your script. To invoke this function you will use the following code snippet to pass the parameters you need.

```
# Sample Invocation
$ServerNames = 'TestServer_01', 'LabServer_02'
Invoke-WindowsFeatureBatchDeployment -ComputerNames $ServerNames
-ConfigurationFilePath:RemoteDesktopConfig.xml
```

The following line in this snippet is the server names you will change to match. As you can see, my servers are TestServer_01 and LabServer_02 and are comma delimited. You can add as many server names as you wish to this list.

```
$ServerNames = 'TestServer_01', 'LabServer_02'
```

The next line in this snippet you will edit is the path of your XML file. Just change it to the path you saved to:

```
-ConfigurationFilePath:RemoteDesktopConfig.xml
```

Once you make your edits, hit Enter and you will see the install begin. It takes a little while to execute.

You can verify the installation by running:

```
PS C:\Users\Administrator> Get-WindowsFeature
```

Once again, any role, service, or feature that will be marked with an X. Take note of the Column name. You'll be using that for future commands. If you already know what role or feature you're interested in learning about, try running like this:

```
PS C:\Users\Administrator> get-windowsfeature RSAT-DS-Tools
```

| Display Name | Name | Install State |
| ----------- | --- | ----------- |
| [X] Remote Desktop Services Tools | RSAT-DS-Tools | Installed |
