# New York A'S ROUTING ENTRIES

| Prefix | Gateway/Interface | Comments |
|---|---|---|
| 0.0.0.0/0 | 192.168.1.1 | The default route—this means if you don't find a better match below, send the packet to 192.168.0.100, or New York." 0.0.0.0/0 is a special value and should not be thought of as anything other than a placeholder meaning "default". |
| 127.0.0.0 | Loopback | Even the loopback address has to be routed! The first entry indicates that the entire loopback network can be reached through the loopback interface; the second entry indicates that the specific address 127.0.0.1 is on that interface, and the third entry indicates directed broadcasts for this network can be sent there. Strictly speaking, the first entry covers the others. |

| Bluetooth Network Connection Wi-Fi | | |

As you can see, the table is displayed in order from least-specific route to most-specific route. You can think of the router inside this computer comparing the destination in the Prefix column against the destination of an IP packet:
"Hmm, I have a packet for 192.168.0.2—where do I go? Well, 0.0.0.0/0 matches if I don't find anything else, that entry will win. What about the next few? They all start with 127, and the prefix hasn't masked that out. My destination address doesn't start with 127, so that won't work. 192.168.0.0/24 matches, because my destination address is 192.168.0.2, and if I zero past the first 24 bits (as the prefix says I should), I get 192.168.0.0, which is the same as the network address of the prefix for this entry. That's the match I will choose instead of the less-specific match I have. No matches, so I am left with sending my packet through the Local Area Connection."
