Use deduplication techniques to reduce file size. Part of the reason behind data growth today's environments is the availability of storage, but storage will become a problem sooner than later. A high percentage of these files contain a large degree of identical data patterns, but using deduplication techniques can dramatically reduce the disk space required and make better use of the storage in place.

**Master It** In your lab copy an ISO multiple into different times, and repeat for office documents that are not located on your System volume. Enable Deduplication on the drive, and exclude a share of importance in your environment.

**Solution** Deduplication in Windows Server 2012 R2 can be managed via PowerShell. Here we outline the steps you will take to work with deduplication and some of the cmdlets you would use.

- 1. From PowerShell type,
`Enable-DedupeVolume -Volume E:\` where E: is the volume you are trying to dedup.
- 2. Exclude a folder using PowerShell:
`Set-DedupeVolume -Volume E:-ExcludeFolder E:\shares`
- 3. Verify all the information using:
`Get-DedupeVolume`
- 4. Change the file age to 0 so all files are considered for dedup:
`Set-DedupeVolume -Volume E:-MinimumAge 0`
- 5. Start an optimization job:
`Start-DedupJob -Type Optimization -Volume E:`
- 6. Verify that space savings have been made:
`Get-DedupStatus -Volume E:`

Combine and NTFS permissions. When a folder is shared from an NTFS drive, it includes both share and NTFS permissions. It's important to understand how these interact so that users can be granted appropriate permission.

**Master It** Maria is in G_HR and G_Managers groups. A folder named Policies is shared as Policies on a server with the following permissions:

NTFS: G_HR Read, G_Managers Full Control
Share: G_HR Read Change

What is Maria's permission when accessing the share? What is her permission when accessing the folder directly?

**Solution** Maria's permission when accessing the share is change. You can determine the result of combined NTFS and share permissions in three steps:

- Determine cumulative NTFS permissions: She has Read and Full Control, her cumulative NTFS permission is Full Control.
- Determine cumulative share permission: She has Read and Change, so share permission is Change.
- Determine which of the two provides the least access (or the most restrictive): Change is more restrictive than Full Control.

If the folder is accessed directly, share permissions do not apply. So, you would have Full Control permission.
