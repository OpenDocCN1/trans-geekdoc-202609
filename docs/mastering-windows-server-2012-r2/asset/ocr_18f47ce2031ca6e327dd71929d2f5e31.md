By default, the wizard allows for anonymous access to the FTP site. If you want to change
this, follow these steps:

+   1. Deselect "Log on anonymously," and type a username you want to use to on.
2. Click the Next button, and name the location (for example *ftp.bigfirm.com*).
3. Click the Next button, and click Finish.

The network location will open, and the network location will be listed in the Network
Location section of the Computer window, as shown in Figure 18.36.
To disconnect a network location, simply right-click the network location, and select Delete.
