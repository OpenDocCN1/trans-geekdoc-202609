4. Click Next to display the Connect to AD FS page. As part of the configuration process, AD FS will register itself with your AD DS. You will be required to enter the credentials of an Active Directory domain administrator to continue this point in the configuration process.

5. After entering the appropriate credentials, Click Next to move to the Specific Properties page. This is where you are required to attach your trusted SSL Certificate to the Federation Service. If you created an SSL Certificate locally to the server then you can easily select it from the drop-down provided, or you can import it to bring in from a network or location. You will notice that as soon as you have selected the certificate you wish to use, the Federation Service Name will auto-populate with the same name as the certificate, as shown in Figure 10.6. Do not worry much about the syntax of the Federation Service Name or the name of your SSL Certificate because the very last option given to us on this page of wizard is to create a friendly Federation Service Display Name that will be displayed when a user signs in. In most cases the name of the Company is used as a Federation Service Display Name.
