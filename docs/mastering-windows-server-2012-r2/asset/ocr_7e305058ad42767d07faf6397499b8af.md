# CREATING A GROUP AT THE COMMAND LINE

You can do the same thing with the command prompt using the net localgroup command.
You can get help by running the following:

net help localgroup

You can create the group by running this:

```
net localgroup Fileshare /add /comment:"Members assigned permission to the fileshare on this server?
```

The syntax for this command is as follows:

```
net localgroup <name of the new group> /add /comment:"a description for the group>
```

Note that you cannot add a user to the group while creating it from the command prompt.
