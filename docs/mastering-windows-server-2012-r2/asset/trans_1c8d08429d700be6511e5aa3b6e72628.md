## 使用组策略对象发布资源

从 Windows 2008 版本的 Active Directory 开始，你能够以中心化的方式将所有常用资源发布到客户端（以及服务器）设备。第 9 章讨论的新功能是**组策略：首选项**。这些策略允许你执行诸如设置驱动器映射、创建快捷方式和配置环境设置的操作，如图 18.23 所示。你可以对位于特定组织单元 (OU) 的用户和计算机执行此操作![](img/41a83208e6906a37326203b8cea_991_0.png)

## 连接网络资源

任何组织的资源配置都应该通过 Active Directory 组进行集中管理和控制。一旦建立了这些组，你就可以通过策略管理文件服务器、打印机和应用程序。过去的本地网络发现和共享已消失，因为安全和合规性要求经过审计。在下一节中，我们将介绍如何向工作站创建并发布某些资源。我们将重点关注 bigfirm.com 的营销部门，并将所需的资源发布到营销团队使用的 WIN8client 设备。

通常，域管理员会将公司文件存储在集中的、安全且易于备份的位置（即不存储在个人计算机上）。为了访问这些资源，你需要确保将适当的 Active Directory (AD) 组应用于文件共享，并配置你的组策略对象 (GPO) 进行发布。

## 发布网络文件共享

以下示例将引导你如何向终端用户发布资源。你将通过创建名为 Marketing 的 OU 组来开始此过程。此示例假设你理解如何创建组织单元和域组。如果你不这些操作，请参见第 7 章“Windows Server 2012 中的 Active Directory”。

-   1. 打开 Active Directory 用户和计算机，创建一个名为 Groups 的 OU。
-   2. 选择 Groups OU 并创建一个名为 Marketing 的组。参见图 18.24 的示例。

# 图 18.24
Active Directory OU 和组设置
![](img/41a83208e6906a37326203b8cea_992_0.png)

-   3. 打开 Marketing 组并将 Kevin 添加到该组。
-   4. 点击“应用”，Marketing 用户将被添加，你可以开始配置你的组策略对象。
-   5. 要创建 GPO，首先打开管理工具 > 组策略管理。
-   6. 选择组策略对象文件夹并右键点击它。创建一个新的 GPO，如图 18.25 所示。

![](img/41a83208e6906a37326203b8cea_993_0.png)

-   7. 对于此示例，将 GPO 命名为 BigFirm_Marketing。
-   8. 双击 BigFirm_Marketing GPO。

你会看到组策略对话框的第一个选项卡，名为“范围”。在范围部分，你需要设置 Marketing 组应用于该 GPO。

-   9. 在“安全筛选”部分下点击“添加”，输入 Marketing 并点击确定。
-   10. 现在选择所有其他组并点击删除。

在左格中选择具有 BigFirm_Marketing 策略的唯一组并选择“编辑”。
-   11. 右键点击名称（默认域策略）。
-   12. 组策略管理编辑器现在打开。在这里选择“用户配置”部分。
-   13. 展开 `UserConfiguration\Preferences\Windows\Settings`。你会看到可以为用户修改的所有基本首选项。
-   14. 选择“驱动器映射”，右键点击并选择“新建”、“映射驱动器”。

“新建驱动器属性”对话框将打开。图 18.26 显示了此配置的基本内容。

# 图 18.26
创建驱动器映射首选项策略
![](img/41a83208e6906a37326203b8cea_994_0.png)

-   在“操作”字段中，选择“创建”。
-   在“位置”字段中，输入你的通用命名规范 (UNC) 驱动器映射：`\bf1\BF_Marketing`。
-   勾选重新连接框。
-   在“标记为”字段中，输入你希望驱动器向终端用户显示的名称。我们在示例中使用 Marketing。
-   为你的驱动器号点击“使用第一个可用，从：”选项。你也可以点击“使用:”选项并在下拉框中选择驱动器。
-   我们让所有其他选项保持默认值，你可以根据环境需求进行修改。

-   15. 点击“应用”和“确定”返回“驱动器映射”部分。

你应该能在右格中看到 E 驱动器映射。
现在 GPO 已创建，并且定义了驱动器映射策略，你需要将其链接到 bigfirm.com，这样你就可以使用此策略了，如图 18.27 所示。将此组策略对象链接到 bigfirm.com 允许营销用户（无论他们处于哪个 OU）都应用该策略。
