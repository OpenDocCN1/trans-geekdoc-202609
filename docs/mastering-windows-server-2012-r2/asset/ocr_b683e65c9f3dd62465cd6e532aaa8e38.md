# Adding the SMTP E-mail Feature to an IIS 8 Website

Once the SMTP E-mail feature and the entire Web Server role of role services have been installed, the SMTP E-mail feature will appear in the Information Services (IIS) Manager console for IIS 8 websites. Despite the IIS virtual servers' state(s), the SMTP E-mail feature can be enabled for the entire server or for a few chosen sites or websites. Global settings for SMTP defined at the server-level application.config file can be inherited by one or more websites.

The SMTP E-mail feature is listed at the server-level under the area titled ASP.NET (Figure 19.21). From the Views, the Actions link opens to view the feature settings, restarts/starts/stops the feature, views application pools that are configured to service the feature, views sites that have been configured to use the feature, or get help with SMTP email.
