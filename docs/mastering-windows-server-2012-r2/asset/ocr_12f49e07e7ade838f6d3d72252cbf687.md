# CHAPTER 13 FILES, FOLDERS, AND BASIC SHARES

+   1. Launch Server Manager and browse to the Shares tab of File and Storage Services, you'll see all the shares that are currently shared on the network.

+   2. Right-click any of the available shares and select Properties.

+   3. Click the Settings button, and select the Caching tab.

Your display will look similar to Figure 13.33. On this page you can enable caching of the share and BranchCache if it is not already enabled.
