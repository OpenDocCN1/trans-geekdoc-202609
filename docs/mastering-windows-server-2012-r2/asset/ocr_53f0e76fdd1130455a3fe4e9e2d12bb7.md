Excluding a file is great, but you may have some folders in the organization that are highly sensitive, and for that reason you can't dedup them. At the start of this chapter we said that the dedup engine has a background process that will run every hour by default. In Figure 12.73 you also have the option to change that schedule.

+   7. Click the Set Deduplication Schedule button, and you will see three checkboxes, as shown in Figure 12.74.

By default background optimization is turned on, you can also enable throughput optimization, which will force the optimization job through when dealing with large amounts of data. Microsoft says a throughput job can process roughly 2 TB of data volume in a 24-hour period on a single volume. If you have multiple volumes, you can run this in parallel.
