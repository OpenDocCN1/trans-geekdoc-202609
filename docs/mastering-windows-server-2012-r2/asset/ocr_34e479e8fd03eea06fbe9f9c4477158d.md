# RENAMING THE SERVER

Every Windows computer should have a unique name to uniquely identify it on the network. Every organization has its own practice. Some use tightly structured names that describe the location and function, some use nondescriptive names with incremental numbers, and some names of characters from their favorite TV show or from a team that they support.
Click the link next to Computer Name, which you can find in the details of Server Manager, as shown in Figure 2.28, to control the name of this server or the domain or workgroup membership of this server. You should rename this server according to the naming standards of the organization. You should click Change to do this in the dialog box shown in Figure 2.29.
