# LOGGING IN WITH A NEW GROUP MEMBERSHIP

Here's something important to note. It doesn't matter if you are working with Active Directory or local groups. A user can use their group membership only when they log in or the group membership has been modified. Steve would not be able to use his new group membership if he was currently logged in. You would have to advise him log out and back in again.
