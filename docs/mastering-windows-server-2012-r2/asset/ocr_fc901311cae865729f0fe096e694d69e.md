# ENABLING THE AD RECYCLE BIN WITH POWERSHE

Use the following PowerShell script as an alternative method to enable the AD Recycle Bin:

```
Enable-ADOptionalFeature -Identity CN-Recycle Bin Feature,CN=Optional
Features,CN=Directory Service,CN=Windows NT,CN=Services,CN=Configuration,DC=BigF
rm,DC=COM' -Scope ForestConfigurationSet -Target 'BigFarm.com'
```

# RECOVERING A DELETED OBJECT WITH THE RECYCLE BIN

If you've accidentally deleted an object in your Active Directory but you have the AD Recycle
Enabled, follow these steps to properly recover it. (For our example, we've deleted a user
Sally and now need to get back):

+   1. From Server Manager, choose Local Server ➤ Tools ➤ Active Directory Administrative
Center, and click your (local) domain from the navigation pane to the left.
2. Double click the Deleted Objects container in the central pane.
3. Locate the deleted object, right-click it, and then choose a restore option from the
menu, as shown in Figure 32.11.
