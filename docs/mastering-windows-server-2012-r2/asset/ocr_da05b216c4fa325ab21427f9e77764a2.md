If you already have share and quota templates, you can easily configure quota by right-clicking the share on the Shares tab of the File and Storage Services role in Manager and selecting Configure Quota. Adjusting the properties and creating quota templates is done directly through FSRM in the Tools directory over Server Manager.

Imagine you want to monitor the data that is stored in a folder named Graphics on your system. Specifically, you want to know whether the amount of storage used is getting close to 50 MB. If the limit is reached, you want to send a report to the user letting know which files are duplicates, which files are the largest, and which files haven't been used recently.

You can use the following steps to create this quota:

+   1. Launch Server Manager, and browse to Tools ➤ File Server Resource Manager.

+   2. Expand Quota Management, right-click Quotas, and select Create Quota.

+   3. Enter the path to folder you want to monitor in the Quota Path text box.

For example, you could enter I:\ Finance. Alternately, you could click Browse and browse to the path. You are given the choice here to apply this new quota only to the selected folder, or you can propagate this template to all existing and new subfolders within the Graphics directory.

The next choice on this page allows you to define the quota properties.

+   4. For this exercise select the 200 MB Limit Reports to User option. We will edit this property later.

+   5. Review the summary of quota properties and click Create.

The new quota will now be displayed, allowing you to further modify your desired settings.

+   6. Right-click the new quota and select Edit Quota Properties.

On the Quota Properties page provide a description of your new quota.

+   7. Then manually adjust the Space limit to 500 MB and keep the default setting of "Hard quota." Now you can edit your Notification thresholds, as shown on the left side of Figure 13.25.

+   8. Select the Warning (100%) notification threshold, and click Edit.

+   9. Review the information on the E-mail Message, Event Log, and Command tabs.

 a warning appears indicating that an SMTP server is not configured, review the information, and click Yes to continue; you can configure the SMTP server later. Notice that you can modify the data on any of these tabs.

+   10. Click the Report tab. Your display will look similar to the right side of Figure 13.25.
