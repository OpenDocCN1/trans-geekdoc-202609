# IP ADDRESS BLOCKS

In IPAM, an IP address block is the highest organizational level you can to group your address spaces. IP address blocks contain IP address ranges that can be sorted into chunks (all private addresses in one block, all public addresses in another, for example) to help you manage and maintain your IP environment. When you configure an IP address block with IPAM, if the address block comprises both IPv4 and IPv6 addresses, it will automatically sort the IPv4 into public and private address spaces and any IPv6 into unicast global blocks.

To create a private IP address block, follow this procedure:

+   1. Open the IPAM console from administrative account, and from the navigation bar, click through to IP Address Space > IP Blocks.

+   2. From the lower pane in the navigation bar, right-click IPv4 and then choose Add IP Block from the context menu, as shown in Figure 5.16.
