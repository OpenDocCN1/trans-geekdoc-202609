# CREATING A NEW SEPARATOR PAGE

Given the built-in separator pages are mostly necessary in specific instances, you'll probably want to create your own separator pages if you use them. All separator pages are just text files, so you can create them in the Notepad. You can also copy the original files and modify them to fit your needs.
