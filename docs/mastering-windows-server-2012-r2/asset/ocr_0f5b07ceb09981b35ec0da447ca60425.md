This is a real time-saver. As we said, one administrator cannot create a trust for two domains; it takes admin from both sides. That meant that you'd first set up one side of the trust on one domain and then run over to a DC for the other domain and finish setting up the trust at the other domain. However, this saves you trouble. If you click "Both this domain and the specified domain," then the wizard will ask you for an administrator account and password on the other domain.
