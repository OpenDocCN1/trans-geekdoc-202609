# Windows Server 2012 R2
Networking Enhancements

When Microsoft first released Windows Server 2012, the new networking capabilities were arguably the most hyped and eagerly awaited features of the operating system. With the release of Windows Server 2012 R2, networking has been further enhanced. In this chapter we will explain how IPv6 and Windows PowerShell enhance the Windows Server 2012 R2 networking experience, and we will discuss Network Interface Card (NIC) Taming and enhanced Quality of Service (QoS). Toward the end of the chapter, we will delve into networking performance and management to ensure that you get the most out of your networking deployments.

* Understand the new QoS features
* Manage network performance

# The Journey to IPv6

Because Windows Server 2012 networking is built on Internet Protocol version 6 (IPv6), it’s worth going back history to explore the development of the Transmission Control Protocol (TCP) and its journey to where we are now. When TCP was combined with the first publicly version of Internet Protocol (IPv4), we got TCP/IP, which is the base of all modern networking. Microsoft first developed its TCP stack in the 1990s. It evolved as Microsoft developed the various versions of its operating systems, but at its core remained mostly unchanged right up to Windows Server 2003. At that point, it became apparent that the old TCP/IP(4) stack couldn't evolve further and was starting to become a bottleneck. Microsoft saw the need for a new stack to be able to take advantage of new technologies and opportunities that its customers and partners were encountering. As a result, they worked on the new version of TCP/IP, which would include a suite of protocols and standards newly developed by the Internet Engineering Task Force (IETF) known as IPv6.
