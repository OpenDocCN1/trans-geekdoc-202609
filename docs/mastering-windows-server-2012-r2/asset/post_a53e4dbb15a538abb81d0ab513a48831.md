The Scope tab helps keep track of many aspects of the GPO. The most important of these details include when in Active Directory it is linked to the uppermost area of the tab named Security Filtering. The Links area and the middle area are, listing the sites, domains, and OUs the GPO is currently linked to. The Security Filtering area clearly indicates which groups and users have the permission to apply the settings in the GPO. WMI filters allow the targeting of GPOs to computer accounts based on the state of the computer at the time the WMI query runs.

There are two major types of settings, as we mentioned earlier. Computer Configuration settings are applied to computers at startup and during the background refresh interval. User Configuration settings are applied to the user accounts at logon and during the background refresh interval. Once you've configured your Group Policy settings, simply simplify the GPME window. There is no Save or Save changes option. Changes are written to the GPO when you click OK or Apply on a particular setting, although the user or computer will not actually see the change until the policy is refreshed.

# Group Policy Application

Like most technologies, Group Policy has associated with it to ensure a reliable manner. For the most part, the application of Group Policy will be straightforward. It is only when you start to conflicting settings in multiple GPOs and you want to modify the default behavior that the logic becomes more complex. Regardless, when you wish to design and implement your settings, you will need to fully grasp what the end result will be.

In this section, we will cover the default Group Policy application, which will resolve all your questions regarding GPO settings. You know, "What if I have a GPO at the domain that removes the Run command from the Start menu but a different GPO linked to the Desktops OU adds the Run command to the Start?"

We will delve into areas that will help you "target" your GPO settings for when too many users and computers (or not enough users and computers) are receiving the policy. With WMI filters, enforcement, blocking inheritance, and more, you will certainly be without options.
