# APPLING DYNAMIC ACCESS CONTROL POLICIES

You have created a Dynamic Access Control policy, but you need to apply it to your servers in
 to be effective. This is done via Group Policy. By deploying it via Group Policy
you have amazing flexibility to start targeting specific server groups and roll it out further as
necessary.

In Chapter 9 you have become familiar with Group Policy; if not, skip back now and
read it.

You need to use the Group Policy Management console to create a new group policy to roll
out your Central Access Policy. To recap, the Group Policy Management console is located in
Server Manager ▷ Tools.
