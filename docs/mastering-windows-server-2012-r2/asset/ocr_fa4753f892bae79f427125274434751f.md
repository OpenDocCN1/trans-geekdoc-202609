# WHEN TO BACK UP

Remember that performing a backup requires heavy disk activity and processor cycles. Because of this, backups should be performed only when user activity on the server is low, such as overnight off-hours. If you perform backups during peak usage times, your users may complain of slow access, and their activities on the server may delay the backup.
