# DEPLOYMENT CONFIGURATION

The deployment choice option allows you to identify whether you are creating a new domain in a new forest or adding it to an existing forest. If you're adding it to an existing forest, you can add another domain controller to an existing domain (which is covered later in this chapter) or create a new domain.

For the first DC, your choice is simple. You'll be creating a new domain in a new forest.
