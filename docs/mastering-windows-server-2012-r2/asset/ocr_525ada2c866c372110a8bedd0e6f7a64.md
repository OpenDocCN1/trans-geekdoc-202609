Chances are you are a system administrator, responsible for a number of servers in your organization. If you've been in the business, you will have noticed that server power tends to grow faster than the requirements of applications.

In the past, if a company needed to host a new line of business, they would likely go out and purchase a new server. That would require at least 4 GB of RAM and 8 GB or. Moreover, because Windows Server 64-bit capable hardware, they'd purchase a machine that supports this. This process was repeated frequently when new applications were brought online; a consequence of this is that most servers are just idling with 5 percent CPU usage, massive gigabytes of memory, and I/O bandwidth to spare. This is a waste of resources, and that's where virtualization makes a lot of sense.

With virtualization, you can consolidate many servers on the same hardware. Not only will these servers, you will consume less of the hardware, but because you have fewer physical servers, even better with the right software, you can move virtual servers between physical servers easily, giving you a flexible configuration.
