# Configuring Mandatory Profiles

Ask a veteran administrator that the cause of many problems is not far from a desktop environment, and you'll be sure to find that user configuration is not from the top of the list. You may want a solution that provides users with a clean user configuration every they log in.

The solution that we're talking about is a mandatory profile. This works by pre-creating a profile for users, configuring it as a mandatory profile, and making it available to all the required users as their roaming profile. No matter what the user makes, they will not be saved. Every time the user logs in, their profile will be reset to what the administrator had defined.

Other benefits include the following:

+   - You can provide the user with a preconfigured and consistent working experience.
- You can always ensure that the user has the required shortcuts for applications.
- You will reduce the administrative workload and complexity associated with roaming profiles.

These are typical scenarios where you find mandatory profiles:

+   - Remote Desktop Services server farms
- Environments where there may be significant staff churn and training time is minimal, for example, call centers

You'll learn how to create a mandatory profile.
