Just as the different domain functional levels adds features to your domain, the different
forest functional levels also provide various features.

**Windows Server 2003** Windows Server 2003 provides the following features:

+   * Ability to create forest trusts
* Ability to rename a domain
* Ability to deploy a read-only domain controller (RODC)
* Improved Knowledge Consistency Checker (KCC)
* Improved linked-value replication so that only the differences of the group memberships
replicated
* Access-based enumeration in the DFS namespace

**Windows Server 2008** The Windows Server 2008 functional level does not provide any
additional features.

**Windows Server 2008 R2** The Active Directory Recycle Bin lets you restore deleted objects
without starting the domain controller in Active Directory Restore Mode. You need to enable
the Active Directory Recycle Bin using PowerShell commands. Active Directory Recycle Bin is
a great feature that was improved in Windows Server 2012. It is now much easier to set up andnmanage, as you will see later in this book.

**Windows Server 2012** The Windows Server 2012 functional level offers no new features.

# WHAT'S DIFFERENT IN WINDOWS SERVER 2012 R2 FUNCTION LEVELS

As we are writing this book, we are testing with a preview version of Windows Server 2012 R2.
Although little in Active Directory has changed, there are some changes in functional levels from
predecessor.

You can add a Windows Server 2012 R2 controller into an existing 2003 functional level
environment. But be aware that the Windows Server 2012 R2 functional level is
deprecated. When you deploy a Windows Server 2012 R2 into an existing Windows Server 2003
environment, you will be prompted to move to a higher functional level.

The lowest functional level you can select in Windows Server 2012 R2 is the Windows Server
2008 domain and forest functional.

You can find a full-featured overview of the new functional level on TechNet. Hopefully,
will be updated by the time this book is published. Go to:

functional-levels.aspx
