# FIGURE 2.29

Computer name

![](bbox=[0.316, 0.423, 0.883, 0.755])

This was a clean installation of Windows. You may remember that the install didn't ask you for a computer name. Instead, the server was given a randomly generated name. Some security experts like this, but we like to be keep track of our servers, so we try to give them structured names.

To do this, you should change the name under “Computer name,” and click OK (see Figure 2.30). Make sure that name is unique on the network; otherwise, you will encounter problems.
