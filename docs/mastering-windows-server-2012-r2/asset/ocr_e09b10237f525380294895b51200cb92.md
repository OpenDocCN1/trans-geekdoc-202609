# ## PROTECT FROM DELETION

"Protect from accidental deletion" is a neat feature that prevents anyone (even administrators) from accidentally deleting an object. Even ADAC prompts you with the “Are you sure?” question, many of us click right through these confirmation dialog boxes. However, when this option is set, the object cannot be deleted until the object is cleared.

If you really want to delete an object, you can still. Modify this setting by right-clicking the object in ADAC, choose Properties, and deselect the option.

You notice that you have two Users objects in Active Directory, but they are very different. The Users OU within the Sales OU is an OU and can have GPOs linked to it. The Users container under is the only container (not an OU) and cannot have GPOs linked to it. OUs have slightly different icons to identify them—it is not just a folder but instead with an icon embedded on the front of the folder reminding you that it is something more.
