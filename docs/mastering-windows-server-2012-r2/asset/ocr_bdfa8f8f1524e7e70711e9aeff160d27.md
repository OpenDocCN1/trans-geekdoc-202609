# CONFIGURING HOME DIRECTORIES

Disable folder permission inheritance, and set the folder permissions as follows:

| Group | Permission |
| BF2\Administrators | Full Control |
| System | Full Control |

You're doing this because any folders you create in D:\Shares will inherit these permissions by default. This makes the new shared folders secure by default. It will be up to you and other administrators to assign access to the correct users or security groups. It will also prevent administrators from creating folders here without permission. Now create a folder in D:\Shares called Home.

The Home folder will now be shared. This will mean that you can create subfolders for each user and only have to manage a single share. The aim of this is to simplify deployment and make security management easy as possible.

You are now going to use the File and Storage Services tools. The tool shown in Figure 26.3 will appear when you select File and Storage Services from the Server Dashboard and then select the Shares.
