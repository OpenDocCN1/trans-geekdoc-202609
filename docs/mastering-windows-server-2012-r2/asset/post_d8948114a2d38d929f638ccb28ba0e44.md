Trust relationships can fall apart for various reasons, or if you create a trust, leave it for a few months, and then try to use it by migrate, you might find that it doesn't work. netdom can "refresh" a trust with the /reset option:

```
netdom apex.com /domain:Test.com \
/User:testAdmin/Password:T3$.com \
/User:apexAdmin/Password:@apex.com \
/reset
```

It's the same as the command that creates, but instead of adding /add /toway /enablesidhistory, you just use /reset.
