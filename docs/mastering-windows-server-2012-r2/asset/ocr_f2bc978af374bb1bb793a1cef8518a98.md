# FILTERING LOGS

Custom views can be filtered just as any regular event log can be filtered. A log could contain hundreds or thousands of events. If you're looking for a specific event, it may take you hours to comb through the events one by one, but you can use a filter to quickly narrow your search.

Although this section covers how to filter a custom view, you can follow the same steps to filter any log within Event Viewer.
