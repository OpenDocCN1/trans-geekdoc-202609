In the Find drop-down list, choose Printers. If there are multiple domains on the network, you can search more specific by choosing your domain name from the drop-down list (located to the right of the Find drop-down list). If the list of printers is long, you can search by name or keyword or use the Advanced tab to search by other properties. You can set your search criteria, click Now. All printers published to Active Directory that meet your search criteria will appear in the Results window.

To add a printer to your computer, right-click the printer and choose Connect. The printer will install, and you will see it in your Printers folder.

# Adding a Network Printer from the Command Line

If you know the name of the printer you want and the server it's attached to, you can add it from the command line with the start command. For instance, add the printer bf_main_printer connected on server b1 to a Windows 7 or Windows 7 client, open a command prompt and type the following:

```
start \b1\bf_main_printer
```

When the printer installs, the print queue for that printer will appear, and the printer will be listed for you in the Devices and Printers applet.

# Adding a Network Printer Using the Network Applet

To add a network printer to a Windows 8 or Windows 7 client machine, open the Network applet, and click the Add Printer link on the toolbar of the Network dialog box. Clicking the link will open the Add Printer Wizard. This is the same wizard you get when you add a printer from the Devices and Printers button (located on the Start menu in Windows 7) and the Printers applet (located in Control Panel in Windows Vista). Remember, you can get to operating system features in many ways.

Like previous versions of the Add Printer Wizard, this version allows you to add local printers, Bluetooth resources, and printers that are located on the network. This section will concentrate on network resources, which comprise cable or wireless network. To add a network printer, click "Add a network, or Bluetooth printer," and click Next. As you click this option, the wizard will search for printers on the network and return any it finds. On the Results screen. The default configuration is to make Next the default printer, you can change this by deselecting the "Set as default printer" box. Click the "Print a test page" button to send a test page to the printer, and click Finish.

The options are to do the following:

+   - Search Active Directory for published network printers
- Enter a printer location and name (in the form of \\server\intername)
- Specify a printer using its hostname or its TCP/IP address (also called TCP/IP printer)

The option "Find in a directory, based on location and feature" opens the Printers window. You search Active Directory for printers by specifying certain search criteria (such as a name or a printer model) or a printing feature (such as the ability to print double-sided). Click the Find Now button, and the wizard returns printers that match the specified criteria, as shown in Figure 18.31. You can also enter no criteria, and the search will return all printers in Active Directory.
