# Changing Domain User Passwords

Good security practice demands that passwords be changed regularly and known only to the user. The operating system users employ to connect to a Windows Server 2012 domain requires user intervention to change the passwords.

Most of this book is geared toward the administrator, this section has information that the administrator will need to convey to the user population so they can do it. The good news is that changing passwords is extremely simple, and the UI will give them the guidance the user needs:

+   * If policy requires a user to change their password when they first use an account, they'll be prompted to do this.

+   * If policy demands a user to change their password because the password will soon expire, they'll be prompted to do so, told how to do it, and how long they have until the password expires.

If a user forgets their old password, they will not be able to change it, and if the administrator has followed best practices, they won't know the password either. The administrator will need to update the password on the domain account and then set the password to be changed at first login.

# PASSWORD POLICIES AND ADVANCED FEATURES

Windows Server 2012 provides the same user password policies that have existed since Windows Server 2008 and R2. Windows Server 2012 enables the available features such as fine-grained passwords.

Windows Server 2008 introduced fine-grained policies to allow IT and security groups to have multiple security principals in the main domain or forest. Previously in Active Directory you could manage only one default password policy for your entire domain. Setting fine-grained passwords in Windows Server 2008 was a tedious task and wasn't very intuitive.

Windows Server 2012 has this feature much more intuitive and allows you to perform configurations in Windows Manager, or utilize the full-feature capabilities from PowerShell 3.0.
The Windows Server 2012 Default Group Policy enforces regular password changes and complexity rules. The Group Policy setting is located at Computer Configuration\Policies\Windows Settings\Security Settings\Account Policies\Password Policy.

The default password policy settings are as follows:

Enforce Password History This requires users to use a certain number of unique passwords before an old password can be reused. The default number is 24 passwords.

Maximum Password Age This is the number of days a password can be used before the user must change it. The default is 42 days.
