A thing being about forest is that all of them trust each other because of transitive

This is the transitive nature of some trusts. The automatically built parent-child trusts and
the forest-root-tree root trusts are transitive. Shortcut trusts and forest trusts are transitive,
they are created manually. The transitive nature reduces the number of trusts needed to be
created.
