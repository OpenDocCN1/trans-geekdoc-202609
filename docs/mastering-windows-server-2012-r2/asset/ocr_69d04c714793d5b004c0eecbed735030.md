# USING DSAIN.EXE

Dsamine makes a copy of the AD database available through the LDAP from your computer. LDAP, you can access this version of AD DS using a variety of tools, such as Ld.exe or any of the Active Directory snap-ins in Windows Server 2012 R2.
These steps assume that you have created and mounted a snapshot using the previous procedures:

+   1. Use Windows Explorer to browse to the Nds.dit file in the mounted snapshot. The path will be similar to: C:\$SNAP_200986191422_VOLUM$\Windows\NTDS\Nds.dit.
2. Hold the down Shift key, and right-click Nds.dit. Click "Copy as path."
3. Open an elevated command prompt.
4. Type dsamine /path <path>/ldapPort 10389. For the <path> value, right-click the command prompt, and select Paste, paste in the copied path.
The result should be similar to this:
dsamine /path C:\$SNAP_200986191422_VOLUM$\Windows\NTDS\Nds.dit
/ldapPort 10389
5. If the command completes successfully, leave the command prompt open while you work with the mounted snapshot.
Once you close the command prompt, you will close the dsamine.exe session.
6. To quit dsamine.exe, press Ctrl+C.

Now that you have the snapshot mounted and have made it available as an LDAP instance, you can view it with any tool that can connect to LDAP, as asied.
