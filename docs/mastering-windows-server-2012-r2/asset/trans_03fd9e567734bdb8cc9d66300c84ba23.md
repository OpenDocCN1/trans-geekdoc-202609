## IP 地址空间

在这里，你将看到 IPAM 如何集中管理你的 IP 地址空间。该视图由三个不同的部分组成，如此处讨论所示。

## IP 地址块

在 IPAM 中，IP 地址块是你可以用于对地址空间进行分组的最高组织级别。IP 地址块包含 IP 地址范围，这些范围可以被分成若干块（例如，一个块包含所有私有地址，另一个块包含所有公有地址），以帮助你管理和维护 IP 环境。当你使用 IPAM 配置 IP 地址块时，如果地址块同时包含 IPv4 和 IPv6 地址，它会自动将 IPv4 分为公共和私有地址空间，并将任何 IPv6 分为全局单播块。

要创建一个私有 IP 地址块，请遵循以下步骤：

- 1. 使用管理员账户打开 IPAM 控制台，在导航栏中点击进入 IP 地址空间 (IP Address Space) > IP 块 (IP Blocks)。
- 2. 从导航栏底部的窗格中右键点击 IPv4，然后从上下文菜单中选择“添加 IP 地址块”(Add IP Block)，如图 5.16 所示。

- 3. 在“添加或编辑 IPv4 地址”对话框中，分别在网络 ID (Network ID) 和前缀长度 (Prefix Length) 字段中输入你选择的 ipv4 地址和子网掩码前缀长度——我们选择了网络 192.168.1.0 和前缀长度 24——然后点击确定。值得注意的是，根据你提供的 IP 和子网信息，IPAM 将自动将此 IP 块添加到公共或私有地址空间。

- 5. 现在点击 IP 地址块，查看“配置”（Configuration Details）选项卡中的所有相关信息。

## 第5章 IP 地址管理与 DHCP 故障转移

一旦地址块开始处理数据，利用（Utilization）和事件（Event）选项卡将开始填充。

创建 IPv4 地址块的过程与创建私有地址块类似，但有一些额外的步骤：

- 1. 使用管理员账户打开 IPAM 控制台，从导航栏点击进入 IP 地址空间 > IP 块。
- 2. 从导航栏底部的窗格中右键点击 IPv4，然后从上下文菜单中选择“添加 IP 地址块”，如图 5.16 所示。
- 3. 在添加或编辑 IPv4 地址块对话框中，分别在网络 ID 和前缀长度字段中输入你选择的 IPv4 地址和子网掩缀长度——我们选择了网络 208.215.179.132 和前缀长度 30。
- 4. 现在，由于这是一个公共 IP 地址块，选择区域互联网注册机构 (RIR) 作为 IP 地址块（我们在此选择了 RIPE），如果适用，完成 RIR 值设置。
- 5. 要查看新创建的 IP 地址块，从下拉菜单中选择“IP 块”视图，并在下方窗格中点击 IPv4。
- 6. 验证你的新公共 IP 地址块可用，并可以在“配置详情”选项卡中查看信息，如图 5.17 所示。

## IPAM 分配

为了更好地理解 IP 地址块，请记住 IPAM 将将 IP 地址分配给 IP 地址范围（类似于 DHCP 范围），然后这些 IP 地址范围将自动分配到类似：IP 地址范围 > IP 地址块。

## IP 地址清单

在这里，你可以看到 IPAM 可用的所有 IP 地址以及与之关联的设备信息（例如主机名和设备类型）。这里有实用的筛选（Filter）和添加（Add）标准，允许你根据大量选项将 IP 地址缩小到组级别。从此视图，你可以通过右键点击 IP 地址为 DNS 和 DHCP 添加记录和预留。

## IP 地址组范围

IP 地址空间的最终优势允许你创建逻辑组来帮助组织你的 IP 地址范围。你可以点击下拉菜单在 IP 地址、IP 地址范围和 IP 地址组之间导航。如果你在这里选择“IP 范围”选项并点击编辑，可以在自定义配置部分配置自定义字段，通过 Active Directory 站点、国家或地区、部门、设备类型等标准定义 IP 地址范围。

你还可以指定某些标准的值以获得对逻辑地址范围组的进一步控制（例如指定 IP 地址空间自定义字段）。一旦你使用自定义字段和值编辑了这里的 IP 地址范围，将看到一个完全透明且熟悉的 IP 资产分组，使用静态电子表格！

## 虚拟化 IP 地址空间

在 Windows Server 2012 的 IPAM 版本中，使用 System Center 2012 虚拟机管理器 (VMM) 管理虚拟 IP 地址的能力非常有限。由于数据中心和云管理的关注，微软在增强 Windows Server 2012 R2 的 IPAM 方面投入最多。IPAM 控制台的“虚拟化 IP 地址空间”部分通过与 VMM 的新连接简化了物理和虚拟地址空间的管理。这种集成开启了本地和云方案之间的 IP 地址管理功能。

## 第5章 IP 地址管理与 DHCP 故障转移

配置相对简单，但它仅适用于 Windows Server 2012 R2 和 System Center 2012 虚拟机管理器。假设你已经在与 IPAM 服务器相同的域中部署了 VMM 2012 R2 服务器，集成方法如下：

- 1. 使用具有管理员权限的账户登录 VMM 2012 R2 控制台，点击导航栏中的“架构”（Fabric）标签。
- 2. 从功能区点击“添加资源”（Add Resources）按钮并选择“网络服务”（Network Service），如图 5.18 所示。

- 3. 在“添加网络服务”向导的“名称”框中，输入名称（例如 IPAM）和服务的描述；点击“下一步”。
- 4. 从“制造商和模型”对话框中，将制造商保留为 Microsoft，从模型菜单选择“Windows Server IP 地址管理”，如图 5.19 所示；然后点击“下一步”。
