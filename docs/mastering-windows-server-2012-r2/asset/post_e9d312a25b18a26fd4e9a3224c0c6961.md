# Modifying the Allowed List

If you want to allow users to have their passwords replicated or cached onto any RODC instead of a specific RODC, you can modify the properties of the Allowed RODC Password Replication group by following these steps:

- 1. Launch Active Directory Users and Computers.
- 2. Browse to the Users container.
- 3. Right-click the Allowed RODC Password Replication group, and select Properties.
- 4. Select the Members tab.
- 5. Click the Add button.
- 6. Enter Remote Office Admins in the text box.

This is the name of a group created earlier in this chapter. If desired, you can also click the Advanced button and browse to locate a user or group. Your display will look like Figure 23.17. Notice that you can add or remove groups from this page.

# SECURITY WARNING

Although it is possible to remove members from the Denied RODC Password Replication group, Microsoft recommends not modifying any of the prepopulated groups. These groups ensure that passwords for accounts with elevated permissions are not cached on the server. If a member of the group logs onto the RODC, it is possible their account credentials will be stored on the RODC and subject to compromise if the RODC is stolen or attacked.

# Staged Installations

Normally, you need to be at least a member of the Domain Admins group to promote a server to a domain controller. However, it is highly unlikely that a member of the Domain Admins group will be assigned to work at a remote office.

This may not be a problem in many scenarios, but situations may arise when it is difficult for a member of the Domain Admins group to travel to the remote office. With this in mind, you have several options:

**Build the RODC at the Main Office and Ship It to the Remote Site** This could be expensive and time consuming. If the server is a new purchase, it would be cheaper to ship it directly to the remote office and build it there.

**Have a Domain Admin Travel to the Remote Site to Perform the Installation** If the office is across the country, this is an ideal solution.

**Staged Installations**

A staged installation involves preparing the RODC at a central location and then shipping it to the remote site. This avoids the need for a Domain Admin to travel to the remote office.

# Using Installation Media

To create the installation media, you need to run ndsutil:

1. Launch a command prompt with administrative privileges.
2. Create an empty directory:
   ```
   md c:\ifm
   ```
3. Run ndsutil and press Enter.
4. Type `activate ntds`, and press Enter.
5. Type `ifm`, and press Enter.
6. Type `create c:\ifm`, and a folder named Active Directory will be created with a single file ntds.dit.

You can copy this file to installation media and ship it to the remote. After the installation media is created, you can install it on the remote server using the Active Directory Services Configuration Wizard. On the Paths page select "Install from media" and browse to the proper file location.

# PRESTAGING THE RODC ACCOUNT

Prestaging an RODC account is just a fancy way of saying you create an account for the RODC before it is promoted. You must be a member of the Domain Admins group to prestage an account.

Follow these steps to prestage an account:

- 1. Launch Active Directory Users and Computers by selecting Server Manager > Tools Active Directory Users and Computers.
- 2. Browse to the Domain Controllers OU. Right-click the Domain Controllers OU, and select "Pre-create Read-only Domain Controller account," as shown in Figure 23.18.

![](img/41a83208e6906a3732620203b836cea7_1214_0.png)

The Active Directory Services Installation Wizard will start.

- 3. Review the information on the Welcome page and click Next.
- 4. On the Network Credentials page, click Alternate Credentials, and enter the credentials of an account in the Domain Admins group if the current logged-on credentials are not sufficient.
- 5. On the Specify Name page, enter the name of the RODC. Your display will look like Figure 23.19. Click Next.
- 6. On the Select Site page, select the site where the RODC will be placed.

The Additional Domain Controller Options page will appear with the DNS Server, Global Catalog, and Read-only Domain Controller choices selected. You can deselect the DNS server or global catalog if desired, the RODC selection is dimmed.
