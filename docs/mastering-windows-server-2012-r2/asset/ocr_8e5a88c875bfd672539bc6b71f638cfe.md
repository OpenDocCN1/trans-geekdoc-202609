# Adding Links to a DFS Root

Under this root share, you can add links to files or folders. To do this, all you need to do is to click the Add Folder target and add any and all files and folders you want. So, let's create a new folder and add those target files and folders.

You will need to create a new folder within the DFS Management window under Actions on the right, click to add a name to it, and then browse for the folders.

+   1. To do this, click New Folder in the DFS Management window under Actions on the right, click to add a name to it, and then browse for the folders.
2. Then just browse to add folder targets, as shown in Figure 14.34, and click OK.
3. Click OK, and if you have not created a replication for the new folder (and who would you did not know what you were going to name it?), you can then create that now.
