

# 第 14 章创建和管理共享文件夹

列出文件夹内容 (List Folder Contents)
“列出文件夹内容”权限与“读取和执行”权限类似，但它仅适用于文件夹。“列出文件夹内容”允许你查看文件夹的内容。更重要的是，“列出文件夹内容”只会被文件夹继承，并且在仅查看文件夹的安全属性时它会显示。该权限允许你看到文件夹中存在文件——类似于“读取”——但不会对这些文件应用“读取和执行”权限。如果你对文件夹应用了“读取和执行”权限，你将获得查看文件夹及其内容的相同能力，并且其内容将在这些文件夹内传播“读取和执行”权限。

特殊权限 (Special Permissions)
“特殊权限”简单来说是对原子权限的自定义分组，当标准的分子权限之一不适用于你的特定情况时，你可以创建这种分组。虽然“特殊权限”功能看起来是 Server 2003 中引入的新功能，但实际上它在 Windows 2000 中就已经存在了。它当时没有以分子权限的形式可见。在 Windows 2000 中，除非查看安全属性页的“高级”选项卡，否则无法判断文件夹是否具有原子权限。在 Server 2012 中，你可以通过查看用于“特殊权限”的“允许/拒绝”检查框来判断访问控制实体 (ACE) 是否已修改。如果勾选框出现，通过点击“高级”选项卡即可查看并编辑这些修改。

# 继承权限 (Inherited Permissions)

自早期 Windows Server 版本以来，一直存在的一个工具就是继承权限功能。现在，你可能已经习惯了使用这个强大的功能。如果一个文件或文件夹被设置为继承权限，它本身实际上没有自己的权限，而是使用父文件夹的权限。如果父文件夹也在继承权限，你只需要沿着目录链一直下去，直到找到一个实际上分配了硬性权限的目录。尽管如此，根目录是有权限的。

例如，假设你有一个名为 APPS 的文件夹，其中三个子文件夹和文件夹。所有的子文件夹和文件夹都继承权限。如果你对 APPS 设置权限为给所有用户所有“读取和执行”权限，那么所有子文件夹和文件将自动镜像这些新权限。如果你想自定义应用程序 1 的权限以便使用户也能写入怎么办？如果你右键点击应用程序 1，选择“属性”，然后点击“安全”选项卡查看文件夹的权限。如果除“特殊权限”以外的任何勾选框均为灰色，则说明该文件夹正在从父文件夹继承权限。从这里，你需要选择“高级”选项卡以便查看“从父级继承权限并传播到此对象和所有子对象”选项（这名字真长）。此选项显示对象是否正在继承权限，并允许你选择允许继承。

# 分配文件和目录权限

一旦你理解了不同权限的含义，将它们分配给文件和文件夹就是轻而易举了。从资源管理器开始，按照以下步骤操作：

- 1. 找到你想要分配权限的文件或文件夹，右键点击它，选择“属性”，然后点击“安全”选项卡。查看图 14.12。

顶部窗口显示了分配权限的不同组或用户，底部窗口了分配给所选用户或组的权限。在本示例中，你正从一个 APFS 文件夹开始。理想情况下，这是用于应用程序的，你希望所有用户都有“读取和执行”权限，而没有更改、添加或删除任何内容的能力。你还希望让管理员保持完全控制，以便他们仍然维护数据，并且有一组数据库管理员你希望他们拥有“修改”权限。由于“用户”和“管理员”组默认已有一个条目，你将开始向“数据库管理员”组添加项并赋予其“修改”权限。

- 2. 点击“编辑”，然后点击“添加”按钮、“选择高级”按钮，将出现“计算机、服务帐户或组”对话框，如之前的图 14.9 所示。

你可以输入用户或组的名称，点击“高级”按钮并点击“立即查找”，或者你可以手动设置查询以列出域帐户列表。

- 3. 由于你知道在此示例中想要添加的组名称（Database Managers），只需在“选择用户、计算机、服务帐户或组”对话框中输入它，然后点击“检查名称”按钮。

这将手动输入的条目与名称列表进行交叉检查以找到匹配。

- 4. 一旦名称带有下划线出现，点击“确定”返回 APPS 属性页的“安全”选项卡。

# 快速添加用户和组

你可以可以使用一个示例中的任何界面一次性添加多个用户和组。当你手动输入名称时，只需输入第一个名称，点击“检查名称”按钮，然后开始下一个名称。如果你在点击“检查名称”之前没有输入完整名称，它将给你与你输入条目最匹配的项。如果你选择使用 Active Directory 搜索界面，可以通过点击第一个条目按按 Ctrl 键点击其他条目来选择多个帐户。

现在你们需要做的就是分配正确的权限，即“修改”权限。

- 5. 高亮“数据库管理员”组，并在“允许”列中勾选“修改”。安全选项卡现在看起来像图 14.14。

# 权限级别注意事项

在选择权限级别时需要小心。由于有许多权限来自许多不同的地方（在这里甚至不是共享权限！），这个过程很容易变得难以排故障。尽量尽可能地简化你的资源和用户，按数量、按分组进行，这会让生活变得简单得多。

要查看你可以让用户组对 APPS 文件夹拥拥权限，请按照以下步骤操作：

- 1. 选择具有“读取和执行”权限的条目。
- 2. 然后点击“高级安全设置”页面上的“查看”按钮。
- 3. 接下来点击“高级权限”，并注意这里的选项是灰色的。

如果你在“数据库管理员”组上重复相同的步骤，为什么“查看”按钮现在变成了“编辑”按钮？为什么“数据库管理员”的权限不是灰色的？原因是继承被应用于“用户”组而不是“数据库管理员”组。如果你想在这里编辑这些“用户”组，你需要断开继承并重新添加该组。
