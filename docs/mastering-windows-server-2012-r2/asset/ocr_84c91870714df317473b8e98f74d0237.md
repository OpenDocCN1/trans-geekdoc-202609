This is the main configuration window, it is split into three main areas:

**Storage Pools** This area contains a section called Storage Spaces, and under it is listed primordial. By default, all disks assigned to a different pool are assigned to the Primordial pool. As you work with Storage Spaces you will notice the Primordial pool will disappear when all disks have been assigned.

As you can see, there are no other pools assigned or configured yet. In the top-right corner of this area, Tasks is the option to create a new storage pool. We will play with this later on, so don't worry about it.

You can right-click the Primordial pool and examine its properties.

**Virtual Disks** Virtual disks represent the volumes you will create inside a storage pool. Remember, this is not a VHD or VHDX. You cannot create a virtual disk inside the primordial pool; you must create a storage pool.

**Physical Disks** Physical disks are the disks that are available to Storage Spaces to assign. A disk can be assigned to only one pool at a time. If you right-click on a disk in this list, you get the option to toggle (turn off) on drive lights to help find which disk you are working on a physical storage array; this will only work if the storage you are using SCSI Storage Services (SES) compliant. SES also works if a drive is failing and will communicate with Storage Spaces to let the administrator know what is happening.

# Using PowerShell

As mentioned, you can use PowerShell cmdlets to quickly provide Storage Spaces. Administrators prefer to work with a command-line environment when administering servers. Personally, I like to mix them.

Windows 2012 R2 has a PowerShell module called Storage Spaces, which contains all the PowerShell cmdlets you need to work with Storage Spaces.

In Windows 2012 and above, a PowerShell module is automatically imported when you attempt to call a cmdlet that is from that module. To review the cmdlets available to you under the Storage module, open an elevated PowerShell window and **get-command module Storage** in Windows 2012 R2, there are 102 cmdlets available to you. Not all are storage related.
