Typically, the preferred option for the first migration is “Fix users’ group memberships.” This will update the SIDs in the groups of which the users were members. The other options can be used later in re-migrating the account to stripping off the old SID history. “Update user rights” will replace the SIDs with the new one. “Translate roaming profiles” will reassign permissions to the new SID.

Specific properties can be excluded from the migration (see Figure 7.62). Bigfirm doesn’t want the department or company fields of a user account migrated; these can be singled out and excluded from this page.
