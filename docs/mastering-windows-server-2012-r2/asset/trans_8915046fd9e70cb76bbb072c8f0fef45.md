你已准备好开始将“文档”（Documents）重定向到用户的主目录了。

- 4. 右键点击“文档”，并选择“属性”。

这将打开一个对话框，你可以在其中配置文件夹的重定向。你在这里有三个选择：

**未配置 (Not Configured)**：这将禁用文件夹重定向。

**基本 – 将所有人的文件夹重定向到相同位置**：这允许你配置所有用户重定向到公共位置。在公共文件共享中，将文件夹重定向到 `\\bigfirm.com\BigFirmShares\`。这是一个“一刀切”的策略，通常是合适的选择。

**高级 – 为不同的用户组指定位置**：这允许你为不同的组指定唯一的路径。当你的 OU（组织单元）布局与你预期的文件夹重定向设计不匹配时，可以使用此项。

我们将介绍你可能常用的简单方法，即基本重定向。

- 5. 选择“基本”（Basic），如图 26.34 所示。

“目标文件夹位置”根据你正在重定向的文件夹提供若干种选择：

## 第 26 章 高级用户账户管理与用户支持

图 26.34
将文件夹重定向到用户的主目录

![](img/41a83208e6906a3732620203b836cea7_1345_0.png)

**重定向到用户的主目录 (Redirect To The User's Home Directory)**：这个非常简单的解决方案将文件夹重定向到用户的主目录。它不会为重定向的文件夹创建子文件夹，而是直接将内容转到其主目录的根目录下。如果你重定向了许多文件夹，对用户来说将变得不可能。

**在根路径下为每个用户创建一个文件夹 (Create A Folder For Each User Under The Root Path)**：将在你指定的路径内创建一个与重定向文件夹同名的文件夹；例如，如果你指定 `\|Bigfirm.com\BigFirmShares\Home`，则会在 `\|Bigfirm.com\BigFirmShares\Home\Jblogs` 中创建“文档”文件夹。如何智能地添加用户名？这将解决之前提到的困惑。

**重定向到以下位置 (Redirect To The Following Location)**：这是一种简单的重定向，所有用户共享一个公共文件夹。如果为远程桌面服务器集群重定向“开始”菜单，这可能是合适的。

**重定向本地用户配置文件位置 (Redirect The Local User Profile Location)**：这将强制文件夹改回本地配置文件。

- 6. 如图 26.34 所示，选择“将‘文档’重定向到 DFS 命名空间中的子文件夹”。你可以移动文件夹的物理存储位置，而无需更改此策略。你只需要更新 DFS 命名空间中的链接。你可以通过额外的文件夹来实现这一点，并且知道用户将在其主目录内为每个重定向文件夹看到一个独立的文件夹——既简单又减少了服务台的工单！

- 7. 点击“设置”（Settings）选项卡，查看 Windows 将如何处理重定向。

## 图 26.35

默认“文档”文件夹重定向设置

![](img/41a83208e6906a3732620203b836cea7_1346_0.png)

默认情况下，用户将对重定向期间创建的任何文件夹拥有独占权限。请注意，当将“文档”重定向到主目录（而不是子文件夹）时，并不适用。你可以通过取消勾选“授予用户对文档的独占权限”来更改此设置。你可能希望这样做，以便如果你使用管理员账户执行归档或备份/恢复的服务，就可以对“文档”执行管理任务。我们在图 26.36 中做了演示。

## 图 26.36

已配置的“文档”文件夹重定向设置

![](img/41a83208e6906a3732620203b836cea7_1346_1.png)

当重定向策略生效时，你可以移动配置文件中“文档”的所有内容。这是默认开启的，可能也是你想要做的。但是，你有选项关闭此行为。

你可以更改当你正在配置的策略不再适用于用户时发生的情况。默认情况下，重定向的文件夹和内容将留在重定向的地方。在这种情况下，你可以将文件夹和内容重定向回配置文件。

图 26.36 显示禁用对文件夹的访问、移动内容以及启用旧版支持。当策略不再适用时，文件夹也将重定向回配置文件。

你现在可能想测试一下：

- 1. 使用继承了新策略的用户账户登录你的测试工作站。
- 2. 使用 JBlogs 登录 Win8；JBlogs 配置为不使用漫游配置或强制配置。
- 3. 在实验室中，你不想等待策略刷新，因此运行以下命令让你的工作站进行两次刷新：

```
gpupdate /target:user /force
```

在此处使用 `/force` 标志是因为某些 GPO 设置可能需要两次刷新才能生效。
系统将提示你需要注销并重新登录以更改生效。注销并重新登录后，验证重定向是否正常。

- 4. 打开 Windows 资源管理器并导航到你的主目录。验证“文档”文件夹已重定向到正确位置。
- 5. 在重定向的“文档”文件夹中创建一个新文件，验证它是否出现在目标位置。
- 6. 将重定向策略更改为“未配置”，验证文件夹不再重定向。
- 7. 将策略改回“基本”，验证文件夹再次重定向。
