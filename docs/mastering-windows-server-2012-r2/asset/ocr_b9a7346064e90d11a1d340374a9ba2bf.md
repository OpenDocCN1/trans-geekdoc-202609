# MANUALLY CONFIGURING LOCAL AREA CONNECTION SETTINGS IN WINDOWS 7

Close the Network Connection window and click the Properties button on the Local Area Connection Status page to open the Local Area Connection Properties page as shown in Figure 18.11.
