Servers This section lists the servers role is installed on (see Figure 2.50). Inside this there are a few things you can do to get more information. If you right-click the header, as shown in Figure 2.51, you can add more columns of information. We added operating system version so we can quickly see what version each server is running. For one server we have, it may not be important, but if you have a server pool or web farm, this can be handy.

Events This is a very useful tool to help you diagnose problems. Just like event viewers in previous operating systems, it delivers some great troubleshooting information. We have a warning on your DNS role. You get a short, “at a glance” look at the warning or error. If you click on the error, it will give a detailed description of the problem, as shown in Figure 2.52.
