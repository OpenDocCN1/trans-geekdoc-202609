# Placing a Server in a Site

Right now all four of the enterprise's DCs are in HQ. Suppose BF3 belongs to Crosstown. You could tell AD BF3 is physically located in the Crosstown site by moving it there. Navigate to Sites ➤ Servers, right-click BF3, and choose Move to see a dialog box like the one in Figure 22.11.

# Adding Site Links

Site links are used to identify the actual WAN links. Active Directory Sites and Services start a default site link with another highly creative name: BeFa1PS1te1. Just as you can rename the default site and links, you can rename the default site link and create other site links.

Consider Figure 22.12. It shows three sites within an enterprise: HQ, a crosstown town, and a remote office. This site diagram shows the three sites connected with three WAN links and different WAN link speeds. Later in this section, we'll show how to create site links to match these WAN links.
