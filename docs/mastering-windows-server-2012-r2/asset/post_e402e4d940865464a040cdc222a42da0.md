Master It Connect to a server using RDC. Ensure your local drives are accessible connected to the remote server.

Solution Launch RDC by selecting Start > Accessories > Remote Desktop Connection. Alternatively, you can enter mstsc from the command line or Run line. Enter the name of the remote server in the Computer text box. Click Options. Select the Local Resources tab. Click More, and select Drives.

Remotely connect to Windows Server 2012 R2 servers using a Remote Desktop Protocol file. If you regularly connect to a remote server using RDC, you can configure an RDP file that can be preconfigured for your needs for this server. This RDP file will store all the settings for your connection.

Master It Configure a file that you can use to connect with a server named Server1. Configure the file to automatically Launch Manager when connected.

Solution Launch RDC by selecting Start > Accessories > Remote Desktop Connection. Click Options, and select the Programs tab. Select the “Start the Following Program on Connection” check box, and enter ServerManager.msc in the text box. Click the General tab, and enter Server1 in the Computer text box. Click Save As, and save the file.

Configure a server for Remote Assistance. When your environment includes locations where junior administrators may occasionally need assistance, you can use Remote Assistance to access their session and demonstrate procedures.

Master It Configure a server for Remote Assistance.

Solution Launch Manager, select Roles and Features, and add the Remote Assistance feature. Once the wizard is complete, Remote Assistance is enabled. Click Start, right-click Computer, select Properties, and select Remote Settings. Verify that the Remote Assistance check is selected.

Install the Remote Server Administration Tools. The Remote Server Administration Tools (RSAT) include the snap-ins and command-line tools needed to manage Server 2003, 2008, and Server 2012 servers from Windows Vista and Windows 7 and 8.

Master It Obtain and install RSAT on a Windows Vista or Windows 7 system.

Solution Obtain RSAT by going to Microsoft’s download site at www.microsoft.com/downloads and typing in RSAT. Install RSAT by double-clicking the downloaded file and following the wizard. Enable the tools by adding the Remote Server Administration Tools via Control Panel > Programs > Turn Windows Features On or Off.

**Master It** You need to verify that a client machine has received the correct IP address configuration via DHCP for the network you are working on. Which of the following commands would return these results?

- ipconfig /all
- ipconfig /refresh
- msconfig /show
- msconfig

**Solution** The ipconfig /all command returns local area connection information including the following:

- IP address
- DNS IP addresses
- DHCP server suffix

- Domain name suffix

**Join a client computer to a domain.** Joining an Active Directory domain is key for workstations, because this provides centralized management from the Domain Admins group within the domain. Group Policy is centralized, security can be established, and even software can be controlled centrally.

**Master It** Is the following statement true or false? "When joining a computer to an Active Directory domain"

**Solution** It is false. Users can add computers to the domain, but they can only do so up to 10 times. Users can also be delegated the right to add computers to the domain.

**Change user passwords.** By default Windows AD provides a 42-day maximum password age limit. This is limited by a 14-day reminder that you need to change your password. The 42-day maximum is designed to maintain a certain level of security for the enterprise, not allowing passwords to become stale.

**Master It** A user has become paranoid and wants to change his account password right away. He does not know how to do this and calls the help desk. The computer he is using is running Windows 7 operating system. What do you tell him?

**Solution** To open the Start menu, click the Windows Start button, and click "Change a password." He will need to input his old password and his new password and then click the arrow button.

**Connect to network resources.** Here's a typical scenario: a user wants to connect to a printer on the domain that does double-sided printing and stapling. But the user does not know where the company keeps these printers. The user calls the help desk.

**Master It** Which of the following is the most efficient way for the user to find printers matching this description?

- a. Tell the user to walk around the office complex and check each printer to see whether it has features.
- b. Tell the user to use the view command to check for shared printers on a per-computer basis.
- c. Tell the user to start the Add Printer Wizard and then select the Active Directory option.

**Solution c.** The user should search Active Directory using the Add Printer Wizard. Using this wizard, the user can specify specific printer feature criteria and see all the printers that are published to Active Directory that have the feature set the user needs.

Prepare Active Directory for Mac OS clients. Although Mac OS X can join Active Directory, you must take some preparatory steps to ensure they can communicate with Windows Server 2012.

Master it You want your Active Directory users who have Mac clients to connect to your Windows Server 2008 R2 servers using a single Active Directory logon. What network security feature of Windows you must change to permit Mac clients to communicate with Windows Server 2012 domain?

**Solution** You must change the local policy for domain controllers to not always require SMB packet signing.

Connect to the domain. Mac OS X can connect to Active Directory and join domains. SMB protocol support is provided by a built-in version of Samba, letting OS X connect to Windows shares and printers.

Master it You want to add your Mac OS X client to your Active Directory domain. Which OS X utility should you use?

**Solution** Use Directory Access in your Utilities to configure and connect to Active Directory and create a computer account in the domain.

Connect to files shares and printers. OS X connects to Windows files shares and printers using the SMB support provided by Samba. Because support is integrated, you can use the Finder to connect to Windows resources directly rather than adding additional software.

Master It You are trying to access a network folder that is shared on a Windows Server 2012 computer from your domain-joined Mac client. How can you use the Finder to connect?

**Solution** In the Finder, click the Go menu, and select Connect to Server; then type the path using the format smb://servername/sharename.

Plan for and install IIS 8.5. By default, IIS 8.5 must be carefully and painstakingly-planned so as not install more functionality than you need. More than a resource concern, learning unnecessary role services over the server is also a method of securing your websites. Master It You are about to install IIS 8.5 on a Windows Server 2012 R2 with the GUI removed. You want to install the default roles as well as the ASP.NET role and what that requires. What is the PowerShell command needed to accomplish this?

**Solution** The PowerShell command is Install-WindowsFeature -Name Web-Server-Web-Net45.

Manage IIS 8's global default. IIS 8 modules are only one piece of evidence of the product's compartmentalization. Web applications and individual configuration settings per site can be independently managed. A hierarchical ladder of globabl, web, application, and page settings allows granular administration by multiple engineers.

Master It What is feature delegation?

**Solution** Delegation is the art of allowing site administrators to configure IIS features at their own sites rather than accepting the feature behavior dictated by the global settings on the server. Delegation is enabled by using specific sections of the web.config files or on more sites.
