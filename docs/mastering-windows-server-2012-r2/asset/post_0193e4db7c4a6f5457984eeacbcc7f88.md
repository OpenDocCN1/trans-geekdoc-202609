## Using Server Manager to Configure Your Servers

For years, Microsoft has been trying to get people to use a single tool for managing the configuration of servers. In the past, when we logged into the newest version of Windows Server, we were greeted by some tool that promised to do pretty much. We looked at it briefly and saw a little box that said something like "Do not display this at again," selected that, and then the tool would never again see the light of the day. The only time we heard of while studying for some sort of Microsoft certification exam. We just know better...why use that tool when we could get exactly what we wanted from Control Panel's Add/Remove Programs in a much shorter time?

You noticed early on that Windows Server 2012 R2 is quite different from its predecessors. Before 2012 the tool was the Initial Configuration Tasks utility. Now you are greeted by the Server Manager dashboard every time you log in. Trust us, you will want to use Server Manager (Figure 2.21) instead of the old utility.

Now another tool pops up by itself. Welcome to Server Manager. It's in the superbly (or the taskbar) in Windows Server 2012 R2. You will find additional ways to access Server Manager by starting it from Administrative Tools, by running cmdmgr launcher.exe, or by using Programs and Features in Control Panel.

## SERVER MANAGER TIP!

Server Manager has a habit of popping up every time you log in. That will get pretty old in a very short time. You can control this by editing the REG_DWORD value of DoNotOpenServerManagerAtLogon in HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Server Manager. The default is 0, which causes Server Manager to appear every time you log. Setting it to 1 will disable this. Another way to disable Server Manager from appearing at login is to select the Server Manager drop-down menu in the top-right corner of Server Manager. Then select Server Manager Properties. A small pop-up will appear with check box "Do not show this at login."

## USING SERVER MANAGER TO CONFIGURE YOUR SERVERS

Server Manager is the tool that you will use to manage the configuration of servers. Using it, you can add and remove native functionality, manage that, and diagnose problems. You can also use a command-line alternative called PowerShell to manage.

## Changes to Server Manager

There are some differences between Server Manager in Windows 2008 and Windows Server 2012 R2:

- As stated earlier in this chapter Initial Configuration Tasks is no longer the default tool upon login; Server Manager will open all the server properties
- You will notice that the GUI is different from any previous version. With metro boxes and a cleaner look, it may take a bit to get used, but in the long run you will appreciate it.
- With Server Manager you have multiserver remote support. You can easily add servers to the network within this tool. An added feature is group management, which allows you to send commands to all servers within the group.
- The event logs and services can now be accessed from Server Manager for both local and remote servers.
- The Roles Wizard has new screens with a few options before role selection. The first screen is called Installation Type. The second screen is called Server Selection. We will discuss these new screens and how they are used little later in the chapter.
- Server manager cmd.exe has been deprecated. PowerShell is now the command-line tool for use.
- Adding a feature using the GUI is now part of the Roles Wizard and is no longer a separate tool.

This sounds like a lot of differences, Server Manager is more alike than different on Windows 2008 and Windows Server 2012 R2.
