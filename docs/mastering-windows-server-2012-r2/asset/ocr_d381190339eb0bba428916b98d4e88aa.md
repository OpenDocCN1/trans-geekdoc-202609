# WAIT ON THE LICENSE SERVER

When experimenting with Remote Desktop sessions to find out how many users will be able to support for each session, do not set up a license server; let the RDS server issue its temporary 120-day licenses for this purpose. Although this sounds counterintuitive, using the temporary licenses prevents you from unwittingly assigning per-device licenses to test equipment. See the “Licensing Mode” section for an explanation of how licensing and license allocation works.
