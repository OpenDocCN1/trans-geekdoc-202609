# Group Policy Policies

You can find the GPO settings to control Group Policy under Administrative Templates of both the User Configuration and Computer Configuration nodes (Policies\Administrative Templates\System\Group Policy). Computer Configuration node contains most of the policies we will be discussing. Figure 9.11 and Figure 9.12 show the User Configuration and Computer Configuration options for Group Policy.
