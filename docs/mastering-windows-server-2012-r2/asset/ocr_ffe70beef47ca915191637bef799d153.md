Since passwords are unique to user accounts, password options will be seen only in the User Account Migration Wizard. Basically, you can migrate the passwords or have ADMT come up with new ones for yours. The former needs the PES server. The latter needs a location to store the text file containing all these new passwords. As you can imagine, distributing this file to your users should not be done as an email attachment to the All Users distribution group. So, you will have an additional challenge to get the passwords to the users after the migration.
