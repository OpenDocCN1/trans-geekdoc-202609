# CHANGING PASSWORDS AT FIRST LOGON

When the administrator forces a password reset (security reasons or on a new account), the user will be prompted for the new password when they attempt to log on for the first time, as shown in Figure 18.19. The default password applied by the administrator is simply to prevent a user account from being unprotected before it's used.

When the user clicks OK, they'll be prompted for the new password, as shown in Figure 18.20.
