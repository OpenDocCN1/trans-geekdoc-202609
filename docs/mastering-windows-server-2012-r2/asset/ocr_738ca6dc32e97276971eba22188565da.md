As an example, you may want to use the Administrative Events log as a template but add information events and filter it so the last 24 hours are viewable. The following steps will show you how to create this log:

+   1. Launch Event Viewer from the Windows Server 2012 R2 Start screen by typing eventwr and pressing Enter or via Server Manager > Tools > Event Viewer.

+   2. Right-click the Administrative Events custom view, select Custom View.

+   3. Change the name to Today’s Core Log Events.

+   4. Click New Folder. Type My Custom Views in the Name text box and click OK.

+   5. Click OK to create the copy of the Administrative Events custom view in the My Views folder.

+   6. Right-click the Today’s Core Log Events log, and select Properties.

+   7. Click Edit Filter button.

Notice that the properties are the same as the original Administrative Events custom view, but you can edit them.

+   8. Select the drop-down box for Logged, and select Last 24 Hours.

+   9. Select the Event level box for Information.

The check boxes for Critical, Warning, and Error should already be checked.

+   10. Select the Event Logs drop-down box.

The Application and Services Logs item have the check box dimmed indicating that some of the logs are selected.

+   11. Select it to select all the logs. Click it again to deselect it, and all of the logs will be deselected.

Your display will look similar to Figure 30.10. In the figure, we have clicked the plus to show all the active logs, but three of the Windows logs are actually selected.

+   12. Click OK twice to save your custom view.

# CREATING A NEW CUSTOM VIEW

You can create custom views from scratch. This is useful if you're troubleshooting specific issues. You may need to monitor the starting and stopping of services.
You can use the following steps to create a custom view that allows you to quickly view all the events related to a service starting or stopping:

+   1. Launch Event Viewer from the Windows Server 2012 R2 Start screen by typing eventwr and pressing Enter or via Server Manager > Tools > Event Viewer.

+   2. Right-click Custom Views, and select Custom View.

+   3. Select the Critical, Warning, Error, and Information check boxes.

+   4. Select the By Source radio button.
