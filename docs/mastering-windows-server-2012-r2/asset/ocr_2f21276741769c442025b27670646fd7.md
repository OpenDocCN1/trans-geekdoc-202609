# CHAPTER 8 CREATING AND MANAGING USER ACCOUNTS

Profile Path This setting is the location where the user profile is located. A profile is a folder structure that contains the settings that are unique to that user. It also contains things such as My Documents and Favorites folders.

Logon Script This allows you to define a script that will be stored on domain controllers and will be run every time user logs on. You might store this logon script for a local user account.

Home Folder This setting allows you to define a network drive that will be dedicated to this user and mapped as a particular drive letter when they log in.
