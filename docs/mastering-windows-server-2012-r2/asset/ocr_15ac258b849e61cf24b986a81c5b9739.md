The print queue shows a list of all print jobs currently waiting to be printed and the following information:

+   * The filename of the document being printed

+   * The job's status (printing, spooling, paused, or blank if the printer is paused)

+   * Who sent the job to the printer

+   * How many pages are in the job and how many remain to be printed

+   * The file size of the print job

+   * The time and date you submitted the job

When you select a job in the list, you can use the tools in the Document menu to pause a job, restart a print job from the beginning, or cancel a print job. The catch is that you have to do this all while the job is still spooling to the printer. You can control the parts of the job that have already been sent to the printer device.

If you pause a job before it starts printing, you can edit its priority or printing times in the middle of printing. From the Document, choose Properties to open the dialog box shown in Figure 16.41.

From here, you can view many properties inherited from the printer and to the job, and you can raise or lower the job's priority. The higher a job's priority, the higher its place in line, so you can use this feature to manipulate the order in which jobs print even if one job goes to the printer before another did.
