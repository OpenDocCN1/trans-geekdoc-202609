## 原子权限

我们将从原子级开始。这些权限是我们通常所说的权限（如读取、修改和完全控制）的构建模块。你可能永远看不到这些权限，更不用说单独引用它们。

**遍历文件夹/执行文件** 遍历权限允许你跳过上层的所有锁定，本质上直接“以自己的身份”进入第 4 层。和执行权限一样，这是一个非常有用的权限，但它与文件无关。这里发生的情况是，当 NTFS 检查权限时，它会向上到第 3 层。在查看第一项时，它会自问：“这是一个文件还是文件夹？”如果是文件，它会将第一个位被解释为“执行文件”权限。你会在其他某些权限中以不那么极端的方式看到这一点。

**列出文件夹/读取数据** 列出文件夹权限允许你查看文件夹内的文件和文件夹名称。读取权限允许你查看文件的内容。这项原子权限是“读取”的核心组件。

思考这两个原子权限之间的分离。它们之间真的有很大区别吗？有的，但可能不会持续多久。记得以前我们把一切都称为文件和目录的日子了吗。现在文件和文件夹的术语已成为主流。正当我们开始习惯它时，另一个术语又出现了：对象。你机器上的所有内容都是对象——文件和文件夹都是如此。这项原子权限可以重新表述为“读取对象”。无论此权限适用于文件还是文件夹，这项权利都允许你检查对象的内容。

**读取属性** 基本属性是文件的属性性，如只读、隐藏、系统和存档。原子级权限允许你查看这些属性。

**读取扩展属性** 某些程序为其文件类型包含其他属性。例如，如果你在系统中安装了 Microsoft Word 并查看 DOC 文件的属性，将显示各种属性，如作者、主题、标题等。这些被称为扩展属性，并且随程序而异。此原子权限允许你查看这些属性。

**创建文件/写入数据** 创建文件权限允许你向文件夹中放入新文件。写入允许你覆盖文件内的现有数据。此原子权限不允许你向现有文件添加数据。

**创建文件夹/追加数据** 创建文件夹允许你在文件夹内创建文件夹。追加允许你向现有文件的末尾添加数据，但不能更改文件内部的数据。

**写入属性** 此权限允许你更改文件的基本属性。

**写入扩展属性** 此权限允许你更改文件的扩展属性。

**删除子文件夹和文件** 这项原子权限很奇怪。使用此项进行删除：即使你对子文件夹或文件没有“删除”权限。这怎么可能吗？如果你提前读取到子文件夹，你就可以删除它。但你需要父文件夹的权限。这是 NTFS 内部一个常见的困惑点。

**读取权限** 此权限允许你查看分配给文件或文件夹的权限。

**更改所有者** 此权限允许你更改文件或文件夹的所有者。

**取所有权** 此权限允许你获取文件或文件夹的所有权，即使你没有访问它的权限。
