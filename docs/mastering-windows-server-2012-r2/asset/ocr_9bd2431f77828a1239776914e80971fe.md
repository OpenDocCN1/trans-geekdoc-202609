By default, the configuration uses the Local Area Connection. You can use the PowerShell
New-IPAddress cmdlet to change it. It is changed with the following properties:

```
New-IPAddress [-IPaddress <String>] [-InterfaceAlias <String>] [-AddressFamily
<AddressFamily>] [-AsJob] [-CimSession <CimSession> ] [-DefaultGateway
<String>] [-PolicyStore <String>] [-PreferredLifetime <TimeSpan>]
[-PrefixLength <Byte>] [-SkipAddress <Boolean> ] [-ThrottleLimit <Int32>]
[-Type <Type>] [-ValidLifetime <TimeSpan> ] [-Confirm] [-WhatIf] [
<CommonParameters>]
```
