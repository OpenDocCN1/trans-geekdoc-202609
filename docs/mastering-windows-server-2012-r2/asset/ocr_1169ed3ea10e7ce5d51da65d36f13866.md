# INSTALLING ADMT AND PES

ADMT is available as a download from Microsoft. Installing the utility is straightforward for a C&P installation since you will not be importing databases from previous versions. It asks whether the database will be on SQL Express or a standard installation of SQL. In most cases, SQL Express will be the preferred option.

# Creating a Password Key on the Target

Now, you want your users' passwords to move over with their accounts and ADMT can do with the help of the Password Encryption Service (PES). Before it will migrate passwords, ADMT requires you to create a password encryption key for ADMT01 and then copy that over to DC2003, and DC2003 will use to be able to send passwords over the wire—encrypted.

To do this, you run ADMT from the command line. The following is an example of the command syntax:

```
admt key /option:create /sourcedomain:otherdomain
/keyfile:c:\temp\password.pes /keypassword:Password
```

This says to prepare a key for OtherDomain.local use to transfer passwords to Bigform (Bigform is not explicitly mentioned because you're working on a Bigform DC) The C:\temp\password.pes file just where to put the file. If your server has a floppy drive, then A:\ works fine. It doesn't matter where you put it—just understand that you'll have to somewhere transport that file to the OtherDomain.local, DC2003. When it runs properly, ADMT will return a message looking something like this:

The password server encryption key for domain 'otherdomain' was
successfully created and saved to 'c:\temp\password.pes'

You're finished on ADMT01.Bigform.com for the moment. It's time to move to the DC2003.

# Moving Over the PES File

Once you're logged in at DC2003, you need to get that PES file from ADMT01.bigform.com to a
local drive; we usually just create a share and copy it across the network. You can alternatively
put it on a floppy, a CD-ROM, or whatever you want—but it has to get over to DC2003 one way
or another.
