
## CHAPTER 2 INSTALLING AND UPGRADING WINDOWS SERVER 2012 R2

Windows Server 2012 R2 comes on a DVD. It's a pretty installation. Ensure your server has a DVD-ROM drive, and then insert the DVD media. Alternatively, if you are using a virtual machine, you can recreate the virtual CD/DVD to the Windows Server DVD image that you have downloaded from Microsoft or created from your original media.

## What, NO DVD DRIVE?

You may have a server that doesn't have a DVD drive. If so, you could look at one of the advanced network installation methods mentioned earlier. But you can also install Windows Server 2012 R2 from a USB drive. You can find a set of instructions on this blog post by a Microsoft employee: http://tinyurl.com/ktz5fq

Once the media is loaded, you should power up your server and ensure that your server boots from the DVD drive. Normally, a computer with a blank disk will boot from the DVD drive by default. If the computer fails to boot from the DVD, then there may be one of a few things going on. There may be a valid operating system on the hard disk that is booting by default. If you have a boot menu available during or the Power-On Self Test (POST), Alternatively, your server might not get the option to boot from DVD because of a boot configuration. You can alter this by entering the BIOS and making a change. These two options will vary depending on your hardware, you should consult your hardware vendor's contact or their support desk. In most cases it will show something like "Boot Order." We have also seen situations where you have burned the DVD from an ISO file but used a write-speed that was too slow to ensure a good burn

In the following examples, we will explain how to install Windows Server 2012 R2.

Figure 2.1 is the first screen you will see. It allows you to customize the installation language, time and currency format, and the keyboard settings of the server. You will need to change settings if the defaults do not match your language, region, and keyboard. For example, if you are in Ireland using Irish-based keyboard, these defaults won't suit you at all! The time won't work correctly, currency symbols will be wrong, and the keyboard layout will be totally wrong. For example, you will struggle to find the backslash (\), which is kind of important in the Windows.

The Language will vary depending on the languages supported by your DVD. Most people reading this book will be happy with English-based media, even in non-English speaking nations. But you may be choosing Spanish, French, German, Chinese, and so, on, depending on where you are and what your company standards are.

The "Time and currency format" setting affects how Windows presents and formats those regional-specific settings. You'll probably always want to ensure that this matches the location where your server is located.

The "Keyboard or input method" setting should match the keyboard that is physically attached to the computer. Keyboards often vary by country, so make sure this is correct. It won't affect your ability to manage a server using Remote Desktop. RDP session will use the keyboard settings of the client computer that connects to the server.

The screen in Figure 2.2 allows you to do a different things:

- You can kick off an installation.
- You can troubleshoot and repair an existing installation of Windows Server 2012 R2.

On this screen, you can delete, create, and format volumes as you need. You'll find yourself coming here when you don't want to accept the default of using the entirety of your first disk (Disk 0) for the C drive. If you choose to add a new partition, simply click New and then select the size of the partition you need and Select. But what if your installer fails to find any disks? Found nothing wrong The cables are fine, and your BIOS can see all of your disks. Well, odds are the installer doesn't have the required driver to access your storage drive. As time goes by, this will become more and more common as newer storage controllers are released into the market. You can add a driver by clicking Load Driver. It used to be that the storage controller had to be present on a floppy drive. That would be a problem considering that the servers usually don't come with a floppy drive anymore and Microsoft really wants to kill off the use disks.
