# How Offline Files Works

Offline Files is enabled on shares hosted on a server. When enabled, it automatically caches accessed files, storing the cached copies in a folder on a local hard drive (a not surprisingly called Offline). It uses those cached copies to speed up network access (or apparent network access), because subsequent accessing of a file can be handled by the local hard disk’s cache rather than over the network.

This is great for users on the road. Offline Files can use the cached copies of files to act as a stand-in for the network if its not present (as for mobile users) or even if the network has failed.

Offline Files uses a write-through caching mechanism; when you write a file out, it goes to the network to save it, and it is also cached to your local hard drive. When you want to access a file, but only first, Offline Files checks if the file hasn’t changed at the server by examining the file date, time, and size both on server and in the cache. If they’re the same, then Offline Files gives you the file out the cache without any worries; Offline Files fetches the copy so you have the most-to-date copy.

Offline Files increases the chances that it has the most-to-date copies of your files by doing background synchronization in several user-definable ways. This synchronization is largely invisible to the user, who simply utilizes the share over the network.

You’ll use Offline Files for several reasons:

**Always Mode** This new configurable feature in Windows 8 and Windows Server 2012 provides an improved user experience with faster access to files and lower bandwidth usage by working offline. Unlike previous editions that switched from online to offline depending on network connectivity, Always Mode stays offline even when connected synchronizing with the Offline Files cache. This new feature helps drive better performance. Always Mode requires the domain to be joined and have Group Policy Management to be configured for use.

**Faster Access** Because these used-cached files will reside on the local disk in the Offline Files folder, you’ll immediately see what seems to be an increase in network response speed. Opening a file that appears to be on the network but is really in a local disk folder will yield apparent improvements in response time, because little or no activity is required.

**Reduced Traffic** Since cached files don’t need to be retransmitted over the LAN, network traffic is reduced. Having frequently used files in a cache also solves the problem of “What do I do when the network’s down and I need a file from a server?” If you try to access a file on a server that’s not responding (or you’re not physically connected to the network), Offline Files shifts to “offline” mode. When in offline mode, Offline Files looks in your local Offline Files network cache and, if it finds a copy of file in the cache, it delivers the file to you just as if the server were, running, and attached to the user’s workstation.
