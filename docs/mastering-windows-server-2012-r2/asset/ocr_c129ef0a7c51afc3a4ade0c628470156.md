# Unlocking a User Account

You can also use PowerShell to do the mundane work. If you want to unlock a user account, you can run the following:

```
PS:\Users\Administrator> Unlock-ADAccount -identity SRed
```

-The identity flag takes the name of the user to unlock. In this example we've used the friendly user name. You might want to use the DN to identify the user object:

```
PS:\Users\Administrator> Unlock-ADAccount -identity "CN=Steve Red,OU=Users,OU=Bigfirm,DC=com"
```

You can reset a user's password using this command:

```
PS:\Users\Administrator> Set-ADAccountPassword -identity SRed -reset-newpassword (read-host "Please Enter The New Password" -AsSecureString)
```

Please Enter The New Name: ********

Set-ADAccount cmdlet uses the -identity flag to specify a user object that requires knowing the old password. The -reset flag tells PowerShell that you're not doing a normal password change. Instead, you want to change a password for a user object because the user has forgotten their password. You're again using the Read-Host cmdlet to read a password and convert it to a secure string for the -newpassword flag.

By default it retrieves only a small set of the available attributes. If you want to see everything that's available in a user object, run the Get-ADUser command and ask for all properties using a * wildcard:

```
PS:\Users\Administrator> Get-ADUser SRed -properties * | more
```
