Use Remote Desktop from a Mac client. Microsoft created the Remote Desktop Connection for Mac to provide Remote Desktop connectivity for Mac clients. Using RDC, you can access the functionality of your Windows computer directly from your Mac clients.

Master It You are using RDC to connect to your Windows Server 2012 server computer and want to save your network credentials so you don't have to enter them every time you connect. How can you do this?

Solution Enter your Active Directory credentials in Preferences under the RDC menu, and select the option to save the credentials in your Keychain.

# Chapter 19: Web Server Management with IIS

Plan for and install IIS 8.5. By default, IIS 8.5 must be carefully and painstakingly-planned so as not to install more functionality than you need. More than a resource concern, learning unnecessary role services over the server is also a method of securing your websites. As always with Microsoft, there are many ways to install IIS 8.5, from an intuitive GUI to PowerShell.

Master It You are about to install IIS 8.5 on a Windows Server 2012 R2 with the GUI removed. You want to install the default roles as well as the ASP.NET role and what that requires. What is the PowerShell command needed to accomplish this?

Solution The PowerShell command is Install-WindowsFeature -Name Web-Server-Web-Net45.

Manage IIS 8's global default. IIS 8 modules are only one piece of evidence of the product's compartmentalization. Web applications and individual configuration settings per site can be independently managed as well. A hierarchical ladder of globabl, web, application, and page settings allows granular administration by multiple engineers.

Master It What is feature delegation?

Solution Delegation is the art of allowing site administrators to configure IIS features at their own sites rather than accepting the feature behavior dictated by the global settings on the server. Delegation is enabled by using specific sections of the web.config files or on more sites.
