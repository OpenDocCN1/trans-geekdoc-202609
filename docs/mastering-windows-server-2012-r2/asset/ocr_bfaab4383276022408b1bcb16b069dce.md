# Configuring WSUS for Deployments

Once the installation of the WSUS server role is complete, you can launch Windows Server Update Services (shown in Figure 31.9) from the Start screen and begin your configuration.

FIGURE 31.9
Windows Server Update Services on your Start screen

![](bbox=[0.326, 0.176, 0.729, 0.532])

To begin the configuration of your WSUS you need to configure the updates required for your environment. Once the Update Services console has opened, you will be presented with the Windows Server Update Services Configuration Wizard; this wizard will walk you through the steps to get updates configured for deployment. As the wizard starts, the first screen you see is Before Begin; this has a couple of items you need to make sure of before starting this process:

+   - Is this computer firewall configured to allow clients to the server?
- Can this computer connect to the upstream server (such as Microsoft Update)?
- Do you have user credentials for the proxy server, if needed?

After you have validated that you have the appropriate items set up, follow these steps:

+   1. Begin the initial configuration of Windows Update Services by clicking Next.
2. Once you've decided whether to join the program, click Next to continue.

You will be prompted to join the Microsoft Update Improvement Program—you can leave the check box to Yes if you so desire.

You'll need to choose your upstream server, and you will utilize Microsoft Update if this is your first server. Any additional servers you add later can point to this server to synchronize. For this example we will be utilizing Microsoft Update as our synchronization partner.
