And although it be a comforting thought to believe that any time you need to manage IIS 8 or IIS 8.5, the server will be readily accessible and you can perform all of your maintenance from there, the reality is most administrators prefer the convenience of remote management over the reliability of local administration on the server. The Web Management Service (WMSC) in IIS allows a remote connection into Windows Server 2012 or Windows 8 installation of IIS using the IIS Manager console. Of course, the traditional remote administration and VPN approaches of connecting to the operating system are still a possibility, but why not introduce the extra bandwidth if you don't have?

But if your heart is on full OS access while managing your IIS installation, Microsoft offers a robust Remote Management (WinRM) for Windows Server 2012 OS which also commonly allowed firewall port calls. WinRM became available on Windows Server 2003 R2 but had to be added to the OS in Control Panel. Starting in Windows Server 2012, Windows Remote Management is installed, enabled, and ready to be used.

# Using Web Management Services

Before you can sit at your desk in your comfy leather chair and launch an IIS Manager console that will connect to your IIS server down the hall, you must do the basic tasks you need to perform to set up remote management services are the following:

+   1. Enable WMSVC.
2. Enable remote connectivity.
3. Configure optional settings.
4. Start WMSVC.
