# MANAGING GROUPS

It's time for you to see how you can add members to a group using the command prompt. You'll be using net localgroup again:

```
net localgroup Fileshare SRed /add
```

That's a pretty simple command to add a user to a group. The syntax is pretty simple as well:

```
net localgroup Fileshare <name of object to add to the group> /add
```

The following quickly adds the Domain Users from the BigFirm to your local group:

```
net localgroup "bigfirm\domain users" /add
```
