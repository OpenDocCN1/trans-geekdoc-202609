15. Click Apply and OK to return to the Drive Maps section.

You should see the E drive mapping appearing in the right pane.
Now that the GPO created and a policy for drive mappings defined, you need to link it to bigfirm.com so you can start to use this policy, as shown in Figure 18.27. Having this Group Policy object linked to bigfirm.com allows Marketing users, no matter what OU they are in, to have the policy applied to them.
