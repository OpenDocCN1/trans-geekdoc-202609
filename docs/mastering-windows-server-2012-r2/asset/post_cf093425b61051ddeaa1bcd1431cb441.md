## Shared Storage and Clustering / Introduction

Shared storage and clustering in Windows Server 2012 R2 deliver arguably the most significant functionality that any large enterprise or datacenter infrastructure design requires. Ensuring that resources such as applications, services, files, and folders are delivered in a highly available, centralized, and scalable offering should be paramount to every IT administrator and consultant. Utilizing shared storage and clustering gives organizations the ability to scale out on demand, create centralized locations for resources, and make them highly available (HA) to the business.

The concepts of shared storage and clustering aren't new. In this chapter, you will learn to:
- Use shared storage
- Use clustering
- Build a highly available environment

## Shared Storage Basics

In its most basic form, shared storage is a network-connected entity that allows servers to access disks. Many examples of this include:
- Network Attached Storage (NAS)
- Storage Area Network (SAN)
- Serial Attached SCSI (SAS)

The main goal of shared storage is to provide a centralized location for data that can be accessed by multiple servers. This improves data protection and availability because if one server fails, the data remains accessible to another server.

## Storage Area Network

A storage area network is a dedicated network for access to storage. What we are really talking about is block-level storage that is available over the network. SAN is typically a large device with numerous hard drives, and it presents them to servers over the network.

In addition, a SAN doesn't have to be a traditional network; it could be Fiber Channel, for example. With Fiber Channel, the same principle applies; it is a network with fiber optics. In most organizations, the storage network has a switch dedicated to SAN. The data transfer to a SAN is typically known as the storage fabric. Part of the storage is the host bus adapter (HBA). HBAs are the network interface cards (NICs) that connect the storage fabric to the resources.

## iSCSI

Internet Small Computer System Interface (iSCSI) has been around for many years and has been used as a way to allow computers or servers to communicate with disk drives or other storage devices. As iSCSI has adapted, the network infrastructure connecting your servers and computers Gigabit-based networks are much more commonplace and allow you to run storage connections natively through these higher-bandwidth connections. iSCSI is used to facilitate the transfer of data over a TCP/IP (Ethernet) network. The iSCSI protocol lets you present the disk drives located in your SAN over an existing network to your servers.
