So, we’ll be discussing what NFS is and what Server 2012 can provide.

Network File System provides a file-sharing solution for organizations that have a mixed Windows and Unix/Linux environment. NFS gives you the ability to share files across these different platforms when you are running Server 2012. NFS Services include the features and improvements in Server 2012:

**Active Directory Lookup** You have the ability to use Windows Active Directory to access user identifier (UID) and group identifier (GID) fields. The Identity Management for Unix Active Directory schema extension enables NFS for NFS and Client for NFS to look up Windows-to-Unix user account mappings directly from Active Directory Domains. Identity Management for Unix simplifies Windows-to-Unix user account mapping in Active Directory Domains.

**Enhanced Server Performance** Services for NFS include a file filter driver, which significantly reduces common server file latencies.

**Unix Special Device Support** Services for NFS support Unix special devices (mknd). **Enhanced Unix Support** Services for NFS support the following versions of Unix: Sun Microsystems Solaris version 9, Red Hat Linux version 9, IBM AI version 5.2, and Hewlett Packard HP-UX version 11. However, newer versions will undoubtedly be supported in the future.
