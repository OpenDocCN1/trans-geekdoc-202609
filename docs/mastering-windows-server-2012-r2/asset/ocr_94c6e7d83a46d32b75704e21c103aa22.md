Thanks to the abstraction provided by DFS namespace, can easily move the Home folder to another server. All it requires is a quick change of the mapping for the folder within the namespace. No user objects or scripts would be needed to reflect the change.
Administrators have used both these approaches in the past and kept user disruption to a minimum. Administrators using the traditional file shares without DFS will find that there is some effort required to introduce DFS. However, the gains are worth the effort once the migrations are complete.
