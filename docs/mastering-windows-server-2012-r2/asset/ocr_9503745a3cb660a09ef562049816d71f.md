# WEBSITE PROVISIONING

Once you're connected to a web server, you will notice that not much has changed in the navigation since IIS 7. The Connections pane on the left is easily navigated vertically to expose the application pools and sites of various IIS servers the management console is currently connected to. This pane remains visible when using the console. The path across the top of the console has the familiar Forward, Back, Refresh, and Help buttons.

Once you highlight a connected server in the Connections pane, the start page disappears and is replaced with the server's Home page in Features and grouped by area as the default. An Actions pane will also appear on the right, and the tasks hyperlinked in this pane will change relative to the Connections pane based on(see Figure 19.8 for an example of the console pane's layout).

# Constructing Bigform's Websites

For illustrative purposes, assume that the new Apples Rule! pages will be part of the bigform.com domain and will serve static .htm content across all server network interfaces through TCP port 80. Also assume that the image and content for these new pages are already stored in an Apples directory you created under the default IIS 8 content directory of %systemdrive%\inetpub.

To create the new Apples Rule! pages using IIS Manager, do the following:

+   1. Expand Server, and then expand the Sites node in the Connections pane.

+   2. Click Default Web Site, click view Virtual Directories in the Actions pane, and then click Add Virtual Directory in the Actions pane. The Add Virtual Directory dialog box opens, as shown in Figure 19.9.
