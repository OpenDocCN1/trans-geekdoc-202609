# MAC ADDRESS EXAMPLES

Note that the examples we have chosen are example addresses. The Media Access Control (MAC) address is a globally unique identifier, expressed as a long string of hexadecimal digits, usually separated into parts by dashes. These are generally assigned in pools to vendors by the Institute of Electrical and Electronics Engineers (IEEE).

# IPv4: Address Resolution Protocol

This is where the Address Resolution Protocol (ARP) comes in to see the picture. ARP is an Ethernet broadcast. Technically, all Ethernet packets are broadcast across the subnet, but most of them carry a destination address and are discarded by other Ethernet cards when they are received. An Ethernet broadcast packet is meant to be picked up by any Ethernet.

The ARP packet contains the source MAC address of the requester and the IP address it is searching for. Every Ethernet card on this segment will receive this request and has to forward it to its IP. The layer will check whether it owns the IP address being requested. The interface that owns this IP address will respond affirmatively to the owner of the requested address.

The requester receives this response and associates the ARP table address with the Ethernet address. You can view this ARP table in any Windows using a number of different methods. The easiest to remember is probably the command -a, which shows the addresses that have been assigned to network cards, as you can see in Figure 20.2.

As with most network facilities, you can also see this table using a netstat command, netstat interface ipv4, as shown in Figure 20.3.

In this example, the IP computer at A will create a packet that sends "I192.168.0.1, and I want to know the MAC address for the interface with IP 192.168.0.3." Computer A will then "shout", segment, most will stop what they're doing, check their IP address to see whether they are 192.168.0.3, and only one (C) will send a response back to A, saying, "I am an ARP response packet from the machine at IP 192.168.0.3, and my MAC address is 00:01:CA:FE:D5:03."
