| 计算机配置 \ 管理模板\ 系统\ 用户配置文件 | 留存 Windows 安装程序和组策略软件安装数据 | 可以通过组策略为用户安装应用程序。这存储了用户的配置文件。删除要删除的配置数据会导致应用程序重新安装。这可以防止重复安装。 |
| 计算机配置 \ 管理模板\ 系统\ 用户配置文件 | 卸载和更新配置的最大重试次数 | 这允许管理员指定 Windows 尝试将 NUSER.dat 保存到文件共享的次数。如果应用程序在注销时更新缓慢，你可能需要增加此次数。默认情况下，漫游 Windows 在几秒内最多尝试 60 次。 |
| 计算机配置 \ 管理模板\ 系统\ 用户配置文件 | 防止配置文件传播到服务器 | 用户在此机器上对文件的任何更改都不会保存到其漫游配置文件中。 |
| 计算机配置 \ 管理模板\ 系统\ 用户配置文件 | 如果用户具有漫游配置文件或远程主目录，设置网络等待时间 | 如果带有这些共享的文件服务器不可，Windows 将等待最多 30 秒。你可以覆盖该设置。当你在无线网络上发现漫游配置文件未下载且主目录未连接，且唯一问题是时机问题时，可以使用此设置。 |
| 计算机配置 \ 管理模板\ 系统\ 用户配置文件 | 为对话框建立超时时间 | 当 Windows 需要人工交互来做出决定时，会弹出对话框。默认为 30 秒。你可以在 0 到 60 秒之间更改此设置。 |

这些都是针对机器的设置；也就是说，它们将影响所有登录到应用了策略机器的用户。你也可以将策略应用于用户对象以控制漫游配置文件。

要小心“限制配置文件大小”策略。请记住，“我的文档”和“桌面”等文件夹包含在其中。你需要尽快想办法将它们移动到另一个位置。

# 重定向文件夹

漫游配置文件在 Windows 世界中已经是很常见的做法。它们有效，但远非完美。
漫游配置文件容易在文件加载、卸载和损坏方面出现问题。情况可能会变得非常复杂。这就引出了文件夹重定向。
文件夹重定向允许你将用户配置文件中的特殊文件夹移动到更合适的位置。例如，与其将这些文件夹存储在漫游配置文件中，你可以将其存储在用户的主目录中。文件夹重定向允许你处理以下文件夹：

- AppData (漫游)
- 桌面
- 开始菜单
- 文档
- 图片
- 音乐
- 视频
- 收藏
- 联系人
- 下载
- 链接
- 搜索
- 保存的游戏

# 文件夹重定向的起源

文件夹重定向作为 IntelliMirror 的一部分引入 Windows 2000 的。IntelliMirror 的概念是为用户提供一个移动的工作环境，用户移动到哪里环境就跟随哪里。遗憾的是，这个品牌多年来似乎被遗忘了。

当你看那个列表时，似乎包含了配置文件中所有的重要内容。如果你可以将这些文件夹存储在某个特殊文件夹中，你还需要漫游配置文件吗？
这是一个非常好的问题。事实上，许多组织并不费力部署漫游配置文件。你已经看到，除了主目录之外部署漫游配置文件会将你必须执行的管理工作增加倍。通过将它们存储在用户的主目录中，你可以减少网络上文件共享的管理。这简化了部署、备份/恢复、审核、归档以及灾难恢复规划/实施。漫游配置文件有很多复杂性，例如在具有不同软件配置的机器以及不同操作系统的机器之间移动。
那么，文件夹重定向到底做了什么？简单来说，就是配置这些特殊文件夹指向配置文件之外的备用位置。该位置是用户唯一的的文件——你可能已经为每个用户创建了目录，你可以配置文件夹重定向映射到那里而不是配置文件。例如，“我的文档”通常在配置文件中以“文档”的形式存在。使用文件夹重定向，它可以以“文档”的形式存在于主目录。这实现了几点：

- 你可以将所有必需文件夹重定向到主目录，以便用户可以在当前和旧操作系统上拥有一致的工作环境；也就是说数据存在于版本限制之外。

# 第 26 章 高级用户账户管理与用户支持

- 通过重定向包含用户数据的文件夹，你可以可靠地应用配置文件大小配额，而不影响包含在“我的文档”等文件夹中的业务数据。

- 通过重定向所有对组织重要的文件夹，你可能完全消除对配置的需求。漫游配置文件可能是问题的源，，被系统管理员认为是过时的技术。

在此之前，我们应该快速解决此时可能会提出的问题。如果像“我的文档”的内容被重定向到文件服务器，而你是一个带笔记本电脑的旅行用户该怎么办？默认情况下，重定向的文件夹通过离线文件复制到本地计算机。连接到网络时，计算机会将离线文件缓存与文件服务器上的共享同步。
