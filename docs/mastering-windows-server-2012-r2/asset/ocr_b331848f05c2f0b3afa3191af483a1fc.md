# Real World Scenario

# TA CARE WHEN IMPLEMENTING SCREEN SAVER SECURITY

Be careful when forcing policies like screen saver configuration. Best practice in terms of security is that the screen saver should be active for everyone and require a password to unlock it. A common experience is that the people who require this security are the ones who will hit it most. Directors and sales staff hate having screen savers with password locking. You should find the balance between IT security and sustained employment—it’s good to get guidance on something like this from your employer after presenting a considered briefing on best-practice security before going-gunho and applying policies by yourself.
