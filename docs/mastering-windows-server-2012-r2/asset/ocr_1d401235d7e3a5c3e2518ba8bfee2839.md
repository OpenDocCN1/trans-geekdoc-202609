We won't repeat ourselves when it comes to these settings in this section. We are assuming you've read the descriptions in the previous section on local user accounts.
Let's start by looking at the General tab.

# GENERAL TAB

You can see, again in Figure 8.17, some descriptive information for your user. You'll see the usual first name and last name. You also have the ability to see some other information about the user in the account object in Active Directory as their office, telephone number, email address, and web page. You'll find that you can use of any defined email address or web page settings for this user by right-clicking the account object in Active Directory Users and Computers. This allows you to use the user's defined web page or send mail to their defined email address.

# ADDRESS TAB

The Address tab is shown in Figure 8.18. This allows you to define a postal address for the user in question. Why would want to do this? Active Directory can be used as a directory for users; in other words, it can be used by users to find out about other users on the network, or it can be used by applications to store, retrieve, and share information about users.
