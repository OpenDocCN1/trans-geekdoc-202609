# CHAPTER 5 IP ADDRESS MANAGEMENT AND DHCP FAILOVER

The Utilization Trend and Event Catalog tabs will start to populate with information once the IP address block starts handling data.

The process of creating a IPv4 address block is similar to the private process, but there are some additional steps to:

+   1. Open the IPAM console with an administrative account, and from the navigation bar, click through to IP Space > IP Address Blocks.

+   2. From the lower pane in the navigation bar, right-click IPv4 and then choose Add IP Address Block from the context menu, as shown in Figure 5.16.

+   3. In the Add or Edit IPv4 Address Block dialog box, type a public IPv4 and subnet prefix length of your choice into the Network ID and Prefix length fields, respectively—we choose Sychen.com network ID of 208.215.179.132 and a prefix length of 30.

+   4. Now, since this is a public IP address block, choose the Regional Internet Registry (RIR) that issued the IP address blocks (we picked RIPE here) and, if applicable, or possible, complete the Received Date from RIR value, although this is not required.

+   5. To see the newly created address block, choose the IP Address Blocks view from the Current view drop-down menu, and in the lower navigation pane, click Public Address Space under IPv4.

+   6. Verify that your new public IP address block is available and that you can see information in the Configuration Details tab, as shown in Figure 5.17.
