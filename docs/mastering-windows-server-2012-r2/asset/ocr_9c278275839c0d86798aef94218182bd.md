# Pooling with PowerShell

We mentioned everything that you can do in the GUI you can do via PowerShell. We will show you how to create a storage pool using PowerShell:

+   1. First, you need to find which disks are available. Use the Get-PhysicalDisk cmdlet to retrieve a list of all disks in the system. Figure 12.20 shows the results for our example.

+   2. Look at the CanPool property. When its value is True, this disk can be used in a storage pool.

+   3. Filter on physical disks that can be pooled, and store the results in a variable for later use using the following syntax:

```
$drivestool = Get-physicaldisk | where {$_.CanPool -eq $True}
```

+   4. Next, identify the storage subsystem you are running, and store it in a variable, but in this case you are only interested in the FriendlyName of the property, as shown in Figure 12.21.
