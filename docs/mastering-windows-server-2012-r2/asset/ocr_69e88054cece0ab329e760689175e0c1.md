3. On the Sync Share screen, you can rename the share and provide a description. The description is optional, but six months or a year down the road it can be very helpful when you are trying to figure out what each sync folder was being used for.

4. The next screen, Sync Access is where you will be granting access to the share. You can do this by user or security group. Click Add and select IT Administrators. By default, administrators will not have access to the users' data on the server; you should want to give access to this data, check the "Disabled permissions" check box.

The Device Policy screen is where you can enforce policies on the device that the data will be synced to.

+   5. Select both checks and move to the next step.

+   6. Review your settings and create the share.

The Work Folders screen will now show your newly created share, the users who have access, the value information, and any quotas that have been defined for the users, as shown in Figure 26.44. The server has been configured and is ready for users to start syncing their files. Alternatively, you could have configured Work Folders via PowerShell Administrators

```
PS C:\>New-SyncShare ITSyncShare -path D:\ITSyncShare -User "BigFirm,IT Administrators"-RequireEncryption true -RequireAutoLock true
```
