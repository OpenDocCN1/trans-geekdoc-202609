Delegation This allowing another name server to control a subdomain of a namespace. For example, the Bigfirm.com name servers can delegate control of the Ecoast Bigfirm.com namespace to another server.

Forwarding This is an alternative to the recursion process. Forwarding is a lateral request to another name server within the network. The forwarding server obtains a response and relays it to the originating name server.

Iteration This is a client-directed request to resolve an FDN. If the client receives a negative request from a name server, it will query another name server.

NetBIOS Naming System This legacy naming system was used primarily within Microsoft NT 4.0 networks. Its processes are part of modern-day Windows operating systems, particularly when using non-domain (workgroup)-computers.

Service Service records (SRV) are records that map a service to a hostname. This is an essential part of DNS supporting Active Directory.

Dynamic Update Dynamic DNS (DDNS) is a process that allows DNS clients to register their hosts in an assigned namespace such as DHCP. This reduces the need of admins to manually enter records in the name server databases. This is another essential part of DNS supporting Active Directory.

# Installing DNS

DNS for Windows Server 2012 R2 can be deployed into several configurations depending on your scenario. You can choose to install a stand-alone DNS server onto a nondomain-joined computer, or deploy it onto either your domain-joined member servers or Active Directory domain controllers servers. Whatever the scenario, the Installing DNS role is simple. This section will first explain what you need to do to manually deploy DNS onto a nondomain-joined computer in a stand-alone configuration. Later, we will explain how to automatically configure DNS to integrate with Active Directory as to ensure name resolution smoothly within your environment.

# Configuring a Stand-Alone DNS Server

First things you will need to allocate a static IP address to the server that you want to install the DNS role onto, since making a moving target is tough for clients! From the desktop, if you press Ctrl+R and type ncpa.cpl and hit Enter, you will be brought to the Network Connections window. Here, you can click-right your adapter and then Properties to open the configuration. If you double-click Internet Protocol Version 4 (TCP/IPv4), you will be presented with the TCP/IPv4 dialog box. Once there, you then assign a static IP address, as shown in Figure 6.3.

When you have assigned a static IP address, you should also add the primary suffix, such as Bigfirm.com, in the Advanced TCP/IPv4 Settings box, as shown in Figure 6.4.

We use the word here because it isn't always necessary to add a primary DNS suffix. The primary suffix is modified automatically when the computer joins a domain. If the server is going to operate as part of a workgroup (as is the case in our example here), you will need to add it so that other DNS servers can locate it in the DNS structure and the DNS service is properly configured during installation.
