
The Managed By tab allows you to elect a user or a group that will be the owner of this group. This group can be assigned rights to resources. We’ve saved the best bit for last. The selected owner can give rights to manage the membership of the group by selecting the “Manager can update membership list” box. Super! You don’t have to give the manager rights to manage the security rights of a shared folder. Can imagine the disasters that could arise from that? All you need to do is give them a mechanism for editing the group membership that has the right to use the shared folder. This can be the Active Directory Users and Computers snap-in, a script, or may be a web app.

## CREATING A GROUP AT THE COMMAND LINE

It’s important to learn how to manage groups from the command line. You’ll first look out how to create a group using dsadd group. You can get more help by typing the following:

```
dsadd group /?
```

The following is a simple command that re-creates what you can do in the GUI. It creates a domain group called Managed in the \BigFirm\Security Groups OU in the bigfirm.com

```
dsadd group "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -scope l
```

Here’s the syntax:

```
dsadd group <distinguished name of the new group> -scope <Domain Local = l | Global = g | Universal = u>
```

By default, this creates a security group. You can actually use the -scope option if a global group is what you want. You can make a global distribution group instead of running this:

```
dsadd group "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -scope g
```

The change in the syntax is as follows:

```
-secgrp group = yes | distribution group = no
```

The default is to create a security group. You don’t need to use this option in your command if a security group is what you need to create.

Do you remember that the GUI for creating domain-based groups didn’t offer you other than the ability to create the group? You had to go into the properties of the group to see the properties or members. You can use this command:

```
dsadd group "CN=Senior Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -scope g -desc "This group contains senior managers"
-memberof "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com"
-members "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com"
-"CN=Simona Corso,OU=Users,OU=BigFirm,DC=bigfirm,DC=com"
```

This command has done quite a bit. You've created a global security group called Senior Management in the Security Groups OU. You've set the group description to "This group contains senior managers." The Senior Management group was added as a member of the Managers group. And finally, you have added two users to the New Senior Managers group.

You can use the dsmod command to modify an existing group. Here's the command to get some help:

```
dsmod group /
```

This command will add Steve Red and Simona Corso to the Management group:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -addmbr "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com" "CN=Simona Corso,OU=Users,OU=BigFirm,DC=bigfirm,DC=com"
```

The syntax is as follows:

```
dsmod group <CN of the group to manage> -addmbr
<DN of the users to add to the group>
```

Next you want to remove Steve Red from the group:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -rmmbr "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com"
```

You can erase the member list of a group and add a replacement member list by running:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -chmbr "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com"
```

You can change the scope to universal by running this:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -scope u
```

The syntax for the -scope option is as follows:

```
-scope Domain = l | Global = g | Universal = u
```

One disappointment is that you cannot set the manager properties for group. How about deleting group? That's pretty easy:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com"
```

This command will delete the Management group. You'll get prompted to confirm the deletion. You can skip that by running this:

```
dsmod "CN=Management,OU=Security Groups,OU=BigFirm,DC=bigfirm,DC=com" -noprom
```

## MONDAY MORNING ADMIN TASKS

Here's how you can change a user's password using the dsmod command:

```
C:\Users\Administrator>dsmod user "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com" -pwd *
```

Enter User Password:

dsmod succeeded:CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com

The -pwd option instructs the command that you will enter the new password and confirm it. Alternatively, you can reset the password in the command:

```
dsmod user "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com" -pwd Password12345678
```

You can use an additional option with these commands to force the user to change their password when they log on:

```
dsmod user "CN=Steve Red,OU=Users,OU=BigFirm,DC=bigfirm,DC=com" -pwd Password12345678 -mustchpwd yes
```

## Locked-Out Scenarios

Account lockout policies ... oh, boy! Pretty much of the "security experts" you will encounter on the Internet or in person will tell you "three false logons in 30 minutes will cause a lockout policy." What know? That's a great recipe for facilitating a denial-of-service attack. Get access to a desktop in your forest with an user account for a couple of minutes, and you can run a script that will fail logons for every user in your Active Directory in time at all. Every single user except for the default domain administrator accounts will be locked out. That'll shut down your business. It's for this reason real security experts have been telling us to think hard about using the lockout option for passwords.(Check out the "The Case for Passphrases" sidebar to see an alternative) It's for this reason that lockouts are disabled by default in the Domain Policy. Our opinion is that this is a very good idea. Nevertheless, some organizations will enable this policy. You may have a valid reason for it. For this reason, it's important to know how to unlock a user account.
