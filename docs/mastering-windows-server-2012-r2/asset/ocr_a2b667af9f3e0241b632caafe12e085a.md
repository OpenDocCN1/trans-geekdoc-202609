In Windows Server 2012 R2, BranchCache improvements include automatic client computer database configuration and big performance and scalability increases. Clients can be configured through the use of a Group Policy object. If the GPO has not been configured for BranchCache, then BranchCache will check the cached server and use those settings by default.

One of the new advantages of BranchCache is the ability to reload specific content, like media and DVDs, on a cached server and then have content sent to the client cache.

Another nice advantage is the improvements that have been made to allow for better database performance. BranchCache has done this by using the Extensible Storage Engine (ESE). This is the same database technology used by Microsoft Exchange Server. It allows scaling of a single cached server to handle the increased demands of more people without having to increase hardware.

Hosted caches no longer need a server certificate issued by a certificate authority (CA). This will greatly reduce costs when deploying a public key with multiple CAs.

# SMB 3.0

Windows' file server bears the official name of SMB, which stands unfortunately for Server Message Block. (Blame IBM, not Microsoft, because an IBM guy first designed it) SMB has changed little over its roughly 25 years of life, with its biggest changes being of somewhat bigger block sizes so as to be able to make use of networks faster than 100 Mbps (appeared in 2000), the ability to handle multiple paths, and the addition of digital signatures to fool man-in-the-middle attacks (appeared in2001).

Windows Server 2012 R2 sports a somewhat reworked version of SMB that handles slow networks better, handles encryption intelligently, cranks up throughput on file transfers, and supports PowerShell.

# File Resource Manager

You can manage data stored on a file server using the tools in File Resource Manager. Some of the tools included help you automate classification and reporting and manage files and quotas.

With Dynamic Access Control's File Classification Infrastructure you can control and audit access to files on the file server. You can now get more control over how your files are classified on your file servers. With the enhanced features, classifying files can be done manually or automatically.

You can read more about this topic in Chapter 13, "Files, Folders, and Basic Shares."
