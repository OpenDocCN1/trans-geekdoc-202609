# Additional Role Services and Features

Server Manager is a single console that includes several sections that can be used to manage
the different roles including the File and Storage roles. File and Storage Services in
Windows Server 2012 R2 helps you do more than just share folders. The File and Storage
Services include several additional role services:

**File Server** This is the primary role required to support the File and Storage Services
role. This role provides you the ability to create and manage shares among allowing users
to share and access files that are available on the network. One feature of File Server is that
it is automatically added when a folder is shared. This role uses the new SMB 3.0 protocol, which
is discussed in more depth to towards the end of this chapter.

**Distributed File** Distributed File System (DFS) includes DFS Replication and
Namespaces and is covered in more depth in Chapter 14, "Creating and Managing Shared
Folders."

**Data Deduplication** Data Deduplication (Dedup) allows you to save more disk space by
locating and removing deduplication within data files. Instead of storing multiple copies of
same identical files, only a single copy takes up space and all duplicates reference the original.
