# CHAPTER 7 ACTIVE DIRECTORY IN WINDOWS SERVER 2012

You're migrating a group named Administration, but what if there already is a group named Administration? The page shown in Figure 7.63 answers the question.

+   13. You can skip the migration, zap the existing Administration group, or add a prefix to the name.

+   14. Walk through the rest of the wizard to the Finish button, and the migration kicks off.

It will display the statistics of the migration process, as shown in Figure 7.64. If errors pop up, view the log with the available button. You can also visit the logs in the c: \windows\adstore log. The file is named with a date/timestamp.
