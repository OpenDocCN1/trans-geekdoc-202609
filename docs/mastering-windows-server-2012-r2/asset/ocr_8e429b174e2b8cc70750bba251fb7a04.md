The Active Directory module for Windows PowerShell offers a command-line interface and to script Active Directory management tasks. You can use this to automate repetitive tasks using scripts or to perform complex and large operations that would consume too much time using an administrative console.

**Master It** You are managing the Windows Server 2012 Active Directory forest for an international corporation. The directors have announced that a new call center with 5,000 employees is to be opened soon. The human resources department will be able to produce a file from its database with the names of the new employees thanks to in-house developers. You want to create the user objects as quickly as possible with minimum human effort. How would you do this?

**Solution** You can work with the in-house developers so that the new employee from the human resources application will be a CSV file. The header row will describe the entries in the following rows. Each of the following rows will contain the values that you would use in the PowerShell New-ADUser cmdlet, for example:

```
Sam,AccountName,GivenName,Surname,DisplayName,
AccountPassword
Rachel Kelly,RKelly,Rachel,Kelly Kelly,OU=Users,OU=Bigfirm,DC=com,RKelly@bigfirm.com,NewPassword
Ulrika Gerhardt,UGerhardt,Ulrika,Gerhardt,Gerhardt,OU=Users,OU=Bigfirm,DC=bigfirm,DC=com,UGerhardt@bigfirm.com,
Tomz Kozlowski,TKozlowski,Tomasz,Kozlowski,Tomaz Kozlowski,OU=Users,OU=BigFirm,DC=bigfirm,DC=com,TKozlowski@bigfirm.com,NewPassword
```

You will run a PowerShell command that reads the values in the CSV file and shares the New-ADUser cmdlet to create the new user objects, for example:

```
C:\Users\Administrator> Import-CSV C:\users.csv | ForEach-Object (New-ADUser -Name $_.AccountName -SamAccountName $_.AccountName -GivenName $_.Surname -Surname $_.DisplayName -Path $_.Path -UserPrincipalName -AccountPassword (ConvertTo-SecureString -AsPlainText $_.Password) -Enabled True -PasswordNeverLogon )
```

This command will rapidly read the file and create each of the 5,000 user objects in the organizational unit(s) of your choice. Instead of spending days creating objects in a console, you will spend one minute typing this command.

**Delegate group management.** Part of the power of Active Directory is to delegate administrative tasks. You can grant permissions to users or groups to manage any organizational unit or in the domain. You can limit those rights so people only have permissions to do what they need to for their role in the organization.
