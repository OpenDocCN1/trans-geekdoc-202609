# MANAGING PRINT SECURITY

You can manage permissions to security for the entire server through the Security tab. There are differences in permissions that can apply to a server and permissions that apply to a printer.

Figure 16.27 shows the permissions on the left and the permissions on the right.

FIGURE 16.27 Viewing the security tabs; security on the left, and individual printer security is on the right.

![](img/41a83208e6906a3732620203b836cea7_894_0.png)

Just as NTFS and share permissions (covered in Chapter 10, "Active Directory Federation Services") can be set to Allow or Deny for any individual user or group of users, permissions on the print server or individual printers can be set to Allow or Deny.

For any of the permissions that are the same on the server and printer, setting them at the server level will cause all new printer installations to receive the same permissions. Existing permissions are not modified; only permissions for new installations.

The print server permissions as follows:

- **Print Users**: Users can send print jobs to the printer. The Everyone is granted this permission by default.
- **Manage Printers**: Users can change printer properties and permissions. This is granted to the Administrators, Server Operators, and Print Operators by default.
- **Manage Documents**: Users can control document-specific settings and pause, restart, and delete spoiled print jobs. This is granted to the Creator Owner, Administrators, Server Operators, and Print Operators by default. When a user creates a print job, they become a member of the Creator Owner group for job, allowing them to manage their own documents.
- **View Server**: Users can view the server properties and settings. This does not give them permission to change the properties. The View Server permission is granted to the Everyone, Administrators, Server Operators, and Print Operators by default.
- **Manage Server**: The Manage Server permission allows users to modify any of the server properties and settings. It is granted to the Administrators, Server Operators, and Print Operators by default.
- **Special Permissions**: Individual permissions can be assigned at the granular level including. If any granular permissions are assigned, the Special Permissions check box will be grayed out.

# DELEGATION OF PERMISSIONS

Default permissions on Windows Server 2012 R2 do not allow non-administrative users to perform any administrative print operations. However, it is possible to grant any specific printer permission desired at the server without granting users full administrative rights.
