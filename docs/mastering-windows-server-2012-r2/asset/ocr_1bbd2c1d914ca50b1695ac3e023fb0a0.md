# Creating an Answer File

Before you create an answer file, you should understand a little of what it is and what's going on behind the scenes.

You have reading about it this far, but what exactly is an answer file? An answer file is an XML file that answers installation questions for you during the installation process. If you have installed an operating system, then you know at some point you will need to set the time zone, for example. Instead of setting your time manually, you could specify the time zone in the answer file. When the installation would normally prompt you for the time zone, the answer file will answer this for you. This may not mean much to you if you're installing one or two computers, but when you have many computers to do, this process will work for you and you will be glad you needed this.

When Windows 8 or Windows Server 2012 R2 is installing, the installation outline goes through some or all of seven configuration passes, described in Table 2.3. Each of these passes is responsible for carrying out certain tasks. You can think of them as stages. Some tasks can be performed in more than one of the passes. Typically only three of these passes actually need to be executed for Windows to install.
