# Configuring Clients for Windows Updates

In this section we will cover configuration and validation that a Windows 8 computer (called WINCLIENT) gets updates from your Windows Server 2012 R2 WSUS server. The client-side setup is very simple and only requires the updates or configuration of the Group Policy object to receive updates. If you have upgraded to a new Windows Server 2012 R2 WSUS server, then you only need to modify the Group Policy objects from the previous section.

Modification of the GPOs is the only major task to configure your clients to get updates from your new WSUS server. This section will cover the basics to check and make sure your client is getting its updates and is pointed to the right server.
