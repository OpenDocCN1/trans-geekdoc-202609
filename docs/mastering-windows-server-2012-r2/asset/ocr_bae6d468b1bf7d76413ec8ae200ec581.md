The PMC is divided into three main sections:

**Custom Filters** The filters allow you to look at all the printers managed from this console, regardless of which print server they are connected to. If a print server hosts just five devices, this is no big deal. However, if you have hundreds of print devices connected, the ability to search using the custom filters will make your job a lot easier. You'll see later in this chapter, the tool comes with some default filters, but you can also create your own.

**Print Servers** In 16.4, one print server (LabServer) is added. However, if your organization has several print servers, you can manage them all through a single PMC. Each server will have its own drivers, forms, and printers.

**Deployed Printers** Printers that have been deployed using Group Policy are listed here. You'll see how to deploy printers with Group Policy later in this chapter.

Additionally, with each print server, you have four primary nodes. These nodes are used to manage the different print devices and printers served by the server:

**Drivers** You can add drivers that are needed for your printers here. Drivers have been simplified into three types: Titanium for high-end servers, x64 for 64-bit operating systems, and x86 for 32-bit operating systems.

**Forms** The forms on a server show the various print layouts the installed printers support. They define the paper size and the printer area margins. The majority of most people use letter-size paper (8.5"x11"), and the letter form defines letter-size paper. However, there are many other forms that can be selected, and you can make your own. The forms are shown on a per-server basis, not a per-printer basis.
