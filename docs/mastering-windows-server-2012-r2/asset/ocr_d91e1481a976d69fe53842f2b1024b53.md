This is how the ADAC works under the hood. If you are going to create a user object, you will not have to fight cmdlets; instead, pack all the necessary information into a one-liner.

It doesn't make a difference whether you create a user or a group or even an OU; ADAC will log every PowerShell step in this window. In order to see the full details on each you can click the + sign on the left side of the cmdlet. This will expand all the parameters, as you can see in Figure 8.80.
