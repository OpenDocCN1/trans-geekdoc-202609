By default, IIS 8 stores the automatically generated historical versions of applicationhost.config in the history subdirectory under %systemdrive:\inetub. This may not be the most secure location for all important files. To redirect future backups of applicationhost.config to another location, for instance, D:\MyHostFiles, execute the following PowerShell command:

```
Set-WebConfigurationProperty -Filter //System.ApplicationHost/ConfigHistory -Name Path -Value "D:\MyHostFiles"
```
