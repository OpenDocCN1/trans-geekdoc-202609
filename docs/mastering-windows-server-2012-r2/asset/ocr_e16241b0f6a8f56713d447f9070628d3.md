Understand System Center 2012 R2 Operations Manager. Operations Manager (also known as OpsMgr or SCOM) is an end-to-end monitoring solution that covers Microsoft and 19 different cross-platform environments. With it, you can centrally monitor servers, applications, hardware, and operations for many computers from a central console. You can use it to map out all of the components of your individual IT services and then roll them into a holistic and easy-to-manage single monitoring view.
