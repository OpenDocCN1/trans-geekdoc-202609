# Deploying Updates and Migration for Windows Server Update Services

You must be running one of the following operating systems to receive updates: Windows 8, Windows 7, Windows Server 2012 R2, Windows Server 2008 R2, Windows Vista, Windows Server 2008, or Windows Server 2003. Windows 8 RT is also supported in a limited capacity.
