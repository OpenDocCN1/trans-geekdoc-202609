+   6. Next, click the Classification tab.
In the Classification tab the first thing you need to choose is the classification method.
There are three methods by default:
**Content Classifier** Content Classifier allows you to set up patterns that you can detect within a file to autoclassify the document.
**Folder Classifier** Folder Classifier automatically classifies all folders to the configured value.
**Windows PowerShell** The PowerShell Classifier allows you to write your own detection agent in PowerShell and execute it. It is extremely powerful for advanced users.
