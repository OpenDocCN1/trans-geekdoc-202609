Connect Used to start the virtual console.

Settings Used to configure the VM, as discussed in previous sections.

Start Used to boot the VM. Depending on the state of the VM, you will have more options here, such as Shutdown.

Checkpoint Used to create a point-in-time image of the VM.

Move Used to move a virtual machine or its storage.

Export Used to save the entire VM, including configuration and virtual hardware.

Rename Used to give the VM another name.

Delete Used to remove the VM configuration but not its hard disks.

Enable Replication Used to replicate the VM to another Hyper-V host.

Another point to note is that the exact items in the Actions pane vary with the power state of the VM. The previous options assume that the VM is still running. When a VM is running, you have additional items to turn the VM off, reset, shut down, and so on.

# Installing a Virtual Machine

With the VM configured, the hard part is done. The next step is to install the operating system in the VM. You are used to dealing with physical servers, but the details of installing in a VM here are bit different.

The first question is how to connect to the console of the VM. After all, you want to see what's going on. To do that, open Hyper-V Manager, select the VM (WS2012R2-SRV in our example) you want to connect to, and Connect in the lower-right corner.
