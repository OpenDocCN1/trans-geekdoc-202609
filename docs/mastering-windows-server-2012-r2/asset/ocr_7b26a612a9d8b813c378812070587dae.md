# Device

Like users, devices also have a huge amount of information that you can use. A good example would be for sensitive information; to prevent leakage of this data, it would be great to be able to limit access to this information to devices that you know will be physically located and connected to the corporate network. You can restrict access to such information based on location. For desktop computers, you can simply enter On Location field, and for laptops you can enter Mobile.

Normally for desktops, you can restrict access to removable media and physically secure the asset. Because a laptop by its very nature is mobile, it would be very difficult to secure the asset, and there may be a valid business reason to allow access to removable media. A user can now access the sensitive information, copy it to their laptop, and then copy it onto a USB device. With a Device claim you can restrict access to this sensitive information by the type of device used, or even if not on a physically secure asset, they can't access the sensitive information, preventing data leakage.

# Resources

Resources are key. If they haven't been defined, they should be defined. They clarify the data on your file servers, and they will work with the File Server Manager to ensure this happens automatically. This solves the big issue of how to apply retroactively to your current environment. Microsoft has already done a lot of work out of the box on defining resources within DAC, and it is my opinion that it is best to see what is there. You may spend time planning your resources; if you don't, it will become a big problem later on.

# Claims

A claim is information from a trusted source about an entity. It is a method of authorization that is based on an attribute (either a device or a user normally) to provide additional security to resources. It could be your office location or your department or any other attribute that is defined to provide you access to information. For example, if your office location is New York, then you can access the America user share.

Claims are three different types (we've already discussed user and device claims, we're providing just a brief overview here)

User User claim is associated with the Active Directory user attributes, for example, your department or location. Any attribute technically can become part of the user claim model.

Device Like a user claim, a device claim's information comes from the attributes associated with Active Directory computer accounts. For example, location or operating system could be used to create a claim.
