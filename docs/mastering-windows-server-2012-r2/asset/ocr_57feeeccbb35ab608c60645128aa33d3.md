# PREPPING THE SOURCE DOMAIN CONTROLLER

You need to decide what will be done with the source domain controller prior to performing the operation. If the server is to remain in the domain as a domain controller, little needs to be done. If it will be redeployed, you must consider how to replace the network's reliance on it.
The following data for the source server should be collected in order to apply similar settings to the target member server after the domain controller promotion:

+   - Server name.
- IP addresses (IPv4 and IPv6).
- Assigned Active Directory site.
- Assigned OU.
- Applied GPOs and RSOP output. You can type,
gresult /scope GPOResult.txt
to push the results to a text file.
- Assigned FSMO roles. These will be transferred if the server will be decommissioned.
- Global catalog role.
- Additional services, as DHCP, file and printer sharing, and Internet Authentication Services for VPN connections.

Finally, perform system state backups for all domain controllers and file system backups for essential services to be migrated outside Active Directory Services.

# PROMOTING THE MEMBER SERVER

The Active Directory Domains Configuration Wizard does the meat of the work. You should select the option "Add a domain controller to an existing domain" for the deployment configuration. Also, you should enable the options for the DNS and Global Catalog roles as required.

After the wizard has finished, a restart is required and the DNS service should be configured on the target domain controller. Although the Active Directory integrated DNS zones have been replicated to the domain controller, the DNS service may not be showing.

+   1. On the source server, enumerate the DNS zones and application partitions:
dnscd /enumzones
dnscd /enumdirectorypartitions
2. On the target server, enumerate the DNS application partitions and zones using the previous command.
3. Compare the results between the two servers.

If they are not listed, you can use the dnscd /enlistdirectorypartitions command to force the new DNS server to start sharing the partitions. The zones should be listed since the domain controller is listed as a name server for the zones.
