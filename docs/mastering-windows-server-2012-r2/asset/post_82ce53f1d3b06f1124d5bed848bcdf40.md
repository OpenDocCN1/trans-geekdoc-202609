This is typically done via Group Policy. You can use the Local Security snap-in for a stand-alone server. If you're in a domain, you can create a new Group Policy (GPO) or use an existing GPO such as the Default Domain Policy.

# ENABLING OBJECT ACCESS AUDITING

Enabling object access auditing must be done before auditing on any individual objects will occur. In this context, objects are resources such as printers, files, and folders. Once object access auditing is enabled via Group Policy, auditing can be enabled on any individual objects. However, if auditing is enabled on the object but object access auditing is not enabled, then auditing doesn't occur at all. Both steps must be done.

# SETTING AVAILABLE HOURS

You can make printers available to everybody (which is the default), or you can pick and choose the times the printer will be.

A printer will always accept print jobs, but you can manipulate the time when a printer sends jobs to the print device. If a job is sent to a printer outside of these hours, the job will be queued and printed when the scheduled time arrives. Jobs queued in this manner will not prevent other jobs from printing.

As a simple example, suppose Sally occasionally needs to print lengthy documents for the following day. Without a printer schedule, she'd print with everyone else. As her print jobs are printed, everyone's print jobs will have to wait.

However if you alter the printer schedule for Sally, her jobs could be set between the hours of 8 p.M. and 5 a.M.—when everyone is gone.
There's an important point to grasp here, though. If you create a printer named Laserjet that everyone uses to print and you alter the schedule for Laserjet, you've just altered the schedule for everyone. What you must do is create a new printer.

# Creating a Second Printer for a Single Print Device

You'd create a new printer using the procedures covered earlier in this chapter. Remember, the printer is the software component, and the print device is the physical device that creates the printed output. When creating the new printer, make sure you do these things:

- Give the new printer a different name and share name.
- Choose the same settings (port, printer manufacturer and model, and so on) you chose for the first printer.

Sending documents to the new printer will cause them to print on the same print device.
The only difference will lie in the configuration options you set for the new printer.
In this example, you could name your printer AfterHoursLaser. All the settings would be the same, except you'd edit the printer's hours of availability.

# Modifying the New Printer

Once you've created the printer, you simply access the Advanced tab, select Available From, and select the desired time. You'd need to provide some training to the user to ensure the user understands that any jobs sent to this printer would not print until the scheduled time.
You can also modify the security settings or share the settings so others can't find the share. And, if you desired, you can place a $ symbol at the beginning of the share name, it will be hidden. Users who know the printer name can still reach it, but it won't be visible.

# Setting Printer Priorities

The default priority is the lowest, but you can increase the priority of a printer. A higher priority means the printer will be used before printers with lower priority. This is useful if you have multiple printers of the same type.

To set the priority of a printer:
1. Open the properties of the printer to modify.
2. Go to the Advanced tab.
3. Click the Priority button.
4. Enter a priority value from 1 to 99, where 1 is the highest priority.
5. Click OK.

If multiple printers have the same priority, the spooler uses them in the order they were added to the queue. You can change the priority of a printer at any time.

The default priority for all printers is 1. If you set the priority of a printer to 1, it will be used before any other printers. If you set the priority of a printer to 99, it will be used after all other printers.
