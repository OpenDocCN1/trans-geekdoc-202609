# # Installing and Upgrading to Windows Server 2012 R2

Experienced Windows Server administrators and consultants might feel the urge to skip this chapter. You might be thinking that you don't need to go through this material again. We urge you to think about that. We will be covering the fundamentals, but we will also be going through some details that you will probably not already know and that you will find useful.

Your first experience of Windows Server is probably going to be a manual installation of the operating system on a lab or virtual machine. Depending on the complexity of your environment and your upgrade/migration plans, you may decide to continue with manual installations or even use automated installations. No matter what you choose, you'll probably want to read this chapter to understand what the typical installation steps are.

In this chapter, we'll cover a clean manual installation and a manual upgrade of Windows Server. From there we will delve into installation and upgrade strategies for Active Directory. If you are performing many installations of Windows Server, then you will like this next piece. We will discuss how you can save some time and keyboard wear and tear by automating your installations of Windows Server 2012 R2 using an unannotated installation file that you will create using Windows System Image Manager.

In this chapter, you'll learn to:

+   * Upgrade your old servers
* Configure your server
* Build a small server farm

# # What Has Changed?

We think you'll find installing Windows Server 2012 R2 much simpler than installing any previous version of Windows Server. If you have installed Windows 8 or Windows Server 2008, then you have a good idea of what to expect from Windows Server 2012 installations. The installation routine has really been trimmed down to ask for just the basics to give you a secure installation that you can customize.

Let's look at that last sentence. It's something we've heard before, but you might not noticed much of a difference. You'll see it straightaway with Windows Server 2012 R2. What does that mean?
