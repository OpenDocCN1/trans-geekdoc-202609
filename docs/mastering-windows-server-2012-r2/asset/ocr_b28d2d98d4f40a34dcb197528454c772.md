# Understanding Regular Expressions

I promised to give you a quick demonstration of regular expressions. This is something you should ask experienced programmers or telefono engineers because they are wizards at this stuff and usually have a great ability to construct exceptionally complex but useful expressions.
nAlso, in your favorite search engine for "Regular Expression Cheat Sheets," There are a few cool links available that you can use as a reference.
With most things, regular expressions won't make sense until you use them for something. Say let's look at a basic example. Say you want to detect a credit card number. First, you should look at what characteristics a credit card number has, and to my thinking the simplest one to start with is that it has 12 numbers. We will start with that.
In order to detect a 12-digit number with regular expressions you would have a query like:

```
\\d{12}"
```
