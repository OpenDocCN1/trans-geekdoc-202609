After all this explaining, let's get on the walk-through. The following steps presume that have access to two hosts (one will be the server and one will be the destination) running Windows Server 2012 R2 with the Hyper-V role installed. These two hosts should be part of the same Active Directory domain.

+   1. Log on to the source Hyper-V host server with an account that has administrator permissions.

+   2. Open Hyper-V Manager, ensure that the source host is selected in the left pane, and then click Hyper-V Settings in the Actions pane.

+   3. Click Live Migrations and then check the "Enabling and outgoing live migrations" box to turn on the feature, as shown in Figure 28.12.
