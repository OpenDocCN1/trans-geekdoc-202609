In this example we have a single folder shared share. It is shared to everyone for read-only access via its share permissions and read-only via NTFS permissions, and we also allow administrators Full Control. You can see from Figure 15.3, however, the Everyone principal has Read & execute access. You can now start to see the granular Advanced Security settings, but this is still not DAC.

In order to progress, you must select a principal. A principal would be, for example, a user account or a group to which you want to assign privileges. If you not select a principal at this stage, all the elements will stay grayed out.

As you can, quite a few options look familiar from previous versions of Windows. However, now there is a new section where you can add a condition. This is where the power of DAC begins: with conditional expressions.
