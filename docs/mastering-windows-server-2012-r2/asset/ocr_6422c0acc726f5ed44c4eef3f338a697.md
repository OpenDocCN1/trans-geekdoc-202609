# Managing Printer Properties

As the print server has several properties that can be managed, viewed, and manipulated, you can also manipulate properties for individual printers. Earlier in the chapter, you learned how to add printers. If you later need to modify any of the printers, simply right-click the printer, and Select Properties.
Figure 16.30 shows the properties of a printer with the General tab selected. The General tab shows basic information on the printer such as the name, location, comments (if added), model, and features supported by the printer. This page will also include a Preferences button that can be used to modify specific user preferences for the printer. It also includes a button to test a page that can be very useful for connectivity with the printer.
