# Utilizing the Best Practice Analyzers

For number of years the Solution Accelerator team of Microsoft would release Best Practice Analyzer tools to complement some of your key offerings. One of the best known of these is the Microsoft Exchange BPA (ExBPA), this tool enabled administrators and consultants around the world to ensure they had configured their environments optimally to the best-practice recommendations of Microsoft. Back then, the BPAs were separate tools from the application, Microsoft made a decision to start including BPAs in Windows Server (from the 2008 release onward) to analyze each role deployed in the operating system. A nice benefit of this is that BPAs get updated through Windows Update in the way that the operating system does, ensuring that you always get up-to-date recommendations when you need them.
