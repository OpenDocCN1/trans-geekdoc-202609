# IP ADDRESS TRACKING

This section is where you'll most find yourself if you need to track IP address information based on specific hosts or users. You have four different views here to choose from:

+   - By IP Address
- By Client ID
- By Hostname
- By User Name

By choosing any of these views, you will be able to decide on the date and when to search, with the search includes or excludes any additional correlated event data that was generated by any managed domain controllers or Network Policy services. Similar to the DHCP Configuration Events, clicking the Tasks menu here will allow you to purge, retrieve, or export your data.

# IPAM Delegation

When you install the server role, the installation process automatically creates a number of local security groups that can be used to deliver Role-Based Access Control (RBAC) of your IPAM environment to designated users and administrators. Depending on the type of administrative privileges that you want your users to have, all you need to do is add their accounts to the appropriate security group.
