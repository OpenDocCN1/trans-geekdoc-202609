# HANDY TROUBLESHOOTING TIPS

You can delete cached profiles on your Windows 8 machine by right-clicking the Start icon in the lower-left corner and selecting Selecting. That launches System from Control Panel (that's a handy shortcut). Then click Advanced System Settings. Click Settings in the User Profiles section of the Advanced tab. That dialog box will display the profiles that are cached on the PC. You can select one and delete it if required.

You shouldn't try to delete the profile of a logged-in user. Even if you user out and log in as an administrator, you can't delete that cached profile because there's an open or locked file or folder. You will have to reboot the PC.

If the PC gets a bit messy, you can find the user's cached profile folder in C:\Users. It's possible to have several versions of the profile whenever the user is using by regedit .exe, the registry editor tool. Browse to \HKEY_MACHINE\SOFTWARE\Windows\NT\CurrentVersion\ProfileList. Here you'll see the security identifiers (SIDs) of the users. If this is a test machine, it won't be hard to identify which one to look at. Go to the key that names after the SID of the relevant user. The ProfileImagePath will contain the path to this user's cached profile.

While you, take a look at the folders on the file server and the PC that you're testing is a good learning experience. You'll see that Windows caches the profile on the PC. That's handy for PC users, especially laptop users, whenever the file server is not available when the user logs in. If a laptop user goes home and can't download their profile, then they get a temporary profile that doesn't contain their files and settings. Thanks to the cache, they still have their files and settings.

Rename the profile on the file server without changing the user object. You'll find that Windows will load a cached copy or will generate a temporary profile from the default user profile.
