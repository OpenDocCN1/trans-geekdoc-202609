

# IPAM 179

手动添加或删除您的 DHCP 和 DNS 服务器。此功能允许您同时对所有 DHCP 和 DNS 服务器进行同步更新。

此功能还提供了监控功能，可以检查您的 DHCP 范围和 DNS 区域的可用性。

# 地址空间管理

IPAM 的地址空间管理 (ASM) 功能可以从单个集中式控制台提供对您的 IP 地址基础设施的完全透明化。它包含一个整洁的报告功能，允许您跟踪 IPv4 地址利用率趋势，并以易于消费的报告提供数据。使用 ASM 来确保对网络进行更好的规划、问责和控制，将是处理 IP 地址问题时从主动（在问题发生前修复问题）变为被动（在问题发生后才发现问题）的真正区别。

您可以使用 IPAM 来检测在不同 DHCP 服务器上配置不同的重叠 IP 范围或作用域，以及 DNS 和 DHCP 条目，并定位范围内的任何空闲 IP 地址。图 5.2 显示了一个月内的 IP 地址利用率趋势。

![](img/41a83208e6906a3732620203b836cea_214_0.png)

# 网络审计

IPAM 的网络审计功能会深入研究您的 DHCP 服务器的 Windows 事件日志，并为您提供环境中发生的所有 DHCP 配置更改的完整视图。它将来自 IPAM 数据库、DHCP 服务器租约日志以及您的域控制器 (DC) 和 NPS 安全日志的数据相关起来，显示有关用户、设备和 IP 地址的跟踪信息。由于此类数据随时可用且可完全搜索，您可以随时运行报告来帮助识别任何配置问题。

# 拓扑部署选项

在部署 IPAM 管理跨越多个物理和逻辑环境的 IP 地址状态时，有三个拓扑设计选项可供选择。这些配置在表 5.1 中分类并定义。

# 第 5 章 IP 地址管理与 DHCP 故障转移

# 表 5-1：IPAM 拓扑结构

| 拓扑 | 定义 |
| --- | --- |
| 集中式 | 在中心位置部署一台 IPAM 服务器来管理一切。 |
| 分布式 | 在企业的每个站点都部署一个 IPAM 服务器。每个 IPAM 服务器上的信息将隔离在每个站点，或者通过企业内不同 IPAM 服务器之间的开箱即用数据复制进行同步。 |
| 混合式 | 这种设计利用了集中式和分布式模型的混合，在一个中心 IPAM 服务器的同时，部署在不同站点的多个分布式 IPAM 服务器上。 |

# IPAM 安装

现在您已经了解了 IPAM 是什么，我们可以介绍安装步骤。在本节中，假设您已经有一个需要管理的 IP 地址基础设施（DC、DNS、DHCP 等），或者您至少遵循了书中概述的步骤来构建和配置一个实验室或测试网络（我们在此处的示例环境中使用 Bigfirm.com 域），这样您就可以从中部署 IPAM。以下是部署 IPAM 所需的高层级步骤：

- 1. 使用“添加角色和功能”向导安装 IPAM 服务器功能。
- 2. 手动或使用组策略配置 IPAM 预备。
- 3. 配置 DHCP 或 DNS 和 DHCP 条目。
- 4. 定位范围内的任何空闲 IP 地址。
- 5. 运行报告以帮助识别任何配置问题。
- 6. 按照步骤完成。

既然您现在已经了解了 IPAM 是什么，我们就可以介绍安装步骤。在本节中，假设您已经有一个需要管理的 IP 地址基础设施（DC、DNS、DHCP 等），或者您至少遵循了书中概述的步骤来构建和配置一个实验室或测试网络（我们在此处的示例环境中使用 Bigfirm.com 域），这样您就可以从中部署 IPAM。以下是部署 IPAM 所需的高层级步骤：

- 1. 使用“添加角色和功能”向导安装 IPAM 服务器功能。
- 2. 手动或使用组策略配置 IPAM 预备。
- 3. 配置 DHCP 或 DNS 和 DHCP 条目。
- 4. 定位范围内的任何空闲 IP 地址。
- 5. 运行报告以帮助识别任何配置问题。
- 6. 按照步骤完成。
