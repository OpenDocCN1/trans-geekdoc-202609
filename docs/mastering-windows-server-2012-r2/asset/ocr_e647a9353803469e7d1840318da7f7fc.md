Disks Get as many disk spindles as you can reasonably afford. Four independent medium-capacity disks will be faster than two large-capacity disks when using multiple VMs. SATA disks are OK for testing and non-demanding applications. For better performance for SCSI or SAS disks, but if you have the money for it, invest in high-speed solid-state disks for optimal performance. Avoid a RAID-5 configuration because it's slow on write operations. RAID 0 and RAID 1 combinations are fine for low-end systems—remember that RAID 0 has no fault tolerance. For high-end applications, consider RAID 0.

NICs For Hyper-V networking, the general recommendation is to have at least two NICs, to manage one and another for the VMs to access the network. Preferably, you should have four or more NICs if you want to make use of built-in NIC Teaming, Converged Networking, and Failover Cluster features of Windows Server 2012 R2. If you expect high network throughput or have iSCSI connections that require dedicated NICs, you will need even more.

# SOFTWARE REQUIREMENTS

Now that you have hardware requirements sorted, we will discuss the software side. Table 27.1 summarizes the different Hyper-V options and their virtualization rights based on the number of Virtual Operating System Environment (VOSE) instances you can run on. VOSE is a term for a guest operating system running on a host.

TABLE 27.1: Windows Server 2012 Editions and Hyper-V
| WINDOWS 2012 EDITION | CPU SOCKETS | VIRTUALIZATION RIGHTS |
|---|---|--|
| Windows Server 2012 R2 Datacenter | Two | Unlimited free VOSEs |
| Windows Server 2012 R2 Standard | Two | Two free VOSEs |

Note the edition named Hyper-V Server 2012. This is basically a scaled-down version of Server Core that the Hyper-V role enabled by default. Its main benefit is that it's available as a free download and can be used for basic virtualization. The remaining editions differ in their virtualization capabilities and licensing models. Briefly, Datacenter and Standard edition cover two CPU sockets. If your server has four sockets, you'll need two licenses. The unlimited VOSE is on condition that the sockets are licensed correctly. Server 2012 has valid use when customers already have existing licenses that can cover the VMs. In the other two editions of Windows Server 2012 (Essentials and Foundation), the Hyper-V role is not available.
