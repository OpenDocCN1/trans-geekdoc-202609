You should see now in your Password Settings container in Active Directory Center a PSO called PSO_G_ITAdmins.
Now you need some kind of proof that this PSO works and what settings you have. In our previous examples we created a user named Sally Smith. Let's assume that this user is an IT administrator, and we are going to add Sally Smith into the G_ITAdmins group. Sally should now receive the new password settings; you can easily prove it by logging onto as the.smith account. Another way to see what kind of PSO rules are applied to a user as follows:

+   1. Open Active Directory Administrative Center.
