# Combine and NTFS permissions. When a folder is shared from an NTFS drive, it includes both share permissions and NTFS permissions. It's important to understand how these permissions interact so that users can be granted appropriate permission.

**Master It** Maria is in the G_HR and G_Managers groups. A folder named Policies is shared as Policies on a server with the following permissions:

NTFS: G_HR Read, G_HRManagers Full Control

Share: G_HR Read, G_HR Change

What is Maria's permission when accessing the share? What is her permission when accessing the folder directly on the server?

**Solution** Maria's permission when accessing the change. You can determine the result of combined NTFS and share permissions in three steps:

+   - Determine cumulative NTFS permissions: She has Read and Full Control, her cumulative NTFS permission is Full Control.
- Determine cumulative share permission: She has Read and Change, so her share permission is Change.
- Determine which of the two provides the least access (or the most restrictive): Change is more restrictive than Full Control.

If the folder is accessed directly, share permissions do not apply. So, would you have Full Control permission.

**Implement BitLocker Drive Encryption.** BitLocker Drive Encryption allows you to encrypt an entire drive. If someone obtains the drive that shouldn't have access to the data, the encryption will prevent them from accessing the data.

**Master It** What are the hardware requirements for BitLocker Drive Encryption, and what needs to be done to the operating system to use BitLocker?

**Solution** BitLocker requires Trusted Platform Module 1.2, which is a hardware component and is typically included in the motherboard on systems that it has. It is possible to use BitLocker without TPM using either a password or a smart card and a PIN. BitLocker needs to be added as a feature using Server Manager before it can be implemented.
