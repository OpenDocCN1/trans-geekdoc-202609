# Using Effective Permissions to Troubleshoot Access Control

Let's say your company has a Central Access Policy to test share on your file server. This share has several subsets containing simple folder names based on three departments: Sales, Accounts, and Engineering. The administrator has already configured the policies to authorize access to the individual folder only by the department.

The administrator ensures that policies are working correctly. With the use of effective permissions you can achieve this, and you can also test individual user accounts without having to obtain their credentials and test their access.

Don't worry if you don't understand this right now. In this chapter we'll show you how to use effective permissions, and we'll include the appropriate screenshots.

# Automatic File Classification

By now you're aware of the considerable power Dynamic Access Control can bringng. Think about all the information contained within the files that are hosted on the network shares your company and try to imagine how you can protect every one of them.

Traditionally, protecting data was a manual process, and what was worse, you had to ensure the IT administrators and users understand how to manage their documents.

Imagine someone put the payroll Excel spreadsheet in the wrong place, which didn't have the traditional methods to protect it! Imagine if your company had intellectual property and it was not secured correctly! Imagine the stress of managing and trying to guarantee the security of the data.

In modern infrastructures, centralized management—where many tasks are possible as automated—should be the minimum base for an organization. Applying this simple principle to the classification of data is extremely important.

Using the resource properties mentioned early in this chapter, you can do this! Resource properties allow you to manually set classifications, but when you combine these with the File Server Resource Manager (FSRM) in Windows Server 2012, you can automatically classify the documents. If an end user misplaces a document in a file share, you are confident that no sensitive information can be accessed by unauthorized parties. Later in this chapter we'll give you a demonstration on how to complete this.
