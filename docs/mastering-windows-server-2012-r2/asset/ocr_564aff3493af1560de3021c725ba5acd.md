SCSI Controller The next item on the hardware list is SCSI hard disk that you configured as part of the New Machine Wizard. It is automatically added You can add up to four SCSI controllers to a virtual machine, and each of these controllers can have up to 64 virtual hard disks attached, each virtual machine having a capacity of 64 TB. If you do the math on this, you'll see that a virtual machine in Windows Server 2012 R2 can have 16 terabytes of storage.

Under the SCSI Controller section, you can also attach a DVD drive to use for mounting ISO files. Unlike earlier versions of Hyper-V, the DVD drive is no longer available by default to Gen2 VMs, and this is why it is not available as an option when you run the New Virtual Machine Wizard.

When you have a virtual drive attached to a SCSI controller, you can click the sign beside the drive to expand and access the Advanced Features area. Here you can turn on Quality of Service management for a specific virtual hard disk, where you can determine minimum and maximum values for IOPS measured in 8 KB increments. You can also enable virtual disk sharing here to allocate a specific disk to be used as shared storage to facilitate clustering scenarios with your virtual machines.
