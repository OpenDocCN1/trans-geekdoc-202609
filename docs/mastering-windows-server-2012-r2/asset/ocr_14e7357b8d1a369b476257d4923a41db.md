# Chapter 13

# Files, Folders, and Basic Shares

One of the core functions of any server is to serve resources such as files and folders. In Windows Server 2012 R2, the File Services and Storage Services roles have been combined into one role called File and Storage Services. This role is installed by default; however, any additional roles that serve File and Storage Services will need to be added via the wizard in Server Manager. The File Services role includes roles such as the File Resource Manager (PSRM), services for Network File System (to support Unix clients), the Windows search service, and BranchCache for remote offices. Now that Storage Services is available in conjunction with File Services, Windows Server 2012 R2 has unleashed some new and improved roles and features like Dedplication, Storage Spaces, and Storage Pools that have made this version of Windows Server 2012 the best.

When you plan on sharing folders and files, it's important that you understand not only how to share the data but how to protect it with permissions including both Technology File System (NTFS) and share permissions. Both sets of permissions are applied independently, to provide multiple levels of enhanced security options. You should be able to quickly determine what the ultimate permissions are for a user who accesses a share over the network. And, if you want to protect hard drives, you can still use BitLocker Drive Encryption to encrypt them using Windows Server 2008 R2. One of the most notable new features in Windows Server 2012 R2 drive BitLocker Drive Encryption options. You can now use the "Encrypted disk space only" option—no waiting hours for the entire volume to finish encryption when you are only using a small portion of the total disk space. We will take a deep dive into BitLocker's new features towards the end of the chapter.

The underlying protocol that handles file transfers is Server Message Block (SMB), which has been upgraded to 3.0 in Server 2012. SMB 3.0 comes with many new features that have redefined files as a foundation for enterprise storage solutions for small and medium-sized companies. This protocol stack provides significant benefits for file transfers over the network—as you are connecting to the right kinds of clients. Both SMB 1.0 and SMB 2.0, with all their inherent challenges, will still be used when connecting to legacy machines. Currently only Windows 8 and the Windows Server 2012 family can take full advantage of the new SMB 3.0 features that will be discussed in this chapter.
