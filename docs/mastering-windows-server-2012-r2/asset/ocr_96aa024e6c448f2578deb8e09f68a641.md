# Setting Local User Account Properties

Let us open the user account for Steve that is created on the member server, Server01. You should right-click that and choose Properties. This opens the screen in Figure 8.9.

This dialog box will look pretty familiar. These are the settings defined for the user account when you created it. The grayed-out check box, "Account is locked" will be enabled if the user is locked out. An account will be locked out if the password policy defines that it is locked out after x number of failed password entries within a specified time frame. By default, this is defined in the Default Domain Policy. Notice that you cannot select this box; that's because you cannot use this dialog to lock out a user. The option becomes enabled only when the user is actually locked out.
