## 有效访问

总而言，你需要拥有相应的权限来查看你正在访问的任何资源的权限，并且在确定有效访问的因素方面存在一些局限。例如，你可能无法查看每个用户或组的权限。考虑服务器 Storage 上的“本地用户”组，你的 APPS 共享就在那里。由于此服务器是 Active Directory 域的成员，名为“域用户”（Domain Users）的组会自动嵌套在“本地用户”组中。你可以通过在高级安全设置页的“有效访问”选项卡上进行以下选择，来查看“本地用户”组的有效权限：

- 1. 点击“选择用户或设备”按钮，然后选择“位置”按钮。
- 2. 选择名为 Storage 的本地位置（而不是目录）。

由于“域用户”组嵌套在“本地用户”组中，域用户对该文件夹拥有相同的权限，除非存在任何与这些权限冲突的其他权限集。但当你尝试使用此工具获取“域用户”的有效权限时，它会显示无访问，因为此工具无法计算嵌套在本地组中的域组的有效权限。

这显然限制了该工具的有效性，但你仍然可以使用它像上一个示例所示的那样为用户或组计算多个 ACE（访问控制项）。

## 所有权

在分配和撤销权限的过程中，你不可避免会遇到包括管理员在内的任何人都无法访问文件的问题。而且你无法更改文件的权限，因为你需要权限。幸运的是，所有权可以帮助你。对于每个对象，必须有一个所有者。所有者可以更改对象的权限。即使所有者被拒绝了访问，所有者也可以更改权限。如果对象没有所有者，管理员可以接管成为所有者。
