# User and Group Migration with the ADMT Snap-In

Group migration and user migration are very similar. In this example, we will walk through the User Migration Wizard.

+   1. On the ADMT menu, choose User Account Migration Wizard, and click Next to see the first panel, the all-familiar Welcome page.
Earlier versions of ADMT offered a test run of the operations. Version 3.1 isn't timid. So, be certain to run this in a test environment for familiarization and then on pilot accounts in the production environment.
2. Click Next on the Welcome page, and you'll see the dialog shown in Figure 7.54.
