# Server Core Survival Guide

Before getting into the details, you need to learn a few survival tips for handling this operating system. We'll discuss using Task Manager to control processes, start tasks, and view performance. Then we'll cover basic commands that we typically neglect when flashy GUI is available. These will help you perform routine administration tasks and allow access to the network.

# Switching between Server Core and the GUI and Vice Versa

I'm placing this at the top of the Survival Guide because it may prove to be very handy you need to switch from Server Core to the GUI and vice versa. Many administrators complete the initial setup using GUI and switch over to Server Core for production.
You will need to download the script here: http://gallery.technet.microsoft.com/scriptcenter/Switch-between-Windows-9680265d/file/70875/1/SwitchGUICORE.zip.

This script is used no matter which version you are switching to. Before you run the script, you need to enable scripts on; they are disabled by default. To do this, run the script, as shown in Figure 3.5.

![](bbox=[0.176, 0.516, 0.905, 0.626])

Where prompted, add the integer value as follows:

+   1—Switch to Server Core
2—Switch to the GUI
3—To install the GUI from online resource

Be patient; this process takes a few minutes to complete. Once it has finished, you will be prompted to reboot the server. When the server reboots, you should be in the version you need.
