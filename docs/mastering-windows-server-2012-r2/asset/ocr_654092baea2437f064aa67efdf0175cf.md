# ROLES VS. FEATURES

A role is considered a major function of the server, whereas a feature is a smaller add-on package that usually provides additional support to a major role. Roles would include Active Directory, DNS, and DHCP. Features like PowerShell, Windows Server Backup, and Remote Assistance provide additional functionality to help you manage your server roles.
