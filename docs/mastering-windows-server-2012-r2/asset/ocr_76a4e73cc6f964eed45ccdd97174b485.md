# CHAPTER 15 DYNAMIC ACCESS CONTROL: FILE SHARES, REIMAGINED

Our share on ContosoFS01 has two subfolders: Accounts and Engineering. We have applied our previous Central Access Policy folder to restrict access to Accounts and HR. We used an "Or" case for this, so if you are in either Accounts or HR, you would get access to the resource. In this case we ensure only engineers "And" staff in the Empire State building get to the Engineering resources.

Let's begin. First, we will summarize the steps we have to proceed:

+   1. Create a claim type for title and office.
2. Create a resource property based on the claim types.
3. Add a resource property to the resource property list.
4. Create an access rule using the resource properties previously created.
5. Create a new access policy and deploy it to your file servers.
6. Apply the policy to the Engineering subfolder.
7. Test with effective access.

# Step 1: Create the Claim

Perform the following steps to create a claim:

+   1. Open Active Directory Administrative Center, and on the left side click Dynamic Access Control.
2. Select Claim Types, and under Tasks Choose New ➤ Claim Types.
3. In the search box under the Source attribute, type in title.
4. Scroll down to Suggested Values, and click "The following values are suggested.\n5. Click the Add button, and enter the values in the following table:

| VALUE | DISPLAY NAME |
| --- | --- |
| Engineer | Engineer |
| Accountant | Accountant |
| Reception | Reception |
| Director | Director |

+   6. Click OK when finished.
