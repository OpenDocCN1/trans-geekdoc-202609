# # Forcing Replication
The repadmin command-line tool includes a neat feature that you can use to replicate data between two domain controllers even if it's outside the schedule. This can be useful when troubleshooting replication problems between sites. The repadmin switch is /replisleobj.

> USING COMMAND-LINE REPLICATION

In previous versions of Windows, the replisleobject switch was used to replicate objects between DCs even there wasn't a connection. However, this has been shortened to just replisleobj (adj instead of object) in Windows Server 2012 R2. This shorter version was also available in Windows Server 2003 with the longer version, but in 2012 and 2008, only the shorter version is available. We can tell you from experience that no how many times you try it without shortening object to obj, it simply won't work.
