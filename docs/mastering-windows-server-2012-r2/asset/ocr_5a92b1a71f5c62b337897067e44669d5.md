There are many settings you may want to control from the server level. Registration and security of the modules come immediately to mind. And many of these settings are easily managed in the IIS Manager GUI, AppCmd. exe, or PowerShell. We will cover more administration topics later, but it suffices to say that it would be a good idea to identify which settings from the server level you will be customizing on your new site and plan for disallowing inheritance once your new site is created.

# Creating a Simple Website

You can use the GUI administration tools, the AppCmd. exe, utility or PowerShell to create new websites in IIS 8, depending on your comfort level and scripting needs. PowerShell will be covered in more detail later, so for now we will continue creating the site, planning is required to determine the appropriate settings for the new site:

+   * What IP address should be associated with the site?
* What TCP/IP port number should be associated with the site?
* Will you use a custom host header in the URL?
* What application pools will use the site's applications?
* Where will the virtual directory point to locate content for the site?

# Site Setup via IIS Manager
