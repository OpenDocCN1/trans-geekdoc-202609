# PERFORMING A FULL SERVER BACKUP FROM THE COMMAND LINE

Windows Backup's command-line component, wbadmin.exe, can be used in cases where you want to script backup operations or when you prefer to use the command line to maintain a server computer. These steps assume that you are creating a scheduled full server backup using the command line:

+   1. Open an elevated command prompt. You must be a member of the Administrators or Backup Operators group to perform these steps.

+   2. Enter the following command:
wbadmin.exe enable backup -vssFull -schedule:02:00 -addtarget:E: -include:C:\nThe vssFull switch indicates a full server backup, and -addtarget defines the destination path to store the backup. -include:C:\ indicates that the C drive should be included. When you use a drive line with -include, you must include the final backlash. Figure 32-4 shows the result of this command.

+   3. Enter the following command to start the backup you just created:

wbadmin.exe start backup
