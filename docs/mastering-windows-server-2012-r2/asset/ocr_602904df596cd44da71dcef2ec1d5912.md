At this point, the helper can manipulate the mouse and keyboard of the remote desktop to demonstrate any tasks. This is shared control. In other words, both the helper and the user have control over the desktop.

It's useful if the helper and user are able to talk over the phone during this process, but it's not necessary. The Windows Remote Assist dialog boxes include a Chat feature that allows each of the users to type questions and comments.

Additionally, the user being helped could end the session whenever they want by clicking Sharing or Fause.

# Windows Remote Management Service

The Windows Remote Management Service (WinRM) will allow you to issue any command-line command from one computer against a remote computer.

For example, you might be working on a Windows 7 or Windows 8 computer, but you want to query some information from a remote server. If the server has been configured with WinRM, you can execute a WinRS command-line from the desktop system and get the results just if you were at the computer or connected with RDC.

One of the benefits of this is that you do not to consume one of the remote sessions for a server or even launch RDC. You can simply enter the command at your command prompt.
The following are the two commands used by the Windows Remote Management Service:

WinRM The WinRM tool is executed on the remote server and enables the listener to listen and respond to WinRS requests.

WinRS The WinRS tool is executed from the command line on a desktop or other server accessed by an administrator. It allows the administrator to execute any command-line commands against the remote server.
