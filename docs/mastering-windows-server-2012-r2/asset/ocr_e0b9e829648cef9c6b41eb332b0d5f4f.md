# INSTALLING ACTIVE DIRECTORY FROM MEDIA

In a previous step we mentioned that you could use NTDSUtil to create a kind of snapshot from your current Active Directory and then use this point-in-time copy to promote a new domain controller. The next step is to copy this snapshot to your portable disk drive or then install a domain controller using this media. If you want to know how to create media like this, there is a detailed guide on TechNet
