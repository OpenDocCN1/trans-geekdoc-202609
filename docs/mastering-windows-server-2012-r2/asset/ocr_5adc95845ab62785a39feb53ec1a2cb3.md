application dependent. Older legacy Windows applications looked at a name and considered it NetBIOS TCP/IP-based applications thought it a hostname. This affects how the name is resolved, and it is still part of the Windows operating systems.

Examples of this include the net view command and the ping command. The net view command is a command from the ancient days of LAN Manager, which relied on NetBIOS. If you attempt to connect to a server using the command, you will see the NetBIOS cache populated with the server name. This is displayed with nbtstat -c The cache can be cleared

```
rem view the NetBIOS cache
C:\Users\Administrator.BF1>nbtstat -c
```

When you ping a server, the DNS process is used because it was written as a TCP/IP utility. You can see that it resolved the server via DNS by displaying the DNS cache with the ipconfig /displaydns. The cache is cleared with ipconfig /flushdns.
