This utility is not on the default installation of Windows Server 2012 R2 or Windows 8 since they don't need it, but it is in the Windows\System32 folder of Windows Server 2008 and Windows Vista.

You can configure this utility to run on clients that need it with the following steps:

+   1. Launch the Group Policy Management console (GPMC) by pressing the Windows key and choosing Group Policy Management.
2. Browse to the Deploy Printers GPO in the domain, right-click, and select Edit, as shown in Figure 16.23.

# DEPLOYING VIA GPO DIRECTLY

You can also deploy printers from the Group Policy snap-in. Go to the Policies\Windows Settings\Deployed Printers section, and right-click its folder. From the context menu, choose Deploy Printer, and browse to the desired printer.

+   3. Browse to the Computer Configuration\Policies\Windows Settings\Scripts (Startup/Shutdown) node.
4. Double-click Startup, and click Show Files.
5. Click Add. Click Browse, and select PushPrinterConnections. Click Open.

Notice that this is empty now. You need to copy the PushPrinterConnection.exe utility to this folder. Once the file is placed, close Windows Explorer.
