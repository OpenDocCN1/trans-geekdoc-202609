# ELIMINATING LOGON SCRIPTS USING GROUP POLICY PREFERENCES

Many companies are still using legacy scripts to apply settings to desktops such as drive mappings and printer mappings. Using logon scripts is archaic in comparison to the new and improved capabilities of GPP.

Many other companies have switched to using GPP when possible to eliminate some, if not all, of the settings in their logon scripts. You can use the following preferences in lieu of logon scripts:

+   **Mappings** Drive mappings can now be targeted to "just-in-time" mappings that make more sense for users. Item-level targets can be used in conjunction with mappings to only provide access to data based on user having the correct application, with the right path installed, and only when in a Terminal Services session.

+   **Printers** Printers are often hard to manage for medium and large organizations that have mobile users. When a user goes to a branch office, it can be difficult for the user to find and configure the correct printer. The GPP for printers can be used to map all printers in the company. When a user with an item-level target (such as an IP address or AD site), users will get the printer they need in the branch office, because they are in the branch gyrations

+   **Registry** With the new registry preference, any registry entry can now be placed in a GPO without any custom ADM template or ADMX file. This includes binary and multstring values, which were not possible in ADM templates.

# The New and Improved GPMC

The GPMC has been around for a while. The first generation of the GPMC was revolutionary and made administration of GPOs much easier. This generation of the GPMC continues to make the administration of GPOs easy, efficient, and stable. No more are the days when you needed to launch the Active Directory Users and Computers to create, link, and manage GPOs. That was archaic to the least. Now, the new GPMC can run on Windows Server 2012 R and Windows 8.

+   - You will need to install the GPMC because it is not installed by default. For your Windows Server 2012 R computers, you can install the GPMC from Server Manager.

+   1. Launch Server Manager, and select the Features menu.

+   2. From here, you just need to click the Add Features option, which will give you a full list of tools you can install, as shown in Figure 9.28.

+   3. Select the Group Policy Management option, which will take you through some gyrations to get the tool installed.

+   4. After a restart, you will now have the GPMC installed.
