As you saw in Figure 12.81, TableScheduler has two other objects that run on a weekly basis. We discuss both of them. First, we'll talk about GarbageCollection. GarbageCollection is configured to run on a weekly basis, but you can invoke it as needed. The GarbageCollection job cleans up the chunk store by removing unused chunks, which releases disk space. You can see that it is an important job.

To manually invoke Start-Dedupjob -Type GarbageCollection -volume E:

This will queue the job until the system is idle, or you can run it from within Task Scheduler to accelerate it.
