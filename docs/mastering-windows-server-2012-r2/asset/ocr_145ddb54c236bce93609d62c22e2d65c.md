Starting with Windows Server 2008 R2, you can actually view symbolic links such as Explorer.

# Quick Migration and Live Migration

It's impossible to have a full disclosure of server virtualization without mentioning quick migration and live migration. These are related but different technologies to move virtual machines between hosts. In previous versions of Hyper-V, you had the option to use shared storage with high-speed networks. In this section, we'll introduce you to quick migration and traditional live migration, and later, we will discuss the new Shared Live Migration functionality.

**Quick Migration** Quick migration works by saving the state of the VM, transferring control to another node, and restarting on that node. This process is predictable and reliable but not so fast that it passes unnoticed. Time is lost during saving and restoring the VM state, and it may take a number of minutes for VMs with a lot of memory.
