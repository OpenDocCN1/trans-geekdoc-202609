## USING THE NEW FEATURES FOR USER AND GROUP MANAGEMENT 443

Let's do some work. In this example, you'll create a user. Navigate to |BigFirm| using the new navigation node that you just created in the list view, and click New ➤ User in the Tasks panel. That opens the dialog box in Figure 8.72.

# FIGURE 8.72
Creating a new user in ADAC

![](img/41a83208e6906a3732620203b836cea7_478_0.png)

Wow! That's a hefty dialog box, and it might be a bit daunting at first. Let's take a look around before you do anything. First, let's simplify things. You only need to complete the fields with a * beside them to create a user. The left navigation pane tips you off that this window is broken into sections. You can use the Sections button on the top right to hide or reveal those sections. This allows you to hide any sections that you never use. ADAC will remember what sections are hidden or revealed.

When you see that we've reorganized the Organization in the center of the dialog and Encryption options sections on the upper-right side of the dialog in Figure 8.73. We have filled out the dialog box to create a user named Greene Green. Instead of navigating through a wizard and opening the user properties to complete the operation, you can do everything here. Every commonly used option for setting up the user is available in this dialog box. initially daunting window will reduce the amount of time it takes to create and configure a user account.

# FIGURE 8-73
Removed dialog box sections in ADAC

![](img/41a83208e6906a3732620203b836cea7_479_0.png)

We have just entered the full name and the SAM account name to create this user. What happens if you don't enter the non-mandatory password? The account will be created, it will be disabled. You will not be able to enable it because the lack of a password contravenes the default domain password policy. You can reset the password and enable the account. Here’s what you should do:

- 1. Enter the username details.
2. Specify the password.
3. Add the user to a group.
4. Click OK.

The user is created and added to the OU that you are in. You probably noticed not every single attribute or property for user objects was available. The common ones were, but lots of others weren't. In Active Directory, you will probably configure those properties via policies instead. However, you can still access them. Figure 8.74 shows the properties of the user account in ADAC. A new section appears in the window called Extensions. This allows you to view and configure advanced features of the object.

You can simplify the view by clicking the Sections button to remove Member Of section, for example. Let's create a group called Helpdesk. Figure 8.77 shows the completed dialog box to create the new Helpdesk group. Again, you can enter a lot of information into a single dialog box, by going through a wizard and editing the group object properties afterward. Do the following:

- 1. Enter the group name, and fill in SamAccountName.
2. Specify the group type and scope.
3. Select the "Protect from accidental deletion" check box so you can't delete the group accidentally.
4. Specify an email address.
5. Edit the description.
6. Add users to the group.
7. Click OK.
