# CHAPTER 22 ADDING MORE LOCATIONS: SITES IN ACTIVE DIRECTORY

If you don't make the DC GC, you should enable universal group membership caching on the site. When this is enabled, the domain controller will cache the user's group membership data the first time the user logs on and to create the user's token for subsequent logins.

Universal group membership for users who have logged onto the DC is refreshed every eight hours. The DC can hold universal group membership cached data for as as 500 users.

The primary reason why you wouldn't want to make a DC GC in a remote site is that the replication of the global catalog will consume too much bandwidth. For example, bandwidth utilization is already at 80 percent, making the DC GC could cause utilization to peak at 100 percent.

You can make any DC GC by modifying the NTDS Settings properties sheet of the server. Figure 22-7 shows this sheet with the Global Catalog box selected.
