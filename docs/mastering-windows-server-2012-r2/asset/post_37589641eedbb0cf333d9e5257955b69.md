
Add the following component into pass 4, “4 specialize.” You use ComputerName, well, to set the name of the computer. That's not very mysterious. You set it to *. # Using An Answer File

This process is easy enough. You need to store the file autounattend.xml on the root of removable storage. You will then boot up the new server using the correct Server 2012 R2.

# A WORD OF CAUTION

Don't go with this stuff on a machine that is valuable to you. Test it in a lab first. This is a destructive process; in other words, the hard disk on the computer you use for this will be wiped.

In our example, as soon as the server starts to boot from the DVD, you should also insert the removable storage that contains your answer file. The supported forms of removable storage are:

- **CD/DVD**: This requires your server to have two drives: a DVD drive, to boot and install Windows Server 2012 R2 from, and another drive to read the answer file.
- **Disk**: How many servers have drives? This will be OK for lab machines.
- **USB Memory Stick**: This is the most likely of all the choices.

Pick your choice of media that is suitable for the server you are going to build, and copy the answer file into the root of that storage device. If you are using a virtual machine, then here's a neat CD/DVD to the virtual machine where you intend to install Windows 2012 R2. Make sure your DVD has mounted the correct ISO for installing Windows. Create an ISO file that contains only your autattend.xml file. You don't have a tool for that? That's OK, because there is one in ADK. Try running the following from your Deployment and Imaging Tools prompt:

```
oscdimg -n C:\answer\answer.iso
```

This will create an ISO file on C:\ called answer.iso using contents of the folder C:\Answer. Please make sure you have not placed your autattend.xml in C:\ and you are trying to make an ISO file from your entire hard disk It's an easy trap to fall into. The syntax for the previous is as follows:

```
oscdimg -F<Folder as a Source> <Location and Name of the ISO Image>
```

OK, let's get rocking! Insert your answer file media as soon as the server has started to boot from the DVD. The first few times you do this you should watch what goes on to make sure the process runs cleanly. What happens is that Windows Server 2012 R2 silently kicks off an installation, reboot, and waits for you to enter the administrator password so you can log in. If the answer file has a mistake, then something else will happen as the following:

- A dialog box with a question will appear and wait for human input.
- An error dialog box will appear.
- A critical failure will occur and cause a reboot.

You will need to revisit your answer file in WSIM if you have gotten everything right, then you now have an answer file that completely automate your manual installations of Windows Server 2012 R2. You've also gotten a peek into some of the steps required for automated installations.
