# USING SERVER MANAGER TO CONFIGURE YOUR SERVERS

Obtain a configuration for the new server from your network administrators, and then enter the details similar to how we entered them in Figure 2.27. Click OK to save your settings, and close all the remaining dialog boxes.

There is a command-line way to do this using the netsh command. You will need to find the name of your network interface, and you can use the ipconfig command to get it:

```
C:\netsh interface ip set address="Local Connection" static 192.168.1.49 255.255.255.0 192.168.1.1
```

The syntax for the netsh interface ip set address is as follows:

```
C:\netsh interface ip set address="Name of the Network Interface" static <Desired IP Address> <Desired Subnet Mask> <Desired Default Gateway>
```

That saves the address configuration of the server. You'll also want to set the DNS server addresses. This first netsh command will set the DNS server:

```
C:\netsh interface ip dns "Local Area Connection" static 192.168.1.21
```

The syntax is as follows:

```
netsh interface ip dns "Name of the Network Interface" static <IP Address of the Primary DNS Server>
```

If you have a secondary DNS server, then you should also configure it. The command is slightly different:

```
C:\netsh interface ip add "Local Area Connection" 192.168.1.22
```

Your IPv4 configuration should now be applied. You might want to run the ipconfig command from prompt to verify your work:

```
C:\ipconfig
```

# RENAMING THE SERVER

Every Windows computer should have a unique name to identify it on the network. Every organization has its own practice. Some use structured names that describe the location, some use nondescriptive names with incremental numbers, and some names of characters from their favorite show.

To do this, you should click the link next to Computer Name, which you can find in Server Manager, as shown in Figure 2.28, to control the name of this server or the domain membership of this server. You should rename this server according to the naming standards of the organization. Click Change to do this in the dialog box shown in Figure 2.29.
