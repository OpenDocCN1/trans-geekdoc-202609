# # Starter GPOs

Microsoft is making strides to make GPO management easier and more efficient. The first
atempt at this is using Starter GPOs. You can use a Starter GPO to re-create a suite of GPO settings,
only to use the Starter GPO again and again. Say, for example, you are in charge of ensuring that Internet Explorer is configured properly for your organization. You could create
a Starter GPO that includes all of the required Internet Explorer settings and save the Starter
GPO. Then, when any new GPO is created, it uses the Starter GPO you created to ensure the
Internet Explorer settings are included.
