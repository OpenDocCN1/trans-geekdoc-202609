# THE BOTTOM LINE

Reporting The Remote Access Reporting section of the console is particularly interesting and useful when you need to generate reports on DirectAccess usage. All you need to do is input start and end dates and then click the Generate Report link. You can also use the Configure Accounting action in the Tasks pane to configure your Remote Access accounting and data logging, as shown in Figure 21.40. The accounting logs can be stored either on a remote RADIUS server or locally in a Windows Internal Database.
