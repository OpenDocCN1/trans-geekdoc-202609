Now that you have nodes set up, your cluster can provide failover to any of the workloads you wish to support.

You may have noticed in Figure 11.18 two other columns next to Status:

+   ◆ Assigned Vote

+   ◆ Current Vote

Windows Server 2012 R2 provides an advanced quorum configuration option where you can add or edit quorum vote by node. Out of the box all nodes are assigned a vote. You may decide to remove votes from specific nodes to help with disaster recovery solutions. The most common situation is when you have a geocluster and want to remove the votes from your recovery site; if you consider doing this, refer to Microsoft's guide on quorum considerations for DR found here: http://tinyurl.com/c11ClusterDR.
