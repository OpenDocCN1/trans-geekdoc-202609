
4. In your Terminal session type in the following command:

```
dsconfig -aladmins enable -groups BigAdmin@Bigfrim.com, Enterprise BigAdmins@bigfrim.com
```

The commands require you to use cleartext passwords, so if your Active Directory does not allow them, you will have to set this up to be enabled for Services logging. Another tool that is commonly used is audit. This command will look at the internal state of directory services and records, allowing you to enable logging and change your statistics.

5. Run the following command:

```
odutil set log debug
```

This command will set log logging on the device to Debug mode, so if you have any issues connecting to your Active Directory domain, you can run debugging-event depth detailed logs. The logs for odutil are stored at /var/log/opendirectory.log.

## Troubleshooting

In this section, we offer some troubleshooting tips that will come in handy if you experience these issues while trying to bind your Mac to Active Directory:

**You have an issue with AD domains ending in .local.** Many people have reported issues connecting to an Active Directory domain that ends with .local (such as is used with Windows Small Business Server networks). Bonjour, Apple's implementation of Multicast DNS, does not see .local as a valid top-level domain and assumes it should be resolved through Bonjour. Because of this, the Mac will not query the DNS server to retrieve the .local addresses. You can enable your Mac to look up local by adding your search domain, as shown in Figure 18.42.

Figure 18.42
Adding to search domain

![](img/41a83208e6906a3732620203b836cea7_1011_0.png)

**Active Directory does not respond when binding.** If you receive an error that the Active Directory failed to respond, there are a few things to check:

- Verify that your network settings specify a valid DNS server.
- Verify that SMB packet signing has been set correctly.

Active Directory stops responding. Various versions of OS X have had challenges connecting to Active Directory. Make sure you have the latest updates for the operating system.
