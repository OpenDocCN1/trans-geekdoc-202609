# Building Trusts WITH NETDOM

Now you'll learn how to build a trust with netdom. Trusts of: external (domain-to-domain nontransitive) and forest (forest-to-forest transitive) trusts. netdom can create external trusts. By now, it will be easy to specify who to trust and present admin credentials for each domain. Here's the syntax:

```
NETDOM trusting_domain_name /Domain:trusted_domain_name
[/User]: /Password:[password | *]
[/User]: /Password:[password | *]
```

Remember that in the most basic trusts, a trust is a trusting and a trusted domain. You may choose to make it two-way, even if you do, netdom insists that you call one domain trusting and the trusted.(Of, if you're building a two-way trust, it doesn't matter which you made the trust and which you are making the trust.)
