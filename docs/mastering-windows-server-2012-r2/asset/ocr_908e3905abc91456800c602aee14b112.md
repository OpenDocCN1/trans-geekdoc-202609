# User-specific LGPO

Finally, you can configure a very granular LGPO on every Windows Server 2012 R2 and Windows 8 computer. This policy is geared to target individual user accounts. There are only user-based policy settings this is in the LGPO, and the settings target only a single user.

The caveat to using this LGPO is that the user must have an account in a local SAM of the computer that you are configuring.
