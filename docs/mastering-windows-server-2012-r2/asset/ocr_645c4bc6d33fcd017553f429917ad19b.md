# Managing Shutdown Tasks with Logoff Scripts

While you were setting up a logon script using Group Policy, you likely saw an option for logoff scripts.

A logoff script runs every time a user logs off. This allows administrators to define tasks that can be run every time a user logs off. It is set up identically to how you set up a logon script. You can see an example of a configured logoff script in Figure 26.57.
