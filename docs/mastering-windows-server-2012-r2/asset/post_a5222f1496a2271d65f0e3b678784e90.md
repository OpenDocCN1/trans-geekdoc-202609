# Server Core Survival Guide

Before getting into the details, you need to learn a few survival tips for handling this operating system. We'll discuss using Task Manager to control processes, start tasks, and view performance. Then we'll cover basic commands that we typically neglect when flashy GUI is available. These will help you perform routine administration tasks and allow access to the network.

## Switching between Server Core and the GUI and Vice Versa

I'm placing this at the top of the Survival Guide because it may prove to be very handy you need to switch from Server Core to the GUI and vice versa. Many administrators complete the initial setup using GUI and switch over to Server Core for production.

You will need to download the script here: http://gallery.technet.microsoft.com/scriptcenter/Switch-between-Windows-9680265d/file/70875/1/SwitchGUICORE.zip.

This script is used no matter which version you are switching to. Before you run the script, you need to enable scripts on; they are disabled by default. To do this, run the script, as shown in Figure 3.5.

![](img/41a83208e6906a3732620203b836cea7_144_0.png)

Where prompted, add the integer value as follows:

- 1—Switch to Server Core
- 2—Switch to the GUI
- 3—To install the GUI from online resource

Be patient; this process takes a few minutes to complete. Once it has finished, you will be prompted to reboot the server. When the server reboots, you should be in the version you need.

## Accessing Task Manager

Server Core provides a few graphical user interfaces. The most important is Task Manager. It's the same one you have come to know and love with other Windows versions. There are two primary ways to open Task Manager.

- Ctrl+Alt+Del: You can open the trustworthy Security dialog box by pressing the Ctrl+Alt+Del key combination. On this page, you can opt to lock the workstation, log out, or start Task Manager.
- Ctrl+Shift+Esc: You can use the “MSCE secret handshake” method of Ctrl+Shift+Esc to start Task Manager. Now that you know this, you're part of an elite club. It was once one of these undocumented features.

## Closing the Command Prompt

As a system administrator, you close applications when you've finished using so as not to consume valuable resources, such as memory and CPU cycles, right? So, you will probably close the command prompt after completing a task while logged onto Server Core.

After realizing you have closed only your interface to the OS, you can perform the following steps to return to the command prompt:

- 1. Open Task Manager, as discussed earlier.
- 2. Click File > New Task (Run). This is just like the Run prompt you find on the Start Menu.
- 3. Enter cmd and then click OK, as shown in Figure 3.6.

![](img/41a83208e6906a3732620203b836cea7_145_0.png)
- 4. Enter PowerShell at the command prompt, which will switch you to the PowerShell command prompt.

## Changing the Administrator's Password

You'll use PowerShell for most administration tasks, but there are still a few command-line tools that are easier to use, and we include them in our examples.

After logging into a Server Core installation for the first time, you might be wondering how you can change the administrator password in the future. You can do so with the net user command:

```
PS C:\Users\administrator>net user administrator *
```

Type a password for the user:
Retype the password to confirm:
The command completed successfully.

The asterisk prompts you for the new password. The command is a really old one. It was old when NT was new technology. One of the ways to change a password is using the PowerShell cmdlet Set-ADAccountPassword. The following is the complete cmdlet with properties:

```
Set-ADAccountPassword [-ADAccount>] [--AuthType <Negotiate> | <Basic>]
[-Credential <PSCredential>] [-NewPassword SecureString>] [-OldPassword
<SecureString>] [-Partition <string>] [-PassThru switch] [-Reset switch]
[-Server <string>] [-Confirm] [-WhatIf] <CommonParameters>
```
