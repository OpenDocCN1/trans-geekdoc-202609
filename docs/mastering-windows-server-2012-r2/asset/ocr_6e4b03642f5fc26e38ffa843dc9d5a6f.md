Once youve configured a static IP address and DNS suffix on your non-domain-joined server, follow these steps to install the DNS role: as shown in Figure 6.5.

+   1. Open Server Manager, click Dashboard, and select the “Add roles and features” option, as shown in Figure 6.5.

+   2. At the “Before you Begin” dialog box inside the Add Roles and Features Wizard, click Next to continue.

+   3. Choose the “Role-based or Feature-based Installation” option from the Select Installation Type box; then click Next.
