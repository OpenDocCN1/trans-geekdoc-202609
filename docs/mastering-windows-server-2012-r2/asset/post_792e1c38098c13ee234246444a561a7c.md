# Deduplication: Disk and Network

Windows Server 2012 introduces Data Deduplication as a native storage feature. Data Deduplication is a more efficient way of storing data. With the ever-increasing need for storage in cloud technologies, you can imagine the amount of duplicate files that are stored. Even I have several copies of ISO files or virtual hard disks for USB storage and servers. These files are 3-7 GB each. I'm losing a lot of space by keeping multiple copies and not coming up with a proper library system.

This is a simple example but it brings up another point: files have all same parts and they all take up space. Wouldn't it be cool if you could identify those common pieces, create a single master reference on disk, and then point to it for every other file that has that common? You have this ability in Data Deduplication.

Data Deduplication in Windows uses a concept called the chunk store. A file gets split into variable-size chunks usually between 32 KB and 128 KB, on average a chunk is around 64 KB. These chunks are compressed and stored in the chunk store. Each chunk is stored in a container, which grows up to 1 GB in size before a new container is created. You can view the chunk store and its contents in a folder called System Volume Information. The folder by default is locked down to the System account, so you must take ownership of it and ensure that the account remains in full control. A repair point replaces the normal file. If the file is accessed, the repair point shows where the data is stored and restores the file. See Figure 12.70.

Although not installed by default, Data Deduplication is designed to be easy to deploy. It has been designed to reduce 20% impact on the users; in fact, the users won't notice anything. You can turn on Data Deduplication on any of your primary data volumes with minimal impact on performance. It is designed not to interfere with files that are new or are currently being written to. Rather it will wait, and every hour it will check for files that are eligible for deduplication. You can reschedule the process according to the needs of your company.

Eligibility for deduplication starts with files that are over three days old (again this is configurable based on needs), and it excludes files that are smaller than 32 KB, extended attributes, or are encrypted. If you have other files that you don't want to be part of the dedup process, this is also configurable.

Deduplication happens on network traffic as. As traffic is sent or received, it is assessed to see if it can be deduplicated, effectively reducing the potential amount of traffic that has to be sent or received. With storage deduplication, you cannot modify a storage or data type for the network ded.
