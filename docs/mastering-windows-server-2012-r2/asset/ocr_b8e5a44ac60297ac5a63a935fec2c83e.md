There are two major types of settings, as we mentioned earlier. Computer Configuration settings are applied to computers at startup and during the background refresh interval. User Configuration settings are applied to the user accounts at logon and during the background refresh interval. Once you've configured your Group Policy settings, simply simplify the GPME window. There is no Save or Save changes option. Changes are written to the GPO when you click OK or Apply on a particular setting, although the user or computer will not actually see the change until the policy is refreshed.

# Modifying Group Policy Default Behavior

Group Policy is fantastic all by itself, but there are behaviors that you might want to tweak or control. It might seem cyclical, but there are GPO settings to control the behavior of Group Policy and some of its settings. You will find that many of these settings don't need to be configured, but in the instances where you need to make some minor adjustments, they will come in handy.
