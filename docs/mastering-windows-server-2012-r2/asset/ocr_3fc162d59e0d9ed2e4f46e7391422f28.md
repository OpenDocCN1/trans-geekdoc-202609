# PerfView

PerfView is another analysis tool that can be used to simplify the collection and analysis of your performance-related data. Runs at a deeper level than Performance Monitor or PAL utilizes the Event Tracing for Windows (ETW) feature of Windows Server 2012 R2 to collect information. Ordinarily, this type of ETW information can seem complete jargon to you and me, but to performance-monitoring ninjas, as the Windows Performance group inside Microsoft uses, it is translated into an understandable and easy-to-use tool.
