# Finding Commands from A to Z

Command-line references are very handy. There is one in Windows Server 2012 R2 for help on the full installation; however, it has Internet hyperlinks to the explanations for all of those commands. The best location for finding a list of available commands is the Command-Line Reference (http://technet.microsoft.com/en-us/library/cc754340.aspx), which offers an A-Z menu.
- To find a command that will do your job, this is the first place to go.

Most of the PowerShell cmdlets can be located from this parent page (http://technet.microsoft.com/en-us/library/h0b19d4.aspx).
You will see all the administration categories with links to hundreds of cmdlets.

# Reading Text Files with Notepad

In a full installation, use Notepad to edit text files. It's also available in Server Core as well. Notepad utility "old-school"; it was a release of a very early version. It's not as-school as VI, but it has been resurrected from the days of NT. (If you get that command, you are old)
Incredibly, the designers of Server Core were actually thinking about dropping this thing out until the market gets feedback from users. This would have been a huge mistake.
Notepad is an essential tool for Server Core.

We have a sample file called configCommand.txt. To open the text file, use the following command:

```
C:\Users\Administrator>notepad documents\configCommand.txt
```

Using Notepad to construct complex commands. At the bottom of a text file like this one, you can cut, copy, paste, and edit the examples to get what you want to. Then you can copy and paste them into the command prompt. The output can be copied from the command window in the context menu, which you display by right-clicking the window. You paste it back into Notepad.

# Editing the Registry

scregedit.wf is a script developed by the Server Core team to perform common tasks like editing the registry. You can use the parameter /cl to list all commands on Server Core. It may not be as-efficient for what you need to do, but it does list the MSCE handshake for opening Task Manager.
Since scregedit.wf is a VB script, you have to run it through an interpreter. It's located in the System32 folder, so you have to change the directory to it:

```
C:\Windows\System32>scregedit.wf /cli
```

# Rebooting and Shutting Down

There's also a PowerShell command to reboot and shut down the server. You can even enter the reason for the reboot or shutdown as a remark. Use the following command for rebooting your server:

```
PS C:\> Restart-Computer
```

To restart computers you can use this example, which shuts down remote computers (Server01 and Server02) and the local computer (localhost):

```
PS C:\> Restart-Computer -ComputerName Server01, Server02, localhost
```
