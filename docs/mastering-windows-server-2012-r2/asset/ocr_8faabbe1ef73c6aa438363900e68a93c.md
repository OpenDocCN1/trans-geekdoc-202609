Let's assume you're creating 10 user objects and you to set them all with the same password and enable the users. You also want to force the users to change their password when they log in for the first time. You can do something like this:

```
PS C:\Users\Administrator> $pw = Read-Host "Please Enter The Password"\n-AsSecureString
```

```
PS C:\Users\Administrator> New-ADUser "Philipp Witschi" -SamAccountName "Pwitschi" -GivenName "Philipp" -Surname "Witschi" -DisplayName "Philipp\nWitschi"\n-Path 'OU=Users,OU=BigFirm,DC=bigfirm,DC=com' -UserPrincipalName -AccountPassword $pw -Enabled 1 -ChangePasswordAtLogon 1
```

The first line prompts the administrator to enter a password. When the text is entered, the $ to PowerShell pw will be a variable or a container where you want to store a value. The Read-Host cmdlet will prompt you for a value. ASSECURESTRING will convert the value you entered in response to the prompt to enter a secure string. $pw will be stored in memory by this PowerShell session until you overwrite the value or close the PowerShell window.

When you run the command, you're prompted to enter the password. Respond with an easy-to-communicate string that meets the password complexity and length requirements.
The second command will create your user. You can add few flags to meet your requirements:

**AccountPassword** Use the $pw from the previous command. This passes your desired password for the new user object in a secure format.

**Enable** This takes either a 1 (user object to be enabled) or 0 (user object to be disabled) value.

**ChangePasswordAtLogon** This takes either a 1 (a force password change) or 0 (do not force a password change) value.

The result of this is that the user object is created with your desired password and is enabled, the user will be forced to change their password when they log in for the first time.
It seems wonderful to run two commands, doesn't it? It would be for just one. But by this approach, you can repeat for the other users you want to create. Each one would have the same password.

If you wanted to create just one, then you could do everything in one command. This approach will take advantage of PowerShell' speed. You'll need the Read-Host cmdlet:

```
PS C:\Users\Administrator> New-ADUser "Philipp Witschi" -SamAccountName "Pwitschi" -GivenName "Philipp" -Surname "Witschi" -DisplayName "Philipp\nWitschi"\n-Path 'OU=Users,OU=BigFirm,DC=bigfirm,DC=com' -UserPrincipalName -AccountPassword (read-host "Please Enter The Password") -AsSecureString -Enabled 1 -ChangePasswordAtLogon 1
```
