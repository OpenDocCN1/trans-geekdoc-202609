The screen also allows you to document the share. It makes sense to describe the shared folder for someone else needs to diagnose or fix an issue and you’re not around to help. Enter a description for the share.

The Other Settings screen provides additional configuration options for your share. The “Allow caching of share” option will be enabled by default. You also have the options of encrypting the data and enabling access-based enumeration.\ It is best practice to lock down permissions on a shared folder in two ways. The first is to lock the permissions on the NTFS folder; you have already done this. The second is to lock down permissions on the share. Click the Custom Setting button, select the Share tab, and set the share permissions as follows:

| Group | Permission |
| --- | --- |
| BF2':Administrators | Full Control |
| Everyone | Read |
