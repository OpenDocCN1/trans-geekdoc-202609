You need to collect the following data for the source server in order to apply similar settings to the target member server after the domain controller promotion:

+   - Server name.

+   - IP addresses (IPv4 and IPv6).

+   - Assigned Active Directory state.

+   - Assigned OU.

+   - Applied GPOs and RSOP output. You can type `gresult /scope computer > GPOResult.txt` to push the results to a text file.

+   - Assigned FMSO roles. These will be transferred if the server will be decommissioned.

+   - Global catalog role.

+   - Additional services such as DHCP, File and Print Services, and Internet Authentication Services for VPN connections.

Finally, perform system state backups for all domain controllers and file system backups for essential services to be migrated outside Active Directory Domain Services (AD DS).
