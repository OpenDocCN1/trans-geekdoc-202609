# START OF AUTHORITY RECORDS

A Start of Authority (SOA) record is a single record within each zone. It has information about what DNS server controls this zone and parameters on how to resolve the records. It contains several values that should not be modified by editing the record. You should edit them on the Start of Authority (SOA) tab in the properties of the zone, as shown in Figure 6.23.
