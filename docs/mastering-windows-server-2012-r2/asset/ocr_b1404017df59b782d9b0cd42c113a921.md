We've browsed to \BigFirm\Users and added that OU to the control in the right side of the window. Did noticed that you can use the "Connect to other domains" control at the bottom right to navigate to OUs or containers in other domains in the forest? You can use this to manage many domains in many forests at once with ADAC.

In Figure 8.70, you can see that we have clicked OK to add the \BigFirm\Users OU to the list view in ADAC. Now you can quickly get to the OU where you are managing user accounts, another time-saver for day-to-day administration. The Tasks pane now contains new actions, allowing you to perform administration within the OU.
