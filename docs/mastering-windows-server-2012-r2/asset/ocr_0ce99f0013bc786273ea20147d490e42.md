# Installing the Remote Access Role

Since you've already deployed the Network Policy and Access Services role, here are the remaining high-level steps you'll need to perform to configure your server as a VPN server and connect with a client:

+   1. Install the Remote Access role.
2. Configure Routing and Remote Access.
3. Add policies to allow connections.
4. Configure user dial-in permissions.
5. Configure the VPN client and connect.

The following sections will walk you through these steps to help you get your VPN server up and running. Here's what you need to deploy the Remote Access role:

+   1. To begin, log on to your domain-joined Windows Server 2012 R2 installation with an account that has domain administrative permissions, and from the Server Manager Local Server > Manage, choose the Add Roles and Features option.
2. In the “Before you Begin” dialog box, click Next.
3. Ensure that “Role-based or Feature-Based Installation” is selected in the Select Type dialog box, and then click Next.
4. In the Select Destination Server dialog box, leave the default option of “Select a Server from the Server Pool” checked, confirm that your server is highlighted in the Server Pool section, and then click Next to continue.
5. When you reach the Select Roles dialog box, scroll down until you find the Remote Access option in the Roles list, and check the box beside it.
6. You'll be prompted to add some required features, such as the RAS Connection Manager Administration Kit (CMAK) and Web Server (IIS), so just click the Features button in the window that pops up.
7. Click Next to continue.
8. Leave the features as they are in the Select Features dialog box, and then click Next twice.
9. Check the box DirectAccess and VPN (RAS), then click Next three times, leaving the Web Server Role (IIS) selections at their defaults.
10. In the Confirm Installation Selections dialog box, ensure that your settings have been chosen correctly, and then click Install to begin.
11. After the installation completes, click Close.
