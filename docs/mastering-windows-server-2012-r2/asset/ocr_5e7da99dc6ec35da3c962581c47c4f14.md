Second, you must plan to allow the embedded FTP publishing service to access anonymous connections and support basic cleartext authentication strings. You can also limit access to anonymous users or specific users/groups (see Figure 19.25). Additionally, you must decide whether allowed users may write or only read.

To prove that FTP Publishing services have been successfully embedded into the website, in the Connections pane need to expand the host where FTP was added. A new group of icons for FTP management now appear in the Features view; which of the more notable features are:

+   * FTP authorization rules allow you to configure more rules that will either allow or deny a specific group of users a particular permission level of access to the FTP services on this site.

+   * FTP address and domain restrictions allow you to restrict FTP services to only a particular IP address, subnet range or domain name.

+   * FTP User isolation will allow you to prevent users from accessing other user's directories.
