# UNDERSTANDING ACTIVE DIRECTORY INTEGRATED

The third zone, Active Directory Integrated, is the predominant implementation of Windows DNS servers. The name Active Directory says it all:

+   - First, the DNS records are stored in the Active Directory database rather than a text file.
- Second, the zones are replicated to all other Active Directory domain controllers in the domain rather than zone transfer process.

Since the Active Directory database uses multicast replication, changes can be made to the DNS zone on any domain controller, and with the integration of DNS in Active Directory, the coupling of DNS and domain controllers became the norm. For more information concerning the replication process, refer to Chapter 22.

Like the standard, an Active Directory integrated zone can be created with the New Zone Wizard. On the first page of the window, shown in Figure 6.17, it says “Store the zone in Active Directory”–check box.
