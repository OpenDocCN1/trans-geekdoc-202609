# CHAPTER 16 SHARING PRINTERS ON WINDOWS SERVER 2012 R2 NETWORKS

If you're running Server Core on a server and want to make this print server including the Print and Document services, you need to activate PowerShell. The Server Core command line, type PowerShell. Notice that the command line starts with PS to let you know you are in the PowerShell application.

Then enter the following commands on the Server Core command line:

```
PS:\Users\Administrator>ipmso ServerManager
PS:\Users\Administrator>add-WindowsFeature Print-Server
```

After a moment, you will see the results of the installation, as shown in Figure 16.15.

# GET-WINDOWSFEATURE TO INSTALLED ROLES

You can use the Get-WindowsFeature cmdlet to provide configuration information on your Server Core installation. This also gives you the correct spelling and syntax of all the roles you want to add. For example, the printer role is identified as Print-Services.

At this point, you'll have a decision to make. Do you want to manage the Print-Services role from the command line or from a GUI? If you want to manage it from a GUI (which is much more intuitive), you can configure the Server Core to be remotely administered. Chapter 17, "Remote Server Administration," how to do this.

Network Discovery needs to be enabled on the Server Core for print server management. You can enable this with the following PowerShell command:

```
PS:\Users\Administrator> netsh advfirewall service set printfile enabled
```

You'll also need to enable the server to be managed by an MMC on a remote server with the following command. Even though it appears on two lines in the book, enter it as a single PowerShell command.

```
PS:\Users\Administrator> netsh advfirewall firewall rule group = "Remote Administration"
 new enable = yes
```

Once the Server Core is configured for remote administration, you can then remotely administer it from a server that has the full operating system installed. For example, you may have 10 file and print servers all running Server Core but one central server with the full operating system installed that you'll use to remotely administer all servers.
