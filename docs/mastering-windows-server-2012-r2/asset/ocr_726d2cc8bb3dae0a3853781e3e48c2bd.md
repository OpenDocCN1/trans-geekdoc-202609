# Renovating IIS Construction

Altering the construction of IIS is as easy as using the A/C adapter of your laptop computer for plugging in your mobile phone charger instead! Feel free to add or remove modules for exploration, testing, or actual production. The addition of a feature to IIS is not a permanent decision. You can remove the feature down by deselecting the check box.

If you did not perform a full installation of all Web Server services in the OS when you initially installed IIS, then you will need to add the appropriate role service before that role service's associated native modules will be available to add to IIS. The “Adding Services to the Web Server for Bigfirm” section shows how to register a native module using the OS, allowing Windows Server 2012 to trust the code and give it unrestricted access to all resources. With any equals code, be careful to register only native IIS modules from trusted sources because they will have privileged access to the system.

# Add Role Services to the Web Server Role for Bigfirm

In order to configure the website in our example, you will need ASP page support on the Oranges website until you rewrite some of the content, and then you will use HTTP Redirection to point visitors to the new content it is written. You can add role services to an applied role server via the Web Server Manager, AppCmd.exe, or PowerShell. For example, to add the ASP role service to an existing web server role on the BFI server at Bigfirm by the Web Server Manager, follow these steps:

+   1. Launch Server Manager.

+   2. Select the IIS role in the left tree pane.

+   3. Scroll down to the right details pane to reach the Role and Features section for a summary of the web server roles that are installed, as shown in Figure 1.2.

![](bbox=[0.118, 0.613, 0.881, 0.763])

+   4. Click the Tasks drop-down menu on the role and select Add Roles and Features.

+   5. In the Roles and Features Wizard dialog box that pops up, advance to the Roles page, and select the ASP role service located under Web Server (IIS)\Web Server\Application Development.
