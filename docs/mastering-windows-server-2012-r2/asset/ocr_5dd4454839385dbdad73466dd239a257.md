netsh The netsh command is designed to handle all network-related configuration settings and displays that will arise in the future. The command to display the routing table is netsh interface ipv4 route or netsh interface ipv6 route.

Each command displays the same routing table, but the information and presentation vary. The command route displays a more class-based routing table and is familiar to many. You should feel comfortable by the end of this chapter with output such as that in Figure 20.5, which shows a sample of the IPv4 routing table.
