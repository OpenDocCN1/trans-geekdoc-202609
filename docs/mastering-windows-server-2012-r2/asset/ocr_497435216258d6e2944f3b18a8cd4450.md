# CREATING GROUPS WITH POWERSHELL (ADAC Windows PowerShell History)

In the previous examples you created OUs and users using PowerShell. We showed you the command you needed to create the object. But what if you don't know the command or could use some help? If you followed the steps for creating the groups using the Active Directory Administrative Center, then you already have everything in front of you:

+   1. After you create the G_SalesAdmin group, click the down arrow with a circle on the right side of where it shows Windows PowerShell History in your console, as shown in Figure 7.22.

Now you will see all the tasks previously executed in the ADAC. You should also see the last two New-ADGroup commands, as shown in Figure 7.22.

+   2. Click the + sign on the left side of the cmdlet to expand and see all its parameters.

![](bbox=[0.176, 0.378, 0.893, 0.693])

+   3. Right-click the New-ADGroup cmdlet, copy and paste it into a PowerShell window. Change the Name and SamAccountName of the group to something else, for example:

```
New-ADGroup -GroupCategory:"Security" -GroupScope:"Global" -Name:"G_SalesPowerUsers"
-Path:"OU=Users,DC=bigfirm,DC=com" -SamAccountName:"G_SalesPowerUsers"
-Server:"DC02.bigfirm.com"
```

+   4. Execute the command by pressing Enter.

If you don't receive any errors, you will have just created another global group.
