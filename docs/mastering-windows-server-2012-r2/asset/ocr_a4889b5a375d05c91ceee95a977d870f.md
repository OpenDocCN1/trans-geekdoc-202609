# Exploring the Distributed File System

What is DFS? With, DFS, you can create a single share that encompasses every file resource on your network. Think of it as a home for all the files on your network with “links” page that connects the clients to the particular server or servers that actually house those. You could have shares that span the entire world. Group them all under one namespace, and have namespace to the user to allow an easy, user-friendly, centralized way of sharing resources. To take a step further, DFS can replicate the shares to any servers that are members of the replication group, keeping all servers up to date.
Server 2012 uses technologies:

DFS Namespaces gives you the ability to group shared folders that live on different sites and into one or more logically structured namespaces. The namespace is presented to you as a single folder containing many members of all of the shared folders live in a local directory. This is a great functionality that gives you a centralized way of managing and using shares across multiple physically separated servers or site locations. This structure increases availability and automatically connects users to shared folders in the same Active Directory Domain Services site, when available, instead of routing over WAN connections.
