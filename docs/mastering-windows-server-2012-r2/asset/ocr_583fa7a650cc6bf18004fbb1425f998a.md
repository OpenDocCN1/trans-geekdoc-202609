# Event Log Readers Group

The easiest way to grant Read permission on the source logs is to add a user account to the Event
Readers group. You can add an account to this group on each computer, or you can add a user
account to the domain Event Log Readers group located in the built-in container.

# Source COMPUTER-INITIATED SUBSCRIPTIONS

In a computer-initiated subscription, the source computers push the subscriptions to the
collector computer. The source computers can be identified individually or by using a global
group within Active Directory.

Source computer-initiated subscriptions work best when the list of source computers
changes frequently. The subscription can be created once using a global group, the groups
be added and removed from this global group in Active Directory.

Figure 30.15 shows the configuration page for a source computer-initiated subscription.
In the figure, a global group named Monitored Computers from the Bigfirm domain
added to the subscription. This global group includes a list of computers that will act as source
computers in the subscription.
