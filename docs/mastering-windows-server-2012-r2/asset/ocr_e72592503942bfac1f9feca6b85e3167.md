# CONFIGURING HOME DIRECTORIES

+   - Who must be able to access each user’s home directory

The norm is to allow only the user, administrators, and System to access to the folder. Some organizations choose to treat the home directory as a personal folder that the user can use to share data with everyone. We'll demonstrate the more usual approach in this section.

+   - How will you name the folders?

Some people use something predictable. They name the folder after the user who owns the home directory. For example, the user Joe Bloggs has a username of JBloggs. His home directory will be called JBloggs. This makes it easier to perform automated tasks such as connecting the user to the share.

+   - How will you share the folder?

Some to choose and share every home directory. That's a lot of work. Others prefer to create one generic and create a folder underneath for each user. This suits the DFS approach earlier because there's only one DFS link if you need to restore or move the home directory to a new location. The shared folder will be made available via a DFS namespace.
