# Adding Servers to Manage

You can add additional servers to manage and monitor with Server Manager by following these steps:

+   1. Log on to your Windows Server 2012 R2 computer with an elevated account that has administrative permissions.

+   2. Click Server Manager ➢ Dashboard.

+   3. Choose the “Add other servers to manage” option from the Quick Start tab.

+   4. From the Servers dialog box and in the Active Directory tab, filter by location and operating system; either type the beginning of a name for the servers you want to add or click the Find Now button to display all servers for your chosen options.

+   5. Double-click (or Ctrl+click) each server you want to add to the Selected column; then click OK.

Now in the Dashboard, you will see the “Servers total” value under the Roles and Server groups reflect the number of servers you’ve added for monitoring.

+   6. Click the View menu from Server Manager, then choose 75 to see a compressed view of all the roles from your multiple servers under your monitoring control within Server Manager, as shown in Figure 30.1, with each individual server and its relevant status (green for healthy and red for unhealthy).
