# The File Transfer Publishing Service

Because FTP is incorporated into IIS 8, you need only the FTP service to the Web Server role in order to take advantage of file transfers via your websites. Since we covered adding role services to IIS 8 earlier in this chapter, let's not digress. But with all features, roles, and role services, do not add FTP to your web server unless you need to employ it on a website; otherwise, you could be introducing a security vulnerability. # Adding FTP to IIS 8 Website

One of the advantages of the FTP Publishing service is that you can add FTP functionality to an existing website in IIS 8 alongside HTTP. From the Actions pane in the IIS Manager simply click the Add FTP Publishing to kick off FTP configuration for the HTTP site. Before you add file transfer, you need to make some preliminary decisions.
