# FIGURE 8.21
Active Directory user Logon Workstations dialog box

![](bbox=[0.328, 0.105, 0.638, 0.366])

This dialog box allows you to control which computers this user can log into Active Directory. You might consider doing this in a few scenarios:

+   - You need to control where some or all of your users log in. This isn't exactly a common configuration request, but we might imagine that some places have CIA/NSA-like security want to use this.

+   - You are a consultant or visiting engineer on-site, and you want to restrict the person to the computers they should be working on.

+   - You are creating a user account for an application or a service, and you need to ensure that it is used only on the designated servers. This will restrict any damage (temporarily!) that can be done if that account is compromised.

The Log On To and the Logon Settings on the Account tab can be used together to accomplish your domain-based user account logon restrictions.
Returning to Figure 8.19, you have noticed that you have many more options for controlling the account? It's not immediately obvious until you scroll down in the middle of the dialog:

**User Change Password at Next Logon** This is used by an administrator to force a user to change their password after an administrator has set or reset it. This means the administrator should have no knowledge of what the user will use for their password.

**User Cannot Change Password** This would be used by an administrator for a service account to ensure that it cannot be changed.

**Password Never Expires** This control overrides any password expiration policies that may be configured in Active Directory. Ideally it won't be used for ordinary user accounts, but it is typically used for service user accounts.
