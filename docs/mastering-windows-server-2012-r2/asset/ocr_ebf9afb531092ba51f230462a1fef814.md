"Port mirroring" can be used for network traffic analysis between two VMs connected to the same virtual switch. One of the VMs can use the diagnostic tools to perform the analysis, and the other might be part of a locked-down environment whereby the analysis tools cant be installed into it. Mirroring the port of the VM without the VM with the tools the analysis requires.

The final advanced option here is "NIC teaming." Not to be confused with the NIC teaming of the host that we speak about in Chapter 4, "Enable this network adapter to be part of a team in guest operating system" does exactly what it says up! If you want to create a NIC team that stays up if one of the physical NIC stops working, then ensure that you have this option enabled.

Continuing the discussion of the left pane, we can go to the Management section. Normally you don't need to change any settings here, since the defaults are sensible. You can change the name of the VM here, configure the Integration Services components (discussed earlier in "Virtual Machine (Guest) Partitions"), specify the checkpoint file (discussed later when we discuss checkpoints) and smart paging file locations, and decide what should happen when the host starts up or shuts down.
