# CHECKING FOR ERRORS

Be sure to log in and out a few times as the user. Check for errors in the notification area and in the Application log in Event Viewer. Any errors are typically related to misspellings or permissions issues.

Hold on a second! How do you know if there's anything in that profile folder? You've probably just re-created this scenario and noticed that administrators have any access to the profile. That actually is the way it meant to work. The user has created their own folder, and as Creator Owner they have full and access to it. It's a bit of a pain because it makes things like backup/recovery and helping the user nearly impossible!

It's messy to grant administrators to user profiles. Ideally, there would be a way to grant access as required. You can do this with a Group Policy that you can apply to the computers creating the profiles. However, this solution must be applied before the profiles are created.

+   1. Log into the domain controller, BFI, and launch the Group Policy Management console from Administrative Tools.

+   2. Create and link a new Group Policy object, as shown in Figure 26.21, to the Computers OU where Win8, the workstation, resides.
