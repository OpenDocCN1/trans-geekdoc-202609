# FIRST, RECAP

Before we get into the nuts and bolts of routing with Windows, we'll start with a quick recap of what we expect to know about TCP/IP for this chapter:

**IP addresses identify individual interfaces.** Each active interface on a TCP/IP host (whether it's a PC or a device such as a router or firewall) owns one or more IP addresses; these IP addresses are 32-bit numbers for IPv4 and 128-bit numbers for IPv6. IPv4 addresses are commonly written as “dotted quotes”—four numbers from 0 to 255, separated by dots, such as 192.168.1.234. IPv6 addresses are written as hex digits, representing 16 bits at a time, with colons to separate groups, such as 2001:db8:85a3:d4f2::ac102. The double colon represents consecutive zeros that have been omitted for brevity, in case, 32-bit worth, or the equivalent of 0:000

**IP is an unreliable protocol.** It makes no effort to guarantee delivery or report on a failure of data to reach its destination.

**UDP is an unreliable protocol built on top of IP.** It adds the concepts of ports to IP—one for destination and source.

**TCP is a reliable protocol built on top of IP.** Apart from the size of addresses, there is no difference between IPv6 and TCP over IPv4. TCP adds to IP the concepts of ports for the destination and source, a connection lasting from initial greeting to ending of life, a handshake for opening and gracefully closing the connection, sequencing to maintain the order of each byte in the connection stream, and a way to abort a connection when either end detects an error condition.
