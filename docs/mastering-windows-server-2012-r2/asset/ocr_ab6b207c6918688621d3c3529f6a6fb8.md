# Common Shares

In Windows Server, several common shares have already been created for you. Most of these are hidden. If you know of these shares, you can connect to any of them using the IPC path.

C$, D$, and So On. All drives, including CD-ROM drives, are a given share to the root of the drive. This share is what called an administrative share. You cannot change the permissions or properties of these shares, other to configure them for Offline Files (we'll talk about Offline Files at the end of this chapter). Only the Administrators and Backup Operators groups can connect to administrative shares, without modifying the registry or stopping the server service (which stops all sharing). These comes are handy for server administrators who do a lot of management work. Mapping a drive to the C$ share is equivalent to being at C:\ on the server.

ADMIN$ is another administrative share and it is used to map the location of the operating system. If you installed the operating system on D:\\windows, the ADMIN$ maps to D:\\windows.

IPC$ The IPC$ share is one of the most used shares in intercomputer communications, though you will rarely interact with it directly. When you try to access resources on other computers (to read event logs, for example), the system uses named pipes. A named pipe is a piece of memory that handles a communication channel between two processes, whether local or remote, and IPC is used by the named pipes.

NETLOG The NETLOG share is used in conjunction with login requests from users. Once users successfully log in, they are given any profile and script information they are required to run. This script is often a batch file. For example, we have a common batch file that we want all of users to run every time they log in.
