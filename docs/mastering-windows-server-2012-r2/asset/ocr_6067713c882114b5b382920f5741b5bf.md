The DNS service is waiting for Active Directory Services (AD DS) to signal that the initial synchronization of the directory has completed. The DNS server cannot start until the initial synchronization is complete; if problems DNS data might not be replicated onto this AD DS event log indicate that there are problems with DNS replication. Check the AD DS event log for details about DNS server list in the Internet Protocol properties of this computer. This event will be logged every two minutes until AD DS has signaled that the initial synchronization has successfully completed.
