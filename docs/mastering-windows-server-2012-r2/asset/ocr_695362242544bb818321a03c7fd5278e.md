# REMOTE SERVER ADMINISTRATION TOOLS

Users still need the appropriate permissions to run the installed tools. For example, a junior administrator who installs the tools on their desktop system won't be added to the Enterprise Admins role and suddenly be able to perform anything in the forest.

The tools available in RSAT can be used to Manage Windows Server 2012 R2 roles and features.

# RSAT Compatibility Issues

RSAT is not compatible with the Administration Tools Pack used to remotely administer Windows Server 2000 and Windows Server 2003 servers. If you have these tools installed on your system, you must uninstall them before installing RSAT.

Additionally, RSAT will not allow you to manage a server with the Streaming Media Services role. There are separate Server Administration Tools for the Streaming Media Services you can download and install to manage a Windows Server 2012 R2 server hosting the Streaming Media Services role.

For more information on issues with a Streaming Media Services role, check out the Microsoft KB article at http://support.microsoft.com/kb/934518. The RSAT information is located near the end of the article.

# RSAT Tools

After installing RSAT on a desktop system, you'll have access to a full suite of tools that you'd find on a Windows Server 2012 R2 server with all the roles and features installed. As long as the remote server has the appropriate role or feature installed, you can use the client-side RSAT tools to administer it.

In other words, if a server is running the DHCP role, you can use the DHCP console to remotely administer it. However, if the server isn't a DHCP server, you can't use the RSAT-installed DHCP console to make a DHCP server.

The following list shows some of the more commonly used tools available with RSAT. This isn't meant to be an exhaustive list but instead a summary of the commonly used tools. For a complete list, check out the Microsoft KB article at http://support.microsoft.com/kb/94317.

**Active Domain Services Tools**

The AD tools include Active Directory Users and Computers, Active Directory Domains and Trusts, Active Directory Sites and Services, and other snap-ins and command-line tools for remotely managing Active Directory Domains.

**Active Directory Certification Services Tools**

These tools include the Active Directory Certification tools used for enumerate certificates and certificate authority tools used for stand-alone certificate authorities.

**Dynamic Host Configuration Protocol Server Tools**

The DHCP snap-in is included.

**Domain Name System Server Tools**

DNS tools include the DNS Manager snap-in and the Dnscd.exe command-line tool.

**File Services Tools**

These tools include the Share and Storage Management snap-in, Distributed File System tools, and the File Server Resource tools.

**Network Policy and Access Services Tools**

The Routing and Remote Access snap-in is included for network policy and network access.
