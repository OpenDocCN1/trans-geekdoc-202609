# 保持您的集成服务为更新

建议您像为宿主机操作系统更新 Microsoft 的最新补丁和修复一样，将您的客机操作系统集成服务也保持在最新状态。当您更新宿主机时，集成服务不会自动更新到新版本，因此您需要手动更新它们，或使用 System Center 2012 - Orchestrator 自动化此过程。要确定您的集成服务是否需要更新，可以使用 Hyper-V MVP Didier Van Hoy 提供的这段优秀脚本来检查版本：http://workinghardt.wordpress.com/2012/12/07/checking-host-integration-services-version-on-all-nodes-of-a-windows-server-2012-hyper-v-cluster-with-powershell/

关于虚拟机状态的最后一点：您可以对物理机进行启动、关机、休眠、挂起和重置。虚拟机还有一个额外的电源状态：处于保存状态（saved state）。此功能在测试环境中非常实用。它类似于从宿主机发起的休眠状态，但无论虚拟机中安装了什么操作系统，它始终有效。“保存”操作可以在 Hyper-V 管理控制台或虚拟机虚拟控制的常规位置找到，点击它时，您将看到“正在保存”的状态，并带有一个显示进度的百分比计数器。启动虚拟机，保存的状态将重新加载，使您恢复到上次离开的地方。

对于某些测试，在原地冻结虚拟机很有用。这与保存状态不同，因为数据没有保存到磁盘中。冻结（Hyper-V 称为暂停 pause）只是让虚拟机瞬间停止当前运行。这是另一个在物理机上很难找到的功能。图 27:8 显示了 Hyper-V 控制台上的电源按钮。

从左到右，您可以使用这些按钮执行以下操作：

- 向虚拟机发送 Ctrl+Alt+Del 序列。

- 在关机或保存状态后启动虚拟机。

# 使用 VLAN

之前我们讨论了虚拟交换机和 Hyper-V 网络。现在您已经了解了如何配置和安装新虚拟机，是时候详细介绍如何将您的虚拟机连接到不同的网络子网。在物理世界中，如果您出于安全或可扩展性考虑而隔离不同的子集，您可能会使用虚拟局域网（VLAN）技术。VLAN 在网络设备（通常是交换机或路由器）上配置，通过 ID 标记实现网络隔离。

VLAN 工作在 OSI 网络第 2 层。具体的协议定义为 802.1Q。每个属于 VLAN 的数据包都有一个标识符。这是一个 0 到 4095 之间的数字，4095 留给其他用户。假设有一个标识符为 100 的 VLAN。带有 VLAN ID 的网卡只会更新具有相同 ID 的包，并忽略所有其他 ID。VLAN 的意义在于，启用了 802.1Q 的交换机路由器可以将 VLAN 连接到不同的交换机端口。换句话说，普通的 IP 交换机仅限于物理交换机的一组端口，而 VLAN 中的子网可以出现在任何端口上——当然，前提是经过配置。

通过 Hyper-V 虚拟交换机，您可以通过为虚拟网卡分配 ID 来利用 VLAN 连接和 ID 标记。宿主机中的物理网卡需要连接到物理交换机上的 VLAN 节点端口（或创建并分配给物理网卡的任何物理交换机）。一旦您以这种方式配置了网络，您只需遵循以下步骤：

- 从设置中，选择网络适配器。

- 在设置中，勾选“启用虚拟网络标识”。

- 点击确定。

# 使用检查点进行时间旅行

正如您所见，许多功能非常有帮助。如果您仔细观察这一点，可以得出一些有趣的结论。首先，Hyper-V 允许真正的节点。不仅磁盘被保留了，内存和配置也是如此。您可以更改内存并添加网络，然后仍然可以恢复到原始状态。

检查点是虚拟机的一个时间点副本。它包含了状态和配置。在实验室或测试环境中，没有理由不重复此过程。您可以拥有检查点链或多个检查点链，最多 50 个（您真的不需要那么多）。此过程的局限性是它适用于虚拟磁盘。如果您的虚拟机在许多情况下使用透通磁盘，则无法检查点。

最后，虽然检查点很快且非常诱人，但我强烈建议您谨慎地使用此功能，最好在您的实验室或测试环境中使用。在生产环境中使用带有检查点的虚拟机在删除检查点之前会注意到性能影响。

可以通过多种方式检查检查，类似于更改电源状态。要在 Hyper-V 管理控制台中执行，右键点击虚拟机，并从上下文菜单中选择“检查点”。图 27.40 展示了 Hyper-V 管理中的检查点。

![](img/41a83208e6906a3732620203b836cea7_1429_0.png)

这已经有很多检查点了。当前检查点被突出显示。它的图标与其他不同。新检查点的默认名称是当前的时间和日期，但立即重命名它更有意义。

# 使用 PowerShell 使用检查点

如果您需要对检查点进行脚本，那么新的 `Checkpoint-VM` 命令就是您的开始。输入以下内容为虚拟机创建一个自定义名称的新检查点：
`Checkpoint-VM -Name "WS2012R2-SRV" -SnapshotName "Before Service Pack Install"`
