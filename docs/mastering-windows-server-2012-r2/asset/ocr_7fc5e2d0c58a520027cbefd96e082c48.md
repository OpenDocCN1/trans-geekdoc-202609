# A BETTER DESTINATION

Rhonda Layfield, a colleague and a deployment guru, has a great tip for when you are installing ADK. You're asked to choose a location for installing ADK. We usually choose the default of C:\Program Files (x86)\Windows Kits\8\. Once you start using ADK a lot, however, you'll realize how much command-line stuff you need to do. By burying your work in a deep path full of long names isn't exactly command-line friendly. Rhonda's tip is to simply install ADK into C:\ That will save keyboard and tear.

You have arrived at the ADK select features screen. Let's take a moment to discuss these features. You will notice the list in Figure 2.67 that SQL Express is not shown. This is because I already have SQL Server on my computer. If you do not have SQL Server, then the SQL Server Express option will be in the list and is required for the Application Compatibility Toolkit (ACT).
