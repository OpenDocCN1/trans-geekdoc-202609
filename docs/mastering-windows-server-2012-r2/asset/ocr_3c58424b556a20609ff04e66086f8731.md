+   1. Right-click the desired node, in this case Desktops OU.
2. Select the "Link to an Existing GPO menu" option.
3. In the Select GPO dialog box, select the Desktop Security GPO, and then click the OK button.

Notice that the Desktop OU have a linked GPO associated with it. If you want to create and link a GPO to an OU, you can do this in just a single step. By right-clicking the OU (or domain or site, for that matter), you can select the option called "Create a GPO in this domain, and link here." This will perform both steps in a single action.

+   4. Now, click your GPO, in this case Desktop Security.

Notice that the GPO has some tabs and properties associated with it in the right pane of the GPMC. Four tabs are associated with each GPO: Scope, Details, Settings, and Delegation (see Figure 9.6).
