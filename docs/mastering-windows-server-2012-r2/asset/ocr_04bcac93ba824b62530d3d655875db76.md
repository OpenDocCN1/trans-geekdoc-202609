# MANAGEMENT PACKS OVERVIEW

IT as a service

![](bbox=[0.259, 0.093, 0.905, 0.246])

Unlike the other monitoring solutions on the market that to monitor everything
from the start, you first deploy Operations Manager and decide to push an agent out to
a server, it will only see that server as an entity that is up or down. Operations Manager
won't know that the agent has been deployed to a Windows Server 2012 R2 computer or that the
agent is running on a server that has the Hyper-V role deployed, for example.

Operations Manager understands what it has to monitor on each agent through specific
management packs that have been developed and made available by each application/
product vendor or the General System Center connectivity. These management packs throw light
t on the Operations Manager infrastructure and allow the agents to understand the components
that need to be brought under monitoring control.
