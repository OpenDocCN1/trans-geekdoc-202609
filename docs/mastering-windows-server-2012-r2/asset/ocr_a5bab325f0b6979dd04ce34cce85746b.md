# EXPLORING THE DISTRIBUTED FILE SYSTEM

DFS root must be hosted on a domain controller so that there is an Active Directory to post to. One of the most important benefits of being published in Active Directory is that domains can have replica roots. A, root lets you have any domain controller host the root, which greatly improves fault tolerance. Because the roots Active Directory to be replicas at this level, stand-alone roots cannot be and cannot replicas.
