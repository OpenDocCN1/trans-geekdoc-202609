# The Bottom Line

Add a File and Storage Roles to your server. Before you can use and DFS or NFS, share files and folders, or perform any file-related function across the domain in Server 2012, you will need to install the Additional File and Storage Roles services.

Master It Go to Server Manager, and add the server roles DFS and NFS.
