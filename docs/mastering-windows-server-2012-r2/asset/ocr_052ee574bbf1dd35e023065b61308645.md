# Remote Desktop Licensing Manager

Although you have a grace period during which RDS will function normally, after the grace period ends, RDS will no longer accept connections if licensing is not configured. The grace period lasts for 120 days or until the permanent RDS CAL is issued by a license server, whichever occurs first.

As mentioned previously, you can choose between per-user or per-device Remote Desktop Client Access Licenses. The licensing server must be activated before you can install the licenses.
