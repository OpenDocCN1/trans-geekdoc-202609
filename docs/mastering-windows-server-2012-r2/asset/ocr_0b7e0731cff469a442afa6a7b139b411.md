Unlocking configurable settings can also be accomplished by using the Remove-
WebConfigurationLockPowerShell cmdlet, however, as in order of writing this book it does not
support an exclusive lock, and you would need to clear the whole section and then
add the needs.

Of course, allowing override of server-level defaults at the lower website level does
garantee that the server level administrator will actually take the challenge
and manage their owns. The successful delegation of duties requires strong training and
accountability management. But at least now the applicationhost.config file does not
vent editing of site settings by IIS Manager.

# Installing and Configuring SMTP

Microsoft has deprecated the SMTP server as of Windows Server 2012. As of Windows Server
2012 R2, the SMTP service still works as it did back in Windows 2008 R2, with the exception
of the management script, which has been removed. You can continue to use it as you have
in the past, but administrators and programmers should start using System.Netmtp
sending mail. Information on System.Netmtp can be found at http://tinyurl.com/
ms26125smtp.

The SMTP service in IIS 8 has not changed previous versions but this can be a very
useful tool. It's designed to send mail from the IIS server to another SMTP server, and although
it sends and receives mail messages, it is not intended to provide mailboxes for end users.
That of functionality you may want to look at Exchange Server or Office 365.
