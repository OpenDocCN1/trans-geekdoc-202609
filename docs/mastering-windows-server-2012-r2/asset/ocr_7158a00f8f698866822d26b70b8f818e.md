The first condition to choose from is a device or a user. You can secure data not only down to the user account but also from the device from which they access the resource. You can ensure that they have access to the resources from a corporate device but not their home laptop. That way, you can ensure the security of the data you control the corporate laptop/desktop.
In the example in Figure 15.6, we have allowed John McCabe (johm@contoso.ie) Read & Execute, List Folder Contents, and Read permissions, but we have now added a condition in order to share the access he needs to be on a computer that is part of the Domain Computers group.
