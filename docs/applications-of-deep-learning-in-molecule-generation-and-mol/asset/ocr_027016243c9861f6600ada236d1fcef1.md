SPECTUS: Recent advances in computer hardware and software have led to a revolution in deep neural networks that have impacted fields ranging from translation to computer vision. Deep learning has also impacted a number of areas in drug discovery, including the analysis of chemical images and the design of new routes for the synthesis of organic molecules. While work in these areas has been incomplete, a complete review of the scope of a single Account. In this Account, we will focus on two key areas of deep learning in drug discovery: the prediction of molecular properties and the de novo generation of suggestions for new molecules.

One of the most significant advances in the quantitative development of structure–activity relationships (QSARS) has come from the application of deep learning methods to predict the biological activity and physical properties of molecules in drug discovery. Rather than using expert-derived chemical features to typically build models, researchers are now using deep learning to model complex, nonlinear representations. These representations, have led to state-of-the-art performance. While deep learning has changed the way that many researchers approach QSARs, it is not a panacea. With any other machine learning technique, the task of designing and creating a training set is still a fundamentally challenging issue, such as identifying critical areas that are still uncertain. Multiple researches have the development of methods for assessing the confidence in a model.

Deep learning has also contributed to the generation of new molecular structures. Rather than relying on manual design, deep learning has opened up new possibilities. Techniques that were originally developed for image generation and language translation have been adapted to the generation of molecules. These deep learning methods have been used with the predictive models above and being used to generate new molecules with specific predicted biological profiles. While these generative algorithms appear promising, there have been only a few reports on the synthesis and testing of molecules proposed by generative designs. The evaluation of the diversity, quality, and ultimate value of molecules produced by generative models is still an open question. The field has produced a number of benchmarks, but it needs to agree on how one should assess molecules" by an inventory.
