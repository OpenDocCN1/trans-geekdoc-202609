## 7.7 网络的监控与监视

由于银行和商家无法依赖 SET 等保护机制的广泛采用，他们不得不转向其他方式来打击和检测互联网上的卡片欺诈。假设现有的卡交易处理安排足以应对电子时代的危险，已在估计影响 22 个国家 900,000 名受害者的案例中得到强调。美国联邦贸易委员会的调查导致 1999 年 1 月发布了此处转载的新闻稿。

这种骗局似乎组织良好，其细节由明尼苏达大学的 John Faughnan 博士拼凑而成（Wallich 1999）。Faughnan 博士确定了欺诈的五个主要要素。

* *获取卡号*。犯罪分子无需拦截消息或入侵文件。由于 VISA 卡的格式规范和校验位计算是众所周知的，任何人都可以生成一份有效的 VISA 号码清单。这些号码会通过任何输入有效性检查，后者仅检查是否符合基本格式规则。

* *商家身份*。欺诈是通过申请并获得授权作为卖家接受信用卡付款的公司来操作的。在某些情况下，另一家公司将被用作所谓“销售”来源的幌子——也许甚至不知道骗局。这些销售公司将参与互联网上电子材料的交易，通常是色情性质的。

* *交易处理*。虚假交易的详细信息将通过正常的交易分拣流程发送给负责受害者账户的银行。一些卡号可能在分拣过程中被退回，其他则可能稍后被银行本身退回。然而，其中许多卡号得以通过，尤其是在某些国家/地区（这显然随后成为该计划的理想目标）。

* *设置账户扣费*。所有交易金额都很小（通常略低于 20 美元），按每月定期支付。那些通过筛选流程的交易现在将从银行向商家产生稳定的收入流。

* *受害者的反应*。受害者会被阻止采取行动，因为美国的信用卡交易通常只有在金额超过 50 美元时才会被赔偿，而且许多银行在 60 天后不再受理索赔。试图通过“供应商”寻求补救将遇到 FTC 描述的障碍。尽管如此，一些人似乎对自己被暗示购买了色情内容感到特别愤怒，这可能有助于增加向 FTC 提出的投诉数量。

这种类型的骗局很容易由任何不诚实的商家在小规模上实施。然而，通过采取系统化的方法并协调多个参与者的努力，就有可能获得估计约为 4000 万美元的利润。被发现的风险被保持在较低水平，因为任何主要参与方都无法获得完整而详细的事件全貌。如果只有极少数主导的卡提供商，这种欺诈的机会当然可能会减少，但在英国确实如此时，这种主导地位被认为会降低竞争并违背公共利益（MMC [1989](#reference.xhtml#ref_r175)）。此外，由于欺诈具有国际范围，一个国家监管机构（如 FTC）很难将所有线索拼凑在一起，如果犯罪分子最终位于美国境外，它将缺乏管辖权。

鉴于参与信用卡处理的金融机构数量众多，如果在处理周期中检查应在哪一步应用出现不一致，也就不难理解了。理论上，可以很容易地排除任何“发明”的卡号，通过将所有号码与实际已发行的卡清单进行核对。要求提供到期日期或持卡人姓名等佐证细节也会有所帮助，因为这些细节必须与虚假卡号一起编造，并且可能有助于暴露问题。当卡在商店的销售点终端上出示时，这些细节会被自动捕获，但在电话或互联网交易中必须明确请求。正如 FTC 案例所示，必须假定负责请求此类细节的一些商家可能积极参与欺诈。

金融机构的另一项武器是体现*人工智能*的软件。它可以通过监控交易来“学习”正常活动模式，并挑选出可疑事件。这种软件已被证明在检测卡片滥用方面很成功，并被银行和一些国家 VISA 组织使用。该软件将审查与交易相关的多个因素，并为每个因素赋予权重。如果总和超过某个阈值，则交易被视为异常可疑。理想情况下，这应由发卡银行执行，因为它拥有个人持卡人正常购买习惯的记录，并且可以在个人层面寻找不太可能的消费模式。在国家或国际层面筛选大量交易不太可能产生成效，而且本案中描述的欺诈性 20 美元扣费似乎已“溜过雷达”。

组织可能需要在自己的专用网络上实施监控和监视；这将在[第 13.4 节](#ch13.xhtml#ch13_sa4)中进一步讨论。
