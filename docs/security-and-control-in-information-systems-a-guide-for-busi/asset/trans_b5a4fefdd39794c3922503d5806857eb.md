最终，直觉将不得不成为评估信任在任何给定情况下如何运作的主要指导。然而，由于两个因素，在实施控制时永远不能忽视信任。

* *员工态度和敏感性*。看起来传递不信任信号的控制措施会遭到怨恨，特别是那些习惯于在高度信任环境中工作的员工。同样，如果工作氛围正好相反，怀疑盛行，很少有人会将事情看作表面那样，那么就很不明智地认为所有用户都值得信任。这只会被解读为管理上的软弱或无能。
* *最小化成本*。信任可以被视为一种资产，具有真实的货币价值。如果员工*可以*被信任，对精细而昂贵的控制的任何投资都将是浪费的（而且可能适得其反）。然而，这对经理来说是一个极其难以采取和捍卫的立场，因为它需要对其他员工有高度的信任，并愿意放弃依赖明确控制所提供的更可预测的“更安全”选择。然而，这对组织在启动和经常性成本方面的节省可能相当可观。

## 3.5 信任的局限：‘社会工程’的兴起

如果组织可以通过培养信任文化获得利益，那么如果他们的员工既信任又天真，他们也可能面临严重风险。员工必须意识到各种自信骗子带来的威胁，他们会试图冒充合法用户，然后利用这种信任地位。这已成为那些从事计算机滥用计划的人的流行技术，并且创造了术语 *社会工程* 来描述他们的活动。最简单的例子是使用某种计谋说服某人透露其密码。能够输入有效的用户标识符和密码总是比不得不诉诸技术伎俩进入系统要容易得多。

社会工程可以成为那些对欺诈或盗窃感兴趣的人的有用起点，但它主要与黑客的恶意入侵有关。Kevin Mitnick 是一名黑客，他在洛杉矶的青少年时期发展了他的社会工程技能，正如所描述的事件所示。

该事件说明了社会工程的三个基本原则：

* 为自己编造一个合理的身份，以及你所做事情的理由。
* 转移对你真实动机和意图的注意力。
* 利用人们的易感性和弱点。

第三原则由 Mitnick 应用，他利用了警卫感到无聊的事实。社会工程师也可能利用人们渴望取悦他人的心理、他们感到不安全以及他们不愿因看似非常小的程序问题而卷入争执的心理。

虽然社会工程可用于进入建筑物，或在面对面交谈中诱骗信息，但社会工程师的首选媒介是电话。摆脱了实际露面的需要，冒名顶替者可以扮演多种不同的角色。Gordon（[1995](#reference.xhtml#ref_r94)）认为这些可分为五大基本类别：

1. *无知的菜鸟*。冒名顶替者扮演新员工，或刚将 PC 连接到网络的人的角色，并致电计算机中心寻求帮助。这种装傻的方式会博取同情，并鼓励人们详细说明每一个细节。
2. *技术人员*。这里角色互换，例如，冒名顶替者致电秘书，声称自己正为公司从事某种深度技术工作，并询问是否可以获得某人的密码以帮助进行测试。
3. *VIP*。此人仗势欺人，假装是高级管理人员或官员。透露信息将有某种至关重要且紧急的原因，如果不透露将产生严重后果。
4. *有愤怒老板的人*。在这种情况下，会博取听众的同情：‘销售经理在这件事上真的为难我了。你能帮我一把吗？’
5. *安全人员*。这是一个有风险的选择，但如果成功，它结合了 VIP 的权威和技术人员的吓人术语。冒充安全官员可以提出各种关于程序、密码和系统设施的问题。

对抗社会工程的对策取决于持续的警惕，以及愿意以相关问题作出回应的意愿。如果员工对来电者的身份有疑问，应鼓励他们以冷静而坚持的方式尽可能多地寻求佐证信息。他们的培训应涵盖泄露看似无害的细节的危险，例如某人的工作时间，或她拥有访问权限的系统，即使对方身份存疑也不应透露给任何人。最重要的是，应鼓励员工*永远*不要想当然地认为电话来电者就是他或她声称的那个人。

## 3.6 控制的合法性：一些正直和监视问题

从理论上讲，每个组织都力求使其所有数据完全准确可靠，并根据合法的“需知”原则限制访问。当然，这些雄心壮志存在技术限制（将在后续章节探讨），但公司必须运作的社会和伦理框架也对其施加了限制。

例如，跨国公司试图在其所有业务中应用统一的会计系统。它在海关官员期望在货物能从码头移走之前收到巨额贿赂的国家进行贸易，或在政客期望收到巨额诱因以润滑商业交易的地方进行贸易。这些付款应如何记录？是否有人在账簿中记入条目，完全准确地显示在某月某日支付了 X 美元的贿赂？即使这被记录在账簿中，也极不可能在公司账目中在“贿赂和诱因”下出现一笔款项。会计系统必须在某处被篡改，以便这些付款与销售的其他、更合法的成本一起被埋藏。
