## 3.7 忠诚与义务的冲突

雇主有权期望员工忠诚，但不能期望这种忠诚是完全无条件的。例如，员工可能认为自己有权对公司不当行为“吹哨”，或拒绝接受他们认为不诚实或不安全的指示。这种忠诚冲突已被商业伦理作家广泛讨论（Hoffman and Frederick [1995](#reference.xhtml#ref_r118)）。

更常见的是，忠诚冲突出现在员工希望遵守源自组织之外的正式 *道德行为准则* 时。这通常是因为他们的工作受专业机构监管，如医学和社会工作等关怀职业，或法律和会计等商业职业。在这种情况下，员工可能面临关于控制的适当行使和使用的困境。一些例子包括：

* 负责 *员工福利* 和 *职业健康* 等领域的人员可能觉得有义务保护他们从员工处获得的某些信息的保密性。这可能是因为信息涉及家庭事务，因此提及组织之外的人，或因为它是健康记录，相关个人希望保持私密。这可能意味着禁止高级管理人员访问相关数据字段，而高级管理人员通常期望能够完全访问员工的人事记录（例如检查他们的工作时间，或最新的绩效评估等级）。
* *政府* 机构的员工，无论是地方还是国家层面，可能对让某些信息项目可供民选代表访问也有类似的担忧。例如，这可能是因为他们怀疑信息主要被寻求作为对政治对手施压的一种方式。这一技巧最著名的倡导者可能是美国总统理查德·尼克松，他曾寻求有关其政治敌人的税务事务的信息（Watergate Hearings [1973](#reference.xhtml#ref_r235); Impeachment Report [1974](#reference.xhtml#ref_r126)）。
* 员工可能希望对具有未来 *证据价值* 的材料获得控制方面的保证。有时一项发现或意见将被“记录在案”。这可能包括以专业身份作出的陈述，或与内部调查或质询相关的陈述。在这种情况下，可以合理地期望对这些陈述的任何电子版本适用特殊保障措施。例如，一名安全官可能会记录一些观察或测量结果，这些结果指向安全制度的缺陷，并希望确保这些记录随后无法被更改或删除。

如果忠诚应归于客户，可能有必要设立 *防火墙*。这些通常用于组织拥有在同一市场竞争的客户 A 和客户 B 的情况下。分配给客户 A 的团队必须能够向其客户保证，商业敏感信息不会被客户 B 的团队访问。另一个团队也必须能够向 *其* 客户提供类似保证。然而，两个团队可能都在同一系统上存储文件和文档。

防火墙是通过扩展正常的安全控制来创建的，以确保不会发生任何不期望的信息交叉流动，即使是无意的。防火墙也用于客户因其他（合法）原因要求工作完全保密的情况，例如，信息的流通可能导致内幕交易指控，或客户正在准备一次意外的收购要约。在这些情况下，对额外、量身定制的保护的要求需要超出基本客户文件，还包括电子邮件，以及与客户之间传输的任何文件。

在某些情况下，客户可能期望防火墙适用于相当常规的服务。这在金融服务行业尤其适用，其中银行、保险、信贷和投资服务可能都由同一家公司提供。客户会期望某些交易——尤其是通过银行账户进行的交易——仅对一个服务中心保密。对公司 *不* 实施限制的压力源于他们所掌握数据的商业价值。美国注册会计师协会（AICPA [1999](#reference.xhtml#ref_r2)）指出：

> 随着公司和个人的更多交易以电子方式处理，将有可能根据交易模式和内容准确而深入地描绘个人和公司。商业企业、政府机构和不法个人对这些信息将有巨大的需求。将存在合法和非法的市场用于收集和转售这些信息。公司和公司内部的个人将被诱惑出售在保密情况下捕获的信息。许多公司将声称已建立防火墙以防止信息未经授权的传播。用户将需要保证已建立有效的程序。

如果公司 X 代表竞争对手提供数据处理服务，类似的“需求”信息是可以预期的。1993 年，维珍航空与英国航空之间爆发了一场激烈的争执，维珍指控英国航空根据其根据外包合同为维珍处理的乘客信息，开展了“肮脏手段”活动（Hawker [1993](#reference.xhtml#ref_r113)）。最近，两家在线书商之间发生的类似争端以法庭案件告终，当时 Alibris，即为亚马逊提供互联网服务的公司的所有者，承认窥探了亚马逊的电子邮件流量（Silicon [1999](#reference.xhtml#ref_r213)）。

## 3.8 问题

1. 你是律师事务所的资深合伙人。你在事务所的新 IT 系统上投入了大量资金，该事务所雇用了 50 多人。担任高级管理员、25 年来一直忠诚且非常有效的员工，对 IT 带来的变化热情不足。该系统的选型和实施由一名两年前加入事务所的年轻、刚取得资格的律师主导。

在管理新系统的安全方面可能会出现什么问题？请建议在这种情况下如何最好地分配一些关键职责。

2. 总部已向所有经理发出指令，声明在任何情况下都不得使用公司的电子邮件服务进行个人通信。它指出，经理将对其部门内系统任何滥用负责。

你是一名负责二十名文员团队的经理，所有人都定期使用电子邮件。起草一份传阅给你的团队的备忘录，解释并论证该政策，并描述你打算进行的检查类型。

3. 你独自在公司伦敦办公室，晚上加班时电话响了。你不认识来电者，对方声称是公司多伦多办公室的一名会计。你知道公司在加拿大有大量员工，但对其了解不多。来电者带有加拿大口音。
