

不同的 `motivations` 潜藏在每一种威胁之后。前两种（盗窃和欺诈）都由对 `personal enrichment` 的希望驱动。这可能是通过直接获取金钱、服务或商品（在盗窃的情况下），或通过更狡猾的手段（例如董事发布歪曲公司状况的账目）。由于目的是利用他人的资产，后者将被留下未受损害，除非这在推进犯罪过程中不可避免。

这种动机可能在安全措施出现漏洞时才被激活，例如在办公桌上发现写有密码的纸片，或注意到某项控制程序未被正确执行。或者，有人可能以更渐进的方式滑向不当行为。有些人会采取系统化的方法；他们会着手积累关于系统弱点的知识，并进行实验（起初可能相当无害）以了解如何利用这些弱点。

可能最难辨别的动机与恶意破坏有关。这些可分为两个主要类别：`grievance`（包括对个人或组织的报复、推行某种意识形态，或对世界整体的某种无焦点不满）和 `vanity`（向自己或更广泛的黑客社区证明自己的技能）。通常动机是混合的，就像有才华的黑客，他们既想展示自己的技能，同时也希望给他们不同意其目标或价值观的组织制造麻烦。黑客在探测可利用的弱点时通常会采取系统化的方法。

错误和无能为管理带来特殊问题。它们可能可追溯到一般缺乏动机的根源，即员工对工作缺乏投入，因此无法发挥最佳水平。同样，导致损害的技能或知识缺乏可能源于培训不足，因此并非完全是员工的过错。

最后，自然灾害可归类为保险业所用的“天灾”。它们将由于组织无法控制的异常天气条件或其他情况造成，没有必要考虑动机的問題。恐怖袭击背后可能存在强烈动机，但此类怨恨往往是一般性的；组织可能只是不幸地在错误的时间出现在错误的地点。

## 1.6 Internal Versus External Threats

威胁源自何处？上一节强调的案例表明，它们可能来自各个方向。在上一章中，引入了将威胁视为 `internal` 或 `external` 的概念，具体取决于它们来自 `organisational boundary` 内部还是外部。这意味着存在两组人：一组在边界内部，组织对其具有一定影响力；另一组在边界外部，组织对其相对无能为力。

实际上，生活并非如此简单，边界的性质也难以界定。很容易识别出直接受雇于组织、因此根据雇佣条款有义务遵循管理指令的人员。然而，大多数组织在各种其他协议下聘请协助，例如使用代理员工、服务承包商和顾问。随着 [section 1.4](#ch1.xhtml#ch01_sa4) 中描述的 IT 及其他领域的外部承包和外包安排的普及，这已变得越来越普遍。这些承包商可能被允许完全进入组织的场所和设施，并在许多方面被视为与正式员工一样对待。这些员工的合同通常要求他们必须遵守组织的日常规则，包括与数据安全相关的规则。然而，最终，他们的培训和工作实践中仍会有一些方面超出组织的直接控制范围，并且他们要对其自身的管理负责。如果此类人员行为不当，他们应被视为“内部”还是“外部”运作？

一种解决方案是用承认 `series` 边界的模型取代基于 `single` 边界的模型。随着每一次边界的跨越，组织施加的影响力范围变得越来越弱。这种情况在 [Figure 1.1](#ch1.xhtml#fig1_1) 中有所说明。

从个人管理者的角度来看，围绕其直接负责的工作组还存在一个额外的边界。在管理良好的组织中，这应意义不大；然而，如果组织不够和谐，则在其他部门建立影响力时可能会出现问题。

承包商即使在理论上受相同条款和条件约束，实际上也更难施加影响。交易伙伴拥有更大的独立性；尽管可以通过具有法律约束力的协议施加压力，或因为他们重视业务关系而不愿危及它。

可能最大的变化发生在考虑组织的客户（或客户）时。他们没有理由觉得自己欠组织人情。即使他们可能被授予直接访问组织系统（例如网站或在线银行服务）的权限，他们也可能选择蔑视指令或警告。如果他们知道自己可以选择将业务转移给竞争对手，这种情况尤其可能发生。

在某些情况下（如信用卡或在线信息服务），客户必须向服务提供商注册，这使得可以对服务使用附加条件并正式实施。然而，对于首次通过互联网查询或购物的用户来说，这根本不可行。最后，除了在所有这些不同身份下与组织有往来的人之外，还有大量从未与之接触过的人，但他们可能获得其计算机系统的访问权限。

威胁越“外部”，在计算机系统 `within` 应用自动化控制时就越需要严格。这是因为影响用户行为的其他选择变得越来越有限；即使存在，使用起来也可能很繁琐。例如，随着从 [Figure 1.1](#ch1.xhtml#fig1_1) 的左侧向右侧移动，通常会适用以下情况：
