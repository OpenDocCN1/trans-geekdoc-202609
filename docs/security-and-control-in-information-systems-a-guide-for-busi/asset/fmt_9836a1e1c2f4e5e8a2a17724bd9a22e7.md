
## Virus

: A program which is designed to spread itself from one computer to another. Every virus needs a ‘carrier’, which is often ‘fun’ material which people will be tempted to pass on, such as a computer game or a screen saver. The effects of a virus can vary in severity, from e.g. displaying irritating messages, to wiping all the data from a disk.

## Worm

: A virus which is designed specifically to perpetuate itself across network links (usually causing some kind of harm to the network connections in the process).
