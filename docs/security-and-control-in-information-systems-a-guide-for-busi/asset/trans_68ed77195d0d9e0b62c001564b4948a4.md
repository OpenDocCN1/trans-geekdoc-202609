# 第十三章 计算机取证

DOI: [10.4324/9780203992319-19](https://dx.doi.org/10.4324/9780203992319-19)

## 13.1 引言

管理人员经常不得不基于直觉或怀疑行事。如果有迹象表明计算设施被滥用，本能的反应通常是采取一些先发制人的行动。例如，可能收紧访问控制制度，或重新分配员工职责；如果这样做是隐秘的，就无需对任何人提出指控，也不会损害良好的工作关系。与此同时，管理层传达了一个明确的信息，即不会容忍滥用行为。
然而，这些“温和”的做法并不总是合适的，在这种情况下，就有必要获取确凿证据并对肇事者进行对质。要成功做到这一点需要对 **计算机取证** 有良好的理解。计算机取证可能在以下情况下使用：
* 滥用行为如此公然和严重，以至于认为识别和惩罚肇事者很重要；
* 管理层希望确切了解滥用是如何发生的，以便他们确信其对策会有效；
* 组织因滥用而面临来自其他方的法律诉讼。例如，软件供应商因违反许可协议条款而提出的索赔，或关于在计算机系统中流传的材料具有诽谤性的指控。
在这种情况下，需要进行调查，其范围远不止于确定滥用是否发生。这些调查可被视为“取证”，与警察侦探工作相类比。它们旨在提供足够强有力的证据，以抵御被牵连者可能提出的任何质疑。
由于基于计算机的证据可能被迅速销毁，因此在不引起任何嫌疑人注意的情况下收集证据至关重要。证据还必须足够全面，以排除对事件的任何其他解释。即使组织没有打算将证据带上法庭，它也必须假设证据最终可能被迫走上这一方向，因此必须始终怀着这种可能性收集证据。一旦它对一名员工提出指控，该员工可能会寻求某种形式的正式审查，特别是如果存在惩罚性行动的可能性。这就有可能使证据最终必须在全面诉讼的背景下提出，在这种情况下，可以预期会尽一切努力对其进行 discredit。
在理想的世界里，取证调查应常规进行，而不仅仅是在怀疑出现问题时进行（如第 264 页的案例 A）。不幸的是，此类调查无一例外地昂贵，而且在开始时很少能准确预测任何特定调查的费用 *有多高*。一旦开始，调查可能持续几天，也可能持续数月。调查人员的时间成本很高，因为他们必须高度熟练于在系统中寻找，使用复杂的搜索和分析工具。必须在保护和记录证据方面格外小心，这大大增加了间接成本。组织必然不愿投资于这种资源密集型的活动，除非存在严重的损失或犯罪似乎值得这样做。更不用说，如果一开始没有任何证据表明有什么特别问题，他们更不愿为此提供资金。
乍一看，取证调查似乎是组织自身计算机审计员的理想任务，但该领域的顾问强烈反对这种做法，而且并非完全出于自利。例如，Wilding（[1997](#reference.xhtml#ref_r238)）指出，长期密切从事系统工作的人并不最适合发现其弱点。如果发现缺陷，他们可能会采取防御性反应，觉得自己在某种程度上负有责任。此外，他们可能对收集和存储证据相关的法律要求了解不足。
无论计算机审计员是否实际发起取证调查，他们的投入和协助在流程的各个阶段都是必不可少的。本章概述了当今“计算机侦探”可用的一些方法和工具。

## 13.2 获取有效计算机证据的技术和程序

无论调查人员面对的是局域网上的两三台 PC，还是基于大型机的庞大企业系统，他们面临的第一个问题基本相同。从哪里开始寻找？一位大型系统专家总结了这个问题：“欺诈的证据通常埋藏在计算机上保存的数十万条有效记录之下”（Iyer [1996](#reference.xhtml#ref_r129): 396）。调查人员需要随身携带的第一件也是最重要的工具是能够帮助挖掘这些数据的软件。
在基于大型机的系统中，此类工具可能是应用程序软件或操作系统不可分割的一部分。如果组织建立了企业数据库或数据仓库，或使用覆盖多个主要部门的应用程序软件，如企业资源规划，就尤其可能出现这种情况。合适的工具也可能在执行信息系统中提供，该系统使高级管理人员能够“向下钻取”企业数据，以调查各个单位的绩效情况。
规划者和预测者也可能在决策支持系统中拥有类似的设施，其目标也是从组织的各个部分检索数据，尽管目的不同。DSS 用户感兴趣的是整合信息，以便他们能够构建财务模型并做出预测。大多数时间，他们都在查看汇总数据并试图发现其中的显著趋势。
