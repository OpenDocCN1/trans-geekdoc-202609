# 第十一章 计算机审计 新系统的引入

DOI：[10.4324/9780203992319-17](https://dx.doi.org/10.4324/9780203992319-17)

## 11.1 计算机审计员的角色

当公司首次开始将核心会计系统转移到计算机上时，很快就变得显而易见，某些传统的审计方法根本行不通。以前依赖表格和备忘录的过程现在被隐藏在计算机的“底层”之下。为了检查到底发生了什么，现在有必要考虑在其内部运行的程序的逻辑。传统审计员不确定应如何处理这种新技术，这种技术缺乏今天理所当然的用户友好功能，对于非技术人员来说可能相当令人困惑。作为回应，一种新型的专家出现了，最初被称为 EDP 审计员（即“电子数据处理”）。EDP 是与早期大型机系统相关的术语，随着计算的传播和多样化，更合适的做法是将名称改为“计算机审计员”。有时也使用“IS 审计员”这一术语。

真正的“审计”应由完全独立于负责安装或运行系统的人员的人来执行，并且在接下来的章节中假设了这种地位。人们在进行各种检查和调查时常自称从事“审计”工作并不罕见；或者技术人员可能会被指派代表内部审计部门从事“计算机审计”工作，即使他们的常规汇报线在其他地方。如果审计部门规模小或资源不足，这可能确实是唯一可用的选择。

理想情况下，企业治理将得到最好的服务，如果计算机审计成为内部审计职能不可分割的一部分，并在其指导下进行。这将其牢固地置于更广泛的内部控制框架之内，而这些控制又将受到外部审计师的审查。

在实践中，担任计算机审计员角色的人通常是从编程和系统设计的工作中转过来的。他们通常起初对审计的规则和方法只有粗浅的了解，但通过在审计团队中工作，他们通过实践经验获得了这些技能。与此同时，他们将帮助开发处理基于新技术的系统审计所需的工具和程序。

计算机审计领域一直在迅速发展，但关于计算机审计是否可以真正被视为一种独立的职业或专业仍存在许多不确定性。因为在信息时代，让*任何*类型的审计员都无法处理至少是计算的基本方面是没有意义的。这已为世界各地的专业会计机构所认识到，他们稳步在其课程中引入了更多与 IT 相关的元素。然而，要同时精通*审计*和 IT 仍然极其困难，尤其是在跟上技术方面不断创新的情况下。因此，审计团队很可能仍需要征用和培训那些主要专长是技术的人才。

IT 对内部和外部审计的工作都产生了重大影响，但“计算机审计员”这一称号通常保留给在内部审计团队工作的那些人。提供外部审计服务的公司已开始雇用和培训大量 IT 专家，部分原因是帮助发展他们蓬勃发展的咨询副业。由于外部审计是一个竞争非常激烈的行业，它也很大程度上依赖于计算机化工具，这些工具有助于提高审计计划的效率及其结果的分析和呈现。在这些领域工作的审计员可能仍然不会认为自己以任何特殊方式是*计算机*审计员。这部分是因为他们理所当然地认为，如今他们将不得不处理绝大多数客户的计算机系统，部分原因是因为法律和会计职业非常明确地定义了公共审计中必须实现的目标——拥有纯粹的“计算机”版本是没有多大意义的。

外部审计可以追溯到十九世纪末，当时几个国家的会计专业机构成立，政府开始强制进行审计，以保护股东的利益。外部审计的重点仍然是每个财政年度末报告和账目的公布。重点是为股东提供保证，即他们的资源被有效使用，并确认已公布账目中的信息未受欺诈或错误污染（Sherer 和 Kent [1983](#reference.xhtml#ref_r208)）。这要求充分了解客户的会计系统的工作方式，但与此同时，外部审计师往往不得不依赖内部审计师已设立并核证的检查和控制。由于时间和资源的压力，外部审计师很难对安全和控制机制进行任何实质性的深入调查。

相比之下，*内部*审计是一个年轻得多的职业。例如，美国内部审计师协会成立于 1941 年。内部审计师的角色以务实的方式演变，回应了组织，特别是大型组织感受到的需求，即他们应该有某种方式来检查规则和程序是否得到正确执行。这最好通过让一个与他人稍有区别的人或部门负责，并能提供独立的观点来实现。这种独立性可以通过让审计师直接向审计委员会报告来加强（尽管其有效性受到了质疑（Wolnizer [1995](#reference.xhtml#ref_r242)））。或者，内部审计可能有一个更常规的汇报线，通常向财务总监汇报。在最糟糕的情况下，它可能只不过是一个象征性的存在，基于对会计部门中某个不幸人员分配的几乎看不见且非常兼职的责任。

内部审计主要关注财务交易，但可以扩展到行政的其他领域。其角色未由立法定义，因此组织可以自由地以他们喜欢的任何授权设立它。例如，他们可能会决定审计员应参与新系统选择和设计的非常早期阶段，并期望他们为所有后续阶段做出贡献，直至最终实施。在其他情况下，他们可能希望审计员更低调，仅在要求时提供建议。审计员参与所有系统项目并非必不可少，只有在*相关*项目中以*适当*的方式参与即可。其含义将在以下各节中讨论。
