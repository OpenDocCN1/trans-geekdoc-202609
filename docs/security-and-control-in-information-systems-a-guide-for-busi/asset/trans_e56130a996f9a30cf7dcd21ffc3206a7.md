

即使成功，产品标准化往往也是一把双刃剑。仅仅因为变得熟悉和流行，产品就会吸引黑客和病毒编写者的注意。当用户从同一供应商安装一套“产品系列”时，问题会变得更加严重，而供应商自然乐于鼓励这种做法。这确保了产品能够顺畅地协同工作，得益于它们符合供应商的专有标准。最近病毒编写的创新已经利用了这一点，例如针对由 Microsoft Outlook 处理的电子邮件发起的“Bubbleboy”病毒株（Hancock [1999a](#reference.xhtml#ref_r109)）。关于产品标准的安全性方面以及赞助和监督它们的机构的进一步描述见 14.3。

尝试为*人员*指定胜任能力和资格通常是基于职位说明书进行的。在大多数情况下，这意味着对信息系统审计有很强的侧重。 [Table 14.1](#ch14.xhtml#table14_1) 显示了一些可获得的资格。这些资格在为人们提供提升专业知识的激励方面发挥着宝贵作用。然而，就其与普通企业的相关性而言，它们也引发了一些更广泛的问题。

首先，必须对 IS 安全和控制“专业人员”将被负责的事务范围做出一些假设。如果他们的角色*纯粹*是审计和提供建议，那么这不会引起多少管辖权问题。最终做出决定的那些人始终有选择忽略所提供建议的选项，并且不会觉得必须放弃任何权威。

然而，许多组织，特别是规模较小的组织，不愿意仅仅为了获取专业建议而雇用人员。他们也不愿意支付聘请顾问所带来的高昂费用。相反，他们会尽量确保必要的专业知识在公司各个部门的员工中尽可能广泛地分布。这将包括诸如现场安全、质量控制、应急规划和人力资源等职能，以及管理信息系统本身的人员。在这种情况下，将 IS 安全和控制的适当知识子集纳入*所有*相关专业和管理群体的资格认证中开始显得更为可取。

第二个问题集源于技能的测试方式。设置涉及技术事实或理论的考试总是更容易的，特别是如果测试（如 CISA 和 CISSP）使用多项选择题。测试更柔软的技能则更困难，例如进行一次重大的风险分析，或说服员工遵守新的安全制度。资格认证试图通过要求在相关岗位上的实践经验来解决这个问题，但对于任何人来说，判断候选人可能从中学习到什么或没有学习到什么总是很困难的。事实上，如果没有广泛的监督，经验只会强化和延续不良做法的风险始终存在。

推广资格认证的人也必须确保他们能够销售自己的产品。如果没有令人向往的就业前景来激励候选人，很少有人会感兴趣投入时间学习。如果获得资格的标准没有做到客观和透明，资格认证就会缺乏可信度。因此，不难发现对已被广泛认可的一个角色（计算机审计员）的反复强调，以及考试中强烈以技术为中心的侧重。这里概述了两种特定情况下所需的部分知识。

与其试图为产品或职业设定标准，可以认为采用通过*监管*制度的“自上而下”方法更为可取，该制度规定组织必须实现的安全和控制结果。然后可以让相关管理层自行决定如何遵守。监管可以直接通过立法实施，也可以由被赋予对特定商业部门或活动进行监督的机构间接管理。

在制定新法规时，各国政府往往集中在公众利益较高的领域（例如涉及个人隐私或信息自由的问题）或政府自身有既得利益的领域（例如与执法和税收有关）。这并不总是产生合乎逻辑或连贯的结果。例如，一家美国法院曾被要求裁定一家向客户提供互联网服务的有线电视公司如何同时遵守《有线通信政策法》，*和*《电子通信隐私法》。这两部法律都规定了在怀疑客户从事刑事活动时拦截消息的条件。不幸的是，这些法律在诸如是否必须首先通知客户等重要细节上存在分歧。有人认为，即使是最守法的有线电视运营商也无法同时遵守这两部立法（Massachusetts [1999](#reference.xhtml#ref_r161)）。

多年来，世界各地的政府一直试图通过禁止出口任何真正有效的算法来监管密码学的使用。最著名的例子可能是美国政府使用其《国际武器贸易条例》。密码产品被列入美国军需品清单，出口任何（无论是设计、代码还是硬件）能够使某人创建强大密码设施的东西都成为违法行为。许多其他国家也实施了类似的限制（清单可在 Garfinkel 和 Spafford ([1997](#reference.xhtml#ref_r92)) 中找到，Koops ([2000](#reference.xhtml#ref_r144)) 维护了一个当前限制的网站）。多年来，系统供应商和公民自由团体提出的投诉导致越来越多的例外情况被做出，但仍有许多限制存在（Dam 和 Lin [1996](#reference.xhtml#ref_r57)：[Ch. 4](#ch4.xhtml)）。

在欧洲，已经努力协调与电子商务行为有关的法律。1999 年，经过大量磋商和修改，达成了一个框架，用于规范认证机构，并使数字签名与传统签名具有同等效力（EC [1999](#reference.xhtml#ref_r74)）。现在必须将适当的措施纳入国家立法，例如 1999 年底提交英国议会的《电子通信法案》。
