# 第 6 部分 法规和标准

## 第 6 部分介绍

如果我要向你推销一把门锁，我可以当着你的面把演示模型拆开，并试图说服你其内部构造如此精妙且设计精良，以至于能抵御最坚定的窃贼。或者，我也可以请专家事先对产品进行彻底检查。如果专家得出结论认为该锁符合某些标准，而你愿意接受这些结论，我们双方都会节省大量时间。

针对消费品的合规性测试已得到确立。许多产品都带有批准标志或“风筝标志”，表明它们已通过某种认证流程。人们已做出大量努力，试图将同样的方法应用于信息安全和控制。标准已为信息系统产品中的安全功能、自身的安全产品，甚至安装中的整体安全管理制定。

防火墙或操作系统的安全标准，当然比门锁复杂得多。此外，安全门锁的原理已被很好地理解且广为人知。如果你愿意，拆开锁自己看一看并不太困难。在信息系统安全领域，情况则恰恰相反。专家并不总是就安全功能应如何构建达成一致，普通人几乎没有机会评估由电路板和代码行构成的产品。

在 [第 6 部分](#pt6.xhtml) 中，描述了一些为设定和衡量标准而开发的方案。在大多数情况下，这些方案都由监管机构支持，并且描述了其中一些机构的地位。还特别关注了数据保护问题，目前在世界许多地区已实施了相关法规。该部分最后提供了有关未来可能变化的几点提示。

# 第十四章 标准、行为准则和监管机构

DOI: [10.4324/9780203992319-21](https://dx.doi.org/10.4324/9780203992319-21)

## 14.1 监管框架

鉴于信息系统的完整性和安全性至关重要，人们可能会期望公共机构渴望鼓励监督和监管。事实上，许多政府和国际机构都已启动了相关举措。然而，由于众多希望成为监管者的机构各自拥有自己的标准、规则、基准和行为准则，情况变得混乱。有些由政府赞助，有些由行业联盟赞助，还有些由专业和消费者团体赞助。总体而言，结果并不十分连贯。一方面，有资源充足的机构能够通过严格的程序执行其标准，另一方面则是一些机构，尽管名称听起来令人印象深刻，却缺乏实质或权威。

这使得任何寻求“官方”指导或保证的人都难以应对。关于谁有权在特定情况下行使管辖权以及基于什么依据，也存在很大的混淆可能。这种不太理想的状况有几个原因，主要如下。

* 技术继续快速发展，为制定规则和法规的人设定了不断变化的目标。
* 网络交易越来越多地在全球范围内进行，因此监管制度必须在全球范围内才能有效。这不可避免地会产生巨大压力，因为各国都在争取其认为符合国家利益的东西。
* 由于信息系统渗透到业务的许多方面，其监管并不 neatly 适合任何一个职业、行业部门或政府机构的职权范围。
* 在技术层面，有大量业务软件和硬件产品可供选择。每个组织都以自己的方式设置产品组合。很难预测当所有这些产品组合在一起形成系统并开始相互作用时，会出现何种漏洞。
* 即使有意建立监管制度，也严重缺乏具备适当技能和知识来付诸实践的人才。

面对这些阻碍进展的障碍，令人惊讶的是，事实上已实施了许多有用且值得称道的措施。引入一定程度的秩序和保证的努力可以从三个不同方向看到，如 [Figure 14.1](#ch14.xhtml#fig14_1) 所示。

就 *产品* 而言，“标准”有两种截然不同的相关方式。首先，标准可以以详细规范的形式应用，指示产品应如何工作。例如，如果要在网络上在两台计算机之间建立连接，往返的消息必须在两端以完全相同的方式处理。这取决于 *标准化*，这对于基本通信协议以及应用于消息的任何安全功能（例如加密或消息认证码）都是必要的。

“设定标准”还有更常见的含义，其目的是确保产品达到一定的 *质量* 水平。例如，可以编写一个忠实遵循 SET 或 SSL 等安全协议的程序，但其中包含的编码缺陷使其容易受到不法分子的攻击。对于安全相关产品，实施必须在 *两种* 意义上都符合标准。其中，证明产品质量良好且无缺陷通常要困难得多。为此，必须对产品的设计和编码进行严格审查，并在受控条件下将其置于各种问题情况或恶意攻击之下。安德森进行的多项研究已证明了此类检查的重要性，他发现了若干商业安全系统的实现存在弱点，包括智能卡和自动取款机（Anderson [1994](#reference.xhtml#ref_r5)）。

另一方面，符合 *标准化* 通常更容易检查，因为不正确的实现会产生明显的错误，甚至可能根本无法工作。例如，我对标准加密算法的不完全正确实现很可能产生输出，使得其他人即使使用正确的算法和密钥也无法解密。
