# 术语表

**访问控制**

: 一种识别信息系统授权用户、并确定他们被允许使用系统内哪些设施的方法。

**访问控制表**

: 一张列出所有被授权访问信息系统或其中某个应用程序人员的表。针对每个用户标识符，该表指明该用户被允许或不被允许做什么。

**ALE（年度损失期望值）**

: 一种比较风险的简单方法。针对给定威胁可能造成的损害估算出一笔现金金额，然后乘以该威胁在任何一年内发生的概率。

**算法**

: 在密码学中，指一组指令（通常以计算机程序的形式），决定明文如何转换为加密消息，反之亦然。

**应用控制**

: 其范围仅限于某一特定应用程序的控制。应用程序是指专门服务于组织内某一特定职能（如会计或计算机辅助设计）的单个程序或一套程序。

**非对称密码学**

: 一组基于特殊生成的密钥对使用的密码技术。一个密钥用于加密消息，另一个密钥用于解密。如果发送者保管好一个密钥（私钥）并公开另一个密钥（公钥），就有可能创建数字签名（见相关条目）。

**审计**

: 由独立评估人员进行的审查。审计概念由会计师发展而来，他们定期进行*外部*审计，以让利益相关者放心，确信组织的财务事务得到妥善管理。*内部*审计由组织内部员工执行，通常以更持续的方式进行。

**审计追踪**

: 一组证据，使审计员能够追踪业务流程每个阶段发生了什么。追踪记录可能包含计算机记录和纸质文档的混合体。

**认证 / 鉴权**

: 通常通过自动化手段，由电子交易双方中的一方提供身份证明。

**生物特征识别 / 生物测定学**

: 可用作自动识别基础的一个人的物理属性或特征，例如独特的声纹或指纹模式。

**分组密码**

: 一种加密方法，其中数据首先被分成固定长度的块（通常为 64 位或更多）。然后每个块依次由密码算法进行转换。这会给数据带来一些“断续性”，这可能使该技术不适合“实时”声音或视频传输。另见流密码。

**业务连续性规划**

: 一项全企业范围的工作，旨在识别可能严重损害业务运作能力的威胁。然后制定计划以消除此类威胁，或在无法预防时将其影响降至最低。

**CEN（欧洲标准化委员会）**

: 也称为欧洲标准化委员会。致力于推广欧洲的技术标准。

**认证机构**

: 一个信誉良好的机构，颁发电子证书以证明公钥的真实性。每个证书至少应显示密钥所有者的身份（无论是个人还是组织）、密钥的副本以及有效期。证书应由 CA 进行数字签名。

**校验位**

: 在参考号码（如增值税注册号或信用卡号）末尾添加一位或两位额外数字。每当号码被重新录入系统时，这些额外数字都会被重新计算，作为检查该号码是否有效的一种方式。

**中间隔离 / 防火墙**

: 一种安排，即同一组织内的人员之间对某些信息（通常与客户有关）相互保密。

**CISA（注册信息系统审计师）**

: 由 ISACA（见相关条目）管理的资格认证。

**COBIT（信息及相关技术控制目标）**

: 一套由 ISACA（见相关条目）开发的用于实施安全和控制的标准。

**冷备份**

: 发生灾难时可将计算机服务转移至的备用站点。该站点仅具备基本设施，可能需要一两天时间才能使服务启动运行。

**并发性**

: 适用于内置于系统中的计算机审计功能的术语，这些功能可以在系统实际使用时被激活。

**控制总计**

: 如果正在向应用程序录入一批条目，或正在执行一系列计算，系统会按数量或价值计算出一个适当的总计。然后独立地重新计算该总计，并将两个结果进行比较。

**CRAMM（CCTA 风险分析与管理方法）**

: 由英国政府中央计算机与电信局设计的一种风险分析方法论。

**CRL（证书吊销列表）**

: 由认证机构发布的列表，列出了其已颁发但尚未到期、但 CA 希望注销的证书。该列表应由 CA 进行数字签名，以证明其真实性。

**对策**

: 针对信息系统的每一种威胁，都会有一种或多种可能的对策。这些对策要么防止威胁发生，要么大幅降低其影响。

**密码学**

: 使用算法和密钥对数据进行转换，使其能被他人复现或逆向还原。最初主要用于提供通信保密性，密码学现在在提供防篡改、签名和时间戳等功能方面发挥着大大扩展的作用。

**数据加密标准**

: 一种基于 64 位分组的对称加密技术，首次作为标准发布于 1977 年。

**解密**

: 对加密消息进行解码，以显示（有意义的）明文。有时也称为破译消息。

**Diffie-Hellman 密钥交换**
