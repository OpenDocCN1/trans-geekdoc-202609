## 1.7 Questions

1. 判定以下每起事件适用哪一类威胁（定义见[section 1.5](#ch1.xhtml#ch01_sa5)）。
   * 一名秘书重新格式化了一张软盘（从而删除了盘上的所有数据），她认为盘中包含的是无人需要的旧备忘录。事实上，盘中保存的是首席执行官一份重要报告的唯一副本。
   * 一名应收账款职员在正常工作时间以外接受客户的现金付款，开具手写收据且不做任何记录。他将钱据为己有。
   * 一名秘书认为办公室使用的图形软件包对她儿子的家庭作业有用，于是将其复制到软盘上，以便带回家在自己的电脑上使用。
   * 一家公司在一栋大型办公楼内租用空间。其中另一名租户篡改了燃气供暖系统，造成大爆炸，导致该公司的本地网络服务器停止运行。
   * 一名刚刚被裁员的员工在办公桌上度过最后几分钟，删除了重要的电子邮件记录，并用一系列关于管理层的贬损性信息取而代之。

2. 以与问题1相同的方式分析以下问题。注意，这些案例分类起来更困难（例如可能涉及不止一类威胁）。
   * 员工A有权合法访问会计系统。在A离开座位时，来自另一部门的员工B使用她的终端机提高当月自己的薪酬。
   * 一名报社记者贿赂一名护士，以便从病人管理系统获取有关正在医院接受治疗的一名演艺界人士的信息。
   * 一名员工从一个共享软件互联网站点下载了一个被宣传为“包治百病”的防病毒软件包。该软件实际上包含一种危险的病毒，很快导致办公室多台PC停止运行。
   * 一名初级员工致电高级经理的秘书，自称是内部审计员，正在检查密码。他要求并获得了经理的密码。然后他以经理身份登录，向全体员工发送了一封恶作剧电子邮件，并对当月的销售数据进行了修改。

3. 在以下情况下，你作为经理可能施加什么影响？
   * 一名自由职业顾问受聘一个月，紧急制作一份成本效益分析报告。顾问已获得公司会计和生产系统的完全访问权限。她经常将数据下载到她的便携式PC上在家工作。该PC似乎缺乏任何安全功能，而你的员工刚刚把一台遗留在员工餐厅椅子上的电脑带给你。
   * 你是某家大街银行当地分行的经理。一名愤怒的客户寄回一张新发行的取款机卡，说卡不能用。事实证明，客户已在卡背面写上了他的个人识别号码（PIN）。如果你：
     1. 卡因在上面写PIN号码而受损？
     2. 卡最初编码错误，因此故障实际上是银行的过错，与写PIN号码无关？
   * 你收到一封来自互联网上一个你从未听说过的来源的电子邮件。它邀请你访问一个“火爆”的色情网站，并指出同样的邀请已发送给组织内其他人。

4. 将以下威胁归类为“内部”或“外部”（如果合适，请指出威胁兼具两者特征）。
   * 系统管理员通过电子邮件向你发送新的登录密码。你的秘书按时打印出该信息并放在开放式办公室的你的办公桌上。
   * 你向客户发放磁条卡以识别他们。其中一张卡被借用、复制并用于冒充持卡人。
   * 一名不明的电话呼叫者致电负责管理你的局域网（LAN）服务器的高级秘书。呼叫者讲了一个合理的故事，结果秘书透露了进入LAN的你的密码。
   * 来自你的会计系统的定期报告显示，你的三个供应商似乎都位于同一地点，而该地点实际上是一个住宿地址。没有人注意到这一点。

## 2.1 Why Appraise Risk?

列出可能适用于信息系统的所有威胁相对容易。然而，其中一些可能极不可能发生，或造成的损害微乎其微。可以安全地忽略它们，因为担心它们会浪费每个人的时间。另一方面，清单中可能包括更频繁发生的威胁，或发生频率较低但可能造成毁灭性后果的威胁。在这种情况下，管理层必然要求采取行动应对它们。大多数威胁介于这两个极端之间。问题在于，在决定如何处理之前，如何权衡威胁的严重性。

这种情况可以与房主在决定如何保护房屋时面临的情况相比较。可以想象各种各样的危险，包括火灾、水灾、天上掉落的碎片、燃气爆炸、盗窃、结构坍塌和风暴损坏。虽然房主力求尽可能安全地防范此类威胁，但他们不会试图消除每一种可能的风险。做到这一点将涉及用防爆墙加固房屋，在每个房间安装电子设备以探测入侵者，并在屋顶安装导弹电池以粉碎可能从飞机上掉落的碎片。采取此类措施的成本和不便会被认为是不合理的，除非是处于高度偏执状态的人。同时，大多数房主会期望采取防范更常见威胁的预防措施，例如安装烟雾探测器、窗锁和防盗报警器。
