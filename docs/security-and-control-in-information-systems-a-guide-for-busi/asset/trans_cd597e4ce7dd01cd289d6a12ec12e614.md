

病毒是最常见且最广泛经历的数据安全事件原因。在大多数情况下造成的损害很轻微，但宽松的程序与坏运气结合起来，可能导致整台 PC 或 LAN 完全混乱。

由于病毒攻击的概念现在已为大多数人所熟悉，人们想出了各种诡计来利用他们的恐惧。其中常见的一种是电子邮件信息，警告称通过电子邮件传播一种极其危险的病毒：如果用户收到包含特定标题信息的邮件，决不能打开它，因为 PC 的硬盘将立即严重损坏，等等等等。这些警告通常被呈现为源自某些权威来源，例如 IBM 或 Microsoft 或官方机构。收件人被敦促将警告转发给他人。这些信息大多是恶作剧，目的是让很多人担心，并产生大量无意义的电子邮件流量。员工应被告知绝不要转发此类信息，除非也许转发给有能力评估信息是否真实的 IT 部门人员。

其他危害不断出现在互联网上。其中一些是规模和复杂程度各异的恶意程序，使原始的 DOS 病毒看起来非常原始。这里描述了一些例子。

## 8.6 规范互联网的使用

安装互联网连接，无论是通过组织网络的一部分的网关，还是通过直接连接到 PC 的电话线，现在都是一项相对简单的任务，可以在几分钟内完成。在授权此类连接之前，管理层应确信它将是有用且必要的。否则它将制造大量危害，却毫无意义。

一种可用的控制选项是使用过滤机制，限制 PC 用户可以进行的活动。这一领域的主要倡议来自学校和家长组织，他们担心儿童能够从互联网上检索“成人”材料。一个例子是 Internet 4 Families（见 [Figure 8.1](#ch8.xhtml#fig8_1)）。

企业可能希望使用类似的筛选方式，以防止员工通过办公设施浏览不合适的网站。筛选可以通过多种不同的方式进行。

* 检查可以基于网页头中包含的类别代码。对此类代码的标准已被提出（“互联网内容选择平台”，或 PICS）。然而，这取决于网页提供者广泛合作并包含代码，这并不总是能实现。
* 可以依赖商业提供的“过滤列表”。这是一个网站地址列表，会不断更新，以包含提供商认为应被 *排除* 的所有网站的内容。这可以与在私人电话交换机中设置“禁止”电话号码列表相比较。
* 供应商正在开发“智能”过滤器，它们检查传入的图像并寻找可疑特征，例如肉色比例过高。这可能会捕获更明显的色情形式，但始终存在风险，即它也可能反对董事会成员的数字化肖像，而这些肖像急需纳入年度报告中。此类程序还必须能够处理图像传输的许多不同格式（包括视频和各种图像压缩形式）。
* 如果对互联网的合法使用预计仅限于少数几个网站，则可以指定这些网站为唯一要 *包含* 的网站。
* 过滤也可以应用于从 PC *发出* 的消息。通常，用户产生的向互联网发出的流量很少，与作为回复发送的兆字节的屏幕图像和 Java 代码片段相比微不足道。这种传出流量可以针对网站地址或发送到搜索引擎中的关键词进行筛选。这种方法困难之处在于识别“违规”关键词。许多网站对性和暴力使用非常含糊和委婉的提法。

在与传入电子邮件相关的保护中也可能寻求额外保护，其中不受请求的“垃圾”消息很容易超过收到的合法消息的数量。筛选再次可以基于允许所有消息通过，除非它们源自禁止列表中的地址，或仅接受来自批准列表中的地址的消息。对于许多组织而言，后一种方法并不太可行，特别是如果它们依赖来自以前未知地址的电子邮件查询作为新业务来源。

供应商现在还提供可以“智能”扫描电子邮件的软件。这可以避免一些列表维护问题，但其使用也可能引发难以处理的伦理问题，这些问题在 [section 13.6.](#ch13.xhtml#ch13_sa6) 中进一步讨论。

## 8.7 问题

1. 你是二十名秘书和行政人员的办公室经理。你的员工通过 LAN 进行网络连接，通过该网络他们可以使用公司的电子邮件服务。他们无法访问互联网。写一份备忘录（约 500 字），为员工提供有关如何防范病毒感染的建议。包括在检测到病毒时应采取的行动的参考。
2. 解释计算机支持协作工作的引入如何可能改变员工与管理层之间的关系，特别是在合规和控制问题方面。
3. 一款会计软件广告称其包含“现代企业可能需要的一切控制”，并继续说“设置控制既快又简单，可以在几分钟内由没有任何系统使用经验的人完成”。解释为什么你可能会怀疑这些说法的真实性。通过描述一种产品可能难以兑现其承诺的控制类型来说明你的答案。
4. 你刚刚安装了一款新软件包来支持你小型企业的活动，该企业是一家位于城市商务区的旅行社。你可能希望对软件中的以下功能施加哪些限制，为什么？
    * 软件手册建议可以从互联网网站下载该软件包的定期升级。网站地址已提供。
    * 手册还解释了，如果客户取消预订，有一个命令会立即从系统中删除客户的所有详细信息和预订。

## 第四部分介绍

本书前面（在 [Chapter 2](#ch2.xhtml)）提到过处理风险的问题，其中潜在损害极其严重，但概率非常低。在这种情况下计算年度损失期望值总是会得出一个适中的数字，这本身并不太令人担忧。然而，每个人心里都会有这样的想法：如果损害 *确实* 发生，其影响可能是毁灭性的——甚至可能导致企业倒闭。
