

在着手证明某种不当行为确实发生时，过程中很可能会出现伦理问题。例如，在正常情况下会被视为私人的事项，可能需要进行核查。还有一种危险，即责任可能会被引导指向某一个特定的人，因为其他人试图撇清关系，导致那个人被孤立成为替罪羊。调查还必须基于公平和一致的原则。例如，如果一种做法在过去几年里一直被默许，那么突然引入“零容忍”政策并对违规者进行突击打击，几乎是不合理的。

伦理判断之所以尤其困难，是因为没有任何规则手册能够涵盖调查过程中可能出现的各种曲折。它们还因为管理层和员工双方的利害关系都可能很高而变得更加棘手。公司可能损失宝贵的信息资产，员工可能最终被解雇。这些是伦理决策，正如阿德里安·卡多伯里爵士所说，管理者需要“自己制定规则”。他的意思并不是说他们可以随意为所欲为；他的观点是，伦理、商业和其他方面的考虑经常会发生冲突，而且管理者可能会发现“伦理路标并不总是指向同一个方向”（Andrews [1989](#reference.xhtml#ref_r7)：70）。

那么管理者应如何着手“制定规则”呢？伦理学中一个被广泛接受的一般规则是，应该始终首先寻求对事实的完整而准确的版本。然而，在涉及信息系统的调查中，通常会有强烈感觉认为某些事实*不*应让调查人员获取。对隐私的尊重要求个人背景或活动的某些方面应被允许保持秘密。在某些情况下，类似的保护也可能由其他法律实体主张，例如合伙企业或公司。

提出了三条主要论点来主张尊重隐私，即使这可能会妨碍调查的进展。第一条强调需要在不受与案件无关但可能引起各种偏见的信息影响的情况下做出判断。这里借用法律理论家约翰·罗尔斯在发展其关于井然有序社会的概念时使用的“无知之幕”的想法很有用。罗尔斯认为，如果决策不受当事人“某些在道德上无关的信息”影响，将有助于制定公平的规则（Rawls [1999](#reference.xhtml#ref_r194)：236）。数据保护规则的共同目标是规定在何处以及如何施加无知之幕：例如，目前欧洲大部分数据保护法所依据的一项指令规定，数据应始终为特定目的而收集，并且不得以与该目的不一致的任何方式披露（EC [1995](#reference.xhtml#ref_r73)；参见[第14.4节](#ch14.xhtml#ch14_sa4)）。然而，此类规则不能绝对化，必须在更大的公共利益中允许例外。因此，例如，如果一名员工故意在系统中输入虚假信息，她几乎不能要求将其保密，理由是这纯粹是私事。与此同时，调查人员也没有理由翻查与员工相关的*所有*记录。在这一领域，很难定义明确的伦理或法律规则，尤其是在调查工作中；不可避免地会出现无法知道在寻找证据时可能会偶然发现什么的情况。

第二条论点关注数据主体的权利。这从这样一个假设开始，即个人可以对个人信息主张类似于所有权的权利。因此，如果信息被披露，始终应征得个人的同意。这在调查背景下又会产生问题，因为嫌疑人可能必须不知道调查正在进行。在这种情况下，征求同意只会暴露调查意图。无论如何，决定个人信息的“所有权”可能很困难，因为它经常是模糊的：例如，如果A已婚B，或者如果A已经向大量人提供了该信息。因此，一些作者更喜欢探讨个人在多大程度上可以通过控制个人信息的使用方式来主张其*自主权*（Gross [1971](#reference.xhtml#ref_r99)）。

最后，专业人士经常提出一个更务实的论点，他们从客户那里保密地接收信息。他们的担忧是，如果客户不能确信这些信息将被完全保密，他们就不会向他们提供亲密和个人细节。这在许多国家已成为一个主要问题，涉及家庭医生持有的记录。唐纳森和洛尔（Donaldson and Lohr [1994](#reference.xhtml#ref_r67)）指出，各种调查机构可能寻求获取此类记录，以追查医疗保健索赔或付款方面的可能不规则行为、虐待风险儿童的细节等。因此，医生已无法再保证信息不会超出诊疗室文件柜的范围，人们担心患者因此会更加谨慎。

这三种隐私观点绝非相互排斥，在任何特定情况下都可能同等重要。例如，在追查X的欺诈性健康保险索赔的过程中，可能出现了关于Y的医疗细节，而Y宁愿将其保密。假设Y是无辜的第三方，这可以被视为各种意义上的不公平释放无关信息、对Y隐私权的侵犯，以及对医患保密的违反。

使用执行电子通信例行扫描的程序也可能引发对员工隐私侵入的困境。当然，从监控系统提取的信息的使用可以使员工受益。例如，冒犯性电子邮件的传播肯定会让员工不安，事实上，如果组织不对违规者采取行动，它可能面临法律诉讼。在工作中完全的行动和通信隐私既不实际也不 desirable。然而，如果信息的使用不审慎，就很容易进入不可接受的领域，例如，如果一名员工因违反公司规则的轻微违规而被“挑出来”。拦截和干预必须始终以对所涉及的伦理问题敏感的方式进行。
