

窃听者关注的是*最低*层，因为他们希望在数据通过物理链路传输时（即沿着电线，或通过无线电波广播）获得数据的读取。因为数据将被切分成数据包，并且控制代码会混入其中，他们面临着从 resulting 杂乱中筛选并剔除与特定消息相关的有意义位点的挑战。可能有多个消息同时通过一条链路传输，这给窃听者带来了更大的问题。

因此，攻击者可能更倾向于针对中间（网络）层，该层决定消息如何在网络上传输。例如，用户 X 和 Y 之间可能存在两条可能的路由，如[图 6.2](#ch6.xhtml#fig6_2)所示。

![Figure 6.2 ](images/fig6_2_C.jpg)

[Figure 6.2 ](#ch6.xhtml#R_fig6_2)

路由软件期望在每个数据包中找到报头信息，其中包括发送者的地址（在本例中为用户 X）和目的地址（用户 Y）。网络层的作用是根据网络上当前的流量水平和其他相关条件，决定使用哪条路由。因此，它将决定消息是否经由节点 B 或节点 C。

如果入侵者能够找到某种方式破坏寻址系统或路由过程，这将为转移消息打开各种可能性。它也避免了可能因窃听特定链路而产生的问题，例如节点 A 和节点 B 之间的链路。毕竟，所寻求的消息最终可能经由节点 C 路由。对路由机制的成功干扰将使攻击者能够将消息发送到不同的目的地，创建虚假消息，或仅仅便于在更方便的位置进行窃听。关于消息路由的信息本身也可能引起兴趣，只是为了确定 X 和 Y 之间是否正在传输流量；在某些情况下，这本身就足以泄露有价值的信息。

最后，攻击者可以专注于顶层（应用层），该层与计算机中运行的应用程序进行交互。每当应用程序需要在网络上传送或接收数据时，就会调用这一层。数据的形式与应用程序用户所见的形式非常接近这一事实意味着它将更容易被解释。各类层的威胁总结于[表 6.1](#ch6.xhtml#table6_1)。

Table 6.1

| Layer || Data || Threats arise from: |
| --- | --- | --- |
| Application || Complete, and close to form actually seen by users || Interference with software on the user’s computer |
| --- | --- | --- |
| Network || Divided up, with control information added || Interference with the network routing software |
| Link || Divided up (may also be incomplete, if multiple routes are used) || Eavesdropping on individual nodes or links |

## 6.5 The Role of Cryptography

实际上不可能使每根电缆都防篡改，也不可能阻止未经授权的人在他们想听时监听无线电传输。然而，可以通过发送已被故意变得完全无法理解形式的消息来挫败他们。这是密码学的主要作用之一。密码学具有诸多优势，因为它可以在数据仍处于应用层时就被应用。这自动提供了在数据通过所有其他层移动过程中的拦截保护。这种密码学的使用有时被称为“端到端”（见[图 6.3](#ch6.xhtml#fig6_3)）。

![Figure 6.3 ](images/fig6_3_C.jpg)

[Figure 6.3 ](#ch6.xhtml#R_fig6_3)

将密码学用于保密消息的用途可以追溯到希腊和罗马时代（Beutelspacher [1994](#reference.xhtml#ref_r29)）。其中一种最早的方法由公元前五世纪的斯巴达将军发明。一条长而薄的纸条被螺旋式地缠绕在一根棍子上。然后沿着棍子的长度在纸上书写消息。当纸被展开时，它包含一串毫无意义的字母。然而，通过将纸缠绕在另一根直径相同的棍子上，接收者可以立即解码消息。如果纸条落入敌手手中，它看起来会包含完全的胡言乱语。

在二十世纪的大部分时间里，政府和军队一直以与斯巴达人相同的方式继续应用密码学。技术不断改进，但主要关注点是防止敌对国家窃听内部通信（Andrew [1996](#reference.xhtml#ref_r6)）。然而，近年来，便宜且充足的计算能力的出现促进了新型密码技术的发展，这些技术可用于其他目的。例如，它们可用于“签名和密封”消息。这些技术旨在保护数据的*完整性*而非保密性。它们对于确保业务数据准确且真实很有用，从而满足 Clark 和 Wilson ([1987](#reference.xhtml#ref_r53)) 提出的某些需求（见引言）。

密码学的机制实际上不需要对使用者可见。越来越多的供应商生产软件包来处理所有技术细节，并使用户能够通过点击简单的菜单和图标来应用密码学。尽管如此，盲目使用此类设施而不了解密码学提供的保护的优势和局限性，存在一定的危险。

密码学将人类可读的数据转换为看似完全无意义的数据位流。但结果只是*看起来*毫无意义：任何知道所使用密码算法并拥有正确密码密钥的人都可以逆转该过程，从而使材料变得有意义，如[图 6.4.](#ch6.xhtml#fig6_4)所示

在当今的多媒体世界中，“明文”实际上可能是一段语音录音、一张照片、一个视频剪辑，或任何其他基于位流的数据形式。现代加密方法可以处理任何以数字形式表示的东西。由于业务越来越多地使用包含图表和图解的电子文档，或包含声音和视频序列的计算机生成演示文稿，因此如果需要，所有此类材料都可以通过加密过程得到保护。

这与过去使用的加密方法之间存在显著差异。历史上，加密依赖于单个字母的*换位*（如斯巴达示例）或根据预先安排的方案将一个字母*替换*为另一个字母。后一种方法的例子是十六世纪布莱兹·德·维吉尼尔发明的密码（见[图 6.5](#ch6.xhtml#fig6_5)）。

维吉尼尔密码与现代加密方法之间的一个共同点是其对使用*密钥*的依赖。示例中显示的密钥长五个字符长，必须为消息的发送者和接收者所知。如同密码一样，一般原则是密钥越长越好。在行和列中查找字母的过程可以与当今加密中使用的*算法*相比较。
