# Layer 4—Transport

The Transport Layer handles packet sequencing, flow control, and error detection. TCP and UDP are Layer 4 protocols.

Layer 4 makes several features available, such as resending or re-sequencing packets. Taking advantage of these features is a protocol implementation decision. As we see later, TCP takes advantage of these features, at the expense of speed. Many of these features are not implemented in UDP, which chooses speed over reliability.

# Layer 5—Session

The Session Layer manages sessions, which provide maintenance on connections. Mounting a file share via a network requires several maintenance sessions, as Remote Procedure Calls (RPCs); these exist at session layer. A good way to remember the session layer’s function is “connections between applications.” The Session Layer uses simplex, half-duplex, and full-duplex communication.

> Note
The transport and session layers are often confused. For example, “maintenance of connections” a transport layer or session issue? Packets are sequenced at the transport layer, and network file shares are mounted at the session layer: you may consider either to be maintenance. Words “maintenance” imply more work than packet sequencing or retransmission: it requires “heavy lifting,” like removing a network share that has been un-mounted, so session layer is the best answer.

# Layer 6—Presentation

The Presentation Layer presents data to the application (and user) in a comprehensive way. Presentation Layer includes data conversion, character sets such as ASCII, and image formats as GIF (Graphics Interchange Format), JPEG (Joint Photographic Experts Group), and TIFF (Tagged Image File Format).

# Layer 7—Application

The Application Layer is where you interface with your computer application. Web browser, processor, and instant messaging client exist at Layer 7. The protocols Telnet and FTP are Application Layer protocols.

> Note
Many mnemonics help remember the OSI model. From bottom to top, “Please Do Not Sausage Pizza Away” (Physical Data-Link Network Transport Session Presentation Application) is a bit silly, but that makes it memorable. Also silly: “Please Do Not Sell People Anything.” From top to bottom, “All People See To Need Data Processing” is popular.
