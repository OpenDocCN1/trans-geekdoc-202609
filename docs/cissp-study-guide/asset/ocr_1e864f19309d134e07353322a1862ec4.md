# Routers

Routers are Layer 3 devices that route traffic from one LAN to another. IP-based routers make decisions based on the source and destination IP addresses.

> Note
in the real world, chassis, such as a Cisco 6500, can be many devices at once: a router, a switch, a firewall, a NIDS. The exam is likely to give more-clear examples: a firewall, a dedicated switch, or if the exam references a multifunction device, that will be made clear.
Regardless, it is helpful to know how to think of these devices as distinct concepts.

# Static and Default Routes

For simple routing needs, static routes may suffice. Static routes are fixed routing entries, saying “The route for network 10.0.0.0/8 routes via router 192.168.2.7; the route for network 172.168.0.0/12 routes via router 192.168.2.8,” most SOHO (Small/Home/Office Network) routers have a “default route” that sends all external traffic to (typically controlled by the ISP).\ Here is an example of a typical home LAN configuration:

+   - Internal network: 192.168.1.0/24
- Internal Firewall IP: 192.168.1.1
- External Network: 192.0.2.0/30
- External Firewall IP: 192.0.2.2
- Next hop address: 192.0.2.1

The firewall has an internal and external interface, with IP addresses of 192.168.1.1 and 192.0.2.2, respectively. Internal (trusted) hosts receive address addresses on the 192.168.1.0/24 subnet via DHCP. External traffic is NAT-translated to the external firewall IP of 192.0.2.2. The default route for internal hosts is 192.168.1.1. The default route is 192.0.2.1. This is a router owned and controlled by the ISP.
