# 802.11

802.11 wireless has many standards, using various frequencies and speeds. The original mode is simply called 802.11 (sometimes 802.11-1997, based on the year it was created), which operated at 2 megabits per second (Mbps) using the 2.4 GHz frequency; it was quickly supplanted by 802.11b, at 11 Mbps. 802.11g was designed to be backwards compatible with 802.11 devices, offering speeds up to 54 Mbps using the 2.4 GHz frequency. 802.11a offers the same top speed, using the 5 GHz frequency.

802.11 uses 2.4 and 5 GHz frequencies, and is able to use multiple antennas with multiple-input-output (MIMO). This allows speeds up to 600 Mbps. 802.11ac uses the 5 GHz frequency, offering speeds up to 3 Gbps. Finally, 802.11ax uses the 2.4, 5, and 6 GHz bands, offering speeds up to 10 Gbps.

The 2.4 GHz frequency can be crowded: cordless phones and baby monitors use its frequency, as Bluetooth and some other wireless devices. Microwave ovens can interfere with 2.4 GHz devices. # Managed, Master, Ad-Hoc, and Monitor Modes

802.11 wireless NICs operate in four modes: managed, master, ad hoc, and monitor mode.

802.11 wireless clients connect to an access point in managed mode (also called client mode). Once connected, clients communicate with the access point only; they cannot directly communicate with other clients.

Master mode (also called infrastructure mode) is the mode used by wireless access points. A wireless card can only communicate with connected clients in managed mode.
