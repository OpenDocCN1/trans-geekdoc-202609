VNC and RDP allow for graphical access of remote systems, as opposed to the older terminal-based approach to remote access. RDP is a Microsoft protocol.

Increasingly, users are expecting access to a graphical desktop over the Internet that can be established quickly and from any number of devices. These expectations can prove difficult with traditional VNC and RDP based approaches, which for security purposes, are frequently tunneled over an encrypted channel such as a VPN.

Recent alternative to these approaches is to use a reverse tunnel, which allows a user who established an outbound encrypted tunnel to connect back through the same tunnel. This usually requires a small agent installed on the user's computer to initiate an outbound connection using HTTPS over TCP 443. This connection will terminate at a central server, which the user can authenticate to (from outside the office) to take control of their office desktop machine. Two of the most prominent solutions that employ this style of approach are GoToMyPC and LogMeIn.

# Desktop and Application Virtualization

In addition to accessing standalone desktop systems remotely, another approach to providing remote access to computing resources is desktop and application virtualization. Desktop virtualization is an approach that provides a centralized structure that hosts a desktop image that can be remotely leveraged by the workforce. Desktop virtualization is often referred to as VDI, which, depending on the vendor stands (for either Virtual Desktop Infrastructure or Virtual Desktop Interface), is also called DaaS (Desktop as an Infrastructure).

As opposed to providing a full desktop environment, an organization can choose to simplify key applications that will be served centrally. Like desktop virtualization, the centralization associated with application virtualization allows the organization to employ strict access control, and perhaps more quickly patch the application. Additionally, application virtualization can also be used to run legacy applications that would otherwise be unable to run on the systems employed by the workforce.

While the terms and particulars of the approach are relatively new, the underlying concepts of both desktop and application virtualization have existed for decades in the form of thin clients, mainframes, and terminal servers. The main premise of the refreshed and more traditional approaches is that there might more organizational benefits to having more centralized and consolidated computing systems and infrastructure rather than a large number of more complex systems. In addition to general "economies of scale" justifications, there could be security advantages to more tightly controlled desktop and application environments.
