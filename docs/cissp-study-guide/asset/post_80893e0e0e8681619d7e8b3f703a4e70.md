Multimode fiber carrier uses multiple modes (paths) of light, resulting in light dispersion. Single-mode fiber uses a strand of fiber, and the light uses one mode (path) down the center of the fiber. # Ethernet Technologies and Protocols

Local Area Network concepts focus on layer 1–3 technologies such as network cabling types, physical and logical network topologies, Ethernet, and others.

# Ethernet

Ethernet is a dominant local area networking technology that transmits network data via frames. It originally used a physical bus topology, but later added support for physical star. Ethernet describes Layer 1 issues such as frames. Ethernet is baseband (one channel), so it must address issues such collisions, where two nodes attempt to transmit data simultaneously.

Ethernet has evolved from 10-megabit buses that used "thinnet" or "thicknet" coaxial cable. The star-based physical layer uses Twisted Pair cables that range in speed from 10 megabits to 1000 megabits and beyond. A summary of these types is listed in Table 5.7.

# CSMA

Carrier Sense Multiple Access (CSMA) is designed to address collisions. Ethernet is baseband media, which is the equivalent of a “party line,” In the early days of phone service, many people did not have a dedicated phone line for their house: they shared a party line with their neighbors. A protocol emerged for using the shared line:

1. Lift the receiver and listen to determine if the line is idle
2. If the line is not idle, hang up and wait before trying again
3. If the line is idle, dial

Ethernet works in the same fashion, but there is one state that has not been accounted for: two neighbors lift their receivers and listen to hear if the line is in use. Hearing nothing, both dial simultaneously. Their calls “collide”: the integrity of theirs is ruined. CSMA is designed to address collisions.

Carrier Sense Multiple Access with Collision Detection (CSMA/CD) is used to immediately detect collisions within a network. It takes the following steps:

1. Monitor the network to see if it is idle
2. If the line is not idle, wait a random amount of time
3. If the line is idle, transmit
4. While transmitting, monitor the network
5. If more electricity is sent, another station must also be sending
   (a) Send signal to all nodes to stop transmitting
   (b) Wait a random amount of time before retransmitting

CSMA/CD is used for systems that can send and receive simultaneously, such as wired Ethernet. CSMA/CA (Collision Avoidance) is used for systems such as 802.11 wireless that cannot send and receive simultaneously. CSMA/CA relies on receiving an acknowledgment from the receiving station: if no acknowledgment is received, there must have been a collision, and the node will wait and retransmit. CSMA/CD is superior to CSMA/CA because collision detection detects a collision almost immediately.

Physical Network Topologies describe Layer 1 locally: how the cables are physically run. Over the years, many, such as the bus and ring, have faded as the star topology has become dominant.

# Legacy Topologies

A physical bus connected nodes in a string. Thinnet and Thicknet were bus technologies. A physical ring connected nodes in a ring: if you followed the cable from node to node, you would finish where FDDI (Fiber Distributed Data Interface) was a ring technology. All are considered legacy technologies that have been overtaken by star.

# Star

Star topology has become the dominant physical topology for LANs. Each node is connected directly to a device such as a hub or switch, as shown in Fig. 5.14.

# WAN Technologies and Protocols

ISPs and other “long-haul” network providers whose networks span from cities to countries often use Wide Area Network technologies. Many of us have hands-on experience configuring LAN technologies such as Cat5 cabling; it is less common to have hands-on experience building WANs.

# T1s, T3s, E1s, E3s

There are several international circuit standards: the most prevalent are T Carriers (United States) and E Carriers (Europe). A T1 is a dedicated 1544-megabit circuit that carries twenty-four DS0 (Digital Signal 0) channels (as circuit-switched phone calls). Note the terms DS1 (Digital Signal 1) and T1 are often used interchangeably. DS1 describes the flow of bits (via any medium, such as copper, fiber, and wireless); a T1 is a telephone circuit that carries a DS1.

A T3 is a bundled T1s, forming a 44736-megabit circuit. The terms T3 and DS3 (Digital Signal 3) are also used interchangeably, with the same T1/DS1 distinction.

# Frame Relay

Frame Relay is a packet-switched Layer 2 WAN protocol that provides no error recovery and focuses on speed. Higher layer protocols carried by Frame Relay, such as TCP/IP can be used to provide reliability.

Frame Relay multiplexes logical connections over a single physical connection to create Virtual Circuits; this shared bandwidth model is an alternative to dedicated circuits as T1, a PVC (Permanent Virtual Circuit) is always connected to a real dedicated circuit like T1. A Switched Virtual Circuit (SVC) sets up "call," transfers data, and terminates the connection after an idle timeout. Frame Relay is addressed locally via Data Connection Identifiers (DLCI), pronounced "delci".

# X.25

X.25 is an older packet-switched WAN protocol. X.25 provided a cost-effective way to transmit data over long distances in the 1970s through the early 1990s, when the most common option was a direct call via analog modem. X.25's popularity has faded as the Internet has become ubiquitous.

The global packet-switched X.25 network is separate from the global IP-based Internet. X.25 performs error correction which can add latency on long links. It can carry other protocols such as TCP/IP, but since TCP/IP contains its own reliability, there is no need to take the extra performance by also providing reliability at X.25 layer.
