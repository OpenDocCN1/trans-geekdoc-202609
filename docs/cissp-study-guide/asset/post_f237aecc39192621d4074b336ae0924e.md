## MAC Addresses

A Media Access Control (MAC) address is the unique hardware address of an Ethernet network interface card (NIC), typically “burned in” at the factory. MAC addresses may be changed in software.

> Note: Burn-in MAC addresses should be unique. There are real-world exceptions to this, often due to mistakes by NIC manufacturers, but MAC addresses are considered unique on the exam.

Historically, MAC addresses are 48 bits long. They have two halves: the first 24 bits form the Organizationally Unique Identifier (OUI) and the last 24 bits form a serial number (formerly called an extension identifier).

Organizations that manufacture NICs, such as Cisco, Juniper, HP, IBM, and many others, produce 24-bit OUIs from the Institute of Electrical and Electronics Engineers (IEEE), Incorporated Registration Authority. A list of registered OUIs is available at https://www.ieee.org/products-programs/regauth/.

Juniper owns 00-05-85, for example. Any NIC with a MAC address beginning with 00:05:85 is a Juniper NIC. Juniper can then assign MAC addresses based on their OUI: the first would have MAC address 00:05:85:00:00:00, the second 00:05:85:00:00:02. This process continues until the serial numbers for that OUI have been exhausted. A new OUI is needed.

## EUI-64 MAC Addresses

The IEEE created the EUI-64 (Extended Unique Identifier) standard for 64-bit MAC addresses. The OUI is still 24 bits, but the serial number is 40 bits for far more MAC addresses, compared with 48-bit addresses. IPv6 autoconfiguration is compatible with types of MAC addresses.

## IPv4

IPv4 is Internet Protocol version 4, commonly called “IP.” It is the fundamental protocol of the Internet, designed in the 1970s to support packet-switching networking for the United States Defense Research Projects Agency (DARPA). IPv4 was used for the ARPANET, which later became the Internet.

IP is a simple protocol, designed to carry data across networks. It is so simple that it requires a “helper protocol” called ICMP (see below). IP is connectionless and unreliable; it provides “best effort” delivery of packets. If connections and reliability are required, they must be provided by a higher-level protocol by IP, such as TCP.

IPv4 uses 32-bit source and destination addresses, usually shown in “dotted quad” format, such as “192.168.2.4.” A 32-bit address field allows $2^{32}$, or nearly 4.3 billion, addresses. A lack of IPv4 addresses in a world where humans (and their devices outnumber available IPv4 addresses is a fundamental problem: this was one of the factors leading to the creation of IPv6, which uses larger 128-bit addresses.

### IP Fragmentation

If a packet exceeds the Maximum Transmission Unit (MTU) of a network, a router along the path it may fragment. Fragmentation breaks a large packet into multiple smaller packets. A typical MTU size for an IP packet is 1500 bytes. The IP identification field (IPID) is used to reassociate fragmented packets (they will have the same IPID). The flags are used to determine if fragmentation is allowed, and whether more fragments are coming. The fragment offset gives the data offset the current fragment carries: "Copy this data beginning at offset 1480."

Path MTU uses fragmentation to discover the largest size packet allowed across a network. A large packet is sent with the DF (not fragment) flag set. A router with a smaller MTU than the packet size will seek to fragment, that it cannot, and drop it, sending a "Fragmentation needed" ICMP message. The sending node sends smaller packets with the DF flag set, they pass cleanly across the network.

## IPv6

IPv6 is the successor to IPv4, featuring larger address space (128-bit addresses compared to IPv4's 32 bits), simpler routing, and simpler address assignment. A lack of IPv4 addresses was the primary factor that led to the creation of IPv6.

IPv6 has become more prevalent since the release of the Microsoft Vista operating system, the first Microsoft client system to support IPv6 and it enabled by default. All versions through Windows 11 have the same. Other modern operating systems, such as OS X, Linux, UNIX, also enable IPv6 by default.

> Note: The IPv6 address space is $2^{128}$, which is big: there are over 34 undecillion IPv6 addresses, which is 340,282,366,920,938,463,463,374,607,431,768,211,456.

### IPv6 Addresses and Stateless Autoconfiguration

IPv6 hosts autoconfigure (SLAAC) using the host's MAC address. The "ifconfig" output in Fig. 5.3 shows the MAC address 00:0c:29:ef:11:36. IPv6 addresses are 128 bits long and use colons instead of dots. Sections of zeroes are condensed into two colons.

- Version: IP version (4 for IPv4)
- Traffic Class: used for QoS
- Flow Label: for routing
- Payload Length: length of the header
- Next Header: embedded protocol
- Hop Limit: to prevent routing loops

- IPv6 addr fc01::20c:29ff:feef:1136/64 Scope:Global
- IPv6 addr fe80::20c:29ff:feef::1136/64 Scope:Link
