# Cable Modems

Cable modems are used by Cable TV providers to provide Internet access via broadband TV. Cable TV access is not ubiquitous but is available in many large towns and cities in industrial areas. Broadband, unlike baseband, has multiple channels (like TV channels), dedicating bandwidth for network services requiring dedicated channels for that purpose. Cable modems provide a compelling “last mile” solution for the Cable TVs; they have already invested in connecting the last mile, and the Internet service offers another revenue stream based on investment.
Unlike DSL, Modem bandwidth is typically shared with neighbors on the same network segment.

# Callback and Caller ID

Callback is a modem-authentication system. When a callback account is created, the modem user will call for entered into the account. The user later connects via modem and authenticates. The system hangs up and calls the user back at the preconfigured number.
Caller ID is a similar method; in addition to username and password, it requires calling from the correct phone number. Caller ID can be easily forged: many providers allow the end user to select any Caller ID of their choice. This makes Caller ID a weak form of authentication.
