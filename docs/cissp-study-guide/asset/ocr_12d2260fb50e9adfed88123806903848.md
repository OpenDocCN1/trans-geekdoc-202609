# TCP

TCP is the Transmission Control Protocol, a reliable Layer 4 protocol. TCP uses a three-way handshake to create reliable connections across a network. TCP can reorder segments that arrive out of order, and retransmit missing segments.

# Key TCP Header Fields

A TCP header, shown in Fig. 5.5, is 20 bytes long (with options), and contains a number of fields. Important fields include:

+   - Source and Destination port
- Sequence and Acknowledgment Numbers: Keep full-duplex communication in sync
- TCP Flags
- Window Size: Amount of data that may be sent before receiving acknowledgment

# TCP Ports

TCP connects from a source port to a destination port, as from source port 51178 to destination port 22. The TCP port is 16 bits, allowing port numbers from 0 to 65535.

There are two types of ports: reserved and ephemeral. A reserved port is 1023 or lower; ephemeral ports require super-user privileges to open a reserved port. Any user may open an (unused) ephemeral port.
Common services like HTTP use well-known ports. The Internet Assigned Numbers Authority (IANA) maintains a list of well-known ports at https://www.
