# Network Architecture and Design 263

One of the goals of SDN is to allow micro-segmentation: nimble and customizable networking capabilities. A hallmark of SDN is the potential for achieving flexibility using inexpensive "white-box" networking hardware and open protocols rather than traditional proprietary hardware, firmware, and software. Another common goal with SDN is to accommodate dynamic instantiation of networking capabilities rules as they become needed within the infrastructure.

The well-known protocol in this space is OpenFlow, which can, among other capabilities, allow for control of switching rules to be designated or updated at a central controller. OpenFlow is a TCP protocol that uses TLS encryption.

# Software-Defined Wide Area Network

Software-Defined Wide Area Network (SD-WAN) takes the concept of Software-Defined Networks and scales it to the cloud. It uses a combination of various technologies, including MPLS, cellular, and broadband: A Software-defined Wide Area Network (SD-WAN) is a virtual WAN that allows enterprises to leverage any combination of transport services—including MPLS, LTE and broadband services—to connect users to applications. An SD-WAN uses a centralized function to securely and intelligently direct traffic across the WAN and directly to SaaS and IaaS providers. This increases application performance and delivers a high-quality user experience, which increases business productivity and agility and reduces IT costs [10].

SD-WAN can automatically provide the best connection for any user or application lets networks route traffic based on centrally managed rules, no matter the entry and exit points of the traffic are, and with full security. For example, if a user in a branch office is working in Office365, SD-WAN can route their traffic directly to the closest cloud data center for that app, improving networking responsiveness for the user and lower bandwidth costs for the business [11].

# Virtual Extensible Local Area Network

Virtual Local Area Network (VXLAN) extends the concept of VLANs (Virtual Local Area Networks, discussed later in this chapter) to cloud. VLAN support 4096 segment IDs (or VLANs), VXLAN supports 16 million segment IDs (hence "extensible”), allowing global scale. VXLAN encapsulates data via UDP port 4789; the encapsulation and de-encapsulation is done by VTEPs (Virtual Tunnel Endpoints).

VXLAN is a technology that allows you to segment your networks (as VLANs do) but also solves the scaling limitation of VLANs and provides benefits that VLANs cannot. Some of the important benefits of using VXLANs include:

+   - You can theoretically segment as many as 16 million VXLANs in an administrative domain (as opposed to 4094 VLANs).
- VXLANs provide network segmentation at the scale required by cloud builders to support large numbers of tenants.
