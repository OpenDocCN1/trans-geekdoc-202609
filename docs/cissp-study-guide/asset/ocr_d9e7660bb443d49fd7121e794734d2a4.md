| Class | IP Range |

| Class D (multicast) | 224.0.0.0-239.255.255 |
| Class E (reserved) | 240.0.0.0-255.255.255 |

Similarly, the Class C network of 192.0.2.0 contains any IP address that begins with 192.0.2.0:22.177, 192.0.2.253, etc. That Class network is 192.0.2.0/24 in CIDR format: the first 24 bits (192) describe the network; the remaining 8 bits (177 or 253 in the previous example) describe the host.

Once networks are described in CIDR notation, additional routable network sizes are possible. Need 128 IP addresses? Chop a Class C (/24) in half, resulting in two /25 networks. Need 64 IP addresses? Chop /24 network into quarters, resulting in four / 26 networks with 64 IP addresses each.
