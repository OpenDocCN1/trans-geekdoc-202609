formula we use, related to adding up all the distance between points and centroids, is:

```
$J = \sum_{j=1}^{n} \sum_{i=1}^{c} ||x_i - d_j|^2$
```

where $n$ is the number of clusters, $c$ the number of data points and the right half is measuring the distance between each data point and a centroid.
