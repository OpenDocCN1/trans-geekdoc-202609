**Intellectual property:** Referred to created works such as music, art and literature.

**Internet of things:** A network of interconnected devices embedded with sensors and software.

**Interval:** A type of quantitative data where the difference between values is meaningful, but there is no true zero – an example is temperature in Celsius.

**Latency:** The delay in transferring or processing data.

**Lineage:** The origin and history of the data set.

**Linear regression:** A statistical method that models the relationship between a dependent variable and one or more independent variables using a straight line.

**Lists:** A simple collection of items, usually in a specific order.

**Load:** Where data is placed in a data store.

**Machine learning:** Where software designed to perform a task improves the more it undertakes a task.

**Metadata:** Data about data.
