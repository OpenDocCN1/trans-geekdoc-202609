To be used in our tools and models, the data might need to be of a particular data type. For example, if we are forecasting future values over time, the dates in our data set will need to have the data type date/time. However, they could have been stored as a string data type, or the data type might have been corrupted in our export or load. Another example is where an integer is stored as a float or a string. It is therefore important to check and, where necessary, change the data type.

When using dates, it is also worth considering their format. You might just be interested in the day, month and year, but the date may include a time as well. In this case, you might need to change the data type to address this or, in some instances, restructure the data to remove the parts that are not required.

Scale

When we measure things, we use different units of measurement, and these often have different ranges. For example, in measuring age we normally use years, and this range might be 0 to 120, if you are very lucky. In measuring daily mobile phone usage, the unit could be minutes and the range 0 to 1440, if you are an insomniac.
