# Choose the right chart type

Selecting the appropriate chart type is like choosing the right tool for a job. Different types of data and messages call for different visual representations.

![](bbox=[0.125, 0.357, 0.203, 0.411])

**Bar charts:** These are great for comparing quantities across categories.

![](bbox=[0.125, 0.537, 0.199, 0.591])

**Line charts:** They are ideal for showing trends over time.

![](bbox=[0.125, 0.681, 0.203, 0.735])

**Pie charts:** These are useful for displaying percentages or the share of a whole. Be careful, though, because pie charts are often over-relied upon and used for the wrong purposes. Use sparingly.
