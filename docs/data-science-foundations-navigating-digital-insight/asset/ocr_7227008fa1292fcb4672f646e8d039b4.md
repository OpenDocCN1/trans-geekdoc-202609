Identify coordinates:

$x_1 = 1, y_1 = 2$

$x_2 = 4, y_2 = 6$

Apply the formula:

$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}

$d = \sqrt{(4 - 1)^2 + (6 - 2)^2}

$d = \sqrt{(3)^2 + (4)^2}

$d = \sqrt{9 + 16}$

$d = \sqrt{25}$

$d = 5$

Therefore, the distance between points A(1, 2) and B(4, 6) is five units.
