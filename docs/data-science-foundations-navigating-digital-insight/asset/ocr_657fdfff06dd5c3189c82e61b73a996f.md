+   **Colour:** This can be used to draw attention to important. For example, in a chart looking at forecast figures for a team, those team members who had received training might be shown in a different colour. In this case, it might illustrate the effect additional training has had on expected performance. In using colour, give thought to the use of contrasts to aid accessibility. People attach meaning to colour – for example, green for good and red for bad, or blue for cold and red for hot. Using these associations can aid communication and cause confusion if ignored. It is also important to consider any cultural differences in colour association that might cause confusion. If we created clusters of sales regions, we might choose to show the best cluster performing in green and the worst performing in red.
