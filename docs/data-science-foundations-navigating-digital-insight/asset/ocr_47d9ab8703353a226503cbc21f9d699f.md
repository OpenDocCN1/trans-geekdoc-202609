When to use line graphs

+   * Tracking changes over time: They are ideal for showing how a variable changes over time, such as stock prices or temperature.

+   * Comparing multiple series: They are useful for comparing multiple data series on the same graph.

Remember: Use different line styles or colours to distinguish between multiple lines on the same graph, ensuring clarity.
