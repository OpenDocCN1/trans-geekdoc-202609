We can see that the differences (20, 10, 40, 10, 20, 30) don’t have a clear trend – they are not obviously increasing or decreasing.

# Step 2: Identify the ARIMA parameters (p, d, q)

ARIMA has three main parameters:

+   1. **p (auto regressive order):** This is the number of past values (lags) the model looks at. For example, if $p=1$, the model uses the previous one’s sales to make predictions.
2. **d (differencing order):** This is the number of times the data is differenced to make it stationary. From Step 1, we differenced the data **once**, so $d=1$.
3. **q (moving average order):** This is the number of past errors the model uses to make predictions. For example, if $q=1$, the model uses the error from the last week.

We’ll use **p=1, d=1** and **q=1** for this example (this is a common starting point).
