+   - **Source** looks for and at the data that is available to answer the question.
- **Prepare** ensures the data is of a suitable quality and format to be used in the analysis.
- **Explore** investigates appropriate methods to answer the questions and the ability to use the available data to build effective models.
- **Create** builds the actual models to be used in the analysis.
- **Analyse** evaluates the models created.
- **Communicate** shares the insight gained from the analysis of the models.
