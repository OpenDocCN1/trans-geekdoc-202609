# Measuring distance between points

The distance between two points on the Cartesian plane can be calculated using the distance formula, derived from the Pythagorean theorem. This formula provides a straightforward way to find the straight-line distance (or Euclidean distance) between two points.

# Distance formula

For two points, (x₁, y₁) and (x₂, y₂), the distance $d$ between them is given by:

```
distance = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
```
