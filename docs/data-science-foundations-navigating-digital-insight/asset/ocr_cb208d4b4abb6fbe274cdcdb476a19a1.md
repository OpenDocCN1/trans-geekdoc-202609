Heat maps use colour to represent data values in a matrix format, making it easy to envisage complex data relationships. You can easily see where ‘hot spots’ are in your data (Figure 11.9).

When to use heat maps

+   - **Visualising correlations**: They are perfect for displaying correlation matrices or relationships between multiple variables.
- **Highlighting patterns**: They are useful for spotting patterns, trends and anomalies in large data sets.
