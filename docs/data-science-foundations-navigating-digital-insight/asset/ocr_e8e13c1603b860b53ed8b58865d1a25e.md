# Hybrid delivery

It is possible to take a hybrid approach. This might typically consist of a high-level linear plan with the detail being managed through sprints. In this situation, the data analysis lifecycle can provide the framework for the linear plan, showing the focus at any one time. The iterations required to address the problem are managed at the granular level through the backlog and sprints.

# PRACTICAL TIPS

+   - Plan your activity and time – the data analysis lifecycle can help with this.
- Allow time to go back to previous steps – the data analysis lifecycle is iterative.
- Planning can help to manage stakeholder expectations.
- Consider how the project fits with other initiatives.
