+   * **Confidence**: This is the likelihood that a rule is true for a transaction (two or more items) that already contains the first item.
* **Lift**: This is the ratio of the observed support to the expected support if the items were independent.

# The formula

**Support** = the percentage of transactions that contain an item (e.g. item 1).

**Confidence** = the percentage of transactions that contain item 1 and also contain item 2.
