+   1. AR: The model predicts the next value using the previous value(s), for example if sales increased by 20 phones last week, they might increase by 20 again this week.

+   2. I: The model works with the differenced data – changes in sales, not the raw sales.

+   3. MA: The model adjusts its prediction using past errors.
