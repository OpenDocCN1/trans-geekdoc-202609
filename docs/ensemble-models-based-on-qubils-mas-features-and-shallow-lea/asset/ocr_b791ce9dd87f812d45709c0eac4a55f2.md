# Molecular Descriptor Classification.

The topological 0-2D MDs (atom- and bond-indices) and local linear, quadratic, and binary indices were calculated using the QChemBL-MS software (http://www.chembl.org/). These descriptors have been widely used in QSAR modeling, showing good performance in many applications, such as for analyticity, pharmacophores, toxicophores, inhibitors, and reactivity. These properties were predicted⁷.

In the classification, the program used the following validation approach for data selection: (1) all Na (n-number) values were evaluated; (2) a Shannon entropy was used to select descriptors with entropy higher than 60% of the maximum entropy value; and (3) a pairwise correlation test was applied using a Pearson correlation coefficient of 0.8⁸. Then, from the descriptor lines, three subsets were selected based on different performance features. The first approach involved a supervised selection based on the Jeffreys information-entropy ranking method implemented in the IMMAN software (http://robust-hub.com/imman-software/)⁹.
