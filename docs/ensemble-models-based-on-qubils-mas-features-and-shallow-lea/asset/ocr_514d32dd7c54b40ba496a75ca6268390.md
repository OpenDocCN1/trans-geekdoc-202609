# ## RESULTS

**Data Sets, Feature Selection, and Base Models.** From the selection process, three subsets of MDs were built with 126, 125, and 251 MDs, denoted as Imman-126, Weka-125, and IW-251, respectively. A wrapper-type method was applied to classify these subsets. As a result, models were obtained (see files S2 and S3-II) with ACC = 0.71, EP = 0.73, SP = 0.50, and MCC = 0.37 and ACC = 0.72, 0.76, SP = 0.58, and MCC = 0.45 for the tests. It is important to note that the data sets used are unbalanced; as they have more cases with positive-DILI than negative-DILI. Consequently the synthetic oversampling technique (SMOTE) was applied. The method described in the feature selection and model processing are summarized in Section 3.

By applying a cutoff on the validation sets for 1_T_100 [ACC > 0.76 and MCC > 0.5] and 2_B_75 [ACC > 0.77 and MCC > 0.4], the models M2, M9, and E18 were selected as the most robust models. The model M9 was obtained using a SMOTE process of 50% on the test set, increasing the number of positive-DILI instances from 423 to 636, which is close to the number of positive-DILI instances of 652. The statistical parameters for these models are presented in Table 2. In order to improve results of individual models, several ensemble models were constructed using the previous step. Another WEKA-wrapper type feature was selected to control the inclusion of individual classes into the final ensemble. Each output Δ0% obtained from each individual model was used as an input in the wrapper. The same ML techniques integrating the best combinations were then applied. Approximately 100 possible ensembles were generated. There were 19 ensembles (denoted from E1 to E19) selected as the best ones according to ACC, SE, SP, and MCC statistical measures. The number of ensembles with MCC less than or equal to was 7. The training accuracy was approximately equal to 0.8, whereas the maximum ACC obtained by the individual models was 0.74. With respect to the 1_T_120 test set, an increase of 0.07 was observed, and for the 2_B_75 test set, an increase of 0.04 was obtained. To select the most robust ensembles, some cutoffs in the statistics were applied as follows: for 1_T_1075, ACC > 0.83, SE > 0.88, SP > 0.76, and MCC > 0.66 were the criteria applied.
