Modeling Process. We used the WEKA software, a wrapper selection method to select the features that were identified as best. The forward, step-greedy, and genetic algorithm strategies were used for selection, using the accuracy (ACC) as an evaluation measure. The k-nearest neighbor (KNN), multilayer perceptron (ML), logistic regression (LR), classification tree (C4.5), Fisher filter, and Naive Bayes (NB) were performed for each method. The 14 configurations considered for machine learning techniques were performed through cross-validation (CV).
