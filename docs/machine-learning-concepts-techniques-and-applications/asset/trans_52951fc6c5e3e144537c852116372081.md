

贝叶斯网络提供了一种以紧凑且结构化的方式描述联合概率分布的方法。一组随机变量构成了网络的节点。一组有向链接或箭头连接成对的节点。从 `X` 指向 `Y` 的箭头的直观含义是 `X` 对 `Y` 有直接影响——直接依赖。贝叶斯网络假设该图是无环的，因此不存在有向循环（DAG）。每个节点都有一个条件概率表，用于量化父节点对该节点的影响。一个节点的父节点是所有指向它的箭头所源自的节点。因此，贝叶斯网络的两个组成部分是图结构（条件独立性假设）以及给定其父节点时与每个变量相关联的数值概率。贝叶斯信念网络描述了一组随机变量 `Y[1]`、`Y[2]`、…`Y[n]` 上的概率分布。每个变量 `Y[i]` 可以取值集合 `V(Y[i])`。变量集合 `Y` 的`联合空间`是叉积（公式 7.5）

```
(7.5)  
V(Y[1]) × V(Y[2]) × … × V(Y[n])
```

`联合概率分布`：指定联合空间中各项的概率。由于`马尔可夫条件`，我们可以使用公式计算贝叶斯网络中所有变量 `X[1]`、…、`X[n]` 的联合概率分布。

在贝叶斯网络的背景下，我们需要定义的一个重要概念是`条件独立性`。条件独立性意味着如果在给定 `Z` 的情况下 `X` 和 `Y` 条件独立，等价地说，如果我们知道 `Z`，那么知道 `Y` 不会改变对 `X` 的预测。即 `P(X|Y,Z) = P(X|Z)`，常用的表示法为 `Ind(X;Y|Z)` 或 `(X⊥Y|Z)`。另一个重要方面是`马尔可夫条件`，它指出给定其父节点（`P[1]`、`P[2]`），随机变量 `X` 与其非后代节点（`ND[1]`、`ND[2]`）条件独立（[图 7.11](#ch7.xhtml#fig7_11)）。

解释贝叶斯网络组成部分的示例显示在[图 7.12](#ch7.xhtml#fig7_12)中。在该示例中，我们有六个节点或领域变量。

[图 7.12 贝叶斯网络示例。](#ch7.xhtml#R_fig7_12)

边对应直接因果影响。每个子节点关联一个条件概率表（CPT）。在[图 7.12](#ch7.xhtml#fig7_12)中，子节点 Preparedness（准备程度）的 CPT 针对其每个父节点——此处为 Good Teacher（好老师）和 Intelligent（聪明）的每个取值给出。每个变量关联两个概率值，分别表示该变量为真和为假的概率。一个节点的 CPT 大小取决于它拥有的父节点数量。因此，贝叶斯网络中有向边定义的条件依赖关系连同节点关联的 CPT 共同定义了领域上的完整联合分布。该网络是一种紧凑且自然的表示，当节点拥有 `≤ k` 个父节点时，参数数量为 `O(2^k * n)`。网络结构编码了条件独立性。此处 Answer Correctness（答案正确性）和 Good Teacher（好老师）在给定 Evaluator Type（评估者类型）的条件下是独立的。

同样对于[图 7.12](#ch7.xhtml#fig7_12)中给出的示例，完整联合分布可以回答任何形式为 `P(event|evidence)` 的查询。它还允许结合不同类型的推理：

*   `因果推理`：`P(Evaluator Type|Good Teacher)`
*   `证据推理`：`P(Evaluator Type|not good Grades)`
*   `交互因果推理`：`P(Evaluator Type|not good Grades, Preparedness)`

现在让我们考虑[图 7.13](#ch7.xhtml#fig7_13)中给出的一个简单贝叶斯网络。现在，`B` 给定 `A` 的条件概率分布在 `B` 的 CPT 中指定。对于父节点取值的给定组合（此例中为 `B`），`P(C = true | B)` 和 `P(C = false | B)` 的条目之和必须为 1（[图 7.13](#ch7.xhtml#fig7_13)）。例如，`P(C = true | B = false) + P(C = false | B = false) = 1`。如果我们有一个具有 `k` 个布尔父节点的布尔变量，该表有 `2^(k+1)` 个概率（但只需存储 `2^k` 个）。

#### 7.4.5.1 独立性

让我们使用[图 7.14](#ch7.xhtml#fig7_14)解释独立性的概念。`Difficulty`（难度）和 `Intelligence`（智力）是两个未由边连接的随机变量，因此它们是独立的。这意味着 `P(D,I) = P(I)P(D)`，独立性表示为 `P(D|I) = P(D) D ^ I` 和 `P(I|D) = P(I) I ^ D`。因此 `P(D, I) = P(I|D)P(D) = P(I)P(D)` 且 `P(D, I) = P(D|I)P(I) = P(D)P(I)`。

![图 7.14 解释独立性。](images/fig7_14_B.jpg)

[图 7.14 解释独立性。](#ch7.xhtml#R_fig7_14)

在给定 `Grade`（成绩）的条件下，`Letter`（推荐信）独立于 `Difficulty`（难度）和 `Intelligence`（智力），这表示为 `P(C|A,G,S) = P(C|S) C ⊥ A,G | S`。然而，在给定 `Grade`（成绩）的条件下，`Difficulty`（难度）`依赖`于 `Intelligence`（智力）。类似地，`Grade`（成绩）和 `SAT` 相依赖；然而，在给定 `Intelligence`（智力）的条件下，`Grade`（成绩）独立于 `SAT`，即 `P(S|G,I) = P(S|I)`。

### 7.4.6 贝叶斯网络的局限性

贝叶斯网络通常需要许多概率的先验知识。先验知识的质量和广度在贝叶斯网络中起着非常重要的作用。涉及巨大的计算成本（NP 难题）。使用贝叶斯网络时，未预料到的事件概率无法得到处理。

### 7.4.7 构建贝叶斯网络

现在让我们讨论贝叶斯网络的构建。假设问题可以用 `n` 个随机变量来定义。构建步骤如下。

```
1. 选择变量顺序 X[1], … ,X[n]
2. 对于 i = 1 到 n
       将 X[i] 加入网络
       从 X[1], … ,X[i-1] 中选择父节点，使得
       P(X[i] | Parents(X[i])) = P(X[i] | X[1], … X[i-1])
```
