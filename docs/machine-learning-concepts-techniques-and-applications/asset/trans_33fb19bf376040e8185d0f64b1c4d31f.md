
下一个略有不同的示例是**游戏对弈**示例。这是一个有趣的示例，因为训练数据、新样本和输出可以用不同的方式指定。例如，输入可以指定为棋盘的状态以及该状态下的最佳走法，此时新样本将只是一个状态（此前未见过），而学习过程将输出最佳走法。另一方面，输入可以是从初始局面开始通向最终局面的一系列走法，最终局面被标记为胜或负。规范也可以改变，使训练数据由棋盘局面以及从该局面进行特定走法导致获胜的次数组成。这一解释旨在让你明白，同一个问题可以用不同的方式指定和表示。所涉及的学习可能是找到一系列能导致获胜的走法。在[图 1.6b](#ch1.xhtml#fig1_6)中，训练数据由许多对弈的走法序列以及对弈是否导致胜负组成。学习模型利用这些训练数据来决定搜索和评估策略，判断从当前棋盘走出的一步棋是否有可能以胜利告终。基于这一评估，模型从当前棋盘局面建议出最佳走法。

我们将考虑的下一个示例是**疾病诊断**的情况。在这里，训练阶段的输入是患者病历数据库，目标值指示疾病是存在还是不存在。在这种情况下，当给定新患者的数据时，学习到的疾病分类器将指示疾病的不存在或存在（[图 1.6c](#ch1.xhtml#fig1_6)）。

另一个示例是为发放贷款而**核查客户信用资质**。这里的输入将是先前的客户档案，以及指示贷款是否已偿还的标签。当给定一个新客户时，模型将预测他或她是否具有信用资质（[图 1.6d](#ch1.xhtml#fig1_6)）。

我们应该在早期阶段就理解，机器学习的有效性取决于我们使用的输入特征以及如何表示它。根据手头的学习任务，特征可以是不同的。

现在我们将更详细地探讨两个机器学习示例，以尝试理解所使用的特征。第一个示例是我们想要标记文本文章中所有组织名称的提及。作为人类，我们将如何处理这个问题？一种简单的方法是使用组织名称的列表或字典。但这归结为一种查表方法。另一种方法是寻找能指示组织名称的特征，比如以大写字母开头的单词，或识别典型表达，如*$Organization 制造*或*$Organization 父子公司*。我们还需要训练数据，其中每个单词都被标记为 $Organization 或 $Other。现在我们必须拟合一个模型，以便我们可以在新文章中将单词标记为 $Organization。

## 1.6 机器学习的影响领域

机器学习是计算机科学的一个子领域，它源于人工智能中模式识别和计算学习理论的研究。用于获取知识的机器学习算法基于人工智能。统计学在机器学习中起着非常重要的作用。机器学习主要利用未知概率分布进行学习。大脑模型已被用于通过使用具有加权输入的非线性元件来建模认知过程以进行学习。这是人工神经网络背后的原理。机器学习还研究如何建模生物进化以提高程序性能。

## 1.7 机器学习的应用

现在出现了一个重要问题，究竟谁在实际使用机器学习？在当前的形势下，这个问题的答案几乎是每个人，包括你我日常生活中的每一个人。大多数处理大量数据的行业都已认识到机器学习的价值。机器学习的一些成功应用包括学习识别口语单词（SPHINX；Lee 1989）、学习驾驶自动驾驶车辆（ALVINN；([Pomerleau 1988](#ch1.xhtml#ref1_17))）、学习对天体进行分类（Fayyad 等人，1995）、学习进行世界级西洋双陆棋对弈（TD-GAMMON；Tesauro 1992）、设计机电装置的形态和控制结构（GOLEM；Lipton, Pollock 2000）。

一般来说，机器学习的应用包括计算机视觉和机器人技术，涉及物体的检测、识别和分类；人脸识别；视频中物体（刚性和关节式）的跟踪和视觉注意力建模；语音识别；推荐系统（购买哪些产品/书籍）；计算机安全等。机器学习在现实世界中的其他一些应用包括机器翻译、问答系统、社交网络分析、天气预测、自动驾驶汽车等（[Harrington, 2012](#ch1.xhtml#ref1_4)）。

**金融服务**，如银行和其他金融企业，利用机器学习识别数据中的重要洞见并防止欺诈。数据分析可以预测投资机会的价格和市场。数据挖掘有助于识别高风险客户画像，或检测使用模式以识别欺诈。

**政府机构**利用机器学习从多源数据中获取洞见，以改善为公共安全和公用事业提供的服务。例如，分析传感器数据可以找出提高效率和节省资金的方法。机器学习可以找出提高效率和节省资金的方法，并有助于检测欺诈和最大限度减少身份盗窃。

**医疗保健**是另一个以多种方式使用机器学习的行业。由于可穿戴设备和传感器的出现，患者数据可以实时评估。机器学习提供了方法、技术和工具，可帮助解决各种医学领域的诊断和预后问题。它被用于分析临床参数及其组合对预后的重要性。机器学习还被用于数据分析，例如通过适当处理不完美数据来检测数据中的规律性、解释重症监护室中使用的连续数据，以及用于智能报警，从而实现有效高效的监控。机器学习方法可以帮助在医疗环境中集成基于计算机的系统，提供机会促进和加强医学专家的工作，并最终提高医疗护理的效率和质量。机器学习还用于生物医学中的药物发现和计算基因组学（分析和设计）。
