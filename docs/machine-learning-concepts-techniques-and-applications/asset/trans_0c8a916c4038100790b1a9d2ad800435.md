

## 8.2.1 精确率–召回率权衡

正如我们所见，提高精确率会降低召回率，反之亦然。这被称为精确率/召回率权衡，如[图 8.9](#ch8.xhtml#fig8_9)所示。分类器模型在不同阈值下的表现不同；也就是说，可以通过设置阈值来改变正向和负向预测。我们可以固定一个输出概率阈值，以便将样本标记为正类。例如，为了诊断疾病，只有在非常有把握时，我们才会提高阈值，从而导致精确率升高、召回率降低。另一方面，如果我们希望避免漏掉太多疾病病例，例如，我们会降低阈值，从而导致召回率升高但精确率降低。精确率-召回率曲线总结了预测模型在使用不同置信概率阈值时，真正例率（召回率）与阳性预测值（精确率）之间的权衡。

![Figure 8.9 Precision–recall curve.](images/fig8_9_B.jpg)

[图 8.9 精确率-召回率曲线。](#ch8.xhtml#R_fig8_9)

精确率-召回率曲线显示了不同阈值下精确率和召回率之间的权衡。曲线下面积（AUC）较大代表既有高召回率又有高精确率，其中高精确率对应低假阳性率，高召回率对应低假阴性率。两者得分都高表明分类器返回的结果准确（高精确率），同时也返回了大多数正样本（高召回率）。

### 8.2.1.5 F1 分数

当我们想要比较具有不同精确率-召回率值的模型时，需要将精确率和召回率结合成一个单一指标来计算性能。`F1` 分数定义为精确率和召回率的调和平均数，如[图 8.10](#ch8.xhtml#fig8_10)所示。

![Figure 8.10 F1 score.](images/fig8_10_B.jpg)

[图 8.10 F1 分数。](#ch8.xhtml#R_fig8_10)

使用调和平均数是因为它不像简单平均数那样对极大值敏感。如果我们寻求精确率和召回率之间的平衡，`F1` 分数是一个更好的度量指标。

### 8.2.1.6 ROC/AUC 曲线

接收者操作特征曲线（`ROC`）是另一种常用的评估方法。它绘出了模型在 `0` 到 `1` 之间每一个可能的决策规则截止点下的灵敏度（敏感度）和特异度。对于具有概率输出的分类问题，阈值可以将概率输出转换为分类结果。我们获得了控制混淆矩阵的能力，因此通过改变阈值，混淆矩阵中的某些数值会发生变化。为了找到合适的阈值，我们使用 `ROC` 曲线。对于每一个可能的阈值，`ROC` 曲线绘制假阳性率与真阳性率的关系，其中假阳性率是被错误分类为正类的负实例所占比例，而真阳性率是被正确预测为正类的正实例所占比例。因此，`ROC` 曲线作为模型整体性能的图形化总结，显示了在所有可能的概率截止值下真阳性和假阳性的比例。[图 8.12a](#ch8.xhtml#fig8_12) 讨论了 `0.1` 的低阈值和 `0.9` 的高阈值，而 [图 8.12b](#ch8.xhtml#fig8_12) 解释了不同阈值下的 `ROC` 曲线。

![Figure 8.12 ROC curve.](images/fig8_12_B.jpg)

[图 8.12 ROC 曲线。](#ch8.xhtml#R_fig8_12)

当 `TPR = 1` 且 `FPR = 0` 时的 `ROC` 曲线代表不存在的理想模型，其中正类被以零错误率分类为正类。在 `TPR = 0` 且 `FPR = 0` 的严格模型中，极少有样本被分类为真。在 `TPR = 1` 且 `FPR = 1` 的宽松模型中，每个正类都被分类为正类，但代价是许多负类也被分类为正类。对于一个好的模型，`ROC` 曲线应陡峭上升，表明随着概率阈值降低，真阳性率的增长快于假阳性率。

比较分类器的一种方法是测量 `ROC` 曲线下面积（`AUC`），`AUC` 总结了分类器的整体性能。

## 8.2.2 多类分类

我们已经讨论了二分类器的评估。当分类问题有两个以上的标签时，我们就有了多类分类，其性能可以用类似二分类的方式来衡量。拥有 `m` 个类别时，混淆矩阵是一个 `m × m` 的表格，其中位置 (`i`, `j`) 的元素表示属于类别 `i` 但被分类为类别 `j` 的实例数量。为了使分类器具有良好的准确率，理想情况下对角线上的大多数元素应有较大的值，而其余元素应接近零。混淆矩阵可能包含额外的行或列，以提供每个类别的总数或识别率。在多类分类中，有时某一个类别重要到足以被视为正类，而将所有其他类别合并为负类。因此，一个大的 `m × m` 混淆矩阵可以简化为 `2 × 2` 矩阵。

现在让我们讨论在多类场景下，针对特定类别计算 `TP`、`TN`、`FP` 和 `FN` 值的方法。这里 `TP` 是实际值和预测值相同时矩阵单元格中的值。`FN` 是该类别对应行的值的总和（不包括 `TP` 值），而 `FP` 是该类别对应列的值的总和（不包括 `TP` 值）。另一方面，`TN` 是除我们正在计算的那个类别的行和列之外，所有其他行和列的值的总和。

## 8.3 机器学习中的交叉验证

交叉验证是一种检查机器学习模型如何泛化到独立数据集的技术。这里通过在输入数据的子集上训练模型，并在先前未见过的输入数据子集上测试来验证模型效率。为了验证目的，我们保留数据集的一个特定样本，称为验证数据集，它不是训练数据集的一部分，然后在部署前在这个样本上测试模型。一种流行的交叉验证技术是 `k-fold` 交叉验证（`k` 折交叉验证），其中输入数据集被分成 `k` 组大小相等的样本，称为**折**。对于每一个学习集，预测函数使用 `k−1` 个折，其余的折用作测试集。这种方法比其他方法偏差更小。`k-fold` 交叉验证的第一步是将输入数据集分成 `k` 组。然后对于每一组，取一组作为保留集或测试数据集。剩下的 `k − 1` 组用作训练数据集。训练集用于学习模型，性能使用保留的测试数据集进行评估。

## 8.4 集成方法

**集成方法** 结合多个基础机器学习模型，以产生一个最优的预测模型。**集成学习** 是机器学习的一种通用元方法，它通过结合多个模型的预测而不是单一模型的预测来寻求更好的预测性能。基本思想是学习一组分类器（专家）并让它们投票。分类器集成以特定方式结合一组分类器的个体决策，以预测新样本的类别（[图 8.14](#ch8.xhtml#fig8_14)）。
