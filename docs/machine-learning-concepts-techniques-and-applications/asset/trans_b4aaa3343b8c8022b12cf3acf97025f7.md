# 16 深度学习的其他模型及深度学习的应用

DOI: [10.1201/9781003290100-16](https://dx.doi.org/10.1201/9781003290100-16)

## 16.1 循环神经网络 (RNN)

循环神经网络 (RNN) 是一种将输出回环至输入的神经网络类型。一般来说，传统神经网络 (NN) 的输入和输出相互独立，无法处理序列数据，只能处理当前输入，且无法记住之前的输入。然而，在语音识别和自然语言处理中，需要理解数据的序列特征并利用模式预测下一个可能的状态。因此，开发出了 RNN，它可以处理序列数据，并利用其记忆记住之前的输入，为此 RNN 利用了隐藏层。隐藏状态保留了关于序列的一些信息，是 RNN 的主要且最重要的特征（[图 16.1](#ch16.xhtml#fig16_1)）。

![图 16.1 循环神经网络 (RNN)。](images/fig16_1_B.jpg)

[图 16.1 循环神经网络 (RNN)。](#ch16.xhtml#R_fig16_1)

RNN 拥有一个“记忆”，保留所有与计算相关的数据。它们对所有输入或隐藏层执行相同的操作以产生输出，对每个输入使用相同的设置。与其他神经网络相比，这最小化了参数集的复杂性。

循环神经网络解决了可变宽度输入的问题，这是传统神经网络在处理文本分析等应用时出现的问题。这当然也是照片的一个问题，但答案略有不同，因为我们可以随时缩放和拉伸图像以适应我们所需的任何尺寸。单词不像图像那样工作。

### 16.1.1 RNN 的工作原理

让我们通过一个示例场景来理解 RNN 的工作原理。

考虑一个更深的网络，它有一个输入层、一个输出层和三个隐藏层。通常每个隐藏层都与其自己的一组权重和偏置相关联，即 (`w1`, `b1`)、(`w2`, `b2`)、(`w3`, `b3`)（[图 16.2](#ch16.xhtml#fig16_2)），对应三个隐藏层中的每一个。这本质上意味着这些层中的每一个都是相互独立的，并且不保留与早期输出相关的信息。

![图 16.2 更深的循环神经网络。](images/fig16_2_B.jpg)

[图 16.2 更深的循环神经网络。](#ch16.xhtml#R_fig16_2)

然而，RNN 通过在所有层中使用相同的权重和偏置引入了依赖性，减少了参数数量，并通过将每个输出反馈到下一个隐藏层来记住之前的输出。因此，这三个层合并为单个循环层，所有隐藏层具有相同的权重和偏置（[图 16.3](#ch16.xhtml#fig16_3)）。

![图 16.3 三个隐藏层的组合。](images/fig16_3_B.jpg)

[图 16.3 三个隐藏层的组合。](#ch16.xhtml#R_fig16_3)

以下公式 (16.1) 确定当前状态：

```
(16.1)
h[t] = f(h[t−1], x[t])
```

其中，

*   `h[t]` 当前状态
*   `h[t−1]` 前一状态
*   `x[t]` 输入状态

在公式 (16.1) 中应用激活函数 (tanh) 后，当前状态变为 (公式 16.2)，

```
(16.2)
h[t] = tanh(w[hh] * h[t−1] + w[xh] * x[t])
```

其中，

*   `w[hh]` → 循环神经元处的权重
*   `w[xh]` → 输入神经元处的权重

输出由公式 (16.3) 确定：

```
(16.3)
y[t] = w[hy] * h[t]
```

其中，

*   `y[t]` 输出
*   `w[hy]` 输出层处的权重

### 16.1.2 通过 RNN 进行训练

1.  网络由具有相同权重和激活函数的 `n` 个输入层组成，并被给予输入的单个时间步。
2.  然后，使用当前输入和前一状态的输出，计算当前状态。
3.  对于下一个时间步，当前状态 `h[t]` 变为 `h[t−1]`。
4.  根据问题，可以重复任意多的时间步，以整合来自所有前一状态的信息。
5.  所有时间步完成后，使用最终的当前状态来计算输出。
