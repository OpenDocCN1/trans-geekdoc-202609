
选择模型后，我们需要定义一个**损失函数**（`loss function`），量化拟合优劣。对于数据 `x`，算法预测 `y`，但目标实际为 `t`。通常使用平方误差损失函数，如公式 (7.9) 所示：

(7.9)

```
(y, t) = 1/2 (y - t)^2
```

其中 `y - t` 为残差，我们希望其尽可能小。

现在对所有训练数据求该损失函数的平均，得到代价函数或总体损失函数 `y^(i)`：

(7.10)

```
(w, b) = 1/(2N) Σ_{i=1}^N (y_i - t_i)^2 = 1/(2N) Σ_{i=1}^N (w^T x_j - t_j)^2
```

因此，给定数据集 `D = (x[1], y[1]), …, (x[n], y[n])`，我们需要找到最优权重向量（公式 7.11）：

(7.11)

```
W = argmin_w Σ_{j=1}^n (w^T x_j - t_j)^2
```

### 7.5.1.1.3 控制模型复杂度与过拟合

接下来需要选择正则化项以控制模型复杂度和过拟合。在线性回归中，模型除了学习数据，还会学习其中的噪声。过度完美地拟合训练点会导致过拟合。我们希望通过用替代拟合过程（即最小化均方误差 `MSE` 的值）替换最小二乘拟合来改进线性回归模型。

使用普通最小二乘估计存在两个问题：预测准确性和模型可解释性。当目标值 `y` 与输入 `x` 的关系为线性，且观测数 `n` 远大于预测变量数 `p` 时，最小二乘估计具有相对较低的偏差和方差。如前所述，高偏差导致欠拟合，高方差导致过拟合。然而，最小二乘拟合可能具有高方差，导致过拟合，进而影响对未见观测的预测准确性。当模型中有大量输入变量 `x` 时，通常许多变量对目标 `y` 影响甚微或无影响。保留这些变量会使“重要变量”的效应难以辨识，降低模型可解释性。一种处理方法是子集选择法，即识别出所有 `p` 个预测变量中与响应 `y` 相关的子集，再用该子集拟合模型。

#### 收缩或正则化

子集选择法涉及使用最小二乘拟合仅包含部分预测变量的线性模型。我们也可以使用一种技术拟合包含所有 `p` 个预测变量的模型，该技术约束或正则化系数估计，等价地将系数估计向零收缩。在回归分析中，拟合关系在新数据集上的表现通常不如拟合数据集，我们用收缩来正则化不适定推断问题。正则化约束机器学习算法以改善样本外误差，特别是在存在噪声时。通过移除（即将系数设为零）不重要的变量，模型会更易解释。收缩正则化方法使用一种技术拟合包含所有 `p` 个预测变量的模型，该技术约束或**正则化**（`regularizes`）系数估计（即**收缩**（`shrinks`）系数估计向零）。

收缩或正则化方法向模型使用的损失函数施加惩罚项。最小化损失函数等于最大化准确性。回顾线性回归通过最小化实际值与预测值的平方差来绘制最佳回归曲线以获得最佳预测准确性。显著收缩系数估计可降低其方差。由于欠拟合或过拟合数据的问题，需要收缩方法。当我们要最小化平均误差（线性回归中的 `MSE`）时，需要优化偏差-方差权衡。

#### 岭回归

线性回归使用使以下公式 (7.12) 最小化的值来估计系数：

(7.12)

```
RSS = Σ_{i=1}^n (y_i - β_0 - Σ_{j=1}^p β_j x_{ij})^2
```

换句话说，**正则化**（`regularization`）的思想是通过添加惩罚模型参数特定性质的正则化项来修改损失函数（公式 7.13）。岭回归添加惩罚项 `lambda` 将系数向零收缩：

(7.13)

```
Σ_{i=1}^n (y_i - β_0 - Σ_{j=1}^p β_j x_{ij})^2 + λ Σ_{j=1}^p β_j^2 = RSS + λ Σ_{j=1}^p β_j^2
```

此处 `λ` 为标量，给出正则化项的权重（或重要性）。收缩惩罚 `λ ≥ 0` 为调优参数。

岭回归相对于线性回归的优势在于利用了偏差-方差权衡。随着 `λ` 增加，系数更向零收缩。岭回归（也称 L1 正则化）具有将大值“收缩”向零的效果。这种约束应能改善拟合，因为收缩系数可显著降低其方差。岭回归的主要缺点是无论系数值如何，输出模型都包含所有 `p` 个预测变量，对于特征数量巨大的模型具有挑战性。

#### Lasso 回归

Lasso 回归通过执行变量选择克服了岭回归的缺点。Lasso 回归使用 L-1 惩罚，而岭回归使用 L-2 惩罚，前者取系数绝对值而非平方，如公式 (7.14) 所示：

(7.14)

```
Σ_{i=1}^n (y_i - β_0 - Σ_{j=1}^p β_j x_{ij})^2 + λ Σ_{j=1}^p |β_j| = RSS + λ Σ_{j=1}^p |β_j|
```

岭回归使系数值接近零，而 Lasso 回归强制部分系数值恰好等于零。在 Lasso 回归中优化 `λ` 的值同样重要，以降低 `MSE` 误差。Lasso 相对于岭回归的主要优势在于生成更简单、更易解释的模型，仅涉及预测变量的子集。Lasso 导致与岭回归定性相似的行为：随着 `λ` 增加，方差减小、偏差增大，且能比岭回归产生更准确的预测。为避免任意选择，应使用交叉验证选择 `λ`。
