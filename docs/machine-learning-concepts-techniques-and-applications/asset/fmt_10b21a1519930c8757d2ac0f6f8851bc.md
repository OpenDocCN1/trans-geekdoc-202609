## 15.6.3 Backpropagation—For Outermost Layer

- Outermost layer parameters directly affect the value of the error function.
- Only one term of the `E` summation will have a nonzero derivative: the one associated with the particular weight we are considering.

(15.13)

$$\\frac{\\partial E}{\\partial w\_{\\mathit{jk}}} = \\frac{\\partial E}{\\partial a\_{k}}\\frac{\\partial a\_{k}}{\\partial z\_{k}}\\frac{\\partial z\_{k}}{\\partial w\_{\\mathit{jk}}}$$

Each component of the backpropagation of the outermost layer’s equation (Equation 15.13) is derived in the following equations (Equations 15.14–15.17):

(15.14)

$$\\frac{\\partial E}{\\partial a\_{k}} = \\frac{\\partial}{\\partial a\_{k}}\\left( \\frac{1}{2}\\sum\\limits\_{k \\in K}\\left( a\_{k} - t\_{k} \\right)^{2} \\right) = \\left( a\_{k} - t\_{k} \\right)$$

(15.15)

$$\\frac{\\partial a\_{k}}{\\partial z\_{k}} = \\frac{\\partial}{\\partial z\_{k}}\\left( f\_{k}\\left( z\_{k} \\right) \\right) = f\_{k}^{,}\\left( z\_{k} \\right)$$

(15.16)

$$\\frac{\\partial z\_{k}}{\\partial w\_{\\mathit{jk}}} = \\frac{\\partial}{\\partial w\_{\\mathit{jk}}}\\left( \\sum\\limits\_{j}a\_{j}w\_{\\mathit{jk}} \\right) = a\_{j}$$

For the sigmoid activation function,

(15.17)

$$\\frac{\\partial z\_{k}}{\\partial w\_{\\mathit{jk}}} = \\left( a\_{k} - t\_{k} \\right)a\_{k}\\left( 1 - a\_{k} \\right)\\left. a\_{j} \\right)$$

The backpropagation algorithm is used for calculating the gradient of the loss function, which points us in the direction of the value that minimizes the loss function, and using gradient descent iteratively in the direction given by the gradient, we move closer to the minimum value of error. The perceptron uses backpropagation in the following manner.

1. **Step 1:** There is a need to estimate the distance between the predicted solution and the desired solution, which is generally defined as a loss function such as mean squared error. In the case of a regression problem using mean squared error as a loss function, the squares of the difference between actual `yᵢ` and predicted value `ŷᵢ` are as shown in Equation (15.21).

   (15.21)

   $$\\mathbf{MS}\\mathbf{E}\_{\\mathbf{i}} = \\left( \\mathbf{y}\_{\\mathbf{i}} - {\\widehat{\\mathbf{y}}}\_{\\mathbf{i}} \\right)^{2}$$

   The average loss function for the entire training data set: the cost function `C` for the entire data set is the average loss function for all `n` datapoints and is given in Equation (15.22) as follows.

   (15.22)

   $$C = \\mathit{MSE} = \\frac{1}{n}\\sum\\limits\_{i = 1}^{n}\\left( \\mathbf{y}\_{\\mathbf{i}} - {\\widehat{\\mathbf{y}}}\_{\\mathbf{i}} \\right)^{2}$$

2. **Step 2:** In order to find the best weights and bias for our perceptron, we need to know how the cost function changes in relation to weights and bias. This is done with the help of the gradients (rate of change)—how one quantity changes in relation to another quantity. In our case, we need to find the gradient of the cost function with respect to the weights and bias.

The gradient of cost function `C` with respect to the weight `wᵢ` can be calculated using *partial derivation*. Since the cost function is not directly related to the weight `wᵢ`, the chain rule can be used as given in Equation (15.23).

(15.23)

$$\\frac{\\partial\\mathbf{C}}{\\partial\\mathbf{w}\_{\\mathbf{i}}} = \\frac{\\partial\\mathbf{C}}{\\partial\\widehat{\\mathbf{y}}} \\ast \\frac{\\partial\\widehat{\\mathbf{y}}}{\\partial\\mathbf{z}} \\ast \\frac{\\partial\\mathbf{z}}{\\partial\\mathbf{w}\_{\\mathbf{i}}}$$
