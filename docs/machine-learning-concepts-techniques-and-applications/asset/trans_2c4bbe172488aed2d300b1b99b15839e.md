
20世纪90年代，机器学习的工作重心从知识驱动方法转向了数据驱动方法。机器学习的焦点从继承自AI研究的方法转移到了概率论和统计学中使用的方法和策略。人们创建了能够分析大量数据并从结果中得出结论的程序。1990年，Robert Schapire和Yoav Freund为机器学习引入了提升法，旨在通过组合许多弱机器学习模型，并采用平均或投票的方式将它们结合起来，以增强预测能力。1995年，Tin Kam Ho引入了随机决策森林，将多棵决策树合并成一片森林以提高准确性。然而，总体而言，20世纪90年代被认为是“AI寒冬”时期，AI研究资金短缺。然而，这也是AI研究的黄金时期，包括马尔可夫链蒙特卡洛、变分推断、核方法和支持向量机、提升法、卷积网络以及强化学习的研究。此外，还有IBM深蓝计算机的开发，它于1997年战胜了世界国际象棋冠军加里·卡斯帕罗夫。

### 1.3.5 应用机器学习——文本、视觉与机器学习竞赛

21世纪头十年是应用机器学习的时代，计算机视觉和自然语言处理（NLP）采用了机器学习技术。*深度学习*一词由Geoffrey Hinton于2006年提出，用以解释一种全新类型的算法，该算法让计算机能够看见并区分图像或视频中的物体或文本。2002年，首个用于机器学习的开源软件库Torch发布。2006年，Netflix发起了一项竞赛，目标是创建一个比当时Netflix现有版本更准确的用户推荐机器学习算法。2010年，Kaggle作为一个机器学习竞赛平台正式上线。

### 1.3.6 深度学习——神经网络的成熟期

2009年，由Fei-Fei Li发布了一个名为ImageNet的大规模标注图像视觉数据库，它提供了优质的训练数据，使得深度学习领域得以开展广泛研究。2010年代是深度学习时代，基于神经网络的系统在语音转文本和目标识别方面的性能得到提升，促使科技行业大规模采用机器学习。2011年，IBM的沃森在《危险边缘》节目中战胜了人类选手。此外，2012年，Google开发了配备深度神经网络的Google Brain，它能够学会发现和分类物体（特别是猫）。2014年，一组科学家开发了生成对抗网络（GAN），它能够基于训练数据生成新数据。

### 1.3.7 产业参与与机器学习

2014年，Facebook推出了DeepFace，这是一种特殊的软件算法，能够在照片上识别和验证个人身份，其水平堪比人类。同年，Google推出了Sibyl，这是一个大规模机器学习系统，用于对产品和页面进行排名、衡量用户行为以及广告投放。同样在2014年，第一个被认为通过了图灵测试的聊天机器人“Eugene Goostman”由三位朋友开发。2015年，Amazon推出了自己的机器学习平台，使机器学习更易获取，并将其推向软件开发的前沿。此外，2015年，Microsoft创建了分布式机器学习工具包，使开发者能够高效地将机器学习问题分发到多台机器上。同年，然而，包括Elon Musk、Stephen Hawking和Steve Wozniak等知名人士在内的三千多名AI和机器人研究者签署了一封公开信，警告能够在无人干预下自主选择目标的自主武器的危险。

2015年，Google的人工智能算法在中式棋类游戏围棋中战胜了职业选手。围棋被认为是世界上最复杂的棋类游戏。由Google开发的AlphaGo算法在比赛中以五比零获胜，再次将AI推向显著地位。2017年，Waymo开始基于机器学习测试自动驾驶汽车。

2020年，OpenAI发布了开创性的自然语言处理算法GPT-3，它在给定提示词时表现出生成类人文本的卓越能力。如今，GPT-3被认为是世界上最大、最先进的语言模型，使用了1750亿个参数和Microsoft Azure的AI超级计算机进行训练。目前，人们高度关注机器学习的伦理和社会影响。

## 1.4 什么是机器学习？

简单来说，机器学习是预测未来或对信息进行分类以帮助人们做出必要决策的最流行技术。这里我们再次解释最常见的机器学习类型——监督学习。现在让我们尝试理解如何解决一个具体问题。我们编写一个程序，对一组有助于解决问题的规则进行编码。然而，在许多情况下，理解问题并编写具体规则来解决它非常困难，例如如何判断给定图像是否为人物图像。机器学习系统并非被直接编程来解决问题，而是基于大量示例和试错经验，开发出自己的程序或模型来解决问题。[图 1.3](#ch1.xhtml#fig1_3) 展示了传统编程与机器学习的区别。因此，机器学习试图基于称为训练数据的输入-输出对来学习一个未知函数。

[图 1.3 传统编程与机器学习的对比。](#ch1.xhtml#R_fig1_3)

机器学习算法通过示例进行训练，从中学习过去的经验并分析历史数据。换句话说，随着它们反复在示例上训练，机器学习算法能够识别模式，从而对未来进行预测。多年来，机器学习有许多定义不断演变。

机器学习的第一个定义由Arthur Samuel于1959年给出：“机器学习是一门研究领域，它使计算机在无需显式编程的情况下获得学习能力。” ([Samuel, 1959](#ch1.xhtml#ref1_12))

在机器学习中，你不需要提供程序，而是定义这是数据、这是我们期望的输出，计算机必须对其建模或自我编程，以便在你给出数据时获得必要的输出。程序是机器学习的输出。这是机器学习最早的定义之一，至今仍然成立，因为今天的机器学习全都是关于学习模型的。

机器学习定义的另一个视角与从数据中学习和提升性能有关。Herbert [Simon (1970)](#ch1.xhtml#ref1_13) 将机器学习定义为“系统提升其性能的任何过程。”

1983年，Simon再次从同一脉络定义机器学习如下：学习指系统中的变化，这些变化具有适应性，意味着它们使系统下次能更有效地执行相同任务（或从一组相似任务中抽取的任务）。

Tom Mitchell ([Mitchell, 2017](#ch1.xhtml#ref1_9)) 将机器学习定义为一种计算机程序，它通过经验提升在某类任务上的性能（1997）。他的定义如下：

> 如果一个计算机程序在任务类T上的性能（由P衡量）随着经验E的增加而提高，则称该程序从过去的经验E中学习了关于任务类T的知识。
