

构建预测分类模型后，您需要评估模型的性能，即模型在预测未用于训练模型的新测试数据的结果方面有多好。换句话说，我们需要使用新的测试数据集来估计模型预测的*准确性*和预测误差。因为我们知道测试数据集中观测值的实际结果，所以可以通过将预测结果值与已知结果值进行比较来评估预测模型的性能。评估指标用于衡量分类模型的质量。构建模型时，衡量预期结果的预测准确度至关重要。不同的机器学习算法集有不同的评估指标。对于评估分类模型，我们使用分类指标；对于回归模型，我们使用回归指标。评估指标有助于评估模型性能、监控生产环境中的机器学习系统，并控制模型以满足业务需求。任何分类系统的目标都是创建并选择一个在未见数据上具有高准确率的模型。使用多个评估指标来评估模型很重要，因为模型可能根据一个评估指标的一种度量表现良好，但根据另一个评估指标的另一种度量却表现不佳（[Agrawal, 2022](#ch8.xhtml#ref8_1)）。

## 8.2 分类指标

### 8.2.1 二分类

分类是关于给定输入数据预测类别标签。在二分类中，只有两个可能的输出类别（即二分法）。在多分类中，可能存在两个以上的类别。衡量分类性能有多种方法（[Beheshti, 2022](#ch8.xhtml#ref8_2)）。准确率、混淆矩阵、对数损失、以及曲线下面积/受试者工作特征曲线（AUC-ROC）是其中最流行的指标之一。精确率和召回率是分类问题中广泛使用的指标。

我们将首先描述混淆矩阵，它是一个 `n` × `n` 矩阵（其中 `n` 是标签的数量），用于描述分类模型在一组已知真实值的测试数据上的性能。混淆矩阵中的每一行代表一个实际类别，而每一列代表一个预测类别。两个类别（二分类）`C1` 和 `C2` 的混淆矩阵如[图 8.1](#ch8.xhtml#fig8_1)所示。

![图 8.1 二分类的混淆矩阵。](images/fig8_1_B.jpg)

[图 8.1 二分类的混淆矩阵。](#ch8.xhtml#R_fig8_1)

假设我们有一个将乘客分类为癌症阳性和阴性的机器学习模型。在执行分类预测时，可能会出现四种类型的结果（[图 8.2](#ch8.xhtml#fig8_2)）：

*   **真阳性（`TP`）**：当您预测某观测值属于某个类别，且它实际上确实属于该类别时——在本例中，某乘客被分类为癌症阳性且实际上为阳性。
*   **真阴性（`TN`）**：当您预测某观测值不属于某个类别，且它实际上确实不属于该类别时——在本例中，某乘客被分类为非癌症阳性（阴性）且实际上非癌症阳性（阴性）。
*   **假阳性（`FP`）**：当您预测某观测值属于某个类别，但它实际上不属于该类别时——在本例中，某乘客被分类为癌症阳性但实际非癌症阳性（阴性）。
*   **假阴性（`FN`）**：当您预测某观测值不属于某个类别，但它实际上属于该类别时——在本例中，某乘客被分类为非癌症阳性（阴性）但实际为癌症阳性。

![图 8.2 混淆矩阵——二分类示例。](images/fig8_2_B.jpg)

[图 8.2 混淆矩阵——二分类示例。](#ch8.xhtml#R_fig8_2)

现在，给定混淆矩阵，我们将讨论各种评估指标。

#### 8.2.1.1 准确率

第一个指标是准确率。准确率关注真阳性和真阴性。准确率是给出正确预测比例的一个指标。正式定义如公式 (8.1) 所示。

(8.1)

```math
\text{Accuracy} = \frac{\text{Number of correct predictions}}{\text{Total number of predictions}}
```

就混淆矩阵而言，准确率定义如[图 8.3](#ch8.xhtml#fig8_3)所示。

![图 8.3 准确率。](images/fig8_3_B.jpg)

[图 8.3 准确率。](#ch8.xhtml#R_fig8_3)

[图 8.3](#ch8.xhtml#fig8_3) 所示示例中的准确率为 99.9%。此处的目标是识别实际的癌症患者，将这些阳性患者错误标记为阴性是不可接受的；因此在这种情况下，准确率不是一个好的度量标准。

#### 8.2.1.2 灵敏度或真阳性率

召回率或灵敏度给出了我们在所有阳性中正确识别为阳性的比例（如[图 8.5](#ch8.xhtml#fig8_5)所示)，换句话说，表示我们在预测时有多精确。

![图 8.5 召回率或灵敏度。](images/fig8_5_B.jpg)

[图 8.5 召回率或灵敏度。](#ch8.xhtml#R_fig8_5)

该度量显示了在所有实际阳性病例中正确识别的阳性病例所占的比例。在[示例 8.1](#ch8.xhtml#box8_1)中，召回率为 `0/10 = 0`。在这种情况下，召回率是一个好的度量标准。我们通常希望最大化召回率。现在假设数据集中的所有患者都被错误地分类为癌症阳性。这种标记是不好的，因为它会导致精神痛苦以及检查成本。从[图 8.6a](#ch8.xhtml#fig8_6)可以看出，`Recall = 1`，这同样不是一个好的度量标准。

![图 8.6 (a) 召回率计算，(b) 特异性。](images/fig8_6_B.jpg)

[图 8.6 (a) 召回率计算，(b) 特异性。](#ch8.xhtml#R_fig8_6)

然而，单独测量时这也不是一个好的度量标准。召回率需要与精确率协同测量。我们也可以像[图 8.6b](#ch8.xhtml#fig8_6)那样为阴性病例定义 `specificity`（特异性）。
