
## 长短期记忆网络（LSTM）

长短期记忆网络（LSTM）的核心思想是：它是一个循环单元，致力于“遗忘”不必要的信息，同时尝试“记住”网络遇到的所有先前信息。为实现这一目标，引入了多层激活函数（通常称为“门”），用于不同目的。每个 LSTM 循环单元还会跟踪一个称为**内部细胞状态**的向量。该向量概念性地描述了前一个 LSTM 循环单元选择存储的信息。LSTM 由四个不同的门组成，每个门具有独特功能，详述如下。

1.  **遗忘门（`f`）**：决定前序数据被遗忘的程度。
2.  **输入门（`i`）**：负责确定将写入内部细胞状态的信息量。
3.  **输入调制门（`g`）**：常被视为输入门的组成部分，许多关于 LSTM 的文献要么不提及它，要么错误地认为它包含在输入门内。它通过向信息添加非线性并使信息零均值，来调制输入门将写入内部状态细胞的信息。这样做是为了缩短学习时间，因为零均值输入收敛更快。即使该门的作用不如其他门显著，且常被视为一种提供精细度的概念，但将其包含在 LSTM 单元构建中是良好的实践。
4.  **输出门（`o`）**：根据内部细胞的当前状态，决定生成什么输出（下一个隐藏状态）。

LSTM 的基本过程流程与循环神经网络（RNN）非常相似；唯一的区别是 LSTM 中内部细胞状态会与隐藏状态一起传递（[图 16.13](#ch16.xhtml#fig16_13)）。

LSTM 单元的操作步骤如下，并如[图 16.14](#ch16.xhtml#fig16_14)所示：

1.  输入为当前输入、前一个隐藏状态和先前的内部细胞状态。
2.  现在按如下方式确定四个不同门的值：
    *   对每个门，计算相关向量与各门对应权重的逐元素乘法，以获得当前输入和先前隐藏状态的参数化向量。
    *   对每个门的参数化向量逐元素应用相应的激活函数。各门应用的激活函数描述如下。
3.  当前内部细胞状态由（公式 16.10）确定：

    (16.10)  
    $$c[t] = i \odot g + f \odot c[t-1]$$

    *   首先计算输入门和输入调制门的逐元素乘法向量，
    *   然后计算遗忘门和前一个内部细胞状态的逐元素乘法向量，
    *   最后将两个向量相加。
4.  当前隐藏状态由以下方式确定：
    *   首先计算当前内部细胞状态向量的逐元素双曲正切，
    *   然后与输出门进行逐元素乘法。

RNN 和 LSTM 使用的反向传播方法相似，但在数学建模方式上有所不同。

设 $\overline{y_t}$ 为每个时间步的预测输出，$y[t]$ 为每个时间步的实际输出。则每个时间步的误差由（公式 16.11）给出：

(16.11)  
$$\mathbf{E_t} = - \mathbf{y_t}\log\left( \overline{\mathbf{y_t}} \right)$$

总误差因此为所有时间步误差之和（公式 16.12）：

(16.12)  
$$\begin{array}{l} {\mathbf{E} = \sum\limits_{\mathbf{t}}\mathbf{E_t}} \\ {\mathbf{E} = \sum\limits_{\mathbf{t}} - \mathbf{y_t}\log\left( \overline{\mathbf{y_t}} \right)} \\ \end{array}$$

类似地，值 $\frac{\partial E}{\partial W}$ 可计算为每个时间步梯度之和（公式 16.13）。

(16.13)  
$$\frac{\partial\mathbf{E}}{\partial\mathbf{W}} = \sum\limits_{\mathbf{t}}\frac{\partial\mathbf{E_t}}{\partial\mathbf{W}}$$

利用链式法则，并利用 $\overline{y_t}$ 是 $h[t]$ 的函数，也是 $c[t]$ 的函数这一事实，得到以下表达式（公式 16.14）：

(16.14)  
$$\frac{\partial\mathbf{E_t}}{\partial\mathbf{W}} = \frac{\partial\mathbf{E_t}}{\partial\overline{\mathbf{y_t}}}\frac{\partial\overline{\mathbf{y_t}}}{\partial\mathbf{h_t}}\frac{\partial\mathbf{h_t}}{\partial\mathbf{c_t}}\frac{\partial\mathbf{c_t}}{\partial\mathbf{c_{t-1}}}\frac{\partial\mathbf{c_{t-1}}}{\partial\mathbf{c_{t-2}}}\ldots\ldots.\frac{\partial\mathbf{c_0}}{\partial\mathbf{W}}$$

因此总误差梯度由以下公式给出（公式 16.15）：

(16.15)  
$$\frac{\partial\mathbf{E}}{\partial\mathbf{W}} = \sum\limits_{\mathbf{t}}\frac{\partial\mathbf{E_t}}{\partial\overline{\mathbf{y_t}}}\frac{\partial\overline{\mathbf{y_t}}}{\partial\mathbf{h_t}}\frac{\partial\mathbf{h_t}}{\partial\mathbf{c_t}}\frac{\partial\mathbf{c_t}}{\partial\mathbf{c_{t-1}}}\frac{\partial\mathbf{c_{t-1}}}{\partial\mathbf{c_{t-2}}}\ldots\ldots.\frac{\partial\mathbf{c_0}}{\partial\mathbf{W}}$$

注意：LSTM 反向传播的梯度方程涉及 $\partial c[t]$ 的链，而基本 RNN 的梯度方程涉及 $\partial h[t]$ 的链。
