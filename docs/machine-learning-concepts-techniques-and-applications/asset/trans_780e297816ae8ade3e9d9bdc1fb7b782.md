我们将要讨论的一些重要概念包括智能、学习和机器学习。

### 1.1.1 智能

在开始之前，让我们看看什么是智能。《梅里亚姆-韦伯斯特词典》对 *intelligence* 的定义是：“智能是指学习、理解或应对新情况或棘手情况的能力（这不是死记硬背），以及运用知识操纵环境或进行抽象思维的能力，这些能力可通过某些客观标准来衡量。” ([Merriam Webster Online Dictionary 2023](#ch1.xhtml#ref1_7))。一个重要的视角是，我们应该改进描述学习目标的某个参数。智能的另一个重要方面是抽象，即发现共同模式的能力——这对研究尤其如此，甚至对许多商业应用也是如此。最后，智能涉及适应，即将我们所学应用于明天不断变化的环境的能力，换句话说，智能要求学习必须是动态的。需要智能的任务包括：为解决谜题和做出判断而进行的推理、规划行动序列、学习、自然语言处理、技能整合，以及感知和行动的能力。

### 1.1.2 学习

了解了智能的定义后，让我们来理解学习。赫伯特·西蒙对学习的定义是：“学习是系统通过经验提高其性能的任何过程” (Herbert [Simon, 1983](#ch1.xhtml#ref1_14))。西蒙解释说，学习还意味着在从未遇到过的情境下执行任务的能力。这个定义很重要，因为机器学习的一个重要定义就是基于它的。对于机器而言，经验以数据的形式出现。机器学习之所以在今天变得重要，原因之一是海量数据变得可用。我们想要执行的任务可能是分类、问题求解、规划或控制。学习定义中的下一个组成部分是性能的提升。这种性能提升是根据目标来衡量的，目标可以表示为收益（例如利润增加）或损失（如误差减少）。

学习是许多活动的核心，包括高级认知、执行知识密集型推理、构建自适应智能系统、处理杂乱的真实世界数据以及分析数据。学习的目的可能是多方面的，包括获取知识、适应人类及其他系统、以及做出决策。

有了这些关于智能和学习的定义，我们可以继续定义机器学习。我们将讨论许多机器学习的定义，但在此之前，让我们先看看为什么我们需要机器学习。

### 1.1.3 机器学习非正式简介

机器学习模型是当你用数据训练机器学习算法时生成的输出。例如，预测算法将创建一个预测模型。然后，当你向预测模型提供数据时，你将基于训练该模型的数据获得预测结果。机器学习现在是创建分析模型所必需的。

### 1.1.4 人工智能、机器学习和深度学习

*   **人工智能 (AI)** 是一个完整知识领域的名称，机器学习是其重要的子领域。《柯林斯词典》将人工智能定义为“利用计算机程序对人类心智功能进行建模的研究 ([Collins Dictionary, 2023](#ch1.xhtml#ref1_3))。” AI 由两个词组成：*artificial*（人工）和 *intelligence*（智能）。任何非自然、由人类创造的事物都是人工的。*Intelligence* 意味着理解、推理、规划等能力。因此，任何能使机器模仿人类认知或行为的代码、技术或算法都称为 AI。AI 使用逻辑、如果-那么规则、决策树和机器学习，后者包含深度学习。
*   **机器学习** 是 AI 的一个子集，涉及实现能够从数据或过往实例中学习、并能在没有显式指令或编程的情况下执行任务的算法。从数据中学习的过程涉及模式的统计识别和模型拟合，以便更准确地评估数据并提供精确的结果。
*   **深度学习** 是机器学习的一部分，涉及使用人工神经网络，而神经网络是机器学习方法的一种类型。深度学习涉及构建、训练和使用神经网络的现代方法，通过让多层神经网络接触海量数据来执行任务。由于神经网络能够更准确地从大数据中学习并为用户提供可靠结果，深度学习机器学习算法是许多行业最流行的选择 ([Microsoft 2022](#ch1.xhtml#ref1_8))。

## 1.2 机器学习的必要性

### 1.2.1 提取相关信息

我们需要计算机对新的、未见过的数据做出明智的决策。在以前的时代，我们拥有大量信息；我们只是试图从信息中寻找模式，如果我们给出相似的信息，就能找到相同的答案——这是纯粹的模式匹配。今天，我们致力于从新的、未见过的数据中寻找答案。这里我们谈论的是大量数据。因此，手工设计一套规则往往太困难了。机器学习关乎从数据中自动提取相关信息，并将其应用于分析新的未见数据。这个特定方面谈论的是提取信息；即从数据中提取相关信息，换句话说，我们需要从数据中筛选出信息。我们将这些提取的信息应用于分析新数据。
