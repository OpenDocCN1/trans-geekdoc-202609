在 [图 9.3](#ch9.xhtml#fig9_3) 中，`a` 对应数据点 `x[i]` 和 `x[j]` 均为值 0 的属性数量，`b` 对应 `x[i]` 为 0 且 `x[j]` 为 1 的情况，`c` 对应 `x[i]` 为 1 且 `x[j]` 为 0 的情况，而 `d` 对应数据点 `x[i]` 和 `x[j]` 均为值 1 的属性数量。

如果两种状态（0 和 1）具有同等重要性且权重相同，则可以使用混淆矩阵。此时距离函数为其值不匹配的比例（公式 9.1）：

(9.1)
```
dist(x[i], x[j]) = (b + c) / (a + b + c + d)
```

然而，有时二元属性是非对称的，即其中一种状态比另一种更重要。我们假设状态 1 代表重要状态，在这种情况下，基于混淆矩阵的 Jaccard 度量可定义如下（公式 9.2）：

(9.2)
```
JDist(x[i], x[j]) = (b + c) / (a + b + c)
```

对于文本文档，通常使用余弦相似度，这是一种相似度度量，而非距离度量。余弦相似度是通过测量两个向量之间夹角的余弦值来获得的两个向量之间的相似度度量（[图 9.4](#ch9.xhtml#fig9_4)）。任意两个给定文档 `d[j]` 和 `d[k]` 表示为向量后的相似度如下（公式 9.3）：

(9.3)
$$
{sim}\left( d_{j},d_{k} \right) = \frac{{\overline{d}}_{j} \cdot {\overline{d}}_{k}}{\mid {\overline{d}}_{j} \mid \mid {\overline{d}}_{k} \mid} = \frac{\sum_{i = 1}^{n}w_{i,j}w_{i,k}}{\sqrt{\sum_{i = 1}^{n}w_{i,j}^{2}}\sqrt{\sum_{i = 1}^{n}w_{i,k}^{2}}}
$$

![图 9.4 向量之间的余弦夹角.](images/fig9_4_B.jpg)

[图 9.4 向量之间的余弦夹角.](#ch9.xhtml#R_fig9_4)

在这种情况下 `w[i]` 是一个权重，可能基于单词在文档中的频率。

当角度为 0 时，余弦函数的结果等于 1；当角度为任何其他值时，结果小于 1。随着向量之间夹角的减小，余弦值趋近于 1，即两个向量更接近，文档之间的相似度增加。

## 9.7 聚类方法

聚类的基本方法是层次法，分为凝聚法和分裂法两类。凝聚聚类是一种自底向上的方法，初始假设每个数据点本身就是一个簇。然后反复将距离最近的两个簇合并为一个。另一方面，分裂聚类是一种自顶向下的过程，从一个簇开始，递归地分裂簇，直到无法再分裂。我们通常执行点分配，即维护一组簇并将点分配给最近的簇。

### 9.7.1 层次聚类

在层次聚类方法中，我们以顺序方式对数据集进行划分。该方法通过将对象分组到一个簇树中，一次创建一个层次的划分（[图 9.5](#ch9.xhtml#fig9_5)）。在这种情况下，不需要预先知道簇的数量。通常，距离矩阵被用作聚类准则。

[图 9.5 层次聚类.](#ch9.xhtml#R_fig9_5)

### 9.7.2 层次聚类的类型

层次聚类方法可进一步分为凝聚法或分裂法，具体取决于层次分解是以自底向上（合并）还是自顶向下（分裂）的方式形成。正如我们所讨论的，层次方法顺序划分数据点并构建一个簇树。以下是构建簇树的两种顺序聚类策略。这两种情况下的重要问题是所考虑的簇间距离和所用的终止条件。

#### 9.7.2.1 凝聚聚类

在凝聚聚类中，初始每个数据点形成其自身的（原子）簇，因此遵循自底向上的策略。然后根据某些距离度量将这些原子簇合并为越来越大的簇。当所有数据点都在单个簇中时算法终止，或继续合并直到满足特定的终止条件。大多数层次聚类方法属于此类。数据集 `{a, b, c, d, e}` 上的凝聚聚类如 [图 9.6](#ch9.xhtml#fig9_6) 所示。

![图 9.6 凝聚和分裂层次聚类.](images/fig9_6_B.jpg)

[图 9.6 凝聚和分裂层次聚类.](#ch9.xhtml#R_fig9_6)

#### 9.7.2.2 分裂聚类

分裂聚类是一种自顶向下的策略，它执行与凝聚层次聚类相反的操作，初始所有数据点共同形成单个簇。它将簇细分为越来越小的部分，直到满足特定的终止条件，例如达到期望的簇数量或每个簇的直径在特定阈值内（[图 9.6](#ch9.xhtml#fig9_6)）。

### 9.7.3 层次聚类：算法

层次聚类以一组点作为输入。然后创建一棵树或树状图，其中点为叶节点，内部节点将相似的点归类在一起。该方法初始将所有点放在单独的簇中。然后只要簇的数量多于一个，就合并距离最近的一对簇。

#### 9.7.3.1 层次聚类：合并簇

现在，合并簇的一个重要准则是簇间距离。有三种不同的方式来定义这种簇间距离。
