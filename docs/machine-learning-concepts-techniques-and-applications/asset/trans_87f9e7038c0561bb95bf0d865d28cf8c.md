# 4 机器学习技术的基础与分类

DOI：[10.1201/9781003290100-4](https://dx.doi.org/10.1201/9781003290100-4)

## 4.1 简介

**数据** 是指截然不同的信息片段，通常经过格式化并存储，以便用于特定目的。机器学习的基本层面在于数据，以及数据如何被收集和表示、如何描述针对学习过程目标的特定特征及其表示，以及所使用的机器学习算法类型。在本章中，我们将讨论这些方面。我们还将讨论机器学习算法的底层概念。

### 4.1.1 数据及其重要性

机器学习的基本目标是基于数据预测结果。所有机器学习任务都可以用这种方式表示。你拥有的样本种类越丰富，就越容易找到相关模式并预测结果。因此，机器学习问题的一个重要组成部分是所使用的数据。数据越多样化，结果越好。数万个样本是正常学习所需的绝对最低限度。数据来源于数据库、在线平台、文档、传感器、工业流程等；它可以有多种形式和格式，如结构化、非结构化等；可以是干净的，也可以是混乱的。在机器学习中，数据被视为一个示例列表。理想情况下，我们需要许多性质相同的示例。每个示例通常表示为一个数字向量（如果不是，我们会将其转换为此类向量）。[图 4.1](#ch4.xhtml#fig4_1) 展示了水果图像标注的一个示例。请注意图像在适当预处理后是如何被转换为维度为 `d` 的特征向量的。

### 4.1.2 问题维度

当我们谈论机器学习问题时，我们谈论的是问题维度：样本数量 `n`（通常非常大）、输入维度 `d` 即刻画每个样本的输入特征或属性的数量（通常为 100 到 1000 甚至更多）、目标维度 `m`，例如类别数量（通常较小）。适合机器学习的数据通常会被组织成一个矩阵，如果目标维度为 1（如 [图 4.1](#ch4.xhtml#fig4_1) 所示，这在许多应用中均成立），则矩阵维度为 `n × (d + 1)`；如果目标维度为 `m`，则维度为 `n × (d + m)`。[图 4.1](#ch4.xhtml#fig4_1) 所示的数据集可以视为高维向量空间中的一个点云，如 [图 4.2](#ch4.xhtml#fig4_2) 所示。

![图 4.2 高维向量空间中作为点云的数据集。](images/fig4_2_B.jpg)
