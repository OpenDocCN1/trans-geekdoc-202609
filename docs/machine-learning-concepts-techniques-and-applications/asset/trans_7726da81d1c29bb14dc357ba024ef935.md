
# 伦理机器学习：关键概念

*   伦理预测模型在决策应用中非常重要，例如筛选面试候选人或决定保险费。
*   个人和心理画像影响隐私、歧视和保密性的伦理原则。
*   可解释性是指用人类可理解的术语进行解释的能力。
*   GDPR 是一项关于伦理的具有法律约束力的法规。
*   公平机器学习旨在确保由算法指导的决策是公平的。
*   数据偏差是数据中的系统性扭曲，损害了其代表性。
*   黑箱机器学习不属于伦理机器学习。
*   性别偏见有时是不道德的，有时却是可取的。
