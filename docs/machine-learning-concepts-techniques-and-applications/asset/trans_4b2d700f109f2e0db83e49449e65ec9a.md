
## 2.4 设计周期

### 关键设计选择

*   选择训练经验（集合 `X`），以及如何表示它。
*   选择具体要学习的内容，即目标函数 `C`。
*   选择如何表示目标函数 `C`。
*   选择一个学习算法，从经验中推断目标函数。
*   找到一种评估过程和指标来测试学习到的函数。

设计周期（[Pykes, 2021](#ch2.xhtml#ref2_7)）如[图 2.4](#ch2.xhtml#fig2_4)所示。第一步是数据收集。下一步是特征选择。这是一个重要步骤，可能影响整体学习效果。在大多数情况下，利用关于输入数据和待学习内容的先验知识来选择合适的特征。第三步是模型选择，本质上是选择一个能拟合数据的模型。同样，这里可以利用关于数据的先验知识来选择模型。一旦选定模型，学习步骤通过选择参数来微调模型以使其泛化。最后，评估和测试步骤使用未见数据评估学习系统。步骤详细解释如下。

举个简单的例子，让我们考虑这样一种情况：我们想根据身高找到一个人的预期体重。这里我们需要收集每个体重-身高组合的数据，其中一维图中的每个点代表一个数据点。然而，在所有机器学习示例中，考虑的特征或属性的数量和数据点的数量都很大。体重-身高示例纯粹是为了理解。请注意，这里每个数据点 `d[1]` 可以与许多属性或特征相关联，假设有 `m` 个属性，因此每个数据点可以是 `m` 维的。当维度较高时，数据集可以想象为高维向量空间中的点云。高维示例可以可视化为[图 2.6](#ch2.xhtml#fig2_6)所示。

### 步骤 2：特征选择

特征选择本质上是为模型构建选择相关特征的过程。特征的选择取决于学习问题，如[示例 2.1](#ch2.xhtml#box2_1)所示。

特征选择可以通过两种方式进行；一种是减少每个数据点考虑的属性数量。这种类型的特征选择称为降维，如[图 2.7](#ch2.xhtml#fig2_7)所示。第二种方法是减少考虑的数据点数量，其中原始 `D` = {`d[1]`, `d[2]`, … `d[m]`, … `d[n]`} 减少为 `D` = {`d[1]`…`d[m]`}，其中 `m` < `n`（[图 2.8](#ch2.xhtml#fig2_8)）。

### 步骤 3：模型选择

模型是从训练数据中学习得到的。下一步是模型选择，我们选择最有可能拟合数据点的模型或模型集。注意模型是手动选择的。结合选定的模型（或函数），我们需要选择参数。我们假设一个非常简单的线性模型（公式 2.1），

(2.1)

```
ε = N(0, σ)
```

学习涉及将该模型拟合到给定的训练数据，在这个简单示例中涉及学习参数斜率 `a` 和截距 `b`（[图 2.9](#ch2.xhtml#fig2_9)）。

![图 2.9 选择模型。](images/fig2_9_B.jpg)

[图 2.9 选择模型。](#ch2.xhtml#R_fig2_9)

这里这条线可以帮助我们进行预测。我们的主要目标是减小估计值和实际值之间的距离，即误差。为了实现这一点，我们将画一条穿过所有点的直线。

当维度数量增加时，模型可以表示为

(2.2)

```
y = a_m x_m + a_{m-1} x_{m-1} + ... + a_2 x_2 + a_1 x + b + ε
```

这个方程（公式 2.2）代表线性回归模型，将在线性回归章节中详细解释。现在将解释误差 `ε` 的作用。这里误差是一个重要方面，定义为从模型获得的输出与训练数据的期望输出之间的差异。需要优化误差函数 `ε`。一个简单的误差函数例子是随后给出的均方误差，它描述了输出 `y` 的真实值和预测值之间的差异（公式 2.3）：

(2.3)

$$
\frac{1}{n}\sum\limits_{i = 1}^{n} \left( y_{i} - f\left( x_{i} \right) \right)^{2}
$$

在这个函数中，`n` 是数据点的数量，`y[i]` 是来自训练数据的 `y` 的真实值，`f(X[i])` 给出了通过应用学习到的函数获得的 `y` 的预测值（[图 2.10](#ch2.xhtml#fig2_10)）。

![图 2.10 误差函数。](images/fig2_10_B.jpg)

[图 2.10 误差函数。](#ch2.xhtml#R_fig2_10)

### 步骤 4：学习

学习步骤涉及找到优化误差函数的参数集，即具有最小误差的模型和参数。我们的主要目标是最小化误差，使其尽可能小。减小实际值和估计值之间的误差可以提高模型性能，此外，我们收集的数据点越多，模型就会变得越好。因此，当我们输入新数据时，系统将预测输出值。

### 步骤 5：测试与评估

最后一步是应用学习到的模型进行评估，使用学习到的函数 `f(x)` 为迄今未见的输入 `x` 预测输出 `y`（[图 2.11](#ch2.xhtml#fig2_11)）。

![图 2.11 测试系统。](images/fig2_11_B.jpg)

[图 2.11 测试系统。](#ch2.xhtml#R_fig2_11)

这里我们初步了解评估。在后续章节中，我们将讨论其他评估方法。一种评估方法是简单的留出法，即将可用的经验（数据）分为训练数据和测试数据。当我们仅使用训练数据设计模型时，我们使用测试数据对其进行测试。当我们想比较使用两种不同学习方法对回归或分类问题的预测性能时，我们需要比较测试数据集上的误差结果。在本章讨论的背景下，测试误差较小的学习方法效果会更好。
