# 14 机器学习的伦理方面

DOI: [10.1201/9781003290100-14](https://dx.doi.org/10.1201/9781003290100-14)

## 14.1 引言

AI 和机器学习应用正在渗透到世界各地的应用中，例如共享经济、无人驾驶汽车、个性化医疗和改进的机器人，实际上涵盖了所有我们需要学习、预测、处方和做出真正数据驱动决策的情况。如果利用得当，AI 和机器学习能带来巨大效益，并支持更公平、更安全、更具包容性和更明智的决策制定。然而，为了使机器学习有效且可接受，需要极大的关注和有意识的努力，包括面对并最小化机器学习的风险和滥用。因此，AI 和机器学习最终将产生多大影响，取决于人们在接受它时做出的选择，因为其潜在的颠覆性影响引发了多方面的担忧。这些担忧（[图 14.1](#ch14.xhtml#fig14_1)）包括负面的经济和社会影响，如失业、隐私和安全丧失、决策中的潜在偏见、人类无法解释的解决方案，以及自动化系统和机器人的故障和失控。

![图 14.1 与 AI 和机器学习相关的担忧。](`images/fig14_1_B.jpg`)

[图 14.1 与 AI 和机器学习相关的担忧。](#ch14.xhtml#R_fig14_1)

虽然这些担忧问题很重要，但可以通过正确的规划、设计和治理来解决。程序员和企业需要选择应用哪些技术及其用途；在政府和文化接受度设定的边界内，必须有一个高效的流程，允许质疑算法的使用或输出，并且负责设计机器学习算法的实体应当是可识别的，并对这些算法的影响负责，即使这些影响是非预期的。

在当今形势下，AI 和机器学习的一些核心原则包括：产生大于成本的效益、以最小化负面结果的方式实施、以及遵守所有相关的国家和国际政府义务、法规和法律。
