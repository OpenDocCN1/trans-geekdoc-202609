### 9.16.1.1 PCA 方法论

PCA 将数据沿着数据变化最大的方向进行投影。这些方向由对应于最大特征值的`协方差矩阵的特征向量`决定。特征值的大小对应于特征向量方向上数据的方差。假设 `d` 个可观测变量是 `k` < `d` 个向量的线性组合。我们希望使用这组基，因为它维度较低，且包含所有（或几乎所有）所需信息。使用此基，我们期望数据是不相关的，否则本可进一步降维。我们选择显示大方差的投影，否则特征不包含信息。我们选择使数据总方差最大的方向（[图 9.22](#ch9.xhtml#fig9_22)）；即我们选择使总方差最大化的投影。我们选择正交方向并试图最小化相关性。当我们考虑 `d 维特征` 空间时，我们需要选择 `k` < `d` 个使总方差最大化的正交方向。我们首先通过从样本估计的 `d` 阶对称 `协方差矩阵` 来计算 `d`。然后我们选择 `协方差矩阵` 的 `k` 个最大特征值及其对应的 `k` 个特征向量。特征值越大，对应特征向量方向上的方差就越大。

![图 9.22 主成分方向。](images/fig9_22_B.jpg)

[图 9.22 主成分方向。](#ch9.xhtml#R_fig9_22)

因此，PCA 可以看作是通过旋转旧坐标轴来寻找一组新的正交基，直到找到最大方差方向为止。

PCA 旨在实现准确的数据表示，而非数据分类。PCA 的主要任务是尽可能多地保留数据中的方差。因此，只有当最大方差方向对分类很重要时，PCA 才能给出良好的分类结果。接下来我们将讨论 Fisher 线性判别方法。

## 9.16.2 Fisher 线性判别方法

Fisher 线性判别方法的主要思想是找到一条投影线，使得不同类别的样本投影到该线上后能很好地分离开（[图 9.23](#ch9.xhtml#fig9_23)）。

![图 9.23 不良与良好投影。](images/fig9_23_B.jpg)

[图 9.23 不良与良好投影。](#ch9.xhtml#R_fig9_23)

假设我们有两个类别和 `d 维` 样本 `X[1]`，……，`X[n]`，其中 `n1` 个样本来自第一类，`n2` 个样本来自第二类。考虑在一条线上的投影，设线的方向由单位向量 `V` 给出。标量 `V^(t)X[i]` 是 `x[i]` 的投影到原点的距离。因此 `V^(t)X[i]` 是 `X[i]` 在一维子空间上的投影。因此，样本 `X[i]` 在方向 `V` 的线上的投影由 `V^(t)X[i]` 给出。我们如何度量不同类别投影之间的分离度？设 $\\widetilde{\\mu\_{1}}$ 和 $\\widetilde{\\mu\_{2}}$ 为类别 1 和 2 的投影均值（[图 9.24](#ch9.xhtml#fig9_24)），`μ[1]` 和 `μ[2]` 为类别 1 和 2 的均值，则 | $\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}\\ $| 似乎是一个好的度量。

![图 9.24 投影均值。](images/fig9_24_B.jpg)

[图 9.24 投影均值。](#ch9.xhtml#R_fig9_24)

现在让我们讨论 |$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}\\ $| 作为分离度量的优劣。|$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}\\ $| 越大，预期的分离效果越好。对于类别可分性，垂直轴比水平轴是更好的投影线（图 9.36）。然而，`μ̂[1]` − `μ̂[1]`| > |$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}$|。|$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}$| 的问题在于它不考虑类别的方差。我们需要用一个与方差成正比的因子来归一化 |$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}$|。

让我们考虑一些样本 `Z[1]`，…，`Z[n]`。样本均值如下（公式 9.19）：

(9.19)  

$$\\mu\_{z} = \\frac{1}{n}\\sum\\limits\_{i = 1}^{n}Z\_{i}$$  

现在让我们定义它们的 `scatter`（散度）如下（公式 9.20）：

(9.20)  

$$S = \\sum\\limits\_{i = 1}^{n}\\left( Z\_{i} - \\mu\_{z} \\right)^{2}$$  

因此 `scatter`（散度）就是样本方差乘以 `n`。换句话说，`scatter`（散度）度量与方差相同的概念，即数据围绕均值的分散程度，只是 `scatter`（散度）的尺度与方差不同。

### 9.16.2.1 Fisher 线性判别

Fisher 的解决方案是找到一条投影线，使得不同类别的样本投影到该线上后能很好地分离开，即用 `scatter`（散度）来归一化 |$\\widetilde{\\mu\_{1}} - \\widetilde{\\mu\_{2}}$|。

设 `y[i]` = `V^(t)X[i]`，即 `y[i]` 为投影样本，类别 1 的投影样本的 `scatter`（散度）如下（公式 9.21）：

(9.21)  

$${\\widetilde{S}}\_{1}^{2} = \\sum\\limits\_{y\_{i} \\in \\text{Class}\\; 1}\\left( y\_{i} - {\\widetilde{\\mu}}\_{1} \\right)^{2}$$  

同样，类别 2 的投影样本的 `scatter`（散度）为公式 (9.22)：

(9.22)  

$${\\widetilde{S}}\_{2}^{2} = \\sum\\limits\_{y\_{i} \\in \\text{Class}\\; 2}\\left( y\_{i} - {\\widetilde{\\mu}}\_{2} \\right)^{2}$$  

我们需要同时用类别 1 的 `scatter`（散度）和类别 2 的 `scatter`（散度）进行归一化。因此，Fisher 线性判别需要投影到方向 `v` 的线上，以最大化 `J(V)`（[图 9.25](#ch9.xhtml#fig9_25)）。这里 `J(V)` 的定义使得我们希望投影均值彼此远离，且每个类别的 `scatter`（散度）尽可能小；即我们希望各类别的样本聚集在其投影均值周围。如果我们找到使 `J(v)` 变大的 `v`，则保证类别间分离良好（[图 9.26](#ch9.xhtml#fig9_26)）。
