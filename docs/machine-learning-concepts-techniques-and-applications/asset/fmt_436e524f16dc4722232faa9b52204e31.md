
$$
\frac{\partial\mathbf{C}}{\partial\widehat{\mathbf{y}}} = \frac{\partial}{\partial\widehat{\mathbf{y}}}\frac{1}{\mathbf{n}}\sum\limits_{\mathbf{i} = 1}^{\mathbf{n}}\left( \mathbf{y}_{\mathbf{i}} - {\widehat{\mathbf{y}}}_{\mathbf{i}} \right)^{2} = 2 \ast \frac{1}{\mathbf{n}}\sum\limits_{\mathbf{i} = 1}^{\mathbf{n}}\left( \mathbf{y}_{\mathbf{i}} - {\widehat{\mathbf{y}}}_{\mathbf{i}} \right)
$$

Let `y` = [`y`₁, `y`₂, … `y`[`n`]] and `ŷ` = [`ŷ`₁, `ŷ`₂, … `ŷ`[`n`]] be the row vectors of actual and predicted values. Hence the previous equation is simplified as follows (Equation 15.25):

**Equation (15.25)**

$$
\frac{\partial\mathbf{C}}{\partial\widehat{\mathbf{y}}} = \frac{2}{\mathbf{n}}\sum\left( \mathbf{y} - \widehat{\mathbf{y}} \right)
$$

Now let's find the gradient of the `predicted value` with respect to `z` (Equation 15.26). This will be a bit lengthy.

**Equation (15.26)**

$$
\begin{array}{ll} \frac{\partial\widehat{\mathbf{y}}}{\partial\mathbf{z}} & {= \frac{\partial}{\partial\mathbf{z}}\sigma\left( \mathbf{z} \right)} \\ & {= \frac{\partial}{\partial\mathbf{z}}\left( \frac{1}{1 + \mathbf{e}^{- \mathbf{z}}} \right)} \\ & {= \frac{\mathbf{e}^{- \mathbf{z}}}{\left( 1 + \mathbf{e}^{- \mathbf{z}} \right)^{2}}} \\ & {= \frac{1}{\left( 1 + \mathbf{e}^{- \mathbf{z}} \right)}^{\ast}\frac{\mathbf{e}^{- \mathbf{z}}}{\left( 1 - \mathbf{e}^{- \mathbf{z}} \right)}} \\ & {= \frac{1}{\left( 1 + \mathbf{e}^{- \mathbf{z}} \right)}^{\ast}\left( 1 - \frac{1}{\left( 1 + \mathbf{e}^{- \mathbf{z}} \right)} \right)} \\ & {= \sigma\left( \mathbf{z} \right) \ast \left( 1 - \sigma\left( \mathbf{z} \right) \right)} \\ \end{array}
$$

The gradient of `z` with respect to the weight `wᵢ` is given in Equation (15.27).

**Equation (15.27)**

$$
\begin{array}{ll} \frac{\partial\mathbf{z}}{\partial\mathbf{w}_{\mathbf{i}}} & {= \frac{\partial}{\partial\mathbf{w}_{\mathbf{i}}}\left( \mathbf{z} \right)} \\ & {= \frac{\partial}{\partial\mathbf{w}_{\mathbf{i}}}\left( \sum\limits_{\mathbf{i} = 1}^{\mathbf{n}}\mathbf{x}_{\mathbf{i}}\mathbf{w}_{\mathbf{i}} + \mathbf{b} \right)} \\ & {= \mathbf{x}_{\mathbf{i}}} \\ \end{array}
$$

Therefore we get Equation (15.28),

**Equation (15.28)**

$$
\frac{\partial\mathbf{C}}{\partial\mathbf{w}_{\mathbf{i}}} = \frac{2}{\mathbf{n}}\sum\left( \mathbf{y} - \widehat{\mathbf{y}} \right) \ast \sigma\left( \mathbf{z} \right) \ast \left( 1 - \sigma\left( \mathbf{z} \right) \right) \ast \mathbf{x}_{\mathbf{i}}
$$

What about bias? Bias is theoretically considered to have an input of constant value 1. Hence (Equation 15.29),

**Equation (15.29)**

$$
\frac{\partial C}{\partial b} = \frac{2}{n}\sum\left( y - \widehat{y} \right) \ast \sigma\left( z \right) \ast \left( 1 - \sigma\left( z \right) \right)
$$

## 15.7 Multilayered Perceptron

A `Multilayered Perceptron (MLP)` is one of the most common neural network models used in the field of deep learning. Often referred to as a `Vanilla Neural Network`, an `MLP` is simpler than the complex models of today's era. However, the techniques it introduced have paved the way for further advanced neural networks.

The `MLP` is used for a variety of tasks, such as stock analysis, image identification, spam detection, and election voting predictions.

### 15.7.1 The Basic Structure

A multilayered perceptron consists of interconnected neurons transferring information to each other, much like the human brain. Each neuron is assigned a value. The network can be divided into three main layers as shown in [Figure 15.10](#ch15.xhtml#fig15_10).

![Figure 15.10 Multilayer perceptron.](images/fig15_10_B.jpg)

*   **Input Layer**: This is the initial layer of the network which takes in an input that will be used to produce an output.
*   **Hidden Layer(s)**: The network needs to have at least one hidden layer. The hidden layer(s) perform computations and operations on the input data to produce something meaningful.
*   **Output Layer**: The neurons in this layer display a meaningful output.
*   **Connections**

*   The `MLP` is a `Feed Forward Neural Network`, which means that the data is transmitted from the input layer to the output layer in the forward direction.
*   The connections between the layers are assigned `Weights` as shown in [Figure 15.11](#ch15.xhtml#fig15_11). The weight of a connection specifies its importance. This concept is the backbone of an `MLP`'s learning process.

    ![Figure 15.11 MLP architecture with weights.](images/fig15_11_B.jpg)

*   While the inputs take their values from the surroundings, the values of all the other neurons are calculated through a mathematical function involving the weights and values of the layer before it.
*   For example, the value of the `h5` node in [Figure 15.11](#ch15.xhtml#fig15_11) could be (Equation 15.30),

    **Equation (15.30)**

    ```
    h[5] = h[1] * w[8] + h[2] * w[9] * h[5]
    ```

### 15.7.2 Backpropagation

`Backpropagation` is a technique used to optimize the weights of an `MLP` using the outputs as inputs.

In a conventional `MLP`, random weights are assigned to all the connections as shown in [Figure 15.12](#ch15.xhtml#fig15_12). These random weights propagate values through the network to produce the actual output ([Figure 15.13](#ch15.xhtml#fig15_13)). Naturally, this output would differ from the expected output. The difference between the two values is called the `Error`.

![Figure 15.12 Simple model for predicting the next binary number.](images/fig15_12_B.jpg)

![Figure 15.13 Iteration 1—training with first input of training set.](images/fig15_13_B.jpg)

`Backpropagation` refers to the process of sending this error back through the network ([Figure 15.14](#ch15.xhtml#fig15_14), [Figure 15.15](#ch15.xhtml#fig15_15)), readjusting the weights automatically so that eventually the error between the actual and expected output is minimized ([Figure 15.16](#ch15.xhtml#fig15_16)).

![Figure 15.14 Backpropagation—adjusting weights from output layer to hidden layer.](images/fig15_14_B.jpg)

![Figure 15.15 Back propagation—adjusting weights from hidden layer to input layer.](images/fig15_15_B.jpg)

![Figure 15.16 Training for particular input.](images/fig15_16_B.jpg)

In this way, the output of the current iteration becomes the input and affects the next output. This is repeated until the correct output is produced. The weights at the end of the process would be the ones on which the neural network works correctly ([Figure 15.16](#ch15.xhtml#fig15_16), [Figure 15.17](#ch15.xhtml#fig15_17)).

![Figure 15.17 Generation of final model.](images/fig15_17_B.jpg)
