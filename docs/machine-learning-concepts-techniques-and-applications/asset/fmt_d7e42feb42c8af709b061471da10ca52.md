## 3.1 Introduction

In [Table 3.1](#ch3.xhtml#table3_1) we list the context in which mathematical concepts are used.

**Table 3.1 Mathematical Concepts Used in Machine Learning**

| Mathematical Concept | Applications in Machine Learning |
|---|---|
| **Linear Algebra for Machine Learning** | Data representation and data preprocessing—attributes of input, image, audio, text<br>Operations on or between vectors and matrices for finding patterns in data<br>Linear equations to model the data<br>Linear transformation to map input and output<br>Cosine similarity between vectors<br>Eigen vectors, principal components, and dimensionality reduction |
| **Probability Theory for Machine Learning** | Classification models generally predict a probability of class membership.<br>Many iterative machine learning techniques like `maximum likelihood estimation (MLE)` are based on probability theory. `MLE` is used for training in models like `linear regression`, `logistic regression`, and `artificial neural networks`.<br>Many machine learning frameworks based on the `Bayes theorem` are called in general `Bayesian learning` (e.g., `naive Bayes`, `Bayesian networks`).<br>Learning algorithms make decisions using probability (e.g., information gain).<br>Algorithms are trained under probability frameworks (e.g., maximum likelihood).<br>Models are fitted using probabilistic loss functions (e.g., `log loss` and `cross entropy`).<br>Model hyper-parameters are configured with probability (e.g., `Bayesian optimization`).<br>Probabilistic measures are used to evaluate model skill (e.g., `brier score`, `receiver operator characteristic (ROC)`). |
| **Information Theory for Machine Learning** | `Entropy` is the basis for information gain and mutual information used in decision tree learning—`ID3` algorithm.<br>`Cross-entropy` is used as a loss function that measures the performance of a classification model.<br>`Kullback–Liebler (KL) divergence` measures are used in deep learning.<br>`KL divergence` is also used in dimensionality reduction technique—`t-distributed stochastic neighbour embedding (t-SNE)`. `Entropy` can be used to calculate target class imbalances. |
