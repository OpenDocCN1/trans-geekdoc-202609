## 4.8 机器学习算法的类型

机器学习算法的类型可分为经典机器学习、强化学习，以及基于神经网络和深度学习的算法。我们将首先讨论所谓的经典机器学习算法类型。这种分类取决于给予机器学习算法的反馈程度，主要有两种类型的机器学习算法，即监督学习和无监督学习。监督机器学习基本上分为两类，即分类和回归。无监督学习可进一步分为聚类、关联规则挖掘和降维（[图 4.8](#ch4.xhtml#fig4_8)）。

![图 4.8 经典机器学习的分类。](images/fig4_8_B.jpg)

[图 4.8 经典机器学习的分类。](#ch4.xhtml#R_fig4_8)

在经典类别中，我们还将讨论半监督机器学习，其中训练数据包含部分期望输出。请注意，我们在[第 2 章](#ch2.xhtml)中讨论的大多数概念都是基于监督学习的。所有机器学习算法的细节将在后续章节中讨论。在以下各节中，我们将对上述技术进行广泛的概述。

### 4.8.1 监督学习

监督学习是机器学习算法中理解得最透彻的类别。这里提供给算法的训练数据由输入和相应的期望输出或目标组成。监督学习旨在从示例中学习一个函数，并将其输入映射到输出。因此，算法学会了在给定新输入向量时预测输出。学习决策树是一种监督学习形式。监督学习的优点是它可以学习复杂模式，且通常性能良好。然而，这些算法需要大量带有输出标签的数据。

监督学习也称为预测模型，这意味着一旦学习了模型，它们就能从给定的新输入 `x` 中预测目标 `y`。在分类中，`y` 代表一个类别或“类”，而在回归中，`y` 是一个实值数字。分类可以描述为基于相似性对实体或信息进行分组。监督方法接收两种训练数据：一组我们拥有其输入数据（如图像或特征）的对象，以及一组与这些对象相关联的标签。标签可以是“狗”、“猫”或“马”等，这些被视为真实标签，或专家提供的反馈。标签不一定非要有离散的分类；它们可以是连续变量，如狗的长度或狗每天吃的食物量。现在让我们考虑一个分类示例（[图 4.9](#ch4.xhtml#fig4_9)）。该示例以两个词作为输入，输出标签将这组词分类为具有积极或消极情感。机器被训练为将输入数据与其标签相关联。

监督机器学习学习将输入映射到输出标签的预测模型或假设。因此，训练阶段涉及从原始数据中提取特征以形成特征向量 `x`。在[图 4.10](#ch4.xhtml#fig4_10)中，展示了训练样本 `I1`、`I2`、…… 的特征向量矩阵，每个样本关联 `m` 个特征。矩阵中的每一行对应一个 `x`。然后学习涉及将训练数据 `(x, y)` 拟合到假设 `h`。

在测试阶段，一个此前未知的输入被转换为特征向量并提供给预测模型，模型随后输出该输入的标签。这里同样，未见过的原始数据被转换为特征向量 `x`，然后我们将函数 `h` 应用于 `x` 作为 `h(x)`，并评估误差。

#### 4.8.1.2 分类与回归

如[图 4.8](#ch4.xhtml#fig4_8)所示，监督学习可进一步分为分类和回归。由于两者都是监督学习的例子，因此都需要提供输入和输出标签。在分类中，预测的是一个类别；而在回归中，则是基于训练数据预测一个数值输出。因此，在分类中，输出类型是离散的；我们试图找到类别之间的边界；通常使用的评估指标是准确率。在回归中，输出类型是连续的；我们试图最佳拟合一条线，即寻找一个线性或多项式函数来拟合数据；评估使用平方误差和（稍后将讨论）。值得注意的是，同一个问题可以建模为分类或回归。例如温度预测，在分类中我们预测明天天气是热还是冷，而在回归中我们预测明天的实际温度。
