2.  **E.3.1.2** 用例—贝叶斯定理—贝叶斯垃圾邮件过滤
    *   假设我们想利用贝叶斯定理根据某些词汇进行垃圾邮件过滤。我们假设事件 `A` 是消息为垃圾邮件。我们有一个测试 `X`，记录消息包含某些特定词汇。
    *   已知：
        1.  已知消息是垃圾邮件的情况下，测试 `X` 为真的概率 = 0.85%。
        2.  消息通常是垃圾邮件的概率是 30%。
        3.  尽管测试 `X` 为真，但消息不是垃圾邮件的概率 = 2%。
    *   我们需要找到在测试为真（即包含某些特定词汇）的情况下，消息是垃圾邮件的概率。
