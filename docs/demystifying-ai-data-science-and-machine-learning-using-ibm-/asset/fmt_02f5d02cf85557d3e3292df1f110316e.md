
## Application-specific considerations

The suitability of data normalization depends on the specific data and the machine learning methods. In some cases, maintaining the original scale of the data might be necessary for meaningful interpretation or compatibility with certain algorithms. Normalization should be carefully evaluated based on the requirements and characteristics of the data and the intended modeling techniques.

[Table 5.4](#chapter5.xhtml#tbl5_4) presents common data normalization methods. When choosing a normalization method, several factors must be considered:

**TABLE 5.4** Common Data Normalization Methods and When to Use Them [Return to text.⏎](#chapter5.xhtml#b5tbl5_4)

| Normalization Methods | Descriptions | When to Use |
| --- | --- | --- |
| Min-max normalization (also known as rescaling) | Formula: `X' = (X - X_min) / (X_max - X_min)`<br>Range: `[0, 1]` | When you want to scale the data to a specific range, particularly when the distribution is known to be bounded. |
| Z-score normalization (also known as standardization) | Formula: `X' = (X - X_mean) / SD` | When you want to standardize the data to have a mean of 0 and a standard deviation (SD) of 1. This method is commonly used when the distribution of the data is unknown or not normally distributed. |
| Robust scaling (also known as median and MAD scaling) | Formula: `X' = (X - X_median) / MAD` | When you have data with outliers or a skewed distribution and you want to scale the data based on the median and median absolute deviation (MAD) instead of the mean and SD. |
| Log transformation | Formula: `X' = log(X)` | When the data are highly skewed or contain exponential growth patterns, applying a logarithmic transformation can help normalize the distribution. |
| Power transformation | Formula: `X' = X^n` | When the data have a specific power-law relationship, a power transformation can help normalize the distribution. Common power values include `n = 0.5` (square root), `n = 2` (square), and `n = -1` (inverse). |

Note: `X'` = New value; `X` = Current value.

*   **Purpose of normalization**: Determine whether the goal is to enhance the performance of your machine learning model or to make the data easier to visualize or interpret.
*   **Type of data**: Consider whether you are working with numerical or categorical data. Note that normalization is applicable only to continuous variables.
*   **Size of dataset**: For large datasets, it's essential to select a more efficient normalization method to handle the volume of data effectively.
*   **Algorithms used**: Some algorithms, such as k-nearest neighbors and artificial neural networks, are more sensitive to data scaling than others. Linear regression, for instance, performs best with normally distributed data. If you're using these algorithms, ensure that all variables are on the same scale by applying normalization.
*   **Model performance**: Experiment with different normalization methods and evaluate which one yields the best performance for your model.

### Variable Discretization

![](images/ufig5_16.jpg)

Variable discretization is the process of converting a continuous variable into a categorical variable. This is a common preprocessing step in data mining when you need to transform a variable with a continuous scale into discrete categories. Discretization can be particularly useful when you want to capture nonlinear relationships or when a specific data mining algorithm requires the variable to be treated as categorical. [Figure 5.2](#chapter5.xhtml#fig5_2) illustrates this concept, showing how the input (a continuous variable) is transformed into the output (a categorical variable with discrete levels).

![FIGURE 5.2 Data discretization. Return to text.⏎](images/fig5_2.jpg)

**FIGURE 5.2** Data discretization. [Return to text.⏎](#chapter5.xhtml#b5fig5_2)

A general approach to converting a continuous variable into categorical variables can be described as follows:

1.  **Determine the number and range of categories**: Decide on the desired number of categories or groups you want to create for the new variables. This number represents the number of levels that you need for the categorical variable. This decision may depend on the specific dataset, the nature of the variable, and the purpose of the analysis. You can also consider using domain knowledge or statistical techniques to guide your decision.
2.  **Partition the range of values**: Divide the range of values of the continuous variable into distinct bins. Each bin represents a category or level. The intervals should be defined to capture meaningful distinctions in the data while maintaining a balance between the number of categories and the information contained within each category.
3.  **Assign categories to data points**: Map each data point from the original continuous variable to its corresponding category based on its value falling within the defined intervals. This mapping can be achieved using `if-else` statements, mathematical functions, or specialized functions available in data mining software.
4.  **Encode categories into the new categorical variable**: Once the data points are assigned to categories, represent each category as a separate level of the new categorical variable. This step can be done differently depending on the software.

For example, when converting a continuous variable like age into a categorical variable, you might define categories such as `young`, `middle-aged`, and `elderly` based on specific age ranges. You would create three distinct bins based on the predefined ranges and assign continuous age values to these bins accordingly. Finally, the new categorical variable (e.g., `r_age`) would be created and encoded with three levels: `young`, `middle-aged`, and `elderly`.

It's important to note that converting continuous variables into categorical variables can result in some loss of information due to the discretization of the data. Additionally, the specific approach and the number of categories chosen can impact the results of your data mining efforts. It's advisable to experiment with different categorization schemes and evaluate their effects on model performance.

[Table 5.5](#chapter5.xhtml#tbl5_5) describes common methods for variable discretization, with guidance on when to use each method based on the data's characteristics and the analysis purpose.

**TABLE 5.5** Common Variable Discretization Methods and When to Use Them [Return to text.⏎](#chapter5.xhtml#b5tbl5_5)

| Discretization Methods | Description | When to Use |
| --- | --- | --- |
| Fixed-width/binning (equal-width binning) | This method divides the range of the continuous variable into a predetermined number of equal-width bins and assigns category labels based on which bin each value falls into. | When you want to perform a simple discretization without considering the distribution of the data. This method is less sensitive to outliers but may not capture the underlying patterns in the data. |
| Quantiles/binning (equal-frequency binning) | This method divides the data into bins based on equal-frequency or equal-sized subsets to ensure that each bin contains an equal number of data points. Then, it assigns category labels based on the bin each value belongs to. | When you want to ensure an equal representation of data points in each category and capture the distribution of the data. This method can be helpful for handling skewed data, but it may result in uneven bin sizes if the data contain outliers or extreme values. |
