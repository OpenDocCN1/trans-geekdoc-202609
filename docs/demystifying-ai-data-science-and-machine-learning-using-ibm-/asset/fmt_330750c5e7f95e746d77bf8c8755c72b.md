
# 回归分析的两种主要类型

回归分析主要有两种类型：线性回归和逻辑回归。虽然两者都是回归方法，但它们存在根本性差异。

## 线性回归

当目标变量是连续变量时使用线性回归，这使其成为一种关联模型。在某些情况下，使用李克特量表测量的目标变量可以用线性回归进行分析，前提是各等级之间的间隔相等。正如[第3章](#chapter3.xhtml)所述，在这种情况下，李克特量表变量可被视为区间变量。

![图片](images/ufig7_5.jpg)

## 逻辑回归

另一方面，当目标变量是分类变量（二元或名义）时使用逻辑回归，这使其成为一种分类模型。二元变量有两个水平，而名义变量有两个以上水平（多类）。当目标变量是名义变量时，该模型通常被称为多项逻辑回归。然而，在数据挖掘中，二元和名义目标变量的区别不那么重要，因为重点转移到了模型性能上。为保持简单，我将对二元和名义目标变量统一使用“逻辑回归”这一术语，在必要时会指明目标变量的尺度以作澄清。[表7.1](#chapter7.xhtml#tbl7_1)展示了线性回归和逻辑回归的示例，有助于说明这两种方法的实际差异。

**表7.1 线性回归与逻辑回归示例** [返回文本.⏎](#chapter7.xhtml#b7tbl7_1)

| 回归方法 | 示例 |
| :--- | :--- |
| 线性回归示例 | 目标变量是学生的SAT分数，这是一个连续变量，范围从0到1600。预测变量包括年龄、性别、种族、高中GPA和家庭收入。 |
| 逻辑回归示例 | 目标变量是学生选择特定专业（如市场营销）的决定。这是一个二元变量（是或否）。另一个示例涉及学生在四个专业中的选择：市场营销、会计、金融或管理。在这种情况下，目标变量是具有四个水平的名义变量：1（市场营销）、2（会计）、3（金融）或4（管理）。预测变量包括年龄、性别、种族、高中GPA和家庭收入。 |

由于目标变量的差异，线性回归和逻辑回归采用不同的估计方法，导致其假设、输出和结果解释方面存在差异。具体而言，线性回归使用**普通最小二乘法（OLS）**估计回归方程，而逻辑回归依赖**最大似然法（ML）**进行估计。

![图片](images/ufig7_6.jpg)

这些方法的回归方程如下所示。为使方程更易理解，我避免了典型的数学符号，而是以更直接的方式命名变量和系数，而非使用希腊字符。

### 线性回归方程

```
target = int + coe1 * predictor1 + coe2 * predictor2 + coe3 * predictor3 + … + error
```

### 逻辑回归方程

```
logit(target) = int + coe1 * predictor1 + coe2 * predictor2 + coe3 * predictor3 + … + error
```

其中：

*   `target` 是目标变量，
*   `predictor` 是预测变量，
*   `int` 是截距，
*   `coe` 是对应预测变量的回归系数，
*   `error` 是误差项。

你可能会注意到，在逻辑回归中，我们不直接估计目标变量，而是估计该变量的**logit值**。自然地，logit值的概念可能难以理解。因此，在解释逻辑回归结果时，我们使用**优势比**而非相关系数。我将在本章后面的“如何阅读和理解逻辑回归结果”部分对此进行解释。

[图7.1](#chapter7.xhtml#fig7_1)中的图表展示了线性回归方程与逻辑回归方程的差异。正如你所见，线性回归仅检测目标变量（`Y`）与预测变量（`X`）之间的**线性关系**。相比之下，逻辑回归通过logit函数捕捉目标变量（`Y`）与预测变量（`X`）之间的**非线性关系**。由于逻辑回归中的目标变量是二元的（0或1），`Y`只能取这两个值。但请注意，**logit(Y)**与`X`之间的关系保持线性，正如方程所示。

![图7.1 线性回归和逻辑回归. 返回文本.⏎](images/fig7_1.jpg)

**图7.1 线性回归和逻辑回归.** [返回文本.⏎](#chapter7.xhtml#b7fig7_1)

因此，虽然逻辑回归可以通过logit函数检测非线性关系，但其建模非线性的能力仅限于这种变换以及相关系数的线性效应。这是逻辑回归与其他非线性方法（如决策树、神经网络或随机森林）的关键区别，后者可以识别更复杂形式的非线性。

[表7.2](#chapter7.xhtml#tbl7_2)重点介绍了线性回归和逻辑回归之间的一些关键差异。在接下来的章节中，我们将探讨这两种方法的细节以及如何使用这些方法配置模型。

**表7.2 线性回归与逻辑回归的差异** [返回文本.⏎](#chapter7.xhtml#b7tbl7_2)

| 项目 | 线性回归 | 逻辑回归 |
| :--- | :--- | :--- |
| 因变量的性质 | 线性回归中的目标变量是连续数值型，代表一系列实数。模型旨在建立预测变量与连续结果之间的线性关系。 | 逻辑回归中的目标变量是二元或分类型，代表两个或多个离散结果。模型预测某一类别事件发生的概率。 |
| 输出与范围 | 线性回归的输出是连续值，预测值可以是任何实数。预测范围不受约束。 | 逻辑回归的输出是0到1之间的概率分数，代表事件发生的可能性。 |
| 模型函数 | 线性回归的模型函数是一个线性方程，表示预测变量的加权和加上截距项。假设变量间关系是线性的。 | 逻辑回归的模型函数是逻辑（Sigmoid）函数，将预测变量的加权和映射为概率分数。它对事件发生的几率建模。注意：事件几率与预测变量之间的关系假设为线性。 |
| 应用 | 线性回归用于预测和建模连续结果，如基于各种因素预测房价、温度或销量。 | 逻辑回归用于二元或多项分类任务，如预测邮件是否为垃圾邮件，或将图像分类到多个类别中。 |
| 评估指标 | 线性回归使用关联模型的常见模型拟合指标，加上F检验和R平方（决定系数）。 | 逻辑回归使用分类模型的常见模型拟合指标。 |
