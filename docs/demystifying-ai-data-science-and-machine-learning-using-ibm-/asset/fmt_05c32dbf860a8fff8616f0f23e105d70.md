
| Optimization method | The model parameters in linear regression are typically estimated using methods like ordinary least squares (OLS) to minimize the sum of squares errors. | The model parameters in logistic regression are typically estimated using maximum likelihood estimation (MLE) to maximize the likelihood of the observed outcomes. |

## Linear Regression

![](images/ufig7_9.jpg)

### Linear Regression Equation

Let's begin with a linear regression equation to understand the components of this method. As previously mentioned, the regression equation represents the mathematical relationships between the target variable and predictors. Linear regression is applicable only when the target variable is continuous. Here, we will present the linear regression equation in its traditional form, which helps you interpret outputs provided by various software applications. You can always refer to the simplified version shown earlier.

```
Y = β[0] + β[1]x[1] + β[2]x[2] + … + β[n]x[n] + ε
```

Where

*   `Y` is the target variable,
*   `x[1] to x[n]` are predictor variables (1 – n),
*   `β[0]` is the intercept,
*   `β[1] – β[n]` are the regression coefficients for the corresponding predictors,
*   `ε` is the residual or error.

### Estimation Approach

An estimation approach refers to the statistical method used to calculate the values of all components in the regression equation, including the intercept, regression coefficients, and error terms. `OLS` is the standard estimation method for linear regression. It is commonly used to estimate the intercept and regression coefficients by minimizing the sum of squares errors (`SSEs`). The mathematical foundation of `OLS` is thoroughly explained in many statistics books, so I won't elaborate here. What is important to emphasize is that using this method imposes strict assumptions on linear regression.

### Assumption Requirements

In traditional statistical studies, linear regression is subject to strict assumptions to ensure the validity of the results. These include assumptions of normality, homoscedasticity, linearity, non-multicollinearity, continuous variables, and no missing values. If these assumptions are violated, the software can still run the analysis and produce outputs, but the validity of the results—and consequently the conclusions—becomes uncertain. In traditional settings, researchers typically work with a small number of predictors and a small sample size. For instance, with five predictors and an effect size of 0.25, a sample size of just 57 records is required. With ten predictors, the sample size increases only slightly to 75 records.

![](images/ufig7_10.jpg)

However, in data mining, we work with very large datasets containing many predictors and a large sample size. As a result, we have more flexibility in terms of meeting these assumptions when using linear regression. The Central Limit Theorem supports this flexibility, as it states that with a large enough sample size, the distribution of the sample can be assumed to be approximately normal. Therefore, when applying linear regression in data mining, we do not need to strictly meet all the assumptions, as is required in traditional studies.

That said, it is still advisable to address key assumptions to improve the performance of the regression model. For instance, handling and imputing missing values is highly recommended, as linear regression performs better with a complete dataset. Normalizing the data can also improve model fit by addressing the normality assumption. Additionally, managing outliers helps reduce noise in the data, leading to a more accurate model fit.

![](images/ufig7_11.jpg)

**You may ask:** **Should we be concerned about the validity of the results if we do not meet the test assumptions?** It's a good question, as we should always consider the reliability and validity of the results. In data mining studies, we implement additional rigorous steps to ensure the quality of the results. As mentioned in [Chapter 3](#chapter3.xhtml), we typically split the dataset into `training`, `test`, and `validation` samples. The training sample is used to build the model while the test and validation samples ensure the model's performance beyond just the training data, helping prevent overfitting. By comparing the model's results across these three samples, we can assess the model's performance and ensure its reliability and validity. Thus, even if we do not meet all assumptions, these steps allow us to maintain the validity of our predictive models.

Here are a few key assumptions for linear regression, along with the level of flexibility we have in data mining projects:

*   **The target variable must be continuous**: This assumption is crucial for establishing an association model. However, a target variable on a Likert scale is acceptable as long as the gaps between levels are equal.
