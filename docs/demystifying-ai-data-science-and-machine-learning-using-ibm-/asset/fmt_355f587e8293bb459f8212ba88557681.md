### Modeling

254. Our objective is to build and run a logistic regression model with the target field being airline recommendation. Since this is a binary field, we will use binomial logistic regression rather than multinomial regression, which is used for target fields with multiple levels.

There are various approaches to building the model, using different data transformation options and SPSS Modeler tools. To explore the best approach, I will build four different logistic regression models and compare them to determine which one offers the best predictive power. #### Steps to Build Logistic Model 1

1. Open SPSS Modeler and create a new stream. Name the stream `Airline_Regression`.
2. Add the data source file `AirlineRecommendation.sav` to the stream.
3. Add a `Type` node to the stream and connect it to the data source. Open the `Type` node settings.
4. 256. Double-check the `field names`, `measurement scales`, and `roles` for accuracy.
5. Set the `role` of the field `recommendation` as `Target`. All other fields should be set as `Input`.
6. Perform replacement using the `Filter node` to replace zero values in the `price sensitivity` field with missing values (see [Chapter 5](#chapter5.xhtml) for reference).
7. Perform imputation using `SuperNodes` as described earlier (see [Chapter 5](#chapter5.xhtml) for reference). After this step, you should have a SuperNode named `Missing Value Imputation` for handling missing values.
8. Add another `Type` node to the stream and connect it to the SuperNode `Missing Value Imputation`. Open the `Type` node settings and double-check the fields, measurements, and roles.
9. Add a `Partition` node to the stream and connect it to the `Type` node. Open the `Partition` node settings.
10. Select `Train, test, and validation` and set the `training partition` size to `60%`, the `testing partition` size to `20%`, and the `validation partition` size to `20%` (refer to the Data Partition step for more details).
11. Click `Apply`, then click `OK`.
12. Add an `Auto Data Prep` node to the stream and connect it to the `Partition` node.
13. Under `Settings` > `Prepare Inputs & Target`, check the box for `Reorder nominal fields to have the smallest category first, largest last` and uncheck all other boxes. This ensures proper numeric formatting for categorical input fields required to run the `Logistic` node.

     ![](images/ufig7_44.jpg)

14. Click `Apply` and then `Analyze Data`.
15. 257. Add another `Type` node to the stream and connect it to the `Auto Data Prep` node. Open the `Type` node settings.

     ![](images/ufig7_45.jpg)

16. Confirm that all categorical input fields have been transformed (I use a `_t` suffix to denote transformed fields).

     ![](images/ufig7_46.jpg)

17. From the `Modeling` group, add a `Logistic` node to the stream. Name it `Logistic 1` and connect it to the `Type` node. Open the `Logistic` node settings.
18. Under the `Model` tab, select `Use partition data` and `Build model for each split`.
19. Select `Binomial` for the `Procedure`.
20. Choose `Forward Stepwise` for the `Method`.
21. 258. Select and add all `categorical inputs` to the model. The `Base Category` column shows the reference level for these categorical inputs. You can change it to either the `First` or `Last` level. For this example, leave the setting as `First` for all fields.

     ![](images/ufig7_47.jpg)

22. Under the `Analyze` tab, select `Calculate predictor importance`.
23. Click `Apply` and `Run`.
24. SPSS Modeler will run the analysis and add the `model nugget` (result node) to the stream. If there are errors during the run, the software will display an error message.
