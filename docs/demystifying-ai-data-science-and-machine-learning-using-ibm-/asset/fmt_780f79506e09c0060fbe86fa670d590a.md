
## Markov Blanket Components

1.  **Parents:** The parents of the target variable in the Bayesian network. These are the nodes directly connected to the target variable by incoming edges.

2.  **Children:** The children of the target variable. These are the nodes directly connected to the target variable by outgoing edges.

3.  **Spouses:** The parents of the children of the target variable. These are the nodes that are directly connected to the children of the target variable, excluding the target variable itself.

The Markov blanket is important because it represents a minimal set of variables that need to be observed or considered when predicting the target variable or performing probabilistic inference. Variables outside the Markov blanket are irrelevant to the target variable once the Markov blanket variables are known. The Markov blanket provides a way to identify and exploit the conditional independence relationships between variables in a Bayesian network. It helps reduce the computational complexity of probabilistic inference by focusing on the minimal set of relevant variables.

## Network Structure Learning Algorithms

![](images/ufig16_14.jpg)

One important step in the Bayesian network process is learning the network structure from data. In data mining, learning algorithms are employed to accomplish this task. In the context of Bayesian networks, two primary types of learning algorithms are commonly used: score-based algorithms and constraint-based algorithms. In this section, we will gain a fundamental understanding of these algorithms and their differences.

### Score-Based Algorithm

A score-based algorithm is a Bayesian network structure learning approach that aims to maximize a scoring metric to identify the most probable network structure, given the data. The algorithm searches through possible network structures and selects the one that best fits the data according to a specific scoring criterion. Commonly used scoring metrics include log-likelihood, Bayesian information criterion (`BIC`), and Akaike information criterion (`AIC`). The algorithm assigns a score to each structure, with higher scores indicating a better fit of the model to the data. The goal is to find the network structure that maximizes this score.

### Constraint-Based Algorithm

A constraint-based algorithm learns the network structure by identifying the probabilistic dependencies between variables without directly optimizing a scoring metric. Instead of exhaustively searching all possible network structures, this algorithm tests and evaluates conditional independence relationships among the variables. By iteratively applying these tests, the algorithm constructs a network that captures the dependencies and independencies in the data, thus defining the structure.

Each of these approaches has its strengths and weaknesses, and the choice of the method depends on factors such as the size of the dataset, the complexity of the network, the availability of domain knowledge, and the desired interpretability of the resulting model.

## Causal Data Mining Process

Given Bayesian networks’ capability to capture probabilistic relationships among variables in a complex network, I want to introduce the concept of causal data mining and how Bayesian networks can be applied in causal data mining projects.

In traditional data mining, as discussed in previous chapters, the goal is often to use machine learning algorithms to detect unknown relationships within data that help predict a target variable. These projects generally result in a predictive model that accurately forecasts the target variable based on key predictors. However, the focus in such projects is not on understanding how the variables interact with and influence one another. The outcome users seek is the “champion model” that can make accurate predictions about the risk or event of interest.

553. But what if, in some cases, users want to delve deeper into the data, exploring how variables interact and influence one another? Or what if they want to know which variable has a direct causal effect on another, setting off a chain reaction that impacts further variables? Gaining insight into these causal relationships helps organizations make sense of their predictions and craft long-term strategies that are grounded in a deeper understanding of the data. In this scenario, traditional data mining techniques may not be sufficient. What we need here is a new type of data mining, which I call *causal data mining*.

![](images/ufig16_15.jpg)

In my article published in the *Journal of Air Transport Management* in 2021, I define causal data mining as “a method of using causal machine learning algorithms to detect unknown patterns involving variables and their interrelationships in a causal network from data to predict outcomes.” In projects of this nature, common processes such as `SEMMA` or `CRISP-DM` may not be the best fit, as they do not reflect the causal nature of the problem. To address this, I developed a six-step process tailored specifically for causal data mining: Understanding, Sampling, Exploring, Learning, Evaluating, and Inferring, abbreviated as **USELEI**.

In this section, I describe the `USELEI` process and explain how it can be applied to causal data mining projects to uncover deeper insights about how variables relate and influence each other.
