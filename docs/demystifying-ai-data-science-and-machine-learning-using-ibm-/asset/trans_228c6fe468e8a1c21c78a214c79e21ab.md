
为了获取更多性能指标，我们向每个模型添加一个“分析”节点并运行它。从“分析”节点的输出中，我们可以提取相关指标。然而，正如[第 8 章](#chapter8.xhtml)所述，我们将主要使用平均绝对误差（MAE）和线性相关性来比较模型，因为其他指标对于比较而言意义较小。

如[表 9.9](#chapter9.xhtml#tbl9_9)所示，根据测试样本结果，MLP 4 拥有最高的 EP，但其 MAE 并非最低。MLP 3 显示出最低的 MAE 和最高的线性相关性。这种差异产生的原因是 EP 是基于训练样本计算的，而 MAE 是基于测试样本计算的。在这种情况下，我们应优先考虑测试样本的结果。重新计算测试样本的 EP 后，确认 MLP 3 的 EP 高于 MLP 4。因此，MLP 3 表现出最高的预测准确性。

**表 9.9 模型比较结果** [返回正文.⏎](#chapter9.xhtml#b9tbl9_9)

| 模型 | EP (%) (训练) | MAE (测试) | 线性相关性 (测试) |
| --- | --- | --- | --- |
| MLP 1 | 84.1 | 2.712 | 0.864 |
| MLP 2 | 84.0 | 2.515 | 0.889 |
| MLP 3 | 85.7 | 2.418 | 0.89 |
| MLP 4 | 87.0 | 2.693 | 0.877 |
| RBF 1 | 44.1 | 4.8 | 0.564 |
| RBF 2 | 71.4 | 3.344 | 0.788 |
| RBF 3 | 83.7 | 3.233 | 0.777 |
| RBF 4 | 83.5 | 3.828 | 0.632 |

在 MLP 模型中，MLP 1（节点数自动确定）的准确性最低。准确性最高的模型 MLP 3 使用两个隐藏层，每层包含 20 个节点，这比 MLP 1 和 MLP 2 都多。然而，这并不意味着节点越多准确性就越高（例如，MLP 4 每个隐藏层有 30 个节点，却没有超越 MLP 3）。关键在于找到最佳节点数（神经元数）。SPSS Modeler 缺乏网络结构的自动优化功能，因此确定最佳配置需要反复试验。还值得注意的是，节点越多的模型收敛所需的计算时间越长。

在 RBF 模型中，RBF 1（节点数自动确定）准确性最低。有趣的是，拥有 50 个节点的 RBF 3 在 RBF 模型中准确性最高。然而，总体而言，对于该数据集，MLP 模型的准确性高于 RBF 模型。

综上所述，由于 MLP 3 具有卓越的预测准确性，因此被选为冠军模型。

### 冠军模型的可靠性

在此步骤中，我们评估冠军模型的可靠性。[表 9.10](#chapter9.xhtml#tbl9_10) 展示了测试样本与训练样本指标的并列比较。结果显示这两个样本之间存在显著差异，特别是在 MAE、标准差和线性相关性方面。具体而言，差异分别为 MAE 12%、标准差 16%、线性相关性 4%。这些差异表明模型在测试样本上的表现准确性低于训练样本，引发了潜在的可靠性担忧。

**表 9.10 冠军模型可靠性评估——MLP 3** [返回正文.⏎](#chapter9.xhtml#b9tbl9_10)

| 指标 | 测试 | 训练 |
| --- | --- | --- |
| 最小误差 | −10.665 | −24.142 |
| 最大误差 | 23.489 | 10.308 |
| 平均误差 | 0.1 | 0.131 |
| 平均绝对误差 | 2.418 | 2.126 |
| 标准差 | 3.778 | 3.154 |
| 线性相关性 | 0.89 | 0.926 |

相对较小的样本量加剧了这种不一致性（训练样本量：304 条记录；测试样本量：202 条记录）。通常情况下，较小的样本量，尤其是在变量众多时，会导致建模过程中的误差增大。为提高模型的可靠性，建议收集更多数据并重新训练模型。虽然在本例中无法采取此类措施，但认识到这一问题并为未来工作考虑潜在解决方案非常重要。
