
Additionally, it's important to examine this chart for any apparent patterns. A **non-random pattern** indicates a correlation between residuals and predicted values, suggesting that some 195. explanatory information is missing from the model. This implies that the predictors in the model may not be fully capturing certain variables, which are instead reflected in the residuals. Typically, we aim for a chart with **no clear pattern**—a random distribution, also known as “white noise.” To meet this requirement, points should be symmetrically distributed and clustered toward the center of the plot (see [Figure 6.6](#chapter6.xhtml#fig6_6)).

![](images/ufig6_26.jpg)

[Figure 6.7](#chapter6.xhtml#fig6_7) presents several examples of scatter plots with non-random patterns, such as an uneven distribution of points (Chart A), clear shapes (Charts B and C), and outliers (Chart D). In these cases, the model does not achieve a satisfactory fit and requires improvement. Potential solutions could include reconfiguring the model, using an ensemble model, resampling to add more data points, or incorporating additional predictors.

## Model Fit Metrics for Classification Models

Classification models typically involve either binary or nominal target variables. **Binary target variables** are more common since they often predict the occurrence of an event. The target variable has two levels: occurrence (events) and non-occurrence (non-events). For example, this can be applied to predicting credit fraud risk, aviation accidents, flight cancellations, or customer purchase decisions. As a result, we will primarily focus on models with binary target variables. Models with **nominal target variables** (more than two levels) use the same model fit metrics but with some calculation differences, which I will explain later.

## Model Fit Metrics for Binary Target Variables

### Confusion Matrix Metrics

![](images/ufig6_29.jpg)

When dealing with a binary target variable, several important model fit metrics can be used to evaluate the model's performance. These metrics are calculated based on the **confusion matrix**, also known as the **classification matrix**, which summarizes the performance of a classification algorithm. It presents all the results of the prediction, including both correct and incorrect predictions. Specifically, it shows the number of **True Positives (TP)**, **True Negatives (TN)**, **False Positives (FP)**, and **False Negatives (FN)**. [Table 6.6](#chapter6.xhtml#tbl6_6) shows the structure of a confusion matrix. These values (TP, TN, FP, FN) are extracted from the results of the modeling process. Definitions of these terms are provided in the definition box.

TABLE 6.6 Classification Matrix or Confusion Matrix [Return to text.⏎](#chapter6.xhtml#b6tbl6_6)

| | Predicted YES | Predicted NO |
| --- | --- | --- |
| Actual YES | TP (true positive) | FN (false negative) |
| Actual NO | FP (false positive) | TN (true negative) |

In most data mining projects, we aim to predict events and non-events. For this, we usually use a binary target variable with values of 1 (event) or 0 (non-event). Events (1) are considered positives, and non-events (0) are considered negatives. For example, when predicting the risk of flight cancellation, 1 indicates a cancellation (positive) and 0 indicates no cancellation (negative).
