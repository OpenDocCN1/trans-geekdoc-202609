This is why evaluating both model reliability and validity is essential. We cannot fully confirm a model's validity until it demonstrates reliability. In other words, for a model to be valid, it must consistently produce accurate predictions of the target variable. Essentially, model validity is the same as predictive power. With a clear understanding of the difference between reliability and validity, the next step is to learn how to assess these qualities in a predictive model. It's important to note that we cannot assess reliability and validity through separate processes since the same model fit metrics are used for both. Therefore, they must be evaluated within the same process, even though we provide separate evidence for each.

## Model Reliability and Validity Assessment Process

Follow the steps below to evaluate the reliability and validity of a predictive model:

![](images/ufig6_12.jpg)

1.  **Split the sample** into sub-samples, including training, test, and validation sets. The recommended split ratio is 60–40, with 60% for training, 20% for testing, and 20% for final validation.

2.  **Configure a predictive model** based on the chosen machine learning method (details on specific methods will be covered in the next chapters).

3.  **Train the model** using the training sample and then test it with the test sample. Most data mining software automates this step.

4.  **Evaluate the model fit** of the training sample using pre-determined metrics (discussed in the following sections). If the model fit is satisfactory, proceed to Step 5. If not, return to Step 2 to reconfigure the model.

5.  **Compare the model fit metrics** between the training and test samples. Use the same metrics to assess both.

6.  **Assess model reliability** by comparing two samples. If the comparison shows consistency between the training and test samples, you can conclude that the model is reliable. The level of acceptable consistency depends on the context of the study, but if the discrepancy is less than 5%, it can be considered reliable. **Conclusion**: Model reliability is achieved.

7.  **If model reliability is not achieved**, adjust the sampling and modeling processes in Steps 1 and 2. Solutions may include resampling data, reconfiguring the model, trying alternative machine learning methods, or using an ensemble model. Repeat Steps 2–5 until reliability is achieved.

8.  **Evaluate the overall model fit** for the test sample to confirm it meets the desired criteria (additional metrics may be used). If the model fit is satisfactory, move to Step 9. If not, further adjustments are needed to improve performance.

9.  **Evaluate the model fit for the validation sample** as the final assessment. If the model shows a good fit with the validation sample, then model validity is achieved. **Conclusion**: Model validity is achieved.

## How to Report Model Reliability and Validity Results

Suppose we have completed the predictive modeling process and achieved both model reliability and validity. How do we report the results effectively? Since the process is iterative, presenting results for every step could make the report overly complex and potentially confusing for readers. To avoid this, I recommend the following steps to present the results clearly and effectively. These steps are particularly useful for projects involving multiple models.

![](images/ufig6_13.jpg)

1.  **Present model comparison results**: If there are multiple models, compare their performance using key model fit metrics from the test sample. Explain whether the model fit is satisfactory and why. While it is necessary to evaluate the model fit for the training sample during the process, there is no need to report the training sample results separately. Since the test sample evaluates the model's generalization, reporting test results will be most informative for readers to understand the tested model fit.

2.  **Identify the preliminary champion model**: Based on the comparison of test sample results, identify the preliminary champion model. Confirm this selection by evaluating multiple model fit metrics to ensure robustness.

3.  **Compare model fit metrics across samples**: Focus on the champion model and present a comparison of model fit metrics across the training, test, and validation samples. Explain whether the results are consistent and reliable across the samples. If the results are consistent, you can conclude that model reliability is achieved.

4.  **Evaluate complete model fit**: Present additional model fit metrics, particularly focusing on the validation sample. This step ensures a thorough evaluation of the model fit and confirms whether the champion model fits well with the validation data.

5.  **Conclude model validity**: If the model fit metrics for the test sample are satisfactory and the model shows reliability across the samples, you can conclude that the model has achieved validity. In summary, the champion model has good predictive power.

6.  **Report model structure and variable importance**: Finally, explain the structure of the champion model, the relationships between variables, and the importance of each variable in the model.

## Model Comparison

In data mining, the goal is to discover unknown patterns from large and often noisy datasets. This process involves mining the data to uncover new insights and relationships among variables that may not be found in existing literature or identifying new predictors. Because of the exploratory nature of data mining, it's difficult to predict in advance which machine learning methods and configurations will work best. The ideal machine learning model depends on the data itself. Our objective is to find the model that best fits the data. Importantly, using a more advanced or complex method does not guarantee that it will be the best model.

Let's consider a hypothetical scenario illustrated in [Figure 6.4](#chapter6.xhtml#fig6_4). Imagine we build two models for the same dataset. One model uses an advanced method, such as neural networks (on the right), which captures nonlinear relationships between predictors and the target variable and seems to fit the data very well. The other model uses a simpler method, linear regression (on the left), which assumes a linear relationship between the predictors and the target variable.

![](images/ufig6_15.jpg)![FIGURE 6.4 Simple linear model vs. a complex, nonlinear model—A hypothetical scenario. Return to text.⏎](images/fig6_4.jpg)

FIGURE 6.4 Simple linear model vs. a complex, nonlinear model—A hypothetical scenario. [Return to text.⏎](#chapter6.xhtml#b6fig6_4)

During the model training process, the neural network model may appear to outperform the linear regression model based on prediction accuracy. However, if we examine the data visually using a scatter plot, we might notice that the data follows a linear pattern. This suggests that, despite being simpler, the linear regression model captures the underlying pattern better than the more complex neural network model.
