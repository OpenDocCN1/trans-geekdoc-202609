## Exercise 1: Bayesian Network Models for the Bank dataset

1.  Open the `bank` dataset in SPSS Modeler.

2.  Sample the entire dataset. See the variable names and descriptions in Appendix A.

3.  Partition the data using a split ratio of 60–20–20 (train: 60%, test: 20%, and validation: 20%).

4.  Perform data modification as follows:
    *   Impute missing values.
    *   Normalize the data.

5.  Set `CRSCORE` (credit scores) as the target variable.

6.  Configure five Bayesian Network models for this dataset as follows.

    ### TAN 1 Model Configurations

    **Model options**
    *   Select “Use partitioned data” and “Build model for each split”.
    *   Structure type: TAN.
    *   Parameter learning method: Maximum likelihood.

    **Expert options**
    *   Select “Expert”.
    *   Missing values: Use only complete records.
    *   Independent test: Likelihood ratio.

    ### TAN 2 Model Configurations

    **Model options**
    *   Select “Use partitioned data” and “Build model for each split”.
    *   Structure type: TAN.
    *   Parameter learning method: Bayes adjustment for small cell counts.

    **Expert options**
    *   Select “Expert”.
    *   Missing values: Use only complete records.
    *   Independent test: Pearson chi-square.

    ### Markov Blanket 1 Model Configurations

    **Model options**
    *   Select “Use partitioned data” and “Build model for each split”.
    *   Structure type: Markov Blanket.
    *   Parameter learning method: Maximum likelihood.

    **Expert options**
    *   Select “Expert”.
    *   Missing values: Use only complete records.
    *   Independent test: Likelihood ratio.

    ### Markov Blanket 2 Model Configurations

    **Model options**
    *   Select “Use partitioned data” and “Build model for each split”.
    *   Structure type: Markov Blanket.
    *   Parameter learning method: Bayes adjustment for small cell counts.

    **Expert options**
    *   Select “Expert”.
    *   Missing values: Use only complete records.
    *   Independent test: Pearson chi-square.

    ### Markov Blanket FS Model Configurations

    **Model options**
    *   Select “Use partitioned data” and “Build model for each split”.
    *   Structure type: Markov Blanket.
    *   Select “Include feature selection preprocessing step”.
    *   Parameter learning method: Maximum likelihood.

    **Expert options**
    *   Select “Expert”.
    *   Missing values: Use only complete records.
    *   Independent test: Likelihood ratio.

7.  Compare the model fit metrics between these four models using the testing results.

8.  Select the champion model and justify this selection with the necessary evidence.

9.  Present the results of the champion model.

10. Evaluate the reliability and validity of the champion model.

11. Present the variable importance chart and interpret the results.
