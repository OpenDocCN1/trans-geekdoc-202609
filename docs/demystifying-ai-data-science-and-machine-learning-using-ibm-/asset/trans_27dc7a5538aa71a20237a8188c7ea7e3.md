

## 11. 价格敏感度节点关系

**价格敏感度**是**推荐**、**年均航班数**、**出行目的**、**性别**和**年龄**的父节点，但它是**航空公司会员等级**和**乘客舱位等级**的子节点。

如前所述，贝叶斯网络中预测变量对目标变量的影响，其解释方式与其他机器学习方法不同。关键输出是每个节点的条件概率表（CPT）。要在 SPSS Modeler 中访问 CPT，请导航到模型块窗口，从左侧面板选择一个节点，然后在右侧面板选择**条件概率**。特定节点的先验概率和后验概率总结如下。由于带有父节点的节点（如推荐、价格敏感度、出行目的、年均航班数、年龄和性别）的表格篇幅较长，为清晰起见，仅演示部分条件。这些变量的完整 CPT 显示在[表 16.9](#chapter16.xhtml#tbl16_9)、[表 16.10](#chapter16.xhtml#tbl16_10)、[表 16.11](#chapter16.xhtml#tbl16_11)、[表 16.12](#chapter16.xhtml#tbl16_12)、[表 16.13](#chapter16.xhtml#tbl16_13)、[表 16.14](#chapter16.xhtml#tbl16_14)、[表 16.15](#chapter16.xhtml#tbl16_15)、[表 16.16](#chapter16.xhtml#tbl16_16)、[表 16.17](#chapter16.xhtml#tbl16_17)、[表 16.18](#chapter16.xhtml#tbl16_18)、[表 16.19](#chapter16.xhtml#tbl16_19)中。
