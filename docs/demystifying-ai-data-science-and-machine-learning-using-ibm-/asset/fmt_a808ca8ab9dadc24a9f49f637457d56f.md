
# Interactive Chart Building in SPSS Modeler

I won’t go over all of the chart types again since we’ve already covered several in detail. What's important to note is that SPSS Modeler provides this graph tool in a very interactive manner. Once you select the desired chart type, simply identify the fields on the left panel, as required for that chart type, and click **Apply**. The chart will then appear in the middle panel. For example, [Figure 4.22](#chapter4.xhtml#fig4_22) shows how easily we can build a pie chart for the **Recommend the airline** field. The pie chart displays percentage values for added convenience. You can change the pie chart type and see the changes reflected instantly. Additionally, you can click on a specific class of the variable (such as **Yes**) to focus on data for that level, and the chart will automatically adjust. This tool is highly interactive and dynamic, making it great for visualization demonstrations.

## Limitations

However, this tool is not without its shortcomings:

1.  It doesn’t offer much customization for colors and fonts, so you’ll need to accept the default settings.
2.  Only pie charts display percentages, while other charts do not. If you need percentage values for other chart types, you’ll still have to calculate them in Excel.
3.  You can’t adjust the axis scales as you can with the other graph tools we’ve discussed.
4.  Since this tool runs on Java, working with very large datasets may take some time, and in some cases, the interface might freeze.

Despite these shortcomings, I still believe this hidden feature is a valuable tool for data visualization. You should definitely give it a try and determine when it's appropriate to use this tool to create charts for your data mining projects.

# Chapter Summary

Data exploration is a crucial step in the data mining process because it enables us to thoroughly understand the data before analysis. This exploration provides insights into the variables, patterns, and trends within the dataset, guiding our decisions on which variables and methods to use during the modeling phase.

We explored two primary methods of data exploration: **visualization** and **descriptive statistics**. Visualization is a widely used technique for examining large datasets because it produces outputs that are easy to interpret. Various types of graphs can be utilized to create visual representations of the data, including bar charts, histograms, box plots, pie charts, line charts, density plots, scatter plots, and multiplots.

SPSS Modeler offers several visualization tools that allow us to generate different types of charts, tailored to the variables and the analysis objectives. Beyond visualization, it's also essential to examine descriptive statistics, which provide detailed statistical information on all variables, such as frequency, missing values, minimum and maximum values, standard deviation, skewness, and kurtosis. These statistical insights help us determine the subsequent steps in the data mining process, particularly whether we need to impute missing values or transform the data.
