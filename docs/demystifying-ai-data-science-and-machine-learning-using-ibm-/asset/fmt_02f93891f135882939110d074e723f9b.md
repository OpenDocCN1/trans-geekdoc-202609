
# Linear Regression Estimation Results

For linear regression, the estimation results typically include the following information:

*   Intercept
*   Unstandardized regression coefficient (B)
*   Standard error for B
*   Standardized regression coefficients (beta)
*   t-value
*   Probability value (p-value)
*   95% confidence interval for B

To interpret the regression results correctly, we focus on the `probability value (p-value)`, `unstandardized coefficients`, and `standardized coefficients`. [Table 7.8](#chapter7.xhtml#tbl7_8) explains these terms and how to use them when interpreting regression results.

## Probability Value (p-Value)

The `p-value` is a statistical measure used to assess the significance of the estimated coefficients (also known as regression weights or beta values) of the predictors in a regression model. It indicates whether the relationship between each predictor and the target variable is statistically significant or if it could have occurred by chance. The threshold for determining statistical significance is called the `significance level (alpha)`, with the most commonly used significance level being 0.05 (5%).

223. If the p-value is less than or equal to the significance level (`p ≤ α`), it suggests that the coefficient is statistically significant. For example, in a linear regression model where the target variable is students’ SAT scores, suppose the analysis reveals that `GPA` and `family income` have p-values lower than 0.05. This would indicate that these two predictors are statistically significant and have a meaningful impact on predicting SAT scores.

## Unstandardized Regression Coefficients (B)

After identifying significant predictors, the next step is to explain their relationships with the target variable using `unstandardized regression coefficients (B)`. Unstandardized coefficients quantify the relationship between each predictor and the target variable in their original units of measurement.

In our example of predicting SAT scores, suppose the regression results show unstandardized coefficients of 120 for `GPA` and 0.01 for `family income`, with an intercept of 105. The regression equation would be as follows:

```
SAT score = 105 + 120 × GPA + 0.01 × Family income
```

This equation includes the intercept and unstandardized coefficients. It suggests that `GPA` and `family income` are significant predictors of SAT scores, both positively correlated with the SAT score. These predictors represent the student's academic performance (via GPA) and the family's financial resources for education and SAT tutoring (via income).

Using this equation, we can predict a student's SAT score based on known values of these predictors. More importantly, we can interpret how changes in each predictor affect the target variable. For example, with a coefficient of 120 for GPA, a one-point increase in GPA results in a 120-point increase in the SAT score. Similarly, an increase in family income by $1 results in a 0.01-point increase in SAT scores. In practical terms, an increase of $10,000 in family income would raise the SAT score by 100 points (`0.01 × 10,000 = 100`).

224. Note that the error term is not included in this equation because we have already used it to evaluate model fit. The error represents the difference between predicted and actual SAT scores, and since our model fit is good, the error is considered acceptable. At this stage, the focus is on using the equation to predict changes in SAT scores based on the changes in significant predictors, making the error term less relevant for interpretation.

## Standardized Regression Coefficients (Beta)

One thing to notice about unstandardized coefficients is that they depend on the unit of measurement of the predictor, making them scale-dependent. For example, while GPA may have a higher regression coefficient than family income, we can’t directly compare their impact because GPA is measured in points and income in USD. To make meaningful comparisons, we use `standardized coefficients`.

![](images/ufig7_17.jpg)

A `standardized regression coefficient` measures the relationship between a predictor and the target variable after both have been standardized to a common scale. Standardized coefficients range from 0 to 1 and are expressed in terms of standard deviations, making them scale-independent and directly comparable across predictors.

For instance, if the standardized coefficients for GPA and family income are 0.68 and 0.34, respectively, we can conclude that GPA has twice the effect size of family income in predicting SAT scores. In this case, GPA is more important than family income by a factor of two.

To identify and rank important predictors, it is recommended to use `standardized coefficients` and rank them from highest to lowest. In data mining, a more generic term used to capture the significance of predictors is `“relative importance.”`
