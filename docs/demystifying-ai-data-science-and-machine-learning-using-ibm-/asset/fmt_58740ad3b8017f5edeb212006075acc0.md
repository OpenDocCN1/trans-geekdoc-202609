
# Stepwise Methods in Data Mining

One important point to note is that all three methods are forms of the stepwise method, an iterative variable selection process used in data mining to identify the most relevant subset of variables for a predictive model. To avoid confusion, I refer to them as `forward stepwise`, `backward stepwise`, and `adaptive stepwise`. Each method results in multiple models, with the final one typically being the best. Below, I describe the steps for each method, along with corresponding diagrams ([Figure 7.2](#chapter7.xhtml#fig7_2), [Figure 7.3](#chapter7.xhtml#fig7_3), [Figure 7.4](#chapter7.xhtml#fig7_4)).

![FIGURE 7.2 Forward stepwise method. Return to text.](images/fig7_2.jpg)

## Forward Stepwise ([Figure 7.2](#chapter7.xhtml#fig7_2))

1.  The process begins with a model without any predictors (null model).
2.  The most significant variables are added to the model, one after the other. Significant variables are the ones significantly associated with the target variable. Typically, the most significant predictor is the one with the smallest p-value or provides the highest increase in R².
3.  The selection will stop when all variables under consideration are added or a pre-determined stopping rule is met.

## Backward Stepwise ([Figure 7.3](#chapter7.xhtml#fig7_3))

![FIGURE 7.3 Backward stepwise method. Return to text.](images/fig7_3.jpg)

**FIGURE 7.3** Backward stepwise method. [Return to text.](#chapter7.xhtml#b7fig7_3)

1.  The process begins with a model that includes all predictors (full model).
2.  The least significant variables are removed from the model, one after the other.
3.  The selection will stop when no variables are left or a pre-determined stopping rule is met.

## Adaptive Stepwise ([Figure 7.4](#chapter7.xhtml#fig7_4))

This method is similar to forward stepwise but with one key difference: After adding an additional variable to the model, it can remove a variable currently in the model but no longer significant. In other words, it is adaptive. This adaptability allows the model to evolve dynamically, and for this reason, in some cases, `adaptive stepwise` is also known as `bidirectional stepwise`.

1.  The process begins with a model without any predictors (null model).
2.  The most significant variables are added to the model, one after the other.
3.  After each addition, any variables already in the model that are no longer significant will be removed.
4.  The selection will stop when all variables under consideration are added or a pre-determined stopping rule is met.

![FIGURE 7.4 Adaptive stepwise method. Return to text.](images/fig7_4.jpg)

**FIGURE 7.4** Adaptive stepwise method. [Return to text.](#chapter7.xhtml#b7fig7_4)

The important question is: **Which stepwise method should we use?** [Table 7.6](#chapter7.xhtml#tbl7_6) outlines scenarios where each method is appropriate. As discussed earlier, `adaptive stepwise` seems to be the most capable of selecting predictors that best predict the target variable. Unlike forward and backward stepwise methods, which follow a linear and sequential process, adaptive stepwise allows for the dynamic addition and removal of variables, resulting in the best model fit. In other words, it can select the best combination of predictors for model-fitting purposes. For this reason, adaptive stepwise is generally recommended for data mining. However, it has a few disadvantages, such as requiring more computing time and, in some cases, leading to overfitting. To mitigate this, cross-validation with sub-samples can be used to evaluate predictive power and avoid overfitting.

![](images/ufig7_14.jpg)

**TABLE 7.6** When to Use Which Stepwise Method? [Return to text.](#chapter7.xhtml#b7tbl7_6)

| When to Use Forward Stepwise? | When to Use Backward Stepwise? | When to Use Adaptive Stepwise? |
| --- | --- | --- |
| **Large number of predictors**<br>When dealing with a large number of potential predictors, forward stepwise is computationally more efficient, as it starts with an empty model and incrementally adds variables. | **Multicollinearity concerns**<br>If there are concerns about multicollinearity (high correlation) between predictors, backward stepwise helps identify and remove redundant predictors. | **Exhaustive search**<br>Adaptive stepwise allows for an exhaustive search of significant predictors without becoming overly computationally intensive. |
| **Exploratory analysis**<br>Forward stepwise is a good starting point for exploratory analysis, as it allows us to gradually build a model by adding variables that have a significant impact on the target variable. | **Well-founded theoretical basis**<br>When there is a strong theoretical basis or domain knowledge for what predictors are more important than others, backward stepwise is useful in eliminating less significant variables from the model. | **Data exploration and model building**<br>Adaptive stepwise is useful at the initial stages of data exploration and model building as it allows for a comprehensive examination of various predictor subsets and their impact on the model. |
| **No prior knowledge**<br>When there is no strong prior knowledge or theory about which predictors are likely to be relevant, forward stepwise helps identify potentially important predictors. | **Complex models**<br>Backward stepwise is particularly useful in complex models, where removing less relevant variables can improve the model's interpretability and generalization. | **Model fit improvement**<br>Since adaptive stepwise considers all possible combinations of predictors, it provides more robust results and improves the model fit. |
| | | **Variable interaction analysis**<br>When interactions between predictors are essential, adaptive stepwise helps identify relevant interaction terms that might not be captured by individual forward or backward selection. |

# How to Read and Understand the Regression Equation and Results?

After running a regression analysis, the first step is to evaluate the model fit using the recommended metrics, such as `R²`, `F-test`, `RMSE`, `MAPE`, `RSE`, `EP`, the `actual vs. predicted chart`, and the `residuals vs. predicted chart`. If all criteria are met and indicate a good model fit, the next step is to report and interpret the regression outputs. But how do we make sense of those outputs, and what conclusions can we draw?

![](images/ufig7_16.jpg)

These are common questions when conducting any data analysis, and they are even more crucial in data mining, where models often include a large number of predictors.
