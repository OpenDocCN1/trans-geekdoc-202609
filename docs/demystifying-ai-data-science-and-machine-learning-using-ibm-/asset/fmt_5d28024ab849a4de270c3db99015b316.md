
Now that we understand the differences between correlation and causation, it's important to know how they are tested. There are distinct approaches to calculating correlation and causation.

538.

#### Testing Correlation

![](images/ufig16_2.jpg)

The correlation between two variables, `X` and `Y`, can be determined by calculating the correlation coefficient. A positive correlation means that if `X` increases, `Y` also increases, while a negative correlation means that if `X` increases, `Y` decreases. The value of the correlation coefficient indicates the effect size or the strength of the correlation between the two variables. While correlation is commonly used in prediction, it is important to note that it cannot be used to infer causation. Additionally, data mining methods based on correlation are prone to overfitting, particularly with large sample sizes. The larger the sample, the more likely relationships between variables will appear statistically significant, even if they do not reflect causal connections.

#### Testing Causation

Causation is much harder to test because it requires isolating the variables of interest within a controlled environment. Causation occurs when variable `X` directly causes `Y` to occur. One common approach to testing causality is through probabilistic analysis, specifically by using conditional probabilities.

Unlike correlation, a probabilistic relationship describes the association between two or more variables in terms of uncertainty, and it is expressed using probabilities. A probabilistic relationship between variables `X` and `Y` can be determined using **Bayes' theorem**. This theorem describes the probability of event `Y` occurring given event `X`, based on the individual probabilities of `X` and `Y`, and the probability of observing `X` if `Y` is true. The formula below presents this probabilistic relationship. In this equation, the probabilistic relationship between `X` and `Y` is represented by the conditional probability `P(Y|X)`, which takes into account the prior probabilities of `Y` and `X`, and the likelihood of `X` given `Y`.

```
P(Y|X) = P(X|Y) * P(Y) / P(X)
```

where

*   `P(Y|X)` represents the conditional probability of event `Y` happening, given that event `X` has already occurred. In other words, it tells us the chance of `Y` occurring when we know that `X` has happened.
*   `P(X|Y)` is the conditional probability of event `X` happening, given that event `Y` has already occurred. It tells us the chance of `X` occurring when we know that `Y` has happened.
*   `P(Y)` is the probability of event `Y` happening, without considering any other events. It represents the overall chance of `Y` occurring.
*   `P(X)` is the probability of event `X` happening, without considering any other events. It represents the overall chance of `X` occurring.

### Definition of Bayesian Network

![](images/ufig16_3.jpg)

A **Bayesian network**, also known as a Bayesian belief network or a probabilistic graphical model, is a powerful and popular method for representing and reasoning about uncertainty and probabilistic relationships between variables. It is named after Thomas Bayes, an 18th-century statistician and philosopher, and represents a set of variables and their conditional dependencies through a `DAG`.

539. A Bayesian network consists of two main components: nodes and edges. Nodes represent variables of interest while edges represent probabilistic dependencies between those variables. The nodes can be either discrete or continuous, and they are connected by directed edges that indicate cause-and-effect relationships or conditional dependencies between the variables.

The structure of a Bayesian network is typically represented by a `DAG`, where each node corresponds to a variable, and the edges (or arcs) capture probabilistic dependencies. These edges represent conditional probabilities, showing how one variable influences another. [Figure 16.2](#chapter16.xhtml#fig16_2) illustrates a typical Bayesian network structure.

Conditional dependencies in a Bayesian network are defined using conditional probability tables (`CPTs`). Each node's `CPT` describes the probability distribution of that node, given its parent nodes in the graph. These `CPTs` allow for the quantification of uncertain relationships and enable probabilistic inference to be propagated throughout the network.
