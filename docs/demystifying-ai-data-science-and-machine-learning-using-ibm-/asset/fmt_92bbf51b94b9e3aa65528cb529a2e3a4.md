Interpreting the rotated component matrix involves identifying which variables have high loadings on each component. Variables with high loadings are strongly associated with that component and help us interpret the underlying dimension or factor represented by it. In this case, the results indicate that flight distance and flight time have high loadings on Component 1, suggesting that these fields collectively measure an underlying factor related to flight duration. Similarly, arrival delay and departure delay have high loadings on Component 2, representing an underlying factor related to flight delays. These two components are logical, as the variables within each component are highly correlated and measure the same underlying construct.

We can apply the same interpretation to Component 3, which includes age, number of flights, percentage of flights with other airlines, and number of other loyalty cards. These variables all relate to flying experience, forming a coherent component.

However, issues arise when reviewing Components 4 and 5. For example, spending on eating and drinking at the airport is loaded onto Component 4, while shopping amount at the airport is loaded onto Component 5, despite the expectation that they would be highly correlated and grouped in the same component. Additionally, the number of years of flying is associated with Component 5 but does not seem to fit well with shopping amount at the airport. These inconsistencies suggest that further adjustments may be needed to improve the component structure and interpretability.

The concerns regarding the use of five components raise an important question: Is this the best decision for PCA? Since SPSS Modeler extracted five components based on the condition that eigenvalues are greater than 1, it would be prudent to explore an alternative method for determining the optimal number of components. As described earlier, a scree plot is commonly used for this purpose, based on the "elbow" of the plot.

Since SPSS Modeler does not provide a scree plot in the PCA/Factor node output, I generated one in Excel using the eigenvalues and number of components. [Figure 12.4](#chapter12.xhtml#fig12_4) presents this scree plot. However, identifying the exact elbow from this plot is somewhat challenging.

As you may recall, the elbow point on a scree plot indicates where the curve starts to flatten, suggesting that adding more components beyond this point does not significantly enhance the explanation of the variance in the data. In this case, it appears the elbow may occur around four components, as the slope becomes less steep at this point. However, the plot's shape introduces some ambiguity in identifying the elbow.

To identify the elbow more clearly, I reconstructed the scree plot using **proportional eigenvalues**. As mentioned earlier, proportional eigenvalues are calculated by dividing the percentage of variance explained by the cumulative percentage of variance explained for each component.
