## Steps to Compare Logistic Models 1 and 2

1.  Start with the stream `Airline_Regression` that we created earlier.
2.  Detach the model nugget for **Logistic 2** from the **Type** node. To do this, hover over the connector, right-click, and select **Delete Connection**.
3.  Connect the model nugget for **Logistic 1** to the model nugget for **Logistic 2**.
4.  Add a **Filter** node to the stream and connect it to the model nugget for **Logistic 2**.

6.  In the settings, change `$L-Recommend the airline` to **Logistic 1**, and change `$L1-Recommend the airline` to **Logistic 2**.

## Conclusion

This approach offers an alternative method to compare metrics among models using a single **Analysis** node. However, it has several limitations:

*   It requires modifications to the stream, which prevents reconfiguring the models within the stream.
*   The restriction on identical field names makes it difficult to compare models that use transformed data.
*   Some important metrics still need to be calculated manually based on each model's confusion matrix.

My recommendation is to use separate **Analysis** nodes for each model and extract the necessary metrics. In cases where field names are identical across models, this method can still be useful for generating ROC and Lift charts for multiple models.

# Chapter Summary

Regression is one of the most widely used machine learning algorithms due to its simplicity in implementation and ease of interpreting results. Regression methods allow us to predict the value of a target variable based on multiple predictors. Linear regression is an association model used for continuous target variables while logistic regression is a classification model used for binary target variables. The key characteristic of regression methods is the assumption of a linear relationship. In linear regression, the equation represents a linear relationship between the target variable and the predictors, whereas in logistic regression, the equation represents a linear relationship between the logit value of the target variable and the predictors.

Regression analysis is widely applied across fields such as economics, finance, healthcare, aviation, and social sciences to make predictions and derive insights from data.

This chapter covers the fundamental concepts and techniques of regression, including regression equations, estimation methods, model selection, assumptions, model fit metrics, and interpreting outputs. We also demonstrate how to perform both linear and logistic regressions on actual datasets using SPSS Modeler. This chapter provides detailed, hands-on examples of model training, result presentation, model comparison, champion model selection, and regression equation interpretation.

While regression offers numerous advantages, such as providing a straightforward approach to making predictions and being interpretable, it also has limitations. Regression assumes a linear relationship between variables, and violations of this assumption may lead to inaccurate predictions. Additionally, regression models are sensitive to outliers and missing data, which can affect model performance.

Overall, regression is a valuable tool in data mining for understanding and predicting relationships between variables, but it is crucial to carefully assess its assumptions and limitations to ensure reliable results.
