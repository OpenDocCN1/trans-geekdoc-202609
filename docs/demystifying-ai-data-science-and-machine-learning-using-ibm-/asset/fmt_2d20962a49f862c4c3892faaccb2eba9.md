## Classification and Regression Tree (CART)

CART is a popular decision tree method developed by [Breiman (1984)](#bibab10c.xhtml#refbib_13). For more detailed information, you can refer to their book, *Classification and Regression Trees*. In this explanation, I will skip the mathematical details and focus on practical applications.

**CART is a binary tree**, meaning that it repeatedly splits a parent node into two child nodes. This process can be used for both categorical (classification) and continuous (regression) target variables. CART is widely employed in machine learning due to its simplicity, interpretability, and effectiveness.

### Binary Recursive Splitting

CART uses a binary recursive splitting approach. At each node of the tree, the algorithm selects a feature and a threshold to split the data into two subsets. For categorical variables, CART performs multi-way splits by creating branches for each category, while for continuous variables, it identifies a threshold for splitting.

#### Splitting Criteria

*   For **classification models**, CART typically uses **Gini impurity** as the splitting criterion. Gini impurity measures the likelihood of incorrectly classifying a randomly chosen instance. The algorithm selects splits that minimize impurity.
*   For **regression models**, CART uses **variance reduction** as the splitting criterion, with **least squared deviation (LSD)** being the common measure for variance. The goal is to find splits that reduce variance within the resulting subsets.

Most data mining software integrates both classification and regression capabilities in their CART implementation, so you don't need to manually separate the two tree types.

### Recursive Tree Building

The process of building the tree is recursive. After the initial split, the algorithm applies the same procedure to each resulting subset, continuing to split nodes until a stopping criterion is reached. Common stopping criteria include the following:

*   A minimum number of instances in a leaf node.
*   A maximum tree depth.
*   No further improvement in impurity or variance reduction.

### Pruning

Once the tree is fully grown, it may be pruned to improve generalization and avoid overfitting. Pruning involves removing branches that do not significantly enhance predictive accuracy. CART typically uses cost-complexity pruning, which balances the complexity of the tree with its accuracy on a validation set.

### Handling Missing Values

CART is capable of handling missing data. When a feature contains missing values, the algorithm distributes instances with missing data among child nodes based on the available information from other features.

## Chi-Squared Automatic Interaction Detection (CHAID)

![](images/ufig8_13.jpg)

**CHAID** was developed by Kass in 1980. This method is based on the chi-square statistic, a non-parametric test used to examine differences between categorical variables. CHAID aims to identify significant relationships between variables by applying chi-squared tests for independence. The test produces a probability value (p-value) between 0 and 1. A chi-square value closer to 0 indicates a significant difference between the two variables while a value closer to 1 indicates no significant difference. Unlike CART, CHAID can split a parent node into more than two child nodes, making it useful for creating multi-way splits.

### Splitting Rule

At each split, CHAID assesses the statistical significance of the relationships between predictor variables and the target variable using chi-squared tests. The algorithm seeks to create homogeneous groups, where the target variable is similar within each branch of the tree.

### Handling Continuous and Categorical Variables

CHAID is primarily designed for categorical variables. While it works for both association and classification models, it requires categorical predictors, either ordinal or nominal. However, many software implementations of CHAID can accept continuous variables by automatically grouping values into ranges before growing the tree. Since Kass' original algorithm, CHAID has evolved to handle continuous target variables by using the p-value from an F-test. A key distinction from CART is that CHAID can split a node into two or more child nodes, as illustrated in [Figure 8.4](#chapter8.xhtml#fig8_4), which depicts a multi-way tree.

### Initial Split

CHAID starts with the entire dataset, selecting the predictor variable that has the most significant association with the target variable based on a chi-squared test for independence. The dataset is then split into subsets according to the chosen variable and its categories.

### Recursive Splitting

The algorithm recursively splits each subset into smaller subsets by selecting the variables and categories that maximize the statistical association with the target variable. The process continues until a stopping criterion is met, such as reaching a maximum tree depth or having a minimum number of instances in a leaf node.

### Handling Multi-Way Splits

CHAID can perform multi-way splits for categorical variables with more than two categories, creating branches for each category. This ability makes it well-suited for datasets with multiple categorical variables.

### Merge Procedure for Pruning

After the tree is constructed, CHAID applies a merge procedure to prune the tree and simplify its structure. This process merges adjacent categories or nodes that do not significantly differ in terms of the target variable. The merge procedure helps prevent overfitting and produces a more interpretable final tree.

### Handling Missing Values

CHAID handles missing values using surrogate splits. Missing values are treated as separate categories, and if a variable has missing data, CHAID identifies surrogate variables—alternative predictors that closely mimic the behavior of the primary variable. These surrogates act as backup rules when making decisions for instances with missing values.

## C5.0 Tree

![](images/ufig8_14.jpg)

**C5.0** is a powerful decision tree algorithm developed by Ross Quinlan in 1993. Primarily designed for classification models, C5.0 can also handle association models. The algorithm uses the information gain or gain ratio criterion to select the best attributes for node splitting, creating a tree structure that optimally classifies or predicts the target variable. C5.0 is known for its efficiency, scalability, and ability to handle both categorical and continuous variables. Additionally, it incorporates advanced pruning techniques to improve model interpretability and prevent overfitting, making it a widely used and effective tool for predictive modeling. It is considered an improvement over its predecessor, C4.5, offering faster performance and greater flexibility.
