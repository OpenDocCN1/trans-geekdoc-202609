
Another reason researchers prefer treating Likert scale variables as “interval” is that it simplifies result interpretation. Since Likert scale data are coded numerically (e.g., `1–5` or `1–7`), the statistical outputs—such as correlation coefficients, model fit, and explained variance—are easier to interpret as metric values. If we were to treat these variables as “ordinal,” the interpretation process would resemble that used for nominal variables, which is more complex because the responses are non-metric. [Chapter 7](#chapter7.xhtml) provides specific examples of this when discussing logistic regression. In fact, ordinal regression functions similarly to logistic or multinomial regression.

Ultimately, how we treat the Likert scale depends on the study's purpose. My rule of thumb is to treat Likert scale variables as “interval” unless there is a compelling reason to do otherwise and a clear plan for data analysis and result interpretation. In such cases, it's essential to provide evidence that the gaps between levels are equal and test the assumptions required for the parametric methods used.

### Supervised vs. Unsupervised Learning

Machine learning algorithms can be broadly categorized into “supervised learning” and “unsupervised learning.” “Supervised learning” is best suited for structured data and requires a target variable. Models are developed to predict this target variable based on numerous predictors. In contrast, “unsupervised learning” is more appropriate for less structured data, where there is no specific target variable; instead, all variables are treated as input variables. The primary goal of unsupervised learning is to detect the intrinsic structure of the data. The rule of thumb for deciding whether to use supervised or unsupervised learning is to check if your dataset has a target variable and whether your research aims to predict it.

![](images/ufig2_16.jpg)![](images/ufig2_17.jpg)

Typically, there are more supervised learning methods available than unsupervised ones. Examples of supervised learning methods include regression and logistic regression, decision trees, random forests, gradient boosting, memory-based reasoning, support vector machines, neural networks, and Bayesian networks. The appropriate method for your research depends on the study's purpose and the scale of the target variable. Methods like regression and logistic regression share foundations with traditional statistical techniques, but in data mining, they are applied to much larger datasets with less stringent assumptions, such as the requirement for normal distributions. It's also worth noting that random forest and gradient boosting are ensemble methods based on decision trees, where multiple trees are constructed to improve predictive accuracy. We’ll examine these machine learning methods and their characteristics in depth later. It's common practice to use multiple methods to build various predictive models and compare them to identify the best-performing model.

Examples of unsupervised learning algorithms include cluster analysis, principal component analysis, and multidimensional scaling. These methods group cases based on similarity or detect underlying factors in the data. Like their supervised counterparts, the foundations of these methods are rooted in multivariate statistics, but they are applied to much larger datasets in data mining.
