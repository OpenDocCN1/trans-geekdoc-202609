## Types Of Clustering Algorithms

![](images/ufig13_9.jpg)

Two common types of clustering algorithms are **hierarchical clustering** and **partitioning clustering**. In this section, we discuss these algorithms at a high level, avoiding complex mathematical expressions. Most data mining software applications incorporate these algorithms into their interfaces, allowing users to perform clustering analysis without setting up intricate configurations.

### Hierarchical Clustering

Hierarchical clustering is a clustering algorithm that organizes data points into a tree-like structure known as a dendrogram. The process begins by assigning each data point to its own cluster. Then, the algorithm successively merges the closest clusters based on their similarity. This merging continues until all data points are combined into a single cluster or until a specified number of clusters is reached. Hierarchical clustering can be performed in two ways:

*   **Agglomerative** (bottom-up approach): Each data point starts as its own cluster, and clusters are merged step by step.
*   **Divisive** (top-down approach): All data points start in one cluster, and the cluster is split recursively.

### Partitioning Clustering

Partitioning clustering divides data points into a predefined number of clusters. The primary objective is to minimize the distance between data points within each cluster while maximizing the distance between different clusters. The most commonly used partitioning clustering algorithm is **k-means**, which assigns data points to clusters by minimizing the within-cluster variance.

### Dendrogram

The dendrogram is a key element of hierarchical clustering. It visually represents the process in which data points are incrementally merged into clusters based on their similarity. Each step in the dendrogram indicates the formation of a new cluster, either by combining two individual data points or merging existing clusters.

To help clarify how a dendrogram functions and how it can be interpreted, let's consider a simple example with six data points: A, B, C, D, E, and F. Using hierarchical clustering, we begin by treating each data point as its own cluster. We then progressively merge the closest clusters, determined by a distance metric (e.g., **Euclidean distance**), until all data points are combined into a single cluster. [Figure 13.4](#chapter13.xhtml#fig13_4) presents the dendrogram for this example.
