### What is the Linear Node in SPSS Modeler?

In addition to the Regression node, which is commonly used for performing linear regression in a traditional way, SPSS Modeler offers another node called `Linear`. The Linear node is an automatic linear modeling tool that handles all the steps in the linear regression process automatically. This includes data preparation, transformation, model selection, ensemble construction, and result presentation. Essentially, once the measurement scales and roles for the fields in the data are defined, the Linear node takes over the entire data mining process. However, since most decisions are made automatically by the software, the researcher has limited control and customization options.

For demonstration purposes, I will use the Linear node to run a linear regression analysis on the Boston housing dataset and compare the results with the four previously created regression models.

#### Description and Configuration of Regression 5

*   **Description**: Automatic linear modeling (data preparation and model configuration are handled automatically by the software).

*   **Configurations**:

    *   **Objective**: Create a standard model (we are not constructing ensembles here, as this topic will be covered later in [Chapter 10](#chapter10.xhtml)).

    *   **Basis**: Automatically prepare the data, including adjustment of measurement levels, handling of outliers, and treatment of missing values.

    *   **Model selection**: Forward stepwise.

    *   **Criteria for entry/removal**: Information criterion (AICC).

#### Steps to Add and Set Up the Linear Node

1.  Continue with the stream that contains the four previous regression models.

2.  From the **Modeling** group, add a **Linear** node to the stream and connect it to the **Type** node (the one following the data source). Name it **Regression 5**. Open the **Linear** node settings.

    ![](images/ufig7_36.jpg)

3.  Accept all the default settings of the node. Verify that the configurations are as follows:

    *   **Objective**: Create a standard model.

    *   **Basis**: Automatically prepare the data.

    *   **Model selection**: Forward stepwise.

    *   **Criteria for entry/removal**: Information criterion (AICC).

4.  Click Apply and then Run the node.

5.  Once the run is complete, a model nugget labeled **Regression 5** will be added to the stream.

6.  Add an **Analysis** node to the stream and connect it to the model nugget **Regression 5**. Open the **Analysis** node settings.

7.  Under the **Analysis** tab, select the following options: **Performance evaluation**, **Evaluation metric**, **Confidence figures**, and **Separate by partition**.

8.  Click Apply and then Run.

As you can see, the process is simple, easy, quick, and seamless, requiring no prior understanding of the regression algorithm. The output from the Analysis node provides metrics such as the MAE, mean error, standard error, and correlation (as described earlier). To access additional metrics, you need to open the model nugget.

You’ll notice that this output differs significantly from the Regression node's output. First, you still receive some overall results, including the adjusted R² and the predictor importance chart. Additionally, the output automatically generates the predicted vs. observed chart (similar to the actual vs. predicted chart) without requiring any extra steps.

However, unlike the Regression node, this output does not include an Advanced tab, which would normally provide the model summary, analysis of variance (ANOVA), and coefficients. As a result, we don’t have access to metrics such as the `R²` and the `F-test`. To compensate, I added the `MAE` and used the `adjusted R²` as the EP to compare this model with the four other models we created earlier (refer to [Table 7.16](#chapter7.xhtml#tbl7_16)).

Unfortunately, the Linear node does not provide detailed regression outputs, such as the model summary, ANOVA, or coefficients. As a result, we cannot observe the number of steps in the stepwise process nor the changes in R², F-tests, or coefficients for significant predictors. Keep in mind that the Linear node is designed to perform linear regression analysis quickly and automatically, which means it does not guarantee the production of a well-fitting model every time.

For these reasons, I recommend using the Regression node to gain more control and customization over the modeling process. The Regression node allows for adjustments to the model configuration, offering greater flexibility in achieving a good fit. However, the Linear node can be useful for running a preliminary regression analysis, providing quick insights into your model and data. Based on these initial results, you can make informed decisions regarding data modifications and modeling plans to improve your predictive model.

### Logistic Regression Equation

Logistic regression is used with a binary or nominal target variable. The traditional logistic regression equation is as follows:

