In contrast, divisive clustering starts with all data points in one cluster and then splits them recursively into smaller clusters. At each step, the algorithm identifies the most dissimilar cluster and divides it into two smaller clusters, again based on a selected distance metric. This process is repeated until each data point is isolated in its own cluster (see [Figure 13.6](#chapter13.xhtml#fig13_6)).

The choice of distance measure is critical in hierarchical clustering, as it directly influences how clusters are formed. The linkage criterion determines how the distance between clusters is calculated during the merging or splitting process. Common linkage methods include single-linkage, complete-linkage, and average-linkage. We will delve into these distance measures later in this chapter.

Hierarchical clustering offers several advantages. It reveals the inherent structure and relationships within the data by creating a hierarchy of clusters. The dendrogram serves as a visual representation of the clustering process, making it easier to interpret. Additionally, hierarchical clustering can handle various types of data, including numerical, categorical, and binary.

However, hierarchical clustering has its limitations. It can be computationally intensive, particularly with large datasets, due to the need for pairwise distance calculations. Furthermore, the selection of distance metric and linkage criterion, as well as the interpretation of the resulting dendrogram, can vary depending on the specific characteristics of the data and the objectives of the analysis.

## Partitioning Clustering

![Partitioning Clustering](images/ufig13_11.jpg)

Partitioning clustering, also known as partitional clustering, is a type of clustering algorithm that aims to partition a dataset into non-overlapping clusters. Unlike hierarchical clustering, which creates a hierarchy of clusters, partitioning clustering directly assigns each data point to a specific cluster. The goal is to optimize a predefined objective function, such as minimizing the intra-cluster distance and maximizing the inter-cluster distance.

One of the most well-known partitioning clustering algorithms is k-means. The k-means method partitions the data into K distinct clusters by iteratively updating the cluster centroids and assigning data points to the nearest centroid. The algorithm works iteratively to assign data points to clusters and adjust the cluster centroids until convergence. The objective is to minimize the sum of squared distances between data points and their respective cluster centroids.

### Steps in K-Means Clustering

1.  **Initialization**: Choose the number of clusters, `k`, and randomly initialize `k` centroids within the data range.

2.  **Assignment**: Assign each data point to the nearest centroid based on a distance measure, commonly Euclidean distance. This step creates `k` clusters.

3.  **Update**: Recalculate the centroid for each cluster by taking the mean of all data points assigned to that cluster.

4.  **Iteration**: Repeat steps 2 and 3 until convergence. Convergence occurs when the centroids no longer change significantly or when a predetermined maximum number of iterations is reached.

5.  **Result**: Once the algorithm converges, each data point belongs to a particular cluster, and the cluster centroids represent the center of each cluster.

K-means is an efficient and straightforward algorithm, but its success depends on the initial selection of centroids and the number of clusters (`k`). The number of clusters is often determined using domain knowledge or techniques like the elbow method or silhouette analysis to select the optimal number of clusters. Multiple runs of the algorithm with different initializations may be required, and the result with the lowest error is typically chosen.

### Advantages of K-Means

*   K-means is relatively efficient and can scale well with large datasets.
*   It works well when clusters have a spherical shape and similar sizes.
*   The algorithm is easy to implement and interpret.

### Limitations of K-Means

*   It assumes clusters are spherical and mutually exclusive, which may not always be the case in real-world data.
*   It is sensitive to the initial placement of centroids, which can lead to different clustering results.
*   The choice of `K`, the number of clusters, can be arbitrary if not properly determined using a suitable method.

## Two-Step Cluster Analysis

![Two-Step Cluster Analysis](images/ufig13_12.jpg)

Two-step cluster analysis is a hybrid approach that combines elements of hierarchical clustering and k-means clustering. This method is particularly useful for analyzing large datasets or datasets that contain both continuous and categorical variables, making it versatile for real-world applications. The algorithm works in two main stages, as described below:

### Process of Two-Step Cluster Analysis

*   **Pre-clustering**

    In the first step, a hierarchical clustering method (often agglomerative clustering) is used to generate preliminary clusters. This step helps in identifying potential clusters by reducing the computational load, especially when dealing with large datasets. By creating pre-clusters, the process becomes more efficient.

*   **Two-step clustering**

    In the second step, k-means clustering is applied to the pre-clustered data. This step assigns data points to clusters based on their proximity to the centroids. As in standard k-means clustering, the centroids are updated iteratively until the clusters stabilize, ensuring convergence.

### Advantages of Two-Step Cluster Analysis

*   **Suitable for large datasets**

    This method is well-suited for handling large datasets, making it efficient and scalable compared to traditional clustering methods.

*   **Automatic determination of the number of clusters**

    One of the main benefits of two-step cluster analysis is its ability to automatically determine the optimal number of clusters based on statistical criteria, saving the user from having to manually specify the number of clusters.

*   **Handles mixed data types**

    Two-step cluster analysis can accommodate both categorical and continuous variables, providing flexibility for datasets with mixed data types.

### Limitations of Two-Step Cluster Analysis

*   **Sensitivity to outliers**

    Like many clustering algorithms, two-step cluster analysis can be sensitive to outliers, which may distort the results and lead to incorrect cluster assignments.

*   **Relies on predefined distance measures**

    The algorithm assumes that the similarity between data points can be adequately measured using predefined distance measures (e.g., Euclidean or Manhattan), which may not always capture the true relationships in the data.

*   **Lack of interpretability**

    The clusters generated may not always have clear or intuitive meanings, requiring further analysis and validation to understand the significance of each cluster.

In conclusion, two-step cluster analysis is a valuable tool in data mining, especially when dealing with large datasets or mixed data types. Its ability to automatically determine the optimal number of clusters enhances its efficiency, and its flexibility in handling various variable types makes it applicable across diverse domains. However, like all clustering methods, careful attention should be given to outliers, and further interpretation is often necessary to fully understand the clusters.
