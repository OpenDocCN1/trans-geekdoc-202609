
# Key Findings Summary

## Target Variable Distribution
The frequency and percentage of the two levels of the target variable indicate a relatively balanced dataset, with 52.46% of the data being “Yes” (recommend) and 47.54% being “No” (not recommend).

## Missing Values
There are no missing values in the categorical variables. However, among the continuous variables, there are missing values for three variables: `Arrival delay time`, `Departure delay time`, and `Flight time`. While other continuous variables do not seem to have missing values, a closer look at the `Price sensitivity` variable reveals something unusual. This variable has a minimum value of zero, which is unexpected because `Price sensitivity` is measured on a Likert scale (typically ranging from 1 to 5). Therefore, a value of zero indicates a missing value, and we will need to recode this value as missing. Handling these missing values will be discussed in [Chapter 5](#chapter5.xhtml).

## Descriptive Statistics for Categorical Variables
The dataset includes variables with varying numbers of levels: three variables with two levels, two variables with three levels, one variable with four levels, and two variables with 52 levels (representing the 52 U.S. states).

## Descriptive Statistics for Continuous Variables
[Table 4.8](#chapter4.xhtml#tbl4_8) presents key statistics such as field name, minimum, maximum, mean, median, standard deviation, skewness, and kurtosis. These are standard descriptive statistics that most statistical software applications generate. It is noteworthy that only a few variables have distributions close to normal, with skewness and kurtosis values near zero. These include `Age`, `Number of flights per year`, `Number of loyalty cards`, `Price sensitivity`, and `Number of years flying`. Variables like `Flight distance` and `Flight time` are not perfectly normal but are close. Conversely, other variables exhibit high skewness and kurtosis values, indicating that their distributions are skewed and far from normal. Depending on the machine learning methods chosen for modeling, we may need to consider data normalization and transformation.

# Hidden Feature in SPSS Modeler— Interactive Graph Tool

![](images/ufig4_38.jpg)

In the previous sections, we’ve explored various graph tools available in SPSS Modeler under the **Graphs** group in the **Node Pallet**. While I focused on the most commonly used tools, it's worth taking the time to practice with all of them. You may discover ways to effectively leverage these tools to create meaningful visualizations for your data. As previously mentioned, these tools are useful but not particularly interactive, requiring the addition of new nodes to create separate charts for different fields or chart types. Additionally, most graphs do not provide percentage values, so if you want to display percentages, you’ll need to export the graph data to Excel and calculate those values manually. This process is not ideal, especially when other software, like SAS Enterprise Miner, allows you to switch between frequency and percentage within the same settings window easily.

But what if I told you that SPSS Modeler actually has a hidden feature that simplifies data visualization with a more interactive interface, and the graphs can indeed display percentage values? In this section, I’ll reveal this hidden feature, which is not listed in the menu bar or **Node Pallet**. Even the SPSS Modeler guidelines do not provide instructions for this feature. It is integrated into a menu option called “**View Data**.”

**View Data** is a menu option that allows you to view your data at any node, enabling you to observe changes in the dataset after sampling, partitioning, transformation, or modeling. You can also use it to view your original data. However, most users are unaware that this menu option includes a chart feature, offering an interactive way to create charts more efficiently.

Let's walk through an example. Suppose you have a stream with the **Airline Recommendation** data source connected to a **Type** node. If you right-click on the **Type** node (you can also right-click on the data source node), a drop-down menu will appear. Select **View Data** from this menu, which will open a **View Data** window (this feature runs on Java, so ensure your Java is up to date).

![](images/ufig4_39.jpg)

This window contains several tabs, including **Charts**, **Spreadsheet**, **Data Audit**, and **Dashboard**. I’ll focus on the **Charts** tab because the other tabs are primarily for viewing data and statistics, which we’ve already covered. As shown in [Figure 4.21](#chapter4.xhtml#fig4_21), the **Charts** tab offers 28 different types of charts, including the ones we’ve discussed in this chapter, such as **Bar**, **Histogram**, **Pie**, **Scatter**, **Line**, **Box Plot**, and **Multi-Series** (similar to Multiplot). Additionally, it provides other useful tools like **Treemap**, **Q-Q Plot**, **Population**, and more.
