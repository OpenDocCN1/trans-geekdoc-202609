
# C5.0

C5.0 uses the concept of entropy to measure the impurity or disorder in a dataset. Entropy quantifies the uncertainty associated with a random variable. Information gain is then employed to find the best variable for splitting the dataset at each node. It measures the reduction in entropy that results from splitting the data based on a particular variable.

## Splitting Criteria

The algorithm evaluates various predictors and selects the one that maximizes information gain or other splitting criteria like gain ratio. These criteria help determine which variable best improves the homogeneity of the target variable's distribution across the resulting child nodes. The goal is to partition the data into subsets that are more homogeneous in terms of the target variable.

## Tree Construction

The dataset is divided into subsets based on the selected variable, and the process is recursively applied to each subset. The tree continues to grow until a stopping criterion is met, such as reaching a maximum tree depth or having a minimum number of instances in a leaf node.

## Handling Continuous and Categorical Variables

While C5.0 is primarily designed for building classification trees, it can handle both continuous and categorical variables. For continuous variables, the algorithm determines optimal split points based on information gain. It can also handle categorical variables with multiple levels, finding the best way to split the categories for maximum information gain.

## Pruning

Once the tree is fully grown, it may be pruned to avoid overfitting. The C5.0 algorithm uses a combination of cost-complexity pruning and reduced-error pruning to enhance the tree's ability to generalize to new data.

## Handling Missing Values

C5.0 handles missing values in the dataset using surrogate splits. These are alternative rules that serve as backups when the primary variable for splitting has missing values for certain instances.

# Quest (Quick, Unbiased, Efficient, Statistical Tree)

QUEST is a decision tree algorithm developed by Loh and Shih in 1997. It is designed for building trees in classification models, with a particular emphasis on handling large datasets efficiently. QUEST is known for its speed and the robust statistical foundation that guides its split decisions.

## Overview of QUEST

![](images/ufig8_16.jpg)

QUEST operates by using a statistical approach to construct decision trees. The algorithm iteratively selects variables and split points based on statistical criteria, aiming to maximize homogeneity within the branches while minimizing statistical impurity. Unlike traditional tree algorithms, QUEST performs simultaneous tests on multiple variables at each node, allowing for efficient and unbiased selection of the best split. The algorithm focuses on statistical significance and quick tree construction, adapting its structure to the complexity of the data. This makes QUEST particularly useful in situations where interpretability and statistical validity are key.

## Binary Tree Structure

QUEST generates a **binary tree**, meaning each internal node splits into exactly two child nodes. This binary structure simplifies the decision-making process and enhances the efficiency of data separation.

## Splitting Criteria

QUEST uses statistical measures to make splitting decisions. It often applies statistical tests, such as chi-squared tests or other association measures, to quantify the relationship between a potential splitting variable and the target classes. The goal is to maximize the statistical significance of each split, ensuring the resulting child nodes are as distinct as possible in terms of the target variable.

## Recursive Binary Splitting

Similar to other decision tree algorithms, QUEST employs recursive binary splitting. The process begins with the entire dataset, selecting the predictor variable and split point that maximizes the statistical difference in the response variable. The data are then split into two subsets, and the process is repeated for each subset.

## Stopping Criteria

The tree-building process continues until a predefined stopping criterion is met. Common stopping criteria include reaching a specified tree depth, having a minimum number of instances in a node, or other conditions designed to prevent overfitting. QUEST strives to find an optimal tree size based on statistical considerations.

## Unbiased Approach

One of QUEST's main strengths is its unbiased approach to decision-making. The algorithm ensures that decisions are driven by statistical significance rather than biased criteria, providing an accurate and objective representation of the data.

## Pruning

To avoid overfitting, QUEST incorporates pruning techniques. The pruning process uses a cost-complexity pruning strategy, where the algorithm evaluates the cost-complexity measure at various levels of tree complexity. It then selects a subtree that strikes an optimal balance between accuracy and simplicity.

## Speed and Efficiency

A key feature of QUEST is its speed and efficiency, especially when dealing with large datasets. The algorithm is designed to be fast and unbiased, making it a suitable choice for applications where computational resources are limited or where processing time is critical.

[Table 8.2](#chapter8.xhtml#tbl8_2) highlights key differences between CART and CHAID decision trees. Overall, these two types of trees share many similarities, but they differ primarily in how nodes are split. As a reminder, CART uses a binary split algorithm, while CHAID uses a multi-split approach. Both methods can be applied to build either association or classification models. However, CART generally performs better with continuous or ordinal predictors while CHAID is more suited to categorical predictors. That said, most data mining software allows for a combination of predictor types.
