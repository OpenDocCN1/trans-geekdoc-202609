| Steps | Descriptions |
| --- | --- |
| **STEP 1: UNDERSTANDING**<br>Purpose: Understanding the research problem and objectives | This step is dedicated to thoroughly understanding the research problem and objectives from a business perspective. Relevant information about the industry, market, stakeholders, systems, or organizations must be gathered, then translated into a clear problem statement and research questions that necessitate mining large datasets to predict an outcome. Researchers need to identify what they aim to achieve with causal data mining. The system's complexity and dynamics should be outlined, along with the potential variables to be included in the model. |
| **STEP 2: SAMPLING**<br>Purpose: Selecting dataset, sampling, and partitioning | Data are collected and sampled from reliable sources. The sampling method should be determined based on the target population and research scope. The dataset should be large enough to capture relevant information but not so large as to hinder efficient modeling. Afterward, the data are divided into training and validation samples. The training sample is used to build the model, and the validation sample is used to test the model's performance. If cross-validation is applied, the dataset should be split into multiple subsamples. |
| **STEP 3: EXPLORING**<br>Purpose: Exploring and preparing the data | The dataset is explored in detail to understand the variables, examine descriptive statistics, identify missing data, and detect outliers. Missing values and outliers should be handled appropriately to prevent information loss and reduce bias. A key step in data preparation for causal data mining is discretization, using algorithms such as equal distance, normalized equal distance, equal frequency, K-means, or tree-based methods. |
| **STEP 4: LEARNING**<br>Purpose: Learning unsupervised and supervised causal networks and performing cross-validation | Initially, an unsupervised network structure is developed to explore preliminary causal relationships among variables without specifying a target variable. This network facilitates causal inferences between individual variables and identifies the most important variables in the entire system, but it does not indicate each variable's impact on the target variable. It serves as the foundation for constructing the full network. Next, a supervised network is built using causal learning algorithms with an identified target variable. This network helps predict the target variable and assess each predictor's significance and influence. The network structure is learned from the data, so it must be validated by comparing results from training and validation samples. For large datasets, more robust validation methods, such as k-fold cross-validation, are recommended to minimize overfitting. |
| **STEP 5: EVALUATING**<br>Purpose: Evaluating the network performance and predictive precision | The performance of the causal network is assessed using model fit metrics to ensure its reliability and validity. If the model does not meet evaluation standards, a post-hoc analysis is performed. During this step, the model can be refined to improve performance by systematically removing variables with minimal predictive contribution, one at a time. This iterative process continues until the network achieves satisfactory performance. |
| **STEP 6: INFERRING**<br>Purpose: Performing target analysis, sensitivity analysis, and causal inference | Key predictors are identified and reported, along with their effect sizes on the target variable. Both total and direct effects should be analyzed. Additionally, sensitivity analysis is performed to determine how changes in one predictor influence the target variable. Lastly, causal inference is conducted, based on the probabilistic dependencies modeled within the network, to explore causal relationships between selected predictors and the target variable under certain conditions. This analysis can be used to create "what-if" scenarios, which allow decision-makers to develop strategies to prepare for incidents or mitigate risks. |

## Differences Between USELEI, SEMMA, and CRISP-DM

555. **You may ask: Why do we need another data mining process? And how does USELEI differ from the other two processes (SEMMA and CRISP-DM)?**

![](images/ufig16_17.jpg)

[Table 16.5](#chapter16.xhtml#tbl16_5) provides a summary and comparison of three data mining processes—USELEI, CRISP-DM, and SEMMA. These processes share similarities in various stages, such as sampling, data exploration, preparation, modeling, and model evaluation. However, when it comes to causal data mining, the USELEI process offers distinct advantages over the other two. USELEI places a stronger emphasis on constructing a causal network structure, performing causal inference, and conducting sensitivity analysis—key features that are particularly valuable for organizations in making informed business decisions.

| --- | --- | --- | --- |
| Steps | Understanding→Sampling → Exploring and preparing→Learning and validation→ Evaluating→Inferring | Business understanding→Data understanding→Data preparation→Modeling→Evaluation→Deployment | Sample→Explore →Modify→Model→ Assess |

Additionally, USELEI highlights the importance of understanding the research problem and identifying research objectives from a business perspective, which is not as prominently featured in SEMMA. These aspects allow for a more holistic approach to both predictive and causal modeling.

Overall, SEMMA and CRISP-DM are excellent processes for traditional data mining projects, where identifying causal relationships among variables is not a priority. In contrast, USELEI is specifically designed for causal data mining. Although it caters to a narrower audience, the USELEI process offers rigorous and comprehensive steps for conducting a causal data mining project.

It's important to note that Bayesian networks play a critical role in causal data mining, as this method enables the construction of a causal network from data, revealing probabilistic relationships among variables. The Bayesian network structure is used not only to predict the target variable but also to examine the causal relationships among variables within the network through probabilistic inference.
