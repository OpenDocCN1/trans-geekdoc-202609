
# CRISP-DM in SPSS Modeler

As we can see, CRISP-DM is very practical-oriented, which is why practitioners widely use it in the industry for real-life business problems. It should also be noted that CRISP-DM is built into the SPSS Modeler software. It is essentially an extension of the standard SPSS Modeler project tool (Figure 2.2). In fact, you can toggle between the CRISP-DM view and the standard Classes view to see your streams and output organized by type or by phases of CRISP-DM.

# SEMMA Process

Another popular data mining process is SEMMA, which stands for Sample-Explore-Modify-Model-Assess. This process is proposed by SAS Institute and has been widely used in many industries, particularly by academic researchers. SEMMA is integrated into SAS Enterprise Miner software to guide users in conducting data mining. It provides a sequence of steps that should be followed to analyze large datasets and uncover new patterns (Figure 2.4). Some of these steps are very similar to those in CRISP-DM. Specifically, Data Understanding is similar to Explore, Data Preparation is similar to Modify, Modeling is similar to Model, and Evaluation is similar to Assess. However, two steps in CRISP-DM that differ from SEMMA are Business Understanding and Deployment.

The following explains each step in the SEMMA process:

## SAMPLE

In the Sample step, we start with data sampling, selecting a portion of the whole dataset (sample) for analysis purposes. The sample should be large enough to contain sufficient information yet small enough to be used efficiently. If the original dataset is too large, we can decide to sample a part of it. For example, if we have a dataset with ten million data points, using the whole dataset may increase computing time. For data mining purposes, 10% of it, providing us with one million records, should be sufficient. However, if we do not sample correctly, our sample may be skewed from the original data, leading to sampling biases. In other words, our sample would not be representative of the full dataset, rendering the data mining results invalid. Therefore, we need to choose the right sampling method to minimize sampling biases and ensure a quality dataset for data mining.

Additionally, this phase involves data partitioning, where the data are split into sub-samples. The training sample is used to train the model, and the validation sample is used to validate the model. In some cases, a test sample may be used to test the final model. If we have an imbalanced dataset, our model may suffer from overfitting. In such cases, re-sampling may be needed to ensure the balance of the dataset. Details of different sampling methods will be covered later in Chapter 3.

## EXPLORE

In the Explore step, we explore and understand the data by discovering anticipated and unanticipated relationships between the variables and identifying abnormalities using data visualization. By using data visualization, we can produce multiple charts in different formats for various variables, gaining a deep understanding of the variables, scales, and values. Features such as descriptive statistics, missing value detection, and variable selection are used in this step. This step is crucial for understanding the variables and the data, allowing us to decide how to prepare and modify the data before analysis. Remember, "garbage in, garbage out" still applies here. We aim for quality data to produce quality output. A deep understanding of the variables and data also helps us select the right machine learning method, choose the right configurations for the models, interpret the results, and make necessary adjustments to the model configurations to improve model fit.

## MODIFY

The Modify step involves transforming and preparing variables for model training. Once we understand the quality and completeness of the data, we can decide how to improve data quality and reduce noise. While data mining can handle noisy data, clean data are crucial for building valid models. Large datasets tend to be less structured and messy. In this step, we handle missing values and outliers and perform any necessary data transformations. By reducing noise and outliers and addressing missing values, we create cleaner and more complete data for analysis. Judgment calls are necessary in this step, depending on the type of data and the project's purpose.

## MODEL

In the Model step, we select appropriate machine learning methods and apply specific configurations to the prepared variables to train models that may provide the desired outcome. Machine learning algorithms are used in this step to build multiple predictive models, either supervised or unsupervised learning. Depending on the project's purpose, the target variable, and the data, we can build multiple models using different methods or use a few methods with varied configurations to produce more models. This is an iterative process, requiring multiple configurations and reconfigurations until satisfactory models are achieved. A deeper understanding of the variables, scales, data, and machine learning increases the likelihood of building good models. Detailed configurations for each machine learning method will be covered later in this book.

## ASSESS

The last step is Assess, where we evaluate model performance and compare models using appropriate metrics. Model fit metrics are chosen based on the study's purpose and the type of data mining model. Based on the model comparison, we select the champion model, which is the best model. We also examine the model's usefulness and usability and identify important predictors. The champion model, along with important predictors, is recommended to decision-makers to help them make informed decisions on using the tool to improve business operations.

The SEMMA process provides a comprehensive framework for guiding the steps involved in importing, exploring, and analyzing data to yield high-quality outcomes. By constructing our project diagram in alignment with SEMMA's steps, we can systematically track our progress, document the results of each phase, and ultimately arrive at well-informed conclusions. This structured approach proves invaluable when troubleshooting errors or mispredictions during the modeling process. By retracing our steps and pinpointing where and why discrepancies occurred, we can make the necessary adjustments for improved accuracy and reliability.
