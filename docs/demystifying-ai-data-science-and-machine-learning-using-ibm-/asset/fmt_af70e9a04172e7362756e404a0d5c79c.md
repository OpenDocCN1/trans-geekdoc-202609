
Several model fit metrics are derived from the confusion matrix. The most common metrics include **misclassification rate**, **prediction accuracy**, **sensitivity**, **specificity**, and the **F-1 score**. 199. The formulas for calculating these metrics based on the confusion matrix are listed below, with [Table 6.7](#chapter6.xhtml#tbl6_7) providing descriptions of each metric.

### TABLE 6.7 Model Fit Metrics and Descriptions [Return to text.⏎](#chapter6.xhtml#b6tbl6_7)

| Model Fit Metrics | Description |
| --- | --- |
| Misclassification rate (MR) | How often a model misclassifies (makes incorrect predictions) the target variable (including actual positives and actual negatives) |
| Prediction accuracy (ACC) | How accurate a model predicts the target variables (including actual positives and actual negatives) ACC = 1 − MR |
| Sensitivity, recall, or true positive rate (TPR) | The probability of a positive result (event) or how well a model can predict true positives (events) |
| Specificity, selectivity, or true negative rate (TNR) | The probability of a negative result (non-event) or how well a model can predict true negatives (non-events) |
| F1 score | Alternative accuracy metric; it is the harmonic mean of the sensitivity (recall) and precision (positive predicted value); a high F1 score means low false positives (FP) and low false negatives (FN) |

```
Misclassification~rate~\left( MR \right) = \frac{FP + FN}{Total} = \frac{FP + FN}{TP + TN + FP + FN}
```

```
Accuracy~\left( {ACC} \right) = \frac{TP + TN}{Total} = \frac{TP + TN}{TP + TN + FP + FN} = 1 - MR
```

```
Sensitivity,~Recall,~or~True~positive~rate~\left( TPR \right) = \frac{TP}{TP + FN}
```

```
Specificity,~Selectivity,~or~True~negative~rate~\left( TNR \right) = \frac{TN}{TN + FP}
```

```
F1~score = \frac{2TP}{2TP + FP + FN}
```

It is essential to examine multiple metrics rather than relying on just one. While the **accuracy rate (ACC)** gives an overall sense of how accurate the model is, it doesn’t reveal potential issues with **false negatives (FN)** or **false positives (FP)**. For instance, a model with a 90% accuracy rate, which implies a 10% misclassification rate, may seem like a good predictive model at first glance. However, if we further examine the metrics and discover that **sensitivity (recall)** is only 50%, this signals a deeper problem.

Sensitivity, also known as the **true positive rate**, indicates how well the model predicts positive cases (events). A low sensitivity suggests a high number of false negatives. So, why does the model still appear to have good overall accuracy? As discussed in [**Chapter 3**](#chapter3.xhtml), one primary reason could be an **imbalanced dataset** with rare events. For example, if the imbalance ratio is only 5%, as in a flight cancellation scenario, where only 5% of cases are cancellations, the model could classify all cases as non-cancellations and still achieve 95% accuracy. However, looking at the sensitivity reveals that the model is failing to predict the events (cancellations), which was the primary objective of the project. This renders the model invalid, unusable, and not generalizable. In this case, the accuracy and misclassification rates can be misleading, underscoring the importance of evaluating multiple metrics.

There are no standard cutoff values for these metrics. Ultimately, the decision depends on the industry and the tolerance for error, which may vary based on business needs. For instance, as 200. a decision-maker, you must consider: **What margin of error is acceptable for your business?** Is it 1%, 5%, or 10%? My general rule of thumb is similar to the previous section. A **misclassification rate (MR)** of 5% or lower is considered great, and an MR between 5% and 10% is considered good. For **accuracy rate**, **sensitivity**, **specificity**, and the **F1 score**, a value of 95% or higher is considered great, while 90–95% is considered good.

## Example: Model Fit Metrics for a Classification Model

![](images/ufig6_31.jpg)

This example demonstrates how to calculate model fit metrics for a classification model. For example, we have a confusion matrix for a house-buying prediction, as presented in [Table 6.8](#chapter6.xhtml#tbl6_8).

### TABLE 6.8 Example of a Confusion Matrix for a House Buying Prediction [Return to text.⏎](#chapter6.xhtml#b6tbl6_8)

| | Predicted Buying | Predicted Not Buying |
| --- | --- | --- |
| Actual Buying | TP = 982 | FN = 17 |
| Actual Not buying | FP = 53 | TN = 864 |

Using the formulas above, we calculate our model fit metrics as follows:

```
Misclassification~rate~\left( {MR} \right) = \frac{53 + 17}{982 + 864 + 53 + 17} = 0.037~or~3.7\%
```

```
Accuracy~\left( {ACC} \right) = \frac{982 + 864}{982 + 864 + 53 + 17} = 0.963~or~96.3\%
```

```
or ACC = 1 – MR = 1 – 0.037 = 0.063
```

```
Sensitivity,~Recall,~or~True~positive~rate~\left( {TPR} \right) = \frac{982}{982 + 17} = 0.983~or~98.3\%
```

```
Specificity,~Selectivity,~or~True~negative~rate~\left( {TNR} \right) = \frac{864}{864 + 53} = 0.942~or~94.2\%
```

```
F1~score = \frac{2*982}{2*982 + 53 + 17} = 0.966~or~96.6\%
```

Overall, the model's **misclassification rate** is 3.7%, meaning the **accuracy rate** is 96.3%, which is considered great. Further examination reveals a **sensitivity** (true positive rate) of 98.3%, which is also great, and a **specificity** (true negative rate) of 94.2%, which is good. Lastly, the **F1 score** is 96.6%, indicating great performance. In conclusion, the model demonstrates excellent fit, and all model fit metrics show consistent results.

## Additional Model Fit Metrics

![](images/ufig6_32.jpg)

In addition to the previously discussed metrics, several other metrics should be evaluated to further confirm model fit. These metrics are not based on the confusion matrix but provide a different perspective by showing how well the model explains the target variable. These include the **ROC chart**, **Lift chart**, and **Gini coefficient**.

### Receiver Operating Characteristic (ROC) Chart

![](images/ufig6_33.jpg)

The **ROC chart** (Receiver Operating Characteristic chart) displays the **true positive rate (sensitivity)** on the vertical axis and the **false positive rate (1 − specificity)** on the horizontal axis. Essentially, the ROC chart illustrates the trade-off between sensitivity and specificity, metrics we’ve already discussed.

In the ROC chart, the straight diagonal line represents the baseline (random guessing), while the vertical line on the left and the horizontal line at the top indicate perfect classification. The larger the area between the model's ROC curve and the diagonal line, the better the model fit. [Figure 6.10](#chapter6.xhtml#fig6_10) illustrates the ROC chart and various scenarios for model fit evaluation.

It is important to note that the ROC chart can only be produced with binary target variables because it operates in two dimensions. For nominal target variables with more than two levels, we can only calculate the **ROC index**. An ROC index of 0.9 or higher is generally considered a good fit.

### Lift Chart

![](images/ufig6_34.jpg)

202. The **Lift chart** is another common metric used to evaluate model performance in classification models. **Lift** measures the effectiveness of a predictive model by calculating the ratio between results obtained with the model and those without it. The Lift chart, or Lift curve, provides a graphical representation of the relationship between lift values and response rates. A model with a higher Lift value at a given response rate performs better.
