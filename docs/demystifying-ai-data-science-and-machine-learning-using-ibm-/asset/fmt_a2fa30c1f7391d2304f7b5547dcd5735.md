
When we test both models with a new dataset (the test sample), we find that the linear regression model consistently provides a good model fit. In contrast, the neural network model's fit for the 189. test sample is significantly worse than it was during training. What's happening here? The neural network model is likely overfitting the training data, meaning it tries to account for noise in the data and incorporates this noise into the model. While this results in a nearly perfect fit for the training data, it performs poorly when applied to the test sample because the noise is not part of the actual pattern in the data.

In this scenario, the nonlinear relationships derived by the neural network model do not capture the true pattern, and the model is not generalizable—it has poor predictive power. Therefore, despite the complexity of the neural network model, the linear regression model is the better choice for this dataset.

This example demonstrates that it is difficult to pre-determine or speculate which machine learning method will perform best without applying various methods to the actual data. Otherwise, we could always default to the most advanced method and avoid considering simpler approaches. Similarly, even when using the same method, we can create numerous analytical configurations to find a model with strong predictive power. For example, in the scenario above, we could reconfigure the neural network model to capture the linear pattern rather than the nonlinear one. In fact, the simplest form of a neural network closely resembles linear regression.

![](images/ufig6_18.jpg)

With that in mind, the best practice for finding a model with good predictive power is to build multiple models using different methods and configurations. Then, we compare the performance of these models using model fit metrics to identify the one with the best overall performance. This is known as the **champion model**, which can be used as the final predictive model for real-life predictions. However, it is important to note that this is only the champion model among the models we trained and tested with the given data. There is still a possibility that the champion model does not have the expected predictive power, particularly if none of the models we trained have a good model fit. In this case, the best-performing model is relatively better but may not be ideal. Therefore, we must still evaluate the champion model and decide whether further adjustments are needed or if additional models should be trained.

### Model Comparison Steps

Follow the steps below to build and compare models:

![](images/ufig6_16.jpg)

1.  **Develop and train multiple predictive models** using different machine learning methods and analytical configurations appropriate for the given data.

2.  **Run the models** on both the training and test samples.

3.  **Select model fit metrics** for comparing and selecting the best model.

4.  **Compare the models** using the chosen metrics (for the test sample) and select the champion model.

5.  **Examine the model fit** of the champion model to determine if it is satisfactory. If not, adjust the configurations of existing models or consider adding new models.

6.  **Repeat Steps 1–5** until a satisfactory champion model is achieved.

7.  **Evaluate the model fit** of the champion model with the validation sample to confirm its predictive power.

## Model Fit Metrics for Association Models

![](images/ufig6_21.jpg)

Model fit metrics are used to assess how well our trained model aligns with the data, typically measured by either the accuracy or the error of its predictions. For association models with continuous target variables, these metrics can be categorized into error measures and charts. Error measures allow for a numerical evaluation of model fit, while charts provide a visual examination of the model's performance.

### Prediction Error Measures

Prediction errors reflect how much our trained model deviates from fitting the data. Generally, the lower the error, the more accurate the model. There are numerous error measures in statistics, ranging from simple to more complex. Using all of them can be excessive and unnecessary, as many are quite similar. Here, I will describe a few common error measures and recommend the most practical ones. The following formulas outline these common error measures and demonstrate how to calculate them using actual values, predicted values, and mean values:

*   **Sum of squared error (`SSE`)**
    `SSE = Sum of (Actual - Predicted)²`
*   **Sum of squared regression (`SSR`)**
    `SSR = Sum of (Predicted - Mean)²`
*   **Sum of squared total (`SST`)**
    `SST = Sum of (Actual - Mean)²`
*   **Mean absolute error (`MAE`)**
    $$MAE = \frac{\left. Sum~of~ \middle| Actual - Predicted \right|}{Sample~size}$$
*   **Mean squared error (`MSE`)**
    $$MSE = \frac{Sum~of~\left( Actual - Predicted \right)^{2}}{Sample~size}$$
*   **Root mean squared error (`RMSE`)**
    $$RMSE = \sqrt{\frac{Sum~of~\left( Actual - Predicted \right)^{2}}{Sample~size}}$$
*   192. **Mean absolute percent error (`MAPE`)**
    $$MAPE = \frac{Sum~of~\left( \frac{Actual - Predicted}{Actual} \right)}{Sample~size}$$
*   **Relative squared error (`RSE`)**
    $$RSE = \frac{Sum~of~\left( Actual - Predicted \right)^{2}}{Sum~of~\left( Actual - Mean \right)^{2}} = \frac{SSE}{SST} = \frac{Unexplained~Variance}{Total~Variance}$$
*   **Model's explanatory power (`EP`)**
    $$EP = 1 - RSE = \frac{Explained~Variance}{Total~Variance}$$
