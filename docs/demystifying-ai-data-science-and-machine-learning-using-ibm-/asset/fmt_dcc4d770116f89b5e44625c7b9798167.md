Regarding normal distribution, we can assess the skewness and kurtosis values, which are expected to be closer to zero for a normal distribution. After normalization, we observe improvements in skewness and kurtosis for all fields except for **B**. However, it's worth noting that **PtRatio_LogN** and **RmSQ_Inverse** are still not close enough to normal distributions, indicating further adjustments may be needed for these fields.

Additionally, while running the transformation for the complete dataset, we observed data loss in three fields: **Charles_River_Log10** (417 missing values), **CrimePC_Log10** (54 missing values), and **ZonePr_Log10** (318 missing values). All three fields were transformed using the LogN function. Typically, applying a logarithm function to a value of zero results in an undefined value, which is recorded as missing. Since these fields had multiple records with zero values, the transformation introduced many missing values.

To address this issue, I will change the transformation functions for these fields to **Square Root**, which will return a zero for any record with a zero value (as shown in [Table 5.13](#chapter5.xhtml#tbl5_13)).
