
# 术语表

## Bayesian network
**Bayesian network**，也称为 Bayesian belief network 或 probabilistic graphical model，是一种用于表示和推理变量之间不确定性及概率关系的强大且流行的方法。它是一种图形模型，通过有向无环图表示一组变量及其条件依赖关系。

## Bias
**Bias** 项会被加到每个神经元的输入加权和中。它允许网络学习向某些值的偏向，并提高模型的准确性。

## Big data
**Big data** 是一个术语，用于描述海量数据——包括结构化和非结构化数据——这些数据每天都在淹没企业。

## Boosting
**Boosting** 是一种迭代集成方法，基学习器按顺序训练，每个学习器专注于纠正其前驱者的错误。Boosting 为误分类实例分配更高的权重，从而有效地更多地关注具有挑战性的样本。

## Box plot
**Box plot**（box-and-whisker plot，箱线图）是数值数据分布的图形化摘要，显示中位数、四分位数和潜在异常值，简洁地展示数据的集中趋势和离散程度。

## Branch or sub-tree
**Branch** 或 **sub-tree** 是决策树的一个子部分。

## Category
参见 “Class”。

## Causal data mining
**Causal data mining** 是一种利用因果机器学习算法，从数据中的因果网络检测涉及变量及其相互关系的未知模式以预测结果的方法。

## Centroids
**Centroids** 是簇中对象属性的平均值。它们用于代表簇，并常作为将新对象分配给簇的基础。

## Champion model
**Champion model** 是在数据挖掘项目中，相比较模型中预测性能最好的模型。它是相对最优的。

## Chi-squared Automatic Interaction Detection (CHAID)
**CHAID** 是一种非参数方法，用于通过基于分类预测变量递归地将数据分割成同质子组来创建决策树，使用卡方检验评估变量间的独立性并找到显著分割。

## Class
**Class** 指数据集中代表特定组或数据实例类型的独特类别或标签，通常是目标变量。

## Classification and Regression Tree (CART)
**CART** 是一棵二叉树，它使用算法将父节点反复分割成两个子节点。CART 可用于分类和关联模型。

## Classification model
具有二元或名义型目标变量的预测模型。

## Cluster assignment
**Cluster assignment** 是根据对象与簇质心的相似性，将每个对象分配给特定簇的过程。分配通常通过比较对象到质心的距离或相似度来完成。

## Cluster or segment
**Cluster**，也称为 **segment**，指基于特定特征或属性相互相似的一组数据点或对象。

## Cluster profiling
**Cluster profiling** 涉及分析每个簇的特征，例如属性的平均值或簇内对象的分布。

## Cluster sampling
**Cluster sampling** 是一种抽样方法，将总体分成簇或组，随机选择整个簇，然后从选定簇的所有成员中收集数据。

## Cluster validation
**Cluster validation** 是评估所得簇的质量和可靠性的过程。它涉及评估簇的内部凝聚力和分离度，以及其稳定性和意义。

## Clustering
**Clustering** 是基于相似性或邻近性将对象或观测值分组到簇（段）中的过程。目标是创建内部同质（同一簇内对象相似）且外部异质（不同簇间对象不相似）的簇。

## Clustering algorithms
**Clustering algorithm** 确定簇的数量并将观测值分配给簇。聚类算法可分为层次聚类和划分聚类。

## Component rotation
**Component rotation** 用于转换主成分，使其与原始变量对齐，从而实现数据更具可解释性和意义的表示。

## Conditional Probability Tables (CPTs)
贝叶斯网络中的每个节点都有一个关联的 **CPT**，它定义了给定其父节点状态下该节点的条件概率分布。CPT 量化了变量之间的概率关系。

## Confidence level
**Confidence level** 表示我们对从样本获得的估计值的确定程度或置信度。

## Confusion matrix
**Confusion matrix**，也称为分类矩阵，是总结分类算法性能的表格。

## Connection (edge) (in neural networks)
**Connection** 连接神经元。每个连接都有一个关联的权重，决定了连接神经元之间的影响程度。

## Constraint-based algorithm
**Constraint-based algorithm** 是一种通过发现变量间的概率依赖关系而不直接优化评分指标，从数据中学习网络结构的方法。它迭代地测试和评估变量间的条件独立关系以确定网络结构。

## Convenience sampling
**Convenience sampling** 是一种非概率抽样方法，研究者选择最容易获得的个体作为样本，导致缺乏随机化和潜在偏差。

## Cost-sensitive learning
**Cost-sensitive learning** 是一种基于误分类成本来评估和选择模型的方法。

## Covariance
两个变量之间的 **Covariance** 衡量它们共同变化的程度。如果两个变量具有高协方差，意味着它们正相关；低协方差表示无相关。在 PCA 中，我们选择主成分时期望它们是不相关的。

## CRISP-DM process
**Cross-Industry Standard Process for Data Mining**（跨行业数据挖掘标准流程）。

## Data de-identification
**Data de-identification** 是从数据集中移除或修改识别信息以保护个人隐私和匿名性的过程。

## Data mining
**Data mining** 是一种利用机器学习算法，在大型数据集中检测涉及变量间关系的未知模式以预测关注结果的方法，可辅助做出明智的商业决策。

## Data mining model
参见 “Predictive model”。

## Data mining process
**Data mining process** 指使用各种技术和算法从大型数据集中发现有意义的模式、关系和洞察所涉及的步骤。

## Data modification
**Data modification** 涉及准备和转换原始数据，使其适合训练预测模型。

## Data science
**Data science** 是一个更大且多学科的领域，专注于从数据中获取和提取知识并传达结果。数据科学包含数据挖掘作为分析数据的重要组成部分，以及数据收集和管理、数据处理、数据可视化、计算机编程和人工智能应用等其他组成部分。

## Data scientist
**Data scientist** 是从事涉及分析、数据收集和处理、数据挖掘、机器学习和编程的任务或任务组合的专业人员。
