
此外，检查该图表是否存在任何明显模式也很重要。**非随机模式**表明残差与预测值之间存在相关性，暗示模型中缺少某些 195. 解释性信息。这意味着模型中的预测变量可能无法完全捕捉某些变量，这些变量反而体现在残差中。通常，我们希望图表呈现**无明显模式**——即随机分布，也称为“白噪声”。为满足这一要求，数据点应对称分布并聚集在图表中心（参见[图 6.6](#chapter6.xhtml#fig6_6)）。

![](images/ufig6_26.jpg)

[图 6.7](#chapter6.xhtml#fig6_7) 展示了几个具有非随机模式的散点图示例，例如点分布不均匀（图 A）、清晰的形状（图 B 和图 C）以及离群点（图 D）。在这些情况下，模型无法达到令人满意的拟合效果，需要改进。潜在的解决方案可能包括重新配置模型、使用集成模型、重采样以增加数据点，或引入额外的预测变量。

## 分类模型的拟合优度指标

分类模型通常涉及二元或名义目标变量。**二元目标变量**更为常见，因为它们常用于预测事件发生与否。目标变量有两个水平：发生（事件）和不发生（非事件)。例如，可用于预测信用欺诈风险、航空事故、航班取消或客户购买决策。因此，我们将主要关注具有二元目标变量的模型。具有**名义目标变量**（两个以上水平）的模型使用相同的拟合优度指标，但在计算上存在一些差异，我稍后会解释。

## 二元目标变量的拟合优度指标

### 混淆矩阵指标

![](images/ufig6_29.jpg)

在处理二元目标变量时，可以使用几个重要的模型拟合指标来评估模型性能。这些指标基于**混淆矩阵**计算，也称为**分类矩阵**，它汇总了分类算法的性能。它展示了所有预测结果，包括正确和错误的预测。具体而言，它显示了**真阳性 (TP)**、**真阴性 (TN)**、**假阳性 (FP)** 和**假阴性 (FN)** 的数量。[表 6.6](#chapter6.xhtml#tbl6_6) 展示了混淆矩阵的结构。这些值（TP、TN、FP、FN）从建模过程的结果中提取。这些术语的定义在定义框中提供。

表 6.6 分类矩阵或混淆矩阵 [返回正文。⏎](#chapter6.xhtml#b6tbl6_6)

| | 预测为是 | 预测为否 |
| --- | --- | --- |
| 实际为是 | TP (真阳性) | FN (假阴性) |
| 实际为否 | FP (假阳性) | TN (真阴性) |

在大多数数据挖掘项目中，我们旨在预测事件和非事件。为此，我们通常使用取值为 1（事件）或 0（非事件）的二元目标变量。事件 (1) 被视为阳性，非事件 (0) 被视为阴性。例如，在预测航班取消风险时，1 表示取消（阳性），0 表示未取消（阴性）。
