## Chapter Summary

90. In this chapter, we covered the sampling step, which is crucial in data mining since proper sampling provides us with a high-quality dataset for analysis. By selecting the right sampling method, we can obtain a generalized dataset, enabling us to develop a robust predictive model. A model with strong predictive power should perform well across all datasets, not just the training sample.

I provided recommendations for sample size and imbalance ratio to ensure data adequacy. It's also essential to work with a balanced dataset, as an imbalanced dataset can lead to overfitting, resulting in an invalid and unusable predictive model. To address data imbalance, several strategies can be employed, including using multiple model fit criteria, partitioning data, resampling, and CSL.

Resampling is a common technique used to balance an imbalanced dataset. We explored three different resampling methods: undersampling, oversampling, and SMOTE. Additionally, data partitioning is an important step to divide the dataset into subsamples. Typically, the training sample is used to train the model, the test sample is used to evaluate the model, and the validation sample is used to confirm the final model's generalizability.

I also provided recommendations for the split ratio based on different sample sizes. This chapter included demonstrations on how to use SPSS Modeler for data sampling, resampling, and data partitioning.
