
### Predictors must be continuous

There is more flexibility with this assumption. Although continuous predictors are preferable for interpretability and model fit, categorical (binary or nominal) predictors can still be used. These variables can be converted into dummy variables, for example, coding an education level variable (1—high school, 2—bachelor, and 3—graduate) into three separate variables: high school, bachelor, and graduate (with two levels, 1 for “yes” and 0 for “no”). While traditional statistical software often requires manual dummy coding, many data mining tools automate this process. Nonetheless, interpreting regression coefficients for dummy variables requires extra caution, as they are not as straightforward as with continuous variables.

### Normality

Normality is a common assumption for parametric statistical methods, particularly with the `OLS` method. In data mining, with larger datasets, fully satisfying the normality assumption is not always necessary. However, skewed data can still negatively impact model performance. Therefore, reviewing histograms and transforming variables to normalize data are recommended. Additionally, outliers can skew data, so reviewing histograms and box plots to identify and remove extreme outliers is also beneficial. Achieving full normality is not essential, but moving closer to a normal distribution generally improves model fit.

### Non-multicollinearity

Linear regression assumes that predictors are independent. In traditional studies, multi-collinearity—inter-correlation among predictors—must be addressed before running the regression analysis. However, research suggests that increasing the sample size can reduce the impact of multi-collinearity. In data mining projects, where large datasets are common, multi-collinearity is typically not a major concern.

### No missing values

In traditional statistical studies, regression analysis requires a complete dataset, and missing values must be addressed through imputation or elimination. Some software may even produce an error if missing values are detected. In data mining, however, models can still run with missing values. If the percentage of missing data is small, model performance is generally not significantly affected. Still, if more than 15% of values are missing, imputation is recommended, as a complete dataset generally leads to a better-fitting model.

### Linear Regression Model Fit Evaluation

In the `OLS` process, evaluating the **model fit** is essential. But what exactly is model fit? We discussed this in detail in [Chapter 6](#chapter6.xhtml). Essentially, we have a theoretical regression model, represented by the regression equation, and we also have data for the target variable and all predictors. Our goal is to see how well the data aligns with the theoretical model—this alignment is what we refer to as model fit.

```
Residuals = Actual data – Predicted data
```

In [Chapter 6](#chapter6.xhtml), I covered the general model fit metrics for association models, including `RMSE`, `MAPRE`, residual sum of squares error (`RSE`), **explanatory power (EP)**, the **actual vs. predicted** chart, and the **residuals vs. predicted** chart. In this chapter, I will focus specifically on metrics used for linear regression. In particular, when using linear regression, we need to evaluate the **F-test** and `R²`. [Table 7.4](#chapter7.xhtml#tbl7_4) explains these metrics and how to interpret them.

**TABLE 7.4** Model Fit Metrics Specific to Linear Regression [Return to text.⏎](#chapter7.xhtml#b7tbl7_4)

| Metrics | Description |
| --- | --- |
| F-test | The F-test evaluates the significance of the overall model. A significant F-test indicates that the regression model fits the data better than a model with no predictors. A significant F-test is expected for a well-fitting model. |
| R² (coefficient of determination) | R² is a common metric for assessing model fit in linear regression. It represents the percentage of variance in the target variable explained by the predictors. There is no absolute cutoff for a good R², as it depends on the number of predictors, but a general rule of thumb is as follows: <br> - R² > 0.7: Good model fit <br> - R² between 0.5 and 0.7: Acceptable model fit <br> - R² < 0.5: Poor model fit <br> Keep in mind that R² tends to decrease as the number of predictors increases, which is often the case in data mining. A lower R² can still be acceptable with many predictors. |
| Adjusted R² | Adjusted R² is a modified version of R² that accounts only for predictors that significantly impact the model's performance. It is generally recommended to use adjusted R² for evaluation. You can apply the same thresholds as suggested for R² above. |

In linear regression, when reviewing materials on the F-test and R², you may encounter specific terminologies, notations, and formulas. I have included these in [Table 7.5](#chapter7.xhtml#tbl7_5) for quick reference. Below are the formulas for calculating sum of squares total (`SST`) and `R²` using sum of squares regression (`SSR`) and `SSE`:

**TABLE 7.5** Key Terminologies and Notations in Linear Regression [Return to text.⏎](#chapter7.xhtml#b7tbl7_5)

| Terminologies | Notations | Descriptions |
| --- | --- | --- |
| Target variable | `y` | Actual value of the target variable (dependent variable). |
| Predictor | `x` | Actual value of the predictor (independent variable). |
| Mean of target variable | `ȳ` | Mean value of the target variable. |
| Predicted value | `ŷ` | Predicted value of the target variable estimated by the model. |
| Error | `e` | Error (residual) is the difference between the actual and predicted values of the target variable. |
| Sum of squares error | `SSE` | A measure of how far the data points are from the model's predicted values. |
| Sum of squares total | `SST` | A measure of how far the data points are from the mean of the target variable. |
| Sum of squares regression | `SSR` | A measure of how far the mean is from the model's predicted values. |

```
SST = SSR + SSE
```

```
R² = (SST - SSE) / SST = Explained variance / Total variance
```

As explained in [Chapter 6](#chapter6.xhtml), these formulas apply exclusively to linear regression and not to other methods. As you can see, in linear regression, **R²** is essentially the same as the **EP** that we discussed in [Chapter 6](#chapter6.xhtml).
