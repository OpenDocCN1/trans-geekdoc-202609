

# 关键发现摘要

## 目标变量分布
目标变量两个水平的频数和百分比表明数据集相对平衡，其中 52.46% 的数据为“是”（推荐），47.54% 为“否”（不推荐）。

## 缺失值
分类变量中不存在缺失值。然而，在连续变量中，有三个变量存在缺失值：`Arrival delay time`（到达延误时间）、`Departure delay time`（出发延误时间）和 `Flight time`（飞行时间）。虽然其他连续变量似乎没有缺失值，但仔细观察 `Price sensitivity`（价格敏感度）变量会发现一些异常。该变量的最小值为零，这在预期之外，因为 `Price sensitivity` 是在李克特量表上测量的（通常范围为 1 到 5）。因此，零值表示缺失值，我们需要将该值重新编码为缺失值。处理这些缺失值将在[第 5 章](#chapter5.xhtml)中讨论。

## 分类变量的描述性统计
数据集包含水平数量各异的变量：三个双水平变量、两个三水平变量、一个四水平变量，以及两个具有 52 个水平的变量（代表美国 52 个州）。

## 连续变量的描述性统计
[表 4.8](#chapter4.xhtml#tbl4_8) 展示了字段名、最小值、最大值、平均值、中位数、标准差、偏度和峰度等关键统计量。这些是大多数统计软件应用程序生成的标准描述性统计量。值得注意的是，只有少数变量的分布接近正态分布，其偏度和峰度值接近零。这些变量包括 `Age`（年龄）、`Number of flights per year`（年飞行次数）、`Number of loyalty cards`（忠诚卡数量）、`Price sensitivity`（价格敏感度）和 `Number of years flying`（飞行年数）。`Flight distance`（飞行距离）和 `Flight time`（飞行时间）等变量虽然不完全符合正态分布，但较为接近。相反，其他变量表现出较高的偏度和峰度值，表明其分布呈偏态且远离正态分布。根据建模所选的机器学习方法，我们可能需要考虑数据标准化和转换。

# SPSS Modeler 中的隐藏功能——交互式图表工具

![](images/ufig4_38.jpg)

在前面的章节中，我们探讨了 SPSS Modeler **节点面板** 中 **图表** 组下可用的各种图表工具。虽然我重点介绍了最常用的工具，但花时间练习所有工具是值得的。您可能会发现有效利用这些工具为您的数据创建有意义的可视化效果的方法。如前所述，这些工具虽然有用，但交互性不强，需要添加新节点来为不同的字段或图表类型创建单独的图表。此外，大多数图表不提供百分比值，因此如果您想显示百分比，则需要将图表数据导出到 Excel 并手动计算这些值。这个过程并不理想，特别是当其他软件（如 SAS Enterprise Miner）允许您在同一个设置窗口中轻松切换频数和百分比时。

但如果我告诉您 SPSS Modeler 实际上有一个隐藏功能，它通过更具交互性的界面简化了数据可视化，并且图表确实可以显示百分比值，您会怎么想？在本节中，我将揭示这个隐藏功能，它未列在菜单栏或**节点面板**中。甚至 SPSS Modeler 指南也没有提供该功能的说明。它集成在一个名为“**查看数据**”的菜单选项中。

**查看数据** 是一个菜单选项，允许您在任何节点查看数据，从而观察采样、分区、转换或建模后数据集的变化。您也可以用它来查看原始数据。然而，大多数用户不知道该菜单选项包含一个图表功能，提供了一种更高效地创建图表的交互式方式。

让我们通过一个示例进行演示。假设您有一个流程，其中 **Airline Recommendation** 数据源连接到一个 **Type** 节点。如果您右键单击 **Type** 节点（也可以右键单击数据源节点），将出现一个下拉菜单。从该菜单中选择 **查看数据**，这将打开一个 **查看数据** 窗口（此功能基于 Java 运行，因此请确保您的 Java 是最新版本）。

![](images/ufig4_39.jpg)

该窗口包含多个选项卡，包括 **Charts**（图表）、**Spreadsheet**（电子表格）、**Data Audit**（数据审核）和 **Dashboard**（仪表板）。我将重点介绍 **Charts** 选项卡，因为其他选项卡主要用于查看数据和统计信息，我们已经介绍过这些内容。如[图 4.21](#chapter4.xhtml#fig4_21)所示，**Charts** 选项卡提供 28 种不同类型的图表，包括我们在本章讨论过的图表，如 **Bar**（条形图）、**Histogram**（直方图）、**Pie**（饼图）、**Scatter**（散点图）、**Line**（线图）、**Box Plot**（箱线图）和 **Multi-Series**（多系列图，类似于多重图）。此外，它还提供其他有用的工具，如 **Treemap**（树状图）、**Q-Q Plot**（Q-Q 图）、**Population**（人口图）等。
