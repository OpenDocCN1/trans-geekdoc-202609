#### K-Means Cluster Node

479. The `K-Means` cluster node will allow us to perform the K-means clustering with three clusters, a reduction from the five-cluster model that had been automatically determined earlier. Our goal is to improve the interpretability and generalizability of the cluster model while maintaining or improving the model fit.

Follow the steps below to configure the `K-Means` cluster node:

1.  **Add a K-Means Node:**
    *   In the existing stream, add a `K-Means` node from the `Modeling` group.
    *   Connect it to the `Type` node.
2.  **Open Node Settings:**
    *   Open the `K-Means` node settings.
3.  **Model Tab:**
    *   Uncheck the box labeled “**Use partitioned data**.”
    *   Set the **Number of clusters** to **3**.
    *   Select the box “**Generate distance field**.”

        ![](images/ufig13_22.jpg)
4.  **Expert Tab:**
    *   Go to the **Expert** tab.
    *   Select “**Expert**” and “**Custom**” options.
    *   Set **Maximum iterations** to **100**.

        ![](images/ufig13_23.jpg)
5.  Click Apply and then Run.

By adjusting the model to use 3 clusters, we aim to strike a balance between model complexity and interpretability, and see if the clustering results provide more meaningful insights while maintaining a good model fit.

### Cluster Distance

Typically, reporting the distance between clusters helps show how distinct clusters are from one another, providing an indication of the quality of the clusters. Unfortunately, SPSS Modeler does not provide cluster distances directly in its results. However, we can still present the cluster distances in a different way. When we configured the `K-Means` node, we selected the option to generate the distance field, resulting in the addition of the new field, `$KMD-K-Means`, to the dataset. This field is a continuous variable that represents the distance of each record from the center of its assigned cluster.

Using this distance field, we can create a histogram to display the distributions of distances for all three clusters ([Figure 13.3](#chapter13.xhtml#fig13_3)). The results show that the distance ranges are consistent among the three clusters, falling between 0.35 and 1.4. Furthermore, Cluster 1 and Cluster 3 have similar distributions, while Cluster 2 exhibits a notably different distribution. The mean distances for Cluster 1 and Cluster 3 are 0.605 and 0.602, respectively, which are very close. In contrast, Cluster 2 has a slightly higher mean distance of 0.688.
