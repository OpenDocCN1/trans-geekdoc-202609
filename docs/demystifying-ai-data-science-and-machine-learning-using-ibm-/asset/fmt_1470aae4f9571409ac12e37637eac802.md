
| | Predicted YES | Predicted NO |
|---|---|---|
| Actual YES | True Positive<br>Cost = 0 | False Negative<br>Cost = 20 |
| Actual NO | False Positive<br>Cost = 200 | True Negative<br>Cost = 0 |

The reason is that false positives could lead to the airline incorrectly anticipating higher demand, causing them to increase flights and aircraft, thus raising operating costs without a corresponding increase in revenue. On the other hand, false negatives result in opportunity costs for the airline, as they miss out on potential demand. However, these costs are lower compared to the costs associated with false positives.

For this demonstration, we assume a hypothetical scenario where the cost of false positives is ten times higher than the cost of false negatives. Rather than using actual dollar amounts (which we do not have), we use a unit cost: 200 units for false positives and 20 units for false negatives (as shown in [Table 8.11](#chapter8.xhtml#tbl8_11)). The objective is to identify the predictive model that minimizes the total cost of misclassification.

![](images/ufig8_33.jpg)

Since SPSS Modeler does not provide a built-in tool to handle cost minimization or profit maximization as expected, I will demonstrate how to perform CSL using manual calculations. As outlined in [Chapter 6](#chapter6.xhtml), the formula for calculating the total cost of misclassification is as follows:

```
Total cost = FP × C(FP) + FN × C(FN)
```

where:

*   `FP` = False positives
*   `FN` = False negatives
*   `C(FP)` = Cost of a false positive
*   `C(FN)` = Cost of a false negative

We will use the results from the decision tree models developed earlier in this chapter. For this example, I selected the top three models: `C&R Tree 2`, `CHAID 1`, and `C5.0 2`. These are the models with the best prediction accuracy. To calculate the total cost of misclassification for each model, we need to extract the **false positives** and **false negatives** from the **Analysis** node for each model and apply the formula above.

[Table 8.12](#chapter8.xhtml#tbl8_12) presents the false positives, false negatives, and total cost for each model. I also included the ACC for comparison. Note that the results are based on the testing sample.

In other words, if the objective is to minimize the total cost of misclassification, `CHAID 1` emerges as the champion model with the lowest overall cost.

### Cost-Sensitive Learning (CSL) with the Profit Maximization Objective

In this scenario, we focus on maximizing the profits from accurate predictions. We assume that the airline is experiencing a decrease in demand, which necessitates making operational decisions regarding the number of flights and investments in new airplanes. Here, the prediction of **non-recommendations** (true negatives) becomes more valuable than the prediction of **recommendations** (true positives).

In other words, accurately predicting how many passengers will not recommend the airline enables the company to adjust flight volume, airplane capacity, and flight paths accordingly. These adjustments can lead to significant cost savings, which in turn increases overall profits.

[Table 8.13](#chapter8.xhtml#tbl8_13) presents the decision matrix for this scenario. The unit profit for true negatives is set at 1,000 units while the unit profit for true positives is set at 100 units. The objective is to identify the predictive model that maximizes the total profit from accurate classification.

**TABLE 8.13 Decision Matrix—Profits of Accurate Classification** [Return to text.⏎](#chapter8.xhtml#b8tbl8_13)

|---|---|---|
| Actual YES | True Positive<br>Profit = 100 | False Negative<br>Profit = 0 |
| Actual NO | False Positive<br>Profit = 0 | True Negative<br>Profit = 1,000 |

In this example, we will use the following formula to calculate the total profit from accurate predictions (as explained in [Chapter 6](#chapter6.xhtml)):

```
Total profit = TP × P(TP) + TN × P(TN)
```

where:

*   `TP` = True positives
*   `TN` = True negatives
*   `P(TP)` = Profit of a true positive
*   `P(TN)` = Profit of a true negative

We can extract the values for true positives and true negatives from the Analysis node (for the testing sample) for the three models. Then, using the formula above, we calculate the total profit of accurate predictions for each model.

As shown, when we factor in the profit from accurate predictions, `CHAID 1` achieves the highest total profit, followed by `C5.0 2` and `C&R Tree 2`. ### How to Conduct CSL Using SPSS Modeler?

The approach outlined above requires manual calculation of total misclassification costs or total profits from accurate predictions. While SAS Enterprise Miner provides the Decision node to handle both types of CSL, SPSS Modeler does not offer a similar feature. So, how do we handle CSL in SPSS Modeler?

In SPSS Modeler, misclassification costs are only available for decision tree algorithms, including `CART`, `CHAID`, `C5.0`, and `QUEST`. Other machine learning methods do not support this setting.

Misclassification costs in SPSS Modeler allow users to assign different weights to specific misclassifications, such as false positives and false negatives. These weights are integrated into the model, influencing predictions to avoid costly errors. When misclassification costs are incorporated into a decision tree algorithm, the algorithm adjusts predictions by imposing higher penalties on certain misclassifications, which may alter the prediction outcomes.

### How to Apply Misclassification Costs in SPSS Modeler?

Incorporating misclassification costs into a tree algorithm is straightforward. You follow the same steps used in constructing tree models, with one additional step as follows:

1.  In the tree setting window, go to the **Build Options** tab.
2.  Select **Costs & Priors**.
3.  Check the box labeled **Use misclassification costs**.
4.  Enter the misclassification cost information in the matrix.
5.  Complete the remaining steps (as described above) and run the tree model.
