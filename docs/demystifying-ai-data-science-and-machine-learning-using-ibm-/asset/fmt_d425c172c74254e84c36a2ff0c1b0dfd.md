## Neural Network Searching

Training a neural network involves finding a network structure (comprising nodes, layers, connections, weights, and activation functions) that best fits the data. Given the vast number of parameters (hyperparameters) and possible network configurations, this process can be time-consuming. It is not feasible to manually determine the best network based on judgment due to the sheer number of potential configurations. Most data mining software applications include an optimization learning feature that iteratively searches for the optimal neural network based on the data.

342. This iterative training process solves an optimization problem by minimizing error or loss on the training dataset, given the constraints of the parameters and data. As the complexity of the network architecture increases, the learning time tends to increase exponentially due to the growing number of computations required to find the optimal solution.

### Local Optimum Situation

During neural network training, we may encounter a situation known as a **local optimum**. A local optimum is a solution that appears optimal (either maximum or minimum) within a specific neighborhood of candidate solutions but is not the best solution overall. This contrasts with the **global optimum**, which is the best solution among all possible solutions.

[Figure 9.7](#chapter9.xhtml#fig9_7) illustrates the difference between a local and global optimum. In the figure, point A represents the global optimum with the lowest error. However, the training process may result in two local optima, represented by points B and C. These local optima are solutions with the lowest error only within a localized set of solutions but do not reflect the true optimal solution. In other words, the training process might incorrectly identify point B or point C as the optimum due to limitations in the learning algorithm.

Of course, we aim for the **global optimum** since a local optimum is not the true optimal solution and may result in a poorly fitting model. Overcoming local optimum problems in neural networks is challenging and requires building a robust optimization model, which is beyond the scope of this book. However, a local optimum is not always a bad outcome. In some cases, particularly when constructing larger neural networks, a local optimum with reasonably low error can be acceptable.

### Stopping Rules

Stopping rules for neural networks are criteria or conditions used to determine when the training process should be terminated. These rules are essential to prevent overfitting, optimize computational resources, and improve the generalization performance of the model. The following are common stopping rules for neural networks.

1.  **Early stopping**
    *   Description: Training is stopped when the performance on the testing sample ceases to improve or starts degrading.
    *   Rationale: This rule helps prevent overfitting by monitoring the testing error during training. Once the testing error increases or remains stagnant for a predefined number of epochs, training is halted.

2.  **Fixed number of epochs (training cycle)**
    *   Description: Training is stopped after a pre-defined number of epochs.
    *   Rationale: This is a straightforward rule where the algorithm is trained for a specific number of iterations, regardless of the model's performance. It is useful when computational resources are limited.

3.  **Minimum error threshold**
    *   Description: Training is terminated when the error (loss) on the training or testing sample falls below a certain threshold.
    *   Rationale: Ensures that the model stops when it has achieved an acceptable level of performance, avoiding unnecessary computational costs.

4.  **Resource constraints**
    *   Description: Training can be stopped if computational resources, such as time or memory, are exhausted.
    *   Rationale: Especially important in resource-intensive deep learning models, this rule prevents excessive use of resources and helps manage computational costs.
