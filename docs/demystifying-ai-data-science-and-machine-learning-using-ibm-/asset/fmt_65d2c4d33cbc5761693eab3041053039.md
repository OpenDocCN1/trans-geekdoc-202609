
## 11. Price Sensitivity Node Relationships

**Price sensitivity** is the parent node of **recommendation**, **average number of flights per year**, **travel purpose**, **gender**, and **age**, but it is the child node of **airline status** and **passenger class**.

As mentioned earlier, the effects of predictors on the target variable in Bayesian networks are not interpreted in the same way as in other machine learning methods. The key output is the CPT for each node. To access the CPTs in SPSS Modeler, navigate to the nugget window, select a node from the left panel, and choose **Conditional Probabilities** on the right panel. Prior and posterior probabilities for specific nodes are summarized below. Due to the length of the tables for nodes with parent nodes (such as recommendation, price sensitivity, travel purpose, average number of flights per year, age, and gender), only some conditions are demonstrated for clarity. The complete CPTs for these variables are displayed in [Table 16.9](#chapter16.xhtml#tbl16_9), [Table 16.10](#chapter16.xhtml#tbl16_10), [Table 16.11](#chapter16.xhtml#tbl16_11), [Table 16.12](#chapter16.xhtml#tbl16_12), [Table 16.13](#chapter16.xhtml#tbl16_13), [Table 16.14](#chapter16.xhtml#tbl16_14), [Table 16.15](#chapter16.xhtml#tbl16_15), [Table 16.16](#chapter16.xhtml#tbl16_16), [Table 16.17](#chapter16.xhtml#tbl16_17), [Table 16.18](#chapter16.xhtml#tbl16_18), [Table 16.19](#chapter16.xhtml#tbl16_19).
