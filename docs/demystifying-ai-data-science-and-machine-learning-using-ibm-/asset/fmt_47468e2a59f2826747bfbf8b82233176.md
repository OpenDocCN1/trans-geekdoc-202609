## Quick Chart Explorer Using Data Audit Node

![](images/ufig4_32.jpg)

One question you may have is: What if we want to view the distributions of all variables in the dataset at once to examine their distributions and missing values? Instead of manually creating those charts one by one, as shown before, SPSS Modeler offers a way to generate all these charts simultaneously using the `Data Audit` node.

The `Data Audit` node provides a comprehensive review of the data. This information is presented in a matrix that is easy to understand, sortable, and conducive to generating detailed graphs along with a range of data preparation nodes.

*   The **Audit** tab presents summary statistics, histograms, and distribution graphs, offering an initial insight into the data. Additionally, the report includes a storage icon positioned before the field name.

*   The **Quality** tab details outliers, extremes, and missing values, and provides tools to address these issues.

![](images/ufig4_33.jpg)

This feature is particularly useful when you need to quickly visualize and assess the distribution of multiple variables without creating separate charts for each one. By running the `Data Audit` node, you can efficiently review the frequency distributions and identify any potential issues, such as skewness or outliers, across all variables in your dataset simultaneously.

Follow the steps below to add and set up the `Data Audit` node.

1.  Open the “Airline_Explore” stream. We should have the data node and `Type` node created before.

2.  From the Output group in the Node Palette, add the `Data Audit` node to the stream and connect it to the `Type` node.

3.  Open the settings window of the `Data Audit` node.

4.  On the **Settings** tab, keep the Default setting, which will include all fields in the analysis.

5.  Check the box **Advanced statistics**.

    ![](images/ufig4_34.jpg)

6.  On the **Quality** tab, make sure to check two boxes for **Missing values: Count of records with valid values** and **Breakdown counts of records with invalid values**.

7.  Click **Apply** and **Run**.

This approach is highly effective for viewing the distributions of all variables simultaneously. [Figure 4.19](#chapter4.xhtml#fig4_19) shows the results of these multi-charts for the **Airline recommendation** dataset. You can see all histograms and bar charts for the variables across multiple windows. Expand each window to view the detailed chart for that variable. Remember that bar charts are used for categorical variables, while histograms are used for continuous variables.

## Statistics Exploration Using Data Audit Node

![](images/ufig4_35.jpg)

Data visualization offers a variety of graphical tools to help us visualize data trends and patterns. However, to select the appropriate machine learning method and determine the right configurations for predictive modeling, it's also essential to explore the statistical characteristics of our data. Specifically, we need to review the descriptive statistics of all variables to understand their attributes, identify any potential concerns, and decide if any data transformations are required in the Modify step. Key descriptive statistics to consider include:

*Sample size*

*   **for categorical variables**: Frequency of each level, percentage, and missing values.

*   **for interval variables**: Minimum, maximum, mean, standard deviation, skewness, kurtosis, and missing values.

These are the typical descriptive statistics covered in statistics courses. As a reminder, skewness and kurtosis provide insights into the distribution of data and whether they follow a normal distribution, which is a required assumption for the linear regression method.

For statistical exploration, we use the `Data Audit` node in SPSS Modeler. This multipurpose tool allows us to examine variable distributions and statistics within our datasets.

To illustrate, we’ll run the same `Data Audit` node that was created earlier. In this example, to display the basic descriptive statistics, I selected only the “Basic statistics” option in the settings window. [Figure 4.20](#chapter4.xhtml#fig4_20) shows the output of the `Data Audit` node under the **Audit** tab. It includes measurements for all fields. For continuous variables, the output displays minimum, maximum, mean, standard deviation, skewness, and the number of valid cases. For categorical variables, it shows the number of unique levels and valid cases.

### Additional Information: Missing Values, Outliers, and Extreme Values

The **Audit** tab does not directly display invalid cases (missing values). While it's possible to calculate missing cases using Excel, the **Quality** tab conveniently presents missing values under the “Null values” column. This information can be copied and merged with the descriptive statistics. Additionally, the **Quality** tab highlights the number of outliers and extreme values for each field.
