
## Neural Network Components

| Component | Description |
| --- | --- |
| **Neuron (node)** | A neuron, also called a node or unit, is a basic building block of a neural network. It receives inputs, processes them using an activation function, and produces outputs. |
| **Connection (edge)** | A connection connects neurons. Each connection has an associated weight that determines the level of the influence between connected neurons. |
| **Activation function** | An activation function is a function that determines the output of a neuron based on the weighted sum of its inputs. Common activation functions include sigmoid, `ReLU` (Rectified Linear Unit), and `tanh` (hyperbolic tangent). |
| **Weight** | Each connection between neurons is assigned a weight, which represents the strength or importance of that connection. These weights determine how much influence the input of one neuron has on the output of another. |
| **Bias** | A bias term is added to the weighted sum of inputs in each neuron. It allows the network to learn a bias toward certain values and improves the accuracy of the model. |
| **Layers** | Neurons are organized into layers in a neural network. The input layer receives the input data, the output layer produces the final output, and there can be one or more hidden layers in between. |
| **Forward propagation** | Forward propagation is the process of transmitting input signals through the network, layer by layer, to produce an output. Each neuron in a layer receives input from the previous layer, performs computations using its activation function, and passes the output to the next layer. |
| **Backward propagation (or backpropagation)** | Backward propagation is the process of adjusting the weights and biases in the network based on the prediction error. It involves calculating the gradients of the loss function and adjusting the parameters to minimize the error. |
| **Training** | Training a neural network involves iteratively adjusting the weights and biases using a training dataset. The goal is to minimize the error or loss function and improve the network's prediction accuracy. |
| **Loss function** | A loss function measures the discrepancy between the predicted output of the neural network and the actual target values. It quantifies the error and guides the adjustment of the parameters during training. |
| **Optimization algorithm** | The optimization algorithm is used during training to adjust the network's parameters based on the computed gradients. Gradient descent is a common optimization algorithm used for this purpose. |
| **Epoch** | An epoch refers to one complete pass through the entire training sample during the training of a neural network. |

### Network Connections

Essentially, an output node is a function of the hidden nodes connected to it, along with the corresponding weights. Each connection from a hidden node to an output node carries a weight, much like the regression weights in traditional models. These weights capture the importance of each connection in the model. Similarly, each hidden node is a function of the input nodes connected to it, along with their corresponding weights.

In each of these connections, we also have a bias node. A bias is a learnable parameter associated with each node that allows the model to shift the function left or right, which is crucial during training. The function we're referring to is called the **activation function**. Although the mathematical expressions governing these connections are more complex, at their core, this is what they represent. We will soon explore some common activation functions in more detail.

You may wonder why I don't present these equations like a linear regression equation (with an intercept, weights, input variables, and errors). The reason is that the **activation function** can be either linear or nonlinear. This flexibility is one of the key strengths of neural networks, as it allows them to capture nonlinear relationships between input, hidden, and output nodes within a complex network architecture.

## Activation Functions

![](images/ufig9_11.jpg)

As mentioned earlier, an **activation function** determines the output of a node based on an input or a set of inputs. It is a critical component of neural networks because it introduces nonlinearity, allowing the network to model complex, nonlinear relationships in data. Selecting the right activation function plays a key role in building an effective neural network.

As explained, the activation function takes the weighted sum of the inputs to a node (neuron), adds a bias term, and applies a nonlinear transformation to generate the node's output. This output is then passed to the next layer as input. In essence, activation functions mathematically represent the connections between nodes, which form the neural network model. Choosing and configuring the activation function is a fundamental task in neural network modeling.

There are several types of activation functions, each with its own strengths and weaknesses. *   **Identity (linear)**: The identity function is a simple linear function that returns the input value unchanged. It is useful in specific neural network architectures where the goal is to reconstruct the input from the output. This function is commonly used as the default activation function in the output layer of regression models, where the aim is to predict continuous values. In such cases, the output of the neural network is a linear combination of the inputs, similar to a regression function. However, because the identity function does not introduce nonlinearity, it limits the network's ability to model complex functions.
