### Ensemble Modeling

We will use the `Ensemble` node to combine the best models previously built using regression, decision tree, and neural network algorithms. To ensure that all models used for ensembling have identical field names, we will select top-performing models that use imputed and transformed data. The selected models are:

*   Best regression model: `Regression 1`
*   Two tree models: `C&R Tree 1` and `CHAID 1`
*   Four neural network models: `MLP 1`, `MLP 2`, `MLP 3`, and `MLP 4`

**Steps to Create the Ensemble Model:**

1.  Create a new stream and name it `Boston_Ensemble1`.
2.  Open the `Boston_Regression` stream.
3.  Copy the following nodes: `Data source`, `Type`, `Missing Value Imputation`, `Supernode-Transformation`, and `Partition` from the stream.
4.  Paste these nodes into the stream `Boston_Ensemble1`.
5.  Copy the model node and nugget for `Regression 1` and paste them into the stream. (Ensure the model node is still connected to the nugget when copied).
6.  Open the `Boston_Tree` stream, and copy the model nodes and nuggets for two trees: `C&R Tree 1` and `CHAID 1`. Paste them into the `Boston_Ensemble1` stream.
7.  Open the `Boston_NN` stream and copy the model nodes and nuggets for four models: `MLP 1`, `MLP 2`, `MLP 3`, and `MLP 4`. Paste these nodes into the `Boston_Ensemble1` stream.
8.  Connect the `Partition` node to the model node and nugget for `Regression 1`. Ensure the model node is still connected to the nugget.
9.  Connect the `Partition` node to the model node `C&R Tree 1` and then connect the nugget for `Regression 1` to the nugget for `C&R Tree 1`.
10. Repeat **Step 9** to connect all model nodes and nuggets in the following order: `Regression 1` → `C&R Tree 1` → `CHAID 1` → `MLP 1` → `MLP 2` → `MLP 3` → `MLP 4`.

After completing these steps, you should have a diagram that looks similar to the one described, with all the selected models connected in sequence.

![](images/ufig10_18.jpg)

11. Add an `Ensemble` node from the `Field Ops` group to the stream and connect it to the last nugget in the sequence `MLP 4`. Open the node setting.
12. For **Target field for ensemble**, select the target field `Imv`.
13. Click Apply and OK.
14. Add an `Analysis` node from the `Output` group to the stream and connect it to the `Ensemble` node. Open the node setting.
15. Select **Performance evaluation**, **Confidence figures**, and **Separate by partition**.
16. Click Apply and Run.
