
# Clustering Criteria

Clustering criteria are statistical measures used to evaluate the performance and quality of clustering models. Two widely recognized criteria for determining the optimal number of clusters in a dataset are the **Bayesian Information Criterion (BIC)** and the **Akaike Information Criterion (AIC)**. These measures help balance the trade-off between model complexity and goodness of fit, ensuring the clusters are meaningful without overfitting.

## Bayesian Information Criterion (BIC)

BIC is a criterion for model selection among a finite set of models. In the context of clustering, BIC is often used to evaluate the goodness of fit of different clustering solutions with varying numbers of clusters. BIC balances the trade-off between the complexity of the model (number of clusters) and the goodness of fit to the data. It is calculated using the formula:

```
BIC = -2 × log-likelihood + k × log(n)
```

where:

*   **Log-likelihood**: A measure of how well the model fits the data.
*   **k**: The number of parameters in the model.
*   **n**: The number of data points.

In clustering, a lower BIC value indicates a better model fit with an appropriate level of complexity. The optimal number of clusters corresponds to the model with the minimum BIC value, providing the best trade-off between model complexity and data fit.

## Akaike Information Criterion (AIC)

Similar to BIC, AIC is a measure of the relative quality of a statistical model. It penalizes models for their complexity to prevent overfitting. AIC is calculated using the formula:

```
AIC = -2 × log-likelihood + 2 × k
```

where the terms have the same meaning as in BIC.

In the context of clustering, AIC serves a similar purpose as BIC in selecting the optimal number of clusters. However, AIC tends to be less stringent in penalizing model complexity compared to BIC. Therefore, AIC may favor more complex models with higher numbers of clusters compared to BIC.

## Application of BIC and AIC in Clustering

To determine the optimal number of clusters, analysts typically run several clustering models with varying numbers of clusters and compute the BIC and AIC values for each model. The model with the minimum BIC or AIC value is selected as having the optimal number of clusters for the dataset.

*   **BIC** often selects fewer clusters as it penalizes more complex models more heavily.
*   **AIC** might suggest more clusters, being less conservative with complexity.

By applying these criteria, analysts can find a clustering solution that achieves a balance between simplicity and model fit, avoiding overfitting while ensuring the model captures the essential patterns in the data.

# Cluster Quality Assessment

![](images/ufig13_11.jpg)

Evaluating the quality of clusters is crucial to understanding how effectively clustering algorithms have grouped data points. One commonly used metric for assessing cluster quality is the silhouette measure, which quantifies how well a data point fits within its assigned cluster compared to other clusters. The silhouette measure considers both cohesion (how closely points are grouped within a cluster) and separation (how distinct the cluster is from other clusters).

## Silhouette Measure Calculation

The silhouette measure for a data point `i` is calculated as follows:

1.  **Mean intra-cluster distance (a)**: This is the average distance between data point `i` and all other points within the same cluster.
2.  **Mean nearest-cluster distance (b)**: This is the average distance between data point `i` and all points in the nearest cluster (i.e., the cluster to which `i` does not belong).
3.  **Silhouette coefficient (s)**: The silhouette coefficient for data point `i` is given by:

```
s_i = (b_i - a_i) / max(a_i, b_i)
```

The silhouette coefficient ranges from −1 to 1, where:

*   `s_i` = 1 indicates that the data point is well-clustered.
*   `s_i` = 0 indicates that the data point is on the boundary between two clusters.
*   `s_i` = −1 indicates that the data point may have been assigned to the wrong cluster.

By calculating the silhouette coefficient for each data point and averaging the values across all points, we can obtain an overall measure of cluster quality. A higher average silhouette coefficient implies better-quality clusters, with values closer to 1 indicating more compact and well-separated clusters.

## Application of Silhouette Measure

The silhouette measure is especially useful for determining the optimal number of clusters. By comparing the average silhouette coefficient across different numbers of clusters, analysts can find the cluster configuration that best balances cohesion and separation. Additionally, a silhouette plot can provide a visual representation of how well individual points are clustered, which aids in interpreting the clustering results.

## Comparison between Silhouette, BIC, and AIC

*   BIC and AIC are model selection criteria that focus on finding the best-fit model while penalizing for complexity, whereas silhouette score evaluates the quality of clusters directly.
*   BIC and AIC are typically used to compare different clustering solutions based on their overall fit to the data, while silhouette score is used to assess the quality of individual clusters within a solution.
*   Lower values of BIC and AIC indicate better model fit, whereas higher silhouette scores indicate better cluster quality.

# Cluster Analysis in SPSS Modeler

SPSS Modeler provides several nodes to perform cluster analysis. In this book, we will focus on three primary clustering nodes: `k-means node`, `TwoStep Cluster node`, and `Auto Cluster node`.

![](images/ufig13_16.jpg)

## K-Means Node

The K-means node performs cluster analysis using the k-means clustering method. K-means operates by initially establishing a predetermined set of cluster centers derived from the dataset. Subsequently, it assigns each data record to the cluster with the highest similarity, as determined by the input field values of the record. Once all records are assigned, the cluster centers are adjusted to accommodate the newly assigned records. Then, the records are reevaluated to determine if they should be reassigned to a different cluster. This iterative process of record assignment and cluster adjustment continues until either the maximum number of iterations is achieved or the change between consecutive iterations falls below a specified threshold.

## TwoStep Cluster Node

The TwoStep Cluster node performs cluster analysis using the two-step clustering method. In the initial step, the node makes a single pass through the data, compressing the raw input data into a more manageable set of subclusters. Subsequently, in the second step, a hierarchical clustering technique is utilized to progressively merge these subclusters into larger clusters, all without necessitating another pass through the data. Notably, hierarchical clustering eliminates the need for pre-selecting the number of clusters in advance. Many hierarchical clustering algorithms commence with individual records as initial clusters, merging them recursively to form increasingly larger clusters. While such methods may struggle with extensive datasets, the initial preclustering performed by TwoStep facilitates swift hierarchical clustering, even with large volumes of data.

## Auto Cluster Node

The Auto Cluster node estimates and evaluates clustering models designed to identify groups of records sharing similar characteristics. Operating akin to other automated modeling nodes, it facilitates experimentation with various combinations of options within a single modeling iteration. The node allows for the comparison of models using fundamental measures, aiding in the filtering and ranking of the usefulness of cluster models.
