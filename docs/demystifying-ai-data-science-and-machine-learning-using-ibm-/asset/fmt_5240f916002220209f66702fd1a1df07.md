### Imputation Example for the Boston Housing

Since the missing values account for about 11% of the data, we will use the mean imputation method. As in the previous example, we will perform the imputation using a combination of the **Data Audit** node and a **SuperNode**.

![](images/ufig5_33.jpg)

Follow the steps below to implement data imputation:

1. Open SPSS Modeler.
2. Create a new stream and name it “**Boston_Modify**.”
3. From the **Sources** group, add the **Statistics File** node to the stream and import the file `Boston.sav` from your computer.
4. From the **Field Ops** group, add a Type node to the stream and connect it to the data source.
5. Check the measurement scales for all fields. Change the role of the target field `Imv` to **Target.**
6. From the **Output** group, add a Data Audit node to the stream and connect it to the Type node.

    ![](images/ufig5_34.jpg)

7. Click **Apply** and **Run**.
8. In the **Data Audit** output window, select the **Quality** tab.
9. 164. For the field `Imv`, under the **Impute Missing** column, select **Specify**, and make the following changes:
    * Impute when: **Null Values**
    * Impute method: **Fixed**
    * Impute fixed values: **Mean**

        ![](images/ufig5_35.jpg)

10. To apply these imputations, generate a **SuperNode**. Under the **Generate** menu, select **Missing Values SuperNode**. This will generate a SuperNode containing the imputation configurations for `Imv`.
11. Click OK.
12. SPSS Modeler will create a SuperNode, named **Missing Value Imputation** node, into the stream. Connect this node to the Type node.
13. In order to execute the SuperNode, add another **Data Audit** node and connect it to the SuperNode.
14. Run the **Data Audit** node.

The results displayed in [Figure 5.8](#chapter5.xhtml#fig5_8) show that the field `Imv` now contains all valid records, with no missing values. This confirms that the missing values in this field have been successfully imputed with the mean value.
