
These stopping rules can be used individually or in combination, depending on the specific requirements of the task and the characteristics of the data. Implementing stopping rules is crucial for achieving an optimal balance between model performance and computational efficiency during the training process.

## Normalization

![](images/ufig9_19.jpg)

Before we begin constructing and training a neural network model, there is one more important concept to cover: **normalization**. The primary purpose of normalization is to convert input and output variables to the same scale, which improves model training efficiency and helps with result interpretation. Variables often exist on different scales, and in some cases, the differences can be significant. This can lead to longer training times and less accurate predictions. Additionally, interpreting the outputs becomes more challenging when variables are on varying scales. By normalizing these variables, we can enhance training efficiency and make the results easier to interpret, as all variables will be on a consistent scale.

There are three common normalization approaches. Don’t be intimidated by the formulas presented below—they are quite simple. I’ll focus more on the ranges of values rather than the technical details of the formulas.

1.  **Z-score normalization**: This is a widely used approach in statistics. Though technically, Z scores can take any value, they typically range between −4 and +4, with a more common range being −3 to +3.

2.  **Min-max normalization**: This method uses the minimum and maximum values to scale data between 0 and 1. It is commonly used with the **sigmoid activation function**.

3.  **Adjusted normalization**: Similar to min-max normalization but with some adjustments, this approach scales values between −1 and +1. It is often used with the **hyperbolic tangent (tanh) activation function**.

Below, I provide the formulas for these three methods in simple terms.

*   Z-score method

    $$new~value = \\frac{actual~value - mean~value}{standard~deviation}$$

*   Normalization method using max and min values

    $$new~value = \\frac{actual~value - min~value}{\\max{value - {\\min{value}}}}$$

*   Adjusted normalization method

    $$new~value = \\frac{2\*\\left( actual~value - {\\min{value}} \\right)}{\\max{value - {\\min{value}}}}~ - 1$$
