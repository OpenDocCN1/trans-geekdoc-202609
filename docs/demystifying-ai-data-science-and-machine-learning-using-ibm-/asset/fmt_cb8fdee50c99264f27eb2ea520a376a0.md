## Extracting Model Fit Results

The Analysis node results show the model's performance for both the training and test samples. In this output, the field `$E-Imv` represents the `predicted value` of the target field while `Imv` is the `actual (observed) value` of the target field. Most of the metrics are straightforward. Remember, `error` refers to the difference between observed and predicted values.

Below is a brief description of the key metrics:

*   **Minimum error**: The smallest error value.
*   **Maximum error**: The largest error value.
*   **Mean error**: The average of errors across all records, indicating any potential systematic bias in the model.
*   **Mean absolute error (MAE)**: The average of the absolute errors across all records, showing the average magnitude of error.
*   **232. Standard deviation**: The standard deviation of the errors.
*   **Linear correlation**: The linear correlation between the predicted and actual values, ranging from −1 to 1.
*   **Occurrences**: The sample size. In this case, 304 records are used for training the model and 202 records are used for testing the model.

As discussed in [Chapter 6](#chapter6.xhtml), these metrics alone are not ideal for evaluating model performance and comparison. Specifically, for association models, it is recommended to use metrics like `RMSE`, `MAPE`, `RSE`, and `EP`. Additionally, metrics specific to linear regression—including `F-test`, `R²`, and `adjusted R²`—should be used. However, since SPSS Modeler does not provide `RMSE`, `MAPE`, `RSE`, and `EP` directly through the Analysis node output, we will need to export the prediction outputs to Excel and calculate these metrics separately (see the section “Steps to Export Regression 1 Output to Excel” later in this chapter.).

One important thing to note is that regression-specific metrics, such as the `F-test`, `R²`, and `adjusted R²`, are only provided for the training sample. While these can be used for a preliminary evaluation of the regression model, they are not suitable for model comparison and reliability evaluation.

## Extracting F-test, R², and Adjusted R²

To extract the `F-test`, `R²`, and `adjusted R²` from SPSS Modeler, these values are stored in the model nugget rather than in the Analysis node. You can access the model nugget to view these regression-specific metrics.

Follow the steps below to extract `F-test`, `R²`, and `adjusted R²` for our `Regression 1` model. Note that these results are based on the training sample, which we can use for model comparison.

1.  Double-click the model nugget `Regression 1` from the stream. The Regression 1 result window will open.
2.  Under the `Advanced` tab, select `Regression/Model Summary`. You will see that the algorithm ran nine models during the stepwise process to find the final model. Model 9 is the final model with `R² = 0.735` and `adjusted R² = 0.727`.

![](images/ufig7_28.jpg)

3.  Select the `ANOVA tab`, where you can view the `F-test` for Model 9, which is `90.629`.

As explained earlier, in linear regression, `R²` is equivalent to `EP`, and `RSE` can be calculated as `1 − EP`. Therefore, we have `EP = R² = 0.735` and `RSE = 1 − EP = 1 − 0.735 = 0.265`. In other words, based on the training sample results, this model has an `EP of 73.5%`, meaning it can explain 73.5% of the variance in the target field (`Imv`) based on the variance in the predictors.

That's how you extract these metrics. I will dive deeper into the details of the regression model once we identify the `champion model`.
