

## 冠军模型的有效性评估

下一步是评估冠军模型的有效性。为此，我们将重点关注验证样本的模型拟合指标作为最终评估，如[表 9.7](#chapter9.xhtml#tbl9_7)所示。观测到的预测准确率（ACC）低于 80%，这一阈值通常被认为是次优的。然而，灵敏度（真正例预测）表现良好，达到 0.906。较低的 ACC 主要归因于特异性（真反例预测）不佳，仅为 0.656，表明假阳性率较高。

**表 9.7** 冠军模型的有效性评估—MLP 3 [返回正文.⏎](#chapter9.xhtml#b9tbl9_7)

| 指标 | 验证 | 评价 | C&R Tree 2 |
| --- | --- | --- | --- |
| ACC | 78.71% | 不佳 | 79.5% |
| MR | 21.29% | 不佳 | 20.5% |
| 灵敏度或 TPR | 0.906 | 良好 | 0.951 |
| 特异性或 TNR | 0.656 | 不佳 | 0.623 |
| F1 | 0.817 | 可接受 | 0.83 |
| 基尼系数 | 0.699 | 良好 | 0.673 |
| AUC (ROC 指数) | 0.85 | 可接受 | 0.837 |

F1 分数平衡了灵敏度和特异性，处于可接受范围内。ROC 指数为 0.85，也被认为是可接受的，尽管 0.9 或更高的指数将表明更好的模型拟合。基尼系数相当不错，为 0.699。此外，提升图显示，使用 20% 的数据集时，提升值为 1.64，意味着与无模型场景相比，该模型捕获的正例多 1.64 倍（32.8%）。

总之，当我们综合考虑所有指标时，可以得出结论：该模型具有勉强可接受的预测能力。

综上所述，虽然该预测模型的某些拟合指标被认为是可接受的，但该模型可能无法满足航空公司对预测乘客推荐意愿的期望。尽管模型在预测航空公司推荐的正例方面表现良好，但在准确预测非推荐方面却有所欠缺，整体准确率有待提高，特别是在减少假阳性方面。这与我们在[第 7 章](#chapter7.xhtml)和[第 9 章](#chapter9.xhtml)得出的结论一致。

为了对比，我还在[表 9.7](#chapter9.xhtml#tbl9_7)中列入了我们在第 8 章开发的最佳决策树模型（C&R Tree 2）。如表所示，决策树模型具有更高的准确率（ACC）、更低的 MR、更高的灵敏度和更好的 F1 分数。然而，`MLP 3` 神经网络模型在特异性、基尼系数和 ROC 指数方面优于决策树模型。在后续章节中，我们将继续使用其他算法为该数据集构建更多预测模型。
