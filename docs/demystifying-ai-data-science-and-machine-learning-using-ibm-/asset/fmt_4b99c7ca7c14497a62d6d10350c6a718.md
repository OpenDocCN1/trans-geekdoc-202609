## Data Visualization

![](images/ufig4_9.jpg)

With the vast amount of data collected daily, visualization has become a powerful tool for reviewing data trends and patterns without the need to delve into raw data or rely solely on descriptive statistics. Data visualization simplifies the process, making it easy for users to understand the data, even if they lack a background in data analytics or statistics. In many industries, organizations develop business intelligence dashboards that allow users to quickly select key variables or key performance indicators (KPIs) and generate charts representing data trends or patterns. Operators use these tools to monitor daily operations, while decision-makers leverage visualization to form strategies and make business decisions. However, it's crucial to know what to look for (KPIs or metrics) and how to interpret the outcomes.

Visual analytics applications such as Tableau, Spotfire, SAS Visual Analytics, and Microsoft Power BI offer many features for users. Regardless of the tool, several common chart types are typically used for visualization. In this book, I will cover some of these common chart types, explain how to create them, and demonstrate how to interpret the results. I will show you how to create charts using SPSS Modeler, though you can use other tools you’re comfortable with, such as SPSS Statistics or MS Excel. As previously mentioned, in this book, data visualization is just one step in the data mining process. Therefore, we will use these charts in a deterministic mode rather than the full dynamic mode often seen in intelligent dashboards.

I will use several primary visualization tools in SPSS Modeler: **Graphboard**, **Distribution**, **Histogram**, **Plot**, **Multiplot**, and **Time Plot**. These tools are all listed under the **Graphs** group in the Node Palette. My favorite node for visualization is the **Graphboard** node, as it is the most robust and versatile. It allows us to create different types of graphs based on the variables and their scales. The **Graphboard** node can automatically detect the appropriate chart types based on the number of variables and their scales. For example, if we select one nominal variable, the node will suggest using bar charts, plot charts, etc. [Figure 4.1](#chapter4.xhtml#fig4_1) shows an example where we select one nominal variable (recommendation) and one continuous variable (price sensitivity), displaying the available chart options for this selection. ### Bar Charts and Histograms

![](images/ufig4_10.jpg)

Bar charts and histograms are among the most common graphical tools used in data visualization. Both use bars to present results, either vertically or horizontally. So, what are the differences between them? [Table 4.3](#chapter4.xhtml#tbl4_3) summarizes some key distinctions between these two graphical tools. Bar charts are ideal for categorical variables, while histograms are used for continuous variables. We will explore the details of these chart types and discuss when to use each one.

TABLE 4.3 Differences between Bar Charts and Histograms [Return to text.](#chapter4.xhtml#b4tbl4_3)

| Items | Bar Charts | Histograms |
| --- | --- | --- |
| Data type | Bar charts are used to display categorical data. The categories or groups are displayed on the x-axis, with the height or length of the bars representing the frequencies or percentages associated with each category. | Histograms are suitable for continuous data. The data are divided into intervals or bins, and the height of the bars represents the frequency of data points within each interval. |
| X-axis representation | In a bar chart, the x-axis represents discrete categories or groups. Each category is usually represented by a separate bar. | In a histogram, the x-axis represents the range of values or intervals for the continuous variable being measured. The intervals are continuous and adjacent, forming a continuous scale. |
| Data presentation | Bar charts are effective for comparing data across different categories, showing distinct categories and comparing their frequencies. | Histograms display the distribution of values within a continuous variable, providing insights into the shape, central tendency, and spread of the data. |
| Bar placement | In a bar chart, the bars are usually separated from each other with gaps to emphasize the distinction between categories. | In a histogram, the bars are typically placed adjacent to each other without gaps, as the intervals are continuous and form a continuous scale. |
| Axis labels | Bar charts use a label for each category on the x-axis to indicate a specific group or category. | Histograms use labels on both the x-axis and y-axis. The x-axis label represents the measured variable, while the y-axis label represents the frequency of data points within each interval. |

### Bar Charts

![](images/ufig4_11.jpg)

Bar charts are used for categorical variables to present the frequency or percentage for each category or level. They are straightforward to understand and interpret. Percentages are particularly effective for comparison purposes, while frequencies can show the number of cases in each category.
