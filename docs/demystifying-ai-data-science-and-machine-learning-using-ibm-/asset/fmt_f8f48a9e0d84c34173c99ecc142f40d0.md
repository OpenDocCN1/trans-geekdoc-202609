
# Gradient Boosting Hyperparameters and Example

## Key Hyperparameters

1.  **Number of trees**: This hyperparameter determines the number of weak learners (trees) in the ensemble. Increasing the number of trees can improve the model performance, but it also increases training time. It is essential to find the right balance to avoid overfitting. You can try different values and use cross-validation to select the optimal number.

2.  **Learning rate**: The learning rate controls the contribution of each weak learner to the overall model. A lower learning rate makes the model more robust but increases the number of iterations needed for convergence. A higher learning rate may lead to faster convergence but could result in overfitting. Experiment with different learning rates to find the optimal value.

3.  **Maximum depth of trees**: This hyperparameter determines the depth of the individual decision trees. A deeper tree can capture more complex relationships in the data but is prone to overfitting. Shallower trees reduce overfitting but may result in underfitting. It's important to tune the maximum depth based on the complexity of the problem and the available data.

4.  **Subsampling**: Subsampling refers to the fraction of training samples to be used for training each weak learner. Using a value less than 1.0 introduces randomness and can reduce overfitting. However, setting it too low may result in underfitting. Cross-validation can help identify the optimal subsampling value.

5.  **Variable subsampling**: This hyperparameter determines the fraction of variables to be used for training each weak learner. It introduces randomness and helps reduce overfitting. You can try different values (e.g., 0.5, 0.8) to find the optimal variable subsampling ratio.

6.  **Automated hyperparameter optimization**: There are also automated hyperparameter optimization techniques available, such as Bayesian optimization, genetic algorithms, or gradient-based optimization. These methods can efficiently search the hyperparameter space and find optimal values, often using a guided exploratory process.

### Gradient Boosting Modeling

In this example, we train four gradient boosting models using the dataset with missing values. Follow the steps below to set up the Gradient Boosting models:

1.  **Create a New Stream**:
    *   Open SPSS Modeler and create a new stream named `Airline_GradientBoosting`.

2.  **Copy the Existing Stream**:
    *   Open the stream `Airline_Tree`.
    *   Copy the section of the stream from the **data source**, **Filler node**, to the **Partition node**.
    *   Paste these nodes into your new `Airline_GradientBoosting` stream.

3.  **Add Five XGBoost Tree Nodes**:
    *   From the **Modeling** group, add four **XGBoost Tree Nodes** to the stream.
    *   Connect them to the **Partition node**.
    *   Label the four XGBoost Tree nodes as:
        1.  Gradient Boosting 1
        2.  Gradient Boosting 2
        3.  Gradient Boosting 3
        4.  Gradient Boosting 4

At this point, your stream diagram should look like the following:

![Figure 15.14](images/ufig15_14.jpg)

Then, use the details below to set the configurations for each gradient boosting model. We focus on a few key configurations that are available under the Basic options, Learning task, and Advanced options in the XGBoost Tree node settings.

#### Gradient Boosting 1: Default

*   **Basic options**
    *   Hyper-parameter optimization: `unchecked`
    *   Tree method: `auto`
    *   Number boost round: `10`
    *   Max depth: `6`
    *   Min child weight: `1`
*   **Learning task**
    *   Objective: `binary:logistic`
    *   Early stopping: `unchecked`
*   **Advanced options**
    *   Sub sample: `1.0`
    *   Gamma: `0.0`

#### Gradient Boosting 2

*   **Basic options**
    *   Hyper-parameter optimization: `unchecked`
    *   Tree method: `auto`
    *   Number boost round: `50`
    *   Max depth: `20`
    *   Min child weight: `1`
*   **Learning task**
    *   Objective: `binary:logistic`
    *   Early stopping: `unchecked`
*   **Advanced options**
    *   Sub sample: `1.0`
    *   Gamma: `0.0`

#### Gradient Boosting 3

*   **Basic options**
    *   Hyper-parameter optimization: `unchecked`
    *   Tree method: `auto`
    *   Number boost round: `100`
    *   Max depth: `50`
    *   Min child weight: `1`
*   **Learning task**
    *   Objective: `binary:logistic`
    *   Early stopping: `unchecked`
*   **Advanced options**
    *   Sub sample: `1.0`
    *   Gamma: `0.0`

#### Gradient Boosting 4 (hyper-parameter optimization)

*   **Basic options**
    *   Hyper-parameter optimization: `checked` (note: change the configurations below before checking this box).
    *   Tree method: `auto`
    *   Number boost round: `100`
    *   Max depth: `50`
    *   Min child weight: `1`
*   **Learning task**
    *   Objective: `binary:logistic`

    *   Sub sample: `1.0`

To run each of the XGBoost Tree nodes separately and produce model nuggets, follow the same steps described in [Chapter 7](#chapter7.xhtml):

1.  **Run each node separately**: After configuring the four gradient boosting models (Gradient Boosting 1, Gradient Boosting 2, Gradient Boosting 3, and Gradient Boosting 4) with the specified settings, execute each of the nodes separately. This will generate the corresponding model nuggets for each.
2.  **Connect model nuggets**: Since all models use the same input data with identical field names, you can use the approach described in [Chapter 7](#chapter7.xhtml) to connect all the model nuggets for comparison. Follow the same steps outlined in [Chapter 7](#chapter7.xhtml) under the section “How to Run the Analysis Node with Multiple Models?”
3.  **Add filter node**: Add a Filter node to the stream and connect it to the model nugget for Gradient Boosting 4. Rename the model nuggets to the selected names (Gradient Boosting 1, Gradient Boosting 2, etc.) (see the detailed instructions below).
4.  **Add analysis node**: After renaming the model nuggets, use an Analysis node to compare the performance of the models. The Analysis node will compare the models based on key performance metrics.
5.  **Add evaluation graph node**: Use an Evaluation Graph node to produce ROC charts and Lift charts for all the models. This will provide a graphical representation of model performance.
6.  **Run the diagram**: Run the entire diagram to generate the comparison results for each gradient boosting model.

By following these steps, you’ll have a diagram as below, including model comparison through the Analysis node and graphical evaluation with the ROC and Lift charts.

![Figure 15.15](images/ufig15_15.jpg)

To configure the Filter node settings to change the model names for each of the gradient boosting models, follow these steps:

1.  **Open the Filter node**: After connecting the model nuggets (Gradient Boosting 1, Gradient Boosting 2, Gradient Boosting 3, and Gradient Boosting 4) to the Filter node, open the settings of the Filter node.
2.  **Rename models**: Select the field to rename each model as follows:
    *   Rename the field `$XGT-Recommend the airline` to `Gradient Boosting 1`.
    *   Rename the field `$XGT1-Recommend the airline` to `Gradient Boosting 2`.
    *   Rename the field `$XGT2-Recommend the airline` to `Gradient Boosting 3`.
    *   Rename the field `$XGT3-Recommend the airline` to `Gradient Boosting 4`.
