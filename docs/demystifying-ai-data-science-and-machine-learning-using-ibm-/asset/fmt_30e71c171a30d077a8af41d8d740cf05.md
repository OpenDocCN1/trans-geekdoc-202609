450. In this example, we will conduct PCA for the Boston Housing dataset with the purpose of identifying underlying factors from the data.

* **Dataset:** `Boston.sav`
* **Target variable:** `Imv` (Continuous—Median home value)

### Variables for PCA

Since all the input variables in the Boston Housing dataset are continuous, they will all be used for PCA. Note that the target variable `Imv` will not be included in this analysis, as PCA is an unsupervised learning method and target variables are not used.

### Sample-Explore-Modify

As discussed in previous chapters, we address missing values by using imputed data for the continuous variables. Since PCA is an unsupervised method and does not require the target variable, there is no need to partition the data into training or testing sets. For this analysis, the entire dataset will be used.

### PCA Modeling

Follow the steps below to configure the PCA/Factor node in SPSS Modeler:
