
Then, we compare this ensemble model with individual models to determine which performs better.

## Example: A Classification Model Using the Ensemble Feature in a Tree Node

![](images/ufig10_13.jpg)

In this example, we will build several ensemble models for the same dataset using the ensemble feature within a tree node. This feature allows us to run an ensemble using either the boosting or bagging method (note that stacking is not available in SPSS Modeler). For each tree model, we can create two ensemble models: one using boosting and the other using bagging.

The following tree models, developed in [Chapter 8](#chapter8.xhtml), have been selected to create ensemble models based on their algorithms:

*   `C&R Tree 2` boosting
*   `C&R Tree 2` bagging
*   `CHAID 1` boosting
*   `CHAID 1` bagging
*   `C5.0 2` boosting (Note: The `C5.0` node does not support the bagging method).

### Steps

1.  Open the `Airline_Tree` stream.
2.  Save it as `Airline_Tree_Ensemble`.
3.  Remove all non-selected tree nodes and keep only the nodes listed above.
4.  Ensure that all configurations previously set up for these nodes in [Chapter 8](#chapter8.xhtml) remain unchanged.

Once these steps are completed, you should have a stream that resembles the following structure:

*   `C&R Tree 2` boosting and `C&R Tree 2` bagging nodes
*   `CHAID 1` boosting and `CHAID 1` bagging nodes
*   `C5.0 2` boosting node

This will allow us to evaluate how the boosting and bagging ensemble methods improve the performance of these tree models.

![](images/ufig10_14.jpg)

Follow the steps below to build the ensemble models:

#### To build a boosting ensemble model for C&R Tree 2 (boosting)

1.  Open the node settings.
2.  Under the `Build Options` tab, in the `Objective` menu, select `Enhance model accuracy (boosting)`.
3.  In the `Ensembles` menu, set `Default combining rule for categorical targets` to `Highest probabilities win`. Set the `Number of component models` to `100`.
4.  Click Apply and Run.

#### To build a bagging ensemble model for C&R Tree 2 (bagging)

1.  Open the node settings.
2.  Under the `Build Options` tab, in the `Objective` menu, select `Enhance model stability (bagging)`.
3.  In the `Ensembles` menu, set `Default combining rule for categorical targets` to `Highest probabilities win`. Set the `Number of component models` to `100`.
