## Replacement Example for the Airline Recommendation

![](images/ufig5_20.jpg)

The purpose of this example is to use the replacement technique to re-code the zero values in the `price sensitivity` field as missing values, thereby correcting the information in the dataset. Since SPSS Modeler does not have a specific node designated for replacement, we will use the Filler node for this task. You might wonder: Why not use the Reclassify node, which can also re-code data? The main reason is that the Reclassify node is primarily intended for categorical fields. In this case, we are working with a continuous field, making the Filler node more appropriate. As mentioned earlier, the Filler node is particularly useful for replacing field values and is commonly used to handle missing values.

Follow the steps below to re-code the missing values using the Filler node:

1.  Open SPSS Modeler.
2.  Create a new stream and name it `Airline_Modify`.
3.  From the Sources group in the Node Pallet, double-click the Statistics File node to add it to the stream.
4.  Double-click the Statistics File node to open its settings window.
5.  Click the ellipsis button (three-dot button) and select the `AirlineRecommendation.sav` file from your computer.
6.  From the **Field Ops** group, add a **Type** node to the stream and connect it to the data node. This node allows you to view and change the measurement scales and roles of fields.
7.  Check the measurement scales of all fields. For the field `recommendation`, change the role to **Target**.
8.  From the Field Ops group, add a **Filler** node to the stream and connect it to the Type node. Rename this node to `Missing value recoding`. Open the node settings.
9.  Select `Price sensitivity` for **Fill in fields** and **Based on condition** under Replace.
10.  For Condition, type `Price sensitivity = 0` (this condition tells the software to select cases with zero values only).
11.  For **Replace with**, type `undef` (`undef` returns the undefined value, which SPSS Modeler will interpret as blank or null).
12.  Click Apply, and then click OK.

![](images/ufig5_21.jpg)

The Filler node will replace all zero values in the `Price sensitivity` field with blanks, saving the modified information in the same field. As shown in [Figure 5.3](#chapter5.xhtml#fig5_3), the results indicate 3,976 missing values for `Price sensitivity`. These missing values represent the original zero values that have been successfully replaced. Thus, the replacement task has been completed successfully.

## Imputation Example for the Airline Recommendation

![](images/ufig5_23.jpg)

In this example, we use the imputation method to replace missing values with the mean. We selected the mean imputation method because the percentage of missing values is low (around 2%), and it is one of the most common techniques used for imputation.

It's important to note that, unlike SAS Enterprise Miner, SPSS Modeler does not have a specific node dedicated to imputation. This makes the task a bit tricky in SPSS Modeler, but I will guide you through the process step by step. We will begin by using the **Data Audit** node to configure the imputation settings, then create a **SuperNode** to perform the actual imputation. But first, what is a SuperNode, and what does it do?

**SuperNodes** consolidate multiple nodes into a single node, effectively encapsulating parts of a data stream. This offers several advantages for data miners:

*   It simplifies and organizes complex data streams.
*   Nodes can be grouped into a SuperNode, customized for specific business needs.
*   SuperNodes can be exported to libraries and reused across multiple data mining projects.

While this might sound more complex than it really is, the process is straightforward. To perform imputation, we first configure the imputation method using the Data Audit node (under the **Quality** tab). Then, we encapsulate these configurations in a SuperNode and execute it to complete the imputation.

### Performing Imputation Using the SuperNode

1.  Open the `Airline_Modify` stream created earlier.
2.  From the **Output** group, add a **Data Audit** node to the stream and connect it to the Filler node named `Missing value recoding`. Open the node settings.

3.  Click Apply, and then **Run**.
