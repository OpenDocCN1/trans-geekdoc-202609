
To obtain additional performance metrics, we add an Analysis node to each model and run it. From the output of the Analysis node, we can extract the relevant metrics. However, as discussed in [Chapter 8](#chapter8.xhtml), we will primarily use Mean Absolute Error (MAE) and linear correlation to compare models, as other metrics are less meaningful for comparison.

As shown in [Table 9.9](#chapter9.xhtml#tbl9_9), based on the testing sample results, MLP 4 has the highest EP, but it does not have the lowest MAE. MLP 3 shows the lowest MAE and highest linear correlation. This discrepancy arises because EP is calculated from the training sample, while MAE is calculated from the testing sample. In such cases, we should prioritize the results from the testing sample. After recalculating the EP for the testing sample, it was confirmed that MLP 3 has a higher EP than MLP 4. Thus, MLP 3 demonstrates the highest prediction accuracy.

Among the MLP models, MLP 1 (with an automatic number of nodes) has the lowest accuracy. The most accurate model, MLP 3, uses two hidden layers, each with 20 nodes, which is higher than both MLP 1 and MLP 2. However, this does not mean that more nodes always result in better accuracy (e.g., MLP 4, with 30 nodes per hidden layer, did not outperform MLP 3). The key is to find the optimal number of nodes (neurons). SPSS Modeler lacks an automatic optimization feature for network structures, so identifying the best configuration requires trial and error. It's also worth noting that models with more nodes require more computing time to converge.

Among the RBF models, RBF 1 (with an automatic number of nodes) is the least accurate. Interestingly, RBF 3, with 50 nodes, has the highest accuracy among the RBF models. However, overall, the MLP models exhibit higher accuracy than the RBF models for this dataset.

In conclusion, MLP 3 is selected as the champion model due to its superior prediction accuracy.

### Reliability of the Champion Model

In this step, we assess the reliability of our champion model. [Table 9.10](#chapter9.xhtml#tbl9_10) presents a side-by-side comparison of metrics between the testing and training samples. The findings reveal notable discrepancies between these two samples, particularly in MAE, standard deviation, and linear correlation. Specifically, the differences are 12% for MAE, 16% for standard deviation, and 4% for linear correlation. These differences suggest that the model performs with lower accuracy on the testing sample compared to the training sample, raising potential reliability concerns.

While such actions are not feasible for this example, it is important to recognize this issue and consider potential solutions for future work.
