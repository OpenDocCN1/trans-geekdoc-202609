Since $Z_i \sim N(0,1)$, by the Law of Large Numbers (see Appendix C.1), we have that the expected value of position $X_T$ is:

```
$E[X_T] = \sigma \sqrt{dt} E \sum_{i=1}^{n} dZ_i = 0$
```

The variance of the position $X_T$:

```
$Var[X_T] = Var[\sigma \sqrt{dt} \sum_{i=1}^{n} dZ_i] = \sigma^2 dt Var\sum_{i=1}^{n} dZ_i]$ (2.1.8)
```

Since all the $dZ_i$ variables are IID $N(0,1)$ we have $Var[dZ_i] = 1$ and $Var[\sum_{i=1}^{n} X_i] = \sum_{i=1}^{n} Var_i[X_i]$ (see Appendix C.3.1). Thus

```
$Var[X_T] = \sigma^2 dt \sum_{i=1}^{n} Var[dZ_i] = \sigma^2 dt \sum_{i=1}^{n} 1$ (2.1.9)
```

which gives:

```
$Var[X_T] = \sigma^2 dt = T\sigma^2$" (2.1.10)"
```

So, at time $T$, the position of the pollen grain $X_T$ is distributed as $X_T \sim N(0, \sigma^2)$.

If the water container is not perfectly level the pollen grains will exhibit drift in a particular direction. We can modify Eq. (2.1.5) to take this into account as:

```
$dX_T = \mu dt + \sigma \sqrt{dt} dZ_i, dZ_i \sim N(0,1),$ (2.1.11)
```

or equivalently

```
$dX_T = \mu dt + \sigma dW_t, dW_t \sim N(0, dt),$ (2.1.12)
```

where we have included the constant drift $\mu$. We proceed in a similar manner to that for the case of $zero$ drift Brownian motion we have:

```
$X_T = \sum_{i=1}^{n} (\mu dt + \sigma \sqrt{dt} dZ_i) = \mu dt + \sum_{i=1}^{n} \sigma \sqrt{dt} \sum_{i=1}^{n} dZ_i$
```

```
$= \mu dt + \sigma \sqrt{dt} \sum_{i=1}^{n} dZ_i$
```

which gives

```
$E[X_T] = E[\mu dt + \sigma \sqrt{dt} \sum_{i=1}^{n} dZ_i]$
```

```
$E[X_T] = \mu dt + \sigma \sqrt{dt} E[\sum_{i=1}^{n} dZ_i] = \mu dt$
```
