# H.6 Proof of Eq. (H.1.7)

Since $P(ar{X}_t \ge x) = P(m_t^X \ge b, ar{X}_t \ge x) + P(m_t^X \ge b, ar{X}_t \le x)$ we have:

```
$P(m_t^X \ge b, ar{X}_t \ge x) = P(ar{X}_t \ge x) - P(m_t^X \ge b, ar{X}_t \le x) \quad (H.6.1)$
```

Substituting the results of Eqs. (H.1.4) and (H.1.6) into Eq. (H.6.1) yields:

```
$P(m_t^X \ge b, ar{X}_t \ge x) = N_1\left(\frac{vt - x}{\sigma \sqrt{t}}\right) - \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{2b - x + vt}{\sigma \sqrt{t}}\right)$
```

# H.7 Proof of Eq. (H.1.8)

We start by writing:

```
$P(m_t^X \le b) = P(ar{X}_t \le b, ar{X}_t \le b) + P(m_t^X \le b, ar{X}_t \ge b)$
```

However, $P(m_t^X \le b, ar{X}_t \le b) = P(ar{X}_t \le b)$ since the probability that the minimum is less than $b$ and the final value $ar{X}_t$ is less than $b$ is the same as the probability that the final value $ar{X}_t$ is less than $b$. Therefore:

```
$P(m_t^X \le b) = P(ar{X}_t \le b) + P(m_t^X \le b, ar{X}_t \ge b)$
```

Substituting for $P(ar{X}_t \le b)$ from Eq. (H.1.4) gives:

```
$P(m_t^X \le b) = N_1\left(\frac{b - vt}{\sigma \sqrt{t}}\right) + P(m_t^X \le b, \bar{X}_t \ge b) \quad (H.7.1)$
```

From Eq. (H.1.6):

```
$P(m_t^X \le b, \bar{X}_t \ge b) = \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{2b - b + vt}{\sigma \sqrt{t}}\right)$
```

```
$= \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{b + vt}{\sigma \sqrt{t}}\right) \quad (H.7.2)$
```

Combining Eqs. (H.7.2) and (H.7.1) yields:

```
$P(m_t^X \le b) = N_1\left(\frac{b - vt}{\sigma \sqrt{t}}\right) + \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{b + vt}{\sigma \sqrt{t}}\right)$
```
