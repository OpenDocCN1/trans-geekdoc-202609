```
$d(X_t \exp(\alpha t)) = \sigma \exp(\alpha t) dW_t \quad (2.10.4)$
```

Integrating Eq. (2.10.4) gives

```
$\int_{s=0}^{t} d(X_s \exp(\alpha s)) = \sigma \int_{s=0}^{t} \exp(\alpha s) dW_s$
```

which yields

```
$X_t \exp(\alpha t) - X_{t_0} = \sigma \int_{s=0}^{t} \exp(\alpha s) dW_s$
```

and thus the solution of Eq. (2.10.1) is

```
$X_t = X_{t_0} \exp(-\alpha t) + \sigma \int_{s=0}^{t} \exp(\alpha s) dW_s \quad (2.10.5)$
```

We will now derive expressions for both the unconditional mean and the un-conditional variance of $X_t$.

# The mean

Taking expectations of both sides of Eq. (2.10.5) yields

```
$E[X_t] = E[X_{t_0} \exp(-\alpha t)] + E[\sigma \int_{s=0}^{t} \exp(-\alpha s) dW_s] \quad (2.10.6)$
```

since

```
$E[\sigma \int_{s=0}^{t} \exp(-\alpha s) dW_s] = \sigma \exp(-\alpha t) \int_{s=0}^{t} \exp(\alpha s) dW_s] = 0$
```

the unconditional mean is

```
$E[X_t] = X_{t_0} \exp(-\alpha t) \quad (2.10.7)$
```
