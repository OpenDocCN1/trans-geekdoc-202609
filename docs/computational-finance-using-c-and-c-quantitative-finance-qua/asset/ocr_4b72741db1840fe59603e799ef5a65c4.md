We obtain

$\log\left(\frac{S_T}{S_{t0}}\right) \sim N(vT, \sigma^2 T) \quad (2.3.9)$

and so

$\log\left(\frac{S_T}{S_{t0}}\right) = vT + \sigma W_T \quad (2.3.10)$

The solution to the geometric Brownian motion (GBM) in Eq. (2.2.3) is

$S_T = S_{t0} \exp(vT + \sigma W_T), \quad v = \mu - \frac{\sigma^2}{2} \quad (2.3.11)$

The asset value at time $t+dt$ can then be generated from its value at time $t$ by using

$S_{t+dt} = S_t \exp(v dt + \sigma dW_t)$

We have shown that if the asset price follows geometric Brownian motion, then the logarithm of the asset price follows standard Brownian motion. Another way of stating this is, over the time interval $dt$, the change in the logarithm of the asset price is a Gaussian distribution with mean $(\mu - \sigma^2/2)dt$, and variance $\sigma^2 dr$.

These results can easily be generalized to include time varying drift and volatility. Now instead of Eq. (2.2.3) we have

$dS_t = S_t \mu_t dt + \sigma_t dW_t \quad (2.3.12)$

which results in

$d(\log(S_t)) = v_t dt + \sigma_t dW_t \quad (2.3.13)$

so

$\int_{t=t_0}^T d(\log(S_t)) = \int_{t=t_0}^T v_t dt + \int_{t=t_0}^T \sigma_t dW_t$

which results in the following solution for $S_T$

$S_T = S_{t0} \exp\left(\int_{t=t_0}^T v_t dt + \int_{t=t_0}^T \sigma_t dW_t\right)$ where $v_t = \mu_t - \frac{\sigma^2}{2} \quad (2.3.14)$

The results presented in Eqs. (2.3.11) and (2.3.14) are very important and will be referred to later sections of the book.

# 2.4 Girsanov's theorem

This theorem states that for any stochastic $k(t)$ such that $\int_0^t k(s)^2 ds < \infty$ then the Radon-Nikodym derivative $\frac{dQ}{dP} = \rho(t)$ is given by:

$\rho(t) = \exp\left{\int_0^t k(s) dW_s^P - \frac{1}{2} \int_0^t k(s)^2 ds\right\} \quad (2.4.1)$
