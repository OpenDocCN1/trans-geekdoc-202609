# 7.3.1 FX forward

An FX forward is a contract to exchange an amount of domestic currency for an agreed amount of foreign currency at a future time $T$. If $P^f$ is the amount (number of units) of foreign currency, and $P^d$ is the amount (number of units) of domestic currency, then the value (in domestic currency) of the FX contract at time T is:

$$FX_d(T) = P^f X_d^f(T) - P^d$$

The value of the contract at time t is this:

$$FX_d(t) = \{P^f X_d^f(t) - P^d\}DF^d(t, T)$$

where $t < T$. Substituting for $X_d(t, T)$ from Eq. (7.3.1) gives:

$$FX_d(t) = \left\{P^f X_d^f(t) \frac{DF^f(t, T)}{DF^d(t, T)} - P^d\right\}DF^d(t, T)$$

which can be re-expressed

$$FX_b(t) = P^f X_d^f(t)DF^f(t, T) - P^d DF^d(t, T) \quad (7.3.2)$$

The value of this FX forward contract in base currency is

$$FX_b(t) = \{P^f X_d^f(t)DF^f(t, T) - P^d DF^d(t, T)\}X_b^d$$

That is,

$$FX_b(t) = P^f X_d^f(t)DF^f(t, T) - P^d DF^d(t, T)X_b^d \quad (7.3.3)$$

where we used the fact that $X_d^f(t) = X_d^b(t)$.

An alternative way of expressing Eq. (7.3.3) is as:

$$FX_b(t) = P^f \{X_d^f(t)DF^f(t, T) - KDF^d(t, T)X_d^b(t)\} \quad (7.3.4)$$

where $K = P^d/P^f$. In the next section we will see that $K$, the agreed rate to be for one unit of foreign currency in units of domestic currency, corresponds to the strike of an FX call option.
