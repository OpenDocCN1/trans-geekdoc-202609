## Compute the Monte Carlo estimate

The Monte Carlo estimate, $\theta_H$, is computed as the average of $\theta_H^p, p = 1, \dots, n_{sim}$, where $n_{sim}$ is the number of simulations:

```
$\theta_H = \sum_{i=1}^{n_{sim}} \theta_H^i$
```

In code excerpt 5.21, we provide a computer program which prices single asset American put and call options using a stochastic lattice. The method used by the program is depth first procedure outlined in Broadie and Glasserman (1997), which has the advantage that the memory requirements are only of order $b \times d$; as before, b is the number of branches per node and $d$ is the number of time intervals.

Here here we assume the underlying asset GBM and the function normal (M, S) to generate a normal distribution with M and standard deviation S. We can then check the accuracy of the simulation with that obtained by a closed form which assumes a lognormal distribution, in this case the formula in Geske and Janson (1984).

However, the power of this method is when the underlying asset follows a more realistic process which is non-Gaussian and time-varying. The only modification to code is to replace the call to normal with another distribution and time-varying parameters.

```c
// Stochastic lattice for computing the value of American and European options via Monte Carlo
// Here we assume the asset prices follow a lognormal distribution, so we generate normal variables; this can be easily removed.
void main() {
    int i, j;
    is_put, is_american, w[200], num_simulations, b;
    double T, time_step, sqrt_time, opt_value, pay_off, log_fac, asset_price;
    double opt_time, opt_val, sum_opt_val, drift, std_term, S0, q, r, sigma=0;
    double tot_opt_val[10];
    printf("Stochastic lattice for computing the value of American and European options");
    is_put = 1; // If is_put == 0 a call option, otherwise a put option
    T = 1.0; // The maturity of the option
    sigma = 2; // The volatility of the underlying asset
    X = S0; // The strike price of the underlying asset
    r = 0.05; // The free interest rate
    q = 0.2; // The continuous dividend yield
    d = 4; // The number of time intervals
    time_step = T/d; // The time intervals
    sqrt_time = sqrt(time_step); // The standard deviation of each variate
    drift_term = (r - sigma/2); // The mean of each variate
    seed = 1; // The seed for the random number generator
    srand(seed);
    tot_opt_val = 0;
    num_simulations = 100;
    for (j = 1; j <= num_simulations; j++) {
        sum_opt_val = 0;
        j = 0;
        asset_price = S0;
        for (j = 2; j <= d; j++) {
            log_fac = normal(drift_term, std_term);
            asset_price = asset_price*exp(log_fac);
            v[j] = asset_price;
        }
        j = 0;
        while (j < d) {
            if (j == d && (w[j] < b)) { // CASE 1: Terminal node, asset prices for b branches
                if (is_put) {
                    pay_off = MAX(X - v[j][j], 0);
                } else {
                    pay_off = MAX(v[j][j]-X, 0);
                }
                v[j][j] = pay_off;
                asset_price = v[j-1];
                log_fac = normal(drift_term, std_term);
                v[j][j] = asset_price*exp(log_fac);
                w[j] = j + 1;
            } else if (j != d && (w[j] >= b)) { // CASE 2: Terminal node, set option value for last branch (parent node refers to t+1) Also generate a new node and set asset values.
                for (i = j; i <= b; i++) {
                    sum_opt_val += v[i][j+1];
                }
                temp = sum_opt_val/(double)b;
                hold = temp; // An American option
                if (is_put) {
                    pay_off = MAX(X - w[j][j], 0);
                } else {
                    pay_off = MAX(w[j][j]-X, 0);
                }
                opt_val = MAX(pay_off, hold);
            } else { // European option
                opt_val = hold;
            }
            v[j][j] = opt_val;
            if (j < d) {
                asset_price = v[j-1];
                log_fac = normal(drift_term, std_term);
                v[j][j] = asset_price*exp(log_fac);
                w[j] = j + 1;
                for (i = 1; i <= d; i++) { // Generate a new node
                log_fac = normal(drift_term, std_term);
                asset_price = asset_price*exp(log_fac);
                v[i] = asset_price;
                }
                j = d;
            } else {
                j = 0;
            }
        }
        else if ((j < d) && (w[j] == b)) { // CASE 4:Internal node, calculate option value for the last branch
            sum_opt_val = 0;
            for (i = j; i <= b; i++) {
                sum_opt_val += v[i][j+1];
            }
            temp = sum_opt_val/(double)b;
            hold = temp; // An American option
            if (is_put) {
                pay_off = MAX(X - w[j][j], 0);
            } else {
                pay_off = MAX(w[j][j]-X, 0);
            }
            opt_val = MAX(pay_off, hold);
        } else { // European option
            opt_val = hold;
        }
        v[j][j] = opt_val;
        w[j] = 0;
        j = j - 1;
    }
    tot_opt_vals = tot_opt_vals + opt_v[1]; // Sum the option values for each simulation
    opt_value = tot_opt_vals/(double)num_simulations; // Compute the average option value
    printf("The estimated option is %12.4f\n", opt_value);
}
```
