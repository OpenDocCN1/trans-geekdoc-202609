Now since $\phi$ is a martingale under $Q^{k+1}$ we know that $D = 0$, and therefore Eq. (7.2.65) results in:

```
$$(1 + F_{k+1})F_k\mu_k \, dt = -ho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} \, dt$$
```

This means the drift is:

```
$$\mu_k = -\frac{ho_{k,k+1}\sigma_k\sigma_{k+1}}{1 + F_{k+1}}$ $$(7.2.66)$
```

Substituting for $\mu_k$ in Eq. (7.2.61) gives:

```
$$dF_k = F_k\sigma_k \left\{ \frac{ho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \ dt + dW^{k+1} \right\}$$ $$(7.2.67)$
```

Comparing Eq. (7.2.67) with Eq. (7.2.40) we have:

```
$$dW^k = -\frac{ho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \, dr + dW^{k+1}$$ $$(7.2.68)$
```

which is the relationship between Brownian motions $dW^k$ and $dW^{k+1}$.

$i \geq k+2$
Let the stochastic process followed by $F_k$ under $Q^{k+1}$ be:

```
$$dF_k = F_k\mu_k \, dt + F_k\sigma_k \, dW^{k+2}$$ $$(7.2.69)$
```

Where $W^k$ is Brownian motion under probability measure $Q^{k+2}$, and drift term $\mu_k$ is to be found.
Replacing $k$ with $k+1$ in Eq. (7.2.68) gives:

```
$$dW^{k+1} = -\frac{ho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}} \, dr + dW^{k+2}$$ $$(7.2.70)$
```

and using Eq. (7.2.70) to substitute for $dW^{k+1}$ in Eq. (7.2.68) gives:

```
$$dW^k = -F_k\sigma_k \left\{ \frac{ho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \, dt - \frac{ho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}} \, dt \right\}$$ $$(7.2.71)$
```

Substituting for $dW^k$ in Eq. (7.2.40) gives:
and thus the drift is

```
$$\mu_k = -\frac{ho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} - \frac{ho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}}$$ $$(7.2.72)$
```

The following general expression can be derived in a similar manner:

```
$$dF_k = -F_k\sigma_k \sum_{j=k+1}^i \frac{ho_{k,j}\sigma_k\sigma_j}{1 + F_j} \, dt + \sigma_k F_k \, dW^i$ $$(7.2.73)$
```

where all the symbols have the same means as before, but now $i$ can take any integer value greater than $k$.
