
So substituting the above expression into Eq. (2.10.8)

$Var[X_t] = E\left[\left{\{exp(-\alpha t)\sigma \int_{s=0}^{t} \exp(\alpha s) dW_s\right\}^2\right]$ (2.10.9)

$Var[X_t] = \sigma^2 \exp(-2\alpha t) E\left[\left{\{\int_{s=0}^{t} \exp(\alpha s) dW_s\right\}^2\right]$ (2.10.10)

Using Ito’s isometry (see Section 2.12.2)

$E\left[\left{\{\int_{s=0}^{t} \exp(\alpha s) dW_s\right\}^2\right] = E\left[\int_{s=0}^{t} {{\exp(\alpha s)\}^2} ds\right]$

Then using Fubini’s theorem (see Section 2.12.11)

$E\left[\int_{s=0}^{t} {{\exp(\alpha s)\}^2} ds\right] = E\left[\int_{s=0}^{t} \exp(2\alpha s) ds\right] = \int_{s=0}^{t} \exp(2\alpha s) ds = \frac{\left{\exp(2\alpha s)\right\}_{s=0}^{t}}{2\alpha} = \frac{\exp(2\alpha t)-1}{2\alpha}$

Substituting the above result into Eq. (2.10.10)

$Var[X_t] = \sigma^2 \exp(-2\alpha t) \left{\{\frac{\exp(2\alpha t)-1}{2\alpha}\right\}$

which yields the following expression for the variance

$Var[X_t] = \sigma^2 \left{\{\frac{1-\exp(-2\alpha t)}{2\alpha}\right\}$ (2.10.11)

The expressions for the mean and variance derived in Eqs. (2.10.7) and (2.10.11) allow us to write the distribution of $X_t$

$X_t \sim N(X_{t_0} \exp(-\alpha t), \sigma^2 \left{\{\frac{1-\exp(-2\alpha t)}{2\alpha}\right\right})$ (2.10.12)

which, if $X_{t_0} = 0$, reduces to

$X_t \sim N(0, \sigma^2 \left{\{\frac{1-\exp(-2\alpha t)}{2\alpha}\right\right})$ (2.10.13)

The transition density from $X_{t_0}$ to $X_t$ is:

$P(X_t|X_{t_0}) = \sqrt{\frac{K}{2\pi(1-\gamma^2)}} \exp\left{\left{\frac{K(X_t-X_{t_0})\exp(-\alpha(t-t_0))^2}{1-\gamma^2}\right\right\}$ (2.10.14)

where $K = 2\alpha/\sigma^2$ and $\gamma = \exp(-\alpha(t-t_0))$.

# Introduction to stochastic processes

Ornstein–Uhlenbeck stochastic paths can be simulated using

$X_{t+dt} = X_t \exp(-\alpha dt) + \sigma \sqrt{\frac{1 - \exp(-2\alpha dt)}{2\alpha}} dZ \quad (2.10.15)$

From Eq. (2.10.14) we can write

$E[X_{t+dt}|X_t] = X_t \exp(-\alpha dt)$

$Var[X_{t+dt}|X_t] = \sigma^2 \left\{ \frac{1 - \exp(-2\alpha dt)}{2\alpha} \right\}$

We will show that in the limit $dt \to 0$, Eq. (2.10.15) reduces to the Ornstein–Uhlenbeck process given in Eq. (2.10.1). For small $dt$ we can take a first-order expansion of the exponentials in Eq. (2.10.15) to obtain

$X_{t+dt} = X_t \{(1 - \alpha dt)\} + \sigma \sqrt{\frac{(1 - (1 - 2\alpha dt))}{2\alpha}} dZ$

so

$X_{t+dt} = X_t - X_t \alpha dt + \sigma \sqrt{\frac{2\alpha dt}{2\alpha}} dZ$

Therefore

$X_{t+dt} = X_t - \alpha X_t dt + \sigma \sqrt{dt} dZ$

which is

$dX_t = -\alpha X_t dt + \sigma dW_t$

## 2.11 The Ornstein–Uhlenbeck bridge

An Ornstein–Uhlenbeck process have value $X_{t_0}$ at time $t_0$ and $X_{t_1}$ at time $t_1$. We are interested in the distribution of $X_t$ at an intermediate point, of $P(X_t|X_{t_0}, X_{t_1}})$, where $t_0 < t < t_1$. We will show that $X_t$ is a Gaussian with conditional mean

$\mu_t = X_{t_0} \exp(-\alpha(t - t_0)) \left\{ \frac{1 - \exp(-2\alpha(t - t_0))}{\gamma^2}\right\} + X_{t_1} \exp(-\alpha(t - t_1)) \left\{ \frac{1 - \exp(-2\alpha(t - t_1))}{\gamma^2}\right\}$ (2.11.1)

and conditional variance

$V_t = \frac{(1 - \exp(-2\alpha(t - t_0)))(1 - \exp(-2\alpha(t_1 - t)))}{\alpha(1 - \exp(-2\alpha(t_1 - t_0))}$ (2.11.2)

where $\gamma = \exp(-\alpha(t_1 - t_0))$.

PROOF. The standard Ornstein-Uhlenbeck process ($\sigma = 1$) is defined by:

$dX_t = -\alpha X_t dt + dZ_t$ (2.11.3)

From Section 2.10 we have

$X_t = X_{t_0} \exp(-\alpha(t-t_0)) + \sigma \sqrt{\frac{1 - \exp(-2\alpha(t-t_0))}{2\alpha}} dZ_t$ (2.11.4)

and transition density from $X_{t_0}$ to $X_t$ is

$P(X_t|X_{t_0}) = \frac{\sqrt{2\alpha}}{\sqrt{2\pi(1 - \exp(-2\alpha(t-t_0))}} \exp\left\{ \frac{\alpha(X_t-X_{t_0})\exp(-\alpha(t-t_0))}{1 - \exp(-2\alpha(t-t_0))}\right\}$ (2.11.5)

The joint density of $X_t$ and $X_{t_1}$ given $X_{t_0}$ is:

$P(X_t, X_{t_1}|X_{t_0}) = P(X_t|X_{t_1})P(X_{t_1}|X_{t_0})$ (2.11.6)

We have:

$P(X_t, X_{t_1}|X_{t_0}) = \kappa \exp\left\{ \frac{\alpha(X_t-X_{t_0})\exp(-\alpha(t-t_0))}{1 - \exp(-2\alpha(t-t_0))}\right\} \times \exp\left\{ \frac{\alpha(X_{t_1}-X_{t_0})\exp(-\alpha(t_1-t))}{1 - \exp(-2\alpha(t_1-t))}\right\}$

where

$\kappa = \frac{1}{2\pi} \sqrt{(1 - \exp(-2\alpha(t-t_0)))(1 - \exp(-2\alpha(t_1-t))}$

The distribution of $X_t$ given $X_{t_0}$ and $X_{t_1}$, is

$P(X_t|X_{t_0}, X_{t_1}) = \frac{P(X_t, X_{t_1}|X_{t_0})}{P(X_{t_1}|X_{t_0})}$ (2.11.7)

where

$P(X_{t_1}|X_{t_0}) = \frac{\sqrt{2\alpha}}{\sqrt{2\pi(1 - \exp(-2\alpha(t_1-t_0)))}} \times \left\{ \frac{\alpha(X_{t_1}-X_{t_0})\exp(-\alpha(t_1-t_0))}{1 - \exp(-2\alpha(t_1-t_0))}\right\}$

After some algebra we can re-express Eq. (2.11.7) as

$P(X_t|X_{t_0}, X_{t_1}) = \sqrt{\frac{\alpha}{\pi\phi_{t_1}}} \exp[A]$ (2.11.9)

where

$A = -\frac{\alpha}{\phi}(B_1 + B_2 - B_3)$

$B_1 = \{X_{t_0}^2 + X_{t_0}^2 \exp(-\alpha(t - t_0)) - 2X_t X_{t_0} \exp(-\alpha(t - t_0)) \times \left\{\frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2}\right\}$ (2.11.10)

$B_2 = \{X_{t_1}^2 + X_{t_1}^2 \exp(-\alpha(t - t_1)) - 2X_t X_{t_1} \exp(-\alpha(t - t_1)) \times \left\{\frac{1 - \exp(-2\alpha(t - t_1))}{1 - \gamma^2}\right\}$ (2.11.11)

$P(X_t|X_{t_0}, X_{t_1}) = \frac{1}{\sqrt{2\pi V_t}} \exp\left(-\frac{(X_t-\mu_t)^2}{2V_t}\right)$ (2.11.13)

$V_t = \frac{(1 - \exp(-2\alpha(t - t_0)))(1 - \exp(-2\alpha(t_1 - t)))}{1 - \exp(-2\alpha(t_1 - t_0))} = \frac{\phi_t}{2\alpha}$

The conditional mean can be obtained by noting that $X_{t_0}$ and $X_{t_1}$ are constants and the coefficients of $X_t$ and $X_t^2$ in Eq. (2.11.14) must be the same. Comparing coefficients of $X_t$ we have proved:

$-2\mu_t = -2X_{t_0} \exp(-\alpha(t - t_0)) \left\{ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2}\right\} - 2X_{t_1} \exp(-\alpha(t_1 - t)) \left\{ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2}\right\}$

$\mu_t = X_{t_0} \exp(-\alpha(t - t_0)) \left\{ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2}\right\} + X_{t_1} \exp(-\alpha(t_1 - t)) \left\{ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2}\right\}$

This completes the proof.

# Relation to the Brownian bridge

We will prove that in the limit $(t_1 - t_0) \rightarrow 0$ the Brownian bridge result is obtained.
For the conditional mean, we have:

$\mu = X_{t_0} \exp(-\alpha(t - t_0)) \left\{ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2}\right\} + X_{t_1} \exp(-\alpha(t_1 - t)) \left\{ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2}\right\}$

where:

$\gamma = \exp(-\alpha(t_1 - t_0))$

which is:

$\mu = X_{t_0} \left\{ \frac{\exp(-\alpha(t - t_0)) - \exp(-2\alpha(t_1 - t_0))}{1 - \exp(-2\alpha(t_1 - t_0) - \alpha(t - t_0))} \right\} + X_{t_1} \left\{ \frac{\exp(-\alpha(t_1 - t_0)) - \exp(-2\alpha(t - t_0) - \alpha(t_1 - t))}{1 - \exp(-2\alpha(t_1 - t_0))} \right\}$

For small $t_1 - t_0$ both $t_1 - t$ and $t - t_0$ are small, so:

$\mu \rightarrow X_{t_0} \left\{ \frac{1 - \alpha(t - t_0)\} - \{1 - 2\alpha(t_1 - t) - \alpha(t)\}}{1 - \{1 - 2\alpha(t_1 - t_0)\}\right\} + X_{t_1} \left\{ \frac{1 - \alpha(t_1 - t)\} - \{1 - 2\alpha(t - t_0) - \alpha(t_1)\}}{1 - \{1 - 2\alpha(t_1 - t_0)\}\right\}$

which yields the Brownian bridge result for the conditional:

$\mu \rightarrow X_{t_0} \frac{t_1 - t_0}{t_1 - t_0} + X_{t_1} \frac{t - t_0}{t_1 - t_0}$
