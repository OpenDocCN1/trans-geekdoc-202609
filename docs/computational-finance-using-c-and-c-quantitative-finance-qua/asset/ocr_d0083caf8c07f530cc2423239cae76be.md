$\Delta\Pi = -\sum_{i=1}^n \mu_i S_i\Delta t\frac{\partial f}{\partial S_i}-\Delta t\frac{\partial f}{\partial t}-\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}$

```
\sum_{i=1}^n \sigma_i S_i\Delta t\frac{\partial f}{\partial S_i\|+\sum_{i=1}^n \mu_i S_i\Delta t\frac{\partial f}{\partial S_i}
```

```
\sum_{i=1}^n \sigma_i S_i\Delta t\frac{\partial f}{\partial S_i} \quad (4.4.21)
```

Cancelling terms we obtain:

```
\Delta\Pi = -\Delta t(\frac{\partial f}{\partial t\|+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}) \quad (4.4.22)
```

If this portfolio is at at riskless interest rate r we have:

$r\Delta t = \Delta\Pi$

So Eq. (4.4.22) we have that:

```
\Delta\Pi = -\Delta t(\frac{\partial f}{\partial t\|+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}) \quad (4.4.23)
```

Substituting for $\Pi$ we obtain:

```
$r\Delta t = f-\\sum_{i=1}^n S_i\frac{\partial f}{\partial S_i}-\Delta t+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j} \quad (4.4.24)
```

Rearanging Eq. (4.4.24) gives:

```
\frac{\partial f}{\partial t\|+\sum_{i=1}^n S_i\frac{\partial f}{\partial S_i\|+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}=rf \quad (4.4.25)
```

which is the $n$-dimensional Black–Scholes partial differential equation.

# 4.4.3 The Black–Scholes formula

The Black-Scholes model consists of two assets: the riskless money account and an equity. It can be cast as the following two-dimensional Ito equation:

```
$dS_t=\mu_S S_t dt+\sigma_S S_t dW^P \quad (4.4.26)
```

```
$dB_t=rB_t dt
```

where $W^P$ is Brownian motion (without drift) under measure $\mathbb{P}$, so $dW^P \sim N(0,dt)$.
