# A.2 Gamma

Gamma is defined as the second derivative of the option value with respect to the underlying stock price. This means (see Section A.3) it is the rate of delta with to the underlying stock price.

For a European call the value of gamma is:

```
$$$\Gamma_c = \frac{\partial^2 \Delta_c}{\partial S^2} = \frac{\partial \Delta_c}{\partial S}\frac{\partial \Delta_c}{\partial S}\{N_1(d_1)exp(-q(T-t))\}$$
```

where value of $\Delta_c$ is given in Section A.3. So

```
$$$\Gamma_c = exp(-q(T-t))frac{\partial d_1}{\partial S} = exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial S}$$
```
