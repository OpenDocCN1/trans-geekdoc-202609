In these circumstances we have:

```
$$a^2 + b^2 + 1 = \exp(2r\Delta t) + \exp(2r\Delta t)\{exp(\sigma^2\Delta t) - 1\}+1$
\sim 1 + 2r\Delta t + (1 + 2r\Delta t)\sigma^2\Delta t \sim 1 + 2r\Delta t + \sigma^2\Delta t$
```

Therefore,

```
$$\sqrt{(a^2 + b^2 + 1)^2 - 4a^2} \sim \sqrt{(2 + 2r\Delta t + \sigma^2\Delta t)^2 - 4(1 + 2r\Delta t)}$$
\sim \sqrt{4 + 8r\Delta t + 4\sigma^2\Delta t - 4 - 8r\Delta t}
\= \sqrt{4\sigma^2\Delta t} = 2\sigma\sqrt{\Delta t}
```

and so

```
$$u \sim \frac{2 + 2r\Delta t + \sigma^2\Delta t + 2\sigma\sqrt{\Delta t}}{2\exp(r\Delta t)}$$
$$$u \sim (1 + r\Delta t + \frac{\sigma^2\Delta t}{2} + \sigma\sqrt{\Delta t})(1 - r\Delta t)$$
$$$u \sim 1 + r\Delta t + \frac{\sigma^2\Delta t}{2} + \sigma\sqrt{\Delta t} - r\Delta t = 1 + \sigma\sqrt{\Delta t} + \frac{\sigma^2\Delta t}{2}$
```

which to order dt gives:

```
$$u = \exp(\sigma\sqrt{\Delta t}) \quad and \quad d = \exp(-\sigma\sqrt{\Delta t})$$ (5.3.20)
```

where we have used

```
$$\exp(\sigma\sqrt{\Delta t}) = 1 + \sigma\sqrt{\Delta t} + \frac{\sigma^2\Delta t}{2} + \frac{\sigma^3(\Delta t)^{3/2}}{6} + \dots$$
```

and

```
$$d = \frac{1}{u}$$
```

It is interesting to note (by substituting into Eq. (5.3.19)) when $r = 0$ and $\Delta t \to 0$, we have $p = \frac{\sigma}{2}$.

Now we know the values of the lattice with a specified number of time steps. Once this has been constructed, it can be used to compute the values and Greeks for various types of financial options. These could simply be American/European vanilla options, or more exotic options that incorporate features such as: *lockout periods*, *barriers*, and nonstandard payoff functions.

We will discuss how to create a lattice which can be used for American and European vanilla options.

If the current value of the underlying asset is $S$, and the duration of the option is $\tau$ and we use a lattice with $n$ equally spaced time intervals $\Delta t$, then we have:

```
$$\Delta t = \frac{\tau}{n}$$
```
