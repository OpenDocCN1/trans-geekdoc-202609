Similarly the process followed by the price of a foreign equity $S^f$ under the foreign risk neutral measure $\mathbb{F}$ is:

```
$dS^f = S^f r^f dt + \sigma_s S^f dW_s^f \quad (7.5.12)$
```

However, the process followed by the price of a foreign equity under the domestic risk neutral measure $\mathbb{Q}$ is:

```
$dS^f = S^f (r^f + \alpha) dt + \sigma_s S^f dW_s^Q \quad (7.5.13)$
```

where $\alpha$ (the *quantum adjustment*) is to be determined.
We will now derive the value for $\alpha$, and use this to price both quanto forwards and quanto options.

# Determining the quantum adjustment, $\alpha$

Since $X_d^B B^f$ and $X_d^B S^f$ are domestic tradables it means the relative prices $X_d^B B^f/X_d^B B^d$ and $X_d^B S^f/X_d^B B^d$ are also martingales under the probability measure $\mathbb{Q}
Now $X_d^B B^f/X_d^B B^d$ is a martingale,

```
$d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight) = \sigma_x \frac{X_{Bd}^B B^f}{X_{Bd}^B B^d} dW_Q^x \quad (7.5.14)$
```

We will start by writing $X_d^B B^f/B^d$ as $(S^f/B^f)(X_d^B B^f/X_d^B B^d)$. Using the Ito
product rule we have:

```
$d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight) = d\left(\frac{S^f}{B^f}ight)d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight) + E\left[d\left(\frac{S^f}{B^f}ight)d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight)ight] \quad (7.5.15)$
```

Substituting for $d(X_d^B B^f/X_d^B B^d)$ from Eq. (7.5.14) into Eq. (7.5.15) gives:

```
$d\left(\frac{S^f}{B^f}\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight) = d\left(\frac{S^f}{B^f}ight)d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight) + \sigma_x \frac{S^f}{B^f}\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d} dW_Q^x + + E\left[d\left(\frac{S^f}{B^f}ight)d\left(\frac{X_{Bd}^B B^f}{X_{Bd}^B B^d}ight)ight] \quad (7.5.16)$
```

