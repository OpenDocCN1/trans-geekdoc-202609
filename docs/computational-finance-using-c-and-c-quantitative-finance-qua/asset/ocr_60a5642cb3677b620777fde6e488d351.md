# Case i > k

We now consider the case when the maturity of the numeraire $DF_i$ is after the expiry of the forward rate $F_k$.

$i = k+1$

Here $DF_{k+1}$ is the numeraire and $F_k$ is the forward rate which starts at time $t_{k-1}$ and ends at time $t_k$.

Since $DF_{k-1}$ is a tradable price, $\phi = DF_{k-1}/DF_{k+1}$, is a martingale under $Q^{k+1}$, and has zero drift.

Now:

```
$\phi = \frac{DF_{k-1}}{DF_{k+1}} = (1+	au F_k)(1+	au F_{k+1})$
```

where the processes for $F_{k+1}$ and $F_k$ are are

```
$dF_{k+1} = F_{k+1}\sigma_{k+1}dW^{k+1}$
```

```
$dF_k = F_k\mu_k dt + F_k\sigma_k dW^{k+1}$
```

and the drift, $\mu_k$, is to be determined.
Using Ito have:

```
$d\phi = \frac{\partial \phi}{\partial F_k}dF_k + \frac{\partial \phi}{\partial F_{k+1}}dF_{k+1} + \frac{1}{2}\sum_{i=k}^{k+1}\sum_{j=k}^{k+1}\frac{\partial^2 \phi}{\partial F_i \partial F_j}E[dF_i, dF_j]$
```

where

```
$\frac{\partial \phi}{\partial F_k} = 	au(1+	au F_{k+1}), \quad \frac{\partial \phi}{\partial F_{k+1}} = 	au(1+	au F_k)$
```

```
$\frac{\partial^2 \phi}{\partial F_k^2}\frac{\partial^2 \phi}{\partial F_k^2} = 0, \quad \frac{\partial^2 \phi}{\partial F_k \partial F_{k+1}}\frac{\partial^2 \phi}{\partial F_{k+1}^2} = \tau^2$
```

```
$E[dF_k, dF_{k+1}] = [dF_k, dF_{k+1}] = \rho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} dt$
```

Substituting the values in (7.2.63) into Eq. (7.2.62) we obtain:
After expanding the terms in $d\phi$ and $dF_k$ we have:

```
$d\phi = 	au(1+	au F_{k+1})dF_k + (1+	au F_k)dF_{k+1} + \tau^2\rho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} dt$
```

```
$\phi = \tau(1+	au F_{k+1})\{F_k\mu_k dt + F_k\sigma_k dW^{k+1}\} + \tau(1+	au F_k)F_{k+1}\sigma_{k+1} dW^{k+1} + \tau^2\rho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} dt$
```

and this can be re-expressed as

```
$d\phi = D + \tau(1+	au F_{k+1})F_k\sigma_k dW^{k+1} + \tau(1+	au F_k)F_{k+1}\sigma_{k+1} dW^{k+1}$
```

where the drift $D$ in Eq. (7.2.64) is given by:

```
$D = \tau(1+	au F_{k+1})F_k\mu_k dt + \tau^2\rho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} dt$
```
