# D.4 The general error distribution

This section proves various relations for the generalized error distribution.
The density function for the generalized error distribution is:

```
$f(\epsilon_i) = \mathcal{K} \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) \text{ where } \mathcal{K} = \frac{a}{\lambda 2^{(1+1/a)}}\Gamma(1/a)} \quad (D.4.1)$
```

# D.4.1 Value of $\lambda$ for variance $h_i$

Calculation of the scale factor $\lambda$ required for a generalized error distribution with mean zero and variance $h_i$.
The variance of the distribution, $E(\epsilon_i^2)$, is given by:

```
$E(\epsilon_i^2) = \mathcal{K} \int_{-\infty}^{\infty} \epsilon_i^2 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i = 2\mathcal{K} \int_{0}^{\infty} \epsilon_i^2 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i$
```

Using the standard integrals in Section E.1 with $n=2, p=a$, and $b=\frac{1}{2}(\lambda)^a$ gives:

```
$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\\frac{3}{a} \left(\\frac{1}{2}\lambda\right)\right)^{-3/a}$
```

which after some simplification yields:

```
$h_i = \frac{2\mathcal{K}^{2/a}/\lambda^2}{a} \Gamma\left(\frac{3}{a}\right)$
```

Substituting for $\mathcal{K}$ and simplifying then gives:

```
$h_i = \lambda^{22/a} \frac{\Gamma(3/a)}{\Gamma(1/a)}$
```

The required value of $\lambda$ is therefore:

```
$\lambda = \left\{h_i^{-2/a} \frac{\Gamma(1/a)}{\Gamma(3/a)}\right\}^{1/2}$
```

# D.4.2 The kurtosis

```
$E(\epsilon_i^4) = \mathcal{K} \int_{-\infty}^{\infty} \epsilon_i^4 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i = 2\mathcal{K} \int_{0}^{\infty} \epsilon_i^4 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i$
```

However, from standard mathematical tables:

```
$\int_{0}^{\infty} \epsilon_i^4 \exp(-b\epsilon_i^p) = \frac{\Gamma(k)}{pb^k}$
```

where $p=a, b=\frac{1}{2}(\lambda)^a$, and $k=5/a$ which gives:

```
$E(\epsilon_i^4]) = \frac{2\mathcal{K}^{2/a}\lambda^5}{a} \Gamma\left(\frac{5}{a}\right)$
```
