Integrating both sides

## Problem 3

Solve

$dX_t = -X_t dt + \exp(-t) dW_t$$

Rearranging yields

$dX_t + X_t dt = \exp(-t) dW_t$$

Using the integrating factor $\exp(t)$ we obtain

$$\exp(t) dX_t + \exp(t)X_t dt = dW_t$$

and

$$d(\exp(t)X_t) = \exp(t) dX_t + \exp(t)X_t dt$$

which means that

$$d(\exp(t)X_t) = dW_t \text{ and } \int_{s=0}^{t} d(\exp(s)X_s) = \int_{s=0}^{t} dW_s$$

Integrating

$X_t \exp(t) - X_{t_0} = W_t - W_{t_0}$

Since $W_{t_0} = 0$

$X_t \exp(t) - X_{t_0} = W_t$

that is

$X_t = X_{t_0} \exp(-t) + W_t \exp(-t)$

## Problem 4

Prove

$$\int_{s=0}^t W_s^2 dW_s = \frac{1}{3}W_t^3 - \int_{s=0}^t W_s ds$$

Using Itô's formula

$$d(W_t^3) = 3W_t^2 dW_t + \frac{6}{2}W_t dt$$

Therefore

$$\int_{s=0}^t d(W_t^3) = 3 \int_{s=0}^t W_s^2 dW_s + 3 \int_{s=0}^t W_s ds$$

and

$$W_t^3 - W_0^3 = 3 \int_{s=0}^t W_s^2 dW_s + 3 \int_{s=0}^t W_s ds$$

Using $W_0 = 0$ we obtain

$$\int_{s=0}^t W_s^2 dW_s = \frac{1}{3}W_t^3 - \int_{s=0}^t W_s ds$$

So

$$\int_{s=0}^t W_s^2 dW_s = \frac{1}{3}W_t^3 - \int_{s=0}^t W_s ds$$

## Problem 5

$dY_t = r dt + \alpha Y_t dW_t$, where $r$ and $\alpha$ are real constants.

Use the integrating factor $F_t = \exp(-\alpha W_t + \frac{\alpha^2}{2}t)$

$$dY_t - \alpha Y_t dt = r dt$$

Multiplying by $F_t$

$$dY_t \exp(-\alpha W_t + \frac{\alpha^2}{2}t) - \alpha Y_t \exp(-\alpha W_t + \frac{\alpha^2}{2}t) = r \exp(-\alpha W_t + \frac{\alpha^2}{2}t) dt$$

Using Itô's formula

$$d(Y_t \exp(-\alpha W_t + \frac{\alpha^2}{2}t)) = dY_t \exp(-\alpha W_t + \frac{\alpha^2}{2}t) - \alpha Y_t \exp(-\alpha W_t + \frac{\alpha^2}{2}t) dW_t = r \exp\left(-\alpha W_t + \frac{\alpha^2}{2}t\right)dt$$

Integrating

$$\int_{s=0}^t d\left(Y_s \exp\left(-\alpha W_s + \frac{\alpha^2}{2}s\right)\right) = r \int_{s=0}^t \exp\left(-\alpha W_s + \frac{\alpha^2}{2}s\right)ds$$

$$Y_t \exp\left(-\alpha W_t + \frac{\alpha^2}{2}t\right) - Y_0 \exp\left(-\alpha W_0\right) = r \int_{s=0}^t \exp\left(-\alpha W_s + \frac{\alpha^2}{2}s\right)ds$$

Using $W_0 = 0$ yields

$Y_t \exp\left(-\alpha W_t + \frac{\alpha^2}{2}t\right) = Y_0 + r \int_{s=0}^t \exp\left(-\alpha W_s + \frac{\alpha^2}{2}s\right)ds$

So

$Y_t = Y_0 \exp\left(-\alpha W_t + \frac{\alpha^2}{2}t\right) + r \int_{s=0}^t \exp\left(-\alpha (W_t-W_s) + \frac{\alpha^2}{2}(t-s)\right)ds$

## Problem 6

### 6(a)

Solve

$dX_t = (m - X_t)dt + \sigma dW_t$

where $m$ and $\sigma$ are constants.

Rearranging

$dX_t + X_t dt = m dt + \sigma dW_t$

Use the integrating factor $\exp(t)$

$$d(\exp(t)X_t) = \exp(t)dX_t + \exp(t)X_t dt = m \exp(t) dt + \sigma \exp(t) dW_t$$

Integrating

$$\int_{s=0}^t d(\exp(s)X_s) = \exp(t)X_t - X_0 = m(\exp(t) - 1) + \sigma \int_{s=0}^t \exp(s) dW_s$$

which can be expressed

$X_t = X_0 \exp(-t) + m(1 - \exp(-t)) + \sigma \int_{s=0}^t \exp(s-t) dW_s$

### 6(b)

Taking expectations of the expression for $X_t$ derived in part (a)

$E[X_t] = X_0 \exp(-t) + m(1 - \exp(-t))$ where we used $E[\int_{s=0}^t \exp(s) dW_s] = 0$

$Var[X_t] = E[(X_t - E[X_t])^2] = E\left[\left(\sigma \int_{s=0}^t \exp(s-t) dW_s\right)^2\right]$

From Itô's isometry

$$Var[X_t] = \sigma^2 \int_{s=0}^t \exp(2(s-t)) ds = \sigma^2 \left[ \frac{1}{2}\exp(2(s-t)) \right]_0^t = \frac{\sigma^2}{2}(1 - e^{-2t})$$

## Problem 7

Consider the equation $dS_t = \mu_t S_t dt + \sigma_t S_t dW_t$ where the value of $S_t$ at time $t=0$ is denoted by $S_0$.

- (a) Show that the mean is $E[\log(S_t)] = \log(S_0) + \int_{\tau=0}^t \left(\mu_\tau - \frac{\sigma_\tau^2}{2}\right) d\tau$
- (b) Show that the variance is $Var[\log(S_t)] = \int_{\tau=0}^t \sigma_\tau^2 d\tau$

### 7(a)

$\phi = \log(S)$ then using Itô's formula we have

$$d\phi = \frac{\partial \phi}{\partial S}dS + \frac{1}{2}\frac{\partial^2 \phi}{\partial S^2}E[(dS)^2] = \frac{1}{S}(\mu_t S_t dt + \sigma_t S_t dW_t) - \frac{1}{2S^2}\sigma_t^2 dt$$

So

$$d(\log(S_t)) = \left(\mu_t - \frac{\sigma_t^2}{2}\right)dt + \sigma_t dW_t$$

and therefore

$$\int_{\tau=0}^t d(\log(S_\tau)) = \int_{\tau=0}^t \left(\mu_\tau - \frac{\sigma_\tau^2}{2}\right)d\tau + \int_{\tau=0}^t \sigma_\tau dW_\tau$$

which gives

$$\log(S_t) - \log(S_0) = \int_{\tau=0}^t \left(\mu_\tau - \frac{\sigma_\tau^2}{2}\right)d\tau + \int_{\tau=0}^t \sigma_\tau dW_\tau$$

Taking expectations we obtain

$E[\log(S_t)] - \log(S_0) = \int_{\tau=0}^t \left(\mu_\tau - \frac{\sigma_\tau^2}{2}\right)d\tau$ where we used $E[\int_{\tau=0}^t \sigma_\tau dW_\tau] = 0$

and

$E[\log(S_t)] = \log(S_0) + \int_{\tau=0}^t \left(\mu_\tau - \frac{\sigma_\tau^2}{2}\right)d\tau$

### 7(b)

$Var[\log(S_t)] = E[(\log(S_t) - E[\log(S_t)])^2] = E\left[\left(\int_{\tau=0}^t \sigma_\tau dW_\tau\right)^2\right]$

Using Itô's isometry

$$Var[\log(S_t)] = \int_{\tau=0}^t \sigma_\tau^2 d\tau$$

## Problem 8

Prove if $\phi = \exp(tW_t)$ then $d\phi = \phi\left(W_t + \frac{t}{2}\right)dt + t\phi dW_t$

From Itô we have

$$d\phi = \frac{\partial \phi}{\partial t}dt + \frac{\partial \phi}{\partial W_t}dW_t + \frac{1}{2}\frac{\partial^2 \phi}{\partial W_t^2}E[(dW_t)^2]$$

Now

$$\frac{\partial \phi}{\partial t} = W_t \exp(tW_t), \frac{\partial \phi}{\partial W_t} = t \exp(tW_t), \frac{\partial^2 \phi}{\partial W_t^2} = t^2 \exp(tW_t)$$

So

$$d\phi = W_t \exp(tW_t)dt + t \exp(tW_t)dW_t + \frac{t^2}{2} \exp(tW_t)dt$$

Therefore

$$d\phi = \phi\left(W_t + \frac{t}{2}\right)dt + t\phi dW_t$$

## Problem 9

Given

$$Z_t = \exp\left(\int_{s=0}^{t} \theta_s dW_s - \frac{1}{2}\int_{s=0}^{t} \theta_s^2 ds\right)$$

Use Itô to prove that the process for $Z_t$ is $dZ_t = Z_t\theta_t dW_t$.

### 9(a)

Let

$$X_t = \int_{s=0}^t \theta_s dW_s - \frac{1}{2}\int_{s=0}^t \theta_s^2 ds$$

so

$$dX_t = \theta_t dW_t - \frac{1}{2}\theta_t^2 dt$$

We thus have:

$$Z_t = \exp(X_t)$$

Using Itô we have

$$dZ_t = \frac{\partial Z_t}{\partial X_t} dX_t + \frac{\partial^2 Z_t}{\partial X_t^2}(dX_t)^2$$

so

$$dZ_t = Z_t \left(\theta_t dW_t - \frac{1}{2}\theta_t^2 dt\right) + \frac{1}{2}Z_t (\theta_t dW_t)^2$$

$$dZ_t = Z_t \theta_t dW_t - \frac{1}{2}Z_t\theta_t^2 dt + \frac{1}{2}Z_t \theta_t^2 dt$$

$$dZ_t = Z_t \theta_t dW_t$$
