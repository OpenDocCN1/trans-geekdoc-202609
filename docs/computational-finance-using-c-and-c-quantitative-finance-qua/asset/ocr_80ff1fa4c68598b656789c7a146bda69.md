the values $S'_i, i = 1, \dots, n, 0 \leqslant t \leqslant T$. Any asset $S'$ which only takes values that are greater than zero is called a *numereraire*. Numeraires can be denoted all the asset prices in the economy. So (for example) if $S^1$ is a numereraire the prices of the other assets denominated in units of $S^1$ are the relative prices $Z'_i = (S'_i/S'_1), i = 2, \dots, n$.

One can find a unique probability measure $\mathbb{Q}$ such that the relative prices $Z'_i, i = 2, \dots, n,$ are martingales. If the economy is free of arbitrage opportunity every payoff pattern $H_t$ is represented as a linear combination of the asset values $S'_i, i = 1, \dots, n,$ and in addition the relative price process $(H_t/S'_1)$ is a martingale.

This means we can write

```
$E^{\mathbb{Q}}\left[\frac{H_i}{S'_i}ight] = E^{\mathbb{Q}}\left[\frac{H_t}{S'_1}ight], \quad \text{where } 0 \leqslant t \leqslant T$
```

The current (time $t$) value $V_t$ of the payoff $H_t$ is thus

```
$V_t = N_t E^{\mathbb{Q}}\left[\frac{H_t}{N_T}ight]$
```

In general for a numereraire $N$ which takes the values $N_t, 0 \leqslant t \leqslant T$, we can write

```
$V_t = N_t E^{\mathbb{Q}}\left[\frac{H_t}{N_T}ight] \quad (4.2.1)
```

Equation (4.2.1) is very important because $V_t$ is the current (time $t$) price of a financial derivative with maturity $T$ and payoff $H_t$.

It should be mentioned that the price of a financial derivative is independent of the martingale measure under which it is valued, and thus the same price $V_t$ will be obtained for different numeraires $N$.
