The results were obtained using a binomial lattice and the analytic formula (Johnson 1987) and Stulz (1982). The time to maturity of the option is varied from 0.1 years to 8 years. The parameters are $E = 44.0, S_1 = 50.0, S_2 = 50.0, r = 0.1, \sigma_1 = 0.2, \sigma_2 = 0.2, q_1 = q_2 = 0, \rho = 0.5, n_{steps} = 50$.

Then, following Stulz (1982) and Johnson (1987), we have:

> $c_{\max} = S_1 N_2(d_1(S_1, E, \sigma_1^2), d_1'(S_1, S_2, \sigma_2^2), \rho_1) + S_2 N_2(d_2(S_2, E, \sigma_2^2), d_2'(S_1, S_2, \sigma_1^2), \rho_2) - E e^{-rt}[1 - N_2(-d_2(S_1, E, \sigma_1^2), -d_2(S_2, E, \sigma_2^2), \rho)] \quad (6.5.5)$

and

> $c_{\min} = S_1 N_2(d_1(S_1, E, \sigma_1^2), -d_1'(S_1, S_2, \sigma_2^2), -\rho_1) + S_2 N_2(d_2(S_2, E, \sigma_2^2), -d_2'(S_1, S_2, \sigma_1^2), -\rho_2) - E e^{-rt}N_2(-d_2(S_1, E, \sigma_1^2), -d_2(S_2, E, \sigma_2^2), \rho) \quad (6.5.6)$

where $N(a, b, \rho)$ is the bivariate cumulative function. It gives the probability, in a standardized bivariate normal distribution, where the variables $x_1$ and $x_2$ satisfy $x_1 \le a$ and $x_2 \le b$ when the correlation coefficient between $x_1$ and $x_2$ is $\rho$—the value is computed using routine `cumnorm`. The other symbols are defined as follows:

- $\rho_1 = \frac{\sigma_1 - \sigma_2}{\sigma_*}$
- $\rho_2 = \frac{\sigma_2 - \sigma_1}{\sigma_*}$
- $d_1(S_i, E, \sigma_i^2) = \frac{\log(S_i/E) + (r + \sigma_i^2/2)t}{\sigma_i\sqrt{t}}, \quad i=1, 2$
- $d_2(S_i, E, \sigma_i^2) = \frac{\log(S_i/E) + (r - \sigma_i^2/2)t}{\sigma_i\sqrt{t}}, \quad i=2$
- $d_1'(S_i, S_j, \sigma_k^2) = \frac{\log(S_i/S_j) + (\sigma_k^2/2)t}{\sigma_k\sqrt{t}}, \quad i=1, j=2 \text{ or } i=2, j=1$

It can also be shown that:

$c_{\max}(S_1, S_2, E, \tau) + c_{\min}(S_1, S_2, E, \tau) = c(S_1, E, \tau) + c(S_2, E, \tau) \quad (6.5.7)$

where $c(S_1, E, \tau)$ is the value of a vanilla call. We will now derive an expression for the value of the corresponding put options.

## Put options on the minimum of two assets

It will now shown that the price of a European option on the minimum of two assets, $p_{\min}(S_1, S_2, E, \tau)$ is:

$p_{\min}(S_1, S_2, E, \tau) = E e^{-r\tau} - c_{\min}(S_1, S_2, 0, \tau) + c_{\min}(S_1, S_2, E, \tau) \quad (6.5.8)$

where the meaning of the symbols has been previously defined. This result can be proved by considering the following two investments:

- PORTFOLIO A: Purchase one option on the minimum of $S_1$ and $S_2$ with exercise price $E$.
- PORTFOLIO B: Purchase one discount bond which pays $E$ at maturity. Write (that is, sell) one option on the minimum of $S_1$ and $S_2$ with an exercise price of zero. Purchase one option on the minimum of $S_1$ and $S_2$ with exercise price $E$.

We now consider the values of these portfolios at option maturity, time $\tau$.

If $\min(S_1, S_2) \ge E$:
- PORTFOLIO A: pays zero
- PORTFOLIO B: pays $E - \min(S_1, S_2) + \min(S_1, S_2) - E = 0$

If $\min(S_1, S_2) = S_1 < E$:
- PORTFOLIO A: pays $E - S_1$
- PORTFOLIO B: pays $E - S_1 + 0 = E - S_1$

If $\min(S_1, S_2) = S_2 < E$:
- PORTFOLIO A: pays $E - S_2$
- PORTFOLIO B: pays $E - S_2 + 0 = E - S_2$

We have therefore shown that, under all possible circumstances, Portfolio A has the same value as Portfolio B. This means that Eq. (6.5.8) is true.

## Put options on the maximum of two assets

It will be shown that the price of a European put option on the maximum of two assets, $p_{\max}(S_1, S_2, E, \tau)$ is:

$p_{\max}(S_1, S_2, E, \tau) = E e^{-r\tau} - c_{\max}(S_1, S_2, 0, \tau) + c_{\max}(S_1, S_2, E, \tau) \quad (6.5.9)$

where, as before, the meaning of the symbols has been previously defined. This result can be proved by considering the following two investments:

- PORTFOLIO A: Purchase one option on the maximum of $S_1$ and $S_2$ with exercise price $E$.
- PORTFOLIO B: Purchase one discount bond which pays $E$ at maturity. Write (that is, sell) one option on the maximum of $S_1$ and $S_2$ with exercise price of zero. Purchase one option on the maximum of $S_1$ and $S_2$ with exercise price $E$.

As before now consider the values of these portfolios at option maturity, $\tau$.

If $\max(S_1, S_2) \ge E$:
- PORTFOLIO A: pays zero
- PORTFOLIO B: pays $E - \max(S_1, S_2) + \max(S_1, S_2) - E = 0$

If $\max(S_1, S_2) = S_1 < E$:
- PORTFOLIO A: pays $E - S_1$
- PORTFOLIO B: pays $E - S_1 + 0 = E - S_1$

If $\max(S_1, S_2) = S_2 < E$:
- PORTFOLIO A: pays $E - S_2$
- PORTFOLIO B: pays $E - S_2 + 0 = E - S_2$

It follows that, under all possible circumstances, Portfolio A has the same value as Portfolio B, and that Eq. (6.5.9) is true.

## American options

We assume that the prices of asset 1 and 2 follow a lognormal process with drift terms $\mu_1 = r - \sigma_1^2/2$ and $\mu_2 = r - \sigma_2^2/2$, respectively. As before, $r$ is the riskless interest rate and $\sigma_1$ and $\sigma_2$ are the instantaneous volatilities of asset 1 and 2. If we let $S_{1,t}$ and $S_{2,t}$ denote the respective prices of asset 1 and asset 2 at time $t$, then we can write:

$\log(S_{1,t+\Delta t}) = \log(S_{1,t}) + \varepsilon_{1,t} \quad (6.5.10)$
$\log(S_{2,t+\Delta t}) = \log(S_{2,t}) + \varepsilon_{2,t}$

where $\varepsilon_{1,t}$ is a random normal variable with mean $\mu_1\Delta t$ and variance $\sigma_1^2\Delta t$, and $\varepsilon_{2,t}$ is a random normal variable with mean $\mu_2\Delta t$ and variance $\sigma_2^2\Delta t$. In the binomial model, over the interval $\Delta t$, the variate $\log(S_{1,t})$ is only allowed to jump up or down by the amount $v_1 = \sigma_1\sqrt{\Delta t}$, and similarly the variate $\log(S_{2,t})$ is only permitted to jump up and down by the amount $v_2 = \sigma_2\sqrt{\Delta t}$. We will denote the probability of both $\log(S_{1,t})$ and $\log(S_{2,t})$ having an up jump and $\log(S_{2,t})$ having a down jump by $p_{ud}$, etc. The mean values in Eqs. (6.15) and (6.16) then give

$E[\varepsilon_{1,t}] = v_1(p_{uu} + p_{ud} - p_{du} - p_{dd}) = \mu_1\Delta t$
$E[\varepsilon_{2,t}] = v_2(p_{uu} + p_{ud} - p_{du} - p_{dd}) = \mu_2\Delta t$

and the variance/covariance terms yields

$Var[\varepsilon_{1,t}] = v_1^2(p_{uu} + p_{ud} + p_{du} + p_{dd}) = \sigma_1^2\Delta t$
$Var[\varepsilon_{2,t}] = v_2^2(p_{uu} + p_{ud} + p_{du} + p_{dd}) = \sigma_2^2\Delta t$
$E[\varepsilon_{1,t}\varepsilon_{2,t}] = v_1v_2(p_{uu} - p_{ud} - p_{du} - p_{dd}) = \mu_1\sigma_2\Delta t$,

where $\rho$ is the correlation coefficient between $\varepsilon_{1,t}$ and $\varepsilon_{2,t}$. We obtain:

- $p_{uu} + p_{ud} - p_{du} - p_{dd} = \frac{\mu_1\sqrt{\Delta t}}{\sigma_1}$
- $p_{uu} - p_{ud} + p_{du} - p_{dd} = \frac{\mu_2\sqrt{\Delta t}}{\sigma_2}$
- $p_{uu} + p_{ud} + p_{du} + p_{dd} = 1$
- $p_{uu} - p_{ud} - p_{du} + p_{dd} = \rho$

These lead to the following jump probabilities:

- $p_{uu} = \frac{1}{4}\{1 + \sqrt{\Delta t}(\frac{\mu_1}{\sigma_1} + \frac{\mu_2}{\sigma_2}) + \rho\}$
- $p_{ud} = \frac{1}{4}\{1 + \sqrt{\Delta t}(\frac{\mu_1}{\sigma_1} - \frac{\mu_2}{\sigma_2}) - \rho\}$
- $p_{dd} = \frac{1}{4}\{1 + \sqrt{\Delta t}(-\frac{\mu_1}{\sigma_1} + \frac{\mu_2}{\sigma_2}) + \rho\}$
- $p_{du} = \frac{1}{4}\{1 + \sqrt{\Delta t}(-\frac{\mu_1}{\sigma_1} - \frac{\mu_2}{\sigma_2}) - \rho\}$
