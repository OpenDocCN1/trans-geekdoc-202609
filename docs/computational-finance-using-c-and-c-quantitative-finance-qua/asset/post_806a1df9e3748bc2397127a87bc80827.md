
where $dY$ is the change in the value of $\log(S)$ over the time interval $dr$. Later on we derived the (Black-Scholes) partial differential equation that is satisfied by the value, $V$, of an option written on a single asset. The equation is

```
$$\frac{\partial V}{\partial t}+\frac{\sigma^{2}}{2}\frac{\partial^{2} V}{\partial S^{2}}+rS\frac{\partial V}{\partial S}-rv=0$$
```

The above result can be generalized to deal with multiset options. Suppose that $m$ assets are described by the following processes:

```
$dY_{i}=(r-\frac{\sigma_{i}^{2}}{2})dt+\sigma_{i}dW_{i},\quad i=1,...,m,\quad(6.2.1)
```

where the subscript $i$ refers to value associated with the $i$th asset. The $m$-element random vector $dW$ is distributed as $dW \sim N(0,C)$. The diagonal elements of $C$ are $C_{ii}=\text{Var}[dW_{i}]=dt, i=1,...,m$, and off-diagonal elements are:

```
$C_{ij}=E[dW_{i}dW_{j}]=\rho_{ij}dt,\quad i=1,...,m,j=1,...,m,i\neq j$
```

We also write the above equation in vector form by introducing the $m$-element vector $dY$ which is normally distributed:

```
$dY\sim N(\bar{\mu},\bar{C}),\quad(6.2.2)
```

where $\bar{\mu}$ is the mean vector and $\bar{C}$ is the covariance matrix. The elements of the covariance matrix are:

```
$$\bar{C}_{ii}=\sigma_{i}^{2}dt,\quad i=1,...,m$$
$\bar{C}_{ij}=\sigma_{i}\sigma_{j}\rho_{ij}dt,\quad i\neq j,i=1,...,m,j=1,...,m,\quad(6.2.3)$$
```

where $\rho_{ij}$ is the correlation coefficient between asset $i$ and asset $j$; that is, the correlation between $dW_{i}$ and $dW_{j}$. The elements of the mean vector are:

```
$v_{i}=r-\frac{\sigma_{i}^{2}}{2},\quad i=1,...,m,\quad(6.2.4)$
```

The value $V$ of an option on $m$ assets satisfies the following differential equation:

```
$$\frac{\partial V}{\partial t}+\sum_{i=1}^{m}\sum_{j=1}^{m}\sigma_{i}\sigma_{j}\rho_{ij}S_{i}S_{j}\frac{\partial^{2} V}{\partial S_{i}\partial S_{j}}+rS\sum_{i=1}^{m}\frac{\partial V}{\partial S_{i}}-rv=0$$
```

For a European call on the maximum of $m$ assets (time $\tau$) is given by $P_{c}^{MAX}=\max(S_{c}^{1},S_{c}^{2},...,S_{c}^{m})-E$, where $S_{c}^{i},i=1,...,m$, denotes the value of the $i$th asset at maturity, and $E$ represents the strike price. Similarly a European put option on the minimum of $m$ assets has a pay-off, $P_{p}^{MIN}$, at time $\tau$, given by $P_{p}^{MIN}=\max-\min(S_{c}^{1},S_{c}^{2},...,S_{c}^{m}),0$.

# 6.3 Multidimensional Monte Carlo methods

We have already mentioned that Monte Carlo simulation can easily price European multasset options (also sometimes referred to as basket options, or rainbow options) involving a large number of assets (say 20 or more).

In addition Monte Carlo simulation can also include the following features:

- Non-Gaussian distribution of stock returns; distributions with heavy tails are usually of interest because they more accurately represent what is observed in the financial markets
- Options with path dependency (such as barrier options, etc.); these are known as exotic options
- Complex time dependency (e.g., ARMA, GARCH or Levy processes) of model parameters such as interest rates, asset prices, etc.

The main drawbacks with Monte Carlo simulation are:

- It is difficult to compute the value of American-style options
- It is difficult (or impossible) to achieve the same accuracy that can be obtained using finite difference methods.

In a different section of this book we will show how Monte Carlo simulation can be used to price American options by using a hybrid Monte Carlo lattice approach developed by Boyle, Evnine, and Gibbs (1997).

In Chapter 3 we show that when pseudo-random numbers are used, the standard errors of integrals computed via Monte Carlo simulation decrease at the rate $N^{1/2}$, where $N$ is the number of simulations. This means that it can require hundreds of thousands of simulations to achieve an accuracy of $10^{-1}$ or $10^{-2}$ in the estimated option price. It is because this various Monte Carlo variance reduction techniques are used to increase the accuracy of the computed integral.

In this section we show how to price a three-asset basket option using Monte Carlo simulation; the accuracy of the results obtained with quasirandom numbers and pseudo-random numbers are compared.

# 6.4 Introduction to multidimensional lattice methods

Finite-lattices can be used to value options on about 4 assets before they require immensely large amounts of memory. The main advantage of finite-lattice methods is that they are easier to cater for American style exercise within the option. This is not true of Monte Carlo methods. They can easily model complex European options, but have difficulty modelling American-style options.

In this section we use the approach of Kamrad and Ritchie (1991), we will call the the BE method, for price basket options. We first derive expressions for the jump size and jump probabilities for a single asset, and show that these are equivalent to those of the Cox, Ross, and Rubinstein binomial lattice (CRR lattice) discussed in Chapter 5. We will then give expressions for the jump sizes and jump probabilities of a general basket option.

To derive the BEKR equations for one asset we assume that the asset follows a lognormal process with drift $\mu=r-\sigma^2/2$, which is the riskless interest rate and $\sigma$ is the instantaneous volatility.
