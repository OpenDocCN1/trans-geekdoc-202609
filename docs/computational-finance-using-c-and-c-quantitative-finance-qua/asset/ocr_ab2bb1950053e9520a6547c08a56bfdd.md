The variance of the position $X_T$ is:

```
Var[X_T] = Var \left[ \mu T + \sigma\sqrt{dt} \sum_{i=1}^n dZ_i \right] = Var \left[ \sigma\sqrt{dt} \sum_{i=1}^n dZ_i \right]
```

Here we have used the fact (see Appendix C.3.1) $Var[a+bX]=b^2Var[X]$, where $a=\mu T$, and $b=1$. From Equs. (2.1.9) and (2.1.10) we have:

```
Var[X_T] = Var \left[ \sigma\sqrt{dt} \sum_{i=1}^n dZ_i \right] = \sigma^2 T$.
```

So, at time $T$, the position of the pollen grain $X_T$ is distributed $\sim N(\\mu T, \sigma^2)$.

We have shown that when we vary the drift of a Brownian motion, its volatility remains unchanged. This is a very important property and (as we will see later) is used extensively in the theory of derivative pricing.

# 2.2 A Brownian model of asset price movements

In the previous section we showed how Brownian motion can be used to describe the random motion of small particles suspended in a liquid. The first attempt at using Brownian motion to describe financial asset price movements was provided by Bachelier (1900). This, however, only had limited success because the significance of an *absolute* change in asset price depends on the original asset price. For example, a $\pounds1$ increase in the value of a share originally $\pounds10$ is much more significant than a $\pounds1$ increase in the value of a share originally $\pounds100$. It is for reason that asset price movements are generally described in terms of *relative* or percentage changes. For example, if the $\pounds1.10$ increases by 11 percent and the $\pounds100$ share increases in value by $\pounds10$, both of these changes have the same significance, and correspond to a 10 percent increase in value. The idea of relative price changes in the value of a share at time $t$. The return, $R_t$, is defined as follows:

```
R_t = \frac{S_{t+dt} - S_t}{S_t} = \frac{dS_t}{S_t} (2.2.1)
```

Where $S_{t+dt}$ is the value of the share at time $t+dt$, $S_t$ is the value of the share at time $t$, and $dS_t$ is the change in the value over the time interval $dt$. The percentage return $R^*$ over the interval $dt$ is simply defined as $R^* = 100 \times R_t$.

We are now in position to construct a simple Brownian model of asset price movements; further information on Brownian motion within finance can be found in Shreve, Chalasani, and Jha (1997). The *asset return* at time $t$ is now given by:

```
R_t = \frac{dS_t}{S_t} = \mu dt + \sigma dW_t, dW_t \sim N(0, dt) (2.2.2)
```
