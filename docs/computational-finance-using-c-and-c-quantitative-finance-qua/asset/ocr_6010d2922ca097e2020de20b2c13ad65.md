# # Appendix I:
 The Feynman-Kac formula

The Feynman-Kac formula provides a link between stochastic processes and partial differential equations, which we will now illustrate.

In the risk neutral measure the equation followed by the asset price is:

$dS = rSdt + \sigma S dW \quad (I.1.1)$

and that of the money account:
$dB = Br dt \quad (I.1.2)$

If $f(S,t)$ is the value of a derivative then using Ito's lemma we have

$df = \left[frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}\right] dS + S\frac{\partial f}{\partial S} dW \quad (I.1.3)$

Since $f$ is a tradable we know that the process $(\frac{f})$ must be a martingale in the risk neutral measure, and therefore have zero drift (see Eq. (2.6.4)):

$d\left(\frac{X_1}{X_2}\right) = \left(\frac{dX_1}{X_2} - \frac{X_1dX_2}{X_2^2}\right) + E\left(\frac{dX_2}{X_2}\frac{dX_2}{X_2}\right) - E\left(\frac{dX_2}{X_2}\frac{dX_1}{X_1}\right) \quad (I.1.4)$

and rewrite Eqs. (I.1.2) and (I.1.3) as:

$dX_1 = \mu_1 dt + \sigma_1 dW$\n$dX_2 = \mu_2 dt$

where

$d\left(\frac{X_1}{X_2}\right) = d\left(\frac{f}{B}\right), \quad \mu_1 = \left[frac{\partial f}{\partial t} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}\right]\n\sigma_1 = \sigma_1 S\frac{\partial f}{\partial S}, \quad X_1 = f, \quad X_2 = B, \quad \mu_2 = r$

Evaluating Eq. (I.1.4) we obtain:

$E\left[left(\frac{dX_2}{X_2}\right)\frac{dX_2}{X_2}\right] = E\left[\mu_2^2 dt^2\right] \to 0$

$E\left[left(\frac{dX_1}{X_2}\right)\frac{dX_2}{X_2}\right] = E\left[left(\frac{\mu_1 dt + \sigma_1 dW}{X_1}\right)\left(\frac{\mu_2 dt}{X_2}\right)\right] \to 0$
