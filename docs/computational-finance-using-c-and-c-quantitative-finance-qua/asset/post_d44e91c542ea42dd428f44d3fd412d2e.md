## The Black approximation

The Black (1973) approximation for an American call with cash dividends is simpler than the Roll–Geske–Whaley method we have just described. For American call option that expires at time $T$, with $n$ discrete cash dividends $D_i, i = 1, \dots, n$, at times $t_i, i = 1, \dots, n$, involves calculating the prices of European options that matures at times $T$ and $t_n$, and then setting the option price to the greater of these two values, see for Hull (2003).

The Black approximation, $C_{BL}$, can be expressed more concisely in terms of our previously defined notation as:

```
$C_{BL}(S, \tau) = \max(v_1, v_2)$
```

where $v_1$ and $v_2$ are the following European calls:

$v_1 = c(S_D, E, \tau)$ and $v_2 = c(S_D^+, E, \tau), \tau = T - t, \tau_1 = T - t_n$

```
$S_D = S - \sum_{i=1}^n D_i \quad \text{and} \quad S_D^+ = S - \sum_{i=1}^{n-1} D_i$
```

This exercise premium is defined precisely for American puts and calls. If current time t the asset price is S, then the exercise premium for an American call expires at time T, and then has maturity $\tau = T - t$, is $v_c(S, \tau) = C(S, \tau) - c(S, \tau) \geq 0$ (5.2.8) where $C(S, \tau)$ denotes the value of the American call and $c(S, \tau)$ denotes the value of the European call. The exercise premium of an American put is similarly defined as $v_p(S, \tau) = P(S, \tau) - p(S, \tau) \geq 0$ (5.2.9) where $P(S, \tau)$ is the value of the American put, and the key insight provided by Black-Barone-Whaley is that both the American and European option values satisfy the Black–Scholes partial differential equation, so the early exercise premium we can write:

$$\frac{\partial v}{\partial t} + (r-q)S\frac{\partial v}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 v}{\partial S^2} = rv \quad (5.2.10)$$

where as usual S is the price, r is the continuously compounded interest rate, q is the continuously compounded dividend, $\sigma$ is the volatility, and time $t$ increases from the time to the expiry $T$. We will now introduce the variable $h(t) = 1 - \exp(-rt)$ and use the factorization $v(S, E, \tau) = h(t)g(S, E, h)$. From standard calculus we obtain:

```
$\frac{\partial v}{\partial t} = g\frac{\partial h}{\partial t} + h\frac{\partial g}{\partial t} = rg(h-1) + h\frac{\partial^2 g}{\partial h}\frac{\partial h}{\partial t} = rg(h-1) + lr(h-1)\frac{\partial g}{\partial h}$
```

and also

```
$\frac{\partial v}{\partial S} = h\frac{\partial g}{\partial S}$ and $\frac{\partial^2 v}{\partial S^2} = h\frac{\partial^2 g}{\partial S^2}$
```

Substituting these results into Eq. (5.20) yields the transformed Black-Scholes equation:

```
$S^2\frac{\partial^2 g}{\partial S^2} + (r-q)Sh\frac{\partial g}{\partial S} + rg(h-1) + rh(h-1)\frac{\partial g}{\partial h} = rgh$ (5.2.11)
```

which can be further simplified to give:

```
$S^2\frac{\partial^2 g}{\partial S^2} + \frac{2(r-q)S}{\sigma^2}\frac{\partial g}{\partial S} - \frac{2rg}{h\sigma^2} - \frac{2r(1-h)}{\sigma^2}\frac{\partial g}{\partial h} = rgh$ (5.2.12)
```

or

```
$S^2\frac{\partial^2 g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h}\frac{\partial g}{\partial h} - g - (1-h)\frac{\alpha}{\partial h} = 0$ (5.2.13)
```

where $\alpha = 2r/\sigma^2$ and $\beta = 2(r-q)/\sigma^2$.

We now consider the last term of Eq. (5.213) and note that when $\tau$ is large, $1-h(t) \sim 0$. Also when $\tau \to 0$ the option is close to maturity, and the value of both European and American options converge, this means that $v(S, E, \tau) \sim 0$ and $\frac{\partial v}{\partial t} \sim 0$. It can then be seen that the last term is generally small and the Black-Barone-Whaley approximation assumes that it can be integrated. This results in the following equation:

```
$S^2\frac{\partial^2 g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h}\frac{\partial g}{\partial h} = 0$ (5.2.14)
```

which is a second-order differential equation with two linearly independent solutions of the form $aS^\gamma$. They can be found by substituting $g(S, E, h) = aS^\gamma$ into Eq. (5.2.14) as:

```
$\frac{\partial g}{\partial S} = a\gamma S^{\gamma-1}$, $\frac{\partial^2 g}{\partial S^2} = a\gamma(\gamma-1)S^{\gamma-2} = a\gamma^2 S^{\gamma-2} - a\gamma S^{\gamma-2}$
```

so

```
$S^2\frac{\partial^2 g}{\partial S^2} = a\gamma^2 S^{\gamma} - a\gamma S^{\gamma} = a\gamma^2 g - a\gamma g$
```

and

```
$\beta S\frac{\partial g}{\partial S} = \beta a\gamma S^{\gamma} = \beta \gamma g = \beta S\gamma g$
```
