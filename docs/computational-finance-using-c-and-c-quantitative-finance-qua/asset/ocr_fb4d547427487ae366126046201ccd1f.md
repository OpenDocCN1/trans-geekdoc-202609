The expression for $b_i$
Here we derive an expression for the term $b_i$ which is used in Eq. (5.2.34).

```
$b_i = \frac{\partial c(S_i^*, E, \tau)}{\partial S_i^*} + \frac{1}{\gamma_2}\{1 - exp(-q\tau)N_1(d_1(S_i^*))}\}\S_i^*\frac{\partial N_1(d_1(S_i^*))}{\gamma_2}\frac{\partial d_1(S_i^*)}{\partial S_i^*}$
```

We will now quote the following results which are derived in Appendix A, Eq. (A.1.3).

```
$$\frac{\partial N_1(d_1(S_i^*))}{\partial d_1(S_i^*)} = n(d_1(S_i^*))$
```

Appendix A, Eq. (A.1.6).

```
$$\frac{\partial d_1(S_i^*)}{\partial S_i^*} = \frac{1}{S_i\sqrt{\tau}}$
```

Appendix A, Eq. (A.3.2).

```
$$\Delta_c = \frac{\partial c(S_i^*, E, \tau)}{\partial S_i^*} = exp(-q\tau)N_1(d_1(S_i^*))$
```

Substituting these results into the above expression, we therefore obtain:

```
$b_i = exp(-q\tau)N_1(d_1(S_i^*)) + \frac{1}{\gamma_2}exp(-q\tau)N_1(d_1(S_i^*)) - \frac{exp(-q\tau)n(d_1(S_i^*))}{\gamma_2\sqrt{\tau}}$
```

which can be rearranged to yield:

```

```
$E - S_{**}^{*} = p(S_{**}^{*}, E, \tau)\frac{S_{**}^{*}}{\gamma_1}\{1 - N_1(-d_1(S_{**}^{*}))exp(-q\tau)\}$
```

If we let $S_{**}^{*}$ the $ith$ approximation to the critical asset value $S_{**}^{}$, then we can represent the left-hand side of the equation:

```
