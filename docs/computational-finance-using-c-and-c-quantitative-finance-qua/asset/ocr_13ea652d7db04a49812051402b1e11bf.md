This can be expressed as zero drift Brownian motion under probability measure P:

```
$dX_t = \sigma dW_t^P, \quad dW_t^P \sim N(0, dt) \quad (H.5.1)
```

or

```
$X_t = \sigma W_t^P, \quad W_t^P \sim N(0, t)$
```

Now we can choose another probability measure Q so that:

```
$dW_t^P = dW_t^Q + \frac{
u}{\sigma}dt \quad (H.5.2)
```

where $
u$ is a constant.

Under probability measure Q the motion in Eq. (H.5.1) is:

```
$\widetilde{X}_t = \sigma \left(dW_t^Q + \frac{\nu}{\sigma}dt\right) \quad (H.5.3)
```

so

```
$\widetilde{X}_t = \nu dt + \sigma dW_t^Q \quad (H.5.4)
```

It be seen from Section 2.4 that the transformation between measures P and Q can be achieved using $k = \nu/\sigma$, and the associated Radon–Nikodym derivative is:

```
$\frac{dQ}{dP} = \exp\left(kW_t^P - \frac{1}{2}k^2t\right)$$\n$= \exp\left(\frac{\nu}{\sigma}W_t^P - \frac{\nu^2}{2\sigma}\right)$$\n$= \exp\left(\frac{\nu}{\sigma^2}\widetilde{X}_t - \frac{\nu^2}{2\sigma}\right) \quad (H.5.5)
```

where we have the fact that under probability measure P we can write:

```
$\widetilde{W}_t^P = X_t/\sigma$.
```

Now

```
$P(\widetilde{X}_t^P \le b, \widetilde{X}_t^P \ge x) = E^Q[\mathbb{I}_{[\widetilde{X}_t^Q \le b)}(\widetilde{X}_t^Q \ge x)] \quad (H.5.6)
```

where $\mathbb{I}_{\{\{condition\}}$ is an indicator function which takes unit value when *condition* is satisfied and zero otherwise—for example $\mathbb{I}_{\{\widetilde{X}_t^P \le b\}}$ is one when $\widetilde{X}_t^P \le b$ and

zero when $\widetilde{X}_t^P > b$.

However for some Baxter and Rennie (1996)), we have:

```
$E^Q[\mathbb{I}_{[\widetilde{X}_t^P \le b)}(\widetilde{X}_t^P \ge x)] = E^P[\mathbb{I}_{[\widetilde{X}_t^Q \le b)}\frac{dQ}{dP}] \quad (H.5.7)
```

So substituting for $\frac{dQ}{dP}$ from Eq. (H.5.5) gives:

```
$E^Q[\mathbb{I}_{[\widetilde{X}_t^P \le b)}(\widetilde{X}_t^P \ge x)] = E^P[\mathbb{I}_{[\widetilde{X}_t^Q \le b)}\exp\left(\frac{\nu X_t}{\sigma^2} - \frac{\nu^2}{2\sigma^2}\right)] \quad (H.5.8)
```
