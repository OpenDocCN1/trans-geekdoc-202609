# Appendix G:
The Brownian bridge:
alternative derivation

We provide an alternative derivation of the Brownian bridge equation given in Chapter 2.
Let a Brownian process have values $W_{t_0}$ at time $t_0$ and $W_{t_1}$ at time $t_1$. We want to find the conditional distribution of $W_t$, where $t_0 < t < t_1$. This distribution will be denoted by $P(W_t|W_{t_0}, W_{t_1})$, to indicate that $W_t$ is conditional on the end values $W_{t_0}$ and $W_{t_1}$
We have:

```
$P(W_t|W_{t_0}) = \frac{1}{\sqrt{2\pi(t-t_0)}} \exp\left{\frac{(W_t - W_{t_0})^2}{2(t-t_0)}\right\}$
```

The joint distribution of $W_t$ and $W_{t_1}$ given $W_{t_0}$ is:

```
$P(\{W_t, W_{t_1}\})P(W_{t_1}|W_{t_0})\n= \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t_0)}} \exp\left{\frac{(W_t - W_{t_0})^2}{2(t-t_0)}, \frac{(W_{t_1} - W_{t_0})^2}{2(t_1-t_0)}\right{\n= \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \exp\left{\frac{1}{2}\frac{(W_t - W_{t_0})^2}{2(t-t_0)} + \frac{(W_{t_1} - W_{t_0})^2}{2(t_1-t)}\right\}$
```

Similarly

```
$P(W_{t_1}|W_{t_0}) = \frac{1}{\sqrt{2\pi(t_1-t_0)}} \exp\left{\frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t_0)}\right\}$
```

Now we have:

```
$P(W_t|{W_{t_0}, W_{t_1}\})\n= \frac{P(\{W_t, W_{t_1}\}|W_{t_0})}{P(W_{t_1}|W_{t_0})}\n= \frac{1}{\sqrt{2\pi}\frac{t_1-t_0}{(t-t_0)(t_1-t)}}}\times\exp\left{\frac{1}{2}\frac{(W_t-W_{t_0})^2}{t-t_0}-\frac{(W_{t_1}-W_{t_0})^2}{t_1-t}\ight\}$
```
