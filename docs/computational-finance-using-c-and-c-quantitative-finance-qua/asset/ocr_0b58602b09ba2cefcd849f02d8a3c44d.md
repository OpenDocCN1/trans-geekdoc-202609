PROOF. From Eqs. (2.9.2) and (2.9.7) we have:

```
$f_t = \frac{\sigma^2\exp(\sigma^2\exp(2\alpha t))}{2\alpha} \text{ and } a_t = \exp(-2\alpha t) \quad (2.9.8)$
```

Therefore

```
$a_t' = \frac{-\alpha\exp(-\alpha t)}{\exp(-\alpha t)} = -\alpha \quad (2.9.9)$
```

and

```
$f_t' = \frac{\sigma^2}{2\alpha}\exp(2\alpha t) = \sigma^2\exp(2\alpha t) \quad (2.9.10)$
```

So

```
$$\sqrt{f_t'} = \sqrt{\sigma^2\exp(2\alpha t)} = \sigma\exp(\alpha t)\sqrt{dt} \quad (2.9.11)$
```

Thus

```
$dW_{W,t} = -\alpha dY_{W,t} dt + \exp(-\alpha t)\sigma\exp(\alpha t)\sqrt{dt} dZ \quad (2.9.12)$
```

which means that

```
$dY_{W,t} = -\alpha dY_{W,t} dt + \sigma dW_t \quad (2.9.13)$
```

From Eq. (2.9.13) it can be seen that conditional mean and variance

```
$E[dY_{W,t}|F_t] = \alpha dY_{W,t} dt \quad (2.9.14)$
```

```
$Var[dY_{W,t}|F_t] = \sigma^2 dt \quad (2.9.15)$
```

```
$E[Y_{W,t}] = E[\exp(-\alpha t)W(\frac{\sigma^2\exp(2\alpha t)}{2\alpha})] \text{ where } \alpha > 0 \text{ and } t \to \infty \quad (2.9.16)$

So

```
$E[Y_{W,t}] = 0 \quad (2.9.17)$
