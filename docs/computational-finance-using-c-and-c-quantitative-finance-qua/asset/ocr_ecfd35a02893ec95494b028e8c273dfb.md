$I_C = -\frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}}\int_{X=\log(E/S)}^{\infty} \exp(X)\exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}}{\sigma^2\tau}\right) \times \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2\tau}\right)dX$

and

$I_D = -\frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}}\int_{X=\log(E/S)}^{\infty}\exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}}{\sigma^2\tau}\right) \times \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2\tau}\right)$

We will first consider $I_D$ and transform the integrand as follows:

```
$-\exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}}{\sigma^2\tau}\right)\exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2\tau}\right)\n= \exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}-4\log(B/S)(X-\log(B/S))}{\sigma^2\tau}\right)\n= \exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}-2\log(B/S)}{\sigma^2\tau}\right)\n= \exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}-4\log(B/S)\tau}{\sigma^2\tau}\right) \quad (B.1.3)$
```

This means that $I_D$ can be expressed as:

```
$.I_D = \frac{B}{S}^{2(r-q-\sigma^2/2)/\sigma^2}} \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}}\int_{X=\log(E/S)}^{\infty}\exp\left(-\frac{\{X-(r-q-\sigma^2/2)\tau\}-2\log(B/S)}{\sigma^2\tau}\right)dX$
```

Letting $u=(X-(r-q-\sigma^2/2)\tau-2\log(B/S))/(\sigma\sqrt{\tau})$ we have $dX=\sigma\sqrt{\tau}du$ and

```
$I_D = \frac{B}{S}^{2(r-q-\sigma^2/2)/\sigma^2}} \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}}\int_{u=k_3}^{\infty}\exp\left(-\frac{u^2}{2}\right)du$
```

where

```
$k_3 = \frac{\log(E/S)-(r-q-\sigma^2/2)\tau-2\log(B/S)}{\sigma\sqrt{\tau}}\n= \frac{\log(ES/B^2)-(r-q-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

So

```
$I_D = \frac{B}{S}^{2r/\sigma^2-1}} E\exp(-r\tau)N_1(-k_3) \quad (B.1.4)$
```
