# Problem 6

# 6(a)

Solve

$dX_t = (m - X_t)dt + \sigma dW_t$

where $m$ and $\sigma$ are constants.

Rearranging

$dX_t + X_t dt = m dt + \sigma dW_t$

Use the integrating factor $\exp(t)$

$d(X_t \exp(t)) = \exp(t) dX_t + X_t \exp(t) dt$

$= m \exp(t) dt + \sigma \exp(t) dW_t$

Integrating

$$\int_{s=0}^t d(X_s \exp(s)) = m \int_{s=0}^t \exp(s) ds + \sigma \int_{s=0}^t \exp(s) dW_s$

$X_t \exp(t) - X_0 = m(\exp(t) - 1) + \sigma \int_{s=0}^t \exp(s) dW_s$

which can be expressed

$X_t = m + (X_0 - m) \exp(-t) + \sigma \int_{s=0}^t \exp(-t) dW_s$
