We can expand the above expression as follows:

$E[e^{tx}] = E\left[1 + tx + \frac{1}{2}(tx)^2 + \cdotsight]$

$M_x(t) = 1 + tE[x] + \frac{1}{2}t^2E[x^2] + \cdots \quad (C.S.1)$

Now

$\frac{d^k(M_x(t))}{dt^k} = \frac{d^k}{dt^k}E[e^{tx}] = E\left[\frac{d^k e^{tx}}{dt^k}ight] = E[x^k e^{tx}]$

For $t=0$ we thus have:

$\frac{d^k(M_x(t))}{dt^k}ig|_{t=0} = \frac{d^k(M_x(0))}{dt^k} = E[x^k e^0] = E[x^k] \quad (C.S.2)$

# Moment generating function of a linear function of a random variable $x$

If the random variable $y$ is defined as: $y=ax+b$ the moment generating function of $y$, $M_y(t)$ is obtained as follows:

$M_y(t) = M_{ax+b}(t) = E[e^{(ax+bt)}] = e^{bt}E[e^{at}]$

Therefore:

$M_y(t) = e^{bt}M_x(at) \quad (C.S.3)$

# Moment generating function of a linear combination of random variables

Let $z=x+y$ where $x$ and $y$ are independent random variables. Then

$M_z(t) = E[e^{tz}] = E[e^{tx+ty}] = E[e^{tx}]E[e^{ty}]$

Since $x$ and $y$ are independent:

$E[e^{tx}e^{ty}] = E[e^{tx}]E[e^{ty}] = M_x(t)M_y(t)$

More generally if $s_n = \sum_{i=1}^n x_i$ where $x_i, i=1, \dots, n$, are independent variables then:

$M_s(t) = \prod_{i=1}^n M_x(t) \quad (C.S.4)$

If $x_i, i=1, \dots, n$, are IID then we have

$M_n(t) = E\left[\exp\left(t\sum_{i=1}^n x_iight)ight] = (E[e^{tx}])^n = (M_x(t))^n \quad (C.S.5)$
