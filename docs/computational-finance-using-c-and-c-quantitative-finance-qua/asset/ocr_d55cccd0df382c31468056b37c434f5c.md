The conditional mean can be obtained by noting that $X_{t_0}$ and $X_{t_1}$ are constants and the coefficients of $X_t$ and $X_t^2$ in Eq. (2.11.14) must be the same. Comparing coefficients of $X_t$ we have proved:

```
$$-2\mu_t = -2X_{t_0} \exp(-\alpha(t - t_0)) \left\ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2} \right\;\n- 2X_{t_1} \exp(-\alpha(t_1 - t)) \left\ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2} \right\;\n$$
```

So the conditional mean $\mu_t$ is:

```
$$\mu_t = X_{t_0} \exp(-\alpha(t - t_0)) \left\ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2} \right\;\n+ X_{t_1} \exp(-\alpha(t_1 - t)) \left\ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2} \right\;\$$
```

This completes the proof.

# Relation to the Brownian bridge

We will prove that in the limit $(t_1 - t_0) \rightarrow 0$ the Brownian bridge result is obtained.
For the conditional mean, we have:

```
$$\mu = X_{t_0} \exp(-\alpha(t - t_0)) \left\ \frac{1 - \exp(-2\alpha(t_1 - t))}{1 - \gamma^2} \right\;\n+ X_{t_1} \exp(-\alpha(t_1 - t)) \left\ \frac{1 - \exp(-2\alpha(t - t_0))}{1 - \gamma^2} \right\;\n$$
```

where:

```
$\gamma = \exp(-\alpha(t_1 - t_0))$$\
```

which is:

```
$$\mu = X_{t_0} \left\ \frac{\exp(-\alpha(t - t_0)) - \exp(-2\alpha(t_1 - t_0))}{1 - \exp(-2\alpha(t_1 - t_0) - \alpha(t - t_0))} \right\;\n+ X_{t_1} \left\ \frac{\exp(-\alpha(t_1 - t_0)) - \exp(-2\alpha(t - t_0) - \alpha(t_1 - t))}{1 - \exp(-2\alpha(t_1 - t))} \right\;\n$$
```

For small $t_1 - t_0$ both $t_1 - t$ and $t - t_0$ are small, so:

```
$$\mu \rightarrow X_{t_0} \left\ \frac{\{1 - \alpha(t - t_0)\} - \{1 - 2\alpha(t_1 - t) - \alpha(t)\}}{1 - \{1 - 2\alpha(t_1 - t_0)\}} \right\;\n+ X_{t_1} \left\ \frac{\{1 - \alpha(t_1 - t)\} - \{1 - 2\alpha(t - t_0) - \alpha(t_1)\}}{1 - \{1 - 2\alpha(t_1 - t_0)\}} \right\;\n$$
```

which yields the Brownian bridge result for the conditional:

```
$$\mu \rightarrow X_{t_0} \frac{t_1 - t_0}{t_1 - t_0} + X_{t_1} \frac{t - t_0}{t_1 - t_0} \$$
```
