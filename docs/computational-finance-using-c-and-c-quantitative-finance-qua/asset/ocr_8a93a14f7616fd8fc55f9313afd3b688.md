where $f(\theta) = 1/(2\pi)$, $f(r) = re^{-r^2/2}$ are independent probability density functions.

The corresponding cumulative distribution functions $F(\theta)$ and $F(r)$ can be found by evaluating the following integrals:

$$F(\theta) = \frac{1}{2\pi}\int_0^{\theta}d\theta = \frac{\theta}{2\pi}$

and

$$F(r) = \int_0^r e^{-r^2/2}dr = [-e^{-r^2/2}]_0^r = 1 - e^{-r^2/2}$

We now want to draw variates $\hat{r}$ and $\hat{	heta}$ from the probability distributions $f(r)$ and $f(\theta)$ respectively. To do this we will use the result (see for example Evans, Hastings, and Peacock (2000)), that a uniform variate $\hat{u}$, from $U(0,1)$ can be transformed into a variate $\hat{v}$ from the probability distribution $f(v)$ by using $\hat{v} = F^{-1}(\hat{u})$, or equivalently $F(\\hat{v}) = \hat{u}$. The variates $\hat{v}$ are found by first drawing the uniform variate $\hat{u}$ and then finding the value of $v$ which makes cumulative distribution function $F(v)$ equal to $\hat{u}$.

Therefore, if $V_1$ and $V_2$ are from $U(0,1)$, then the variates $\hat{r}$ and $\hat{	heta}$ which satisfy $V_1 = F(r) = 1 - e^{-r^2/2}$, and $V_2 = F(\theta) = \hat{	heta}/(2\pi)$ are from the distributions $f(r)$ and $f(\theta)$.

For convenience we define the $U(0,1)$ variates

$$V_1 = 1 - V_1' = e^{-r^2/2}$ and $V_2 = V_2'$

So we have

$$V_1 = e^{-r^2/2}$, $V_2 = \frac{\hat{	heta}}{2\pi}$

and

$$log V_1 = \frac{-\hat{r}^2}{2}$, $\hat{r} = (-2\log V_1)^{1/2}$, and $\hat{	heta} = 2\pi V_2$

Since $\hat{r}$ is from the same distribution as $r$, and $\hat{	heta}$ is from the same distribution as $\theta$, we can use

$$log V_1 = -r^2/2$, $r = (-2\log V_1)^{1/2}$, and $\theta = 2\pi V_2$

Substituting these results into Eq. (3.3.2) gives

$$x = (-2\log V_1)^{1/2} \cos 2\pi V_2$, $y = (-2\log V_1)^{1/2} \sin 2\pi V_2$

where $x$ and $y$ are $N(0,1)$.
