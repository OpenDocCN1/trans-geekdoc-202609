# 8.4 Equity deal classes

In this section we provide the C# code for both single and multiset equity options. The deal attributes correspond to the properties of the deal class, and attribute default values can be readily found by reading the C# code. The enumerations used by the deal classes are declared below.

```
public enum BuySell ( Buy, Sell );
public enum PutCall ( Put, Call );
public enum EuropeanAmerican ( European, American );
public enum MinimumMaximum ( Minimum, Maximum );
public enum UseMonteCarlo ( Yes, No );
public enum CalculationMethod ( Analytic, Numeric, MonteCarlo );
```

and it can be that the enumerators have obvious names.
It has already been noted that the volatility used by the application to price options is supplied as a deal attribute, rather than being stored as market data. The reason for this simplicity is. In Chapter 4 we mentioned that volatility surface is required to represent the implied volatility to price options. Storing the implied volatility would thus require a set of volatility surfaces in the market data file and multidimensional interpolation to retrieve the volatility applicable to a given option. It was decided to supply the volatility as a trade attribute—and update it appropriately.
