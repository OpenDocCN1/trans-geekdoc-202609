We now use the Roll, Geske, and Whaley formula for the current value of an American call which pays a single cash dividend $D_1$ at time $t_i$; it is

```
$C(S, E, \tau) = S_D \left\{ N_1(b_1) + N_2(a_1, -b_1, \sqrt{\frac{t_1-t}{\tau}}) + D_1 \exp(-r(t_1-t))N_1(b_2) - E \exp(-r\tau)N_1(b_2)\exp(r\tau) + N_2(a_2, -b_2, \sqrt{\frac{t_1-t}{\tau}}) \right\}$ (5.2.6)
```

where $S_D$ is given by Eq. (5.2.1), $E$ is the exercise price, $	au$ is the option expiry date, $t$ represents the current time, $	au$ is the option maturity, $N_1(a)$ is the univariate cumulative normal density function with upper integral limit $a$, and $N_2(a,b,\rho)$ is the bivariate cumulative normal density function with upper integral limits $a$ and $b$ and correlation coefficient $\rho$. The other symbols in Eq. (5.2.6) are defined as

```
$a_1 = \frac{\log(S/E) + (r + \sigma^2/2)\tau}{\sigma\sqrt{\tau}},\quad a_2 = a_1 - \sigma\sqrt{\tau}\nb_2 = \frac{\log(S/S^*) + (r + \sigma^2/2)(t_1-t)}{\sigma\sqrt{\tau}},\quad b_2 = b_1 - \sigma\sqrt{t_1-t}$
```

and $S$ is the current (time $t$) asset price, $S^*$ is found using Eq. (5.2.5), $r$ is the riskless interest rate, $\sigma$ is the asset's volatility, $\tau = T-t$ and $\tau_1 = T-t_1$. To compute the value of an American call option pays $n$ cash dividends $D_i, i=1,...,n$, at times $t_i, i=1,...,n$, we can use the fact that optimal exercise usually occurs at the final ex-dividend date $t_n$; for example the American call but not $t_1$ should be set to $t_n$, $D_1$ should be set to $D_n$, and $S_D$ is given by

```
$S_D = S - \sum_{i=1}^n D_i \exp(-r(t_i-t))$ (5.2.7)
```
