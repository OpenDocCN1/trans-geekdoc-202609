# European options

We can now solve Eq. (4.4.31) by using the result given in Eq. (2.3.11). We have

```
$S_T = S \exp(v(T-t_0) + \sigma W_{T-t_0})$
```

where $S$ is the price at current time $t_0$, and $v = r - \sigma^2/2$.
The forward price with maturity $T$, denoted by $S(t_0, T)$, is $E[S_T]$. From Appendix D.2 we have

```
$S(t_0, T) = E[S_T] = S \exp(r(T-t_0))$ (4.4.32)
```

Using Eq. (2.3.9) the distribution of the asset at current time $T$ is:

```
$\log \frac{S_T}{S} \sim N(v(T-t_0), \sigma^2(T-t_0))$ (4.4.33)
```

We want to consider the current price of a European option with strike price $E$ which matures at time $T$, and thus has a duration of $	au = T-t_0$. The approach which we adopt here is to first derive an expression for the value of a European call option, and then use the put/call parity relationships of Section 2.2 to obtain the value of the corresponding European option.
Referring to (4.2.1) we have

```
$V_0 = B_0 E [\frac{H_T}{B_T}] = \frac{B_0}{B_T} E[H_T]$ (4.4.34)
```

Substituting $B_0 = 1, B_T = \exp(r(T-t_0)) = \exp(r	au)$, and $H_T = \max(S_T-E, 0)$ we have

```
$V_0 = \frac{1}{\exp(r\tau)} E[\max(S_T-E, 0)]$ (4.4.35)
```

and so denoting the value of call by $c(S, E, 	au)$ we obtain

```
$c(S, E, \tau) = \exp(-r\tau) E[\max(S_T-E, 0)]$ (4.4.36)
```

It can be seen from Eq. (4.4.36) the value of the European option is the expected value of the option's payoff at maturity, discounted to current time $t$ by the riskless interest rate $r$.
This means the value of the call option can be written

```
$c(S, E, \tau) = \exp(-r\tau) \int_{S_T=E}^{\infty} f(S_T)(S_T-E) dS_T$ (4.4.37)
```

where $f(S_T)$ is the probability density function of $S_T$.nInstead of integrating over $S_T$ we will evaluate (4.4.37) using the variable $X = \log(S_T/S)$. From Eq. (4.4.33), we know that the probability density function of X is

```
$f(X) = \frac{1}{\sigma\sqrt{2\pi}} \exp(\left(-\frac{(X-(r-\sigma^2/2)\tau)^2}{2\sigma^2\tau}\right)$ (4.4.38)
```
