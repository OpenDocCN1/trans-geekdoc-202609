#  2.12.3 Expectation of a stochastic integral

If $f(t)$ is a deterministic function of time then

```
$$E\left[\int_{s=a}^{b} f(s) \ dW_s\right] = 0$$\quad (2.12.6)$
```

PROOF. We first express the integral (2.12.6) by the following summation:

```
$\int_{s=a}^{n-1} f(s) dW_s = \sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}} - W_{t_i}),$$
```

where $a < t_0 < t_1 < \dots < t_n < t_b$

Taking expectations of the above equation yields:

```
$$$E\left[\int_{s=a}^{b} f(s) dW_s\right] = E\left[\sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}} - W_{t_i})\right]$$\n= \sum_{i=0}^{n-1} f(t_i)E[W_{t_{i+1}} - W_{t_i}]\n= 0$$
```

we have used $E[W_{t_{i+1}} - W_{t_i}] = 0$, which is Brownian motion property (iii) in Section 2.1.
