# D.3 The Student’s $t$ distribution

This section derives an expression for the kurtosis of the Student’s $t$ distribution.
Since the Student’s $t$ distribution density function is:

```
$f(\epsilon_i) = \mathcal{K} \left[1 + \frac{\epsilon_i^2}{h_i(\nu-2)}\right]^{-(\nu+1)/2}$
```

where

```
$$\mathcal{K} = \frac{\Gamma((
u+1)/2)(\nu-2)^{-1/2}}{\pi^{1/2}\Gamma(\nu)}h_i^{-1/2}$
```

we have:

```
$E[\epsilon_i^2] = 2\mathcal{K} \int_0^{\infty} \frac{\epsilon_i^2 d\epsilon_i}{(1+\epsilon_i^2/(h_i(\nu-2)))^{(\nu+1)/2}}$$\n=2\mathcal{K}(h_i(\nu-2))(\nu+1)/2} \int_0^{\infty} \frac{\epsilon_i^2 d\epsilon_i}{(h_i(\nu-2))+\epsilon_i^2)^{(\nu+1)/2}}$
```


Substituting for $\mathcal{K}$ and simplifying we obtain:

```
$E[\epsilon_i^2] = \frac{h_i(\nu-2)\Gamma((\nu-1)/2)}{\Gamma(\nu/2)}$
```

```
$$\Gamma(\left\frac{\nu-2}{2}\right)\Gamma(\left\frac{\nu-2}{2}\right) = \Gamma(\left\frac{\nu-1}{2}+1) = \Gamma(\left\frac{\nu}{2}\right)$
```
