# Coupon payment on time

In this section we will justify the approach we have adopted in obtaining the present value of future cashflows generated from vanilla forward rates.

From Eq. (4.2.1) we know that the value at time $t_0$ of a coupon payment at time $t_k$ is:

```
$V_{t_0} = DF(t_0, t_k) E^{Q_k} \left[ \frac{F(t_{k-1}, t_{k-1}, t_k)}{DF(t_k, t_k)} ight] 	au P$
```

be the zero coupon bond which we use, and we have chosen to be the zero coupon bond matches at time $t_k$. Since $DF(t_k, t_k) = 1$ we can write

```
$V_{t_0} = DF(t_0, t_k) E^{Q_k} \left[ F(t_{k-1}, t_{k-1}, t_k) ight] \quad (7.2.28)
```

In Section 7.2.3 we show that $F(t, t_{k-1}, t_{k-1})$ follows the process:

```
$d(F(t, t_{k-1}, t_{k-1})) = \sigma_k F(t, t_{k-1}, t_{k-1}) dW^k \quad (7.2.29)
```

If we assume $\sigma_k$ is constant, then Eq. (7.2.29) is GBM (see Chapter 2) and has the solution:

```
$F(t, t_{k-1}, t_k) = F(t_0, t_{k-1}, t_k) \exp \left( \frac{(t-t_0)\sigma_k^2}{2} + \sigma_k W_t^k ight) \quad (7.2.30)
```

where we have taken $W_{t_0}^k = 0$. Substituting $t=t_{k-1}$ into Eq. (7.2.30) gives:

```
$F(t_{k-1}, t_{k-1}, t_k) = F(t_0, t_{k-1}, t_k) \exp \left( \frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k ight) \quad (7.2.31)
```

which means:

```
$E^{Q_k} [F(t_{k-1}, t_{k-1}, t_k)] \n= E^{Q_k} \left[ F(t_0, t_{k-1}, t_k) \exp \left( \frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k ight) ight] \n= F(t_0, t_{k-1}, t_k) E^{Q_k} \left[ \exp \left( \frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k ight) ight] \n= F(t_0, t_{k-1}, t_k) E^{Q_k} \left[ \exp \left( \frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k \sqrt{t_{k-1}-t_0} N(0,1) ight) ight] \n= F(t_0, t_{k-1}, t_k)$
```

where we have used this (Appendix D.2)

```
$E^{Q_k} \left[ \exp \left( -\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k \sqrt{t_{k-1}-t_0} N(0,1) ight) ight] \n= \exp \left( -\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \frac{(t_{k-1}-t_0)\sigma_k^2}{2} ight) = 1$
```
