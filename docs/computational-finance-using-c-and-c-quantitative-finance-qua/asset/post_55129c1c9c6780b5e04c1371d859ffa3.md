## 2.12 Other useful results

### 2.12.1 Fubini's theorem

Fubini's theorem states that (for well-behaved functions) the value of a multidimensional integral is independent of the order in which the integral is evaluated. For example, the two-dimensional integral of $f(X, Y)$ can be evaluated as:

```
$$\int_{X=a}^b \int_{Y=c}^d f(X, Y) \ dY \ dX = \int_{Y=c}^d \int_{X=a}^b f(X, Y) \ dX \ dY = \int_{X=a}^b \int_{Y=c}^d f(X, Y) \ dY \ dX$
```

We will mainly use this in the form:

```
$$\int_{s=0}^\infty f(W, s) \ ds = \int_{s=0}^\infty E[f(W, s)] \ ds \quad (2.12.1)$$
```

Since

```
$E[f(W, s)] = \int_{-\infty}^\infty P(W, s) f(W, s) \ dW$
```

Where $P(W, s)$ is the probability density function of $f(W, s)$, we can then use Eq. (2.12.1) in full as:

```
$$\int_{W=-\infty}^\infty \int_{s=0}^\infty P(W, s) f(W, s) \ ds \ dW = \int_{s=0}^\infty \int_{W=-\infty}^\infty P(W, s) f(W, s) \ dW \ ds$$
```

## 2.12.2 Ito's isometry

The expected value of the integral of the well-behaved function $f(W_t, t)$ satisfies:

PROOF. We use the following approximation:

```
$\int_{s=t_a}^{t_b} f(W_s, s) dW_s = \sum_{i=0}^{n-1} f(W_{t_i}, t_i)(W_{t_{i+1}} - W_{t_i})$
```

where $a = t_0 < t_1 < \dots < t_n < t_b$ and $t_{i+1} - t_i = \Delta t$. Thus the integral on the left-hand side of Eq.

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j)(W_{t_{i+1}} - W_{t_i})(W_{t_{j+1}} - W_{t_j}) \quad (2.12.3)$
```

Taking expectations of Eq. (2.12.3) we obtain:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j) E[(W_{t_{i+1}} - W_{t_i})(W_{t_{j+1}} - W_{t_j})] \quad (2.12.4)$
```

which means:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j) E[(W_{t_{i+1}} - W_{t_i})(W_{t_{j+1}} - W_{t_j})] \quad (2.12.5)$
```

From Brownian motion property (iii) in Section 2.1 we have:

```
$E[(W_{t_{i+1}} - W_{t_i})(W_{t_{j+1}} - W_{t_j})] = 0 \quad \text{when } i \neq j \text{ and when } i = j$
```

Therefore Eq. (2.12.5) can be rewritten as:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right] = \sum_{i=0}^{n-1} f(W_{t_i}, t_i)^2 \Delta t_i$
```

which means:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right] = E\left[\int_{s=t_a}^{t_b} f(W_s, s)^2 ds\right]$
```

## 2.12.3 Expectation of a stochastic integral

If $f(t)$ is a deterministic function of time then

```
$$E\left[\int_{s=a}^{b} f(s) \ dW_s\right] = 0 \quad (2.12.6)$$
```

PROOF. We first express the integral (2.12.6) by the following summation:

```
$\int_{a}^{b} f(s) dW_s = \sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}} - W_{t_i}),$
```

where $a = t_0 < t_1 < \dots < t_n = b$

Taking expectations of the above equation yields:

```
$$E\left[\int_{s=a}^{b} f(s) dW_s\right] = E\left[\sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}} - W_{t_i})\right]$
= \sum_{i=0}^{n-1} f(t_i)E[W_{t_{i+1}} - W_{t_i}]
= 0$$
```

we have used $E[W_{t_{i+1}} - W_{t_i}] = 0$, which is Brownian motion property (iii) in Section 2.1.

# 3 Generation of random variates

## 3.1 Introduction

Monte Carlo simulation and random number generation are techniques that are widely used in financial engineering as a means of assessing the level of exposure to risk. Typical applications include the pricing of financial derivatives and scenario generation in portfolio management. In fact many of the financial applications that use Monte Carlo simulation involve the evaluation of various stochastic integrals which are related to the probabilities of particular events occurring.

In many cases, however, the assumptions of constant volatility and a lognormal distribution for $S_T$ are quite restrictive. Real financial applications may require a variety of extensions to the standard Black–Scholes model, time-varying volatities, caps, floors, barriers, etc. In these circumstances, it is often the case that there is no closed solution to the problem. Monte Carlo simulation can then provide a very useful method of evaluating the required integrals.

When we evaluate the integral of a function, $f(x)$, in the s-dimensional cube $I^s$, by the Monte Carlo method we are in calculating the average of the function at a set of randomly sampled points. Each point adds linearly to the accumulated sum that will become the integral and linearly to the accumulated sum of squares that will become the variance of the integral.

When there are $N$ sample points, the integral is:

```
$$\nu = \sum_{i=1}^{N} f(x^i)$$
```

where $u$ is used to denote the approximation to the integral and $x^1, x^2, \dots, x^N$ are the $N$, $s$-dimensional, sample points.
