Substituting for erfc(x) we obtain:

$I(x) = 2 - \{2 - \text{erfc}(-x)\} = \text{erfc}(-x)$

So we have

$$\text{erfc}(-x) = \frac{2}{\sqrt{\pi}} \int_{-\infty}^{x} \exp(-t^2) dt \ (E.3.2)$

Now the cumulative normal distribution is defined as

$N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{x} \exp(-t^2) dt$

Letting $u = t/2$, we have $du = \sqrt{2} dt$, and for the upper limit we have $x = t\sqrt{2}$, or $t = x/\sqrt{2}$.

This integral becomes:

$N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{0}^{x/\sqrt{2}} \exp(-t^2)\sqrt{2} dt \ (E.3.3)$

From Eq. (E.3.2) we have:

$N_1(x) = \frac{1}{2} \text{erfc}(\frac{x}{\sqrt{2}})$

We also note that:

$N_1(-x) = 1 - N_1(x)$

# E.4 Arithmetic and geometric progressions

# Arithmetic progression

The sum of the first $n$ terms of an arithmetic progression is:

$s_n = \frac{n}{2}[2a_1 + (n-1)d] \ (E.4.1)$

where $a_1$ is the first term, and $d$ is the common difference; that is, the terms in the sequence are: $a_1, a_1+d, a_1+2d, a_1+3d, \dots$.

# Geometric progression

The sum of the first $n$ terms of a geometric progression is:

$s_n = \frac{a_1(1-r^n)}{1-r} \ (E.4.2)$

where $a_1$ is the first term, and $r$ is the common ratio; that is, the terms in the sequence are: $a_1, a_1r, a_1r^2, a_1r^3, \dots$.
