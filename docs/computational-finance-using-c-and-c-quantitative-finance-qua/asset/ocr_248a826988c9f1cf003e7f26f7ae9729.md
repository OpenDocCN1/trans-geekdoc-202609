# Appendix H: Brownian motion

Expressed in terms of the reflected Brownian motion, $X_t^R = 2b - X_t$, Eq. (H.5.8) can be written:

```
$P(m_t^X \le b, \bar{X}_t \ge x)$
\n= \mathbb{E}^P \left[\mathbb{1}_{[2b-X_t^R \ge x)} \exp\left(\\frac{\nu(2b-X_t)}{\sigma^2} - \frac{\nu^2 t}{\sigma^2}\right)\right]\n\= \exp\left(\frac{2\nu b}{\sigma^2}\right) \mathbb{E}^P \left[\mathbb{1}_{[2b-X_t^R \ge x)} \exp\left(\\frac{\nu X_t^R}{\sigma^2} - \frac{\nu^2 t}{\sigma^2}\right)\right]$ (H.5.9)
```

Since

```
$\mathbb{1}_{[2b-X_t^R > x]} = \mathbb{1}_{[2b-X_t^R < -x]} = \mathbb{1}_{[X_t^R < 2b-x]}$
```

Equation (H.5.9) becomes:

```
$P(m_t^X \le b, \bar{X}_t \ge x)\n\n= \exp\left(\frac{2\nu b}{\sigma^2}\right) \mathbb{E}^P \left[\mathbb{1}_{[X_t < 2b-x]} \exp\left(\frac{\nu X_t}{\sigma^2} - \frac{\nu^2 t}{\sigma^2}\right)\right]$ (H.5.10)
```

where, for of notation, we now denote $X_t^R$ by $X_t$ on the right-hand side of Eq. (H.5.10).

Therefore:

```
$P(m_t^X \le b, \bar{X}_t \ge x)\n\= \exp\left(\frac{2\nu b}{\sigma^2}\right) \int_{X_t=-\infty}^{X_t=2b-x} \frac{1}{\sqrt{2\pi t}} \exp\left(\frac{(X_t^* + 2\nu X_t t + +\nu^2 t^2)}{\sigma^2}\right) dX_t\n\= \frac{1}{\sqrt{2\pi t}} \exp\left(\frac{2\nu b}{\sigma^2}\right) \int_{X_t=-\infty}^{X_t=2b-x} \exp\left(\frac{(X_t + +\nu t)^2}{\sigma^2}\right) dX_t\n\= \frac{1}{\sqrt{2\pi t}} \exp\left(\frac{2\nu b}{\sigma^2}\right) \int_{V=-\infty}^{V=(2b-x+vt)/\sqrt{t}} \exp\left(-\frac{V^2}{2}\right) dV
```

If $V = (X_t + \nu t)/\sqrt{t}$, then $dX_t = \sqrt{t} dV$, $X_t = 2b-x$ corresponds to $V = (2b-x+vt)/\sqrt{t}$, and $V = -\infty$ corresponds to $V = -\infty$.

```
$= N_1\left(\frac{2b-x+vt}{\sqrt{t}}\right)$
```

We thus obtain:

```
$P(m_t^X \le b, \bar{X}_t \ge x) = \exp\left(\frac{2\nu b}{\sigma^2}\right) N_1\left(\frac{2b-x+vt}{\sqrt{t}}\right)$
```
