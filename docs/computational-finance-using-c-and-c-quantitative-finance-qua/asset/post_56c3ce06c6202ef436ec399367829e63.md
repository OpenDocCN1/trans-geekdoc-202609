
Now since $\phi$ is a martingale under $Q^{k+1}$ we know that $D = 0$, and therefore Eq. (7.2.65) results in:

```
$$(1 + F_{k+1})F_k\mu_k \, dt = -\rho_{k,k+1}\sigma_k\sigma_{k+1}F_k F_{k+1} \, dt$$
```

This means the drift is:

```
$$\mu_k = -\frac{\rho_{k,k+1}\sigma_k\sigma_{k+1}}{1 + F_{k+1}}$$ $$(7.2.66)$$
```

Substituting for $\mu_k$ in Eq. (7.2.61) gives:

```
$$dF_k = F_k\sigma_k \left\{ \frac{\rho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \, dt + dW^{k+1} \right\}$ $$(7.2.67)$$
```

Comparing Eq. (7.2.67) with Eq. (7.2.40) we have:

```
$$dW^k = -\frac{\rho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \, dr + dW^{k+1}$$ $$(7.2.68)$$
```

which is the relationship between Brownian motions $dW^k$ and $dW^{k+1}$.

$i \geq k+2$
Let the stochastic process followed by $F_k$ under $Q^{k+1}$ be:

```
$$dF_k = F_k\mu_k \, dt + F_k\sigma_k \, dW^{k+2}$$ $$(7.2.69)$$
```

Where $W^k$ is Brownian motion under probability measure $Q^{k+2}$, and drift term $\mu_k$ is to be found.
Replacing $k$ with $k+1$ in Eq. (7.2.68) gives:

```
$$dW^{k+1} = -\frac{\rho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}} \, dr + dW^{k+2}$$ $$(7.2.70)$$
```

and using Eq. (7.2.70) to substitute for $dW^{k+1}$ in Eq. (7.2.68) gives:

```
$$dW^k = -F_k\sigma_k \left\{ \frac{\rho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} \, dt - \frac{\rho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}} \, dt \right\}$$ $$(7.2.71)$$
```

Substituting for $dW^k$ in Eq. (7.2.40) gives:
and thus the drift is

```
$$\mu_k = -\frac{\rho_{k,k+1}\sigma_k\sigma_{k+1}F_{k+1}}{1 + F_{k+1}} - \frac{\rho_{k+1,k+2}\sigma_{k+1}\sigma_{k+2}F_{k+2}}{1 + F_{k+2}}$$ $$(7.2.72)$$
```

The following general expression can be derived in a similar manner:

```
$$dF_k = -F_k\sigma_k \sum_{j=k+1}^i \frac{\rho_{k,j}\sigma_k\sigma_j}{1 + F_j} \, dt + \sigma_k F_k \, dW^i$ $$(7.2.73)$$
```

where all the symbols have the same means as before, but now $i$ can take any integer value greater than $k$.

## 7.2.4 Interest rate quantos

This section considers derivatives whose value depends on the foreign interest rate yield curve but have a payoff in domestic currency. We use the same notation as in Section 7.3, which deals with foreign exchange derivatives.

For example, a standard rate cap has a payoff in domestic currency and also depends on the domestic currency forward rates. The value at time $t_0$ of a caplet which pays at time $t_k$ and extends from time $t_{k-1}$ to $t_k$ is:

```
$Caplet(t_0) = P\tau D^p(t_0, t_k)E^Q[max(F^d_k - K, 0)]$
```

where P is the principal, K is the strike, $\tau = t_{k-1}-t_k$, $F^d$ is the domestic forward rate $F^d(t_0, t_k, t_{k-1})$. Equation (7.2.74) can be evaluated using the Black–Scholes formula as:

```
$Caplet(t_0) = P\tau D^p(t_0, t_k)\{F^d(t_0, t_k, t_{k-1})N_1(d_1) - KN_1(d_2)\}$
```

where $\sigma_d$ is volatility of $F^d$, and

```
$d_1 = \frac{\log(F^d(t_0, t_k, t_{k-1})/K) + \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$
$d_2 = \frac{\log(F^d(t_0, t_k, t_{k-1})/K) - \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$
```

In Section 7.2.3 we showed that $(F^d(t, t_{k-1}, t_k)/DF^p(t, t_k))$ is a martingale, is zero drift when $DF^p(t, t_k)$ is used as numeraire.

```
$dF^d(t, t_{k-1}, t_k) = \sigma_d F^d(t, t_{k-1})dW_t^Q$
```

## Quanto caplet

In a quanto caplet using the domestic forward rate $F^d(t_0, t_k)$ we use foreign forward rate $F^f(t, t_{k-1}, t_k)$. Under probability measure $\mathbb{F}$ associated with foreign zero coupon bond $DF^f(t, t_k)$ the foreign forward rate is a martingale, and is described by the following equation:

```
$dF^f(t, t_{k-1}, t_k) = \sigma_f F^f(t, t_{k-1})dW_t^{\mathbb{F}}$
```

However, when we use $DF^d(t, t_k)$ as numeraire the process $(F^f(t, t_{k-1}, t_k)/DF^d(t, t_k))$ has a drift, and follows the process:

```
$dF^f(t, t_{k-1}, t_k) = F^f(t, t_{k-1}, t_k)\alpha dt + \sigma_f F^f(t, t_{k-1}, t_k)dW_t^{\mathbb{Q}}$
```

Our aim is to find the value of $\alpha$ and then price the quanto caplet:

```
$QCaplet(t_0) = P\tau D^p(t_0, t_k)\times\{F^f(t_0, t_{k-1})\exp(\alpha(t_{k-1}-t_0))N_1(d_1) - KN_1(d_2)\}$
```

where $P$ is the principal, K is the strike, $\tau = t_{k-1} - t_k$, $F^f(t_0, t_{k-1}, t_k)$ is foreign currency forward rate, $\sigma_f$ is volatility of $F^f(t_0, t_{k-1}, t_k)$ and

```
$d_1 = \frac{\log(F^f(t_0, t_{k-1}, t_k)/K) + (\alpha + \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
$d_2 = \frac{\log(F^f(t_0, t_{k-1}, t_k)/K) + (\alpha - \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```

We will now derive the value of $\alpha$.
First we define two processes $X_1(t)$ and $X_2(t)$ such that:

```
$X_1(t) = \left(\frac{DF^f(t, t_{k-1}) - DF^f(t, t_k)}{DF^f(t, t_k)}\right)X_d^f(t) \quad (7.2.80)$
```

and

```
$X_2(t) = \tau X_d^f(t)\frac{DF^f(t, t_k)}{DF^f(t, t_k)} = \tau X_d^f(t, t_k) \quad (7.2.81)$
```

$X_d^f(t, t_k)$ is the forward foreign exchange rate (Section 7.3). Therefore,

```
$X_1(t) = \frac{DF^f(t, t_{k-1}) - DF^f(t, t_k)}{\tau DF^f(t, t_k)} = F^f(t, t_{k-1}, t_k) \quad (7.2.82)$
```

Now $X_1$ and $X_2$ are martingales under $\mathbb{Q}$ so we have:

```
$dX_1 = \sigma_1 X_1 dW_1^{\mathbb{Q}} \quad (7.2.83)$
```

and

```
$dX_2 = \sigma_2 X_2 dW_2^{\mathbb{Q}} \quad (7.2.84)$
```

Equation (7.2.84) can be expressed as

```
$d\left(\frac{\tau X_d^f(t, t_k)}{\tau X_d^f(t, t_k)}\right) = \sigma_x dW_x^{\mathbb{Q}} \quad (7.2.85)$
```

Using it to obtain:

```
$d\left(\frac{X_1}{X_2}\right) = \frac{X_1}{X_2}[\sigma_1 dW_1^{\mathbb{Q}} - \sigma_2 dW_2^{\mathbb{Q}}] + \frac{X_1}{X_2}[E[(\sigma_1 dW_1^{\mathbb{Q}})^2] - E[(\sigma_1 dW_1^{\mathbb{Q}})(\sigma_2 dW_2^{\mathbb{Q}})] \quad (7.2.86)$
```

and the following processes for $\log(X_1)$ and $\log(X_2)$:

```
$d\log(X_1) = -\frac{\sigma_1^2}{2}dt + \sigma_1 dW_1^{\mathbb{Q}}$
$d\log(X_2) = -\frac{\sigma_2^2}{2}dt + \sigma_2 dW_2^{\mathbb{Q}} \quad (7.2.87)$
```

## Other financial derivatives

Using Eq. (7.2.85) we can write Eq. (7.2.87) as:

```
$d\log(\tau X_d^f(t, t_k)) = -\frac{\sigma_x^2}{2} dt + \sigma_x dW_x^{\mathbb{Q}} \quad (7.2.88)$
```

Now, where we ignored terms in $dt$ greater than 1.
In addition

```
$E[d\log(X_2) - d\log(X_1)] = -E[d\log(X_2) d\left(\frac{X_1}{X_2}\right)] = -E[d\log(X_2) d(F^f(t, t_{k-1}, t_k)] = -E[d\log(X_d^f(t, t_k)) d(F^f(t, t_{k-1}, t_k)] = -\sigma_x\sigma_f\rho_{x,f} dt$
```

where $\sigma_x$ is the volatility of the foreign exchange rate $X_d^f(t, t_k)$, $\sigma_f$ is the volatility of the forward rate $F^f(t, t_{k-1}, t_k)$, and $\rho_{x,f}$ is the correlation between $dW_x^Q$ and $dW_f^Q$.
Therefore Eq. (7.2.86) can be written as:

```
$d\left(\frac{X_1}{X_2}\right) = -\frac{X_1}{X_2}(\sigma_x\sigma_f\rho_{x,f}) dt + \frac{X_1}{X_2}\{\sigma_1 dW_1^{\mathbb{Q}} - \sigma_2 dW_2^{\mathbb{Q}}\}$
```

which means that

```
$D^f(t, t_{k-1}, t_k) = -F^f(t, t_{k-1}, t_k)(\sigma_x\sigma_f\rho_{x,f}) dt + \sigma_f F^f(t, t_{k-1}, t_k) dW^Q \quad (7.2.89)$
```

and $\alpha = -\sigma_x\sigma_f\rho_{x,f}$.

## Quanto floorlet

The formula to value a quanto floorlet can be obtained in similar manner to that used for the quanto caplet.
The value at time $t_0$ of a standard floorlet which pays at time $t_k$ and extends from time $t_{k-1}$ to time $t_k$ is:

```
$Floorlet(t_0) = P\tau DF^d(t_0, t_k)E^{Q^d}[\max(K - F_d^d, 0)]$
```

Where P is the principal, K is the strike, $\tau = t_{k-1}-t_k$, $F_k$ is the domestic forward rate $F(t_0, t_{k-1}, t_k)$. Equation (7.2.90) can be evaluated using the Black-Scholes formula as:

```
$Floorlet(t_0) = P\tau DF^d(t_0, t_k)[-F^d(t_0, t_{k-1}, t_k)N_1(d_1) + KN_1(d_2)]$
```

where the symbols have the same meaning as the corresponding quanto caplet.

```
$d_1 = \frac{\log(F^d(t_0, t_{k-1}, t_k)/K) + \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$
$d_2 = \frac{\log(F^d(t_0, t_{k-1}, t_k)/K) - \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$
```

In a quanto floorlet, instead of using the domestic forward rate $F^d(t_0, t_{k-1}, t_k)$, we use the foreign forward rate $F^f(t_0, t_{k-1}, t_k)$:

```
$Floorlet(t_0) = P\tau DF^f(t_0, t_k)\times\{-F^f(t_0, t_{k-1}, t_k)\exp(\alpha(t_{k-1}-t_0))N_1(d_1) + KN_1(d_2)\}$
```

where $P$ is the principal, K is the strike, $\tau = t_{k-1} - t_k$, $F^f(t_0, t_{k-1}, t_k)$ is the foreign currency forward rate, $\sigma_f$ is the volatility of $F^f(t_0, t_{k-1}, t_k)$ and

```
$d_1 = \frac{\log(F^f(t_0, t_{k-1}, t_k)/K) + (\alpha + \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
$d_2 = \frac{\log(F^f(t_0, t_{k-1}, t_k)/K) + (\alpha - \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```
