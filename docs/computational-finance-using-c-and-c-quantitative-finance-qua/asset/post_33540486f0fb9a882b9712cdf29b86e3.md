$dS_t = S_t \mu dt + S_t \sigma dW_t$

The process in Eqs. (2.2.2) and (2.2.3) is termed geometric Brownian motion; which we will abbreviate as GBM. This is because the relative (rather than absolute) price changes follow Brownian motion.

## 2.3 Ito's formula (or lemma)

In this section we will derive Ito's formula; a more rigorous treatment can be found in Karatzas and Shreve (1991).

Let us consider the stochastic process X:

$dX = a dt + b dW = a dt + b \sqrt{dt} dZ, \quad dZ \sim N(0, 1), \quad dN \sim N(0, dt)$

where $a$ and $b$ are constants. We want to find the process followed by a function of the stochastic variable $X$, that is $\phi(X,t)$. This can be done by applying a Taylor expansion, up to second order, in the two variables $X$ and $t$ as follows:

$\phi^* = \phi + \frac{\partial \phi}{\partial t} dt + \frac{\partial \phi}{\partial X} dX + \frac{1}{2} \frac{\partial^2 \phi}{\partial X^2} dX^2 + \frac{1}{2} \frac{\partial^2 \phi}{\partial t^2} dt^2 + \frac{\partial \phi}{\partial X} dX dt$

$\phi^*$ is used to denote the value $\phi(X+dX, t+dt)$, and $\phi$ denotes the value $\phi(X,t)$. We will now consider the magnitude of the terms $dX^2$, $dX dt$, and $dt^2$ as $dt \to 0$. First

$dX^2 = (a dt + b \sqrt{dt} dZ)(a dt + b \sqrt{dt} dZ) = a^2 dt^2 + 2ab dt^{3/2} dZ + b^2 dt^2$

then

$dX dt = a dt^2 + b dt^{3/2} dZ$

So as $dt \to 0$, and ignoring all terms in $dt$ of order greater than 1, we have:
$dX^2 \sim b^2 dt^2 \quad dt^2 \sim 0, \quad dX dt \sim 0$

Therefore Eq. (2.3.2) can be rewritten as:

$d\phi = \frac{\partial \phi}{\partial t} dt + \frac{\partial \phi}{\partial X} dX + \frac{1}{2} \frac{\partial^2 \phi}{\partial X^2} E[dX^2]$

where $d\phi = \phi^* - \phi$, and we have replaced $dX^2$ with its expected value $E[dX^2]$.
Now

$E[dX^2] = E[b^2 dt^2 dZ^2] = b^2 dt$

where we have used the fact that $dZ \sim N(0, 1)$, the variance of $dZ$, $E[dZ^2]$, is by definition equal to 1. Using these values in Eq. (2.3.3) and substituting for $dX$ from Eq.(2.3.1), we obtain:

```
$d\phi = \frac{\partial \phi}{\partial t}dt + \frac{\partial \phi}{\partial X}(a\dt + b\dW) + \frac{b^2}{2}\frac{\partial^2 \phi}{\partial X^2}dt$ (2.3.4)

$d\phi = (\frac{\partial \phi}{\partial t} + a\frac{\partial \phi}{\partial X} + \frac{b^2}{2}\frac{\partial^2 \phi}{\partial X^2})dt + \frac{\partial \phi}{\partial X}b\dW$ (2.3.5)
```

In particular we are considering the Geometric Brownian process:
$dS = \mu S dt + \sigma dW$

where $\mu$ and $\sigma$ are constants, substituting $X=S, a=\mu S,$ and $b=\sigma S$ into Eq. (2.3.5) yields:

```
$d\phi = (\frac{\partial \phi}{\partial t} + \mu S\frac{\partial \phi}{\partial S} + \frac{\sigma^2}{2}\frac{\partial^2 \phi}{\partial S^2})dt + \frac{\partial \phi}{\partial S}\sigma dW$ (2.3.6)

```

$\log\left(\frac{S_T}{S_{t0}}\right) \sim N(\nu T, \sigma^2 T) \quad (2.3.9)$
