First let us compute $Y_t^2$.

```

```

```

Next we compute $X_t^2+Y_t^2-Z_t^2$ as follows

```
$X_t^2+Y_t^2-Z_t^2 = \frac{(t_1-t_0)X_t^2+(t-t_0)Z_t^2-2\sqrt{t_1-t_0}\sqrt{t-t_0}X_tZ_t}{t_1-t} \quad (2.8.7)
```

Dividing top and bottom of Eq. (2.8.7) by $t_1-t_0$ we obtain:

```
$X_t^2+Y_t^2-Z_t^2 = \frac{X_t^2+((t-t_0)/(t_1-t_0))Z_t^2-2\sqrt{(t_1-t_0)/(t_1-t_0)}\sqrt{(t-t_0)/(t_1-t_0)}X_tZ_t}{(t_1-t_0)/(t_1-t_0)} \n = \frac{X_t^2+((t-t_0)/(t_1-t_0))Z_t^2-2\sqrt{(t-t_0)/(t_1-t_0)}X_tZ_t}{(t_1-t_0)/(t_1-t_0)}
