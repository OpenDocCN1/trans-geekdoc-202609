# Problem 3

Solve

$dX_t = -X_t dt + \exp(-t) dW_t$$

Rearranging yields

$dX_t + X_t dt = \exp(-t) dW_t$$

Using the integrating factor $\exp(t)$ we obtain

$$\exp(t) dX_t + \exp(t)X_t dt = dW_t$$

and

$$\exp(t)X_t) = \exp(t) dX_t + \exp(t)X_t dt$$

which means that

$$\exp(t)X_t) = dW_t$ and $\$\int_{s=0}^{t} \exp(s)X_s) = \int_{s=0}^{t} dW_s$$

Integrating

$X_t \exp(t) - X_{t_0} = W_t - W_{t_0}$

Since $W_{t_0} = 0$

$X_t \exp(t) - X_{t_0} = W_t$$

that is

$X_t = X_{t_0} \exp(-t) + W_t \exp(-t)$
