## Equity quantity forward

The time (t) value of a domestic equity forward contract with maturity $T$ is:
$F(t)=D^d(t,T)S^d(t,T)-K^d$

Where $K^d$ is the strike in domestic currency and $S^d(t,T)$ is the domestic forward price.

To value an equity forward contract we need to know the forward price of the foreign equity $S^f$.

## 8 C# portfolio pricing application

### 8.1 Introduction

This section provides details concerning a C# application, created using Microsoft Visual Studio 2005 (version 2.0), which values the deals contained in a set of user specified portfolios. It has been included to illustrate how the kind of software that may be found in a bank, financial institution, or educational establishment can be incorporated into the technical skills required in the previous sections of the book can be discussed. Here we provide code excerpts from the application; however, additional source code is available from the publisher's website.

The main features of this application are as follows:

- User defined portfolios of deals can be valued without the need to compile either C or C# programs. portfolios of deals can be valued without the need to compile either C or C# programs. This application is easy to use and accessible to those who possess business or financial knowledge, but do not have the technical skills required to write computer code.
- This application only deals with equity, foreign exchange derivatives—the exception is the inclusion of an interest rate forward rate. However, the software can be easily extended to include new deal types.
- All input/output to the application is by means of text files which can be easily edited.
- The software is modular and consists of a main C# program which calls both DealLibrary and also Analytics_Lib. It should be mentioned that in many cases deal class uses reasonable values. For example, the number of time steps in binomial lattice is set internally and cannot be changed by the user. The random seed for Monte Carlo simulation is set internally and cannot be changed.

We will now provide a brief overview of each component of the application when deal classes are described.

### 8.1.1 The C# code

The application is defined by the C# code.

The application is defined by the C# solution PortfolioValuer.sln, the projects DealLibrary.csproj and PortfolioValuer.csproj.

The project PortfolioValuer.csproj is the driver for the application and contains the C# code given 8.1. The user interface is simply a windows form with a button to start, and this could easily customized by the user. Once the application has been started, it loads market data file and reads a portfolio configuration file to determine which portfolios are be valued.

The project DealLibrary.csproj is concerned with the valuation of available trades. A separate C# class, derived from a single abstract class BaseDeal, is provided for each trade type. The BaseDeal class provides abstract methods such as Price() and Validate(), need to be implemented in deal classes. We will be primarily concerned with the method Price(), which is used to return the current value of a trade. Deal valuation may either be performed completely in C# code or calling appropriate C routines in the Analytics_Lib dynamic library.

### 8.1.2 The text files

The application is driven by a portfolio configuration file and also a number of portfolio definition files, each of which is in plain text and can easily be edited by the user. The portfolio configuration file specifies the names of the portfolio files that are to be valued, and each portfolio definition file provides the details of the trades contained in a given portfolio. In addition there is a market data file (also in text format) which provides the market data required to value the trades.
