## H.2 Proof of Eq. (H.1.2)

From Eq. (H.1.1):

$X_t = \sigma\sqrt{t}, Z_t \sim N(0, 1)$

where $X_0 = 0$. We will derive the probability of events $m_t^X \leqslant b$ and $X_t \geqslant x$ occurring. For each event $m_\tau^X$ to occur there must be a time $\tau$ at which $X_\tau \leqslant b$, where $0 < \tau \leqslant t$. At time $\tau$, instead of continuing with the original Brownian motion, we will consider the *reflected* motion $X_t^R$ defined by:

```
$X_s^R = X_s, \quad s < \tau$
X_s^R = 2b - X_s, \quad s \geqslant \tau$
```

Therefore, before time $\tau$ the motion $X_s$ is identical to the event $X_s^R$. For $s \geqslant \tau$ the *coordinates* of $X_s^R$ are obtained by reflecting the values of $X_s$ about the level $b$. (remember $b \leqslant x$). The event $X_t \geqslant x$ is then equivalent to the event $X_t^R \leqslant 2b-x$ (remember $b \leqslant 0$ and $x \geqslant 0$). However, the event $X_\tau^R \leqslant 2b-x$ only occurs if $m_\tau^X \leqslant b$ also occurs, giving:

```
$P(X_\tau^R \leqslant 2b-x) = P(m_\tau^X \leqslant b, X_\tau \leqslant x)$
```

At time $\tau$

```
$X_\tau^R = 2b - X_\tau \quad(H.2.1)$
```

and after time $\tau$

```
$X_{\tau+\gamma}^R = 2b - X_{\tau+\gamma}, \quad \gamma > 0 \quad(H.2.2)$
```

Thus subtracting Eq. (H.2.1) from Eq. (H.2.2) gives:

```
$X_{\tau+\gamma}^R - X_\tau^R = X_\tau - X_{\tau+\gamma}$
X_{\tau+\gamma}^R - X_\tau^R = -(X_{\tau+\gamma} - X_\tau) \quad(H.2.3)$
```

However, we know that:

```
$(X_{\tau+\gamma} - X_\tau) \sim N(0, \sigma^2\gamma) \quad(H.2.4)$
```

So

```
$(X_{\tau+\gamma}^R - X_\tau^R) \sim -N(0, \sigma^2\gamma)
```

which means that:

```
$X_{t+\gamma}^R - X_t^R \sim N(0, \sigma^2\gamma) \quad (H.2.5)$
```

Since the left-hand sides of Eqs. (H.2.4) and (H.2.5) have the same distribution, and $X_t$ satisfies the three Brownian properties given in Section 2.1, we can write:

```
$P(X_t^R \le 2b-x) = P(X_t \le 2b-x) = N_1\left(\frac{2b-x}{\sigma\sqrt{t}}\right)$
```

Therefore:

```
$P(m_t^X \le b, X_t \ge x) = N_1\left(\frac{2b-x}{\sigma\sqrt{t}}\right)$
```

## H.3 Proof of Eq. (H.1.4)

From Eq. (H.1.3) $\bar{X}_t = vt + \sigma\sqrt{t}Z_t, Z_t \sim N(0, 1)$. So we can write:

```
$P(\bar{X}_t \le K) = P(vt + \sigma\sqrt{t}Z_t \le K)$
= P\left(Z_t \le \frac{K-vt}{\sigma\sqrt{t}}\right)$
= N_1\left(\frac{K-vt}{\sigma\sqrt{t}}\right), Z_t \sim N(0, 1)$
```

## H.4 Proof of Eq. (H.1.5)

We know that $P(\bar{X}_t \ge K) = 1 - P(\bar{X}_t \le K)$. Substituting from Eq. (H.1.4) gives:

```
$P(\bar{X}_t \ge K) = 1 - N_1\left(\frac{K-vt}{\sigma\sqrt{t}}\right)$
```

Since $1 - N_1(x) = N_1(-x)$ we obtain:

```
$P(\bar{X}_t \ge K) = N_1\left(\frac{vt-K}{\sigma\sqrt{t}}\right)$
```

## H.5 Proof of Eq. (H.1.6)

From Eq. (H.1.1):

```
$dX_t = \sigma\sqrt{dt}dZ_t, dZ_t \sim N(0, 1)$
```

This can be expressed as zero drift Brownian motion under probability measure P:

```
$dX_t = \sigma dW_t^P, \quad dW_t^P \sim N(0, dt) \quad (H.5.1)$
```

or

```
$X_t = \sigma W_t^P, \quad W_t^P \sim N(0, t)$
```

Now we can choose another probability measure Q so that:

```
$dW_t^P = dW_t^Q + \frac{\nu}{\sigma}dt \quad (H.5.2)$
```

where $\nu$ is a constant.

Under probability measure Q the motion in Eq. (H.5.1) is:

```
$\widetilde{X}_t = \sigma \left(dW_t^Q + \frac{\nu}{\sigma}dt\right) \quad (H.5.3)$
```

so

```
$\widetilde{X}_t = \nu dt + \sigma dW_t^Q \quad (H.5.4)$
```

It be seen from Section 2.4 that the transformation between measures P and Q can be achieved using $k = \nu/\sigma$, and the associated Radon–Nikodym derivative is: 

```
$\frac{dQ}{dP} = \exp\left(kW_t^P - \frac{1}{2}k^2\right)$
$= \exp\left(\frac{\nu}{\sigma}W_t^P - \frac{\nu^2}{2}\right)$
$= \exp\left(\frac{\nu}{\sigma}X_t - \frac{\nu^2}{2t}\right) \quad (H.5.5)$
```

where we have the fact that under probability measure P we can write:

```
$\widetilde{W}_t^P = X_t/\sigma$.
```

Now

```
$P(\widetilde{X}_t^P \le b, \widetilde{X}_t^P \ge x) = E^Q[\mathbb{I}_{\widetilde{X}_t^Q \le b}(\widetilde{X}_t^Q \ge x)] \quad (H.5.6)$
```

where $\mathbb{I}_{\{\widetilde{X}_t^P \le b\}}$ is an indicator function which takes unit value when the condition is satisfied and zero otherwise—for example $\mathbb{I}_{\{\widetilde{X}_t^P \le b\}}$ is one when $\widetilde{X}_t^P \le b$ and zero when $\widetilde{X}_t^P > b$. However, for Baxter and Rennie (1996), we have:

```
$E^Q[\mathbb{I}_{\widetilde{X}_t^P \le b}(\widetilde{X}_t^P \ge x)] = E^P[\mathbb{I}_{\widetilde{X}_t^Q \le b}]\frac{dQ}{dP} \quad (H.5.7)$
```

So substituting for $\frac{dQ}{dP}$ from Eq. (H.5.5) gives:

```
$E^Q[\mathbb{I}_{\widetilde{X}_t^P \le b}(\widetilde{X}_t^P \ge x)] = E^P[\mathbb{I}_{\widetilde{X}_t^Q \le b}\exp\left(\frac{\nu X_t}{\sigma} - \frac{\nu^2 t}{2}\right)] \quad (H.5.8)$
```

# Appendix H: reflected Brownian motion

Expressed in terms of reflected Brownian motion, $X_t^R = 2b - X_t$, Eq. (H.5.8) can be written:

```
$P(m_t^X \le b, \bar{X}_t \ge x) = E^P[\mathbb{I}_{X_t^R \le b}(X_t^R \ge x)] \exp\left(\frac{\nu(X_t^R)}{\sigma} - \frac{\nu^2 t}{2}\right) \quad (H.5.9)$
```

Since $\mathbb{I}_{X_t^R \le b} = \mathbb{I}_{2b-X_t \le b} = \mathbb{I}_{X_t \ge b}$ (not true) and $\mathbb{I}_{X_t^R \ge x} = \mathbb{I}_{2b-X_t \ge x} = \mathbb{I}_{X_t \le 2b-x}$, Equation (H.5.9) becomes:

```
P(m_t^X \le b, \bar{X}_t \ge x) = \exp\left(\frac{2\nu b}{\sigma^2}\right) E^P[\mathbb{I}_{X_t < 2b-x} \exp\left(\frac{\nu X_t}{\sigma} - \frac{\nu^2 t}{2}\right)] \quad (H.5.10)
```

where, for notation, we now denote $X_t^R$ by $X_t$ on the right-hand side of Eq. (H.5.10). Therefore:

```
$P(m_t^X \le b, \bar{X}_t \ge x) = \exp\left(\frac{2\nu b}{\sigma^2}\right) \int_{-\infty}^{2b-x} \frac{1}{\sqrt{2\pi t}} \exp\left(\frac{(X_t + \nu t)^2}{\sigma^2}\right) dX_t
```

If $V = (X_t + \nu t)/\sqrt{t}$, then $dX_t = \sqrt{t} dV$, $X_t = 2b-x$ corresponds to $V = (2b-x+vt)/\sqrt{t}$, and $V = -\infty$ corresponds to $V = -\infty$.

```
$= N_1\left(\frac{2b-x+vt}{\sqrt{t}}\right)$
```

We thus obtain:

```
$P(m_t^X \le b, \bar{X}_t \ge x) = \exp\left(\frac{2\nu b}{\sigma^2}\right) N_1\left(\frac{2b-x+vt}{\sqrt{t}}\right)$
```

## H.6 Proof of Eq. (H.1.7)

Since $P(\bar{X}_t \ge x) = P(m_t^X \ge b, \bar{X}_t \ge x) + P(m_t^X \ge b, \bar{X}_t \le x)$ we have:

```
$P(m_t^X \ge b, \bar{X}_t \ge x) = P(\bar{X}_t \ge x) - P(m_t^X \ge b, \bar{X}_t \le x) \quad (H.6.1)$
```

Substituting the results of Eqs. (H.1.4) and (H.1.6) into Eq. (H.6.1) yields:

```
$P(m_t^X \ge b, \bar{X}_t \ge x) = N_1\left(\frac{vt - x}{\sigma \sqrt{t}}\right) - \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{2b - x + vt}{\sigma \sqrt{t}}\right)$
```

## H.7 Proof of Eq. (H.1.8)

We start by writing:

```
$P(m_t^X \le b) = P(\bar{X}_t \le b, \bar{X}_t \le b) + P(m_t^X \le b, \bar{X}_t \ge b)$
```

However, $P(m_t^X \le b, \bar{X}_t \le b) = P(\bar{X}_t \le b)$ since the probability that the minimum is less than $b$ and the final value $\bar{X}_t$ is less than $b$ is the same as the probability that the final value $\bar{X}_t$ is less than $b$. Therefore:

```
$P(m_t^X \le b) = P(\bar{X}_t \le b) + P(m_t^X \le b, \bar{X}_t \ge b)$
```

Substituting for $P(\bar{X}_t \le b)$ from Eq. (H.1.4) gives:

```
$P(m_t^X \le b) = N_1\left(\frac{b - vt}{\sigma \sqrt{t}}\right) + P(m_t^X \le b, \bar{X}_t \ge b) \quad (H.7.1)$
```

From Eq. (H.1.6):

```
$P(m_t^X \le b, \bar{X}_t \ge b) = \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{2b - b + vt}{\sigma \sqrt{t}}\right)$
```

```
$= \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{b + vt}{\sigma \sqrt{t}}\right) \quad (H.7.2)$
```

Combining Eqs. (H.7.2) and (H.7.1) yields:

```
$P(m_t^X \le b) = N_1\left(\frac{b - vt}{\sigma \sqrt{t}}\right) + \exp\left(\frac{2vb}{\sigma^2}\right)N_1\left(\frac{b + vt}{\sigma \sqrt{t}}\right)$
```
