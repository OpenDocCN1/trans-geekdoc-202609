# 5.4.6 The double knockout call option

The purpose of this section is to provide an example that illustrates the benefits to be gained from both the log transformed Black–Scholes equation and a nonuniform grid.

The problem we consider is the European double knockout call option with strike price $E$, and expire date $T$. This is a barrier option with both an upper barrier at $B_U$, and a lower barrier at $B_L$. During the life of the option, the asset price either goes above the upper barrier or below the lower barrier, then the option becomes worthless. If, on the other hand, the asset price stays between the barriers then the option has max($S_T - E$), where $S_T$ is the asset price at time $T$.

This problem has been previously investigated by Boyle and Tian (1998), heretofore referred to as BT, using an explicit finite-difference method based on a modified binomial lattice. The method we use here is based on the finite-difference equations given in Section 5.4.5, and all the results obtained by using the function dko_call (see Code excerpt 5.20) are presented in Tables 5.8–5.12.
