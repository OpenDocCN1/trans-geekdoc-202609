# PORTFOLIO B: One European put, $p(S, E, 	au)$, and one share of value $S \exp(-q	au)$.

At option expiry the value of the call and put are $c(S, E, 0)$ and $p(S_T, E, 0)$, respectively. Also, if the value of the share at time $t$ is denoted by $S$, the combined value of shares and dividends at time $T$ is $S \exp(qT)$: Note that $q$ is treated in a similar manner to the continuously compounded riskless interest rate $r$.

+   If $S_T \ge E$

Portfolio A is worth:
$\max(S_T - E, 0) + \exp(r	au)E \exp(-r	au) = S_T - E + E = S_T$
Portfolio B is worth:
$\max(E - S_T, 0) + \exp(-q	au)\exp(q	au) = 0 + S_T = S_T$
where $S \exp(-q	au) \exp(q	au)$ is the combined value of the shares and dividends at maturity.

+   If $S_T < E$

Portfolio A is worth:
$\max(S_T - E, 0) + \exp(r	au)E \exp(-r	au) = 0 + E = E
Portfolio B is worth:
$\max(E - S_T, 0) + S \exp(-q	au)\exp(q	au) = E - S_T + S_T = E$

We have therefore shown that under all conditions the value of portfolio A is the same as that of portfolio B.
