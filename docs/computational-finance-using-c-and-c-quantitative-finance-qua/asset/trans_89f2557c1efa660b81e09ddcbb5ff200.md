- 股票衍生品
- 利率衍生品
- 外汇衍生品
- 信用衍生品

还有一个详尽的章节，演示了如何将基于 C 的分析定价库用于 C# 投资组合估值软件。除了该应用程序外：

- 说明了 C# 字典、抽象类和 .NET InteropServices的使用
- 允许读者对自定义投资组合进行估值
- 允许通过配置文件指定市场数据
- 包含一个通用篮，读者可以指定支付函数
- 读者可以免费下载

本书还增加了对随机过程、Ito 积分和蒙特卡洛模拟的覆盖。这些主题有实际应用和解决例题的支持。
