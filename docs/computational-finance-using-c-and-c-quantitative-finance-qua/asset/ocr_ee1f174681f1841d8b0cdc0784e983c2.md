# 2.5 Ito's lemma for multasset geometric Brownian motion

We will now consider the $n$-dimensional stochastic process:

```
$dX_i = a_i dt + b_i \sqrt{dt} dZ_i = a_i dt + b_i dW_i, \quad i = 1, \dots, n, \quad (2.5.1)$
```

or in vector form:

```
$dX = A dt + \sqrt{dt} B dZ = Ad + B dW \quad (2.5.2)$
```

where $A$ and $B$ are $n$-element vectors respectively containing the constants, $a_i, i = 1, \dots, n,$ and $b_i = 1, \dots, n$. The stochastic vector $dX$ contains the $n$ stochastic variables $X_i, i = 1, \dots, n$.

We will assume that the $n$ element random vector $dZ$ is drawn from a multivariate normal distribution with zero mean and covariance matrix $	ilde{C}$. That is, we can write:

```
$dZ \sim N(0, \tilde{C})$
```

Since $	ilde{C}_{ii} = Var[dW_i] = 1, i = 1, \dots, n$, the diagonal elements of $	ilde{C}$ are all unity and the matrix $C$ is in fact a *correlation matrix* with off-diagonal elements given by:

```
$\tilde{C}_{ij} = E[dW_i dW_j] = \rho_{ij}, \quad i = 1, \dots, n, j = 1, \dots, n, i \neq j,$
```

where $ho_{ij}$ is the correlation coefficient between the $i$th and $j$th elements of the vector $dZ$. Similarly the $n$-element random vector $dW$ is drawn from a multivariate distribution with zero mean and covariance matrix $C$. We can write:

```
$dW \sim N(0, C)$
```

The diagonal elements of $C$ are $C_{ii} = Var[dW_i] = dt, i = 1, \dots, n$, and off-diagonal elements are

```
$C_{ij} = E[dW_i dW_j] = \rho_{ij} dt, \quad i = 1, \dots, n, j = 1, \dots, n, i \neq j$
```
