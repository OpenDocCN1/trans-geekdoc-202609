The value $c_{do}$ of a European down and out call option with strike $E$, satisfying $E > B$, is given by:

```
$c_{do} = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} {\exp(X) - E\f(X > B) dX \quad (4.5.9)
```

This integral is evaluated in Appendix B.1, and the value of the down and out call option $c_{do}$:

```
$c_{do} = c - c_{di} \quad (4.5.10)
```

where

```
$c = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2)
```

```
$c_{di} = S\exp(-q\tau)N_1(d_1) (\frac{B}{S})^{\frac{2(r-q)}{\sigma^2}} - E\exp(-r\tau)N_1(d_3) (\frac{B}{S})^{\frac{2(r-q)-1}{\sigma^2}}$
```

```
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

```
$d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

```
$d_3 = \frac{\log(B^2/SE) + (r - q - \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

and

```
$d_4 = \frac{\log(B/ES) + (r - q + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

In Code excerpt 4.7 we provide the function bs_opt_barrier_downout_call which uses Eq. (4.5.10) to price a down and out European call option. This routine will be used in Chapter 5 to measure the accuracy achieved using various finite-difference grid techniques to solve the Black-Scholes equation.

# 4.5.3 Analytic pricing of up and out call options

Here we will obtain an expression for an up and out European call option with continuous dividend yield $q$, in a manner similar to that used in Section 4.5.2 for the down and out European call option. A European up and out barrier option with maturity $\tau$ and a barrier $X=B$ will cease to exist (become worthless) if at any time $X_t \geq B$, for $t \leq T$. The probability density function that the barrier option will continue to exist at time $T$ if the end point is $X$ is:

```
$f(X < B) = \sqrt{\frac{2}{\pi}} \int_{b=B}^{\infty} \Omega \exp(\frac{2(X-b)}{\sigma^2\tau}) \times \exp([X - (r - q - \sigma^2/2)\tau]^2) db \quad (4.5.11)
```
