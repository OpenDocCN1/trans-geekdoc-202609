# 5.3.3 Binomial lattice with a control variate

The control variate technique is used to enhance the accuracy that a standard binomial lattice gives for the value of an American vanilla option. It involves using the same standard binomial lattice to value both an American option and the equivalent European option. The Black–Scholes formula is if we assume that the error in pricing the European option is the same as for the American option, we can achieve an improved estimate for the value of the American option.

When applied to the valuation of an American put option this can be expressed as follows:

> European pricing error, $\Delta_E = p^{BS}(S, E, \tau) - p^L(S, E, \tau)$
American pricing error, $\Delta_A = P^*(S, E, \tau) - P^L(S, E, \tau)$

where $S$ is the current value of the asset, $E$ is the strike price, and $\tau$ is the maturity of the option. $p^{BS}(S, E, \tau)$ is the Black-Scholes Values of the European put option, $p^L(S, E, \tau)$ is the binomial lattice estimate of the European put option, $P^*(S, E, \tau)$ is the (unknown) accurate value of the American put option, and $P^L(S, E, \tau)$ is the binomial lattice estimate of the American put option.

Let $\Delta_A = \Delta_E$ then we have:

> $p^{BS}(S, E, \tau) - p^L(S, E, \tau) = P^*(S, E, \tau) - P^L(S, E, \tau)$

which on rearrangement yields:

> $P^*(S, E, \tau) = p^{BS}(S, E, \tau) - p^L(S, E, \tau) + P^L(S, E, \tau)$

We use $P^*(S, E, \tau)$ as the improved, control variate estimate for the value of the American put option. Of course, exactly the same approach can be used to obtain an improved estimate for the value of an American call.
