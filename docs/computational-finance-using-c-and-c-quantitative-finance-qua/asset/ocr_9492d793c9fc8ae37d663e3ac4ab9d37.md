which means that $\widetilde{X} \sim N(0, \sigma_B^2 \, dt + \sigma_A^2 \, dt - 2\sigma_B\sigma_Aho_{AB} \, dt)$ and the variate $(\sigma_B^2 - 2\sigma_B\sigma_Aho_{AB})dW^P$ is from the same distribution as $\widetilde{X}$.
We can write:

```
$$d\left(\frac{S_B^B}{S_A^B}\right) = \left(\frac{S_B^B}{S_A^B}\right)\hat{\mu} \, dt + \left(\frac{S_B^B}{S_A^B}\right)\sigma \, dW^P$$quad (6.5.2)$
```

where

```
$$\widetilde{\sigma} = \sqrt{\sigma_B^2 + \sigma_A^2 - 2\sigma_B\sigma_A}$
```

and

```
$$\hat{\mu} = \mu_B - \mu_A + \sigma_A^2 - \sigma_B\sigma_A\rho_{AB}$
```

Following Section 4.4.3 chooses the probability measure $\mathbb{Q}$ so that the drift term in Eq. (6.5.2) is zero. We have

```
$dW^P = dW^Q - \left(\frac{\mu}{\sigma}\right)dt$$
```

Substituting this into Eq. (6.5.2) gives

```
$$d\left(\frac{S_B^B}{S_A^B}\right) = \left(\frac{S_B^B}{S_A^B}\right)\sigma \, dW^Q$$quad (6.5.3)$
```

It can be seen that Eq. (6.5.3) is identical to Eq. (4.4.31) but with the mapping:

```
$$S_t \to \frac{S_B^B}{S_A^B}, \quad \sigma \to \widetilde{\sigma}, \quad r \to 0$$quad (6.5.4)$
```

Now combining Eqs. (4.4.3) and (4.4.37) we have

```
$$\exp(-r\tau)E^Q[max(S_t - E, 0)] = SN_1(d_1) - E\exp(-r\tau)N_1(d_2)$
```

where $d_1$ and $d_2$ have been defined in Section 4.4.3.

Therefore,

```
$$\E^Q[max(S_t - E)] = \exp(r\tau)SN_1(d_1) - N_1(d_2)$
```

Using the mapping defined in Eq. (6.5.4), and also $E = 1$ in the Black-Scholes formula, we have:

```
$$\E^Q\left[\left(\frac{S_B^B}{S_A^B}\right) - 1\right]\right] = \left(\frac{S_B^0}{S_A^0}\right)N_1(d_1) - N_1(d_2)$$
```

and from Eq. (6.5.1):

```
$$\V(t_0) = S_A^0\frac{S_B^0}{S_A^0}N_1(d_1) - N_1(d_2)\}$\}$
```

This means that the value of the exchange option at time $t_0$ is:

```
$$\V(t_0) = S_B^0N_1(d_1) - S_A^0N_1(d_2)$
```
