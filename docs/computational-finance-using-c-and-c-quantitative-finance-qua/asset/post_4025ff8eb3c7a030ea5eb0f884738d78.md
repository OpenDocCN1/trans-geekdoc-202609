The current asset value S is assigned to the central element S[M], where M is the number of time steps in the lattice. The lattice elements above center are S[M+i] = Su^i, i = 1, \dots, M, and the lattice elements below center are S[M-i] = Sd^i, i = 1, \dots, M.

$ET \cap OT = \emptyset$, the elements of $ET$ and $OT$ for any consecutive pair of time steps are related by the constant multiplicative factor $d$. Also, for even time step there is a central node corresponding to the current asset price $S_0$, and the remaining nodes are symmetrically arranged about this, see Code except 5.6. These features are illustrated in Fig. 5.1, for a standard lattice with six time steps.

The number of distinct asset prices in a lattice is the sum of the number of nodes in the last two time steps. Since the number of nodes in the $i$th time step, $S_i$, is $i+1$ (see Fig. 5.1), for an $n$ time step lattice we have:

$S_n = n+1$ and $S_{n-1} = n$

This means the number of different asset values in an $n$ time step lattice is:

$LS_n = S_n + S_{n-1} = 2n+1$

The number of nodes in an $n$ time step lattice, $\LN_n$, is:

$$\LN_n = \sum_{i=0}^{n} (i+1) = \frac{(n+1)(n+2)}{2}$$

where we used the fact that $\LN_n$ is the sum of an arithmetic progression with first term 1, increment by $n+1$, it is necessary to store the value of each lattice node which would contain $\LN_n$ values.

One might initially think that, in order to price options, storing the value of each lattice node would contain $\LN_n$ values. However, this is not the case. We only need to store the number of different asset values in the lattice; that is, $LS_n$.

Storing $LS_n$ instead of $\LN_n$ can result in dramatic economies of storage. For example, an accurate, 1000 step lattice, $\LN_n = 2001 \times 2002 \times 1/2 = 2003001$, while the corresponding value of $LS_n$ is only $2 \times 1000 + 1 = 2001$.

# Compute the option payoff at the terminal nodes

The current value of an option is evaluated by starting at option maturity, the end of the tree, and working backwards. The option values for the terminal nodes of the tree are just given by the payoff (at maturity) of the option; this independent of whether the option is an American or European. For a lattice with n time steps there are n + 1 terminal nodes, with option values, $f_{n,j,j} = 0, \dots, n$.

To compute the values of vanilla American and European options, with exercise price E, we will start with the following terminal node values:

for put options:

$f_{n,j} = \max(E - Su^j d^{n-j}, 0), \quad j = 0, \dots, n,$

and for calls:

$f_{n,j} = \max(Su^j d^{n-j} - E, 0), \quad j = 0, \dots, n,$
