So

$E[x^2] = \mu^2 + \sigma^2$

where we used (see Section E.1 result (ii) with $a=1/(\sigma^2)$) that

$\frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y^2 exp\left(-\frac{y^2}{2\sigma^2}\right) dy = \sigma^2$

Therefore:

$Var[x] = E[x^2] - (E[x])^2 = \mu^2 + \sigma^2 - \mu^2 = \sigma^2$

The mean and variance can also be obtained by the moment generating function, $M_x(t)$.

From Section C.5:

$E[x] = \frac{dM_x(t)}{dt}|_{t=0} = \frac{d}{dt} exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)|_{t=0} \n (\mu + \sigma^2 t) exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)|_{t=0} = \mu$

$E[x] = \mu$ and $E[x^2] = \mu^2 + \sigma^2$
