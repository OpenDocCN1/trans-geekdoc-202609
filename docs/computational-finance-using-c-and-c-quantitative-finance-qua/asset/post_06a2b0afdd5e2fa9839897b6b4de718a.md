# Code except 8.8. (Continued.)

Declarations are given in Code excerpt 8.9. It can be seen that C function parameters by value and declared as double val long int correspond to C# double val and int parameters, C functions that are passed by reference are a little more tricky to deal with in C#. This is because C# does not explicitly specify pointers. A double parameter passed by reference using double * can be used in C# by using ref double. Similarly, the C function length* is declared in C# as ref int. It should be noted for clarity we use the syntax double[] and long[] for arrays of double and long, respectively; it is also correct to declare these as double a and long* a*.

However, there is still a problem because C functions can be coded to check whether or not a null pointer has been supplied as a parameter, and then take appropriate action. For instance, the function black_scholes in Code excerpt 4.1, will not compute the Greeks if the parameter Greeks[] is null. The code fragment below shows how IntPtr, which is a recent addition to C#, can be used to resolve this:

```csharp

public static extern void ref(ref double value, double greeks,
double s0, double x, double sigma, double t, double r, double q, int put, ref int flag);
```

```csharp
double x, double sigma, double t, double r, int put, ref int flag);
```

The first declaration specifies that the function called black_schools in Analytics_MathLib.dll will have the name black_schools2 in C#. In addition the C parameter double greeks[] is mapped to double greeks in C#. This means that we will need to declare an array variable (say the _greeks will hold the Greeks and pass it to black_schools2 using the syntax ref _greeks[0]). In this case the Greeks will always be computed, even if we don't want to use them.

The second declaration specifies that the function black_schools2 in C# will also call the routine black_schools in Analytics_MathLib.dll. However, in this case the C parameter double greeks[] is mapped to IntPtr greeks in C#. This allows us to set the double greeks[] to null by passing the IntPtr.Zero—for example class EquityOptionDeal in Code excerpt 8.10.
