# D.4.3 The distribution for shape parameter, a

If the distribution has variance $h_i$, then from Section D.4.1:

$\lambda = \frac{2^{-2/a}\Gamma(1/a)h_i}{\Gamma(3/a)^{1/2}}$

Now for $0 < x < 1$ we have $\Gamma(1+x) = 1 + a_1x + a_2x^2 + a_3x^3 + \dots$, where the coefficients are $|a_i| < 1$ (see Abramowitz and Stegun (1968)). Since $x\Gamma(x) = \Gamma(1+x)$, to third order in $x$, we have:

$x\Gamma(x) = 1 + a_1x + a_2x^2 + a_3x^3$

This gives $\Gamma(x) = \frac{1}{x} + a_1 + a_2x + a_3x^2$, and $\Gamma(x) \approx \frac{1}{x}$ as $x \to 0$. As $a \to \infty$ we have the following:

$2^{(1+1)/a} \approx 2, \quad 2^{-2/a} \approx 1, \quad \frac{1}{\Gamma(1/a)} \approx \frac{a}{2}$

$\Gamma(1/a) \approx \frac{a}{3} \quad \text{and} \quad \Gamma(5/a) \approx \frac{3a}{3}$ \n$\\Gamma(3/a) \approx \frac{5a}{5}$

The kurtosis is:
$\\kappa = \frac{\Gamma(5/a)\Gamma(1/a)}{\Gamma(3/a)\Gamma(3/a)} \approx \frac{9}{a^2}$

Also as $a \to \infty, \lambda \approx (3h_i)^{1/2} < \epsilon_i < (3h_i)^{1/2}$, we have:

$\frac{\epsilon_i}{\lambda} \approx \frac{\epsilon_i}{(3h_i)^{1/2}} \approx 0 \quad \text{and therefore} \quad \exp\left(-\frac{1}{2}|\left\frac{\epsilon_i}{\lambda}\right|^a\right) \approx 1$

Substituting the above results into Eq. (D.4.1), the probability density function reduces to:

$f(\epsilon_i) \approx \frac{1}{2(3h_i)^{1/2}}$

which is a uniform distribution $U(-(3h_i)^{1/2}, (3h_i)^{1/2})$, with lower limit $-(3h_i)^{1/2}$ and upper limit $-(3h_i)^{1/2}$.
