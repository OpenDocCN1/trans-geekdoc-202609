# 3.3.1 Normal distribution

The fundamental distribution is the univariate standard normal distribution, N(0, 1), with zero mean and unit variance. The case of p independent variables takes this form of a p variate independent normal distribution N(0, I_p) with zero mean and $p \times p$ unit covariance matrix $I_p$.

We will quote a result concerning multivariate probability density functions; see Press, Teukolsky, Vetterling, and Flannery (1992). If $x_1, x_2, \dots$ are random variables with a joint probability density function $p(x_1, x_2, \dots)$, and if there are an equal number of y variates $y_1, y_2, \dots$ that are functions of the x's, then the joint probability density function of the y variates, $p(y_1, y_2, \dots)$, is given by the following expression:

```
$p(y_1, y_2, \dots) dy_1 dy_2, \dots = p(x_1, x_2, \dots) J_{x,y} dy_1 dy_2, \dots \quad (3.3.1)
```

where $J_{x,y}$ is the Jacobian determinant of the x's with respect to the y's. An important application of this result is that a p variate independent normal distribution N(0, I_p) is generated from a p variate uniform distribution U(0, 1); see Box and Muller (1958).

We will now describe how the method works. Consider two independently distributed N(0, 1) variables $x$ and $y$, and use the polar transformation to obtain:

```
$x = r \cos \theta, \quad y = r \sin \theta, \quad \text{and} \quad r^2 = x^2 + y^2 \quad (3.3.2)
```

From Eq. (3.3.1) the joint probability density functions $f(r, \theta)$ and $f(x, y)$ obey the equation

```
$f(r, \theta) dr d\theta = f(x, y) J_{x,y} dr d\theta$
```

where the Jacobian is

```
$J_{xy,r\theta} = \begin{pmatrix} \cos \theta & -r \sin \theta \ \sin \theta & r \cos \theta \end{pmatrix} = r$
```

We therefore have

```
$f(r, \theta) = rf(x, y) \quad (3.3.3)
```

Furthermore $x$ and $y$ are independent N(0, 1)

```
$f(x, y) = f(x)f(y)
```

where

```
$f(x) = \frac{e^{-x^2/2}}{\sqrt{\pi}} \quad \text{and} \quad f(y) = \frac{e^{-y^2/2}}{\sqrt{\pi}}$
```

Therefore:

```
$f(r, \theta) = rf(x)f(y) = r \frac{e^{-x^2/2}}{\sqrt{\pi}} \frac{e^{-y^2/2}}{\sqrt{\pi}}$
```
