where $dY$ is the change in the value of $\log(S)$ over the time interval $dr$. Later on we derived the (Black-Scholes) partial differential equation that is satisfied by the value, $V$, of an option written on a single asset. The equation is

```
$$\frac{\partial V}{\partial t\|+\frac{\sigma^{2}}{2}\frac{\partial^{2} V}{\partial S^{2}}+rS\frac{\partial V}{\partial S}-rv=0$
```

The above result can be generalized to deal with multiset options. Suppose that $m$ assets are described by the following processes:

```
$dY_{i}=(r-\\frac{\sigma_{i}^{2}}{2})dt+\sigma_{i}dW_{i},\quad i=1,...,m,\quad(6.2.1)
```

where the subscript $i$ refers to value associated with the $i$th asset. The $m$-element random vector $dW$ is distributed according $dW \sim N(0,C)$. The diagonal elements of $C$ are $C_{ii}=\text{Var}[dW_{i}]=dt, i=1,...,m$, and off-diagonal elements are:

```
$C_{ij}=E[dW_{i}dW_{j}]=\rho_{ij}dt,\quad i=1,...,m,j=1,...,m,i\neq j$
```

We also write the above equation in vector form by introducing the $m$-element vector $dY$ which is normally distributed:

```
$dY\simN(\ar{\mu},\bar{C}),\quad(6.2.2)
```

where $\bar{\mu}$ is the mean vector and $\bar{C}$ is the covariance matrix. The elements of the covariance matrix are:

```
$$\bar{C}_{ii}=\sigma_{i}^{2}dt,\quad i=1,...,m$\n$\bar{C}_{ij}=\sigma_{i}\sigma_{j}\rho_{ij}dt,\quad i\neq j,i=1,...,m,j=1,...,m,\quad(6.2.3)
```

where $\rho_{ij}$ is the correlation coefficient between asset $i$ and asset $j$; that is, the correlation between $dW_{i}$ and $dW_{j}$. The elements of the mean vector are:

```
$v_{i}=r-\\frac{\sigma_{i}^{2}}{2},\quad i=1,...,m,\quad(6.2.4)
```

The value $V$ of an option on $m$ assets satisfies the following differential equation:

```
$$\frac{\partial V}{\partial t\|+\sum_{i=1}^{m}\sum_{j=1}^{m}\sigma_{i}\sigma_{j}\rho_{ij}S_{i}S_{j}\frac{\partial^{2} V}{\partial S_{i}\partial S_{j}}+rS\sum_{i=1}^{m}\frac{\partial V}{\partial S_{i}}-rv=0$
```

For a European call on the maximum of $m$ assets (time $	au$) is given by $P_{c}^{MAX}=\max(S_{c}^{1},S_{c}^{2},...,S_{c}^{m})-E$, where $S_{c}^{i},i=1,...,m$, denotes the value of the $i$th asset at maturity, and $E$ represents the strike price. Similarly a European put option on the minimum of $m$ assets has a pay-off, $P_{p}^{MIN}$, at time $	au$, given by $P_{p}^{MIN}=max-\min(S_{c}^{1},S_{c}^{2},...,S_{c}^{m}),0$.
