distribution $\Lambda(\mu, \sigma^2)$ then $\log(x)$ is a normal distribution with mean $\mu$ and variance $\sigma^2$. Conversely if $y \sim N(\mu, \sigma^2)$ then the distribution for $x = e^y$ is $x \sim \Lambda(\mu, \sigma^2)$.

```
$E[x'] = \frac{\sigma}{\sqrt{2\pi}}\int_{x'=-\infty}^{\infty} x' \exp\left(-\frac{(\log(x')-\mu)^2}{2\sigma^2}\right)dx$
```

Using $y = \log(x)$ do we have:

```
$\frac{dy}{dx} = \frac{1}{x}, \quad dx = x\ dy, \quad \text{and}\quad x' = (e^y)' = e^y$
```

Thus,

```
$E[x'] = E[e^y] = M_y(t) = \frac{1}{\sqrt{2\pi}}\int_{y=-\infty}^{\infty} e^{ty} \exp\left(-\frac{(y-\mu)^2}{2\sigma^2}\right)dy$
```

where $M_y(t)$ is the moment generating function of a normal distribution with mean $\mu$ and variance $\sigma^2$.

From Section D.1:

```
$E[x'] = M_y(t) = \exp\left(\\mu t + \frac{\sigma^2 t^2}{2}\right)$
```

Therefore $x \sim \Lambda(\mu, \sigma^2)$ then:

for $t = 1$

```
$E[x] = \exp\left(\mu + \frac{\sigma^2}{2}\right) \quad (D.2.2)
```

for $t = 2$

```
$E[x^2] = \exp(2\mu + 2\sigma^2) \quad (D.2.3)
```

and the variance is obtained using

```
$Var[x] = E[x^2] - (E[x])^2 = \exp(2\mu + 2\sigma^2) - \exp(2\mu + \sigma^2)$
```

So

```
$Var[x] = \exp(2\mu + \sigma^2)(\exp(\sigma^2) - 1)$
```

or

```
$Var[x] = (E[x])^2(\exp(\sigma^2) - 1) \quad (D.2.4)
```

Note. If $x_1 = \exp(\mu + \sigma Z)$, where $Z \sim N(0,1)$ then $x_1 \sim \Lambda(\mu, \sigma^2)$. So $E[x_1]$ and $Var[x_1]$ are given by Eqs. (D.2.2) and (D.2.4).
