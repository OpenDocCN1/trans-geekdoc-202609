
key to the accuracy achieved by dko_call is a combination of:

- The logarithmic transformation of the Black–Scholes equation
- The ability to place a grid line at the upper boundary $B_U$, and also at the lower boundary $B_L$
- The use of a weighted $\Theta_m$ finite-difference scheme, $0 \le \Theta_m \le 1$, instead of the numerically unstable explicit finite-difference method used by a binomial lattice in our notation (see Section 5.4.2) is equivalent to $\Theta_m = 1$.

It should be mentioned that the function dko_call could, without much difficulty, be modified to deal with:

- American double knockout call options
- European double knockout put options
- American double knockout put options

and also a range of other variations which may include lockout periods, rebates, etc. In particular, options with time-varying barrier levels can be dealt with using grid lines to locate the barrier position at each time instant.

## 5.5 Pricing American options using a stochastic lattice

In this section we consider the use of Monte Carlo simulation and stochastic lattices to price American options. Information on the use of Monte Carlo simulation to value both asset and multiset European options is provided in Chapter 4 and Chapter 6. The main difficulty in using simulation to value American options is the need to incorporate early exercise policies. The standard simulation algorithms for valuing European contracts are forward in time. That is each price path, which contributes to the value of the option, is generated by stepping from current time, $t$, to option maturity, $t+\tau$, where $\tau$ is the duration of the option. For instance if there is $n$ required time steps of size $\Delta t$, and only one underlying asset, then we use the asset values $S_i,t_i=0,\dots,n$, where $S_i$ corresponds to the asset value at the $i$th time instant, $t_i=t_0$. $S_{i+1}$ is generated from the previous asset value $S_i$ as follows:

$$\frac{S_{i+1}}{S_i} = dS_i \quad \text{for } i=0,\dots,n-1$$

where $dS_i$ is a random variate from a given distribution. When $S_i$ follows GBM, we have from Eq. (2.3.11):

$$\frac{S_{i+1}}{S_i} = \exp\left(r - \frac{\sigma^2}{2}\right)\Delta t + \sigma_i dW_i, \quad i=0,\dots,n-1$$

where $dW_i \sim N(0,\Delta t)$ and the usual defaults are used for $\sigma$ and $r$. For European exotic options (such as time dependent barrier options) the value of a particular price path will depend on the asset values $S_i,i=0,\dots,n$.

### Single asset American options

This is not true of European vanilla options whose value depends on $S_t$, the underlying asset price at option maturity. The Monte Carlo approximation to the value of a European option is thus:

$$f = \sum_{j=1}^{n_{sim}} p_j(n_j)$$

$n_{sim}$ is the number of simulations, $n_j$ is the number of time steps associated with the $j$th price path, and $p_j(n_j)$ is the value of the $j$th price path. In the case of European vanilla options we can use $n_j = 1, 1, \dots, n_{sim}$: the accuracy obviously improves with increasing $n_{sim}$.

The valuation of American-style options, which include the possibility of early exercise, is more complicated. In Chapter 5 we described the use of binomial lattice to price options when the underlying asset process is GBM. Dynamic programming was used and the option prices were computed by backward in time through the lattice. The application of Monte Carlo for American options was described in Tilley (1993), Barraguand and Martineau (1995), and also Boyle, Broadie, and Glasserman (1997). Here we will outline the stochastic lattice approach discussed in Broadie and Glasserman (1997), where both a high estimator and a low estimator of the American option value are calculated. Since both of these biased estimators converge (with increasing number of simulations and lattice nodes) to the true option value, we will only consider how to compute the high estimator, $\theta_H$. We summarize the approach as follows:

- Set the parameters
- Generate the lattice asset prices
- Compute the lattice option prices
- Compute the Monte Carlo estimate.

We will now consider each of these steps in detail.

### Set the parameters

First we set the simulation parameters; $n_{sim}$ is the number of lattice simulations, $b$ is the number of branches per lattice node, and $d$ is the number of time instants in the lattice. Note: this definition of $d$ is different from that used in the original paper by Broadie and Glasserman (1997) where $d$ is defined as the number of time steps in the lattice.

### Generate the lattice asset prices

Next we generate the asset prices for the $i$th stochastic lattice. The lattice is non recombining at the $b'$ nodes/asset prices. This contrasts with the binomial lattice of Chapter 5 where the asset prices at a given time step are arranged in ascending order, that is $S_j'$ increases with increasing $j$.

We denote the $j$th value at the $i$th time step by $S_i^j$. For example, in Fig. 5.9, where $b=3$ and $d=3$, we have for the first time step:

$S_1^1 = 115, \quad S_2^1 = 60, \quad \text{ and } S_3^1 = 114$

$S_1^2 = 116, \quad S_2^2 = 90, \quad S_3^2 = 149, \quad \dots \quad S_7^2 = 102.$
$S_8^2 = 88, \quad S_9^2 = 80$

The $k$th asset price at the $i$th time step, $S_i^k$, then generates the following asset prices at the $(i+1)$th time step:

$$S_{i+1}^{(k-1)+b+j} = dS_i^k, \quad j=1, \dots, b, k=1, \dots, b^i$$

(where Eq. (5.5.1)), $dS_i^k$ is a random variable from a *given* distribution. $S_i$ follows GBM, we therefore have

$$S_{i+1}^k = \exp\left((r - \frac{\sigma_i^2}{2})\Delta t + \sigma_i dW_i\right), \quad j=1, \dots, b, k=1, \dots, b^i$$

### Compute the lattice option prices

The method used to compute the option values is *similar* to that used by the binomial lattice. The main difference is that there are $b$ branches per node instead of two. The option values are computed starting at maturity, working backward. Here we denote the $k$th value at the $i$th time step by $S_i^k$. For example, in Fig. 5.9, where $b=3$ and $d=3$, we have for the first time step:

$S_1^1 = 115, \quad S_2^1 = 60, \quad \text{ and } S_3^1 = 114$

and for the second time step:

$S_1^2 = 116, \quad S_2^2 = 90, \quad S_3^2 = 149, \quad \dots \quad S_7^2 = 102.$
$S_8^2 = 88, \quad S_9^2 = 80$

The $k$th asset price at the $i$th time step, $S_i^k$, then generates the following asset prices at the $(i+1)$th time step:

$$S_{i+1}^{(k-1)+b+j} = dS_i^k, \quad j=1, \dots, b, k=1, \dots, b^i$$

(where Eq. (5.5.1)), $dS_i^k$ is a random variable from a *given* distribution. $S_i$ follows GBM, we therefore have

$$S_{i+1}^k = \exp\left((r - \frac{\sigma_i^2}{2})\Delta t + \sigma_i dW_i\right), \quad j=1, \dots, b, k=1, \dots, b^i$$
