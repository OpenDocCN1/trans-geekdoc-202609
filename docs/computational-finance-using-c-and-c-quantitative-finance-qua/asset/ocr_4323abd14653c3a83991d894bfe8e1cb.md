and therefore:

```
$d\left(\frac{X_1}{X_2}\right)=\left(\frac{X_1}{X_2}\right)\left(\frac{\mu_1 dt+\sigma_1 dW}{X_1}-X_2\tilde{\mu}_2 dt\right)${\n=\left(\frac{\tilde{\mu}_1}{X_2}-\left(\frac{X_1}{X_2}\right)\tilde{\mu}_2 dt+\left(\frac{\tilde{\sigma}_1}{X_2}\right)\right)$$\n=\frac{1}{X_2}(\tilde{\mu}_1-X_1\tilde{\mu}_2) dt+\left(\frac{\tilde{\sigma}_1}{X_2}\right)$ (I.1.5)
```

Since $\frac{X_1}{X_2}$ is a martingale, the drift term in Eq. (I.1.5) is zero so:

```
$$\tilde{\mu}_1-X_1\tilde{\mu}_2=0$ (I.1.6)
```

Therefore, substituting for $\tilde{\mu}_1$, and $\tilde{\mu}_2$ in Eq. (I.1.6) we obtain:

```
$$\frac{\partial f}{\partial t}+rS\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}-rf=0$ (I.1.7)
```

or

```
$$\frac{\partial f}{\partial t}+rS\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}=rf$ (I.1.8)
```

which is the Black-Scholes partial differential equation, which we derived in Chapter 4.

In general if an asset follows the process:

```
$$\dS=\tilde{\mu}dt+\tilde{\sigma}dW$ (I.1.9)
```

then the price of a derivative $f(S,t)$ obeys the partial differential equation:

```
$$\frac{\partial f}{\partial t}+\tilde{\mu}\frac{\partial f}{\partial S}+\frac{\tilde{\mu}^2}{2}\frac{\partial^2 f}{\partial S^2}=rf$ (I.1.10)
```

or

```
$$\left(\frac{\partial f}{\partial t}+\tilde{\mu}\frac{\partial f}{\partial S}+\frac{\tilde{\mu}^2}{2}\frac{\partial^2 f}{\partial S^2}\right)f=rf$ (I.1.11)
```
