and substituting Eq. (5.3.4) into Eq. (5.3.7) gives:

```
Var[S_{t+\Delta t}] = S_t^2 \exp(2r\Delta t)\{\exp(\sigma^2\Delta t) - 1\}$
```

Since we are modelling asset price movements with a binomial lattice, the asset price, $S_t$, at any given node is only permitted to either jump up or jump down in value over the next time step. Here we will assume that the next price, $S_{t+\Delta t}$, is $S_u$ for an jump up and $S_d$ for a jump down where $u$ and $d$ are constants that apply to all lattice nodes. If we further note the probability of an jump up by $p$, then the probability of a jump down (by definition) is $1-p$.

Now that we have specified the parameters we will use to match the first two moments of the lognormal distribution. This results in the following equation for the mean:

```
$E[S_{t+\Delta t}] = pS_u + (1 - p)S_d = S_t \exp(r\Delta t)$
```

The corresponding equation for the variance requires a little more:

```
$Var[S_{t+\Delta t}] = E[(S_{t+\Delta t})^2] - (E[S_{t+\Delta t}])^2$
```

Since

```
$E[(S_{t+\Delta t})^2] = p(S_u)^2 + (1 - p)(S_d)^2 = S_t^2\pu^2 + (1 - p)d^2\}$
```

and from Eq. (5.3.9), we have:

```
$(S_{t+\Delta t})^2 = S_t^2 \exp(r\Delta t)^2 = S_t^2 \exp(2r\Delta t)$
```

we can substitute Eqs. (5.3.13) and (5.3.14) into Eq. (5.3.12) to obtain:

```
$Var[S_{t+\Delta t}] = S_t^2 \pu^2 + (1 - p)d^2\ - S_t^2 \exp(2r\Delta t)$
```

From Eqs. (5.3.10) and (5.3.15):

```
$\exp(r\Delta t)\{\exp(\sigma^2\Delta t) - 1\ = pu^2 + (1 - p)d^2$\n\= pu^2 + (1 - p)d^2 - \exp(2r\Delta t)$
```

So, restating Eq. (5.3.11) and simplifying Eq. (5.3.16), we obtain the two equations:

```
$pu + (1 - p)d = \exp(r\Delta t)$
```

```
$\exp(2r\Delta t) + \sigma^2\Delta t = pu^2 + (1 - p)d^2\n
```

which we will use to solve for the three parameters $u, d,$ and $p$. Since there are three unknowns and only two equations, we can impose an additional constraint- to obtain a unique solution. The constraint used in the CRR binomial model is:

```
$u = \frac{1}{d}$
```

We now use the following notation:

```
$a = \exp(r\Delta t)$
```
