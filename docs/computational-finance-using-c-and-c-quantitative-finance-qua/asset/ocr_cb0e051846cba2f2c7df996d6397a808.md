# American call options

For American call options we need to solve Eq. (5.2.24), which is:

```
$S^*_i - E = c(S^*_i, E, 	au) + \frac{S^*_i}{\gamma^2} \{1 - \exp(-q	au)N_1(d_1(S^*_i))\}$
```

We denote the $ith$ approximation to the critical asset value $S^*$ by $S^*_i$, and represent the left-hand side of the equation:

```
$LHS(S^*_i, E, \tau) = S^*_i - E$
```

and the right-hand side of the equation by:

```
$RHS(S^*_i, E, \tau) = c(S^*_i, E, \tau) + \frac{S^*_i}{\gamma^2} \{1 - \exp(-q\tau)N_1(d_1(S^*_i))\}$
```

If we let $K(S^*_i, E, \tau) = RHS(S^*_i, E, \tau) - LHS(S^*_i, E, \tau)$ then we want to find the value of $S^*_{i+1}$ which (to a specified tolerance) gives $K(S^*_i, E, \tau) \sim 0$. This can be achieved with Newton's root finding method, in a better approximation,

```
$S^*_{i+1} = S^*_i - \frac{K(S^*_i, E, \tau)}{K'(S^*_i, E, \tau)} \quad (5.2.33)$
```

where:

```
$K'(S^*_i, E, \tau) = \frac{\partial}{\partial S^*_i} \{RHS(S^*_i, E, \tau) - LHS(S^*_i, E, \tau)\}\n= \frac{\partial}{\partial S^*_i} \{RHS(S^*_i, E, \tau)\} - \frac{\partial}{\partial S^*_i} \{LHS(S^*_i, E, \tau)\}\n= b_i - 1$
```

Here we have $b_i = \frac{\partial}{\partial S^*_i} \{RHS(S^*_i, E, \tau)\}$, and the expression for $b_i$ is given by Eq. (5.2.35), which is derived at the end of this section.

Substituting for $K(S^*_i, E, \tau)$ and $K'(S^*_i, E, \tau)$ into Eq. (5.2.32), we obtain:

```
$S^*_{i+1} = S^*_i - \frac{RHS(S^*_i, E, \tau) - LHS(S^*_i, E, \tau)}{b_i - 1}\n= S^*_i - \frac{RHS(S^*_i, E, \tau) - (S^*_i - E)}{b_i - 1}\n= \frac{b_i S^*_i - RHS(S^*_i, E, \tau) + E}{b_i - 1}
```

The final iterative algorithm for the American call is therefore:

```
$S^*_{i+1} = \frac{E + RHS(S^*_i, E, \tau) - b_i S^*_i}{1 - b_i} \quad (5.2.34)$
```
