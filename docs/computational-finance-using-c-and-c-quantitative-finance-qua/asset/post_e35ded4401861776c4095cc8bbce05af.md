
# The floating leg

We will now evaluate Eq. (7.2.14). The floating leg coupon payment at time $t_i$ will be denoted by $C_i$ and has value:

```
$C_i = PF(t, t_{i-1}, t_{i-1} + \tau_{t_i})$
```

where

```
$F(t, t_{i-1}, t_{i-1} + \tau_{t_i}) = \left\{ \frac{DF(t, t_{i-1})}{DF(t, t_{i-1} + \tau_{t_i})} - 1 \right\}$
```

From Eq. (7.2.14) we have thus:

```
$FLT(t) = \sum_{i=k+1}^{n} C_i DF(t, t_i)
= P \sum_{i=k+1}^{n} DF(t, t_i) \tau_{t_i} \left\{ \frac{DF(t, t_{i-1})}{DF(t, t_i)} - 1 \right\}$
$= P \sum_{i=k+1}^{n} \{DF(t, t_{i-1}) - DF(t, t_i)\}$
= P\{DF(t, t_k) - DF(t, t_{k+1}) + DF(t, t_{k+1}) - \dots$
- DF(t, t_i) + DF(t, t_i) - \dots - DF(t, t_n)\}$
= P\{DF(t, t_k) - DF(t, t_n)\}$
```

and so the value of floating leg is

```
$FLT(t) = P\{DF(t, t_k) - DF(t, t_n)\}$, (7.2.15)
```

# The swap rate

The time $t$ swap rate $SR_t$ is the value of the fixed rate $K$ that makes the IRS zero. Thus, from Eqs. (7.2.12)-(7.2.14):

```
$P\{DF(t, t_k) - DF(t, t_n)\} = PSR_t \sum_{i=k+1}^{n} DF(t, t_i) \tau_{t_i}$ (7.2.16)
```

so

```
$SR_t = \frac{DF(t, t_k) - DF(t, t_n)}{\sum_{i=k+1}^{n} DF(t, t_i) \tau_{t_i}}$ (7.2.17)
```

# Amortization

So we have assumed that the principal is fixed and set to the value $P$. We will now deal with the situation where the principal varies with time according to the following amortization schedule:

```
$AM_i = P_{i-1} - P_i, \quad i = 0, \dots, n-1$, (7.2.18)
```

# Other financial derivatives

where $P_i$ is the value of the principal at time $t_i$ and $P_0 = P$. The value of the floating leg is now computed as:

```
$FLT(t) = \sum_{i=k}^n P_{i-1}DF(t, t_i)\tau_i \left{\frac{DF(t, t_{i-1})}{DF(t, t_i)} - 1\right\} \frac{1}{\tau_i}$
$= \sum_{i=k}^n P_{i-1}\{DF(t, t_{i-1}) - DF(t, t_i)\}$
$= P_kDF(t, t_k) - P_kDF(t, t_{k+1})$
$+ P_{k+1}DF(t, t_{k+1}) - P_{k+1}DF(t, t_{k+2}) + \dots$
$+ P_{n-2}DF(t, t_{n-1}) - P_{n-1}DF(t, t_{n-1}) - P_{n-1}DF(t, t_n)$
$ P_kDF(t, t_k) - DF(t, t_k)(P_k - P_{k+1}) - P_{k+1}\dots$
$- DF(t, t_{n-2})(P_{n-2} - P_{n-1}) - \sum_{i=k}^{n-1} AM_iDF(t, t_i)$
$= P_kDF(t, t_k) - P_{n-1}DF(t, t_n) + \sum_{i=k}^{n-1} AM_iDF(t, t_i) \quad (7.2.19)$
```

and so the value of the floating leg is:

```
$FLT(t) = P_kDF(t, t_k) - P_{n-1}DF(t, t_n) + \sum_{i=k}^{n-1} AM_iDF(t, t_i) \quad (7.2.20)
```

When there is no association ($P_k = P_{n-1}$ and $AM_i = 0, i = 0, \dots, n-1$) then Eq. (7.2.20) reduces to Eq. (7.2.15).

# Basis swap

This is very similar to an interest rate swap, but now there are two floating legs, each with their associated principal amount.

For example, floating leg 1 could be associated with the one month LIBOR (London Inter Bank Offer Rate) and have a schedule of monthly payments, while floating leg 2 could use the three month LIBOR rates and quarterly payments. In this case, the forward rates and discount factors for leg 1 would be computed using one month LIBOR yield curve and the forward factors for leg 2 will be computed using the three month LIBOR yield curve.

We will use the subscripts 1 and 2 to denote quantities associated. The payment times associated with leg 1 are $t'_i, i=1, \dots, n_1$, while for leg 2 are $t''_i, i=1, \dots, n_2$, and (for this example) $n_1 = 3n_2$.

If counterparty A makes the quarterly payments (that is, receives the payments made on leg 1), then the time $t$ value of the basis swap is:

```
$BS(t) = C_1DF(t, t_k) + FLT_1(t) - C_2DF(t, t_k) - FLT_2(t) \quad (7.2.21)
```

we have used similar notation to that used in Eq. (7.2.12), with

$FLT_1(t) = P_1(DF_1(t, t_k) - DF_1(t, t_n)) \quad (7.2.22)$

and

$FLT_2(t) = P_2(DF_2(t, t_k) - DF_2(t, t_n)) \quad (7.2.23)$

In Eqs. (7.2.22) and (7.2.23) $P_1$ is the principal for leg 1 and $P_2$ is the principal for leg 2. The time of the next coupon payment for leg 1 is $t_{k_1}$, while for leg 2 is $t_{k_2}$; in addition we have used the fact that $t_{n_1} = t_{n_2}$.

We will now consider the case in which the basis swap has been traded at time $t$, and will also assume that $C_1 = C_2 = 0$ and $t_{k_1} = t_{k_2}$. In addition, we will specify that principal exchange occurs at the start (time) and end (time) of the swap. The cash flows associated with principal exchange at the start of the swap are in the opposite direction to those for the remainder of the swap; Hull (203).

$FLT_1(t) = P_1 - P_1DF_1(t, t_n) + \{P_1 - DF_1(t, t_n)\} \quad (7.2.24)$

and

$FLT_2(t) = P_2 - P_2DF_2(t, t_n) + \{P_2 - DF_2(t, t_n)\} \quad (7.2.25)$

where the principal exchange terms are in the curly brackets, and use discount factors $DF_1(t, T)$ from the main currency curve (in GBP) rather than $DF_2(t, T)$.

It can be seen from Eq. (7.2.21) that principal exchange at the start of the swap causes leg 2 to contribute the positive $P_2$ to the value of swap, while leg 1 contributes the negative $P_2$ to the value. In contrast, principal exchange at the end of the swap results in leg 2 contributing the negative $-P_2DF(t, t_n)$ to the swap, while leg 1 contributes the positive $P_1DF(t, t_n)$. If $P_1 = P_2$ then principal exchange does not affect the value of basis swap. It can also be seen from Eq. (7.2.24) that if leg 1 used the main curve instead of main LIBOR curve, then $DF_1(t, t_n) = DF(t, t_n)$ which would result in $FLT_1(t) = 0$. Similarly $DF_2(t, t_n) = DF(t, t_n)$ would mean $FLT_2(t) = 0$.

If the valuation time $t$ is after the date has started, Eq. (7.2.21) can be used to price the basis swap, but Eqs. (7.2.24) and (7.2.25) need to be modified as follows:

$FLT_1(t) = P_1DF_1(t, t_k) - P_1DF_1(t, t_n) + \{P_1DF_1(t, t_n)\} \quad (7.2.26)$

and $FLT_2(t) = P_2DF_2(t, t_k) - P_2DF_2(t, t_n) + \{P_2DF_2(t, n)\} \quad (7.2.27)$

We will now consider how the timing of the coupon payment in relation to its associated forward rate affects the present value, $V_0$. In this section we will justify the approach we have adopted in obtaining the present value of future cashflows generated from vanilla forward rates.

From Eq. (4.1) we know that the value at $t_0$ of a coupon payment at time $t_k$ is:

```
$V_{t_0} = DF(t_0, t_k)E^{Q_k} \left[\frac{F(t_{k-1}, t_{k-1}, t_k)}{DF(t_k, t_k)}\right]$
```

Since $DF(t_k, t_k) = 1$ we can write:

```
$V_{t_0} = DF(t_0, t_k)E^{Q_k} [F(t_{k-1}, t_{k-1}, t_k)] \quad (7.2.28)
```

In Section 7.2.3 we show that $F(t, t_{k-1}, t_{k-1})$ follows the process:

```
$d(F(t, t_{k-1}, t_{k-1})) = \sigma_k F(t, t_{k-1}, t_{k-1}) dW^k \quad (7.2.29)
```

If we assume $\sigma_k$ is constant, then Eq. (7.2.29) is GBM (see Chapter 2) and has the solution:

```
$F(t, t_{k-1}, t_{k-1}) = F(t_0, t_{k-1}, t_{k-1}) \exp\left(\frac{(t-t_0)\sigma_k^2}{2} + \sigma_k W_t^k\right) \quad (7.2.30)
```

where we have taken $W_{t_0}^k = 0$. Substituting $t=t_{k-1}$ into Eq. (7.2.30) gives:

```
$F(t_{k-1}, t_{k-1}, t_k) = F(t_0, t_{k-1}, t_{k-1}) \exp\left(\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k\right) \quad (7.2.31)
```

which means:

```
$E^{Q_k} [F(t_{k-1}, t_{k-1}, t_k)] = E^{Q_k} \left[ F(t_0, t_{k-1}, t_k) \exp\left(\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k\right) \right]$
$= F(t_0, t_{k-1}, t_k) E^{Q_k} \left[ \exp\left(\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W_{t_{k-1}}^k\right) \right]$
$= F(t_0, t_{k-1}, t_k) E^{Q_k} \left[ \exp\left(\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k \sqrt{t_{k-1}-t_0} N(0,1)\right) \right]$
$= F(t_0, t_{k-1}, t_k)$
```

where we have used this (Appendix D.2):

```
$E^{Q_k} \left[ \exp \left(-\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k \sqrt{t_{k-1}-t_0} N(0,1)\right) \right] = \exp \left(-\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k \sqrt{t_{k-1}-t_0} N(0,1)\right) = 1$
```

so

```
$V_{t_0} = DF(t_0, t_k) \cdot F(t_0, t_{k-1}, t_k)
```

matches the zero coupon bond $DF(t_0, t_k) = DF(t_0, t_{k-1})F(t_{k-1}, t_{k-1}, t_k)$

```
$V_{t_0} = DF(t_0, t_{k-1})
```

# General payment

The value of the floating leg is now computed as:

```
$FLT(t) = \sum_{i=k}^n P_{i-1}DF(t, t_i)\tau_i \left{\frac{DF(t, t_{i-1})}{DF(t, t_i)} - 1\right\} \frac{1}{\tau_i}$
$= \sum_{i=k}^n P_{i-1}\{DF(t, t_{i-1}) - DF(t, t_i)\}$
$= P_kDF(t, t_k) - P_kDF(t, t_{k+1})$
$+ P_{k+1}DF(t, t_{k+1}) - P_{k+1}DF(t, t_{k+2}) + \dots$
$+ P_{n-2}DF(t, t_{n-1}) - P_{n-1}DF(t, t_{n-1}) - P_{n-1}DF(t, t_n)$
$ P_kDF(t, t_k) - DF(t, t_k)(P_k - P_{k+1}) - P_{k+1}\dots$
$- DF(t, t_{n-2})(P_{n-2} - P_{n-1}) - \sum_{i=k}^{n-1} AM_iDF(t, t_i)$
$= P_kDF(t, t_k) - P_{n-1}DF(t, t_n) + \sum_{i=k}^{n-1} AM_iDF(t, t_i) \quad (7.2.19)$
```

and so the value of the floating leg is:

```
$FLT(t) = P_kDF(t, t_k) - P_{n-1}DF(t, t_n) + \sum_{i=k}^{n-1} AM_iDF(t, t_i) \quad (7.2.20)$
```

When there is no association ($P_k = P_{n-1}$ and $AM_i = 0, i = 0, \dots, n-1$) then Eq. (7.2.20) reduces to Eq. (7.2.15).
