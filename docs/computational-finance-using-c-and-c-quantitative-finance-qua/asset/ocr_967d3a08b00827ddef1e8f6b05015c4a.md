# Lognormal variance

```
Var[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2\nexp(2\eta + v^2)[exp(v^2) - 1]$
```

substituting for $\eta$ and $v^2$ gives:

```
Var[X] = exp{2r(r - \sigma^2/2)\Delta t + \sigma^2\Delta t}
```

which can be simplified to yield:

```
Var[X] = exp[2r\Delta t][exp($\sigma^2\Delta t$) - 1]
```

Since we assume that the expected value of X grows at the riskless rate, $r$, we can also write:

```
$E[X] = exp(r\Delta t)$
```

The above results can be used to find the first two moments of the asset price distribution $S_{t+\Delta t}$, given that we know the asset price, $S_t$, at instant time $t$. To do this we will use (see Appendix C.3 for a proof) the fact that for a random variable $G$ we have:

```
$E[a + bG] = E[a]+E[G]$ and $Var[a + bG] = b^2Var[G]$
```

where $a$ and $b$ are constants. Applying this to the variable X:

```
$E[X] = E[S_{t+\Delta t}/S_t] = \frac{1}{S_t}E[S_{t+\Delta t}]$
```

and

```
$Var[X] = Var[S_{t+\Delta t}/S_t] = \frac{1}{S_t^2}Var[S_{t+\Delta t}]$
```

where we have used $a=0$ and $b=1/S_t$. Note: It is also easy to show that:

```
$Var[S_{t+\Delta t}] = Var[S_t]$
```

where the change in asset price over the time interval $\Delta t$ is denoted by $\Delta S = S_{t+\Delta t} - S_t$. This elementary result is sometimes used without proof, for ex-example Hull (1997), p. 344. The proof is simple:

```
$Var[S_{t+\Delta t}] = Var[S_t + \Delta S] = Var[\Delta S]$
```

where we have used:

```
$Var[a + bG] = b^2Var[G]$, this time with $a=0$ and $b=1$.
```

To find expressions for the mean and variance of $S_{t+\Delta t}$ we simply substitute Eq. (5.3.5) into Eq. (5.3.6) and obtain:

```
$E[S_{t+\Delta t}] = S_t exp(r\Delta t)$
```
