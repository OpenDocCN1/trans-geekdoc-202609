The project PortfolioValuer.csproj is the driver for the application and contains the C# code given in Code excerpt 8.1. The user interface is simply a windows form with a button to start the application, and if this could easily be customized by the reader. Once the application has been started, it loads a market data file and reads a portfolio configuration file to determine which portfolios are to be valued. Valuation proceeds for all the deals contained in the portfolio files and the results are written to the appropriate portfolio results.

The project DealLibrary.csproj is concerned with the valuation of the available trades. A separate C# class, derived from a single abstract class BaseDeal, is provided for each trade type. The BaseDeal class provides abstract methods such as Price() and Validate(), need to be implemented in deal classes. We will be primarily concerned with the method Price(), which is used to return the current value of a trade. Deal valuation may either be performed completely in C# code or calling appropriate C routines in the Analytics_MathLib dynamic library—this contains C pricing functions discussed in previous sections of the book and also utilities (such as random generators),

# 8.1.2 The text files

The application is driven by a portfolio configuration file and also a number of portfolio definition files, each of which is in plain text and can easily be edited by the user. The portfolio configuration file specifies the names of the portfolio files that are to be valued, and each portfolio definition file provides the details of the trades contained in a given portfolio. In addition there is a market data file (also in text format) which provides the market data required to value the trades.

A portfolio configuration file and two portfolio definition files are given in Exhibit 8.1. It can be seen that comments are useful for documenting the deals contained in the portfolio definition files; it is also possible to ignore a single trade by using a // at the beginning of a line. Complete sections of a portfolio definition file can also be ignored using the C# style syntax /*.*/

The syntax of each deal entry in the Portfolio Definition file is as follows:

```
Trade=<DealClass>, Reference=<Descriptive Text,DealClassParam1=<Valuel>, ... 
DealClassParamN=<N>
```
