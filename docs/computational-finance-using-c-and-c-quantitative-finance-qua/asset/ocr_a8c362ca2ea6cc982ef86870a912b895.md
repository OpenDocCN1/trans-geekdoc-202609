European options

Rearranging the integrand:

```
$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \exp\left(\frac{\{X - (r - \sigma^2/2)\tau\}^2 - 2\sigma^2 X}{2\sigma^2\tau}\right) dX\n(4.4.44)$
```

Expanding the terms in the exponential:

```
${X - (r - \sigma^2/2)\tau\}^2 - 2\sigma^2 X\n= X^2 - 2\{(r - \sigma^2/2)\tau\}X + \{(r - \sigma^2/2)\tau\}^2 - 2\sigma^2 X\n= X^2 - 2\{(r + \sigma^2/2)\tau\}X + \{(r - \sigma^2/2)\tau\}^2\n= {X - (r - \sigma^2/2)\tau\}^2 + \{(r - \sigma^2/2)\tau\}^2$
```

Which results in:

```
${X - (r - \sigma^2/2)\tau\}^2 - 2\sigma^2 X = {X - (r + \sigma^2/2)\tau\}^2 - 2\sigma^2 r\tau^2$ (4.4.45)$
```

Substituting Eq. (4.4.45) into the integrand of Eq. (4.4.44) we have:

```
$\exp(X) \exp\left(\frac{\{X - (r - \sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right)\n= \exp(r\tau) \exp\left(\frac{\{X - (r + \sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right)$
```

The integral $I_A$ can be expressed as:

```
$I_A = \frac{\exp(r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \exp\left(\frac{\{X - (r + \sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right) dX$
```

If we let $u = \frac{X-(r+\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ then $dX = \sigma\sqrt{\tau} du$. So

```
$I_A = \frac{S\sigma}{\sigma\sqrt{2\pi}} \int_{u=k_1}^{\infty} \exp\left(-\frac{u^2}{2}\right) du$
```

where the lower limit of integration is $k_1 = \frac{\log(E/S)-(r+\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$. We therefore have:

```
$I_A = SN_1(-k_1)$ (4.4.46)
```

Therefore the value of a European call is:

```
$c(S, E, \tau) = SN_1(-k_1) - E\exp(-r\tau)N_1(-k_2)$
```

which gives the usual form of the Black-Scholes formula for a European call as:

```
$c(S, E, \tau) = SN_1(d_1) - E\exp(-r\tau)N_1(d_2)$ (4.4.47)
```
