# # A.6 Vega

Vega is the rate of change of option value with volatility. For a call we have:

```
$$\mathcal{V}_c = \frac{\partial c}{\partial\sigma}\n= \frac{\partial}{\partial\sigma}\{S\exp(-q(T-t))N_1(d_1) - E\exp(-r(T-t))N_1(d_2)}\n= S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\sigma} - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial r} \quad (A.6.1)$
```

Substituting for $n(d_2)$ and $\frac{\partial d_2}{\partial\sigma}$ we obtain:

```
$$\mathcal{V}_c = S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\sigma}\n=- Sn\exp(-q(T-t))\left{\frac{\partial d_1}{\sigma} - \sqrt{T-t}\right\\}$
```

Therefore

```
$$\mathcal{V}_c = S\exp(-q(T-t))n(d_1)\sqrt{T-t} \quad (A.6.2)$
```

For a European put we have:

Substituting for $n(d_2)$ and $\frac{\partial d_2}{\partial\sigma}$ we obtain:

```
$$\mathcal{V}_p = S\exp(-q(T-t))n(d_1)\sqrt{T-t} \quad (A.6.3)$
```

which is the same as for a call.
