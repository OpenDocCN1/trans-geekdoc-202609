The user also supplies the function opt\_gfd with the number of time intervals for the grid. When there are $n_t$ time intervals, the grid has $n_t + 1$ uniformly spaced times, $t_i = i\Delta t, i = 0, \dots, n_t$, and the time step is simply:

```
$$\Delta t = \frac{\tau}{n_t} \quad (5.4.3)$
```

As with the binomial lattice methods we will solve the equation backwards in time from maturity $(t + \tau)$ to the present $(t)$. So as we solve the equation the time index will start at $i = n_t (t + \tau)$ and decrease to $i = 0$ (current time $t$).

Here we discuss the grid method of solving the Black-Scholes equation in terms of:

+   * The finite-difference approximation
* The boundary conditions
* Computation of the option values at a given time instant
* Backwards iteration and early exercise

Each of these aspects will be considered in turn.

# The finite-difference approximation

The option value corresponding to the grid node at $t_i = i\Delta t$ and $S_j = j\Delta S$ will be denoted by $f_{i,j}$. We will approximate the partial derivative of $f_{i,j}$ with respect to time simply as:

```
$$\frac{\partial f}{\partial t} = \frac{f_{i+1,j} - f_{i,j}}{\Delta t} \quad (5.4.4)$
```

For the other terms in Eq. (5.4.1) we will use the weight, $\Theta_m$, method. This technique involves selecting an appropriate choice for $\Theta_m$ in the range $0 < \Theta_m \le 1$ so that the contribution from node $(i, j)$ is a weighted sum over the values at $(i, j)$ and $(i+1, j)$. For instance, the term $rf|_{i,j}$ in Eq. (5.4.1) is approximated as:

```
$$\rf|_{i,j} = r\{\Theta_m f_{i,j} + (1 - \Theta_m)f_{i,j}\ \quad (5.4.5)$
```

and the term $\frac{\partial f}{\partial S}|_{i,j}$ in Eq. (5.4.1) is approximated as:

```
$$\frac{\partial f}{\partial S}|_{i,j} = \{\Theta_m \frac{\partial f}{\partial S}|_{i+1,j} + (1 - \Theta_m)\frac{\partial f}{\partial S}|_{i,j}} \quad (5.4.6)$
```

Using this method we obtain, at node $(i, j)$, the following discretized version of Eq. (5.4.1):

```
$$\frac{f_{i+1,j} - f_{i,j}}{\Delta t} + (r - q)S_j{\Theta_m f'_{i+1,j} + \Theta_m^* f'_{i,j}\}
n+ \frac{1}{2}\sigma^2 S_j^2{\Theta_m f''_{i+1,j} + \Theta_m^* f''_{i,j}\} = r{\Theta_m f_{i+1,j} + \Theta_m^* f_{i,j}} \quad (5.4.7)$
```
