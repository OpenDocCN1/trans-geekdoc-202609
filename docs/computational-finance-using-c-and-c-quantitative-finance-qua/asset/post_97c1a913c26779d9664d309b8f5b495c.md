### Code example 8.12 (Continued).

On an arbitrary number of underlying assets; the derived class implement the abstract method Payoff. In the earlier sections of this book, we have considered options with standard payoffs such as: vanilla put, vanilla call, and call/put on min/max assets. However, GenericEquityBasketOption now opens the possibility of supplying a user-defined Payoff function so that options with non-standard payoffs can be valued.

Below we provide examples for options on two and ten assets. The assets were Drinks, Beverage-Ltd, H-Ltd, and Wines-Ltd. The trade attributes are a time to expire of one year, all volatilities are 0.2, and the number of units is 100. Other information required to price the option, as the correlations between the equities and the free interest rate, is taken from market dictionaries.

The syntax for using the deal class GenericEquityBasketOption with the portfolio definition is:

| Attribute | Value |
| :--- | :--- |
| Trade | GenericBasketOptionDeal:Payoff=MaxPut |
| Reference | A |
| Strike | 100.0 |
| Volatilities | 0.2, 0.2, 0.2, 0.2 |
| Equities | Drinks, Beverage-Ltd, H-Ltd, Wines-Ltd |
| NumberOfUnits | 100 |
| Time_Expiry | 1.0 |
| NumberScenarios | 100 |

while that for the deal class FourEquityOption:

| Attribute | Value |
| :--- | :--- |
| Trade | FourEquityOptionDeal |
| Reference | B |
| Volatility1 | 0.2 |
| Volatility2 | 0.2 |
| Volatility3 | 0.2 |
| Volatility4 | 0.2 |
| Equity1 | Drinks, Beverage-Ltd |
| Equity3 | H-Ltd, Wines-Ltd |
| NumberOfUnits | 100 |
| Strike | 100.0 |
| Time_Expiry | 1.0 |
| OptionType | put, MinMax |
| MonteCarlo | Yes |
| NumberScenarios | 1000 |

The crucial difference is that the entry for GenericEquityBasketOption contains the extra directive `Trade=GenericEquityOptionDeal:Payoff=MaxPut`, whereas FourEquityOption is the usual `Trade=FourEquityOptionDeal:Payoff=MaxPut` which means the contents of the file Payoff_Max.txt will be compiled at runtime and thereby create the (sub)class GenericEquityOptionMaxPut, which is derived from the abstract base class GenericEquityBasketOption. .NET assembly containing the class GenericEquityOptionMaxPut is stored in memory and its Price() is called to validate the option.

the file PayoffMaxPut.txt contains the following C# code:

```cs
using System;
namespace ComputationalLib
{
    public class GenericEquityOptionMaxPut : GenericEquityOptionOption
    {
        public override string Name()
        {
            string temp_string = "";
            temp_string = "Generic option: Put on maximum " + n_.ToString() + " assets";
            return temp_string;
        }

        public override double Payoff() // implement max, put
        {
            double the_max = 0.0;
            double pay_val = 0.0;
            double zero = 0.0;
            for (int j = 0; j < n_; j++)
            {
                if (ST_[j] > the_max) the_max = ST_[j];
            }
            pay_val = Math.Max(Strike - the_max, zero);

            return pay_val;
        }
    }
}
```

In the above code ST_, Strike_, and n_ are data members of the base class GenericEquityBasketOption. We now present other entries in the portfolio file which illustrates the versatility of the data class GenericEquityBasketOption.
