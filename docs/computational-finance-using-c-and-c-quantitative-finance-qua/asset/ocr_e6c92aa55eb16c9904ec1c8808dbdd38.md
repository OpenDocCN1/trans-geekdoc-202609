# 7.2.4 Interest rate quantos

This section considers derivatives whose value depends on the foreign interest rate yield curve but have a payoff in domestic currency. We use the same notation as in Section 7.3, which deals with foreign exchange derivatives.

For example, a standard rate cap has a payoff in domestic currency and also depends on the domestic currency forward rates. The value at time $t_0$ of a caplet which pays at time $t_k$ and extends from time $t_{k-1}$ to $t_k$ is:

```
$Caplet(t_0) = P\tau D^p(t_0, t_k)E^Q[max(F^d_k - K, 0)]$
```

where P is the principal, K is the strike, $	au = t_{k-1}-t_k$, $F^d$ is the domestic forward rate $F^d(t_0, t_k, t_{k-1})$. Equation (7.2.74) can be evaluated using the Black–Scholes formula as:

```
$Caplet(t_0) = P\tau D^p(t_0, t_k)\{F^d(t_0, t_k, t_{k-1})N_1(d_1) - KN_1(d_2)\}
```

where $\sigma_d$ is the volatility of $F^d$, and

```
$d_1 = \frac{\log(F^d(t_0, t_k, t_{k-1})/K) + \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$\n$d_2 = \frac{\log(F^d(t_0, t_k, t_{k-1})/K) - \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$
```

In Section 7.2.3 we showed that the $(F^d(t, t_{k-1}, t_k)/DF^p(t, t_k))$ is a martingale, that is zero drift when $DF^p(t, t_k)$ is used as a numera.

```
$d(F^d(t, t_{k-1}, t_k)) = \sigma_d F^d(t, t_{k-1}, t_k)dW_t^Q$
```

# Quanto caplet

In a quanto caplet inset using the domestic forward rate $F^d(t_0, t_k, t_k)$ we use the foreign forward rate $F^f(t, t_{k-1}, t_k)$. Under the probability measure $\mathbb{F}$ associated with a foreign zero coupon bond $DF^f(t, t_k)$ the foreign forward rate is a martingale, and is described by the following equation:

```
$d(F^f(t, t_{k-1}, t_k)) = \sigma_f F^f(t, t_{k-1}, t_k)dW_t^{\mathbb{F}}$
```

However, when we use $DF^d(t, t_k)$ as a numeraire the process $(F^f(t, t_{k-1}, t_k)/DF^d(t, t_k))$ has a drift, and follows the process:

```
$d(F^f(t, t_{k-1}, t_k)) = F^f(t, t_{k-1}, t_k)\alpha dt + \sigma_f F^f(t, t_{k-1}, t_k)dW_t^{\mathbb{Q}}$
```

Our aim is to find the value of $\alpha$ and then price the quanto caplet:

```
$QCaplet(t_0) = P\tau D^p(t_0, t_k)\n\times\{F^f(t_0, t_{k-1})exp(\alpha(t_{k-1}-t_0))N_1(d_1) - KN_1(d_2)\}
```
