For the conditional variance:

```
$V_t = \frac{(1 - \exp(-2\alpha(t_1 - t_0)))(1 - \exp(-2\alpha(t_1 - t)))}{2\alpha(1 - \exp(-2\alpha(t_1 - t_0)))}$
```

For small $t_1 - t_0$ both $t_1 - t$ and $t - t_0$ are small, we can write:

```
$V \to \frac{\{\{1 - 2\alpha(t_1 - t_0)\}\}(\{1 - 2\alpha(t_1 - t)\}\}}{2\alpha(1 - 2\alpha(t_1 - t_0))}$
```

which yields the Brownian bridge result for the conditional variance:

```
$V_t \to \frac{\{t - t_0)(t_1 - t)\}}{t_1 - t_0}$
```

# 2.12.1 Fubini's theorem

Fubini's theorem states that (for well-behaved functions) the value of a multidimensional integral is independent of the order in which the integral is evaluated. For example, the two-dimensional integral of $f(X, Y)$ can be evaluated as:

```
$$\int_{X=a}^b \int_{Y=c}^d f(X, Y) \ dY \ dX = \int_{Y=c}^d \int_{X=a}^b f(X, Y) \ dX \ dY = \int_{X=a}^b \int_{Y=c}^d f(X, Y) \ dY \ dX$
```

We will mainly use this in the form:

```
$$\int_{s=0}^\infty f(W, s) \ ds = \int_{s=0}^\infty E[f(W, s)] \ ds \quad (2.12.1)$
```

Since

```
$E[f(W, s)] = \int_{-\infty}^\infty P(W, s) f(W, s) \ dW$
```

Where $P(W, s)$ is the probability density function of $f(W, s)$, we can then use Eq. (2.12.1) in full as:

```
$$\int_{W=-\infty}^\infty \int_{s=0}^\infty P(W, s) f(W, s) \ ds \ dW = \int_{s=0}^\infty \int_{W=-\infty}^\infty P(W, s) f(W, s) \ dW \ ds$
```
