# 4.5.4 Monte Carlo pricing of down and out options

In this section we show how Monte Carlo simulation can be used to price
down and out barrier options. We will describe both a basic Monte Carlo approach and a Brownian bridge method which gives a more accurate results (see Chapter 8).

The asset price, $S$, will be assumed to be GBM, so the logarithm of the asset
price $X$ follows the Brownian process:

```
$\Delta X = v\Delta t + \sigma\Delta W_t$ \quad (4.5.18)$
```

where $\nu$ is the drift and $\sigma$ is the volatility.
