We denote the $j$th value at the $i$th time step by $S_i^j$. For example, in Fig. 5.9, where $b=3$ and $d=3$, we have for the first time step:

$S_1^1 = 115, \quad S_2^1 = 60, \quad$ and $S_3^1 = 114$

and for the second time step:

$S_1^2 = 116, \quad S_2^2 = 90, \quad S_3^2 = 149, \quad \dots \quad S_7^2 = 102.\\nS_8^2 = 88, \quad S_9^2 = 80$

The $k$th asset price at the $i$th time step, $S_i^k$, then generates the following asset prices at the $(i+1)$th time step:

```
$S_{i+1}^{(k-1)+b+j} = dS_i^k, \quad j=1, \dots, b, k=1, \dots, b^i$
```

(where Eq. (5.5.1)), $dS_i^k$ is a random variable from a *given* distribution. $S_i$ follows GBM, we therefore have

```
$S_{i+1}^k = \exp((r - \frac{\sigma_i^2}{2})Delta t + \sigma_i dW_i), \quad j=1, \dots, b, k=1, \dots, b^i$
```
