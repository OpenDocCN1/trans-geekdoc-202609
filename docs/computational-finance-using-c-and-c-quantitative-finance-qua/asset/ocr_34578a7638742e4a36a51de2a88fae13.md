The conditional probability density function associated with $P(m_t^X \leqslant b, X_t \geqslant x)$ is

```
$p(m_{t_2}^X \leqslant b, X_{t_2} | X_{t_1}) = \frac{1}{\sigma\sqrt{2\pi\Delta t}}\exp\left(\frac{2v(b-X_{t_1})}{\sigma^2}\right)\exp\left(-\frac{(X_{t_1} + X_{t_2} - 2b + \nu\Delta t)}{2\sigma^2\Delta t}\right) \(H.1.10)$
```

where $t_2 \geqslant t_1$ and $\Delta t = t_2 - t_1$.

# H.2 Proof of Eq. (H.1.2)

From Eq. (H.1.1):

$X_t = \sigma\sqrt{t}, Z_t \sim N(0, 1)$

where $X_0 = 0$. We will derive the probability of events $m_t^X \leqslant b$ and $X_t \geqslant x$ occurring. For each event $m_	au^X$ to occur there must be a time $	au$ at which $X_	au \leqslant b$, where $0 < \tau \leqslant t$. At time $	au$, instead of continuing with the original Brownian motion, we will consider the *reflected* motion $X_t^R$ defined by:

```
$X_s^R = X_s, \quad s < \tau\nX_s^R = 2b - X_s, \quad s \geqslant \tau$
```

Therefore, before time $	au$ the motion $X_s$ is identical to the event $X_s^R$. For $s \geqslant \tau$ the *coordinates* of $X_s^R$ are obtained by reflecting the values of $X_s$ about the level $b$. (remember $b \leqslant x$). The event $X_t \geqslant x$ is then equivalent to the event $X_t^R \leqslant 2b-x$ (remember $b \leqslant 0$ and $x \geqslant 0$). However, the event $X_	au^R \leqslant 2b-x$ only occurs if $m_	au^X \leqslant b$ also occurs, giving:

```
$P(X_	au^R \leqslant 2b-x) = P(m_	au^X \leqslant b, X_	au \leqslant x)$
```

At time $	au$

```
$X_	au^R = 2b - X_	au \quad(H.2.1)$
```

and after time $\tau$

```
$X_{	au+\gamma}^R = 2b - X_{	au+\gamma}, \quad \gamma > 0 \quad(H.2.2)$
```

Thus subtracting Eq. (H.2.1) from Eq. (H.2.2) gives::

```
$X_{	au+\gamma}^R - X_	au^R = X_	au - X_{	au+\gamma}\nX_{	au+\gamma}^R - X_	au^R = -(X_{	au+\gamma} - X_	au) \quad(H.2.3)$
```

However, we know that:

```
$(X_{	au+\gamma} - X_	au) \sim N(0, \sigma^2\gamma) \quad(H.2.4)$
```

So

```
$(X_{	au+\gamma}^R - X_	au^R) \sim -N(0, \sigma^2\gamma)$
```
