# 8.3 The PricingUtils class and the Analytics_MathLib

It has already been mentioned that these classes make possible to the C pricing function that are contained in Analytics_MathLib.dll. To do this it is necessary to provide a C# declaration for the pricing function. This is carried out in the PricingUtils class by declaring the routines as extern and using the C# DImport attribute, which is defined in the namespace System.Runtime.Interop. Code except 8.8 provides a sample of the C# runtime in PricingUtils and some of the C Dec-
