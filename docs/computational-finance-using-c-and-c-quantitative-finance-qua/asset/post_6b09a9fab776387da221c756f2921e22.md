For the most general case let: $Z_1 = a + \sum_{i=1}^n b_i X_i$ and $Z_2 = c + \sum_{j=1}^M b_j Y_j$. So

```
$$\text{Cov}[Z_1, Z_2] = \text{Cov} \left[ a + \sum_{i=1}^n b_i X_i, c + \sum_{j=1}^M d_j Y_j \right]$$

= \text{Cov} \left[ a + \sum_{i=1}^n b_i X_i, c + \sum_{j=1}^M d_j Y_j \right]$$
```

So

```
$$\text{Cov} \left[ a + \sum_{i=1}^n b_i X_i, \sum_{j=1}^M d_j Y_j \right] = \text{Cov} \left[ b_i X_i, \sum_{j=1}^M d_j Y_j \right]$$

= \sum_{i=1}^n b_i \text{Cov} \left[ X_i, \sum_{j=1}^M d_j Y_j \right]$$

= \sum_{i=1}^n b_i \sum_{j=1}^M d_j \text{Cov} \left[ X_i, Y_j \right]$$
```

```
$$\text{Cov}[Z_1, Z_2] = \sum_{i=1}^n \sum_{j=1}^M b_i d_j \text{Cov}[Y_j, X_i]$$
```

## C.3.3 Covariance matrix

Let $X$ denote the $n$ element vector containing the random variables $X_i, i = 1,\dots,n$. The mean and variance of the $i$th variable is $E[X_i]$ and $E[(X_i - E[X_i])^2]$ respectively. The covariance $\text{Cov}[X]_{ij}$ between the $i$th and $j$th variables is $E[(X_i - E[X_i])(X_j - E[X_j])]$. The elements of $n$ by $n$ covariance matrix $\text{Cov}[X]$ are them:

```
$$\text{Cov}[X]_{ij} = E[(X_i - E[X_i])(X_j - E[X_j])]$$

$i = 1,\dots,n, j = 1,\dots,n \quad \quad (C.3.1)$$
```

We will now show that $\text{Cov}[X + A] = \text{Cov}[X]$ where $A$ is an $n$ element vector containing the constants $A_i, i = 1,\dots,n$. Since $E[X_i + A_i] = E[X_i] + A_i$ we obtain:

```
$$\text{Var}[(X + A)_i] = \text{Var}[X_i + A_i]$$

= E[(X_i + A_i - E[X_i + A_i])^2] = E[(X_i - E[X_i])^2]$$
```

and

```
$$\text{Cov}[X + A]_{ij} = E[(X_i + A_i - E[X_i + A_i])(X_j + A_j - E[X_j + A_j])]$$

= E[(X_i - E[X_i])(X_j - E[X_j])]$$

= \text{Cov}[X]_{ij} \quad \quad \quad (C.3.2)$$
```

## C.4 Conditional mean and covariance of normal distributions

$X = [X_1, X_2]^T$ be distributed as $N_p(\mu, \Sigma)$ with $\mu = [\mu_1, \mu_2]^T$ and $\Sigma = \begin{bmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{bmatrix}$ and $|\Sigma_{21}| > 0$.

We will prove that the conditional distribution of $X_1$, given that $X_2 = x_2$, is normal and has:

Mean = $\mu_e s_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$, and covariance = $\Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$.
Let the inverse of $\Sigma$ be $\Sigma^{-1}$, where

```
$$\Sigma^{-1} = \begin{bmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{bmatrix}^{-1} \quad (C.4.1)$$
```

So $\Sigma^{-1} = \begin{bmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{bmatrix}^{-1} = \begin{bmatrix} I_q & 0 \\ 0 & I_{p-q} \end{bmatrix} \quad (C.4.2)$

Multiplying out these identities yields the following equations:

```
$$\Sigma_{11} + \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21} = I_q \quad (C.4.3)$$

$$\Sigma_{21} + \Sigma_{22}\Sigma_{22}^{-1}\Sigma_{12} = 0 \quad (C.4.4)$$

$$\Sigma_{11}\Sigma_{22}^{-1}\Sigma_{21} + \Sigma_{12} = 0 \quad (C.4.5)$$

$$\Sigma_{21}\Sigma_{22}^{-1}\Sigma_{12} + \Sigma_{22} = 0 \quad (C.4.6)$$
```

Multiplying Eq. (C.4.5) on the left by $\Sigma_{11}^{-1}$ and on the right by $\Sigma_{22}^{-1}$ gives:

```
$$\Sigma_{11}^{-1}\Sigma_{12} = -\Sigma_{12}\Sigma_{22}^{-1} \quad (C.4.7)$$
```

Multiplying Eq. (C.4.3) on the left by $\Sigma_{11}^{-1}$ yields:

```
$$I + \Sigma_{11}^{-1}\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21} = I_q \quad (C.4.8)$$
```

and substituting for $\Sigma_{11}^{-1}\Sigma_{12} = -\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}^{-1}$ from Eq. (C.4.7) into Eq. (C.4.8) gives:

```
$$\Sigma_{11}^{-1} = \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21} \quad (C.4.9)$$
```

The probability density function of $x$ is:

```
$f(x) = (2\pi)^{-p/2}|\Sigma^{-1}|^{1/2}\exp\left\{\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)\right\}$$
```

writing $x, \mu$ and $\Sigma^{-1}$ in their partitioned form gives:

```
$f(x) = (2\pi)^{-p/2}|\Sigma^{-1}|^{1/2}\exp\left[-\frac{1}{2}(x_1-\mu_1)^T\Sigma^{11}(x_1-\mu_1) + 2(x_1-\mu_1)^T\Sigma^{12}(x_2-\mu_2) + (x_2-\mu_2)^T\Sigma^{22}(x_2-\mu_2)\right] \quad (C.4.10)$
```

The conditional distribution of $x_1$ given the value of $x_2$ is thus obtained by dividing this density by the marginal density of $x_2$, and treating $x_2$ as a constant in the resulting expression. The only portion of the resultant that is not constant is the portion involving $x_1$. It can be easily seen that:

```
$f(x_1|x_2) = \exp\left[-\frac{1}{2}(x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + 2(x_2-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)\right]$
```

where the constant of proportionality is obtained using $\int f(x_1|x_2) dx = 1$. If we let $\mathcal{G} = (x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + 2(x_2-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)$ then we obtain:

```
$$\mathcal{G} = (x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + (x_1-\mu_1)^\top\Sigma^{12}(x_2-\mu_2) + (x_2-\mu_1)^\top\Sigma^{21}(x_1-\mu_1)$$

$$\mathcal{G} = \{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\}^\top \times \Sigma^{11}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\} - (x_2-\mu_1)^\top\Sigma^{21}(\Sigma^{12})^{-1}(x_2-\mu_2) \quadquad (C.4.11)$$
```

where, we have used the scalar quantity $\{(x_1-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)\} = (x_2-\mu_2)^\top\Sigma^{21}(x_1-\mu_1)$

Since the last term in Eq. (C.4.11) only involves constants (as far as $f(x_1|x_2)$ is concerned), it follows that:

```
$f(x_1|x_2) = \exp\left[-\frac{1}{2}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\}^\top \times \Sigma^{11}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\}\right]$
```

which is the density of a multivariate distribution that has a mean of $\mu_1 - (\Sigma^{11})^{-1}\Sigma^{12}(x_2)$, from which Eq. (C.4.7) can be expressed as $\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2)$. The covariance matrix is $(\Sigma^{11})^{-1}$, which from Eq. (C.4.9) can be written as $\Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$.

## C.5 Moment generating functions

If $x$ is a random variable with probability distribution $f_x(x)$ then the moment generating function $M_x(t)$ is defined by:

```
$M_x(t) = E[e^{tx}] = \int_{-\infty}^{\infty} e^{tx} f_x(x) dx$
```

We can expand the above expression as:

```
$E[e^{tx}] = E\left[1 + tx + \frac{1}{2}(tx)^2 + \dots\right]$

$M_x(t) = 1 + tE[x] + \frac{1}{2}t^2E[x^2] + \dots \quad (C.S.1)$
```

Now

For $t=0$ we have:

```
$$\frac{d^k M_x(t)}{dt^k}\bigg|_{t=0} = \frac{d^k}{dt^k}E[e^{tx}] = E[x^k] \quad (C.S.2)$$
```

## Moment generating function of a linear function of $x$

If the random variable $y$ is defined as $y=ax+b$ the moment generating function $M_y(t)$ is obtained as:

```
$M_y(t) = M_{ax+b}(t) = E[e^{(ax+b)}] = e^{bt}E[e^{at}]$
```

Therefore:

```
$M_y(t) = e^{bt}M_x(at) \quad (C.S.3)$
```

## Moment generating function of linear combination of random variables

Let $z=x+y$ where $x$ and $y$ are independent random variables. Then

```
$M_z(t) = E[e^{tz}] = E[e^{tx+ty}] = E[e^{tx}]E[e^{ty}]$
```

Since $x$ and $y$ are independent:

```
$E[e^{tx}e^{ty}] = E[e^{tx}]E[e^{ty}] = M_x(t)M_y(t)$
```

More generally if $s_n = \sum_{i=1}^n x_i$ where $x_i, i=1,\dots, n$, are independent variables then:

```
$M_s(t) = \prod_{i=1}^n M_x(t) \quad (C.S.4)$
```

If $x_i, i=1,\dots, n$, are IID then we have

```
$M_n(t) = E\left[\exp\left(t\sum_{i=1}^n x_i)\right] = (E[e^{tx}])^n = (M_x(t))^n \quad (C.S.5)$
```

## D.1 The normal (Gaussian) distribution

Here we describe some properties of the normal distribution. If $x$ comes from a normal distribution, the associated moment generating function, $M_x(t)$, is given by:

```
$M_x(t) = E[e^{tx}]$$
$= \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} exp(tx)exp\left(\frac{(x-\mu)^2}{2\sigma^2}\right)dx$
$= \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} exp\left(-\frac{(x-\mu)^2-2\sigma^2tx}{2\sigma^2}\right)dx$
```

Now completing the square we have:

```
$$\frac{1}{2\sigma^2}\{(x-\mu)^2-2t\sigma^2x\}=\frac{1}{2\sigma^2}\{x^2+\mu^2-2\mu x-2t\sigma^2\}$$

=-\frac{1}{2\sigma^2}\{(x-\sigma^2t-\mu)^2-2\mu t\sigma^2-\sigma^4t^2\}$$

$= \mu t+\frac{\sigma^2t^2}{2}-\frac{1}{2\sigma^2}\{(x-\sigma^2t-\mu)^2$$
```

We thus have:

```
$E[e^{tx}] = \frac{1}{\sigma\sqrt{2\pi}}exp\left(\mu t+\frac{\sigma^2t^2}{2}\right)\int_{x=-\infty}^{x=\infty} exp\left(\frac{(x-\sigma^2t-\mu)^2}{2\sigma^2}\right)dx$
```

Now letting $y=x-\sigma^2t-\mu$, $dx=dy$

```
$E[e^{tx}] = \frac{1}{\sigma\sqrt{2\pi}}exp\left(\mu t+\frac{\sigma^2t^2}{2}\right)\int_{y=-\infty}^{y=\infty} exp\left(-\frac{y^2}{2\sigma^2}\right)dy$

$= \frac{1}{\sigma\sqrt{2\pi}}\sigma\sqrt{2\pi}exp\left(\mu t+\frac{\sigma^2t^2}{2}\right)$

$=exp\left(\mu t+\frac{\sigma^2t^2}{2}\right)$
```
