# 3.3.3 Student’s $t$-distribution

If $S(\mu, \nu)$ represents the Student’s $t$-distribution with mean $\mu$ and number of degrees of freedom $\nu$, then $X \sim S(0, \nu)$ can be generated as follows:

```
$$\X \sim \frac{Z}{\sqrt{Y/\nu}} \quad (3.3.15)$
```

where $Z \sim N(0, 1)$, and $Y \sim \chi_{
u}^2$. The variance of $X$ is:

```
$$\E[X^2] = \frac{\nu}{\nu-2}$
```

Variates $X'$ from a Student’s $t$-distribution having $\nu$ degrees of freedom mean $\mu$ and variance $s$ can be generated by modifying Eq. (3.3.15) as follows:

```
$$\X' \sim \mu + \frac{s^{1/2}}{\sqrt{Y/(\nu-2)}} \frac{\sqrt{Y}}{\nu} \quad (3.3.16)$
```

The probability density function, $f(x)$, for $X'$:

```
$$\f(x) = \frac{\Gamma((\nu+1)/2)(\nu-2)^{-1/2}s^{-1/2}}{\pi^{1/2}\Gamma(\nu/2)} \left[ 1 + \frac{(x-\mu)^2}{s(\nu-2)} \right]^{-(-
u+1)/2} \quad (3.3.17)$
```

where $\nu > 2$.
