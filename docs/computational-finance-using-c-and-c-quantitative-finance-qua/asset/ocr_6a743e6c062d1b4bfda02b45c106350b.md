The results were obtained using a binomial lattice and the analytic formula (Johnson 1987) and Stulz (1982). The time to maturity of the option is varied from 0.1 years to 8 years. The parameters are $E = 44.0, S_1 = 50.0, S_2 = 50.0, r = 0.1, \sigma_1 = 0.2, \sigma_2 = 0.2, q_1 = q_2 = 0, ho = 0.5, n_{steps} = 50$.

Then, Following Schulz (1982) and Johnson (1987), we have:

> $c_{\max} = S_1 N_2(d_1(S_1, E, \sigma_1^2), d_1'(S_1, S_2, \sigma_2^2), ho_1)\\n + S_2 N_2(d_2(S_2, E, \sigma_2^2), d_2'(S_1, S_2, \sigma_1^2), ho_2)\\n - E e^{-rt}[1 - N_2(-d_2(S_1, E, \sigma_1^2), -d_2(S_2, E, \sigma_2^2), ho)] \quad (6.5.5)$

and

> $c_{\min} = S_1 N_2(d_1(S_1, E, \sigma_1^2), -d_1'(S_1, S_2, \sigma_2^2), -ho_1)\\n + S_2 N_2(d_2(S_2, E, \sigma_2^2), -d_2'(S_1, S_2, \sigma_1^2), -ho_2)\\n - E e^{-rt}N_2(-d_2(S_1, E, \sigma_1^2), -d_2(S_2, E, \sigma_2^2), ho) \quad (6.5.6)$

where $N(a, b, \rho)$ is the bivariate cumulative function. It gives the probability, in a standardized bivariate normal distribution, where the variables $x_1$ and $x_2$ satisfy $x_1 \le a$ and $x_2 \le b$ when the correlation coefficient between $x_1$ and $x_3$ is $ho$—the value is computed using the routine `cum_norm2`. The other symbols are defined as follows:

$$d_1(S_i, E, \sigma_i^2) = \frac{\log(S_i/E) + (r + \sigma_i^2/2)t}{\sigma_i\sqrt{t}}, \quad i=1, 2$$
$$d_2(S_i, E, \sigma_i^2) = \frac{\log(S_i/E) + (r - \sigma_i^2/2)t}{\sigma_i\sqrt{t}}, \quad i=2$$
