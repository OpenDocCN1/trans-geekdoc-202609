## H.9 Proof of Eq.

We use Eq. (H.1.6) to compute $\frac{\partial P}{\partial x}$, where $P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x)$ is denoted by P.

Let $\Theta = (2b-x+vt)/(\sigma\sqrt{t})$ we obtain:

```
$$\frac{\partial P}{\partial x} = \exp\left(\frac{2vb}{\sigma^2}\right)\frac{\partial}{\partial x}[N_1(\Theta)]\n= \exp\left(\frac{2vb}{\sigma^2}\right)\frac{\partial}{\partial \Theta}[N_1(\Theta)]\frac{\partial \Theta}{\partial x}\n= -\exp\left(\frac{2vb}{\sigma^2}\right)\frac{1}{\sigma\sqrt{\pi}}n(\Theta)\n= \frac{1}{\sigma\sqrt{2\pi t}}\exp\left(\frac{2vb}{\sigma^2}\right)\exp\left(\frac{(2b-x+vt)^2}{2\sigma^2t}\right) \quad (H.9.1)$
```

Now since the probability $P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x)$ increases as we have:

```
$P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x) - P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x+\Delta x) = -\frac{\partial P}{\partial x}\Delta x \quad (H.9.2)$
```

and also:

```
$P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x) - P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x+\Delta x) \sim p(m_t^{\bar{X}} \le b, \bar{X}_t = x)\Delta x \quad (H.9.3)$
```

where $p(m_t^{\bar{X}} \le b, \bar{X}_t = x)$ is the probability density function of $P(m_t^{\bar{X}} \le b, \bar{X}_t \ge x)$, and $\Delta x \to 0$.

Combining Eqs. (H.9.2) and (H.9.3) we thus obtain

```
$p(m_t^{\bar{X}} \le b, \bar{X}_t = x) = -\frac{\partial P}{\partial x}\Delta x$
```

So,

```
$p(m_t^{\bar{X}} \le b, \bar{X}_t = x) = \frac{1}{\sigma\sqrt{2\pi t}}\exp\left(\frac{2vb}{\sigma^2}\right)\exp\left(-\frac{(2b-x+vt)^2}{2\sigma^2t}\right)$
```

which means that:

```
$p(\{m_{t_1,t}}^{\bar{X}} \leqslant b, \bar{X}_t)|\bar{X}_0) = \frac{1}{\sqrt{2\pi}} exp\left(\frac{2vb}{\sigma^2}\right)\n\times \exp\left(\frac{(2b-\bar{X}_t+vt)^2}{2\sigma^2}\right) \quad (H.9.4)$
```

where as usual we take $\bar{X}_0=0$. So Eq. (H.9.4) gives the probability density for the Brownian motion which goes through the points $\bar{X}_0$ and $\bar{X}_t$ and has a minimum value which is less than or equal to $b$.

Instead of considering the complete path of $\bar{X}_t$ from $\bar{X}_0$ we can move the origin to the point $\bar{X}_{t_1}$, where $t_1 \leqslant t$. Substituting into Eq. (H.9.4) we then obtain:

```
$p(\{m_{t_1,t}}^{\bar{X}} \leqslant b, \bar{X}_t)|\bar{X}_{t_1}) = \frac{1}{\sqrt{2\pi(t-t_1)}} exp\left(\frac{2v(b-\bar{X}_t)}{\sigma^2}\right)\n\times \exp\left(\frac{(2(b-\bar{X}_{t_1})-(\bar{X}_t-\bar{X}_{t_1})+v(t-t_1))^2}{2\sigma^2(t-t_1)}\right)\n= \frac{1}{\sqrt{2\pi(t-t_1)}} exp\left(\frac{2v(b-\bar{X}_t)}{\sigma^2}\right)\n\times \exp\left(\frac{(2b-\bar{X}_t-\bar{X}_t+v(t-t_1))^2}{2\sigma^2(t-t_1)}\right)$
```

which can be re-expressed as:

```
$p(\{m_{t_1,t_2}}^{\bar{X}} \leqslant b, \bar{X}_{t_2})|\bar{X}_{t_1}) = \frac{1}{\sqrt{2\pi\Delta t}} exp\left(\frac{2v(b-\bar{X}_{t_2})}{\sigma^2}\right)\n\times \exp\left(\frac{(\bar{X}_{t_1}+\bar{X}_{t_2}-2b-v\Delta t)^2}{2\sigma^2\Delta t}\right)$
```

where $t_2 \geqslant t_1$ and $\Delta t = t_2-t_1$.

## Appendix I: The Feynman-Kac formula

The Feynman-Kac formula provides a link between stochastic processes and partial differential equations, which we will now illustrate.

In the risk neutral measure the equation followed by the asset price is:

$dS = rSdt + \sigma S dW \quad (I.1.1)$

and that of the money account:
$dB = Br dt \quad (I.1.2)$

If $f(S,t)$ is the value of a derivative then using Ito's lemma we have

$df = \left[\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}\right] dS + S\frac{\partial f}{\partial S} dW \quad (I.1.3)$

Since $f$ is tradable we know that the process $(f)$ must be a martingale in the risk neutral measure, and therefore have zero drift (see Eq. (I.1.4)):

```
$d\left(\frac{X_1}{X_2}\right) = \left(\frac{dX_1}{X_2} - \frac{X_1 dX_2}{X_2^2}\right) + E\left(\frac{dX_2}{X_2}\right)\frac{dX_1}{X_1} \quad (I.1.4)$
```

and rewrite Eqs. (I.1.2) and (I.1.3) as:

$dX_1 = \mu_1 dt + \sigma_1 dW$
$dX_2 = \mu_2 dt$

where $d\left(\frac{X_1}{X_2}\right) = d\left(\frac{f}{B}\right), \quad \mu_1 = \left[\frac{\partial f}{\partial t} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}\right], \quad \sigma_1 = S\frac{\partial f}{\partial S}, \quad X_1 = f, \quad X_2 = B, \quad \mu_2 = r$

Evaluating Eq. (I.1.4) we obtain:

```
$E\left[\left(\frac{dX_2}{X_2}\right)\frac{dX_2}{X_2}\right] = E\left[\mu_2^2 dt\right] \to 0$
$E\left[\left(\frac{dX_1}{X_2}\right)\frac{dX_2}{X_1}\right] = E\left[\left(\frac{\mu_1 dt + \sigma_1 dW}{X_2}\right)\left(\frac{\mu_2 dt}{X_1}\right)\right] \to 0$
```

and therefore:

```
d\left(\frac{X_1}{X_2}\right)=\left(\frac{X_1}{X_2}\right)\left(\frac{\mu_1 dt+\sigma_1 dW}{X_1}-\frac{\mu_2 dt}{X_2}\right)=\left(\frac{X_1}{X_2}\right)\left(\frac{\mu_1}{X_1}-\frac{\mu_2}{X_2}\right)dt+\left(\frac{X_1}{X_2}\right)\frac{\sigma_1 dW}{X_1}\quad (I.1.5)
```

Since $\frac{X_1}{X_2}$ is a martingale, the drift term in Eq. (I.1.5) is zero:

```
\frac{\mu_1}{X_1}-\frac{\mu_2}{X_2}=0 \quad (I.1.6)
```

Therefore, substituting for $\mu_1$ and $\mu_2$ in Eq. (I.1.6) we obtain:

```
\frac{\partial f}{\partial t}+rS\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}=0 \quad (I.1.7)
```

or

```
\frac{\partial f}{\partial t}+rS\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}=rf \quad (I.1.8)
```

which is the Black-Scholes partial equation, which we derived in Chapter 4. In general if an asset follows the process:

```
$dS=\mu dt+\sigma dW \quad (I.1.9)
```

then the price of a derivative $f(S,t)$ obeys partial equation:

```
\frac{\partial f}{\partial t}+\mu S\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}=0 \quad (I.1.10)
```

or

```
\frac{\partial f}{\partial t}+rS\frac{\partial f}{\partial S}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}=rf \quad (I.1.11)
```
