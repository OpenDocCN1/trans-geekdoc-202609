This gives Ito's formula

```
$d\phi = (\frac{\partial \phi}{\partial t} + a\frac{\partial \phi}{\partial X} + \frac{b^2}{2}\frac{\partial^2 \phi}{\partial X^2})dt + \frac{\partial \phi}{\partial X}b\dW$ (2.3.5)
```

In particular we are considering the Geometric Brownian process:
dS = \mu S dt + \sigma dW

where $\mu$ and $\sigma$ are constants, substituting $X=S, a=\mu S,$ and $b=\sigma S$ into Eq. (2.3.5) yields:

```
$d\phi = (\frac{\partial \phi}{\partial t} + \mu S\frac{\partial \phi}{\partial S} + \frac{\sigma^2}{2}\frac{\partial^2 \phi}{\partial S^2})dt + \frac{\partial \phi}{\partial S}\sigma dW$ (2.3.6)
```

Equation (2.3.6) describes the change in value of a function $\phi(S,t)$ over the time interval dr, where the stochastic S follows GBM. This result has many important applications in the pricing of financial derivatives. Here the function $\phi(S,t)$ is taken as the price of a financial derivative, $f(S,t)$, that depends on the value of an underlying asset $S$, which is assumed to follow GBM. In Chapter 4 we use Eq. (2.3.3) to derive the process followed by $\phi = \log(S_t)$. We have:

```
$$\frac{\partial \log(S_t)}{\partial t} = 0$\n$\$\frac{\partial \log(S_t)}{\partial S_t} = \frac{1}{S_t}, \quad \fracfrac{\partial^2 \log(S_t)}{\partial S_t^2} = -\frac{1}{S_t^2}$
```

So

```
$d(\log(S_t)) = \nu dt + \sigma dW \quad \text{where } \nu = \mu - \frac{\sigma^2}{2}$ (2.3.7)
```

Integrating Eq. (2.3.7) yields

```
$$\int_{t_0}^T d(\log(S_t)) = \int_{t_0}^T \nu dt + \int_{t_0}^T \sigma dW_t$$
```

so

```
$$\log(S_T) - \log(S_{t_0}) = \nu T + \sigma W_T$ (2.3.8)
```

where we have used $t_0 = 0$ and $W_0 = 0$.
