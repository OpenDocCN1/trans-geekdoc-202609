# 2.12.2 Ito's isometry

The expected value of the integral of the well-behaved function $f(W_t, t)$ satisfies:

PROOF. We use the following approximation:

```
$\int_{s=t_a}^{t_b} f(W_s, s) dW_s = \sum_{i=0}^{n-1} f(W_{t_i}, t_i)(W_{t_{i+1}} - W_{t_i})$
```

where $a < t_0 < t_1 < \dots < t_n < t_b$ and $t_{i+1} - t_i = dr$. Thus the integral on the left-hand side of Eq. is

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j)\{W_{t_{i+1}} - W_{t_i}\}\{W_{t_{j+1}} - W_{t_j}\} \quad (2.12.2.3)
```

Taking expectations of Eq. (2.12.2.3) we obtain:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j)\{W_{t_{i+1}} - W_{t_i}\}\{W_{t_{j+1}} - W_{t_j}\} \quad (2.12.2.4)
```

which means:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right]$
```

```
$= \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j) E[\{W_{t_{i+1}} - W_{t_i}\}\{W_{t_{j+1}} - W_{t_j}\] \ \quad (2.12.5.5)
```

From the Brownian motion property (iii) in Section 2.1 we have:

```
$E[\{W_{t_{i+1}} - W_{t_i}\}\{W_{t_{j+1}} - W_{t_j}\}] = 0 \quad \text{when } i \neq j \text{ and when } i = j$
```

Therefore Eq. (2.12.5.5) can be rewritten as:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right] = \sum_{i=0}^{n-1} \{f(W_{t_i}, t_i)\}^2 dt$
```

which means:

```
$E\left[\left(\int_{s=t_a}^{t_b} f(W_s, s) dW_s\right)^2\right] = E\left[\int_{s=t_a}^{t_b} \{f(W_s, s)\}^2 ds\right]$
```
