$\Phi = X_t Y_t$.

From Ito's formula we obtain:

$d\Phi = \frac{\partial \Phi}{\partial X_t} dX_t + E\left[\frac{\partial \Phi}{\partial Y_t} dY_t + \frac{1}{2} \frac{\partial^2 \Phi}{\partial X_t \partial Y_t} dX_t dY_t + \frac{1}{2} \frac{\partial^2 \Phi}{\partial Y_t^2} dY_t dX_t\right]$

Now

$\frac{\partial^2 \Phi}{\partial X_t \partial Y_t} = Y_t + \frac{\partial^2 \Phi}{\partial Y_t \partial X_t} = 1, \quad \frac{\partial \Phi}{\partial X_t} = Y_t \quad \text{and} \quad \frac{\partial \Phi}{\partial Y_t} = X_t$

We thus obtain:

$d\Phi = Y_t dX_t + X_t dY_t + E[dX_t dY_t]$

Using

$\int_{s=0}^t d(X_t, Y_t) = \int_{s=0}^t Y_s dX_s + \int_{s=0}^t X_s dY_s + \int_{s=0}^t E[dX_s dY_s]$

$X_t Y_t - X_0 Y_0 = \int_{s=0}^t Y_s dX_s + \int_{s=0}^t X_s dY_s + \int_{s=0}^t E[dX_s dY_s]$
