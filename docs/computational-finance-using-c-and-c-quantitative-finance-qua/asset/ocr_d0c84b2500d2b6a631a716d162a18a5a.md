# European options

$f(b \le X^{\min}, X)$

$=-\Omega \sqrt{\frac{2}{\pi}} \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)\exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2\tau}\right) \quad (4.5.6)$

$r$ is the free risk rate and $q$ is the continuous dividend yield. A European down and out barrier option with maturity $\tau$ and a barrier at $X=B$ will cease to exist (become worthless) if at time $X_s \le B$, for $t \le s \le T$. The probability density function that the barrier option will continue to exist at time $T$ if the end point is $X$ is therefore:

$f(X > B) =-\sqrt{\frac{2}{\pi}} \int_{b=S\exp(b)}^{b=X} \Omega \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)\\times \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2\tau}\right)db \quad \quad (4.5.7)$

or

$f(X > B) =-\sqrt{\frac{2}{\pi}} \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2\tau}\right)\\times \int_{b=\log(B/S)}^{b=X} \Omega \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)db \quad (4.5.8)$

where we have integrated over all possible values of $b$, $B < b < X$ that keep the option alive. Recalling that:

> $-\int_{b=\log(B/S)}^{b=X} \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)db\\\-\int_{b=\log(B/S)}^{b=X} \exp\left(\frac{(X-2b)}{\sigma^3\tau^{3/2}}\right)\exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)db$

and noting that:

> $$\frac{\partial}{\partial b} \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)=\exp\left(\frac{2(X-2b)}{\sigma^2\tau}\right)\exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)$

we have:

> $-\int_{b=\log(B/S)}^{b=X} \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)db\\\-\exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right)\times_{b=\log(B/S)}^{b=X} = 1-\exp\left(\frac{2\log(B/S)(X-\\log(B/S))}{\sigma^2\tau}\right)$

So we have:

> $f(X > B) =-\frac{1}{\sigma\tau\sqrt{\frac{2}{\pi}}}} \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2\tau}\right)\\times \left\{1-\exp\left(\frac{2\log(B/S)(X-\\log(B/S))}{\sigma^2\tau}\right)\right\\}$
