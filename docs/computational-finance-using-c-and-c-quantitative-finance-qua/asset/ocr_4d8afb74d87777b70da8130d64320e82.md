void hist_vol(double *sigma, double *err, double data[], long n, double dt, long *ifail) {
    // Input parameters:
    data - the data, which consists of n asset prices
    - the number of data points
    dt - the (constant) time spacing between the data points (years)
    Output parameters:
    sigma - the computed historical volatility
    err - the standard error in the volatility estimate sigma
    iflag - an error indicator
}

#define DATA(i) data(i-1)

double mean=0.0,sum=0.0;
double temp,tn;

for(i = 2; i <= n; i++) {
    mean += log(DATA(i))-log(DATA(i-1));
}
mean = mean/(double)(n-1);

for(i = 2; i <= n; i++) {
    temp = log(DATA(i))-log(DATA(i-1));
    sum += (temp-mean)*(temp-mean);
}
sigma = sqrt(sum/dt);
tn = (double)dt*(n-1);
er = sigma/sqrt(tn);
    return;
}

# Implied volatility

The implied volatility of a European option is the volatility that, when substituted into the Black-Scholes equation, yields the market value quoted for the same option. In general the implied volatility will depend on the time to expiry of the option and the ratio of the current asset price to the strike—this is known as the volatility smile. These values are usually stored in a multidimensional volatility surface, and the volatility for pricing a given option obtained via multidimensional interpolation.

The routine provided in Code excerpt 4.3 uses Newton's method to calculate the implied volatility for a European option from its market price. We will illustrate this technique for a European call with market value opt_value. The implied volatility, $\sigma$, is then that value which satisfies:

$K(\sigma) = c(S, E, \tau, \sigma) - opt\_value = 0$

where $c(S, E, \tau, \sigma)$ represents the value of the European call and the other symbols have their usual meaning.
