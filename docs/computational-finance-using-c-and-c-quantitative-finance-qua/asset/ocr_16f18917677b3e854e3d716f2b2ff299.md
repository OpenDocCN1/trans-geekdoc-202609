# General payment timing

For the general case, in which the coupon date does not correspond to the end of its associated forward rate, we use the result from Eq. (7.2.43) and that

```
$dW^k = \left(\frac{\mu_k}{\sigma_k}ight)dt + dW^i, \ i \neq k$ (7.2.33)
```

Equation (7.2.33) states that Brownian motion $W^i$ under numeraire $DF(t, t_i)$ can be transformed into Brownian motion $W^k$ under numeraire $DF(t, t_k)$ by the addition of a drift term $\mu_k, W_{t_0}^k = W_{t_0}^i = 0$ if we obtain:

```
$W_t^k = (t-t_0)\left(\frac{\mu_k}{\sigma_k}ight) + W_t^i$ (7.2.34)
```

and in Eq. (7.2.30)\n$\sigma_t^k = (t-t_0)\mu_k + \sigma_k W_t^i$

A constant $\mu_k$ can be achieved by freezing the forward rates that make up $\mu_k$; for example, $F(t, t_{k-1}, t_k) 	o F(t, t_{k-1}, t_k)$; see Section 7.2.3 for more details concerning $\mu_k$.

This means that $F(t, t_{k-1}, t_k)$ follows the process:

```
$d(F(t, t_{k-1}, t_k)) = F(t, t_{k-1}, t_k)\mu_k dt + F(t, t_k)\sigma_k dW^i$
```

The above equation can be solved by GBM with modifying Eq. (7.2.30):

```
$F(t_0, t_{k-1}, t_k)$
```

```
$= F(t_0, t_{k-1}) \exp\left(\frac{(t-t_0)\mu_k^2}{2} + \sigma_k W_t^iight)$ (7.2.35)
```

As the coupon payment, the $t_i$ value of coupon payment at time $t_i$ is:

```
$V_{t_0} = DF(t_0, t_i)E^{Q_t}\left[\frac{F(t_{k-1}, t_{k-1}, t_k)}{DF(t_i, t_i)}ight] 	au P$
```

which since $DF(t_i, t_i) = 1$ becomes

```
$V_{t_0} = DF(t_0, t_i)E^{Q_t}[F(t_{k-1}, t_{k-1}, t_k)]	au P$ (7.2.36)
```
