# Estimating the hazard rate from market observables

From Eq. (7.2.10) we know the time $t$ forward rate between times $T_1$ and $T_2$ is given:

```
$$\mathbf{F}(t, T_1, T_2) = \frac{1}{T_2 - T_1} \left\{ \frac{DF(t, T_1)}{DF(t, T_2)} \right\ \quad (7.4.11)$
```

where $DF(t, T_1)$ and $DF(t, T_2)$ are the prices of the nondefaultable zero coupon bonds with maturities $T_1 = T$ and $T_2 = T + \Delta$, respectively.

Letting $T_1 = T$ and $T_2 = T + \Delta$ we obtain:

```
$$\mathbf{F}(t, T, T + \Delta) = \frac{1}{\Delta} \left\{ \frac{DF(t, T)}{DF(t, T + \Delta)} \right\ \quad (7.4.12)$
```

which can be re-expressed as

```
$$\frac{DF(t, T + \Delta) - DF(t, T)}{\Delta} = \frac{1}{DF(t, T + \Delta)} \quad (7.4.13)$
```

If $\Delta \to 0$ then $F(t, T + \Delta) \to f(t, T)$ and from Eq. (7.4.13) we obtain:

```
$$\f(t, T) = \frac{\frac{\partial DF(t, T)}{\partial T}}{\ln(DF(t, T))} = -\frac{\partial \ln DF(t, T)}{\partial T} \quad (7.4.14)$
```

Using Eq. (7.4.14) the instantaneous forward rate computed using nondefaultable zero coupon bonds is:

```
$$\f(t, T) = \frac{\ln(DF(t, T))}{\partial T} \quad (7.4.15)$
```

and the corresponding instantaneous forward rate computed from defaultable zero coupon bonds is:

```
$$\tilde{f}(t, T) = \frac{\ln(\widetilde{DF}(t, T))}{\partial T} \quad (7.4.16)$
```

Taking the survival probability $S(t, T)$ to be the ratio of the prices of defaultable and nondefaultable zero coupon bonds:

```
$$\S(t, T) = \frac{\widetilde{DF}(t, T)}{DF(t, T)} \quad (7.4.17)$
```

Now from Eqs. (7.4.15) and (7.4.16) we have:

```
$$\tilde{f}(t, T) - f(t, T) = \frac{\ln(\widetilde{DF}(t, T)) - DF(t, T))}{\partial T} = -\frac{\partial}{\partial T} \ln \left{\frac{\widetilde{DF}(t, T)}{DF(t, T)} \right\} \quad (7.4.18)$
```
