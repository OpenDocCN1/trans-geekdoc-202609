The discretized version of this equation is:

```
$$\Delta f = \Delta t\left(\mu S\frac{\partial f}{\partial S},\frac{\partial f}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\right)+\frac{\partial f}{\partial S}\sigma\Delta W, \Delta W \sim N(0, \Delta t)$.$\n(4.4.1)
```

where the time interval is now $\Delta t$ and the change in derivative value is $\Delta f$. If we assume that the asset price, S, follows GBM we also have:

```
$$\Delta S = \mu S\Delta t+\sigma\Delta W, \Delta W \sim N(0, \Delta t)$.$\n(4.4.2)
```

where $\mu$ is the constant drift and the diffusion of the other symbols is as before. Let us now consider a portfolio consisting of $-1$ derivative and $\frac{\partial f}{\partial S}$ units of the asset. In other words we go *short* (that is sold) a derivative of an asset and have $\frac{\partial f}{\partial S}$ stocks of the (same) underlying asset. The value of the portfolio, $\Pi$, is therefore:

```
$$\Pi = -f+\frac{\partial f}{\partial S}$.$\nn(4.4.3)
```

and the change, $\Delta\Pi$, in the value of the portfolio over $\Delta t$ is:

```
$$\Delta\Pi = -\Delta f+\frac{\partial f}{\partial S}\Delta S$.$\n(4.4.4)
```

Substituting Eqs. (4.4.1) and (4.4.2) into Eq. (4.4.4) we obtain:

```
$$\Delta\Pi = -\left(\mu S\frac{\partial f}{\partial S},\frac{\partial f}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\right)\Delta t$\n-\sigma\Delta W\frac{\partial f}{\partial S}+\mu S\Delta t+\sigma\Delta W$\n:\. \Delta\Pi = -\mu S\Delta t\frac{\partial f}{\partial S}-\Delta t\frac{\partial f}{\partial t}-\frac{1}{2}\Delta t\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}$\n-\sigma\Delta W\frac{\partial f}{\partial S}+\mu S\Delta t\frac{\partial f}{\partial S}+\sigma\Delta W\frac{\partial f}{\partial S}$.$\n(4.4.5)
```

Cancelling terms we obtain:

```
$$\Delta\Pi = -\Delta t\left(\frac{\partial f}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\right)$.$\n(4.4.6)
```

If this portfolio grows to the risk-free interest rate $r$, we have:

```
$r\Delta t = \Delta\Pi$
```

So we have that:

```
$r\Delta t = -\Delta t\left(\frac{\partial f}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\right)$.$\n(4.4.7)
```

Substituting for $\Pi$, we obtain:

```
$r\Delta t\left(f-S\frac{\partial f}{\partial S}\right) = -\Delta t\left(\frac{\partial f}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\right)$.$\n(4.4.8)
```
