## 5.4 Grid methods for vanilla options

### 5.4.1 Introduction

In Section 5.3 we discussed the use of binomial lattice methods for valuing both European and American options. The lattice methods we have described the advantage that they are fairly easy to implement and can value simple options, such as vanilla puts and calls, reasonably accurately. The use of up and down jump probabilities at the lattice nodes is also an appealing feature, since they are directly to the stochastic process which is being modelled. However, lattice techniques have the following drawbacks:

- They require small time steps to ensure numerical stability
- There is little control over where nodes are located. This can lead to very poor accuracy valuing certain types of options; for example, those with particular asset prices. One method of addressing these limitations is through the use of finite-difference grids. Although the probabilistic interpretation of the binomial lattice has the following advantages:
- There is complete control over the placement of nodes, and their associated grids.
- Fewer times are required to ensure numerical stability.

The Black-Scholes equation for the value of an option $f$ is given by:
$$\frac{\partial f}{\partial t} + (r - q)S\frac{\partial f}{\partial S} + \frac{1}{2}\sigma^2S^2\frac{\partial^2 f}{\partial S^2}=rf$$
We want to solve this over the duration of the option, that is from the current time to maturity $\tau$.

The user also supplies the function `opt_gfd` with the number of time intervals for the grid. When there are $n_t$ time intervals, the grid has $n_t + 1$ uniformly spaced times, $t_i = i\Delta t, i = 0, \dots, n_t$, and the time step is simply:

$$\Delta t = \frac{\tau}{n_t} \quad (5.4.3)$$

#### The finite-difference approximation

The option value corresponding to the grid node $t_i = i\Delta t$ and $S_j = j\Delta S$ will be denoted by $f_{i,j}$. We approximate the partial derivative of $f_{i,j}$ with respect to time simply as:

$$\frac{\partial f}{\partial t} = \frac{f_{i+1,j} - f_{i,j}}{\Delta t} \quad (5.4.4)$$

For the other terms in (5.4.1) we will use the weight, $\Theta_m$, method. This technique involves selecting an appropriate choice for $\Theta_m$ in the range $0 < \Theta_m \le 1$ so that the contribution from node $(i, j)$ is a weighted sum over the values at $(i, j)$ and $(i+1, j)$. For instance, the term $rf|_{i,j}$ in (5.4.1) is approximated as:

```
$$\rf|_{i,j} = r\{\Theta_m f_{i,j} + (1 - \Theta_m)f_{i,j}\ \quad (5.4.5)$
```

and the term $\frac{\partial f}{\partial S}|_{i,j}$ in (5.4.1) is approximated as:

```
$$\frac{\partial f}{\partial S}|_{i,j} = \{\Theta_m \frac{\partial f}{\partial S}|_{i+1,j} + (1 - \Theta_m)\frac{\partial f}{\partial S}|_{i,j}\} \quad (5.4.6)$
```

Using this method we obtain, at node $(i, j)$, the following discretized version of Eq. (5.4.1):

```
$$\frac{f_{i+1,j} - f_{i,j}}{\Delta t} + (r - q)S_j\{\Theta_m f'_{i+1,j} + \Theta_m^* f'_{i,j}\}
n+ \frac{1}{2}\sigma^2 S_j^2\{\Theta_m f''_{i+1,j} + \Theta_m^* f''_{i,j}\} = r\{\Theta_m f_{i+1,j} + \Theta_m^* f_{i,j}\} \quad (5.4.7)$
```
