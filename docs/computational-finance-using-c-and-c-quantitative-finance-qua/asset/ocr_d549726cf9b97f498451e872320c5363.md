# The floating leg

We will now evaluate Eq. (7.2.14). The floating leg coupon payment at time $t_i$
will be denoted by $C_i$ and has value:

```
$C_i = PF(t, t_{i-1}, t_{i-1} + 	au_{t_i})$
```

where

```
$F(t, t_{i-1}, t_{i-1} + 	au_{t_i}) = \left\{ \frac{DF(t, t_{i-1})}{DF(t, t_{i-1} + 	au_{t_i})} - 1 \right\}$
```

From Eq. (7.2.14) we have thus:

```
$FLT(t) = \sum_{i=k+1}^{n} C_i DF(t, t_i)\n= P \sum_{i=k+1}^{n} DF(t, t_i)	au_{t_i} \left\{ \frac{DF(t, t_{i-1})}{DF(t, t_i)} - 1 \right\}$$\n= P \sum_{i=k+1}^{n} \{DF(t, t_{i-1}) - DF(t, t_i)\}\n= P\{DF(t, t_k) - DF(t, t_{k+1}) + DF(t, t_{k+1}) - \dots\n- DF(t, t_i) + DF(t, t_i) - \dots - DF(t, t_n)\}\n= P\{DF(t, t_k) - DF(t, t_n)\}$
```

and so the value of floating leg is

```
$FLT(t) = P\{DF(t, t_k) - DF(t, t_n)\}$, (7.2.15)
```

# The swap rate

The time $t$ swap rate $SR_t$ is the value of the fixed rate $K$ that makes the IRS
zero. Thus, from Eqs. (7.2.12)-(7.2.14):

```
$P\{DF(t, t_k) - DF(t, t_n)\} = PSR_t \sum_{i=k+1}^{n} DF(t, t_i)	au_{t_i}$ (7.2.16)
```

so

```
$SR_t = \frac{DF(t, t_k) - DF(t, t_n)}{\sum_{i=k+1}^{n} DF(t, t_i) \tau_{t_i}}$ (7.2.17)
```

# Amortization

So we have assumed that the principal is fixed and set to the value $P$. We
will now deal with the situation where the principal varies with time according
to the following amortization schedule:

```
$AM_i = P_{i-1} - P_i, \quad i = 0, \dots, n-1$,$ (7.2.18)
```
