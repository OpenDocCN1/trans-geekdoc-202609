# Vega:

$V_c = \frac{\partial c}{\partial\sigma} = V_p = \frac{\partial p}{\partial\sigma} = S\exp(-q\tau)n(d_1)$

$n(x) = \frac{1}{\sqrt{2\pi}} \exp(-x^2/2)$
