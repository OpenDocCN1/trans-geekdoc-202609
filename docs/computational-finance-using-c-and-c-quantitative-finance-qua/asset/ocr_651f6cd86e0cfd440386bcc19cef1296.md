```
c(S, E, \tau) = \exp(-r\tau) \int_{X=\log(E/S)}^{\infty} {\exp(X) - E}f(X)dX \quad (4.4.39)
```

where we have used $S_T = S\exp(rt)$. The lower limit in Eq. (4.4.39) corresponds to $S_T = E$ in Eq. (4.4.37) is found by setting $E = \exp(X)$; this yields the lower limit $X = \log(E/S)$.
The integral in Eq. (4.4.39) is evaluated by splitting it into the two parts:

```
c(S, E, \tau) = I_A - I_B \quad (4.4.40)
```

where

```
I_A = \frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \exp(X) \exp\left( -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX \quad (4.4.41)
```

and

```
I_B = \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \exp\left( -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX \quad (4.4.42)
```

To evaluate these integrals we make use of the fact that the cumulative normal function $N_1(x)$ is:

```
N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{u=-\infty}^{x} \exp\left( -\frac{u^2}{2} \right) du
```

By symmetry we have $N_1(-x) = 1 - N_1(x)$
We will first consider $I_B$, which is the easier of the integrals.

```
I_B = \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=-\infty}^{\infty} \exp\left( -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX
```

If we use $\frac{X-(r-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ then $dX = \sigma\sqrt{\tau} du.

```
I_B = \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{u=k_2}^{\infty} \exp\left( -\frac{u^2}{2} \right) du
```

where the lower integration limit is $k_2 = \frac{\log(E/S)-(r-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
We therefore have:

```
I_B = E\exp(-r\tau)N_1(-k_2) \quad (4.4.43)
```
