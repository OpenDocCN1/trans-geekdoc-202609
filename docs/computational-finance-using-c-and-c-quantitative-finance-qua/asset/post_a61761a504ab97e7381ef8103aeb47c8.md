```
$C_3 = \frac{\Theta_m(r-q)j\Delta t}{2} + \frac{\Theta_m^*\sigma^2 j^2\Delta t}{2}$
```

Since we are solving the equation backwards in time and we determine the option values at time index $i$ from the known option values $(f_{i+1,j+1}, f_{i+1,j}$ and $f_{i+1,j-1})$ at time index $i+1$. This can be achieved by rearranging Eq. (5.4.13) as follows

```
$a_j f_{i,j-1}+b_j f_{i,j}+c_j f_{i,j+1}=R_{i+1,j}$
```

where the right-hand side, $R_{i+1,j}$, is:

```
$R_{i+1,j}=\tilde{a}_j f_{i+1,j-1}+\tilde{b}_j f_{i+1,j}+\tilde{c}_j f_{i+1,j+1}$
```

The six coefficients are:

```
$a_j=(1-\Theta_m)\frac{\Delta t}{2}\{(r-q)j-\sigma^2 j^2\}$
$b_j=(1-\Theta_m)\Delta t\{r+\sigma^2 j^2\}$
$c_j=-(1-\Theta_m)\frac{\Delta t}{2}\{(r-q)j+\sigma^2 j^2\}$
$\tilde{a}_j=-\Theta_m\frac{\Delta t}{2}\{(r-q)j\}$
$\tilde{b}_j=1-\Theta_m\frac{\Delta t}{2}\{r+\sigma^2 j^2\}$
$\tilde{c}_j=\Theta_m\frac{\Delta t}{2}\{(r-q)j+\sigma^2 j^2\}$
```

Before we solve Eq. (5.4.14), we will briefly consider its characteristics for different values of the weight parameter $\Theta_m$.

When $\Theta_m = 1$ the values of the coefficients in Eq. (5.4.14) are $a_j = c_j = 0$, and $b_j = 1$. This means that Eq. (5.4.14) reduces to:

```
$f_{i,j} = \tilde{a}_j f_{i+1,j-1} + b_j f_{i+1,j} + \tilde{c}_j f_{i+1,j+1}$
```

This is the explicit method, and it can be seen that the unknown option value $f_{i,j}$ at grid $(i,j)$ is a weighted sum of the (known) option values $f_{i+1,j-1}, f_{i+1,j}, f_{i+1,j+1}$. This is the simplest situation to deal with and actually carries poor numerical properties and requires a very small step size to obtain accurate results; see Smith (1985).

When $\Theta_m \neq 1$, the unknown option value $f_{i,j}$ depends not only on the known values $f_{i+1,j-1}, f_{i+1,j}, f_{i+1,j+1}$ (as in the explicit method), but also on the unknown option values $f_{i+1,j-1}$ and $f_{i+1,j+1}$. It is now necessary to solve a system of simultaneous equations in order to compute the value $f_{i,j}$. This is therefore called an *implicit method*; see Smith (1985).

The implicit $\Theta_m = 0$ is also called the *fully implicit method*, since the new unknown value $f_{i,j}$ only depends on the neighboring values $f_{i+1,j-1}, f_{i+1,j+1}$, at time step $i+1$. This can be obtained by substituting $\tilde{a}_j = \tilde{c}_j$ and $b_j = 1$, which means that Eq. (5.4.14) reduces to:

```
$a_j f_{i,j-1} + b_j f_{i,j} + c_j f_{i,j+1} = f_{i+1,j}$
```

The implicit $\Theta_m = 0.5$ is also termed the Crank-Nicolson method. This method, first used by John and Nicolson (1947), computes $f_{i,j}$ by giving equal weight to the contributions from time step $i+1$ and time step $i$. Substituting $\Theta_m = 0.5$ in Eq. (5.4.16) to Eq. (5.4.21) we obtain Crank-Nicolson coefficients:

```
$a_j = -\frac{\Delta t}{4}\{(r-q)j - \sigma^2 j^2\}$
$b_j = 1 + \frac{\Delta t}{2}\{r + \sigma^2 j^2\}$
$\tilde{b}_j = 1 - \frac{\Delta t}{2}\{r + \sigma^2 j^2\}$
$c_j = -\tilde{c}_j = \frac{\Delta t}{4}\{(r-q)j + \sigma^2 j^2\}$
```

We notice that we are solving backwards in time, but time index in the forward direction, our values of $\Theta_m$ corresponding to implicit and explicit are different from normally used. For example, in Smith (1985) $\Theta_m = 0$ is the explicit method and $\Theta_m = 1$ is the implicit method; the Crank-Nicolson method is still $\Theta_m = 0.5$.

## The boundary conditions

In order to solve Eq. (5.4.14) at instant $i\Delta t$ we need to obtain the values at: the upper asset boundary, the lower asset boundary, and initial values specified at option maturity. Here we calculate boundary values using the time independent payoff $p_j$, at the $j$th asset index within the grid. If $E$ is the strike price then vanilla call options have:

- $p_j = \max(j\Delta S - E, 0)$, for $j = 0, \dots, n_s-1$

and vanilla put options have payoffs:

- $p_j = \max(E - j\Delta S, 0)$, for $j = 0, \dots, n_s-1$

### Upper asset boundary

At the upper boundary $j = n_s-1$ and $(n_s-1)\Delta S = S_{max}$; we note for the grid to be useful we require $S_{max} > E$. Here assume $S_{max} > E$ and for call options:

- $p_{n_s-1} = S_{max} - E$

and for put options:

- $p_{n_s-1} = 0$

The option value at the upper boundary, denoted by $f_{BU}$, is set to $p_{n_s-1}$, and we have $f_{i,n_s-1} = f_{BU}$, for $i = 0, \dots, n_t$.

### Lower asset boundary

At the lower boundary $j = 0$, the value of $j\Delta S$ is zero. So for call options:

- $p_0 = 0$

and for put options:

- $p_0 = E$

The option value at the lower boundary, denoted by $f_{BL}$, is set to $p_0$, and we have $f_{i,0} = f_{BL}$, for $i = 0, \dots, n_t$.

### Boundary values at option maturity

At option maturity $(i = n_t)$ the initial boundary values are the previously mentioned. If $E$ is the strike price then vanilla call options have:

- $f_{n_t,j} = \max(j\Delta S - E, 0)$, for $j = 0, \dots, n_s-1$

and vanilla put options have:

- $f_{n_t,j} = \max(E - j\Delta S, 0)$, for $j = 0, \dots, n_s-1$

## Computation of the options at a given time instant

Having found the option boundary we are now in a position to solve Eq. (5.4.14) at time instant $t_i = i\Delta t$. First we note that $f_{i,0} = f_{BL}$ and $f_{i,n_s-1} = f_{BU}$. Eq. (5.4.14) needs to be solved for values of the asset index $j$ in the range $1$ to $j = n_s-2$. We now deal with the following situations:

- Case 1: $j = 1$, the asset line just above the lower boundary
- Case 2: $j = n_s-2$, the asset line just below the upper boundary
- Case 3: all other asset grid lines not included in Case 1 or Case 2
