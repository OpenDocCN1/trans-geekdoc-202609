Having the LU decomposition we can now solve the lower tri-angular system Ly = R using forward elimination; this is shown in Code-excerpt 5.15.

In code 5.15 we make use of the two right-hand side arrays: the rhs which is used to store the elements of the array R, and the array work which is both used as workspace and to store the computed solution vector y. As previously mentioned the subdiagonal elements of L are given by l[j] = a[j]/u[j-1]. This is that in Code 5.15, the line:
