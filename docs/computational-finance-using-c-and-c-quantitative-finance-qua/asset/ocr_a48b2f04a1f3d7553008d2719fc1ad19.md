# Appendix B: Barrier option integrals

Substituting for $f(X < B)$ we have $c_{uo} = I_A + I_B$ where:

```
$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}}} \int_{\log(E/S)}^{\log(B/S)} \{S\exp(X) - E\ \times \exp\left(\frac{\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right)\right)dX$
```

and

```
$I_B = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \times \int_{\log(E/S)}^{\log(B/S)} \{S\exp(X) - E\}\exp\left(\frac{\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right) \times \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2\tau}\right)dX$
```

Letting $I = I_1 + I_2$ where

```
$I_1 = \frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{\log(E/S)}^{\log(B/S)} \exp(X)\exp\left(\frac{\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right)dX$
```

and

```
$I_2 = \frac{-E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{\log(E/S)}^{\log(B/S)} \exp\left(\frac{\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right)dX$
```

From our derivation of the Black-Scholes formula in Chapter 4 we have:

```
$I_1 = \frac{S\exp(-q\tau)}{\sigma\sqrt{2\pi}} \int_{k_1}^{k_2} \exp\left(-\frac{u^2}{2}\right)du = S\exp(-q\tau)\{N_1(k_2)-N_1(k_1)\}$
```

where

```
$k_1 = \frac{\log(E/S)-(r-q+\sigma^2/2)\tau}{\sigma\sqrt{\}}$
```

and

```
$k_2 = \frac{\log(B/S)-(r-q+\sigma^2/2)\tau}{\sigma\sqrt{\}}$
```

```
$I_2 = \frac{-E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{k_3}^{k_4} \exp\left(-\frac{u^2}{2}\right)du = -E\exp(-r\tau)\{N_1(k_4)-N_1(k_3)\}$
```

where

```
$k_3 = \frac{\log(E/S)-(r-q-\sigma^2/2)\tau}{\sigma\sqrt{\}}$
```

and

```
$k_4 = \frac{\log(B/S)-(r-q-\sigma^2/2)\tau}{\sigma\sqrt{\}}$
```
