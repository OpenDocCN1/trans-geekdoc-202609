
$\Delta\Pi = -\sum_{i=1}^n \mu_i S_i\Delta t\frac{\partial f}{\partial S_i}-\Delta t\frac{\partial f}{\partial t}-\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}$

```
\sum_{i=1}^n \sigma_i S_i\Delta t\frac{\partial f}{\partial S_i}+\sum_{i=1}^n \mu_i S_i\Delta t\frac{\partial f}{\partial S_i}
```

```
\sum_{i=1}^n \sigma_i S_i\Delta t\frac{\partial f}{\partial S_i} \quad (4.4.21)
```

Cancelling terms we obtain:

```
\Delta\Pi = -\Delta t\left(\frac{\partial f}{\partial t}+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}\right) \quad (4.4.22)
```

If this portfolio is at a riskless interest rate $r$ we have:

$r\Delta t = \Delta\Pi$

So Eq. (4.4.22) we have that:

```
\Delta\Pi = -\Delta t\left(\frac{\partial f}{\partial t}+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}\right) \quad (4.4.23)
```

Substituting for $\Pi$ we obtain:

```
$r\Delta t = f-\sum_{i=1}^n S_i\frac{\partial f}{\partial S_i}-\Delta t+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j} \quad (4.4.24)
```

Rearranging Eq. (4.4.24) gives:

```
\frac{\partial f}{\partial t}+\sum_{i=1}^n S_i\frac{\partial f}{\partial S_i}+\frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_i\sigma_j\rho_{ij}S_i S_j\frac{\partial^2 f}{\partial S_i\partial S_j}=rf \quad (4.4.25)
```

which is the $n$-dimensional Black–Scholes partial differential equation.

## 4.4.3 The Black–Scholes formula

The Black-Scholes model consists of two assets: the riskless money account and an equity. It can be cast as the following two-dimensional Ito equation:

```
$dS_t=\mu_S S_t dt+\sigma_S S_t dW^P \quad (4.4.26)
```

```
$dB_t=rB_t dt
```

where $W^P$ is Brownian motion (without drift) under measure $\mathbb{P}$, so $dW^P \sim N(0,dt)$.

Current time will be denoted by $t_0$, and the option maturity time by $T$. The money market account has value $B_{t_0}=1$ at time $t_0$ and $B_T = \exp(r(T - t_0))$ at time $T$.

We will now consider the process by the relative value $\phi(S_t, B_t) = S_t/B_t$.

Using the Ito quotient rule as described in Section 2.6.2 and substituting $X_1 = S_t$ and $X_2 = B_t$ in Eq. (2.6.8) we have:

```
$d\left(\frac{S_t}{B_t}\right) = \left(\frac{S_t}{B_t}\right)(\mu - r)dt + \left(\frac{S_t}{B_t}\right)\sigma dW^P$
```

So finally we can write

```
$dS_t^* = S_t^*(\mu - r)dt + S_t^*\sigma dW^P$ (4.4.27)
```

where $S_t^* = S_t/B_t$. Referring to Girsanov's theorem in Section 2.4, we can choose a probability measure $Q$

```
$dW^P = dW^Q - \left(\frac{\mu - r}{\sigma}\right)dt \quad (4.4.28)
```

In Eq. (2.4.3) we thus have $k(t) = -((\mu - r)/\sigma)$ and

```
$\frac{dQ}{dP} = \exp\left\{-\left(\frac{\mu - r}{\sigma}\right)W^P - \frac{1}{2}\left(\frac{\mu - r}{\sigma}\right)^2 t\right\}$ (4.4.29)
```

See p. 114 of Musiela (1998). Substituting for $dW^P$ in Eq. (4.4.27) yields

```
$dS_t^* = S_t^*(\mu - r)dt + S_t^*\sigma\left(\frac{\mu - r}{\sigma}\right)dW^Q$
```

which simplifies to

```
$dS_t^* = S_t^*\sigma dW^Q$ (4.4.30)
```

Equation (4.4.30) means that the process for $S_t^*$ is a martingale under probability $Q$.

Replacing $dW^P$ in (4.4.26) with the value in Eq. (4.4.28) yields

```
$dS_t = \mu_t S_t dt + S_t\sigma dW^P$
$= \mu_t S_t dt + S_t\sigma\left\{dW^Q - \left(\frac{\mu - r}{\sigma}\right)dt\right\}$
$= \left\{S_t\mu_t dt - S_t\sigma\left(\frac{\mu - r}{\sigma}\right)dt\right\} + S_t\sigma dW^Q$
```

So in risk neutral measure $Q$ the dynamics of $S_t$ are

```
$dS_t = r dt + S_t\sigma dW^Q$ (4.4.31)
```

Comparing Eq. (4.4.31) with the original Eq. (4.4.26) we see that changing from the real-world measure to risk neutral simply involves substituting $dW^P$ for $dW^Q$ and $r$ for $\mu$.

## European options

We can now solve Eq. (4.4.31) by using the result in Eq. (2.3). We have

```
$S_T = S \exp(v(T-t_0))$
```

where $S$ is the price at current time $t_0$, and $v = r - \sigma^2/2$. The forward price with maturity $T$, denoted by $S(t_0, T)$, is $E[S_T]$. From Appendix D, we have

```
$S(t_0, T) = E[S_T] = S \exp(r(T-t_0))$ (4.4.32)
```

Using Eq. (2.3) the distribution of the asset at current time $T$ is:

```
$\log \frac{S_T}{S} \sim N(v(T-t_0), \sigma^2(T-t_0))$ (4.4.33)
```

We want to consider the price of a European option with strike price $E$ which matures at time $T$, and thus has duration $\tau = T-t_0$. The approach we adopt here is to first derive an expression for the value of a call option, and then use put-call parity of Section 2 to obtain the value of the corresponding European option. Referring to (2.1) we have

```
$V_0 = B_0 E\left[\frac{H_T}{B_T}\right]$ (4.4.34)
```

Substituting $B_0 = 1, B_T = \exp(r\tau)$, and $H_T = \max(S_T-E, 0)$ we have

```
$V_0 = \frac{1}{\exp(r\tau)} E[\max(S_T-E, 0)]$ (4.4.35)
```

and denoting the value of call by $c(S, E, \tau)$ we obtain

```
$c(S, E, \tau) = \exp(-r\tau) E[\max(S_T-E)]$ (4.4.36)
```

It can be seen from Eq. (4.4.36) the value of the European option is the expected value of the option's payoff at maturity, discounted to current time $t_0$ by the riskless interest rate $r$. This means the value of call option can be written

```
$c(S, E, \tau) = \exp(-r\tau) \int_{S_T=E}^{\infty} f(S_T)(S_T-E) dS_T$ (4.4.37)
```

where $f(S_T)$ is the probability density function of $S_T$. Instead of integrating over $S_T$ we will evaluate (4.4.37) using the variable $X = \log(S_T/S)$. From Eq. (4.4.33) we know that the density function of $X$ is

```
$f(X) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(X-(r-\sigma^2/2)\tau)^2}{2\sigma^2\tau}\right)$ (4.4.38)
```

and therefore the value of the option is

```
$c(S, E, \tau) = \exp(-r\tau) \int_{X=\log(E/S)}^{\infty} \{Se^X - E\}f(X)dX$ (4.4.39)
```

where we have used $S_T = S\exp(X)$. The lower limit in Eq. (4.4.39) corresponds to $S_T = E$ in Eq. (4.4.37) and is found by setting $E = S\exp(X)$; this yields the lower limit $X = \log(E/S)$. The integral in Eq. (4.4.39) is evaluated by splitting it into the two parts:

```
$c(S, E, \tau) = I_A - I_B$ (4.4.40)
```

where

```
$I_A = \frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} e^X \exp\left -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX$ (4.4.41)
```

and

```
$I_B = \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \exp\left -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX$ (4.4.42)
```

To evaluate these integrals we make use of the fact that the cumulative normal function $N_1(x)$ is:

```
$N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{u=-\infty}^{x} \exp\left -\frac{u^2}{2} \right) du
```

By symmetry we have $N_1(-x) = 1 - N_1(x)$
We will first consider $I_B$, which is the easier of the integrals.

```
$I_B = \frac{E\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=-\infty}^{\infty} \exp\left -\frac{(X - (r-\sigma^2/2)\tau)^2}{2\sigma^2\tau} \right)$
```

If we use $u = \frac{X-(r-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ then $dX = \sigma\sqrt{\tau}$. So

```
$I_B = E\exp(-r\tau) \int_{u=-\infty}^{\infty} \exp\left -\frac{u^2}{2}\right) du$
```

where the lower limit of integration is $u = \frac{\log(E/S)-(r-\sigma^2/2)\tau}{\sigma\sqrt{\tau}} = -d_2$. Thus $I_B = E\exp(-r\tau) N(d_2)$.

Now consider $I_A$:

```
$I_A = \frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} e^X \exp\left -\frac{(X - (r - \sigma^2/2)\tau)^2}{2\sigma^2\tau} \right) dX$
```

Using the substitution $u = \frac{X-(r-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$, then $dX = \sigma\sqrt{\tau} du$ and $X = u\sigma\sqrt{\tau} + (r-\sigma^2/2)\tau$.

```
$I_A = \frac{S\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{u=-d_2}^{\infty} e^{u\sigma\sqrt{\tau} + (r-\sigma^2/2)\tau} \exp\left -\frac{u^2}{2}\right) \sigma\sqrt{\tau} du$
```

```
$I_A = S\exp(-r\tau)e^{(r-\sigma^2/2)\tau} \frac{1}{\sqrt{2\pi}} \int_{u=-d_2}^{\infty} \exp\left -\frac{u^2-2u\sigma\sqrt{\tau}}{2}\right) du$
```

Completing the square in the exponent: $u^2-2u\sigma\sqrt{\tau} = (u-\sigma\sqrt{\tau})^2 - \sigma^2\tau$.

```
$I_A = S\exp(-r\tau)e^{r\tau-\frac{\sigma^2\tau}{2}} e^{\frac{\sigma^2\tau}{2}} \frac{1}{\sqrt{2\pi}} \int_{u=-d_2}^{\infty} \exp\left -\frac{(u-\sigma\sqrt{\tau})^2}{2}\right) du$

```

```
$I_A = S \frac{1}{\sqrt{2\pi}} \int_{u=-d_2}^{\infty} \exp\left -\frac{(u-\sigma\sqrt{\tau})^2}{2}\right) du$
```

Let $v = u-\sigma\sqrt{\tau}$, then $dv=du$. The lower limit becomes $-d_2-\sigma\sqrt{\tau} = -d_1$.

```
$I_A = S \frac{1}{\sqrt{2\pi}} \int_{v=-d_1}^{\infty} \exp\left -\frac{v^2}{2}\right) dv = S N(d_1)
```

where $d_1 = \frac{\log(S/E)+(r+\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ and $d_2 = d_1-\sigma\sqrt{\tau}$.

Finally the Black-Scholes formula is

```
$c(S, E, \tau) = SN(d_1) - E\exp(-r\tau)N(d_2)$
```
