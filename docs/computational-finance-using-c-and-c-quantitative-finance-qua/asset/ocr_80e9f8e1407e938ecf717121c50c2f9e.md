# ## 7.2 Interest rate derivatives

It is not possible to make real profit without risk. For example, if we (without risk) invest £1 in a bank account, then for interest, the total number of pounds at time T will be $1+\Delta I(t,T)$, where $\Delta I(t,T)$ is the amount of interest accrued from t to time T. Since our investment grows by the riskless interest rate, the real value which for inflation must still be £1, so:

$DF(t,T)[1+\Delta I(t,T)]=1$

where $DF(t,T)$ is the discount factor from t to T.

Continuously compounded spot rate

When continuous compounding is used $1+\Delta I(t,T)=\exp\{R(t,T)(T-t))$, where $R(t,T)$ is the annual continuously compounded spot rate between t years and T years. We have thus:

```
$DF(t,T)\exp\{R(t,T)(T-t)\}=1 \quad (7.2.1)$
```

so the discount factor is

```
$DF(t,T)=\exp\{-R(t,T)(T-t)\} \quad (7.2.2)$
```

and the continuously compounded rate is

```
$R(t,T)=-\frac{\log(DF(t,T))}{T-t} \quad (7.2.3)$
```
