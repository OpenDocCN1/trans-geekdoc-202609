In the earlier sections of this book, we have considered options with standard payoffs such as: vanilla put, vanilla call, and call/put on the min/max of assets. However, the GenericEquityBasketOption now opens the possibility of supplying a user-defined Payoff function so that options with nonstandard payoffs can be valued.

Below we provide examples for options on two and ten assets. The assets were Drinks-4U, Beverage-Ltd, H20-Ltd, and Fine-Wines-Ltd. The trade attributes are a time to expire of one year, all volatilities are 0.2, and the number of units is 100. Other information required to price the option, as the correlations between the equities and the free interest rate, is taken from the market dictionaries.

The syntax for using the deal class GenericEquityBasketOption with the portfolio definition is:

```
Trade=GenericEquityBasketOptionDeal:Payoff=MaxPut,Reference=1A,Strike=100.0,
Volatilities=0.230,240,260,
Equities=Drinks-4U+Beverage-Ltd+H20-Ltd+Fine-Wines-Ltd,NumberOfUnits=100,
Time_Expiry=1.0,NumberScenarios=100
```

while that for the deal class FourEquityOptionDeal:

```
Trade=FourEquityOptionDeal,Reference=1B,Volatility1=0.2,Volatility2=0.2,
Volatility3=0.2,Volatility4=0.2,Equity1=Drinks+Beverage-Ltd,
Equity3=H20-Ltd+Fine-Wines-Ltd,NumberOfUnits=100,Strike=100.0,
Time_Expiry=1.0,OptionType=put,MinMax,MonteCarlo=Yes,NumberScenarios=1000
```
