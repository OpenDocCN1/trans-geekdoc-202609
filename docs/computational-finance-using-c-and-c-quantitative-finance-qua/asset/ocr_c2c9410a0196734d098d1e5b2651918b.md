In general, at time $t+i\Delta t$, there are $i+1$ stock prices; these are:

$S_{i,j} = Su^j d^{i-j}, \quad j=0, 1, \dots, i$

We note that, since $u=1/d$, an movement followed by a down movement gives the same stock price as a $T$ movement followed by an up movement; for instance, $Su^2=Su$. This means that the tree recombines, and the number of nodes required to represent all the different asset prices is significantly reduced.
