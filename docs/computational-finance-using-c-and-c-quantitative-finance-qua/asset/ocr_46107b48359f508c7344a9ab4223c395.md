# Compute the Monte Carlo estimate

The Monte Carlo estimate, $	heta_H$, is computed as the average of $	heta_H^p, p = 1, \dots, n_{sim}$, where $n_{sim}$ is the number of simulations:

```
$\theta_H = \sum_{i=1}^{n_{sim}} \theta_H^i$
```

In code excerpt 5.21, we provide a computer program which prices single asset American put and call options using a stochastic lattice. The method used by the program is depth first procedure outlined in Broadie and Glasserman (1997), which has the advantage that the memory requirements are only of order $b \times d$; as before, b is the number of branches per node and $d$ is the number of time intervals.

Here we assume the underlying asset GBM and the function normal (M, S) to generate a normal distribution with M and standard deviation S. We can then check the accuracy of the simulation with that obtained by a closed form which assumes a lognormal distribution, in this case the formula in Gekse and Janson (1984).
