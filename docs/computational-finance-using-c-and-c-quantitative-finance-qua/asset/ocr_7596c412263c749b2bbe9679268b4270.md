# Appendix J: Answers to problems

Use Ito to prove that the process for $Z_t$ is $dZ_t = Z_t	heta_t dW_t$.

# 9(a)

Let

```
$X_t = \int_{s=0}^t \theta_s dW_s - \frac{1}{2}\int_{s=0}^t \theta_s^2 ds$
```

so

```
$dX_t = \theta_t dW_t - \frac{1}{2}\theta_t^2 dt$
```

We thus have:

```
$Z_t = \exp(X_t)$
```

Using Ito we have

```
$dZ_t = \frac{\partial Z_t}{\partial X_t} dX_t + \frac{\partial^2 Z_t}{\partial X_t^2}(dX_t)^2$
```

so

```
$dZ_t = Z_t \left\ \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right\$
++ Z_t E\left[ \left( \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right) \left( \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right) \right]$
```

Now

```
$E\left[ \left( \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right) \left( \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right) \right]$$
= E[\theta_t^2 dW_t^2] + E[\frac{1}{4}\theta_t^4 dt^2] - E[\theta_t^3 dt dW_t]$
```

```
$E[dW_t^2] = \theta_t^2 E[dW_t^2] = \theta_t^2$ and $E[\theta_t^3\theta_t dt dW_t] = \theta_t^3 dt E[dW_t] = 0$
```

We have

```
$dZ_t = Z_t \left\ \ \theta_t dW_t - \frac{1}{2}\theta_t^2 dt \right\$ + \frac{1}{2}Z_t\theta_t^2 dt = Z_t\theta_t dW_t$
```

Hence we have shown that

```
$dZ_t = Z_t\theta_t dW_t$
```
