## 7.4 Credit derivatives

Credit derivatives take into account the fact that a counterparty may not honor (for reasons of bankruptcy, etc.) the obligations set out in a given financial contract. To obtain the time $t$ value of these derivatives it is necessary to determine the probability that the counterparty (and thus the contract) will survive until some future time $T > t$. Here we will denote the survival probability between times $t$ and $T$ by $S(t, T)$, and we compute its value from the hazard rate.

### The hazard rate

As previously mentioned the survival probability between times $t$ and $T$, where $T > t$, is denoted by $S(t, T)$. This means the probability of default between times $t$ and $T$ is:

```
$$P_{def}(t, T) = 1 - S(t, T)$$
```

and the probability of default, as seen from time $t$, between times $T_1$ and $T_2$ is:

```
$$P_{def}(t, T_1, T_2) = S(t, T_1) - S(t, T_2), \quad T_2 > T_1$$
```

The time $t$ discrete hazard rate between times $T$ and $T + \Delta T$, denoted by:

```
$$H(t, T, T + \Delta T) = \frac{1 \cdot P_{def}(t, T, T + \Delta T)}{\Delta T} \frac{1 \cdot S(t, T) - S(t, T + \Delta T)}{\Delta T}$$
```

which means that

```
$$H(t, T, T + \Delta T) = \frac{S(t, T + \Delta T) - S(t, T)}{\Delta T} \frac{1}{S(t, T + \Delta T)} \quad (7.4.2)$$
```

### Other financial derivatives

As $\Delta T \rightarrow 0, H(t, T+\Delta T) \rightarrow h(t, T)$, where $h(t, T)$ is the continuous hazard rate between times $t$ and $T$.

We observe that $\Delta T \rightarrow 0$ Eq. (7.4.2) becomes:

```
$h(t, T) = \frac{\partial S(t, T)}{\partial \Delta T} \frac{1}{S(t, T)} \quad (7.4.3)$
```

Now Eq. (7.4.3) can be re-expressed as:

```
$h(t, s) = \frac{\partial S(t, s)}{\partial s} \frac{1}{S(t, s)} = -\frac{\partial \ln(S(t, s))}{\partial s} \quad (7.4.4)$
```

where $s > t$, and we have used:

```
$$\frac{1}{S(t, T)} = \frac{\partial \ln(S(t, T))}{\partial T}$$
```

Integrating Eq. (7.4.4) yields:

```
$\int_{s=t}^{T} h(t, s) ds = \int_{s=t}^{T} d\ln(S(t, s)) = -{\ln(S(t, T)) - \ln(S(t, t))} = -\ln(S(t, T)) \quad (7.4.5)$
```

where we used $S(t, t) = 1$ and $\ln(S(t, t)) = 0$.
Using Eq. (7.4.5) the survival probability can be expressed as:

```
$S(t, T) = \exp\left(-\int_{s=t}^{T} h(t, s) ds\right) \quad (7.4.6)$
```

or

```
$S(t, T) = \exp\{-I(t, T)\} \quad (7.4.7)$
```

where $I(t, T)$ is the cumulative hazard rate from time $t$ to time $T$.
It is usual to approximate $I(t, T)$ as follows:

```
$I(t, T) \sim I(t, t_k) = \sum_{i=1}^{k} h(t_{i-1}, t)(t_i - t_{i-1}) \quad (7.4.8)$
```

where $t_0 = t, t_k = T$, and the following section details on how to estimate $h(t_{i-1}, t)$ from market observables.
One way of representing the hazard rates is to use a *hazard rate curve* which is defined as:

```
$\{t_i, I(t_i)\}, \ i = 0, \dots, n \quad (7.4.9)$
```

If we define $t_0 = t$ and $t_n = T$, then Eq. (7.4.9) becomes:

```
$\{(0, 0), \{t_1, I(0, t_1)\}, \{t_2, I(0, t_2)\}, \dots, \{t_n, I(0, t_n)\} \quad (7.4.10)$
```

where we have used the fact that $I(t_0, t_0) = I(0, 0) = 0$.

### 7.4.1 Credit default swap

A Credit Default Swap (CDS) is a contract between two counterparties, one (A) makes:

```
$$\mathbf{F}(t, T_1, T_2) = \frac{1}{T_2 - T_1} \left\{ \frac{DF(t, T_1)}{DF(t, T_2)} \right\} \quad (7.4.11)$$
```

where $DF(t, T_1)$ and $DF(t, T_2)$ are the prices of the nondefaultable zero coupon bonds with maturities $T_1 = T$ and $T_2 = T + \Delta$, respectively.

Letting $T_1 = T$ and $T_2 = T + \Delta$ we obtain:

```
$$\mathbf{F}(t, T, T + \Delta) = \frac{1}{\Delta} \left\{ \frac{DF(t, T)}{DF(t, T + \Delta)} \right\} \quad (7.4.12)$$
```

which can be re-expressed as

```
$$\frac{DF(t, T + \Delta) - DF(t, T)}{\Delta} \frac{1}{DF(t, T + \Delta)} = \quad (7.4.13)$$
```

If $\Delta \rightarrow 0$ then $F(t, T + \Delta) \rightarrow f(t, T)$ and from Eq. (7.4.13) we obtain:

```
$$f(t, T) = -\frac{\partial \ln(DF(t, T))}{\partial T} \quad (7.4.14)$$
```
