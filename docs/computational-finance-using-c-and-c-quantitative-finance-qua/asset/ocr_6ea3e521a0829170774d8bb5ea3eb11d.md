# The finite-difference approximation

Here we consider how to discretize the Black–Scholes equation using a nonuniform grid, with both the price interval ΔS and the time step Δt are not constant but can vary throughout the grid.

Allowing for a nonconstant time step is quite simple. The time step occurs in both the first derivative f_{i,j} (see Eq. (5.4.4)) and in the option value equations (see Eqs. (5.4.14)-(5.4.21)) as the constant Δt. To incorporate a varying time step, Δ_{i,j}=0, thus only requires setting Δt=Δ_{i,j} at the ith step and then continuing with the solution method outlined in Section 5.4.

The incorporation of nonconstant asset price intervals requires more work. This is because the finite-difference approximations to the second derivatives f'_{i,j} and f''_{i,j}' in Eqs. (5.4.10) and (5.4.11) are based on a Taylor expansion about the point f_{i,j}.

We will now derive expressions for these derivatives.

If we let ΔX_j=S_j-S_{j-1} and ΔX^+j=S_{j+1}-S_j and then use a Taylor expansion about f_{i+1,j} we have

```
f_{i+1,j+1}=f_{i+1,j}+f'_{i+1,j}\Delta X^+j+\frac{1}{2}f''_{i+1,j}(\Delta X^+j)^2 \quad (5.4.32)
```

and also

```
f_{i,j-1}=f_{i,j}-f'_{i,j}\Delta X^+j+\frac{1}{2}f''_{i,j}(\Delta X^+j)^2 \quad (5.4.33)
```

Multiplying Eq. (5.4.32) by ΔX^+j and adding it to ΔX^+j times Eq. (5.4.33), gives

```
ΔX^+j_{i+1,j-1}=ΔX^+j_{i+1,j}+ΔX^+j_{i+1,j}+\frac{1}{2}f''_{i+1,j}(((\Delta X^+j)^2+(\Delta X^+j)^2)\Delta X^+j)
```
