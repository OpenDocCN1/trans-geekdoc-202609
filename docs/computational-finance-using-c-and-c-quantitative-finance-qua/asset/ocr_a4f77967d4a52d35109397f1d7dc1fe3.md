# 6.5 Two asset options

In this section we consider options based on the underlying prices of two assets, S1 and S2. We use analytic formulae to price European exchange options and those based on the maximum or minimum of two assets. In addition we show how to construct binomial lattices for the valuation of two asset American-style options.

# 6.5.1 European exchange options

A European exchange option gives the holder the right to exchange one asset for another asset at maturity; see Margrave (1978). Let the real-world processes of assets S^A and S^B be:

```
$dS^A = S^A \mu_A dt + S^A \sigma_A dW_t^A$
dS^B = S^B \mu_B dt + S^B \sigma_B dW_t^B$
```

where S^A denotes the value of asset A at time t and S^B denotes the value of asset B at time t and W—the symbols have their obvious meanings.

We now find the value, at current time t_0, of an option that gives the holder right to exchange asset A for B at maturity T. The payoff at maturity is H_T = \max(S_T^B/S_T^A, 0).

If we use of asset S A as the numeraire, from Eq. (4.2.1), the value of the exchange option at time t_0 is:

```
$V(t_0) = S_0^A E\left[\max(S_T^B/S_T^A, 0)\right]$
```

which can be written as

```
$V(t) = S_t^A E\left[\max(S_T^B/S_T^A) - 1\right] \quad (6.5.1)
```

where \mathbb{Q} is the probability measure under which the relative price (S_T^B/S_T^A) is a martingale.

The process followed by (S_T^B/S_T^A) can be found by substituting X_1 = S_t^B and X_2 = S_t^A into Eq. (2.6.7). This yields

```
$d(\frac{S_t^B}{S_t^A}) = (\frac{S_t^B}{S_t^A})(\mu_B - \mu_A + \sigma_A^2 - \sigma_A\sigma_B\rho_{AB})dt\n+ (\frac{S_t^B}{S_t^A})(\sigma_B dW_t^B - \sigma_A dW_t^A)$
```

Let \tilde{X} = \sigma_B dW_t^B - \sigma_A dW_t^A$, so E[\tilde{X}] = \sigma_B E[dW_t^B] = 0, and Var[\tilde{X}] = \sigma_B^2 dt + \sigma_A^2 dt - 2\sigma_A\sigma_B\rho_{AB}dt$ where we have used (see Appendix C.3):

$Var[a dW_t + b dW_2] = a^2 Var[dW_1] + b^2 Var[dW_2] + 2ab Cov[dW_1, dW_2]$,\nVar[dW_t^B] = Var[dW_t] = dt \quad \text{and} \quad Cov[dW_t^B, dW_t^A] = \sigma_B\sigma_A\rho_{AB}dt$
