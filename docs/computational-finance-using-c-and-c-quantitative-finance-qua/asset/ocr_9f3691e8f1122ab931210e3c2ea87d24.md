Similarly we have:

```
$E[\varepsilon_i^4] = 2K \int_{0}^{\infty} \frac{\varepsilon_i^4 \mathrm{d}\varepsilon_i}{(1+\varepsilon_i^2/h_i(v-2))^{(v+1)/2)}} =2K(h_i(v-2))^{(v+1)/2} \int_{0}^{\infty} \frac{\varepsilon_i^4 \mathrm{d}\varepsilon_i}{(h_i(v-2) + \varepsilon_i^2)^{(v+1)/2}}$
```

Using the standard integrals in Section E.1 with $a=4, b=2, c=(v+1)$, and $m=(v-2)h_i$ gives:

```
$$\Gamma(\frac{m^{(a+1-bc)/b}}{b}) = \frac{(h_i(v-2))^{(4-v)/2}}{b} \quad \Gamma(\frac{a+1}{b}) = \Gamma(\frac{5}{2})$$
$\Gamma(c-\frac{a+1}{b}) = \Gamma(\frac{\nu-4}{2}), \quad \Gamma(c) = \Gamma(\frac{\nu+1}{2})$
```

and

```
$E[\varepsilon_i^4] = 2K(h_i(v-2))^{(v+1)/2} \left\{ \frac{(h_i(v-2))^{(4-v)/2}\sqrt{\pi}\Gamma((\nu-4))}{8\Gamma((\nu+1)/2)} \right\}$
```

Substituting $K$ and simplifying we obtain:

```
$E[\varepsilon_i^4] = \frac{3h_i(v-2)^2\Gamma((\nu-4)/2)h_i^2}{4\Gamma(\nu/2)}$
```

But

```
$$\Gamma(\frac{\nu-4}{2})\Gamma(\frac{\nu-4}{2}) = \Gamma(\frac{\nu-2}{2})$
```

and

```
$$\Gamma(\frac{\nu-2}{2})\Gamma(\frac{\nu-2}{2}) = \Gamma(\frac{\nu}{2})$
```

Therefore:

```
$$\Gamma(\frac{\nu-4}{2}) = \frac{4\Gamma(\nu/2)}{\Gamma(\nu-2)}$
```

So

```
$E[\varepsilon_i^4] = \frac{3(\
u-2)^2\Gamma(\nu/2)h_i^2}{4\Gamma(\
u/2)(\nu-4)} = \frac{3(\
u-2)h_i^2}{\nu-4}$
```

The kurtosis is then:

```
$$\kappa = \frac{E[\varepsilon_i^4]}{(E[\varepsilon_i^2])^2} = \frac{3(\
u-2)h_i^2}{(\nu-4)h_i^2} = \frac{3(\
u-2)}{\nu-4} \quad (D.3.1)$
```
