and the right-hand side of the equation by:

```
$RHS(S_i^{**}, E, \tau) = p(S_i^{**}, \tau) - \frac{S_i^{**}}{\gamma_1}\{1 - N_1(d_1(S_i^{**}))} \exp(-\tau)$$\n= p(S_i^{**}, E, \tau) - \frac{S_i^{**}}{\gamma_1}[1 - N_1(d_1(S_i^{**}))} \exp(-\tau)]$\n= p(S_i^{**}, E, \tau) - \frac{S_i^{**}}{\gamma_1}\{1 - \exp(-\tau)\} + N_1(d_1(S_i^{**})) \exp(-\tau)$
```

We then denote $K(S_*^{**}, E, \tau) = RHS(S_i^{**}, E, \tau) - LHS(S_i^{**}, E, \tau)$ and using Newton's method we obtain

```
$S_{i+1}^{**} = S_i^{**} - \frac{\partial}{\partial S_i^{**}} \frac{K(S_i^{**}, E, \tau)}{K'(S_i^{**}, E, \tau)} \quad (5.2.36)
```

where as:

```
$K'(S_i^{**}, E, \tau) = \frac{\partial}{\partial S_i^{**}} \{RHS(S_i^{**}, E, \tau) - LHS(S_i^{**}, E, \tau)\}$
```

So $K'(S_i^{**}, E, \tau) = 1 + b_i$, where $b_i = \frac{\partial(RHS(S_i^{**}, E, \tau))}{\partial S_i^{**}}$, and the expression for $b_i$ is given by Eq. (5.2.36), which is derived at the end of this section.

Equation (5.2.36) can be written as:

```
$S_{i+1}^{**} = S_i^{**} - \frac{RHS(S_i^{**}, E, \tau) - LHS(S_i^{**}, E, \tau)}{1 + b_i}$\n= \frac{S_i^{**}(1 + b_i) - RHS(S_i^{**}, E, \tau) + E - S_i^{**}}{1 + b_i}$
```

The final iterative algorithm for the Put is therefore:

```
$S_i^{**} = \frac{E - RHS(S_i^{**}, E, \tau) + b_i S_i^{**}}{1 + b_i} \quad (5.2.37)
```
