# D.1.1 Some elementary results involving the mean and variance of a normal distribution

From first principles we have:

+   - The mean:

$E[x] = \frac{1}{\sqrt{2\pi}} \int_{x=-\infty}^{x=\infty} x exp(-\frac{(x-\mu)^2}{2\sigma^2}) dx$

Letting $y = x - \mu$ we have $dx = dy$ and $x = y + \mu$; therefore:

$E[x] = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} (y+\mu) exp(-\frac{y^2}{2\sigma^2}) dy$

$E[x] = \mu \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} exp(-\frac{y^2}{2\sigma^2}) dy$

$+ \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} y exp(-\frac{y^2}{2\sigma^2}) dy$

Since

$$\int_{-\infty}^{\infty} y exp(-\frac{y^2}{2\sigma^2}) dy = 0$

we have the integral result (i) in Section E.1 with $a=1/(2\sigma^2)$:

$E[x] = \mu \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} exp(-\frac{y^2}{2\sigma^2}) dy = \mu$

+   - The variance:

$E[x^2] = \frac{1}{\sqrt{2\pi}} \int_{x=-\infty}^{x=\infty} x^2 exp(-\frac{(x-\mu)^2}{2\sigma^2}) dx$

Letting $y = x - \mu$ we have $dx = dy$ and $x^2 = y^2+2y\mu+\mu^2$; therefore:

$E[x^2] = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} (y^2+2y\mu+\mu^2) exp(-\frac{y^2}{2\sigma^2}) dy$
