Since we are modelling asset price movements with a binomial lattice, the asset price, $S_t$, at any given node is only permitted to either jump up or jump down in value over the next time step. Here we will assume that the next price, $S_{t+\Delta t}$, is $S_u$ for a jump up and $S_d$ for a jump down where $u$ and $d$ are constants that apply to all lattice nodes. If we further note the probability of an jump up by $p$, then the probability of a jump down (by definition) is $1-p$.
