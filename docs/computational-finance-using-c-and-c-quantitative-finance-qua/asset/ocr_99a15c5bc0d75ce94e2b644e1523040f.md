PROOF. The standard Ornstein-Uhlenbeck process ($\sigma = 1$) is defined by the process:

```
$dX_t = -\alpha X_t \, dt + \sqrt{d} \, dZ_t \quad (2.11.3)
```

From Section 2.10 we have that

```
$X_t = X_{t_0} \exp(-\alpha(t-t_0)) + \left\{ \frac{1 - \exp(-2\alpha(t-t_0))}{2\alpha} \right\} dZ_t \quad (2.11.4)
```

and that transition density from $X_{t_0}$ to $X_t$ is

```
$P(X_t|X_{t_0}) = \frac{\sqrt{2\alpha}}{\sqrt{2\pi(1 - \exp(-2\alpha(t-t_0)))}} \\times \exp\left\{ \frac{\alpha(X_t - X_{t_0}) \exp(-\alpha(t-t_0)))}{1 - \exp(-2\alpha(t-t_0))} \right\ \quad (2.11.5)
```

The joint density of $X_t$ and $X_{t_1}$ given $X_{t_0}$ is:

```
$P(\{X_t, X_{t_1}\}|X_{t_0}) = P(X_t|X_{t_1})P(X_{t_1}|X_{t_0}) \quad (2.11.6)
```

We have:

```
$P(\{X_t, X_{t_1}\}|X_{t_0}) = \kappa \exp\left\{ \frac{\alpha(X_t - X_{t_0}) \exp(-\alpha(t-t_0)))}{1 - \exp(-2\alpha(t-t_0))} \right\} \\times \exp\left\{ \frac{\alpha(X_{t_1} - X_{t_0}) \exp(-\alpha(t_1-t)))}{1 - \exp(-2\alpha(t_1-t))} \right\}$
```

where

```
$\kappa = \frac{1}{2\pi} \sqrt{(1 - \exp(-2\alpha(t-t_0)))(1 - \exp(-2\alpha(t_1-t))}$ \quad
```

The distribution of $X_t$ given $X_{t_0}$ and $X_{t_1}$, $P(X_t|X_{t_0}, X_{t_1})$ is:

```
$P(X_t|{X_{t_0}, X_{t_1}\}) = \frac{P(\{X_t, X_{t_1}\}|X_{t_0})}{P(X_{t_1}|X_{t_0})} \quad (2.11.7)
```

where

```
$P(X_{t_1}|X_{t_0}) = \frac{\sqrt{2\alpha}}{\sqrt{2\pi(1 - \exp(-2\alpha(t_1-t_0)))}} \\timestimes \exp\left\{ \frac{\alpha(X_{t_1} - X_{t_0}) \exp(-\alpha(t_1-t_0)))}{1 - \exp(-2\alpha(t_1-t_0))} \right\}$
```

After some algebra we can re-express Eq. (2.11.7) as

```
$P(X_t|{X_{t_0}, X_{t_1}\}) = \sqrt{\frac{\alpha}{\pi\phi_{t_1}}} \exp[A] \quad (2.11.9)
```
