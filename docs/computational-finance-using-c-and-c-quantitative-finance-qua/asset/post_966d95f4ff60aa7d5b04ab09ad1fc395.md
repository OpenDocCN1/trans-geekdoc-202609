$d_1=\frac{\log(S/E) + (r + \sigma^2/2)\tau}{\sigma\sqrt{\tau}} \quad \text{and}

To gain some insight into the meaning of the above equation, we will rewrite it in the following form:

```
$c(S, E, \tau)=\exp(-r\tau)SN_1(d_1)\exp(r\tau)-EN_1(d_2) \qquad (4.4.49)$
```

The term $N_1(d_2)$ is a probability that the option will be exercised in a risk-neutral world, so that $EN_1(d_2)$ is the strike price multiplied by the probability that the strike price will be paid. The term $SN_1(d_1)\exp(r\tau)$ is the expected value of a variable, in a risk neutral world, equals $S_T$ if $S_T > E$ and is otherwise zero.

The corresponding formula for a put can be shown using put parity (see Section 4.3) to be:

```
$p(S, E, \tau)=E\exp(-r\tau)N_1(-d_2)-SN_1(-d_1) \qquad (4.4.50)$
```

or equivalently, using $N_1(-x)=1-N_1(x)$ we have

```
$p(S, E, \tau)=\exp(-r\tau)\{1-N_1(d_2)\}-S\{1-N_1(d_1)\} \qquad (4.4.51)$
```

# The inclusion of dividends

The effect of dividends on the value of a European option can be dealt with assuming that the asset price is the sum of a riskless component involving known dividends that will be paid during the life of the option, and a risky (stochastic) component; see Hull (2003).

As continuous $q$ are paid, the stock price is reduced by the same amount, and by the time the European option measures all the dividends have been paid, leaving only the risky component of the asset price.

From Eq. (4.4.26) we have thus:

```
$d\mu=\muSdt-Sqdt+\sigmaSdW^P
$dB=rBdt \qquad (4.4.52)$
```

where under probability measure $\mathbb{P}$ we know that $dW^P \sim N(0, dt)$.

As before (Girsanov's theorem), we choose probability measure $\mathbb{Q}$ so that

```
$dW^P=dW^Q-(\frac{\mu-r}{\sigma})dt$
```

and thus under this measure the process for $S$ is

```
$dS=\muSdt-Sqdt-(\frac{\mu-r}{\sigma})dt+\sigmaSdW^Q, \quad \text{where } dW^Q \sim N(0, dt)$
```

which results in

```
$$\$ dS = S(r-q)dt + \sigma dW^Q \text{ where } dW^Q \sim N(0, dt) \quad (4.4.53)$$
```

Proceeding as we obtain:

```
$$X \sim N(\{r-q-\sigma^2/2\tau, \sigma^2\tau\})$
```

where $X = S_T/S_0$. The probability density function of $X$ is:

```
$$f(X) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(X-(r-q-\sigma^2/2)\tau)^2}{2\sigma^2\tau}\right)$$
```

The value of a call option is:

```
$$c(S,E,\tau) = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{log(E/S)}^{\infty} {S\exp(X)-E\exp\left(-\frac{(X-(r-q-\sigma^2/2)\tau)^2}{2\sigma^2\tau}\right)} dX \quad (4.4.54)$$
```

with

```
$$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{log(E/S)}^{\infty} \exp(X) \exp\left(-\frac{[X-(r-q-\sigma^2/2)\tau]^2}{2\sigma^2\tau}\right) dX$$
```

and

```
$$I_B = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{log(E/S)}^{\infty} \exp(X) \exp\left(-\frac{[X-(r-q-\sigma^2/2)\tau]^2}{2\sigma^2\tau}\right) dX$$
```

So $I_B = \exp(-r\tau)N_1(-k_2)$, where $k_2 = \frac{\log(E/S)-(r-q-\sigma^2/2)\tau}{\sqrt{\tau}}$

We will now consider integrand $I_A$.

```
$$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{log(E/S)}^{\infty} \exp(X) \exp\left(-\frac{[X-(r-q-\sigma^2/2)\tau]^2}{2\sigma^2\tau}\right) dX$$
```

Rearranging the integrand:

```
$$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \int_{log(E/S)}^{\infty} \exp(X) \exp\left(-\frac{[X-(r-q-\sigma^2/2)\tau]^2}{2\sigma^2\tau}\right) dX$$
```

Expanding the exponential, we obtain:

```
${\X-(r-q-\sigma^2/2)\tau\}^2-2\{X-(r-q+\sigma^2/2)\tau\}$
```

The integral $I_A$ can therefore be expressed as:

```
$$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}} \times \int_{log(E/S)}^{\infty} \exp\left(-\frac{[X-(r-q+\sigma^2/2)\tau]^2}{2\sigma^2\tau}\right) dX$$
```

which gives $I_A = S\exp(-q\tau)N_1(-k_1)$ where $k_1 = \frac{\log(E/S)-(r-q+\sigma^2/2)\tau}{\sqrt{\tau}}$

The Black-Scholes formula for the value of a European call including continuous dividends is:

```
$c(S, E, \tau) = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2) \quad (4.4.55)$
```

and the corresponding formula for a put can be used (using call parity) to be:

```
$p(S, E, \tau) = -S\exp(-q\tau)N_1(-d_1) + E\exp(-r\tau)N_1(-d_2) \quad (4.4.56)$
```

or equivalently, using $N_1(-x) = 1 - N_1(x)$, we have

```
$p(S, E, \tau) = E\exp(-r\tau)[1 - N_1(d_2)] - S\exp(-q\tau)\{1 - N_1(d_1)\} \quad (4.4.57)$
```

where

```
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}, \quad d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

Thus put/call options with continuous dividends can be priced using Eqs. (4.4.47) and (4.4.50) but with $S$ replaced by $S\exp(-q\tau)$.

These formulae also be re-expressed in terms of the current equity forward price with maturity $T$, $S(t,T)$, as follows:

```
$c_t = \exp(-r(T-t))\{S(t,T)N_1(d_1) - EN_1(d_2)\} \quad (4.4.58)$
```

```
$p_t = \exp(-r(T-t))\{-S(t,T)N_1(-d_1) + EN_1(-d_2)\} \quad (4.4.59)$
```

where we have used the short notation $p_t$ and $c_t$ to denote the current (time) value of put and call; the current equity forward price with maturity $T$ is

```
$S(t,T) = S\exp((r-q)(T-t)), \quad t \le T,$
```

and

```
$d_1 = \frac{\log(S(t,T)/E) + (\sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}, \quad d_2 = \frac{\log(S(t,T)/E) - (\sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}$
```

The inclusion of discrete dividends here we consider discrete dividends $D_i = 1, \dots, n$, at times $t_i = 1, \dots, n$, during the life of the option. In these circumstances the Black-Scholes formula can be used to price European options, but with the asset value $S$ reduced by the present value of cash dividends. This means that instead of $S$ we use the quantity $S_D$ which is computed as

```
$S_D = S - \sum_{i=1}^n D_i\exp(-rt_i)$
```

where $r$ is the (in this case constant) riskless interest rate. The formulae for European puts and calls is then

```
$c(S, E, \tau) = S_DN1(d_1) - E\exp(-r\tau)N_1(d_2) \quad (4.4.60)$
```

```
$p(S, E, \tau) = E\exp(-r\tau)\{1 - N_1(d_2)\} - S_D N_1(d_1) \quad (4.4.61)$
```

where

$d_1 = \frac{\log(S_D/E) + (r + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}, \quad d_2 = \frac{\log(S_D/E) + (r - \sigma^2/2)\tau}{\sigma\sqrt{\tau}} = d_1 - \sigma\sqrt{\tau} \quad (4.4.62)$

# The Greeks

Now that we have derived for european puts and calls it is possible to work out their partial derivatives (hedge statistics). We will now quote expressions for the Greeks (hedge statistics) for European options. Here the subscript $c$ refers to call, and the subscript $p$ refers to a put. Complete derivations of these results can be found in Appendix A.

# Gamma

```
$\Gamma_c = \frac{\partial^2 c}{\partial S^2} = \Gamma_p = \frac{\partial^2 p}{\partial S^2} = \exp(-q\tau)\frac{N_1(d_1)}{\sigma\sqrt{\tau}} \quad (4.4.63)$
```

# Delta

```
$\Delta_c = \frac{\partial c}{\partial S} = \exp(-q\tau)N_1(d_1)$
$\Delta_p = \frac{\partial p}{\partial S} = \exp(-q\tau)\{N_1(d_1) - 1\} \quad (4.4.64)$
```

# Theta

```
$\Theta_c = \frac{\partial c}{\partial t} = q \exp(-q\tau)N_1(d_1) - r E \exp(-r\tau)N_1(d_2) - \frac{S\exp(-q\tau)\sigma(d_1)}{2\sqrt{\tau}}$
$\Theta_p = \frac{\partial p}{\partial t} = -q \exp(-q\tau)N_1(-d_1) + r E \exp(-r\tau)N_1(-d_2) + \frac{S\exp(-q\tau)\sigma(d_1)}{2\sqrt{\tau}} \quad (4.4.65)$
```

# Rho

```
$\rho_c = \frac{\partial c}{\partial r} = E\tau N_1(d_2), \quad \rho_p = \frac{\partial p}{\partial r} = -E\tau N_1(-d_2) \quad (4.4.66)$
```

# Vega

```
$V_c = \frac{\partial c}{\partial\sigma} = V_p = \frac{\partial p}{\partial\sigma} = S\exp(-q\tau)n_1(d_1)$
```

$n(x) = \frac{1}{\sqrt{2\pi}} \exp(-x^2/2)$

We now present, in Code 4.1, a computer program to calculate the Black-Scholes option value and Greeks in Eqs. (4.4.63)–4.4.67). The routine uses $EPS = 1.0e-16$ to identify which arguments are too small

```c
black_scholes(double value, double greeks[], double s0, double x,
double sigma, double t, double r, double q, long put, int flag) {
    // Input parameters:
    s0 = the current price of the underlying asset
    x = the strike price
    sigma = the volatility,
    t = the time to maturity
    r = the interest rate
    q = the continuous dividend yield
    put = if put is then call option, otherwise a put
    // Output Parameters:
    value = the value of the option
    greeks[0] = the hedge statistics as follows: greeks[0] is gamma, greeks[1] is delta
    greeks[2] is theta, greeks[3] is rho, and greeks[4] is vega
    iflag = an error index;
    double one=1.0,two=2.0;
    double eps,d1,d2,temp,pi2;
    if (x < EPS) || (sigma < EPS) || (t < EPS)) { /* Check if any of the input
    arguments are too small */
    iflag = 2;
    return;
    }
    temp = log(s0/x);
    d1 = (temp+(r-q+sigma*sigma/2)*t)/sigma*sqrt(t);
    d2 = d1-sigma*sqrt(t);
    /* evaluate the option price */
    if(put==0) {
    * value = (s0*exp(-q*t)*cum_norm(d1))(x*exp(-r*t)*cum_norm(d2));
    } else {
    * value = (x*exp(-r*t)*cum_norm(-d2))-(s0*exp(-q*t)*cum_norm(-d1));
    }
    /* calculate the Greeks */
    temp1 = d1-sigma*sqrt(t);
    p2 = d1-sigma*sqrt(t)*temp1;
    greeks[1] = (cum_norm(d1)-exp(-q*t))*temp1 / delta *;
    greeks[2] = -sigma*exp(-q*t)/sqrt(t) / gamma *;
    q0*cum_norm(-d1)*exp(-q*t) + r*exp(-r*tau)*cum_norm(-d2) / theta *;
    greeks[3] = x*exp(-r*t)*cum_norm(d2) / rho *;
    } else { /* a put option */
    greeks[1] = (cum_norm(-d1)-exp(-q*t)) / delta *;
    greeks[2] = -sigma*exp(-q*t)/sqrt(t) / gamma *;
    q0*cum_norm(-d1)*exp(-q*t) + r*exp(-r*tau)*cum_norm(-d2) / theta *;
    greeks[3] = -x*exp(-r*t)*cum_norm(d2) / rho *;
    }
    greeks[0] = np*exp(-q*t)/(s0*sigma*sqrt(t)); / gamma *;
    greeks[4] = sigma*sqrt(t)*exp(-q*t) / vega *;
}
return;}
``````
