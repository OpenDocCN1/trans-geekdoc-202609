# 3.3.2 Lognormal distribution

The lognormal distribution can be generated from the normal distribution discussed in the previous section by means of a simple transformation. If y ~ N(\mu, \sigma^2$) and y = log(x) then x = exp(y), and we say that the variable X has the lognormal distribution L(\mu, \sigma^2).

The lognormal density function is:

> $f(x) = \frac{1}{x\sigma(2\pi)^{1/2}} \exp\left(\frac{(\log x - \mu)^2}{2\sigma^2}\right)$

If $z_i, i = 1, \dots, p$, are independent normal variates $N(\\mu_i, \sigma_i^2)$, $i = 1, \dots, p$, then lognormal variates $\ell_i, i = 1, \dots, p$, can be generated using the transformation:

> $\ell_i = \exp(z_i), i = 1, \dots, p,$

> $E[x_i] = \tilde{m}_i = \exp\left(\\mu_i + \frac{\sigma_i^2}{2}\right)$

and the variance is

> $Var[x_i] = \tilde{s}_i^2 = \exp(2\mu_i + \sigma_i^2)(\exp(\sigma_i^2) - 1)$

The ratio of variance to the mean squared is squared

> $\frac{\tilde{s}_i^2}{\tilde{m}_i^2} = \exp(\sigmasigma_i^2) - 1$
