# The BBSR method

The BBSR method applies two point Richardson extrapolation to the computed BBS values; for more information concerning Richardson extrapolation see Marchuk and Shaidurov (1983). In this method the price estimates from two BBS lattices, with differing numbers of time steps, are combined to form an estimate.
