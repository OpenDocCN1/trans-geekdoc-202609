# H.9 Proof of Eq.

We use Eq. (H.1.6) to compute $\frac{\partial P}{\partial x}$, where $P(m_t^{ar{X}} \le b, \bar{X}_t \ge x)$ is denoted by P.

Let $\Theta = (2b-x+vt)/(\sigma\sqrt{t})$ we obtain:

```
$$\frac{\partial P}{\partial x} = \exp\left(\frac{2vb}{\sigma^2}\right)\frac{\partial}{\partial x}[N_1(\Theta)]\n= \exp\left(\frac{2vb}{\sigma^2}\right)\frac{\partial}{\partial \Theta}[N_1(\Theta)]\frac{\partial \Theta}{\partial x}\n= -\exp\left(\frac{2vb}{\sigma^2}\right)\frac{1}{\sigma\sqrt{\pi}}n(\Theta)\n= \frac{1}{\sigma\sqrt{2\pi t}}\exp\left(\frac{2vb}{\sigma^2}\right)\exp\left(\frac{(2b-x+vt)^2}{2\sigma^2t}\right) \quad (H.9.1)$
```

Now since the probability $P(m_t^{ar{X}} \le b, \bar{X}_t \ge x)$ increases as we have:

```
$P(m_t^{ar{X}} \le b, \bar{X}_t \ge x) - P(m_t^{ar{X}} \le b, \bar{X}_t \ge x+\Delta x) = -\frac{\partial P}{\partial x}\Delta x \quad (H.9.2)$
```

and also:

```
$P(m_t^{ar{X}} \le b, \bar{X}_t \ge x) - P(m_t^{ar{X}} \le b, \bar{X}_t \ge x+\Delta x) \sim p(m_t^{ar{X}} \le b, \bar{X}_t = x)\Delta x \quad (H.9.3)$
```

where $p(m_t^{ar{X}} \le b, \bar{X}_t = x)$ is the probability density function of $P(m_t^{ar{X}} \le b, \bar{X}_t \ge x)$, and $\Delta x \to 0$.

Combining Eqs. (H.9.2) and (H.9.3) we thus obtain

```
$p(m_t^{ar{X}} \le b, \bar{X}_t = x) = -\frac{\partial P}{\partial x}\Delta x$
```

So,

```
$p(m_t^{ar{X}} \le b, \bar{X}_t = x) = \frac{1}{\sigma\sqrt{2\pi t}}\exp\left(\frac{2vb}{\sigma^2}\right)\exp\left(-\frac{(2b-x+vt)^2}{2\sigma^2t}\right)$
```
