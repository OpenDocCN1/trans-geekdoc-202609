# Case $i < k$

Here we consider situations in which the maturity of the numeraire $DF_i$ is before the expiry of the forward rate $F_k$.

$i = k - 1$

In this case $DF_{k-1}$ is the numeraire, the forward rate is $F_k = F(t, t_{k-1}, t_k)$, and the numeraire matures at time $t_{k-1}$, while the forward rate has expiry $t_k$.

Since $DF_k$ is a tradable relative price, $\phi = DF_k/DF_{k-1}$, is a martingale under $\mathbb{Q}^{k-1}$, and thus has zero drift.

Now

```
$\phi = \frac{DF_k}{DF_{k-1}} \frac{1}{1 + \tau F_k}$ (7.24.44)
```

where we have used:

```
$DF_{k-1} = DF_k(1 + \tau F_k)$ (7.24.45)
```

Let the stochastic process followed by $F_k$ under $\mathbb{Q}^{k-1}$ be:

```
$dF_k = F_k \mu_k dt + F_k \sigma_k dW^{k-1}$ (7.24.46)
```

and the drift, $\mu_k$, is to be determined.

Using Ito we have:

```
$\frac{\partial \phi}{\partial F_k} dF_k + \frac{1}{2} \frac{\partial^2 \phi}{\partial F_k^2} E[(dF_k)^2], E[(dF_k)^2] = \sigma_k^2 F_k^2 dt,$ (7.24.47)
```

where from Eq. (7.24.44)

```
$\frac{\partial \phi}{\partial F_k} = \frac{\tau}{1 + \tau F_k}, \frac{\partial^2 \phi}{\partial F_k^2} = \frac{-2\tau}{(1 + \tau F_k)^3}$ (7.24.48)
```

Substituting the values in Eq. (7.24.48) into Eq. (7.24.47) we obtain:

```
$d\phi = - \frac{\tau \phi}{1 + \tau F_k} [F_k \mu_k dt + F_k \sigma_k dW^{k-1}] + \frac{\tau^2 \phi \sigma_k^2 F_k^2}{2(1 + \tau F_k)^2}$ (7.24.49)
```

which can be rearranged as:

```
$d\phi = - \left( \frac{\tau F_k \mu_k \phi}{1 + \tau F_k} + \frac{\phi \phi \sigma_k^2 F_k^2}{(1 + \tau F_k)^2} \right) dt - \frac{\tau \phi \sigma_k}{1 + \tau F_k} dW^{k-1}$
```

Now since Eq. (7.24.49) is driftless

```
$\left( \frac{\tau F_k \mu_k \phi}{1 + \tau F_k} + \frac{\phi \phi \sigma_k^2 F_k^2}{(1 + \tau F_k)^2} \right) dt = 0$
```

and

```
$\mu_k = - \frac{\tau \sigma_k^2 F_k}{1 + \tau F_k}$ (7.24.50)
```
