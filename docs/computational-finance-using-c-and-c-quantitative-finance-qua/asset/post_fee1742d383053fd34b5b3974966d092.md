```

First let us compute $Y_t^2$.

```
$Y_t^2 = \left(\frac{\sqrt{t_1-t_0}Z_t - \sqrt{t-t_0}X_t}{\sqrt{t_1-t}}\right)^2
```

so

```
$Y_t^2 = \frac{(t_1-t_0)Z_t^2+(t-t_0)X_t^2-2\sqrt{t_1-t_0}\sqrt{t-t_0}X_tZ_t}{t_1-t} \quad (2.8.6)
```

Next we compute $X_t^2+Y_t^2-Z_t^2$ as follows

```
$X_t^2+Y_t^2-Z_t^2 = \frac{(t_1-t_0)X_t^2+(t-t_0)Z_t^2-2\sqrt{t_1-t_0}\sqrt{t-t_0}X_tZ_t}{t_1-t} \quad (2.8.7)
```

Dividing top and bottom of Eq. (2.8.7) by $t_1-t_0$ we obtain:

```
$X_t^2+Y_t^2-Z_t^2 = \frac{X_t^2+((t-t_0)/(t_1-t_0))Z_t^2-2\sqrt{(t_1-t_0)/(t_1-t_0)}\sqrt{(t-t_0)/(t_1-t_0)}X_tZ_t}{(t_1-t_0)/(t_1-t_0)} = \frac{X_t^2+((t-t_0)/(t_1-t_0))Z_t^2-2\sqrt{(t-t_0)/(t_1-t_0)}X_tZ_t}{(t_1-t_0)/(t_1-t_0)}
```

which gives

```
$X_t^2+Y_t^2-Z_t^2 = \frac{(X_t-\sqrt{(t-t_0)/(t_1-t_0)}Z_t)^2}{(t_1-t_0)/(t_1-t_0)} \quad (2.8.8)
```

where we have used

```
$(X_t-\sqrt{\frac{t_1-t_0}{t_1-t_0}}Z_t)^2 = X_t^2+\frac{t-t_0}{t_1-t_0}Z_t^2-2\sqrt{\frac{t-t_0}{t_1-t_0}}X_tZ_t$,
```

Substituting Eq. (2.8.8) into Eq. (2.8.5) yields

```
$P(X_t|Z_t) = \frac{1}{\sqrt{2\pi}} \exp\left{\frac{(X_t-\sqrt{(t-t_0)/(t_1-t_0)}Z_t)^2}{2(t_1-t)/(t_1-t_0)}\right\}
```

Therefore $P(X_t|Z_t)$ is a Gaussian distribution with:

```
$E[X_t] = \sqrt{\frac{t-t_0}{t_1-t_0}} Z_t \quad \text{and} \quad Var[X_t] = \frac{t_1-t}{t_1-t_0}$
```

Substituting for $Z_t$ we have

```
$E[X_t] = \sqrt{\frac{t-t_0}{t_1-t_0}} Z_t = \sqrt{\frac{t-t_0}{t_1-t_0}} W_{t_1} - \sqrt{\frac{t_1-t}{t_1-t_0}} W_{t_0}
```

which gives:

```
$E[X_t] = \sqrt{\frac{t-t_0}{t_1-t_0}} (W_{t_1} - W_{t_0}) \quad (2.8.9)
```

The variate $\bar{X}_t = E[X_t] + \sqrt{Var[X_t]}Z_t$ has the same distribution as $P(X_t|Z_t)$. So we can substitute $\bar{X}_t$ for $X_t$ in Eq. (2.8.1) to obtain:

```
$W_t = W_{t_0} + \sqrt{t-t_0}[E[X_t] + \sqrt{Var[X_t]}Z_t]$
```

which gives:

```
$W_t = W_{t_0} + \sqrt{t-t_0} \left\{ \sqrt{\frac{t-t_0}{t_1-t_0}}(W_{t_1} - W_{t_0}) + \sqrt{\frac{t_1-t}{t_1-t_0}}Z_t\right\}$
```

and simplifying we get

```
$W_t = W_{t_0} \frac{t_1-t_0}{t_1-t_0} + \frac{t-t_0}{t_1-t_0}(W_{t_1} - W_{t_0}) + \sqrt{\frac{(t_1-t)(t-t_0)}{t_1-t_0}}Z_t \quad (2.8.10)
```

Variates, $W_t$, from the distribution $P(W_t|\{W_0, W_1\})$ can be generated using

```
$W_t = W_{t_0} \frac{t_1-t}{t_1-t_0} + W_{t_1} \frac{t-t_0}{t_1-t_0} + \sqrt{\frac{(t_1-t)(t-t_0)}{t_1-t_0}}Z_t \quad (2.8.11)

# 2.9 Time-transformed Brownian motion

Let us consider the Brownian motion:

```
$dW_t = \sigma \sqrt{dt} dZ_t \quad (2.9.1)
```

and the scaled and time-transformed Brownian motion

```
$Y_{W,t} = a_t W_t \quad (2.9.2)
```

where the scale factor, $a_t$, is a real function and the time transformation, $f_t$, is a continuous increasing function satisfying $f_t \geqslant 0$; see Cox and Miller (1965).

Using Ito's lemma,

```
$dY_{W,t} = \frac{\partial Y_t}{\partial t} dt + \frac{\partial Y_t}{\partial W_t} dW_t \quad (2.9.3)
```

where we used the fact that $\frac{\partial^2 Y_t}{\partial W_t^2} = 0.$

From Eq. (2.9.3)

```
$dY_{W,t} = \left(\frac{\partial a_t}{\partial t}\right) W_{f,t} dt + a_t dW_{f,t} \quad (2.9.4)
```

Now

```
$dW_{f,t} = \sqrt{df_t} dZ_t = \sqrt{\frac{\partial f_t}{\partial t}} dtZ_t \quad (2.9.5)
```

so we can write:

```
$dY_{W,t} = a'_t W_{f,t} + a_t \sqrt{f'_t} dt dZ_t \quad (2.9.6)
```

where

$a'_t = \frac{\partial a_t}{\partial t} \quad \text{and} \quad f'_t = \frac{\partial f_t}{\partial t}$

# 2.9.1 Scaled Brownian motion

We will prove that $\widehat{W}_t$ defined by

$\widehat{W}_t = \frac{1}{c}W_{c^2t}, \quad c > 0,$

is Brownian motion.

Let us consider the process

$Y_t = W_{c^2t}$

From Eq. (2.9.2) we have $a_t = 1, f_t = c^2t, a'_t = 0$ and $f'_t = c^2$. Substituting these values into Eq. (2.9.6), yields

$dY_t = \sqrt{c^2}dt dZ_t$

which gives

$dY_t = c\sqrt{dt}dZ_t = c dW_t$

Therefore $\widehat{W}_t = dY_t/c$ is Brownian motion.

# 2.10 Ornstein-Uhlenbeck process

The Ornstein-Uhlenbeck process is often used to model interest rates because of its mean reverting property. It is defined by the equation

$dX_t = -\alpha X_t dt + \sigma dW_t \quad (2.10.1)$

Using the integrating factor $exp(\alpha t)$ we have:

$exp(\alpha t) dX_t = -\alpha X_t exp(\alpha t) dt + \sigma exp(\alpha t) dW_t$

so

$exp(\alpha t) dX_t + \alpha X_t exp(\alpha t) dt = \sigma exp(\alpha t) dW_t \quad (2.10.2)$

# Introduction to stochastic processes

Using the product rule we have:

$d(X_t \exp(\alpha t)) = \exp(\alpha t) dX_t + \alpha X_t \exp(\alpha t) dt \quad (2.10.3)$

Integrating Eq. (2.10.3) gives

$X_t \exp(\alpha t) - X_0 = \sigma \int_0^t \exp(\alpha s) dW_s \quad (2.10.4)$

which yields

$X_t = X_0 \exp(-\alpha t) + \sigma \int_0^t \exp(-\alpha(t-s)) dW_s \quad (2.10.5)$

$X_t = X_0 \exp(-\alpha t) + \sigma \int_0^t \exp(-\alpha(t-s)) dW_s \quad (2.10.6)$

# The mean

$E[X_t] = E[X_0 \exp(-\alpha t) + \sigma \int_0^t \exp(-\alpha(t-s)) dW_s] = X_0 \exp(-\alpha t) \quad (2.10.7)$

# The variance

$Var[X_t] = E[\{X_t - E[X_t]\}^2] = E[\{\sigma \int_0^t \exp(-\alpha(t-s)) dW_s\}^2] = \sigma^2 \int_0^t \exp(-2\alpha(t-s)) ds \quad (2.10.8)$

$Var[X_t] = \sigma^2 \left[ \frac{\exp(-2\alpha(t-s))}{2\alpha} \right]_0^t = \frac{\sigma^2}{2\alpha} (1 - e^{-2\alpha t}) \quad (2.10.9)$

As $t \to \infty$, $Var[X_t] \to \frac{\sigma^2}{2\alpha} \quad (2.10.10)$
