In the case when $N(d_1) = N(d_2) = 1$ (i.e., there is no uncertainty) Eq. (7.3.13) becomes:

```
$$C_b(t) = P^f \{-X_b^f(t)DF^f(t, T) - KX_b^d(t)DF^d(t, T)\}$$$
```

which is the same as that already given in Eq. (7.3.4) for the FX forward.

FX put

The time $t$ value of the corresponding put in units of base currency:

```
$$P_b(t) = P^f \{-X_b^f(t)DF^f(t, T)N(-d_1) + KX_b^d(t)DF^d(t, T)N(-d_2)\}$$$
```

where the symbols have the same meanings as for the FX call.

# 7.4 Credit derivatives

Credit derivatives take into account the fact that a counterparty may not honor (for reasons of bankruptcy, etc.) the obligations set out in a given financial contract. To obtain the time $t$ value of these derivatives it is necessary to determine the probability that the counterparty (and thus the contract) will survive until some future time $T > t$. Here we will denote the survival probability between times $t$ and $T$ by $S(t, T)$, and we compute its value from the hazard rate.

The hazard rate

As previously mentioned the survival probability between times $t$ and $T$, where $T > t$, is denoted by $S(t, T)$. This means the probability of default between times $t$ and $T$ is:

```
$$P_{def}(t, T) = 1 - S(t, T)$$$
```

and the probability of default, as seen from time $t$, between times $T_1$ and $T_2$ is:

```
$$P_{def}(t, T_1, T_2) = S(t, T_1) - S(t, T_2), \quad T_2 > T_1$$$
```

The time $t$ discrete hazard rate between times $T$ and $T + \Delta T$, denoted by:

```
$$H(t, T, T + \Delta T) = \frac{1 \cdot P_{def}(t, T, T + \Delta T)}{\Delta T} \frac{1 \cdot S(t, T) - S(t, T + \Delta T)}{\Delta T}$$$
```

which means that

```
$$H(t, T, T + \Delta T) = \frac{S(t, T + \Delta T) - S(t, T)}{\Delta T} \frac{1}{S(t, T + \Delta T)} \quad (7.4.2)$$$
```
