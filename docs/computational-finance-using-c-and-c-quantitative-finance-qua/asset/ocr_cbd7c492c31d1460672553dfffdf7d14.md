# Appendix J: Answers to problems

# 7(a)

$\phi = \log(S)$ then using Ito's formula we have

```
$d\phi = \frac{\partial \phi}{\partial S}dS + \frac{1}{2}\frac{\partial^2 \phi}{\partial S^2}E[(dS)^2] = \frac{1}{S}(\mu_t S_t dt + \sigma_t dW_t) - \frac{1}{2S^2}\sigma_t^2 dt$
```

So

```
$d(\log(S_t)) = \left(\\mu_t - \frac{\sigma_t^2}{2}\right)dt + \sigma_t dW_t$
```

and therefore

```
$\int_{\	au=0}^t d(\log(S_tau)) = \int_{\	au=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau + \int_{\	au=0}^t \sigma_	au dW_	au$
```

which gives

```
$\log(S_t) - \log(S_0) = \int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau + \int_{\tau=0}^t \sigma_	au dW_	au$
```

Taking expectations we obtain

```
$E[\log(S_t) - \log(S_0)] = E\left[\int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau\right] + E\left[\int_{\tau=0}^t \sigma_	au dW_	au\right]$
```

Since $\int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau$ is deterministic

```
$E\left[\int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau\right] = \int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau$
```

and using

```
$E\left[\int_{\tau=0}^t \sigma_	au dW_	au\right] = 0$
```

and

```
$E[\log(S_0)] = \log(S_0)$
```

we finally obtain

```
$E[\log(S_t)] = \log(S_0) + \int_{\tau=0}^t \left(\\mu_	au - \frac{\sigma_	au^2}{2}\right)d\tau$
```
