### D.1.1 Some elementary results involving the mean and variance of a normal distribution

From first principles we have:

- The mean:

$E[x] = \frac{1}{\sqrt{2\pi}} \int_{x=-\infty}^{x=\infty} x exp(-\frac{(x-\mu)^2}{2\sigma^2}) dx$

Letting $y = x - \mu$ we have $dx = dy$ and $x = y + \mu$; therefore:

$E[x] = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} (y+\mu) exp(-\frac{y^2}{2\sigma^2}) dy$

$E[x] = \mu \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} exp(-\frac{y^2}{2\sigma^2}) dy + \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} y exp(-\frac{y^2}{2\sigma^2}) dy$

Since

$$\int_{-\infty}^{\infty} y exp(-\frac{y^2}{2\sigma^2}) dy = 0$$

we have the integral result (i) in Section E.1 with $a=1/(2\sigma^2)$:

$E[x] = \mu \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} exp(-\frac{y^2}{2\sigma^2}) dy = \mu$

- The variance:

$E[x^2] = \frac{1}{\sqrt{2\pi}} \int_{x=-\infty}^{x=\infty} x^2 exp(-\frac{(x-\mu)^2}{2\sigma^2}) dx$

Letting $y = x - \mu$ we have $dx = dy$ and $x^2 = y^2+2y\mu+\mu^2$; therefore:

$E[x^2] = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=\infty} (y^2+2y\mu+\mu^2) exp(-\frac{y^2}{2\sigma^2}) dy$

$E[x^2] = \mu^2 \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} exp\left(-\frac{y^2}{2\sigma^2}\right) dy + \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y^2 exp\left(-\frac{y^2}{2\sigma^2}\right) dy$

So

$E[x^2] = \mu^2 + \sigma^2$

where we used (see Section E.1 result (ii) with $a=1/(\sigma^2)$) that

$\frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y^2 exp\left(-\frac{y^2}{2\sigma^2}\right) dy = \sigma^2$

Therefore:

$Var[x] = E[x^2] - (E[x])^2 = \mu^2 + \sigma^2 - \mu^2 = \sigma^2$

The mean and variance can also be obtained by the moment generating function, $M_x(t)$.

From Section C.5:

$E[x] = \frac{dM_x(t)}{dt}|_{t=0} = \frac{d}{dt} exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)|_{t=0} = (\mu + \sigma^2 t) exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)|_{t=0} = \mu$

also

$E[x^2] = \frac{d^2M_x(t)}{dt^2}|_{t=0} = \frac{d}{dt} \left((\mu + \sigma^2 t) exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)\right)|_{t=0}$

$E[x^2] = \left\{exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)(\mu + \sigma^2 t)^2 + \sigma^2\right\}_{t=0} = \mu^2 + \sigma^2$

These results are the same as those we previously derived from first principles:

$E[x] = \mu$ and $E[x^2] = \mu^2 + \sigma^2$

## D.2 The lognormal distribution

If the variable $x$ follows a lognormal distribution then the probability density function $f(x)$ is given by:

$f(x) = \frac{1}{x\sigma\sqrt{2\pi}} exp\left(-\frac{(\log(x)-\mu)^2}{2\sigma^2}\right), x>0$. Here we denote the lognormal distribution for $x$ as $x \sim \Lambda(\mu, \sigma^2)$. Setting $y = \log(x)$ it can be seen that $y \sim N(\mu, \sigma^2)$. Conversely if $y \sim N(\mu, \sigma^2)$ then the distribution for $x = e^y$ is $x \sim \Lambda(\mu, \sigma^2)$.

$E[x'] = \int \frac{1}{\sigma\sqrt{2\pi}} exp\left(-\frac{(\log(x')-\mu)^2}{2\sigma^2}\right) dx'$

Using $y = \log(x)$ we have:

$\frac{dy}{dx} = \frac{1}{x}, \quad dx = x dy, \quad x' = e^y$

Thus,

$E[x'] = E[e^y] = M_y(1) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} e^{y} exp\left(-\frac{(y-\mu)^2}{2\sigma^2}\right) dy$

where $M_y(t)$ is the moment generating function of a normal distribution with mean $\mu$ and variance $\sigma^2$.

From Section D.1:

$M_y(t) = \exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)$

Therefore $x \sim \Lambda(\mu, \sigma^2)$ then:

for $t = 1$, $E[x] = \exp\left(\mu + \frac{\sigma^2}{2}\right)$ (D.2.2)

for $t = 2$, $E[x^2] = \exp(2\mu + 2\sigma^2)$ (D.2.3)

and the variance is obtained using

$Var[x] = E[x^2] - (E[x])^2 = \exp(2\mu + 2\sigma^2) - \exp\left(\mu + \frac{\sigma^2}{2}\right)^2$

So

$Var[x] = \exp(2\mu + 2\sigma^2)(\exp(\sigma^2) - 1)$

or

$Var[x] = (E[x])^2(\exp(\sigma^2) - 1)$ (D.2.4)

Note. If $x_1 = \exp(\mu + Z)$, where $Z \sim N(0,1)$ then $x_1 \sim \Lambda(\mu, \sigma^2)$. So $E[x_1]$ and $Var[x_1]$ are given by Eqs. (D.2.2) and (D.2.4).

## D.3 The Student’s $t$ distribution

This section derives an expression for the kurtosis of the Student’s $t$ distribution.

Since the Student’s $t$ density function is:

$f(\epsilon_i) = \mathcal{K} \left[1 + \frac{\epsilon_i^2}{h_i(\nu-2)}\right]^{-(\nu+1)/2}$

where

$$\mathcal{K} = \frac{\Gamma((\nu+1)/2)(\nu-2)^{-1/2}}{\pi^{1/2}}h_i^{-1/2}$$

we have:

$E[\epsilon_i^2] = 2\mathcal{K} \int_{0}^{\infty} \frac{\epsilon_i^2 d\epsilon_i}{(1+\epsilon_i^2/(h_i(\nu-2)))^{(\nu+1)/2}} = 2\mathcal{K}(h_i(\nu-2))(\nu+1)/2} \int_{0}^{\infty} \frac{\epsilon_i^2 d\epsilon_i}{(h_i(\nu-2))+\epsilon_i^2)^{(\nu+1)/2}}$

Using the standard integrals in Section E.1 with $a=2, b=2, c=(\nu+1)$ and $m=(\nu-2)h_i$:

$$\frac{m^{(a+1-bc)/b}}{b} = \frac{(h_i(\nu-2))(\nu-2)/2}}{2}, \quad \Gamma\left(\frac{a+1}{b}\right) = \Gamma\left(\frac{3}{2}\right)$$
$$\Gamma\left(c-\frac{a+1}{b}\right) = \Gamma\left(\frac{\nu-2}{2}\right)$$

This gives

$E[\epsilon_i^2] = 2\mathcal{K}(h_i(\nu-2))(\nu+1)/2} \left{\frac{(h_i(\nu-2))(\nu-2)/2}\sqrt{\pi}\Gamma((\nu-2))}{4\Gamma((\nu+1)/2)}\right\}$

Substituting for $\mathcal{K}$ and simplifying we obtain

$E[\epsilon_i^2] = \frac{h_i(\nu-2)\Gamma((\nu-1)/2)}{\Gamma(\nu/2)}$

But

$\Gamma\left(\frac{\nu-2}{2}\right)\Gamma\left(\frac{\nu+1}{2}\right) = \Gamma\left(\frac{\nu}{2}\right)$

So

$E[\epsilon_i^2] = \frac{h_i(\nu-2)\Gamma(\nu/2)}{2(\nu-2)} = h_i$

Similarly we have:

$E[\epsilon_i^4] = 2\mathcal{K} \int_{0}^{\infty} \frac{\epsilon_i^4 d\epsilon_i}{(1+\epsilon_i^2/h_i(\nu-2))^{(\nu+1)/2}} = 2\mathcal{K}(h_i(\nu-2))(\nu+1)/2} \int_{0}^{\infty} \frac{\epsilon_i^4 d\epsilon_i}{(h_i(\nu-2))+\epsilon_i^2)^{(\nu+1)/2}}$

Using the standard integrals in Section E.1 with $a=4, b=2, c=(\nu+1)$, and $m=(\nu-2)h_i$ gives:

$$\frac{m^{(a+1-bc)/b}}{b} = \frac{(h_i(\nu-2))^{(nu-2)/2}}{2}, \quad \Gamma\left(\frac{a+1}{b}\right) = \Gamma\left(\frac{5}{2}\right)$$
$$\Gamma\left(c-\frac{a+1}{b}\right) = \Gamma\left(\frac{\nu-4}{2}\right), \quad \Gamma(c) = \Gamma\left(\frac{\nu+1}{2}\right)$$

and

$E[\epsilon_i^4] = 2\mathcal{K}(h_i(\nu-2))(\nu+1)/2} \left\{ \frac{(h_i(\nu-2))^{(4-v)/2}\sqrt{\pi}\Gamma((\nu-4))}{8\Gamma((\nu+1)/2)}\right\}$

Substituting $K$ and simplifying we obtain

$E[\epsilon_i^4] = \frac{3h_i(\nu-2)^2\Gamma((\nu-4)/2)}{4\Gamma(\nu/2)}$

But

$\Gamma\left(\frac{\nu-4}{2}\right)\Gamma\left(\frac{\nu-2}{2}\right) = \Gamma\left(\frac{\nu}{2}\right)$

Therefore:

$$\Gamma\left(\frac{\nu-4}{2}\right) = \frac{4\Gamma(\nu/2)}{\Gamma(\nu-2)}$$

So

$E[\epsilon_i^4] = \frac{3(\nu-2)^2h_i^2}{4\Gamma(\nu/2)(\nu-4)} = \frac{3(\nu-2)h_i^2}{\nu-4}$

The kurtosis is then:

$$\kappa = \frac{E[\epsilon_i^4]}{(E[\epsilon_i^2])^2} = \frac{3(\nu-2)h_i^2}{(\nu-4)h_i^2} = \frac{3(\nu-2)}{\nu-4} \quad (D.3.1)$$

## D.4 The general error distribution

This section proves various relations for the generalized error distribution.
The density function for the generalized error distribution is:

$f(\epsilon_i) = \mathcal{K} \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) \text{ where } \mathcal{K} = \frac{a}{\lambda 2^{(1+1/a)}}\Gamma(1/a)} \quad (D.4.1)$

### D.4.1 Value of $\lambda$ for variance $h_i$

Calculation of the scale factor $\lambda$ required for a generalized error distribution with mean zero and variance $h_i$.
The variance of the distribution, $E(\epsilon_i^2)$, is given by:

$E(\epsilon_i^2) = \mathcal{K} \int_{-\infty}^{\infty} \epsilon_i^2 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i = 2\mathcal{K} \int_{0}^{\infty} \epsilon_i^2 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i$

Using the standard integrals in Section E.1 with $n=2, p=a$, and $b=\frac{1}{2}(\lambda)^a$ gives:

$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\frac{3}{a} \left(\frac{1}{2}\lambda\right)\right)^{-3/a}$

which after some simplification yields

$h_i = \frac{2\mathcal{K}^{2/a}\lambda^2}{a} \Gamma\left(\frac{3}{a}\right)$

### D.4.2 The kurtosis

$E(\epsilon_i^4) = \mathcal{K} \int_{-\infty}^{\infty} \epsilon_i^4 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i = 2\mathcal{K} \int_{0}^{\infty} \epsilon_i^4 \exp\left(-\frac{1}{2} \left|\frac{\epsilon_i}{\lambda}\right|^a\right) d\epsilon_i$

However, from standard mathematical tables:

$$\int_{0}^{\infty} \epsilon_i^4 \exp(-b\epsilon_i^p) = \frac{\Gamma(k)}{pb^k}$$

where $p=a, b=\frac{1}{2}(\lambda)^a$, and $k=5/a$ which gives

$E(\epsilon_i^4]) = \frac{2\mathcal{K}^{2/a}\lambda^5}{a} \Gamma\left(\frac{5}{a}\right)$

Substituting $K$ and simplifying we obtain

$E[\epsilon_i^4] = \frac{3h_i(\nu-2)^2\Gamma((\nu-4)/2)}{4\Gamma(\nu/2)}$

But

$\Gamma\left(\frac{\nu-4}{2}\right)\Gamma\left(\frac{\nu-2}{2}\right) = \Gamma\left(\frac{\nu}{2}\right)$
