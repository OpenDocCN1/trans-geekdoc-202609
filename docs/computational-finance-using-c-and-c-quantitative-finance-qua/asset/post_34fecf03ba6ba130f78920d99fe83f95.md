## 4.5.4 Monte Carlo pricing of down and out options

In this section we show how Monte Carlo simulation can be used to price down and out barrier options. We will describe both a basic Monte Carlo approach and a Brownian bridge method which gives a more accurate results (see Chapter 8).

The asset price, $S$, will be assumed to be GBM, so the logarithm of the asset price $X$ follows the Brownian process:

```
$\Delta X = \nu\Delta t + \sigma\Delta W_t \quad (4.5.18)$
```

where $\nu$ is the drift and $\sigma$ is the volatility.

If the barrier level is $B$ the option will be knocked out when $S \le B$, or equivalently $\log(S) \le \log(B)$. This will be expressed as $X \le b$, where $b = \log(B)$.

The basic approach to simulating the down and out option is to first decide many scenarios and also how many TimeSteps are to be in each scenario. The size of each time step is $time\_step = TimeTimeToExpiry/TimeSteps$. For each scenario the path of $X_t$ is advanced in time $t$ to $t + \Delta t$ using Eq. (4.5.18), with $dr = time\_step$ and a value for $W_t$, from a Gaussian random number generator. Path construction is stopped if either the option expiry time is reached or if the option is knocked out before—i.e., $X \le b$. The option is knocked out before the payoff for that scenario is zero. We will denote the option value obtained from the $i$th scenario by $DO_i$ where $i=1, \dots$. Scenarios. The option value is the average of $DO_i$ over all scenarios; for more details see Code excerpt 4.8.

One problem with this approach is that it does not take into account the possibility that $X_T \le b, t < \tau < t + \Delta t$, even though $X_t > b$ and $X_{t+\Delta t} > b$. In these circumstances the option would be knocked out, since $X$ hit (or crossed) the barrier $b$ at time $\tau$, but then increased to the value of $X_{t+\Delta t}$ at time $t + \Delta t$.

We will now discuss the Brownian bridge method deals with this situation. We take two time points $t_1$ and $t_2 = t_1 + \Delta t$, and assume that both $X_{t_1}$ and $X_{t_2}$ are above the (logarithmic) barrier level $b$. We want to find the probability that in the time interval $[t_1, t_2]$, the asset price went lower than $B$, and use this to get more accurate values for down and out options. The required barrier crossing probability is thus:

$P(m_{t_1}^{t_2} \le b|X_{t_1}, X_{t_2}) =$

where $m_{t_1}^{t_2}$ denotes the minimum of $X$ over the time interval $[t_1, t_2]$. The probability density of $X_{t_2}$ conditional on $X_{t_1}$ is:

$p(X_{t_2}|X_{t_1}) = \frac{1}{\sigma\sqrt{2\pi\Delta t}} \exp\left(-\frac{(X_{t_2} - X_{t_1})^2}{2\sigma^2\Delta t}\right)$

where $\Delta t = t_2 - t_1$. From Bayes law we know that:

$p(m_{t_1}^{t_2} \le b|X_{t_1}, X_{t_2}) = \frac{p(m_{t_1}^{t_2} \le b, X_{t_2})}{p(X_{t_2}|X_{t_1})}$

We show in Appendix I that

$p(m_{t_1}^{t_2} \le b|X_{t_1}) = \frac{1}{\sigma\sqrt{2\pi\Delta t}} \exp\left(\frac{2(b - X_{t_1})}{\sigma^2}\right) \dots$ (Note: original text has fragmented formulas here)

We will use some algebra to simplify this expression:

$P(m_{t_1}^{t_2} \le b|X_{t_2}, X_{t_1}) = \exp\left\{\frac{4\nu\Delta t(b - X_{t_1}) - (X_{t_2} - X_{t_1})^2 - 2(b - X_{t_1})^2}{2\sigma^2\Delta t}\right\}$
$= \exp\left\{\frac{4\nu\Delta t(b - X_{t_1}) + 2(b - X_{t_1})(X_{t_2} - X_{t_1}) + 4(b - X_{t_1})^2}{2\sigma^2\Delta t}\right\}$
$= \exp\left\{\frac{2(b - X_{t_1})(X_{t_2} + \dots)}{\sigma^2\Delta t}\right\}$

which yields

$P(m_{t_1,t_2}^{\log(S)} \le b|\log(S_{t_2})) = \exp\left\{\frac{2(\log(B) - \log(S_{t_1}))(\log(B) - \log(S_{t_2}))}{\sigma^2\Delta t}\right\} (4.5.19)$

Equation (4.5.19) gives the probability of the option having been knocked out between times $t_1$ and $t_2$ even though the asset prices $S_{t_1}$ and $S_{t_2}$ are greater than $B$. The probability that the option hasn't been knocked out between times $t_1$ and $t_2$ is therefore:

$P(m_{t_1,t_2}^{\log(S)} > b|\log(S_{t_2})) = 1 - \exp\left\{\frac{2(\log(B) - \log(S_{t_1}))(\log(B) - \log(S_{t_2}))}{\sigma^2\Delta t}\right\} (4.5.20)$

This means that for the (complete) $i$th scenario path, of $n$ time steps, the probability that $m^{\log(S)} > b$ is

$BB_i^n = \prod_{j=0}^{n-1} \left\{1 - \exp\left\{\frac{2(\log(B) - \log(S_{t_j}^i))(\log(B) - \log(S_{t_{j+1}}^i))}{\sigma^2\Delta t}\right\}\right\}$

$S_{t_j}^i$ is the $i$th scenario asset price at time $t_j$.

The basic Monte Carlo $i$th scenario option value $DO_i$ can therefore be adjusted as follows

$DO_i^n = DO_i BB_i^n$

and the new Monte Carlo estimate $DO^*$ is

$DO^* = \sum_{i=1}^{Scenarios} DO_i^*$

where more details can be found in Code excerpt 4.8.
