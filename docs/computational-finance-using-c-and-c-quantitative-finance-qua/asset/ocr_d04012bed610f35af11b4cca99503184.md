# ## E.1 Standard integrals

$\int_{0}^{\infty} \exp(-ay^2) dy = \frac{1}{2}\sqrt{\frac{\pi}{a}}$ \quad (i)

$\int_{0}^{\infty} y \exp(-ay^2) dy = \frac{1}{2}$ \quad (ii)

$\int_{0}^{\infty} y^2 \exp(-ay^2) dy = \frac{1}{4a}\sqrt{\frac{\pi}{a}}$ \quad (iii)

$\int_{0}^{\infty} y^4 \exp(-ay^2) dy = \frac{3}{8a^2}\sqrt{\frac{\pi}{a}}$ \quad (iv)

$\int_{0}^{\infty} y^{2n} \exp(-ay^2) dy = \frac{1 	imes 3 	imes 5 	imes \cdots 	imes (2n-1)}{2^{n+1}a^n}\sqrt{\pi}$ \quad (v)

$\int_{0}^{\infty} \epsilon_i^n \exp(-b\epsilon_i^p) = \frac{\Gamma(k)}{pb^k}$ \quad (vi)

where $n > -1, p > 0, b > 0$ and $k = \frac{n+1}{p}$

$\int_{0}^{\infty} \epsilon_i^a d\epsilon_i (m+\epsilon_i^b)^c = \frac{m^{(a+1-bc)/b}\Gamma((a+1)/b)\Gamma(c-(a+1)/b)}{b\Gamma(c)}$ \quad (vii)

where $a > -1, b > 0, m > 0$ and $c > \frac{a+1}{b}$
