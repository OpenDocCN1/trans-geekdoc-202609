# 7.2.2 Interest rate swap

Interest Rate Swaps (IRS) are very common financial instruments—it is not uncommon for 80 percent of the trades in a portfolio to be IRS deals. Here we will provide a description of some of the characteristics of interest rate swaps; more detail can be found in Hull (2003).

A vanilla IRS consists of a strip of FRA trades, each FRA starting when the previous FRA finishes. The maturity date of the IRS corresponds to the maturity date of the FRA.

Let the start of the FRAs be $t_i, i = 0, \dots, n-1$, and the maturity times of the FRAs be $t_i, i = 1, \dots, n$; note that the FRA start corresponds to the forward rate reset times, and the maturity times correspond to the FRA payment times. We will now adopt the (common) convention of calling the trades *swaps*, so an IRS is made up of a number of swaps.

When the counterparty A pays the fixed rate and receives the floating rate (from A perspective) it is a payer IRS. Alternatively, if A receives the fixed rate and pays the floating rate, the term is a receiver IRS.

The value of an IRS at time $t_k$, where $t_{k-1} < t < t_k$, will be considered. We will assume that discount factors used to compute the forward rates and those used to discount the coupon payments are associated with the same yield curve. Using Eq. (7.2.10) we have

```
$IRS(t) = CDF(t, t_k) + \sum_{i=k+1}^n DF(t, t_i)\tau_i[K - F(t, t_{i-1}, t_{i-1} + \tau_i)]$

(7.2.11)
```

where $C$ is the *next coupon payment* after current time $t$ (this occurs at time $t_k$), and $	au_i$ is the tenor of the $i$-th swap which starts at time $t_{i-1}$ and ends at time $t_i$.

Note that the next coupon payment $C$ for the swapping starting at time $t_{k-1}$ and maturing at time $t_k$ is already known with certainty at time $t$ because the forward rate $F(t, t_{k-1}, t_k)$ was reset in the past; $t_{k-1} < t$.

We will now rewrite Eq. (7.2.11) as:

```
$IRS(t) = CDF(t, t_k) + FXD(t) - FLT(t)$

(7.2.12)
```

where $FXD(t)$, the time value of the fixed leg is,

```
$FXD(t) = PK \sum_{i=k+1}^n DF(t, t_i)\tau_i$

(7.2.13)
```

and $FLT(t)$, the time value of the floating leg is,

```
$FLT(t) = P \sum_{i=k+1}^n DF(t, t_i)\tau_i F(t, t_{i-1}, t_{i-1} + \tau_i)$$

(7.2.14)
```
