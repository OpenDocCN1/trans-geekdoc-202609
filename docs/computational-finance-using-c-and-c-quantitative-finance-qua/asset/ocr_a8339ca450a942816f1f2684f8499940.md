The conditional distribution of $x_1$ given the value of $x_2$ is thus obtained by dividing this density by the marginal density of $x_2$, and treating $x_2$ as a constant in the resulting expression. The only portion of the resultant that is not constant is the portion involving terms in $x_1$. It can be easily seen that:

```
$f(x_1|x_2) = \exp\left[-\frac{1}{2}(x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + 2(x_2-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)\right]$
```

where the constant of proportionality is obtained using $\int f(x_1|x_2) dx = 1$. If we let $\mathcal{G} = (x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + 2(x_2-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)$ then we obtain:

```
$$\mathcal{G} = (x_1-\mu_1)^\top\Sigma^{11}(x_1-\mu_1) + (x_1-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)$
$+(x_2-\mu_1)^\top\Sigma^{21}(x_1-\mu_1)$
$$\mathcal{G} = \x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\}^top$\n$$\times \Sigma^{11}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)}\$\n$$-(x_2-\mu_1)^\top\Sigma^{21}(\Sigma^{12})^{-1}(x_2-\mu_2)$ \quadquad (C.4.11)$
```

where, we have used the scalar quantity $\{(x_1-\mu_1)^\top\Sigma^{12}(x_2-\mu_2)\} = (x_2-\mu_2)^\top\Sigma^{21}(x_1-\mu_1)$

Since the last term in Eq. (C.4.11) only involves constants (as far as $f(x_1|x_2)$ is concerned), it follows that:

```
$f(x_1|x_2) = \exp\left[-\frac{1}{2}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)\}\right]^top$\n$$\times \Sigma^{11}\{x_1-\mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)}\}$
```

which is the density of a multivariate distribution that has a mean of $\mu_1 - (\Sigma^{11})^{-1}\Sigma^{12}(x_2-\mu_2)$, from which Eq. (C.4.7) can be expressed as $\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2-\mu_2)$. The covariance matrix is $(\Sigma^{11})^{-1}$, which from Eq. (C.4.9) can be written as $\Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$.

# C.5 Moment generating functions

If $x$ is a random variable with probability distribution $f_x(x)$ then the moment generating function $M_x(t)$ is defined by:

```
$M_x(t) = E[e^{tx}] = \int_{-\infty}^{\infty} e^{tx} f_x(x) dx$
```
