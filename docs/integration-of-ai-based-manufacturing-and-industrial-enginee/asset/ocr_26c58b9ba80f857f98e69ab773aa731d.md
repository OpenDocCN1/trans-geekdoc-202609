recall = TP / (TP + FN)

The F1 measures harmonic mean of precision and recall, more accurately, the model's performance.

F1 = 2 * precision * recall / (precision + recall)

The high accuracy is predicting who will churn which is computed between the observed values to the predicted values.

accuracy = (TP + TN) / (TP + TN + FP + TN)
