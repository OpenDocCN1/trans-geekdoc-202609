EY (≥, ≈, ≲) a reflects a set of constraints in the vector notation.

The membership function in a fuzzy decision-making condition is actually achieved by trying to define allowed variations of up and down, and the kind of membership function is influenced by the nature of the goal. If the goal is not implemented fully, the decision-maker is comfortable up to a certain tolerable limit, according to the aspirational level of the fuzzy goal in (4.1). According to Zimmermann, a linear membership function, μ_l, can indeed be asserted (Zimmermann, 1976, 1978).

The limitation of the type ≥, μ_l will be algebraically framed as follows:

```
μ_l = 
1 if M_l(Y) ≥ P_l 
(M_l(Y) - L_l)/(P_l - L_l) if L_l ≤ M_l(Y) ≤ P_l 
0 if M_l(Y) ≤ L_l 
(4.3)
```

Here L_l denotes the least tolerance limit for the fuzzy goal M_l(Y).

```
μ_l = 
1 if M_l(Y) ≤ P_l 
(U_l - M_l(Y))/(U_l - P_l) if P_l ≤ M_l(Y) ≤ U_l 
0 if H_l(Y) ≥ U_l 
(4.4)
```

Here U_l represents the higher tolerance limit for the fuzzy goal M_l(Y).
