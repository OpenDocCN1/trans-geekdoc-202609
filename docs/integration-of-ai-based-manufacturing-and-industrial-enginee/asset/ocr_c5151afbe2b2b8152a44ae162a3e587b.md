**FIGURE 4.2** Membership function form of Equation (4.4).

The restriction of type ≽, μ_l will be algebraically framed as follows:

$$\mu_l = \begin{cases}
1 & \text{if } M_l(Y)=P_l \\
\dfrac{U_l-M_l(Y)}{U_l-P_l} & \text{if } P_l \le M_l(Y) \le U_l \\
\dfrac{M_l(Y)-L_l}{P_l-L_l} & \text{if } L_l \le M_l(Y) \le P_l \\
0 & \text{if } H_l(Y) \ge U_l \\
0 & \text{if } H_l(Y) \le L_l
\end{cases} \tag{4.5}$$

The additive model would be expressed by the combination of the membership functions with the fuzzy goal programming problem (4.1):

**Maximize:**

$$Z(\mu)=\sum_{l=1}^{m}\mu_l$$

**Subject to:**

$$\mu_l=\frac{M_l(Y)-L_l}{P_l-L_l}$$
