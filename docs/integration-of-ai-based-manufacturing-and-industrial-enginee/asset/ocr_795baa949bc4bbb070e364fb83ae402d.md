# 15.3 LANDMINE DETECTION AND CLASSIFICATION TECHNIQUES USING MACHINE LEARNING ALGORITHMS

The Least Mean Square (LMS) pre-screening is used for anomaly recognition and finding signatures similar to landmines. Translation-invariant features were extracted from the identified regions of interest (ROI) using edge histogram descriptor (EHD) assigned the confidence value for accurate detection using probabilistic KNN (Frigui and Gader, 2009). Ultra-Wideband synthetic aperture radar (UWB SAR) identified the suspected area through space-wavenumber processing. The efficient features were retrieved using the sequential forward floating selection (SFFS) and classified using a fuzzy hypersphere support vector machine (FHSSVM) (Rachna et al., 2021). Equation (15.1) calculated the risk based on the number of misclassified landmines and clutter (N_L, N_C) and the risk of misclassification of landmines and clutter (R_L, R_C) (Jin and Zhou, 2010).

Risk = N_L R_L + N_C R_C
