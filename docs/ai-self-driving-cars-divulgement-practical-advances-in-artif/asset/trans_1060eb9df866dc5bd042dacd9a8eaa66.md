## 什么是自动驾驶

作为背景，Zoox 是一家总部位于硅谷的自动驾驶汽车制造商，成立于 2014 年，自此一直是一家初创公司。让他们与众不同的是，他们深信不疑且坚定不移地认为：自动驾驶汽车必须从零开始打造。这是什么意思？许多自动驾驶软件开发实体将其自主能力瞄准传统汽车，通过配备精密的传感器套件和其他增强设备，将其改装成自动驾驶车辆。与此同时，尽管 Zoox 也通过使用特别改装的丰田汉兰达和普锐斯 C 做着同样的事，但他们的总体激情在于彻底重塑汽车平台。例如，在人类驾驶的汽车中，始终将汽车设计为前向行驶是合理的，因为人类坐在固定位置面向前方。在现代汽车发明史上，我们一直是这样坐、这样开车的。但在自动驾驶汽车中，AI 在驾驶，因此你可以设计车辆随时在任一方向“前向”行驶。因此，抛弃有时需要“倒车”的陈旧观念，转而将驾驶方向设定为始终向前，即使你碰巧正朝着刚来的反方向行驶。他们称之为对称且双向的设计，此外该车辆将是零排放的电动汽车（EV）。你可能会好奇，哪条路更好？是在传统车上堆砌复杂的尖端技术，还是重新构想汽车的构成。棘手的是，如果你决定走看似激进的路线，尝试前所未有的设计，你可能要同时面对两场硬仗。你必须确保物理车辆本身能在道路上运行且安全，同时还要确保 AI 和自动驾驶系统正常工作。这就是为什么许多自动驾驶相关项目专注于使用各种增强版日常用车，试图减少原本就无可争议的“登月级”壮举中的变数和不确定性。逻辑是：你可以审慎地通过一个基于已验证车型的坚实基础，缓步进入自动驾驶领域，从而只需应对 AI 自动驾驶能力背后的焦虑与阵痛。Zoox 本质上想“两全其美”，他们通过使用经过自动驾驶技术增强的特定常规车型（包括将这些车投入道路进行真实世界试驾），在幕后全力推进全新专用车型的研发。如果你一直跟得上我的解释，接下来让我们更深入地挖掘埃隆·马斯克那条推文所蕴含的多维度、令人费解的含义。大家都知道马斯克一直致力于让特斯拉不仅成为顶级车企，也成为卓越的自动驾驶汽车提供商。通过使用 Autopilot 及封装在特斯拉车辆中的传感器，特斯拉一直在逐步、渐进地将半自动驾驶转变为全自动驾驶。让我们确保每位读者都知道一个非常清晰、不容辩驳的事实：**如今的特斯拉并非全自动驾驶。** 无论你听到多么狂野的宣称，看到网上多少愚蠢的视频里人们错误地相信他们的特斯拉能自己开车，这完全是胡扯，是令人遗憾且危险的谎言。以如今的特斯拉及其所有“自动辅助驾驶”功能来看，它仍是一辆需要人类驾驶员的车。在自动驾驶等级划分中，你会说这些车属于 L2 级。真正的自动驾驶汽车是 L4 级，未来有望达到 L5 级。Zoox 专注于 L4 和 L5 级。特斯拉处于 L2 级，并试图逐步迈向 L4 和 L5 级。因此你可以明确指出，特斯拉和 Zoox 最终都在追求真正的自动驾驶，只是特斯拉从较低级别的半自动驾驶起步，而 Zoox 则跳过那些低级别，直接冲刺最高级别。没人能确定哪条路径更好。特斯拉这类公司无疑会声称，他们通过逐步完善的方法论走的是“正确”路线。许多人似乎没完全意识到，特斯拉涉足 L2 级并推定进入 L3 级，让自己面临巨大的昂贵风险和潜在垮台危机。我反复呼吁：我们将会有不认真履行 L2 或 L3 级车辆驾驶员责任的人类驾驶员。当涉及 L2 和 L3 级车辆的车祸发生时，车企会立即试图通过指出人类驾驶员是驾驶任务的责任方，来为自己完全免责。这种做法能否继续让这些公司获得“免责特权”仍有待观察，但我预测很可能会爆发大规模诉讼，可能会严重打击这些公司，甚至让一些公司倒闭。因此，一些人坚持认为，Zoox 等公司跳跃式冲刺 L4 并最终达到 L5 的路径更为稳妥，避免了陷入 L2 和 L3 级的泥潭中可能引发的、足以毁掉公司的丑陋纠葛。当然，处于 L2 和 L3 级的公司倾向于声称，他们更有可能更早达到 L4 甚至 L5，因为他们是一步步构建上来的，在过程中学习和复用。同时，他们能从 L2 和 L3 级赚取收入，而那些冲刺 L4 级的公司基本没有任何收入，还在为让 L4 适应日常世界而挣扎。额外的转折在于，一些冲刺 L4 和 L5 级的公司将自动驾驶能力用于除载客乘用车之外的其他方面。通过利用相关用例，这些公司有望更早建立可行的收入来源并维持运营。例如利用自动驾驶配送车辆和自动驾驶班车等其他运输模式，这些可能被认为更容易实现商业化，同时继续应对棘手的乘用车需求（一些人认为亚马逊极有可能看中 Zoox 的能力用于处理配送和物流出行事务，而非作为网约车或共享出行服务提供商）。
