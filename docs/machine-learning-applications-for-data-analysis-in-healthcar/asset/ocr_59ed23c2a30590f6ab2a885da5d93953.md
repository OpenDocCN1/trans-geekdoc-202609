Structure-based virtual screening (SBVS) employs scoring functions to quantify the force of noncovalent contacts between a ligand and a molecular target in order to forecast the ideal interaction mode between two molecules to create a stable complex [5]. As a result, the success or failure of SBVS software is mostly determined by scoring functions.

SBVS is performed using a variety of software packages, each of which is based on a distinct algorithm and yields various results. In the recent decade, a novel SBVS approach called consensus virtual screening has been widely employed in several researches to improve SBVS precision and minimize the number of false positives produced in these trials. The presence of a 3D structure of the target protein is an absolute need for SBVS to work. Virtual databases have been built to hold 3D structures of molecules, such as the Protein Data Bank. However, obtaining the 3D structure experimentally is not always achievable. In this case, homology modeling allows for the prediction of a protein’s 3D structure based on its amino acid sequence.

# 7.2.1 LBDD APPROACH

When target structures are unknown, LBDD approaches are frequently applied in drug designing. It begins with building a ligand using software like Chemsktech, Schrodinger, and so on and generating many random combinations by adding or removing new functional groups or by Finding databases like Zinc Database to screen out a variety of ligands known to be having some biological efficacy against the target protein or gene. After building or finding the effective ligand molecule, QSAR (quantitative structure–activity relationship) approach is applied to estimate the efficacy and biological activity of those molecules.
