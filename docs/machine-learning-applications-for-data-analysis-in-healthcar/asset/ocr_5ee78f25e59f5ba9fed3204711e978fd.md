# ## 1.2.9 GRADIENT BOOST

This is one of the most robust algorithms in ML [19]. GB is an ML procedure which has its applications in both regression and classification tasks. It furnishes a prognostic model which is basically DTs in manifestation of an ensemble of weak prediction models. GB generally surpasses RFs because it minimizes the errors by constructing a new model each time on the flaws of the preceding models. A gradient-boosted tree is fabricated in a hierarchical manner as in other boosting procedures, but it globalizes other procedures by optimizing randomly differentiable loss functions. The bias error of the model can be diminished by using a GB algorithm and therefore it enhances the efficiency in predicting the outcome of our binary classification task and hence it increases the accuracy of our overall model.

# ## 1.2.10 LIGHT GRADIENT BOOSTING MACHINE

LGBM is another boosting algorithm which comes under the family of supervised ML, and it is widely used in the industry because of its better performance [20]. It is highly memory efficient and takes less time to train with respect to the majority of the ML algorithms. It can be used for classification as well as regression use cases. This algorithm is based on trees, it rapidly decreases the error of the overall model as it always tries to split its nodes leaf-wise fashion hence fabricating the model leaf-wise and continuing to grow the leaf with high loss in order to reduce it. This is the reason why it performs better than other algorithms which are based on trees performing level-wise splits. LGBM algorithm uses histograms to bucket out contiguous feature values into distinct bins which enhances the speed of the training procedure; it also results in minimized memory usage. As compared to XGB, it is adept in executing equally well with enormous datasets with a remarkable depletion in training time. All these features made this algorithm the best fit for our dataset.
