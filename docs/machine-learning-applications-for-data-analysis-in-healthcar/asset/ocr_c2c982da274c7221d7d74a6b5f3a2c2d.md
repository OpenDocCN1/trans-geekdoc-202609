# 13.1.2 CNN (CONVOLUTIONAL NEURAL NETWORK)

Convolutional neural networks (CNNs) serve the purpose of image classification and recognition. CNNs automatically extract features from images, unlike traditional neural networks. CNNs use convolutional layers to apply learnable filters to input images. These filters identify edges and textures, and the convolutional layer output is routed via nonlinear activation functions to build a feature map. Pooling layers downsample the feature maps to minimize their spatial dimensions while retaining the most relevant characteristics. CNNs finish with fully linked layers to classify learned features. Backpropagation with stochastic gradient descent reduces a loss function by modifying filter weights and biases.

CNNs excel at picture classification, object recognition, and segmentation. Natural language processing, voice recognition, and other applications employ them.
