## 10.4 PERFORMANCE ANALYSIS

The performance analysis is done based on four parameters: TP, TN, FP, and FN which is true positive, true negative, false positive, and false negative, respectively. Equation 10.5 is used to calculate the “Accuracy” as follows.

### 10.4.1 ACCURACY (ACC)

The accuracy (ACC) [35] is calculated as the total TP (\(\alpha\)) and TN (\(\lambda\)) records count divided by the total number of instances (\(\alpha\) = TP, \(\lambda\) = TN, \(\beta\) = FN, \(\Omega\) = FP). Equation 10.5 is used to calculate the “Accuracy” as follows:

$$ACC = \frac{\alpha + \lambda}{\alpha + \lambda + \beta + \Omega}$$ (10.5)

### 10.4.2 PRECISION (PE)

The precision (PE) [36] is calculated as the ratio of total true positive (\(\alpha\)) records count by the total number of instances (\(\alpha\) = TP, \(\beta\) = FN). The “precision” is calculated using Equation 10.6 as follows:

$$SN = \frac{\alpha}{\alpha + \beta}$$ (10.6)

### 10.4.3 RECALL (RE)

The recall (RE) [37] is calculated as the ratio of total true positive (\(\alpha\)) records count by the total number of true instances (\(\alpha\) = TP, \(\Omega\) = FP). The “Recall” is calculated using Equation 10.7 as follows:

$$RE = \frac{\alpha}{\alpha + \Omega}$$ (10.7)

## 10.5 CONCLUSION

An ECG is a graphic representation of the electrical patterns the heart produces. This test is extensively used for persons with cardiac difficulties and is an important diagnostic tool. ECGs are frequently recorded on chapters with a grid. The grid work on ECG recordings is made up of many little 1 mm square blocks. Each of these little boxes lasts around 40 ms. Image processing and numerical data extraction from ECGs. A transthoracic interpretation of the heart’s electrical activity over time is called an ECG. The study of the ECG signal provides details regarding the condition of the heart. A variety of approaches, including FFTs and wavelet transforms, have been employed to diagnose cardiac problems. The combination of ELM with discrete wavelet transform resulted in an ELM-healthcare model in this work. This model is basically comprised of four components: preprocessing, heartbeat segmentation, feature extraction, and heartbeat classification. With 99.9% accuracy, our proposed model surpassed existing state-of-the-art models, 98.9% sensitivity, and 99.9% specificity. In the future, this proposed model can be applied to medical imaging issues and different modalities.
