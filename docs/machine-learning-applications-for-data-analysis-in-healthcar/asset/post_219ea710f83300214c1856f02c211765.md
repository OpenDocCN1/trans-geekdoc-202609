### 11.3.1 DATA PREPROCESSING

Stop words removal: Removal of stop words from sentence. Since these words are not useful for text information, it is to be removed before applying classification model. Some of the common stop words are “a,” “an,” “the,” “is,” “as,” and so on. In Python, we can easily remove stop words using Natural Language Toolkit (NLTK). NLTK has a list of stop words in their dictionary; thus, we can first convert the whole corpus into list of words and remove the words that match with stop words in the dictionary of NLTK.

Punctuation removal: Removal of unnecessary symbols in a document. We remove unknown characters and symbols, such as “#,” “!,” “$,” so that we can find the root words that carry the actual information of the text.

Convert to lowercase: Convert to lower or uppercase for comparison ease. We either convert the whole corpus in lowercase or uppercase. In Python, we can use function lower("string") to convert into lowercase and function upper("string") to convert into uppercase.

Tokenization: Split the text into a list of words. Before applying NLP, we first tokenize the text into list of words. We do it because the meaning of the text can be interpreted by analyzing the words.

Stemming: Reducing derived word into stem/root word. It is a normalization technique. It helps to find out similar words when we search in our whole corpus.

Lemmatization: Similar to Stemming but returns actual dictionary word. Thus, the word we get after lemmatization carries similar meaning to the original word.

### 11.3.4 CALCULATION OF TF-IDF (TERM FREQUENCY–INVERSE DOCUMENT FREQUENCY)

Term frequency–inverse document frequency (TF–IDF) gives us an idea about which word is most important in our documents. The document which has similar words will carry similar vector which is important for our machine learning model. The highest TF–IDF score represents a rare word in the document. This score thus generates vector of all words and used as an input to classification model such as linear SVC, naive Bayes (NB) classifier.

TF: TF is a way of normalization. The formula for TF is given as follows:

```
TF(t) = (number of times word “t” appears in a document)/(total number of words in the document)

t_{f_{i,j}} = \frac{n_{i,j}}{\sum_k n_{k,j}}
```

IDF: IDF measures how important a term is. Basically, it is to scale down the impact of tokens that occur very frequently in every document, such as “a,” “the.”

```
IDF(t) = log_e(total number of documents/number of documents with term t in it).
```

$idf\left(w\right)=log\left(\frac{N}{df_i}\right)$

TF–IDF: TF–IDF is simply the TF multiplied by the IDF.

$w_{i,j}=tf_{i,j}\times log\left(\frac{N}{df_i}\right)$

For every accident document, we get the TF–IDF value for each word, and the higher the TF–IDF value signifies the importance of that word. Thus, across each document, we get the most important word by seeing the word containing the highest TF–IDF value in that corresponding document. This TF–IDF matrix is used as an input for the linear SVC.
