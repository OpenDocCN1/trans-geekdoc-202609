
The matching strategy uses two code maps, one is the angular distance which is computed based on the normalized Hamming distance, and the other is band-limited phase-only correlation (BLPOC) which is used to measure the similarity between Fourier transforms (global information) of the images. Thus, two separately calculated matching distances d₁ and d₂ from local and global features combine according to the matching weight rule and this algorithm achieved EER as low as 0.402%.

In Ref. [13], the author tried to extract the orientation feature from the FKP image using a Gabor filter bank having five different scales and eight different orientations and keeping all other parameters constant. Further, the author applied the PCA for feature dimension reduction. Since a combination of PCA and LDA provides a good effect on feature selection, LDA is applied to PCA weights. The Euclidean distance is used for matching. The proposed method of FKP recognition is tested over all four finger images and it is observed that the right middle finger has a better recognition rate of 75.25%. A different combination of feature-level fusion is carried out for all fingers and the maximum recognition rate was 98.79% achieved.

A novel FKP recognition technology proposed robust FKP feature extraction and matching algorithm based on speeded-up robust features (SURF) [14]. This novel feature is extracted by following two steps: first, a coordinate system is defined based on the local convex direction map of FKP to align the FKP image and a region of interest is cropped. Second, the key points are detected using a fast Hessian detector to which orientation was assigned accordingly to the Haar wavelet responses inside a neighbor circle area of a detected key point, and an orientation invariant descriptor is constructed for each key point. In this matching method, the distance of the second-closest neighbor is matched with the distance of the first-closest neighbor. All matches are performed in which the distance ratio between the two is less than 0.6. Thus, the tentative correspondence between two key point sets of training image and template image is obtained. The Random Sample Consensus (RANSAC) is formulated to remove the false matching and the final matched pair is used to determine the consistency of the palm images. This method is invariant to rotation and scale transform and provides an accurate and robustness of 90.63% for validation and 96.91% for identification purposes.

A novel method was proposed to identify individuals using a single FKP [15]. A major advantage of this method is to reduce the huge database size and this proposed method trains the classifier by describing the edges of an image with discontinuities in the grey levels. A self-defined convolution template of size 3 × 5 as a gradient operator is used in the spatial domain to minimize the noise and extract the lines feature. The method was then used to prevent making a wrong decision due to the varying position and different standing posture of the acquisition device during the collection of images. Eight different images were obtained by translation operation and one image original, as a whole nine image is used for confirming the user’s identity using the principle of the maximum cross-correlation coefficient. The experiments conducted on the FKP obtained a recognition rate of 95.68% at a 30-threshold value, which revealed that it is a reliable and accurate biometric trait.

Morales et al. [16] presented a novel approach for FKP authentication. In this technique, the author uses a Gabor transform to enhance the orientation information of the image, and SIFT descriptor is used to extract and represent the feature sets. El-Tarhouns et al. [17] applied multiscale LBP and PCA techniques to extract the local and global features from the FKP image and a matching attempt can be considered as a combination of both global and local features.

In Ref. [18], the author proposed a multimodal biometric system using FKP and Palmprint biometric trait. This model extracted various features from both and computed scores are combined using score level fusion. Various combinations of experiments are conducted and found that SURF plus bidirectional empirical mode decomposition feature extraction technique provides better performance. ## 12.3 BIOMETRIC SYSTEM BASIC BLOCK DIAGRAM

Originally, the biometric system is a pattern recognition system that obtains the biometric data from an individual, draws out a primary characteristic set from the data, differentiates this characteristic set against the characteristic set(s) reserved in the database, and results in a decision based on the differentiation.

A biometric system thus has the following basic modules: a raw data acquisition module, a quality improvement module (preprocessing module), a matching module, feature extraction module, and a database module. Figure 12.1 describes the basic block diagram of the biometric system.

![](img/e7e1b4040cce350b0d1520d1f0df754d_224_0.png)

FIGURE 12.1 Basic block diagram of biometric system.

### 12.3.1 DATA ACQUISITION

Raw data from the individual may be obtained by using an appropriate sensor, a camera, or a scanner. This module must be capable of acquiring good-quality images for the biometric system to provide good performance.

### 12.3.2 PREPROCESSING

The function of this module is to assess the quality of the raw data obtained from the previous stage. Any preprocessing algorithm may be applied to the raw data to enhance its quality so that it is suitable for feature extraction.

### 12.3.3 FEATURE EXTRACTION

Next, a suitable algorithm is applied to the preprocessed image to extract the features (a compact representation of the preprocessed image) that can be used to uniquely identify a person. The extracted features are stored as templates in the database.

### 12.3.4 MATCHING

For a given test or a query image, the features are extracted and are compared with the reserved templates of the database to measure the level of closeness between the template and the extracted features of the claiming person. A decision is then made as to whether the individual or the user is a genuine (authorized or enrolled user) or an impostor (unauthorized user) depending on the observed closeness measure.

### 12.3.5 DATABASE

The feature set extracted from the raw biometric data (i.e., the template) is stored in the database along with some additional information (such as name, Personal Identification Number, address, etc.) representing the user.
