In this algorithm, all features are given the same priority and as the features are not interrelated; they can independently take part in prognosticating the final outcome, no feature has fear of getting left behind as the model penalizes itself for doing so. It sets aside the values that are continuous and only accounts for discrete or discontinuous data. It is blazingly fast in comparison with other classification algorithms, as it treats each feature separately with its corresponding binary values and it explicitly penalizes the model for absence of any of its features which is crucial for speculating the outcome. Due to its rapid prediction capability, it can find its usage in making real-time predictions and it is unresponsive to irrelevant features.

# 1.2.7 K-NEAREST NEIGHBOR

KNN is a kind of algorithm which is merely based on intuition that data belonging to a similar group would have a similar impact on new data points’ outcome which belongs to the same group [17]. This algorithm belongs to the supervised category of ML algorithm and is majorly used in classification use cases. It does not have any parameter to train according to the dataset, instead, it stores all the data that it gets and utilizes all those stored at the time of classification. It is one of the simplest ML algorithms and requires less time to train as compared to tree-based algorithms. It can also be used for regression problem statements by making some changes in the underlying algorithm.

# 1.2.8 ADAPTIVE BOOSTING CLASSIFIER

Adaptive boosting is the most basic boosting ensemble algorithm which also belongs to the supervised category of the ML algorithms and canbe used for both classification as well as regression use cases [18]. It used multiple similar kinds of models to prognosticate the final outcome. The models that are used in fabricating this model are also known as weak learners. Each weak learner that is appended to the model with updated values of weight, tries to diminish the error of the previous model as a whole and at the end due to this the overall performance of the model increases, hence it can predict the outcome more accurately. It has proven to give better results as compared to DTs as the aggregation makes it more robust and increases the overall performance of the model.
