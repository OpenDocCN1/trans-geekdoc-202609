It usually performs with time series that have a lot of seasonal variation and historical information from multiple seasons. The Facebook Prophet is used in a wide range of Facebook apps to provide correct estimates for planning, control, and goal setting. It is accommodating of incomplete information and trend modifications, and it generally manages outliers. The Prophet method gives customers a lot of options for tweaking and adjusting predictions.

In this chapter, the author has evaluated a Facebook Prophet Model for the prediction of a pandemic outbreak. The author has taken a COVID-19 dataset and visualized it first to find out the country-wise plot for the number of COVID-19 cases in 2020 (Figure 2.1). Further visualization is done to find out the number of tests conducted and the number of deaths (Figure 2.2).
