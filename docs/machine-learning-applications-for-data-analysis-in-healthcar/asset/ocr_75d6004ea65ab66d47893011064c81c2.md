# TABLE 5.2 Types of Inputs Used for CVD Detection

| Types | Explanation |
|---|---|
| Clinical test | Chest pain, resting blood pressure, serum cholesterol, fasting blood sugar, resting electrocardiographic, maximum heart rate, exercise-induced angina |
| ECG | ECG is a graphical plot showing the interrelation between the electrical activity of the heart versus time. It happens due to depolarization and repolarization of cardiac muscule |
| Heart sound | The heart sound is created due to turbulence when the heart valves snap shut |
| ICG | It is noninvasive in nature and measures the total electrical conductivity of the thorax. It changes in time to process continuously a number of cardiodynamic parameters |
| MCG | It is a technique to measure the magnetic field strength produced by electrical current in the heart |
| CT images | It is a noninvasive imaging test of the arteries that supply blood to the heart. It is used to diagnose the condition of the heart |

Notes: ECG: electrocardiogram, ICG: impedance cardiography, MCG: magnetocardiography, CT: computed tomography

# 5.3.2 SOURCES OF DATA FOR CVD DETECTION

The CVD detection models are developed through training process using standard data relating to CVD. Subsequently, these models are applied to diagnose the HD of a patient. These standard datasets have been collected and presented in Table 5.3 [1]. In many situations, real-life data are collected from various standard hospital sources preprocessed and passed through intelligent classifiers for detection. In addition, online medical data are obtained from patients at remote places and then transferred to doctors in standard hospitals through IoT platform.
