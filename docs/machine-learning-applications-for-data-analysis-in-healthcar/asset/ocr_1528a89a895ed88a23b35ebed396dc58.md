# ### 10.3.1 ECG ANALYSIS

ECG signal analysis and identification has long been a fascinating subject, and there is still ongoing study in this area. For ECG analysis, several fast and short Fourier transform approaches have been developed [22].

# #### 10.3.1.1 FAST FOURIER TRANSFORM

Time domain approach was previously employed for ECG signal analysis. However, the drawback was that it was not enough to analyze every aspect of the ECG signal [23, 24]. As a result, the fast Fourier transform (FFT) method was introduced. Fourier transform translates time-domain signals to the frequency domain to find frequency coefficients [25]. FFT is a fundamental transform in digital signal processing that can be applied to a variety of tasks, including frequency analysis and signal processing [26]. It is a faster and more powerful technique that produces the same result as the discrete Fourier transform [27]. The following formula, which can be found in Equation 10.1, is used to define FFT:

```
Xk = ΣN−1 xe−nk2πi/n, n = 0 (10.1)
```

One of the most important methods is FFT. The following steps make up the entire process:

+   - Obtaining an input signal or ECG sample.
+   - Before compression can be performed, the low-frequency components of the incoming signal are filtered out.
