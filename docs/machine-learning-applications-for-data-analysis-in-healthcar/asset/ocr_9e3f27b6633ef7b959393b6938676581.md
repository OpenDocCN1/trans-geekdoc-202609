Healthcare data are secured with a symmetric key that is additionally encrypted with the authorized user’s public key from a 2048-bit Rivest–Shamir–Adleman key pair. The healthcare data cannot be obtained by adversaries without the symmetric key. As a result, this plan offers a high level of data privacy.
