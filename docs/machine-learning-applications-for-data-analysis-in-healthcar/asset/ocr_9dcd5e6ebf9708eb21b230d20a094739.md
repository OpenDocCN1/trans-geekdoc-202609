# 11.3.1 DATA PREPROCESSING

Stop words removal: Removal of stop words(.) from sentence. Since these words are not useful for text information, it is to be removed before applying classification model. Some of the common stop words are “a,” “an,” “the,” “is,” “as,” and so on. In Python, we can easily remove stop words using Natural Language Toolkit (NLTK). NLTK has a list of stop words in their dictionary; thus, we can first convert the whole corpus into list of words and remove the words that match with stop words in the dictionary of NLTK.

Punctuation removal: Removal of unnecessary symbols in a document. We remove unknown characters and symbols, such as “#,” “!,” “$,” so that we can find the root words that carry the actual information of the text.
