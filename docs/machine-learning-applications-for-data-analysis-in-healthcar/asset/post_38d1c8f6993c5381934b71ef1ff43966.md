A novel method called weighted linear embedding (WLE) was proposed [5] to recognize FKP. This method combines the Fisher criterion with the manifold learning criterion to extract features from a linear model. The concept of the manifold learning theory states that the importance of local information is more significant than nonlocal information. This concept is implemented and both local and nonlocal features are extracted from the data sets. The author uses Gaussian weighing to mapping procedure that combines nonlocal and local information. It is commonly used to find a mapping vector that is suitable for estimating the weighted class scatters maximized. The classification is done on the base of the nearest neighbor classifier. The authors have also tested the proposed algorithm on palmprint and have made a comparative study of PCA, LDA, LDE, and WLE. The WLE is tested on the right index finger of 1000 persons and achieved a recognition rate of 78.2%.

This chapter also compares the individual finger performance and shows that the left index finger has better performance than the right index finger.

An author presented a method that simultaneously measures distances and angles between the image data vectors to study the similarities between them [7]. An image angle measurement method that is focused on a shifted image space is proposed to highlight the distinction between the angles of different data. Both the distance and angle are obtained through a parallel fusion procedure that uses the complex locality-preserving projections to extract low-dimensional features. Orthogonal complex locality preservation projections or OCLPP is a subspace method that can minimize the redundant information in each image and four images were randomly selected for the recognition process and achieved a recognition rate up to 88%. ## 12.2.2 CODING-BASED FKP RECOGNITION ALGORITHM

In the coding-based technique, the FKP image is segmented into several subimages, and information like orientation or edges is extracted from each subdivided image. Several coding algorithms are proposed in the literature to improve the recognition performance of FKPs. These coding techniques are widely used for palmprint recognition and found good recognition results. The finger knuckle surface is very rich in lines and creases and highly unique in individuals. These techniques of coding are mainly based on the concept of iris code.

A research work exploited the local feature in comparison to the global feature for reliable performance [8]. The preprocessing step helps to minimize the effects of light variation on the texture features and improves the overall performance. To avoid wrapping around an inherent modulo operation, finite radon transform and modified finite radon transform (MFRT) are commonly used to determine the orientation of the grease lines or knuckle lines in a local neighborhood region. The dominant direction at each pixel is computed and coded into binary bits called knuckle code. The normalized Hamming distance is used to compute the similarity measurement between two FKP and these techniques achieved 98.6% accuracy.

A method [9] is proposed to capture an FKP image and automatically align the FKP image with a local coordinate system. The bottom of the FKP image is stable because of the acquisition method. Hence, this is considered the x-axis of the ROI coordinate system by fitting this boundary as a straight line. A model for the convexity of FKP was established. The resulting magnitude will reach the minimum at the center of the phalangeal joint and it can be used to set the coordinate system's y-axis. After the coordinate system is fixed, an ROI subimage of size 110 x 220 is cropped. Then orientation information is extracted using Gabor filtering and represented the information in the form of competitive code. The angular distance is used for matching between two FKP and finally an energy efficiency ratio (EER) of 1.09% was achieved.

An improved competitive and magnitude code is developed in 2010 [2]. This uses Gabor filters to extract the magnitude and orientation information. This information is further used to set up a code map that is based on the competitive code. This computed angular and magnitude distance is fused and the minimum distance is considered the final distance. This proposed algorithm is compared with one standard coding algorithm and found better performance.

The concept of the monogenic code was proposed [8] to fast features extract from a two-dimensional signal f(x,y). The monogenic signal is defined as the combination of f(x,y) and its Riesz transform which is a vector-valued extension of the Hilbert transform in the 2D Euclidean space. The code represents the 3 bits of the monogenic signal that were extracted from the pixel. It shows the phase information and orientation of the pixel. This algorithm also shows similar accuracy in comparison to the state-of-the-art method of FKP recognition.

In Ref. [10], the author proposed a new coding method that has the advantages of high accuracy, robustness, and compactness. To find the above code, Riesz transform identifies and characterizes the visual patterns of the FKP image and also encodes the local patches using second-order Riesz transform. A 6-bit coding scheme namely the Riesz Compcode was developed. This Riesz Compcode is a 6-bit coding scheme that combines the advantages of Riesz transformation and Compcode in characterizing the local FKP feature together. A normalized Hamming distance is computed at the matching stage of the proposed work and this scheme of the coding algorithm shows better performance in terms of recognition accuracy when compared with another coding algorithm.

Nigam et al. [11] used pixel-based feature information around a specified area of the local blob, edge, or corners for FKP recognition. This technique of FKP recognition is sensitive to illumination but unguarded to rotation. It proposed a new feature extraction technique using vertical code and horizontal code. The proposed work extracts feature by taking derivatives along the x-axis and y-axis, respectively, and are represented by vcode and hcode. The extracted vcode and hcode are used by gradient ordinal relation pattern (GORP) and star gradient ordinal relation pattern (SGORP) to compute four types of features and are represented by vcode_GORP, hcode_GORP, vcode_SGORP, and hcode_SGORP. These four extracted features form a feature vector which is used for matching. Zhang et al. [9] used various coding techniques for FKP authentication and tested on a big dataset, and finally achieved a leading authentication performance. ## 12.2.3 OTHER RECOGNITION ALGORITHM

In the literature, several image processing techniques are used to extract texture features, local, global, and line features from FKP to either independently or combined manner. The local and global combined information provides more information and hence better recognition performance.

A technique known as local global information combination (LGIC) was proposed [12], and based on psychophysics and neurophysiology study, the author states that both local and global information are crucial for FKP recognition. The local feature is orientation information which is extracted by the Gabor filter using four scales and six orientations wavelet. This procedure is suitable for extracting features from images with an abundant line-like structure available and has advantages like high accuracy, robustness to light intensity variation, and computation efficiency. The global feature is extracted by increasing the scale to infinity of the Gabor filter and obtaining the Fourier coefficient from the transformed FKP image.
