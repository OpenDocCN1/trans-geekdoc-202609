Therefore, hyperparameter optimization techniques like Random Search CV or Grid Search CV are applied on the models for which the best-suitting hyperparameters are to be found. In this technique, the best fitting hyperparameter values are chosen from a pool of values which was provided to a hyperparameter optimization technique.

So, we thought of tuning our ML models using Random Search CV to get the best performance out of our models. As discussed previously, we too provided a pool of values to this technique from which it randomly selects different combinations of parameters and trains the model using those sets of parameters and record its results. In the end, it returns the set of hyperparameters which yields the best result. After tuning all the models, we obtained the hyperparameter values as in Table 1.6.
