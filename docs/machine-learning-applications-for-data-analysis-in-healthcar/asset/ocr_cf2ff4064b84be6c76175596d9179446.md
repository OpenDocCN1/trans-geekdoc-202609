# 1.4.2.3 SCALING THE DATA

As we can see in our dataset that the data vary very much and the difference between the lowest and the highest values is very huge. So, this could increase the overall model training time or may cause the model to get biased toward the data or the feature that has a huge positive or negative value which in turn would make our model more prone to overfitting, thereby deteriorating the overall model's performance which we do not want to happen. Knowing the consequences that come with the unscaled data we thought of scaling our dataset and then training our model on the scaled data for making our model more robust and reducing the overall training time. Hence, we decided to scale our training and testing data of both unbalanced and balanced dataset using Standard Scalar. After applying Standard Scalar, the feature values of our dataset came in close proximity with each other and started ranging between −1 and 1.
