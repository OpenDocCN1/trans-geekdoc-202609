# 7.2.2 VIRTUAL SCREENING IN LBDD

Virtual screening is a computational technique for analyzing an extensive library of chemical compounds to find new drug candidates. It is widely used for evaluating large libraries of compounds automatically by using computer tools. Virtual screening explores the properties of the biological molecules on the basis of Lipinski's rule of five. Only those molecules which are potential to be a drug candidate based on Lipinski's rule are screened out and given in the result of virtual screening.

Virtual screening software can provide very accurate findings since they are based on quantum and molecular physics rules. We can also alter the ligands and build new forms of ligands by adding or removing specific functional groups using CHEMSKETCH software freely available online.

CHEM SKETCH is a comprehensive structure editor with a variety of tools and functionality which provide a combination of scientific and chemical information [9].

In CHEMSKETCH, we have to draw molecular structure, generate structure from InChl (The InChl program includes the ability to generate an InChl key which is a condensed 25-character representation of the InChl string. This compact representation significantly expands the use of InChl encoding for structure specification and search, particularly over the internet.) or SMILES strings, or copy/paste from chemDraw. Tools available in CHEMSKETCH allow us to incorporate the following features very easily.

+   - Insert predraw templates of amino acids, aromatics, steroids, sugar, and more.
+   - Search the dictionary of >170,000 systematic, trivial, and trade names.
+   - Easily draw reactions and complex chemical schemes (including biotransformation maps).
+   - Use graphical templates and tools to communicate chemistry and chemical biology concepts (e.g., chemical bond types Lewis's structure, molecular orbitals Newman projections, peptide sequence, and more).
+   - Import and export structure files in a variety of standard files and formats.
