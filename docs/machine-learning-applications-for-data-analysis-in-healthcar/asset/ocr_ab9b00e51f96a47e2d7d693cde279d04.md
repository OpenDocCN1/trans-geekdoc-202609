# 7.3.3 TOOLS AND SOFTWARE APPLIED FOR MOLECULAR DOCKING

Different programs use different docking algorithms. Most of the programs are based on virtual screening. The following are major programs used in docking:

+   1. AutoDock: It is a modeling simulation software which is very effective in protein–ligand docking. It is an automated tool that helps in predicting how small fragments adhere to receptors of known 3D structure. It also has applications in chemical mechanism studies, X-ray crystallography, virtual screening, and SBDD. It consists of two programs, one is to DOCK and another is AUTOGRAID [48,49]. URL: http://autodock.scripps.edu/

+   2. AutoDockVina: This is a free molecular docking program and is a new generation of Autodock with improvement in speed and accuracy level. It internally calculates the grid for the atom types and precalculating grid maps for them. It has applications in lead optimization, protein docking, and so on. URL: http://vina.scripps.edu/

+   3. DOCK: It is a program for multiple protein structures and uses a similar matching algorithm to build ligand binding orientation [50, 51]. It uses sphere ligand-matching algorithm of UCSF DOCK to generate confirmations.

+   4. Glide: It is a ligand-docking program and it predicts protein–ligand binding. It is best and feasible in doing HTS [52]. URL: http://www.schrodinger.com/glide/

+   5. FlexX: It is a high-throughput software [10,53–55]. URL: http://www.biosolveit.de/FlexX/
