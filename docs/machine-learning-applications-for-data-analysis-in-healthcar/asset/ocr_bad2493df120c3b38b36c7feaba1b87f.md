# ABSTRACT

The human being has several biometric traits that can be used to identify a person such as fingerprint, finger vein, hand vein, hand geometry, face, iris, finger knuckle print, palm print, ear, gait, retina, and so on but the hand-based biometric system is highly acceptable due to easy acquisition, ease-to-use, and leading recognition performance. The fingerprint-based biometric system is an older one and is often used type for person recognition/identification. Apart from various advantages, the fingerprint trait has three major drawbacks. First, the fingerprint ridges are rugged in the hard-working people like cultivator, industrial labor, machine mechanics, rickshaw pooler, and so on. Second, the skin elasticity is not constant throughout the seasons; and third, applied thumb pressure is not always the same, cause dispersion of thumb skin is varied, resulting the extracted feature sets are also varied.
