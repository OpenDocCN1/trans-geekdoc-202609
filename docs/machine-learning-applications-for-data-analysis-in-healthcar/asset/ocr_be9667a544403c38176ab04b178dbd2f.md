# ABSTRACT

The real challenge posed to in-hospital mortality study is from heterogeneous data from nonhomogeneous class of patients. This motivates the study, which uses traditional machine learning (ML) algorithms to analyze the heterogeneous data containing 48 features and classify in-hospital mortality. The retrospective cohort was focused on heart failure patients. Twelve ML algorithms have been deployed on a publicly available dataset for binary classification. The dataset used for the study was highly resource constrained and unbalanced; hence a novel data preprocessing unit has been designed. In addition to standard implementations, hyperparameter tuning and stacked implementations have also been done.
