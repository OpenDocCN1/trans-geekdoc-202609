[24], the authors proposed to build a model whose decision-making capability is much better as compared to others existing models so as to properly assign the beds in the ICU to the patients in need. They trained their models using two algorithms, that is, linear discriminant analysis classifier and SVM. Before undergoing the training phase, chi-square distribution was used to refine the data and SMOTE (synthetic minority oversampling technique) was used to deal with the imbalanced nature of the dataset. A total of 12 features were used for prognosticating the mortality and a \( k \)-fold CV value of five was used to evaluate the SVM model. Between their presented models in the chapter, SVM works better with a recall of 69%, accuracy 77%, and fall out (0.5).

In Ref. [25], they have proposed a model that is useful in prognosticating extubation failure. The ML algorithm that they used for fabricating their model was LGBM. They have also shown that this algorithm performs better than algorithms like LR, XGB, ANN, and SVM. In the data processing part, they had removed the feature that had missing values greater than 40% and imputed the rest using the mean of their respective column. They also discarded the data that were repetitive using Pearson’s correlation coefficient. At last, they trained LGBM on top 36 features, obtained from feature importance analysis of 68 features which was interpreted using SAPS, XGBoost, and LGBM. They achieved an accuracy (80.2%), sensitivity (74.77%), specificity (83.94%), and AUROC (81.98%).
