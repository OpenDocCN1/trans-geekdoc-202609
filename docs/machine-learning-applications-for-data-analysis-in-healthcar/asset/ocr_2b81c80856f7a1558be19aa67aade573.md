# ABSTRACT

This chapter provides a simplified overview of early detection of coronary heart disease (CHD) from different types of data sources of subjects. It also provides separate block diagram with concise explanation of machine learning (ML)/deep learning (DL) classification models with different types of inputs. It deals with the development and performance evaluation of naïve Bayes (NB), long-short term memory (LSTM), generative adversarial network (GAN), and ensemble model of GAN and LSTM. The performance metrics in terms of accuracy, F1-score and area under the curve (AUC) obtained in simulating DL/ML/ensemble models along with receiver operating characteristics (ROC) plots are also provided in this chapter. It is observed from the results of the simulation study that the GAN model provides the best performance in terms of accuracy (0.978), F1-score (0.975), and AUC value (0.981) for MIT-BIH ECG dataset compared to LSTM and NB models.
