Tokenization: Split the text into a list of words. Before applying NLP, we first tokenize the text into list of words. We do it because the meaning of the text can be interpreted by analyzing the words.

Stemming: Reducing derived word into stem/root word. It is a normalization technique. It helps to find out similar words when we search in our whole corpus.

Lemmatization: Similar to Stemming but returns actual dictionary word. Thus, the word we get after lemmatization carries similar meaning to the original word.
