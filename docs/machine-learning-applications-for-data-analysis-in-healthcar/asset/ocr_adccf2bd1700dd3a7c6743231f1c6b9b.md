An improved competitive and magnitude code is developed in 2010 [2]. This uses Gabor filters to extract the magnitude and orientation information. This information is further used toset up a code map that is based on the competitive code. This computed angular and magnitude distance is fused and the minimum distance is considered the final distance. This proposed algorithm is compared with one standard coding algorithm and found better performance.

The concept of the monogenic code was proposed [8] to fast features extract from a two-dimensional signal f(x,y). The monogenic signal is defined as the combination of f(x,y) and its Riesz transform which is a vector-valued extension of the Hilbert transform in the 2D Euclidean space. The code represents the 3 bits of the monogenic signal that were extracted from the pixel. It shows the phase information and orientation of the pixel. This algorithm alsoshows similar accuracy in comparison to the state-of-the-art method of FKP recognition.

In Ref. [10], the author proposed a new coding method that has the advantages of high accuracy, robustness, and compactness. To find the above code, Riesz transform identifies andcharacterizes the visual patterns of the FKP image and also encodes the local patches using second-order Riesz transform. A 6-bit coding scheme namely the Riesz Compcode was developed. This Riesz Compcode is a 6-bit coding scheme that combines the advantages of Riesz transformation and Compcode in characterizing the local FKP feature together. A normalized Hamming distance is computed at the matching stage of the proposed work and this scheme of the coding algorithm shows better performance in terms of recognition accuracy when compared with another coding algorithm.
