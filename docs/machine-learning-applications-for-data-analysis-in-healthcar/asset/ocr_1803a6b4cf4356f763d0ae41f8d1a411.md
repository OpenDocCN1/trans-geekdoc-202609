$idf\left(w\right)=log\left(\frac{N}{df_i}\right)$

TF–IDF: TF–IDF is simply the TF multiplied by the IDF.

$w_{i,j}=tf_{i,j}\times log\left(\frac{N}{df_i}\right)$

For every accident document, we get the TF–IDF value for each word, and the higher the TF–IDF value signifies the importance of that word. Thus, across each document, we get the most important word by seeing the word containing the highest TF–IDF value in that corresponding document. This TF–IDF matrix is used as an input for the linear SVC.
