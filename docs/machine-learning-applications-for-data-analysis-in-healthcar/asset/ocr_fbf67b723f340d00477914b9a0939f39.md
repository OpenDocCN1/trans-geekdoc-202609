# 7.3 MOLECULAR DOCKING

Molecular docking refers to fitting in the potential ligands in the active site of the target protein and generates the least energy, best-fit molecular conformation. Various molecular parameters are analyzed during docking followed by multiple iterative rounds to minimize the energy using algorithm like Newton–Raphson, steepest descent, and conjugate variate methodologies [36]. Molecular docking generates plethora of docked structures and conformations which are then categorized using scoring function feature. Scoring function is based on multiple parameters such as free energy, topological properties, electronic structure, stability of complexes, binding energy, root mean square deviation, and so on [37].

The accurate ligand-binding conformation depends on two rules which are as follows:

+   - Conformation space which helps in finding suitable binding regions.
+   - Binding energy of each prediction is correlated with each conformation.
