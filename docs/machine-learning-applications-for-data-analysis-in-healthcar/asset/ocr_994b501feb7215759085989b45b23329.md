Homology modeling is very useful in predicting protein structure when only sequence data is available. When a target protein of an unknown structure has a structural homolog in the database, the structure of the target protein can be modeled by using a template. This method is composed of six basic steps:

+   * Template selection: FASTA and BLAST are used for sequence alignment to find the template protein for the target protein. Minimum 35% sequence similarity should be there.
+   * Target-template sequence alignment: After finding a template sequence, alignment of the query sequence with the template sequence is carried out by using software T-coffee and PRALINE [20].
+   * Model building: It has two substeps known as the backbone model building and loop modeling.
+   * After model building, Side-chain refinement is done using algorithms like SCWRL.
+   * Built model is optimized by model refinement procedures. Model refinement is done by using energy minimization functions. We use software like GROMOS for model refinement.
+   * Model evaluation is carried out by PROCHECK and WHAT IF.

After the prediction of three-dimensional structure of the target, it is essential to correlate the model by checking the stereochemical properties and this is done by assessing the prediction structures using Ramachandran plot [21]. This helps in determining torsion angles ψ and φ and help in providing insight about the peptides structure. After applying Ramachandran plot, predicting the active site of the target protein where the ligand will bind, is an essential step. Multiple freely available tools and software are used for active site or binding cavity residues prediction. These methods are based on the evaluation of the interaction energy and van der Waals forces. Q-site finder is one such tool which is used for active-site prediction. Q-site finder is an energy-based method commonly used for binding-site prediction [22]. In this method, van der Waals interaction energies of proteins are calculated with a methyl probe. Those that have favorable energy are employed.
