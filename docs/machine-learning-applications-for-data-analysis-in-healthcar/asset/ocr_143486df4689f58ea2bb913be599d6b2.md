To find the root cause of accidents, a custom-trained NER (named entity recognition) model is used. Basically, NER model is a method to extract the key entity from the text. But before applying the NER model, it is necessary to annotate the text data. Over 450 text narratives are annotated. Further, two desired entities, namely, root causes and objects, involved in an accident/incident are labeled. The causation sentences are categorized into four levels by identifying the number of clusters using the elbow method and linear support vector classifier (SVC). It is found the most frequently occurring words in whole corpus, called top event related to accidents are fire, fall down, slipped, and gas leakage. Along with this, the bow-tie diagram is plotted using the open-source BowtieXP software. Bow-tie diagram gives an effective risk assessment process to systematically assess the potential risks.
