# 13.1 INTRODUCTION

Because of the COVID-19 pestilence, people all over the world need to take steps to stop it from spreading. Face masks are among the most efficient ways to stop the virus from spreading. But it can be hard to make sure that everyone in public places wears a mask at all times. In this situation, making face mask detection systems that work automatically can be a key part of lowering the risk of getting sick.

In this chapter, we propose a way to solve this problem by making a face mask detection system using ResNet-50, fuzzy c-mean segmentation, and bilinear interpolation. The proposed system is meant to automatically tell if people in an image are wearing face masks or not. It could be added to existing surveillance systems to keep track of people in real time. Overall, our research demonstrates the potential of using deep learning techniques and image processing algorithms to automate the face mask detection procedure, offering a practical solution to help containing the spread of COVID-19.

# 13.1.1 DEEP LEARNING

It is a specialized branch of machine learning. Deep learning trains multi-layered neural networks to do complex tasks. Deep learning algorithms use vast amounts of data to automatically learn characteristics and patterns for accurate predictions and classifications.

Deep learning has transformed computer vision, NLP, speech recognition, and robotics. Deep learning has enabled accurate, scalable models for image classification, object identification, segmentation, language translation, and speech synthesis.

Deep learning algorithms work well with big data because they can learn from plenty of data. Deep learning has also advanced drug development, genetics, and customized medicine by analyzing difficult datasets.
