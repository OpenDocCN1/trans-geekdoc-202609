# 1.4.2.2 BALANCING DATA

As we can perceive from the data presented in Figure 1.3, we can see that our data are highly unbalanced with a ratio of approximately 1:6 for death to alive respectively. So, this means that our data are highly imbalanced and there is a need for balancing the data to avoid any chances of model biasing toward the majority class and hence deteriorating the overall performance of the model. This study of the dataset implies that we need to balance our data to achieve prime performance from our model. As we know, there are two ways to perform data balancing procedures one of that is undersampling, which randomly chooses the data of majority class and deletes it until both our data are equal and second technique is oversampling, which increases the data of minority class by making copies of the data present in it and hence increasing it until both data becomes equal. We rejected the undersampling technique because while deleting the data values, it might delete some data which carry meaningful insights toward the result formation of the model so we chose an oversampling technique and balanced our data using SMOTE.
