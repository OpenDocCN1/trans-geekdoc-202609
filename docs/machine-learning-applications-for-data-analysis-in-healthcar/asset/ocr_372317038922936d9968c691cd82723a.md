# 10.4 PERFORMANCE ANALYSIS

The performance analysis is done based on four parameters: TP, TN, FP, and FN which is true positive, true negative, false positive, and false negative, respectively. Equation 10.5 is used to calculate the “Accuracy” as follows.

# 10.4.1 ACCURACY (ACC)

The accuracy (ACC) [35] is calculated as the total TP (\(\alpha\)) and TN (\(\lambda\)) records count divided by the total number of instances (\(\alpha\) = TP, \(\lambda\) = TN, \(\beta\) = FN, \(\Omega\) = FP). Equation 10.5 is used to calculate the “Accuracy” as follows:

$$ACC = \frac{\alpha + \lambda}{\alpha + \lambda + \beta + \Omega}$$ (10.5)

# 10.4.2 PRECISION (PE)

The precision (PE) [36] is calculated as the ratio of total true positive (\(\alpha\)) records count by the total number of instances (\(\alpha\) = TP, \(\beta\) = FN). The “precision” is calculated using Equation 10.6 as follows:

$$SN = \frac{\alpha}{\alpha + \beta}$$ (10.6)
