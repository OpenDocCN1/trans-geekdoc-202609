# ## 12.2.3 OTHER RECOGNITION ALGORITHM

In the literature, several image processing techniques are used to extract texture features, local, global, and line features from FKP to either independently or combined manner. The local and global combined information provides more information and hence better recognition performance.

A technique known as local global information combination (LGIC) was proposed [12], and based on psychophysics and neurophysiology study, the author states that both local and global information are crucial for FKP recognition. The local feature is orientation information whchis extracted by the Gabor filter using four scales and six orientations wavelet. This procedure is suitable for extracting features from images with an abundant line-like structure available and has advantages like high accuracy, robustness to light intensity variation, and computation efficiency. The global feature is extracted by increasing the scale to infinity of the Gabor filter and obtaining the Fourier coefficient from the transformed FKP image.
