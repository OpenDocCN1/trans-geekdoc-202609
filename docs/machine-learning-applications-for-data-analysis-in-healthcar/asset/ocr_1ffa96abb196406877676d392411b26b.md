# 12.3 BIOMETRIC SYSTEM BASIC BLOCK DIAGRAM

Originally, the biometric system is a pattern recognition system that obtains the biometric data from an individual, draws out a primary characteristic set from the data, differentiates this characteristic set against the characteristic set(s) reserved in the database, and results in a decision based on the differentiation.

A biometric system thus has the following basic modules: a raw data acquisition module, a quality improvement module (preprocessing module), a matching module, feature extraction module, and a database module. Figure 12.1 describes the basic block diagram of the biometric system.

# 12.3.1 DATA ACQUISITION

Raw data from the individual may be obtained by using an appropriate sensor, a camera,or a scanner. This module must be capable of acquiring good-quality images for the biometric system to provide good performance.

# 12.3.2 PREPROCESSING

The function of this module is to assess the quality of the raw data obtained from the previous stage. Any preprocessing algorithm may be applied to the raw data to enhance itsquality so that it is suitable for feature extraction.
