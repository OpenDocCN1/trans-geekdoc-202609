Hence, a stacking ensemble model is proposed here, consisting of six base learners (random forest [RF], extreme gradient boosting [XGB], support vector machine [SVM], K-nearest neighbors [KNN], decision tree classifier [DT], adaptive gradient boost [AB], gradient boosting [GB], and histogram-based gradient boosting [HGB]) and light gradient boosting machine (LGBM) as metalearner which we have chosen from a pool of 12 ML classification algorithms such as AB, GB, LGBM, SVM, RF, logistic regression (LR), DT, XGB, HGB, Gaussian naïve Bayes (GNB), Bernoulli naïve Bayes (BNB), and KNN.

The various ML proposed model has less significant performances in majority of the cases related to in-hospital mortality prediction in ICU patients [4]. In this regard, we have observed many difficulties that all the medical datasets have two things in common and that is highly unbalanced and data with lots of missing values [5, 6]. Data extracting is a more challenging task to control the high volume of missing values within the dataset due to irregular sampling [7]. Data imbalance makes the training procedure more hectic and in turn deteriorates the performance of the model in prognosticating the outcome [8]. Also, it is stated by Anand et al. [9] that each and every algorithm has its own advantages and drawbacks. So before applying any algorithms, the data were processed thoroughly and all the missing values were imputed and the data were balanced and scaled so that the results do not get biased or degraded by any means [10, 11].

After preprocessing the data, we divided the data into train and test splits and trained all of our 12 ML algorithms mentioned above using our training data having K-fold cross-validation (CV) of value 10 and then tested all our models. After this, we finely tuned the models that were yielding better results. Thereafter, testing and evaluating many different combinations of tuned models for metalearner and base learners of our stacking ensemble model, we got the best results while using LGBM as metalearner and RF, XGB, SVM, KNN, DT, AB, GB, and HGB as base learners. Hence, declaring this as our proposed model which achieves an accuracy of 0.982, F1 score 0.977, area under the receiver operating characteristic curve (AUROC) 0.977, recall 0.969, precision 0.984, Cohen kappa 0.955, standard deviation 0.64.
