## 5.5 GENERALIZED ML, DL, AND IOT PLATFORM-BASED CLASSIFIER MODELS FOR CVD DETECTION

### 5.5.1 ML-BASED CVD DETECTOR

In this section, the generalized block diagrams of various classification schemes have been presented. Figure 5.1 provides an adaptive classification model for detecting CVD. This scheme takes samples of either ECG signal/heart sound/clinical test data/ICG/MCG/CT images as inputs. Subsequently features are extracted and if needed these are reduced to make the classifier simple. These features are then fed to the model for detection purposes. The list of features extraction methods is given in Table 5.4. The extracted HD-related features are passed through any of the classifiers listed in Table 5.5. In supervised learning approach, the error term computed between desired and predicted classes are used in the learning algorithm to update the trained parameters of the classifier. After successful training of the classifiers, the parameters are frozen. The trained model is subsequently used for validation purpose using the feature sets of patients which have not been used for training purpose.

### 5.5.2 THE DL-BASED CVD DETECTOR

Obtaining the desired features for achieving better classification is a complex task. If the features chosen are not appropriate, the classification accuracy goes down. To alleviate this problem, the DL-based classifiers have been reported in the literature which essentially do two main tasks: features extraction and classification. The block diagram of generalized DL-based classifier is shown in Figure 5.2. As may be evident, one single block contains both features extraction and classifier. For example, in the case of CNN classifier, the set of convolution operations extract the desired features. The pooling operation reduces the size of features vector.

FIGURE 5.2 Generalized block diagram of DL-based CVD detection model.

### 5.5.3 IOT PLATFORM-BASED CLASSIFIER FOR CVD DETECTION

The IoT platform-based CVD detection model is shown in Figure 5.3. The first block contains the direct noninvasive test signal obtained from the patients of remote places. This extracted signal (ECG/sound signal/ICG/MCG/CT images) is discretized and the samples are passed to cloud data center through sensor network and gateway. In this case also, the samples are passed through the preprocessing block comprising of low pass filter followed by wavelet transform-based denoiser. The preprocessed data is then used to extract features extraction and subsequently used for the classification of CVD.

### 5.5.4 ENSEMBLE CLASSIFIER FOR CVD DETECTION

## 5.6 EXPERIMENTAL RESULTS

The performance measures during training and validation phases have been evaluated by simulating the naïve Bayes (NB), long short-term memory (LSTM), and generative adversarial network (GAN) models using MIT-BIH HD dataset. In addition, the ensemble model of LSTM-GAN is also simulated using the same dataset. The various results have been obtained and the details have been presented in Ref. [18]. Some of the reported results of this article have been provided in this section for ease of understanding and to carry out further research in this field.

The comparison of accuracy plots of NB-based CVD detection model during training and validation phases is shown in Figure 5.5. It is observed, as expected, that the accuracy during the validation phase is lower than that during training phase. The accuracy increases steadily during training until it achieves almost a constant value after successful training of the model. A similar plot for LSTM model is presented in Figure 5.6. In the case of GAN-based DL model similar accuracy plot has been obtained through a simulation study and is shown in Figure 5.7. This plot exhibits the comparison of accuracy of generator and discriminator parts of GAN. The receiver operating characteristic (ROC) plot of a model is very important as its area under the curve (AUC) signifies the performance potential of a detector. The ROC plots of various ML and DL models have been obtained using simulation study and by MIT-BIH dataset. The comparative ROC plots of various classification models are shown in Figure 5.8. Also the corresponding AUC value of each model is listed in the same figure. It may be noted that the higher the AUC, the better is the detection efficiency of a model. The three performance measures: Accuracy, $F_1$ score, and AUC of NB, LSTM, GAN, and ensemble of GAN-LSTM models obtained from the simulation study and have been presented in Table 5.6. It is observed from Table 5.6 that GAN-LSTM ensemble model provides the best performance of classification yielding 0.992, 0.987, and 0.984 values in terms of accuracy, $F_1$ score, and AUC, respectively. In descending order of these performances, the second, third, and fourth ranks of the models are GAN, LSTM, and NB. To assess the consistent performance of these models, simulation study using other datasets should also be carried out and the results need to be analyzed.
