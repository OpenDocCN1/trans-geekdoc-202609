## 1.2 BACKGROUND ON ML ALGORITHMS

### 1.2.1 SUPPORT VECTOR MACHINE

SVM is an algorithm which comes under the supervised category of ML algorithms which finds its place in solving both classification and regression tasks [12] but mostly preferred for classification tasks. This algorithm makes a clear line of distinction known as hyperplane between the data points that gets plotted according to the input data and it classifies data based on the distinction made by the corresponding hyperplane. This algorithm is fast to train unlike other algorithms based on trees. It can also be used on datasets with many rows and columns. It generally gives good results for the datasets where the distinction between data points can be made easily.

### 1.2.2 RANDOM FOREST

This algorithm is present in the supervised category of ML algorithm which is predominantly used in both regression and classification type problems [13]. Multiple DTs are generated on the training data and then the most voted or most prevailing result is considered as the final result. Since RF uses multiple DTs to train the algorithm by selecting the data in a random manner, it ensures that every data contributes their meaningful insights toward the accurate model formation which gives efficient results. It also ensures that the model does not overfit by considering the majority of the votes.

### 1.2.3 DECISION TREE

It is a tool that has applications spanning various different areas [14]. This algorithm is also a part of the supervised algorithm family of ML which deals with regression as well as classification problems. It is the most fundamental algorithm which forms the basis of many different ML algorithms like RF, gradient-boosted trees, XGB, and so on. It can handle both categorical and numerical data. Each node of this algorithm represents a decision that is to be taken, to go further down the tree and reach the leaf node that represents the result or the outcome of the classification task. It cleaves its node focusing on concepts like information gain, Gini index, and entropy. Its aim is to divide the whole feature space and infer meaningful information from it and create decision nodes that help in fabricating the overall model and hence prognosticating the outcome of the problem.

### 1.2.4 LOGISTIC REGRESSION

LR is one of the robust members of the supervised ML algorithm family which is easy to implement [15]. It always finds its usage whenever there is a discussion for a binary classification task as it is based on a sigmoid function which only has two outcomes either zero or one. It is trouble-free to execute, explain, and very efficient to train. It makes no presumptions in the feature space about distributions of classes and it can be easily prolonged to multiple classes. We can also customize the default threshold value which is 0.5 to any number between 0 and 1 whenever it is required to meet the demands of our problem and achieve better performance.

### 1.2.5 GAUSSIAN NAIVE BAYES

GNB is also a supervised ML algorithm which is based on the principles of naive Bayes and Gaussian normal distribution [16]. It is generally used for classification tasks but it can be used for regression tasks as well if some changes are made in the algorithm. A presumption is often taken that the contiguous values analogous to each class are disseminated according to normal distribution while working with contiguous data. It can also give high accuracy in comparison to other algorithms in datasets having less data as it does not require high amounts of data to be trained on. It can be used on datasets with high dimensionality as its training time is very less and its unresponsiveness to outliers makes it a highly robust, efficient, and reliable algorithm.

### 1.2.6 BERNOULLI NAIVE BAYES

BNB is another algorithm based on the principles of naive Bayes and uses Bernoulli distribution to predict the outcome [16]. As it is based on Bernoulli distribution, it finds its usage when the data are discontinuous. In this algorithm, all features are given the same priority and as the features are not interrelated; they can independently take part in prognosticating the final outcome, no feature has fear of getting left behind as the model penalizes itself for doing so. It sets aside the values that are continuous and only accounts for discrete or discontinuous data. It is blazingly fast in comparison with other classification algorithms, as it treats each feature separately with its corresponding binary values and it explicitly penalizes the model for absence of any of its features which is crucial for speculating the outcome. Due to its rapid prediction capability, it can find its usage in making real-time predictions and it is unresponsive to irrelevant features.

### 1.2.7 K-NEAREST NEIGHBOR

KNN is a kind of algorithm which is merely based on intuition that data belonging to a similar group would have a similar impact on new data points' outcome which belongs to the same group [17]. This algorithm belongs to the supervised category of ML algorithm and is majorly used in classification use cases. It does not have any parameter to train according to the dataset, instead, it stores all the data that it gets and utilizes all those stored at the time of classification. It is one of the simplest ML algorithms and requires less time to train as compared to tree-based algorithms. It can also be used for regression problem statements by making some changes in the underlying algorithm.

### 1.2.8 ADAPTIVE BOOSTING CLASSIFIER

Adaptive boosting is the most basic boosting ensemble algorithm which also belongs to the supervised category of the ML algorithms and can be used for both classification as well as regression use cases [18]. It used multiple similar kinds of models to prognosticate the final outcome. The models that are used in fabricating this model are also known as weak learners. Each weak learner that is appended to the model with updated values of weight, tries to diminish the error of the previous model as a whole and at the end due to this the overall performance of the model increases, hence it can predict the outcome more accurately. It has proven to give better results as compared to DTs as the aggregation makes it more robust and increases the overall performance of the model.
