# 11.6 DISCUSSION

We collected more than 500 accident text data from the workplace
at a distinct working site. Data comprise raw text data, so we first did
preprocess like stop word removal, convert to lowercase and punctuation
removal, tokenization, stemming, and lemmatization, thus bringing the
data in a correct usable format. In order to find out the root causation
and object involved in an accident, we applied a custom-trained NER
model on annotated 450 text data with the label of root cause and object.
This custom-trained NER model gave F1 score of 0.84 which is better
than compared with a pretrained NER model with F1 score of only 0.51.
Also, we find out the potential sentence which contains both root cause
word and object using regular expression technique. To categorize the text
containing causation words, we first applied the elbow method to get the
optimal number of clusters, we got the output of 4–6. Linear SVC gives
good accuracy over NB and RF classifiers. The accuracy we got from
linear SVC is 66%. Finally, we build a bow-tie diagram using open-source
BowtieXP software for better visualization of accident reports. Also, we
find the most frequently occurring words in our whole corpus, called top
event related to accidents like fire, fall down, slipped, and gas leakage.
On the left of top event, we suggested preventive measures for the threat,
and on the right, we suggested mitigative measures so that we can prevent
future danger or injury.
