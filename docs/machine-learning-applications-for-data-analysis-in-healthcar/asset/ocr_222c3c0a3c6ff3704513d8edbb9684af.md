# 12.2.2 CODING-BASED FKP RECOGNITION ALGORITHM

In the coding-based technique, the FKP image is segmented into several subimages, and information like orientation or edges is extracted from each subdivided image. Several codingalgorithms are proposed in the literature to improve the recognition performance of FKPs. These coding techniques are widely used for palmprint recognition and found good recognition results. The finger knuckle surface is very rich in lines and creases and highlyunique in individuals. These techniques of coding are mainly based on the concept of iris code.

A research work exploited the local feature in comparison to the global feature for reliable performance [8]. The preprocessing step helps to minimize the effects of light variation on the texture features and improves the overall performance. To avoid wrapping around an inherent modulo operation, finite radon transform and modified finite radon transform (MFRT) are commonly used to determine the orientation of the grease lines or knuckle lines ina local neighborhood region. The dominant direction at each pixel is computed and coded intobinary bits called knuckle code. The normalized Hamming distance is used to compute the similarity measurement between two FKP and these techniques achieved 98.6% accuracy.
