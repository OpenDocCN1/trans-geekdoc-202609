# 1.2.4 LOGISTIC REGRESSION

LR is one of the robust members of the supervised ML algorithm family which is easy to implement [15]. It always finds its usage whenever there is a discussion for a binary classification task as it is based on a sigmoid function which only has two outcomes either zero or one. It is trouble-free to execute, explain, and very efficient to train. It makes no presumptions in the feature space about distributions of classes and it can be easily prolonged to multiple classes. We can also customize the default threshold value which is 0.5 to any number between 0 and 1 whenever its required to meet the demands of our problem and achieve better performance.

# 1.2. GAUSSIAN NAIVE BAYES

GNB is also a supervised ML algorithm whichis based on the principles of naive Bayes and Gaussian normal distribution [16]. It is generally used for classification tasks but it can be used for regression tasks as well if some changes are made in the algorithm. A presumption is often taken that the contiguous values analogous to each class are disseminated according to normal distribution while working with contiguous data. It can also give high accuracy in comparison to other algorithms in datasets having less data as it does not require high amounts of data to be trained on. It can be used on datasets with high dimensionality as its training time is very less and its unresponsiveness to outliers makes it a highly robust, efficient, and reliable algorithm.

# 1.2.6 BERNOULLI NAIVE BAYES

BNB is another algorithm based on the principles of naive Bayes and uses Bernoulli distribution to predict the outcome [16]. As it is based on Bernoulli distribution, it finds its usage when the data are discontinuous.
