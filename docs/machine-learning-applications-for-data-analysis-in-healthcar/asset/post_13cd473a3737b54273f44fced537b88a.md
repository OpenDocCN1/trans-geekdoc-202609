## 1.4.4 TUNING MODEL

While developing any model, there are chances that the model might not perform up to its full potential and thereby resulting in a suboptimal solution. Tuning helps us in unlocking the maximum potential of any model for a given problem without overfitting or deviating much from the actual results. A model is tuned by changing and selecting the best hyperparameter values that give the optimal results for a given problem. Selecting correct hyperparameters is very important as it highly influences the outcome of the model. The hyperparameter values are not something that we can predict. However, we may acquire these values from previous similar problems or using hit and trial methods, but by doing this there is a high chance of getting suboptimal results. Therefore, hyperparameter optimization techniques like Random Search CV or Grid Search CV are applied on the models for which the best-suitting hyperparameters are to be found. In this technique, the best fitting hyperparameter values are chosen from a pool of values which was provided to a hyperparameter optimization technique.

So, we thought of tuning our ML models using Random Search CV to get the best performance out of our models. As discussed previously, we too provided a pool of values to this technique from which it randomly selects different combinations of parameters and trains the model using those sets of parameters and record its results. In the end, it returns the set of hyperparameters which yields the best result. After tuning all the models, we obtained the hyperparameter values as in Table 1.6.
