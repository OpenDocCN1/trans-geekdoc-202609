
## 1.2.9 GRADIENT BOOST

This is one of the most robust algorithms in ML [19]. GB is an ML procedure which has its applications in both regression and classification tasks. It furnishes a prognostic model which is basically DTs in manifestation of an ensemble of weak prediction models. GB generally surpasses RFs because it minimizes the errors by constructing a new model each time on the flaws of the preceding models. A gradient-boosted tree is fabricated in a hierarchical manner as in other boosting procedures, but it generalizes other procedures by optimizing randomly differentiable loss functions. The bias error of the model can be diminished by using a GB algorithm and therefore it enhances the efficiency in predicting the outcome of our binary classification task and hence it increases the accuracy of our overall model.

## 1.2.10 LIGHT GRADIENT BOOSTING MACHINE

LGBM is another boosting algorithm which comes under the family of supervised ML, and it is widely used in the industry because of its better performance [20]. It is highly memory efficient and takes less time to train with respect to the majority of the ML algorithms. It can be used for classification as well as regression use cases. This algorithm is based on trees, it rapidly decreases the error of the overall model as it always tries to split its nodes leaf-wise fashion hence fabricating the model leaf-wise and continuing to grow the leaf with high loss in order to reduce it. This is the reason why it performs better than other algorithms which are based on trees performing level-wise splits. LGBM algorithm uses histograms to bucket out contiguous feature values into distinct bins which enhances the speed of the training procedure; it also results in minimized memory usage. As compared to XGB, it is adept in executing equally well with enormous datasets with a remarkable depletion in training time. All these features made this algorithm the best fit for our dataset.

## 1.2.11 HISTOGRAM-BASED GRADIENT BOOSTING

HGB was introduced as an alternative to the GB algorithm’s huge time-consuming nature while training on the dataset [21]. GB slows down the training procedure when the data has numerous rows. So to overcome this drawback, HGB was introduced which was also fabricated using trees and it converted the contiguous input data into individual distinct discrete packets and stored them in a histogram-like structure which helps it in saving time during the formation of trees. This model building approach using histograms reduces the overall model training time by many folds. This ML ensemble also comes under supervised machine category and can be used for classification as well as regression tasks. This approximator has indigenous support for absent (NaNs) values.

## 1.2.12 EXTREME GRADIENT BOOSTING

XGB is a supervised ML algorithm which can be used for both classification and regression use cases. It is built to perform tasks with high efficiency and is easy to use and supple [22]. Under the GB framework, it applies the ML algorithms. XGB solves several data science tasks in a brisk and precise manner because it provides boosting of trees parallelly (also known as GBDT, GBM). Having an enhanced performance and pace in tree-based ML algorithms, it is one of the popular GB ensemble methods. It smartly and efficiently manages the memory for large datasets exceeding RAM, supports parallel processing, having a diversity of regularizations which help in minimizing overfitting, has good cache optimization, supports auto tree pruning which implies that the DTs will not grow further after certain limits internally, has a built-in CV, can handle outliers and missing values up to some extent. All these features made XGBoost suitable for our dataset.

## 1.3 RELATED WORK

In Ref. [1], authors have proposed a nomogram that will be able to prognosticate the in-hospital mortality of heart-failure patients which are admitted in the ICU of the hospitals. In the data preprocessing part, they imputed all the missing values in their dataset using the mean of their respective feature column. The ML algorithms that they used in their study were (XGB) and Least Absolute Shrinkage and Selection Operator (LASSO) regression. They had also used the GWTG-HF risk model. At the end, they chose XGB as their final model as it was performing better than the rest of the models, the area under receiver operating characteristic curve was 0.8416.

In Ref. [23], a stacking ensemble model was proposed by authors who foretell the mortality of the patients admitted in the ICU. They used five different algorithms, that is, KNN, LR, linear discriminant analysis for dimensionality reduction, DT, and multilayered perceptron on a time-stamped dataset of 10,664 patients having 80 features. Six different subsets of data were created from the most important features column. Before undergoing any undersampling technique to balance the dataset, the data were thoroughly preprocessed by handling missing values, using normalization, and removal of any noise present in the dataset. Their model sees an uplift in the performance on implementing a stacking model where LR acts as a metalearner. They achieved AUROC 93.3%, precision 96.4%, accuracy 94.4%, recall 91.1%, and \( F_1 \) score 93.7% on using \( k \)-fold CV evaluation process.

In Ref. [24], the authors proposed to build a model whose decision-making capability is much better as compared to others existing models so as to properly assign the beds in the ICU to the patients in need. They trained their models using two algorithms, that is, linear discriminant analysis classifier and SVM. Before undergoing the training phase, chi-square distribution was used to refine the data and SMOTE (synthetic minority oversampling technique) was used to deal with the imbalanced nature of the dataset. A total of 12 features were used for prognosticating the mortality and a \( k \)-fold CV value of five was used to evaluate the SVM model. Between their presented models in the chapter, SVM works better with a recall of 69%, accuracy 77%, and fall out (0.5).

In Ref. [25], they have proposed a model that is useful in prognosticating extubation failure. The ML algorithm that they used for fabricating their model was LGBM. They have also shown that this algorithm performs better than algorithms like LR, XGB, ANN, and SVM. In the data processing part, they had removed the feature that had missing values greater than 40% and imputed the rest using the mean of their respective column. They also discarded the data that were repetitive using Pearson’s correlation coefficient. At last, they trained LGBM on top 36 features, obtained from feature importance analysis of 68 features which was interpreted using SAPS, XGBoost, and LGBM. They achieved an accuracy (80.2%), sensitivity (74.77%), specificity (83.94%), and AUROC (81.98%).

In Ref. [26], the authors had presented a model for in-hospital mortality prediction using a balanced random forest (BRF) for ICU patients. They had taken into account the complication that comes with unbalanced data. They derived their data from the MIMIC-III database and chose seven distinct time series data from it and then extracted six statistical features from each of them which contributed to 716 features and applied LR and BRF on them. The hyperparameters of this algorithm were tuned using adjusted geometric mean (AGm). The model that was created using the BRF algorithm was performing better than the LR model as it was able to classify the inferior (class that was lesser in number) class with increased results in comparison to LR or any other benchmarking model with recall 69.52%, AUC (73.68%), and AGm (75.58%).
