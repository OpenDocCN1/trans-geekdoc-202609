A novel FKP recognition technology proposed robust FKP feature extraction and matching algorithm based on speeded-up robust features (SURF) [14]. This novel feature is extracted by following two steps: first, a coordinate system is defined based on the local convex direction map of FKP to align the FKP image and a region of interest is cropped. Second, the key points are detected using a fast Hessian detector to which orientation was assigned accordingly to the Haar wavelet responses inside a neighbor circle area of a detected key point, and an orientation invariant descriptor is constructed for each key point. In this matching method, the distance of the second-closest neighbor is matched with the distance of the first-closest neighbor. All matches are performed in which the distance ratio between the two is less than 0.6. Thus, the tentative correspondence between two key point sets of training image and template image is obtained. The RANdom SAmple Consensus (RANSAC) is formulated to remove the false matching and the final matched pair is used to determine the consistency of the palm images. This method is invariant to rotate and scale transform and provides an accurate and robustness of 90.63% for validation and 96.91% for identification purposes.
