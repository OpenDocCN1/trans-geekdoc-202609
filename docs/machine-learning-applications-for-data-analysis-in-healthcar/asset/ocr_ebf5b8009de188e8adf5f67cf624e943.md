# 11.3.4 CALCULATION OF TF-IDF (TERM FREQUENCY–INVERSE DOCUMENT FREQUENCY)

Term frequency–inverse document frequency (TF–IDF) gives us an idea about which word is most important in our documents. The document which has similar words will carry similar vector which is important for our machine learning model. The highest TF–IDF score represents a rare word in the document. This score thus generates vector of all words and used as an input to classification model such as linear SVC, naive Bayes (NB) classifier.

TF: TF is a way of normalization. The formula for TF is given as follows:

```
TF(t) = (number of times word “t” appears in a document)/(total number of words in the document)

t_{f_{i,j}} = \frac{n_{i,j}}{\sum_k n_{k,j}}
```

IDF: IDF measures how important a term is. Basically, it is to scale down the impact of tokens that occur very frequently in every document, such as “a,” “the.”

```
IDF(t) = log_e(total number of documents/number of documents with term t in it).
```
