+   - depiction of the binding site,
+   - ligand fixing with the specific binding region, and
+   - assessing the energy of interaction between a specific ligand–receptor complex [39].

Pharmacophore modeling is required as a preliminary step in many cases before going for molecular docking. Pharmacophore is a 3D arrangement of functional groups having a molecular structure. Pharmacophore modeling refers to generating a model of the specific conformation of active functional groups which is derived from a set of known ligands that are selected for a target [40]. This model depends upon steric and electronic features. It uses algorithms that encompass the following steps: input, conformational search, feature extraction, representation of structure, pattern identification, and scoring [41]. It is generally used to select hits for docking studies. Scoring functions are mathematical tools by which binding affinity of two molecules is predicted after they are docked.

# 7.3.1 DOCKING PARAMETERS

Docking has a large number of input parameters based on its functionality. We need to check accessible surface area, force field parameters acting on each molecule, dipole moment, steary complementary between receptor and ligand, physicochemical properties of the ligand and receptor. Docking can be carried by varying different parameters listed below:

+   - Flexible ligand: Used to relax an input conformation; have parameters such as anchor search, anchor size, and torsion drive [42].
+   - Orient ligand: Helps in orientation search; done by matching.
+   - Score ligand: Does scoring of orientation.
+   - Minimize ligand: It minimizes conformations and improves the efficiency.
+   - Multiple ligand
+   - Chemical screen: Allows rapid filtering of data based on 3D structure.
+   - Random seed: Figure to seed the random number generator [43].
