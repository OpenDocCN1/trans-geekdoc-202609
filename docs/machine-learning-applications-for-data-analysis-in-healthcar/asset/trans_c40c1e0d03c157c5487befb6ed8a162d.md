## 4.6 拟议系统及其优势

在所参考的基础文章或早期工作（《基于CNN LSTM方法从X光图像分类膝骨关节炎严重程度的新方法》，作者Rima Tri Wahyuningrum及其他合著者）中，作者使用了X光图像数据集并实现了CNN模型，但所得准确率为75.28%。而在我们的拟议系统中，我们将使用包含X光/MRI的混合数据集，并结合先进的图像预处理和CNN模型，以获得更高的准确率，这将有助于在早期阶段以更准确的结果预测KOA。
