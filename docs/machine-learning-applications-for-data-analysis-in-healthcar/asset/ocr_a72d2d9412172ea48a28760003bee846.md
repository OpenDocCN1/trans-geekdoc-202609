# 3.6 CONCLUSION AND FUTURE WORKS

# 3.6.1 CONCLUSION

Our app is built on the fact that some people around the world could not afford to go to expensive treatments by doctors offline. So we would make it online and much more interactive so he/she does not feel that disconnected from the real process. Our app has achieved the proposed ideas that wanted to achieve the above-set objectives. We will enhance some things which will make it much more attractive and effective as well. This app has been made by keeping in mind the fact why users would use this and how beneficial it can he/she be to remove depression. These types of mobile apps are really needed in today’s man-machine life scenario.
