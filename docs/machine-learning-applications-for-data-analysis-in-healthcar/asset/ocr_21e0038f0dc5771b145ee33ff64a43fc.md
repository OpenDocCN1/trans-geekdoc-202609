# 1.2.1 SUPPORT VECTOR MACHINE

SVM is an algorithm which comes under the supervised category of ML algorithms which finds its place in solving both classification and regression tasks [12] but mostly preferred for classification tasks. This algorithm makes a clear line of distinction known as hyperplane between the data points that gets plotted according to the input data and it classifies data based on the distinction made by the corresponding hyperplane. This algorithm is fast to train unlike other algorithms based on trees. It can also be used on datasets with many rows and columns. It generally gives good results for the datasets where the distinction between data points can be made easily.

# 1.2.2 RANDOM FOREST

This algorithm is present in the supervised category of ML algorithm which is predominantly used in both regression and classification type problems [13]. Multiple DTs are generated on the training data and then the most voted or most prevailing result is considered as the final result. Since RF uses multiple DTs to train the algorithm by selecting the data in a random manner, it ensures that every data contributes their meaningful insights toward the accurate model formation which gives efficient results. It also ensures that the model does not overfit by considering the majority of the votes.
