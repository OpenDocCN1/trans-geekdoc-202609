一种面向消费者、使用户能够无论身在何处、何时都利用手机识别植物的系统，可能是植物识别系统的一项新兴发展。然而，这项技术需要一个强大的解码器，能够在各种情况下识别植物的任何部分。因此，有必要创建一个包含多种植物物种及其各种环境条件的数据库。此外，未来的草本植物识别系统应能够自动推导植物特征的数学模型。出于此原因，利用3-D扫描将特别有帮助，因为它将记录每一个物理测量值。
