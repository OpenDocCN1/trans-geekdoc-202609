建议使用 VKS 模型来避免 IoT 设备的恶意路由和 DDOS 攻击。密钥验证和新密钥生成不仅能防止恶意攻击，还能防止其他漏洞。该模型已使用 Cooja 模拟器进行验证，且本章提供了伪代码。
