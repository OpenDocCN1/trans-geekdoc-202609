# 10.3 ESTIMATION OF FRACTIONAL ORDER OPTICAL FLOW

# 10.3.1 Formulation of Nonlinear Fractional Order Variational Optical Flow Model

At any pixel position, let intensity values be J(X,Y,T) and J(X+δX,Y+δY,T+δT) at spatiotemporal coordinates (X,Y,T) and (X+δX,Y+δY,T+δT), respectively. By employing the data conservation assumption (BCA) [20], we obtain

```
J(X+δX,Y+δY,T+δT) = J(X,Y,T)  (10.1)
```

where, J:Ω ⊂ R^3 → R is a volume representing a rectangular image sequence. Therefore, using Taylor series expansion in Eq. (10.1), we have

```
(∇J)^T w + J_T = 0  (10.2)
```

where ∇J = (J_X, J_Y)^T stands for the intensity gradient in the spatial region, w = (μ,v)^T is the desired optical flow field with μ(X,Y) and v(X,Y) as its X and Y flow components. Here, J_T denotes the intensity temporal derivative. The problem of optical flow estimation using Eq. (10.2) is referred to as an ill-posed problem. To convert this problem into a well posed one, it needs to be regularized by introducing an additional constraint called the smoothness constraint [20]. This constraint is laid down on the assumption that all the neighboring pixels of any pixel in an image plane move coherently. The general form of smoothness terms is as follows:

```
F(μ,v,∇μ,∇v) = F_1(μ,v) + F_2(∇μ,∇v)  (10.3)
```

where F_1 and F_2 are scalar valued functions that are convex in nature. Here, F_2(∇μ,∇v) is based on the pixel flow rate. Thus, in general, optical flow is estimated with the help of following variational functional [20, 33]

```
E(w) = ∫_Ω [(∇J^T w + J_T)^2 + F_1(μ,v) + F_2(∇μ,∇v)] dX  (10.4)
```

where X = (X,Y). The discontinuous information on images such as texture and edges are efficiently preserved by fractional order derivatives. Moreover, fractional order derivatives can be evaluated corresponding to an optimal choice of fractional order α for which the solutions are stable
