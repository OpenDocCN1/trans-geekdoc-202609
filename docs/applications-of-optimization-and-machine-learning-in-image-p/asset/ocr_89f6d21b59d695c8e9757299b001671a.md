There are different layers present in the ANNs, which are explained as follows:

+   1. Input Layers: An ANN's input layer, which is the first layer, accepts data in the format of text, numbers, audio snippets, image pixels and other formats.

+   2. Hidden Layers: The ANN model's center contains the hidden layers. A solitary hidden layer, as in a perceptron, or several hidden layers are possible. These hidden layers use the supplied data to execute multiple kinds of mathematical computations and recognize patterns.

+   3. Output Layers: The result obtained through stringent computation conducted by the center of the frame is obtained in the output layer.
