where all the neighboring pixels of the pixel at $(i, j)$ position that lie along the $\mathcal{X}$ and $\mathcal{Y}$ directions through $(i, j)$ are contained in the set $\mathscr{P}$ and \(p_{ij} = \max\big[\big|\overline{\imath} - i\big|, \big|\overline{\jmath} - j\big|\big]\).

# 10.3.2.2 Numerical Scheme

The following discussion demonstrates a system of discretized equations for the two optical flow components that are derived with the help of expression (10.19) and system Eq. (10.12):

```
\(\begin{bmatrix} \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w} + \mathcal{J}_\mathcal{T}\big)} \mathcal{J}_{\mathcal{X}\mathcal{X}} + \boldsymbol{K} & \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w} + \mathcal{J}_\mathcal{T}\big)} \mathcal{J}_{\mathcal{X}\mathcal{Y}} \\ \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w} + \mathcal{J}_\mathcal{T}\big)} \mathcal{J}_{\mathcal{X}\mathcal{Y}} & \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w} + \mathcal{J}_\mathcal{T}\big)} \mathcal{J}_{\mathcal{Y}\mathcal{Y}} + \boldsymbol{K} \end{bmatrix}\)
```

```
\(\boldsymbol{w} = 2\lambda \sum_{(\overline{\imath}, \overline{\jmath}) \in \mathscr{P}(i,j)} \boldsymbol{\omega}_{p_{ij}}^{(\alpha)} \overline{\boldsymbol{w}} - \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w}\big)} \mathcal{J}^T\)
```

For the sake of convenience, we abbreviate various terms in Eq. (10.20):

```
\(\mathcal{J}_{xx} = \mathcal{J}_{\mathcal{X}}^2, \qquad \mathcal{J}^T = \big( \mathcal{J}_{\mathcal{X}} \mathcal{J}_T, \mathcal{J}_{\mathcal{Y}} \mathcal{J}_T \big)^T\)
\(\mathcal{J}_{yy} = \mathcal{J}_{\mathcal{Y}}^2, \qquad \boldsymbol{w} = \big( \mu(\overline{\imath}, \overline{\jmath}), \nu(\overline{\imath}, \overline{\jmath}) \big),\)
\(\mathcal{J}_{xy} = \mathcal{J}_{\mathcal{X}} \mathcal{J}_{\mathcal{Y}}, \qquad \boldsymbol{K} = 2\beta^2 + 2\lambda \sum_{(\overline{\imath}, \overline{\jmath}) \in \mathscr{P}(i,j)} \boldsymbol{\omega}_{p_{ij}}^{(\alpha)}\)
```

Finally, optical flow $\boldsymbol{w}$ is estimated at each pixel using the following system of iteration equations:

```
\(\boldsymbol{w}^{(n+1)} = \mathfrak{T}^{(n)} \Bigg[ 2\lambda \sum_{(\overline{\imath}, \overline{\jmath}) \in \mathscr{P}(i,j)} \boldsymbol{\omega}_{p_{ij}}^{(\alpha)} \overline{\boldsymbol{w}}^{(n)} - \frac{1}{\boldsymbol{\psi}\big(\nabla \mathcal{J}^T \boldsymbol{w}^{(n)} + \mathcal{J}_\mathcal{T}\big)} \$
\(\Big( \mathcal{J}_{\mathcal{X}\mathcal{Y}} \boldsymbol{w}_{id}^{(n)} + \mathcal{J}^T \Big]\)
```
