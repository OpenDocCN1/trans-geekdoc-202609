# 8.3.2 Architecture for Object Detection

Object detection is a key in computer vision that focuses on classifying and localizing objects in video and images. Object detection architectures are composed of different types of networks, such as fast detection networks, shortcut connection networks and region-based networks. The first group mainly includes the single shot detector (SSD) family and the YOLO family [26, 51, 52]. The second group includes a two-stage object detector architecture (such as R-CNN, Fast-RCNN, Faster-RCNN, Mask-RCNN and others) that extracts regions of interest and then classifies objects using classifiers [22, 26, 53, 54].
