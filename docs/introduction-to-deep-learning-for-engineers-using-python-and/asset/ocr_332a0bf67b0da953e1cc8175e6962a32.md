# 7.3 UPLOAD DATA INTO STORAGE BUCKET

To upload the data folder “input” in the cloud console, follow the steps shown below.

+   1. **Step 1:** Go to GCP Navigation Menu → File Storage → CREATE BUCKET
+   2. **Step 2:** Choose a bucket name (e.g., deeplearning_bucket1) and keep on selecting “continue” to accept all the default settings (Figs. 7.4, 7.5, and 7.6).
+   3. **Step 3:** Select “CREATE” to create the bucket folder (Fig. 7.6).
+   4. **Step 4:** Select “Upload folder” from the bucket and upload the “input” folder (Fig. 7.7).
