# Inspection rulesets

Inspection rulesets allow you to customize both built-in and custom infoType detectors using context rules. The two types of inspection rules are as follows:

+   - **Exclusion rules**, which help exclude false or unwanted findings
- **Hotword rules**, which help adjust the likelihood of the finding based on how near the hotword is to the finding

To add a ruleset, first, specify one or more built-in or custom infoType detectors in the infoTypes Section. These are the infoType detectors that your rules will be modifying. Then, do the following:

+   1. Click in the **Choose infoTypes** field. The infoType or infoTypes you specified previously appear below the field in a menu, as shown in *Figure 10.5*.
