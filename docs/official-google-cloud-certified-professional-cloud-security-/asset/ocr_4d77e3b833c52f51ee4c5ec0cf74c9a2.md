# Google Cloud Armor 215

Use the Google Cloud Armor custom rules to define expressions in the match condition of one or more rules. When Cloud Armor receives a request, it analyzes it against the following expressions. Depending on whether the rules are met, inbound traffic is either denied or allowed. There are some instances of Cloud Armor expressions written in the Common Expression Language (CEL):

+   - To define expressions in a rule, use the gcloud --expression flag or the Google Cloud console.

+   - In the following example, requests from 2001:db8::32 in the AU region match the following expression:

```
origin.region_code == "AU" && inRange(origin.ip,
2001:db8::32);
```

+   - The following example matches requests from 192.0.2.0/24 and with a user agent that contains the string WordPress:

```
inRange(origin.ip, '192.0.2.0/24') && has(request,
headers['user-agent']) && request.headers['user-agent']
contains('WordPress')
```

# WAF rules

In this section, we look at the different types of rules that you can create. There are some WAF rules that can be pre-configured, but you have the option of creating custom rules to meet your requirements. Let's take a look at the options available.

You can create IP-address-based rules both at the edge and for your backend services. These rules are the IP address allowlist- and denylist-based rules. Both ipv4 and ipv6 are supported. HTTP 403 (Unauthorized), 404 (Access Denied), and 502 (Bad Gateway) responses are all possible outcomes of denies. An HTTP 429 is an error code that is returned when an application has exceeded a number of requests. This is usually caused by an action rule that limits the number of requests that can be made in a given period of time.

There are pre-configured rules based on the OWASP ModSecurity rule set version 3.0. These rules can provide you with protection from the following types of attacks:

+   - SQL injection

+   - Cross-site scripting (XSS) attacks

+   - Local file inclusion (LFI) attacks

+   - Remote file inclusion (RFI) attacks

+   - Remote code execution (RCE)
