# Security by design

Google implements robust security measures to protect employee devices and credentials. In fact, Google leverages a service accessible to all clouds to safeguard its own devices and user credentials. ThroughCorp Enterprise, Google ensures that appropriate users have timely access to designated applications. This approach involves continuous monitoring of devices and users, regular patching and updates, enforcement of strong authentication measures, and utilization of two-factor authentication (2FA). Additionally, application-level access controls access to internal applications solely for authorized users accessing the service from managed devices and network addresses or geolocations align with the established policy.

To address insider risk, all privileged user access is actively monitored. To further limit employee access, any privileged action that can be performed using automation is done. All users who have access to end-user data have their activity logged and monitored by the security team for access and patterns. https://packet.link/FuBbM

Google uses sophisticated intrusion detection techniques, where all data processing pipelines integrate with both host- and network-level signals. These signals are combined with detection rules and machine learning to identify potential threats that are monitored and actioned by security operation teams around the clock. Google also conducts an active Red Team exercise to improve security and its overall effectiveness.

# Network security

We have covered how Google owns, operates, and manages its own private network, which is fully encrypted and has TLS enforced. This not only delivers lower latency but improves security. Once customers' traffic is on Google's network, it no longer transits the public internet, making it less likely to be attacked, intercepted, or manipulated in transit. This besides, Google ensures its Google Front Ends (GFEs). When a service wants to make itself available on the internet, it can register with the GFE. The GFE performs a number of functions, such as ensuring that the correct certificates are used for terminating TLS and applying best practices as perfect forward secrecy. Google also provide protection against DDoS attacks. Google has multi-tier and multi-layer protection for DDoSes to ensure that the services being GFEs are protected from volumetric attacks. Besides GFEs, there are multiple layers of hardware- and software-based load balancers that are both network- and application-aware. All these security controls, together with Google’s global-scale infrastructure, ensure that the largest of the DDoS attacks can be mitigated and managed.

Besides these network-based security controls, Google further enforces user authentication before it allows any access to its network. The user authentication goes beyond a simple username and password and also intelligently challenges users for additional information based on risk factors. These risk factors include information about the device the user is logging in, such as the IP address and geographical location of the device. Once past controls, the user is prompted for a second factor before access is granted.
