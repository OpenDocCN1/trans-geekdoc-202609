# Filtering assets

An organization may have many assets. Because there are no filters in the preceding example, all assets are returned. You can utilize filters in SCC to get information about certain assets. Filters, where like clauses in SQL queries, only apply to objects returned by the API instead of columns.

The examples sample output displays certain fields and subfields, as well as their characteristics, that can be utilized in filters. The SCC API accepts complete JSON arrays and objects as potential property types. You can refine your results by using the following filters:

+   - Array elements
- Full JSON objects with partial string matching within the object
- JSON object subfields
