Finally, some key things to remember for the exam. Many of you will already know this, but remember to read the questions very carefully. Most questions have a scenario to paint a picture, but the actual question that is asked is in the last line. For example, a question may describe how developers in an organization are building an application that stores sensitive data and how developers and users access it. It is important to focus on aspects such as who the user is (*the developer*), how they access the application (*by identity and access control*), and what needs to be protected (*the sensitive data*). Extracting such information will help you identify the solution that addresses all areas.

Always use the option of marking the question for later if you are not sure. Sometimes, the next question is asked in a way that answers the previous question. In that case, you can mark both questions to come back to later and then revisit them if you hit submit. Keep some time at the end to revisit the questions.
