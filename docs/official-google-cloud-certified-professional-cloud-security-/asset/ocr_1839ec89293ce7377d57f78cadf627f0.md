# Trust and Compliance

Let's do a quick walk-through of how you can download these reports:

+   1. Using the filter, you can select report you want to download. The options in the filter include Industry, Region, Report Type, and Product Area. Industry has options: Industry-agnostic, such as the ISO, SOC, and CSA reports, and Government/Public sector, which refers to reports relevant to government agencies as IRAP for Australia. Please work with your Google Cloud representative to help you locate those reports.

+   2. Next, you can specify using the filter what report you want, and you will see the option to select and then download the default from Compliance Report Manager. In this example, we have left Industry as default, Region as Global, Report Type as Audit Report, and Product Area is Google Cloud.
