# Shared VPC

A Shared VPC network is like any other VPC – the difference is that it is shared. You create a Shared VPC network inside a host project. Network administrators can control via a single pane of glass all the subnets, firewall rules, interconnect/VPN, logs, and more inside the Shared VPC network. You can also create an organizational policy to restrict Shared VPC networks to host projects. The point of a Shared VPC network is to centrally control and manage all the network services that are offered by VPC.
