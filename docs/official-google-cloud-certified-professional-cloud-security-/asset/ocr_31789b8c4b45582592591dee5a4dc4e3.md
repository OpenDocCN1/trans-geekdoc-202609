# Automating user lifecycle management with Cloud Identity as the IdP

User provisioning and de-provisioning in larger enterprises can become very complex. Users leaving the organization or moving within the organization can lead to changes in the scope of applications a user has access to. In order to address this, Google Cloud Identity provides a catalog of automated provisioning connectors between third-party apps and Cloud Identity. For the SAML-based SSO section, we will look at, by using Cloud Identity and SAML-based SSO, you can use more than 300 pre-configured applications and, if required, create custom applications as well.
