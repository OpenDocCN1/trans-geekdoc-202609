Next, let's look at how you can enforce 2V from the console:

+   1. Log in with your credentials to admin.google.com

+   2. Navigate to the left-hand side menu to Security | Authentication | 2-step verification (see Figure 5.2). In the settings, select the organizational group from the left where you want to enforce the 2SV policy.

Security > 2-Step Verification

![](bbox=[0.1428, 0.2435, 0.8571, 0.6265])

Figure 5.2 – Account security (2SV)

+   3. From the configuration options available here, you can set Enforcement to On or Off or schedule it to turn on for specific data. Selecting On will enforce it immediately.
