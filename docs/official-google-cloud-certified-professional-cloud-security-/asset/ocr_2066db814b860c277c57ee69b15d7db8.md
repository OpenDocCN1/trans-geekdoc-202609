Here are the steps that are followed to encrypt data using envelope encryption:

+   - A DEK is generated locally, specifying a cipher type and a key material to generate the key.
- This DEK is used to encrypt the data.
- A new KEK is either generated or an existing KEK from Cloud KMS is used—based on user preference. This KEK is used to wrap the data.
- The wrapped DEK is stored with the encrypted data.

Now let see the steps that are followed to decrypt data using envelope encryption.

As depicted in Figure 9.6, the process of decrypting data is to retrieve the encrypted data and the wrapped DEK, retrieve the wrapped DEK, use the KEK to unwrap the DEK, and then use the unwrapped DEK to decrypt the data. The KEK never leaves Cloud KMS.

Figure 9.6 – Envelope encryption

To decrypt data using envelope encryption, you do the following:

+   - Retrieve the encrypted data and the wrapped DEK.
- Use the KEK stored in Cloud KMS to unwrap the encrypted DEK.
- Use the plaintext DEK to decrypt the encrypted data.
