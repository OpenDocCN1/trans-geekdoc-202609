# Create Cloud NAT gateway

Cloud NAT lets your VM instances and container pods communicate with the internet using a shared, public IP address.

Cloud NAT uses Cloud NAT gateway to manage those connections. Cloud NAT is region and VPC specific. If you have VM instances in multiple regions, you'll need to create a Cloud NAT gateway for each region. Learn more
