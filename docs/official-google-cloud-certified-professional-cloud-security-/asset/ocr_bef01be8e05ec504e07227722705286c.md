2. Next, you can specify the location, which can be Regional or Multi-region, based on your requirements.

3. We then set Default storage class, select Uniform access control, and finally set Retention policy (best for compliance), which is the best option for compliance when storing logs. You can specify a retention period in days, hours, months, or years. In our example, we set it to 5 days.
