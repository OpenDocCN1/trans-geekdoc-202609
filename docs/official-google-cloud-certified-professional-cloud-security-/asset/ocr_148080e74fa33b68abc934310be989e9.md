# Continuous compliance

All the benefits that the cloud has to offer, specifically, capabilities as automation and orchestration, make compliance in the cloud much easier to achieve. One of the key advantages that many customers gain when moving from traditional on-premises data centers to the cloud is the ability to achieve compliance in a more automated way. The cloud helps you achieve compliance and audit objectives in an automated and on-demand fashion rather than quarterly manual audits. This reduces the time needed to resolve security-related issues, improving your overall security posture. Google Cloud offers an elegant solution to meet compliance objectives.
