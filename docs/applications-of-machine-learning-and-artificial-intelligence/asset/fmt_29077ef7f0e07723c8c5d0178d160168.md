# WHAT IS IMAGE CLASSIFICATION?

Consider the following image, whenever this image is seen, it is instantly recognized as a house. Take a step back and analyze how a human being came up to this conclusion. Whenever this image was shown, any human being has classified the class it belonged to (a house, in this example). That is what an image classification is all about. Image classification is a technique used to analyze an image and identify its 'class' the image falls beneath. A class is typically a label, for instance, 'house', 'dog', 'flower', etc.

In our example, we input an image of a house. Image classification is the method of the computer examining the image and showing you it's a house. (Or the probability that it's a house.)
