
# Clustering

Clustering is a division of data into groups of similar objects. In each group, named a cluster, there are objects that are compared and grouped based on identical and dissimilar properties. If data is represented in the cluster, it will lose some fine details but achieve simplification. Most data clustering problems are considered NP-hard. Clustering methods can be categorized into different paradigms: Partitional clustering, Hierarchical clustering, Density-based clustering, and Spectral clustering.

## Partitional Clustering

As the name suggested, in partitional clustering, data is divided into non-overlapping subsets such that each data instance is assigned to exactly one subset. For example, `K-means` (Steinhaus, 1956) and `K-medoids` are the most famous example of this kind. `K-means` clustering applies an iterative approach. At first, it chooses the means of cluster commonly known as centroids. Afterward, it assigns data points to its nearest centroids. This approach is efficient in terms of computational speed and simple to use (Shapiro, 1992). However, the main shortcoming is the vulnerability of the random seeding technique. If the initial seeding points are not chosen carefully, the result will not be satisfactory. For this reason, an updated method name `K-means++` (Arthur & Vassilvitskii, 2007) was proposed to improve. However, `K-mediod` is an improvement of `K-means` also to deal with discrete data, which takes the data point, most near the center of data points, as the representative of the corresponding cluster.

## Hierarchical Clustering

In this approach, clusters are formed by either a bottom-up approach or a top-down approach. This dataset is represented by a dendrogram. At the initial level, clusters are formed along the hierarchy. Single-linkage clustering is a classic bottom-up approach in which data points are gradually agglomerated together to form clusters. For each step, all the pairwise distances are calculated to find a minimum. The points with minimum distance are linked together. Steps are repeated until all points are linked. This results in a tree structure, and the depth of the tree can be used from the cluster. Moreover, hierarchical clustering is suitable for the data set with different shapes and attributes of arbitrary type. However, the time complexity is relatively high, and several clusters are needed to be preset. Some mentionable algorithms for this category are `BIRCH`, `CURE`, and `ROCK`.

## Density-Based Clustering

Density-based clustering is one of the well-known clustering techniques. This technique uses connectivity and density functions for clustering. In density-based clustering, data points are separated based on density, connectivity, and boundary. A cluster is formed at the base of the connected dense component and then is expanded to the direction of density. This property gives density-based clustering the ability to discover arbitrary shapes and remove the outliers. `DBSCAN`, `OPTICS`, `DBCLASD`, and `DENCLUE` are algorithms that are commonly used clustering techniques. The `DBSCAN` algorithm uses density-based notions to define clusters. It utilizes two connectivity functions, density-reachable and density-connected to define each data point as either a core point or a border point. `DBSCAN` then visits points arbitrarily until all points have been visited. However, if the point is a core point, it attempts to expand and form a cluster around itself. Based on the experimental results, it tends to derive cluster robustness toward discovering arbitrarily shaped clusters.

## Grid-Based Clustering

In grid-based clustering, the data points are divided into multiple portions (grids) at different granularity levels to be clustered individually. This method's processing time is significantly faster because it only concentrates on the statistical properties of certain grid portions. After calculating all the grids, the results are consolidated and analyzed. This approach makes it independent in performing clustering on the grid rather than the whole data set. This technique is highly grid-dependent, and the size of the grid plays a vital role in performances. For highly irregular data distribution, only some grids may not be formed adequately to achieve the correct result. A few well-known grid-based clustering methods are `Wave Cluster`, `STING`, and `CLIQUE`. In particular, `CLIQUE` is written so that it can automatically find subspaces with high-density clusters, and it does not require any assumption of data distribution. Its experimental results prove that this cluster can scale dimensions efficiently and, thus, it is exceptionally efficient in clustering high dimensional data.
