# System Implementation

In this system, I have used camera as input where in live video face is detected and frame by frame it is given as input to CNN model. Image frame is pre-processed before passing to CNN model like face is cropped and resize to 48x48 and converted to grayscale images. CNN will processed the image of face by extracting the features and then classify the emotions as negative or positive emotions.

# CONCLUSION

In this chapter, Convolutional neural network is used to identify emotion of human face by examining the facial expression of a person. Human face features are eyes, mouth, nose which will be detected and processed by Convolutional Neural Network. If the emotion detected as negative such as sad and anger than automatically music will be played to change the emotions of a person to positive emotions such as happy and neutral. Once emotion detected as positive, automatically music will be stopped. CNN is simple to implement and faster to train. It have good accuracy rate with test data. The dataset used to train CNN is FER-2013. CNN image processing through all different layer is shown step by step. It also contain algorithm and code snippet for the architecture shown to process and classify the image using CNN. This chapter shows how music affects person emotions by releasing good hormone like Dopamine. There is numerous health benefits while listening to music like decrease in blood pressure, managing pain. The application of this chapter are it can be used as psychotherapy to treat depression, anxiety management, anger management, Alzheimer’s disease to retain memory, Pain management in cancer patients. In this chapter, histogram of positive and negative emotions is plotted. The graph is plotted for different performance measures.

The concepts explained in this chapter can be implemented in future with human brain signals, which can be measured by electroencephalogram (EEG) along with facial expression. Music will be play according to brain signal changes to detect emotions.
