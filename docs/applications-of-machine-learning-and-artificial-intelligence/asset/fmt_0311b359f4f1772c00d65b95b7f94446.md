
# Supervised Learning

Supervised learning is the Machine Learning technique to get information (pattern, features) from labeled training data (Rieke, 1997). Typically, the training data includes a set of labeled/ known data instances. For example, in an image classification problem, where a model wants to classify images, training data will include instances of known classes. A supervised Machine Learning algorithm analyzes the training data, learns from it, and then uses that learning to do various tasks. Supervised algorithms can also label unseen instances by mapping new instances with the learning knowledge from the training phase. However, it requires a generalization from the training data with the help of inductive bias. Supervised algorithms are widely used for various applications. The process of implementing a supervised algorithm to a problem domain is to adhere to the following steps.

## Training Data Selection

A supervised algorithm strongly depends on training data. The performance is related to the choice of training data. It is crucial to choose the correct training data set. For example, in an animal image classification, the training data might be a single animal (cat, dog, etc.) or multiple animals of the same type. However, the training data set should be a representation of real-world instances. A set of input instances are gathered, and the corresponding output is also determined. This process can be done with the involvement of statistical measurements or human experts.

## Feature Selection

After selecting the training data, some features need to be selected as a learning function. These features will be learned by the supervised algorithm and be used for future predictions. When a supervised algorithm learns better from the training dataset, it will show high accuracy. Generally, training data is transformed into a feature vector that represents the number of available features. The number of features should be chosen carefully since data can have multiple dimensions and that makes it complex for the algorithm to learn for better prediction.

## Learning Function Structure

The learning function structure needs to be predetermined since the availability of various supervised algorithms. Once these are done, the algorithm needs to be trained by the training data. Moreover, some supervised algorithms provide flexibility to choose certain parameters during the training phase. Those parameters are problem-specific and need to be adjusted adaptively. The performance evaluation of the supervised algorithm can be measured by a test set that is different from the training dataset. It will indicate the learning accuracy of the algorithm.

## How Supervised Algorithm Works

Supervised learning uses a known data set to train an algorithm with features to make the prediction. This known data set is also known as training data which is associated with the desired output. Supervised learning establishes a model by learning the relationship between features and the output that is used afterward to make a prediction of a new dataset (test dataset).

## Bias-Variance Tradeoff

In supervised learning, bias indicates the difference between the average prediction of the model and the actual/ correct value of the desired prediction. If a supervised learning model has a high bias, that indicates that the model is very liberal to the training data and oversimplifies the model. If a model oversimplifies, then it will not learn complex patterns and associations of training data, and that can lead to high error on testing results. On the other hand, variance is an indicator of how much the estimate of target prediction will alter if training data are different. In other words, the amount of difference of random variable from the expected value. A model with high variance concentrates a lot on training data and does not generalize the data. But it also ends up doing a very high error rate in the testing result. There should be a trade-off between bias and variance to get a better prediction result. The prediction error is an indication of the balance of bias and variance. Moreover, the prediction error is the sum of bias and the variance (Allikmets, 1998).

## Training Data Availability and Functional Complexity

Supervised learning depends on the quality of training data. The question is, how much data does a model need to perform better? There is no exact answer to this problem. But it is well known that quality and amount of training data is the single most important factor for a model's performance. So, the answer for the amount of training data needed is – it depends. It depends on the task the model is trying to complete, the expected performance of the model, the available input features, the amount of noise in the training data and extracted features, and so on. For example, if the model is trying to predict something simple, then any algorithm with high bias and low variance will be able to learn from a small amount of training data. On the other hand, if the model is trying to achieve something complex which needs a lot of interactions among input features, it requires a large amount of training data. As mentioned above, there are no empirical bounds for required training data but based on experiments, and some suggestions were made by various researchers. In the case of regression, ten training instances for each class are required as per one in ten rule of thumb (Haldar, 2015). These numbers change for variations of the regression model. In computer vision, image classification using a deep neural network requires almost 1000 images per class (Warden, 2017). An efficient supervised learning model automatically adjusts the bias and variance trade-off with the amount of available training data.

## The Dimensionality of Input Data

In various domains, the input dataset and the selected features may have multiple dimensions. The learning process for the model can be difficult in that case though the expected prediction may only depend on few features. The reason is, data with multiple dimensions confuse the algorithm, and as a result, the model has high variance. In this case, the model needs to be tuned in for low variance and high bias. Nonetheless, if irrelevant features can be removed manually or with the help of available feature selection algorithms, then the model can still perform better accurately.

Besides all those above-mentioned issues, some other factors can also influence choosing a learning algorithm. Heterogeneity of data plays a role. Heterogeneity means the feature vector includes various types – discrete, counts, continuous, etc. In that case, some algorithms are easier to implement and perform better. Supervised algorithms—linear regression, support vector machine, logistic regression, neural networks—require numerical input features with a similar range. However, data redundancy is also important. If the input data is highly correlated, then there are numerical instabilities. Linear Regression, logistic regression will perform poorly for that type of data.
