# Key Terms and Definitions

**Computer Vision**: A research area of computer science that deals with image and video. The goal is to extract important information extraction from images and video.

**Human Skin Detection**: Process to detect human skin from images or videos. It has various applications in computer vision.

**Machine Learning**: A part of the artificial intelligence domain. It consists of various algorithms which can be used to analyze data and get some insights from the data.

**Supervised Learning**: A technique of a Machine Learning algorithm. It uses known data to get some prediction about unknown data with the statistical model.

**Testing Data**: It is a dataset without known labels/information. Computer models used that data for real-life applications.

**Training Data**: It is a dataset with a known label. This type of data is used to train a computer model for the desired application.

**Unsupervised Learning**: A Machine learning technique. It does not need any known data. It discovers various data information by itself.

## Abstract

Humans communicate with each other and express emotions using facial expressions. Facial expression is an important part of expressing emotions. Facial features can be considered as eyes, mouth, and nose. In this chapter, the authors considered these facial features for emotion detection and processed them with `convolutional neural network (CNN)`. There are mainly six basic types of emotions: fear, disgust, anger, sadness, happiness, and surprise. These emotions can be classified into two types: positive emotions and negative emotions. A positive emotion is a feeling where there is no negativity such as happy, neutral. A negative emotion is a feeling of depression, frustration including anger, sadness, fear. This chapter describes a step-by-step method in processing an image in `CNN` and giving an output. `CNN` classifies different emotions. Further classification is done for emotion as negative and positive, and when the negative emotion is detected, music is played to change the emotion of a person.

A `convolutional neural network (CNN)` is a neural network consisting of one or more number of convolutional layers which is used in image processing, classification of objects or images, segmentation. It is mainly used to process large set of data and only one `CNN` algorithm can extract features, classify an object or image and give a desired fast. `CNN` processing is much faster. `CNN` consists of three layers and they are first is convolutional layer, second is pooling layer and last is fully connected layer. `CNN` has many applications but mostly it is used in image related application. Some application of `CNN` are image classification, image segmentation, object detection in images, weather forecasting, etc. The research work contains information about image processing and classification of to detect the emotions by analysing facial features, algorithm and its code snippets to process an image and classify it to get the desired output. It is also shown that how an image is getting processed step by step in different layers of convolutional layer with output. For all the layers of `CNN`, various equations are shown in this chapter. In this chapter, `CNN` is detecting emotions of person and then classify emotion into positive and negative emotion and in later stage negative emotions are considered and musical therapy is given so that person mood is changed from negative to positive emotions. ## Background

The term `Convolutional neural networks` was first introduced in the year 1980 by Yann LeCun. `Convolutional neural network (CNN)` is a class of deep learning neural network. Convolutional networks was inspired by observing the patterns between neurons in animal visual cortex. A `convolutional neural network` is a kind of artificial neural network which is used in image recognition and then processing which is designed to process a pixel data. `CNN` consists of an input layer, hidden layer and an output layer. `CNN` extract features from the images. The input layer in `CNN` is a grayscale image. The output layer consists of multi-class labels. Hidden layer consists of convolution layer, `ReLu` layer, Pooling layer and a fully connected neural network. To train `CNN`, each input image is need to pass through multiple series of convolution layers with kernals, `ReLu` layer, Pooling layers and at last to fully connected layer so that an object or image can be classified with probability values ranging between 0 and 1. For this chapter, some survey were done to proof that `CNN` is best for processing and classifying a images. Some of the surveys are listed below:

*   In a paper, published in year 2012 by Deng J, the author describe about an hierarchical framework for detecting emotion and it consist of two layers, the first one is external layer that show preliminary and superficial emotions and the second one is inherent layer that shows psychic and resonant emotions. A music emotion model called `Resonance Arousal Valence model` is built depending on this two given layer. This model display emotions in a three dimensional and continuous space. Based on features like intensity, pitch, harmony, etc., music will be passing to the given model. To efficiently illustrate music with many emotion labels a supervised multiclass label is implemented using `KNN` method.

*   In a paper, published in 2015 by H.Jing, author had designed cognitive emotional model inside a robot for monitoring elder people. By combining `Gabor filter`, `k-Nearest neighbour algorithm` and `Local Binary Pattern algorithm` facial features is extracted and recognized, and. Facial features have effect on robot emotional state and is called as `AVS emotion space`. After this optimization of smart home environment on the cognitive emotional model is analysed using `simulated annealing algorithm`. Then, lastly transformation probability from different emotional state is obtained using `cognitive reappraisal strategy` and `Euclidean distance`. The simulation and experiment have been tested to reduce negative emotions.
