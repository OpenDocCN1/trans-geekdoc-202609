
## Various existing clustering methods

Various existing clustering methods use an iterative approach to achieve local minima and find functional clusters using different initial cluster starting points. In contrast, spectral clustering uses maximum eigenvectors that are provided from the distance matrix as a form of a matrix. Spectral clustering usually reduces the dimension of K-means clustering. It considers the range of the similarity matrix of the input data. These clustering methods treat the cluster as a graph partition. For that reason, it does not make any strong assumption for the statistical properties of a cluster; therefore, in terms of time complexity, it is very fast. Its drawbacks, however, are that it can be sensitive to the choice of parameters and computationally expensive for large datasets.

## Discussion on Various Clustering Algorithms

Partitional algorithms apply mainly to numerical datasets. However, a variation of K-means named K-mode has been developed for categorical data. Moreover, they are based on a certain assumption to partition a dataset. Thus, they need to specify the number of clusters prior. The results of clustering are devoted to similar points that belong to the same cluster. Those points can be centroid or mediods, which depend on the clustering algorithm used. However, regardless of algorithm choice, the object remains the same: Minimization of distance within the same cluster and maximization of distance among separate clusters. Also, a centroid of a K-means represents the minimum distance of data points that belongs to the same cluster.

Hierarchical clustering methods create a hierarchical decomposition of the database represented as a dendrogram. This algorithm is a more effective method for detecting outlier and handling noisy data. BIRCH uses a hierarchical data structure called CF-tree for multi-phase clustering. In BIRCH, the first scan determines a good clustering and more scan improves the cluster quality. But it is only applicable for numerical data. Besides, it is order sensitive, which means, for the same data points, it can demonstrate multiple clusters but in a different order. However, it has performance limitations for un-uniform data size and shape. The reason is, it heavily depends on the centroid value when data points are redistributed at the final stage. So, cluster quality is parameter depended.

Density-based clustering algorithms suitably handle arbitrarily shaped collections of points as well as clusters of different sizes. Moreover, they can efficiently separate noise. Grid-based algorithms perform well for large databases. It can also find various arbitrary shapes of the cluster with the detection of outliers. A well-known grid-based algorithm is STING.

This evaluation process is known as cluster validity. In general terms, there are three approaches to investigate cluster validity. The first is based on external criteria. This implies that the results of a clustering algorithm are evaluated based on a pre-specified structure. The second approach is based on internal criteria. In this approach, the cluster is assessed based on various proximity matrices. The last one uses a relative measurement. Also, cluster evaluation is done with comparisons of another cluster. This cluster is a result of the same cluster but at that time with different parameters.

## Validity Indices

Quantitative evaluation of clustering results is known as cluster validity methods. There are three criteria-external, internal, and relative criteria. In an external criteria approach, data points are examined to conclude whether or not they are randomly structured. This analysis is based on the Null Hypothesis expressed as a statement of the random structure of a dataset. This hypothesis is based on statistical tests, which lead to a computationally complex procedure. For internal criteria, the aim is to evaluate the clustering result of an algorithm using only quantities and features inherent to the dataset. Statistical testing is the basis of the above-mentioned validation methods. Thus, the main setback is, since it needs consideration for internal or external criteria, it needs a large computation. For this, a different validation approach-relative criteria are proposed. It is based on relevant criteria, excluding the requirement of any statistical tests. Ultimately it chooses the best clustering approach for the prior defied scheme based on the criterion specified.
