
# 卷积神经网络

卷积神经网络由输入层、输出层和多个隐藏层组成。隐藏层作为 CNN 的一部分，包含一系列卷积层，这些层将通过乘法或其他点积进行卷积。`RELU` 层是激活函数，其后跟随另一种称为池化层的卷积，全连接层被称为隐藏层，因为这些输入和输出被激活函数和最后一个卷积层所掩盖。最后一个卷积层包含反向传播，以便最终产品的权重更加准确。

## CNN 的工作原理

所有输入图像都需要通过包含池化、滤波器、全连接层的多个卷积层，然后应用 `softmax` 函数，以便在 0 到 1 的概率范围内对物体进行分类。下图展示了 CNN 的完整流程，演示了输入图像如何被处理以及如何基于数值对物体进行分类。类似于人类大脑通过检测特征来识别物体，CNN 通过识别特征对图像进行分类。CNN 图示如图 5 所示。

CNN 主要由三层组成：

*   **输入层**
*   **隐藏层**
*   **输出层**

### 输入层

输入层将具有输入图像的宽度、高度和深度。它代表像素矩阵。

### 隐藏层

隐藏层位于输入层和输出层之间，人工神经元接收一对加权输入并使用激活函数给出输出。CNN 由许多隐藏层组成，这提高了结果的准确性。隐藏层包含用于特征学习的卷积、`RELU`、池化层，以及用于分类的全连接和 `SOFTMAX` 层。

#### 特征学习层

**卷积层**：它是 CNN 的构建模块，在两个矩阵之间执行点积运算，其中第一个矩阵包含一对称为 `kernel` 的可学习参数，第二个矩阵是感受野的有限部分。它是两个函数的组合积分，展示了一个函数如何修改另一个函数。输入图像表示为 `48x48` 矩阵形式，`kernel` 大小为 `3x3`，步长为 `1`。卷积层对输入图像应用滤波器并创建输出特征图。步长是 `kernel` 在图像上移动的量。第一个卷积层的输出即特征图，按公式 (1) 计算。特征图如图 6 所示，经过卷积层处理的图像如图 7 所示。

```
nxn * fxf = n-f+1 x n-f+1  (1)
```

此处 `n` 为 `48x48` 矩阵表示的输入图像，`f` 为 `3x3` 的滤波器或 `kernel` 大小。

因此输出尺寸减小为 `46x46`，即为特征图。

**ReLU**：`ReLU` 称为线性整流单元，用于非线性操作。`ReLU` 层作为逐元素激活函数 `maximum(0,x)` 应用，将负值变为零。此处体积大小不变，且不存在超参数。此处不需要 `kernel` 大小。

`ReLU` 的输出使用公式 (2) 计算：

```
ƒ(x) = maximum(0,x)  (2)
```

此处 `x` 作为输入给神经元。

图像的输入矩阵传递给 `ReLU` 层，将矩阵中所有负值替换为零，如图 8 所示。

#### 分类层

在 CNN 中使用全连接层和 `SOFTMAX` 层对图像进行分类。

**全连接层和 SOFTMAX**：一层的所有神经元连接到另一层的所有神经元。为了对图像进行分类，扁平化矩阵需要通过全连接层。它检测情绪并将其分类为积极或消极情绪。最后的全连接层将使用 `Softmax` 激活函数，根据给定的训练数据集，将作为输入的图像特征分类为不同类别。输出为 `n` 维矩阵形式。`softmax` 层的节点数与输出层相同。

### 输出层

隐藏层的输出被送入 `softmax`，将所有类别的输出转换为所有类别的概率得分。

根据检测到的消极情绪（如悲伤），系统将自动播放欢快音乐，使人的情绪从消极（悲伤）转变为积极（快乐），一旦检测到快乐情绪，音乐将自动停止。检测到的情绪如图 10 所示。

## TensorFlow 与情绪调节

`Tensor flow` 是一个包含人工智能库的开源框架，其拥有显示数据流的图，用于模型构建。这有利于构建包含许多层的复杂神经网络。它主要用于分类、预测和创建。当人聆听快乐或舒缓的音乐时，会分泌一种称为多巴胺的有益激素，使人的心情愉悦，将情绪从悲伤转变为快乐。如果播放舒缓音乐或古典音乐，处于愤怒情绪的人会感到放松，因为其血压会恢复正常，从而呈现中性情绪。愤怒时，由于肾上腺素激素水平高，人的血压和心率会迅速增加，聆听舒缓音乐会降低肾上腺素水平，从而使心率和血压恢复正常。

### 情绪分类

CNN 将情绪分类为消极和积极情绪。本研究考虑了两种消极情绪（愤怒和悲伤）和两种积极情绪（快乐和中性）。一旦检测到消极情绪，则绘制消极情绪的直方图。播放舒缓音乐后，消极情绪转变为积极情绪并绘制直方图。摄像头将持续监控人的面部以检测过程中的任何变化，此过程循环进行。针对所有情绪绘制不同的柱状图。

### 音乐数据集

音乐数据集使用暴力法手动创建。它包含快乐音乐和放松音乐。`Pygame` 作为 Python 中的音乐库，负责控制音频。给定数据集的大小为 `2 Mb`。
