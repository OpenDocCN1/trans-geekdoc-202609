
# Image Segmentation in Computer Vision

In computer vision, a significant real world problem is image segmentation. Segmentation of an image means to divide an image into various regions based on the pixel characteristics. These regions can be used to identify objects or boundaries which can be used for further analysis. In addition, segmentation of an image allows us to separate foreground from a background, identify the location of an object in the image and also locate the boundary that separates two objects. In practice, cameras can capture a lot of objects within one image. The separation/segmentation is crucial for current real-world problem solving.

Segmentation techniques separate or distinguish objects based on the pixel's information. A typical image can contain millions of individual pixels and segmentation allows us to separate pixels with similar characteristics from others. For this reason, clustering is a good choice for image segmentation. In medical image processing segmentation is particularly useful, where the doctor wants to separate healthy cells from the cancerous cells. Clustering techniques, for example `K-mean` clustering will separate objects with similar properties (shape, color, etc.) from objects different from them.
