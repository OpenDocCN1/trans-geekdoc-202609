Microsoft's extensible web server for the Windows NT operating system is called Internet Information Services (IIS), originally known as Internet Information Server. IIS supports the following protocols: FTP, HTTP, HTTP/2, HTTPS, etc. Despite not being active by default and possibly being absent in some editions, it has been a member of the Windows NT family. Although the security flaw CA-2001-13 that resulted in the infamous Code Red attack affected IIS 4 and IIS 5, versions 6.0 and 7.0 have no known concerns with this particular flaw. Microsoft decided to alter the pre-installed ISAPI handlers' behavior in IIS 6.0 to decrease the attack surface of IIS.
