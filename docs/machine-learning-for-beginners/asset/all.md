**Chapter 2  
  
**Machine Learning

Machine learning in computing is borrowed from the behavior of human beings. It is a branch of artificial intelligence which involves the design and development of systems capable of self-improvements based upon previous experiences.

 

This means that when reacting to the same situation, a machine should show an improvement from time to time.

With machine learning, software systems are able to predict accurately without having to be programmed explicitly.

 

The goal of machine learning is to build algorithms which can receive input data and then apply statistical analyses to predict the output value within an acceptable range.

 

Machine learning is based upon the association of learning with pattern recognition, and the theory that computers should be able to recognize patterns in such a way as to “learn”, to adjust their responses without human intervention (e.g. additional programming or human inputs). 

 

Researchers in the field of artificial intelligence wanted to determine whether computers can learn from accessible data. Machine learning is an iterative approach, and therefore machine learning models are able to adapt as they are being exposed to new data. Models learn from their previous computations (their outputs become inputs) to give repeatable, reliable results and decisions.

The increasing popularity of machine learning can be attributed to the same factors which led to the increasing popularity of data mining. Such factors include the availability of cheaper and powerful computational processing, greater varieties of data, and more affordable means for data storage.

 

Given these three, it is easy to produce models capable of analyzing bigger and more complex data to deliver quicker and more accurate results. A more precise model makes it easier for a business to identify profitable opportunities and to avoid risks.

 

With machine learning, businesses can also draw conclusions and identify patterns which can help them create models for making predictions. This can help them in making wise business decisions.

 

## Details about Machine Learning

Machine Learning algorithms can be categorized into three classes, namely supervised, unsupervised or reinforced learning.

![Image](Images/image00072.jpeg)

 

## Supervised Learning

![Image](Images/image00073.jpeg)

For the case of supervised learning, the human is expected to provide the desired inputs and outputs as well as furnish feedback based on the accuracy of predictions made training. After completion of training, the algorithm will have to apply what it learnt to the next set of data.

 

The concept of supervised learning can be compared to learning of a student under a teacher’s supervision. The teacher provides input and output samples from which the student derives rules which will then be applied to future inputs. 

 

There are two kinds of supervised machine learning algorithms: regression and classification.

 

In regression problems, the target is a numeric value, while in classification, the target is a class or a tag.

 

A regression task can help determine the average cost of all houses in London, while a classification task will help determine the types of flowers based on the lengths of their sepals and petals.

## Unsupervised Learning

![Image](Images/image00074.jpeg)

For the case of unsupervised learning, algorithms are provided unlabeled inputs only - no output or feedback. The algorithm uses an approach called deep learning, an iterative approach, to review data and arrive at new conclusions.

 

This makes unsupervised learning algorithms suitable for use in processing tasks of greater complexity than those which can be handled by supervised learning algorithms. An unsupervised learning algorithm learns solely from samples without any conclusions given, identifying patterns from the samples on its own.

 

The work of an unsupervised learning algorithm is similar to the human observation and analysis that leads to detection of similarities between two or more objects. Most recommender systems you encounter when purchasing items online work based on unsupervised learning algorithms. 

 

By first examining your shopping history and comparing it to histories of other customers, recommender algorithms can predict what kinds of items you might want to purchase and produce personalized shopping suggestions.

## Reinforcement Learning

![Image](Images/image00075.jpeg)

This type of learning occurs when the algorithm is presented with raw, unlabeled inputs only - no outputs. But a positive or negative feedback is provided in response to the solution (output) proposed by the algorithm. This can best be compared to trial and error in human learning. 

 

Errors become useful in learning when they are associated with a penalty such as pain, cost, loss of time etc.

 

Machine learning processes are similar to those of data mining and predictive modeling. In both cases, searching through the data is required to detect and act upon recognized patterns, adjusting output accordingly. 

 

Again, recommender systems are serve as an excellent example of machine learning applications as, if you purchase an item online, you are likely very shortly to see an ad related to that very purchase.

The tool was developed to be used in computer image classification by leveraging the Convolutional Neural Networks (CNNs).

Singa is heavily applied in healthcare systems, especially in disease progression modeling for early detection and management of chronic diseases.

## Techniques to handle Outliers

An outlier is simply an observation which lies at an abnormal distance from the other values in a random sample obtained from a given population. When dealing with data, most people ignore the outliers.

 

Even in controlled experiments, outliers are a common occurrence. They are normally caused by errors in measurements or by faulty measuring or recording instruments.

 

The best way to detect outliers in your data is through the use of graphical means. Other options include the use of statistical methods and tools such as R, Python, Excel, etc.

 

 

![Image](Images/image00076.jpeg)

Diagram Credits: Opabinia regalis

 

Scatterplots and boxplots are the two most common graphical representations used to reveal outliers. A histogram is another option. There are many strategies which can be used to deal with outliers.

 

Most tools used for outlier detection also provide means for dealing with them, but they typically differ in their approaches.

 

Let us discuss some of the strategies which can be used to handle outliers:

1.   

1.  Create a filter in the testing tool.

Suppose you have an A/B testing tool which you are using to track revenue. You can create code which will identify and omit abnormally large orders from the test results. Past analytics data can help you determine the average web order, and the filter should be created with this in consideration. If you find the average to be $100, then any order above $150 might be considered an outlier.

 

1.  Change or remove outliers during the post-test analysis

Another alternative is to trim the dataset so as to exclude as many outliers as possible. Trimming is easy in Excel through the use of the TRIMMEAN function. Simply specify the array to be manipulated and the amount by which you need to trim the upper and lower extremities.

 

R also provides a convenient trimming function, the mean function. A significant disparity between mean and median indicates the presence of data values sufficiently large or small to skew the body of data. To solve this problem, you can trim a certain percentage of data at both the low and high ends. You can use mean (*x, trim = .05*): in this case, *x* is the data set, and *.05* (or whatever you value you choose) is the percentage of extreme data to be omitted.

 

1.  Changing the outlier value

Instead of removing the outlier, you can choose to give it another, more sensible (probable) value. But how will you decide which value is most sensible? There are various methods for doing this. Instead of using a more technical and complex processes to determine this, you may just want to identify the value in your data which makes sense to you, and use it for replacement. This way, you will have a standard data for training your model. 

 

1.  Box-Cox Transformation

This involves the transformation of the data until it is normally distributed. There are a number of transformations for data normalization.

 

Possible options for data normalization include squaring or taking the reciprocal or square root of the data. In some other cases, the logarithms for the data values may be distributed normally. It depends upon the data.

 

Each of these transformations which may produce a normal distribution can be grouped together into a box-cox transformation. The box-cox transformation takes the following formula:![Trans2](Images/image00077.gif)

In this case, *x* is the raw data, *y* represents the transformed data, and lambda represents the transformation constant. If lambda is given a value of 1, the transformation has no effect. But if the value of lambda is 2, for example, the transformation becomes a square transformation function.

 

There are a number of ways through which you can find the value of the lambda in the Box-Cox transformation. One is Most Likely Estimate (MLE), but this approach can be time consuming. The easiest way to determine the correct value of lambda is by varying its value between -5 and 5, observing the results in order to determine which value for lambda will give you the most normal distribution.

 

The best value for lambda is the one which provides you with smallest standard deviation of the variation between transformed and normally distributed data. This will help you resolve the skewness of your data.

 

1.  **Winsorize (Threshold Control)**

In this method, outliers are replaced with the nearest value in the data which is not considered to be an outlier.

 

The process of replacing the extreme values is known as *winsorization*. In most cases, winsorization involves setting all the extreme outliers to some specified percentile of your data. If you are using a winsorization of 90% for example, all the data below the 5^(th) percentile will be set to 5^(th) percentile, while all data above 95^(th) percentile will be set to 95^(th) percentile.

 

The winsorized estimators are known to be more robust to the outliers compared to the more standard forms. The purpose of winsorizing the outliers is to reduce their extremity to some specified value, so that they can more nearly fit a normal distribution curve.

 

All outliers can be conformed to specific chosen values, but there is another similar approach that is preferred by some. You can alternatively conform the first (least extreme high or low) outlier to your chosen near value, but bring the second outlier to an incrementally more extreme value than the first and the third to an incrementally more extreme value than the second, and so on.

 

This method corrects the values while maintaining their relative orders from the lowest to highest. The value to be added can be chosen by determining the scale of the variable you need to correct.

 

However, it is good for you to note that if the addition is small, there are high chances that there will be no change to the statistical output.

 

Management of outliers increases the probability of obtaining meaningful information from your analysis. The amount by which an outlier affects your analysis depends on a number of factors including the size of the dataset. 

 

If the set is large, each observation will carry less weight, such that the effect of an outlier will be minimal. This is not the case with a small dataset in which each observation carries much more weight. Using one of the above presented methods, however, you will address the problem of outliers and achieve an effective analysis. 

 

 

Chapter 5  
  
Data Management

Data management refers to the process of ensuring that research data is archived, stored, and/or securely and safely discarded during and after a research project. This includes the formulation of policies for handling both electronic and non-electronic data.

## Storing Data

It is always important to consider how and where you will store your data after collecting it. Data needs to be held securely so that it cannot be compromised in any way. You should also determine which data you will store, which data will be discarded, and the file format to be used for data storage.

 

There are a variety of places into which data can be stored, including laptops, flash drives, desktops and the cloud. If the data is stored in a networked drive, you will be able to schedule regular backups, minimize security breaches and losses, and provide access to all who need it.

 

The UCL (University College of London) repository provides you with another possible data storage solution. This facility is centrally managed and can accommodate both small and large data volumes. You can access up to 5TB of storage for free. If your data is sensitive, you can use the UCL Data Safe Haven for storage.

 

The cloud provides another storage option, though if you are dealing with sensitive data you will have to come up with a means for encrypting it. Also, note that cloud providers will not take responsibility should your data somehow become corrupted.

 

It is possible as well that a cloud provider may go out of business or encounter a problem that necessitates a temporary shutdown, and you may end up losing access, at least for a time, to your data.

 

If your data is stored in hard copies, identify the records you will be using frequently and keep them close to your office; then keep the rest off-site.

## Securing Raw Data

Data security is forever a matter of prime concern. There are a number of procedures which can help you maintain the security of your data, including frequent password changes and the creation of very strong passwords. If your documents are kept in laptops and flash drives, you can use software to encrypt them.

 

Implementing separate passwords for each document is not recommended. This is also the case with saving your data in hard drives. Note that data security extends also to the protection of the data from erasure.

## How to Avoid Common Problems

A number of problems can occur when training, validating and applying a machine learning model. Let us discuss these problems and how one can avoid them.

## How to Avoid Overfitting

Overfitting occurs when our model conforms too closely to our training data interpreting any random fluctuations or noise as relevant to the predictive process and learning them as concepts during the training and validation phases.

 

These concepts may not be applicable to generalized data, and if not, the model will perform poorly. There are two techniques which can help you avoid over fitting:

1.  Estimate model accuracy using a resampling technique.
2.  Hold back the validation dataset.

 

Resampling refers to training and validating using varied partitions of our training data. 

 

The k-fold cross validation is the most popular resampling technique. It involves dividing the training data into k sets, of which, for each of k iterations of training and validation, a different one of the k sets is reserved for validation and the other K-1 sets are used for training. Predictive error will be computed for each iteration, allowing a much more accurate estimate of expected predictive performance of the machine learning model on generalized data.

 

A validation dataset refers to a subset of training data which one holds back from the machine learning algorithms to the end of the project. After selecting and tuning the machine learning algorithm on training dataset, the learned model can be evaluated on the validation dataset so as to gain an insight into how it will perform on unseen data.

 

## How to Avoid Underfitting

Underfitting is the failure of a model to adequately model even the provided training data. The model cannot be used to identify or capture the underlying pattern or trend in a dataset. 

 

It has poor performance on the training data; hence it isn’t a suitable model.

The remedy to this problem is use a different machine learning algorithm. Simple machine learning models should also be avoided.

 

## How to Avoid Dirty Data

Dirty data refers to data containing missing values, inconsistencies and noise. Such data has a negative effect on the training, validation and application of machine learning models.

 

To avoid dirty data, adequate filtering must be implemented. Presence of duplicates of data should also be avoided as this may cause inconsistencies as you will not be sure or certain which data set is the most accurate one.

 

If you are obtaining all or part of your data from outside sources, be sure that you have verified their processes for ensuring that their data is clean.

Because dirty data may also result from typing errors, you should have a reliable, dedicated data entry person to key data into your systems.

## Data Sampling & Splitting

When it comes to training a machine learning model, it is always best to use the largest possible amount of data. Relying on only a few observations will not give you a good model for prediction. Use of a small data set to train a model will give you a simple model, which can lead to the problem of under fitting. To avoid this, ensure that your training data includes as many observations as possible.

 

Data normalization is very essential. This should only be done if you realize that there are some inconsistencies in your data. If some of your data values are outside the desired range, normalizing them will improve the algorithm’s learning. 

 

In machine learning, the dataset should be divided into two sets, the *learning or the training set* and the *validation or test set*.

 

However, this must be done with great care so as not to introduce systematic differences between training and testing.

For example, you should not reserve the first half of the data as the test data, since it is possible the data might be chronological, or ordered by provider. 

 

We don’t want to risk biasing our training and test data in any way. The best way to avoid systematic differences is to select the data randomly when creating the *learning* and the *test* sets.

 

The purpose of the test data set is to help us assess our final model and determine its ability to predict. The test data also helps us make the best decision when it comes to choosing the best machine learning model to use for prediction.

 

The learn partition of the data will provide the raw material from which we will be able to create the machine learning model. For us to build the predictive model, the test partition is not necessary, but we must have the learn partition.

 

But how much data should we should use for each partition? Since the learn partition will help us build our model, it should be allocated more data than the test partition. The purpose of the test partition is to help us evaluate the performance of our model, and less data is needed for this purpose.

## Supervised Learning Algorithms

As discussed earlier, Supervised machine learning algorithms are those in which both the input and the output data are provided. They can be divided into two broad categories:

*   Classification
*   Regression

 

Let’s discuss them.

### Classification

Classification involves discovering the inherent groupings of present in a set of data. The categorization of customers based upon their purchasing behaviors is an example of classification. Characterization of emails as either spam or non-spam is another. Other examples include the bull and bear cycle in property market, characterization of student grades and prediction of employee churn

 

Let’s look at some of the classification algorithms for machine learning:

1.  Logistic Regression

A logistic regression algorithm uses a logistic function to make predictions valued between 0 and 1.

 

This is an indication that these predictions can be interpreted to be class probabilities. Due to the linear nature of these models, they work well when you have linearly separable classes, meaning that a single decision surface can be used for separating the classes.

 

Advantages of this algorithm are that the outputs will have a proper probabilistic interpretation, and that it is possible to regularize the algorithm (by penalizing the coefficients with tunable penalty strength) so as to avoid the problem of overfitting.

 

However, linear regression does not perform well when you have non-linear or multiple decision boundaries. Also, they are not good for capturing complex relationships.

 

1.  Classification Tree (Ensembles)

They are good for classification problems, and they work in the same way as regression trees. Practically, they perform very well.

 

They are also scalable, robust to outliers and naturally model the non-linear decision boundaries due to their hierarchical structure.

 

However, individual trees are vulnerable to over fitting which can be solved by use of the ensemble methods.

 

1.  Deep Learning

Deep learning can be categorized to be as part of a classification problem. A good example is image classification. A deep learning algorithm will give you a very nice performance when you are classifying text, audio and image data.

 

However, deep neural networks require a huge training data set, and that is why it is a general-purpose algorithm.

 

1.  Support Vector Machines (SVM)

SVMs use kernels for the purpose of calculating the distance between any two observations. The algorithm looks for a decision boundary which maximizes the distance between the closest members of separate classes.

 

SVMs can be used for modeling nonlinear decision boundaries, and they provide many kernels from which to choose. They are not prone to overfitting, especially in cases in which you have a high-dimensional space.

SVM is a memory intensive algorithm, however, and the importance of selecting the right kernel makes it hard to tune the model. This algorithm is not suitable for use with larger data sets.

 

1.  Naïve Bayes

This algorithm works based on counting and conditional probability. The model is simply a probability table which is updated depending on training data.

 

For you to make a prediction, you observe the class probabilities in the probability table based on the feature values. It was given the name naïve because of its conditional independence assumption which is a rare occurrence in real world.

 

Naïve Bayes models are easy to implement and offer a very good performance. They scale very well with your dataset.

### Regression

In regression, the relationships between variables are modeled.  Regression algorithms should be used for problems in which the response variable is continuous or numeric. However, in classification algorithms, the response variables are made up of data group into classes (usually, two classes).

 

A regression algorithm is a good predictor of a value such as the price of a product (based upon related input variables).

 

The learning process is centered on a training dataset with labeled inputs and the numeric target variable. The model is refined iteratively through a process in which a model is generated, tested against the data set for accuracy, adjusted generating a new model…. 

Regression algorithms are heavily applied in statistical machine learning. Some examples are the house valuation vs the selling price and predictive returns vs realized returns in unit trusts.

## Unsupervised Learning Algorithms

The training data set for unsupervised learning algorithms contains input data (X) only. No output data (Y) is given.

 

The name *unsupervised* comes from the fact that there is no “teacher” (output); and the correct answers are not given known. 

The goal of unsupervised learning is to model the underlying distribution or structure of the data and to learn more from the data. The algorithm is tasked with discovering the underlying data structure on its own.

 

Unsupervised learning algorithms can be classified into the following:

*   Clustering
*   Dimensionality Reduction

 

Let’s discuss these.

### Clustering

In clustering problems, our aim is to discover the inherent groupings of our data. For example, groupings of customers based upon their purchasing behaviors. Other applications of clustering include the grouping of related items in e-commerce, and various social network analyses.

 

The product of a cluster in algorithm is usually a data visualization enabling the user to see and evaluate the results. 

 

Examples of clustering algorithms include k-Means k-Medians, Expectation Maximization (EM) and Hierarchical Clustering.

 

In clustering, our goal is to map the data into different groups known as clusters. Related data will be placed in the same cluster, while no different data will appear in the same cluster.

### Dimensionality Reduction

Just like the clustering algorithms, the dimensionality reduction algorithms work to identify the underlying structure of a dataset.

 

Dimensionality Reduction algorithms are further divided into the following:

*   Feature Selection
*   Feature Extraction

 

The term “dimensionality” in machine learning denotes the number of features in a dataset. If the number of features happens to be large compared to the number of observations in the dataset, some of learning algorithms will find it tough to train effective models. This is what is referred to as “Curse of Dimensionality”.

 

Feature Selection helps in filtering redundant or irrelevant features from your dataset.

 

The difference between feature selection and feature extraction is that in feature selection, a subset of original features is kept while in feature extraction, brand new features are created. 

 

In dimensionality reduction, the goal is to reduce the number of features which are under consideration, and each feature is a dimension which represents the objects.

 

## Reinforce Learning Algorithms

The goal of Reinforce Learning Algorithms is a decision model which, given a certain combination of inputs (situation) will produce a desirable output (response). The desired outputs (responses) are not given for training, only the inputs (situation), but reinforcements are given based upon the desirability of the decision (response). 

The learning process involves the discovery of the best decision, which is the one producing the maximum reward.

 

A good example of reinforced learning is a child’s process of learning to walk. The child must watch others who are walking and try to imitate them. He or she will realize that in order to walk, he must first stand up. She will stagger and slip, but still be determined to stand. The next task will be to stand unassisted. The child must be able to release his or her grasp on supports. Finally, he or she will attempt to walk: decide which foot to start with, learn to balance the body weight, etc.

 

The mathematical framework for obtaining a solution to to reinforced learning problems is known as the Markov Decision Process.

 

The process can be defined as follows:

*   Set of states, S
*   Set of actions, A
*   Reward function, R
*   Policy, π
*   Value, V

 

An action (A) is required in order for us to transition from the start state to the end state (S). We will earn a reward (R) for each action taken. Note that we can get either positive or negative rewards for our actions. The actions taken define the policy (π) and the rewards obtained define our value (V). Our goal is to maximize the reward by selecting the right policy.

 

The travelling salesman problem is a good example to which reinforced learning can be applied. The goal is to move from the start point to the end point at the lowest cost possible.

 

Graphically, this is represented in the form of nodes and edges, and the edges have values on them which indicate the cost of moving from one point to another. In this case, the value is the total cumulative reward (accumulated during the progression from node to node) during the execution of a policy.

 

In both reinforced and supervised learning, there is mapping from the inputs to the outputs. However, reinforced learning algorithms have a reward which provides feedback to the learning agent whereas, supervised learning has an external supervisor that share the knowledge with the agent to accomplish the task.

 

In unsupervised learning, there is no mapping from inputs to the outputs. The goal in unsupervised learning is to identify the underlying pattern or trend in a dataset.

Regression analysis is a type of predictive modeling with an aim of finding the relationship between a dependent (or target) variable and an independent (or predictor) variable. ## How Regression Algorithms work

Regression is a good technique for one to model and analyze data. In most cases, a best-fit curve or line is drawn for the data points with an aim of minimizing the average distance from the point to the line or curve. Simply put, the purpose of regression is to identify and describe the relationship (interdependence) between two or even more variables. 

 

For example, suppose you need to determine how the sales of a company have grown with the changes in the economic conditions. A regression on recent company data shows growth in company sales to be roughly two and half times the growth in the economy. From information drawn from past data we may be better able to predict future sales.

 

With regression analysis, it is also possible for us to determine the impact of various variables on an outcome. Examples include the impact of price changes and the promotional activities. With such knowledge, data scientists, data analysts and market researchers can know which variables to eliminate and which ones to use in building predictive models.

 

### Examples of Regression Algorithms

There are various types of regression algorithms which can be used for making predictions. These techniques are mostly influenced by factors such as the number of the dependent variables, the number of the independent variables and the shape of the regression line.

 

Let’s discuss the various regression algorithms:

1.  Linear Regression

This is a widely used technique in predictive modeling. The dependent variable (Y) is always continuous while the independent variable (s) can be either continuous or discrete.

 

The regression line is linear in shape. The goal is to determine the relationship between the dependent variable (Y) and one or more of the independent variables (X).

 

A best-fit line is the regression line is used for this purpose. Linear regression is represented by the following equation:

Y=a+b\*X + e

In which a represents the intercept, b represents the slope line while e is the error term. If you are given the predictor variables, then it is possible for you to predict the value of the dependent variable.

 

In multiple linear regression, there are multiple independent variables, while in simple linear regression there is only one.

 

The Least Square Method can help us get the best-fit line. In other words, it can help us find the line which most accurately defines the relationship between variables. It works by minimizing the sum of squares of vertical deviations from every data point to our line. 

 

Squaring of the deviations eliminates the problem of cancellation of all the error due to the existence of both positive and negative deviations. The R-square method can be used for assessing the performance of the model.

 

 

1.  Logistic Regression

Logistic regression helps us to find the probabilities of failure and success for an event. This algorithm should be used only when the dependent variable takes binary values, that is: True/False, 0/1, etc.

 

The Y values should range between 0 and 1, and they take the following equation:

 

odds= p/ (1-p) = probability of occurrence / probability of non- occurrence

ln(odds) = ln(p/(1-p))

logit(p) = ln(p/(1-p)) = b0+b1X1+b2X2+b3X3....+bkXk

 

In the above equation, p represents the probability of the presence of a characteristic of interest. This algorithm is widely used in classification problems.

 

In order to avoid the problems of overfitting and underfitting, ensure that all significant variables have been included. Large sample sizes are also required for this algorithm, as maximum likelihood estimates are less powerful in cases of low sample sizes compared to ordinary least square.

1.  Polynomial Regression

A regression equation is said to be polynomial if the independent variable has a power greater than 1. Below is an example of a polynomial equation:

y=a+b\*x^2

 

With such an equation, the best-fit line will not be adequate. A polynomial equation produces a curve, so it will be a curve that best fits our data points. If you choose to minimize error by using a high degree polynomial, you can experience the problem of overfitting.

 

1.  Stepwise Regression

This is the best regression technique when there are many independent variables. An automatic process has to be employed for the purpose of choosing the independent variables, and no human intervention is involved.

To achieve the feat, we have to observe statistical values such as the R-square, AIC metric and t-stat.

 

Stepwise regression will fit the regression model by dropping/adding covariates, one by one, depending on certain specified criteria.

 

Below are some of the methods commonly used in stepwise regression:

*   Standard stepwise regression adds and removes predictors in the way expected in every step.  
     
*   Forward selection begins with the most significant predictor in your model, and it adds a variable for every step.  
     
*   Backward elimination begins with the predictors in your model, and the least significant variable is removed in each step.

 

The goal of this prediction technique is to maximize the power of prediction using the minimum number of predictor variables. It is one of the best ways of handling higher dimensionality in any data set.

A good application of this model is determination of factors which affect IQ (intelligence quotient) in human beings. IQ will be the dependent variable, while the independent variables for this problem can be height, weight and brain size.

 

With stepwise regression, you can create a model which works in such a way that the independent variable with the least (or no) contribution to the dependent variable (IQ) will be dropped.

 

1.  Ridge Regression

This regression technique is good for use with data which suffers from multicollinearity, that is, the independent variables are closely related.

 

Although least square estimates (OLS) in multicollinearity are not biased, they have large variances which normally deviate the observed value largely from true value. If a degree of bias is added to regression estimates, the standard errors will be reduced by ridge regression.

 

The equation for linear regression should be as follows:

y=a+b\*x+e (error term)

y=a+y= a+ b1x1+ b2x2+....+e

 

The shrinkage parameter, lambda (λ) is used in ridge regression for the purpose of solving the multicollinearity problem.

1.  Lasso Regression

Lasso stands for Least Absolute Shrinkage and Selection Operator. It is also good in penalizing the absolute size of regression coefficients just like the ridge regression. It can also reduce the variability and improve the accuracy of the linear regression models.

However, unlike the ridge regression, lasso regression uses absolute values in penalty function rather than squares.

 

Values that cause some parameter estimates to be zero are penalized. If a larger penalty is applied, the estimates shrink towards absolute zero, and this leads to a variable selection out of the given n variables.

KNN Algorithms 

KNN, which stands for K-Nearest Neighbors, is a simple algorithm that works well in practical situations.

 

The algorithm is non- parametric, meaning that no assumption is made regarding the underlying distribution of your data. The algorithm can be applied either to regression or to classification problems.

## How KNN Algorithm works

In KNN, complex data structures such as k-d trees can be used for data storage. This will help to make look-ups and matching for discovery of new patterns during predictions.

 

Once you have stored the whole of the data training set, you should consider how consistent your data is. Update it after getting new data, then make sure that any erroneous data is removed.

 

For KNN to make predictions, it directly uses the dataset. The predictions are made for some new instance (x) by means of a search through the whole training set for K similar instances (neighbors) and the output variable is summarized for the K instances.

 

For the case of regression, this will be the mean or median output variable, while for a classification problem, this will be the mode-class (or most common) variable.

 

In order to identify the K instances in a training dataset which are most similar to the new input, we use a distance measure.

 

For input variables which are real values, the common distance measure is the Euclidean distance. To calculate this distance, we have to find the square root of sum of squared differences between new point (X) and the existing point (Xi) across all the input variables j.

This can be expressed using the following formula:

EuclideanDistance(x, xi) = sqrt( sum( (xj – xij)^2 ) )

 

Other distances which can be used include the following:

Hamming distance - involves calculation of distance between the binary vectors.

 

Manhattan distance \- involves calculation of the distance between the real vectors by use of the sum of their absolute difference. It is also referred to as City Block Distance.

 

Minkowski distance - this is a generalization of the above two distances.

 

The kind of distance measure to use should be determined by your data. If you are not sure which is best for your data, you may need to experiment with the different measures and different values for K, and choose the one which gives you the most accurate model.

 

Euclidian distance should be used where the input variables are of similar type. For example, the measurement of heights and widths, are of similar type (meters).

 

The Manhattan distance should be used where the input variables are of different types. For example, age, height, gender.

 

The best way to select a value for K, is through experimentation. Try different values for K, and choose the one which gives you the best model. 

 

The KNN’s computational complexity normally increases with the size of the data set. If the training dataset is too large, you can make KNN stochastic by taking some sample from your training dataset from which you will calculate K most similar instances.

 

## Using KNN for Regression

If the KNN algorithm is used for a regression problem, the prediction will be based on the median or mean of K most similar instances.

## Using KNN for Classification

When KNN is used for a classification problem, the output may be calculated as the class which has the highest frequency from K-most similar instances.

 

Every instance will vote for its own class, and the class receiving the most votes will be taken for prediction.

 

Class probabilities can be calculated as normalized frequencies of occurrence (number of samples belonging to every class in a set of K similar instances for the new data).

 

The calculation for the case of a binary classification problem, for example, is:

p(class=0) = count(class=0) / (count(class=0)+count(class=1))

In case you are using K and the number of classes is even, avoid a tie by choosing an odd number for the value of K. If the number of classes takes an odd number, take an even number for the value of K.

For you to break ties, you can expand the K consistently by 1 then have a look at the class of next most similar instance in your training dataset.

 

KNN works well when the number of input variables (p) is small, but it will struggle if this number becomes large.

 

Every input variable can be seen to be a dimension of p-dimensional input space. Suppose you have two input variables namely x1 and x2, your input space will be 2-dimensional. If the number of dimensions is increased, the volume of input space will increase by an exponential rate.

 

Some of the examples of uses of KNN algorithm include nearest neighbor content retrieval.

 

A good example is computer vision applications such as handwriting detection.

Reinforcement Machine Learning Algorithms 

Clustering, a process used to find the structure of a collection of unlabeled data, is the most important kind of unsupervised learning algorithm. 

 

Clustering divides the data points into a set of groups known as clusters such that the data points in the same cluster are more closely related to each other than to the data points in other clusters.

 

In simple terms, the goal of clustering is to segregate the data into groups with similar characteristics and then assign them to clusters.

## How Clustering Algorithms Work

Suppose you run a rental store and your aim is to know the preferences of your customers in order to boost your business. It is impossible for you to analyze the preferences of each individual customer and then come up with a strategy for everyone.

 

The best way to approach this problem is to divide your customers into a number of groups, say 8, according to their purchasing habits. A strategy should then be devised for the customers of each group. This is how clustering algorithms work. 

 

Clustering can either be hard or soft.

 

In hard clustering, every data point must belong to a particular group, completely or not.

 

In our above example, each customer must belong to any of the 8 groups.

 

In soft clustering, each data point is not put into a separate cluster, but the likelihood or probability of assigning that data point to the cluster is assigned.

 

In our above example, every customer is assigned a probability of belonging to either of the 8 groups.

 

## Types of Clustering Algorithms

Clustering is a subjective task, meaning that there may be many paths to the desired goal. In every methodology, a set of rules is followed for the purpose of defining the similarity between the data points.

 

Let’s discuss some of the common clustering algorithms:

1.  K Means Clustering

This is a clustering algorithm which works iteratively with an aim of finding the local maxima during each iteration. The algorithm follows the following steps:

 

i. Specify the number of clusters you wish to have, K. 

ii. Assign every data point to a cluster randomly.

iii. Determine the cluster centroids.

iv. Re-assign every point to closest cluster centroid.

v. Re\-computer the cluster centroids.

Repeat steps iv. and v. until there are no possible improvements. At this point global optima shall have been reached.

 

This will be the end of the algorithm (if the algorithm was not explicitly limited).

 

The following are the advantages of the K-Means clustering algorithm:

*   The K-Means clustering algorithm offers a fast computation if the variables are huge and K is kept small.  
     
*   The algorithms can produce tighter clusters, making it easy for one to determine the relationship between the cluster members.

 

The following are the disadvantages of K-Means clustering algorithm:

*   Predicting the value of K may be difficult.  
     
*   Different initial partitions may give final clusters which are different.  
     
*   It doesn’t work well in cases where the clusters are of different densities and sizes.

 

1.  Hierarchical Clustering 

Hierarchical clustering works by creating a hierarchy of clusters. The algorithm begins with data points each of which has been assigned to its own cluster.

 

The two nearest clusters are then merged into a single cluster. The algorithm will terminate once only a single cluster is left.

 

A dendrogram is the best way to demonstrate how this clustering algorithm works. In a dendrogram, you begin with a set of data points, with each assigned to a separate cluster.

 

Two closest clusters are merged, and this continues until we remain with one cluster at the top of the dendrogram. The height in a dendrogram at which any two clusters are merged demonstrates the distance between the two clusters in a data space.

 

The following are the advantages of a Hierarchical clustering algorithms:

*   The algorithms are easy to implement and sometimes give the best results.  
     
*   There is no a prior information regarding the number of clusters to be formed. 

 

The following are the disadvantages of hierarchical clustering algorithms:

*   It impossible for algorithms to undo what has been done previously.  
     
*   A time complexity of about O(n2 log n) is needed, with n being the number of data points.  
     
*   There is no direct minimization of objective functions.
*   Identifying the number of clusters in the dendogram may be difficult.  
     

Note that K-Means is suitable when you have big data. This is because the K-Means algorithm has a linear time complexity, but a hierarchical clustering algorithm has a quadratic time complexity.

 

In K-Means, the number of clusters is chosen randomly, meaning that obtained results may differ from one selection of K to the next. In hierarchical clustering, we may reproduce the results.

 

The following are the applications to which you can apply clustering algorithms:

*   Market segmentation
*   Medical imaging
*   Search result grouping
*   Image segmentation
*   Recommendation engines
*   Anomaly detection
*   Social network analysis

## When to use Clustering Algorithms

Clustering algorithms should be used when one has a set of items and there is need to create some number of groups from these items.

 

Items which are similar are placed in the same group, while items which are different appear in separate groups.

 

Division of a population into either male or female is a good example of a clustering application. You may use characteristics such as hair length. Those with shorter hair might be grouped separately from these with longer hair. 

 

Another application might be the grouping of news articles by category: business articles, politics, human interest, etc.   
 

Or suppose you have a number of documents written in various languages. You might use a clustering algorithm to create clusters from these documents, based upon the language used.

Artificial Neural Networks 

The neurons of the human brain are connected together like semiconductors in a computer processor. Their interconnection creates a network in which each neuron interacts, according to a set of defined rules, with the neurons surrounding it.

 

An artificial neural network is a software simulation of the human brain. The network is composed of interconnected programs called neurons.

The data enters the system at the first neuron, which performs the programmed operations and passes its output to the next neuron on the network.

 

This neuron in turn performs its program, producing another intermediate output. Neurons in an artificial neural network are arranged in layers, and the final output is produced in the final layer. 

 

The process of generating an output from the given input is governed by the programming of the individual neurons as well as the initial conditions of the data. Rules can be implemented in artificial neural networks so as to ensure that they simulate the human brain.

## How ANNs Work

The process of learning in neural networks is implemented through the use of a learning algorithm. As we said, the neurons in a neural network are organized into layers.

 

Each layer is connected to the layers on either side. The purpose of the input layer is to receive the input from the external environment which you need to learn about.

The last layer in the neural network is referred to as the output layer, and this is the layer which gives the results of the learning process.

 

Between the input and the output layers, there exists some number of hidden layers. A fully connected neural network is one in which every hidden layer is connected to the layers on either side of it.

 

The connection of one layer to another is represented by a number known as a *weight*. The value of the weight can be positive or negative. A higher weight will have a greater influence on the network.

 

The common design of a neural network in which inputs are fed into the input layer with outputs received at the output layer is referred to as a *feedforward network*.

 

Each unit receives inputs from units located to its left, then multiplied by the values of the weight they have travelled along.

 

Every unit will add all connections it receives and if this sum exceeds a particular threshold value, will fire and propagate or trigger the units it is connected to on the right side of the network.

 

In order for a neural network to learn, there must be feedback. The feedback is similar to a “right” or “wrong” response to the selected output or action. 

 

This kind of learning occurs in children when they are told whether what they are doing is right or wrong -- or even in adults! Think about it. If you became aware after the fact that you failed in some task, you probably planned how you might improve your “output” the next time approach the same task. It is the same with artificial neural networks.

 

The purpose of feedback is to allow comparison between actual output and the desired output. The difference between the two is assessed, and a determination is made on how the process might be improved in order to generate a better output next time. 

The feedback process in neural networks is known as *backpropagation*.

 

The final output of the network is compared to the desired output, and the difference is used to prescribe modifications to the weights of the connections between the network units.

 

This is done for output unit, to each of the hidden units, and lastly to the input unit. In other words, for each unit in reverse order from output to input. The process causes the neural network to learn, reducing the difference between actual and target outputs this difference is normally referred to as the *network error.*

 

The goal, obviously, is to reach a network error of zero, which requires that the network output be equal to the target output, but this may be difficult. After using several examples to train the artificial neural network, your network output will be sufficient to allow you to give the network a brand new set of input data and observe the outputs it gives.

 

Consider an example in which you train your artificial neural network to differentiate between chairs and tables.

 

You input the pictures of chairs and tables into the network and it classifies them as either chairs or tables. You train the network with 25 chairs and 25 tables. Now let say we give the network a new untested picture with perhaps a slightly different in design than earlier pictures, a designer coach chair, it should be able to classify it as either a chair or a table based on its previous experience.

 

However, this is not an indication that a neural network is capable of just looking at something and responding instantly to give the result. Its behavior is not like that of a person.

 

In the example given previously, the network will not be looking at pieces of furniture. The network receives input in a binary form, meaning that each input unit is switched either on or off.

 

Suppose you have 5 input units, information about five different characteristics of chairs in the form of binary answers (yes/no).

The questions can be:

Does the item pictured have a top?

A backrest?

Can you sit on it comfortably for a longer period?

Can you place a lot of stuff on it?

 

For a typical table, the answers will be yes, no, no, yes. In binary terms, these answers can be expressed as 1001. For a typical chair, the answers would be no, yes, yes, no. In binary terms, these can be expressed as 0110.

 

During the learning process, the artificial neural network will learn the characteristics which represent a chair those which represent a table, and those common to both.

 

With this knowledge, the neural network will be able to different between chairs and tables.
