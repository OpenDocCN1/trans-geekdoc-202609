
# 后向消除

后向消除从模型中的预测器开始，并在每一步中移除最不显著的变量。

该预测技术的目标是使用最少的预测器变量来最大化预测能力。它是处理任何数据集中更高维度的最佳方法之一。

该模型的一个良好应用是确定影响人类智商（IQ）的因素。IQ 将是因变量，而用于此问题的自变量可以是身高、体重和脑容量。

通过阶梯回归，你可以创建一个模型，其工作方式是自变量对因变量（IQ）贡献最小（或没有贡献）的变量将被剔除。

1.  岸上回归

这种回归技术适用于存在多重共线性的数据，即自变量之间存在较高相关性。

虽然在多重共线性下最小平方估计（OLS）不偏，但其方差较大，通常会导致观测值与真实值差异很大。如果在回归估计中加入一定程度的偏差，岭回归会减少标准误差。

线性回归的方程应为：

y=a+ b\*x

在上述方程中必须加入误差项。下面是完整的方程：

y=a+b\*x+e（误差项）

误差项是用于修正预测值与观测值之间错误的值。对于多个自变量的情况，我们应该有：

y=a+y= a+ b1x1+ b2x2+....+e

收缩参数，lambda（λ），在岭回归中用于解决多重共线性问题。

1.  拉索回归

Lasso 代表最小绝对收缩和选择算子。它与岭回归一样，对回归系数的绝对大小进行惩罚，还能减少线性回归模型的变异性并提高准确性。

然而，与岭回归不同，拉索回归在惩罚函数中使用绝对值而非平方。

导致某些参数估计为零的值会被惩罚。如果应用更大的惩罚，估计值将收缩至绝对零，从而实现从给定的 n 个变量中选择变量。

## 回归算法的优势

以下是回归分析的优势：

*   通过回归算法，我们可以确定一系列中的相对变异。

*   帮助我们确定变量之间的关系。从而可以根据已知值推导未知变量的值。

*   它是高度适用于日常生活的技术。我们可以用它来估计诸如死亡率、税率、出生率、产量率等趋势。

## 回归算法的缺点

*   必须假设变量之间的关系保持不变。在现实生活中这可能不总是成立，且任何关系的改变都可能导致预测出错。

*   回归算法的计算和分析过程冗长且复杂。

*   回归算法无法用于估计定性变量，如犯罪、诚实等。

## 何时使用回归算法

回归也可以帮助你理解各种因素之间的相互作用。

当你需要知道最重要的因素以及可以忽略的因素时，回归是一个好的技术选择。

回归算法被企业和公司广泛应用于预测未来事件或确定如何增加销售额以及招聘和留住高质量员工。

# KNN 算法

KNN，即 K-Nearest Neighbors，是一个简单的算法，在实际应用中表现良好。

该算法是非参数的，意味着不假设数据的底层分布。该算法可用于回归或分类问题。

## KNN 算法的工作原理

在 KNN 中，可以使用 k-d 树等复杂数据结构来存储数据。这将有助于在预测过程中进行查找和模式发现。

一旦你存储了整个训练数据集，你应该考虑数据的一致性。在获得新数据后更新它，并确保删除任何错误数据。

为了使 KNN 进行预测，它直接使用数据集。预测是通过在整个训练集中搜索 K 个相似的实例（邻居），然后对输出变量进行总结。

对于回归问题，这将是 K 个最相似实例输出变量的平均值或中位数；对于分类问题，这将是众数类（或最常见）变量。

为了找出训练数据集中与新输入最相似的 K 个实例，我们使用距离度量。

对于实值输入变量，常用的距离度量是欧几里得距离。计算该距离需要求新点（X）与现有点（Xi）在所有输入变量 j 之间差值的平方和的平方根。

公式如下：

EuclideanDistance(x, xi) = sqrt( sum( (xj – xij)^2 ) )

其他可用的距离度量包括：

*   汉明距离 - 用于计算二进制向量之间的距离。

*   曼哈顿距离 - 通过实向量的绝对差值之和计算距离，也称为“城市区块距离”。

*   威尔逊距离 - 这是上述两种距离的推广。

应使用的距离度量取决于你的数据。如果不确定哪种最适合，可能需要尝试不同的度量和 K 值，选择表现最佳的模型。

欧几里得距离应用于输入变量类型相似的情况，例如身高和宽度的测量，单位均为米。

曼哈顿距离应用于输入变量类型不同的情况，例如年龄、身高和性别。

选择 K 值的最佳方式是通过实验。尝试不同的 K 值，选择表现最佳的模型。

KNN 的计算复杂度通常随数据集大小而增加。如果训练数据集过大，可以通过取样使 KNN 具有随机性，即从训练数据集中抽取样本，从中计算 K 个最相似的实例。

## 使用 KNN 进行回归

如果将 KNN 算法用于回归问题，预测将基于 K 个最相似实例的中位数或平均值。

## 使用 KNN 进行分类

当将 KNN 用于分类问题时，输出可以计算为 K 个最相似实例中出现频率最高的类别。

每个实例会为其所属类别投票，预测类别为获得最多票数的类别。

类别概率可以计算为出现频率的归一化（在 K 个相似实例中，属于每个类别的样本数之比）。

对于二元分类问题，例如：

p(class=0) = count(class=0) / (count(class=0)+count(class=1))

如果你使用 K 且类别数为偶数，通过选择奇数 K 来避免平局。如果类别数为奇数，则选择偶数 K。

为了打破平局，你可以将 K 稳步增加 1，然后查看训练数据集中与最相似实例的下一个类别。
