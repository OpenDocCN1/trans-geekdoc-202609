## Introduction To Machine Learning

人类不断学习。如果您考虑儿童和成人行为的差异，就会认识到学习对人类发展的重要性。个体不断受其环境的影响。经验使个体能够改变行为，以便更有效地与环境互动。因此，学习可以定义为受先前经验影响而发生的变化。技能、习惯、兴趣、知识以及其他个人特征都是学习的结果。

## Chapter 2

## Machine Learning

机器学习在计算机领域是借鉴人类行为而来的。它是人工智能的一个分支，涉及设计和开发能够基于以往经验进行自我改进的系统。

这意味着，在面对相同的情况时，机器应能够时不时表现出改进。

通过机器学习，软件系统能够准确预测，而无需显式编程。

机器学习的目标是构建能够接收输入数据并运用统计分析在可接受范围内预测输出值的算法。

机器学习基于学习与模式识别的关联，以及计算机应能够识别模式并“学习”，在无需人工干预（如额外编程或人工输入）的情况下调整其响应的理论。

人工智能领域的研究者希望确定计算机是否能从可获取的数据中学习。机器学习是一种迭代方法，因此机器学习模型在接触新数据时能够适应。模型会从以往的计算（其输出成为输入）中学习，以提供可重复、可靠的结果和决策。

机器学习的日益流行归因于促使数据挖掘流行的相同因素。这些因素包括更便宜且更强大的计算处理能力、更丰富的数据种类以及更经济的数据存储手段。

基于这三点，很容易产生能够分析更大更复杂数据、提供更快更准确结果的模型。更精确的模型使企业更容易识别盈利机会并规避风险。

通过机器学习，企业还能够得出结论并识别模式，从而创建预测模型。这有助于企业做出明智的决策。

## Details about Machine Learning

## Supervised Learning

![Image](Images/image00073.jpeg)

在监督学习的情况下，人类需要提供期望的输入和输出，并根据预测的准确性给出反馈。训练完成后，算法需要将所学应用于下一组数据。

监督学习的概念可以类比于受教师监督的学生学习。教师提供输入和输出样本，学生从中推导出规则，然后将这些规则应用于未来的输入。

监督学习算法主要有两种：回归和分类。

在回归问题中，目标是一个数值；而在分类问题中，目标是一个类别或标签。

回归任务可以用于确定伦敦所有房屋的平均成本，而分类任务则可以用于根据萼片长度和花瓣长度来确定花的种类。

## Unsupervised Learning

![Image](Images/image00074.jpeg)

在无监督学习的情况下，算法仅接收未标记的输入——没有输出或反馈。算法采用深度学习这一迭代方法，对数据进行审查并得出新结论。

这使得无监督学习算法适用于处理比监督学习算法更复杂的任务。无监督学习算法仅凭样本学习，无需给出任何结论，能够自主从样本中识别模式。
