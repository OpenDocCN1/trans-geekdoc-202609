By first examining your shopping history and comparing it to histories of other customers, recommender algorithms can predict what kinds of items you might want to purchase and produce personalized shopping suggestions.

## Reinforcement Learning

![Image](Images/image00075.jpeg)

This type of learning occurs when the algorithm is presented with raw, unlabeled inputs only - no outputs. But a positive or negative feedback is provided in response to the solution (output) proposed by the algorithm. This can best be compared to trial and error in human learning. 

Errors become useful in learning when they are associated with a penalty such as pain, cost, loss of time etc.

Machine learning processes are similar to those of data mining and predictive modeling. In both cases, searching through the data is required to detect and act upon recognized patterns, adjusting output accordingly. 

Again, recommender systems are serve as an excellent example of machine learning applications as, if you purchase an item online, you are likely very shortly to see an ad related to that very purchase. 

**Chapter 3  

**Machine Learning Tools

A variety of tools have been developed for use in machine learning. These tools are helpful to people who are interested in machine learning but have little or no knowledge of computer programming.

With the use of such tools it is possible to create machine learning models and then to train and use them to make predictions. Let’s discuss some of the best of these machine learning tools. 

## Tensorflow

Tensorflow is a tool developed by Google Brain Team and used for machine learning and deep neural networks. The tool is open source and compatible with most GPUs and CPUs.

Most Google services, such as Gmail, Google Photos, Speech Recognition and Google Search come equipped with Tensorflow, which makes use of data flow graphs to perform complex numerical tasks.

Graphs created from edges and nodes are used for elaborating the mathematical computations. The nodes are used for implementing the operations as well as endpoints where data can be fed. The edges are a representation of the input/output associations between the various nodes.

IoT (Internet of Things), security and automotive industries are using Tensorflow for voice recognition. Telecom and handset manufacturers are also using Tensorflow for voice search.

## Caffe

This is a machine learning tool developed with a strong emphasis on speed, expression and modularity.

The tool was developed to be used in computer image classification by leveraging the Convolutional Neural Networks (CNNs).

Compared to Tensorflow, which is better suited to research and development, Caffe is better for building computer applications. Caffe is not well suited for applications dealing with sound, text and time series data.

However, but for those in need of computer vision, Caffe can run on a variety of different hardware, and it is the best for switching between GPU and CXPU by use of a single flag.

Examples of established companies using Caffe include Facebook, Microsoft, Adobe, Yahoo and others, in their image processing projects.

## Amazon Machine Learning

The AML is Amazon’s own machine learning service, created for use by developers. It is made up of several tools which can be used to generate high-end, sophisticated, intelligent learning models without writing any code.

The tool also provides various APIs (application programming interfaces) which can be used for making predictions needed for applications. This service is very flexible and heavily used by Amazon’s data scientists for powering their Amazon Cloud Services.

It can be connected to data stored in Amazon S3, Redshift or RDS for performing tasks such as regression, binary classification or multi-class categorization so as to create new models.

## Apache Singa

A good tool for machine learning, Apache Singa was developed for use in distributed deep learning via model partitioning and parallelizing 0f the training process. It provides a simple but robust programming model which can be used across node clusters. It is widely used in natural language processing (NLP) and image recognition.

Apache Singa was developed with an abstraction layer. The kit supports a number of deep learning models. Due to the flexibility of the architecture, Singa can run synchronous, asynchronous and hybrid training models.

The three key components of Singa include IO, Model and the Core. The IO component is made up of classes which can be used for reading and writing data to network and disk. The core component is responsible for handling memory management and tensor operation functions. The model component has the data structures and algorithms which can be used in the machine learning models.

Singa is heavily applied in healthcare systems, especially in disease progression modeling for early detection and management of chronic diseases.

## Microsoft CNTK

CNTK stands for Cognitive Toolkit, and it is an open source machine learning tool developed by Microsoft. It is commonly used in speech recognition, but it is also good for image and text processing. It supports many machine learning algorithms like AS CNN, LSTM, Sequence-to-Sequence, RNN, and Feed Forward, making it one of the most dynamic machine learning tools.

CNTK is capable of supporting a wide variety of hardware, including GPUs and CPUs.

The CNTK framework has a high degree of compatibility and is recognized as the most expressive and easy-to-use machine learning framework.

The tool allows you to work with programming languages such as Python and C++. You can also build your own training models or use the built-in ones.

Microsoft is using CNTK to create its marquee products.

## Torch

This is a machine learning tool which can be easily set up, especially if you are running Ubuntu Linux. Big tech companies such as Twitter and Facebook heavily use Torch.

It was developed using the Lua programming language, which is easy for anyone to read and understand. Also contributing to Torch’s ease of use are its clear error messages, repository of sample code, guides, and a helpful user community.

The Facebook AI Research Group, Yandex, IBM, and Idiap Research Institute are examples of companies using Torch.

These companies use it to generate hardware implementations for data flows similar to those of neural networks.

## Accord.NET

An open source machine learning framework based on .NET, Accord.NET is ideal for use in scientific computing. It has a number of libraries which are applicable to pattern recognition, statistical data processing, artificial neural networks, image processing, linear algebra, and others. The libraries for the framework come in the form of source code, installers and NuGet packages. Accord.NET also comes with a matrix library which can be used to facilitate algorithmic changes and code reusability.

## Apache Mahout

This open source software was developed by the Apache Software Foundation for the purpose of providing a scalable or distributed machine learning framework to be applied to classification, clustering and collaborative filtering.

Mahout also has Java collections for various Java libraries and computational operations. It has been deployed on top of Hadoop by use of the MapReduce paradigm. It is highly applicable where one needs to gain insights into data.

After connecting the Big Data stored in Hadoop, the tool can help you to identify useful patterns from the data. The Apache Software Foundation uses Mahout to implement its distributed learning models.
