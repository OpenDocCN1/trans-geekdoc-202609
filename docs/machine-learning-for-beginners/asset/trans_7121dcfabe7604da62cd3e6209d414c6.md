
无监督学习算法的工作原理类似于人类观察和分析，从而发现两个或多个物体之间的相似性。你在网上购物时遇到的大多数推荐系统都是基于无监督学习算法的。

通过首先查看你的购物历史，并将其与其他客户的历史进行比较，推荐算法可以预测你可能感兴趣购买的商品类型，并提供个性化的购物建议。

## 强化学习

![Image](Images/image00075.jpeg)

这种学习发生在算法仅接收未标记的原始输入时，没有输出。但对算法提出的解决方案（输出）会提供正向或负向反馈。这最好可以类比于人类学习中的试错过程。

当错误与某种惩罚（如疼痛、成本、时间损失等）相关联时，错误就会在学习中变得有用。

机器学习过程与数据挖掘和预测建模相似。在这两种情况下，都需要在数据中搜索，以检测和利用已识别的模式，并据此调整输出。

再次，推荐系统是机器学习应用的一个极佳例子。例如，你在网上购买了一件商品，很快就会看到与该购买相关的广告。

**第3章  

**机器学习工具

为机器学习开发了各种工具。这些工具对对机器学习感兴趣但缺乏计算机编程知识的人很有帮助。

使用这些工具，你可以创建机器学习模型，然后训练它们并用于进行预测。让我们讨论其中一些最佳的机器学习工具。

## Tensorflow

Tensorflow 是由 Google Brain Team 开发的工具，用于机器学习和深度神经网络。该工具是开源的，兼容大多数 GPU 和 CPU。

大多数 Google 服务，如 Gmail、Google Photos、语音识别和 Google 搜索都配备了 Tensorflow，它使用数据流图来执行复杂的数值任务。

由边和节点创建的图用于阐述数学计算。节点用于实现操作以及数据输入的端点。边代表节点之间的输入/输出关联。

物联网（IoT）、安全和汽车工业使用 Tensorflow 进行语音识别。电信和手机制造商也使用 Tensorflow 进行语音搜索。

## Caffe

这是一个强调速度、表达能力和模块化的机器学习工具。

该工具是用于利用卷积神经网络（CNNs）进行计算机图像分类而开发的。

与 Tensorflow 相比，后者更适合科研和开发，Caffe 更适合构建计算机应用。Caffe 不适合处理音频、文本和时间序列数据的应用。

然而，对于需要计算机视觉的用户，Caffe 可以在各种硬件上运行，并且通过使用单个标志来切换 GPU 和 CXPU，这使其成为切换的最佳选择。

使用 Caffe 的知名公司包括 Facebook、Microsoft、Adobe、Yahoo 等，它们在图像处理项目中使用它。

## Amazon Machine Learning

AML 是亚马逊自己的机器学习服务，专为开发者设计。它包含多种工具，可用于在无需编写任何代码的情况下生成高端、复杂、智能的学习模型。

该工具还提供多种 API（应用程序编程接口），可用于为应用程序提供预测。该服务非常灵活，并被亚马逊的数据科学家广泛用于为其 Amazon Cloud Services 提供支持。

它可以连接存储在 Amazon S3、Redshift 或 RDS 中的数据，用于执行回归、二元分类或多类分类任务，以创建新模型。

## Apache Singa

Apache Singa 是一个用于机器学习的良好工具，它被开发用于通过模型分区和并行化训练过程来进行分布式深度学习。它提供了一个简单但强大的编程模型，可用于跨节点集群。它在自然语言处理（NLP）和图像识别中被广泛使用。

Apache Singa 采用了抽象层进行开发。该套件支持多种深度学习模型。由于其架构的灵活性，Singa 可以运行同步、异步和混合训练模型。

Singa 的三个关键组件包括 IO、Model 和 Core。IO 组件包含用于读取和写入网络和磁盘数据的类。Core 组件负责处理内存管理和张量操作函数。Model 组件包含机器学习模型的数据结构和算法。

Singa 在医疗系统中被广泛应用，特别是在慢性病早期 detection 和管理的疾病进展建模中。

## Microsoft CNTK

CNTK 代表认知工具包，是由 Microsoft 开发的开源机器学习工具。它常用于语音识别，但也适合图像和文本处理。它支持许多机器学习算法，如 AS CNN、LSTM、序列到序列、RNN 和 Feed Forward，使其成为最具活力的机器学习工具之一。

CNTK 能够支持广泛的硬件，包括 GPU 和 CPU。

CNTK 框架具有高度的兼容性，被认为是最具表达性和易用性的机器学习框架。

该工具允许你使用 Python 和 C++ 等编程语言工作。你也可以构建自己的训练模型，或使用内置的模型。

Microsoft 使用 CNTK 创建其标志性产品。

## Torch

这是一个机器学习工具，可以轻松设置，特别是在运行 Ubuntu Linux 时。像 Twitter 和 Facebook 等大型科技公司大量使用 Torch。

它是基于 Lua 编程语言开发的，该语言易于阅读和理解。此外，Torch 的易用性还得益于其清晰的错误消息、示例代码库、指南以及有帮助的用户社区。

Facebook AI 研究小组、Yandex、IBM 和 Idiap Research Institute 是使用 Torch 的公司示例。

这些公司使用它来生成类似于神经网络的数据流的硬件实现。

## Accord.NET

Accord.NET 是一个基于 .NET 的开源机器学习框架，非常适合科学计算。它包含多个库，适用于模式识别、统计数据处理、人工神经网络、图像处理、线性代数等。该框架的库以源代码、安装程序和 NuGet 包的形式提供。Accord.NET 还附带一个矩阵库，可用于促进算法变更和代码可重用性。

## Apache Mahout

这是 Apache Software Foundation 开发的开源软件，旨在提供一个可扩展或分布式机器学习框架，用于分类、聚类和协同过滤。

Mahout 还提供用于各种 Java 库和计算操作的 Java  collections。它通过 MapReduce 范式在 Hadoop 上部署。它在需要从数据中获得洞察时非常有用。

在将大数据存储在 Hadoop 后，该工具可以帮助你从数据中识别有用的模式。Apache Software Foundation 使用 Mahout 实现其分布式学习模型。
