
This method corrects the values while maintaining their relative orders from the lowest to highest. The value to be added can be chosen by determining the scale of the variable you need to correct.

However, it is good for you to note that if the addition is small, there are high chances that there will be no change to the statistical output.

Management of outliers increases the probability of obtaining meaningful information from your analysis. The amount by which an outlier affects your analysis depends on a number of factors including the size of the dataset. 

If the set is large, each observation will carry less weight, such that the effect of an outlier will be minimal. This is not the case with a small dataset in which each observation carries much more weight. Using one of the above presented methods, however, you will address the problem of outliers and achieve an effective analysis.

Data Management

Data management refers to the process of ensuring that research data is archived, stored, and/or securely and safely discarded during and after a research project. This includes the formulation of policies for handling both electronic and non-electronic data.

## Storing Data

It is always important to consider how and where you will store your data after collecting it. Data needs to be held securely so that it cannot be compromised in any way. You should also determine which data you will store, which data will be discarded, and the file format to be used for data storage.

There are a variety of places into which data can be stored, including laptops, flash drives, desktops and the cloud. If the data is stored in a networked drive, you will be able to schedule regular backups, minimize security breaches and losses, and provide access to all who need it.

The UCL (University College of London) repository provides you with another possible data storage solution. This facility is centrally managed and can accommodate both small and large data volumes. You can access up to 5TB of storage for free. If your data is sensitive, you can use the UCL Data Safe Haven for storage.

The cloud provides another storage option, though if you are dealing with sensitive data you will have to come up with a means for encrypting it. Also, note that cloud providers will not take responsibility should your data somehow become corrupted.

It is possible as well that a cloud provider may go out of business or encounter a problem that necessitates a temporary shutdown, and you may end up losing access, at least for a time, to your data.

If your data is stored in hard copies, identify the records you will be using frequently and keep them close to your office; then keep the rest off-site.

## Securing Raw Data

Data security is forever a matter of prime concern. There are a number of procedures which can help you maintain the security of your data, including frequent password changes and the creation of very strong passwords. If your documents are kept in laptops and flash drives, you can use software to encrypt them.

Implementing separate passwords for each document is not recommended. This is also the case with saving your data in hard drives. Note that data security extends also to the protection of the data from erasure.

There are tools to help you recover deleted data. These can be a lifesaver in a pinch, but remember: if you need to remove sensitive data from your system, you must ensure that this data has been wiped completely from the portable drives and hard disks in order to prevent a later access which might lead to leakage of sensitive data to the unauthorized persons.

The aim of securing data is to ensure that it is not deleted, altered, or accessed by any unauthorized individuals. If your data is altered before training your model, your training is compromised, as will be the resulting predictions. Make use of all of the above security measures in order to secure your data.

## Data Preservation

Finally, at some point you must determine what to do with the data after the project. Where will the data be stored, for how long, and how the data can it be made accessible for the long term? Also, which data (from raw data to final outputs) should be made available, and to whom?

The format in which you have stored your data might also become obsolete with time, so you have to plan for this possibility. The kind of software you are using for data storage will also determine obsolescence. It is recommended that you use open, non-proprietary, well documented formats when storing your data, especially for the long term.

Note that there are some data which, once lost, can never be replaced. Preservation of the data may be required, therefore, especially if an organization funded your project. This is why you need to be very intentional about choosing the best possible means of preserving your data.

## Training Phase

In order to train a machine learning model, you must provide a machine learning algorithm with training data from which it will learn.

The training data should include correct outputs, to which we normally refer collectively as the target. The purpose of the training algorithm is to identify, through the discovery of patterns in the data, rules which can map the input data to the target. "These rules will be incorporated into a machine learning model capable of producing correct outputs for future data inputs."

![Image](`Images/image00078.jpeg`)

Your trained model will be able to produce correct outputs for new data targets are not known. Let’s say you want to create a machine learning model capable of determining whether or not an email should be identified as spam.

You should first train the model using data with labels identifying each email as spam or not spam, such that the target for the training data will be known. This training will result in a machine learning model which will, in turn, be detect on its own whether or not any given email is spam.

There are several tools which can be used to create and train machine learning models. If you need to create a neural network machine learning model for instance, you can use the Neuroph Studio or any of the other appropriate tools mentioned in this book.

Most of these tools will take you through the following steps to train your machine learning model:

1.  Uploading the Training Data

The training data must be loaded to the tool. Training data can take different forms, such as text, images, comma separated values (CSV), JSON, etc.

Your machine learning tool will provide you with an easy mechanism for uploading your data. Neuroph Studio, for example, asks you to specify how your data has been grouped. It is advisable that you save your data in a text file and space the files.

1.  Data Labeling

Next you will be required to indicate whether data in different columns are separated by commas or tabs. If you are using a tool such as Minitab, the data should be separated by tabs, maybe in a text file, and you will need to specify which columns contain input data and which contain outputs (targets).

When using a tool such as Minitab, you should organize the data into rows and columns. For the case of a tool such as Neuroph Studio, you can choose to separate the data by use of tabs, commas etc. The tool is able to know how the data has been organized, and it will automatically organize the data into rows and columns.

It is during the time of data labeling that you are expected to specify the data columns which are the inputs and the data columns which are the outputs.

1.  Transformation Instructions

Some tools will ask you to choose the type of training algorithm you need to apply to your data. There are various machine learning algorithms provided by software tools for creating and training machine learning models.
