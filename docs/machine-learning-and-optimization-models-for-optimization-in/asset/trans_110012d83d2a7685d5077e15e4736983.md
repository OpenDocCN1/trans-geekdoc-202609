## 5.1.4.3 Virtual Machine (VM) Migration

The cloud is a distributed environment where users can migrate workloads to different machines to complete execution quickly. Virtualization means running multiple logical machines on a single physical machine. During migration, the VM moves from one physical machine to another. Migration can be offline or online (live). In offline migration, the machine stops until the migration process completes; whereas in online (live) migration, client services are not interrupted during the migration process. Live migration has been widely used to reduce energy consumption, for load balancing, and for dynamic resource allocation.

To migrate a VM, the entire VM state must be transferred from the source to the destination. The VM includes persistent storage, volatile storage, the state of connected devices, and the internal state of the virtual CPU. Persistent storage does not need to be moved as it is provided by Network Attached Storage (NAS). The CPU state and the state of virtual devices with smaller volumes can be easily transferred to the destination host. The main issue with live migration is the transfer of main memory (i.e., volatile storage) because it contains gigabytes of data [4].

## 5.2 Introduction to Neural Networks

Artificial Neural Networks are inspired by the functioning of the human brain. `ANN` is a set of algorithms that function similarly to the human brain to recognize patterns. Neural networks take some raw input data and interpret it through clustering, perceiving, or labeling. `ANN` can recognize all real-world objects and patterns, such as images, sounds, text, etc. `ANN` helps in classification, clustering, and grouping of unlabeled data.

Looking at the expanded name, `neural` refers to the brain cell neurons in the human body, and `network` refers to interconnected components. Neurons in the human body transmit signals to the brain, but importantly, the human brain learns from experience and trains data based on past experiences. Similarly, we want artificial machines to work based on the concept of the human brain, called neural networks. In Artificial Neural Networks, there will be artificial neurons transmitting signals and training data to generate better outputs. Neural networks can be used in recognition domains where the human brain excels, such as data classification and pattern recognition.

**Types of Neural Networks**:

*   **Artificial Neural Network (`ANN`).**
*   **Convolutional Neural Network (`CNN`).**
*   **Recurrent Neural Network (`RNN`).**

## 5.2.1 Artificial Neural Network (ANN)

This is the simplest type of neural network. An Artificial Neural Network is a collection of various neural networks at different levels. Inputs in `ANN` are processed in the forward direction. Therefore, `ANN` is also called a Feedforward Neural Network. These networks are universal function approximators because they can learn any type of non-linear function. Mapping is done by assigning weights to inputs to generate outputs. Activation functions help the network understand the relationship between inputs and outputs.

`ANN` has the following three layers (Figure 5.3):

*   **Input Layer**: In the input layer of `ANN`, inputs are received. Inputs received and forwarded to the next layer. In our case, the input will contain the following variables.
*   **Hidden Layer**: The hidden layer of `ANN` has no connection with the outside world; hence it is called the hidden layer. It processes inputs forwarded by the input layer.
*   **Output Layer**: The output of `ANN` generates the output processed by the hidden layer.

## 5.2.2 Convolutional Neural Network (CNN)

Convolutional Neural Networks are mainly used for image classification. `CNN` can generate data from images and can distinguish one image from another. The building block of `CNN` is the kernel. The kernel is also called a filter. Using the convolution operation, the kernel or filter is used to extract relevant features from the input.

## 5.2.3 Recurrent Neural Network (RNN)

Recurrent Neural Network is an extended version of the Artificial Neural Network. Unlike `ANN` which processes forward at each layer, `RNN` adds an iterative constraint in the hidden layer. Therefore, through iterative constraints, we can access information from the previous iteration and train data based on past iterations. Because it has recurrent connections in the hidden layer, it is called a Recurrent Neural Network. The previous output is considered as input for the next layer.

*   **Input Layer**: The input layer of `RNN` receives input.
*   **Recurrent Layer**: In the recurrent layer, input is processed and iterated to generate better output.
*   **Output Layer**: This layer generates the output processed by the recurrent layer.
