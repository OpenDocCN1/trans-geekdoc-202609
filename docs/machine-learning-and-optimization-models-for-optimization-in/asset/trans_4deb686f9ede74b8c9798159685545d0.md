

# 7.5 结果与讨论

仿真使用 `Cloudsim 3.0` 进行。仿真采用真实任务模拟的工作负载追踪，该追踪为来自并行工作负载存储库的免费开源数据集，格式为 `SWF` 格式的工作负载文件（[表 7.1](#index_split_002.html#p146)）。

`bat-ANN` 模型的性能评估使用以下性能指标进行：

1. 总执行时间/完工时间（毫秒）。
2. 平均开始时间（毫秒）。
3. 平均完成时间（毫秒）。
4. 已完成任务数。
5. 失败任务数。

[图 7.2](#index_split_002.html#p145) 展示了所提 `bat-ANN` 模型的流程图。该流程图展示了所提算法 `bat-ANN` 的图示表示。它清晰地描绘了蝙蝠优化技术的作用以及多层感知机模型的边缘权重优化。因此，训练数据集是使用蝙蝠算法生成的。

虚拟机 ID 和云任务 ID 的输入数据集是通过自然启发的频率调谐进化技术提供的。

# 7.6 结论与未来工作

本文提出了一种用于云基础设施任务调度的高效任务调度方案。所提 `bat-ANN` 模型优于遗传算法和现有技术。结果部分表明，该模型在云 `IaaS` 环境下的表现优于现有技术。性能通过以下指标计算：平均完成时间（毫秒）、平均开始时间（毫秒）、总执行时间、故障率、已完成任务数和失败任务数。

本工作仅专注于使用蝙蝠算法进行云任务调度。该工作提出了一种具有高服务质量的容错模型。在未来的工作中，所提模型将用于主机上的资源调度和迁移方法，以通过最优资源更好地利用资源，改善云应用的运行成本。
