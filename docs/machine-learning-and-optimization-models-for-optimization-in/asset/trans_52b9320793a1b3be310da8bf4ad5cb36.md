# 7.1 引言

系统的可靠性是通过系统的故障概率来衡量的[[4]](#index_split_002.html#p149)。在本文中，我们介绍了一种主动的、预测性的、功耗感知的、容错的高效调度技术，该技术基于蝙蝠算法和前馈神经网络的混合方法[[1]](#index_split_002.html#p148)。这也被称为基于ANN的容错功耗高效调度（FTS-ANN）。结果表明，提出的蝙蝠算法-ANN技术提高了虚拟机的可靠性。本文组织结构如下。第7.2节简要回顾了聚焦于云环境中容错调度的相关文献。第7.3节阐述了提出的FTS-ANN技术。第7.4节展示了FTS-ANN与其他基于主动容错感知调度机制的静态、动态和元启发式技术相比的实验结果。还详细讨论了使用FTS-ANN模型的结果。最后，第7.5节涵盖了结论和工作的未来扩展。
