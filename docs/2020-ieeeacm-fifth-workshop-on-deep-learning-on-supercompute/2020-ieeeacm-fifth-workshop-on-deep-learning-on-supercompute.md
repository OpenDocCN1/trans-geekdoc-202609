
# 2020 IEEE/ACM 第五届超级计算机深度学习研讨会 (DLS)

## 工作讨会主席致辞

人们对深度学习（DL）与高性能计算（HPC）融合的兴趣正迅速增长。深度学习从业者在类 HPC 系统上训练神经网络，以利用其海量的计算能力、卓越的内存架构和高速互连技术；而科学家和工程师则将深度学习方法应用于分类、插值和反向建模等问题。然而，深度学习也对科学研究和 HPC 社区带来了新挑战，例如需要高效地处理大型且复杂的训练数据、新的通信模式，以及对低精度算术的需求。例如，深度学习中传统研究的图像分类任务涉及二维、三通道的图像；相比之下，科学数据往往具有更多的通道，并/或扩展到三维、四维或更多维度。许多现实世界的问题涉及大型数据集，有时规模达到数 TB（太字节）级。高效处理此类大型且复杂的数据通常需要在跨节点扩展神经网络训练的同时，缓解 I/O 瓶颈。另一个重要挑战是在大规模训练网络时保持最终解决方案的准确性。仅仅通过增加批处理大小（`batch size`）来简单地扩展深度学习算法，可能会导致利用率降低或准确性下降。设计良好的网络架构并进行超参数调优至关重要，由于单次训练运行的计算需求，这项引入了额外的挑战。此外，在评估各种框架、深度学习算法和硬件平台组合的性能时也存在其他挑战：深度学习和 HPC 社区技术的快速发展使得这些结果难以复现。

本次工作讨会的目标是提供一个平台，让科学家和工程师能够交流该领域的最新进展和成果。我们希望工作讨会能够对此处列出的挑战进行富有见地的讨论，并促进跨机构的合作。最终目标是联合 HPC 和科学计算社区的人员，共同追求新方法，以加速超级计算机在科学发现中的应用。

我们在第五届超级计算深度学习工作讨会（DL2020）中接受了 7 篇经过评审的论文。这些论文涵盖了可扩展算法、深度学习性能建模与基准测试以及可扩展深度学习基础设施设计等主题。其他论文描述了物理和材料科学中基于深度学习的数学解决方案，以及天文学中的新应用，并通过主题建模对 COVID-19 研究文献进行问答。我们感谢作者和评审员对本次工作讨会的贡献。
