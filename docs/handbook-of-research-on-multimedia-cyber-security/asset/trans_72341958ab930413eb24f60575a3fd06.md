

# 接收端

在接收端，需要重建处理后的像素值。像素值以一维数组的格式接收。为了将其描绘为图片，必须将一维数组转换为二维数组。因此，使用数组调色板中的 `reshape array` 块，其中行和列维度均设为 256。这样便获得了二维表示。这些像素使用图形和声音调色板中的 `Flatten pixmap` 块进行扁平化处理。8位灰度图像的相应色表也作为输入给出。输出可以写入文件或使用指示器显示。结合上述讨论的模块，所提方法的发射端和接收端框图如图 1a 和图 1b 所示。

# 结果与讨论

软件仿真涉及输入 256×256 灰度图像的可观传输与接收，以及通过仿真 AWGN 噪声信道模型在接收端的正确重建。结合上述获得的参数值，软件仿真结果在 `LabVIEW` 平台上进行测试。所提方法包括在发射端按给定顺序串联低级加密模块：使用哈达马矩阵、BCH 编码器、置换器、符号映射、`IFFT` 块、循环前缀插入和加窗。上述模块使用 `LabVIEW` 中各种信号处理和射频通信调色板中的不同模块构建。获得的仿真结果在框图窗口和前面板窗口中以特写形式展示如下。

待传输的图像使用 `LabVIEW` 视觉工具包中的图像采集块获取，如图 3 所示。从输入文件路径读取图像，并使用 `IMAQ Image to Pixel` 块以二维数组形式获取每个像素值。这些像素值进一步处理并发送进行哈达马矩阵低级加密。同时，也输入了发射机属性参数，包括位数、子载波数、字到符号映射、D/A 速率、基频、循环前缀百分比和所选加窗方法类型。

经过哈达马矩阵和置换器的低级加密后，像素被转换为无符号 8 位二进制值，并拼接在一起形成输入比特流。然后，输入比特作为源编码部分进行霍夫曼编码，作为信道编码部分进行 BCH 编码。由于哈达马矩阵处理和信道编码的增加会增加带宽使用，因此使用无损压缩来抵消这种影响至关重要。霍夫曼编码是一种可变长编码方案。图 5 显示了源编码和信道编码数据的前面板。
