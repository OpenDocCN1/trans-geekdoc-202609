
# 用户画像与智能图像服务器关联

包含个人信息、账户数据、访问控制级别以及身份验证问题和答案的用户画像将链接到智能图像服务器。每个身份验证图像可能包含一个或多个“可点击对象”，这些对象代表用户的关键字或信息。例如，“蹦床”代表用户说她喜欢跳的关键字之一。对于其他用户，它可能代表他/她最讨厌的游戏；可能代表黑色；可能代表体操等。因此，图像可能具有以下特征：

*   图像可能包含一个或多个对象
*   每个可点击区域可能关联不同的关键字
*   每个对象一次隐式代表一个答案
*   对象只能点击一次
*   图像中可能存在一些诱饵对象以提高安全级别
*   每次呈现时，每个关键字将由不同的对象代表

系统选取图像的方式使得“预期”关键字仅存在于呈现的图像中。例如，如果预期答案是蹦床，而图像同时包含蹦床和“芭比”娃娃，则存在冲突。为避免冲突，系统可能会选择仅包含一个预期关键字的图像，或将代表“芭比”的区域设为“不可点击”。

如前所述，`IPAS` 密码是用户（客户端）和系统（云端服务器）共知的一条信息。该信息存储在数据库服务器中（关联至用户画像），用于身份验证过程。密码以隐式方式通过图像呈现给合法用户，这是 `IPAS` 身份验证的主要方法。呈现对象的隐式级别将根据访问控制级别而变化，该级别在用户与管理员（云系统）的注册阶段决定。

在某些情况下（如手机屏幕显示不清晰），用户可能难以处理 `IPAS` 身份验证过程中代表其密码的图像。此时，`IPAS` 提供辅助选项以继续身份验证过程。这些辅助选项是基于文本或基于令牌的身份验证方法，用户可在注册阶段将其作为可选方法选择。辅助身份验证选项不会影响 `IPAS` 的安全级别，用户的匿名级别也无变化。

若用户难以处理 `IPAS` 主要身份验证图像，可切换至基于文本的方法。此场景下，用户将使用设备键盘输入密码，而非点击图像上的对象。若密码尝试失败，用户可请求另一次尝试（涉及另一次身份验证请求）。用户以加密显式形式输入密码，该形式代表 `IPAS` 图像中的隐式对象。下一个密码与前一个不同，消除了因重放攻击或窥视黑客导致密码被复制或记录的可能性。因此，用户切换至 `IPAS` 辅助选项时，安全级别不受影响。

在基于令牌的辅助选项方法中（特别是数字形式的密码），用户可在需要时从 `IPAS` 主要方法切换至辅助方法。此场景不影响 `IPAS` 安全级别，且免疫任何外部或内部攻击。用户可使用 `OTP`（一次性密码）令牌，它代表用户在 `IPAS` 身份验证过程中的密码。该密码每次都会变化，将密码被复制或记录的可能性降至最低。如今，`OTP` 软令牌作为手机应用程序可用，有助于消除传统硬件令牌的额外成本。因此，`IPAS` 辅助身份验证选项安全且免疫外部和内部攻击。此外，辅助选项展示了 `IPAS` 作为灵活且用户友好的身份验证系统的动态特性。

结果，用户可在无法识别当前图像时请求另一图像，或随时切换至基于文本/令牌的方法。因此，`IPAS` 提供了灵活的身份验证环境，增强了方案的用户友好性，并提供了如上所述的高安全级别。

# IPAS 示例场景

针对每个关键字（密码），服务器可使用图像创建智能身份验证空间，将各用户针对特定关键字的答案隐式嵌入图像中。身份验证时，服务器可随机选取用户注册时选择的一个或多个关键字（关键字数量取决于请求的服务级别）。针对每个选定关键字，服务器可从身份验证空间随机选择一幅图像作为挑战呈现给用户。用户需使用手写笔或鼠标浏览图像并点击正确答案。例如，服务器可能呈现一幅地球图片。若悉尼是用户喜欢访问或已访问过的城市，他需点击澳大利亚。随后澳大利亚放大，用户需在地图上点击悉尼（如图 7 所示）。下一次若服务器选中相同关键字，呈现的场景可能不同。下一次服务器可能显示包含著名建筑和纪念碑的图像。用户需点击“悉尼歌剧院”以隐式传达答案。由于服务器每次使用不同场景且答案隐式给出，该系统免疫屏幕捕获攻击。此外，除服务器和合法用户外，对其他人答案可能模糊不清。例如，用户点击“歌剧院”可能意味着“用户喜欢聆听的音乐类型”，或代表其“出生地”、“当前居住地”等。

# IPAS 组件

大多数当前用于用户身份验证的方案在静态过程中运行（如密码或令牌），然而 `IPAS` 的灵活性根据所需操作的访问级别，为用户提供了身份验证过程的空间和选择。因此，用户可随时使用相同信息从基于图像的方法切换至基于文本的方法，详见下一小节。

## 智能基于图像的身份验证选项

基于图像的身份验证是 `IPAS` 的主要组件，用户的答案在身份验证过程中隐式呈现于图像中。系统将根据先前分阶段描述的请求访问级别选择图像的隐式级别。因此，用户需点击图像中代表其答案的正确对象以完成身份验证。随后，访问控制模块将允许用户执行所需操作和动作。

得益于 `IPAS` 的动态性和高灵活性，用户可在成功导航基于图像的方法时随时切换至基于文本的方法。此外，若用户在当前图像上遇到困难，可请求另一幅图像。
