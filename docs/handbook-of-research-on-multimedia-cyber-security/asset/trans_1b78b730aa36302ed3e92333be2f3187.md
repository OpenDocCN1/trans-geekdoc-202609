

# 利用平面内差值嵌入的整数变换

## 整数变换

整数变换也称为整数哈尔小波变换或 S 变换。整数变换满足可逆性（Tian, 2002）。其工作原理如下。对于一对 8 位灰度像素 `(x, y)`，整数变换由一对 `(m, d)` 给出。其中 `m` 表示整数平均值，`d` 表示差值。

`m` 和 `d` 的计算如下。

```
m = floor((x + y) / 2)  (1)
d = x - y               (2)
```

逆变换由下式给出

```
x = m + floor((d + 1) / 2)  (3)
y = m - floor(d / 2)        (4)
```

其中 `floor()` 表示向下取整运算，将数值舍入为最接近的整数。在整数变换中，差值 (`d`) 根据水印比特 (`b`) 进行修改，以将 `b` 隐藏到像素对中。可逆整数变换在 `(x, y)` 和 `(m, d)` 之间提供了一一对应关系。

此处 `(x, y)` 和 `(m, d)` 均为表示图像中像素的整数。

`(x, y)` 的取值范围为 `[0, 255]`。`(m, d)` 也应在同一范围 `[0, 255]` 内，以防止溢出和下溢。这意味着对于给定的像素对 `(x, y)`，`(m, d)` 应满足以下条件。

```
0 <= m + floor((d + 1) / 2) <= 255  (5)
0 <= m - floor(d / 2) <= 255        (6)
```

上述不等式等价于

```
-d - 1 <= 2m - 255 <= d     (7)
-d <= 2m - 255 <= d + 1     (8)
```

由此，可轻易得到以下条件。

```
|2m - 255| <= d             (9)
```

此处，秘密数据比特（水印）可通过扩展差值 (`d`) 来嵌入。扩展后的差值 (`d'`) 由下式获得

```
d' = 2 * d + b              (10)
```

扩展后的差值应满足溢出和下溢条件。因此，

```
|2m - 255| <= d'            (11)
```

若满足以下条件，则称 `d'` 为可扩展的

```
|2m - 255| <= 2 * d + b
```

其中 `b = {0, 1}` 表示水印（秘密信息）。在扩展这些差值时，整数平均值不进行扩展。因此，利用 `(m, d')` 通过公式 3 和 4 生成新的像素对。

由公式 10 可知，扩展后的差值由 2 的倍数之和给出。因此，扩展后的差值可重写为

```
d' = 2 * d + LSB(d')        (12)
```

其中 `LSB(d')` 返回整数 `d'` 的最低有效位。以下示例解释了公式 10 如何通过公式 12 重写。

考虑差值 `d = 4` 和水印 `b = 1`。使用公式 10，`d = 4` 的扩展过程如下。

由公式 10

```
d' = 2 * d + b              (13)
```

将 `d = 4` 和 `b = 1` 代入公式 13

```
d' = 2 * 4 + 1 = 9          (14)
```

现在，利用公式 12 从 `d'` 导出 `d'`，过程如下。

由公式 12

```
d' = 2 * d + LSB(d')        (15)
```

将 `d' = 9` 代入公式 15

```
9 = 2 * 4 + 1               (16)
```

因此，扩展后的差值 (`d'`) 被重写。首先检查差值是否可扩展。对于可扩展的差值，通过修改 LSB 进行扩展。在此修改后，可扩展差值可进一步改变以嵌入另一比特信息。这称为多层嵌入。扩展后的差值在整数平均值下进行改变。整数平均值在整数变换中不被改变。借助该整数平均值，在提取过程中可无损恢复原始像素值。因此，整数变换实现了可逆嵌入。

## 利用平面内差值嵌入的改进整数变换

Tian (2003) 提出了一种利用上述整数变换的 MLDHS。它通俗地称为 DE 方法。该方案工作流程如下。

1.  **步骤 1：** 从图像中的连续像素形成像素对，并利用整数变换转换该像素对。例如，考虑像素对 `(208, 203)`。根据上述整数变换：

    ```
    x = 208, y = 203
    平均值 (m) = floor((208 + 203) / 2) = 205
    差值 (d) = 208 - 203 = 5.
    ```

    现在，从像素对 `(x, y)` 获得 `(m, d)` 对。这称为正向整数变换。

2.  **步骤 2：** 扩展差值以在像素对 `(x, y)` 内嵌入水印比特 (`b)`。这是通过用水印比特 (`b`) 修改差值 (`d`) 来完成的。例如 `b = 1`，根据公式 10 获得修改后的差值 (`d'`) 如下：

    ```
    d' = 2 * d + b = 2 * 5 + 1 = 11.
    ```

3.  **步骤 3：** 利用修改后的差值生成含水印像素。应用逆整数变换获得修改后的像素对。对于步骤 1 和 2 中的示例：

    ```
    x' = m + floor((d' + 1) / 2) = 205 + (12 / 2) = 211.
    y' = m - floor(d' / 2) = 205 - (11 / 2) = 200.
    ```

    获得修改后的像素对 `(x' = 211, y' = 200)`。因此，水印被嵌入图像中。现在，将此 `(x', y')` 发送给接收方。

4.  **步骤 4：** 接收方收到 `(x', y')` 后，对 `x = x'` 和 `y = y'` 重复步骤 1。`x' = 211` 和 `y' = 200`：

    ```
    平均值 (m) = floor((211 + 200) / 2) = 205
    差值 (d) = 211 - 200 = 11.
    ```

5.  **步骤 5：** 读取 (`d`) 的最低有效位以获取水印信息。

    ```
    LSB(d) = LSB(11) = 1 → 此处提取出水印。
    ```

6.  **步骤 6：** 通过将 `d` 修改为 `d / 2` 来恢复原始像素对。

    ```
    d' = floor(d / 2) = floor(11 / 2) = 5.
    x = m + floor((d' + 1) / 2) = 205 + floor((5 + 1) / 2) = 208.
    y = m - floor(d' / 2) = 205 - floor(5 / 2) = 203.
    ```
