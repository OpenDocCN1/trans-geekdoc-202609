## Discussion

After these experiments, `DenseNet` has the highest accuracy of 0.953 mAP; `YOLOv3` has the highest accuracy of 96.29% by using the Weizmann dataset; `YOLOv3` has the highest mAP (0.8458) with the KTH dataset. For the Weizmann dataset, Jacking recognition has the highest precision and accuracy. Moreover, Boxing recognition using the KTH dataset has the highest precision within all experiments. However, in the Weizmann dataset, the precision and accuracy of Running and Skipping may not be robust; the same applies to Running and Jogging recognition in the KTH dataset. The reason for this low precision is that we are using video frames as the training dataset; these behaviors may have similarities. Thus, during the tests, the results were lower than expected.

Table 4 and Table 5 compare traditional machine learning methods, deep learning methods, and ensemble learning methods for human behavior recognition in two different public datasets. For `YOLOv3`, we achieved the highest accuracy of 96.29%; the Nearest Neighbor Classifier (`NNC`) has shown an accuracy of 95.6% by using the global spatiotemporal distributions of interest points (Bregonzio et al., 2009). Moreover, pertaining to the deep learning methods, they achieved real-time recognition; meanwhile, traditional methods required human behavior recognition frame by frame.

For the KTH dataset, `DenseNet` achieved 86.63% accuracy. With regard to 3D CNNs, they extract spatiotemporal features by performing 3D convolutions, which have the highest accuracy (90.2%) (Ji et al., 2013). Moreover, Ivan et al. proposed a histogram of gradients with a greedy matching method to recognize human behavior, which achieved an accuracy of 94.2% (Ivanov et al., 2000). Because some behaviors have similar local spatiotemporal events, it leads to misclassifications (Laptev et al., 2004). Moreover, Jagadeesh et al. implemented human behavior recognition with 92.48% accuracy by adopting SVM with HOG features (Jagadeesh et al., 2019). Furthermore, an ensemble learning-based method was proposed by using Weka 3 to combine these four models together, which gained more advanced results in human behavior recognition. In the experiments, we made use of two different ensemble learners to evaluate the results. For the Bagging classifier with random forest, it got 98.8% accuracy, which is 12.17% higher than single model recognition; by utilizing the AdaBoost classifier with random forest, it was able to have 98.71% accuracy with the KTH dataset. By combining AdaBoost and Bagging ensemble learners with random forest with the Weizmann dataset, the final accuracy has been achieved at 97.76%.
