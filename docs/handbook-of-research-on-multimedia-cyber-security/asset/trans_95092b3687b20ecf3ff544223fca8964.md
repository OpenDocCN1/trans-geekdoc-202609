

# 触摸屏输入动作作为行为生物特征认证

本文关注触摸屏输入动作作为一种行为生物特征认证方法，通过监控和分析用户如何与触摸屏移动设备交互来识别用户。触摸屏交互数据的监控可应用于用户能执行的最简单手势层面，即手指触摸屏幕然后抬起，这被称为**笔划**。笔划是用户将手指放在屏幕上然后释放时形成的轨迹（Eljetlawi, 2010）。根据记录这些动作的采样率，每个笔划由若干触摸动作组成。另一个监控层面是**会话层面**，可在其中记录和处理多个笔划作为一个整体，称为**触摸会话**。这不同于前述的笔划层面，后者将每个单独的笔划作为一个独立的信息单元进行处理。

主要研究集中在将笔划层面作为信息单元（Frank et al., 2013; Fierrez et al., 2018），这可简化系统实现；然而，它忽略了所有这些单个笔划之间的相关性，而这些相关性可能包含大量关于用户身份的重要信息。少数研究，如 O'connell 和 Walker (2017) 以及 Karnan 等人 (2011)，已引入会话层面认证，我们将在论文中应用该方法，同时结合笔划层面监控。先前的研究已针对上述问题提出不同方式的适用解决方案；因此，我们将利用这些方案提出一个更高效、更准确的解决方案。我们将使用现代触摸屏技术支持的单点触控笔划和多点触控笔划，因为依我们来看，多点触控笔划比单点触控笔划包含更多关于用户身份的重要信息，尤其是其手部几何特征。本文的主要贡献是提出一个基于行为生物特征的认证框架，该框架专注于从两个不同视角分析触摸屏输入动作；即我们提出两种不同的特征提取模型：笔划层面特征模型和会话层面特征模型。我们使用两种不同分类算法和两种不同特征选择方法的组合来比较这两个模型的性能，以决定哪个模型在认证过程中更准确、更有效。

本文为引入其贡献所采用的方法论可列举如下：

*   引入一个用户认证框架，作为概念验证，旨在考虑用户在触摸屏上的输入动作的会话层面信息，以获得更准确、更高效的认证方法。
*   在两个模型中使用人工神经网络和支持向量机作为分类算法，以选择最优分类算法。
*   通过搜索特征判别力和特征一致性，并根据特征重要性使用加权特征法，引入一种新的特征选择方法。
*   使用 PCA 作为特征选择的替代方法，以代替加权特征法，从而选择特征选择方法。
*   将单点触控笔划和多点触控笔划结合到一个模型中，以利用现代触摸屏的所有能力，并最大化认证系统的整体准确性和效率。

本文结构安排如下。除本节外，第 2 节重点介绍与行为生物特征相关的背景知识，特别是触摸屏输入行为，以帮助我们理解基于触摸屏的行为生物特征认证方案。还详细展示了该研究领域先前相关工作的贡献。第 3 节介绍一种从用户触摸动作原始数据中提取的最合适特征的选择方法，详细描述其背后的概念，然后展示我们如何开发该框架以使其灵活适应未来的改进。第 4 节展示构建和评估该认证框架所进行的实验阶段，并呈现我们为评估所提框架而进行的所有实验结果，分析这些结果以评估所提框架的性能。最后，第 5 节总结本论文，并给出未来工作的路线图特征。

# 生物特征认证

任何生物特征识别系统（见图 1）都必然通过检查某人已注册的物理和/或行为特征及其提交的相应查询特征，来自动识别该人。理想的生物特征应具有“零”误接纳率和误拒率，并应满足一些特性，如普遍性、唯一性、永久性、可接受性，且应能抵御可能的攻击。图 1 描绘了包含四个组件的生物特征系统框图，定义如下（Jain et al., 2004）：

*   **数据源**：该模块处理从个体采集的生物特征数据。它包括硬件和软件。还可能包含一个额外的“质量检查器”组件以确保数据质量。
*   **特征提取器**：该模块处理从采集的生物特征样本中提取判别性特征，以便在数据库中描绘最相关的用户信息。
*   **数据库**：该模块处理从用户数据生成的生物特征模板的存储和管理。
*   **匹配器/比较器**：该模块将声称的或查询的模式与先前存储的模式进行匹配，并决定接受/拒绝。对于验证，它执行一对一匹配；对于识别，它将输入查询模式与所有类别的所有存储模式进行匹配（1:N），随后根据获得的最高分数识别用户。

生物特征模态的选择取决于除识别性能外的各种因素。文献考虑了确定这些特征适用性的七个因素，如下所述（Jain et al., 2011）：

1.  **普遍性**：每个用户都需要具备该生物特征模态。该因素有助于确定生物特征识别系统的注册失败率（FTER）。
2.  **唯一性**：给定的模态在一组人群中应在不同个体间有足够的差异。
3.  **一致性**：给定的模态应在一定时间段内保持一致。
4.  **可测量性**：在不给用户造成任何不便的前提下，使用最佳设备采集和数字化生物特征模态的可能性。
5.  **性能**：除了识别准确性，生物特征系统的吞吐量也应能应对应用施加的约束。
6.  **可接受性**：它反映了用户向系统提供其特征的容易程度和舒适度。
7.  **规避性**：它指复制、模仿或修改其他参与者的模态以获取系统非法访问权限的容易程度。

生理生物特征通常需要一种获取方法，如扫描仪或摄像头，以及一种将其从详细扫描转换为简洁特征向量的方法，该向量代表最显著（即最独特）的部分。这些生物特征各有优劣，选择使用哪种取决于将部署它的应用程序的需求。生理生物特征的例子包括指纹、掌纹、虹膜和视网膜扫描以及人脸识别。
