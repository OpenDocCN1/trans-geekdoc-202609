

# 图形密码系统综述

## Awase-E 系统

一种称为 Awase-E 的图像密码系统，允许用户使用喜欢的图像作为“通行图像”来替代文本密码进行身份验证。Awase-E 认证框架包含两个阶段：图像注册界面和通知界面。

要注册图像，用户需通过电子邮件将图像及几次关键点击发送给系统，随后从其他图像中选择通行图像。通知界面为用户提供触发器以实际处理威胁，会通知用户与认证过程相关的各类事件发生情况。例如，Awase-E 会向已注册照片的用户发送包含 URL（统一资源定位符）的电子邮件。该 URL 链接的网页包含用户刚注册的照片，用户可通过网页确认注册的照片。

尽管 Awase-E 系统具有较高的易用性，但由于图像存储空间需求大且无法抵御重放攻击，实现难度较大。此外，用户倾向于选择知名图像（或与用户有关联的图像，如子女、配偶或访问过的地点等），这可能导致猜测攻击。

Dirik 等人（2007）研究了基于识别的方案，得出结论：即使过了一两个月，用户仍能以 90% 的准确率记住其图形密码。该研究支持“人类对图像的记忆优于文本”这一理论。此外，商业系统 Passfaces 使用人脸图像。研究表明，用户的密码选择受种族和性别影响，这使得 Passfaces 的密码具有一定可预测性。

虽然基于识别的图形密码易于记忆，提高了易用性，但并不完全安全。Wei-Chi 和 Maw-Jinn（2005）指出，为提供合理大的密码空间，认证需要多轮图像识别，这很繁琐。此外，由于使用固定图像作为密码，基于识别的系统容易受到重放攻击和鼠标追踪攻击。因此，我们在下一章描述的拟议系统中考虑了这些缺陷，该系统也克服了基于回忆方案的问题。

## 基于回忆的系统

在基于回忆的系统中，用户需重现注册阶段创建或选择的内容。基于回忆的方案大致可分为两类：纯回忆技术和提示回忆技术。

### 纯回忆技术

此方法要求用户在无任何系统帮助或提示的情况下重现密码。Draw-A-Secret（DAS）技术、网格选择和 Passdoodle 是常见的纯回忆技术示例。

Towhidi 等人（2009）提出了 DAS（Draw-A-Secret）方案，其中密码是绘制在大小为 `G * G` 的二维网格上的形状（如图 1 所示）。网格中的每个单元格由不同的矩形坐标 `(x, y)` 表示。触摸网格的值按绘制的时间顺序存储。如果按相同的注册序列穿过确切坐标，则通过身份验证。与其他纯回忆技术一样，DAS 存在许多缺陷。Birget 和 Dawei（2006）的调查表明，大多数用户会忘记笔画顺序，且记忆文本密码比 DAS 更容易。此外，用户选择的密码容易受到图形字典攻击和重放攻击。

Thorpe 和 Van Oorschot 提出了网格选择技术（Renaud，2009 引用），旨在增强 DAS 的密码空间。他们的研究显示笔画数对 DAS 密码空间的影响：对于固定密码长度，笔画减少会导致密码空间显著减小。为提高 DAS 安全级别，他们建议采用“网格选择”技术：初始选择网格较大，显示一个细粒度网格供用户选择绘图网格，即一个用于放大的矩形区域，用户可在其中输入密码（如图 2 所示）。该技术增加了 DAS 的密码空间，从而提高了安全级别。但实际上，该技术仅改善了 DAS 的密码空间，仍保留上述 DAS 的弱点和缺陷。

Passdoodle（Birget 和 Dawei，2006 讨论）是手绘图形或文本的图形密码，通常用触控笔在触摸屏上绘制（如图 3 所示）。研究表明，用户识别完整涂鸦密码的准确度与文本密码相当。不幸的是，Passdoodle 方案存在许多缺陷。Renaud（2009）提到，用户会被其他用户绘制的涂鸦吸引，常输入他人密码仅为绘制不同于自己的涂鸦。作者得出结论：Passdoodle 方案易受猜测、间谍软件、键盘记录器和肩窥攻击。

### 提示回忆技术

此技术中，系统提供提示帮助用户高准确度地重现密码。提示以图像中的热点（区域）形式呈现。用户需选择部分区域注册为密码，登录时按相同顺序选择相同区域。用户必须记住“选定的点击点”并保密。实现方式包括 Blonder 算法和 PassPoint 方案。

1996 年，Blonder 算法设计了一种方法：在视觉显示器上向用户展示预定图像，用户需按特定顺序“点击”图像上的预定义位置以通过身份验证（如图 4 所示）。该方法后经修改作为 Passpoint 呈现（Dawei 等人，2006；Birget 等人，2005）。

2005 年，PassPoint 方案被创建，类似于 Blonder 方案但克服了其主要局限。在 PassPoint 中，图像可以是包含许多可点击区域的任意照片或绘画（如图 5 所示）。这将增加 PassPoint 方案的密码空间，进而提高安全级别。另一区别在于没有像 Blonder 算法那样具有清晰边界的预定义点击区域。用户密码可包含图像中任意选定的点序列，提高了该方案的易用性。

PassPoint 系统拥有巨大的密码空间，与其他类似系统相比提高了安全级别。例如，图像上的五或六个点击点可产生的密码数量超过标准 26 字母表的 8 字符文本密码。为增强安全性，PassPoint 系统以哈希（加密）形式在密码文件中存储图像密码。此外，哈希不允许近似匹配：两个几乎相同但不完全相同的密码将产生不同的哈希值。为通过身份验证，用户必须点击接近选定点的位置，在距通行点某个测量容差距离内。
