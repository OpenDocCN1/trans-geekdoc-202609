

# 实验结果

经过六层 CNN 后，紧接着一个名为 `flatten[dropout]` 的层。我们展开 CNN 的输出并添加 dropout 操作以克服过拟合问题。然后，`flatten[dropout]` 的结果将被导入 `cls[output]` 和 `loc[output]` 层进行火焰分类和定位。`cls[output]` 和 `loc[output]` 都等同于一个两层 MLP，由两个子层组成。我们在输出层使用非线性激活函数。`predict` 层通过处理 `cls[output]` 和 `loc[output]` 层的输出给出最终输出，最终输出呈现为 `[classID, conf, x[min], x[max], y[min], y[max]]`，其中 `classID` 代表对象所属类别的标签，`conf` 指属于该类别的概率。输出的其余部分 `[x[min], x[max], y[min], y[max]]` 是边界框的坐标。

分类是我们实验中最关键的步骤，直接影响火焰识别的结果。在本章中，我们研究了六类火焰，包括营火、蜡烛火、燃气火、喷枪火、燃气罐火和酒精壁炉火，如 Figure 2 所示。当火焰出现在我们的摄像头前时，我们的模型将自动检测区域并识别这五类火焰之一。我们将火焰限制在带有火焰类别名称的边界框内，并使用分类准确率。卷积神经网络有一种独特的方式将视频帧的颜色层转换为数字矩阵。CNN 模型的结果与使用颜色模型的结果一样好，边界框定位的准确率相当高。这些图片中显示的、与火焰具有非常相似颜色和纹理的背景，并未出现在我们检测到的边界框中。我们用六组实验的结果展示了最高准确率（98.6%）。

在运行神经网络之前，我们不需要从图像中提取特征。因此，与使用机器学习的传统目标识别相比，CNN 具有显著的性能优势。我们看到火焰几乎位于边界框的中心。不同燃烧材料的火焰都位于边界框内，除了蜡烛火焰的结果。幸运的是，从 Figure 2 所示的最后一张图像中，我们发现 CNN 并未将墙上蜡烛火焰的反射识别为有意义的情况。

关于火焰检测的定位问题，我们将其视为一般回归问题。定位损失函数中的预测位置 `f[loc]` 和期望位置 `b` 也适用于边界框。因此，我们为模型尝试了 Table 3 所示的四组参数，其中 `MFD2` 等同于 `MFD1` 的线性变换，区别在于 `MFD2` 将值归一化到区间 `[0, 1]` 内。`MFD3` 和 `MFD4` 旨在改善模型对小目标的定位结果。因为 `MFD1` 和 `MFD2` 基于定位误差的绝对测量，所以大目标和小目标之间的偏差被同等对待。例如，10 像素的偏差对于大目标可能很小，但对于小目标却可能相当大。

总的来说，`MFD 1` 模型在我们的火焰识别中表现最好。卓越的准确率不仅体现在识别上，也体现在定位上，无论目标大小。在我们的比较中，`YOLO` 对小目标表现不佳，因为它在一个网格中预测两个框且只归属一类。由于损失函数的选择，定位误差是影响检测效率的主要原因，特别是在处理过大或过小目标时。由于结构复杂，`R-FCN` 在火焰识别方面表现优于 `YOLO`。

# 结论

在本章中，我们使用深度学习中的卷积神经网络训练了一个有价值的模型，用于自动识别和检测火焰的发生。基于我们自己的数据集，介绍并考察了卷积神经网络的各种要素和相关关键功能。

在实验中，我们设计了一个相对简化的神经网络来实现火焰识别的目标。我们收集了六种类型的火焰来扩充数据集。最终，我们获得了 96% 的平均准确率。此外，我们检测了火焰区域并评估了相应的准确率。我们发现，当火焰占据视频帧的很大一部分时，识别准确率将显著提高。

未来，我们将致力于多火焰的检测和识别。此外，森林火灾、建筑火灾等更复杂的火焰将被加入项目。由于真实场景中复杂多变的环境，将会有更多不可控因素可能影响我们的火焰识别。未来，视频源的动态特性（如白炽灯、荧光灯等）将被纳入考虑。
