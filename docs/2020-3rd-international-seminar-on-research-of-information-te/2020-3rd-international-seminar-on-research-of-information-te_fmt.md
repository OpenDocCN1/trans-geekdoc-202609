## I. 引言

森林火灾是一个国际性问题，影响着环境、基础设施和人类生活。文献中有各种使用建模方法的技术，可以分为三大类：基于物理的、基于统计的、基于方法的方法，参见 [1]。众所周知，文献中使用的变量基于卫星数据、火灾相关数据和气象数据（如天气和气象数据，参见 [2]）。

许多机器和数据方法引起了许多研究者的关注。例如，[2] 研究了森林火灾算法，即回归 (`MR`)、决策树 (`DT`)、神经网络 (`NN`) 和支持向量机 (`SVM`)，利用气象和天气数据对森林火灾发生预测进行建模。[3] 使用聚类、归一化对数据进行预处理，并将分类方法应用于归一化后的数据。他们发现模糊 C 均值（Fuzzy-Cmeans）与余弦距离、归一化以及反向传播神经网络（带有一个隐藏层）分类的结合，与其他分类方法 (`SVM`, `K-Nearest`) 相比提供了相对准确的预测。

## II. 方法

### A. 分类方法

如前，我们考虑了各种经典机器学习方法，如支持向量机 (`SVM`)、K-近邻 (`KNN`)、逻辑回归 (`logit`)、决策树 (`DT`) 和朴素贝叶斯 (`NB`)。这里我们只提供这些方法描述的简要总结，因为所有这些方法已经在各种标准机器学习书中被考虑过。更多细节参见 [7]。

#### 1) 支持向量机

支持向量机 (`SVM`) 是一种经常用于分类的监督学习算法。`SVM` 算法将在 N-1 维空间中寻找最优超平面（N 表示用于分类数据的特征/变量数量）。通过设置一个优化问题来获取间隔（`margin`），即不同类别数据点之间的最大距离。

#### 2) K-近邻 (`KNN`)

##### 1. 欧几里距离

```
d(x, y) = \sqrt{\sum_{i=1}^n(x_i - y_i)^2}
```

##### a) 线性可分 SVM

线性数据的超平面和支持向量公式：

```
g(x) = w^Tx + w_o
```

假设为：

```
g(x) \geq -1, x \in C 1 类
```

且 `g(x) \leq 0 x` 为 2 类

为每个支持向量计算 `z`：

```
z_1 = \frac{|g(x)|}{\|w\|} x \in C 1 类
z_2 = \frac{|g(x)|}{\|w\|} x \in C 2 类
```

##### 2. 曼哈顿

```
d(x, y) = \sum_{i=1}^n|x_i - y_i|
```

##### 3. 明可斯基

```
d(x, y) = \sum_{i=1}^n|x_i - y_i|^{1/q}
```

更多细节参见 [9]。

则间隔 `z` 为：

```
z = |\frac{1}{n_1}\sum z_1 - \frac{1}{n_2}\sum z_2|
```

其中：`w` = 权重

最小化 `w` 是用于最大化分离的非线性优化函数。通过 `KKT` (Karush-Kuhn-Tucker) 条件完成 `w` 的最小化：

```
w = \sum \lambda_i y_i
```

`KKT` (Karush-Kuhn-Tucker) 条件：

```
sum \lambda_i y_i = 0
```

##### b) 非线性可分 SVM

非线性 `SVM` 可将数据映射到高维。使用核技巧将数据映射到高维，使其变为线性可分。`SVM` 使用了以下 2 种：

1. 径基函数 (`RBF`)

```
k(z, x) = \exp(-\frac{\|x-z\|^2}{\sigma^2})
```

当变量数小于观测数时使用。

2. 多项式核

```
k(z, x) = (x^Tx + c)^d
```

当观测数很大时使用。

#### 3) 朴素贝叶斯

朴素贝叶斯分类器是概率方法之一，由贝斯定理推导，贝叶斯可以计算后概率 `P(c|x)` 和 `P(c)`。贝斯的公式：

```
P(c|x) = \frac{P(x|c)P(c)}{P(x)}
```

```
P(x) = P(x_1|c)P(x_2|c)...P(x_n|c)
```

其中：

`P(x)` 是给定属性（目标）的后验概率。

`P(c)` 是特定类的先验概率。

`P(x|c)` 是给定特定类的似然。

贝斯算法步骤：

1. 将数据集转换为频率表。
2. 计算经验概率并定义似然表。
3. 方程用于以获取每个类别的后验概率。

#### 4) 逻辑回归

逻辑回归是流行的分类方法之一。可以将数据分为两个或多个类。逻辑回归回归步骤：

逻辑回归定义为：

$h_0(x) = \theta^Tx$

线性函数基本上作为另一个函数 `g` 的输入：

$h(x) = g(h_0(x)) \text{ 其中 } h_0(x) \le 1$

函数 `g` 是逻辑或 `sigmoid` 函数

$g(z) = \frac{1}{1+e^{-z}}$

`Sigmoid` 曲线可以是正或负。如果输出落在 0 和 1 之间，则属于正类的概率。

##### B. 逻辑回归决策边界

定义损失来衡量算法性能，我们使用的表示为：

$h_0(x) = g(\theta^Tx)$

`C` 定义逻辑回归参数

$J(\theta) = \sum (-x \log(h) - (1-x) \log(1-h))$

定义函数后，我们的主要目标是最小化该函数。我们使用的函数是：

$\frac{\partial j}{\partial \theta} = x - g(\theta^Tx)$

更多细节参见 [11]。

#### 5) 决策树

决策树使用监督学习算法解决分类问题。可以使用以下步骤：

1. 使用完整数据集作为树的起点（根节点）。
2. 使用属性选择 (`ASM`) 选择最佳属性。该指标适用于寻找每个节点和子节点。`ASM` 的指标有：

   **A. 信息增益**

   `DT` 将使用信息增益 (`IG`) 最大的节点并进行分裂。`IG` 可以计算为：

   信息增益

   $Entropy(S) = -Weighted Average \times Entropy(\text{each feature})$

   `S` 的熵可以计算为：

   $Entropy(S) = -\sum p_i \log p_i$

   **B. 基尼指数** 通常称为 `Gini` 指数，其定义为：

   Gini Index = $1 - \sum p_i^2$

3. 根据最佳属性在数据集子集中使用根节点并生成决策树。迭代更新直到到达最终叶节点/节点，树无法进一步分类。
4. 为了防止过拟合，可以对树的大小进行剪枝。剪枝可以使用代价复杂度剪枝或误差剪枝的方法。

更多细节参见 [12]。

### B. 集成分类：Adaboost 方法

自适应提升 (`Adaptive Boosting`) 用于 `AdaBoost`，这是一种机器学习集成方法。使用 `AdaBoost`，可以通过组合被称为提升分类器的加权和来提高“弱学习器”的性能，其具有

$F(x) = \sum f(x)$

其中 `x` 是接受任务作为输入并返回 `x` 的类的学习器。`AdaBoost` 有变体，本研究使用的算法是使用多分类指数损失函数的自适应阶段 (`SAMME`) `AdaBoost`。
