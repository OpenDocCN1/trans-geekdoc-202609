# 7.5.1. Local differential privacy versus global differential privacy (UI Hassan et al. 2020)

Consider a scenario where a researcher requests some kind of data for analysis to multiple data generators. In the local private system, each data generator will generate raw data, add noise to it and send data to the researcher. While in global privacy system, each data generator will firstly send data to a trusted curator, who will aggregate the data (or group the data), then add noise to it and provide it to the researcher.
