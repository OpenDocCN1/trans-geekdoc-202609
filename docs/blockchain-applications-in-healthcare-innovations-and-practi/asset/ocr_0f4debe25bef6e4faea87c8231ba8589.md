+   - Syntactic interoperability: the appropriate process that permits one EHR format system to associate with additional system.
+   - Semantic interoperability: the process of data sharing with appropriate data that has to be translated in between distinct systems at the data field level.
+   - Interoperability across domains: when we consider distinct organizations that cooperate to confirm protected and appropriate data communication as the effective data that is being used between various organizations and individuals.

# 6.3.3. A distributed network

The architecture being implemented in Blockchain is a peer-to-peer (P2P) architecture that consists of distinct nodes made up of various network participants, where each of the associates in the network stores a duplicate copy of the Blockchain and provides for cooperative procedures to further validate and certify all of the digital transactions in the network.
