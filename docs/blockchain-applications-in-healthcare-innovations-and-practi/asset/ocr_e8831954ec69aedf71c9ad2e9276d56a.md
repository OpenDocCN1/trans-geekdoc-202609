# ## 3.5.1. Data sharing using Gem Health Network

As discussed earlier, the healthcare sector contains the records of patients and stores them in a centralized database, which can lead to issues such as data security and interoperability. If a patient needs the records when going through a specialized treatment either in another hospital, interstate or overseas, then the sharing of data becomes a problem. Every time a person sees another doctor, there is a need to form a new set of records and update several existing records, changing the communication protocols between the doctors, and also there is IT interference which is very time-consuming. Hence, there has been a solution given out for the problem by the Gem as Health Network that uses Ethereum Blockchain Technology and creates a shared network infrastructure. This network helps different professionals in the healthcare sector to access the same information and records of the patients, unlike the centralized database. Access to the latest treatment information (which is transparent and relevant) is only given to the authorized users. This helps in reducing the risk of neglecting a person’s health issues due to misinformation or outdated health records.
