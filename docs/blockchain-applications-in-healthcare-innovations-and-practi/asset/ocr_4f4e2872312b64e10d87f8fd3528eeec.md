# 9.3.2.2. Y model

Capretz et al. (2005) proposed the Y model. This model is based on a component-based development approach, as shown in Figure 9.10. The model's Y form makes it easier to iterate and overlap in appropriate places. Domain engineering, frame working, assembly, archiving, system analysis, design, implementation, testing, deployment and maintenance are some of the anticipated phases. This model supports change instability and the reusability concept for developing any software product. This model mainly focuses on software reusability during component-based development and emphasizes reusability when software is developed, evolves and desired reusable components are built on the assumption.
