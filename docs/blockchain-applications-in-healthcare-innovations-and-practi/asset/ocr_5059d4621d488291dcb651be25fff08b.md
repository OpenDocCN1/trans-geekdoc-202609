The Blockchain architecture, shown in Figure 1.2, consists of two main blocks, the transaction block and the maintenance block. The transaction block, which consists of several blocks through different network sources, tends to transmit the data towards the Blockchain in different time slots. Each time a new transaction occurs, it is transmitted to the network of computers which are connected worldwide. The network then checks and confirms the validity of the transaction that has occurred and thus allows it to become clustered within the block. All of these blocks are then chained with each other, and the entire transaction is said to be completed.
