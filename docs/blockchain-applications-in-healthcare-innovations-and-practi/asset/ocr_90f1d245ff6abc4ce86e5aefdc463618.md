**1) Requirement analysis:** the first phase of developing software is the requirement analysis phase, in which developers analyze the need for software products according to the client. This phase collects detailed information about the desired product from the client and analyzes its functionality, development cost, technical issues, etc. After analyzing the desired product requirements, the developer prepares a document for the software product, which is called a software requirements specification (SRS).

**2) Design:** in this phase, the developer designs the basic structural framework of the software system. Developers decide what architecture and programming language are best for product development, which technology should be used, the constraints of the project, and how much time and budget should be used for developing software. This phase also decides how different modules of architecture communicate among them.

**3) Implementation:** in the implementation phase, developers actually start the development process according to SRS. This phase is also known as the building phase. In this phase, the developer follows all the standard guidelines of coding.

**4) Testing:** this phase is the last phase of SDLC before delivering the final software product to the customer. In this phase, the developer tests the final product, tracks where the bug is present in the implementation code and reports it. The testing phase confirms whether the final product meets the customer’s requirement.

**5) Deployment:** once the software system is ready, the developer deploys this product for the user. In this phase, the developer releases the tested software products in the appropriate market. The developer releases their software products in a limited segment and analyzes their acceptance rate. After analyzing the acceptance rate, the product is released in a particular market based on the product’s response.

In this chapter, we have given a brief comparative study of various software development life-cycle models and divided the software development life-cycle model into two categories. The first one is a traditional software development model, and the second one is a modern software development model based on CBSE.
