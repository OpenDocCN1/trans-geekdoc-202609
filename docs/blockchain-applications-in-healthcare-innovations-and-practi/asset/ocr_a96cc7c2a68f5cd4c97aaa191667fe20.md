# 9.1. Introduction

Today, software is being used everywhere, such as in the education, health, transportation, banking, sports and communication sectors etc. Software is required to operate computers, airplanes, mobiles, TVs, cars and even children’s toys. It has a great impact on our daily lives and society. It supports comfortable living, along with monitoring facilities. In recent years, the healthcare sector has grown rapidly and has started to use software technology. Software technology has ensured that digitalized records are more effectively accessible when needed. The appropriate use of medical software will prove to be a boon for the health industry. It provides better accessibility for patient records, easy collaboration between physicians and easy to track patient health records, which all contribute to the best treatment (Katuwal et al. 2018; Ullah et al. 2020). Therefore, the effect of these applications is to shorten the patient’s treatment time, save money and effort, resolve the problem of unnecessary visits, and maintain and update the patient’s medical history. However, implementing healthcare software faces various challenges, such as how to choose better software methodology, how to incorporate user requirements into the design, how to trust in the medical software, how to easily adopt changes in technologies and culture, and also how to fix security issues. Healthcare solutions provide different types of software services, such as electronic health record services, practice management software, hospital management systems, billing software, lab information management software, etc., and tries to fulfill patient needs. But all of these software services have not increased the trust and transparency between the patient and the physician.

Software engineering methodologies play an important role in building a large and complex healthcare application. Software engineering can be defined as the study of the software process, principles and methodology applied in any real scenario of software development (Lalband et al. 2019). It helps to reduce the complexity of large software development, minimize software cost, deliver on time, handle bugs, and fulfill user expectations and needs. A proper software model (known as a software development life-cycle model) plays a vital role in developing software. Effective software models in software engineering help to build, design, develop, test, maintain and evolve any software systematically. It is a framework that helps to pre-plan. The software industry that tells us how to create a software product. Software development life-cycle (SDLC) is a group of various phases that helps us to understand the process of building software. It helps the developer to understand project context and user requirements. Hence, the project’s success always requires the best SDLC model according to its needs. An effective SDLC model provides a good software project within a certain timeframe, at lower cost, with less effort, without going over budget.
