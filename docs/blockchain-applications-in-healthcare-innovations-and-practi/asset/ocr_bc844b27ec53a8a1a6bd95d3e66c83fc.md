# 9.3.2.5. An improved model

Irshad and Noor proposed this model in 2012 (Khan and Khan 2012). In this model, the component development life-cycle and component-based system development life-cycle work in parallel, as shown in Figure 9.13. In this model, the authors discussed some issues related to component-based development and tried to reduce this issue by merging the traditional software development life-cycle model and component-based software development life-cycle model. This model helps us to resolve the problem related to unsatisfied requirements, repository management and the component’s version handling.
