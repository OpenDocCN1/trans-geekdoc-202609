Many research organizations are trying to develop a software system with the latest technology to increase our trust and secure data exchanges. Blockchain technology is a system that has the above features. A Blockchain is defined as a distributed digital ledger. It contains several blocks. These blocks are interlinked by hash cryptography in a peer-to-peer network. Every block of the Blockchain contains a block number, time stamp, nonce, data in the form of Merkle root and hash of the previous block, as shown in Figure 9.2. Every block is immutable, so there is no possibility of malicious attacks in the future. This technology was firstly introduced by Haber and Stornetta in 1991, and the first application was introduced by Satoshi Nakamoto in 2008 in the form of cryptocurrency for peer-to-peer transactions, known as Bitcoin (Nakamoto 2009). In Blockchain, data can be stored as a block that contains any type of data such as text, video and any kind of transaction. When a new block wants to join this Blockchain, its information is broadcast over the entire peer network, where miners are ready to mine this new block. After mining, a valid block is added to the Blockchain. Each Blockchain contains a set of rules known as a consensus algorithm (PoW, PoS). With the help of a consensus algorithm, the miners validate the new block and decide which block is added to or discarded from the Blockchain. This technology is becoming more popular because of its features, which include security, decentralization, immutability and transparency. Blockchain has the potential to solve many problems related to healthcare applications, such as a lack of disability of transition, trust and security for the patient record.
