After implementing the component as a block, the next phase is the verification and testing phase. In this phase, the developer mines the newly created block by using a consensus algorithm. Mining of a block is a process to verify a new block (component). The developer uses a consensus algorithm called the proof of work that is maintained by all participants for the verification and validation of blocks. A consensus algorithm is used to select a leader (miner), who will decide the content of the next block. After verification, the new block is added to the Blockchain.
