# 9.3. Software development models

A software development process generally requires a framework that is used to analyze, plan, control and manage the process of software development. This framework is known as a software development life-cycle model (SDLC). An SDLC model is a systematic process for developing and designing a project from the beginning stage to completion (McMurtrey et al. 2013; Kneuper et al. 2017). A good software developer always chooses the best SDLC model based on the project context and user requirements for developing software. It provides a sequence of activities that helps to process, develop and maintain software products with improved quality and reliability. Different software life-cycle models may suit a project based on the user’s requirement, cost, development time and project risks. In this chapter, we have discussed a comparative study of traditional software development life-cycle models, as well as modern software development life-cycle models based on component-based development. Traditional models do not support rapid changes in the requirements. They only focus on documentation rather than reliability or trust. In comparison, modern models handle these unwanted changes in the requirements successfully. They produce high-quality software in less time and maintain reliability and trust.
