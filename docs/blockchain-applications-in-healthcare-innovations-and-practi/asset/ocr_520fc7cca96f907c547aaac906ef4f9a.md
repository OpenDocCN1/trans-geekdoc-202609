This model is based on the V model, in which two V models are joined and work together, as shown in Figure 9 111. The first V model depicts the component life-cycle, while the second depicts the system life-cycle (Lau et al. 2011). The model is divided into two phases, one for component design and the other for component deployment. In the design phase, according to the domain engineering, software components are identified, designed and implemented. After building the component, it is stored in a repository, whereas in the deployment phase, the product is constructed and deployed using these already developed components.

# 9.3.2.4. X model

Tomar and Gill (2010) proposed the X model, which depicts how reusable components are used in complex and large-scale software projects. This model mainly focuses on reusability for developing software through the use of reusable components. As illustrated in Figure 9.12, the X model's life-cycle is divided into four sub-cycles: component-based software developer, development for reuse, development after modification and development without modification. This model supports the overlapping of different phases and increased complexity for developing any software.
