People get confused because they use both the words interchangeably and consider both means data protection; however, the truth is that security and privacy are different yet have similar components which creates ambiguity.

Information security is about preservation of confidentiality, integrity and availability. The meaning of confidentiality is to keep data safe from unauthorized access, integrity means preserving the accuracy of data and keeping it reliable, and availability means that data should be accessible by authorized users/services whenever required. However, privacy starts from the control of collection of personal data, the control of use of personal data and goes as far as the control of destruction/disposal of data.

It is important to understand that security can be achieved without privacy, but privacy cannot be achieved without security. Security controls focus on all information while privacy controls focus on PII, i.e. personally identifiable information, personal data or sensitive personal data.

To keep it simple, security preserves integrity, confidentiality and availability of data while privacy preserves the protection of privacy rights with respect to the processing of data and data anonymity.

# 7.3.1. Privacy in Blockchain

Before getting into privacy in Blockchain, let us recall some basic terminologies. A distributed ledger is a kind of database which is spread across various computer devices usually in different geographical locations. Distributed ledger technology is the name given to any technology which helps in storing and updating the distributed ledger (Belotti et al. 2019; Ul Hassan et al. 2020). Blockchain is a distributed ledger system that allows for the sharing of a validated ledger of transactions which are kept in blocks and connected by a chain. The genesis block is the very first block on the Blockchain, and all subsequent blocks are added sequentially onto it. Privacy in Blockchain is achieved by three key principles, i.e. cryptography, decentralization and consensus algorithm (Tian et al. 2019; Sharma and Balamurugan 2020):

**– Cryptography:** hashing is a well-known cryptography terminology; hashing is a mathematical function that creates a value of specific size for any data in this case block, and if there is any change in this data (block), the hash value will change. This means that the hash value assures the integrity of data (block). Each block on a Blockchain contains the hash of the previous block, and along with the hash, each block also consists of a timestamp, a nonce and a record, i.e. transaction data. In the term Blockchain, chain is the hash value because it is a reference to the prior block
