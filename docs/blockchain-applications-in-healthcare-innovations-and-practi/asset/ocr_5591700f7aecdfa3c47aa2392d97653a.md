# 8.2. Use of AI in healthcare systems

EHRs have supported the healthcare industry’s digitalization, but the process has resulted in a plethora of challenges, including cognitive fatigue, repetitive paperwork and user burnout. Artificial intelligence has been used by EHR developers to create interfaces that are more intuitive and automate some of the repetitive tasks that previously took up a lot of a user’s time.
