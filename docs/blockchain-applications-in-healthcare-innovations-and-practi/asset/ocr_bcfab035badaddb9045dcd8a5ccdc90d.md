# # Component-based Healthcare Software Application Using Blockchain

Software technology plays an important role in our lifestyles. This technology affects our activities in many areas such as education, the car industry, administration, games, healthcare, etc. The primary aim of the software industry is to produce a high-quality and low-cost software system in good time. To achieve this goal, many software companies follow the component-based software engineering approach to develop software rather than traditional approaches. The component-based approach is an emerging technology for software development. Its main aim is to develop a software system by selecting the appropriate software components from a repository as per the requirement specification and assemble all of the components with a well-defined software architecture. Healthcare software systems are gaining attention from software developers as they are being increasingly used in day-to-day life. In the present scenario, monitoring our health has become a part of many people’s lifestyles. This means that customers need to search for reliable and secure healthcare software. The main challenges of health applications are to manage data safely. Hence, we need a technology that provides confidentially and security for healthcare information. Blockchain is one of the technologies that can be used to secure our data and increase our trust in the application. Further, it is becoming popular because of its features, which include security, decentralization, immutability and transparency. Many healthcare standards such as life-cycle models and design methodologies give the best software practices and design principles to secure our application. In this chapter, we discuss the life-cycles of software development through the component-based software engineering approach. Further, we discuss how to create a Blockchain-based repository that stores software component and also discuss how Blockchain technology helps to secure our data in healthcare applications. The proposed software development life-cycle model ensures the security of user data and also improves the quality of healthcare applications.
