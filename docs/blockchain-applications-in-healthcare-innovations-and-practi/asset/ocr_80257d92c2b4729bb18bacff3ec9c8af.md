# 6.3.1. Sharing of data

Hospitals, clinics, laboratories and other healthcare facilities rely on a range of data sources maintained in diverse systems, as the healthcare data has to be preserved then recovered and altered through various healthcare contributors for medical objectives that include medical data that interchange. The adapted technique is problematic due to the diverse data architecture between different institutions. It is considerably critical to ensure data interoperability among different entities before sharing the data.
