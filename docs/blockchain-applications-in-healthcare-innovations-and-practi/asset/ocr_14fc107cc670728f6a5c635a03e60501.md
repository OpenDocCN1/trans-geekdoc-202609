# 7.4. Regulatory compliance requirements

With the increase in size of data along with emerging technologies such as IoT, cloud, big data, etc., the instances of data breach have also increased. The impact of any data breach is very high when it involves sensitive data like health records. PHI (protected health information) suffers from a greater risk.
