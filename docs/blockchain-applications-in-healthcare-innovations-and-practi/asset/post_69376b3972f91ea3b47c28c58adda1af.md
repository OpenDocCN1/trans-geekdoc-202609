
## Component-based Healthcare Software Application Using Blockchain

Software technology plays an important role in our lifestyles. This technology affects our activities in many areas such as education, the car industry, administration, games, healthcare, etc. The primary aim of the software industry is to produce a high-quality and low-cost software system in good time. To achieve this goal, many software companies follow the component-based software engineering approach to develop software rather than traditional approaches. The component-based approach is an emerging technology for software development. Its main aim is to develop a software system by selecting the appropriate software components from a repository as per the requirement specification and assemble all of the components with a well-defined software architecture. Healthcare software systems are gaining attention from software developers as they are being increasingly used in day-to-day life. In the present scenario, monitoring our health has become a part of many people’s lifestyles. This means that customers need to search for reliable and secure healthcare software. The main challenges of health applications are to manage data safely. Hence, we need a technology that provides confidentiality and security for healthcare information. Blockchain is one of the technologies that can be used to secure our data and increase our trust in the application. Further, it is becoming popular because of its features, which include security, decentralization, immutability and transparency. Many healthcare standards such as life-cycle models and design methodologies give the best software practices and design principles to secure our application. In this chapter, we discuss the life-cycles of software development through the component-based software engineering approach. Further, we discuss how to create a Blockchain-based repository that stores software component and also discuss how Blockchain technology helps to secure our data in healthcare applications. The proposed software development life-cycle model ensures the security of user data and also improves the quality of healthcare applications.

### 9.1. Introduction

Today, software is being used everywhere, such as in the education, health, transportation, banking, sports and communication sectors etc. Software is required to operate computers, airplanes, mobiles, TVs, cars and even children’s toys. It has a great impact on our daily lives and society. It supports comfortable living, along with monitoring facilities. In recent years, the healthcare sector has grown rapidly and has started to use software technology. Software technology has ensured that digitalized records are more effectively accessible when needed. The appropriate use of medical software will prove to be a boon for the health industry. It provides better accessibility for patient records, easy collaboration between physicians and easy to track patient health records, which all contribute to the best treatment (Katuwal et al. 2018; Ullah et al. 2020). Therefore, the effect of these applications is to shorten the patient’s treatment time, save money and effort, resolve the problem of unnecessary visits, and maintain and update the patient’s medical history. However, implementing healthcare software faces various challenges, such as how to choose better software methodology, how to incorporate user requirements into the design, how to trust in the medical software, how to easily adopt changes in technologies and culture, and also how to fix security issues. Healthcare solutions provide different types of software services, such as electronic health record services, practice management software, hospital management systems, billing software, lab information management software, etc., and tries to fulfill patient needs. But all of these software services have not increased the trust and transparency between the patient and the physician.

Software engineering methodologies play an important role in building a large and complex healthcare application. Software engineering can be defined as the study of the software process, principles and methodology applied in any real scenario of software development (Lalband et al. 2019). It helps to reduce the complexity of large software development, minimize software cost, deliver on time, handle bugs, and fulfill user expectations and needs. A proper software model (known as a software development life-cycle model) plays a vital role in developing software. Effective software models in software engineering help to build, design, develop, test, maintain and evolve any software systematically. It is a framework that helps to pre-plan. The software industry that tells us how to create a software product. Software development life-cycle (SDLC) is a group of various phases that helps us to understand the process of building software. It helps the developer to understand project context and user requirements. Hence, the project’s success always requires the best SDLC model according to its needs. An effective SDLC model provides a good software project within a certain timeframe, at lower cost, with less effort, without going over budget.

In the 1960s, there was no method or framework for the development of the software process model. The developer collects all of the information related to software in text form. Hence, it was not able to properly understand what exactly the user wanted. Due to this, developing software was time-consuming and needed more effort. But today, the definition of the software development process is different. They follow standards and methods to create any kind of project. SDLC uses these standards to collect and analyze requirements related to the development process systematically. There are various SDLC methodologies, such as the waterfall model, iterative model, prototyping model, spiral model, agile model, etc., which are used for software development. Each SDLC model is different from the other. But these models are older and do not give more functionality to the user or support rapidly changing requirements. Today, due to more expectations of user requirements, the developer is bound to create large and complex software. These traditional models are not fit to develop large and complex software and never give better quality and accuracy. Hence, the developer needs to choose another advanced SDLC model technique that removes the above issues and uses less time, cost and effort to develop software. It also ensures that transparency between the developers is maintained, developing speed is enhanced and the risk factor is minimized. At the end, users get a high-quality product that fulfills user requirements. This advanced SDLC model technique is based on component-based software engineering (CBSE).

CBSE is an advanced development approach in which software products are developed by selecting reliable and reusable components, and assembled using the appropriate software architecture (Mahmood et al. 2007; Vale et al. 2016). Here, the component is various software modules, packages, self-unit codes that are executed, verified and deployed independently. The main aim of adopting this technique is to increase productivity, lower cost and time to market, and improve performance and quality. This new concept is different from the traditional approach, where software is not developed from scratch. The CBSE approach consists of two life-cycles that work in parallel, one is a component-based development life-cycle and another is a system development life-cycle through component. When a developer wants to create any software using the CBSE approach, they search for the desired components in the software repository. If the desired components are present in the repository, then they assemble these components and construct a software product. If the desired component is not presented in the repository, then they create it from scratch. The development of an SDLC based on CBSE plays an important role in providing better-quality and cost-effective software (Aoyama 1998; Cai et al. 2000). A better development life-cycle model helps to reduce time, cost and effort and increases the performance and quality of the software. Although this approach increases the software’s productivity and performance, it does not increase reliability and trust in them as the selection of expected software components to develop the software is not always trustworthy and reliable.
