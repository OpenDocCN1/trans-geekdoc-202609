# 7.4.2. Blockchain as a savior

The fundamental pillars of Blockchain can support security/privacy controls when different regulatory requirements need to be implemented in the form of technical controls (Yue et al. 2016; Kuo et al. 2017; Shu and Jahankhani 2017; Jin et al. 2019):

+   - Let us start with decentralization. In traditional healthcare applications DBMS is used while Blockchain provides decentralization which makes different healthcare entities collaborate without any central management entity. This is not possible so easily with DBMS.
+   - With the help of Blockchain, the PHI is more secure from any tampering as the ledger cannot be altered as Blockchain only supports the creation and reading of the ledgers.
