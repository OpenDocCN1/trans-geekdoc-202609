Encryption schemes, for instance, Public Key Encryption (PKE), Symmetric Key Encryption (SKE), secure Multi Party Computation (MPC) and others are rather widespread. In the proposed system, a Blockchain based in a healthcare network comprises a public key encryption technique, such as Elliptic Curve Cryptography (ECC). This is used to perform the encryption of private data over a secure channel, which corresponds to the data generated from various sensors that will be uploaded in a Blockchain network by means of a pair of exclusive private and public keys, in order to ensure the privacy and security of biometric data (Daemen and Rijmen 2002; Dai et al. 2020).

Al Omar et al. (2017) advocated that data should be encrypted using a symmetric key technique with a threshold encryption scheme before being uploaded to cloud services. The process of Shamir's Secret Sharing (SSS) divides the symmetric key into many shares that are further distributed to distinct key keepers. The process of decrypting the encrypted text can be performed when the data requstor accepts adequate key segments. Data leaking may not arise when certain key keepers negotiate the (minimal threshold) value. Smart phone is a Healthcare Data Gateway (HDG) that is built on Blockchain, and uses MPC technology by enabling the system that calculates the data that is encrypted directly by performing over the private Blockchain cloud, to attain the concluding results instead of illuminating original data (Azaria et al. 2016; Ahsan et al. 2020).

Changing encryption keys is a common practice in healthcare systems and is a common method to avoid malicious, statistical attacks. But it incurs enhanced storing and managing costs with a large number of historical keys, which should be stored properly in sequence to perform decryption of some historical data in near future. This process leads to an increase in storage costs, specifically because of partial computational means and storage procedures to solve problems such as: web developed trivial backup and recovery key management systems that are implemented as a body of sensor networks (BSNs) to protect the privacy of the sensor data from a person by reducing secret key storage expenses. Without storing any encryption keys, fuzzy vault technology is used to generate, backup and recover keys, with BSNs performing the key recovery of the sensor data that is encrypted using symmetric encryption technology (AES or 3DES) (Blum et al. 1988; Rama et al. 2017). Hence, the attacker will have a hard time decrypting it without a symmetric key.
