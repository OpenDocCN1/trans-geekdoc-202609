RNNs compute the new output by taking into account both the current and prior inputs. The fundamental issue with RNN, despite its promising performance, is the diminishing gradient during training. The introduction of gated recurrent units (GRUs) and long short-term memory (LSTM) networks, which are capable of holding patterns for a long period, is one way to address this issue.

# 9.7.3 Long Short-Term Memory RNNs

RNN models are very well suited to the problems having sequential temporal data. Many of its variants have also been proposed to deal with the long-range dependency between the dataset. A LSTM network was first suggested by Hochreiter and Schmidhuber [34]. The same network has outperformed in several datasets including handwriting recognition, acoustic modeling of speech, language modeling, and language translation. Later modifications in the internal architecture of the LSTM model have been proposed. These have been demonstrated as performing at a level similar to, or better than, that of LSTM networks.

# 9.7.4 Deep Belief Network

The DBNs are capable of learning -dimensional data manifolds. Directed and undirected connections are seen in DBNs, a hybrid multilayer neural network. While all other connections are directed, the layers among the top two stages are undirected. DBNs can be viewed as a collection of greedy restricted Boltzmann machines (RBMs). RBM layers interact with one another as well as with degrees prior to later. A feedforward system and multiple phases of RBM serve as feature extractors in this design. There are only two stages in an RBM: a hidden phase and a visible phase [35]. # 9.7.5 Autoencoder

An ANN called an autoencoder (AE) seeks to effectively code the data as shown in Figure 9.14. As a result, it may be applied to a network setup or to reducing features. It does by translating the input via a network of neural connections to itself. Unsupervised learning is categorized as AE, which encompasses severe adverse event (SAE), ventilator-associated event (VAE), and dialysis-associated encephalopathy (DAE). DAE is a neural network that was developed from AE and is mostly used for extracting features from noisy datasets. The DAE typically has three layers: an input phase, an encoding phase, and a decoding phase [36]. DAE may be layered to produce advanced properties. Another DL technique that has recently been applied to nonlinear dimensionality reduction is called Sabouraud dextrose (SDAE).
