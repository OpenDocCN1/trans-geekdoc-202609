WSN is anything that connects to a wireless network to collect data or monitor the environment.

IoT consists of WSN + Internet + Cloud Storage + Mobile/Web Applications.

WSN consists of a large number of tiny low-power devices called nodes that communicate through wireless channels for information sharing.

IoT consists of a gateway that is used to connect the devices to networks (using switches, routers, Access Points, etc.).

WSN follows IPv4 and it has a sink node not by gateway.

Routing protocols in WSN include. DSR, CTP, PEGASIS, LEACH, SEP, AODV, OLSR, SPIN, and TEEN.

IoT follows IPv6 on the sensor network (802.15.4 MAC/PHY) and IPv4 on the internet part [11]. Routing protocols in IoT include. RPL, LoWWPAN, MQTT-SN, CoAP, AODV, BLE Mesh, and Zigbee.
