# 3.4.4 LoRaWAN

For long-range, low-power wireless IoT applications, LoRaWAN was developed.
This innovative technology allows low-data-rate wide-area networks with bat-
lives. In this section, we will discuss LoRaWAN’s primary advantages and uses
in the integrated IoT-WSN framework for smart cities.

LoRaWAN uses unlicensed ISM channels like 868 MHz in Europe and 915 MHz
North America in the sub-GHz band. Its long-range characteristics allow device
s send data over many kilometers, even in highly populated places with bari-
s and interference. Due to its long-range connection, LoRaWAN is ideal for smart
city applications that require wide-area coverage.

LoRaWAN saves power. The technology reduces usage to extend battery
life by many years. Because of its low power requirements and minimal
maintenance and operational costs, LoRaWAN is ideal’ for remote or inaccessible
device deployments.

LoRaWAN uses a star-of-stars network to connect end devices to a gateway,
which connects to the network server. The gateway sends data to the net-
server for examination. This star-of-stars architecture simplifies network con-
st and data handling.

The protocol can support modest data rates of a few hundred to several kilobits
per second, depending on settings. Many IoT applications, such as environmental
itoring, asset tracking, and smart agriculture, require periodic data transfer.
