Cisco first initiated the fog computing concept, which helps expand computing to the edge of the network [47]. The word “fog” is used because fog devices make cloud resources more accessible to IoT devices or users, i.e. from core to edge computing which helps to provide reliable services in a short period. Like the traditional CDC, fog devices yield a yielded platform that furnishes processing, storage, and networking services to IoT devices and users. Using existing articles, a fog environment consists of many ubiquitous, heterogeneous, and decentralized computing nodes that execute and hold data locally using various wireless communication modes. This is without the impact of a third party [48].
