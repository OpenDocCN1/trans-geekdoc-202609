# 6G and Distributed Computing for IoT: A Survey

Abhishek Hazra, Mainak Adhikari, and Lalit Kumar Awasthi

The Internet of Things (IoT) is a rapidly evolving field that integrates various physical devices and systems, such as sensors, cameras, and actuators, with the Internet. It enables real-time data collection, transmission, and analysis. IoT has potential applications in smart cities, power grids, smart agriculture, transportation systems, and healthcare [1]. For instance, in the healthcare industry, IoT implementation can enhance patient care, increase efficiency, and reduce costs by tracking healthcare staff and patients, monitoring vital signs, and managing chronic diseases [2]. IoT also brings benefits to industries like optimizing traffic, improving crop yields, and managing power grids more efficiently. To leverage the advantages of IoT, a robust infrastructure is crucial, enhancing communication and computation capabilities that can handle the large volume of data generated by IoT devices. This includes advanced technologies like beyond 5G/6G communication, cloud computing, and fog computing. Additionally, robust security and privacy measures are necessary to safeguard sensitive data [1].

The evolution of the internet, from peer-to-peer to the wide web, mobile to social, and is now powered by rapid network advancements. Fifth generation (5G) wireless networks, with its high bandwidth (10 Gbps), and lower computational cost, the ideal infrastructure for executing IoT applications that require various quality-of-service (QoS) parameters. The Tactile Internet, another significant advancement in Internet technology, enables ultra-low latency machine-to-machine and machine-to-human communication, ensuring network availability, security, and reliability for data transmission [3]. With these advancements, IoT devices can transmit data with minimal latency and high reliability to computational servers. Smaller IoT applications can be executed on connected sensors or fog devices, while larger applications necessitate robust infrastructure, storage, and computation resources to meet QoS parameters [4]. For demanding applications, data transmission to highly computational devices such as cloud data centers, which possess ample capacity and storage, is required.

One of the main limitations of cloud computing is the use of virtual machine (VM) technology, which combines programs into a single server [5]. Each VM program has its own operating system (OS) image, leading to memory and storage overhead.
