There were two interesting files discovered on this domain. The robots.txt file is especially interesting because this is the file that tells search engines which folders to index and which to ignore.

In other words, if a website has folders that people (or search engines) should not be looking, those folders would be noted in this file. The discovery of folders that should not be indexed is typically a good sign that you are on the right track to discovering something interesting; those folders are almost always worth exploring.

## Pushpin Geolocation Modules

The Pushpin modules in Recon-NG look for files that have been geotagged, or have geolocation metadata saved within them. The name is derived from the pushpins that are pinned to maps locations. In this case, these modules are designed to do exactly that—to pinpoint the exact location from which the files were posted.

With the level of security included in most social media and online sites, stumbling upon an online image or file with embedded location data is akin to hitting the lot—it is extremely rare and will probably happen under the right circumstances. Nevertheless, plenty of scenarios exist such as the direct examination of a phone’s archive, you should always try. The Pushpin module searches Flickr, Shodan, and YouTube for media with embedded geolocation data. The Pushpin module will not tell you where a specific piece of media was published. Instead, you can enter an address or specific coordinates and the module will return all media published around location.

Annoyingly, each of those sites has its own module, so you need to search them individually. To search for the location of the Pushpin modules, type the following:

```
search pushpin

[recon-ng](default) > search pushpin
[*] Searching for 'pushpin'...
recon/locations-pushpins/flickr
recon/locations-pushpins/shodan
recon/locations-pushpins/twitter
recon/locations-pushpins/youtube
reporting
```

Each module has its own set of parameters and descriptions which you can view by loading the module and using the show info command. Let's get info on the Flickr module:

```
[recon-ng](default) > use flickr
[recon-ng](default)[flickr] > show info
```

Options:
```sql
SELECT DISTINCT latitude || ',' || longitude FROM locations WHERE latitude IS NOT NULL AND longitude IS NOT NULL representing a single input path to a file containing a list of inputs
```

Comments:
* Radius must be greater than zero and less than 32 kilometers.

We can see from the module's page that we need to have the coordinates of an address as well before we can use the module. Plenty of free tools are available to do this. One example is https://www.mapdevelopers.com/geocode.php. After visiting the website, enter your desired address, and it will return your latitude and coordinates. For example, I used the coordinates of St. Louis, MO. MapDevelopers.com returned the following:

```
Latitude 38.63716
Longitude -90.241648
```

Now that we have location coordinates, let's see what kind of information we find in the Pushpin module. First, we need to add the location to Recon-NG using the add locations command:

```
[recon-ng](default)[geocode] > add locations
latitude (TEXT): 38.63716
longitude (TEXT): -90.241648
street_address (TEXT):
```

This is things that can run fully. The latitude and longitude of St. Louis have been entered as location data—let's see if anyone from this area has tweeted. This searches the Twitter Pushpin module using the following command:

```
use recon/locations-pushpins/twitter
```
