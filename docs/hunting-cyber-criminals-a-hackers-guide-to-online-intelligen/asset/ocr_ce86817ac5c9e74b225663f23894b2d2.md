Macros will freak an adversary out. If you try to drop a macro in a document, they're not going to open it. If you try to put a macro in an Excel spreadsheet, macros are always in Excel spreadsheets ...so they are going to open it, and they're not? It's defer.

On the other hand, if you tried to put a link in a cascading stylesheet (CSS), or an image source tag in the metadata of a document, your likelihood of them actually opening and having it beacon back is now a lot better.

Some of my favorite ideas to get adversaries to run things like simple ideas. Just set up a directory on a website that serve VPN, and have an executable that does the automatic VPN configuration and then you create that executable with its own functionality. Or you can even sign that executable, wait for any lookups on that code signing certificate whenever it fires, or when somebody tries to run the executable as well.

It's more of an issue of just moving beyond the traditional document arouse, but actually using the right bait to get that individual to open those particular documents and intercepting with a component that you created to attract them.
