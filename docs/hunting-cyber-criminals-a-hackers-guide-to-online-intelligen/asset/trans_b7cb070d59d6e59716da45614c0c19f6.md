# Wayback 站点快摘要：Wayback 缓存的所有站点 URL 列表

我们可以通过向 `search?url=our string` 中添加 `collapse:digest` 来进一步扩展查询，以搜索 Wayback 缓存的每个特定站点 URL：

```
https://web.archive.org/cdx/search?url=domain.com&collapse=digest
```
