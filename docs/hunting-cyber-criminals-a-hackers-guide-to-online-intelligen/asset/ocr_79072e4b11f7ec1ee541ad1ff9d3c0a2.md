Inurlrb is PHP based, so running it might be a little different than the other Python scripts. Make sure you have a PHP environment set up. To start, let's search for a deep dump to search for active AXIS cameras using only Bing (results shown in Figure 8.11):

```
inurlrb.php --dock inurl:view/index.shtml -q 2 -s save.txt
```
