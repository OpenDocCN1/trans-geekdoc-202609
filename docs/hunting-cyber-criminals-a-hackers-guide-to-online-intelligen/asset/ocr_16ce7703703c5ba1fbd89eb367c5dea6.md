# FOCA

Fingerprinting Organizations with Collected Archives, or FOCA, is an open-source reconnaissance-gathering tool for Windows. FOCA is a GUI tool that downloads publicly available documents from web servers and scans them for metadata and other hidden information. FOCA uses Google, Bing, and DuckDuckGo to search for documents.

FOCA can analyze various document formats, (but not limited to) PDF, DOC, XLS, PPT, JPG, PNG, SVG, and more. It can also be to extract EXIF information from graphic files. A useful feature of FOCA is that it analyzes the document metadata prior to downloading the file and limits the downloads to only files that contain useful metadata information.
