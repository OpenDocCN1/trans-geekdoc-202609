# EXPERTTIP: ALEX HEID

Even the most cybercriminals make mistakes. Wuzz focuses with two bad wordlists. When I run Wuzz, I will first run Wuzz for directory names, then I will run a second fuzz for FIP, zip, tgz, txt, sql. The file `big.txt`, which comes with Wuzz, will find the most of awesome stuff.

I regularly find files like 1.sql or Ab.sql. People making file name the file something short and Wuzz will just rip through detect those. I have found source codes for entire darknet sites that way. I also look for 'c99', which is a common webshell. I find that people will use instead of installing something like Cpanel or Plesk.

# Photon

Photon is OSINT web crawler and data extraction engine. It is highly sophisticated and a great tool to use when you are going for a wide shotgun approach. According to Photon's GitHub page, it is “an incredibly fast crawler for OSINT.” Photon is available for download at https://github.com/amd3v/Photon.

Uses for Photon include looking for creative/hard-to-find pages on a site, external links, and broken links; creating a hard-to-the website; and determining changes to a site over time.

There are literally hundreds of web crawlers available—many of them as powerful as they are expensive. Photon is fantastic because it works, and it is open source.
