## How Does It Work?

Rather than looking for related domain names, we can also use the certificate searches to look for outdated IP addresses. If these IPs are not part of the Cloudflare network, we surmise that the IP belongs to our target domain.

If you would like to automate this process, there is a Python tool called Cloud-Flare (CF, so do not confuse with Cloudflare, the company). CF is a tool used to automate the process of finding the origin of publicly exposed servers that do not properly restrict access to the Cloudflare.com ranges.

This tool is available for download at https://github.com/christophehtd/CloudFlair.

For our first example, let's see if we use CF to track the originating server of Codepenio.

```
root@OSINT: python cloudflare.py codepio.io
```
