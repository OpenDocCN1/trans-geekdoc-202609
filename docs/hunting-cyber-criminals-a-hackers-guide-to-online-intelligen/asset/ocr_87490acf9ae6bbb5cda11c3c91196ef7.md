The Iris Pivot Engine is the cornerstone of the investigation search. As you search for new items, the Pivot Engine will highlight which other paths you can explore within the domain WHOIS data. Each path is referred to as a pivot. Every time you take a new step in a different direction, you are pivoting from your original step. The data displayed in the Pivot Engine table shown in Figure 11.2 is very wide—it has 20 columns, which can highlight any number of searchable fields, including (but not limited to):
