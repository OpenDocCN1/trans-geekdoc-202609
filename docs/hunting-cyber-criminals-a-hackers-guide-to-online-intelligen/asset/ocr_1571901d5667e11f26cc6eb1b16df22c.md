# WHOIS

WHOIS data can contain a lot of useful attribution information regarding the
towner of a domain if you are able to access it.

The WHOIS protocol is used to query databases containing all sorts of pub-
licably available information on Internet resources, including domain names and
IP addresses. It was derived from the earlier Name/Finger Protocol, the same
protocol before the ARPANET NICNAME server, which was part of ARPANET,
precursor to the Internet.
