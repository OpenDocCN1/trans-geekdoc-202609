Spiderfoot chains and correlates data using more than 150 modules to query APIs, such as Shodan, VirusTotal, and Censys (to name a few). It scrapes websites and performs scans. Spiderfoot is an automated tool in the sense that it recursively analyze any new information obtained through an initial scan in order to find as much information as possible. The results will exponentially balloon out quickly.

Running Spiderfoot is pretty simple:

```
root@OSINT:/opt/spiderfoot$ python sf.py 0.0.0:5001
```

From there, you can access Spiderfoot via a web browser on port 5001. You should take this time to set up your API keys in the app settings. Once you have ready, running your first scan is pretty simple, as shown in Figure 5.2.
