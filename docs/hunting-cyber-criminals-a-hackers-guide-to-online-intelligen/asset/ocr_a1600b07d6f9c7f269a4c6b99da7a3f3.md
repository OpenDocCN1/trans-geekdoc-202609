# Chapter 16 Searching Social Media

I haven't talked much about Cr00k yet (more on him in the coming chapters), but he/his username was associated with TDO as one of the first deadliest predators. His name was all over the forums, as a result, over any TDO-related threat reports. Interestingly, the real person behind cr00k was smart enough to steal another's username, which is a common tactic of this.

This is a very smart move, and to watch out for. When people researched the name cr00k, they would inevitably be led down a path of misinformation in place by other threat actors using the same name.

Not only that, but creating and reusing names within members of the same group is a very common tactic to create confusion. You should definitely keep this in mind when dealing with a timeline of events.

```
[Screenname search target info - cr00k
[1] All - Run modules associated to the email module group
[2] Known - Run username to determine registered sites
[3] Blank - Run username to determine registered sites
[4] Valid - Run username and information if registered
[5] Reset - Reset the panel to new target address
[6] Back - Return to main menu
[Select] Select a number to continue: 1
```
