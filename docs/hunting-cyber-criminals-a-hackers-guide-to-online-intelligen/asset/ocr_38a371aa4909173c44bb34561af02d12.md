Looking at the Domain Status, we can see that the domain was in "REDEMPTIONPERIOD," indicating that Johnny let the domain expire around this time. The current owner of WhitePacket is probably not the same person who owned it in 2014.

While it is technically possible that the 2014 owner could have the domain expire and then purchased it back in 2015 with private registration status, that scenario seems unlikely.

However, this is something to keep in the back of your mind. Many reasons exist why someone would let a domain expire, then buy it back again using private registration. For example, maybe this threat actor is so smart that he knew wanted to use the domain for malicious purposes and anticipated this type of investigation. Highly unlikely, but you never know.
