## Firewalking

Firewalking gathers information about a host by using an IP TTL (time to live) expiration algorithm to determine if a host is active or not. In a nutshell, the route to the host is determined by traceroute. A packet is sent to the host with a TTL equal to the distance to the target. If the packet times out, it is returned with the previous value minus one. If ICMP type 11 code 0 (TTL exceeded) is received, that means the packet was forwarded and the port is not blocked. If no response is received, the port is blocked on the gateway. Since traceroute is dependent on an IP layer (the TTL), any transport protocol can be the same (TCP, UDP, and ICMP).

NMAP scripting engine (NSE) has a firewall script that will automatically perform all of these steps. The script will try to discover the firewall rules using the IP TTL expiration method previously described.

We can run the firewall script using the following command:

```bash
nmap --script=firewalking --script-args=firewall.max.probed.ports=5 \
--traceroute host
```

## Comparing Results

In the previous examples, we've run a number of different scan types and presumably output them all to sort format that we can go back and look at (I usually use XML).

Ndiff is a tool for the Linux diff command. It will show you differences between files. Ndiff is specifically designed to show you differences between NMAP results.

I typically run three or four different scan variations to make sure I have all of my bases covered. Ndiff is designed in these cases to essentially show you what changed between the different scans.

Another case would be a sysadmin that runs an NMAP scan on his network every week and to see if anything new has popped up. Ndiff would be the fastest way to do that.

## Styling NMAP Reports

One thing I have always had trouble with visualizing NMAP results. There are a few programs that they say do this, but I have never found anything worthwhile. You can actually style the output of an NMAP XML file using XL stylesheets with the -stylesheet parameter. Andreas Hontzia of Germany created a nice XSL sheet to style NMAP output to a nicely readable report:

```bash
nmap -sS pepsi.com -oA filename --stylesheet \
https://raw.usercontent.com/honze-net/nmap-bootstrap-xsl/
mmap/master-bootstrap.xsl
```

Once the scan is complete, you can view the XML file in a web browser. The results will look like Figure 4.1.
