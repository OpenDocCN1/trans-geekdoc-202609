# Running a Single Site Scan

Let's start with a basic scan of a website running the Drupal CMS, we can head over to www.builtwith.com, and search for "Drupal."

For a test case, I randomly selected PayCheck.com, a popular payroll company. There is a good chance it has a web application firewall (WAF), and most WAFs know to block for CMS scanning apps. The way to get around that is to specify a custom browser user agent, which will trick the WAF into thinking the request is coming from a user's web browser.

The -a parameter of CMSMap allow us to specify a custom user agent:
