Inurlrb also allows you to search through TOR, Shodan, Exploits, and Wikileaks. It is available for download at https://github.com/googleinurln/SCANNER-INURLB.

To use Inurlrb, you provide the app with your specified dork, and it will return all the sites that it finds. This is especially useful when looking for a particular exploit, or sites with a c99 shell.

Inurlrb is also an exploit finder, which this book won't discuss (and we can't publish vulnerabilities). Some of the cool features for Inurlrb include:

+   - Customization of HTTP headers and user-agent strings
- Random proxy cycling
- Email and URL extraction
- Vulnerability validation
- SQLi, LFI injection exploits
- Search pages based on specific patterns (i.e., regex)
