# IP History and relation feature BuiltWith

Another useful feature of BuiltWith is the ability to see which other domains are currently using—or have historically used—the same IP address. If you are looking for a specific threat actor or organization, it is likely that they will recycle the IP addresses, especially if they run their own servers. This is a good way to get a glimpse of the other domains they have.

# Webapp Information Gatherer (WIG)

WIG is exactly what it says—it is a tool to gather information on web apps. Since most websites/web apps use content management systems, WIG is a good way to quickly identify which CMS the target is.

> WIG is available at https://github.com/jekyc/wig.

CMS systems power a large majority of modern websites, so being able to identify which CMS is in at a target website is a fairly important first step in determining the direction for the rest of the engagement.
