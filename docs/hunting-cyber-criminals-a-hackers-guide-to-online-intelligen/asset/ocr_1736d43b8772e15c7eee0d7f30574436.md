# Another Test Subject

For this next example, let's look up our good friend and fellow security expert Christopher Meunier (aka WhitePacket). Most of Chris's Facebook profiles are offline, due to the magic of Facebook's search algorithms, I typed in his name and popped a new profile with his profile picture and an intentionally misspelled name. The Facebook profile was listed as Chris Maunier, but for some reason the search results displayed the profile. Maybe Facebook had associated his profile, or maybe it was just giving me close matches. Either way!

In order to perform any searches, we need to know his Facebook ID. We can tell from the URL that his username is christopher.maunier.923. All we need to do is enter username in the "Get Facebook User ID by Profile" API search (Figure 16.6).

Once we run the search, we easily obtain his Facebook ID of 10003275741589. Unfortunately, Chris's profile is mostly private, but there is still a decent amount of information we can get from it. To start, "Get Facebook User Profile by User ID" (Figure 16.7) will return a summary of the target's Facebook profile, which includes recent posts, headline, full name, direct photo, and more.

One thing we can immediately see from these results is the URL of his Facebook photo. Using OSINT.rest also includes a reverse image search API. Let's first start by navigating to this URL. The public post and profile photo for user 10003275741589 (Figure 16.8) contains the caption "F u."

Now that we have a profile, we can save it for later or copy the URL and perform a reverse image search.
