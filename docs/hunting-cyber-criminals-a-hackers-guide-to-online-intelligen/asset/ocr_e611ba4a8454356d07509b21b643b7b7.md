# 206 Part II Web Exploration

For this example, let's revisit our WhitePacket. The domain www.whitepacket.com has privacy enabled started in 2015 (which is presumably when the current domain owner took ownership of it). In this case the WHOIS data is no help, but looking at the data we can see that the domain's DNS is using Cloudflare.

Cloudflare's DNS provides a mechanism to mask a server's IP address, making it extremely difficult to investigate. One I also love about Cloudflare is that it provides a shared SSL certificate that you can use for all domains in your account.
