# 回到 TDO

# 总结

本章强调了我与不同威胁行为者的直接交流情况，并解释了为什么在调查期间可能需要直接与他们接触。有时需要引诱他们出来并让他们主动找你，而其他时候可能需要制造或助长他们内部的冲突，以让他们相互竞争。
