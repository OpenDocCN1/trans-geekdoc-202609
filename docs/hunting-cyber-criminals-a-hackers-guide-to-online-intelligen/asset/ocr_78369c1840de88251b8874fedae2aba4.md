# Part II ■ Web Exploration

> NOTE If a website has automatic URL redirection set up, you will be flooded with a list of URLs and 302 response codes. This is Wuzzing that every folder is active. If you start to see a bunch of 301 or 302 response codes, the site may have a custom 404, or error redirection set on every page. In either case, to hide anything but a 202 response, use the following code: -hc 404,301,302.

Code 200 shows success usage. If the URL is interesting, it may be worth checking out. On the other hand, 403 errors are almost interesting because we cannot tell the file exists; we just don't have access to it. As we progress in our investigation, this can give us an indication of what type of other files to look for, or it can provide us with an attacker vector later if we are able to gain access.

Based on what is discovered, we can also tailor our fuzzing strategy to go two or three levels in a particular direction.
 example, the last line of our scan detected the folder typo3temp. Typo3 is popular but not without CMS. Even if we do not have access to the typo3temp folder, we know it is there, and there is a good chance there are accessible files within that folder.
