# SpiderFoot HX (高级版)

SpiderFoot HX 是 SpiderFoot 的高级版本。HX 纯基于云端，包含许多额外的增强和功能，包括改进的扫描速度、多线程/并发扫描、更好的可视化、团队协作、风险识别以及显著改进的自动化数据关联。

升级后的关联引擎立即引起了我的注意。在本节中，将在 SpiderFoot HX 中重新扫描上一组目标，并提供差异对比。
