# EagleEye

EagleEye is an image search tool designed to reverse-search social media pictures. The main drawback of EagleEye is that you need to know a part of the person's name in order to search for more matches of their profile pictures. This may not necessarily be a problem if you already know the name of the threat actor or target and are just looking for more information on that person.

EagleEye first searches the name across Facebook, then performs a reverse image search on the picture across Google, ImageRaider, and Yandex to find the person's other social media accounts. The end result is a nicely formatted PDF report.

Another good use of this tool would be to check if someone is potentially catfishing. It's always good to run someone's picture through and see what other matches you come back with.

You can download EagleEye at https://github.com/ThoughtfulDev/EagleEye. Figure 15.17 shows the main EagleEye screen.
