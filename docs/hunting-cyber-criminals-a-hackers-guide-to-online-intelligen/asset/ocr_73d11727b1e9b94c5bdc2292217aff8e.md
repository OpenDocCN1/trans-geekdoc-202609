# Decoy Scan

When performing a decoy scan, NMAP will spoof additional packets that appear to be from a number of different spoofed decoy addresses. This might make a host think it is being bombarded from multiple systems simultaneously and the IDS/firewall to ignore the scans from our main system.

To include decoy packets, use the -D command, followed by RND:[number]. This will tell NMAP to generate X decoys.

This command will mask your IP by actually bypassing an IDS. When performing a decoy scan, an IDS might report 10 different port scans from unique IP addresses, not knowing which is actually performing the scan. This can be a good way to mask your actual IP by creating a lot of noise. Although, this attack is very noisy, but if the goal is to mask the IP of the machine your actual IP will still be in the logs. A better approach to mask your IP is to use proxies as previously discussed.

The following command will generate 10 decoy packets while using a SYN Scan against a target:

```
root@INTEL: nmap -D RND:10 -s pepsi.com
```

The results are the same as you just saw since we are not changing the type of scan, only adding decoys.
