# Userrecon

Userrecon is a simple Python script that searches for usernames across 75 different networks. It is very similar to the Knowem or Namechk tools used by Skipertr in that the tool will look for active accounts under a number of different sites by testing the URL.\ Userrecon tests more sites and has more accurate results, so it is worth trying. You can download Userrecon via GitHub at https://github.com/thelinuxchoice/userrecon.

```
root@osint: ~/userrecon$ ~
```
