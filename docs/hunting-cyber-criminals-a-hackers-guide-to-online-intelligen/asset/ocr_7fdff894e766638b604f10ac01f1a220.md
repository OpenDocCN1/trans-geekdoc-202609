Figure 11.16

The uncovered hosting history shows all of the different IPs from my web server going back to 2003. Possible search at this point is to look into each of the IPs to see if any malicious or questionable sites are tied to those IPs.
This will be a very time-consuming process, so one suggestion would be to use Iris’s notes mentioned earlier in this chapter. Iris’s notes can be placed on any pivot point and search you perform, which will make for a very good way to help you backtrack and understand how or why you came to a particular point in your research.
You never know when a piece of information (such as an IP) will come up later in an investigation, so make sure to document your results in a way that is easily searchable later.
