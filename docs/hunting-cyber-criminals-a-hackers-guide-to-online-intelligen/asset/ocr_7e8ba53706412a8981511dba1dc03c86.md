# CMSMap

CMSMap is an open-source Python scanner that automates the process of detecting security flaws in popular content management systems (CMSs). CMSMap is similar to WIG in that both tools are able to map and identify CMS systems, but CMSMap is more advanced and comes with additional features.

You can download CMSMap here: https://github.com/Dionach/CMSMap.

Though similar, CMSMap is considerably more advanced than WIG and supports a number of different options and parameters. In addition to detecting CMSs in use by web, CMSMap can also enumerate site plugins, bruteforce logins, and crack passwords. CMSMap also uses the official ExploitDB repo, which you can download here: https://github.com/offensive-security/exploitdb..
Some of the available CMSMap parameters include:

+   - f W/J/D/M, --force W/J/D/M
-P, --full scan(W), (J)oomla or (D)rupa or (M)oodle scan using large plugin lists.
-t, --threads number of threads (Default 5)
-a, --agent set user-agent
-H, --header add custom header (e.g. 'Authorization: Basic ')
-i, --input scan multiple targets in a given file
-o, --output save output in file
-E, --noembed enumerate plugins without searching exploits
-c, --noacleanurls disable clear urls for Drupal only
-s, --nolscheck don't validate the server's certificate
-d, --dictattack run low intense dictionary attack during scan

Brute-Force:

+   -u, --user username or file
-p, --pass password or password file
-x, --noxmlrpc brute-forcing WordPress without XML-RPC

Post Exploitation:

+   -k, --crack password hashes file
(Require hashcat installed. For WordPress and Joomla only)
-w, --wordlist wordlist file

Others:

+   -v, --verbose verbose mode (Default false)
-h, --help show this help message and exit
-D, --default run CMSMap with default options
-U, --update use (C)MSMap, (P)l or (PC) for both
