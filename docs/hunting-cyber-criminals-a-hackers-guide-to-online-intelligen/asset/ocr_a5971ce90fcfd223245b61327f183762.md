If you're not sure how to find a particular module in Recon-NG, you can search by typing search followed by the module. The following command will search for the interesting _files module:

```
search interesting_files
```

To load the module, use interesting _files. Figure 12.4 shows the output of the show info command when run after loading the module.

As we can see from the screenshot, this module needs info from the hosts table before we can run it. For our example, we will set the source to Apple.com:

```
set source apple.com
```
