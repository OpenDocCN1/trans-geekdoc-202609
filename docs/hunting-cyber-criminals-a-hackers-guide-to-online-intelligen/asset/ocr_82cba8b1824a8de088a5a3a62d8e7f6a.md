# No Authorization

An unexpected error occurred while enumerating the databases on
0.0.0.0:27017 - not authorized on admin to execute
command { listDatabases: 1, nameOnly: true }

You will see this message if the MongoDB server has authentication set up.
More and MongoDB instances have authentication now, which means even
if the database is detected by Shodan, you will not be able to access it without
proper credentials.

# Bad IP/Timed Out

Error connecting to 0.0.0.0:27017 - timed out

Pretty self-explanatory. The IP is no longer active or a firewall has been set
u to prevent access.

# Elasticsearch

NoScrape was initially developed as a way to quickly search and dump a large
el Elasticsearch databases. Everything that NoScrape can just as\easily be manually using curl commands (as discussed earlier in this
chapter). The difference, again, is that NoScrape puts everything in one nice\and package for you.

Similar to the MongoDB options, I personally specify a target CSV file
at contains a list of IPs and their ports. When running NoScrape, make sure to set
d database type to es using the -d parameter.
Elasticsearch scraper within NoScrape has four different scraper types that
be specified using the -s parameter: scan, search, dump, and matchdump.
Let’s look at them.

# Scan

The scan parameter will list the basic output of Elasticsearch server and
output the contents of the indices to the screen (or output file). This is the same
as querying the server using the / _cat/indices?v command discussed earlier:

```
root@osint ~ python noscroll.py -d -tf es-list.txt -s scan
```
