# Gnostic's Hacking Techniques

The method for these hacks was revealed to be NSFW (discussed in previous chapters) and confirmed by Nclay. The method was also confirmed by several of the hacked organizations.
Hack was simple but extremely effective the group would target developers and use recycled credentials to log in their GitHub accounts. From there, they would search the developer's Git repositories for AWS keys or similar credentials that had been checked in. Once the hackers had the keys, they would log into the company's systems and simply take what they wanted.
