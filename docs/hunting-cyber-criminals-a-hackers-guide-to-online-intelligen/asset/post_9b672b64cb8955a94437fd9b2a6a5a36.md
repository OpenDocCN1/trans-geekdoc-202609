## Wayback Machine Scraper

The Wayback Machine (www.archive.org) can be an amazing source of information. When dealing with large sites, the amount of information you have to sift through can be overwhelming.

The best way I've found to do is to literally scrape all cached copies of a site, then sift through the data locally. A few tools are available that you can use to scrape the data. One of them, enum_wayback, is even baked right into Metasploit, thanks to Rob Fuller (aka Mubix).

> EXPERTTIP: ROB FULLER
> I suck at pen testing web applications. I'm not very good at figuring out how they're filtered and what they do. And since everything's a web application these days, doesn't lend well to breaking into them. So, knowing how an application works on the backend and knowing which websites or URIs go to target is sort of a guessing game. You have to kind of to figure out where you need to log in to get the slash panel, dashboard, etc. All of those URIs that go into the dashboard has a kind of inherent vulnerability in it. Unless they code it, you can directly access resources from the dashboard or panel.

The Wayback Machine records websites at different states. If the Wayback Machine made a record of URL that is no longer in use or was open for a minute when it caught it, it can really be beneficial to knowing how an application works, or at least just a history of it.

The enum_wayback script was designed to give you a bunch of URLs that you might not have known about. It can show you URLs that existed and may not exist now. The script won't copy all of the functionality of a web application, but it does spider it.

Let's say they had a custom version of Drupal and a custom version of WordPress next. You're going to get both Drupal and WordPress URLs or URLs. There's a good chance that Java either files around or didn't set the routing correctly, or some other detail, and there's going to be technical debt then. Wayback not only finds its, but it also finds that was open probably shouldn't have been.

Let's use Bob's Web Store as an example. There's a good chance that Bob's Web Store has been around for 15 years, they didn't think about security until 10 years ago, and so those URLs were indexed and cataloged might still be there and very valid, now more secure.

It might be that 80% of them are more secure, but you might just find that one isn't—and can really make the difference. The script is designed to give you a resource of pages to look at.

Using it is really straightforward. All you do is point it at a specific host name or domain and it gives you the results from the Wayback, all parsed and nice and neat, so you don't have to page through anything and that makes it very easy to load into Burp, too.

## Enum Wayback

enum_wayback is a Ruby script that is part of the Metasploit framework. Since this is a book on investigations and OSINT, we really won't be digging too far into Metasploit or all of the amazing things you can do with it. If you haven't used Metasploit in the path (or maybe don't know what it is), Metasploit will be one of your primary tools when conducting a penetration test. ## Archive.org Site Search

Many scrapers tools require you to provide them with a hard list of URLs to scrape. Building a list of working URLs can prove to be a very big challenge, especially when you are talking about millions of posts. As it turns out, you can use specially crafted cURLs to download lists of pages cached by Archive.org which give you each cached copy of a site, substituting the actual domain: https://web.archive.org/cdx/search?url=.
