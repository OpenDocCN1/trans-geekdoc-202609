## Search

The search parameter will perform a deeper dive into the Elasticsearch database by looking at the mappings table for each of the indices within the database. This is the same as looking at a table headers. Using this option is useful more often than, the actual index will be obscured or not something you would ever pique interest. The mappings file will show you exactly what type of data is located within each.

The dump parameter will use Elasticsearch to dump every index within the IP address. Use this with caution as it will download everything. You do not need to specify an output filename if Elasticsearch will use the name of the index as the JSON filename.

There is a very good chance that the output for this will be massive, so be prepared to deal with an large file. An output will look like this:
