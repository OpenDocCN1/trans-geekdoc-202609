# Metagofil

Metagofil is an information-gathering tool that allows metadata to be extracted from publicly available documents on web servers. While Exiftool can help reading metadata from files we already have, Metagofil can help take your investigation further by allowing you to find files about your target.

Metagofil works by performing doc searches across Google to find documents containing potentially useful metadata. Its capabilities include being able to save the documents locally and extract metadata remotely from popular file types and formats (but not limited to) Word documents, Excel sheets, PDF files, and many more.

Email addresses, shared resources, and server names are just some of the metadata that can be extracted from documents using the tool.
You can download Metagofil from https://github.com/laranies/metagofil.
The parameters of Metagofil include:

+   - d: domain to search
- t: filetype to download (pdf,doc,xls,ppt,opt,ods,doc,xlsx,pptx)
- l: limit of results to search (default 200)
- h: work with documents in directory (use "yes" for local analysis)
- n: limit of files to download
- o: working directory (location to save downloaded files)
- f: output file

Running Metagofil is straightforward. Enter the command followed by -d and the domain you want to search. For example:

```
python metagofil.py -d apple.com
```

Before running our search, I like to set up my working directory of files (so Metagofil saves a copy of everything it) and create an output file so I can see my results. Metagofil also requires you to specify which file types to look for (or it won't run). We will also decrease the search results to a maximum of 100 and let's run a search with those parameters against Busey Beck and see what we can find:

```
python metagofil.py -d busey.com -t doc,pdf,xls,doc,xlsx,xlsx -l 100
-n 100 -o docs -f results.txt
```
