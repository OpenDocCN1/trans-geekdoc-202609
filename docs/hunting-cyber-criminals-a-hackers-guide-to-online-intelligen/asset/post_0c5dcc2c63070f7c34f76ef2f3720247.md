Even the most professionals make mistakes. Fuzzing focuses with wordlists. When I run fuzzing, I will first run it for directory names, then I will run fuzzing for zip, txt, sql. The `big.txt`, which comes with ffuzz, will find the most awesome stuff. I have found source codes for entire sites that fuzzing will just rip through instead of installing something like Plesk.

Photon is an OSINT web crawler and data extraction engine. It is highly sophisticated and a great tool for a wide approach available for download at https://github.com/project. Uses for Photon include looking for hard-to-find pages on a site, external links, and broken links; determining changes to a site over time. There are literally hundreds of crawlers available—many of them as powerful as Photon. Photon is fantastic because it works, and is open source.

For OSINT, Photon can easily extract different points from a website. This can include information about staff (such as names and email addresses), contact info, related social media sites, and other potential hidden information like secret keys and buckets. During a typical website crawl, Photon can extract the following type of information:

- URLs (in-scope and out-of-scope)
- Parameter-based URLs
- Emails, social media accounts, buckets
- Files (pdf, doc, csv, etc.)
- Secret keys (API, etc.)
- Strings matching custom regex
- Subdomain and DNS related data
- Wayback/Internet archives

Photon also has built-in plugins to grab content from third-party services like Wayback Machine (Internet archive) and DNS Dumpster (DNS-related). There is also a --clone parameter that allows you to keep a local copy of the entire site. The parameters for Photon are:

```
-u --url root url
--level to crawl
--threads number of threads
--delay between requests
-c cookie
--regex regex pattern
--seeds additional seed urls
--output export formatted result
--output specify output directory
-v --verbose output
--clone make a copy of the site
--keys extract secret keys
--exclude urls by regex
--stdout print to stdout
--timeout http requests timeout
--ninja ninja mode
--update update photon
--dns enumerate subdomains & dns data
--only-urls only extract urls
--wayback Use URLs from archive.org as seeds
--user-agent specify user-agent(s)
```

## Crawling a Website

To perform a simple website crawl, use the -u switch followed by the URL:

```
python photon.py -u "http://www.vinnyteria.com"
```

Figure 7.1 shows the output of launching Photon against your personal website.

The results saved from this command include a list of detected URLs from the target website.

At this point the --clone parameter will take those URLs and perform a full scrape of the site, and save every page to disk:

```
python photon.py -u "http://www.vinnyteria.com" --clone
```

For complex sites like those of big corporations, blogs, and message boards, you should modify the depth of the scan and the number of simultaneous threads. The -t switch allows you to specify threads, and the -d switch specifies the depth (meaning how many levels of nested pages will be followed):

```
python photon.py -u "http://www.site.com" -t 5 -d 5
```

Another incredibly useful feature of Photon is the ability to automatically spider DNS and related subdomains using the -dns switch. This will give you the ability to capture the layout of a site and all of its subdomains in one shot:

```
python photon.py -u "http://www.ethereum.org" --dns
```
