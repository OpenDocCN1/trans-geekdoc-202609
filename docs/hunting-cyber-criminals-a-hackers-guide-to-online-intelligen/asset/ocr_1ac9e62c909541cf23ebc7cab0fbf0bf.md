# # Hacker Target

Hacker Target (https://hackertarget.com/reverse-dns-lookup) makes searching for subdomains and reverse DNS lookups really easy using their API. You can just query a domain or IP with a specific URL like this:

```
https://api.hackertarget.com/reversedns?q=url
```

A quick search for pepsi.com on hackertarget.com reveals 31 different subdomains:

```
https://api.hackertarget.com/reversedns/?q=pepsi.com
```
