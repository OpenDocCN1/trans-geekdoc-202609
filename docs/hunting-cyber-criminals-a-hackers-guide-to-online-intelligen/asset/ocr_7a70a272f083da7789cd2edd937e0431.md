# # Hosting History

Finally, the Hosting tab in Iris can provide even more clues as to a domain owner based on where the IP is located. It should come as no surprise that threat actors (and often do) point subdomains to their home IP address. Either way, knowing where a site is hosted can turn out to be an important piece of information. If a site is hosted on Amazon, Azure, or some other giant hosting provider, it is probably a dead end for that line of research unless you can link that with some other piece of data.

Figure 11.17 shows the Hosting tab for my personal website, which includes the different pre- and post-action IP addresses. This can be extremely useful if someone decides to host a domain from a private server, such as their house.
