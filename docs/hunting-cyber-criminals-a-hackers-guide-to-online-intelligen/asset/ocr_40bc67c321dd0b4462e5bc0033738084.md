# Wayback Site Digest: A List of Every Site URL Cached by Wayback

We can expand further our query to search every site-specific URL cached by Wayback by adding *collapse:digest to search?url=our string:

```
https://web.archive.org/cdx/search?url=domain.com&collapse=digest
```
