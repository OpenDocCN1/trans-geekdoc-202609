# TCP Window Scan

The -sW scan of nmap will perform "window scan." A TCP window scan is similar to an ACK scan but has been designed to differentiate between open and closed ports instead of showing them as unfiltered

```
root@OSINT: nmap -v -p -- pepsi.com -sW
```

# Working Firewalls and IDS
