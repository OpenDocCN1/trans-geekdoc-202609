## Twitter

I have not come across a single threat actor or cyber criminal that did not have at least one Twitter account. Twitter usually contains a gold mine of criminal activity, so you should always perform exhaustive searching of Twitter. Continuing from our previous example, we already know Mr. "Maunier" is associated with the name WhitePacket, let's see if we can come up with anything. To start our Twitter searches, we need to identify the target's Twitter ID. Luckily, OSINT.rest has an API search that allows us to derive the Twitter ID from a username. Figure 16.10 shows the "Get Twitter User ID by User Alias" search, with a query string of "whitepacket."

![](img/ceaab52f5a948b18995b8efe89758781_372_0.png)

Figure 16.10

We have a match—which is surprising because WhitePacket shut down his Twitter account a few months ago. I guess he decided to start it up again.

Now that we have his Twitter ID, we can perform all sorts of fun and interesting searches, getting lists of who he is following and his followers. Unfortunately, this account is fairly new, so he does not have many followers. In my mind, that means the people he is following (or that are following him) are most likely quality worth investigating.

Figure 16.11 shows a search to get list of Twitter followers based on Twitter ID. It’s that simple. If we were a target, we could expand our search to get lists of tweets that he liked or retweeted, and use that to assemble a threat actor matrix.

We only covered a handful of the different search APIs available in OSINT.rest, so I highly recommend checking this service.

## Sherlock

Sherlock is a powerful Python tool that uses basic web scraping to compile passive information on a target. Sherlock has a number of modules that harvest information based on telephone numbers, email addresses, screen names (first and last names), home addresses, hostnames, license plate numbers, and breached website credentials (using HIBP.com).

The email modules will search for accounts based on your target email address on sites as LinkedIn, BeenPwned, MySpace, and AdvancedBackgroundChecks.

The name modules will search for a target's first and last name on sites like TrueFinder, TruePeople, and AdvancedBackgroundChecks.

The phone modules lookup US phone numbers (performing a reverse search) on TruePeopleSearch, WhoCalled, and Whitepages. The license plate module will search a nationwide database of registered U.S. license plates.

Finally, the screenname (username) module will search for similar usernames on sites such as Knowem and Namechk.

You can download Sherlock for free at https://github.com/johnyaya/sherlock.

## Searching for an Email Address

Let's start off by searching for an email address. Pressing 1 on your keyboard while on the home menu will bring you to the email search menu (Figure 16.15).

Next, we can enter any target email. Let's go back to a previous example and use hacker@live.com. For some reason, searching LinkedIn does not work, which means you can't search “All.” Instead, we have to run each module individually.
