# Styling NMAP Reports

One thing I have always had trouble with visualizing NMAP results. There are a few programs that they say do this, but I have never found anything worthwhile. You can actually style the output of an NMAP XML file using XL stylesheets with the -stylesheet parameter. Andreas Hontzia of Germany created a nice XSL sheet to style NMAP output to a nicely readable report:

```
nmap -sS pepsi.com -oA filename --stylesheet \
https://raw.usercontent.com/honze-net/nmap-bootstrap-xsl/
mmap/master-bootstrap.xsl
```

Once the scan is complete, you can view the XML file in a web browser. The results will look like Figure 4.1.
