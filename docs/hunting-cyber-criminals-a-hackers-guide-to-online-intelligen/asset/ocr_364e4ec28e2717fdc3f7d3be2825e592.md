```
[recon-ng][default][metacrawler] > show info

Name: Meta Data Extractor
Path: modules/recon/domains-contacts/metacrawler.py
Author: Tim Times (@LiamGaite53)
```

Description:
Searches for files associated with the domain(s) and any contact related metadata.

| Name | Current Value | Required | Description |
| --- | --- | --- | --- |
| EXTRACT | False | yes | extract metadata from discovered files |
| SOURCE | default | yes | source of input (see 'show info' for details) |

Source Options:
default:
<script> select DISTINCT FROM domain WHERE domain IS NOT NULL
<path> path to a file containing a list of inputs
<query> database query returning one column of inputs

+   Comments:
* Currently supports doc, docx, xls, xlsx, ppt, pptx, and pdf file types.

```
[recon-ng][default][metacrawler] > []
```

In order to extract the data to your Recon-NG database, set the extract option to true by the following:

```
[recon-ng][default][metacrawler] > set extract true
[recon-ng][default][metacrawler] > run
```
