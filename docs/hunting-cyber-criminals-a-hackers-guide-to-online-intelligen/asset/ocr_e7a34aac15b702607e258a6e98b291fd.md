# Starting a Search for Forums

The first thing we need is to search. But where? To his, the threat actor behind the names Cr0tk and F3tty was smart enough to use popular names that have plenty of searching results. Searching Google for F3tty give us a mountain of information on the rapper, which is useless to us. Researching a threat under these conditions makes it extremely difficult unless you are a master at dorking techniques.

We need to narrow our search, and given that we know the name F3tty from hacker forums, the best place to look for more clues would be other hacker forums.

It is unlikely that you will be able to use durs and other advanced search techniques to find relevant data from forums, because most hacker require a login (sometimes pays) in order to view their content. With everything else, sometimes you will get lucky. This is one of those times.

There are several clear web hacker forums we can (and should) look through, such as HackForums.net, Nled.to, RaidForums.com, and OGUsers.com. Having some allies to work with means we can easily perform a Google search using the “inside” operator, or we can go to each site and search for posts or threads containing that username.
