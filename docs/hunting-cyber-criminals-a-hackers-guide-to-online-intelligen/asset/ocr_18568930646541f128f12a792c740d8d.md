There were two interesting files discovered on this domain. The robots.txt file is especially interesting because this is the file that tells search engines which folders to index and which to ignore.

In other words, if a website has folders that people (or search engines) should not be looking, those folders would be noted in this file. The discovery of folders that should not be indexed is typically a good sign that you are on the right track to discovering something interesting; those folders are almost always worth exploring.

# # Pushpin Geolocation Modules

The Pushpin modules in Recon-NG look for files that have been geotagged, or have geolocation metadata saved within them. The name is derived from the pushpins that are pinned to maps locations. In this case, these modules are designed to do exactly that—to pinpoint the exact location from which the files were posted.

With the level of security included in most social media and online sites, stumbling upon an online image or file with embedded location data is akin to hitting the lot—it is extremely rare and will probably happen under the right circumstances. Nevertheless, plenty of scenarios exist where this could be a common find, such as during the direct examination of a phone’s archive, you should always try.

The Pushpin module searches Flickr, Shodon, Twitter, and YouTube for media with embedded geolocation data. The Pushpin module will not tell you where a specific piece of media was published. Instead, you can enter an address or specific coordinates and the module will return all media published around location.

Annoyingly, each of those sites has its own module, so you need to search them individually.

To search for the location of the Pushpin modules, type the following:

```
search pushpin

[recon-ng] [default] > search pushpin
[*] Searching for 'pushpin'...
```
