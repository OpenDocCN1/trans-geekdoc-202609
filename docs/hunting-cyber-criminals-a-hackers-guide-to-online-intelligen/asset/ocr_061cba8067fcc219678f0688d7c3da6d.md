# Bulk WHOIS

Bulk Parsed WHOIS accepts a list of domains via the text input window and automatically generates and downloads a CSV file containing WHOIS records for those domains. You can enter up to 2,000 domains at a time, and you can run successive queries up to your allotted monthly query limit.

This is a useful feature if you need to get the results of multiple domains at once, in a nice, easy-to-read CSV format.
