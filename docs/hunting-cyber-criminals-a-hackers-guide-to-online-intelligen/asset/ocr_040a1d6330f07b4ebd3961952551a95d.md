# Search Engine Caches

Sometimes Google will offer cached versions of websites through its standard search. To access a version of a site, click the green arrow ↓ to a search result and select "cached view." Let's try looking for a cached version of WhitePacket's Twitter page (shown in Figure 10.8) by entering the following search in Google:

```
site:twitter.com/whitepacket
```

Google has only one result that allows you to view a cached copy. Several tweets are listed, but clicking them brings us to a "page not found" error since the page was deleted.
