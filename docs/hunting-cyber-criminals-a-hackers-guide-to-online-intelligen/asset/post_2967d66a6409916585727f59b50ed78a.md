## Cree.py and Geolocation

Cree.py is an OSINT tool designed to retrieve geolocation information from publicly available data on social media sites.
Most notably, Cree.py can retrieve geolocation data for tweets as long as the target users have not disabled geolocation data in their Twitter client. If geolocation is disabled, Cree.py can still retrieve very useful non-location-specific information from a target's Twitter account, such as their number of followers, which users retweet, the device types they use to connect to Twitter, and the frequency and times of day they typically tweet.
Cree.py is available for Windows, Mac OSX, and Linux at https://www.geocepy.com.

## IP Address Tracking

At this year's Derbycon, I saw John Strand give a talk on cyber attribution. In his talk, he demonstrated a way to get better results when attempting to pinpoint the physical location of an IP address.

> EXPERT TIP: JOHN STRAND
> I was testing Canarytokens on a user I knew was in downtown, KY. When the user opened the malicious package, I was sent back his IP address. When I performed a geolocation lookup on the IP address, the result was not very accurate – the results came back with a location that was about 20 miles away.
> I have found one way to get better granularity on geolocation lookup: use the traceroute command on the IP address in question. Then, when looking at your results, take the IP address of the last hop and locate that instead. This will get you closer. In my test case, I was able to pinpoint the IP address to one block of the hotel. The reason why this works is because most IP addresses (for home users in particular) are handed out via DHCP. The IPs can bounce around and a geolocation lookup will have no way of knowing where you actually are. But using traceroute infrastructure we can typically get much closer and more accurate results for a location.
