The elmNN package employs the extreme learning mechanism, i.e., sparse network learning [Huang, et al., 2012; Huang, et al., 2015]. The brnn package employs the Bayesian learning approach [Mackay, 1992].

To show how these three packages work, the seeds data was used again. Ten hidden neurons were used in three models. The Jacknife test was used for all three models. Table 3.8 shows three confusion matrices of these models. Figure 3.26(a) shows the ROC curves for these three models. All showed a similar performance.
