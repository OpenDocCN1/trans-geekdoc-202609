For the LDA $eta$, the data point $b$ is classified on the left side (assigned a predicted class label as zero) and other three data points are classified on the right side (assigned a predicted class label as one). These predicted class labels are shown in the first two columns of Table 3.7. In addition to two LDAs, the third LDA is added on top of these two LDAs (namely, $\alpha$ and $eta$). The third LDA examines whether the predicted class labels of LDA $\alpha$ are the same as the predicted class labels of LDA $eta$. If the predicted class label of LDA $\alpha$ is the same as the predicted class label of LDA $eta$, the top level LDA outputs a predicted class label one. Otherwise, the top level LDA outputs a predicted class label zero. Afterwards, four data points have been well-labeled or well-classified. Table 3.7 shows this result. The process is in Figure 3.25(b) and Table 3.7.
