$O = |X^t\mathbf{w}-y|^2 + \frac{\alpha}{eta}\mathbf{w}^t\mathbf{w} = |X^t\mathbf{w}-y|^2 + \lambda\mathbf{w}^t\mathbf{w} \quad (4.38)$

Equivalently, RLR applies a constraint to the weights

$|\mathbf{w}||^2 \leq s \quad (4.39)$

With this constraint, the regression coefficient of one variable increases, the regression coefficients of the other variables decrease. For instance, suppose there are two variables for a RLR model, then there are two regression coefficients, i.e., $w_1$ and $w_2$. Because $w_1^2+w_2^2 \leq s$, if $w_1$ increases, $w_2$ decreases. Suppose $w_1$ is increased by $\delta$. Because $w_2^2=s-w_1^2$, the following equation shows the relationship between $w_2^{old}$ and $w_2^{new}$, i.e., how $w_2$ decreases when $w_1$ increases,

$w_2^{new} \leq \sqrt{s-(w_1+\delta)^2} < \sqrt{s-w_1^2}=w_2^{old} \quad (4.40)$

Figure 4.18 shows an example of how regression coefficients are constrained. When the regression coefficient vector moves from the point $A$ to the point $B$, the magnitudes of two regression coefficients change. Because the sum of the squares of two regression coefficients is constrained, when $w_1$ increases, $w_2$ decreases accordingly.
