y = 1.64 + 1.86 x

Within this model, two variables have a constant proportional relationship, i.e., 1.86. When $x$ changes by one unit at any point, $y$ will change 1.86 units accordingly. For instance, when $x$ changes from four to five for one unit (delta in $x$ or $\delta x$), $y$ will move from 9.08 to 10.94. The difference between them is 1.86 (delta in $y$ or $\delta y$). This constant relationship is maintained all the way no matter how the $x$ variable changes, either in an interpolating way or in an extrapolating way.
