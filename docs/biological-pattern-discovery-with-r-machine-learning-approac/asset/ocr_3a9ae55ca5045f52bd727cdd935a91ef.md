# 7.2.4.5 The R library for the Smith-Waterman algorithm

The pairwiseAlignment function of the Biostrings can also be
used for employing the Smith-Waterman algorithm for a local pair-wise
homology sequence alignment depending on the design of a properly
designed substitution matrix, a gap opening penalty and a gap extension
penalty. Aligning the above two RNA sequences using the Smith-
Waterman algorithm is shown below. First the RNAString function was
called to define two RNA sequences

```
s1=RNAString('GCAUUGA')
s2=RNAString('ACUCU')
```

Next a substitution matrix was defined. All the diagonal entries of this
substitution matrix were filled by one and all off-diagonal entries were
filled by -0.3. To do this, the following code was used. Table 7.17 shows
this substitution matrix used by the Smith-Waterman algorithm.

```
subs=matrix(-0.3,nrow=4,ncol=4)
diag (subs)=1
rownames (subs)=colnames (subs)=RNA_ALPHABET[1:4]
```

Table 7.17. Forward propagation result.

| | A | C | G | U |
|---|---|---|---|---|
| A | 1 | -0.3 | -0.3 | -0.3 |
| C | -0.3 | 1 | -0.3 | -0.3 |
| G | -0.3 | -0.3 | 1 | -0.3 |
| U | -0.3 | -0.3 | -0.3 | 1 |

The pairwiseAlignment function was then called. The definition
of two parameters (gapOpening and gapExtension) were assigned
-1.3 and and-0.3.

```
align-pairwiseAlignment(s1,s2,type='local',
substitutionMatrix=subs,gapOpening=-1.3,
gapExtension=-0.3)
```
