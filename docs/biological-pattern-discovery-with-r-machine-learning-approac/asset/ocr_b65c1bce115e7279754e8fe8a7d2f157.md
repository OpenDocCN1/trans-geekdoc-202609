# 4.6.3 The elastic net linear regression algorithm

The elastic net linear regression algorithm (ELR) introduces two Lagrange terms [Zou and Hastie, 2005] as shown below, where λ1 and λ2 stand for two positive constants. It can be seen that ELR is a shrinkage mixture, i.e., a mixture of RLR represented by the λ1 term and Lasso regression represented by the λ2 term.

```
$$\min_{\mathbf{w}}(y - \mathbf{w}^T)(y - \mathbf{w}) + \lambda_1(\mathbf{w}^T\mathbf{w} - c) + \lambda_2 \sum_{i=0}^{d} |w_i|$
```

The glmnet package can also be used for ELR, in which the alpha parameter is set to a value between zero and one, for instance, 0.5,

```
glmnet (x, y,alpha=0.5,lambda)
```
