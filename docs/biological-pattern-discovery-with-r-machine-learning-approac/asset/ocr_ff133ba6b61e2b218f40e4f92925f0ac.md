To measure the goodness of a cluster model, the mixture model algorithm employs the Bayesian Information Information Criterion (BIC) [Schwarz, 1978] to optimise a model structure. The BIC is defined as below, where RSS is the residual sum of squares, N is the number of data points and C is a constant,

> $BIC = -rac{N}{2} \log\left(\frac{RSS}{N}\right) + C \quad (2.28)$
