Having understood that almost all experimental data is very likely contaminated by noise, the basic principle used in almost all regression analysis algorithms is what is called regressing random to unknown truth, i.e., the mean of the observations. All regression analysis approaches therefore have the same principle,"regress to mean”. In a simple experiment it is assumed that most observations are composed of a variation due to sample preparation error, technique error and data collection error. The error is assumed to be random and mostly follow a Gaussian distribution. Regressing these noises will finally lead the answer to the mean of these observations.

If the errors of a collected data set are assumed to follow a Gaussian distribution, the mean of these observations is the true value. The likelihood of the Gaussian errors of N observed data is defined as below, where $x_n$ is the $n^{th}$ data point, $\sigma^2$ stands for the variance of the data, $\mu$ is the unknown truth, i.e., the,

```
$$\mathcal{L} = (2\pi)^{-N/2} \prod_{n=1}^{N} \exp\left(\frac{(x_n-\mu)^2}{2\sigma^2}\right) \quad (4.1)$
```

Applying the negative logarithm to this likelihood function leads to the following equation,

```
$-\log\mathcal{L} = \sum_{n=1}^{N}(x_n-\mu)^2 + C \quad (4.2)$
```

Its derivative is shown below,

```
$$\frac{\partial(-log\mathcal{L})}{\partial\mu} = \sum_{n=1}^{N}x_n - N\mu \quad (4.3)$
```

Zeroing this derivative leads to the estimated mean as shown below,

```
$$\hat{\mu} = \frac{1}{N}\sum_{n=1}^{N}x_n \quad (4.4)$
```
