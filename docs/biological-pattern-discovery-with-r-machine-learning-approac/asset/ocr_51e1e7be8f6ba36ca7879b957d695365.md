Figure 3.40(a) shows an unpruned CART tree constructed for the Iris data[Fisher, 1936]. In this tree, five branch nodes were employed based on three of four variables. Some variable was repeatedly used, as Petal.Length. Importantly, the branch node Sepal.Length was a redundant node. The far right node Petal.Length was also a redundant branch node. The leaf nodes of these two nodes ended up with the same class. Therefore, this tree needs to be pruned. The rpart package was used for pruning this data. Figure 3.40(b) shows a pruned tree. It can be seen that only two variables and two branch nodes were sufficient to describe the relationship between the feature variables and the species type for this data set.
