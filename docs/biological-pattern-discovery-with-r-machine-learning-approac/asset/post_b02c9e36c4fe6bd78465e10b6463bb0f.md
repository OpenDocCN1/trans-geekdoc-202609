Z=\hat{y}>0.5

If an expected vector of raw class labels is denoted by y, a confusion matrix is generated using the following code,

```R
my.confusion=table(y,Z)
```

A general format of a confusion matrix with four summary statistics shown below,

$$\begin{pmatrix} TN & FP \\ FN & TP \end{pmatrix} (3.27)$$

In a confusion matrix, a class labelled by a zero is treated as the negative class and a class labelled by a one is treated as the positive class. TN, TP, FN, and FP thus stand for the true negative number, the true positive number, the false negative number, and the false positive number.

Normally the negative class is used to represent a class which may not have a severe outcome and the positive class is used to denote a class which may have a severe outcome in a medical practice. For instance, in cancer diagnosis, the negative class represents the benign tumours and the positive class represents the malignant tumours. Suppose a confusion matrix is used to evaluate a model for cancer diagnosis. TN is the number of correctly classified benign tumours. TP is the number of correctly classified benign tumours which should be malignant tumours. FP is the number of predicted benign tumours which should be malignant tumours.

Five measurements can be calculated based on these four statistics for the meaningful interpretation of a classifier. The specificity is the proportion of correctly classified negative data points (benign tumours). The sensitivity is the proportion of correctly classified positive data points (malignant tumours). The total accuracy is the proportion of all correctly classified data points (tumours). The negative prediction power is the proportion of negative predictions which are indeed negative. The positive prediction power is the proportion of positive predictions which are indeed positive. For instance, these five measurements have been included in Table 3.3 for the prediction table shown in Table 3.2. Suppose class A represented the benign tumour group and class B represented the malignant tumour group. The accuracy of diagnosing a malignant tumour

by this model was 60% and the confidence to trust a malignant diagnosis using this model was 75%.

The five measurements are defined as below,

| Metric | Formula |
| :--- | :--- |
| specificity | TN / (TN + FP) |
| sensitivity | TP / (TP + FN) |
| total accuracy | (TN + TP) / (TN + FP + FN + TP) |
| negative prediction power | TN / (TN + FP + FN + TP) |
| positive prediction power | TP / (TP + FP) |

## 3.4.2 Receiver operating characteristic analysis

A confusion matrix is a fix-point evaluation approach. It does not measure how robust a classifier is. In medical applications, it is often required to shift a threshold so as to minimise the cost involved with the life loss. It is for sure [that] missing a cancer patient's diagnosis has a much greater cost than a falsely diagnosed cancer patient.

Figure 3.10 shows such an example of the impact of a threshold on the classification performance. There are densities for two classes from a constructed classifier in this figure. The left density curve is for one class and the right density curve is for the other class. Two densities have been overlapped meaning the misclassification will more or less happen no matter what a threshold is used to separate two classes. For two thresholds shown on the horizontal axes, the misclassification rates shown as the shaded in two panels are different. In Figure 3.10(a), the left class has a greater misclassification rate than the right class. The grey shaded area (for the left class) is much larger than the dark shaded area (for the right class). But in Figure 3.10(b), the right class has a greater misclassification rate than the left class. The dark shaded area is much larger than the grey shaded area. This is because the threshold has been moved towards the right direction. This shows that classification performance depends on a threshold. In other words, the threshold variation causes the misclassification rate variation.

Fig. 3.10. The impact of the threshold variation on the misclassification rate variation. (a) The threshold causes more misclassifications in the left class. (b) The threshold causes more misclassifications in the right class.

Based on the discussion of the example in Figure 3.10, a question arises, i.e., the robustness of a classifier. The question is how to determine whether a classifier is robust against the threshold variation for the discrimination between two classes of data points. In other words, the misclassification rate variation of a classifier can be less dependent on the threshold variation. There are two classifiers shown in Figure 3.11, where one classifier is placed in the upper panels and the other classifier is placed in the lower panels. The densities of these two classes are highly overlapped shown in the upper panels. Therefore, when a threshold is changed, a dramatic misclassification rate change will happen. For instance, the top-left panel shows a much great misclassification rate for the class on the left side. The top-right panel shows a great misclassification rate for the class on the right side. However two densities of classes have a light degree of overlap shown in the lower panels. When a threshold is changed, little misclassification rate variation may happen. Therefore the classifier shown in the lower panels is more robust than that shown in the upper panels against the threshold variation. Through this analysis, it can be seen that if a classifier is robust against the threshold variation, the overlap between the densities of two classes should be as small as possible.
