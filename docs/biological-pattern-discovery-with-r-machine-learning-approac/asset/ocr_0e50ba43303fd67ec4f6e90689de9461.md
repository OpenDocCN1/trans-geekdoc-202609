A Bayesian learning procedure is used for RVM, by which the $a$ priori structure is set for the linear coefficients given a vector of the hyper-parameters for $\mathbf{w}$,

```
$p(\mathbf{w}|\alpha) = \prod_{n=1}^{N} G(w_n|0, \alpha_n^{-1})$
```

The posterior over $\mathbf{w}$ is derived using the Bayes rule and the marginal likelihood is established for the model [Tipping, 2001]. RVM has been applied for EEG signal classification, where the commonly used Gaussian and polynomial kernels were replaced by a chaotic dynamic kernel [Dong, et al., 2018]. It was also used for the protein-protein interaction prediction problem [Li, et al., 2018].

The R package for RVM is implemented in kernlab. The package supports a number of different kernel functions. The use of a relevance-vector machine based on kernlab package is shown below,

```
rvm(x, y, kernel, kpar)
```

Figure 3.35(a) shows the RVM model constructed for a two-cluster data set. The relevance vectors were those surrounding two clusters.

Similarly, the kernels used in RVM can also be replaced by the bio-basis function for modelling peptides data. Doing so, the model is called a bio-RVM. A bio-RVM model was constructed for the factor Xa protease cleavage data. In the model, bio-basis function was supported by the Dayhoff mutation matrix for the homology score calculation between peptides and relevance vectors. The Jackknife test was used for the generalisation test of the model. Figure 3.35(b) shows the ROC curve of the Jackknifed model. The AUC value was 0.962.
