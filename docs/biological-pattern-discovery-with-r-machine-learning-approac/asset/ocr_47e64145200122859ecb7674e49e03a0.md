When applying such a baseline estimation algorithm to a data set, there is normally no a priori knowledge of what a regularisation constant (smoothing parameter) should be used [Taylor, 1992]. Therefore, it is very important to pay the attention to search for an optimal regularisation constant so as to guarantee an optimal baseline to be estimated for the accurate signal discovery.

How to determine an optimal value for the regularisation constant is non-trivial. The value of the regularisation constant must be enumerated manually to determine at which point, an optimal baseline model can be estimated for a spectrum. Figure 5.4 shows how the fidelity measurement and the smoothness vary when the regularisation constant varies. As shown in Figure 5.3(c), when the regularisation constant becomes too large, an estimated baseline tends to be more and more flattened resulting in a great error or fidelity. This is also shown in Figure 5.3 (a) when the regularisation constant is too small, a curve fits every detail of the intensities in a spectrum. Therefore a baseline estimated will not be sufficiently smooth.

A critical, but less focused issue is how to handle multiple spectra, i.e., spectra data with more than one replicate. Most baseline estimation algorithms have not yet dealt with this issue very well. A baseline estimation model constructed for each single spectrum will generate a peak spectrum after a baseline has been estimated and removed from each spectrum.
