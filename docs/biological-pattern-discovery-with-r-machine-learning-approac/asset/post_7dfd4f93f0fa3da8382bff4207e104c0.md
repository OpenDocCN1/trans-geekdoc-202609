## 2.4.4 Gene essential pattern discovery using multivariate models

Rather than using a univariate approach for gene essentiality pattern analysis [Langridge, et al., 2009; Zomer, et al., 2012; Yang, et al., 2017], it is useful to consider a multivariate approach, such as the K-means algorithm and the fuzzy C-means algorithm as well as the mixture models.

### 2.4.4.1 The multi-statistics multivariate model

First, three transposon statistics (the insertion statistic, the site statistic and the MF statistic) were joined together, i.e., treated as three variables, to construct a multivariate cluster model for gene essentiality analysis for this data set. The K-means model (kmeans), the fuzzy C-means (cmmeans) and the Gamma mixture model (mixR) and the Gaussian mixture model (mixtools) were constructed.

Both the K-means model and the fuzzy C-means model predicted 442 essential genes meaning these 406 genes had strong essentiality compared with other genes. Figure 2.48 shows the result. In this Venn diagram, it can be seen that the disagreement between four models became smaller. The coincident rate between four models was about 86.02% among 472 predicted essential genes by four models.

## Summary

Responsive gene discovery is a subject for filtering out non-responsive genes and discovering responsive genes for further investigation in an experiment under a stress. Such an exercise has become more and more challenging because most modern biology experiments are undertaken genome-wise and this is the so-called big data era. Big data needs novel methods to deal with. This chapter has shown how unsupervised machine learning approaches can be used for responsive gene discovery, in which there is normally no a priori knowledge about how to separate responsive genes from non-responsive genes. Various density estimation approaches and cluster analysis algorithms have been introduced and demonstrated in association with the main subject of this chapter, i.e. responsive gene discovery. In addition, the principles, the working procedures and the technical implementations in R have been introduced as well. However, the gene essentially pattern discovery still needs more substantial improvement. One important issue, which has not yet been fully solved, is the uncertainty of transposon distribution resulting from various early-stage data preparation errors, from sample preparation, to sequencing and to alignment. An error in every step may cast an accuracy or an effectiveness problem in the gene essentiality pattern discovery. How to properly incorporate these uncertainties for a better gene essentiality pattern discovery certainly needs more effort.
