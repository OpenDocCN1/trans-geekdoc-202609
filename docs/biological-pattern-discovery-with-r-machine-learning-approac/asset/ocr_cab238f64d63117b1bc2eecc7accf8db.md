# Spectral Pattern Discovery 211

In most situations, the function of a baseline is unknown and will not be in an analytic format. Importantly, the background structure or the baseline (curve) varies with the spectrum across experiments and samples. This therefore leads to the difficulty in analysing the spectrometric data for detecting chemicals or molecules from a spectrum. This difficulty has resulted the development of various algorithms for baseline estimation.

There are mainly three types of baseline estimation algorithms. The first type is to fit a smoothing spline to a spectrum (Hastie and Tibshirani, 1990). The fitting is based on a pre-defined model structure, i.e., the smoothing order or the smoothing degree. These algorithms have a typical advantage of simplicity and therefore have been widely used in a variety of applications for discovering chemicals or molecules from spectra data including the Raman spectrum [Shusterman, et al., 2000; Fonseca, et al., 2015; Schulz, et al., 2019; Monteiro, et al., 2020]. However, these algorithms have a typical limitation because a model structure must be defined and the baseline removal performance is closely related with a priori design of a smoothing degree [Froning, et al., 1988]. These algorithms also have a problem to effectively deal with some complicated baseline structures [Perperglou, et al., 2019].

The second type of baseline estimation algorithms is to use the wavelet smoothing technique, or the wavelet decomposition and integration approach [Price, et al., 2008; Restrepo-Agudelo, et al., 2017]. The approach assumes that a spectrum has a typical property that a high wave intensity corresponds to a chemical peak (or a signal) and a low wave intensity represents a baseline value. Therefore two types of spectroscopic patterns can be separated by decomposing two types of wave intensities. The wavelet approach has also been applied to the Raman spectrometric data [Hwang, et al., 2005; Alimov, et al., 2019]. However, this approach suffers a problem that an optimised threshold should be carefully determined between the low and high wave intensities [Hu, et al., 2007].

The third type of algorithms for baseline estimation is the least squared error approach (LSE). LSE has been the most and widely adopted one for the estimation of a baseline in a spectrum.
