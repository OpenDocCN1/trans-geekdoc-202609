A volcano plot is a two-dimensional visualisation of the discovered DEGs and employs the fold change (biological significance) as its x-coordinate and the base negative logarithm of the p values (the statistical significance) as its y-coordinate. Each gene is located in this two-dimensional space as a point. Using this technique, the distribution of discovered DEGs can be visualised and analysed for biological significance and statistical significance.

The limma package has a function named volcanoplot. Below is the code of drawing a volcano plot for the prostate cancer data using this. In this code, coef=2 is consistent with the aforementioned point that β2 or in the second column of coefficients corresponds to the limma fold change or the modified fold change. Moreover, highlight=10 instructs the function to highlight top genes with the smallest p values in the resulting volcano plot. Figure 6.8 shows such a volcano plot.

```
volcanoplotplot(sam.model, coef=2, highlight=10)
```
