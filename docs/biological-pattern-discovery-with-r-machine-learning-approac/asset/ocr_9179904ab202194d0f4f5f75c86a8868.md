# Genetic-Epigenetic Interplay Discovery

A lm model is composed of the regression model parameters ($\alpha$ and $eta$). The estimated regression coefficient for this data set was 9.23. When the stone weight increased by one unit, the oil content in olives increased for 9.23 units in this data set. This is consistent with what it has been generalised in Figure 4.11.

Oil.content = 20 + 9.23 \times Stone.weight (4.23)

To derive regression statistics, the summary function was called whose input was the model constructed by lm for the olive oil content data,

```
stat=summary(model)
```

This statistics object (stat) contained the statistics include $R^2$ and the F-statistic $p$ value. $R^2$ for this data was 0.1962. It was accessed using the following code,

```
stat$r.squared
```

The F-statistic $p$ value was 0.000155. Therefore, the null hypothesis $\mathcal{H}_0: F = 0$ was rejected. This statistics object contained a coefficient matrix, which was obtained by using the following code,

```
coef=data.frame(coefficients(stat))
```

The regression coefficient $p$ value was 0.000155, the null hypothesis that $\mathcal{H}_0: \beta=0$ was rejected. The access to the regression coefficient $p$ value can be made using `coef$Pr[2]`, where [2] pointed to the row of the coefficient matrix or the second entry of the $p$ value vector,

The confidence bands were obtained by calling the predict function. When calling this function, the first input was the regression model constructed by lm and the parameter interval was specified as confidence,

```
bands=predict(model,interval='confidence')
```
