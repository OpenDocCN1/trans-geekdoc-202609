
## Gene Expression Pattern Discovery

![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_289_0.png)

An expression is included in the initial tight cluster (z+) if it satisfies the following condition, where xi stands for either a control expression or a case expression and the tight cluster box is sized by four standard deviations (-2σ and +2σ) from the left to the mean of the tight cluster μ,

$z^+ = U \{xi|xi \in [\mu - 2\sigma, \mu + 2\sigma]\}$ (6.17)

In this way, the initial tight cluster is composed of part or all control expressions and maybe a few case expressions. The rest of expressions, which can be some control expressions and case expressions, are treated as the candidate outliers. The outlier list is denoted by z-. They are then sorted in an ascending order. As in [Yang and Yang, 2013], each candidate outlier is tested one by one in terms of its relationship with the tight cluster. The one in the candidate list, is most close to the tight cluster box z+ defined above, is selected for testing at the first. If the relationship is significant, this candidate outlier is merged into the tight cluster z+ and the parameters of the tight cluster are updated. The merged outlier is removed from the candidate set z- and the test continues. If a candidate outlier cannot be merged into the tight cluster, a search process is terminated. At this point, all the rest candidates in z- are treated as the outliers or the outstanding case expressions for a DEG. To do so is because the initial candidate list has been ordered. If the first of the remaining candidates in z- cannot be merged into the tight cluster z+, all the rest of candidates cannot be merged into the tight cluster well.

## Biological Pattern Discovery with R

As usual, a control expression vector is denoted by **x** and a case expression vector is denoted by **y**. A joint expression vector is composed of all expressions and is denoted by **z = U(x,y)**. A tight Gaussian cluster is denoted by **z+**. A tight cluster box is defined as above, i.e., $\omega = [\mu - 2\hat{\sigma}, \mu + 2\hat{\sigma}]$ for 95% of a Gaussian confidence interval. A candidate outlier set **z-⁻** is composed of all expressions which are not included in the tight cluster set **z+** and is denoted by

$z^- = \{z_i^- | z_i^- \in \omega\}$ (6.18)

Based on the initial tight cluster **z+** and an initial candidate outlier set **z-**, an adaptive learning process is implemented using the Bayesian learning mechanism [Yang and Yang, 2013]. The likelihood function of the Gaussian tight cluster is defined as below, where **i** is an identity vector and $\beta = \sigma^{-2}$

$\mathcal{L}(z^+|\mu, \beta) = \frac{\beta}{2\pi} \exp(-\frac{1}{2}(z^+ - \mu i)^2)$ (6.19)

For this Gaussian likelihood function, one *a priori* structure for the inverse variance $\beta$ is defined as an inverse Gamma

$IG(\beta|a, b) = \frac{b^a}{\Gamma(a)} \beta^{-(1+a)}\exp(\frac{b}{\beta})$ (6.20)

A prior for the mean $\mu$ is defined as a Gaussian function,

$G(\mu|\mu_0, \sigma_0^2) = \frac{1}{\sqrt{2\pi\sigma_0^2}} \exp(-\frac{(\mu - \mu_0)^2}{2\sigma_0^2})$ (6.21)

The log-posterior of the likelihood combined with priors leads to the following format, where the model parameter set is $\theta = (\mu, \beta)$ and the hyper-parameter set is $\alpha = (\mu_0, \sigma_0^2, a, b)$,

$logP(\theta|z^+, \alpha) \propto \alpha log\mathcal{L}(z^+|\mu, \beta) + logIG(\beta|a, b) + logG(\mu|\mu_0, \sigma_0^2)$ (6.22)

In the equation above, the log-likelihood is simplified as below,

$\log\mathcal{L}(\mathbf{z}^+|\mu, \beta) \propto \frac{1}{2}\log\beta - \frac{1}{2}\beta(\mathbf{z}^+ - \mu)^2$ (6.23)

The log-prior $\beta$ is defined as follows,

$\log IG(\beta|a,b) \propto a\log\beta + (a+1)\log\beta - b\beta$ (6.24)

The log-prior of $\mu$ is defined as follows,

$\log G(\mu|\mu_0, \sigma_0^2) \propto \frac{1}{2}\log\sigma_0^2 - \frac{(\mu-\mu_0)^2}{2\sigma_0^2}$ (6.25)

The optimisation follows the procedure of maximising a posteriori [Bishop, 2006]. The process is implemented in two steps, i.e., the expectation step and the maximisation step. In the expectation step, the posterior is calculated based on both model parameters and hyperparameters. In the maximisation step, the model parameters and hyperparameters are updated based on the evaluated posterior. The update of $\mu$ is shown below [Yang and Yang, 2013]

$\mu = \frac{\beta \mathbf{z}^+ + \beta_0 \mu_0}{n + \beta_0}$ (6.26)

The update rule for $\beta$ is shown below,

$\beta = \frac{n+2a}{\sum_i(\mathbf{z}_i^+ - \mu)^2 + 2b}$ (6.27)

The update rule for $\beta_0$ is shown below,

$\beta_0 = \frac{a+1}{(\mu-\mu_0)^2/2+b}$ (6.28)

Based on the analysis above, a $t$ statistic is defined as below, $\mathbf{z}_i^- \in \mathbf{z}^-$ is the first candidate outlier in $\mathbf{z}^-$ or the one most close to the tight cluster,

$t_i = \frac{\mathbf{z}_i^- - \mu}{\sigma}$ (6.29)

For this new $t_i$ statistic, a threshold is defined as $t_\alpha$ based on a confidence level $\alpha$ (0.05). If $|t_i| \le t_\alpha$, $z_i^-$ is predicted as a non-outlier and is removed from the candidate list,

$z^- = z^- \setminus z_i^-$ (6.30)

This candidate outlier $(z_i^-)$ is also inserted into the cluster set,

$z^+ = z^+ \cup z_i^-$ (6.31)

If $t_i > t_\alpha$, $z_i^-$ is predicted as an outlier (perhaps a high extreme outlier) and the examination of $z_j^+ > z_i^+, \forall z_j^+ \in \mathbf{z}^+$ is terminated. If $t_i < -t_\alpha$, $z_i^-$ is predicted as an outlier (perhaps a low extreme outlier) and the examination of $z_j^- < z_i^-, \forall z_j^- \in \mathbf{z}^-$ is terminated.

## 4.4.8 Discover DEGs when outlier genes are present

A simulated toy data set was generated for the demonstration of discovering DEGs when outliers are present. In this data, 40 non-DEGs and 50 up-regulated DEGs as well as 50 down-regulated DEGs were designed. The replicate number was 20. The number of outliers varied from one to five. Outliers were inserted into 10% of non-DEGs. This means 40 non-DEGs had outliers. Outliers were also inserted into 20% of DEGs. Therefore, ten down-regulated DEGs and ten up-regulated DEGs had outliers. Figure 6.18 shows three types of genes in this simulated toy data. Figure 6.18(a) shows a non-DEG in which one control replicate and one case were the outliers. In Figure 6.18(b), two control replicates were the outliers for an up-regulated DEG. In Figure 6.18(c), two case replicates were the outliers for a down-regulated DEG.

When outliers appear, the traditional $t$ test may not work well. Even the modified $t$ test may not work. Figure 6.19 shows an experiment of how the presence of outliers in the data has led to misleading result using the $t$ test. The error statistics were also included in the figure. From zero to ten down-regulated DEGs were misclassified. From six to ten down-regulated DEGs was ten and the maximum number of up-regulated DEGs was ten. There was no prediction error for the non-DEGs using the $t$ test. Therefore, no Type I error that the $t$ test was very sensitive to outliers, especially when the outlier number was increased.
