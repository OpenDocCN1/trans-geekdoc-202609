# 5.4 The spline smoother

A spline smoother is used to fit a pre-defined spline function to a spectrum so as to filter out peaks to estimate a baseline (Hastie and Tibshirani, 1990). It also employs a regularised constant. If a wavenumber variable (spectra analyser) is denoted by $w$ and a baseline function $s(w)$ is at least twice-differentiable, the roughness of a function or a curve is defined as below, where $w_1$ and $w_2$ are used to define the boundary of a spectrum,

```
$R = \int_{w_1}^{w_2} (s''(w))^2 dw \quad (5.4)$
```

If the order of a spline function $s(w)$ is greater than one, $s(w)$ is thus twice-differentiable. Suppose a spline function is shown below,

```
$s(w) = aw^3 + bw^2 + cw + d$
```

Its second derivative is still a continuous function of $w$,

```
$s''(w) = 6aw + 2b$
```

Similar to WH, the error between a baseline and observed spectrometric data (intensity) is defined as below, where $w_i$ is the $i^{th}$ spectra analyser value of a spectrum and $b_i$ is the baseline intensity corresponding to $w_i$,

```
$E = \sum_{i=1}^{n} (b_i - s(w_i))^2 \quad (5.5)$
```

A regularised spline is defined as below, where $\lambda$ is the regularisation constant,

```
$O = \sum_{i=1}^{n} (b_i - s(w_i))^2 + \lambda \int_{w_1}^{w_2} (s''(w))^2 dw \quad (5.6)$
```

The value of the regularisation constant requires to be optimised for an optimal estimation of a baseline for a spectrum
