# 7.4.2.3 The pattern discovery power

It is also interesting to examine whether the word length (the k value of the k-mer approach) matters. Based on the above two comparisons, the k value varied from two to six to examine whether the accuracy of alignment-free approach can be maintained. Figure 7.15 shows the result. It can be seen that when the word length increases, the correlation between the alignment distance and the k-mer-distance decreases. This means that it is better to use shorter words for using the alignment-free approach for sequence comparison so to maintain the discovery power.
