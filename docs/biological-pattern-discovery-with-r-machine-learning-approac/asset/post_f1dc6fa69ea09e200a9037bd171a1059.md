### 8.3.2.5 Single-chromosome crossover

The single-chromosome crossover operation only happens to one single elite RPN chromosome. There are also two ways for the single-chromosome crossover operation, which are the same as the dual-chromosome crossover operation, i.e. swapping operators or not.

If there is no subtree in an elite RPN chromosome, such as xy*, no self-crossover is implemented for this kind of elite RPN chromosome. If there are more than one subunit (subtree) in this selected elite RPN chromosome, two of them are randomly selected. After two subunits have been selected, an elite RPN chromosome is chopped into five segments, which are expressed as below, where $\theta_1$ and $\theta_2$ stand for two selected subunits (subtrees) for a swap operation, i.e., a single-chromosome crossover operation,

$(\theta_1 \quad \mu \quad \theta_2 \quad \rho) \quad (8.3)$

| x y + | * | 4 x | * + y * |
| x z | * | 4 x y | * + y * |

### 8.3.2.6 The training of a GP model

A GP training process is implemented in an iterated process. To start a GP learning process, a pool of randomised RPN chromosomes are generated. Within each iteration of a learning process, the first job is to measure the fitness of each RPN chromosome to a given data set. The fitness measurement is composed of two parts. They are the model accuracy and the length of an RPN chromosome. in terms of their fitness measurements to a data set. The latter is used to award more parsimonious RPN chromosomes.

Suppose a problem is a regression question. The target variable or the dependent variable of a regression model is denoted by $y$ and the output of a model described by an RPN chromosome is denoted by $\hat{y}$. The sum of the squared errors between them is defined as below, where $N$ is the total number of the observed target values, $y_i$ and $\hat{y}_i$ stand for the $i^{th}$ observed target value and the $i^{th}$ predicted value from a model defined by an RPN chromosome,

$$\varepsilon = \frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i - y_i)^2 \quad (8.5)$$

Suppose the length of an RPN chromosome is denoted by $\ell_m$. The fitness measurement is defined as below, where $m$ is the $m^{th}$ model described by an RPN chromosome, $0 < \alpha < 1$ for the trade-off constant, $\varepsilon_m$ stands for the sum of the squared errors for the $m^{th}$ RPN chromosome,

$$\varepsilon_m = \alpha\times\varepsilon_m + (1 - \alpha)\times\ell_m \quad (8.6)$$

The two terms of the above fitness measurements need to be as small as possible. The best model is determined by the following equation, where $M$ stands for the number of RPN chromosomes in a pool, $\vartheta^*$ stands for the best model described by a RPN chromosome, which has the least fitness value,

$$\vartheta^* = \text{argmin}{\vartheta_m}, \forall m \in [1, M] \quad (8.7)$$

For a classification problem, $\epsilon_m$ can be replaced by a classification accuracy measurement such as the area under an ROC curve (AUC). Suppose it is denoted by $\omega_m$. The fitness measure is revised as below, where $\sigma(\ell_m)$ is the sigmoid function of the size of the $m^{th}$ RPN chromosome,

$$\varphi_m = \alpha \times \omega_m + (1 - \alpha) \times \{1 - \sigma(\ell_m)\} \quad (8.8)$$

In the equation above, $0 \le \omega_m \le 1$ and $0 \le \sigma(\ell_m) \le 1$ are constrained. The above fitness must be maximised to discover the best model described by an RPN chromosome, i.e.,

$$\varphi^* = \text{argmax}{\varphi_m}, \forall m \in [1, M] \quad (8.9)$$

The fitness measurements of $M$ models expressed by $M$ RPN chromosomes have been measured, the $M$ RPN chromosomes are sorted in an ascending order for a regression problem and in a descending order for a classification problem.

The $M$ RPN chromosomes are divided into two parts. One part with the optimal fitness measurements is named as an elite set of RPN chromosomes and the corresponding models are called the elite models. The rest of RPN chromosomes are called non-elite ones. The task which follows is to use the elite chromosomes to create or breed new chromosomes to replace the non-elite chromosomes. Doing this is in that the newly generated chromosomes may produce new models with better fitness measurements than the old non-elite models. Therefore the next task is to breed new RPN chromosomes based on the elite RPN chromosomes.

In each iteration of a GP learning process, either the mutation operation, or the dual-chromosome crossover operation or the single-chromosome crossover operation is randomly selected for breeding new RPN chromosomes based on the elite RPN chromosomes.

For a mutation operation, the slot of each non-elite RPN chromosome is replaced by a new RPN chromosome mutated from a randomly selected elite RPN chromosome. For dual-chromosome crossover operation, the slots of two non-elite RPN chromosomes are replaced by two new RPN chromosomes generated through the crossover operation based on two randomly selected elite RPN chromosomes. These new RPN chromosomes are inserted into the non-elite chromosome set. For the single-chromosome crossover or self-crossover operation, only one elite RPN chromosome is selected. This new chromosome is inserted into the non-elite chromosome set.

To demonstrate how GP works, a simple function approximation (or called a regression) problem was used. The function was designed as below, where $x, y$ and $z$ were three variables, $t$ was the function output and $\varepsilon$ was the regression error,

$$t = (z - x) * (z + y) + \varepsilon$$

The introduction of an error term was based on the assumption that observed data may be corrupted with a noise. The error term in this function was following a normal distribution, $\varepsilon\sim\mathcal{G}(0,0.1)$. For this function, 300 data points were generated. Figure 8.21 shows the distribution of the target values, i.e., the $t$ values. The pool size was designed as 100. The elite set size was 10 and the non-elite set size was 90. The value of $\alpha$ was 0.9. The maximum learning cycle was 100. The other termination rule was designed as the stabilisation of the fitness measurement. If the fitness measurement is maintained and unchanged in ten cycles (shown in the equation below), the learning was terminated, with $\delta = 1e-6$,

$$\frac{1}{N} \sum_{i=1}^{N} (t_i - \hat{t}_i)^2 \le \delta$$
