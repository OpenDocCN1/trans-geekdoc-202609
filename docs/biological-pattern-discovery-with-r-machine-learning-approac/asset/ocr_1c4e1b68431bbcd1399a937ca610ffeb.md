# 2.3.4 The mixture model cluster analysis algorithm

The mixture model algorithm is also a partitioning algorithm [Pearson, 1984; Day, 1969; McLachlan and Basford, 1988; Bishop, 2006]. Its basic principle is similar to the semi-parametric density estimation approach, i.e., it is a mixture of a few components such as the Gaussian components or the Gamma components. A final density is a linear combination of a finite number of components.

Suppose the $k^{th}$ cluster is centred at $\mathbf{u}_k$ with a covariance matrix $\Sigma_k$. The membership function is defined as a probability $p(\mathbf{x}_n|\mathbf{u}_k, \Sigma_k)$, while the objective function is defined as the likelihood function below, where $p(\mathbf{x}_n|\mathbf{u}_k) \in \mathcal{R}^d$ is a member of the $k^{th}$ cluster, $w_k \in [0,1]$ is the mixing coefficient of the $k^{th}$ cluster,

```
$0 = \prod_{n=1}^{N} \sum_{k=1}^{K} w_k p(\mathbf{x}_n|mathbf{u}_k, \Sigma_k) = \prod_{n=1}^{N} p(\mathbf{x}_n) \quad (2.26)$
```
