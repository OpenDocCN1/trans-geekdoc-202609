A regression model can be univariate or multivariate depending on the number of the repressors or the independent variables employed in a regression model. In a univariate regression model, only the relationship between two variables is examined. One variable is an independent variable (x) and the other is a dependent variable (y). The relationship claims that y can be explained or interpreted by x in a linear way. Its formal notation is shown below, where $\alpha$ is the intercept, $eta$ is the regression coefficient and $\epsilon$ is the regression error

```
$y = \alpha + \beta x + \epsilon$
```

In the above equation, $\epsilon$ interprets how the regression model is and $eta$ interprets how $y$ depends on $x$. For instance, when one unit has happened in $x$, $eta$ units change will happen in $y$ accordingly. Figure 4.3 shows such a model.
