$$\epsilon = \sum_{k=1}^K \sum_{n=1}^N f_{nk}|\mathbf{x}_n - \mathbf{u}_k||^2$ (2.21)

The derivative of this quadratic error function leads to the direction of error minimisation or the update of cluster centres. The K-means centre update rule is thus derived and shown, where $N_k = \sum f_{nk}$ is the number of data points clustered into the $k^{th}$ cluster,

$$\mathbf{u}_k = \frac{1}{N_k} \sum_{n=1}^K \mathbf{x}_n$ (2.22)

Now, a data set composed of seven data points (Figure 2.22) was used to demonstrate how the K-means algorithm works. In this example, seven data points marked by $a, b, c, d, e, f$ and $g$ were guaranteed to belong to two clusters, which were marked by **A** and **B**. Figure 2.22(a) shows two initial cluster centres, which were denoted by $\mathbf{u}_A^0$ and $\mathbf{u}_B^0$. They were random values at this stage. These two initial cluster centres ($\mathbf{u}_A^0$ and $\mathbf{u}_B^0$) were certainly very different from the true cluster centres. However, they will change during a learning process.

Each of seven data points was assigned a membership function value one to a cluster where the distance between them was the least and zeros otherwise. A membership function value one was thus assigned between $a$ and **A** because they had the least distance, so between $b$ and **A**. A membership function value one was assigned between $c$ and **B**, $d$ and $e$ and **B**, $f$ and **B** as as $g$ and **B**. All other membership function values were assigned zeros. This is shown as the arrows in Figure 2.22(b) and the panel named by **Step 1** in Table 2.7.
