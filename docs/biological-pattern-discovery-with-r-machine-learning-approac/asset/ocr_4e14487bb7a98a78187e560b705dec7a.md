
In the above equations, $f(k|x_i)$ is defined as below,

```
$$f(k|x_i) = w_k \frac{\mathcal{G}(x_i|\mu_k,\sigma_k^2)}{f(x_i)}$$\quad (2.12)
```

The major difference between the non-parametric (kernel) approach and the semi-parametric approach is the number of kernels or components. Each data point is perhaps used as a kernel in a kernel-based density estimation model. Sometimes, a subset of data points is employed as the kernels in a kernel-based density estimation model. All kernels of a kernel-based model normally employ an identical variance, i.e., $\sigma_1^2 = \sigma_2^2 = \dots = \sigma_M^2 = \sigma^2$ supposing $M$ kernels are employed in a model. In a semi-parametric model, the number of components is much smaller than the number of kernels. Moreover, the components of a semi-parametric model have different variances, i.e., $\sigma_1^2 \neq \sigma_2^2 \neq \dots \neq \sigma_M^2$ if $M$ components are employed.

Figure 2.13 shows a comparison between a kernel-based model and a semi-parametric model for a data set. A kernel-based model constructed for this set is shown in Figure 2.13(a), in which a random sample of 20 data points were used as the kernels. A semi-parametric model constructed for the same data set is shown in Figure 2.13(b), in which two Gaussian components were used. Although two density estimators result in a similar density function, their basic principles are different and their computational costs are different as well. A kernel-based model is less costing when it is constructed, but is costing when it is used for the inference on new data. A semi-parametric model requires more time to construct, but it is computationally cheap when it is used for the inference on new data.
