Although an essential gene should not attract any transpos insertion theoretically, a transpos may be found in an essential gene because of several reasons [Lamichhane, et al., 2003; Deng, et al., 2013; Fels, et al., 2013]. For instance, the essentiality of a gene may not be disrupted if a transpos is inserted within the distal regions of a gene because the truncated gene product may still retain functionality. Often, the essentiality of a gene may still maintain if a transpos is inserted in only a few sites of a gene. In addition to these biological reasons, there are also two technical reasons by which it is required to examine the transpos insertion pattern genome-wise to avoid missed discovery of essential genes. First, the transpos sequencing technology is not yet 100% accurate to distribute a transpos to the locations where it should go without any bias. Second, aligning short transpos sequencing reads to a reference genome will not be free of error. The shorter the sequencing reads for an alignment, the greater the error will be. Therefore, a few insertions occurring in a gene may be caused by either error or errors aforementioned.

Due to the aforementioned reasons, there have been three updated machine learning approaches for a robust gene essential pattern analysis based on the high-throughput transpos sequencing technology. First, a gene with a few insertion sites may be classified as an essential gene [Langridge, et al., 2009]. Second, a gene with a few insertions may also be classified as an essential gene [Zomer, et al., 2012]. Third, a gene with the transpos insertions only in its distal regions may also be classified as an essential gene [Yang, et al., 2017].

The density estimation approaches have been exercised for discovering essential genes for a long time. In the context of gene essentiality analysis, the basic principle of density estimation is to re-construct a density function, which is unknown in advance, for a transpos statistic such as the transpos insertions per gene statistic or the transpos insertion sites per gene statistic. A constructed density model is thus used for the interpretation and prediction. The assumption is that such a density function should show a bimodal distribution, in which a cutting point can be effectively determined to separate genes into two clusters. After a division, one cluster is composed of genes with smaller transposon statistic values and the other cluster is composed of genes with greater transposon statistic values. The cluster of genes with smaller transposon statistic values is therefore treated as an essential gene cluster. Several density estimation algorithms have been developed for identifying essential genes based on some genome-wise transposon statistic [Langridge, *et al.*, 2009; Zomer, *et al.*, 2012; Yang, *et al.*, 2017]. Different models for essential gene discovery are based on different assumptions of the nature of transposon insertion profile. TraDIS discovers essential genes through estimating a density function based on the transposon insertion sites per gene statistic [Langridge, *et al.*, 2009]. ESSENTIALS discovers essential genes through estimating a density function based on the transposon insertions per gene statistic [Zomer, *et al.*, 2012]. DEM (distinct effect model) discovers essential genes through estimating a density function based on the mutation feature statistic which is the convolution between the transposon insertions per gene and the transposon insertion sites per gene [Yang, *et al.*, 2017].

In addition to density estimation, cluster analysis can also be considered when dealing with the problems for separating essential genes from non-essential genes, especially in the context of multivariate analysis.

## 2.2 Density estimation

Very often, the future inference is required based on the knowledge learned from collected experimental data through a pattern discovery and analysis process. Various density estimation approaches are such a process of re-constructing an unknown data distribution from which data are believed to be sampled or drawn [Silverman, 1986; Duda, *et al.*, 2000]. For instance, a mean value and a standard deviation can be estimated for a data set if the data set is assumed to be a sample drawn from a Gaussian distribution. After these two parameters have been well-estimated, a distribution model of the data set can be constructed and be used for the future inference for novel data.

It should be noted that an estimated density based on a collected data set may have some deviation from the expectation. This is not a surprise because a drawn sample always has a much smaller size than a whole distribution. Therefore, the density functions estimated based on different samples drawn from the same distribution will be more or less different. Figure 2.1 shows five estimated functions for five data sets drawn from a Gaussian distribution with a zero mean and a unit standard deviation. The population statistics (the mean and the standard deviation) shown in Figure 2.1 are all slightly different from the expectation. One of the important objectives of density estimation is thus to estimate a density function for a data set as accurately and as precisely as possible. A density function can be estimated using several approaches. The following sections introduce several commonly used ones as well as their implementations in the R environment.

### 2.2.1 The histogram approach

The histogram approach is the simplest approach for density estimation [Pearson, 1985]. Its basic principle is to count data points which fall in several pre-defined bins and use these counts to profile a density function for a data set.

Figure 2.2 shows how a histogram is constructed for the gene itself of the Francisella Tularensis species in a gene Essentials pattern analysis project [Yang, et al., 2017]. The gene attracted 7,753 transposon insertions. These insertions were distributed across 180 sites within the gene. The gene base pairs were between 3,204 and 3,988 in the genome. The transposon insertion sites were between 3,207 and 3,980 base pairs.

The top-left panel of Figure 2.2 shows the insertion spectrum of this gene. To analyse transposon insertions in this gene were distributed, eight bins were designed. The top-right panel of Figure 2.2 shows nine boundaries for eight bins, which had the same size. For each bin, the insertions of the transposon were counted and recorded. Each recorded count or frequency was expressed as a bar with the height which was the same as the transposon insertions within a bin. For instance, 1,277 insertions were within the boundaries of the first bin. Therefore the height of the first bin was recorded as 1,277. The bottom-left panel of Figure 2.2 shows this histogram of the transposon insertion distribution of this gene. The bottom-right panel of Figure 2.2 shows the probability density of the transposon insertions of this gene. Based on this histogram, the distribution pattern can be analysed.
