To remove some baseline artifacts, the median values are calculated for local windows and the Gaussian smooth function used in this algorithm is defined as below, where $w$ is the window size, $M_j$ is the median of a local window indexed by $j$ and $\mathcal{G}(n)$ is a Gaussian function, \n\n$b_i$ is defined as

```
$b_i = \sum_{j=i-\frac{w}{2}+1}^{i+\frac{w}{2}} M_j\mathcal{G}(i-j) \quad (5.15)$
```
