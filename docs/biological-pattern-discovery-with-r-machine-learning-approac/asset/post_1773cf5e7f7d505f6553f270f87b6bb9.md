This kind of error is named as a Type I error. A Type II error, on the other hand, refers to a falsely accepted null hypothesis. In the context of gene differential expression analysis, a Type I error refers to a wrongly predicted DEG and a Type II error stands for a wrongly predicted non-DEG, i.e., a missing DEG [Li, *et al.*, 2013; Mudge, *et al.*, 2017; Gonzalez, *et al.*, 2020].

The Type I and II errors occur often in an experiment especially when the sample size of a data is small. This is because it is often to prepare a few replicates to cut the expenses in many biological experiments. A severe outcome for a data set with insufficient replicate is an unreliable population variance in addition to an unreliable population.

In the letrozole drug data which employs 58 baseline replicates and 58 letrozole replicates, the gene EHD2 is a DEG and the gene STAT1 is a non-DEG. Suppose subset of replicates is randomly drawn from 58 replicates for these two genes. It is interesting to observe how the differential expression status of these two genes change. For this investigation, the Type I and II errors were counted. The drawing number from two to 50. For each draw sample with a specific replicate number, 100 random simulations were carried out and hence 100 $t$ test $p$ values were calculated using the $t$ test. # 6.2 Microarray gene expression analysis

Having understood from the above analysis that the t test may not be robust when the replicate number is small, a question is how to deal with this difficulty. A direct consideration is to compensate the denominator of the t statistic, or modify it as to make it suitable to data with insufficient replicate number. An approach called the significant analysis for microarrays (SAM) has been proposed to adjust the denom of a t statistic for this purpose. The method is called the modified t test [Tusher, et al., 2001]. It has a wide application in gene expression pattern analysis [Cecchini, et al., Tsuda, et al., 2018; that, et al., 2019]. How to improve the performance of the modified t test still draws the attention in the community [Zhang, 2007; Li, et al., 2013; Tzeng, 2021]. The modified t statistic used in the modified t test is defined below,

```
t = \frac{\hat{\mu}_A - \hat{\mu}_B}{\sigma(X_A, X_B) + \alpha}
```

where $\alpha$ is positive and is the focal point of the research of gene expression analysis for DEG discovery. A $p$ value calculated based on this modified $t$ statistic is called a modified $p$ value. When $\alpha$ is introduced, the t statistic will be reduced. The consequence is a greater $p$ value. Theoretically, the chance of introducing the Type I error in a DEG discovery process is reduced using this modified $t$ test. However, if $\alpha$ is too large, the chance of introducing the Type II error will be increased. How to accurately estimate $\alpha$ is then a question of the research. To estimate the best value for $\alpha$, the traditional $t$ test, which is only applied to one gene, has been replaced by the modified $t$ test, in which the statistical significance values for all genes are estimated in one model.

# 6.2.1 The limma package

The *limma* (Linear Models for MicroArrays) package [Smyth, 2004] is one of the best ones so far for employing the modified $t$ test for gene expression data generated using the microarray technology. In *limma*, a mathematical approach called the shrinkage approach was used to estimate $\alpha$. The package was developed by Gordon Smyth and his colleagues and has been included in the Bioconductor environment. The package has been widely used to discover DEGs for the microarray gene expression data [Lorenz, et al., 2019; Nilson, et al., 2020]. It has also been used to analyse RNA-seq gene expression data this kind of data has a different distribution [Mou, et al., 2020].

In limma, the $p$ values are calculated using an approach called the empirical Bayes (eBayes) [Smyth, 2004; McCarthy and Smyth, 2009]. By using the shrinkage approach, the standard deviations of genes are moderated by the package making the extreme values move towards centre of a distribution. From this, significantly differentially expressed genes will have greater fold changes.

To use the *limma* package, especially the eBayes function of the package to discover DEGs based on the microarray gene expression data, a gene expression matrix is required to be generated in rows and samples in columns.

The first thing limma does is to generate a linear model. To do so, a design matrix is required, which defines the experimental conditions, i.e., how replicates distribute in two experimental conditions. A prostate cancer diagnosis data set (GSE3325) [Varambally, et al., 2005] was used for the demonstration. The data was composed of six primary cancer samples as well as six metastasis cancer samples. The code shown below was used to generate a design matrix which is shown in Table 6.1.
