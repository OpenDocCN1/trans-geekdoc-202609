# 2.3.2 The K-means cluster analysis algorithm

The K-means cluster analysis algorithm as the simplest partitioning clustering algorithm partitions data into clusters through estimating cluster centres based on a pre-defined cluster number [MacQueen, 1967]. Its main feature is the use of the hard membership function to define the relationship between a data point and a cluster. Suppose there are three clusters. The hard membership function indicating how a data point belongs to clusters may be expressed by a vector which is either (0, 1, 0) or (0, 0, 1) or (1, 0, 0). A one entry means the belongingness relationship and a zero entry means the irrelevance relationship. Constructing a K-means model is fast due to the use of this hard membership function.

Because of its simplicity, the K-means cluster analysis algorithm has been one of the most popular ones for biological/medical pattern discovery research. For instance, it has been used to improve quantitative susceptibility mapping, oxygen extraction fraction as well as cerebral metabolic rate of oxygen [Cho, et al., 2020]. It has been used to model time evolution image data based on healthy subjects as ischemic stroke patients and the result shows that such model can significantly influence analysis robustness. In searching for MRI biomarkers of residue for clinical impact assessment, it has been used to discover how the computation of cerebral blood volume in postprocessing steps on a population of 49 subjects with low- and high-grade gliomas [Bell, et al., 2020].

The key point of the K-means algorithm is to find the cluster centres, i.e., the means. Once the centres have been found, each data point is assigned with a membership vector, which is composed of either a zero or a one.
