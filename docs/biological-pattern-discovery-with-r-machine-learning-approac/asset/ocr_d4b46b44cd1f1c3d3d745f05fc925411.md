# Responsive Gene Discovery

Suppose it is required to estimate the density function for a data set named by x and suppose such a density is a mixture of two Gaussians with known parameters. The following code can be used,

```
w1*dnorm(x, mean=mul, sd=sigma1) +
w2*dnorm(x, mean=mu2, sd=sigma2)
```

The above approach requires the component parameters to be known in advance. The component parameters of a mixture model can be estimated using an R package mclust, for which the R function is named as Mclust,

```
Mclust (x, G=NULL, ...)
```

The first input is a vector or a matrix. The second input is to define the component number or set of the component numbers. The second input can be a scalar to specify the component number. For instance, using as G=3 will employ three components. It can also be a vector such as G=2:5, which means that a density estimation estimation process will try four models using two, three, four and five components. The function finds the best model to fit a data set among these models.

The main output of the Mclust function includes a component number of a Gaussian mixture ($G) and the component parameters, which are in $parameter. The $parameter object includes the mixing coefficients ($pro), the mean values ($mean) and the variances ($variance) for an estimated density function. Here a toy data was used to demonstrate how it works,

```
x=c(-0.24,-1.24,0.74,0.38,1.49,0.19,0.30,
-0.99,0.58,-0.46,1.17,-2.89,-2.04,
-0.82,0.92,0.91,-0.88,1.06,0.95,0.44,
-1.16,-1.12,10.75,4.05,3.23,
7.85,-1.56,4.21,9.34,0.05)
```

When the Mclust function was called to estimate a density function for this data set, G was set for employing two Gaussian densities for a mixture,

```
model=Mclust(x,G=2)
```
