```
$$p_A = \frac{\pi_A f_A}{\pi_A f_A + \pi_B f_B}$
$p_B = \frac{\pi_B f_B}{\pi_A f_A + \pi_B f_B}$ (1.15)$
```

These two posterior probabilities have the properties, $0 \le p_A, p_B \le 1$ and $p_A + p_B = 1$. Using these two probabilities, the Bayes rule is defined as below,

```
$$Z = \begin{cases} A & p_A > p_B \ B & p_A \le p_B \end{cases}$ (1.16)$
```

or

```
$$Z = \begin{cases} A & p_A > 0.5 \ B & p_A \le 0.5 \end{cases}$ (1.17)$
```
