# 4.6 The constrained regression analysis algorithms

OLR and GAM do not apply a constraint to the model parameters. Therefore, these algorithms do not provide an efficient ranking mechanism for independent variables. In a constrained regression analysis, the parameters of a model are assumed to follow a pre-defined distribution or are bounded to a constant. Therefore the model parameters will be constrained, i.e., a competition scheme is introduced. With this competition scheme, the variables of a regression model will compete each other to win within a constraint. In other words, independent variables will press down unimportant independent variables because the space for all variables is limited.
