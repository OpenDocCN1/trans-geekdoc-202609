The model parameters are estimated by maximising the posterior (Bishop, 2006), giving the iterative variance update formula below,

```
$$\sigma_m^2 = \frac{\sum_i \vartheta_{i,m}z_i^2 + 2b_m}{\sum_i \vartheta_{i,m} + 2a_m} \quad (6.51)$
```

where $\vartheta_{i,m}$ is defined as,

```
$$\vartheta_{i,m} = \frac{w_m\mathcal{G}(z_l|\mu_m, \sigma_m^2)}{f(z_l|theta)} \quad (6.52)$
```

The iterative update rule for the mixing coefficients can be written as,

```
$$\w_m = \frac{1}{n} \sum_{i=1}^n \vartheta_{i,m} \quad (6.53)$
```

and the iterative update rule for each centre is, where $\mu_{m0} = 0$,

```
$$\mu_m = \frac{eta_m\sum_i \vartheta_{i,m}z_i + 2v_m\mu_{m0}}{\beta_m\sum_i \vartheta_{i,m} + 2v_m} \quad (6.54)$
```
