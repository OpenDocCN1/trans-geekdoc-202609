# 6.3 DEG discovery for RNA-seq sequencing count data

Along with the significant cost reduction of the sequencing technology, analysing gene expression pattern or detecting differentially expressed genes based on sequencing count data has been more and more popular in biological/medical research. The sequencing count data are normally generated using the next-generation sequencer such as the so-called Illumina machine [Behajati and Tarpey, 2013; Forde and O’Tool, 2013; van Dijk, et al., 2014]. A next-generation sequencer generates short sequences, which are normally 100 base pairs long or shorter. Such a short sequence is called a sequencing read. One of the major applications of the sequencing count data is the transcriptome data for gene differential expression pattern discovery [Crowgey, et al., 2020; Goswami and Harada, 2020]. Therefore, the majority of the sequencing count data used for discovering differentially expressed genes is called the RNA-seq count data.

It must be noted that an individual sequencing read has no biological meaning. The biological meaning of sequencing reads can be investigated only when they have been aligned or mapped to a reference genome. There are several packages for mapping or align sequencing reads to a selected reference genome, such as BWA [Li and Darwin, 2009] and Bowtie [Langmead, et al., 2009]. An active gene may attract a greater amount of sequencing reads while an inactive gene may attract little or no sequencing reads. Only after sequencing reads have been mapped (aligned) to a reference genome, it is possible to assess whether a gene is more active and less active than other genes depending on the number of sequencing reads which hit the gene. The direct outcome of the mapping from sequencing reads to a reference genome is a sequencing count matrix across genes and replicates. Only after such a matrix has been generated, discovering DEGs based on sequencing count data can then follow.
