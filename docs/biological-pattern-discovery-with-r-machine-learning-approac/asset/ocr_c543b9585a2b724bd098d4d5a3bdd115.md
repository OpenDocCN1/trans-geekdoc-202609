# 3.6.3.1 The bio-basis function neural network algorithm

The bio-basis function neural network (BBFNN) has been developed based on this idea, i.e., mapping a non-numeric peptide space to a numerical space which is supported by the homology alignment scores between peptides using an amino acid mutation matrix [Thomson, et al., 2003; Yang and Berry, 2004; Berry, et al., 2004; Yang and Chou, 2004b; Senawongse, et al., 2005; Yang, et al., 2005; Yang, 2005b; Yang, 2005c; Yang and Thomson, 2005; Sidhu and Yang, 2006; Yang, et al., 2006; Yang and Hammer, 2007; Maji and Das, 2010; Maji and Das, 2010b].

Suppose a peptide is denoted by $x_n$ and its functional status is denoted by $y_n \in [0,1]$, which is either functional (cleaved) or non-functional (non-cleaved). Suppose set of cleaved peptides is denoted by $\Omega^+$ and a protease cleavage discovery problem is a discrimination problem. It is well-understood that only cleaved peptides will show the amino acid composition trend. Moreover, a basis used in a basis function neural network mode is served as a supporting coordinate in the kernel space. Such a supporting coordinate must be composed of rich information. Non-cleaved peptides are certainly non-informative. Therefore, only cleaved peptides are employed as bio-bases in BBFNN.
