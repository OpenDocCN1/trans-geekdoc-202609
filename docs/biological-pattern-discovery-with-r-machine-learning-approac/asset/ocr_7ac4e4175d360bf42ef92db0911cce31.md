The outputs of the kmeans function include several sums of squares. The output named as withinss is a vector and is called the withincluster sum of squares. Each entry of the vector is the variance of the cluster, i.e., the within-cluster variance. Such a variance is the sum of the squared distances between the centre of the cluster and all data points which have been classified into the cluster. The output named as tot.withinss is the sum of withinss and stands for the total within-cluster variance. It is denoted by $S_W^2$. The output named as betweenss stands for the sum of the squared distances between the cluster centres and is named as the betweencluster variance. It is denoted by $S_B^2$.

In summary, two statistics (tot.withinss or $S_W^2$ and betweenss or $S_B^2$) can be used to assess the performance of a cluster model. Based on $S_W^2$ and $S_B^2$, the well-known $F$ statistic used in ANOVA can be considered for optimising a K-means model structure.
