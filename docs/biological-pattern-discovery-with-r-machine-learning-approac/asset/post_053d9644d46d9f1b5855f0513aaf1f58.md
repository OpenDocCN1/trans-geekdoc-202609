## 5.7.4 The fitness of a BWH model

For a simulated data set, it is possible to examine whether the discovered (merged and unique) peaks are correct. The following equation can be used to detect whether the discovered peak locations (the spectra analyser value) of a merged or unique peak across replicated, where $p_i$ stands for the $i^{th}$ location (spectra analyser value), $y_i$ stands for the true peak location, $y$ stands for a vector of all true peak locations and $\delta y$ stands for the difference between consecutive peak locations. The value of $\varepsilon$ was 0.054 in a BWH model constructed for the simulated data shown in Figure 5.5.

```
$\varepsilon = \frac{1}{\min(\delta y)} \sum_{i=1}^{N}(p_i - y_i)^2 \quad (5.32)$
```

## 5.7.5 Aligning peaks for replicated spectra

The aforementioned was used to estimate a baseline for a single spectrum. For a data set composed of multiple spectra, an update is required. Suppose

### Spectral Pattern Discovery

A peak spectrum is expressed as below, where w is an error threshold, which is heterogeneous across a whole spectrum and p is an extracted spectrum,

```
p = s - b - w (5.33)
```

A spectra intensity is thus treated as a peak only when the following condition is satisfied, i.e., p_l > 0. Here, a peak is assumed to correspond to a true signal. Due to any possible variation, it may not be possible for a discovered peak to have an identical spectra analyser value, i.e., the value shown at the horizontal axis of a spectrum, across replicates in a spectra data. However, the spectra analyser values across replicates for a true peak are assumed to have a relatively small variation and this variance is significantly smaller than the distance between true peaks. Therefore, an alignment process is required when discovering peaks for spectra data with multiple replicates. The main purpose of using an alignment process is obvious, i.e., removing false signals and the confusion across replicates. The other assumption for applying an alignment process to the discovered significant peaks in a replicated data set is that a peak corresponding to a potential true signal should occur in most replicates. Instead, a false signal may present in one replicate by a chance.

Unlike analysing a single spectrum, estimating baselines and extracting peak spectrum based on a spectra data with multiple replicates needs some update to the t vector. The new t vector is defined as below,

```
t_i = 1 - r_i = 1 / (1 + exp[-kE_m(s_mi - b_mi - w_m)]) (5.34)
```

Such a t vector is called a global anchor. In the equation, k1 is a large positive number, which was set 100 as default [Lau, et al., 2012], E_m stands for the expectation across replicates and m is used to index the $m^{th}$ spectrum. The use of such a sigmoid function is to make it differentiable. The derivative of r_i is called an entropy and is shown below,

```
r_i' = r_i(1 - r_i) (5.35)
```

The noise threshold variable w is assumed to follow a Gamma distribution. Therefore the model posterior of replicated spectra is as below, where $\Theta$ stands for a set of model parameters and $\mathcal{H}$ stands for a set of hyper-parameters,

```
$f_{B|E}(\mathbf{B}) \propto f_{E|B}(\mathbf{E})f_B(\Theta)f_{\theta|\mathcal{H}}(\Theta) \quad (5.36)$
```

The posterior for monitoring replicated spectra is defined as below,

```
$f_{B|E}(\mathbf{B}) \propto \prod_{m=1}^M (\sigma_{m,S}^2)^{-\omega_S}(\sigma_{m,F}^2)^{-\omega_F} \exp(-\sum_{m=1}^M v_m w_m^{\alpha_w-1}) \quad (5.37)$
```

In the above equation, $v_m$ is defined as,

```
$v_m = \frac{e_t^m \Gamma_m}{\sigma_{m,F}^2} + \frac{d_t^m}{\sigma_{m,S}^2} + \frac{\beta_{m,F}}{\sigma_{m,S}^2} \quad (38)$
```

The noise threshold variable $w$ can be estimated by maximising the posterior and is shown below,

```
$w_m = \beta_w + \frac{1}{2M \sigma_{m,F}^{-2} e_m^t}{\alpha_w-1} \quad (39)$
```

In the above equation, $\mathbf{H}$ is a matrix and is defined as

```
$\mathbf{H} = \text{diag}(\{r_i(1-r_i)\}_{i=1}^N \quad (40)$
```

The next is the derivative of the error term $t_i(s_i-b_i)^2$. Because there is a sigmoid term in the expression of $t_i$, the derivative is slightly complicated. Therefore, a linear approximation is used in BWH which is shown below,

```
$t_i(s_i-b_i) + r_i(1-r_i)(s_i-b_i)^2 \approx t_i(s_i-b_i) \quad (41)$
```

```
$\alpha_W, \beta_W \longrightarrow w$
$\alpha_F, \beta_F \longrightarrow \sigma_F^2$
$\alpha_S, \beta_S \longrightarrow \sigma_S^2$
```

## 5.8 Analyse the milk spectra data

The milk spectra data was saved in baseline. The data was used in an early study [Liland, et al., 2009]. The data was composed of 45 spectra. The data was generated using the MALDI-TOF spectrometry technique and the purpose of the research was to identify proteins, peptides including some compounds from the spectra data [Liland, et al., 2009]. The peak intensities were identified at each measured mass-to-charge (m/z), i.e., the spectral analyser. Figure 5.20 shows the estimated baseline for one of 45 spectra using BWH.

The milk data also contains the cow milk concentration percentage. It is therefore useful to investigate how the spectra pattern of the data set associated with the cow milk concentration percentage. For this investigation, each spectrum was converted to a set of variables using the short-term Fourier transform. The R package wavelets was used for the short-term Fourier transform of the spectra of this data set.

The visualisation was carried out through a process in which the 45 replicates were mapped to different neurons, which were arranged as a two-dimensional array of cells. Cell is one neuron on this array. If two spectra profile were mapped to the same neuron (cell), it is believed that these two spectra profile shared a great degree of similarity compared with others. In addition, similar spectra were supposed to be mapped to neighbouring neurons (cells). The R package kohonen was used for this data visualisation.

The self-organising map for this data set was composed of 36 neurons on which each of 45 spectra data was mapped with a cow milk concentration percentage printed on the cells of the map. Some neurons attracted no spectrum, some attracted one spectrum and attracted more than one spectrum.
