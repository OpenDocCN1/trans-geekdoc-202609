
# Biological Pattern Discovery with R

The following code was used for estimating the density function for the malignant tumours supposing the data was saved in a matrix x the malignant tumours were labelled by M in the class label x$class,

```R
malignant=x$radius[x$class=='M']
mu=mean(malignant)
sigma=sd(malignant)
y=dnorm(sort(malignant),mean=mu,sd=sigma)
hist(malignant,nclass=50,prob=TRUE)
lines(sort(malignant), y)
```

Here y is a y-coordinate vector representing a density function estimated using the dnorm function. The histogram approach was used at first to generate a density function with the prob parameter switched on. Next a smooth density curve was added using the parametric density estimation approach. Figure 2.8 shows the densities of the malignant tumour radius and the benign tumour estimated using the above code.

![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_38_0.png)

Figure 2.8. The densities of two types of tumours estimated using the parametric approach for the tumour radius of the breast cancer data. (a) The malignant tumour density. (b) The benign tumour density.

Using the dnorm function for the parametric density estimation is under the assumption that a data set follows a Gaussian distribution. The data interval of a Gaussian distribution is between $-\infty$ and $\infty$ comprising all real numbers. In fact, some features of this breast cancer data will not be negative such as the tumour area. In order to estimate a better density for such a feature, the Gamma distribution can be used. The R function for estimating a Gamma density function for a data set is dgamma. The format

# Responsive Gene Discovery

of this call is shown below, where shape and rate are two distributional statistics,

```R
dgamma(x, shape, rate, ...)
```

These two distributional statistics can be estimated using the density fitting function named as fitdist in the MASS library before calling the dgamma function. The function is a generic one to estimate the distributional statistics for a variety of density functions. Given a vector x, the syntax of this function is shown below, where densfun is the parameter to specify a density function such as Gaussian or Gamma or others,

```R
fitdist(x, densfun, ...)
```

The tumour area feature of the breast cancer diagnosis set was expected to follow a Gamma distribution, the following code was used to estimate two distributional statistics (the shape and the rate parameters) for the feature, which malignant was generated using the same way as above for the tumour radius

```R
model=fitdist(malignant, densfun='gamma')
```

The statistics of this function include the shape and the rate parameters of a Gamma density function. Next, the dgamma function was called to estimate a Gamma density function for this breast tumour area feature,

```R
shape=model$estimate[1]
rate=model$estimate[2]
y=dgamma(sort(malignant), shape=shape, rate=rate)
```

Figure 2.9 shows the resulting densities of the benign tumours and the malignant tumours using this method for the tumour area feature of the breast cancer data. It can be seen from both plots that each estimated density using the parametric approach fits the raw density estimated using the histogram approach very well. This shows that if the density format is known in advance, the parametric approach is a good alternative to estimate a density function for a data set. The major advantage of the

parametric approach is obvious, i.e., the knowledge of data density can be saved using a number of distributional parameters.
