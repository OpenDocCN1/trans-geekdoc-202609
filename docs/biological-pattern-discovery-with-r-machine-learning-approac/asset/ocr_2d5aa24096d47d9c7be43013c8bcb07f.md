# 4.5 The Bayesian linear regression algorithm

The Bayesian learning provides a more robust approach to model parameter estimation. The Bayesian linear regression algorithm (BLR) is such an example [Buerkner, 2017]. The posterior probability of a BLR model can be calculated based on following definition,

# $$p(w|y,X) = \frac{p(y|X,w,\Sigma) \times p(w|\alpha)}{p(y|X)}$$\quad (4.32)$

where $w$ and $\Sigma$ stand for the regression coefficients and the covariance matrix, $\alpha$ stands for the hyper-parameter of the $a priori$ structure for $w$. The likelihood function is shown below, where $\varepsilon = X^Tw - y$.

# $$p(y|X,w,\Sigma) = \frac{1}{(2\pi)^{N/2}\sqrt{\Sigma}} \exp\left(-\frac{1}{2}\varepsilon^T\Sigma^{-1}\varepsilon\right)$$\quad (4.33)$

A Gaussian $a priori$ structure is defined as below, where $d$ stands for the number of independent variables,

# $$p(w|\alpha) = \left(\frac{\alpha}{2\pi}\right)^{d/2} \exp\left(-\frac{\alpha}{2}w^Tw\right)$$\quad (4.34)$

Other $a priori$ structures can also be used in BLR algorithm [Buerkner, 2017]. The $R$ package $brms$ can be used for constructing a model for a data set using BLR. The $R$ function for BLR in this package is named as $brm$. The call of this $R$ function is shown below,

```
brm.model=brm(formula, data, family)
```
