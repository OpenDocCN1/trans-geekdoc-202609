Although GAM can model some nonlinear data, it still belongs to the theme of linear algorithms as the estimation of the parameters of a GAM model follows a similar procedure as that used to construct an OLR model using LSE. A vector-matrix format of a GAM model is shown below, where $\mathbf{y} = (y_1, y_2, \dots, y_N)$ stands for a vector as a dependent variable for $N$ data points, $\mathbf{\beta} = (eta_0, \beta_1, \beta_2, \dots, \beta_K)$ stands for a vector of model parameters for $K$ splines of $K$ independent variables and $\mathbf{S}$ stands for the spline function matrix,

```
$\mathbf{y} = \mathbf{S} \times \mathbf{\beta} + \varepsilon$
```

The spline matrix $\mathbf{S}$ which is composed of an interceptor variable is shown below,

```
$\mathbf{S} = \begin{pmatrix} 1 & S(x_{11}) & \dots & S(x_{1K}) \ 1 & S(x_{21}) & \dots & S(x_{2K}) \ \vdots & \vdots & & \vdots \ 1 & S(x_{N1}) & \dots & S(x_{NK}) \end{pmatrix} (4.29)
```
