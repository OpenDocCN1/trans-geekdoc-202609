The procedure of the gap maximisation test is therefore designed as below. First, all the delta expressions are calculated using equations (6.39) and (6.40). These dealth expressions are saved in a variable named as Δ shown below,

```
$$\Delta =(\delta_1, \delta_2, \dots, \delta_M)$$ (6.41)
```

where $M = N \times (K-1)$ is the number of all the delta expressions for a data set with $N$ genes and $K$ replicates. Note that all the expressions of $\Delta$ should be positive. However, in case there might be identical expressions within some genes, zero delta expressions may occur and be removed from $\Delta$ if they present before proceeding to the following stages. It is assumed that $\Delta$ follows a Gamma distribution which is shown below,

```
$$\Delta\sim G(\delta|\alpha, \beta) = \frac{\beta^{\alpha}\delta^{\alpha-1}e^{-\beta\delta}}{\Gamma(\alpha)}$ (6.42)
```

After two parameters $\alpha$ and $\beta$ have been estimated, the Gamma density function is then used for evaluating the gene-wise delta expression significance, i.e., to calculate a $p$ value for each delta expression of each gene.

The gene expressions of real data often contain outliers. It is therefore required to distinguish between outliers and bimodality. If there are one or few replicates far away from the main expression cluster for a gene, these replicates should be treated as the outliers. This is because they can hardly form a subpopulation for the further meaningful biomedicine investigation. In other words, a phenomenon does not lead to the conclusion of a bimodal gene. Any outlier it has been discovered, will be removed. Afterwards, whatever there is more significant delta expression is examined again for the gene. If so, the gene is treated as a multi-modal gene or a bimodal gene.
