Suppose the initial data set of the 20 amino acids is denoted by

> $\mathcal{D} = (A, C, D, E, F, G, H, I, K, L, M, N, P, R, Q, S, T, W, V, Y)$

Figure 2.17 shows a hierarchical clustering tree generated for this amino acid data set. In this hanging tree, it can be seen that the amino acids R and Y were the first pair of the amino acids to be merged from $\mathcal{D}$ because they had the least distance compared with all other pairs of the amino acids. The mean descriptor vector of the amino acids R and Y, which was $\omega_{RY}$, was inserted into $\mathcal{D}$. After the merge of the amino acids R and Y, $\mathcal{D}$ had the following structure, where $\omega_{RY}$ represents the mean descriptor vector of the amino acids R and Y,

> $\mathcal{D} = (A, C, D, E, F, G, H, I, L, K, M, N, P, Q, S, T, W, V, \omega_{RY})$
