
$\mathbf{y} = (y_1, y_2, \dots, y_N)^t \quad (4.11)$

The independent variable is denoted as a matrix and is shown below, where the first row is an identity vector used for the intercept parameter $\alpha$,

$\mathbf{X} = \begin{pmatrix} 1 & & \dots & 1 \\ x_1 & x_2 & & \dots & x_N \end{pmatrix} \quad (4.12)$

The LSE estimation of model parameters is shown below, as $(\mathbf{X}^T\mathbf{X})^{-1}$ is called the pseudo inverse,

$\hat{\mathbf{w}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} \quad (4.13)$

Given estimated weight vector $\hat{\mathbf{w}}$, the final regression model is written as,

$\hat{\mathbf{y}} = \mathbf{X}\hat{\mathbf{w}} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} \quad (4.14)$

Note that $y$ and $\hat{y}$ have different meanings. The former is a vector of the observations and the latter is a vector of the regressed means or the outputs (predictions) of a regression model. This can easily extended to some multivariate OLR models. In addition to LSE for estimating the model parameters for a regression model, other approaches such as the Bayesian approach [Box and Tao, 1973] can also be used to estimate the regression model parameters.

The study of the regression model fitness aims to measure how good a regression model is in relationship with the regression error. The R-squared (also denoted as $R^2$), which is also called a coefficient determination, is one of the measurements. It measures how good a regression model fits data regardless of how a model is constructed [Steel and Torrie, 1962]. The definition of $R^2$ is shown below, which is metric-free, hence can be used for comparing different models constructed on different data,

$R^2 = 1 - \frac{\sum_{n=1}^N \varepsilon_n^2}{(N-1)\sigma^2} \quad (4.15)$

The explanation of the $R^2$ is shown below,

$R^2 = 1 - \frac{\text{variance explained by a model}}{\text{total variance}} \quad (4.16)$

If $R^2 = 1$, a regression model fits the data completely because the variance explained by a regression model is zero. In other words, there is no distance between the observations and the regressed means in a model. If $R^2 = 0$, a regression model completely fails to fit the data because the total distance between the observations and the regressed means is the same as the variance of the dependent variable. Figure 4.7 shows three scenarios where the fitness measurement was from the largest (0.9531) to the smallest (0.0049). Through comparing these three models, it can be seen that the model shown in Figure 4.7(a) was the best with the highest fitness measurement while the model shown in Figure 4.7(c) was the worst with the lowest fitness measurement.

The other useful statistic which has been used in ANOVA can also be used to measure the fitness of a regression model. It is a ratio of two variances and is called the Fisher-statistic or the F-statistic. In regression analysis, this $F$-statistic is replaced by a different ratio and is called the F-test [Johnston, 1972]. The null hypothesis for using the F-test for assessing the fitness of a regression model is $H_0: F = 0$. The test of the null hypothesis is done by calculating a $p$ value for the significance analysis of the $F$-statistic. The $F$-statistic is defined as below,

$F = \frac{\text{explained variance}}{\text{explained variance}} \quad (4.17)$

Suppose $N$ is the number of data points, $K$ is the number of variables which are employed as the independent variables in a regression model. The explained variance is defined as below, where $\hat{y}_n$ is the model, $\bar{y}$ stands for the mean of model outputs, i.e., $\bar{y} = \sum_{n=1}^N \hat{y}_n / N$,

$\frac{\text{corrected sum of squares}}{\text{corrected degrees of freedom}} = \frac{\sum_{n=1}^N(\hat{y}_n - \bar{y})^2}{K} \quad (4.18)$

The unexplained variance is defined as below,

$\frac{\text{sum of squares for errors}}{\text{degrees of freedom for error}} = \frac{\sum_{n=1}^N(\hat{y}_n - y_n)^2}{N - K} \quad (4.19)$

## 4.3.3 The significance analysis of regression coefficients

The next question is the significance analysis of regression coefficients with importance of the independent variables in a regression model. It examines whether an independent variable is significantly correlated with the dependent variable. If an independent variable has significant correlation with the dependent variable, it is believed to have a significant contribution to the dependent variable. To examine whether an independent variable has a significant contribution to the dependent variable, another statistical test is required. This is done by testing a null hypothesis, $H_0: \beta_i = 0$ for each regression coefficient. It calculates the following statistic [Weisberg, 2005], where $\hat{\beta}_i$ is the estimated regression coefficient for the $i^{th}$ independent variable,

$t = \frac{\hat{\beta}_i}{se(\hat{\beta}_i)} \quad (4.20)$

where $se(\hat{\beta}_i)$ is calculated using the following formula and $\mu_{x_i} = \sum_{n=1}^N x_i/N$,

$se(\hat{\beta}_i) = \sqrt{\frac{\sum_{n=1}^N(\hat{y}_n - y_n)^2}{\sum_{n=1}^N(x_i - \mu_{x_i})^2}} \quad (4.21)$

Two regression models are shown in Figure 4.9. Both had a large degree of noise (variance). The regression coefficient was 0.3606 in Figure 4.9(a) and was 0.0102 in Figure 4.9(b). Their $p$ values were 0.0192 and 0.9328 in Figures 4.9(a) and (b), respectively. This answered the question whether an independent variable was significantly correlated with the dependent variable or whether an independent variable had a significant contribution to the dependent variable in a regression model.
