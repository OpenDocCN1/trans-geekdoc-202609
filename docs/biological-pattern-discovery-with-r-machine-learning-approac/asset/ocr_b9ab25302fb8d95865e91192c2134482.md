# 3.6.6 Deep neural network

Deep neural network (DNN) is an algorithm of deep learning [Schmidhuber, 2015; Bengio, et al., 2015]. The basic principle of DNN is to integrate feature extraction into a model construction process by increasing the number of hidden layers, where the first hidden layer is used for the feature extraction and selection process [Bengio, et al., 2015]. DNN has been used as human biological polyadenylation coding mechanism [Leung, et al., 2018] and signal peptide recognition [Savoijardo, et al., 2018]. One of the available R packages for DNN is H2O.

For the factor Xa protease cleavage data, a grid search was used to search for the optimal hidden neurons for two hidden layers of the H2O model. The optimisation was varying the hidden neuron number in hidden layers from two to twenty. The feature space was generated using the Dayhoff matrix to measure the similarity between peptides. Therefore this model was called a bio-DNN model. The grid search led to no hidden neurons for the first hidden layer and five neurons for the second hidden layer as the optimal DNN model structure. The first step of using the H2O package was to initialise a H2O environment using the following code,

```
h2o.init(nthreads=-1, enable_assertion=FALSE)
```
