Protease cleavage data are in the format of peptides. A peptide is composed of nonnumerical attributes such as the amino acids or the nucleic acids. A proper treatment of these non-numerical data the encoding process must be considered because not all the machine learning algorithms can accept non-numerical inputs. In addition to the commonly used binary encoding, this chapter has introduced an alternative encoding approach which has biological significance. This novel encoding method is called the bio-basis function. This alternative does not treat the residues of a peptide as the independent variables. Just like the move from the 1980s’ edit distance-based homology alignment to the 1990s’ mutation-based homology alignment, the introduction of the bio-basis function has updated the binary encoding method. When being integrated with different discriminant analysis algorithms, the bio-basis function can be efficiently used for a better protease cleavage pattern discovery as shown in several cases in this chapter. Importantly, they show different outstanding features for protease cleavage pattern discovery. For instance, the mixture bio-DNN benefits the use of multiple mutation matrices, leading to the improved performance in peptide cleavage pattern discovery. Through the integration between the bio-basis function with the random forest algorithm, the cleaved de-novoed peptides which are most close to the probable prototype can be discovered. This thus provides some important information for the efficient inhibitor design. Besides, this cutting-edge approach can be well used for similar biological/medical discovery tasks.
