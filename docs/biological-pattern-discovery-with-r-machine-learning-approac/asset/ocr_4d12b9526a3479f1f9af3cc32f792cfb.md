# Summary

This chapter has discussed several issues of the gene expression pattern discovery. Importantly, this chapter has discussed the issues which commonly occurred in biological/medical gene expression data analysis. They are the outlier problem, the bimodality gene problem and the insufficient replicate problem. For each of these issues, several methods or algorithms have been introduced and compared in this chapter. However, none can be uniquely superior to the others so far. There is still a great space for improving these methods or developing new algorithms in the future. For instance, the DSG is required to be extended to multidimensional space gene expression modelling based on the current work. It is also required to have a unified approach for detecting heterogeneous DEGs and bimodal genes.
