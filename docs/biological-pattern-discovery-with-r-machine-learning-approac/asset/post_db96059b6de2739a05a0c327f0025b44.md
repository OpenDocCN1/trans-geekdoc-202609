A regression model can be univariate or multivariate depending on the number of the repressors or the independent variables employed in a regression model. In a univariate regression model, only the relationship between two variables is examined. One variable is an independent variable (x) and the other is a dependent variable (y). The relationship claims that y can be explained or interpreted by x in a linear way. Its formal notation is shown below, where $\alpha$ is the intercept, $\beta$ is the regression coefficient and $\epsilon$ is the regression error.

```
$y = \alpha + \beta x + \epsilon$
```

In the above equation, $\epsilon$ interprets how the regression model is and $\beta$ interprets how $y$ depends on $x$. For instance, when one unit has happened in $x$, $\beta$ units change will happen in $y$ accordingly. Figure 4.3 shows such a model. The relationship between two variables in this univariate regression model is defined as,

## 4.3 The ordinary linear regression analysis algorithm

The simplest analysis approach is the ordinary linear regression algorithm (OLR). Without using any constraint, the parameters of an OLR model are estimated using the simplest approach, i.e., the least squared error approach. The approach estimates model parameters through minimising the total regression error.

### 4.3.1 The least squared error approach

Establishing an OLR model requires the model parameters $(\alpha$ and $\beta)$ to be estimated using the least squared error approach (LSE). In a regression model, an error is defined as the distance between an observed outcome $y$ and a predicted outcome $\hat{y}$ from a regression model. $\hat{y}$ is also called the regressed mean variable or the model output variable or the regression prediction variable. In order to use LSE to estimate model parameters, the property of regression errors should be introduced at first.

First, $\hat{y}$ is obtained or predicted from a regression model after the model parameters $(\alpha$ and $\beta)$ have been accurately estimated. The distance between $\hat{y}$ and $y$ is named as the regression error, which is defined below, where the regressed mean function is as $\hat{y} = \alpha + \beta x$,

```
$$\varepsilon = y - \alpha - \beta x = y - \hat{y} \quad (4.7)$$
```

There are three pairs of $x$ and $y$, which are denoted by $(x_1, y_1)$, $(x_2, y_2)$ and $(x_3, y_3)$ as shown in Table 4.1. If a regression model has been constructed for them, there will be three model outputs as well. Note that both $x$ and $y$ are experimental data, and $\hat{y}$ takes three values for three values of $x$, i.e., $\alpha + \beta x_1$, or $\alpha + \beta x_2$ or $\alpha + \beta x_3$. The regression model outputs are individually denoted by $\hat{y}_1$, $\hat{y}_2$ and $\hat{y}_3$ of this data. $\hat{y}$ is a vector of the regressed means. The final regression function is an interpolated curve based on these regressed means.
