Summarising the predictions in different categories and compare the predictions against the desirable categories converts a prediction table shown in Table 3.2 to a confusion matrix shown in Table 3.3. In this table (confusion matrix), each entry is a summary statistic generated from a prediction table shown in Table 3.2. For instance, Table 3.3 shows that four data points of class A were correctly predicted and one data point of class A was incorrectly predicted. Moreover, three data points of class B were correctly predicted and two data points of class B were misclassified.

Table 3.3: An example of a confusion matrix derived from Table 3.2.

| Predicted A | Predicted B | % |

| true B | 2 | 3 | 60 |
| % | 67 | 75 | 70 |
