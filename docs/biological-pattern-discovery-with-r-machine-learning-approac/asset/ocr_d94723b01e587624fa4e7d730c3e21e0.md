# 3.6.3.3 The orthogonal kernel machine

A BBFNN model is expressed as **y = Sw+e**, where the matrix **S** has K columns. The orthogonal least square algorithm is a forward kernel selection procedure [Chen, et al., 1991]. The use of the orthogonal least square algorithm for BBFNN has led to a new version of BBFNN, which is named as the orthogonal kernel machine (OKM) [Yang, 2005c]. At each kernel selection step, the incremental information content is maximised. The feature matrix is re-written as **S = (z₁, z₂, ..., zₖ)**, where **zₖ** corresponds to **sₖ**. The elements in **zₖ** are the mapping values of all the inputs on **sₖ**. It is obvious that there are correlated or there is some redundancy among kernels **z₁, z₂, ..., zₖ**.
