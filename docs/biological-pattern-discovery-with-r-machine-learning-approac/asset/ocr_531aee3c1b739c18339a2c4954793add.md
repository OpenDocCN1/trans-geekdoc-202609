# 4.6.1 The ridge linear regression algorithm

The ridge linear regression algorithm (RLR) was rooted from the
Tikhonov regularisation [Tikhonov, 1963] and has been exercised for
decades. It is still researched intensively nowadays for improving
its performance and applicability in many areas [Hoer, 1962; Tikhonov,
1963; Dorugade and Kashid, 2010; Roozbeh, et al., 2020]. The reason that
it is still a popular research subject is its incompatible feature in model
interpretation.

The introduction of the Tikhonov regularisation is due to the ill-
condition which often happens to the pseudo inverse (X'X)⁻¹ in a
regression model [Hoer, 1962; Tikhonov, 1963]. The problem arises
before X'X can be singular and its inverse cannot be calculated.
in Tikhonov regularisation, a positive constant λ was introduced into
the formula X'X + λ leading to a matrix, which is invertible all the times.
this has replaced w = (X'X)⁻¹X'y by the following format as
the solution to a RLR model,

```
w = (X'X + λI)⁻¹X'y (4.35)
```

The above equation also satisfies the Lagrange multiplier [Kalman,
2009], where c is a positive constant,

```
min(w - Xw)'t(w - Xw) + λ(w'w - c) (4.36)
```

Another view, RLR is also connected with BLR. Applying negative
logarithm to the Equation (4.32) used in BL leads to the following
formula, where C is a constant,

```
-logp(w|y,X) ∝ β/2|X'w - y|² + α/2w'w - N/2logβ - d/2logα (4.37)
+ C
```
