# 6.5.3 The gap maximisation test approach

The gap maximisation test approach (GM) is another simple approach for gene expression bimodality discovery [Al Watban and Yang, 2016]. The basic idea is to model the density of delta expressions. It is believed that the existence of the bimodality within a gene expression vector may cause a typical decaying Gamma density of the delta expressions of the gene. If such a density can be well-estimated, the expression bimodality can then be well-discovered.
