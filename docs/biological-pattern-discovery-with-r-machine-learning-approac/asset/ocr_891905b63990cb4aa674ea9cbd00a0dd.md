# Responsive Gene Discovery

```
$$\hat{\mu} = E(x) = \frac{1}{N} \sum_{n=1}^{N} x_n$$
$$$\hat{\sigma}^2 = \text{var}(x) = \frac{1}{N-1} \sum_{n=1}^{N} (x_n - \mu)^2$ (2.3)$
```

Based on these Gaussian distributional statistics, an estimated Gaussian density function is defined as below,

```
$f(x) = \mathcal{G}(x|\hat{\mu} \hat{\sigma}^2) = \frac{1}{\sqrt{2\pi \times \hat{\sigma}^2}} e^{\frac{(x-\hat{\mu})^2}{\hat{\sigma}^2}}$ (2.4)$
```

For instance, if a vector $x = (1.3181, 0.1948, -0.1481, -3.2131, 0.0733, -0.6179, -0.7869, -0.4848, -0.3497)$ was expected to follow a Gaussian distribution, but the two distributional statistics ($\mu$ and $\hat{\sigma}^2$) were unknown, the above equations can be used to estimate these statistics. After calculation, the estimated population mean $\hat{\mu}$ was $-0.13$ and the estimated population variance $\hat{\sigma}^2$ was $1.79$ for the data set $x$. The estimated Gaussian distribution for this data set is shown below,

```
$f(x) = \mathcal{G}(x| -0.13, 1.79) = e^{\frac{(x+0.13)^2}{1.79}}}{\sqrt{2\pi \times 1.79}}$
```

```
dnorm(x, mean=0, sd=1)
```

A Gaussian distribution for a data set can be generated based on the estimated population mean and the estimated population variance, i.e., $\hat{\mu}$ and $\hat{\sigma}^2$. Here, the breast cancer diagnosis set [Wolberg, et al., 1994; Wolberg, et al., 1995] was used for this demonstration. The data set was composed of 30 mammographic features for breast cancer diagnosis. The feature named as radius (tumour radius) was used for this demonstration. The benign tumours were separated from the malignant tumours at first.
