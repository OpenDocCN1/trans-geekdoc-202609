In order to improve the learning quality of a MLP model, the above simple update rule has been altered by introducing the momentum term [Rumelhardt, et al., 1986], which is based on the update of the model parameters in the previous learning cycle. The momentum term can efficiently prevent over-update of model parameters. The use of the momentum term is shown below, where $0 < \alpha < 1$ is called the momentum factor.

$\Delta\mathbf{w}^{t+1} = -\eta\frac{\nabla\mathcal{E}^t}{\nabla\mathbf{w}^t} + \alpha\Delta\mathbf{w}^t$ (3.36)

In the above equation, $\Delta\mathbf{w}^t$ stands for the update of $\mathbf{w}$ at the learning cycle $t$ and $\Delta\mathbf{w}^{t+1}$ stands for the update of $\mathbfmathbf{w}$ in the learning cycle $t+1$. It can be seen that the update term $\eta\nabla\mathcal{E}^t/\nabla\mathbf{w}^t$ and the momentum term $\alpha\Delta\mathbf{w}^t$ have different signs, different directions. Whenever the term $\eta\nabla\mathcal{E}^t/\nabla\mathbf{w}^t$ goes too far, the term $\alpha\Delta\mathbf{w}^t$ will pull the move backward slightly. Therefore the momentum term can reduce the oscillation possibility and prevent the potential move from a wrong direction so as to miss the saddle point on the error function curve. As shown in Figure 3.23, it is the move from $x_0$ to $x_3$, which will make the move to the saddle point fast. The other advanced approach for improving the learning capability is the use of the second order derivative, such as the Hessian matrix [Bishop, 1996].
