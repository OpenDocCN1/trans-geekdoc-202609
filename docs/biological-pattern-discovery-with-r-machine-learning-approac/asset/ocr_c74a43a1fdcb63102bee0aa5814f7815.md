# 3.6.1.2 The learning mechanism of MLP

To estimate the parameters of a MLP model, a simple way is to establish an error function, such as

```
$$\varepsilon = \frac{1}{N} \sum_{n=1}^{N} (\hat{y}_n - y_n)^2 \quad (3.33)$
```

Denoting all model parameters using a vector **$\mathbf{w}$** and a data point as **$\mathbf{x}_n$**, the estimation of **$\mathbf{w}$** is an optimisation process

```
$$\hat{\mathbf{w}} = \min_{\arg} \left( \frac{1}{N} \sum_{n=1}^{N} f(\mathbf{x}_n, \hat{\mathbf{w}}) - y_n)^2 \right) \} \quad (3.34)$
```

Because $f(\mathbf{x}_n, \hat{\mathbf{w}})$ is a nonlinear function, there will not be an analytic format of the estimated model parameters such as the used in linear models. Therefore, an algorithm called the back propagation algorithm has been developed to estimate parameters for a MLP model [Rumelhart, et al., 1986]. The back propagation algorithm is a variant of the Newton's method [Fletcher, 1987]. It is based on the derivative function of an error function, which is defined in an equation shown below, where $0 < \eta < 1$ is called the learning rate,

```
$$\Delta\mathbf{w} = -\eta \frac{\nabla\varepsilon}{\nabla\mathbf{w}} \quad (3.35)$
```

The use of the above equation means that the change (update) of every new model parameter is negatively proportional to the derivative function of the error function, $\mathbf{w}^{t+1} = \mathbf{w}^t - \eta\nabla\varepsilon/\nabla\mathbf{w}$. A great derivative points to a steep or sharp curve of the error function. Therefore, a cautious update of the model parameters is required. This cautious move can avoid missing the optimal point (jumping over the saddle point). A small derivative function corresponds to a more curved curve of the error function. Therefore, a greedy or greater update can happen to the model parameters.
