The call of the msa function generated a multiple sequence comparison model using the following code,

```
model=msa(mySeq)
```

The msa function also derives a consensus sequence for sequences under alignment. To show the consensus sequence for these five sequences, the following code was used,

```
show(model)
```

The outcome of the above code is shown below, where the last line shows the consensus sequence for these five sequences.

