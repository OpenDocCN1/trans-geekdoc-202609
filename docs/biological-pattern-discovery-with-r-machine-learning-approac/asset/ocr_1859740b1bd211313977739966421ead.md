# 2.2.5 The multivariate density estimation

In most real applications, multivariate density estimation may need to be considered. The general principle of multivariate density estimation is the same as being used in the univariate density estimation examples aforementioned. There are mainly two R packages for multivariate density estimation ks and kde. The R package for using the kernel approach for estimating a density function for a multi-dimensional data set is ks. The R function of this package for density estimation is kde. Below is an example, where x is a matrix,

```
kde (x, ... )
```
