This bio-basis space was supported by the cleaved peptides for the factor Xa protease data. Afterwards, the party package was used to generate a random forest model. In such a tree, all the cleaved peptides used as the bio-basis functions were ranked. Some peptides were ranked at the top and some were not. Figure 3.51(a) shows such a tree, in which it can be seen that the peptide ULSR was ranked the top, i.e., the most important cleaved peptide. The smallest p value of this peptide indicates its significance as the one which most served the prototype. The next peptides were LQFRU and UWWRU. Figure 3.51(b) shows the ROC curve of this model, where the Dayhoff matrix was used. It is noted that this unique feature may not be feasible in other machine learning algorithms.
