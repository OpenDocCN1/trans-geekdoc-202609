To examine data statistics, the summary function was called. The result of this call is shown below. Based on the base two logarithm fold change, i.e., LFC and a critical p value 0.1, the model identified 1,564 up-regulated genes and 1,193 down-regulated genes. It also shows 39% of low counts and 0.84% outliers within the data set.

```
summary(res.table) #summary of results
##
## out of 25258 with nonzero total read count
## adjusted p-value < 0.1
## LFC > 0 (up) : 1563, 6.2%
## LFC < 0 (down) : 1188, 4.7%

## low counts [2] : 9971, 39%
## (mean count < 10)
## [1] see 'cooksCutoff' argument of ?results
## [2] see 'independentFiltering' argument of ?results
```

This function has a parameter alpha, which stands for a critical p value. Its default value is 0.1. When a critical p value was reduced from 0.1 to 0.01, the new result is shown below, where the DEG numbers were reduced.

```
> summary(res.table,alpha=0.01)
out of 25258 with nonzero total read count
adjusted p-value < 0.01
LFC > 0 (up) : 851, 3.4%
LFC < 0 (down) : 586, 2.3%
```
