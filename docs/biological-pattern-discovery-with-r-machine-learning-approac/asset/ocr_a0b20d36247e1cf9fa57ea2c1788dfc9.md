The output named merge of the hclust function is a matrix of N-1 rows and two columns, i.e., $(N-1) \times 2$ for $N$ data points. The output named as height of the hclust function is a vector of $N-1$ values recording $N-1$ merging heights. A subtree is such a structure, which is a part of the tree below a branch node including the root node. A subtree is called a lower-rank subtree. The subtree of the amino acids F, I, L is a lower-rank tree of the subtree of the amino acids W, F, I and L in Figure 2.17. Note that subtree is also a meta data during a clustering process. A subtree can either be a single data point such as the amino acid R or a lower-rank subtree.
