# 6.6.2 A real data set study

A data set used to analyse breast cell lines to examine how miR-335 expression inhibits metastatic cancer invasion from lung cancer cells into breast cells (GDS3138) [Tavazoie, et al., 2008]. For this data set, the eBayes, the cyberT and the SAMr algorithms were used in addition to the DSG algorithm for the DEG discovery. Figure 6.52 shows the Venn diagram of comparing four models for the data about the numbers of the discovered DEGs. The result shows a great deviation among four models. The numbers of discovered DEGs were 4542, 11794, 879, and 925 by the DSG, cyberT model, SAMr and eBayes models, respectively. Only 660 DEGs were discovered by all four models.

Figure 6.53 shows the distribution of DEGs discovered by four models. It can be seen that the SAMr model and the eBayes model demonstrated a similar pattern of DEGs, the cyberT model had too many discovered DEGs because it extended towards two sides. The DSG model discovered DEGs by calculating gene differential expression between two means, which is similar to the fold change. This is why it had a uniform boundary on both sides.
