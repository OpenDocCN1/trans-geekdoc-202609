# 3.6.7.6 Factor Xa protease cleavage data classification

An important feature of the decision tree algorithms is that they can handle non-numerical data. For instance, both CART and C5.0 can be applied to the factor Xa protease cleavage set directly without an encoding process [Yang, et al., 2006], which was composed of cleaved and non-cleaved peptides. The structure is a string of the amino acids, which are non-numerical. The structure of the factor Xa protease sub-sequences are $R_4R_3R_2R_1R'_1$, where cleavage happens between $R_1$ and $R'_1$. These five residues were labelled as P1, P2, P3, P4 and P5 in data. Figure 3.45(a) shows the CART tree model for this data set and Figure 3.45(b) shows the C5.0 tree model for this data set.
