The following code was used to construct a K-means model, a fuzzy C-means model and a model of the mixture model algorithm, where x was a matrix of the MF statistic for three replicates. All models were constructed for two clusters only, where one cluster was for essential genes and the other was for non-essential genes.

```
kms=means(x, centers=2) # use K-means
cms=cmeans(x, centers=2) # use Fuzzy c-means
mms=Mcluster(x, G=2) # use mixture model
```

The numbers of predicted essential genes were 474, 474 and 435 using the K-means model, the fuzzy C-means model and the model of the mixture model algorithm, respectively. Among them, 433 genes were predicted as essential genes by all three prediction models. The coincidence rate was 90.97% (the highest) for 476 predicted essential genes, demonstrating the powerfulness of a multivariate model to minimise the uncertainty of gene essential analysis for this data set.
