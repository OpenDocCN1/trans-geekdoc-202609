Because of the use of this membership function, especially the use of a covariance matrix, the cluster boundaries of a cluster model constructed by the mixture algorithm will be different from that constructed by the K-means algorithm and the fuzzy C-means algorithm. The clustering boundaries of a cluster model constructed by the mixture algorithm can be elliptic in addition to spheric. The latter is used in both the K-means algorithm and the fuzzy C-means algorithm.
