The uncertainty in the raw multi-dimensional data space is measured by two co-variance matrices for two classes. They are denoted by $\Sigma_1$ and $\Sigma_2$. The relationship between the mapping space variance and the raw space covariance matrices is defined below,

```
$S_W = \mathbf{w}^t(\Sigma_2 + \Sigma_1)\mathbf{w}$ (3.7)
```

Suppose the distance between two mapping centres is denoted by $\tau_2 - \tau_1 = \mathbf{u}_2 - \mathbf{u}_1$. A discrimination ratio as the mapping quality associated with the discrimination power of a classifier is defined as below,

```
$R(\mathbf{w}) = \frac{S_B}{S_W} = \frac{\mathbf{w}^t(\mathbf{u}_2 - \mathbf{u}_1)}{\mathbf{w}^t(\Sigma_2 + \Sigma_1)\mathbf{w}}$ (3.8)
```

If $R(\mathbf{w})$ is optimised (maximised), the mapping vector $\mathbf{w}$ is said to be a good projection direction and is able to maximise the separation between two classes in the raw space. In the projection space, the distance between two mapping centres in the $\hat{y}$ space will be max and the variance of two clusters have an identical covariance matrix, hence an identical volume, i.e., $\Sigma_1 = \Sigma_2 = \Sigma$. Mapping $R(\mathbf{w})$ leads to the solution of a LDA model shown below [Duda, et al., 2000],

```
$\hat{\mathbf{w}} \propto \Sigma^{-1}(\mathbf{u}_2 - \mathbf{u}_1)$ (3.9)
```

In other words, the calculation of the mean vectors $(\mathbf{u}_1$ and $\mathbf{u}_2)$ of the covariance matrix $(\Sigma)$ leads to the solution of the estimated or optimised projection direction $(\hat{\mathbf{W}})$. A simple two-dimensional data set shown in Table 3.1 is used to demonstrate how an LDA model can be constructed using the principle discussed above. ```

# 3.2.4 Making decision using the Bayes rule for a LDA model

Decisions can be made to classify objects by comparing the posterior probabilities. If the probability of class A is higher, the object is assigned to class A, otherwise it is assigned to class B.

The posterior probability of class A given $x$ is calculated as:

$$P(A|x) = \frac{f(x|A)P(A)}{f(x|A)P(A) + f(x|B)P(B)}$$

Similarly, the posterior probability of class B given $x$ is:

$$P(B|x) = \frac{f(x|B)P(B)}{f(x|A)P(A) + f(x|B)P(B)}$$

where $P(A)$ and $P(B)$ are the prior probabilities, and $f(x|A)$ and $f(x|B)$ are the conditional densities.

In LDA, we assume that the conditional densities are Gaussian with a common covariance matrix $\Sigma$. This simplifies the decision rule to a linear boundary.

The decision boundary between two classes is given by:

$$w^T x = \frac{1}{2}(\mathbf{u}_2 + \mathbf{u}_1)^T \Sigma^{-1} (\mathbf{u}_2 - \mathbf{u}_1) + \frac{1}{2}(\mathbf{u}_1^T \Sigma^{-1} \mathbf{u}_1 - \mathbf{u}_2^T \Sigma^{-1} \mathbf{u}_2) + \ln\frac{P(A)}{P(B)}$$

Since the boundary is linear in $x$, the method is called Linear Discriminant Analysis.
