RLR model is degenerated to an OLR model. When $\lambda \to \infty$, the model parameters are shrunk to zero.

The R package glmnet can be used for constructing a RLR model. The code to call this function is shown below,

```
glmnet(x, y, alpha=0, lambda)
```

Figure 4.19 shows how the regression coefficients evolve with the $\lambda$ values in an iterated parameter shrinkage process when RLR was applied to the olive oil data content. The regression coefficients were obtained by calling the glmnet function with the optimal $\lambda$ value as one of the inputs. In 4.19, it can be seen that the regression coefficients became more and more divergent during the learning process. When a subset of regression coefficients increased, the other set of regression coefficients were forced to decrease. Finally, the fruit weight became an outstanding important variable with the largest regression coefficient. The model fitted to the data very well. The R-square of the model was 0.64. The F-statistic value of the model was 5.983e-7.

# 4.6.2 The Lasso linear regression algorithm

In addition to RLR as a constrained linear regression algorithm, Lasso is another one. RLR employs the L2 constraint, i.e., the sum of squared parameters is constrained to a constant. This ensures the shrinkage of a subset of the regression coefficients of the less important variables when a subset of the important variables is increased.
