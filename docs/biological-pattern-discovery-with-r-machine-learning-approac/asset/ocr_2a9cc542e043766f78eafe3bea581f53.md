To construct a SVM model, there are a few things which require attention. They are the kernel function and the kernel parameters of the kernel function. The radial basis kernel with a parameter γ has been widely used in applications for most numerical data, where the distances between data points can be calculated by the Euclidean distance. The radial basis kernel function is defined as,

> Ψ(x, x_n) = exp(-γ(x - x_n)ᵀ(x - x_n))

A breast cancer data set [Wolberg, et al., 1994; Wolberg, et al., 1995] was used for the demonstration. To optimise the γ parameter, a grid search was used for γ to vary from 0.001 to 0.1. Figure 3.31(a) shows how the AUC was varying along with the γ values. Figure 3.31(b) shows the ROC curve for this SVM model employing the best γ value obtained by a grid search, which was 0.053.

The polynomial kernel function used in SVM is defined using three parameters shown as below, d, α and β are two parameters,

> Ψ(x, x_n) = (αᵀx_n + β)^d
