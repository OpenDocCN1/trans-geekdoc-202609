
## Genetic-Epigenetic Interplay Discovery

### 4.9.1 Methylation site to gene — the M2E models

The main objective of this M2E model was set to discover and analyse which of 910 DMSs were the main contributor to each of 1,250 DEGs. Afterwards, it was aimed to investigate whether the top-ranked DMS in a regression model for a DEG was a local or a remote methylation site in the genome. Based on the information, a statistical analysis was carried out to investigate the trend of the methylation-to-expression interplay pattern, i.e., being the local or remote interplay.

Suppose $X_g$ was used to represent a differential expression vector of the $g^{th}$ DEG, which was the target (dependent) variable of a regression model. In such a model, 910 DMSs were treated as the regressors or the independent variables. Moreover, $w$ was used to represent a vector of regression coefficients or model parameters for 910 regressors and $\mathbf{M}$ was used to represent a matrix of the differential methylation ratios of 910 DMSs. The $\mathbf{M}$ matrix has 114 rows and 910 columns. The regression model for the $g^{th}$ DEG was defined as,

```
$x_g = f(\mathbf{M}, \mathbf{w})$
```

Within such a regression model, f was designed as a regression function, which was either linear or nonlinear. In a constrained (such as RLR) linear regression model, the above equation was simplified as below,

```
$\mathbf{x}_g = \mathbf{M}\mathbf{w} + \lambda\mathbf{w}^t$
```

There were 1,250 regression models for 1,250 DEGs. These models were designed to investigate how DMSs, which were either local or remote methylation sites, contributed to the differential expression profile (pattern) of the $g^{th}$ DEG. Only the top-ranked DMSs were used for the impact analysis, if a remote DMS was ranked at the top, the distance between this remote DMS and the $g^{th}$ DEG was then investigated. The Lasso, RLR, SVM and random forest were used to model the relationship between the variables (between the $g^{th}$ DEG and all 910 DMSs) and rank variables. Figure 4.29 shows the R-square measurements for four models. It can be seen that four models all fitted to very well.

![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_212_0.png)

Fig. 4.29. The R-square for the M2E models constructed by four algorithms. Lasso stands for the Lasso regression models, Ridge stands for the RLR models, Forest stands for the random forest models, and SVM stands for the SVM regression models.

In each of four regression models constructed for a DEG, say the $g^{th}$ DEG, DMS employed as the independent variables were ranked. Suppose the $m^{th}$ DMS was ranked at the top. Its host gene was found and indexed by $k$. Note that the $k^{th}$ gene was not necessarily a DEG. Whether the $k^{th}$ gene was the host gene for the methylation site of the $m^{th}$ DMS was determined by the following method. Suppose the start and end base pairs of the $k^{th}$ gene were denoted by $\vartheta_{k,0}$ and $\vartheta_{k,1}$. The interval was then defined as $[\vartheta_{k,0} - 1000, \vartheta_{k,1} + 1000]$ for searching for the host gene for a methylation site. Suppose the base pair of the methylation site of the $m^{th}$ DMS was denoted as $\omega_m$. If $\vartheta_{k,0} - 1000 \leq \omega_m \leq \vartheta_{k,1} + 1000$, the $k^{th}$ gene was the host gene of the methylation site of the $m^{th}$ DMS.

All genes were ordered in terms of their sequential occurrence in a genome. The genes were indexed by their sequential occurrence positions in a genome. For instance, the first gene was assigned an integer one, the second gene was assigned an integer two, the third gene was assigned an integer three, etc. Therefore, the $g^{th}$ gene was assigned an integer $g$ and the $k^{th}$ gene was assigned an integer $k$.

Two distances were calculated. The first distance was named as the gene order distance and was the absolute distance between $g$ and $k$. It must be noted that the $g^{th}$ gene was a DEG and the $k^{th}$ gene was not necessarily a DEG. It has been found in this data that the methylation site within the body of a gene was not necessarily a DMS even the gene was a DEG. Moreover, even a methylation site was a DMS, but its host gene was not necessarily a DEG.

Suppose the $k^{th}$ gene was the host gene of the $m^{th}$ DMS and the $m^{th}$ DMS was ranked at the top in the $g^{th}$ regression model constructed for the $g^{th}$ DEG. The gene order distance between the $g^{th}$ DEG and the $k^{th}$ gene was defined as below,

```
$|g - k|$
```

The second distance was called the base pair distance. The mean basepair of the $g^{th}$ DEG was denoted by $\omega_g$ and the methylation site of the $m^{th}$ DMS was denoted by $\omega_m$. The base pair distance was defined as below,

```
$|\omega_g - \omega_m|$
```
