A vector-matrix format of a GAM model is shown below, where $\mathbf{y} = (y_1, y_2, \dots, y_N)$ stands for a vector as a dependent variable for $N$ data points, $\mathbf{\beta} = (\beta_0, \beta_1, \beta_2, \dots, \beta_K)$ stands for a vector of model parameters for $K$ splines of $K$ independent variables and $\mathbf{S}$ stands for the spline function matrix,

```
$\mathbf{y} = \mathbf{S} \times \mathbf{\beta} + \varepsilon$
```

The spline matrix $\mathbf{S}$ which is composed of an interceptor variable is shown below,

```
$\mathbf{S} = \begin{pmatrix} 1 & S(x_{11}) & \dots & S(x_{1K}) \\ 1 & S(x_{21}) & \dots & S(x_{2K}) \\ \vdots & \vdots & & \vdots \\ 1 & S(x_{N1}) & \dots & S(x_{NK}) \end{pmatrix} (4.29)
```

If LSE estimation is used, the solution of this model is shown below,

## $$\hat{y} = S\hat{\beta}\quad (4.30)$$

The pseudo inverse for GAM model is defined as below, where it can be seen that this format is almost identical with the LSE estimate for OLR model,

## $$\hat{\beta} = (S^T S)^{-1}S^T y\quad (4.31)$$

## 4.5 The Bayesian linear regression algorithm

The Bayesian learning provides a more robust approach to model parameter estimation. The Bayesian linear regression algorithm (BLR) is such an example [Buerkner, 2017]. The posterior probability of a BLR model can be calculated based on following,

$$p(w|y,X) = \frac{p(y|X,\Sigma) \times p(w|\alpha)}{p(y)}\quad (4.32)$$

where $w$ and $\Sigma$ stand for the regression coefficients and the covariance matrix, $\alpha$ stands for the hyperparameter. The likelihood function is shown below, where $\varepsilon = X^Tw - y$.

$$p(y|X,\Sigma) = \frac{1}{(2\pi)^{N/2}\sqrt{|\Sigma|}} \exp\left(-\frac{1}{2}\varepsilon^T\Sigma^{-1}\varepsilon\right)\quad (4.33)$$

A Gaussian prior structure is defined as below, where $d$ stands for the number of independent variables,

$$p(w|\alpha) = \left(\frac{\alpha}{2\pi}\right)^{d/2} \exp\left(-\frac{\alpha}{2}w^Tw\right)\quad (4.34)$$

Other prior structures can also be used in BLR [Buerkner, 2017]. The $R$ package $brms$ can be used for constructing a model for data set using BLR. The $R$ function for BLR is named as $brm$. The call of this $R$ function is shown below,

```
brm.model=brm(formula, data, family)
```

## 4.6 The constrained regression analysis algorithms

OLR and GAM do not apply a constraint to the model parameters. Therefore, these algorithms do not provide an efficient ranking mechanism for independent variables. In a constrained regression analysis, the parameters of a model are assumed to follow a pre-defined distribution or are bounded to a constant. Therefore the model parameters will be constrained, i.e., a competition scheme is introduced. With this competition scheme, the variables of a regression model will compete each other to win within a constraint. In other words, independent variables will press down unimportant independent variables because the space for all variables is limited. When the regression coefficients of important independent variable increase, the weights of unimportant variables certainly give space and decrease. Using this kind of regression analysis models, the independent variables of a model can thus be ranked.

## 4.6.1 The ridge linear regression algorithm

The ridge linear regression algorithm (RLR) was rooted from the Tikhonov regularisation [Tikhonov, 1963] and has been exercised for decades. It is still researched intensively nowadays for improving its performance and applicability in many areas [Hoer, 1962; Tikhonov, 1963; Dorugade and Kashid, 2010; Roozbeh, et al., 2020]. The reason that it is still a popular research subject is its incompatible feature in model interpretation.

The introduction of the Tikhonov regularisation is due to the ill-condition which often happens to the pseudo inverse (X'X)⁻¹ in a regression model [Hoer, 1962; Tikhonov, 1963]. The problem arises before X'X can be singular and its inverse cannot be calculated. in Tikhonov regularisation, a positive constant λ was introduced into the formula X'X + λ leading to a matrix, which is invertible all the times. this has replaced w = (X'X)⁻¹X'y by the following format as the solution to a RLR model,

```
w = (X'X + λI)⁻¹X'y (4.35)
```

The above equation also satisfies the Lagrange multiplier [Kalman, 2009], where c is a positive constant,

```
min(w - Xw)'t(w - Xw) + λ(w'w - c) (4.36)
```
