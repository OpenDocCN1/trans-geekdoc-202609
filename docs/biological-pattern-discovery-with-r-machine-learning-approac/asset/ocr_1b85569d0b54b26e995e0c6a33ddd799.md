To evaluate the performance such as the discrimination power of a constructed LDA model, new data should be inputted into a constructed LDA model to examine whether the outputs of a constructed LDA model are as expected. When inputting new data to a constructed LDA model, the outputs of the LDA model are called the predictions. To make prediction based on a constructed LDA model for new data, the predict function is called,

```
my.output=predict(my.lda, newdata, ...)
```

The main components of my.output include $class, $posterior and $x. $x is composed of the predictions ($\hat{Y}$) which are the mapped data on the optimised projection direction ($\hat{W}$) from the independent variables. The posterior probabilities are saved in a matrix of two columns for two classes and is named as $posterior. Its first column is composed of the posterior probabilities for the first class and the second column is composed of the posterior probabilities for the second class of the data set for which the LDA model is constructed. If the first posterior probability in a row is greater than the second posterior probability in the same row, the data point at that row is assigned a label of the first class. Otherwise, it is assigned a label of the second class. Based on a default threshold (0.5) for using the posterior probabilities for decision-making, the posterior probability $posterior is converted to the predicted binary variable which is binary and is named as $class in the output object (my.output) of the predict function. For a row, if the second posterior probability is greater than the first posterior probability, $class is one. Otherwise, it is zero.
