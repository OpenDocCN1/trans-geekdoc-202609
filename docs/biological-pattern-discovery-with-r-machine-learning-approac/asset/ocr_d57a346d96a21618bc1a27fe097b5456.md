```
$$\varepsilon = y - \alpha - \beta x = y - \hat{y}$ \quad (4.7)$
```

There are three pairs of $x$ and $y$, which are denoted by $(x_1, y_1)$, $(x_2, y_2)$ and $(x_3, y_3)$ as shown in Table 4.1. If a regression model has been constructed for them, there will be three model outputs as well. Note that both $x$ and $y$ are experimental data, and $\hat{y}$ takes three values for three values of $x$, i.e., $\alpha + \beta x_1$, or $\alpha + \beta x_2$ or $\alpha + \beta x_3$. The regression model outputs are individually denoted by $\hat{y}_1$, $\hat{y}_2$ and $\hat{y}_3$ of this data. $\hat{y}$ is a vector of the regressed means. The final regression function is an interpolated curve based on these regressed means. Between $y$ and $\hat{y}$, there are three regression errors. They are denoted by $\varepsilon_1$, $\varepsilon_2$ and $\varepsilon_3$. Their squared sum is called the sum of squared error or the total regression error is denoted by $\varepsilon = \varepsilon_1^2 + \varepsilon_2^2 + \varepsilon_3^2$ in this case.

Table 4.1. The correspondence between an independent variable x, a dependent variable y, the model outputs (the regressed means) and the regression errors. The squared errors are also included.

| Observation | Model output | Error | Squared error |
|---|---|---|--|
| $y_1$ | $\hat{y}_1$ | $\varepsilon_1 = y_1 - \hat{y}_1$ | $\varepsilon_1^2$ |
| $y_2$ | $\hat{y}_2$ | $\varepsilon_2 = y_2 - \hat{y}_2$ | $\varepsilon_2^2$ |
| $y_3$ | $\hat{y}_3$ | $\varepsilon_3 = y_3 - \hat{y}_3$ | $\varepsilon_3^2$ |
