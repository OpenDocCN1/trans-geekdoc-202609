The polynomial kernel is more suitable to the data in which variables are discrete, especially binary. The difference between the radial kernel and the polynomial kernel is the definition of the relationship between a data point and a support vector. Using the radial basis kernel, the relationship between a data point and a support vector is defined by the Euclidean distance, i.e., $||\mathbf x - x_n||^2$. However, the relationship between a data point and a support vector is defined as a dot product using the polynomial kernel, i.e., $\mathbf x^T x_n}$. Figure 3.32(a) shows the ROC curve of a SVM model using the polynomial kernel function constructed for the breast cancer data, where both $\alpha$ and $\beta$ were optimised via a grid search again. The degree parameter $(d)$ was fixed at 3. Both $\alpha$ and $\beta$ varied from 0.01 to 0.1. The best $\alpha$ value was 0.097 and the best $\beta$ value was 0.009 for this breast cancer data using this SVM kernel function.

The sigmoid kernel used in SVM is designed using two parameters shown below, where both $\alpha$ and $\beta$ are two parameters,

```
$$\Psi(\mathbf x, \mathbf x_n) = \frac{1}{1 + \exp(-\mathbf x^T x_n - \beta)}$ \quad (3.71)$
```
