# 3.6.8 The random forest algorithm

The aforementioned decision tree algorithms employ the orthogonal division approach, i.e., each partitioning rule employs one variable, and compare the value of the variable against a constant, such as $x < T$. Using this kind of partitioning strategy, a complex data space may need many partitioning rules to generate a decision tree model. Figure 3.47(a) shows a data space in which there are two classes of data points. If the orthogonal division approach is used by employing three partitioning rules, Figure 3.47(b) shows a decision tree constructed for this data set. The first partitioning rule and the third partitioning rule do not generate pure subspaces. The consequence is that only one subspace is pure for one class. This is shown in Figure 3.47(b), where only one leaf node is coloured by a single colour. For instance, the left subspace generated by the first partition rule $x < x0$ is composed of 17 data points of one class and one data point of the other class. It is no doubt that all subspaces are required to be pure, the derived decision tree will be very complex.
