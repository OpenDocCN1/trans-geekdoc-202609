## 2.3.2 The K-means cluster analysis

The K-means cluster analysis algorithm as the simplest partitioning algorithm partitions data into clusters through estimating cluster centres based on a pre-defined cluster number [MacQueen, 1967]. Its main feature is the use of a hard membership function to define the relationship between a data point and a cluster. Suppose there are three clusters. The hard membership function indicating how a data point belongs to clusters may be expressed by a vector which is either (0, 1, 0) or (0, 0, 1) or (1, 0, 0). A one entry means the belongingness relationship and a zero entry means the irrelevance relationship. Constructing a K-means model is fast due to the use of this hard membership function.

Because of its simplicity, the K-means cluster analysis algorithm has been one of the most popular ones for biological/medical pattern discovery. For instance, it has been used to improve quantitative susceptibility mapping, oxygen extraction fraction as well as cerebral metabolic rate of oxygen [Cho, et al., 2020]. It has been used to model time evolution image data based on healthy subjects as stroke patients and the result shows that such model can significantly influence analysis robustness. In searching for MRI biomarkers for clinical assessment, it has been used to discover how the computation of cerebral blood volume in postprocessing steps on a population of 49 subjects with low- and high-grade gliomas [Bell, et al., 2020].

The key point of the K-means algorithm is to find the cluster centres, i.e. the means. Once the centres have been found, each data point is assigned with a membership vector, which is composed of either a zero or a one. Because of the use of the least distance, only one entry of the membership function vector is one for a data point. The rest of the membership vector are zeros. By this way, each data point is assigned to one cluster only.

The cluster centres of a model are normally unknown when starting a clustering process for a data set. Therefore, data points cannot be assigned to clusters without known cluster centres. A basic exercise used in the machine learning community comes to the front, which is the so-called trial and error learning strategy. Its basic principle is a repeated process of estimating model parameters. In the trial stage, a set of model parameters is either assigned by a set of random values or updated according to the direction by a pre-defined error function is decreased or minimized. In the error stage, a new error is estimated based on the fitness performance of the model with the current parameters. The new error thus provides a new parameter update direction.

The cluster centres of a model as the model parameters are assigned by random values as guesses at the beginning although they are definitely inaccurate. These guessed cluster centres are then examined to see whether they are accurate or not. If not, they are updated towards a direction at which a pre-defined error function can be reduced. Gradually, the clustering error is diminishing or the cluster centres of a model stop to change when the optimal cluster structure has been found.

A membership by which the $n^{th}$ data point $(\mathbf{x}_n)$ of a data set $\mathcal{D}$ belongs to the $k^{th}$ cluster is denoted by $f_{nk}$ and the K-means membership function is defined as,

$f_{nk} = \begin{cases} \mathbf{x}_n & \text{belongs to cluster } k \\ 0 & \text{otherwise} \end{cases} \quad (2.20)$
