## 2.2.4.2 Gamma mixture

The Gamma mixture has been popular for analysing biology data with positive continuous values. A Gamma component density is defined as below,

> $$\mathcal{T}(\alpha, \beta) = \frac{\beta^\alpha x^{\alpha-1}e^{-\beta x}}{\Gamma(\alpha)}$$ (2.13)

A Gamma mixture is defined as below,

```
$f(x_i) = \sum_{k=1}^{K} w_k \mathcal{T}(x_i|\alpha_k, \beta_k) \eqno (2.14)$
```

The parameters of a Gamma mixture model can be estimated using the likelihood maximisation approach [Dempster, et al., 1977] or the Bayesian approach [Mohammadi, et al., 2013] as well. mixR is an R package for the Gamma mixture modelling using the likelihood maximisation approach. The function for estimating a Gamma mixture density in this package is mixfit. For instance, the following code was used to estimate the density of the first replicate of the airway sequencing count data [Himes, et al., 2014] if the raw count data have been saved in a matrix x. Only non-zero count data were logarithm transformed for the density estimate. Figure 2.15(a) shows the estimated density, which shows a clear Gamma mixture.

```
x=log(1+x)
z=as.numeric(x[which(x[,1]>0)],
model=mixfit(z,ncomp=2,family='gamma')
```

The mixR package also has a function for optimising the model structure to select an optimal number of Gammas for a mixture based on the use of the Bayesian Information Criterion (BIC) [Schwarz, 1978].
```
x=log(1+x)
z=as.numeric(x[which(x[,1]>0),1])
model=select(z, family='gamma',ncomp=1:3)
```

## 2.3 Cluster analysis

Cluster analysis is an unsupervised learning approach, which aims to partition a data set into sub-data sets, each of which is a cluster. When it is required to investigate how genes function within a genome under a stress, cluster analysis can be used to partition genes into groups according to their measured responsive strengths so to discover how the genes function in different ways. Because of this reason, cluster analysis has been very popular in many biological/medical pattern discovery tasks [Le Roch, et al., 2003; Liu, et al., 2005; Huang and Pan, 2006; Pan, 2006; Higashi and Saito, 2013]. Cluster analysis has been used to examine how Ca2+-dependent conformation changes [Chaturvedvedi, et al., 2020]. In a lung cancer study, the use of cluster analysis has discovered that malignant mesotheliomas demonstrate high ROR1 expression [Miyake, et al., 2020]. To examine whether bovine is a symptom of aberration of liver functions, cluster analysis has been used to confirm the relationship of gene expression between bovine granulocytes and aberration of liver functions [Kizaki, et al., 2020]. The molecules which share similar biological functions in similar biological pathways are believed to show similar activities in an experiment. A cluster analysis study has revealed different numbers of differentially expressed genes responding to the same drought stress in wheat, maize and rice [Wei and Chen, 2018].

Most of these researches are hypothesis-driven and have little or no a priori knowledge about how a cluster model should look in advance. In other words, no knowledge will tell which group of molecules demonstrate a similar response to a stress before a pattern analysis process using a machine learning algorithm starts. Cluster analysis is thus a good approach to be used for this kind of pattern analysis.

To cluster data, the first issue is how to measure the distances between data points. Different clustering algorithms may use different metrics for measuring the distances or the similarities between data points for different types of data. Among them, the Euclidean distance, the Hamming distance, as well as the correlation coefficient are commonly used to cluster numerical data. Supose two $d$-dimensional vectors are denoted by $\mathbf{x} = (x_1, x_2, \dots, x_d)$ and $\mathbf{y} = (y_1, y_2, \dots, y_d)$, the Euclidean distance between them is defined as below,

```
$D^E(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^d (x_i - y_i)^2$ (2.15)
```

The Hamming distance [Hamming, 1950] is commonly used for discrete data and it is defined as below,

```
$D^H(\mathbf{x}, \mathbf{y}) = \frac{1}{d} \sum |x_i - y_i|$ (2.16)
```

A distance measures the dissimilarity. A correlation coefficient can be used to measure how two data points are similar to each other. The definition of the correlation coefficient for two vectors (hence two data points) $\mathbf{x}$ and $\mathbf{y}$ is shown below, where $\mu_x$ and $\mu_y$ stand for the population means, $\sigma_x^2$ and $\sigma_y^2$ stand for the variances of two populations,

```
$ho(\mathbf{x}, \mathbf{y}) = \frac{\sum_{i=1}^d(x_i - \mu_x)(y_i - \mu_y)}{(d-1) \sqrt{\sigma_x^2\sigma_y^2}}$ (2.17)
```
