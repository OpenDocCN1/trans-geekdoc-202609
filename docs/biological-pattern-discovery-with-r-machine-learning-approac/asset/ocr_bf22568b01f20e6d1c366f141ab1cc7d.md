If $\lambda$ is small, more regression coefficients are shrunk to zero. This means that unimportant variables are penalised while important variables are enhanced in a model. A Lasso model is generally not analytically solvable and the quadratic programming approach [Garey and Johnson, 1979] is used to estimate the parameters for a Lasso model. In bioinformatics, Lasso has been used to derive the parsimonious models or the sparse models. For instance, it has been used for building the parsimonious Cox proportional hazards models [Sohn, et al., 2009], for constructing more parsimonious generic new features through exploring the mutual relationships between genes [Gustafsson, et al., 2009; Shimamura, et al., 2007], and for detecting the causative genes of diseases [Shi, et al., 2007].
