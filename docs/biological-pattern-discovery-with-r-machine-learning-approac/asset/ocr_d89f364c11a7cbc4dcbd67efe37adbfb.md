Such an exercise has become more and more challenging nowadays because most modern biology experiments are undertaken genome-wise and this is the so-called big data era. Big data needs novel methods to deal with. In gene essentially pattern discovery based on the transposon sequencing technology, the analysis of an individual mutant has been replaced by the massive analysis of millions of mutants simultaneously. Therefore, the conventional methods of discovering essential genes have been challenged and have been replaced by the big-data essential gene discovery methods. This chapter has shown how unsupervised machine learning approaches can be used for responsive gene discovery, in which there is normally no a priori knowledge about how to separate responsive genes from non-responsive genes. Various density density estimation approaches and cluster analysis algorithms have been introduced and demonstrated in association with the main subject of this chapter, i.e. responsive gene discovery. In addition, the principles, the working procedures and the technical implementations in R have been introduced as well. However, the gene essentially pattern discovery still needs more substantial improvement. One important issue, which has not yet been fully solved, is the uncertainty of transposon distribution resulting from various early-stage data preparation errors, from sample preparation, to sequencing and to alignment. An error in every step may cast an accuracy or an effectiveness problem in the gene essentiality pattern discovery for a data set. How to properly incorporate these uncertainties for a better gene essentiality pattern discovery certainly needs more effort.
