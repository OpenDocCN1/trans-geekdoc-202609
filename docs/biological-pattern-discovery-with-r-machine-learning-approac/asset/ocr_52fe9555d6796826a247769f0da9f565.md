It is known that peptides are composed of non-numerical data. The binary encoding is one way to encode amino acids or nucleic acids [Wu, et al., 1995; Kawabata and Doi, 1997; White and Seffens, 1998]. The radial basis kernel function is therefore inappropriate to use. The dot product kernel function can be an alternative and it is defined below,

> $$\Psi(\mathbf{x}, \mathbf{x}_n) = \mathbf{x}^T\mathbf{x}_n$$\quadquad(3.72)
