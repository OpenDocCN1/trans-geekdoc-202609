In a traditional way, the fold change is calculated gene-wisely, but the fold changes are estimated through a regression analysis based on all genes for a data set in a limma model. Therefore the estimated fold change by the limma model is more robust and less noise-affected.

Based on a design matrix, a linear model is then used for the gene expression significance analysis. The following code was used to generate a linear model for this data set based on the generated design matrix for the prostate cancer data.

```
lm.model=lmFit(X, D)
```

The generated model denoted by lm.model was composed of multiple statistics, in which, $coefficients is a matrix. Its second column corresponds to $\beta_2$, i.e., the fold change. For an illustration, the original fold changes were compared with the limma model fold changes and this comparison is shown in Figure 6.5(a). It can be seen that the two had a strong correlation (a correlation coefficient was 0.93). Moreover, the limma fold changes had little outliers compared with the original fold change.

Based on the limma model, gene significance analysis, i.e., the SAM p value calculation can be implemented using the following code,

```
sam.model=eBayes(lm.model)
```

This will return many components. Among which, $p.value has an important role for DEG analysis. In addition, $coefficients contained in lm.model will be inherited to this object (sam.model) as well. It is interesting to examine the relationship between the t test p values and the SAM t test (modified t test) p values. 6.5(b) shows the correlation between the t test p values and the SAM t test p values for the prostate cancer data. It shows that they had some difference the t test p values and the SAM test p values show a high correlation coefficient (0.99).
