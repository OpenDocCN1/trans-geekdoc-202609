The basic component of the Bernoulli function is called the binary entropy [MacKay, 2003], i.e., $\vartheta = p^y(1-p)^{1-y}$, where $y \in \{0,1\}$ and $p \in [0,1]$. When $y=1$ and $p=1.0$ or $y=0$ and $p=0.0$, $\vartheta$ is maximised. The parameters $\alpha$ and $eta$ can be estimated through maximising this likelihood function. The logistic regression algorithm has been applied for drug-drug interaction prediction [Celebi, et al., 2019] and common cancer detection [Lopes, et al., 2019]. The R function for constructing a logistic regression analysis model is `glm`.

# 3.3.4 The Bayesian linear discriminant analysis

In order to deliver a more robust discriminant analysis model, the Bayesian learning has been introduced for linear discriminant analysis as well. In a Bayesian learning discriminant analysis model, the *a priori* probabilities are no longer simply the proportions of data points belonging to two classes. Instead, they are parameters to be estimated using the *a priori* function [Zhou, et al., 2013]. Suppose the likelihood function of the model parameters is defined as,

```
$p(\mathbf{y}|\mathbf{w}, \beta) = \left(\frac{\beta}{2\pi}\right)^{N/2} \exp\left(-\frac{\beta}{2}|\mathbf{X}^t\mathbf{w}-\mathbf{y}|^2\right) \quad (3.23)$
```

The *a priori* function of model parameters is defined as,

```
$p(\mathbf{w}|\alpha) = \left(\frac{\alpha}{2\pi}\right)^{d/2} \exp\left(-\frac{\alpha}{2}\mathbf{w}^t\mathbf{w}\right) \quad (3.24)$
```
