Suppose a count matrix shown in Table 6.4 was saved in X and a design matrix shown in Z. A working data was generated by DESeqDataSetFromMatrix of DESeqs. The parameter tidy was switched on because the first column of the count matrix data was the gene names.

```
Q=DESeqDataSetFromMatrix(countData=X, colData=Z, design=~class, tidy=TRUE)
```

The data structure of Q is a DESeqDataSet data structure. The sequencing count matrix had 38,694 genes and eight samples. The assay type was the sequencing counts. The prefix of gene IDs is ENSG000000000. The prefix of sample names is SRR10395. The sample classification ID was dex. Q is an S4 object in R and its entries can be viewed using `slotNames`. Based on this working data Q, a DESeq model can be constructed using the following code,

```
model=DESeq(Q)
```

In order to obtain statistics as the p values, the results must be based on a DESeq model. This generates a table of results shown in Table 6.6.

```
res.table=results(model)
```
