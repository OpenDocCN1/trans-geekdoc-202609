# 4.4 The generalised additive model algorithm

Not all biological data can show relationships between variables. In order to model the nonlinear relationship between variables, many complex or nonlinear regression algorithms can be considered as the alternatives. Among them, the generalised additive model algorithm (GAM) is a good candidate [Hastei and Tibshirani, 1990]. A GAM model is a linear function of spline functions. The nonlinearity is embedded in each spline function. GAM is defined as below, where $s(x)$ is a spline function of the independent variable

$y = \beta_0 + \beta_1 s(x) + \varepsilon$
