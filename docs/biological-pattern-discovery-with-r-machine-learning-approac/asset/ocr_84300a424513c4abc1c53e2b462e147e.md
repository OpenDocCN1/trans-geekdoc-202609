DOG that the non-outlier case (or control) expressions have a significantly small distance with the tight cluster formed by the control expressions for most non-DEG. Each of such a case (or control) expression will be merged into the tight cluster. Therefore the tight cluster will be adaptively updated or growing its size when scanning the case expressions. All case expressions will be scanned by one to the point where a case expression cannot be treated as a member of the tight cluster and its membership of the tight cluster is significantly denied. In other words, the adaptive process of the algorithm is terminated when the remaining case expressions, which are treated as outliers, cannot be merged to the tight cluster. An alternative to allow an outlier to present among the control expressions in DOG is to use the 9^th percentile of the control expressions to form an initial tight cluster [Yang and Yang, 2013]. For a DEG, most case expressions will be significantly deviated from a tight cluster constructed based on the control expressions. Therefore, a process of searching for an outlier using the tight cluster approach will be terminated in a very early stage.

It is common that there is normally an overlap between the control expressions and the case expressions for a gene. Therefore, DOG has been further updated in this chapter. Rather than using the 9^th percentile of the control expressions, a new initial tight cluster is formed in a slightly different way. With this method, an initial equation defines an empirical standard deviation, where the coefficient 1.4826 used in the COPA algorithm [Tom, et al., 2005] and $\mu$ stands for the median of all expressions,

$$\hat{\sigma} = 1.4826 \times \text{median}(|x - \mu|)$

Figure 6.17 shows the relationship between the true (or expected) standard deviations ($\sigma$) and the estimated standard deviations ($\hat{\sigma}$) using the above equation. The correlation between two sets of standard deviations was about 0.97 meaning that an estimated standard deviation can be a very good approximate to the true or expected standard deviation and can be used as an initial standard deviation to start a tight cluster in the algorithm.
