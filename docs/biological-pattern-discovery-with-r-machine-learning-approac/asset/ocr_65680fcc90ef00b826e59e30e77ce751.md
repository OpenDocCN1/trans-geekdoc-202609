# Whole Genome Pattern Discovery

The FASTA file of these 17 sequences was loaded using the readFASTA function of the insect library and saved in x, where the bin parameter is switched off meaning sequences were not saved in the binary format

```
x=insect::readFASTA('SARS.HIV.fasta',bin=FALSE)
```

The code shown below was used for the pair-wise homology alignments between 17 sequences to generate homology scores,

```
score=matrix(0,length(x),length(x))
diag(score)=1
for(i in 1:length(x)-1)
for(j in (i+1):length(x))
score[i,j]=pairwiseAlignment(x[i],x[j],
type='local',substitutionMatrix=S,
gapOpening=-1.3,gapExtension=-0.3)@score
```

Afterwards, a score matrix was generated, for which a heatmap was produced. The heatmap is shown in Figure 7.10. It can be seen that six HIV sequences were closely clustered while ten SARS-CoV-2 sequences were closely clustered together. However, one SARS-CoV and six HIV sequences had a smaller difference.

An alignment-free approach was also applied to compare these 17 sequences. The function countPattern of Biostrings was used to calculate 3-mer word frequency for these 17 sequences using the following R code.

```
mer=matrix(0,length(x),length(word))
for(i in 1:length(x))
{
  for(j in 1:length(word))
  mer[i,j]=countPattern(word[j],x[i])
  mer[i,]=mer[i,]/sum(mer[i,])
}
rownames(mer)=c(rep('S',10),'X',rep('H', 6))
pca=prcompr(mer)
```
