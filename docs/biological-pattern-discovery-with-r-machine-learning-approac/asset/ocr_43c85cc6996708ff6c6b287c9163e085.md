# 2.3.5 The other clustering algorithms

There are other clustering algorithms which have been developed and
applied to different areas. The K-medoids algorithm will estimate a
medoid for each cluster of a cluster model [Kaufman and Rousseau,
1987]. Given N data points, D = (x₁, x₂, ..., xN), a medoid of a cluster is
defined below,

```
x_{medoid} = argmin_{y\in D} \sum_{i=1}^{N} d(y, x_i) (2.29)
```
