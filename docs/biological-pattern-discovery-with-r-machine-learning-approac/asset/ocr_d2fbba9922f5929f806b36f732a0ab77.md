points to act as kernels. Each kernel is a Gaussian distribution, for which a raw data point acts as the centre. Each kernel thus has a density and is called the kernel density. The whole density for a data set is an integration of all kernel densities. Suppose there are N data points, for which a subset (M data points) is used as the kernels. The kernel densities are denoted by $f_1, f_2, \dots, f_M$, where $M \le N$. The format of the kernel method for estimating a density for a data set is shown below,

```
$F = \frac{1}{M} \sum_{m=1}^{M} f_m = \frac{1}{M}(f_1 + f_2 + \dots + f_M) \quad (2.5)$
```

where each kernel density $f_m$ is defined as below,

```
$f_m = \frac{1}{\sqrt{2\pi}\sigma} e^{\frac{(x-u_m)^2}{\sigma^2}} \quad (2.6)$
```
