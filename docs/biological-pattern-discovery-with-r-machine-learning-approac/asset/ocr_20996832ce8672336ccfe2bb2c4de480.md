# 2.2.3 The non-parametric approach

The histogram approach is generally used for generating a visible density, which is loyal to the true data distribution. But, it cannot be used for a data set in a high-dimensional space. The parametric approach enjoys the simplicity and a resulting density model is parsimonious in structure. It is also based on two important assumptions. First, the density format is known in advance. Second, the density is a single-mode data distribution such as a single Gaussian or a single Gamma distribution. Therefore to estimate the density for a single more complicated distribution, the alternatives should be considered. Among them, the non-parametric approach is the one.

The advantage of the non-parametric density estimation approaches are that they can estimate a density function without priori knowledge about how a distribution looks like and still maintain a limited flexibility of the parameterisation of a density model [Rosenblatt, 1956; Parzen, 1962; Duda, et al., 2000].
