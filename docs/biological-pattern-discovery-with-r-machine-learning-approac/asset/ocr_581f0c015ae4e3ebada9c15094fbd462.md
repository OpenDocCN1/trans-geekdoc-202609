The code shown below is for five-fold cross-validation for this data set, where CV was a cross-validation vector, in which five integers from one to five were randomly distributed. The vector test was used as the indexes of the testing data set. It was composed of one fold of the whole data set. The vector '-test' was composed of indexes of the training data set. It was composed of four folds of the whole data set. The matrix input has the class variable removed. The vector Z was a variable of predicted class labels.

```
CV=sample(1:5,nrow(x),replace=TRUE)
input=x[,which(colnames(x)!='class')]
Z=rep(0,nrow(x))
for(fold in 1:5)
{
    test=which(CV==fold)
    model=lda(class ~,x[-test,])
    Z[test]=predict(model,input[test,])$$class
}
```

The following code was used for running the Jackknife test for the data set, where a seed was enumerated, the seed input[n] was used as the testing data while all other seeds x[-n] were used as the training data set.

```
Z=rep(0,nrow(x))
for(n in 1:nrow(x))
{
    model=lda(class ~,x[-n,])
    Z[n]=predict(model,input[n])
}
```
