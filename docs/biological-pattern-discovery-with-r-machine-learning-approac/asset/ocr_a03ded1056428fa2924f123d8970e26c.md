Establishing a regression function is a process of minimising the total regression error. For any set of collected data points, there will be a unique set of regressed means. The regressed means correspond to the estimated regression model parameters, i.e., $\alpha$ and $\beta$. A linear regression function expressed as a straight line is thus parametrised by these two parameters. This method is called the least squared error method (LSE) developed in the 18th century [Stigler, 1986].

A basic assumption of LSE is that the responses (the $y$ values) or the regression errors of an OLR model follows a Gaussian distribution. If $y\sim\mathcal{G}(\mu_y, \sigma_y^2)$, then $\epsilon\sim\mathcal{G}(\hat{y}-y, \sigma_\epsilon^2)$ as well. Given a mean and a variance of a Gaussian distribution for a data set with $N$ data points, a likelihood function is defined as

```
$$\mathcal{L} = \prod_{n=1}^{N} p(\epsilon_n) = \prod_{n=1}^{N} \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{(\hat{Y}_n - y_n - \mu)^2}{2\sigma^2}\right)$ $(4.8)$
```

Applying the negative logarithm to the likelihood function $\mathcal{L}$ leads to the error function shown below, where $C$ is a constant,

```
$E = -log\mathcal{L} = \sum_{n=1}^{N} (\hat{Y}_n - y_n - \mu)^2 + C$ $(4.9)$ \n $ = \sum_{n=1}^{N} (\hat{Y}_n - \alpha - \beta x_n - \mu)^2 + C$
```

Minimising this error function (equivalently maximising the likelihood function) results in an analytic solution of an OLR model. A vector-matrix notation can be used to show the LSE solution to an OLR Model. The model parameters are denoted by a vector shown below,

```
$$\mathbf{w} = (\alpha, \beta)$ $(4.10)$
```
