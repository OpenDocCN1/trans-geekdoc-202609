$\log\mathcal{L}(\mathbf{z}^+|\mu, eta) \propto \frac{1}{2}\logeta - \frac{1}{2}eta(\mathbf{z}^+ - \mu)^2$  (6.23)

The log-prior $eta$ is defined as follows,

$\log IG(eta|a,b) \propto a\logeta + (a+1)\logeta - beta$  (6.24)

The log-prior of $\mu$ is defined as follows,

$\log G(\mu|\mu_0, \sigma_0^2) \propto \frac{1}{2}\log\sigma_0^2 - \frac{(\mu-\mu_0)^2}{2\sigma_0^2}$  (6.25)

The optimisation follows the procedure of maximising a posteriori [Bishop, 2006]. The process is implemented in two steps, i.e., the expectation step and the maximisation step. In the expectation step, the posterior is calculated based on both the model parameters and the hyperparameters. In the maximisation step, the model parameters and the hyperparameters are updated based on the evaluated posterior. The update of $\mu$ is shown below [Yang and Yang, 2013]

$\mu = \frac{eta \mathbf{z}^+ + eta_0 \mu_0}{eta n + eta_0}$  (6.26)

The update rule for $eta$ is shown below,

$eta = \frac{n+2a+2}{\sum_i(\mathbf{z}_i^+ - \mu)^2 + 2b}$  (6.27)

The update rule for $eta_0$ is shown below,

$eta_0 = \frac{a+1}{(\mu-\mu_0)^2/2+b}$  (6.28)

Based on the analysis above, a $t$ statistic is defined as below, $\mathbf{z}_i^- \in \mathbf{z}^-$ is the first candidate outlier in $\mathbf{z}^-$ or the one which is most close to the tight cluster box,

$t_i = \frac{\mathbf{z}_i^- - \mu}{\sigma}$  (6.29)
