## 8.3.2.2 The GP breeding rules

Based RPN, GP can be formulated using the similar breeding operators used in GA. However, they need to be updated because RPN chromosome is no longer a string of binary values. Before introducing how the breeding operators work for a GP problem, two RPN strings are designed. They are $x3y*+xz++ for $x + 3y + x$ and $5xy**zy*+$ for $5xy + zy$. Figure 8.7 shows two RPN chromosomes for these two equations.

| x | 3 | y | * | x | z | + |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 5 | x | y | * | z | y | * | + |

Fig 8.7. Two RPN chromosomes for two equations.

An RPN chromosome is only one way of expression of an equation. The equation can also be generalised by a tree. Figure 8.8 shows two tree expressions for the RPN chromosomes shown in Figure 8.7.

In GA, a chromosome is a string of binary values, therefore a mutation operation or a crossover operation is much easier to implement. For instance, the use of the mutation operator will turn over between zero and one in some bits of a chromosome to change the presence and absence status of the candidate variables. However, an RPN chromosome is not composed of binary values. Instead, each entry is either a variable, a constant, or an operator, or a bracket if a more complicated equation is used. For instance, the first token of the RPN chromosome in the upper panel in Figure 8.7 is a variable x. If a mutation is required for this token, it can only be mutated to another available variable which is available rather than an operator. If it is mistakenly mutated by an operator +, the resulting system mutated is ill-conditioned as shown in Figure 8.9(a), where the mistakenly mutated token is shown in the box with the dark box. It can be seen that this tree does not represent a proper equation. Parsing the RPN string for this tree will encounter an error. Figure 8.9(b) shows another error, where an operator (+) as the eighth token of the RPN shown in the upper panel of Figure 8.7 is wrongly mutated to a variable x. The mistakenly mutated token is shown in the box with the dark box. Certainly, the subtree on the right side in Figure 8.9(b) is also an ill-conditioned tree or an ill-conditioned RPN string.

![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_390_0.png)

Therefore, both the mutation operator and the crossover operator must be carefully designed for handling RPN strings when they are used for breeding new chromosomes in a GP model. In an RPN chromosome, it is important to know in advance how many token styles have been employed. Normaly, there are three types of tokens. They are the constants, the variables and the operators. In a complex system, where one operator may be applied to a varying number of variables, the brackets will be used. For instance, the RPN string xyz**uv*w/ can be used for the following equation. However, an efficient way for this equation is to use the brackets, which makes the evaluation of such an RPN string much easier and effective. Using the brackets, the following equation can be expressed as ((xyz)*(uv)*)+w). Figure 8.10 shows such a tree structure.

(x * y * z + u * v)/w

## 3.3.2.3 Mutation

The first breeding operator used in GP for handling RPNs is the mutation operator. In an RPN chromosome, only the constants, the variables and the operators can be mutated. The brackets cannot be mutated. A constant can only be mutated to another constant, a variable can only be mutated to another variable and an operator can only be mutated to another operator. Figure 8.11(a) shows how the mutation operator is applied to the RPN chromosome at the fifth token shown in the upper panel of Figure 8.7. The mutation replaces the + operator by the * operator, resulting in a new chromosome. Figure 8.11(b) shows the resulting tree, where the mutated token is in a box with the dark box.

If a system is composed of both unary operators and binary operators, a mutation operation must be careful. A unary operator can only be mutated to another unary operator and a binary operator can be mutated to another binary operator. For instance, the RPN string for the equation xy + \sqrtz is xy*z# suppose the # key is used to represent a square root operation. By a mistake, a unary operator is mutated to a binary operator or a binary operator is mutated to a unary operator, the resulting tree means nothing. Figure 8.12 shows such a mistake. ## 8.3.2.4 The dual-chromosome crossover

The second one to be considered is the crossover operator. In GP, the crossover operation can be done in two ways. One is the single-chromosome crossover (or the self-crossover). The other is the dual-chromosome crossover, which employs two elite chromosomes to breed new chromosomes. In a dual-chromosome crossover, two subunits of RPN chromosomes are randomly selected and swapped. Thus, two new chromosomes are generated.
