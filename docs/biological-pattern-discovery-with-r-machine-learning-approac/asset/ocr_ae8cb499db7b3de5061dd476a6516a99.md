Based on the above vector-matrix notation of data, a BBFNN model is defined as below, where **B(X)** stands for the transformation using the bio-basis peptides,

```
$$\hat{\mathbf{y}} = \mathbf{Sw} + \mathbf{e} = \mathbf{B(X)w} + \mathbf{e}$$ (3.46)
```

A simple implementation of BBFNN is to use a maximum likelihood approach of a logistic regression model to estimate **w**. The sigmoid function is used for squashing $\hat{\mathbf{y}}$ into the interval between zero and one,

```
$$\mathbf{\pi} = \frac{1}{1 + e^{-\hat{\mathbf{y}}}}$$ (3.47)
```

A Bernoulli likelihood function is generated based on the logit vector **y,

```
$$\mathcal{L} = \sum_{n=1}^{N} \pi_n^{y_n} (1 - \pi_n)^{1-y_n}$$ (3.48)
```

Maximising this likelihood can estimate **w**. Based on the estimated model parameters $\hat{\mathbf{W}}$, which is the estimated version of **w**, a constructed BBFNN model can be used to scan a long protein sequence to identify potential protease cleavage sites for a specific protease or posttranslational sites for a specific chemical.

BBFNN has been implemented in different versions. For instance, a Bayesian BBFNN and an orthogonal kernel machine.

# 6.6.3.2 The Bayesian BBFNN algorithm

The Bayesian BBFNN is an extension to BBFNN. The aim of developing the Bayesian BBFNN is for generating a more robust BBFNN modelling algorithm for protease cleavage peptide data analysis [Yang, 2005b]. Suppose an error vector is denoted by **e = (e_1, e_2, ..., e_N)^t**, a linear combination of $K$ bio-basis functions is defined as below,

```
$$\hat{\mathbf{y}}_n = \sum_{k=1}^{K} w_k \mathbf{B(x_n, \mathbf{s}_k)} = y_n - \mathbf{e}_n$$ (3.49)
```
