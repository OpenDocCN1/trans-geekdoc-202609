# 6.4.3 OS

Following COPA, the outlier-sum algorithm (OS) was proposed [Tibshirani and Hastie, 2007]. The outliers are defined by $\{y \in y_i; y > q_{75}(\mathbf{x}_i, y_i) + 	ext{IQR}(\mathbf{x}_i, y_i)\}$. The OS $t$ statistics is defined as below, where $m$ is the number of the case expressions. The OS $p$ value is also calculated using the permutation approach.

```
$$t^{OS} = \frac{\sum_{i=1}^{m}(y_i - \lambda)}{\sigma} \quad (6.11)$
```

# 6.4.4 ORT

The numerator was further revised in the outlier robust $t$ statistic algorithm (ORT). In ORT, the range of outlier discovery was enlarged using the inter-quarter percentile [Wu, 2007]. OS and ORT employ a similar division strategy. OS makes a division between the outlier and non-outlier expressions while ORT divides the control expressions using the pooled expressions. ORT uses the same statistic but defines the outliers in relation to the case expressions only:

```
$${y \in y_i; y > q_{75}(x_i) + \text{IQR}(x_i)\}$ \quad (6.12)$
```

# 6.4.5 MOST

The maximum ordered subset $t$ statistic algorithm (MOST) employs a ranking method [Lian, 2008]. For both the control expressions and the case expressions, two median values are calculated. They are $\mu_x = \text{median}(\mathbf{x})$ and $\mu_y = \text{median}(\mathbf{y})$. Based on these two median values, the median of the differences between expressions and expression medias is calculated using the following equation,

```
$$\omega = 1.4826 	imes \text{median}(|x - \mu_x|, |y - \mu_y|)$ \quad (6.13)$
```
