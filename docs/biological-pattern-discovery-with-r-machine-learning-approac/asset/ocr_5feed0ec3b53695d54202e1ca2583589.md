A hierarchical clustering model for a data set is always deterministic because does not involve a process of randomising model parameters at the beginning of a learning process. However, a K-means model is not deterministic. Most machine learning models show different modelling outcomes for the same data set using the same model parameters in different runs. This is because they start from a learning process with random values assigned to the model parameters. This process is called the model parameter initialisation. The cluster centres of a K-means model are also assigned by random values at the beginning of a learning process. Because of this, two data points may be classified into the same cluster in one model, but may be classified into different clusters in the other model using the K-means algorithm. Figure 2.26 shows four K-means models for a data set with three clusters of data points. They show some different clustering results. Therefore, it is required to take care when clustering data using the K-means algorithm.
