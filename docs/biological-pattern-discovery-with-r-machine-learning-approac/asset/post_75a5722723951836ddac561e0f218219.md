The basic principle of the random forest algorithm is to avoid overfitting a classifier through creating many smaller trees [Ho, 1998, Hastie et al., 2001]. Unlike a decision tree model, a random forest model generates oblique hyperplanes which can have better performance with less nodes as the example shown in Figure 3.48. The random forest algorithm has also been applied for biological/medical pattern discovery, such as Daphnia magna acute toxicity prediction [Marzo, et al., 2020] and cancer diagnosis [Yang, et al., 2020].

The R function for the random forest algorithm is in the randomForest package. The R function is also called randomForest. The random forest algorithm can be used for both classification and regression analysis. A random forest model is constructed using the following code:

```
randomForest(formula, data, ...)
```

Figure 3.49(a) shows the ROC curve of a random forest model for the breast cancer data.

The random forest algorithm can also analyze non-numerical data. This is because it is developed based on decision tree algorithms. The factor Xa protease data was used for the demonstration. Figure 3.49(b) shows the ROC curve for this random forest constructed for the data, where no encoding process was used to encode the peptides.

Figure 3.49(c) shows the ROC curve of a random forest model constructed using the party package for the factor Xa protease cleavage data. Again, no encoding process was used for the amino acids in the peptides.

The advantage of the party package is that it can generate a tree for interpretation and visualization. For instance, Figure 3.50 shows a tree generated by the party package for the breast cancer data set. Using this, it is possible to find which variables play the significant roles in the breast tumor classification problem, hence providing useful knowledge for breast cancer diagnosis. The tree also shows the significance of each variable, i.e., a p-value associated with a variable. For instance, the variable X24 had the least p-value and hence was the most significant variable for breast cancer diagnosis based on a model constructed for this data set. This can provide a user to trade-off between the prediction system complexity and the prediction accuracy.

When dealing with a protease cleavage pattern discovery problem, in which peptides are non-numerical, there are two ways to construct a random forest model. Using raw peptides as input is one way, which is shown above and in Figure 3.49(b) and Figure 3.49(c). In such a random forest model, the residue variables can be ranked in addition to a discrimination model.

However, if it is required to discover which peptides are the most significant ones for discriminating between cleaved and non-cleaved peptides, the random forest algorithm can be used to rank cleaved peptides with the support of the bio-basis function. This is especially useful in inhibitor design. When this is required, the random forest model with the support of the bio-basis function can be used to discover the most probable cleaved peptides as prototypes for inhibitor design.

This bio-basis space was supported by the cleaved peptides for the factor Xa protease data. Afterwards, the party package was used to generate a random forest model. In such a tree, all the cleaved peptides used as the bio-basis functions were ranked. Some peptides were ranked at the top and some were not. Figure 3.51(a) shows a decision tree, where only one partitioning rule is employed. It is no doubt that a decision tree generated using the oblique division approach can generate a more parsimonious and efficient decision tree structure, and perhaps with a better performance.
