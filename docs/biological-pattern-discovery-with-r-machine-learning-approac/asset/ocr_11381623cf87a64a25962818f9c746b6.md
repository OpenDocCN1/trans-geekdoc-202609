For a mutation operation, the slot of each non-elite RPN chromosome is replaced by a new RPN chromosome mutated from a randomly selected elite RPN chromosome. For a dual-chromosome crossover operation, the slots of two non-elite RPN chromosomes are replaced by two new RPN chromosomes generated through the crossover operation based on two randomly selected elite RPN chromosomes. These new RPN chromosomes are inserted into two slots of the non-elite RPN chromosome set. For the single-chromosome crossover or the self-crossover operation, only one elite RPN chromosome is selected. This new chromosome is inserted into the non-elite RPN chromosome set.

To demonstrate how GP works, a simple function approximation (or called a regression) problem was used. The function was designed as below, where $x, y$ and $z$ were three variables, $t$ was the function output and $\varepsilon$ was the regression error,

$t = (z - x) * (z + y) + \varepsilon$$

The introduction of an error term was based on the assumption that observed data may be corrupted with a noise. The error term in this function was following a normal distribution, $\varepsilon\sim\mathcal{G}(0,0.1)$. For this function, 300 data points were generated. Figure 8.21 shows the distribution of the target values, i.e., the $t$ values. The pool size was designed as 100. The elite set size was 10 and the non-elite set size was 90. The value of $\alpha$ was 0.9. The maximum learning cycle was 100. The other termination rule was designed as the stabilisation of the fitness measurement. If the fitness measurement is maintained and unchanged in ten cycles (shown in the equation below), the learning was terminated, with $\delta = 1e - 6$,

```
$$\frac{1}{N} \sum_{i=1}^{N} (t_i - \hat{t}_i)^2 \le \delta$$
```
