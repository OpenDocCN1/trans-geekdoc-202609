# 3.3.2 The Naïve Bayes algorithm

In both LDA and QDA, the independent variables are not assumed to be independent. For instance, the projection direction ($\mathbf{w}$) is assumed to be proportion to $\Sigma^{-1}(\mathbf{u}_2 - \mathbf{u}_1)$ in the LDA algorithm. The density of each class in LDA is formulated as $\exp\{-0.5\delta^T\Sigma^{-1}\delta\}/\sqrt{(2\pi)^d|\Sigma|}$, where $\delta = \mathbf{x} - \mathbf{u}$. If the variables in $(\mathbf{x})$ are mutually correlated, the covariance matrix $\Sigma$ will not be diagonal, i.e., the off-diagonal entries of $\Sigma$ will not be zero. If independent variables are mutually independent from each other, the corresponding covariance $\Sigma$ is degenerated to a diagonal matrix, i.e., its off-diagonal entries are zeros. If $\Sigma$ is diagonal, the determinant of a covariance matrix ($|\Sigma|$) can be simplified by the product of the diagonal entries, each of which is the variance of a variable. The decomposition of a covariance to the variance due to the independence between variables is implemented by $|\Sigma_k| = \prod \sigma_{ki}^2$. In this situation, the Naïve Bayes discrimination analysis algorithm [Rennie, et al., 2003] can be more useful. The definition of the Naïve Bayes is defined as belowow,

```
$f(\mathbf{x}_n|u_k, \Sigma_k) = \prod_{i=1}^d \exp\left(-\frac{(x_{ni} - u_{ki})^2}{2\sigma_{ki}^2}\right) \quad (3.19)$
```

where $	ext{diag}(\Sigma_k) = (\sigma_{k1}^2, \sigma_{k2}^2, \dots, \sigma_{kd}^2)$ and $\mathbf{x}_n = (x_{n1}, x_{n2}, \dots, x_{nd})$. It can be seen that the decomposition of the covariance matrix leads to the ignorance of the mutual correlation between the independent variables in a model. When the mutual correlation between variables is indeed minimal or insignificant, this approach can deliver a model with a better and efficient performance.
