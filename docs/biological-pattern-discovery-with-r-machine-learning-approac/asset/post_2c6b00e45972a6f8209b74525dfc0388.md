```
Z0=DGEList(counts, group, genes)
```

The working data Z0 was a list. It was composed of three entries, counts a count matrix, samples was a matrix of samples as well as initial normalisation factors (being one) and genes was a vector of gene symbols. Based on the working data Z0, the counts were normalised using the following function, which aligned the counts based on the normalization factors calculated from the count matrix.

# Biological Pattern Discovery with R

Z1=calcNormFactors (Z0)

The Z1$samples matrix had a similar data structure as the Z0$samples matrix. Both had the same count matrix. But named as samples from two working data sets were different. However, in Z1, the normalisation factors had used. Based on the normalised data matrix Z1, the negative binomial conditional likelihood function was used to estimate the dispersion value across all genes



Z2=estimateCommonDisp (Z1)

The Z2 object inherited some entries of the Z1 object. In the Z2 object, the raw counts data was inherited from previous data structures, such as Z0 and Z1. The normalised counts data was included in the Z2 object, which was saved in $pseudo.counts. The raw integer counts had been normalised. The value of $AveLogCPM stands for the average base logarithm of the counts-per-million for each row of counts.

Next, the empirical Bayes approach was used to estimate the tag-wise dispersion for all genes. The estimation function was the weighted maximum likelihood. The code is shown below,

Z3=estimateTagwiseDisp (Z2)

An edgeR model was constructed using exactTest based on the Z3 object,

```
model=exactTest(Z3)

# Gene Expression Pattern Discovery

Based on the constructed edgeR model, decideTestsDGE was called to discover DEGs.

```
sig=decideTestsDGE(model)
```

The object contained information of DEGs. For instance the following code was used to show the statistic. When sig was 0, the figure shows the number of non-DEGs. When sig was -1, the figure shows the number of down-regulated DEGs. When sig was +1, the figure shows the number of up-regulated DEGs.
