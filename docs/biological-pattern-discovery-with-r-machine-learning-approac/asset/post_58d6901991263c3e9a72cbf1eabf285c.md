## 8.2 Introduction

Most linear algorithms enjoy an excellent interpretation and explanation capability, but may not be sufficient to explain the interplay between residues in protease cleavage data or posttranslational modification data. Although the decision-tree algorithms and the random forest algorithms can be used to deliver intelligent rules, these algorithms may not deliver optimal rules because both types of algorithms derive rules based on the heuristic principles. Discovering the best solution for a system among a huge number of candidates is prohibitive and problematic if the exhaustive approach has to be used. Avoiding the expensive and exhaustive search strategies, the use of an optimisation process is considered as a reasonable strategy. Inspired by Darwin’s natural evolutionary theory, various evolutionary computation algorithms have been developed, aiming to mimic a natural evolutionary process using a computer program in a computer so as to examine how the rule of survival of the fittest be utilised for the optimisation problems of rule discovery [Fogel, et al., 1966; Holland, 1975; Goldberg, 1989].

There are mainly three types of evolutionary computation approaches. They are the evolutionary algorithms (EA), the genetic algorithms (GA) and the genetic programming algorithm (GP). The evolutionary algorithms are normally used to optimise a numerical system with many parameters which are required for optimisation. For instance, the evolutionary algorithm can be used to optimise the parameters of a neural network. This is because the conventional Newton’s method used to optimise the parameters is very likely stuck in a local optimum and the objective function of a neural network is complex [Angeline, et al., 1994; Brusic, et al., 1998; Bird, et al., 2019]. The use of the evolutionary algorithm can start with a pool of initial weights. The use of Newton approach for each individual set of weights can approach one which is the global optimum. Among many candidate solutions, the evolutionary algorithm can find the optimal solution through a process of evolutionary computing. This then can prevent the global optimum from being missed.

Figure 8.1 shows an example of how multiple candidates compete with each other to arrive at the global optimum. The objective function has three points with three objective values, namely $y_1, y_2$, and $y_3$. One of them ($y_1$) is the global optimum solution. There are five initial model parameters, i.e., $x_1, x_2, x_3, x_4$ and $x_5$. Newton’s method will generate five models. Each of the models updates its model parameters leading to these points. When the point of $y_1$ is reached, the other two points are thrown away. Therefore, it is less likely to miss the global minimum in this case.

Suppose the limit of candidate is three (not five) for the example shown in Figure 8.1. As shown in Figure 8.2(a), none of these three candidates can reach the global minimum $y_1$. The evolutionary computation can use an evolutionary operator to generate new candidates from these candidates. The new candidates may lead to some better initial points so that Newton’s method can be used to reach the global minimum. Although the original three candidates ($x_1, x_2$ and $x_3$) cannot reach the global minimum shown in Figure 8.2(a), after the evolutionary operation, these new candidates become $z_1, z_2$ and $z_3$ as shown in Figure 8.2(b), where two of them can reach the global minimum $y_1$ by using Newton's method.

The genetic algorithms are normally used for solving combinatorial optimisation, in which candidates can take a limited number of status such as binary status. The binary status includes the presence and absence of an object or a variable. If the problem is sufficiently large, exhausting all possible combinations in a modern computer may become infeasible. For instance, sequence homology alignment, which has been introduced in Chapter 7 of this book, is a combinatorial optimisation process. Fortunately, the genetic algorithms have been used to reach some optimal homology alignments between sequences [Chowdhury and Garai, 2017]. The genetic algorithms have also been used for trend prediction, which was organised as a combinatorial optimisation problem [Kim, et al., 2021].

The genetic programming algorithms are normally used for modelling a complicated system, where a system can be expressed by a mathematical equation of variables and the variables can interplay in such a system [Koza, 1992; Suganuma, et al., 2020]. Given a data set, the genetic programming can be used to discover an optimal mathematical equation by which the data are assumed to be generated. Therefore, this kind of machine learning algorithms can be used to discover the intelligence hidden in data and express the discovered intelligence using human-readable rules, such as the equations.

## 8.3 Genetic programming

The genetic programming algorithm (GP) has had applications in the analysis of various biological/medical data for pattern analysis [Gao and Loney, 2001; McKay, et al., 1997; Lin, et al., 2002; Yang, et al., 2003; Yang, et al., 2009]. In a GP model, a chromosome is used to represent a tree. Within such a model, an algebraic equation is commonly used to represent the relationship between variables. This kind of human-thinking-like intelligence is very useful in many applications, where the understanding of how model is trained, how the intelligence can be expressed and how a prediction is delivered is urgently required.

### 8.3.1 The genetic algorithm

As GP was developed based on the genetic algorithm (GA), it is better to briefly introduce GA first and introduce the basic operators used in GA because the main GA operators are also used in GP.

In GA, a combinatorial problem is expressed by a chromosome, which is a string. If a combinatorial problem is binary, the chromosome or the string for a problem is a binary vector. Suppose there are ten variables ($x_1, x_2, ..., x_{10}$) as the potential contributors to formulate a system. Before formulating a system, it is unknown whether all these variables must be employed or part of them can be employed. Suppose this ten-variable system is expressed by a function shown below, which is either an analytic equation or a complex function,

$y = f(x_1, x_2, ..., x_{10})$

To determine which of these ten variables should finally contribute to a system of a practical problem, a string of presence/absence of variables can be used. Such a string is called a chromosome.
