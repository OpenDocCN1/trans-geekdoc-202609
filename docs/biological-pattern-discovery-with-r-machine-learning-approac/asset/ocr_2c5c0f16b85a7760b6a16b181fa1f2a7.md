# 6.1.3 The Type I and Type II errors

A p value stands for a tolerated error when making a decision. For any decision made, there might be two types of errors. They are the Type I error and the Type II error. They are important subjects in all statistical significance analysis based on the use of p values [Markel, 1991; Yarandi, 1996; Biau, et al., 2010]. For a commonly critical p value 0.05, the error rate is 5% among the denied null hypotheses. This means that at least five of 100 null hypotheses, which have been rejected, may be true
