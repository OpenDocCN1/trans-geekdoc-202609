# 9.5 SARS-CoV-2 protease cleavage pattern discovery

The protease cleavage site identification problem has been well researched for several decades. It is still an important area for studying protein functions. Although the exercise in this area has been very successful, the ultimate objective of protease cleavage site identification or protease cleavage pattern analysis for drug design such as the inhibitor design problem is still challenging. The conversion from discovered protease cleavage profile to effective drug design is still not an easy job [Vizovisek, et al., 2016]. After evaluating recent models for the protease cleavage site discovery, it has been found that most machine learning models including deep learning models work very well. It has been suggested that the parallel as well as distributed computing should be the main method for fast and accurate discovery of protease cleavage sites Having Having the SARS-CoV-2 pandemic worldwide, urgent attention has been paid to the problem of how to discover the SARS-CoV-2 viral proteolytic cleavage sites. For instance, the novel S1/S2 site viral has been identified within the spike protein of SARS-CoV-2 [Javier, et al., 2020] and the furin [Xia, et al., 2020]. The question, which still waits for a good answer, is whether it is possible to quickly discover the cleavage pattern for developing drugs to fight against the pandemic. This may be an urgent challenging task at the moment.
