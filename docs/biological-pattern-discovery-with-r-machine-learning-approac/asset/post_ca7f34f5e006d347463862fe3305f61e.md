The text format of a pruned tree for the Iris data is shown below. It shows that the root node (A) received the whole data set. This space was partitioned using the first partitioning rule Petal.Length<2.45. After this partition, this subspace was pure for the Setosa class. This is noted by a vector (1 0 0) for this partition, which indicated no other classes except for the Setosa class in this subspace. The other subspace was mixed by other two classes of the flowers as indicated by a vector (0 0.5 0.5). It indicated that the half (50%) of this subspace was occupied by the Versicolor flowers and the other half (50%) of this subspace was occupied by the Virginica flowers. This subspace was further partitioned by the branch node B which employed the second partitioning rule, i.e., Petal.Width<1.75. This partitioning rule generated one subspace, which was composed of 54 Versicolor flowers and five Virginica flowers. Therefore based on this node (in a leaf), the probability of classifying a flower to the Versicolor class was 91% and to be the Virginica class was 9%. The other subspace was composed 46 Virginica flowers and one Versicolor flower. On this leaf node, the probability of classifying a flower to the Virginica class was 98% and to be the Versicolor class was 2%.

```
root 150 100 setosa (0.33 0.33 0.33)
A) Petal.Length<2.45 50 0 setosa (1 0 0) *
   Petal.Length>2.45 50 versicolor (0 0.5 0.5)
B) Petal.Width<1.75 54 5 versicolor (0 0.91 0.99) *
   Petal.Width>1.75 1 virginica (0 0.92 0.98) *
```

# 3.6.4 The C50 algorithm

The earliest version of decision tree was Leicester Dichotomous 3 (ID3), which was developed by Ross Quinlan [Quinlan, 1986]. ID3 was updated to C4 [Quinlan, 1993]. C5.0 (R package C50) is the most recently updated version. The basic measurement used in this algorithm for recursively partitioning a data space is the information gain. One of the best features of C50 is its graphical presentation. The R function of C50 is shown below C5.0(formula,data,trials)

# 3.6.7.6 Factor Xa protease data classification

An important feature of the decision tree algorithms is that they can handle non-numerical data. For instance, both CART and C5.0 can be applied to the factor Xa protease cleavage set directly without an encoding process [Yang, et al., 2006], which was composed of cleaved and non-cleaved peptides. The structure is a string of the amino acids, which are non-numerical. The structure of the factor Xa protease sub-sequences are $R_4R_3R_2R_1R'_1$, where cleavage happens between $R_1$ and $R'_1$. These five residues were labelled as P1, P2, P3, P4 and P5 in data. Figure 3.45(a) shows the CART tree model for this data set and Figure 3.45(b) shows the C5.0 tree model for this data set.
