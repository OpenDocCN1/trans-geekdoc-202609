# 8.1 A biological question — protease cleavage pattern discovery

The main data used in either the protease cleavage pattern discovery or the posttranslational modification pattern discovery are peptides. A peptide is a short sequence cut from a long sequence, which normally is between a few to a dozen of residues. There are two key problems of peptide pattern discovery. They are the poly-protein cleavage activity caused by various proteases and the post-translational modification caused by various chemicals. Many diverse functions in proteins are due to a wide distribution of these proteases and chemicals in nature. Both subjects have been extensively researched in the protein science. For instance, the studies cover many areas as protein chemistry, proteomics, and biopharmaceutical manufacture, peptide mass fingerprinting, protein fragmentation, protein domain separation and pattern activity recognition [Cheronis, 1993].

A peptide used for the protease cleavage pattern discovery is commonly expressed as $R_m \dots R_2R_1R'_1R'_2 \dots R'_n$, where $R_{1\le i\le m}$ stands for the N-terminal residues and $R'_{1\le j\le n}$ stands for the C-terminal residues. The cleavage happens between $R_1$ and $R'_1$. A peptide used for the post-translational modification pattern discovery is commonly expressed as $R_m \dots R_3R_2R_0R'_1R'_2 \dots R'_n$, where $R_0$ is the modification site. Most machine learning models constructed for peptide pattern discovery treat residues as mutually independent variables. For instance, the binary encoding approach encodes each residue using a binary vector and the bio-function function introduced in Chapter 3 of this book employs a mutation matrix to align two peptides as to encode peptides. The alignment between two peptides is a linear sum of the mutation probabilities between two peptides pair-wise. Therefore, potential residue interplay has not been considered in a modelling process of peptide pattern analysis using both encoding approaches.
