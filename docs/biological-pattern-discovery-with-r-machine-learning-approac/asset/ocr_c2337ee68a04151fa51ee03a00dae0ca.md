# Responsive Gene Discovery

$F = \frac{S_B^2}{S_W^2} \quad (2.23)$

It can be seen that the $F$ statistic should be maximised. This is because maximising $S_B^2$ is equivalent to the maximisation of the $F$ statistic and minimising $S_W^2$ is equivalent to the maximisation of the $F$ statistic as well. When trying different cluster numbers, different $F$ statistic values will be calculated. To find the best cluster model structure, it is therefore required to maximising the $F$ statistic. This means that the best cluster model structure will correspond to the maximised $F$ statistic for a specified cluster number.

Because it is not easy to determine a good threshold for the $F$ statistic, a $p$ value is used for the significance analysis. Figure 2.30(a) shows a data with nine clusters. The distribution of $p$ values is shown in Figure 2.30(b), where 15 models, which employed two, three, till sixteen clusters, were tested. If the critical $p$ value was 0.01, the selected model structure was eight clusters because it was the first cluster with a $p$ value being less than 0.01 in the $p$ value distribution. It was one less than the true cluster number.
