A negative logarithm of $\mathcal{L}$ leads to

```
$O = \frac{1}{2}\{\alpha(\mathbf{Sw}-\mathbf{y})^t(\mathbf{Sw}-\mathbf{y}) + \beta\mathbf{w}^t\mathbf{w} + \vartheta\alpha^2 + \tau\beta^2 \ -Nlog\alpha - Klog\theta - logr\} \quad (3.60)
```

The maximum a posteriori procedure is used to estimate parameters for Bayesian BBFFN [Yang, 2005b]. The parameters are updated in a loop with the initialised values for $\mathbf{w}$, $\vartheta$ and $\tau$. The parameters $\alpha$ and $\beta$ are estimated at first. The estimate of $\alpha$ is shown below, where $\mathbfmathbf{e}$ is an error vector between a model output vector $\hat{\mathbf{y}}$ and a target vector $\mathbfmathbf{y}$,

```
$\alpha = \frac{-\mathbf{e}^2 + \sqrt{\mathbf{e}^4 + 8\vartheta N}}}{4\vartheta} \quad (3.61)
```

The estimate of $\beta$ is shown below,

```
$\beta = \frac{-\mathbf{w}^t\mathbf{w} + \sqrt{(\mathbf{w}^t\mathbf{w})^2 + 8\tau K}}}{4\tau} \quad (3.62)
```

After $\alpha$ and $\beta$ have been estimated, $\mathbf{w}$ is estimated using the following equation,

```
$\mathbf{w} = \alpha(\alpha\mathbf{S}^t\mathbf{S} + \beta\mathbf{I})^{-1}\mathbf{S}^t\mathbf{y} \quad (3.63)
```
