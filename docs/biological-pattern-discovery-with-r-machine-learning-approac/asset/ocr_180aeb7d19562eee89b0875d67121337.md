# 3.6.7.3 The classification and regression tree algorithm

Constructing a classification tree model is based on a series of optimisation processes, each of which is implemented by measuring the value of a purity or impurity index aforementioned for each partitioning rule. The CART algorithm can be used for both classification analysis and regression analysis. It works in three steps [Breiman, et al., 1984].

In the first step, a tree is grown for a data set based on the recursive partitioning of a data space using a series of partitioning rules. A decision-making node is created in a tree for every partitioning rule. Every node is composed of two parts. One is a selected variable (such as x) and the other is a selected threshold (such as T). The selection of T is based on the minimisation of the Gini index or the maximisation of the entropy index (the information gain) among many candidate partitioning rules. A logic operator is used to combine them to generate a logic expression for producing a partitioning rule, such as x < T. A data space, which is either an original space or a previously partitioned subspace, is called a working space for testing a newly generated partitioning rule. Suppose a partitioning rule is defined as a logic expression, i.e., x < T. A working space is divided into two subspaces by testing this logic expression. One of two subspaces is composed of data points that satisfy this logic expression, i.e., x < T. The other subspace is composed of the rest of data points. These data points violate this logic expression, i.e., x  T or x ≥ T. An impurity is evaluated for each newly partitioned subspace and hence a new node. If the Gini index is zero, no further partitioning is required from this new node. Each node below this node is further labelled according to the class property of the data points in the corresponding subspace. Such a node with a labelled class is called a leaf in a decision-making tree.
