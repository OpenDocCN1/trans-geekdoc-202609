# Whole Genome Pattern Discovery

The alignment-free sequence comparison package kmer was also used to analyse this data set. Instead of using the Euclidean distance, the distance between the k-mer patterns from multiple sequences was calculated in a different way. First, a F statistic was calculated using the following equation,

```
$F = \sum_{\theta \in \Theta} \frac{\min(N_1(\	heta), N_2(\	heta))}{\min(L_1, L_2) - k + 1} \quad (7.16)$
```

$\Theta$ was a set of all k-mers, $\theta$ was one of k-mer, $N_1(\	heta)$ and $N_2(\	heta)$ stands for the frequency of $\theta$ in two sequences and $L_1$ as as $L_2$ represented lengths of two sequences. The distance between two sequences was calculated as

```
$d = \frac{\log(0+F) - \log(1.1)}{\log(0.1)} \quad (7.17)$
```

