The K-fold cross-validation, which is also named as the rotation-validation approach, divides a data set into K subsets and builds up K models [Devijver and Kittler, 1982]. Each of K models is trained on the K – 1 folds (subsets) and tested on the reserved one subset, which is called a testing subset, in turn. The final performance is evaluated on all K test subsets of the K models. Figure 3.15 shows a 3-fold cross-validation diagram. The K-fold cross-validation is commonly implemented using a loop, which will rotate the subset of samples to be selected for training and testing. The other important feature of the K-fold cross-validation approach is that each data point will be tested for exactly one time.

Fig. 3.15. A diagram of 3-fold cross-validation. From left to middle, two folds are selected for training a model. From right to middle, one fold is selected for testing.

The Jackknife test [Quenouille, 1949; Bishop, 1996], which is commonly used for a median- or small-sized data set, is a typical case of the K-fold cross-validation when only one data point is reserved for testing every time. Suppose there are N points. Rather than constructing K models using the K-fold cross-validation, N models will be constructed using the Jackknife test approach for the generalisation of test of a supervised model. An important benefit of the Jackknife test is its robustness because there is no uncertainty when using the Jackknife test. There is no random sampling process regarding data division in a Jackknife test process.
