#  6.5.4 Simulated data analysis

The data was composed of 1,000 simulated genes with 40 replicates. Among these simulated genes, 100 were designed as bimodal genes. In addition, 20 genes (ten unimodal and ten bimodal) were composed of maximum two outliers. Table 6.9 shows four confusion matrices for the LR (likelihood ratio) test, the GM (gap maximisation) test and the BI (bimodal index) test. Figure 6.41 shows the ROC curves for three test models (GM, LR and BI). The GM and the BI tests worked well compared with the LR test.

Table 6.9. The confusion matrices of the LR, BI and GM tests run on the simulated data set for the gene expression bimodality pattern discovery simulation. UN stands for unimodal. BM stands for bimodal. MCC stands for the Mathews correlation coefficient [Matthews, 1977].

Figure 6.42 shows the logarithm gene expression profile of a designed bimodal gene. The p value of the GM test was 0.0065. However, the LR test failed to identify it. The bimodal index test also failed to identify this bimodal gene. Its bimodal index test value was 0.69, but the threshold (BI0) for separating the bimodal genes from the unimodal genes for this whole simulated data set was 1.84.
