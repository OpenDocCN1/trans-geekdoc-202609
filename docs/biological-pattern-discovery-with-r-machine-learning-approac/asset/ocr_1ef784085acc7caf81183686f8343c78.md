For instance, to provide accurate discrimination between benign and malignant tumours, researchers have employed deep learning algorithms to construct predictive models based on either biomarkers or images [Coudray, et al., 2018; Munir, et al., 2019; Shen, et al., 2019; Campi, et al., 2020; Pathak, et al., 2021; Kumar and Bakariya, 2021; Lotter, et al., 2021; Masoudi, et al., 2021].

Different deep learning algorithms have also been considered for different data sets and requirements. The algorithms include different learning strategies as static models like the convolutional neural networks and the generative adversarial models as well as the dynamic models like restricted Boltzmann’s machine and the recurrent neural networks [Munir, et al., 2019]. Based on a deep network model constructed on the image data, the detection accuracy for breast cancer [Shen, et al., 2019; Lotter, et al., 2021], lung cancer [Coudray, et al., 2018; Kumar and Bakariya, 2021] and prostate cancer [Masoudi, et al., 2021] as well as other cancers have significantly improved. Deep learning has also been used to detect differentially expressed genes from a single-cell RNA-sequencing data set [Cui and Wang, 2021], to discriminate the SARS-CoV-2 genome from other viral genomes [Lopez-Rin, et al., 2021].

However, no matter how successful neural network and deep learning algorithms are in different areas, the advantages of the linear models have become the disadvantages of neural network and deep learning models [Heaven, 2019; Waldrop, 2019]. After a neural network model or a deep neural network has been well trained, its tolerance capability is still in doubt. This is not a surprise because most of these models are well trained in house using well-prepared data [Heaven, 2019]. Heaven’s opinion is that such a model is too complicated so that it pick up too many details, making it fragile. George Hinton, the pioneer of the theory and algorithms of neural networks and deep neural networks, also had a question: “what is missing?” Waldrop has suggested to consider the employment of separate networks rather than a single network which has a too complicated structure.
