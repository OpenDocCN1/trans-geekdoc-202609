# Summary

This chapter has introduced how the genetic programming approach can be used to provide another way to discover intelligent rules for the peptide pattern discovery. The most striking features of the genetic programming approach are its great interpretation capability as well as the possibility of discovering the optimal rules without exhausting all possible candidates. This chapter has introduced the min-max function, which is especially useful for dealing with the protease cleavage pattern discovery. In addition, the reverse Polish notation has been used to express the chromosomes of rules for mimicking an evolution process for the optimal solutions. By the mutation operator, the dual-chromosome operator and the single-chromosome crossover are designed and used for breeding new RPN chromosomes of rules have been introduced and demonstrated in this chapter as well. In order to avoid the possibility of a homogeneous population and increase the diversity among candidates in a GP pool, the process called the revolution has been introduced. This chapter has applied the genetic programming approach with the min-max function to the factor Xa protease cleavage data analysis. The resulting decision-making rule shows a good discrimination power and has a good interpretation capability.
