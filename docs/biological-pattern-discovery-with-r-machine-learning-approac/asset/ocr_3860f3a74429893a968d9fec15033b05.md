In fact, there are many different mutation matrices in addition to the Dayhoff mutation matrix; each of them was developed based on different families of protein sequences with different backgrounds. Therefore, differences may exist between these mutation matrices. The problem of which mutation matrix is the best for modelling a specific data set using the bio-basis function needs careful consideration. Certainly, the use of one single mutation matrix generates a typical set of bio-basis features. The use of different mutation matrices thus generates different sets of bio-function features. Optimising these bio-basis features is of course important issue to make a protease cleavage discrimination model as accurate as robust. Therefore, one attempt was to use as many available mutation matrices as possible to model this factor protease cleavage data. A bio-DNN model employing ten mutation matrices shown in Table 3.11 was thus a mixture bio-DNN model. Figure 3.36(b) shows the ROC curve of a mixture bio-DNN model constructed for the factor Xa protease cleavage data.

Many machine learning algorithms are able to deliver a good prediction model for a problem through a proper training process.
