# Chapter 9

# Advanced Subjects

Biological/medical systems are highly complex. It is still a challenge to improve the accuracy, robustness and interpretation capability of approaches or models for biological pattern discovery. The previous chapters in this book have only covered a very small proportion of biological pattern discovery subjects. Even for these subjects, there have been ongoing advanced studies. This last chapter is dedicated to a brief introduction of several promising new trends in this area.

# 9.1 Neural networks and deep learning

In addition to the accuracy of a constructed machine learning model, a very common question in most biological/medical experiments is how the phenomenon change can be explained by the genetic components. For instance, the explanation must be given when a disease has been diagnosed and the answer must be sought when one set of genes is very active while others are found silent in an experiment with an applied stress.

Before using machine learning algorithms to model biological/medical data for pattern discovery, the conventional statistical models, which are basically linear, are used, and they normally have an excellent interpretation capability. For instance, a linear regression model can show which explanatory variables have the most significant impact on the phenomenon change of a predictor variable.
