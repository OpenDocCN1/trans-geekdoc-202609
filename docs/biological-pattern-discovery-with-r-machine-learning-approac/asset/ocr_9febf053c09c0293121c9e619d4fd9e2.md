The data used by H2O object, which was done using of the following code,

```
x=as.h2o(x)
```

The classification variable was a factor vector. H2O ran an inbuilt validation process. The following code was used for this inbuilt validation

```
splits=h2o.splitFrame(x,c(alpha,beta))
```

The training function is shown below, where h1 and h2 were the numbers of hidden neurons in two layers, train.id and valid.id were obtained by h2o.splitFrame, response was the classification variable name in the data matrix, predictors was for all the independent variables and epochs was the learning cycle,

```
h2o.deeplearning(model_id='dl_model_first',
training_frame=train.id,
validation_frame=valid.id,
x=predictors,y=response,hidden=c(h1,h2),
epochs)
```
