# 8.3.1 The genetic algorithm

As GP was developed based on the genetic algorithm (GA), it is better to briefly introduce GA First and introduce the basic operators used in GA because the main GA operators are also used in GP.

In GA, a combinatory problem is expressed by a chromosome, which is a string. If a combinatory problem is binary, the chromosome or the string for a problem is a binary vector. Suppose there are ten variables ($x_1, x_2, ..., x_{10}$) as the potential contributors to formulate a system. Before formulating a system, it is unknown whether all these variables must be employed or part of them can be employed. Suppose this ten-variable system is expressed by a function shown below, which is either an analytic equation or a complex function,

$y = f(x_1, x_2, ..., x_{10})$

To determine which of these ten variables should finally contribute to a system of a practical problem, a string of presence/absence of variables can be used. Such a string is called a chromosome. Figure 8.3 shows two chromosomes of two potential solutions to this problem, where the upper panel shows that four variables $x_3, x_5, x_8$ and $x_{10}$ are employed to define the system. The lower panel shows that three variables $x_3, x_4$ and $x_{10}$ are employed to define the system. The upper panel of Figure 8.3 will end up with a model expressed as $f(x_3, x_5, x_8, x_{10})$ and the lower panel of Figure 8.3 represents a model... Both are more parsimonious than the use of ten variables. However, which has the best fitness to a system is unknown and needs an evaluation.
