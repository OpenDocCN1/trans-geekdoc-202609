```
$$\hat{Y} = \sum_{n=1}^{K} w_n \mathcal{G}(\mathbf{x}|\mathbf{x}_n, \vartheta_n) = \mathbf{G}^t\mathbf{w}$ $(3.38)$
```

where $\mathbf{x}_n \in \mathbb{R}^d$ is the $n^{th}$ basis function, $\mathbf{x}$ has the same dimension as $\mathbf{x}_n$, i.e., $\mathbf{x} \in \mathbb{R}^d$, and $w_n$ are the $n^{th}$ smoothing parameter and weighting parameter, $\mathcal{G}(\cdot)$ is the basis (normally Gaussian) function, and $\hat{y}$ is the model output or prediction for $\mathbf{x}$. This transformation maps any $d$-dimensional data space $(\mathbf{x,x}_n \in \mathbb{R}^d)$ to a $K$-dimensional kernel space. It is assumed that this $K$-dimensional kernel space has a linearity property, i.e., a linear relationship between a dependent variable or phenotype variable (y) and the features or the basis function $(\mathcal{G}(\cdot))$.

To establish a RBFNN model, the likelihood function is commonly used as an objective function for classification problems. Suppose the sigmoid is used by RBFNN for the output transformation based on the following definition, where the sigmoid output is treated as a probability,

```
$p(\mathbf{x}_n) = \frac{1}{1 + \exp(-\hat{y}_n)}$ $(3.39)$
```

The likelihood function for $N$ data points is defined as below using the Bernoulli function [Uspensky, 1937]

```
$$\mathcal{L} = \prod_{n=1}^{N} P(\mathbf{x}_n|y_n) = \prod_{n=1}^{N} p(\mathbf{x}_n)^{y_n}(1 - p(\mathbf{x}_n))^{1-y_n}$ $(3.40)$
```

For a regression analysis problem, an error function shown below is commonly used,

```
$$\varepsilon = \frac{1}{N} \sum_{n=1}^{N} (y_n - \hat{y}_n)^2$ $(3.41)$
```

RBFNN has a wide application in many areas including biological/medical pattern analysis. For instance, RBFNN has been used to examine how pear rootstocks tissue culture media is formed [Jamshidi et al., 2019] and to remove tomography ring artifacts [Chao and Kim, 2019].
