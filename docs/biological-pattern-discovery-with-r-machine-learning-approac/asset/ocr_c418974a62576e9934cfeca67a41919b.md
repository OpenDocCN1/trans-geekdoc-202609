7.17(a) shows the PCA analysis for the word matrix. Again it shows a perfect discrimination power between two groups of SARS genome sequences. The discrimination power of the k-mers word frequency library has been already researched in the literature [Ghandi, et al., 2016; Fletez-Brant, et al., 2016; Lee, 2016; Beer, 2017; Shrikumar, et al., 2019].
