For a classification problem, $\epsilon_m$ can be replaced by a classification accuracy measurement such as the area under an ROC curve (AUC). Suppose it is denoted by $\omega_m$. The fitness measure is revised as below, where $\sigma(\ell_m)$ is the sigmoid function of the size of the $m^{th}$ RPN chromosome,

```
$$\varphi_m = \alpha \times \omega_m + (1 - \alpha) \times \{1 - \sigma(\ell_m)\} \quad (8.8)$
```

In the equation above, $0 \le \omega_m \le 1$ and $0 \le \sigma(\ell_m) \le 1$ are constrained. The above fitness must be maximised to discover the best model described by an RPN chromosome, i.e.,

```
$$\varphi^* = \text{argmax}{\varphi_m}, \forall m \in [1, M] \quad (8.9)$
```

The fitness measurements of $M$ models expressed by $M$ RPN chromosomes have been measured, the $M$ RPN chromosomes are sorted in an ascending order for a regression problem and in a descending order for a classification problem.

The $M$ RPN chromosomes are divided into two parts. One part with the optimal fitness measurements is named as an elite set of RPN chromosomes and the corresponding models are called the elite models. The rest of RPN chromosomes are called non-elite ones. The task which follows is to use the elite chromosomes to create or breed new chromosomes to replace the non-elite chromosomes. Doing this is in that the newly generated chromosomes may produce new models with better fitness measurements than the old non-elite models. Therefore the next task is to breed new RPN chromosomes based on the elite RPN chromosomes.
