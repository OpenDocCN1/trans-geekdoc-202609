Figure 5.1 only shows a case where a spectrum is not contaminated by noise. A real spectrum is often contaminated by noise. For instance, Figure 5.2 shows an example of the milk MALDI-TOF MS spectrum [Liland, et al., 2009; Liland, et al., 2010]. It can be seen that there are many artifacts (noise) in addition to the signals along the baseline. Therefore, statistical methods must be used to deal with such a noisy spectrum for an efficient and effective signal detection process.
