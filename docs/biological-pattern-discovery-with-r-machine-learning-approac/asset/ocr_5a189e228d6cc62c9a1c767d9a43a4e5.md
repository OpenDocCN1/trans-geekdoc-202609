The radius is calculated as the distance between $x$ and the furthest nearest neighbour. The volume $V_d$ is calculated by the following equation:

```
$V_d = \frac{\pi^{d/2}}{\Gamma(\frac{d}{2} + 1)} \quad (2.8)$
```

Figure 2.12 shows an application of this K-nearest neighbour approach for estimating the density of a Gaussian distribution with different nearest neighbours. The density employing ten nearest neighbours is non-smooth. The density employing 50 nearest neighbours improves the smoothness. The density employing 100 nearest neighbours seems the best in terms of the smoothness and its capability of capturing the density shape. It can be seen that a density function can be more smooth if more nearest neighbours are employed.

There is no easy-to-use R package for the K-nearest neighbour density estimation for one-dimensional data so far. The following code is a simple alternative.

```
knn=function (x, z, K, d)
{
D=abs (x-z)
or=order (D)
subset=x[or[1:K]]
N=length (subset)
```
