```
$I_G(x=	au) = \sum_{k=1}^{K} p_k(\tau)[1 - p_k(\tau)] \quad (3.75)$
```

It can be seen that, for a subspace for one class, $p_k(\tau)=1$. Or, $p_k(\tau)=0$ and $1-p_k(\tau)=1$. Therefore, $p_k(\tau)[1-p_k(\tau)]=0$. If all subspaces are pure for one class, $I_G(x=	au)=0$. If a partitioning rule generates a random classification model, $p_k(\tau)=0.5$. The value of $I_G(x=	au)=0.25 \times K$. Therefore, the minimum value of the Gini index is zero when set of partitioning rules constitute a perfect classification model and the maximum value of the Gini index is $0.25K$.

The other measure should be information gain based on the entropy theory, which is defined below, as $\log_2(1+p_k(\tau))$ has been replaced by $\log_2$ for avoiding an infinite value in case $p_k(\tau)$ approaching zero,

```
$I_E(x=	au) = \sum_{k=1}^{K} p_k(\tau)\log_2(1+p_k(\tau)) \quad (3.76)$
```

The information gain should be maximised for a better partitioning rule. If a partitioning rule generates a pure subspace, $p_k(\tau)=1$. Therefore, $p_k(\tau)\log_2(1+p_k(\tau))=1$. The maximum information gain is thus $K$.
