# 3.6.1 Multi-layer perceptron (MLP)

The multi-layer perceptron (MLP) or artificial neural network stands for a class of computational algorithms for pattern analysis [Rumelhart, et al., 1986; Bishop, 1996]. MLP rooted from the human brain research and the modern computational technology. It is also called an information processing system because it it can be used for knowledge discovery and memory association with a large-scale data mining process. The typical case is that MLP can be used to discover the pattern underlying data and to reconstruct it without a priori knowledge about what the pattern function looks like. The most important feature that makes MLP an excellent intelligent processing system is its power of storing knowledge or intelligence learned from a data set. Due to this powerfulness, MLP has been widely used for pattern discovery and recognition in many areas including biology and medicine. For instance, it has been used for amelioration of inflammatory bowel disease based on mice model [Sabater, et al., 2019]. Another recent study using MLP has been the investigation of generating single-cell RNA-seq through learning nonlinear gene-gene relationship of complex, multiple cell type samples [Marouf, et al., 2020].

# 3.6.1.1 The structure of MLP

Figure 3.21 shows one example of MLP structure, in which there are three layers of computing units called neurons. They are a layer of the input neurons ($x_1$ and $x_2$), a layer of the hidden neurons ($z_1$ and $z_2$) and a layer of the output neuron ($y$). Suppose

```
$z_1 = f_1(x_1, x_2)$
z_2 = f_2(x_1, x_2)$
y = f_3(z_1, z_2)$ $\quad\quad (3.29)
```

The dependent variable $y$ is then a complex function of the independent variables $x_1$ and $x_2$,

```
$y = f_3\{f_1(x_1, x_2), f_1(x_1, x_2)\}$ $\quad\quad (3.30)
```
