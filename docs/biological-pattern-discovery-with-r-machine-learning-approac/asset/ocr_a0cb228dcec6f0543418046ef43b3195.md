In the second step, a tree is pruned if it does not generate a significantly better prediction performance compared to a simpler (smaller) tree. Note that when a tree pruning process is completed, a leaf node may not be pure for one class of data points. In this case, a probability that data points belonging to one class in the corresponding subspace is calculated for the leaf node. For instance, if $m < n$ of data points belong to the class $A$ in the corresponding subspace denoted by a leaf, the probability of the class $A$ is commonly denoted $m/n$ and the probability of the class $B$ is commonly denoted by $(n-m)/n$ for the leaf.

A pruning select may produce multiple simpler trees. Therefore, an optimal tree is selected among multiple pruned trees for the optimal generalisation capability in the last step of CART.

Using a constructed CART tree or model for making predictions on novel data or interpreting the decision-making process using the model will scan a tree from its root node gradually downwards to a leaf. The root node examines a variable's value against a threshold to determine where to move, i.e., to its left branch or its right branch. The same examination applies to all the following nodes of a tree until reaching a leaf. When a leaf is reached, the prediction is made through maximising two probabilities, i.e., $m/n > (n-m)/n$ or $m/n \le (n-m)/n$.

CART still has a wide application in biological/medical pattern analysis. For instance, it has been used to study how $eta$-Lactam pharmacodynamics plays a role in critical illness due to the infection caused by Gram-negative blood stream [Wong, et al., 2020]. The study has discovered that a $eta$-lactam fCmin/MIC > 1.3 can be a critical indicator of critical illness among patients with Gram-negative BSI. Therefore, they have recommended to consider the possibility of using this as an antibiotic dosing target. In a study of early detection of blood stream infection among older patients, CART has been used to discover the decover the break point of some predictive parameters [Walker, et al., 2020]. The study has discovered some significant predictive values for the management of BSI among older patients.
