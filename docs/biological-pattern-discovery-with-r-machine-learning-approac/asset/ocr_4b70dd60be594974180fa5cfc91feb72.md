In the above equation, $\delta(x_N)$ is the current (last) local alignment, which needs to be optimised while $\sum_{i=1}^{N-1} \delta(x_i, y_i)$ is all the alignments before the last pair of residues from two sequences. It is assumed that $\sum_{i=1}^{N-1} \delta(x_i, y_i)$ has been optimised. For any local alignment, the above distance can be re-written as below, where $x_m$ and $y_m$ stand for the residues of the current local alignment while $\sum_{i=1}^{m-1} \delta(x_i, y_i)$ stands for the alignment for two sequences from the first pair of aligned residue till the $(m-1)^{th}$ pair of aligned residues,

```
$d(x_m,y_m) = \sum_{i=1}^{m-1} \delta(x_i, y_i) + \delta(x_m, y_m) \quad (7.5)$
```

Suppose a representative (parental) sequence without an insertion or a deletion is expressed as

```
$x = (x_1, x_2, \cdots, x_N) \quad (7.6)$
```

Such a sequence can become evolutionary sequence with the mutations, the deletions or the insertions. Suppose there are two sequences for an alignment. They are $x_1x_2 \cdots x_M$ and $y_1y_2 \cdots y_N$. There are three incremental alignments in the forward propagation stage. There are therefore remaining residues from two sequences $x$ and $y$ as the alignment candidates. Two sequences with the remaining residues are denoted by $x_{m+1}x_{m+2} \cdots x_M$ and $y_{n+1}y_{n+2} \cdots y_N$. The first residue of sequence $x$ is $x_{m+1}$ and the first remaining residue of sequence $y$ is $y_{n+1}$. They are the likely candidates to be picked up for the next alignment.
