The commonly used sequence homology alignment algorithms may not be the best approach to model about 59,000 sequences to discover the genetic differentiation of this virus across countries. Therefore, this chapter will introduce the alignment-free sequence comparison approaches that play a key role for a large-scale multiple sequence comparison problem.

Chapter 8 will focus on the global optimisation pattern discovery problem. A typical problem is how to find the optimal and intelligent rules for protease cleavage pattern discovery. This chapter will introduce the genetic programming algorithm and introduce the novel min-max function for the discovery of the optimised decision-making rules for a protease cleavage data. How the genetic programming algorithm works for different kind of data will be introduced in this chapter.

Chapter 9 will outline several recent developments or future research directions in the area of biological pattern discovery using machine learning approaches. It covers some cutting-edge studies including the effort of how to generate sparse neural networks to make models more useful for the interpretation, the quantum computing for developing novel and more powerful machine learning algorithms, the advanced issues of incorporating the evolutionary computation approaches with the deep learning approaches to further promote the pattern discovery power as well as the advanced protease cleavage problems.

The chapters of this book can be read separately because each of them has been written for addressing a specific biological pattern problem associated with different machine learning algorithms.

Finally, all introductions and discussions in this book are based on the R programming language, which is a good platform for statistical learning and machine learning. This provides a good opportunity to integrate the machine learning theory and algorithms with the workable environment for researchers, especially for the new researchers.
