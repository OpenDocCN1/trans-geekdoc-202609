# Genetic-Epigenetic Interplay Discovery

# 4.9.1 Methylation site to gene — the M2E models

The main objective of this M2E model was set to discover and analyse which of 910 DMSs were the main contributor to each of 1,250 DEGs. Afterwards, it was aimed to investigate whether the top-ranked DMS in a regression model for a DEG was a local or a remote methylation site in the genome. Based on the information, a statistical analysis was carried out to investigate the trend of the methylation-to-expression interplay pattern, i.e., being the local or remote interplay.

Suppose $X_g$ was used to represent a differential expression vector of the $g^{th}$ DEG, which was the target (dependent) variable of a regression model. In such a model, 910 DMSs were treated as the regressors or the independent variables. Moreover, $w$ was used to represent a vector of regression coefficients or model parameters for 910 regressors and **M** was used to represent a matrix of the differential methylation ratios of 910 DMSs. The **M** matrix has 114 rows and 910 columns. The regression model for the $g^{th}$ DEG was defined as,

```
$x_g = f(\mathbf{M}, \mathbf{w})$
```

Within such a regression model, f was designed as a regression function, which was either linear or nonlinear. In a constrained (such as RLR) linear regression model, the above equation was simplified as below,

```
$\mathbf{x}_g = \mathbf{M}\mathbf{w} + \lambda\mathbf{w}^t$
```

There were 1,250 regression models for 1,250 DEGs. These models were designed to investigate how DMSs, which were either local or remote methylation sites, contributed to the differential expression profile (pattern) of the $g^{th}$ DEG. Only the top-ranked DMSs were used for the impact analysis, if a remote DMS was ranked at the top, the distance between this remote DMS and the $g^{th}$ DEG was then investigated. The Lasso, RLR, SVM and random forest were used to model the relationship between the variables (between the $g^{th}$ DEG and all 910 DMSs) and rank variables.
