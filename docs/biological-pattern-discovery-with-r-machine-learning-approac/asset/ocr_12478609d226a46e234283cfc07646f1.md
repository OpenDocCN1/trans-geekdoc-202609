The most commonly used function for the computing nodes to process information and information transmission is called the sigmoid function. All three functions ($f_1, f_2$ and $f_3$) use this sigmoid function for processing, storing and bypassing information, where the input to the sigmoid function is weighted signal from lower-layer neurons. Figure 3.22 shows the sigmoid function. The sigmoid function transforms the interval $(-\infty, \infty)$ into the interval $(0, 1)$. For instance, the input for $z_1$ is shown below, where $x_1$ and $x_2$ are the lower-layer (input layer) neurons (or signals),

$w_{11} \times x_1 + w_{12} \times x_2 \quad\quad (3.31)$

The output of $z_1$ is defined as a sigmoid function which is shown below,

$1 + e^{-w_{11}x_1-w_{12}x_2} \quad\quad\quad (3.32)$

The output of $z_2$ and the output of $y$ employ the similar function.
