## 2.3.1 The hierarchical cluster analysis algorithm

The hierarchical cluster analysis algorithm merges data points gradually into a hanging tree [Jardine and Sibson, 1971]. Afterwards, such a tree is cut to generate subtrees if it is required. Each of the cut subtrees is treated as a cluster. The most attractive feature of the hierarchical cluster analysis algorithm is that the pairwise relationships between data points can be clearly generalised in a hierarchical structure.

The hierarchical cluster analysis algorithm has been used to classify red wines of two varieties using phenolic compounds analysis and discovered major clusters of red wines [Stoj, et al., 2020]. In a colon cancer study, it has been used to evaluate different approaches and revealed that Raman spectroscopy shows the best performance for colon cancer diagnosis [Depciuch, et al., 2020]. The hierarchical cluster analysis has also been used to discover extremely small volume of interesting molecules and to separate molecules based on bacteriophage-based colorimetric sensor array technology [Kim, et al., 2020]. In blood monocyte subtype research which aims to discover biomarkers for cardiovascular inflammation, the knowledge of human monocyte heterogeneity is imperfect. Therefore, a study has employed the hierarchical cluster analysis algorithm to discover circulating monocyte subtypes based on expression data provided by high-throughput flow cytometry arrays [Hoffmann, et al., 2020]. The study has discovered 242 specific markers and revealed some new markers which can define classical, intermediate and non-classical subtypes.

Given a data set $\mathcal{D}$, the algorithm finds a pair of data points $(\mathbf{x}_n \in \mathcal{D}$ and $\mathbf{x}_m \in \mathcal{D})$ with the least distance or the maximum correlation coefficient at one cycle of a clustering process and thus merge them.

```
$$(n,m) = \text{argmin}_{i,j}(\mathbf{x}_i - \mathbf{x}_j)^2 \quad \forall\mathbf{x}_i,\mathbf{x}_j \in \mathcal{D} \quad (2.18)$$
```

argmin stands for minimising an expression $(\mathbf{x}_i - \mathbf{x}_j)^2$ through enumerating the arguments, which are $i$ and $j$. The return of this calculation is a collection of two indices of data points $\mathbf{x}_n$ and $\mathbf{x}_m$, by which the distance between them is the least. The operation $\forall$ means 'for all'. Suppose two data points $(\mathbf{x}_n$ and $\mathbf{x}_m)$ satisfy the above condition and have been selected. They are merged and removed from $\mathcal{D}$. In addition, the median (or the mean) of them is inserted into $\mathcal{D}$. This mean or median is called a meta data. The operation for every merge is shown below,

```
$$\mathcal{D} = \mathcal{D} \setminus (\mathbf{x}_n, \mathbf{x}_m)$$
$$\mathcal{D} = \mathcal{D} \cup \omega_{nm} \quad (2.19)$$
```

where $\setminus$ is an operator called set for removing data from a set, $\cup$ is a union operator called set for adding new data into a set. $\omega_{nm}$ is the meta data, the mean of $\mathbf{x}_n$ and $\mathbf{x}_m$. size of $\mathcal{D}$ is reduced by one after every merge, if $\mathcal{D} = (1, 2, 3, 4)$, $\mathcal{D} \setminus (2, 3)$ removes 2 and 3 from $\mathcal{D}$ leading to a new set $\mathcal{D} = (1, 4)$. Moreover, $\mathcal{D} = \cup 2.5$ adds 2.5 to $\mathcal{D}$ resulting in $\mathcal{D} = (1, 4, 2.5). Note that 2.5 is the meta data point $\omega_{(2,3)}$ for the data points 2 and 3. This process continues until $\mathcal{D}$ contains only one meta data.

The output named `merge` of the `hclust` function is a matrix of $N-1$ rows and two columns, i.e., $(N-1) \times 2$ for $N$ data points. The output named as `height` of the `hclust` function is a vector of $N-1$ values recording $N-1$ merging heights. A subtree is such a structure, which is a part of the tree below a branch node including the root node. A subtree is called a lower-rank subtree. The subtree of the amino acids F, I, L is a lower-rank tree of the subtree of the amino acids W, F, I and L in Figure 2.17. Note that subtree is also a meta data during a clustering process. A subtree can either be a single data point such as the amino acid R or a lower-rank subtree.
