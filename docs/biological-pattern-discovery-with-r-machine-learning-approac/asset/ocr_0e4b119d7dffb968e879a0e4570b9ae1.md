The most popularly used estimation approach for the mixture algorithm is the expectation-maximisation (EM) algorithm [Dempster, et al., 1977], which is a two-step iterative procedure (the E step and the M step) starting from parameter initialisation using random values. The probabilities are estimated in the E step using the information of current model parameters, i.e., the cluster centres, the cluster covariance matrices and the mixing coefficients. If model parameters have not yet been optimised, information of probabilities is used to update model parameters in the M step. In other words, new model parameters are calculated in the M step based on the current cluster membership function values, which are the probabilities.

The mixture algorithm has been widely employed for analysing biological/medical patterns. For instance, it has been used to improve the accuracy of the infection prediction when investigating the Bovine viral diarrhea infection among cattle herds [Eze, et al., 2019]. The study revealed some interpretable epidemiologically clusters. Another recent study has employed the Gaussian mixture model for breast cancer diagnosis based on mRNA expression data which contains over 300 clinical samples of breast cancer and healthy tissue [Prabakaran, et al., 2019]. The study has demonstrated a significant value of a Gaussian mixture model for clinical practice. The Gamma mixture model has also been employed in an image analysis for developing unbiased pre-processing system of biological images [Llera, et al., 2019] and in a HIV test data analysis project [Rice, et al., 2019].
