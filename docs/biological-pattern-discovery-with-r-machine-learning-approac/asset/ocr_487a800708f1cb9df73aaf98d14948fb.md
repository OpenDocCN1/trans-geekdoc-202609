When there are large candidates for an optimisation process, the evolutionary computation approaches can be very powerful. The genetic algorithm has used for solving some global optimisation problems, which is normally a binary recombinational problem. For instance, the genetic algorithm has been used for optimising a discovery process of the demographic history for population imprints [Noskova, et al., 2020] and for researching how uncategorised nonsynonymous single nucleotide variation results in phenotypic effects [Korigo, et al., 2018], where deep learning was also incorporated. This study shows one important direction, i.e., whether two streams in artificial intelligence can be well integrated for a better pattern discovery task. In addition to binary optimisation problems, which can be dealt with using the genetic algorithm, there are many optimisation problems which are not binary, as the parameters of a neural network model. In this, the evolutionary algorithms can be well employed for discovering the best solution for a parametrised model. For instance, analysing the subpopulation formation problem within a cancer population based on genomics data is not a binary optimisation problem. Instead, continuous parameter optimisation is needed for gene expression data [Volkel, et al., 2020]. The genetic programming algorithm is different from the genetic algorithms which has a specific specification, which is used to optimise a system with a specific specification, which can be expressed using a language-based and human-friendly system as the reverse Polish notation used in Chapter 8 of this book. The rule discovered by the genetic programming algorithm is very human-intelligence-like. By tuning the specification using the breeding operators as the insertion, deletion, mutation, an optimised specification of a system can be found. The genetic programming hence, has been applied for automatic medical data classification for discovering intelligence rules for improving the decision-making accuracy [Kumar, et al., 2020]. To better understand a biological/medical system, the genetic programming may be very powerful in terms of interpretation and explanation. Recently, the evolutionary computation approaches have been combined into deep learning for better performance [Baldominos, et al., 2018; Albadr, et al., 2020; Beyaz, et al., 2020; Pham, et al., 2020; Prince, et al., 2020].
