There is no easy-to-use R package for the K-nearest neighbour density estimation for one-dimensional data so far. The following code is a simple alternative.

```
knn=function (x, z, K, d)
{
D=abs (x-z)
or=order (D)
subset=x[or[1:K]]
N=length (subset)
R=D[or[ K ]
return ( (K/N)*1/ ((sqrt pi)/gamma (1+d/2)) ) *R)
}
```

### 2.2.4 The semi-parametric approach

Both the parametric approaches and the non-parametric approaches enjoy their advantages when estimating a density for a data set. However they still have some limitations. The inflexibility of the parametric approaches and the space costing problem of the non-parametric approaches lead to the consideration of the semi-parametric approaches for density estimation. The semi-parametric approaches estimate a density function for a data set by assuming that a data set is drawn from a mixture of the finite number of components, which have the similar function as the kernels used in the kernel density estimation approach. Each component can be a single Gaussian distribution or a single Gamma distribution or [Olkin and Spiegelman, 1987; Duda, et al., 2000]. The number of components in a mixture is pre-defined or can be optimised using a statistic metric.

### 2.2.4.1 The Gaussian mixture

Below shows the Gaussian mixture of $K$ components, where $\mu_k.\sigma_k^2$, and $w_k$ stand for the mean, the variance and the mixing coefficient (weight) of the $k^{th}$ component, respectively,

```
$f(x_i) = \sum_{k=1}^{K} w_k \mathcal{G}(x_i|\mu_k, \sigma_k^2)$ (2.9)$
```

The log-likelihood function of such a model is defined as below, where $\beta_k = \sigma_k^{-2}$,

```
$log L \propto \sum_{i=1}^{N} \sum_{k=1}^{K} w_k \sqrt{\beta_k} \exp\left(-\frac{\beta_k}{2}(x_i - \mu_k)^2\right)$ (2.10)$
```

The maximum likelihood method is normally used to estimate the model parameters for a Gaussian mixture model. The following equations are used to estimate $\mu_k, \beta_k$, and $w_k$, respectively,

```
$$\mu_k = \frac{\sum_{i=1}^N f(k|x_i)x_i}{\sum_{i=1}^N f(k|x_i)}$$
$$\beta_k = \frac{\sum_{i=1}^N f(k|x_i)(x_i - \mu_k)^2}{\sum_{i=1}^N f(k|x_i)}$$
$$w_k = \frac{1}{N}\sum_{i=1}^N f(k|x_i) \quad (2.11)$
```

In the above equations, $f(k|x_i)$ is defined as below,

```
$f(k|x_i) = w_k \mathcal{G}(x_i|\mu_k, \sigma_k^2) \quad (2.12)$
```

The major difference between the non-parametric approach and the semi-parametric approach is the number of components. However, the semi-parametric approach is more flexible because the number of components can be estimated. The non-parametric approach is more computationally expensive because it requires to consider all data points.
