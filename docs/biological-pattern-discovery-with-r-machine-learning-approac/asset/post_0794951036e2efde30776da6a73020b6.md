## 3.6.1.3 From SLP (LDA) to MLP

MLP can be used for nonlinear classification analysis. Figure 3.24(a) shows a typical nonlinear classification problem which is called the XOR problem. A random data set was generated for the XOR problem, which is shown in Figure 3.24(b). LDA was applied to this data set. Figure 3.24(c) shows the density of the projections or predictions ($\hat{y}$) of the LDA model. It can be seen that two densities of two classes were definitely non-separable. This shows that it was impossible to find a single cutting point (as most linear classifiers do) to separate two classes of data points using this model. Table 3.6 shows the confusion matrix for applying LDA to this data set. It can be seen that the classifier gives nothing, but random division.

Suppose two LDAs are placed onto this XOR space, which has four data points labelled by $a, b, c$, and $d$, shown in Figure 3.25(a). These two LDAs are labelled by $\alpha$ and $\beta$. They are shown as two straight lines in Figure 3.25(a) because they are linear models. For the LDA, the data point $a$ is classified on the left side (assigned a class label as zero) and other three data points are classified on the right side (assigned a predicted class label as one). For the LDA $\beta$, the data point $b$ is classified on the left side (assigned a predicted class label as zero) and other three data points are classified on the right side (assigned a predicted class label as one). These predicted class labels are shown in the first two columns of Table 3.7. In addition to two LDAs, the third LDA is added on top of these two LDAs (namely, $\alpha$ and $\beta$). The third LDA examines whether the predicted class labels of LDA $\alpha$ are the same as the predicted class labels of LDA $\beta$. If the predicted class label of LDA $\alpha$ is the same as the predicted class label of LDA $\beta$, the top level LDA outputs a predicted class label one. Otherwise, the top level LDA outputs a predicted class label zero. Afterwards, four data points have been well-labeled or well-classified. Table 3.7 shows this result. ## 3.6.1.4 The R packages for MLP

There are several R packages for constructing a MLP model. Typical ones include nnet, elmNN and brnn. These packages were developed based on different learning mechanisms. The nnet package employs the traditional MLP learning mechanism which maximises a likelihood function [Ripley, 1996]. The elmNN package employs the extreme learning mechanism, i.e., sparse network learning [Huang, et al., 2012; Huang, et al., 2015]. The brnn package employs the Bayesian learning approach [Mackay, 1992].

To show how these three packages work, the seeds data was used again. Ten hidden neurons were used in three models. The Jacknife test was used for all three models. Table 3.8 shows three confusion matrices of these models. Figure 3.26(a) shows the ROC curves for these three models. All showed a similar performance.

Therefore 13 sets of models were constructed and they employed two, three, four, till 14 hidden neurons. For each set of models, the AUC values were recorded for the comparison. Figure 3.26(b) shows the result, where it can be seen that brnn preferred a modeling less hidden neurons while the other preferred a model employing more hidden neurons for getting a better performance, i.e., a greater AUC value.

## 3.6.2 Radial basis function neural network

The radial basis function neural network algorithm (RBFNN) is an extension of the kernel density estimation approach to the classification problems. The kernel density estimation approach is an unsupervised machine learning approach, which does not involve class labels and is only working on one set of experimental data, which is normally the genotype data when analyse biological/medical data. When there are two experimental data (one is the genotype data X and the other is the phenotype data y), the kernel density estimation approach can be extended to a classification analysis problem to generate a map X to y. This extension is called RBFNN and the basis function of RBFNN adopts a bell-shaped density distribution such as the Gaussian function.

Suppose there are N data points. A general format of a basis function method is defined as below, where x is a data point for its density, x_n is the data point with class information, vartheta is the smoothing parameter and f(x) is the estimated density.

$$f(x) = \frac{1}{N} \sum_{n=1}^{N} p(x|\vartheta) \quad (3.37)$$

The earlier application of RBFNN is for function approximation [Powell, 1977; Broomhead and Lowe, 1988]. Suppose there are K basis functions. The output of RBFNN is defined as below,

$$\hat{Y} = \sum_{n=1}^{K} w_n \mathcal{G}(\mathbf{x}_n, \vartheta_n) = \mathbf{G}^t\mathbf{w} \quad (3.38)$$

where $\mathbf{x}_n \in \mathbb{R}^d$ is the $n^{th}$ basis function, $\mathbf{x}$ has the same dimension as $\mathbf{x}_n$, i.e., $\mathbf{x} \in \mathbb{R}^d$, and $w_n$ are the $n^{th}$ smoothing and weighting parameter, $\mathcal{G}(\cdot)$ is the basis (normally Gaussian) function, and $\hat{y}$ is the model output or prediction for $\mathbf{x}$. This transformation maps any $d$-dimensional data space $(\mathbf{x,x}_n \in \mathbb{R}^d)$ to a $K$-dimensional kernel space. It is assumed that this $K$-dimensional kernel space has a linearity property, i.e., a linear relationship between a dependent variable or phenotype variable (y) and the features or the basis function $(\mathcal{G}(\cdot))$.

To establish a RBFNN model, the likelihood function is commonly used as an objective function for classification problems. Suppose the sigmoid is used by RBFNN for the output transformation based on the following definition, where the sigmoid output is treated as a probability,

$$p(\mathbf{x}_n) = \frac{1}{1 + \exp(-\hat{y}_n)} \quad (3.39)$$

The likelihood function for $N$ data points is defined as below using the Bernoulli function [Uspensky, 1937]:



$$\mathcal{L} = \prod_{n=1}^{N} P(\mathbf{x}_n|y_n) = \prod_{n=1}^{N} p(\mathbf{x}_n)^{y_n}(1 - p(\mathbf{x}_n))^{1-y_n} \quad (3.40)$$

For a regression analysis problem, an error function shown below is commonly used,

$$\varepsilon = \frac{1}{N} \sum_{n=1}^{N} (y_n - \hat{y}_n)^2 \quad (3.41)$$

RBFNN has a wide application in many areas including biological/medical pattern analysis. For instance, RBFNN has been used to examine how pear rootstocks tissue culture media is formed [Jamshidi et al., 2019] and to remove tomography ring artifacts [Chao and Kim, 2019].
