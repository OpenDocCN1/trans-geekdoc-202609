# 6.3.2 Discover DEGs for sequencing count data using edgeR

The Bioconductor package edgeR [Robinson, et al., 2009] can also be
used to discover DEGs on the sequencing count data. The airway
data was used again to show how edgeR works. The following function
was called to generate a working data, where counts was a sequencing
count matrix, groups defined sample class labels (experimental design)
 genes was a gene symbol vector,

```
Z0=DGEList(counts, group, genes)
```

The working data Z0 was a list. It was composed of three entries,
counts a count matrix, samples was a matrix of samples as well
as initial normalisation factors (being one) and genes was a vector of
gene symbols. Based on the working data Z0, the counts were normalised
