# 4.9 Epigenetic-genetic interplay discovery

The data were downloaded from GEO. GSE36001[Kresse et al., 2012], GSE53261 [Wagner et al., 2014] and GSE68909. GSE36001 contains human osteosarcoma cell lines. The study were 48,701 genes and 27,578 methylation sites. The study identified differentially expressed genes and differentially methylated sites. In this chapter, only genes with methylation sites and genes with the genomic base-pair location were used for the demonstration of the genetic-epigenetic interplay discovery. This led to 23,215 genes and methylation sites for the analysis. The data were composed of osteosarcoma cell lines and 6 normal cell lines. Because samples were paired, the cross-replication method was used to calculate differential expressions for each gene and to calculate differential methylations for each methylation site. For instance, the osteosarcoma cell lines were compared with each of 6 normal cell lines to calculate differential expression or methylation for one gene or methylation site. Finally a differential expression matrix of 114 columns and a differential methylation matrix of 114 columns were generated for identifying the differentially expressed genes and the differentially methylated sites.

The differentially expressed genes (DEGs) were identified using the limma package with a critical fold change value one and a critical p value 0.01, it resulted in 1,250 DEGs. The limma package will be introduced in Chapter 6. The differentially methylated sites (DMSs) were also identified using the limma package with a critical fold change value 0.5 and a critical p value 0.01. This led to 910 DMSs to be used. The reason of using these critical values was for generating roughly balanced DEGs and DMSs for the analysis in a normal computer.

Afterwards, two objectives were investigated for this set. The first was to investigate how the differential expressions of each DEG were contributed or determined by the differential methylations of 910 DMSs. This was called the methylation-to-expression pattern discovery. This set of models were called the M2E models. A regression model was constructed between one DEG and 910 DMSs which were used as the regressors. For the quantitative relationship between DEGs and DMSs have been modelled using the regression analysis methods, the most important DMS contributor of each DEG was identified and analysed. Moreover, whether the differential methylation of the local methylation sites or the remote methylation sites were the top contributor to the differential expression pattern of a gene was examined.

The second aimed to discover the expression-to-methylation pattern. This set of models were named E2M models. For each DMS, a regression model was constructed between its differential methylations and the differential expressions of 1,250 DEGs. Through this regression model, the quantitative relationship between the differential methylations and the differential expressions were used to identify the most influencing DEG for a DMS. Similarly, whether the differential expression of the local gene or the remote gene was the major contributor to the differential methylation of a methylation site was examined.
