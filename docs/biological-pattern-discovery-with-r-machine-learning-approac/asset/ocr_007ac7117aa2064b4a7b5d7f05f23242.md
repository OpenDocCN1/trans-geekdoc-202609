vector y, i.e., z = x ∪ y', where y' stands for a sorted vector of y. The z
vector is shown below, where n is the number of the control expressions,
m is the number of the case expressions, x_{i} is the $i^{th}$ control expression and
y_{k'} is the $k^{th}$ sorted case expression,

```
$z = (x_1, x_2, ..., x_n, y_1, y_2, ..., y_m) \quad (6.32)$
```

A cumulative S is defined as below,

```
$S_r = \sum_{i=1}^{r} z_i \quad (6.33)$
```

Based on the S statistic, the likelihood ratio statistic is defined as below,

```
$\lambda = \max_{n<i<n+m} \frac{iS_{n+m}/(n+m) - S_i}{\sqrt{i(1 - i/2)}} \quad (6.34)$
```

An approximate significance level will be calculated for the likelihood
ratio [Hu, 2008].

# 6.5.2 The bimodality index test approach

The bimodality index test approach assumes that the expressions of a
bimodal gene follow a mixture of two Gaussians. It also joins the control
replicates and the case replicates together into one vector for the test. The
mixture model for the bimodality index test is shown below, where $z_{i}$
stands for the $i^{th}$ expression in $z$, $\mu_{1}$ and $\mu_{2}$ stand for the mean values of
t Gaussians, $\sigma_{1}^{2}$ and $\sigma_{2}^{2}$ stand for the variances of two Gaussians,

```
$z \sim \pi G(\mu_1, \sigma_1^2) + (1 - \pi) G(\mu_2, \sigma_2^2) \quad (6.35)$
```

The bimodality index simplifies the model using a uniform variance,
i.e., $\sigma_1^2 = \sigma_1^2 = \sigma^2$. A standardised distance is defined by the
bimodality index by $\mathcal{H}_0: \delta = 0$

```
$\delta = \frac{|\mu_1 - \mu_2|}{\sigma} \quad (6.36)$
```
