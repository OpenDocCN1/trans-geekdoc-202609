The errors are assumed to follow a Gaussian distribution, where $\alpha = \sigma_e^{-2}$,

```
$e_n \sim \mathcal{N}(0, \sigma_e^2) = \mathcal{N}(0, \alpha^{-1}) \quad (3.50)$
```

The Gaussian distribution of errors is governed by a super distribution,

```
$\alpha \sim \mathcal{N}(0, \vartheta) \quad (3.51)$
```

The prior of **$w$** is also designed as a Gaussian distribution [Bullen, et al., 2003], where $eta = \sigma_w^{-2}$,

```
$w_k \sim \mathcal{N}(0, \beta) \quad (3.52)$
```

The parameter $eta$ is also controlled by *a priori*,

```
$eta \sim \mathcal{N}(0, \tau) \quad (3.53)$
```

Suppose a set of all hyper-parameters $(\vartheta$ and $	au)$ is denoted by $\omega$, a conditional probability (or likelihood) is denoted by $p(\mathbf{y}|\mathbf{\omega})$, a normalized factor (evidence) is denoted by $p(\mathbf{y})$, the *a priori* structure is denoted by $p(\mathbf{w}, \mathbf{\omega})$ and a posterior probability is denoted by $p(\mathbf{w}|\mathbf{y})$. The relationship between these notations is defined as below,

```
$p(\mathbf{w}|\mathbf{y}) = \frac{p(\mathbf{y}|\mathbf{\omega})p(\mathbf{w}, \mathbf{\omega})}{p(\mathbf{y})} \quad (3.54)$
```

The *a priori* structure $p(\mathbf{w}, \vartheta)$ can be decomposed as below,

```
$p(\mathbf{w}, \vartheta) = p(\mathbf{w})p(\vartheta) \quad (3.55)$
```

where $p(\mathbf{w}|\mathbf{\omega})$ is a conditional probability given hyper-parameters and $p(\omega)$ is the *a priori* probability of hyper-parameters. With this simplification, the posterior probability is simplified as below, where the evidence term $p(\mathbf{y})$ is omitted because it is a constant,

```
$\mathcal{L} \propto p(\mathbf{y}|\mathbf{\omega})p(\mathbf{w}|\mathbf{\omega})p(\omega) \quad (3.56)$
```
