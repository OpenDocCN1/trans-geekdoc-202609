```
$D^E(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^d (x_i - y_i)^2$ (2.15)
```

The Hamming distance [Hamming, 1950] is commonly used for discrete data and it is defined as below,

```
$D^H(\mathbf{x}, \mathbf{y}) = \frac{1}{d} \sum |x_i - y_i|$ (2.16)
```

A distance measures the dissimilarity. A correlation coefficient can be used to measure how two data points are similar to each other. The definition of the correlation coefficient for two vectors (hence two data points) $\mathbf{x}$ and $\mathbf{y}$ is shown below, where $\mu_x$ and $\mu_y$ stand for the population means, $\sigma_x^2$ and $\sigma_y^2$ stand for the variances of two populations,

```
$ho(\mathbf{x}, \mathbf{y}) = \frac{\sum_{i=1}^d(x_i - \mu_x)(y_i - \mu_y)}{(d-1) \sqrt{\sigma_x^2\sigma_y^2}}$ (2.17)
```

The partitioning strategy and the grouping strategy are two major clustering strategies. For the former, a data space is partitioned into a number of subspaces, each of which is a cluster. Each subspace is parameterised by a cluster centre. Sometimes, the variance or covariance of a cluster is also considered as a parameter to describe a subspace. Each data point is labelled through minimising its distance with the cluster centres of cluster model. Most clustering algorithms employing the partitioning strategy are the parametrised models. This means that the knowledge of how data points are grouped or clustered can be saved in a number of model parameters such as the cluster centres and the variances.
