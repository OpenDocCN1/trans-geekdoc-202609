# 7.2.3.1 The initialisation stage

In the initialisation step, each cell for an identical pair of residues from two sequences is filled by one and others are filled by zeros. Shown in Table 7.6 is an example for aligning two sequences x=CAGGCA and y=AGTCA, where the initialisation stage has been completed.

# 7.2.3.2 The forward propagation stage

In the forward propagation stage, the cells of the table are filled row by row from the bottom to the top of a table and column from column to the left of a table. The score calculation of the Needleman-Wunsch algorithm is defined as

```
$M_{ij} = S_{ij} + \max\{M_{i+1,j+1}, M_{i+1,j}, M_{i,j+1}\}$ (7.11)
```

where $i$ and $j$ represent the $i^{th}$ row and the $j^{th}$ column, $M_{ij}$ is the alignment score of the cell indexed by $i$ and $j, S_{ij}$ is the match score of the cell.
