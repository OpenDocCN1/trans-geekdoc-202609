# 8.3.2.2 The GP breeding rules

Based RPN, GP can be formulated using the similar breeding operators used in GA. However, they need to be updated because RPN chromosome is no longer a string of binary values. Before introducing how the breeding operators work for a GP problem, two RPN strings are designed. They are x3y*+xz++ for x + 3y + x and 5xy**zy*+ for 5xy + zy . Figure 8.7 shows two RPN chromosomes for these two equations.

| x | 3 | y | * | x | z | + |
| 5 | x | y | * | z | y | * | + |

In GA, a chromosome is a string of binary values, therefore a mutation operation or a crossover operation is much easier to implement. For instance, the use of the mutation operator will turn over between zero and one in some bits of a chromosome to change the presence and absence status of the candidate variables.
