Fortunately, several new ideas have been motivated such as the Lasso neural network [Ross and Lage, 2017; Mohammadi, 2020] and the sparse deep neural network [Scardapane, et al., 2017; Qiao, et al., 2020]. The Lasso neural network can increase the interpretation capability using a L1 penalty applied to the input graph shown, where x stands for inputs, y stands for labels, H(y,ŷ) stands for the cross-entropy,

```
$$L(\theta|x,y) = H(y,\hat{y}) + \lambda_{\theta}|\theta||_1 + \lambda_{\nu}|\nabla_x H(\\hat{y})||_1 \quad (9.1)$
```

The conventional approach for generating a sparse neural network as well as a deep learning model for increasing the interpretation capability is to apply a regularisation constraint to the model parameters (weights). As another alternative, the group sparse regularisation deep learning network aims to group neurons or regularise neurons to achieve a better model interpretation capability [Scardapane, et al., 2017; Lin and Runger, 2018; Qiao, et al., 2020]. All of these new efforts aim to explore the interpretation capability of a neural network model or a deep network model. It is expected that these new developments may play an increasing role in biological/medical pattern analysis projects soon. To increase the intelligence of a neural network model or a deep network model, it has been well recognised that few neurons can promote a better intelligence power of a network [Lechner, et al., 2020]. But how to reduce the model complexity while maintaining the model accuracy is still an open subject for research. The promising ideas of new research suggests the combination between artificial intelligence with deep learning to produce more interpretable machine learning models [Heaven, 2019].
