The K-fold cross-validation, which is also named as rotation approach, divides a data set into K subsets and builds K models. Each of K models is trained on K-1 folds (subsets) and tested on the reserved subset, in turn. The final performance is evaluated on all K subsets. Figure 3.15 shows a 3-fold cross-validation diagram. The K-fold cross-validation is commonly implemented using a loop, which will rotate the subset of samples to be selected for training and testing. The important feature of K-fold cross-validation is that each data point will be tested exactly once.

![](img/c3caa9b5c0f40fb2a44f2ab6e94f78_123_0)

Fig. 3.15. A diagram of 3-fold cross-validation. From left to middle, two folds are selected for training. From right to middle, one fold is selected for testing. The Jackknife test [Qu1949; Bishop, 1996], which is commonly used for small-sized data, is a typical case of K-fold cross-validation when one data point is reserved for testing. Suppose there are N points. Rather than constructing K models using the K-fold cross-validation, N models will be constructed using the Jackknife approach for the generalization of test. An important benefit of the Jackknife test is its robustness because there is no uncertainty when using the Jackknife test. There is no random sampling process regarding data division.

### 3.5 Example

Seeds classification [Ajaz and Hussain, 205] was used for the demonstration of how evaluation and generalization are used. Whole data was saved in a matrix x and independent variables were saved in another matrix named input. The code shown below is for five-fold cross-validation for this data set where CV was a cross-validation vector, in which five integers from one to five were randomly distributed. The vector was used as the testing data. It was composed of one fold of the whole data set. The matrix input has class variable removed. The vector Z was predicted labels.

```
CV=sample(1:5,nrow(x),replace=TRUE)
input=x[,colnames(x)=='class']
Z=rep(0,nrow(x))
for(fold in 1:5) {
    test=which(CV==fold)
    model=lda(class~x[-test])
    Z[test]=predict(model,input[test])
}
```

The following code was used for running the Jackknife test for the data set where a seed was enumerated, all other seeds x[-n] were used as the training data while seed input was used as the testing data.

```
Z=rep(0,nrow(x))
for(n in 1:nrow(x)) {
    model=lda(class~x[-n])
    Z[n]=predict(model,input[n])
}
```
