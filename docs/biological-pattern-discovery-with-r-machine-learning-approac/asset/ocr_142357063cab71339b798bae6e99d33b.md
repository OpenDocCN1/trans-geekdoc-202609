# 6.4.9 Discover heterogenous DEGs for a cancer data set

The seven tests were used to discover heterogenous DEGs for the breast cancer diagnosis data (GDS3139) [Tripathi, et al., 2008]. For all tests, the critical p value for this data set was 0.01. Figure 6.22 shows the distributions of the p values of the COPA, OS, ORT, MOST, LSOSS and DOG models constructed for this data set. The distributions of the p values from the OS, ORT, MOST and LSOSS models were questionable. As indicated earlier, the density of the p values should be a mixture of uniform distribution for the non-DEGs and a Gamma distribution for the DE [Tusher, et al., 2001; Store and Tibshirani, 2003]. Based on this theory, only the p value distribution of the DOG model was reasonable.

Figure 6.23(a) shows the correlation analysis plot of the negative base logarithm of the p values of the models using the seven tests for the data set. It can be seen that the DOG model was highly correlated with the t test, the OS model was highly correlated with the ORT model and the COPA model was highly correlated with the ORT model.
