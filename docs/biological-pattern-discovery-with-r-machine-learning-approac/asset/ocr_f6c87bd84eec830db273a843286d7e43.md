# ## 6.2.2 The visualisation of the discovered DEGs using the MA plot

The MA plot [Ritchie, et al., 2015] provides a way to envisage gene expression pattern analysis and has been popular in the biological/medical data analysis research. It was rooted from the so-called Bland-Altman plot (BA plot or a MA plot), which is also called the Tukey mean difference plot for the descriptive statistics used in various applications [Bland and Altman, 1986; Bland and Altman, 1999]. Such a plot can be used to examine the relationship between two meta variables, which are derived from a number of raw variables. They are the variable difference and the variable mean.

The basic assumption of gene expression data is that most genes will not have significantly differential responses to a stress across conditions. Moreover, it is also assumed that many genes may have small mean expression values. In a MA plot, the x-coordinate uses the variable mean, i.e., the y-coordinate uses the variable difference, i.e., the differential variable. To generate a MA plot in limma, a MA data structure needs to be defined in limma. The code is shown below, where sam.model is an eBay model generated by eBayes, $Amean is the mean expression variable and the differential variable is coefficients[,2], which is the fold change.

```
MA=new("MAlist")
MA$A=sam.model$Amean
MA$M=sam.model$coefficients[,2]
```

Afterwards, a vector of the classification of genes is defined to indicate the status of each gene, i.e., being a down-regulated DEG, or an up-regulated DEG or a non-DEG.

```
status=rep('Non-DEG',nrow(X))
old=sam.model$coefficients[,2]
pv=sam.model$pv[fold<-2 & pv<0.01)]='Down'
status[which(fold>2 & pv<0.01)]='Up'
```

Finally, a limma function plotMA is called to generate a MA plot for the data.

```
plotMA(MA, status=status, values=values, hl.col=col)
lines(range(MA$A),c(-2,-2),lty=3,lwd=2)
```
