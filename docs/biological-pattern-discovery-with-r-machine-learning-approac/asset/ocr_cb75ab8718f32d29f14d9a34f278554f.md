# 2.3.3 The fuzzy C-means cluster analysis algorithm

The fuzzy c-means cluster analysis algorithm was proposed to overcome the drawback of the K-means algorithm by introducing the soft membership function to a clustering process [Dunn, 1973; Bezdek, 1981]. The centre of a cluster is defined as below, $f_k(\mathbf{x}_n) \in [0,1]$ is a soft membership function measuring the degree by which the $n^{th}$ data point $\mathbf{x}_n$ belongs to the $k^{th}$ cluster whose centre is $\mathbf{u}_k$.

```
$$\mathbf{u}_k = \frac{\sum_{n=1}^N f_k(\mathbf{x}_n)\mathbf{x}_n}{\sum_{n=1}^N [f_k(\mathbf{x}_n)]^m}$
```

In the above definition, $m$ is a positive parameter to weight the membership. The membership $f_r(\mathbf{x}_n)$ for the $n^{th}$ data point $\mathbf{x}_n$ to belong to the $r^{th}$ cluster is defined as below,

```
$f_r(\mathbf{x}_n) = \sum_{k=1}^K \frac{\|\mathbf{x}_n - \mathbf{u}_r\|}{\|\|\mathbf{x}_n - \mathbf{u}_k\|^{m-1}}$
```

The same as the K-means algorithm, the fuzzy C-means algorithm also initialises model parameters (cluster centres $\mathbf{u}_k$) using random values. Based on the initialised cluster centres, the algorithm estimates the memberships for each data point, i.e., $f_r(\mathbf{x}_n)$. Afterwards, the centres are updated. These two calculations are repeated until the maximum cycles are reached or the cluster stop to change.

Because of the use of the soft membership function, the fuzzy C-means algorithm benefits from a slightly higher accuracy for dealing with a more complicated cluster model. In biological/medical pattern analysis, the fuzzy C-means algorithm has been integrated into a linear model which has led to a significant improvement of the discovery accuracy of Type 1 diabetes based on blood glucose data [Montaser, et al., 2020]. It has also been used to cluster tissues in a computer-aided diagnosis of Alzheimer's disease [Lazli, et al., 2020].

One R package for the fuzzy C-means algorithm is fcluster. The main R function for constructing a fuzzy C-means model is fcm, which is defined as

```
fcm(x, centers, ...)
```
