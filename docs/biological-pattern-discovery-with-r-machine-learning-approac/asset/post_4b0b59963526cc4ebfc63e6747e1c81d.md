## 5.6 The asymmetric least square smoother

The asymmetric least square smoother algorithm (ALSS) [Liland, et al., 2010] employs the concept of residual weights. Suppose a spectrum is denoted by a vector s, an unknown baseline is denoted by a vector b, residual weights are denoted by a vector w, the regularisation constant is denoted by λ. The objective function of the asymmetric least squared smoother is defined as below, where $d=\Delta\Delta b$ and W is a diagonal matrix of w,

```
$O = (\mathbf{s}-\mathbf{b})W(\mathbf{s}-\mathbf{b})^t + \lambda dd^t \quad (5.12)$
```

In the equation, the residual weight is defined as below, where $0 \leq p \leq 1$ is a constant,

```
$w_i = \begin{cases} p & \text{if } s_i > b_i \\ 1-p & \text{otherwise} \end{cases} \quad (5.13)$
```

The Tukey's b-square weight mechanism is used in ALSS, where $r_i = \sqrt{\rho(s_i-b_i)}/\sigma$ and $\sigma = \text{median}(\sqrt{\rho(s_i-b_i)}/0.6745)$,

```
$w_i = \begin{cases} 1 & \text{if } r_i < 0 \\ \max[1-(\frac{r_i}{b})^2, 0] & \text{otherwise} \end{cases} \quad (5.14)$
```

To remove some baseline artifacts, the median values are calculated for local windows and the Gaussian smooth function used in this algorithm is defined as below, where $w$ is the window size, $M_j$ is the median of a local window indexed by $j$ and $\mathcal{G}(n)$ is a Gaussian function, $b_i$ is defined as

```
$b_i = \sum_{j=i-\frac{w}{2}+1}^{i+\frac{w}{2}} M_j\mathcal{G}(i-j) \quad (5.15)$
```

The R package for ALSS is baseline. The R code of using this package for the baseline estimation is shown below, where $s$ is a spectra vector, `method` specifies a smoothing method to be used and `lambda` stands for the regularization constant,

```
baseline(s, method, lambda, ...)
```

## 5.7 The Bayesian Whittaker-Henderson algorithm

The Bayesian Whittaker-Henderson smoother algorithm (BWH) has been proposed for providing a better baseline estimation performance [Leu, et al., 2012]. The algorithm is an extension from several algorithms by framing the Whittaker-Henderson smoother into Bayesian framework. Moreover, BWH can align multiple spectra. The algorithm assumes that a signal, if it is true, should occur in more than one replicate. Based on this assumption, BWH can support robust signal detection for spectra sets of replicates.

### 5.7.1 The working principle of BWH

Most spectra smoothing algorithms assume that only spectra intensities below baseline are treated as noise and spectra intensities above baseline are not treated as noise. However, BWH treats artifacts on both sides of baseline as noises that the noise is distributed on both sides of baseline when using BWH to estimate a baseline for spectrum. BWH also assumes both the fidelity and the smoothness follow independent identical Gaussian distributions. They are defined as below, where $\sigma_f^2$ and $\sigma_s^2$ are variances,

```
$e_i \sim G(0, \sigma_F^2), d_i \sim G(0, \sigma_s^2) \quad (16)$
```

The BWH fidelity is defined as below, where $w$ is the upper-bound,

```
$e_i = \begin{cases} s_i - b_i & \text{if } s_i < b_i + w \\ \infty & \text{otherwise} \end{cases} \quad (17)$
```

Based on the definition, $b_i + w$ defines a upper-bound of noise above baseline. Because of this, the noise from both sides of baseline will finally removed during baseline estimation for discovering peaks. Therefore, likelihood of false signals can be minimized. BWH has introduced an indicator for peaks. If a wave number (spectra value) does not correspond to a peak, zero is assigned, otherwise unit value is assigned. The definition of this indicator is for incorporating peak information into baseline estimation. The indicator is defined as,

```
$t_i = \begin{cases} 1 & \text{if } e_i < \infty \\ 0 & \text{otherwise} \end{cases} \quad (18)$
```

Corresponding, a vector $\mathbf{t}$, which is also called aligner vector, is used for all wave numbers (spectra values). Density function of fidelity is defined as [Taylor, 1992], where $N$ stands for spectral length, i.e., number of wave numbers, is error vector and $\Gamma = \text{diag}(\mathbf{t})$,

```
$f_{\mathbf{E}|\mathbf{B}}(\mathbf{e}) = \frac{1}{(2\pi\sigma_F^2)^{N/2}} \exp\left -\frac{\Gamma^T\Gamma}{2\sigma_F^2} \right) \quad (19)$
```

The prior of the smoothness is defined as Gaussian distribution [Taylor, 1992],

```
$f_{\mathbf{D}|\sigma_S^2}(\mathbf{d}) = \frac{1}{(2\pi\sigma_S^2)^{(N-1)/2}} \exp\left -\frac{\mathbf{d}^T\mathbf{d}}{2\sigma_S^2} \right) \quad (20)$
```

Taylor interpreted the regularisation constant of baseline model as a Bayesian prior [Taylor, 1992]. Because of this, the relationship between the smoothness and the fidelity (regression error) can be defined as below,

```
$f_{B|E=e}(b) = \frac{f_{E|B=b}(e)f_B(b)}{f_E(e)} \quad (21)$
```

where $f_E(e) = \int_{-\infty}^{\infty} f_{E|B=b}(e)f_B(\beta)d\beta$ is called the evidence, which is a constant. Therefore, the posterior of a BWH baseline is then proportional to the product of the fidelity density and the smoothness prior,

```
$f_{B|E=e}(b) \propto f_{E|B=b}(e)f_B(b) \quad (22)$
```

In the above equation, $f_{B|E=e}(b)$ is a prior of the baseline and its smoothness prior is $f_{D=d|\sigma_S^2}(d)$. Two hierarchical inverse Gamma priors for variances ($\sigma_F^2$ and $\sigma_S^2$) are introduced for BWH. The inverse Gamma prior for $\sigma_F^2$ is defined as below, where $\alpha_F$ and $\beta_F$ are two hyper-parameters for the fidelity prior,

```
$f_{\sigma_F^2|\alpha_F,\beta_F}(\sigma_F^2) = \frac{\beta_F^{\alpha_F}}{\sigma_F^{\alpha_F+2}\Gamma(\alpha_F)} \exp\left(-\frac{\beta_F}{\sigma_F^2}\right) \quad (23)$
```

The inverse Gamma prior for $\sigma_S^2$ is defined as below, where $\alpha_S$ and $\beta_S$ are two hyper-parameters for the smoothness prior,

```
$f_{\sigma_S^2|\alpha_S,\beta_S}(\sigma_S^2) = \frac{\beta_S^{\alpha_S}}{\sigma_S^{\alpha_S+2}\Gamma(\alpha_S)} \exp\left(-\frac{\beta_S}{\sigma_S^2}\right) \quad (24)$
```
