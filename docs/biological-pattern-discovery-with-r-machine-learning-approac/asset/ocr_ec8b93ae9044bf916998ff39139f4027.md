A transposon sequencing data set has two types of transposon statistics. They are the insertion statistic and the site statistic. The former stands for the number of transposon insertions per gene and the latter stands for the number of transposon insertion sites per gene. These two types of statistics represent two types of transposon events in a genome. The insertion statistic represents the total number of transposon insertions a gene has. This value depends on the sequencing coverage. The greater the sequencing coverage, the greater the insertions per gene. The site statistic represents the strength of the transposon distribution across a gene. This statistic depends on two factors, i.e. the sequencing coverage and the gene essentiality.
