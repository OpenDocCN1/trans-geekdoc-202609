Afterwards, regression models are used to discover the significant contributing signatures from hundreds or thousands of candidates (regressors) for a target variable, which is either a genetic signature or an epigenetic signature. The next and the most important objective is to discover whether a significant contributing signature (regressor) of a target variable is a local or remote event. Therefore, a regression algorithm with the facility of variable ranking is desirable. Because of this, various regression algorithms, either linear or nonlinear, which can provide a variable ranking mechanism, have been introduced in this chapter. How they can be used for the genetic-epigenetic interplay pattern discovery has been demonstrated in this chapter. The performance of these algorithms has been examined and compared. In addition, whether different models generate a consistent result has been discussed as as well. The common genetic-epigenetic interplay pattern has been discovered by exploring different types of regression models. That is, the majority of the genetic-epigenetic interplay happens between the remote events.
