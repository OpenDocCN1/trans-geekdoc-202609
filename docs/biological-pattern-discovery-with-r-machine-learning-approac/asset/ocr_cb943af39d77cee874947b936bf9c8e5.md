To construct a histogram for density analysis for a data set x, the following procedure is used,

+   Prepare a data set x = $(x_1, x_2, \dots, x_N)$.nDesign bins B = $(B_1, B_2, \dots, B_M)$ such as the eight bins $(M = 8)$ shown in the top-right panel of Figure 2.2.
Throw each data point $x_n$ into a bin $B_m$ if $x_n$ is within the boundaries of $B_m$.
Count the data points $(x_n)$ falling in each bin $B_m$, as such, 1,277 insertions in the first bin in Figure 2.2.
Denote the data point count of each bin $f_m$ (frequency) as shown in the bottom-left panel of Figure 2.2.
Convert each frequency $(f_m)$ to a probability $(p_m)$ as shown in the bottom-right panel of Figure 2.2.
Use either $f_m$ or $p_m$ to interpret the estimated density.

The formula for converting a histogram to a probabilistic histogram is defined as below,

> $$p_m = \sum_{k=1}^{n} \frac{f_m}{f_k} \quad (2.1)$

Two histogram statistics have different meanings. $f_m$ stands for the real count of the $m^{th}$ bin while $p_m$ stands for the probability for data to occur in the $m^{th}$ bin. The former can be used for interpreting or explaining how data are distributed. The latter can be used for making an inference for novel data. In other words, the probability of a bin can indicate how likely a novel data point occurs in the bin. For instance, the probability that a novel transposition insertion statistic fails into the first bin and the seventh bin is 8% and 19%, respectively for the gene isful shown in the bottom-right panel of Figure 2.2.

The R function for the histogram algorithm is hist. Given a vector x, the syntax of the `hist` function is shown below, where `nclass` is the parameter for designing the bin number,

```
hist(x, nclass, ...)
```
