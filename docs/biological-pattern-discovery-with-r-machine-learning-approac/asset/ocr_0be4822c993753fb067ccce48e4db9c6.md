# 4.3.5 R function for ordinary linear regression analysis

To construct an OLR model for a data set, three R functions are needed. They are lm, summary and predict. The R function for constructing an OLR model is lm, which is formatted as below, where x is an independent variable and y is a dependent variable,

```
model=lm(y~x, ...)
```

To show how this function works, the olive oil content data [Baraz et al., 2017] was used for the demonstration at first. The data production quality from different olive trees in the southeast Mediterranean area. The data was composed of five independent variables. For a simple illustration, only one of them was used for an easy explanation of how a linear regression model works. The variable used here was the stone weight.
