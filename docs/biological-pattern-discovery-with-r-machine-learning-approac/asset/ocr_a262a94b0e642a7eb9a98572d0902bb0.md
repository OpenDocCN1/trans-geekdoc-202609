The mixing coefficients are modelled using the non-informative priors and each of $\mu_0$ and $\mu_1$ is assigned a Gaussian prior with a zero mean and a small deviation $\tau_m$ which is a hyper-parameter (the inverse of a variance),

```
$\mu_m \sim \mathcal{G}(\\mathbf{0}, \tau_m) \quad (6.47)$
```
