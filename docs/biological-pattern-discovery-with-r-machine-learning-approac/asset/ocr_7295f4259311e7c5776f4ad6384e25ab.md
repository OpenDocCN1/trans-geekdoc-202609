Based on this design matrix $D$, a linear model was formulated below, where $x$ was a vector of gene expressions for one gene, $eta$ was a vector of parameters and $\epsilon$ was an error vector.

```
$x = D\beta + \epsilon \quad (6.7)$
```

The formula can be re-written as below, where $x_i^A$ and $x_j^B$ represented gene expressions of two experimental conditions.

```
$$\begin{pmatrix} x_1^B \ x_2^B \ \vdots \ x_m^B \ x_1^A \ x_2^A \ \vdots \ x_m^A \end{pmatrix} = \begin{pmatrix} 0 \ 0 \ \vdots \ 0 \ 1 \ 1 \ \vdots \ 1 \end{pmatrix} (\beta_1 \ \beta_2)^t + \epsilon \quad (6.8)$
```

Note that the above equations are for one gene. In *limma*, $eta_1$ and $eta_2$ are estimated based on the expressions of all genes in a data set. Therefore, the estimation of $eta_1$ and $eta_2$ using the *limma* package will be more robust.
