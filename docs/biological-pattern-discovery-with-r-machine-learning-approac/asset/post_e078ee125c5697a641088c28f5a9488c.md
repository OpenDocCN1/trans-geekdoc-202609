### 3.6.1 Multi-layer perceptron (MLP)

The multi-layer perceptron (MLP) or artificial neural network stands for a class of computational algorithms for pattern analysis [Rumelhart, et al., 1986; Bishop, 1996]. MLP rooted from the human brain research and the modern computational technology. It is also called an information processing system because it can be used for knowledge discovery and memory association with a large-scale data mining process. The typical case is that MLP can be used to discover the pattern underlying data and to reconstruct it without a priori knowledge about what the pattern function looks like. The most important feature that makes MLP an excellent intelligent processing system is its power of storing knowledge or intelligence learned from a data set. Due to this powerfulness, MLP has been widely used for pattern discovery and recognition in many areas including biology and medicine. For instance, it has been used for amelioration of inflammatory bowel disease based on mice model [Sabater, et al., 2019]. Another recent study using MLP has been the investigation of generating single-cell RNA-seq through learning nonlinear gene-gene relationship of complex, multiple cell type samples [Marouf, et al., 2020].

#### 3.6.1.1 The structure of MLP

Figure 3.21 shows one example of MLP structure, in which there are three layers of computing units called neurons. They are a layer of the input neurons ($x_1$ and $x_2$), a layer of the hidden neurons ($z_1$ and $z_2$) and a layer of the output neuron ($y$). Suppose

```
$z_1 = f_1(x_1, x_2)$
z_2 = f_2(x_1, x_2)$
y = f_3(z_1, z_2)$ $\quad\quad (3.29)
```

The dependent variable $y$ is then a complex function of the independent variables $x_1$ and $x_2$,

```
$y = f_3\{f_1(x_1, x_2), f_1(x_1, x_2)\}$ $\quad\quad (3.30)
```

### 3.6.1.2 The mechanism of MLP

To estimate the parameters of MLP, the simple way is

```
$\varepsilon = \frac{1}{N} \sum_{n=1}^{N} (\hat{y}_n - y_n)^2 \quad\quad (3.33)$
```

Because $\hat{y}_n$ is nonlinear, the estimation of parameters is difficult.

```
$\frac{\partial \varepsilon}{\partial w} = \frac{2}{N} \sum_{n=1}^{N} (\hat{y}_n - y_n) \frac{\partial \hat{y}_n}{\partial w} \quad\quad (3.34)$
```

The derivative $\frac{\partial \hat{y}_n}{\partial w}$ is calculated using the chain rule:

```
$\frac{\partial \hat{y}_n}{\partial w} = \frac{\partial \hat{y}_n}{\partial z_j} \frac{\partial z_j}{\partial w} \quad\quad (3.35)$
```

The derivative $\frac{\partial \hat{y}_n}{\partial z_j}$ is calculated using the sigmoid function:

```
$\frac{\partial \hat{y}_n}{\partial z_j} = \hat{y}_n(1 - \hat{y}_n) \quad\quad (3.36)$
```

The derivative $\frac{\partial z_j}{\partial w}$ is calculated using:

```
$\frac{\partial z_j}{\partial w} = x_i \quad\quad (3.37)$
```

The derivative $\frac{\partial \varepsilon}{\partial w}$ is then:

```
$\frac{\partial \varepsilon}{\partial w} = \frac{2}{N} \sum_{n=1}^{N} (\hat{y}_n - y_n) \hat{y}_n(1 - \hat{y}_n) x_i \quad\quad (3.38)$
```

The update of $w$ is calculated as:

```
$w^{t+1} = w^t - \eta \frac{\partial \varepsilon}{\partial w} \quad\quad (3.39)$
```

The update of $w$ is then improved by introducing momentum:

```
$w^{t+1} = w^t - \eta \frac{\partial \varepsilon}{\partial w} + \alpha \Delta w^t \quad\quad (3.40)$
```

where $\Delta w^t = w^t - w^{t-1}$. This is the back propagation algorithm with momentum.
