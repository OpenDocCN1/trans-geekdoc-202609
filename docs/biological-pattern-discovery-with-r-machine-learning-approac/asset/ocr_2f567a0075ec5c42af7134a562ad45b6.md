This has led to new and more robust transposon statistic which is the insertion statistic. It is called the convolution between the site statistic with the mutation feature statistic (MF) [Yang, et al., 2017]. During a convolution process, the functionality of the transposon insertion sites near distal ends of a gene is penalised. An insertion site near the centre position of a gene is assigned a greater weight while an insertion site near either end of a gene is assigned a smaller weight.
