A hanging tree is shown in Figure 2.18(a) and the tree has been saved in a variable called model. This tree can be cut to generate subtrees with the maximum subtree height as using the following code. The resulting subtrees are shown in Figure 2.18(b), where it can be seen that the cut has led to three clusters, i.e., a cluster of data point labelled by A, a cluster of data points labelled by B and C as well as a cluster of data points labelled by D and E.

```
cutree(model, h=2)
```

A hanging tree can also be cut for a specified cluster number. The code shown below cuts a hanging tree into two clusters. Figure 2.19 shows the result.

```
cutree(model, k=2)
```
