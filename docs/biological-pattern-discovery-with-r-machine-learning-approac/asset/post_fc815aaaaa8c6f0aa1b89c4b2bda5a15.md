## 9.4 Next-generation sequencing data quality

The next-generation sequencing technology has been the very widely used in biological/medical researches. For instance, it has been incorporated with the transposon technology to generate a new method for the mutation pattern analysis. The new method is called the transposon sequencing technology. Using this technology, millions of mutants can be identified in a single experiment. Based on the gene-wise transposon statistics, essential genes can be identified using the density pattern analysis approaches as discussed in Chapter 2 of this book. However, most existing approaches for identifying essential genes are based on replicated-free data. The assumption is that a single transposon sequencing data is noise-free or the noise level can be well controlled. However, it has been recognised that transposon insertions are random events [Golden, et al., 2000; Aboklash, et al., 2014; Baym, et al., 2016]. In other words, in replicated transposon sequencing data, it is very unlikely that there will be identical patterns of transposon insertion distributions across replicates. An insertion site in one replicate may not be present in others in the same experiment. Even when it is presented across replicates, it is less likely for it to be inserted at the exact identical base pair across replicates. It has been assumed that a well-designed study will ensure that all transposon insertion sites are covered in replicated data. In other words, it assumes that the replicate number is the minimum set to cover all transposon insertion sites. In addition, the insertion frequency is a random event and will differ between replicates at each insertion site. It is therefore a reasonable assumption that unobserved but true transposon insertion frequency can be discovered if replicated data are used. Based on this assumption, a novel and more efficient approach may need to be considered for dealing with sequencing noise for a better gene identification. This kind of thinking can also be used for other areas dealing with the sequencing data such as sequencing assembling, where it has also been exercised for replicate-free data assembly quality has drawn attention due to this uncertainty [Florea, et al., 2011] and different methods such as curation [Howe, et al., 2021] or using new assessment metric [Ou, et al., 2018; Thrash, et al., 2020; Xie and Wong, 2021] have been used. Similarly, the quality of sequencing read alignment has drawn great attention and has also been researched recently [Redmont, et al., 2019; Woste, et al., 2020].

## 9.5 SARS-CoV-2 protease cleavage pattern discovery

The protease cleavage site identification problem has been well researched for several decades. It is still an important area for studying protein functions. Although the exercise in this area has been very successful, the ultimate objective of protease cleavage site identification or protease cleavage pattern analysis for drug design such as the inhibitor design problem is still challenging. The conversion from discovered protease cleavage profile to effective drug design is still not an easy job [Vizovisek, et al., 2016]. After evaluating recent models for the protease cleavage site discovery, it has been found that most machine learning models including deep learning models work very well. It has been suggested that the parallel as well as distributed computing should be the main method for fast and accurate discovery of protease cleavage sites. Having the SARS-CoV-2 pandemic worldwide, urgent attention has been paid to the problem of how to discover the SARS-CoV-2 viral proteolytic cleavage sites. For instance, the novel S1/S2 site viral has been identified within the spike protein of SARS-CoV-2 [Javier, et al., 2020] and the furin [Xia, et al., 2020]. The question, which still waits for a good answer, is whether it is possible to quickly discover the cleavage pattern for developing drugs to fight against the pandemic. This may be an urgent challenging task at the moment.
