#  7.6.1 Genomics distribution of sequences

A self-organising map (SOM) [Kohonen, 1982] model with 900 neurons was constructed for the dual-normalised 3-mer data set for these 58,897 sequences from four countries. Figure 7.18 shows the map generated by the kohonen package. The map has shown a clear pattern that the sequences from four countries have been mapped to distinct areas. In this map, eight cells were empty, which had no sequence mapped. The mapping rate was 99.11%. Among 892 cells, 839 cells were occupied by the sequences from a unique country, such as USA, India, Russia or Brazil. This indicated that 94.06% cells were pure for the sequences of one country. This means that the decomposition of 58,897 sequences into four subsets $f(X) \Rightarrow U\{\mathbb{u}_{USA}, \mathbb{u}_{India}, \mathbb{u}_{Brazil}, \mathbb{u}_{Russia}\}$ was successful and this set of sequences did have some intrinsic whole genome pattern to discriminate the virus genome from different countries. Among them, 711 neurons were pure for USA, 66 neurons were pure for India, 17 neurons were pure for Russia and 45 neurons were pure for Brazil. Each of 711 neurons only witnessed USA sequences, each of 66 neurons only witnessed India sequences, etc. Some neurons (cells or grids) have evidenced the overlap of sequences from different countries.
