## 7.6 Whole genome pattern discovery for SARS-CoV-2

The whole genome pattern discovery for SARS-CoV-2 is shown in this section. Both sequences and metadata were downloaded from the Global Initiative on Sharing All Influenza Data [Shu and McCauley, 2017] on the 4th January 2021. There were 315,253 sequences across over 200 countries and regions in total till that date.

- Four countries with the highest infection numbers were selected for the investigation in this chapter. They were USA, India, Russia and Brazil. There were 57,836, 4,325, 1,572 and 1,811 sequences for USA, India, Russia and Brazil, respectively. After removing duplicated sequences, there were 51,383, 4,321, 1,502 and 1,771 sequences left for USA, India, Russia and Brazil. There were finally 58,897 sequences from four countries. Each sequence was coded using the 3-mer approach. Therefore, a numerical vector of 64 3-mers or words for each sequence, i.e., $S_n \Rightarrow X_n \in R^{64}$.

First, unsupervised machine learning models were constructed to visualise the genomic patterns (the 3-mer word frequency library) of the viral sequences were distributed in these four countries. What this analysis aims to do is examine whether the set of 3-mers of all sequences (X) can be efficiently and accurately divided into four subsets, namely $\Omega_{USA}$, $\Omega_{India}$, $\Omega_{Brazil}$ and $\Omega_{Russia}$, using an unsupervised machine learning model, $f(X)$.

$f(X) \Rightarrow U\{\Omega_{USA}, \Omega_{India}, \Omega_{Brazil}, \Omega_{Russia}\}$

### 7.6.1 Genomics distribution of sequences

A self-organising map (SOM) [Kohonen, 1982] model with 900 neurons was constructed for the dual-normalised 3-mer data set for these 58,897 sequences from four countries. Figure 7.18 shows the map generated by the kohonen package. The map has shown a clear pattern that the sequences from four countries have been mapped to distinct areas. In this map, eight cells were empty, which had no sequence mapped. The mapping rate was 99.11%. Among 892 cells, 839 cells were occupied by the sequences from a unique country, such as USA, India, Russia or Brazil. This indicated that 94.06% cells were pure for the sequences of one country. This means that the decomposition of 58,897 sequences into four subsets $f(X) \Rightarrow U\{\mathbb{u}_{USA}, \mathbb{u}_{India}, \mathbb{u}_{Brazil}, \mathbb{u}_{Russia}\}$ was successful and this set of sequences did have some intrinsic whole genome pattern to discriminate the virus genome from different countries. Among them, 711 neurons were pure for USA, 66 neurons were pure for India, 17 neurons were pure for Russia and 45 neurons were pure for Brazil. Each of 711 neurons only witnessed USA sequences, each of 66 neurons only witnessed India sequences, etc. Some neurons (cells or grids) have evidenced the overlap of sequences from different countries. means several sequences were perhaps haps into the areas where they should not go. For instance, some sequences of India were mapped to the area of neurons which was mainly occupied by USA sequences.

Fig. 7.18. The SOM map constructed based on the 3-mer data of 58,897 SARS-CoV sequences from four countries. The letters a, b, c and d were used to stand for USA, India, Russia and Brazil, respectively. They were coloured in red, blue, green and black in this map.

In order to examine whether the SOM map truly reflected the data structure of the sequences, the fitness of the SOM neuron occupancy percentages to the percentage distribution of the sequences from different countries in the whole data were tested. Table 7.22 shows the test result. The chi-square test p value of two percentages was 0.996 meaning that two percentage distributions were almost identical. Therefore, the SOM map has truly reflected the genomic deviation of these sequences from four countries. In addition, 53 neurons were mixed by sequences from more one country. In total, 1,355 sequences (2.3%) were mapped onto these 53 neurons. This error rate also implied that this SOM map has well- the original genomics pattern or structure hidden in these sequences from four countries.

### 7.6.2 Discrimination between countries based on genomics pattern

The discriminant analysis models were constructed to examine how genomics pattern deviated between four countries. The pair-wise discrimination power between countries was examined, such as the discrimination power between USA and India, etc. Each discrimination model was constructed using the Lasso regression algorithm, which is a simple linear model. Figure 7.19(a) shows the ROC curves from these models. It can be seen that all models demonstrated almost perfect discrimination power, indicating that the genomics pattern of sequences from four countries may have a significant difference.
