## 7.3 Alignment-based multiple sequence comparison

In some real applications, the multiple sequence alignment or comparison process is required for several research settings. For instance, the multiple sequence comparison practice has been used for synthetic protein identity verification in new chemistries discovery and cell pathway rewiring [Davis, 2019], for examining hypostome and tentacles in hydra Whole Genome Pattern Discovery regenerate [Turankawar and Ghashkadbi, 2019] and species classification [Hasegawa, *et al.*, 2019]. There are mainly two approaches for a multiple sequence comparison process, i.e., the alignment-based approach and the alignment-free approach.

The alignment-based multiple sequence comparison is implemented in several different methods. The most typical methods include the progressive method, the iterative method and the consensus method. The progressive method is a heuristic approach [Feng and Doolittle, 1988], Maiolo, *et al.*, 2018] and has a wide range of applications [Loytnoja and Goldman, 2005; Deorowicz, *et al.*, 2016; Ayad and Pissis, 2017; Maiolo, *et al.*, 2018; Rubio-Largo, *et al.*, 2018]. Among them, the progressive method is more effective and efficient.

The basic principle of the progressive method is to align sequences pair-wise from the most related pairs to the least related pairs. First, a pair-wise alignment is done for all pairs using a fast non-alignment or alignment-free sequence comparison method. Based on these initial comparison results, a hierarchical tree is constructed. Afterwards, the most related pair of sequences is found and aligned using a homology alignment model, The msa is a Bioconductor package, in which clustal series alignment approaches are implemented. The main support package for msa is Biostrings. Suppose following sequences are required to be aligned,

```
GAATCGATGTATAGGCCG
GATTGTATGTATAGGCCG
GAATCGATATATCTCCG
GAATCACATGTATAGGCCG
TGTAACCAATATCGCTCT
```

The following R code employed the Smith-Waterman algorithm to align these five sequences pair-wisely. Because each pair of sequences were required to be aligned, a dual-loop structure was employed. The outcome of this code was a similarity matrix score between all pairs of sequences.

```
for(i in 1:5)
for(j in 1:5)
  score[i,j]=pairwiseAlignment(seq[[i]],
  seq[[j]],type='local',substitutionMatrix=S,
  gapOpening=-1.3,gapExtension=-0.3)@score
```

After using the code, the score matrix was converted to a distance matrix using a simple method shown below,

```
D=max(score)-score
```

Based on this distance matrix, a hierarchical cluster model was constructed to generate a hierarchical cluster tree using the hclust function, which has been introduced in Chapter 2 of this book. Figure 7.4(a) shows such a tree. Afterwards, a function called cluster in the k-mer package was used to generate a clustal tree. Figure 7.4(b) shows a clustal tree. It can be seen that two trees are very similar. The discovered relationship between sequences in two trees were identical. For instance, both trees show that the first sequence and the fourth sequence merged while the fifth sequence was the last one to join the trees.
