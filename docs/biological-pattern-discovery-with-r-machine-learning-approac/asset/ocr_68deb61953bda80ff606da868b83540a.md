One of the important objectives of density estimation is thus to estimate a density function for a data set as accurately and as precisely as possible. A density function can be estimated using several approaches. The following sections introduce several commonly used ones as well as their implementations in the R environment.

# 2.2.1 The histogram approach

The histogram approach is the simplest approach for density estimation [Pearson, 1985]. Its basic principle is to count data points which fall in several pre-defined bins and use these counts to profile a density function for a data set.

Figure 2.2 shows how a histogram is constructed for the gene isntful of the Francisella Tularensis species in a gene Essentials pattern analysis project [Yang, et al., 2017]. The gene attracted 7,753 transposon insertions. These insertions were distributed across 180 sites within the gene. The gene base pairs were between 3,204 and 3,988 in the genome. The transposon insertion sites were between 3,207 and 3,980 base pairs.
