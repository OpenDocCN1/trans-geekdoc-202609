The output named as cluster of the kmeans function will show how data points are clustered. Suppose a K-means model was constructed using the kmeans function for the 20 amino acids and three clusters were designed. Table 2.9 shows how amino acids were clustered by the K-means model. It can be seen that the amino acids A, G, H, Q, S and T were clustered together. Other amino acids were grouped into other clusters.
The hierarchical clustering algorithm and the K-means algorithm are two typical algorithms based on different clustering strategies. It is interesting to compare these two algorithms for the amino acid data set. For this purpose, the first two principal components of a principal component analysis (PCA) [Pearson, 1901] model (the R function prcomp) was used to generate a two-dimensional mapping space for visualising these two cluster models. The hierarchical cluster model and the K-means cluster model were found having the same result as seen in the PCA map as shown in Figure 2.25.
