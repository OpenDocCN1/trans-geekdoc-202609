
## 3.3.2 The Naïve Bayes algorithm

In both LDA and QDA, the independent variables are not assumed to be independent. For instance, the projection direction ($\mathbf{w}$) is assumed to be proportion to $\Sigma^{-1}(\mathbf{u}_2 - \mathbf{u}_1)$ in the LDA algorithm. The density of each class in LDA is formulated as $\exp\{-0.5\delta^T\Sigma^{-1}\delta\}/\sqrt{(2\pi)^d|\Sigma|}$, where $\delta = \mathbf{x} - \mathbf{u}$. If the variables in $(\mathbf{x})$ are mutually correlated, the covariance matrix $\Sigma$ will not be diagonal, i.e., the off-diagonal entries of $\Sigma$ will not be zero. If independent variables are mutually independent from each other, the corresponding covariance $\Sigma$ is degenerated to a diagonal matrix, i.e., its off-diagonal entries are zeros. If $\Sigma$ is diagonal, the determinant of a covariance matrix ($|\Sigma|$) can be simplified by the product of the diagonal entries, each of which is the variance of a variable. The decomposition of a covariance to the variance due to the independence between variables is implemented by $|\Sigma_k| = \prod \sigma_{ki}^2$. In this situation, the Naïve Bayes discrimination analysis algorithm [Rennie, et al., 2003] can be more useful. The definition of the Naïve Bayes is defined as below,

```
$f(\mathbf{x}_n|u_k, \Sigma_k) = \prod_{i=1}^d \exp\left(-\frac{(x_{ni} - u_{ki})^2}{2\sigma_{ki}^2}\right) \quad (3.19)$
```

where $\text{diag}(\Sigma_k) = (\sigma_{k1}^2, \sigma_{k2}^2, \dots, \sigma_{kd}^2)$ and $\mathbf{x}_n = (x_{n1}, x_{n2}, \dots, x_{nd})$. It can be seen that the decomposition of the covariance matrix leads to the ignorance of the mutual correlation between the independent variables in a model. When the mutual correlation between variables is indeed minimal or insignificant, this approach can deliver a model with a better and efficient performance.

The R function for Naïve Bayes `naiveBayes` in the package e1071. Figure 3.8 shows the discrimination boundary of a Naïve Bayes model constructed for the data shown in Figure 3.6. the use of this model caused two misclassified data.

## 3.3.3 The logistic regression algorithm

The logistic regression algorithm [Walker and Duncan, 1967; Wolfram, 2002], which is also called a log regression algorithm, has been intensively studied in statistical learning and machine learning [Crawley, 2005; Cox, 2006; Bishop, 2006]. In a logistic regression model, a log function or a log odd function is defined as below, where $\alpha$ and $\beta$ are two parameters for a univariate regression,

```
$\log \frac{p(x)}{1-p(x)} = \alpha + \beta x \quad (3.20)$
```

This logistic function can be changed to the following format, where $\theta = \beta$ is called a slop parameter and $\delta = -\beta/\alpha$ is called a threshold parameter

```
$p(x) = \frac{1}{1+e^{-\theta(x-\delta)}} \quad (3.21)$
```

Figure 3.9 shows some logistic function with different parameter values. When $\theta=1$ and $\delta=0$, the logistic function is degenerated to the sigmoid function, which has been widely used in neural network algorithms [Bishop, 1996] and will be discussed later in this chapter.

A commonly objective function to model a data set using the logistic regression algorithm is a likelihood function below, where $P(x_n|y_n)$ is defined by a Bernoulli function [Uspensky, 1937],

```
$\mathcal{L} = \prod_{n=1}^N P(x_n|y_n) = \prod_{n=1}^N p(x_n)^{y_n}(1-p(x_n))^{1-y_n} \quad (3.22)$
```

The basic component of the Bernoulli function is called the binary entropy [MacKay, 2003], i.e., $\vartheta = p^y(1-p)^{1-y}$, where $y \in \{0,1\}$ and $p \in [0,1]$. When $y=1$ and $p=1.0$ or $y=0$ and $p=0.0$, $\vartheta$ is maximised. The parameters $\alpha$ and $\beta$ can be estimated through maximising this likelihood function. The logistic regression algorithm has been applied for drug-drug interaction prediction [Celebi, et al., 2019] and common cancer detection [Lopes, et al., 2019]. ## 3.3.4 The Bayesian linear discriminant analysis

In order to deliver a more robust discriminant analysis model, the Bayesian learning has been introduced for linear discriminant analysis as well. In a Bayesian learning discriminant analysis model, the *a priori* probabilities are no longer simply the proportions of data points belonging to two classes. Instead, they are parameters to be estimated using the *a priori* function [Zhou, et al., 2013]. Suppose the likelihood function of the model parameters is defined as,

```
$p(\mathbf{y}|\mathbf{w}, \beta) = \left(\frac{\beta}{2\pi}\right)^{N/2} \exp\left(-\frac{\beta}{2}|\mathbf{X}^t\mathbf{w}-\mathbf{y}|^2\right) \quad (3.23)$
```

The *a priori* function of model parameters is defined as,

```
$p(\mathbf{w}|\alpha) = \left(\frac{\alpha}{2\pi}\right)^{N/2} \exp\left(-\frac{\alpha}{2}|\mathbf{w}|^2\right) \quad (3.24)$
```

The use of maximum posterior probability leads to,

```
$p(\mathbf{w}|\mathbf{y}) \propto p(\mathbf{y}|\mathbf{w})p(\mathbf{w})$
```
