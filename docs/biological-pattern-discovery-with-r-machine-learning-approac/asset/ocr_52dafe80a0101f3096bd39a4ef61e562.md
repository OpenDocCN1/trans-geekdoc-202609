In each of four regression models constructed for a DEG, say the $g^{th}$ DEG, DMS employed as the independent variables were ranked. Suppose the $m^{th}$ DMS was ranked at the top. Its host gene was found and indexed by $k$. Note that the $k^{th}$ gene was not necessarily a DEG. Whether the $k^{th}$ gene was the host gene for the methylation site of the $m^{th}$ DMS was determined by the following method. Suppose the start and end base pairs of the $k^{th}$ gene were denoted by $\vartheta_{k,0}$ and $\vartheta_{k,1}$. The interval was then defined as $[\vartheta_{k,0} - 1000, \vartheta_{k,1} + 1000]$ for searching for the host gene for a methylation site. Suppose the base pair of the methylation site of the $m^{th}$ DMS was denoted as $\omega_m$. If $\vartheta_{k,0} - 1000 \leq \omega_m \leq \vartheta_{k,1} + 1000$, the $k^{th}$ gene was the host gene of the methylation site of the $m^{th}$ DMS.

All genes were ordered in terms of their sequential occurrence in a genome. The genes were indexed by their sequential occurrence positions in a genome. For instance, the first gene was assigned an integer one, the second gene was assigned an integer two, the third gene was assigned an integer three, etc. Therefore, the $g^{th}$ gene was assigned an integer $g$ and the $k^{th}$ gene was assigned an integer k.
