# 3.6.4 The support vector machine algorithm

Support vector machine (SVM) was proposed by Vladimir Vapnik [Cortes and Vapnik, 1995]. The basic principle of SVM is to use a kernel function to map a raw data space to a kernel space, where classification analysis or regression analysis may be implemented [Azerman, et al., 1964]; Cortes and Vapnik, 1995; Bishop, 2006]. It is also hypothesised that such a mapping space is linear.

In RBFNN, all radial basis functions will have their weights estimated as non-zero values. In reality, some radial basis functions may be redundant. In addition, the maximised likelihood approach [Duda, et al., 2000; Bishop, 2006; Rossi, 2018] used to estimate model parameters using the least squared errors approach may not be to generate an optimal model.

When searching for the best hyperplane for the discrimination between two classes of data points, SVM finds a set of data points which are most difficult to classify. These data points are referred to as the support vectors. They are the closest to the hyperplane and are located on the boundaries of the classification margin between two classes.

The idea proposed in SVM is to optimise the classification margin in a mapping space. Figure 3.29 shows this principle. In Figure 3.29(a), a wider classification margin allows some data points which can be easily classified to fall in. In Figure 3.29(b), no such data point is found within the classification margin. SVM will optimise the classification margin through the search of the support vectors. No data points other than support vectors will be used as kernels, hence the model is more parsimonious than a RBFNN model.

A SVM classifier is more robust to data noise or outliers due to the optimisation of a classification margin. The generalisation capability is therefore boosted.
