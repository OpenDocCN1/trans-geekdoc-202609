It must be noted that the signal intensities (s–b) should not be negative and they must be above a baseline, i.e., a signal $s_i - b_i$ is detected if $s_i \gg b_i$. Therefore, some updates have been used to correct the original Whittaker-Henderson algorithm. In these updates, the fidelity has been revised using the following method, which employs a decaying function $f(s_i, b_i)$ [Mazel, et al., 2005; Cobas, et al., 2006; Zhang, et al., 2010].

```
$e_i = \begin{cases} 0 & s_i > b_i \ f(s_i, b_i) & \text{other wise} \end{cases} \quad (5.3)$
```

In this scenario, only the negative errors are treated as noise while the positive errors are ignored when estimating the baseline for a spectrum using this type of approaches. After a baseline has been estimated and removed from a spectrum, the artifacts may be present. The artifacts presented in a baseline-removed spectrum are potential noise. They must be carefully dealt with in order to avoid them to be mistakenly treated as signals. A smoothing process is commonly used to combat the artifacts for the purpose of discovering the signals as accurately as possible from a baseline-removed peak spectrum.

When detecting signals from a spectrum through estimating a baseline which is contaminated by noise, a problem arises. If a model is too restrictive, some true signals may be treated as noise. Otherwise, there is a problem of how to trade-off between the true signal discovery rate and the false signal discovery rate. The optimal strategy is, of course, to maximise the true signal discovery rate and at the same time to minimise the false signal discovery rate.

WH is a version of a regularised regression model. In a WH model, the regularisation constant plays an important role to trade-off between the true signal discovery rate and the false signal discovery rate. As shown in the Equation (5.1), when the regularisation constant $\lambda$ is too small, an estimated baseline will not be sufficiently smooth. For instance, if $\lambda = 0, O = e^f$. In this case, no smoothness is considered. An estimated baseline will curve to fit to every detail signal intensities. The consequence is $s - b \to 0$, i.e., almost no signals at all.
