A C50 tree can also be pruned. For instance, if the minCases parameter of C5.0 is increased. Figure 3.42 shows such a pruned C50 tree. The text version of the pruned tree from C5.0 is shown below. The first branch node employed the partitioning rule Petal.Length≤1.9 to partition the whole space. This rule generated two subspaces. One of which was pure for the Setosa flowers. The other subspace was composed of the rest two classes of flowers. The second branch employed the partitioning rule Petal.Width≤1.7. This rule generated two subspaces. One was composed of 54 Versicolor of flowers and five Virginica flowers. The other was composed of 46 Virginica flowers and one Versicolor flower.

C50 provides a bootstrap approach for delivering a robust decision tree. Suppose ten trials of C5.0 were generated using the following code. There will be ten trees. Figure 3.43 shows two of ten trials. It can be seen that they show some difference.
