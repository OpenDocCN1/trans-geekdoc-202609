The open circles and triangles stand for easily classified data points. The filled circles and triangles represent support vectors which are exactly on the classification boundaries. The shaded circles and triangles are those data points which cannot be correctly classified. The dotted circles and triangles are those that fall in the classification margin. $\gamma$ is the width of the classification margin.

Suppose $y_n$ is the class label of the $n^{th}$ support vector and $\alpha_n$ is the positive parameter of the $n^{th}$ support vector and the number of support vectors ($K$) is determined by an SVM algorithm for a specific data set. A SVM model makes a decision using the following formula,

```
$$\hat{y} = \text{sign}\left(\sum_{n=1}^{K} \alpha_n y_n \Psi(\mathbf{x}, \mathbf{x}_n)\right) \quad (3.67)$
```

In SVM, $\Psi(\mathbf{x}_n)$ is referred to as a feature and is defined below,

```
$$\Psi(\mathbf{x}, \mathbf{x}_n) = \Psi(\mathbf{x}) \cdot \Psi(\mathbf{x}_n) \quad (3.68)$
```
