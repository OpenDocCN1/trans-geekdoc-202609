In other words, five pairs may not show significant differential expressions across two populations, but they have been classified as showing significant differential expressions across two conditions. This kind of error is named as a Type I error. A Type II error, on the other hand, refers to a falsely accepted null hypothesis. In the context of gene differential expression analysis, a Type I error refers to a wrongly predicted DEG and a Type II error stands for a wrongly predicted non-DEG, i.e., a missing DEG [Li, *et al.*, 2013; Mudge, *et al.*, 2017; Gonzalez, *et al.*, 2020].

The Type I and II errors occur often in an experiment especially when the sample size of a data is small. This is because it is often to prepare a few replicates to cut the expenses in many biological experiments. A severe outcome for a data set with insufficient replicate is an unreliable population variance in addition to an unreliable population

In the letrozole drug data which employs 58 baseline replicates and 58 letrozole replicates, the gene EHD2 is a DEG and the gene STAT1 is a non-DEG. Suppose subset of replicates is randomly drawn from 58 replicates for these two genes. It is interesting to observe how the differential expression status of these two genes change. For this investigation, the Type I and II errors were counted. The drawing number from two to 50. For each draw sample with a specific replicate number, 100 random simulations were carried out and hence 100 $t$ test $p$ values were calculated using the $t test$. Based on these 100 $t$ test $p$ values, the Fisher test [Fisher, 1948] for combining $p$ values was used. The Fisher test is defined as below,

```
$F = -2\sum_{k=1}^{K} \ln(p_k) \quad (6.5)$
```

The $F$ statistic follows a $\chi^2$ distribution. The package *metap* was used for this calculation. Figure 6.4 shows the result, where five Type II errors were identified when the replicate number was small for FKBP15 and 16 Type I errors presented when the replicate number was small for MAN1B1.
