## 6.5.3 The gap maximisation test approach

The gap maximisation test approach (GM) is another simple approach for gene expression bimodality discovery [Al Watban and Yang, 2016]. The basic idea is to model the density of delta expressions. It is believed that the existence of the bimodality within a gene expression vector may cause a typical decaying Gamma density of the delta expressions of the gene. If such a density can be well-estimated, the expression bimodality can then be well-discovered.

Fig. 6.32. The delta expression density of three randomly selected genes from the letrozole drug only. 58 letrozole treatments were used for this density estimation. The solid lines stand for the fitted Gamma densities. (a) The gene ZMIZ2. (b) The gene ATP10B. (c) the gene ARHGAP2B.

Figure 6.32 shows the estimated densities as well as their fitting curves of the delta expressions of three randomly selected genes from the data set in which the letrozole drug was used to treat breast cancer (GDS3116) [Miller, et al., 2007; Miller, et al., 2010]. It can be seen that the gene ZMIZ2 shows a sharp decaying Gamma density while the gene ARHGAP28 shows a slow decaying Gamma density. The gene ATP10B shows a median decaying Gamma density. Therefore, their bimodality pattern may be different.

The delta expression of a gene was generated using the following approach. Suppose a vector of $K$ ($58$ for the letrozole drug data) case expressions were expressed as below, where $n$ was the $n^{th}$ gene in data,

```
$$x_n = (x_{n,1}, x_{n,2}, \dots, x_{n,K})$$ (6.38)
```

The expressions in this vector were sorted in an ascending order and expressed as below,

```
$$x'_n = (x_{n,1}, x_{n,2}, \dots, x'_{n,K})$$ (6.39)
```

A delta expression was calculated by the difference between all consecutive pairs of sorted expressions,

```
$$\delta_n = (x_{n,2} - x_{n,1}, x_{n,3} - x_{n,2}, \dots, x_{n,K} - x_{n,(K-1)})$$ (6.40)
```

Figure 6.32 shows that the Gamma density modelling worked very well for fitting the Gamma density to the delta expressions of three genes selected from the letrozole drug data. Based on an estimated Gamma density function, the significance of each delta expression can be evaluated.

Figure 6.33 shows the relationship between the Gamma $p$ values and the delta expressions for three genes from the letrozole drug data shown in Figure 6.32. In these plots, it can be seen that some genes contained significantly great delta expressions, as the genes ZMIZ2 in Figure 6.33(a) and ATP10B in Figure 6.33(b). However, some genes did not contain a significantly great delta expression, such as the gene ARHGAP28 in Figure 6.33(c). A gene containing no such great delta expression implies that the expressions of such a gene likely form a unimodal distribution. Otherwise, the expressions of such a gene may form a multi-modal distribution including a bimodal distribution or such as a gene with outliers.

The procedure of the gap maximisation test is therefore designed as below. First, all the expressions are calculated using (6.39) and (6.40). These delta expressions are saved in a variable named as Δ shown below,

```
$$\Delta =(\delta_1, \delta_2, \dots, \delta_M)$$ (6.41)
```

where $M = N \times (K-1)$ is the number of all the delta expressions for a data set with $N$ genes and $K$ replicates. Note that all the expressions of $\Delta$ should be positive. However, in case there might be identical expressions within some genes, zero delta expressions may occur and be removed from $\Delta$ if they present before proceeding to the following stages. It is assumed that $\Delta$ follows a Gamma distribution which is shown below,

```
$$\Delta\sim G(\delta|\alpha, \beta) = \frac{\beta^{\alpha}\delta^{\alpha-1}e^{-\beta\delta}}{\Gamma(\alpha)}$$ (6.42)
```

After two parameters $\alpha$ and $\beta$ have been estimated, the Gamma density function is then used for evaluating the gene-wise delta expression significance, i.e., to calculate a $p$ value for each delta expression of each gene.

The gene expressions of real data often contain outliers. It is therefore required to distinguish between outliers and bimodality. If there are one or few replicates far away from the main expression cluster for a gene, these replicates should be treated as the outliers. This is because they can hardly form a subpopulation for the further meaningful biomedicine investigation. In other words, a phenomenon does not lead to the conclusion of a bimodal gene. Any outlier it has been discovered, will be removed. Afterwards, whatever there more significant delta expression is examined again for the gene.
