The alignment-based multiple sequence comparison is implemented in several different methods. The most typical methods include the progressive method, the iterative method and the consensus method. The progressive method is a heuristic approach [Feng and Doolittle, 1988], Maiolo, et al., 2018] and has a wide range of applications [Loytnoja and Goldman, 2005; Deorowicz, et al., 2016; Ayad and Pissis, 2017; Maiolo, et al., 2018; Rubio-Largo, et al., 2018]. Among them, the progressive method is more effective and efficient.

The basic principle of the progressive method is to align sequences pair-wise from the most related pairs to the least related pairs. First, a pair-wise alignment is done for all pairs using a fast non-alignment or alignment-free sequence comparison method. Based on these initial comparison results, a hierarchical tree is constructed. Afterwards, the most related pair of sequences is found and aligned using a homology alignment model, The msa is a Bioconductor package, in which clustal series alignment approaches are implemented.
