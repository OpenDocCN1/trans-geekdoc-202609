# Protease Cleavage Pattern Discovery

Suppose $x = R_m \dots R_2R_1R'_1 \dots R'_n$ is used to denote a peptide. In this peptide, $R_{1\le i\le m}$ stands for one of the $N$-terminal residues and $R'_{1\le j\le n}$ stands for one of the C-terminal residues. The cleavage happens between $R_1$ and $R'_1$. The requirement of a successful interaction between a protease and a cleavage site in a protein is the amino acid trend surrounding a cleavage site. Different proteases require different patterns of the amino acid composition trend. For instance, the factor X protease cleavage usually happens when $R_1 = R$, where $R$ is the amino acid arginine [Yang, et al., 2006]. The trypsin cleavage usually happens when $R_1 = K$ or $R_1 = R$, where $K$ is the amino acid lysine [Thomson, et al., 2003].

The success of the protease cleavage pattern discovery for a special protease depends on the accurate recognition of the amino acid composition trend within a set of cleaved peptides. Only when this discovered pattern has a great discrimination power between cleaved peptides and non-cleaved peptides, which is demonstrated in a machine learning model, following successful inhibitor design against the protease is thus possible [Goodman, et al., 1983; Sheeth, et al., 1984; Singh, et al., 2001].

# 3.2 The linear discriminant analysis algorithm

When analysing a biological data set, it is often required to recognise the property of molecules through analysing the factors associated with the property of molecules, such as predicting protein function, gene-gene interaction, enzyme cleavage sites and functional genes. This process is called the object classification. When there are only two classes of objects in a data set, this process is called a discriminant analysis. The final objective of a classification model is to label novel data (novel objects) or novel peptides in this context.

The linear discriminant analysis algorithm (LDA) was developed by Ronald Fisher as a linear model for classifying data and is also called the Fisher discriminant algorithm [Fisher, 1936]. The earliest application of LDA in PubMed was a perinatal mortality study [Greenberg, 1963].
