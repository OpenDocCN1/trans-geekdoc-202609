# 3.6.3 The bio-basis function neural network algorithm

Most machine learning algorithms except the decision tree algorithms are used to model numerical data. Therefore, how to deal with nonnumerical variables as the amino acids of a sequence data requires requires careful experimental design.

One popularly used approach is the binary encoding of the amino acids or the nucleic acids in peptides [Wu, et al., 1995; Kawabata and Doi, 1997; White and Seffens, 1998]. With this approach, each nucleic acid is encoded by a four-bit binary vector and each amino acid is encoded by a 20-bit binary vector.
