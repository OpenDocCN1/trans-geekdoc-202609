## Protease Cleavage Pattern Discovery

A protein functions when it interacts with molecules or chemicals. Among many formats of interactions, protease cleavage is one of the widely researched subjects for several decades. This type of research aims to build up a predictive model based on collected laboratory data to discover novel interactions. Such a model is commonly established on laboratory-verified protease cleavage data, in which the association between protease cleavage structure and protease cleavage function can be examined. A protease cleavage structure commonly means a primary sequence (or sub-sequence or peptide) which is believed to contain a specific amino acid composition pattern or trend in relationship with the protease cleavage function. In other words, the protease cleavage pattern must not show a random amino acid composition. Instead, the composition of the amino acids in a data set of protease cleaved peptides should demonstrate a trend for a specific protease to recognise the interaction. To make a protease cleavage pattern discovery model to work efficiently, two types of peptides are collected and pooled together for constructing a model. They are the cleaved peptides and the non-cleaved peptides. Non-cleaved peptides definitely must have no trend of the amino acid composition at all. Instead, they must show random distribution of the amino acids. By the contrast comparison between a data set with a trend and a data set without any trend, a pattern by which two types of data can be discriminated can thus be discovered and can thus be formulated as the knowledge or the intelligence. The purpose of discovering such intelligence is, no doubt, for the prediction. The protease cleavage pattern discovery problem is a classification problem in machine learning. This chapter will introduce several classification analysis or discriminant algorithms. This chapter will discuss how these algorithms can be used for the protease cleavage pattern discovery. Importantly, how to encode peptides sound as to make-encoded data biologically relevant is the key to make a protease cleavage pattern discovery task successful. This chapter will therefore introduce the bio-basis function, a new and cutting-edge approach for encoding peptides. Based on the bio-basis function, several advanced algorithms will be introduced for the protease cleavage pattern discovery.

### 3.1 A biology question — protease cleavage

A protease is an enzyme that interacts with polyproteins for several biological processes in cells [Antalis, et al., 2007]. For instance, a hepatitis C viral protein can cleave a polyprotein within an affected cell to release viral proteins. These released viral proteins will escape from an affected cell to invade and affect healthy cells to produce more viral proteins [Gottwein, et al., 2007; Scheel, et al., 2008]. An inhibitor is an effective clinical approach to stop or slow down the viral affinity [Lawitz, et al., 2019; Ong, et al., 2019]. Designing an effective drug against a viral protein requires the study of the amino acid composition trend in primary structure (peptides) around the cleavage sites of a specific protease [Cabuk, et al., 2018; Bancur-Ancona, et al., 2018].

A peptide is a sub-sequence with a few or a dozen of the amino acids. The function of a protease is to cleave a polyprotein at the targeted residues to release functional proteins. The interaction between a protease and a polyprotein highly depends on the specificity of the amino acids in the nearby areas of the interaction sites. Such an interaction site between a polyprotein and a protease in a polyprotein is called a protease cleavage site. The consequence of such an interaction or cleavage is the split of a polyprotein leading to the release of functional proteins.

### Protease Cleavage Pattern Discovery

Suppose $x = R_m \dots R_2R_1R'_1 \dots R'_n$ is used to denote a peptide. In this peptide, $R_{1\le i\le m}$ stands for one of the $N$-terminal residues and $R'_{1\le j\le n}$ stands for one of the C-terminal residues. The cleavage happens between $R_1$ and $R'_1$. The requirement of a successful interaction between a protease and a cleavage site in a protein is the amino acid trend surrounding a cleavage site. Different proteases require different patterns of the amino acid composition trend. For instance, the factor X protease cleavage usually happens when $R_1 = R$, where $R$ is the amino acid arginine [Yang, et al., 2006]. The trypsin cleavage usually happens when $R_1 = K$ or $R_1 = R$, where $K$ is the amino acid lysine [Thomson, et al., 2003].

The success of the protease cleavage pattern discovery for a special protease depends on the accurate recognition of the amino acid composition trend within a set of cleaved peptides. Only when this discovered pattern has a great discrimination power between cleaved peptides and non-cleaved peptides, which is demonstrated in a machine learning model, following successful inhibitor design against the protease is thus possible [Goodman, et al., 1983; Sheeth, et al., 1984; Singh, et al., 2001].

### 3.2 The linear discriminant analysis algorithm

When analysing a biological data set, it is often required to recognise the property of molecules through analysing the factors associated with the property of molecules, such as predicting protein function, gene-gene interaction, enzyme cleavage sites and functional genes. This process is called the object classification. When there are only two classes of objects in a data set, this process is called a discriminant analysis. The final objective of a classification model is to label novel data (novel objects) or novel peptides in this context.

The linear discriminant analysis algorithm (LDA) was developed by Ronald Fisher as a linear model for classifying data and is also called the Fisher discriminant algorithm [Fisher, 1936]. The earliest application of LDA in PubMed was a perinatal mortality study [Greenberg, 1963]. Although LDA is a linear model, it lays down the foundation of classification analysis. For instance, it has been used to discover the geographical origin of maize, separate fatty acids, and investigate how it impacts cancer treatment based on profiling microbiome and metabolome.

#### 3.2.1 The definition and working principle of LDA

Suppose the $n^{th}$ observation is represented by a vector $\mathbf{x}_n$ and the label of $\mathbf{x}_n$ is denoted by $y_n$. In terms of protease cleavage discovery, $\mathbf{x}_n$ is a peptide, which is labelled by $y_n$ as either cleaved or non-cleaved. The classification label for this type of data is binary. Normally a non-cleaved peptide $\mathbf{x}_n$ is labelled by a zero, i.e., $y_n = 0$ and a cleaved peptide $\mathbf{x}_n$ is labelled by a one, i.e., $y_n = 1$. A general format of a classification model is shown below:

$\hat{y}_n = f(\mathbf{x}_n, \mathbf{w})$

where $\mathbf{w}$ is a vector of model parameters, $f$ is a classification function, $\hat{y}_n$ is a prediction corresponding to $y_n$. In a well-constructed classifier, $\hat{y}_n$ should be a numerical value close to zero if $y_n = 0$ and $\hat{y}_n$ should be a numerical value to one if $y_n = 1$. If a classification problem is linear, a classification model can be formulated as:

$\hat{Y}_n = \mathbf{w}^{T}\mathbf{x}_n = x_{n1}w_1 + x_{n2}w_2 + \cdots x_{nd}w_d \mapsto y_n$

where $x_{ni}$ corresponds to the $i^{th}$ independent variable of vector $\mathbf{x}_n$ and $w_i$ stands for the $i^{th}$ weight in $\mathbf{w}$, which is used to weigh the contribution of $x_{ni}$ to $\hat{y}_n$. A vector-matrix format of a linear classifier is formulated as below, where $\mathbf{X}$ is an input matrix and $\hat{\mathbf{y}}$ is an output vector:

$\hat{\mathbf{y}} = \mathbf{X}^{T}\mathbf{w}$

The major part of LDA is to find the best projection direction to map a high-dimensional genotype space $(\mathbf{X})$ to a one-dimensional phenotype space $(\hat{\mathbf{y}})$. To make a LDA model work, the density of $\hat{\mathbf{y}}$ is required to be bimodal. Only when this bimodality is maximised, the projection direction or the model parameters $\mathbf{w}$ are considered as an optimal solution.
