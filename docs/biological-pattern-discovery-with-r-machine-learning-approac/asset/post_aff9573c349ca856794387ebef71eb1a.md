Before discussing the uncertainty of a cluster model structure can be well-handled using the K-means algorithm, two measurements can be used. Figure 2.28 shows one scenario where data set is composed of two clusters. Two clusters have the same centre-to-centre (or cluster distance) in three panels. But two clusters have different within-cluster variances. Here a term is defined as the sum of within-cluster variances, which is called the within-cluster sum of squares. It was 24132, 15831 and 4155 in three panels of Figure 2.28, i.e., panel (a), panel (b) and panel (c), respectively. The sum of within-cluster variance is also called the total-cluster variance. Based on the comparison of these three panels, it can be seen that the discrimination power between clusters depends on the total-cluster variance. A greater total-cluster variance may lead to a poorer discrimination power between clusters. However, a smaller total-cluster variance may result in better discrimination power between clusters. Therefore, the data presented in Figure 2.28(a) may have the poorest discrimination power or the worst clustering performance while the data presented in Figure 2.28(b) may have the best clustering performance.![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_69_0.png)

Fig. 2.29. Three scenarios to show the impact of the between-cluster variance on the clustering performance. The dots stand for the data points and the triangles stand for the cluster centres. Sb stands for the between-cluster sum of squares. The outputs of the kmeans function include several sums of squares. The output named `withinss` is a vector and is called the within-cluster sum of squares. Each entry of the vector is the variance of the cluster, i.e., the within-cluster variance. Such a variance is the sum of the squared distances between the centre of the cluster and all data points which have been classified into the cluster. The output named `tot.withinss` is the sum of `withinss` and stands for the total-cluster variance. It is denoted by $S_W^2$. The output named `betweens` stands for the sum of the squared distances between the cluster centres and is named the between-cluster variance. It is denoted by $S_B^2$.

In summary, two statistics (`tot.withinss` or $S_W^2$ and `betweens` or $S_B^2$) can be used to assess the performance of a cluster model. Based on $S_W^2$ and $S_B^2$, the well-known $F$ statistic used in ANOVA can be considered for optimising a K-means model structure. The $F$ statistic is defined as below, for which a $p$ value can be calculated for the significance evaluation,

$$F = \frac{S_B^2}{S_W^2} \quad (2.23)$$

It can be seen that the $F$ statistic should be maximised. This is because maximising $S_B^2$ is equivalent to the maximisation of the $F$ statistic and minimising $S_W^2$ is equivalent to the maximisation of the $F$ statistic as well. When trying different cluster numbers, different $F$ statistic values will be calculated. To find the best cluster model structure, it is therefore required to maximise the $F$ statistic. This means that the best cluster model structure will correspond to the maximised $F$ statistic for a specified cluster number.

Because it is not easy to determine a good threshold for the $F$ statistic, a $p$ value is used for the significance analysis. Figure 2.30(a) shows a data with nine clusters. The distribution of $p$ values is shown in Figure 2.30(b), where 15 models, which employed two, three, till sixteen clusters, were tested. If the critical $p$ value was 0.01, the selected model structure was eight clusters because it was the first cluster with a $p$ value being less than 0.01 in the $p$ value distribution. It was one less than the true cluster number.![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_71_0.png)

The fuzzy C-means algorithm was proposed to overcome the drawback of the K-means by introducing soft membership. The fuzzy C-means is defined below. The membership of a data point $x_n$ to a cluster $k$ is denoted by $u_{nk}$, which is a function [Dunn, 1973; Bezdek, 1981]. $m$ is a positive parameter to weight the membership. The fuzzy C-means algorithm also initialises the centres randomly. The centres are updated until the maximum cycles are reached.

$$ \sum_{n=1}^N \sum_{k=1}^C u_{nk}^{\frac{2}{m-1}} \|x_n - c_k\|^2$$

In the fuzzy C-means, the membership of a data point $x_n$ to a cluster $k$ is denoted by $u_{nk}$, which is calculated as:

$$u_{nk} = \frac{\sum_{j=1}^C \|x_n - c_j\|^{\frac{2}{m-1}}}{\sum_{j=1}^C \|x_n - c_j\|^{\frac{2}{m-1}} \|x_n - c_k\|^{\frac{2}{m-1}}}$$

The centres $c_k$ are updated as:

$$c_k = \frac{\sum_{n=1}^N u_{nk}^{\frac{2}{m-1}} x_n}{\sum_{n=1}^N u_{nk}^{\frac{2}{m-1}}}$$

The fuzzy C-means algorithm has been used in many medical fields. For example, it has led to a significant accuracy of Type 1 diabetes based on blood glucose [Montaser et al., 2020]. It has also been used to cluster tissues in computer-aided diagnosis of Alzheimer's disease [Lazli et al., 2020]. One R package for the fuzzy C-means is `cluster`. The main R function for constructing a fuzzy C- model is `fcm`, which is defined as
