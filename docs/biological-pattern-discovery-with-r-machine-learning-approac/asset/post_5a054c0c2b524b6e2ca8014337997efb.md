### 3.6.3.3 The orthogonal kernel machine

A BBFNN model is expressed as **y = Sw+e**, where the matrix **S** has K columns. The orthogonal least square algorithm is a forward kernel selection procedure [Chen, et al., 1991]. The use of the orthogonal least square algorithm for BBFNN has led to a new version of BBFNN, which is named as the orthogonal kernel machine (OKM) [Yang, 2005c]. At each kernel selection step, the incremental information content is maximised. The feature matrix is re-written as **S = (z₁, z₂, ..., zₖ)**, where **zₖ** corresponds to **sₖ**. The elements in **zₖ** are the mapping values of all the inputs on **sₖ**. It is obvious that there are correlated or there is some redundancy among kernels **z₁, z₂, ..., zₖ**. It is expected to find new kernels which have no mutual correlation. In OKM, each kernel **zₖ** is transformed to an orthogonal kernel (**pₖ**) to minimise the mutual correlation or the information redundancy. This search is continued until the error is below a pre-defined threshold.

### 3.6.4 The support vector machine algorithm

Support vector machine (SVM) was proposed by Vladimir Vapnik [Cortes and Vapnik, 1995]. The basic principle of SVM is to use a kernel function to map a raw data space to a kernel space, where classification analysis or regression analysis may be implemented [Azerman, et al., 1995].

In reality, all basis functions have non-zero weights [Duda, et al., 2000; Bishop, 2006]. Using least squared errors to estimate parameters may not correctly classify data points [Rossi, 2018]. SVM finds a set of data points which are most difficult to classify; these are referred to as support vectors which are located on the boundaries of the classification margin. The idea proposed in SVM is shown in Figure 3.29. (a) A classification margin, which may not be optimal; (b) A classification margin, which may be optimized. Data points fall in the classification margin; $\gamma$ is the width of the margin. A SVM classifier is more robust to data noise or outliers due to the optimization of the classification margin. The generalization capability is therefore boosted. A trained SVM classifier is a linear combination of similarities between an input and support vectors.
