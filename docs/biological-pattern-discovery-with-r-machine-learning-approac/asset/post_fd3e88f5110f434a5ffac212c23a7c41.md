## 3.6.7 Inductive learning

The main objective of every prediction model is to indicate what will happen in the future. Many machine learning algorithms are able to deliver a good prediction model for a problem through a proper training process. However, it is very often to have such a question, and why how a prediction is delivered. In many applications, the capability of interpreting a constructed model and a prediction has been a desirable feature.

## Biological Pattern Discovery with R

The interpretation capability is certainly important to all computational models in all disciplines. For instance, a protein function prediction model may need to know which genotype variable is a major factor initiating a specific protein function from a constructed machine learning model [Schietgat, et al., 2010]. A linear model can provide a good interpretation function, but is unable to model complex data. A nonlinear algorithm such as MLP or RBFNN or SVM can model complex data, but has less power of explaining what has been done in a model.

Data handling is also a key issue of the concern when modelling a data set. Data types can be very different from applications to applications. For instance, they might be categorical data or non-numerical data. The protease cleavage pattern discovery problem always deals with non-numerical data, i.e., the amino acids. Without an encoding process, the aforementioned machine learning algorithms can do nothing for the protease cleavage pattern discovery problem. This challenges the aforementioned machine learning algorithms.

Moreover, the problem of model construction complexity has been a great concern in some of the aforementioned machine learning algorithms. This is because they require the lengthy model construction time and a long process of the generalisation test to overcome the model uncertainty problem, such as the MLP algorithms.

Finally, dimensionality is also a concern when employing the aforementioned machine learning algorithms. Some of these algorithms are unable to handle data in which the dimension is greater than the number of samples. This is because the statistical significance cannot be guaranteed during a learning process.

### 3.6.7.1 The working principle of inductive learning

The inductive learning approaches have been well recognised to have a unique feature to overcome these limitations which occur to the aforementioned machine learning algorithms. The most commonly researched inductive learning approaches include the decision tree algorithm (DT) [Quinlan, 1986] and the classification and regression tree algorithm (CART) [Breiman, et al., 1984]. These algorithms have also been employed in many biological/medical pattern analysis projects.

The basic principle of DT and CART is “divide and conquer”, which is an old concept exercised in the computer sciences since 1970s

[Karatsuba and Ofman, 1963]. With this principle, a data space with a mixture of data points of different classes is gradually divided into subspaces using some classification or partitioning rules. It is also called the binary search because the use of every partitioning rule divides a space into two subspaces [Shapiro and Haralick, 1982]. This kind of learning strategy is still in use for biological/medical pattern analysis, such as the fast DNA copy number data analysis [Ruan, et al., 2019].

Figure 3.37 shows the use of this binary search strategy. In Figure 3.37(a), either the partitioning rule $y=2$ or the partitioning rule $y=0$ can divide the whole space into two parts, i.e., two subspaces. After each partition, the data points distribute in the upper panel subspace and others distribute in the lower panel subspace. The classification performance of these two partitions depends on the how data points are distributed. Obviously, the upper panel in Figure 3.37(a) shows a great mixture of data points from two classes when using the partitioning rule $y=0$. But the partitioning rule $y=2$ in Figure 3.37(a) generates two subspaces which are more clean or pure to a single class, i.e., either subspace has a very limited mixture of data points from two classes.

In Figure 3.37(b), the partitioning rule $y=0$ certainly does not help to separate two classes of data points into two pure subspaces. Two more partitioning rules $x=0$ and $x=3$ are therefore included into the decision-making system in addition to the partitioning rule $y=0$ to make four subspaces for the classification of the data points. After this data space has been well-defined into four subspaces, data points can be classified.

A subspace, which is only composed of one class of data points, is certainly very useful for the inference on novel data, i.e., providing the highest confidence. For instance, if a novel data point is found in the upper-left subspace shown in Figure 3.37(b), this novel data point is then labelled or predicted as a new member of the cross class with an almost 100% confidence. This is because all data points in this subspace belong to the cross class. Of course, if a novel data point is located in the upper subspace generated by the partitioning rule y = 0 in Figure 3.37(a), the confidence of labelling this data point to the cross class is much lower because this subspace has far less pure for the cross class.

Suppose a partitioning strategy for a data space has been derived, how this partitioning strategy can be expressed or visualised as a decision-making model for interpreting every decision which has been made using the model? The plots in Figure 3.37 are certainly not very efficient to use. In order to explore human intelligence of a model, a tree-like making structure has been adopted by the inductive learning algorithms. Using such a tree, how a decision can be clearly visualised in the tree step. Importantly, a decision-making process is sequentially visualised. For instance, such a tree can show which variable is employed at first and which variable is employed in the next steps to explain why and how a decision is made. Finally, such a tree can show how confident to trust a decision which has been made. In short words, an inductive learning model can help deliver a human-intelligence-alike model.
