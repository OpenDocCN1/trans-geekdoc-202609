To parse and evaluate an RPN string, a stack is normally used and a string is scanned from the left terminal to the right terminal of an RPN string, token by token.

When a scanned token is a variable, a value assigned to the variable is pushed into the stack. When a scanned token is an operator, a number of values within the stack are popped up from the top of the stack one by one downwards for them to take part in a calculation for the operation specified by the scanned token. After calculation, the calculated result is pushed back to the stack. When an RPN string has been fully scanned, the stack is only composed of one value as the final output of a system.

Suppose x=1, y=2, z=3 for a system x + 3y + x expressed using xy*x* and a stack was denoted by S. Figure 8.6 shows how each token was scanned for the evaluation of this RPN string. The scanning process of this RPN string is shown as follows. The first token was a variable x. Therefore the value of x was pushed into the stack, i.e., S = 1. At this step, the stack was only composed of one value, which was one. The second token was three, which was a constant. Therefore, it was also pushed into the stack. The stack was now composed of two values, S = (1, 3). Note that the top entry of S was three, which was the last one pushed into the stack. The operation strategy of a stack was last-first-out. The third token was a variable y. Therefore, the value of y was pushed into the stack. The stack was now composed of three values, S = (1, 3, 2). The fourth token was a multiplication operator (a star). After popping the top two entries of S, the stack was composed of only one value, S = 1. The popped values were used for a multiplication between them, i.e 3 X 2 = 6. The outcome, which was six, was pushed back into the stack. The stack was now composed of two values, S = (1, 6). The fifth token was again an operator (a cross). Therefore two entries of the stack were popped up leaving an empty stack, i.e, S = NULL. Two popped values (one and six) were summed up. The outcome was then pushed back to the stack. The stack became S = 7. The sixth token was a variable x. Therefore, the value of x was pushed into the stack, i.e., S = (7, 1). The seventh token was a variable z. Therefore the value of z was pushed into the stack, i.e., S = (7, 1, 3). The eighth token was an operator (a star).
