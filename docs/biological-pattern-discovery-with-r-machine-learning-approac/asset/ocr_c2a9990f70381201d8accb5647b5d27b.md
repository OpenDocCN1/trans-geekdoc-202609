In addition to a regression model which only employs one independent variable, many biological applications require more than one independent variable. In this case, a univariate regression analysis is extended to a multivariate regression analysis model. Suppose $y$ is a dependent variable, $x_1$ and $x_2$ are independent variables, $eta_0$ is an intercept, $eta_1$ and $eta_2$ are two regression coefficients for two independent variables, $\varepsilon$ is an error term of a multivariate regression analysis model. A multivariate regression analysis model is defined below,

$y = eta_0 + eta_1 	imes x_1 + eta_2 	imes x_2 + \varepsilon$ (4.24)

Suppose all independent variables of the olive oil content data were used to analyse how they contribute to olive oil content. An OLR model can be established using the following code,

```
model=lm(Oil.content ~ .)
```

Figure 4.14 shows the visualised multivariate OLR model for employing all independent variables of this olive oil content data. The $R^2$ value was 0.3434. The F-statistic $p$ value was 6.57e-5. Among these independent variables, one had significant association with the dependent variable suppose the critical $p$ value was 0.05. It was the stone width.
