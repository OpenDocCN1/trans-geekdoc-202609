#  2.4.4.1 The multi-statistics multivariate model

First, three transposon statistics (the insertion statistic, the site statistic and the MF statistic) were joined together, i.e., treated as three variables, to construct a multivariate cluster model for gene essentiality analysis for this data set. The K-means model (kmeans), the fuzzy C-means (cmmeans) and the Gamma mixture model (mixR) and the Gaussian mixture model (mixtools) were constructed.

Both the K-means model and the fuzzy C-means model predicted 442 essential genes meaning these 406 genes had strong essentiality compared with other genes. Figure 2.48 shows the result. In this Venn diagram, it can be seen that the disagreement between four models became smaller. The coincident rate between four models was about 86.02% among 472 predicted essential genes by four models.
