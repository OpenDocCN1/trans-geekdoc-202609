Chapter 5 will focus on the problem of discovering the chemicals or molecules which reside on a spectra curve. This is a very special data type. The curve on the chemicals or molecules reside is called a baseline and is normally non-analytic and complex. To discover the chemicals or the molecules, it is required to estimate and remove this baseline as accurately as possible. Therefore, various spectra baseline estimation algorithms will be introduced in this chapter. How these algorithms can be used to support the robust chemical or molecule discovery will be demonstrated in this chapter as so as to improve the discovery quality will also be discussed.

Chapter 6 will focus on another responsive gene discovery problem. This kind of research requires to discover the differentially expressed genes in an experiment. There are two types of data for this kind of applications, i.e., the microarray gene expression data and the sequencing count data. Different methods for dealing with these two types of data will be introduced in this chapter. In addition to commonly used algorithms, this chapter will also introduce the algorithms tailored to special data for discovering differentially expressed genes. For instance, this chapter will introduce algorithms which are designed to handle the problems of how to discover the differentially expressed genes for a data set where outliers are presented, how to discover the subpopulation formation, i.e., the bimodal genes and how to discover the differentially expressed genes in a data set with insufficient replicate.
