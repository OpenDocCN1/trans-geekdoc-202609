# 6.4 Discover differentially expressed genes when outliers are present

It is not a surprise that outliers occur in the gene expression data from time to time. When this happens, gene expressions across replicates show a heterogeneous distribution and only a small proportion of expressions show an inconsistent trend. For instance, most replicates show high expressions, but a few show very low expressions. A heterogeneous expression distribution often happens in disease-related experiments such as drug trials, drug resistance and cancer diagnosis research. Evidence can be found in the literature regarding the heterogeneous pattern of gene expression profile [Miyachi, et al., 1993; Wani, et al., 1993; Hess, et al., 1994; Ezzat, et al., 1995; Suzuki, et al., 1998; Kraust, et al., 2000; Nakayama, et al., 2000; Ebina, et al., 2001; Makhijani, et al., 2018; Zolotareya, et al., 2020]. A differentially expressed gene with some outlier expression(s) is called a heterogeneous differentially expressed gene and the expressions of such a gene are called the heterogeneous expressions.

The consequence of heterogeneous expressions is the potential increase of the Type I error rate or the Type II error rate. Because of the heterogeneous expressions, the discovery of DEGs is challenged when using the common methods such as the t test or the modified t test. In addition, the conventional outlier test approaches [Dixon, 1950; Grubbs, 1950; Dixon, 1951] may not be efficient. An efficient way is to embed an outlier detection component into the DEG discovery process for a robust DEG discovery.
