The next question was the fitness of each RPN rule formulated using the min-max function. Because analysing the factor Xa protease cleavage data for pattern discovery was a classification problem, therefore equations (8.8) and (8.9) were used for the fitness analysis.

The pool size was 100, and the value of $\alpha$ was 0.9 for the factor Xa protease cleavage pattern discovery. The mutation, dual-chromosome crossover, and single-chromosome crossover operations were randomly selected with an equal probability during a learning process. The learning process was terminated when the top fitness measurement was unchanged for more than 20 cycles or maximum learning cycle. Two mutation matrices were used to measure the similarity between amino acids and were used for a comparison. One was the Dayhoff mutation matrix [Dayhoff and Schwartz, 1978] and the other was the BLOSUM62 mutation matrix [Henik and Henikov, 1992].

In addition to three breeding operators, a special treatment as a supplement to the old approach [Yang, et al., 2003] was also introduced.
