A subspace, which is only composed of one class of data points, is certainly very useful for the inference on novel data, i.e., providing the highest confidence for the inference. For instance, if a novel data point is found in the upper-left subspace shown in Figure 3.37(b), this novel data point is then labelled or predicted as a new member of the cross class with an almost 100% confidence. This is because all data points in this subspace belong to the cross class. Of course, if a novel data point is located in the upper subspace generated by the partitioning rule y = 0 in Figure 3.37(a), the confidence of labelling this data point to the cross class is much lower because this subspace has far less pure for the cross class.

Suppose a partitioning strategy for a data space has been derived, how this partitioning strategy can be expressed or visualised as a decision-making model for interpreting every decision which has been made using the model? The plots in Figure 3.37 are certainly not very efficient to use. In order to explore human intelligence of a model, a tree-like making structure has been adopted by the inductive learning algorithms. Using such a tree, how a decision can be clearly visualised in the tree step. Importantly, a decision-making process is sequentially visualised. For instance, such a tree can show which variable is employed at first and which variable is employed in the next steps to explain why and how a decision is made. Finally, such a tree can show how confident to trust a decision which has been made. In short words, an inductive learning model can help deliver a human-intelligence-alike model.
