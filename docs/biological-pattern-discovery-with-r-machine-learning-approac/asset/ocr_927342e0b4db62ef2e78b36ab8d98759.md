Fig. 6.19. The experiment showing how the outlier has caused misleading outcome using the $t$ test, E1, E2 and E3 stand for the prediction errors of the non-DEGs, the up-regulated DEGs and the down-regulated DEGs. The blue triangles in the curves stand for the E2 errors and the red crosses stand for the E3 test.

The prediction errors were not significantly reduced using the modified $t$ test [Smyth, 2004]. This was not a surprise because the modified $t$ test algorithms do not address the outlier problem in data. Using the *limma* package, from zero to ten up-regulated DEGs were misclassified and from four to ten down-regulated DEGs were misclassified. Similar to the $t$ test result, the *limma* model did not work well when the outlier number was increased. There was no prediction error for the non-DEGs, i.e., hence no Type I error for using the *limma* package as well.
