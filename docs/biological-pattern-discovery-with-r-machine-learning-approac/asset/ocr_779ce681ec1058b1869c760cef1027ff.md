# Summary

This chapter has introduced several approaches used for the whole genome pattern discovery problem. Among them, the focal point is how to integrate different approaches to analyse genomics patterns hidden in sequence data. The introduction in this chapter has covered the sequence homology alignment approaches including global and local alignment as well as pair-wise and multiple alignment. The emphasised point in this chapter is the multiple sequence comparison approaches. Therefore the alignment-free and alignment-based multiple sequence alignment approaches have been introduced and compared. Based on these introductions, this chapter has also shown how these approaches, especially the alignment-free approaches can be used for the whole genome pattern discovery for a SARS-CoV-2 sequence research, i.e., whether the whole genome statistic can be used to interpret the difference of the pandemic in different countries.
