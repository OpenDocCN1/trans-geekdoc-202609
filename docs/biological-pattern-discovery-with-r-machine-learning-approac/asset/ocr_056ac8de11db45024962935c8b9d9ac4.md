Fig 2.13. A comparison between the kernel approach and the semi-parametric approach for estimating a density function for a data set. The thick lines stand for the final densities. The grey lines stand for the kernel/component densities. (a) The Kernel-based model. (b) The semi-parametric model.

When using the semi-parametric approach to estimate a density function for a data set, it is important to make a right assumption of the basic densities or components. In other words, the component number should be accurately decided. Figure 2.14(a) shows a case, where the true component number was three, but the designed component number was two. The resulting density is certainly misleading. However, when employing too many basic densities, this problem may disappear because some components may be duplicated at all. Figure 2.14(b) shows a case where a semi-parametric model employing too many components for a data set which was actually a mixture of two Gaussians still worked. The model was therefore heavier.
