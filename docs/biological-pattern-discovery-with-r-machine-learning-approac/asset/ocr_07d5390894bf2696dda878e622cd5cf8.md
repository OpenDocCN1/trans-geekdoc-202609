# Responsive Gene Discovery

# 2.3 Cluster analysis

Cluster analysis is an unsupervised learning approach, which aims to partition a data set into sub-data sets, each of which is a cluster. When it is required to investigate how genes function within a genome under a stress, cluster analysis can be used to partition genes into groups according to their measured responsive strengths so to discover how the genes function in different ways. Because of this reason, cluster analysis has been very popular in many biological/medical pattern discovery tasks [Le Roch, et al., 2003; Liu, et al., 2005; Huang and Pan, 2006; Pan, 2006; Higashi and Saito, 2013]. Cluster analysis has been used to examine how Ca2+-dependent conformation changes [Chaturvedvedi, et al., 2020]. In a lung cancer study, the use of cluster analysis has discovered that malignant mesotheliomas demonstrate high ROR1 expression [Miyake, et al., 2020]. To examine whether bovine is a symptom of aberration of liver functions, cluster analysis has been used to confirm the relationship of gene expression between bovine granulocytes and aberration of liver functions [Kizaki, et al., 2020]. The molecules which share similar biological functions in similar biological pathways are believed to show similar activities in an experiment. A cluster analysis study has revealed different numbers of differentially expressed genes responding to the same drought stress in wheat, maize and rice [Wei and Chen, 2018].

Most of these researches are hypothesis-driven and have little or no a priori knowledge about how a cluster model should look in advance. In other words, no knowledge will tell which group of molecules demonstrate a similar response to a stress before a pattern analysis process using a machine learning algorithm starts. Cluster analysis is thus a good approach to be used for this kind of pattern analysis.
