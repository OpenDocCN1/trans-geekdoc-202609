Taylor has interpreted the regularisation constant of a baseline model as a Bayesian prior [Taylor, 1992]. Because of this, the relationship between the smoothness and the fidelity (regression error) can be defined as below,

```
$f_{B|E=e}(b) = \frac{f_{E|B=b}(e)f_B(b)}{f_E(e)} \quad (5.21)$
```

where $f_E(e) = \int_{-\infty}^{\infty} f_{E|B=b}(e)f_B(\beta)d\beta$ is called the evidence, which is a constant. Therefore, the posterior of a BWH baseline model is then proportional to the product of the fidelity density and the smoothness prior,

```
$f_{B|E=e}(b) \propto f_{E|B=b}(e)f_B(b) \quad (5.22)$
```

In the above equation, $f_{B|E=e}(b)$ is a prior of the baseline and its smoothness prior is $f_{D=d|\sigma_S^2}(d)$. Two hierarchical inverse Gamma priors for variances ($\sigma_F^2$ and $\sigma_S^2$) are introduced for BWH. The inverse Gamma prior for $\sigma_F^2$ is defined as below, where $\alpha_F$ and $\beta_F$ are two hyper-parameters for the fidelity prior,

```
$f_{\sigma_F^2|\alpha_F,\beta_F}(\sigma_F^2) = \frac{\beta_F^{\alpha_F}}{\sigma_F^{\alpha_F+2}\Gamma(\alpha_F)} \exp(\left(-\frac{\beta_F}{\sigma_F^2}\rightright) \quad (5.23)$
```

The inverse Gamma prior for $\sigma_S^2$ is defined as below, where $\alpha_S$ and $\beta_S$ are two hyper-parameters for the smoothness prior

```
$f_{\sigma_S^2|\alpha_S,\beta_S}(\sigma_S^2) = \frac{\beta_S^{\alpha_S}}{\sigma_S^{\alpha_S+2}\Gamma(\alpha_S)} \exp(\left(-\frac{\beta_S}{\sigma_S^2}\rightright) \quad (5.24)$
```

The posterior of a baseline estimation is defined as below, $\theta=(\sigma_F^2,\sigma_S^2,\alpha_F,\alpha_S,\eta_F,\beta_S),$

```
$f_{B|b,e}(\theta) \propto f_{B|b=e}(b)f_{D=d|\sigma_D^2}(d)f_{\sigma_F^2|\alpha_F,\beta_F}(\sigma_F^2)f_{\sigma_S^2|\alpha_S,\beta_S}(\sigma_S^2) \quad (5.25)$
```
