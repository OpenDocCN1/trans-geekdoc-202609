# Biological Pattern Discovery with R

In a sequencing count matrix, genes are arranged in rows and replicates are arranged in columns. Each entry of such a matrix stands for the number of sequencing reads hitting a gene of a replicate, i.e., the sequencing count in one replicate for one gene. Table 6.4 shows such a count matrix used to examine how genes contribute to the airway smooth muscle cytokine function [Himes, et al., 2014], where there were two experimental conditions and each condition had four replicates. The objective of analysing such a sequencing count matrix was to find out which subset of genes are differentially expressed across conditions.

The sequencing count data are different from the microarray data as count data are non-negative integers. Therefore, limma may not be very useful. The negative binomial distribution has been employed for identifying DEGs for the sequencing count data [Robinson, et al., 2009; Anders and Huber, 2010].
