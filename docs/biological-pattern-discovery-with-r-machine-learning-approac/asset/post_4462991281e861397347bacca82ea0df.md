## 4.9.2 Gene to methylation site association — E2M models

Suppose $m_k$ stands for a differential methylation vector of a DMS, $X$ stands for a differential expression matrix of 1,250 DEGs and $w$ stands for a vector of regression coefficients or model parameters which needs to be estimated. There were in total 910 E2M regression models, each of which was defined as below,

```
m_k = f(X, w) (4.51)
```

The methylation site of a DMS in such a regression model above was named as the target methylation site. In other words, each of 910 DMSs was the target DMS in one regression model.

Figure 4.35 shows the density of the R-square measurements of four E2M models. The four models worked very well, especially the random forest and SVM models.

The host gene of each target DMS was also identified. Based on equations (4.49) and (4.50), the order distance between the host gene of each target DMS and the top-ranked DEG was calculated. The densities of the gene distances were estimated for the investigation of the skewness. Figure 4.36 shows the distribution of the gene order distances between the host genes of the target DMSs and the top-ranked DEGs of the four E2M regression models. The distances were also binned into six intervals. It can be seen from Figure 4.35 that all distributions have the same pattern, i.e., being skewed towards the right side for the greater order distance intervals. Suppose the Lasso models were used for the analysis. In total 806 of 910 (about 89%) top-ranked DEGs deviated from the host genes of the target DSMs for more than 1,000 genes. Only two (0.2%) top-ranked DEGs were within two order distance distances with the host genes of the target DSMs. This means that the most important contribution towards differential methylation came from the differential expressions of remote genes. All skewness tests were significant based on the chi-square test p values.

Figure 4.37 shows the densities of the base pair distances between the methylation sites of the target DSMs and the bases of the top-ranked influencing DEGs in four E2M models.
