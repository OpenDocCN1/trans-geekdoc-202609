## 1.5 The whole-genome pattern discovery process

The DNA sequencing technology has been improved continuously for several decades. Because of this, the high-throughput sequencing data have played an outstanding role in modern biology research nowadays. The modern DNA sequencing technology or the next-generation sequencing technology (NGS) can generate sequencing count data for a genome in less than an hour’s time. It has changed, shaped and transformed the modern biology/medicine research thoroughly [Hood and Rowen, 2013]. Among them, the most exciting project is the human genome project, which has made a huge impact on genome genome [Dulbecco, 1984; Collins and Galas, 1993; Collins and McKusick, 2001; Vincent, et al., 2017; Dunn, et al., 2018].

There are many subjects for the whole-genome pattern discovery based on NGS count data. Among them two are more relevant to the machine learning concepts. The first one is how to analyse whole genome sequences for knowledge discovery, i.e., the research of the sequence homology alignment approaches. It has had at least five decades since the first sequence homology alignment algorithm was developed [Needleman and Wunsch, 1970]. Besides, the currently widely used one named as BLAST has been developed for three decades [Altschul, et al., 1990].

Most earlier alignment algorithms align sequences pairwise and mostly globally. Along with the huge increase of sequencing data using NGS, the speed of sequence comparison is hugely challenged especially when comparing a novel sequence against a database of hundreds or thousands of known sequences. BLAST is such an algorithm. However, no matter how fast a homology algorithm is, the speed is still the bottleneck to the requirement of the fast sequence comparison. Therefore, some more advanced sequence comparison algorithms were developed more than a decade ago, i.e., comparing sequences based on the sequence statistics such as the word library or the k-mer library (Gao and Qi, 2007; Sims, et al., 2009; Wang, et al., 2009; Sims, and Kim, 2011; Kolekar, et al., 2012; Hatje and Kollmar, 2012; Leimeister, et al., 2014). This type of algorithms is named as the alignment-free sequence comparison approaches and has played a very important role in many modern whole-genome pattern discovery projects.

In addition, the quantum computing technique has also been considered for sequence homology alignment [Huo, et al., 2008; Prousalis and Konofao, 2019] and whole-genome *de novo* sequence assembly [Sohn and Nam, 2018].

## 1.6 The global optimisation pattern discovery problem

Many machine learning algorithms are originally based on the Newton’s method which is also called the greatest descent method or the greedy search method. To estimate model parameters for a machine learning model, a numerical objective function, which is differentiable, needs to be established at first. The basic principle is to find a saddle point on the objective function curve. At the saddle point, the objection function is minimise. The most useful method of detecting a saddle point within an objective curve is based on the derivative function of the objective function. This is why an objective function must be differentiable. A saddle point is always residing at the point in which the first derivative function is zero and the objective function value at a saddle point is minimised.

To search for a saddle point within an objective function curve to estimate the parameters for a complicated model is called the Newton’s method [Fletcher, 1987; Nocedal and Wright, 1999]. With this method, no matter where the initial point is, the method will lead the move to a saddle point of the objective function curve quickly and efficiently. The parameters of a model which have been mapped to a saddle point are called optimised parameters. But, this is true only if an objective function curve has a unique saddle point.

If an objective function curve is complex with more than one saddle point, the problem becomes complex. This is because it is impossible to guarantee that all the saddle points have the same minimum objective value. In addition, the Newton's method can only guarantee an optimisation process to reach one saddle point based on one initial point on an objective function curve. Therefore, one initial point leads to one multiple saddle points using the Newton's method. Whenever one saddle point has been reached, the Newton's optimisation process will never be able to move out from the saddle point even if this saddle point does not correspond to the minimum objective function value.

Therefore, the evolutionary computation techniques or algorithms have been considered for the optimisation problems where a problem requires a complex objective function with multiple saddle points [Fogel, et al., 1966; Holland, 1975; Goldberg, 1989]. The basic principle of the evolutionary computation approaches is to start from multiple initial points in an objective function curve. Multiple models are constructed simultaneously using the Newton's method or similar greatest descent methods from these multiple initial points. In an evolutionary computation model, a pool of candidates (or candidate solutions) is designed. Only those candidates with the best fitness measurements have the right to maintain the pool and have the right to breed new offspring, which are used to replace those who fail the designed criterion. Through this kind of evolution process, an optimal candidate or solution to a system can be discovered finally. The evolutionary computation approaches have been widely used in many biological/medical research projects with success [Fogel, 2008; Francois and Siggia, 2008; Rostain, et al., 2015; An, et al., 2020; Ereemev and Spirov, 2021].

## 1.7 The chapters

This book is composed of nine chapters. From Chapter 2 to Chapter 8, each chapter is designed to introduce a specific biological pattern discovery problem. The machine learning algorithms which can be used to discover the pattern will be introduced as well.

Chapter 2 will focus on one responsive gene discovery problem. In modern days, the essential gene discovery is mainly based on the-throughput sequencing technology. Based on this technology, millions of mutants can be generated in one experiment. Genes essentiality is analysed based on estimating a density function for a transposon statistic such as the insertions per gene statistic or the transposon insertion sites per gene statistic. This is a typical unsupervised learning problem. Therefore, various density estimation algorithms and cluster analysis algorithms will be introduced in this chapter. For the gene discovery will be demonstrated.

Chapter 3 will focus on the peptide pattern discovery problem. This problem is a type of applications where protein functional sites are discovered using local protein structures, i.e., protein peptides. The research projects of this problem mainly include the discovery of cleavage sites or post-translational modifications in peptides. Protein functional site discovery employs two sets of peptides, i.e., having no functional sites and those having functional sites verified in laboratories. The latter refers to the protease cleaved peptides ortranslational modified peptides. This type of applications fits the mainstream in machine learning, i.e., classification analysis or discriminant analysis. This chapter will introduce various classification analysis algorithms and demonstrate how these algorithms can be used for peptide pattern discovery. A typical problem of the protein functional site discovery is the data type. A protein sequence is a string of amino acids, which are non-numerical. Therefore this chapter will introduce different encoding approaches for handling amino acids in peptides so that a machine learning algorithm, which needs numerical data as the input, can be used.
