## 4.3.5 R function for ordinary linear regression analysis

To construct an OLR model for a data set, three R functions are needed. They are lm, summary and predict. The R function for constructing an OLR model is lm, which is formatted as below, where x is an independent variable and y is a dependent variable,

```
model=lm(y~x, ...)
```

To show how this function works, the olive oil content data [Baraz et al., 2017] was used for the demonstration at first. The data production quality from different olive trees in the southeast Mediterranean area. The data was composed of five independent variables. For a simple illustration, only one of them was used for an easy explanation of how a linear regression model works. The variable used here was the stone weight. Therefore, this was a univariate linear regression analysis problem. A lm object is composed of multiple statistics. One of them is called fitted.values which corresponds to Ŷ. Figure 4.11 compares the observations (the olive oil content — the dots) and model outputs (Ŷ shown as in the solid line). This plot shows that two variables had a positive correlation. In other words, the olive oil content increased when the paste water content increased.

![](img/c3caa39b5c0f40fb2a44f2ab6e940f78_190_0.png)

Fig. 4.11. The visualisation of fitted.values between the olive oil content and stone weight of the olive oil content data. The dots are the raw data and the solid line represents the estimated regression function.

The lm function also records the prediction errors which were saved in a variable called residuals of the lm object. Figure 4.12(a) shows the prediction error distribution and Figure 4.12(b) shows the QQ-plot for the standardised residues (errors). Both the histogram and the QQ-plot demonstrate that the residues follow a Gaussian distribution. The standardised errors are defined as below,

> $$\varepsilon - \mu_{\varepsilon} / \sigma_{\varepsilon}$$ (4.22)

In addition to a regression model which only employs one independent variable, many biological applications require more than one independent variable. In this case, a univariate regression analysis is extended to a multivariate regression analysis model. A multivariate regression analysis model is defined below,

$y = \beta_0 + \beta_1 \times x_1 + \beta_2 \times x_2 + \varepsilon$ (4.24)
