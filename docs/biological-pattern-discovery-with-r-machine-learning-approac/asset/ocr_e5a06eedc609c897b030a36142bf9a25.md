If a system is composed of both unary operators and binary operators, a mutation operation must be careful. A unary operator can only be mutated to another unary operator and a binary operator can be mutated to another binary operator. For instance, the RPN string for the equation xy + \sqrtz is xy*z# suppose the # key is used to represent a square root operation. By a mistake, a unary operator is mutated to a binary operator or a binary operator is mutated to a unary operator, the resulting tree means nothing. Figure 8.12 shows such a mistake. Certainly, the equation expressed in Figure 8.12(b) will not be working.

# 8.3.2.4 The dual-chromosome crossover

The second one to be considered is the crossover operator. In GP, the crossover operation can be done in two ways. One is the single-chromosome crossover (or the self-crossover) and the other is the dual-chromosome crossover operation employs two elite RPN chromosomes to generate two new RPN chromosomes. The operation randomly selects subunits from two elite RPN chromosomes. Afterwards, the operation exchanges subunits across two elite RPN chromosomes to breed new chromosomes.
