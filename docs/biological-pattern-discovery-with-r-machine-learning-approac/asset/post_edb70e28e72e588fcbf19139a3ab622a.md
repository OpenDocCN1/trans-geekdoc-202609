## Spectral Pattern Discovery

Analysing a spectrum to discover chemicals and molecules has been one of the important subjects in biochemistry research. However, spectrometric data is complex because it is often a mixture between a number of signals and a complicated background. The latter is also called a baseline. The signals mixed with the background of a spectrum can be well discovered only after the background of a spectrum has been accurately identified. Background estimation or baseline removal is thus the very first step to go in the area of spectra pattern discovery. The difficulty, however, is that a baseline of a spectrum is hardly an easily estimated linear function (a straight curve) or a simple function. Instead, it is commonly a complex, unknown and a non-analytic function. Many algorithms have therefore been developed for estimating the baseline of a spectrum in the hope to extract peaks and thus discover the signals as accurately and correctly as possible. Only when a baseline has been accurately estimated and removed, the number of the falsely signals can be minimised and the number of the true signals can be maximised. Among many algorithms, the Whittaker-Henderson smoother is one of the best for spectra pattern discovery. This chapter will introduce this algorithm and its variants as well as other algorithms which are used for spectra pattern discovery. How these algorithms can be applied to some real spectrometric data for spectra pattern discovery will be introduced in this chapter.

In most situations, the function of a baseline is unknown and will not be in an analytic format. Importantly, the background structure or the baseline (curve) varies with the spectrum across experiments and samples. This therefore leads to the difficulty in analysing the spectrometric data for detecting chemicals or molecules from a spectrum. This difficulty has resulted the development of various algorithms for baseline estimation.

There are mainly three types of baseline estimation algorithms. The first type is to fit a smoothing spline to a spectrum (Hastie and Tibshirani, 1990). The fitting is based on a pre-defined model structure, i.e., the smoothing order or the smoothing degree. These algorithms have a typical advantage of simplicity and therefore have been widely used in a variety of applications for discovering chemicals or molecules from spectra data including the Raman spectrum [Shusterman, et al., 2000; Fonseca, et al., 2015; Schulz, et al., 2019; Monteiro, et al., 2020]. However, these algorithms have a typical limitation because a model structure must be defined and the baseline removal performance is closely related with a priori design of a smoothing degree [Froning, et al., 1988]. These algorithms also have a problem to effectively deal with some complicated baseline structures [Perperglou, et al., 2019].

The second type of baseline estimation algorithms is to use the wavelet smoothing technique, or the wavelet decomposition and integration approach [Price, et al., 2008; Restrepo-Agudelo, et al., 2017]. The approach assumes that a spectrum has a typical property that a high wave intensity corresponds to a chemical peak (or a signal) and a low wave intensity represents a baseline value. Therefore two types of spectroscopic patterns can be separated by decomposing two types of wave intensities. The wavelet approach has also been applied to the Raman spectrometric data [Hwang, et al., 2005; Alimov, et al., 2019]. However, this approach suffers a problem that an optimised threshold should be carefully determined between the low and high wave intensities [Hu, et al., 2007].

The third type of algorithms for baseline estimation is the least squared error approach (LSE). LSE has been the most and widely adopted one for the estimation of a baseline in a spectrum. This is mainly because of its flexibility though it also has a problem of model selection or optimisation. Both the classical and the LSE variants have been used to detect chemicals from the Raman spectroscopic data [Vyumvuhore, et al., 2014; Acikgoz, et al., 2018]. The Whittaker-Henderson algorithm is a typical regularised LSE variant for the baseline estimation [Whittaker, 1923; Henderson, 1924; Taylor, 1992].

## 5.3 The Whittaker-Henderson algorithm

The Whittaker-Henderson algorithm (WH) is a special case of the ridge linear regression algorithm (RLR). The main concept and implementation of RLR has been introduced in the last chapter. The error term used in RLR is named as fidelity in WH. Suppose a spectrum is expressed as a vector of $n$ entries, $\mathbf{s} = (s_1, s_2, \dots, s_n)$. Each entry of this vector is called wave intensity or simply intensity. As aforementioned, such intensity may not represent a real signal or peak of a chemical. It is instead a mixture between baseline intensity and signal intensity, i.e., $s_i = b_i + e_i$, where $b_i$ stands for the baseline intensity contained in the $i^{th}$ intensity and $e_i$ stands for the distance between the $i^{th}$ signal intensity $s_i$ and the $i^{th}$ baseline intensity $b_i$. Such a distance is also called error. The vector-expression of this relationship is $\mathbf{s} = \mathbf{b} + \mathbf{e}$, where values are expressed by vectors. Both $\mathbf{b}$ and $\mathbf{e}$ are unknown. In addition to the fidelity definition, $d_i = b_i - b_{i-1}$. A vector $\mathbf{d}$ is used to represent all the smoothness values. WH employed an objective function by introducing a regularisation constant $\lambda$ to make a balance between the fidelity (regression error) and the smoothness. The WH objective function is defined as below,

$O = \mathbf{e}^T\mathbf{e} + \lambda\mathbf{d}^T\mathbf{d} \quad (5.1)$

The LSE optimisation of this objective function leads to the solution of unknown baseline below,

$\mathbf{b} = (\mathbf{I} + \lambda\mathbf{d}\mathbf{d}^T)^{-1}\mathbf{s} \quad (5.2)$

Figure 5.1 shows an example based on a simulated spectrum, where the baseline ($\mathbf{b}$) is expressed by a solid line and the spectrum ($\mathbf{s}$) is expressed by a dotted line. It can be seen that if the baseline has well-estimated and the estimated baseline has been removed, peaks can be correctly extracted. The extraction is implemented using $p = s - b$ for $s_i \gg b_i$.

Figure 5.1 only shows a case where a spectrum is not contaminated by noise. A real spectrum is often contaminated by noise. For instance, Figure 5.2 shows an example of MALDI-TOF MS spectrum [Liland, et al., 2009; Liland et al., 2010]. It can be seen that there are many artifacts (noise) in addition to the signals along the baseline. Therefore, statistical methods must be used to deal with such a noisy spectrum for an efficient and effective signal detection process.

It must be noted that the signal intensities (s–b) should not be negative and they must be above a baseline, i.e., a signal $s_i - b_i$ is detected if $s_i \gg b_i$. Therefore, some updates have been used to correct the original Whittaker-Henderson algorithm. In these updates, the fidelity has been revised using the following method, which employs a decaying function $f(s_i, b_i)$ [Mazel, et al., 2005; Cobas, et al., 2006; Zhang, et al., 2010].

$e_i = \begin{cases} 0 & s_i > b_i \\ f(s_i, b_i) & \text{otherwise} \end{cases} \quad (5.3)$

In this scenario, only the negative errors are treated as noise while the positive errors are ignored when estimating the baseline for a spectrum using this type of approaches. After a baseline has been estimated and removed from a spectrum, the artifacts may be present. The artifacts presented in a baseline-removed spectrum are potential noise. They must be carefully dealt with in order to avoid them to be mistakenly treated as signals. A smoothing process is commonly used to combat the artifacts for the purpose of discovering the signals as accurately as possible from a baseline-removed peak spectrum.

When detecting signals from a spectrum through estimating a baseline which is contaminated by noise, a problem arises. If a model is too restrictive, some true signals may be treated as noise. Otherwise, there is a problem of how to trade-off between the true signal discovery rate and the false signal discovery rate. The optimal strategy is, of course, to maximise the true signal discovery rate and at the same time to minimise the false signal discovery rate.

WH is a version of a regularised regression model. In a WH model, the regularisation constant plays an important role to trade-off between the true signal discovery rate and the false signal discovery rate. As shown in the Equation (5.1), when the regularisation constant $\lambda$ is too small, an estimated baseline will not be sufficiently smooth. For instance, if $\lambda = 0, O = e^f$. In this case, no smoothness is considered. An estimated baseline will curve to fit to every detail signal intensities. The consequence is $s - b \to 0$, i.e., almost no signals at all. If $\lambda = \infty, O = d^f d$. In this case, an estimated baseline will be a straight line. The consequence is that many true signals may be missed while many false signals appear.
