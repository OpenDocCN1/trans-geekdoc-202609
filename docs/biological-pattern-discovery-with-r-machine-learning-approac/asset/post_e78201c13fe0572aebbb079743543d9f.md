It can be seen that there will be many possible alignments for any two sequences. Each of these alignments will have a different alignment pattern as well as an alignment statistic such as the number of matches as well as the number of mismatches plus the number of inserted gaps. Suppose the number of matches and the number of mismatches as well as the number of inserted gaps are incorporated into a unique alignment statistic. Among all possible alignments, if they can be exhausted, there must be one (or more than one) homology alignment which has the optimised alignment statistic. Therefore, a homology alignment process is an optimisation process. It is a process of discovering the best homology alignment with an optimised alignment statistic.

No doubt, an exhaustive search is impossible if sequences are significantly long. Therefore the best approach is to employ a heuristic optimisation process. One of the best approaches for this kind of optimisation process is the dynamic programming algorithm [Kirk, 1970; Alser, et al., 2019; Chen, et al., 2019]. The dynamic programming algorithm is well-designed for most combination optimisation programming.

A combination optimisation problem is such a process in which an optimised combination is searched based on the limited number of components. A decision is made on a course to discover the best or the optimal solution among many sequential combinations of the components.

In addition, all combinatory processes can be optimised by the use of dynamic programming if the whole optimisation can be linearly decomposed. Therefore, if an optimisation can be decomposed into piece-wise optimisation problems, an optimisation is then an incremental process. This means that the current sub-optimisation is independent from the previous sub-optimisations.

The sequence homology alignment problem is such an optimisation because the whole homology alignment can be decomposed. The main reason for this decomposition is that all metrics used in sequence homology are linear. Suppose the alignment length of a pair of sequences is $N$ and the score of each aligned pair is denoted by $s_n$. The linearity property of homology between two sequences is shown below,

```
$S = \sum_{n=1}^N s_n$ (7.1)
```

This linearity property shows that it is possible to decompose this homology alignment for any $1 < m < k < N$ as shown below, where $S_m$ and $s_k$ are alignment scores for two segments, one of which has $m$ pairs and the other has $k$ pairs,

```
$S = \sum_{n=1}^m s_n + s_k$ (7.2)
```

The above equation is very important as it shows that the calculation of $s_k$ is independent of the calculation of $S_m$ or the optimisation is independent from the previous. Therefore, a homology alignment has been optimised in a sequence process. The previous homology alignment only affects the whole alignment score.

## 7.2.1 Issues of sequence alignment

Before introducing sequence alignment algorithms, it is better to understand key issues which play key roles in designing sequence alignment algorithms.

### 7.2.1.1 The three evolution events

The first issue of sequence alignment is that an organism can evolve, making its primary sequence structure changed. There are three evolution events which may happen through an evolution process. They are the residue substitution, which is also called mutation, the insertion and the deletion of a residue or segment within a sequence [Tseng, et al., 2006; Rivas, et al., 2008]. The latter two are also called indel. A residue substitution means the replacement of a residue, i.e., an existing nucleic acid or amino acid has been replaced by a new nucleic acid or amino acid in evolution. For instance, the second residue of LGPSSQT has been mutated from G to S in an evolution leading to a new sequence LGPSSQT.

The indel stands for two scenarios. First, residue(s) is introduced into a sequence through an evolution process. This is called insertion. Second, residue(s) is missing through an evolution process. This is called deletion. Suppose an original sequence is LGPSSQT. A new residue C is introduced between S and K through an evolution process. One of the alignments between these sequences is shown below, where a gap denoted by a hyphen is inserted in the ancestor sequence for it to be aligned with its descendant sequence.

```
LGPSS-KQT
||| |||
LGPSSQT
```

Suppose a deletion happens to the ancestor sequence LGPSSQT during evolution and this has caused two consecutive residues (the fifth and the sixth, S and K) from the ancestor sequence. One of the alignments for them is shown below, where two hyphens are inserted in the descendant sequence to denote two deletions (lost residues) which have happened to its ancestor sequence in evolution.

```
LGPSSKQT
| | | |
LGPS--QT
```

### 7.2.1.2 The alignment gap

The second issue of sequence alignment is the alignment gap. An alignment algorithm has to satisfy the following requirements: Aligning two sequences without inserting a gap may not work properly, especially when an indel event has happened. This is because two sequences definitely have different lengths when an indel event has happened. For instance, the evolution of the ancestor sequence LGPSSQT to the descendant sequence LGPSQT has resulted in sequences with different lengths. Without introducing gaps, aligning these two sequences will not generate a meaningful alignment. Of course, aligning two sequences with too many gaps is also unacceptable. Therefore, an alignment should maximise the number of the aligned pairs and minimise the number of the inserted gaps. A gap penalty, which can quantify the impact of gap insertion on an alignment performance, is therefore introduced for this purpose in almost every alignment algorithm.
