# Biological Pattern Discovery with R

The regression analysis aimed to find the relationship between the time lag variable and 64-3mers for each country and to examine whether this relationship is significant. Moreover, whether some 3-mers were significantly correlated with the lag variable was examined as well. For each Lasso regression model, the fitness was measured using the R-square measurement. Figure 7.23(a) shows the Lasso regression model for the USA sequences. In this Lasso model, top five 3-mers were ATT, TAT, TCA, TTC and TAC. The R-square is 0.2345. Figure 7.23(b) shows the Lasso regression model for the India sequences. The R-square for this model was 0.3209 and top five 3-mers were CAA, TTA, TTG, and AAC.
