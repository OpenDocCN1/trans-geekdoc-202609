# Biological Pattern Discovery with R

This book was written based on the author’s research in collaboration with his colleagues, and the objective of this book is to provide some bases for researchers who enter this area. The book was especially written with the aim to give readers the opportunity to transfer their machine learning theories to practical problems. From this, they can be motivated to develop new methodologies, new ideas and new algorithms for biological pattern discovery. Therefore, the R programming environment was used throughout this book. Moreover, this book was written on individual subjects of biological pattern discovery. The main subjects include gene expression data analysis for both microarray and sequencing count data, genomic sequencing comparison, peptide data analysis, spectra data analysis for molecule discovery, as well as pattern optimisation involving the evolutionary computation approaches. The selection of the subjects in this book was based on individual machine learning approaches. Therefore, each chapter of this book can be independently read and referred to. The reader can start via any chapter according to his/her requirements.
