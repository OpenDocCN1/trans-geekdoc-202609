The ROC package also provides a function for extracting the optimal threshold through the cost analysis. The optimal threshold for the minimum cost can also be extracted. Figure 3.17(b) shows the curves associated with the threshold variation for two models. The optimal threshold for minimising the cost can be extracted and they were 0.757 for the cross-validation model and 0.563 for the Jackknife model. All deviated from 0.5. This indicated optimal discrimination threshold was not necessary at 0.5 all the time. In other words, the optimal threshold may vary from 0.5 depending on a specific data set and a different generalisation test approach for a data set.

There are other useful packages for the ROC analysis. The pROC package can be used for the ROC analysis with a confidence interval [Robin, et al., 2011]. The package employs the bootstrap approach [Efron, 1979; Breiman, 1996] to estimate the confidence bands on an ROC curve and can also be used for the partial ROC analysis. The pROC package does not use the false alarm rate as the horizontal axis. Instead, it uses the specificity as the horizontal axis. This is why its horizontal axis ranges from one to zero.
