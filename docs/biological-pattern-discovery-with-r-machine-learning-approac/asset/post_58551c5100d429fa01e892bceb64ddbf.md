### 2.4.1 The data

The transposon sequencing technology can insert a transposon into a genome millions of times, generating millions of mutants. A mutant represents an insertion site in a gene because such an insertion site may disrupt the function of the gene. If the function of a gene is not disrupted by a transposon and a species still survives, the function of the gene is thus the target of research.

A transposon sequencing data set has two types of transposon statistics. They are the insertion statistic and the site statistic. The former stands for the number of transposon insertions per gene and the latter stands for the number of transposon insertion sites per gene.
