Table 6.8 shows the error statistics (Type II error) of all tests for the down-regulated DEGs and the up-regulated DEGs. Except for the MOST and the LSOSS models, others had small errors for the up-regulated DEGs. This was not a surprise for the COPA, OS and ORT models. These algorithms were developed based on the similar working principle, i.e., assuming the outliers were present in the case replicates only. The MOST and LSOSS showed unreasonable results because many outliers were also mis-classified. In terms of the down-regulated DEGs, it was not a surprise when the COPA, OS and ORT returned the bad performance. As aforementioned, these algorithms only targeted the up-regulated DEGs with high extreme outliers. Surprisingly, the MOST and LSOSS models did not work well for the down-regulated DEGs. The DOG model also worked well for the down-regulated DEGs. This is because the DOG algorithm targeted both the up-regulated and the down-regulated DEGs when outliers are present.

## 6.4 Discover heterogeneous DEGs for a cancer data

The seven tests were used to discover heterogeneous DEGs for the breast cancer diagnosis data (GDS139) [Tripathi et al., 2008]. For all tests, the critical p value for this data set was 0.01. Figure 6.22 shows the distributions of p values of the COPA, OS, ORT, MOST, LSOSS and DOG models constructed for this data set. The distributions of p values from the OS, MOST and LSOSS models were questionable. As indicated earlier, the density of p values should be a mixture of uniform distribution for the non-DEGs and a Gamma distribution for the DEGs [Tusher et al., 2001; Store and Tibshirani, 2003]. Based on this theory, only the p value distribution of the DOG model was reasonable.

Figure 6.23(a) shows the correlation analysis of the negative base logarithm of the p values of the models using the seven tests for the data set. It can be seen that the DOG model was highly correlated with the t test, the OS model was highly correlated with the ORT model and the COPA model was highly correlated with the ORT model. Figure 6.23(b) shows a Venn diagram analysis of the detected DEGs for the breast data set by the DOG, COPA, OS and ORT models. It shows a similar pattern found in the correlation plot that the COPA model was more similar to the ORT model and the OS model was more similar to the ORT model.

The gene was also predicted as a DEG by the ORT model and the MOST model, but not the t test and the LSOSS model as well. The gene expression profile shows a mixed distribution of the normal and the cancer replicates. Eight replicates of both the normal and the cancer replicates were treated as the outliers and were removed, the remaining two groups of replicates, which formed a tight cluster, did not show a significant difference.

Therefore the DOG p value for this data set with the outliers removed was 0.169. The inset boxplot of the figure shows the expression distribution of two groups of replicates within the tight cluster, i.e., with the outliers removed. It can be seen that two populations were heavily overlapped. Due to this, this gene with the outliers removed could be treated as a DEG.
