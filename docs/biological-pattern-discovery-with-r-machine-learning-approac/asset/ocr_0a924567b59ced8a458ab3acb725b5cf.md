Two types of outliers were analysed for this data set. An outlier at the bottom of an expression profile of a gene was named as a low extreme outlier. An outlier at the top of an expression profile of a gene was named as a high extreme outlier.

Figure 6.13 shows that the 221505_at in GDS3139 was classified as a Type I error. It was a non-DEC because of the cancer replicates was a low extreme outlier. This outlier pulled down the mean expression of the cancer replicates so to cause the potential misclassification of a non-DEC to a type I error. The raw p value was 0.0093 and the new p value was 0.0185 after an outlier was removed. If the critical p value was 0.01, it can be seen that the differential expression pattern turned around because of this low extreme outlier, i.e., it was discovered as a DEG when the outlier was not removed, but discovered as a non-DEG when the outlier was removed. A thorough investigation was done for all genes in this data set to examine the heterogeneous differential expression problem. It was assumed that a gene had only a single outlier. The investigation had 33 genes, which were likely the false DEGs (the Type I errors) in this data set (GDS3139).
