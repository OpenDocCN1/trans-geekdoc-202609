# 9.4 Next-generation sequencing data quality

The next-generation sequencing technology has been very widely used in biological/medical researches. For instance, it has been incorporated with the transposon technology to generate a new method for the mutation pattern analysis. The new method is called the transposon sequencing technology. Using this technology, millions of mutants can be identified in a single experiment. Based on the gene-wise transposon statistics, essential genes can be identified using the density pattern analysis approaches as discussed in Chapter 2 of this book. However, most existing approaches for identifying essential genes are based on replicated-free data. The assumption is that a single transposon sequencing data is noise-free or the noise level can be well controlled. However, it has been recognised that transposon insertions are random events [Golden, et al., 2000; Aboklash, et al., 2014; Baym, et al., 2016]. In other words, in replicated transposon sequencing data, it is very unlikely that there will be identical patterns of transposon insertion distributions across replicates. An insertion site in one replicate may not be present in others in the same experiment. Even when it is presented across replicates, it is less likely for it to be inserted at the exact identical base pair across replicates. It has been assumed that a well-designed study will ensure that all transposon insertion sites are covered in replicated data. In other words, it assumes that the replicate number is the minimum set to cover all transposon insertion sites. In addition, the insertion frequency is a random event and will differ between replicates at each insertion site. It is therefore a reasonable assumption that unobserved but true transposon insertion frequency can be discovered if replicated data are used. Based on this assumption, a novel and more efficient approach may need to be considered for dealing with sequencing noise for a better gene identification. This kind of thinking can also be used for other areas dealing with the sequencing data such as sequencing assembling, where it has also been exercised for replicate-free data.
