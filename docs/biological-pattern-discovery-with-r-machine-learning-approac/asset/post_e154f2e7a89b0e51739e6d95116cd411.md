
To construct a histogram for density analysis for a data set x, the following procedure is used,

- Prepare a data set x = $(x_1, x_2, \dots, x_N)$.
- Design bins B = $(B_1, B_2, \dots, B_M)$ such as the eight bins $(M = 8)$ shown in the top-right panel of Figure 2.2.
- Throw each data point $x_n$ into a bin $B_m$ if $x_n$ is within the boundaries of $B_m$.
- Count the data points $(x_n)$ falling in each bin $B_m$, as such, 1,277 insertions in the first bin in Figure 2.2.
- Denote the data point count of each bin $f_m$ (frequency) as shown in the bottom-left panel of Figure 2.2.
- Convert each frequency $(f_m)$ to a probability $(p_m)$ as shown in the bottom-right panel of Figure 2.2.
- Use either $f_m$ or $p_m$ to interpret the estimated density.

The formula for converting a histogram to a probabilistic histogram is defined as below,

> $$p_m = \sum_{k=1}^{n} \frac{f_m}{f_k} \quad (2.1)$$

Two histogram statistics have different meanings. $f_m$ stands for the real count of the $m^{th}$ bin while $p_m$ stands for the probability for data to occur in the $m^{th}$ bin. The former can be used for interpreting or explaining how data are distributed. The latter can be used for making an inference for novel data. In other words, the probability of a bin can indicate how likely a novel data point occurs in the bin. For instance, the probability that a novel transposition insertion statistic fails into the first bin and the seventh bin is 8% and 19%, respectively for the gene shown in the bottom-right panel of Figure 2.2.

The R function for the histogram algorithm is hist. Given a vector x, the syntax of the `hist` function is shown below, where `nclass` is the parameter for designing the bin number,

```
hist(x, nclass, ...)
```

## 2.2.2 The parametric approach

The parametric approach estimates a density function based on the assumption that a data set follows a pre-specified single parametric distribution such as a Gaussian distribution or a Gamma distribution [Silverman, 1986; Duda, et al., 2000]. Based on this assumption, the density parameters are estimated using either the likelihood maximisation method or the Bayesian learning method. For instance, if N data points x = $(x_1, x_2, ..., x_N)$ are expected to follow a Gaussian distribution, the likelihood maximisation approach can estimate the model parameters (or the distributional statistics) using the following equations,

```
$$\hat{\mu} = E(x) = \frac{1}{N} \sum_{n=1}^{N} x_n$$
$$\hat{\sigma}^2 = \text{var}(x) = \frac{1}{N-1} \sum_{n=1}^{N} (x_n - \mu)^2 \quad (2.3)$$
```

Based on these Gaussian distributional statistics, an estimated Gaussian density function is defined as below,

```
$f(x) = \mathcal{G}(x|\hat{\mu} \hat{\sigma}^2) = \frac{1}{\sqrt{2\pi \times \hat{\sigma}^2}} e^{\frac{(x-\hat{\mu})^2}{\hat{\sigma}^2}} \quad (2.4)$$
```

For instance, if a vector $x = (1.3181, 0.1948, -0.1481, -3.2131, 0.0733, -0.6179, -0.7869, -0.4848, -0.3497)$ was expected to follow a Gaussian distribution, but the two distributional statistics ($\mu$ and $\hat{\sigma}^2$) were unknown, the above equations can be used to estimate these statistics. After calculation, the estimated population mean $\hat{\mu}$ was $-0.13$ and the estimated population variance $\hat{\sigma}^2$ was $1.79$ for the data set $x$.

```
dnorm(x, mean=0, sd=1)
```

A Gaussian distribution for a data set can be generated based on the estimated population mean and the estimated population variance, i.e., $\hat{\mu}$ and $\hat{\sigma}^2$. Here, the breast cancer diagnosis set [Wolberg, et al., 1994; Wolberg, et al., 1995] was used for this demonstration. The data set was composed of 30 mammographic features for breast cancer diagnosis. The feature named as radius (tumour radius) was used for this demonstration. The benign tumours were separated from the malignant tumours at first.
