# Protease Cleavage Pattern Discovery

The dot product kernel is very useful for discrete data, especially binary data. Figure 3.33(a) shows the ROC curve of a SVM model with the dot kernel function constructed for the factor Xa protease cleavage data [Yang, et al., 2006], where the peptides were encoded using the binary encoding approach. Figure 3.33(b) and Figure 3.33(c) show the ROC curves of two SVM models of the sigmoid and polynomial kernels constructed for the binary-encoded factor Xa data. They show similar performance, but the SVM model using the polynomial kernel seems the best.

Rather than using the binary encoding approach for the amino acids, a mutation matrix can be used for transforming an amino acid space to a kernel space. Having understood the powerfulness of the support vector machine, the bio-basis function was used as a kernel function for the support vector machine, which was named as the bio-support vector machine (bio-SVM) [Yang and Chou, 2004b]. Figure 3.34 shows the ROC curve of the bio-SVM model constructed for the factor Xa protease cleavage data, in which the Dayhoff mutation matrix [Dayhoff and Schwartz, 1978] was used to generate the bio-support vectors.
