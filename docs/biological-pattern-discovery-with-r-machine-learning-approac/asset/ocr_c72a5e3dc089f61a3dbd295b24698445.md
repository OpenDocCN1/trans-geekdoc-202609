If an objective function curve is complex with more than one saddle point, the problem becomes complex. This is because it is impossible to guarantee that all the saddle points have the same minimum objective value. In addition, the Newton's method can only guarantee an optimisation process to reach one saddle point based on one initial point on an objective function curve. Therefore, one initial point leads to one multiple saddle points using the Newton's method. Whenever one saddle point has been reached, the Newton's optimisation process will never be able to move out from the saddle point even if this saddle point does not correspond to the minimum objective function value.

Therefore, the evolutionary computation techniques or algorithms have been considered for the optimisation problems where a problem requires a complex objective function with multiple saddle points [Fogel, et al., 1966; Holland, 1975; Goldberg, 1989]. The basic principle of the evolutionary computation approaches is to start from multiple initial points in an objective function curve. Multiple models are constructed simultaneously using the Newton's method or similar greatest descent methods from these multiple initial points. In an evolutionary computation model, a pool of candidates (or candidate solutions) is designed. Only those candidates with the best fitness measurements have the right to maintain the pool and have the right to breed new offspring, which are used to replace those who fail the designed criterion. Through this kind of evolution process, an optimal candidate or solution to a system can be discovered finally. The evolutionary computation approaches have been widely used in many biological/medical research projects with success [Fogel, 2008; Francois and Siggia, 2008; Rostain, et al., 2015; An, et al., 2020; Ereemev and Spirov, 2021].
