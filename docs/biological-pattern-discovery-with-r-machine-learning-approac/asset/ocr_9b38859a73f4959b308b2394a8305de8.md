# 3.3 The other analytic discriminant analysis algorithms

A LDA model is an analytic linear model because the relationships between the dependent variables and the independent variables are quantitatively parametrised. From such a model, it is very easy to determine how an independent variable correlates with the dependent variable. When the format is slightly changed, the other discriminant analysis algorithms have been developed. However, the straightforward proportional relationship between the dependent variable and independent variables is no longer valid. Instead, the relationship between the dependent variable and the independent variables becomes nonlinearly analytic.

# 3.3.1 The quadratic discriminant analysis algorithm

It has been discussed above that two classes are an identical covariance matrix in LDA, i.e., $\Sigma_1 = \Sigma_2 = \Sigma$. This is only valid when the difference between two covariance matrices $(\Sigma_1$ and $\Sigma_2)$ is insignificant. When this difference becomes significant, the use of an identical covariance matrix for two classes may no longer be a good approach. To deal with the difficulty of significantly different covariance matrices across two classes, the quadratic discriminant analysis algorithm (QDA) is an alternative [Tharat, 2016]. The algorithm is also called the generalised discriminant analysis algorithm (GDA)[Cover, 1965]. It extends LDA in the format shown below, where the matrix $W$ and the vector $\beta$ are model parameters

```
$y = \mathbf{x}^T W \mathbf{x} + \mathbf{\beta}^T \mathbf{x} + c$
```

In a QDA model, two covariance matrices are allowed to be different, i.e., $\Sigma_1 \neq \Sigma_2$. The R function for constructing a QDA model is qda. Because of the use of different covariance matrices for two classes, the discrimination boundary between two classes will not be a straight line again. Figure 3.6 shows a data set with two classes. The cross class has a larger variance than the triangle class.
