## 2.3.4 The mixture model cluster analysis algorithm

The mixture model algorithm is also a partitioning algorithm [Pearson, 1984; Day, 1969; McLachlan and Basford, 1988; Bishop, 2006]. Its basic principle is similar to the semi-parametric density estimation approach, i.e., it is a mixture of a few components such as the Gaussian components or the Gamma components. A final density is a linear combination of a finite number of components.

Suppose the $k^{th}$ cluster is centred at $\mathbf{u}_k$ with a covariance matrix $\Sigma_k$. The membership function is defined as a probability $p(\mathbf{x}_n|\mathbf{u}_k, \Sigma_k)$, while the objective function is defined as the likelihood function below, where $p(\mathbf{x}_n|\mathbf{u}_k) \in \mathcal{R}^d$ is a member of the $k^{th}$ cluster, $w_k \in [0,1]$ is the mixing coefficient of the $k^{th}$ cluster,

```
$0 = \prod_{n=1}^{N} \sum_{k=1}^{K} w_k p(\mathbf{x}_n|mathbf{u}_k, \Sigma_k) = \prod_{n=1}^{N} p(\mathbf{x}_n) \quad (2.26)$
```

The mixing coefficients must satisfy the conditions, i.e., $0 < w_k < 1$ and $\sum_{k=1}^{K} w_k = 1$. The most widely researched mixture model is the Gaussian mixture model. It requires to estimate $u_k, \Sigma_k$ and $w_k$. The probability function used in a Gaussian mixture model is defined as below,

```
$p(x_n|u_k, \Sigma_k) = \frac{1}{(2\pi)^{d/2}|\Sigma_k|}} exp\left(-\frac{(x_n-u_k)^T\Sigma_k^{-1}(x_n-u_k)}{2}\right) \quad (2.27)$
```

Because of the use of this membership function, especially the use of a covariance matrix, the cluster boundaries of a cluster model constructed by the mixture algorithm will be different from that constructed by the K-means algorithm and the fuzzy C-means algorithm. The clustering boundaries of a cluster model constructed by the mixture algorithm can be elliptic in addition to spheric. The latter is used in both the K-means algorithm and the fuzzy C-means algorithm.

It can be seen that the K-means model did not work well for this data set because it employs the spherical cluster boundaries. When this condition is violated such as the cluster structure shown in Figure 2.34, a cluster model may not be useful for interpretation. However, in the model constructed by the mixture algorithm, this phenomenon disappeared. The clustering boundaries of three clusters have been well recognised. This ensures the correct and accurate recognition of data points in different clusters and generate meaningful interpretations.

The most popularly used estimation approach for the mixture algorithm is the expectation-maximisation (EM) algorithm [Dempster, et al., 1977], which is a two-step iterative procedure (the E step and the M step) starting from parameter initialisation using random values. The probabilities are estimated in the E step using the information of current model parameters, i.e., the cluster centres, the cluster covariance matrices and the mixing coefficients. If model parameters have not yet been optimised, information of probabilities is used to update model parameters in the M step. In other words, new model parameters are calculated in the M step based on the current cluster membership function values, which are the probabilities.

The mixture algorithm has been widely employed for analysing biological/medical patterns. For instance, it has been used to improve the accuracy of the infection prediction when investigating the Bovine viral diarrhea infection among cattle herds [Eze, et al., 2019]. The study revealed some interpretable epidemiologically clusters. Another recent study has employed the Gaussian mixture model for breast cancer diagnosis based on mRNA expression data which contains over 300 clinical samples of breast cancer and healthy tissue [Prabakaran, et al., 2019]. The study has demonstrated a significant value of a Gaussian mixture model for clinical practice. The Gamma mixture model has also been employed in an image analysis for developing unbiased pre-processing system of biological images [Llera, et al., 2019] and in a HIV test data analysis project [Rice, et al., 2019].

## 2.3.5 The other clustering algorithms

There are other clustering algorithms which have been developed and applied to different areas. The K-medoids algorithm will estimate a medoid for each cluster of a cluster model [Kaufman and Rousseau, 1987]. Given N data points, D = (x₁, x₂, ..., xN), a medoid of a cluster is defined below,

```
$x_{medoid} = argmin_{y\in D} \sum_{i=1}^{N} d(y, x_i) (2.29)$
```

To measure the goodness of a cluster model, the mixture model algorithm employs the Bayesian Information Criterion (BIC) [Schwarz, 1978] to optimise a model structure. The BIC is defined below,

> $BIC = -\frac{N}{2} \log\left(\frac{RSS}{N}\right) + C \quad (2.28)$
