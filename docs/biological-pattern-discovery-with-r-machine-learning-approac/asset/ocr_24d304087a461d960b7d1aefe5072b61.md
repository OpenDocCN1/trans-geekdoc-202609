The genetic algorithms are normally used for solving a combinational optimisation, in which the candidates can take several limited number of status such as the binary status. The binary status includes the presence and the absence of an object or a variable. If the problem is sufficiently large, exhausting all possible combinations in an even modern computer may become infeasible. For instance, sequence homology alignment, which has been introduced in Chapter 7 of this book, is a combinational optimisation process. Fortunately, the genetic algorithms have been used to reach some optimal homology alignments between sequences [Chowdhury and Garai, 2017]. The genetic algorithms have also been used for the center trend prediction, which was organised as a binaryational optimisation problem [Kim, et al., 2021].

The genetic programming algorithms are normally used for modelling a complicated system, where a system can be expressed by a mathematical equation of variables and the variables can interplay in such a system [Koza, 1992; Suganuma, et al., 2020]. Given a data set, the genetic programming can be used to discover an optimal mathematical equation by which the data are assumed to be generated. Therefore, this kind of machine learning algorithms can be used to discover the intelligence hidden in data and express the discovered intelligence using human-readable rules, such as the equations.
