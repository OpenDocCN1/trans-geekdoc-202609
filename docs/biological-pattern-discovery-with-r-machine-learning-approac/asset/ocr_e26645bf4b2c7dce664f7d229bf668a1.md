# 7.2.4 The Smith-Waterman algorithm

The Sellers algorithm and the Needledman-Wunsch algorithm were designed for the global pair-wise homology alignment. Using these algorithms, every residue of two sequences is used in an alignment. The local homology alignment only focuses on the segments which are the most similar to each other. The Smith-Waterman alignment algorithm is such a typical algorithm [Smith and Waterman, 1981].

# 7.2.4.1 The alignment metric and moving directions

The algorithm uses a uniform positive score for an exact match, which is one, a negative score for a mismatch, which is -0.3 and a length-dependent gap penalty, which is defined below with L denoting the number of continuous gaps or the length of a gap inserted into a sequence,

$G_L = -1 - L/3$

The moving directions are used from the top-left corner cell to the bottom-right corner cell as shown in Figure 7.3, where $s_{ij}$ is the alignment score between the $i^{th}$ residue of sequence $x$ and the $j^{th}$ residue of sequence $y$, $M_{ij}$ is the score of the previous optimised alignment till the cell $(i, j)$ in the table. For the cell $(i, j)$, there can be three moving directions for an alignment. If no gap is inserted, a move is from the cell $(i-1, j-1)$ to the cell $(i, j)$ meaning both the $i^{th}$ residue of sequence $x$ and the $j^{th}$ residue of sequence $y$ are used for a new incremental alignment. This is called the diagonal move in the table.
