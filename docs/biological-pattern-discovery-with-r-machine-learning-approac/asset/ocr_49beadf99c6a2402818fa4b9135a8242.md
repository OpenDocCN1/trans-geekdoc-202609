# Responsive Gene Discovery

The $F$ statistic used for optimising a K-means cluster model structure can also be used for optimising a fuzzy C-means model structure. Figure 2.31 shows the $F$ statistic p value distribution using the fuzzy C-means algorithm based on different cluster numbers for the data set with nine clusters, which is shown in Figure 2.30(a). In total, 15 models were tested. These 15 models employed two, three, till 16 clusters. Based on the $F statistic p value distribution, the model with eight clusters was also selected as the best model structure, which was again one cluster less than the true cluster number.
