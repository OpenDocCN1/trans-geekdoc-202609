In addition, all combinatory processes can be optimised by the use of the dynamic programming algorithm if the whole optimisation problem can be linearly decomposed into sub-optimisations. Therefore, if an optimisation can be decomposed into piece-wise sub-optimisation problems, an optimisation is then an incremental optimisation process. This means that the current sub-optimisation process is independent from the previous sub-optimisation processes in such an optimisation problem.

The sequence homology alignment problem is such an optimisation because the whole homology alignment can be decomposed. The main reason for this decomposition likelihood is that almost all metrics used in sequence homology are linear. Suppose the alignment length of a pair of aligned sequences is $N$ and the score of each aligned pair of residues is denoted by $s_n$. The linearity property of the homology measurement between two sequences is shown below,

```
$S = \sum_{n=1}^N s_n$ (7.1)
```

This linearity property shows that it is possible to decompose this homology alignment for any $1 < m < k$ and $m < k < N$ as shown below, where $S_m$ and $s_k$ are two decomposed alignment scores for two segments, one of which has $m>1$ pairs alignments and the other has one pair alignment,

```
$S = \sum_{n=1}^m s_n + s_k = S_m + s_k$ (7.2)
```

The above equation is very important as it shows that the calculation of $s_k$ is independent of the calculation of $S_m$ or the later optimisation is independent from the previous optimisations. Therefore, a later homology alignment assumes the previous homology alignment has been optimised in a sequence alignment process. The previous homology alignment only affects the whole homology alignment score.
