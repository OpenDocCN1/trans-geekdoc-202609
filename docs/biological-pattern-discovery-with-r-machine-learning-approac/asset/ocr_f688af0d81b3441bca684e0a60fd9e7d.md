# 7.2.3.4 The R library for the Needleman-Wunsch algorithm

The R library Biostrings in Bioconductor provides a function for using the Needleman-Wunsch algorithm to align two sequences. The function is named pairwiseAlignment. Its format is shown below, where s1 and s2 are two sequences, substitutionMatrix, gapOpening is the penalty applied to an inserted gap and gapExtension is the penalty applied to extended gaps.

```
pairwiseAlignment(s1,s2,substitutionMatrix,
gapOpening,gapExtension)
```

To define a sequence, Biostrings provides three functions. The DNAString function is used to define a DNA sequence. The RNAString function is used to define a RNA sequence. The AAString function is used to define an amino acid sequence. The following code can be used to align two sequences,

```
s1=AAString('ABCNJRQLCRPM')
s2=AAString('AJCJNRCKCRBBP')
subs=matrix(0,nrow=22,ncol=22)
diag(subs)=1
rownames(subs)=colnames(subs)=AA_ALPHABET[1:20]
pairwiseAlignment(s1,s2,substitutionMatrix=subs,
gapOpening=0,gapExtension=0)
```

The alignment result for these two sequences is shown below,

```
ABC-NJRQLCR-PM
| | | | | |
AJCJ-R-CKCRBP-
```
