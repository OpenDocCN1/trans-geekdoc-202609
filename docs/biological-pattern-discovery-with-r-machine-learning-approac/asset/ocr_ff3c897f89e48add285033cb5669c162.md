For this new $t_i$ statistic, a threshold is defined as $t_	au$ based on a confidence level $	au$ (default 0.05). If $|t_i| \le t_	au, z_i^-$ is predicted as a non-outlier and is removed from the candidate outlier list,

```
$z^- = z^- \setminus z_i^-$ (6.30)
```

This candidate outlier $(z_i^-)$ is also inserted into the tie cluster set,

```
$z^+ = z^+ \cup z_i^-$ (6.31)
```

If $t_i > t_	au, z_i^-$ is predicted as an outlier (perhaps a high extreme outlier) and the examination of $z_j^+ > z_i^+, \forall z_j^+ \in \mathbf{z}^+$ is terminated. If $t_i < -t_	au, z_i^-$ is predicted as an outlier (perhaps a low extreme outlier) and the examination of $z_j^- < z_i^-, \forall z_j^- \in \mathbf{z}^-$ is terminated.
