# 5.7.3 The generation of the merged and unique peaks

After smoothing a peak spectrum derived from a raw spectrum with an estimated baseline removed, the other important benefit can be seen. It can be seen from Figure 5.13 that the artifacts which have low intensities have also been smoothed, leading to less number of glitches. Therefore, the intensity difference between the true peaks and the artifacts has been enlarged. The next question is how to separate the true peaks from the artifacts. A statistical process is therefore required.

Having a *a priori* knowledge which peaks are the true peaks for discovery, a density estimation approach can be used for the discrimination between the true peaks of interest and artifacts. A density estimation process as a classic statistical process can be used to deliver a quantitative method to identify the significant difference between the true peaks and the artifacts in a smoothed peak spectrum.

All the intensity heights (for short, the heights) in a smoothed peak spectrum are positive, no matter they are the true peaks or the artifacts. Moreover, if the height difference between the true peaks and the artifacts is sufficiently great and every peak has a trend that it moves to the peak height gradually and moves down from the peak height gradually, the density of the heights will follow a sharp decay pattern.
