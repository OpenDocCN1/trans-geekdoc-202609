A very promising feature that a linear model has is such that a model is possible to extrapolate beyond the interval of the available data on which a model has been constructed. The reason that a linear model has this capability is that a linear model can discover the trend relationship between variables.

However, linear models have a common limitation that they may fail to model a complicated data set. This therefore may result in some misleading interpretations if the nonlinearity in data has been missed during a modelling process. The nonlinear modelling algorithms such as neural network learning and then later deep learning algorithms have drawn great attention for modelling biological/medical data for knowledge discovery and pattern analysis since 1980s. The greatest contribution is the significant improvement of the accuracy of such a model. Deep learning as a new promising machine learning strategy has drawn even greater attention for biological/medical data analysis and pattern discovery. The reason that deep learning is its unique property. When a machine learning model is constructed based on some non-numerical variables, such as the variables in the image data or spectra data, a conversion process from non-numerical variables to numerical variables has to be followed, which is called the feature extraction. A feature extraction process can generate hundreds or thousands of feature variables based on an image data. Some of them may have a high discrimination power, but some may not. Some of them may be highly correlated to each other, making some feature variables redundant, but some may not. Therefore, after feature variables have been extracted, a process has to be followed to filter out non-contributing feature variables. This is called a feature selection process. Although there have been many machine learning algorithms developed for both feature extraction and feature selection, these two processes are still non-trivial. Selecting the most representative feature variables is also another tedious process in addition to feature extraction and is prone to error. Importantly, there is no unique method for this process.
