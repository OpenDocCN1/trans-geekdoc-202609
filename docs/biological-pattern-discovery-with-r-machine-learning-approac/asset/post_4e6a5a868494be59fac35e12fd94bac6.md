## 3.6.7.2 The purity measurements

A decision-making model is a system composed of a set of partitioning rules. To derive an optimal set of partitioning rules as the best decision-making model for a data set is an inductive learning process. For instance, y = 0 is certainly not a good partitioning rule compared with the partitioning rule although the lower subspace is very pure to one y = 2 in Figure 3.37(a). This is because the upper subspace generated by this partitioning rule is highly mixed by two classes of data points On the other hand, each subspace generated by the partitioning rule y = 2 is more pure to one class of data points.

To automate the discovery of an optimal partitioning rule set, a quantitative measurement for measuring the purity or impurity of the subspaces generated by every partitioning rule is required. Two measurements have been proposed and are still in use. One is called the Gini index used by CART [Breiman, et al., 1984] and the other is called the information given by both DT and CART [Breiman, et al., 1984; Quinlan, 1986].

The Gini index is calculated for each partitioning rule. It is the classwise sum of the products between the probability of correct classification and the probability of mis-classification. The product $p_k(\tau)[1 - p_k(\tau)]$ is called the Bernoulli variance. Suppose there are $K$ classes, $x$ is a variable, $x=\tau$ is a partitioning rule, $p_k(\tau)$ is the probability or proportion of correct classification of the $k^{th}$ class of data points using the partitioning rule $(x=\tau)$. The Gini index is defined as,

```
$I_G(x=\tau) = \sum_{k=1}^{K} p_k(\tau)[1 - p_k(\tau)] \quad (3.75)$
```

It can be seen that, for a subspace for one class, $p_k(\tau)=1$. Or, $p_k(\tau)=0$ and $1-p_k(\tau)=1$. Therefore, $p_k(\tau)[1-p_k(\tau)]=0$. If all subspaces are pure for one class, $I_G(x=\tau)=0$. If a partitioning rule generates a random classification model, $p_k(\tau)=0.5$. The value of $I_G(x=\tau)=0.25 \times K$. Therefore, the minimum value of the Gini index is zero when set of partitioning rules constitute a perfect classification model and the maximum value of the Gini index is $0.25K$.

The other measure should be information gain based on the entropy theory, which is defined below, as $\log_2(1+p_k(\tau))$ has been replaced by $\log_2$ for avoiding an infinite value in case $p_k(\tau)$ approaching zero,

```
$I_E(x=\tau) = \sum_{k=1}^{K} p_k(\tau)\log_2(1+p_k(\tau)) \quad (3.76)$
```

The information gain should be maximised for a better partitioning rule. If a partitioning rule generates a pure subspace, $p_k(\tau)=1$. Therefore, $p_k(\tau)\log_2(1+p_k(\tau))=1$. The maximum information gain is thus $K$.

## 3.6.7.3 The classification and regression tree algorithm

Constructing a classification tree model is based on a series of optimisation processes, each of which is implemented by measuring the value of a purity or impurity index aforementioned for each partitioning rule. The CART algorithm can be used for both classification analysis and regression analysis. It works in three steps [Breiman, et al., 1984].

In the first step, the tree is grown. Each node is split into two subsets by selecting the feature and split point that minimizes the impurity. This process is repeated recursively until some stopping criterion is met.

In the second step, the tree is pruned if it does not generate significantly better performance on a validation set.

In the last step, the pruned tree is used for making predictions.
