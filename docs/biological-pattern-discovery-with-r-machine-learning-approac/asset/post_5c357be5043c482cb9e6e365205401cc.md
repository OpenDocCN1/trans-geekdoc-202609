## 7.6.3 Genomics pattern evolving with time

This pandemic has lasted for over one year. The GISAID has collected all sequences submitted in this period. Each submitted sequence has an accompanied submission date. For each country, the submission dates were extracted for each sequence and the submission date of the first submitted sequence was used as the beginning date. The rest of submission dates were subtracted by this first submission date. This generated a variable named as the time lag. Each country had one time lag value. This time lag was treated as the dependent variable and 64 3-mers were treated as the independent variables in regression models. A Lasso regression model was constructed between these variables for each country.

## 8 Optimised Peptide Pattern Discovery

### 8.1 A biological question — protease cleavage discovery

The main data used in either the protease cleavage discovery or posttranslational modification discovery are peptides. A peptide is a short sequence cut from a long sequence, which normally is between a few to a dozen of residues. There are two key problems of peptide discovery. They are the poly-protein cleavage activity caused by various proteases and the post-translational modification caused by various chemicals. Both subjects have been extensively researched in protein science. For instance, the studies cover many areas as protein chemistry, proteomics, biopharmaceutical manufacture, peptide mass fingerprinting, protein fragmentation, protein domain separation and pattern activity recognition [Cheronis, 1993].

A peptide used for the protease cleavage discovery is commonly expressed as $R_m \dots R_2R_1R'_1R'_2 \dots R'_n$, where $R_{1\le i\le m}$ stands for the N-terminal residues and $R'_{1\le j\le n}$ stands for the C-terminal residues. The cleavage happens between $R_1$ and $R'_1$. A peptide used for the post-translational modification discovery is commonly expressed as $R_m \dots R_3R_2R_0R'_1R'_2 \dots R'_n$, where $R_0$ is the modification site. Most machine learning models constructed for peptide discovery treat residues as mutually independent variables. For instance, the binary encoding approach encodes each residue using a binary vector and the bio-function function introduced in Chapter 3 of this book employs a mutation matrix to align two peptides as to encode peptides. The alignment between two peptides is a linear sum of the mutation probabilities between two peptides pair-wise. Therefore, potential residue interplay has not been considered in a modelling process of peptide pattern analysis using both encoding approaches.
