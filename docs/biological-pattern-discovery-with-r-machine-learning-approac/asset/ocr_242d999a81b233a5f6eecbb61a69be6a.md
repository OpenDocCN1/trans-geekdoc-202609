It should be noted that the bin width of a histogram constructed by calling the hist function is determined by the function through rounding up the w parameter shown below, where n stands for a designed bin number, max and min stand for the maximum and minimum values of a data set, respectively,

```
$w = \frac{\max - \min}{n} $$ (2.2)
```

For instance, if the bin number was five when calling the hist function for the sample SRR1039508 of the airway data density was slightly different. This is shown in Figure 2.4, where the actual bin number became seven. The height of a bin represents a count, i.e., the number of data points falling within a bin. For instance, the height of the first bin on the left side was 4,506. The following code can be used to check whether this height is true,

```
sum(log(x[which(x[,1]>0),1])^2)
```
