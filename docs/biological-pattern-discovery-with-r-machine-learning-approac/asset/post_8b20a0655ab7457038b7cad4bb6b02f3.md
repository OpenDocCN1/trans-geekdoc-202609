## 9.3 Quantum computing for biological analysis

Quantum computing started in the 1980s and it implements computations employing quantum mechanics such as superposition and entanglement. This has led to the development of quantum computers. The research of quantum computing has led to the development of quantum machines such as the quantum neural networks [Benioff, 1980; Feynman, Ladd, et al., 2010; Reicher, et al., 2017].

Quantum computing has been implemented for machine learning in recent years. The basic component of machine learning is an information system that incorporates noise data with a properly designed cost function. Unsupervised machine learning can be implemented by developing a new entangled states of the quantum bus in a quantum computer [Gyongozzi, 2020]. The work was introduced based on the observation that the quantum gate oscillates in a random mode which is similar to data noise. Quantum computing has been implemented as a kernel-based support vector machine. The support vector machine algorithm has a limitation when a feature space is too large. The quantum computing can implement the quantum-based support vector machines to speed up learning, where the novel idea is to use a smaller quantum space to replace a kernel space [Vojtech, et al., 2019].
