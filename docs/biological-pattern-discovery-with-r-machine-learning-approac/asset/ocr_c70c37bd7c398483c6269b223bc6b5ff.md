Chapter 2 will focus on one responsive gene discovery problem. In modern days, the essential gene discovery is mainly based on thethroughput transposon sequencing technology. Based on this technology, millions of mutants can be generated in one experiment. Genes essentiality is analysed based on estimating a density function for a transposon statistic such as the insertions per gene statistic or the transposon insertion sites per gene statistic. This is a typical unsupervised learning problem. Therefore, various density estimation algorithms and cluster analysis algorithms will be introduced in this chapter. For the essential gene discovery will be demonstrated.

Chapter 3 will focus on the peptide pattern discovery problem. This problem is a type of applications where protein functional sites are discovered using local protein structures, i.e., protein peptides. The research projects of this problem mainly include the discovery of cleavage sites or post-translational modifications in peptides. The same idea also applies to the discovery of the DNA binding sites, transcription factor sites, etc. Protein functional site discovery employs two sets of peptides, i.e., having no functional sites and those having functional sites verified in laboratories. The latter refers to the protease cleaved peptides or thetranslational modified peptides. This type of applications fits the mainstream in machine learning, i.e., classification analysis or discriminant analysis. This chapter will introduce various classification analysis algorithms and demonstrate how these algorithms can be used for peptide pattern discovery. A typical problem of the protein functional site discovery is the data type. A protein sequence is a string of amino acids, which are non-numerical. Therefore this chapter will introduce different encoding approaches for handling amino acids in peptides so that a machine learning algorithm, which needs numerical data as the input, can be used.
