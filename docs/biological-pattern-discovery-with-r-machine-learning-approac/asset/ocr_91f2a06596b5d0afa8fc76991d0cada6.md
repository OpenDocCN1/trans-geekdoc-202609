The **density** function is a non-parametric density estimation approach, which will be introduced later in this chapter.

```
z=log(x[which(x,1]>0),1])nhist(z,nclass=50,xlab='log count', 
main='SRR1039508',prob=TRUE)
lines(density(z))
```

An important issue of the histogram approach is the proper design of the bin number. When employing too few bins, a density function may show a more flattened density curve. Figure 2.6(a) shows such a case, where only four bins were employed. When employing too many bins, a density function is very non-smooth, which may not be able to reveal a real distributional pattern. Figure 2.6(c) shows such a case, where 200 bins were employed. Only a proper bin number can help accurate pattern discovery. Figure 2.6(b) shows a case, where 20 bins were employed and the density pattern can be easily visualised for the data.
