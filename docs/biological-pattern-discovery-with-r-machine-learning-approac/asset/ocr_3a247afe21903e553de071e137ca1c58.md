Figure 5.9. The estimated baselines with two different regularisation constant values for the spectra data shown in Figure 5.5 using the baseline package.

Figure 5.9 shows the use of this package for the spectra data shown in Figure 5.5 with two different regularisation constant values. It can be seen that when the regularisation constant changes, the estimated baselines have different shapes. As shown in the upper panel of Figure 5.9, the estimated baseline was reasonable when the regularisation constant was one. However, the estimated baseline as shown in the lower panel Figure 5.9 was worse when the regularisation constant was 15, where the estimated baseline became a straight line. It was definitely useless for discovering signals from such a baseline because both the false peak discovery rate and the missing true peak discovery rate will be unreasonably high.

Figure 5.10 shows the peak spectrum extracted on the estimated baseline as shown in Figure 5.9 using the baseline package, where two different regularisation constant values were employed. It can be seen that when the regularisation constant was one, the extracted peak spectrum demonstrated a better pattern as shown in the upper panel of Figure 5.10. This peak spectrum is certainly better for signal discovery. When the regularisation constant was 15, the extracted peak spectrum failed to show a good pattern as shown in the lower panel of Figure 5.10. Therefore signal discovery from such a peak spectrum won’t be very successful.
