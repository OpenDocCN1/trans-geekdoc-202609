# 5.4 RESULTS

The research experiment has been performed using deep learning architecture such as LSTM, GRU, CNN, and Multilayer Perceptron (MLP) on the German data sets, on the Taiwanese data sets and finally on the European data sets. For analysis and comparison of model we have tuned the parameter such as activation function, number of hidden layers and number of neurons in hidden layers of deep learning architecture. In this experiment celu, sigmoid, tanh and switch activation function and 1 hidden layer and 2 hidden layers have been used with the number of neurons remains constant. The number of epochs used in each implementation is 150. The number of input neuron has taken as 22 when the model is implemented on European data set while the number of input neuron has been taken 18 when the model is implemented on Taiwanese and German data sets. As the data sets are imbalance so, this experiment has considered F1 score for evaluation of the proposed model. Table 5.1 shows the results obtained from German datasets.

As the implementation has been done using deep learning architecture, it can be observed from Table 5.1 that the accuracy of training and testing set of the cases is good. However, whenever the parameters of the architecture (i.e, the number of hidden layers and activation functions has been tuned), it has been observed that there is a slight variation in the results. In all the architectures it has been observed that the architecture with two layers provides better results when compared with one hidden layer. Also, in each of the architectures it has been observed that the best results are when the architecture is implemented with sigmoid activation function. From the table table it can be illustrated that the MLP architecture with sigmoid activation function and two hidden layers is providing precision of 0.68, recall of 0.51, F1 score of 0.56 and MCC score of 0.411. In CNN architecture with sigmoid activation function and two hidden layers the precision is 0.60, recall is 0.57, F1 score is 0.58, MCC score is 0.413. In LSTM architecture with sigmoid activation function and two hidden layers the precision is 0.54, recall is 0.57, F1 score is 0.55, MCC score is 0.350. In GRU architecture with sigmoid activation function and two hidden layers the precision is 0.49, recall is 0.76, MCC score is 0.388. But as in this experiment F1 score has been considered as its main evaluation metrics among the four architecture the best F1 score which is 0.60 has been achieved by GRU with sigmoid activation function and two hidden layers.
