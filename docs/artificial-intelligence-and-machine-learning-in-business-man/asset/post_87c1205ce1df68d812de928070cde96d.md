## 13.3 WORKING PRINCIPLE OF LSTM

The Long Short-Term Memory networks were first introduced by Hochreiter and Schmidhuber in 1997 [25], and was modified and popularized by other researchers in a wide range of research fields. The feature of memorizing the information for long periods of time is to overcome the problem of long-term dependency in RNN architecture. Due to this feature of RNN networks it resembles the process of human understanding based on their experiences by having loop of similar networks to persist the information which was required to predict the future values.

In this paper, the Long Short-Term Memory networks (LSTMs), a special type of RNN that has the capacity to learn long-term dependencies, have been implemented to predict foreign exchange rates.

In this model, back-propagation algorithm is used to train LSTMs through time, thus sophisticated Recurrent Neural Network (RNN) can be developed to implement on different sequence problems. LSTM cells have model blocks in the place of neurons which component should choose. The cell state ($C_{t-1}$ or $C_t$), is the soul of LSTM, runs as a conveyor belt performing some simple linear calculation. The LSTM is capable to remove old information and add new information with the help of neural structures as gates. Gates (Forget gate, Input gate and Output gate) are composition of an activated Sigmoid layer and point-wise multiplication. Sigmoid layer outputs value between 0 to 1 and decides how much & which one value let through.

![](img/9665bc5b38d724f414bf1c78dda7410a_228_0.png)

FIGURE 13.1 Long Short-Term Memory networks (LSTMs) cell.

Input variables are passed through the block (Figure 13.1) and activated using Sigmoid function. The gate $f_t$ decides what information to discard from the state using Sigmoid activation function $s=\frac{1}{1+e^{-x}}$ over the inputs $h_{t-1}$ and $x_t$, where $h_{t-1}$ is the input from previous hidden layer and $x_t$ is the input from the network.

$f_t = \sigma(W_f \cdot x_t + U_f \cdot h_{t-1} + b_f)$ (13.1)

Short-Term Memory networks (LSTMs) cell is shown below in Figure 13.1. Next steps decide which new information is going to store in the cell state. A sigmoid layer (i.e., input layer, $i_t$) outputs the updating value and $tanh$ layer

$tanh = \left(\frac{e^x-e^{-x}}{e^x+e^{-x}}\right)$ creates a vector value $a_t$

$i_t = \sigma(W_i \cdot x_t + U_i \cdot h_{t-1} + b_i)$
$a_t = \tanh(W_a \cdot x_t + U_a \cdot h_{t-1} + b_a)$ (13.2)

Point-wise multiplication of these two layers is used when updating the cell state $C_{t-1}$ into $C_t$. The update is carried out by adding the multiplication of $f_t$ & old state $C_{t-1}$ with $i_t * \tilde{C}_t$.

$c_t = f_t \cdot c_{t-1} + i_t \cdot a_t$ (13.3)

Finally, the output operation is performed. The output gate decides the cell state through output gate to get output.

$o_t = \sigma(W_o \cdot x_t + U_o \cdot h_{t-1} + b_o) \cdot \tanh(c_t)$ (13.4)

For the simplicity of the cell state, we use the following form:

$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$ (13.5)

Before back-propagating the LSTM, we calculate the loss function.

$e = \frac{(o-\hat{o})^2}{2}$ (13.6)

For back propagation, we have:

$\delta e = o - \hat{o}$ (13.7)

Now for the back-propagation of LSTMs:

$\delta h_t = \Delta t$ (13.8)

$\Delta t$ is the difference between the actual and predicted value.

$\delta c_i = \delta h_i \cdot (1-\tanh^2(c_i)) + \delta c_{i+1} \cdot f_{i+1}$
$\delta a_i = \delta c_i \cdot i_i \cdot (1-a_i^2)$
$\delta i_i = \delta c_i \cdot \tanh(c_i)$
$\delta f_i = \delta c_i \cdot c_{i-1}$ (13.9)

The final updates to the internal parameters are:

$\delta W = \sum_{t=0}^{T} \delta s_t \cdot x_t$
$\delta U = \sum_{t=0}^{T} \delta s_{t+1} \cdot h_t$ (13.10)
$\delta b = \sum_{t=0}^{T} \delta s_{t+1}$

To adjust the neural network model, previous weight values of the weight matrix must update by adding the multiplicative results of learning rate and changes in weight matrix.

$W^{new} = W^{old} - \lambda \cdot \delta W$
$U^{new} = U^{old} - \lambda \cdot \delta U$
$b^{new} = b^{old} - \lambda \cdot \delta b$ (13.11)
