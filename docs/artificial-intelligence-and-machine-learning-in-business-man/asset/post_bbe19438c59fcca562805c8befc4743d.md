A comparative analysis has been made to determine the fraudulent transaction by various deep learning architecture such as LSTM, CNN, GRU, MLP. The proposed model was implemented on three publicly available data sets. As all the data sets were highly imbalanced, SMOTE technique has been used to get rid of whereas F1 score has been considered for the evaluation purpose. It has found that, among all the deep learning architectures implemented on three of the data set, the highest F1 score is achieved by the GRU model with sigmoid activation function and 2 hidden layers.
