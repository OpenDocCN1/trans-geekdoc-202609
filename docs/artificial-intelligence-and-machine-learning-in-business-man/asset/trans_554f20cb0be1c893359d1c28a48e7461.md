# 3.1.1 谈判

智能体通常处理与其他智能体的世界。谈判或智能体间的互动可能从另一个智能体处获取实体、让另一个智能体执行活动或改变另一个智能体的感知。

DOI: 10.1016/978-22519-3

# 3.2 商务中的人工智能与机器学习

首先，智能体表达观点，这可能会导致冲突，然后通过提供妥协达成共识。谈判的关键特征包括 (a) 参与智能体使用的术语、(b) 采用的协议以及 (c) 使用的判断过程。协议的选择取决于多种类型。根本上，谈判的主要目的是帮助理解。我们探讨了以下概念：

- (i) 谈判是在给定协议和智能体技术的帮助下，解决两个或多个智能体之间分歧的方法。
- (ii) 通常，协议遵循智能体在谈判期间需要采取的步骤，而智能体的技术是其思考过程的一部分（这需要收集和评估知识并提供组件）。
- (iii) 谈判是通过一组智能体就共同关注的事达成共识。从上述描述推断，谈判的目的是达成一个符合智能体偏好或限制的协议。
- (iv) 未达成一致可能是由于缺乏时间、参与者缺乏替代方案（可能是由于对参与者倾向的信息不足）或智能体策略之间的不兼容。然而，如果可能且双方愿意执行，双方通常都会确保协议的内容。
