# FIPA Communication Acts (Performatives)

The FIPA Communication Acts

FIPA

Communicative Act

Explanation

| Act | Explanation |
| --- | --- |
| Accept Proposal | The act of approving a request, previously submitted to execute an operation. |
| Agree | The practice of agreeing to undertake any action, perhaps in the future. |
| Cancel | The act of one agent telling another that the former no longer has the intention that the latter carries out some operation. |
| Call for Proposal | The agent requires certain proposals to carry out a given action. |
| Confirm | The sender advises the recipient that given proposal is valid where it is understood that the recipient is unsure about the suggestion. |
| Disconfirm | The sender tells the recipient that a given proposal is false or not, where it is understood that the recipient assumes that the idea is real. |
| Failure | The action of informing the other agent that an act has been performed, however it failed. |
| Inform | The sender tells the recipient a given proposal is valid. |
| Inform If | The sender tells the receiver whether a given proposal is true or not. |
| Inform Ref | A macro permits the sender to notify the recipient of a certain item that the sender asserts it refers to a particular descriptor (e.g., a name). |
| Not Understood | The act's (for instance, i) tells the recipient (for instance, j) that j executed some operation which failed competent. A relevant case is that j is told by i that i did not understand the text that j had just sent to i. |
| Propagate | The sender plans that the recipient handles the embedded message sent instantly to the recipient and wants the recipient to recognize the agents denoted by the provided descriptor and to acquire propagate message to them. |
| Propose | The act of sending a plan to carry out certain activities, provided preconditions. |
| Proxy | The sender wants the recipient to pick target agents represented by a given definition and transmit an embedded message to them. |
| Query | The act of querying another agent if a given proposal is valid or not. |
| Query Ref | The act of querying other for the item addressed by a referential statement. |
| Refuse | An disapproving of act and clarifying the refusal's reason. |
| Reject Proposal | The act of declining a proposal to carry out an operation at the time of negotiation. |
| Request | The sender puts forward a request for the receiver to undertake. One significant category of the request act is to make an appeal to the receiver to carry out another communicative act. |
| Request When | The sender needs the recipient to take some action when a given proposal becomes relevant. |
| Request Whenever | The sender needs the recipient to carry out an action instantly when a proposition turns out to be true and subsequently each and every time when proposition turns to true again. |
| Subscribe | The action of requesting a certain intent to inform the sender of the value of a reference, as well as to notify again and every time the object is recognized by the changes in reference.|
