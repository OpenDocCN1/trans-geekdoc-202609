## 15.2 VIDEO ANALYTICS

Video analytics (VA) is the ability to process and analyze video content to extract meaningful information. It uses various techniques such as computer vision and machine learning to identify objects, behaviors, and events. VA is used in a wide range of applications including security, healthcare, retail, and transportation.

## 15.3 NEED FOR VIDEO ANALYTICS

The rapid increase in video data has led to a growing demand for video analytics. Organizations need to process and analyze vast amounts of video information to gain insights and make decisions. Video analytics can help automate tasks, improve efficiency, and enhance security measures.

## 15.4 THE WORKFLOW

Semantic data extraction using video analysis aims at making use of enormous data to extract useful information. It uses various techniques such as computer vision and machine learning to collect the valuable portion of the video and then implements the concept of optical character recognition [3] to extract information from it. In other words, it takes video or images as input and produces some text as an output.

### 15.4.1 Frame Extraction

This is the first and perhaps the most straightforward stage. Here, the provided video is converted into a set of frames. The input of this stage is a video, and output is an image sequence obtained from the video.

### 15.4.2 Segmentation Model

In this stage, the position of the licence plate of the vehicle is detected and segmented using the segmentation model. The segmentation model takes the image as an input and returns the segmented licence plate as output [4–10].

### 15.4.3 Preprocessing

Preprocessing involves preparing the extracted video frames for further analysis. This may include tasks like noise reduction, contrast enhancement, and color correction.

### 15.4.4 Feature Extraction

In this stage, relevant features are extracted from the pre-processed frames. These features may include edges, textures, colors, and other descriptive characteristics.

### 15.4.5 Object Localization

Object localization involves identifying the location of objects of interest within the frames. This is often done using bounding boxes to enclose the detected objects.

### 15.4.6 Character Segmentation

Character segmentation involves separating the segmented licence plate into individual characters. This is a crucial step for character recognition.

### 15.4.7 Boundary Extraction Using Horizontal and Vertical Projection

Boundary extraction uses horizontal and vertical projections to identify the boundaries of characters. This technique can be effective for separating characters with clear spacing.

### 15.4.8 Connected Component Analysis (CCA)

Connected Component Analysis is a technique used to group pixels that belong to the same object. It can be used to identify characters in segmented frames.

### 15.4.9 Character Recognition

Character recognition involves identifying the individual characters from the segmented images. This is often done using machine learning or deep learning models.

### 15.4.10 Collecting Training Dataset

Collecting a training dataset involves gathering and labeling data to train the character recognition model. This data typically includes images of various characters and their corresponding labels.

### 15.4.11 Machine Learning Classifier

A machine learning classifier is used to classify the extracted characters. The classifier is trained on the collected dataset and then used to recognize characters in new images.
