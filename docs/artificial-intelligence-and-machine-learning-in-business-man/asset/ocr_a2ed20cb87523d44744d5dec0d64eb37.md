Then, univariate feature selection has been applied on these data sets in which only 75% features were selected, which means in European data sets only 22 features and in Taiwanese and German data sets only 18 features got selected. Feature selection is important because it helps in reducing training time, improving accuracy and limiting the over-fitting problem of the model.

Moreover, all the data sets are highly imbalanced as per the statistics observed. The European data set has only 0.0173 fraudulent transactions, while the Taiwanese data set has 0.2212 and the German data sets have 0.3 fraudulent transactions. To overcome the problem of imbalanced data sets we have applied SMOTE. SMOTE helps to balance the class distribution.
