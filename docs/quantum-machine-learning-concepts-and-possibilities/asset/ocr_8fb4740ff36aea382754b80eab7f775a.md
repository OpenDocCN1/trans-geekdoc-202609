# 4.4 Linear quantum models

Quantum kernels rely on fixed quantum feature maps and classical optimization. In contrast, linear quantum models introduce trainable parameters directly into quantum circuits. These models represent quantum analogs of linear classifiers, such as logistic regression or perceptrons, but operate in high-dimensional Hilbert space where the feature space is defined by the structure of a quantum circuit.

The most common approach involves PQCs, also known as variational circuits, where some gates are equipped with tunable angles. These parameters are optimized using classical routines, making the overall learning architecture hybrid quantum-classical model.

# 4.4.1 Parameterized quantum circuits for classification

A parameterized quantum circuit is a quantum circuit with gates that depend on a vector of parameters $	heta$. In the context of classification, a typical circuit structure includes:

+   * A quantum feature map $U_{\phi}(x)$, which encodes the classical input $x$ into a quantum state.
* A trainable unitary $U(\theta)$, applied after the encoding, representing the model's hypothesis.
* A measurement in the computational basis to extract the output.

This circuit prepares a state

```
$$\psi(x; \theta)\rangle = U(\theta)U_{\phi}(x)|0\rangle^{\otimes n}, \quad (4.15)$
```

and the predicted label is obtained by measuring one or more qubits and postprocessing the result. For example, in binary classification, one might define

```
$f(x; \theta) = \langle\psi(x; \theta)|M|\psi(x; \theta)\rangle, \quad (4.16)$
```
