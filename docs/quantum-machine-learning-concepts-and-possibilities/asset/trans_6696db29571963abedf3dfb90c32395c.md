

## 量子机器学习

若干量子机器学习框架为混合自动求分提供了基础设施：

- **PennyLane [18]** 实现了全可微的量子-经典混合图，支持 PyTorch、TensorFlow 和 JAX 后端。它暴露了带有内置梯度的*量子节点*，并支持使用优化器进行端到端优化。
- **Qiskit Machine Learning [19]** 通过自定义的 `TORCHCONNECTOR` 模块与 PyTorch 集成，并在 IBM 后端或模拟器上支持参数移位梯度或有限差分估计器。
- **TensorFlow Quantum [20]** 支持与经典 TensorFlow/Keras 流水线集成的可微量子层。它在仿真中使用伴随微分，并使用基于采样的梯度规则。

这些框架会自动跟踪图中哪些部分是量子的，哪些是经典的，并据此调用正确的梯度规则。

**混合训练循环**
考虑一个模型，其中量子电路产生一个实值输出 $f(x; 0)$，用于逻辑回归任务。损失函数可能是：

$L(f, y) = -y\log(f) - (1 - y)\log(1 - f).$ (6.6)

- 在训练期间：
  - **前向传播**在输入 $x$ 上评估量子电路，测量观测量并计算结果，存储在图中。
  - 损失 $L$ 使用标量输出 $f$。
  - **反向传播**从 $\nabla_f L$ 开始，使用量子梯度规则评估 $\nabla(f)$，并应用链式法则计算 $\nabla_x L$。
  - 经典优化器（例如 Adam）更新参数 $\theta$。

整个过程对用户是透明的，用户只需像构建经典神经网络一样以声明的方式定义模型和损失。

## 实践中的可微性

跨量子-经典边界的可微性之所以可能，是因为在给定门和观测量的情况下，量子电路可以表示为期望值函数。然而，由于采样噪声、贫瘠高原（barren plateaus）和硬件限制，**可微性并不意味着可分析性**；必须采样以确保梯度具有信息量且可靠。

尽管如此，混合自动求分已使变分量子模型变得实用。它允许量子模块集成到大规模机器学习系统中，促进了在量子计算发挥重要且可训练作用的架构上的实验。

## 6.2.2 参数移位规则

使能够在量子硬件上训练变分量子电路的主要突破口之一是参数移位规则（PSR）[21]。该规则允许我们仅通过在参数移位值处对量子电路进行评估，计算期望值相对于电路参数的梯度，这意味着不需要访问内部量子态或波函数。这使得 PSR 成为一种在 NISQ 设备上计算梯度的硬件友好型且在解析上精确的方法。

### 数学推导

假设我们有一个由门组成的参数化量子电路 $U(\theta)$，其中特定门 $R(\theta)$ 的形式为：

$R(\theta) = e^{-i\theta G},$

其中 $G$ 是一个海尔米特算子，具有两个不同特征值 $\pm r$（常见情况：$r=\frac{1}{2}$，如 Pauli 旋转）。

令电路准备量子态：

$|\psi(\theta)\rangle = U(\theta)|\psi_0\rangle$，

并令输出为某些观测量 $M$ 的期望值：

$f(\theta) = \langle\psi(\theta)|M|\psi(\theta)\rangle$，

那么参数移位规则规定：

$\frac{\partial f}{\partial\theta} = \frac{1}{2}[f(\theta+\frac{\pi}{4r}) - f(\theta-\frac{\pi}{4r})],$

其中 $s=\frac{\pi}{4r}$。

对于常见情况 $G=\frac{1}{2}Z$（即单比特旋转门，如 $R_X, R_Y, R_Z$），它简化为：

$\frac{\partial f}{\partial\theta} = \frac{1}{2}[f(\theta+\frac{\pi}{2}) - f(\theta-\frac{\pi}{2})],$

此结果是精确的，不涉及有限差近似或对波函数的认知，只需在不同的参数值下评估同一个电路。

### 直觉

在变分电路中，参数化门通常是绕 (X, Y 和 Z) 轴的单比特旋转：

- $R_X(\theta) = e^{-i\theta X/2}$，
- $R_Y(\theta) = e^{-i\theta Y/2}$，
- $R_Z(\theta) = e^{-i\theta Z/2}$。

## 量子机器学习

参数移位规则告诉我们，改变 $\theta$ 对测量结果的影响可以通过在两个对称移位点处评估电路来捕捉。这特别有利，因为即使电路运行在噪声量子设备上它也有效。

### 实际实现

为了计算损失函数相对于参数 $\theta$ 的梯度，必须：

1. 将 $\theta$ 向前移动 $\frac{\pi}{2}$，评估电路并记录结果。
2. 将 $\theta$ 向后移动 $\frac{\pi}{2}$，再次评估电路。
3. 取差，除以 2，并与损失函数链式。

这导致**每个可训练参数对应两次前向传播**。

## 6.2.3 广化参数移位规则

标准 PSR 适用于具有两个特征值的生成器，但许多量子操作涉及多两个特征值的生成器。广化 PSR [22] 为任意形式的门计算期望值提供了框架：

$U(\theta) = e^{-i\theta G},$ (15)

### 梯度的通用形式

给定准备态 $|\psi\rangle = U(\theta)|\psi_0\rangle$ 的量子电路和观测量 $M$，期望值为：

$f(\theta) = \langle\psi(\theta)|M|\psi(\theta)\rangle,$ (16)

那么，在适当条件下（例如 $G$ 具有离散谱），导数 $f(\theta)$ 可以表示为在多个参数值处电路评估的有限和：

$\frac{\partial f}{\partial\theta} = \sum_{s} c_s f(\theta + s).$ (17)

其中：

- $s \in \mathbb{R}$ 是一组移位值
- $c_s \in \mathbb{R}$ 是取决于 $G$ 谱的系数

### 主要观察

- 移位的数量取决于 $G$ 的**不同特征值的数量**。对于 Pauli 生成器（两个特征值），需要两次移位；对于复杂的门，所需的移位相应增加。
- **多比特门**（如控相位或控旋转门）生成器通常具有四个或更多特征值。在这种情况下，可能需要四、六甚至更多电路评估来估计单个参数的梯度。
- **对角生成器**（例如投影或块对角形式的哈密顿量）通常可以进行解析分解，有利于高效的广化 PSR 公式。

示例：三特征值生成器
假设 $G$ 具有特征值 $(-1, 0, +1)$。那么广化 PSR 产生：

$\frac{\partial f}{\partial\theta} = \sum_{k} c_k f(\theta + s_k),$ (18)

其中移位值 $s_k \in \{\pm\pi/2, \pm\pi/4\}$，且系数 $c_k$ 计算计算以匹配 $f$ 的导数。
