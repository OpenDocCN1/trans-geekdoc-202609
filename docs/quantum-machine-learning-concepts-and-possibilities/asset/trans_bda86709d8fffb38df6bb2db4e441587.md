在训练过程中，会调整网络参数 $\theta = \{W, b\}$ 以最小化损失函数 $L(f(x; \theta), y)$，该函数量化了预测输出与真实标签之间的误差。这通常通过**梯度下降**、随机梯度下降或其许多变体之一来实现。梯度是使用**反向传播**计算的，这是微积分链式法则在网络各层中的递归应用。

神经网络是**通用函数近似器** [6, 7]；一个具有单个隐藏层和足够单元的前馈网络在给定正确参数的情况下，可以逼近紧致定义域上的任何连续函数。这一强大的理论基础，结合高效的训练方法和硬件加速（例如 GPU），推动了深度学习在许多领域的兴起，包括计算机视觉、自然语言处理和科学数据建模。针对更深层的神经网络架构，已经推导出了通用近似定理 [8]。

## 6.1.2 作为学习模型的参数化量子电路

如上一章介绍的，参数化量子电路 (PQC) 或变分量子电路 (VQC) 由一组任意量子门组成，这些量子门由一组决定电路结果的控制参数进行参数化。PQC 的一种特定类型是所谓的量子神经网络 (QNN)，其中在给定的数据集上学习适用于任务的合适参数集，这类似于经典神经网络的训练 [9–11, 13, 37]。

经典神经网络为变分量子模型提供了架构和概念蓝图。理解经典神经网络为欣赏它们的量子对应物奠定了基础。量子电路像神经网络一样，由对输入应用的顺序变换组成，随后是非线性输出过程（在本例中为测量）。这些门可以是固定的（例如 Hadamard、CNOT），也可以是参数化的（例如 $R_X(\theta), R_Y(\theta), R_Z(\theta)$），它们的结构定义了*拟态* (*ansatz*)，即模型的表达能力。VQC 分类器的通用工作流如下：

1. **状态准备**（*数据编码*）：使用*编码电路* $U_{enc}(x)$ 将经典输入数据 $x \in \mathbb{R}^d$ 编码为量子态 $|\psi(x)\rangle$。该电路将数据映射到 $n$ 个量子比特的希尔伯特空间。
2. **参数化量子变换**：将由具有可调参数 $\theta = (\theta_0, \theta_1, \dots, \theta_l)$ 的门组成的参数化量子电路 $U(\theta)$ 应用于最终态。这是经典神经网络中可学习权重的量子类比。
3. **测量与输出**：在应用变分电路后，在选定的基（计算基）中进行测量。分类器的输出源于测量算符 $M$ 在最终态上的*期望值*，

```
$f(x; \theta) = \langle\psi(x; \theta)|M|\psi(x; \theta)\rangle, \quad (6.2)$
```

或者显式用电路单元表示：

```
$f(x; \theta) = |0\rangle U^{\dagger}_{enc}(x) U^{\dagger}(\theta) U(\theta) U_{enc}(x)|0\rangle. \quad (6.3)$
```

测量结果可以根据分类任务有不同的解释方式：

- *二分类*：测量单个比特的观测值（例如 Z）

训练循环类似于经典训练，但在前向步骤中带有量子评估，并使用专门技术（例如参数位移规则）来计算梯度。测量前的最终态：

```
$|\psi(x; \theta)\rangle = U(\theta) U_{enc}(x)|0\rangle^{\otimes n}. \quad (6.4)$
```

这种混合结构*经典输入* $\rightarrow$ *量子嵌入* $\rightarrow$ *参数化量子演化* $\rightarrow$ *经典输出*构成了量子分类模型的主干。
类似于神经网络，VQCs 可以进行堆叠、通过数据上传层进行扩展，并与经典层相结合。然而，它们的训练动力学和表示能力显著不同，这激发了新的理论和实证分析。

## 6.2 量子模型中的反向传播和梯度估计

训练变分量子分类器需要对**观测相对于电路参数的期望值**求导。与经典神经网络不同（反向传播通过微分原语图流动），量子硬件只返回**测量结果的样本**，因此梯度必须通过**硬件兼容的规则**进行估计。在混合模型中，这些量子梯度随后被整合进更大的*端到端*自动微分流水线中。下面我们回顾了主要技术、它们的假设、成本以及何时使用它们。

### 6.2.1 混合计算图上的自动微分

在现代机器学习中，自动微分 (autodiff) [14] 是高效基于梯度的训练骨干。无论是在 PyTorch [15]、TensorFlow [16] 还是 JAX [17] 中，自动微分都能通过遍历**计算图**无缝计算导数。在量子机器学习的背景下，混合模型（将量子电路嵌入经典学习架构中）的引入了一个关键问题：我们如何通过一个包含量子电路的模型传播梯度？

答案在于混合计算图，它将自动微分范式扩展到量子节点。这些节点封装了量子操作（状态准备、变分演化和测量），并向外暴露了*自定义梯度规则*，以便经典优化器跨越量子-经典边界更新参数。

#### 混合量子图结构

一个典型的模型包含：

- **经典节点**：特征预处理、全连接层和损失函数。
- **量子节点**：作用于输入编码态的参数化量子电路，返回期望值或样本统计数据。

这些节点在计算图中连接，其中数据流在评估期间向*正向*流动，而梯度在训练期间*反向*流动。整体架构类似于深度学习流水线，但变分电路承担了非线性变换的角色。

形式上，令 $x \in \mathbb{R}^d$ 为 $d$ 维经典特征向量，令 $\psi(x; \theta)$ 为由角度向量 $\theta$ 参数化的量子电路准备的状态。量子电路的输出为 $f(x; \theta)$——例如，如果输出是 $M$ 的期望值：

```
$f(x; \theta) = \langle\psi(x; \theta)|M|\psi(x; \theta)\rangle. \quad (6.5)$
```

输出是一个限制在 $[-1, 1]$ 之间的标量值，提取自标签 $\hat{f}(x; \theta)$。标签提取的示例包括使用经典偏置参数作为二标签，或将 $[-1, 1]$ 的值重缩到 $[0, 1]$。然后使用真实标签 $y$ 计算经典损失 $L^C(y, \hat{f})$。相对于参数的梯度为

```
$\nabla_{\theta} L(f(x; \theta), y) = \frac{\partial L}{\partial f} \frac{\partial f}{\partial \theta} \quad (6.6)$
```

这里，$\frac{\partial f}{\partial \theta}$ 是经典计算的，而必须使用兼容量子的方法（如参数位移规则）进行估计。
