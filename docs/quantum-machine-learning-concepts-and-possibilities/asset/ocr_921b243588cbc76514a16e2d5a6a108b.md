# **Table 6.4.** Summary of key architectural and implementation advantages of QGNs.

| Property | Explanation |
|---|---|
| Graph-aware modeling | QGNs incorporate graph topology directly into circuit design, allowing the learning of relational and structural dependencies between data points. |
| Entanglement along edges | Edge-conditioned entangling gates capture correlations dictated by the input graph, enhancing representational power over classical message passing. |
| Scalability via sparsity | Sparse graphs translate into shallow circuits with fewer entangling operations, enabling feasible implementation on NISQ devices. |
| Permutation and symmetry invariance | QGNs can be designed to respect graph symmetries (e.g. node permutation), improving generalization and reducing redundancy in learning. |
| Flexible architecture design | Supports static (graph-shaped circuits) and dynamic (input-dependent embeddings) models, adaptable to different quantum hardware constraints. |
