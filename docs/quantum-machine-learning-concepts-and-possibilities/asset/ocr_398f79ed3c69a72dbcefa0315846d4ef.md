# ## 3.3 Autoencoders

Autoencoders [9, 10] are a class of machine learning models designed to learn efficient, lower-dimensional representations of data. In the classical setting, an autoencoder consists of an encoder $E: \mathbb{R}^d 	o \mathbb{R}^d$ and a decoder $D: \mathbb{R}^d 	o \mathbb{R}^d$, trained jointly to minimize reconstruction loss:

```
$$\mathcal{L}(x) = ||D(E(x)) - x|^|^2 \quad (3.9)$
```

The learned representation $z = E(x)$ ideally captures the most salient features of the input data in a compressed format. Quantum autoencoders (QAEs) [11] extend this concept to quantum data (see table 3.2 for comparison of classical and quantum autoencoders), aiming to compress quantum states into Hilbert space while preserving the essential information. Let $|\psiangle_{in} \in \mathcal{H}_A \otimes \mathcal{H}_B$, where $\dim(\mathcal{H}_A) = 2^n$ and $\dim(\mathcal{H}_B) = 2^m$. A QAE seeks a unitary $U$ that

```
$U|\psiangle \approx |psiangle_A \otimes |0angle_B, \quad (3.10)$
```

where $|\psiangle_A$ encodes the compressed information and $|0angle_B$ is a fixed reference state of the discarded subsystem. The loss function used in variational quantum autoencoders (VQAEs) [12] is typically of the form

```
$$\mathcal{L}_{QAE} = 1 - \text{Tr}[\rho_B|0\rangle\langle 0|] \quad (3.11)$
```

where $ho_B = 	ext{Tr}_A[|\psiangle\langle\psi|U^\dagger]$ is the reduced density matrix of the discarded subsystem. Loss is minimized when the discarded subsystem is disentangled and in the reference state, allowing for successful compression.
