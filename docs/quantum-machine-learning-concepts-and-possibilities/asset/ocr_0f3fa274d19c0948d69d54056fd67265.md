# 6.2.8.1 Mixed states and Kraus operators

A mixed quantum state is described by a density matrix $ho(\theta)$, and its evolution can be modeled using quantum channels $\varepsilon$, which are completely positive and trace-preserving (CPTP) maps.

The general form of a channel acting on a state is

```
$\rho(\theta) = \sum_{k} K_k(\theta)\rho_0K_k^{\dagger}(	heta)$. (6.29)
```

where $[K_k(\theta)]$ are the Kraus operators of the channel, and may depend on variational parameters.

The observable expectation becomes

```
$f(\theta) = \text{Tr}[M\rho(\theta)] = \sum_{k} MK_k(\theta)\rho_0K_k^{\dagger}(	heta)$. (6.30)
```

The gradient of this function can be computed by differentiating the Kraus operators:

```
$\frac{\partial f}{\partial\theta} = \sum_{k} \text{Tr}\left[\frac{\partial K_k}{\partial\theta}\rho_0K_kM + K_k\rho_0\frac{\partial K_k^{\dagger}}{\partial\theta}M\right]$. (6.31)
```

This expression is exact but requires access to the functional form of the Kraus operators.

# 6.2.8.2 Noisy quantum circuits

When circuits are executed on hardware, noise acts between gates or at measurement. This leads to effective states of the form

```
$\rho_{out}(\theta) = \mathcal{N}_l\mathcal{U}_l(\theta)^*\dots\mathcal{N}_1\mathcal{U}_1(\theta)(\rho_0)$. (6.32)
```

where:

+   - $\mathcal{U}_i$ are unitary gates (parameterized)
- $\mathcal{N}_i$ are noise channels (e.g. depolarizing, amplitude damping).

In this context, gradient estimation methods that assume pure states become inaccurate. Shot noise, stochastic gate noise and hardware drift all contribute to gradient variance and bias. To combat this:

+   - Finite-difference and SPSA remain valid, as they make no assumption about the internal circuit.
