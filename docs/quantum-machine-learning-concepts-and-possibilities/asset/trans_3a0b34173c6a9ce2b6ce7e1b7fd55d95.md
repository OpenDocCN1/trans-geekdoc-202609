# 关于系列丛

IOP 量子系列丛致力于汇集量子科学及其技术应用新兴领域的最前沿文本和参考书。该系列由领先专家编写，旨在面向已从事该领域或打算扩展该领域的研究生和研究人员。该系列寻求涵盖（但不限于）以下主题的出版：

- 量子生物学
- 量子通信
- 量子计算
- 量子控制
- 量子密码
- 量子工程
- 量子机器学习与智能
- 量子材料
- 量子计量学
- 量子光学
- 量子传感
- 量子模拟
- 量子软件、算法与代码
- 量子热力学
- 混合量子系统

在此可以在该系列近期出版的书单：https://iopscience.iop.org/bookListInfo/iop-series-in-quantum-technology。
