Machine Learning is the use of mathematical and statistical tools to recognize a pattern in a dataset. Mostly, it is used to perform tasks that are repetitive in nature and exhausting for humans. By far, it is the best method to approach Artificial Intelligence. Machine Learning process can be divided into 4 steps : ●       Collect and refine the dataset (labelled or unlabeled) ●       Choose a Machine Learning Algorithm ●       Train a Machine Learning model ●       Make predictions out of trained model There are three types of Machine Learning Algorithms: Supervised Machine Learning Algorithms: Those kinds of Machine Learning Algorithms where you use a collection of input-output pairs to make machines understand the relation between them. This collection of input-output pairs is called a labelled dataset. Applying that relation, the machine can then predict the output for a given unknown input.  (Don’t worry if you haven’t understood, just stay till the end, you’ll understand all.) Some of the examples of supervised Machine Learning Algorithms are: ●       Linear Regression ●       Artificial Neural Networks ●       Logistic Regression ●       Support Vector Machine ●       Naive Bayes Classifier, etc. Unsupervised Machine Learning Algorithms: Those kind of machine Learning Algorithms where you have to use unlabeled dataset to train a machine learning model are unsupervised machine learning algorithms. They are mostly used for classification and clustering tasks. Some of the examples of Unsupervised Machine Learning algorithms are: ●       K-means clustering ●       Autoencoders ●       Principal Component Analysis ●       Generative Adversarial Networks , etc. Reinforcement Learning Algorithms: This is a relatively new approach which works on a hit-and-trial method. There is a system of reward and punishment. The model performs random activities at initial stage and for each activity that didn’t provide a good outcome, it’ll get a negative point and vice versa. The model works to increase its points. After the process, the result is an optimal model. For example, let’s say you are learning cycling. Then, every time you fall, you realize that particular step used when you fell should not be used again i.e. punishment and every time you cycle without falling, you realize you should use that particular steps i.e. reward. After a few days of similar repetition, you will learn cycling. This is how reinforcement learning works. What is Deep Learning? It is the process of mapping the (linear) relation between input and output and using that to predict the output. A linear function looks like this, Y = mX + c Where X is the input and Y is the output. Using the data the algorithm is provided, it tries to estimate the value of m and c which would be used to find Y i.e. Output. Let’s say you have plotted some points on the graph. ![](rsrc23D.jpg)Fig 3-1. Data points Now, what Linear Regression does is try to fit the line that best suits these data points. ![](rsrc23E.jpg)Fig 3-2. Line fitted on data points To do this, the program generates a random value for m and c. Then, it takes input-output pairs to validate m and c. To validate, it uses mean squared error. For example, if you have (10,30) where 10 is X and 30 is Y. Then, with the randomly generated value of m and c, inputting 10 gives us 65 (it is an arbitrary value) but the actual output is 30. CHAPTER 6 Neural Networks In Chapter 1, we touched the surface of Deep learning and Neural Networks. Now, we have to dive a bit deeper. There’s one question that might arise in your mind. Structure of a Neural Network Don’t get panicked by seeing this figure. I will explain every bit of it. From the previous knowledge, you might have understood this neural network takes two inputs and gives one output. Each circle in the figure is called a node and as you can see in the figure, each node is connected with every other node of neighboring layers. You might be wondering what are those w1, w2, w3, …. Stuffs. They are weights of the network. Simply, each of them are the strength of the relationship between two nodes. In the figure, w1 determines the strength of the relationship between x1 and h1. Similarly, w2 determines that for x1 and h2 and so on. For example, if x1 is the amount of rainfall and h1 is the amount of crops grown, then w1 will be high because these two things are strongly related. Same applies to your brain as well. You remember some moments of your life clearly whereas you forget most of them. This is because you’ve been thinking about that moment and it made the relationship strong. So, you remember those moments. Whereas, you don’t think about other moments and gradually the relationship gets weaker and will be difficult for you to remember later on. Consider it as the fundamental thing that defines what decisions the neural network makes. Now, what are those b1, b2, b3? These are biases. Let’s say you have a factory. You get expenses from electricity, raw materials, etc. while your industry is running. But there are some fixed expenses that will occur even if you stop production for sometime. Those costs include land rent, employee salary, etc. From now on, Whenever I use W and B, W represents all the weights of the model i.e. w1, w2, w3, .... ,wn and B represents all the biases of the model i.e. b1, b2, b3, ..., bn. B and W changes throughout the training process to make the prediction better. So, B and W are called Parameters . Also, consider B as the c in the linear equation Y = mX + c. They are constant values which helps a line to deviate from the origin to fit the data better. (And of course, W is similar to m in the linear equation.) Now, let’s see what happens inside each node in a hidden layer (In this case, h1,h2 and h3). h1 = x1 \* w1 + x2 \* w4 + b1 h2 = x1 \* w2 + x2 \* w5 + b2 h3 = x1 \* w3 + x2 \* w6 + b3 And ŷ = h1 \* w7 + h2 \* w8 + h3 \* w9 As you can see, each input node is multiplied with the respective weight connecting it to a specific hidden layer node and added together with the bias. After that, those hidden layer nodes are multiplied with the weights connecting them with the output layer and added together. (Note: Output Layer doesn’t contain any bias. We’ll talk about it later.) By doing this, the data is moving in the forward direction i.e. from input node to hidden layer(s) to output layer. So, during training the neural network model, this process is called Forward Propagation . After it reaches the output layer, an output is generated i.e. ŷ. At first, W and B are all randomly generated. So, ŷ is also arbitrary. Now, The error/loss in the prediction is calculated by, Loss = (y - ŷ) ² For a better prediction, This loss has to be minimized to its least. For this, we have to change the values of the parameters (W and B). We do it by the process called Backward Propagation . ![](rsrc242.jpg)Fig 6-2. Backward Propagation algorithm The goal of taking derivatives of Loss (L) with each respective weight is to check how a small change in each weight affects the Loss. Let’s take w8 and see how it is updated. w8 ” = w8 - η \* dL/dw 8 Where, η = Learning Rate (LR). They are introduced to prevent a big change in weights. Let’s say dL/dw 8 \= 20\. This is a huge number and will change w 8 drastically. So, to minimize this, we can multiply it by some minimal value, let’s say 0.01. Then, it would only change the value of w 8 by 0.2. This is the function of Learning Rate. Similarly, every other weights and biases are updated. As you can see, the process moves backwards i.e. from output layer to hidden layer to input layer. So, this process is called Backward Propagation . Now, before diving into code, let’s learn about a few more things. Activation Function There’s one thing I haven’t told you yet. The actual non-linearity in the model is given by activation function. Previously, we wrote that, h1 = x1 \* w1 + x2 \* w4 + b1 h2 = x1 \* w2 + x2 \* w5 + b2 h3 = x1 \* w3 + x2 \* w6 + b3 But to provide non-linearity, what actually happens is, h1 = f (x1 \* w1 + x2 \* w4 + b1) h2 = f (x1 \* w2 + x2 \* w5 + b2) h3 = f (x1 \* w3 + x2 \* w6 + b3) Where, f(x) can be any activation function. CHAPTER 9 Recurrent Neural Network You all know Siri, Alexa, Bixby, and many other voice assistants. But how do they understand what you said? It turns out that they use Recurrent Neural Network. They are specialized in time series and sequential data. From the learnings we’ve had till now, you might know that the output of a simple neural network is not affected by previous input. If an image was predicted to be a dog, then every time you use that same image, the output is going to be the same regardless of what you’ve predicted before or after. But there are some cases where we need to take care of the previous input. Let’s say you want to do a stock market forecasting. But you can’t do that by treating the market price of each day as an independent input. Today’s market price is affected by yesterday’s and yesterday's is affected by a day before’s and so on. That’s where RNN comes handy. See it’s architecture. ![](rsrc24V.jpg)Fig. 9-1. RNN architecture (source: [Click Here](https://www.researchgate.net/figure/A-recurrent-neural-network-and-the-unfolding-architecture-U-V-and-W-are-the-weights-of_fig4_318991900) ) As you can see, The model has only one hidden neuron. The same network is recurring for every input. Hence, it is called recurrent neural network. For the input x t , the output from  x t-1 is used as a part of input and so on. This way, the sequence of the data is kept. Each and every output is influenced by previous input. The number of input passed recurrently is a time step. In the above figure, there are 3 time steps. Problems in RNN RNN seems very good. It’s applicable as well. But there’s one problem with it. During training it is prone to suffer from Vanishing/Exploding Gradient Problem . As we know that the update in weights during backpropagation is done by, ![](rsrc24W.jpg)Fig 9-2. Weights update (source: [Click Here](https://hmkcode.com/ai/backpropagation-step-by-step/) ) This is done for every timestep in RNN. So, subtracting the derivative from last time step to first time step, The first few layers are going to have either tiny weights or huge weights. This will result in the stopping of training. So, to overcome this problem, few variants of RNN were introduced. The most popular ones are LSTM and GRU. Long Short Term Memory (LSTM) To solve the Vanishing/Exploding Gradient problem in RNN, a modified architecture of RNN i.e. LSTM was introduced. The major idea of this architecture is the use of a thing called cell state . It travels throughout the network. It carries information along with it. To change the information in the cell state, LSTM uses the structure called gates . They are controlled by sigmoid function which gives output from 0 to 1. 0 means don’t let information flow and 1 means let every information flow . There are 2 types of gates. Forget gate decides what and how much information to erase from the cell state. Input gate decides what and how much new information to add to the cell state. That’s it for LSTM. We won’t go deeper into LSTM in this book. Language Fundamentals: Before learning about NLP, let's learn a bit about languages. A language consists of followings: ●       Syntax ●       Semantics ●       Pragmatics These are the things that define a language. Let's learn about them. Syntax: Syntax is a set of rules that defines the structure of a sentence. Semantics: It is the study of the sentence to find its meaning.
