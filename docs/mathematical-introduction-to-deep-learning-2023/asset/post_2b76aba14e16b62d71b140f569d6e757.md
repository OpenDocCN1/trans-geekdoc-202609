
(i) it holds that $c \leq L$,
(ii) it holds for all $\theta \in \mathbb{B}$, $\gamma \in [0, \infty)$ that

$\| \theta - \gamma(\nabla \mathscr{L})(\theta) - \vartheta \|^2 \leq (1 - 2\gamma c + \gamma^2 L^2) \| \theta - \vartheta \|^2$, (6.31)

(iii) it holds for all $\gamma \in (0, \frac{2c}{L^2})$ that $0 \leq 1 - 2\gamma c + \gamma^2 L^2 < 1$, and

(iv) it holds for all $\theta \in \mathbb{B}$, $\gamma \in [0, \frac{c}{L^2}]$ that

$\| \theta - \gamma(\nabla \mathscr{L})(\theta) - \vartheta \|^2 \leq (1 - c\gamma) \| \theta - \vartheta \|^2$. (6.32)

Proof of Lemma 6.1.8. First of all, note that (6.30) ensures that for all $\theta \in \mathbb{B}$, $\gamma \in [0, \infty)$ it holds that
$0 \leq \| \theta - \gamma(\nabla \mathscr{L})(\theta) - \vartheta \|^2 = \| (\theta - \vartheta) - \gamma(\nabla \mathscr{L})(\theta) \|^2$
$= \| \theta - \vartheta \|^2 - 2\gamma \langle (\theta - \vartheta), (\nabla \mathscr{L})(\theta) \rangle + \gamma^2 \| (\nabla \mathscr{L})(\theta) \|^2$
$\leq \| \theta - \vartheta \|^2 - 2\gamma c \| \theta - \vartheta \|^2 + \gamma^2 L^2 \| \theta - \vartheta \|^2$
$= (1 - 2\gamma c + \gamma^2 L^2) \| \theta - \vartheta \|^2$. (6.33)

This establishes item (ii). Moreover, note that the fact that $\mathbb{B} \setminus \{\vartheta\} \neq \emptyset$ and (6.33) assure that for all $\gamma \in [0, \infty)$ it holds that
$1 - 2\gamma c + \gamma^2 L^2 \geq 0$. (6.34)

Hence, we obtain that
$1 - \frac{c^2}{L^2} = 1 - \frac{2c^2}{L^2} + \frac{c^2}{L^2} = 1 - 2\bigl[\frac{c}{L}\bigr]c + \bigl[\frac{c}{L}\bigr]^2 L^2$
$= 1 - 2\bigl[\frac{c}{L^2}\bigr]c + \bigl[\frac{c}{L^2}\bigr]^2 L^2 \geq 0$. (6.35)

This implies that $\frac{c^2}{L^2} \leq 1$. Therefore, we obtain that $c^2 \leq L^2$. This establishes item (i). Furthermore, observe that (6.34) ensures that for all $\gamma \in (0, \frac{2c}{L^2})$ it holds that
$0 \leq 1 - 2\gamma c + \gamma^2 L^2 = 1 - \underbrace{\gamma(2c - \gamma L^2)}_{>0} < 1$. (6.36)

This proves item (iii). In addition, note that for all $\gamma \in [0, \frac{c}{L^2}]$ it holds that
$1 - 2\gamma c + \gamma^2 L^2 \leq 1 - 2\gamma c + \gamma \bigl[\frac{c}{L^2}\bigr]L^2 = 1 - c\gamma$. (6.37)

Combining this with (6.33) establishes item (iv). The proof of Lemma 6.1.8 is thus complete.

## 6.1.4 Error analysis for GD optimization

In this subsection we provide an error analysis for the GD optimization method. In particular, we show under suitable hypotheses (cf. Proposition 6.1.9 below) that the considered GD process converges to a local minimum point of the objective function of the considered optimization problem.

### 6.1.4.1 Error estimates for GD optimization

**Proposition 6.1.9** (Error estimates for the GD optimization method). Let $\mathfrak{d} \in \mathbb{N}$, $c$, $L \in (0, \infty)$, $r \in (0, \infty]$, $(\gamma_{n})_{n \in \mathbb{N}} \subseteq \left[0, \frac{2c}{L^{2}}\right]$, $\vartheta \in \mathbb{R}^{\mathfrak{d}}$, $\mathbb{B} = \{w \in \mathbb{R}^{\mathfrak{d}}: \|w - \vartheta\|_{2} \leq r\}$, $\xi \in \mathbb{B}$, $\mathcal{L} \in C^{1}(\mathbb{R}^{\mathfrak{d}}, \mathbb{R})$ satisfy for all $\theta \in \mathbb{B}$ that

$\langle \theta - \vartheta, (\nabla \mathcal{L})(\theta) \rangle \geq c \|\theta - \vartheta\|_{2}^{2} \quad \text{and} \quad \| (\nabla \mathcal{L})(\theta) \|_{2} \leq L \|\theta - \vartheta\|_{2}, \quad (6.47)$

and let $\Theta : \mathbb{N}_{0} \to \mathbb{R}^{\mathfrak{d}}$ satisfy for all $n \in \mathbb{N}$ that

$\Theta_{0} = \xi \quad \text{and} \quad \Theta_{n} = \Theta_{n - 1} - \gamma_{n}(\nabla \mathcal{L})(\Theta_{n - 1}) \quad (6.48)$

(cf. Definitions 1.4.7 and 3.3.4). Then

- (i) it holds that $\{\theta \in \mathbb{B} : \mathcal{L}(\theta) = \inf_{w \in \mathbb{B}} \mathcal{L}(w)\} = \{\vartheta\}$,
- (ii) it holds for all $n \in \mathbb{N}$ that $0 \leq 1 - 2c\gamma_{n} + (\gamma_{n})^{2}L^{2} \leq 1$,
- (iii) it holds for all $n \in \mathbb{N}$ that $\|\Theta_{n} - \vartheta\|_{2} \leq (1 - 2c\gamma_{n} + (\gamma_{n})^{2}L^{2})^{1/2}\|\Theta_{n - 1} - \vartheta\|_{2} \leq r$,
- (iv) it holds for all $n \in \mathbb{N}_{0}$ that

$\|\Theta_{n} - \vartheta\|_{2} \leq \left[ \prod_{k = 1}^{n} (1 - 2c\gamma_{k} + (\gamma_{k})^{2}L^{2})^{1/2} \right]\|\xi - \vartheta\|_{2}, \quad (6.49)$

and
- (v) it holds for all $n \in \mathbb{N}_{0}$ that

$0 \leq \mathcal{L}(\Theta_{n}) - \mathcal{L}(\vartheta) \leq \frac{L}{2}\|\Theta_{n} - \vartheta\|_{2}^{2} \leq \frac{L}{2}\left[ \prod_{k = 1}^{n} (1 - 2c\gamma_{k} + (\gamma_{k})^{2}L^{2}) \right]\|\xi - \vartheta\|_{2}^{2}. \quad (6.50)$
