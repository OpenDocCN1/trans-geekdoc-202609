# 6.1. GD optimization

$\mathcal{S}$ proves item **(i)**. Furthermore, note that **(6.108)** assures that for all $v = (v_1, v_2, \ldots, v_\mathfrak{d}) \in \mathbb{R}^\mathfrak{d}$ it holds that

```
$$\begin{aligned} \|\Lambda v\|_2 = \left[ \sum_{i=1}^{\mathfrak{d}} |\Lambda_{i,i}v_i|^2 \right]^{1/2} &\leq \left[ \sum_{i=1}^{\mathfrak{d}} \max\left\{ |\Lambda_{1,1}|^2, \ldots, |\Lambda_{\mathfrak{d},\mathfrak{d}}|^2 \right\} |v_i|^2 \right]^{1/2} \\ &= \left[ \max\left\{ |\Lambda_{1,1}|, \ldots, |\Lambda_{\mathfrak{d},\mathfrak{d}}| \right\}^2 \|v\|_2^2 \right]^{1/2} \tag{6.110} \\ &= \max\left\{ |\Lambda_{1,1}|, \ldots, |\Lambda_{\mathfrak{d},\mathfrak{d}}| \right\} \|v\|_2 \\ &= \left( \max_{\lambda \in \mathcal{S}} |\lambda| \right) \|v\|_2 \end{aligned}$$
```

(cf. Definition **3.3.4**). The fact that $O$ is an orthogonal matrix and the fact that $A = O \Lambda O^*$ therefore imply that for all $v \in \mathbb{R}^\mathfrak{d}$ it holds that

```
$$\begin{aligned} \|Av\|_2 = \|O \Lambda O^*v\|_2 &= \|\Lambda O^*v\|_2 \\ &\leq \left( \max_{\lambda \in \mathcal{S}} |\lambda| \right) \|O^*v\|_2 \tag{6.111} \\ &= \left( \max_{\lambda \in \mathcal{S}} |\lambda| \right) \|v\|_2. \end{aligned}$$
```

This implies that

```
$$\sup_{v \in \mathbb{R}^\mathfrak{d} \setminus \{0\}} \left[ \frac{\|Av\|_2}{\|v\|_2} \right] \leq \sup_{v \in \mathbb{R}^\mathfrak{d} \setminus \{0\}} \left[ \frac{\left( \max_{\lambda \in \mathcal{S}} |\lambda| \right) \|v\|_2}{\|v\|_2} \right] = \max_{\lambda \in \mathcal{S}} |\lambda|. \tag{6.112}$$
```

In addition, note that the fact that $\mathcal{S} = \left\{ \Lambda_{1,1}, \Lambda_{2,2}, \ldots, \Lambda_{\mathfrak{d},\mathfrak{d}} \right\}$ ensures that there exists $j \in \{1, 2, \ldots, \mathfrak{d}\}$ such that

```
$$|\Lambda_{j,j}| = \max_{\lambda \in \mathcal{S}} |\lambda|. \tag{6.113}$$
```

Next observe that the fact that $A = O \Lambda O^*$, the fact that $O$ is an orthogonal matrix, and **(6.113)** imply that

```
$$\begin{aligned} \sup_{v \in \mathbb{R}^\mathfrak{d} \setminus \{0\}} \left[ \frac{\|Av\|_2}{\|v\|_2} \right] &\geq \left[ \frac{\|AOe_j\|_2}{\|Oe_j\|_2} \right] = \|O \Lambda O^* O e_j\|_2 = \|O \Lambda e_j\|_2 \tag{6.114} \\ &= \|\Lambda e_j\|_2 = \|\Lambda_{j,j} e_j\|_2 = |\Lambda_{j,j}| = \max_{\lambda \in \mathcal{S}} |\lambda|. \end{aligned}$$
```

Combining this and **(6.112)** establishes item **(ii)**. It thus remains to prove item **(iii)**. For this note that **(6.108)** ensures that for all $v = (v_1, v_2, \ldots, v_\mathfrak{d}) \in \mathbb{R}^\mathfrak{d}$ it holds that

```
$$\begin{aligned} \langle v, \Lambda v \rangle &= \sum_{i=1}^{\mathfrak{d}} \Lambda_{i,i} |v_i|^2 \leq \sum_{i=1}^{\mathfrak{d}} \max\{\Lambda_{1,1}, \ldots, \Lambda_{\mathfrak{d},\mathfrak{d}}\} |v_i|^2 \tag{6.115} \\ &= \max\{\Lambda_{1,1}, \ldots, \Lambda_{\mathfrak{d},\mathfrak{d}}\} \|v\|_2^2 = \max(\mathcal{S}) \|v\|_2^2 \end{aligned}$$
```
