This shows that for all $n \in \mathbb{N}_0$ it holds that

$\|\Theta_n-\vartheta\|_2^2=\overset{\flat}{\sum}_{i=1}^{\flat}\left|\Theta_n^{(i)}-\vartheta_i\right|^2=\overset{\flat}{\sum}_{i=1}^{\flat}\left[\left|1-\gamma\lambda_i\right|^{2n}\left|\xi_i-\vartheta_i\right|^2\right]$

$\geq \left[\min \left\{\left|\xi_1-\vartheta_1\right|^2, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|^2\right\}\right]\left[\overset{\flat}{\sum}_{i=1}^{\flat}\left|1-\gamma\lambda_i\right|^{2n}\right]$

$\geq\left[\min \left\{\left|\xi_1-\vartheta_1\right|^2, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|^2\right\}\right]\left[\max \left\{\left|1-\gamma\lambda_1\right|^{2n}, \ldots,\left|1-\gamma\lambda_{\flat}\right|^{2n}\right\}\right]$

$=\left[\min \left\{\left|\xi_1-\vartheta_1\right|, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|\right\}\right]^2\left[\max \left\{\left|1-\gamma\lambda_1\right|, \ldots,\left|1-\gamma\lambda_{\flat}\right|\right\}\right]^{2n}$

(cf. Definition 3.3.4). Furthermore, note that

$\max \left\{\left|1-\gamma\lambda_1\right|, \ldots,\left|1-\gamma\lambda_{\flat}\right|\right\}\geq \max \left\{\left|1-\gamma\lambda_{\ell}\right|,\left|1-\gamma\lambda_i\right|\right\}$

$=\max \left\{\left|1-\gamma \mathcal{K}\right|,\left|1-\gamma \kappa\right|\right\}=\max \left\{1-\gamma \mathcal{K}, \gamma \mathcal{K}-1, 1-\gamma \kappa, \gamma \kappa-1\right\}$

$=\max \left\{\gamma \mathcal{K}-1, 1-\gamma \kappa\right\}.$

In addition, observe that for all $\alpha \in\left(-\infty,\frac{2}{\mathcal{K}+\kappa}\right)$ it holds that

$\max \left\{\alpha \mathcal{K}-1, 1-\alpha \kappa\right\} \geq 1-\alpha \kappa \geq 1-\left[\frac{2}{\mathcal{K}+\kappa}\right]_{\kappa}=\frac{\mathcal{K}+\kappa-2 \kappa}{\mathcal{K}+\kappa}=\frac{\mathcal{K}-\kappa}{\mathcal{K}+\kappa}.$

Moreover, note that for all $\alpha \in\left[\frac{2}{\mathcal{K}+\kappa}, \infty\right)$ it holds that

$\max \left\{\alpha \mathcal{K}-1, 1-\alpha \kappa\right\} \geq \alpha \mathcal{K}-1 \geq\left[\frac{2}{\mathcal{K}+\kappa}\right]_{\mathcal{K}}-1=\frac{2 \mathcal{K}-(\mathcal{K}+\kappa)}{\mathcal{K}+\kappa}=\frac{\mathcal{K}-\kappa}{\mathcal{K}+\kappa}.$

Combining this, (6.241), and (6.242) proves that

$\max \left\{\left|1-\gamma\lambda_1\right|, \ldots,\left|1-\gamma\lambda_{\flat}\right|\right\} \geq \max \left\{\gamma \mathcal{K}-1, 1-\gamma \kappa\right\} \geq \frac{\mathcal{K}-\kappa}{\mathcal{K}+\kappa} \geq 0.$

This and (6.240) demonstrate that for all $n \in \mathbb{N}_0$ it holds that

$\left\|\Theta_n-\vartheta\right\|_2 \geq\left[\max \left\{\left|1-\gamma\lambda_1\right|, \ldots,\left|1-\gamma\lambda_{\flat}\right|\right\}\right]^n\left[\min \left\{\left|\xi_1-\vartheta_1\right|, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|\right\}\right]$

$\geq\left[\max \left\{\gamma \mathcal{K}-1, 1-\gamma \kappa\right\}\right]^n\left[\min \left\{\left|\xi_1-\vartheta_1\right|, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|\right\}\right]$

$\geq \left[\frac{\mathcal{K}-\kappa}{\mathcal{K}+\kappa}\right]^n\left[\min \left\{\left|\xi_1-\vartheta_1\right|, \ldots,\left|\xi_{\flat}-\vartheta_{\flat}\right|\right\}\right].$

The proof of Lemma 6.3.8 is thus complete.
