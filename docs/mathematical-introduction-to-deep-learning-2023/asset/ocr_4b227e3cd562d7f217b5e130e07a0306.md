**Corollary 13.2.5.** Let $(E, \delta)$ be a non-empty separable metric space, let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space, let $M \in \mathbb{N}$, for every $x \in E$ let $Y_{x, m}: \Omega \rightarrow \mathbb{R}$, $m \in \{1, 2, \ldots, M\}$, be independent random variables with $\mathbb{E}\left[|Y_{x, 1}| + |Y_{x, 2}| + \cdots + |Y_{x, m}|\right] < \infty$, let $L \in (0, \infty)$ satisfy for all $x, y \in E$, $m \in \{1, 2, \ldots, M\}$ that $|Y_{x, m} - Y_{y, m}| \leq L \delta(x, y)$, and for every $x \in E$ let $Z_{x}: \Omega \rightarrow \mathbb{R}$ satisfy

```
Z_x = \frac{1}{M} \left[ \sum_{m=1}^{M} Y_{x,m} \right]. \tag{13.35}
```

Then

+   (i) it holds for all $x \in E$ that $\mathbb{E}[|Z_x|] < \infty$.

+   (ii) it holds that $\Omega \ni \omega \supset \sup_{x \in E}|Z_x(\omega) - \mathbb{E}[Z_x]| \in [0, \infty)$ is $\mathcal{F}/\mathcal{B}([0, \infty))$-measurable, and

+   (iii) it holds for all $p \in [2, \infty)$, $c \in (0, \infty)$ that

```
\begin{aligned}&\left(\mathbb{E}\left[\sup_{x \in E}|Z_x - \mathbb{E}[Z_x]|^{p}\right]\right)^{1 / p} \\ & \leq \frac{2 \sqrt{p-1}}{\sqrt{M}} \left(\mathcal{C}^{(E, \delta), \frac{c \sqrt{p-1}}{L \sqrt{M}}} / \frac{c \sqrt{p-1}}{L \sqrt{M}}\right)^{1 / p} \left[c + \sup_{x \in E} \max_{m \in \{1, 2, \ldots, M\}}\left(\mathbb{E}\left[|Y_{x, m} - \mathbb{E}[Y_{x, m}]|^{p}\right]\right)^{1 / p}\right] \tag{13.36}\end{aligned}
```

(cf. Definition 4.3.2).

**Proof of Corollary 13.2.5.** Observe that Lemma 13.2.4 establishes items (i) and (ii). Note that Lemma 13.2.4 (applied with $r \frown \frac{c \sqrt{p-1}}{(L \sqrt{M})}$ for $c \in (0, \infty)$ in the notation of Lemma 13.2.4) demonstrates that for all $p \in [2, \infty)$, $c \in (0, \infty)$ it holds that

```
\begin{aligned}&\left(\mathbb{E}\left[\sup_{x \in E}|Z_x - \mathbb{E}[Z_x]|^{p}\right]\right)^{1 / p} \\ & \leq 2 \left(\mathcal{C}^{(E, \delta), \frac{c \sqrt{p-1}}{L \sqrt{M}}} / \frac{c \sqrt{p-1}}{L \sqrt{M}}\right)^{1 / p}\left[\frac{L c \sqrt{p-1}}{L \sqrt{M}} \\ & \qquad + \frac{\sqrt{p-1}}{\sqrt{M}}\left(\sup_{x \in E} \max_{m \in \{1, 2, \ldots, M\}}\left(\mathbb{E}\left[|Y_{x, m} - \mathbb{E}[Y_{x, m}]|^{p}\right]\right)^{1 / p}\right)\right] \\ & = \frac{2 \sqrt{p-1}}{\sqrt{M}} \left(\mathcal{C}^{(E, \delta), \frac{c \sqrt{p-1}}{L \sqrt{M}}} / \frac{c \sqrt{p-1}}{L \sqrt{M}}\right)^{1 / p}\left[c + \sup_{x \in E} \max_{m \in \{1, 2, \ldots, M\}}\left(\mathbb{E}\left[|Y_{x, m} - \mathbb{E}[Y_{x, m}]|^{p}\right]\right)^{1 / p}\right] \tag{13.37}\end{aligned}
```

(cf. Definition 4.3.2). This proves item (iii). The proof of Corollary 13.2.5 is thus complete.
