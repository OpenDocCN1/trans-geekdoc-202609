($ii$) there exist $\epsilon \in (0, 1)$, $C \in \mathbb{R}$ such that for all $n \in \mathbb{N}_0$ it holds that

and

($iii$) there exist $\epsilon \in (0, 1)$, $C \in \mathbb{R}$ such that for all $n \in \mathbb{N}_0$ it holds that

**Proof of Corollary 6.1.12.** Throughout this proof, let $\alpha, \beta \in \mathbb{R}$ satisfy

$0 < \alpha < \liminf_{n \rightarrow \infty} \gamma_n \le \limsup \gamma_n < \beta < \frac{2c}{L^2}$ (6.82)

(cf. (6.78)), let $m \in \mathbb{N}$ satisfy for all $n \in \mathbb{N}$ that $\gamma_{m+n} \in [\alpha, \beta]$, and let $h: \mathbb{R} \rightarrow \mathbb{R}$ satisfy for all $t \in \mathbb{R}$ that

$h(t) = 1 - 2ct + t^2 L^2.$ (6.83)

Observe that (6.77) and item (ii) in Lemma 5.6.8 prove item (i). In addition, observe that the fact that for all $t \in \mathbb{R}$ it holds that $h'(t) = -2c + 2tL^2$ implies that for all $t \in (-\infty, \frac{c}{L^2}]$ it holds that

$h'(t) \le -2c + 2[\frac{c}{L^2}] L^2 = 0.$ (6.84)

The fundamental theorem of calculus hence assures that for all $t \in [\alpha, \beta] \cap [0, \frac{c}{L^2}]$ it holds that

$h(t) = h(\alpha) + \int_\alpha^t h'(s) \mathrm{d}s \le h(\alpha) + \int_\alpha^t 0 \mathrm{d}s = h(\alpha) \le \max\{h(\alpha), h(\beta)\}.$ (6.85)

Furthermore, observe that the fact that for all $t \in \mathbb{R}$ it holds that $h'(t) = -2c + 2tL^2$ implies that for all $t \in [\frac{c}{L^2}, \infty)$ it holds that

$h'(t) \le h'(\frac{c}{L^2}) = -2c + 2[\frac{c}{L^2}] L^2 = 0.$ (6.86)

The fundamental theorem of calculus hence ensures that for all $t \in [\alpha, \beta] \cap [\frac{c}{L^2}, \infty)$ it holds that

$\max\{h(\alpha), h(\beta)\} \ge h(\beta) = h(t) + \int_t^\beta h'(s) \mathrm{d}s \ge h(t) + \int_t^\beta 0 \mathrm{d}s = h(t).$ (6.87)

Combining this and (6.85) establishes that for all $t \in [\alpha, \beta]$ it holds that

$h(t) \le \max\{h(\alpha), h(\beta)\}.$ (6.88)
