*Proof of Corollary 6.3.4*. Throughout this proof, let $\mathbf{m}\colon\mathbb{N}_{0}\to\mathbb{R}^{\mathfrak{d}}$ satisfy for all $n\in\mathbb{N}$ that $\mathbf{m}_{0}=0\quad\text{and}\quad\mathbf{m}_{n}=\alpha_{n}\mathbf{m}_{n-1}+(1-\alpha_{n})\mathcal{G}(\Theta_{n-1}).$ (6.208)

Note that (6.204) implies item (i). Observe that (6.204), (6.208), and Lemma 6.3.3 assure that for all $n\in\mathbb{N}_{0}$ it holds that $\mathbf{m}_{n}=\sum_{k=0}^{n-1}a_{n,k}\mathcal{G}(\Theta_{k})\quad\text{and}\quad\sum_{k=0}^{n-1}a_{n,k}=1-\prod_{k=1}^{n}\alpha_{k}.$ (6.209)

This proves item (ii). Note that (6.189), (6.190), (6.191), (6.208), and (6.209) demonstrate that for all $n\in\mathbb{N}$ it holds that $\Theta_{n}=\Theta_{n-1}-\gamma_{n}\mathbf{m}_{n}=\Theta_{n-1}-\gamma_{n}\Big[\sum_{k=0}^{n-1}a_{n,k}\mathcal{G}(\Theta_{k})\Big].$ (6.210)

This establishes item (iii). The proof of Corollary 6.3.4 is thus complete. $\square$
