ℰ[‖X1‖2] < ∞ demonstrate that for all n ∈ ℕ it holds that

```
ℰ[‖Θn − ℰ[X1]‖₂²] = ℰ[‖(1/n)(X1 + X2 + ... + Xn) − ℰ[X1]‖₂²]
= ℰ[‖(1/n)∑_{k=1}^{n}(Xk − ℰ[X1])‖₂²]
= (1/n²)(ℰ[‖∑_{k=1}^{n}(Xk − ℰ[Xk])‖₂²])
= (1/n²)∑_{k=1}^{n}ℰ[‖Xk − ℰ[Xk]‖₂²]
= (1/n²)[nℰ[‖X1 − ℰ[X1]‖₂²]]
= ℰ[‖X1 − ℰ[X1]‖₂²]/n.
```

This establishes item **(iii)**. It thus remains to prove item **(iv)**. For this note that **(7.88)** and **(7.94)** ensure that for all n ∈ ℕ it holds that

```
ℰ[𝓛(Θn) − 𝓛(ℰ[X1])] = ℰ[(1/2)(‖ℰ[X1] − X1‖₂² + ‖Θn − ℰ[X1]‖₂²)]
− (1/2)(ℰ[‖ℰ[X1] − X1‖₂²] + ‖ℰ[X1] − ℰ[X1]‖₂²)
= (1/2)ℰ[‖Θn − ℰ[X1]‖₂²]
= (1/2)ℰ[‖X1 − ℰ[X1]‖₂²]n^{-1}.
```

This proves item **(iv)**. The proof for Example **7.2.14** is thus complete. □
