Combining this and (6.224) ensures that for all $n \in \mathbb{N}$, $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that

$\Theta_{n}^{(i)}-\vartheta_{i}=\Theta_{n-1}^{(i)}-\frac{2}{(\kappa+\kappa)}\big(\frac{\partial \ell}{\partial \vartheta_{i}}\big)_{n-1}(\Theta_{n-1})-\vartheta_{i}$

$=\Theta_{n-1}^{(i)}-\vartheta_{i}-\frac{2}{(\kappa+\kappa)}\big[\lambda_{i}(\Theta_{n-1}^{(i)}-\vartheta_{i})\big]$

$=\big(1-\frac{2\lambda_{i}}{(\kappa+\kappa)}\big)(\Theta_{n-1}^{(i)}-\vartheta_{i}).$ (6.227)

Hence, we obtain that for all $n \in \mathbb{N}$ it holds that

$\|\Theta_{n}-\vartheta\|_{2}^{2}=\sum_{i=1}^{\mathfrak{d}}\|\Theta_{n}^{(i)}-\vartheta_{i}\|^{2}$

$=\sum_{i=1}^{\mathfrak{d}}\big[1-\frac{2\lambda_{i}}{(\kappa+\kappa)}\big]^{2}\big[\|\Theta_{n-1}^{(i)}-\vartheta_{i}\|^{2}\big]$

$\leq\big[\max\big\{\big[1-\frac{2\lambda_{i}}{(\kappa+\kappa)}\big]^{2},\dots,\big[1-\frac{2\lambda_{\mathfrak{d}}}{(\kappa+\kappa)}\big]^{2}\big\}\big]\bigg[\sum_{i=1}^{\mathfrak{d}}\|\Theta_{n-1}^{(i)}-\vartheta_{i}\|^{2}\bigg]$

$=\big[\max\big\{\big|1-\frac{2\lambda_{i}}{(\kappa+\kappa)}\big|,\dots,\big|1-\frac{2\lambda_{\mathfrak{d}}}{(\kappa+\kappa)}\big|\big\}\big]^{2}\|\Theta_{n-1}-\vartheta\|_{2}^{2}$ (6.228)

(cf. Definition 3.3.4). Moreover, note that the fact that for all $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that $\lambda_{i} \geq \kappa$ implies that for all $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that

$1-\frac{2\lambda_{i}}{(\kappa+\kappa)} \leq 1-\frac{2\kappa}{(\kappa+\kappa)} = \frac{\kappa+\kappa-2\kappa}{\kappa+\kappa} = \frac{\kappa-\kappa}{\kappa+\kappa} \geq 0.$ (6.229)

In addition, observe that the fact that for all $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that $\lambda_{i} \leq \mathcal{K}$ implies that for all $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that

$1-\frac{2\lambda_{i}}{(\kappa+\kappa)} \geq 1-\frac{2\mathcal{K}}{(\kappa+\kappa)} = \frac{\kappa+\kappa-2\mathcal{K}}{(\kappa+\kappa)} = -\big[\frac{\mathcal{K}-\kappa}{\kappa+\kappa}\big] \leq 0.$ (6.230)

This and (6.229) ensure that for all $i \in \{1, 2, \dots, \mathfrak{d}\}$ it holds that

$\big|1-\frac{2\lambda_{i}}{(\kappa+\kappa)}\big| \leq \frac{\mathcal{K}-\kappa}{\kappa+\kappa}.$ (6.231)

Combining this with (6.228) demonstrates that for all $n \in \mathbb{N}$ it holds that

$\|\Theta_{n}-\vartheta\|_{2} \leq \big[\max\big\{\big[1-\frac{2\lambda_{i}}{\kappa+\kappa}\big|,\dots,\big|1-\frac{2\lambda_{\mathfrak{d}}}{\kappa+\kappa}\big\}\big]\|\Theta_{n-1}-\vartheta\|_{2}$

$\leq \big[\frac{\mathcal{K}-\kappa}{\kappa+\kappa}\big]\|\Theta_{n-1}-\vartheta\|_{2}.$ (6.232)

Induction therefore establishes that for all $n \in \mathbb{N}_{0}$ it holds that

$\|\Theta_{n}-\vartheta\|_{2} \leq \big[\frac{\mathcal{K}-\kappa}{\kappa+\kappa}\big]^{n}\|\Theta_{0}-\vartheta\|_{2} = \big[\frac{\mathcal{K}-\kappa}{\kappa+\kappa}\big]^{n}\|\xi-\vartheta\|_{2}.$ (6.233)

The proof of Lemma 6.3.7 is thus complete. $\square$
