and

```
\|\Theta_{t} - \psi\|_{2} \leq \mathfrak{C}(1 - \alpha)^{-1}(1 + \mathfrak{C}^{-2}(t - \delta_{n}))^{\alpha - 1}
= \left[\left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{\alpha - 1}}(1 + \mathfrak{C}^{-2}(t - \delta_{n}))\right]^{\alpha - 1}
= \left[\left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{\alpha - 1}}\left[1 + \mathfrak{C}^{-2}(\tau - \delta_{n})\right] + \left[\left(\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{1 - \alpha}}\mathfrak{C}^{2}\right]^{-1}(t - \tau)\right]^{\alpha - 1} . (9.177)
```

Next let $\mathfrak{C}$, $\tau \in (0, \infty)$ satisfy

```
\mathfrak{C} = \max\{\mathfrak{C}^{2}, \left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{1 - \alpha}}\mathfrak{C}^{2}\} \quad \text{and} \quad \tau = \delta_{n} + \mathfrak{C}^{2}\left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{1 - \alpha}} . (9.178)
```

Observe that (9.176), (9.177), and (9.178) demonstrate for all $t \in [\tau, \infty)$ that

```
0 \leq \mathcal{L}(\Theta_{t}) - \mathcal{L}(\psi) \leq (1 + \mathfrak{C}^{-2}(t - \tau))^{-1} \leq (1 + \mathfrak{C}^{-1}(t - \tau))^{-1} (9.179)
```

and

```
\|\Theta_{t} - \psi\|_{2} \leq \left[\left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{\alpha - 1}}\left[1 + \mathfrak{C}^{-2}(\tau - \delta_{n})\right] + \mathfrak{C}^{-1}(t - \tau)\right]^{\alpha - 1}
= \left[\left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{\alpha - 1}}\left[1 + \left[\mathfrak{C}(1 - \alpha)^{-1}\right]^{\frac{1}{1 - \alpha}}\right] + \mathfrak{C}^{-1}(t - \tau)\right]^{\alpha - 1}
\leq \left[1 + \mathfrak{C}^{-1}(t - \tau)\right]^{\alpha - 1} . (9.180)
```

The proof of Proposition 9.11.4 is thus complete.

# **Corollary 9.11.5.** Let $\varrho \in \mathbb{N}$, $\Theta \in C([0, \infty), \mathbb{R}^{\varrho})$, $\mathcal{L} \in C(\mathbb{R}^{\varrho}, \mathbb{R})$, let $\mathfrak{G}: \mathbb{R}^{\varrho} \rightarrow \mathbb{R}^{\varrho}$ be $\mathcal{B}(\mathbb{R}^{\varrho})/\mathcal{B}(\mathbb{R}^{\varrho})$-measurable, assume that for all $\vartheta \in \mathbb{R}^{\varrho}$ there exist $\varepsilon, \mathfrak{C} \in (0, \infty)$, $\alpha \in (0, 1)$ such that for all $\theta \in \mathbb{R}^{\varrho}$ with $\|\theta - \vartheta\|_{2} < \varepsilon$ it holds that

```
|\mathcal{L}(\theta) - \mathcal{L}(\vartheta)|^{\alpha} \leq \mathfrak{C}\|\mathfrak{G}(\vartheta)\|_{2}, (9.181)
```

assumes for all $t \in [0, \infty)$ that

```
\mathcal{L}(\Theta_{t}) = \mathcal{L}(\Theta_{0}) - \int_{0}^{t}\|\mathfrak{G}(\Theta_{s})\|_{2}^{2}\mathrm{d}s \quad \text{and} \quad \Theta_{t} = \Theta_{0} - \int_{0}^{t}\mathfrak{G}(\Theta_{s})\mathrm{d}s, (9.182)
```

and assume $\liminf_{t \rightarrow \infty}\|\Theta_{t}\|_{2} < \infty$ (cf. Definition 3.3.4). Then there exist $\vartheta \in \mathbb{R}^{\varrho}$, $\mathfrak{C}$, $\beta \in (0, \infty)$ which satisfy for all $t \in [0, \infty)$ that

```
\|\Theta_{t} - \vartheta\|_{2} \leq \mathfrak{C}(1 + t)^{-\beta} \quad \text{and} \quad 0 \leq \mathcal{L}(\Theta_{t}) - \mathcal{L}(\vartheta) \leq \mathfrak{C}(1 + t)^{-1} . (9.183)
```
