Furthermore, note that the assumption that for all $x \in \mathbb{R}$ it holds that $\mathscr{L}(x) = \max\{x, c\}$ ensures that for all $a \in (1, \infty)$, $h \in (0, \infty)$ it holds that

```
\begin{equation}\frac{\mathscr{L}(c+h)-\mathscr{L}(c)-ah}{|h|} = \frac{(c+h)-c-ah}{h} = 1-a<0. \qquad \qquad (9.310)\end{equation}
```

Moreover, observe that the assumption that for all $x \in \mathbb{R}$ it holds that $\mathscr{L}(x) = \max\{x, c\}$ shows that for all $a, h \in (-\infty, 0)$, it holds that

```
\begin{equation}\frac{\mathscr{L}(c+h)-\mathscr{L}(c)-ah}{|h|} = \frac{c-c-ah}{-h} = a<0. \qquad \qquad (9.311)\end{equation}
```

Combining this with $(9.310)$ demonstrates that

```
\begin{equation}(\mathcal{D}\mathscr{L})(c) \subseteq [0,1]. \qquad \qquad (9.312)\end{equation}
```

This and $(9.309)$ establish item (iii). The proof of Lemma $9.15.4$ is thus complete. $\square$
