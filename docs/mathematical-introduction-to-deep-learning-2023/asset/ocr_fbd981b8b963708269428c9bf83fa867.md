let $\mathcal{L}: \mathbb{R}^9 \rightarrow \mathbb{R}$ and $\mathscr{G}: \mathbb{R}^9 \rightarrow \mathbb{R}^9$ satisfy for all $U \in \{V \subseteq \mathbb{R}^9: V\text{ is open}\}$, $\theta \in U$ with $\mathcal{L}\vert_U \in C^1(U, \mathbb{R})$ that

and let $\Theta$ be the bias-adjusted momentum GD process for the objective function $\mathcal{L}$ with generalized gradient $\mathscr{G}$, learning rates $(\gamma_n)_{n \in \mathbb{N}}$, momentum decay factors $(\alpha_n)_{n \in \mathbb{N}}$, and initial value $\xi$ (cf. Definition 6.3.5). Then

+   (ii) it holds for all $n \in \mathbb{N}$ that
$$\sum_{k=0}^{n-1}a_{n,k} = 1,$$ (6.217)

and

+   (iii) it holds for all $n \in \mathbb{N}$ that
$$\Theta_n = \Theta_{n-1} - \gamma_n\left[\sum_{k=0}^{n-1}a_{n,k}\mathscr{G}(\Theta_k)\right].$$ (6.218)

Proof of Corollary 6.3.6. Throughout this proof, let $\mathbf{m}: \mathbb{N}_0 \rightarrow \mathbb{R}^9$ satisfy for all $n \in \mathbb{N}$ that
$$\mathbf{m}_0 = 0 \quad \text{and} \quad \mathbf{m}_n = \alpha_n\mathbf{m}_{n-1} + (1-\alpha_n)\mathscr{G}(\Theta_{n-1})$$ (6.219)
and let $(b_{n,k})_{(n,k) \in (\mathbb{N}_0)^2} \subseteq \mathbb{R}$ satisfy for all $n \in \mathbb{N}$, $k \in \{0, 1, \ldots, n-1\}$ that
$$b_{n,k} = (1-\alpha_{k+1})\left[\prod_{l=k+2}^n\alpha_l\right],$$ (6.220)
Observe that (6.215) implies item (i). Note that (6.215), (6.219), (6.220), and Lemma 6.3.3 assure that for all $n \in \mathbb{N}$ it holds that
$$\mathbf{m}_n = \sum_{k=0}^{n-1}b_{n,k}\mathscr{G}(\Theta_k) \quad \text{and} \quad \sum_{k=0}^{n-1}a_{n,k} = \frac{\sum_{k=0}^{n-1}b_{n,k}}{1-\prod_{l=1}^n\alpha_l} = \frac{1-\prod_{l=1}^n\alpha_l}{1-\prod_{l=1}^n\alpha_l} = 1.$$ (6.221)
This proves item (ii). Observe that (6.212), (6.213), (6.214), (6.219), and (6.221) demonstrate that for all $n \in \mathbb{N}$ it holds that
$$\Theta_n = \Theta_{n-1} - \frac{\gamma_n\mathbf{m}_n}{1-\prod_{l=1}^n\alpha_l} = \Theta_{n-1} - \gamma_n\left[\sum_{k=0}^{n-1}\frac{b_{n,k}}{1-\prod_{l=1}^k\alpha_l}\mathscr{G}(\Theta_k)\right]$$
$$= \Theta_{n-1} - \gamma_n\left[\sum_{k=0}^{n-1}a_{n,k}\mathscr{G}(\Theta_k)\right].$$ (6.222)
This establishes item (iii). The proof of Corollary 6.3.6 is thus complete.
