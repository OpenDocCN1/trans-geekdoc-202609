*Proof of Proposition 9.11.4.* Observe that (9.166) implies that $[0, \infty) \ni t \mapsto \mathscr{L}(\Theta_t) \in \mathbb{R}$ is non-increasing. Therefore, we obtain that there exists $\mathbf{m} \in [-\infty, \infty)$ which satisfies

$$\mathbf{m}=\operatorname*{lim sup}_{t \rightarrow \infty} \mathscr{L}\left(\Theta_t\right)=\operatorname*{lim inf}_{t \rightarrow \infty} \mathscr{L}\left(\Theta_t\right)=\operatorname*{inf}_{t \in[0, \infty)} \mathscr{L}(\Theta_t) .(9.168)$$

Furthermore, note that the assumption that $\lim \inf _{t \rightarrow \infty}\left\|\Theta_t\right\|_2<\infty$ demonstrates that there exist $\vartheta \in \mathbb{R}^9$ and $\delta=\left(\delta_n\right)_{n \in \mathbb{N}}: \mathbb{N} \rightarrow[0, \infty)$ which satisfy

$$\lim \inf _{n \rightarrow \infty} \delta_n=\infty \quad \text { and } \quad \lim _{n \rightarrow \infty}\left\|\Theta_{\delta_n}-\vartheta\right\|_2=0 .(9.169)$$

Observe that (9.168), (9.169), and the fact that $\mathscr{L}$ is continuous ensure that

$$\mathscr{L}(\vartheta)=\mathbf{m} \in \mathbb{R} \quad \text { and } \quad \forall t \in[0, \infty): \mathscr{L}\left(\Theta_t\right) \geq \mathscr{L}(\vartheta) .(9.170)$$

Next let $\varepsilon, \mathbf{c} \in(0, \infty), \alpha \in(0,1)$ satisfy for all $\theta \in \mathbb{R}^9$ with $\|\theta-\vartheta\|_2<\varepsilon$ that

$$\left|\mathscr{L}(\theta)-\mathscr{L}(\vartheta)\right|^\alpha \leq \mathbf{c}\left\|\mathscr{G}(\theta)\right\|_2 .(9.171)$$

Note that (9.169) and the fact that $\mathscr{L}$ is continuous demonstrate that there exist $n \in \mathbb{N}$, $\mathbf{c} \in[0,1]$ which satisfy

$$\mathbf{c}=\left|\mathscr{L}\left(\Theta_{\delta_n}\right)-\mathscr{L}(\vartheta)\right| \quad \text { and } \quad \mathbf{c}\left(1-\alpha\right)^{-1} \mathbf{c}^{1-\alpha}+\left\|\Theta_{\delta_n}-\vartheta\right\|_2<\varepsilon .(9.172)$$

Next let $\Phi: [0, \infty) \rightarrow \mathbb{R}^9$ satisfy for all $t \in[0, \infty)$ that

$$\Phi_t=\Theta_{\delta_n+t} .(9.173)$$

Observe that (9.166), (9.170), and (9.173) establish that for all $t \in[0, \infty)$ it holds that

$$\begin{gathered} \mathscr{L}\left(\Phi_t\right)=\mathscr{L}\left(\Phi_0\right)-\int_0^t\left\|\mathscr{G}\left(\Phi_s\right)\right\|_2^2 \mathrm{~d} s, \quad \Phi_t=\Phi_0-\int_0^t \mathscr{G}\left(\Phi_s\right) \mathrm{d} s, \text { and } \mathscr{L}\left(\Phi_t\right) \geq \mathscr{L}(\vartheta) . \\ (9.174) \end{gathered}$$

Combining this with (9.171), (9.172), (9.173), and Corollary 9.11.3 (applied with $\Theta \wedge \Phi$ in the notation of Corollary 9.11.3) establishes that there exists $\psi \in \mathbb{R}^9$ which satisfies for all $t \in[0, \infty)$ that

$$0 \leq \mathscr{L}\left(\Phi_t\right)-\mathscr{L}(\psi) \leq\left(1+\mathbf{c}^{-2} t\right)^{-1},\left\|\Phi_t-\psi\right\|_2 \leq \mathbf{c}(1-\alpha)^{-1}\left(1+\mathbf{c}^{-2} t\right)^{\alpha-1},(9.175)$$

and $\mathscr{L}(\psi)=\mathscr{L}(\vartheta)$. Note that (9.173) and (9.175) show for all $t \in[0, \infty)$ that $0 \leq$ $\mathscr{L}\left(\Theta_{\delta_n+t}\right)-\mathscr{L}(\psi) \leq\left(1+\mathbf{c}^{-2} t\right)^{-1}$ and $\left\|\Theta_{\delta_n+t}-\psi\right\|_2 \leq \mathbf{c}(1-\alpha)^{-1}\left(1+\mathbf{c}^{-2} t\right)^{\alpha-1}$. Hence, we obtain for all $\tau \in\left[\delta_n, \infty\right), t \in[\tau, \infty)$ that

$$\begin{gathered} 0 \leq \mathscr{L}\left(\Theta_t\right)-\mathscr{L}(\psi) \leq\left(1+\mathbf{c}^{-2}\left(t-\delta_n\right)\right)^{-1}=\left(1+\mathbf{c}^{-2}(t-\tau)+\mathbf{c}^{-2}\left(\tau-\delta_n\right)\right)^{-1} \\ \leq\left(1+\mathbf{c}^{-2}(t-\tau)\right)^{-1} \end{gathered}(9.176)$$
