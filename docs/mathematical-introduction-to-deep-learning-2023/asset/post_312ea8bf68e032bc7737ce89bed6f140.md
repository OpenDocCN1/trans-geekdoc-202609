### Proof of Corollary 4.4.13

Throughout this proof let $\mathfrak{C} \in \mathbb{R}$ satisfy

$$
\mathfrak{C} = \frac{9}{8} (3dL(b-a))^{2d} + (d+22)(3dL(b-a))^d + d+11, \quad (4.220)
$$

for every $\varepsilon \in (0,1]$ let $A_{\epsilon} \in (0, \infty)$, $\mathbf{L}_{\epsilon} \in \mathbb{N}$, $\mathbf{I}^{(\varepsilon)} = (\mathbf{l}_0^{(\varepsilon)}, \mathbf{l}_1^{(\varepsilon)}, \ldots, \mathbf{l}_{\mathbf{L}_{\epsilon}}^{(\varepsilon)}) \in \mathbb{N}_{*}^{\mathbf{L}_{\epsilon}+1}$ satisfy

$$
A_{\epsilon} = \bigg(\frac{3dL(b-a)}{\varepsilon} \bigg)^d, \quad \mathbf{L}_{\epsilon} = 1 + \bigg(\bigg\lfloor \log_2 \big(\frac{A_{\epsilon}}{2d} \big) \bigg\rfloor + 1 \bigg)^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon}), \quad (4.221)
$$

$$
\mathbf{l}_0^{(\varepsilon)} = d, \quad \mathbf{l}_1^{(\varepsilon)} = \bigg\lfloor A_{\epsilon} \bigg\rfloor^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon}) + 1, \quad \text{and} \quad \mathbf{l}_{\mathbf{L}_{\epsilon}}^{(\varepsilon)} = 1, \quad (4.222)
$$

and assume for all $\varepsilon \in (0,1]$, $i \in \{2,3, \ldots, \mathbf{L}_{\epsilon} - 1\}$ that

$$
\mathbf{l}_i^{(\varepsilon)} = 3 \bigg\lfloor \frac{A_{\epsilon}}{2d} \bigg\rfloor^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon}) \quad (4.223)
$$

(cf. Definition 4.2.6). Observe that the fact that for all $\varepsilon \in (0,1]$ it holds that $\mathbf{L}_{\epsilon} \geq 1 + \bigg(\bigg\lfloor \log_2 \big(\frac{A_{\epsilon}}{2d} \big) \bigg\rfloor + 1 \bigg)^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon})$, the fact that for all $\varepsilon \in (0,1]$ it holds that $\mathbf{l}_0^{(\varepsilon)} = d$, the fact that for all $\varepsilon \in (0,1]$ it holds that $\mathbf{l}_1^{(\varepsilon)} \geq \| A_{\epsilon} \|_{\infty} (A_{\epsilon})$, the fact that for all $\varepsilon \in (0,1]$ it holds that $\mathbf{l}_{\mathbf{L}_{\epsilon}}^{(\varepsilon)} = 1$, the fact that for all $\varepsilon \in (0,1]$, $i \in \{2,3, \ldots, \mathbf{L}_{\epsilon} - 1\}$ it holds that $\mathbf{l}_i^{(\varepsilon)} \geq 3 \bigg\lfloor \frac{A_{\epsilon}}{2d} \bigg\rfloor^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon})$. Proposition 4.4.12, and Lemma 4.4.2 demonstrate that for all $\varepsilon \in (0,1]$ there exists $\mathbf{F}_{\epsilon} \in \bigg( \prod_{i=1}^{\mathbf{L}_{\epsilon}} \bigg(\mathbb{R}^{\mathbf{l}_i^{(\varepsilon)}} \times \mathbf{l}_{i-1}^{(\varepsilon)} \times \mathbb{R}^{\mathbf{l}_i^{(\varepsilon)}} \bigg) \bigg) \subseteq \mathbf{N}$ which satisfies $\|\mathcal{T} (\mathbf{F}_{\epsilon}) \|_\infty \leq \max \big\{1, L, |a|, |b|, 2|\sup_{x \in [a, b]^d} |f(x)| | \big\}$ and

$$
\sup_{x \in [a, b]^d} | (\mathcal{R}_{\epsilon}^{\mathbf{N}} (\mathbf{F}_{\epsilon}) (x) - f(x)) | \leq \frac{3dL(b-a)}{(A_{\epsilon})^{1/d}} = \varepsilon. \quad (4.224)
$$

(cf. Definitions 1.2.4, 1.3.1, 1.3.4, and 1.3.5). Furthermore, note that the fact that $d \geq 1$ proves that for all $\varepsilon \in (0,1]$ it holds that

$$
\mathcal{H} (\mathbf{F}_{\epsilon}) = \mathbf{L}_{\epsilon} - 1 = \bigg(\bigg\lfloor \log_2 \big(\frac{A_{\epsilon}}{2d} \big) \bigg\rfloor + 1 \bigg)^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon})
$$

$$
= \bigg\lfloor \log_2 \big(\frac{A_{\epsilon}}{2d} \big) \bigg\rfloor^{\| \mathbf{I}^{(\varepsilon)} \|_{\infty}}(A_{\epsilon}) \leq \max \{0, \log_2 (A_{\epsilon}) + 1 \}. \quad (4.225)
$$

Combining this and the fact that for all $\varepsilon \in (0, 1]$ it holds that

$$
\log _ { 2 } ( A _ { \varepsilon } ) = d \log _ { 2 } \left( \frac { 3 L ( b - a ) } { \varepsilon } \right) = d \left( \log _ { 2 } ( \varepsilon ^ { - 1 } ) + \log _ { 2 } ( d ) + \log _ { 2 } ( 3 L ( b - a ) ) \right)

$$
