Lemma 6.3.7 above establishes, roughly speaking, the convergence rate $\frac{K-\kappa}{K+K}$ (see (6.225) above for the precise statement) for the **GD** optimization method in the case of the objective function in (6.223). The next result, Lemma 6.3.8 below, essentially proves in the situation of Lemma 6.3.7 that this convergence rate cannot be improved by means of a difference choice of the learning rate.

**Lemma 6.3.8** (Lower bound for the convergence rate of **GD** for quadratic objective functions). Let $\boldsymbol{0} \in \mathbb{N}$, $\boldsymbol{\xi} = (\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \ldots, \boldsymbol{\xi}_{\mathbf{d}})$, $\boldsymbol{\vartheta} = (\boldsymbol{\vartheta}_1, \boldsymbol{\vartheta}_2, \ldots, \boldsymbol{\vartheta}_{\mathbf{d}}) \in \mathbb{R}^{\mathbf{d}}$, $\gamma, \kappa, K, \lambda_1, \lambda_2, \ldots, \lambda_{\mathbf{d}} \in (0, \infty)$ satisfy $\kappa = \min\{\lambda_1, \lambda_2, \ldots, \lambda_{\mathbf{d}}\}$ and $K = \max\{\lambda_1, \lambda_2, \ldots, \lambda_{\mathbf{d}}\}$, let $\mathcal{L}: \mathbb{R}^{\mathbf{d}} \rightarrow \mathbb{R}$ satisfy for all $\boldsymbol{\theta} = (\boldsymbol{\theta}_1, \boldsymbol{\theta}_2, \ldots, \boldsymbol{\theta}_{\mathbf{d}}) \in \mathbb{R}^{\mathbf{d}}$ that

```
L(\theta) = \frac{1}{2} \left[ \sum_{i=1}^{\mathbf{d}} \lambda_i |\theta_i - \vartheta_i|^2 \right], (6.234)
```

and let $\boldsymbol{\Theta}: \mathbb{N}_0 \rightarrow \mathbb{R}^{\mathbf{d}}$ satisfy for all $n \in \mathbb{N}$ that

```
\Theta_0 = \xi \quad \text{and} \quad \Theta_n = \Theta_{n-1} - \gamma \left( \nabla \mathcal{L} \right)(\Theta_{n-1}). (6.235)
```

Then it holds for all $n \in \mathbb{N}_0$ that

```
\begin{aligned} \| \Theta_n - \vartheta \|_2 \geq \left[ \max\{\gamma K - 1, 1 - \gamma \kappa\} \right]^n \left[ \min\{ |\xi_1 - \vartheta_1|, \ldots, |\xi_{\mathbf{d}} - \vartheta_{\mathbf{d}}| \} \right] \geq \left[ \frac{K-\kappa}{K+\kappa} \right]^n \left[ \min\{ |\xi_1 - \vartheta_1|, \ldots, |\xi_{\mathbf{d}} - \vartheta_{\mathbf{d}}| \} \right] \end{aligned} (6.236)
```

(cf. Definition 3.3.4).

**Proof of Lemma 6.3.8.** Throughout this proof, let $\Theta^{(1)}, \Theta^{(2)}, \ldots, \Theta^{(\mathbf{d})}: \mathbb{N}_0 \rightarrow \mathbb{R}$ satisfy for all $n \in \mathbb{N}_0$ that $\Theta_n = (\Theta_n^{(1)}, \Theta_n^{(2)}, \ldots, \Theta_n^{(\mathbf{d})})$ and let $\iota, \mathcal{I} \in \{1, 2, \ldots, \mathbf{d}\}$ satisfy $\lambda_{\iota} = \kappa$ and $\lambda_{\mathcal{I}} = K$. Observe that (6.234) implies that for all $\boldsymbol{\theta} = (\theta_1, \theta_2, \ldots, \theta_{\mathbf{d}}) \in \mathbb{R}^{\mathbf{d}}$, $i \in \{1, 2, \ldots, \mathbf{d}\}$ it holds that

```
\left( \frac{\partial \mathcal{L}}{\partial \theta_i} \right)(\theta) = \lambda_i (\theta_i - \vartheta_i). (6.237)
```

Combining this with (6.235) implies that for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \mathbf{d}\}$ it holds that

```
\begin{aligned} \Theta_n^{(i)} - \vartheta_i &= \Theta_{n-1}^{(i)} - \gamma \left( \frac{\partial \mathcal{L}}{\partial \theta_i} \right)(\Theta_{n-1}) - \vartheta_i \\ &= \Theta_{n-1}^{(i)} - \vartheta_i - \gamma \lambda_i (\Theta_{n-1}^{(i)} - \vartheta_i) \\ &= (1 - \gamma \lambda_i)(\Theta_{n-1}^{(i)} - \vartheta_i). \end{aligned} (6.238)
```

Induction hence proves that for all $n \in \mathbb{N}_0$, $i \in \{1, 2, \ldots, \mathbf{d}\}$ it holds that

```
\Theta_n^{(i)} - \vartheta_i = (1 - \gamma \lambda_i)^n (\Theta_0^{(i)} - \vartheta_i) = (1 - \gamma \lambda_i)^n (\xi_i - \vartheta_i). (6.239)
```
