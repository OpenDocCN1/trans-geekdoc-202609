and the assumption that the function $\Phi : \mathbb{X} \times \mathbb{Y} \rightarrow [0, \infty]$ is $(\mathcal{X} \otimes \mathcal{Y})/\mathcal{B}([0, \infty])$-measurable show that the function

```
$\begin{equation}\forall Y \ni y \mapsto \phi(y) = \mathbb{E}[\Phi(X, y)] = \int_\Omega \Phi(X(\omega), y) \mathbb{P}(\mathrm{d}\omega) \in [0, \infty] \tag{7.34}
\end{equation}$
```

is $\mathcal{Y}/\mathcal{B}([0, \infty])$-measurable. This proves item **(i)**. Observe that the integral transformation theorem, the fact that $(X, Y)(\mathbb{P}) = (X(\mathbb{P})) \otimes (Y(\mathbb{P}))$, and Fubini's theorem establish that

```
$\begin{aligned}\mathbb{E}\big[\Phi(X, Y)\big] &= \int_\Omega \Phi(X(\omega), Y(\omega)) \mathbb{P}(\mathrm{d}\omega)\\
&= \int_{\mathbb{X} \times \mathbb{Y}} \Phi(x, y) \big((X, Y)(\mathbb{P})\big)(\mathrm{d}x, \mathrm{d}y)\\
&= \int_\mathbb{Y} \Big[\int_\mathbb{X} \Phi(x, y) \big(X(\mathbb{P})\big)(\mathrm{d}x) \Big] \big(Y(\mathbb{P})\big)(\mathrm{d}y)\\
&= \int_\mathbb{Y} \mathbb{E}\big[\Phi(X, y)\big] \big(Y(\mathbb{P})\big)(\mathrm{d}y)\\
&= \int_\mathbb{Y} \phi(y) \big(Y(\mathbb{P})\big)(\mathrm{d}y) = \mathbb{E}\big[\phi(Y)\big].\end{aligned}
\tag{7.35}$
```

This proves item **(ii)**. The proof of Lemma 7.2.7 is thus complete. $\square$

# Lemma 7.2.8. Let $\mathfrak{d} \in \mathbb{N}$, let $(S, \mathcal{S})$ be a measurable space, let $\ell = (\ell(\theta, x))_{(\theta, x) \in \mathbb{R}^\mathfrak{d} \times S} : \mathbb{R}^\mathfrak{d} \times S \rightarrow \mathbb{R}$ be $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R})$-measurable, and assume for every $x \in S$ that the function $\mathbb{R}^\mathfrak{d} \ni \theta \mapsto \ell(\theta, x) \in \mathbb{R}$ is differentiable. Then the function

```
$\begin{equation}\mathbb{R}^\mathfrak{d} \times S \ni (\theta, x) \mapsto \big(\nabla_\theta \ell\big)(\theta, x) \in \mathbb{R}^\mathfrak{d}\n\tag{7.36}
\end{equation}$
```

is $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R}^\mathfrak{d})$-measurable.

Proof of Lemma 7.2.8. Throughout this proof, let $\boldsymbol{g} = (\boldsymbol{g}_1, \ldots, \boldsymbol{g}_\mathfrak{d}) : \mathbb{R}^\mathfrak{d} \times S \rightarrow \mathbb{R}^\mathfrak{d}$ satisfy for all $\theta \in \mathbb{R}^\mathfrak{d}$, $x \in S$ that

```
$\begin{equation}\boldsymbol{g}(\theta, x) = \big(\nabla_\theta \ell\big)(\theta, x).\n\tag{7.37}
\end{equation}$
```

The assumption that the function $\ell : \mathbb{R}^\mathfrak{d} \times S \rightarrow \mathbb{R}$ is $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R})$-measurable implies that for all $i \in \{1, 2, \ldots, \mathfrak{d}\}$, $h \in \mathbb{R} \setminus \{0\}$ it holds that the function

```
$\begin{equation}\mathbb{R}^\mathfrak{d} \times S \ni (\theta, x) = \big((\theta_1, \ldots, \theta_\mathfrak{d}), x\big) \mapsto \bigg(\frac{\ell((\theta_1, \ldots, \theta_{i-1}, \theta_i + h, \theta_{i+1}, \ldots, \theta_\mathfrak{d}), x) - \ell(\theta, x)}{h} \bigg) \in \mathbb{R}\n\tag{7.38}
\end{equation}$
```

is $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R})$-measurable. The fact that for all $i \in \{1, 2, \ldots, \mathfrak{d}\}$, $\theta = (\theta_1, \ldots, \theta_\mathfrak{d}) \in \mathbb{R}^\mathfrak{d}$, $x \in S$ it holds that

```
$\begin{equation}\boldsymbol{g}_i(\theta, x) = \lim_{n \rightarrow \infty} \bigg( \frac{\ell((\theta_1, \ldots, \theta_{i-1}, \theta_i + 2^{-n} \theta_{i+1}, \theta_{i+1}, \ldots, \theta_\mathfrak{d}), x) - \ell(\theta, x)}{2^{-n}} \bigg)\n\tag{7.39}
\end{equation}$
```

hence demonstrates that for all $i \in \{1, 2, \ldots, \mathfrak{d}\}$ it holds that the function $\boldsymbol{g}_i : \mathbb{R}^\mathfrak{d} \times S \rightarrow \mathbb{R}$ is $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R})$-measurable. This ensures that $\boldsymbol{g}$ is $(\mathcal{B}(\mathbb{R}^\mathfrak{d}) \otimes \mathcal{S})/\mathcal{B}(\mathbb{R}^\mathfrak{d})$-measurable. The proof of Lemma 7.2.8 is thus complete. $\square$
