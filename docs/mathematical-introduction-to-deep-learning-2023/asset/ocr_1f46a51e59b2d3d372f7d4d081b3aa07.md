# Corollary 6.2.3 (Local error of the explicit midpoint method for **GF ODEs**). Let $\varnothing \in \mathbb{N}$, $T, \gamma, c \in [0, \infty)$, $\mathscr{L} \in C^{3}(\mathbb{R}^{d}, \mathbb{R})$, $\Theta \in C([0, \infty), \mathbb{R}^{d})$, $\theta \in \mathbb{R}^{d}$ satisfy for all $x, y, z \in \mathbb{R}^{d}$, $t \in [0, \infty)$ that

$\Theta_{t} = \Theta_{0} + \int_{0}^{t}(\nabla \mathscr{L})(\Theta_{s}) \, \mathrm{d}s, \quad \theta = \Theta_{T} - \gamma(\nabla \mathscr{L})(\Theta_{T} - \frac{\gamma}{2}(\nabla \mathscr{L})(\Theta_{T})), \tag{6.180}$

$\| (\nabla \mathscr{L})(x) \|_{2} \leq c, \quad \| \mathrm{Hess} \, \mathscr{L})(x) y \|_{2} \leq c \| y \|_{2}, \text{ and } \| (\nabla \mathscr{L})''(x)(y, z) \|_{2} \leq c \| y \|_{2} \| z \|_{2} \tag{6.181}$

(cf. Definition 3.3.4). Then

$\| \Theta_{T+\gamma} - \theta \|_{2} \leq c^{3} \gamma^{3}. \tag{6.182}$

Proof of Corollary 6.2.3. Throughout this proof, let $\mathscr{G} : \mathbb{R}^{d} \to \mathbb{R}^{d}$ satisfy for all $\theta \in \mathbb{R}^{d}$ that

$\mathscr{G}(\theta) = - (\nabla \mathscr{L})(\theta). \tag{6.183}$

Note that the fact that for all $t \in [0, \infty)$ it holds that

$\Theta_{t} = \Theta_{0} + \int_{0}^{t}\mathscr{G}(\Theta_{s}) \, \mathrm{d}s, \tag{6.184}$

the fact that

$\theta = \Theta_{T} + \gamma \mathscr{G}\left(\Theta_{T} + \frac{\gamma}{2}\mathscr{G}(\Theta_{T})\right), \tag{6.185}$

the fact that for all $x \in \mathbb{R}^{d}$ it holds that $\| \mathscr{G}(x) \|_{2} \leq c$, the fact that for all $x, y \in \mathbb{R}^{d}$ it holds that $\| \mathscr{G}'(x)y \|_{2} \leq c \| y \|_{2}$, the fact that for all $x, y, z \in \mathbb{R}^{d}$ it holds that

$\| \mathscr{G}''(x)(y, z) \|_{2} \leq c \| y \|_{2} \| z \|_{2}, \tag{6.186}$

and Lemma 6.2.2 show that

$\| \Theta_{T+\gamma} - \theta \|_{2} \leq c^{3} \gamma^{3}. \tag{6.187}$

The proof of Corollary 6.2.3 is thus complete.
