Source code 16.2 (code/dgm.py): A simple implementation in PyTORCH of the deep Galerkin method, computing an approximation of the function $u \in C^{1,2}([0,3] \times \mathbb{R}^{2}, \mathbb{R})$ which satisfies for all $t \in [0,3]$, $x = (x_{1},x_{2}) \in \mathbb{R}^{2}$ that $(\frac{\partial u}{\partial t})(t,x) = \frac{1}{200}(\Delta_{x}u)(t,x) + u(t,x) - [u(t,x)]^{3}$ and $u(0,x) = \sin(x_{1})\sin(x_{2})$. The plot created by this code is shown in Figure 16.2.
