# 12.3.2 Uniform estimates for the statistical learning error

Lemma 12.3.8. Let (E, δ) be a separable metric space, assume E ≠ ∅, let M ∈ N, L, D ∈ (0, ∞), let (Ω, F, P) be a probability space, let X_{x,m}: Ω → R, x ∈ E, m ∈ {1, 2, ..., M}, and Y_m: Ω → R, m ∈ {1, 2, ..., M}, be functions, assume for all x ∈ E that (X_{x,m}, Y_m), m ∈ {1, 2, ..., M}, are i.i.d. random variables, assume for all x, y ∈ E, m ∈ {1, 2, ..., M} that |X_{x,m} - X_{y,m}| ≤ Lδ(x, y) and |X_{x,m} - Y_m| ≤ D, let _x: Ω → [0, ∞), x ∈ E, satisfy for all x ∈ E that

```

```

and let _x ∈ [0, ∞), x ∈ E, satisfy for all x ∈ E that _x = E[|X_{x,1} - Y_1|²]. Then Ω ⊃ ω ↦ sup_{x∈E}|_x(ω) - _x| ∈ [0, ∞] is F/B([0, ∞))-measurable and

```
\mathbb{P}(\sup_{x\in E}|\mathfrak{E}_x - \underline{\mathfrak{E}}_x| \ge \varepsilon) \le 2C^{(L,\delta),s\bar{L}D}\exp\left(\frac{-\varepsilon^2M}{2D^4}\right) \tag{12.167}
```

(cf. Definition 4.3.2).

Proof of Lemma 12.3.8. Throughout this proof, let _{x,m}: Ω → [0, D²], x ∈ E, m ∈ {1, 2, ..., M}, satisfy for all x ∈ E, m ∈ {1, 2, ..., M} that

```
\mathfrak{E}_{x,m} = |X_{x,m} - Y_m|^2. \tag{12.168}
```

Observe that the fact that for all x_1, x_2, y ∈ R it holds that (x_1 - y)² - (x_2 - y)² = (x_1 - x_2)((x_1 - y) + (x_2 - y)), the assumption that for all x ∈ E, m ∈ {1, 2, ..., M} it holds that |X_{x,m} - Y_m| ≤ D, and the assumption that for all x, y ∈ E, m ∈ {1, 2, ..., M} it holds that |X_{x,m} - X_{y,m}| ≤ Lδ(x, y) imply that for all x, y ∈ E, m ∈ {1, 2, ..., M} it holds that

```
\begin{aligned} |\mathfrak{E}_{x,m} - \mathfrak{E}_{y,m}| &= \left|(X_{x,m} - Y_m)^2 - (X_{y,m} - Y_m)^2\right| \
&= |X_{x,m} - X_{y,m}||(|X_{x,m} - Y_m| + (X_{y,m} - Y_m)|) \
&\le |X_{x,m} - X_{y,m}|(|X_{x,m} - Y_m| + |X_{y,m} - Y_m|) \
&\le 2D|X_{x,m} - X_{y,m}| \le 2LD\delta(x, y). \end{aligned} \tag{12.169}
```

In addition, note that (12.166) and the assumption that for all x ∈ E it holds that (X_{x,m}, Y_m), m ∈ {1, 2, ..., M}, are i.i.d. random variables show that for all x ∈ E it holds that

```
\begin{aligned} \mathbb{E}[\mathfrak{E}_x] &= \frac{1}{M}\left[\sum_{m=1}^M \mathbb{E}[|X_{x,m} - Y_m|^2]\right] = \frac{1}{M}\left[\sum_{m=1}^M \mathbb{E}[|X_{x,1} - Y_1|^2]\right] = \frac{1}{M}\left[\sum_{m=1}^M \underline{\mathfrak{E}}_x\right] = \underline{\mathfrak{E}}_x, \end{aligned} \tag{12.170}
```
