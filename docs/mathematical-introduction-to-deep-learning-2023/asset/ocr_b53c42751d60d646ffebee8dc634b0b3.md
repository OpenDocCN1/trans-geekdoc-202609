**Lemma 2.2.7** (Properties of fully-connected feedforward ReLU identity ANN$s$). Let $d \in \mathbb{N}$. Then

+   (i) it holds that
$\mathcal{D}(\mathfrak{J}_d) = (d,2d,d) \in \mathbb{N}^{3}$
and
(ii) it holds that
$\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_d) = \mathrm{id}_{\mathbb{R}^{d}}$

(cf. Definitions 1.3.1, 1.3.4, and 2.2.6).
*Proof of Lemma 2.2.7.* Throughout this proof, let $L=2$, $l_{0}=1$, $l_{1}=2$, $l_{2}=1$. Note that (2.70) establishes that
$\mathcal{D}(\mathfrak{J}_1) = (1, 2,1) = (l_0, l_1, l_2)$.

This, (2.71), and Proposition 2.2.4 prove that
$\mathcal{D}(\mathfrak{J}_d) = (d,2d,d) \in \mathbb{N}^{3}$.
This establishes item (i). Next note that (2.70) assures that for all $x \in \mathbb{R}$ it holds that
$(\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_1))(x) = \mathtt{r}(x)-\mathtt{r}(-x) = \max\{x,0\}-\max\{-x,0\} = x$.

Combining this and Proposition 2.2.3 demonstrates that for all $x=(x_1, \ldots, x_d) \in \mathbb{R}^{d}$ it holds that $\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_d) \in C(\mathbb{R}^{d}, \mathbb{R}^{d})$ and
\begin{align*}
(\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_d))(x) & = (\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathbf{P}_d(\mathfrak{J}_1, \mathfrak{J}_1, \ldots, \mathfrak{J}_1)))(x_1, x_2, \ldots, x_d) \\
& = ((\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_1))(x_1), (\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_1))(x_2), \ldots, (\mathcal{R}_{\mathtt{r}}^{\mathbb{N}}(\mathfrak{J}_1))(x_d)) \\
& = (x_1, x_2, \ldots, x_d) = x
\end{align*}
(cf. Definition 2.2.1). This establishes item (ii). The proof of Lemma 2.2.7 is thus complete.

# 2.2.3 Extensions of fully-connected feedforward ANN$s$

**Definition 2.2.8** (Extensions of fully-connected feedforward ANN$s$). Let $L \in \mathbb{N}$, $\mathbb{I} \in \mathbf{N}$ satisfy $\mathcal{I}(\mathbb{I}) = \mathcal{O}(\mathbb{I})$. Then we denote by

$\mathcal{E}_{L, \mathbb{I}}: \{ \Phi \in \mathbf{N}: (\mathcal{L}(\Phi) \leq L \text{ and } \mathcal{O}(\Phi) = \mathcal{I}(\mathbb{I})) \} \rightarrow \mathbf{N}$

the function which satisfies for all $\Phi \in \mathbf{N}$ with $\mathcal{L}(\Phi) \leq L$ and $\mathcal{O}(\Phi) = \mathcal{I}(\mathbb{I})$ that
$\mathcal{E}_{L, \mathbb{I}}(\Phi) = (\mathbb{I}^{* (L-\mathcal{L}(\Phi))}) \bullet \Phi$

(cf. Definitions 1.3.1, 2.1.1, and 2.1.6).
