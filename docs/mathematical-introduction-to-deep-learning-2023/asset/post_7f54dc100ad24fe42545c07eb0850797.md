
## 5.4 Loss functions

### 5.4.1 Absolute error loss

**Lemma 5.3.4 (Differentiability of the empirical risk function).** Let $\mathfrak{L}, \mathfrak{d} \in \mathbb{N}\setminus\{1\}$, $M, l_0$, $l_1, \dots, l_L \in \mathbb{N}$, $x_1, x_2, \dots, x_M \in \mathbb{R}^{\mathfrak{d}_0}$, $y_1, y_2, \dots, y_M \in \mathbb{R}^{\mathfrak{d}_L}$ satisfy $\mathfrak{d} = \sum_{k=1}^{L} l_k (l_{k-1}+1)$, for every $k \in \{1, 2, \dots, L\}$ let $\Psi_k\colon \mathbb{R}^{l_k} \to \mathbb{R}^{l_{k}}$ be differentiable, and let $\mathcal{L}\colon \mathbb{R}^{\mathfrak{d}} \to \mathbb{R}$ satisfy for all $\theta \in \mathbb{R}^{\mathfrak{d}}$ that

$$ \mathcal{L}(\theta) = \frac{1}{M} \left[ \sum_{m=1}^{M} \mathbf{L}\big( ( \mathcal{N}_{\Psi_1, \Psi_2, \dots, \Psi_L}^{\theta_{l_0}} )(x_m), y_m \big) \right] $$

(cf. Definition 1.1.3). Then $\mathcal{L}$ is differentiable.

Proof of Lemma 5.3.4. Note that Lemma 5.3.3 and Lemma 5.3.1 (applied with $\mathfrak{d}_1 \frown \mathfrak{d} + l_0$, $\mathfrak{d}_2 \frown l_L$, $l_1 \frown l_L$, $l_2 \frown l_L$, $F_1 \frown (\mathbb{R}^{\mathfrak{d}} \times \mathbb{R}^{l_0} \ni (\theta, x) \to ( \mathcal{N}_{\Psi_1, \Psi_2, \dots, \Psi_L}^{\theta_{l_0}} )(x) \in \mathbb{R}^{l_L}$, $F_2 \frown \text{id}_{\mathbb{R}^{l_L}}$ in the notation of Lemma 5.3.1) show that

$$ \mathbb{R}^{\mathfrak{d}} \times \mathbb{R}^{l_0} \times \mathbb{R}^{l_L} \ni (\theta, x, y) \to \big( ( \mathcal{N}_{\Psi_1, \Psi_2, \dots, \Psi_L}^{\theta_{l_0}} )(x), y \big) \in \mathbb{R}^{l_L} \times \mathbb{R}^{l_L} $$

is differentiable. The assumption that $\mathbf{L}$ is differentiable and the chain rule therefore ensure that for all $x \in \mathbb{R}^{\mathfrak{d}_0}$, $y \in \mathbb{R}^{\mathfrak{d}_L}$ it holds that

$$ \mathbb{R}^{\mathfrak{d}} \ni \theta \to \mathbf{L}\big( ( \mathcal{N}_{\Psi_1, \Psi_2, \dots, \Psi_L}^{\theta_{l_0}} )(x_m), y_m \big) \in \mathbb{R} $$

is differentiable. This implies that $\mathcal{L}$ is differentiable. The proof of Lemma 5.3.4 is thus complete.

**Lemma 5.3.5.** Let $a\colon \mathbb{R} \to \mathbb{R}$ be differentiable and let $\mathfrak{d} \in D$. Then $\mathfrak{M}_{a,\mathfrak{d}}$ is differentiable.

Proof of Lemma 5.3.5. Observe that the assumption that $a$ is differentiable, Lemma 5.3.1, and induction demonstrate that for all $m \in \mathbb{N}$ it holds that $\mathfrak{M}_{a,m}$ is differentiable. The proof of Lemma 5.3.5 is thus complete.

**Corollary 5.3.6.** Let $L, \mathfrak{o} \in \mathbb{N} \backslash \{1\}$, $M, l_0, l_1, \ldots, l_L \in \mathbb{N}$, $x_1, x_2, \ldots, x_M \in \mathbb{R}^{l_0}$, $y_1, y_2, \ldots, y_M \in \mathbb{R}^{l_L}$ satisfy $\mathfrak{o} = \sum_{k=1}^{L} l_k(l_{k-1} + 1)$, let $a: \mathbb{R} \to \mathbb{R}$ and $\mathbf{L}: \mathbb{R}^{l} \times \mathbb{R}^{l} \to \mathbb{R}$ be differentiable, and let $\mathcal{L}: \mathbb{R}^{\mathfrak{o}} \to \mathbb{R}$ satisfy for all $\theta \in \mathbb{R}^{\mathfrak{o}}$ that

$$\mathcal{L}(\theta) = \frac{1}{M} \left[ \sum_{m=1}^{M} \mathbf{L}\left( \left( \mathfrak{N}_{\mathfrak{m}_{a,l_1}^{\rho_0,l_0}, \mathfrak{m}_{a,l_2}, \ldots, \mathfrak{m}_{a,l_{L-1}}, \mathrm{id}_{\mathfrak{g}_{L}^{l}} \right) (x_m), y_m \right) \right] \tag{5.37}$$

(cf. Definitions 1.1.3 and 1.2.1). Then $\mathcal{L}$ is differentiable.

*Proof of Corollary 5.3.6.* Note that Lemma 5.3.5, and Lemma 5.3.4 prove that $\mathcal{L}$ is differentiable. The proof of Corollary 5.3.6 is thus complete. $\square$

**Corollary 5.3.7.** Let $L, \mathfrak{o} \in \mathbb{N} \backslash \{1\}$, $M, l_0, l_1, \ldots, l_L \in \mathbb{N}$, $x_1, x_2, \ldots, x_M \in \mathbb{R}^{l_0}$, $y_1, y_2, \ldots, y_M \in (0, \infty)^{l_L}$ satisfy $\mathfrak{o} = \sum_{k=1}^{L} l_k(l_{k-1} + 1)$, let $A$ be the $l_L$-dimensional softmax activation function, let $a: \mathbb{R} \to \mathbb{R}$ and $\mathbf{L}: (0, \infty)^{l} \times (0, \infty)^{l} \to \mathbb{R}$ be differentiable, and let $\mathcal{L}: \mathbb{R}^{\mathfrak{o}} \to \mathbb{R}$ satisfy for all $\theta \in \mathbb{R}^{\mathfrak{o}}$ that

$$\mathcal{L}(\theta) = \frac{1}{M} \left[ \sum_{m=1}^{M} \mathbf{L}\left( \left( \mathfrak{N}_{\mathfrak{m}_{a,l_1}^{\rho_0,l_0}, \mathfrak{m}_{a,l_2}, \ldots, \mathfrak{m}_{a,l_{L-1}}, A \right) (x_m), y_m \right) \right] \tag{5.38}$$

(cf. Definitions 1.1.3, 1.2.1, and 1.2.43 and Lemma 1.2.44). Then $\mathcal{L}$ is differentiable.

*Proof of Corollary 5.3.7.* Observe that Lemma 5.3.5, the fact that $A$ is differentiable, and Lemma 5.3.4 establish that $\mathcal{L}$ is differentiable. The proof of Corollary 5.3.7 is thus complete. $\square$

**Definition 5.4.1.** Let $d \in \mathbb{N}$ and let $\|\cdot\|: \mathbb{R}^{d} \to [0, \infty)$ be a norm. We say that $\mathbf{L}$ is the $\ell^{1}$-error loss function based on $\|\cdot\|$ (we say that $\mathbf{L}$ is the absolute error loss function based on $\|\cdot\|$) if and only if it holds that $\mathbf{L}: \mathbb{R}^{d} \times \mathbb{R}^{d} \to \mathbb{R}$ is the function from $\mathbb{R}^{d} \times \mathbb{R}^{d}$ to $\mathbb{R}$ which satisfies for all $x, y \in \mathbb{R}^{d}$ that

$$\mathbf{L}(x, y) = \|x - y\|. \tag{5.39}$$

```python
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt
import plot_util

ax = plot_util.setup_axis((-2,2), (-.5,2))

x = np.linspace(-2, 2, 100)

mae_loss = tf.keras.losses.MeanAbsoluteError(
        reduction=tf.keras.losses.Reduction.NONE)
zero = tf.zeros([100,1])

ax.plot(x, mae_loss(x.reshape([100,1]), zero),
        label=r'$\mathscr{l}^{1}$-error')
ax.legend()

plt.savefig('../../plots/l1loss.pdf', bbox_inches='tight')
```

### 5.4.2 Mean squared error loss

**Definition 5.4.2.** *Let $d \in \mathbb{N}$ and let $\|\cdot\|: \mathbb{R}^{d} \rightarrow [0, \infty)$ be a norm. We say that $\mathbf{L}$ is the mean squared error loss function based on $\|\cdot\|$ if and only if it holds that $\mathbf{L}$: $\mathbb{R}^{d} \times \mathbb{R}^{d} \rightarrow \mathbb{R}$ is the function from $\mathbb{R}^{d} \times \mathbb{R}^{d}$ to $\mathbb{R}$ which satisfies for all $x, y \in \mathbb{R}^{d}$ that*

$\mathbf{L}(x, y) = \|x - y\|^{2}. \tag{5.40}$

```python
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt
import plot_util

ax = plot_util.setup_axis((-2,2), (-.5,2))

x = np.linspace(-2, 2, 100)

mse_loss = tf.keras.losses.MeanSquaredError(
    reduction=tf.keras.losses.Reduction.NONE)
zero = tf.zeros([100,1])

ax.plot(x, mse_loss(x.reshape([100,1]),zero),
        label='Mean squared error')
ax.legend()

plt.savefig("../plots/mseloss.pdf", bbox_inches='tight')
```

**Lemma 5.4.3.** *Let $d \in \mathbb{N}$ and let $\mathbf{L}$ be the mean squared error loss function based on $\mathbb{R}^{d} \ni x \mapsto \|x\|_{2} \in [0,\infty)$ (cf. Definitions 3.3.4 and 5.4.2). Then*

(i) *it holds that $\mathbf{L} \in C^{\infty}(\mathbb{R}^{d} \times \mathbb{R}^{d}, \mathbb{R})$*

(ii) *it holds for all $x,y,u,v \in \mathbb{R}^{d}$ that*

$$\mathbf{L}(u,v) = \mathbf{L}(x,y) + \mathbf{L}'(x,y)(u-x, v-y) + \frac{1}{2}\mathbf{L}^{(2)}(x,y)\big((u-x, v-y), (u-x, v-y)\big).\tag{5.41}$$
