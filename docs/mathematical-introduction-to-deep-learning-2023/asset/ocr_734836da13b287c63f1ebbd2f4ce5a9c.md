This establishes (3.60) in the base case $k = 1$. For the induction step observe that (3.52) ensures that for all $k \in \mathbb{N} \cap (1, \infty) \cap (0, K]$ with $\sum_{n=0}^{k-2} c_n = \frac{f_{k-1} - f_{k-2}}{\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}}$ it holds that

$\begin{align*}
\sum_{n=0}^{k-1} c_n &= c_{k-1} + \sum_{n=0}^{k-2} c_n = \frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}} - \frac{f_{k-1} - f_{k-2}}{\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}} + \frac{f_{k-1} - f_{k-2}}{\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}} = \frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}}. \quad (3.62)\n\end{align*}$

Induction thus implies (3.60). Furthermore, note that (3.58), (3.60), and the fact that for all $k \in \{1, 2, \ldots, K\}$ it holds that $\mathfrak{F}_{k-1} < \mathfrak{F}_k$ demonstrate that for all $k \in \{1, 2, \ldots, K\}$, $x \in [\mathfrak{F}_{k-1}, \mathfrak{F}_k]$ it holds that

$\begin{align*}
(\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) - (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(\mathfrak{F}_{k-1}) &= \sum_{n=0}^{K} c_n (\max\{x - \mathfrak{F}_n, 0\} - \max\{\mathfrak{F}_{k-1} - \mathfrak{F}_n, 0\}) \
&= \sum_{n=0}^{k-1} c_n [(x - \mathfrak{F}_n) - (\mathfrak{F}_{k-1} - \mathfrak{F}_n)] = \sum_{n=0}^{k-1} c_n (x - \mathfrak{F}_{k-1}) \
&= \left(\frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}}\right)(x - \mathfrak{F}_{k-1}). \quad (3.63)\n\end{align*}$

Next we claim that for all $k \in \{1, 2, \ldots, K\}$, $x \in [\mathfrak{F}_{k-1}, \mathfrak{F}_k]$ it holds that

$(\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) = f_{k-1} + \left(\frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}}\right)(x - \mathfrak{F}_{k-1}). \quad (3.64)$

We now prove (3.64) by induction on $k \in \{1, 2, \ldots, K\}$. For the base case $k = 1$ observe that (3.59) and (3.63) show that for all $x \in [\mathfrak{F}_0, \mathfrak{F}_1]$ it holds that

$(\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) = (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(\mathfrak{F}_0) + (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) - (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(\mathfrak{F}_0) = f_0 + \left(\frac{f_1 - f_0}{\mathfrak{F}_1 - \mathfrak{F}_0}\right)(x - \mathfrak{F}_0). \quad (3.65)$

This proves (3.64) in the base case $k = 1$. For the induction step note that (3.63) establishes that for all $k \in \mathbb{N} \cap (1, \infty) \cap [1, K]$, $x \in [\mathfrak{F}_{k-1}, \mathfrak{F}_k]$ with $\forall y \in [\mathfrak{F}_{k-2}, \mathfrak{F}_{k-1}]: (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(y) = f_{k-2} + \frac{f_{k-1} - f_{k-2}}{\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}}(y - \mathfrak{F}_{k-2})$ it holds that

$\begin{align*}
(\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) &= (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(\mathfrak{F}_{k-1}) + (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(x) - (\mathcal{R}_{\textbf{f}}^{\mathbf{N}}(\mathbf{F}))(\mathfrak{F}_{k-1}) \
&= f_{k-2} + \left(\frac{f_{k-1} - f_{k-2}}{\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}}\right)(\mathfrak{F}_{k-1} - \mathfrak{F}_{k-2}) + \left(\frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}}\right)(x - \mathfrak{F}_{k-1}) \
&= f_{k-1} + \left(\frac{f_k - f_{k-1}}{\mathfrak{F}_k - \mathfrak{F}_{k-1}}\right)(x - \mathfrak{F}_{k-1}). \quad (3.66)\n\end{align*}$

Induction thus ensures (3.64). Moreover, observe that (3.52) and (3.60) imply that

$\sum_{n=0}^{K} c_n = c_K + \sum_{n=0}^{K-1} c_n = -\frac{f_K - f_{K-1}}{\mathfrak{F}_K - \mathfrak{F}_{K-1}} + \frac{f_K - f_{K-1}}{\mathfrak{F}_K - \mathfrak{F}_{K-1}} = 0. \quad (3.67)$
