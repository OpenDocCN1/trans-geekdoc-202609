# 4.4.3 Approximation through ANNs with variable architectures

Corollary 4.4.9. Let $d, K, \mathbf{d}, \mathbf{L} \in \mathbb{N}$, $\mathbf{l} = (\mathbf{l_0}, \mathbf{l_1}, \dots, \mathbf{l_K}) \in \mathbb{N}^{K+1}$, $L \in [0, \infty)$ satisfy that

$\mathbf{L} \geq [\log_2(K)] + 2, \quad \mathbf{l_0} = d, \quad \mathbf{l_K} = 1, \quad \mathbf{l_1} \geq 2dK, \quad \text{and} \quad \mathbf{d} \geq \sum_{i=1}^\mathbf{L} \mathbf{l_i} (\mathbf{l_{i-1}} + 1),$ (4.182)

assume for all $i \in \mathbb{N} \cap (1, \mathbf{L})$ that $\mathbf{l_i} \geq 3 [\frac{K^i}{2^{i-1}}]$, let $E \subseteq \mathbb{R}^d$ be a set, let $\mathbf{r_1}, \mathbf{r_2}, \dots, \mathbf{r_K} \in E$, and let $f: E \to \mathbb{R}$ satisfy for all $x, y \in E$ that $|f(x) - f(y)| \leq L \|x - y\|_1$ (cf. Definitions 3.3.4 and 4.2.6). Then there exists $\theta \in \mathbb{R}^q$ such that

$\|\theta\|_\infty \leq \max\{1, L, \max_{\mathbf{k} \in \{1,2,\dots,K\}} \|\mathbf{r_k}\|_\infty, 2 \max_{\mathbf{k} \in \{1,2,\dots,K\}} |f(\mathbf{r_k})|\}$ (4.183)

and

$\sup_{x \in E} |f(x) - \mathcal{A}_{\infty,\infty}^{\theta,1}(x)| \leq 2L [\sup_{x \in E} (\inf_{\mathbf{k} \in \{1,2,\dots,K\}} \|x - \mathbf{r_k}\|_1)]$ (4.184)

(cf. Definition 4.4.1).

Proof of Corollary 4.4.9. Throughout this proof, let $\boldsymbol{\eta} \in \mathbb{R}^K$, $\boldsymbol{\Phi} \in \mathbb{N}$ satisfy $\boldsymbol{\eta} = (f(\mathbf{r_1})$, $f(\mathbf{r_2}), \dots, f(\mathbf{r_K}))$ and

$\boldsymbol{\Phi} = \mathbb{M}_K \bullet \mathbf{A}_{\mathbf{L} - 1 \mathbf{L}_K} \bullet \mathbf{P}_K (\underline{\mathbf{A}}_{\mathbf{d}} \bullet \mathbf{A}_{\mathbf{l_d}, -\mathbf{r_1}}, \underline{\mathbf{A}}_{\mathbf{d}} \bullet \mathbf{A}_{\mathbf{l_d}, -\mathbf{r_2}}, \dots, \underline{\mathbf{A}}_{\mathbf{d}} \bullet \mathbf{A}_{\mathbf{l_d}, -\mathbf{r_K}}) \bullet \mathbb{T}_{\mathbf{d}, K}$ (4.185)

(cf. Definitions 1.3.1, 1.5.5, 2.1.1, 2.2.1, 2.3.1, 2.4.6, 4.2.1, and 4.2.5). Note that Lemma 4.2.9 and Proposition 4.3.1 establish that

+   (I) it holds that $\mathcal{L}(\boldsymbol{\Phi}) = [\log_2(K)] + 2$,

+   (II) it holds that $\mathcal{I}(\boldsymbol{\Phi}) = d$,

+   (III) it holds that $\mathcal{O}(\boldsymbol{\Phi}) = 1$,

+   (IV) it holds that $\mathbb{D}_1(\boldsymbol{\Phi}) = 2dK$,

+   (V) it holds for all $i \in \{2, 3, \dots, \mathcal{L}(\boldsymbol{\Phi}) - 1\}$ that $\mathbb{D}_i(\boldsymbol{\Phi}) \leq 3 [\frac{K^i}{2^{i-1}}]$,

+   (VI) it holds that $\|\mathcal{T}(\boldsymbol{\Phi})\|_\infty \leq \max\{1, L, \max_{\mathbf{k} \in \{1,2,\dots,K\}} \|\mathbf{r_k}\|_\infty, 2 \max_{\mathbf{k} \in \{1,2,\dots,K\}} |f(\mathbf{r_k})|\}$, and

+   (VII) it holds that $\sup_{x \in E} |f(x) - (\mathcal{R}_\mathcal{K}^{\mathbf{N}}(\boldsymbol{\Phi}))(x)| \leq 2L [\sup_{x \in E} (\inf_{\mathbf{k} \in \{1,2,\dots,K\}} \|x - \mathbf{r_k}\|_1)]$ [0.14, 0.70, 0.93, 0.72]

(cf. Definitions 1.2.4, 1.3.4, and 1.3.5). Furthermore, observe that the fact that $\mathbf{L} \geq [\log_2(K)] + 2 = \mathcal{L}(\boldsymbol{\Phi})$, the fact that $\mathbf{l_0} = d = \mathbb{D}_0(\boldsymbol{\Phi})$, the fact that $\mathbf{l_1} \geq 2dK = \mathbb{D}_1(\boldsymbol{\Phi})$, the fact that for all $i \in \{1, 2, \dots, \mathcal{L}(\boldsymbol{\Phi}) - 1\} \setminus \{1\}$ it holds that $\mathbf{l_i} \geq 3 [\frac{K^i}{2^{i-1}}] \geq \mathbb{D}_i(\boldsymbol{\Phi})$, the fact that for all $i \in \mathbb{N} \cap (\mathcal{L}(\boldsymbol{\Phi}) - 1, \mathbf{L})$ it holds that $\mathbf{l_i} \geq 3 [\frac{K^i}{2^{i-1}}] \geq 2 = 2\mathbb{D}_{\mathcal{L}(\boldsymbol{\Phi})}(\boldsymbol{\Phi})$, the fact that $\mathbf{l_K} = 1 = \mathbb{D}_{\mathcal{L}(\boldsymbol{\Phi})}(\boldsymbol{\Phi})$, and Lemma 4.4.8 show that there exists $\theta \in \mathbb{R}^q$ which satisfies that

$\|\theta\|_\infty \leq \max\{1, \|\mathcal{T}(\boldsymbol{\Phi})\|_\infty\}$ and $\mathcal{A}_{\infty,\infty}^{\theta, (\mathbf{l_0},1,\dots,1,\mathbf{l}_\mathbf{L})} = \mathcal{A}_{\infty,\infty}^{\mathcal{T}(\boldsymbol{\Phi}), \mathcal{D}(\boldsymbol{\Phi})}$. (4.186)
