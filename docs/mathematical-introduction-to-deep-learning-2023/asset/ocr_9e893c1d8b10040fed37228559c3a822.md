# 6.6. Root mean square propogation GD optimization (RMSprop)

let $\mathcal{L}: \mathbb{R}^\eth \to \mathbb{R}$ and $\mathcal{G} = (\mathcal{G}_1, \ldots, \mathcal{G}_\eth): \mathbb{R}^\eth \to \mathbb{R}^\eth$ satisfy for all $U \in \{V \subseteq \mathbb{R}^\eth: V \text{ is open}\}$, $\theta \in U$ with $\mathcal{L}|_U \in C^1(U, \mathbb{R}^\eth)$ that

```
$$\mathcal{G}(\theta) = (\nabla \mathcal{L})(\theta), \tag{6.349}$$
```

and let $\Theta = (\Theta^{(1)}, \ldots, \Theta^{(\eth)}): \mathbb{N}_0 \to \mathbb{R}^\eth$ be the bias-adjusted RMSprop GD process for the objective function $\mathcal{L}$ with generalized gradient $\mathcal{G}$, learning rates $\{\gamma_n\}_{n \in \mathbb{N}}$, second moment decay factors $\{\beta_n\}_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, and initial value $\xi$ (cf. Definition 6.6.3). Then

+      - $(i)$ it holds for all $n \in \mathbb{N}$, $k \in \{0, 1, \ldots, n-1\}$ that $0 \le b_{n,k} \le 1$,
   - $(ii)$ it holds for all $n \in \mathbb{N}$ that

```
$$\sum_{k=0}^{n-1} b_{n,k} = 1, \tag{6.350}$$
```

   *and*

+      - $(iii)$ it holds for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \eth\}$ that

```
$$\Theta^{(i)}_n = \Theta^{(i)}_{n-1} - \gamma_n \left[ \varepsilon + \left[\sum_{k=0}^{n-1} b_{n,k} |\mathcal{G}_i(\Theta_k)|^2 \right]^{1/2} \right]^{-1} \mathcal{G}_i(\Theta_{n-1}). \tag{6.351}$$
```

*Proof of Lemma 6.6.4.* Throughout this proof, let $\mathbb{M} = (\mathbb{M}^{(1)}, \ldots, \mathbb{M}^{(\eth)}): \mathbb{N}_0 \to \mathbb{R}^\eth$ satisfy for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \eth\}$ that $\mathbb{M}^{(i)}_0 = 0$ and

```
$$\mathbb{M}^{(i)}_n = \beta_n \mathbb{M}^{(i)}_{n-1} + (1-\beta_n) |\mathcal{G}_i(\Theta_{n-1})|^2 \tag{6.352}$$
```

and let $(B_{n,k})_{(n,k) \in (\mathbb{N}_0)^2} \subseteq \mathbb{R}$ satisfy for all $n \in \mathbb{N}$, $k \in \{0, 1, \ldots, n-1\}$ that

```
$$B_{n,k} = (1-\beta_{k+1}) \left[\prod_{l=k+2}^{n} \beta_l \right]. \tag{6.353}$$
```

Observe that (6.348) implies item $(i)$. Note that $(6.348)$, $(6.352)$, $(6.353)$, and Lemma 6.3.3 assure that for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \eth\}$ it holds that

```
$$\mathbb{M}^{(i)}_n = \sum_{k=0}^{n-1} B_{n,k} |\mathcal{G}_i(\Theta_k)|^2 \quad \text{and} \quad \sum_{k=0}^{n-1} b_{n,k} = \frac{\sum_{k=0}^{n-1} B_{n,k}}{1-\prod_{k=1}^{n} \beta_k} = \frac{1-\prod_{k=1}^{n} \beta_k}{1-\prod_{k=1}^{n} \beta_k} = 1. \tag{6.354}$$
```

This proves item $(ii)$. Observe that $(6.346)$, $(6.347)$, $(6.352)$, and $(6.354)$ demonstrate that for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \eth\}$ it holds that

```
$$\Theta^{(i)}_n = \Theta^{(i)}_{n-1} - \gamma_n \left[ \varepsilon + \left[\frac{\mathbb{M}^{(i)}_n}{1-\prod_{k=1}^{n} \beta_k} \right]^{1/2} \right]^{-1} \mathcal{G}_i(\Theta_{n-1}) \tag{6.355}$$
$$= \Theta^{(i)}_{n-1} - \gamma_n \left[ \varepsilon + \left[\sum_{k=0}^{n-1} b_{n,k} |\mathcal{G}_i(\Theta_k)|^2 \right]^{1/2} \right]^{-1} \mathcal{G}_i(\Theta_{n-1}).$$
```
