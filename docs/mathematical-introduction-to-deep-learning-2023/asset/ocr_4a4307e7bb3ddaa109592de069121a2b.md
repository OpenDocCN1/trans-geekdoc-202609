The triangle inequality therefore establishes that for all $j \in \{1,2\}$, $k \in \{1,2,\dots,L\}\cap(1,\infty)$ it holds that

```
$$\begin{split}\mathfrak{e}_{k}\leq&\left[\sup_{x\in D}\big\|\left(\mathbf{W}_{1,k}-\mathbf{W}_{2,k}\right)\left(\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{j,k-1})) (x)\right)\right)\big\|_{\infty}\right]\n&\quad+\left[\sup_{x\in D}\big\|\mathbf{W}_{3-j,k}\left(\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{1,k-1}))(x)\right)-\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{2,k-1}))(x)\right)\right)\big\|_{\infty}\right]\n&\quad+\|\theta_1-\theta_2\|_\infty\n\leq&\left[\sup_{v\in\mathbb{R}^{k-1}\setminus\{0\}}\left(\frac{\|\left(\mathbf{W}_{1,k}-\mathbf{W}_{2,k}\right)v\|_\infty}{\|v\|_\infty}\right)\right]\left[\sup_{x\in D}\|\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{j,k-1})) (x)\right)\|_\infty\right]\n&\quad+\left[\sup_{v\in\mathbb{R}^{k-1}\setminus\{0\}}\left(\frac{\|\mathbf{W}_{3-j,k}v\|_\infty}{\|v\|_\infty}\right)\right]\left[\sup_{x\in D}\|\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{1,k-1}))(x)\right)-\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{2,k-1}))(x)\right)\|_\infty\right]\n&\quad-\|\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{2,k-1}))(x)\right)\|_\infty\big]+\|\theta_1-\theta_2\|_\infty.\end{split}$$

(11.88)
```

Lemma **11.3.5** and Lemma **11.3.3** hence show that for all $j \in \{1,2\}$, $k \in \{1,2,\dots,L\}\cap(1,\infty)$ it holds that

```
$$\begin{split}\mathfrak{e}_{k}\leq&\,l_{k-1}\,\|\theta_1-\theta_2\|_\infty\left[\sup_{x\in D}\|\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{j,k-1}))(x)\right)\|_\infty\right]\left[\|\theta_1-\theta_2\|_\infty\right]\n&+l_{k-1}\,\|\theta_3-j\|_\infty\left[\sup_{x\in D}\big\|\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{1,k-1}))(x)\right)-\mathfrak{R}_{k-1}^{\mathfrak{N}}\left((\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{2,k-1}))(x)\right)\big\|_\infty\right]\n\leq&\,l_{k-1}\,\|\theta_1-\theta_2\|_\infty\left[\sup_{x\in D}\big\|\left(\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{j,k-1}))(x)\right)\big\|_\infty\right]+\|\theta_1-\theta_2\|_\infty\n&+l_{k-1}\,\|\theta_3-j\|_\infty\left[\sup_{x\in D}\big\|\left(\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{1,k-1}))(x)\right)-\left(\mathcal{R}_{\uparrow}^{\mathfrak{N}}(\phi_{2,k-1}))(x)\right)\big\|_\infty\right]\n\leq&\,\|\theta_1-\theta_2\|_\infty(l_{k-1}\,\mathfrak{m}_{j,k-1}+1)+l_{k-1}\,\|\theta_3-j\|_\infty\,\mathfrak{e}_{k-1}.
\end{split}$$

(11.89)
```

Therefore, we obtain that for all $j \in \{1,2\}$, $k \in \{1,2,\dots,L\}\cap(1,\infty)$ it holds that

(11.90)

(11.91)
