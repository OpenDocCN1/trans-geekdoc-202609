Combining this and (15.20) with (15.19) establishes that for all $ p \in [1, \infty) $ it holds that

```
$$\begin{eqnarray*} \left(\mathbb{E} \left[ \left( \int_D |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \, \mathbb{P}_{X_1}(\mathrm{d}x) \right)^p \right] \right)^{1/p} \leq \left[ \inf_{\theta \in [-c, c]^d} \sup_{x \in D} |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \right] + \frac{4(v - u)b\mathbf{L}(\|\mathbf{1}\|_{\infty} + 1)^r c^\mathbf{L} \max \{ 1, p \}}{K^{[L - 1](\|\mathbf{1}\|_{\infty} + 1) - 2}} \quad (15.22) \\ \hspace{2cm} + \frac{18 \max \{ 1, (v - u)^2 \} \mathbf{L}(\|\mathbf{1}\|_{\infty} + 1)^2 \max \{ p, \ln(3Mb) \}}{\sqrt{M}} .\end{eqnarray*}$$
```

In addition, observe that that Jensen's inequality shows that for all $ p \in (0, \infty) $ it holds that

```
$$\begin{eqnarray*} \left(\mathbb{E} \left[ \left( \int_D |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \, \mathbb{P}_{X_1}(\mathrm{d}x) \right)^p \right] \right)^{1/p} \leq \left( \mathbb{E} \left[ \left( \int_D |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \, \mathbb{P}_{X_1}(\mathrm{d}x) \right)^{\max \{ 1, p \}} \right] \right)^{\frac{1}{\max \{ 1, p \}}} \quad (15.23)\end{eqnarray*}$$
```

This, (15.22), and the fact that $\ln(3Mbb) \geq 1$ prove that for all $ p \in (0, \infty) $ it holds that

```
$$\begin{eqnarray*} \left(\mathbb{E} \left[ \left( \int_D |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \, \mathbb{P}_{X_1}(\mathrm{d}x) \right)^p \right] \right)^{1/p} \leq \left[ \inf_{\theta \in [-c, c]^d} \sup_{x \in D} |\mathcal{H}^{\Theta_{u, v}^{\mathbf{k}, 1}}(x) - \mathcal{E}(x)|^2 \right] + \frac{4(v - u)b\mathbf{L}(\|\mathbf{1}\|_{\infty} + 1)^r c^\mathbf{L} \max \{ 1, p \}}{K^{[L - 1](\|\mathbf{1}\|_{\infty} + 1) - 2}} \quad (15.24) \\ \hspace{2cm} + \frac{18 \max \{ 1, (v - u)^2 \} \mathbf{L}(\|\mathbf{1}\|_{\infty} + 1)^2 \max \{ p, \ln(3Mb) \}}{\sqrt{M}} .\end{eqnarray*}$$
```

The proof of Proposition 15.1.2 is thus complete.

> □

Lemma 15.1.3. Let $ a, x, p \in (0, \infty) $. Then $ ax^p \leq \exp( \frac{a^{1/p} p x}{e} ) $.

Proof of Lemma 15.1.3. Note that the fact that for all $ y \in \mathbb{R} $ it holds that $ y + 1 \leq e^y $ demonstrates that

```
$$\begin{eqnarray*} ax^p = (a^{1/p} x)^p = [ e( \frac{a^{1/p} p x}{e} - 1 + 1 ) ]^p \leq [ e \exp(\frac{a^{1/p} p x}{e} - 1) ]^p = \exp( \frac{a^{1/p} p x}{e} ) . \quad (15.25) \end{eqnarray*}$$
```

The proof of Lemma 15.1.3 is thus complete.

Lemma 15.1.4. Let $ M, c \in [1, \infty) $, $ B \in [c, \infty) $. Then $\ln(3MBc) \leq \frac{23B}{18}\ln(eM) $.

Proof of Lemma 15.1.4. Observe that Lemma 15.1.3 and the fact that $ 2\sqrt[3]{c} \leq \frac{23}{18} $ imply that

```
$$\begin{eqnarray*} 3B^2 \leq \exp(\frac{2\sqrt{3}B}{e}) \leq \exp( \frac{23B}{18} ) . \quad (15.26) \end{eqnarray*}$$
```

The fact that $ B \geq c \geq 1 $ and $ M \geq 1 $ therefore ensures that

```
$$\begin{eqnarray*} \ln(3MBc) \leq \ln(3B^2M) \leq \ln(eM)^{23B/18} = \frac{23B}{18}\ln(eM) . \quad (15.27) \end{eqnarray*}$$
```

The proof of Lemma 15.1.4 is thus complete.
