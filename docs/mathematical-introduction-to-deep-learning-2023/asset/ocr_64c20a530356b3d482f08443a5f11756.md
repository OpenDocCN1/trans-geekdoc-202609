with $(U \supset \vartheta \mapsto \mathcal{L}(\vartheta, x) \in \mathbb{R}) \in C^{1}(U, \mathbb{R})$ that

$\boldsymbol{g}(\theta, x) = (\nabla_{\theta} \mathcal{L})(\theta, x).$ (7.139)

Then we say that **$\Theta$** is the **RMSprop SGD** process on $((\Omega, \mathcal{F}, \mathbb{P}), (\mathcal{S}, \mathcal{S}))$ for the loss function $\mathcal{L}$ with generalized gradient $\boldsymbol{g}$, learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(X_{n, j})_{(n, j) \in(\{k, l \in \mathbb{N}: l \leq J_{k}\})}$ (we say that $\Theta$ is the **RMSprop SGD** process for the loss function $\mathcal{L}$ with learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(X_{n, j})_{(n, j) \in(\{k, l \in \mathbb{N}: l \leq J_{k}\})}$) if and only if it holds that $\Theta=(\Theta^{(1)}, \ldots, \Theta^{(8)}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{9}$ is the function from $\mathbb{N}_{0} \times \Omega$ to $\mathbb{R}^{9}$ which satisfies that there exists $\mathbb{M}=(\mathbb{M}^{(1)}), \ldots, \mathbb{M}^{(8)}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{9}$ such that for all $n \in \mathbb{N}$, $i \in\{1,2, \ldots, \mathfrak{d}\}$ it holds that

$\Theta_{0}=\boldsymbol{\xi}, \quad \mathbb{M}_{0}=0,$ (7.140)

$\mathbb{M}_{n}^{(i)}=\beta_{n} \mathbb{M}_{n-1}^{(i)}+\left(1-\beta_{n}\right)\left[\frac{1}{J_{n}} \sum_{j=1}^{J_{n}} \boldsymbol{g}_{i}\left(\Theta_{n-1}, X_{n, j}\right)\right]^{2},$ (7.141)

and $\Theta_{n}^{(i)}=\Theta_{n-1}^{(i)}-\frac{\gamma_{n}}{\varepsilon+\left[\mathbb{M}_{n}^{(i)}\right]^{1 / 2}}\left[\frac{1}{J_{n}} \sum_{j=1}^{J_{n}} \boldsymbol{g}_{i}\left(\Theta_{n-1}, X_{n, j}\right)\right].$ (7.142)

> **Remark 7.7.2.** In Hinton et al. [199] it is proposed to choose $0.9 = \beta_{1} = \beta_{2} = \ldots$ as default values for the second moment decay factors $(\beta_{n})_{n \in \mathbb{N}} \subseteq [0,1]$ in Definition **7.7.1**.
