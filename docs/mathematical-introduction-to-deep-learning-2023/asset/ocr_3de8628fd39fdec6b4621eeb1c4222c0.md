Item (iv) in Lemma 3.1.2, and (3.18) hence demonstrate that for all $k,l \in \{1,2,\dots,K\}$, $x \in \mathfrak{I}_{k-1}, \mathfrak{I}_k]$, $y \in \mathfrak{I}_{l-1}, \mathfrak{I}_l]$ with $k < l$ and $x \ne y$ it holds that

```
    \begin{align}
    |\mathbb{I}(x)-\mathbb{I}(y)| &\\
    \leq \ \left|\mathbb{I}(x)-\mathbb{I}(x_{k})\right|&+\left(\sum_{j=k+1}^{l-1}w_{j}f(\mathfrak{x}_{j}-\mathfrak{x}_{j-1})\right)+\left|\mathbb{I}(\mathfrak{y}_{l-1})-\mathbb{I}(y)\right| \\
    = &\left|\mathbb{I}(x)-\mathbb{I}(\mathfrak{x}_{k})\right|+\left(\sum_{j=k+1}^{l-1}\left(\frac{w_{j}f(\mathfrak{x}_{j}-\mathfrak{x}_{j-1})}{\mathfrak{x}_{j}-\mathfrak{x}_{j-1}}\right)(\mathfrak{x}_{j}-\mathfrak{x}_{j-1})\right)+\left|\mathbb{I}(\mathfrak{y}_{l-1})-\mathbb{I}(y)\right| \tag{3.22}\\
    \leq &\left|\mathbb{I}(\mathfrak{x}_{k})-\mathbb{I}(x)\right|+L(\mathfrak{y}_{l-1}-\mathfrak{x}_{k})+|\mathbb{I}(y)-\mathbb{I}(\mathfrak{y}_{l-1})|.
    \end{align}
```

This and (3.21) show that for all $k,l \in \{1,2,\dots,K\}$, $x \in \mathfrak{I}_{k-1}, \mathfrak{I}_k]$, $y \in \mathfrak{I}_{l-1}, \mathfrak{I}_l]$ with $k < l$ and $x \ne y$ it holds that

```
$$|\mathbb{I}(x)-\mathbb{I}(y)| \leq L \left( (\mathfrak{x}_{k}-x)+\left(\sum_{j=k+1}^{l-1}(\mathfrak{x}_{j}-\mathfrak{x}_{j-1})\right)+(y-\mathfrak{y}_{l-1}) \right) = L |x-y| \tag{3.23}$$
```

Combining this and (3.20) proves that for all $x, y \in \mathfrak{I}_{0}, \mathfrak{I}_K]$ with $x \ne y$ it holds that

```
$$|\mathbb{I}(x)-\mathbb{I}(y)| \leq L |x-y|. \tag{3.24}$$
```

This, the fact that for all $x, y \in (-\infty, \mathfrak{I}_0]$ with $x \ne y$ it holds that

```
$$|\mathbb{I}(x)-\mathbb{I}(y)| = 0 \leq L |x-y|, \tag{3.25}$$
```

the fact that for all $x, y \in \mathfrak{I}_K, \infty)$ with $x \ne y$ it holds that

```
$$|\mathbb{I}(x)-\mathbb{I}(y)| = 0 \leq L |x-y|, \tag{3.26}$$
```

and the triangle inequality therefore establish that for all $x, y \in \mathbb{R}$ with $x \ne y$ it holds that

```
$$|\mathbb{I}(x)-\mathbb{I}(y)| \leq L |x-y|. \tag{3.27}$$
```

This proves item (i). Observe that item (iii) in Lemma 3.1.6 ensures that for all $k \in \{1,2,\dots,K\}$, $x \in \mathfrak{I}_{k-1}, \mathfrak{I}_k]$ it holds that

```
    \begin{align}
    |\mathbb{I}(x)-f(x)| &= \left|\left(\frac{\mathfrak{x}_{k}-x}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)f(\mathfrak{x}_{k-1})+\left(\frac{x-\mathfrak{x}_{k-1}}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)f(\mathfrak{x}_{k})-f(x)\right| \\
    &= \left|\left(\frac{\mathfrak{x}_{k}-x}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)(f(\mathfrak{x}_{k-1})-f(x))+\left(\frac{x-\mathfrak{x}_{k-1}}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)(f(\mathfrak{x}_{k})-f(x))\right| \\ 
    &\leq \left(\frac{\mathfrak{x}_{k}-x}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)|f(\mathfrak{x}_{k-1})-f(x)| + \left(\frac{x-\mathfrak{x}_{k-1}}{\mathfrak{x}_{k}-\mathfrak{x}_{k-1}}\right)|f(\mathfrak{x}_{k})-f(x)|. \tag{3.28}
    \end{align}
```
