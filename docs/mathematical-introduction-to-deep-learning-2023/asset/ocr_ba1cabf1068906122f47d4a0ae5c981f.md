Therefore, we obtain for all $x \in \mathbb{R}$ with $|x - \xi| \leq \frac{1}{2} \left[ \sum_{n=m}^{N} \frac{|\beta_n n!|}{|\beta_m m!|} \right]^{-1}$ that

$|p'(x)| \geq |x - \xi|^{m-1} \left( |\beta_m m!| - |x - \xi| \left[ \sum_{n=m+1}^{N} |\beta_n n!| \right] \right)$
$\geq |x - \xi|^{m-1} \left( |\beta_m m!| - \frac{|\beta_m m!|}{2} \left( |x - \xi| \left[ \sum_{n=m}^{N} \frac{2|\beta_n n!|}{|\beta_m m!|} \right] \right) \right)$
$\geq |x - \xi|^{m-1} \left( |\beta_m m!| - \frac{|\beta_m m!|}{2} \right) = \frac{1}{2}|x - \xi|^{m-1} |\beta_m m!|.$

Combining this with **(9.54)** demonstrates that for all $x \in \mathbb{R}$ with $|x - \xi| \leq \frac{1}{2} \left[ \sum_{n=m}^{N} \frac{|\beta_n n!|}{|\beta_m m!|} \right]^{-1}$ it holds that

$|p(x) - p(\xi)|^{\alpha} \leq \frac{\xi}{2}|x - \xi|^{m-1} |\beta_m m!| \leq c |p'(x)|.$

This establishes **(9.48)**. The proof of Corollary **9.6.2** is thus complete.

**Corollary 9.6.3** (Quantitative standard **KL** inequalities for general one-dimensional polynomials). *Let* $\xi \in \mathbb{R}$, $N \in \mathbb{N}$, *p* $\in \mathcal{C}^{\infty}(\mathbb{R}, \mathbb{R})$ *satisfy for all* $x \in \mathbb{R}$ *that* $p^{(N+1)}(x) = 0$, *let* $\beta_0, \beta_1, \dots, \beta_N \in \mathbb{R}$ *satisfy for all* $n \in \{0, 1, \dots, N\}$ *that* $\beta_n = \frac{p^{(n)}(\xi)}{n!}$, *let* $\rho \in \mathbb{R}$ *satisfy* $\rho = \mathbb{1}_{\{0\}}(\sum_{n=1}^{N} |\beta_n n!|) + \min(\{|\sum_{n=1}^{N} |\beta_n n!|\} \setminus \{0\}\} \cup \{\sum_{n=1}^{N} |\beta_n n!|\}$, *and let* $\alpha \in (0, 1]$, *c, \varepsilon \in* $[0, \infty)$ *satisfy*

$\alpha \geq 1 - N^{-1}$, $c \geq 2\rho^{-1} \left[ \sum_{n=1}^{N} |\beta_n|^\alpha \right]$, $\varepsilon \leq \rho \mathbb{1}_{\{0\}}(\sum_{n=1}^{N} |\beta_n|) + 2(\sum_{n=1}^{N} |\beta_n n!|)^{-1}.$

*Then it holds for all* $x \in [\xi - \varepsilon, \xi + \varepsilon]$ *that*

$|p(x) - p(\xi)|^{\alpha} \leq c |p'(x)|.$

*Proof of Corollary 9.6.3.* Throughout this proof, assume without loss of generality that

$\sup_{x \in \mathbb{R}} |p(x) - p(\xi)| > 0.$

Note that Corollary **9.6.1** and **(9.60)** ensure that $\sum_{n=1}^{N} |\beta_n| > 0$. Hence, we obtain that there exists $m \in \{1, 2, \dots, N\}$ which satisfies

$|\beta_m| > 0 = \sum_{n=1}^{m-1} |\beta_n|.$

Observe that **(9.61)**, the fact that $\alpha \geq 1 - N^{-1}$, and Corollary **9.6.2** ensure that for all $x \in \mathbb{R}$ with $|x - \xi| \leq \frac{1}{2} \left[ \sum_{n=1}^{N} \frac{|\beta_n n!|}{|\beta_m m!|} \right]^{-1}$ it holds that

$|p(x) - p(\xi)|^{\alpha} \leq \left[ \sum_{n=1}^{N} \frac{2|\beta_n|^{\alpha}}{|\beta_m m!|} \right] |p'(x)| \leq \left[ \frac{2}{\rho} \left( \sum_{n=1}^{N} |\beta_n|^{\alpha} \right) \right] |p'(x)| \leq c |p'(x)|.$

This establishes **(9.59)**. The proof of Corollary **9.6.3** is thus complete.
