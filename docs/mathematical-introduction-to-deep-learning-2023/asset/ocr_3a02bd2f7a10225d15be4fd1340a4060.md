The fact that $P$ is $\mathcal{B}[[-B, B]^d]/\mathcal{B}[[-B, B]^b]$-measurable and (11.113) therefore prove item (i). In addition, note that (11.113), (11.115), and the fact that $2 \leq \mathbf{b} = \sum_{i=1}^{\mathbf{L}}\mathbf{l}_i(\mathbf{l}_i+1) \leq \mathbf{L}(\|\mathbf{l}\|_\infty+1)^2$ ensure that for all $\theta \in [-B, B]^d$, $p \in (0, \infty)$ it holds that

```
(E[min_{k \in \{1, 2, \ldots, K\}} |R(\Theta_k) - R(\theta)|^p])^{1/p}
= (E[min_{k \in \{1, 2, \ldots, K\}} |R(P(\Theta_k)) - R(P(\theta))|^p])^{1/p}
\leq \frac{4(v-u)b\mathbf{L}(\|\mathbf{l}\|_\infty+1)\mathbf{L}B^l\sqrt{\max\{1, p/3\}}}{K^{1/3}} 	ag{11.116}

```

This establishes item (ii). The proof of Corollary 11.3.9 is thus complete.
