This assures that

```
$$\begin{align*} &\Theta_{T+\gamma} - \Theta_{T}\\ &= \Theta_{T+\frac{\gamma}{2}} - \left[\frac{\gamma}{2}\right]\mathscr{G}(\Theta_{T+\frac{\gamma}{2}}) + \left[\frac{\gamma^{2}}{8}\right]\mathscr{G}'(\Theta_{T+\frac{\gamma}{2}})\mathscr{G}(\Theta_{T+\frac{\gamma}{2}})\\ &\quad + \frac{\gamma^{3}}{16}\int_{0}^{1}\left(1-r\right)^{2}\left(\mathscr{G}''(\Theta_{T+(1+r)\gamma/2})\langle\mathscr{G}(\Theta_{T+(1+r)\gamma/2}),\mathscr{G}(\Theta_{T+(1+r)\gamma/2})\rangle\\ &\quad + \mathscr{G}'(\Theta_{T+(1+r)\gamma/2})\mathscr{G}'(\Theta_{T+(1+r)\gamma/2})\mathscr{G}(\Theta_{T+(1+r)\gamma/2})\right)\mathrm{d}r\\ &\quad - \left[\Theta_{T+\frac{\gamma}{2}} - \left[\frac{\gamma}{2}\right]\mathscr{G}(\Theta_{T+\frac{\gamma}{2}}) + \left[\frac{\gamma^{2}}{8}\right]\mathscr{G}'(\Theta_{T+\frac{\gamma}{2}})\mathscr{G}(\Theta_{T+\frac{\gamma}{2}})\\ &\quad - \frac{\gamma^{3}}{16}\int_{0}^{1}\left(1-r\right)^{2}\left(\mathscr{G}''(\Theta_{T+(1-r)\gamma/2})\langle\mathscr{G}(\Theta_{T+(1-r)\gamma/2}),\mathscr{G}(\Theta_{T+(1-r)\gamma/2})\rangle\\ &\quad + \mathscr{G}'(\Theta_{T+(1-r)\gamma/2})\mathscr{G}'(\Theta_{T+(1-r)\gamma/2})\mathscr{G}(\Theta_{T+(1-r)\gamma/2})\right)\mathrm{d}r\bigg]\\ &= \gamma\mathscr{G}(\Theta_{T+\frac{\gamma}{2}}) + \frac{\gamma^{3}}{16}\int_{0}^{1}\left(1-r\right)^{2}\left(\mathscr{G}''(\Theta_{T+(1+r)\gamma/2})\langle\mathscr{G}(\Theta_{T+(1+r)\gamma/2}),\mathscr{G}(\Theta_{T+(1+r)\gamma/2})\rangle\right.\\ &\quad \left. + \mathscr{G}'(\Theta_{T+(1+r)\gamma/2})\mathscr{G}'(\Theta_{T+(1+r)\gamma/2})\mathscr{G}(\Theta_{T+(1+r)\gamma/2})\right.\\ &\quad \left. + \mathscr{G}''(\Theta_{T+(1-r)\gamma/2})\langle\mathscr{G}(\Theta_{T+(1-r)\gamma/2}),\mathscr{G}(\Theta_{T+(1-r)\gamma/2})\rangle\right.\\ &\quad \left. + \mathscr{G}'(\Theta_{T+(1-r)\gamma/2})\mathscr{G}'(\Theta_{T+(1-r)\gamma/2})\mathscr{G}(\Theta_{T+(1-r)\gamma/2})\right)\mathrm{d}r.\end{align*}$$
```

This, (6.169), and (6.175) assure that
