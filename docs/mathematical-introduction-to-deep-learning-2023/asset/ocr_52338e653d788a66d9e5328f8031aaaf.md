*Proof of Corollary 9.11.5.* Note that Proposition 9.11.4 demonstrates that there exist $\vartheta \in \mathbb{R}^{\mathfrak{d}}$, $\mathfrak{C}, \tau, \beta \in (0, \infty)$ which satisfy for all $t \in [\tau, \infty)$ that

```
$\|\Theta_{t}-\vartheta\|_{2} \leq\left(1+\mathfrak{C}(t-\tau)\right)^{-\beta}\quad \mathrm{and} \quad 0 \leq \mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\vartheta) \leq\left(1+\mathfrak{C}(t-\tau)\right)^{-1}$. (9.184)
```

In the following let $\mathcal{K} \in (0, \infty)$ satisfy

```
$\mathcal{K}=\max \left\{1+\tau,\left(1+\tau\right)^{\beta}, \mathfrak{C} \tau^{-1}, \mathfrak{C} \tau^{-\beta},\left(1+\tau\right)^{\beta}\left(\sup _{s \in[0, \tau]}\left\|\Theta_{s}-\vartheta\right\|_{2}\right),(1+\tau)\left(\mathcal{L}\left(\Theta_{0}\right)-\mathcal{L}(\vartheta)\right)\right\}$. (9.185)
```

Observe that (9.184), (9.185), and the fact that $[0, \infty) \ni t \mapsto \mathcal{L}\left(\Theta_{t}\right) \in \mathbb{R}$ is non-increasing prove for all $t \in[0, \tau]$ that

```
$\|\Theta_{t}-\vartheta\|_{2} \leq \sup _{s \in[0, \tau]}\left\|\Theta_{s}-\vartheta\right\|_{2} \leq \mathcal{K}\left(1+\tau\right)^{-\beta} \leq \mathcal{K}\left(1+t\right)^{-\beta}$ (9.186)
```

and

```
$0 \leq \mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\vartheta) \leq \mathcal{L}\left(\Theta_{0}\right)-\mathcal{L}(\vartheta) \leq \mathcal{K}\left(1+\tau^{-1}\right) \leq \mathcal{K}\left(1+t^{-1}\right)$. (9.187)
```

Furthermore, note that (9.184) and (9.185) imply for all $t \in[\tau, \infty)$ that

```
$\begin{gathered} \|\Theta_{t}-\vartheta\|_{2} \leq\left(1+\mathfrak{C}(t-\tau)\right)^{-\beta}=\mathcal{K}\left(\mathfrak{C}^{1 / \beta}+\mathfrak{C}^{1 / \beta} \mathfrak{C}(t-\tau)\right)^{-\beta} \\ \leq \mathcal{K}\left(\mathfrak{C}^{1 / \beta}+t-\tau\right)^{-\beta} \leq \mathcal{K}\left(1+t\right)^{-\beta} . \end{gathered}$ (9.188)
```

Moreover, observe that (9.184) and (9.185) demonstrate for all $t \in[\tau, \infty)$ that

```
$0 \leq \mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\vartheta) \leq \mathcal{K}\left(\mathcal{K}+\mathfrak{C} \mathfrak{C}(t-\tau)\right)^{-1} \leq \mathcal{K}\left(\mathcal{K}-\tau+t\right)^{-1} \leq \mathcal{K}\left(1+t^{-1}\right)$. (9.189)
```

The proof of Corollary 9.11.5 is thus complete. $\square$
