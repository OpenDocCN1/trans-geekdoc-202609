**Corollary 9.8.4.** Let $\varepsilon \in (0, \infty)$, $U \subseteq \mathbb{R}$, $\vartheta \in U$ satisfy $U = \{ \theta \in \mathbb{R} : |\theta - \vartheta| \le \varepsilon \}$ and let $\mathscr{L} : U \rightarrow \mathbb{R}$ satisfy for all $\theta \in U$ that

$$\limsup_{K \to \infty} \left| \mathscr{L} (\theta) - \mathscr{L} (\vartheta) - \sum_{k=1}^{K} a_{k} (\theta - \vartheta)^{k} \right| = 0. \tag{9.99}$$

Then there exist $\delta \in (0, \varepsilon)$, $c \in (0, \infty)$, $\alpha \in (0, 1)$ such that for all $\theta \in \{ \xi \in \mathbb{R} : |\xi - \vartheta| < \delta \}$ it holds that

$$|\mathscr{L} (\theta) - \mathscr{L} (\vartheta)|^{\alpha} \le c \, |\mathscr{L}^{\prime} (\vartheta)|. \tag{9.100}$$

*Proof of Corollary 9.8.4.* Throughout this proof, let $V \subseteq \mathbb{R}$ satisfy $V = \{ \theta \in \mathbb{R} : |\theta| \le \varepsilon \}$ and let $\mathcal{M} : V \rightarrow \mathbb{R}$ satisfy for all $\theta \in V$ that $\mathcal{M}(\theta) = \mathscr{L} (\theta + \vartheta)$. Observe that (9.99) and the fact that for all $\theta \in V$ it holds that $\theta + \vartheta \in U$ ensures that for all $\theta \in V$ it holds that

$$\begin{aligned} &\limsup_{K \to \infty} \left| \mathcal{M} (\theta) - \mathcal{M}(0) - \sum_{k=1}^{K} a_{k} \theta^{k} \right| \\ &= \limsup_{K \to \infty} \left| \mathscr{L}(\theta + \vartheta) - \mathscr{L} (\vartheta) - \sum_{k=1}^{K} a_{k} ((\theta + \vartheta) - \vartheta)^{k} \right| = 0. \end{aligned} \tag{9.101}$$

Corollary 9.8.3 hence establishes that there exist $\delta \in (0, \varepsilon)$, $c \in (0, \infty)$, $\alpha \in (0, 1)$ which satisfy that for all $\theta \in \{ \xi \in \mathbb{R} : |\xi| < \delta \}$ it holds that

$$|\mathcal{M} (\theta) - \mathcal{M}(0)|^{\alpha} \le c \, |\mathcal{M}^{\prime} (0)|. \tag{9.102}$$

Therefore, we obtain for all $\theta \in \{ \xi \in \mathbb{R} : |\xi| < \delta \}$ that

$$|\mathscr{L}(\theta + \vartheta) - \mathscr{L} (\vartheta)|^{\alpha} = c \, |\mathscr{L}^{\prime} (\vartheta)|. \tag{9.103}$$

This implies (9.100). The proof of Corollary 9.8.4 is thus complete.

**Corollary 9.8.5.** Let $U \subseteq \mathbb{R}$ be open, let $\mathscr{L} : U \rightarrow \mathbb{R}$ be analytic, and let $\vartheta \in U$ (*cf.* Definition 9.7.1). Then there exist $\varepsilon, c \in (0, \infty)$, $\alpha \in (0, 1)$ such that for all $\theta \in \{ \xi \in U : |\vartheta - \xi| < \varepsilon \}$ it holds that

$$|\mathscr{L} (\vartheta) - \mathscr{L} (\theta)|^{\alpha} \le c \, | (\nabla \mathscr{L}) (\vartheta)|. \tag{9.104}$$

*Proof of Corollary 9.8.5.* Note that Corollary 9.8.4 establishes (9.104). The proof of Corollary 9.8.5 is thus complete.

**Corollary 9.8.6.** Let $\mathscr{L} : \mathbb{R} \rightarrow \mathbb{R}$ be analytic (*cf.* Definition 9.7.1). Then $\mathscr{L}$ is a standard *KL* function (*cf.* Definition 9.1.2).

*Proof of Corollary 9.8.6.* Observe that (9.2) and Corollary 9.8.5 establish that $\mathscr{L}$ is a standard *KL* function (*cf.* Definition 9.1.2). The proof of Corollary 9.8.6 is thus complete.
