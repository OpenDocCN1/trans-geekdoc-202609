
(iii) it holds for all $x \in \{y \in U : |y| < \varepsilon\}$, $l \in \mathbb {N}$ that $\sum _ { k = l } ^ { \infty } [ \frac { k ! } { [ k - l ] ! } ] | a _ { k } | | x | ^ { k - l } < \infty$ and

$$ f ^ { ( l ) } ( x ) = \sum _ { k = l } ^ { \infty } \left[ \frac { k ! } { [ k - l ] ! } \right] a _ { k } x ^ { k - l } , $$

and

(iv) it holds for all $k \in \mathbb { N }$ that $f ^ { ( k ) } ( 0 ) = k ! a _ { k }$.

Proof of Lemma 9.8.1. Lemma 9.8.2. Let $\varepsilon , \delta \in ( 0 , 1 )$, $N \in \mathbb { N } \backslash \{ 1 \}$, $( a _ { n } ) _ { n \in \mathbb { N } _ { 0 } } \subseteq \mathbb { R }$ satisfy $N = \min \{ \{ k \in \mathbb { N } : a _ { k } \neq 0 \} \cup \{ \infty \} \}$, let $U \subseteq \mathbb { R }$ satisfy $U = \{ \xi \in \mathbb { R } : | \xi | \leq \varepsilon \}$, let $\mathcal { L } : U \rightarrow \mathbb { R }$ satisfy for all $\theta \in U$ that

$$ \limsup _ { K \rightarrow \infty } \left| \mathcal { L } ( \theta ) - \mathcal { L } ( 0 ) - \left[ \sum _ { k = 1 } ^ { K } a _ { k } \theta ^ { k } \right] \right| = 0 , $$

and let $M \in \mathbb { N } \cap ( N , \infty )$ satisfy for all $k \in \mathbb { N } \cap [ M , \infty )$ that $k ! | a _ { k } | \leq ( 2 \varepsilon ^ { - 1 } ) ^ { k }$ and

$$ \delta = \min \{ \frac { \varepsilon } { 4 } , a _ { N } [ 2 ( \operatorname* { m a x } [ | a _ { 1 } | , | a _ { 2 } | , \ldots , | a _ { M } | ] ) + ( 2 \varepsilon ^ { - 1 } ) ^ { N + 1 } ] ^ { - 1 } \} . $$

Then it holds for all $\theta \in \{ \xi \in \mathbb { R } : | \xi | < \delta \}$ that

$$ | \mathcal { L } ( \theta ) - \mathcal { L } ( 0 ) | ^ { \frac { N - 1 } { N } } \leq 2 | \mathcal { L } ^ { \prime } ( \theta ) | . $$

Proof of Lemma 9.8.2. Note that the assumption that for all $k \in \mathbb { N } \cap [ M , \infty )$ it holds that $| a _ { k } | \leq k ! | a _ { k } | \leq ( 2 \varepsilon ^ { - 1 } ) ^ { k }$ ensures that for all $K \in \mathbb { N } \cap [ M , \infty )$ it holds that

$$ \begin{aligned} \sum_ { k = N + 1 } ^ { K + N + 1 } & | a _ { k } | | \theta | ^ { k } \\ &= | \theta | ^ { N + 1 } \left[ \sum _ { k = 0 } ^ { K } | a _ { k + N + 1 } | | \theta | ^ { k } \right] \\ &= | \theta | ^ { N + 1 } \left[ \left( \sum _ { k = 0 } ^ { M } | a _ { k + N + 1 } | | \theta | ^ { k } \right) + \left( \sum _ { k = M + 1 } ^ { K } | a _ { k + N + 1 } | | \theta | ^ { k } \right) \right] \\ & \leq | \theta | ^ { N + 1 } \left[ \left( \operatorname* { m a x } \{ | a _ { 1 } | , | a _ { 2 } | , \ldots , | a _ { M } | \} \right) \left( \sum _ { k = 0 } ^ { M } | \theta | ^ { k } \right) + \left( \sum _ { k = M + 1 } ^ { K } ( 2 \varepsilon ^ { - 1 } ) ^ { k + N + 1 } | \theta | ^ { k } \right) \right] \\ &= | \theta | ^ { N + 1 } \left[ \left( \operatorname* { m a x } \{ | a _ { 1 } | , | a _ { 2 } | , \ldots , | a _ { M } | \} \right) \left( \sum _ { k = 0 } ^ { M } | \theta | ^ { k } \right) + ( 2 \varepsilon ^ { - 1 } ) ^ { N + 1 } \left( \sum _ { k = M + 1 } ^ { K } ( 2 \varepsilon ^ { - 1 } | \theta | ) ^ { k } \right) \right] . \end{aligned} $$

Therefore, we obtain for all $\theta \in \mathbb{R}$ with $|\theta| \leq \frac{\varepsilon}{4}$ that

$$ \begin{align}
\sum_{k=N+1}^{\infty} |a_{k}| |\theta|^{k} &\leq |\theta|^{N+1} \left[ \left\{ \max\{ |a_{1}|, |a_{2}|, \ldots, |a_{M}| \} \right\} \left( \sum_{k=0}^{\infty} \left| \frac{1}{4} \right|^{k} \right) + \left( 2\varepsilon^{-1} \right)^{N+1} \left( \sum_{k=1}^{\infty} \left| \frac{1}{2} \right|^{k} \right) \right] \\
&\leq |\theta|^{N+1} \left[ 2\left\{ \max\{ |a_{1}|, |a_{2}|, \ldots, |a_{M}| \} + \left( 2\varepsilon^{-1} \right)^{N+1} \right\} \right].
\end{align} \tag{9.84} $$

This demonstrates that for all $\theta \in \mathbb{R}$ with $|\theta| \leq \delta$ it holds that

$$ \sum_{k=N+1}^{\infty} |a_{k}| |\theta|^{k} \leq |a_{N}| |\theta|^{N}. \tag{9.85} $$

Hence, we obtain for all $\theta \in \mathbb{R}$ with $|\theta| \leq \delta$ that

$$ \left| \mathcal{L}(\theta) - \mathcal{L}(0) \right| = \left| \sum_{k=N}^{\infty} a_{k}\theta^{k} \right| \leq |a_{N}| |\theta|^{N} + \sum_{k=N+1}^{\infty} |a_{k}| |\theta|^{k} \leq 2|a_{N}| |\theta|^{N}. \tag{9.86} $$

Next observe that the assumption that for all $k \in \mathbb{N} \cap [M, \infty)$ it holds that $k|a_{k}| \leq \left( 2\varepsilon^{-1} \right)^{k}$ ensures that for all $K \in \mathbb{N} \cap [M, \infty)$ it holds that

$$ \begin{align}
\sum_{k=N+1}^{N+K+1} k|a_{k}| |\theta|^{k-1}
&= |\theta|^{N} \left[ \left( \sum_{k=0}^{M-N-1} (k+N+1)|a_{k+N+1}| |\theta|^{k} \right) + \left( \sum_{k=M-N}^{K} (k+N+1)|a_{k+N+1}| |\theta|^{k} \right) \right] \\

&\leq |\theta|^{N} \left[ \max\{ |a_{1}|, 2|a_{2}|, \ldots, M|a_{M}| \} \left( \sum_{k=0}^{M-N-1} |\theta|^{k} \right) + \left( 2\varepsilon^{-1} \right)^{N+1} \left( \sum_{k=M-N}^{K-N} \left| 2\varepsilon^{-1}\theta \right|^{k} \right) \right].
\end{align} \tag{9.87} $$

Therefore, we obtain for all $\theta \in \mathbb{R}$ with $|\theta| \leq \frac{\varepsilon}{4}$ that

$$ \begin{align}
\sum_{k=N+1}^{\infty} k|a_{k}| |\theta|^{k-1}
&\leq |\theta|^{N} \left[ \max\{ |a_{1}|, 2|a_{2}|, \ldots, M|a_{M}| \} \left( \sum_{k=0}^{\infty} \left| \frac{1}{4} \right|^{k} \right) + \left( 2\varepsilon^{-1} \right)^{N+1} \left( \sum_{k=1}^{\infty} \left| \frac{1}{2} \right|^{k} \right) \right] \\
&\leq |\theta|^{N} \left[ 2\left\{ \max\{ |a_{1}|, 2|a_{2}|, \ldots, M|a_{M}| \} + \left( 2\varepsilon^{-1} \right)^{N+1} \right\} \right].
\end{align} \tag{9.88} $$

This establishes that for all $\theta \in \mathbb{R}$ with $|\theta| \leq \delta$ it holds that

$$ \sum_{k=N+1}^{K} k|a_{k}| |\theta|^{k-1} \leq |a_{N}| |\theta|^{N-1}. \tag{9.89} $$

## 9.8. Standard KL inequalities for one-dimensional analytic functions

Hence, we obtain for all $K \in \mathbb{N} \cap [N, \infty)$, $\theta \in \mathbb{R}$ with $|\theta| < \delta$ that

$$ \left| \sum_{k=1}^{K} k a_{k} \theta^{k-1} \right| = \left| \sum_{k=N}^{K} k a_{k} \theta^{k-1} \right| \geq N |a_{N}| |\theta|^{N-1} - \sum_{k=N+1}^{\infty} |k| |a_{k}| |\theta|^{k-1} \geq (N-1) |a_{N}| |\theta|^{N-1}. \tag{9.90} $$

Proposition 9.7.2 therefore proves that for all $\theta \in \{ \xi \in \mathbb{R} : |\xi| < \varepsilon \}$ it holds that $\sum_{k=1}^{\infty} k|a_{k}| |\theta|^{k-1} < \infty$ and

$$ |\mathscr{L}'(\theta)| = \left| \sum_{k=1}^{\infty} k a_{k} \theta^{k-1} \right| \geq (N-1) |a_{N}| |\theta|^{N-1}. \tag{9.91} $$

Combining this with (9.86) shows that for all $\theta \in \mathbb{R}$ with $|\theta| \leq \delta$ it holds that

$$ |\mathscr{L}(\theta) - \mathscr{L}(0)|^{\frac{N-1}{N}} \leq |2 a_{N}|^{\frac{N-1}{N}} |\theta|^{N-1} \leq |2 a_{N}|^{\frac{N-1}{N}} (N-1)^{-1} |a_{N}|^{-1} \mathscr{L}'(\theta) \leq 2 \mathscr{L}'(\theta). \tag{9.92} $$

The proof of Lemma 9.8.2 is thus complete.

**Corollary 9.8.3.** Let $\varepsilon \in (0, \infty)$, $U \subseteq \mathbb{R}$ satisfy $U = \{ \theta \in \mathbb{R} : |\theta| \leq \varepsilon \}$ and let $\mathscr{L} : U \rightarrow \mathbb{R}$ satisfy for all $\theta \in U$ that

$$ \limsup_{K \to \infty} \left| \mathscr{L}(\theta) - \mathscr{L}(0) - \sum_{k=1}^{K} a_{k} \theta^{k} \right| = 0. \tag{9.93} $$

Then there exist $\delta \in (0, \varepsilon)$, $c \in (0, \infty)$, $\alpha \in (0, 1)$ such that for all $\theta \in \{ \xi \in \mathbb{R} : |\xi| < \delta \}$ it holds that

$$ |\mathscr{L}(\theta) - \mathscr{L}(0)|^{\alpha} \leq c |\mathscr{L}'(0)|. \tag{9.94} $$

**Proof of Corollary 9.8.3.** Throughout this proof, assume without loss of generality that $\varepsilon < 1$, let $N \in \mathbb{N} \cup \{ \infty \}$ satisfy $N = \min \{k \in \mathbb{N} : a_{k} \neq 0 \} \cup \{ \infty \}$, and assume without loss of generality that $1 < N < \infty$ (cf. item (iv) in Lemma 9.8.1 and Corollary 9.4.2). Note that item (iii) in Lemma 9.8.1 ensures that for all $\theta \in \mathbb{R}$ with $|\theta| < \varepsilon$ it holds that

$$ \sum_{k=1}^{\infty} k|a_{k}| |\theta|^{k-1} < \infty. \tag{9.95} $$

Hence, we obtain that

$$ \sum_{k=1}^{\infty} k|a_{k}| \left( \frac{\varepsilon}{2} \right)^{k} < \infty. \tag{9.96} $$

This implies that there exists $M \in \mathbb{N} \cap (N, \infty)$ which satisfies that for all $k \in \mathbb{N} \cap [M, \infty)$ it holds that

$$ k|a_{k}| \leq (2 \varepsilon^{-1})^{k-1} \leq (2 \varepsilon^{-1})^{k}. \tag{9.97} $$

Lemma 9.8.2 therefore establishes that for all $\theta \in \{ \xi \in \mathbb{R} : |\xi| < \min \{ \frac{\varepsilon}{4}, |a_{N}| 2(\max \{|a_{1}|, |a_{2}|, \ldots, |a_{M}|\} + (2 \varepsilon^{-1})^{N+1})^{-1} \}$ it holds that

$$ |\mathscr{L}(\theta) - \mathscr{L}(0)|^{\frac{N-1}{N}} \leq 2 |\mathscr{L}'(\theta)|. \tag{9.98} $$

The proof of Corollary 9.8.3 is thus complete.
