# 12.2.1.2 Packing radii (Inner entropy numbers)

Definition 12.2.6 (Packing radii). Let $(X, d)$ be a metric space and let $n \in \mathbb{N}$. Then we denote by $\mathcal{P}_{(X, d), n} \in [0, \infty)$ (we denote by $\mathcal{P}_{X, n} \in [0, \infty]$ the extended real number given by

\begin{equation}\mathcal{P}_{(X, d), n} = \sup \big( \{ r \in [0, \infty) : (\exists x_1, x_2, \ldots, x_{n+1} \in X : \[\min_{i,j \in \{1, 2, \ldots, n+1\}, i \neq j} d(x_i, x_j) > 2r \}) \cup \{0\} \big) \tag{12.75}\end{equation}

and we call $\mathcal{P}_{(X, d), n}$ the $n$-packing radius of $(X, d)$ (we call $\mathcal{P}^{X, r}$ the $n$-packing radius of $X$).

# 12.2.1.3 Packing numbers

Definition 12.2.7 (Packing numbers). Let $(X, d)$ be a metric space and let $r \in [0, \infty]$. Then we denote by $\mathcal{P}^{(X, d), r} \in [0, \infty]$ (we denote by $\mathcal{P}^{X, r} \in [0, \infty]$ the extended real number given by

and we call $\mathcal{P}^{(X, d), r}$ the $r$-packing number of $(X, d)$ (we call $\mathcal{P}^{X, r}$ the $r$-packing number of $X$).
