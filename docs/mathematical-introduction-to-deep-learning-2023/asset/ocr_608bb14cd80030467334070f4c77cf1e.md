# **7.6.** *Adagrad SGD optimization (Adagrad)*

**Definition 7.6.1** (Adagrad SGD optimization method). Let $\boldsymbol{d} \in \mathbb{N}$, $(\gamma_n)_{n \in \mathbb{N}} \subseteq [0, \infty)$, $(J_n)_{n \in \mathbb{N}} \subseteq \mathbb{N}$, $\varepsilon \in (0, \infty)$, let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space, let $(\mathcal{S}, \boldsymbol{S})$ be a measurable space, let $\xi: \Omega \to \mathbb{R}^{\boldsymbol{d}}$ be a random variable, for every $n \in \mathbb{N}$, $j \in \{1, 2, \ldots, J_n\}$ let $X_{n,j}: \Omega \to \mathcal{S}$ be a random variable, and let $\ell = (\ell(\theta, x))_{(\theta, x) \in \mathbb{R}^{\boldsymbol{d}} \times \mathcal{S}: \mathbb{R}^{oldsymbol{d}} \times \mathcal{S} \to \mathbb{R}$ and $\boldsymbol{g} = (\boldsymbol{g}_1, \ldots, \boldsymbol{g}_{\boldsymbol{d}}): \mathbb{R}^{oldsymbol{d}} \times \mathcal{S} \to \mathbb{R}^{oldsymbol{d}}$ satisfy for all $U$ in $\{V \subseteq \mathbb{R}^{oldsymbol{d}}: V \text{ is open}\}$, $x \in \mathcal{S}$, $\theta \in U$ with $(U \ni \psi \mapsto \ell(\psi, x) \in \mathbb{R}) \in C^1(U, \mathbb{R})$ that

$$\boldsymbol{g}(\theta, x) = (\nabla_{\theta} \ell)(\theta, x). \tag{7.137}$$

Then we say that $\Theta$ is the Adagrad SGD process on $((\Omega, \mathcal{F}, \mathbb{P}), (\mathcal{S}, \boldsymbol{S}))$ for the loss function $\ell$ with generalized gradient $\boldsymbol{g}$, learning rates $(\gamma_n)_{n \in \mathbb{N}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n,j})_{(n, j) \in \{(k, l) \in \mathbb{N}^2: l \leq J_k\}}$ (we say that $\Theta$ is the Adagrad SGD process for the loss function $\ell$ with learning rates $(\gamma_n)_{n \in \mathbb{N}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n,j})_{(n, j) \in \{(k, l) \in \mathbb{N}^2: l \leq J_k\}}$ if and only if it holds that $\Theta = (\Theta^{(1)}, \ldots, \Theta^{(\boldsymbol{d})}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^{oldsymbol{d}}$ is the function from $\mathbb{N}_0 \times \Omega$ to $\mathbb{R}^{oldsymbol{d}}$ which satisfies for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \boldsymbol{d}\}$ that $\Theta_0 = \xi$ and

$$\Theta_n^{(i)} = \Theta_{n-1}^{(i)} - \gamma_n \left( \varepsilon + \left[ \sum_{k=1}^{n} \left( \frac{1}{J_k} \sum_{j=1}^{J_k} \boldsymbol{g}_{i, j}(\Theta_{k-1}, X_{k, j}) \right)^2 \right]^{1/2 - 1} \right) \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{g}_{i, j}(\Theta_{n-1}, X_{n, j}) \right]. \tag{7.138}$$

An implementation in PYTORCH of the Adagrad SGD optimization method as described in Definition 7.6.1 above is given in Source code 7.7. The Adagrad SGD optimization method as described in Definition 7.6.1 above is also available in PYTORCH in the form of the built-in `torch.optim.Adagrad` optimizer (which, for applications, is generally much preferable to implementing it from scratch).
