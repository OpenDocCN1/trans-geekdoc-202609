This ensures for all $\theta \in [\alpha, \beta]^\mathrm{d}$, $p \in (0, \infty)$ that

$$(\mathbb{E}[\min_{k \in \{1,2, \ldots, K\}} | \mathcal{R}(\Theta_{k}) - \mathcal{R}(\theta) |^{p}])^{1 / p} \leq \frac{L(\beta - \alpha) \max \{1, (p / a)^{1 / a}\}}{K^{1 / a}}$$

$$\leq \frac{L(\beta - \alpha) \max \{1, p\}}{K^{1 / a}} .$$

This proves item **(ii)**. The proof of Proposition **11.2.7** is thus complete.

# **11.3.1** Local Lipschitz continuity estimates for the parametrization functions of ANNs

**Lemma 11.3.1.** Let $a, x, y \in \mathbb{R}$. Then

$$|\max \{x, a\} - \max \{y, a\}| \leq \max \{x, y\} - \min \{x, y\} = |x - y| .$$

*Proof of Lemma 11.3.1.* Note that the fact that

$$|\max \{x, a\} - \max \{y, a\}| = |\max \{\max \{x, y\}, a\} - \max \{\min \{x, y\}, a\}|$$

$$= \max \left\{\max \{x, y\}, a\} - \max \left\{\min \{x, y\}, a\right\}$$

$$= \max \left\{\max \{x, y\} - \max \left\{\min \{x, y\}, a\right\}, a - \max \left\{\min \{x, y\}, a\right\}\right\}$$

$$\leq \max \left\{\max \{x, y\} - \max \left\{\min \{x, y\}, a\right\}, a - a\right\}$$

$$= \max \left\{\max \{x, y\} - \max \left\{\min \{x, y\}, a\right\}, 0\right\} \leq \max \left\{\max \{x, y\} - \min \{x, y\}, 0\right\}$$

$$= \max \{x, y\} - \min \{x, y\} = |\max \{x, y\} - \min \{x, y\}| = |x - y| .$$

establishes (11.69). The proof of Lemma **11.3.1** is thus complete.

**Corollary 11.3.2.** Let $a, x, y \in \mathbb{R}$. Then

$$|\min \{x, a\} - \min \{y, a\}| \leq \max \{x, y\} - \min \{x, y\} = |x - y| .$$

*Proof of Corollary 11.3.2.* Observe that Lemma **11.3.1** shows that

$$|\min \{x, a\} - \min \{y, a\}| = |- (\min \{x, a\} - \min \{y, a\})|$$

$$= |\max \{-x, -a\} - \max \{-y, -a\}|$$

$$\leq |(-x) - (-y)| = |x - y| .$$

The proof of Corollary **11.3.2** is thus complete.
