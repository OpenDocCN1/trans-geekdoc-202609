# ### **6.3.1 Representations for GD optimization with momentum**

In (**6.189**), (**6.190**), and (**6.191**) above the momentum **GD** optimization method is formulated by means of a one-step recursion. This one-step recursion can efficiently be exploited in an implementation. In Corollary **6.3.4** below we provide a suitable full-history recursive representation for the momentum **GD** optimization method, which enables us to develop a better intuition for the momentum **GD** optimization method. Our proof of Corollary **6.3.4** employs the explicit representation of momentum terms in Lemma **6.3.3** below. Our proof of Lemma **6.3.3**, in turn, uses an application of the following result.

**Lemma 6.3.2.** Let \((\alpha_{n})_{n \in \mathbb{N}} \subseteq \mathbb{R}\) and let \((m_{n})_{n \in \mathbb{N}_{0}} \subseteq \mathbb{R}\) satisfy for all \(n \in \mathbb{N}\) that \(m_{0} = 0\) and

\begin{equation}\tag{6.192}m_{n} = \alpha_{n}m_{n - 1} + 1 - \alpha_{n}.
\end{equation}

*Then it holds for all* \(n \in \mathbb{N}_{0}\) *that*

\begin{equation}\tag{6.193}m_{n} = 1 - \prod_{k = 1}^{n}\alpha_{k}.
\end{equation}

*Proof of Lemma 6.3.2.* We prove (**6.193**) by induction on \(n \in \mathbb{N}_{0}\). For the base case \(n = 0\) observe that the assumption that \(m_{0} = 0\) establishes that

\begin{equation}\tag{6.194}m_{0} = 0 = 1 - \prod_{k = 1}^{0}\alpha_{k}.
\end{equation}

This establishes (**6.193**) in the base case \(n = 0\). For the induction step note that (**6.192**) assures that for all \(n \in \mathbb{N}_{0}\) with \(m_{n} = 1 - \prod_{k = 1}^{n}\alpha_{k}\) it holds that

\begin{align}\tag{6.195}m_{n + 1} = &\alpha_{n + 1}m_{n} + 1 - \alpha_{n + 1} = \alpha_{n + 1} \left[ 1 - \prod_{k = 1}^{n}\alpha_{k} \right] + 1 - \alpha_{n + 1} \notag \
 = &\alpha_{n + 1} - \prod_{k = 1}^{n + 1}\alpha_{k} + 1 - \alpha_{n + 1} = 1 - \prod_{k = 1}^{n + 1}\alpha_{k}.
\end{align}

Induction hence establishes (**6.193**). The proof of Lemma **6.3.2** is thus complete. $\square$
