The fact that for all $ k \in \{0, 1, \dots, K\} $ it holds that $ \mathfrak{f}_k \leq \mathfrak{f}_K $ and (3.58) therefore demonstrate that for all $ x \in [\mathfrak{f}_K, \infty) $ it holds that

$(\mathcal{R}_\mathfrak{c}^\mathbf{N}(\mathbf{F}))(x) - (\mathcal{R}_\mathfrak{c}^\mathbf{N}(\mathbf{F}))(\mathfrak{f}_K) = \left[\sum_{n=0}^K c_n(\max\{x - \mathfrak{f}_n, 0\} - \max\{\mathfrak{f}_K - \mathfrak{f}_n, 0\}) \right]$ (3.68)

$= \sum_{n=0}^K c_n[(x - \mathfrak{f}_n) - (\mathfrak{f}_K - \mathfrak{f}_n)] = \sum_{n=0}^K c_n(x - \mathfrak{f}_K) = 0.$

This and (3.64) show that for all $ x \in [\mathfrak{f}_K, \infty) $ it holds that

$(\mathcal{R}_\mathfrak{c}^\mathbf{N}(\mathbf{F}))(x) = (\mathcal{R}_\mathfrak{c}^\mathbf{N}(\mathbf{F}))(\mathfrak{f}_K) = f_{K-1} + \left(\frac{f_K - f_{K-1}}{\mathfrak{f}_K - \mathfrak{f}_{K-1}}\right)(\mathfrak{f}_K - \mathfrak{f}_{K-1}) = f_K.$ (3.69)

Combining this, (3.59), (3.64), and (3.11) proves item (ii). The proof of Proposition 3.2.5 is thus complete.
