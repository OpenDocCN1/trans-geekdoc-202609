```

This establishes (8.20) in the base case $k = L+1$. For the induction step observe (8.16) and (8.18) demonstrate that for all $k \in \{L, L-1, \ldots, 1\}$ with $[D_{k+1}]^* = \begin{bmatrix} \frac{\partial \mathfrak{C}}{\partial x}(\mathfrak{f}_L, \mathfrak{f}) \end{bmatrix}\mathbf{D}_{k+1}$ it holds that

```

Induction thus establishes (8.20). Furthermore, note that item (**iii**) in Proposition 8.1.1 assures that for all $k \in \{1, 2, \ldots, L\}$ it holds that
