**Example 9.10.2** (Example of a differentiable function that fails to satisfy the standard **KL** inequality). *Let* \(\mathcal{L} : \mathbb{R} \to \mathbb{R}\) *satisfy for all* \(x \in \mathbb{R}\) *that*

\[ \mathcal{L}(x)= \int_{0}^{\max \{x, 0\}} y|\sin(y^{-1})| \, dy. \tag{9.117} \]

*Then*

+   (i) it holds that \(\mathcal{L} \in C^{1}(\mathbb{R}, \mathbb{R})\),

+   (ii) it holds for all \(c \in \mathbb{R}\), \(\alpha, \varepsilon \in (0, \infty)\) that *there exist* \(x \in (0, \varepsilon)\) *such that*

\[ |\mathcal{L}(x)-\mathcal{L}(0)|^{\alpha} > c|\mathcal{L}^{\prime}(x)|, \tag{9.118} \]

+   (iii) it holds for all \(c \in \mathbb{R}\), \(\alpha, \varepsilon \in (0, \infty)\) that *we do not have that* \(\mathcal{L}\) *satisfies the standard* **KL** *inequality at* \(0\) *on* \([0, \varepsilon)\) *with exponent* \(\alpha\) *and constant* \(c\)

*(cf. Definition 9.1.1).*

**Proof for Example 9.10.2.** Throughout this proof, let \(\mathcal{G}: \mathbb{R} \to \mathbb{R}\) satisfy for all \(x \in \mathbb{R}\) that

\[ \mathcal{G}(x)= \begin{cases} x|\sin(x^{-1})| & : x > 0 \\[2pt] 0 & : x \leq 0. \end{cases} \tag{9.119} \]

Note that (9.119) proves that for all \(k \in \mathbb{N}\) it holds that

\[ \mathcal{G}((k \pi)^{-1})= (k \pi)^{-1}|\sin(k \pi)|= 0. \tag{9.120} \]

Furthermore, observe that (9.119) shows for all \(x \in (0, \infty)\) that

\[ |\mathcal{G}(x)-\mathcal{G}(0)|= |x\sin(x^{-1})| \leq |x|. \tag{9.121} \]

Therefore, we obtain that \(\mathcal{G}\) is continuous. This, (9.117), and the fundamental theorem of calculus ensure that \(\mathcal{L}\) is continuously differentiable with

\[ \mathcal{L}^{\prime}=\mathcal{G}. \tag{9.122} \]

Combining this with (9.120) demonstrates that for all \(c \in \mathbb{R}\), \(\alpha \in (0, \infty)\), \(k \in \mathbb{N}\) it holds that

\[ |\mathcal{L}((k \pi)^{-1})-\mathcal{L}(0)|^{\alpha}= |\mathcal{L}((k \pi)^{-1})|^{\alpha} > 0= c|\mathcal{G}((k \pi)^{-1})|= c|\mathcal{L}^{\prime}((k \pi)^{-1})|. \tag{9.123} \]

The proof for Example 9.10.2 is thus complete. \(\quad\) \(\square\)
