# **17.1 Stochastic optimization problems for expectations of random variables**

Lemma 17.1.1. Let (Ω, F, ℙ) be a probability space and let X: Ω → ℝ be a random variable with ℙ[|X|²] < ∞. Then

(i) it holds for all y ∈ ℝ that

ℙ[X − y]² = ℙ[X − ℙ[X]²] + |ℙ[X] − y|², (17.1)

(ii) there exists a unique z ∈ ℝ such that

ℙ[X − z]² = inf_{y∈ℝ} ℙ[X − y]², (17.2)

and

(iii) it holds that

ℙ[X − ℙ[X]²] = inf_{y∈ℝ} ℙ[X − y]². (17.3)

Proof of Lemma 17.1.1. Note that Lemma 7.2.3 establishes item (i). Observe that item (i) proves items (ii) and (iii). The proof of Lemma 17.1.1 is thus complete.

# **17.2 Stochastic optimization problems for expectations of random fields**

Proposition 17.2.1. Let d ∈ ℕ, a ∈ ℝ, b ∈ (a, ∞), let (Ω, F, ℙ) be a probability space, let X = (X_x)_{x∈[a,b]^d}: [a, b]^d × Ω → ℝ be (ℬ([a, b]^d) ⊗ F)/ℬ(ℝ)-measurable, assume for every x ∈ [a, b]^d that ℙ[|X_x|²] < ∞, and assume that [a, b]^d ∋ x ↦ ℙ[X_x] ∈ ℝ is continuous. Then

(i) there exists a unique u ∈ C([a, b]^d, ℝ) such that

∫_{[a,b]^d} ℙ[|X_x − u(x)|²] dx = inf_{v∈C([a,b]^d, ℝ)} (∫_{[a,b]^d} ℙ[|X_x − v(x)|²] dx) (17.4)

and

(ii) it holds for all x ∈ [a, b]^d that u(x) = ℙ[X_x].

Proof of Proposition 17.2.1. Note that item (i) in Lemma 17.1.1 and the assumption that for all x ∈ [a, b]^d it holds that ℙ[|X_x|²] < ∞ demonstrate that for every function u: [a, b]^d → ℝ and every x ∈ [a, b]^d it holds that

ℙ[|X_x − u(x)|²] = ℙ[X_x − ℙ[X_x]²] + |ℙ[X_x] − u(x)|². (17.5)
