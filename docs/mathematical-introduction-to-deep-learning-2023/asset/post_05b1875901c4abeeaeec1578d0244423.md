
Proof of Corollary 9.11.6. Note that Lemma 9.11.1 demonstrates that for all $t \in [0, \infty)$ it holds that

$$\mathcal { L } ( \Theta _ { t } ) = \mathcal { L } ( \Theta _ { 0 } ) - \int _ { 0 } ^ { t } \| \nabla \mathcal { L } \| ( \Theta _ { s } ) \| _ { 2 } ^ { 2 } \mathrm { d } s .$$

Corollary 9.11.5 therefore establishes that there exist $\vartheta \in \mathbb { R } ^ { \mathrm { g } } , \, \mathcal { C } , \beta \in ( 0 , \infty )$ which satisfy for all $t \in [ 0 , \infty )$ that

$$\| \Theta _ { t } - \vartheta \| _ { 2 } \leq \mathcal { C } ( 1 + t ) ^ { - \beta } \quad \text { a n d } \quad 0 \leq \mathcal { L } ( \Theta _ { t } ) - \mathcal { L } ( \vartheta ) \leq \mathcal { C } ( 1 + t ) ^ { - 1 } .$$

This ensures that

$$\lim _ { t \rightarrow \infty } \operatorname { s u p } \| \Theta _ { t } - \vartheta \| _ { 2 } = 0 .$$

Combining this with the assumption that $\mathcal { L } \in C ^ { 1 } ( \mathbb { R } ^ { \mathrm { g } } , \mathbb { R } )$ establishes that

$$\lim _ { t \rightarrow \infty } \operatorname { s u p } \| ( \nabla \mathcal { L } ) ( \Theta _ { t } ) - ( \nabla \mathcal { L } ) ( \vartheta ) \| _ { 2 } = 0 .$$

Hence, we obtain that

$$\lim _ { t \rightarrow \infty } \operatorname { s u p } \| \| ( \nabla \mathcal { L } ) ( \Theta _ { t } ) \| _ { 2 } - \| ( \nabla \mathcal { L } ) ( \vartheta ) \| _ { 2 } \| = 0 .$$

Furthermore, observe that (9.193) and (9.194) ensure that

$$\int _ { 0 } ^ { \infty } \| ( \nabla \mathcal { L } ) ( \Theta _ { s } ) \| _ { 2 } ^ { 2 } \mathrm { d } s < \infty .$$

This and (9.197) demonstrate that

$$( \nabla \mathcal { L } ) ( \vartheta ) = 0 .$$

Combining this with (9.194) establishes (9.192). The proof of Corollary 9.11.6 is thus complete.

## 9.12 Convergence analysis for GD processes

### 9.12.1 One-step descent property for GD processes

**Lemma 9.12.1.** Let $\mathfrak { g } \in \mathbb { N }$, $L \in \mathbb { R }$, let $U \subseteq \mathbb { R } ^ { \mathfrak { g } }$ be open and convex, let $\mathcal { L } \in C ^ { 1 } ( U , \mathbb { R } )$, and assume for all $x , y \in U$ that

$\| ( \nabla \mathcal { L } ) ( x ) - ( \nabla \mathcal { L } ) ( y ) \| _ { 2 } \leq L \| x - y \| _ { 2 } \quad \text{(9.204)}$

(cf. Definition 3.3.4). Then it holds for all $x , y \in U$ that

$\mathcal { L } ( y ) \leq \mathcal { L } ( x ) + \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + \frac { L } { 2 } \| x - y \| _ { 2 } ^ { 2 } \quad \text{(9.205)}$

(cf. Definition 1.4.7).

**Proof of Lemma 9.12.1.** Observe that the fundamental theorem of calculus, the Cauchy-Schwarz inequality, and (9.204) prove that for all $x , y \in U$ we have that

\begin{align}
& \mathcal { L } ( y ) - \mathcal { L } ( x ) \\
&= \big [ \mathcal { L } ( x + r ( y - x ) ) \big ] _ { r = 0 } ^ { r = 1 } = \int _ { 0 } ^ { 1 } \langle ( \nabla \mathcal { L } ) ( x + r ( y - x ) ) , y - x \rangle \, \mathrm { d } r \\
&= \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + \int _ { 0 } ^ { 1 } \langle ( \nabla \mathcal { L } ) ( x + r ( y - x ) ) - ( \nabla \mathcal { L } ) ( x ) , y - x \rangle \, \mathrm { d } r \\
&\leq \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + \int _ { 0 } ^ { 1 } \big | \langle ( \nabla \mathcal { L } ) ( x + r ( y - x ) ) - ( \nabla \mathcal { L } ) ( x ) , y - x \rangle \big | \, \mathrm { d } r \\
&\leq \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + \left[ \int _ { 0 } ^ { 1 } \| ( \nabla \mathcal { L } ) ( x + r ( y - x ) ) - ( \nabla \mathcal { L } ) ( x ) \| _ { 2 } \, \mathrm { d } r \right] \| y - x \| _ { 2 } \\
&\leq \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + L \| y - x \| _ { 2 } \left[ \int _ { 0 } ^ { 1 } \| r ( y - x ) \| _ { 2 } \, \mathrm { d } r \right] \\
&= \langle ( \nabla \mathcal { L } ) ( x ) , y - x \rangle + \frac { L } { 2 } \| x - y \| _ { 2 } ^ { 2 }
\end{align}

$\quad \text{(9.206)}$

(cf. Definition 1.4.7). The proof of Lemma 9.12.1 is thus complete. $\square$

**Corollary 9.12.2**. Let $\mathfrak { g } \in \mathbb { N }$, $L , \gamma \in \mathbb { R }$, let $U \subseteq \mathbb { R } ^ { \mathfrak { g } }$ be open and convex, let $\mathcal { L } \in C ^ { 1 } ( U , \mathbb { R } )$, and assume for all $x , y \in U$ that

$$\| ( \nabla \mathcal { L } ) ( x ) - ( \nabla \mathcal { L } ) ( y ) \| _ { 2 } \leq L \| x - y \| _ { 2 }$$

(cf. Definition 3.3.4). Then it holds for all $x \in U$ with $x - \gamma ( \nabla \mathcal { L } ) ( x ) \in U$ that

$$\mathcal { L } \left( x - \gamma ( \nabla \mathcal { L } ) ( x ) \right) \leq \mathcal { L } \left( x \right) + \gamma \left( \frac { L \gamma } { 2 } - 1 \right) \| ( \nabla \mathcal { L } ) ( x ) \| _ { 2 } ^ { 2 }$$

**Proof of Corollary 9.12.2**. Observe that Lemma 9.12.1 ensures that for all $x \in U$ with $x - \gamma ( \nabla \mathcal { L } ) ( x ) \in U$ it holds that

\begin{align}
\mathcal { L } \left( x - \gamma ( \nabla \mathcal { L } ) ( x ) \right) \leq & \mathcal { L } \left( x \right) + \left\langle ( \nabla \mathcal { L } ) ( x ) , -\gamma ( \nabla \mathcal { L } ) ( x ) \right\rangle + \frac { L } { 2 } \| \gamma ( \nabla \mathcal { L } ) ( x ) \| _ { 2 } ^ { 2 } \\
= & \mathcal { L } \left( x \right) - \gamma \| ( \nabla \mathcal { L } ) ( x ) \| _ { 2 } ^ { 2 } + \frac { L \gamma ^ { 2 } } { 2 } \| ( \nabla \mathcal { L } ) ( x ) \| _ { 2 } ^ { 2 } .
\end{align}

This establishes (9.208). The proof of Corollary 9.12.2 is thus complete. $\square$

**Corollary 9.12.3**. Let $\mathfrak { g } \in \mathbb { N }$, $L \in ( 0 , \infty )$, $\gamma \in [ 0 , L ^ { - 1 } ]$, let $U \subseteq \mathbb { R } ^ { \mathfrak { g } }$ be open and convex, let $\mathcal { L } \in C ^ { 1 } ( U , \mathbb { R } )$, and assume for all $x , y \in U$ that
