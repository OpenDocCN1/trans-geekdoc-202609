
This and item **(i)** prove item **(ii)**. Moreover, note that the integral transformation theorem with the diffeomorphism $ ( 1 , \infty ) \ni t \mapsto \frac { 1 } { t } \in ( 0 , 1 ) $ ensures that

$$
\begin{align*} B ( x , y ) & = \int _ { 0 } ^ { 1 } t ^ { ( x - 1 ) } \left( 1 - t \right) ^ { ( y - 1 ) } \mathrm { d } t = \int _ { 1 } ^ { \infty } \left[ \frac { 1 } { t } \right] ^ { ( x - 1 ) } \left[ 1 - \frac { 1 } { t } \right] ^ { ( y - 1 ) } \frac { 1 } { t ^ { 2 } } \mathrm { d } t \\ & = \int _ { 1 } ^ { \infty } t ^ { ( - x - 1 ) } \left[ \frac { t - 1 } { t } \right] ^ { ( y - 1 ) } \mathrm { d } t = \int _ { 1 } ^ { \infty } \frac { t ^ { ( - x - y ) } ( t - 1 ) ^ { ( y - 1 ) } } { } \mathrm { d } t \\ & = \int _ { 0 } ^ { \infty } ( t + 1 ) ^ { ( - x - y ) } t ^ { ( y - 1 ) } \mathrm { d } t = \int _ { 0 } ^ { \infty } \frac { t ^ { ( y - 1 ) } } { ( t + 1 ) ^ { ( x + y ) } } \mathrm { d } t . \end{align*} \tag { 11.13 }
$$

In addition, observe that the fact that for all $ ( u , v ) \in ( 0 , \infty ) \times ( 0 , 1 ) $ it holds that

$$

$$

shows that for all $ ( u , v ) \in ( 0 , \infty ) \times ( 0 , 1 ) $ it holds that

This, the fact that

$$

$$

and the integral transformation theorem imply that

$$
\begin{array} { l l } \Gamma ( x ) \cdot \Gamma ( y ) & = \int _ { ( 0 , \infty ) \times ( 0 , 1 ) } f ( \Phi ( u , v ) ) | \operatorname* { d e t } ( \Phi ' ( u , v ) ) | \mathrm { d } ( u , v ) \\ & = \int _ { 0 } ^ { \infty } \int _ { 0 } ^ { 1 } ( u ( 1 - v ) ) ^ { ( x - 1 ) } ( u v ) ^ { ( y - 1 ) } e ^ { - ( u ( 1 - v ) + u v ) } u \, \mathrm { d } v \, \mathrm { d } u \\ & = \int _ { 0 } ^ { \infty } \int _ { 0 } ^ { 1 } u ^ { ( x + y - 1 ) } e ^ { - u } v ^ { ( y - 1 ) } ( 1 - v ) ^ { ( x - 1 ) } \mathrm { d } v \, \mathrm { d } u \\ & = \left[ \int _ { 0 } ^ { \infty } u ^ { ( x + y - 1 ) } e ^ { - u } \mathrm { d } u \right] \left[ \int _ { 0 } ^ { 1 } v ^ { ( y - 1 ) } ( 1 - v ) ^ { ( x - 1 ) } \mathrm { d } v \right] \\ & = \Gamma ( x + y ) B ( y , x ) . \end{array} \tag { 11.17 }

This establishes item **(iii)**. The proof of Lemma 11.2.1 is thus complete. $\square$

## Lemma 11.2.2

*It holds for all* $\alpha, x \in [0, 1]$ *that* $(1 - x)^\alpha \le 1 - \alpha x$.

*Proof of Lemma 11.2.2.* *Note that the fact that for all* $y \in [0, \infty)$ *it holds that* $[0, \infty) \ni z \mapsto y^2 \in [0, \infty)$ *is convex demonstrates that for all* $\alpha, x \in [0, 1]$ *it holds that*

$$

The proof of Lemma 11.2.2 is thus complete. $\square$

## Proposition 11.2.3

*Let* $\Gamma : (0, \infty) \to (0, \infty)$ *and* $\lfloor \cdot \rceil : (0, \infty) \to \mathbb{N}_0$ *satisfy for all* $x \in (0, \infty)$ *that* $\Gamma(x) = \int_0^\infty t^{x-1} e^{-t} \, \mathrm{d}t$ *and* $\lfloor x \rceil = \max([0, x] \cap \mathbb{N}_0)$. *Then*

-   (i) *it holds that* $\Gamma : (0, \infty) \to (0, \infty)$ *is convex,*
-   (ii) *it holds for all* $x \in (0, \infty)$ *that* $\Gamma(x+1) = x\,\Gamma(x) \le x^{\lceil x \rceil} \le \max\{1, x^x\}$,*
-   (iii) *it holds for all* $x \in (0, \infty)$*,* $\alpha \in [0, 1]$ *that*

$$
(\max\{x + \alpha - 1, 0\})^\alpha \le \frac{x}{(x + \alpha)^{1-\alpha}} \le \frac{\Gamma(x+\alpha)}{\Gamma(x)} \le x^\alpha, \tag{11.19}
$$

-   *and*
-   (iv) *it holds for all* $x \in (0, \infty)$*,* $\alpha \in [0, \infty)$ *that*

$$
(\max\{x + \min\{\alpha - 1, 0\}, 0\})^\alpha \le \frac{\Gamma(x+\alpha)}{\Gamma(x)} \le (x + \max\{\alpha - 1, 0\})^\alpha. \tag{11.20}
$$

*Proof of Proposition 11.2.3.* *Throughout this proof, let* $\lfloor \cdot \rceil : (0, \infty) \to \mathbb{N}_0$ *satisfy for all* $x \in [0, \infty)$ *that* $\lfloor x \rceil = \max([0, x] \cap \mathbb{N}_0)$. *Observe that the fact that for all* $t \in (0, \infty)$ *it holds that* $\mathbb{R} \ni x \mapsto t^x \in (0, \infty)$ *is convex establishes that for all* $x, y \in (0, \infty)$*,* $\alpha \in [0, 1]$ *it holds that*

$$
\begin{aligned}
\Gamma(\alpha x + (1-\alpha)y) = &\int_0^\infty t^{\alpha x + (1-\alpha) y - 1} e^{-t} \, \mathrm{d}t = \int_0^\infty t^{\alpha x + (1-\alpha) y} t^{-1} e^{-t} \, \mathrm{d}t \\
\le &\int_0^\infty (\alpha t^x + (1 - \alpha) t^y) t^{-1} e^{-t} \, \mathrm{d}t \\
= &\alpha \int_0^\infty t^{x-1} e^{-t} \, \mathrm{d}t + (1 - \alpha) \int_0^\infty t^{y-1} e^{-t} \, \mathrm{d}t \\
= &\alpha\,\Gamma(x) + (1 - \alpha)\Gamma(y).
\end{aligned} \tag{11.21}
$$

This proves item (i). Furthermore, note that item (ii) in Lemma 11.2.1 and item (i) ensure that for all $\alpha \in [0, 1]$ it holds that

$$
\Gamma(\alpha + 1) = \Gamma(\alpha \cdot 2 + (1 - \alpha) \cdot 1) \le \alpha\,\Gamma(2) + (1 - \alpha)\Gamma(1) = \alpha + (1 - \alpha) = 1. \tag{11.22}
$$

This shows for all $x \in (0,1]$ that
$$
\Gamma(x+1) \leq 1 = x^{\lfloor x \rfloor} = \max\{1, x^x\}. \tag{11.23}
$$
Induction, item **(i)** in Lemma **11.2.1**, and the fact that $\forall x \in (0, \infty) : x - \lfloor x \rfloor \in (0,1]$ therefore imply that for all $x \in [1, \infty)$ it holds that

\Gamma(x+1) = \left[\prod_{i=1}^{\lfloor x \rfloor}(x-i+1)\right]\Gamma\big(x-\lfloor x \rfloor+1\big) \leq x^{\lfloor x \rfloor}\Gamma(x-\lfloor x \rfloor+1) \leq x^{\lfloor x \rfloor} \leq x^x = \max\{1, x^x\}.

Combining this and **(11.23)** with item **(i)** in Lemma **11.2.1** establishes item **(ii)**. Moreover, observe that Hölder’s inequality and item **(i)** in Lemma **11.2.1** demonstrate that for all $x \in (0, \infty), \; \alpha \in [0,1]$ it holds that
