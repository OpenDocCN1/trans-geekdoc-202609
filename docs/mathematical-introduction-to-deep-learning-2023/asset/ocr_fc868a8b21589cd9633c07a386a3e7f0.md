# **6.1.2 Euler discretizations for GF ODEs**

**Theorem 6.1.3** (Taylor's formula). *Let* $N \in \mathbb{N}$, $\alpha \in \mathbb{R}$, $\beta \in (\alpha, \infty)$, $a,b \in [\alpha, \beta]$, $f \in C^N([\alpha, \beta], \mathbb{R})$. *Then*

$$f(b) = \left[\sum_{n=0}^{N-1} \frac{f^{(n)}(a)(b-a)^n}{n!}\right] + \int_0^1 \frac{f^{(N)}(a + r(b-a))(b-a)^N(1-r)^{N-1}}{(N-1)!} \, \mathrm{d}r.$$ (6.6)

*Proof of Theorem 6.1.3*. Observe that the fundamental theorem of calculus assures that for all $g \in C^1([0,1], \mathbb{R})$ it holds that

$$g(1) = g(0) + \int_0^1 g'(r) \, \mathrm{d}r = g(0) + \int_0^1 \frac{g'(r)(1-r)^0}{0!} \, \mathrm{d}r.$$ (6.7)

Furthermore, note that integration by parts ensures that for all $n \in \mathbb{N}$, $g \in C^{n+1}([0,1], \mathbb{R})$ it holds that

$$\int_0^1 \frac{g^{(n)}(r)(1-r)^{n-1}}{(n-1)!} \, \mathrm{d}r = \left[- \frac{g^{(n)}(r)(1-r)^n}{n!} \right]_{r=0}^{r=1} + \int_0^1 \frac{g^{(n+1)}(r)(1-r)^n}{n!} \, \mathrm{d}r$$
$$= \frac{g^{(n)}(0)}{n!} + \int_0^1 \frac{g^{(n+1)}(r)(1-r)^n}{n!} \, \mathrm{d}r.$$ (6.8)

Combining this with (6.7) and induction shows that for all $g \in C^N([0,1], \mathbb{R})$ it holds that

$$g(1) = \left[\sum_{n=0}^{N-1} \frac{g^{(n)}(0)}{n!}\right] + \int_0^1 \frac{g^{(N)}(r)(1-r)^{N-1}}{(N-1)!} \, \mathrm{d}r.$$ (6.9)

This establishes (6.6). The proof of Theorem 6.1.3 is thus complete. $\square$
