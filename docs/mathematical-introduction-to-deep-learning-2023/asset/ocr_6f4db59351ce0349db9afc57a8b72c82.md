# **1.2.4 Clipping activation**

**Definition 1.2.9 (Clipping activation function).** Let $u \in [-\infty, \infty)$, $v \in (u, \infty]$. Then we denote by $\mathfrak{c}_{u,v}: \mathbb{R} \to \mathbb{R}$ the *function which satisfies* for all $x \in \mathbb{R}$ that

$$\mathfrak{c}_{u,v}(x) = \max\{u, \min\{x, v\}\}. \qquad\qquad\qquad\qquad (1.45)$$

*and we call $\mathfrak{c}_{u,v}$ the $(u, v)$-clipping activation function.*

import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt
import plot_util
ax = plot_util.setup_axis((-2,2), (-.5,2))
x = np.linspace(-2, 2, 100)
ax.plot(x, tf.keras.activations.relu(x), linewidth=3, label='ReLU')
ax.plot(x, tf.keras.activations.relu(x, max_value=1),
        label='(0,1)-clipping')
ax.legend()
plt.savefig("../plots/clipping.pdf", bbox_inches='tight')
