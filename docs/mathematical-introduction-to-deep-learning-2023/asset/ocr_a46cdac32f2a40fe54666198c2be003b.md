# 6.3.4 Numerical comparisons for GD optimization with and without momentum

In this subsection we provide in Example 6.3.15, Source code 6.1, and Figure 6.1 a numerical comparison of the plain-vanilla GD optimization method and the momentum GD optimization method in the case of the specific quadratic optimization problem in (6.312)–(6.313) below.

**Example 6.3.15.** Let $\mathcal{K}=10$, $\kappa=1$, $\vartheta=(\vartheta_1,\vartheta_2)\in\mathbb{R}^2$, $\xi=(\xi_1,\xi_2)\in\mathbb{R}^2$ *satisfy*

$\vartheta=\begin{pmatrix}\vartheta_1\\\vartheta_2\end{pmatrix}=\begin{pmatrix}1\\1\end{pmatrix}\quad \text{and}\quad \xi=\begin{pmatrix}\xi_1\\\xi_2\end{pmatrix}=\begin{pmatrix}5\\3\end{pmatrix}$, (6.312)

*let* $\mathcal{L}:\mathbb{R}^2\to\mathbb{R}$ *satisfy for all* $\theta=(\theta_1,\theta_2)\in\mathbb{R}^2$ *that*

$\mathcal{L}(\theta)=\begin{pmatrix}\xi_1\\\xi_2\end{pmatrix}\big[\theta_1-\vartheta_1\big]^2+\begin{pmatrix}\frac{\xi_1}{2}\\\frac{\xi_2}{2}\end{pmatrix}\big[\theta_2-\vartheta_2\big]^2$, (6.313)

*let* $\Theta:\mathbb{N}_0\to\mathbb{R}^\vartheta$ *satisfy for all* $n\in\mathbb{N}$ *that* $\Theta_0=\xi$ *and*

$\begin{aligned}\Theta_n=\;&\Theta_{n-1}-\frac{2}{(\kappa+\kappa)}\big(\nabla\mathcal{L}\big)(\Theta_{n-1})\;=\;\Theta_{n-1}-\frac{2}{11}\big(\nabla\mathcal{L}\big)(\Theta_{n-1})\\ &=\;\Theta_{n-1}-0.18\big(\nabla\mathcal{L}\big)(\Theta_{n-1})\;\approx\;\Theta_{n-1}-0.18\big(\nabla\varphi\big)(\Theta_{n-1}),\end{aligned}$ (6.314)

*and let* $\mathcal{M}:\mathbb{N}_0\to\mathbb{R}^\vartheta$ *and* $\mathbf{m}:\mathbb{N}_0\to\mathbb{R}^\vartheta$ *satisfy for all* $n\in\mathbb{N}$ *that* $\mathcal{M}_0=\xi$, $\mathbf{m}_0=0$, $\mathcal{M}_n=\mathcal{M}_{n-1}-0.3\,\mathbf{m}_n$, *and*

$\begin{aligned}\mathbf{m}_n=\;&0.5\,\mathbf{m}_{n-1}+(1-0.5)\big(\nabla\mathcal{L}\big)(\mathcal{M}_{n-1})\\ &=\;0.5\,(\mathbf{m}_{n-1}+(\nabla\mathcal{L}\big)(\mathcal{M}_{n-1})\big).\end{aligned}$ (6.315)

*Then*

+   (i) *it holds for all* $\theta=(\theta_1,\theta_2)\in\mathbb{R}^2$ *that*

$\begin{aligned}\big(\nabla\mathcal{L}\big)(\theta)=\begin{pmatrix}\kappa(\theta_1-\vartheta_1)\\\mathcal{K}(\theta_2-\vartheta_2)\end{pmatrix}=\begin{pmatrix}\theta_1-1\\10\,(\theta_2-1)\end{pmatrix}\;\;,\end{aligned}$ (6.316)

+   (ii) *it holds that*

$\Theta_0=\begin{pmatrix}5\\3\end{pmatrix}$, (6.317)

$\begin{aligned}\Theta_1=\;&\Theta_0-\frac{2}{11}\big(\nabla\mathcal{L}\big)(\Theta_0)\;\approx\;\Theta_0-0.18\big(\nabla\varphi\big)(\Theta_0)\\ =\;&\begin{pmatrix}5\\3\end{pmatrix}-0.18\,\begin{pmatrix}5-1\\10(3-1)\end{pmatrix}\;=\;\begin{pmatrix}5-0.18\cdot4\\3-0.18\cdot20\end{pmatrix}\\ =\;&\begin{pmatrix}5-0.72\\3-3.6\end{pmatrix}\;=\;\begin{pmatrix}4.28\\-0.6\end{pmatrix},\end{aligned}$ (6.318)
