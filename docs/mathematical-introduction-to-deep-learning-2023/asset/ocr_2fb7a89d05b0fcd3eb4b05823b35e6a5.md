*Proof of Proposition 3.2.5.* Throughout this proof, let $c_{0}, c_{1}, \dots, c_{K} \in \mathbb{R}$ satisfy for all $k \in \{0, 1, \dots, K\}$ that

```
$$c_{k} = \frac{f_{\min\{k+1,K\}} - f_{k}}{\mathfrak{f}_{\min\{k+1,K\}} - \mathfrak{f}_{\min\{k,K-1\}}} - \frac{(f_{k} - f_{\max\{k-1,0\}})}{(\mathfrak{f}_{\max\{k,1\}} - \mathfrak{f}_{\max\{k-1,0\}})} \tag{3.52}$$
```

and let $\Phi_{0}, \Phi_{1}, \dots, \Phi_{K} \in ((\mathbb{R}^{1 \times 1} \times \mathbb{R}^{1}) \times (\mathbb{R}^{1 \times 1} \times \mathbb{R}^{1})) \subseteq \mathbf{N}$ satisfy for all $k \in \{0, 1, \dots, K\}$ that

```
$$\Phi_{k} = c_{k} \otimes (\mathbf{i}_{1} \bullet \mathbf{A}_{1,-\mathfrak{f}_{k}}). \tag{3.53}$$
```

Note that Lemma 3.2.4 shows that for all $k \in \{0, 1, \dots, K\}$ it holds that

```
$$\mathcal{R}^{\mathbf{N}}_{\mathfrak{c}_{k}}(\Phi_{k}) \in C(\mathbb{R}, \mathbb{R}), \qquad \mathcal{D}(\Phi_{k}) = (1,1,1) \in \mathbb{N}^{3}, \tag{3.54}$$
```

```
$$\text{and} \qquad \forall \, x \in \mathbb{R} : (\mathcal{R}^{\mathbf{N}}_{\mathfrak{c}_{k}}(\Phi_{k}))(x) = c_{k}\max\{x - \mathfrak{f}_{k}, 0\}. \tag{3.55}$$
```

(cf. Definitions 1.2.4 and 1.3.4). This, Lemma 2.3.3, Lemma 2.4.11, and (3.51) prove that

```
$$\mathcal{D}(\mathbf{F}) = (1, K+1, 1) \in \mathbb{N}^{3} \qquad \text{and} \qquad \mathcal{R}^{\mathbf{N}}_{\mathfrak{c}}(\mathbf{F}) \in C(\mathbb{R}, \mathbb{R}). \tag{3.56}$$
```

This establishes item (i). Observe that item (i) and (1.78) ensure that

```
$$\mathcal{P}(\mathbf{F}) = 2(K+1) + (K+2) = 3K + 4. \tag{3.57}$$
```

This implies item (iii). Note that (3.52), (3.55), Lemma 2.3.3, and Lemma 2.4.11 demonstrate that for all $x \in \mathbb{R}$ it holds that

```
$$(\mathcal{R}^{\mathbf{N}}_{\mathfrak{c}}(\mathbf{F}))(x) = f_{0} + \sum_{k=0}^{K}(\mathcal{R}^{\mathbf{N}}_{\mathfrak{c}_{k}}(\Phi_{k}))(x) = f_{0} + \sum_{k=0}^{K} c_{k}\max\{x - \mathfrak{f}_{k}, 0\}. \tag{3.58}$$
```

This and the fact that for all $k \in \{0, 1, \dots, K\}$ it holds that $\mathfrak{f}_{0} \le \mathfrak{f}_{k}$ show that for all $x \in (-\infty, \mathfrak{f}_{0}]$ it holds that

```
$$(\mathcal{R}^{\mathbf{N}}_{\mathfrak{c}}(\mathbf{F}))(x) = f_{0} + 0 = f_{0}. \tag{3.59}$$
```

Next we claim that for all $k \in \{1, 2, \dots, K\}$ it holds that

```
$$\sum_{n=0}^{k-1} c_{n} = \frac{f_{k} - f_{k-1}}{\mathfrak{f}_{k} - \mathfrak{f}_{k-1}}. \tag{3.60}$$
```

We now prove (3.60) by induction on $k \in \{1, 2, \dots, K\}$. For the base case $k=1$ observe that (3.52) proves that

```
$$\sum_{n=0}^{0} c_{n} = c_{0} = \frac{f_{1} - f_{0}}{\mathfrak{f}_{1} - \mathfrak{f}_{0}}. \tag{3.61}$$
```
