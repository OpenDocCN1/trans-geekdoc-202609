
(cf. Definitions 1.1.3, 1.2.1, 1.2.43, 5.4.5, and 5.4.10 and Corollary 5.3.7). Then it holds for all $i, j \in \{1, 2\}$ that $\Theta^{i}$ that $\Theta^{j}$ is a GF trajectory for the objective function $\mathcal{L}_{j}$ with initial value $\xi$ (cf. Definition 5.2.1).

Proof for Example 5.5.2. Observe that Lemma 5.4.11 implies that for all $x, y \in (0, \infty)^{l_{L}}$ it holds that

```
$\left( \nabla_{x} \mathbf{L}_{1} \right) (x, y) = \left( \nabla_{x} \mathbf{L}_{2} \right) (x, y).$ (5.90)
```

Hence, we obtain that for all $x \in \mathbb{R}^{d}$ it holds that

```
$\left( \nabla \mathcal{L}_{1} \right) (x) = \left( \nabla \mathcal{L}_{2} \right) (x).$ (5.91)
```

This, (5.9), (5.10), and (5.89) demonstrate that for all $i \in \{1, 2\}$ it holds that $\Theta^{i}$ is a GF trajectory for the objective function $\mathcal{L}_{i}$ with initial value $\xi$ (cf. Definition 5.2.1). The proof for Example 5.5.2 is thus complete. $\square$
