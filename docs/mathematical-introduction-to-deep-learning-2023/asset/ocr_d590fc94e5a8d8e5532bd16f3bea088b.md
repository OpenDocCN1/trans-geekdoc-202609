Combining this with **(3.1)** and Lemma **3.1.2** implies that for all $k \in \{1, 2, \dots, K\}$, $x \in [\mathfrak{k}_{k-1}, \mathfrak{k}_k]$ it holds that

```
$\begin{align*} |\mathbb{I}(x) - f(x)| \leq w_f([\mathfrak{k}_{k-1}, \mathfrak{k}_{k-1}])&\left( \frac{\mathfrak{k}_k - x}{\mathfrak{k}_k - \mathfrak{k}_{k-1}} + \frac{x - \mathfrak{k}_{k-1}}{\mathfrak{k}_k - \mathfrak{k}_{k-1}} \right) \\ &= w_f([\mathfrak{k}_{k-1}, \mathfrak{k}_k-1]) \leq w_f(\max_{j \in \{1, 2, \dots, K\}} [\mathfrak{j}_j - \mathfrak{j}_{j-1}]). \end{align*}$
```

This establishes item **(ii)**. The proof of Proposition **3.1.7** is thus complete. $\square$

# **Corollary 3.1.8** (Approximation and Lipschitz continuity properties for the linear interpolation operator). Let $K \in \mathbb{N}$, $L$, $[\mathfrak{f}_0, \mathfrak{f}_1], \dots, \mathfrak{f}_K \in \mathbb{R}$ satisfy $\mathfrak{f}_0 < \mathfrak{f}_1 < \dots < \mathfrak{f}_K$ and let $f: [\mathfrak{f}_0, \mathfrak{f}_K] \to \mathbb{R}$ satisfy for all $x, y \in [\mathfrak{f}_0, \mathfrak{f}_K]$ that

```
$$|f(x) - f(y)| \leq L|x - y|.$$ 
```

*Then*

+   *(i) it holds for all $x, y \in \mathbb{R}$ that*

```
$\left| (\mathscr{L}^{f(\mathfrak{f}_0), f(\mathfrak{f}_1), \dots, f(\mathfrak{f}_K)}_{\mathfrak{f}_0, \mathfrak{f}_1, \dots, \mathfrak{f}_K}(x) - (\mathscr{L}^{f(\mathfrak{f}_0), f(\mathfrak{f}_1), \dots, f(\mathfrak{f}_K)}_{\mathfrak{f}_0, \mathfrak{f}_1, \dots, \mathfrak{f}_K}(y)| \leq L|x - y|$
```

*and*

+   *(ii) it holds that*

```
$\sup_{x \in [\mathfrak{f}_0, \mathfrak{f}_K]} \left| (\mathscr{L}^{f(\mathfrak{f}_0), f(\mathfrak{f}_1), \dots, f(\mathfrak{f}_K)}_{\mathfrak{f}_0, \mathfrak{f}_1, \dots, \mathfrak{f}_K}(x) - f(x) \right| \leq L \left( \max_{k \in \{1, 2, \dots, K\}} [\mathfrak{k}_k - \mathfrak{k}_{k-1}] \right)$
```

*(cf. Definition 3.1.5).*

*Proof of Corollary 3.1.8.*  Note that the assumption that for all $x, y \in [\mathfrak{f}_0, \mathfrak{f}_K]$ it holds that $|f(x) - f(y)| \leq L|x - y|$ demonstrates that

```
$0 \leq \frac{|f(\mathfrak{f}_L) - f(\mathfrak{f}_0)|}{(\mathfrak{f}_L - \mathfrak{f}_0)} \leq \frac{L|\mathfrak{f}_L - \mathfrak{f}_0|}{(\mathfrak{f}_L - \mathfrak{f}_0)} = L.$
```

Combining this, Lemma **3.1.4**, and the assumption that for all $x, y \in [\mathfrak{f}_0, \mathfrak{f}_K]$ it holds that $|f(x) - f(y)| \leq L|x - y|$ with item **(i)** in Proposition **3.1.7** shows that for all $x, y \in \mathbb{R}$ it holds that

```
$\begin{align*} &\left| (\mathscr{L}^{f(\mathfrak{f}_0), f(\mathfrak{f}_1), \dots, f(\mathfrak{f}_K)}_{\mathfrak{f}_0, \mathfrak{f}_1, \dots, \mathfrak{f}_K}(x) - (\mathscr{L}^{f(\mathfrak{f}_0), f(\mathfrak{f}_1), \dots, f(\mathfrak{f}_K)}_{\mathfrak{f}_0, \mathfrak{f}_1, \dots, \mathfrak{f}_K}(y)| \\ \leq &\left( \max_{k \in \{1, 2, \dots, K\}} \left( \frac{L|\mathfrak{k}_k - \mathfrak{k}_{k-1}|}{[\mathfrak{k}_k - \mathfrak{k}_{k-1}]} \right) \right) |x - y| = L|x - y|. \end{align*}$
```
