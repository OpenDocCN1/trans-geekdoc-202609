Induction thus proves item **(i)**. Furthermore, observe that (6.196) and (6.199) demonstrate that for all $n \in \mathbb{N}$ it holds that $m_0 = 0$ and

$m_{n} = \sum_{k=0}^{n-1} a_{n,k} = \sum_{k=0}^{n-1} (1-\alpha_{k+1}) \left[ \prod_{l=k+2}^{n} \alpha_{l} \right] = 1 - \alpha_{n} + \sum_{k=0}^{n-2} (1-\alpha_{k+1}) \left[ \prod_{l=k+2}^{n} \alpha_{l} \right]$
$= 1-\alpha_{n} + \sum_{k=0}^{n-2} (1-\alpha_{k+1}) a_{n} \left[ \prod_{l=k+2}^{n-1} \alpha_{l} \right] = 1-\alpha_{n} + \alpha_{n} \sum_{k=0}^{n-2} a_{n-1,k} = 1-\alpha_{n} + \alpha_{n} m_{n-1}$.

Combining this with Lemma 6.3.2 implies that for all $n \in \mathbb{N}_{0}$ it holds that

$m_{n} = 1 - \prod_{k=1}^{n} \alpha_{k}.$

This establishes item **(ii)**. The proof of Lemma 6.3.3 is thus complete.

$\mathcal{G}(\theta) = (\nabla \mathcal{L})(\theta) \ $,

$\sum_{k=0}^{n-1} a_{n,k} = 1 - \prod_{k=1}^{n} \alpha_{k} \ $,

and

+   (iii) it holds for all $n \in \mathbb{N}$ that

$\Theta_{n} = \Theta_{n-1} - \gamma_{n} \left[ \sum_{k=0}^{n-1} a_{n,k} \mathcal{G}(\Theta_{k}) \right] \ $.
