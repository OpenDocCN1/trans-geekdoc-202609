# 4.4.2 Embedding ANNs in larger architectures

**Lemma 4.4.3.** Let $a \in C(\mathbb{R}, \mathbb{R})$, $L \in \mathbb{N}$, $l_0, l_1, \ldots, l_L, l_0, l_1, \ldots, l_L \in \mathbb{N}$ *satisfy for all* $k \in \{1, 2, \ldots, L\}$ that $l_0 = l_0$, $l_L = l_L$, and $l_k \ge l_k$ for every $k \in \{1, 2, \ldots, L\}$ let $W_k = (W_{k,i,j})_{(i,j) \in \{1, 2, \ldots, l_k\} \times \{1, 2, \ldots, l_{k-1}\}} \in \mathbb{R}^{l_k \times l_{k-1}}$, $\mathcal{W}_k = (\mathcal{W}_{k,i,j})_{(i,j) \in \{1, 2, \ldots, l_k\} \times \{1, 2, \ldots, l_{k-1}\}} \in \mathbb{R}^{l_k \times l_{k-1}}$, $B_k = (B_{k,i})_{i \in \{1, 2, \ldots, l_k\}} \in \mathbb{R}^{l_k}$, $\mathcal{B}_k = (\mathcal{B}_{k,i})_{i \in \{1, 2, \ldots, l_k\}} \in \mathbb{R}^{l_k}$, *assume for all* $k \in \{1, 2, \ldots, L\}$, $i \in \{1, 2, \ldots, l_k\}$, $j \in \mathbb{N} \cap (0, l_{k-1}]$ *that*

```
W_{k,i,j} = \mathcal{W}_{k,i,j} and B_{k,i} = \mathcal{B}_{k,i}, (4.136)
```

*and assume for all* $k \in \{1, 2, \ldots, L\}$, $i \in \{1, 2, \ldots, l_k\}$, $j \in \mathbb{N} \cap (l_{k-1}, l_{k-1} + 1)$ *that* $\mathcal{W}_{k,i,j} = 0$. *Then*

```
\mathcal{R}_a^{\mathbb{N}}(((W_1, B_1), (W_2, B_2), \ldots, (W_L, B_L))) = \mathcal{R}_a^{\mathbb{N}}(((\mathcal{W}_1, \mathcal{B}_1), (\mathcal{W}_2, \mathcal{B}_2), \ldots, (\mathcal{W}_L, \mathcal{B}_L))) (4.137)
```

(cf. Definition 1.3.4).

*Proof of Lemma 4.4.3.* Throughout this proof, let $\pi_k: \mathbb{R}^{l_k} \to \mathbb{R}^{l_k}$, $k \in \{0, 1, \ldots, L\}$, *satisfy for all* $k \in \{0, 1, \ldots, L\}$, $x = (x_1, x_2, \ldots, x_{l_k})$ *that*

```
\pi_k(x) = (x_1, x_2, \ldots, x_{l_k}). (4.138)
```

*Note that the assumption that* $l_0 = l_0$ and $l_L = l_L$ *proves that*

```
\mathcal{R}_a^{\mathbb{N}}(((W_1, B_1), (W_2, B_2), \ldots, (W_L, B_L))) \in C(\mathbb{R}^{l_0}, \mathbb{R}^{l_L}) (4.139)
```

(cf. Definition 1.3.4). *Furthermore, observe that the assumption that for all* $k \in \{1, 2, \ldots, l\}$, $i \in \{1, 2, \ldots, l_k\}$, $j \in \mathbb{N} \cap (l_{k-1}, l_{k-1} + 1)$ *it holds that* $\mathcal{W}_{k,i,j} = 0$ *shows that for all* $k \in \{1, 2, \ldots, L\}$, $x = (x_1, x_2, \ldots, x_{l_{k-1}}) \in \mathbb{R}^{l_{k-1}}$ *it holds that*

```
\pi_k(\mathcal{W}_k x + \mathcal{B}_k)
= 
\begin{pmatrix}
\left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,1,i} x_i \right] + \mathcal{B}_{k,1}, \left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,2,i} x_i \right] + \mathcal{B}_{k,2}, \ldots, \left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,l_k,i} x_i \right] + \mathcal{B}_{k,l_k}
\end{pmatrix} \quad (4.140)
= 
\begin{pmatrix}
\left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,1,i} x_i \right] + \mathcal{B}_{k,1}, \left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,2,i} x_i \right] + \mathcal{B}_{k,2}, \ldots, \left[\sum_{i=1}^{l_{k-1}} \mathcal{W}_{k,l_k,i} x_i \right] + \mathcal{B}_{k,l_k}
\end{pmatrix}.
```

*Combining this with the assumption that for all* $k \in \{1, 2, \ldots, L\}$, $i \in \{1, 2, \ldots, l_k\}$, $j \in \mathbb{N} \cap (0, l_{k-1}]$ *it holds that* $\mathcal{W}_{k,i,j} = W_{k,i,j}$ and $\mathcal{B}_{k,i} = B_{k,i}$ *ensures that for all* $k \in \{1, 2, \ldots, L\}$, $x = (x_1, x_2, \ldots, x_{l_{k-1}}) \in \mathbb{R}^{l_{k-1}}$ *it holds that*

```
\pi_k(\mathcal{W}_k x + \mathcal{B}_k)
= 
\begin{pmatrix}
\left[\sum_{i=1}^{l_{k-1}} W_{k,1,i} x_i \right] + B_{k,1}, \left[\sum_{i=1}^{l_{k-1}} W_{k,2,i} x_i \right] + B_{k,2}, \ldots, \left[\sum_{i=1}^{l_{k-1}} W_{k,l_k,i} x_i \right] + B_{k,l_k}
\end{pmatrix} \quad (4.141)
= W_k \pi_{k-1}(x) + B_k.
```
