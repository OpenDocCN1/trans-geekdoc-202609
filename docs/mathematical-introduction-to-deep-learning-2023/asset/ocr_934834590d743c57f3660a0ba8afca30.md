(iii) it holds for all $x \in \{u \in U : \|u\|_2 < \varepsilon\}$, $l \in \mathbb{N}$, $v_1, v_2, \dots, v_l \in \mathbb{R}^m$ that

```
\sum_{k=l}^{\infty} \left( \left[ \frac{k!}{(k-l)!} \right] \| A_k(v_1, v_2, \dots, v_l, x, x, \dots, x) \|_2 \right) < \infty \tag{9.67}
```

and

```
f^{(l)}(x)(v_1, \dots, v_l) = \sum_{k=l}^{\infty} \left( \left[ \frac{k!}{(k-l)!} \right] A_k(v_1, v_2, \dots, v_l, x, x, \dots, x) \right) \tag{9.68}
```

and

(iv) it holds for all $k \in \mathbb{N}$ that $f^{(k)}(0) = k!A_k$.

**Proof of Proposition 9.7.2.** Throughout this proof, for every $K \in \mathbb{N}_0$ let $F_K : \mathbb{R}^m \to \mathbb{R}^n$ satisfy for all $x \in \mathbb{R}^m$ that

```
F_K(x) = f(0) + \sum_{k=1}^{K} A_k(x, x, \dots, x). \tag{9.69}
```

Note that (9.65) ensures that for all $x \in U$ it holds that

```
\lim \sup_{K \to \infty} \| f(x) - F_K(x) \|_2 = 0. \tag{9.70}
```

Therefore, we obtain for all $x \in U$ that

```
\lim \sup_{K \to \infty} \| F_{K+1}(x) - F_K(x) \|_2 = 0. \tag{9.71}
```

This proves for all $x \in U$ that

```
\sup_{k \in \mathbb{N}} \| A_k(x, x, \dots, x) \|_2 = \sup_{K \in \mathbb{N}_0} \| F_{K+1}(x) - F_K(x) \|_2 < \infty. \tag{9.72}
```

Hence, we obtain for all $x \in \{u \in U : \|u\|_2 < \varepsilon\} \setminus \{0\}$ that

```
\begin{aligned} &\sum_{k=1}^{\infty} \| A_k(x, x, \dots, x) \|_2 = \sum_{k=1}^{\infty} \left( \left[ \frac{\|x\|_2}{\varepsilon} \right]^k \left\| A_k \left( \frac{\varepsilon x}{\|x\|_2}, \frac{\varepsilon x}{\|x\|_2}, \dots, \frac{\varepsilon x}{\|x\|_2} \right) \right\|_2 \right) \\ &\hspace{5cm} \le \left[ \sum_{k=1}^{\infty} \left[ \frac{\|x\|_2}{\varepsilon} \right]^k \right] \left[ \sup_{k \in \mathbb{N}} \left\| A_k \left( \frac{\varepsilon x}{\|x\|_2}, \frac{\varepsilon x}{\|x\|_2}, \dots, \frac{\varepsilon x}{\|x\|_2} \right) \right\|_2 \right] < \infty. \end{aligned} \tag{9.73}
```

This shows that for all $x \in \{u \in U : \|u\|_2 < \varepsilon\}$ it holds that

```
\sum_{k=1}^{\infty} \| A_k(x, x, \dots, x) \|_2 < \infty. \tag{9.74}
```

Combining this with (9.65) establishes item (i). Observe that, for instance, Krantz & Parks [254, Proposition 2.2.3] implies items (ii) and (iii). Note that (9.68) implies item (iv). The proof of Proposition 9.7.2 is thus complete.
