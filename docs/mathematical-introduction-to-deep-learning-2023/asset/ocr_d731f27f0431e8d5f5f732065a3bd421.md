Specifically, deep learning algorithms solve optimization problems of the type $(5.6)$ by means of $gradient\ based\ optimization\ methods$. Loosely speaking, gradient based optimization methods aim to minimize the considered objective function (such as $(5.6)$ above) by performing successive steps based on the direction of the negative gradient of the objective function. One of the simplest gradient based optimization method is the plain-vanilla $\mathbf{GD}$ optimization method which performs successive steps in the direction of the negative gradient and we now sketch the $\mathbf{GD}$ optimization method applied to $(5.6)$. Let $\xi \in \mathbb{R}^{\mathfrak{p}}$, let $(\gamma_{n})_{n \in \mathbb{N}} \subseteq [0, \infty)$, and let $\theta = (\theta_{n})_{n \in \mathbb{N}_{0}}: \mathbb{N}_{0} \rightarrow \mathbb{R}^{\mathfrak{p}}$ satisfy for all $n \in \mathbb{N}$ that

$$\theta_{0}=\xi\ \ \ \ \ \ \ \ \ \ \ \ \text{and} \ \ \ \ \ \ \ \theta_{n} = \theta_{n-1} - \gamma_{n}(\nabla \mathscr{L})(\theta_{n-1}).$$

The process $(\theta_{n})_{n \in \mathbb{N}_{0}}$ is the $\mathbf{GD}$ process for the minimization problem associated to $(5.6)$ with learning rates $(\gamma_{n})_{n \in \mathbb{N}}$ and initial value $\xi$ (see Definition $6.1.1$ below for the precise definition).

This plain-vanilla $\mathbf{GD}$ optimization method and related $\mathbf{GD}$-type optimization methods can be regarded as discretizations of solutions of $\mathbf{GF}$ ODEs. In the context of the minimization problem in $(5.6)$ such solutions of $\mathbf{GF}$ ODEs can be described as follows. Let $\Theta = (\Theta_{t})_{t \in [0, \infty)}: [0, \infty) \rightarrow \mathbb{R}^{\mathfrak{p}}$ be a continuously differentiable function which satisfies for all $t \in [0, \infty)$ that

$$\Theta_{0}=\xi \ \ \ \ \ \ \ \ \ \ \ \ \text{and} \ \ \ \ \ \ \ \ \dot{\Theta}_{t}= \frac{\partial}{\partial t}\Theta_{t}= -(\nabla \mathscr{L})(\Theta_{t}).$$

The process $(\Theta_{t})_{t \in [0, \infty)}$ is the solution of the $\mathbf{GF}$ ODE corresponding to the minimization problem associated to $(5.6)$ with initial value $\xi$.

In Chapter 6 below we introduce and study deterministic $\mathbf{GD}$-type optimization methods such as the $\mathbf{GD}$ optimization method in $(5.7)$. To develop intuitions for $\mathbf{GD}$-type optimization methods and for some of the tools which we employ to analyze such $\mathbf{GD}$-type optimization methods, we study in the remainder of this chapter $\mathbf{GF}$ ODEs such as $(5.8)$ above. In deep learning algorithms usually not $\mathbf{GD}$-type optimization methods but stochastic variants of $\mathbf{GD}$-type optimization methods are employed to solve optimization problems of the form $(5.6)$. Such $\mathbf{SGD}$-type optimization methods can be viewed as suitable Monte Carlo approximations of deterministic $\mathbf{GD}$-type methods and in Chapter 7 below we treat such $\mathbf{SGD}$-type optimization methods.
