# **Lemma 7.2.5.**

Let $(\mathbf{\Omega},\mathbf{F},\mathbf{P})$ be a probability space, let $d \in \mathbb{N}$, let $\langle\cdot,\cdot\rangle:\mathbb{R}^d \times \mathbb{R}^d \rightarrow \mathbb{R}$ be a scalar product, let $\|\cdot\|:\mathbb{R}^d \rightarrow [0, \infty)$ satisfy for all $v \in \mathbb{R}^d$ that

```
$$ \|v\|=\sqrt{\langle v,v\rangle}, $$(7.23)
```

let $X:\Omega \rightarrow \mathbb{R}^d$ be a random variable, assume $\mathbf{E}\left[\|X\|^{2}\right]<\infty$, let $e_1,e_2,\ldots,e_d \in \mathbb{R}^d$ satisfy for all $i,j \in\{1,2,\ldots,d\}$ that $\langle e_i,e_j\rangle=\mathbb{I}_{\{i\}}(j)$, and for every random variable $Y:\Omega \rightarrow \mathbb{R}^d$ with $\mathbf{E}\left[\|Y\|^{2}\right]<\infty$ let $\operatorname{Cov}(Y) \in \mathbb{R}^{d \times d}$ satisfy

```
$$\begin{aligned} \operatorname{Cov}(Y) & =\left[\mathbf{E}\left[\left\langle e_i,Y-\mathbf{E}[Y]\right\rangle\left\langle e_j,Y-\mathbf{E}[Y]\right\rangle\right]\right]_{(i,j) \in\{1,2,\ldots,d\}^{2}} . \end{aligned} $$(7.24)
```

Then

```
$$\operatorname{Trace}(\operatorname{Cov}(X))=\mathbf{E}\left[\left\|X-\mathbf{E}[X]\right\|^{2}\right] . $$(7.25)
```

**Proof of Lemma 7.2.5.** First, note that the fact that $\forall i, j \in\{1,2,\ldots,d\}:\left\langle e_i,e_j\right\rangle=\mathbb{I}_{\{i\}}(j)$ implies that for all $v \in \mathbb{R}^{d}$ it holds that $\sum_{i=1}^{d}\langle e_i, v\rangle e_i=v$. Combining this with the fact that $\forall i, j \in\{1,2,\ldots,d\}:\left\langle e_i,e_j\right\rangle=\mathbb{I}_{\{i\}}(j)$ demonstrates that

```
$$\begin{aligned} \operatorname{Trace}(\operatorname{Cov}(X)) & =\sum_{i=1}^{d} \mathbf{E}\left[\left\langle\left\langle e_i,X-\mathbf{E}[X]\right\rangle\left\langle e_i,X-\mathbf{E}[X]\right\rangle\right]\right] \\ & =\sum_{i=1}^{d} \sum_{j=1}^{d} \mathbf{E}\left[\left\langle\left\langle e_i,X-\mathbf{E}[X]\right\rangle\left\langle e_j,X-\mathbf{E}[X]\right\rangle\left\langle e_i,e_j\right\rangle\right]\right] \\ & =\mathbf{E}\left[\left\langle\left\langle\sum_{i=1}^{d}\left\langle e_i,X-\mathbf{E}[X]\right\rangle e_i,\sum_{j=1}^{d}\left\langle e_j,X-\mathbf{E}[X]\right\rangle e_j\right\rangle\right]\right] \\ & =\mathbf{E}\left[\left\langle\left\langle X-\mathbf{E}[X], X-\mathbf{E}[X]\right\rangle\right\right]=\mathbf{E}\left[\left\|X-\mathbf{E}[X]\right\|^{2}\right] . \end{aligned} $$(7.26)
```

The proof of Lemma 7.2.5 is thus complete.

**Lemma 7.2.6.** Let $d, n \in \mathbb{N}$, let $\langle\cdot,\cdot\rangle:\mathbb{R}^{d} \times \mathbb{R}^{d} \rightarrow \mathbb{R}$ be a scalar product, let $\|\cdot\|:\mathbb{R}^{d} \rightarrow [0, \infty)$ satisfy for all $v \in \mathbb{R}^{d}$ that

```
$$\|v\|=\sqrt{\langle v,v\rangle}, $$(7.27)
```

let $(\Omega, \mathbb{F}, \mathbb{P})$ be a probability space, let $X_k: \Omega \rightarrow \mathbb{R}^d, k \in \{1,2,\ldots,n\}$, be independent random variables, and assume $\sum_{k=1}^{n} \mathbf{E}\left[\left\|X_k\right\|\right]<\infty$. Then

```
$$\begin{aligned} \mathbf{E}\left[\left\|\sum_{k=1}^{n}\left(X_k-\mathbf{E}\left[X_k\right]\right)\right\|^{2}\right] & =\sum_{k=1}^{n} \mathbf{E}\left[\left\|X_k-\mathbf{E}\left[X_k\right]\right\|^{2}\right] . \end{aligned} $$(7.28)
```

**Proof of Lemma 7.2.6.** First, observe that Lemma 7.2.4 and the assumption that $\mathbf{E}\left[\left\|X_1\right\|+ \left\|X_2\right\|+\ldots+\left\|X_n\right\|\right]<\infty$ ensure that for all $k_1,k_2 \in\{1,2,\ldots,n\}$ with $k_1 \neq k_2$ it holds that

```
$$\mathbf{E}\left[\left|\left\langle X_{k_1}-\mathbf{E}\left[X_{k_1}\right], X_{k_2}-\mathbf{E}\left[X_{k_2}\right]\right\rangle\right|\right] \leq \mathbf{E}\left[\left\|X_{k_1}-\mathbf{E}\left[X_{k_1}\right]\right\|\left\|X_{k_2}-\mathbf{E}\left[X_{k_2}\right]\right\|\right]<\infty $$(7.29)
```
