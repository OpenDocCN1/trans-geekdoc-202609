**Lemma 11.2.2.** *It holds for all* $\alpha, x \in [0, 1]$ *that* $(1 - x)^\alpha \le 1 - \alpha x$.

*Proof of Lemma 11.2.2.* *Note that the fact that for all* $y \in [0, \infty)$ *it holds that* $[0, \infty) \ni z \mapsto y^2 \in [0, \infty)$ *is convex demonstrates that for all* $\alpha, x \in [0, 1]$ *it holds that*

```
\begin{equation}
\begin{aligned}
(1 - x)^\alpha \le &\alpha(1 - x)^1 + (1 - \alpha)(1 - x)^0 \\
= &\alpha - \alpha x + 1 - \alpha = 1 - \alpha x.
\end{aligned} \tag{11.18}
\end{equation}
```

The proof of Lemma 11.2.2 is thus complete. $\square$

**Proposition 11.2.3.** *Let* $\Gamma : (0, \infty) \to (0, \infty)$ *and* $\lfloor \cdot \rceil : (0, \infty) \to \mathbb{N}_0$ *satisfy for all* $x \in (0, \infty)$ *that* $\Gamma(x) = \int_0^\infty t^{x-1} e^{-t} \, \mathrm{d}t$ *and* $\lfloor x \rceil = \max([0, x] \cap \mathbb{N}_0)$. *Then*

+   (i) *it holds that* $\Gamma : (0, \infty) \to (0, \infty)$ *is convex,*

+   (ii) *it holds for all* $x \in (0, \infty)$ *that* $\Gamma(x+1) = x\,\Gamma(x) \le x^{\lceil x \rceil} \le \max\{1, x^x\}$,*

+   (iii) *it holds for all* $x \in (0, \infty)$*,* $\alpha \in [0, 1]$ *that*

```
\begin{equation}
(\max\{x + \alpha - 1, 0\})^\alpha \le \frac{x}{(x + \alpha)^{1-\alpha}} \le \frac{\Gamma(x+\alpha)}{\Gamma(x)} \le x^\alpha, \tag{11.19}
\end{equation}
```

+   *and*

+   (iv) *it holds for all* $x \in (0, \infty)$*,* $\alpha \in [0, \infty)$ *that*

```
\begin{equation}
(\max\{x + \min\{\alpha - 1, 0\}, 0\})^\alpha \le \frac{\Gamma(x+\alpha)}{\Gamma(x)} \le (x + \max\{\alpha - 1, 0\})^\alpha. \tag{11.20}
\end{equation}
```

*Proof of Proposition 11.2.3.* *Throughout this proof, let* $\lfloor \cdot \rceil : (0, \infty) \to \mathbb{N}_0$ *satisfy for all* $x \in [0, \infty)$ *that* $\lfloor x \rceil = \max([0, x] \cap \mathbb{N}_0)$. *Observe that the fact that for all* $t \in (0, \infty)$ *it holds that* $\mathbb{R} \ni x \mapsto t^x \in (0, \infty)$ *is convex establishes that for all* $x, y \in (0, \infty)$*,* $\alpha \in [0, 1]$ *it holds that*

```
\begin{equation}
\begin{aligned}
\Gamma(\alpha x + (1-\alpha)y) = &\int_0^\infty t^{\alpha x + (1-\alpha) y - 1} e^{-t} \, \mathrm{d}t = \int_0^\infty t^{\alpha x + (1-\alpha) y} t^{-1} e^{-t} \, \mathrm{d}t \\
\le &\int_0^\infty (\alpha t^x + (1 - \alpha) t^y) t^{-1} e^{-t} \, \mathrm{d}t \\
= &\alpha \int_0^\infty t^{x-1} e^{-t} \, \mathrm{d}t + (1 - \alpha) \int_0^\infty t^{y-1} e^{-t} \, \mathrm{d}t \\
= &\alpha\,\Gamma(x) + (1 - \alpha)\Gamma(y).
\end{aligned} \tag{11.21}
\end{equation}
```

This proves item (i). Furthermore, note that item (ii) in Lemma 11.2.1 and item (i) ensure that for all $\alpha \in [0, 1]$ it holds that

```
\begin{equation}
\Gamma(\alpha + 1) = \Gamma(\alpha \cdot 2 + (1 - \alpha) \cdot 1) \le \alpha\,\Gamma(2) + (1 - \alpha)\Gamma(1) = \alpha + (1 - \alpha) = 1. \tag{11.22}
\end{equation}
```
