**Lemma 2.2.9** (Length of extensions of fully-connected feedforward **ANNs**). Let $d, \mathbf{i} \in \mathbb{N}$, $\Psi \in \mathbb{N}$ satisfy $\mathcal{D}(\Psi) = (d, \mathbf{i}, d)$ (cf. Definition 1.3.1). Then

+   (i) it holds for all $n \in \mathbb{N}_0$ that $\mathcal{H}(\Psi^{*n}) = n$, $\mathcal{L}(\Psi^{*n}) = n+1$, $\mathcal{D}(\Psi^{*n}) \in \mathbb{N}^{n+2}$, and

```
$\begin{equation} \mathcal{D}(\Psi^{*n}) = \begin{cases} (d, d) & : n = 0 \\ (d, \mathbf{i}, \mathbf{i}, \ldots, \mathbf{i}, d) & : n \in \mathbb{N} \end{cases} \tag{2.80} \end{equation}$
```

*and*

+   (ii) it holds for all $\Phi \in \mathbb{N}$, $L \in \mathbb{N} \cap [\mathcal{L}(\Phi), \infty)$ with $\mathcal{O}(\Phi) = d$ that

```
$\begin{equation} \mathcal{L}(\mathcal{E}_{L, \Psi}(\Phi)) = L \tag{2.81} \end{equation}$
```

(cf. Definitions 2.1.6 and 2.2.8).

*Proof of Lemma 2.2.9*. Throughout this proof, let $\Phi \in \mathbb{N}$ satisfy $\mathcal{O}(\Phi) = d$. Observe that Lemma 2.1.7 and the fact that $\mathcal{H}(\Psi) = 1$ show that for all $n \in \mathbb{N}_0$ it holds that

```
$\begin{equation} \mathcal{H}(\Psi^{*n}) = n\mathcal{H}(\Psi) = n \tag{2.82} \end{equation}$
```

(cf. Definition 2.1.6). Combining this with (1.78) and Lemma 1.3.3 ensures that

```
$\begin{equation} \mathcal{H}(\Psi^{*n}) = n, \quad \mathcal{L}(\Psi^{*n}) = n+1, \quad \text{and} \quad \mathcal{D}(\Psi^{*n}) \in \mathbb{N}^{n+2}. \tag{2.83} \end{equation}$
```

Next we claim that for all $n \in \mathbb{N}_0$ it holds that

```
$\begin{equation} \mathbb{N}^{n+2} \supseteq \mathcal{D}(\Psi^{*n}) = \begin{cases} (d, d) & : n = 0 \\ (d, \mathbf{i}, \mathbf{i}, \ldots, \mathbf{i}, d) & : n \in \mathbb{N}. \end{cases} \tag{2.84} \end{equation}$
```

We now prove (2.84) by induction on $n \in \mathbb{N}_0$. Note that the fact that

```
$\begin{equation} \Psi^{*0} = (\mathbf{I}_d, 0) \in \mathbb{R}^{d \times d} \times \mathbb{R}^{d} \tag{2.85} \end{equation}$
```

establishes (2.84) in the base case $n = 0$ (cf. Definition 1.5.5). For the induction step assume that there exists $n \in \mathbb{N}_0$ which satisfies

```
$\begin{equation} \mathbb{N}^{n+2} \supseteq \mathcal{D}(\Psi^{*n}) = \begin{cases} (d, d) & : n = 0 \\ (d, \mathbf{i}, \mathbf{i}, \ldots, \mathbf{i}, d) & : n \in \mathbb{N}. \end{cases} \tag{2.86} \end{equation}$
```

Note that (2.86), (2.41), (2.83), item (i) in Proposition 2.1.2, and the fact that $\mathcal{D}(\Psi) = (d, \mathbf{i}, d) \in \mathbb{N}^{3}$ imply that

```
$\begin{equation} \mathcal{D}(\Psi^{*(n+1)}) = \mathcal{D}(\Psi \bullet (\Psi^{*n})) = (d, \mathbf{i}, \mathbf{i}, \ldots, \mathbf{i}, d) \in \mathbb{N}^{n+3} \tag{2.87} \end{equation}$
```
