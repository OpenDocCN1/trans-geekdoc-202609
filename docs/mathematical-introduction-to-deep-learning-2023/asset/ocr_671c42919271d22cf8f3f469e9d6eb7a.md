Furthermore, observe that (9.314) and (9.316) establish that for all $k \in \mathbb{N}$ it holds that $Z_2(k) \in (\mathcal{D}\mathcal{L})(Z_1(k))$. Combining this and (9.317) with item (i) in Lemma 9.15.3 proves that $y_0 \in (\mathcal{D}\mathcal{L})(x_0)$. The proof of Lemma 9.15.5 is thus complete. $\square$

# ## 9.16 Non-smooth slope

**Definition 9.16.1 (Non-smooth slope).** *Let $\mathfrak{d} \in \mathbb{N}$, $\mathcal{L} \in C(\mathbb{R}^\mathfrak{d}, \mathbb{R})$. Then we denote by* $\mathbb{S}_f: \mathbb{R}^\mathfrak{d} \to [0, \infty]$ *the function which satisfies for all* $\theta \in \mathbb{R}^\mathfrak{d}$ *that*

```
$$\mathbb{S}_\mathcal{L}(\theta) = \inf \{\lvert r \rvert : r \in \mathbb{R}: (\exists h \in (\mathfrak{D}\mathcal{L})(\theta): r = \lvert h \rvert_2) \} \cup \{\infty\} \quad (9.319)$$
```

*and we call* $\mathbb{S}_f$ *the non-smooth slope of* $f$ *(cf. Definitions 3.3.4 and 9.15.1).

# ## 9.17 Generalized KL functions

**Definition 9.17.1 (Generalized KL inequalities).** *Let* $\mathfrak{d} \in \mathbb{N}$, *$c \in \mathbb{R}$, $\alpha \in (0, \infty)$, $\mathcal{L} \in C(\mathbb{R}^\mathfrak{d}, \mathbb{R})$, *let* $U \subseteq \mathbb{R}^\mathfrak{d}$ *be a set, and let* $\theta \in U$. *Then we say that* $\mathcal{L}$ *satisfies the generalized* **KL** *inequality at* $\theta$ *on* $U$ *with exponent* $\alpha$ *and constant* $c$ *(we say that* $\mathcal{L}$ *satisfies the generalized* **KL** *inequality at* $\theta$*) if and only if for all* $\vartheta \in U$ *it holds that*

```
$$\lvert \mathcal{L}(\theta) - \mathcal{L}(\vartheta) \rvert^\alpha \leq c \lvert \mathbb{S}_\mathcal{L}(\vartheta) \rvert \quad (9.320)$$
```

*(cf. Definition 9.16.1).*
