# 9.11 Convergence analysis for solutions of GF ODEs

# 9.11.1 Abstract local convergence results for GF processes

**Lemma 9.11.1.** Let $\mathfrak{d} \in \mathbb{N}$, $\Theta \in C([0, \infty), \mathbb{R}^{\mathfrak{d}})$, $\mathcal{L} \in C^{1}(\mathbb{R}^{\mathfrak{d}}, \mathbb{R})$, let $\mathscr{F} : \mathbb{R}^{\mathfrak{d}} \to \mathbb{R}^{\mathfrak{d}}$ *satisfy for all* $\theta \in \mathbb{R}^{\mathfrak{d}}$ *that* $\mathscr{F}(\theta) = (\nabla \mathcal{L})(\theta)$, *and assume for all* $t \in [0, \infty)$ *that* $\Theta_{t} = \Theta_{0} - \int_{0}^{t}\mathscr{F}(\Theta_{s}) \, \mathrm{d}s$. *Then it holds for all* $t \in [0, \infty)$ *that*

```
$$\mathcal{L}\bigl(\Theta_{t}\bigr) = \mathcal{L}\bigl(\Theta_{0}\bigr) - \int_{0}^{t}\bigl\lVert \mathscr{F}\bigl(\Theta_{s}\bigr) \bigr\rVert_{2}^{2} \, \mathrm{d}s \tag{9.124}$$
```

*(cf. Definition 3.3.4).*

**Proof of Lemma 9.11.1.** Note that Lemma 5.2.3 *implies* (9.124). *This completes the proof of Lemma 9.11.1.* $\square$

**Proposition 9.11.2.** Let $\mathfrak{d} \in \mathbb{N}$, $\vartheta \in \mathbb{R}^{\mathfrak{d}}$, $\mathfrak{c} \in \mathbb{R}$, $\mathfrak{C}, \varepsilon \in (0, \infty)$, $\alpha \in (0, 1)$, $\Theta \in C([0, \infty), \mathbb{R}^{\mathfrak{d}})$, $\mathcal{L} \in C(\mathbb{R}^{\mathfrak{d}}, \mathbb{R})$, let $\mathscr{F} : \mathbb{R}^{\mathfrak{d}} \to \mathbb{R}^{\mathfrak{d}}$ *be* $\mathcal{B}(\mathbb{R}^{\mathfrak{d}})/\mathcal{B}(\mathbb{R}^{\mathfrak{d}})$- *measurable, assume for all* $t \in [0, \infty)$ *that*

```
$$\mathcal{L}\bigl(\Theta_{t}\bigr) = \mathcal{L}\bigl(\Theta_{0}\bigr) - \int_{0}^{t}\bigl\lVert \mathscr{F}\bigl(\Theta_{s}\bigr) \bigr\rVert_{2}^{2} \, \mathrm{d}s \qquad \text{and} \qquad \Theta_{t} = \Theta_{0} - \int_{0}^{t}\mathscr{F}\bigl(\Theta_{s}\bigr) \, \mathrm{d}s, \tag{9.125}$$
```

*and assume for all* $\theta \in \mathbb{R}^{\mathfrak{d}}$ *with* $\lVert \theta - \vartheta \rVert_{2} < \varepsilon$ *that*

```
$$\bigl| \mathcal{L}(\theta) - \mathcal{L}(\vartheta) \bigr|^{\alpha} \leq \mathfrak{C} \bigl\lVert \mathscr{F}(\theta) \bigr\rVert_{2}, \qquad \mathfrak{c} = \bigl| \mathcal{L}\bigl(\Theta_{0}\bigr) - \mathcal{L}(\vartheta) \bigr|, \qquad \mathfrak{C}(1-\alpha)^{-1}\mathfrak{c}^{1-\alpha} + \bigl\lVert \Theta_{0} - \vartheta \bigr\rVert_{2} < \varepsilon, \tag{9.126}$$
```

*and* $\inf_{t \in \{s \in [0, \infty) : \forall r \in [0, s] : \lVert \Theta_{r} - \vartheta \rVert_{2} < \varepsilon \} \} \mathcal{L}(\Theta_{t}) \geq \mathcal{L}(\vartheta)$ *(cf. Definition 3.3.4). Then there exists* $\psi \in \mathbb{R}^{\mathfrak{d}}$ *such that*

+   *(i) it holds that* $\mathcal{L}(\psi) = \mathcal{L}(\vartheta)$

+   *(ii) it holds for all* $t \in [0, \infty)$ *that* $\lVert \Theta_{t} - \psi \rVert_{2} < \varepsilon$,

+   *(iii) it holds for all* $t \in [0, \infty)$ *that* $0 \leq \mathcal{L}(\Theta_{t}) - \mathcal{L}(\psi) \leq \mathfrak{C}^{2}\mathfrak{c}^{2}(\lVert_{[0]}(\mathfrak{c}) + \mathfrak{C}^{2}\varepsilon + \mathfrak{c}^{2\alpha}t)^{-1}$*, *and*

+   *(iv) it holds for all* $t \in [0, \infty)$ *that*

```
$$\begin{aligned} \bigl\lVert \Theta_{t} - \psi \bigr\rVert_{2} & \leq \int_{t}^{\infty}\bigl\lVert \mathscr{F}\bigl(\Theta_{s}\bigr) \bigr\rVert_{2} \, \mathrm{d}s \leq \mathfrak{C}(1-\alpha)^{-1}\bigl[\mathcal{L}(\Theta_{t}) - \mathcal{L}(\psi)\bigr]^{1-\alpha} \\[5pt] & \leq \mathfrak{C}^{3-2\alpha}\mathfrak{c}^{2-2\alpha}(1-\alpha)^{-1}(\lVert_{[0]}(\mathfrak{c}) + \mathfrak{C}^{2}\varepsilon + \mathfrak{c}^{2\alpha}t)^{\alpha-1}. \end{aligned} \tag{9.127}$$
```
