Then we say that $\Theta$ is the *Adadelta SGD* process on $(\Omega, \mathcal{F}, \mathbb{P}), (S, \mathcal{S})$ for the loss function $\ell$ with generalized gradient $\boldsymbol{\mathcal{G}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, second moment decay factors $(\beta_n)_{n \in \mathbb{N}}$, delta decay factors $(\delta_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(\boldsymbol{X}_{n,j})_{(n, j) \in \{\kappa_0\} \in \mathbb{N}^2: 1 \leq j \leq J_k}$ (we say that $\Theta$ is the *Adadelta SGD* process for the loss function $\ell$ with batch sizes $(J_n)_{n \in \mathbb{N}}$, second moment decay factors $(\beta_n)_{n \in \mathbb{N}}$, delta decay factors $(\delta_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(\boldsymbol{X}_{n,j})_{(n, j) \in \{\kappa_0\} \in \mathbb{N}^2: 1 \leq j \leq J_k}$) if and only if it holds that $\Theta = (\Theta^{(1)}, \ldots, \Theta^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ is the function from $\mathbb{N}_0 \times \Omega$ to $\mathbb{R}^3$ which satisfies that there exist $\mathbb{M} = (\mathbb{M}^{(1)}, \ldots, \mathbb{M}^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ and $\Delta = (\Delta^{(1)}, \ldots, \Delta^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ such that for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \boldsymbol{d}\}$ it holds that

$\Theta_0 = \boldsymbol{\xi}, \quad \mathbb{M}_0 = 0, \quad \Delta_0 = 0, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (7.148)$

$\mathbb{M}_n^{(i)} = \beta_n \mathbb{M}_{n-1}^{(i)} + (1 - \beta_n) \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{\mathcal{G}}_i(\Theta_{n-1}, \boldsymbol{X}_{n,j}) \right]^2, \qquad\qquad (7.149)$

$\Theta_n^{(i)} = \Theta_{n-1}^{(i)} - \left( \frac{\varepsilon + \Delta_{n-1}^{(i)}}{\varepsilon + \mathbb{M}_n^{(i)}} \right)^{1/2} \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{\mathcal{G}}_i(\Theta_{n-1}, \boldsymbol{X}_{n,j}) \right], \qquad (7.150)$

$\text{and} \qquad \Delta_n^{(i)} = \delta_n \Delta_{n-1}^{(i)} + (1 - \delta_n) |\Theta_n^{(i)} - \Theta_{n-1}^{(i)}|^2. \qquad\qquad\qquad\qquad\qquad\qquad\qquad (7.151)$
