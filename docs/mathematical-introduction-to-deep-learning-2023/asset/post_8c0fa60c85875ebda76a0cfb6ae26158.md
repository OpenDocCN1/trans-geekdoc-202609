### Proposition 4.3.8 (Implicit multi-dimensional ANN approximations with prescribed error tolerances and explicit parameter bounds)

Let $d \in \mathbb{N}$, $L, a \in \mathbb{R}$, $b \in [a, \infty)$, $\varepsilon \in (0,1]$ and let $f: [a, b]^{d} \rightarrow \mathbb{R}$ satisfy for all $x, y \in [a, b]^{d}$ that

$|f(x)-f(y)| \leq L\|x-y\|_{1}$    (4.111)

(cf. Definition 3.3.4). Then there exists $\mathbf{F} \in \mathbf{N}$ such that

-   (i) it holds that $\mathcal{I}(\mathbf{F})=d$,
-   (ii) it holds that $\mathcal{O}(\mathbf{F})=1$,
-   (iii) it holds that $\mathcal{H}(\mathbf{F}) \leq d\left(\log _{2}\left(\max \left\{\frac{3 d L(b-a)}{2}, 1\right\}+\log _{2}\left(\varepsilon^{-1}\right)\right)+2\right)$,
-   (iv) it holds that $\mathbb{D}_{1}(\mathbf{F}) \leq \varepsilon^{-d} d(3 d \max \{L(b-a), 1\})^{d}$,
-   (v) it holds for all $i \in\{2,3,4, \ldots\}$ that $\mathbb{D}_{i}(\mathbf{F}) \leq \varepsilon^{-d} 3\left(\frac{(3 d L(b-a))^{i}}{2^{i}}+1\right)$,
-   (vi) it holds that $\mathcal{P}(\mathbf{F}) \leq \varepsilon^{-2 d} 9\left(3 d \max \{L(b-a), 1\}\right)^{2 d} d^{2}$,
-   (vii) it holds that $\|T(\mathbf{F})\|_{\infty} \leq \max \{1, L,|a|,|b|, 2\left[\sup _{x \in [a, b]^{d}}|f(x)|\right]\}$, and
-   (viii) it holds that $\sup _{x \in [a, b]^{d}}\left(\mathcal{R} \mathbf{N}(\mathbf{F})(x)-f(x)\right) \leq \varepsilon$

(cf. Definitions 1.2.4, 1.3.1, 1.3.4, and 1.3.5).

*Proof of Proposition 4.3.8.* Throughout this proof, assume without loss of generality that

$L(b-a) \neq 0$.    (4.112)

Observe that (4.112) ensures that $L \neq 0$ and $a < b$. Combining this with the assumption that for all $x, y \in [a, b]^{d}$ it holds that

$|f(x)-f(y)| \leq L\|x-y\|_{1}$,    (4.113)

ensures that $L > 0$. Proposition 4.3.7 therefore ensures that there exists $\mathbf{F} \in \mathbf{N}$ which satisfies that

-   (I) it holds that $\mathcal{I}(\mathbf{F}) = d$,
-   (II) it holds that $\mathcal{O}(\mathbf{F}) = 1$,
-   (III) it holds that $\mathcal{H}(\mathbf{F}) \le \big[ d \log_2(\frac{3dL(b-a)}{2\varepsilon}) + 1 \big] \mathbb{I}_{(0,d/4]}(\frac{\varepsilon}{2L(b-a)})$,
-   (IV) it holds that $\mathbb{D}_1(\mathbf{F}) \le 2d(\frac{3dL(b-a)}{2\varepsilon})^d \mathbb{I}_{(0,d/4]}(\frac{\varepsilon}{2L(b-a)}) + \mathbb{I}_{(d/4,\infty)}(\frac{\varepsilon}{2L(b-a)})$,
-   (V) it holds for all $i \in \{2, 3, 4, \ldots\}$ that $\mathbb{D}_i(\mathbf{F}) \le 3 \big[ (\frac{3dL(b-a)}{2\varepsilon})^d \frac{1}{2^{i-1}} \big]$,
-   (VI) it holds that $\mathcal{P}(\mathbf{F}) \le 35 (\frac{3dL(b-a)}{2\varepsilon})^{2d} d^2 \mathbb{I}_{(0,d/4)}(\frac{\varepsilon}{2L(b-a)}) + (d+1) \mathbb{I}_{(d/4,\infty)}(\frac{\varepsilon}{2L(b-a)})$,
-   (VII) it holds that $\|\mathcal{T}(\mathbf{F})\|_\infty \le \max\{1, L, |a|, |b|, 2 \|\mathrm{s}_{[a,b]^d}\|f(x)\|_\infty \}$, and
-   (VIII) it holds that $\sup_{x \in [a,b]^d} |(\mathcal{R}_{\tau}^N(\mathbf{F}))(x) - f(x)| \le \varepsilon$

(cf. Definitions 1.2.4, 1.3.1, 1.3.4, 1.3.5, and 4.2.6). Note that item **(III)** assures that

$$
\begin{align*}
\mathcal{H}(\mathbf{F}) \le \big( d \big( \log_2(\frac{3dL(b-a)}{2}) + \log_2(\varepsilon^{-1}) \big) + 2 \big) \mathbb{I}_{(0,d/4)}(\frac{\varepsilon}{2L(b-a)}) \\

### Corollary 4.3.9 (Implicit multi-dimensional ANN approximations with prescribed error tolerances and asymptotic parameter bounds)

*Let* $d \in \mathbb{N}$, $L$, $a \in \mathbb{R}$, $b \in [a, \infty)$ *and let* $f \colon [a, b]^d \to \mathbb{R}$ *satisfy for all* $x, y \in [a, b]^d$ *that*

$\left\vert f(x) - f(y)\right\vert \leq L\left\Vert x - y\right\Vert_1$ (4.118)

(*cf. Definition* **3.3.4**). *Then there exist* $\mathfrak{C} \in \mathbb{R}$ *such that for all* $\varepsilon \in (0,1]$ *there exists* $\mathbf{F} \in \mathbf{N}$ *such that*

$\mathcal{H}(\mathbf{F}) \leq \mathfrak{C}(\log_2(\varepsilon^{-1}) + 1), \qquad \left\Vert \mathcal{T}(\mathbf{F}) \right\Vert_\infty \leq \max\big\{1, L, \vert a\vert, \vert b\vert, 2\big[\sup_{x \in [a,b]^d}\vert f(x)\vert\big]\big\},$ (4.119)

$\mathcal{R}^{\mathbf{N}}_\tau(\mathbf{F}) \in C(\mathbb{R}^d, \mathbb{R}), \quad \sup_{x \in [a,b]^d}\big(\left\vert \mathcal{R}^{\mathbf{N}}_\tau(\mathbf{F})\right)(x) - f(x)\big)\vert \leq \varepsilon, \quad \text{and} \quad \mathcal{P}(\mathbf{F}) \leq \mathfrak{C}\varepsilon^{-2d}$ (4.120)

(*cf. Definitions* **1.2.4, 1.3.1, 1.3.4, and 1.3.5**).

*Proof of Corollary* **4.3.9**. *Throughout this proof, let* $\mathfrak{C} \in \mathbb{R}$ *satisfy*

$\mathfrak{C} = 9\big(3d \, \max\{L(b-a), 1\}\big)^{2d} d^2.$ (4.121)

Note that items **(i), (ii), (iii), (vi), (vii), and (viii)** in Proposition **4.3.8** *and the fact that for all* $\varepsilon \in (0,1]$ *it holds that*

$d\big(\log_2\big(\max\{\frac{3dL(b-a)}{2}, 1\}\big) + \log_2(\varepsilon^{-1})\big) + 2 \leq d\big(\max\big\{\frac{3dL(b-a)}{2}, 1\big\} + \log_2(\varepsilon^{-1})\big) + 2$
$\leq d \, \max\{3dL(b-a), 1\} + 2 + d \, \log_2(\varepsilon^{-1})$
$\leq \mathfrak{C}(\log_2(\varepsilon^{-1}) + 1)$ (4.122)

*imply that for every* $\varepsilon \in (0,1)$ *there exists* $\mathbf{F} \in \mathbf{N}$ *such that*

$\mathcal{H}(\mathbf{F}) \leq \mathfrak{C}(\log_2(\varepsilon^{-1}) + 1), \qquad \left\Vert \mathcal{T}(\mathbf{F}) \right\Vert_\infty \leq \max\big\{1, L, \vert a\vert, \vert b\vert, 2\big[\sup_{x \in [a,b]^d}\vert f(x)\vert\big]\big\},$ (4.123)

$\mathcal{R}^{\mathbf{N}}_\tau(\mathbf{F}) \in C(\mathbb{R}^d, \mathbb{R}), \qquad \sup_{x \in [a,b]^d}\big(\left\vert \mathcal{R}^{\mathbf{N}}_\tau(\mathbf{F})\right)(x) - f(x)\big)\vert \leq \varepsilon, \quad \text{and} \quad \mathcal{P}(\mathbf{F}) \leq \mathfrak{C}\varepsilon^{-2d}$ (4.124)

(*cf. Definitions* **1.2.4, 1.3.1, 1.3.4, and 1.3.5**). *The proof of Corollary* **4.3.9** *is thus complete.* $\square$
