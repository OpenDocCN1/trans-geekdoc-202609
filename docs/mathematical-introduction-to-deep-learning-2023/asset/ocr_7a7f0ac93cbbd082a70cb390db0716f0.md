establish that for all $k \in \{0, 1, \dots, K\}$ it holds that

```
$$\begin{align} |c_k| &\le \frac{K(|f(\mathtt{f}_{\min\{k+1,K\}}) - f(\mathtt{f}_k)| + |f(\mathtt{f}_{\max\{k-1,0\}}) - f(\mathtt{f}_k)|}{(b-a)} \\ &\le \frac{KL(\mathtt{f}_{\min\{k+1,K\}} - \mathtt{f}_k| + |\mathtt{f}_{\max\{k-1,0\}} - \mathtt{f}_k|}{(b-a)} \\ &\le \frac{2KL(b-a)[\max\{K,1\}]^{-1}}{(b-a)} \le 2L. \end{align}\tag{3.101}$$
```

This and $(3.98)$ prove item $\mathbf{(vii)}$. The proof of Corollary $\mathbf{3.3.5}$ is thus complete.$\square$

**Corollary 3.3.6** *(Implicit one-dimensional ANN approximations with prescribed error tolerances and asymptotic parameter bounds).* *Let* $L, a \in \mathbb{R}$, *$b \in [a, \infty)$* *and let* $f: [a, b] \to \mathbb{R}$ *satisfy for all* $x, y \in [a, b]$ *that*

```
$$|f(x) - f(y)| \le L|x - y|.\tag{3.102}$$
```

*Then there exist* $\mathfrak{C} \in \mathbb{R}$ *such that for all* $\varepsilon \in (0, 1]$ *there exists* $\mathbf{F} \in \mathbf{N}$ *such that*

```
$$\mathcal{R}^{\mathbf{N}}_{\mathfrak{t}}(\mathbf{F}) \in \mathcal{C}(\mathbb{R}, \mathbb{R}), \quad \sup_{x \in [a,b]}(|\mathcal{R}^{\mathbf{N}}_{\mathfrak{t}}(\mathbf{F})(x) - f(x)|) \le \varepsilon, \quad \mathcal{H}(\mathbf{F}) = 1,\tag{3.103}$$
$$\|\mathcal{T}(\mathbf{F})\|_\infty \le \max\{1, |a|, |b|, 2L, |f(a)|\}, \quad \text{and} \quad \mathcal{P}(\mathbf{F}) \le \mathfrak{C}\varepsilon^{-1}\tag{3.104}$$
```

*(cf. Definitions* $\mathbf{1.2.4}$*,* $\mathbf{1.3.1}$*,* $\mathbf{1.3.4}$*,* $\mathbf{1.3.5}$*, and* $\mathbf{3.3.4}$*).*

*Proof of Corollary* $\mathbf{3.3.6}$. *Throughout this proof, assume without loss of generality that* $a < b$ *and let*

```
$$\mathfrak{C} = 3L(b-a) + 7.\tag{3.105}$$
```

Note that the assumption that $a < b$ shows that $L \ge 0$. Furthermore, observe that $(3.105)$ ensures that for all $\varepsilon \in (0, 1]$ it holds that

```
$$3L(b-a)\varepsilon^{-1} + 7 \le 3L(b-a)\varepsilon^{-1} + 7\varepsilon^{-1} = \mathfrak{C}\varepsilon^{-1}.\tag{3.106}$$
```

This and Corollary $\mathbf{3.3.5}$ imply that for all $\varepsilon \in (0, 1]$ there exists $\mathbf{F} \in \mathbf{N}$ such that

```
$$\mathcal{R}^{\mathbf{N}}_{\mathfrak{t}}(\mathbf{F}) \in \mathcal{C}(\mathbb{R}, \mathbb{R}), \quad \sup_{x \in [a,b]}(|\mathcal{R}^{\mathbf{N}}_{\mathfrak{t}}(\mathbf{F})(x) - f(x)|) \le \varepsilon, \quad \mathcal{H}(\mathbf{F}) = 1,\tag{3.107}$$
$$\|\mathcal{T}(\mathbf{F})\|_\infty \le \max\{1, |a|, |b|, 2L, |f(a)|\}, \quad \text{and} \quad \mathcal{P}(\mathbf{F}) \le 3L(b-a)\varepsilon^{-1} + 7 \le \mathfrak{C}\varepsilon^{-1}\tag{3.108}$$
```

(cf. Definitions $\mathbf{1.2.4}$, $\mathbf{1.3.1}$, $\mathbf{1.3.4}$, $\mathbf{1.3.5}$, and $\mathbf{3.3.4}$). The proof of Corollary $\mathbf{3.3.6}$ is thus complete.$\square$
