Proof of Lemma 4.4.7. Throughout this proof, let $\Xi \in \mathbf{N}$ satisfy $\Xi = \mathfrak{L}_{\mathfrak{I}_L}(\Phi)$ (cf. Definitions 2.2.6 and 2.2.8). Note that item (i) in Lemma 2.2.7 establishes that $\mathcal{D}(\mathfrak{I}_{L}\mathfrak{c}) = (L, 2L, L_L) \in \mathbb{N}^{3}$. Combining this with Lemma 2.2.11 shows that $\mathcal{D}(\Xi) \in \mathbb{N}^{\mathfrak{I} + 1}$ and

```
\begin{equation} \mathcal{D}(\Xi) = \begin{cases} \left( \mathfrak{l}_0, \mathfrak{l}_1, \ldots, \mathfrak{l}_L \right) & : \mathfrak{L} = L \\ \left( \mathfrak{l}_0, \mathfrak{l}_1, \ldots, \mathfrak{l}_{L-1}, 2\mathfrak{l}_L, 2\mathfrak{l}_L, \ldots, 2\mathfrak{l}_L, L \right) & : \mathfrak{L} > L. \end{cases} \end{equation}
```

Furthermore, observe that Lemma 4.4.6 (applied with $\mathfrak{d} \frown \mathfrak{l}_L$, $L \frown \mathfrak{L}$, $\Phi \frown \Phi$ in the notation of Lemma 4.4.6) ensures that

```
\begin{equation} \left\| \mathcal{T}(\Xi) \right\|_{\infty} \leq \max \left\{ 1, \left\| \mathcal{T}(\Phi) \right\|_{\infty} \right\} \end{equation}
```

(cf. Definitions 1.3.5 and 3.3.4). Moreover, note that item (ii) in Lemma 2.2.7 implies that for all $x \in \mathbb{R}^{\mathfrak{l}}$ it holds that

```
\begin{equation} \left( \mathcal{R}_{\mathfrak{c}}^{\mathbf{N}}(\mathfrak{I}_L) \right)(x) = x \end{equation}
```

(cf. Definitions 1.2.4 and 1.3.4). This and item (ii) in Lemma 2.2.10 prove that

```
\begin{equation} \mathcal{R}_{\mathfrak{c}}^{\mathbf{N}}(\Xi) = \mathcal{R}_{\mathfrak{c}}^{\mathbf{N}}(\Phi). \end{equation}
```

In addition, observe that (4.166), the assumption that for all $i \in [0, L]$ it holds that $\mathfrak{l}_0 = l_0$, $\mathfrak{l}_\mathfrak{L} = l_L$, and $\mathfrak{l}_i \leq l_i$, the assumption that for all $i \in \mathbb{N} \cap (L - 1, \mathfrak{L})$ it holds that $\mathfrak{l}_i \geq 2l_L$, and Lemma 4.4.4 (applied with $a \frown \mathfrak{c}$, $L \frown \mathfrak{L}$, $(l_0, l_1, \ldots, l_L) \frown \mathcal{D}(\Xi)$, $(\mathfrak{l}_0, \mathfrak{l}_1, \ldots, \mathfrak{l}_\mathfrak{L}) \frown (\mathfrak{l}_0, \mathfrak{l}_1, \ldots, \mathfrak{l}_\mathfrak{L})$, $\Phi \frown \Xi$ in the notation of Lemma 4.4.4) demonstrate that there exists $\Psi \in \mathbf{N}$ such that

```
\begin{equation} \mathcal{D}(\Psi) = (\mathfrak{l}_0, \mathfrak{l}_1, \ldots, \mathfrak{l}_\mathfrak{L}), \\ \left\| \mathcal{T}(\Psi) \right\|_{\infty} = \left\| \mathcal{T}(\Xi) \right\|_{\infty}, \\ \text{ and } \\ \mathcal{R}_{\mathfrak{c}}^{\mathbf{N}}(\Psi) = \mathcal{R}_{\mathfrak{c}}^{\mathbf{N}}(\Xi). \end{equation}
```

Combining this with (4.167) and (4.169) proves (4.165). The proof of Lemma 4.4.7 is thus complete.
