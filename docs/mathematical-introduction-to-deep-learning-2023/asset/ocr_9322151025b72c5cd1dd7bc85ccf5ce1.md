Source code 7.1 (code/optimization_methods/sgd.py): PYTHON code implementing the SGD optimization method in the training of an ANN as described in Example 7.2.2 in PYTORCH. In this code a fully-connected ANN with a single hidden layer with 200 neurons using the hyperbolic tangent activation function is trained so that the realization function approximates the target function sin : $\mathbb{R} \rightarrow \mathbb{R}$. Example 7.2.2 is implemented with $d = 1$, $h = 1$, $\mathfrak{d} = 301$, $l_1 = 200$, $a = \text{tanh}$, $M = 10000$, $\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_M \in \mathbb{R}$, $\mathbf{y}_i = \sin(x_i)$ for all $i \in \{1, 2, \dots, M\}$, $\gamma_n = 0.003$ for all $n \in \mathbb{N}$, and $J_n = 32$ for all $n \in \mathbb{N}$ in the notation of Example 7.2.2.
