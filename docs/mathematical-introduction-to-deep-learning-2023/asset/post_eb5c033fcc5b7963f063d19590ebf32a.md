
## 7.6. Adagrad SGD optimization (Adagrad)

**Definition 7.6.1** (Adagrad SGD optimization method). Let $\boldsymbol{d} \in \mathbb{N}$, $(\gamma_n)_{n \in \mathbb{N}} \subseteq [0, \infty)$, $(J_n)_{n \in \mathbb{N}} \subseteq \mathbb{N}$, $\varepsilon \in (0, \infty)$, let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space, let $(\mathcal{S}, \boldsymbol{S})$ be a measurable space, let $\xi: \Omega \to \mathbb{R}^{\boldsymbol{d}}$ be a random variable, for every $n \in \mathbb{N}$, $j \in \{1, 2, \ldots, J_n\}$ let $X_{n,j}: \Omega \to \mathcal{S}$ be a random variable, and let $\ell = (\ell(\theta, x))_{(\theta, x) \in \mathbb{R}^{\boldsymbol{d}} \times \mathcal{S}}: \mathbb{R}^{\boldsymbol{d}} \times \mathcal{S} \to \mathbb{R}$ and $\boldsymbol{g} = (\boldsymbol{g}_1, \ldots, \boldsymbol{g}_{\boldsymbol{d}}): \mathbb{R}^{\boldsymbol{d}} \times \mathcal{S} \to \mathbb{R}^{\boldsymbol{d}}$ satisfy for all $U$ in $\{V \subseteq \mathbb{R}^{\boldsymbol{d}}: V \text{ is open}\}$, $x \in \mathcal{S}$, $\theta \in U$ with $(U \ni \psi \mapsto \ell(\psi, x) \in \mathbb{R}) \in C^1(U, \mathbb{R})$ that

$$\boldsymbol{g}(\theta, x) = (\nabla_{\theta} \ell)(\theta, x). \tag{7.137}$$

Then we say that $\Theta$ is the Adagrad SGD process on $((\Omega, \mathcal{F}, \mathbb{P}), (\mathcal{S}, \boldsymbol{S}))$ for the loss function $\ell$ with generalized gradient $\boldsymbol{g}$, learning rates $(\gamma_n)_{n \in \mathbb{N}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n,j})_{(n, j) \in \{(k, l) \in \mathbb{N}^2: l \leq J_k\}}$ (we say that $\Theta$ is the Adagrad SGD process for the loss function $\ell$ with learning rates $(\gamma_n)_{n \in \mathbb{N}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n,j})_{(n, j) \in \{(k, l) \in \mathbb{N}^2: l \leq J_k\}}$ if and only if it holds that $\Theta = (\Theta^{(1)}, \ldots, \Theta^{(\boldsymbol{d})}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^{\boldsymbol{d}}$ is the function from $\mathbb{N}_0 \times \Omega$ to $\mathbb{R}^{\boldsymbol{d}}$ which satisfies for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \boldsymbol{d}\}$ that $\Theta_0 = \xi$ and

$$\Theta_n^{(i)} = \Theta_{n-1}^{(i)} - \gamma_n \left( \varepsilon + \left[ \sum_{k=1}^{n} \left( \frac{1}{J_k} \sum_{j=1}^{J_k} \boldsymbol{g}_{i, j}(\Theta_{k-1}, X_{k, j}) \right)^2 \right]^{1/2 - 1} \right) \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{g}_{i, j}(\Theta_{n-1}, X_{n, j}) \right]. \tag{7.138}$$

An implementation in PyTorch of the Adagrad SGD optimization method as described in Definition 7.6.1 above is given in Source code 7.7. The Adagrad SGD optimization method as described in Definition 7.6.1 above is also available in PyTorch in the form of the built-in `torch.optim.Adagrad` optimizer (which, for applications, is generally much preferable to implementing it from scratch).

```python
import torch
import torch.nn as nn
import numpy as np

net = nn.Sequential(
    nn.Linear(1, 200), nn.ReLU(), nn.Linear(200, 1)
)

M = 1000

X = torch.rand((M, 1)) * 4 * np.pi - 2 * np.pi
Y = torch.sin(X)

J = 64

N = 150000

loss = nn.MSELoss()
lr = 0.02
eps = 1e-10

sum_sq_grad = [p.clone().detach().fill_(eps) for p in net.parameters()]

for n in range(N):
    indices = torch.randint(0, M, (J,))

    x = X[indices]
    y = Y[indices]

    net.zero_grad()

    loss_val = loss(net(x), y)
    loss_val.backward()

    with torch.no_grad():
        for a, p in zip(sum_sq_grad, net.parameters()):
            a.add_(p.grad * p.grad)
            p.sub_(lr * a.rsqrt() * p.grad)

    if n % 1000 == 0:
        with torch.no_grad():
            x = torch.rand((1000, 1)) * 4 * np.pi - 2 * np.pi
            y = torch.sin(x)
            loss_val = loss(net(x), y)
            print(f"Iteration: {n+1}, Loss: {loss_val}")
```

## 7.7 Root mean square propagation SGD optimization (RMSPROP)

In this section we introduce the stochastic version of the RMSprop GD optimization method from Section 6.6 (cf. Hinton et al. [199]).

**Definition 7.7.1** (RMSprop SGD optimization method). Let $\mathbf{d} \in \mathbb{N}$, $(\gamma_{n})_{n \in \mathbb{N}} \subseteq [0, \infty)$, $(J_{n})_{n \in \mathbb{N}} \subseteq \mathbb{N}$, $(\beta_{n})_{n \in \mathbb{N}} \subseteq [0, 1]$, $\varepsilon \in (0, \infty)$, let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space, let $(S, \mathcal{S})$ be a measurable space, let $\xi: \Omega \rightarrow \mathbb{R}^{d}$ be a random variable, for every $n \in \mathbb{N}$, $j \in \{ 1, 2, \ldots, J_{n} \}$ let $X_{n,j}: \Omega \rightarrow S$ be a random variable, and let $\ell = (\ell(\theta, x))_{(\theta, x) \in \mathbb{R}^{d} \times S}: \mathbb{R}^{d} \times S \rightarrow \mathbb{R}$ and $\mathbf{g} = (\mathbf{g}_{1}, \ldots, \mathbf{g}_{d}): \mathbb{R}^{d} \times S \rightarrow \mathbb{R}^{d}$ satisfy for all $U \in \{ V \subseteq \mathbb{R}^{d}: V$ is open$\}$, $x \in S$, $\theta \in U$ with $(U \supset \vartheta \mapsto \mathcal{L}(\vartheta, x) \in \mathbb{R}) \in C^{1}(U, \mathbb{R})$ that

$$\boldsymbol{g}(\theta, x) = (\nabla_{\theta} \mathcal{L})(\theta, x). \tag{7.139}$$

Then we say that $\Theta$ is the RMSprop SGD process on $((\Omega, \mathcal{F}, \mathbb{P}), (\mathcal{S}, \mathcal{S}))$ for the loss function $\mathcal{L}$ with generalized gradient $\boldsymbol{g}$, learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(X_{n, j})_{(n, j) \in(\{k, l \in \mathbb{N}: l \leq J_{k}\})}$ (we say that $\Theta$ is the RMSprop SGD process for the loss function $\mathcal{L}$ with learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(X_{n, j})_{(n, j) \in(\{k, l \in \mathbb{N}: l \leq J_{k}\})}$) if and only if it holds that $\Theta=(\Theta^{(1)}, \ldots, \Theta^{(\mathbf{d})}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{\mathbf{d}}$ is the function from $\mathbb{N}_{0} \times \Omega$ to $\mathbb{R}^{\mathbf{d}}$ which satisfies that there exists $\mathbb{M}=(\mathbb{M}^{(1)}, \ldots, \mathbb{M}^{(\mathbf{d})}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{\mathbf{d}}$ such that for all $n \in \mathbb{N}$, $i \in\{1,2, \ldots, \mathbf{d}\}$ it holds that

$$\Theta_{0}=\boldsymbol{\xi}, \quad \mathbb{M}_{0}=0, \tag{7.140}$$

$$\mathbb{M}_{n}^{(i)}=\beta_{n} \mathbb{M}_{n-1}^{(i)}+\left(1-\beta_{n}\right)\left[\frac{1}{J_{n}} \sum_{j=1}^{J_{n}} \boldsymbol{g}_{i}\left(\Theta_{n-1}, X_{n, j}\right)\right]^{2}, \tag{7.141}$$

and

$$\Theta_{n}^{(i)}=\Theta_{n-1}^{(i)}-\frac{\gamma_{n}}{\varepsilon+\left[\mathbb{M}_{n}^{(i)}\right]^{1 / 2}}\left[\frac{1}{J_{n}} \sum_{j=1}^{J_{n}} \boldsymbol{g}_{i}\left(\Theta_{n-1}, X_{n, j}\right)\right]. \tag{7.142}$$

**Remark 7.7.2.** In Hinton et al. [199] it is proposed to choose $0.9 = \beta_{1} = \beta_{2} = \ldots$ as default values for the second moment decay factors $(\beta_{n})_{n \in \mathbb{N}} \subseteq [0,1]$ in Definition 7.7.1.

An implementation in PyTorch of the RMSprop SGD optimization method as described in Definition 7.7.1 above is given in Source code 7.8. The RMSprop SGD optimization method as described in Definition 7.7.1 above is also available in PyTorch in the form of the built-in `torch.optim.RMSprop` optimizer (which, for applications, is generally much preferable to implementing it from scratch).
