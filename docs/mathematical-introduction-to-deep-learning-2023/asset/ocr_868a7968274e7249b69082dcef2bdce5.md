Hence, we obtain that for all $x \in \mathbb{R}$ it holds that

$\begin{aligned}a''(x) &= \left[ a(x)(1 - a(x)) \right]' = a'(x)(1 - a(x)) + a(x)(1 - a(x))' \\- &= a'(x)(1 - a(x)) - a(x)a'(x) = a'(x)(1 - 2a(x)) \\- &= a(x)(1 - a(x))(1 - 2a(x)) = a(x) - [a(x)]^2 - 2[a(x)]^2 + 2[a(x)]^3 \\- &= 2[a(x)]^3 - 3[a(x)]^2 + a(x). \end{aligned}$

This establishes item **(ii)**. The proof of Proposition [1.2.20](https://arxiv.org/abs/1.2.20) is thus complete.

# 1.2.7.2 Integral of the standard logistic activation function

> **Lemma 1.2.21** (Primitive of the standard logistic activation function). Let $\mathbf{s}$ be the *softplus* activation function and let $\mathbf{l}$ be the *standard logistic activation function* (*cf. Definitions* [1.2.11](https://arxiv.org/abs/1.2.11) *and* [1.2.18](https://arxiv.org/abs/1.2.18)). *Then it holds for all* $x \in \mathbb{R}$

$\int_{-\infty}^{x} \mathbf{l}(y) \, \mathrm{d}y = \int_{-\infty}^{x} \left( \frac{1}{1 + e^{-y}} \right) \, \mathrm{d}y = \ln(1 + \exp(x)) = \mathbf{s}(x).$

*Proof of Lemma* [1.2.21](https://arxiv.org/abs/1.2.21). *Observe that* ([1.47](https://arxiv.org/abs/1.47)) *implies that for all* $x \in \mathbb{R}$ *it holds that*

$\mathbf{s}'(x) = \left[ \frac{1}{1 + \exp(x)} \right] \exp(x) = \mathbf{l}(x).$

The fundamental theorem of calculus hence shows that for all $w, x \in \mathbb{R}$ with $w \leq x$ it holds that

$\int_{\underbrace{w}_{\geq 0}}^{x} \mathbf{l}(y) \, \mathrm{d}y = \mathbf{s}(x) - \mathbf{s}(w).$

Combining this with the fact that $\lim_{w \to -\infty} \mathbf{s}(w) = 0$ establishes ([1.57](https://arxiv.org/abs/1.57)). The proof of Lemma [1.2.21](https://arxiv.org/abs/1.2.21) is thus complete.

# 1.2.8 Swish activation

> **Definition 1.2.22** (Swish activation function). *Let* $\beta \in \mathbb{R}$. *Then we say that* $a$ *is the* *swish* *activation function with parameter* $\beta$ *if and only if it holds that* $a: \mathbb{R} \to \mathbb{R}$ *is the function from* $\mathbb{R}$ *to* $\mathbb{R}$ *which satisfies for all* $x \in \mathbb{R}$ *that*

$a(x) = \frac{x}{1 + \exp(-\beta x)}.$
