### 7.7.1 Bias-adjusted root mean square propagation SGD optimization

**Definition 7.7.3** (Bias-adjusted RMSprop SGD optimization method). Let $\mathfrak{d}\in\mathbb{N}$, $(\gamma_{n})_{n\in\mathbb{N}}\subseteq[0,\infty)$, $(J_{n})_{n\in\mathbb{N}}\subseteq\mathbb{N}$, $(\beta_{n})_{n\in\mathbb{N}}\subseteq[0,1]$, $\varepsilon\in(0,\infty)$ satisfy $\beta_{1}<1$, let $(\Omega,\mathcal{F},\mathbb{P})$ be a probability space, let $(S,\mathcal{S})$ be a measurable space, let $\xi:\Omega\to\mathbb{R}^{\mathfrak{d}}$ be a random variable, for every $n\in\mathbb{N}$, $j\in\{1,2,\dots,J_{n}\}$ let $X_{n,j}:\Omega\to S$ be a random variable, and let $\ell=(\ell(\theta,x))_{(\theta,x)\in\mathbb{R}^{\mathfrak{d}}\times S}:\mathbb{R}^{\mathfrak{d}}\times S\to\mathbb{R}$ and $\boldsymbol{g}=(\boldsymbol{g}_{1},\dots,\boldsymbol{g}_{\mathfrak{d}}):\mathbb{R}^{\mathfrak{d}}\times S\to\mathbb{R}^{\mathfrak{d}}$ satisfy for all $U \in\{V \subseteq \mathbb{R}^{\mathfrak{d}}$: $V$ is open$\}$, $x \in S$, $\vartheta \in U$ with $(U \cup \varnothing \to \ell(\vartheta, x) \in \mathbb{R}) \in C^{1}(U, \mathbb{R})$ that

$$\vartheta^{\prime} \vartheta(\vartheta, x)=(\nabla \ell^{\vartheta^{\prime}})(\vartheta, x) \text{.} \qquad(7.143)$$

Then we say that $\Theta$ is the bias-adjusted RMSprop **SGD** process on $((\Omega, \mathcal{F}, \mathbb{P}), (S, \mathcal{S}))$ for the loss function $\ell$ with generalized gradient $\vartheta^{\prime}$, learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n, j})_{(n, j) \in\{k, \ell\} \times \{j: 1 \leq J_{k}\}}$ (we say that $\Theta$ is the bias-adjusted RMSprop **SGD** process for the loss function $\ell$ with learning rates $(\gamma_{n})_{n \in \mathbb{N}}$, batch sizes $(J_{n})_{n \in \mathbb{N}}$, second moment decay factors $(\beta_{n})_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\xi$, and data $(X_{n, j})_{(n, j) \in\{k, \ell\} \times \{j: 1 \leq J_{k}\}}$ if and only if it holds that $\Theta=(\Theta^{(1)}, \ldots, \Theta^{(\mathfrak{d})}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{\mathfrak{d}}$ is the function from $\mathbb{N}_{0} \times \Omega$ to $\mathbb{R}^{\mathfrak{d}}$ which satisfies that there exists $\mathbb{M}=(\mathbb{M}^{(1)}, \ldots, \mathbb{M}^{(\mathfrak{d})}): \mathbb{N}_{0} \times \Omega \rightarrow \mathbb{R}^{\mathfrak{d}}$ such that for all $n \in \mathbb{N}$, $i \in\{1,2, \ldots, \mathfrak{d}\}$ it holds that

$$\Theta_{0} \equiv \xi \text{, } \mathbb{M}_{0} \equiv 0 \text{,} \qquad \qquad \qquad(7.144)$$

$$\mathbb{M}_{n}^{(i)} = \beta_{n} \mathbb{M}_{n-1}^{(i)} + \left(1 - \beta_{n}\right)\left[\frac{1}{J_{n}} \sum_{j = 1}^{J_{n}} \vartheta_{i}(\Theta_{n-1}, X_{n, j})\right]^{2} \text{,} \qquad \qquad(7.145)$$

and $\Theta_{n}^{(i)} = \Theta_{n-1}^{(i)} - \gamma_{n}\left[\varepsilon + \left[\left(\frac{\mathbb{M}_{n}^{(i)}}{(1 - \prod_{l = 1}^{n} \beta_{l})}\right)\right]^{1/2}\right]^{-1}\left[\frac{1}{J_{n}} \sum_{j = 1}^{J_{n}} \vartheta_{i}(\Theta_{n-1}, X_{n, j})\right]$ . $\qquad(7.146)$

# 7.8 Adadelta SGD optimization

In this section we introduce the stochastic version of the Adadelta GD optimization method from Section 6.7 (cf. Zeiler [429]).

**Definition 7.8.1** (Adadelta SGD optimization method). Let $\vartheta \in \mathbb{N}$, $(J_n)_{n \in \mathbb{N}} \subseteq \mathbb{N}$, $(\beta_n)_{n \in \mathbb{N}} \subseteq [0, 1]$, $(\delta_n)_{n \in \mathbb{N}} \subseteq [0, 1]$, $\varepsilon \in (0, \infty)$, let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space, let $(S, \mathcal{S})$ be a measurable space, let $\xi: \Omega \rightarrow \mathbb{R}^p$ be a random variable, for every $n \in \mathbb{N}$, $j \in \{1, 2, \dots, J_n\}$ let $X_{n,j}: \Omega \rightarrow S$ be a random variable, and let $\ell = (\ell(\theta, x))_{(\theta, x) \in \mathbb{R}^p \times S}: \mathbb{R}^p \times S \rightarrow \mathbb{R}$ and $\boldsymbol{g} = (\boldsymbol{g}_1, \dots, \boldsymbol{g}_q): \mathbb{R}^p \times S \rightarrow \mathbb{R}^q$ satisfy for all $U \in \{V \subseteq \mathbb{R}^p: V$ is open\}, $x \in S$, $\theta \in U$ with $(U \ni \vartheta \mapsto \ell(\vartheta, x) \in \mathbb{R}) \in C^1(U, \mathbb{R})$ that

$$\boldsymbol{g}(\theta, x) = (\nabla_{\theta} \ell^i)(\theta, x). \tag{7.147}$$

Then we say that $\Theta$ is the *Adadelta SGD* process on $(\Omega, \mathcal{F}, \mathbb{P}), (S, \mathcal{S})$ for the loss function $\ell$ with generalized gradient $\boldsymbol{\mathcal{G}}$, batch sizes $(J_n)_{n \in \mathbb{N}}$, second moment decay factors $(\beta_n)_{n \in \mathbb{N}}$, delta decay factors $(\delta_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(\boldsymbol{X}_{n,j})_{(n, j) \in \{\kappa_0\} \in \mathbb{N}^2: 1 \leq j \leq J_k}$ (we say that $\Theta$ is the *Adadelta SGD* process for the loss function $\ell$ with batch sizes $(J_n)_{n \in \mathbb{N}}$, second moment decay factors $(\beta_n)_{n \in \mathbb{N}}$, delta decay factors $(\delta_n)_{n \in \mathbb{N}}$, regularizing factor $\varepsilon$, initial value $\boldsymbol{\xi}$, and data $(\boldsymbol{X}_{n,j})_{(n, j) \in \{\kappa_0\} \in \mathbb{N}^2: 1 \leq j \leq J_k}$) if and only if it holds that $\Theta = (\Theta^{(1)}, \ldots, \Theta^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ is the function from $\mathbb{N}_0 \times \Omega$ to $\mathbb{R}^3$ which satisfies that there exist $\mathbb{M} = (\mathbb{M}^{(1)}, \ldots, \mathbb{M}^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ and $\Delta = (\Delta^{(1)}, \ldots, \Delta^{(3)}): \mathbb{N}_0 \times \Omega \to \mathbb{R}^3$ such that for all $n \in \mathbb{N}$, $i \in \{1, 2, \ldots, \boldsymbol{d}\}$ it holds that

$\Theta_0 = \boldsymbol{\xi}, \quad \mathbb{M}_0 = 0, \quad \Delta_0 = 0, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (7.148)$

$\mathbb{M}_n^{(i)} = \beta_n \mathbb{M}_{n-1}^{(i)} + (1 - \beta_n) \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{\mathcal{G}}_i(\Theta_{n-1}, \boldsymbol{X}_{n,j}) \right]^2, \qquad\qquad (7.149)$

$\Theta_n^{(i)} = \Theta_{n-1}^{(i)} - \left( \frac{\varepsilon + \Delta_{n-1}^{(i)}}{\varepsilon + \mathbb{M}_n^{(i)}} \right)^{1/2} \left[ \frac{1}{J_n} \sum_{j=1}^{J_n} \boldsymbol{\mathcal{G}}_i(\Theta_{n-1}, \boldsymbol{X}_{n,j}) \right], \qquad (7.150)$

$\text{and} \qquad \Delta_n^{(i)} = \delta_n \Delta_{n-1}^{(i)} + (1 - \delta_n) |\Theta_n^{(i)} - \Theta_{n-1}^{(i)}|^2. \qquad\qquad\qquad\qquad\qquad\qquad\qquad (7.151)$
