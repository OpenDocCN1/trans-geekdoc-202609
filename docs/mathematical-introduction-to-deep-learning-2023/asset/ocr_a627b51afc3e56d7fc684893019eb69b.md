```
(ℒ_{k,ℛ₂●ℛ₃}, Ĥ_{k,ℛ₂●ℛ₃})
∌
```

This, (2.36), and (2.33) establish that for all k ∈ {1, 2, . . . , L(ℛ₁) + L(ℛ₂) + L(ℛ₃) - 2} it holds that

```
(ℒ_{k,(ℛ₁●ℛ₂)●ℛ₃}, Ĥ_{k,(ℛ₁●ℛ₂)●ℛ₃}) = (ℒ_{k,ℛ₁●(ℛ₂●ℛ₃)}, Ĥ_{k,ℛ₁●(ℛ₂●ℛ₃)}). △.38
```

Hence, we obtain that

```
(ℛ₁ ● ℛ₂) ● ℛ₃ = ℛ₁ ● (ℛ₂ ● ℛ₃). △.39
```

The proof of Lemma 2.1.4 is thus complete.
