Proof of Lemma 4.3.10. Throughout this proof, assume without loss of generality that $q < \infty$, let $e_{1}, e_{2}, \ldots, e_{d} \in \mathbb{R}^{d}$ satisfy $e_{1} = (1, 0, \ldots, 0)$, $e_{2} = (0, 1, 0, \ldots, 0)$, $\ldots$, $e_{d} = (0, \ldots, 0, 1)$, let $r \in \mathbb{R}$ satisfy

```
r = p^{-1}q, (4.126)
```

and let $x = (x_{1}, \ldots, x_{d})$, $y = (y_{1}, \ldots, y_{d}) \in \mathbb{R}^{d}$ satisfy for all $i \in \{1, 2, \ldots, d\}$ that

```
y_{i} = |x_{i}|^{p}. (4.127)
```

Observe that (4.127), the fact that

```
y = \sum_{i=1}^{d} y_{i} e_{i}, (4.128)
```

and the fact that for all $v, w \in \mathbb{R}^{d}$ it holds that

```
\|v + w\|_{r} \leq \|v\|_{r} + \|w\|_{r} (4.129)
```

(cf. Definition 3.3.4) ensures that

```
\|x\|_{q} = \left[\sum_{i=1}^{d} |x_{i}|^{q}\right]^{1/q} = \left[\sum_{i=1}^{d} |x_{i}|^{pr}\right]^{1/q} = \left[\sum_{i=1}^{d} |y_{i}|^{r}\right]^{1/q} = \left[\sum_{i=1}^{d} |y_{i}|^{r}\right]^{1/(pr)} = \|y\|_{r}^{1/p} \newline = \left\|\sum_{i=1}^{d} y_{i} e_{i}\right\|_{r}^{1/p} \leq \left[\sum_{i=1}^{d} \|y_{i} e_{i}\|_{r}\right]^{1/p} = \left[\sum_{i=1}^{d} \|y_{i}\| \|e_{i}\|_{r}\right]^{1/p} = \left[\sum_{i=1}^{d} |y_{i}|\right]^{1/p} \newline = \|y\|_{1}^{1/p} = \|x\|_{p}. (4.130)
```

This establishes (4.125). The proof of Lemma 4.3.10 is thus complete.

Corollary 4.3.11 (Implicit multi-dimensional ANN approximations with prescribed error tolerances and asymptotic parameter bounds). Let $d \in \mathbb{N}$, $L$, $a \in \mathbb{R}$, $b \in [a, \infty)$ and let $f : [a, b]^{d} \rightarrow \mathbb{R}$ satisfy for all $x, y \in [a, b]^{d}$ that

```
|f(x) - f(y)| \leq L \|x - y\|_{1} (4.131)
```

(cf. Definition 3.3.4). Then there exist $\mathfrak{C} \in \mathbb{R}$ such that for all $\varepsilon \in (0, 1]$ there exists $\mathbf{F} \in \mathbf{N}$ such that

```
\mathcal{R}_{\varepsilon}^{\mathbf{N}}(\mathbf{F}) \in C([a, b]^{d}, \mathbb{R}), \quad \sup_{x \in [a, b]^{d}} (\mathcal{R}_{\varepsilon}^{\mathbf{N}}(\mathbf{F}))(x) - f(x)) \leq \varepsilon, \quad and \quad \mathcal{P}(\mathbf{F}) \leq \mathfrak{C} \varepsilon^{-2d} (4.132)
```

(cf. Definitions 1.2.4, 1.3.1, and 1.3.4).
