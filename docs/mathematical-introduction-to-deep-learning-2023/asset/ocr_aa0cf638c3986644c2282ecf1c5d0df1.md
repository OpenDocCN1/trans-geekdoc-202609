# 1.2. Activation functions

**Definition 1.2.26** (Multidimensional hyperbolic tangent activation functions). Let \(d \in \mathbb{N}\). Then we say that \(A\) is the *d*-dimensional hyperbolic tangent activation function if and only if \(A = \mathfrak{M}_{\tanh,d}\) (cf. Definitions 1.2.1 and 1.2.25).

**Lemma 1.2.27**. Let *a* be the standard logistic activation function (cf. Definition 1.2.18). Then it holds for all \(x \in \mathbb{R}\) that

\[
	anh(x) = 2a(2x) - 1 	ag{1.63}
\]

*(cf. Definitions 1.2.18 and 1.2.25).*

**Proof of Lemma 1.2.27**. Observe that (1.52) and (1.62) ensure that for all \(x \in \mathbb{R}\) it holds that

\[
\begin{align}
2a(2x) - 1 & = 2 \left( \frac{\exp(2x)}{\exp(2x)+1} \right) - 1 = \frac{2\exp(2x) - (\exp(2x)+1)}{\exp(2x)+1} \\
& = \frac{\exp(2x)-1}{\exp(2x)+1} = \frac{\exp(x)(\exp(x)-\exp(-x))}{\exp(x)(\exp(x)+\exp(-x))} \\
& = \frac{\exp(x)-\exp(-x)}{\exp(x)+\exp(-x)} = \tanh(x). \tag{1.64}
\end{align}
\]

The proof of Lemma 1.2.27 is thus complete.

# 1.2.10 Softsign activation

**Definition 1.2.28** (Softsign activation function). *We say that* *a* *is the softsign activation function if and only if it holds that* \(a \colon \mathbb{R} \rightarrow \mathbb{R}\) *is the function from* \(\mathbb{R}\) *to* \(\mathbb{R}\) *which satisfies for all* \(x \in \mathbb{R}\) *that*

\[
a(x) = \frac{x}{|x|+1}. \tag{1.66}
\]
