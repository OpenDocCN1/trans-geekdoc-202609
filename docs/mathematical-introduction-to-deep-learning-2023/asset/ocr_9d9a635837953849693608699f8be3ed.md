This demonstrates that for all $t \in [0, \tau)$ it holds that

```
L(t) \leq \mathfrak{D}\left[\mathbf{L}\left(t_{0}\right)^{-1}+t\right]^{-1}=\mathfrak{C}^{2} \mathfrak{c}^{2-2 \alpha}\left(\mathfrak{C}^{2} \mathfrak{c}^{1-2 \alpha}+t\right)^{-1}=\mathfrak{C}^{2} \mathfrak{c}^{2}\left(\mathfrak{C}^{2} \mathfrak{c}+\mathfrak{c}^{2 \alpha} t\right)^{-1} . \quad (9.154)
```

The fact that for all $t \in[\tau, \infty)$ it holds that $\mathbf{L}(t)=0$ and (9.131) hence ensure that for all $t \in[0, \infty)$ it holds that

```
0 \leq \mathbf{L}(t) \leq \mathfrak{C}^{2} \mathfrak{c}^{2}\left(\|_{(0)}\right)(\epsilon)+\mathfrak{C}^{2} \mathfrak{c}+\mathfrak{c}^{2 \alpha} t\right)^{-1} . \quad(9.155)
```

Moreover, observe that (9.147) and the assumption that $\mathcal{L} \in C\left(\mathbb{R}^{\mathfrak{D}}, \mathbb{R}\right)$ prove that $\limsup _{t \rightarrow \infty}\left|\mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\vartheta)\right| =0$. Combining this with (9.155) establishes that $\mathcal{L}\left(\psi\right)=\mathcal{L}(\vartheta)$. This and (9.155) show that for all $t \in[0, \infty)$ it holds that

```
0 \leq \mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\psi) \leq \mathfrak{C}^{2} \mathfrak{c}^{2}\left(\|_{(0)}\right)(\epsilon)+\mathfrak{C}^{2} \mathfrak{c}+\mathfrak{c}^{2 \alpha} t\right)^{-1} . \quad(9.156)
```

In the final step of our proof of items (i), (ii), (iii), and (iv) we establish convergence rates for the real numbers $\|\Theta_{t}-\psi\|_{2}$, $t \in[0, \infty)$. Note that (9.147), (9.146), and (9.142) imply that for all $t \in[0, \infty)$ it holds that

```
\left\|\Theta_{t}-\psi\right\|_{2}=\left\|\Theta_{t}-\left[\lim _{s \rightarrow \infty} \Theta_{s}\right]\right\|_{2}=\lim _{s \rightarrow \infty}\left\|\Theta_{t}-\Theta_{s}\right\|_{2} \leq \mathcal{G}_{t} \leq \mathfrak{C}(1-\alpha)^{-1}[L(t)]^{-1-\alpha} . \quad(9.157)
```

This and (9.156) demonstrate that for all $t \in[0, \infty)$ it holds that

```
\begin{aligned}

& \left\|\Theta_{t}-\psi\right\|_{2} \leq \mathcal{G}_{t} \leq \mathfrak{C}(1-\alpha)^{-1}\left[\mathcal{L}\left(\Theta_{t}\right)-\mathcal{L}(\psi)\right]^{-1} \alpha \\
& \quad \leq \mathfrak{C}(1-\alpha)^{-1}\left[\mathfrak{C}^{2} \mathfrak{c}^{2}\left(\|_{(0)}\right)(\epsilon)+\mathfrak{C}^{2} \mathfrak{c}+\mathfrak{c}^{2 \alpha} t\right]^{-1-\alpha} \\

& \quad =\mathfrak{C}^{3-2 \alpha} \mathfrak{c}^{2-2 \alpha}\left(1-\alpha\right)^{-1}\left(\|_{(0)}\right)(\epsilon)+\mathfrak{C}^{2} \mathfrak{c}+\mathfrak{c}^{2 \alpha} t\right) \alpha^{-1} . \quad(9.158)

\end{aligned}
```

Combining this with (9.132) and (9.156) proves items (i), (ii), (iii), and (iv). The proof of Proposition 9.11.2 is thus complete.
