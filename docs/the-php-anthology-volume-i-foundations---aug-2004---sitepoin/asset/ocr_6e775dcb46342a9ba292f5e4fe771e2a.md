```
function suffix($num)
{
    if ($num < 11 || $num > 13) {
        $desc = array(0 => 'st', 1 => 'nd', 2 => 'rd',
                      4 => 'th', 5 => 'th', 6 => 'th', 7 => 'th',
                      8 => 'th', 9 => 'th');
        return $desc[$num % 10];
    } else {
        return 'th';
    }
}
```

Note that the numbers 11, 12, and 13 are special cases in the English language, and are treated as such by the code above.
