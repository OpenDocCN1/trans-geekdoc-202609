
Next, we use ftp_chdir to change directory. It's important when using FTP to remember that the root directory for the FTP-related operations will be the directory in which you started when you logged into the server, not the true root directory of the server. So be sure to specify an absolute path when appropriate.

To show that we're in the right place, we use ftp_pwd to display the present working directory. The ftp_nlist function returns an array of files from the current directory, which we can then display.
