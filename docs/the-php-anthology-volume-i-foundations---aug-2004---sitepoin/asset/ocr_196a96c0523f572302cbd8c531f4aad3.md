You have the option of using `fetch` to iterate through the extracted path variables, or you can use `fetchByIndex`, which returns the variable for which you supplied the index. You can also use `size` to find out how many variables the object has found. Finally, `fetchAll` can be used to return the complete array of path variables. # Hiding PHP Scripts with ForceType

Having successfully moved query string variables to the URL suffix, all we need to do to achieve search-engine friendly URLs is to hide the filename of the PHP script. That is, we want to transition from http://www.example.com/article.php/123/4 to http://www.example.com/article/123/4. There are actually two distinct ways to do this; in this section I'll explain the most straightforward of the two, and I'll cover the second method in the next. As with the method for reading URL suffixes, both techniques rely on useful features of the Apache Web server.
