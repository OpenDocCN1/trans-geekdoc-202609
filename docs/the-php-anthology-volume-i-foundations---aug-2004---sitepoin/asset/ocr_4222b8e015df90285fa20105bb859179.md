As of PHP 4.3, a new function called file_get_contents reads a file straight into a string without breaking it up. For example:

```
<?php
// Read file into a string
$file = file_get_contents('demo/writeSecureScripts.html');

// Strip the HTML tags from the file
$file = strip_tags($file);
?>
```
