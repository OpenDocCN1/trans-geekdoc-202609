Now we can modify the query to use a LIMIT clause generated by the pager:

```
// Basic SQL statement
$sql = "SELECT * FROM user";

// A switch to allow sorting by column
switch (@$_GET['sort']) {
    case 'login':
    $sql .= " ORDER BY login ASC";
    break;
    case 'email':
    $sql .= " ORDER BY email ASC";
    break;
    default:
    $sql .= " ORDER BY lastName, firstName ASC";
    break;
}

// Add the LIMIT clause
$sql .= " LIMIT " . $pager->getStartRow() . ", " .
    $pager->getRowsPerPage();
```
