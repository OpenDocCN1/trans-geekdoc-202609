Let’s see how it works with a simple example. We’ll repeat the above user list and add some attractive visuals. First, having included the HTML_Table class, we’ll build a switch statement that allows us to order the results by a particular column:

```

// Include the PEAR::HTML_Table class
require_once "HTML/Table.php";

$db = &new MySQL($dbHost, $dbUser, $dbPass, $dbName);

// Basic SQL statement
$sql = "SELECT * FROM user";

// A switch to allow sorting by column
switch (@$_GET['sort']) {
case 'login':
$sql .= " ORDER BY login ASC";
break;
case 'email':
$sql .= " ORDER BY email ASC";
break;
default:
$sql .= " ORDER BY lastName, firstName";
break;
}
```
