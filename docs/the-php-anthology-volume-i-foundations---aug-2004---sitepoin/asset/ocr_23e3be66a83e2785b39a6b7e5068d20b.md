The Day class comes with the methods isFirst and isLast, which allow you to identify Days that have been constructed by buildWeekDays and fall at the beginning or end of a week, respectively.

The isEmpty method allows us to identify “empty” days, as discussed above. Should we find one, all we want to display is an empty table cell. If the day isn’t empty, we must check to see if it’s a “selected” day, for which we used the isSelected method.
