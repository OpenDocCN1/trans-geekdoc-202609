

# 经济危机的后续影响

经济危机的后续影响包括人们对现有金融体系失去信心，导致大规模从银行提款。这促成了比特币的演变 [[5](#C_009_c4.xhtml#r4_5)]。它由一名叫中本聪的人于 2008 年发明，旨在作为比特币的社区交易或业务注册系统。比特币通常称为 `BTC` [[6](#C_009_c4.xhtml#r4_6)]，其本质完全是数字化的，运作方式类似于任何独立货币。它是一种开源的 P2P 货币，数据同时存储在多个节点上 [[7](#C_009_c4.xhtml#r4_7)]。由于交易是匿名的，它提供了高度的隐私保护。它具有不可篡改、成本更低、安全和通货紧缩的特性。它也是法币性质的，因为它不由有形物质作担保 [[8](#C_009_c4.xhtml#r4_8)]。本文介绍了一些机器学习和深度学习算法 [[9](#C_009_c4.xhtml#r4_9)] 的概念，用于处理比特币数据集，从而提出比特币价格和趋势的时间预测。对于时间序列预测，可以使用两类算法：(1) 白箱算法，如 `Auto Regressive Integrated Moving Average (ARIMA)` [[10](#C_009_c4.xhtml#r4_10)]、`ARMA` 和 `AR`；(2) 黑箱算法，如 `long short-term memory (LSTM)` [[11](#C_009_c4.xhtml#r4_11)]、`Recurrent Neural Network (RNN)`、`CNN` 和 `NNETAR`，以及一些监督学习概念，如 `support vector machine` [[12](#C_009_c4.xhtml#r4_12)]。时间序列可以用不同的模型进行预测。其中一些模型如下：`Naïve`、`Seasonal decomposition (+ any model)`、`ARIMA`、`GARCH`、`Prophet`、`NNETAR` 和 `LSTM`。

使用 `K-means clustering` [[13](#C_009_c4.xhtml#r4_13)] 预测数据集中的异常数量，旨在检测比特币交易过程中的异常。由于区块链是一个数字化过程，它极易受到虚假交易和异常的影响 [[14](#C_009_c4.xhtml#r4_14)]。为克服这种情况，首先应预测交易中异常发生的几率和领域。`Blockchain anomaly detection` [[15](#C_009_c4.xhtml#r4_15)] 有助于构建标准行为模型，然后对新数据集（测试数据）进行预测，以判断其与该基准模型的偏离程度。区块链技术的核心概念蕴含于两个主要组件中：`Hash Tree` 和 `Timestamp`。`Merkle Tree (Hash Tree)`：由 R. Merkle 于 1979 年提出。叶子节点的顶点由数据的哈希标记，非叶子节点的顶点由标签及其子节点的解码哈希标记。如果我们更改数据或哈希，将导致与根哈希不匹配。因此，它非常难以被篡改 [[16](#C_009_c4.xhtml#r4_16)]。

本文介绍了一种综合方法，利用各种机器学习算法预测比特币过程中时间序列的性质，并自动识别区块链系统中的异常。在当前数据集中，比特币的加权价格和交易量处发生异常的几率较高；因此，在对时间戳进行日期时间转换后，我们分别绘制了比特币加权价格和交易量随时间戳变化的图表。此外，本文还讨论了实施过程中的各种挑战性结果及可能的解决方案。本工作的主要贡献总结如下。

*   系统详细地研究了 `ARIMA`、`LSTM` 和 `XGBoost` 等机器学习算法。
*   本工作展示了使用 `ARIMA`、`LSTM` 和 `XGBoost` 进行比特币趋势预测。此外，输出图表显示 `ARIMA` 模型产生的预测趋势优于其他模型。
*   还通过使用 `K-means clustering` 的实施程序研究了异常检测。此处，利用时间戳概念来防止篡改，并避免在任何情况下出现单点故障。
*   展示了比特币加权价格和交易量随时间戳变化的图表。

## 4.2 背景

比特币是一种加密货币，用于在线交换数字资产。区块链是数字加密货币比特币的支柱。它是一个分布式软件网络，服务于两大核心功能 [[17](#C_009_c4.xhtml#r4_17)]。第一是作为数字账本，第二是一种无需中介即可安全转移资产的机制。许多人混淆了区块链和比特币的概念。区块链是一项技术，而 `Ethereum` [[18](#C_009_c4.xhtml#r4_18)]、比特币和 Neo 是其协议。`Ethereum` 是一个构建了货币和支付系统（称为加密货币）的互联网。其他应用既不会窃取你的数据，也无法监视你。它为每个人提供了一个可访问的经济系统。它于 2015 年提出概念，至今仍是世界领先的计算化区块链。`Ether` 是 `Ethereum` 的原生货币，在许多方面与比特币相似。许多去中心化应用构建于 `Ethereum` 之上，这意味着没有单一实体可以控制它。[图 4.1](#C_009_c4.xhtml#f4_1) 展示了区块链与比特币及 `Ethereum` 的区别。

![图 4.1 区块链与比特币的区别。](images/Fig04_01.jpg)

**图 4.1** 区块链与比特币的区别。

简单来说，区块链是一种 `P2P (Peer to Peer)` 即对等网络账本数据结构。该数据结构的内容是区块，例如比特币交易。该数据结构还有一个区块头，包含关于区块的数据、前一个区块的引用以及一个指纹（称为哈希），用于引用下一个区块。区块的指纹用于引用目标区块 [[19](#C_009_c4.xhtml#r4_19)]。这些区块指纹通过算法生成，用于验证数据。每笔交易都由 51% 多数派验证。每个参与者都拥有数据库的完整版本。部分区块链领域的顶级投资者如下：`Mitsubishi UFJ Capital`、`Andreessen Horowitz`、`Greylock partners`、`Xapo`、`Ripple labs`、`Coinbase` 等。[表 4.1](#C_009_c4.xhtml#t4_1) 展示了 `Cascading Style Sheets (CSS) System`（客户端-服务器系统）与 `P2P System` 的对比。

**表 4.1** CSS 系统与 P2P 系统的区别 [[20](#C_009_c4.xhtml#r4_20)]

| 标准 | 客户端-服务器系统 | P2P 系统 |
| --- | --- | --- |
| 定义 | 多个客户端连接到一台服务器 | 每个节点可随时成为客户端或服务器 |
| 服务提供 | 客户端向服务器请求服务 | 每个节点均可请求或提供服务 |
| 关注点 | 信息共享 | 互联互通 |
| 数据存储 | 集中式 | 存储在每个对等节点上 |
| 服务器请求处理 | 请求过多时成为瓶颈和单点故障 | 不适用 |
| 成本 | 高端服务器，昂贵且可扩展 | 由物联链构成，因此更便宜 |

### 4.2.1 ARIMA
