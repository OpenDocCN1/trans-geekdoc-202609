

# 4.2 时间序列预测模型

## 4.2.1 ARIMA

ARIMA 代表一类原型，能够捕捉时间序列统计中一套不同的常规时间配置 [[21](#C_009_c4.xhtml#r4_21)]。模型的本质或内在性质由其自身捕获。`AR` 代表自回归，一种利用实际观测值与少数滞后观测值之间依赖关系的模型。`I` 代表整合，即利用实际原始观测值的差分（如用后一观测值减去前一观测值）使时间序列平稳。`MA` 代表移动平均，一种利用观测值与移动平均模型的残余误差之间的关联，并进一步应用滞后观测值的模型。在 Python 中，基于 ARIMA 的预测原型可以利用 `Auto ARIMA` (Pyramid ARIMA) 或 `Stats Model` 进行设计 [[22](#C_009_c4.xhtml#r4_22)]。模型进一步拟合到时间序列数据集中，以预测序列中的后续点。

## 4.2.2 RNN

RNN 是人工神经网络 (ANN) 的一种分类，其中顶点之间的依赖关系形成一条具有时间序列的有向轨迹，从而使其能够表现出时间动态性能 [[23](#C_009_c4.xhtml#r4_23)]。“循环神经网络”这一术语被随意用来指代两大类具有相同通用结构的网络，其中一类是有限脉冲，另一类是无限脉冲。这两类网络均表现出时间动态行为。有限脉冲循环网络也可以是一条有向无环轨迹，可以通过实际的前馈人工神经元网络展开并复原；而无限脉冲循环网络可能是一条有向环状轨迹，无法展开 [[24](#C_009_c4.xhtml#r4_24)]。本章中实现了 LSTM，它是 RNN 的一种分类。

## 4.2.3 Prophet

预测被用作战略制定者或企业的顾问，因此在塑造商业决策方面发挥着重要作用 [[25](#C_009_c4.xhtml#r4_25)]。Prophet 是一款用于商业预测的公共领域软件，由 Facebook 数据科学团队发布。它基于一种加法模型，其中非线性趋势被训练以拟合季节性。[图 4.2](#C_009_c4.xhtml#f4_2) 展示了 Prophet 模型。Prophet 的通用方程如下：

![FIGURE 4.2 Prophet model.](images/Fig04_02.jpg)

[**图 4.2**](#C_009_c4.xhtml#f4_2b) Prophet 模型。

```
z(t)=j(t)+r(t)+h(t) + €n(4.1)
```

`j(t)` 定义数据中长期增长或下降的模型趋势。根据预测问题的类型，Prophet 结合了两种趋势表示：饱和增长模型和分段线性模型。`r(t)` 描述数据集如何受季节性因素（如年份周期）影响，基本上它用傅里叶级数建模季节性。`h(t)` 对假期或大型事件的影响进行建模，这些事件可能对商业时间序列产生不利或有利影响，`€n` 代表不可约误差项。[表 4.2](#C_009_c4.xhtml#t4_2) 展示了各类时间序列预测之间的比较。

[**表 4.2**](#C_009_c4.xhtml#t4_2b) 各类时间序列预测的差异 [[26](#C_009_c4.xhtml#r4_26),[27](#C_009_c4.xhtml#r4_27)]

| 标准 | ARIMA | Prophet | RNN |
| --- | --- | --- | --- |
| 定义 | 基于回归分析工作。 | 基于加法模型的商业预测公共领域软件。 | 代表循环神经网络，是人工神经网络的一种分类。 |
| 基础 | 基于线性时间序列分析。 | 基于贝叶斯曲线拟合。 | 以前的观测值用作当前步骤的输入，描绘过去和当前观测值之间的关系。 |
| 用户 | 由受过训练的专业人员使用。 | 通常由非专业人士（非统计学家）使用。 | 因为是深度学习概念，所以由训练有素的专家使用。 |
| 优势 | 不需要调整超参数。 | 能高效识别复杂的季节性模式。 | 与 ARIMA 相比，能捕捉时间序列中更多的滞后阶数，本质也非常灵活。 |
| 后果/局限 | 需持续输入数据以进行进一步预测，且应使用平稳数据。 | 具有强随机成分的时间序列模型无法使用 Prophet 进行适当预测。 | 梯度消失和梯度爆炸问题。此外，训练时间较长。 |

## 4.2.4 聚类

聚类是最被广泛接受的探索性数据分析方法之一，用于获取对数据配置的直观理解 [[28](#C_009_c4.xhtml#r4_28)]。它可以描述为在数据集中识别子群，使得同一簇或子群中的数据点非常相似，而不同簇或子群中的数据点非常不相似。簇之间可以基于欧氏距离或相关距离来判定相似或不相似。`K-means` 聚类侧重于将 `t` 个观测值划分为 `K` 个簇。此处每个观测值仅属于一个具有最近平均值的簇。因此，数据空间被划分为 Voronoi 单元。

## 4.2.5 XGBoost

XGBoost 使用零值或前值填补缺失值。eXtreme Gradient Boosting 包的一些特性如下：速度与性能，因为它比其他集成分类器快得多。核心算法可并行化，因为它可以利用多核的力量。它始终表现出优于其他算法方法的性能。有多种调优参数，包括正则化、交叉验证、树参数、缺失值处理和 scikit-learn。XGBoost 属于提升算法家族，其核心使用梯度提升 (GBM) 框架。[图 4.3](#C_009_c4.xhtml#f4_3) 展示了 XGBoost 模型，[表 4.3](#C_009_c4.xhtml#t4_3) 展示了 XGBoost 模型与聚类的比较。
