

## XGBoost 模型

用于预测的另一个模型是 XGBoost，它使用梯度提升框架，并用前值或零填充缺失值。它基于集成技术工作。[表 4.5](#C_009_c4.xhtml#t4_5) 显示了 XGBoost 模型的步骤。

**表 4.5** XGBoost 模型步骤

1.  开始
2.  生成一组实际预测值作为 `Y[a]`。
3.  生成一组假设值作为 `Z[a]`。
4.  谬误 = `P(Y[a], Z[a])`
5.  均方误差可计算为
    `J() = Σ(Y[a] − Z[a])^2`
6.  识别观测值中的负梯度
7.  重复：
8.  持续尝试移动 `Z[a]` 以减少假设中的谬误。
    `Z[a] = Z[a] + γH[a]`
9.  `H[a]` 近似于 `▼P(Y[a], Z[a])`
10. 结束

### 4.4.3 异常检测

对于异常检测，可以使用许多机器学习算法，如孤立森林、K 近邻和 K 均值聚类。在本章中，实现了 K 均值聚类来查找比特币数据集中的异常。[表 4.6](#C_009_c4.xhtml#t4_6) 显示了用于异常检测的 K 均值聚类步骤。

**表 4.6** K 均值聚类模型步骤

1.  开始
2.  输入
    `Z` ← 要形成的聚类数量
    `R` ← 提升比例集合
3.  从 `R` 中随机选择 `Z` 个对象作为初始聚类中心
4.  重复：
    {
    4.1 根据配置的高度相似性，将每个条目分配到对应的聚类。
    4.2 计算各个聚类中条目的平均值。
    4.3 直到不再发生变化
    }
5.  结束
