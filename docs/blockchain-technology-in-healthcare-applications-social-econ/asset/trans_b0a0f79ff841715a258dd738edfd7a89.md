
通常，区块链可分为两类：公有链和私有链。在公有链中，用户可以加入无许可账本，即他们既拥有读取权限，也拥有写入权限[[19](#C_006_c1.xhtml#r1_19)]。参与者可以匿名，但安全性由有效的区块挖掘和公钥密码系统保障。尽管区块防篡改，但执行和交易速度比私有链慢[[20](#C_006_c1.xhtml#r1_20)]。另一方面，私有链限制参与者，仅允许选定的矿工进行读写。这里的去中心化概念略有妥协，但效率极高，同时确保了区块链的所有其他特性[[21](#C_006_c1.xhtml#r1_21)]。还有一种称为联盟链或混合链的区块链类型。它结合了公有链和私有链的条件，以满足预期结果。

## 1.2.2 特性

除了在加密货币中的应用，区块链因其特性还具有多功能应用，如：

*   **去中心化**：区块链确保没有单一实体或第三方组织能够控制网络。矿工需遵循共识算法挖掘区块，以确保交易经过认证[[22](#C_006_c1.xhtml#r1_22)]。

*   **不可篡改性**：一旦区块被添加到网络，没有人可以更改其中的信息或将其删除[[23](#C_006_c1.xhtml#r1_23)]。

*   **匿名性**：即使所有矿工都拥有每个区块的副本，除持有密钥者外，数据也无法被提取[[24](#C_006_c1.xhtml#r1_24)]。此外，参与交易的个人信息对所有人也是未知的，因为他们每次都会使用生成的地址。

*   **可审计性**：通过哈希函数，每个区块将包含前一个区块的信息[[25](#C_006_c1.xhtml#r1_25)]。因此，透明度和可审计性将得以维持。

*   **安全性与隐私**：区块链最重要的特性是提供高度的安全性和隐私。公钥密码系统、共识协议、数字签名、点对点网络的使用，以及以太坊等最新技术的加入，使区块链在抵御恶意活动和网络攻击方面更加强健[[26](#C_006_c1.xhtml#r1_26)]。

## 1.2.3 交易流程

1.  **请求交易**：用户使用私钥加密数据，生成唯一哈希值及数字签名，并请求将其添加到点对点网络[[27](#C_006_c1.xhtml#r1_27)]。

2.  **认证交易**：使用公钥密码学对交易进行认证，网络验证该请求。

3.  **区块验证**：使用真实的哈希值、随机数、时间戳等，矿工对区块进行验证，并考虑将其追加到网络。

4.  **添加至区块链**：最后，区块被组装进区块链网络，遵循 PoW 或 PoS 等共识协议。此后该区块不可移除、不可更改[[28](#C_006_c1.xhtml#r1_28)]。

## 1.3 物联网基础

物联网不断扩展其关联传感器和设备的领域，使系统比以往任何时候都更复杂。因此，为了高效发挥物联网的效益，提出了不同的物联网架构[[29](#C_006_c1.xhtml#r1_29)]。考虑到区块链和物联网日益增长的工业用途和应用，我们将讨论日益流行的五层架构方法。五层架构包括：

1.  物体层
2.  网络层
3.  服务管理层
4.  应用层
5.  业务层

### 1.3.1 物体层

物体层或感知层作为数据收集和处理层工作。它利用物联网传感器和设备收集湿度、位置、温度、振动和重量等信息[[30](#C_006_c1.xhtml#r1_30)]。随后，数据被传输至网络层以建立通信过程。该层使用安全通道并传输大数据。

### 1.3.2 网络层

网络层或对象抽象层用于将收集的信息从物体层传输到服务管理层。它利用 GSM、RFID、Wi-Fi、WiMAX、3G、4G、卫星、蓝牙和红外等技术传输数据[[31](#C_006_c1.xhtml#r1_31)]。此外，数据管理和云计算等任务也由该层维护[[32](#C_006_c1.xhtml#r1_32)]。

### 1.3.3 服务管理层

服务管理层或中间件层的目的是连接不同类型物联网设备之间的服务。设备携带其地址和名称创建请求，中间件层管理服务请求并存储来自下层的信息。该层还参与决策制定，并将计算结果传递给设备[[33](#C_006_c1.xhtml#r1_33)]。

### 1.3.4 应用层

应用层直接与用户连接。它将来自前几层生成或收集的信息（如温度或湿度）传递给最终客户[[34](#C_006_c1.xhtml#r1_34)]。该层的例子包括智能家居、智能交通、智能治理和智能识别。

### 1.3.5 业务层

业务层或管理层代表系统的聚合性能或分析。它可以根据接收和传输的数据生成图表、流程图或模型。因此，它提供了架构中所用各层和设备的完整效率。此外，通过比较各层预期输出与实际输出，它还可以提升性能[[35](#C_006_c1.xhtml#r1_35)]。

其他提出的物联网架构（如三层模型或中间件模型）在某些情况下也很有效。然而，并非所有层都能利用所有类型的技术和数据传输过程。例如，基于 SOA 的架构有一个服务组合层，在数据执行和传输上耗时较多[[36](#C_006_c1.xhtml#r1_36)]。另一方面，这种五层模型可以生成架构分析，并倾向于提升性能。业务层可以使用大量数据并在强大设备上执行复杂计算。因此，为满足当前对大数据和更快传输的需求，五层模型是首选架构之一。

### 1.3.6 物联网组件

通常，物联网系统由五个主要组件构成[[37](#C_006_c1.xhtml#r1_37)]：

1.  **传感器**：物联网系统使用许多传感器来识别、收集和传输数据。根据数据的多样性，存在不同类型的传感器。

2.  **计算**：包含处理器的节点用于处理传感器收集的信息。这些节点用于执行特定计算，以进一步保护和传输接收到的数据。

3.  **接收器**：它像收发器一样工作，将消息从一个节点传输到另一个节点。它通常连接本地和远程节点，并收集其计算数据。

4.  **激活器**：根据从前序组件接收和计算的数据，为请求的服务生成信号。物联网设备的功能被激活以触发目标设备。

5.  **设备**：触发功能后，连接到物联网系统的设备执行期望的功能。
