

## 拒绝睡眠攻击

拒绝睡眠攻击针对的是以电池作为工作电源的设备 [[52](#C_020_c15.xhtml#r15_52)]。这些电池的续航时间有限；耗尽后需要充电。当电池充电时，设备会进入睡眠模式。该攻击阻止设备切换到睡眠模式，从而导致设备永久关机。

## 15.4.2 基于策略检查的漏洞与攻击

策略在最大程度减少由弱密码、弱认证机制、弱互联网协议 (IP) 扫描和过滤机制触发的攻击方面发挥着重要作用。以下要点详细解释了这些参数。

*   **用户认证** 是医疗 4.0 中至关重要的一环，因为其涉及个人性质的数据。用户可以确保其身份得到安全认证，尤其是在医疗领域。医疗数据由医护人员、患者和其他工作人员访问。这要求在危急情况下保证用户能紧急访问数据。确保用户认证的方法是使用生物识别安全技术，这是验证用户身份最高效的机制之一。它可以在医疗 4.0 中得到有效应用。此外，生物识别数据可以从医疗领域或医疗部门使用的设备中获取 [[53](#C_020_c15.xhtml#r15_53)]。密码管理系统应在策略中得到周全考虑，以便限制通过暴力破解和其他社会工程学攻击绕过认证。

*   **设备认证** 是另一个关键参数，即个人设备或服务器在从传感器接收医疗数据前，需要验证身份 [[54](#C_020_c15.xhtml#r15_54)]。这至关重要，因为错误的数据或任何通信故障在监测和诊断患者健康时可能导致严重问题。因此，在医疗 4.0 中，认证方法应以高度安全的方式实施，并能确保个人医疗数据的完整性和机密性。在医疗 4.0 中，不应留有任何数据被篡改的可能性，以防止医疗部门医护人员、患者和工作人员的个人信息泄露。

## 15.4.3 传感器、物理漏洞与攻击

在医疗 4.0 中，保护医疗数据是最高优先级的任务。因此，数据获取的源头必须是安全的。传感器负责数据收集。因此，在传感器层面实施安全至关重要。可能的安全措施强调在个人设备上执行最大量的计算，并在数据交换过程中减少开销。以下是建立传感器级安全的解决方案。

*   **传感器** 由于是物理实体，面临被对手窃取和篡改的风险。这在实施医疗 4.0 时对医疗部门构成威胁。因此，设计一个防篡改系统，不允许任何第三方访问医疗数据，显得尤为重要。

*   **定位** 是传感器安全的另一个因素 [[55](#C_020_c15.xhtml#r15_55)]，即识别传感器在人体上的位置。然而，识别传感器在人体上的位置对医护人员至关重要，因此无法省略。在这样的场景下，设备可能会频繁偏离网络范围。解决定位问题的一个方案是设计一个实时系统，以检测医疗 4.0 网络中的入侵，能够高效上报恶意活动并提醒用户。

*   安全也可以通过 **自愈方法** 来保障。自愈方法可以检测医疗 4.0 网络中的攻击，并自行应用安全措施。然而，每种攻击的诊断方式可能不同；因此，自愈方法应据此设计 [[56](#C_020_c15.xhtml#r15_56)]。

*   医疗 4.0 包含 **空中下载技术** 用于更新医疗 4.0 网络中大量 IoT 节点 [[57](#C_020_c15.xhtml#r15_57)]。然而，这可能导致攻击者节点感知更新并冒充合法节点。因此，需要设计严格的安全机制，使医疗 4.0 网络中的任何恶意节点无法利用其他合法节点并影响医疗 4.0 系统。

*   由于传感器是物理设备，它们可能引入故障并在网络中表现异常，从而影响医疗 4.0 中的数据和通信。因此，确保数据传输前后的安全极为重要。即，需要妥善解决向后和向前兼容性问题 [[58](#C_020_c15.xhtml#r15_58)]。为此，可使用空中下载技术来分发相关更新。

## 15.5 利用区块链实现医疗 4.0 的隐私与安全

在当前形势下，患者记录和相关医疗数据已实现数字化，且数据量与日俱增。此外，数据分布在多个设备上，由云服务器提供支持，不再局限于单一设备。专用 IoT 设备和传感器负责收集和处理数据 [[59](#C_020_c15.xhtml#r15_59)]。此外，还有多个信息来源，如 **电子健康记录 (EHRs)**，用于向所需用户提供医疗信息 [[60](#C_020_c15.xhtml#r15_60)]。大量患者数据集包含敏感和个人信息。因此，确保医疗领域的隐私和安全至关重要，且相关方法需要得到有效实施。保障医疗数据安全的合适方法之一是使用 **区块链**。区块链支持不可篡改性和信息可辨识性。然而，如果结合加密方法，区块链可以在网络中为医疗数据提供更强的安全性和一致性 [[61](#C_020_c15.xhtml#r15_61)]。与区块链中数据保护相关的困难如下所述。

*   **身份安全**：保护患者或用户的身份及敏感信息。
*   **交易安全**：保障信息的安全交换，并确保经过授权和认证的交易（查看或修改数据）。
