

## 7.3.3 Android 应用程序

基于线性回归分类器开发了一款 Android 应用程序，用于根据用户输入预测 SBP 和 DBP。系数值从预训练模型中获取并用于血压估计。所提设计采用了 JAVA 平台，并在运行 Android 操作系统（KitKat，Google, Inc.）的 Moto E（Motorola, Inc.）智能手机上实现了该应用程序 [[17]](#C_012_c7.xhtml#r7_17)。

## 7.4 结果与讨论

156 名受试者的测量数据被顺序划分为 106 名受试者用于训练，50 名受试者作为未知测试集。50 名测试受试者的血压预测准确性如 [表 7.1](#C_012_c7.xhtml#t7_1) 所示。通过测量平均误差（ME）、平均绝对误差（MAE）、误差标准差（SDE）和均方根误差（RMSE）来观察性能。根据医疗仪器促进协会（AAMI）的标准，测试受试者的 ME 和 SDE 值必须分别低于 5 和 8 mmHg [[18]](#C_012_c7.xhtml#r7_18)。在 [表 7.1](#C_012_c7.xhtml#t7_1) 中，所提方法的 ME 值低于 AAMI 标准的可接受限值。就 SDE 标准而言，DBP 值在误差范围内，而根据获取的数据集，SBP 超出了可接受限值。

**表 7.1** 测试数据血压预测误差

| | ME | MAE | SDE | RMSE |
| --- | --- | --- | --- | --- |
| SBP | −1.5 | 9.36 | 11.5 | 11.49 |
| DBP | 1.94 | 4.9 | 6.48 | 6.7 |

[表 7.2](#C_012_c7.xhtml#t7_2) 还展示了关于英国高血压学会（BHS）标准 [[19]](#C_012_c7.xhtml#r7_19) 的准确性。BHS 标准考虑三个不同的阈值，即误差值小于 5、10 和 15 mmHg 进行分级。根据 BHS 协议，针对获取的数据集，所提方法对于 DBP 的估计可视为 B 级，对于 SBP 的估计可视为 C 级。

**表 7.2** SBP 和 DBP 测量的累积误差百分比

| | < 5 mmHg | < 10 mmHg | < 15 mmHg |
| --- | --- | --- | --- |
| SBP | 39.74 | 69.23 | 85.25 |
| DBP | 57.69 | 81.4 | 93.6 |

[图 7.3](#C_012_c7.xhtml#f7_3) 显示了 Bland-Altman 图的散点图，用于检查实际和预测血压值之间的差异。*y* 轴表示测量值和估计值之间的差异，而 *x* 轴显示这两种技术的平均值 [[20]](#C_012_c7.xhtml#r7_20)，[[21]](#C_012_c7.xhtml#r7_21)。Bland-Altman 图使用虚线包含了上下一致性限值的 95% 置信区间。

![图 7.3 误差值的 Bland-Altman 图。(a) 显示实际值和参考值平均值的 SBP 差异。(b) 显示实际值和参考值平均值的 DBP 差异。](images/Fig07_03.jpg)

**图 7.3** 误差值的 Bland-Altman 图。(a) 显示实际值和参考值平均值的 SBP 差异。(b) 显示实际值和参考值平均值的 DBP 差异。

从 Bland-Altman 图中可以明显看出存在来自偏差的趋势。误差差异随 DBP 测量幅度变宽，且预测高 DBP 值时比例误差也增加。对于 SBP，标准值存在中等趋势，且在预测高 SBP 值时绝对系统误差在减小。此外，实际值与预测值之间的相关性分别为 SBP 0.64 和 DBP 0.54。

根据此分析，发现 BMI 与 BP 之间存在显著正相关。BMI 的增减与 SBP 和 DBP 的变化显著相关。然而，BMI 对 BP 的确切影响仍不清楚。[表 7.3](#C_012_c7.xhtml#t7_3) 显示了预测 SBP 和 DBP 值的优势比（OR） [[22]](#C_012_c7.xhtml#r7_22)，[[23]](#C_012_c7.xhtml#r7_23)。就 SBP 而言，超重人群（BMI > 25 kg/m²）患高血压（SBP > 140 mmHg）的可能性是正常 BMI（18–25 kg/m²）人群的 7.3 倍，患高血压前期（SBP 120–140 mmHg）的可能性是正常人群的 3.82 倍。DBP 显示超重人群患高血压的可能性是正常人群的 6.3 倍，且低于高血压前期人群与正常 BMI 类别人群的对比。低体重人群（BMI < 18 kg/m²）与高血压和高血压前期均无关联。在一项额外分析中，BMI 对 60 岁及以上人群影响最强。SBP 的 OR 为高血压 11，高血压前期 1.86。对于 DBP 测量，高血压人群的 OR 为 8。特别是，BMI 异常升高的老年患者表现出向高血压发展的渐进倾向。

**表 7.3** SBP 和 DBP 的优势比预测

| | 高血压 | 高血压前期 |
| --- | --- | --- |
| 超重 | SBP | 7.3 | 3.82 |
| | DBP | 6.3 | 0.8 |
| 低体重 | SBP | 0.87 | 0.38 |
| | DBP | NA | 0.25 |
| 正常 | 作为参考 |

此外，执行了双尾独立样本 *t* 检验，以观察每对血压测量值之间是否存在统计学显著差异。在 *t* 检验中，三个参数（BMI、HR 和年龄）的显著性水平取为 0.05。峰度和偏度的值小于进行 t 检验的可接受值 [[24]](#C_012_c7.xhtml#r7_24)。[表 7.4](#C_012_c7.xhtml#t7_4) 显示了高血压、高血压前期和正常人不同配对获得的 *P* 值。应注意，*P* 值越小表明这三种情况之间的区分度越好。结果显示，除了一种情况（高血压-高血压前期情况下 HR 的 *P* 值）外，BMI、HR 和年龄的 *P* 值均显示出高血压、高血压前期和正常患者之间的区分。
