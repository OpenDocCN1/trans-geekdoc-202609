

# 研究现状与应用综述

## 价格预测与区块链优化

许多研究已利用 `RNN` 和 `ARIMA` 模型进行价格预测。研究人员正在提出检测异常的解决方案，并致力于预防异常。研究工作正集中于最大化吞吐量、带宽和规模。为了在比特币交易区块中提供低延迟并增强区块链安全性，必须在特定交易区块上花费更多时间。因此，开发了一种技术，可在不干扰其安全模型的前提下，在几秒钟内构建区块并确认其交易。研究人员正尝试为哈希函数增加更多安全层级。比特币应用程序编程接口（`API`）难以使用；因此，需要一个对开发者友好的 `API` 以预测更好的结果。

在韩国等国家，区块链被用于发行债券。区块链已被用于屏蔽假新闻。印度即将开发基于区块链的投票系统，而非使用以太坊虚拟机。阿联酋政府转向区块链，以使其医疗数据防篡改。时间序列预测已被用于简化、观察和预测趋势的某些因果行为。它基本上允许我们发现数据集的过去结果如何影响未来。

## 时间序列预测的应用领域

时间序列预测的应用涵盖商业、金融、科学、工程和医疗健康领域。

- **商业领域**：广泛用于供应链、预订、监控网络流量等。能有效预测商业领域的未来发展，涉及收入政策、销售、税收以及各类资源和交付物的需求。基于历史数据集，企业界可预测未来结果，从而相应规划预算和资金，并合理分配资源。它还影响策略决策，以采用最佳方法实现持续增长。
- **金融与经济**：用于预测股市趋势和价格、货币兑换、计量经济学。
- **科学与工程**：用于天文学预测、天气预报、地震和自然灾害预测；广泛应用于传感器和控制信号处理。
- **医疗健康**：用于疾病医学诊断和生物医学监测。时间序列预测可成功应用于预测死亡率、疾病进展，并据此预测未来可能发生的各种风险。

## 异常检测的应用与区块链结合

异常检测广泛用于保护基于 Web 的零售业务、金融部门、入侵和欺诈活动检测、故障检测、医疗设施监控、传感器网络和控制信号中的事件检测以及环境干扰检测。使用机器学习算法进行异常检测是当今几乎所有行业最重要的活动之一。

区块链领域有许多拟议研究，为加密世界指明新方向。`SreeragIyer` 等人 [[31]](#C_009_c4.xhtml#r4_31) 提出，`Hyperledger Composer` 中的代币（也称为资产，`Hyperledger Composer` 是一组工具，为各类开发者和商人提供制造区块链应用以解决业务问题的能力）可根据企业在废水管理中的贡献发放给商业和工业。

- 最有效的企业是指在水体中实行零排放政策，并将公司产生的废水完全再利用于自身程序和操作的企业。
- 最差的企业是指不顾后果将所有废水排放到周围栖息地或领土，且不将其视为可重用组分的企业。

因此，代币的分发同时考虑废水再利用的质量和数量。如果企业超过了定义的阈值，则可将代币出售给未达到阈值的其他企业。生成的代币数量与再利用水的纯度成正比。发行和交易这些代币或资产的规则和法规称为智能合约 [[32]](#C_009_c4.xhtml#r4_32)。许多企业可能将此作为通过篡改授予这些资产的信息来非法获取比特币的手段。因此，该拟议系统利用异常检测算法来预测物联网（`IoT`）仪表中可能发生的潜在骗局或异常。

## 聚类算法与深度学习在异常检测中的研究

研究了各种聚类算法，如 `K-means` 聚类和基于密度的空间聚类。空间聚类也称为 `DBSCAN`。研究的用于异常检测的深度学习领域其他算法包括自编码器（`auto-encoder`）和 `LSTM`。

在区块链上存储数据和信息使其成为不可更改的审计追踪，并根据智能合约提供自动分析系统 [[33]](#C_009_c4.xhtml#r4_33)。为使原型更坚固、更稳健，执行有监督和无监督算法以查明供应废水回收统计数据的企业 `IoT` 仪表的任何变化。

- `K-means` 聚类通过研究肘部图并确定拐点，预先指定了要形成的聚类数量。
- `DBSCAN` 算法根据其输入变量形成聚类。

此处 `Hyperledger Fabric` 使用基于 `Kafka` 的共识机制，这与使用昂贵的工作量证明（`Proof-of-Work`）的 `Ethereum` 或 `bitcoin` 不同。该拟议系统具有一个控制机制，用于提供资产并检查异常或欺诈，因此不需要 `Proof-of-Work` [[34]](#C_009_c4.xhtml#r4_34)，因为供应商和借款人的身份必须是已知的。

## 基于区块链与深度学习的智能电网隐私保护架构

`MarwaKeshk` 等人 [[35]](#C_009_c4.xhtml#r4_35) 提出了一种依赖于区块链和各种深度学习算法的隐私保护架构，以委托智能电网的数据集，从而能感知未来对数据的潜在攻击。该架构包含两级安全机制：

1. 第一级定义了一种 `ePoW` 方法以确认信息完整性。
2. 第二级包含一种变分自编码器（`variational auto encoder`）技术，以隐藏数据并将其重组为新配置。

与当代方法相比，利用两步安全机制可获得更优越的成果，且在避免数据篡改和推理攻击利用智能电网本地数据存储方面也非常有效。其中一种异常观测方法是 `LSTM`，它在执行两步安全技术前后均应用于数据 [[36]](#C_009_c4.xhtml#r4_36)。获得的结果表明，该拟议技术在精确率和预警率方面优于其他拟议技术。该研究的未来扩展包括在来自智能电网的各种实时数据上实施该架构，以评估其可扩展性、可行性和盈利能力。

电网现代化极受关注，特别是对美国和澳大利亚等技术领先的发达国家而言，因为智能电力系统有能力最大化能源消耗并提供最佳解决方案。如 [图 4.4](#C_009_c4.xhtml#f4_4) 所示的网络物理系统展示了单个每次点击成本（`cost-per-clicks`）单元如何合并以确定智能电网，后者结合物理和信息传输自动化及相应组件，以扩展电网的能力和生产力 [[37]](#C_009_c4.xhtml#r4_37)。
