### 15.3.2.6 应用层

该层位于客户端，一旦客户端应用程序发起交易即开始起作用。它由业务应用程序组成，包括物联网、数字身份等。客户端应用程序使用软件开发工具包（SDK）或命令行界面（CLI）来实现区块链网络中节点间的通信。应用层借助一些特定框架、应用程序编程接口（API）和脚本，促进最终用户与区块链网络之间的交互。执行层是其子层，包含待执行的实际代码。

### 15.3.3 共识协议

共识协议负责确保分布式区块链网络中各节点各自的区块链账本达成共识。下面小节介绍了一些重要的共识协议。

#### 15.3.3.1 工作量证明

PoW 是一种基于证明的算法，用于识别节点，并允许其将新挖出的区块添加到现有链的末尾，前提是提供必要的证明 [[44](#C_020_c15.xhtml#r15_44)]。该算法解决了决定哪些节点可以将交易打包进区块的模糊性问题。

#### 15.3.3.2 权益证明

PoS 是一种算法，要求矿工在区块链中拥有足够的权益，这也有助于缓解区块链网络中可能出现的可疑活动 [[45](#C_020_c15.xhtml#r15_45)]。它高度强调能源效率。

#### 15.3.3.3 委托权益证明

与 PoS 的直接方式不同，委托权益证明（DPoS）采用民主方式，由利益相关者选举代表来验证区块 [[46](#C_020_c15.xhtml#r15_46)]。与 PoS 相比，它能实现更快的区块生成和交易快速确认。然而，代表可能会自我投票并操纵其他参与者投票。

#### 15.3.3.4 燃烧证明

燃烧证明（PoB）方案用于带验证的加密货币销毁。两个重要功能构成了 PoB：一个用于生成加密货币地址的功能，和一个用于检查该地址是否真正不可花费的验证功能。PoB 遵循币销毁策略，导致区块链中使用的币减少，从而提高币值。PoB 具有三个显著特性：抗审查性、绑定性和不可花费性。

#### 15.3.3.5 经过时间证明

根据经过时间证明（PoET），每个节点生成一个随机数以估算生成区块前的等待时间。它不涉及所有用户的失效；而是在链内选举一位领导者来创建新区块。每个节点都有一个关联的随机定时器。如果同一节点反复被选为领导者，PoET 能高效追踪恶意用户。

#### 15.3.3.6 容量证明

容量证明（PoC）方案倾向于利用节点的硬盘空间，而非随机生成 nonce 值。因此，与 PoW 协议相比，它的计算强度较低。根据 PoC，拥有更多磁盘空间的节点有资格拥有更多权益。

#### 15.3.3.7 实用拜占庭容错

当网络中两个通信节点即使在存在少数恶意节点的情况下也能安全达成共识时，这种状况称为拜占庭容错（BFT）。因此，PBFT 是一种复制算法，其中节点与一个主节点按顺序排列，其他节点作为备份。通过投票验证数据的完整性和来源。PBFT 存在三个阶段：预准备、准备和提交。

#### 15.3.3.8 权威证明

该协议解决了 PoW 中出现的某些能源消耗和依赖问题，并用于私有区块链。Li 等人 [[47](#C_020_c15.xhtml#r15_47)] 指出，受信节点被授予利用多数标准形成共识和创建新区块的权限。链中的“N”个受信节点称为权威节点，假设 N 个节点中至少有 (N/2) + 1 个是诚实的。

## 15.4 医疗健康 4.0 中的网络安全

如果一项技术包含敏感私密数据、异构结构和复杂合规要求，网络安全问题就会日益凸显。医疗健康 4.0 是最新技术的结合体，包括物联网和人工智能，它们以最高效的方式驱动医疗健康运作。医疗健康的异构性使得数据库、网络、前端更容易受到网络攻击。医疗健康中使用各种设备，如闭路电视（CCTV）和传感器，它们不具备自我更新能力 [[48](#C_020_c15.xhtml#r15_48)]。这使得它们容易受到制造后网络世界出现的攻击。下面小节深入关注使医疗健康更易受网络攻击的各种关键参数。

### 15.4.1 网络漏洞与攻击

网络是医疗健康 4.0 的骨干。所有设备以互联模式协同工作。医疗健康中的这些设备从现场传感器或设备获取第一手输入，后者进一步从周围环境接收输入。由于各种设备缺乏补丁更新功能，医疗健康网络变得脆弱。这导致网络易受各种基于网络的攻击，如拒绝服务（DoS）、干扰、节点篡改（NT）、睡眠剥夺、欺骗和泛洪。它可能影响前端设备，如路由器、交换机、闭路电视摄像头、传感器，或医疗健康的内部计算设备，如 Web 服务器和数据库服务器。以下列举的要点进一步解释了基于网络的攻击。

*   DoS 攻击可关闭医疗健康 4.0 的网络，使医疗健康系统中的员工、管理员和患者无法访问。这种攻击会瘫痪流量或使其对预期用户不可用。DoS 攻击要么泛洪网络，要么使其崩溃。缓冲区溢出攻击、互联网控制消息协议泛洪和 SYN 泛洪是 DoS 用来泛洪医疗健康网络的三种主要攻击。此外，崩溃是由于网络或网络设备中存在的漏洞导致的 DoS 攻击结果 [[49](#C_020_c15.xhtml#r15_49)]。当以分布式方式执行时，即多个设备攻击单个网络，这种攻击会变得更具毁灭性。

*   干扰攻击是另一种基于网络的攻击，主要针对无线网络系统 [[50](#C_020_c15.xhtml#r15_50)]。由于医疗健康 4.0 包含各种无线通信，且主要用于传感器，这种攻击在医疗健康 4.0 系统中变得突出。存在各种类型的干扰攻击，如欺骗性干扰器 [[51](#C_020_c15.xhtml#r15_51)] 和随机干扰器，它们可影响医疗健康 4.0 网络中的无线通信。

*   NT 在医疗健康 4.0 中极有可能发生，因为它是通过物理手段实施的。医疗健康 4.0 的许多网络设备和现场传感器无人看管，攻击者可轻松访问。攻击者可用其受感染的节点（路由器、集线器、交换机等）替换真实节点。
