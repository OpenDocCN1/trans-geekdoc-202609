

# 物联网医疗应用中的安全挑战

物联网部署了大量小型智能设备来收集关于环境的详细信息 [[10](#C_016_c11.xhtml#r11_10)]。尽管实现了微型化并降低了制造成本，但这些设备在功率传输、数据处理、带宽、存储容量和能源方面通常资源有限。然而，传输和接收操作消耗了节点设备的大部分能量 [[11](#C_016_c11.xhtml#r11_11)]。毫不奇怪，在评估传感器网络性能时，服务寿命可能是最重要的指标，特别是因为大多数低功耗设备的寿命有限；此外，为成千上万部署在难以到达区域的这些设备持续更换电池通常是不切实际甚至不可能的 [[12](#C_016_c11.xhtml#r11_12)]。因此，能量消耗是传感器面临的一个关键挑战。为此，提出了多种方法来节约感知层面的能源资源，并克服其局限性固有的挑战 [[13](#C_016_c11.xhtml#r11_13)]。

已经探讨了与物联网相关的许多其他问题，其中最重要的问题之一是安全问题 [[14](#C_016_c11.xhtml#r11_14)]。一个拥有大量互联设备的巨大网络的存在几乎肯定会暗示各种攻击和窃听场景，这可能会危及这些实体及其用户 [[15](#C_016_c11.xhtml#r11_15)]。这些联网“事物”构成的威胁不仅影响物联网系统，还影响整个生态系统，包括网站、应用程序、社交网络和服务器。在使用物联网的医疗应用中，随着我们在衣物和身体上添加更多设备，将收集更多个人信息。随着物联网设备数量呈指数级增长，技术和安全挑战也随之增加 [[16](#C_016_c11.xhtml#r11_16)]。例如，攻击可能会合理地修改药物剂量，从而导致某位患者死亡或产生灾难性的健康后果。此外，医疗设备可以通过多种通信媒介（如 Wi-Fi、Zigbee、蓝牙、6LowPAN 和 NFC）被远程利用。在这种情况下，攻击者可以轻松窃听通信信道并获取传输的数据 [[17](#C_016_c11.xhtml#r11_17)]。开发新的安全框架以防止敌对或未授权对象访问物联网系统、读取或篡改收集的数据至关重要 [[18](#C_016_c11.xhtml#r11_18)]。

本章旨在回顾关于基于物联网的医疗应用中安全和隐私挑战及方法的当前文献。为了揭示物联网危险的根源，我们介绍并分类了物联网安全威胁类别以及防御技术，以便为读者提供必要的安全背景知识，从而更好地理解这一领域。我们呈现了物联网攻击的分类法，以及对物联网各层级安全关注点的分析。我们还根据攻击目标给出了安全需求分类法。然后，我们介绍了提高物联网安全性的解决方案。本文其余部分组织如下：我们在第 11.2 节 [[Section 11.2](#C_016_c11.xhtml#h11_2)] 中给出了针对医疗系统的当前安全和隐私攻击的完整分类法。医疗系统的安全需求分类法在下一节中提供。在第 11.4 节 [[Section 11.4](#C_016_c11.xhtml#h11_4)] 中，我们将探讨研究人员提供的一些保护医疗系统的现有方法。最后，我们在第 11.5 节 [[Section 11.5](#C_016_c11.xhtml#h11_5)] 中总结本文。

## 11.2 基于物联网的医疗应用中的安全攻击

如前所述，当前的医疗设备和应用不符合安全和隐私标准。攻击者可以利用医疗系统的许多组件来执行不需要的操作 [[19](#C_016_c11.xhtml#r11_19)]。为了将安全需求仔细纳入物联网系统，首先需要调查物联网的漏洞和攻击。攻击是一种破解加密方案的尝试，成功的攻击意味着该方案下加密数据的安全性已被破坏 [[20](#C_016_c11.xhtml#r11_20)]。在本节中，我们将讨论针对医疗系统不同部分（如传感器、设备和网络）的多种攻击类型，以及攻击者如何破坏目标医疗系统的安全性和隐私。详细总结见表 11.1 [[Table 11.1](#C_016_c11.xhtml#t11_1)]。

**表 11.1** 基于物联网的医疗安全攻击
