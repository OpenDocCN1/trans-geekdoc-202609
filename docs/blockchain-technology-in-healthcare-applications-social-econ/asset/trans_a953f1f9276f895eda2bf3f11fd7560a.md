
超级账本技术未能为可扩展性提供合适的解决方案[[81](#C_018_c13.xhtml#r13_81)]。McKee 等人[[82](#C_018_c13.xhtml#r13_82)]对其分析方法也有类似的担忧。随着比特币的发展，私有区块链被开发出来，用于哈希特定数据以保障交易安全。由于每条区块链都维护着自己的永久记录，因此无法操纵与每个产品关联的私钥。该系统的创建旨在防止产品转移过程中的任何错误，并确保整个供应链的完全透明。

制药供应链也是许多正在进行的项目的研究主题，这些项目探索分布式账本的使用以实现可追溯性。Arsene 等人[[83](#C_018_c13.xhtml#r13_83)]涉及 IBM、Cisco、Intel、Bloomberg 和 Blockstream 等公司的全球合作。每种药物都被分配一个时间范围，使其能够追溯到其源头和制造商。Le 等人[[84](#C_018_c13.xhtml#r13_84)]考察了利用区块链提供符合 DSSA 监管框架的解决方案，以增强全球互操作性。

### 13.5.3 基于区块链的制药供应链追踪器

研究发现，利益相关者可以使用一个称为 DApp 的前端软件层，该层通过类似 `Infura`、`Web3` 和 `JSON RPC` 的 API 连接到区块链和存储系统。利益相关者可以通过智能合约调用预授权函数，并通过去中心化存储系统访问数据文件。作为最后一步，他们将与链上资源交互以获取相关数据，如日志、星际文件系统（`IPFS`）哈希值和交易。以下要点提供了有关系统各组件的更多信息。

*   药房、制造商、分销商以及食品药品监督管理局（`FDA`）等监管机构是利益相关者。在智能合约中，参与者根据其在供应链中的角色被分配特定功能。链上资源（`OR`），如日志信息和历史记录，均可随时访问，以确保供应链交易可被追踪。此外，他们还可以访问 `IPFS` 信息，包括药品批次图片和说明书。

*   去中心化存储系统利用低成本的链下存储[[85](#C_018_c13.xhtml#r13_85)]，使供应链交易数据公开可访问、可靠且安全。每个上传的文件都会生成一个存储在公司服务器上的唯一哈希值。然后将这些哈希值存入区块链，当这些上传文件发生变化时，可通过哈希技术经由智能合约检索这些哈希值。

*   通过使用以太坊智能合约（`ESC`）和智能合约部署区块链供应链，参与者可以访问供应链信息并追踪交易的历史渊源。智能合约管理去中心化存储服务器上的哈希值，从而记录交易历史。此外，智能合约定义了每个利益相关者的功能，并通过修饰符授权相关方访问这些功能。修饰符通过添加额外功能或限制来增强或修饰函数。

*   供应链部署通过 `ESC` 处理。它允许参与者检索供应链信息，因为智能合约使他们能够访问交易历史并管理哈希值。此外，智能合约定义了各利益相关者的职责。获授权的参与者可通过修饰符访问这些功能。修饰符用于通过添加更多功能或施加限制来增强组件。智能合约还可以处理交易，如药品批次或箱子的交易。

*   日志和事件由智能合约存储在 `OR` 中，以便进行追踪。注册和文档系统作为 `OR`，将参与者的以太坊地址与一种以去中心化方式存储人类可读文本的方法相关联。

集成系统组件可使用户实时验证药品历史，从而消除实时追踪需求。用户只需检查药品的真实性，并确认药品来自信誉良好的制造商即可。可以实施多种技术来实时追踪药品批次的位置。启用 `IoT` 的智能集装箱配备了传感器，可从起点到目的地持续监控和追踪集装箱。全球定位系统（`GPS`）接收器用于确定其位置，温度传感器用于监控温度，压力传感器则对集装箱的任何开启或关闭敏感[[86](#C_018_c13.xhtml#r13_86)]。

## 13.6 结论与未来研究方向

区块链是当今医疗保健领域最具革命性的底层技术之一。数据收集和验证实现了自动化，提供无错误、不可篡改且防篡改的数据，确保网络犯罪尝试减少。数据还可以从多种来源聚合，并以安全的方式查看。此外，区块链具有容错性并支持分布式数据。医疗保健是区块链技术最重要的应用之一，而这是一个相对较新的领域。医疗保健领域已开发出该技术的多种应用，包括共享医疗信息、管理药品供应链和监测患者。利用区块链技术，我们可以实现运营去中心化，并高效、高保真地管理安全。本文进行了深入分析，建议将区块链技术作为保障医疗保健和制药行业数据安全与追溯的具体解决方案之一。论文从区块链嵌入式医疗系统领域的当前进展切入。论文还介绍了医疗保健和制药行业盛行的各种网络攻击。

最后，概述了医疗行业区块链应用的众多未来指导方针。预计这项工作将作为知识库和有序标准，协助未来关于整合区块链、`IoT` 设备和连接技术到医疗系统的研究。医疗保健和制药行业正在迅速采用现代技术，因此需要更多的安全性和可追溯性。本文提供了可用于未来研究工作的各种参数。
