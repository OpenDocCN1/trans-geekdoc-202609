# IIoT 安全挑战

IIoT 构成了一个自主环境，因此必须严肃对待安全特性。随着 IIoT 应用使用量的巨大增长，网络安全威胁也随之增加。在像 IIoT 这样的自主互联环境中，可能出现多种漏洞，此类攻击将损害系统的可靠性。在考虑 IIoT 生态系统的安全挑战时存在若干问题。一个主要问题是缺乏风险缓解。这意味着 OT 部分的操作员可能不深刻理解由 IT 专家处理的原则。因此，尽管存在多种缓解技术，但只有少数被有效利用。其他问题包括缺乏适当的安全更新、攻击影响、缺乏终端组件可见性等。

另一个主要问题是所涉及系统组件的脆弱性。由于工业设备最初设计用于封闭环境，当时未考虑安全问题。与 IIoT 设备相关的安全风险包括设备管理、补丁管理、使用相同的认证凭据以及返回错误数据。IIoT 依赖大量传感器、处理元件和执行器来自动化数据收集、处理和响应。IoT 生态系统的可靠性取决于实施的几个阶段，如设备可靠性、通信可靠性、网络可靠性和应用可靠性 [[3]](#C_007_c2.xhtml#r2_3)。

IoT 系统的设备层包含电磁设备，称为传感器和执行器。一旦这些资源受限的传感器设备大规模部署在各个位置，就难以监控并确保它们准确传送数据。数据收集阶段面临的主要挑战之一是机电设备提供的准确性。传感器性能可能因设备故障、环境因素和缺乏固件更新等原因而下降。本文提出了一种基于区块链的算法，以提高 IIoT 应用数据收集阶段的传感器可靠性。该范围最初在 [[4]](#C_007_c2.xhtml#r2_4) 中探讨。

## 2.3 区块链与权益证明算法

区块链被设想为一种分布式账本，可取代现有的中心化记录模型。它作为比特币（首个被接受的加密货币）运行平台被引入。区块链通常基于分布式共识概念工作，确保仅在大多数参与者认可真实性时才添加账本条目。这是验证者的职责。交易存储在条目链上，每个条目保存链中前一条目的哈希值。这使区块链天生具有不可篡改性，因为交易后对区块链的任何更改都会导致哈希值改变，从而使此后所有条目失效。文献 [[8]](#C_007_c2.xhtml#r2_8) 描述的区块链基本组成部分和方面如下：

- **交易**：交易是区块链的基本单元。执行交易需要源地址、源数字签名、交易信息和目标地址。
- **矿工**：矿工是区块链网络中的共识参与者，确保所有交易得到验证。每笔交易经验证后与其他交易打包进一个区块。若成功，则广播给所有其他节点进行验证，并标记为最新区块。
- **哈希指针**：由哈希函数创建，将区块内容映射到哈希指针。通常通过获取前一区块的哈希值并将其作为条目添加到当前区块来创建。这通过确保前一数据的任何变更将导致下一区块出现不同的哈希值，并可追溯至创世区块（即链的第一个区块），使任何篡改显而易见。
- 根据不同共识机制的要求，区块还可包含额外数据。为减少存储空间，区块中的交易可按默克尔树形式存储。
