
物联网还涉及许多其他问题，其中最重要的一个是安全问题。一个拥有大量互联设备的庞大网络的存在，几乎必然会引出各种攻击和窃听场景，这些场景可能会危及这些实体及其用户。如前所述，由于物联网设备在处理和存储方面存在物理限制，典型的安全措施无法直接应用于物联网设备。此外，在设备或用户访问物联网服务之前，必须根据预设的安全规定，在设备/用户与物联网系统之间执行相互认证和授权。另一方面，所提出的安全措施必须考虑到物联网设备的受限资源。区块链技术可以解决这些主要问题 [[32](#C_016_c11.xhtml#r11_32)]。研究人员越来越多地转向基于区块链的安全框架，以保护医疗数据免受未授权方的侵害。为了确保基于物联网的医疗应用中的通信安全，文献 [[31](#C_016_c11.xhtml#r11_31)] 的作者提出了一种有效的多层认证协议和一种用于无线体域网 (WBAN) 的安全会话密钥生成机制。文献 [[32](#C_016_c11.xhtml#r11_32)] 的作者提出了一种基于区块链技术的医疗数据存储方案，以确保个人医疗数据的安全存储和共享。为了实现医疗应用中的安全通信，Deebak 等人 [[33](#C_016_c11.xhtml#r11_33)] 基于 ECC 和加密哈希函数提出了一种安全匿名生物识别用户认证方案 (SAB-UAS)。[表 11.3](#C_016_c11.xhtml#t11_3) 总结了这些工作。

### 11.4.4 基于轻量级密码学的解决方案

密码学解决方案是密码学提供的所有安全服务。密码学提供各种安全技术，并可在使用物联网的医疗应用中提供机密性、认证、完整性及许多其他优势。为实现这些安全服务，密码学采用不同的方法，如加密/解密方法、密钥生成方法、哈希函数 [[3](#C_016_c11.xhtml#r11_3)] 和数字签名。可采用轻量级密码技术来实现包括机密性、完整性和认证在内的关键安全需求 [[4](#C_016_c11.xhtml#r11_4)]。许多基于密码学的方法被构建出来，用于检测和阻断使用物联网的医疗应用中的攻击。文献 [[6](#C_016_c11.xhtml#r11_6)] 中，作者提出了一个名为 `MADAR` 的框架来对抗 DoS 攻击。`MADAR` 可以抵抗利用基于 ID 的签名方案和自生成假名组合来影响通信的 DoS 攻击。它还可以检测基于使用强度可变的消息特定谜题来攻击通信的 DoS 攻击。Kiho 等人 [[8](#C_016_c11.xhtml#r11_8)] 引入了一种基于群签名的密钥管理协议，以确保基于物联网的医疗系统保护中的认证。利用这一概念，拥有相同签名组的设备可以安全通信。文献 [[10](#C_016_c11.xhtml#r11_10)] 的作者使用哈希函数为基于物联网的医疗系统构建了 `HCPA-GKA` 方案。设备的组密钥管理机制分发是通过中国剩余定理 (CRT) 完成的。当设备加入和退出组时，它可以被更新。[表 11.3](#C_016_c11.xhtml#t11_3) 总结了这些工作。

### 11.4.5 基于人工智能的解决方案

机器学习 (ML) 是一种数据分析技术，它允许医疗系统从数据中学习并执行特定任务，如异常检测、行为分析等。机器学习主要有两类：监督学习和无监督学习。当人工手动将训练数据分类为有害或真实，然后将这些数据输入算法以开发一个包含数据“类别”的模型，并将待分析流量与之比较时，就会发生监督学习 [[38](#C_016_c11.xhtml#r11_38)]。无监督学习避免使用训练数据和人工标记，转而支持将可比较的数据片段分组到类别中，然后根据每个类别内的数据连贯性和类别间的数据模块化对其进行分类 [[39](#C_016_c11.xhtml#r11_39)]。机器学习被用于创建复杂的算法，以保护网络和系统，包括物联网设备。研究界已探讨了 ML 技术以检测针对医疗系统的攻击 [[40](#C_016_c11.xhtml#r11_40)]。Saeedi 等人在文献 [[41](#C_016_c11.xhtml#r11_41)] 中利用决策树方法检测医疗设备中的恶意攻击。Vhaduri 等人利用支持向量机 (SVM) 特性，通过卡路里消耗、平均步数和每分钟心率等多种生理和行为指标，检测对医疗设备及其获取数据的非法访问 [[42](#C_016_c11.xhtml#r11_42)]。Newaz 等人提出了 HealthGuard，这是一种基于 ML 的安全框架，用于检测互联医疗系统中的敌对行为 [[43](#C_016_c11.xhtml#r11_43)]。HealthGuard 从各种医疗设备收集生命体征，并应用 ML 算法关联患者生物过程的变化，以区分良性和恶性活动。[表 11.3](#C_016_c11.xhtml#t11_3) 总结了这些工作。
