

## EOS 平台概述

EOS 是一个去中心化且可扩展的平台，专为企业级应用设计，同时也可运行 dApps。该平台支持公有链和私有链部署 [[64](#C_014_c9.xhtml#r9_64)]。合约具有图灵完备性，并使用 C/C++ 进行开发。此外，EOS 中使用的智能合约与以太坊类似，每次执行合约时都会创建一个新的合约实例。另外，EOS 中的合约不需要任何交易手续费 [[37](#C_014_c9.xhtml#r9_37)]。此外，EOS 中的节点协作出块而非竞争出块，这也提高了安全性 [[65](#C_014_c9.xhtml#r9_65)]。

## 9.4 区块链与智能合约的应用

区块链结合智能合约，凭借其去中心化、不可篡改、透明、抗抵赖、假名性和快速处理等显著特性，带来了巨大的机遇。医疗保健 [[66](#C_014_c9.xhtml#r9_66)]、金融 [[67](#C_014_c9.xhtml#r9_67)]、房地产、音乐产业 [[68](#C_014_c9.xhtml#r9_68)]、保险 [[69](#C_014_c9.xhtml#r9_69)] 和媒体 [[70](#C_014_c9.xhtml#r9_70)] 等领域只是其中一部分，它们已经意识到区块链和智能合约的潜在优势，并因此开始使用它们。例如，在医疗保健领域，区块链可实现患者和医疗设备记录的数字化维护、药品供应链管理、远程患者监测和健康数据分析 [[71](#C_014_c9.xhtml#r9_71)]。涉足该领域的公司包括 Medicalchain [[72](#C_014_c9.xhtml#r9_72)]、IRYO [[73](#C_014_c9.xhtml#r9_73)] 和 Burstiq [[74](#C_014_c9.xhtml#r9_74)]。许多此类公司旨在让患者完全控制并拥有其电子病历，并允许患者决定与谁共享其医疗记录。保险是另一个可以利用区块链和智能合约提升的领域。区块链和智能合约在保险领域可实现的功能包括：消除对中介的需求、更高效地检测欺诈、协助建立动态的保险公司/客户关系，并使申请流程更加以客户为中心 [[75](#C_014_c9.xhtml#r9_75)]。

房地产是另一个拥抱区块链的领域。得益于智能合约和分布式账本，客户可以在一个安全高效的环境中租赁、购买、投资和借贷。例如，基于区块链的公司 Propertyclub 允许用户利用区块链通过其门户浏览、出售、出租、购买和投资房产 [[76](#C_014_c9.xhtml#r9_76)]。因此，区块链正成为一种极具前景的未来技术，能够支持和增强商业的许多领域和域。

## 9.5 区块链与智能合约的安全性

区块链和智能合约蕴含巨大潜力，由于底层特性如加密技术、去中心化和分布式数据库，被认为是安全的，这使得攻击者极难进行黑客攻击或篡改。特别是，基于区块链的系统不会遭受与中心化系统相关的问题，如单点故障、对第三方或中介的必要性、权威机构保持完全控制，以及最重要的是用户隐私问题。

尽管如此，区块链本身仍存在安全和隐私问题。过去发生的许多安全攻击，如 DAO 攻击、自私挖矿攻击、Parity 多签攻击和 51% 攻击 [[77](#C_014_c9.xhtml#r9_77), [78](#C_014_c9.xhtml#r9_78), [79](#C_014_c9.xhtml#r9_79)]，表明该技术仍处于发展阶段。一些与区块链和智能合约相关的安全攻击在 [表 9.2](#C_014_c9.xhtml#t9_2) 中简要讨论。尽管如此，区块链社区和联盟正持续致力于缓解这些攻击。

### 表 9.2：区块链和智能合约的各类攻击

| 攻击焦点 | 攻击 | 简要描述 |
| :--- | :--- | :--- |
| 区块链 | 多数攻击 | 当攻击者积累的算力超过其他人时，其能够控制整个区块链并改变诚实节点对网络的视图 [[79](#C_014_c9.xhtml#r9_79), [80](#C_014_c9.xhtml#r9_80)]。 |
| 区块链 | 日蚀攻击 | 攻击者填充诚实节点的数据结构，以将其隔离并操纵其对区块链的视图（即 P2P 网络中的账本）。该攻击是其他攻击（如多数攻击和 DDoS 攻击）的基石 [[81](#C_014_c9.xhtml#r9_81)]。 |
| 区块链 | DoS 攻击 | 攻击者向网络发送异常大量的请求，瘫痪网络处理真实流量的能力 [[82](#C_014_c9.xhtml#r9_82)]。攻击者旨在使网络的矿池、电子钱包、加密货币交易所和其他金融服务断开连接 [[80](#C_014_c9.xhtml#r9_80)]。 |
| 区块链 | 女巫攻击 | 由单个用户控制的多个节点。通过利用它们，可能会排挤诚实节点。此攻击通常用于控制网络，也可能为更大规模的攻击（如 DDoS 攻击或多数攻击）铺平道路 [[83](#C_014_c9.xhtml#r9_83)]。 |
| 区块链 | 自私挖矿攻击 | 恶意矿工（或矿工组）私下挖掘新区块并不向网络其余部分发布。此类矿工持续挖掘新区块，直到其本地（私有）区块链副本比当前公开可用的区块链更长。在获得足够领先优势后，自私矿工发布（广播）更长的区块链，该链将被网络接受。自私矿工的一个明显意图是最大化获得的奖励 [[28](#C_014_c9.xhtml#r9_28), [80](#C_014_c9.xhtml#r9_80)]。 |
| 区块链 | 竞争攻击 | 竞争攻击是一种双重支付尝试。它要求接收方接受未确认的交易作为付款。这是通过向目标发送欺诈交易、向矿池发送合法交易来实现的 [[83](#C_014_c9.xhtml#r9_83), [84](#C_014_c9.xhtml#r9_84)]。 |
| 智能合约 | DAO 攻击 | DAO 黑客事件发生于 2016 年 6 月，攻击者窃取了超过 360 万个以太币（当时价值 6000 万美元）。智能合约中的一个称为重入的漏洞是 DAO 攻击的根源 [[77](#C_014_c9.xhtml#r9_77), [85](#C_014_c9.xhtml#r9_85)]。 |
| 智能合约 | Parity 多签钱包攻击 | 钱包开发者创建了一个部署在以太坊上的公共库，以节省每笔交易产生的 Gas 成本。攻击者利用此公共库窃取了超过 150,000 个以太币（3000 万美元）[[77](#C_014_c9.xhtml#r9_77), [86](#C_014_c9.xhtml#r9_86)]。 |
| 智能合约 | 整数下溢/上溢攻击 | 以太坊和 Solidity 中的漏洞为攻击者传递某些参数创造了途径，这些参数可被利用以获取比原本可用更多的账户余额 [[77](#C_014_c9.xhtml#r9_77)]。 |
