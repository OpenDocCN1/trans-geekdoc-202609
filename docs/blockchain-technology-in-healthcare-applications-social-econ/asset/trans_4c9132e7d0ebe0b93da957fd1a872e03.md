

# 药品篡改与基于区块链的药品追踪

药品篡改已成为当今的主要关注点，它对公共卫生构成恶性威胁，对人类健康和医疗效果产生不利影响。根据世界卫生组织（WHO）的数据[[1]](#C_019_c14.xhtml#r14_1)，篡改药品是伪造产品来源和身份的结果。据世卫组织数据显示，发展中国家15%的药品和发达国家1.5%–2.5%的药品遭到篡改[[2]](#C_019_c14.xhtml#r14_2)。篡改药品对所有制药利益相关者产生不利影响，包括全球的医院、药房、批发分销商、全球卫生项目和监管机构。这些药品对人类致命。在有远见的制药供应链（PSC）背后，存在着一个巨大的非法药品市场，这些市场通过改变成分、将过期库存混入新库存中来生产虚假和受污染的药品。之所以存在这个过程，仅仅是因为缺乏在供应链每个环节追踪和验证药品真实性的技术。新冠疫情期间假瑞德西韦注射液的流通，就是近期造成人员伤亡的假冒药品案例[[3]](#C_019_c14.xhtml#r14_3)。

更容易受到非正规药品影响的地区有亚太地区、埃及和拉丁美洲。40%的药品制造和使用导致每年170万人死亡[[4]](#C_019_c14.xhtml#r14_4)。在欧洲地区，基于假冒药品的案件总数比去年增加了一倍[[5]](#C_019_c14.xhtml#r14_5)。欧洲一位杰出研究人员刚刚发布的一份报告强调，假冒药品行业现在被认为是一项更有利可图、更赚钱的生意，因为合法药品销售更加困难，其预估收入损失约占行业药品销售额的8%，每年达160亿欧元[[6]](#C_019_c14.xhtml#r14_6)。通过网上药店和非法分销渠道购买和获取药品的增长，使得在供应链网络系统中确保产品安全变得极具挑战性。同样，供应链网络中针对库存的有限数据透明度不足，给非正规行为进入市场提供了更多机会[[7]](#C_019_c14.xhtml#r14_7)。药品检测是辨别药品真伪和合法性的能力，确保所有利益相关者能在供应链系统的每个阶段检测和追踪每笔交易。美国《药品供应链安全法》（DSCSA）[[8]](#C_019_c14.xhtml#r14_8)等法规要求所有药品供应链利益相关者采取可靠措施以实现更好的产品追踪；DSCSA的实际实施将以渐进分阶段的方式在2025年前完成。通过在线访问PSC的日益增长的需求，为造假者提供了更多造假途径，未经授权的经销商分销药品也是药品造假的一个附加因素[[9]](#C_019_c14.xhtml#r14_9)。缺乏透明度和可追溯性也为药品造假者提供了可乘之机。

区块链技术是以分布式方式排列的区块链，旨在确保其所持有数据的安全性、真实性、透明度和可追溯性。存储在区块链上的数据是不可篡改的[[10]](#C_019_c14.xhtml#r14_10)；它凭借银行、教育、物流、交通管理、身份管理、电子健康记录管理、能源、贸易等应用覆盖了生活的几乎所有领域[[11]](#C_019_c14.xhtml#r14_11)。区块链在追踪PSC以根除篡改药品方面大有可为。区块链技术能够创建一个用于分配共享数据存储的平台，并在利益相关者不同的供应链系统之间共享交易数据，确保信息可供授权群体获取、不可更改、透明，并通过不同的加密技术保持安全[[12]](#C_019_c14.xhtml#r14_12)，[[13]](#C_019_c14.xhtml#r14_13)。因此，为制药系统供应链中的追踪、查找和管理真实性提供前瞻性方法至关重要。我们研究工作的主要贡献如下：

*   本文探讨了制药行业如何从基于区块链的供应链药品追踪系统中受益的原因。
*   本文揭示了使用基于区块链的药品配送解决方案相较于现有解决方案所带来的所有重要优势。
*   本文重点介绍了三种用于制药行业药品供应或使用追踪的基于区块链的架构，分别为 `Hyperledger fabric`、`Hyperledger besu` 和 `Ethereum`。
*   本文检测、评估并反驳了一些可能阻碍基于区块链的解决方案在药品正确使用和配送中有效实施的挑战性问题。

本文其余部分安排如下：[第14.2节](#C_019_c14.xhtml#h14_2) 概述区块链技术，包括其特性和本质，并探讨了区块链类别的比较。此外，[第14.3节](#C_019_c14.xhtml#h14_3) 概述制药行业的药品追踪。另外，[第14.4节](#C_019_c14.xhtml#h14_4) 阐述三种基于区块链的药品追踪系统及其药品追踪流程。而且，针对一些参数对三种讨论的基于区块链的药品追踪架构进行了比较。[第14.5节](#C_019_c14.xhtml#h14_5) 阐述与区块链采用技术相关的一些挑战或局限性，这些问题需要被描述以促进药品追踪。最后，[第14.6节](#C_019_c14.xhtml#h14_6) 给出结论并展望未来研究方向。

## 14.2 区块链概述

区块链是区块的链条，每个区块包含关于交易的信息。区块链的副本共享给网络中的每台计算机/节点，这确保了存储数据的透明度。区块链网络由一组计算机组成，它们在单一协议下运行，以将更新的区块添加到现有链中[[14]](#C_019_c14.xhtml#r14_14)，[[15]](#C_019_c14.xhtml#r14_15)。因此，区块链的区块网络是一个分布式系统，它存储了所有过去执行交易的信息，并选择一个协议来验证交易、裁决交易流程，并确定网络及其所有参与者的所有工作。因此，该网络被称为分布式网络，在该网络中，每笔交易的数据都存储在其中工作的每个特定区块上[[16]](#C_019_c14.xhtml#r14_16)。
