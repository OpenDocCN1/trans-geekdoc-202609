

# 数据共享与互操作性

患者的病历仍存储在纸质文档和分散的位置中，这最终导致医疗行业在快速发展的世界中变得极其低效。这些纸质记录不适合同步护理，也无法减少常见的医疗错误 [[47](#C_018_c13.xhtml#r13_47)]。如今，医疗数据的收集通过数字方式在各个节点进行。有必要检索收集到的数据，以便在不使流程复杂化的前提下充分利用这些数据。医疗行业面临着一个关键挑战：无法高效且以合理的资源支出存储和共享大数据 [[54](#C_018_c13.xhtml#r13_54)]。在跨各种系统操作时，实现数据可移植性和分布式数据兼容性至关重要 [[55](#C_018_c13.xhtml#r13_55)]。

对于需要关于数据一致性的身份验证和同意的数据，区块链技术是完美的选择。区块链可更好地用于保护具有多个访问点的大数据，且多方可访问。关键且必要的数据通过区块链变得不可攻破 [[56](#C_018_c13.xhtml#r13_56)]。医疗行业面临的问题是记录保存和收集持续稳定增长的业务往来，对此区块链是一个坚实的解决方案。

开放消费者交易能发现区块链更大的用武之地，在这些场景中，旧数据的重要性微乎其微，且数据稳步持续增长 [[57](#C_018_c13.xhtml#r13_57)]。数据记录包含基因信息和个人医疗史，这些被考虑应用区块链以提供高标准的安全性。医疗机构可实施区块链来存储患者病史的特定信息，并帮助医生通过提供给他们的网络访问这些数据 [[58](#C_018_c13.xhtml#r13_58)]。

## 13.4.2 数据共享与互操作性

低效的可交换性引发了两类问题。第一个常见问题是患者识别困难，当医疗机构不允许与另一个网络交换信息时就会出现此问题。其次，信息阻断发生的原因是患者不得不重复进行许多检测和体检 [[59](#C_018_c13.xhtml#r13_59)]。只有当患者的统一识别标识符和反信息阻断法律在基础层面被引入时，高效的医疗系统才能成为日常实践。此外，可交换性至关重要，特别是在冠状病毒等流行病期间。这场大流行的突然爆发揭示了医疗系统的现状，并暴露了对强健的数据共享基础设施的迫切需求。

强健的基础设施有助于简化患者与机构之间的沟通，缓解可管理的数据流动，避免公共卫生威胁。拜访一位可能非其家庭医生的医生时，患者必须能轻松访问其病历。此外，优化医疗数据流将允许医生进行远程监测和远程医疗咨询，使患者能让其家庭医生知晓其医疗史 [[60](#C_018_c13.xhtml#r13_60)]。在当前，随着冠状病毒感染者数量激增，包含患者体征、症状及风险数据在内的宝贵且透明的数据变得最为重要。

当前医疗系统缺乏可交换性的问题在这次大流行中凸显得更加明显 [[60](#C_018_c13.xhtml#r13_60)]。中心化 IT 系统以数字方式保存医疗史，但使共享变得困难。申请、发送、获取和汇总患者医疗信息既耗时、费力，又昂贵。由于监管限制、患者记录碎片化和后端系统不协调，医疗数据管理行业开发解决方案的速度较慢。由于医疗数据存储系统缺乏联盟，数据传输、恢复和调查变得困难。因此，患者与其医疗记录交互的能力受限，因为大多数数据存放在孤岛数据库中 [[54](#C_018_c13.xhtml#r13_54)]。

将区块链技术引入医疗领域，可显著提高医疗信息共享效率，并终结行业内缺乏可交换性的问题。哈希标识（ID）可作为使用授权医疗区块链的患者的唯一标识符。ID 的哈希值使其具有唯一性，并确保用户的真实性。患者将选择其医疗服务提供者，并向其披露各自的解密密钥。健康生态系统将变得更安全、私密和互操作，并以患者为中心 [[61](#C_018_c13.xhtml#r13_61)]。精确、当前且包容的医疗记录将使患者和提供者受益匪浅。

## 13.4.3 数据安全与管理

患者健康记录的安全漏洞引发了关于患者数据和隐私的警示性担忧。名为 Beazley 的公司报告称，针对医疗和制药行业的勒索软件网络攻击增加了 45% [[62](#C_018_c13.xhtml#r13_62)]。医疗记录越来越频繁地遭到黑客攻击，医疗数据泄露事件频发。报告发现，2017 年医疗领域报告的数据泄露事件超过 350 起，而 2009 年不足 20 起 [[63](#C_018_c13.xhtml#r13_63)]。卫生与公众服务部（DHHS）数据显示，2018 年因医疗行业数据泄露，共 1300 万份医疗记录被暴露 [[64](#C_018_c13.xhtml#r13_64)]。2016 年，有超过 2700 万份患者记录受健康数据泄露影响，平均每天一起 [[65](#C_018_c13.xhtml#r13_65)]。Unity Point Health 医院网络于 2018 年遭黑客攻击，导致 140 万患者的敏感医疗信息泄露，黑客从患者记录中窃取了实验室检测结果、治疗方案、社会安全号码及其保险信息 [[66](#C_018_c13.xhtml#r13_66)]。

大多数医疗机构的 IT 基础设施老化，往往容易受到勒索软件和其他网络攻击。各类医疗和制药公司将其重要的健康相关数据及信息保存在中心化位置 [[54](#C_018_c13.xhtml#r13_54)]。医疗机构海量的数据常使其成为复杂网络攻击的主要目标。如果提供者失去对患者医疗记录和其他基本数据的访问权，可能导致机构损失数百万美元。医疗行业投资于加密数据和利用人工智能等先进安全技术，以在泄露变得严重前加以预防。数据安全和患者隐私担忧日益增加，网络攻击数量上升，IT 安全已成为亟待解决的关键问题。

基于区块链的系统可为医疗数据的安全和管理提供多重优势 [[66](#C_018_c13.xhtml#r13_66)]。它保护私人数据不被滥用，并能遏制威胁。除了使数据不可篡改外，区块链还对其进行加密，使其无法解密。每笔交易由唯一的私有标识密钥发起。交易由仅用户知晓的私有标识密钥授权。因此，与当今的数据访问技术不同，医疗服务提供者只有在直接访问区块链记录时，才被允许访问患者的医疗信息 [[55](#C_018_c13.xhtml#r13_55)]。医疗机构可通过改善提供者间的数据协作，提供具有成本效益的护理。
