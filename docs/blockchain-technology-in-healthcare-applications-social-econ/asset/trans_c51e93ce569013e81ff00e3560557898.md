## 11.3 基于物联网的医疗应用中的安全需求

我们根据 [11.2 节](#C_016_c11.xhtml#h11_2) 中所示的物联网攻击目的，将物联网安全需求分为三类：数据安全、通信安全和设备安全。[表 11.2](#C_016_c11.xhtml#t11_2) 总结了这些安全需求。

**表 11.2 基于物联网的医疗安全需求**

| 特性 | 描述 |
| :--- | :--- |
| **数据安全** | **机密性** [[3]](#C_016_c11.xhtml#r11_3)<br>只有授权的人员或实体才能访问设备信息、系统设置和医疗数据。在访问任何与医疗相关的机密信息之前，这些实体必须经过授权。然而，现有的医疗设备（如胰岛素泵通信路径）可能被窃听，以获取患者数据和设备相关信息。 |
| | **完整性** [[4]](#C_016_c11.xhtml#r11_4)<br>当交换的消息受到保护，防止未经授权的修改时，即实现了完整性。它是指以安全的方式从设备、应用程序或基础设施传输数据，而不篡改原始数据。 |
| | **隐私** [[6]](#C_016_c11.xhtml#r11_6)<br>隐藏个人信息以及控制其处理方式都是隐私的例子。在数据收集、传输和存储过程中，必须考虑数据隐私。针对数据隐私问题提供了许多切实可行的解决方案。例如基于匿名化的解决方案、伪随机数生成器、分组密码和流密码等技术。 |
| **通信安全** | **认证** [[8]](#C_016_c11.xhtml#r11_8)<br>认证是验证某人或某物是否为其声称的身份的机制，用于允许访问信息系统中的资源，防止未经授权访问程序、系统、网络或设备；只有经过认证的对等方才能参与该过程。认证机制分为两类：节点认证（验证访问网络信息的权利）和消息认证（通过认证消息来保证其完整性和隐私）。 |
| | **访问控制** [[12]](#C_016_c11.xhtml#r11_12)<br>访问控制是一种安全要素，用于检查人员和系统是否有权限对其他系统和资源执行操作。访问控制算法分为五种不同类型：基于角色、基于组织、基于能力、基于属性和基于信任的算法。 |
| | **不可抵赖** [[4]](#C_016_c11.xhtml#r11_4)<br>医疗系统会执行不同的程序，这些程序通常保存在访问日志中。对该日志的任何更改都应被追踪和监控，且仅允许确认的用户进行修改。攻击者可能试图删除这些日志以掩盖踪迹。许多资源受限的医疗设备没有日志记录功能，攻击者可能试图在不留下任何痕迹的情况下访问系统。 |
| **设备安全** | **信任** [[8]](#C_016_c11.xhtml#r11_8)<br>关于与未知实体通信做出决策的过程称为信任管理。为了保护物联网系统，需要与受信任的物联网设备进行交互，以防止流氓节点执行不良操作。信任管理技术分为两类：确定性信任和非确定性信任。 |
| | **可用性** [[16]](#C_016_c11.xhtml#r11_16)<br>在正常和紧急情况下，医疗系统的服务应始终可供授权用户访问设备系统和患者数据。在可用性网络中，信息应全天候（24/7）可供真实用户访问，以防止网络中的多种攻击。 |

## 11.4 基于物联网的医疗应用中的安全解决方案

安全是基于医疗系统的物联网中最热门的研究课题之一，吸引了来自学术界、工业界和标准化机构的众多研究人员。迄今为止，已出现大量旨在解决物联网安全问题的解决方案。为了提高物联网安全性，提出了几种新技术和方法。在以下小节中，我们将通过归纳为六大类来讨论医疗系统的不同现有安全措施，包括雾计算、软件定义网络、区块链、轻量级密码学、同态加密与可搜索加密，以及机器学习。
