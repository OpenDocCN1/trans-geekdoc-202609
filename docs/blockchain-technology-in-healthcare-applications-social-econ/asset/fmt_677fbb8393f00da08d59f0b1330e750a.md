
技术的进步现在使得监测心率、体温和睡眠模式成为可能；利用 IoT 设备持续追踪运动；记录大脑活动。经典加密技术已非常成功地用于保护传输中和存储中的数据 [[44]](#C_016_c11.xhtml#r11_44)。然而，加密数据的过程也使其在计算中变得不可用。最近开发的全同态加密（FHE）技术在很大程度上改进了这一点。与需要在计算前解密数据的经典方法不同，同态方法允许数据同时被安全地存储或传输并用于计算 [[45]](#C_016_c11.xhtml#r11_45)。然而，FHE 对计算施加了严重的限制，无论是算术方面（例如，无法执行除法）还是计算方面（例如，乘法变得慢得多），导致传统统计算法不再适用。使用可搜索加密（SE），可以对存储在云服务器上的加密数据进行安全搜索。非对称 SE、对称 SE 和基于属性的 SE 是 SE 技术的示例 [[46]](#C_016_c11.xhtml#r11_46)。文献中提供了多种利用同态加密和 SE 保护基于 IoT 的医疗系统的安全方案。Almalki 等人 [[8]](#C_016_c11.xhtml#r11_8) 提出了 EPPDA：一种带有认证的高效隐私保护数据聚合方案，用于基于 IoT 的医疗应用。EPPDA 在数据聚合和转发过程中验证数据完整性，以便在验证和授权阶段尽早检测到虚假数据。在另一项工作中，Helen 等人 [[46]](#C_016_c11.xhtml#r11_46) 强调了用于 WBAN 系统的增强型基于 MAC 的安全延迟感知医疗监测系统（E-MHMS）。该解决方案确保了安全高效的数据聚合，其中数据分为三类：关键数据、近关键数据和普通数据。首先，基站（BS）向所有授权节点发送密钥。Mahender 等人 [[48]](#C_016_c11.xhtml#r11_48) 阐述了一项名为“托管免身份基聚合签加密方案以保障数据传输（EF-IDASC）”的新贡献，以确保医疗物联网（IoMT）上的隐私保护访问控制。[表 11.3](#C_016_c11.xhtml#t11_3) 总结了这些工作。

## 11.5 结论

基于 IoT 的医疗提供持续的健康监测，特别针对老年人和患有慢性病的患者，这使得医疗团队和/或卫生服务能够对患者做出更快、更准确的响应。确实，由于医疗设备和应用中存在多种设计缺陷且缺乏有效的安全措施，基于 IoT 的医疗行业正日益面临安全挑战和威胁。医疗系统安全不足的后果可能包括：某些健康记录可能包含地址、姓名和家庭详细信息，这些信息可被用于推断或向未经授权的用户泄露患者身份，从而导致隐私泄露。本概述旨在作为一个知识库，提供独特的见解，帮助用户和管理员以符合其总体目标、使命和愿景的方式定位自己及其组织，以取得卓越成果。
