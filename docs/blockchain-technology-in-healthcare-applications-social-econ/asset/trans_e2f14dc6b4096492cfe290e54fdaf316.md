
加密货币（如 `bitcoin` 和 `Ethereum`）的出现增加了人们对区块链和智能账本研究的兴趣。区块链技术以一种可靠且绝对的方式累积和共享分布式数据，无需中介即可进行数据共享。它不需要交易确认集中化 [[35](#C_018_c13.xhtml#r13_35), [36](#C_018_c13.xhtml#r13_36)]。在区块链中，透明性使得跨网络访问基于账本的交易变得更加简单；网络可以连接来自多个节点的不同算力，因此其计算速度极快 [[37](#C_018_c13.xhtml#r13_37)]。区块链包含各种技术和设施。简述如下。

*   **哈希密码学**：区块链使用 `SHA256` 哈希添加交易。这是由美国国家安全局（NSA）创建的，具有 64 位字符代码、单向加密、确定性函数、增强计算和雪崩效应以抵抗碰撞。哈希算法也需要是确定性的。
*   **分布式 P2P 网络**：跨多个用户分发和更新数据。交易通过网络传输。
*   **共识协议**：区块链网络拥有各自的共识协议，该协议决定允许哪些用户进行交易。
*   **不可变账本**：区块链网络记录所有交易，共享账本无法被第三方访问或修改。
*   **挖矿**：奖励由源自 `nonce` 值的哈希值决定，为了获得奖励，矿工必须拥有高算力。

区块链网络可以复制到另一个不同的位置，以便与学者、合作机构或其他相关组织（如保险提供商）共享医疗数据。区块链是一个由连接的计算机组成的网络，它们共享数据并确保其准确性、可靠性和一致性。因此，区块链可以在一个位置填充数据，并分发到同一网络上的另一个或多个额外位置。此外，这些新位置将数据传输到整个网络，最终允许位置访问分发给整个网络中每个人的最新数据。

## 13.3.1 区块链网络的类型

存在几个不同的区块链群组，每个群组都有其特征，反映了网络行为。就区块链的特性而言，Gautam 等人 [[38](#C_018_c13.xhtml#r13_38)] 描述了区块链的分类。区块链的类型枚举如下。

*   **公有区块链**：所有节点间保持交易透明。网络中的任何节点均可使用共识机制验证区块链交易。网络管理员无需授权即可允许该节点加入。此类网络内的节点能够以前所未有的水平进行通信与协作。`Bitcoin` 和 `Ethereum` 等加密货币即此类网络的示例 [[34](#C_018_c13.xhtml#r13_34)]。
*   **许可区块链**：该网络中的节点仅在获得组织事先授权后才被允许加入结构，该组织也控制其交易 [[34](#C_018_c13.xhtml#r13_34)]。由于访问该网络上的内容需要认证过程，因此提供了更高程度的保密性。Multichain Platform (MP) 是此类平台的一个示例 [[39](#C_018_c13.xhtml#r13_39)]。
*   **联盟区块链**：由于由一个群体管理且加入网络需要认证，因此与许可区块链共享部分特征。其特点是极少数验证节点可通过预定义功能验证交易。在此类网络中，验证交易需要选定节点间的相互同意，从而创建新区块并完成流程 [[40](#C_018_c13.xhtml#r13_40)]。

## 13.3.2 区块链中的有效性验证流程

区块链被用于许多算法实现中，其中算法（如 `proof-of-work (PoW)`）将区块链验证过程定义为挖矿 [[28](#C_018_c13.xhtml#r13_28)]。共识算法确定节点为验证区块必须遵循的规则。它遵循交易应执行的顺序，以确保验证节点从所有节点接收到满意的响应。区块可基于这些决定插入链中 [[40](#C_018_c13.xhtml#r13_40), [41](#C_018_c13.xhtml#r13_41)]。区块链已成为更可靠的网络，归功于旨在验证区块的共识协议。医疗区块链的分析需要以下提及的关键协议。

*   **PoW**：在此认证过程中，多个节点解决加密谜题（即矿工）。节点可通过找到解决方案来创建有效区块以进行交易并验证它。还值得注意的是，某些 `PoW` 实现（如 `Bitcoin`）会向获胜者提供奖励 [[28](#C_018_c13.xhtml#r13_28)]。在医疗场景中，它可用于检查有效交易。
*   **权益证明**：选择验证者时会考虑其在网络中的参与度。该节点将通过验证拥有更多代币的区块来确定区块的真实性 [[42](#C_018_c13.xhtml#r13_42), [43](#C_018_c13.xhtml#r13_43)]。这可以识别涉及的节点是医疗系统中的有效用户还是入侵者。
*   **实用拜占庭容错 (PBFT)**：该系统中的节点分为两类：客户端和服务端。`PBFT` 通过多个过程验证交易，例如客户端节点向提供商节点请求交易。服务提供商节点广播交易以决定是否接受。节点在获得服务端节点对交易的接受后广播就绪消息。在这种情况下，只要许多节点批准交易，它就会进入“确认警报”阶段；节点确认交易后，向其他节点发送消息以验证其行为，最后发送方收到响应，确认交易是否有效 [[43](#C_018_c13.xhtml#r13_43), [44](#C_018_c13.xhtml#r13_44)]。

## 13.3.3 面向医疗生态系统的区块链

在医疗行业，区块链的采用已分为多个阶段。在初始阶段，区块链可直接供医疗服务提供商访问；现有的医疗信息技术（IT）系统追踪并存储所有临床数据。区块链网络的应用程序接口（API）利用患者 ID 传输各种患者数据。智能合约允许在区块链系统中执行入账转移。每笔区块链网络上的交易均使用患者公共 ID（非个人信息）。不可变账本将区块链接在一起。然后，为每笔交易分配一个唯一标识符。因此，医疗服务提供商通过 API 发起挖矿过程或查询处理。区块数据库中可用的信息仅包括患者的非可识别特征，包括性别、年龄和疾病。通过分析临床数据可发现新见解。最后，患者若希望披露身份，也可选择与其医疗服务提供商共享私钥。这样，提供商即可访问患者数据，进而针对已识别症状提供护理或解决方案。任何没有患者私钥的人都无法访问数据，因此数据保持机密。
