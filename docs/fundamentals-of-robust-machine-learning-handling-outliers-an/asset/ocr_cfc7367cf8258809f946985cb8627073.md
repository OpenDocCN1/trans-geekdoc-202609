# 2.7 Least Squares Estimation (LSE)

We are now ready to examine the least squares method in a more formal setting using the proper notation. Consider the multiple linear model in matrix form as follows:

```
y = Xβ + ε, \\
(2.7.1)
```

where y = (y1, ..., yn)^T is a response vector, X is an n × (d + 1) design matrix of constants with an embedded column of 1’s, and ε = (ε1, ..., εn)^T is the error term. Here we assume ε ~ N(0, σ^2 I_n), the normal distribution with mean 0 and variance-covariance matrix σ^2 I_n. Regression parameters β = (β0, ..., βd)^T are the d + 1 coefficients of interest.

The solution to a multidimensional problem is no longer a line but rather a plane or hyperplane. An example of a two-variable regression model and its solution is illustrated in Figure 2.6. In this case, the slopes are β1 and β2, while the intercept on the y-axis is β0. The slopes represent the angle of the plane in each dimension. Beyond two dimensions, the plane becomes a hyperplane. For obvious reasons, the hyperplanes cannot be visualized; however, the same concepts apply.

We can write the L2 loss function in two different ways. The first uses matrix notation, as follows:

```
J(β) = (y - Xβ)^T (y - Xβ). \\
(2.7.2)
```

This is just the sum of the squares of the errors written in matrix notation. To obtain the least squares estimates, β^LS, we minimize this loss function by taking the derivative of J(β) w.r.t. β and setting it to 0, that is

```
\frac{\partial J(β)}{\partial β} = -2X^T (y - Xβ) = 0. \\
(2.7.3)
```

Then, it follows that

```
-X^T y + X^T X β = 0, \\
(2.7.4)
```
