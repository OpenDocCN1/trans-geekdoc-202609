One way to do this is to select two features from the dataset and plot only the outliers in that two-dimensional space. Note that any two features can be used as long as the outlier positions are spread out enough to identify them visually. These outlier positions then become the targets for the other anomaly detectors to hit so that their accuracy can be assessed. This is shown in Figure 11.15 in the top-left corner. After running auto-kNN, the 14 shaded dots show the positions of the outliers using features Alcohol and Malic Acid. The other three methods must hit those targets to be considered as accurate.

The first anomaly detector to be evaluated is MADmax. This approach requires no user intervention. The dataset is simply fed to the algorithm and it reports its findings. The results are shown in the top-right corner of Figure 11.15. A total of nine anomalies are detected, each one hitting one of the targets set up by auto-kNN (see black dots).
