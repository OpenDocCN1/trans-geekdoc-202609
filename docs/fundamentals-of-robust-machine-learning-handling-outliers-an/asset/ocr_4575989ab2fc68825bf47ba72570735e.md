that we seek through optimization. To obtain the largest margin, the term $2/||eta||_2$ is to be maximized. Alternatively, we can instead minimize $||eta||_2/2$, or equivalently minimize $||eta||_2^2/2$ (for mathematical convenience). However, minimizing this function would lead to the trivial solution $\beta = 0$ which sets the margins at infinity. We need to apply some constraints to obtain nontrivial results.

To formulate the optimization problem, let $y_i \in \{-1, 1\}$, $\beta = (\beta_1, \dots, \beta_d)^\top$, and call $\beta_0$ the bias. For logistic regression, we said that $\mathbf{x}_i$ belongs to Class 1 if

```
$(\mathbf{x}_i^\top \beta + \beta_0) > 0$
```

and Class 0 if

```
$(\mathbf{x}_i^\top \beta + \beta_0) < 0.$
```

Now, we insist on a larger margin such that $\mathbf{x}_i$ belongs to Class 1 only if

```
$(\mathbf{x}_i^\top \beta + \beta_0) > 1$
```

and Class 0 only if

```
$(\mathbf{x}_i^\top \beta + \beta_0) < -1.$
```

Instead of keeping track of two conditions, we could simply write that $\mathbf{x}_i$ is properly classified if

```
$y_i(\mathbf{x}_i^\top \beta + \beta_0) > 1.$
```

Otherwise it is improperly classified. The added constraint in choosing a suitable $\beta$ is that all the data be properly classified, which avoids the trivial solution.

The constrained optimization problem can be stated as

```
$\underset{\beta \in \mathbb{R}^d}{\text{minimize}} \frac{1}{2} ||\beta||^2 \text{ s.t. } y_i(\mathbf{x}_i^\top \beta + \beta_0) > 1, \forall i = 1, \dots, n.$ (8.10.2)
```
