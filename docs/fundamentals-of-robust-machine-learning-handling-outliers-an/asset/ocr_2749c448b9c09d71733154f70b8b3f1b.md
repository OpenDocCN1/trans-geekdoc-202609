In a (d + 1)-dimensional space, each estimate will have its own s.e. value. Least squares regression has a well-known formula for the **covariance matrix** given by

\(\text{Var}(\hat{\beta}^\text{LS}) = \sigma^2(\mathbf{X}^T\mathbf{X})^{-1}.\)
(3.6.2)

The parameter variances lie along the diagonal and their square root produces the standard errors as follows:

\(\text{s.e.}(\hat{\beta}^\text{LS}) = \sqrt{\text{diag}(\hat{\sigma}^2(\mathbf{X}^T\mathbf{X})^{-1})},\)
(3.6.3)

where the unbiased estimator of \(\sigma^2\) is given by

\(\hat{\sigma}^2 = \frac{1}{n - (d + 1)} \sum_{i=1}^n (r_i - \bar{r})^2.\)
(3.6.4)

Hence, the residuals are needed to obtain the standard errors.

There is an issue with this formulation when outliers are present. Specifically, the value of \(\hat{\sigma}^2\) will be inflated due to the fact that outliers will contribute large residuals to the sum and each one will be squared to increase their values even further.

In the case of log-cosh, a different approach is needed but with the same general formulation. For large \(n\), we treat the estimates as being normally distributed with

\(\text{Var}(\hat{\beta}^\text{LC}) = \nu^2(\mathbf{X}^T\mathbf{X})^{-1}\)
(3.6.5)

and then define the term \(\nu^2\) as follows (see Maronna et al. 2019)3:

\(\nu^2 = s^2 \frac{\text{E}[\psi_\text{LC}(r/s)]}{\text{E}[\psi'_\text{LC}(r/s)]^2}\)
(3.6.6)

which has an unbiased estimate that can be obtained by replacing expectations with averages

\(\hat{\nu}^2 = \hat{s}^2 \frac{\frac{1}{n} \sum \psi_\text{LC}(r_i/\hat{s})^2}{\left[\frac{1}{n} \sum \psi'_\text{LC}(r_i/\hat{s})\right]^2} \frac{n}{n - d - 1}.\)
(3.6.7)

In the above, the residuals are \(r_i = y_i - \mathbf{x}_i^T\hat{\beta}^\text{LC}\) and, to provide a robust estimate of \(\nu\), we estimate \(s\) using

\(\hat{s} = \text{MADN}(\mathbf{r}).\)
(3.6.8)

where the function MADN(x) was defined in Chapter 1, Eq. (1.4.6). To compute the terms under the summations, recall that

\(\psi_\text{LC}(x) = \rho'_\text{LC}(x) = \tanh(x)\)
(3.6.9)

and

\(\psi'_\text{LC}(x) = \rho''_\text{LC}(x) = \text{sech}^2(x).\)
(3.6.10)

These functions must be applied as required in Eq. (3.6.7). The s.e.’s are computed as the square root of the diagonal elements of the covariance matrix, \(\nu^2(\mathbf{X}^T\mathbf{X})^{-1}\).
