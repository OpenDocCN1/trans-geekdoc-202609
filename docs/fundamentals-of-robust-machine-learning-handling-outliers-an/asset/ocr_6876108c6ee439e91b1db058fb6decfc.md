The median is obtained using the $L_1$ loss function. The gradient function is

$L'_1(\theta) = - \sum_{i=1}^n \text{sgn}(x_i - \theta).$

To illustrate one of the problems with $L_1$, consider the data $x = (0, 3, 5, 7, 10)^T$. We seek the mean and the median using the $L_2$ and $L_1$ loss functions, respectively. By inspection, both the mean and median are 5. The loss functions have been plotted in Figure 2.8 along with the gradient functions. Note that the $L_2$ loss is continuous and smooth, whereas the $L_1$ loss is continuous but **piecewise linear**. This is further confirmed by the gradient plots where the $L_1$ gradient is composed of a series of steps while the $L_2$ gradient is linear.
