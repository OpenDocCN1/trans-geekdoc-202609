**Ans.:** The likelihood function is given by:

$L(r_1, r_2, \dots, r_n; \boldsymbol{\beta}) = \prod_{i=1}^n \frac{1}{2}e^{-|r_i|}.$ (2.5.16)

The negative log-likelihood expression is

$-\ell(r_1, r_2, \dots, r_n; \boldsymbol{\beta}) = n \log 2 + \sum_{i=1}^n |r_i|.$ (2.5.17)

The first term is constant for a given n which is ignored during minimization and this gives rise to the L1 loss function in terms of residuals:

$L_1 \text{ loss} = \sum_{i=1}^n |r_i|.$ (2.5.18)
