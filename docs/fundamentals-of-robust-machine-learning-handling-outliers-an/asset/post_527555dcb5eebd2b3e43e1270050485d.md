
Thus, we may define mixtures of two $d$-dimensional Gaussian distributions as

$$f_x(\mathbf{x}) = \pi_1 \mathcal{N}_d(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1) + \pi_2 \mathcal{N}_d(\boldsymbol{\mu}_2, \boldsymbol{\Sigma}_2).$$ (1.8.3)

In the rest of this chapter, we will assume that the covariance matrix takes the simplified form of $\boldsymbol{\Sigma} = \sigma^2 \mathbf{I}_d$, where $\mathbf{I}_d$ is a $d \times d$ identity matrix. This is suitable for circular or spherically shaped distributions of data. Then, for $K = 2$ and an arbitrary $d$,

$$f_x(\mathbf{x}) = \pi_1 \mathcal{N}_d(\boldsymbol{\mu}_1, \sigma_1^2 \mathbf{I}_d) + \pi_2 \mathcal{N}_d(\boldsymbol{\mu}_2, \sigma_2^2 \mathbf{I}_d).$$ (1.8.4)

In the case when $K = 2$ and $d = 2$, we have

$$f_x(\mathbf{x}) = \pi_1 \mathcal{N}_2(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1) + \pi_2 \mathcal{N}_2(\boldsymbol{\mu}_2, \boldsymbol{\Sigma}_2).$$ (1.8.5)

where $\pi_1 + \pi_2 = 1, \boldsymbol{\mu}_1 = (\mu_{11}, \mu_{12})^\top, \boldsymbol{\mu}_2 = (\mu_{21}, \mu_{22})^\top$,

$$\boldsymbol{\Sigma}_1 = \sigma_1^2 \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} \text{ and } \boldsymbol{\Sigma}_2 = \sigma_2^2 \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}.$$

For notational convenience, we can define a set $\Theta = \{\pi_1, \pi_2, \boldsymbol{\mu}_1, \boldsymbol{\mu}_2, \sigma_1, \sigma_2\}$ that contains all the true parameters. Data can be generated from the probability distribution of this two-dimensional Gaussian mixture in the same manner as described for the one-dimensional case. Based on the data, we can estimate the parameters of the mixture to reconstruct the distribution. When we compute these parameters, we will use $\hat{\Theta} = \{\hat{\pi}_1, \hat{\pi}_2, \hat{\boldsymbol{\mu}}_1, \hat{\boldsymbol{\mu}}_2, \hat{\sigma}_1, \hat{\sigma}_2\}$, where the "hat" represents an estimate of each parameter. This would constitute the **model** of the distribution.

Assume we can identify the two clusters and the points belonging to each one using some clustering algorithm. ## 1.9 Clustering Algorithms

We have already described a Gaussian mixture method of generating data and a generic Lloyd-style iteration loop to create clusters. We now examine two ways to implement Algorithm 1.1. Once we choose a distance measure, a cost function and a centering criteria, the generic algorithm becomes a specific algorithm.

### 1.9.1 k-Means Clustering

The first approach is called k-means clustering. In phase 1, points are assigned to their closest center based on an L2 distance measure. Each distance is computed as follows:

```
distance(i,j) = \|x^{(i)} - \mu^{(j)}\|_2^2
= (x_1^{(i)} - \mu_1^{(j)})^2 + (x_2^{(i)} - \mu_2^{(j)})^2 ... (x_d^{(i)} - \mu_d^{(j)})^2,
```

where \(x^{(i)}\) is the \(i\)th observation of \(X\) and \(\mu^{(j)}\) is the \(j\)th center out of \(K\) possible centers. Then each of the \(x^{(i)}\), \(i = 1, \dots, n\), is assigned to the closest \(\mu^{(j)}\), \(j = 1, \dots, K\) based on the distance formula. In the second stage, the *centroids* of the clusters are computed using the points assigned to each cluster for all \(K\) clusters. This is simply the column-wise mean of the data points assigned to each cluster,

\(\mu^{(j)} = \text{mean } (C_j) \text{ for all } j = 1, \dots, K.\)

In the above, \(C_j\) is the cluster matrix for cluster \(j\).

The cost is computed as the total sum of all distances between data points inside each cluster to their respective cluster centers for all clusters:

\(\text{cost} = \sum_{j=1}^K \sum_{i \in C_j} \|x^{(i)} - \mu^{(j)}\|_2^2.\) (1.9.1)

In the above, \(C_j\) is the set of row numbers of \(X\).

The old and new costs are compared relative to a small value, \(\varepsilon\), to determine convergence as follows:

\(|\text{cost}_{\text{new}} - \text{cost}_{\text{old}}| < \varepsilon.\) (1.9.2)

The two-phase loop continues until the convergence criterion is satisfied and none of the centers change in two consecutive loops.

**Exercise:** Let \(x^{(i)}\) be the \(i\)th observation of matrix \(X \in \mathbb{R}^{60 \times 2}\) given by

\(X = \begin{pmatrix} 1 & 2 \\ 1 & 4 \\ \vdots & \vdots \\ 2 & 3 \end{pmatrix}.\)

Only the 1st, 2nd, and 60th rows of the matrix are shown above. Let cluster \(C_1\) consist of only those three points, specifically \(x^{(1)}\), \(x^{(2)}\), and \(x^{(60)}\). By our notation, \(C_1 = \{1, 2, 60\}\). What is the cluster centroid, which we denote by \(\mu^{(1)}\)?

**Ans.:** The data points in \(C_1\) are \(x^{(1)} = (1, 2)^\top\), \(x^{(2)} = (1, 4)^\top\), and \(x^{(60)} = (2, 3)^\top\). The centroid is the coordinate-wise average. Therefore, the centroid is \(\mu^{(1)} = ((1 + 1 + 2)/3, (2 + 4 + 3)/3)^\top = (4/3, 3)^\top\).

**Exercise:** Let \(X \in \mathbb{R}^{60 \times 2}\) be defined as above. What is the \(L_2\) distance from \(x^{(2)}\) to a cluster center \(\mu^{(1)} = (4/3, 3)^\top\)?

\(\text{distance}(2, 1) = \|x^{(2)} - \mu^{(1)}\|_2^2 = (x_1^{(2)} - \mu_1^{(1)})^2 + (x_2^{(2)} - \mu_2^{(1)})^2.\)

### 1.9.2 k-Medians Clustering

One problem with k-means clustering is that it is not robust to outliers. This issue will be highlighted in sections to follow, but there are many clustering problems that contain outliers and they will disrupt the ability to obtain acceptable results using k-means. A logical alternative is to use k-medians clustering which employs different distance, cost, and center calculations. The distance is typically given by the Manhattan distance (although Euclidean distance can also be used) as follows:

```
\(\text{distance}(i,j) = \| \boldsymbol{x}^{(i)} - \boldsymbol{\mu}^{(i)} \|_1\)
\(= |x_1^{(i)} - \mu_1^{(i)}| + |x_2^{(i)} - \mu_2^{(i)}| + \dots + |x_d^{(i)} - \mu_d^{(i)}|.\) (1.9.3)
```

This \(L_1\) distance measure is used to determine the assignment of observations to clusters. Although this is typically used in k-medians, the \(L_2\) distance is also suitable for this purpose. The reason is that distance is a relative measure here so either of the two options may be used. What is crucial for robustness is the computation of the centers. After assignment, the centers are subsequently determined as the column-wise medians of the observations in each cluster:

```
\(\boldsymbol{\mu}^{(i)} = \text{median}(\boldsymbol{C}_j) \quad \forall j = 1, \dots, K,\)
```

where matrix \(\boldsymbol{C}_j\) contains the subset of rows of \(\boldsymbol{X}\) that belong in cluster \(j\).

The cost is computed as follows:

```
\(\text{cost} = \sum_{j=1}^K \sum_{\boldsymbol{i} \in \boldsymbol{C}_j} \| \boldsymbol{x}^{(i)} - \boldsymbol{\mu}^{(i)} \|_1.\) (1.9.4)
```

The use of the median for center computation is what robustifies the algorithm. The centers are no longer controlled by outliers and reasonable values of centers that truly represent each each cluster will be found using this approach. To summarize, both the cost and distance measures of k-means can be used in the k-medians approach, so long as the centers are computed using the median.
