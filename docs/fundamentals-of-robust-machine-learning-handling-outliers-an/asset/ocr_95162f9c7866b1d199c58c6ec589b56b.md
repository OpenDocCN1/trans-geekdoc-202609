# 2.10.2 Comparison with LSE and LAD

We compare the three methods of estimation, namely, LSE, LAD, and Huber’s method, on the Belgium telephone dataset. The estimates are provided in Table 2.2. For Huber, the optimal choice of δ is data dependent as mentioned earlier. In this case, the optimal value is δ = 0.269. The results of Huber’s method and LAD are quite similar and both are quite different from LSE, as expected.

To gain a better understanding of the effect of δ, consider the plot of the linear regression results in Figure 2.13. In this case, 100 different values of δ were selected between 0 and 100. The resulting 100 lines produced by Huber shade the region bounded by LSE and LAD. This is expected because, at one extreme, Huber’s method reduces to LSE and, at the other extreme, it becomes LAD. Again, δ is data dependent but is usually set to a default value of δ = 1.345 in practice.
