# **Algorithm 8.1** Cross-entropy logistic regression (CELR).

+   1: Input: training dataset X, y; number of iterations (T); learning rate (ℓ).
+   2: Set n=number of observations, d=number of parameters.
+   3: Set t=0. Initialize β^(0) to small nonzero values.
+   4: while t < T do
+   5: Compute loss function:
+      J^CE(β) = - Σ^n_{i=1} [yi log(pi) + (1 - yi) log(1 - pi)]
+   6: for j = 0 to d do
+   7: Compute gradient of the loss w.r.t. βj:
+      ∂J^CE(β)/∂βj = Σ^n_{i=1} (yi - pi)(-xij)
+   8: Update estimate: βj^((t+1)) = βj^(t) - ℓ × ∂J^CE(β)/∂βj
+   9: end for
+   10: Update iteration: t = t + 1
+   11: end while
+   12: Output: model β^CE

# **Algorithm 8.2** log-cosh logistic regression (LCLR).

+   1: Input: training dataset X, y; number of iterations (T); learning rate (ℓ).
+   2: Set n=number of observations, d=number of parameters.
+   3: Set t=0. Initialize β^(0) to small non-zero values.
+   4: while t < T do
+   5: Compute loss function: J^LC(β) = 1/a Σ^n_{i=1} log(cosh(a(yi - pi)))
+   6: for j = 0 to d do
+   7: Compute gradient of the loss w.r.t. βj:
+      ∂J^LC(β)/∂βj = Σ^n_{i=1} tanh(a(yi - pi))pi(1 - pi)(-xij)
+   8: Update estimate: βj^((t+1)) = βj^(t) - ℓ × ∂J^LC(β)/∂βj
+   9: end for
+   10: Update iteration: t = t + 1
+   11: end while
+   12: Output: model β^LC
