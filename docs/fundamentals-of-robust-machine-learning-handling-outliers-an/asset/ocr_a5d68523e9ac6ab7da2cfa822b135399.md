```
logcosh = lambda x: np.logaddexp(x, -x)-np.log(2)
def SMRQ(b):
    beta = b
    ri = y-np.matmul(X,beta)
    LCsum = np.sum((1/(2*a)) *logcosh(a*ri)+
    (tau-1/2)*ri)

    return LCsum
```
