# 7.7 Selection of Robustness Coefficient

We now address the issue of selecting the robustness coefficient, \(a\), in detail. We saw in Chapter 3 that this factor controls the steepness of the slope of the \(\tanh(ax)\) function as it crosses the origin and the smoothness around the kink region of the loss term \(\frac{1}{a} \log(\cosh(ace))\). As \(a \rightarrow 100\), the function approaches the \(L_1\) loss term. The same applies to the quantile loss term for exactly the same reasons. The difference here is that we need to select the robustness coefficient to remove the crossing problem while at the same time keeping the errors as small as possible.
