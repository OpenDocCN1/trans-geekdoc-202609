Finally, in the Huber case, we use

$J^{H\text{-LASSO}}(\beta) = \sum_{i=1}^n \rho_H(r_i) + \lambda \sum_{j=1}^d |\beta_j|, \qquad (5.4.3)$

where \(\rho_H(r_i)\) was defined earlier in Eq. (5.3.5).

**Exercise:** In a linear regression problem, let \(d = 2\). The two parameters of interest are \(\beta_1\) and \(\beta_2\). Write the LASSO penalty function using these two parameters with a constraint \(c\) applied.

**Ans.:** The expanded form of the LASSO penalty is

\(P(\beta) = |\beta_1| + |\beta_2| \le c.\)

For a two-dimensional problem, the constrained optimization problem of Eq. (5.2.3) can be written as

\(\text{minimize}_{\beta \in \mathbb{R}^3} \sum_{i=1}^n \rho(\beta) \quad \text{subject to } |\beta_1| + |\beta_2| \le c. \qquad (5.4.4)\)

This implies that as \(c\) decreases (which is equivalent to \(\lambda\) increasing), the two parameters are constrained to live in a tighter and tighter *diamond* around the origin. Therefore, the parameters will shrink in value as the constraint \(c\) is made smaller.

+   1) subtract a value until it reaches 0, or
