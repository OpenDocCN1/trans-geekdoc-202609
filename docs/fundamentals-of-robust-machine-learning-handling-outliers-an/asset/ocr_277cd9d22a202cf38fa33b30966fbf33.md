The entire sequence of operations will now be described for the neural network of Figure 9.5. In the description to follow, we will use _j_ as the index for the input (two inputs), _k_ as the index for hidden units (four units), and _i_ for the row index of the training set (_n_ rows). Consider the case when we apply input vector \(x_i = (x_{i1}, x_{i2})^T\) with a known response \(y_i\). In forward propagation, the following four steps are executed.

Step 1: First, the input values are multiplied by a weight matrix **_W_** and the bias vector **_b_** is added to produce \(z_i\) as follows:

```
\(z_i = Wx_i + b,\) \\
(9.5.1) \\
where \\
\(z_i = \begin{bmatrix} z_{i1} \\ z_{i2} \\ z_{i3} \\ z_{i4} \end{bmatrix}, W = \begin{bmatrix} w_{11} & w_{21} \\ w_{12} & w_{22} \\ w_{13} & w_{23} \\ w_{14} & w_{24} \end{bmatrix} \text{ and } b = \begin{bmatrix} b_1 \\ b_2 \\ b_3 \\ b_4 \end{bmatrix}.\)
```

Step 2: The resulting vector \(z_i\) is “activated” with relu to produce vector \(a_i\) as follows:

```
\(a_i = relu(z_i).\) \\
(9.5.2)
```

Step 3: To produce the raw output, \(z_{\text{out},i}\), we simply take the dot product of \(a_i = (a_{i1}, a_{i2}, a_{i3}, a_{i4})^T\) and \(w = (w_1, w_2, w_3, w_4)^T\) and add the bias \(b_0\) as follows:

```
\(z_{\text{out},i} = w^T a_i + b_0 = w_1 a_{i1} + w_2 a_{i2} + w_3 a_{i3} + w_4 a_{i4} + b_0.\) \\
(9.5.3)
```

Step 4: The raw output is passed through the sigmoid activation function to produce \(p_i\) as follows:

```
\(p_i = \text{sigmoid}(z_{\text{out},i}) = \frac{1}{1 + \exp(-z_{\text{out},i})}.\) \\
(9.5.4)
```

# 9.5.2 Backward Propagation

The procedure used in backward propagation is somewhat more elaborate than forward propagation but it is conceptually straightforward. Initially, the value of the predicted output, \(p_i\), produced by forward propagation, may deviate considerably from the target value of \(y_i\). A loss function, defined with \(y_i\) and \(p_i\), is minimized to produce the final model by adjusting the weights and biases in the entire network using gradient descent.

To adjust the parameter values, we must compute the gradients of the loss function relative to all 17 parameters of the network and then apply one step of gradient descent.
