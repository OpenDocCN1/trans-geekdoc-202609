```
SELECT region, SUM(amount_spent) AS regional_sales
FROM transaction_records
JOIN buyer_info ON transaction_records.buyer_id = buyer_info.buyer_id
GROUP BY region;
```

This query aggregates sales data by buyer region, offering insights into regional sales trends and performance.
