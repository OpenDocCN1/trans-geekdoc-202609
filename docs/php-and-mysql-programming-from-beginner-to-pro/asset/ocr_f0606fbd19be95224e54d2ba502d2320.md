# Illustrative Example of a Structured Log Entry in JSON Format:

```
{
    "time": "2021-09-01T12:00:00Z",
    "severity": "ERROR",
    "detail": "Failed to connect to database",
    "component": "authentication-module",
    "errorInfo": {
      "errorCode": "DB_FAIL_CONNECT",
      "message": "Connection attempt failed after 10 seconds"
    },
    "userInfo": {
      "userID": "12345",
      "accessLevel": "administrator"
    }
  }
```

This structured log entry exemplifies how information can be organized in a JSON format, offering clarity and ease of analysis for various log attributes.
