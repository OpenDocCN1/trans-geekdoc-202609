# Fine-Tuning OPcache for Peak Performance

To fully exploit OPcache's capabilities, careful configuration is crucial to align with the specific demands of the application. Important configuration directives include:

+   * opcache.enable: This switch activates OPcache, which should be set to 1 for optimal performance.

+   * opcache.memory_consumption: This parameter specifies the memory allocated for storing compiled opcodes, tailored to fit the application's scale and complexity.

+   * opcache.max_accelerated_files: This limit on the number of cacheable scripts should be set high enough to encompass the application's entire script inventory.

```
opcache.enable=1
opcache.memory_consumption=128
opcache.max_accelerated_files=10000
```

This configuration activates OPcache with 128 MB of memory dedicated to opcode caching, allowing up to 10,000 files to be cached, accommodating the needs of most applications.
