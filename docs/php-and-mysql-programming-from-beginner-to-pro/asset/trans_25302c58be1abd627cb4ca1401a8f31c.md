
SELECT * FROM products;

要有条件地从同一表中选择性查询 'name' 和 'price'：

```
SELECT name, price FROM products WHERE category = 'Electronics';
```

### INSERT 语句

INSERT INTO 命令对于将新记录插入数据库表至关重要，它指定目标表、要填充的列以及相应的值，从而促进新数据的加入。

- 语法要点：

```
INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);
```

- 实际应用：要向 'products' 表追加一个新产品：

```
INSERT INTO products (name, price) VALUES ('Smartphone', 599);
```

### UPDATE 语句

UPDATE 命令用于修改表中现有数据，允许指定表、要更新的列、新值以及条件，以准确定位待修改的记录。

- 基本语法：

```
UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

- 实际应用：要修改 id = 5 的产品价格：

```
UPDATE products SET price = 399 WHERE id = 5;
```

### DELETE 语句

使用 DELETE FROM 命令可以从表中删除记录。鉴于其可能不可逆地消除数据，审慎使用该命令至关重要。

- 语法入门：

```
DELETE FROM table_name WHERE condition;
```

- 实际应用：要从 'products' 表中删除 id = 5 的产品：

```
DELETE FROM products WHERE id = 5;
```

### SQL 命令执行的战略考量

- 维护数据完整性：执行 INSERT、UPDATE 或 DELETE 操作时，需要留意其对数据库关系完整性的影响，尤其是在互联的数据结构中。

- 确保查询效率：复杂的 SELECT 操作（尤其是涉及大量数据或多个关系连接的操作）可能会影响数据库性能。战略性索引和查询优化对于维持运营效率至关重要。

- 缓解注入风险：SQL 命令（尤其是整合用户输入的命令）易受 SQL 注入威胁，因此有必要采用预处理语句或存储过程等预防措施来加强安全性。

### 结论

对基本 SQL 命令（SELECT、INSERT、UPDATE 和 DELETE）的全面掌握对于数据库操作和管理不可或缺。这些基本操作为数据库从业人员提供了高效查询、插入、修改和删除数据的手段，充分发挥关系型数据库的潜力，以支撑现代软件生态系统中不可或缺的强大数据管理实践。

## 第五章

## 集成 PHP 和 MySQL

## 使用 PHP 连接 MySQL 数据库

在 PHP 与 MySQL 数据库之间建立连接是 Web 开发者的关键技能，有助于构建依赖数据库交互的动态网站和应用程序。PHP 因其与 MySQL 的兼容性而闻名，提供了多种方法来连接、查询和管理 MySQL 数据库中的数据。本文阐述了使用 PHP 连接 MySQL 数据库的步骤和推荐做法，以确保安全高效的数据通信。

### 必备准备

在通过 PHP 启动与 MySQL 数据库的连接之前，必须具备某些先决条件：

- MySQL 服务器实例：托管目标数据库的正在运行的 MySQL 服务器。
- PHP 环境：配置得当的 PHP 环境，理想情况下更新到最新版本以获得增强的安全性和功能。
- 访问凭据：所需的访问详细信息，包括数据库名称、主机地址（通常为 localhost）以及具有必要访问权限的用户凭据（用户名和密码）。

### PHP 的 MySQL 连接扩展

PHP 提供了多种用于 MySQL 数据库交互的扩展，其中 MySQLi（MySQL 改进版）和 PDO（PHP 数据对象）是主要选择。每种都为数据库操作提供了一组独特的功能，但它们在应用和范围上有所不同：

- MySQLi：专为 MySQL 数据库设计，MySQLi 支持过程式和面向对象编程范式，提供全面的 MySQL 功能，如预处理语句和事务支持。

- PDO：PDO 为各种数据库类型建立统一的访问层，便于采用面向对象方法。它特别适用于可能需要与 MySQL 以外的不同数据库系统交互的应用程序。

### 连接建立过程

### 使用 MySQLi

- 过程式方法：

```
$connection = mysqli_connect("localhost", "username", "password", "databaseName");

if (!$connection) {
    die("Connection error: " . mysqli_connect_error());
}

echo "Successfully connected";
```

- 面向对象方法：

```php
$mysqli = new mysqli("localhost", "username", "password", "databaseName");

if ($mysqli->connect_error) {
    die("Connection error: " . $mysqli->connect_error);
}

echo "Successfully connected";
```

### 使用 PDO

```php
try {
    $pdo = new PDO("mysql:host=localhost;dbname=databaseName", "username", "password");
    // Set PDO error mode
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Successfully connected";
} catch(PDOException $e) {
    die("Connection error: " . $e->getMessage());
}
```

### 安全连接实践

- 采用预处理语句：在 MySQLi 和 PDO 中都使用预处理语句，可通过将数据与 SQL 命令分隔来降低 SQL 注入风险。

- 实施错误管理：建立全面的错误处理来有效解决连接问题，避免泄露敏感信息。

- 适当终止连接：使用后明确结束数据库连接以节省系统资源。

- 安全凭据存储：将数据库凭据存储在安全的环境变量或配置文件中，与主代码库明确分开。

- 保持更新：确保 PHP 环境和 MySQL 服务器持续更新，以纳入最新的安全增强和功能改进。

### 结论

将 MySQL 数据库与 PHP 相连接是构建动态、内容丰富的 Web 平台的基本功能。无论选择用于 MySQL 特定功能的 MySQLi，还是用于适应多种数据库系统的 PDO，掌握 PHP 中的数据库连接都是基础。遵循安全高效的数据库通信既定最佳实践至关重要，这为开发复杂的数据驱动型 Web 应用程序奠定了基础。

### 从 PHP 执行数据库操作

通过 PHP 执行数据库任务是构建动态 Web 平台的基石活动，能够实现数据的无缝管理和操作。PHP 与多种数据库系统的全面兼容性使开发者能够执行数据检索、插入、修改和删除等多种数据库功能，这对于实时数据驱动型应用程序至关重要。对于 Web 开发者来说，掌握以高效安全方式在 PHP 中执行这些操作的细微差别至关重要。

### 启动与数据库的连接

通过 PHP 进行数据库操作的基础步骤涉及与目标数据库建立稳健连接。PHP 提供了多种数据库连接方式，其中 PDO（PHP 数据对象）和 MySQLi（MySQL 改进版）是 MySQL 数据库的主要选择。每种都为数据库交互提供了一系列功能，但在方法和数据库驱动程序支持方面有所不同。

- PDO：提供与数据库无关的接口，促进代码在各种数据库系统间的适应性。它因支持预处理语句和事务而受到赞誉，增强了数据库操作的安全性和稳定性。

- MySQLi：专为 MySQL 数据库设计，MySQLi 提供过程式和面向对象接口，与 PDO 类似，支持预处理语句和事务。

### 查询执行

在建立稳定的数据库连接后，PHP 可以执行 SQL 查询以与数据库交互。在 PDO 和 MySQLi 之间的选择会影响准备、执行查询和处理结果数据的方法。
