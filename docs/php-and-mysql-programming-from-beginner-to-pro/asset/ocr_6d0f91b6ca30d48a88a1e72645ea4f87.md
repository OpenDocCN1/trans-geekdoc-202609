Here, `Configuration` is a Singleton class that centralizes access to configuration settings, preventing multiple instances and ensuring consistent access to settings throughout the application.

# Factory Pattern for Dynamic Object Creation

The Factory pattern is adept at dynamically creating objects of various types based on specified criteria, such as user roles, without exposing the instantiation logic to the client code.

```
interface User
{
    public function getRole():
}

class Administrator implements User
{
    public function getRole() { return 'administrator'; }
}

class GuestUser implements User
{
    public function getRole() { return 'guest'; }
}

class RegisteredUser implements User
{
    public function getRole() { return 'registered'; }
}

class UserFactory
{
    public static function buildUser(role)
    {
        switch (role) {
            case 'administrator':
                return new Administrator();
            case 'registered':
                return new RegisteredUser();
            default:
                return new GuestUser();
        }
    }
}

$user = UserFactory::buildUser("administrator");
```
