# Encryption Paradigms for Data Protection

Encryption is the process of converting intelligible data into a coded format using cryptographic algorithms and keys, thereby restricting access to authorized individuals possessing the decryption key.

+   • Symmetric Encryption: This encryption model uses a singular key for both the encryption and decryption processes, offering a streamlined and efficient mechanism for securing substantial data sets. The Advanced Encryption Standard (AES) is commonly utilized for its optimal blend of security and operational efficiency.

```
from Crypto.Cipher import AES
import base64

def secure_encrypt(plaintext, encryption_key):
    cipher = AES.new(encryption_key, AES.MODE_ECB)
    return base64.b64encode(cipher.encrypt(plaintext))
```
