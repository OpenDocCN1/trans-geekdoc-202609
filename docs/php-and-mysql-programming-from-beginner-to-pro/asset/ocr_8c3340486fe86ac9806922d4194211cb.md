+   - SELECT Queries: Employed for data extraction from the database, with options to format the fetched data as associative arrays or objects based on application requirements.

+   - INSERT Queries: Enable the addition of new entries into the database, with both PDO and MySQLi offering mechanisms to ascertain the ID of the most recently inserted record.

+   - UPDATE Queries: Facilitate the modification of existing database records, necessitating precise conditions to accurately target the intended data entries.

+   - DELETE Queries: Used for eliminating records from the database, where the specificity of the condition is vital to prevent unintended data loss.

# Leveraging Prepared Statements

Prepared statements stand out for their security benefits, notably in thwarting SQL injection threats, by distinctly segregating SQL commands from the data. This separation ensures user input is strictly interpreted as data.

+   - In PDO: Prepared statements are initiated with the `prepare()` method, executed with `execute()`, with data binding to placeholders via `bindParam()` or directly through `execute()`.

+   - In MySQLi: Prepared statements follow a similar process, initiated with `prepare()`, executed with `execute()`, and data binding via `bind_param()`.
