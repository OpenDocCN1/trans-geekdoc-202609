```
function fetchFileContent($file) {
    $handle = fopen($file, 'rb');
    while (!feof($handle)) {
        yield fgets($handle);
    }
    fclose($handle);
}
```

This generator function exemplifies an efficient approach to processing large files, conserving memory by yielding content line by line.
