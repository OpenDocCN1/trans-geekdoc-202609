# Writing custom PHP extensions in C

Developing custom PHP extensions using C is a potent method to augment PHP's functionality, offering capabilities beyond its standard library, or optimizing for higher efficiency and speed. Given PHP's interpreted nature, it may not always deliver the desired performance for compute-heavy tasks. Introducing custom extensions crafted in C can lead to significant performance gains, as compiled C code operates at a lower level, closer to the hardware.
