```
+   * Common Table Expressions (CTEs) Enhancement: MySQL 8's embrace of CTEs significantly boosts the readability and manageability of complex SQL queries by permitting the definition of temporary result sets that can be referenced within SELECT, INSERT, UPDATE, or DELETE statements.

```
```sql
WITH recursive_cte AS (
SELECT 1 as n
UNION ALL
SELECT n + 1 FROM recursive_cte WHERE n < 10
)
SELECT * FROM recursive_cte;
```

```
+   * JSON Table Functions Introduction: The advent of JSON table functions in MySQL 8 markedly improves the handling and querying of JSON data, enabling JSON documents to be interacted with as relational tables, simplifying data manipulation.
```

SELECT name, age
FROM JSON_TABLE('{"data": [{"name": "Charlie", "age": 22}, {"name": "Dana", "age": 34}]}',
'$.data[*]' COLUMNS (name VARCHAR(50) PATH '$.name', age INT PATH '$.age'))
AS json_table;
