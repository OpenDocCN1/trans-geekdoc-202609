# CSRF Tokens: Mitigating Unauthorized Actions

To defend against Cross-Site Request Forgery (CSRF), incorporating a unique, unpredictable token within forms that are validated server-side upon submission is a standard practice, ensuring the request originates from the intended user.

Example:

```
// Implementing a CSRF token in a form
echo '<input type="hidden" name="token" value="" . $_SESSION['token'] . "">';
```

# Implementing CAPTCHAs: Distinguishing Between Humans and Bots

CAPTCHAs help differentiate human users from automated scripts, protecting forms from spam and automated exploitation, particularly in sensitive forms like registrations and logins.
