```
PHP_FUNCTION(sample_function)
{
    char *param = NULL;
    size_t param_len;

    if (zend_parse_parameters(ZEND_NUM_ARGS(), "s", &param, &param_len) == FAILURE)
        return;
}

php_printf("Received parameter: %s\n", param);
RETURN_TRUE;
}
```

3. Extension Initialization: Every extension requires an initialization function `PHP_MINIT_FUNCTION(extension_name)`, where you can register the extension's functions and any provided classes or constants.

```
PHP_MINIT_FUNCTION(example_extension)
{
    REGISTER_STRING_CONSTANT("EXTENSION_VERSION", "1.0", CONST_CS | CONST_PERSISTENT);
    return SUCCESS;
}
```
