# Sanitizing Inputs: Neutralizing Harmful Data

Sanitization involves cleaning input data to remove or encode unwanted characters, significantly reducing the risk of injection attacks and ensuring data can be safely used or displayed.

Example:

```
// Sanitizing a string in PHP
$safeText = filter_var($userText, FILTER_SANITIZE_SPECIAL_CHARS);
```
