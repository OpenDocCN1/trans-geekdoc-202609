# Optimizations in Server and Networking

+   1. Leveraging a CDN: Utilize a Content Delivery Network (CDN) to distribute and cache assets across various global locations, minimizing latency by serving assets from a server proximal to the user.

+   2. Adopting Modern HTTP Protocols: Embrace the latest HTTP protocols that support features like multiplexing, header compression, and prioritization, enhancing asset delivery efficiency.
