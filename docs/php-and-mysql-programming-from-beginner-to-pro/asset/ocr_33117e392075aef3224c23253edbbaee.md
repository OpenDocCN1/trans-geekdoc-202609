# Crafting a Basic PHP Extension

+   1. Starting with a Skeleton: Utilize the `ext_skel` script from the PHP source to generate a basic framework for your extension. This script sets up a foundational structure, including necessary configuration files and a template C file.

```
./ext_skel --extname=example_extension
```

+   2. Function Implementation: The essence of your extension lies in its functions. PHP functions in C are introduced using the `PHP_FUNCTION` macro, followed by the actual function code. Parameters are extracted via the `ZEND_PARSE_PARAMETERS` API, and return values are assigned using `RETURN_` macros.
