# Core Principles of AJAX

AJAX enables web apps to send and retrieve data from a server asynchronously, allowing for real-time content updates without reloading the entire page.

+   1. XMLHttpRequest (XHR) Usage: This traditional method for AJAX calls interacts with servers to fetch or send data in various formats, including JSON, XML, and plain text.

```
// Basic XMLHttpRequest example
var xhr = new XMLHttpRequest();
xhr.open("GET", "data-source.php", true);
xhr.onload = function () {
    if (xhr.status == 200) {
        document.getElementById("container").innerHTML = xhr.responseText;
    }
};
xhr.send();
```

+   2. Utilizing the Fetch API: The Fetch API offers a modern, promise-based alternative to XHR, making it simpler to perform asynchronous HTTP requests with improved syntax and error handling.
