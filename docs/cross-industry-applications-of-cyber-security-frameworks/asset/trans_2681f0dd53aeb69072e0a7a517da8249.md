

# 网络安全：法律框架与国际文书

## 威胁态势

网络攻击者主要攻击政府网站、金融系统、新闻媒体网站、军事网络以及公共基础设施系统。这些攻击者的动机范围从身份盗窃、知识产权盗窃和金融欺诈到关键基础设施攻击。（Mohammad and Gair, 2015）

在计算环境下，网络安全包含网络安全和物理安全，企业利用两者来防范未经授权的数据控制访问和其他计算机化系统访问。旨在维护数据机密性、完整性和可用性的安全，是网络安全的一个子集。（Seema et.al., 2018）

安全是网络安全的主要问题，必须建立在适当的政策基础上并严格执行。这是云计算面临的一大挑战，涉及刑事诉讼管辖权的问题，这反过来又给治理和领土管辖权带来了诸多挑战。有效的高质量安全水平将确保这些新服务被接受。（Joshi and Singh, 2013）

## 目的

本章的主要目的如下：

1.  探讨国家和国际层面为应对网络犯罪而制定的法律框架，因为网络犯罪已成为全球性问题。
2.  认识实施网络犯罪的各种动因。
3.  分析国家犯罪记录局记录和报告的选定数据。
4.  考察印度选定法律在解决网络犯罪问题方面的成效。

## 关于网络安全的国际文书

《2001年网络犯罪公约》（即《布达佩斯公约》）是首个关于网络犯罪的公约，旨在解决与网络犯罪相关的问题。它涉及改进调查程序、协调国家法律以及促进此方面的国际合作。截至2020年，该条约有67个签署国。但印度尽管致力于建设“数字印度”，尚未签署或批准该条约。欧洲委员会（COE）于2001年联合47个国家推出了首个关于网络犯罪的国际公约，美国、日本和连同46个成员国一同签署。然而，仅有25个国家批准了该公约。（Ahmed et.al., 2008）

亚太经合组织（APEC）电信与工作组（TEL）于2002年8月发布了应对网络安全的网络安全战略，后于2005年纳入《利马宣言》。该宣言提出了网络安全相关问题，并重申建立计算机应急响应小组。（Ajayi, 2016）

由34个国家组成的经济合作与发展组织（OECD）发布了《信息系统和网络安全指南：走向安全文化》，以确保社会的网络安全。

英联邦于2002年提交了一部根据《2001年网络犯罪公约》起草的示范法。（国际电信联盟，2009），该法提供了一个法律框架，协调英联邦国家内部的立法并保障国际合作。

由15个成员国组成的西非国家经济共同体（ECOWAS）于2009年通过了《打击ECOWAS网络犯罪指令》，为成员国提供法律框架，其中包括实体刑法和程序法。（Nicholas, 2008）

联合国（UN）大会于1990年通过了一项处理计算机犯罪立法的决议。2000年，通过了一项关于打击犯罪性滥用信息技术的决议；2002年，又通过了第二项关于犯罪性滥用信息技术的决议。（Nicholas, 2008）

八国集团（G8）于1997年公布了一份部长级公报，包含打击网络犯罪、保护数据和系统免遭未经授权损害的行动计划和原则。它进一步强制要求所有执法人员必须接受培训并装备起来应对网络犯罪，并指定所有成员国在每天24小时、每周7天的基础上设立联络点。（Chang et.al.）

国际电信联盟（ITU）将电信与网络安全问题交织在一起，联合国于2003年推出了《日内瓦原则宣言》和《日内瓦行动计划》，其中强调了打击网络犯罪措施的重要性。

## 印度防止网络犯罪和维护网络安全的法律框架

### 《2000年信息技术法》（以下简称《I.T.法，2000》）下的条款

根据《2000年信息技术法》处理网络犯罪的主要条款如下：

**第65条：篡改计算机源文档。**——“任何人明知或故意隐藏、销毁或篡改，或明知或故意导致他人隐藏、销毁或篡改任何计算机源代码，该源代码用于计算机、计算机程序、计算机系统或计算机网络，且根据现行法律规定必须保存或维护该计算机源代码时，应处以最高三年监禁，或最高二十万卢比罚金，或两者并罚。”¹

**第66条：计算机相关犯罪。**——“如果任何人以不诚实或欺诈方式实施第43条所述的任何行为，应处以最高三年监禁，或最高五十万卢比罚金，或两者并罚。”²

**第43条：对计算机、计算机系统等造成损害的罚款和赔偿。**——“如果任何人未经所有者或负责计算机、计算机系统或计算机网络的任何其他人许可，——（a）访问或获取对该计算机、计算机系统或计算机网络[或计算机资源]的访问权限；（b）从该计算机、计算机系统或计算机网络下载、复制或提取任何数据、计算机数据库或信息，包括存储在任何可移动存储介质中的信息或数据；（c）向任何计算机、计算机系统或计算机网络引入或导致引入任何计算机污染物或计算机病毒；（d）损坏或导致损坏任何计算机、计算机系统或计算机网络、数据、计算机数据库或驻留在该计算机、计算机系统或计算机网络中的任何其他程序；（e）中断或导致中断任何计算机、计算机系统或计算机网络；（f）以任何方式拒绝或导致拒绝任何获授权访问计算机、计算机系统或计算机网络的人员的访问；（g）提供任何协助以便于某人违反本法、规则或其下制定的法规的规定，获取对计算机、计算机系统或计算机网络的访问权限；（h）通过篡改或操纵任何计算机、计算机系统或计算机网络，将某人享用的服务费用记入另一人账户；（i）销毁、删除或篡改驻留在计算机资源中的任何信息，或降低其价值或效用，或以任何方式对其造成有害影响；（j）窃取、隐藏、销毁或篡改用于计算机资源的任何计算机源代码，或导致任何人窃取、隐藏、销毁或篡改该源代码，意图造成损害；应承担向受影响人支付损害赔偿金的责任。”³
