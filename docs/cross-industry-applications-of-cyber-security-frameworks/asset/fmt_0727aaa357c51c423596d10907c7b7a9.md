
# 技术进步对金融领域的影响

技术进步推动了金融领域的演变。得益于金融科技创新，过去十年间，消费者在支付、贷款、保险、储蓄和投资等领域的服务获取能力有了显著提升，且速度与范围前所未有（Kim et al., 2015）。然而，这也引发了隐私担忧，例如技术应用是否会暴露和泄露客户数据，以及机器学习和人工智能等相关技术是否会被用于银行风险管理（Kareem et al., 2020）。随着这些技术的进步，网络攻击手段也在不断演变并变得更加普遍。攻击操作专业人员致力于改进其方法以实现突破。至关重要的是，要比安全团队更快地识别威胁类型，理解网络安全风险及其对金融服务的影响，以便应对日益复杂的攻击技术。随着金融科技重要性的提升，更强大的网络安全解决方案显得必不可少，从而保障金融科技的红利。这要求在多个领域做好准备，包括网络治理，这需要加强对互联网技术和安全事实的认知与研究，以及建立安全合作伙伴关系。核心问题在于，随着金融和银行业务的近期发展及高能力化，巨大风险随之而来，这些服务伴随着猛烈的攻击，机构必须对此做好准备。银行业务监管机构应监督与电子银行业务兴起及其所涉风险相适应的监管体系，因为金融公司最容易受到这些威胁。

# 文献综述

Al Duhaidahawi 等人（2020）测度了金融科技变量与网络安全的关系，其中金融科技变量为解释变量，网络安全为被解释变量。研究观测结果显示，在 5.00% 显著性水平下，因变量与自变量间存在显著关系，金融科技变量间具有 90.80% 的互补性。

Ng, Artie W. 等人（2017）针对香港金融科技服务政策制定与网络安全的研究表明，技术适配性与道德适配性对于降低金融科技带来的网络安全风险至关重要；两项政策的高效实施有助于探索欺诈风险领域，从而促进金融科技发展。

Vucinic M.（2020）通过金融稳定性、风险与收益，关联了金融科技与市场结构。研究指出，金融科技为市场参与者带来机遇与风险，可能从微观和宏观经济风险角度威胁金融稳定；同时，由于技术接入点解决方案可能成为黑客攻击目标，网络风险将随之增加。

Rahman Benazir 等人（2021）展示了孟加拉国金融科技的生态系统、机遇与挑战。通过初级调查，研究发现金融科技在孟加拉国金融领域增长迅速，对金融部门有显著影响，存在各类改进活动，但也面临阻碍金融科技增长的不同障碍，并通过四个卡方（`χ²`）检验假设进行了验证。

Jayalath J A R C & Premaratne S. C.（2021）在其题为“金融科技公司关键数字技术基础设施与网络安全考量因素分析”的研究中描绘：随着金融平台通过互联网向公众开放，网络威胁急剧增加；因此，金融科技公司、银行和金融机构需要结构完善的数字技术基础设施，以提供数字化解决方案降低网络威胁。

Khan Mr. Ashraf & Malaika Majid（2021）的研究提到央行是关键决策者，但决策机构在网络安全和金融科技改进问题上尚未完全跟上形势，而金融科技已使央行运营（金融监管、储备管理和货币管理）面临风险。国际货币基金组织（IMF）建议央行建立“适当的层级结构”、“委员会结构”，并明确将投资部门与风险管理部门分离，以降低网络安全风险。

# 什么是金融科技

**FinTech** 是 Financial Technology（金融技术）的首字母缩写，指将技术与金融服务相结合（Schueffel, 2016）。它展示了云计算、移动互联网和大数据分析等现代互联网相关技术如何与支付、借贷、抵押、贷款和股票市场等商业活动相关联。FinTech 是金融技术的缩写，指利用技术进行金融交易的企业。

金融科技已成为一个独特的技术术语，主要代表企业或组织在广泛活动中的金融技术领域，重点在于通过信息技术（IT）应用提升服务质量（Schueffel, P., 2016）。

银行制造商汉诺威信托公司副总裁 Abraham Leon Bettinger 先生在一篇学术文章中给出了如下定义，文中详述了他分析和解决银行日常遇到的问题的模型（Prabook, 2016）：“**FINTECH** 是 financial technology 的首字母缩写，融合了银行专业知识与现代管理科学技术及计算机技术。”（Bettinger, p.62, 1972）

# 金融科技与数字支付系统在孟加拉国货币体系中的演变与增长

支付与结算系统被视为一国金融体系高效运行的关键。这些系统支持金融机构、企业和个人间的资金划转。作为监管机构，孟加拉国央行（`BB`）鼓励计划银行保持顺畅、稳健的电子银行运营。`BB` 采取必要举措启动电子商务、电子银行、自动清算系统（`ACHS`）、手机银行等。目前，银行已能通过互联网、ATM、手机或其他电子设备等电子渠道进行在线资金交易、公用事业缴费、资金划转、进出口贸易支付等。`BB` 的其他重大成功项目包括 `NPSB`、`BACPS`、`BEFTN`、`CIB`、数据仓库等。
