
# Security Framework for Internet Banking

## Literature Review and Problem Statement

From the reviewed literature we found that the security system of the banking sector focused only on the perspective of bank site security. The banking industry needs a coordinated and synchronized outlook of banks, financial institutions, service providers, authorities, regulatory bodies, customers, and other relevant stakeholders to apply encyclopedic chambers (implement properly) of appropriate internet banking security stricture under one framework. An exceptional program should be developed which will redirect messages sent from intruders to customers (Kok 2016). This program will automatically identify fake URLs against the bank's dedicated server through tools or manual identification by the authentication team to minimize financial loss and reputation loss.

## Study Objectives and Contributions

The study assists banks in constructing and implementing Internet Banking security to lower and minimize threats and attacks relevant to net banking services. Specifically, this study recommends that security enforcement and measures should be established based on both bank site and customer site perspectives.

This paper addresses Internet banking problems, threats, and attacks facing the banking industry, and critically discusses the importance of strong security implementation in the Bangladeshi banking industry by recommending security enforcement and measures based on bank site as well as customer site perspectives.

This study illustrates a security framework able to provide proper safeguard and safety. The research unveils internet banking crime methodologies and the limitations of existing security systems by constructing a manifold-layered security system framework.

## Proposed Manifold-Layered Security System

To mitigate internet security problems, a manifold-layered security system should be ensured among clients and banks. To achieve proper Internet banking security goals, the banking industry needs a coordinated and synchronized outlook of banks, financial institutions, service providers, authorities, regulatory bodies, customers, and other relevant stakeholders to apply encyclopedic chambers (implement properly) of appropriate internet banking security stricture under one framework.

The prime objective of this study was to suggest a manifold-layered Internet Banking Security system in the banking industry. To fulfill this motive, the study selected the Bangladeshi banking industry to realize current Internet Banking security practices through investigating security implementation in this banking service and identifying factors influencing security implementation. From existing theories, knowledge, ideas of reviewed literature, and conducted surveys, this study has drawn a new structure of the framework applied in the banking industry for practicing Internet Banking security implementation safely.

This study draws a manifold-layered security system to outweigh currently identified limitations denoted by security experts and analysts through viva-voce and conversation. The suggested manifold-layered internet banking security framework consists of an outer-layer security (consisting of national fraud protection organizations/institutes/departments) and an inner-layer (consisting of bank and client site security), ensuring governance and transparency by combining and coordinating different security layer systems from different perspectives.

### Inner Layer Components

The inner part-layer of the manifold-layered Internet Banking Security system is formed by five major models:

*   Internet Banking Client Site security model
*   Risk Mitigation Model
*   Internet Banking Verification, Delegation, Authorization and Auditing model
*   Internet Banking Protective model
*   Internet Banking security verification checklist

The outer-layer consists of the Financial Intelligence Center (FIC) and Cyber Emergency Response Team (CERT).

Undoubtedly, this framework structure makes it possible for banks to have an appropriate approach to mitigate Internet Banking security risk by realizing the manifold-layered security system.

## Recommendations

From the bank side, this study suggests proper security approaches and authentication of transactions based on monitoring through SMS, Phone, and Email. All of this should be performed in cooperation and observation from the national Financial Intelligence Center (FIC) and Cyber Emergency Response Team (CERT).

Additionally, clients' Uniform Resource Locator evaluation instruments should be upgraded for ensuring authenticity. Adequate testing should be done regarding usability issues.

A program should be developed which can redirect messages sent from intruders to customers if fake URLs against the bank's dedicated server are automatically identified through tools or manually identified by the authentication team to minimize financial loss and reputation loss.
