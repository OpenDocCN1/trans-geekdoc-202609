# TABLE 3.1
Deep Learning Models for Drug Target Identification

| DL Algorithm Used | Input Data Used | Targeted Disease Type | Limitations | Reference |
|---|---|---|---|---|
| Deep neural networks | mRNA expression profile datasets from GEO | Lung adenocarcinoma | The heterogeneity of data can cause biases in the yield | [9] |
| DeepWalk graph- embedding algorithm | miRNA profiles associated with cancer types | Breast cancer, lung cancer, prostate cancer | Limited data availability; Experimental validation of the results is required | [10] |
| Convolutional neural networks, recurrent neural networks | Curated druggable proteins from the DrugBank and Therapeutic Target Database | General | The non-availability of large-scale training and validation; Extended efforts to fine-tune the model parameters are required to overcome limitations | [11] |
| XGBoost | Cancer-related lncRNAs | Cancer | Imbalanced data and additional measures should be considered while dealing with such data. | [12] |
| Deep belief networks | Long noncoding RNAs | Cancer | The dataset used has less-conserved biological properties; Features are extracted by the network itself. | [13] |
