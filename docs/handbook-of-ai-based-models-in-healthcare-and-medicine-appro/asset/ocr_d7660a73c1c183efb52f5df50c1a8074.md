The cumulative reward value obtained with the π of the system starting at s_t is defined as G(s_t)=r_t+γr_{t+1}+γ²r_{t+2}+..., where 0≤γ≤1 is the discount factor. The value function calculates how the agent will be good in each state. Two functions – state value (V^π(s)) and action value (Q^π(s,a)) – are utilized to predict the future reward. According to [16], the state-value function is preferred when one has knowledge of the environment/system model, and the action-value function is preferred when it is a model-free concept. V^π(s) is defined under policy π as

V^π(s_t)=∑_{i=0}^∞ γ^i r_{t+i}. (17.6)

The optimal policy (π*) that must be obtained because of learning is the policy that maximizes the cumulative reward. V*(s) that is an optimal state-value function can be expressed as

V*(s)= max_π V^π(s), ∀s∈S. (17.7)

In addition, the optimal action-value function is

Q*(s,a)= max_π Q^π(s,a), ∀s∈S, ∀a∈A. (17.8)
