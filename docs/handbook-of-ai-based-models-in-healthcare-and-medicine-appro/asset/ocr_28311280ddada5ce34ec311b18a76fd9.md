# 14.6.1.3.3 Heart BPM Estimator

This application helps the user fetch their live heart BPM rate with the help of a Flutter plugin called heart_bpm. The heart BPM is captured via camera and flash in the smartphone shown in Figures 14.12 and . Heart BPM acts as one of the features for predicting the user’s heart risk [19]. In order to complete the medical records, the application requires the user to place their index finger on the torch light for 15 to 20 seconds in order and calculate the BPM. The calculated value is used for prediction and visualization purposes.
