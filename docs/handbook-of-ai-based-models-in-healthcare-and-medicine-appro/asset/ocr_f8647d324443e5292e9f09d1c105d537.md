# 14.6.1.3.1 Authentication Module

This application enables the user to create an individual account with the help of register and login pages. The authentication module will be present at the start of the application. Once the user enters the application, they must register the details in the given sign-up form. The MongoDB stores the registration details and helps the user log in to the application using the login form. FastAPI acts as a validator to check whether the given login details match the existing database.
