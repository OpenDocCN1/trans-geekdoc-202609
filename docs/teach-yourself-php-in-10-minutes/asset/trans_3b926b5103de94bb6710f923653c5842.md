## 使用 PHP 处理表单

现在让我们来看看单击提交按钮后，PHP 如何处理表单中各类型的项目。

### 访问表单值

表单值通过一些特殊的数组结构在 PHP 中可用。数组 `$_GET` 和 `$_POST` 分别包含使用 `GET` 和 `POST` 方法提交的值。混合数组 `$_REQUEST` 包含这两个数组的内容，以及来自 `$_COOKIE` 的值，您将在第 14 课 "*Cookie 和会话*" 中使用它。

**超全局变量** 系统生成的、名称以下划线字符开头的数组被称为 *超全局变量*，因为它们可以在 PHP 脚本的任何位置引用，无论作用域如何。例如，您无需显式将 `$_POST` 声明为全局，即可在函数中访问其元素。

访问表单项的值相当直观：表单项名称成为 `$_GET` 或 `$_POST` 中的元素键，数组中的每个值都是提交时对应元素的值。

例如，*评论表单页面* 提交的电子邮件地址将是 `$_POST["email"]`，评论文本将是 `$_POST["comments"]`。

对于 `CHECKBOX` 和 `RADIO` 输入类型，`VALUE` 属性决定 PHP 看到的值。如果名为 `may_contact` 的复选框被选中，则数组元素 `$_POST["may_contact"]` 的值为 `Y`。如果未选中，则该元素在数组中不存在；应使用 `isset` 检查复选框是否被选中。

**默认复选框值** 如果未为复选框项指定 `VALUE` 属性，则选中时其在 PHP 中的值为 `on`。

单选按钮组 `gender` 会导致 `$_POST["gender"]` 包含值 `m` 或 `f`，具体取决于选中哪个值；与复选框一样，如果未选中任何值，则数组元素不存在。

查看表单提交的所有数据的最简单方法是使用 print_r 调用输出 `$_POST` 的内容，如下所示：

```
echo "<PRE>";
print_r($_POST);
echo "</PRE>";
```

如果您想查看表单正在将哪些数据传递给脚本，这是一种有用的调试技术。如果您创建 send_comments.php，仅包含这些行，则输出会依次显示每个表单元素的值。以下是示例输出：

```
Array
(
    [name] => Chris Newman
    [email] => chris@lightwood.net
    [gender] => m
    [referrer] => search
    [may_contact] => Y
    [comments] => This is my favorite website ever
)
```

如果给提交按钮命名且在提交表单时单击了该按钮，PHP 甚至可以看到提交按钮的值。下面的表单有两个名称不同的按钮，因此您可以使用 PHP 确定实际点击了哪个按钮：

```
<FORM ACTION="button.php" METHOD=POST>
<INPUT TYPE="SUBMIT" NAME="button1" VALUE="Button 1">
<INPUT TYPE="SUBMIT" NAME="button2" VALUE="Button 2">
</FORM>
```

在 button.php 中，您可以使用类似于以下的条件来查看点击了哪个按钮：

```
if (isset($_POST["button1"])) {
    echo "You clicked button 1";
} elseif (isset($_POST["button2"])) {
    echo "You clicked button 2";
} else {
    echo "I don't know which button you clicked!";
}
```

提交按钮的 VALUE 属性决定按钮本身上显示的标签，但该值也是单击按钮时传递给 PHP 的值。

### 提交按钮

许多现代 Web 浏览器会在输入字段获得焦点时按下 Enter 键时提交表单。即使表单中只有一个提交按钮，除非实际用鼠标单击它，否则其值也不会发送到 PHP。

### 隐藏输入

还有另一种表单输入类型，可用于在脚本之间传递值，而这些值在网页本身上不可见。

HIDDEN 类型像往常一样接受 NAME 和 VALUE 属性，但它只是该值的占位符。

提交表单时，以下隐藏输入会被传递到 PHP 脚本，且 $_POST["secret"] 包含表单中的值：

```
<INPUT TYPE="HIDDEN" NAME="secret" VALUE="this is a secret">
```

不过请注意，HIDDEN 属性输入不适合传输密码和其他敏感数据，因为它们不安全。尽管它们不会在网页上显示，但如果查看页面源代码，仍可在 HTML 代码中看到隐藏值。

## 创建表单邮件脚本

本课中使用的评论表单的预期结果是提供一种方式，将用户提交的评论通过电子邮件发送给网站所有者。现在您将学习如何组装一个表单处理脚本，为网站创建此组件。

### mail 函数

PHP 的 mail 函数使用系统的邮件程序发送电子邮件。在 Linux/Unix 系统上，使用 sendmail 实用程序将消息放入出队列中。在 Windows 计算机上，它通常通过 SMTP 发送，并且中继服务器的名称必须在 php.ini 中定义才能正常工作。第 23 课 "PHP 配置" 更详细地介绍了配置问题。

mail 函数的三个必需参数是收件人的电子邮件地址、邮件主题和邮件正文。可选的第四个参数可以包含要发送的其他邮件标头；这对于设置 From: 地址或添加 Cc: 收件人很有用。

清单 11.2 中的脚本 send_comments.php 获取评论表单发送的数据，并通过电子邮件将其发送给网站所有者。

该脚本会遍历 $_POST 中的所有元素并构建字符串 $body，该字符串成为电子邮件的正文。请注意，输出中使用 \n 字符来分隔行，因为创建的是纯文本电子邮件，这意味着不需要 HTML 格式。

### 清单 11.2. send_comments.php

```
<?php

$body = "These comments were sent via the website\n\n";

foreach($_POST as $field => $value) {
    $body .= sprintf("%s = %s\n", $field, $value);
}

mail('owner@website.com', "Comments sent via website", $body,
    'From: "WebComments" <comments@website.com>');

?>
<H1>Thank You</H1>
Your comments have been sent!
```

发送给网站所有者的电子邮件大致应如下所示：

```
The following comments were submitted via the website

name = Chris Newman
email = chris@lightwood.net
gender = m
referrer = search
may_contact = Y
comments = This is my favorite website ever
```

此电子邮件的格式非常粗糙，因为每一行都是自动生成的。当然，如果您愿意，可以花更多时间创建格式精美的电子邮件；例如，可以将 gender 和 referrer 的编码值替换为它们的完整描述。
