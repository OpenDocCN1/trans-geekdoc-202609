

## PHP 标签

考虑以下来自显示当前日期的 PHP 驱动网页的摘录：

```php
Today is <?php echo date('j F Y');?>
```

`<?php` 标签告诉 PHP，紧随其后的所有内容都是程序代码而非 HTML，直到闭合 `?>` 标签。在此示例中，`echo` 命令告诉 PHP 将下一项显示到屏幕上；随后的 `date` 命令生成当前日期的格式化版本，包含日、月和年。

### 语句终止符

分号字符用于指示 PHP 命令的结束。在之前的示例中，只有一条命令，分号实际上不是必需的，但最好始终包含它，以显示命令已完成。

在本书中，PHP 代码出现在形如 `<?php ... ?>` 的标签内。可以使用其他标签样式，因此你可能会遇到其他人的 PHP 代码，以形如 `<?`（短标签）、`<%`（ASP 标签样式）或 `<SCRIPT LANGUAGE="php">`（脚本标签）的标签开头。

在可以使用的不同标签样式中，只有完整的 `<?php` 标签和脚本标签始终可用。其他标签样式通过 PHP 配置设置打开或关闭。我们将在第 23 课“PHP 配置”中查看 `php.ini` 配置文件。

### 标准 PHP 标签

始终使用 `<?php` 标签样式是良好的做法，这样你的代码可以在任何安装了 PHP 的系统上运行，无需额外配置。如果你想使用 `<?` 作为快捷方式，请知道，每次将代码移动到另一个 Web 服务器时，你都需要确保它能理解这种标签样式。

任何未包含在 PHP 标签内的内容都会原样直接传递给浏览器，完全与脚本中出现的一样。因此，在之前的示例中，文本 `Today is` 会在显示页面时出现在生成的日期之前。

## 你的第一个脚本

在继续之前，你需要确保在阅读本书示例的过程中能够创建和运行 PHP 脚本。这可以在你自己的机器上进行，你可以在附录 A“安装 PHP”中找到安装 PHP 的说明。此外，许多 Web 托管公司在其套餐中包含 PHP，你可能已经可以访问合适的 Web 空间。

请创建一个名为 `time.php` 的新文件，其中包含清单 1.1，放在 PHP 支持的 Web 服务器可以访问的位置。这是对先前所示日期示例的微小变体。

### 清单 1.1. 显示系统日期和时间

```php
The time is
<?php echo date('H:i:s');?>
and the date is
<?php echo date('j F Y');?>
```

当你在 Web 浏览器中输入该文件的 URL 时，你应该会看到根据 Web 服务器上的系统时钟显示的当前日期和时间。

### 在本地运行 PHP

如果你在本地 PC 上运行 PHP，脚本中的 PHP 代码只有在通过启用了 PHP 模块的 Web 服务器访问时才会执行。例如，如果你通过双击或将文件拖放到浏览器中直接在 Web 浏览器中打开本地脚本，它将仅被视为 HTML。

### Web 文档位置

如果你在 Windows 上使用默认的 Apache 安装，你会将 `time.php` 创建在文件夹 `C:\Program Files\Apache Group\Apache\htdocs` 中，正确的 URL 将是 http://localhost/time.php。

如果你按照所示完全输入清单 1.1，你可能会注意到生成的实际输出可以格式得更好一些——时间和单词 _和_ 之间没有空格。脚本中仅包含 PHP 标签内代码的任何行在生成的 HTML 中都不会占据输出行。

如果你使用 Web 浏览器中的“查看源文件”选项，你可以看到脚本生成的准确输出，它应类似于以下内容：

```
The time is
15:33:09and the date is
13 October 2004
```

如果你在 `?>` 后插入一个空格字符，该行现在包含非 PHP 元素，输出间距正确。

## echo 命令

虽然 PHP 非常适合在网页中嵌入小型动态元素，但事实上，如果整个脚本都包含在 PHP 标签中，整个页面可能由一组用于生成输出的 PHP 指令组成。

`echo` 命令用于将输出发送到浏览器。清单 1.1 使用 `echo` 来显示 `date` 命令的结果，该命令返回包含当前日期格式化版本的字符串。清单 1.2 做同样的事情，但在单个 PHP 代码块中使用一系列 `echo` 命令来显示日期和时间。

### 清单 1.2. 使用 echo 将输出发送到浏览器

```php
<?php
echo "The time is ";
echo date('H:i:s');
echo " and the date is ";
echo date('j F Y');
?>
```

你想要输出的非动态文本元素包含在引号中。可以使用双引号（如清单 1.2 所用）或单引号（与撇号相同的字符）来括起文本字符串，尽管你将在第 2 课“变量”中看到两种样式之间的重要区别。以下语句均有效：

```php
echo "The time is ";
echo 'The time is ';
```

请注意，这些语句中的引号内使用了空格字符，以确保 `date` 的输出与周围文本分开。实际上，清单 1.2 的输出与清单 1.1 略有不同，但在 Web 浏览器中，你需要使用“查看源文件”才能看到差异。清单 1.2 的原始输出如下：

```
The time is 15:59:50 and the date is 13 October 2004
```

这次生成的页面源代码中没有换行符。在 Web 浏览器中，输出看起来与清单 1.1 完全一样，因为在 HTML 中，所有空白（包括回车符和多个空格或制表符）在呈现的网页中都显示为单个空格。

PHP 代码块内的换行字符不构成输出的一部分。可以使用换行符以可读的方式格式化代码，但多条短命令可以出现在同一行代码上，或一条长命令可以跨越多行——这就是为什么你使用分号来指示命令结束的原因。

### 清单 1.3. 格式混乱的显示日期和时间的脚本

```php
<?php echo "The time is "; echo date('H:i:s'); echo
" and the date is "
; echo date(
'j F Y'
);
?>
```

### 使用换行符

如果你想将显式换行字符发送到 Web 浏览器，可以使用字符序列 `\n`。有几个像这样的字符序列具有特殊含义，你将在第 6 课“使用字符串”中看到更多。
