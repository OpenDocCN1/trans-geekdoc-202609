
合适。例如，要更改基本安装目录，应使用 --prefix 开关，后跟所需位置。可以输入 configure --help 查看可能的 configure 开关列表。

您需要至少包含 --enable-module=so 开关，以确保以后加载 PHP 模块时可用 DSO 支持。应输入以下命令，添加需要包含的任何其他配置开关：

```
# ./configure --enable-module=so
```

configure 命令会输出几屏信息，因为它正在尝试检测系统的最佳编译设置。完成后，您将返回到 shell 提示符，并可以继续安装。

要开始编译，请发出 make 命令：

```
# make
```

同样，会产生大量输出，编译所需时间取决于系统的速度。构建完成后，您会看到以下行，并返回到 shell 提示符：

```
make[1]: Leaving directory `/usr/local/src/httpd-2.0.52'
```

最后一步是安装新构建的软件。为此，只需输入 make install ，文件将自动复制到正确的系统位置：

```
# make install
```

发出 apachectl start 命令以启动 Apache Web 服务器，并在 Web 浏览器中输入服务器的 IP 地址以测试安装是否成功。如果未更改默认安装位置，请使用以下命令：

```
# /usr/local/apache/bin/apachectl start
```

## 编译和安装 PHP

您可以从 www.php.net/downloads.php 下载最新版本的 PHP。撰写本文时，最新版本是 5.0.3，因此要下载的文件名为 php-5.0.3.tar.bz2 。如果有更高版本，请务必在文件名出现的任何地方替换相应的版本号。需要将此文件保存到文件系统中的 `/usr/local/src` 或其他存放源代码的位置。使用 bunzip2 解压缩存档，方法如下：

```
# bunzip2 php-5.0.3.tar.bz2
```

**解压缩** 如果系统不包含 bunzip2 实用程序，则应改为下载名为 httpd-2.0.52.tar.gz 的文件。此存档略大，但使用 gzip 压缩，gzip 更广泛可用。

文件解压缩后，将失去 .bz2 文件扩展名。使用 tar 提取此未压缩的存档文件：

```
# tar xvf php-5.0.3.tar
```

文件将提取到名为 php-5.0.3 的目录中。在继续之前，应切换到此新目录：

```
# cd php-5.0.3
```

接下来，应使用任何适当的配置开关发出 configure 命令。例如，要通过 MySQLi 扩展包含数据库支持，将使用 --with-mysqli 开关，后跟 mysql_config 实用程序的路径。要查看 configure 开关的完整列表，可以运行 configure --help 。

需要包含 --with-apxs 或 --with-apxs2 开关之一；后者适用于 Apache 2.0，后跟系统上 apxs 实用程序的位置。默认 Apache 安装将使用以下语句之一：

```
# ./configure --with-apxs2=/usr/local/apache2/bin/apxs
```

```
# ./configure --with-apxs2=/usr/local/apache/bin/apxs
```

configure 命令会输出几屏信息，因为它正在尝试检测系统的最佳编译设置。完成后，您将返回到 shell 提示符，并可以继续安装。

要开始编译，请发出 make 命令：

```
# make
```

同样，会产生大量输出，编译所需时间取决于系统的速度。构建完成后，您会看到以下文本，并返回到 shell 提示符：

Build complete.
(It is safe to ignore warnings about tempnam and tmpnam).

最后一步是将新构建的 PHP 模块安装到 Web 服务器中。为此，请输入 make install ，文件将自动复制到正确的系统位置：

```
# make install
```

要完成安装，需要更改 Web 服务器配置文件，以告知其将 .php 文件传递给 PHP 模块。应编辑 httpd.conf 文件以添加以下行：

```
AddType application/x-httpd-php .php
```

如果需要，可以包含 .php 以外的其他文件扩展名。

下次使用 apachectl restart 命令重启 Web 服务器时，PHP 扩展将被加载。要测试 PHP，可以创建一个简单的脚本 /usr/local/apache2/htdocs/index.php ，内容如下：

```
<?php
phpinfo();
?>
```

在 Web 浏览器中，可以访问 Web 服务器 IP 地址上的 index.php ，应该会看到一个提供大量有关 PHP 配置信息的页面。

## Windows 安装

本节中的说明将指导您在 Windows 系统上将 PHP 安装到 Apache Web 服务器中。

### 安装 Apache

如果系统上已安装 Apache Web 服务器，可以跳过本节。

从 httpd.apache.org 下载最新版本的 Apache。要获取的文件是 MSI 安装程序包，当前 Apache 2.0.52 版本命名为 apache_2.0.52-win32-x86-no_ssl.msi 。将此文件保存到桌面并双击以开始安装过程。

安装过程通过向导完成，大多不言自明。必须接受许可条款才能继续安装，之后会显示一些发行说明。阅读这些内容后单击下一步，然后将要求输入服务器信息。

输入服务器的域名和主机名以及电子邮件地址。如果在个人工作站上安装，应将 localhost 和 localdomain 用作服务器信息。应保留推荐选项，即在端口 80 上安装 Apache 处于选中状态。

在要求选择安装类型时，应选择典型安装。随后将有机会选择 Apache 文件的目标文件夹。默认情况下，此路径为 C:\Program Files\Apache Group 。最后，Apache 准备就绪，单击安装按钮将导致系统开始在系统中复制和设置文件。

安装完成后，Apache 服务器和监视程序将启动，并且在系统托盘中会看到一个新图标。可以双击此图标以打开 Apache 服务监视器，可使用它来启动和停止 Web 服务器进程。绿灯指示服务器正在运行。

### 安装 PHP

可以从 www.php.net/downloads.php 的 Windows 二进制文件部分下载最新版本的 PHP。应选择 zip 文件而不是安装程序包；针对最新版本的 PHP（撰写本文时为 5.0.3），该文件名为 php-5.0.3-Win32.zip 。如果有更高版本，请务必在文件名出现的任何地方替换相应的版本号。

需要将 zip 文件保存到桌面并双击将其提取到 C:\php 。可以选择其他位置，但前提是也更改本节中的其他指令以反映该位置。

接下来，需要将 PHP 模块添加到 Apache。使用文件资源管理器，需要打开 Apache 配置目录（如果使用默认位置，则应为 C:\Program Files\Apache Group\Apache2\conf ）并编辑 httpd.conf 。然后需要将以下行添加到文件末尾：

```
LoadModule php5_module c:/php/php5apache2.dll
AddType application/x-httpd-php .php
```

下次从 Apache 监视器重启 Web 服务器时，PHP 扩展将被加载。要测试 PHP，可以在 Apache 安装位置下的 htdocs 文件夹中创建一个如下所示的简单脚本：

```
<?php
phpinfo();
?>
```

在 Web 浏览器中，如果访问 http://localhost/index.php ，应该会看到一个提供大量有关 PHP 配置信息的页面。
