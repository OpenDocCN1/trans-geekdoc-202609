## 第 1 课。了解 PHP

*在本课中，你将了解 PHP 是什么，并了解它能做什么。*

### PHP 基础

很有可能你已经对 PHP 能做什么有了一定了解——这大概就是你拿起这本书的原因。PHP 非常受欢迎，这也是名副其实。即使你没有遇到过赞美它的现有用户，你几乎肯定也用过运行在 PHP 上的网站。本课阐明了 PHP 的功能、工作原理及其能力。

PHP 是一种为创建动态网站而设计的编程语言。它嵌入你的 Web 服务器，并在网页发送到 Web 浏览器之前处理页面中包含的指令。因此，页面的某些元素可以即时生成，这样页面每次加载时都会发生变化。例如，你可以使用 PHP 在网站的每个页面顶部显示当前日期和时间，如本课后面所示。

PHP 这个名字是一个递归缩写，代表 *PHP: 超文本预处理器*。它最初名为 PHP/FI，“FI”部分代表 *表单解释器*。尽管名称在一段时间前被缩短，但 PHP 最强大的功能之一是处理 HTML 表单中提交的数据变得非常容易。PHP 还可以与各种数据库系统通信，使你能够根据 SQL 查询生成网页。

例如，你可以在网页的表单字段中输入搜索关键字，使用此值查询数据库，并生成匹配结果页面。你几乎在任何网上商店以及许多不销售任何东西的网站（例如搜索引擎）上都见过这种应用。

PHP 语言灵活且相当宽容，即使你过去没有编程经验，也容易学习。如果你已经懂另一种语言，你几乎肯定会在这里找到相似之处。PHP 看起来像 C、Perl 和 Java 的混合体，如果你熟悉其中任何一种，你会发现可以很容易地将现有编程风格适应到 PHP 中。

### 服务器端脚本

刚开始学习 PHP 时，最重要的概念是了解它在 Web 环境宏观格局中究竟处于什么位置。当你理解这一点后，你就明白了 PHP 能做什么和不能做什么。

PHP 模块附加到你的 Web 服务器，告诉服务器应检查具有特定扩展名的文件是否包含 PHP 代码。在页面中找到的任何 PHP 代码都会被执行，并且在网页发送到浏览器之前，PHP 代码会被其生成的输出所替换。

**文件扩展名** 通常的 Web 服务器配置是，`somefile.php` 将由 PHP 解释，而 `somefile.html` 将直接传递给 Web 浏览器，PHP 不会介入。
