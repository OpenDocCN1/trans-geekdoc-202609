

}

在此示例中，`$row` 的元素按数字索引，从零开始。因为所选列在 `SELECT` 语句中指定，顺序是已知的，你可以确定 `$row[0]` 包含 `col1` 的值。

你可以向 `fetchRow` 传入一个可选参数，以更改数组索引方式。默认值是创建数字索引数组，即 `DB_FETCHMODE_ORDERED`。通过指定 `DB_FETCHMODE_ASSOC`，将创建关联数组，并使用列名作为键。

你可以使用以下循环来重现前面的示例，但改为使用获取值的关联数组：

```php
while ($row = $res->fetchRow(DB_FETCHMODE_ASSOC)) {
   echo "col1 = " . $row["col1"] . ", ";
   echo "col2 = " . $row["col2"] . "<br>";
}
```

如果你更喜欢，可以使用 `fetchRow` 方法创建对象结构而非数组，只需传入参数 `DB_FETCHMODE_OBJECT`。下面的循环与前两个示例等效，但它使用对象方法：

```php
while ($row = $res->fetchRow(DB_FETCHMODE_OBJECT)) {
   echo "col1 = " . $row->col1 . ", ";
   echo "col2 = " . $row->col2 . "<br>";
}
```

![](img/2edc6e6954e3485ad7d94117645931d8_218_0.png)

**获取模式** 你使用的获取模式通常取决于个人偏好。关联数组和对象结构通常能编写出更易读的代码。但是，在需要最佳性能的场景中，你应该尽量使用 `DB_FETCHMODE_ORDERED`。

## 查询快捷方式

如果查询只返回单行单列（例如，单个聚合函数的结果），可以使用 `getOne` 方法快速执行查询并返回结果。提供字符串查询参数，并返回数据库结果：

```php
$sum = $db->getOne("SELECT sum(col1) FROM mytable");
```

还有其他快捷方法可用，包括 `getRow`（执行查询并返回整行）和 `getAll`（执行查询并将整个数据集作为数组返回）。有关完整函数列表，请参阅文档。

## 数据库可移植性问题

使用数据库抽象层，你可以编写数据库驱动的代码，只需更改用于连接数据库的 DSN，即可与多种后端协同工作。

然而，并非所有数据库系统都相同，因此你需要考虑数据库表和 SQL 语句的设计，以确保你的代码尽可能广泛地受到支持。

最重要的是，确保你的 SQL 是为所有希望兼容的数据库后端所共享的 SQL 语言的最小公共子集而编写的。例如，包含子查询的 SQL 不适用于 MySQL 4.0 或更早版本。同样，你应避免使用特定于某些数据库系统的 SQL 命令，例如 LIMIT 或 CREATE SEQUENCE。

## 可移植性模式

DB 类包含一些可移植性模式设置，可以简化从一个数据库后端到另一个的过渡。这些模式由一系列常量表示（如表 20.3 所示），你可以使用 setOption 方法并结合所需选项和逻辑 OR 运算符来设置。下面的语句显示了一个示例：

```php
$db->setOption('portability',
   DB_PORTABILITY_ERRORS | DB_PORTABILITY_NUMROWS);
```

### 表 20.3. 可移植性模式常量

| 常量 | 模式 |
| :--- | :--- |
| DB_PORTABILITY_ALL | 启用所有可移植性功能 |
| DB_PORTABILITY_NONE | 禁用所有可移植性功能 |
| DB_PORTABILITY_DELETE_COUNT | 在没有 WHERE 子句的 DELETE 语句中强制执行计数，并向语句追加 WHERE 1=1 |
| DB_PORTABILITY_ERRORS | 提高不同数据库系统之间错误报告的一致性 |
| DB_PORTABILITY_LOWERCASE | 强制将表名和列名转换为小写 |
| DB_PORTABILITY_NULL_TO_EMPTY | 将获取的 NULL 值转换为空字符串；某些数据库不区分这两者 |
| DB_PORTABILITY_NUMROWS | 使 numRows 方法在 Oracle 中能正确工作 |
| DB_PORTABILITY_RTRIM | 强制从获取的数据中删除尾随空白 |

## 使用引号

你可以使用 DB 方法 quoteSmart 将值括在引号中，以便安全地将其插入列中。字符串值将被括在引号中，任何需要转义的字符都会自动处理。

以下示例使用 quoteSmart 构建 SQL 语句，以确保字符串中的撇号不会产生干扰：

```php
$sql = "INSERT INTO phrases (phrase) ".
"VALUES ( ' " . $db->quoteSmart($text) . " ' );";
```

使用 MySQL 驱动程序执行上述语句时，$sql 的值如下：

```
INSERT INTO phrases (phrase)
VALUES ( 'Let\'s get ready to rumble' )
```

输出和使用的定界规则取决于你连接的数据库。

## 序列

不同数据库引擎中序列的实现方式差异很大。例如，在 MySQL 中，你在表列上使用 AUTO_INCREMENT 属性；在 SQL Server 中，它被称为 IDENTITY 字段；在 Oracle 中，你使用 CREATE SEQUENCE 创建一个独立于任何表的数据库对象，用于跟踪序列值。

DB 类使用自己的一组函数来管理序列，因此使用任何类型的自增字段都不会将你的代码绑定到某个特定的数据库后端。

![](img/2edc6e6954e3485ad7d94117645931d8_221_0.png)

**序列** 如果你的后端数据库支持 CREATE SEQUENCE，将使用该功能。否则，DB 类将使用一个存储序列值的表来模拟序列，并在每次访问序列时执行递增操作。

要创建新序列，请在数据库对象上使用 `createSequence` 方法，并提供一个唯一的序列标识符。创建序列后，可以使用该标识符调用 `nextId` 方法以返回下一个序列值。

以下示例创建名为 `order_number` 的序列并显示第一个序列值：

```php
$db->createSequence("order_number");
echo $db->nextId("order_number");
```

随后对该序列调用 `nextId` 将返回递增值。

当不再需要序列时，请调用 `dropSequence` 方法将其删除。

## 查询限制

MySQL 在 SQL 语句中实现了 `LIMIT` 关键字，你可以使用它来限制查询返回的行数。这是非标准 SQL，其他数据库系统不包含此功能。

`DB` 类包含 `limitQuery` 方法，你可以使用它在 SQL 语句中模拟 `LIMIT` 子句，以实现最大兼容性。该方法的调用方式与查询相同，但需要两个额外参数：用于指定起始行和要返回的行数。

以下示例从查询的数据集中返回五行，从第 11 行开始（行号从零开始）：

```php
$res = $db->limitQuery("SELECT * FROM mytable", 10, 5);
```

# 第 21 课。在命令行上运行 PHP

虽然 PHP 最初被构思为创建动态网页的工具，但由于 PHP 语言非常强大，它也已成为编写命令脚本甚至桌面程序的热门选择。

在本课中，你将学习如何编写用于命令行的 PHP 并创建自己的命令脚本。

## 命令行环境

要在命令行中使用 PHP，系统需要安装 PHP 可执行文件。在 Web 环境中运行时，PHP 通常作为 Apache 模块安装，但也可以构建名为 `php` 的独立程序，将其用作命令行接口（CLI）。

### CLI 和 CGI 二进制文件的区别

从 4.2 版本开始，PHP 开始区分用于 CGI 和 CLI 用途的二进制程序。这两个可执行文件提供相同的语言解释器，但 CLI 版本包括以下更改，使其更适合命令行使用：

- 输出中不写入 HTTP 头。
- 错误消息不包含 HTML 格式。
- `max_execution_time` 值设置为零，这意味着脚本可以无限时间运行。

要确定 `php` 二进制文件是 CGI 版本还是 CLI 版本，可以使用 `v` 开关运行它以查看版本信息。例如，以下输出来自 CLI 版本 PHP 5.0.3：

```
PHP 5.0.3 (cli) (built: Dec 15 2004 08:07:57)
Copyright (c) 1997-2004 The PHP Group
Zend Engine v2.0.3, Copyright (c) 1998-2004 Zend Technologies
```

版本号后括号中的值表示正在使用的服务器应用程序编程接口（SAPI）。你还可以在脚本中通过查看函数 `php_sapi_name` 的返回值来动态查找此值。

![](img/2edc6e6954e3485ad7d94117645931d8_225_0.png)

**Windows 发行版** PHP 4.2 的 Windows 发行版包含两个二进制文件——CGI 版本称为 `php.exe`，CLI 二进制文件称为 `php-cli.exe`。对于 PHP 4.3，两者都称为 `php.exe`，但分别位于名为 `cli` 和 `cgi` 的文件夹中。

对于 PHP 5 及更高版本，`php.exe` 是 CLI 版本，CGI 二进制文件现在命名为 `php-cgi.exe`。还包含一个名为 `php-win.exe` 的新 CLI 二进制文件，它以静默方式运行——也就是说，用户不需要打开命令提示符窗口。
