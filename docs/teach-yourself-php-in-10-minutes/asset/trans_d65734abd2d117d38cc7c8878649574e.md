

例如，在显示字符串之前隐去电话号码，你可以使用如下代码：

```
echo ereg_replace(
    "\(([[:digit:]]{3})\)[[:digit:]]{3}-[[:digit:]]{4}$",
    "(XXX) XXX-XXXX", $string);
```

正如你可以使用 eregi 来代替 ereg，以执行不区分大小写的搜索和替换正则表达式一样，你可以使用 eregi_replace。

## 第 9 课. 使用日期和时间

在本课中，你将学习如何在 PHP 中存储、显示和操作日期和时间值。

## 日期格式

PHP 没有原生的日期数据类型，因此为了在脚本中存储日期值，你必须首先决定存储这些值的最佳方式。

### 自定义日期格式

虽然你经常看到日期以结构化格式编写，例如 05/03/1974 或 2001-12-31，但这些都不是处理日期值的理想格式。然而，在这两者中，后者比前者更合适，因为其组件的顺序是从最重要的（年份）到最不重要的（日期），因此可以使用常用的 PHP 运算符来比较这些值。

作为字符串，2002-01-01 大于 2001-12-31，但由于数字比字符串的比较效率更高，因此可以将其更好地写为 20020101，其格式为 YYYYMMDD。这种格式可以扩展以包含时间部分，再次按照最重要元素优先的顺序，例如 YYYYMMDDHHMMSS。

然而，使用这种格式进行日期运算几乎是不可能的。例如，虽然你可以给 20040501 加一，并找到该月的下一天，但仅仅给 20030531 加一，会导致 5 月 32 日这种毫无意义的日期。

### Unix 时间戳格式

Unix 时间戳格式是日期和时间的整数表示。它是一个自 1970 年 1 月 1 日午夜开始计算秒数的值。

**Unix 纪元** 整数值为零的时间戳精确表示 1970 年 1 月 1 日格林威治标准时间（GMT）的午夜。这个日期被称为 *Unix 纪元*。

现在，我们有一个 10 位的日期和时间时间戳。要查找当前时间戳，可以使用 time 函数：

```
echo time();
```

Unix 时间戳格式很有用，因为对其进行计算非常容易，因为你知道该值始终表示秒数。例如，你可以给时间戳值加上 3,600 来增加一小时，或者加上 86,400 来增加一天——因为一小时有 3,600 秒，一天有 86,400 秒。

不过，一个缺点是 Unix 时间戳格式无法处理 1970 年之前的日期。虽然某些系统可能能够使用负时间戳值从纪元开始倒计数，但这种行为不可靠。

时间戳适用于表示当代日期值，但它们可能不总是适合处理出生日期或具有历史意义的日期。在决定时间戳是否是使用的正确格式时，你应该考虑将要使用什么值。

**时间戳限制** Unix 时间戳的最大值取决于系统的架构。大多数系统使用 32 位整数来存储时间戳，因此它能表示的最晚时间是 2038 年 1 月 19 日凌晨 3:14。

## 使用时间戳

有时使用自己的日期格式很有好处，但在大多数情况下，时间戳是最佳选择。让我们看看 PHP 如何与时间戳日期格式交互。

### 格式化日期

显示的日期如下所示：

## 创建时间戳

别担心；每次想要计算时间戳时，你不必从 1970 年 1 月 1 日开始计数。PHP 函数 mktime 根据给定的日期和时间值返回一个时间戳。

参数按顺序为：小时、分钟、秒、月、日和年。以下示例将 $timestamp 赋值为 2001 年 12 月 25 日上午 8 点的时间戳值：

```
$timestamp = mktime(8, 0, 0, 12, 25, 2001);
```

Unix 时间戳格式从 1970 年 1 月 1 日 GMT 午夜开始计数。mktime 函数返回相对于系统运行所在时区的时间戳。例如，在德克萨斯州的 Web 服务器上运行时，mktime 返回的时间戳值会比在纽约的机器上使用相同参数高 3,600。

**夏令时** 如果你只关心时间戳的日期部分，那么 `mktime` 的前三个参数只有在一年中的某个时间点临近午夜且夏令时是一个因素时才重要。

例如，当时钟拨快一小时时，这一天只有 23 小时长。给表示该天午夜的时间戳加上 86,400 秒，实际上会将时间戳的日期部分往后移动两天。你可以使用中午而不是午夜作为时间元素，以避免这些问题。

**格林威治标准时间** 要获得始终相对于 GMT（即没有夏令时调整时伦敦的时间）的时间戳值，应使用 `gmmktime` 而不是 `mktime`。

如果你向 `mktime` 提供不合理的参数，例如一个月中不存在的日期，该函数非常宽容。例如，如果你尝试计算非闰年 2 月 29 日的时间戳，返回的值实际上会表示 3 月 1 日，如下语句所示：

```
echo date("d/m/Y", mktime(12, 0, 0, 2, 29, 2003));
```

你可以利用这种行为来执行日期和时间运算。考虑以下示例，它计算并显示 2001 年 12 月 30 日中午之后 37 小时的日期和时间：

```
$time = mktime(12 + 37, 0, 0, 12, 30, 2001);
echo date("d/m/Y H:i:s", $time);
```

只需向 `mktime` 的某个参数中添加一个常量，就可以按该数量偏移返回的时间戳值。日期和时间显示如下：

```
01/01/2002 01:00:00
```

此示例中返回的值正确地偏移了日、月、年和小时值，考虑了 12 月的天数以及 12 月是一年中的最后一个月。

## 将其他日期格式转换为时间戳

如果你有一个存储为 DD-MM-YYYY 格式的日期，将其转换为时间戳是一个相当简单的过程，即围绕连字符字符拆分字符串。explode 函数接受一个分隔符参数和一个字符串，并返回一个数组，该数组包含由给定分隔符分隔的字符串的每个部分。

以下示例将此格式的日期拆分为其组件，并从这些值构建一个时间戳：

```
$date = "03-05-1974";
$parts = explode("-", $date);
$timestamp = mktime(12, 0, 0,
    $parts[1], $parts[0], $parts[2]);
```

对于许多日期格式，有一个更简单的方法来创建时间戳——使用 strtotime 函数。以下示例都从字符串日期值显示相同的有效时间戳：

```
$timestamp = strtotime("3 May 04");
$timestamp = strtotime("3rd May 2004");
$timestamp = strtotime("May 3, 2004");
$timestamp = strtotime("3-may-04");
$timestamp = strtotime("2004-05-03");
$timestamp = strtotime("05/03/2004");
```

请注意，在最后几个示例中，给定的日期格式是 MM/DD/YYYY，而不是 DD/MM/YYYY。你可以在 www.gnu.org/software/tar/manual/html_chapter/tar_7.html 上找到 strtotime 接受的完整格式列表。
