

## 摘要

在本课中，您已学习如何处理 HTML 表单中用户提交的数据。在下一课中，您将学习如何使用 PHP 即时创建 HTML 表单项，例如菜单和单选按钮组。

## 第 12 课。生成动态 HTML

在本课中，您将学习如何使用 PHP 创建 HTML 表单元素。这些技术使您能够为输入项指定默认值，并根据脚本中的数据创建动态下拉菜单或单选按钮组。

### 设置默认值

让我们先从一些简单示例开始，这些示例在加载页面时将 PHP 嵌入表单元素中，以设置某些项的默认值。

### 默认输入值

文本输入的默认值在 VALUE 属性中给出。加载页面时，此值会显示在字段中，除非被覆盖，否则在提交表单时，相同的值会发送到 PHP 处理脚本。

设想一个在线商店的购物车页面，客户在最终订单之前有机会更改购物车中每件商品的数量。每个行项目的当前数量将显示在一个小文本输入框中，可以被覆盖，然后用户可以点击按钮来刷新购物车内容。清单 12.1 是此示例的一个非常简单的版本，适用于只销售一种商品但允许您选择购买数量的商店。

### 清单 12.1. 设置文本输入字段的默认值

```php
<?php
if(isset($_POST["quantity"]))
	$quantity = settype($_POST["quantity"], "integer");
else
	$quantity = 1;

$item_price = 5.99;
printf("%d x item = $%.2f",
		$quantity, $quantity * $item_price);
?>
<FORM ACTION="buy.php" METHOD=POST>
Update quantity:
<INPUT NAME="quantity" SIZE=2
VALUE="<?php echo $quantity;?>" >
<INPUT TYPE=SUBMIT VALUE="Change quantity">
</FORM>
```

首先，您为 $quantity 设置了一个总体默认值 1，因此首次加载页面时，这是在字段中显示并用于计算总价的数量。然后，在 VALUE 标签内，您运行单条 PHP 语句来输出 $quantity 的值。如果表单中发布了数量值，则使用该值代替。

此脚本应命名为 buy.php，以便在提交表单时表单提交给自身。如果您更改数量值并按提交按钮，脚本会计算新的总价。此外，页面重新加载时，数量输入字段将默认设置为您刚刚输入的值。

### 检查复选框

`CHECKED` 属性决定加载页面时复选框默认处于开启还是关闭状态。使用 PHP，您可以在 `<INPUT>` 标签内嵌入条件，以确定是否在复选框中包含 CHECKED 属性：

```html
<INPUT TYPE="CHECKBOX"
NAME="mybox" <?php if(condition) echo "CHECKED"; ?>>
```

此写法可能令人困惑，特别是因为标签末尾出现了两个 > 符号——一个用于关闭 PHP 部分，另一个用于关闭 `<INPUT>` 标签。事实上，CHECKED 属性的位置并不重要，因此您可以根据喜好移动它以提高可读性：

```html
<INPUT <?php if(condition) echo "CHECKED"; ?>
TYPE="CHECKBOX" NAME="mybox">
```

> **关闭 PHP 标签** 嵌入小块 PHP 时，应尽可能尽早包含关闭 `?>` 标签。如果遗漏此关闭标签，PHP 会尝试将随后的 HTML 解释为 PHP，并可能产生一些有趣的错误消息！

在 HTML 中使用 PHP 时，空格可能非常重要。在前一个示例中，如果 PHP 语句两侧没有空格且条件为真，则生成的实际 HTML 如下：

```html
<INPUT CHECKEDTYPE="CHECKBOX" NAME="mybox">
```

由于 `CHECKEDTYPE` 不被识别为 `<INPUT>` 标签的一部分，您的浏览器可能会将其显示为文本输入框，而不是复选框！在 HTML 标签中，动态元素周围空格过多总比空格不足的风险更好。

### 选择单选按钮组中的项

`CHECKED` 属性还用于指定单选按钮组中哪一项应默认被选中。例如，在线商店可能会提供三种运输选项，每种的成本都不同。为了确保客户始终选择运输选项，其中一个选项会被默认选中，并且可以在需要时更改（单选按钮无法取消选中，除非同一组中的另一个按钮被选中）：

```html
<INPUT TYPE="RADIO" CHECKED
NAME="shipping" VALUE="economy"> Economy
<INPUT TYPE="RADIO" NAME="shipping" VALUE="standard"> Standard
<INPUT TYPE="RADIO" NAME="shipping" VALUE="express"> Express
```

要将 CHECKED 属性动态分配给单选按钮组中的某一项，每一项都必须包含一个条件，用于检查 $shipping 的当前值与对应该项的值是否匹配。清单 12.2 给出了示例。

### 清单 12.2. 选择默认单选按钮组项

```php
<?php
if (!isset($shipping))
  $shipping = "economy";

echo "Your order will be sent via $shipping shipping";
?>
<FORM ACTION="shipping.php" METHOD=POST>

<INPUT TYPE="RADIO" NAME="shipping" VALUE="economy"
<?php if ($shipping == "economy") echo "CHECKED"; ?>> Economy

<INPUT TYPE="RADIO" NAME="shipping" VALUE="standard"
<?php if ($shipping == "standard") echo "CHECKED"; ?>>
Standard

<INPUT TYPE="RADIO" NAME="shipping" VALUE="express"
<?php if ($shipping == "express") echo "CHECKED"; ?>> Express
<INPUT TYPE="SUBMIT" VALUE="Change shipping option">
</FORM>
```

请注意这有多么笨拙，即使是仅包含三个项的短单选按钮组也是如此。本课后面，您将学习如何即时创建单选按钮组，从而以更优雅的方式管理更大的单选按钮组。

### 在菜单中设置默认选中项

<OPTION> 标签中的 SELECTED 属性指定哪一项应默认被选中。如果没有任何项具有 SELECTED 属性，则列表中的第一项会默认显示。

使用 PHP 在适当选项上显示 SELECTED 属性，与在单选按钮组中选择选定项一样笨拙，且使用相同的技术。清单 12.3 显示了与清单 12.2 相同的运输费率示例，但使用下拉菜单代替单选按钮组。

### 清单 12.3. 从菜单中选择默认项

```php
<?php
if (!isset($shipping))
	$shipping = "economy";

echo "Your order will be sent via $shipping shipping";
?>
<FORM ACTION="shipping.php" METHOD=POST>
<SELECT NAME="shipping">
<OPTION <?php if ($shipping == "economy") echo "SELECTED"; ?>
	VALUE="economy">Economy</OPTION>
<OPTION <?php if ($shipping == "standard") echo "SELECTED"; ?>
	VALUE="standard">Standard</OPTION>
<OPTION <?php if ($shipping == "express") echo "SELECTED"; ?>
	VALUE="express">Express</OPTION>
<INPUT TYPE="SUBMIT" VALUE="Change shipping option">
</FORM>
```

与单选按钮组一样，使用函数即时生成菜单可以让您处理更大的选项列表，同时仍然动态选择所选选项。

## 创建表单元素

现在让我们看看如何使用自定义 PHP 函数生成 HTML 表单中的某些项目。这种模块化意味着，每当需要在表单中包含同一类型的项目时，都可以反复使用同一个函数。

### 创建动态单选按钮组

生成单选按钮组的模块化例程需要三部分信息：组名称、值列表和标签列表。您可以使用关联数组一次将值和标签传递给函数。

假设您想要使用类似于以下的简单代码来生成单选按钮组的 HTML：

```php
$options = array("economy" => "Economy",
                 "standard" => "Standard",
                 "express" => "Express");
$default = "economy";
$html = generate_radio_group("shipping", $options, $default);
```

如您所见，在创建 HTML 表单时，您可能会反复使用这类函数，建立一系列类似函数的工具箱非常有用，可以轻松完成常见任务。generate_radio_group 函数的实现可能如下：

```php
function generate_radio_group($name, $options, $default="") {
    $name = htmlentities($name);
    foreach($options as $value => $label) {
        $value = htmlentities($value);
        $html .= "<INPUT TYPE=\"RADIO\" ";
        if ($value == $default)
            $html .= "CHECKED ";
        $html .= "NAME=\"$name\" VALUE=\"$value\">";
        $html .= $label . "<br>";
    }
    return($html);
}
```

函数核心是遍历 $options 的循环，依次生成每个 <INPUT> 标签，为每个标签赋予相同的 NAME 属性但不同的 VALUE 属性。标签文本放置在每个按钮旁边，在这个示例函数中，唯一的格式是在组中的每个按钮之间放置一个 <br> 标签。您可以将选项格式化为表格或任何您认为合适的其他方式。
