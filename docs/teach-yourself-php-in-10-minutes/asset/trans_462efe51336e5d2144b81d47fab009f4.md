## 多维数组

使用数组存储二维甚至多维数据不仅可行，而且通常非常有用。

### 访问二维数据

实际上，*二维数组*是数组的数组。假设你要使用数组按年份存储平均月温，使用月份和年份两个关键维度。你可能会按如下方式显示 1995 年 2 月的平均温度：

```
echo $temps[1995]["feb"];
```

因为 `$temps` 是数组的数组，`$temps[1995]` 是按月份索引的温度数组，你可以通过在方括号中添加键名来引用其元素。

### 定义多维数组

定义多维数组相当简单，只要记住你正在处理的实际上是一个包含更多数组的数组即可。

你可以通过引用各个元素来初始化值，如下所示：

```
$temps[1995]["feb"] = 41;
```

你还可以通过在适当位置嵌套 array 函数来定义多维数组。下面的示例通过在适当位置嵌套 array 函数来定义数组。下面的示例定义了三年的头几个月（完整的数组显然会比这个大得多）：

```
$temps = array (
    1995 => array ("jan" => 36, "feb" => 42, "mar" => 51),
    1996 => array ("jan" => 37, "feb" => 42, "mar" => 49),
    1997 => array ("jan" => 34, "feb" => 40, "mar" => 50) );
```

`print_r` 函数可以跟踪数组包含的任意多个维度，格式化输出将进行缩进，以使每个层级清晰可读。以下是刚刚定义的三维 `$temps` 数组的输出：

    )

## 第 8 课 正则表达式

在本课中，你将学习使用正则表达式进行高级字符串操作。你将了解如何使用正则表达式验证字符串以及执行查找替换操作。

### 正则表达式简介

使用正则表达式（有时也称为 _正则表达式_）是编写识别特定字符串格式规则的一种强大且简洁的方法。由于它们只需几个字符就能表达相当复杂的规则，如果你之前没有接触过它们，正则表达式看起来确实可能非常令人困惑。

在最简单的形式中，正则表达式可以只是一个字符串，其中表达式匹配按顺序包含这些字符的任何字符串。在更高级的级别，正则表达式可以识别字符串中的详细字符模式，并根据这些模式将字符串拆分为组件。

### 正则表达式类型

PHP 支持两种不同类型的正则表达式：本课将探讨的 POSIX 扩展语法，以及 Perl 兼容正则表达式（PCRE）。这两种类型使用不同的语法执行相同的功能，实际上无需同时掌握两种类型。如果你已经熟悉 Perl，你可能会发现使用 PCRE 函数比学习 POSIX 语法更容易。

PCRE 的文档可在线查阅：www.php.net/manual/en/ref.pcre.php。

### 使用 ereg

PHP 中的 ereg 函数用于将字符串与正则表达式进行测试。使用非常简单的正则表达式，下面的示例检查 $phrase 是否包含子字符串 PHP：

```php
$phrase = "I love PHP";
if (ereg("PHP", $phrase)) {
    echo "The expression matches";
}
```

如果在 Web 浏览器中运行此脚本，你会发现该表达式确实匹配 $phrase。

正则表达式区分大小写，因此如果表达式为小写，此示例将找不到匹配项。要执行不区分大小写的正则表达式比较，可以使用 eregi：

```php
if (eregi("php", $phrase)) {
    echo "The expression matches";
}
```

**性能** 迄今你所见的正则表达式执行基本的字符串匹配，这也可以通过你在第 6 课“使用字符串”中学到的函数（如 strstr）来完成。一般来说，如果为简单的字符串比较使用字符串函数代替 ereg，脚本的性能会更好。

### 测试字符集

除了检查字符序列是否出现在字符串中，你还可以通过将字符括在方括号中来测试字符集。只需列出要测试的所有字符，如果其中任何一个出现，表达式即匹配。

下面的示例实际上等同于本课前面所示的 eregi 用法：

```php
if (ereg("[Pp][Hh][Pp]", $phrase)) {
    echo "The expression matches";
}
```

此表达式检查大写或小写 P，后跟大写或小写 H，再后跟大写或小写 P。

你还可以通过在两个字母或数字之间使用连字符来指定字符范围。例如，[A-Z] 匹配任何大写字母，[0-4] 匹配零到四之间的任何数字。

仅当 $phrase 包含至少一个大写字母时，以下条件才为真：

```
if (ereg("[A-Z]", $phrase)) ...
```

^ 符号可用于否定字符集，以便正则表达式指定字符串不得包含一组字符。仅当 $phrase 包含至少一个非数字字符时，以下条件才为真：

```
if (ereg("[^0-9]", $phrase)) ...
```

### 常见字符类

使用正则表达式时，可以使用多个字符集。要测试所有字母数字字符，你需要一个如下所示的正则表达式：

```
[A-Za-z0-9]
```

表示同一组字符的字符类可以用更清晰的方式表示：

```
[[:alnum:]]
```

[: 和 :] 字符表示表达式包含字符类名称。可用类如表 8.1 所示。

### 表 8.1. 用于正则表达式的字符类

| 类名 | 描述 |
|---|---|
| alnum | 所有字母数字字符，A-Z、a-z 和 0-9 |
| alpha | 所有字母，A-Z 和 a-z |
| digit | 所有数字，0-9 |
| lower | 所有小写字符，a-z |
| print | 所有可打印字符，包括空格 |
| punct | 所有标点字符（任何非空格或 alnum 的可打印字符） |
| space | 所有空白字符，包括制表符和换行符 |
| upper | 所有大写字母，A-Z |

### 测试位置

迄今你所见的所有表达式，只要该表达式出现在被比较字符串中的任何位置即匹配。你还可以在正则表达式中测试字符串中的位置。

^ 字符（当不属于字符类时）表示字符串的开头，$ 表示字符串的结尾。你可以使用以下条件分别检查 $phrase 是以字母字符开头还是结尾：

```
if (ereg("^[a-z]", $phrase)) ...
```

```
if (ereg("[a-z]$", $phrase)) ...
```

如果要检查字符串是否仅包含特定模式，可以将该模式夹在 ^ 和 $ 之间。例如，以下条件检查 $number 是否仅包含一个数字字符：

```
if (ereg("^[[:digit:]]$", $number)) ...
```

**美元符号** 如果要在正则表达式中查找字面量 $ 字符，必须将该字符定界为 \$，以免其被视为行尾指示符。

当表达式位于双引号中时，必须使用 \\$ 对字符进行双重定界；否则，$ 符号可能被解释为变量标识符的开头。

### 通配符匹配
