## 第 2 课。变量

在本课中，你将学习如何在 PHP 中为变量赋值，并在一些简单表达式中使用它们。

## 理解变量

*变量* 是可以存储值并在以后检索的容器，是任何编程语言的基本构建块。

例如，你可以有一个名为 `number` 的变量，其值为 5，或者一个名为 `name` 的变量，其值为 `Chris`。以下 PHP 代码声明了这些名称和值的变量：

```php
$number = 5;
$name = "Chris";
```

在 PHP 中，变量名总是以美元符号开头。如果你记住这一点，声明新变量就非常简单：只需使用等号，左侧是变量名，右侧是你希望它采用的值。

**声明变量** 与某些编程语言不同，在 PHP 中，变量在使用前不需要声明。你可以随时为新变量名赋值，以便开始使用它。

变量可以在整个 PHP 语言中用于替代固定值。以下示例使用 `echo` 以与显示一段固定文本相同的方式显示变量中存储的值：

```php
$name = "Chris";
echo "Hello, ";
echo $name;
```

输出结果为：

Hello, Chris

### 命名变量

通常不建议将变量命名为 `$a`、`$b` 等。你可能不会长久记住每个字母代表什么（如果有代表的话）。好的变量名会明确告诉你存储在其中的值是什么类型（例如，`$price` 或 `$name`）。

![](img/2edc6e6954e3485ad7d94117645931d8_27_0.png)

**区分大小写** PHP 中的变量名区分大小写。例如，`$name` 与 `$Name` 是不同的变量，两者可以在同一个脚本中存储不同的值。

变量名只能包含字母、数字和下划线字符，并且每个变量名必须以字母或下划线开头。表 2.1 列出了一些有效和无效变量名的示例。

### 表 2.1. 有效和无效变量名示例

| 有效的变量名 | 无效的变量名 |
|---|---|
| `$percent` | `$pct%` |
| `$first_name` | `$first-name` |
| `$line_2` | `$2nd_line` |

![](img/2edc6e6954e3485ad7d94117645931d8_27_1.png)

**使用下划线** 使用下划线字符是给变量命名的一个便捷方式，该名称由两个或多个单词组成。例如，`$first_name` 和 `$date_of_birth` 因为使用了下划线而更具可读性。

另一种流行的组合单词的约定是将每个单词的首字母大写，例如 `$FirstName` 和 `$DateOfBirth`。如果你偏好这种风格，可以随意在脚本中使用，但请记住大小写很重要。

## 表达式

```php
$sum = 16 + 30;
echo $sum;
```

变量 $sum 取等号右侧表达式的值。值 16 和 30 使用加法运算符（加号 +）组合，将两个值相加的结果被返回。如预期，这段代码显示值 46。

为了演示变量可以用于替代固定值，你可以对两个变量执行相同的加法运算：

```php
$a = 16;
$b = 30;
$sum = $a + $b;
echo $sum;
```

$a 和 $b 的值被相加，再次，输出结果是 46。

## 字符串中的变量

你已经知道文本字符串需要用引号括起来，并且已经了解单引号和双引号之间存在差异。

差异在于，双引号字符串中的美元符号表示该变量的当前值应成为字符串的一部分。而在单引号字符串中，美元符号则被视为普通字符，不会引用任何变量。

以下示例有助于解释这一点。在以下示例中，变量 $name 的值被包含在字符串中：

```php
$name = "Chris";
echo "Hello, $name";
```

这段代码显示 Hello, Chris 。

在以下示例中，美元符号被视为普通字符，不会进行变量替换：

```php
$name = 'Chris';
echo 'Hello, $name';
```

这段代码显示 Hello, $name 。

有时你需要向 PHP 精确指示变量在哪里开始和结束。你可以通过使用花括号（即大括号 { }）来实现。如果你想显示带有后缀（以指示磅或盎司）的重量值，语句可能如下所示：

```php
echo "The total weight is {$weight}lb";
```

如果你没有在 $weight 周围使用花括号，PHP 将尝试查找 $weightlb 的值，而该值可能在你的脚本中不存在。

你也可以使用连接运算符（即句点符号）来完成相同的操作，它可用于将两个或多个字符串连接在一起，如以下示例所示：

```php
echo 'The total weight is ' . $weight . 'lb';
```

这三个值（两个固定字符串和变量 $weight）只是按照它们在语句中出现的顺序简单地连接在一起。请注意，第一个字符串末尾包含一个空格，因为你希望 $weight 的值与单词 is 连接在一起。

如果 $weight 的值为 99，该语句将产生以下输出：

```
The total weight is 99lb
```

## 数据类型

每个持有值的变量都有一个数据类型，用于定义它持有的是什么类型的值。PHP 的基本数据类型在表 2.2 中所示。

### 表 2.2. PHP 数据类型

| 数据类型 | 描述 |
|---|---|
| 布尔型 | 布尔值；可以是 `TRUE` 或 `FALSE`。 |
| 整型 | 数值；可以是正或负整数。 |
| 双精度浮点型（或 float） | 浮点数值；可以是任何小数。 |
| 字符串型 | 字符串值；可以包含任意数量的 ASCII 字符。 |

当你为变量赋值时，变量的数据类型也会被设置。PHP 根据你赋予的值自动确定数据类型。如果你想检查 PHP 认为某个值是什么数据类型，可以使用 `gettype` 函数。

运行以下代码显示小数的数据类型为 double：

```php
$value = 7.2;
echo gettype($value);
```

与 `gettype` 相辅相成的函数是 `settype`，它允许你重写变量的数据类型。如果存储的值不适合存储在新类型中，它将被修改为尽可能接近的值。

以下代码尝试将字符串值转换为整数：

```php
$value = "22nd January 2005";
settype($value, "integer");
echo $value;
```

在此例中，字符串以数字开头，但整个字符串并非整数。转换会转换直到第一个非数字字符之前的所有内容并丢弃其余部分，因此输出结果仅为数字 `22` 。
