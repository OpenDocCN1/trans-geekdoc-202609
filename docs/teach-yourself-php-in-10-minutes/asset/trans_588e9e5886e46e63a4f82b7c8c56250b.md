PHP 包含另一种随机数生成器，称为梅森旋转算法（Mersenne Twister），被认为产生比 `rand` 更好的随机结果。要使用此算法，需使用函数 `mt_rand` 和 `mt_srand`。

## 课程 6. 使用字符串

## 字符串结构

字符串（*string*）是被视为单个实体的字符集合。在 PHP 中，字符串用引号括起来，您可以通过将其赋值为包含在单引号或双引号中的字符串来声明字符串类型变量。

以下示例是相同的；两者都创建一个名为 `$phrase` 的变量，其中包含所示的短语：

```
$phrase = "The sky is falling";
$phrase = 'The sky is falling';
```

> **引号字符** PHP 中的引号没有方向性。启动字符串和指示字符串结束使用相同的符号。您必须在单引号字符串周围使用两个撇号字符（` `）；请勿使用反引号字符（` `）。

### 使用反斜杠转义字符

双引号可以用于单引号字符串中，反之亦然。例如，以下两个字符串赋值都有效：

```
$phrase = "It's time to party!";
$phrase = 'So I said, "OK"';
```

但是，如果要在引号字符串中使用相同的字符，必须使用反斜杠转义该引号。以下示例演示了这一点：

```
$phrase = 'It\'s time to party!';
$phrase = "So I said, \"OK\"";
```

在上述示例中，如果未使用反斜杠，PHP 将不匹配引号，并导致错误。

您使用哪种引号样式在很大程度上取决于个人偏好，当然也取决于是否希望编写整洁的代码。但是，请记住，如您在课程 2“变量”中所见，双引号字符串内以美元符号开头的变量会被替换为其值，而在单引号字符串中，美元符号和变量名会原样显示。

如果希望美元符号成为双引号字符串的一部分，也可以使用反斜杠对其进行转义。例如，以下两条语句是等价的：

```
$offer = 'Save $10 on first purchase';
$offer = "Save \$10 on first purchase";
```

如果没有反斜杠，第二个示例将尝试查找名为 `$10` 的变量的值，而 `$10` 实际上是一个非法变量名。

反斜杠字符也可用于双引号字符串中，以表示字符串内的一些特殊值。当其后跟一个三位数字时，表示具有该八进制值的 ASCII 字符。

您可以使用标准转义字符发送常见的不可打印 ASCII 字符。换行符是 `\n`，制表符是 `\t`，以此类推。有关完整列表，请参阅系统上的 man ascii 或 www.ascii.cl。

### 连接

您已经了解如何使用句号符号作为连接运算符来连接字符串。此运算符的复合版本 `.=` 可用于将字符串追加到现有变量。

以下示例分阶段构建字符串，然后显示结果：

```
$phrase = "I want ";
$phrase .= "to teach ";
$phrase .= "the world ";
$phrase .= "to sing";
echo $phrase;
```

短语将按预期显示。请注意在 teach 和 world 后使用空格，以确保最终字符串间距正确。

### 比较字符串

您可以通过使用标准比较运算符来比较字符串值。要检查两个字符串是否相等，请使用双等号（`==`）：

```
if ($password == "letmein")
    echo "You have a guessable password";
```

当应用于字符串时，相等运算符会执行区分大小写的比较。在上述示例中，`$password` 的任何其他大小写形式（例如 `LetMeIn`）都无法通过此测试。

不等式运算符 `<`、`<=`、`>` 和 `>=` 基于字符串中各个字符的 ASCII 值执行比较。以下条件可用于根据姓氏将人们分为两组——姓氏以 A-M 开头的一组和以 N-Z 开头的一组：

```
if ($last_name < "N")
    echo "You are in group 1";
else
    echo "You are in group 2";
```

**ASCII 值** 由于字符串比较是基于其底层 ASCII 值进行的，因此所有小写字母的值都高于其对应的大写字母。字母 `a-z` 的值为 `97-122`，而 `A-Z` 占据 `65-90`。

## 格式化字符串

PHP 提供了一种使用 `printf` 和 `sprintf` 函数创建格式化字符串的强大方法。如果您在 C 语言中使用过这些函数，它们对您来说会非常熟悉，尽管 PHP 的语法略有不同。

### 使用 printf

您使用 `printf` 来显示格式化字符串。在最简单的情况下，`printf` 采用单个字符串参数，其行为与 `echo` 相同：

```
printf("Hello, world");
```

然而，`printf` 的强大之处在于其能够将值替换到字符串中的占位符。占位符由百分号（`%`）后跟格式说明符字符标识。

以下示例使用简单的格式说明符 `%f` 来表示浮点数。

```
$price = 5.99;
printf("The price is %f", $price);
```

`printf` 的第二个参数将替换 `%f` 的位置，因此会生成以下输出：

```
The price is 5.99
```

实际上，`printf` 语句中的替换参数数量没有限制，只要要显示的字符串中有等量数量的占位符即可。以下示例通过添加一个字符串项来演示这一点：

```
$item = "The Origin of Species";
$price = 5.99;
printf("The price of %s is %f", $item, $price);
```

### 表 6.1. `printf` 格式字符

| 字符 | 含义 |
|---|---|
| b | 二进制（基数 2）数 |
| c | 具有参数数值的 ASCII 字符 |
| d | 有符号十进制（基数 10）整数 |
| e | 以科学计数法显示的数字（例如，2.6e+3） |
| u | 无符号十进制整数 |
| f | 浮点数 |
| o | 八进制（基数 8）数 |
| s | 字符串 |
| x | 带小写字母的十六进制（基数 16）数 |
| X | 带大写字母的十六进制（基数 16）数 |

假设您使用 `%d` 格式说明符而不是 `%f` 来显示 `$price` 的值：

```
$price = 5.99;
printf("As a decimal, the price is %d", $price);
```

在这种情况下，PHP 会将传递的参数视为整数，因此只会显示值的整数部分。生成的输出如下。

作为十进制数，价格是 5

**十进制** `%d` 格式字符串表示十进制整数，其中 *十进制* 是指基数 10 的数字，而不是小数点。有不同的格式说明符可用于以基数 16（*十六进制*，`%x`）、基数 8（*八进制*，`%o`）和基数 2（*二进制*，`%b`）显示数字。

### 格式代码

格式说明符还可以包含可选元素，用于指定要显示的值的填充、对齐、宽度和精度。这样可以执行一些非常强大的格式化操作。

宽度说明符指示格式化后的值在显示的字符串中应占用多少个字符，并出现在百分号和类型说明符之间。例如，以下示例确保显示的名称恰好占用 10 个字符：

```
$name1 = "Tom";
$name2 = "Dick";
$name3 = "Harry";
echo "<PRE>";
printf("%10s \n", $name1);
printf("%10s \n", $name2);
printf("%10s \n", $name3);
echo "</PRE>";
```

**填充** 这些示例使用 `<PRE>` 标签，以确保用于填充的多个空格在屏幕上显示。通常，Web 浏览器会将多个相邻的空白字符视为一个空格。

在创建动态网页时，字符串填充不常用。但是，在 PHP 中生成纯文本输出（例如生成的电子邮件文本）时，它非常有用。

如果在 Web 浏览器中运行此示例，您会发现每个显示的名称都从屏幕左侧缩进了正确数量的字符，以使每个名称相互右对齐。

默认行为是右对齐到给定宽度。但是，您可以通过使用减号作为对齐说明符来反转此行为。要将上述示例中的字符串左对齐，请使用格式说明符 `%-10s`。尽管从外观上看这与仅使用 `%s` 没有区别，但字符串将在右侧用空格填充到长度为 10 个字符。

您可以将填充字符从空格更改为任何其他字符，方法是将该字符放在宽度值之前，并加上单引号作为前缀。以下示例确保五位订单号在必要时始终用零填充显示：

```
$order = 201;
printf("Order number: %'05d", $order);
```

生成的输出如下：

```
Order number: 00201
```
