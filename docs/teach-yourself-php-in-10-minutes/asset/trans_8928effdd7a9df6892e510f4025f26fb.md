

## 显示验证警告

另一个需要考虑的问题是，当验证失败时，应将用户发送到哪里。目前为止，我们一直假设表单提交到处理脚本，当发现一个或多个验证错误时，表单会提示用户使用浏览器的“后退”按钮来修复错误。

这不仅为用户完成表单增加了一步——在在线商店中，你希望在客户和完成订单之间设置尽可能少的障碍——而且点击后退按钮时，有时还会导致表单字段中的数据丢失。

后退按钮是否会导致数据丢失，通常取决于缓存设置，无论是网络服务器、用户浏览器还是用户的互联网服务提供商上的设置。在很多情况下没有问题。然而，尤其当PHP会话已启动时，浏览器会自动发送无缓存标头，这会导致点击后退按钮时表单字段中的数据重置为原始值。你将在第14课“Cookie和会话”中了解更多关于PHP会话的内容。

一个好的技巧是将表单和处理脚本放在同一文件中，并让表单提交给自身。这样，如果有错误，它们可以在表单所在的同一页面上显示，之前输入的值可以自动填充到表单中。

## 清单13.1. 带有必填字段的示例注册表单

```php
<?php
$required = array("name" => "Your Name",
                 "email" => "Email Address");

foreach($required as $field => $label) {
   if (!$_POST[$field]) {
      $err .= "$label is a required field <br>";
   }
}

if ($err) {
   echo $err;
}

?>
<FORM ACTION="register.php" METHOD=POST>
<TABLE BORDER=0>
<TR>
   <TD>Your Name</TD>
   <TD><INPUT TYPE=TEXT SIZE=30 NAME="name"
      VALUE="<?php echo $_POST["name"]; ?>"></TD>
</TR>
<TR>
   <TD>Email Address</TD>
   <TD><INPUT TYPE=TEXT SIZE=30 NAME="email"
VALUE="<?php echo $_POST["email"]; ?>"></TD>
</TR>
<TR>
<TD>Telephone</TD>
<TD><INPUT TYPE=TEXT SIZE=12 NAME="telephone"
VALUE="<?php echo $_POST["telephone"]; ?>"></TD>
</TR>
</TABLE>
<INPUT TYPE=SUBMIT VALUE="Register">
</FORM>

<?php
}
else {
    echo "Thank you for registering";
}
?>
```

请注意，本示例中的警告消息即使在表单尚未提交时也会出现。可以通过在脚本中使用`is_array`检查`$_POST`数组的存在来改进这一点，但对`$err`的检查也需要查找`$_POST`；否则，表单将永远不会显示。

检查`$err`的条件跨越了HTML表单，即使围绕这段HTML的PHP标签已关闭，只有当该条件为真时，才会显示表单。

在本示例中，表单成功完成后，只显示一条简单的消息。这里是你基于提交的数据进行任何处理的地方，例如将其存储到数据库，你将在第19课“使用MySQL数据库”中了解这一点。或者，脚本可以使用Location HTTP标头强制浏览器自动将用户重定向到另一页，如下所示：

```
header("Location: newpage.php");
```

## 强制执行数据规则

你通常希望不仅确保已在必填字段中输入数据，而且在继续之前数据质量足够好。例如，你可能希望检查电子邮件地址或电话号码格式是否正确，使用在第8课“正则表达式”中开发的规则。你还可以对字段强制执行最小长度，以确保用户不能只是在每个字段中输入一个x来继续下一页。

因为每个字段可能都有不同的验证规则，你不能在循环中强制执行数据规则；相反，必须为每个要检查的字段编写规则。然而，与前面示例中的循环空字段检查配合使用时，你还应该在进行任何进一步验证之前检查是否已输入值。否则，警告消息会先告诉用户某个字段是必填的，然后又说它的格式不正确！

以下规则可以添加到清单13.1中，在必填字段检查之后，以强制执行电子邮件地址和电话号码的适当值：

```
if ($_POST["email"] &&
!ereg("^[^@]+@([a-z0-9\-]+\.)+[a-z]{2,4}$",
$_POST["email"]))
$err .= "Email address format was incorrect <br>";

if ($_POST["telephone"] &&
!ereg("^\(([[:digit:]]{3})[[:digit:]]{3}-[[:digit:]]{4}$",
$_POST["telephone"]))
$err .= "Telephone must be in format (555)555-5555 <br>";
```

因为这些附加规则在发现错误时会向$err添加新消息，脚本的其余部分保持不变。

## 高亮显示需要关注的字段

与其用警告消息列表轰炸用户，不如高亮显示表单中需要关注的字段，这样更用户友好。

这里使用的技术与前面的示例非常相似，但不应将每条警告消息追加到$err，而应为每个字段提供自己的警告文本。如果使用警告数组，只需计算$warnings中的元素数量，就可以轻松查看表单是否已成功验证。

你编写每条规则，以便在该字段验证失败时向$warnings添加一个元素，如下面的示例所示：

```
if (!eregi("^[^@]+@([a-z\-]+\.)+[a-z]{2,4}$",
    $_POST["email"]))
$warnings["email"] = "Invalid Format";
```

然后，在表单本身中，你可以在相应字段旁边显示此警告文本：

```
<TR>
<TD>Email Address</TD>
<TD><INPUT TYPE=TEXT SIZE=30 NAME="email"
VALUE="<?php echo $_POST["email"]; ?>"></TD>
<TD><b><?php echo $warnings["email"]; ?></b></TD>
</TR>
```

## 清单13.2. 使用内联警告的表单验证

```php
<?php

$required = array("name" => "Your Name",
    "email" => "Email Address");

foreach($required as $field => $label) {
    if (!$_POST[$field]) {
    $warnings[$field] = "Required";
    }
}

if ($_POST["email"] &&
    !ereg("^[^@]+@([a-z\-]+\.)+[a-z]{2,4}$", $_POST["email"]))
$warnings["email"] = "Invalid email";

if ($_POST["telephone"] &&
    !ereg("^\(([[:digit:]]{3})[[:digit:]]{3}-[[:digit:]]{4}$",
    $_POST["telephone"]))
$warnings["telephone"] = "Must be (555)555-5555";

if (count($warnings) > 0) {
?>
<FORM ACTION="register.php" METHOD=POST>
<TABLE BORDER=0>
<TR>
<TD>Your Name</TD>
<TD><INPUT TYPE=TEXT SIZE=30 NAME="name"
VALUE="<?php echo $_POST["name"]; ?>"></TD>
<TD><?php echo $warnings["name"]; ?></TD>
</TR>
<TR>
<TD>Email Address</TD>
<TD><INPUT TYPE=TEXT SIZE=30 NAME="email"
VALUE="<?php echo $_POST["email"]; ?>"></TD>
<TD><?php echo $warnings["email"]; ?></TD>
</TR>
<TR>
<TD>Telephone</TD>
<TD><INPUT TYPE=TEXT SIZE=12 NAME="telephone"
VALUE="<?php echo $_POST["telephone"]; ?>"></TD>
<TD><?php echo $warnings["telephone"]; ?></TD>
</TR>
</TABLE>
<INPUT TYPE=SUBMIT VALUE="Register">
</FORM>
<?php
}
else {
echo "Thank you for registering";
}
?>
```

第一个循环将警告文本"Required"分配给任何留空的必填字段。每个单独的验证规则都有自己的警告文本。

你如何高亮显示需要关注的字段取决于你对HTML的想象力和创造力。例如，通过检查每个字段的$warnings中是否存在元素，你可以将输入框的样式更改为带阴影的背景，如下所示：

```
<INPUT TYPE=TEXT SIZE=30 NAME="email"
<?php if ($warnings["email"]) echo "STYLE=\"shaded\""; ?>
VALUE="<?php echo $_POST["email"]; ?>">
```
