

Lynx/2.8.5dev.7 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.7a

这三个示例分别对应 Internet Explorer、Mozilla Firefox 和 Lynx。请注意，Internet Explorer 和 Firefox 都自称是 Mozilla 浏览器，因此要确切知道用户使用的是哪个程序，需要进一步分析该字符串。

```
if (strstr($_SERVER["HTTP_USER_AGENT"], "MSIE")) {
    echo "You are using Internet Explorer";
}
elseif (strstr($_SERVER["HTTP_USER_AGENT"], "Firefox")) {
    echo "You are using Firefox";
}
else {
    echo "You are using some other web browser";
}
```

由于浏览器对 DHTML 或 JavaScript 的实现存在差异，你可能偶尔需要使用此方法。

REMOTE_ADDR 属性包含访问 Web 服务器的请求所来源的 IP 地址。它应为用户计算机的 IP 地址，或用户 ISP 的 Web 缓存地址。你可能希望使用远程 IP 地址进行日志记录或安全审计。

如果 REMOTE_ADDR 值是 Web 缓存，则元素 HTTP_X_FORWARDED_FOR 也会存在，并且它包含用户计算机的 IP 地址。

如果用户已使用基本 HTTP 身份验证登录，你也可以通过查看 $_SESSION["REMOTE_USER"] 中的值来获取其用户名。

## 服务器信息

$_SERVER 中的其他元素允许你访问与 Web 服务器配置相关的各种值。

例如，$_SERVER["SERVER_NAME"] 对应 Apache 的 ServerName 指令。这是该 Web 服务器的主名称，但不一定是脚本被访问所用的域名；它可能与 $_SERVER["HTTP_HOST"] 不同。同样，$_SERVER["SERVER_ADMIN"] 保存了在 ServerAdmin 指令中设置的 Webmaster 电子邮件地址。

SERVER_ADDR 和 SERVER_PORT 元素包含运行 Web 服务器的机器的 IP 地址和端口号。检查 $_SERVER["REQUEST_METHOD"] 可以得知是使用 GET 方法还是 POST 方法将值传递给脚本。

最后，如果你正在使用共享 Web 主机或他人的 Web 服务器，并想查看对方运行的 Web 服务器软件版本，可以检查 $_SERVER["SERVER_SOFTWARE"]。此值与本课开头在 Server 标头中传输的值相同，其形式类似于以下内容：

```
Apache/1.3.29 (Unix) mod_gzip/1.3.26.1a PHP/4.3.9
mod_ssl/2.8.16 OpenSSL/0.9.7c
```

## 第 17 课。文件系统访问

在本课中，你将学习如何使用 PHP 访问 Web 服务器的文件系统，以及如何在脚本中读取和写入文件。

### 管理文件

让我们来看看 PHP 如何允许你处理存储在 Web 服务器硬盘上的文件。

### 文件权限

在从 PHP 执行任何文件系统访问之前，你需要考虑想要处理的文件的权限设置。本节主要讨论 Unix/Linux 系统上的文件权限系统，但相同的注意事项适用于所有平台。

通常，你的 Web 服务器将以 `apache` 或 `nobody` 用户名运行，而你的 Web 文档和 PHP 脚本则由你的实际系统用户拥有。除非 Web 服务器用户有权访问你的文件，否则任何访问尝试都将失败。

要向所有用户授予文件的只读访问权限，请使用 `chmod` 命令，该命令为除当前用户（`o`）以外的所有用户在文件上设置读取标志（`r`）：

```
$ chmod o+r filename
```

你也可以按以下方式使用 `chmod` 为文件设置全局读/写权限：

```
$ chmod o+rw filename
```

有关完整详情和更多示例，请参阅 `man chmod`。

如果文件具有全局权限，Web 服务器将能够访问它。然而，系统上的任何其他用户也将对这些文件拥有完全访问权限。在某些情况下，你可能更倾向于将文件所有权更改为 `apache` 用户，而不是授予全局写入权限。超级用户通过使用 `chown` 命令来实现此操作：

```
# chown apache filename
```

PHP 函数 `chmod` 也可用于更改文件权限。它接受两个参数：文件名和模式。模式参数可以是字符串类型（例如 `o+rw`），也可以是数字类型（例如 `0644`），只要该数字以零开头即可。

### 获取文件信息

PHP 提供了多种用于获取系统中文件信息的函数。最简单、且你可能经常使用的一个是 `file_exists`，它只是告诉你给定名称的参数是否存在文件。`file_exists` 函数如果文件系统中有任何具有给定名称的项目（即使是目录或特殊文件类型）则返回 `True`。该参数可以包含路径，如下所示：

```
if (file_exists("/home/chris/myfile")) {
echo "The file exists";
}
else {
echo "The file does not exist";
}
```

还有许多其他函数允许你测试文件的某些属性。这些函数在表 17.1 中列出。

表 17.1. 用于测试文件属性的函数

| 函数 | 描述 |

| `is_readable` | 检查文件是否可读。 |
| `is_writeable` | 检查文件是否可写。 |
| `is_link` | 检查是否为符号链接。 |
| `is_file` | 检查是否为真实文件，而非链接。 |

### 移动和复制文件

假设你有权执行此操作，可以从 PHP 执行文件复制、移动或删除操作。这些操作对应的函数分别是 copy、rename 和 unlink。

copy 和 rename 函数接受两个参数（源文件名和目标文件名），而 unlink 只接受一个文件名。

**文件路径** 从 PHP 执行文件操作时（尤其是删除操作）应格外小心。你需要始终确保知道当前工作目录是什么，或为目标文件提供完整路径。

### 使用文件名

basename 和 dirname 函数提供了一种简单的方法，分别将字符串拆分为文件名和路径。你可以使用这些函数在给出完整路径时查找基本文件名，或者在希望将文件与已知文件名位于同一位置时查找路径名。

basename 函数返回字符串中从最后一个斜杠字符到结尾的所有内容，而 dirname 函数返回该斜杠之前的字符串部分。
