

## 分析数据类型

在实践中，你不会经常使用 `settype` 和 `gettype`，因为你很少需要更改变量的数据类型。本书较早地介绍了这个主题，以便你了解 PHP 确实会为每个变量分配数据类型。

## 类型转换

有时，如果预期值为特定类型，PHP 会执行隐式数据类型转换。这称为 *类型转换*。

例如，加法运算符期望位于两个数字之间。字符串类型的值会在执行操作前转换为 double 或 integer，因此以下加法会产生整数结果：

```
echo 100 + "10 inches";
```

该表达式将 100 和 10 相加，并显示结果 110。

当字符串运算符用于数值数据时，也会发生类似的情况。如果对数值类型执行字符串操作，数值会先转换为字符串。事实上，你在本课前面已经通过连接运算符见过这种情况。显示的 $weight 值是数值。

字符串操作的结果始终是字符串数据类型，即使它看起来像数字。以下示例会产生结果 69，但如 `gettype` 所示，$number 包含字符串值：

```
$number = 6 . 9;
echo $number;
echo gettype(6 . 9);
```

我们将在第 5 课“使用数字”和第 6 课“使用字符串”中介绍与 PHP 中数值和字符串数据类型相关的强大运算符范围。

## 变量变量

可以使用存储在变量中的值作为另一个变量的名称。如果这听起来令人困惑，以下示例可能会有所帮助：

```
$my_age = 21;
$varname = "my_age";
echo "The value of $varname is ${$varname}";
```

生成的输出为

```
The value of my_age is 21
```

因为该字符串用双引号括起来，美元符号表示变量的值应成为字符串的一部分。构造 ${$varname} 表示 $varname 所命名的变量的值应成为字符串的一部分，这被称为变量变量。

$varname 两侧的花括号用于指示应首先引用它；在双引号字符串中是必需的，否则可选。以下示例使用连接运算符生成与前面示例相同的输出：

```
echo 'The value of ' . $varname . ' is ' . $varname;
```

## 条件语句

PHP 中的条件语句以关键字 `if` 开头，后跟括号中的条件。以下示例检查变量 `$number` 的值是否小于 10，且 `echo` 语句仅在满足此条件时显示其消息：

```
$number = 5;
if ($number < 10) {
    echo "$number is less than ten";
}
```

如果 `<` 符号左侧的值小于右侧的值，则条件 `$number < 10` 满足。如果此条件成立，则将执行随后花括号中的代码；否则，脚本将跳转到右花括号之后的下一条语句。

**布尔值** 每个条件表达式都求值为布尔值，`if` 语句只是对 `true` 或 `FALSE` 值进行操作，以确定是否应执行下一块代码。在 PHP 中，任何零值都被视为 `FALSE`，任何非零值都被视为 `true`。

目前，前面的示例将为 `true`，因为 5 小于 10，因此将执行花括号中的语句并显示相应的输出。现在，如果将 `$number` 的初始值更改为 10 或更高并重新运行脚本，条件将失败，且不会产生任何输出。

花括号在 PHP 中用于将代码块分组。在条件语句中，它们围绕在前面条件为 true 时要执行的代码部分。

**括号和花括号** 编写 PHP 脚本时，你会遇到三种括号。每种类型最常用的术语是圆括号 `( )`、花括号 `{ }` 和方括号 `[ ]`。

`if` 语句后不需要花括号。如果省略它们，则当条件为 true 时，会执行接下来的单条语句。任何后续语句都会执行，与条件状态无关。

**花括号和缩进** 虽然代码的缩进方式对 PHP 没有影响，但惯例是在花括号内的代码块前加上几个空格字符，以便在视觉上将该块与其他语句分开。

即使你只希望条件或循环应用于一条语句，使用花括号以保持清晰度仍然很有用。当嵌套多个结构时，这样做尤为重要，以保持可读性。

### 条件运算符

PHP 允许执行多种不同的比较，以检查两个值的相等性或相对大小。PHP 的条件运算符如表 3.1 所示。

### 表 3.1. PHP 中的条件运算符

| 运算符 | 说明 |
| --- | --- |
| == | 等于 |
| === | 完全相等（值相等且数据类型相同） |
| != | 不等于 |
| !== | 不完全相等 |
| < | 小于 |
| <= | 小于或等于 |
| > | 大于 |
| >= | 大于或等于 |

>= 还是 ==？比较相等性时要小心使用双等号 (==)。单个 = 始终是赋值运算符，除非赋值为零，否则你的条件将始终返回 true，并记住 TRUE 是任何非零值。比较两个值时，始终使用 == 以避免麻烦。

### 逻辑运算符

你可以组合多个表达式，在单个条件语句中检查两个或多个条件。例如，以下语句检查 $number 的值是否在 5 和 10 之间：

```
$number = 8;
if ($number >= 5 and $number <= 10) {
  echo "$number is between five and ten";
}
```

关键字 and 是一个逻辑运算符，表示仅当两边的表达式都为 true 时，整体条件才为 true。也就是说，$number 必须既大于或等于 5，又小于或等于 10。

表 3.2 显示了 PHP 中可用的逻辑运算符。

### 表 3.2. PHP 中的逻辑运算符

| 运算符 | 名称 | 说明 |
| :--- | :--- | :--- |
| `! a` | NOT | `a` 不为 true 时为 true |
| `a && b` | AND | `a` 和 `b` 都为 true 时为 true |
| `a || b` | OR | `a` 或 `b` 任一为 true 时为 true |
| `a and b` | AND | `a` 和 `b` 都为 true 时为 true |
| `a xor b` | XOR | `a` 或 `b` 为 true，但不同时为 true 时为 true |
| `a or b` | OR | `a` 或 `b` 任一为 true 时为 true |

你可能已经注意到，在 PHP 中执行逻辑 AND 或 OR 有两种不同的方式。`and` 和 `&&`（以及 `or` 和 `||`）之间的区别在于用于求值表达式的优先级。

表 3.2 首先列出优先级最高的运算符。以下看似相同但细微却显著不同的条件：

```
a or b and c
a || b and c
```

在前一种条件中，`and` 优先级最高且首先求值。如果 `a` 为 true，或者 `b` 和 `c` 都为 true，则整体条件为 true。

在后一种条件中，`||` 优先级最高，因此 `c` 必须为 true，且 `a` 或 `b` 任一必须为 true，才能满足条件。

**运算符符号** 请注意，逻辑 AND 和 OR 运算符分别是双符号 `&&` 和 `||`。这些符号单独使用时含义不同，你将在第 5 课“使用数字”中看到。

### 多条件分支

通过在 `if` 语句中使用 `else` 子句，你可以指定在条件不满足时要执行的备选操作。以下示例测试 `$number` 的值并显示一条消息，说明它是大于还是小于 10：

```
$number = 16;
if ($number < 10) {
     echo "$number is less than ten";
}
else {
     echo "$number is more than ten";
}
```

`else` 子句为条件语句提供一种二选一机制。要向条件语句添加更多分支，可以使用 `elseif` 关键字添加一个进一步的条件，只有在语句中的先前条件失败时才会检查该条件。

以下示例使用 `date` 函数来查找当前的一天中的时间 `date("H")` 返回 0 到 23 之间的数字，表示时钟上的小时，并显示合适的问候语：

```
$hour = date("H");
if ($hour < 12) {
    echo "Good morning";
}
elseif ($hour < 17) {
    echo "Good afternoon";
}
else {
    echo "Good evening";
}
```

如果服务器时间在午夜到 11:59 之间，此代码显示 `Good morning`；从中午到下午 4:59 显示 `Good afternoon`；从下午 5 点开始显示 `Good evening`。
