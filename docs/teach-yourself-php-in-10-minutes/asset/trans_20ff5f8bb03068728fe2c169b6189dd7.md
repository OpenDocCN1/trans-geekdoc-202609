## 参数和返回值

每个函数调用都由函数名和括号内的参数列表组成。如果有多个参数，列表项之间用逗号分隔。有些函数根本不需要任何参数，但即使括号内没有参数，仍然需要一对括号。

内置函数 phpinfo 生成一个包含有关 PHP 模块大量信息的网页。此函数不需要任何参数，因此可以从像这样简单的脚本中调用：

```php
<?php phpinfo(); ?>
```

如果创建此脚本并在 Web 浏览器中打开它，您将看到一个包含系统信息和配置设置的网页。

## 返回成功或失败

由于 phpinfo 生成自己的输出，您不需要在其前面加上 echo，但出于同样的原因，您不能将其生成的网页分配给变量。实际上，phpinfo 的返回值是整数值 1。

> **返回 true 和 false** 没有显式返回值的函数通常使用返回码来指示其操作是否已成功完成。零值（FALSE）表示失败，非零值（TRUE）表示成功。

以下示例使用 mail 函数尝试从 PHP 脚本发送电子邮件。mail 的前三个参数指定收件人电子邮件地址、邮件主题和邮件正文。mail 的返回值用于 if 条件中，以检查函数是否成功：

```php
if (mail("chris@lightwood.net",
    "Hello", "This is a test email")) {
  echo "Email was sent successfully";
} else {
  echo "Email could not be sent";
}
```

如果运行此脚本的 Web 服务器未正确配置为发送电子邮件，或在尝试发送时发生其他错误，mail 将返回零，指示电子邮件无法发送。非零值表示消息已移交给您的邮件服务器进行发送。

**返回值** 尽管您不一定需要测试每个函数的返回值，但应该知道 PHP 中的每个函数都会返回某个值。

## 默认参数值

mail 函数是接受多个参数的函数示例；收件人、主题和邮件正文均为必填项。mail 的原型还指定该函数可以接受可选的第四个参数，该参数可包含其他邮件标头。

以太少参数调用 mail 会导致警告。例如，包含以下内容的脚本：

```php
mail("chris@lightwood.net", "Hello");
```

将生成类似于以下内容的警告：

```
Warning: mail() expects at least 3 parameters, 2 given in
/home/chris/mail.php on line 3
```

但是，以下两次 mail 调用都有效：

```php
mail("chris@lightwood.net", "Hello", "This is a test email");
mail("chris@lightwood.net", "Hello", "This is a test email",
   "Cc: editor@sampublishing.com");
```

要在自己的函数中有多个参数，只需在函数定义中使用逗号分隔的变量名列表。要使其中一个参数可选，请在参数列表中为其赋予默认值，就像给变量赋值一样。

以下示例是 add_tax 的变体，接受两个参数——净金额和要添加的税率。$rate 的默认值为 10，因此是可选参数：

```php
function add_tax_rate($amount, $rate=10) {
    $total = $amount * (1 + ($rate / 100));
    return($total);
}
```

使用此函数，以下两次调用都有效：

```php
add_tax_rate(16);
add_tax_rate(16, 9);
```

第一个示例使用默认税率 10%，而第二个示例指定使用 9% 的税率，产生与原始 add_tax 函数示例相同的行为。

**可选参数** 函数的所有可选参数都必须出现在参数列表末尾，先传递必需值。否则，PHP 将不知道您正在向函数传递哪些参数。

## 变量作用域

值必须作为参数传递给函数的原因与变量作用域有关——即决定脚本哪些部分可以访问哪些变量的规则。

基本规则是，在脚本主体中定义的任何变量都不能在函数内部使用。同样，在函数内部使用的任何变量都不可见于主脚本。

**作用域** 函数内可用的变量称为局部变量，或者说其作用域局限于该函数。非局部变量称为全局变量。

局部变量和全局变量可以具有相同的名称并包含不同的值，但最好尽量避免这种情况，以使脚本更易于阅读。

调用 add_tax 时，它会计算 $total，这是返回的值。但是，即使在调用 add_tax 之后，局部变量 $total 在该函数外部也是未定义的。

以下代码片段尝试从函数内部显示全局变量的值：

```php
function display_value() {
    echo $value;
}

$value = 125;
display_value();
```

如果运行此脚本，您将看到没有输出，因为 $value 未在局部作用域中声明。

要在函数内部访问全局变量，必须在函数代码顶部使用 `global` 关键字。这样做会替换该变量的作用域，以便在函数内部读取和修改它。以下代码显示一个示例：

```php
function change_value() {
    global $value;
    echo "Before: $value <br>";
    $value = $value * 2;
}
$value = 100;
display_value();
echo "After: $value <br>";
```

现在可以在函数内部访问 $value 的值，因此生成的输出如下：

```
Before: 100
After: 200
```

## 使用库文件

创建一个有用的函数后，您可能希望在其他脚本中再次使用它。与其将函数定义复制到每个需要使用它的脚本中，不如使用库文件，这样您的函数只需存储和维护在一个位置。

在继续之前，您应该创建一个名为 `tax.php` 的库文件，其中包含 `add_tax` 和 `add_tax_rate` 函数，但不包含其他 PHP 代码。

**使用库文件** 库文件需要像常规脚本一样将其 PHP 代码包含在 `<?php` 标签内；否则，当内容被包含在脚本中时，它们将显示为 HTML。

## 包含库文件

要将外部库文件合并到另一个脚本中，请使用 `include` 关键字。以下内容包含 `tax.php`，以便在该脚本中可以调用 `add_tax`：

```php
include "tax.php";
$price = 95;
echo "Price before tax: $price <br>";
echo "Price after tax: ";
echo add_tax($price);
```

**`include` 路径设置** 默认情况下，`include` 仅在当前目录和少数系统位置中搜索要包含的文件。如果要包含其他位置的文件，可以使用文件路径。

可以通过更改 `include_path` 设置的值来扩展 `include` 路径，以包含其他位置而无需路径。有关更多信息，请参阅第 23 课“PHP”。

如果要确保库文件仅加载一次，可以使用 `include_once` 关键字。如果脚本尝试第二次定义同一个函数，将导致错误。使用 include_once 有助于避免此问题，特别是当从其他库文件包含文件时。通常，有一个包含多个其他文件（每个文件包含几个函数）的库文件，比一个巨大的库文件更有用。

**require** require 和 require_once 指令与 include 和 include_once 的工作方式类似，但行为略有不同。发生错误时，include 生成警告，但脚本会尽可能继续运行。require 语句失败会导致脚本立即退出。
