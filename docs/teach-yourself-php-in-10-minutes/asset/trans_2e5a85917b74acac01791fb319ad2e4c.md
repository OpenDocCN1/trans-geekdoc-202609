

正则表达式中的点字符（.）是通配符，它匹配任意字符。例如，以下条件匹配包含双字母 o 的任意四个字母的单词：

```
if ( ereg("^oo.$", $word) ) ...
```

^ 和 $ 字符分别表示字符串的开始和结束，每个点都可以代表任意字符。此表达式可以匹配 book 和 tool 等单词，但不匹配 buck 或 stool。

**通配符** 仅包含点的正则表达式匹配任何至少包含一个字符的字符串。必须使用 ^ 和 $ 字符来指示表达式的长度限制。

## 重复模式

你现在已经了解如何测试字符串中的特定字符或一组/某类字符，以及如何在正则表达式中使用通配符字符来定义广泛的模式。除此以外，你还可以使用另一组字符来指示模式可以或必须在字符串中重复指定次数。

你可以使用星号（*）来指示前面的项在字符串中可以出现零次或多次，也可以使用加号（+）符号来确保该项至少出现一次。

以下示例使用了 * 和 + 字符，彼此非常相似。两者都匹配仅包含字母数字字符的任意长度字符串。但是，第一个条件也匹配空字符串，因为星号表示 [[:alnum:]] 出现零次或多次：

```
if ( ereg("^[[:alnum:]]*$", $phrase) ) ...
```

```
if ( ereg("^[[:alnum:]]+$", $phrase) ) ...
```

若要表示应重复的一组匹配字符，请在其周围使用括号。例如，以下条件匹配任何包含交替字母和数字的偶数长度字符串：

```
if ( ereg("^([[:alpha:]][[:digit:]])+$", $string) ) ...
```

此示例使用加号符号来指示字母/数字序列可重复一次或多次。要指定固定重复次数，可以在花括号中给出数字。

可以给出一个数字或逗号分隔的范围，如以下示例所示：

```
if (ereg("^([[:alpha:]][[:digit:]]){2,3}$", $string)) ...
```

此表达式将匹配四个或六个字符的字符串，其中包含交替的字母和数字。但是，单个字母和数字或更长的组合不会匹配。

问号（?）字符表示前面的项可能出现一次或根本不出现。同样的行为可以通过使用 {0,1} 来指定模式重复的次数来实现。

## 一些实际示例

你主要在脚本中使用正则表达式来验证用户输入，以确保输入的值是可接受的。以下是使用正则表达式的一些实际示例。

## 邮政编码

如果客户的邮政编码存储在 $zip 中，你可能希望检查其格式是否有效。美国邮政编码始终由五个数字组成，后面可选地跟一个连字符和四个额外的数字。以下条件验证此格式的邮政编码：

```
if (ereg("^[[:digit:]]{5}(-[[:digit:]]{4})?$", $zip)) ...
```

此正则表达式的第一部分确保 $zip 以五个数字开头。第二部分位于括号内，后跟一个问号，表示此部分是可选的。第二部分定义为连字符字符后跟四个数字。

无论第二部分是否出现，$ 符号都表示字符串的结束，因此要满足此条件，除了表达式允许的字符外，不能有其他字符。因此，此条件匹配如 90210 或 90210-1234 这样的邮政编码。

## 电话号码

你可能希望强制执行电话号码的格式，以确保其外观如 (555)555-5555。此格式没有可选部分。但是，由于括号字符在正则表达式中具有特殊含义，因此必须使用反斜杠对其进行转义。

以下条件验证此格式的电话号码：

```
if (ereg("^\([[:digit:]]{3}\)[[:digit:]]{3}-[[:digit:]]{4}$",
$telephone)) ...
```

## 电子邮件地址

在验证电子邮件地址时，需要考虑许多变量。在最简单的级别，.com 域名的电子邮件地址类似于 somename@somedomain.com。

但是，存在许多变体，包括两个字符的顶级域名（例如 .ca）或四个字符的顶级域名（例如 .info）。

某些国家/地区特定的域具有两部分扩展名，例如 .co.uk 或 .com.au。

正如你所见，用于验证电子邮件地址的正则表达式规则需要相当宽松。但是，通过对电子邮件地址格式做出一些一般性假设，你仍然可以创建一个拒绝许多格式错误地址的规则。

电子邮件地址包含两个主要部分，由 @ 符号分隔。@ 符号左侧出现的字符通常是收件人的邮箱名称，可以是字母数字并包含某些符号。

假设电子邮件地址的邮箱部分可以由 @ 符号本身以外的任何字符组成，长度可以是任意。与其尝试列出你能想到的所有可接受字符，例如，是否应允许电子邮件地址中包含撇号？通常只需强制要求电子邮件地址只能包含一个 @ 字符，且该字符之前的所有内容均为有效邮箱名称即可。

对于正则表达式规则，你可以定义电子邮件地址的域部分由两个或多个部分组成，由点分隔。你还可以假设最后一部分的长度只能在两到四个字符之间，这足以覆盖当前使用的所有顶级域名。

域部分中可使用的字符集比邮箱名称更为严格；只能使用小写字母数字字符和连字符。

考虑到这些假设，你可以得出以下条件来测试电子邮件地址的有效性：

```
if (ereg("^[^@]+@([a-z0-9-]+\.)+[a-z]{2,4}$", $email)) ...
```

此正则表达式的解析如下：任意数量的字符，后跟一个 @ 符号，然后是一个或多个仅由小写字母、数字或连字符组成的部分。这些部分中的每一个都以点结尾，最后一部分必须为两到四个字母长。

**走多远** 此表达式可以进一步细化。例如，域名不能以连字符开头，最大长度为 63 个字符。但是，为了捕获拼写错误的电子邮件地址，此表达式已足够。

## 将字符串拆分为组件

你已使用括号将正则表达式的部分组合在一起以指示重复模式。你还可以使用括号来指示表达式的子部分，而 ereg 允许你根据括号将模式拆分为组件。

当向 ereg 传递可选的第三个参数时，该变量将被分配一个值数组，这些值对应于正则表达式中括号标识的模式部分。

让我们以电子邮件地址正则表达式为例。以下代码包含三组括号，用于隔离邮箱名称、域名（扩展名除外）和域扩展名：

```
$email = "chris@lightwood.net";
if (ereg("^([^@]+)@([a-z\-]+\.)+([a-z]{2,4}$)",
    $email, $match)) {
    echo "Mailbox: " . $match[1] . "<br>";
    echo "Domain name: " . $match[2] . "<br>";
    echo "Domain type: " . $match[3] . "<br>";
}
else {
    echo "Email address is invalid";
}
```

如果在网络浏览器中运行此脚本，你会得到类似于以下内容的输出：

```
Mailbox: chris
Domain name: lightwood.
Domain type: net
```

请注意，$match 的第一个键引用找到的第一个模式。数组键像往常一样从零开始编号；但是，$match[0] 包含整个匹配模式。

## 搜索和替换

你可以使用 ereg_replace 函数利用正则表达式对字符串执行搜索和替换操作。其三个参数是正则表达式搜索模式、替换字符串和要替换的目标字符串。返回修改后的字符串。

**str_replace** 如果你想执行不需要正则表达式的简单字符串替换操作，可以使用 `str_replace` 代替 `ereg_replace`。`str_replace` 更高效，因为 PHP 甚至不需要考虑你可能正在查找正则表达式。
