

```
[5] => 79
[6] => 84
[7] => 83
[8] => 76
[9] => 65
[10] => 54
[11] => 42
)
```

**print_r** print_r 函数在开发脚本时非常有用，尽管你永远不会将其作为实时网站的一部分使用。如果你对数组中发生的事情不确定，使用 print_r 通常可以很快地揭示问题所在。

## 遍历数组

你可以轻松复制 print_r 遍历数组中每个元素的方式，使用循环结构对数组中的每个值执行另一个操作。

使用 while 循环，你可以像使用 print_r 函数一样，从数组中找出所有索引键及其值，如下所示：

```
while (list($key, $value) = each($temps)) {
    echo "Key $key has value $val <br>";
}
```

对于数组中的每个元素，索引键值将存储在 $key 中，值将存储在 $value 中。

PHP 还提供另一种在循环中遍历数组的结构，即使用 foreach 结构。无论你使用 while 还是 foreach 循环，都取决于个人偏好；你应该使用你觉得最易读的那个。

与前一个示例等价的 foreach 循环如下：

```
foreach($temps as $key => $value) {
...
}
```

**循环** 你可能已经意识到，在 `$temps` 示例中，一个从 0 计数到 11 的 `for` 循环也可以用来查找数组中每个元素的值。但是，尽管这种技术在此情况下有效，数组中的键不一定总是连续的，并且，如你将在下一节中看到，甚至可能不是数字。

### 关联数组

本章目前为止的数组示例都使用了数字键。*关联数组* 允许你使用文本键，以便索引可以更具描述性。

要使用关联键为数组赋值并引用该值，只需使用带引号的文本键名，如以下示例所示：

```
$temps["jan"] = 38;
echo $temps["jan"];
```

以这种方式定义完整的平均月度温度数组，你可以像以前一样使用 `array` 函数，但你需要指定键值以及每个元素。你使用 `=>` 符号来显示键与其值之间的关系：

```
$temps = array("jan" => 38, "feb" => 40, "mar" => 49,
       "apr" => 60, "may" => 70, "jun" => 79,
       "jul" => 84, "aug" => 83, "sep" => 76,
       "oct" => 65, "nov" => 54, "dec" => 42);
```

关联数组中的元素按定义顺序存储（你将在本课后面学习数组排序），并在循环中遍历此数组时按定义顺序查找元素。你可以在数组上调用 `print_r` 来验证这一点。输出的前几行如下：

```
Array
(
    [jan] => 38
    [feb] => 40
    [mar] => 49
    ...
```

## 数组函数

你已经看到过用于从值列表生成数组的 `array` 函数。现在让我们看看 PHP 提供的用于操作数组的一些其他函数。

PHP 中的数组函数远比本书所能涵盖的多。如果你需要执行尚未学习的复杂数组操作，请参阅 www.php.net/ref.array 的在线文档。

### 排序

要对数组中的值进行排序，你可以使用 `sort` 函数或其衍生函数之一，如以下示例所示：

```
sort($temps);
```

> **排序函数** `sort` 和其他相关函数接受单个数组参数并对该数组进行排序。排序后的数组不会被返回；返回值表示成功或失败。

使用 `sort` 对原始 `$temps` 数组进行排序会将值按数字顺序排列，但键值也会被重新编号。执行排序后，数组的索引 0 将包含数组中的最小值，并且无法知道哪个值对应每个月。

你可以使用 `asort` 在保持键关联的同时对数组进行排序，无论它是关联数组还是数字索引数组。对 `$temps` 进行排序后，索引 0 仍将包含一月的平均温度，但如果你遍历数组，元素将按排序顺序检索。

以关联数组 `$temps` 为例，以下代码显示月份及其平均温度，从最冷到最热：

```
$temps = array("jan" => 38, "feb" => 40, "mar" => 49,
    "apr" => 60, "may" => 70, "jun" => 79,
    "jul" => 84, "aug" => 83, "sep" => 76,
    "oct" => 65, "nov" => 54, "dec" => 42);
asort($temps);
foreach($temps as $month => $temp) {
    print "$month: $temp <br>\n";
}
```

还可以使用 `ksort` 按键而非元素值对数组进行排序。在关联 `$temps` 数组上使用 `ksort` 会按月份名称键对元素进行字母顺序排列。因此，当你遍历排序后的数组时，检索到的第一个值将是 `$temps["apr"]`，其次是 `$temps["aug"]`，以此类推。

要反转这些函数中的任何一个的排序顺序，请使用 `rsort` 代替 `sort`。`asort` 的逆序是 `arsort`，`ksort` 的逆序是 `krsort`。要在不排序的情况下反转数组当前的顺序，只需使用 `array_reverse`。

## 随机化数组

除了将数组的值排序之外，PHP 还提供函数，让你可以轻松地随机化数组中的元素。

`shuffle` 函数的工作方式与排序函数类似：它接受单个数组参数，并将该数组中的元素随机化。与 `sort` 类似，键关联会丢失，随机化后的值将始终以数字索引。

## 集合函数

通过将数组视为一组值，你可以使用 PHP 的数组函数执行集合运算。

要合并不同数组中的值（并集操作），你可以对两个或多个数组参数使用 `array_merge` 函数，如以下示例所示：

```
$union = array_merge($array1, $array2, $array3, ...);
```

将返回一个新数组，包含列出的数组中的所有元素。在此示例中，`$union` 数组将包含 `$array1` 中的所有元素，接着是 `$array2` 中的所有元素，以此类推。

要从任何数组中删除重复值，你可以使用 `array_unique`，这样如果两个不同的索引键引用相同的值，只保留一个。

`array_intersect` 函数对两个数组执行交集操作。以下示例生成一个新数组 `$intersect`，其中包含 `$array1` 中且也存在于 `$array2` 中的所有元素：

```
$intersect = array_intersect($array1, $array2);
```

要查找两个集合之间的差异，你可以使用 `array_diff` 函数。以下示例返回数组 `$diff`，其中仅包含存在于 `$array1` 但不存在于 `$array2` 中的元素：

```
$diff = array_diff($array1, $array2);
```

## 查看数组内部

count 函数返回数组中的元素数量。它接受单个数组参数。例如，以下语句显示 `$temps` 数组中有 12 个值：

```
echo count($temps);
```

要查找某个值是否存在于数组中而无需编写循环来搜索每个值，你可以使用 `in_array` 或 `array_search`。第一个参数是要搜索的值，第二个参数是要查看的数组：

```
if (in_array("PHP", $languages)) {
...
}
```

这些函数之间的区别在于返回值。如果值存在于数组中，`array_search` 返回相应的键，而 `in_array` 仅返回布尔结果。

> **大海捞针** 有些令人困惑的是，`in_array` 和 `array_search` 中 needle 和 haystack 参数的顺序与字符串函数（如 `strpos` 和 `strstr`）相反。

要检查特定键是否存在于数组中，你可以使用 `array_key_exists`。以下示例确定 `$temps` 的 `dec` 键值是否已设置：

```
if (array_key_exists("dec", $temps)) {
...
}
```
