

PCS 文档概述了一种结构化的编码方式，以便包能够被接受为 PEAR 项目的一部分。这些标准非常详细，大部分涉及风格要点，例如标识符命名约定以及声明函数和类时应使用的一致风格。

这听起来可能有点令人望而生畏，但随着你的脚本变得越来越复杂，你会意识到编写可读代码的重要性，并开始形成清晰的编码风格。PCS 文档仅仅是将一套编写可读 PHP 代码的指南形式化。

你可以在网上找到 PCS 文档，网址为 http://pear.php.net/manual/en/standards.php 。

## PHP 基础类

PFC 是 PEAR 包的一个子集，这些类有一套严格的入学标准：

- **质量** 包必须处于稳定状态。
- **通用性** 包不应过度针对任何特定类型的环境。
- **互操作性** 包应与其他包以及不同环境良好协作，并且应具有标准化的 API。
- **兼容性** 包在添加新功能时必须设计为向后兼容。

目前，只有 PEAR 安装程序随 PHP 一起发布。然而，在未来的某个日期，某些类可能会作为标准包含。PFC 就是这些类。

## PEAR 的在线支持

PEAR 网站（网址为 http://pear.php.net）为 PEAR 项目提供了全面的在线文档。可以通过网站搜索包数据库，包维护者可以登录以更新其项目详细信息。

PEAR 用户、维护者、核心开发者和网站管理员有多个邮件列表。你可以使用 http://pear.php.net/support/lists.php 处的表单加入其中任何或全部列表。

## 使用 PEAR

在以下部分中，你将学习如何使用 PEAR 在系统上查找和安装包，并学习如何提交自己的项目以供考虑作为 PEAR 包。

## 查找 PEAR 包

PEAR 网站的每个页面都有一个搜索框，你可以使用它来搜索包数据库。只需输入名称或名称的一部分，所有匹配的包都将显示。

**搜索包** 要对包名、维护者或发布日期进行详细搜索，可以使用 http://pear.php.net/package-search.php 处的表单。

你可以从搜索结果中点击感兴趣的包名称。然后显示的页面应提供有关该包的一些关键信息，包括其功能摘要、当前发布版本和状态以及关于其依赖项的信息，即该包正常工作所需的任何其他 PEAR 包。

包详细信息页面顶部的选项卡允许你查看文档。如果你不确定从摘要信息中确切了解使用特定包可以实现什么，可以浏览文档页面。

如果你只想浏览所有可用的 PEAR 包，可以前往 http://pear.php.net/packages.php 处的分类列表。

## 使用 PEAR 安装程序

一旦你确定某个包将有所帮助，你可以使用其包信息页面顶部的选项卡从网上下载它。但是，使用 PEAR 安装程序是管理 PHP 安装中的包的一种快速简便的方法。安装程序能够查找并下载包的最新版本，还可以为你自动安装它。

PEAR 安装程序名为 pear 。要运行安装程序，请运行 pear 命令，后跟一个命令选项。要查看系统上当前安装的所有包，可以使用 list 命令选项：

```
$ pear list
```

**命令选项** 不带任何参数运行 pear 会列出所有可用的命令选项。

输出应类似于以下内容：

| 包 | 版本 | 状态 |
| --- | --- | --- |
| DB | 1.6.2 | stable |
| HTTP | 1.2.2 | stable |
| Net_DNS | 1.00b2 | beta |
| Net_SMTP | 1.2.6 | stable |
| Net_Socket | 1.0.1 | stable |
| PEAR | 1.3.2 | stable |
| SQLite | 1.0.2 | stable |

将显示每个包名称、已安装的版本及其发布状态。你系统上实际安装的包可能与这里显示的不同。

你可以使用 `search` 命令选项来搜索 PEAR 包数据库。要搜索所有包含字符串 `mail` 的包，请运行以下命令：

```
# pear search mail
```

输出将显示所有匹配的包、其最新版本号以及简要摘要。执行的搜索不区分大小写。

要查看所有可用的稳定 PEAR 包，请使用 `list-all` 命令：

```
# pear list-all
```

这将生成一个很长的列表！

要下载并安装一个包，请使用 `install` 命令选项，后跟包名。要安装 Mail 包，请发出以下命令：

```
# pear install Mail_Queue
```

除非系统上已安装其他包，否则某些包无法安装，如果找不到所需的包，安装将失败。以下输出显示在安装 Mail 包之前尝试安装 Mail_Queue 包的情况：

```
# pear install Mail_Queue
downloading Mail_Queue-1.1.3.tar ...
Starting to download Mail_Queue-1.1.3.tar (-1 bytes)
....done: 98,816 bytes
requires package 'Mail'
Mail_Queue: Dependencies failed
```

某些依赖项是可选的。当你安装 Mail 包以修复前一条错误消息中报告的依赖项时，PEAR 会建议你，如果你也安装 Net_SMTP，Mail 包的功能可以得到增强：

```
# pear install Mail
downloading Mail-1.1.4.tar ...
Starting to download Mail-1.1.4.tar (-1 bytes)
....done: 73,728 bytes
Optional dependencies:
package 'Net_SMTP' version >= 1.1.0 is recommended to
utilize some features.
install ok: Mail 1.1.4
```

你可以使用 upgrade 命令选项来下载并安装已安装包的更高版本。要检查 Mail 包是否有新版本发布，请使用以下命令：

```
# pear upgrade Mail
```

如果找到比已安装的更高版本，它将自动升级。

![](img/2edc6e6954e3485ad7d94117645931d8_268_0.png)

**升级包** 你可以使用 upgrade-all 命令一次性检查所有已安装 PEAR 包的较新版本。

如果你想完全删除一个 PEAR 包，请使用 uninstall 命令。

## 提交你自己的 PEAR 项目

如果你编写了一个认为对其他开发者有用的 PHP 项目，可以考虑提交提案，将其纳入 PEAR。

在线文档（位于 http://pear.php.net/manual/en/guide-newmaint.php）包含一份项目维护者指南，详细说明了先确保你的项目适合提交到 PEAR，然后确保你的代码符合适当标准的过程。如果你打算编写适合其他开发者使用的包，应该阅读该指南。即使你的项目不适合 PEAR，这些指南也会让你思考软件设计和编码标准，并帮助你生成质量更高的包。

## 附录 A. 安装 PHP

如果你需要自己安装 PHP，本附录适合你：它将逐步引导你完成安装过程，适用于 Linux/Unix 和 Windows 平台。

### Linux/Unix 安装

这些说明将引导你使用 Apache Web 服务器从源代码安装 PHP。你应该通过发出 `su` 命令并输入超级用户密码来成为 `root` 用户以执行安装。

#### 从源代码编译 Apache

如果你已经安装了支持动态共享对象 (DSO) 的 Apache Web 服务器，可以跳过此部分。要检查你的 Web 服务器是否包含此功能，请运行以下命令：

```
$ httpd -l
```

如果输出中包含 `mod_so.c`，则表示包含 DSO 支持。请注意，你可能需要提供 `httpd` 的完整路径（例如，`/usr/local/apache/bin/httpd`）。

你首先从 [Apache HTTP Server 项目](http://httpd.apache.org) 下载最新的 Apache 源代码。撰写本文时，最新版本为 2.0.52，因此要下载的文件名为 `httpd-2.0.52.tar.bz2`。如果有更高版本可用，请确保在文件名出现的任何地方都替换为相应的版本号。

你需要将此文件保存到文件系统中的 `/usr/local/src` 或其他存放源代码的位置。使用 `bunzip2` 解压缩存档，如下所示：

```
# bunzip2 httpd-2.0.52.tar.bz2
```

文件解压缩后，将丢失 `.bz2` 文件扩展名。你使用 `tar` 提取此存档文件：

```
# tar xvf httpd-2.0.52.tar
```

文件将被提取到名为 `httpd-2.0.52` 的目录中。在继续之前，你应该切换到这个新目录：

```
# cd httpd-2.0.52
```
