PHP is such a powerful language that you can even use it to create desktop applications.
Furthermore, because PHP is an interpreted language, any such applications are likely to be highly portable.

The PHP-GTK extension implements an interface to the GIMP window toolkit, GTK+.
This provides PHP developers with the ability to create applications with a graphical front end that includes
windows, menus, buttons, and even drag-and-drop functionality.

Creating a complex graphical application is beyond the scope of this book. If you are interested in
learning more about PHP-GTK, however, see http://gtk.php.net .
