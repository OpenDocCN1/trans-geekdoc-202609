

```php
<?php
$now = time();
$original_tz = $_ENV["TZ"];
echo "The time now is " . date("H:i:s", $now) . "<br>";
putenv("TZ=US/Pacific");
echo "The time on the US West Coast is " .
    date("H:i:s", $now) . "<br>";
putenv("TZ=Europe/Paris");
echo "The time in France is " . date("H:i:s", $now) . "<br>";
putenv("TZ=Australia/Sydney");
echo "The time in Sydney is " . date("H:i:s", $now) . "<br>";
putenv("TZ=Asia/Tokyo");
echo "The time in Tokyo is " . date("H:i:s", $now) . "<br>";
putenv("TZ=$original_tz");
?>
```

请注意，清单 18.1 开始时会存储当前时区值，以便在您完成值更改后可以恢复它。

**存储时间** 时间戳在清单 18.1 开始时保存到 $now 中，以便相同的值可以传递给每个 `date` 函数。虽然 `date` 的第二个参数可以省略，但如果省略，脚本执行可能会在一秒钟过渡时进行，这将产生令人困惑的输出。

### 安全注意事项

希望您已经意识到，在 Web 服务器上拥有一个能够执行主机程序命令的脚本并不总是个好主意。事实上，在第 24 课“PHP 安全”中，您将学习如何使用 PHP 的安全模式对主机程序执行施加限制。

为了结束本课，您将学习如何确保主机程序执行始终以安全的方式进行。

### 转义 Shell 命令

请参阅清单 18.2 中的脚本，它为 `finger` 命令创建了一个 Web 表单界面。

### 清单 18.2. 从 Web 表单调用 `finger` 命令

```
<FORM ACTION="finger.php" METHOD="POST">
<INPUT NAME="username" SIZE=10>
<INPUT TYPE="SUBMIT" VALUE="Finger username">
</FORM>
<?php
if ($_POST["username"]) {
    $cmd = "finger {$_POST['username']}";
    echo "<PRE>" . `$cmd` . "</PRE>";
}
?>
```

如果在浏览器中运行此脚本并输入用户名，将显示 `finger` 信息。

然而，如果您改为输入分号后跟另一个命令——例如，`; ls`——则 `finger` 命令将在没有参数的情况下运行，然后您输入的第二个命令将被执行。根据您的 Web 服务器平台，可以使用其他符号产生类似的诡计。

这显然不是一件好事。您可能认为，以与 Web 服务器相同的用户身份运行进程只能造成有限的损害；然而，许多严重的漏洞利用可以利用这种行为。恶意用户可以发出诸如 `wget` 或 `lynx` 之类的命令，在服务器硬盘上安装敌对程序并运行它。这可能是一个 `rootkit`，试图利用其他服务器漏洞，也可能是一个脚本，通过耗尽系统资源来发动拒绝服务攻击。无论如何，向匿名用户授予这种访问 Web 服务器的权限都是坏消息。

为了保护自己免受这种攻击，您应该使用 `escapeshellcmd` 函数。任何可能被用来欺骗 Shell 执行非预期命令的字符都会加上反斜杠前缀。这样一来，不希望的字符实际上会变成命令的参数。

为了使清单 18.2 安全，构建 $cmd 的语句应更改为以下内容：

```
$cmd = escapeshellcmd("finger {$_POST['username']}");
```

现在，在表单中输入 ;ls 会导致执行的命令为 `finger \; ls`，实际上会尝试在系统上查找名为 ; 或 ls 的用户。

## 第 19 课. 使用 MySQL 数据库

在本课中，您将学习如何从 PHP 访问 MySQL 数据库。PHP 和 MySQL 的组合非常流行且强大，以至于发现不使用 MySQL 或至少其他数据库后端的 PHP 相当罕见。

### 使用 MySQL

本课假设您的 Web 服务器上已安装 MySQL，并且 PHP 已加载 MySQL 模块。有关安装 MySQL 的信息，请参阅 http://dev.mysql.com/doc/mysql/en/Installing.html，并要了解如何在 PHP 中激活 MySQL 支持，请参阅第 23 课“PHP 配置”。

![](img/2edc6e6954e3485ad7d94117645931d8_202_0.png)

**进一步阅读** 要了解 MySQL 数据库，请阅读 *在 24 小时内学会 MySQL*，作者是 Julie Meloni。或者，如需快速 SQL 语言指南，请参阅 *在 10 分钟内学会 SQL*，作者是 Ben Forta。

PHP 5 引入了 mysqli 扩展，它可以利用 MySQL 4.1 及更高版本中的新功能，也可以以面向对象的方式使用。本书专注于经典的 mysql 扩展，因为它仍然是许多 Web 托管提供商提供的版本，并且在 PHP 5 中仍然可用。

一般来说，如果您想使用本课中描述的经典 mysql 扩展之外的 mysqli，大多数函数名前缀为 mysqli 而非 mysql，但其行为方式相似。有关更多信息，请参阅 www.php.net/mysqli 的在线文档。

### 连接到 MySQL 数据库

您可以使用 mysql_connect 函数连接到 MySQL 数据库。三个参数定义连接参数：主机名、用户名和密码。在许多情况下，MySQL 服务器将与 PHP 运行在同一台机器上，因此此值仅为 localhost。典型的 mysql_connect 语句可能如下所示：

```
$db = mysql_connect("localhost", "chris", "mypassword");
```

![](img/2edc6e6954e3485ad7d94117645931d8_202_1.png)

**数据库主机名** 由于 MySQL 使用基于主机的身份验证，您必须提供正确的主机名——即允许建立连接的主机名。例如，您的 MySQL 服务器可能运行在 www.yourdomain.com 上，但可能仅配置为接受对 localhost 的连接。

除非您确定 MySQL 服务器运行在其他位置，否则要使用的主机名几乎总是 localhost。

`mysql_connect` 函数返回一个数据库链接标识符，在前面的示例中被分配给了 `$db`。此资源用作其他 MySQL 函数的参数。

请注意，传递给 `mysql_connect` 的连接参数不包括数据库名。事实上，连接到 MySQL 服务器后，选择数据库是一个独立的步骤；为此，您使用 `mysql_select_db` 函数。例如，以下语句选择 `mydb` 作为当前数据库：

```
mysql_select_db("mydb", $db);
```

链接标识符 `$db` 参数在 `mysql_select_db` 和许多其他 MySQL 函数中实际上不是必需的。如果省略，PHP 假设您指的是最近打开的 MySQL 连接。然而，在 MySQL 函数调用中始终包含链接标识符是良好的做法，以使代码更清晰。

调用 `mysql_select_db` 后，传递给 MySQL 的每个后续 SQL 语句都将在所选数据库上执行。

在脚本中使用完 MySQL 后，您可以使用 `mysql_close` 关闭连接并释放其资源，如下所示：

```
mysql_close($db);
```

### 执行 SQL 语句

用于将 SQL 语句传递给 MySQL 的函数是 mysql_query。它接受两个参数——查询本身和一个可选的链接标识符。

以下代码在 MySQL 数据库上为 $db 执行 CREATE TABLE SQL 语句：

```
$sql = "CREATE TABLE mytable (col1 INT, col2 VARCHAR(10))";
mysql_query($sql, $conn);
```

如果在 Web 浏览器中运行包含这些语句的脚本并检查 MySQL 数据库，您会发现已创建一个名为 mytable 的新表。

所有类型的 SQL 语句都可以通过 mysql_query 执行，无论它们以某种方式修改数据还是获取若干行。

### 更改数据库的命令

本课前面您已看到一个 CREATE TABLE 语句示例。其他数据定义语言 (DDL) 语句可以以类似方式执行，并且在没有遇到错误的情况下，它们将静默执行。您将在本课后面了解错误处理。

在执行被称为数据操纵语言 (DML) 的 DELETE、INSERT 或 UPDATE 语句 SQL 子集时，表中的若干行可能会受到查询影响。要了解实际受影响的行数，可以使用 mysql_affected_rows 函数。以下示例展示如何使用简单的 UPDATE 语句来实现此操作：

```
$sql = "UPDATE mytable SET col2 = 'newvalue' WHERE col1 > 5";
mysql_query($sql, $conn);
echo mysql_affected_rows($conn) . " row(s) were updated";
```

mysql_affected_rows 的参数是数据库链接标识符，调用此函数会返回最近一次查询所影响的行数。此 UPDATE 语句受影响的行数不一定与 WHERE 子句匹配的行数相同。如果新值与已存储的值相同，MySQL 不会更新该行。

![](img/2edc6e6954e3485ad7d94117645931d8_204_0.png)

**删除所有行** 如果执行没有 WHERE 子句的 DELETE 语句，则无论实际删除了多少行，mysql_affected_rows 返回的数字都是零。MySQL 只是清空表而不是逐行删除，因此没有可用的计数。
