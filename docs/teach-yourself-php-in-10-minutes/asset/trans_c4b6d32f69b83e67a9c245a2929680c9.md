## 第 18 课。主机程序执行

在本课中，你将了解 PHP 如何允许你在主机系统上执行程序，并处理产生的任何输出。

### 执行主机程序

PHP 可以以多种方式调用驻留在 Web 服务器上的外部程序。我们将在以下部分中逐一介绍。

#### passthru 函数

使用 passthru 函数是运行主机命令并将输出显示到屏幕上的最简单方法。作为参数传入的命令会在 Web 服务器上执行，并且任何生成的输出都会发送到浏览器。

以下是在 Unix/Linux 和 Windows 系统上都适用的简单示例：

```
passthru("hostname");
```

主机系统会执行 hostname 命令并显示其输出。hostname 命令用于查找系统主机名并将其显示。

passthru 的可选第二个参数允许你查找命令的退出代码。如果你想确定命令是否成功，这通常很有用——所有程序在成功完成时都应该返回退出代码零——或者用于测试可能有多个返回值的命令。

**命令输出** Web 浏览器窗口中仅显示标准输出流，因此如果你想查看主机命令生成的警告和错误，必须重定向 stderr 流。

例如，你可以在带有 Bourne shell 的 Unix 服务器上使用 passthru("cmd 2>&1")。

最常见的非零返回值是 1（表示非特定错误）和 127（表示你尝试运行的命令找不到）。特定于特定程序的其他错误代码通常会有文档说明。

下面的示例对 hostname 命令进行系统调用，并根据其返回代码采取相应操作：

```
passthru("hostname", $return);
switch ($return) {
case 0: echo "Command completed successfully";
break;
case 127: echo "Command could not be found";
break;
default: echo "Command failed with code $return";
}
```

#### 使用反引号

反引号 (`) 字符是一个方便的快捷方式，可用于指示在 Web 服务器本身上执行的系统命令。两个反引号之间的字符串会被执行，并返回主机系统生成的响应。

下面的示例与 passthru 示例等效，但使用了反引号语法：

```
echo `hostname`;
```

使用反引号，你可以将主机命令的结果赋值给变量，如下面的语句所示：

```
$hostname = `hostname`;
```

事实上，反引号字符可以在 PHP 脚本的任何位置使用。它们会立即中断程序执行以调用主机命令，并将结果值替换到脚本中。下面的示例表明，主机命令的结果甚至可以在条件中使用：

```
if (chop(`hostname`) == "hal9000") {
    echo "Good evening, Dave";
}
```

因为 hostname 的结果以回车符结尾，这样在命令 shell 中运行时输出看起来更整洁，所以前面的示例使用 chop 来确保只比较非空白字符。

**退出代码** 使用反引号时无法获取退出代码。相反，你应该使用 exec 函数，它的工作方式与 passthru 类似，但会将命令输出作为字符串返回。可选的第二个参数可用于获取退出代码。

#### 构建命令字符串

命令作为参数传递给 `passthru` 或 `exec`，或者只是包含在反引号中的字符串。因此，如果需要，你可以使用变量或分阶段构建命令字符串。

变量替换发生在双引号命令字符串中，但如果字符串用单引号括起来，任何以美元符号开头的标识符都将被视为 shell 变量。

PHP 中看起来最奇怪的语句可能是使用反引号执行存储在字符串中的命令。其形式如下：

```
`$cmd`;
```

变量 `$cmd` 可以包含任何系统命令，如果你确实不关心命令的输出是什么，这也是有效的。

不过，请注意，终止分号是必需的。右反引号会关闭主机命令，但不会终止 PHP 语句。

### 主机环境

现在让我们来看看 PHP 如何与 Web 服务器的主机环境交互。

#### 检测主机平台

因为不同类型的系统有不同的可用主机命令集，如果你编写的脚本可能在不同平台上执行，那么检测正在使用哪种 Web 服务器很有用。

常量 PHP_OS 包含表示操作系统的字符串。检查它的最常见原因是查明脚本是否在 Windows 平台上运行——毕竟，大多数类 Unix 系统，甚至 Mac OS，的行为方式非常相似。

Windows Web 服务器上的 PHP_OS 值可能是 Windows、WINNT 或 WIN32，将来可能会出现其他 PHP_OS 值。因此，要测试 Windows 平台，你应该对字符串的前三个字符进行不区分大小写的比较。下面的条件展示了其中一种方法：

```php
if (strtoupper(substr(PHP_OS, 0, 3)) == "WIN") { ... }
```

#### 环境变量

$_ENV 超全局数组包含每个存在的环境变量的一个元素。环境变量来自底层操作系统，PHP 可用的那些来自 PHP 和 Web 服务器运行所在的环境。

PATH 环境变量为系统提供了一系列位置列表，用于搜索可执行程序。系统会依次检查每个位置，直到找到程序或没有更多位置可尝试为止，否则会发生错误。

查找当前路径值就像使用以下语句一样简单：

```php
echo $_ENV["PATH"];
```

在 Unix/Linux 系统上，它可能如下所示：

```
/bin:/usr/bin:/usr/X11R6/bin:/home/chris/bin
```

然而，在 Windows 系统上，它可能如下所示：

```
C:\WINDOWS\system32;C:\WINDOWS
```

请注意，不同操作系统的格式差异很大。Unix/Linux 版本使用冒号分隔位置，并在路径名中使用正斜杠，而 Windows 版本使用分号和反斜杠。出于这个原因，PHP 提供了特定于主机的常量 DIRECTORY_SEPARATOR 和 PATH_SEPARATOR，使你能够为每个操作系统找到要使用的适当符号。

在许多情况下，重置 PATH 值取决于底层平台；例如，即使使用了正确的 PATH_SEPARATOR 常数，C:/WINDOWS 在 Linux 服务器上也不存在。不过，这使你可以很容易地将当前工作目录或其相对目录添加到路径中。

下面的示例将相对于当前位置的 bin 目录添加到系统路径的开头：

```
$newpath = getcwd() . DIRECTORY_SEPARATOR . "bin" .
PATH_SEPARATOR . $_ENV["PATH"];
putenv("PATH=$newpath");
```

putenv 函数接受一个参数，其中环境变量被赋予新值。此更改不是永久性的，新值仅在脚本结束前被记住。

#### 时区

TZ 环境变量包含服务器的时区设置。通过覆盖此值，你可以显示世界其他地方的时间，而无需知道正确的偏移量或执行任何日期运算。

世界大多数主要城市或地区都有易于记忆或推断的 TZ 值（例如，Europe/London、US/Pacific）。它也可以是相对于格林威治标准时间或其他常见时区的值，例如 GMT-8 或 EST。在大多数系统上，你可以通过查看 /usr/share/zoneinfo 中的项目来找到可用的时区。
