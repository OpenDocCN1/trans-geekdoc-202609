## 第 10 课。使用类

在本节中，你将学习面向对象 PHP 的基础知识。你将了解如何定义类，以及如何访问第三方类中的方法和属性。

### 面向对象 PHP

如果愿意，PHP 可以采用面向对象（OO）风格编写。在 PHP5 中，该语言的 OO 功能得到了显著增强。

如果你熟悉其他面向对象语言，例如 C++ 或 Java，你可能更倾向于使用 OO 方法编写 PHP；而如果你习惯其他过程式语言，则可能完全不想使用对象。毕竟，解决同一问题有很多种方法。

如果你对编程和 PHP 都陌生，那么目前可能对这两种方式都没有强烈的偏好。诚然，如果你完全没有编程经验，面向对象概念比有过程式语言背景时更容易理解，但即便如此，本书中的十分钟课程也讲不完 OO 方法！

本节的目标是介绍如何在 PHP 中创建和引用类，以便如果你偏好使用对象，可以开始使用 OO 方法开发脚本。不过，最重要的是，你将能够学习并使用许多可用于 PHP 的免费第三方类库，这些类库可从 www.phpclasses.org 等资源获取，还包括 PEAR 的一部分内容（你将在第 25 课“使用 PEAR”中了解 PEAR）。

### 什么是类？

类是定义对象的模板结构。它可以包含函数（也称为类方法）和变量（也称为类属性或特性）。

每个类都包含一组 PHP 语句，用于定义如何执行你希望频繁重复的任务或一组任务。类可以包含私有方法（仅在内部用于执行类的功能）和公共方法（你可用于与类交互）。

一个好的类隐藏其内部实现，只包含为其功能提供简单接口所需的公共方法。如果你将复杂的代码块封装到类中，那么任何使用该类的脚本都无需担心特定操作是如何执行的。所需的只是了解类的公共方法。

由于 PHP 有许多可用的免费第三方类，在许多情况下，你无需浪费时间去实现一个已经可以免费获得的功能。

### 何时使用类

起初，使用类似于将函数模块化到包含文件中看似没有任何真正的优势。面向对象不一定是编程的更好方法，而是一种不同的思维方式。是否选择开发自己的类是个人偏好的问题。

面向对象编程的一个优势是，它可以让你的代码轻松扩展到非常大的项目。在面向对象编程中，一个类可以继承另一个类的属性并对其进行扩展；这意味着已经开发的功能可以被重用并调整以适应特定情况。这被称为继承，是面向对象开发的关键特性。

当你读完本书后，如果有兴趣进一步了解面向对象编程，可以参阅 Anthony Sintes 所著的 Sams Teach Yourself Object-Oriented Programming in 21 Days。

### 类的样子

类是各种函数和变量的分组，在 PHP 中编写时也正是这个样子。类定义与函数定义非常相似；它以关键字 class 和一个标识符开头，后跟包含在一对花括号 ({}) 中的类定义。

以下是一个简单的类示例，用于展示类的样子。此示例只包含一个属性 myValue 和一个方法 myMethod（该方法不执行任何操作）：

```
class myClass {
  var $myValue;
function myMethod() {
    return 0;
}
}
```

如果你已经熟悉面向对象编程，并希望快速入门 OO PHP，可以参阅 www.php.net/manual/en/language.oop5.php 上的在线文档。

### 创建和使用对象

要从类中创建对象实例，在 PHP 中使用 new 关键字，如下所示：

```
$myObject = new myClass;
```

在此示例中，myClass 是必须在脚本中定义的类名（通常在包含文件中），而 $myObject 成为一个 myClass 对象。

**多个对象** 你可以在同一个脚本中多次使用同一个类，只需从该类创建新实例但使用新的对象名称即可。

### 方法和属性

myClass 中定义的方法和属性可以为 $myObject 引用。以下是通用示例：

```
$myObject->myValue = "555-1234";
$myObject->myMethod();
```

由连字符和大于号组成的箭头符号 (->) 表示给定对象的方法或属性。要在类定义中引用当前对象，请使用特殊名称 $this。

以下示例定义了 myClass，其中包含引用对象属性之一的方法：

```
class myClass {
var $myValue = "Jelly";

function myMethod() {
echo "myValue is " . $this->myValue . "<br>";
}
}
```

```
$myObject = new myClass;
$myObject->myMethod();
$myObject->myValue = "Custard";
$myObject->myMethod();
```

此示例对 myMethod 进行两次单独调用。第一次显示 myValue 的默认值；类中的赋值为属性指定默认值。第二次调用发生在该属性被赋予新值之后。类使用 $this 引用其自身属性，并不在意（甚至不知道）在脚本中其名称为 $myObject。

如果类包含一个名为构造函数的特殊方法，则在创建对象时可以在括号中提供参数，这些值随后会被传递给构造函数。这通常用于为每个对象实例初始化一组属性，其形式类似于以下内容：

```
$myObject = new myClass($var1, $var2);
```

### 使用第三方类

学习如何使用类的最佳方法是使用一个类。让我们来看看由 Manuel Lemos 编写的一个流行的第三方类，它提供了一种全面验证电子邮件地址的方法。你可以从 www.phpclasses.org/browse/file/28.html 下载此类，并将文件保存到本地名为 email_validation.php。

Manuel 的类不仅通过检查格式是否正确来验证电子邮件地址，还通过执行域名查找来确保其可投递。它甚至会连接到远程邮件服务器，以确保给定的邮箱实际存在。

- **域名查找** 如果你在基于 Windows 的 Web 服务器上跟随此示例，则需要下载额外文件 getmxrr.php，以向 PHP 添加合适的域名查找函数。你可以从 www.phpclasses.org/browse/file/2080.html 下载该文件。

email_validation.php 脚本定义了一个名为 email_validation_class 的类，因此你首先需要创建一个名为 $validator 的验证器对象实例，如下所示：

```
$validator = new email_validation_class;
```

你可以为新类设置多个属性。有些属性是类正常工作所必需的，而其他属性则允许你更改默认行为。
