## 算术

正如你所料，PHP 包含所有基本算术运算符。如果你没有使用过其他编程语言，所使用的符号可能并不全都明显，因此我们将快速浏览 PHP 中的基本算术规则。

### 算术运算符

加法使用加号（ `+` ）执行。此示例将 6 和 12 相加并显示结果：

```
echo 6 + 12;
```

减法使用减号（ `-` ）执行，减号也用作连字符。此示例从 24 中减去 5：

```
echo 24 - 5;
```

减号也可用于对数字求负（例如，20）。

乘法使用星号（ `*` ）执行。此示例显示 4 和 9 的乘积：

```
echo 4 * 9;
```

除法使用正斜杠（ `/` ）执行。此示例用 48 除以 12：

```
echo 48 / 12;
```

![](img/2edc6e6954e3485ad7d94117645931d8_57_0.png)

**除法** 当你除以两个整数时，如果除得尽，结果是整数。否则，它是双精度浮点数。带小数的结果不会被四舍五入为整数。

### 取模

取模使用百分号（ % ）执行。此示例显示 3，即 21 除以 6 的余数：

```
echo 21 % 6;
```

![](img/2edc6e6954e3485ad7d94117645931d8_58_0.png)

**取模** 取模运算符可以通过 `$number % 2` 来测试一个数字是奇数还是偶数。对于所有偶数，结果为 `0`；对于所有奇数，结果为 `1`（因为任何奇数除以 2 的余数都是 1）。

## 自增和自减

在 PHP 中，你可以使用双加号（`++`）或双减号（`--`）符号来递增或递减一个数字。以下两条语句都给 `$number` 加 1：

```
$number++;
```

```
++$number;
```

运算符可以放在变量的任一侧，其位置决定递增发生的时机。

此语句在显示结果之前从 `$countdown` 减去 1：

```
echo --$countdown;
```

但是，以下语句在递减之前显示 `$countdown` 的当前值：

```
echo $countdown--;
```

自增和自减运算符通常用于循环中。以下是一个典型的 `for` 循环，使用计数器将代码段重复 10 次：

```
for ($count=1; $count<=10; $count++) {
echo "Count = $count<br>";
}
```

在这种情况下，代码只是在循环的每次迭代中输出 $count 的值。

## 复合运算符

当你想要对现有变量应用算术运算时，复合运算符提供了一个方便的快捷方式。以下示例使用复合加法运算符将 6 加到 $count 的当前值：

```
$count += 6;
```

其效果是获取 $count 的初始值，加上 6，然后将其重新赋值给 $count。事实上，该操作等同于执行以下操作：

```
$count = $count + 6;
```

所有基本算术运算符都有对应的复合运算符，如表 5.1 所示。

### 表 5.1。复合运算符

| 运算符 | 等价于 |
| :--- | :--- |
| $a += $b | $a = $a + $b; |
| $a -= $b | $a = $a - $b; |
| $a *= $b | $a = $a * $b; |
| $a /= $b | $a = $a / $b; |
| $a %= $b | $a = $a % $b; |

## 运算符优先级

运算符优先级规则指定表达式求值的顺序。例如，以下语句是模棱两可的：

```
echo 3 * 4 + 5;
```

是先将 3 和 4 相乘，然后将 5 加到结果上，总共得到 17？还是先将 4 和 5 相加，然后乘以 3，得到 27？在脚本中运行此语句将向你显示，在 PHP 中，结果是 17。

原因是乘法的优先级高于加法，因此当这些运算符出现在同一表达式中时，乘法首先执行，使用紧邻乘法运算符的值。

要告诉 PHP 你明确希望先执行加法，可以使用括号，如以下示例所示：

```
echo 3 * (4 + 5);
```

在这种情况下，结果是 27。

在 PHP 中，算术运算符的优先级遵循你可能在学校学过的 PEMDAS 规则：括号、乘方、乘法/除法、加法/减法。

PHP 的完整运算符优先级列表包括许多你尚未接触过的运算符

## 数字数据类型

你已经看到，PHP 为每个值分配一种数据类型，而数字数据类型是整数和双精度浮点数，用于整数。

要检查值是否属于这两种类型之一，你使用 `is_float` 和 `is_int` 函数。同样，要在一次操作中检查任意一种数字数据类型，可以使用 `is_numeric` 。

以下示例包含一个条件，用于检查 `$number` 的值是否为整数：

```php
$number = "28";
if (is_int($number)) {
    echo "$number is an integer";
}
else {
    echo "$number is not an integer";
}
```

因为该变量的实际声明赋予了一个字符串值（尽管包含一个数字），所以条件不成立。

尽管前面示例中的 `$number` 是一个字符串，但 PHP 足够灵活，允许将此值用于数字运算。以下示例表明，包含数字的字符串值可以被递增，并且结果值是一个整数：

```php
$number = "6";
$number++;
echo "$number has type " . gettype($number);
```

## 了解 NULL

NULL 值是一种独立的数据类型——一个实际上没有值的值。它没有数值，但与整数零比较的结果为真：

```php
$number = 0;
$empty = NULL;
if ($number == $empty) {
    echo "The values are the same";
}
```

**类型比较** 如果你想检查条件中的值和数据类型是否都相同，请使用三重等号比较运算符（===）。

## 数字函数

让我们来看看 PHP 中可用的一些数字函数。

## 数字舍入

有三个不同的 PHP 函数可用于将小数舍入为整数。

你使用 ceil 或 floor 分别将数字向上或向下舍入到最近的整数。例如，ceil(1.3) 返回 2，而 floor(6.8) 返回 6。

**负数舍入** 注意负数的舍入方式。floor(-1.1) 的结果是 -2，即数值上下一个更低的整数，而不是 -1。同样，ceil(-2.5) 返回 -2。

要将值舍入到最近的整数，你使用 round。小数部分小于 .5 会向下舍入，而 .5 或更高会向上舍入。例如，round(1.3) 返回 1，而 round(1.5) 返回 2。

round 函数还可以接收一个可选的精度参数。以下示例显示保留两位小数的值：

```
$score = 0.535;
echo round($score, 2);
```

显示的值为 0.54；第三位小数是 5，导致最后一位向上舍入。

你还可以将 round 与负精度值一起使用，将整数舍入到指定的有效位数，如以下示例所示：

```
$distance = 2834;
echo round($distance, -2);
```

## 比较

要查找一组数字中最小和最大的值，你分别使用 min 和 max。这些函数接受两个或多个参数，并分别返回列表中数值最低或最高的元素。

此语句将显示变量 $a 和 $b 中较大的一个：

```
echo max($a, $b);
```

可比较的参数数量没有限制。以下示例从一组较大的值中查找最小值：

```
echo min(6, 10, 23, 3, 88, 102, 5, 44);
```

毫不奇怪，显示的结果是 3。

## 随机数

你使用 `rand` 生成随机整数，使用系统内置的随机数生成器。`rand` 函数可选地接受两个参数，指定从中选取随机数的数字范围。

**随机限制** 常量 `RAND_MAX` 包含系统上可以生成的最高随机数值。此值在不同平台之间可能有所不同。

以下语句选取 1 到 10 之间的随机数并显示它：

```
echo rand(1, 10);
```

你可以将此命令放入脚本中运行几次，以查看每次运行时数字都会发生变化。

事实上并不存在计算机生成的随机数一说。实际上，数字是从一个与真随数具有非常相似特性的非常长的序列中选取的。为了确保你每次都从这个序列的不同位置开始，你必须通过调用 `srand` 函数来对随机数生成器进行 *设置种子*；不需要参数。
