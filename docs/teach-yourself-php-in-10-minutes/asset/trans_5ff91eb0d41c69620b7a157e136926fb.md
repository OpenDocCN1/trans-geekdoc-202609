## 第 20 课. 数据库抽象

在本课中，你将学习如何使用单个接口从 PHP 访问不同的数据库。数据库抽象是一种非常强大的技术；它允许你为非特定数据库后端编写脚本，然后只需更改连接参数即可轻松移植。

## 安装 DB 类

要检查 Web 服务器上是否安装了 DB 类，可以运行以下命令以显示已安装的软件包列表：

```
$ pear list
```

如果需要安装 DB 类，请运行以下命令：

```
$ pear install DB
```

请注意，安装 PEAR 类需要管理员权限，因此如果你使用的是共享 Web 托管服务，可能需要联系系统管理员。

由于使用了底层 PHP 扩展，因此从 DB 类与每种类型的数据库通信时不需要额外的数据库驱动程序。

## 数据源名称

要通过 DB 类连接到数据库，需要构建一个有效的数据源名称 (DSN)，它是一个包含连接所需所有参数的单个字符串，其构建方式与你用于访问受保护的网页或 FTP 服务器的 URL 类似。

以下 DSN 可用于连接在 localhost 上运行的 MySQL 数据库：

```
mysql://chris:mypassword@localhost/mydb
```

此 DSN 的组件包括数据库后端类型 (mysql)、用户名 (chris)、密码 (mypassword)、主机 (localhost) 和数据库名称 (mydb)。

DSN 的完整语法定义如下，可用于构建它的组件列于表 20.2 中。

```
phptype(dbsyntax)://username:password@protocol+hostspec/
database?option=value
```

### 表 20.2. DSN 的组件

| 组件 | 描述 |
|---|---|
| phptype | 要使用的数据库后端协议（例如，mysql、oci8） |
| dbsyntax | 与 SQL 语法相关的可选参数；对于 ODBC，应包含数据库类型（例如，access、mssql） |
| username | 数据库登录用户名 |
| password | 数据库登录密码 |
| protocol | 连接协议（例如，tcp、unix） |
| hostspec | 主机规范，可以是主机名或主机名:端口 |
| database | 数据库名称 |
| option | 其他连接选项；多个选项之间用 & 分隔 |

如连接到 MySQL 的第一个示例所示，DSN 的每个组件并非全部必需。确切语法取决于数据库后端需要的信息。

例如，连接到不需要用户名、密码或 hostspec 的 SQLite 如下所示：

```
sqlite:///path/to/dbfile
```

另一方面，连接到未在标准端口号上运行的 PostgreSQL 服务器需要更复杂的内容，例如：

```
pgsql://username:password@tcp(hostname:port)/dbname
```

数据库类型 phptype 参数的数据库类型值为表 20.1 第一列中显示的值。

## 使用 DB 类

要在脚本中开始使用 DB 类，只需使用以下语句将其包含：

```
include "DB.php";
```

要连接到数据库，请在 DB 类上调用 connect 方法，并将 DSN 作为参数传递：

```
$db = DB::connect($dsn);
```

$db 返回值是一个对象，可以在其上调用 DB 类方法以执行不同类型的数据库操作。

> **数据库对象** 请注意，不能使用 `new` 关键字创建 DB 对象的新实例。必须调用 `DB::connect` 以启动新的数据库会话。

如果数据库连接失败，返回值是一个 DB_Error 对象，可以使用 `isError` 和 `getMessage` 方法对其进行分析。以下代码显示了带有错误检查的数据库连接尝试：

```
$db = DB::connect($dsn);
if (DB::isError($db)) {
    echo "Connection error: " . $db->getMessage();
    exit;
}
```

只有在传递的参数是 `DB_Error` 对象时，函数 `isError` 才返回 `True`，这表明数据库连接存在某种问题。然后可以在 `DB_Error` 对象上调用 `getMessage` 方法，以从数据库服务器检索实际错误消息。

> **连接错误** 无论连接是否成功，`$db` 都会被赋予某种对象值。其值永远不会是 `NULL` 或 `FALSE`。

## 执行查询

要通过 DB 类执行 SQL 查询，请使用 query 方法。返回值取决于正在执行的查询类型，但如果发生任何错误，将返回 DB_Error 对象，并可以以与连接错误相同的方式检测和诊断错误。

以下示例执行存储在 $sql 中的查询并进行错误检查：

```php
$res = $db->query($sql);
if (DB::isError($res)) {
    echo "Query error " . $res->getMessage();
    exit;
}
```

如果提交的查询是 INSERT、UPDATE 或 DELETE 语句，返回值是常量 DB_OK。可以通过在数据库对象本身上调用 affectedRows 方法来了解语句影响的行数，如以下示例所示：

```php
$sql = "UPDATE mytable SET col2 = 'newvalue' WHERE coll > 5";
$res = $db->query($sql);
echo $db->affectedRows() . " row(s) were affected";
```

## 检索所选数据

如果发出 SELECT 语句，查询的返回值是 DB_Result 对象，可用于从结果数据集中访问记录。

要查看数据集中的行数和列数，请分别使用 numRows 和 numCols 方法，如本示例所示：

```php
$sql = "SELECT * FROM mytable";
$res = $db->query($sql);
echo "Query found " . $res->numRows . " row(s) ".
    "and " . $res->numCols . " column(s)";
```

可以在 DB_Result 对象上使用 fetchRow 方法一次以数组结构返回一行数据。然后会增加结果指针，以便每次随后调用 fetchRow 都按顺序返回下一行数据。以下代码演示了如何在循环中使用 fetchRow 来获取查询返回的所有行：

```php
$sql = "SELECT coll, col2 FROM mytable";
$res = $db->query($sql);
while ($row = $res->fetchRow()) {
    echo "coll = " . $row[0] . ", ";
    echo "col2 = " . $row[1] . "<br>";
}
```
