

检查该值是否在 12 到 17 之间，因为初始的 `if` 条件确保如果 `$hour` 小于 12，PHP 根本不会执行到 `elseif`。

如果所有其他条件都不满足，则会执行 `else` 子句中的代码。对于 `$hour` 值为 17 或更大的情况，`if` 和 `elseif` 条件都不会为真。

**elseif 与 else if** 在 PHP 中，你也可以将 `elseif` 写为两个词：`else if`。PHP 对这种变体的解释略有不同，但其行为完全相同。

## `switch` 语句

`if` 语句可以包含你需要的任意数量的 `elseif` 子句，但包含太多此类子句往往会导致代码冗长，而另一种可行的替代方案是 `switch`。`switch` 是一种条件语句，可以采用更加紧凑的格式拥有多个分支。

以下示例使用 `switch` 语句将 `$name` 与两个列表进行比较，以查看它是否属于朋友：

```
switch ($name) {
case "Damon":
case "Shelley":
    echo "Welcome, $name, you are my friend";
    break;
case "Adolf":
case "Saddam":
    echo "You are no friend of mine, $name";
    break;
default:
    echo "I do not know who you are, $name";
}
```

每个 `case` 语句定义一个值，匹配该值时将执行接下来的 PHP 代码块。如果将你的名字赋给 `$name` 并运行此脚本，当你的名字是 Damon 或 Shelley 时，系统会欢迎你是朋友；如果你的名字是 Adolf 或 Saddam，系统会告诉你不是我的朋友。如果你有其他任何名字，脚本会告诉你它不知道你是谁。

在相关的 PHP 代码之前可以有任意数量的 `case` 语句。如果 `switch` 语句正在测试的值（在此例中为 `$name`）与其中任何一个匹配，则随后的任何 PHP 代码都将执行，直到遇到 `break` 命令为止。

跳出 `break` 语句在 `switch` 语句中非常重要。当一个 `case` 语句匹配后，随后的任何 PHP 代码都将执行，即使还有另一个检查不同值的 `case` 语句。这种行为有时可能有用，但大多数情况下不是你想要的，所以请记得在每个 `case` 后面加上 `break`。

## 循环

PHP 提供三种类型的循环结构，它们都做同样的事情：以略有不同的方式多次重复执行一段代码。

### while 循环

while 关键字在括号中获取一个条件，随后的代码块会在该条件为真时重复执行。如果条件最初为假，则代码块根本不会被重复执行。

> **无限循环** 重复执行的代码必须执行某些操作来影响条件，使得循环条件最终不再满足；否则，循环将永远重复下去。

以下示例使用 while 循环显示 1 到 10 的平方数：

```
$count = 1;
while ($count <= 10) {
    $square = $count * $count;
    echo "$count squared is $square <br>";
    $count++;
}
```

计数器变量 $count 被初始化为值 1。while 循环计算该数字的平方并显示它，然后将 $count 的值加 1。++ 运算符在其前面的变量值上加 1。

只要条件 $count <= 10 为真，循环就会重复，因此前 10 个数字及其平方会依次显示，然后循环结束。

### do 循环

do 循环与 while 循环非常相似，只是条件位于重复代码块之后。正因为如此，即使条件最初为假，循环代码也至少会执行一次。

以下 do 循环与前面的示例等效，显示 1 到 10 的数字及其平方：

```
$count = 1;
do {
  $square = $count * $count;
  echo "$count squared is $square <br>";
  $count++;
} while ($count <= 10);
```

### **for** 循环

for 循环提供了一种创建循环的紧凑方式。以下示例执行与前两个示例相同的循环：

```
for ($count = 1; $count <= 10; $count++) {
  $square = $count * $count;
  echo "$count squared is $square <br>";
}
```

如你所见，使用 **for** 可以让你用比 **while** 和 **do** 少得多的代码来完成相同的事情。

**for** 语句由三个部分组成，用分号分隔：

- 第一部分是一个表达式，在循环开始时只求值一次。在前面的示例中，你初始化了 $count 的值。
- 第二部分是条件。只要条件为真，循环就继续重复。与 **while** 循环一样，如果条件开始时为假，则随后的代码块根本不会被执行。
- 第三部分是一个表达式，在每次循环结束时只求值一次。在前面的示例中，$count 在每行输出显示后加 1。

### 嵌套条件和循环

到目前为止，你只见过条件和循环的简单示例。但是，你可以将这些结构相互嵌套，以创建一些相当复杂的规则来控制脚本的流程。

> **请记住缩进** 脚本中的流程控制越复杂，缩进代码就越重要，以便清楚哪些代码块对应哪些结构。

## 跳出循环

你已经学习了在 `switch` 语句中使用关键字 `break`。你也可以在循环结构中使用 `break` 来告诉 PHP 立即退出循环并继续执行脚本的其余部分。

`continue` 关键字用于结束循环的当前迭代。但是，与 `break` 不同，脚本会跳回同一个循环的顶部并继续执行，直到循环条件不再满足。

## 使用函数

函数用于将可能包含许多行代码的任务变成可以使用单个指令调用的例程。

PHP 包含许多执行各种有用任务的函数。有些是内置在 PHP 语言中的；其他则更加专业，只有在安装 PHP 时激活了某些扩展才可用。

在线 PHP 手册（www.php.net）是一个非常宝贵的参考资料。除了语言中每个函数的文档外，手册页面还附有用户提交的技巧和示例，如果你愿意，甚至可以提交自己的评论。

**在线参考** 要快速调出任何函数的 PHP 手册页面，请使用此快捷方式：www.php.net/function_name。

你已经使用 date 函数生成了一个包含当前日期格式化版本的字符串。让我们更仔细地看看第 1 课“了解 PHP”中的那个示例是如何工作的。示例如下所示：

```
echo date('j F Y');
```

在线 PHP 手册为 date 提供的原型如下：

```
string date (string format [, int timestamp])
```

这意味着 date 接受一个名为 format 的字符串参数以及可选的整数 timestamp。它返回一个字符串值。此示例将 j F Y 作为 format 参数发送给函数，但省略了 timestamp。echo 命令显示返回的字符串。

**原型** 每个函数都有一个原型，用于定义它接受多少个参数、参数的数据类型以及返回什么值。可选参数用方括号 ([ ]) 表示。

## 定义函数

除了内置函数外，PHP 还允许你定义自己的函数。使用自己的函数有很多好处。不仅当同一段代码需要执行多次时不需要多输入代码，自定义函数还能让你的脚本更易于维护。如果你想更改任务的执行方式，只需在函数定义中更新一次程序代码，而不是在脚本中出现的每个位置都修复它。

> **模块化代码** 将任务分组到函数中是*模块化*代码的第一步——这一点在脚本规模变大并变得更加复杂时，对于保持脚本可维护性尤其重要。

以下是一个简单示例，展示如何在 PHP 中定义和使用函数：

```php
function add_tax($amount) {
   $total = $amount * 1.09;
   return $total;
}

$price = 16.00;
echo "Price before tax: $price <br>";
echo "Price after tax: ";
echo add_tax($price);
```

`function` 关键字定义一个名为 `add_tax` 的函数，用于执行随后的代码块。构成函数的代码始终包含在花括号中。在函数名后将 `$amount` 放在括号中，规定 `add_tax` 接受一个单个参数，该参数将存储在函数内名为 `$amount` 的变量中。

函数代码的第一行是一个简单的计算，将 `$amount` 乘以 1.09（相当于在该值上加 9%），并将结果赋给 `$total`。`return` 关键字后跟函数在脚本中被调用时要返回的值。

运行此示例会产生以下输出：

```
Price before tax: 16
Price after tax: 17.44
```
