
精度说明符用于浮点数，以指定要显示的小数位数。最常见的用法是与货币值一起使用，以确保两位分位数始终出现，即使是整数美元金额。

精度值跟在可选宽度说明符之后，由句点后跟要显示的小数位数表示。以下示例使用 %.2f 显示不带宽度说明符的货币值：

```php
$price = 6;
printf("The price is %.2f", $price);
```

价格格式正确如下：

价格是 6.00

**浮点宽度** 对于浮点数，宽度说明符仅表示小数点前的数字宽度。例如，%6.2f 实际上长度为九个字符，包含句点和两位小数。

## 使用 sprintf

sprintf 函数用于将格式化的字符串赋值给变量。语法与 printf 相同，但格式化后的值不是作为结果输出，而是由函数作为字符串返回。

例如，要将格式化的价格值赋给新变量，可以执行以下操作：

```php
$new_price = sprintf("%.2f", $price);
```

适用于 printf 的所有格式说明符规则也适用于 sprintf 。

## 字符串函数

让我们来看看 PHP 中可用的其他一些字符串函数。字符串函数的完整列表可在在线手册中找到，网址为 www.php.net/manual/en/ref.strings.php 。

### 大小写转换

您可以使用 strtoupper 或 strtolower 分别将字符串的大小写切换为全大写或全小写。

以下示例演示了这对混合大小写字符串的影响：

```php
$phrase = "I love PHP";
echo strtoupper($phrase) . "<br>";
echo strtolower($phrase) . "<br>";
```

显示的结果如下：

```
I LOVE PHP
i love php
```

如果只想大写字符串的第一个字符，请使用 ucfirst ：

```php
$phrase = "welcome to the jungle";
echo ucfirst($phrase);
```

您还可以使用 ucwords 大写每个单词的首字母，这对于姓名很有用：

```php
$phrase = "green bay packers";
echo ucwords($phrase);
```

ucfirst 和 ucwords 都不会影响字符串中已经是大写的字符，因此如果要确保所有其他字符都是小写，必须将这些函数与 strtolower 结合使用，如以下示例所示：

```php
$name = "CHRIS NEWMAN";
echo ucwords(strtolower($name) );
```

### 解析字符串

`substr` 函数允许通过指定字符串内的起始位置和长度参数来提取子字符串。以下示例演示了此操作：

```php
$phrase = "I love PHP";
echo substr($phrase, 3, 5);
```

对 `substr` 的此调用将返回从位置 3 开始且长度为 5 个字符的 `$phrase` 部分。请注意，位置值从零开始，而不是从一开始，因此实际显示的子字符串是 `ove P` 。

如果省略长度参数，则返回的值是从给定位置到字符串末尾的子字符串。以下语句为 `$phrase` 生成 `love PHP` ：

```php
echo substr($phrase, 2);
```

如果位置参数为负数，`substr` 将从字符串末尾开始计数。例如，以下语句显示字符串的最后三个字符，在此示例中为 `PHP` ：

```php
echo substr($phrase, -3);
```

如果需要知道字符串的长度，请使用 `strlen` 函数：

```php
echo strlen($phrase);
```

要查找字符或字符串在另一字符串中的位置，可以使用 `strpos` 。第一个参数通常称为 `haystack` ，第二个称为 `needle` ，以指示它们之间的关系。

以下示例显示电子邮件地址中 `@` 字符的位置：

```php
$email = "chris@lightwood.net";
echo strpos($email, "@");
```

**字符串位置** 请记住，字符串中的字符位置从左侧开始编号，从零开始。位置 1 实际上是字符串中的第二个字符。当 strpos 在比较的字符串开头找到匹配项时，返回值为零，但当未找到匹配项时，返回值为 FALSE 。

必须检查返回值的类型以确定这种差异。例如，条件 strpos($a, $b) == 0 仅在 $b 与 $a 的第一个字符匹配时才为真。

strstr 函数从字符或字符串出现的位置开始提取字符串的一部分，直到字符串末尾。这是一个便捷函数，可免去您同时使用 strpos 和 substr 的操作。

以下两条语句等效：

```php
$domain = strstr($email, "@");

$domain = substr($email, strpos($email, "@"));
```

## 第 7 课。使用数组

在本课中，您将学习如何在 PHP 中使用数组来存储和检索索引数据。

### 什么是数组？

_数组_ 是一种可以存储并对一组值建立索引的变量类型。当要存储的数据具有共同点或逻辑上被分组为一组时，数组非常有用。

### 创建和访问数组

假设您想存储一年中每个月的平均气温。使用单值变量（也称为 _标量变量_）时，您需要 12 个不同的变量（例如 `$temp_jan`、`$temp_feb` 等）来存储这些值。通过使用数组，可以使用单个变量名将值分组，并让索引键指示每个值指的是哪个月。

以下 PHP 语句声明了名为 `$temps` 的数组，并为其赋予 12 个值，分别代表一月到十二月的温度：

```php
$temps = array(38, 40, 49, 60, 70, 79,
84, 83, 76, 65, 54, 42);
```

创建的 `$temps` 数组包含 12 个值，这些值使用从 `0` 到 `11` 的数字键进行索引。要引用数组中的索引值，请在变量名后加上索引键。例如，要显示三月的气温，请使用以下内容：

```php
echo $temps[2];
```

**索引编号** 由于索引值默认从零开始，第三个月（三月）的值存储在数组的第二个元素中。

方括号语法也可用于为数组元素赋值。例如，要为十一月设置新值，可以使用以下内容：

```php
$temps[10] = 56;
```

**array 函数** array 函数是一种快捷函数，可快速从提供的值列表构建数组，而无需逐个添加元素。

为数组元素赋值时如果省略索引号，将自动使用下一个更高的索引号。从空数组 $temps 开始，以下代码将开始构建与之前相同的数组：

```php
$temps[] = 38;
$temps[] = 40;
$temps[] = 49;
...
```

在此示例中，值 38 将分配给 $temps[0] ，40 分配给 $temps[1] ，依此类推。如果要确保这些赋值从 $temps[0] 开始，最好先初始化数组，以确保数组中没有现有数据。可以使用以下命令初始化 $temps 数组：

```php
$temps = array();
```

### 输出数组内容

PHP 包含一个实用函数 print_r ，可用于递归输出数组中存储的所有值。以下脚本定义了温度值数组，然后在屏幕上显示其内容：

```php
$temps = array(38, 40, 49, 60, 70, 79,
84, 83, 76, 65, 54, 42);
print "<PRE>";
print_r($temps);
print "</PRE>";
```

需要在 print_r 周围使用 `<PRE>` 标签，因为生成的输出是带有空格和换行符的文本格式。此示例的输出如下：

```
Array
(
 [0] => 38
 [1] => 40
 [2] => 49
 [3] => 60
 [4] => 70
