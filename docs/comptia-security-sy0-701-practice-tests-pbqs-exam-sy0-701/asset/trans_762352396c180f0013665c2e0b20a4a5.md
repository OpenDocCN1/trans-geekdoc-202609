**问题 367。** 一个营销团队正在合作开展新活动，并需要共享文件夹的访问权限。然而，他们不应该能够修改他人创建的文件。应该如何设置此共享文件夹的权限？

- (A) 赋予营销团队完全控制权限
- (B) 允许营销团队只读访问
- (C) 赋予营销团队仅写访问
- (D) 赋予营销团队修改权限但拒绝删除权限

**解析 367.** **正确答案：D. 赋予营销团队修改权限但拒绝删除权限。** 通过提供修改权限但拒绝删除权限，团队成员可以创建和编辑自己的文件，但他们无法删除或修改他人创建的文件。

选项 A 错误。完全控制将允许团队成员修改或删除任何文件，这并不是所要求的。

选项 B 错误。只读访问将阻止团队成员创建或编辑。
