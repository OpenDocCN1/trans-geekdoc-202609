# 问题 169. 一家大型律所拥有一个集中文档库，律师们在其中存储客户信息、法律草案和其他敏感数据。新法务 Jenna 加入了律所，她需要能够查看客户文档，但不应该能够修改或删除这些文档。应该授予 Jenna 哪种类型的权限？

- (A) 只读 (Read-Only)
- (B) 完全控制 (Full Control)
- (C) 修改 (Modify)
- (D) 执行 (Execute)

解释 169. 正确答案：A. 只读 (Read-Only)。只读权限允许用户查看和打开文件或资源，但不允许他们对其进行修改、删除或执行。在这种场景中，授予 Jenna 只读访问权限确保她能够查看客户文档，而不会进行任何更改或删除。

选项 B 错误。完全控制将赋予 Jenna 修改、删除甚至更改文档权限的能力，这超出了她职位所需的权限。

选项 C 错误。修改权限允许用户对文档进行更改，根据场景要求，这对于 Jenna 来说是不合适的。

选项 D 错误。执行权限通常用于运行程序或脚本，与 Jenna 查看文档的需求无关。

问题 170. 一家公司正在开发一个新的 Web 应用程序，该程序将处理高度敏感的用户数据。他们希望确保如果 Web 服务器被攻破，攻击者无法直接访问数据库或其他关键基础设施。以下是实现该目标的**最佳**策略是什么？

- (A) 为应用程序使用强身份验证方法
- (B) 对静态和传输中的用户数据进行加密
- (C) 将 Web 服务器和数据库服务器放置在不同的网络段中
- (D) 对 Web 服务器实施实时监控

解释 170. 正确答案：C. 将 Web 服务器和数据库服务器放置在不同的网络段中。通过将 Web 服务器和数据库服务器放在不同的网络段中，公司可以实现隔离。这意味着即使 Web 服务器被攻破，攻击者仍然需要突破额外的安全措施才能访问数据库服务器或其他基础设施的关键部分。

选项 A 错误。虽然使用强身份验证方法很重要，但它没有在 Web 服务器与其他关键组件之间提供隔离。

选项 B 错误。加密用户数据对于数据保护至关重要，但它没有在 Web 服务器与其他系统之间提供基于网络的隔离。

选项 D 错误。实时监控可以对可疑活动提供警报，但它没有提供所需的隔离。

问题 171. 一位 IT 技术人员正在公司的服务器机房进行例行安全审计。他发现一台服务器的固件过时，已经两年没有更新了。过时的固件使服务器暴露于哪些潜在漏洞？

- (A) SQL 注入
- (B) 物理篡改
- (C) 未修补的漏洞利用 (Unpatched exploits)
- (D) 凭据填充 (Credential stuffing)

解释 171. 正确答案：C. 未修补的漏洞利用 (Unpatched exploits)。固件像软件一样，会接收更新以修复已知漏洞。如果固件过时，可能会导致系统容易受到攻击者利用的已知漏洞的影响。

固件是硬件设备的基础软件。当固件不定期更新时，它可能包含在后续版本中已修复的漏洞。这些漏洞可能会被攻击者利用，使设备和连接的系统面临风险。

选项 A 错误。SQL 注入是与数据库和 Web 应用程序相关的漏洞，与固件无关。

选项 B 错误。物理篡改涉及某人物理访问并更改设备。虽然固件漏洞有时会导致物理篡改（通过引导层级攻击），但过时固件与物理篡改之间的直接联系没有与未修补的漏洞利用之间的联系紧密。

选项 D 错误。凭据填充是一种攻击方法，涉及使用已知的用户名-密码对获取未经授权的访问。它与固件漏洞没有直接关系。

# 问题 172. 一家大型组织的 IT 部门收到员工报告，称他们无法访问网络上的某些资源。经过调查，该部门发现访问控制列表 (ACL) 设置最近被修改过。以下哪项是检查和修改 ACL 设置的**主要**原因？

- (A) 均衡网络负载
- (B) 更新组织的防火墙规则
- (C) 确保对资源的适当访问
- (D) 更新组织的密码策略策略

解释 172. 正确答案：C. 确保对资源的适当访问。ACL 是确定网络或系统内谁有权访问资源的本质工具。

选项 A 错误。虽然网络负载均衡至关重要，但它与 ACL 无关。

选项 B 错误。虽然它们可以协同工作，但防火墙规则主要关注允许或阻止流量。

- (A) 不安全的 API 端点
- (B) 弱的加密方法
- (C) 缺乏资源隔离
- (D) 备份策略不充分

解释 173. 正确答案：C. 缺乏隔离。云特有的漏洞可能由于云的共享性质而产生。在这种场景中，在开发、测试和生产等不同环境之间没有边界会导致漏洞。如果没有适当的资源隔离，在开发环境中引入的恶意代码可能会进入生产环境，或者机密的生产数据可能会在测试环境中暴露，导致潜在的数据泄露。

选项 A 错误。不安全的 API 端点涉及用于管理和交互云服务的 API 未经妥善保护的问题。

选项 B 错误。弱的加密方法指的是使用过时或脆弱的加密算法，这与环境混合没有直接关系。

选项 D 错误。备份策略不充分涉及没有足够的数据备份和恢复机制，这是资源隔离的另一个关注点。
