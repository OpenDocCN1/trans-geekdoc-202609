**问题 175。** 一位系统管理员注意到，尽管默认账户设置配置正确，一个未经授权的用户仍能够在服务器上获得高权限。调查发现，该服务器的操作系统已经几个月没有更新了。可能利用了哪种漏洞？

- (A) 应用配置错误
- (B) OS 补丁管理问题
- (C) 弱加密算法
- (D) 密码重用攻击

**解析 175。** **正确答案：B. OS 补丁管理问题。** 当操作系统未定期更新时，它们就会受到由于供应商已修复的已知漏洞的攻击。攻击者可以利用这些漏洞获取未经授权的高权限。

基于操作系统的漏洞通常是由于缺少补丁或更新而引起的。保持操作系统更新至关重要，因为供应商经常发布补丁来解决已知漏洞。在这种情况下，更新操作系统的疏忽为攻击者利用并获取高权限留下了机会窗口。

**选项 A 错误。** 应用配置错误涉及软件应用程序中的错误设置或配置，而不是操作系统。该场景并未暗示应用程序设置存在任何问题。

**选项 C 错误。** 弱加密算法指的是由于算法本身的缺陷而被容易解密或破解的加密。场景未提到加密或解密问题。

**选项 D 错误。** 密码重用攻击涉及攻击者使用之前泄露的密码来访问不同的账户。场景未指示与密码相关的问题。

**问题 176。** 一位安全分析师发现，过去两天内一个外部 IP 地址反复尝试所有可能的字符组合，以访问公司的 VPN 门户。这最可能描述的是哪种类型的密码攻击？

- (A) 密码喷洒（Password Spraying）
- (B) 字典攻击（Dictionary Attack）
- (C) 彩虹表攻击（Rainbow Table Attack）
- (D) 暴力破解攻击（Brute Force Attack）

**解析 176. 正确答案：D. 暴力破解攻击。** 暴力破解攻击涉及系统地尝试所有可能的字符组合，直到找到正确的组合。场景指定在 VPN 门户上尝试所有可能的字符组合，这表明是暴力破解攻击。

**选项 A 错误。** 密码喷洒涉及在多个账户上尝试几个常用的密码，而不是在一个账户上尝试所有可能的组合。

**选项 B 错误。** 字典攻击使用常用或频繁使用的密码列表来尝试访问。它不涉及尝试所有可能的组合。

**选项 C 错误。** 彩虹表攻击使用预计算的表来反转密码学哈希函数。该场景未提到哈希值或此类表的使用。

**问题 177。** XYZ 公司的员工 Jane 最近注意到她的浏览器主页意外发生了变化，而且她收到的针对性广告越来越多。此外，她的浏览器中还出现了一个她不记得安装过的新工具栏。根据这些症状，哪种恶意软件最可能影响 Jane 的电脑？

- (A) 勒索软件（Ransware）
- (B) 蠕虫（Worm）
- (C) 间谍软件（Spyware）
- (D) 僵尸网络（Botnet）

**解析 177. 正确答案：C. Spyware。** 间谍软件是从用户系统中秘密收集信息的恶意软件。浏览器设置的变化（如新主页或新工具栏）结合针对性广告，是系统中存在间谍软件的常见指标。

**选项 A 错误。** 勒索软件是加密用户文件并要求付款释放文件的恶意软件。描述的症状与勒索软件的行为不符。

**选项 B 错误。** 蠕虫是一种可以自我复制并在网络中传播的恶意软件。它们通常不会修改浏览器设置或显示针对性广告。

**选项 D 错误。** 僵尸网络涉及连接的设备的集合，这些设备可能被感染了恶意软件并被用于执行协调任务。它不会直接导致描述的浏览器症状。

**问题 178。** XYZ 公司的一名软件开发人员在公司的软件中包含了一段代码，如果他的名字从应用程序的贡献者列表中被移除，应用程序的数据库就会损坏。在他离开公司几个月后，应用程序数据库在更新后损坏了。哪种恶意软件负责这一操作？

- (A) 木马（Trojan）
- (B) 间谍软件（Spyware）
- (C) 广告软件（Adware）
- (D) 逻辑炸弹（Logic bomb）

**解析 178。** **正确答案：D. Logic bomb。** 逻辑炸弹是一种由特定事件或条件触发的恶意软件。在这种情况下，软件开发人员的名字从贡献者列表中移除触发了恶意代码。

**选项 A 错误。** 木马伪装成合法软件，但在安装后执行恶意活动。场景未描述具有木马特征的行为。

**选项 B 错误。** 间谍软件设计用于收集并发送信息，通常在用户不知的情况下进行。它不会根据特定触发器损坏数据库。

**选项 C 错误。** 广告软件向用户传递不受的广告。它不会根据特定事件采取恶意行动。

**问题 179。** 一个流行的在线购物平台注意到，某些产品评论包含一个奇怪的链接，点击后会将用户引导至与平台相似但会收集登录凭据的网站。评论系统的哪种漏洞可能允许攻击者发布此类链接？

- (A) 会话劫持（Session Hijacking）
- (B) 跨站脚本（XSS）
- (C) 密码喷洒（Password Spraying）
- (D) 凭据填充（Credential Stuffing）

**解析 179. 正确答案：B. 跨站脚本 (XSS)。** XSS 漏洞允许攻击者向网页内容注入恶意脚本。如果平台的评论系统没有正确过滤输入，可能会允许攻击者嵌入指向钓鱼网站的恶意链接。在这种情况下，在产品评论中发布恶意链接的能力是 XSS 漏洞的标志。

**选项 A 错误。** 会话劫持涉及接管活动的用户会话。它不涉及在网页内容中发布恶意链接。

**选项 C 错误。** 密码喷洒涉及使用常用密码对许多用户账户尝试身份验证。它不涉及在网页内容中嵌入恶意链接。

**选项 D 错误。** 凭据填充攻击涉及使用大量的用户名和密码自动尝试获取访问。它与在网页内容中插入恶意链接无关。
