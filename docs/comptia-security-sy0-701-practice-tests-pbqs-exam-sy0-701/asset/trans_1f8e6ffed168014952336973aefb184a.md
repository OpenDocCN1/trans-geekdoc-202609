# 问题 30。AlphaCorp 正在迁移到云基础设施，并希望确保所有虚拟机（VM）从一开始就经过了安全配置。在部署多个 VM 实例之前，AlphaCorp 应该做什么以确保每台虚拟机都从安全配置开始运行？

- (A) 使用云服务提供商提供的默认 VM 模板
- (B) 为 VM 配置建立安全基准并将其用于部署
- (C) 定期备份所有虚拟机
- (D) 为云访问使用多因素身份验证

# 解释 30. 正确答案：B。为 VM 配置建立安全基准并将其用于部署。

为 VM 配置建立安全基准可以确保每台虚拟机在部署时都有一套标准的安全设置，从而减少由于默认配置或潜在配置错误导致的漏洞。

选项 A 错误。仅依赖云提供商提供的默认 VM 模板可能无法满足组织的特定安全需求。自定义并创建安全基准会更有效。

选项 C 错误。虽然定期备份对于数据恢复至关重要，但它们不能直接确保虚拟机从安全配置启动。

选项 D 错误。多因素身份验证是访问云资源的关键安全措施，但它不能确保虚拟机以安全配置进行部署。

# 问题 31。SecureNet Ltd. 希望保护用户账户免受暴力攻击。他们希望实施一种措施，在失败一定次数的登录尝试后，账户将暂时无法访问。哪种标准最符合这一要求？

- (A) 密码最小长度
- (B) 账户锁定阈值
- (C) 强制重置密码
- (D) 双因素身份验证

# 解释 31. 正确答案：B。账户锁定阈值。账户锁定阈值定义了连续失败登录尝试的次数，达到后账户将被锁定，防止在指定时间内进一步尝试。这种措施通过使快速、重复的登录尝试变得不可行直接震慑了暴力攻击。

选项 A 错误。密码最小长度规定了密码的长度，这可以震慑某些暴力尝试，但无法解决此类攻击的特征——快速且重复的尝试。

选项 C 错误。强制重置密码强制用户定期更改密码。虽然这可以防止使用被盗的旧凭据，但它不能防止暴力攻击。

选项 D 错误。双因素身份验证要求访问账户时两种形式的标识。尽管它显著增强了安全性，但它并没有根据失败次数来限制登录尝试。

# 问题 32。一家能源公司寻求增强其 ICS/SCADA 系统的安全性。他们意识到默认配置可能存在漏洞。在确保其 ICS/SCADA 系统安全方面，采取的最佳初始步骤是什么？

- (A) 将 ICS/SCADA 系统连接到互联网以进行远程监控
- (B) 使用商业现成软件增加一层安全性
- (C) 实施针对 ICS/SCADA 环境定制的安全基准配置
- (D) 增加具有管理权限的用户数量，以确保对问题做出快速响应

# 解释 32. 正确答案：C。实施针对 ICS/SCADA 环境定制的安全基准配置。工业控制系统 (ICS) 和监视控制与数据采集 (SCADA) 系统在管理工业过程中至关重要。实施针对这些系统定制的安全基准配置可以最大限地减少不必要的服务和潜在漏洞。

选项 A 错误。将 ICS/SCADA 系统直接连接到互联网会使其暴露在各种威胁和潜在的网络攻击之中。

选项 B 错误。虽然商业现成软件可能很有用，但它不是最佳初始步骤。针对 ICS/SCADA 环境定制的安全基准更为有效。

选项 D 错误。增加具有管理权限的用户数量违反了最小权限原则，并可能引入更多的安全漏洞。

# 问题 33。IT 部门希望实时监控网络流量以检测任何异常或恶意活动。以下哪种安全控制可以实现这一目标？

- (A) 安全策略文档
- (B) 入侵检测系统 (IDS)
- (C) 员工行为规范
- (D) 访问控制列表 (ACL)

# 解释 33. 正确答案：B。入侵检测系统 (IDS)。入侵检测系统 (IDS) 是一种技术控制，它可以实时监控网络流量，并根据预定义的规则或启发式算法提醒管理员任何可疑或恶意活动。

选项 A 错误。安全策略文档是一种管理控制措施。它为维护安全提供了指南，但不会主动监控流量。

选项 C 错误。员工行为规范是一种管理控制措施。它提供了关于员工在专业环境中应如何表现的指南，但不会主动监控流量。

选项 D 错误。访问控制列表 (ACL) 是技术控制，但它们用于定义谁可以访问资源的权限。它们不会实时监控流量以检测异常或恶意活动。

# 问题 34。某公司位于易发生地震和洪水等自然灾害的地区。以下哪种物理控制措施在确保公司基础设施安全方面最有效？

- (A) 在服务器访问中使用中使用生物识别身份验证
- (B) 部署防火墙以防止网络威胁
- (C) 在中心建立架空地板系统
- (D) 定期进行渗透测试

# 解释 34. 正确答案：C。在中心建立架空地板系统。数据中心的架空地板系统通过将设备抬离地面起到物理控制作用，帮助其免受洪水发生时潜在的水损害的保护，并对其他环境风险提供某些保护。

选项 A 错误。使用生物识别验证是一种技术控制，通过根据物理或行为属性确认用户身份来增强安全性。虽然它加强了访问安全，但不能提供针对自然灾害的保护。

选项 B 错误。部署防火墙是一种技术控制，用于防止对私有网络的未经授权的访问。虽然它可以防止网络威胁，但无法对物理威胁提供保护。

选项 D 错误。定期进行渗透测试是一种技术且有时是操作控制，用于识别组织数字资产的漏洞。虽然它增强了网络安全，但不能保护基础设施免受物理威胁。

# 问题 35。一名网络工程师正在为大型组织准备一批新路由器。工程师应该优先考虑以下哪些步骤，以确保路由器从开始就经过安全配置？

- (A) 配置路由器使用 DHCP 为连接的设备动态分配 IP 地址
- (B) 更改路由器的默认管理凭据
- (C) 将路由器固件更新到最新的功能版本，而不考虑其安全性状况
- (D) 定制路由器的 LED 颜色以便在机房内识别

# 解释 35. 正确答案：B。更改路由器的默认管理凭据。路由器通常带有众为人知的默认凭据，攻击者可以轻易利用。更改这些凭据对于建立安全基准至关重要。
