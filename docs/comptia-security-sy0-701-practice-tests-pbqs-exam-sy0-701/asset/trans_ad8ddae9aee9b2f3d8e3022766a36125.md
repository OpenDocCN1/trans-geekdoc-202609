**第 340 题** 在一次例行安全审查期间，一名安全分析师发现安全机房的电子门禁系统出现多次登录失败尝试，且都发生在短时间内。访问日志显示访问代码是按顺序进行尝试的。这可能是在尝试哪种类型的物理攻击？

- (A) 尾随攻击 (Tailgating)
- (B) 网络钓鱼 (Phishing)
- (C) 暴力破解 (Brute force)
- (D) 社会工程学 (Social engineering)

**解释 340。** **正确答案：C. 暴力破解。** 暴力破解攻击涉及尝试所有可能的组合以找到正确的组合。日志中按顺序尝试访问代码的模式表明，攻击者正在系统地遍历所有潜在的组合。

**选项 A 错误。** 尾随攻击涉及攻击者在没有相应凭据的情况下，跟随授权的人员进入安全区域。它不涉及多次电子访问代码的尝试。

**选项 B 错误。** 网络钓鱼是一种社会工程学攻击，通常涉及欺骗某人泄露凭据或其他敏感信息。它不涉及直接的物理访问尝试。

**选项 D 错误。** 虽然社会工程学确实涉及操纵个人以获得未经授权的访问，但它特指针对电子系统的暴力破解攻击。

**第 341 题** 一家跨国电子商务公司正在扩大其基础设施以处理日益增长的流量。主要目标是将传入的 Web 流量分布到多个服务器上，以确保没有哪个服务器被过载。该公司应该使用哪种方法？

- (A) 部署 Web 应用防火墙
- (B) 实现服务器集群
- (C) 使用硬件级防火墙
- (D) 设置负载均衡器

**解释 341。** **正确答案：D. 设置负载均衡器。** 负载均衡器将传入的流量分布到多个服务器上，确保没有单个服务器过载，从而增强应用程序的可用性和容错能力。

**选项 A 错误。** 虽然 Web 应用防火墙可以防止 Web 威胁，但它不会将传入的流量分布到服务器上。

**选项 B 错误。** 服务器集群主要关注提供冗余和故障转移能力，而不是分配传入流量。

**选项 C 错误。** 硬件级防火墙主要用于过滤流量并保护网络免受外部威胁，而不是分配传入的 Web 流量。

**第 342 题** Alice 需要证明她发送给 Bob 的数字文档的真实性。Alice 应该使用以下哪个加密元素来完成此任务，并确保 Bob 知道文档来自她？

- (A) 使用 Bob 的私钥加密文档
- (B) 使用她的公钥加密文档
- (C) 使用她的私钥对文档签名
- (D) 使用 Bob 的公钥对文档签名

**解释 342。** **正确答案：C. 使用她的私钥对文档签名。** 为了证明真实性，使用发送者的私钥创建数字签名。当 Bob 收到文档时，他可以使用 Alice 的公钥验证签名。这证明了文档是由 Alice 签名的，且在传输过程中没有被篡改。

**选项 A 错误。** Bob 的私钥仅为 Bob 所知，不应被任何其他人使用，包括用于加密。

**选项 B 错误。** 使用 Alice 的公钥加密不能证明真实性。这意味着 Alice 的私钥可以解密它（此处逻辑表述有误，通常是公钥加密私钥解密，但核心是无法证明身份）。

**选项 D 错误。** Bob 的私钥仅为 Bob 所知，不应被任何其他人使用，包括用于加密。

**第 343 题** Sarah，一名安全分析师，收到报告称某笔记本电脑被盗。全磁盘加密（FDE）如何影响这种安全？

- (A) 磁盘仍然易于访问，因为启动分区未加密
- (B) 受到受到保护，因为整个硬盘内容已加密
- (C) 受到保护，因为只有用户目录已加密
- (D) 处于脆弱状态，因为笔记本连接到了网络

**解释 343。** **正确答案：B. 受到保护，因为整个硬盘内容已加密。** 全磁盘加密（FDE）确保了即使设备被盗，如果没有相应的解密密钥，数据也无法读取。

**选项 A 错误。** 磁盘仍然易于访问，因为启动分区未加密。

**选项 C 错误。** 受到保护，因为只有用户目录已加密。

**选项 D 错误。** 处于脆弱状态，因为笔记本连接到了网络。

**第 344 题** 一家大型新闻网站在一次重大新闻事件期间无法访问。网络日志显示来自 IoT 设备的巨大流量。这表明是哪种 DDoS 攻击利用了 IoT 设备？

- (A) 反射攻击 (Reflected Attack)
- (B) 僵尸网络攻击 (Botnet Attack)
- (C) 放大攻击 (Amplification Attack)
- (D) 滴攻击 (Teardrop Attack)

**解释 344。** **正确答案：B. 僵尸网络攻击。** 僵尸网络（包括受感染的 IoT 设备）通常用于通过将设备的总带宽指向目标来发动大规模 DDoS 攻击。

**选项 A 错误。** 在反射攻击中，攻击者向第三方发送流量，并伪装成来自受害者，然后由第三方将流量反射给受害者。

**选项 C 错误。** 放大攻击利用脆弱的网络服务来放大发送给受害者的流量。

**选项 D 错误。** 滴攻击涉及发送具有重叠和过大负载的损坏 IP 分片，以崩溃目标系统。
