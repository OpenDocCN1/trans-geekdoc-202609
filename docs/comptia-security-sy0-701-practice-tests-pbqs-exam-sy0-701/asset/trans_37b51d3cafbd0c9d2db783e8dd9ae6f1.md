组件的完整性和安全性在产品开发中至关重要，特别是当这些组件是来自不同供应商的供应链的一部分时。如果某个供应商的安全措施松懈或其遭到攻破，他们所提供的组件就可能向最终产品中引入漏洞，影响其整体安全态势，并可能导致数据泄露或其他网络威胁。

**选项 A 错误。** 虽然跟踪保修是一项运营层面的考虑，但在从多个供应商处采购组件时，它并不会构成直接的安全风险。

**选项 B 错误。** 产品组装时间和供应商的交付时间表属于物流和运营层面的问题，而不是与供应链供应商相关的主要的安全风险。

**选项 D 错误。** 管理多个采购订单是一项业务流程挑战，而不是主要的安全关量问题。

**问题 135。** XYZ 公司的一名员工从供应商网站下载了一个看似无害的 PDF 文件。打开该 PDF 后，公司的入侵检测系统（IDS）向安全团队发出了源自该员工电脑的可疑活动警告。该 PDF 文件可能包含以下哪种威胁？

- (A) 水坑攻击 (Watering Hole Attack)
- (B) 恶意宏 (Malicious Macro)
- (C) SQL 注入 (SQL Injection)
- (D) 凭据收集 (Credential Harvesting)

**解释 135. 正确答案：B。恶意宏。** 许多文档类型（包括 PDF）都可以包含宏。恶意宏可以在文档打开时执行违背用户意愿的动作，例如下载并安装恶意软件。

**选项 A 错误。** 水坑攻击是指攻击者猜测或观察组织经常使用的某些网站，并在其中植入恶意软件，意在破坏该组织成员的设备。该情景并未提供指向此类攻击的证据。

**选项 C 错误。** SQL 注入是一种旨在在数据库中执行恶意 SQL 语句的攻击。这种攻击与打开 PDF 文件无关。

**选项 D 错误。** 旁路下载（Drive-By Download）涉及在用户不知情或未经许可的情况下下载软件（通常是恶意软件），这通常发生在用户访问被攻破的网站时。该情景专门讨论了下载后又手动打开的 PDF。

**问题 136。** 安全分析师 John 注意到连接到公司无线网络的未经授权设备有所增加。为了找出原因，他意识到无线接入点仍在使用旧的加密标准。可能正在使用的是哪种已知易被攻破的过时加密标准？

- (A) WPA3
- (B) WEP
- (C) WPA2-PSK
- (D) AES

**解释 136. 正确答案：B. WEP。** 有线等效隐私保护（WEP）是无线网络的一种老旧且过时的加密协议。它有多个已知的漏洞，并被认为是不安全的，使得攻击者更容易对其攻破。

选项 A 错误。WPA3 是一种较新的、更安全的无线网络加密协议，被认为是对以前标准的重大改进。

选项 C 错误。WPA2-PSK（带有预共享密钥的 Wi-Fi 保护 2）比 WEP 更安全。虽然它可能仍面临困难，但它不像 WEP 那样容易被攻破。

选项 D 错误。AES（高级加密标准）是一种加密标准，而不是无线加密协议。它通常用于 WPA2 和 WPA3 以保护无线数据。

**问题 137。** Lucy 是一名安全分析师，接到通知员工收到了通过蓝牙的未经授权的消息。以下哪种攻击最可能是正在尝试的类型？

- (A) 蓝牙劫持 (Bluejacking)
- (B) ARP 欺骗 (ARP Poisoning)
- (C) 蓝牙嗅取 (Bluesnarfing
- (D) 恶意孪生攻击 (Evil Twin)

**解释 137. 正确答案：A. 蓝牙劫持。** 蓝牙劫持是指向蓝牙支持的设备发送未经授权的请求或信息。该情景描述的是通过蓝牙发送此类消息的攻击。

选项 B 错误。ARP 欺骗是一种在局域网上伪造 ARP 消息的攻击类型，这与情景描述的通过蓝牙发送消息不符。

选项 C 错误。蓝牙嗅取（Bluesnarfing）是指通过蓝牙未经授权地访问信息，这超出了仅仅发送消息的范围。

选项 D 错误。恶意孪生攻击（Evil Twin）涉及创建一个伪造的合法 Wi-Fi 热点以拦截数据，它与蓝牙连接无关。

**问题 138。** 国家 A 和 B 正在进行领土争议。突然，发电厂、交通枢纽等关键基础设施遭遇了系统性攻击。在没有勒索的情况下，这些攻击最可能的动机是什么？

- (A) 经济利益 (Financial gain)
- (B) 道德黑客测试 (Ethical hackers)
- (C) 因哲学分歧导致的干扰 (Disruption due to philosophical disagreements)
- (D) 网络战争行为 (Acts of cyberfare)

**解释 138. 正确答案：D. 网络战争行为。** 考虑到领土争议的背景以及对关键基础设施的针对性且没有勒索，极可能是这些攻击是作为削弱国家 B 位置的网络战争行为。

选项 A 错误。虽然市场干扰可能为了经济利益而被利用，但领土争议的背景和攻击性质表明其动机与地缘战略有关而非财务收益。

选项 B 错误。道德黑客通常是发现并报告漏洞，而不是利用漏洞造成大规模破坏。

选项 C 错误。这些攻击的规模太大，不可能是仅由哲学分歧驱动的个人或团体行为。

**问题 139。** Maria 在手机上收到了一条来自未知号码的短信，声称她获得了一张热门在线商店价值 500 美元的礼品卡。短信包含一个链接，要求她点击以领取奖品。Maria 不确定该信息的真实性。对于 Maria 来说，以下哪种做法是最佳？

- (A) 点击链接检查网站是否真实
- (B) 将短信转发给朋友，验证他们是否也收到了类似的消息
- (C) 在不点击任何链接的情况下删除短信
- (D) 回复发送者询问有关该优惠的更多细节

**解释 139. 正确答案：C. 在不点击任何链接的情况下删除短信。** 来自未知来源的消息（尤其是听起来好得不真实的消息）通常预示着潜在的安全威胁。安全的方法是在不交互任何链接的情况下删除此类消息。

短信钓鱼（Smishing）是一种钓鱼攻击类型，攻击者利用短信欺骗用户披露个人信息、访问恶意网站或在智能手机上下载恶意软件。用户应始终对未知号码的未经授权短信保持警惕。
