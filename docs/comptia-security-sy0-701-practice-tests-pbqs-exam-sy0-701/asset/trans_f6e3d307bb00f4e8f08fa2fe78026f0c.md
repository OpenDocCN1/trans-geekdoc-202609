问题 439。一个云基础设施团队频繁收到来自环境中各种资源的性能告报。他们希望确保相关团队立即收到通知，并能够对任何超过性能阈值的资源采取行动。实现这一目标的最佳方法是什么？

- (A) 召开每周会议来审查所有性能告报
- (B) 对任何超过性能阈值的资源自动创建工单，并将其分配给相关团队
- (C) 将所有性能告报发送到云基础设施团队的邮箱进行审查
- (D) 禁用性能监控以减少告报疲劳

解释 439。正确答案：B。对任何超过性能阈值的资源自动创建工单，并将其分配给相关团队。自动化工单创建过程可以确保警报不会被遗漏，并实时通知相关团队，从而实现及时解决。

**选项 A 错误。** 每周进行一次审查无法针对关键性能问题采取采取行动。

**选项 C 错误。** 将所有告报发送到团队邮箱可能会导致告报疲劳，并可能在不重要的告报中遗漏关键告报。

**选项 D 错误。** 禁用性能监控将阻止团队接收重要告报，而且这不是一个实用的解决方案。

问题 440。一个开发团队正在为一家金融机构开发一项关键任务应用程序。该团队希望确保任何代码更改都不会引入漏洞或破坏现有功能。实现此目标的最佳自动化方法是什么？

- (B) 使用持续集成工具自动针对已知漏洞和功能测试对代码更改进行编译和测试
- (C) 依赖用户在应用程序部署后报告任何问题
- (D) 实施防火墙以阻止对应用程序的潜在攻击

解释 440。正确答案：B。使用持续集成工具自动针对已知漏洞和功能测试对代码更改进行编译和测试。持续集成工具可以配置为在代码提交时自动测试代码更改。这确保了在开发过程中尽发现漏洞和功能问题。

**选项 A 错误。** 每月手动审查代码更改无法为开发者提供即时反馈，并可能延迟漏洞或功能问题的识别。

- (D) 通知媒体有关即将发生的诉讼

解释 441。正确答案：B。识别并隔离与前高管相关的电子邮件账户。在电子发现（e-discovery）的背景下，定位并保存可能与诉讼相关的电子存储信息（ESI）至关重要。第一步是识别并隔离与请求特定的电子邮件账户或数据源，以确保它们不被篡改或删除。

**选项 A 错误。** 虽然备份是关重要的，但对电子邮件服务器进行全面备份可能无法专门满足电子发现请求。关注问题的特定数据更具相关性。

**选项 C 错误。** 删除潜在证据（特别是收到电子发现通知之后）可能会导致法律处罚，并且不是推荐的行动。

**选项 D 错误。** 通知媒体不是电子发现过程的主要步骤，并可能对公司的声誉产生不利影响。

- (C) 防止新入职人员在试用期结束访问任何系统

- (B) 威胁建模
