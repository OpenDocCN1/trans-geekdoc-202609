**问题 469。** 一家在线银行平台希望在用户开设新账户时改进其身份验证流程。在这种情况下，以下哪种身份证明方法对该目的**最**安全？

- (A) 要求用户从列表中选择并回答一个安全问题
- (B) 要求用户上传政府颁发的身份证明照片和自拍
- (C) 向用户的邮箱地址发送验证码
- (D) 提示用户提供他们喜好的颜色

**解析 469。** **正确答案：B。要求用户上传政府颁发的身份证明照片和自拍。** 该方法通过将用户的实时图像（自拍）与政府颁发的身份证明进行对比，提供了高水平的保证。这种组合确保了此人确是其实。

**选项 A 错误。** 虽然数字签名可以验证消息或文档的真实性和完整性，但它们无法提供随时间变化的资产的去中心化账本。

**选项 B 错误。** 密钥托管是将加密密钥托管给第三方的方法，以便第三方在特定条件下可以访问。在没有中央机构的情况下，它无法帮助验证资产随时间变化的完整性和真实性。

**选项 D 错误。** 密钥管理系统管理加密密钥的生命周期，但它本身并不验证资产随时间变化的完整性和真实性。

**问题 471。** 在某公司中心数据库最近遭受网络攻击后，IT 部门被赋予增强网络基础设施安全的任务。以下哪种技术是确保不同部门（如人事和财务部门）无法访问对方敏感数据的**最佳**技术？

- (A) 实施基于部门的网络分
- (B) 升级整个网络的带宽
- (C) 为所有部门使用单一强密码
- (D) 将所有部门数据移动到云端

**解析 471。** **正确答案：A。实施基于部门的网络分。** 网络分将网络划分为多个段或子网，每个段充作为一个独立的小型网络。这限制了段与段之间的访问，并通过确保只有段内的人员可以访问其资源来保护敏感数据。

**选项 B 错误。** 虽然升级带宽可能会提高网络速度，但它没有解决部门数据隔离的安全问题。

**选项 C 错误。** 为所有部门使用单一强密码不能防止一个部门访问另一个部门的数据。它还引入了单点故障。

**选项 D 错误。** 将数据移动到云端可以提供一些安全优势，但如果没有适当的访问控制和分，不同部门仍然可以访问对方的数据。

**问题 472。** 财务部门员工 Maya 调到了人事部门。IT 部门正在考虑她的访问需求。以下哪种操作最符合**最小权限原则**？

- (A) 保留 Maya 对财务系统的访问权限，并授予对人事系统的额外访问权限
- (B) 移除所有之前的访问权限，并仅提供其对人事系统的访问权限
- (C) 授予 Maya 管理员权限，以方便她在部门之间的转换
- (D) 在过渡期内将 Maya 对财务和人事系统的访问权限限制为只读

**解析 472。** 正确答案：B。移除所有之前的访问权限，并仅提供其对人事系统的访问权限。

当员工从一个部门转到另一个部门时，他们的访问需求会发生。为了遵循最小权限原则，重新评估并调整访问权限至关重要，Maya 不再需要访问财务系统，应该只访问其人事部门新职位所需的资源。

**选项 A 错误。** 当 Maya 不再该部门工作时，保留对财务系统的访问权限是没有必要的，并且可能带来安全风险。

**选项 C 错误。** 授予管理员权限是过度的，并且将为 Maya 提供比其新职位需求更多的访问权限。

**选项 D 错误。** 虽然只读访问限制了潜在的损害，但如果 Maya 的新职位只需要访问人事系统，那么为两个系统提供访问权限是不必要的。

**问题 473。** 一家金融机构 BankCorp 最近经历了针对其员工的钓鱼攻击激增。这些攻击通常涉及与合法 URL 相似但有细微差异的 URL。为了减少员工意外访问这些恶意网站的风险，BankCorp 应该实施哪种措施？

- (A) 实施域名系统（DNS）防火墙
- (B) 采用 URL 扫描来识别并拦截恶意 URL
- (C) 依靠员工手动报告可疑 URL
- (D) 使用虚拟专用网络（VPN）重定向员工的网络流量

**解析 473。** 正确答案：B。采用 URL 扫描来识别并拦截恶意 URL。URL 扫描通过检查完整 URL 并与已知的恶意 URL 或模式对比，识别潜在的恶意网站。这种方法可以阻止访问设计成与合法 URL 相似的 URL。

**选项 A 错误。** 虽然 DNS 防墙可以帮助访问恶意域名，但 URL 扫描通过检查完整 URL（不仅仅是域名）提供了更细粒度的控制。

**选项 C 错误。** 仅依赖员工的手动报告可能不如自动 URL 扫描那样高效有效。这还会给员工识别每个恶意 URL 带来不当责任。

**选项 D 错误。** 使用 VPN 只是更改流量路由并提供加密通信。它本身不提供 URL 扫描功能。

**问题 474。** 某制造公司的 IT 团队正在部署一套基于 IoT 的机械监控系统。他们希望确保这些 IoT 设备即使受到攻击也不会影响其主公司网络。他们应该实施什么来实现这一点？

- (A) 在所有 IoT 设备上安装杀病毒软件
- (B) 定期修补和更新设备固件
- (C) 将 IoT 设备放置在专用 VLAN
- (D) 为 IoT 设备启用多身份认证

**解析 474。** 正确答案：C。将 IoT 设备放置在专用 VLAN。将 IoT 设备放置在专用 VLAN（虚拟局域网）提供了网络隔离，确保设备与主公司网络分离。这种策略确保了即使 IoT 设备受到攻击，也不会对网络系统造成直接威胁。

**选项 A 错误。** 许多 IoT 设备不支持传统的杀病毒软件，即使支持，也没有实现所需的隔离。

**选项 B 错误。** 虽然定期修补和更新设备固件对于安全性至关重要，但它并没有提供与主公司网络的隔离。

**选项 D 错误。** 启用多身份认证可以增强设备安全性，但没有提供场景中指定的网络隔离。
