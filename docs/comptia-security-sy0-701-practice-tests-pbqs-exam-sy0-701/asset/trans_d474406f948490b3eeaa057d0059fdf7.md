

问题 130。TechHaus 最近经历了多次安全漏洞事件，未经授权的人员在下班后进入了他们的服务器机房。为了增强安全措施，公司决定部署一套新系统。以下哪个选项最好即使在完全黑暗的情况下也能根据体热检测出人类入侵者？

- (A) 安装带有 LED 灯光的 CCTV 摄像头
- (B) 使用超声波运动传感器
- (C) 部署红外 (IR) 传感器
- (D) 在入口处实施 RFID 读卡器

解释 130. **正确答案：C. 部署红外 (IR) 传感器。** 红外传感器可以检测红外辐射，例如人体发出的热量。这使得它们在检测人类入侵者方面特别有效，即使在完全黑暗的情况下也能根据其发出的体热进行检测。

选项 A 错误。带有 LED 灯光的 CCTV 摄像头可以提供视觉监控，但它们依赖光线产生图像，在完全黑暗的环境下检测入侵者的效率可能不如红外传感器。

选项 B 错误。超声波运动传感器通过声波检测运动而非体热，这使得它们在区分人类入侵者和其他移动物体时效率较低。

选项 D 错误。RFID 读卡器控制入口处的访问，但无法根据设施内部的体热检测人类入侵者。

问题 131。SecureTech Corp 是一家处理敏感客户数据的公司，正在重新设计其主办公室入口以增强安全性。他们希望确保一次只有一个人获得访问，即使有多人尝试使用单张授权的访问卡进入。以下哪个选项可以实现这一目的？

- (A) CCTV 摄像头
- (B) 步道间 (Mantrap)
- (C) 生物识别扫描仪
- (D) 运动探测器

解释 131. **正确答案：B. 步道间。** 步道间（也称为访问控制门室）是一种物理安全访问控制系统，由一个带有两组互锁门的小空间组成。第一扇门必须在第二扇门打开之前关闭，以确保一次只有一个人通过。这种设计防止了尾随（tailgating）或搭便（piggybacking），即未经授权的人员试图紧跟在授权人员后面进入安全区域。

选项 A 错误。虽然 CCTV 摄像头可以进行监控和记录，但它们无法在物理上阻止多人同时进入。

选项 C 错误。生物识别扫描仪根据物理特征验证身份，但不能从物理上限制进入某区域的人数。

选项 D 错误。运动探测器识别运动，但不能防止尾随或搭便。

问题 132。一家医疗保健机构想要配置其防火墙，以便在发生故障时网络保持可用，以确保业务连续性。防火墙应该使用哪种模式？

- (A) 故障安全 (Fail-safe)
- (B) 故障转移 (Fail-over)
- (C) 故障关闭 (Fail-closed)
- (D) 故障开启 (Fail-open)

解释 132. **正确答案：D. 故障开启。** 在故障开启模式下，如果设备故障，它允许流量通过，以确保业务的连续性和可用性，尽管是以牺牲安全性为代价。

选项 A 错误。故障安全通常涉及系统故障时阻止访问，这在这种语境下会中断业务连续性。

选项 B 错误。故障转移是指主系统故障时切换到备用系统，而不是防火墙设备本身的状态。

选项 C 错误。故障关闭会在发生故障时停止所有流量，这与保持网络可用性的目标背道而驰。

问题 133。在安全审计期间，组织需要识别安全漏洞的潜在后果。他们应该执行哪种过程？

- (A) 风险所有者分配
- (B) 关键风险指标 (KRI)
- (C) 风险影响分析
- (D) 风险阈值

解释 133. **正确答案：C. 风险影响分析。** 该过程涉及评估安全事件对组织造成的潜在后果和影响。

选项 A 错误。风险所有者是负责管理风险的个人，而不是分析后果的过程。

选项 B 错误。关键风险指标 (KRI) 是用于提供风险水平上升警告的指标。

选项 D 错误。风险阈值是组织在采取行动之前愿意接受的风险水平。

问题 134。一家医疗保健机构正在更新其网络基础设施。由于处理的数据具有敏感性，他们希望确保任何异常都能及时报警。他们应该主要考虑哪种系统？

- (A) 入侵防御系统 (IPS)
- (B) 入侵检测系统 (IDS)
- (C) DHCP 服务器
- (D) VPN 集中器

解释 134. **正确答案：B. 入侵检测系统 (IDS)。** 入侵检测系统 (IDS) 监控网络流量并向管理员警报潜在的恶意活动。

选项 A 错误。入侵防御系统 (IPS) 监控流量并采取行动拦截恶意流量，而需求明确是用于警报。

选项 C 错误。DHCP（动态主机配置协议）服务器为设备分配 IP 地址，并不监控异常。

选项 D 错误。VPN 集中器用于创建和管理安全的 VPN 连接，但不主要用于检测入侵。

问题 135。BioGen Inc. 是一家生物技术公司，他们实施了分层安全方法。他们正在考虑为其研究实验室的安全措施引入人为因素。以下哪个选项最好提供了通过人类判断来评估和应对各种安全状况的能力？

- (A) 安装生物识别锁
- (B) 雇佣安保人员
- (C) 实施访问控制门室
- (D) 部署 AI 驱动的安全摄像头

解释 135. **正确答案：B. 雇佣安保人员。** 安保人员提供了人类判断的优势，并能够评估、响应和适应各种安全状况，使其成为为分层安全方法引入人为因素的理想选择。

选项 A 错误。虽然生物识别锁根据独特的人类特征控制访问，但它们无法提供安保人员的评估和响应能力。

选项 C 错误。访问控制门室控制进入区域（通常有两道门），但它不能提供安保人员的评估或现场响应。

选项 D 错误。虽然 AI 驱动的安全摄像头可以提供先进的监控并可能检测可疑活动，但它们无法取代人类安保人员的判断和现场响应能力。
