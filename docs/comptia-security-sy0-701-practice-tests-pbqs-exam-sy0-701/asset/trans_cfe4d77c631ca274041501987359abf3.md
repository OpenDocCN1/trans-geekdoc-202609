

问题 13. GreenTech Industries 拥有一个位于偏远地区的制造设施。近期发生的盗窃和入侵事件引起了管理层的警觉。以下哪种措施最有效地防止未经授权的夜间进入设施周边界？

- (A) 安装红外传感器
- (B) 使用明亮的周边界照明
- (C) 在设施内部部署额外的保安人员
- (D) 增加设施墙的高度

**解释 13. 正确答案：B. 使用明亮的周边界照明。** 明亮的周边界照明对未经授权的人员具有强力威慑作用，因为它减少了隐藏点，使监控摄像头更有效，并让安全人员更容易发现潜在威胁。在偏远地区，适当的照明对于消除黑暗区域和威慑潜在入侵者尤为重要。

**选项 A 错误。** 虽然红外传感器可以检测移动，但它们无法像明亮照明那样起到可见的威慑作用。

**选项 C 错误。** 在设施内部部署额外的安保人员无法解决夜间未经授权进入周边界的紧迫问题。

**选项 D 错误。** 增加墙的高度可以起到威慑作用，但它不能像明亮照明那样照亮或暴露潜在的入侵者。

## 问题 14. 在进行例行安全审查时，安全专家 Jake 发现组织的财务系统中放置了一段意想不到的数据。在询问后，他得知这段数据是特意放置并监控的，以观察是否有任何未经授权的用户或系统与其交互。这种欺骗性数据被称为什么？

- (A) Honeystring（蜜罐字符串）
- (B) Honeypoken（蜜罐）
- (C) Canary token（金丝雀令牌）
- (D) Security marker（安全标记）

解释 14. 正确答案：B. Honeypoken。
Honeytokens 是策略性放置的欺骗性数据，它们没有实际价值或现实用途，但会被密切监控。它们的唯一目的是检测未经授权的交互，因为对 honeytoken 的任何访问或使用可能是恶意的或未经授权的。

选项 A 错误。在所描述的背景下，并没有广认的名为“Honeystring”的安全术语。

选项 C 错误。Canary tokens 是 honeytoken 的特定类型，可以起到相同的作用。但考虑到所提供的选项和问题的背景，“Honeypoken”是最准确的答案。

选项 D 错误。从一般上讲，安全标记可以是任何用于安全目的的标记或指示，但它不是专门放置用于检测未经授权访问的欺骗性数据。

问题 15. 一个组织正在其智能办公室部署新的 IoT 设备。为了确保只有授权的设备才能连接到公司网络，每个设备将获得一个唯一的密钥对。以下哪项最能描述该组织正在使用的系统验证方法？

- (A) 共享密钥验证
- (B) 公钥基础设施 (PKI)
- (C) 基于令牌的身份验证
- (D) 用户名和密码验证

解释 15. **正确答案：B. 公钥基础设施 (PKI)。** 公钥基础设施 (PKI) 是硬件、软件、策略和标准的组合，它们共同工作，为安全通信提供一个框架。PKI 的主要特征之一是使用一对密钥（公钥和私钥）对实体进行身份验证。在场景中，每个 IoT 设备都获得了一个唯一的密钥对，这表明使用了 PKI 进行系统验证。

**选项 A 错误。** 共享密钥验证通常涉及双方拥有一个共享密钥，并用其相互相互验证。场景提到每个设备都有一个唯一的密钥对，这与共享密钥的概念不符。

**选项 C 错误。** 基于令牌的身份验证通常涉及使用生成时间敏感代码的硬件或软件令牌。场景描述的是密钥对的使用，而不是令牌。

**选项 D 错误。** 用户名和密码验证是一种实体提供用户名和机密密码来验证其身份的方法。场景中没有提到对用户名或密码的使用。

问题 16. 在 BankSecure 的新分行，管理层决定在主入口安装一套安全系统，让未来的访客在进入主区域之前必须通过两次独立的授权检查。他们应该考虑哪种物理安全措施？

- (A) 旋转门
- (B) 安保人员
- (C) 访问控制门间（Access Control Vestibule）
- (D) 读卡器

解释 16. 正确答案：C. 访问控制门间。访问控制门间（通常称为人肉道 mantrap）是一种双阶段验证系统。它由两扇门组成：人员进入第一扇门，接受授权检查（如读卡器或生物识别扫描仪），只有在获得批准后才能进入第二扇门，在在那里接受另一次授权检查后才能进入主区域。

选项 A 错误。旋转门控制人员进入地点的流量，并在某种程度上可以防止尾随（tailgating），但它们不能强制执行双阶段授权检查。

选项 B 错误。虽然安保人员可以执行授权检查并控制访问，但他们本身不能提供像访问控制门间那样的双阶段系统。

**选项 D 错误。** 读卡器是访问控制的一种形式，用于检查个人的凭据，但仅靠它们不能确保两次独立的授权检查。

## 问题 17. IT 部门希望实时监控网络流量以检测任何异常或恶意活动。以下哪种安全控制可以实现这一点？

- (A) 安全策略文档
- (B) 入侵检测系统 (IDS)
- (C) 员工行为准则
- (D) 访问控制列表 (ACL)

**解释 17. 正确答案：B. 入侵检测系统 (IDS)。** 入侵检测系统 (IDS) 是一种技术控制，用于实时监控网络流量并根据预定义的规则或启发式方法向管理员报警任何可疑或恶意的活动。

**选项 A 错误。** 安全策略文档是一种管理控制。它提供了维护安全的指南和程序，但并不主动监控网络流量。

**选项 C 错误。** 员工行为准则是一种管理控制。它提供了员工在专业环境下的行为指南，但并不主动监控网络流量。

选项 D 错误。访问控制列表 (ACL) 是技术控制，但它们用于定义谁可以访问特定资源。它们不会实时监控网络流量以检测异常或恶意活动。

问题 18. Jenna 是一家增长中的在线零售企业的 Web 管理员，正在为公司的域名获取 SSL 证书。该公司为不同的服务使用多个子域名，例如 shop.example.com、blog.example.com 和 support.example.com。Jenna 希望不要为每个子域名单独证书，而是使用一个。她应该寻求哪种类型的证书？

- (A) 扩展验证证书
- (B) 通配符证书 (Wildcard Certificate)
- (C) 带有备用名称 (SAN) 的证书
- (D) 代码签名证书

解释 18. 正确答案：B. 通配符证书。通配符证书旨在保护一个域名及其位于相同顶级域名下的子域名。例如，针对 *.example.com 的通配符证书可以保护 shop.example.com、blog.example.com 以及 example.com 的任何其他子域名。

选项 A 错误。扩展验证证书提供了最高级别的验证，但默认并不一定覆盖多个子域名。
