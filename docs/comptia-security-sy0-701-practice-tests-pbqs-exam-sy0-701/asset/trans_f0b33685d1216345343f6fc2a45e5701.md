# 问题 101. XYZ 公司正在实施一种新的漏洞扫描解决方案。安全团队希望一种不需要在目标机器上安装任何软件但仍识别漏洞的解决方案。他们应该选择哪种类型的漏洞扫描解决方案？

- (A) 基于主机的入侵检测系统 (HIDS)
- (B) 无代理漏洞扫描器
- (C) 基于客户端的漏洞扫描器
- (D) 基于主机的入侵预防系统 (HIPS)

**解析 101. 正确答案：B. 无代理漏洞扫描器。** 无代理漏洞扫描器不需要在目标系统上安装任何软件（代理）。相反，它远程扫描系统，并通过比对已知漏洞数据库来识别漏洞。

**选项 A 错误。** 基于主机的入侵检测系统 (HIDS)

**选项 C 错误。** 基于客户端的漏洞扫描器

**选项 D 错误。** 基于主机的入侵预防系统 (HIPS)

# 问题 102. 一款金融应用程序允许用户通过输入账号和转账金额向其他账户转账。在安全审计期间，发现恶意用户可以在账号字段中输入 SQL 代码来操纵应用程序数据库。开发团队应该实施哪种安全技术来解决这一漏洞？

**解析 102. 正确答案：B. 输入验证。** 输入验证确保用户提供的数据在处理之前符合预期的格式、长度和类型，从而防止 SQL 注入等恶意代码被数据库执行。
