**问题 395。** 一家软件开发公司刚刚扩大了团队，并希望在发生灾难时能够在一天内恢复运营。然而，他们的灾备预算有限。以下哪种恢复类型对该公司最合适？

(A)具有每小时数据复制的热备机
(B)具有每月备份的冷备机
(C)具有每日备份的热备机
(D) 异地带备份

**解析 395。** **正确答案：C. 具有每日备份的热备机。** 对于软件开发公司一天内恢复运营的需求，具有每日备份的热备机是理想的。热备机已准备好一些设备和数据，这将比冷备机或异地备份更快地恢复。

**选项 A 错误。** 具有每小时数据复制的热备机可能提供最快的恢复，但也是最贵的选项，可能不符合公司的预算。

**选项 B 错误。** 具有每月备份的冷备机具有成本效益，但由于设置设备所需的时间，可能无法在一天内恢复运营。

**选项 D 错误。** 仅靠异地带备份无法提供快速恢复所需的设施，而且恢复需要大量时间。

**问题 396。** 一家公司最近注意到，工作期间访问社交媒体网站的人数增加，导致生产力下降。为了应对这个问题，安全管理员决定在高峰期间限制对这些网站的访问。管理员应该对防火墙进行哪些修改？

(A) 实施入侵预防系统 (IPS) 规则阻止社交媒体内容
(B) 修改防火墙规则，在上午 9 点到下午 5 点之间拒绝已知社交媒体 IP 地址的访问
(C) 使用防火墙的 URL 过滤功能将社交媒体 URL 加入黑名单
(D) 增加防火墙带宽以容纳额外流量

**解析 396。** **正确答案：B. 修改防火墙规则，在上午 9 点到下午 5 点之间拒绝已知社交媒体 IP 地址的访问。** 实施拒绝访问与社交媒体相关的特定 IP 地址（或范围）的时间性规则，是限制指定时间段访问的有效方法。

**选项 A 错误。** IPS 设计用于根据签名检测并防止恶意活动。阻止社交媒体内容不是它的主要功能。

**选项 C 错误。** URL 过滤将完全阻止对 URL 的访问。要求是仅在特定时间段阻止它们。

**选项 D 错误。** 增加防火墙带宽不能解决员工在工作期间访问社交媒体的问题。

**问题 397。** 作为年度安全培训的一部分，XYZ 公司的 IT 部门决定发起一次模拟钓鱼攻击。其目标是评估员工识别和报告钓鱼邮件的能力。以下哪项是确保该活动成功的**最有效**的第一步？

(A) 提前一周通知所有员工该活动
(B) 创建一个与常见威胁相似的真实的钓鱼邮件
(C) 为点击模拟钓鱼链接的员工提供奖励
(D) 回顾去年活动的结果

**解析 397。** **正确答案：B. 创建一个与常见威胁相似的真实的钓鱼邮件。** 为了让钓鱼攻击有效评估员工识别钓鱼威胁的能力，模拟钓鱼邮件必须尽可能真实。通过使其与常见威胁高度相似，IT 部门可以更准确地衡量员工的意识和反应。

**选项 A 错误。** 提前通知所有员工该活动将违背测试目的，因为他们会预期收到钓鱼邮件，因此更有可能识别并报告它。

**选项 C 错误。** 为点击模拟钓鱼链接的员工提供奖励会鼓励风险行为，并且与提高安全意识的目标背道而驰。

**选项 D 错误。** 虽然回顾以前往活动的结果可以提供见解，但它不是确保当前活动成功的最有效的第一步。

**问题 398。** 一个组织计划部署一个新应用程序，该程序可以从内部网络和互联网访问。该程序将仅通过 HTTPS 通信。安全管理员被要求配置防火墙以允许必要的流量。管理员应该配置以下哪项？

(A) 允许端口 21 并阻塞所有其他端口
(B) 允许端口 443 并阻塞所有其他端口
(C) 允许端口 80 并阻塞所有其他端口
(D) 允许端口 23 并阻塞所有其他端口

**解析 398。** **正确答案：B. 允许端口 443 并阻塞所有其他端口。** HTTPS 主要使用端口 443 进行安全通信。因此，允许端口 443 并阻塞所有其他端口将确保网络应用程序的安全运行。

**选项 A 错误。** 端口 21 用于 FTP（文件传输协议），与 HTTPS 无关。

**选项 C 错误。** 虽然端口 80 用于 HTTP，但它不提供 HTTPS 在端口 443 上所提供的加密功能。

**选项 D 错误。** 端口 23 用于 Telnet，与安全通信无关。

**问题 399。** XYZ 公司的 IT 部门非常希望防止用户更改系统设置（例如更改防火墙配置）。他们的大多数基础设施基于 Windows 操作系统。以下哪是实现这一目标的最有效方法？

(A) 使用 SELinux 强制执行的访问控制
(B) 利用组策略 (Group Policy) 设置并强制与系统设置相关的策略
(C) 部署第三方软件解决方案锁定系统设置
(D) 实施用户培训计划，指导用户遵循系统设置的最佳实践

**解析 399。** **正确答案：B. 利用组策略设置并强制与系统设置相关的策略。** 组策略在 Active Directory 环境中为操作系统、应用程序和用户设置提供集中管理和配置。这可以用于在 Windows 环境中强制执行特定的系统设置策略。

**选项 A 错误。** SELinux（增强型 Linux）主要用于 Linux 环境以实施强制访问控制。对于主要基于 Windows 的基础设施并不合适。

**选项 C 错误。** 虽然可能存在第三方解决方案，但利用组策略等内置功能通常更简洁、更具成本效益且高效。

**选项 D 错误。** 虽然用户培训至关重要，但在不实施技术控制的情况下仅依赖培训，对于防止用户更改系统设置是无效。
