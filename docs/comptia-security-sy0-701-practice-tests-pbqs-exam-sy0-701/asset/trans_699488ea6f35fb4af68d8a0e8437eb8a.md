**问题 270。** 中型企业的首席技术官（CTO）Liam 注意到有几个软件应用程序没有定期更新，导致了潜在的安全漏洞。经过调查，他发现没有特定的团队或个人被指定为这些应用程序的所有。为了增强安全性，Liam 应该强调什么？

- (A) 立即停用所有无所有者的应用程序
- (B) 为所有业务应用程序分配明确的所有权
- (C) 对所有应用程序进行每月漏洞评估
- (D) 将这些应用程序的管理工作外包给第三方供应商

**解析 270。** **正确答案：B. 为所有业务应用程序分配明确的所有权。** 分配明确的所有权可确保有指定的团队或个人负责应用程序的维护、更新和安全性。当所有权明确时，所有者有责任维护和保护应用程序的安全，从而减少漏掉更新等疏忽风险。

**选项 A 错误。** 立即停用可能不切实际或不可行，特别是当这些应用程序对业务运营至关重要时。

**选项 C 错误。** 虽然每月漏洞评估可以帮助识别安全问题，但它们没有解决场景中强调的问题根源——缺乏所有权和责任制。

**选项 D 错误。** 外包可能会转移责任，但不能确保应用程序将获得更好的管理或更安全。无论管理是内部还是外包，所有权的清晰度都是至关重要的。

**问题 271。** Sophia 收到一封来自银行的邮件，要求她由于系统升级尽快更新个人详情。邮件中包含一个链接，重定向指向一个与其银行网站相似的网站。她应该**首先**做什么？

- (A) 点击链接并及时更新她的个人详情，以避免任何不便
- (B) 将邮件转发给朋友和家人，以确保他们了解银行的系统升级
- (C) 立即删除邮件且不采取任何操作
- (D) 通过官方渠道联系她的银行以验证邮件的真实性

**解析 271。** 正确答案：D. 通过官方渠道联系她的银行以验证邮件的真实性。在根据未经请求的邮件采取行动之前（尤其是要求个人信息或凭据的邮件），直接与其声称代表的机构或实体验证其合法性至关重要。

钓鱼攻击通常利用恐惧、紧急性或感知的权威来诱导受害者提供敏感数据。防御此类尝试的最佳方法是在采取行动之前独立验证任何意外或可疑的请求。

选项 A 错误。通过提供个人详情来直接响应潜在的钓鱼邮件是一个常见错误，使用户户面临欺诈和身份盗窃的风险。

选项 B 错误。将可能恶意的邮件转发给他人可能会进一步传播威胁，并可能危及他们的安全。

选项 C 错误。虽然删除邮件可能防止 Sophia 掉入钓鱼陷阱，但告知银行此类可疑邮件仍然是一个做法，这样他们可以采取适当措施并警告其他客户。

**问题 272。** AlphaTech 是一家不断发展的 SaaS 公司，在不同的云提供商处部署了多个应用程序。安全团队难以管理和分析来自这些不同来源的日志。哪种解决方案**最能**帮助 AlphaTech 集中其日志以进行更高效的分析？

- (A) 网络入侵检测系统 (NIDS)
- (B) 日志聚合工具 (Log Aggregation Tool)
- (C) 数据泄露防护 (DLP) 软件
- (D) 漏洞扫描器

**解析 272。** 正确答案：B. 日志聚合工具。日志聚合工具专门用于收集、集中和管理来自各种来源的日志，使其更容易分析和关联相关事件。

**选项 A 错误。** 虽然 NIDS 可以帮助检测网络上的恶意活动，但它不能集中来自不同应用程序源的日志。

**选项 C 错误。** DLP 软件侧重于防止未经授权的数据传输，不起到集中日志的作用。

**选项 D 错误。** 漏洞扫描器设计用于识别系统中的漏洞，但不会聚合来自各种来源的日志。

**问题 273。** AlphaTech 正在寻求一种针对其特定行业的最新网络威胁的全面情报源。虽然开源情报（OSINT）提供了有价值的数据，但公司正在考虑投资一种更专门的解决方案。以下哪项最能满足 AlphaTech 的需求？

- (A) 实施内部蜜罐以捕获攻击者
- (B) 订阅第三方威胁情报馈送
- (C) 定期参加网络安全会议
- (D) 使用开源漏洞扫描器

**解析 273。** **正确答案：B. 订阅第三方威胁情报馈送。** 第三方威胁情报馈送（特别是针对特定行业定制的）提供了关于网络威胁的专门的、通常是实时的信息，提供了超出公共领域可获得信息的见解。

选项 A 错误。虽然蜜罐可以帮助了解针对该组织的攻击者的战术，但它们无法提供关于行业范围内威胁的全面情报。

选项 C 错误。参加网络安全会议可以提供见解和更新，但它不是一个持续或实时的威胁情报源。

选项 D 错误。开源漏洞扫描器有助于识别组织基础设施内部的漏洞，但无法提供关于特定行业网络威胁的专门情报。

**问题 274。** 一名员工接到一个自称来自 IT 部门的人的电话。来电者说员工的电脑需要紧急更新，并索要登录凭据以远程执行更新。该员工由于关于冒充的哪种警旗信号而产生怀疑？

- (A) 打电者没有使用技术术语
- (B) IT 通常通过邮件发送更新通知
- (C) 员工没有预料到会有更新
- (D) 来电者的声音听起来陌生

**解析 274。** 正确答案：B. IT 通常通过邮件发送更新通知。如果组织的标准程序是通过邮件发送更新通知，那么索要凭据的非请求电话就是一个明显的警旗。

冒充是社交工程攻击中常用的策略，攻击者伪装成受害者信任的人。识别偏离标准程序的行为有助于识别冒充尝试。

选项 A 错误。是否使用技术术语并不是判断冒充的可靠指标。一些真实的 IT 人员为了让非技术员工更容易理解会避免使用术语。

选项 C 错误。虽然意外更新可能可疑，但它们本身并不一定意味着冒充。合法的意外更新可能会发生。

选项 D 错误。声音陌生并不是可靠的指标，因为大型组织可能有许多员工从未接触过的 IT 人员。
