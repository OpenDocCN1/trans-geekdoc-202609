问题 43. 在对公司的基础设施遭受了一系列网络攻击后，IT 团队决定部署一种看起来像是网络合法组成部分，但实际上被刻意隔离并受监控的解决方案。他们意在这一孤立环境中检测并分析恶意活动。他们最可能实现的技术是什么？

- (A) 网络分
- (B) 蜜罐 (Honeypot)
- (C) DMZ（非军事化区）
- (D) 沙箱 (Sandboxing)

解析 43. 正答案：B. 蜜罐。蜜罐是特意设置的看似网络合法部分，但它是被隔离并严密监控的。其目的是吸引攻击者并观察他们的行为，从而对潜在威胁和对手采用的方法提供见解。

选项 A 错误。网络分涉及将网络分为较小的子网络。虽然这可以通过限制攻击者对特定分段的访问来增强安全性，但它并不作为吸引攻击者的诱饵。

选项 C 错误。DMZ（非军事化区）是作为互联网和组织内部网络之间缓冲区的子网。虽然它可以包含外部用户可访问的服务器，但其主要目的不是作为诱饵，而是提供一种保护层。

选项 D 错误。沙箱是一种安全机制，允许程序在独立环境中运行，以防止它们影响更广泛的系统。它用于测试和分析潜在的恶意软件，而不是用于诱捕攻击者。

问题 44. 一家中型企业的 CTO Liam 注意到几个软件应用程序没有定期更新，导致了潜在的安全漏洞。经过调查，他意识到没有特定的特定的团队或个人被指定为这些应用程序的所有者。为了增强安全性，Liam 应该强调什么？

- (A) 立即停用所有无所有者的应用程序
- (B) 为所有业务应用程序分配明确的所有权
- (C) 对所有应用程序进行每月的漏洞评估
- (D) 将这些应用程序的管理外包给第三方供应商

解析 44. 正答案：B. 为所有业务应用程序分配明确的所有权。分配明确的所有权可确保有指定的团队或个人负责应用程序的维护、更新和安全性。当所有权归明确时，所有者就有责任维护和确保应用程序的安全，从而减少了诸如遗漏更新之类的风险。

选项 A 错误。立即停用可能不实际或不可行，特别是当这些应用程序对业务运营至关重要时。

选项 C 错误。虽然每月的漏洞评估可以帮助识别安全问题，但它们没有解决场景中强调的问题根源——即缺乏所有权和问责制。

选项 D 错误。外包可能会转移责任，但它不能确保应用程序将得到更好的管理或更安全。无论管理是内部还是外包，所有权的清晰度都是关重要的。

问题 45. TechSoft Corp 是一家中型软件开发公司，将其主办公室搬到新建筑。管理层担心下班后的潜在威胁，特别是由于网络间谍报告的增加。他们正在评估不同的安全措施。哪种方案可以在非工作时间提供即时的物理存在和威慑？

- (A) 带有运动检测的 CCTV
- (B) 所有入口处的视网膜扫描
- (C) 安保人员现场
- (D) 强化固的门窗

解析 45. 正答案：C. 安保人员现场。安保人员提供了可见的威慑和即时的物理存在。在需要对威胁做出立即响应、威慑潜在入侵者或评估可疑活动的情况下，人工因素是无价的，特别是非工作期间。

选项 A 错误。虽然带有运动检测的 CCTV 可以监控并报警移动，但它不能提供安保人员那样的即时人工响应和威慑。

选项 B 错误。视网膜扫描是一种控制访问的验证机制。虽然它提供了高安全性，但它无法提供安保人员那样的可见威慑或即时响应。

选项 D 错误。强化门窗增强了建筑的物理安全性，但它们不能提供像安保人员那样主动且可见的人工威慑。

问题 46. 初创公司的系统管理员 Alice 正准备为她的公司部署一个新网站。为了确保用户与网站之间的通信安全，她计划为网站获取数字证书。在这样做之前，Alice 必须先采取哪一步才能从证书颁发机构 (CA) 获取证书？

- (A) 生成公私钥对
- (B) 向 CA 提交护照扫描件
- (C) 下载最新的 CA 根证书
- (D) 使用对称加密加密网站

解析 46. 正答案：A. 生成公私钥对。在 Alice 操作之前，她必须先从 CA 生成一对公私钥。完成此后，她会创建一个包含其公钥和一些额外信息的证书签名请求 (CSR)。然后将 CSR 提交给 CA 进行签名。

选项 B 错误。CA 通常不要求标准 SSL/TLS 证书提供护照扫描件。他们可能有身份验证流程，但通常是用于扩展验证证书的。

选项 C 错误。虽然可能需要通过下载根证书来信任 CA，但并不是请求数字证书之前所需的步骤。

选项 D 错误。对称加密与获取数字证书的过程无关。

问题 47. 安全管理员 Julia 担心存储在公司服务器上的机密项目文件可能被未经授权的访访问。她决定在项目文件夹中放置一个看起来很有吸引力但实际上受到访问监控的文档。这种策略旨在检测是否有人在未经授权的情况下访问文件。这种文档通常被称为什么？

- (A) 盐文件 (Salt file)
- (B) 蜜罐文件 (Honeyfile)
- (C) 日志文件 (Log file)
- (D) 备份文件 (Backup file)

解析 47. 正答案：B. 蜜罐文件。蜜罐文件是特意放置的、作为诱饵的文件。如果被访问，它可以提供警报，表明可能有人在没有适当授权的情况下访问文件，或者这可能是潜在内部威胁的指示。

选项 A 错误。盐是一种随机数据，作为哈希数据或密码的单向函数的额外输入。它不是诱饵文件。

选项 C 错误。日志文件记录操作系统或其他软件中的事件，以协助故障排除和活动监控，但它不是被用来欺骗措施。
