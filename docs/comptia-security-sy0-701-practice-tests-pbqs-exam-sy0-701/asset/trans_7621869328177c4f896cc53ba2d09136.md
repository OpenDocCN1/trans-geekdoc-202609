问题 140。某家零售公司最近遭受了数据泄露，攻击者加密了所有的销售系统，导致其无法使用。随后收到一封勒索信，要求使用加密货币支付以解密系统。这次攻击背后最明显的动机是什么？

- (A) 抗议公司的环保政策
- (B) 通过勒索获取经济利益
- (C) 为了了解公司供应链而进行的间谍活动
- (D) 通过展示技术技能来提升声誉

解释 140. **正确答案：B. 通过勒索获取经济利益。** 攻击者加密了关键系统，然后索要赎金以解密。此类勒索软件攻击的主要动机是强迫受害者付费以重新获得系统的访问权限，从而获取经济利益。

选项 A 错误。文中没有提到或迹象攻击者的动机是公司的环保或其他任何政策。

选项 C 错误。没有证据表明攻击者对公司的供应链或任何其他内部信息感兴趣。他们的重点是加密和勒索。

选项 D 错误。虽然展示技术技能可能是攻击的副产品，但直接要求付款表明，经济利益而非名声才是主要动机。

问题 141。某公司检测到一起持续了数周的 DDoS 攻击。攻击者使用由数百万台感染设备组成的僵尸网络，并频繁更换攻击向量以绕过缓解措施。这种持久且耗资源的攻击暗示了哪种类型威胁行为者的资源和资金？

- (A) 资源极少的业余黑客
- (B) 测试漏洞的网络安全研究人员
- (C) 具有战略利益的国家级行为者
- (D) 拥有充足资金的组织犯罪集团

解释 141. **正确答案：D. 拥有充足资金的组织犯罪集团。** DDoS 攻击的规模和持续时间，结合大规模僵尸网络的使用和攻击向量的频繁更换，表明威胁者拥有大量的资源。虽然国家可能可能进行此类攻击，但 DDoS 攻击也是资金充足的犯罪集团的特征，特别是当金钱或战略勒索可能是动机时。

选项 A 错误。资源极少的业余黑客没有能力使用包含数百万台设备的僵尸网络持续数周进行大规模 DDoS 攻击。

选项 B 错误。网络安全研究人员通常不参与恶意活动，发起持久的 DDoS 攻击是不符合伦理的也是违法的。

选项 C 错误。虽然国家级行为者可能有资源发起此类攻击，但 DDoS 攻击（尤其是勒索性质的）更多地与组织犯罪集团相关联。

问题 142。在一次例行安全评估中，Claire 发现其组织内新部署的一台数据库服务器仍使用默认登录凭据。与此发现相关的主要的安全风险是什么？

- (A) 数据库将无法正常运行
- (B) 服务器将需要频繁打补丁
- (C) 未经授权的人可能轻易获得访问
- (D) 服务器将消耗更多带宽

解释 142. 正确答案：C. 未经授权的人可能轻易获得访问。默认凭据通常是公开的，如果不进行更改，恶意攻击者可以轻松使用它们来获取系统的未授权访问。

默认凭据（可能包括制造商为初始设置设置用户名和密码）是广为人知的，并且可以在网上轻松搜索到。如果部署后不更改，它们将构成重大的安全风险，因为这允许任何了解这些信息的人访问系统。

选项 A 错误。使用默认凭据并不直接影响数据库的理想运行。

选项 B 错误。使用默认凭据并不意味着服务器需要频繁打补丁。然而，补丁管理是维护服务器安全的另一个独立方面。

选项 D 错误。使用默认凭据不会直接导致服务器消耗更多带宽。

问题 143。在一次大型体育赛事期间，某广播公司的流媒体服务因流量激增而离线。攻击持续了整个赛事期间，然后在赛事结束后消失。这次攻击背后最可能的动机是什么？

- (A) 拦截敏感通信的间谍活动
- (B) **在体育赛事期间导致服务中断**
- (C) 为了未来的勒索要求而进行数据外泄
- (D) 获取未经授权的访问并植入恶意软件

解释 143. 正确答案：B. 在体育赛事期间导致服务中断。流量激增特意针对体育赛事的时间点，并在赛事结束后随后消失，这表明攻击者有针对性地要在赛事期间中断服务。

选项 A 错误。场景中没有迹象表明攻击者对拦截通信感兴趣，特别是目标是广播公司而非外交或政府机构。

选项 C 错误。场景中没有提到任何数据外泄或后续的勒索要求。攻击者的重点是中断流媒体服务。

选项 D 错误。虽然让服务离线有时可以作为更恶意活动的掩护，但该场景中没有证据表明植入了恶意软件或获得了未经授权的访问。

问题 144。一名员工接到一个自称来自 IT 部门的电话。打电者说员工的电脑需要紧急更新，并索要登录凭据以远程执行更新。员工因为哪个关于身份冒充的红旗而产生怀疑？

- (A) 打电者没有使用技术术语
- (B) IT 通常会通过电子邮件发送更新通知
- (C) 员工没有预感到任何更新
- (D) 打电者的声音陌生

解释 144. 正确答案：B. IT 通常会通过电子邮件发送更新通知。如果组织的标准程序是发送更新电子邮件通知，那么索要凭据的非自来电话将是一个明显的红旗。

身份冒充是社会工程中常用的常用策略，攻击者假装成受害者信任的人。识别偏离标准程序的情况有助于识别身份冒充。

选项 A 错误。使用或不使用技术术语并不是身份冒充的可靠指标。某些真实的 IT 人员可能会避免术语，以便让非技术背景的员工听得更清楚。

选项 C 错误。虽然意外的更新可能令人怀疑，但它们本身并不一定表明是身份冒充。合法的意外更新也是可能发生的。

选项 D 错误。声音陌生不是可靠的指标，因为大型组织可能有许多员工未曾接触过的 IT 人员。

问题 145。在一次电子商务网站审计期间，安全分析师发现，如果用户尝试购买产品并同时取消订单，产品有时会被添加到用户的购物车而不扣除任何资金。这种漏洞可能被利用以免费获取产品。该电子商务网站易受到何种类型漏洞的影响？

- (A) 目录遍历
- (B) 不安全的直接对象引用 (IDOR)
- (C) 竞态条件 (Race Condition)
- (D) 跨站请求伪造 (CSRF)

解释 145. 正确答案：C. 竞态条件。当应用程序的非预期行为由于并发事件或操作的时机引起时，表明存在竞态条件。在这里，同时进行的购买和取消导致了错误的结果。
