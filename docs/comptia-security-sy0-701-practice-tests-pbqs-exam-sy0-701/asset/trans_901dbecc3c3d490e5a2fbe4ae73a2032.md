

# 解析 388. 正确答案：D。向其公司的 IT 部门报告该电子邮件并避免点击任何链接。

Sarah 可能收到了一封网络钓鱼邮件，这是攻击者用来欺骗用户提供敏感信息的常用策略。最佳行动是向 IT 部门报告这封可疑邮件，以便他们采取必要的预防措施并通知其他员工。

选项 A 错误。虽然 Sarah 警示他人的直觉是正确的，但转发可能带有恶意的邮件可能会导致更多风险。最好是提醒 IT 部门。

选项 B 错误。在可疑邮件中点击链接（尤其是 URL 拼写错误的链接）可能会导致个人和公司数据泄露。

选项 C 错误。仅仅删除邮件无法解决对组织更广泛的风险。报告此类事件有助于公司加强防御能力。

## 问题 389. 网络管理员 Paul 在其组织中配置了各种网络设备，以便在发生特定故障时发送警报。当一台交换机发生电源故障后，Paul 收到了即时通知。Paul 最可能利用以下哪种工具来接收此通知？

- (A) Syslog 服务器
- (B) 简单网络管理协议 (SNMP) 陷阱
- (C) 数据包嗅器
- (D) 防火墙日志

## 解析 389. 正确答案：B。简单网络管理协议 (SNMP) 陷阱。** SNMP 陷阱是设备发送的未请求的警报消息，用于通知 SNMP 管理站发生了特定事件。在这种情况下，交换机在检测到电源故障时向 Paul 发送了 SNMP 陷阱。

**选项 A** 错误。虽然 Syslog 服务器可以用于收集来自各种设备的日志，但它不会像 SNMP 陷阱那样根据特定事件主动发送警报。

**选项 C** 错误。数据包嗅器会捕获并分析网络流量，但不会主动向管理员报告特定的设备事件。

**选项 D** 错误。防火墙日志是专属于防火墙的，用于跟踪通过防火墙的流量，但它们通常不会发送关于网络设备健康的未请求性警报。

## 问题 390. 安全分析师 Samantha 被指派为高级管理层编写月报，详细说明公司的安全态势。为了确保报告有效传达公司当前的安全状况，包含以下哪个元素是最重要的？

- (A) 所有安全事件的详细技术日志
- (B) 按类别分类的事件图表表示
- (C) 所有用户及其访问权限的完整列表
- (D) 用于演示的近期钓鱼邮件副本

## 解析 390. 正确答案：B。按类别分类的事件图表表示。** 按类别分类的图表能够允许高级管理层快速理解安全事件的类型和频率，有助于决策和资源分配。

**选项 A 错误。**虽然技术日志对于事件分析至关重要，但对于高级管理层报告来说，它们可能过于详细且技术性强。

**选项 C 错误。**虽然管理用户访问权限至关重要，但对于侧重于公司安全态势的月度高级管理报告来说，所有用户及其权限的完整列表可能过量了。

**选项 D 错误。**虽然钓鱼邮件的示例具有教育意义，但对于旨在提供公司安全状况概述的月报来说，它们并不是至关重要的。

## 问题 391. 公司的一位软件开发人员注意到他们使用的一个合法工具反复被公司的安全解决方案标记并隔离。网络安全团队在不损害安全的情况下，解决此问题的最佳行动是哪一个？

- (A) 关闭杀毒解决方案
- (B) 在杀毒设置中将该软件工具加入白名单
- (C) 降低杀毒软件的安全级别
- (D) 安装不同的杀毒解决方案

## 解析 391. 正确答案：B。在杀毒设置中将该软件工具加入白名单。** 白名单允许网络安全团队指定被认为是安全的软件或应用程序，这些程序不应被杀毒解决方案标记或隔离。

**选项 A 错误。**关闭杀毒解决方案将使系统遭受恶意软件的攻击。

**选项 C 错误。**降低杀毒软件的安全级别可能会降低防护。

**选项 D 错误。**仅仅安装不同的杀毒解决方案并保证工具不会被标记。

## 问题 392. 财务公司的 IT 安全经理 Lucy 收到自动警报，一名员工尝试向外部地址发送包含社会安全号码的文档。以下哪项最可能生成了警报？

- (A) 网络入侵检测系统 (NIDS)
- (B) 数据泄露防护 (DLP) 解决方案
- (C) 漏洞扫描器
- (D) 数据包分析器

## 解析 392. 正确答案：B。数据泄露防护 (DLP) 解决方案。** DLP 解决方案专门设计用于监控和控制数据传输。在这种情况下，DLP 检测到了传输的社会安全号码。

选项 A 错误。NIDS 用于检测并警报恶意活动，但它不会扫描传输的数据。

选项 C 错误。漏洞扫描器识别并报告漏洞，但不会监控传输。

选项 D 错误。虽然数据包分析器可以捕获并分析网络流量，但它们本身不会根据传输的内容生成警报。

## 问题 393. 一家拥有全球患者的医疗机构计划为其医疗数据存储建立备份站点。他们被建议在恢复计划中考虑地理分散。在本文中，以下哪个理由最不合理？

- (A) 缓解区域性灾害的风险
- (B) 在局部故障时提供冗余
- (C) 从不同地区的负载中受益
- (D) 为全球患者提供更快的访问速度

## 解析 393. 正确答案：D。为全球患者提供更快的访问速度。** 在恢复的背景下，地理分散的主要目标是弹性和冗余，而不是速度。虽然在不同位置设置服务器可以提高本地用户的速度，但对于恢复备份站点来说，重点在于可用性和冗余。

选项 A 错误。地理分散有助于缓解与自然灾害相关的风险，确保备份站点不受影响主站的相同灾害。

选项 B 错误。通过在不同位置设置站点可以缓解局部故障。

选项 C 错误。地理分散允许组织利用不同地区的错峰时间更有效地管理和分配负载。

## 问题 394. 中型企业 TechCo 计划实施一种解决方案来监控、控制和限制员工访问以提高效率并增强安全性。他们还希望缓存频繁访问的内容以减少带宽消耗。哪种解决方案最符合 TechCo 的需求？

- (A) 在每个部门网络上部署去中心化代理
- (B) 设置基于 DNS 的过滤服务
- (C) 使用具有缓存功能的中心化代理
- (D) 向所有员工推荐用于过滤器的器的扩展

## 解析 394. 正确答案：C。使用具有缓存功能的中心化代理。** 中心化代理允许组织从中心对网络访问进行过滤、监控和控制。此外，具有缓存功能的代理可以存储频繁访问的网络内容，从而减少重复下载并节省带宽。
