**Question 311.** Julia, a cybersecurity analyst, notices a recently installed application named “PhotoEditorPro.exe” on a corporate workstation. Upon further inspection, she identifies that this application is silentlyfiltrating sensitive company data to an external IP address. Which type of malware is Julia most likely observing?

+   **(A)** Worm
**(B)** Ransomware
**(C)** Trojan
**(D)** Adware

**Explanation 311. Correct Answer: C. Trojan.** A Trojan is a type of malware that disguises itself as a legitimate software or application. Unlike viruses, Trojans don’t replicate themselves, but they can be as destructive as if not more so. In this case, the “PhotoEditorPro.exe” appears to be a legitimate photo editing application but is actually being used to transmit sensitive data to an external source.
