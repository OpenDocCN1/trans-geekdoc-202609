**问题 204。** 一家公司的 IT 部门注意到在过去的两天中，账户锁定的数量激增，特别是在非工作时间。虽然某些账户来自不同部门，但大多数来自财务团队。关于这些锁定，以下哪种解释**最有可能**？

- (A) IT 部门的计划内维护
- (B) 员工在财务团队内部共享密码
- (C) 攻击者正试图获取未经授权的访问
- (D) 最近的密码策略更改要求更频繁地更改

**解释 204. 正确答案：C。攻击者正试图获取未经授权的访问。** 账户锁定的突然增加，特别是非工作时间内，表明存在可疑活动。锁定的具有针对性，特别是针对财务等敏感部门，表明攻击者可能正在尝试未经授权的访问。

**选项 A 是错误的。** 计划维护通常会提前通知，而且不太可能导致账户锁定的激增。

**选项 B 是错误的。** 虽然员工共享密码是一个安全问题，但它通常不会导致账户锁定的激增，特别是在非工作时间。

**选项 D 是错误的。** 密码策略的更改可能会导致锁定次数增加，但锁定的针对性（大多数来自财务部门）以及它们在非工作时间的发生，使得该选项的可能性较低。

**问题 205。** Sarah 是某科技公司的一名软件开发人员，她决定获得公司发放移动设备的 root 权限以自定义其功能。不久后，IT 部门检测到她的设备有未经授权的数据传输。哪种移动设备漏洞最可能与她的行为有关？

- (A) 应用程序的侧载
- (B) 操作系统更新不一致
- (C) 移动设备越狱狱（Jailbreaking）
- (D) 使用开放的 Wi-Fi 网络

**解释 205. 正确答案：C。移动设备越狱。** 越狱移除制造商对某些设备施加限制的过程，从而允许获取 root 权限。有了 root 权限，用户可以安装和自定义未经过设备制造商或运营商批准的软件。然而，越狱可能会使设备暴露在各种安全漏洞中，正如未经授权的数据传输所示。

**选项 A 是错误的。** 侧载指的是从官方应用商店以外源安装应用程序。虽然侧载会带来安全风险，但 Sarah 的行为专门与获取 root 权限有关，这指向了越狱。

**选项 B 是错误的。** 操作系统更新不一致指的是不同设备上存在多个版本的操作系统。Sarah 的行为与获取 root 权限有关，而不是更新不一致。

**选项 D 是错误的。** 使用开放的 Wi-Fi 网络可能会使移动设备暴露在威胁中，但 Sarah 的漏洞源于获取 root 权限，而不是她对 Wi-Fi 网络的选择。

**问题 206。** 在某公司中心数据库遭受最近的网络攻击后，IT 部门被要求增强其网络基础设施的安全性。以下哪种技术是**最佳**的，可以确保人力资源和财务等不同部门无法访问对方的敏感数据？

- (A) 基于部门实施网络分段
- (B) 升级整个网络的带宽
- (C) 为所有部门使用单一的强密码
- (D) 将所有部门数据移动到云端

**解释 206. 正确答案：A。基于部门实施网络分段。** 网络分段将网络分为多个段或子网，每个段都作为一个独立的小型网络。这限制了段之间的访问，并通过确保只有段内的人员才能访问其资源来保护敏感数据。

**选项 B 是错误的。** 虽然升级带宽可能会提高网络速度，但它没有解决部门数据隔离的安全问题。

**选项 C 是错误的。** 所有部门使用单一强密码无法防止一个部门访问另一个部门的数据。它还引入了单点故障。

**选项 D 是错误的。** 将数据移动到云端可以提供一些安全优势，但如果没有适当的访问控制和分段，不同部门仍然可以访问彼此的数据。

**问题 207。** 在组织的安全审查期间，网络安全分析师注意到不同的用户账户有多次失败的登录尝试，每个账户使用了几个常用的密码。这种场景**最准确**描述了哪种类型的密码攻击？

- (A) 暴力破解攻击
- (B) 字典攻击
- (C) 凭据填充攻击（Credential Stuffing）
- (D) 密码喷洒（Password Spraying）

**解释 207. 正确答案：D。密码喷洒。** 密码喷洒是一种攻击方法，攻击者对多个用户账户尝试几个常用的密码，而不是对单个账户尝试许多密码。描述的场景是针对多个具有常用密码的用户账户，这与该方法相符。

**选项 A 是错误的。** 暴力破解攻击涉及对特定账户尝试所有可能的密码组合。场景描述的是在多个账户上尝试常用密码，而不是在一个账户上进行穷举组合。

**选项 B 是错误的。** 字典攻击涉及对单个账户尝试可能的密码列表（这些列表通常从字典或常用密码列表中提取）。该场景强调的是多个账户。

**选项 C 是错误的。** 凭据填充涉及使用之前泄露的用户名和密码对来获取未经授权的访问。重点是使用已知的凭据，而不是常用密码。

**问题 208。** TechnoCorp 的 IT 团队注意到过去一周存在一个持续的模式：特定服务器的 CPU 使用率在凌晨 2:00 到 4:00 之间飙升至 100%，这段时间通常用户活动极少。这种情况的**最可能**的原因是什么？

- (A) 服务器正在自动更新其软件
- (B) 员工正在运行一项密集任务
- (C) 服务器正遭受 DDoS 攻击
- (D) 恶意软件正在进行货币挖掘活动

**解释 208. 正确答案：D。恶意软件正在进行货币挖掘活动。** 货币挖掘恶意软件通常会导致大量的资源消耗，特别是 CPU 使用。攻击者经常在非工作时间安排这些活动以减少被的概率。考虑到非工作时间持续的高 CPU 使用，货币挖掘是一个可能的原因。

**选项 A 是错误的。** 虽然软件更新可能会导致资源消耗，但它们通常不会导致持续几天的100% CPU 使用率。

**选项 B 是错误的。** 虽然员工可能正在运行密集任务，但非工作时间的持续模式使得这种可能性较小。

**选项 C 是错误的。** 虽然 DDoS 攻击可以导致资源消耗，但它不会每天在同一时间段专门针对 CPU 使用率。

**问题 209。** 某组织的 IT 部门注意到过去 24 小时内网络流量迅速增加。同时，许多员工报告他们的系统变慢，并且通过电子邮件从同事那里收到了一个名为“updatePatch.exe”的文件，尽管这些同事并没有故意发送任何文件。哪种类型的恶意软件最可能负责这种行为？

- (A) 木马程序
- (B) 勒索软件
- (C) 广告软件
- (D) 蠕虫

**解释 209. 正确答案：D。蠕虫。** 蠕虫是一种自我复制并传播到其他设备的恶意软件。网络流量的迅速增加以及在发送者不知情的情况下向各种用户发送文件是蠕虫行为的特征。它们会消耗带宽和系统资源，导致系统变慢。
