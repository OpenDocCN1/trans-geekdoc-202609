**问题 458。** 一家名为 GlobalTech 的国际公司正在使用不同供应商提供的多个 Web 应用程序。为了确保员工可以访问这些应用程序而无需记住多组凭据，他们希望实现一种能够在公司与服务提供商之间安全交换用户认证信息的解决方案。GlobalTech 应该实施什么？

- (A) 将每个应用程序与独立的 LDAP 服务器集成
- (B) 使用安全断言标记语言 (SAML) 实现单点登录 (SSO)
- (C) 在每个应用程序的 URL 中嵌入加密的用户凭据
- (D) 依赖公司与每个供应商之间共享的公共 API 密钥

解析 458. **正确答案：B. 使用安全断言标记语言 (SAML) 实现 SSO。** SAML 是一种基于 XML 的标准，用于在双方之间交换身份验证授权数据。它旨在促进 Web 应用程序的单点登录。通过使用 SAML 实现 SSO，GlobalTech 可以允许员工只需一次身份验证，即可访问多个应用程序而无需重复身份验证。

**选项 A 错误。** 为每个应用程序都设置独立的 LDAP 服务器违背了 SSO 的初衷，并增加了用户管理的复杂度。

**选项 C 错误。** 在 URL 中嵌入加密的用户凭据是不安全的，不符合推荐做法。

**选项 D 错误。** API 密钥用于系统与系统之间的通信，而不是用于用户认证。此外，不应轻率共享公共 API 密钥。

**问题 459。** 用户想向其同事发送一封机密邮件，并确保只有预期的接收者才能阅读。用户还想向接收者保证，该邮件确实是由他们发送的。用户应该采用哪种加密方法来实现这一目标？

- (A) 使用共享密钥的对称加密
- (B) 使用非对称加密并用接收者的公钥加密邮件
- (C) 使用非对称加密，用用户的私钥加密邮件
- (D) 使用非对称加密，首先用用户的私钥对邮件进行签名，然后用接收者的公钥进行加密

解析 459. **正确答案：D. 使用非对称加密，首先用用户的私钥对邮件进行签名，然后用接收者的公钥进行加密。**

**选项 D 同时提供了机密性和不可否认性。** 邮件使用接收者的公钥加密，确保只有接收者可以使用其私钥对其进行解密。使用发送者的私钥对邮件进行签名允许接收者使用发送者的公钥验证发送者的身份。

**选项 A 错误。** 虽然对称加密提供了机密性，但它不提供不可否认性或发送者验证。

**选项 B 错误。** 使用接收者的公钥加密提供了机密性，但缺乏对发送者的验证。

**选项 C 错误。** 使用用户的私钥加密邮件将提供发送者验证，但不会提供机密性。

**问题 460。** 电子商务公司 DigitalFront 预计在即将到来的年度销售活动期间流量将激增。他们希望确保网站和应用程序能够处理预期的用户活动增长，而不出现任何性能下降。以下步骤哪一个与实现这一目标最相关？

- (A) 增加安全审计的频率
- (B) 实施专门针对技术的容量规划
- (C) 为所有用户采用多因素身份认证
- (D) 投资先进的威胁情报解决方案

解析 460. **正确答案：B. 实施专门针对技术的容量规划。**

专注于技术的容量规划可以确保所有技术资源（如服务器、带宽、存储和软件）都已充分准备，以应对预期的负载或流量增加，确保在高峰期间的性能顺畅。

选项 A 错误。安全审计对于识别漏洞非常重要，但它们无法解决扩展技术资源以管理增加流量的直接需求。

选项 C 错误。多因素身份认证提高了用户的安全性，但无助于处理网站流量或用户活动的激增。

 选项 D 错误。先进的威胁情报解决方案提供了对潜在威胁的洞察，但它们没有解决为了适应增加流量的技术扩展问题。

**问题 461。** 安全分析师 Sarah 担心公司内部门户可能遭受中间人攻击。为了降低这种风险，她建议从可信实体获取数字证书。以下哪种实体负责颁发此类证书？

- (A) 密钥中心
- (B) 证书权威 (CA)
- (C) 令牌系统
- (D) 安全信息事件管理

解析 461. **正确答案：B. 证书权威 (CA)。** 证书权威 (CA) 是负责颁发、验证和吊销数字证书的可信实体。这些证书用于验证互联网上的实体（如网站），确保通信的安全性，从而降低中间人攻击的风险。

选项 A 错误。密钥中心 (KDC) 是 Kerberos 身份验证协议的一部分，负责分发会话票和临时会话密钥，而不是颁发数字证书。

选项 C 错误。令牌化系统将敏感数据替换为非敏感替代品（令牌）。它们不颁发数字证书。

选项 D 错误。安全信息事件管理 (SIEM) 聚合并分析来自各种来源的日志数据，对安全警报进行实时分析，但不颁发证书。

**问题 462。** 一位安全分析师发现一个外部 IP 地址在过去两天内反复尝试所有可能的字符组合以访问公司的 VPN 门户。这最可能描述的是哪种类型的密码攻击？

- (A) 密码喷洒
- (B) 字典攻击
- (C) 彩虹表攻击
- (D) 暴力破解攻击

解析 462. **正确答案：D. 暴力破解攻击。** 暴力破解攻击涉及系统地尝试所有可能的字符组合直到找到正确的为止。场景说明在 VPN 门户上尝试了所有可能的字符组合，表明是暴力破解攻击。

选项 A 错误。密码喷洒是在多个账户上尝试几个常用的密码，而不是在一个账户上尝试所有组合。

选项 B 错误。字典攻击使用常用或之前使用过的密码列表来尝试访问。它并不涉及尝试所有可能的组合。
