
问题 186。在一次安全审计中，某公司发现一个恶意攻击者能够位于网络路径上，截获客户端与服务器之间的 TLS 握手消息。攻击者的目标是通过影响加密套件协商过程来削弱加密。该场景描述的是哪种网络攻击？

- (A) ARP 投毒 (ARP Poisoning)
- (B) 降级攻击 (Downgrade Attack)
- (C) SYN 洪水 (SYN Flood)
- (D) 死亡之源 (Ping of Death)

解析 186。**正确答案：B. 降级攻击 (Downgrade Attack)。**降级攻击发生在攻击者干扰设置过程（例如 TLS 握手）时，强制两个实体选择安全性较低的通信模式或加密标准。在这种案例中，通过截获并可能修改 TLS 握手消息，攻击者正试图让客户端和服务器使用较弱的加密套件。

选项 A 错误。ARP 投毒是一种攻击，攻击者在局域网上发送伪造的 ARP 消息，将攻击者的 MAC 地址与另一个节点的 IP 地址（如默认网关）关联。这是一种实现路径上攻击的方法，但场景描述的是影响加密套件协商，这属于降级攻击。

选项 C 错误。SYN 洪水是拒绝服务攻击的一种，攻击者向目标系统发送一系列 SYN 请求，试图消耗服务器资源。它与截获 TLS 握手消息无关。

选项 D 错误。死亡之源是一种旧的攻击，恶意方发送格式错误或过大的 ping 数据包以导致目标系统崩溃。它不涉及截获或影响 TLS 握手过程。

问题 187。某开发人员在公司网站上实现了一个新功能，允许用户通过名称搜索产品。在几天后，IT 团队注意到异常活动，数据库中的整个数据表被转导出（dumped）。该新功能可能引入了哪种漏洞？

- (A) 跨站脚本 (XSS)
- (B) 分布式拒绝服务 (DDoS)
- (C) 结构化查询语言注入 (SQLi)
- (D) 跨站请求伪造 (CSRF)

解析 187。**正确答案：C. 结构化查询语言注入 (SQLi)。**SQLi 攻击发生在攻击者可以向查询中插入或“注入”SQL 代码时。如果用户输入在用于 SQL 语句之前没有经过妥善清洗，攻击者就可以利用此来操纵查询，导致数据被未经授权的查看、损坏或删除，以及其他恶意活动。

结构化查询语言注入（或 SQLi）是一种攻击者用于在数据库上运行恶意 SQL 语句的代码注入技术。鉴于实现搜索功能后数据库中的整个表被转导出，这清楚表明该功能没有对用户输入进行妥善清洗，导致了 SQLi。

选项 A 错误。跨站脚本 (XSS) 攻击将恶意脚本注入用户查看的网页中。它不会导致场景中描述的数据库表转出。

选项 B 错误。分布式拒绝服务 (DDoS) 攻击通过流量淹没目标，导致服务中断。它与提取数据库信息无关。

选项 D 错误。跨站请求伪造 (CSRF) 欺骗受害者提交恶意请求。它不会导致数据库表的转出。

问题 188。在一次例行安全评估中，渗透测试员 Jake 发现，通过修改位于公共目录下的一个配置文件，他可以为自己分配管理员权限。Jake 正在利用哪种漏洞？

- (A) 跨站脚本 (XSS)
- (B) 权限提升 (Privilege Escalation)
- (C) SQL 注入 (SQL Injection)
- (D) 不安全的直接对象引用 (IDOR)

解析 188。**正确答案：B. 权限提升 (Privilege Escalation)。**权限提升发生在用户将其权限增加到最初授予的权限之外时，允许他们执行本不被允许的操作。在这一场景中，Jake 通过修改配置文件提升了自己的权限。

选项 A 错误。跨站脚本 (XSS) 将恶意脚本注入用户查看的网页中。这不涉及权限的提升。

选项 C 错误。SQL 注入允许攻击者通过输入来操纵查询。

选项 D 错误。不安全的直接对象引用 (IDOR) 涉及通过输入访问对象。

问题 189。在一次例行安全评估中，某组织的安全团队发现攻击者获取了对服务器的未经授权访问。调查发现了一种能够保持隐蔽的工具。攻击者植入了哪种类型的软件？

- (A) 木马 (Trojan)
- (B) 蠕虫 (Worm)
- (C) 逻辑炸弹 (Logic Bomb)
- (D) 根工具 (Rootkit)

解析 189。**正确答案：D. 根工具 (Rootkit)。**Rootkit 是一种能够在标准检测方法面前保持隐蔽的软件，并维持授权访问。

选项 A 错误。木马伪装成合法软件但在安装后执行活动。

选项 B 错误。蠕虫是能够自我复制并传播到其他系统的软件。

选项 C 错误。逻辑炸弹在特定事件发生时执行其恶意活动。

问题 190。XYZ 公司的 IT 团队收到警报，某员工的账户在下午 2:00 从巴黎访问门户，在下午 2:30 从东京访问。该员工目前正在巴黎出差。此警报可能指示什么？

- (A) 员工从巴黎快速旅行到了东京
- (B) 公司的时区设置不当
- (C) 员工的电脑上存在可能的 VPN 配置错误
- (D) 该员工的账户可能被破解

解析 190。**正确答案：D. 该员工的账户可能被破解。**在此语境下，“不可能旅行”是指人在短时间内出现在两个遥远位置的不合理性。鉴于两次尝试的时间非常接近，在半小时内从巴黎旅行到东京是不可能的。

选项 A 错误。人在 30 分钟内不可能巴黎旅行到东京。

选项 B 错误。时区配置错误可能会导致时间戳差异，但不会导致从两个不同城市登录的表现。

选项 C 错误。即使存在 VPN 配置错误，无法解释从两个非常不同的地理位置访问的情况。
