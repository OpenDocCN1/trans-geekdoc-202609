

问题 136. 科技公司 ExamsDigest Corp 近期进行了一项安全评估，以符合行业最佳实践。该公司当前的安全态势与其预期的未来状态进行了比较，并发现了差异。以下哪项最准确地描述了 ExamsDigest Corp 采用的方法？

+   (A) 漏洞评估
(B) 渗透测试
(C) 差异分析
(D) 威胁建模

解释 136. **正确答案：C. 差异分析。** 差异分析是一种将某物（如安全措施）的当前状态与未来状态进行比较，以识别差异或“差距”。在场景中，ExamsDigest Corp 将其当前的安全态势与预期的未来状态进行了比较，这与差异分析的过程一致。

选项 A 是错误的。漏洞评估侧重于识别、量化和对系统漏洞进行排序，而不是将当前状态与预期的未来状态进行比较。

选项 B 是错误的。渗透测试是对系统进行的授权模拟网络攻击，用以评估其安全性，而不是将其当前状态与预期的未来状态进行比较。

选项 D 是错误的。威胁建模是识别系统潜在威胁并确定它们所构成的风险的过程，而不是将当前状态与预期的未来状态进行比较。

问题 137. 中型公司的财务官（CFO）Sophia 接接到一个自称来自 IT 部门的人的电话。对方要求她的登录详情以进行“关键系统更新”。Sophia 怀疑有异，挂断了电话并联系了 IT 部门，部门确认他们没有打过此类电话。Sophia 最可能经历了哪种类型的攻击？

+   (A) 语音诈骗 (Vishing)
(B) 网络钓鱼 (Phishing)
(C) SQL 注入
(D) 跨站请求伪造 (CSRF)

解释 137. 正确答案：A. 语音诈骗。语音诈骗或语音钓鱼是指诈骗者利用电话误导个人透露个人信息或登录凭据的攻击。

选项 B 是错误的。网络钓鱼通常是试图通过欺骗性的电子邮件和网站获取敏感信息，而不是通过电话。

选项 C 是错误的。SQL 注入是一种试图在数据库中执行恶意 SQL 语句的攻击类型。它与电话无关。

选项 D 是错误的。跨站请求伪造 (CSRF) 是一种攻击类型，攻击者诱骗受害者提交恶意请求。这与电话通话场景无关。

问题 138. 一家中型企业准备升级其办公室工作站。IT 部门正在考虑从一个知名度较低但价格更便宜的供应商购买设备。在确定收购之前，以下哪应该是**主要**考虑因素？

+   (A) 供应商是否提供更长的保修期

+   (B) 工作站的美学和设计

+   (C) 供应商对行业安全标准和实践的遵循情况

+   (D) IT 员工支持新设备所需的培训量

解释 138. 正确答案：C. 供应商对行业安全标准和实践的遵循情况。确保供应商遵循行业安全标准和实践对于维护安全环境至关重要。不符合安全标准的设备可能会为组织引入漏洞。

选项 A 是错误的。虽然更长的保修期可能很有吸引力，但它不应是安全考虑因素的首要问题。

选项 B 是错误的。美学和设计不是安全相关的考虑因素。

选项 D 是错误的。IT 员工的培训很重要，但它不是关于硬件本身安全态势的主要考虑因素。

问题 139. XYZ Corp 的一名员工在公司停车场发现了一个 USB 驱动器，出于好奇将其插入了自己的工作站。几乎立即，杀毒软件就检测到了试图执行的恶意软件。该员工可能遇到了哪种类型的攻击？

+   (A) 中间人攻击
(B) 恶性孪生
(C) 鱼叉式钓鱼
(D) USB 投毒攻击

解释 139. 正确答案：D. USB 投毒攻击涉及在可以发现且由无监管的人员找到的地方放置受恶意软件感染的可移动设备（如 USB 驱动器）。一旦设备被插入计算机，它就可能执行恶意软件或脚本。

选项 A 是错误的。中间人攻击涉及攻击者在双方均未察觉的情况下，秘密地拦截并可能更改他们之间的通信。它与 USB 设备无关。

选项 B 是错误的。恶性孪生指的是伪造的 Wi-Fi 访问点，它看起来是合法的，但目的是监听无线通信。它与 USB 设备无关。

选项 C 是错误的。鱼叉式钓鱼是针对特定个人或组织的针对性钓鱼攻击，通常通过电子邮件进行。

问题 140. 一家快速增长的公司面临高流量，并正在考虑一种解决方案来分配入的请求，以确保没有单一服务器被过载。该公司应该部署哪种设备？

+   (A) 入侵检测系统 (IDS)
(B) VPN 集中器
(C) 负载均衡器
(D) 代理服务器

解释 140. 正确答案：C. 负载均衡器。负载均衡器旨在将入流量分布到多个服务器上，以确保没有单一服务器被过载。

选项 A 是错误的。入侵检测系统 (IDS) 用于检测恶意活动，而不是分配流量。

选项 B 是错误的。VPN 集中器用于创建和管理 VPN 连接，而不是平衡服务器负载。

选项 D 是错误的。代理服务器可以作为请求的中间人，但其主要作用并不是专门跨多个服务器进行负载均衡。

问题 141. TechFusion Inc. 是一家老科技公司，已在市场上经营了15年以上。最近，董事会决定公司将通过进入新市场和推出尖端产品来追求进进增长，即使这些伴随着巨大的风险。你会如何对 TechFusion Inc. 的风险偏好进行分类？

+   (A) 保守型
(B) 扩张型
(C) 中立型
(D) 风险规避型

解释 141. 正确答案：B. 扩张型。扩张型风险偏好的特征是实体为了追求回报而愿意接受更高水平的风险。鉴于 TechFusion Inc. 正在寻求进入新市场并推出尖端产品，而这些产品本质上伴随着巨大的风险，因此它们的风险偏好被分类为扩张型。

选项 A 是错误的。保守型风险偏好意味着组织非常谨慎并规避承担重大风险，这与 TechFusion Inc. 的方法相反。

选项 C 是错误的。中立型风险偏好意味着组织既寻求承担风险也不规避风险，维持目前的风险状况。

选项 D 是错误的。风险规避与保守相似，即组织对承担新风险非常谨慎。它没有体现所描述的进取型增长策略。
