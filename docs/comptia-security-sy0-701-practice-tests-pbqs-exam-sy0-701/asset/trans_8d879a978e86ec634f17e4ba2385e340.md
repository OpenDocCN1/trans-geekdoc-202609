问题 365。WebSoft Inc. 是一家领先的软件公司，最近发布了一个新的 Web 应用程序。在上线之前，他们聘请了一家安全公司对该应用程序进行挑战，发现漏洞并像真实黑客一样进行利用。这种激进的测试是为了确保最大程度的安全。WebSoft Inc. 正在选择哪种渗透测试？

- (A) 白盒测试
- (B) 防御性渗透测试
- (C) 攻击性渗透测试
- (D) 灰盒测试

解释 365. 正确答案：C。攻击性渗透测试。攻击性渗透测试是一种激进的测试形式，测试人员会像真实攻击者一样积极尝试发现并利用目标系统或应用程序中的漏洞。

选项 A 是错误的。白盒测试也称为透明盒测试，涉及对被测试应用程序的内部工作机制具有完全的可见性和了解。其重点在于方法论，而不是测试的激进性质。

选项 B 是错误的。没有名为“防御性渗透测试”的特定测试方法。防御性策略通常与蓝团队活动相关，重点是防御系统，而不是激进地测试系统。

选项 D 是错误的。灰盒测试是白盒测试和黑盒测试方法的结合。测试人员对内部工作机制有一定的了解，但没有获得完整信息。这里的重点是对系统的知识水平，而不是测试的激进性质。

问题 366。在行业内发生一系列备受关注的数据泄露后，电子商务平台 OnlineRetail Corp. 希望接受外部审查，以验证其运营的安全性，并向其股东提供一份全面的报告。哪种类型的评估将对其其安全态势提供详细且正式的检查？

- (A) IT 控制和操作的外部检查
- (B) 安全协议的内部审查
- (C) 针对财务报表的外部监管审计
- (D) 来自行业同业人员的非正式反馈

解释 366. 正确答案：IT 控制和操作的外部检查。IT 控制和操作的外部检查对组织的安全态势和运营提供了深度且结构化的评估。该检查由外部专家进行，可以提供正式、全面的发现，以让股东相信公司的安全措施。

选项 B 是错误的。内部审查由组织自己的人员进行，可能缺乏外部检查的独立视角和全面范围。

选项 C 是错误的。针对财务报表的外部监管审计侧重于财务报告，而不是 IT 运营的安全性。

选项 D 是错误的。非正式反馈虽然可能有用，但不能提供外部检查所提供的结构化、全面且独立的见解。

问题 367。XYZ Ltd. 想要评估当前的安全措施是否与他们必须遵守的行业特定法规一致。该评估应由其 IT 部门完成，以便在邀请外部审计师之前进行。XYZ Ltd. 应该采用哪种方法？

- (A) 第三方漏洞扫描
- (B) 内部合规性评估
- (C) 外部证明
- (D) 供应商风险评估

解释 367. 正确答案：B。内部合规评估。内部合规评估由组织的内部团队进行，以评估其运营、流程和配置是否符合要求的合规标准或法规。这有助于在外部审计之前主动识别并纠正不合规行为。

选项 A 是错误的。第三方漏洞扫描侧重于识别漏洞，并不一定检查是否符合行业特定法规的合规性。

选项 C 是错误的。外部证明是来自第三方的验证特定标准的正式陈述。这不会由公司的内部 IT 部门完成。

选项 D 是错误的。供应商风险评估侧重于评估与第三方供应商相关的安全风险，而不评估组织对法规的内部合规性。

问题 368。SafeNet 公司希望证明其安全措施符合行业标准。他们希望通过证明其安全措施是稳健来获得竞争优势。SafeNet 应该选择哪种方式来获得这种证明？

- (A) 来自客户的反馈
- (B) 内部 IT 团队的报告
- (C) 外部独立审计
- (D) 安全咨询公司的非正式评估

解释 368. 正确答案：C。外部独立审计。外部独立审计可以为 SafeNet 对行业标准的遵守提供证明。通过让外部实体评估其实践，可以确保安全性。

选项 A 是错误的。来自客户的反馈很有价值，但不是对银行安全实践的评估。

选项 B 是错误的。内部 IT 团队的报告可能缺乏外部审计的独立视角。

选项 D 是错误的。安全咨询公司的非正式评估可能不如外部独立审计那样严谨。

问题 369。公司的安全管理员观察到有来自特定 IP 地址范围的多次未经授权的访问。管理员希望阻止这些 IP 地址访问公司网络。以下哪种防火墙配置最能满足这一需求？

- (A) 为特定范围配置隐式拒绝规则
- (B) 为特定 IP 范围设置蜜罐
- (C) 允许该范围但设置带宽限制
- (D) 将该范围加入白名单

解释 369. 正确答案：为特定范围配置隐式拒绝规则。通过为该范围配置隐式拒绝规则，防火墙将拦截来自这些地址的所有流量，防止其访问网络。

选项 B 是错误的。虽然蜜罐可以监控和分析攻击者的行为，但它不能阻止这些 IP 地址访问网络。

选项 C 是错误的。允许该范围并设置带宽限制不会阻止访问，只会限制它们发送/接收的数据量。

选项 D 是错误的。将该范围加入白名单将授予它们访问权限，这与要求的行动相反。
