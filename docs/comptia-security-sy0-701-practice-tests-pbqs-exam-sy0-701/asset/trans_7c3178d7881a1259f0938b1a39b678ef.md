

**问题 151.** 一家环保非政府组织的网站被黑客入侵，并被替换为指责他们近期反对森林砍伐运动的消息，声称他们在传播虚假信息。网站留下了一份宣传负责任林业和可持续采木实践的宣言。哪种类型的威胁者最可能是这次事件的幕后黑手？

- **A) 勒索软件组织**
- (B) 有组织犯罪集团
- (C) 黑客主义者
- (D) 高级持续性威胁 (APT)

**解析 151.** **正确答案：C. 黑客主义者。** 该攻击似乎源于对森林砍伐和可持续采木的意识形态差异。黑客主义通常通过网络行动发表政治或社会声明。将非政府组织的网站替换为宣言支持了这是一场意识形态驱动的攻击，这是黑客主义者的典型特征。

**选项 A 错误。** 勒索软件组织主要关注加密数据并要求赎金以解密。在描述的场景中，没有提到赎金或加密数据。

**选项 B 错误。** 有组织犯罪集团通常受财务利益驱动。对该政府组织网站的攻击似乎是意识形态驱动的，而非利润驱动。

**选项 D 错误。** 高级持续性威胁 (APT) 是高度组织化的、通常由国家支持的，进行长期的网络间谍活动。它们的动机通常是战略性的、政治或间谍驱动的。描述的攻击不符合 APT 操作特征。

**问题 152。** 一家跨国公司的 IT 安全分析师收到一封来自“人力资源部”的邮件，要求其紧急验证个人详情，包括家庭地址和社会安全号码。邮件带有公司标志，但有几处拼写错误。这封邮件最代表哪种类型的电子邮件威胁？

- (A) 业务电子邮件欺骗 (BEC)
- (B) 邮件轰炸
- (C) 邮件转发
- (D) 钓鱼

**解析 152.** **正确答案：D. 钓鱼。** 钓鱼邮件旨在通过冒充受信源来欺骗收件者分享个人或敏感数据。邮件质量存疑（如拼写错误），加上对个人信息的请求，是典型钓鱼攻击的特征。

选项 A 错误。虽然 BEC 是一种使用电子邮件的针对性诈骗，但它通常涉及冒充组织内部的高管或高级官员以启动未经的资金转移。描述的场景与此不符。

**选项 B 错误。** 邮件轰炸涉及向单个收件者发送大量邮件，通常是为了瘫系统或隐藏其他恶意活动。该场景并未描述此类攻击。

**选项 C 错误。** 邮件转发是指将邮件从一个地址自动重定向到另一个地址。它本身不是直接威胁，但可能被滥用。描述的场景与此不符。

**问题 153。** 在 XYZ 公司的高级网络管理员职位被解雇后，John 发现了他之前设置的一个进入公司主服务器的后门。随后，他在多月内发起了一系列分布式拒绝服务 (DDoS) 攻击。John 行为最可能的动机是什么？

- (A) 对公司数据处理的伦理担忧
- (B) 通过出售后门访问权限获取财务利益
- (C) 研究并寻找漏洞以实现个人成长的
- (D) 对公司解雇自己的报复

**解析 153.** **正确答案：D. 对公司解雇自己的报复。** 于 John 在被解雇后采取行动并发起了破坏性攻击，很明显他的动机是向前雇主报复。

**选项 A 错误。** 场景中没有迹象表明 John 对公司的数据实践有任何伦理担忧。

选项 B 错误。场景中没有提到 John 出售后门访问权限，只提到他发起了 DDoS 攻击。

选项 C 错误。John 离职后的行为似乎是恶意的，而不是对知识或研究追求。

**问题 154。** 一家金融机构最近发现，大量机密客户记录在非工作时间被访问和复制。调查发现，访问来自公司内部一个经过身份验证的用户，该用户最近在晋升中未被选中。哪种类型的威胁者最可能对这次安全事件负责？

- (A) 黑客主义者
- (B) 内部威胁
- (C) 国家级
- (D) 有组织犯罪集团

**解析 154. 正确答案：B. 内部威胁。** 证据表明这些活动是由组织内部一个经过验证的用户进行的，该用户可能有动机（未获得晋升）。内部威胁是指来自组织内部人员（如员工、承包商或业务伙伴）的风险，他们拥有有关组织安全实践、数据和计算机系统的内部信息。

选项 A 错误。黑客主义者通常受政治或社会事业驱动，并针对目标组织以促进或抗议特定问题。他们通常不会受未获得晋升等个人不满的驱动。

**选项 C 错误。** 国家级力量受政治、间谍或军事目标驱动。出于个人原因访问金融机构的客户记录不符合他们的典型动机。

**选项 D 错误。** 虽然有组织犯罪集团可能为了财务利益对客户记录感兴趣，但内部访问以及与错失晋升相关的动机强烈暗示了内部威胁。

**问题 155。** 一家全球性公司的财务部门发现了一系列从员工工作站发起的未经授权交易。调查显示，该员工一直在绕过公司政策进行投资。根据行为者的属性，如何对该威胁者进行最佳归类？

- (A) 外部攻击者恶意软件
- (B) 利用漏洞的外部攻击者
- (C) 具有直接访问权限的内部攻击者
- (D) 具有间接访问权限的内部攻击者

**解析 155.** **正确答案：C. 具有直接访问权限的内部攻击者。** 威胁源于员工内部的工作站，属于内部威胁。由于该员工使用自己的工作站和凭据进行未经授权的交易，他们具有直接访问权限，因此分类为具有直接访问权限的内部攻击者。

选项 A 错误。场景中没有提到使用恶意软件，且未经授权交易来自员工工作站，表明是内部而非外部威胁。

选项 B 错误。场景并未描述外部攻击者利用漏洞。相反，描述的是员工进行交易。

选项 D 错误。场景中的员工拥有直接访问权限，因为他们使用了自己的工作站和凭据。因此不归类为间接访问。

**问题 156。** 在进行安全评估时，Lucy 发现当她输入一个远超设计的字符串时，特定的应用程序会崩溃。这可能允许她在应用程序上下文中执行任意代码。Lucy 可能正在尝试利用哪种漏洞？

- (A) SQL 注入
- (B) 跨站脚本 (XSS)
- (C) 缓冲区溢出
- (D) 目录遍历

**解析 156.** 正确答案：C. 缓冲区溢出。缓冲区溢出漏洞发生在写入缓冲区的数据超过了该缓冲区边界时，可能会覆盖相邻的内存位置。如果被成功利用，可能会导致执行任意代码。
