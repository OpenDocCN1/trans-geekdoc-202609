

## 问题 92. 用户想要向其同事发送一封机密邮件，并确保只有预期的接收者才能阅读它。用户还希望向收件者保证该邮件确实是由他们发送的。用户应该采用哪种加密方法来实现这一目标？

- (A) 使用共享密钥的对称加密
- (B) 使用非对称加密并使用收件者的公钥对邮件加密
- (C) 使用非对称加密，使用用户的私钥对邮件加密
- (D) 使用非对称加密，首先使用用户的私钥对邮件进行签名，然后使用收件者的公钥加密

解析 92. 正确答案：D。使用非对称加密，首先使用用户的私钥对邮件进行签名，然后使用收件者的公钥加密。

选项 D 同时提供了机密性和不可否认性。使用收件者的公钥加密邮件确保只有收件者可以使用其私钥解密。使用发送者的私钥对邮件进行签名允许收件者使用发送者的公钥验证发送者。

选项 A 错误的。虽然对称加密提供了机密性，但它不提供不可否认性或发送者验证。

选项 B 错误的。使用收件者的公钥加密提供了机密性，但缺乏发送者验证。

选项 C 错误的。使用用户的私钥加密邮件可以提供发送者验证，但不会提供机密性。

## 问题 93. 用户 Amy 想要安全地向她的同事 Bob 发送一份机密文档。Amy 决定对文档进行加密以确保其机密性。Amy 应该使用以下哪项来加密文档，以确保只有 Bob 可以解密？

- (A) Amy 的私钥
- (B) Amy 的公钥
- (C) Bob 的私钥
- (D) Bob 的公钥

解析 93. 正确答案：D。Bob 的公钥。在非对称加密中，如果使用使用个人的公钥进行加密，则只有相应的私钥可以解密它。因此，为了确保只有 Bob 一个人可以解密文档，Amy 应该使用 Bob 的公钥对其进行加密。

选项 A 错误的。使用 Amy 的私钥加密将允许任何拥有 Amy 公钥的人进行解密，而且它将作为数字签名，而不是确保机密性。

选项 B 错误的。使用 Amy 的公钥没有意义，因为那样只有 Amy 的私钥可以解密。

选项 C 错误的。私钥绝不应该被共享或用于加密。它的主要用途是解密和签名。

## 问题 94. 一位安全分析师正在调查一个通过电子邮件收到的可疑图像文件。经过仔细检查，分析师怀疑该图像可能携带了隐藏数据，因为文件大小异常大。发送者可能使用了哪种技术在图像中嵌入秘密信息？

- (A) 对称加密
- (B) 数字水印
- (C) 隐写术 (Steganography)
- (D) 哈希算法

解析 94. 正确答案：C. 隐写术。隐写术是将信息隐藏在另一种形式的数据中的实践。在这种情况下，分析师怀疑图像文件由于其尺寸异常大而携带了隐藏数据，这是隐写实践的常见指标。

选项 A 错误的。对称加密用于使用单个密钥对加密和解密数据进行加密。它不会将数据隐藏在其他数据中。

选项 B 错误的。数字水印将信息嵌入数字信号中，但它通常用于维护权利或所有权，而不是以隐写术的方式隐藏数据。

选项 D 错误的。哈希处理是将输入转换为固定长度字节字符串的过程，通常用于验证数据完整性。

## 问题 95. 一家公司准备为其内部网络部署一套新的基础设施。他们有一台服务器，既存储高度机密的客户信息，也存储非敏感的营销材料。IT 部门希望确保只有机密数据被加密，而营销数据保持易于访问。对于这种场景，哪种加密级别最合适？

- (A) 文件级加密
- (B) 全盘加密
- (C) 分区加密
- (D) 传输层加密

解析 95. 正确答案：C. 分区加密。分区加密允许对存储驱动器的特定分区或卷进行加密。通过加密特定分区，可以确保只有机密数据被加密，而营销数据保持易于访问。

选项 A 错误的。文件级加密无法满足这种需求。

选项 B 错误的。全盘加密会加密整个硬盘。

选项 D 错误的。传输层加密保护传输中的数据。

## 问题 96. Sarah 位安全分析师收到了一份通过电子邮件收到的可疑报告。在仔细检查后，Sarah 发现笔记本电脑被盗了。该笔记本电脑包含敏感数据。全盘加密如何影响这种情况？

- (A) 数据仍然易于访问
- (B) 整个硬盘已被加密
- (C) 只有分区被加密
- (D) 只有目录被加密

解析 96. 正确答案：B。整个硬盘已被加密。全盘加密保护了整个硬盘。

选项 A 错误的。全盘加密保护静态数据。

选项 C 错误的。分区加密只加密特定分区。

选项 D 错误的。全盘加密加密所有用户目录。

## 问题 97. 一所大学的 IT 部门为新员工提供学生记录访问权限。为了保护学生身份，他们将真实的姓名和社会序号替换为虚拟信息，同时保持数据库格式。IT 部门正在利用哪种技术？

- (A) 数字签名
- (B) 数据掩码 (Data masking)
- (C) 隐写术
- (D) 数据去重

解析 97. 正确答案：B. 数据掩码。数据掩码通过模糊数据库中的特定数据来保护数据主体的隐私，使其在非生产环境中不可用且不可用。它常用于测试和开发。

选项 A 错误的。数字签名用于证明数据的真实性和完整性。

选项 C 错误的。隐写术涉及将信息隐藏在其他信息中。

选项 D 错误的。数据去重是消除重复数据副本以节省存储空间的过程。
