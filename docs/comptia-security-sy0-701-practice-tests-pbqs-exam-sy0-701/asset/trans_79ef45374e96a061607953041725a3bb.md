

# 解析 13. 正确答案：C. 利用敏感信息勒索金钱。以发布个人照片换取金钱的直接威胁是勒索的典型特征。攻击者正在利用敏感信息（个人照片）来勒索资金。

## 问题 14. 一家大集团的软件开发团队决定使用未经授权的云端工具来托管和管理他们的源代码。团队认为这会提高他们的效率，尽管这未获得 IT 部门的批准。几周后，检测到其项目数据遭到未经授权的访问。哪种威胁者概念最能描述这种情况？

- (A) 内部威胁
- (B) 黑客行动主义
- (C) 影子 IT (Shadow IT)
- (D) 有组织犯罪集团伙

## 解析 14. 正确答案：C. 影子 IT。影子 IT 指在组织内部未获得批准或监督的情况下使用的任何 IT 系统或解决方案。这可能会引入漏洞，因为未经授权的系统可能不符合组织 IT 部门设定的安全标准。在这种情况下，软件开发团队未经授权使用云工具正是影子 IT 的典型。

选项 A 错误。虽然软件开发团队在未授权的情况下行动，但他们的意图是提高效率，而非损害组织。因此，这种情况不符合“内部威胁”的典型定义，后者通常具有恶意意图。

选项 B 错误。黑客行动主义受政治或社会事业的驱动。场景中没有证据表明团队的决定背后有政治或社会动机。

选项 D 错误。虽然数据在未经授权的情况下被访问，但没有证据表明这是有组织犯罪集团伙所为。目前的主要问题是未经授权使用 IT 资源，这是影子 IT 的特征。

## 问题 15. 一家金融机构经历了未经授权交易的增加。他们希望实施一种控制措施，允许他们实时识别可疑交易。以下哪项是该场景的最佳检测性控制？

- (A) 为所有用户实施多因素身份验证系统
- (B) 建立安全运营中心 (SOC) 以监控网络流量
- (C) 在其网络上安装入侵检测系统 (IDS)
- (D) 将交易功能限制在少数几个受信任的 IP 地址上

## 解析 15. 正确答案：C. 在其网络上安装入侵检测系统 (IDS)。入侵检测系统 (IDS) 通过监控网络流量中的可疑活动和潜在威胁来当检测性控制。在这种背景下，它可以被配置为检测与未经授权交易相关的模式，从而允许及时干预。

选项 A 错误。实施多因素身份验证系统是一种预防性控制，通过要求两个或多个验证方法提供额外的安全层层。虽然它降低了未经授权访问的风险，但它不能检测可疑交易。

选项 B 错误。建立安全运营中心 (SOC) 是处理安全事件的广泛方法，虽然它可以包含检测性控制，但仅仅建立 SOC 并不能提供对未经授权交易的特定实时检测。

选项 D 错误。将交易功能限制在少数几个受信任的 IP 地址上是一种预防性控制，限制了潜在交易的来源。虽然它可以减少未经授权交易的数量，但它不能检测它们。

## 问题 16. MegaTech Inc. 正在制定一项策略，以确保在任何灾难后，关键应用程序能够在 4 小内恢复到工作状态。该组织还希望确保数据丢失不超过 1 小时。以下哪项策略最符合此目标？

- (A) 数据留存策略
- (B) 事件响应策略
- (C) 灾难恢复策略
- (D) 密码策略

## 解析 16. 正确答案：C. 灾难恢复策略。灾难恢复策略详细说明了灾难后恢复 IT 系统、应用程序和数据的策略和程序。恢复时间目标 (RTO) 和恢复点目标 (RPO) 是该策略的核心组成部分。

选项 A 错误。数据留存策略关于数据应存储多久以及何时应丢弃，而不是如何恢复它。

选项 B 错误。事件响应策略围绕如何处理和响应安全事件。虽然相关，但它没有提供恢复目标和时间跨。

选项 D 错误。密码策略是密码创建和管理的标准。它与恢复过程没有直接关系。

## 问题 17. 一家大型金融机构计划升级其 IT 基础设施，以实现硬件资源的硬件利用、更快的应用程序部署以及更短的服务器供应时间。在评估不同技术时，以下哪项符合这些需求？

- (A) 网络分段
- (B) 入侵检测系统
- (C) 虚拟化
- (D) 多因素身份验证

## 解析 17. 正确答案：C. 虚拟化允许多个虚拟机在单个物理主机上运行，从而最大化硬件资源的利用。它实现了服务器和应用程序的快速部署，满足了该金融机构的需求。

选项 A 错误。网络分段将网络划分为较小的子网，主要出于安全和性能考虑。虽然它是最佳实践，但它并没有解决硬件效率的问题。

选项 B 错误。入侵检测系统 (IDS) 监控并检测网络中的恶意活动。虽然它对安全至关重要，但它不适用于快速服务器供应。

选项 D 错误。多因素身份验证是用户提供多种识别方法来验证身份的安全过程。它不会影响硬件效率或应用程序部署时间。

## 问题 18. Bob 收到一封邮件，提示通过点击链接来验证身份。该链接引导他进入一个网页，要求他提供用户名、密码并回答一个个人安全问题。采用的是哪种身份验证方法？

- (A) 生物识别认证
- (B) 基于令牌的认证
- (C) 双因素身份验证
- (D) 单点登录

## 解析 18. 正确答案：C. 双因素身份验证。双因素身份验证 (2FA) 是用户提供两个不同的身份因素来验证身份的安全过程。在场景中，Bob 提供了他所知的（用户名和密码），并回答了个人安全问题，这是另一种“他所知道的内容”的形式。

选项 A 错误。生物识别认证涉及使用个人的独特物理或行为特征进行验证，例如指纹或面部识别。场景中没有提到任何生物识别数据。
