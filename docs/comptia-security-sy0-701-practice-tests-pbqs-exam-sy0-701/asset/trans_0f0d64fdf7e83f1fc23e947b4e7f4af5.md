Question 461. 金融公司 RedFlare Solutions 在数据库中存储敏感客户数据。首席信息安全官 (CISO) 坚持，如果数据在传输过程中被拦截或存储被破坏，数据应该是不可读的。哪种加密标准最能满足这一要求？

- (A) 使用共享密钥的对称加密
- (B) 使用单向函数对数据进行哈希处理
- (C) 使用透明数据加密对整个数据库加密
- (D) 将数据存储在专有格式中

Explanation 461. 正确答案：C. 使用透明数据加密对整个数据库加密。透明数据加密 (TDE) 对整个数据库加密，确保数据在静态和传输过程中都保持加密状态。它使得数据在没有相应加密密钥的情况下是不可的。

**选项 A 错误。** 对称加密可以使数据不可读，但在密钥管理和分发方面可能面临挑战，特别是密钥被泄露时。

**选项 B 错误。** 对数据进行哈希处理使其不可读，但它是一个单向函数。一旦数据被哈希处理，就无法检索或解密，不适用于加密需要访问和读取的存储数据。

**选项 D 错误。** 仅仅将数据存储在专有格式中并不意味着它是加密或不可读的。如果有人了解或对该格式进行逆向工程，数据就可以被读取。

Question 462. 软件开发公司 GlobalTech 正在与网络托管提供商 WebSolutions 建立合作伙伴关系。他们的旨在建立一套规范其持续业务交易的标准条款，包括支付条款、交付协议和保修。这是哪种协议？

- (A) 意向备忘录 (MOU)
- (B) 保密协议 (NDA)
- (C) 许可协议
- (D) 主服务协议 (MSA)

Explanation 462. 正确答案：D. 主服务协议 (MSA)。主服务协议 (MSA) 规定了双方之间的条款和条件。

**选项 A 错误。** 意向备忘录 (MOU) 建立的是意图。

**选项 B 错误。** 保密协议 (NDA) 关注机密性。

**选项 C 错误。** 许可协议涉及使用权。

Question 463. TechCorp 正在实施一种新的云解决方案。安全团队负责负责分析与该项目相关的风险。他们决定根据影响对风险进行分类：低、中、高。TechCorp 正在采用哪种类型的风险分析？

- (A) 量化
- (B) 统计
- (C) 定性
- (D) 财务

Explanation 463. 正确答案：C. 定性。定性风险分析基于描述性类别或排名（如低、中、高）评估风险，而不是使用数值。

**选项 A 错误。** 量化分析使用数值。

**选项 B 错误。** 统计风险分析使用统计方法。

**选项 D 错误。** 财务分析从潜在损失的角度评估风险。

Question 464. SecureBank 正在为其新系统选择供应商。银行非常确保所选供应商具有稳健的安全措施以及维护这些措施的记录。在供应商选择过程中，以下哪些步骤最符合银行的关注？

- (A) 检查供应商过去五年的销售增长
- (B) 对供应商的安全实践进行尽职调查
- (C) 将供应商的用户界面视觉吸引力与竞争对手对比
- (D) 评估供应商的营销策略

Explanation 464. 正确答案：B. 对供应商的安全实践进行尽职调查。对供应商的安全实践进行尽职调查确保银行对供应商的安全态和表现有全面的了解。

**选项 A 错误。** 销售增长可能表明业务成功，但不能提供安全措施方面的见解。

**选项 C 错误。** 用户界面的视觉吸引力不能提供有关安全措施的信息。

**选项 D 错误。** 评估营销策略无法直接提供安全实践的见解。

Question 465. MegaTech Inc. 正在制定一项策略，确保在任何灾难后，关键应用程序能够在 4 小时内恢复工作状态。该机构还确保数据丢失不超过 1 小时。以下哪些政策最有助于实现这一目标？

- (A) 数据留存策略
- (B) 应急响应策略
- (C) 灾难恢复策略
- (D) 密码策略

Explanation 465. 正确答案：C. 灾难恢复策略。灾难恢复策略详细说明了 IT 系统、应用程序和数据的恢复策略和程序。
