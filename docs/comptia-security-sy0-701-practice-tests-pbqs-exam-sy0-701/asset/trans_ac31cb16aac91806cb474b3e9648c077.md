

**问题 80.** 一位软件开发者想要存储用户密码，以便即使数据库被攻破，攻击者也无法获取原始密码。开发人员应该使用什么技术来实现这一目标？

- (A) 对称加密
- (B) 数字签名
- (C) 哈希处理（Hashing）
- (D) 隐术

**解释 80.** **正确答案：C. 哈希处理（Hashing）。** 哈希是一种接收输入（“消息”）并返回固定大小字节字符串的技术，通常以摘要的形式存在。理想情况下，对于每个不同的输入，其输出在合理范围内应该是唯一的。它通常用于存储密码，因为输入中即使是微小的变化也会产生截然不同的输出，而且反转该过程在计算上是非常困难的。

**选项 A 错误。** 对称加密用于加密和解密使用相同的密钥。如果攻击者获取了访问权限，他们就可以解密数据。

**选项 B 错误。** 数字签名用于验证信息的完整性和真实性。

**选项 D 错误。** 隐术涉及将信息隐藏在其他信息之中，与安全存储密码无关。

**问题 81.** 一家软件开发公司正在开发一个移动银行应用程序。他们希望确保加密过程和生物识别验证等敏感操作与操作系统隔离，以防止篡改。他们应该考虑实施哪种工具来实现这一目标？

- (A) 硬件安全模块 (HSM)
- (B) 密钥管理系统 (KMS)
- (C) 安全飞区 (Secure enclave)
- (D) 可信平台模块 (TPM)

**解释 81.** **正确答案：C. 安全飞区 (Secure enclave)。** 安全飞区是现代 CPU（尤其是移动设备）中常见的硬件隔离环境。它旨在运行加密过程和生物识别验证等特定操作，确保此类数据与操作系统隔离，防止篡改。

**选项 A 错误。** 虽然 HSM 是一个管理密钥的专用硬件设备，但它不像安全飞区那样提供 CPU 内隔离环境。

**选项 B 错误。** KMS 主要关注密钥的管理，而不是为操作创建隔离环境。

**选项 D 错误。** TPM 为设备提供硬件级安全，但它并不像安全飞区那样在 CPU 内创建隔离环境。

**问题 82.** 托管公司网站的 Web 服务器将进行操作系统升级。预计升级将持续 30 分钟。为了减少对客户的影响，什么应该是首要考虑因素？

- (A) 实施负载均衡器
- (B) 对网站进行备份
- (C) 提前一周发布维护通知
- (D) 升级服务器硬件

**解释 82.** **正确答案：A. 实施负载均衡器。** 负载均衡器可以在维护期间将流量重定向到其他服务器，确保客户仍可以访问网站，从而减少停机影响。

**选项 B 错误。** 虽然备份对于灾难恢复至关重要，但它们无法减少升级期间的直接停机。

**选项 C 错误。** 通知客户是一种良好的做法，但无法防止停机。某些客户可能仍然尝试访问网站。

**选项 D 错误。** 升级服务器硬件可能会提高性能，但无法直接减少操作系统升级引起的停机。

**问题 83.** 一位项目经理正在准备新产品的发布，本地电脑上有敏感的财务预测文档。她偶尔通过电子邮件与特定的董事成员共享这些文档。她希望保持财务文档的安全，但不想加密计算机上的所有数据。她应该利用哪种加密方法？

- (A) 全盘加密
- (B) 传输加密
- (C) 文件级加密（File-level Encryption）
- (D) 分区加密

**解释 83.** **正确答案：C. 文件级加密（File-level Encryption）。** 文件级加密允许对单独的文件或文件夹进行加密。在这种情况下，项目经理只需加密财务文档，同时保持其余数据为加密加密。

**选项 A 错误。** 全盘加密将加密整个硬盘，这超出了需求。

**选项 B 错误。** 传输加密保护传输中的数据，但不专门针对存储和共享单独的文件。

**选项 D 错误。** 分区加密加密整个分区或卷，在这种场景下没有必要。

**问题 84.** 一位安全分析师正在评估一组存储高度机密数据的笔记本电脑的安全增强。分析师希望确保存储的数据保持加密并维护启动过程的完整性。以下哪项最能满足这一要求？

- (A) 在每台笔记本电脑上安装防病毒软件
- (B) 启用基于软件的全盘加密
- (C) 实施 BIOS 密码
- (D) 利用可信平台模块 (TPM)

**解释 84.** **正确答案：D. 利用可信平台模块 (TPM)。** 可信平台模块 (TPM) 是终端设备上的专用芯片，存储特定主机系统的 RSA 加密密钥。它提供硬件安全，通过启用硬件加密等功能并确保启动过程的完整性来增强设备安全性。

**选项 A 错误。** 虽然防病毒软件对于防止恶意软件至关重要，但它不直接处理硬件加密或启动过程完整性。

**选项 B 错误。** 基于软件的全盘加密可以确保数据的机密性，但它不提供硬件级保护或启动过程完整性。

**选项 C 错误。** BIOS 密码提供层安全，但它不提供存储数据的加密或启动过程完整性。

**问题 85.** 一家大型电子商务公司正在部署一个新的在线支付系统。首席信息安全官 (CISO) 加密密钥的安全，并确保它们免受潜在的盗取或破坏。CISO 应该实施哪种工具为这些密钥提供最高级别的安全？

- (A) 密码库
- (B) 基于软件的密钥存储
- (C) 硬件安全模块 (HSM)
- (D) 云端加密服务

**解释 85.** **正确答案：C. 硬件安全模块 (HSM)。** 硬件安全模块 (HSM) 是专门设计用于管理、保护和安全存储加密密钥的专用设备。它具有防篡性并提供高水平的安全，适用于对加密密钥保护至关的环境，例如电子商务支付系统。

**选项 A 错误。** 密码库主要用于存储和管理密码，而不是支付系统中的加密密钥。

**选项 B 错误。** 基于软件的密钥存储解决方案提供的物理安全性不如 HSM 提供的安全性。

**选项 D 错误。** 虽然云端加密服务可以提供加密功能，但它们可能无法提供本地 HSM 那样的物理保护和控制。
