
选项 B 错误。数据去重是通过删除重复数据来减少存储需求；它并不提供机密性。

选项 D 错误。虽然 WAF 提供了针对网络威胁的保护，但它无法在发生未经授权访问时确保数据的机密性。

第 352 题。John 是一个严格遵守《数据保护条例》（GDPR）国家的公民，他使用一个全球购物平台已经一年。他决定停止使用该平台并请求删除所有个人数据。根据“被遗忘权”原则，该平台的主要义务是什么？

- A) 保留数据，但确保 John 的数据永远用于营销目的
- B) 除非有法律理由，否则删除所有个人数据
- C) 对 John 的数据进行匿名处理并通知他已完成
- D) 将 John 的数据移动到安全的服务器，使其无法被访问

解析 352. 正确答案：B。除非有法律理由，否则删除所有个人数据。GDPR 下的“被遗忘权”允许公民要求组织删除其个人数据，除非组织有正当理由保留这些数据。

选项 A 错误。仅仅避免将 John 的数据用于营销目的并不满足“被遗忘权”。

选项 C 错误。匿名化并不等同于删除数据。

选项 D 错误。仅仅将数据移动到安全的服务器并不符合“被遗忘权”。数据需要被删除。

第 353 题。TechFirm 是一家领先的科技集团，最近进行了一次安全演习。目标是让内部安全团队防御来自外部团队的一系列模拟攻击。外部团队的目标是检测、响应和缓解这些威胁。TechFirm 正在采用哪种渗透测试？

- A) 攻击性渗透测试
- B) 被动渗透测试
- C) 防御性渗透测试
- D) 黑盒测试

解析 353. 正确答案：C。防御性渗透测试。防御性渗透测试旨在测试组织防御其系统和网络受攻击的能力。它通常涉及一个内部安全团队（通常称为蓝队），防御模拟攻击。

选项 A 错误。攻击性渗透测试涉及积极尝试利用漏洞，而不是防御漏洞。

选项 B 错误。被动渗透测试是指在不与目标系统积极交互的情况下收集信息。

选项 D 错误。黑盒测试是一种测试人员对系统内部运行机制一无所知的方法。它并没有描述一种防御姿态。

第 354 题。在对应用程序进行安全评估期间，Ryan 发现他能够在某个字段中输入比预期更大的数据。这样做之后，他注意到应用程序无响应并最终崩溃了。Ryan 可能发现了哪种类型的漏洞？

- A) 输入验证
- B) 跨站脚本 (XSS)
- C) 缓冲区溢出
- D) 不安全的对象引用 (IDOR)

解析 354. 正确答案：C。缓冲区溢出。缓冲区溢出漏洞发生在应用程序允许输入的数据超过其分配的缓冲区空间所能安全处理的范围，导致相邻内存被覆盖。这可能导致应用程序崩溃，或者可能导致攻击者执行任意代码。

选项 A 错误。虽然输入验证可以导致各种漏洞，但这是一个宽泛的类别。在给定的场景中，输入比预期更大的数据的直接后果是应用程序崩溃，这直接指向缓冲区溢出。

选项 B 错误。跨站脚本 (XSS) 漏洞允许攻击者向其他用户查看的网页中注入恶意脚本。它不会因为输入过大而导致应用程序崩溃。

选项 D 错误。不安全的对象引用 (IDOR) 漏洞发生在应用程序根据用户输入直接访问对象时。它不会因为输入过多而导致崩溃。

第 355 题。一家金融机构希望确保，如果网络攻击者未经授权访问了其网络的一个部分，攻击者无法轻易横向移动到网络中更敏感的部分。哪种方法可以帮助实现目标？

- A) 在每个段中部署蜜罐
- B) 实现网络分段
- C) 对所有数据流量进行加密
- D) 为所有用户启用双重身份验证

解析 355. 正确答案：B。实现网络分段。网络分段将网络划分为多个段或子网。每个段独立运行，并可以有自己的安全和访问控制。这意味着如果攻击者攻破了一个分段，他们并不一定能访问其他分段。

选项 A 错误。蜜罐是用于吸引潜在攻击者的诱饵系统，但一旦攻击者进入网络，它无法防止网络内的横向移动。

选项 C 错误。虽然加密数据流量确保了机密性，但它不能防止网络内的横向移动。

选项 D 错误。双重身份验证加强了访问控制，但如果攻击者获得了访问权限，它本身无法停止网络内的横向移动。

第 356 题。执行助理 Emily 接到了一个自称 IT 部门新员工的电话。通话者说他们正在进行例行检查，需要 Emily 确认用户名和密码进行系统验证。Emily 应该如何应对？

- A) 礼貌拒绝并向 IT 部门报告此电话
- B) 为对方提供用户名但不提供密码
- C) 要求对方通过电子邮件发送请求，以便留下书面记录
- D) 什么不说直接挂断

解析 356. 正确答案：A。礼貌拒绝并向 IT 部门报告此电话。这是一个典型的语音钓骗（vishing）尝试，属于社会工程学的一种。在这种情况下，最佳实践是永远不要通过电话提供敏感信息，特别是当电话是非主动来同时。向 IT 部门报告此类尝试可以帮助公司意识到风险并可能防止进一步的尝试。

选项 B 错误。即使 Emily 只提供用户名，它仍可能与其他攻击结合被恶意使用。

选项 C 错误。书面记录可能有用，但至关重要的是不要接受或验证无论是通过电子邮件还是电话收到的非主动请求。

选项 D 错误。虽然挂断可以停止即时威胁，但为了组织的意识和保护，报告此类事件至关重要。

第 357 题。金融机构 SafeNet 决定进行全面的安全评估。他们召集了内部安全团队和外部伦理黑客小组。他们的目标是让这些团队协作评估漏洞、执行实时攻击模拟并评估防御机制。SafeNet 正在利用什么形式的渗透测试？

- A) 黑盒测试
- B) 集成渗透测试
- C) 防御性渗透测试
- D) 红队评估

解析 357. 正确答案：B。集成渗透测试。集成渗透测试（通常与紫队对抗相关）涉及攻击团队和防御团队的共同努力，以对组织的安全态提供整体评估。

选项 A 错误。黑盒测试是一种测试人员对系统架构或底层代码没有先知识的方法。它没有强调攻击和防御团队之间的协作性质。

选项 C 错误。防御性渗透测试侧重于评估组织防御潜在攻击的能力，并不一定意味着与攻击团队协作。

选项 D 错误。红队评估涉及模拟真实世界的网络攻击以测试组织的安全态，但它本质上并不意味着与防御团队共同努力。
