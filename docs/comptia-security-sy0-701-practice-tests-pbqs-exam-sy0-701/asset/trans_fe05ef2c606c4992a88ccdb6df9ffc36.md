
系统可能允许攻击者发布此类链接？
(A) 会话劫持 (Session Hijacking)
(B) 跨站脚本 (XSS)
(C) 密码破解 (Password Spraying)
(D) 凭据填充 (Credential Stuffing)

## 解析 223. **正确答案：B. 跨站脚本 (XSS)。** XSS漏洞允许攻击者向网页内容中注入恶意脚本。如果平台的审核系统没有对输入进行适当清理，可能会允许攻击者嵌入指向钓鱼网站的恶意链接。

跨站脚本攻击利用Web应用程序中的漏洞插入恶意脚本。在这种情况下，在产品评论中发布恶意链接的能力是存在XSS漏洞的表明。当毫无防的用户点击这些链接时，他们会被重定向到旨在窃取凭据的钓鱼网站。

**选项 A 错误。** 会话劫持涉及接活跃用户的会话。它不涉及在网站内容中发布恶意链接。

**选项 C 错误。** 密码破解涉及使用几个常用密码对许多用户账户进行身份验证尝试。它不涉及在网站内容中嵌入恶意链接。

**选项 D 错误。** 凭据填充攻击涉及使用大量有效用户名和密码自动尝试获取访问。它与在网页内容中插入恶意链接无关。

## 问题 224. 一个组织决定专注于保护其存储客户详情和交易记录的数据库服务器的安全性。这些数据没有被积极访问或处理。对于这类数据，哪种类型的安全措施最为合适？

- (A) 针对电子邮件的 DLP 数据泄露防护 (DLP)
- (B) Web 应用防火墙 (WAF)
- (C) 全盘加密 (FDE)
- (D) 针对网络流量的入侵检测系统 (IDS)

## 解析 224. **正确答案：C. 全盘加密 (FDE)。** 静态数据是指未在网络中活动移动的数据，例如存储在硬盘上的数据。全盘加密 (FDE) 是一种专门设计用于保护静态数据的安全措施，通过加密整个硬盘来实现。

**选项 A 错误。** 针对电子邮件的 DLP 主要关注于防止通过电子邮件进行未经授权的数据传输，更适用于传输中的数据，而非静态数据。

**选项 B 错误。** WAF 保护 Web应用程序免受各种在线威胁，并非专门为保护静态数据而定制。

**选项 D 错误。** 针对网络流量的 IDS 主要关注于监控和检测网络流量中的恶意活动，这属于传输中的数据而非静态数据。

## 问题 225. XYZ 公司最近开发了一种新的制造工艺，可将生产成本降低 50%。该工艺尚未获得专利，被视为商业秘密。公司希望确保员工不会向竞争对手泄露该工艺。以下哪种是实现这一目标的最有效的策略？

- (A) 为保持工艺机密的员工提供奖金
- (B) 对员工的通信进行随机检查
- (C) 为所有员工实施强制性的非披露协议 (NDA)
- (D) 举办季度研讨会以教育员工商业秘密的价值

## 解析 225. **正确答案：C. 为所有员工实施强制性的非披露协议 (NDA)。** NDA 是一份具有法律约束力的合同，禁止员工泄露机密（如商业秘密）。如果员工违反了 NDA，公司有法律依据寻求赔偿或其他补救措施。

**选项 A 错误。** 虽然奖金可能为员工提供激励，但它没有为保护商业秘密提供法律框架。

**选项 B 错误。** 随机检查可以震慑某些员工，但可能在范围内并不有效，并且可能导致组织内部信任问题。

**选项 D 错误。** 虽然教育是关重要的并且可以培养责任感，但它无法像 NDA 那样提供保护商业秘密的法律手段。

## 问题 226. 在分析公司 Web 的漏洞时，安全团队参考特定的 CVE 来了解漏洞细节。他们进一步评估了其 CVSS 评分以决定修复的紧急性。以下哪项最准确地描述了此情况下 CVE 和 CVSS 的目的？

- (A) CVE 提供严重性评分，而 CVSS 为漏洞提供唯一标识符
- (B) CVE 和 CVSS 都提供评分机制对漏洞进行排名
- (C) CVE 提供唯一标识符，而 CVSS 提供标准的严重性评分
- (D) CVE 和 CVSS 是所有软件应用程序的强制性要求

## 解析 226. **正确答案：C. CVE 提供唯一标识符，而 CVSS 提供标准的严重性评分。** CVE（常见漏洞和披露）为漏洞提供了标准的标识符，确保了清晰的通信和引用。CVSS（通用漏洞评分系统）提供了一种评估漏洞严重性的标准方法，使组织能够确定修复优先级。

**选项 A 错误。** 恰恰相反。CVE 提供唯一标识符，而 CVSS 提供严重性评分。

**选项 B 错误。** 只有 CVSS 提供对漏洞进行排名的评分机制。CVE 提供唯一标识符。

**选项 D 错误。** 虽然使用 CVE 和 CVSS 可以被最佳实践，但它们并不是所有软件应用程序的强制性要求。

## 问题 227. 在安全评估期间，安全顾问 Maria 发现客户面向外部的 Web 服务器上使用了自签名证书。与此发现相关的主要的安全关注点是什么？

- (A) Web 服务器可能受到分布式拒绝服务 (DDoS) 攻击的影响
- (B) 证书可能会过期
- (C) 用户无法验证网站的真实性
- (D) Web 服务器可能不支持现代算法

## 解析 227. **正确答案：C. 用户无法验证网站的真实性。** 自签名证书不是由受认可的机构签署的。因此，当用户使用自签名证书连接到网站时，通常会收到证书不可信任的警告。

**选项 A 错误。** 虽然 DDoS 攻击是面向外部服务器的关注点，但它们与自签名证书的使用没有直接关系。

**选项 B 错误。** 任何证书（无论是否自签名）都可以过期。但过期不是使用自签名证书的主要关注点。

**选项 D 错误。** 使用现代算法与证书是否为自签名无关。

## 问题 228. 安全管理员 Julia 担心机密文件被未经授权访问。她决定在项目文件夹中放置一个诱人但实际上被监控的文档。这种策略旨在检测有人在访问文件。这种文档通常被称为？

- (A) 盐文件 (Salt file)
- (B) 蜜罐文件 (Honeyfile)
- (C) 日志文件 (Log file)
- (D) 备份文件 (Backup file)

## 解析 228. **正确答案：B. 蜜罐文件。** 蜜罐文件是故意放置的作为诱饵的文件。如果被访问，它可以提供有人正在未经授权访问文件的警告，可能是内部威胁的表明。

**选项 A 错误。** 盐是作为数据或密码哈希函数的额外输入的随机数据。它不是诱饵文件。

**选项 C 错误。** 日志文件记录操作系统或其他软件中的事件以协助故障排除和活动监控，但它不是一种欺骗性措施。

**选项 D 错误。** 备份文件是文件或数据库的副本，可用于数据恢复。它不是检测未经授权访问的诱饵。
