Question 228. Julia, a security administrator, is concerned about potential unauthorized access to confidential project files stored on a company server. What is this document commonly known as?

+   (B) Honeyfile

+   (C) Log file

Explanation 228. Correct Answer: B. Honeyfile. A honeyfile is a monitored file placed intentionally to act as a decoy. If accessed, it can provide an alert that someone might be accessing files without proper authorization, or it might be an indication of a potential insider threat.
