Explanation 156. Correct Answer: C. Buffer Overflow. Buffer overflow vulnerabilities occur when data written to a buffer exceeds that buffer’s boundaries, potentially overwriting adjacent memory locations. If exploited successfully, it can lead to arbitrary code execution.
