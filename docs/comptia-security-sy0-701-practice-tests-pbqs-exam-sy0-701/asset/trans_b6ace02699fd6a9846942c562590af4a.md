

来自受信实体的证书。以下哪项负责颁发此类证书？

- (A) 密钥发行中心 (Key distribution center)
- (B) 证书权威 (CA)
- (C) 令牌化系统 (Tokenization system)
- (D) 安全事件管理系统 (Security incident event manager)

**解释 86. 正确答案：B. 证书权威 (CA)。** 证书权威（CA）是负责发布、验证和吊销数字证书的可信实体。这些证书用于身份验证互联网上的实体（如网站），确保通信的安全性和经过验证，从而降低中间人攻击的风险。

**选项 A 错误。** 密钥发行中心（KDC）是 Kerberos 验证协议的一部分，负责分发会话令牌和临时会话密钥，而不是颁发数字证书。

**选项 C 错误。** 令牌化系统将敏感数据替换为称为令牌（tokens）的非敏感替代品。它们不颁发数字证书。

选项 D 错误。** 安全事件管理系统（SIEM）聚合并分析来自各种源的日志数据，提供安全告警的实时分析，但不颁发证书。

**问题 87。** 一家金融机构希望采用一种加密算法进行交易，与旧标准相比，由于其密钥较长而被认为非常安全。哪种加密算法最符合这一描述？

- (A) DES
- (B) Blowfish
- (C) RSA
- (D) AES-256

**解释 87. 正确答案：D. AES-256。** AES-256 是高级加密标准（AES）家族的一部分，使用 256 位密钥长度。这种扩展的长度提供了更高程度的安全性，在正确使用的情况下，被认为能够抵抗所有已实用攻击。

**选项 A 错误。** DES（数据加密标准）的密钥仅为 56 位，由于密钥较短，对于设备齐全的攻击者来说，被认为是不安全的。

**选项 B 错误。** 虽然 Blowfish 是一种对称加密算法，但它较旧，且不像 AES 那样被广泛推荐用于安全交易。

**选项 C 错误。** RSA 是一种非对称加密算法，通常不直接用于加密大量交易数据。

**问题 88。** Alice 收到 Bob 发的一封邮件，附件中有一个文档。她想验证发送者的真实性以及附件文档的完整性。Bob 在发送邮件之前使用了以下哪种操作？

- (A) 用他的私钥加密文档
- (B) 对文档进行哈希处理 (Hash)
- (C) 用 Alice 的公钥加密文档
- (D) 用他的私钥对文档签名

**解释 88. 正确答案：D. 用他的私钥对文档签名。** 数字签名通过获取消息（或文档）的哈希值并使用发送者的私钥加密该哈希来创建。当 Alice 收到邮件时，她可以使用 Bob 的公钥解密签名以原始哈希值，然后与她计算的文档哈希值进行比较。如果它们匹配，则确认了发送者的身份（真实性）以及文档未被篡改（完整性）。

选项 A 错误。用其私钥加密整个文档对于验证真实性和完整性来说是不切行的。相反，是对文档的哈希进行加密以创建签名。

选项 B 错误。仅对文档进行哈希处理可以提供检查文档完整性的方法，但不能验证发送者的真实性。

选项 C 错误。用 Alice 的公钥加密文档会使其对 Alice 保持保密，但这无助于验证真实性或完整性。

**问题 89。** 在一个关键的财务季度，GlobalFin Corp 因为系统维护在业务高峰期间经历了意外停机，对其运营造成了重大影响。为了防止未来发生此类情况，GlobalFin Corp 在其维护活动方面应该实施什么措施？

- (A) 随机进行维护活动以避免可预测性
- (B) 在业务高峰时段实施维护活动
- (C) 建立指定的维护窗口
- (D) 减少维护活动的频率

**解释 89. 正确答案：建立指定的维护窗口。** 维护窗口是专为系统维护指定的特定时间段，可确保由于更新、补丁或其他维护活动导致的中断不会发生在关键业务时段。通过设置这些窗口（通常在非高峰时段），企业可以减少运营中断。

**选项 A 错误。** 随机进行维护活动会导致不可预料的停机，这会对业务运营产生干扰并损害利益相关者之间的信任。

**选项 B 错误。** 在业务高峰时段实施维护活动恰恰是导致场景中中断的原因。这种方法可能会导致更多的运营问题。

**选项 D 错误。** 减少维护活动的频率可能会降低干扰，但可能导致安全漏洞、软件过时或其他运营问题。

**问题 90。** 一家金融机构希望在其总部和分行之间安全地传输交易数据。数据在传输过程中应进行加密以防止拦截和未经授权的访问。哪种加密方案最适用于传输数据？

- (A) 数据库加密
- (B) 全磁盘加密
- (C) 传输层加密
- (D) 文件级加密

**解释 90. 正确答案：C. 传输层加密。** 传输层加密专门设计用于保护在网络上传输的数据。它确保数据在传输过程中保持机密且不被篡改。对于该金融机构，这种方法在办公室之间之间最为有效。

选项 A 错误。数据库加密用于加密存储在数据库中的数据，而不是传输中的数据。

选项 B 错误。全磁盘加密保护设备的整个存储内容，不适用于网络中传输的数据。

选项 D 错误。文件级加密加密单个文件，但无法确保数据在网络传输中的机密性。

**问题 91。** 在最近的软件更新后，公司的内网门户对部分员工不可访问。IT 团队怀疑这可能是由于网络过滤规则导致的。IT 团队应该审查什么内容来证实他们的怀疑？

- (A) 内容过滤策略
- (B) 恶意软件检测日志
- (C) 允许列表/拒绝列表配置
- (D) 网络带宽利用率图

**解释 91. 正确答案：C. 允许列表/拒绝列表配置。** 网络访问问题（特别是在软件或配置更改之后）通常由于允许列表或拒绝列表配置不当。审查这些配置可以帮助确定特定的 IP 地址或域名是否被错误阻止或未允许，从而导致访问问题。
