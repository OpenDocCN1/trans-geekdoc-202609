**Question 227.** During a security assessment, Maria, a security consultant, identifies a self-signed certificate being used on a client’s public-facing web server. What is the PRIMARY security concern related to this finding?

+   (A) The web server might be vulnerable to Distributed Denial of Service (DDoS) attacks

+   (B) The certificate could be expired

+   (C) Users cannot validate the authenticity of the website easily

+   (D) The web server might not support modern encryption algorithms

**Explanation 227.** **Correct Answer: C. Users cannot validate the authenticity of the website easily.** Self-signed certificates are not signed by a recognized Certificate Authority. As a result, when users connect to a website using a self-signed certificate, they typically receive a warning that the certificate is not trusted. This poses a risk as users cannot easily validate the authenticity of the website, making them more susceptible to man-in-the-middle attacks.
