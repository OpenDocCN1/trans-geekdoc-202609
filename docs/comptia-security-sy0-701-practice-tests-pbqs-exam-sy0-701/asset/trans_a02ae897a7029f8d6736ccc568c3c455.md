
问题 500。某位安全分析师正在审查网络日志，注意到一个位于用户和目标网站之间的攻击者正在拦截并可能修改用户的通信内容，然后将其传递到预定的目的地。这种恶意活动是透明运行的，用户和目标网站都无法察觉。描述的是哪种网络攻击？

- (A) 重放攻击 (Replay Attack)
- (B) 呆层鱼攻击 (Smurf Attack)
- (C) 路径攻击 (On-path Attack)
- (D) 欺骗攻击 (Spoofing Attack)

解释 500. **正确答案：C. 路径攻击 (On-path Attack)。** 路径攻击也称为中间人攻击 (MitM)，涉及攻击者拦截双方之间的通信，可能对通信进行修改，然后将其转发给预期接收者。源和目的地都不知道攻击者的存在。

选项 A 错误。重放攻击涉及捕获合法数据包并在稍后重新传输它们以产生未经授权的后果。它不涉及实时的主动拦截和修改。

选项 B 错误。呆层鱼攻击是一种拒绝服务攻击，使用 ICMP 回显（ping）流量淹没目标系统。它与拦截和修改用户通信无关。

选项 D 错误。欺骗攻击涉及假装成其他事物或人。虽然路径攻击可能包含某些欺骗元素，但场景中描述的特定行为更符合路径攻击。
