

# 解析 65. 正确答案：D. 空隙网络。

物理隔离网络是指在物理上与不安全网络隔离的网络。物理隔离网络上的计算机无法与非隔离的计算机通信，且未连接到外部网络或互联网，从而确保了最高级别的数据安全。

选项 A 错误。DMZ（脱毒区）是私有网络与外部网络（通常是互联网）之间的缓冲区。它的设计目的是提供额外的安全层，但不能保证完全隔离。

选项 B 错误。VPN（虚拟专用网络）用于在不安全的网络（如互联网）上建立安全连接。它们对传输的数据进行加密，但在物理上并不隔离网络。

选项 C 错误。VLAN（虚拟局网）是物理网络内部逻辑分段的网络。它允许在二层网络中分离广播域，但不能提供与其他网络的完全物理隔离。

问题 66. 一家小型企业发现其网站遭到未经授权的访问。攻击者使用默认登录凭据获取了访问。这种攻击表明威胁者具有什么样的复杂程度和能力？

- (A) 具有基础技能的脚本小子 (Script kiddie)
- (B) 利用高级技术的专家级攻击者
- (C) 具有战略目标的国家级攻击者
- (D) 针对高价值资产的有组织犯罪集团

解析 66. 正确答案：A. 具有基础技能的脚本小子。使用默认登录凭据进行未经授权的访问通常表明其复杂程度较低，因为这种方法非常基础，且几乎不需要任何技术技能。此类攻击者通常被称为“脚本小子”，他们通常使用现成的工具或脚本来利用已知漏洞，而并不完全理解其原理。

选项 B 错误。专家级攻击者可能会利用更高级的技术，而不会仅仅依赖默认凭据。

选项 C 错误。虽然国家级攻击者具备发起复杂攻击的能力，但将默认登录凭据作为未经授权访问的主要方法，与此类攻击者通常采用的复杂方法不符。

选项 D 错误。有组织犯罪集团，特别是针对高价值资产的集团，会采用比仅仅使用默认登录凭据更复杂的技术。

问题 67. 为了威慑潜在的网络罪分子不要攻击其在线商店，一家电子商务公司正在考虑各种安全措施。以下哪项作为**威慑控制 (deterrent control)** 的效果最有效？

- (A) 在网站上显示第三方安全认证密封
- (B) 使用 Web 应用防火墙 (WAF)
- (C) 每月进行一次漏洞评估
- (D) 将客户数据存储在加密数据库中

解析 67. 正确答案：A. 在网站上显示第三方安全认证密封。在网站上显示第三方安全认证密封起到威慑控制的作用。它向潜在攻击者传递了一个信息，即该网站的安全措施获得了认可，这可以阻碍他们尝试攻击。

选项 B 错误。使用 Web 应用防火墙 (WAF) 是一种**预防控制 (preventive control)**。它负责过滤、监控和拦截恶意 Web 流量。虽然它有助于防御网络威胁，但它并不是对攻击者可见的威慑手段。

选项 C 错误。每月进行漏洞评估 是一种**检测控制 (detective control)**。它通过识别漏洞来增强安全态势，但对潜在攻击者不起威慑作用。

选项 D 错误。将客户数据存储在加密数据库中是一种**预防控制**，可以确保未经授权的人员无法访问或理解存储的数据。它保护了数据，但不能威慑潜在的网络罪分子。

问题 68. 一位系统管理员正在为一个新的 Web 应用程序设置身份验证系统。以下哪些安全控制属于**技术类**，并能确保用户在获得访问权限之前证明自己的身份？

- (A) 实施安全意识培训计划
- (B) 对新员工进行背景检查
- (C) 使用多因素身份验证 (MFA)
- (D) 建立洁桌面政策

解析 68. 正确答案：C. 使用多因素身份验证。多因素身份验证是一种技术控制，要求用户在获得访问权限之前提供两个或更多证据（因素）。它提供了额外的安全层，以确保用户确实是他们所称的身份。

选项 A 错误。实施安全意识培训计划是一种**管理控制 (administrative control)**，因为它涉及教育员工安全最佳实践，而不是使用技术措施来强制执行。

选项 B 错误。进行背景检查是种**管理控制**，因为它涉及在雇佣潜在员工之前对他们进行审查。这一过程并不会直接执行技术措施。

选项 D 错误。建立洁桌面政策是一种**管理控制**。

问题 69. 领先的软件开发公司 CyberFirm 最近由于新功能和补丁更新了操作系统。鉴于他们已经建立了安全基准 (secure baseline)，CyberFirm **下一步**应该做什么以确保持续安全？

- (A) 对所有服务器进行完全重启
- (B) 在不进行任何修改的情况下重新部署相同的基准
- (C) 更新安全基准包含新配置并进行部署
- (D) 为服务器实施新的防火墙规则

解析 69. 正确答案：C. 更新安全基准包含新配置并进行部署。当系统发生重大更新或更改时，并更新安全基准至关重要，以确保其相关性和有效性。更新基准后，应当重新部署。

选项 A 错误。完全重启系统无法解决更新后安全基准的维护问题。

选项 B 错误。在不进行调整的情况下重新部署相同的基准可能会忽略特定的配置。

选项 D 错误。虽然防火墙规则对于安全至关重要，但它们并不涉及安全基准的维护。

问题 70. 一位安全分析师注意到其国家基础设施系统遭受了一系列复杂的攻击。这些攻击高度协调、资金充足，并且似乎具有特定的地缘政治目标。哪种类型的威胁者**最可能**负责这些攻击？

- (A) 有组织犯罪集团
- (B) 脚本小子
- (C) 内部威胁
- (D) 国家级

解析 70. 正确答案：D. 国家级。针对国家关键基础设施的高度协调、资金充足且具有明确地缘政治目标的攻击，与国家级攻击者的特征和动机最为匹配。他们通常拥有巨大的资源和特定的政治或战略动机，攻击基础设施以产生重大影响或获得战略优势。

选项 A 错误。虽然有组织犯罪集团可能资金充足并能够发起攻击，但他们通常是由利益驱动的，而非地缘政治目标。

选项 B 错误。脚本小子是使用预写脚本或工具利用漏洞的业余黑客。他们通常缺乏发起协调攻击所需的复杂性和资源。

选项 C 错误。内部威胁来自组织内部人员，如员工或承包商。虽然他们可能造成危害，但描述的情况更像是拥有大量资源和地缘政治动机的外部国家级攻击者。
