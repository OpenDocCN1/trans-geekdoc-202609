## 问题 398. 一家公司想要托管一个面向的网站，但要确保即使网站被攻破，攻击者也无法访问敏感的内部数据。实现此点的最佳配置是哪个？

(A) 将 Web 服务器放置在内部网络上并严格监控流量

(B) 将 Web 服务器放置在 DMZ（军事化区域），在其前面放置防火墙，并在 DMZ 和内部网络之间放置另一台防火墙

(C) 直接将 Web 服务器连接到互联网而不使用防火墙，并将敏感数据从服务器移出

(D) 将 Web 服务器放置在 DMZ 中并直接连接到内部网络而不使用防火墙

## 解释 398. 正确答案：B。将 Web 服务器放置在 DMZ 中，在其前面放置防火墙，并在 DMZ 和内部网络之间放置另一台防火墙。通过将 Web 服务器放置在 DMZ 中并使用两个防火墙（一个面向互联网，另一个面向内部网络），公司可以确保即使面向的 Web 服务器被攻破，攻击者仍需绕过另一个防火墙才能到达内部网络。

**选项 A 错误。** 将面向的 Web 服务器放置在内部网络上，即使有监控，也会让网络暴露于不必要的风险之中。

**选项 C 错误。** 在没有任何防火墙的情况下将服务器直接连接到互联网是非常高风险的，即使移动了敏感数据。

**选项 D 错误。** 如果 DMZ 和内部网络之间没有防火墙，DMZ 中被攻破的服务器将更容易影响或访问内部网络。

## 问题 399. BetaTech 的一名安全分析师正在审查部署在整个组织中的监控工具。她希望确保每个工具都能检测到对系统文件和配置的未经授权更改。以下哪些工具最适合此目的？

(A) 网络协议分析器
(B) 文件完整性监控 (FIM) 系统
(C) 带宽监控工具
(D) 被动漏洞扫描器

## 解释 399. 正确答案：B。文件完整性监控 (FIM) 系统。文件完整性监控系统用于在系统文件和配置发生未经授权的更改时检测并告警，确保这些关键组件的完整性。

**选项 A 错误。** 虽然网络协议分析器可以捕获并分析网络流量，但它们并非专门用于监控系统文件和配置的更改。

**选项 C 错误。** 带宽监控工具主要跟踪网络和带宽消耗，而不是对系统文件的修改。

**选项 D 错误。** 被动漏洞扫描器通过监控网络流量来检测漏洞，但不会主动跟踪系统文件的更改。

## 问题 400. 一家公司在过去一个月中注意到恶意软件感染有所增加。调查后确定，感染是由员工访问新注册但具有恶意意图的网站引起的。以下缓解此威胁的最佳方法是哪个？

(A) 实施阻止规则拒绝对所有网站的访问

(B) 使用包含域名信誉检查并阻止近期注册域名的 Web 过滤器

(C) 设置 Web 过滤器阻止所有未被归类为“业务”的网站

(D) 为所有基于互联网的应用程序强制多因素身份验证

## 解释 400. 正确答案：B。使用包含域名信誉检查并阻止近期注册域名的 Web 过滤器。

**选项 A 错误。** 阻止对所有网站的访问是一种极端的措施。

**选项 C 错误。** 仅仅阻止所有未归类为“业务”的网站会阻碍业务运营。

**选项 D 错误。** 虽然强制多因素身份验证可以增强安全性，但无法解决员工访问恶意网站的威胁。

## 问题 401. AlphaTech 的安全团队正在评估新部署的云基础设施的漏洞。在分析潜在风险时，他们考虑了诸如数据中心的物理位置、法律法规以及自然灾害频率等因素。这些因素在漏洞管理中被称为？

(A) 资产评估因素
(B) 风险响应变量
(C) 威胁情报变量
(D) 环境变量

## 解释 401. 正确答案：D。环境变量。漏洞管理中的环境变量是指影响或影响组织安全态的外部因素。这些包括物理位置、法律法规和自然灾害的频率。

**选项 A 错误。** 资产评估因素主要涉及确定资产对组织的价值，通常不考虑自然灾害频率等外部因素。

**选项 B 错误。** 风险响应变量涉及对已识别风险的策略和行动，而非外部因素。

**选项 C 错误。** 威胁情报变量围绕潜在威胁或威胁者的信息展开。它们通常不包含方案所述的物理环境因素。

## 问题 402. 安全分析师 Caroline 收到警报，关键服务器上检测到一个未知文件。她怀疑这可能是恶意软件。关于此潜在威胁，Caroline 应采取的最佳立即行动是什么？

(A) 立即删除文件以防止进一步损害

(B) 隔离文件以防止其执行或扩散

(C) 制作文件的副本进行进一步分析

(D) 通知所有员工该可疑文件

## 解释 402. 正确答案：B。隔离文件以防止其执行或扩散。隔离可疑文件可以将其分离，防止潜在的执行或扩散，同时可以在不立即删除的情况下进行调查。

**选项 A 错误。** 虽然删除文件看起来很主动，但它会消除进一步分析的机会并影响取证调查。

**选项 C 错误。** 制作副本对于分析很重要，但首要任务应该是防止可疑文件的潜在执行或扩散。先隔离，后分析。

**选项 D 错误。** 通知所有员工特定的可疑文件可能会引起恐慌或混乱。更合适的方法先处理事件，然后以结构化的方式传播相关信息。
