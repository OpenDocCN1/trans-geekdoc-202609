问题 160。TechBank 刚刚在市中心开了一家新分行。由于位置原因，管理层担心设施可能受到车辆攻击。TechBank 可以采用以下哪种物理安全措施来专门威慑此类攻击？

- (A) 监控摄像头
- (B) 护柱（Bollards）
- (C) 门禁胸卡
- (D) 保安人员

解析 160. 正确答案：B. 护柱（Bollards）。护柱是短小且坚固的垂直柱子，通常用于控制道路交通。在物理安全背景下，它们的作用是防止车辆进入不允许的区域，起到对潜在车辆攻击的威慑作用。

选项 A 错误。虽然监控摄像头可以监控和记录活动，但它们不能作为防止车辆攻击的物理屏障。

选项 C 错误。门禁胸卡控制人员对设施的访问，但不能威慑车辆攻击。

选项 D 错误。虽然保安人员可以响应威胁并控制访问，但它们不是像护柱那样的威慑车辆攻击的特定措施。

问题 161。一家金融机构的高安全性数据中心对其主入口有一套认证系统。如果系统遇到意外错误，该机构希望确保在系统修复之前，没有任何能够访问数据中心。认证系统应该被设置为哪种配置？

- (A) 故障旁路（Fail-open）
- (B) 故障闭锁（Fail-closed）
- (C) 故障安全（Fail-secure）
- (D) 故障被动型（Fail-passive）

解析 161. 正确答案：B. 故障闭锁（Fail-closed）。故障闭锁也称为故障安全，是一种模式，即如果系统发生故障，它将默认拒绝所有请求，有效地“关闭”访问。在高安全环境中，通常优于这种模式，以防止在系统故障期间发生任何未经授权的访问。

选项 A 错误。故障旁路与该机构所希望的相反。在故障旁路场景下，如果系统发生故障，它将默认允许所有请求。

选项 C 错误。虽然“故障安全”是“故障闭锁”的另一个术语，但在选项中同时使用这两个术语会让考生产生困惑。在这种背景下，选项 B 是更合适的选择。

选项 D 错误。故障被动型在认证失败模式背景下并不是标准术语。故障旁路和故障闭锁（或故障安全）是主要的认可术语。

问题 162。CyberSecure Inc. 正在评估潜在安全泄露对其主服务器的财务影响。公司估计，该服务器的泄露将由于数据恢复、费用和罚款而导致 500,000 美元的直接财务损失。以下哪项最能代表这一估算？

- (A) 年均发生率 (ARO)
- (B) 总拥有成本 (TCO)
- (C) 单次损失期望 (SLE)
- (D) 年化损失期望 (ALE)

解析 162. 正确答案：C. 单次损失期望（SLE）。单次损失期望（SLE）代表每次风险发生时预期的货币损失。在这种情况下，公司正在估计单次泄露事件导致的直接财务损失。

选项 A 错误。年均发生率（ARO）代表预计事件在一年内发生的频率，而不是单次事件的成本。

选项 B 错误。总拥有成本（TCO）指的是在整个周期内拥有特定资产或解决方案的完整成本，而不是单次事件的成本。

选项 D 错误。年化损失期望（ALE）是一个基于 SLE 和 ARO 计算出的值，代表预期的年度损失。

问题 163。一家大型电子商务公司希望确保其新开发的应用程序在部署到生产环境之前不包含任何代码漏洞。他们希望捕获任何软件缺陷，特别是可能导致潜在安全风险的缺陷。他们应该采用以下哪种方法？

- (A) 运行时应用程序自保护 (RASP)
- (B) 对运行中的进行渗透测试
- (C) 静态代码分析
- (D) 用户验收测试 (UAT)

解析 163. 正确答案：C. 静态代码分析。静态代码分析涉及在不执行应用程序的情况下对代码进行分析，侧重于检测漏洞、编码缺陷或其他潜在安全威胁，使其成为所呈现场景的合适方法。

选项 A 错误。运行时应用程序自保护（RASP）关于关实时的应用程序监控和保护，这不会是部署前漏洞检查的首选。

选项 B 错误。对运行中的应用程序进行渗透测试涉及在应用程序上线或运行时对其进行测试，这在寻求识别部署前阶段的漏洞时可能不利。

选项 D 错误。用户验收测试（UAT）侧重于确定软件是否满足业务需求并为终端用户正常运行。它不强调发现安全漏洞。

问题 164。在 BankSecure 的新分行中，管理层决定在主入口安装一套安全系统，强制访客在进入主区域之前通过两次独立的授权检查。他们应该考虑哪种物理安全措施？

- (A) 旋转门（Turnstiles）
- (B) 保安人员
- (C) 门禁间（Access Control Vestibule）
- (D) 门卡读取器

解析 164. 正确答案：C. 门禁间（Access Control Vestibule）。门禁间（也称为人防间或安全门厅）是一种结构，由两道门组成，只有在第一道门关闭后才能进入第二道门。

选项 A 错误。旋转门控制进入区域的流量并在一定程度上防止尾随，但不提供双重授权检查。

选项 B 错误。保安人员可以执行检查，但它们不是像门禁间那样的特定物理隔离措施。

选项 D 错误。门卡读取器是访问控制的一种形式，但它们本身不强制双重授权检查。

问题 165。XYZ 公司 最近实施了一种持续评估公司威胁格局的安全解决方案，监控新兴风险并立即警报安全团队。这种评估模型允许团队快速调整安全态势。他们正在使用哪种类型的风险评估？

- (A) 一临时
- (B) 定期
- (C) 动态
- (D) 持续

解析 165. 正确答案：D. 持续。持续风险评估涉及对风险进行持续监控，使组织能够对变化做出反应。

选项 A 错误。一次性风险评估针对特定事件或目的，并非打算定期执行。

选项 B 错误。定期风险评估按计划间隔（如每年或每两年一次）进行，不是持续性的。

选项 C 错误。动态评估可以适应变化的环境或因素，但“动态”并没有特指像“持续”那样的监控。

问题 166。一家软件开发公司正在评估其应用程序中新发现漏洞的相应风险。在查看日志并模拟潜在攻击后，安全团队估计该漏洞在明年被利用的概率为 0.25。此概率表示什么？

- (A) 该漏洞在明年被利用的概率为 4 分 1
- (B) 该漏洞明年肯定会被利用四次
- (C) 该漏洞在过去一年被利用了 25 次
- (D) 每四位客户都会利用该漏洞。

解析 166. 正确答案：A. 该漏洞在明年被利用的概率为 4 分 1。0.25 的概率表示 25% 的几率，或 4 分 1 的发生可能性。

选项 B 错误。概率值并不预测发生的确切次数，而是事件发生的可能性。

选项 C 错误。给出的概率数字是对未来风险的估算，而不是过去事件的计数。
