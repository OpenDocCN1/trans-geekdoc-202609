问题 210。在一次例行检查中，IT 技术人员注意到公司服务器上的几个文件被重命名为“.locked”扩展名，并且根目录下存在一个名为“README_TO_RECOVER_FILES.txt”的新文件。根据这些指标，最可能正在进行哪种恶意活动？

- (A) 蠕虫传播
- (B) 木马程序执行
- (C) 勒索软件攻击
- (D) 逻辑炸激活

解析 210。正确答案：C。勒索软件攻击。勒索软件是一种会加密受害者文件使其无法访问的恶意软件。攻击者向受害者索要赎金以获取解密密钥。使用特定扩展名（“.locked”）重命名文件以及存在赎金信（“README_TO_RECOVER_FILES.txt”）是勒索软件攻击的典型指标。

选项 A 错误。蠕虫传播指的是独立恶意软件计算机程序的传播，该程序通过自我复制传播到其他计算机。它通常不会重命名文件或留下可读的消息。

选项 B 错误。木马程序是一种欺骗用户真实意图的恶意软件。虽然它可以传递勒索软件有效负载，但描述的指标更直接地暗示了勒索软件活动。

选项 D 错误。逻辑炸弹是一种在满足特定条件时执行恶意功能代码，但它不一定会留下描述的文件痕迹。

问题 211。一个机构正在为数字签名选择哈希函数。他们希望确保该函数能够抵抗攻击者产生两个具有相同哈值的不同消息的情况。他们正试图防御哪种攻击？

- (A) 旁信道攻击
- (B) 重放攻击
- (C) 生日攻击
- (D) 仅密文攻击

解析 211。正确答案：C。生日攻击。在生日攻击中，攻击者利用概率论中生日问题背后的数学原理，旨在找到两个产生相同输出（或哈值）的不同输入。在为数字签名选择哈希函数时，选择一个抵抗生日攻击的函数对于维护签名完整性至关重要。

选项 A 错误。旁信道攻击涉及从加密系统的物理实现获取信息，而不是利用算法或协议的理论缺陷。它与产生具有相同哈值的消息无关。

选项 B 错误。重放攻击涉及拦截数据（如登录会话）然后重新发送或重放它以获得未经授权的访问。它不关注匹配哈值。

选项 D 错误。在仅密文攻击中，攻击者拥有密文并尝试在未知密钥的情况下推导出明文。该场景并未描述这种类型的攻击。

问题 212。一个 IT 安全团队收到报告，称一个新的、此前未知的漏洞正在野外被积极利用。软件供应商尚未为该漏洞提供补丁。关于该漏洞，最准确的术语是什么？

- (A) 遗留漏洞
- (B) 零日漏洞
- (C) 已修复漏洞
- (D) 已知漏洞

解析 212。正确答案：B。零日漏洞。零日漏洞指的是软件、硬件或固件中对于供应商未知的缺陷。这种漏洞存在风险，因为在发现时没有修复程序或补丁，而且它可能已经被恶意攻击者积极利用。

选项 A 错误。遗留漏洞通常指旧软件或系统中的漏洞，这些系统可能不再支持，而不一定是未知且未修复的漏洞。

选项 C 错误。已修复漏洞意味着该漏洞已有可用修复方案。在提供的场景中，尚未发布补丁。

选项 D 错误。虽然该漏洞可能对某些实体（如此场景中的安全团队）已知，但对软件供应商来说仍然未知的。因此，在此语境下，“已知漏洞”不是最准确的描述符。

问题 213。一家公司最近部署了一个新的电子商务应用程序。安全团队希望确保能够检测到应用程序上的任何未经授权或恶意的活动。以下哪种是实现这一目标的最有效方法？

- (A) 对应用程序进行渗透测试
- (B) 在应用程序前安装防火墙
- (C) 对应用程序的日志和活动实施持续监控
- (D) 为用户提供安全浏览习惯培训

解析 213。正确答案：C。对应用程序的日志和活动实施持续监控。

对应用程序日志和活动进行持续监控允许安全团队实时检测并响应任何可疑或未经授权的行为。这确保了及时识别和处理潜在威胁，增强应用程序的安全态。

选项 A 错误。虽然渗透测试可以识别应用程序中的漏洞，但它无法对持续恶意活动提供持续监控或检测能力。

选项 B 错误。虽然防火墙可以通过过滤恶意流量提供一层安全，但它无法提供检测所有未经授权活动所需的细粒度洞察或实时监控。

选项 D 错误。培训用户安全浏览习惯很重要，但不会直接帮助监控或检测恶意活动。

问题 214。安全分析师 Ella 正在查看 Web 应用程序日志，注意到攻击者尝试在登录表单中使用以下输入：' OR '1'='1' --。此输入被用于操纵应用程序的后端数据库。这是哪种注入攻击的示例？

- (A) XML 注入
- (B) 命令注入
- (C) SQL 注入
- (D) LDAP 注入

解析 214。正确答案：C。SQL 注入。输入 `OR '1'='1' --` 是 SQL 注入攻击的经典示例。攻击者利用此技术在未正确验证用户输入的应用程序中操纵 SQL 查询，可能允许未经授权的访问或数据取取。

选项 A 错误。XML 注入针对解析 XML 输入的应用程序。场景中提到的有效负载与 XML 结构无关。

选项 B 错误。命令注入是指攻击者尝试在宿主机操作系统上执行任意命令。给定的输入不是操作系统命令。

选项 D 错误。LDAP 注入针对根据用户输入构建 LDAP 语句的应用程序。给定的有效负载不符合 LDAP 查询结构。

- (A) 在 HR 和 IT 部门之间安装防火墙
- (B) 为文件服务器实施访问控制列表 (ACL)
