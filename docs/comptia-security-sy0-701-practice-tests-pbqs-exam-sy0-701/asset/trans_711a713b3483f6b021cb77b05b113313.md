**问题 307.**** 一家软件公司开发了一个新产品。他们希望发布一份用户手册，详细说明如何使用该软件、其功能以及基础故障排除步骤。该用户手册的分类应该是？

+   (A) 机密 (Confidential)
(B) 限制 (Restricted)
(C) 公开 (Public)
(D) 内部 (Internal)

**解析 307.** **正确答案：C. 公开。** 用户手册面向软件的所有用户，应该易于获取。它不包含关于软件底层代码或算法的敏感或专有信息。因此，它应该被分类为“公开”。

选项 A 是错误的。“机密”分类对于旨在随每份软件副本分发并指导用户的文档来说限制太严格了。

**选项 B 是错误的。** “限制”会不必要地限制手册的分发，使用户户难以访问他们所需的信息。

**选项 D 是错误的。** “内部”分类会暗示该手册仅供公司内部使用，而它的目标是所有软件用户。

**问题 308.**** Jake 最近在他的电脑上运行了一个他从朋友那里收到的旧游戏。不久后，他发现他的一些文件被轻微修改后重复了，而且系统性能正在下降。哪种恶意软件最可能导致这些问题？

+   (A) 广告软件 (Adware)
(B) 特洛马 (Trojan)
(C) 蠕虫 (Worm)
(D) 病毒 (Virus)

**解析 308. 正确答案：D. 病毒。** 病毒是附加在干净文件上并可以复制的恶意程序，会导致产生多个副本。它们在传播过程中可以修改或损坏这些文件，并降低系统性能。

**选项 A 是错误的。** 广告软件主要关注向用户传递不受待的广告。虽然它可能很烦人，但它通常不会复制或修改文档。

**选项 B 是错误的。** 特洛马是伪装成合法程序的恶意软件。虽然它们可以执行各种恶意操作，但它们不会以描述的方式进行自我复制或修改文件。

**选项 C 是错误的。** 蠕虫是跨网络传播的自我复制的恶意软件。虽然它们可能会引起性能问题，但它们通常不像病毒那样附加到文件并对其进行修改。

**问题 309.**** 安全分析师 Caroline 收到警报，称在任务关键型服务器上检测到一个不熟悉的文件。她怀疑这可能是恶意软件。针对这一潜在威胁，Caroline 应该采取的最佳即时行动是什么？

+   (A) 立即删除文件以防止进一步损坏
(B) 隔离文件以防止其执行或传播
(C) 复制文件以便进一步分析
(D) 通知所有员工该可疑文件

**解析 309.** **正确答案：B. 隔离文件以防止其执行或传播。** 隔离可疑文件会将其隔离开，防止潜在的执行或传播，同时允许在不立即删除的情况下进行调查。

**选项 A 是错误的。** 虽然删除文件看起来很主动，但它消除了进一步分析的机会，并可能影响取证调查。

**选项 C 是错误的。** 复制文件对于分析很重要，但首要任务任务应该是防止可疑文件的潜在执行或传播。先隔离，后分析。

**选项 D 是错误的。** 通知所有员工关于某个特定的可疑文件可能会引起恐慌或困惑。更合适的方法是处理事件，然后以结构化的方式通信相关信息。

**问题 312.**** XYZ Corp 的员工 Jane 最近注意到她的浏览器主页发生了变化，并且她收到了越来越多的针对性广告。此外，浏览器中出现了一个不记得自己安装过的工具栏。根据这些症状，哪种恶意软件最可能影响她的电脑？

**解析 312.** **正确答案：C. 间谍软件。** 间谍软件是从系统中悄悄收集信息的恶意软件。浏览器设置的更改（如新主页或新工具栏）结合针对性广告，是间间谍软件的常见迹象。

**问题 313.**** 托管公司电子商务网站的 Web 服务器计划进行操作系统升级。预计升级将持续 30 分钟。为了最大限度地减少潜在停机对客户的影响，主要的考虑因素应该是？
