**问题 380。** CyberSecure Corp 的一名安全分析师审查了一份关于应用程序的漏洞报告，该应用程序允许攻击者上传恶意脚本。一旦这些脚本被执行，攻击者就可以获得对应用程序的完全控制。该漏洞应主要如何分类？

- (A) 完整性漏洞
- (B) 可用性漏洞
- (C) 远程代码执行漏洞
- (D) 泄露漏洞

**解析 380. 正确答案：C. 远程代码执行漏洞。** 远程代码执行 (RCE) 漏洞允许攻击者在目标系统上运行任意命令或脚本。在场景中，应用程序漏洞允许攻击者上传并执行恶意脚本，这与该分类相符。

**选项 A 错误。** 虽然漏洞可能会影响应用程序的完整性，但这里的主要关注点是攻击者执行代码代码，使其成为一个 RCE 漏洞。

**选项 B 错误。** 可用性漏洞主要关注服务或系统的中断，导致授权用户无法访问。该场景并未显示出任何可用性的中断。

**选项 D 错误。** 泄露漏洞涉及对信息的未经授权的查看或访问。描述的漏洞超出了纯粹的泄露，允许了恶意脚本的执行。

**问题 381。** 在组织发生最近的一起安全事件后，IT 团队发现若干合法活动被入侵检测系统标记，导致了大量的误报。提高系统准确性并减少不必要的警报，最合适的操作是什么？

- (A) 禁用入侵检测系统一周以观察常规网络流量模式
- (B) 设置更严格的防火墙规则以阻止所有外部流量
- (C) 实施告警调优以完善系统的检测标准
- (D) 鼓励员工减少互联网使用

**解析 381. 正确答案：C. 实施告警调优以完善系统的检测标准。** 告警调优涉及调整系统的检测规则或标准，以更好地区分合法活动和恶意活动，从而减少误报。

**选项 A 错误。** 禁用入侵检测系统会使组织暴露在真实威胁之下，这是一种风险方法。

**选项 B 错误。** 设置更严格的防火墙规则不能直接解决入侵检测系统的误报问题，并可能会阻塞合法的业务操作。

**选项 D 错误。** 减少互联网使用并不一定与误报的减少相关联。问题在于系统的标准，而不是流量的大小。

**问题 382。** ABC 公司最近由于承包商将受感染的笔记本电脑连接到公司网络而面临安全泄露。管理层希望实施一种解决方案，确保任何连接到公司网络的设备都符合公司的安全标准，包括最新的防病毒病毒定义。ABC 公司应该考虑哪种解决方案？

- (A) 入侵检测系统 (IDS)
- (B) 虚拟专用网络 (VPN)
- (C) 网络访问控制 (NAC)
- (D) Web 应用防火墙 (WAF)

**解析 382. 正确答案：C. 网络访问控制 (NAC)。** 网络访问控制 (NAC) 允许组织为设备连接公司网络设置策略。NAC 可以在设备连接之前评估其安全态，以确保其符合预定义的标准，例如更新的防病毒病毒定义、所需的补丁等。

**选项 A 错误。** 入侵检测系统 (IDS) 监控网络流量中的可疑活动并发布告警，但不在允许网络访问之前评估设备安全态。

**选项 B 错误。** 虚拟专用网络 (VPN) 允许对网络进行安全的远程访问，但本身不评估设备的安全态。

**选项 D 错误。** Web 应用防火墙 (WAF) 侧重于通过监控和过滤 HTTP 流量来保护 Web 应用程序。它用于评估设备安全态。

**问题 383。** Global 公司收到报告，称其某些客户收到了似乎源自公司域名的钓鱼邮件。IT 团队检查并确认 SPF 和 DKIM 配置设置正确。Global 公司 还可以实施何种额外的邮件安全措施，以便在邮件不符合 SPF 和 DKIM 时提供处理这些邮件的清晰策略？

- (A) 启用 TLS 加密
- (B) 实施 DMARC 策略
- (C) 设置新的 SMTP 服务器
- (D) 延长邮件保留期

**解析 383. 正确答案：B. 实施 DMARC 策略。** 通过实施 DMARC 策略，Global 公司可以定义邮件接收者如何处理不符合指定的 SPF 和 DKIM 记录的域名邮件。DMARC 可以设置为监控、隔离或拒绝未通过这些检查的邮件，为防止邮件伪造和钓鱼提供更稳健的保护。

**选项 A 错误。** 虽然 TLS 加密对于保护传输中的邮件内容至关重要，但它没有解决伪造问题，也没有为处理不匹配 SPF 和 DKIM 的邮件提供指南。

**选项 C 错误。** 设置新的 SMTP 服务器可以帮助发送邮件，但它本身不能防止伪造，也无法为不符合 SPF 和 DKIM 的邮件提供指导。

**选项 D 错误。** 延长邮件保留期影响邮件存储的时间，但不能提供防止伪造的保护。

**问题 384。** 一家金融公司刚经历了了网络攻击，IT 团队识别出一种规避了他们传统防病毒解决方案的恶意软件。CISO 现在不仅想要检测，而且能够实时分析并响应此类威胁。该公司应该考虑实施哪种解决方案？

- (A) 漏洞扫描器
- (B) 入侵防御系统 (IPS)
- (C) 终端检测与响应 (EDR)
- (D) 补丁管理系统

**解析 384. 正确答案：C. 终端检测与响应 (EDR)。** 终端检测与响应 (EDR) 对终端事件进行实时监控和分析，允许组织检测、调查并响应潜在的安全威胁。EDR 工具可以识别可能指示规避传统防病毒解决方案的高级威胁。

**选项 A 错误。** 漏洞扫描器用于识别系统或网络中的漏洞，但不提供对威胁的实时监控和响应能力。

**选项 B 错误。** 入侵防御系统 (IPS) 监控网络流量以防止潜在威胁，但可能不如 EDR 解决方案那样在端点提供深度分析和响应。

**选项 D 错误。** 补丁管理系统用于管理软件更新的分发和安装，但不提供实时威胁检测和响应。
