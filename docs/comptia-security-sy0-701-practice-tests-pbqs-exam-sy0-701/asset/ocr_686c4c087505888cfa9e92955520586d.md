**Explanation 260.** **Correct Answer: C. Designing network zones based on data sensitivity and access requirements.**

Zoning based on data sensitivity and access requirements ensures that segments of the network with varying trust levels are isolated. This reduces the risk of a breach in one zone affecting another.

**Option A is incorrect.** While VLANs can segment traffic, doing so based purely on organizational departments may not align with varying trust and data sensitivity requirements.
