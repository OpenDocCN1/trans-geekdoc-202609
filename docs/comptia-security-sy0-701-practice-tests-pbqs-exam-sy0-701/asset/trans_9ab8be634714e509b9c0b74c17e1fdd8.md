

问题 77。一家环保非政府组织（NGO）的网站遭到入侵，并被一条指责他们近期反对森林砍伐信息的取代，声称他们在传播虚假信息。网站上留下了一份推广负责任林业和可持续采伐实践的宣言。哪种类型的威胁者最可能是此事件的幕后黑手？

- (A) 勒索软件组织
- (B) 有组织犯罪集团
- (C) 黑客主义者
- (D) 高级持续性威胁 (APT)

解析 77. **正确答案：C。黑客主义者。** 攻击的动机似乎源于对森林砍伐和可持续采伐的意识形态差异。黑客主义者通常通过网络行动发表政治或社会声明。将 NGO 的网站替换为宣言支持了这是一场意识形态驱动的攻击，这是黑客主义者的典型特征。

**选项 A 错误。** 勒索软件组织主要关注加密数据并要求赎金以释放数据。在描述的场景中，没有提到赎金或加密数据。

**选项 B 错误。** 有组织犯罪集团通常受财务利益驱动。对 NGO 网站的攻击似乎是意识形态驱动的，而非利润驱动。

**选项 D 错误。** 高级持续性威胁 (APT) 是高度组织化的、通常由国家支持的团体，进行长期的网络间谍活动。它们的动机通常是战略性的、政治性的或间谍驱动的。描述的攻击不符合 APT 操作特征。

问题 78。一家政府机构遭遇了网络安全事件，其通信平台被破解。入侵者对提取敏感数据或造成干扰不感兴趣，但被观察到在长时间监控外交通信。攻击者的可能动机是什么？

- (A) 从内幕交易中获得利益
- (B) **通过间谍活动来理解和预判外交动态**
- (C) 内部员工的分歧
- (D) 试图扩大其网络犯罪网络

解析 78. 正确答案：B。通过间谍活动来理解和预判外交动态。在不外泄数据或不引起干扰的情况下静静监控外交通信，表明其动机是理解、预判并可能操纵政府或外交行动。这是间谍活动的一个典型案例。

**选项 A 错误。** 虽然敏感信息对内幕交易可能很有价值，但对外交通信的关注表明其更广泛的战略意图，而不仅仅是为了财务。

**选项 C 错误。** 不满的员工可能会破坏或泄露数据，但静静监控外交通信表明了更高水平的策略和复杂性，通常超出了个人恩怨的范围。

**选项 D 错误。** 攻击者的行为专门针对外交渠道，并没有没有试图将更多系统或个人招募进犯罪网络。

问题 79。在公司的入职过程中，新员工需要阅读并确认理解了各种公司政策。人力资源部门希望确保员工在使用公司设备和互联网资源时知晓自己的责任。入职包中应该包含哪种政策来解决这一问题？

- (A) 密码复杂度策略
- (B) 数据分类策略
- (C) 可接受使用策略 (AUP)
- (D) 供应商管理策略

解析 79. 正确答案：C。可接受使用策略 (AUP)。可接受使用策略 (AUP) 概述了员工在使用公司设备、网络和其他 IT 资源时的“准则”和“禁忌”。将其包含在入职包中将确保新员工知晓自己的责任。

选项 A 错误。虽然密码复杂度策略很重要，但它主要涉及创建和管理密码的要求，而不是 IT 资源的整体可接受使用。

选项 B 错误。数据分类策略侧重于根据敏感性对数据进行分类。它没有提供关于 IT 资源可接受使用的指南。

**选项 D 错误。** 供应商管理策略规范公司与其供应商之间的关系和安全预期，而不是员工对公司 IT 资源的可接受使用。

问题 80。WhiteCape Healthcare 是一家国际医疗服务提供商，拥有包含许多欧盟公民大型患者数据库。他们正准备实施新系统以改进医生对数据的访问。在授予医生访问欧盟患者数据的权限时，他们应该特别关注哪项监管要求？

- (A) 确保数据仅用于税务报表目的
- (B) 在共享数据之前获得患者的明确同意
- (C) 使用专利算法加密所有数据
- (D) 将数据存储在位于欧盟内的物理服务器上

解析 80. 正确答案：B。在共享数据之前获得患者的明确同意。根据 GDPR，在处理或共享其个人数据之前，需要获得个人的明确同意。这意味着欧盟公民应该对其数据的访问和共享给予了明确许可。

**选项 A 错误。** 出于税务报告目的访问数据与 GDPR 处理欧盟公民个人健康数据的要求没有直接关系。

**选项 C 错误。** 虽然加密是数据保护的好做法，但 GDPR 并不强制使用专利算法。此外，加密本身无法解决同意要求。

**选项 D 错误。** 虽然 GDPR 有关于将数据传输到欧盟以外的规定，但仅将数据存储在欧盟内的物理服务器上并绕过共享数据时需要患者明确同意的需求。

问题 81。一家企业正在多个办公地点部署基于 IoT 的安全摄像头。作为首席安全专业人员，你会优先考虑哪项建议来为这些设备建立安全基线？

- (A) 将设备设置为公共模式，以便所有员工都能访问视频流以实现透明
- (B) **定期更新设备固件以修补已知漏洞**
- (C) 启用即插即用 (UPnP) 以确保网络上所有设备都能于连接
- (D) 为所有摄像头使用相同的密码以便于管理

解析 81. 正确答案：B。定期更新设备固件以修补已知漏洞。定期的固件更新可确保 IoT 设备免受已漏洞的威胁，有助于维护其安全态势。

**选项 A 错误。** 将设备设置为公共模式可能导致隐私泄露和未经授权的访问。

**选项 C 错误。** UPnP 会通过自动打开端口并允许设备设置配置来引入漏洞，可能导致安全风险。

**选项 D 错误。** 为所有设备使用相同密码会产生单点故障。如果一个设备的密码被破解，所有设备都会变得脆弱。

问题 82。一家机器人公司正在开发一种依赖实时操作系统 (RTOS) 管理运行的自动驾驶车辆。开发团队希望确保车辆的 RTOS 具有良好的安全态势。在为该 RTOS 建立安全基线时，团队应该优先考虑什么？

- (A) 安装强有的防病毒软件
- (B) 启用所有功能以实现最大功能
- (C) 定期将 RTOS 数据备份到云端
- (D) 最小化服务和开放端口的数量

解析 82. 正确答案：D。最小化服务和开放端口的数量。减少服务和开放端口的数量可以减少 RTOS 上的攻击面，使攻击者更难发现漏洞。

**选项 A 错误。** 虽然防病毒软件对许多系统都是至关重要的，特别是对于自动驾驶车辆的系统，但应优先考虑减少攻击面并确保实时性能，而不是依赖传统的防病毒解决方案。
