
问题 105。AcmeBank 最近对其在线银行系统进行了业务影响分析。结果显示，该银行可以承受最多4 小时的系统停机，而不会导致巨大的财务损失和客户不满。哪种概念最能描述这 4 小时的时长？

- (A) 恢复点目标 (RPO)
- (B) 最大可忍机时间 (MTD)
- (C) 恢复时间目标 (RTO)
- (D) 恢复时间 (TTR)

解释 105. 正确答案：C. 恢复时间目标 (RTO)。恢复时间目标 (RTO) 是业务过程在中断后恢复到所需状态的目标持续时间，以避免不可接受的后果。AcmeBank 对其在线银行系统的 RTO 为 4 小时。

选项 A 错误。恢复点目标 (RPO) 描述的是组织为了在灾难后恢复必须从备份存储中恢复的文件的最大年龄。它不是指时间长度。

选项 B 错误。最大可忍机时间 (MTD) 是业务过程在对业务造成不可弥救的损害之前可以停止运行的最长时间。虽然两者有关，但题目专门描述的是 RTO。

选项 D 错误。恢复时间 (TTR) 通常是一个用于衡量恢复特定过程或系统所需时间的指标。然而，该场景直接描述的是 RTO。

问题 106。一家金融公司想通过拦截和检查网络流量来提高其网页浏览安全性，防止用户访问恶意网站或下载恶意软件。他们正在寻找一种可以作为客户端向其他服务器请求资源时的中间件的解决方案。该公司应该实施什么？

- (A) 网络入侵检测系统 (IDS)
- (B) VPN 集中器
- (C) 代理服务器 (Proxy server)
- (D) 跳板服务器

解释 106. 正确答案：C. 代理服务器。代理服务器充当用户计算机和互联网之间的中间件。它拦截 Web 请求，并提供过滤网页内容、缓存 Web 请求以及出于安全考虑检查流量等功能。

选项 A 错误。网络入侵检测系统 (IDS) 监控并检测网络上的恶意活动，但并不作为 Web 请求的中间件。

选项 B 错误。VPN 集中器为组织网络提供安全的远程访问，但并不作为网页浏览请求的中间件。

选项 D 错误。跳板服务器用于对内部服务器进行安全且审计的访问，但不是为拦截网络流量设计的。

问题 107。一名用户收到一条声称来自其银行的短信，提醒其账户存在未经授权的活动。信息指示用户立即点击提供的链接并验证其账户详情。该用户尚未注意到其银行账户有任何异常。此短信最可能是哪种类型攻击的组成？

- (A) 短信钓骗 (Smishing)
- (B) 语音钓骗 (Vishing)
- (C) 蓝牙夹持 (Bluejacking)
- (D) 蓝牙信息盗取 (Bluesnarfing)

解释 107. 正确答案：A. 短信钓骗。短信钓骗是一种钓鱼攻击，恶意攻击者利用短信欺骗个人提供敏感信息，通常通过冒充受信任的组织或联系人。

选项 B 错误。语音钓骗是指语音钓鱼，攻击者使用语音电话代替短信或电子邮件冒充合法实体并诈骗受害者。

选项 C 错误。蓝牙夹持涉及向启用蓝牙的设备发送未请求请求的消息。它通常不涉及为了欺骗目的而冒充合法实体。

选项 D 错误。蓝牙信息盗取是一种未经授权访问或盗取蓝牙设备上信息的行为。它不涉及欺骗性短信。

问题 108。安全分析师 Jane 收到一份关于在每天特定时间发生网络变慢的报告。调查后，她发现某台设备正在向网络泛洪流量，导致合法请求被丢弃。该设备可能正在执行哪种类型的攻击？

- (A) 分布式拒绝服务 (DDoS)
- (B) ARP 毒化
- (C) MAC 溢出
- (D) DNS 放大攻击

解释 108. 正确答案：C. MAC 溢出。MAC 溢出通过向交换机填充伪造 MAC 地址导致交换表溢出。

选项 A 错误。分布式拒绝服务 (DDoS) 是通过泛洪流量使服务不可用。

选项 B 错误。ARP 毒化涉及发送伪造 ARP 消息到本地网络。

选项 D 错误。DNS 放大攻击利用开放的 DNS 解析器使目标瘫痪。

问题 109。在大型体育赛事期间，一组未具身份的黑客同时对交通网络、电网和电信系统发起了网络攻击。没有索要金或任何明确的动机。最可能的动机是什么？

- (A) 从销售数据获利
- (B) 对赛事的伦理关注
- (C) 针对特定运动员或团队的报复
- (D) 制造混乱和破坏

解释 109. 正确答案：D. 制造混乱和破坏。考虑到攻击目标的广泛性以及在赛事期间发生，且没有明显的财务动机，显然其主要目标是造成破坏。

选项 A 错误。场景中没有迹象显示数据被被出售，也没有提供财务动机。

选项 B 错误。虽然伦理关注可能是某些攻击的原因，但这些攻击的规模和目标表明了更广泛的动机。

选项 C 错误。场景并未特别针对某个运动员或团队；攻击是广泛的。

问题 110。一家当地咖啡馆为客户提供免费 Wi-Fi。最近，有报告称网络上存在中间人攻击。老板决定升级无线安全性，并希望实施一种加密协议来保护数据传输。哪种协议能为公共 Wi-Fi 用户提供安全性和性能之间的平衡？

- (A) 高级加密标准 (AES)
- (B) 有线等隐私 (WEP)
- (C) RC4 流加密
- (D) 开放式无线

解释 110. 正确答案：A. 高级加密标准 (AES)。AES 在安全性和性能之间提供了良好的平衡。它是一种现代加密标准，提供强安全性的同时不会产生大量的性能开销，适用于安全性和体验都很重要的公共 Wi-Fi 环境。

选项 B 错误。WEP 是一种过时的加密协议，存在已知漏洞。它不安全且容易被破解，不适用于保护公共 Wi-Fi 网络。

选项 C 错误。RC4 是一种用于早期无线协议（如 WEP）的流加密。它被发现存在多种攻击漏洞，不再认为无线网络是安全的。

选项 D 错误。开放无线网络不实施任何加密，导致数据传输面临威胁。
