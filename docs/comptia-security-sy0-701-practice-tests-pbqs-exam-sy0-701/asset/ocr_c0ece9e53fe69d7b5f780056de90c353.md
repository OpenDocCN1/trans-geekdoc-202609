**Explanation 248.** **Correct Answer: B. OS Patch Management Issue.** When operating systems are not regularly updated, they become vulnerable to known exploits that have since been patched by vendors. An attacker can take advantage of these vulnerabilities to gain unauthorized elevated privileges.

Operating system-based vulnerabilities often arise due to missed patches or updates. Keeping the OS updated is crucial because vendors frequently release patches to address known vulnerabilities. In this case, the lapse in updating the operating system opened a window for attackers to exploit and obtain elevated privileges.

**Option A is incorrect.** Application Misconfiguration pertains to incorrect settings or configurations in software applications, operating systems. The scenario does not suggest any issues with application settings.
