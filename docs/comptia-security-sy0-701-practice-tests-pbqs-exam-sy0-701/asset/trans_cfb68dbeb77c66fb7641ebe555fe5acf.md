

## 第1章
通用安全概念

## 第1-110 题

**问题 1.** 一位客户否认自己签署过一份数字合同。服务提供商需要证明该签名确实来自客户且未被篡改。服务提供商依靠的是以下哪种安全概念？

- (A) 身份验证 (Authentication)
- (B) 机密性 (Confidentiality)
- (C) 不否认性 (Non-repudiation)
- (D) 访问控制 (Access Control)

**问题 2.** IT 顾问 Carlos 为一家初创公司提供网络安全最佳实践建议。该公司计划在不同的子域名下启动多个微站。他们希望有一种具有成本效益且确保网站经过第三方验证的解决方案。Carlos 推荐哪种证书？

- (A) 为每个微站创建一个独立的自签名证书
- (B) 为每个子域名提供独立的第三方证书
- (C) 第三方通配符证书 (Wildcard certificate)
- (D) 由内部 CA 发布的 EV 证书

**问题 3.** 公司希望确保值班人员能够尽快发现并处理安全事件。为了实现这一目的，实施以下哪种操作安全控制措施最好？

- (A) 部署网络入侵防御系统 (NIPS)
- (B) 建立 24/7 安全运营中心 (SOC)
- (C) 创建公司范围内的安全策略
- (D) 实施端到端数据加密

**问题 4.** 在例行检查期间，IT 部门发现几名员工在午休时间离开电脑且无人看管。哪种操作安全控制有助于降低与此行为相关的风险？

- (A) 实施生物识别身份验证
- (B) 执行严格的密码策略
- (C) 部署无空闲后自动锁定屏幕
- (D) 实施安全编码规范

**问题 5.** 一家艺术画廊想要部署一种安全解决方案，以检测带有多个雕塑的开放庭院内的运动。该空间的温度条件变化，可能会导致某些运动检测技术产生误报。在这种情况下，哪种类型的传感器最能确保一致的运动检测？

- (A) 热成像传感器
- (B) 压力敏感垫
- (C) 超声波探测器
- (D) 微波运动探测器

**问题 6.** 公司访问安全服务器室的主要安全控制措施是生物识别指纹扫描仪。然而，扫描仪在高湿度环境下偶尔会故障。安全团队正在考虑一种替代方案，以便在主方法失效时授予访问权限。以下哪项是最合适的补偿控制措施（Compensating control）？

- (A) 实施基于令牌的身份验证系统
- (B) 在正门配备安保人员
- (C) 在服务器房内安装监控摄像头
- (D) 定期进行服务器房审计

**问题 7.** 一家金融机构希望确保客户了解银行的信息共享政策以及其个人数据的使用情况。以下哪种安全控制措施最能向客户传达这些信息？

- (A) 为在线交易实施端到端加密
- (B) 在银行网站上发布隐私政策
- (C) 为员工进行年度网络安全意识培训
- (D) 在网上银行中使用多因素身份验证

**问题 8.** 一家大型金融机构希望确保所有员工都理解网络安全的重要性以及他们在保护公司资产方面所起的作用。以下哪种管理安全控制对实现这一目标最有效？

- (A) 在网络边界安装防火墙
- (B) 为员工进行定期安全意识培训
- (C) 部署入侵检测系统 (IDS)
- (D) 加密所有公司数据

**问题 9.** 一公司面临过多次未经授权的人员进入办公场所的情况。以下哪种预防性安全控制对于防止未经授权的物理访问最有效？

- (A) 为网络流量实施日志监控解决方案
- (B) 在所有出入口处安装视频监控摄像头
- (C) 为员工进行定期安全意识培训
- (D) 为网络访问实施多因素身份验证系统

**问题 10.** TechVault 是一家专门安全存储解决方案的公司，最近发生了一次未经授权的入侵，窃偷成功绕过了他们的运动传感器。为了防止未来的泄露，他们正在考虑部署一种能够检测限制区域重量变化的系统，以警报任何未经授权的访问。以下哪项最符合要求？

- (A) 超声波运动探测器
- (B) 压力敏感地板垫
- (C) 带有人脸识别功能的监控摄像头
- (D) 玻璃破碎传感器

**问题 11.** 系统管理员正在为新的 Web 应用程序设置身份验证系统。以下哪种安全控制属于技术类别，并确保用户在获得访问权限之前证明其身份？

- (A) 实施安全意识培训计划
- (B) 对新员工进行背景检查
- (C) 使用多因素身份验证
- (D) 建立整洁桌面策略

**问题 12.** 一家电子商务公司遭遇了分布式拒绝服务 (DDoS)攻击，导致其网站无法访问数小时。为了在未来减轻此类攻击的影响，实施以下哪种纠正性控制措施（Corrective control）最好？

- (A) 在网站上显示第三方安全认证的标志
- (B) 建立 Web 应用防火墙 (WAF) DDoS 保护
- (C) 对网站进行例行漏洞评估
- (D) 为网站管理员实施强密码策略

**问题 13.** GreenTech Industries 的制造设施位于一个相对偏远的地区。最近发生的侵入事件警报了管理层。以下哪种措施最有效地威慑对设施周边的未经授权的访问？

- (A) 安装红外传感器
- (B) 使用明亮的周边界照明
- (C) 在设施内部署安保人员
- (D) 增加围墙高度

**问题 14.** 在例行审查时，安全专家 Jake 在组织的财务系统中发现了一个意想不到的数据。经询问，他得知该数据是故意放置的，以观察是否有授权用户交互。这种数据被称为？

- (A) 蜜罐字符串 (Honeystring)
- (B) 蜜罐 (Honeytoken)
- (C) 金丝雀 (Canary token)
- (D) 安全标记

**问题 15.** 一个组织正在智能办公室部署新的 IoT 设备。为了确保只有授权设备可以连接到公司网络，每个设备将获得一个唯一密钥。组织使用的是哪种方法？

- (A) 共享密钥身份验证
- (B) 公钥基础设施 (PKI)
- (C) 基于令牌的身份验证
- (D) 用户名和密码身份验证

**问题 16.** 在 BankSecure 的新分支，管理层决定在正门安装安全系统，强制访问客进入进入场所前通过两次检查。他们应该考虑哪种物理安全措施？

- (A) 闸机
- (B) 安保人员
- (C) 门厅/缓冲区 (Access Control Vestibule)
- (D) 读卡器

**问题 17.** IT 部门希望实时监控网络流量，以检测任何异常或恶意活动。以下哪种安全控制可以实现此目标？

- (A) 安全策略文档
- (B) 入侵检测系统 (IDS)
- (C) 员工行为规范
- (D) 访问控制列表 (ACL)

**问题 18.** 成线零售业务的网站管理员 Jenkins 正在为域名获取 SSL 证书。公司为不同的服务使用多个子域名，例如 shop.example.com、blog.example.com 和 support.example.com。与其为每个子域名获取单独证书，Jenkins 希望使用一个证书。Jenkins 应该追求哪种证书？

- (A) 扩展验证证书 (EV)
- (B) 通配符证书 (Wildcard Certificate)
- (C) 带有备用名称 (SAN) 的证书
- (D) 代码签名证书

**问题 19.** 在一家新建的博物馆内，展室希望在闭馆后检测任何未经授权的运动。房间内充满了空调声和来自城市的外部噪音。哪种传感器最适合在这种条件下检测运动，且不受噪音影响？

- (A) 声学传感器
- (B) 玻璃破碎探测器
