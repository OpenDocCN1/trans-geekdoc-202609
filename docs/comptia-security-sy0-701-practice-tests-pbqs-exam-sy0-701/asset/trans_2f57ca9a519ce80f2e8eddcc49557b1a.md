**问题 259。** 在一个关键的财务季度，GlobalFin Corp 在业务高峰期因系统维护导致了意外停机，对其业务运营造成了重大影响。为了防止未来发生此类情况，GlobalFin Corp 在其维护活动方面应该实施哪些措施？

- (A) 随机进行维护活动以避免可预测性
- (B) 在业务高峰期实施维护活动
- (C) 建立指定的维护窗口
- (D) 减少维护活动的频率

**解释 259。** **正确答案：C. 建立指定的维护窗口。** 维护窗口是专为系统维护指定的特定时间段，可确保由于更新、补丁或其他维护活动导致的中断不会发生在关键业务时段。通过设置这些窗口（通常在非峰值时段），企业可以最大限度地减少运营中断的影响。

**选项 A 错误。** 随机进行维护活动可能导致不可预测的停机，这可能会干扰业务运营并降低利益相关者之间的信任。

**选项 B 错误。** 在业务高峰期实施维护活动正是导致场景中出现中断的原因。这种方法可能会导致更多的运营问题，特别是对于在这些时段有关键业务运营的企业而言。

**选项项 D 错误。** 减少维护活动的频率可能会减少中断，但也可能导致未修补的漏洞、过时的软件或其他安全和运营问题。

**问题 260。** Alex 是某 IT 公司的新实习生，他想要访问公司内部门户。他没有输入“companyportal.com”，而是不小心输入了“comapnyportal.com”，结果进入了一个外观完全相同但要求他下载安全证书的网站。这一场景最能描述的是哪种类型的攻击？

- (A) 鱼叉式钓鱼 (Spear Phishing)
- (B) 水蛭穴攻击 (Watering Hole Attack)
- (C) 域名抢骗 (Typosquatting)
- (D) 中间人 (Man-in-the-Middle)

**解释 260。** 正确答案：C. 域名抢骗。攻击者利用用户在向浏览器中输入 URL 时犯的拼写错误，然后可能在欺骗性网站上以某种方式利用用户。

域名抢骗（也称为 URL 劫持）涉及攻击者注册与热门网站拼写错误的域名。其意图通常是欺骗那些输错 URL 的用户，引导他们进入恶意网站。

**选项 A 错误。** 鱼叉式钓鱼针对特定的个人或公司，通过定制的尝试来窃取信息。描述的场景围绕着对拼写错误的利用，而不是针对性的邮件攻击。

**选项 B 错误。** 水蛭穴攻击涉及入侵目标经常访问的网站。

**选项 D 错误。** 中间人攻击涉及攻击者拦截并可能篡改双方之间的通信。

**问题 261。** DataGuard. 运营于欧盟，最近遭受了数据泄露。根据《通用数据保护条例》(GDPR) 的规定，以下哪项是可能的后果？

- (A) 将被强制关闭
- (B) 将将面临监禁
- (C) 将要求发布公开道歉
- (D) DataGuard 将面临巨额罚款

**解释 261。** 正确答案：D. DataGuard 将面临巨额罚款。 根据 GDPR，违规企业可能面临高达其全球年度营业额 4% 或 2000 万欧元的罚款，以高者为准。

**选项 A 错误。** GDPR 并不要求关闭公司。

**选项 B 错误。** GDPR 的后果是罚款而非监禁。

**选项 C 错误。** 发布公开道歉不是 GDPR 规定的法律强制罚措施。

**问题 262。** 一家制药公司正在研发一种彻底改变疾病治疗的新药物。研发团队拥有关于该药物成分、程序和试验结果的详细文档。这些文档应如何分类？

- (A) 未分类 (Unclassified)
- (B) 公开 (Public)
- (C) 机密 (Confidential)
- (D) 敏感 (Sensitive)

**解释 262。** 正确答案：C. 机密。为了防止窃取、工业间谍活动或意外泄露，这些文档应被分类为机密，以确保有限的访问。

**选项 A 错误。** 未分类的数据不需要特殊保护或机密性。

**选项 B 错误。** 公开分类将使信息对所有人可见，不适用于药物配方。

**选项 D 错误。** 虽然该信息是敏感的，但“机密”分类提供了更严格的控制，更符合此类情况。

**问题 263。** 在最近一次软件更新后，公司的内网门户部分员工无法访问。IT 团队怀疑可能是由于网络过滤规则。IT 团队应该检查什么来确认他们的怀疑？

- (A) 内容过滤策略
- (B) 恶意软件检测日志
- (C) 允许列表/拒绝列表配置 (allow/deny list configurations)
- (D) 网络带宽利用图

**解释 263。** 正确答案：C. 允许列表/拒绝列表配置。网络访问问题（特别是在配置更改之后）通常由于允许列表或拒绝列表配置错误引起的。检查这些配置可以判断特定的 IP 地址或域名是否被错误阻止或未允许。

**选项 A 错误。** 内容过滤策略主要关注阻止特定类型的内容（如社交媒体或成人网站），而不是导致特定用户无法访问。

**选项 B 错误。** 恶意软件检测日志记录潜在的安全威胁，而非网络访问配置。除非特定用户的机器被隔离，否则它们通常不会导致选择性的不可访问。

**选项 D 错误。** 虽然网络带宽利用图可能会显示流量减少，但它们无法提供导致不可访问的特定允许/拒绝列表详细信息。
