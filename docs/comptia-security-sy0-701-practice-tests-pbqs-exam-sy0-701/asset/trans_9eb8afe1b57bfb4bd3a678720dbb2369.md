
问题 587。在一次常规的安全评估中，Claire 发现其组织内新部署的数据库服务器仍在使用默认登录凭据。与此发现相关的**主要**安全风险是什么？

- (A) 数据库将无法以最佳状态运行
- (B) 服务器将需要频繁更新补丁
- (C) 未经授权的人员可能轻松访问
- (D) 服务器将消耗更多带宽

解释 587. 正确答案：C。未经授权的人员可能轻松访问。默认凭据通常是公开的，如果不更改它们，恶意攻击者可以轻松地使用它们获取对系统的未经授权访问。

默认凭据可能包括制造商为初始设置设置用户名和密码，并且可以在网上轻松搜索到。如果部署后不更改，它们将构成重大的安全风险，因为它们允许任何知道这些信息的人访问系统。

选项 A 错误。使用默认凭据不会直接影响数据库的最优运行。

选项 B 错误。使用默认凭据并不意味着服务器需要频繁更新补丁。然而，补丁管理是维护安全的另一个独立方面。

选项 D 错误。使用默认凭据不会直接导致服务器消耗带宽。

问题 588。DeltaTech 是一家进步的科技公司，旨在通过消除与密码相关的漏洞来提高其安全态，正在考虑部署无密码身份验证系统。以下哪项代表此类系统的**主要**优势？

- (A) 它允许用户选择密码复杂度
- (B) 它消除了记忆密码的需求
- (C) 它保证免受所有威胁的保护
- (D) 它确保与所有遗留系统兼容

解释 588. 正确答案：B。它消除了记忆密码的需求。无密码身份验证方法（如生物识别、硬件令牌或移动应用程序确认）消除了用户记忆和输入密码的需求，降低了与弱密码相关的风险并增强了便利性。

选项 A 错误。无密码系统完全消除了密码这一概念。

选项 C 错误。虽然无密码身份验证可以显著提高安全性（特别是针对撞库填充攻击等威胁），但它不能保证免受保护。

选项 D 错误。如果不进行修改，无密码身份验证方法可能与遗留系统兼容。

问题 589。一家金融机构最近发现，大量机密客户记录在非工作时间被访问和复制。经过调查发现，这些访问来自公司内部一个经过身份验证的用户，该用户最近未获得晋升。哪种类型的威胁者对此事件负**主要**责任？

- (A) 黑客行动者
- (B) 内部威胁
- (C) 国家级
- (D) 有组织犯罪

解释 589. 正确答案：B。内部威胁。证据表明，这些活动是由组织内部一个经过身份验证的用户进行的，该用户可能具有动机（因为未获得晋升）。

选项 A 错误。黑客行动者通常受政治或社会事业驱动，他们将针对特定组织以抗议特定问题。

选项 C 错误。国家级受间谍活动或军事目标驱动。出于个人原因访问客户记录与他们的动机不符。

选项 D 错误。虽然有组织犯罪集团可能为了财务利益对客户记录感兴趣。

问题 590。一家金融机构希望确保客户了解银行关于信息共享的政策以及个人数据如何被使用。以下哪种安全控制**最好**向客户传达这些信息？

- (A) 为在线交易实施端到端加密
- (B) 在银行网站上发布隐私政策
- (C) 为员工进行年度网络安全意识培训
- (D) 为网上银行使用多因素身份验证

解释 590. 正确答案：B。在银行网站上发布隐私政策。隐私政策作为一种指令，因为它告知客户银行在收集、使用和共享个人数据方面的做法。通过阅读政策，客户可以理解自己的权利和银行的责任。

选项 A 错误。虽然端到端加密确保了在线交易的机密性，但它没有告知客户银行关于信息共享的政策或数据如何使用。

选项 C 错误。年度网络安全意识培训针对员工而非客户。它不会直接向客户传达银行的信息共享政策。

选项 D 错误。使用多因素身份验证通过要求多种形式的验证提高了网上银行的安全性。然而，它没有告知客户个人数据是如何被使用的或银行的信息共享政策。

问题 591。大型医疗保健提供者 OmegaHealth 正在将自动化整合到其运营中。当招聘新的医疗工作人员时，他们需要访问多个系统。为什么 OmegaHealth 要对这些系统的用户配置过程进行自动化？

- (A) 为所有医疗工作人员强制统一的密码。
- (B) 通过确保在所有必要平台上一致且同步地创建账户来节省时间
- (C) 防止新员工在试用期结束之前访问任何系统
- (D) 通过延迟账户激活来减少所需的软件许可

解释 591. 正确答案：B。通过确保在所有必要平台上一致且同步地创建账户来节省时间。用户配置的自动化，特别是在需要访问多个系统的环境中，可以大幅节省时间并减少人为错误。通过自动化，可以在所有要求的平台上一致且同步地创建账户。

选项 A 错误。为所有用户强制统一密码是一种糟糕的安全实践。自动化应该侧重于效率和安全，而不是创建潜在的漏洞。

选项 C 错误。用户配置自动化本身并不会防止新员工访问系统。自动化应该设计为根据特定规则和角色进行配置。

选项 D 错误。用户配置的自动化是为了简化账户的创建和管理，而不是为了减少软件许可或延迟激活。

问题 592。在检测到网络遭到未经授权的入侵后，一家金融机构希望实施一种控制措施，将受损的系统恢复到已知的良好状态。以下哪是**最**合适的纠正性控制？

- (A) 在网络中实施入侵检测系统 (IDS)
- (B) 频繁更新防火墙规则
- (C) 从经过验证的备份恢复系统
- (D) 为用户启用多因素身份验证

解释 592. 正确答案：部署红外 (IR) 传感器。红外 (IR) 传感器检测红外辐射，例如人体发出的热量。这使得它们在检测人类入侵者方面特别有效，即使在完全黑暗的情况下也能根据他们散发的热量进行检测。
