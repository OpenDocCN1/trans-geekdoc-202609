**问题 321。** DataCorp 的一名安全分析师被要求防止未经授权的外部应用程序连接到他们的服务器。分析师主要应该依靠哪种方法来实现这一点？

- (A) 为批准的应用程序实施白名单
- (B) 监控服务器 CPU 使用率
- (C) 定期为服务器打补丁
- (D) 对服务器上的静态数据进行加密

**解析 321。** **正确答案：A. 为批准的应用程序实施白名单。** 通过实施白名单，分析师可以指定哪些应用程序被授权连接到服务器。任何不在列表中的应用程序都将被阻止建立连接，从而有效地阻止了未经授权的外部应用程序。

**选项 B 错误。** 虽然监控服务器 CPU 使用率可以深入了解服务器性能和潜在异常，但它并不能阻止未经授权的应用程序连接。

**选项 C 错误。** 定期为服务器打补丁是修复已知漏洞的安全最佳实践。然而，打补丁并不能直接阻止特定的外部应用程序连接。

**选项 D 错误。** 对静态数据进行加密有助于保护存储的数据免受未经授权的访问，但不限制哪些应用程序可以连接到服务器。

**问题 322。** 您的组织计划升级数据库系统。为了在此过程中保持安全性，在升级验证之前，以下操作应该是被限制（RESTRICTED）的？

- (A) 监控数据库任何异常
- (B) 允许终端用户访问升级后的数据库
- (C) 对数据库进行定期备份
- (D) 审查数据库系统日志

**解析 322。** **正确答案：B. 允许终端用户访问升级后的数据库。** 在升级系统通过验证并解决任何潜在问题之前，应该限制终端用户的访问。这确保了升级引入的任何漏洞或问题都不会损害数据或允许未经授权的活动。

**选项 A 错误。** 监控数据库对于识别任何潜在安全问题至关重要，不应被限制。

**选项 C 错误。** 定期备份应该继续，因为它们是全面灾难恢复和数据保护策略的一部分。

**选项 D 错误。** 审查日志对于监控系统健康和安全至关重要；因此，它不应被限制。

**问题 323。** 在经过一系列系统增强后，一家金融机构决定使用手动方法在单独的文件记录更改，而不是实施版本控制系统。在审计期间，网络安全团队难以确定关键系统文件的哪个版本是最新且准确的。对此类文档不实施版本控制的首要（PRIMARY）风险是什么？

- (A) 多个文件导致存储需求增加
- (B) 团队成员之间协作困难
- (C) 缺乏可追溯性且难以回滚到已知稳定状态
- (D) 需要更多地培训员工进行手动文档记录

**解析 323。** **正确答案：C. 缺乏可追溯性且难以回滚到已知稳定状态。** 版本控制提供了清晰的更改历史，确保可以轻松回滚到已知稳定状态，并识别文档或系统文件的最新版本。在缺乏版本控制的情况下，识别最新且准确的版本可能是具有挑战性的。

**选项 A 错误。** 虽然存储可能是一个关注的问题，但首要风险是无法跟踪更改并回滚到稳定状态。

**选项 B 错误。** 协作可能会受到阻，但直接风险与可追溯性和稳定性有关。

**选项 D 错误。** 培训员工始终是关重要的，但迫切关注的问题是跟踪和管理更改的能力。

**问题 324。** 您的组织正准备升级一个支持电子商务应用程序的数据库服务器。对变更管理文档的审查显示，多个应用程序依赖此特定的数据库服务器来实现各种功能。为了确保升级过程顺畅且没有中断，应该首先（FIRST）采取哪些步骤？

- (A) 立即升级数据库服务器以利用新功能
- (B) 对数据库服务器进行备份
- (C) 识别并测试所有依赖该服务器的应用程序
- (D) 告知用户可能的停机时间

**解析 324。** **正确答案：C. 识别并测试所有依赖该服务器的应用程序。**

**选项 A 错误。** 在不考虑依赖关系的情况下立即升级可能会导致中断。

**选项 B 错误。** 虽然备份服务器是一个良好的做法，但识别依赖关系应该放在优先。

**选项 D 错误。** 告知用户是关重要的，但理解影响是首位的。

**问题 325。** 一家跨国公司担心由于密钥丢失或泄露而失去对加密数据的访问。他们向第三方组织寻求解决方案。以下哪项是安全持有加密密钥的系统？

- (A) 公钥库
- (B) 密钥生成中心
- (C) 密钥托管（Key Escrow）
- (D) 密钥更新服务

**解析 325。** **正确答案：C. 密钥托管。** 密钥托管是一种系统，其中加密密钥安全地存储在第三方处，以便在原始密钥丢失或泄露的情况下可以检索它们。

**选项 A 错误。** 公钥库是存储公钥的地方，而不是用于备份或恢复。

**选项 B 错误。** 密钥生成中心负责创建加密密钥，而不是为了恢复而存储它们。

**选项 D 错误。** 密钥更新服务处理密钥过期的更换，而不是为了恢复而存储它们。

**问题 326。** XYZ Corp 的一名软件开发人员公司软件中包含一段代码，如果他的名字从应用程序的致谢列表中移除，该代码将损坏应用程序数据库。在他离开公司几个月后，应用程序数据库被损坏了。哪种类型的恶意软件负责此操作？

- (A) 木马
- (B) 间谍软件
- (C) 广告软件
- (D) 逻辑炸弹

**解析 326。** **正确答案：D. 逻辑炸弹。** 逻辑炸弹由特定事件触发的恶意软件。在此例中，软件开发人员的名字从贡献列表中移除触发了该代码。

**选项 A 错误。** 木马伪装成合法软件，但在安装后会执行恶意活动。该场景没有描述木马的行为。

**选项 B 错误。** 间谍软件旨在收集并发送信息，通常在用户不知情的情况下进行。它不会根据特定触发器损坏数据库。

**选项 C 错误。** 广告软件向用户投放不受欢迎的广告。它不会根据特定事件采取恶意行动。

**问题 327。** 一名员工注意到，在使用 RFID 卡进入办公大楼时，一个陌生人带着一个设备离她非常近。几天后，她同事的卡突然停止工作，尽管该卡没有被报告或损坏。安全团队应该怀疑哪种类型的攻击？

- (A) 针对访问控制系统的暴力破解攻击
- (B) RFID 克隆
- (C) 尾随进入
- (D) RFID 干扰

**解析 327。** **正确答案：B. RFID 克隆。** RFID 克隆是通过捕获其信号来制作 RFID 卡或标签的未经授权复制。那个带着设备离得近的陌生人可能一直在捕获 RFID 信号以进行克隆。
