解析 178. 正确答案：C. 平均故障间隔时间 (MTBF)。平均故障间隔时间 (MTBF) 是衡量硬件或系统可靠性的一种指标。它是指从一次故障发生到下一次故障发生之间的平均时间。对于 WebServ 公司而言，两次故障之间的 2000 小时时长反映了 MTBF。

选项 A 错误。恢复时间目标 (RTO) 是业务流程在中断后必须恢复的预期时间和和服务水平，以避免不可接受的损失。

选项 B 错误。平均修复时间 (MTTR) 代表修复故障组件所需的平均时间。

选项 D 错误。恢复点目标 (RPO) 衡量的是从时间跨度上来说，在不对业务连续性造成损害的情况下，可以丢失的数据量。

问题 179. 终端用户 Sarah 从一个网站下载了软件更新。在安装之前，她想确保软件没有被恶意篡改，并且源自受信任的来源。Sarah 应该检查什么来验证这一点？

- (A) 网站的 SSL 证书
- (B) 应用程序的代码签名证书
- (C) 应用程序的开源仓库
- (D) 软件的用户评论

解析 179. 正确答案：B. 应用程序的代码签名证书。通过检查应用程序的代码签名证书，Sarah 可以验证该软件确实是由受信任的实体颁发的，并且自签名以来未经过任何改动。有效的代码签名证书让用户对软件的真实性和完整性充满信心。

选项 A 错误。虽然网站的 SSL 证书确保了服务器和浏览器之间数据传输的安全，但它不能保证所下载软件的完整性或真实性。

选项 C 错误。开源仓库可能包含软件的源代码，但检查这些仓库并不一定能验证 Sarah 下载的编译后软件版本的完整性。

选项 D 错误。用户评论可以提供有关软件功能和体验的见解，但不能依赖它们来确认软件的真实性或完整性。

问题 180. 某组织正在对其云基础设施进行风险评估。评估确定，通过不安全的 API 发生数据泄露的可能性为“高”。哪些因素可能导致这一概率评级？

- (A) API 已经过彻底测试，并具有已知的安全配置
- (B) 行业内此类泄露的记录较少
- (C) 该 API 是公开访问的，且在过去六个月内已报告了多个漏洞
- (D) 云提供商提供了针对任何形式安全泄露的保证 SLA

解析 180. 正确答案：C. 该 API 是公开访问的，且在过去六个月内已报告了多个漏洞。一个公开访问且近期有漏洞记录的 API 会显著增加泄露概率，使得该场景最符合“高”概率评级。

选项 A 错误。经过彻底测试且已知的安全配置可能会降低概率评级。

选项 B 错误。类似泄露的记录较少也可能降低评估的概率。

选项 D 错误。保证性的 SLA 可能在泄露发生后提供补救措施，但它从本质上并没有降低泄露发生的概率。

问题 181. 一家跨国公司的新任 CIO Jenny 希望确保组织中的每件软件和硬件资产都有明确的所有者，负责其安全和维护。以下实现这一目标**最有效**方法是哪种？

- (A) 部署自动化资产发现工具，并根据位置将资产分配给部门
- (B) 规定每个部门负责人都是其部门所有资产的默认所有者
- (C) 定期进行审计并要求个人用户声称其资产的所有权
- (D) 引入资产管理系统，在资产采购或分配时记录具有定义所有权的资产

解析 181. 正确答案：D. 引入资产管理系统，在资产采购或分配时记录具有定义所有权的资产。

选项 A 错误。部署自动化资产发现工具并根据位置分配资产可能无法明确所有权责任。

选项 B 错误。让部门负责人成为默认所有者可能导致责任划分不明。

选项 C 错误。定期审计并要求用户声称所有权可能无法确保所有资产的有效管理。

问题 182. 某组织正在其智能办公环境中部署新的 IoT 设备。为了确保只有授权设备可以连接到公司网络，以下哪项最描述了该组织使用的认证方法？

- (A) 共享密钥认证
- (B) 公共密钥基础设施 (PKI)
- (C) 基于令牌的认证
- (D) 用户名和密码认证

解析 182. 正确答案：B. 公共密钥基础设施 (PKI)。公共密钥基础设施 (PKI) 是硬件、软件、策略和标准的结合，为安全通信提供框架。PKI 的主要特征之一是使用密钥对（公钥和私钥）进行实体。

选项 A 错误。共享密钥认证通常涉及双方共享一个密钥并用于验证对方。场景中提到的是密钥对，与共享密钥的概念不符。

选项 C 错误。基于令牌的认证通常涉及生成时间性代码的硬件或软件令牌。场景描述的是密钥对，而非令牌。

选项 D 错误。用户名和密码认证是实体提供用户名和秘密密码来验证身份的方法。场景未提到用户名或密码的使用。
