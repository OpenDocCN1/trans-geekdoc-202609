**问题 48。** 公司访问安全服务器房的主要安全控制是生物识别指纹扫描仪。然而，该扫描仪在高湿度环境下偶尔会故障。安全团队正在考虑一种替代方案，以便在主方法失效时授予访问权限。以下哪项是最合适的补偿控制措施？

- (A) 实现基于安全令牌（token）的认证系统
- (B) 在主入口配备安保人员
- (C) 在服务器房内安装摄像头
- (D) 定期进行服务器房审计

**解释 48. 正确答案：A. 实现基于安全令牌（token）的认证系统。** 基于安全令牌的认证系统可以在主控制措施（生物识别指纹扫描仪）失效时作为验证个人身份的替代方法。这为访问提供了直接的补偿控制措施。

**选项 B 错误。** 虽然主入口的安保人员可以提供额外的安全保障，但他们并不是服务器房等特定位置故障生物识别系统的直接补偿控制。

**选项 C 错误。** 虽然在服务器房内安装摄像头可以提供额外保护，但它们不是针对访问权限问题的直接补偿控制。

**选项 D 错误。** 定期进行服务器房审计是一种合规措施，而不是在扫描仪故障时提供访问权限的替代技术手段。

**问题 49。** 某中型公司发现其移动设备经常被未经访问，导致敏感数据泄露。公司决定实施新的安全策略以保护数据。以下哪种措施最能有效防止这种情况？

- (A) 强制使用复杂的磁盘加密
- (B) 实施移动设备管理（MDM）
- (C) 增加设备的物理强度
- (D) 限制设备访问频率

**解释 49. 正确答案：A. 强制使用复杂的磁盘加密。** 强制使用复杂的磁盘加密可以确保即使设备丢失或被未经访问，敏感数据也无法被读取，这是防止数据泄露最有效的措施之一。

**选项 B 错误。** 虽然移动设备管理（MDM）可以帮助管理设备并实施安全策略，但在防止设备被盗取后数据泄露方面，不如加密直接。

**选项 C 错误。** 增加设备物理强度可以防止物理损坏，但无法防止设备在被盗后后数据被泄露。

**选项 D 错误。** 限制设备访问频率可以解决流量问题，但无法防止设备被非法访问后的数据泄露。

**问题 50。** 一家公司面临着由于员工使用公共 Wi-Fi 导致的数据被截获风险。公司希望实施一种技术来确保数据传输的安全。以下哪种措施最合适？

- (A) 要求员工使用虚拟专用网络（VPN）
- (B) 禁用所有无线网络
- (C) 提高防火墙的强度
- (D) 使用更长的 WiFi 密码

**解释 50. 正确答案：A. 要求员工使用虚拟专用网络（VPN）。** 虚拟专用网络（VPN）可以创建加密通道，确保数据在公共 Wi-Fi 上传输时不被第三方截获或窃听。

**选项 B 错误。** 禁用 Wi-Fi 会导致员工无法连接网络，在现代办公环境中通常不是可行的解决方案。

**选项 C 错误。** 提高防火墙强度可以防止未经授权的访问，但无法防止在无线传输过程中数据被截获。

**选项 D 错误。** 使用更长的 WiFi 密码可以增加破解难度，但无法保护数据传输过程中的安全性。
