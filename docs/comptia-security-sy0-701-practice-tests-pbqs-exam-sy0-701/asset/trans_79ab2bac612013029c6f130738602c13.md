-   (A) 在网络过滤器上对该 IP 地址实施阻止规则
-   (B) 禁用受攻击工作站的网络网络端口
-   (C) 使用蜜罐重流恶意流量
-   (D) 更新防火墙的固件

**Explanation 444. 正确答案：A. 在网络过滤器上对该 IP 地址实施阻止规则。** 通过在网络过滤器上专门针对已知的恶意 IP 地址实施阻止规则，任何与该 IP 通信的尝试都将被停止，有效地防止进一步的恶意通信。

**选项 B 错误。** 禁用受攻击工作站的网络端口会使机器断开网络连接，但如果端口重新启用，它并不能专门阻止与恶意 IP 的通信。

**选项 C 错误。** 虽然蜜罐可以用于重流或研究攻击者的行为，但它们不是阻止与已知恶意 IP 地址通信的最直接方法。

**选项 D 错误。** 更新防火墙的固件是一项通用的维护任务，并没有专门针对阻止与已知恶意 IP 的通信。

Question 445. IT 管理员 Jennifer 被要求为一名销售职位的新远程员工办理入职。以下哪项是配置用户账户的**最佳**方法？

-   (A) 为新用户分配与 CEO 相同的访问权限，因为他们可能需要所有资源
-   (B) 为新用户提供管理员权限，以确保他们能够安装和配置任何需要的软件
-   (C) 使用销售人员模板的访问权限提供所需的资源
-   (D) 允许新用户根据其工作角色决定并自选必要的访问权限

**Explanation 445. 正确答案：C. 使用销售人员模板的访问权限提供所需的资源。** 根据角色模板配置用户可以确保用户仅拥有他们所需的访问权限，符合最小权限原则。

**选项 A 错误。** 这违背了最小权限原则，并可能引入重大的安全风险。

**选项 B 错误。** 给没有适当需求的员工提供管理员权限可能会使组织暴露于不必要的风险之中。

**选项 D 错误。** 用户不应自选访问权限，因为他们可能没有意识到潜在的安全影响。

Question 446. 一家大型组织的 IT 部门收到员工报告，称他们无法访问网络上的资源。调查后，IT 部门发现访问控制列表 (ACL) 设置最近被修改过。以下哪项是审查和修改 ACL 设置的**主要**原因？

-   (A) 为了平衡网络负载
-   (B) 更新组织的防火墙规则
-   (C) 确保对资源拥有适当访问权限
-   (D) 更新组织的密码策略

**Explanation 446. 正确答案：C. 确保对资源拥有适当访问权限。** ACL 是确定谁可以访问网络或系统内资源的重要工具。定期审查和修改 ACL 设置可以确保用户拥有适当的访问权限，防止未经授权的访问，并确保授权用户可以访问他们需要的资源。

**选项 A 错误。** 虽然网络负载均衡至关重要，但它与 ACL 没有直接关系。ACL 关注的是访问控制，而不是流量分配。

**选项 B 错误。** 防火墙规则与 ACL 不同。虽然它们可以协同工作，但防火墙规则主要关注允许或阻止网络流量，而 ACL 则决定对资源的访问权限。

**选项 D 错误。** 虽然更新组织的密码策略是一项重要的安全措施，但它与 ACL 无关，ACL 根据用户或组权限控制对资源的访问。

Question 447. TechWorld Corp 担心网络罪分子发送看似源自其域名的电子邮件。公司希望实施一种解决方案，允许接收邮件的服务器验证声称来自 TechWorld Corp 域名的邮件确实源自已批准的服务器。公司应该实施以下哪种方案？

-   (A) SMTP 身份验证
-   (B) DKIM
-   (C) 基于 SSL 的 POP3
-   (D) S/MIME

**Explanation 447. 正确答案：B. DKIM。** 密钥识别邮件 (DKIM) 是一种用于验证邮件来源和完整性的方法。通过 DKIM，可以在发送邮件的标头中添加数字签名。接收邮件服务器随后使用该签名，通过与 DNS 记录中发布的发送域公钥进行对比来验证邮件。

**选项 A 错误。** SMTP 身份验证确保用户在通过服务器发送电子邮件之前提供有效的凭据，但它不会向接收者验证发送者的域名。

**选项 C 错误。** 基于 SSL 的 POP3 (安全套接层) 是关于从服务器安全地检索电子邮件消息的。它没有提供验证发送者域的方法。

**选项 D 错误。** S/MIME (安全/多用途互联网邮件扩展) 用于加密和对邮件消息签名。虽然它确保了邮件内容的完整性和机密性，但它不会向收件人验证发送者的域名。

Question 448. 公司使用的一种云端协作工具向用户显示警告：“您已在两个位置登录。”然而，用户在工作站上只有一个活动会话。安全团队的首要关注点应该是？

-   (A) 用户可能正在使用多个设备
-   (B) 工具可能存在配置错误
-   (C) 协作团队面临故障
-   (D) 可能存在未经授权的访问

**Explanation 448. 正确答案：D. 可能存在未经授权的访问。** 在用户确定只使用一个设备的情况下，并发会话警告是未经授权访问的信号。安全团队应检查是否存在入侵迹象。

**选项 A 错误。** 虽然用户经常使用多个设备，但此场景提到用户只有一个，因此该选项不可能。

**选项 B 错误。** 虽然配置错误会导致各种问题，但它们通常不会表现为虚并发会话。

**选项 C 错误。** 协作工具的故障通常不会导致虚并发会话。

Question 449. 公司正在寻找一种提供分布式账本中不可篡改且透明记录的加密解决方案。以下哪项最符合要求？

-   (A) 对称密钥算法
-   (B) 公钥基础设施
-   (C) 区块链
-   (D) 数字水印

**Explanation 449. 正确答案：C. 区块链。** 区块链是一种去中心化的分布式账本，提供了交易的不可篡改。每个区块包含交易列表并与上一个区块链接。区块链的透明性和不可变性使其特别适用于需要不可赖记录的应用。

**选项 A 错误。** 对称密钥算法是使用相同密钥进行加密和解密的方法，但本身并不提供不可篡改的交易记录。

**选项 B 错误。** 公钥基础设施 (PKI) 用于数字证书和密钥分发，但不提供不可篡改的交易记录。

**选项 D 错误。** 数字水印将信息嵌入数字信号中，但它不提供不可篡改的交易记录。
