
选项 B 错误。虽然员工可能正在运行耗型任务，但在非正常时间段持续出现的模式使其与恶意活动相比，可能性较低。

选项 C 错误。虽然 DDoS 攻击会导致资源消耗，但它不会在每晚的同一时间段内特定地针对 CPU 使用率。

问题 432。一位记者想向她的编辑发送一条机密信息，而不引起怀疑。她没有发送编码或加密文本，而是将信息嵌入到看起来无害的照片中。她正在采用哪种方法隐藏信息？

- (A) 数字签名
- (B) 隧道技术 (Tunneling)
- (C) 隐写术 (Steganography)
- (D) 链 (Chaining)

解析 432. 正确答案：C. 隐写术。
隐写术是一种用于将数据隐藏在另一个数据中的技术。在这种场景中，记者将机密信息嵌入照片中，使其看起来无害且无疑。

选项 A 错误。数字签名用于验证消息或文档的真实性和完整性。它不会在另一份数据中隐藏信息。

选项 B 错误。隧道技术是一种将一种协议封装在另一种协议中的方法，通常用于 VPN，以通过公共网络传输数据。

选项 D 错误。在密码学背景下，“链”通常指如密码分组链（CBC）等操作模式。它不涉及将数据隐藏在其他数据中。

问题 433。安全分析师 Ella 正在审查 Web 应用程序的日志，注意到攻击者尝试在登录表单中使用以下输入：' OR '1='1' --。此输入被用于操纵应用程序的后端数据库。这属于哪种类型的注入攻击？

- (A) XML 注入
- (B) 命令注入
- (C) SQL 注入
- (D) LDAP 注入

解析 433. 正确答案：C. SQL 注入。输入 ' OR '1='1' --` 是 SQL 注入攻击的经典示例。攻击者利用这种技术在未妥当验证用户输入的应用程序中操纵 SQL 查询，可能允许未经授权的访问或数据检索。

选项 A 错误。XML 注入针对的是解析 XML 输入的应用程序。场景中提到的有效载荷（payload）与 XML 结构无关。

选项 B 错误。命令注入是指攻击者尝试在主机操作系统上执行任意命令。给定的输入不是操作系统命令。

选项 D 错误。LDAP 注入针对的是根据用户输入构建 LDAP 语句的应用程序。给定的有效载荷不符合 LDAP 查询结构。

问题 434。在一次安全审计期间，发现某应用程序使用明文哈希存储密码。安全团队建议了一种方法，该方法涉及使用原始结合盐值（salt），然后进行多次重哈希。这种方法被称为什么？

- (A) 密钥聚集 (Key clustering)
- (B) 防止彩虹表攻击 (Rainbow table prevention)
- (C) 密钥轮 (Key rotation)
- (D) 密钥扩展 (Key stretching)

解析 434. 正确答案：D. 密钥扩展。密钥扩展是指对密码（通常与盐值结合）进行多次哈希的过程。这种重复的哈希过程使得暴力破解攻击变得更加耗时且困难，因为攻击者不仅需要猜测密码，还要以与原始过程相同的次数应用哈希函数。

选项 A 错误。密钥聚集涉及不同的密钥从相同的明文产生相同的密文，这与描述的场景无关。

选项 B 错误。虽然盐值可以防止彩虹表的有效使用，但多次对密码重哈希的行为并不专门称为“防止彩虹表”。

选项 C 错误。密钥轮涉及定期更换加密密钥。它与多次哈希密码无关。

问题 435。某大学的 IT 部门为新入职人员提供了学生记录的访问权限。为了保护学生身份，他们在保持数据库原始格式的同时，将真实姓名和社会安全号码替换为虚假信息。IT 部门正在利用哪种技术？

- (A) 数字签名
- (B) 数据掩码 (Data masking)
- (C) 隐写术 (Steganography)
- (D) 数据去重 (Data deduplication)

解析 435. **正确答案：B. 数据掩码。** 数据掩码通过模糊敏感信息来保护数据主体隐私。

选项 A 错误。数字签名用于验证消息的真实性。

选项 C 错误。隐写术用于在其他文件中隐藏数据。

选项 D 错误。数据去重是消除数据副本以节省空间的过程。

问题 436。流行的流媒体服务 StreamNet 计划在新国家推出。他们预计用户量将大幅增加。为了确保无缝体验，StreamNet 应该优先考虑哪些容量规划相关的行动？

- (A) 投资内容加密和 DRM
- (B) 增加营销和促销活动
- (C) 实施更强的身份验证方法
- (D) 扩展并优化基础设施

解析 436. 正确答案：D. 扩展并优化基础设施。容量规划允许 StreamNet 预测所需的资源，并对服务器、网络、存储和其他组件进行必要的调整。

选项 A 错误。内容加密和 DRM 对于保护内容至关重要。

选项 B 错误。营销和促销活动可以吸引用户，但不会直接影响基础设施容量。

选项 C 错误。更强的身份验证方法可以提高安全性，但不能解决容量容量。

问题 437。某电子商务公司的 IT 部门正在为新的产品库存系统配置访问控制。他们希望销售团队更新库存水平和产品详情，但不希望他们访问存储在同一系统中的财务数据。IT 部门正在应用哪种访问控制原则？

- (A) 最小权限原则 (Least Privilege)
- (B) 基于角色的访问控制 (RBAC)
- (C) 强制访问控制 (MAC)
- (D) 基于用户的访问控制 (UBAC)

解析 437. **正确答案：B. 基于角色的访问控制 (RBAC)。** 基于角色的访问控制 (RBAC) 将权限分配给组织内的角色。然后将角色分配给个人，与角色相关的权限决定了他们可以和不能访问的内容。在这种场景中，销售团队将获得一个允许他们更新库存但限制访问财务数据的角色。

选项 A 错误。虽然最小权限原则规定用户应仅获得执行任务所需的最小访问权限，但该场景特别侧重于角色（销售团队）以及与角色相关的权限，这更符合 RBAC。

选项 C 错误。强制访问控制 (MAC) 使用标签（例如分类级别）来确定访问权限。它比 RBAC 更僵化，且场景中没有描述这一点。

选项 D 错误。基于用户的访问控制 (UBAC) 将权限直接分配给每个用户，而不是基于角色。
