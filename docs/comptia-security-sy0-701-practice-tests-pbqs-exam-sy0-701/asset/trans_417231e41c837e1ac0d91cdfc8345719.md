**问题 517。** 领先的科技巨头 TechFirm 最近进行了一次安全演习。其目标是让内部安全团队防御来自外部红队的一系列模拟攻击。当红队发起攻击时，内部团队的目标是检测、响应并缓解这些威胁。TechFirm 为其内部安全团队采用的是哪种类型的渗透测试？

- (A) 攻击性渗透测试 (Offensive penetration testing)
- (B) 被动渗透测试 (Passive penetration testing)
- (C) 防御性渗透测试 (Defensive penetration testing)
- (D) 黑盒测试 (Black box testing)

**解析 517.** **正确答案：C. 防御性渗透测试。** 防御性渗透测试旨在测试组织防御系统和网络免受攻击的能力。它通常涉及内部安全团队（通常被称为蓝队），他们负责防御模拟攻击。

**选项 A 错误。** 攻击性渗透测试涉及主动尝试利用漏洞，而不是防御漏洞。

**选项 B 错误。** 被动渗透测试是指在不与目标系统进行主动交互的情况下收集信息。它并不侧重于防御主动威胁。

**选项 D 错误。** 黑盒测试是一种测试人员对所测试系统的内部工作一无所知的方法。它并没有描述一种防御姿态。

**问题 518。** 助理助理 Emily 接到一个自称是 IT 部门新员工的电话。拨电者说他们正在进行常规检查，需要 Emily 确认她的用户名和密码以进行系统验证。Emily 应该如何回应？

- (A) 礼貌地拒绝并向 IT 部门报告此电话
- (B) 为拨电者提供用户名但不提供密码
- (C) 要求拨电者通过电子邮件发送请求，以便留存书面记录
- (D) 什么也不说直接挂断

**解析 518.** 正确答案：A. 礼貌地拒绝并向 IT 部门报告此电话。这是一个典型的语音钓鱼（vishing）尝试案例，属于社会工程学的一种。在此类情况下，最佳实践是绝不通过电话提供敏感信息，尤其是当电话是未经请求的时。向 IT 部门报告此类尝试可以帮助公司提高意识并可能防止进一步的尝试。

**选项 B 错误。** 即使 Emily 只提供了用户名，它仍可能与其他攻击结合并被恶意使用。

**选项 C 错误。** 书面记录可能很有帮助，但至关重要的是无论通过电子邮件还是电话，都不要理会或验证未经请求的请求。

**选项 D 错误。** 虽然挂断停止了即时威胁，但报告此类事件对于更广泛的组织意识提升和保护是至关重要的。

**问题 519。** 智能家居设备制造商 XYZ Corp 未能在其产品中实施标准的安全实践。一家流行的科技评论网站发布了一篇深度评论，详细列举了这些漏洞。作为直接结果，XYZ Corp 最可能面临以下哪种后果？

- (A) 获得智能家居技术创新奖
- (B) 声誉受损导致销售下降
- (C) 与科技零售商的合作伙伴关系关系增加
- (D) 员工招聘率激增

**解析 519.** 正确答案：B. 声誉受损导致销售下降。负面评论，尤其是强调安全漏洞的评论，会导致消费者信任丧失，并可能因声誉受损而导致销售下降。

**选项 A 错误。** 在公开安全漏洞的情况下，不太可能获得创新奖。

**选项 C 错误。** 鉴于围绕产品安全缺陷的负面宣传，其与科技零售商的合作伙伴关系可能会受到损害，或至少被搁置。

**选项 D 错误。** 负面评论，尤其是强调安全漏洞的评论，不太提高招聘率。潜在员工可能对加入一家声誉受损的公司产生顾虑。

**问题 520。** 软件公司 SoftTech Inc. 考虑将其业务扩展到欧洲。他们将收集并处理欧盟公民的个人数据。以下哪些法律规定对 SoftTech Inc. 是最关键的？

- (A) 各国家的注册
- (B) 欧盟通用数据保护条例 (GDPR)
- (C) 确保安全标准
- (D) 技术代码实现

**解析 520.** 正确答案：B. 欧盟通用数据保护条例 (GDPR)。在处理欧盟公民个人数据时，遵守 GDPR 是至关重要的。

**选项 A 错误。** 在处理个人数据时，各国家的注册不是核心法律要求。

**选项 C 错误。** 确保安全标准是目标，但 GDPR 是必须遵循的特定法律框架。

**选项 D 错误。** 技术代码实现是执行层面的，不是合合性的框架。

**问题 521。** DataGuard 公司运营于欧盟，最近遭遇了重大数据泄露。由于未能遵守 GDPR，以下哪项是最可能发生的结果？

- (A) 被强制关闭
- (B) 高管团队将面临监禁
- (C) 要求发布公开道歉
- (D) 面临巨额罚款

**解析 521.** 正确答案：D. 面临巨额罚款。根据 GDPR 规定，违规行为可能导致巨额行政罚款。

**选项 A 错误。** 虽然违规可能导致运营限制，但最直接的法律后果通常是罚款。

**选项 B 错误。** GDPR 规定通常不涉及高管团队直接面临监禁。

**选项 C 错误。** 虽然公开道歉可能是一种公关手段，但它不是 GDPR 规定的直接法律后果。
