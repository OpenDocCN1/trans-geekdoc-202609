Question 462. A security analyst discovers that an external IP address has been repeatedly trying every possible combination of characters to gain access to the company’s VPN portal for the past two days. Which type of password attack is this MOST likely describing?

+   (A) Password Spraying
(B) Dictionary Attack
(C) Rainbow Table Attack
(D) Brute Force Attack

Explanation 462. Correct Answer: D. Brute Force Attack. Brute Force Attack involves systematically trying every possible combination of characters until the correct one is found. The scenario specifies that every possible combination of characters is being tried on the VPN portal, indicating a brute force attack.

Option A is incorrect. Password Spraying involves trying a few commonly used passwords across multiple accounts, rather than all possible combinations on one account.

Option B is incorrect. A Dictionary Attack uses a list of common or previously used passwords to attempt access. It doesn’t involve trying every possible combination.
