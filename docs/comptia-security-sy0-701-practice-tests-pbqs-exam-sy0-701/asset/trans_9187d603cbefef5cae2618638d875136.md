问题 89。 一家软件开发公司决定在多云环境中托管其应用程序。在部署之前，他们寻求增强其云端资源的安全性。以下哪项是加固其云基础设施的最佳实践实践？

- (A) 确保所有云存储存储桶或容器都是公开访问的，以便于数据共享
- (B) 在所有云提供商处应用一致的安全配置和策略
- (C) 为了统一性，在所有云实例上使用相同的 SSH 密钥对
- (D) 将身份和访问管理 (IAM) 角色的使用仅限制为高级人员

**解释 89. 正确答案：B. 在所有云提供商处应用一致的安全配置和策略。** 在所有云提供商之间保持一致的安全配置和策略，可以确保多云设置中没有薄弱环节，并减少管理多套策略的复杂性。

选项 A 错误。将所有云存储存储桶或容器公开访问会暴露敏感数据，这是导致数据泄露的常见配置错误。

选项 C 错误。在所有实例上使用相同的 SSH 密钥对可能存在风险。如果攻击者获取了 SSH 密钥，他们就可以获得对使用该密钥的所有实例的未经的访问。

选项 D 错误。虽然根据最小权限原则限制访问很重要，但应该根据员工的职责而非仅仅是其资历来适当分配 IAM 角色。这确保了用户拥有完成工作所需的必要权限，而不会对敏感资源产生不必要的访问。

问题 90。金融公司 RedFlare Solutions 正在数据库中存储敏感客户数据。首席信息安全官 (CISO) 坚持，即使数据在传输过程中被拦截或存储遭到破坏，也应该是无法访问的。哪种加密标准最符合这一需求？

- (A) 使用共享密钥的对称加密
- (B) 使用单向函数对数据进行哈希
- (C) 使用透明加密加密整个数据库
- (D) 将数据存储在专有格式中

解释 90. 正确答案：C. 使用透明数据加密加密整个数据库。透明数据加密 (TDE) 加密整个数据库，确保数据在静态存储和传输过程中都保持加密状态。这使得数据在没有相应加密密钥的情况下是无法读取的。

**选项 A 错误。** 对称加密可以使数据无法访问，但在密钥管理和分发方面可能会面临挑战，特别是在密钥泄露的情况下。

**选项 B 错误。** 对数据进行哈希使其变得不可读，但它是一个单向函数。一旦数据被哈希，就无法检索或解密，因此不适用于需要访问和读取的存储数据。

**选项 D 错误。** 仅仅将数据存储在专有格式中并不意味着它是加密的或不可读的。如果有人理解或反向工程了该格式，数据就可以被读取。

问题 91。XYZ 公司计划在其新收购的办公楼内部署新的无线基础设施。IT 经理希望确保整个区域内获得最佳的无线覆盖。在安装无线接入点之前，IT 团队应该优先考虑以下哪项？

- (A) 购买最的无线接入点以确保最大的覆盖范围
- (B) 进行现场勘测以确定接入点的最佳位置
- (C) 将所有接入点部署在窗户附近以增强信号强度
- (D) 确保所有用户都拥有 5GHz 设备

解释 91. 正确答案：B. 进行现场勘测以确定接入点的最佳位置。现场勘测将有助于识别接入点的最佳位置，以实现整个区域一致且稳健的无线覆盖。

选项 A 错误。虽然高质量的设备至关重要，但最的接入点并不总是能保证最佳结果。位置和环境对无线性能起着至关的作用。

选项 C 错误。在窗户附近部署接入点可能会导致信号泄漏，可能使信号覆盖到预期区域之外，并产生安全风险。

选项 D 错误。虽然确保用户拥有 5GHz 设备是一项良好的实践，但它与无线接入点的最佳安装没有直接关系。

问题 92。一名客户对曾签署过数字合同产生争议。服务提供商需要证明该签名确实来自客户且未被篡改。服务提供商依赖于以下哪种安全概念？

- (A) 身份验证
- (B) 机密性
- (C) 不可否认性
- (D) 访问控制

解释 92. 正确答案：C. 不可否认性。不可否认性确保一方不能否认其行为。在这种场景中，它将提供证明客户签署了合同且合同未被篡改。

**选项 A 错误。** 身份验证确认了用户或系统的身份。虽然它在确保正确的人访问系统方面起了作用，但它没有提供证据。

**选项 B 错误。** 机密性确保信息只有具有适当权限的人才能访问。它不提供关于所执行操作的证据。

**选项 D 错误。** 访问控制决定谁可以查看或使用资源。它不能确保操作的有效性。

问题 93。一家软件公司最近发现在其流行的应用程序中存在一个漏洞，该漏洞允许未经授权访问用户数据。在公司发布补丁之前，一组黑客利用了该漏洞，但仅是为了通知用户这一点。他们没有滥用任何数据。该小组行为背后最可能的动机是什么？

- (A) 通过出售数据获取财务利益
- (B) 对软件公司的政治观点
- (C) 对用户隐私和安全的伦理考虑
- (D) 破坏软件公司服务的欲望

解释 93. 正确答案：C. 对用户隐私和安全的伦理考虑。黑客没有滥用数据，而是选择通知用户该漏洞，表明他们的动机是基于伦理考虑，确保用户意识到潜在威胁。

选项 A 错误。黑客没有出售或滥用数据，这意味着财务利益并不是他们的主要目标。

选项 B 错误。没有迹象表明黑客的行动是由针对软件公司的政治观点驱动的。

选项 D 错误。虽然黑客利用了漏洞，但他们的目的并不是破坏公司的服务，而是通知用户漏洞。

问题 94。一家医疗机构遭受了泄露，高知名患者的医疗记录被提取。这些数据没有被出售或公开。相反，某些个人获得了其个人健康信息，并被勒索金钱。这种网络攻击背后的主要动机是什么？

- (A) 暴露医疗领域漏洞的政治活动

- (C) 通过针对性勒索获取财务利益
