

问题 494。某组织正在为数字签名选择一种哈希函数。他们希望确保该函数能够抵抗攻击者产生两个具有相同哈值的不同消息。他们正试图防御哪种攻击？

- (A) 侧信道攻击 (Side-channel Attack)
- (B) 重放攻击 (Replay Attack)
- (C) 生日攻击 (Birthday Attack)
- (D) 仅密文攻击 (Ciphertext-only Attack)

解释 494。正确答案：C。生日攻击。在生日攻击中，攻击者利用概率论中生日问题的数学原理，试图找到产生相同输出（或哈值）的不同输入。在为数字签名选择哈希函数时，选择一个抵抗生日攻击的函数对于维护签名的完整性关重要。

选项 A 错误。侧信道攻击涉及从加密系统的物理实现获取信息，而不是利用算法或协议的理论缺陷。它与产生两个相同哈值的消息无关。

选项 B 错误。重放攻击涉及拦截数据（如登录会话）然后重新发送或重放以获得未经授权的访问。它不关注哈希值的匹配。

选项 D 错误。在仅密文攻击中，攻击者拥有密文并尝试在不知道密钥的情况下推导出明文。该场景并未描述此类攻击。

**问题 495。** 在 ExamsDigest，员工可以访问公司的云端存储系统。然而，对存储器中某些文件的访问取决于员工的部门、职位和工作年限。例如，财务部门工作年限超过五年的高级经理可以查看公司的财务预测。ExamsDigest 正在使用哪种访问控制模型？

- (A) 基于规则的访问控制 (RAC)
- (B) 基于角色的访问控制 (RBAC)
- (C) 基于属性的访问控制 (ABAC)
- (D) 任意裁量访问控制 (DAC)

**解释 495。正确答案：C。基于属性的访问控制 (ABAC)。** 基于属性的访问控制 (ABAC) 根据用户、资源和环境的属性来决定访问。在场景中，员工的部门、职位和工作年限是决定他们访问特定文件的属性。

**选项 A 错误。** RAC 根据预定义的规则工作，通常不涉及部门或职位等多个用户属性。

**选项 B 错误。** 虽然 RBAC 在功能上相似，但它是基于角色（如“经理”或“职员”）分配权限，而不是基于属性的组合。

**选项 D 错误。** DAC 允许资源所有者根据其裁量指定谁可以访问其资源。它不涉及属性组合来决定访问。

问题 496。在最近的系统升级后，CloudTech Corp 决定验证其新数据处理系统的效率和可靠性。为了做到这一点，他们在旧系统旁边运行新系统并比较结果。通过方式，他们他们确保新系统既健壮又能处理当前的工作负载。CloudTech Corp 正在利用哪种测试？

- (A) 负载测试 (Load Testing)
- (B) 故障转移测试 (Failover Testing)
- (C) 并行处理测试 (Parallel Processing Testing)
- (D) 模拟测试 (Simulation Testing)

**解释 496。正确答案：C。并行处理测试。** 并行处理测试涉及同时运行两个系统（通常是新旧两个系统）以比较结果。这种测试确保了新系统与之前的系统一样有效且可靠。

**选项 A 错误。** 负载测试检查系统处理预期交易量的能力，并查看其是否能保持接受的响应时间。

**选项 B 错误。** 故障转移测试是为了确保系统在故障时可以切换到备份或备系统，而不是比较两个系统的一致性。

**选项 D 错误。** 模拟测试涉及创建一个被测系统的模型并使用虚拟用户或设备对其进行刺激，以理解其在不同条件下的行为。

**问题 497。** SecureNet Inc 最近升级了他们的安全基础设施。为了在不将系统暴露于实际风险的情况下验证新系统在真实场景中的响应，他们决定在受控环境中模仿某些网络威胁。SecureNet Inc. 计划进行哪种类型的测试？

- (A) 渗透测试 (Penetration Testing)
- (B) 模拟测试 (Simulation Testing)
- (C) 漏洞评估 (Vulnerability Assessment)
- (D) 故障转移测试 (Failover Testing)。

**解释 497。正确答案：B。模拟测试。** 模拟测试涉及创建一个被测系统的模型，然后使用虚拟用户或设备对其进行刺激，以理解其在不同条件下的行为。在网络安全背景下，这意味着在受控环境中模仿网络威胁以评估安全基础设施的响应。

**选项 A 错误。** 渗透测试涉及道德黑客试图突破组织的防御体系，这涉及实际风险，而不仅仅是模拟。

**选项 C 错误。** 漏洞评估识别、量化并优先考虑系统中的漏洞，但并不一定在受控环境中模仿威胁。

**选项 D 错误。** 故障转移测试确保系统在故障时可以切换到备份或备系统，且不关注模拟威胁。

问题 498。一个营销团队正在合作开展一项新活动，并需要访问共享文件夹的权限。然而，他们不应该能够修改他人创建的文件。应该如何对此共享文件夹上设置权限？

- (A) 为营销团队分配完全控制
- (B) 允许营销团队只读访问
- (C) 为营销团队分配只写访问
- (D) 为营销团队分配修改权限但拒绝删除权限

解释 498。正确答案：D。为营销团队分配修改权限但拒绝权限。通过提供修改权限但拒绝删除权限，团队成员可以创建和编辑自己的文件，但无法删除或修改他人文件。

选项 A 错误。完全控制允许团队成员修改或删除任何文件，这不符合要求。

选项 B 错误。只读访问将阻止团队成员创建或编辑任何文件。

选项 C 错误。只写访问将阻止团队成员查看现有文件。

问题 499。某组织的电子商务平台发生了数据泄露，攻击者利用了一个已知漏洞。事后分析显示，在泄露发生两个月前就有该漏洞的补丁可用但未应用。以下哪些措施对于防止此类泄露**最有效**？

- (A) 实现更强的用户验证方法
- (B) 加强网络监控以检测恶意活动迹象
- (C) 及时应用可用补丁
- (D) 迁移到另一个电子商务平台

解释 499。正确答案：C。及时应用可用补丁。补丁由软件供应商开发以解决软件中的已知漏洞。及时应用这些补丁对于确保系统免受已知威胁至关重要。在这种场景中，应用可用补丁将直接解决被利用的漏洞。

选项 A 错误。虽然实现更强的用户验证方法可以增强安全性，但它不能直接缓解一个可以在无需身份验证的情况下被利用的软件漏洞。

选项 B 错误。增加网络监控可以帮助检测恶意活动，但不能防止对已知软件漏洞的利用。

选项 D 错误。迁移到另一个平台是一个激进措施，可能会引入新的漏洞，除非配合良好的补丁管理实践，否则无法确保安全性。
