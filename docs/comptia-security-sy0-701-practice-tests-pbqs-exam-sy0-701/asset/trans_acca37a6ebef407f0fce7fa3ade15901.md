**问题 512。** 某组织最近的一台工作站遭受了恶意软件感染。一名安全分析师被要求审查受感染系统的端点日志，以收集更多关于该事件的信息。端点日志中的以下哪项最能指示初始的恶意软件感染点？

- (A) 显示用户成功登录和注销事件的日志
- (B) 显示系统健康检查状态为“OK”的条目
- (C) 记录最近从临时目录安装并执行的未知 .exe 文件的日志
- (D) 详细说明到域控制器网络连接性检查的条目

解析 512. 正确答案：C. 记录最近从临时目录安装并执行的未知 .exe 文件的日志。记录了未知 .exe 文件安装和执行（尤其是从从临时目录执行）的端点主机是潜在恶意活动的强有力指标。此类日志可以确定系统上恶意软件的初始感染点。

选项 A 错误。用户登录和注销事件是常规日志，除非与其他可疑活动相关，否则不会提供有关恶意软件感染的特定信息。

选项 B 错误。系统健康检查状态条目旨在提供系统健康的一般信息，并未说明与恶意软件相关的系统操作或更改。

选项 D 错误。到域控制器的网络连接性检查在许多网络环境中是常态，并不会直接指示恶意软件活动。

**问题 513。** 一名安全分析师正在审查 IPS 日志，发现有多个警报源自单个 IP 地址，该地址尝试访问不同的公司服务器。分析师试图确定攻击的类型。以下哪条日志记录最能指示端口扫描活动？

- (A) 在短时间内对不同端口进行多次连续连接尝试
- (B) 每 3 秒对 Web 服务器的 80 端口进行重复连接尝试
- (C) 从同一 IP 地址对 FTP 服务器进行多次失败登录尝试
- (D) 每 5 秒对网络网关进行持续 ping

# 解析 513. **正确答案：A. 在短时间内，对单台服务器上的不同端口进行多次连续连接尝试。**

端口扫描是一种攻击者探测服务器或主机以确定正在运行哪些服务的活动。对各种端口的快速连接尝试表明，攻击者正试图发现开放端口及其上面运行的服务。

**选项 B 错误。** 虽然对单个端口的重复连接尝试可能很可疑，但它并不是端口扫描。这可能指示 DoS 攻击。

**选项 C 错误。** 多次失败登录尝试表明 FTP 服务器可能遭受了暴力破解攻击，而不是端口扫描。

**选项 D 错误。** 定期向网络网关发送 ping 可能是网络制图或检查连接性的指示，但并不意味着端口扫描活动。

**问题 515。** GreenTech 一家数据中心公司计划在一个频繁停电的地区扩张其业务。为了维持安全态势并确保运营连续性，关于电力，以下哪项应该是他们的首要考虑因素？

- (A) 使用节能服务器以降低电力成本
- (B) 设置太阳能板以促进绿色能源
- (C) 投资冗余电源和不间断电源系统 
- (D) 仅在白天运行业务以利用自然光

解析 515. 正确答案：C. 投资冗余电源和不间断电源系统。鉴于该地区频繁停电，拥有冗余电源和 UPS 可以确保操作平稳进行，避免导致系统崩溃、数据损坏或安全泄露。

选项 A 错误。虽然节能服务器可以降低成本，但它们没有解决停电和维持运营的首要问题。

选项 B 错误。太阳能板促进了绿色能源，但在夜间或阴天可能无法提供持续且即时的电力备份。

选项 D 错误。将运营限制在白天对于数据中心来说是不可行的，因为它限制了运营能力，并且没有直接解决停电问题。

**问题 516。** 一家中型企业在经历一系列恶意软件感染后，对其办公工作站的安全表示担忧。作为一名安全分析师，以下哪些建议最能提高工作站的安全基线？

- (A) 安装多个杀毒软件以确保最大的检测率
- (B) 设置带有网络安全卫生提示的屏幕保护程序以教育用户
- (C) 禁用工作站上不必要的和服务端口
- (D) 频繁更换桌面壁纸以防止单调

解析 516. **正确答案：C. 禁用工作站上不必要的和服务端口。** 通过禁用不必要的和服务端口，可以减少潜在的攻击向量和漏洞，从而提高工作站的安全基线。

选项 A 错误。安装多个杀毒软件可能会导致冲突并降低系统性能。最好使用一个强大且持续更新的杀毒解决方案。

选项 B 错误。虽然网络安全卫生提示具有启发性，但它们对工作站的技术安全基线没有直接贡献。
