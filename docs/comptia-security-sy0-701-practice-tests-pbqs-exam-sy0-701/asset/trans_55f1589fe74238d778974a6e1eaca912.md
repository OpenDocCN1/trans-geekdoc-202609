问题 19。在一家新建的博物馆中，管理层希望在展厅安装传感器，以检测下班时间后的任何未经授权的移动。这些房间通常充满了空调声和来自城市的外部杂音。在这种情况下，哪种传感器最适合检测移动，而不受噪声影响？

- ((A) 声学传感器
- ((B) 玻璃破碎检测器
- ((C) 超声波传感器
- ((D) 热成像摄像头

**解释 19. 正确答案：C. 超声波传感器。** 超声波传感器发射高频声波来检测运动。这些声波超出了人类听力范围，不受环境噪声的影响，使其成为噪声条件变化环境的理想选择。当检测到运动时（如反射波的变化所示），就会触发警报。

**选项 A 是错误的。** 声学传感器检测特定的声音。来自城市的外部噪声可能会导致误报或干扰其检测能力。

选项 B 是错误的。玻璃破碎检测器设计用于检测玻璃破碎时的声音或或振动。它们的首要设计目的不是为了检测移动。

选项 D 是错误的。热成像摄像头检测热信号特征，并且可能对空调引起的温度变化更敏感，从而导致误报。

问题 20。一家公司正在其总部与远程分机构之间建立一个安全的通信通道。为了确保通过该通道传输的数据源自分机构的合法系统，公司正在考虑使用数字证书。该公司正在考虑哪种系统身份验证方法？

- ((A) Kerberos 身份验证
- ((B) 基于密码的身份验证
- ((C) 基于证书的身份验证
- ((D) 基于生物识别的身份验证

**解释 20. 正确答案：C. 基于证书的身份验证。** 基于证书的身份验证使用数字证书来验证系统或个人的身份。在给定场景中，公司希望验证通过通信通道传输的数据源自合法系统，因此数字证书是一个合适的选择。

选项 A 是错误的。Kerberos 身份验证是一种基于票的身份验证协议，主要用于验证网络中的用户，而不是专门用于使用数字证书的系统间身份验证。

**选项 B 是错误的。** 基于密码的身份验证要求系统或用户提供秘密密码来证明其身份。它不涉及数字证书的使用。

**选项 D 是错误的。** 基于生物识别的身份验证涉及使用人的独特物理或行为属性进行验证，例如指纹或面部特征。它不适用于系统间的身份验证。

问题 21。一家金融机构经历了未经授权交易的增加。他们希望实施一种控制措施，允许他们实时识别可疑交易。以下哪项是此场景的最佳检测控制 (detective control)？

- ((A) 为所有用户实施多因素身份验证系统
- ((B) 建立安全运营中心 (SOC) 以监控网络流量
- ((C) 在网络上安装入侵检测系统 (IDS)
- ((D) 将交易功能限制在少数几个信任的 IP 地址上

**解释 21. 正确答案：C. 在网络上安装入侵检测系统 (IDS)。** 入侵检测系统 (IDS) 通过监控网络流量中的可疑活动和潜在威胁充当检测控制。在这种情况下，它可以配置为检测与未经授权交易相关的模式，从而允许及时干预。

**选项 A 是错误的。** 实施多因素身份验证系统是一种预防控制 (preventive control)，通过要求两个或多个验证方法提供额外的安全层。虽然它减少了未经访问的风险，但它不能检测可疑交易。

**选项 B 是错误的。** 建立安全运营中心 (SOC) 是处理安全事件的广泛方法，虽然它可以包含检测控制，但仅仅建立 SOC 并不能对未经授权交易提供特定的实时检测。

**选项 D 是错误的。** 将交易功能限制在少数几个信任的 IP 地址上是一种预防控制，限制了潜在交易的来源。虽然它可以减少未经授权交易的数量，但它无法检测它们。

问题 22。TechHaus 最近经历了多次安全违规，未经授权的人员在下班后进入了他们的服务器房。为了增强安全措施，公司决定部署一个新系统。以下哪个选项即使在完全黑暗的情况下也能根据体热检测入侵者？

- ((A) 安装带有 LED 灯光的摄像头
- ((B) 使用超声波运动传感器
- ((C) 部署红外 (IR) 传感器
- ((D) 在入口实施 RFID 读卡器

# 解释 22. 正确答案：C. 部署红外 (IR) 传感器。** 红外 (IR) 传感器检测红外辐射，例如人体发的热量。这使得它们在检测人类入侵者方面特别有效，即使在完全黑暗的情况下（基于体热）。

选项 A 是错误的。虽然带有 LED 灯光的摄像头可以提供视觉监控，但它们依赖光来产生图像，可能不如红外传感器那样高效地检测完全黑暗中的入侵者。

选项 B 是错误的。超声波运动传感器通过声波检测运动，而不是体热，这使得它们在区分人类入侵者和其他移动物体时效率较低。

选项 D 是错误的。RFID 读卡器控制入口处的访问，但不会根据设施内部的体热检测人类入侵者。
