## 问题 276. 一家制药公司正在研发一种新药物配方，该配方有望彻底改变某种疾病的治疗方法。研发团队拥有关于药物试验的成分、程序和结果的详尽文档。应该如何对这些文档进行分类，以确保只有公司内部正确的人员才能访问？

- (A) 未分类
- (B) 公开
- (C) 机密
- (D) 敏感

## 解释 276. 正确答案：C. 机密。这种药物配方及其文档代表了该制药公司的价值知识产权。为了防止盗窃、企业间谍活动或意外泄露，应将其分类为机密，以确保有限且受控的访问。

选项 A 是错误的。未分类的数据不需要任何特殊保护或机密性，对于高价值知识产权来说是不合适的。

选项 B 是错误的。公开分类会让所有人都能访问信息，这对于专有药物配方并不合适。

选项 D 是错误的。虽然药物配方是敏感信息，但“机密”分类提供了更严格的控制，更适合此类高价值知识产权。

## 问题 277. 一家软件开发公司维护着一个共享代码库。公司希望确保只有开发者可以对代码进行更改，但测试人员应该查看代码而不进行修改。应该实施哪种方法？

- (A) 为所有员工分配只读权限
- (B) 为测试人员提供管理员权限
- (C) 实现基于角色的访问控制 (RBAC)
- (D) 对存储库使用数据加密

## 解释 277. 正确答案：C. 实现基于角色的访问控制 (RBAC)。RBAC 根据组织内的角色分配权限。可以给开发者分配一个允许修改代码的角色，而给测试人员分配一个仅允许读取代码的角色。

选项 A 是错误的。为所有员工分配只读权限将阻止开发者对代码进行必要的更改。

选项 B 是错误的。为测试人员提供管理员权限将赋予他们比需要更多的访问权限，可能允许他们修改代码。

选项 D 是错误的。虽然数据加密确保了数据的机密性，但它没有解决针对不同用户角色特定权限级别的需求。

## 问题 278. 一家软件开发公司刚刚扩大了团队，希望确保在发生灾难时，他们可以在一天内恢复运营。然而，他们的灾难恢复预算有限。以下哪种灾难恢复站点类型最符合公司的需求？

- (A) 具有小时级数据同步的热地 (Hot site)
- (B) 具有每月备份的冷地 (Cold site)
- (C) 具有每日备份的温备 (Warm site)
- (D) 离线磁带备份

## 解释 278. 正确答案：C. 具有每日备份的温备 (Warm site)。对于软件开发公司在一天内恢复运营的需求，具有每日备份的温备是理想的。温备拥有设备和某种程度的数据，与冷地或仅有离线备份相比，有助于更快的恢复。

选项 A 是错误的。具有小时级数据同步的热地可能提供最快的恢复，但它也是最贵的选项，可能不符合公司的预算限制。

选项 B 是错误的。具有每月备份的冷地虽然成本较低，但可能无法满足在一天内恢复运营的需求。

选项 D 是错误的。离线磁带备份本身无法提供在灾难后恢复运营所需的设施。

## 问题 279. 一家金融机构希望确保如果攻击者获得了网络某部分的未经授权访问，将无法移动到其他敏感部分。哪种方法可以实现这一目标？

- (A) 在每个网段中部署蜜罐 (honeypot)
- (B) 实现网络隔离
- (C) 对所有流量应用加密
- (D) 为所有用户启用双重身份验证

## 解释 279. 正确答案：B. 实现网络隔离。网络隔离将网络划分为多个网段或子网。每个网段独立运行并拥有自己的安全控制。这意味着如果攻击者攻破了一个网段，他们将无法访问其他网段。

选项 A 是错误的。蜜罐是用于吸引攻击者的饵系统，但无法阻止攻击者在网络内的横向移动。

选项 C 是错误的。加密数据流量确保了机密性，但无法阻止网络内的横向移动。

选项 D 是错误的。双重身份验证加强了访问控制，但本质无法阻止网络内的横向移动。

## 问题 280. 金融分析公司 DataFin 的一个机房发生了小火灾。幸运的是，他们在大楼的另一个区域有备份，可以快速恢复。然而，管理层意识到在重大灾难中，主数据和备份可能被毁。为了这个问题，DataFin 应该考虑哪种备份策略？

- (A) 镜像备份 (Mirror Backup)
- (B) 本地存储备份 (Local Storage Backup)
- (C) 增量备份 (Incremental Backup)
- (D) 异地备份 (Offsite Backup)

## 解释 280. 正确答案：D. 异地备份 (Offsite Backup)。异地备份涉及将备份数据存储在与主数据不同的地理位置。这确保即使灾难影响了主位置，备份也是安全的并可用于恢复。

选项 A 是错误的。镜像备份是指源数据的精确副本备份。它没有指定备份的地理位置。

选项 B 是错误的。本地存储备份通常意味着备份存储在同一场所或靠近主数据的地方，这无法解决 DataFin 对重大灾难导致数据可能丢失的担忧。

选项 C 是错误的。增量备份涉及仅备份自上次备份以来更改的数据，无论存储在何。它没有解决地理隔离的问题。
