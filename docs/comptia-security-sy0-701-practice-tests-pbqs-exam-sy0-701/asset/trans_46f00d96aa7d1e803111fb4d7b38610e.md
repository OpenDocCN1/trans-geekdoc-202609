

# 模拟考试 #2

## 第 101-200 题

**第 101 题。** XYZ 公司正在实施一种新的漏洞扫描解决方案。安全团队希望有一种不需要在目标机器上安装任何软件但仍然能够识别漏洞的解决方案。他们应该选择哪种类型的漏洞扫描解决方案？

+   (A) 基于主机的入侵检测系统 (HIDS)
(B) 无代理漏洞扫描器
(C) 基于客户端的漏洞扫描器
(D) 基于主机的入侵防御系统 (HIPS)

**第 102 题。** 金融机构 FinCorp 最近采用了一种新的安全框架。在该框架中，组织网络内部的每个设备和用户都被视为在边界之外的实体，因此即使是内部内部请求，也需要经过严谨的验证过程。FinCorp 实施了哪种安全范式？

+   (A) 非军事化区 (DMZ)
(B) 网络分段
(C) 入侵检测系统 (IDS)
(D) 零信任

**第 103 题。** 一家画廊想要部署一种安全解决方案，以检测一个拥有几件雕塑的开放庭院内的活动。该空间的温度变化较大，可能会导致某些运动检测技术产生误报。在这样的情况下，哪种类型的传感器最适合确保运动检测的一致性？

+   (A) 热成像传感器
(B) 压力敏感垫垫
(C) 超声波探测器
(D) 微波运动检测器

**第 104 题。** 网络安全公司 SecureNet 正在为其企业客户实施一套入侵检测系统 (IDS)。为了最优化地检测恶意活动，IDS 应该被放置在什么位置？

+   (A) 边界防火墙之前，以捕获所有入站流量
(B) 边界防火墙和内部网络之间，以监控过滤后的流量
(C) DMZ 内部，仅监控外部服务请求
(D) 每个工作站旁，以提供个性化安全保护

**第 105 题。** AcmeBank 最近对其在线银行系统进行了业务影响分析。结果显示，银行在遭受重大财务损失和客户不满之前，该系统可以忍受最多 4 小时的停机时间。哪个概念描述了这 4 小时的时长？

+   (A) 恢复点目标 (RPO)
(B) 最大可忍停机时间 (MTD)
(C) 恢复时间目标 (RTO)
(D) 恢复时间 (TTR)

**第 106 题。** 一家金融公司希望通过拦截和检查网络流量来提高其网页浏览安全性，防止用户访问恶意网站或下载恶意软件。他们正在寻找一种可以作为客户端向其他服务器请求资源时的中间人的解决方案。该公司应该实施什么？

+   (A) 网络 IDS
(B) VPN 集中器
(C) 代理服务器
(D) 跳板服务器

**第 107 题。** 一名用户收到一条声称来自其银行的短信，提醒其账户存在未经授权的活动。信息指示用户立即点击提供的链接并验证其账户详情。用户并没有注意到银行账户有任何异常。这条短信最可能是哪种攻击的一部分？

+   (A) 短信钓鱼 (Smishing)
(B) 语音 钓鱼 (Vishing)
(C) 蓝牙劫持 (Bluejacking)
(D) 蓝牙盗取 (Bluesnarfing)

**第 108 题。** 安全分析师 Jane 收到一份报告，提到每天特定时间会出现网络变慢的情况。经过调查，她发现一个设备正在向网络泛洪大量流量，导致合法请求被丢弃。该设备可能正在执行哪种攻击？

+   (A) 分布式拒绝服务 (DDoS)
(B) ARP 毒化
(C) MAC 泛洪
(D) DNS 放大

**第 109 题。** 在一次重大事件中，一组身份不明的黑客同时对宿主城市的多处基础设施发起了网络攻击，包括交通网络、电网和电信系统。这些攻击背后没有索要赎金或任何明显的财务动机。这些行为背后最可能的动机是什么？

(A) 从数据中获取财务利益
(B) 政治目的
(C) 报复行为
(D) 引起社会混乱

**第 110 题。** 某咖啡馆提供免费的 Wi-Fi，近期报告了中间人攻击。该所有者希望通过加密协议来确保传输安全。哪种协议可以？

(A) 高级加密标准 (AES)
(B) 无线等加密 (WEP)
(C) RC4 流加密
(D) 开放无线网络

**第 111 题。** TechHive 正在对旧服务器进行。为了确保数据不被破坏，TechHive 应该采用哪种方法？

(C) 物理
(D) 碎片整理

**第 112 题。** 一家金融机构报告其每年遭受 3 次钓鱼攻击。根据此，攻击的年度发生率 (ARO) 是多少？

+   (A) 0.33
(B) 1
(C) 3

**第 113 题。** TechFlow 正在对其平台进行风险分析。如果漏洞被利用，将面临 $10,000 的修复成本，$5,000 的数据损失和15,000 的声誉损失。单次损失预期 (SLE) 是？

(C) $30,000

**第 114 题。** A 国和 B 国之间正发生领土争端。突然，B 国的关键设施，如发电厂和交通枢纽遭受了系统性的网络攻击。没有索要赎金，但攻击导致了严重的混乱。这些行为背后的最可能的动机是什么？（此处与第 109 题重复）

**第 115 题。** 一家大型公司的 IT 安全团队正在评估网络监控工具。他们需要一种不会引入潜在延迟或更改流量的解决方案。他们应该考虑哪种类型的设备？
