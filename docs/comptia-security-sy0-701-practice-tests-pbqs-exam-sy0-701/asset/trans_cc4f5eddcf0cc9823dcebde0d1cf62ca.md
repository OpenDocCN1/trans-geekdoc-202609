**解析 162.** **正确答案：C. 数据泄露恶意软件。** 数据泄露恶意软件的设计目的是从目标系统中提取敏感数据并将其传输到攻击者控制的位置。敏感数据被传输到陌生的 IP 地址这一事实指向了这种类型的恶意代码。

**选项 A 错误。** 勒索软件是一种加密受害者文件并索要赎金以恢复访问权限的恶意软件。虽然它可能涉及数据窃取，但它主要以加密和随机索要而闻名，而不是为了向外传输数据。

**选项 B 错误。** 广告软件是一种在用户计算机上显示不受愿广告的软件。虽然它可能具有侵入性且不受欢迎，但它通常不会泄露数据。

**选项 D 错误。** 键盘记录器设计用于记录计算机上的按键，可能会捕获密码等敏感数据。然而，键盘记录器的主要行为是捕获按键，而不是向外传输大量数据。

**问题 163。** 在对应用程序进行安全评估期间，Ryan 发现他能够向某个字段输入比预期更大的数据。这样做之后，他注意到应用程序变得无响应并最终崩溃。Ryan 可能发现了了哪种类型的漏洞？

- (A) 输入验证错误
- (B) 跨站脚本 (XSS)
- (C) 缓冲区溢出
- (D) 不安全的直接对象引用 (IDOR)

## **解析 163.** **正确答案：C. 缓冲区溢出。**

缓冲区溢出发生在应用程序允许输入的输入数据超过其分配的缓冲区空间内能安全处理的范围时，导致相邻内存被覆盖。这会导致应用程序崩溃，或者可能允许攻击者执行任意代码。

**选项 A 错误。** 虽然输入验证错误可以导致各种漏洞，但它是一个广泛的类别。在给定的场景中，输入比预期更大的数据的直接后果是应用程序崩溃，这直接指向了缓冲区溢出。

**选项 B 错误。** 跨站脚本 (XSS) 漏洞允许攻击者在其他用户查看的网页中注入恶意脚本。它不会因为输入过大导致应用程序崩溃。

**选项 D 错误。** 不安全的直接对象引用 (IDOR) 漏洞发生在应用程序根据用户输入直接提供对象的访问时。它不会因为输入数据过多而导致崩溃。

**问题 164。** Jake 最近在他的电脑上运行了一个从朋友那里收到的旧游戏。不久后，他发现他的一些文档被复制并进行了细微修改，而且他的系统性能正在恶化。哪种恶意软件最可能导致这些问题？

- (A) 广告软件
- (B) 木马
- (C) 蠕虫
- (D) 病毒

**解析 164.** **正确答案：D. 病毒。** 病毒是附在清洁文件上的可以复制的恶意程序，会导致产生多个副本。它们在传播过程中可以修改或损坏这些文件并降低系统性能。

**选项 A 错误。** 广告软件主要侧重于向用户投放不受愿的广告。虽然它可能很烦人，但它通常不会复制或修改文档。

**选项 B 错误。** 木马是伪装成合法程序的恶意软件。虽然它们可以执行各种恶意操作，但它们不会以所描述的方式进行自我复制或修改文件。

**选项 C 错误。** 蠕虫是跨网络传播的自我复制恶意软件。虽然它们会引起性能问题，但它们通常不像病毒那样附着于文件并修改它们。

**问题 165。** 一家电子商务公司的 IT 部门正在为一个新的在线产品库存系统配置访问控制。他们希望销售团队更新库存水平和产品详情，但不想让他们访问存储在同一系统中的财务数据。IT 部门正在应用哪种访问控制原则？

- (A) 最小权限原则
- (B) 基于角色的访问控制 (RBAC)
- (C) 强制性访问控制 (MAC)
- (D) 基于用户的访问控制 (UBAC)

**解析 165.** **正确答案：B. 基于角色的访问控制 (RBAC)。** 基于角色的访问控制 (RBAC) 根据组织内的角色分配权限。然后给个人分配角色，与该角色相关的权限决定了他们可以和不能访问什么。在这一场景中，销售团队将获得一个允许他们更新库存但限制访问财务数据的角色。

**选项 A 错误。** 虽然最小权限原则规定用户只应被赋予执行其任务所需的最小访问权限，但场景特别关注角色（销售团队）以及与该角色相关的权限，这更符合 RBAC 的定义。

**选项 C 错误。** 强制性访问控制 (MAC) 使用标签（例如分类分级）来决定访问。它比 RBAC 更严格，且场景中没有描述这种机制。

**选项 D 错误。** 基于用户的访问控制 (UBAC) 将权限直接分配给每个用户，而不是基于他们的角色。场景强调了基于角色的权限，使得 RBAC 是合适的选择。

## **问题 166。** 一家制造公司的 IT 团队正在为他们的机械设备部署一种基于 IoT 的监控系统。他们希望确保这些 IoT 设备如果受到攻击，不会影响其主公司网络。为了实现这一目标，他们应该实施什么？

- (A) 在所有 IoT 设备上安装防病毒软件
- (B) 定期补丁并更新 IoT 设备固件
- (C) 将 IoT 设备放置在专用 VLAN 上
- (D) 为设备启用多因素身份验证

**解析 166.** **正确答案：C. 将 IoT 设备放置在专用 VLAN 上。** 将 IoT 设备放在专用 VLAN（虚拟局域网）上可以确保如果它们受到攻击，也会与公司网络隔离开。

**选项 A 错误。** 许多 IoT 设备可能不支持防病毒软件，即使支持，这无法实现网络隔离。

**选项 B 错误。** 虽然定期打补丁和更新设备固件对于安全至关重要，但它不能提供与主网络的网络隔离。

**问题 167。** 一家公司使用的云端协作工具向用户显示警告：“您已在两个位置登录。”然而，用户在工作站上只有一个活动会话。安全团队首要考虑的问题是什么？

 ( (A) 用户可能正在使用多个设备
- (B) 工具设置中可能存在配置错误
- (C) 协作工具正面临故障
- (D) 账户可能存在未经授权的访问

**解析 167.** **正确答案：D. 账户可能存在未经授权的访问。** 并发会话警告（特别是当用户确定只在使用一个设备时）是潜在未经授权访问的信号。安全团队应将其视为优先事项并调查入侵迹象。

**选项 A 错误。** 虽然用户经常使用多个设备，但场景提到用户确定自己只有一个活动会话，因此这种可能性较低。

**选项 B 错误。** 虽然配置错误可能导致各种问题，但它们通常不会表现为虚假的并发话警告。

**选项 C 错误。** 协作工具的故障通常不会导致虚假的活动会话警告。

**问题 168。** 一家软件开发公司的 IT 部门希望确保在开发环境中只能执行公司批准的开发工具，防止任何未经授权或潜在有害的软件运行。IT 部门应该采用什么来实现这一目标？

- (A) 实现网络隔离
- (B) 定期进行漏洞评估
- (C) 安装状态防火墙
- (D) 建立应用程序白名单

**解析 168.** **正确答案：D. 建立应用程序白名单。** 可以确保只有特定的、预先批准的应用程序可以在开发环境中运行。这将防止任何未经授权或潜在恶意软件的执行，直接符合公司的目标。

**选项 A 错误。** 虽然网络隔离可以隔离网络的不同部分并限制潜在威胁的扩散，但它不能阻止分段内未经授权的应用程序运行。

**选项 B 错误。** 定期漏洞评估识别系统中的漏洞，但它们不会主动阻止特定应用程序的运行。
