**选项 B 错误。** 不良直接对象引用（IDOR）漏洞发生在攻击者通过操纵输入（如 URL 或表单参数）访问其无授权访问的资源时。这与操作的时机或并发性无关。

**选项 D 错误。** 跨站请求伪造（CSRF）诱骗受害者提交恶意请求。它关乎未经授权的操作，而不是由合法操作的时间问题引起的问题。

**问题 146.** 网络管理员 Maria 收到了一份报告，详细列出了公司关键服务器上的几个开放服务端口。她想要验证该报告的准确性。对于 Maria 来说，使用以下哪种工具验证发现结果最好？

- (A) 密码破解器 (Password cracker)
- (B) 端口扫描器 (Port scanner)
- (C) 入侵检测系统 (IDS)
- (D) Web 应用程序防火墙

**解释 146.** **正确答案：B. 端口扫描器。** 端口扫描器（如 Nmap）向网络上的特定端口发送数据包并监听响应。这允许扫描器确定哪些端口是开放的，并可能识别运行在这些端口上的服务。

**选项 A 错误。** 密码破解器用于识别弱密码或易破解的密码。它们不验证开放的服务端口。

**选项 C 错误。** IDS 监控网络流量以发现疑活动。虽然它可以识别潜在攻击，但它不验证开放的服务端口。

**选项 D 错误。** Web 应用程序防火墙（WAF）通过监控、过滤和阻止潜在有害的 HTTP 流量来保护 Web 应用程序。它无法验证开放的服务端口。

**问题 147.** XYZ 公司的高级主管 John 接接到一个自称来自银行欺诈部门的人的电话。通话者要求 John 通过提供发送到其注册手机的 OTP 来确认某些交易。John 可能面临什么形式的社会工程攻击？

- (A) 诱饵 (Baiting)
- (B) 问答 (Quizzing)
- (C) 语音诈骗 (Vishing)
- (D) 钓鱼网站 (Pharming)

**解释 147.** 正确答案：C. 语音诈骗。Vishing 是 voice phishing 的缩写，是指利用电话欺骗用户交出用于身份盗窃的隐私信息的行为。

语音诈骗利用信任，通过语音通话操纵受害者泄露敏感信息。攻击者通常伪装成合法实体或部门（例如银行欺诈部门），以使他们的骗局看起来真实。

**选项 A 错误。** 诱饵涉及在免费或有益下载的幌下诱导受害者下载恶意软件。

**选项 B 错误。** 问答不是一种公认的社会工程攻击类型。

**选项 D 错误。** 钓鱼网站涉及将网站流量重定向到虚假网站，通常是为了获取登录凭据。

**问题 148.** 安全分析师 Jane 收到一份关于每天特定时间发生网络变慢的报告。调查后，她发现一个设备正在向网络泛洪流量，导致合法请求被丢。该设备可能正在执行哪种攻击？

- (A) 分布式拒绝服务 (DDoS)
- (B) ARP 毒骗
- (C) MAC 泛洪 (MAC flooding)
- (D) DNS 放大

**解释 148.** **正确答案：C. MAC 泛洪。** MAC 泛洪是一种旨在用伪造的 MAC 地址填充交换机的 MAC 表直到该表溢出的攻击。一旦溢出，交换机就会像集线器一样，向网络中的所有机器广播数据包。这会导致显著的变慢和中断。

**选项 A 错误。** 分布式拒绝服务（DDoS）攻击使用多个受感染的设备向目标系统泛洪流量，通常是为了使其崩溃并离线。场景描述的是内部网络变慢，而不是对服务的外部攻击。

**选项 B 错误。** ARP 毒骗是一种在局域网上发送错误 ARP 消息的攻击。它用于将攻击者的 MAC 地址与另一个主机的 IP 地址关联。虽然它可以导致中断，但其主要意图不是泛洪网络。

**选项 D 错误。** DNS 放大是一种 DDoS 攻击，攻击者使用公开访问的 DNS 服务器向目标系统泛洪 DNS 响应流量。这与场景中描述的内部网络泛洪不符。

**问题 149.**** 大型公司的一个软件开发团队决定使用未经授权的云工具来托管和管理他们的项目。哪种威胁主体最能描述这种情况的情况？

- (A) 内部威胁 (Insider threat)
- (B) 黑客行动分子 (Hacktivist)
- (C) 影子 IT (Shadow IT)
- (D) 有组织犯罪集团

**解释 149.** 正确答案：C. 影子 IT。影子 IT 指在组织内部在未获得批准或受监管的情况下使用的任何 IT 系统或解决方案。这可能会引入漏洞，因为这些系统可能不符合组织设的安全标准。

**选项 A 错误。** 虽然软件开发团队在未经批准的情况下行动，但他们的意图是提高效率，而不是伤害组织。因此，这种情况不符合“内部威胁”的典型定义（后者通常具有恶意意）。

**选项 B 错误。** 黑客行动分子受政治或社会事业的驱动。这里没有证据表明该团队背后有政治或社会动机。

**选项 D 错误。** 虽然数据在未经授权的情况下被访问了，但没有证据表明这是有组织犯罪集团所为。目前的主要问题是未经授权使用 IT，这是影子 IT 的特征。

**问题 150.** 一家软件公司最近发现其热门应用程序存在一个漏洞，该漏洞允许未经授权访问用户数据。在公司发布补丁之前，一组黑客利用了该漏洞，但为了通知用户。他们没有滥用任何数据。该小组行为背后最可能的动机是什么？

- (A) 通过出售数据获取财务利益
- (B) 反软件公司运营的政治观点
- (C) 对用户隐私和安全的伦理考虑
- (D) 破坏软件公司服务的愿望

**解释 150.** 正确答案：C. 对用户隐私和安全的伦理考虑。黑客没有滥用数据，而是选择通知用户该漏洞，表明他们的动机是基于伦理考量，确保用户对潜在威胁有所意识。

**选项 A 错误。** 黑客没有出售或滥用数据，意味着金钱利益不是他们的主要目标。

**选项 B 错误。** 没有迹象表明黑客的行为受对软件公司的政治观点的驱动。

**选项 D 错误。** 虽然黑客确实利用了漏洞，但他们的目的并不是破坏公司的服务，而是通知用户。
