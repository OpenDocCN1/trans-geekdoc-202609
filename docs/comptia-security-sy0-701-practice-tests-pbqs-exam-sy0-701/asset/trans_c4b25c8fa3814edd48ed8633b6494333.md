## 问题 450。某大型跨公司正在调查一起潜在的内部威胁事件。一名安全分析师被要求检查存储敏感文档的 Windows 服务器的特定操作系统安全日志。日志中的以下哪项条目最可能指示了未经授权的访问尝试？

- (A) 显示 Windows 更新成功安装的日志
- (B) 显示大量登录失败尝试，随后一个用户在常规工作时间之外执行了成功登录的条目
- (C) 表明计划磁盘碎片整理任务的日志
- (D) 详细说明打印机成功连接和打印作业的条目

解释 450. 正确答案：B。显示大量登录失败尝试，随后一个用户在常规工作时间之外执行了成功登录的条目。一系列登录失败尝试后紧跟一次成功登录，特别是在常规工作时间之外，可能是暴力破解攻击或对系统进行未经授权访问尝试的有力指标。

选项 A 是错误的。Windows 更新的成功安装是例行维护活动，并不直接意味着未经授权的访问。

选项 C 是错误的。磁盘碎片整理任务是常规系统维护的一部分，不能指示未经授权的访问。

选项 D 是错误的。虽然监控打印机连接和打印作业在某些安全调查中可能相关，但它们不是未经授权访问服务器的直接指标。

## 问题 451。金融机构 ThetaTech 想要升级其高净值客户在线访问账户的身份验证系统。除了传统的密码外，他们还希望包含一种能够捕捉独特物理或行为特征的方法。他们想要哪种类型的身份验证方法？

- (A) 令牌身份验证
- (B) 地理位置
- (C) 生物识别
- (D) 智能卡

解释 451. 正确答案：C。生物识别。生物识别通过捕捉独特的物理或行为特征（如指纹、虹膜、人脸等）来验证身份。

选项 A 是错误的。令牌身份验证使用令牌（如验证令牌），不涉及捕捉物理或行为特征。

选项 B 是错误的。地理位置验证基于用户所在的物理位置，不涉及捕捉物理或行为特征。

选项 D 是错误的。智能卡是基于包含芯片的物理卡片，不涉及捕捉物理或行为特征。

## 问题 452.XYZ Corp 的安全团队计划针对潜在的数据泄露，评估其响应能力。他们认为以下哪种方法最有助于这种评估？

- (A) 实战演习
- (B) 压力测试
- (C) 红蓝对抗
- (D) 桌面演练

解释 452. 正确答案：D。桌面演练（Tabletop exercise）。桌面演练是一种模拟场景，让团队在讨论环境中探讨如何应对特定类型的安全事件，而不需要进行实际操作。

选项 A 是错误的。实战演习通常在真实环境中进行实际操作，而不仅仅是模拟讨论。

选项 B 是错误的。压力测试旨在测试系统在极端负载下的性能，而不是为了模拟响应流程。

选项 C 是错误的。红蓝对抗通过模拟攻击者和防御者之间的对抗来测试安全性，比单纯的讨论更复杂。

## 问题 453。为了防止潜在的数据泄露，安全分析师被要求确保数据的完整性。他们采取哪种措施可以实现这一点？

- (A) 加密
- (B) 启动
- (C) 磁盘碎片整理
- (D) 漏洞评估

解释 453. 正确答案：A。加密。加密通过将数据转换为密文，确保即使数据被未经授权地访问也无法读取，从而保护其完整性和安全性。

选项 B 是错误的。启动是指系统运行的过程，不确保数据完整性。

选项 C 是错误的。磁盘碎片整理是为了优化磁盘性能，不是为了确保数据完整性。

选项 D 是错误的。漏洞评估是为了识别系统中的弱点，而不是直接确保数据的完整性。

## 问题 454。某公司正在设计一种新系统以确保安全性。以下哪种访问控制模型最符合需求？

- (A) 基于角色的访问控制 (RBAC)
- (B) 任意性访问控制 (DAC)
- (C) 强制性访问控制 (MAC)
- (D) 基于属性的访问控制 (ABAC)

解释 454. 正确答案：C。强制性访问控制 (MAC)。MAC 根据对象的安全级别（如分类）来决定访问权限，而不是由所有者自主决定。

选项 A 是错误的。基于角色的访问控制 (RBAC) 是根据用户的角色分配权限的，而不是基于对象的安全级别。

选项 B 是错误的。任意性访问控制 (DAC) 允许资源所有者决定谁可以访问，这不符合强制分类策略。

选项 D 是错误的。基于属性的访问控制 (ABAC) 是根据用户、环境和资源等属性来做出访问决策的。
