选项 A 错误。虽然业务连续性计划至关重要，但它主要概述了如何管理中断，而并不一定提供供应商内部控制实践的证据。

选项 B 错误。了解供应商的客户可以提供一些背景信息，但它不能直接提供供应商内部控制实践或安全措施的证据。

选项 D 错误。公司的愿景声明提供了公司目标和价值观的概述，但没有提供关于其内部控制实践的特定证据。

问题 276. TechDynamics 是一家不断增长的科技初创公司，计划扩大业务规模并为全球客户提供服务。鉴于其客户群跨多个时区，TechDynamics 应在何时安排系统维护以确保干扰最少？

- (A) 在其总部当地时间最忙碌的时段
- (B) 根据其全球客户的高峰时段进行错峰安排
- (C) 仅在发生系统故障时
- (D) 在大多数客户的非峰时段建立固定的维护窗口

解析 276. 正确答案：D。在大多数客户的非峰时段建立固定的维护窗口。在服务于跨不同时区的全球客户时，在大多数客户最不活跃的小时段建立维护窗口至关重要。这可以最大限度地减少干扰，并确保大多数客户运营顺畅。

选项 A 错误。仅关注总部当地时间会忽略全球客户的运营时间。这种方法可能会导致其他时区客户的干扰。

选项 B 错误。虽然根据全球客户的高峰时段错峰维护看起来很合逻辑，但它可能导致维护计划变得复杂且难以管理，特别是在客户群增长的情况下。

选项 C 错误。等待系统故障再进行维护是被动的，而不是主动的。这种方法可能会导致更长时间且不可预测的停机时间，从而导致更大的干扰和潜在的安全风险。

问题 277. 一家国防承包商正在研发一种新的导弹系统。虽然详细的图纸和操作细节属于机密，但他们有一份只有少数合作伙伴和利益相关者可以查看的概述文档。该概述文档应该如何分类？

- (A) 公开 (Public)
- (B) 受限制 (Restricted)

解析 277. 正确答案：B. 受限制 (Restricted)。

当对文档或数据的访问需要限制在特定的个人组时，使用“受限制”分类。在这种情况下，只有少数合作伙伴和利益相关者允许查看概述文档，因此“受限制”是最恰当的分类。

选项 A 错误。“公开”分类允许任何人访问该文档，这不适用于此场景。

选项 C 错误。虽然“机密 (Confidential)”分类可以提供水平的保护，但它不像“受限制”那样专门地将访问限制在定义的组内。

选项 D 错误。“绝密 (Top Secret)”是一个高级别的分类，更适用于详细的图纸和操作细节，而不是概述文档。

问题 278. TechFusion 和 CodeRush 是两家独立的软件开发公司，它们正在合作一个预计将定义一种新编程语言行业标准的项目。虽然双方对共同责任有共识，但尚未建立具有法律约束力的义务。哪种类型的协议最符合他们目前的合作理解？

- (A) 服务水平协议 (SLA)
- (B) 非保密协议 (NDA)
- (C) 合作备忘录 (MOA)
- (D) 许可协议

解析 278. 正确答案：C。合作备忘录 (MOA)。合作备忘录最适用于尚未建立法律约束义务的情况。

选项 A 错误。服务水平协议 (SLA) 涉及供应商与客户之间的预期。

选项 B 错误。非保密协议 (NDA) 涉及信息的保密。

选项 D 错误。许可协议涉及软件的使用、分发或复制的权利。

问题 279. CyberSecure Corp 的安全分析师审查了一份漏洞报告，该漏洞允许攻击者上传恶意脚本。一旦这些脚本被执行，他们就可以获得应用程序的完全控制。该漏洞主要应如何分类？

- (A) 完整性漏洞 (Integrity)
- (B) 可用性漏洞 (Availability)
- (C) 远程代码执行漏洞 (Remote code execution)
- (D) 泄露漏洞 (Disclosure)

解析 279. 正确答案：C。远程代码执行漏洞允许攻击者在目标系统上运行任意命令或脚本。在场景中，该漏洞允许攻击者上传并执行恶意脚本，这与该分类一致。

选项 A 错误。虽然该漏洞会影响应用程序的完整性，但主要关注的是攻击者远程执行代码的能力。

选项 B 错误。可用性漏洞主要涉及服务或系统的中断，防止授权用户访问。场景中并未指示任何可用性的中断。

选项 D 错误。泄露漏洞涉及对信息的未经查看或访问。描述的漏洞超出了简单的泄露，允许执行脚本。

问题 280. 一家金融机构正在更新其基础设施，以确保客户财务数据不受内部和外部威胁。下列措施中，对于防止内部内部用户访问客户财务数据最有效？

- (A) 在机构网络周围部署防火墙
- (B) 为所有客户账户实施双重身份验证 (2FA)
- (C) 根据最小权限原则执行严格的访问控制
- (D) 为所有员工进行年度安全意识培训

解析 280. 正确答案：C。根据最小权限原则执行严格的访问控制。最小权限原则 (PoLP) 确保用户仅获得执行工作所需的所需的权限，不再更多。通过根据该原则执行严格的访问控制，金融机构可以最大限度地减少未经授权的内部用户访问敏感财务数据的风险。

选项 A 错误。边界防火墙更多地关注防止外部威胁，没有专门解决未经授权的内部访问。

选项 B 错误。实施双重身份验证 (2FA) 主要用于验证用户身份，不能防止已通过验证的内部用户访问数据。

选项 D 错误。虽然安全意识培训至关重要，但它不是防止内部授权访问财务数据最有效的特定措施。
