问题 217。在政治竞选期间，一个匿名团体发布了一系列包含关于候选人过去的虚假数据的文章，旨在影响选民的观点。这是典型的：

- (A) 身份冒充
- (B) 短信钓鱼 (Smishing)
- (C) 虚假信息 (Disinformation)
- (D) 诱饵攻击 (Baiting)

## 解析 217. **正确答案：C. 虚假信息。** 故意传播虚假信息以欺骗或伤害他人，特别是在政治等敏感领域，被归类为虚假信息。

虚假信息活动旨在通过将虚假信息呈现为真实来欺骗受众。在政治场景中，这可能会产生重大影响，影响民意和选举结果。

**选项 A** 错误。身份冒充涉及假装成他人进行欺骗，但场景描述并未指示该匿名团体正在冒充任何人。

**选项 B** 错误。短信钓鱼是使用短信的一种钓鱼攻击类型。它与在文章中传播虚假信息无关。

**选项 D** 错误。诱饵攻击涉及用受害者想要的东西（如免费软件）来诱导他们，以窃取其个人信息或传播恶意软件。它不涉及场景中描述的虚假信息传播。

问题 218。一家跨国公司正在考虑使用位于国外的云存储提供商来存储客户数据。该公司所在的母国家有严格的数据保护法，要求客户数据保留在其边界内。公司在选择云存储提供商时，以下哪种考虑因素**最关键**？

- (A) 从国外云存储访问数据的速度
- (B) 外国云提供商使用的加密标准
- (C) 外国云提供商是否仅提供在公司母国境内的数据存储服务
- (D) 外国云提供商的声誉和客户评价

## 解析 218. 正确答案：C. 外国云提供商是否仅提供在公司母国境内的数据存储服务。数据主权是指数字数据受其所在地国家法律约束的概念。如果公司的母国有要求客户数据留在边界内的法规，那么确保云提供商提供符合该要求的存储服务是关重要的。

**选项 A 错误。** 虽然数据访问速度很重要，但它没有解决数据主权方面的问题。

**选项 B 错误。** 虽然加密对于安全至关重要，但它不能保证符合数据主权法律。

**选项 D 错误。** 声誉很重要，但它没有直接解决数据主权的特定要求。

问题 219。BetaTech 是一家科技制造公司，希望确保其 IoT 设备可能遭到破坏不会危及其主要的制造控制系统。以下哪种方法实现这一目标最有效？

- (A) 为整个网络使用单一强效的防火墙
- (B) 为 IoT 设备定期更改密码
- (C) 将 IoT 设备与制造控制系统隔离
- (D) 为所有 IoT 设备启用自动更新

## 解析 219. 正确答案：将 IoT 设备与制造控制系统隔离。通过将 IoT 设备与主要的制造控制系统隔离，BetaTech 确保 IoT 设备的破坏不会立即使控制系统面临风险。隔离充当屏障，限制了恶意活动的潜在扩散。

**选项 A 错误。** 虽然强效的防火墙对网络安全至关重要，但它不能替代隔离，特别是在设备和风险配置各异的情况下。

**选项 B 错误。** 虽然定期更改密码可以增强 IoT 设备的安全性，但无法防止受损的 IoT 设备影响网络的其他部分。

**选项 D 错误。** 自动更新可以修复 IoT 设备中的已知漏洞，但它们无法提供隔离所提供的隔离功能，以防止破坏影响其他网段。

问题 220。一家软件公司正在开发一种新的云应用程序，客户可以在其中存储和管理其客户联系详情。存储的数据不包括财务或医疗信息，但包含电话号码和电子邮件地址。这些信息应如何分类？

- (A) 公开 (Public)
- (B) 受限制 (Restricted)
- (C) 敏感 (Sensitive)
- (D) 分类 (Classified)

## 解析 220. 正确答案：C. 敏感。电话号码和电子邮件地址被视为个人身份信息 (PII)，应分类为敏感，因为未经授权的访问可能导致隐私 {或滥用。

**选项 A 错误。** 公开分类用于供普通访问且不含机密的数据。

**选项 B 错误。** 受限制通常适用于比敏感数据更机密，例如财务或战略数据。

**选项 D 错误。** 分类是一个更通用的术语，可以涵盖多个级别的数据，包括绝密、秘密、机密。

问题 221。一家跨国公司希望允许远程员工通过互联网安全地访问公司内网。公司的主要关注点是确保传输过程中数据的机性和完整性。公司应该实施哪种解决方案？

- (A) VLAN
- (B) VPN
- (C) NAC
- (D) DMZ

## 解析 221. 正确答案：B. VPN。虚拟专用网络 (VPN) 允许远程用户通过公共互联网建立到组织内部网络的安全连接。它加密传输中的数据，确保了机密性和完整性。

**选项 A 错误。** VLAN（虚拟局域网）用于划分局域网内的网络流量，但它不提供加密或安全访问的方法。

**选项 C 错误。** NAC（网络访问控制）是一种安全解决方案，用于对尝试访问网络资源的设备执行策略，但它本身不提供跨互联网的加密。

**选项 D 错误。** DMZ（非军事化区）是一个网络网段，作为组织内部网络和不可信的外部网络之间的缓冲区。它不为远程用户提供加密。

问题 222。一家金融公司将其支付处理外包给第三方服务提供商。在了一系列欺诈交易后，发现服务提供商在传输数据时没有使用最新的加密标准。这一场景突出了供应链相关的哪种漏洞？

- (A) 供应商背景审查不足
- (B) 服务提供商过时的安全实践
- (C) 供应商提供的硬件组件缺陷
- (D) 带有后门的软件

## 解析 222. 正确答案：B. 服务提供商过时的安全实践。供应链漏洞涵盖了来自第三方供应商和服务提供商的风险。在场景中，第三方服务提供商在传输数据时未使用当前的加密标准，体现了由于服务提供商安全实践过时导致的漏洞。

**选项 A 错误。** 虽然供应商背景审查至关重要，但场景并未专门指向供应商背景的问题。它关注的是加密实践。

**选项 C 错误。** 场景没有提到硬件组件或任何相关问题。

**选项 D 错误。** 此问题涉及加密标准，而不是带有后门的软件。
