**选项 B 错误。** 虽然分段对于安全至关重要，但此场景中的主要问题是数据库缺乏密码保护，而不是它的网络位置。

**选项 C 错误。** 尽管静态加密是数据保护的最佳实践，但此处的直接问题是由于缺乏密码导致的未经访问，而不是数据库存储数据的数据泄露。

**选项 D 错误。** 入侵检测系统 (IDS)可能会更早地检测到未经授权的访问，但核心漏洞是未更改的默认配置。

**问题 192。** 一用户报告，每当他们尝试访问其在线银行网站时，都会被重定向到一个看起来完全相同但 URL 略有不同的网站。该假网站要求提供银行从未请求过的额外个人信息。用户可能遇到了哪种类型的 DNS 攻击？

- (A) DNS 隧道 (DNS Tunneling)
- (B) DNS 快速变化 (DNS Fast Flux)
- (C) DNS 缓存投毒 (DNS Cache Poisoning)
- (D) 域名劫持 (Domain Hijacking)

**解析 192.** **正确答案：C. DNS 缓存投毒。** DNS 缓存投毒（也称为 DNS 欺骗）涉及腐改 DNS 解析器中的 DNS 缓存数据，将用户重定向到恶意网站而不是实际的预期网站。

**选项 A 错误。** DNS 隧道是一种将非 DNS 流量封装在 DNS 协议中的技术。它是一种绕过网络安全的方法，但通常不会导致所描述的重定向场景。

**选项 B 错误。** DNS 快速变化涉及快速更改与域名关联联的 IP 地址，以隐藏恶意域名不被封禁，但不会导致重定向到外观相似的站点。

**选项 D 错误。** 域名劫持涉及攻击者在未经所有者许可的情况下，通过更改注册数据来获取域名的控制。虽然这可能导致类似的结果，但该场景描述的是只有某些用户被重定向的情况，而不是该域的所有访问者。

**问题 193。** Alex 最近购买了一台新笔记本电脑。在首次启动时，他注意到有多个预装的软件应用程序，其中大多数他并不认识或认为必要。考虑到其硬件规格，笔记本电脑的性能低于预期。哪种类型的软件最可能导致这种性能下降？

- (A) 勒索软件 (Ransomware)
- (B) 臃肿软件 (Bloatware)
- (C) 间谍软件 (Spyware)
- (D) 广告软件 (Adware)

**解析 193.** **正确答案：B. 臃肿软件。** 臃肿软件是指预装在新电脑上的不需要软件应用程序。这些应用程序通常消耗系统资源，导致性能下降。制造商有时为了促销目的或由于与软件提供者的合作伙伴关系而预装这些应用程序。

**选项 A 错误。** 勒索软件加密用户文件并要求支付费用以进行解密。它不会预装在新电脑上。

**选项 C 错误。** 间谍软件在用户不知情的情况下从系统中隐地收集信息。它通常不会像臃肿软件那样预装在新设备上。

**选项 D 错误。** 广告软件在计算机上自动显示或下载广告材料。虽然它可能会很令人困扰，但它通常不是随新电脑自带的旨在降低性能的预装软件。

**问题 194。** 一家大型公司的 IT 部门正在对其虚拟化基础设施进行漏洞评估。他们发现了一个潜在威胁：虚拟机（VM）内部的用户可以与主机系统交互并可能破坏它。这种漏洞通常被称为什么？

- (A) 虚拟机克隆 (VM cloning)
- (B) 虚拟机快照 (VM snapshotting)
- (C) 虚拟机逃逸 (VM escape)
- (D) 虚拟机迁移 (VM migration)

**解析 194.** **正确答案：C. 虚拟机逃逸。** 虚拟机逃逸发生在攻击者在虚拟机上运行代码，允许他们突破虚拟机的隔离环境并获得对主机系统的访问权限。

虚拟机（VM）逃逸是指对虚拟化软件漏洞的利用，允许控制虚拟机的攻击者突破其隔离环境并获得对主机系统的访问权限。这可能导致运行在同一主机上的其他虚拟机或底层基础设施面临被破坏的风险。

**选项 A 错误。** 虚拟机克隆是创建虚拟机精确副本的过程。它不涉及突破虚拟机的隔离环境。

**选项 B 错误。** 虚拟机快照涉及创建虚拟机的时间点副本，可用于备份或恢复目的。它与逃离虚拟机无关。

**选项 D 错误。** 虚拟机迁移是指将虚拟机从一台主机移动到另一台主机。它与逃离虚拟机无关。

**问题 195。** 一家著名的科技公司最近发布了一系列新路由器。一段时间后，安全研究人员发现某些路由器包含恶意芯片。这一事件可能代表什么？

- (A) 外包开发 (Outsourced development)
- (B) 安全实践不规范 (Inadequate security practices)
- (C) 硬件被破坏 (Hardware compromise)
- (D) 安全检查 (Security checks)

**解析 195.** **正确答案：C. 硬件被破坏。** 硬件破坏指的是在制造过程中向硬件引入恶意组件。

**选项 A 错误。** 外包开发涉及聘佣外部实体来创建软件或硬件。

**选项 B 错误。** 安全实践不规范并没有专门描述恶意芯片的物理插入。

**选项 D 错误。** 安全检查用于发现漏洞的过程，而不是破坏行为本身。

**问题 196。** 一家大型新闻网站在重大活动期间无法访问。日志显示来自物联网设备的巨大流量。这是哪种 DDoS 攻击？

- (A) 反射攻击 (Reflected Attack)
- (B) 僵尸网络攻击 (Botnet Attack)
- (C) 放大攻击 (Amplification Attack)
- (D) 滴水攻击 (Teardrop Attack)

**解析 196.** **正确答案：B. 僵尸网络攻击。** 僵尸网络是受控设备的网络，通常用于向目标发起大规模 DDoS 攻击。

**选项 A 错误。** 在反射攻击中，攻击者向第三方发送流量，伪装成来自受害者。

**选项 C 错误。** 放大攻击利用漏洞的服务来放大流量。

**选项 D 错误。** 滴水攻击涉及发送带有重叠负载的损坏分片以崩溃系统。

**问题 197。** 一个 Web 应用程序要求使用发送给他们的令牌进行身份验证。安全分析师 Alex 观察到，登录后如果再次提交相同的令牌，不受访问。这描述了哪种漏洞？

- (A) 跨站请求伪造 (CSRF)
- (B) 重放攻击 (Replay Attack)
- (C) 中间人攻击 (MitM Attack)
- (D) 跨站脚本 (XSS)

**解析 197.** **正确答案：B. 重放攻击。** 重放攻击（也称为回放攻击）发生在攻击者拦截数据并重新传输时。在这种场景中，Alex 能够重新使用身份令牌获取访问，表明系统没有防止令牌被多次接受的机制。

**选项 A 错误。** 跨站请求伪造 (CSRF) 是一种攻击者欺骗受害者在已认证的 Web 应用程序上执行意外操作。它不涉及重新使用身份令牌。

**选项 C 错误。** 虽然中间人攻击可能涉及拦截两个双方之间的数据，但描述的场景并不涉及攻击者实时修改或转发信息。

**选项 D 错误。** 跨站脚本 (XSS) 漏洞允许攻击者在网页中注入恶意脚本。场景没有指示任何脚本注入。
