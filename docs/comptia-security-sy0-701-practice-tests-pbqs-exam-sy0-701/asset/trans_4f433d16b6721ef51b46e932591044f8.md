**问题 118。** 一家名为 TechFlow 的公司计划生产一系列新的智能家居设备。他们选择为其设备中的一个关键组件使用单一供应商。以下哪项代表了与这一决策**最重大**的安全风险？

- (A) 与仅有的供应商进行价格谈判将具有挑战性
- (B) 如果供应商的交付时间延迟，产品发布可能会推迟
- (C) 供应商遭受攻破可能导致所有设备出现漏洞
- (D) TechFlow 将依赖供应商的保修和退货政策

解释 118. 正确答案：C。供应商遭受攻破可能导致所有设备出现漏洞。依赖单一供应商意味着该供应商端的任何安全问题都可能直接转化为使用该组件的每个设备的漏洞。

在供应链中，每个实体的安全都是至关重要的。如果一个供应商被攻破，而公司仅依赖该供应商提供关键组件，那么每个使用该组件的产品都可能受到威胁。这可能对终端用户的安全产生广泛影响，并损害公司的声誉。

选项 A 是错误的。价格谈判是业务考虑因素，与使用单一供应商带来的安全影响没有直接关系。

选项 B 是错误的。虽然交付延迟可能对业务产生影响，但它们不代表直接的安全风险。

选项 D 是错误的。保修和退货政策是运营考虑因素，但不是依赖单一供应商相关的主要的安全风险。

**问题 119。** 一位高层高管收到一封邮件，其中包含个人照片和一条信息，威胁除非向特定的加密货币地址转账大笔资金，否则将这些照片公之于。这种威胁背后最明显的动机是什么？

- (A) 为了收集竞争情报的间谍活动
- (B) 为了损害高管所在公司声誉的服务中断
- (C) 利用敏感信息进行索钱的勒索
- (D) 为了在暗网出售的数据外泄

解释 119. 正确答案：C. 利用敏感信息进行索钱的勒索。以发布个人照片换取金钱的直接威胁是勒索的典型特征。攻击者正在利用敏感信息（个人照片）来勒索资金。

**选项 A 是错误的。** 文中没有提到寻求公司秘密或竞争情报。攻击者的焦点是高管的个人照片。

**选项 B 是错误的。** 虽然发布照片可能会损害高管的声誉，但并没有显示出中断公司服务或损害其运营地位的直接意图。

**选项 D 是错误的。** 攻击者直接要求金钱以换发布照片。这与数据外泄不同，在后者中数据可能被出售或以其他方式利用。

**问题 120。** Jane 是某跨国公司的一名会计，她收到一封似乎来自公司 IT 部门的邮件。邮件使用了公司的标志、颜色和字体，敦促 Jane 点击链接以由于“可疑活动”重置密码。然而，在仔细检查时，Jane 注意到发件人邮箱地址的域名存在微小的拼写错误。这种场景描述的是哪种攻击？

- (A) 鱼叉式钓鱼
- (B) 语音钓骗 (Vishing)
- (C) 诱饵 (Baiting)
- (D) 品牌仿冒 (Brand Impersonation)

解释 120. 正确答案：D. 品牌仿冒。攻击者通过模仿公司品牌，试图欺骗接收者认为通信是合法的。品牌仿冒涉及模仿声誉良好的或组织的品牌，旨在让接收者认为通信是合法的。这种策略常用于钓鱼邮件。

选项 A 是错误的。鱼叉式钓鱼是针对特定个人或小群体，这种攻击的定义特征是其针对性。

选项 B 是错误的。语音钓骗涉及电话通话，而该场景描述的是基于电子邮件的攻击。

选项 C 是错误的。诱饵通常提供某些诱人的东西来诱导受害者，该场景中并没有提供或诱饵。

**问题 121。** 在一次例行扫描中，一家设计公司的安全团队发现一名员工从邮件中下载了一个图像，随后检测到来自该工作站的异常网络流量。该图像在打开时看起来正常。这种情况可能使用了哪种攻击？

- (A) 图像隐术恶意软件
- (B) 密码破解
- (C) 钓鱼
- (D) 端口扫描

解释 121. 正确答案：A. 图像隐术恶意软件。隐术是将文件、消息、图像或视频隐藏在另一个文件、消息、图像或视频中的做法。图像隐术专门将恶意代码隐藏在图像中。当下载或打开图像时，恶意代码可以在受害者不知情的情况下执行。

选项 B 是错误的。密码破解是一种攻击方法，通过系统地尝试可能的字母、数字和符号组合直到找到正确密码。

选项 C 是错误的。钓鱼通常涉及欺骗性的电子邮件或消息以欺骗接收者提供信息。虽然钓鱼尝试可以使用图像，但描述的场景并未表明是为了提取信息。

选项 D 是错误的。端口扫描是尝试发现计算机上的开放端口，这可以揭示在这些端口上的服务。它不涉及图像的使用。

**问题 122。** Acme 公司是一家大型组织，近期与 Zenith MSP 签署了 IT 管理和支持合同。Acme 公司的首席安全官（CISO）担心与这一新关系相关的安全风险。在供应链中使用托管服务提供商（MSP）时，以下哪项是主要的安全关注点？

- (A) 由于集成新技术导致成本增加
- (B) 确保一致补丁管理的困难
- (C) 未授权访问公司资源的可能性
- (D) 外包导致 IT 士气下降

解释 122. 正确答案：C. 未授权访问公司资源的可能性。托管服务提供商为了提供服务通常拥有较高的权限，这可能使其成为攻击者的主要目标。MSP 端的攻破可能导致对其客户资源的未经访问。

当公司与 MSP 时，该提供商通常拥有访问关键系统、数据和网络基础设施以便以提供服务。如果 MSP 被攻破，可能会导致连锁反应，使客户系统和数据也面临威胁。公司确保其 MSP 具有稳健的安全态势是关重要的，以防止未经授权的访问。
