
保护。他们应该考虑哪种类型的防火墙？

- (A) 第 4 层防火墙
- (B) 第 2 层防火墙
- (C) 第 7 层防火墙
- (D) 包过滤防火墙

**解释 268.** **正确答案：C. 第 7 层防火墙。**

第 7 层防火墙通常称为应用防火墙，可以根据特定的应用程序数据、命令或功能来理解并过滤流量。它们运行在 OSI 模型的最高层，并根据流量的实际内容做出决策。

**选项 A 错误。** 第 4 层防火墙（称为传输层防火墙）主要根据端口号和协议处理数据。它们在过滤特定应用程序命令方面的效率不如第 7 层防火墙。

**选项 B 错误。** 第 2 层防火墙运行在数据链路层，主要处理 MAC 地址。它们不具备分析特定应用程序内容的能力。

**选项 D 错误。** 包过滤防火墙主要运行在网络层，根据源地址/目的 IP 地址、端口号和协议类型做出决策，而不是根据特定的应用程序内容。

**问题 269。** 一家金融机构的高安全性数据中心为其主入口配备了身份验证系统。如果系统遇到意外错误，该机构希望确保在系统修复之前，没有人可以访问数据中心。身份验证系统应该设置为哪种配置？

- (A) 故障旁路 (Fail-open)
- (B) 故障关闭 (Fail-closed)
- (C) 故障安全 (Fail-secure)
- (D) 故障被动 (Fail-passive)

**解释 269. 正确答案：B. 故障关闭。** 故障关闭（也称为故障安全）是一种模式，如果系统发生故障，它默认拒绝所有请求，从而有效地“关闭”访问。在高安全性环境中，通常优于这种模式以防止系统故障期间发生任何未经授权的访问。

**选项 A 错误。** 故障旁路与该机构的需求相反。在故障旁路场景下，如果系统故障，它将默认允许所有请求。

**选项 C 错误。** 虽然“故障安全”是“故障关闭”的另一个术语，但在选项中同时使用这两个术语可能会误导考生。在这种语境下，选项 B 是更合适的选择。

**选项 D 错误。** 故障被动在身份验证失败模式的背景下并不是标准术语。故障旁路和故障关闭（或故障安全）是主要的认可术语。

**问题 270。** 一家跨国公司希望其远程员工能够通过互联网安全地访问公司内部网。公司主要关注的是确保传输过程中的数据机密性和完整性。公司应该实施哪种解决方案？

- (A) VLAN
- (B) VPN
- (C) NAC
- (D) DMZ

**解释 270. 正确答案：B. VPN。** 虚拟专用网络（VPN）允许远程用户通过公共互联网建立到组织内部网络的安全连接。它会加密传输中的数据，确保了机密性和完整性。

**选项 A 错误。** VLAN（虚拟局域网）用于划分局域网内部的网络流量，但它不提供加密或安全访问的方法。

**选项 C 错误。** NAC（网络访问控制）是一种安全解决方案，对尝试访问网络资源的设备强制执行策略，但它本身并不提供跨互联网的加密通信。

**选项 D 错误。** DMZ（非军事化区）是作为组织内部网络与不可信外部网络之间缓冲的网段。它不为远程用户提供加密通信。

**问题 271。** 在进行业务影响分析后，一家当地图书馆确定他们可以承受数天的停机，而不会对其运营产生重大影响。他们希望有一种能够在成本和恢复能力之间取得平衡的灾难恢复解决方案。哪种站点考虑最符合图书馆的需求？

- (A) 备有全套 IT 设备的移动站点
- (B) 每日数据复制的热备站点
- (C) 冷备站点 (Cold site)
- (D) 每周备份的温备站点

**解释 271. 正确答案：C. 冷备站点。** 冷备站点是一个预先配置的远程设施，用于接收设备和数据备份，但自身不具备任何设备。考虑到图书馆对数天停机的容忍度，冷备站点是最合适的。

**选项 A 错误。** 备有全套 IT 设备的移动站点对于他们的容忍度来说，可能比需要的昂贵。

**选项 B 错误。** 每日数据复制的热备站点考虑到图书馆的容忍度，其成本超过了他们的承受能力。

**选项 D 错误。** 每周备份的温备站点可能无法为他们的需求提供足够频繁的数据同步。

**问题 272。** 一家在线支付网关正在评估增强信用卡数据安全性的方法。他们希望有一种能用令牌（token）替换敏感数据的解决方案。他们应该实施哪种方法？

- (A) 数据哈希 (Hashing)
- (B) 数据加密 (Encrypting)
- (C) 数据掩码 (Masking)
- (D) 数据令牌化 (Tokenizing)

**解释 272.** 正确答案：D. 数据令牌化。 令牌化涉及将敏感数据替换为非敏感等效物（称为令牌），令牌即使被盗，也没有可利用的价值。

**选项 A 错误。** 哈希产生一个不可逆转的固定大小字符串，但它不是令牌化系统。

**选项 B 错误。** 加密将数据转换为只有拥有解密密钥的人读取的格式，这并不是令牌化。

**选项 C 错误。** 掩码涉及隐藏数据的一部分（例如仅显示信用卡最后四位），但它并没有用令牌替换数据。

**问题 273。** 一家软件公司正在开发一种新的云应用程序，客户在其中存储联系详情，包括电话号码和电子邮件。这些信息应该如何分类？

- (A) 公开 (Public)
- (B) 限制 (Restricted)
- (C) 敏感 (Sensitive)
- (D) 分级 (Classified)

**解释 273. 正确答案：C. 敏感。** 电话号码和电子邮件被视为个人身份信息（PII），应分类为敏感，因为未经授权的访问可能导致隐私违反。

**选项 A 错误。** 公开分类适用于供访问的数据，不具备机密性。

**选项 B 错误。** 限制通常比敏感数据更机密。

**选项 D 错误。** 分级是一个涵盖多个安全级别的通用术语。

**问题 274。** Cybertech Corp. 正在审查其备份协议以增强安全性。他们决定在备份传输到远程位置之前，应使数据对未经授权的人不可读。哪种备份策略可以确保这一点？

- (A) 在存储备份前使用去重
- (B) 以专有格式存储备份
- (C) 在传输前加密备份
- (D) 使用标准工具压缩备份

**解释 274.** 正确答案：C. 在传输前加密备份。 加密将数据转换为只有拥有解密密钥的人读取的格式。通过在传输前加密，Cybertech Corp. 确保即使未经授权的人访问了备份数据，他们无法理解其内容。

**选项 A 错误。** 去重通过消除冗余数据减少备份所需的存储空间，但不能让数据对未经授权的人不可。

**选项 B 错误。** 使用专有格式可能会干扰某些未经授权的用户，但它没有提供加密那样的强大保护。

**选项 D 错误。** 使用标准工具压缩备份优化存储，但不确保机密性。

- (A) 对两个数据中心进行漏洞评估
- (B) 执行故障转移测试 (failover test)
