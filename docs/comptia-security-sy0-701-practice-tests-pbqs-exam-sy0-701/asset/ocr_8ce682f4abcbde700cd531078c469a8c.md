**Question 307.** A software company has developed a new product. They want to release a user manual that details how to use the software, its features, and basic troubleshooting steps. What should be the classification of this user manual?

+   (A) Confidential
(B) Restricted
(C) Public
(D) Internal

**Explanation 307.** **Correct Answer: C. Public.** A user manual is intended for all users of the software and should be easily accessible. It doesn’t contain sensitive or proprietary information about the software’s underlying code or algorithms. Hence, it should be classified as “Public.”
