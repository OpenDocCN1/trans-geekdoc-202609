问题 558. 一家大型公司正在调查一起潜在的内部威胁事件。一名安全分析师被要求检查存储敏感文档的 Windows 服务器的特定特定安全日志。日志中的以下哪项最可能指示未经授权的访问尝试？

- (A) 显示 Windows 更新成功安装的日志
- (B) 显示大量登录失败尝试，随后一个用户在非正常工作时间内成功登录的条目
- (C) 指示计划磁盘碎片任务的日志
- (D) 详细说明打印机成功连接和打印作业的条目

解释 558. 正确答案：B。显示大量登录失败尝试，随后一个用户在非正常工作时间内成功登录的条目。

一系列登录失败后跟着一个成功登录，特别是在非正常工作时间之外，是系统遭受暴力破解攻击或未经授权访问尝试的强有力指标。

选项 A 错误。Windows 更新的成功安装是例行维护活动，并不直接意味着未经授权的访问。

选项 C 错误。磁盘碎片任务是常规系统维护的一部分，不能指示未经授权的访问。

选项 D 错误。虽然在某些安全调查中，监控打印机连接和打印作业可能相关，但它们不是服务器未授权授权访问的直接指标。

## 问题 559. 一公司希望确保值班人员能够尽快检测并处理安全事件。为了实现这一目的，实施以下哪种运营安全控制最好？

- (A) 部署网络入侵预防系统 (NIPS)
- (B) 建立 24/7 安全运营中心 (SOC)
- (C) 创建公司范围的安全策略
- (D) 实现端到端数据加密

解释 559. 正确答案：B。建立 24/7 安全运营中心 (SOC)。安全运营中心 (SOC) 是一种运营控制，提供对安全事件的实时监控、检测和响应。通过 24/7 SOC，公司可以确保始终有人员处理发生的安全事件。

选项 A 错误。部署网络入侵预防系统 (NIPS) 是一种技术控制。虽然它可以防止网络上的未经授权活动，但它不能确保全天候都有人员来处理事件。

选项 C 错误。创建公司范围的安全策略是一种管理控制。它设定了安全准则和程序，但不能确保对事件进行持续监控和立即响应。

选项 D 错误。实施端到端数据加密是一种确保数据机密性的技术控制。虽然它保护了数据，但不能确保事件由值班人员实时检测和处理。

## 问题 560. AlphaCorp 的 IT 部门正在审查密码策略，并希望采用一种增强安全性的策略。以下哪种密码策略最安全？

- (A) 密码应至少为 6 个字符，无其他要求
- (B) 密码应至少为 10 个字符，并包含大写字母和小写字母
- (C) 密码应至少为 8 个字符，并包含大写字母、小写字母、数字和特殊字符
- (D) 密码应至少为 4 个字符，并包含大写和小写字母混合

解释 560. 正确答案：C。密码应至少为 8 个字符，并包含大写字母、小写字母、数字和特殊字符。此选项提供了长度和复杂性的平衡，使其更能抵抗破解破解字典攻击。

选项 A 错误。没有任何复杂性要求的 6 位密码用现代计算能力很容易破解。

选项 B 错误。虽然 10 个字符的长度是有好处，但缺乏数字和特殊字符的额外复杂性，这可以进一步增强安全性。

选项 D 错误。长度太短，即使混合了大写和小写字母，也没有为密码提供建议的安全性。

问题 561. 处理敏感客户数据的 SecureTech 公司正在重新设计其主办公室入口以增强安全性。他们希望确保即使多人尝试使用单张授权卡进入，每次也只有一个人获得访问。以下哪项可以实现此目的？

- (A) CCTV 摄像头
- (B) 人肉通道 (Mantrap)
- (C) 生物识别扫描仪
- (D) 运动检测器

解释 561. 正确答案：B。人肉通道（Mantrap），也称为安全间室，是一种物理安全访问控制，由一个带有两扇门的小型空间组成。第一扇门在第二扇门打开之前必须关闭，确保一次只能通过一个人。

选项 A 错误。虽然 CCTV 摄像头可以监控和记录活动，但它们不能在物理上防止尾随进入（tailgating）。

选项 C 错误。生物识别扫描仪根据生物特征进行验证，但不能防止尾随进入。

选项 D 错误。运动检测器可以检测移动，但不能防止使用单张授权进入。

## 问题 562. 在发生蓄意破坏事件后，某公司大楼正在考虑实施威慑潜在犯罪犯的控制。以下哪项作为威慑控制的效果最好？

- (A) 加密所有数据
- (B) 安装生物识别访问控制
- (C) 实现定期数据备份
- (D) 放置显示 24/7 监控的可见安全告示

解释 562. 正确答案：D。放置显示 24/7 监控的可见安全告示。可见安全性作为威慑，通过信号可能被检测的风险和后果来产生作用，即使实际监控并非一直开启。

选项 A 错误。加密所有数据是一种预防控制，确保未经授权的人无法访问或信息。它不能威慑蓄意破坏。

选项 B 错误。安装生物识别访问控制是一种根据独特属性限制物理访问的预防控制。它可以防止非法访问，但不能作为可见的威慑。

选项 C 错误。实施定期数据备份是一种纠正控制，旨在并在安全事件后恢复数据。它不能威慑潜在威胁。

问题 563. 在发布公司内部应用程序的新版本后，若干用户报告访问特定功能存在问题。为了调查根本原因，你决定查看应用程序日志。日志中的什么条目最直接指示与近期部署相关的软件漏洞或错误？

- (A) 显示用户身份验证成功的时间戳的条目
- (B) 详细说明应用程序完成交易数量的条目
- (C) 与所访问的功能相关的“ERROR”或“EXCEPTION”条目
- (D) 显示运行时备份操作的条目

解释 563. 正确答案：C。与所访问的功能相关的“ERROR”或“EXCEPTION”条目。在应用程序日志上下文中，标记为“ERROR”或“EXCEPTION”的条目通常表示应用程序遇到了问题。如果这些条目与用户遇到问题的功能有关，则指向与部署相关的软件漏洞或问题。
