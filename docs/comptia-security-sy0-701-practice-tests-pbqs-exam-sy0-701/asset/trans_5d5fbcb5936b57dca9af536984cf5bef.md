**问题 149。** 一所大学正寻求改造其无线网络，以为学生和教员工提供安全访问。IT 部门希望有一种利用中心化服务器验证用户凭据并与现有目录服务集成的认证方法。他们应该选择哪种认证协议？

- (A) 预共享密钥 (PSK)
- (B) 轻量级扩展认证协议 (LEAP)
- (C) 扩展认证协议-传输层安全协议 (EAP-TLS)
- (D) 共享密钥挑战

## 解析 149. 正确答案：C. 扩展认证协议-传输层安全协议 (EAP-TLS)。

EAP-TLS 通过使用数字证书对客户端和服务器进行认证提供了强大的安全性。它与 RADIUS 服务器配合工作，允许对用户凭据进行中心化管理，并与现有目录服务无缝集成。

选项 B 是错误的。虽然 LEAP 通过 RADIUS 服务器提供中心化认证，但它存在已知的漏洞，可能无法提供该大学所寻求的安全水平。

选项 D 是错误的。共享密钥挑战不是标准的无线认证协议。在实践中，基于共享密钥（如 PSK）的挑战如果密钥被泄露，可能会受到攻击。

**问题 151。** CyberGuard LLC 是一家网络安全公司，在行业内地位稳定，回报持续。领导层决定不追求激进的增长策略，而是选择维持目前的市场份额和运营规模。他们对微小风险持开放态度，但避免重大中断。如何最好描述 CyberGuard LLC 的风险偏好？

- (A) 扩张型
- (B) 中性型
- (C) 保守型
- (D) 激进型

**解析 151. 正确答案：B. 中性。** 中性风险偏好意味着组织既不为了高回报而激进追求风险，也不完全避免风险。鉴于 CyberGuard LLC 寻求维持现状并对微小风险持开放态度，他们的风险偏好可以归类为中性。

**选项 A 是错误的。** 扩张型风险偏好表示组织愿意接受更高的风险以获得可能更高的的回报，这与 CyberGuard LLC 的策略不符。

**选项 C 是错误的。** 虽然 CyberGuard LLC 处事谨慎，但他们的立场并非完全反对承担风险。保守型偏好意味着他们规避大多数风险，但他们对微小风险是开放的。

**选项 D 是错误的。** 激进型意味着有强烈意愿承担重大风险，这并不是描述中 CyberGuard LLC 所具备的立场。

**问题 152。** 在公司基础设施遭受一系列网络攻击后，IT 团队决定部署一种看起来像是网络合法部分，但实际上被刻意隔离并监控的解决方案。他们打算在这一隔离环境中检测并分析恶意活动。他们最可能实施哪种技术？

- (A) 网络分
- (B) 蜜罐 (Honeypot)
- (C) DMZ (非军事化区)
- (D) 沙箱 (Sandboxing)

解析 152. **正确答案：B. 蜜罐。** 蜜罐是故意设置的，看似网络的合法部分，但它是被隔离并经过严密监控的。其目的是吸引攻击者并观察他们的行为，从而对潜在威胁和对手所采用的方法提供洞察。

**选项 A 是错误的。** 网络分是将网络划分为较小的子网络。虽然这可以通过限制攻击者对特定分的访问来增强安全性，但它并不作为吸引攻击者的诱饵。

**选项 C 是错误的。** DMZ (非军事化区) 是作为互联网和组织内部网络缓冲的子网。虽然它可以包含外部用户访问的服务器，但其主要目的不是作为诱饵，而是提供一层保护。

**选项 D 是错误的。** 沙箱是一种安全机制，允许程序在独立环境中运行，以防止它们影响整个系统。它用于测试和分析潜在的恶意软件，而不是诱捕攻击者。

**问题 153。** 贵组织正在考虑与软件供应商 TechVendor Inc. 合作。在确定协议之前，您希望确保其应用程序的安全性。哪种方法可以直接评估其系统防御潜在网络威胁的健壮性？

- (A) 进行内部安全意识培训
- (B) 查看他们过去的审计报告
- (C) 实施严格的防火墙规则
- (D) 对其应用程序进行渗透测试

解析 153. 正确答案：D. 对其应用程序进行渗透测试。渗透测试是一种主动方法，通过模拟来自外部或内部恶意人员的攻击来评估应用程序的安全性。它直接衡量了应用程序中可能被攻击者利用的漏洞。

选项 A 是错误的。虽然安全意识培训对于教育员工安全最佳实践至关重要，但它不能直接评估外部供应商应用程序的安全性。

选项 B 是错误的。过去的审计报告可以提供供应商安全态势的有价值见解，但它们无法像渗透测试那样的提供实时评估。
