
正在尝试的访问代码。这可能正在尝试哪种类型的物理攻击？

- (A) 尾随 (Tailgating)
- (B) 钓鱼 (Phishing)
- (C) 暴力攻击 (Brute force)
- (D) 社会工程 (Social engineering)

**解释 180. 正确答案：C. 暴力攻击。** 暴力攻击涉及尝试所有可能的组合以找到正确的组合。日志中尝试的访问代码的顺序模式表明，攻击者正在系统地遍历所有可能的组合。

**选项 A 错误。** 尾随是指攻击者在没有适当凭据的情况下，跟随授权的人员进入安全区域。它不涉及多次电子访问代码尝试。

**选项 B 错误。** 钓鱼是一种社会工程攻击，通常涉及欺骗某人泄露其凭据或其他敏感信息。它不涉及直接的物理访问尝试。

**选项 D 错误。** 虽然社会工程确实涉及操纵个人以获得未经授权的访问，但它并不是专门针对电子系统的暴力攻击。

**问题 181。** 一家跨国公司使用加密在其分支机构之间传输敏感信息。内部审计发现，正在使用的加密算法是几年前就被弃用的算法。该组织最容易受到以下哪种加密漏洞的影响？

- (A) 生成生成缺陷
- (B) 易受攻击的弱算法
- (C) 公钥基础设施不完善
- (D) 加密密钥管理不当

**解释 181. 正确答案：B. 易受攻击的弱算法。** 当发现一个组织在使用已弃用或旧的加密算法时，意味着他们依赖的加密方法可能存在已知漏洞，或者由于计算和密码分析的进步而更容易被破解。随着时间的推移，某些算法被发现存在弱点，并被更健壮的算法所取代。

**选项 A 错误。** 场景没有说明密钥生成方面的问题，而是重点于使用过时的加密算法。

**选项 C 错误。** 场景中没有信息表明该组织的公钥基础设施存在问题。

**选项 D 错误。** 虽然密钥管理至关重要，但场景中提出的主要问题围绕着弱或过时算法的使用。

**问题 182。** 在对公司服务器进行例行审计期间，系统管理员发现其中一台关键应用程序服务器丢失了一整周的安全日志。以下哪种是发生这种情况最可能的原因？

- (A) 日志服务发生故障
- (B) 日志存储空间不足
- (C) 旨在擦除入侵痕迹的恶意攻击
- (D) 时区设置配置错误

**解释 182. 正确答案：C. 旨在擦除入侵痕迹的恶意攻击。** 攻击者在获得未经授权的访问后使用的主要策略之一是掩盖他们的踪迹。删除或更改日志是避免检测和防止任何恶意活动痕迹的常用方法。

**选项 A 错误。** 虽然日志服务发生故障是可能的，但它导致在不影响其他时间段的情况下丢失特定某周的日志的可能性较较低。

**选项 B 错误。** 存储空间不足可能会导致新日志覆盖旧日志，但通常不会导致某段离散的日志（例如整整周）丢失。

**选项 D 错误。** 时区设置错误可能会导致日志中的时间戳差异，但不会导致日志丢失。

**问题 183。** 一家零售公司的内容过滤日志显示，多次拦截了对以“.exe”结尾的文件下载 URL 的访问。源 IP 地址属于一个销售点（POS）终端。安全团队首要关注的问题是什么？

- (A) POS 终端可能运行过旧软件
- (B) 内容过滤规则可能存在配置错误
- (C) POS 终端可能已被破解并尝试下载恶意可执行文件
- (D) 公司的互联网速度太慢

**解释 183. 正确答案：C. POS 终端可能已被破解并尝试下载恶意可执行文件。** POS 终端可能已被破解并尝试下载恶意可执行文件是安全团队首要关注的问题。POS 终端不应下载恶意可执行文件。

**选项 A 错误。** 虽然 POS 终端可能运行过旧软件，但这不解释为什么下载恶意可执行文件。

**选项 B 错误。** 内容过滤规则可能存在配置错误，但被拦截的流量是。

**选项 D 错误。** 公司的互联网速度与被拦截的流量无关。

**问题 184。** Kara，一名财务分析师，开始注意到与其账户相关的异常活动。经过进一步调查，IT 发现她的电脑上有一个记录按键的程序。她的电脑上发现了哪种恶意软件？

- (A) 勒索软件 (Ransomware)
- (B) 键盘记录器 (Keylogger)
- (C) 广告软件 (Adware)
- (D) 根工具包 (Rootkit)

**解释 184. 正确答案：B. 键盘记录器。** 键盘记录器是一种捕捉并记录用户按键的恶意软件，通常会导致对用户名、密码和其他敏感信息的未授权访问。

**选项 A 错误。** 勒索软件是加密用户数据并索赎金的恶意软件。它不记录。

**选项 C 错误。** 广告软件向用户投放不受欢迎的广告。它不记录。

**选项 D 错误。** 根工具包提供计算机的隐蔽访问，允许攻击者在不被发现的情况下维持特权访问。它记录。

**问题 185。** 财务部门员工 Maya 转到了人力资源部门。IT 部门正在考虑她的访问权限。以下哪项操作最符合最小权限原则？

- (A) 保留 Maya 对财务系统的访问权限，并授予其对人力资源系统的额外访问权限
- (B) 移除所有之前的访问权限，并仅提供其对人力资源系统的访问权限
- (C) 授予 Maya 管理权限以方便她在部门间的转换
- (D) 在过渡期内将 Maya 对财务和人力资源系统的访问限制为只读

**解释 185. 正确答案：B. 移除所有之前的访问权限，并仅提供其对人力资源系统的访问权限。** 当员工从一个部门转向另一个部门时，访问需求发生了变化。为了维护最小权限原则，重新评估并调整访问权限是关重要的。Maya 不再需要财务系统，应该只有其新职位所需的资源访问权限。
