**Question 213.** A company has recently deployed a new e-commerce application. The security team wants to ensure they can detect any unauthorized or malicious activities on the application. Which of the following would be the MOST effective way to achieve this goal?

+   (A) Conduct a penetration test on the application

+   (B) Install a firewall in front of the application

+   (C) Implement continuous monitoring of the application's logs and activities

+   (D) Provide training to users about secure browsing habits

**Explanation 213.** **Correct Answer: C. Implement continuous monitoring of the application’s logs and activities.**
