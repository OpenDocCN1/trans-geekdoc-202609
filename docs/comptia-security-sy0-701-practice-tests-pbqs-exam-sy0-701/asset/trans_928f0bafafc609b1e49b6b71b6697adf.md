第 529 题。一家金融机构的高安全性数据中心对其主入口拥有一套身份验证系统。如果系统遇到意外错误，该机构希望确保在系统修复之前，无人能够访问数据中心。身份验证系统应该设置为哪种配置？

- (A) 故障开路（Fail-open）
- (B) 故障关闭（Fail-closed）
- (C) 故障安全（Fail-secure）
- (D) 故障失效（Fail-passive）

解析 529. 正确答案：B. 故障关闭（Fail-closed）。故障关闭（也称为故障安全）是一种模式，当系统发生故障时，它默认拒绝所有请求，有效地“关闭”访问。在高安全性环境中，通常优于这种方式以防止系统故障期间发生任何未经的访问。

选项 A 错误。故障开路与该机构的要求相反。在故障开路场景下，如果系统故障，它将默认允许所有请求。

选项 C 错误。虽然“故障安全”是“故障关闭”的另一个术语，但在选项中同时使用这两个术语可能会误导测试者。在这种背景下，选项 B 是更合适的选择。

选项 D 错误。故障失效不是身份验证失败模式背景下的一个标准术语。故障开路和故障关闭（或故障安全）是主要的认可术语。

第 530 题。安全分析师 Jane 收到一份关于网络在每天特定时间出现变慢的报告。经过调查，她发现某个设备正在向网络大量流量，导致合法请求被丢弃。该设备可能正在执行哪种攻击？

- (A) 分布式拒绝服务 (DDoS)
- (B) ARP 污染
- (C) MAC 泛洪 (MAC flooding)
- (D) DNS 放大

解析 530. 正确答案：C. MAC 泛洪。MAC 泛洪是一种攻击，旨在用虚假的 MAC 地址填充交换机的 MAC 表，直到表溢出。一旦溢出，交换机就像集线器一样向网络中的所有机器广播数据包。这会导致显著的变慢和中断。

选项 A 错误。分布式拒绝服务 (DDoS) 攻击使用多个受损设备向目标发送大量流量，通常是为了使其过载并离线。该场景描述的是内部网络变慢，而不是对服务的外部攻击。

选项 B 错误。ARP 污染是一种在局域网上发送虚假 ARP 消息的攻击。它用于将攻击者的 MAC 地址与另一个主机的 IP 地址相关联。虽然它可以导致中断，但其主要意图不是泛洪网络。

选项 D 错误。DNS 放大是一种 DDoS 攻击，攻击者利用公开访问的 DNS 服务器向目标系统发送大量的 DNS 响应流量。这不符合场景中描述的内部网络泛洪。

第 531 题。一家中型金融公司注意到一系列未经授权的交易将资金从合法账户转移到海外地区。经过调查，发现有一小组负责利用该公司交易系统中的漏洞。以下哪种动机最可能驱动该小组的行为？

- (A) 在黑客社区中寻求名声
- (B) 从未经授权的交易中获取利益
- (C) 反对金融机构的政治观点
- (D) 揭露公司投资策略的间谍活动

解析 531. 正确答案：B. 从未经授权的交易中获取利益。将资金转移到海外地区的未经授权交易表明其直接试图非法获取资金，指向了获取利益的动机。

选项 A 错误。没有证据表明该小组的行为受对认可或名声的渴望驱动。重点在于转移资金。

选项 C 错误。虽然某些小组可能针对金融机构以发表政治声明，但向海外账户的未经授权交易表明了财务动机，而非政治动机。

选项 D 错误。没有迹象表明该小组对公司的投资策略感兴趣。活动重点是转移资金，而不是收集情报。

第 532 题。A 国和 B 国正进行持续的领土争端。突然，B 国的关键基础设施设施（如发电厂和交通枢纽）遭受了系统性的网络攻击。攻击没有提出要求，但导致了严重的中断。网络攻击背后最可能的动机是什么？

- (A) 从市场中断中获取利益
- (B) 道德黑客测试漏洞
- (C) 因对 B 国政策的哲学分歧导致的中断
- (D) 削弱 B 国地位的网络战争行为

解析 532. 正确答案：D. 削弱 B 国地位的网络战争行为。考虑到领土争端的背景以及对关键基础设施的特定针对性，且没有任何赎金要求，这些攻击极可能是 A 国或其同情者为了实施的网络战争行为，旨在对 B 国施加压力。

选项 A 错误。虽然市场中断可以被利用来获取利益，但领土争端的背景和攻击的性质表明其动机与地缘政治策略有关，而非财务优势。

选项 B 错误。道德黑客通常识别并报告漏洞，而不是利用它们来造成广泛的中断。

选项 C 错误。攻击太针对针对且规模太大，不可能是仅受哲学分歧驱动的个人所为之。

第 533 题。XYZ 公司的员工 Alex 注意到公司停车场掉了一个不熟悉的 USB 闪盘。出于好奇，Alex 将该设备插入了他的工作站。几乎立即，他的杀毒软件检测到恶意软件尝试执行。Alex 可能遇到了哪种攻击？

- (A) 中间人攻击
- (B) 双生攻击 (Evil Twin)
- (C) 鱼叉式钓鱼
- (D) USB 投放攻击 (USB Drop Attack)

解析 533. 正确答案：D. USB 投放攻击。USB 投放攻击涉及将带有病毒的可移动设备（如 USB 闪盘）遗留在可能被无关人员发现并使用的地方。一旦设备插入计算机，它就可能执行恶意软件或脚本。

选项 A 错误。中间人攻击涉及攻击者在双方不察觉的情况下秘密截获并可能更改双方之间的通信。这与 USB 设备无关。

选项 B 错误。双生攻击指的是伪装成法的 Wi-Fi 访问点，其目的是监听无线通信。它不涉及 USB 设备。

选项 C 错误。鱼叉式钓鱼是通过针对特定个人或公司的欺骗性电子邮件窃取敏感信息的定向尝试。它与 USB 设备无关。
