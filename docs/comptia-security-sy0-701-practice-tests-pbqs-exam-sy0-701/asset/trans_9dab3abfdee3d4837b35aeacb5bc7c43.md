**解析 400。正确答案：C。勒索软件攻击。** 索软件是一种恶意软件，它可以加密受害者的文件使其无法访问。攻击者随后向受害者索要赎金以换解密密钥。使用特定扩展名（如“locked”）重命名文件以及存在勒索信（如“README_TO_RECOVER_FILES.txt”）是勒索软件攻击的典型特征。

**选项 A 错误。** 病毒传播是指一种独立恶意软件计算机程序的传播，该程序通过自我复制传播到其他计算机。它通常不会重命名文件或留下可读的消息。

**选项 B 错误。** 特洛伊马是欺骗用户使其真实意图的恶意软件。虽然它可以投递勒索软件载荷，但描述的特征更直接地指向了勒索软件活动。

**选项 D 错误。** 逻辑炸弹是在满足特定条件时执行恶意功能代码，但它并不一定会留下描述的文件痕迹。
