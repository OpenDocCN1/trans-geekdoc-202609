

# 解析 41. 答案：B. 在实施强密码的基础上，额外实施生物识别认证。

生物识别认证（如指纹或面部识别）结合强密码提供了一种稳健的多因素身份验证机制，使得未经授权访问设备变得异常困难。

选项 A 错误。在社交媒体上公开宣布安全措施并不能增强设备的固性。此外，泄露过多安全实践可能会使组织面临针对性攻击。

选项 C 错误。虽然关闭蓝牙和 Wi-Fi 可以减少某些攻击向量，但它不如实施强多因素身份验证那样具有全面的安全性意义。

选项 D 错误。屏幕颜色与设备的安全性加固没有直接关系。

问题 42. 一家跨国公司正在其跨多个国家的数据中心部署一套新服务器。为了确保服务器免受潜在威胁，首先应该采取以下哪项步骤？

- (A) 建立监控系统，在出现任何异常活动时通知 IT 团队
- (B) 部署公司未来可能需要的所有软件应用程序
- (C) 使用服务器的默认配置以确保维护制造商的最佳实践
- (D) 禁用服务器上任何未使用的和服务和端口

**解析 42. 答案：D. 禁用服务器上任何未使用的和服务端口。** 在设置新服务器时，尽可能减少其攻击面至关重要。禁用未使用的和服务端口可以确保只有必要的服务运行在服务器上，从而减少潜在漏洞。

选项 A 错误。虽然监控对于安全至关重要，但在建立监控系统之前，更重要的是加固服务器以尽量减少漏洞。监控应该作为加固措施的补充。

选项 B 错误。部署公司未来可能需要的所有应用程序可能会引入不必要的漏洞和开销。最好只安装需要的程序，并保持服务器精简。

选项 C 错误。依赖服务器的默认配置是有风险的，因为它可能没有针对组织的特定需求进行定制，并且可能开放了不必要的端口或服务。

问题 43. 在事件响应期间，IT 团队发现了一种收集有关军事项目信息的恶意软件。该恶意软件将数据发送到位于国外的服务器。哪种威胁实体最可能参与了这种网络间谍活动？

- (A) 不满的员工
- (B) 国家级力量 (Nation-state)
- (C) 钓鱼诈骗者
- (D) 黑客行动主义者 (Hacktivist)

**解析 43. 答案：B. 国家级力量。** 专门针对军事项目信息并将数据发送到国外服务器的恶意软件是网络间谍活动的特征，这是国家级力量常用的战术。他们有动机收集情报，并可能对其他国家实施干扰或获取优势，特别是在军事或国防相关数据方面。

选项 A 错误。虽然不满的员工可能有损害公司的动机，但他们通常不会参与为外国国家收集军事项目信息。

选项 C 错误。钓鱼诈骗者主要侧重于欺骗个人泄露个人或财务信息。他们通常没有兴趣或资源为外国间谍活动收集特定的军事领域数据。

选项 D 错误。黑客行动主义者通常受意识形态、环境或政治事业的驱动。虽然他们可能会干扰服务或泄露信息，但为外国国家针对军事项目并不是他们活动的典型特征。

问题 44. 一家大型电子商务平台在销售高峰期面临挑战，用户涌入导致运行速度变慢和偶尔宕机。以下哪种解决方案最能提高这些高需求时段的可扩展性？

- (A) 实施集中日志系统
- (B) 采用自动伸缩云解决方案
- (C) 增加数据备份频率
- (D) 强制员工进行定期安全培训

**解析 44. 答案：B. 采用自动伸缩云解决方案。** 云解决方案中的自动伸缩根据实际需求自动调整计算资源的数量。在高峰期间，会自动增加资源以处理需求，确保系统保持可扩展性和响应能力。

选项 A 错误。集中日志系统对于监控和故障排除很有益，但它不能直接解决高峰期间的可扩展性问题。

选项 C 错误。增加数据备份频率是数据完整性和恢复的好做法，但不能直接处理扩展性问题。

选项 D 错误。定期安全培训对于公司的网络安全态至关重要，但它不解决扩展性问题。

问题 45. 一家大型企业考虑转换为更灵活、可编程的网络。他们希望将控制平面化，允许自动化配置和快速供应。他们应该考虑哪种网络架构？

- (A) VLAN（局域网）
- (B) MPLS（多协议标签交换）
- (C) VPN（虚拟专用网络）
- (D) SDN（软件定义网络）

**解析 45. 答案：D. SDN（软件定义网络）。** 软件定义网络 (SDN) 将控制平面集中，并与数据平面解耦。这允许更灵活、可编程的网络，实现自动化配置和快速供应。

选项 A 错误。VLAN 用于在物理网络内创建逻辑网络，但不提供集中控制或可编程性。

选项 B 错误。MPLS 是一种用于高性能电信网络的数据承载技术。它不实现集中控制。

选项 C 错误。VPN 设计用于可能不安全的介质上在网络之间提供安全隧道。它不提供 SDN 的优势。

问题 46. 一份审计报告显示数据中心内的几台网络交换机缺少安全配置，使其成为攻击者的目标。以下哪种加固技术最能降低与这些交换机相关的风险？

- (A) 配置端口镜像以监控网络流量
- (B) 禁用未使用的交换机端口
- (C) 在交换机之间实现负载均衡
- (D) 为了性能而增大 MAC 地址表大小

**解析 46. 答案：B. 禁用未使用的交换机端口。** 通过禁用未使用的交换机端口，你可以最大限度地减少未经授权设备或攻击者的潜在进入点。这是网络交换机加固的基础步骤。

选项 A 错误。端口镜像用于监控，不是直接的加固技术。虽然监控对安全至关重要，但它并不一定能防止未经授权。

选项 C 错误。负载均衡主要是将网络流量高效地分布在多个路径或资源上，它本身不会加固交换机。

选项 D 错误。增大 MAC 地址表大小可能会在某些情况下提高交换机性能，但它不能增强交换机抵御潜在安全的能力。
