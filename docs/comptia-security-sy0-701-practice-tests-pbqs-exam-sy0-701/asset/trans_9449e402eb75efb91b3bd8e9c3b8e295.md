## 答案 311-460

**问题 311.** 一家金融机构正在关闭其数据中心之一。鉴于所存储数据的高度敏感性，该公司希望确保无可能从存储设备中检索数据。以下哪种方法在保证数据销毁方面**最**有效？

+   (A) 用零重写

+   (B) 标准磁盘格式化

+   (C) 物理销毁

+   (D) 运行磁盘清理程序

**解析 311. 正确答案：C. 物理销毁。**物理销毁（如对存储设备进行粉碎或焚烧）可确保媒介彻底破坏，无论使用什么工具或技术，都能使数据检索变得不可能。

**选项 A 错误。** 用零重写是一种数据清理方法，但高级技术可能仍能检索出部分数据。

**选项 B 错误。** 标准磁盘格式化通常无法完全删除数据，可能会留下可以使用专用软件恢复的痕迹。

**选项 D 错误。** 磁盘清理程序设计用于通过删除临时和不必要的文件来释放空间，而不是为了安全地擦除敏感数据。

**问题 312.** 一款金融应用程序允许用户通过输入账号和转账金额将资金转移到其他账户。在安全审计期间，观察到恶意用户可以在账户字段中输入 SQL 代码以操作应用程序数据库。开发团队应该实施哪种安全技术来解决此漏洞？

(A) 代码混淆
(B) 输入验证
(C) 静态加密
(D) 会话超时

**解析 312. 正确答案：B. 输入验证。**输入验证确保应用程序仅接受有效且预期的数据。通过验证和清理用户输入，应用程序可以防止恶意数据（如 SQL 代码）被处理和执行，从而降低 SQL 注入攻击的风险。

**选项 A 错误。** 代码混淆使得攻击者更难理解应用程序代码，但不能阻止他们注入恶意输入。

**选项 C 错误。** 静态加密保护存储的数据，但它不能防止利用应用程序输入处理的 SQL 注入攻击。

**选项 D 错误。** 会话超时限制了用户会话的持续时间，但不会验证或清理用户输入。

**问题 313.** 在一系列网络攻击后，金融机构 BetaTech 决定对其整个服务器机群进行配置标准化。他们已经为服务器建立了安全的基准配置。确保服务器符合这一新基准的**下一步**应该什么？

+   (A) 频繁对所有服务器进行漏洞扫描
+   (B) 为服务器访问引入生物识别认证
**(C) 在所有服务器上部署安全基准**
(D) 监控网络流量以检测异常

**解析 313. 正确答案：C. 在所有服务器上部署安全基准。**建立安全基准后，接下来的直接步骤是将该基准部署或应用于服务器。这确保了所有服务器都从标准且安全的配置开始运行。

选项 A 错误。虽然漏洞扫描至关重要，但它更多是一个识别潜在漏洞的持续过程，并不会直接将安全基准应用于服务器。

选项 B 错误。生物识别认证虽然是一项很有价值的安全措施，但它并不能解决在服务器上部署已建立的安全基准的问题。

选项 D 错误。监控网络流量对于检测潜在威胁至关重要，但它不能直接确保在服务器上部署安全基准。

**问题 314.** 一家能源公司寻求增强其 ICS/SCADA 系统的安全性。他们意识到默认配置可能存在漏洞。确保其 ICS/SCADA 系统安全的**最佳**初始步骤是哪个？

+   (A) 将 ICS/SCADA 系统连接到互联网
+   (B) 使用现成软件进行监控
+   (C) 实施针对 ICS/SCADA 系统定制的安全基准
-   (D) 增加具有管理员权限的用户数量

**解析 314. 正确答案：C. 实施针对 ICS/SCADA 系统定制的安全基准。**

选项 A 错误。将 ICS/SCADA 系统连接到互联网会增加受到潜在威胁的风险。

选项 B 错误。虽然现成软件可能很有帮助，但它们不是加固的最佳初始步骤。

选项 D 错误。增加具有管理员权限的用户数量违反了最小权限原则。

**问题 315.** 一家跨国公司计划为其高管发放移动设备。鉴于他们处理的数据具有敏感性，哪种加固措施**最**有效以确保安全性？

(A) 定期更新公司的社交媒体
(B) 在实施强密码的基础上增加生物识别认证
(C) 不使用时关闭蓝牙和 Wi-Fi
(D) 设置设备屏幕颜色

**解析 315. 正确答案：B. 在实施强密码的基础上增加生物识别认证。**生物识别（如指纹或面部识别）结合强密码提供了一种稳健的多因素身份验证机制，使得未经授权的访问变得更加困难。

选项 A 错误。在社交媒体上公开发布安全措施并不能加固设备。此外，泄露过多安全实践可能会使组织面临性攻击。

选项 C 错误。虽然关闭蓝牙和 Wi-Fi 可以减少某些攻击向量，但它没有多因素认证那么全面。

选项 D 错误。屏幕颜色与设备的安全性没有直接关联。

**问题 316.** 一家大型电子商务公司希望确保其新开发的应用程序在部署到生产环境之前没有任何漏洞。他们希望发现可能导致安全风险的软件缺陷。他们应该采用以下哪种方法？

+   (A) 运行时应用程序保护 (RASP)
+   (B) 运行中的渗透测试
+   (C) 静态代码分析
+((D) 用户验收测试 (UAT)

**解析 316. 正确答案：C. 静态代码分析。**静态代码分析是在不执行代码的情况下分析应用程序代码，专注于检测漏洞、缺陷或其他或其他的安全威胁，因此是该场景的适用方法。

选项 A 错误。运行时应用程序保护 (RASP) 是关于对应用程序进行实时监控和保护，这在部署前识别漏洞时并不是首选方案。

选项 B 错误。运行中的应用程序渗透测试是在应用程序上线或运行后进行的测试，对于希望在部署前阶段识别漏洞的情况来说可能并不适用。

选项 D 错误。用户验收测试 (UAT) 侧重于确定软件是否满足业务需求并对终端用户运行正常。它并不强调安全漏洞。
