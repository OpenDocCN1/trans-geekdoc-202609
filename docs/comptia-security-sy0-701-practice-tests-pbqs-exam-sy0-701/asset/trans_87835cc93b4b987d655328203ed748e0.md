**问题 324。** 一位网络工程师正在为一家大型组织准备一批新路由器。工程师应该优先考虑以下哪个步骤，以确保路由器从一开始就经过了安全配置？

(A) 配置路由器使用 DHCP 为连接的设备动态分配 IP 地址

(B) 更改路由器上的默认管理员凭据

(C) 无论安全态势如何，都将路由器固件更新到最新、功能最丰富的版本

(D) 自定义路由器的 LED 颜色以便在服务器机房中识别

**解析 324. 正确答案：B. 更改路由器上的默认管理员凭据。** 路由器通常带有为人知的默认凭据，这些凭据很容易被攻击者利用。更改这些凭据对于建立安全基准至关重要。

**选项 A 错误。** 虽然 DHCP 常用于许多网络，但启用它并不一定是一种安全基准操作。此外，如果不安全配置，路由器上的 DHCP 可能被利用。

**选项 C 错误。** 在不考虑安全态势的情况下盲目更新到最新固件可能会引入漏洞。确保固件既更新又是安全的提示。

**选项 D 错误。** 自定义 LED 颜色涉及物理识别，并从本质上提高路由器的安全配置。

**问题 325。** 一所大学正寻求改造其无线网络，为学生和教职员工提供安全访问。IT 部门希望采用一种利用中央服务器验证用户凭据并能与现有目录服务集成的身份验证方法。他们应该考虑哪种身份验证协议？

(A) 预共享密钥 (PSK)
(B) 轻量级扩展身份验证协议 (LEAP)
(C) 扩展身份验证协议传输层安全 (EAP-TLS)
(D) 共享密钥挑战

**解析 325. 正确答案：C. 扩展身份验证协议传输层安全 (EAP-TLS)。** EAP-TLS 通过使用数字证书验证客户端和服务器来提供安全性。它与 RADIUS 服务器配合工作，允许对用户凭据进行集中管理并与现有目录服务无缝集成。

**选项 A 错误。** 预共享密钥 (PSK) 不涉及用于身份验证的中央服务器。相反，所有设备都使用单一共享密钥，这在大型大学环境中可能不具备扩展性或不安全。

**选项 B 错误。** 虽然 LEAP 通过 RADIUS 服务器提供集中身份验证，但它存在已知的漏洞，可能无法提供该大学所寻求的安全水平。

**选项 D 错误。** 共享密钥挑战不是标准的无线身份验证协议。在实践中，基于共享密钥（如 PSK）的挑战如果密钥泄露，可能会受到攻击。

**问题 326。** TechHive 公司计划出售其一些旧服务器。在出售之前，他们想确保硬盘上不再留任何可恢复的个人或业务数据。TechHive 应该使用以下哪种方法来确保硬盘清洁且数据无法恢复？

- (A) 简单格式化
(B) 磁消
(C) 物理破坏
(D) 标准碎片整理

**解析 326. 正确答案：B. 磁消。** 磁消（也称为去磁化）使用磁场永久地从存储设备中擦除数据。它使数据无法检索，确保即使使用先进工具也无法恢复个人和业务数据。

**选项 A 错误。** 简单格式化通常会留下数据痕迹，这些痕迹可以使用专用软件进行恢复。

**选项 C 错误。** 虽然物理破坏可以确保数据无法被检索，但它会使服务器无法转售。

**选项 D 错误。** 碎片整理是优化和组织硬盘上数据的过程，但它不会删除数据。

**问题 327。** 一家快速发展的科技公司的网络管理员对公司交换机的潜在漏洞表示担忧。以下措施在加固这些网络交换机以防止可能的攻击方面最有效的是？

(A) 为所有连接的设备分配静态 IP 地址
(B) 为交换机访问实施强密码策略
(C) 升级交换机以支持 10Gbps 以备未来扩展
(D) 自定义交换机的 LED 颜色以便识别

**解析 327. 正确答案：B. 为交换机访问实施强密码策略。** 加固交换机涉及减少对未经授权访问和潜在滥用的脆弱性。实施强密码策略可确保只有授权人员才能访问和配置交换机。

**选项 A 错误。** 虽然分配静态 IP 地址可能有助于网络管理，但它不能从本质上加固交换机免受潜在攻击。

**选项 C 错误。** 升级交换机的速度能力（例如支持 10Gbps）是性能增强，与加固或安全没有直接关系。

**选项 D 错误。** 自定义 LED 颜色与物理识别有关，不会提高交换机的安全态势。

**问题 328。** 一家机器人正在正在一种依赖实时操作系统 (RTOS) 管理运行的自动驾驶车辆。开发团队希望确保车辆的 RTOS 具有良好的安全态势。在为该 RTOS 建立安全基准时，团队应该优先考虑哪项？

- (A) 安装强效的反病毒软件
- (B) 启用所有功能以实现最大功能
- (C) 定期将 RTOS 数据备份到云端
- (D) 减少服务和开放端口的数量

**解析 328. 正确答案：D. 减少服务和开放端口的数量。**

减少和服务开放端口的数量可以减少 RTOS 的攻击面，使发现漏洞变得困难。

**选项 A 错误。** 虽然反病毒软件对于许多系统至关重要，但 RTOS（尤其是自动驾驶车辆上的系统）会优先考虑减少攻击面并确保实时性能，而不是依赖传统的反病毒解决方案。

**选项 B 错误。** 启用所有功能可能会引入不必要的漏洞。最好仅所需的功能以维护安全。

**选项 C 错误。** 虽然备份对于数据完整性和恢复至关重要，但对于 RTOS（特别是自动驾驶车辆中的），主要关注的是实时性能和减少潜在漏洞。
