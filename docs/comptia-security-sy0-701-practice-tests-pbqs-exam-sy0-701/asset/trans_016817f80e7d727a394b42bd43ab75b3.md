**解释 408. 正确答案：C. 数据外泄恶意软件。** 数据外泄恶意软件旨在从目标系统中提取敏感数据并将其传输到攻击者控制的位置。敏感数据正被传输到一个熟悉的 IP 地址这一事实指向了此类恶意代码。

**选项 A 错误。** 勒索软件是一种恶意软件，它会加密受害者的文件并索赎金以恢复访问权限。虽然它可能涉及数据窃取，但它主要以加密和索赎要求闻名，而不是将数据传输到外部。

**选项 B 错误。** 广告软件是一种在用户计算机上显示不想要的广告的软件。虽然它可能具有侵入性且不受欢迎，但通常不会外泄数据。

**选项 D 错误。** 键盘记录器旨在记录计算机上的按键，可能会捕获密码等敏感数据。然而，键盘记录器的主要行为是捕获按键，而不是向外部传输大量数据。

**问题 409。** ExamsDigest 企业想要简化他们的权限分配。他们决定与其逐个为每个用户分配权限，不如根据部门角色对用户进行分组，然后向这些组分配权限。例如，所有“营销”角色的成员都将访问营销数据库。ExamsDigest 企业正在采用哪种访问控制方法？

+ (A) 基于规则的访问控制
+ (B) 强制访问控制 (MAC)
+ (C) 任意自主访问控制 (DAC)
+ (D) 基于角色的访问控制 (RBAC)

**解释 409. 正确答案：D. 基于角色的访问控制 (RBAC)。** RBAC 涉及根据角色（在这种情况下，是如“营销”之类的部门）对用户进行分组，然后向这些角色分配权限。个人被放入这些角色中，从而决定他们的访问权限。ExamsDigest 企业 描述的场景是实施 RBAC 的典型示例。

**选项 A 错误。** 基于规则的访问控制通常处理预定义的访问规则，常见用于防火墙或路由器，而不是根据角色对用户进行分组。

**选项 B 错误。** MAC 更多关于信息分类以及让具有适当许可密级别的用户进行访问。它不涉及上述场景中的部门角色。

**选项 C 错误。** DAC 允许资源所有者授予或拒绝权限。它本身不涉及基于角色或工作功能分配权限。

**问题 410。** 一位安全管理员正在考虑一种加密解决方案，用于保护位于同一数据中心的服务器之间传输的数据。首要目标是确保加密和解密过程的速度和效率。哪种加密类型最符合这一要求？

+ (A) 使用 RSA 的非对称加密
+ (B) 使用 AES 的对称加密
+ (C) 使用结合 RSA 和 AES 的混合加密
+ (D) 使用 ECC 的非对称加密

**解释 410. 正确答案：B. 使用 AES 的对称加密。** 对称加密（如 AES）通常比非对称加密更快，所需的计算资源更少。这使得它适用于高速加密和解密至关重要的场景，例如数据中心内服务器之间传输的数据。

**选项 A 错误。** 使用 RSA 的非对称加密比对称加密更耗计算资源，对于给定的场景可能不是效率最高的。

**选项 C 错误。** 虽然混合加密可以提供安全性和速度之间的平衡，但对于描述的用例，仅使用对称加密 (AES) 更高效。

**选项 D 错误。** ECC 像 RSA 一样是一种非对称加密方法，这意味着它通常会比 AES 等对称方法慢。

**问题 411。** 一家大型电子商务公司正在部署一个新的在线支付系统。首席信息安全官 (CISO) 担心加密密钥的安全，并希望确保它们免受潜在窃盗或破坏。CISO 应该实施哪种工具来为这些密钥提供最高级别的安全性？

+ (A) 密码库
(B) 软件密钥存储
+ (C) 硬件安全模块 (HSM)
+ (D) 云加密服务

**解释 411. 正确答案：C. 硬件安全模块 (HSM)。** 硬件安全模块 (HSM) 是一种专门用于管理、保护和安全存储加密密钥的专用设备。它具有防篡改结构并提供高水平安全性，适用于加密密钥保护至关重要的环境，例如电子商务支付系统。

**选项 A 错误。** 密码库主要设计用于存储和管理密码，而不是支付系统中使用的加密密钥。

**选项 B 错误。** 软件密钥存储解决方案无法提供 HSM 所提供的相同物理安全性。

**选项 D 错误。** 虽然云加密服务可以提供加密能力，但它们可能无法提供本地 HSM 那样的物理保护和控制。

**问题 412。** 在一次安全审计期间，某公司发现恶意攻击者能够位于网络路径上，捕获客户端与服务器之间的 TLS 握手消息。攻击者的目标是通过影响密码套协商来削弱加密。这种场景描述了哪种网络攻击？

+ (A) ARP 投毒
(B) 降级攻击
(C) SYN 洪水
(D) 死亡 Ping

**解释 412. 正确答案：B. 降级攻击。** 降级攻击是指攻击者干预设置过程（例如 握手），以强制实体双方使用不安全的模式或加密标准。在这种情况下，通过捕获并可能修改 握手消息，攻击者试图使用较弱的密码套。

**选项 A 错误。** ARP 投毒是指攻击者在局域网内发送伪造 ARP 消息，将攻击者的 MAC 地址与另一个 IP 地址（如默认网关）关联。这是实现中间攻击的一种手段，但场景描述的是影响密码套协商，属于降级攻击。

**选项 C 错误。** SYN 洪水是一种拒绝服务攻击形式，攻击者向目标系统发送一系列 SYN 请求，试图消耗服务器资源。它与捕获 TLS 握手消息无关。

**选项 D 错误。** 死亡 Ping 是一种旧的攻击方式，恶意实体发送畸形或过大的 Ping 包以崩溃目标系统。它不涉及捕获或影响 TLS 握手过程。
