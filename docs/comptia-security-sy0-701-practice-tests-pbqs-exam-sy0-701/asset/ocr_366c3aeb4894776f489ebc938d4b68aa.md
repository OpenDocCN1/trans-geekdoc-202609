# Question 417. A company has set up its firewall to allow web traffic through port 80 and port 443, denying all other traffic by default. This setup is an example of which type of access control?

+   (A) Role-Based Access Control (RBAC)

+   (B) Mandatory Access Control (MAC)

+   (C) Discretionary Access Control (DAC)

+   (D) Rule-Based Access Control (RAC)

Explanation 417. Correct Answer: D. Rule-Based Access Control (RAC). Rule-Based Access Control (RAC) operates based on predefined rules by administrators. In the scenario described, the firewall is using rules to allow traffic on certain ports (80 and 443) while denying all others, making this a clear example of RAC.

Option A is incorrect. RBAC assigns permissions based on roles within an organization. Firewall rules are not typically assigned based on user roles.

Option B is incorrect. MAC involves classifying information and matching user clearance levels to these classifications. It is unrelated to firewall rule settings.
