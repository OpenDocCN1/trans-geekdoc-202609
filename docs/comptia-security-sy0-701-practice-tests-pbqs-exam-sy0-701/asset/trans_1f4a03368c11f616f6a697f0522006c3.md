- (A) DES

**解析 487。正确答案：D. AES-256.** AES-256 是高级加密标准 (AES) 家族的一部分，使用 256 位的密钥长度。这种扩展的密钥长度提供了更高的安全性，在得得当的情况下，被认为能够抵抗所有知的实际攻击。

**选项 A 错误。** DES（数据加密标准）的密钥仅为 56 位，由于其密钥较短，对于装备充足的攻击者来说，被认为是不安全的。

**选项 B 错误。** 虽然 Blowfish 是一种对称加密算法，但它较旧，且不像 AES 那样被广泛推荐用于安全交易。

**选项 C 错误。** RSA 是一种非对称加密算法，通常不直接用于加密大量交易数据。

**问题 488。** XYZ 公司的 IT 团队收到一条警报，一名员工的账户在下午 2:00 从巴黎访问了公司门户，随后在下午 2:30 从东京访问。该员工目前正在巴黎出差。此警报可能指示了什么？

- (A) 员工从巴黎快速旅行到了东京
- (B) 公司的时区设置配置错误
- (C) 员工的计算机上可能存在 VPN 配置错误
- (D) 员工的账户可能已被破解

**解析 488。正确答案：D. 员工的账户可能已被破解。** 在此语境下，“不可能旅行”（Impossible travel）指的是某人在短时间内出现在两个遥远地理位置的不寻常性。考虑到两次访问尝试的时间非常接近，员工在半小时内从巴黎旅行到东京的可能性极低。这是账户被破解的常见指标。

**选项 A 错误。** 某人在 30 分钟内从巴黎旅行到东京几乎是不可能的。

**选项 B 错误。** 时区配置错误可能会导致时间戳差异，但不会导致在如此短的时间内从两个遥远城市登录的现象。

**选项 C 错误。** 即使存在 VPN 配置错误，也无法解释会在如此短的时间内从两个不同的地理位置进行访问。

**问题 489。** Global 公司收到报告，称其部分客户收到了似乎源自公司域名的网络钓鱼邮件。IT 团队检查并确认 SPF 和 DKIM 配置设置正确。Global 公司 还可以实施何种额外的邮件安全措施，以便在邮件不符合 SPF 和 DKIM 时，提供关于如何处理这些邮件的清晰策略？

- (A) 启用 TLS 加密
- (B) 实施 DMARC 策略
- (C) 设置新的 SMTP 服务器
- (D) 延长邮件保留期

**解析 489.正确答案：B. 实施 DMARC 策略。** 通过实施 DMARC 策略，Global 公司可以定义邮件接收者如何处理来自其域名但不符合指定 SPF 和 DKIM 记录的邮件。DMARC 可以设置为监控、隔离或拒绝未通过这些检查的邮件，为防止电子邮件伪造和钓鱼提供更稳健的保护。

**选项 A 错误。** 虽然 TLS 加密对于保护传输中的邮件内容至关重要，但它没有解决伪造问题，也不会提供处理不匹配 SPF 和 DKIM 邮件的指南。

**选项 C 错误。** 设置新的 SMTP 服务器可以帮助发送邮件，但它本身并不能防止电子邮件伪造，也不会为不符合 SPF 和 DKIM 的邮件提供指导。

**选项 D 错误。** 延长邮件保留期影响邮件存储多长时间，但不能提供针对伪造的保护，也提供处理不匹配邮件的指导。

**问题 490。** 一家金融机构计划为第三方开发者提供数据库访问以创建新的应用程序。然而，他们希望确保开发者看不到实际数据，而是使用保留数据原始结构的伪版本进行工作。该金融机构正在考虑哪种技术？

- (A) 令牌化 (Tokenization)
- (B) 数据掩码 (Data masking)
- (C) 加密 (Encryption)
- (D) 数字水印 (Digital watermarking)

**解析 490.正确答案：B. 数据掩码。** 数据掩码是一种模糊处理数据库内特定数据的技术，使数据无法访问且无法使用。该方法通常用于非生产环境，以保护主体的数据隐私和数据安全。

选项 A 错误。令牌化将敏感数据替换为随机令牌，这些令牌作为原始数据的引用。

选项 C 错误。加密将可读数据转换为不可读格式以保护其机密性。它需要密钥将数据还原为原始。

选项 D 错误。数字水印将数据嵌入数字信号中，主要用于维护权利或所有权。

**问题 491。** 在查看 Web 服务器日志时，安全分析师 Sarah 注意到 URL 中存在包含“..%2F..”的请求模式。她怀疑这可能是试图利用漏洞。这很可能是哪种类型的攻击？

- (A) 命令注入 (Command Injection)
- (B) 跨站脚本 (XSS)
- (C) 目录遍历 (Directory traversal)
- (D) 跨站请求伪造 (CSRF)

**解析 491.正确答案：C. 目录遍历。** 目录遍历（路径遍历）涉及引用文件。

选项 A 错误。命令注入涉及在服务器上执行任意命令。

选项 B 错误。跨站脚本（XSS）涉及在网页中注入恶意脚本。

选项 D 错误。跨站请求伪造（CSRF）欺骗受害者提交请求。

**问题 492。** 一家金融机构将其支付处理外包给第三方提供商。在发生一系列欺诈交易后，发现该提供商在传输数据时未使用加密标准。这突出了供应链的哪种漏洞？

- (A) 供应商检查不足
- (B) 服务商过时的安全实践
- (C) 硬件组件缺陷
- (D) 软件后门

**解析 492.正确答案：B. 服务商过时的安全实践。** 供应链漏洞涵盖源自第三方供应商和服务提供商的风险。在此场景中，第三方提供商未采用加密标准是由于过时的实践导致的漏洞。

选项 A 错误。虽然供应商检查至关重要，但场景并未明确指向检查的问题。

选项 C 错误。场景未提到硬件组件或与其相关的问题。

选项 D 错误。此问题与软件后门无关。
