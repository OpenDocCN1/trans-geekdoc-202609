问题 60。一家公司正在开发一个新的视频会议工具。他们希望确保参与者之间传输的所有视频和音频数据都经过加密并防止被窃听。开发者应该实施哪种类型的加密来达到这一目标？

- (A) 端点加密 (Endpoint Encryption)
- (B) 传输层加密 (Transport-layer Encryption)
- (C) 卷级加密 (Volume-level Encryption)
- (D) 数据库级加密 (Database-level Encryption)

解析 60. 正确答案：B。传输层加密。传输层加密专门用于保护传输中的数据。通过实施这种加密，公司可以确保视频会议期间的所有视频和音频数据都是机密的，从而维护参与者的隐私。

选项 A 错误。端点加密专为笔记本电脑或手机等特定设备上的数据设计，而不是用于在网络上传输的数据。

选项 C 错误。卷级加密涉及加密特定的逻辑驱动器或卷，而不是传输中的数据。

选项 D 错误。数据库级加密保护数据库内部的数据，不特定于通过网络传输的数据。

问题 61。在发生一起重大的网络安全事件后，ABC Tech 改进了其事件响应程序。然而，文档没有更新以反映这些变化。在随后的一次小型事件中，对于应该遵循的步骤产生了困惑。以下哪项是不更新事件响应文档的**最直接**的影响？

- (A) 公司可能需要投资新的网络安全工具
- (B) 利益相关者可能会对公司处理事件的能力失去信任
- (C) 事件响应可能不一致且有效性更低
- (D) ABC Tech 可能需要聘请外部顾问进行事件响应

解析 61. 正确答案：C。事件响应可能不一致且有效性降低。如果没有反映最新事件响应程序的及时更新文档，就存在响应不一致的风险，这可能导致效率低下的和潜在的疏漏。

选项 A 错误。虽然新工具可能有所益，但过时文档的直接关注点是响应的有效性。

选项 B 错误。虽然利益相关者的信任很重要，但过时文档的直接影响是事件响应的质量。

选项 D 错误。聘请外部顾问可能是一个选项，但过时文档的直接后果是内部响应过程可能失效。

问题 62。一家金融机构正在考虑实施一种系统，允许所有用户查看所有交易，但一旦记录交易，就无法更改或删除。他们希望通过这种透明度来增强用户之间的信任。以下哪项最能满足这一要求？

- (A) 数字证书 (Digital certificate)
- (B) 开放公共账 (Open public ledger)
- (C) 对称加密 (Symmetric encryption)
- (D) 安全文件传输协议 (Secure file transfer protocol)

解析 62. 正确答案：B。开放公共账。开放公共账通过允许所有用户查看所有交易提供了透明度。此外，一旦交易被添加到账中，它就是不可不可变的，这意味着无法被更改或删除，确保了数据的完整性并增强了参与者之间的信任。

选项 A 错误。数字证书用于验证实体的身份并将其公钥绑定，但它不提供交易的透明度或不可篡改性。

选项 C 错误。对称加密使用单一密钥对数据进行加密和解密，但它不提供交易透明度或不可变性。

选项 D 错误。安全文件传输协议 (SFTP) 是在网络上安全传输文件的方法，但它不维护交易的公共账。

问题 63。一家公司正在实施一个系统，以确保发布到生产环境的代码未被更改并经过特定团队成员的批准。他们应该实施以下哪种加密技术？

- (A) 对代码进行对称加密
- (B) 使用 SHA-256 对代码进行哈希
- (C) 使用团队成员的公钥对代码加密
- (D) 团队成员的数字签名

解析 63. 正确答案：D。团队成员的数字签名。数字签名提供了完整性和不可否赖性。通过让特定的团队成员对代码进行数字签名，公司可以确保代码没有被更改（完整性），并且它确实是由指定的个人批准的（不可否赖性）。

选项 A 错误。对称加密提供了机密性，但在这种场景下它没有提供所需的完整性和不可否赖性。

选项 B 错误。对代码进行哈希提供了一种检查更改的机制（完整性），但它没有提供不可否赖性或关于特定团队成员批准的证据。

选项 C 错误。使用团队成员的公钥加密不能提供不可否赖性。此外，只有拥有相应私钥的团队成员才能对其解密，这对于生产环境发布可能是不理想的。

问题 64。贵公司最近对其 CRM 应用部署了更新。更新后，用户遇到了连接问题。作为安全管理员，您应该**首先**采取以下哪项步骤来解决连接问题，同时不导致数据丢失？

- (A) 立即重启应用程序
- (B) 断开所有用户并重启应用程序
- (C) 验证更新的完整性然后重启应用程序
- (D) 重新安装上版本的 CRM 应用

解析 64. 正确答案：C。验证更新的完整性然后重启应用程序。在进行任何更改之前，验证更新的完整性至关重要，以确保其被正确应用。

选项 A 错误。如果更新没有正确应用，立即重启可能会导致更复杂的问题。

选项 B 错误。断开用户在某些可能是必要的，但在不验证更新完整性的情况下这样做会导致进一步的扰动。

选项 D 错误。重新安装旧版本是一个激进的，如果可以通过验证更新完整性并重启来解决问题，则没有必要的。
