
选项 D 是错误的。软件更新中增加的功能数量并不代表安全补丁的及时性或有效性。

问题 184. 某公司正要在总部与远程分支机构之间建立一个安全的通信通道。为了确保通过该通道传输的数据源自分支机构的合法系统，该公司正在考虑使用数字证书。该公司正在考虑的是哪种系统身份验证方法？

+   (A) Kerberos 认证
-   (B) 基于密码的认证
-   (C) 基于证书的认证
-   (D) 基于生物识别的认证

解释 184. 正确答案：C. 基于证书的认证。基于证书的身份验证使用数字证书来验证系统或个人的身份。在给定的场景中，公司希望验证通过通信通道传输的数据源自合法系统，因此数字证书是一个合适的选择。

选项 A 是错误的。Kerberos 认证是一种基于票据的身份验证协议，主要用于网络中的用户身份验证，而不是专门用于使用数字证书的系统间身份验证。

选项 B 是错误的。基于密码的认证要求系统或用户提供秘密密码来证明其身份。它不涉及数字证书的使用。

选项 D 是错误的。基于生物识别的认证涉及使用人的独特物理或行为特征进行验证，例如指纹或面部特征。它不适用于系统间的身份验证。

问题 185. 在经历系列网络安全事件后，AlphaTech 公司想采取主动措施来识别其网络中的漏洞。他们的目标是获得一份关于潜在弱点的全面报告，而不利用这些漏洞。以下哪项最能符合这一目标？

+   (A) 渗透测试
-   (B) 漏洞扫描
-   (C) 红队评估
-   (D) 端口安全

解释 185. 正确答案：B. 漏洞扫描。漏洞扫描旨在用于检查系统、网络和应用程序，以识别潜在的弱点或漏洞。与其它某些选项不同，它并不尝试利用这些漏洞；仅仅是识别并报告它们。

选项 A 是错误的。渗透测试比漏洞扫描更进了一步。它不仅能识别漏洞，还会尝试利用这些漏洞以理解数据泄露的潜在影响。

选项 C 是错误的。红队评估是一种基于目标的评估，其中模拟攻击者（红队）试图实现特定目标。它通常涉及漏洞利用，这超出了仅仅识别漏洞的范围。

选项 D 是错误的。端口安全是数据链路层的一种功能，用于根据端口控制基于 MAC 地址的访问。它不提供全面的漏洞报告。

问题 186. 安全分析师 Lucy 收到通知，几名员工在公司食堂时，通过蓝牙收到了多个未经授权的传输请求。以下哪种攻击**最可能**正在尝试实施？

+   (A) 蓝信劫持 (Bluejacking)
-   (B) ARP 投毒
-   (C) 蓝牙盗窃 (Bluesnarfing)
-   (D) 恶性孪生 (Evil Twin)

解释 186. 正确答案：A. 蓝信劫持。蓝信劫持是通过蓝牙向启用蓝牙的设备（如移动手机、笔记本电脑或 PDA）发送未经请求的消息或文件。它通常被用作作剧或向附近的人投放广告。

蓝信劫持不会让攻击者控制受者的设备，但它可以用于发送不受欢迎的消息或文件，这与描述的场景相符。

选项 B 是错误的。ARP 投毒是一种攻击类型，攻击者在局域网内发送伪造的 ARP（地址解析协议）消息。它与蓝牙通信无关。

选项 C 是错误的。蓝牙盗窃是指通过蓝牙连接未经授权访问无线设备中的信息。蓝牙盗窃不仅仅仅是发送未经请求的消息；它寻求的是访问个人数据。

选项 D 是错误的。恶性孪生攻击涉及创建一个伪造的 Wi-Fi 热点来冒充合法热点，以拦截或操纵数据流量。它不直接涉及蓝牙连接。

问题 187. 一家小型企业想要部署一种能够处理防火墙、入侵检测、反恶意软件和内容过滤等功能的单一设备。以下哪项最合适？

+   (A) 网络入侵检测系统 (NIDS)
-   (B) Web 应用防火墙 (WAF)
-   (C) 统一威胁管理 (UTM)
-   (D) 代理服务器

解释 187. 正确答案：C. 统一威胁管理 (UTM)。统一威胁管理 (UTM) 将防火墙、入侵检测、反恶意软件和内容过滤功能整合到一个设备中。

选项 A 是错误的。NIDS 主要用于识别网络中的恶意活动，不提供上述所有功能。

选项 B 是错误的。WAF 专门保护 Web 应用程序免受 XSS 和 SQL 注入。

选项 D 是错误的。代理服务器主要控制互联网访问。

问题 188. 在 NetSecure Corp. 的审计期间，外部审计师发现公司愿意接受可能导致利润下降 10% 的风险，但不能更多。审计师想要记录这一发现。他们应该使用哪个术语？

+   (A) 风险规避
-   (B) 风险转移
-   (C) 风险容度
-   (D) 风险评估

解释 188. 正确答案：C. 风险容度。风险容度代表实体愿意接受或容忍的风险量。NetSecure Corp. 对利润下降 10% 风险的接受代表了其容度。

选项 A 是错误的。风险规避意味着完全回避具有风险的活动。场景表明公司愿意承担风险，但在一定范围内。

选项 B 是错误的。风险转移是将某些风险转移给其他方，通常通过保险或其他合同方法。场景没有提供关于风险转移的信息。

选项 D 是错误的。风险评估是识别、分析和评估风险的整体过程。场景更侧重于公司对特定水平风险的接受，而不是进行评估。

问题 189. Web 托管公司Secure LLC 在过去五年内发生了两次服务器泄露。他们正在分析与其基础设施相关的风险。以下哪项最能代表服务器泄字的年化发生率 (ARO)？

+   (A) 0.2
-   (B) 0.4
-   (C) 2
-   (D) 5

解释 189. 正确答案：B. 0.4。年化发生率 (ARO) 是衡量事件每年预期发生的频率的指标。鉴于五年内发生了两次泄露，因此 ARO 应为 2 除以 5 年，结果为 0.4。

选项 A 是错误的。虽然很接近，但 ARO 的计算应该是发生次数（2）除以年数（5），结果是 0.4，而不是 0.2。
