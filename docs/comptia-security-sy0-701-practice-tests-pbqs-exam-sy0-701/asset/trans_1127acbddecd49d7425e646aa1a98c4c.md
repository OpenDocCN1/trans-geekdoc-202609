# 问题 54. 你公司的一位开发者对无服务器架构的可扩展性优势感到兴奋，并使用它部署了一个新服务。然而，你发现即使在服务未使用时，该服务的账单也增加了。以下哪项可能是导致因素？

- (A) 无服务器函数被意外事件持续触发
- (B) 服务器硬件过旧
- (C) 负载均衡器配置错误
- (D) 组织缺乏内容分发网络 (CDN)

**解析 54. 正确答案：A. 无服务器函数被意外事件持续触发。** 无服务器架构根据函数调用的次数和执行时间收费。如果存在意外事件（例如恶意请求或配置错误的触发器）持续调用无服务器函数，可能会导致意外之外的成本。

选项 B 错误。在无服务器架构中，服务器硬件管理的责任在于服务提供商。客户从硬件细节中被抽象出来。

选项 C 错误。负载均衡器配置错误可能会影响可用性或性能，但与无服务器部署中意外的成本激增没有直接关系。

选项 D 错误。虽然 CDN 对优化内容交付非常有价值，但它们与无服务器架构中意外之外的函数调用的成本影响没有直接关系。

# 问题 55. AlphaTech 希望确保其远程员工在从家里工作时遵循最佳安全实践。安全团队被指派起草一套远程工作指南。这些指南的首要关注点应该是？

- (A) 概述对不合规的惩罚措施
- (B) 阐述公司对远程工作的法律立场
- (C) 针对家庭网络和设备的建议安全措施
- (D) 规定远程工作者具体的软件和硬件规格

**解析 55. 正确答案：C. 针对家庭网络和设备的建议安全措施。** 指南旨在提供建议和推荐。在远程工作的背景下，它们会建议保护家庭网络和设备的最佳安全实践，而不会具有过度强制性。

**选项 A 错误。** 惩罚措施和合规后果通常列在政策或程序中，而不是指南中。

**选项 B 错误。** 公司对远程工作的法律立场将是政策或法律文件的一部分，而不是指南。

**选项 D 错误。** 规定具体的软件和硬件规格更符合标准而不是指南。指南将提供更广泛的建议。

# 问题 56. 安全经理 Lisa 正在审查公司现有的政策，发现没有一份详尽的文档来概述组织在保护信息资产方面的立场、期望和承诺。Lisa 应该优先创建哪项来填补这一空白？

- (A) 应急响应计划
- (B) 信息安全策略
- (C) 可接受使用策略
- (D) 数据备份策略

**解析 56. 正确答案：B. 信息安全策略。** 信息安全策略是一份基础性文档，为整个组织的信息安全提供了一个框架。它涵盖了组织在保护数据和 IT 资产方面的愿景、原则和责任。

**选项 A 错误。** 应急响应计划侧重于安全事件发生后应采取的步骤。它没有详细说明组织对信息安全的整体立场。

**选项 C 错误。** 可接受使用策略提供了关于员工应如何使用公司资源的指南，但它没有提供对组织保护信息资产承诺的全面概述。

**选项 D 错误。** 虽然数据备份策略对于数据可用恢复至关重要，但它没有传达组织对信息安全的更广泛视角和承诺。

# 问题 57. 金融科技公司 GlobalFin 开发了一个新的移动银行应用程序。为了避免任何法律纠纷，GlobalFin 在全球范围内推出该应用程序之前应该最关注以下哪些法律考量？

- (A) 确保应用程序符合全球数据隐私法
- (B) 确认配色方案符合所有国家的品牌法规
- (C) 为应用程序中使用的所有图像获取版权
- (D) 确保应用程序的名称在任何语言中都不具有冒犯性

**解析 57. 正确答案：A. 确保应用程序符合全球数据隐私法。** 对于移动银行应用程序而言，确保符合全球数据隐私法至关重要。不同地区对于如何处理、存储和处理用户数据有不同的要求和法规。

选项 B 错误。虽然品牌建设和配色方案对营销很重要，但它们通常不是像数据隐私法那样的受严格法律监管的对象。

选项 C 错误。虽然获取版权很重要，但银行应用程序的首要法律关注点是数据隐私。

选项 D 错误。虽然确保应用程序名称不冒犯是一项良好的做法，但银行应用程序的主要法律关注点将是数据隐私。

# 问题 58. 在微服务架构中，每个服务应根据特定原则进行设计，以确保它执行特定任务并通过定义的接口与其他服务交互。这指的是哪种原则？

- (A) 最小权限原则
- (B) 单一职责原则
- (C) 开闭原则
- (D) 零信任模型

**解析 58. 正确答案：B. 单一职责原则。** 单一职责原则规定，类或模块（在微服务背景下，即服务）只有一个更改的原因，意味着它应该有一个工作或职责。在微服务中，这确保每个服务只做好一件事，并通过接口与其他交互。

选项 A 错误。最小权限原则是确保用户或服务仅具有执行任务所需的权限而非更多。它并不是专门针对服务的设计。

选项 C 错误。开闭原则是一个设计原则，认为软件实体应对扩展开放但对修改关闭。虽然与软件设计相关，但它不是指导微服务设计的主要原则。

选项 D 错误。零信任模型是一种安全概念，无论组织内部还是外部，默认都不被信任。它不是微服务设计的特定原则。
