**问题 346。** 一家大型公司的财务部门仍然依赖一个遗留应用程序来生成季度报告。该应用程序已知存在某些安全漏洞，但由于其关键性，无法轻易替换。该公司应该如何**最佳**缓解与该应用程序相关的风险？

- **(A)** 对财务团队进行有关最新网络安全威胁的培训
- **(B)** 在最新的硬件上运行遗留应用程序以提高性能
- **(C)** 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后
- **(D)** 频繁更改访问该应用程序的用户密码

**解释 346. 正确答案：C. 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后。** 通过将应用程序置于 WAF 之后，公司可以过滤、监控并拦截针对应用程序漏洞的恶意 HTTP 流量，从而为遗留应用程序中潜在的安全漏洞提供层次化保护。

选项 A 错误。虽然培训至关重要，但它没有直接解决遗留应用程序中的漏洞。

选项 B 错误。使用最新的硬件可能会提高应用程序性能，但无法缓解与其漏洞相关的安全风险。

选项 D 错误。虽然频繁更改密码可以增强安全性，但它们无法解决遗留应用程序固有的漏洞。

**问题 347。** 一家公司准备为其其内部网络部署新的基础设施。他们有一台服务器，将存储高度机密的客户信息和非敏感营销材料。IT 部门希望仅对机密数据进行加密，而营销数据保持易于访问。哪种加密级别最适合这种场景？

- (A) 文件级加密
- (B) 全磁盘加密
- (C) 分区加密
- (D) 传输层加密

**解释 347. 正确答案：C. 分区加密。** 分区加密允许对存储驱动器的特定分区或卷进行加密。通过加密包含机密分区，公司可以确保敏感信息的安全，同时让其他分区（如包含营销材料的分区）不加密以便访问。

选项 A 错误。文件级加密需要对每个机密文件进行单独加密，这可能非常繁琐。

选项 B 错误。全磁盘加密将加密整个磁盘，包括非敏感的营销材料。

选项 D 错误。传输层加密保护传输过程中的数据，而不是存储驱动器上的静态数据。

**问题 348。** 一个组织的安全团队发现攻击者已获得对服务器的未经授权访问。调查，他们发现了一个软件工具，允许攻击者掩盖进程、文件和系统数据，在保持特权访问的同时有效地隐藏。攻击者植入了什么种类型的恶意软件？

- (A) 木马程序
- (B) 病毒
- (C) 逻辑炸弹
- (D) Rootkit（根内核包）

**解释 348. 正确答案：D. Rootkit。** Rootkit 是一种提供对计算机隐蔽访问并从标准检测方法中隐藏其行踪的恶意软件。它可以掩盖文件、进程和其他系统数据。

选项 A 错误。木马程序伪装成合法软件，但在安装后会执行恶意活动。它本身并不具备隐藏进程或文件的功能。

**选项 B 错误。**病毒是可以自我复制并传播到其他系统的恶意软件。它们通常不会在系统级别隐藏其活动。

**选项 C 错误。** 逻辑炸弹设置为在特定事件或条件发生时执行其恶意活动。它并不侧于隐藏系统数据或进程。

**问题 349。** 作为初始渗透测试阶段的一部分，Jackson 正在使用直接探测并与目标系统的网络交互的工具来发现开放端口、服务和其他潜在的访问点。虽然这种方法更直接且可能被目标的安全系统检测，但它提供了详细且可操作的见解。Jackson 正在进行哪种类型的侦察？

- (A) 威胁分析
- (B) 被动侦察
- **(C) 主动侦察**
- (D) 社会工程学

**解释 349. **正确答案：C. 主动侦察** 主动侦察涉及直接与目标系统交互，以获取更详细和可操作的信息。在此阶段，通常会使用可以被目标安全措施检测的工具和技术，例如端口扫描。Jackson 的方法符合主动侦察的特征。

**选项 A 错误。** 威胁分析是识别、评估和优先考虑针对系统或组织的威胁的过程。

**选项 B 错误。** 被动侦察是在不与目标系统直接交互的情况下收集数据，通常使用第三方来源、公共记录和其他非侵入性方法。

**选项 D 错误。** 社会工程学涉及操纵个人以泄露机密或执行某些操作，它与网络探测或服务发现没有直接关系。

**问题 350。** HealthCareNow 是一家大型连锁医院，希望确保其新实现的电子健康记录 (EHR) 系统符合国家标准。哪种类型的审计最适合确认 HealthCareNow 符合有关患者数据的国家法规？

- (A) 使用内部标准进行自评估
- (B) 第三方风险评估
- (C) 外部监管审计
- (D) 非正式同伴评审

**解释 350. 正确答案：C. 外部监管审计。** 外部监管审计由外部实体进行，以确保组织符合行业或国家法规。对于 HealthCareNow 而言，外部监管审计将确认其 EHR 系统符合与患者数据相关的国家标准。

选项 A 错误。虽然自评估对内部审查很有益，但它们可能没有外部监管审计那样的分量或审查深度。

选项 B 错误。第三方风险评估侧重于评估与合作伙伴和供应商相关的安全风险，而不是确认符合国家法规。

选项 D 错误。非正式同伴评审可能会提供见解和建议，但缺乏外部审计的正式结构和对监管的强调。

**问题 351。** 一家医疗机构在其服务器上存储了大量患者数据。虽然他们有强大的边界防御，但他们希望增加额外的安全性，以确保在发生未经授权访问的情况下患者数据保持机密。以下哪项是此需求的最有效解决方案？

- (A) 对所有患者数据使用哈希算法
- (B) 实现数据去重
- (C) 加密存储的患者数据
- (D) 使用 Web 应用防火墙 (WAF)

**解释 351. **正确答案：C. 加密存储的患者数据。** 加密患者数据可以确保即使攻击者获取了数据，如果没有正确的解密密钥，他们无法理解或利用这些数据。

选项 A 错误。哈希主要用于验证数据完整性或安全存储密码。哈希处理无法让医疗机构在需要时检索和使用患者数据。
