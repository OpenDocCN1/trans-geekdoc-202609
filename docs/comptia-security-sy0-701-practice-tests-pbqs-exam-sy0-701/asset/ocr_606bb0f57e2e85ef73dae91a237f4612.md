Question 290. An organization is transitioning its IT infrastructure to be cloud-centric and aims to adopt a zero-trust network approach. (B) Secure access service edge (SASE)
(C) Content Delivery Network (CDN)
(D) Virtual Local Area Network (VLAN)

Explanation 290. Correct Answer: B. Secure access service edge (SASE). SASE integrates multiple network and security functions traditionally delivered in separate point solutions.
