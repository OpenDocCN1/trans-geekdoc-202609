Security Information and Event Management (SIEM).** SIEM tools are designed to aggregate, correlate, and analyze logs and events from various sources in an organization. **Option A is incorrect.** While NIDS monitors and analyzes network traffic for signs of malicious activities, it doesn’t provide centralized logging and reporting functionalities like a SIEM.

**Option C is incorrect.** A Vulnerability Scanner identifies vulnerabilities in systems and applications but doesn’t aggregate and analyze logs from various sources.
