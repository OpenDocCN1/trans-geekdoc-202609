## Question 420. 
问题 420。一家金融公司刚刚经历了一次网络攻击，IT 团队识别出一种规避了传统杀毒病毒解决方案的恶意软件。CISO 现在希望不仅能检测，还能实时分析并响应此类高级威胁。该公司应该考虑实施哪种解决方案？

- (A) 漏洞扫描器
- (B) 入侵预防系统 (IPS)
- (C) 终端检测与响应 (EDR)
- (D) 补丁管理系统

解析 420. 正确答案：C。终端检测与响应 (EDR)。终端检测与响应 (EDR) 对端点事件进行实时监控和分析，允许组织检测、调查并响应潜在的安全威胁。EDR 工具可以识别可能指示规避传统杀毒病毒解决方案的高级的行为。

选项 A 是错误的。漏洞扫描器用于识别系统或网络中的漏洞，但不提供对威胁的实时监控和响应能力。

选项 B 是错误的。入侵预防系统 (IPS) 监控网络流量以防止潜在威胁，但可能无法像 EDR 解决方案那样在终端级别提供深度分析和响应。

选项 D 是错误的。补丁管理系统用于管理软件更新的分发和安装，但不提供实时威胁检测和响应。

## Question 421. 
问题 421。在对公司服务器进行例行审计期间，系统管理员发现一个关键应用程序服务器丢失了一周的安全日志。发生这种情况最可能的原因是什么？

- (A) 日志服务发生故障
- (B) 日志的存储空间不足
- (C) 旨在擦除入侵痕迹的恶意软件攻击
- (D) 时区设置错误

解析 421. 正确答案：C。旨在擦除入侵痕迹的恶意软件攻击。这是攻击者在获得未经授权访问后掩盖行踪的主要策略之一。删除或更改日志是避免检测和防止任何恶意活动痕迹的常用方法。

选项 A 是错误的。虽然日志服务可能发生故障，但导致特定某一周日志丢失且不影响其他时间段的可能性较低。

选项 B 是错误的。存储空间不足会导致新日志覆盖旧日志，但通常不会导致某块特定的日志（例如整整一周）丢失。

选项 D 是错误的。时区设置错误可能会导致日志中的时间戳差异，但不会导致日志丢失。

## Question 422. 
问题 422。一家金融公司正在设计一个新系统，需要确保根据用户的分类和许可级别来访问数据。以下哪种访问控制模型最符合此项要求？

- (A) 基于角色的访问控制 (RBAC)
- (B) 任意自主访问控制 (DAC)
- (C) 强制性访问控制 (MAC)
- (D) 基于属性的访问控制 (ABAC)

解析 422. 正确答案：C。强制性访问控制 (MAC)。MAC 基于信息的分类和用户的许可级别。在 MAC 模型中，操作系统限制了主体或发起者访问对象或目标或对其执行某种类型操作的能力。在这种场景下，数据经过了分类且用户被赋予了许可级别，MAC 是最合适的模型。

选项 A 是错误的。基于角色的访问控制 (RBAC) 为组织中的特定角色分配权限。然后将用户分配给角色。虽然在许多场景中很有用，但它并不关注分类和许可级别。

选项 B 是错误的。任意自主访问控制 (DAC) 允许资源所有者指定谁可以访问。它比 MAC 更灵活但限制更少。

选项 D 是错误的。基于属性的访问控制 (ABAC) 使用策略根据用户、环境和资源本身的属性来确定访问。虽然它可以用于具有分类和许可的场景，但它基于这些因素的定义没有 MAC 严格。

## Question 423. 
问题 423。TechSolutions Inc. 一家快速发展的初创公司正在扩大员工规模以满足客户需求。作为此次扩展的一部分，他们需要确保基础设施能够在不妥损害性能或安全的情况下处理增长。TechSolutions 应该重点关注哪项？

- (A) 采用零信任网络架构
- (B) 增加漏洞评估的频率
- (C) 实施容量规划
- (D) 部署防火墙和入侵检测系统

解析 423. 正确答案：C。实施容量规划。容量规划确保组织的基础设施、技术和人员得到适当扩展以满足需求。在员工涌入的场景下，容量规划至关重要。

选项 A 是错误的。虽然采用零信任网络架构可能会增强安全性，但没有直接解决增长问题。

选项 B 是错误的。漏洞评估对安全至关重要，但它们不直接解决基础设施的能力问题。

选项 D 是错误的。虽然防火墙和 IDS 可以提高安全性，但它们不直接解决容量问题

## Question 424. 
问题 424。安全分析师 Emily 被指派在不直接与系统交互的情况下收集有关目标的初步信息。她决定从第三方来源、搜索引擎、公共记录和其他在线平台收集数据，而不发送数据包。Emily 目前正处于哪种测试阶段？

- (A) 主动侦察
- (B) 被动侦察
- (C) 漏洞扫描
- (D) 威胁狩猎

解析 424. 正确答案：B。被动侦察。被动侦察是初始阶段，渗透测试人员在不直接接触或告警目标的情况下收集有关目标的信息。Emily 从第三方来源收集数据而不发送数据包的方法符合被动侦察的特征。

选项 A 是错误的。主动侦察涉及直接与目标系统交互，通常会发送数据包或探测，这可能会被目标检测。

选项 C 是错误的。漏洞扫描是更进一步的，使用特定工具来识别系统中的漏洞。它比被动侦察更直接。

选项 D 是错误的。威胁狩猎是一种在系统内部寻找恶意活动的主动方法，而不是收集有关目标的信息。

## Question 425. 
问题 425。在建立安全通信通道期间，Alice 和 Bob 需要约定一个共享密钥，而不需要直接向对方发送该密钥，因为他们担心被窃听。哪种协议最有利于实现这一需求？

- (A) RSA
- (B) HMAC
- (C) Diffie-Hellman
- (D) AES

解析 425. 正确答案：C。Diffie-Hellman。Diffie-Hellman 密钥交换协议允许双方各自生成公钥和私钥对，交换公钥，然后派生共享密钥。该密钥随后可以用于对称加密。该协议的妙之处在于，共享密钥可以在不通过通信通道发送的情况下派生，从而防止窃听者直接获取密钥。
