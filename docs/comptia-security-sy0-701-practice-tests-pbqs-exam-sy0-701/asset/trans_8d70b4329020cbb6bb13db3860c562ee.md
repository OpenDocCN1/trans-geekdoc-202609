
问题 391。某组织正计划部署一个新的 Web 应用程序，该程序可以从内部网络和互联网访问。该应用程序将仅通过 HTTPS 进行通信。安全管理员被要求配置防火墙以允许必要的流量。管理员应该配置以下哪一项？

- (A) 允许端口 21 并阻止所有其他
- (B) 允许端口 443 并阻止所有其他
- (C) 允许端口 80 并阻止所有其他
- (D) 允许端口 23 并阻止所有其他

解释 391. 正确答案：B. 允许端口 443 并阻止所有其他。HTTPS 主要使用 443 端口进行安全通信。因此，允许 443 端口并阻止所有其他端口将确保 Web 应用程序的安全运行。

选项 A 错误。端口 21 用于 FTP（文件传输协议），它与 HTTPS 通信无关。

选项 C 错误。虽然端口 80 用于 HTTP，但它不提供 HTTPS 在 443 端口上提供的加密功能。

选项 D 错误。端口 23 用于 Telnet，与安全网络通信无关。

问题 392。公司的安全管理员观察到有多个未经授权的访问尝试来自特定范围的 IP 地址。管理员希望临时阻止这些 IP 地址访问公司网络。以下哪种防火墙配置最能满足这一需求？

- (A) 为特定 IP 范围配置隐式拒绝规则（implicit deny rule）
- (B) 为特定 IP 范围设置蜜罐（honeypot）
- (C) 允许该 IP 范围但设置带宽限制
- (D) 将该 IP 范围添加到白名单

解释 392. 正确答案：A. 为特定 IP 范围配置隐式拒绝规则。通过为该特定 IP 范围配置隐式拒绝规则，防火墙将阻止来自这些地址的任何流量，防止它们访问网络。

选项 B 错误。虽然蜜罐可以监控和分析攻击者的行为，但它不能阻止指定 IP 范围访问公司网络。

选项 C 错误。允许 IP 范围并设置带宽限制无法阻止访问；它只会限制他们发送/接收的数据量。

选项 D 错误。将 IP 范围添加到白名单将授予他们访问权限，这与要求的操作相反。

问题 393。Globex 公司的 IT 部门担心员工在远程工作期间，公司笔记本电脑访问恶意网站的数量日益增加。他们希望确保即使设备在境外，公司网络中设置的 Web 过滤策略也能生效。解决这一疑虑的最佳解决方案是什么？

- (A) 实现基于云的网页过滤解决方案
- (B) 使用 VPN 强制所有远程流量通过公司网络
- (C) 在所有公司笔记本电脑上部署基于代理（agent-based）的网页过滤器
- (D) 定期向员工发送关于可接受网络使用的提醒

解释 393. 正确答案：C. 在所有公司笔记本电脑上部署基于代理的网页过滤器。基于代理的网页过滤器可以在设备位于何地的情况下对设备执行网页过滤策略。这确保了无论设备是在公司网络内部还是外部，策略都能一致生效。

选项 A 错误。虽然云端解决方案可以提供境外过滤，但它们可能没有直接在设备本身上执行公司策略的代理型解决方案那样一致。

选项 B 错误。使用 VPN 会强制所有流量通过公司网络，这会导致延迟，并且在远程工作场景下可能不可行。

选项 D 错误。发送提醒是一种被动的方法，可能无法有效阻止访问恶意网站。

问题 394。安全分析师 Lisa 正在建立一个中央系统，用于关联来自多个源的日志、实时检测恶意活动并生成全面的安全报告。Lisa 应该考虑使用哪种工具来实现目的？

- (A) 网络入侵检测系统 (NIDS)
- (B) Web 应用防火墙 (WAF)
- (C) 漏洞扫描器 (Vulnerability Scanner)
- (D) 安全信息和事件管理 (SIEM)

解释 394. 正确答案：D. 安全信息和事件管理 (SIEM)。SIEM 工具旨在聚合、关联和分析来自组织各种来源日志和事件。它们有助于实时检测和响应安全事件，并生成详细的安全报告。

选项 A 错误。虽然 NIDS 监控并分析网络流量以寻找恶意活动迹象，但它不提供 SIEM 那样的集中日志和报告功能。

选项 B 错误。Web 应用防火墙 (WAF) 保护 Web 应用程序免受 Web 攻击。它不提供 SIEM 的集中日志关联和分析功能。

选项 C 错误。漏洞扫描器识别系统和应用程序中的漏洞，但不会聚合和分析来自各种来源的日志。

问题 395。某金融公司的 IT 安全经理 Lucy 收到一条自动警报，一名员工尝试向外部电子邮件地址发送包含社会安全码的文档。以下哪种工具最可能生成此警报？

- (A) 网络入侵检测系统 (NIDS)
- (B) 数据泄露防护（DLP）解决方案
- (C) 漏洞扫描器
- (D) 包分析仪

解释 395. 正确答案：B. 数据泄露防护（DLP）解决方案。DLP 解决方案专门用于监控和控制跨组织的数据传输。在这种情况下，DLP 检测到了敏感数据（社会安全码）发送并通知了 Lucy。

选项 A 错误。NIDS 检测并警报网络上的恶意活动，但它通常不扫描传输的数据。

选项 C 错误。漏洞扫描器识别系统中的漏洞，但不监控数据传输。

选项 D 错误。虽然包分析仪可以捕获和分析网络流量，但它们不会根据传输数据的内容生成警报。

问题 396。某在线银行平台希望在用户开户时改进其身份验证流程。以下哪种身份验证方法为此目的提供了最高的安全性？

- (A) 要求用户从列表中选择安全问题和答案
- (B) 要求用户上传政府颁发的身份证照片和自拍
- (C) 向用户的电子邮件地址发送验证码
- (D) 提示用户提供他们喜欢的颜色

解释 396. 正确答案：B. 要求用户上传政府颁发的身份证照片和自拍。这种方法通过将用户的实时图像（自拍）与身份证进行对比提供了高水平的保证。这种组合确保了人员身份真实。

选项 A 错误。安全问题（尤其是来自预定义列表）很容易被猜测或被攻击者获取。

选项 C 错误。通过电子邮件发送验证码可以增强身份，但不如检查身份证和自拍那样可靠。

选项 D 错误。个人偏好（如颜色）是身份的弱指标，很容易被猜测。

问题 397。某公司最近注意到员工在工作时间内访问社交媒体网站的数量增加，导致生产力下降。为了应对这个问题，安全管理员决定在工作高峰限制对这些网站的访问。管理员应该制定哪条防火墙规则？

- (A) 实现入侵预防系统 (IPS) 规则以阻止社交媒体内容
- (B) 修改防火墙规则，在上午 9 点到下午 5 点之间拒绝对已知社交媒体 IP 地址的访问
