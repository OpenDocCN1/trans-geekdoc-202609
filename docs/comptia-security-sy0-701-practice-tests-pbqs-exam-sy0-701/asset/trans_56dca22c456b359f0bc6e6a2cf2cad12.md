问题 383。在组织发生最近一次安全事件后，IT 团队发现入侵检测系统标记了若干合法活动，导致了大量的误报。为了提高系统准确性并减少不警报，最合适的操作是什么？

- (A) 禁用入侵检测系统一周以观察常规网络流量模式
- (B) 设置更严格的防火墙规则以阻止所有外部流量
- (C) 实施告警调优（alert tuning）以完善系统的检测准则
- (D) 鼓励员工减少互联网使用

解释 383. 正确答案：C。实施告警调优以完善系统的检测准则。告警调优涉及调整系统的检测规则或标准，以更好地区分合法活动和恶意活动，从而减少误报。

**选项 A 错误。** 禁用入侵检测系统会使组织暴露在真实威胁之下，这种方法风险。

**选项 B 错误。** 设置更严格的防火墙规则不能直接解决入侵检测系统的误报问题，并可能阻止合法的业务操作。

**选项 D 错误。** 减少互联网使用并不一定与误报的减少相关。问题在于系统的准则，而不是流量的大小。

问题 384。网络管理员 Amy 正在研究相关工具，以协助根据特定的安全基线（baseline）对其组织的系统进行自动化评估。她发现了 SCAP 并想要实施它。以下哪项最准确描述了安全内容自动化协议（SCAP）的主要功能？

- (A) 促进威胁情报馈送的实时传输
- (B) 为针对 Active Directory 的用户身份验证提供接口
- (C) 允许自动化漏洞管理和策略合规性评估
- (D) 为远程系统管理提供加密通信通道

解释 384. 正确答案：C。允许自动化漏洞管理和策略合规性评估。SCAP（安全内容自动化协议）是一套开放标准，增强了组织对系统进行自动化漏洞管理、测量和策略合规性评估的能力。

选项 A 错误。虽然威胁情报对安全至关重要，但 SCAP 的设计目的并非实时威胁情报馈送的传输。

选项 B 错误。SCAP 不直接处理任何目录服务的用户身份验证。

选项 D 错误。SCAP 的主要功能不是为远程系统管理提供加密通信通道。其他协议和工具具有此目的。

问题 385。一家金融机构希望确保对客户数据的任何未经授权的访问都能向安全团队触发立即告警。以下哪种方法最有效实现实现这一要求？

- (A) 针对数据库记录的任何修改配置告警
- (B) 为非工作期间的成功登录设置告警
- (C) 根据异常用户行为建立告警阈值
- (D) 将所有访问尝试的每日报告发送给安全团队审查

解释 385. 正确答案：C。根据异常用户行为建立告警阈值。通过根据异常行为设置告警阈值，系统可以根据偏离典型用户行为的模式检测未经授权的访问，为潜在的泄露提供及时告警。

选项 A 错误。针对数据库记录的任何修改可能会产生大量的误报，尤其是在金融机构这样经常发生合法变更的动态环境中。

选项 B 错误。虽然为非工作时间访问设置告警可以捕获某些未经授权的尝试，但可能会漏掉工作时间期间发生的泄露。

选项 D 错误。每日报告可能会延迟对未经授权访问的检测和响应，因为它不提供实时告警。

问题 386。在 Acme 公司遭受最近的网络攻击后，IT 安全团队决定增强增强他们的主动防御机制。他们想从识别网络上未修补的漏洞系统开始。以下哪种扫描活动最能帮助他们完成这一工作？

- (A) 在工作期间进行被动扫描
- (B) 在所有系统上实施全开放端口扫描
- (C) 在他们的网络上运行带凭据的漏洞扫描（credentialed vulnerability scan）
- (D) 扫描边界域名解析

解释 386. 正确答案：C。在他们的网络上运行带凭据的漏洞扫描。带凭据的漏洞扫描使用有效的用户凭据访问并扫描目标系统，从而进行更深层、更全面的未修补检查。

选项 A 错误。被动扫描是非侵入性的流量监控，限制了其识别未修补系统的能力。

选项 B 错误。虽然全端口扫描可以识别开放端口，但并不一定能识别未修补系统。

选项 D 错误。扫描边界域名解析有助于收集信息，但无法直接协助识别未修补系统。

问题 387。一家医疗机构希望评估其患者门户的安全性。他们告知渗透人员所使用的技术（如编程语言和数据库），但对安全措施（如入侵检测系统）保持保密。他们的目标是哪种渗透测试？

- (A) 白盒测试
- (B) 外部测试
- (C) 灰盒测试
- (D) 激活测试

解释 387. 正确答案：C。灰盒测试。灰盒测试意味着测试人员拥有部分知识而非全部细节。在这里，医疗机构提供了所用技术的细节，但对安全措施保持保密。这种部分披露符合灰盒测试的方法论。

选项 A 错误。在白盒测试中，测试人员将拥有系统的完整概述，包括代码、配置和安全措施。

选项 B 错误。外部测试主要关注系统的外部防御（如防火墙配置），而不考虑向测试人员共享了细节。

选项 D 错误。激活测试（Active testing）意味着测试人员直接与系统交互，并不代表对系统内部的知识水平。
