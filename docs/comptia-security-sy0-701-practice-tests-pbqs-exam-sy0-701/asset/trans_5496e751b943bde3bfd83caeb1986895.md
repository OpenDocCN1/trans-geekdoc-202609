**第 524 题.** John 是一个严格遵守《通用数据保护条例》（GDPR）国家的公民，他使用了一个全球在线购物平台了一年。他决定停止使用该平台并请求删除其所有个人数据。根据“被遗忘权”原则，在线平台对 John 的请求的首要义务是什么？

- (A) 保留数据，但确保 John 的数据绝不用于营销目的
- (B) 删除所有关于 John 的个人数据，除非有法律理由保留它们
- (C) 对 John 的数据进行匿名处理并通知他已完成
- (D) 将 John 的数据移动到安全的加密服务器上，使其无法被访问

**解释 524. 正确答案：B。删除所有关于 John 的个人数据，除非有法律理由保留它们。** GDPR 下的“被遗忘权”允许公民要求组织删除其个人数据，除非组织有正当理由（例如法律义务）保留这些数据。

选项 A 错误。仅仅避免将 John 的数据用于营销并不能满足“被遗忘权”。

选项 C 错误。匿名化并不等同于删除数据，且 GDPR 的“被遗忘权”特指删除数据。

选项 D 错误。仅仅将数据移动到安全服务器并不符合“被遗忘权”的原则。除非有充分理由保留数据，否则必须删除数据。

**第 525 题.** WebMasters LLC 是一家受欢迎的网站托管公司，希望确保其托管网站的安全。他们发起了一项安全挑战，邀请全球伦理黑客寻找漏洞，而无需提供有关其服务器、数据库或应用程序的任何细节。WebMasters LLC 正在利用哪种渗透测试方法？

- (A) 外部测试
- (B) 灰盒测试
- (C) 活跃测试
- (D) 黑盒测试

**解释 525. 正确答案：D。黑盒测试。** 在黑盒测试中，测试人员在不知道系统内部细节（如服务器、数据库或应用程序结构）的情况下寻找漏洞。

选项 A 错误。外部测试通常涉及从外部边界开始攻击。

选项 B 错误。灰盒测试意味着测试人员拥有部分内部结构信息。

选项 C 错误。活跃测试通常涉及对系统进行主动的交互和探测。

- (A) 向监管机构提供内部报告，向内部利益相关者提供外部报告
- (B) 向监管机构和内部利益相关者提供外部报告
- (C) 向内部利益相关者提供内部报告，向监管机构提供外部报告
