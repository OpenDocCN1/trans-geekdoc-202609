问题 123。科技公司的员工 Mike 收到了一条来自同事 Jessica 的即时消息。该消息中包含一个链接，并声称展示了一个搞笑的视频。然而，Mike 知道 Jessica 正在休假。他怀疑这条消息可能不是真的来自她。Mike 最可能遇到的是哪种威胁？

+   (A) 水坑攻击 (Watering Hole Attack)
(B) 中间人攻击 (Man-in-the-Middle Attack)
(C) 即时消息欺骗 (IM Spoofing)
(D) 侧信道攻击 (Side-channel Attack)

解释 123. 正确答案：C。即时消息欺骗（IM Spoofing）。当攻击者向系统发送看似来自受信源（通常是已知的联系人）的消息时，就会发生 IM 欺骗。通过冒充受害者认识的人，攻击者可以欺骗受害者打开恶意链接或共享机信息。

选项 A 错误。水坑攻击是攻击者猜测或观察某个群体经常使用的网站，并在其中一个或多个网站中感染恶意软件。

选项 B 错误。中间人攻击涉及攻击者秘密地截获并转发双方之间的通信。攻击者与受害者建立独立的连接，并在他们之间转发消息。

选项 D 错误。侧信道攻击基于从计算机系统的实现中获得的信息，而不是所实现算法本身的漏洞。

问题 124。在一次政治竞选期间，一个匿名团体发布了一系列包含关于候选人过去的虚假数据的文章，意在影响选民的观点。这是……示例：

+   (A) 冒充 (Impersonation)
(B) 手机短信钓鱼 (Smishing)
(C) 虚假信息 (Disinformation)
(D) 诱饵 (Baiting)

解释 124. **正确答案：C。虚假信息 (Disinformation)。** 传播故意传播的虚假信息以欺骗或伤害，特别是在政治等敏感领域，被归类为虚假信息。

虚假信息活动通过将虚假信息呈现为真实来欺骗受众。在政治场景中，这可能会产生重大影响，影响公众意见和选举结果。

**选项 A 错误。** 冒充涉及假装成他人以进行欺骗，但场景并未表明该匿名团体正在冒充任何人。

**选项 B 错误。** 手机短信钓鱼（Smishing）是一种使用短信的钓鱼攻击。它与在文章中传播虚假信息无关。

**选项 D 错误。** 诱饵涉及用受害者想要的东西（如免费软件）诱导他们，以窃取个人信息或传播恶意软件。它不涉及场景中描述的虚假信息的传播。

问题 125。Sophia 收到银行的一封邮件，要求由于系统升级紧急更新她的个人详情。邮件包含一个链接，重定向到一个与她银行网站看起来相似的网站。她应该**首先**做什么？

+   (A) 点击链接并及时更新她的个人详情，以避免任何不便
(B) 将邮件转发给她的朋友和家人，确保他们也知道银行的系统升级
(C) 立即删除邮件，不采取任何行动
(D) 通过官方渠道联系她的银行以验证邮件的真实性

解释 125. **正确答案：D。通过官方渠道联系她的银行以验证邮件的真实性。** 在根据未请求的邮件采取行动之前（尤其是要求个人信息或凭据的邮件），直接向其声称代表的机构或实体验证其合法性至关重要。

钓鱼攻击通常利用恐惧、紧迫感或感知的权威来诱导受害者提供敏感数据。针对此类尝试的最佳防御是在采取行动之前独立验证任何意外或可疑的请求。

**选项 A 错误。** 通过提供个人详情直接回复潜在的钓鱼邮件是一个常见的错误，这使用户容易受到欺诈和身份盗窃的风险。

**选项 B 错误。** 将可能恶意的邮件转发给其他人可能会进一步传播威胁并可能同样损害他们的安全。

**选项 C 错误。** 虽然删除邮件可能会防止 Sophia 掉入钓鱼陷阱，但它并不是最佳做法。

问题 126。用户收到一条声称来自其银行的短信，称账户有异常活动，并要求点击链接以验证身份。这是哪种攻击？

+   (A) 钓鱼 (Phishing)
(B) 手机短信钓鱼 (Smishing)
(C) 语音钓鱼 (Vishing)
(D) 诱饵 (Baiting)

解释 126. 正确答案：B。手机短信钓鱼（Smishing）。手机短信钓鱼是使用短信的钓鱼形式。

选项 A 错误。钓鱼是一个通用术语，通常指电子邮件攻击。此案例使用的是短信。

选项 C 错误。语音钓鱼（Vishing）是通过电话进行的钓鱼。此场景涉及短信。

选项 D 错误。诱饵涉及提供诱措施（如免费礼物或 U 盘）来诱导受害者。这种攻击利用有关账户安全的紧迫感。

问题 127。一家大型制药公司最近宣布提高药品。公告后，其网站被 DDoS 攻击宕机。哪种类型的实体可能负责此？

+   (A) 内部威胁 (Insider threat)
(B) 黑激进分子 (Hacktivist)
(C) 有组织犯罪集团 (Organized crime syndicate)
(D) 国家级 (Nation-state)

解释 127. 正确答案：B。黑激进分子（Hacktivist）。黑激进分子经常进行攻击是为了政治或社会声明，或抗议公司行为。

选项 A 错误。内部威胁来自组织内部。DDoS 攻击通常从目标外部发起。

选项 C 错误。有组织犯罪集团的主要动力是利益。虽然他们可能使用 DDoS，但针对价格抗议更具黑激进分子特征。

选项 D 错误。国家级通常出于战略利益、间谍活动或政治影响进行攻击，而非价格价格。

问题 128。IT 公司的一名新实习生 Alex 想要访问内部门户。他没有输入“companyportal.com”，而是误输入了“comapnyportal.com”，进入了一个看起来完全相同但要求他下载安全证书的网站。这种场景最好描述了哪种攻击？

+   (A) 针对性钓鱼 (Spear Phishing)
(B) 水坑攻击 (Watering Hole Attack)
(C) 域名抢持 (Typosquatting)
(D) 中间人攻击 (Man-in-the-Middle)

解释 128. 正确答案：C。域名抢持（Typosquatting）。域名抢持（也称为 URL 劫持）涉及攻击者注册热门网站的拼写错误的域名。其目的是欺骗误输 URL 的用户，引导他们进入恶意网站。

选项 A 错误。针对性钓鱼是针对特定的个人或公司进行定制尝试以窃取信息。该场景围绕拼写错误展开，而不是针对性的电子邮件攻击。

选项 B 错误。水坑攻击涉及入侵目标经常使用的特定网站或服务。它不依赖于拼写错误。

选项 D 错误。中间人攻击涉及攻击者秘密地截获并可能更改双方之间的通信。场景中并未描述此类情况。
