Question 58. In a microservices architecture, each service should be designed with a specific principle to ensure it performs a specific task and interacts with other services through well-defined interfaces. What principle is this referring to?

+   (A) Principle of Least Privilege
(B) Single Responsibility Principle
(C) Open-Closed Principle
(D) Zero Trust Model

**Explanation 58. Correct Answer: Single Responsibility Principle.** The Single Responsibility Principle dictates that a class or module (or in the context of microservices, a service) should have only one reason to change, meaning it should only have one job or responsibility. In microservices, this ensures that each service does one thing and does it well, and interacts with others through clear interfaces.

**Option A is incorrect.** The Principle of Least Privilege is about ensuring that users or services have only the permissions they need to perform their tasks and nothing more. It’s not specifically about the design of the service itself.
