**问题 403。** XYZ Corp 正在设计其新的 Web 应用程序基础设施。他们希望确保进入和离开应用程序的所有 Web 流量都是加密的。除了选择 HTTPS 作为协议外，他们应该为这种加密流量配置哪个默认端口？

- (A) 21
- (B) 80
- (C) 443
- (D) 25

**解释 403. 正确答案：C. 443。** 443 是 HTTPS（基于 SSL/TLS 的 HTTP）流量使用的默认端口。它确保了 Web 流量经过加密，并在客户端和服务器之间提供了安全的通信通道。

**选项 A 错误。** 端口 21 是 FTP（文件传输协议）的默认端口，用于传输文件，而不是加密的 Web 流量。

**选项 B 错误。** 端口 80 是 HTTP 的默认端口，它是未加密。

**选项 D 错误。** 端口 25 是 SMTP（简单邮件传输协议）的默认端口，用于电子邮件传输，而不是加密的 Web 流量。

**问题 404。** 一公司正在开发一个新的 Web 应用程序，该程序将处理高度敏感的用户数据。他们希望确保如果 Web 服务器被破解，攻击者无法直接访问数据库或其他关键基础设施。以下实现这一目标的最佳策略是？

- (A) 为 Web 应用程序使用强身份验证方法
- (B) 对静态和传输中的用户数据进行加密
- (C) 将 Web 服务器和数据库服务器置在不同的网络段中
- (D) 对 Web 服务器进行实时监控

**解释 404. 正确答案：C. 将 Web 服务器和数据库服务器置在不同的网络段中。** 通过将 Web 服务器和数据库服务器置在不同的网络段中，公司可以实现隔离。这意味着即使 Web 服务器被破解，攻击者仍然需要突破额外的安全措施才能访问数据库服务器或基础设施的其他关键部分。

**选项 A 错误。** 虽然使用强身份验证方法很重要，但它无法在 Web 服务器与其他关键组件之间提供隔离。

**选项 B 错误。** 加密用户数据对数据保护至关重要，但它无法在 Web 服务器与其他系统之间提供基于网络的隔离。

**选项 D 错误。** 实时监控可以对可疑活动提供警报，但它无法提供所需的隔离效果。

**问题 405。** 在发生重大故障后，CloudTech Services 正在审查其灾难恢复策略。公司发现，从备份恢复后，由于配置差异，几个应用程序未能正常运行。未来确保成功恢复的最佳方法是什么？

- (A) 根据重要性对应用程序进行备份排序
- (B) 在全量备份的基础上实施差异化备份
- (C) 定期在测试环境中进行全系统恢复
- (D) 使用第三方备份解决方案而非内部解决方案

**解释 405. 正确答案：C. 定期在测试环境中进行全系统恢复。** 通过在测试环境中进行全系统恢复，CloudTech 可以模拟真实世界的恢复场景。这有助于识别任何在常规备份期间可能被遗漏的差异、配置问题或应用程序依赖关系，确保在关键需要时能够成功恢复。

**选项 A 错误。** 根据重要性对应用程序进行备份排序无法解决配置差异或应用程序之间的相互依赖问题。

**选项 B 错误。** 实施差异备份虽然在捕捉变化方面很有用，但无法解决恢复期间发现的配置差异。

**选项 D 错误。** 使用第三方解决方案而非内部解决方案本身不能保证成功恢复，也无法解决配置差异这一特定问题。

**问题 406。** GlobalBank 实施了一种备份策略，仅记录自上次全量备份以来的更改。考虑到优化存储和减少备份时间的需求，IT 团队每天执行此类备份。GlobalBank 使用的是哪种备份频率和类型？

- (A) 每日增量备份
- (B) 每周差异备份
- (C) 每两周全量备份
- (D) 每日快照备份

**解释 406. 正确答案：A. 每日增量备份。** GlobalBank 仅捕捉自全量备份后的更改，这是增量备份的特征。此外，他们每天执行此类备份，表明频率为每日。

**选项 B 错误。** 差异备份捕捉自上次全量备份以来的更改，但在下一次全量备份之前会不断增大，而增量备份在每次备份后都会重置。

**选项 C 错误。** 全量备份包含所有数据，无论是否有变化，且场景未提到每两周一次。

**选项 D 错误。** 快照备份捕捉特定时间的状态，但场景明确提到了自上次全量备份的更改。

**问题 407。** 一公司最近部署了一个新的电子商务应用程序。安全团队希望确保能够检测到应用程序上的未经授权或恶意活动。以下哪种方法实现此目标最有效？

- (A) 对应用程序进行渗透测试
- (B) 在应用程序前安装防火墙
- (C) 对应用程序的日志和活动进行持续监控
- (D) 为用户提供安全浏览习惯培训

**解释 407. 正确答案：C. 对应用程序的日志和活动进行持续监控。** 对应用程序日志和活动的持续监控允许安全团队实时检测并响应任何可疑或未经授权的行为。这确保了及时识别并处理潜在威胁，增强应用程序的安全态。

**选项 A 错误。** 虽然渗透测试可以识别应用程序的漏洞，但它不提供对持续恶意活动的监控检测能力。

**选项 B 错误。** 虽然防火墙可以通过过滤恶意流量提供一层安全，但它无法提供检测应用程序内部所有未经授权活动所需的细粒度见和实时监控。

**选项 D 错误。** 为用户提供安全浏览习惯培训很重要，但它无法直接帮助监控或检测应用程序上的恶意活动。
