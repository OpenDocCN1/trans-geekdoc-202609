**第 466 题。** CyberSecure Inc. 正在评估潜在安全泄露对其主服务器造成的财务影响。该公司估计，该服务器的泄露将导致由于数据恢复、法律费用和罚款而产生 500,000 美元的直接财务损失。以下哪项最能代表这一估算？

- (A) 均年发生率 (ARO)
- (B) 总拥有成本 (TCO)
- (C) 单次损失期望 (SLE)
- (D) 均化损失期望 (ALE)

**解释 466。** **正确答案：C. 单次损失期望 (SLE)。** 单次损失期望代表每次风险发生时预期的金钱损失。

在这种情况下，公司正在估计单次泄露事件导致的直接财务损失。

**选项 A 是错误的。** 均年发生率 (ARO) 代表预计该事件在一年内发生的频率，而不是单次事件的成本。

**选项 B 是错误的。** 总拥有成本 (TCO) 指的是特定资产或解决方案在整个生命周期内的完整拥有成本，而不是单次事件的成本。

**选项 D 是错误的。** 均化损失期望 (ALE) 是根据 SLE 和 ARO 计算出的值，代表预期的年度损失。

**第 467 题。** SecureWeb LLC 是一家 Web 托管公司，在过去五年中历经了两次服务器泄露。他们目前正在分析与其基础设施相关的风险。以下哪项最能代表服务器泄露的均年发生率 (ARO)？

- (A) 0.2
- (B) 0.4
- (C) 0.2
- (D) 0.5

**解释 467。** **正确答案：B. 0.4。** 均年发生率 (ARO) 是衡量事件预计每年发生的频率的指标。鉴于五年内发生了两次泄露，ARO 应为 2 次泄露除以 5 年，即 0.4。

选项 A 错误。虽然结果接近，但 ARO 的计算方法应该是发生次数（2）除以年数（5），结果为 0.4，而不是 0.2。

选项 C 是错误的。这表明每年都会发生两次泄露，与题中描述的情况不符。

选项 D 是错误的。这表明泄露每年发生五次，与场景不符。

**第 468 题。** 一家电子商务公司最近面临一次 DDoS 攻击，导致其网站无法使用数小时。在反思该事件时，首席信息安全官（CISO）强调了制定详细计划的重要性，包括识别、遏制、根、恢复和教训。哪种策略主要涵盖这些处理安全事件的阶段？

- (A) 变更管理策略
- (B) 事件响应策略
- (C) 灾难恢复策略
- (D) 远程访问策略

**解释 468。** **正确答案：B. 事件响应策略。** 事件响应策略概述了有效响应和管理安全事件的程序和指南。它包含了识别、遏制、根、恢复和教训等多个阶段，以确保处理安全威胁的系统方法。

**选项 A 是错误的。** 变更管理策略侧重于对 IT 环境进行更改的程序和指南，以确保稳定性和安全性。它直接处理安全事件。

**选项 C 是错误的。** 灾难恢复策略涉及在灾难性事件后恢复 IT 系统、应用程序和数据，而不是管理安全事件的步骤。

**选项 D 是错误的。** 远程访问策略详细说明了从远程位置访问组织网络的指南。它没有提供处理安全事件的结构化方法论。

**第 469 题。** AlphaCorp 处于处于选择网络安全顾问的最后阶段。在入围的名单中，SecureWorld 最近聘佣了 AlphaCorp 的前 CISO 担任高级顾问。考虑到这种情况，AlphaCorp 在选择供应商时应该立即关注的问题是什么？

**选项 B 是错误的。** 价格和折扣不是选择选择时与潜在利益冲突相关的主要问题。

**选项 D 是错误的。** 虽然全球布局和声誉是选择供应商的重要因素，但它们没有直接解决潜在的利益冲突。

**第 470 题。** WebServ Corp. 是一家 Web 托管公司，在过去五年中经历了两次服务器泄露。他们目前正在分析与其基础设施相关的风险。以下哪项最能代表服务器泄露的平均故障间隔时间 (MTBF)？

- (A) 恢复时间目标 (RTO)
- (B) 平均修复时间 (MTTR)
- (C) 平均故障间隔时间 (MTBF)
- (D) 恢复点目标 (RPO)

**解释 470。** **正确答案：C. 平均故障间隔时间 (MTBF)。** 平均故障间隔时间 (MTBF) 是系统或组件运行期间可靠性的衡量。鉴于五年内发生了两次泄露，MTBF 应为 5 年除以 2 次，即 2.5 年。

选项 A 是错误的。恢复时间目标 (RTO) 是业务流程中断后必须恢复的目标时间或水平。

选项 B 是错误的。平均修复时间 (MTTR) 代表修复故障组件所需的平均时间。

选项 D 是错误的。恢复点目标 (RPO) 衡量在不对业务连续性造成不可接受的影响的情况下可以丢失的数据量（以时间计）。
