**第 54 题。** SecureTech Corp 是一家处理敏感客户数据的公司，正在重新设计其主办公室入口以增强安全性。他们希望确保一次只有一个人可以访问，即使有多人尝试使用同一个授权门禁卡进入。以下哪种方案可以实现这一目的？

- (A) CCTV 摄像头
- (B) 间道锁 (Mantrap)
- (C) 生物识别扫描
- (D) 运动检测器

**解析 54. 正确答案：B. 间道锁 (Mantrap)。** 间道锁也称为访问控制门室，是一种物理安全访问控制系统，由一个带有两组互锁门的小型空间组成。第一扇门必须在第二扇门打开之前关闭，以确保一次只有一个人通过。这种设计防止了“尾随”（tailgating）和“搭便”（piggybacking），即未经授权的人员试图跟在授权人员后面进入安全区域。

**选项 A 错误。** 虽然 CCTV 摄像头可以监控并记录活动，但它们无法从物理上阻止多人使用同一个门禁卡同时进入。

**选项 C 错误。** 生物识别扫描仪提供了根据独特的物理或行为特征验证身份的方法，但它们无法防止他人尾随其后。

**选项 D 错误。** 运动检测器可以检测移动，但无法限制多个尝试使用同一个授权门禁卡的人员进入。

**第 55 题。** 在设置一个新的内部 Web 应用时，系统管理员 Laura 决定使用数字证书进行 SSL/TLS 加密。由于预算限制，她无法从商业证书颁发机构 (CA) 证书。以下哪个是 Laura 安全应用程序的可行方案？

- (A) 应用程序依赖明文 HTTP
- (B) 从免费证书颁发机构获取证书
- (C) 生成自签名证书
- (D) 使用来自另一个应用程序共享证书

**解析 55. 正确答案：C. 生成自签名证书。** Laura 可以在不需要证书颁发机构的情况下生成自签名证书。虽然自签名证书在面向公众的应用程序中会导致信任问题（因为它们没有经过认可的 CA 签名），但对于内部应用程序来说是合适的，因为可以通知用户并手动建立信任。

**选项 A 错误。** 依赖明文 HTTP 不为应用程序提供任何加密或安全性，使其容易受到各种攻击。

**选项 B 错误。** 虽然从免费证书颁发机构获取证书是一个有效选项，但考虑到强调不使用 CA 的特定场景，这不是最佳选择。

**选项 D 错误。** 使用来自另一个应用程序的共享证书可能会引入安全风险，不是推荐的做法。

**第 56 题。** 网络管理员收到了一个针对关键任务应用程序的新安全补丁。在现环境中应用此补丁之前，以下哪项是**最佳**操作？

- (A) 立即应用补丁以确保系统安全
- (B) 通知所有用户由于补丁导致的即将发生的停机时间
- (C) 在单独的测试环境中测试补丁
- (D) 仅对关键任务应用程序进行备份

**解析 56. C. 在单独的测试环境中测试补丁。** 在将补丁部署到生产环境之前，在单独环境中测试任何更改（包括补丁）都是至关重要的，以确保没有意外的技术影响。这是变更管理流程的关键方面，有助于防止引入系统停机或漏洞。

**选项 A 错误。** 虽然应用补丁对于维护安全至关重要，但在未经过适当测试的情况下立即执行会导致不可预的技术问题。

**选项 B 错误。** 通知用户很重要，但在先测试补丁之前通知他们还时过早了。

**选项 D 错误。** 备份是一个良好的习惯，但它不能替代先测试补丁。

**第 57 题。** TechCo 在其数据库系统实施了重大安全更新后，经历了意外的停机和系统不兼容问题。CISO 希望确保未来此类事件能够被快速解决。TechCo 在部署更新之前应该具备以下哪项措施？

- (A) 所有更新的完整列表
- (B) 自动系统恢复系统
- (C) 备份计划
- (D) 更新的详细用户手册

**解析 57. 正确答案：C. 备份计划。** 备份计划是一种策略或程序set，用于在更新产生不利影响时撤销更改，使系统恢复到稳定状态。

**选项 A 错误。** 虽然拥有所有更新的完整列表有利于记录，但它无法直接帮助缓解影响。

**选项 B 错误。** 自动系统恢复工具可能协助撤销更改，但备份计划更特定于撤销更改。

**选项 D 错误。** 更新的详细用户手册有助于培训和故障排除，但它无法撤销意外的更改。

**第 58 题。** 一家金融机构每天处理数千笔信用卡交易。为了确保这些交易的安全完整性，安全官希望采用一种能够安全管理和存储加密密钥的解决方案。以下哪种是最合适的解决方案？

- (A) 可信平台模块 (TPM)
- (B) 全盘加密 (FDE)
- (C) 硬件安全模块 (HSM)
- (D) 软件密钥库

**解析 58. 正确答案：C. 硬件安全模块 (HSM)。** 硬件安全模块 (HSM) 是专门设计用于管理、处理和存储加密密钥的物理设备。它们提供了针对物理和逻辑攻击的高级保护，并常用于金融机构以确保高价值交易的安全。

**选项 A 错误。** 虽然 TPM 为单个设备提供硬件级安全，但它们并非为处理大量交易的机构加密需求设计的。

**选项 B 错误。** 全盘加密 (FDE) 硬盘上的静态数据，但没有专门管理交易中使用的加密密钥。

**选项 D 错误。** 虽然软件密钥库可以存储加密密钥，但缺乏 HSM 提供的相同物理和逻辑保护。

**第 59 题。** 在建立安全通信通道期间，Alice 和 Bob 需要协商一个共享密钥，而不是直接向对方发送，因为他们担心被窃听。哪种协议最能满足这一需求？

- (A) RSA
- (B) HMAC
- (C) Diffie-Hellman
- (D) AES

**解析 59. 正确答案：C. Diffie-Hellman。** Diffie-Hellman 密钥交换协议允许双方生成公私钥对，交换公钥，然后派导出共享密钥。该密钥可用于对称加密。该协议的精妙之处在于，共享密钥密钥无需直接通过通信通道传输，从而防止窃听者直接获取密钥密钥。
