# Answers 301-400

**问题 301.** 一家金融机构正在实施一种系统，客户可以在不访问原始数据的情况下验证其每月账单的完整性。以下哪种技术最适用于此任务？

- (A) 使用 AES 对账单进行加密
- (B) 压缩账单以减小文件大小
- (C) 对账单进行哈希处理并向客户提供哈值
- (D) 对账单中的敏感数据进行令牌化（Tokenizing）

**解释 301.** **正确答案：C. 对账单进行哈希处理并向客户提供哈值。** 哈希可确保数据完整性。客户可以对收到的账单进行哈希，并与提供的哈希值进行比较，以验证数据未被更改。

**选项 A 错误。** 虽然 AES 是一种强加密方法，但对账单进行加密无法让客户验证账单的完整性。它更多是确保机密性而非完整性。

**选项 B 错误。** 压缩账单只是为了便于存储或传输减小文件大小；它没有帮助验证数据完整性。

**问题 302.** 一家公司正在开发一个新的视频会议工具。他们希望确保参与者之间传输的所有视频和音频数据都经过加密并免受窃听。开发者应该实施哪种类型的加密来实现这一目标？

- (A) 端点加密
- (B) 传输层加密
- (C) 卷加密
- (D) 数据库级加密

**解释 302.** **正确答案：B. 传输层加密。** 传输层加密旨在确保数据传输过程的安全。通过实施这种加密，公司可以确保视频会议期间视频和音频数据的机密性，保护参与者的隐私。

**选项 A 错误。** 端点加密适用于笔记本电脑或手机等特定设备上的数据。

**选项 C 错误。** 卷加密涉及加密逻辑驱动器或卷，不适用于传输数据。

**选项 D 错误。** 数据库级加密保护数据库内部的数据，不适用于网络传输。

**问题 303.** 一家全球金融公司最近因运营区域发生意外灾难而导致停机。该公司希望有一个备份站点，允许其在最小停机时间和零数据丢失的情况下继续运营。哪种类型的备份站点对该公司最合适？

- (A) 冷备（Cold site）
- (B) 温备（Warm site）
- (C) 热备（Hot site）
- (D) 移动站点（Mobile site）

**解释 303.** **正确答案：C. 热备。** 热备是一个完全运行的异地数据中心，可以在灾难发生后立即恢复运营。它拥有所有必要的设备和最新的数据备份，适用于需要最小停机时间和无数据丢失的情况。

**选项 A 错误。** 冷备提供空间和基础设施，但没有即时设备。

**选项 B 错误。** 温备拥有部分设备，但需要时间进行完全配置和更新。

**选项 D 错误。** 移动站点是便式的，通常不用于全面的灾难恢复。

**问题 304.** 在例检期间，IT 技术人员注意到公司服务器上的几个文件被重命名为“.locked”扩展名，并且根目录下存在一个名为“README_TO_RECOVER_FILES.txt”的新文件。根据这些指标，最可能发生哪种类型的恶意活动？

- (A) 蠕虫传播
- (B) 木马执行
- (C) 勒索软件攻击
- (D) 逻辑炸弹激活

**解释 304.** **正确答案：C. 勒索软件攻击。** 勒索软件是加密用户数据并索要解密密钥的恶意软件。勒索说明和文件扩展名是勒索软件攻击的典型指标。
