**Question 249.** A medium-sized e-commerce company recently experienced a data breach due to an external attack. Post-incident analysis revealed that while there were indications of the attack in their network traffic, no alarms were raised at the time of the attack. The company now wants to implement a solution to actively monitor and take action against malicious network traffic. Which of the following should they deploy?

+   (A) Intrusion Detection System (IDS)
(B) Network Access Control (NAC)
(C) Proxy server
(D) Intrusion Prevention System (IPS)

**Explanation 249.** **Correct Answer: D. Intrusion Prevention System (IPS).** An Intrusion Prevention System (IPS) not only detects malicious network activities but also takes active steps to prevent or block them, which is ideal for a company looking to bolster its defenses against real-time threats.
