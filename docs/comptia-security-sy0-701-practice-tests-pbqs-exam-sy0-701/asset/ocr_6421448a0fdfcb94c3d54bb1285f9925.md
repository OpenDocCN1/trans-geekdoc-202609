Question 300. A financial institution is implementing a system where customers can verify the integrity of their monthly statements without having access to the original data. Which of the following techniques would be MOST appropriate for this task?

+   (A) Encrypting the statements using AES
(B) Compressing the statements to reduce file size
(C) Hashing the statements and providing the hash value to the customers
(D) Tokenizing sensitive data within the statements

Explanation 300. **Correct Answer: C. Hashing the statements and providing the hash value to the customers.** Hashing can be used to ensure data integrity. Customers can hash the statement they receive and compare it with the provided hash value to verify that the data hasn’t been altered.

Option B is incorrect. Compressing the statements merely reduces the file size for case of storage or transmission; it doesn’t help in verifying data integrity.

Option D is incorrect. Tokenization replaces sensitive data with non-sensitive placeholders. It doesn’t offer a way to verify the integrity of the entire statement.
