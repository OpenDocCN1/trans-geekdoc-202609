**问题 95。** 一家公司希望确保值人员能够尽可能地检测并处理安全事件。为了这一目的，实施以下哪些运营安全控制措施是**最佳**的？

- (A) 部署网络入侵防御系统 (NIPS)
- (B) 建立 24/7 安全运营中心 (SOC)
- (C) 创建公司范围的安全策略
- (D) 实现端到端数据加密

**解释 95. 正确答案：建立 24/7 安全运营中心 (SOC)。** 安全运营中心 (SOC) 是一种运营控制措施，提供对安全事件的实时监控、检测和响应。通过 24/7 SOC，公司可以确保始终有人员处理随时发生的安全事件。

**选项 A 是错误的。** 部署网络入侵防御系统 (NIPS) 是一种技术控制措施。虽然它可以防止网络上的未经授权活动，但它不能确保有人员全天候待命来处理事件。

**选项 C 是错误的。** 创建公司范围的安全策略是一种管理控制措施。它设定了安全准则和程序，但不能确保对事件进行持续监控和即时响应。

**选项 D 是错误的。** 实现端到端数据加密是一种确保数据机密性的技术控制措施。虽然它保护了数据，但不能确保事件由值班人员实时检测并处理。

**问题 96。** 作为改进安全态势的一部分，TechHive Inc. 决定审查其现有的密码策略。当前策略要求员工使用至少一个大写字母、一个数字和一个特殊字符。然而，他们发现用户在重置密码时，大多数只对密码进行微小的更改。应该将哪种标准集成到他们的策略中，以确保密码随时间推移变得复杂且独特？

- (A) 密码历史保留
- (B) 密码过期期
- (C) 账户锁定时长
- (D) 最大密码年龄

**解释 96. 正确答案：A. 密码历史保留。** 密码历史保留确保用户无法重复使用一定数量的旧密码，迫使他们想独特的密码，而不是仅对当前密码进行微调。

**选项 B 是错误的。** 密码过期期规定了密码在提示用户更改之前有效持续多长时间。虽然它可以让用户频繁更改密码，但不能阻止他们进行微小的更改。

**选项 C 是错误的。** 账户锁定时长指定了在预定义的次数错误登录尝试后账户被锁定的时间。它不能确保密码随时间推移的复杂性或唯一。

**选项 D 是错误的。** 最大密码年龄定义了密码在必须更改之前可以使用多长时间。与选项 B 一样，它不能阻止用户对密码进行微小的更改。

**问题 97。** 一家中型企业在经历一系列恶意软件感染后，对其办公工作站的安全性表示担忧。作为安全分析师，以下哪项建议能**最佳**提高工作站的安全基准？

- (A) 安装多个杀毒软件以确保最大的检测率
- (B) 实现应用程序白名单
- (C) 禁用不需要的服务和端口
- (D) 定期更新桌面壁纸

**解释 97. 正确答案：C. 禁用不需要的服务和端口。** 通过禁用不需要的服务，组织减少了工作站的攻击面，从而提高了安全基准。

**选项 A 是错误的。** 安装多个杀毒软件可能会导致软件冲突和性能下降，而不一定能提高基准安全态势。

**选项 B 是错误的。** 虽然应用程序白名单是一种有效的控制措施，但禁用不必要的的服务和端口通常被视为建立强大安全基准的更基础的第一步。

**选项 D 是错误的。** 定期更新桌面纸是一种审美选择，对工作站的安全性没有影响。

**问题 98。** 在两家大型公司进行重大合并后，安全团队进行了全面评估，以识别合并基础设施中的潜在差距。这是哪种风险评估？

- (A) 循环的 (Recurring)
- (B) 持续的 (Continuous)
- (C) 一次性的 (One-time)
- (D) 动态的 (Dynamic)

**解释 98. 正确答案：C. 一次性的 (One-time)。** 一次性风险评估是为了特定的目的或事件（如合并）进行的，不会定期重复。

**选项 A 是错误的。** 循环性风险评估按固定间隔执行，例如每年或每两年一次。

**选项 B 是错误的。** 持续评估涉及对风险的持续监控，不是指单次评估。

**选项 D 是错误的。** 动态评估不断适应不断变化的环境或因素。

**问题 99。** XYZ 公司最近面临了影响其主数据中心的大规模停电。在事件期间，发现没有关于维持或快速恢复业务运营的明确指导意见。为了解决这个问题，XYZ 公司应该优先考虑实施以下哪种策略？

- (A) 数据分类策略
- (B) 业务连续性策略
- (C) 可接受使用策略
- (D) 网络分策略

**解释 99. 正确答案：B. 业务连续性策略。** 业务连续性策略概述了企业在灾难期间和之后应确保关键功能可以继续运行的流程和程序。它为维持和快速恢复业务运营提供了路线。

**选项 A 是错误的。** 数据分类策略关注根据敏感性对数据进行分类，但不涉及中断期间的业务连续性。

**选项 C 是错误的。** 可接受使用策略规定了员工如何使用公司的 IT 资源和网络。它没有提供灾难期间恢复业务运营的指导。

**选项 D 是错误的。** 虽然网络分策略对于安全至关重要，但将网络划分段并没有专门针对重大中断的连续性。

**问题 100。** 软件开发公司 CyberFleet Inc. 最近听说他们高度依赖的一个第三方库发现了一个新漏洞。安全团队迅速聚集，以理解并分析与该漏洞相关的潜在风险。这种自发的评估最好描述为：

- (A) 常规的 (Routine)
- (B) 临时的 (Ad hoc)
- (C) 计划的 (Scheduled)
- (D) 基准的 (Benchmark)

**解释 100. 正确答案：B. 临时的 (Ad hoc)。** 临时风险评估是针对特定事件或情况进行的，不是提前计划的。

**选项 A 是错误的。** 常规评估与定期评估类似，按固定间隔执行，通常不是针对突发事件的响应。

**选项 C 是错误的。** 计划性风险评估是预先计划并在预定的时间或间隔进行的。

**选项 D 是错误的。** 基准评估是将组织的流程或性能与行业设的标准或最佳实践进行比较的评估。
