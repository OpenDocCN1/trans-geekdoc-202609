Question 77. An online retailer is considering various methods to protect its customers’ credit card information. Instead of storing the actual credit card numbers in their database, they opt for a solution that replaces the numbers with unrelated, random values. What is this method called?

+   (A) Symmetric encryption
(B) Digital watermarking
(C) Hashing
(D) Tokenization

Explanation 77. Correct Answer: D. Tokenization.
Tokenization is a method where sensitive data is replaced with non-sensitive substitutes, referred to as ‘tokens’. These tokens act as references to the original data but don’t contain the actual sensitive data, making it a preferred method for protecting credit card information in many retail environments.

Option A is incorrect. Symmetric encryption is a method of encrypting data using a single key for both encryption and decryption. It changes the original data into a ciphered format but doesn’t replace it with random values as tokenization does.

Option B is incorrect. Digital watermarking embeds data into a digital signal, primarily for asserting rights or ownership and not for replacing sensitive data with random values.
