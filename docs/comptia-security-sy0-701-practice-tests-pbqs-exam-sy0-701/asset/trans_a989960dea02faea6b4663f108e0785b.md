
解析 24。正确答案：C. 从经过验证的备份恢复系统。从经过验证的备份恢复系统是一种纠正控制，因为它可以将受损的系统恢复到最后已知的良好。此操作纠正了入侵带来的负面影响，并确保任何恶意更改都被删除。

选项 A 错误。实施入侵检测系统（IDS）是一种检测性控制。它监控并检测网络中的恶意活动，但不能纠正入侵带来的负面影响。

选项 B 错误。频繁更新防火墙规则是一种预防措施，旨在阻止恶意流量并防止潜在的入侵。虽然这至关重要，但它不能纠正已经发生的入侵的影响。

选项 D 错误。启用多因素认证是一种预防性控制，旨在提供额外的验证层。虽然它增强了安全性，但不能纠正入侵带来的负面影响。

问题 25。Bob 收到一封邮件，提示他点击链接以验证身份。该链接将他引导至网页，他必须在那里提供用户名、密码并回答一个个人安全问题。这里使用的是哪种身份验证方法？

- (A) 生物识别认证
- (B) 基于令牌的认证
- (C) 双因素认证
- (D) 单点登录

解析 25。正确答案：C. 双因素认证。双因素认证（2FA）是一种安全流程，用户提供两个不同的身份验证因素来验证其身份。在这种场景中，Bob 提供了他所知道的东西（用户名和密码），并回答了一个个人安全问题，这是“他所知道的东西”的另一种形式。

选项 A 错误。生物识别认证涉及使用个人独特的物理或行为特征进行验证，例如指纹或面部识别模式。场景中没有提到任何生物识别数据。

选项 B 错误。基于令牌的认证通常涉及使用生成时间敏感代码的硬件或软件令牌。场景中并未描述此类内容。

选项 D 错误。单点登录（SSO）允许用户登录一次即可访问多个系统，而无需在每个系统都提示重新登录。场景描述的是双因素认证过程，而不是 SSO。

问题 26。为了尽可能减少由恶意软件导致的数据泄露，某公司正在决定一种控制措施，以防止恶意软件在公司设备上执行。以下哪项是最好的预防性控制？

- (A) 部署网络入侵检测系统 (NIDS)
- (B) 定期备份关键数据
- (C) 安装带有实时扫描功能的防病毒毒软件
- (D) 在安全事件后进行取证分析

解析 26。正确答案：C. 安装带有实时扫描功能的防病毒毒软件。

问题 27。在经历重大基础设施升级后，GlobalMed 公司遇到了几个意外之外的安全问题。回想起来，IT 经理意识到他们在变更管理过程中跳过了一个关键步骤，该步骤本可以预测并缓解这些问题。他们最可能忽略了哪一步？

- (A) 采购新硬件
- (B) 对 IT 人员进行新系统培训
- (C) 影响分析
- (D) 与旧系统的集成

解析 27。正确答案：C. 影响分析。影响分析在变更管理过程中至关重要，因为它评估了拟议变更的潜在后果。通过进行这种分析，组织可以预判潜在的安全并在实施变更之前对其进行缓解。

选项 A 错误。虽然采购至关重要，但仅仅购买新硬件并不能直接帮助预测或缓解来自基础设施升级的潜在安全问题。

选项 B 错误。对 IT 人员进行培训对于有效实施和运行至关重要，但它没有直接解决预测和理解升级带来的潜在安全后果。

选项 D 错误。与旧系统的集成是一项关键考量，特别是在兼容性方面。然而，场景的重点在于预测和理解潜在的安全问题，这主要通过影响分析来解决。

问题 28。MegaCorp 最近为其客户推出了一个新的 Web 应用程序。在发布之前，该软件在控制环境中经过了严格测试。当该应用程序部署到生产环境时，报告了几个安全漏洞。以下哪个原因可以解释测试结果与实际漏洞之间的不匹配？

- (A) 测试环境是生产环境的精确复制
- (B) 测试结果没有经过彻底审查
- (C) 软件未针对零日漏洞进行测试
- (D) 在生产环境后进行了渗透测试

解析 28。正确答案：测试结果没有经过彻底审查。即使应用程序经过了严格测试，彻底审查和解释测试结果以识别任何潜在的安全漏洞也是至关重要的。未能审查或误读这些结果可能导致漏洞未被发现和未得到解决。

选项 A 错误。拥有一个与生产环境镜像的测试环境是最佳实践。这确保了测试对于软件在生产环境中的行为具有代表性。

选项 C 错误。虽然零日漏洞是一个令人关注的问题，但根据定义，它们是未知的漏洞。专门针对它们进行测试是挑战性的。然而，彻底的测试和审查流程可以缓解潜在风险。

选项 D 错误。渗透测试是安全测试不可或缺的方面，但在生产环境后进行并不能解释在初始测试结果未正确审查的情况下，测试结果与实际漏洞之间的不匹配。

问题 29。一家在线银行网站采用了一种系统，在用户闲置 10 分钟后自动注销，以确保如果用户忘记注销，其他人无法更改用户的银行详情。该银行网站最直接解决了 CIA 三要素中的哪种原则？

- (A) 机密性
- (B) 可用性
- (C) 身份验证
- (D) 完整性

解析 29。正确答案：D. 完整性。CIA 三要素中的完整性确保数据的准确性和可靠性。通过在闲置后注销用户，银行网站旨在防止他人（可能获得无人看会话权限）对用户的银行详情进行未经授权的修改，从而维护数据的完整性。

选项 A 错误。虽然注销用户具有机密性方面，但此场景中的主要目标是防止未经授权的修改而非未经授权的查看。

选项 B 错误。可用性确保授权用户在需要时可以访问数据和系统。此场景没有讨论基于系统运行时间或可用性的提供或限制访问。
