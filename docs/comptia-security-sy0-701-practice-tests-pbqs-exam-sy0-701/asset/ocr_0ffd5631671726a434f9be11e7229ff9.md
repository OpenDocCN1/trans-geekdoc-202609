# Explanation 308. Correct Answer: B. Restricted.

“Restricted” classification is used when access to the document or data needs to be limited to a particular group of individuals. In this scenario, only a select group of partners and stakeholders are allowed to view the overview document, making “Restricted” the most appropriate classification.

Option A is incorrect. “Public” classification would allow anyone to access the document, which is not suitable for this scenario.

Option C is incorrect. While “Confidential” classification would provide a level of protection, it doesn’t specifically restrict access to a defined group as “Restricted” does.

Option D is incorrect. “Top Secret” is a high-level classification that would be more appropriate for the detailed schematics and operational details rather than an overview document.
