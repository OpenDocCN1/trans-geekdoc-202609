问题 463。一家图形设计公司经常处理视频和高分辨率图像等大文件。这些文件存储在他们服务器的专用存储卷上。虽然他们需要保护这些数据，但由于数据量大且访问频繁，他们不想对单个文件加密。对于这种场景，哪种加密方法最合适？

- (A) 文件级加密 (File-level Encryption)
- (B) 全盘加密 (Full-disk Encryption)
- (C) 传输层加密 (Transport-layer Encryption)
- (D) 卷级加密 (Volume-level Encryption)

解析 463。 正确答案：D。卷级加密。卷级加密允许对特定卷或逻辑驱动器进行加密。在这种情况下，它允许公司加密存储这些大文件的整个卷，无需加密单个文件。这确保了整个卷的内容都已加密，同时在需要时提供无缝访问。

选项 A 错误。文件级加密虽然有效，但对大量大文件进行逐一加密会非常繁琐。

选项 B 错误。全盘加密会加密整个磁盘，如果只需要对特定卷进行加密，则没有必要。

选项 C 错误。传输层加密涉及传输中的数据，无法解决在卷层级加密存储数据的需求。

问题 464。Sarah 是一位项目经理，正在编写一份由她拥有的文档。她想向某些团队成员授予特定权限，允许某些人编辑，另一些人只能查看文档。以下哪种访问控制模型最能让 Sarah 完成这一目标？

- (A) 强制访问控制 (Mandatory Access Control (MAC))
- (B) 基于角色的访问控制 (Role-Based Access Control (RBAC))
- (C) 自主访问控制 (Discretionary Access Control (DAC))
- (D) 基于属性的访问控制 (Attribute-Based Access Control (ABAC))

解析 464。 正确答案：C。自主访问控制 (DAC)。DAC 允许资源所有者（在此例中为 Sarah）指定谁可以访问以及他们拥有什么权限（例如：读取、写入、执行）。这种灵活性正是 Sarah 所需要的，以便根据她的意愿向个人团队成员授予特定权限。

选项 A 错误。强制访问控制 (MAC) 基于分类和许可级别。它不符合 Sarah 在此场景中的需求。

选项 B 错误。基于角色的访问控制 (RBAC) 根据组织中的角色分配权限。它无法让 Sarah 对单个权限实现其所需的精细粒度控制。

选项 D 错误。基于属性的访问控制 (ABAC) 根据用户、环境和资源本身的属性来决定访问权限。虽然很灵活，但它并不像 DAC 那样以所有者的意愿为中心。

问题 465。MegaCorp 正在转向云基础架构，并允许员工访问多个云服务，而无需每次都重新输入凭据。他们目前有一个本地 LDAP 目录。MegaCorp 应该采取哪种方法来提供无缝的身份验证体验？

- (A) MegaCorp 应该放弃其 LDAP 目录并为每个云服务创建单独帐户
- (B) 将其 LDAP 与支持云服务的单点登录 (SSO) 解决方案集成
- (C) 将密码存储在明文文件中供用户访问并手动登录到云服务
- (D) 强制用户每天更改密码以增强所有云平台的安全性

解析 465。 正确答案：B。将其 LDAP 与支持云服务的单点登录 (SSO) 解决方案集成。通过将本地 LDAP 与 SSO 解决方案集成，MegaCorp 可以利用现有的用户目录进行身份验证并提供对多个云服务的访问，而无需为每个服务单独登录。

选项 A 错误。放弃现有的 LDAP 目录将消除集中管理的优势并产生管理开销。

选项 C 错误。明文存储密码是严重的安全风险，违反了最佳实践。

选项 D 错误。强制用户每天更改密码是不现实的，可能会导致密码变弱，并且无法提供无缝的身份验证体验。

问题 466。一家全球制造公司希望确保全球员工在工作期间不访问推广仇恨言论、赌博或内容的网站。为了满足这一需求，哪种过滤过滤最有效？

- (A) 部署具有基于位置过滤的中心化代理
- (B) 使用已知包含此类内容的 URL 黑名单
- (C) 实现内容分类并封锁不需要的类别
- (D) 监控互联网使用日志并惩罚违规者

解析 466。 正确答案：C。实现内容分类并封锁不需要的类别。内容分类是一种根据内容类型对网站进行分类的技术，例如“游戏”、“社交媒体”、“新闻”等。通过使用这种技术，组织可以封锁整个内容类别（如“仇恨言论”或“赌博”），确保广泛覆盖，而无需逐一识别每个问题的 URL。

选项 A 错误。虽然中心化代理可以帮助管理互联网访问，但基于位置的过滤更多关注地理位置而非内容类别。

选项 B 错误。仅依赖黑名单可能是无效的，因为需要不断更新以捕捉所有可能的有害 URL，并且可能无法快速覆盖新创建的站点。

选项 D 错误。仅仅监控互联网使用日志并惩罚违规者是事后性的，不能主动防止对不需要内容的访问。

问题 467。在 IT 审计期间，一家公司的加密实践受到了审查。IT 审计员建议增加某些应用程序密钥长度以提高安全性。增加密钥长度的主要原因是什么？

- (A) 加快加密解密过程
- (B) 确保与旧系统的兼容性
- (C) 减少暴力破解的可能性
- (D) 减少密钥管理开销

解析 467。 正确答案：C。减少暴力破解的可能性。增加密钥长度主要通过提高抵抗暴力破解的能力来增强加密安全性。暴力破解攻击尝试所有可能的组合，更长的密钥意味着更多的组合，使得攻击变得极其耗时且困难。

选项 A 错误。密钥密钥通常会减慢加密解密过程，因为需要更多的计算能力。

选项 B 错误。增加密钥长度可能会导致与不支持较长密钥的旧系统产生。

选项 D 错误。密钥管理开销通常随密钥长度而增加，因为需要管理和保护更多数据。

问题 468。PhCorp 确保其研究人员不会将专利方程式和研究数据传输到外部存储设备或云存储。公司需要一种解决方案来防止此类传输，同时允许其他类型的数据传输。他们应该实施？

- (A) Web 应用防火墙 (WAF)
- (B) 数据加密工具
- (C) 数据泄漏防护 (DLP)
- (D) 虚拟专用网络 (VPN)

解析 468。 正确答案：C。数据泄漏防护 (DLP)。数据泄漏防护 (DLP) 旨在检测潜在的数据泄露尝试并防止敏感数据的非法传输。通过在 DLP 解决方案中设置规则和标准，PharmaCorp 可以限制专利信息的传输，同时允许根据需要传输其他数据。
