
选项 D 错误。备份文件是文件或数据库的副本，可用于数据恢复。它不是用于检测未经授权访问的诱饵。

**问题 48.** 在最近发生一起蓄意破坏事件后，某公司大楼正在考虑实施安全控制以威慑潜在的犯罪者。以下哪项最能作为**威慑控制**？

- (A) 加密所有存储数据
- (B) 在所有入口安装生物识别访问控制
- (C) 实施定期数据备份
- (D) 放置指示 24/7 全候监控的可见安全标志

**解释 48. 正确答案：D。放置指示 24/7 全候监控的可见安全标志。** 可见的安全标志可以作为威慑控制手段，因为它通过信号传达被发现的风险和后果来劝阻潜在的犯罪者，即使实际监控并非一直处于激活状态。

**选项 A 错误。** 加密所有存储数据是一种预防性控制，确保未经授权的人员无法访问或理解加密信息。它不能威慑物理破坏行为。

**选项 B 错误。** 安装生物识别访问控制是一种预防性控制，根据独特的生物特征限制物理访问。虽然它能防止未经授权的访问，但它不能作为物理破坏或其他潜在威胁的可见威慑。

**选项 C 错误。** 实施定期数据备份是一种纠正性控制，旨在发生安全事件后恢复数据。它不能威慑潜在威胁。

**问题 49.**** Alice 想要访问一个受限的在线门户。该门户要求她输入唯一的用户名和一个她应该知道的秘密口令。这个过程帮助系统确保 Alice 是她所声称的。该门户正在采用哪种安全概念？

- (A) 授权 (Authorization)
- (B) 审计 (Accounting)
- (C) 多因素身份认证
- (D) 身份验证 (Authentication)

**解释 49. 正确答案：D。身份验证。** 身份验证是验证用户、系统或应用程序身份的过程。在描述的场景中，Alice 通过提供唯一的用户名和口令向系统证明她的身份，这些凭据据认为只有她本人拥有。

**选项 A 错误。** 授权决定了经过验证身份允许访问或执行哪些操作、资源或服务。它不涉及验证身份本身。

**选项 B 错误。** 审计涉及跟踪用户活动并记录它们以供审计目的。它不直接验证用户的身份。

**选项 C 错误。** 多因素身份认证需要来自不同类别凭据的两种或更多验证方法。场景中仅提到了用户名和口令，这是一种单因素身份认证方法。

**问题 50.**** XYZ 公司的网络安全负责人 Sophia 正在起草一项新的安全政策。在起草过程中，她主要咨询了她的安全团队。然而，在实施时，几个部门由于政策干扰了他们的运营而产生了反对。以下哪项最能描述 Sophia 在创建过程中犯的失误？

- (A) 没有使用标准的安全框架
- (B) 过度依赖自动化安全解决方案
- (C) 没有在政策起草过程中包含关键利益相关者
- (D) 过于关注外部威胁而非内部威胁

**解释 50. 正确答案：C。没有在政策起草过程中包含关键利益相关者。** 来自不同部门的利益者对于安全措施如何影响组织内的各种操作和流程提供了至关重要的见解。通过将他们纳入政策起草过程，Sophia 本可以获得反馈，这些反馈有助于制定出一项既能维护安全又能符合不同部门需求的政策。

**选项 A 错误。** 虽然使用标准的安全框架可以提供指导，但它并不一定考虑到组织内不同部门独特的运营需求。

**选项 B 错误。** 场景中没有提到对自动化安全解决方案的任何依赖（无论过度还是其他）。

**选项 D 错误。** 虽然外部和内部威胁都是重要的考虑因素，但这里的主要问题是缺乏与关键利益相关者的协商。

**问题 51.**** BioGen Inc. 一家生物技术公司实施了分层安全方法。他们正在考虑在其研究实验室的安全措施中加入人为因素。以下哪项最能提供通过人类判断评估和响应各种安全状况的能力？

- (A) 安装生物识别锁
- (B) 雇佣安保人员
- (C) 实施访问控制间（Vestibule）
- (D) 部署 AI 驱动的安全摄像头

**解释 51. 正确答案：B。雇佣安保人员。** 安保人员具有人类判断的优势，可以评估、响应并适应各种安全状况，使其成为分层安全方法中增加人为因素的理想选择。

**选项 A 错误。** 虽然生物识别锁可以根据独特的人特征控制访问，但它们不能提供人类安保人员的评估和响应能力。

**选项 C 错误。** 访问控制间控制进入区域的访问，通常有两扇门，但它不能提供安保人员提供的评估、判断或立即响应。

**选项 D 错误。** 虽然 AI 驱动的安全摄像头可以提供先进的监控并可能检测可疑活动，但它们不能替代人类安保人员的判断和立即响应能力。

**问题 52.** 在分析服务器日志时，IT 安全分析师 Mike 注意到一个不熟悉的文件被频繁访问。经过调查，他意识到该文件是安全团队故意放置的，没有任何实际数据，但被密切监控。该文件的目的最可能是：

- (A) 作为数据丢失时的冗余副本
- (B) 作为诱饵吸引并检测未经授权的访问
- (C) 为了审计维护所有用户记录
- (D) 加密后发送给客户的示例

**解释 52. 正确答案：B。作为诱饵吸引并检测未经授权的访问。** 蜜罐文件（Honeyfiles）作为欺骗措施，吸引潜在攻击者或未经授权的用户。如果此类文件被访问，可能表明系统存在可疑活动。

**选项 A 错误。** 冗余副本或备份是为了防止因意外导致的数据丢失，但它们不是作为诱饵被监控的。

**选项 C 错误。** 用户活动日志维护系统或应用程序中执行的操作，这与蜜罐文件等欺骗措施不同。

**选项 D 错误。** 发送给客户的加密示例有其他用途，通常不用于检测未经授权的访问。

**问题 53.** DataCenter Inc. 位于容易抗议和破坏的地区。他们希望增强边界安全以威慑潜在入侵者，并在视觉上明确限制未经授权的访问。以下哪种物理安全措施将是公司最有效的道防线？

- (A) 滑动门
- (B) 安全摄像头
- (C) 高安全围栏
- (D) 接近式读读器

**解释 53. 正确答案：C。高安全围栏。** 高安全围栏是一种主要的物理屏障，用于延迟、威慑和检测入侵。它提供了一个视觉信号，划定了私有财产，并可以配备铁丝网或传感器等额外的威慑措施。

**选项 A 错误。** 滑动门更适用于内部安全或入口点，不作为主要的外部屏障。
