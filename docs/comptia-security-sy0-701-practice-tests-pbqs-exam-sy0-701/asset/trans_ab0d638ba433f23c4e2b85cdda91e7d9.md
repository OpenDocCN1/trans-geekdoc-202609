**问题 308。** 一家国防商正在开发一种新的导弹系统。虽然详细的图纸和操作细节属于机密，但他们有一份只有少数合作伙伴和利益相关者可以查看概述文档。该概述文档应该如何分类？

- (A) 公开 (Public)
- (B) 受限制 (Restricted)
- (C) 机密 (Confidential)
- (D) 绝密 (Top Secret)

## 解析 308. 正确答案：B. 受限制 (Restricted)。

当文档或数据的访问需要限制在特定的个人组时，使用“受限制”分类。在这种场景中，仅允许少数合作伙伴和利益相关者查看概述文档，因此“受限制”是最合适的分类。

选项 A 错误。“公开”分类将允许任何人访问文档，这不适用于该场景。

选项 C 错误。虽然“机密”分类可以提供水平的保护，但它不像“受限制”那样专门将访问限制在定义的组内。

选项 D 错误。“绝密”是一个高级别的分类，更适用于详细的图纸和操作细节，而不是概述文档。

**问题 309.** 一家科技初创公司正在开发移动应用程序，由于许可协议，该程序仅向特定国家的用户提供专属内容。初创公司应该使用哪种方法确保只有该国家的用户可以访问内容？

- (A) 集成基于时间的一次性密码 (TOTP) 系统
- (B) 使用基于地理位置的访问控制 (Geolocation-based access controls)
- (C) 启用生物识别认证
- (D) 实现 IP 白名单 (IP whitelisting)

**解析 309. 正确答案：B. 使用基于地理位置的访问控制。** 基于地理位置的访问控制可以识别用户的地理位置，并根据预定义的地理边界允许或拒绝访问，这是最符合初创公司要求的解决方案。

**选项 A 错误。** TOTP 系统提供基于时间的二次身份验证。

**选项 C 错误。** 生物识别认证根据物理或行为特征验证用户身份，但不根据地理位置限制访问。

**选项 D 错误。** IP 白名单仅允许特定的 IP 地址访问。虽然它可以提供某种程度的地理限制，但没有基于地理位置的控制精确，并可能会无意中阻止或允许用户。

**问题 310.** MetroTech 最近发生了一起事件，一名员工不小心删除了数据库的一部分。IT 团队能够使用 24 小时前的备份快照恢复数据。然而，仍然丢失了一些数据。在未来的类似情况下，以下哪项建议可以最大限地减少数据丢失？

- (A) 配置每周拍摄一次备份快照
- (B) 在快照之外采用差异备份解决方案
- (C) 增加备份的存储容量
- (D) 使用每小时快照备份计划

**解析 310. 正确答案：D. 使用每小时快照备份计划。** 增加快照备份的频率（例如每小时一次），将确保丢失的最大数据量限制在一个范围内。与 24 小时的窗口相比，这最大限度地减少了数据丢失的可能性。

**选项 A 错误。** 每周快照实际上会增加潜在的数据丢失窗口，而不是减少它。

**选项 B 错误。** 虽然差异备份捕获自上次全备份以来的更改，但它们没有每小时快照那样直接解决频率问题。

**选项 C 错误。** 增加存储容量不会影响备份频率，而频率是减少数据丢失窗口的主要因素。
