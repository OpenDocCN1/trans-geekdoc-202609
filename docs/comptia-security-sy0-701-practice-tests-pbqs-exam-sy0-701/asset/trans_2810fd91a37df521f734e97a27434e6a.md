**问题 253。** 一家电子商务公司希望确保客户的信用卡数据在互联网上传输过程中保持机密性。他们正在寻找一种可以帮助保护其网站通信的协议。哪种协议最符合这一要求？

- **(A)** IPSec
**(B)** SSH
**(C)** TLS
**(D)** ICMP

**解释 253.** **正确答案：C. TLS。** 传输层安全协议 (TLS) 是一种加密协议，可确保互联网上数据的机密性和完整性。网站使用 TLS 来保护其服务器与网络浏览器之间的所有通信，非常适合电商平台保护敏感的客户数据。

**选项 A 是错误的。** IPSec 是一套协议，通过对所有 IP 数据包加密加密身份验证来保护 IP 通信。它更常被用于 VPN，而不是保护 Web 通信。

**选项 B 是错误的。** SSH（安全外壳）主要用于对系统的安全远程访问，而不是用于保护基于 Web 的通信。

**选项 D 是错误的。** ICMP（互联网控制消息协议）用于网络设备发送错误消息和操作信息，而不是用于保护传输中的数据。

**问题 254。** 在最近发生一次安全漏洞后，安全分析师 Sarah 正在实施额外措施来检测未经授权的活动。她决定在数据库中嵌入特定的值，这些值没有实际用途，但会对任何未经授权的访问或使用进行监控。这些值的设计一旦被访问或使用就会触发警报。这些特定值通常称为什么？

- (A) 安全标记 (Security flags)
(B) 蜜罐 (Honeypots)
**(C) 蜜罐令牌 (Honeytokens)
(D) 审计日志 (Audit trails)

**解释 254.** **正确答案：C. 从验证的备份恢复系统。** 从验证的备份恢复系统是一种纠正控制，因为可以将受损的系统恢复到最后一个良好状态。此操作纠正了入侵的不利影响，并确保删除了任何恶意更改。

**选项 A 是错误的。** 实施入侵检测系统 (IDS) 是一种检测控制。它监控并检测网络中的恶意活动，但不能纠正入侵的不利影响。

**选项 B 是错误的。** 频繁更新防火墙规则是一种预防性措施，旨在阻止恶意流量并防止潜在入侵。虽然这至关重要，但它不能纠正已经发生的漏洞的影响。

**选项 D 是错误的。** 启用多因素身份验证是一种预防性控制，旨在提供额外的验证层。虽然它增强了安全性，但不能纠正入侵的不利影响。

**问题 255。** Maria 收到了一条短信，内容称她赢得了一张价值 500 美元的礼品卡。短信来自一个未知号码，并包含一个链接。Maria 不确定该信息的真实性。以下哪种操作最符合 Maria 的情况？

- A) 点击链接
(B) 删除短信
**(C) 回复号码**
(D) 忽略短信

**解释 255.** **正确答案：C. 删除短信。** 删除短信是更安全的做法，可以避免点击潜在的恶意链接。短信钓鱼 (Smishing) 是一种攻击形式，攻击者通过短信欺骗用户泄露个人敏感信息。

**选项 A 是错误的。** 点击链接可能导致用户访问恶意网站或下载恶意软件。

**选项 B 是错误的。** 删除短信虽然是安全的，但题目问的是 Maria 在面对此类信息时的最佳操作。

**选项 D 是错误的。** 忽略短信虽然比点击好，但删除短信是更彻底的防止风险的措施。

**问题 256。** 在 AlphaTech，安全团队正在评估新部署基础设施的漏洞。他们考虑了物理位置、当地法律法规等因素。这些因素在漏洞管理中被称为什么？

- (A) 资产价值因素
(B) 风险响应
(C) 威胁情报
**(D) 环境因素

**解释 256.** **正确答案：D. 环境因素。** 环境因素是指影响组织安全态势的外部因素。

**解释 257.** **正确答案：C. 竞态条件 (Race Condition)。** 当应用程序的行为取决于操作的顺序或计时，且操作同时发生时就会产生竞态条件。这会导致不可预测的结果。
