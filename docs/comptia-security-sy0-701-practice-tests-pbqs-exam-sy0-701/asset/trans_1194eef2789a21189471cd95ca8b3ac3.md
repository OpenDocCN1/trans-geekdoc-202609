
哪些项是初始恶意软件感染点的迹象？

- (A) 显示用户成功登录和注销事件的日志
- (B) 显示系统定期健康检查状态为“OK”的条目
- (C) 记录最近从临时目录安装并执行的未知 .exe 文件的日志
- (D) 详细说明到域控制器的网络连接性检查的条目

**解释 426. 正确答案：C. 记录最近从临时目录安装并执行的未知 .exe 文件的日志。** 记录未知 .exe 文件安装和执行的端点日志（尤其是从临时目录执行的）是由于潜在恶意活动的强力迹象。此类日志可以确定位系统上恶意软件的初始感染点。

**选项 A 错误。** 用户登录和注销事件是常规日志，除非与其它可疑活动相关，否则不会提供有关恶意软件感染的具体信息。

**选项 B 错误。** 系统健康检查状态条目旨在提供系统健康状况的通用信息，并未说明与恶意软件相关的系统操作或更改。

**选项 D 错误。** 到域控制器的网络连接性检查在许多网络环境中是常规操作，不会直接指示恶意软件活动。

问题 427。GammaTech 为其员工实施了一项新的远程访问策略。当员工尝试从未知位置访问公司网络时，系统会在授予访问之前请求额外的验证。该策略强调了身份验证的哪种因素？

- (A) 员工回答的基于知识的问题
- (B) 员工的指纹扫描
- (C) 员工访问点的物理坐标
- (D) 发送到员工手机的短信验证码

**解释 427. 正确答案：C. 员工访问点的物理坐标。** 通过验证访问点的位置或坐标，GammaTech 利用利用多因素认证中的“你所在地”（somewhere you are）因素。这强调了用户的地理位置。

**选项 A 错误。** 基于知识的问题属于“你知道”因素，因为用户根据他们记忆的信息进行回答。

**选项 B 错误。** 指纹扫描属于“你特征”因素，因为它是生物识别，是个人特有的物理特征。

**选项 D 错误。** 发送到手机的短信验证码属于“你拥有的”因素，因为它是发送到用户拥有的设备上的。

问题 428。AlphaTech 的 IT 部门正在为远程工作人员推出新的身份验证协议。作为多因素认证过程的一部分，员工需要提供记忆且无法从物理上夺走的信息。以下哪项代表了这种身份验证因素？

- (A) 指纹
- (B) 智能卡
- (C) PIN 码
- (D) USB 安全密钥

解释 428. **正确答案：C. PIN。** 个人识别码（PIN）代表多因素认证中的“你知道”因素。这类信息由用户记忆，不是可以被夺走的物理物品或生物学特征。

选项 A 错误。指纹代表“你特征”因素，涉及生物识别。

选项 B 错误。智能卡代表“你拥有的”因素，因为它是用户拥有的物理物品。

选项 D 错误。USB 安全密钥也属于“你拥有的”因素。它是一个物理设备，而不是被记忆的信息。

问题 429。某公司设置了防火墙，允许 Web 流量通过 80 端口和 443 端口，同时默认拒绝所有其他流量。这种设置是哪种访问控制类型的示例？

- (A) 基于角色的访问控制 (RBAC)
- (B) 强制性访问控制 (MAC)
- (C) 任意性访问控制 (DAC)
- (D) 基于规则的访问控制 (RAC)

**解释 429. 正确答案：D. 基于规则的访问控制 (RAC)。** 基于规则的访问控制 (RAC) 根据管理员设置的定义规则运行。在描述的场景中，防火墙使用规则允许某些端口（80 和 443）的流量同时拒绝所有其他流量，这是 RAC 的典型示例。

**选项 A 错误。** RBAC 根据组织内的角色分配权限。防火墙规则通常不是根据用户角色分配的。

**选项 B 错误。** MAC 涉及信息分类并将用户许可级别与这些分类匹配。它与防火墙规则设置无关。

**选项 C 错误。** DAC 允许资源所有者指定谁可以访问其资源。防火墙规则设置并不是基于个人裁决的。

问题 430。WidgetCorp 的安全团队试图识别潜在的内部威胁。他们建立了一个 SIEM 解决方案，并配有一个显示异常活动的自定义仪表板。以下哪个仪表板对于快速识别员工将大量专有数据上传到外部云存储服务最有效？

- (A) 显示在非工作时间登录的用户
- (B) 网络带宽最高的用户图表
- (C) 最频繁使用的应用程序列表
- (D) 登录失败尝试的可视化

解释 430. 正确答案：B. 网络带宽最高的用户图表。当员工向外部服务上传大量数据时，通常会导致网络带宽急剧激增。因此，视觉化显示网络带宽最高用户的仪表板可以快速提醒安全团队注意潜在的数据外泄活动。

**选项 A 错误。** 虽然在非工作时间登录可能很可疑，但它与数据上传活动没有直接关联。

**选项 C 错误。** 最频繁使用的应用程序列表可能有助于确定组织内使用的常用工具，但它没有专门指向数据上传操作。

选项 D 错误。登录失败尝试的可视化无法直接指示数据活动。

问题 431。Sarah 是一个项目经理，正在处理一份她拥有的文档。她希望允许某些团队成员编辑文档，而其他人只能查看。以下哪种访问控制模型能实现这一点？

- (A) 强制性访问控制 (MAC)
- (B) 基于角色的访问控制 (RBAC)
- (C) 任意性访问控制 (DAC)
- (D) 基于属性的访问控制 (ABAC)

 解释 431. 正确答案：C. 任意性访问控制 (DAC)。DAC 允许资源所有者（在此情况下为 Sarah）指定谁可以访问它以及拥有什么权限（例如读取、写入）。

选项 A 错误。强制性访问控制 (MAC) 基于分类。这不符合 Sarah 的需求。

选项 B 错误。基于角色的访问控制 (RBAC) 根据角色分配权限。它无法满足 Sarah 的特定细粒度控制。

选项 D 错误。基于属性的访问控制 (ABAC) 基于用户、环境和资源本身的属性。虽然很灵活，但它不像 DAC 那样围绕所有者的裁决。

问题 432。CyberSec Corp 的 CISO 想要确定过去一个月是否存在用户行为异常。具体来说，他们担心非工作时间未经授权的数据传输。以下哪些自动化报告对该调查最有用？

- (A) 非工作时间网络活动报告
- (B) 用户密码更改频率报告
- (C) 硬件库存审计报告
- (D) 软件许可合规报告

**解释 432. 正确答案：A. 非工作时间网络活动报告。** 对于非工作时间未经授权数据传输的特定担忧，非工作时间网络活动报告最有用。这些报告将提供在典型工作时间之外的网络活动详情，包括数据传输。

选项 B 错误。虽然用户密码更改频率报告可能指示用户频繁更改密码，这可能是可疑活动的迹象，但它无法直接解决非工作时间数据传输的问题。

选项 C 错误。硬件库存审计报告将提供公司硬件资产的信息，但无法提供数据传输活动的见解。

选项 D 错误。软件许可合规报告将详细说明软件许可的合规状态，这与下班后未经授权传输的担忧无关。
