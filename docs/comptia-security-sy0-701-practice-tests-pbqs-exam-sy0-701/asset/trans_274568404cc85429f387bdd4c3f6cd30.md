第 593 题。Maria 手机上收到一条来自未知的短信，称她获得了一张来自热门在线商店价值 500 美元的礼品卡。短信中包含一个链接，要求她点击该链接领取奖品。Maria 不确定该信息的真实性。对于 Maria 来说，以下哪项是最佳行动方案？

- (A) 点击链接以检查网站看起来是否真实
- (B) 将短信转发给朋友，以验证他们是否收到了类似的信息
- (C) 删除短信，不点击任何链接
- (D) 回复发件者，询问有关该优惠的更多详情

解释 593。正确答案：C。删除短信，不点击任何链接。来自未知来源的消息，尤其是那些听起来好得不可谱的消息，通常预示着潜在的安全威胁。在不与任何链接交互的情况下删除此类信息是最安全的。

短信钓鱼（Smishing）是一种钓鱼攻击，攻击者利用短信 欺骗用户披露个人信息、访问恶意网站或在智能手机上下载恶意软件。用户应该始终对来自未知号码的垃圾信息保持警惕。

选项 A 错误。即使出于好奇，点击链接也可能导致恶意网站或在 Maria 的设备上下载恶意软件。

选项 B 错误。虽然将短信转发给朋友可能会让她了解其真实性，但如果信息是恶意的，也可能让她的朋友面临潜在威胁。

选项 D 错误。回复发件者可能会向他们提供关于 Maria 的更多信息或确认她的号码处于激活状态，从而导致进一步的针对性攻击。

第 594 题。为了准备可能发生的诉讼，网络安全分析师 Meg 被确保特定的数字证据保持完整且不被篡改或删除。Meg 应该实施哪种措施来确保这一要求？

- (A) 加密证据
- (B) 启动法律留存（Legal hold）
- (C) 执行全磁盘擦除
- (D) 进行漏洞评估

解释 594。正确答案：B。启动法律留存。法律留存确保与法律案件可能相关的特定数据在留存解除前被保存，且不被篡改或删除。在这种情况下，Meg 将启动法律留存，以保持数字证据的完整，以备潜在的诉讼。

选项 A 错误。加密证据可以确保其机密性，但不能防止删除，也无法出于法律原因保证其保留。

选项 C 错误。执行全磁盘擦除将消除磁盘上的所有数据，这与保留特定数字证据的要求背道而驰。

选项 D 错误。进行漏洞评估是为了识别系统中的缺陷，而不是为了法律目的保留数字证据。

第 595 题。在 IaaS（基础设施即服务）模型中，在标准的云责任矩阵中，以下哪些任务通常是云客户的责任？

- (A) 数据中心的物理安全
- (B) 宿主机操作系统的补丁
- (C) 网络基础设施维护
- (D) 客户操作系统的补丁

解释 595。正确答案：D。客户操作系统的补丁。在 IaaS 模型中，客户通常负责管理他们自己的虚拟机，这包括为客户操作系统打补丁。云提供商通常负责物理基础设施、网络和宿主机操作系统。

选项 A 错误。数据中心的物理安全是云提供商的责任。客户对云环境中的物理基础设施没有控制力。

选项 B 错误。宿主机操作系统的补丁是云提供商的责任。他们管理物理基础设施、网络和宿主机操作系统。

选项 C 错误。网络基础设施维护是云提供商的责任，确保网络连接的可用性。

第 596 题。某公司检测到一场持续数周的 DDoS 攻击，攻击者使用了百万级的僵尸网络并频繁更换攻击向量。这指向哪种类型的攻击者？

- (A) 资源有限的黑客
- (B) 网络安全研究人员
- (C) 国家级背景攻击者
- (D) 资金充足的犯罪集团

解释 596。正确答案：D。资金充足的犯罪集团。D 攻击的规模和持续时间，结合对百万级僵尸网络的使用和攻击向量的频繁更换，指向拥有资源的攻击者。

选项 A 错误。资源有限的黑客无法进行持续数周且涉及百万级僵尸网络的 DDoS 攻击。

选项 B 错误。网络安全研究人员通常不参与恶意活动，且发动此类攻击是非法的。

选项 C 错误。虽然国家级背景攻击者可能发起此类攻击，但这种规模的通常与资金充足的犯罪集团有关。

第 597 题。一家美术馆希望在一个设有雕塑的开放广场上部署安全解决方案以检测移动。该空间的温度变化可能会导致某些运动检测产生误报。在这种情况下，哪种类型的传感器最适合确保稳定的运动检测？

- (A) 热成像传感器
- (B) 压力垫
- (C) 超声波检测器
- (D) 微波运动检测器

解释 597。正确答案：D。微波运动检测器。微波运动检测器适用于开放区域，且不受温度变化的影响。它们发射微波创建一个不可见的检测区域，并在物体干扰该区域时持续检测移动，无论环境温度如何。

选项 A 错误。热成像传感器检测热量变化。虽然可能有效，但广场温度的变化可能会导致检测不一致。

选项 B 错误。压力垫设计用于检测踩踏时的重量或压力变化。它们不适用于需要在较大区域检测移动的开放广场。

选项 C 错误。超声波检测器通过发射声波检测移动。然而，它们可能会受到外部环境因素的影响，不如微波运动检测器那样适用于开放广场。
