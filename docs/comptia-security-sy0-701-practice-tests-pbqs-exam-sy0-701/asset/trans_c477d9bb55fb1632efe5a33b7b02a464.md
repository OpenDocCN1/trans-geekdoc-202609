选项 D 错误。这表明违规每年发生五次，与情景不一致。

问题 190。DataCenter Inc. 位于一个易发生抗议和破坏的地区。他们希望增强周边界安全，以威慑潜在的入侵者，并明确限制未经授权的访问。下列哪种物理安全措施将是该公司最有效的第一道防线？

- (A) 滑动门
- (B) 安全摄像头
- (C) 高安全围栏
- (D) 邻近卡读卡器

解释 190. 正确答案：C. 高安全围栏。高安全围栏是主要的物理屏障，用于威慑、延迟和检测入侵。它提供了一个清晰的视觉指示，划定了私有财产，并可以配备铁丝网或传感器等额外的威慑措施。特别是在易发生破坏或抗议的地区，坚固的围栏是阻止未经授权访问的即时屏障。

选项 A 错误。滑动门更适用于内部安全或入口点，不作为主要的外部屏障。

选项 B 错误。虽然安全摄像头可以监控和记录活动，但它们不能作为防止或威慑未经授权访问的物理屏障。

选项 D 错误。邻近卡读卡器是一种访问控制形式，用于检查个人的凭证，但不能作为防止破坏或抗议的主要威慑手段。

问题 191。一家金融机构正在关闭其数据中心之一。鉴于所存储数据的高度敏感性，公司希望确保没有从存储设备中检索数据的可能性。下列哪种方法在保证数据销毁方面最有效？

- (A) 用零覆盖
- (B) 标准磁盘格式化
- (C) 物理销毁
- (D) 运行磁盘清理程序

解释 191. 正确答案：C. 物理销毁。物理销毁（如粉碎或焚烧存储设备）确保介质完全销毁，无论采用什么工具或技术，都无法检索数据。

选项 A 错误。用零覆盖是一种数据清理的方法，但高级技术仍可能检索出部分数据。

选项 B 错误。标准磁盘格式化通常不会完全删除数据，可能会留下可以使用专用软件恢复的痕迹。

选项 D 错误。磁盘清理程序旨在通过删除临时和不需要的文件来释放空间，而不是安全地擦除敏感数据。

问题 192。网络管理员 Maria 收到了一份报告，详细列出了公司关键服务器上的几个开放端口。她想验证报告的准确性。对于 Maria 来说，使用哪种工具验证这些结果结果的？

- (A) 密码破解器
- (B) 端口扫描器
- (C) IDS（入侵检测系统）
- (D) Web 应用防火墙

解释 192. 正确答案：B. 端口扫描器。端口扫描器（如 Nmap）向网络上的特定端口发送数据包并监听响应。这允许扫描器确定哪些端口是开放的，并可能识别运行在这些端口上的服务。

选项 A 错误。密码破解器用于识别弱密码或易破解的密码。它们不验证开放的服务端口。

选项 C 错误。IDS 监控网络流量以发现疑活动。虽然它可以识别潜在攻击，但不能直接验证开放端口。

选项 D 错误。Web 应用防火墙 (WAF) 通过监控、过滤和拦截潜在有害的 HTTP 流量来保护 Web 应用。它不能验证开放的服务端口。

问题 193。Acme Corp 正在重构其内部网络以提高安全态势。他们的目标是分离不同信任级别的区域。下列哪种方法最能实现这一目标？

- (A) 根据组织部门实施 VLAN
- (B) 设置边界防火墙以划分外部和内部流量
- (C) 根据数据敏感性和访问需求设计网络区域
- (D) 使用单一的、扁平化的网络以简化操作

解释 193. 正确答案：C. 根据数据敏感性和访问需求设计网络区域。基于数据敏感性和访问需求的区域确保了具有不同信任级别的网络分段是相互隔离的。这降低了某一区域的泄露影响另一个区域的风险。

选项 A 错误。虽然 VLAN 可以划分流量，但纯粹为了组织部门进行划分的效果没有基于敏感性的分区有效。

选项 B 错误。虽然边界防火墙划分了外部和内部流量，但它没有解决基于不同信任级别的内部划分问题。

选项 D 错误。单一的扁平网络在不同信任级别的区域之间没有提供划分。

问题 194。一家公司最近升级了其无线基础设施，并希望通过无线传输的数据受到保护。该公司应该配置哪种方案？

- (A) WEP
- (B) WPA
- (C) WPA2
- (D) WPA3

解释 194. 正确答案：D. WPA3。WPA3 是无线保护访问（Wi-Fi Protected Access）的最新迭代，提供了增强安全性。

选项 A 错误。WEP（加密等效性）已过时且不安全。

选项 B 错误。WPA（无线保护访问）已被超越。

选项 C 错误。WPA2 存在 WPA3 可以解决的问题。

问题 195。AlphaTech 对其新的支付网关进行风险分析。他们计算出特定漏洞的年度发生率 (ARO) 为 2，单次损失期望 (SLE) 为 $50,000。AlphaTech 预计每年损失多少？

- (A) $10,000
- (B) $100,000
- (C) $25,000
- (D) $1,000,000

解释 195. 正确答案：B. $100,000。年度损失期望 (ALE) 的计算方法是年度发生率 (ARO) 乘以单次损失期望 (SLE)。在此情况下，2 x $50,000 = $100,000。

选项 A 错误。没有正确应用 ALE 公式。

选项 C 错误。这是单次损失期望的一半，不代表年度损失。

选项 D 错误。金额远高于 ALE。

问题 196。在最近发生的安全入侵后，CyberSolutions Inc. 评估了他们的响应指标，并确定平均从发现安全入侵到完全解决需要 4 小时。哪种指标最能描述这 4 小时的时间？

- (A) 恢复时间目标 (RTO)
- (B) 恢复点目标 (RPO)
- (C) 平均故障间隔时间 (MTBF)
- (D) 平均修复时间 (MTTR)

解释 196. 正确答案：D. 平均修复时间 (MTTR)。MTTR（平均修复时间）是可维修项目维护性的基础衡量标准。它代表修复故障组件或设备所需的平均时间。对于 CyberSolutions Inc. 而言，从发现到解决入侵的 4 小时长反映了这一点。

选项 A 错误。恢复时间目标 (RTO) 是发生灾难后业务流程必须恢复的目标持续时间，以避免不可接受的后果。

选项 B 错误。恢复点目标 (RPO) 代表以时间为衡的最大可接受数据丢失量。

选项 C 错误。平均故障间隔时间 (MTBF) 是机械或电子系统在正常运行期间发生固有故障之间的预测间隔时间。
