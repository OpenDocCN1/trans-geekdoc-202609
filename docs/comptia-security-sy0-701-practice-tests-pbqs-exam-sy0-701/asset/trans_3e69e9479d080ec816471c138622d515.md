**问题 349。** AlphaCorp 正在迁移到云，并希望确保所有虚拟机（VMs）从一开始就经过安全配置。在部署多个虚拟机之前，AlphaCorp 应该做什么？

(A) 使用云提供商提供的默认虚拟机模板
(B) 为虚拟机配置建立安全基准并使用它
(C) 定期备份所有虚拟机
(D) 使用多因素身份验证访问

**解析 349。正确答案：B. 为虚拟机配置建立安全基准并使用它。** 为虚拟机配置建立安全基准可以确保每个虚拟机按照标准的安全设置部署，减少默认配置带来的漏洞。

**选项 A 错误。** 仅依赖云提供商提供的默认虚拟机模板可能无法满足组织的特定需求。自定义安全基准更为有效。

**选项 C 错误。** 虽然定期备份对于数据恢复至关重要，但它们不能直接确保虚拟机处于安全配置。

**选项 D 错误。** 多因素身份验证是访问资源的重要措施，但它不能确保虚拟机以安全配置部署。

# 问题 350. 一家跨国公司正在其不同国家的数据中心部署一组新服务器。应该采取以下哪项步骤，以确保服务器免受潜在威胁？

(A) 设置监控系统以向 IT 团队报告异常活动
(B) 部署公司未来可能需要的所有应用程序
(C) 使用服务器的默认配置以维护制造商的最佳实践
(D) 禁用服务器上任何不必要的服务和端口

**解析 350。正确答案：D. 禁用服务器上任何不必要的服务和端口。** 在设置新服务器时，减少攻击面至关重要。禁用不必要的服务和端口可以确保服务器上只运行必要的的服务，减少潜在漏洞。

**选项 A 错误。** 虽然监控对于安全至关重要，但在设置监控系统之前，更重要的是加固服务器以减少漏洞。监控应该是加固措施的补充。

**选项 B 错误。** 部署公司未来可能需要的所有应用程序可能会引入不必要的漏洞和开销。最好只安装精简的内容。

**选项 C 错误。** 依赖服务器的默认配置是有风险的，因为它可能未针对组织的特定需求进行调整，且可能开启必要的端口。

**问题 351。** 在分析公司 Web程序的漏洞时，安全团队参考特定的 CVE 以了解漏洞详情。他们进一步评估 CVSS 分数以决定修复的紧急性。以下哪项最能描述 CVE 和 CVSS 的用途？

- (A) CVE 提供严重评分，而 CVSS 为漏洞提供唯一标识
- (B) CVE 和 CVSS 都提供用于划分漏洞的评分机制
- (C) CVE 提供唯一标识，而 CVSS 提供标准的严重评分
- (D) CVE 和 CVSS 是所有应用程序的监管要求

**解析 351。正确答案：CVE 提供唯一标识，而 CVSS 提供标准的严重评分。** CVE（常见漏洞与披露）为漏洞提供了标准的标识符，确保了清晰的通信和参考。CVSS（漏洞评分系统）提供了一种评估漏洞严重程度的标准方法，使组织能够优先修复。

**选项 A 错误。** 恰恰相反。CVE 提供唯一标识，而 CVSS 提供严重评分。

**选项 B 错误。** 只有 CVSS 提供用于划分漏洞的评分机制。CVE 提供唯一标识。

**选项 D 错误。** 虽然使用 CVE 和 CVSS 可以被视为最佳实践，但它们并不是所有应用程序的监管要求。

**问题 352。** 大学的网络管理员希望确保学生登录校园无线网络时，其凭据由大学的中央身份验证服务器验证。此外，管理员希望确保无线访问点与中央服务器之间的数据经过加密。管理员应该实施哪种解决方案？

- (A) 带有 SAE 的 WPA3
- (B) 带有 AES 的 WPA2-Personal
- (C) 带有 RADIUS 的 WPA2-Enterprise
- (D) 带有 VPN 的开放无线

**解析 352。正确答案：C. 带有 RADIUS 的 WPA2-Enterprise。** WPA2-Enterprise 提供了一种适用于大型和大学的更强大的身份验证方法。通过使用 RADIUS，大学可以完成身份验证过程，确保学生的凭据经过中央服务器验证。RADIUS 还会加密无线访问点与中央服务器之间的数据，提供额外的安全层。

**选项 A 错误。** 带有 SAE 的 WPA3 主要用于设备之间的安全握手，与像 RADIUS 那样的服务器中央认证没有直接关系。

**选项 B 错误。** 带有 AES 的 WPA2-Personal 为使用预共享密钥的个人或小型办公室设计。它不支持像 RADIUS 那样的中央认证。

**选项 D 错误。** 虽然 VPN 可以加密设备与网络之间的数据，但它无法像 RADIUSget WPA2-Enterprise 那样实现无线认证的集中。

**问题 353。** 作为公司漏洞管理计划的一部分，安全团队决定进行一系列渗透测试。以下哪项是将渗透测试作为威胁识别方法的主要原因？

- (A) 为了符合监管要求
- (B) 为了验证安全意识培训的效率
- (C) 为了主动利用漏洞并评估潜在影响
- (D) 为了识别 SIEM 系统中的配置错误

**解析 353。正确答案：C. 为了主动利用漏洞并评估潜在影响。** 渗透测试是一种用于在环境中主动利用漏洞的方法。其首要目的是确定这些漏洞在真实场景中的潜在影响和风险，从而允许组织理解并优先考虑修复工作。

**选项 A 错误。** 虽然某些法规要求渗透测试，但该测试的主要目的不仅仅是为了合规。

**选项 B 错误。** 虽然渗透测试有时可以用来衡量安全培训的有效性（例如在社交工程测试中），但它并不是进行这些测试的主要原因。
