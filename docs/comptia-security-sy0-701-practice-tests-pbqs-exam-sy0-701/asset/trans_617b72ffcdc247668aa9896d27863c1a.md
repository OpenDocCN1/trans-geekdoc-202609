**问题 373.** TechCorp Ltd 的 IT 部门接到指令，确保关键系统文件保持不变，以避免潜在的安全泄露。他们希望实现一种系统，每当这些文件发生未经授权的更改时，都能提供警报。以下哪项最能实现此目的？

- (A) 数据泄露防护 (DLP)
- (B) 入侵检测系统 (IDS)
- (C) 文件完整性监控 (FIM)
- (D) 远程监控与管理 (RMM)

**解析 373.** **正确答案：C. 文件完整性监控 (FIM)。** 文件完整性监控 (FIM) 工具用于监控并检测可能预示泄露、恶意软件感染或其他未经授权活动的文件更改。通过跟踪和报告文件更改的模式，FIM 有助于确保数据的完整性和机密性。

**选项 A 错误。** 数据泄露防护 (DLP) 侧重于防止数据从组织内部传输或泄露，而不是监控文件更改。

**选项 B 错误。** 入侵检测系统 (IDS) 主要检测网络上的未经授权的访问或攻击。虽然它可以识别某些未经授权的文件更改，但它并非专门为文件完整性监控设计的。

**选项 D 错误。** 远程监控与管理 (RMM) 工具主要允许 IT 专业人员远程监控和管理端点、网络和计算机。它们并没有专门关注文件完整性。

**问题 374.** ABC Tech 拥有一个包含 Linux 和 Windows 服务器的混合环境。他们希望确保运行在他们的 Linux 服务器上的进程只能访问特定资源，并限制其执行某些操作。对于这项任务，以下哪个工具最合适？

- (A) 在其 Windows 器上使用组策略并将其应用于 Linux 器上
- (B) 实施严格的用户培训计划，以告知用户有关安全最佳实践
- (C) 在强制模式下启用安全增强型 Linux (SELinux)
- (D) 限制用户对 Linux 服务器的访问

**解析 374.** 正确答案：C. 在强制模式下启用安全增强型 Linux (SELinux)。SELinux 通过将进程可以执行的操作限制为仅策略策略定义的操作来提供强制性访问控制，确保它仅具有特定资源的访问权限。通过将 SELinux 设置为强制模式，这些策略将得到积极执行。

**选项 A 错误。** 组策略是 Windows 特有的，无法直接应用于 Linux 服务器。

**选项 B 错误。** 虽然用户培训是一种良好的安全实践，但它无法提供限制 Linux 服务器上进程所需的所需的控制。

**选项 D 错误。** 限制用户对 Linux 服务器的访问并直接控制运行在这些服务器上的进程的操作。

**问题 375.** 安全管理员 Sarah 正在为她的组织的服务器基础设施实施一种监控解决方案。她希望采用一种不需要在服务器本身上安装任何额外软件的解决方案。Sarah 应该选择哪种类型的监控方法？

- (A) 基于代理的监控
- (B) 入侵检测系统 (IDS)
- (C) 无代理监控
- (D) 基于网络的应用程序性能监控 (APM)

**解析 375.** 正确答案：C. 无代理监控。 
无代理监控解决方案不需要在被监控的服务器上安装任何软件代理。它们通常依赖于标准协议和接口来收集性能和其他数据。

**选项 A 错误。** 基于代理的监控要求在每个要监控的服务器或设备上安装软件代理。

**选项 B 错误。** 虽然入侵检测系统 (IDS) 是一种安全工具，但它并非专门为无代理基础设施监控设计的。

**选项 D 错误。** 基于网络的应用程序性能监控 (APM) 专注于网络上的应用程序性能，而不是无代理服务器监控。

**问题 376.** 制药公司 PharmaCorp 希望确保其研究人员无法将专有配方和研究数据传输到外部存储设备或云存储。公司需要一种解决方案来防止此类传输，同时允许其他类型的数据传输。他们应该实施什么？

- (A) Web 应用程序防火墙 (WAF)
- (B) 数据加密工具
- (C) 数据泄露防护 (DLP)
- (D) 虚拟专用网络 (VPN)

**解析 376.** 正确答案：C. 数据泄露防护 (DLP)。 数据泄露防护 (DLP) 旨在检测潜在的数据泄露尝试并防止敏感数据未经授权的传输。通过在 DLP 解决方案中设置规则和标准，PharmaCorp 可以限制专有信息的传输，同时根据需要允许其他数据进行传输。

**选项 A 错误。** Web 应用程序防火墙 (WAF) 用于通过过滤和监控 HTTP 流量来保护 Web 应用程序。它不专门处理到外部存储或云存储的数据传输。

**选项 B 错误。** 数据加密工具加密数据以防止受到未经授权的访问。虽然它增加了一层安全性，但它不能防止数据传输到外部设备或云存储。

**选项 D 错误。** 虚拟专用网络 (VPN) 为两个端点之间的数据传输提供安全隧道。它不会阻止或监控正在传输的数据的类型。

**问题 377.** CyberFirm 一直面临网络钓鱼攻击的问题，攻击者通过伪造他们的域名来发送欺诈邮件。他们已经实施了 DKIM 来对邮件签名，但希望增加额外的措施，来指定哪些邮件服务器有权代表他们的域名发送电子邮件。CyberFirm 应该采用哪种安全措施？

- (A) SPF
- (B) PGP
- (C) SSL 证书
- (D) IMAP

**解析 377.** **正确答案：A. SPF.** 发件者策略框架 (SPF) 旨在防止电子邮件伪造。它允许域名所有者指定哪些邮件服务器授权代表其域名发送电子邮件。

**选项 B 错误。** PGP 用于加密和解密文本、文件、目录和整个磁盘分区，但它没有帮助。

**选项 C 错误。** SSL 证书提供用户浏览器和网站之间的安全连接，确保数据机密性。它不是专门用于验证域名的。

**选项 D 错误。** IMAP 是邮件客户端从邮件服务器获取邮件的协议。它没有帮助指定域名。

**问题 378.** 一所学校希望防止学生在上课期间访问不良网站。IT 部门决定实施一种阻止与不良内容相关的域名请求的解决方案。以下哪个安全解决方案最好？

- (A) 基于 IP 地址的防火墙过滤
- (B) 入侵检测系统监控
- (C) 虚拟专用网络 (VPN) 强制
- (D) 使用黑名单的 DNS 过滤

**解析 378.** 正确答案：D. 使用黑名单的 DNS 过滤。DNS 过滤是一种可以阻止用户访问特定网站的技术。可以创建一个包含不良内容域名的黑名单，当用户尝试访问这些站点时，DNS 过滤器将不会解析域名，从而阻止访问。

**选项 A 错误。** 虽然防火墙基于 IP 地址拦截流量，但这种方法对于阻止特定域名并不有效，特别是当域名有多个 IP 地址或 IP 可能会变化时。

**选项 B 错误。** 入侵检测系统 (IDS) 主要用于检测和警告恶意活动，而不是阻止访问特定域名。

**选项 C 错误。** VPN 用于创建安全通信通道，本质上并非设计用于阻止域名解析。
