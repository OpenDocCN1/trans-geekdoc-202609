**第 230 题。** 一家律师事务所正在转向数字化存储系统，并希望确保客户记录和案件文件免受未经授权的访问。为了确保数字化存储法律信息的机密性，以下哪种策略是最佳的

- (A) 对数字存储系统进行定期的渗透测试
- (B) 对客户记录和案件文件进行加密
- (C) 为数字文档添加水印
- (D) 限制对机房的物理访问

**解析 230。** **正确答案：B. 对客户记录和案件文件进行加密。** 加密是将信息转换为不可读格式的过程，除非拥有适当的解密密钥。通过加密法律文件，未经授权的人即使访问了存储系统，也无法理解文档的内容。

**选项 A 错误。** 虽然定期的渗透测试对于识别系统中的漏洞至关重要，但它不能直接保护所存储的法律信息的机密性。

**选项 C 错误。** 为文档添加水印可以防止复制或未经授权的传播，但不能防止对文档的非法访问或阅读。

**选项 D 错误。** 限制对机房的物理访问可以防止未经授权的物理进入，但无法防止数字泄露或保护文件内容。

**第 231 题。** 在进行例行安全审查时，安全专家 Jake 发现组织财务系统中放置了一段意外的数据。在询问后，他得知这段数据是特意放置并监控的，以观察是否有未经授权的用户或系统与其进行交互。这种欺骗性数据被称为

- (A) Honeystring（蜜罐字符串）
- (B) Honeytoken（蜜罐令牌）
- (C) Canary token（金丝雀令牌）
- (D) Security marker（安全标记）

**解析 231。** **正确答案：B. Honeytoken。** Honeytokens 是策略性放置的欺骗性数据，它们没有实际价值或现实用途，但会被严密监控。它们的唯一目的是检测未经授权的交互，因为对 honeytoken 的任何访问或使用都可能是恶意的或未经授权的。

**选项 A 错误。** 在描述的语境下，并没有一种公认的名为“Honeystring”的安全术语。

**选项 C 错误。** Canary tokens 是 honeytoken 的特定类型，可以起到相同的作用。然而，考虑到给出的选项和问题的背景，“Honeytoken”是最准确的答案。

**选项 D 错误。** 从广义上说，安全标记可以是任何用于安全目的的标记或指示，但它不是专门放置的用于检测未经授权访问的欺骗性数据。

**第 232 题。** 你是一家使用云基础设施的公司的安全顾问。在安全审查期间，你发现云中的开发、测试环境和生产环境之间没有定义边界。这可能导致无意的交互和数据泄露。这种场景说明了哪种漏洞？

- (A) 不安全的 API 端点
- (B) 弱的加密方法
- (C) 缺乏资源隔离
- (D) 备份策略不足

**解析 232。** **正确答案：C. 缺乏资源隔离。** 云特定的漏洞可能由于云基础设施的共享性质而产生。在这种情况下，开发、测试和生产等不同环境之间没有边界或隔离可能会导致漏洞。如果没有适当的资源隔离，引入开发环境的恶意代码可能会进入生产环境，或者机密的生产数据可能会在测试环境中暴露，导致潜在的数据泄露。

**选项 A 错误。** 不安全的 API 端点涉及用于管理和与云服务交互的 API 未能妥善保护的漏洞。

**选项 B 错误。** 弱的加密方法指的是使用过时或有漏洞的加密算法，这与环境的混合没有直接关系。

**选项 D 错误。** 备份策略不足涉及缺乏足够的数据备份和恢复机制，这与资源隔离是不同的问题。

**第 233 题。** AlphaCorp 正在处于选择网络安全顾问的最后阶段。入围的机构之一，SecureWorld 最近聘请了 AlphaCorp 的前 CISO 担任高级顾问。考虑到这种情况，AlphaCorp 在选择供应商期间应立即关注的问题是什么？

- (A) 前 CISO 为 SecureWorld 带来的专业知识
- (B) SecureWorld 可能提供折扣的可能性
- (C) 因先前的关联导致的潜在利益冲突
- (D) SecureWorld 的全球布局和声誉

**解析 233。** **正确答案：C. 因先前的关联导致的潜在利益冲突。** 让 AlphaCorp 的前 CISO 在 SecureWorld 担任高级可能会引发对潜在利益冲突的担忧。确保决策是客观的，且没有因为先前的关联产生偏见至关重要。

**选项 A 错误。** 虽然前 CISO 的专业知识很有价值，但在潜在利益冲突的语境下，这不是要关注的问题。

**选项 B 错误。** 价格和折扣不是供应商选择中与潜在利益冲突相关的主要问题。

**选项 D 错误。** 虽然全球布局和声誉是选择供应商的重要因素，但它们没有直接解决由前 CISO 职位产生的潜在利益冲突问题。

**第 234 题。** 一位 IT 技术人员正在对公司的机房进行例行安全审计。她发现一台服务器的固件过时，已经两年没有更新。过时的固件暴露了哪些潜在漏洞？

- (A) SQL 注入
- (B) 物理篡改
- (C) 未修补的漏洞利用
- (D) 凭据填充

**解析 234。** **正确答案：C. 未修补的漏洞利用。**
固件像软件一样，接收更新以修复已知漏洞。如果固件过时，可能会导致系统容易受到攻击者可以利用的已知漏洞。

固件是硬件设备的基础软件。当固件不定期更新时，它可能包含在后续版本中已修补的漏洞。这些漏洞可能被攻击者利用，给设备和连接的系统带来风险。

**选项 A 错误。** SQL 注入是与数据库和网络应用程序相关的漏洞，而不是固件。

**选项 B 错误。** 物理篡改涉及某人物理访问并更改设备。虽然固件漏洞有时会导致物理篡改（通过启动级攻击），但过时固件与物理篡改之间的直接联系没有与未修补的漏洞利用之间的联系紧密。

**选项 D 错误。** 凭据填充是一种涉及已知的用户名-密码对以获取未经授权访问的攻击方法。它与固件漏洞没有直接关系。
