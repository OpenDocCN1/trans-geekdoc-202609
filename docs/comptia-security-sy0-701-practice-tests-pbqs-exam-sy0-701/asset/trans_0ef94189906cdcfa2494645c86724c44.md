**问题 74。** Alice 需要为她发送给 Bob 的数字文档提供真实性证明。Alice 应该使用以下哪个加密元素来完成此任务并确保 Bob 知道该文档来自她？

- (A) 使用 Bob 的私钥加密文档
- (B) 使用她的公钥加密文档
- (C) 使用她的私钥对文档签名
- (D) 使用 Bob 的公钥对文档签名

**解释 74. 正确答案：C. 使用她的私钥对文档签名。** 为了证明真实性，使用发送者的私钥创建数字签名。当 Bob 接收文档时，可以使用 Alice 的公钥验证签名。这证明了文档是由 Alice 签名的，并且在传输过程中没有被篡改。

**选项 A 是错误的。** Bob 的私钥仅 Bob 本人所知，不应被任何其他人使用，包括用于加密。

**选项 B 是错误的。** 使用 Alice 的公钥加密不能证明真实性。它意味着只有 Alice 的私钥可以解密，这并不是其意图。

**选项 D 是错误的。** 人不会使用接收者的公钥对文档签名。签名是使用发送者的私钥创建的。

**问题 75。** 安全分析师 Carla 收到警报，称公司的一个服务器证书可能在最近的数据泄露中泄露了。Carla 应该采取的最直接行动是什么，以确保泄露的证书不会被恶意使用？

- (A) 向 CA 申请新证书
- (B) 更新公司的防火墙规则
- (C) 将证书添加到证书吊销列表 (CRL)
- (D) 对服务器进行漏洞评估

**解释 75. 正确答案：将证书添加到证书吊销列表 (CRL)。** 如果认为一个证书已被泄露，最直接的行动是吊销它。这是通过将证书添加到证书吊销列表 (CRL) 实现的。在建立安全通信之前检查 CRL 的系统和应用程序将不再信任该受损的证书。

**选项 A 是错误的。** 虽然在撤销受损证书后申请新证书可能是必要的，但最直接的行动应该是撤销可能受损的证书。

**选项 B 是错误的。** 更新防火墙规则虽然对许多安全场景至关重要，但并不能直接解决可能泄露证书的滥用问题。

**选项 D 是错误的。** 漏洞评估是一个识别系统弱点的更广泛的行动。虽然很有价值，但它没有直接解决证书受损的问题。

**问题 76。** 一位数据库管理员担心相同密码的问题。为了降低这种风险，管理员应该实施哪种加密技术？

- (A) 数字签名
- (B) 加盐 (Salting)
- (C) 密钥扩展 (Key stretching)
- (D) 对称加密

**解释 76. 正确答案：B. 加盐。** 加盐涉及在哈希处理之前为每个密码添加一个唯一的字符串，确保相同的密码产生不同的哈希值，并防止彩虹表攻击。

**选项 A 是错误的。** 数字签名用于证明真实性和完整性，而不是用于处理相同密码。

**选项 C 是错误的。** 密钥扩展用于使密码破解变得更加耗时，但不是确保相同密码具有不同哈希值的主要方法。

**选项 D 是错误的。** 对称加密用于数据机密性，无法解决哈希中相同密码的问题。

**问题 77。** 一家在线零售商正在考虑各种保护信用卡信息的方法。他们选择不存储实际数字，而是使用替代品。这称为什么？

- (A) 对称加密
- (B) 数字水印
- (C) 哈希处理
- (D) 令牌化 (Tokenization)

**解释 77. 正确答案：D. 令牌化。** 令牌化将敏感数据替换为称为令牌的非敏感替代品，降低了暴露真实信用卡号的风险。

**选项 A 是错误的。** 对称加密使用密钥来加密数据，而该场景侧重于用替代品替换数字。

**选项 B 是错误的。** 数字水印不是保护信用卡号存储的标准方法。

**选项 C 是错误的。** 哈希处理是一个单向函数，而令牌化对于授权的系统来说是可逆的。

**问题 78。** 在计划的维护窗口期间，安全管理员计划对公司的防火墙应用关键更新。以下哪项行动对于确保停机时间最小化最关键？

- (A) 通知防火墙供应商有关更新的事
- (B) 禁用所有防火墙规则
- (C) 为可能发生的失败创建回滚计划
- (D) 在高峰时段调度更新

**解释 78. 正确答案：C. 为可能发生的失败创建回滚计划。** 在变更管理中，拥有回滚计划可以确保如果应用的更新出现问题，系统可以恢复到之前的状态，从而使停机时间最小。

**选项 A 是错误的。** 虽然通知供应商可能有用，但它不是最小化停机时间的最关键步骤。

**选项 B 是错误的。** 禁用所有防火墙规则可能会引入的安全风险。

**选项 D 是错误的。** 在高峰时段调度更新可能会导致最大的干扰。

**问题 79。** 一位安全管理员正在考虑一种加密解决方案，用于保护位于同一数据中心的服务器之间传输的数据。主要目标是确保加解密过程的速度效率。哪种加密最符合这一要求？

- (A) 使用 RSA 的非对称加密
- (B) 使用 AES 的对称加密
- (C) 使用 RSA 和 AES 结合的混合加密
- (D) 使用 ECC 的非对称加密

**解释 79. 正确答案：B. 使用 AES 的对称加密。** 对称加密（如 AES）通常比非对称加密更快，且所需的计算资源更少。这使得它适用于高速加解密至重要的场景，例如数据中心服务器之间传输的数据。

**选项 A 是错误的。** 使用 RSA 的非对称加密比对称加密计算密集，对于给定的场景可能不是最高效。

**选项 C 是错误的。** 虽然混合加密可以平衡安全性和速度，但对于描述的情况，仅使用对称加密 (AES) 更高效。

**选项 D 是错误的。** ECC 与 RSA 一样是一种非对称加密方法，这意味着它通常会比 AES 等对称方法慢。
