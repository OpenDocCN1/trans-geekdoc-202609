**Question 34.** A company is located in an area prone to natural disasters such as earthquakes and floods. Which of the following physical security controls would be MOST effective in ensuring the safety of the company’s IT infrastructure?

+   (A) Using biometric authentication for server access

+   (B) Deploying a firewall to protect against cyber threats

+   (C) Establishing a raised floor system in the center

+   (D) Conducting penetration testing on a regular basis

**Explanation 34. Correct Answer: C. Establishing a raised floor system in the data center.** A raised floor system in a data center serves as a physical control by elevating equipment off the ground, helping to protect it from potential water damage in the event of flooding and providing some protection from other environmental risks.

**Option A is incorrect.** Using biometric authentication is a technical control that enhances security by confirming users’ identities based on physical or behavioral attributes. While it strengthens access security, it doesn’t provide protection against natural disasters.
