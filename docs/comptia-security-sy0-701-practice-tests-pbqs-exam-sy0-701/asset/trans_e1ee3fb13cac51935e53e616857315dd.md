

# 问题 505。CyberTech Inc. 是一家网络安全咨询公司，目前正在与潜在客户 MedCorp 讨论，协助开发一套新的安全医疗记录系统。作为流程的一部分，MedCorp 将与 CyberTech 共享敏感的患者数据。在共享此类信息之前，应该签署什么协议以确保机密性？

- (A) 合作备忘录 (MOU)
- (B) 服务水平协议 (SLA)
- (C) 非保密协议 (NDA)
- (D) 工作单 (WO)/工作说明书 (SOW)

解析 505. 正确答案：C. 非保密协议 (NDA)。NDA（非保密协议）专门设计用于保护双方之间共享的机密信息。它确保接收方不会泄露或误用所提供的信息。鉴于 MedCorp 将共享的患者数据具有敏感性，NDA 是关重要的。

选项 A 错误。MOU 表示双方之间的共同意图和理解，但它并没有专门针对共享信息的机密性。

选项 B 错误。服务水平协议 (SLA) 主要关于将提供的服务水平，详细说明了性能指标和不合规的惩罚。它本身并不关注数据机密性。

选项 D 错误。工作单 (WO) 或工作说明书 (SOW) 详细说明了项目的细节，从任务到里程碑，但没有直接解决共享数据的机密性问题。

**问题 506。** AlphaTech 正在对其新的在线支付网关进行风险分析。他们计算出特定漏洞的年度发生率 (ARO) 为 2，单次损失预期 (SLE) 为 $50,000。AlphaTech 预计每年由于该漏洞会损失多少？

- (A) $10,000
- (B) $100,000
- (C) $25,000
- (D) $1,000,000

解析 506. 正确答案：B. $100,000。年度预期损失 (ALE) 是通过年度发生率 (ARO) 乘以单次损失预期 (SLE) 计算得。在这种场景中，ALE = 2 x $50,000 = $100,000。

选项 A 错误。这没有正确应用 ALE 的公式。

选项 C 错误。这是单次损失预期的一半，不代表年度损失。

选项 D 错误。该金额远高于计算出的 ALE。

**问题 507。** WhiteCape Healthcare 是一家国际医疗保健提供商，拥有一个包含许多欧盟公民的大型患者数据库。他们正准备实施新系统以改进医生对数据的访问。在授予医生访问欧盟患者数据时，他们应该特别注意以下哪项监管要求？

- (A) 确保数据仅用于税务报表目的
- (B) 在共享数据之前获得患者的显式同意
- (C) 使用专有算法加密所有数据
- (D) 将数据存储在位于欧盟境内的物理服务器上

解析 507. 正确答案：B. 在共享数据之前获得患者的显式同意。根据 GDPR，在处理或共享个人的的个人数据之前，需要获得个人的显式同意。这意味着欧盟公民应该已经对其数据的访问和共享给予了明确的许可。

选项 A 错误。出于税务报表目的访问数据与 GDPR 处理欧盟公民个人医疗数据的要求之间没有直接关系。

选项 C 错误。虽然加密是数据保护的好做法，但 GDPR 并未强制使用专有算法。此外，仅凭加密不能解决同意要求。

选项 D 错误。虽然 GDPR 有关于数据传输到欧盟以外的规定，但仅仅将数据存储在欧盟境内的物理服务器上并绕过共享数据时需要患者显式同意的需求。

问题 508。WebFlix 是一家流行的在线电影流媒体服务，因灾害导致数据中心停机。他们有备份，并使用故障前 6 小时的数据恢复了系统。这导致了某些用户交互的丢失，例如最后 6 小时的评分和观看列表。哪个术语描述了最后一次备份与停机时间之间 6 小时的间隔？

- (A) 恢复时间目标 (RTO)
- (B) 最大可忍机时间 (MTD)
- (C) 恢复持续期 (RDP)
- (D) 恢复点目标 (RPO)

解析 508. 正确答案：D. 恢复点目标 (RPO)。恢复点目标 (RPO) 是以时间衡的最大接受数据丢失。对于 WebFlix 来说，这意味着在发生灾难时，他们可以承受高达 6 小时的数据（在此情况下为用户交互）丢失。

选项 A 错误。恢复时间目标 (RTO) 是系统在中断后可以停机的最大接受时间。

选项 B 错误。最大可忍机时间 (MTD) 代表系统可以承受非运行状态而不产生重大风险或重大损失的总时间。

选项 C 错误。恢复持续期 (RDP) 不是业务连续性和灾难恢复规划中的标准术语。

# 问题 509。作为一名安全顾问，你被一家跨国公司聘用，负责评估其潜在供应商的安全态势。其中一个供应商看起来很有前景，但你的客户希望确保该供应商定期检查并加强其自身的内部程序和安全控制。你应该建议客户向该供应商请求什么？

- (A) 供应商的业务连续性计划
- (B) 供应商的客户列表
- (C) 内部审计证据
- (D) 供应商的公司使命声明

解析 509. 正确答案：C. 内部审计证据。请求内部审计证据可以让客户审查供应商在维护和改进其内部程序和安全控制方面的承诺。

选项 A 错误。虽然业务连续性计划至关重要，但它主要概述了如何管理中断，并不能提供供应商内部控制实践的证据。

选项 B 错误。了解供应商的客户可以提供一些背景，但它没有直接提供供应商内部控制实践的证据。

选项 D 错误。公司使命声明概述了公司的目标和价值观，但没有提供其内部控制实践的具体证据。

问题 510。GlobalFin 是一家金融科技公司，开发了一款移动银行应用程序。为了避免任何法律冲突，GlobalFin 在全球范围内推出应用程序之前应该最关注以下哪些外部法律因素？

- (A) 确保应用程序符合全球数据隐私法
- (B) 确认配色方案符合所有国家的品牌法规
- (C) 为应用程序中使用的所有图像获取版权
- (D) 确保应用程序名称在任何语言中都不冒犯

解析 510. 正确答案：A. 确保应用程序符合全球数据隐私法。对于移动银行应用程序，遵守全球数据隐私法是至关重要的。不同地区对于如何处理、存储和处理用户数据有不同的要求和法规。

选项 B 错误。虽然品牌和配色对营销很重要，但它们通常不是像数据隐私法那样的严格法律监管对象。

选项 C 错误。虽然获取版权很重要，但对于银行应用程序，主要的法律关注点将与数据隐私和安全有关，考虑到财务数据的敏感性。

选项 D 错误。虽然确保应用程序名称具有文化敏感是一个良好的做法，但银行应用程序主要的法律关注点是数据隐私和安全法规。
