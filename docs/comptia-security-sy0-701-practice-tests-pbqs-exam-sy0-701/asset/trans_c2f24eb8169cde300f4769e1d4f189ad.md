**问题 2。** TechFirm 公司决定开展一项新业务。在推进该业务之前，安全团队进行了多次头脑风暴会议、访谈，并审查了历史数据，以生成一份新业务可能面临的潜在安全威胁列表。这项活动是风险管理过程中哪一步的主要组成部分？

- (A) 风险评估
- (B) 风险响应
- (C) 风险监控
- (D) 风险识别

**解释 2.** **正确答案：D. 风险识别。** 风险识别是检测和描述可能影响目标实现的潜在风险的初始过程。

**选项 A 错误。** 风险评估包含了识别、分析和评估风险的整体过程，但提到的特定活动与风险识别有关。

**选项 B 错误。** 风险响应涉及决定应对已识别风险的合适方法，无论是接受、回避、转移还是缓解。

**选项 C 错误。** 风险监控是关于跟踪已识别风险、监控残余风险以及识别新风险。头脑风暴和收集有关风险数据的特定活动属于风险识别。

**问题 3。** 一大型财务机构希望确保所有员工理解网络安全的重要性以及他们在保护公司资产方面所起的作用。以下哪种管理安全控制措施对于实现这一目标最有效？

- (A) 在网络边界安装防火墙
- (B) 为员工定期进行安全意识培训
- (C) 部署入侵检测系统 (IDS) 
- (D) 加密所有公司数据

**解释 3.** **正确答案：B. 为员工定期进行安全意识培训。** 安全意识培训是一种管理控制措施，旨在教育员工安全风险以及他们需要采取的必要预防措施。通过定期培训员工，组织可以确保所有员工都意识到潜在威胁以及他们在网络安全中的角色。

**选项 A 错误。** 安装防火墙是一种技术控制措施，侧重于防止对私有网络未经授权的访问。虽然它保护了网络，但它没有直接教育员工他们在网络安全中的角色。

**选项 C 错误。** 部署入侵检测系统 (IDS) 是一种技术控制措施。它监控网络流量中的可疑活动，但并不直接关注于教育员工。

**选项 D 错误。** 加密公司数据是一种技术控制措施。虽然它确保了数据的机密性，但它没有解决员工对网络安全的知识或意识。

**问题 4。** 一大型制药公司最近宣布提高药品价格。公告后，其网站因 DDoS 攻击而离线，一个声称负责的团体在网上发布了信息，要求所有人都能负担得起的医疗保健。哪种类型的威胁者最可能是这次攻击的幕后黑手？

- (A) 无技能攻击者
- (B) 内部威胁
- (C) 黑客行动主义者
- (D) 国家级力量

**解释 4.** **正确答案：C. 黑客行动主义者。** 黑客行动主义者通常受政治、社会或意识形态动机驱动。他们利用网络攻击作为促进或抗议某些问题的手段。在这一场景中，对制药公司的攻击是对其定价政策的一种抗议形式，具有黑客行动主义行为的特征。

**选项 A 错误。** 无技能攻击者通常是为了个人炫耀或恶作剧而进行攻击。他们通常不会受此类要求负担得起的医疗服务之类的意识形态动机驱动。

**选项 B 错误。** 内部威胁源于组织内部的个人，通常受个人不满或财务利益驱动。描述的场景显示动机与更广泛的社会问题有关，而不是个人或内部动机。

**选项 D 错误。** 国家级力量出于政治、间谍或军事原因进行网络行动。抗议药价不符合他们的典型目标。

**问题 5。** 在大型制造设施中部署无线接入点后，员工报告某些区域的无线连接不稳定。IT 团队使用哪种工具对于直观显示无线信号强度较弱的区域最有效？

- (A) 网络带宽监控器
- (B) 协议分析仪
- (C) 热力图软件
- (D) 入侵检测系统

**解释 5.** **正确答案：C. 热力图软件。** 热力图软件允许 IT 专业人员直观地看到无线信号强弱的区域，从而更容易根据需要调整位置或添加额外的接入点。

**选项 A 错误。** 网络带宽监控器用于测量通过网络发送的数据量，而不是为了可视化无线信号强度。

**选项 B 错误。** 协议分析仪用于捕获和分析网络流量，而不是直观显示无线覆盖范围。

**选项 D 错误。** 入侵检测系统 (IDS) 设计用于检测网络上未经授权的访问或恶意活动。它不会显示无线信号强度较弱的区域。

**问题 6。** 在 IaaS（基础设施即服务）模型中，在标准的云责任矩阵中，以下哪些任务通常是云客户的责任？

- (A) 数据中心的物理安全
- (B) 宿主机操作系统的补丁
- (C) 网络基础设施维护
- (D) 客户操作系统的补丁

**解释 6.** **正确答案：D. 客户操作系统的补丁。** 在 IaaS 模型中，客户通常负责管理自己的虚拟机，包括对客户操作系统进行补丁更新。云提供商通常负责物理基础设施、网络和宿主机操作系统。

**选项 A 错误。** 数据中心的物理安全是云提供商的责任。客户在云环境中无法控制物理基础设施。

**选项 B 错误。** 宿主机操作系统的补丁是云提供商的责任。他们管理底层基础设施。

**选项 C 错误。** 网络基础设施的维护通常由云提供商处理，以确保其提供的资源的连接性和可用性。

**问题 7。** 一家公司的网站被临时篡改了一个幽默的表情包，但没有窃取敏感数据，也没有造成重大损害。攻击者留下了一条信息，炫耀他们首次成功的黑客。哪种类型的威胁者最可能是这次攻击的？

- (A) 内部威胁
- (B) 高级持续性威胁 (APT)
- (C) 无技能攻击者
- (D) 国家级力量

**解释 7.** 正确答案：C. 无技能攻击者。**

无技能攻击者（通常被称为“脚本小子”）通常利用预制的工具或脚本来执行基础攻击。他们的动机通常不仅是为了炫耀或小恶作剧，例如为了好玩或证明自己可以而篡改网站，而不是执行复杂的或具有破坏性的攻击。
