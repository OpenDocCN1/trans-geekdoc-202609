问题 167。在一次例行扫描期间，某图形设计公司的安全团队发现一名员工从电子邮件中下载了一张图片，随后检测到从该员工工作站发出的异常网络流量。该图片在打开时显示正常。在这种情况下可能使用了哪种攻击？

- (A) 图像隐写术恶意软件 (Image Steganography Malware)
- (B) 密码暴力破解 (Password Brute Force)
- (C) 网络钓鱼 (Phishing)
- (D) 端口扫描 (Port Scanning)

解释 167. 正确答案：A. 图像隐写术恶意软件。隐写术是将文件、消息、图像或视频隐藏在另一个文件、消息、图像或视频中的做法。图像隐写术特指在图像中隐藏恶意代码。当该图像被下载或打开时，恶意代码可以在受害者不知情的情况下被执行。

选项 B 是错误的。密码暴力破解是一种攻击方法，攻击者通过系统地尝试所有可能的字母、数字和符号组合，直到发现正确的密码，以此尝试猜测用户的密码。

选项 C 是错误的。网络钓鱼通常涉及欺骗性的电子邮件或消息，试图诱骗收件者披露敏感信息。虽然图像可以用于钓鱼尝试，但所描述的场景并未表明正试图从员工处提取信息。

选项 D 是错误的。端口扫描是尝试发现计算机上的开放端口，这可以揭示运行在这些端口上的服务。它不涉及图像的使用。

问题 168。TechSoft 公司正准备实施一种新的资产跟踪系统，以监控其庞大的计算资源。以下哪项应该是维护最新的硬件和软件清单的**主要**原因？

- (A) 确保软件许可证及时续期
- (B) 及时识别并响应未经授权的设备或软件
- (C) 辅助新硬件和软件的采购
- (D) 让员工了解可用资源

解释 168. 正确答案：B. 及时识别并响应未经授权的设备或软件。虽然所有选项都是维护清单的有效理由，但从安全的角度来看，及时识别未经授权的设备或软件至关重要。未经授权的设备或软件可能会带来重大安全风险，包括潜在的数据泄露或恶意软件感染。

选项 A 是错误的。虽然续期软件许可证很重要，但它不是维护清单的主要安全理由。

选项 C 是错误的。采购决策受益于清单数据，但它们不会像识别未经授权资产那样直接影响即时安全问题。

选项 D 是错误的。虽然让员工了解资源是有益的，但对于安全而言，没有及时识别未经授权的资产那么关键。

问题 169。大型组织 Acme 公司最近与 Zenith MSP 签署了一份关于 IT 管理和支持的合同。Acme 公司的 CISO 对这种新关系带来的相关的安全风险表示担忧。在供应链中使用托管服务提供商（MSPs）时，以下哪项是**主要的**安全关注点？

- (A) 新技术集成导致成本增加
- (B) 难以确保一致的补丁管理
- (C) 公司资源被未经授权访问的风险
- (D) 外包导致 IT 员工士气下降

解释 169. 正确答案：C. 公司资源被未经授权访问的风险。托管服务提供商通常拥有提供服务所需的较高权限，这可能使他们成为攻击者的首要目标。MSP 级别的泄露可能导致其客户资源被未经授权访问。

当公司与 MSP 合作时，该提供商通常能够访问关键系统、数据和网络基础设施以提供其服务。如果 MSP 被攻破，可能会导致连锁反应，客户的系统和数据也变得脆弱。对于公司而言，确保其 MSP 具有稳健的安全态以防止未经授权的访问是非常关重要的。

选项 A 是错误的。虽然成本考虑在业务决策中很重要，但它们不是供应链中 MSP 带来的直接安全风险。

选项 B 是错误的。虽然确保一致的补丁管理很重要，但它不是未经授权访问的主要风险。

选项 D 是错误的。虽然外包导致员工士气下降是一个问题，但它不是主要的安全风险。

问题 170。Mike 是某技术公司的员工，收到了一条来自同事的即时消息。该消息包含一个链接，Mike  这并非来自同事。Mike 最可能遇到的是哪种威胁？

- (A) 水陷阱攻击 (Watering Hole Attack)
- (B) 中间人攻击 (Man-in-the-Middle Attack)
- (C) 消息欺骗 (IM Spoofing)
- (D) 侧信道攻击 (Side-channel Attack)

解释 170. 正确答案：C. 消息欺骗。IM 欺骗发生在攻击者发送看似来自可信源（通常是已知联系人）的消息，欺骗受害者打开恶意链接。

选项 A 是错误的。水陷阱攻击是攻击者观察小组经常使用的网站并在其中一个或多个网站中注入恶意软件。

选项 B 是错误的。中间人攻击涉及攻击者秘密地拦截并转发双方之间的通信。

选项 D 是错误的。侧信道攻击是基于从计算机实现中获得的信息，而不是算法本身的漏洞。

问题 171。在一家新成立的博物馆，管理层想在展厅内安装传感器，以检测下班后的任何未经授权的移动。这些房间经常充满了空调声和来自城市的外部噪声。在这些情况下，哪种传感器**最好**检测移动且不受噪声影响？

- (A) 声学传感器 (Acoustic sensors)
- (B) 玻璃破碎器 (Glass break detectors)
- (C) 超声波传感器 (Ultrasonic sensors)
- (D) 热成像摄像头 (Thermal imaging cameras)

解释 171. 正确答案：C. 超声波传感器。超声波传感器发射高频声波来检测运动。这些声波超出了人耳的范围，不受环境噪声的影响，非常适合噪声多变的环境。当检测到移动时（通过反射波的变化指示），就会触发警报。

选项 A 是错误的。声学传感器检测特定的声音。城市的外部噪声可能会导致误报或干扰其检测能力。

选项 B 是错误的。玻璃破碎器设计用于检测玻璃破碎的声音或振动。它们并非主要用于检测移动。

选项 D 是错误的。热成像摄像头检测热信号，受到房间温度变化的影响，可能会导致虚假检测。
