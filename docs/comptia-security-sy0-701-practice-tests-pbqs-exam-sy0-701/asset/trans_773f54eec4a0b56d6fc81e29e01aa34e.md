**问题 377。** 在最近的一次安全事件后，网络安全分析师 Sarah 想要分析网络流量的流数据以识别模式和潜在威胁。她想收集有关 IP 流量的元数据，并收集地址、端口和协议等详细信息。Sarah 应该使用哪种工具获取这些信息？

- (A) 入侵检测系统 (IDS)
- (B) Syslog 服务器
- (C) NetFlow 收集器
- (D) 简单网络管理协议 (SNMP) 告警

**解释 377。** **正确答案：C. NetFlow 收集器。**
NetFlow 是思科开发的一种网络协议，用于收集 IP 流量信息和监控网络流量。NetFlow 收集器可以提供对流量模式和容量的洞察，使其适用于 Sarah 的需求。

选项 A 错误。虽然 IDS 可以根据特定的签名或启发式算法对恶意活动发出警报，但它不提供像 NetFlow 那样的详细流数据分析。

选项 B 错误。Syslog 服务器主要用于收集和存储来自各种设备的日志数据。它不像 NetFlow 那样关注详细的网络流量流。

选项 D 错误。SNMP 告警用于从设备向管理站发送关于特定事件的未请求告警消息。它们不提供流量流分析。

**问题 378。** 一家大型金融机构最近遭遇了安全破口，攻击者能够绕过其入侵检测系统 (IDS)。经过调查，安全团队发现攻击者利用了一个零日利用漏洞。事后，该机构应该做什么来增强其 IDS 的能力？

- (A) 从基于签名的 IDS 切换到基于行为的 IDS
- (B) 禁用 IDS 并完全依赖防火规则
- (C) 使用最新的威胁情报馈和签名更新 IDS
- (D) 减少 IDS 签名更新的频率

**解释 378。** **正确答案：A. 从基于签名的 IDS 切换到基于行为的 IDS。** 基于行为的 IDS（或异常检测 IDS）监控网络流量并与建立的基准进行比较，使其能够检测到零日漏洞和其他签名系统可能会漏掉的新颖攻击。

选项 B 错误。在没有 IDS 的情况下完全依赖防火规则会降低安全深度，并使机构面临更多风险。

选项 C 错误。虽然使用最新签名更新 IDS 是重要的，但在该漏洞的签名创建并传播之前，它并不一定能检测到零日漏洞。

选项 D 错误。减少 IDS 签名更新频率将使系统对最近的威胁更加脆弱。

**问题 379。** 在发生大停电后，TechWave Corp. 希望确保其主数据中心的运行能够快速、无缝地转移到另一个设施。公司希望此过程是自动化且即时的，以防止任何服务中断。TechWave Corp. 应该进行何种类型的测试来验证此功能？

- (A) 对两个数据中心进行漏洞评估
- (B) 执行故障转移测试 (failover test)
- (C) 参加桌面演练 (tabletop exercise)
- (D) 执行常规备份测试

**解释 379。** **正确答案：B. 执行故障转移测试。**
故障转移测试涉及模拟主系统故障，以确保备份系统无缝接管而无任何服务中断。它有助于验证组织基础设施的韧性和恢复能力。

**选项 A 错误。** 漏洞评估识别系统中的潜在缺陷，但并不测试主系统和备份系统之间的无缝转换。

**选项 C 错误。** 桌面演练是基于讨论的会议，不涉及对系统或过程的现场测试。

**选项 D 错误。** 常规备份测试确保备份可以成功恢复，但不测试系统之间的即时切换能力。

**问题 380。** 安全管理员 Sarah 正在为她的组织服务器基础设施实施监控解决方案。她希望方案不需要在服务器本身上安装任何额外软件。Sarah 应该选择哪种类型的监控监控方法？

- (A) 基于代理的监控
- (B) 入侵检测系统 (IDS)
- (C) 无代理监控 (Agentless monitoring)
- (D) 基于网络的应用程序性能监控 (APM)

**解释 380。** **正确答案：C. 无代理监控。** 无代理监控解决方案不需要在监控的服务器上安装任何软件代理。它们通常依赖标准协议和接口来收集性能和其他数据。

选项 A 错误。基于代理的监控需要在每个要监控的服务器或设备上安装软件代理。

选项 B 错误。虽然入侵检测系统 (IDS) 是一种安全工具，但它并非专门为无代理基础设施监控设计的。

选项 D 错误。基于网络的应用程序性能监控 (APM) 专注于监控网络上的应用程序性能，而不是无代理服务器监控。

**问题 381。** 网络安全分析师 Alice 的任务是在新部署的 Web 应用程序上线之前识别其基础设施中的潜在缺陷。她希望一种工具能够主动发现并报告系统漏洞、缺失补丁和配置错误。Alice 应该利用哪种工具？

- (A) 入侵检测系统 (IDS)
- (B) 网络嗅探器
- (C) 漏洞扫描器
- (D) 安全信息和事件管理 (SIEM) 系统

**解释 381。** **正确答案：C. 漏洞扫描器。** 漏洞扫描器旨在通过探测和分析来发现并报告潜在漏洞。它们可以检测缺失补丁、配置错误等问题。

选项 A 错误。IDS 根据特定签名或启发式算法对潜在恶意活动进行检测并告警，但不会主动扫描漏洞。

选项 B 错误。网络嗅探器捕获并分析网络流量，但不对基础设施组件进行漏洞评估。

选项 D 错误。虽然 SIEM 系统可以聚合和分析来自各种源的日志和事件数据，但它不会像漏洞扫描器那样主动扫描漏洞。

**问题 382。** 在进行业务影响分析后，当地一家图书馆确定他们可以承受几天的停机而不会对其运营产生重大影响。他们希望获得一种能够在成本和恢复能力之间平衡的灾难恢复解决方案。哪种站点考虑因素最符合图书馆的需求？

- (A) 具有全套 IT 设备的移动站点
- (B) 具有每日数据同步的热备 (Hot site)
- (C) 冷备 (Cold site)
- (D) 具有每周备份的温备 (Warm site)

**解释 382。** **正确答案：C. 冷备 (Cold site)。** 冷备是一个预先配置好的场所，用于接收设备和数据备份，但本身不具备任何设备。考虑到图书馆对几天停机的容忍度，冷备是一个符合其恢复能力的成本效益型解决方案。
