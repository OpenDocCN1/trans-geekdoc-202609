**Question 158.** John, a security analyst, noticed an increase in unauthorized devices connecting to the company’s wireless network. To identify the reason, he realized that the wireless access points were still using an an old encryption standard. Which outdated encryption standard is likely in use that is known to be easily compromised?

+   (A) WPA3
(B) WEP
(C) WPA2-PSK
(D) AES

**Explanation 158.** **Correct Answer: B. WEP.** Wired Equivalent (WEP) is an old and outdated encryption protocol for wireless networks. It has several known vulnerabilities and is considered insecure, making it easier for attackers to compromise.
