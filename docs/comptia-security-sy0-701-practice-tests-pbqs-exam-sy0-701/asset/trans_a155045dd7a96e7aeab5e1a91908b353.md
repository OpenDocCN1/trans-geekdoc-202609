问题 143。一家快速增长的电子商务公司最近遭遇了跨站脚本（XSS）和 SQL 注入攻击的增加。该公司希望部署一种专门在应用程序层防御这些威胁的解决方案。哪种类型的防火墙最合适？

- (A) 状态检测包防火墙（Stateful Packet Inspection Firewall）
- (B) 代理防火墙（Proxy Firewall）
- (C) 网络层防火墙（Network Layer Firewall）
- (D) Web 应用防火墙（WAF）

解析 143。正确答案：D。Web 应用防火墙 (WAF)。Web 应用防火墙（WAF）专门用于通过监控、过滤和拦截潜在有害 HTTP 流量来保护 Web 应用程序。这包括针对 Web 应用程序常见的 XSS 和 SQL 注入攻击。

选项 A 错误。虽然状态检测包防火墙可以监控活动连接的状态并根据流量上下文做出决策，但它并没有专门针对 XSS 和 SQL 注入等应用层漏洞。

选项 B 错误。虽然代理防火墙可以提供某些应用层过滤，但其主要目的并非为防御特定的 Web 应用程序漏洞而设计。

**选项 C 错误。** 网络层防火墙主要运行在网络层，不会对应用层威胁提供专门保护。

问题 144。一家金融机构希望增强其有线网络的安全性。目标是确保只有授权的设备才能连接到网络，且身份验证过程应基于凭据或数字证书。哪种协议最符合此目的？

- (A) SNMPv3
- (B) SSL/TLS
- (C) 802.1X EAP
- (D) DHCP

解析 144。正确答案：C。802.1X EAP。802.1X 可扩展身份验证协议（EAP）提供了基于端口的网络访问控制，用于有线网络以确保只有经过的设备设备连接。它支持多种身份验证方法，包括凭据、数字证书和智能卡。

选项 A 错误。SNMPv3（简单网络管理协议 3 版）用于网络管理和监控，而不是用于基于端口的网络访问控制。

选项 B 错误。SSL/TLS（安全套字/传输层安全）是用于互联网上数据传输安全的协议，而不是用于基于端口的网络访问控制。

选项 D 错误。DHCP（动态主机配置协议）为网络上的设备分配 IP 地址，但不处理基于端口的身份验证。

问题 145。某机构正在为他们新的分办事处评估不同的安全解决方案。他们希望确保所选方案能够以最少的配置快速部署。以下哪个选项**最**符合这一要求？

- (A) 为组织独特需求定制的定制化入侵防御系统（IPS）
- (B) 零接触置备防火墙（zero-touch provisioning firewall）
- (C) 具有大量手动设置的开源防火墙
- (D) 需要手动集成日志源的安全信息和事件管理（SIEM）解决方案

解析 145。正确答案：B。零接触置备防火墙。零接触置备允许设备自动配置和配置，确保在最少人工干预的情况下实现快速部署。

选项 A 错误。虽然定制的 IPS 可能根据组织需求定制，但它通常需要大量的配置，且部署速度最快。

选项 C 错误。需要大量手动设置的开源防火墙不被认为是快速部署，因为它们需要更多的配置时间。

选项 D 错误。需要手动集成日志源的 SIEM 解决方案由于涉及手动步骤，部署速度不会最快。

问题 146。一家名为 TechFlow 的公司计划生产一系列新的智能家居设备。他们选择由单一供应商提供设备中的一个关键组件。以下哪项代表了与此决定相关的**最大**安全风险？

- (A) 仅与一个供应商谈判价格将面临挑战
- (B) 如果供应商的交付时间延迟，产品发布可能会推迟
- (C) 供应商处遭到攻击可能导致所有设备出现漏洞
- (D) TechFlow 将依赖供应商的保修和退货政策

解析 146。正确答案：C。供应商处遭到攻击可能导致所有设备出现漏洞。依赖单一供应商意味着该供应商端的任何安全问题都可能直接转化为使用该组件的每个设备的漏洞。

在供应链中，每个实体的安全性都至关重要。如果一个供应商遭到攻击，而公司仅依赖该供应商提供关键组件，那么每个使用该组件的产品都可能受到威胁。可能会对终端用户的安全产生广泛影响，并损害公司的声誉。

选项 A 错误。价格谈判是业务考虑因素，与使用单一供应商的安全影响没有直接关系。

选项 B 错误。虽然交付延迟可能会产生业务影响，但它们不代表直接的安全风险。

选项 D 错误。保修和退货政策是运营考虑因素，但不是依赖单一供应商相关的主要安全风险。

问题 147。某跨国公司的安全团队在全球范围内部署了蜜罐网络（honeypots），使其看起来像一个互联且真实的环境。他们的目标是研究协调的多阶段攻击。这种欺骗性被称为：

- (A) 防火墙集群（Firewall Cluster）
- (B) 虚拟局域网（VLAN）
- (C) 分布式拒绝服务（DDoS）防护
- (D) 蜜罐网（Honeynet）

解析 147。正确答案：D。蜜罐网。蜜罐网本质上是一个蜜罐网络。它设计用于吸引攻击者，让他们认为自己正在攻击真实网络，而实际上他们的策略技术正在被观察和分析。

选项 A 错误。防火墙集群是共同工作的防火墙组，旨在提高可靠性和性能。它不是作为吸引攻击者的诱骗系统。

选项 B 错误。虚拟局域网（VLAN）用于在物理网络内创建逻辑分段网络的协议，提高了性能和安全性。它不是诱骗系统。

选项 C 错误。分布式拒绝服务（DDoS）防护解决方案侧重于识别和缓解大规模网络服务可用性的尝试。它们不会为攻击者提供欺骗性环境。
