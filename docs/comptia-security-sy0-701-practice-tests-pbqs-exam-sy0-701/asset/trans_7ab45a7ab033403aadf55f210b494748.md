问题 8。某金融机构最近发现，大量机密客户记录在非工作时间被访问和复制。调查发现，这些访问来自公司内部的一名经过身份验证的用户，该用户最近错失了晋升。哪种类型的威胁主体**最可能**对此次安全事件负责？

- (A) 黑客主义者 (Hacktivist)
- (B) 内部威胁 (Insider threat)
- (C) 国家实体 (Nation-state)
- (D) 有组织犯罪集团 (Organized crime syndicate)

解析 8. 正确答案：B。内部威胁。证据表明活动是由组织内部的经过身份验证的用户进行的，该用户可能有动机（未获得晋升）。内部威胁是指来自组织内部个人（如员工、承包商或业务伙伴）的风险，他们对组织的安全实务、数据和计算机系统拥有内部信息。

选项 A 是错误的。黑客主义者通常受政治或社会事业驱动，并以目标组织来促进或抗议特定问题。他们通常不会因为错失晋升等个人不满而采取行动。

选项 C 是错误的。国家实体受政治、间谍或军事目的驱动。出于个人原因访问金融机构的客户记录并不符合他们的典型动机。

选项 D 是错误的。虽然有组织犯罪集团可能出于财务利益对客户记录感兴趣，但内部访问以及与错失晋升相关的动机强烈暗示了内部威胁。

问题 9。某公司正在评估其数据存储方案。他们需要一种解决方案，能够让他们对**硬件、软件和网络配置拥有最高级别的控制**，并允许实施定制化的安全控制和措施。哪种部署模型最符合他们的需求？

- (A) 云端基础设施 (Cloud-based Infrastructure)
- (B) 混合基础设施 (Hybrid Infrastructure)
- (C) 本地基础设施 (On-premises Infrastructure)
- (D) 社区云 (Community Cloud)

解析 9. 正确答案：C。本地基础设施。本地基础设施允许组织对其硬件、软件和网络配置拥有完全控制权。这使他们能够根据自己的特定需求定制安全控制和措施。

选项 A 是错误的。云端基础设施由第三方供应商托管，这意味着组织可能对其资源没有同等程度的控制或定制化。

选项 B 是错误的。混合基础设施结合了本地和云资源。虽然它比纯云端解决方案提供了更多控制权，但仍然无法提供本地基础设施所提供的完全控制。

选项 D 是错误的。社区云由几个具有相似需求的组织共享。虽然它提供了一定程度的控制，但无法提供像本地基础设施那样的完全定制化和控制。

问题 10。一家新科技公司最近发布了一种使用面部识别进行身份验证的设备。一名安全研究人员在没有任何恶意意的情况下，演示了使用照片绕过面部识别的方法。随后，研究人员向公司提交了该发现，并未将其发表。研究人员行为背后的主要动机是什么？

- (A) 反对面部识别的哲学信念
- (B) 通过勒索公司获取财务利益
- (C) 对消费者安全的伦理考量
- (D) 旨在损害公司的市场声誉

解析 10. 正确答案：C。对消费者安全的伦理考量。通过在没有恶意意或未公开的情况下向公司负责任地披露漏洞，研究人员展示了伦理动机，旨在提高消费者安全。

选项 A 是错误的。研究人员并未表达对面部识别技术的反对，只是强调了一个潜在的漏洞。

选项 B 是错误的。没有证据表明研究人员试图勒索公司。相反，他们负责任地披露了漏洞。

选项 D 是错误的。研究人员选择不公开漏洞，表明他们的目标不是损害公司的声誉，而是协助改进安全性。

问题 11。ABC 公司最近采纳了自备设备办公 (BYOD) 政策。IT 部门对个人设备访问公司网络带来的风险表示担忧。以下哪种解决方案对于在个人移动设备上强制执行安全策略**最有效**？

- (A) 在每个设备上安装防病毒软件
- (B) 为移动设备建立独立的访客 Wi-Fi 网络
- (C) 使用移动设备管理 (MDM) 来执行安全策略
- (D) 强制要求员工在个人设备上使用强密码

解析 11. 正确答案：C。使用移动设备管理 (MDM) 来执行安全策略。MDM 解决方案提供了集中控制，以执行安全策略、管理设备功能，并确保个人设备在访问公司资源之前符合组织的安全标准。

选项 A 是错误的。虽然安装防病毒软件是一种良好的安全措施，但它无法提供 MDM 那种全面的策略执行能力。

选项 B 是错误的。独立的访客 Wi-Fi 可能限制对内部网络的访问，但它无法管理或强制执行设备本身的安全策略。

选项 D 是错误的。虽然使用强密码至关重要，但它只是设备安全的一个方面。MDM 提供了更广泛的策略执行能力。

问题 12。软件开发公司 AcmeTech 最近经历了重大数据泄露，追溯源于其定制应用程序的一个漏洞。事后分析显示，该漏洞是在编码阶段引入的，在测试期间从未被发现。为了避免未来出现此类漏洞，AcmeTech 应该强调哪种策略以确保在开发过程中维持安全规范？

- (A) 应急响应策略 (Incident Response Policy)
- (B) 变更管理策略 (Change Management Policy)
- (C) 业务连续性策略 (Business Continuity Policy)
- (D) 软件开发生命周期 (SDLC) 策略

解析 12. 正确答案：D。软件开发生命周期 (SDLC) 策略。软件开发生命周期 (SDLC) 策略为软件开发过程的每个阶段提供了指南和标准，确保从需求收集到部署和维护的每一步都集成安全性。

选项 A 是错误的。虽然应急响应策略提供了一种管理和响应安全事件的结构化方法，但它并不关注软件开发过程。

选项 B 是错误的。变更管理策略处理在 IT 环境中实施变更的程序，但不专门针对软件应用程序的开发。

选项 C 是错误的。业务连续性策略侧重于在干扰及之后维持业务运营，不涉及软件开发的细节。

- (A) 获取竞争情报的间谍活动
- (B) 损害该高管公司声誉的服务中断
- (C) 利用敏感信息进行勒索以获取资金
- (D) 为了在暗网出售而外泄数据
