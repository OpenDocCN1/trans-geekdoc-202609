

问题 99. 一位 IT 经理正在考虑保护提供给远程员工的笔记本电脑上存储数据的解决方案。主要关注的是确保如果笔记本电脑丢失或被盗，其笔记本存储驱动器的全部内容都是不可读的。哪种加密级别最能解决这一问题？

- (A) 文件级加密 (File-level Encryption)
- (B) 传输层加密 (Transport-layer Encryption)
- (C) 全盘加密 (Full-disk Encryption)
- (D) 数据库级加密 (Database-level Encryption)

解释 99. **正确答案：C. 全盘加密。**
全盘加密 (FDE) 对整个存储驱动器进行加密，使得在没有正确密密钥或凭据的情况下，驱动器上的所有数据都是不可读的。这对于笔记本电脑等移动式设备特别有用，因为这些设备更容易被物理盗窃。

选项 A 错误。文件级加密的是单个文件而不是整个磁盘，因此某些数据或系统文件可能仍处于加密状态。

选项 B 错误。传输层加密保护传输中的数据，而不是存储驱动器上的静态数据。

选项 D 错误。数据库级加密加密的是数据库内部的数据，不适用于该数据库之外的其他文件或数据。

问题 100. 一家大公司的财务部门仍然依靠一个遗留应用程序进行季度报告。已知该应用程序存在一些安全缺陷，但由于其关键性，无法轻易替换。该公司如何**最佳地**缓解与该应用程序相关的风险？

- (A) 对财务团队进行最新网络安全威胁的培训
- (B) 在最新的硬件上运行遗留应用程序以提高性能
- (C) 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后
- (D) 频繁更改访问该应用程序的用户密码

**解释 100.** **正确答案：C. 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后。** 通过将应用程序置于 WAF 之后，公司可以过滤、监控并阻止针对应用程序漏洞的恶意 HTTP 流量，从而为遗留应用程序中潜在的安全缺陷提供了一层保护。

**选项 A 错误。** 虽然培训至关重要，但它不能直接解决遗留应用程序中的漏洞。

**选项 B 错误。** 使用最新的硬件可能会提高应用程序性能，但不能缓解与其漏洞相关的安全风险。

**选项 D 错误。** 虽然频繁更改密码可以增强安全性，但它们无法解决遗留应用程序固有的漏洞。
