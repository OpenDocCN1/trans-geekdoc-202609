**问题 330。** 终端 Sarah 从一个网站下载了软件更新。在安装之前，她想确保该软件没有被恶意修改，并且源自受信任的来源。Sarah 应该检查什么来验证这一点？

-   (A) 网站的 SSL 证书
-   (B) 应用程序的代码签名证书
-   (C) 应用程序的开源仓库
-   (D) 软件的用户评论

**解释 330. 正确答案：B. 应用程序的签名证书。** 通过检查应用程序的代码签名证书，Sarah 可以验证该软件确实是由受信任的实体颁发的，并且自签名以来未被变动过。有效的代码签名证书能让用户对软件的真实性和完整性有信心。

**选项 A 错误。** 虽然网站的 SSL 证书确保了服务器和浏览器之间数据传输的安全性，但它不能保证所下载软件的完整性或真实性。

**选项 C 错误。** 开源仓库可能包含软件的源代码，但检查这些仓库并不一定能验证 Sarah 下载的编译软件版本的完整性。

**选项 D 错误。** 用户评论可以提供有关软件功能和用户体验的见解，但不能依靠它们来确认软件的真实性或完整性。

**问题 331。** 一家本地咖啡店为其客户提供免费 Wi-Fi。最近，有报告称网络遭受了中间人攻击。老板决定升级无线安全，并希望实现一种加密协议来保护数据传输。哪种协议能在公共 Wi-Fi 用户之间平衡安全性和性能性能？

-   (A) 高级加密标准 (AES)
-   (B) 有线等效隐私 (WEP)
-   (C) RC4 流加密算法
-   (D) 开放无线 (Open Wireless)

**解释 331. 正确答案：A. 高级加密标准 (AES)。** AES 在安全和性能之间提供了良好的平衡。它是一种现代加密标准，提供强安全性的同时不会产生显著的性能开销，适用于安全性和用户体验都重要的公共 Wi-Fi 环境。

**选项 B 错误。** WEP 是一种过时的加密协议，存在已知漏洞。它不安全且容易被破解，不适合保护公共 Wi-Fi 网络。

**选项 C 错误。** RC4 是一种曾用于 WEP 等旧版无线协议的流加密算法。它被发现容易受到各种攻击的影响，且不再被认为对无线网络是安全的。

**选项 D 错误。** 开放无线网络不实现任何加密，导致数据传输容易受到窃听和其他攻击的影响。它无法为咖啡店的 Wi-Fi 用户提供所需的安全性。

**问题 333。** 在对公司基础设施运行漏洞扫描后，安全分析师注意到某服务器上报告了一个漏洞。然而，在经过手动验证后，分析师确定该漏洞并未实际存在服务器上。这种情况最准确描述是？

-   (A) 假阴性 (False negative)
-   (B) 真阳性 (True positive)
-   (C) 假阳性 (False positive)
-   (D) 确认偏差 (Confirmation bias)

**解释 333. 正确答案：C. 假阳性。** 假阳性发生在系统错误地标记漏洞时。

**选项 A 错误。** 假阴性意味着漏洞存在，但系统未能检测到它。

**选项 B 错误。** 真阳性意味着漏洞被正确识别，而事实并非如此。

**选项 D 错误。** 确认偏差是一种认知偏差，人们倾向于支持确认现有信念的信息，这与此处不符。

**问题 334。** 一个电子商务平台最近遭遇了入侵，攻击者利用了会话（sessions）。安全分析师被指派建议保护 cookie 的措施。以下哪项可以确保 cookie 安全地传输？

-   (A) 将 cookie 存储在数据库中
-   (B) 为 cookie 实现“Secure”属性
-   (C) 增加 cookie 的过期时间
-   (D) 对内容进行 Base64 编码

**解释 334. 正确答案：B. 为 cookie 实现“Secure”属性。** “Secure”属性确保 cookie 仅通过 HTTPS 发送，降低了被拦截的风险。

**选项 A 错误。** 将 cookie 存储在数据库中并不一定确保客户端和服务器之间 cookie 传输的安全性。这更多关于存储而非传输。

**选项 C 错误。** 增加 cookie 的过期时间实际上会扩大攻击者利用它的窗口。

**选项 D 错误。** Base64 编码不是加密；它只是将二进制数据表示为 ASCII 字符串的方法，并且很容易反转。

**问题 335。** 安全分析师正在查看一份漏洞报告，看到引用 CVE-2023-12345，其 CVSS 分为 9.5。根据这些信息，分析师可以得出以下哪个结论？

-   (A) 该漏洞在2023 年首次发现
-   (B) 该漏洞严重性较低
-   (C) 该漏洞仅影响 2023 年产生的软件
-   (D) CVE-2023-12345 是软件供应商对该漏洞的内部代码

**解释 335. 正确答案：A. 该漏洞在2023 年首次发现。** CVE 标识符的格式以漏洞公布年份，因此 CVE-2023-12345 表示在2023 年发现的漏洞。

**选项 B 错误。** CVSS 分值范围从 0 到 10，分数越高表示严重性越高。9.5 分被认为是严重程度的。

**选项 C 错误。** CVE 标识符中的年份指的是漏洞发布的年份，而不是软件生产的年份。

**选项 D 错误。** CVE 系统是一种识别漏洞的标准方法，并不代表软件供应商的内部编码。
