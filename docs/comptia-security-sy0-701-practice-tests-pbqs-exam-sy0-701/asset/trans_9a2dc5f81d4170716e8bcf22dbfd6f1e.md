
选项 A 错误。虽然状态检测防火墙（Stateful Packet Inspection Firewall）可以监控活动连接的状态并分析数据包，但它不支持像 NGFW（下一代防火墙）那样的应用级过滤或威胁情报集成等高级功能。

选项 B 错误。代理服务器控制并过滤从客户端到服务器的请求，通常用于 Web 访问。它具备 NGFW 的全面安全功能。

选项 C 错误。Web 应用防火墙（WAF）专门保护应用程序免受针对性攻击。虽然很有价值，但它提供的功能和集成范围不如 NGFW 广泛。

问题 293. 一名安全分析师正在查看一份漏洞报告，看到一个 CVSS 分数为 9.5 的 CVE-2023-12345。根据这些信息，分析师可以得出以下哪个结论？

- (A) 该漏洞首次发现于 2023 年
- (B) 该漏洞的严重程度很低
- (C) 该漏洞仅影响 2023 年生产的软件
- (D) CVE-2023-12345 是软件供应商对该漏洞的内部代码

解释 293. 正确答案：A。该漏洞首次发现于 2023 年。CVE 标识符的格式以漏洞公布的年份开头，因此 CVE-2023-12345 表示该漏洞是在 2023 年的。

选项 B 错误。CVSS 分值范围从 0 到 10，分数越高表示严重程度越高。9.5 分被认为是严重级（critical），而不是低严重性。

选项 C 错误。CVE 标识符中的年份是指漏洞公布的年份，而不是软件生产的年份。

选项 D 错误。CVE 系统是识别漏洞的标准方法，并不代表软件供应商的内部编码。

问题 294. 软件开发公司 GlobalTech 与 Web 托管提供商 WebSolutions 建立合作伙伴关系。他们的目标是建立一套标准条款来管理他们持续的业务交易，包括支付条款、交付协议和保修。哪种类型的协议最适合为未来的交易建立这些基础条款？

- (A) 合作备忘录 (MOU)
- (B) 保密协议 (NDA)
- (C) 许可协议 (Licensing agreement)
- (D) 主服务协议 (MSA)

解释 294. 正确答案：D。主服务协议 (MSA)。主服务协议 (MSA) 旨在定义双方之间业务交易条款和条件的广泛框架。它设定了通用条款，以便在随后的合同中协商细节。鉴于 GlobalTech 和 WebSolutions 意图为它们的持续交易概述基础条款，MSA 是最合适的选择。

选项 A 错误。MOU 建立了共同的意图，但通常不详细说明具体的交易条款。

选项 B 错误。NDA 侧重于维护机密，不建立交易条款。

选项 C 错误。许可协议涉及使用、分发或复制特定软件或知识产权的权利。

问题 295. 领先的 IT 公司 AlphaTech 最近在其主要软件产品中发现了一个严重漏洞。他们已经开发了一个补丁来修复该漏洞。在将补丁分给客户之前，AlphaTech 理想情况下应该执行以下哪些操作？

- (A) 在所有公司系统上部署补丁
- (B) 通知媒体该漏洞
- (C) 在控制环境中测试补丁
- (D) 为受影响的客户提供补偿

解释 295. 正确答案：C。在控制环境中测试补丁。在部署或发布补丁之前（尤其是对于严重漏洞），在控制环境中进行测试是关重要的。这确保了补丁不会引入新问题，并能有效解决漏洞。

选项 A 错误。在不测试的情况下立即在所有公司系统上部署补丁可能会导致不可预的问题，甚至加剧问题。

选项 B 错误。通知媒体该漏洞会导致。

选项 D 错误。为受影响的客户提供补偿无法直接解决漏洞。

问题 296. 某知名软件开发公司的员工经常访问某个论坛。由于该漏洞，攻击者可以利用该网站投放恶意软件。哪种攻击类型最准确地描述这种场景？

- (A) 鱼叉式网络钓鱼 (Spear Phishing)
- (B) 水坑攻击 (Watering Hole)
- (C) 旁路下载 (Drive-by)
- (D) 鲸叉钓鱼 (Whaling)

解释 296. 正确答案：B。水坑攻击。水坑攻击涉及目标成员访问的特定网站或在线资源，一旦被攻破，攻击者可以向其投放恶意软件。

选项 A 错误。鱼叉式网络钓鱼是针对特定个人或组织的网络钓鱼尝试。

选项 C 错误。旁路下载可能是一旦论坛被攻破后用于投放恶意软件的方法。

选项 D 错误。鲸叉钓鱼是针对首席执行官或财务总官等高层目标的钓鱼攻击。

问题 297. 一家网络安全公司被 TechGiant Corp 聘请对其基础设施进行渗透测试。在测试开始之前，TechGiant Corp 的 CEO 希望确保某些关键系统不被针对，并且测试不会干扰他们的日常运营。应该建立什么来定义测试的范围和边界？

- (A) 服务水平协议 (SLA)
- (B) 保密协议 (NDA)
- (C) 介入规则 (ROE)
- (D) 合作备忘录 (MOU)

解释 297. 正确答案：C。介入规则 (ROE)。介入规则 (ROE) 文档定义了渗透测试的范围、边界、方法和其他关键指南。它确保测试团队和组织都理解并同意在测试期间可以做和不能做什么。

选项 A 错误。服务水平协议 (SLA) 主要处理预期的服务水平，如可用性、响应时间等。它不定义渗透测试的边界。

选项 B 错误。保密协议 (NDA) 是关于保持机密的，不会定义测试的范围。

选项 D 错误。合作备忘录 (MOU) 是双方之间的通用协议，但它没有详细说明渗透测试的具体范围和规则，如 ROE。

- (A) 权限提升漏洞 (Elevation of privilege vulnerability)
- (B) 泄露漏洞 (Disclosure vulnerability)
- (C) 重放漏洞 (Replay vulnerability)
- (D) 远程代码执行漏洞 (Remote code execution vulnerability)
