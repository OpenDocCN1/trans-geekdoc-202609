

问题 197。某金融应用程序允许用户通过输入账号密码和转账金额向其他账户转账。在一次安全审计中，发现恶意用户可以在账号字段中输入 SQL 代码来操纵应用程序数据库。开发团队应该实施哪种安全技术来解决这一漏洞？

- (A) 代码混淆 (Code obfuscation)
- (B) 输入验证 (Input validation)
- (C) 静态加密 (Encryption at rest)
- (D) 会话超时 (Session timeout)

解析 197。**正确答案：B. 输入验证。** 输入验证确保应用程序只接受有效且预期的数据。通过对用户输入进行验证和清理，应用程序可以防止恶意数据（如 SQL 代码）被处理和执行，从而降低 SQL 注入攻击的风险。

选项 A 错误。代码混淆攻击者理解应用程序代码的难度，但不能防止他们注入恶意输入。

选项 C 错误。静态加密保护存储的数据，但不能防止利用应用程序输入处理的 SQL 注入攻击。

选项 D 错误。会话超时限制了用户会话的持续时间，但它不对用户输入进行验证或清理。

问题 198。GreenTech 公司正在向另一公司出售一批旧服务器。在交易完成之前，他们希望确保这些服务器上的数据是无法恢复的，并且能够证明他们执行了尽职调查。GreenTech 应该寻求什么证明来向买家保证数据已正确销毁？

- (A) 服务器的销售收据
- (B) 服务器使用的详细日志
- (C) 数据清理证书 (Certificate of data sanitization)
- (D) 服务器的用户说明书

解析 198。正确答案：C. 数据清理证书。来自信誉实体的数据清理证书可以保证服务器上的所有数据都已安全且完全地擦除。此类证书确认了使用了特定技术来确保数据无法恢复，从而给买家信心。

选项 A 错误。销售收据仅证明交易已经发生，但没有涉及数据清理或销毁。

选项 B 错误。服务器使用日志可能会详细说明其运行历史，但不能提供数据销毁的保证。

选项 D 错误。用户说明书提供了如何使用服务器的说明，但不涉及其曾经持有的数据状态或安全性。

问题 199。某医疗机构使用一个软件平台管理患者记录。最近的漏洞评估发现了一个潜在的利用漏洞，未经授权的人员可能会访问 30% 的存储患者数据。以下哪项最准确地描述这一场景？

- (A) 威胁发生的概率为 30%
- (B) 漏洞的发生率为 30%
- (C) 漏洞的暴露因子 (Exposure factor) 为 30%
- (D) 30% 的患者已受到影响

解析 199。正确答案：C。漏洞的暴露因子为 30%。暴露因子是衡量已实现的威胁将破坏或损害的损失规模或资产价值百分比的指标。在这种情况下，漏洞可能导致 30% 的患者数据被访问。

选项 A 错误。可能性（Likelihood）指的是事件发生的概率，而不是潜在影响或可能暴露的数据量。

选项 B 错误。发生率 (ARO) 是衡量特定事件发生频率的指标，而不是潜在影响或可能暴露的数据量。

选项 D 错误。场景并未表明 30% 的患者已经受到影响，仅说明如果漏洞被利用，他们的数据可能会被访问。

问题 200。GreenTech 工业公司位于一个相对偏僻的地区。近期发生的盗窃和入侵事件引起了管理层的警觉。以下哪种措施最有效地防止未经授权的夜间进入设施周边界？

- (A) 安装红外传感器
- (B) 使用明亮的周边照明
- (C) 在设施内部部署额外的安保人员
- (D) 增加设施墙的高度

解析 200。**正确答案：B. 使用明亮的周边照明。** 明亮的周边照明对未经授权的人员具有强力威慑作用，它减少了隐藏点，使监控摄像头更有效，并让安全人员更容易发现潜在威胁。在偏僻地区，适当的照明对于照亮黑暗区域和威慑作用尤为重要。

选项 A 错误。虽然红外传感器可以检测移动，但它们不像照明那样起到威慑作用。

选项 C 错误。在设施内部部署额外的安保人员没有解决迫切的问题。

选项 D 错误。增加设施墙的高度可以起到威慑作用，但它不能提供照明。
