
解析 598. 正确答案：C. 禁用服务器上未使用的的服务和端口。通过减少活动的服务和端口数量，可以直接减少攻击者的潜在切入点数量，从而减小攻击面。

选项 A 错误。虽然增加密码长度可以提高防止暴力破解攻击的安全性，但它不会直接影响攻击面。

选项 B 错误。定期的漏洞评估可以识别潜在的安全漏洞，但除非根据发现的结果采取行动，否则仅仅是识别并不能减少攻击面。

选项 D 错误。严格的 BYOD（自带设备办公）策略可以增强安全性，但它更多关注的是设备类型及其连接方式，而不是减少潜在攻击点的数量。

问题 599. 一用户收到一条声称来自其银行的短信，提醒其账户存在未经授权的活动。短信指示用户立即点击提供的链接并验证其账户详情。该用户尚未发现其银行账户有任何异常。此短信最可能是哪种攻击类型？

- (A) 手机短信钓骗 (Smishing)
- (B) 语音钓骗 (Vishing)
- (C) 蓝牙欺骗 (Bluejacking)
- (D) 蓝牙盗取 (Bluesnarfing)

解析 599. 正确答案：A. 手机短信钓骗 (Smishing)。手机短信钓骗是一种钓鱼攻击，恶意攻击者利用短信欺骗个人提供敏感信息，通常通过冒充受信任的组织或联系人。

选项 B 错误。Vishing 指语音钓骗，攻击者使用语音电话代替短信或电子邮件冒充合法实体并诈骗受害者。

选项 C 错误。Bluejacking 涉及向支持蓝牙的设备发送未经请求的消息。它通常不涉及为了欺骗目的而冒充合法实体。

选项 D 错误。Bluesnarfing 是对蓝牙设备进行未经授权的访问或信息窃取的类型。它不涉及欺骗性短信。

问题 600. 在最近发生安全泄露事件后，CyberCorp 正在审查其软件供应商对漏洞的响应情况。以下哪些指标可以帮助 CyberCorp 判断供应商提供安全补丁的及时性和效率？

- (A) 供应商发布软件更新频率
- (B) 供应商的季度财务报告
- (C) 漏洞披露到供应商发布补丁之间的时间
- (D) 供应商在上次软件更新中添加的功能数量

解析 600. 正确答案：C. 漏洞披露到供应商发布补丁之间的时间。供应商在漏洞披露后发布安全补丁所需的时间，是衡量其对安全威胁响应能力的直接标准。持续越短，表示对安全问题的优先级越高。

选项 A 错误。软件更新的频率并不意味着与安全补丁的及时相关。供应商可能会频繁发布更新，但在处理安全问题方面仍然缓慢。

选项 B 错误。供应商的季度财务报告可能表明公司的财务状况，但不能直接反映其对安全漏洞的响应。

选项 D 错误。软件更新中添加的功能数量不能说明安全补丁的及时性或有效性。
