问题 154。某电子商务平台最近遭受了数据 泄露，攻击者利用 cookie 冒充用户会话。安全分析师的任务是建议保护用户 cookie 的措施。以下哪种措施可以确保 cookie 在用户浏览器和服务器之间安全传输？

- (A) 将 cookies 存储在数据库中
- (B) 为 cookies 设置 "Secure" 属性
- (C) 增加 cookie 的过期时间
- (D) 对 cookie 内容进行 Base64 编码

解释 154. 正确答案：B。为 cookies 设置 "Secure" 属性。"Secure" 属性可确保 cookie 仅通过安全的、加密的 HTTPS 连接发送。通过实施此属性，cookie 将不会在未加密的 HTTP 连接上传输，从而降低了被攻击者拦截的风险。

选项 A 错误。将 cookies 存储在数据库中并不一定能确保客户端和服务器之间 cookie 传输的安全。这更多是关于存储安全，而不是传输安全。

选项 C 错误。增加 cookie 的过期时间实际上会增加攻击者利用 cookie 的机会窗口，使其成为一种不安全的做法。

选项 D 错误。Base64 编码不是加密；它只是将二进制数据以 ASCII 字符串格式表示的方法。编码可以被轻易反转，提供的安全性很低或没有。

问题 155。某机构最近为其关键基础设施接收了一个新的软件补丁。在部署到生产环境之前，安全团队想要了解其行为并确保不包含任何恶意代码。以下哪种方法对于安全地执行和观察补丁的行为最有效？

- (A) 在维护窗口期间部署补丁
- (B) 在沙箱环境中运行补丁
- (C) 对补丁进行代码审查
- (D) 在虚拟机上安装补丁

解释 155. 正确答案：B。在沙箱环境中运行补丁。在沙箱环境中运行补丁允许安全团队在隔离环境中执行并观察软件的行为，确保其不会干扰或损害实际生产环境。

选项 A 错误。在维护窗口期间部署补丁减少了操作中断，但并不允许安全地观察补丁的行为。

选项 C 错误。虽然代码审查可以识别补丁中潜在的安全问题，但它可能无法揭示执行时的实际行为。

选项 D 错误。在虚拟机上安装补丁是一种隔离形式，但沙箱提供了一个专门为观察软件行为设计的更受控、限制更多的环境。

问题 156。CyberTech Inc 新入职的安全分析师想更好地了解组织的网络基础设施。以下哪些活动可以提供网络中当前活动的服务器、工作站、打印机、交换机和路由器的**列表**？

- (A) 漏洞扫描
- (B) 入侵检测
- (C) 网络枚举
- (D) 渗透测试

解释 156. 正确答案：C。网络枚举。网络枚举是识别网络上设备的过程。通过枚举，分析师可以收集有关网络设备、其类型和其他属性的信息，从而对网络基础设施有更清晰的了解。

选项 A 错误。漏洞扫描旨在识别网络设备和系统中的漏洞，而不一定非要列出所有活动设备。

选项 B 错误。入侵检测侧重于监控网络流量以发现恶意活动和潜在的安全违规。

选项 D 错误。渗透测试旨在利用网络中的漏洞来确定其安全态势，而不是列出所有活动设备。

问题 157。Tech Enterprises 计划发布一款新产品。作为产品创建的一部分，他们从多个供应商采购了组件。安全团队的任务是评估与供应链相关的风险。从多个供应商采购组件时，以下哪种风险是最令人担忧的？

- (A) 跟踪多个供应商产品保修细节的困难
- (B) 由于供应商交付时间不一导致产品组装时间增加
- (C) 引入不安全或被破坏组件的可能
- (D) 需要多个采购订单，导致文书工作增加

解释 157. 正确答案：C。引入不安全或被破坏组件的可能。当从多个供应商采购组件时，一个或多个组件存在漏洞或被破坏的风险增加，从而影响整个产品的安全性。

组件的完整性和安全性在产品开发中至关重要，特别是当这些组件是来自各种供应商的供应链的一部分时。如果某个供应商的安全措施松散或遭到破坏，他们提供的组件可能会向制成品中引入漏洞，影响其整体安全态势，并可能导致数据泄露或其他网络威胁。

选项 A 错误。虽然跟踪保修是一个运营问题，但在从多个供应商采购组件时，它并不构成直接的安全风险。

选项 B 错误。产品组装时间和供应商交付时间表是物流和运营问题，不是与供应链供应商相关的主要的安全风险。

选项 D 错误。管理多个采购订单是业务流程挑战，而不是主要的安全问题。

问题 158。安全分析师 John 注意到连接到公司无线网络的未授权设备增加。为了找出原因，他意识到无线接入点仍在使用一种旧的加密标准。可能在使用哪种已知易于被破解的过时加密标准？

- (A) WPA3
- (B) WEP
- (C) WPA2-PSK
- (D) AES

解释 158. 正确答案：B。WEP。有线传输（WEP）是无线网络的一种旧且过时的加密协议。它有多个已知漏洞，被认为是不安全的，使得攻击者更容易破解。

选项 A 错误。WPA3 是无线网络的一种较新且更安全的加密协议，被认为是对以前标准的重大改进。

选项 C 错误。WPA2-PSK（带有预共享密钥的 WiFi 保护）比 WEP 更安全。虽然它仍然可能被针对，但它不像 WEP 那样容易破解。

选项 D 错误。AES（高级加密标准）是一种加密标准，而不是无线加密协议。它通常用于 WPA2 和 WPA3 中以保护无线数据。

问题 159。在从 XYZ Corp 的高级网络管理员职位被开雇后，John 发现他在公司主服务器上之前设置了一个后门。随后，他在一个月多的时间内发起了一系列分布式拒绝服务（DDoS）攻击。John 行为最可能的动机是什么？

- (A) 对公司数据处理的伦理考虑
- (B) 通过出售后门访问权限获取利益
- (C) 研究并寻找漏洞以促进个人成长的欲望
- (D) 对公司解雇自己的报复

解释 159. 正确答案：D。对公司解雇自己的报复。鉴于 John 在被开雇后采取行动并启动破坏性攻击，显而易见，他的动机是出于前雇主的报复。
