**Question 60.** An organization with a single physical network infrastructure wants to separate the traffic of its finance department from that of the HR department. They do not to set up entirely new physical networks but want to ensure data packets from one department do not mix with the other's. What should the organization implement?

+   (A) Air-gapped network

+   (B) DMZ (Demilitarized Zone)

+   (C) VLAN (Virtual Local Area Network)

+   (D) VPN (Virtual Private Network)

**Explanation 60.** **Correct Answer: C. VLAN (Virtual Local Area Network).** A VLAN allows a network administrator to create a logical network within a physical network. This logical segmentation can separate the traffic of different departments, ensuring data packets from one VLAN do not mix with another, effectively isolating them.
