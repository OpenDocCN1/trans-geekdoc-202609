解释 198. **正确答案：C. HTTP 请求头伪造。** HTTP 请求头伪造涉及操作请求中的 HTTP 头来冒充、欺骗或欺骗系统，通常通过绕过安全控制或冒充其他用户。在描述的场景中，恶意攻击者更改了 HTTP 头以冒充另一个用户，这表明是一种 HTTP 请求头伪造攻击。

选项 A 错误。跨站请求伪造 (CSRF) 涉及在用户不知情的情况下，触发其在已认证的 Web 应用程序上执行操作。虽然它涉及伪造，但并不涉及如所述的直接操作 HTTP 请求头。

选项 B 错误。跨站脚本 (XSS) 涉及向其他用户查看的网络内容中注入恶意脚本。该场景不涉及注入脚本。

选项 D 错误。会话劫持涉及接管用户的会话以执行未经授权的操作。它并不特别涉及对 HTTP 请求头的操作。

问题 199. 一家公司的网络管理员注意到网络基础设施中的几个交换机不再接收来自提供的固件更新。这些设备已不再销售或支持。这些交换机为网络引入了什么漏洞？

- (A) 物理硬件篡改
- (B) 缺乏冗余
- (C) 对新威胁的敏感性增加
- (D) 无线干扰

解释 199. **正确答案：C. 对新威胁的敏感性增加。** 寿命结束的硬件通常不再接收安全更新或补丁，随着时间的推移更容易受到新型和不断演变的威胁。

寿命结束 (EOL) 的硬件指的是不再不再支持的设备。缺乏支持意味着设备将不会收到任何进一步的安全更新、补丁或技术支持。因此，这些设备更容易受到新威胁和漏洞的影响，对网络构成安全风险。

**选项 A 错误。** 寿命结束状态本身并不会使设备更容易受到物理篡改。然而，如果没有持续的更新，它们可能容易受到固件或基于软件的攻击，在某些情况下，这可能导致物理篡改。

**选项 B 错误。** 缺乏冗余是指系统或网络中的单点故障。它与与 EOL 硬件相关的漏洞没有直接关系。

**选项 D 错误。** 无线干扰与无线信号的干扰有关，不是 EOL 硬件的直接结果。

问题 200. 在检查 Web 服务器日志时，安全分析师 Sarah 注意到 URL 中包含“..%2F..”的请求模式。她怀疑这可能是试图利用某个漏洞。可能尝试的是哪种类型的应用程序攻击？

- (A) 命令注入
- (B) 跨站脚本 (XSS)
- (C) 目录遍历
- (D) 跨站请求伪造 (CSRF)

解释 200. **正确答案：C. 目录遍历。**
目录遍历（也称为路径遍历）涉及操作引用带有“..”序列及其变体（如“..%2F..”）的文件的变量，这些序列 URL 解码后为“../”，以便导航到意图目录之外。这可以允许攻击者访问 Web 服务器上的受限文件。Sarah 在日志中观察到的模式表明存在一次目录遍历攻击尝试。

选项 A 错误。命令注入攻击涉及通过应用程序漏洞在服务器上执行任意命令。日志中观察到的特定模式并不暗示命令执行。

选项 B 错误。跨站脚本 (XSS) 攻击涉及向其他用户查看的网页中注入恶意脚本。观察到的模式与脚本注入无关。

选项 D 错误。跨站请求伪造 (CSRF) 欺骗受害者提交恶意请求。它不涉及场景中描述的目录或路径操作。

## 201. 安全分析师在检查网络日志时注意到，位于用户和目标网站之间的攻击者正在拦截并可能在将用户的通信传递到目标地之前对其修改。这种恶意活动透明地发生，用户和目标网站都无法察觉。描述的是哪种类型的网络攻击？

- (A) 重放攻击
- (B) 烟雾鱼攻击 (Smurf Attack)
- (C) 路径攻击 (On-path Attack)
- (D) 欺骗攻击 (Spoofing Attack)

解释 201. **正确答案：C. 路径攻击。** 路径攻击，也称为中间人攻击 (MitM)，涉及在将通信传递到目标地之前拦截并可能对其修改。这种恶意活动透明地发生，用户和目标网站都无法察觉。

选项 A 错误。重放攻击涉及捕获数据并在以后重新传输。

选项 B 错误。烟雾鱼攻击是一种拒绝服务攻击，使用 ICMP (ping) 流量淹没目标系统。

选项 D 错误。欺骗攻击涉及伪装成其他东西。

问题 202. 一家金融公司将其支付处理外包给第三方服务商。在系列欺诈交易后，发现该服务商在传输数据时没有使用最新的加密标准。此场景突出了哪种与供应链漏洞？

- (A) 供应商背景检查不足
- (B) 服务提供商过时的安全实践
- (C) 供应商提供的硬件组件缺陷
- (D) 嵌入后门的软件

解释 202. **正确答案：B. 服务提供商的安全实践。** 供应链漏洞包含源自第三方供应商和服务提供商的风险。在这种场景中，第三方服务商未能为传输数据时使用当前的加密标准，说明了由于过时的安全实践而产生的漏洞。

选项 A 错误。虽然供应商背景检查至关重要，但场景并没有专门指向供应商背景的问题。

选项 C 错误。场景没有提到硬件组件或任何与之相关的问题。

选项 D 错误。这里的问题涉及加密标准，而不是带有后门的软件。

问题 203. 网络安全师 Julia 注意到公司工作站上安装了一个名为“PhotoEditorPro.exe”的应用程序。经过进一步检查，她发现该程序正在静地将公司敏感数据外泄到外部 IP 地址。Julia 最可能观察到的是哪种恶意软件？

- (A) 蠕虫
- (B) 勒索软件
- (C) 木马
- (D) 广告软件

解释 203. **正确答案：C. 木马。** 木马是一种把自己伪装成合法软件或应用程序的恶意软件。与病毒不同，木马不会自我复制，但如果不加防，它们的破坏性可能同样甚至更大。在这种情况下，“PhotoEditorPro.exe”看起来是一个合法的照片编辑程序，但实际上被用于将敏感数据传输到外部源。

选项 A 错误。蠕虫是通过自我复制传播到其他设备的恶意软件程序。它们不会伪装成合法的应用程序。

选项 B 错误。勒索软件加密受害者的数据并索赎金以解密。它不会伪装成合法软件。
