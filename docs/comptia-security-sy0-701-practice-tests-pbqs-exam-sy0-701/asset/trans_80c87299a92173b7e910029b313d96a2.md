选项 D 错误。GDPR（通用数据保护条例）是一项要求企业保护欧盟公民个人数据和隐私的法规。它并没有提供安全系统配置的基准。

问题 371。ZenTech 是一家跨国公司，最近采纳了多云策略，在多个云服务提供商处部署了工作负载。这种方法的主要安全益处是什么？

- (A) 所有云资源的集中化管理
- (B) 云与云之间传输数据的自动加密
- (C) 缓解单点故障风险
- (D) 降低云存储解决方案的成本

解析 371. 正确答案：C。缓解单点故障风险。使用多云策略将工作负载分布在不同的云提供商处，这降低了与任何单一提供商停机或安全泄露相关的风险。这种多样化确保了某个云环境的故障或受损不会危及整个基础设施。

选项 A 错误。由于需要与不同的平台和提供商对接，多云策略有时会增加管理的复杂性。在这种背景下，集中化并不是主要益处。

选项 B 错误。虽然加密至关重要，但采用多云方法并不会自动加密不同云环境之间传输的数据。这需要特定的配置和解决方案。

选项 D 错误。虽然成本优化可以是采用多云策略的因素之一，但主要的安全优势与降低成本无关。

问题 372。某公司想要托管一个面向公众的网站，但要确保如果网站被攻破，攻击者无法访问敏感的内部数据。以下哪种是实现这一目标的最佳配置？

- (A) 将 Web 服务器放置在内部网络并严格监控流量
- (B) 将 Web 服务器放置在 DMZ（非军事区），在其前面设置一个防火墙，并在 DMZ 和内部网络之间设置另一个防火墙
- (C) 直接将 Web 服务器连接到互联网而不使用防火墙，并将敏感数据移出服务器
- (D) 将 Web 服务器放置在 DMZ 中并直接连接到内部网络而不使用防火墙

解析 372. 正确答案：B。将 Web 服务器放置在 DMZ 中，在其前面设置一个防火墙，并在 DMZ 和内部网络之间设置另一个防火墙。通过将 Web 服务器放置在 DMZ 中，并有两个防火墙（一个面向互联网，另一个面向内部网络），公司可以确保即使面向公众的 Web 服务器被攻破，攻击者仍需绕过另一个防火才能到达内部网络。

选项 A 错误。将面向公众的 Web 服务器放置在内部网络（即使有监控）也会让网络暴露于不必要的风险之中。

选项 C 错误。在没有任何形式防火墙的情况下将服务器直接连接到互联网是非常危险的，即使移动了敏感数据。

选项 D 错误。如果 DMZ 和内部网络之间没有防火墙，DMZ 中受损的服务器将更容易影响或访问内部网络。

问题 373。TechFirm Inc. 从其用户处收集个人数据，并决定了处理这些数据的目的和手段。他们还将数据存储外包给第三方公司 CloudData。在数据隐私法规的背景下，TechFirm 和 CloudData 分别应如何归类？

- (A) TechFirm：处理者 (Processor）；CloudData：控制者 (Controller)
- (B) TechFirm：控制者 (Controller）；CloudData：处理者 (Processor)
- (C) TechFirm 和 CloudData 均为处理者 (Processors)
- (D) TechFirm 和 CloudData 均为控制者 (Controllers)

解析 373. 正确答案：B。TechFirm：控制者 (Controller）；CloudData：处理者 (Processor)。TechFirm Inc. 决定了处理个人数据的目的和手段，是“控制者”。CloudData 负责代表 TechFirm 处理数据（但不决定其用途），是“处理者”。

选项 A 错误。此选项中的角色反反了。TechFirm 是决策的一方。

选项 C 错误。两者的角色不同。TechFirm 决定数据使用，因此它是控制者。

选项 D 错误。CloudData 只是代表 TechFirm 进行处理，它是处理者。

问题 374。Globex Corp 的 IT 部门担心员工在远程办公时，访问恶意网站的情况在增加。他们希望确保在设备外部时网络策略依然有效。哪种方案是解决此问题的最佳？

- (A) 实现云端过滤解决方案
- (B) 使用 VPN 强制所有流量通过内部网络
- (C) 在所有笔记本电脑上部署基于代理的过滤器
- (D) 定期向员工发送关于网站使用的提醒

解析 374. 正确答案：C。在所有笔记本电脑上部署基于代理的过滤器。基于代理的过滤器可以确保无论设备在内部网络内外，都能执行策略。

选项 A 错误。虽然云端解决方案可以提供外部过滤，但可能不如直接在设备上实施的方案一致。

选项 B 错误。使用 VPN 会强制所有流量通过内部网络，可能会导致延迟且在某些场景下不可行。

选项 D 错误。发送提醒是一种被动的方法，可能无法阻止访问恶意网站。

问题 375。SoftTech Solutions 是一家软件开发公司，决定对其新的 Web 应用进行渗透测试。测试人员获得了用户凭据、网络拓扑图和一些专利代码片段。SoftTech Solutions 采用的是哪种渗透测试？

- (A) 黑盒测试 (Black box testing)
- (B) 双盲测试 (Double-blind testing)
- (C) 已知环境测试 (Known environment testing)
- (D) 知识测试 (Zero-knowledge testing)

解析 375. 正确答案：C。已知环境测试。已知环境测试是渗透测试的一种，测试人员获得了有关目标环境某些信息。这包括用户凭据、网络图等，以模拟内部威胁或获取了某些内部信息的攻击者。

选项 A 错误。在黑盒测试中，测试人员对系统没有先知。

选项 B 错误。在双盲测试中，攻击者和防御者对即将到来的测试均不知情。

选项 D 错误。知识测试是黑盒测试的另一种说法，测试人员对系统内部一无所知。
