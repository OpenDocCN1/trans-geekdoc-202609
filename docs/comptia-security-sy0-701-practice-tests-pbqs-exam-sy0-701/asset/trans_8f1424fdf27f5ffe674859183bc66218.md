**问题 361。** XYZ 公司正在设计其新的 Web 应用程序基础设施。他们希望确保进入和离开应用程序的所有网络流量都经过加密。除了选择 HTTPS 作为协议外，他们应该为加密流量配置哪个默认端口？

- (A) 21
- (B) 80
- (C) 443
- (D) 25

**解析 361.** **正确答案：C. 443。** 端口 443 是用于 HTTPS（基于 SSL/TLS 的 HTTP）流量的默认端口。它确保 Web 流量经过加密，并在客户端和服务器之间提供安全的通信通道。

**选项 A 错误。** 端口 21 是 FTP（文件传输协议）的默认端口，用于传输文件，而不是加密 Web 流量。

**选项 B 错误。** 端口 80 是 HTTP 的默认端口，它是未加密的。

**选项 D 错误。** 端口 25 是 SMTP（简单邮件传输协议）的默认端口，用于邮件传输，而不是加密 Web 流量。

**问题 362。** TechWorld 公司担心网络罪分子发送伪装来自其域名的电子邮件来欺骗其客户。公司希望实施一种解决方案，允许接收邮件服务器能够验证声称来自 TechWorld 公司域名的电子邮件确实源自已批准的服务器。该公司应该实施以下哪项？

- (A) SMTP 身份验证
- (B) DKIM
- (C) 带有 SSL 的 POP3
- (D) S/MIME

**解析 362. 正确答案：B. DKIM。** 域名密钥识别邮件（DomainKeys Identified Mail, DKIM）是一种用于验证邮件来源和完整性的方法。通过 DKIM，可以在发送邮件的标头中添加数字签名。接收邮件服务器随后使用该签名，通过与发送域的公密钥进行比对来验证邮件，该公密钥发布在 DNS 记录中。

**选项 A 错误。** SMTP 身份验证确保用户在通过服务器发送电子邮件之前提供有效的凭据，但它不会向接收方验证发送者的域名。

**选项 C 错误。** 带有 SSL（安全套接层）的 POP3 是关于安全地从服务器检索电子邮件消息的。它没有提供验证发送者域名的方法。

**选项 D 错误。** S/MIME（安全/多用途互联网邮件扩展）用于加密和签名邮件消息。虽然它确保了邮件内容的完整性和机密性，但它并不会向收件人验证发送者的域名。

**问题 363。** 在一次安全事件发生后，法医调查显示一个受攻击的内部工作站正与已知的恶意 IP 地址通信。为了防止进一步通信，安全团队决定采取采取行动。以下哪项是确保工作站无法与该 IP 通信的**最佳**即时行动？

- (A) 在 Web 过滤器上针对该 IP 地址实施拦截规则
- (B) 禁用受攻击工作站的网络端口
- (C) 使用蜜罐引流恶意流量
- (D) 更新防火墙的固件

**解析 363.** **正确答案：A. 在 Web 过滤器上针对该 IP 地址实施拦截规则。** 通过在 Web 过滤器上专门针对已知的恶意 IP 地址实施拦截规则，任何与该 IP 通信的尝试都将被停止，有效地防止进一步的恶意通信。

**选项 B 错误。** 禁用受攻击工作站的网络端口会将机器断网，但如果端口被重新启用，它无法专门阻止与恶意 IP 的通信。

**选项 C 错误。** 虽然蜜罐可以用于引流或研究攻击者的行为，但它们不是阻止与已知恶意 IP 地址通信的最直接方法。

**选项 D 错误。** 更新防火墙固件是一项通用的维护任务，并没有专门解决阻止与已知恶意 IP 通信的问题。

**问题 364。** 网络管理员 Amy 正在研究相关工具，以协助对其组织系统相对于特定安全基准进行自动化评估。她发现了 SCAP 并想要实施它。以下哪项**最准确**描述了安全内容自动化协议（SCAP）的主要功能？

- (A) 促进威胁情报馈的实时传输
- (B) 提供针对 Active Directory 进行用户身份验证的接口
- (C) 允许自动化的漏洞管理和策略合规性评估
- (D) 为远程系统管理提供加密通信通道

**解析 364. 正确答案：C. 允许自动化的漏洞管理和策略合规性评估。** SCAP（安全内容自动化协议）是一套开放标准，增强了组织在系统上实现自动化漏洞管理、测量和策略合规性评估的能力。

**选项 A 错误。** 虽然威胁情报对于安全至关重要，但 SCAP 的设计目的主要不是实时威胁情报馈的传输。

**选项 B 错误。** SCAP 不直接处理任何目录服务的用户身份验证。

**选项 D 错误。** SCAP 的主要功能不是为远程系统管理提供加密通信通道。其他协议和工具具有此功能。

**问题 365。** 一家制药公司正在研发一种新药方，有望彻底改变某种疾病的治疗。研发团队拥有关于药物试验成分、程序和结果的详细文档。应该如何对这些文档进行分类，以确保只有公司内部的人员可以访问？

- (A) 实施域名系统 (DNS) 防墙
- (B) 使用 URL 识别并拦截恶意 URL
- (C) 依靠员工对可疑 URL 的手动报告
- (D) 使用虚拟网络 (VPN) 定向员工网络流量

**解析 365. 正确答案：B. 使用 URL 识别并拦截恶意 URL。** URL 扫描可以通过检查完整 URL 并与已知恶意 URL 或模式进行对比来识别潜在的恶意网站。这种方法可以拦截设计与合法站点相似的 URL。

选项 A 错误。虽然 DNS 防火墙可以帮助拦截恶意域名，但 URL 扫描提供了更细粒度的控制。

选项 C 错误。仅仅依靠员工的手动报告可能不如自动化的 URL 扫描解决方案那样高效或有效。这还会给员工带来识别和报告每个恶意 URL 的额外负担。

选项 D 错误。使用 VPN 只是更改流量的路由并提供加密通信。它本身并不提供 URL 扫描或过滤功能。

**问题 366。** 一家金融机构希望确保对客户数据的非法访问都会触发安全团队的立即警报。以下哪些方法对于实现这一要求**最有效**？
