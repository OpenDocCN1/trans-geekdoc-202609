**问题 111.** TechHive Corp. 计划出售其部分旧服务器。在出售之前，他们希望确保硬盘上不再留可检索的个人或业务数据。TechHive 应该使用以下哪种方法来确保硬盘已干净且数据无法被恢复？

- (A) 简单格式化 (Simple Format)
- (B) 磁性擦除 (Magnetic Wiping)
- (C) 物理破坏 (Physical Destruction)
- (D) 标准碎片整理 (Standard Defragmentation)

**解析 111.** **正确答案：B. 磁性擦除。** 磁性擦除也称为消磁，利用磁场永久擦除存储设备上的数据。它使数据无法检索，确保即使使用先进工具也无法恢复个人和业务数据。

**选项 A 错误。** 简单格式化通常会留下数据痕迹，可以使用专门的软件进行恢复。

**选项 C 错误。** 虽然物理破坏可以确保数据无法被检索，但它会使服务器无法用于转售。

**选项 D 错误。** 碎片整理是优化和组织驱动器上数据的过程，但它不会删除数据。

## **问题 112.** 一家金融机构报告说，他们平均每年遭受 3 次试图破解其用户数据的钓鱼攻击。根据这些数据，这些钓鱼攻击的年发生率 (ARO) 是多少？

- (A) 0.33
- (B) 1
- (C) 3
- (D) 12

解析 112. 正确答案：C. 3。年发生率 (ARO) 代表特定事件或风险每年发生的预期频率。鉴于该金融机构每年遭受 3 次钓鱼攻击，因此 ARO 为 3。

**选项 A 错误。** ARO 为 0.33 表明该事件大约每三年发生一次，而不是一年发生三次。

**选项 B 错误。** ARO 为 1 意味着该事件每年发生一次，这与场景描述不符。

**选项 D 错误。** 这表示该事件每年发生 12 次，或者每月发生一次。
