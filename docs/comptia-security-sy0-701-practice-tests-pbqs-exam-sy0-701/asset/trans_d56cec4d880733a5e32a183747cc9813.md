
一系列渗透测试。将渗透测试作为威胁识别方法的**主要**原因哪哪？

- (A) 确保符合合规性要求
- (B) 验证安全意识培训的有效性
- (C) 积极利用漏洞并评估潜在影响
- (D) 识别 SIEM 系统中的配置错误

**解释 235.** **正确答案：积极利用漏洞并评估潜在影响。** 渗透测试是一种用于积极利用环境中漏洞的方法。其首要目的是确定这些漏洞在现实场景中的潜在影响和风险，从而让组织能够理解并确定补救措施工作的优先顺序。

**选项 A 错误。** 虽然某些法规可能要求进行渗透测试，但测试的主要目标不仅仅是为了合规性，而是为了理解漏洞的潜在影响。

**选项 B 错误。** 虽然渗透测试有时可以用于衡量安全培训的有效性（例如，在社交工程测试中），但这不是进行这些测试的主要原因。

**选项 D 错误。** SIEM 系统用于日志记录和事件管理。虽然渗透测试可能会发现各种系统中的配置错误，但其主要目的并不是聚焦于 SIEM。

问题 236。Globex Industries 正在多个地理位置扩展数据中心。IT 团队希望有一个中心化系统，以获取所有数据中心基础设施的实时状态、中断和指标。以下哪种解决方案对此目的最有效？

- (A) 数据泄露防护 (DLP) 工具
- (B) 分布式拒绝服务 (DDoS) 保护
- (C) 安全信息和事件管理 (SIEM)
- (D) 基础设施管理平台 (IMP)

解释 236. **正确答案：D. 基础设施管理平台 (IMP)。** IMP 为多个地的基础设施提供中心化的控制和监控。它们提供有关基础设施健康、中断和指标的洞察，确保 IT 团队能够及时处理问题。

选项 A 错误。DLP 工具侧重于防止未经的传输和外泄，而不是监控基础设施的健康和状态。

选项 B 错误。DDoS 保护工具防御拒绝服务攻击，但设计目的并非监控数据中心基础设施的整体健康或指标。

选项 C 错误。虽然 SIEM 解决方案汇总了数据并提供了安全事件的洞察，但它们的主要设计目的不是为了监控多个位置的数据中心基础设施健康。

问题 237。在经历重大基础设施升级后，GlobalMed Corp 经历了几个未预料的安全问题。回想起来，IT 经理意识到他们跳过了变更管理中的一个关键步骤，该步骤本预测并缓解这些问题。他们最可能忽略了哪一步？

- (A) 采购新硬件
- (B) 对 IT 人进行新系统培训
- (C) 影响分析
- (D) 与旧系统的集成

**解释 237.** **正确答案：C. 影响分析。** 影响分析在变更过程中至关重要，因为它评估了拟议变化的潜在后果。通过进行这种分析，组织可以预测潜在的安全挑战并在实施变更之前缓解它们。

**选项 A 错误。** 虽然采购至关重要，但仅仅购买新硬件并不能直接预测或缓解源于基础设施升级的潜在安全问题。

**选项 B 错误。** 培训 IT 人对于有效实施和运行至关重要，但无法直接解决预测和理解升级带来的潜在安全后果。

**选项 D 错误。** 与旧系统的集成是一个关键考量，特别是兼容性方面。然而，场景的重点是预测和理解潜在的安全问题，这主要通过影响分析来解决。

问题 238。Sarah 是某科技公司的软件开发人员，她决定获得公司配移动设备的 root 权限以自定义其功能。不久后，IT 部门检测到她的设备有未经授权的数据传输。哪种移动漏洞最可能与其行为相关？

- (A) 应用程序侧载
- (B) 不一致的 OS 更新
- (C) 移动设备越狱 (Jailbreaking)
- (D) 使用开放 Wi-Fi 网络

解释 238. 正确答案：C. 移动设备越狱。越狱是移除制造商对某些设备实施限制的过程，从而允许获取 root 权限。有了 root 权限，用户可以安装和自定义未经设备制造商或运营商批准的软件。然而，越狱可能会使设备暴露于各种安全漏洞之中，如未经授权的数据传输所示。

选项 A 错误。侧载是指从官方应用商店的其他源安装应用程序。虽然侧载会带来安全风险，但 Sarah 的行为专门与获取 root 权限有关，这指向了越狱。

选项 B 错误。不一致的 OS 更新是指不同设备上存在多个版本的操作系统。Sarah 的行为与获取 root 权限有关，而不是不一致的更新。

**选项 D 错误。** 使用开放 Wi-Fi 网络可能会让移动设备面临威胁，但 Sarah 的漏洞源于获取 root 权限，而不是她对 Wi-Fi 网络的选择。

问题 239。Jenna 是一家增长在线零售业务的网络管理员，正在为公司域名获取 SSL 证书。公司为不同的服务使用多个子域名，例如 shop.example.com、blog.example.com 和 support.example.com。Jenna 不想为每个子域名单独获取，而是想使用一个证书。Jenna 应该申请哪种类型的证书？

- (A) 扩展验证证书 (EV)
- (B) 通配证书 (Wildcard)
- (C) 带有主体备名称 (SAN) 的证书
- (D) 代码签名证书

解释 239. **正确答案：B. 通配证书。** 通配证书旨在保护具有相同顶级域名的域名及其子域名。例如，针对 *.example.com 的通配证书将保护 shop.example.com、blog.example.com 以及 example.com 的任何其他子域名。

选项 A 错误。扩展验证证书提供了最高级别的验证，但并不一定默认覆盖子域名。

选项 C 错误。虽然带有主体备名称 (SAN) 的证书可以保护多个域名和子域名，但它不像通配证书那样专门为单个域名下的所有子域名定制。

选项 D 错误。代码签名证书用于对软件代码进行签名以确保其完整性和真实性，而不是用于保护域名或子域名。

问题 240。CyberLock Inc. 正在评估其第三方供应商的安全态势以确定潜在风险。安全团队希望从每个供应商处收集基础安全信息，以评估他们的安全成熟度和实践。从大量供应商处收集这些数据成本效益且高效的方法是什么？

- (A) 为每个供应商进行渗透测试
- (B) 向每个供应商发送安全问卷
- (C) 访问每个供应商现场进行现场评估
- (D) 审查每个供应商的年度财务报告

解释 240. 正确答案：B. 向每个供应商发送安全问卷。安全问卷通常用于从第三方供应商收集基础安全信息。它们具有成本效益，并且高效地从大量供应商处收集标准化数据，以评估其安全态势和实践。

选项 A 错误。为每个供应商进行渗透测试会耗费资源、成本高昂，并且可能无法提供有关供应商安全实践的基础信息。
