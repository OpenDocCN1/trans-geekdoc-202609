What should be the classification of this user manual?

+   (A) Confidential
(B) Restricted
(C) Public
(D) Internal

**Explanation 289.** **Correct Answer: C. Public.** A user manual is intended for all users of the software and should be easily accessible. It doesn’t contain sensitive or proprietary information about the software’s underlying code or algorithms. Hence, it should be classified as “Public.”

**Option A** is incorrect. “Confidential” classification is too restrictive for a document meant to be distributed with every software code and to guide users.

**Option B** is incorrect. “Restricted” would limit the distribution of the manual unnecessarily, making it harder for users to access the information they need.

**Option D** is incorrect. “Internal” classification would suggest the manual is only for internal company use, whereas it’s intended for all users of the software.
