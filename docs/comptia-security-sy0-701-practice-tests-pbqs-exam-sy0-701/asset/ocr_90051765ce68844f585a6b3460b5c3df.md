**Option A is incorrect.** While political activists might expose vulnerabilities in sectors like healthcare, they generally do so to raise awareness rather than for personal financial gain.

**Option D is incorrect.** The attackers’ actions did not revolve around spreading malware or increasing a botnet’s size rather focused on individual extortion based on exfiltrated data.
