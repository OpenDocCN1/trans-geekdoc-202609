**问题 410。** 在最近一次安全事件后，网络安全分析师 Sarah 想要分析网络流量的流数据以识别模式和潜在威胁。她想收集有关 IP 流量流的元数据，并收集 IP 地址、端口和使用的协议等细节。Sarah 应该使用什么工具来获取这些信息？

- (A) 入侵检测系统 (IDS)

- (B) Syslog 服务器

- (C) NetFlow 收集器

- (D) 简单网络管理协议 (SNMP) 陷阱

**解释 410. 正确答案：C. NetFlow 收集器。**

NetFlow 是 Cisco 开发的一种网络协议，用于收集 IP 流量信息和监控网络流量。NetFlow 收集器可以提供对流量模式和容量的洞察，符合 Sarah 的需求。

**选项 A 错误。** 虽然 IDS 可以根据特定的特征或启发式方法提供恶意活动的警报，但它不提供像 NetFlow 那样的详细流数据分析。

**选项 B 错误。** Syslog 服务器主要用于收集和存储来自各种设备的日志数据。它不关注详细的网络流量流分析。

**选项 D 错误。** SNMP 陷阱用于从设备向管理站发送有关特定事件的非请示式警报消息。它们不提供流量流分析。

**问题 411。** 一名安全分析师被委托调查一起可能的数据泄露。在查看网络日志时，分析师注意到在非工作时间内，发往未知 IP 地址的出站流量异常增加。该流量似乎是加密的，并与一个包含敏感数据的已知服务器相关。以下哪种是对此行为**最可能**的解释？

- (A) 服务器正在下载补丁

- (B) 员工正在远程访问服务器

- (C) 正在执行服务器备份
- (D) 正在发生数据泄露

**解释 411.** **正确答案：D. 正在发生数据泄露。** 鉴于流量是加密的、与敏感服务器相关，并且在非工作时间内发送到未知 IP，最可能的情况是未经授权的数据正被传出网络，这被称为数据泄露。

**选项 A 错误。** 虽然服务器会下载补丁，但这些通常是来自已知更新源的入站流量，而不是发往未知 IP 的出站流量。

**选项 B 错误。** 虽然员工可能会远程访问服务器，但流量被加密并在非工作时间内发送到未知 IP 使得这种情况的可能性较低。

**选项 C 错误。** 备份通常不会导致向未知 IP 地址产生加密出站流量，特别是在非工作时间。

**问题 412。** ExamsDigest Enterprises 想要简化其权限分配。他们决定与其逐个地为每个用户分配权限，不如根据部门角色对用户进行分组，然后向这些组分配权限。例如，所有“营销”角色的成员都可以访问营销数据库。ExamsDigest Enterprises 正在采用哪种访问控制方法？

- (A) 基于规则的访问控制
- (B) 强制访问控制 (MAC)
- (C) 任意性访问控制 (DAC)
- (D) 基于角色的访问控制 (RBAC)

**解释 412. 正确答案：D. 基于角色的访问控制 (RBAC)。** RBAC 涉及根据角色（在这种情况下是如“营销”之类的部门）对用户进行分组，然后向这些角色分配权限。然后将个人放入这些角色中，从而决定他们的权限。ExamsDigest Enterprises 描述的场景是实施 RBAC 的典型示例。

**选项 A 错误。** 基于规则的访问控制通常处理访问的预定义规则，常用于防火墙或路由器，而不是基于角色对用户进行分组。

**选项 B 错误。** MAC 更多是关于信息分类以及让具有相应许可级别的用户进行访问。它不涉及此类场景中的部门角色。

**选项 C 错误。** DAC 允许资源所有者授予或拒绝权限。它本身并不涉及基于角色或工作职能分配权限。

**问题 413。** BetaTech 正在为其数据中心的技术人员实施一种新的身份验证机制。技术人员现在不再使用门卡，而是查看一个设备，该设备通过映射特定模式来验证他们的身份。以下哪种是 BetaTech 可能正在实施的

- (A) 密码系统
- (B) 视网膜扫描

- (C) 硬件令牌
- (D) 基于知识的问题

**解释 413. 正确答案：B. 视网膜扫描。**视网膜扫描是一种生物识别方法，通过分析个人视网膜的独特模式来验证其身份。它属于“你本身”因素。

**选项 A 错误。** 密码系统属于“你所知的”因素，因为用户需要记住密码。

**选项 C 错误。** 硬件令牌代表“你拥有的”因素，因为它是用户需要持有的设备。

**选项 D 错误。** 基于知识的问题（例如“你第一只宠物的名字是什么？”）属于“你所知的”因素。

**问题 414。** 一家全球金融公司其基础设施遭遇间发性的网络攻击。公司注意到，在非工作时间发生的攻击由于响应延迟通常会导致更严重的损害。以下哪种措施**最好**能缩短对这些攻击的响应时间？

(A) 培训安全人员在工作时间内处理更大规模的事件

(B) 实施自动化入侵检测和响应系统

(C) 在非工作时间增加安全人员

(D) 检测到攻击时向安全人员发送电子邮件通知

**解释 414. 正确答案：B. 实施自动化入侵检测和响应系统。**通过实施自动化入侵检测和响应系统，公司可以确保无论何时发生都能得到实时检测和响应。与人工干预相比，这大大缩短了响应时间。

**选项 A 错误。** 培训员工在工作时间处理更多事件无法解决非工作时间响应延迟的问题。

**选项 C 错误。** 在非工作时间增加人员可能有所帮助，但可能不如自动化高效或成本效益，且仍然存在人为延迟的可能性。

**选项 D 错误。** 发送电子邮件通知可能导致延迟，特别是如果人员在非工作时间内没有及时查看邮件。
