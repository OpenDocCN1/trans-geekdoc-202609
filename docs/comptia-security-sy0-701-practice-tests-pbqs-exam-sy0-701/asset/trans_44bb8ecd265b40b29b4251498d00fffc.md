

问题 71. 一家电子商务公司正在准备即将到来的黑色五促销活动，预计网络流量将出现激增。为了确保系统在促销期间保持响应能力，以下哪种策略是**最有效**的？

- (A) 增加用户的密码复杂度
- (B) 限制销售商品数量
- (C) 实施内容分发网络 (CDN)
- (D) 进行年度安全审计

解析 71. 正确答案：C。实施内容分发网络 (CDN)。CDN 将负载分布在多个服务器之间，这些服务器通常在地理上是分散的。这不仅加快了向用户交付内容的速度，还有助于处理流量洪峰，确保系统在黑色五促销等高需求期间保持响应。

选项 A 错误。增加密码复杂度可以增强安全性，但不会直接影响高流量期间的系统响应能力。

选项 B 错误。限制销售商品数量可能会减少服务器负载，但也可能减少潜在收入，且不是提高系统响应能力的直接方法。

选项 D 错误。虽然年度安全审计对于识别漏洞至关重要，但它们无法直接解决高流量期间的系统响应问题。

问题 72. Alice 想访问一个受限的在线门户。
该门户要求她输入一个唯一的用户名和一个只有她才知道的秘密口令。这个过程有助于系统确保 Alice 就是她所声称的人。该门户正在采用什么安全概念？

- (A) 授权 (Authorization)
- (B) 审计 (Accounting)
- (C) 多因素认证 (Multifactor authentication)
- (D) 身份验证 (Authentication)

解析 72. 正确答案：D。身份验证。

身份验证验证用户、系统或应用程序身份的过程。在描述的场景中，Alice 通过提供唯一的用户名和口令向系统证明她的身份，这些凭据理上只有她拥有。

选项 A 错误。授权决定了经过验证的身份允许访问或执行的操作、资源或服务。它不涉及身份本身的验证。

选项 B 错误。审计涉及跟踪用户活动并记录以供审计。它不直接验证用户的身份。

选项 C 错误。多因素身份验证需要来自不同类别凭据的两种或更多验证方法。场景中只提到了用户名和口令，这是一种单因素身份验证方法。

问题 73. 在一次例行检查中，IT 部门发现几位员工在午休期间离开电脑且无人看管。哪种运营安全控制可以帮助缓解此类行为相关的风险？

- (A) 实施生物识别认证
- (B) 强制严格的密码策略
- (C) 设置在空闲一段时间后自动锁屏
- (D) 实施安全编码实践

解析 73. 正确答案：C。在空闲一段时间后自动锁屏。在空闲一段时间后部署自动锁屏是一种运营控制。它确保无人看管的设备免受未经授权的访问，从而缓解与员工离开电脑且无人看管相关的风险。

选项 A 错误。实施生物识别认证是一种技术控制。虽然它增强了访问点的安全性，但它不能确保无人看管设备上的活动会话免受未经授权访问的影响。

选项 B 错误。强制严格的密码策略是一种管理控制，规定了强密码的创建和使用。虽然它增强了访问安全性，但不能保护无人看管设备上的活动会话。

选项 D 错误。实施安全编码实践是一种技术控制，有时也是管理控制。它确保编写软件时防止漏洞，但不能直接解决电脑无人看管的风险。

问题 74. 一家零售公司最近遭受了泄露，攻击者加密了所有的销售点系统（POS），导致其无法使用。随后收到一份勒索信，要求使用加密货币支付费用以解密系统。这次攻击背后最明显的动机是什么？

- (A) 抗议公司的环保政策
- (B) 通过赎金获取财务利益
- (C) 间谍活动以了解公司的供应链
- (D) 通过展示技术技能来提升声誉

解析 74. 正确答案：B。通过赎金获取财务利益。攻击者加密了关键系统并索要赎金以解密。此类勒索软件攻击的首要动机是迫使受害者付费以重新获得系统的访问权限，从而获取财务利益。

选项 A 错误。没有提到或指示攻击者的动机是公司的环保政策或任何其他政策。

选项 C 错误。没有证据表明攻击者对供应链感兴趣。

选项 D 错误。虽然展示技术技能可能是副作用，但直接的付款要求表明其目的是获取财务利益。

问题 75. 为了尽可能减少由于恶意软件导致的数据泄露，公司正在决定一种防止恶意软件的控制措施。以下哪种是**最佳**的预防性控制？

- (A) 部署网络入侵系统 (NIDS)
- (B) 定期备份关键数据
- (C) 安装具有实时扫描功能的防病毒软件
- (D) 在事件后进行取证分析

解析 75. 正确答案：C。双因素认证。双因素认证 (2FA) 是一种安全过程，用户提供两个不同的因素来验证其身份。在场景中，Bob 提供了他所知道的（用户名和密码），并回答了一个安全问题，这是另一种“他所知道的东西”的形式。

选项 A 错误。生物识别认证涉及个人的独特物理或行为特征，如指纹或面部特征。场景中没有提到任何生物识别数据。

选项 B 错误。基于令牌的认证通常涉及使用生成时间敏感代码的硬件或软件令牌。场景中并未描述此类内容。

选项 D 错误。单点登录 (SSO) 允许用户登录一次即可访问多个系统，而无需在每个系统都反复提示登录。场景描述的是双因素认证过程，而不是 SSO。

问题 76. 在最近一次服务中断后，一家医院的 IT 团队正在审查其患者记录系统的可用性。他们希望确保系统在发生硬件故障时仍能运行。以下哪些考虑因素与此要求**最相关**？

- (A) 实施数据库镜像 (Database mirroring)
- (B) 定期更新系统的防病毒定义
- (C) 对静态数据使用强力加密
- (D) 对系统进行渗透测试

解析 76. 正确答案：A。实施数据库镜像。数据库镜像是提高 SQL Server 数据库可用性的解决方案。镜像是按数据库实施的，并且仅适用于使用完整恢复模式的数据库。这确保了在发生硬件故障时，有一个镜像数据副本可用。

选项 B 错误。虽然更新防病毒定义对于防止恶意软件感染至关重要，但它与确保硬件故障面前的高可用性没有直接关系。

选项 C 错误。加密对于数据安全至关重要，但不直接解决系统的高可用需求。

选项 D 错误。渗透测试识别系统中的漏洞，但无法为硬件故障提供高可用性解决方案。
