问题 288。GlobalTech 正在实施灾难恢复计划，并确保持续可用且无数据丢失。他们决定使用复制作为备份策略。为了实现目标，GlobalTech 实施哪种复制技术？

- (A) 每天调度一次的定期复制
- (B) 每小时同步一次的异步复制
- (C) 同步复制
- (D) 每 30 分钟一次快照复制

解析 288。正确答案：C. 同步复制。同步复制确保数据同时写入主位置和备用位置，确保无数据丢失且持续可用。这种方法符合 GlobalTech 无数据丢失的要求。

选项 A 错误。每天调度一次的定期复制可能在发生灾难时导致多达一天的数据丢失。

选项 B 错误。每小时同步一次的异步复制可能在同步发生之前发生事故时导致一小时的数据丢失。

选项 D 错误。每 30 分钟一次快照复制可能在发生事故时导致 30 分钟的数据丢失。

问题 289。一家软件公司开发了一个新产品。他们想发布一份用户手册，详细说明如何使用该软件、其功能以及基础故障排除步骤。

该用户手册的分类应该是？

- (A) 机密 (Confidential)
- (B) 限制 (Restricted)
- (C) 公开 (Public)
- (D) 内部 (Internal)

解析 289。正确答案：C. 公开。用户手册适用于所有软件用户并应易于访问。它不包含软件底层代码或算法的敏感或专利信息。因此，它应该分类为“公开”。

选项 A 错误。“机密”分类对于旨在随每份软件代码分发并引导用户的文档来说过于严格了。

选项 B 错误。“限制”分类会不必要地限制手册的分发，使用户获取所需信息变得更加困难。

选项 D 错误。“内部”分类将表明手册仅供公司内部使用，而它是为所有软件用户设计的。

问题 290。一家全球金融公司最近因其主运营区域发生意外灾难而面临停机。该公司希望有一个备份站点，允许他们以最小的停机时间和无数据丢失的情况下继续运营。哪种类型的备份站点对公司最合适？

- (A) 冷场 (Cold site)
- (B) 温场 (Warm site)
- (C) 热场 (Hot site)
- (D) 移动站点 (Mobile site)

解析 290。正确答案：C. 热场。热场是一个完全运行的异地数据中心，配置好并在灾难发生后立即继续运营。它拥有所有必要的设备和最新的数据备份，对于最小停机时间和无数据丢失的场景是理想选择。

选项 A 错误。冷场是具有空间和基础设施的备份设施，但没有更新的设备或数据。它需要时间来建立，不适用于立即恢复。

选项 B 错误。温场是冷场和热场之间的折中。它有一些设备和备份，但与热场相比，需要更多时间才能完全运行。

选项 D 错误。移动站点通常是便携式设置（通常在卡车上），可以部署到各种位置。它可能无法全球金融公司所需的大规模运营。

问题 291。一家国际银行正在为其客户建立一个新的在线门户，以便访问其财务报表。银行应该实施哪种措施来确保客户浏览器与银行服务器之间传输的财务数据保密？

- (A) 对所有财务报表使用文件级加密
- (B) 实现 Web 应用防火墙 (WAF)
- (C) 为门户使用安全套接层 (SSL) 或传输层安全 (TLS)
- (D) 将所有财务数据存储在加密数据库中

解析 291。正确答案：C. 为门户使用安全套接层 (SSL) 或传输层安全 (TLS)。SSL/TLS 用于保护传输数据。通过加密客户浏览器与银行服务器之间的数据，确保数据的机密性。

选项 A 错误。文件级加密保护静态数据，而不一定是传输中的数据。

选项 B 错误。虽然 Web 应用防火墙 (WAF) 可以防止攻击，但它不加密传输中的数据。

选项 D 错误。将数据存储在加密数据库中保护的是静态数据，而不是传输过程。

问题 292。一家全球电子商务网站希望允许其服务代表协助客户，而不暴露完整的信用卡号。IT 部门应该采用哪种方法来实现这一点？

- (A) 将所有数字替换为随机字符
- (B) 只显示后四位并掩蔽其余部分
- (C) 使用对称密钥加密信用卡号
- (D) 使用哈希函数表示信用卡号

解析 292。正确答案：B. 只显示后四位并掩蔽其余部分。显示后四位并掩蔽其余确保服务代表有足够的信息提供协助，而不暴露完整号码。

选项 A 错误。将所有数字替换为随机字符将使信息对服务代表毫无用。

选项 C 错误。加密数字保护了数据，但服务代表需要解密的方法才能访问部分信息。

选项 D 错误。对数字进行哈希将无法查看原始数据的任何部分，在这种情况下是无效的。

问题 293。XYZ Corp 最近面临了勒索软件攻击，关键数据文件被加密。该公司的 IT 团队无法解密文件，但有一份最近的备份。然而，当他们尝试恢复数据时，发现备份已损坏。以下哪种最佳实践可以帮助 XYZ Corp 确保备份的完整性？

- (A) 定期测试备份恢复过程
- (B) 将备份存储在与原始文件相同的目录
- (C) 将备份频率增加到每小时一次
- (D) 使用强加密算法加密备份

解析 293。正确答案：A. 定期测试备份恢复过程。通过定期测试从备份恢复的过程，组织可以在关键恢复需要之前识别并纠正备份文件或过程的任何问题。

选项 B 错误。将备份存储在与原始文件相同的目录中增加了原始文件和备份文件同时受到破坏或损坏的风险。

选项 C 错误。虽然增加备份频率可以减少数据丢失，但它没有解决备份本身的完整性或有效性。

选项 D 错误。虽然加密备份提供了防止未经授权访问的安全性，但它不能确保备份的完整性或可用。
