## 问题 263. 一家软件开发公司正寻求将其旧应用程序迁移到更现代的基础设施。他们希望确保应用程序能够在多个环境中一致地部署，而不会面临依赖项和配置不同的挑战。哪种方法最能实现这一目标？

- (A) 虚拟机部署
- (B) 裸机部署
- (C) 容器化
- (D) 无服务器计算

## 解析 263. 正确答案：C. 容器化

容器化将应用程序及其依赖项封装在一个“容器”中。这允许应用程序无论配置或依赖项如何变化，都能在不同的环境中一致地部署。

选项 A 是错误的。虽然虚拟机为应用程序提供了隔离环境，但它们包含了整个客机操作系统的开销，并且没有直接解决应用程序依赖项在不同环境中变化的挑战。

选项 B 是错误的。裸机部署涉及直接在硬件上安装应用程序，而不使用虚拟化或容器。这种方法从本质上并不能保证跨多个环境的一致性部署。

选项 D 是错误的。无服务器计算将基础设施从开发者手中抽象出来，专注于单个函数。虽然它提供了可扩展性和简单性，但由于依赖项和配置，它无法直接解决跨环境的一致部署。

## 问题 264. 一家大型企业正在考虑转向更灵活、可编程的网络架构。他们希望将控制平面集中，允许自动化、可编程的网络配置和快速置备。他们应该考虑哪种网络架构模型？

- (A) VLAN（虚拟局域网）
- (B) MPLS（多协议标签交换）
- (C) VPN（虚拟专用网络）
- (D) SDN（软件定义网络）

## 解析 264. 正确答案：D. SDN（软件定义网络）。软件定义网络（SDN）将控制平面集中，将其与数据平面解耦。这允许实现更加灵活和可编程的网络，实现自动化配置和快速置备。

选项 A 是错误的。VLAN 用于在物理网络内部创建逻辑网络，但它无法提供跨整个网络的集中化控制或可编程性。

选项 B 是错误的。MPLS 是一种用于高性能电信网络的数据承载技术。它不会像 SDN 那样集中化网络控制或增强可编程性。

选项 C 是错误的。VPN 设计用于在通过互联网等可能不安全的介质时，在网络之间提供安全隧道。它不提供 SDN 那种集中化的、可编程的配置优势。

## 问题 265. 一家全球性公司在过去一年中发生了多次 IT 事件，包括由于自然灾害和网络攻击导致的停机。CEO 希望确保组织的 IT 基础设施能够承受或从破坏性事件中快速恢复。以下哪项涵盖了这一需求？

- (A) 采用零信任架构
- (B) 实施严格的密码策略
- (C) 建立强调韧性的业务连续计划 (BCP)
- (D) 定期更新防火墙规则

## 解析 265. 正确答案：C. 建立强调韧性的业务连续计划 (BCP)。

在此语境下，韧性是指 IT 基础设施在破坏性事件后快速恢复并继续运行的能力。关注韧性的业务连续计划将帮助组织应对并从自然和人为发生的事件中恢复。

选项 A 是错误的。零信任架构强调不对任何用户或系统建立信任，但不是针对破坏性事件的恢复计划。

选项 B 是错误的。虽然密码策略对于安全性至关重要，但它们不是为了应对破坏性事件。

选项 D 是错误的。更新防火墙规则对于阻止意外流量和潜在威胁至关重要。

## 问题 266. 一家医疗公司最近部署了一台设备，用于实时监测心率。该设备使用实时操作系统 (RTOS) 以保证响应时间。安全团队对潜在风险表示关注。以下哪项是增强设备安全的建议？

- (A) 确保实时数据分析能力
- (B) 将设备与云端集成以备份
- (C) 为设备实施严格的网络隔离
- (D) 增加设备的存储容量

## 解析 266. 正确答案：C. 为设备实施严格的网络隔离。为了保护优先考虑性能的 RTOS 设备，减少其暴露至关重要。通过分段网络，可以将设备与其他系统隔离并降低风险。

选项 A 是错误的。实时数据分析更多是关于性能而非安全性。

选项 B 是错误的。如果云环境未妥加密，可能会引入更多安全问题。

选项 D 是错误的。存储容量是设备功能问题，不是 RTOS 设备的安全增强。

## 问题 267. 一家小型企业希望部署一种单一网络安全设备，能够处理防火墙保护、入侵检测、防病毒和内容过滤等多种功能。以下哪项是最合适的解决方案？

- (A) 网络入侵检测系统 (NIDS)
- (B) Web 应用防火墙 (WAF)
- (C) 统一威胁管理 (UTM)
- (D) 代理服务器

## 解析 267. 正确答案：C. 统一威胁管理 (UTM)。统一威胁管理 (UTM) 设备旨在将多种安全功能整合到一个设备中。这对于需要全面的安全功能但可能没有资源部署和管理多个独立设备的小组织是理想的。

选项 A 是错误的。虽然 NIDS 可以识别并通知潜在恶意活动，但它没有提供 UTM 那种多功能能力。

选项 B 是错误的。Web 应用防火墙 (WAF) 专门保护 Web 应用程序免 XSS 和 SQL 注入等类型的攻击。它不包含 UTM 更广泛的安全功能。

选项 D 是错误的。代理服务器主要控制互联网访问并可能提供一些缓存和内容过滤功能，但它无法提供 UTM 那种广泛的安全功能。
