
选项 B 错误。启用所有功能可能会引入不必要的漏洞。最好是仅启用所需的功能以维护安全性。

选项 C 错误。虽然备份对于数据完整性和恢复至关重要，但 RTOS（特别是在自动汽车中）的主要关注点应该是实时性能和减少潜在漏洞。

问题 83。在最近发生一起蓄意破坏事件后，某公司办公大楼正考虑实施安全控制以威慑潜在的犯罪者。以下哪项最适合作为威慑性控制措施？

- (A) 加密所有存储的数据
- (B) 在所有入口处安装生物识别访问控制
- (C) 实施定期数据备份
- (D) 放置显示 24/7 监控的可见安全告示

解释 83. 正确答案：D。放置显示 24/7 监控的可见安全告示。可见的安全告示作为一种威慑性控制措施，因为它通过发出被检测风险和后果的信号来阻止潜在的犯罪者，即使实际监控可能并不处于激活状态。

选项 A 错误。加密所有存储的数据是一种预防性控制，确保未经授权的人员无法访问或理解加密信息。它不能威慑物理破坏行为。

选项 B 错误。安装生物识别访问控制是一种预防性控制，它根据独特的生物属性限制物理访问。虽然它防止了未经授权的访问，但它不能作为对破坏行为或其他潜在威胁的可见威慑措施。

选项 C 错误。实施定期数据备份是一种纠正性控制，旨在发生安全事件后恢复数据。它不能威慑潜在的威胁。

问题 84。某全球性公司的财务部门发现系列源自员工工作站的未经授权交易。调查显示，该员工一直在绕过公司政策，使用公司资金进行未经授权的投资。根据行为者的属性，该威胁行为者应如何归类？

- (A) 利用恶意软件的外部人员
- (B)  de漏洞的外部人员
- (C) 具有直接访问权限的内部人员
- (D) 具有间接访问权限的内部人员

解释 84. 正确答案：C。具有直接访问权限的内部人员。威胁源于组织内部员工的工作站，因此是内部威胁。由于该员工使用自己的工作站和凭据进行未经授权的交易，他们拥有直接访问权限，因此将其归类为具有直接访问权限的内部人员。

选项 A 错误。场景中没有提到使用恶意软件，且未经授权的交易来自员工的工作站，表明是内部威胁而非外部威胁。

选项 B 错误。该场景没有描述外部人员利用漏洞。相反，它描述的是员工在组织内部进行未经授权的交易。

选项 D 错误。该场景中的员工由于使用了自己的工作站和凭据，因此对公司资源具有直接访问权限。因此，他们不被归类为具有间接访问权限。

问题 85。在经历一系列网络攻击后，金融机构 BetaTech 决定对其整个服务器群的配置进行标准化。他们已经为服务器建立了一个安全基准配置。确保服务器符合这一新基准的**下一步**应该是什么？

- (A) 频繁地对所有服务器进行漏洞扫描
- (B) 为服务器访问引入生物识别身份认证
- (C) 在所有服务器上部署安全基准配置
- (D) 监控网络流量以检测异常

解释 85. 正确答案：C。在所有服务器上部署安全基准配置。在建立基准后，接下来的直接步骤是将该基准部署或应用到服务器。这确保了所有服务器都从标准化且安全的配置开始。

选项 A 错误。虽然漏洞扫描至关重要，但它更多是一个识别潜在漏洞的持续过程，而不是直接将安全基准应用到服务器上。

选项 B 错误。生物识别认证虽然是一项价值的安全措施，但并没有解决在服务器上部署已建立的安全基准的问题。

选项 D 错误。监控网络流量对于检测潜在威胁至关重要，但它不能直接确保在服务器上部署安全基准。

问题 86。ClearView Industries 希望让员工能够灵活地选择自己的设备进行工作，同时保留对设备配置和应用程序的控制。哪种部署模型最符合 ClearView 的目标？

- (A) 自带设备 (BYOD)
- (B) 自选设备 (CYOD)
- (C) 公司所有、个人备用 (COPE)
- (D) 固定设备部署 (FDD)

解释 86. 正确答案：B。自选设备 (CYOD)。在 CYOD 模型中，允许员工从经过批准的设备列表中选择设备。组织保留对设备配置和应用程序的控制，确保了用户偏好与公司安全的平衡。

选项 A 错误。BYOD 允许员工携带个人设备到公司工作，这意味着组织对配置和应用程序的控制较少。

选项 C 错误。虽然 COPE 提供了公司所有的设备并允许个人使用，但它并不一定赋予员工选择获取哪种设备的权利。

选项 D 错误。固定设备部署 (FDD) 在移动解决方案语境下不是标准的部署模型，而且无法反映设备选择的灵活性。

问题 87。XYZ 公司使用 MDM 管理公司所有和员工拥有的移动设备。一名员工报告在周末丢失了个人手机。IT 部门应该使用哪种 MDM 功能来确保手机上的敏感公司数据不被访问？

- (A) 监控设备位置
- (B) 强制更新设备应用程序
- (C) 远程擦除设备
- (D) 修改用户邮箱密码

解释 87. 正确答案：C。远程擦除设备。通过远程擦除功能，IT 部门可以清除丢失设备上的所有数据（包括公司数据），确保敏感信息不会落入他人手中。

选项 A 错误。监控设备位置可能有助于找到设备，但不能防止对设备上数据的未经访问。

选项 B 错误。强制更新设备应用程序可能会解决应用程序中的漏洞，但不能直接保护设备上的公司数据。

选项 D 错误。修改用户邮箱密码可以防止对用户邮箱的未经访问，但无法保护设备上可能存在的其他敏感公司数据。

问题 88。在一次大型体育赛事期间，某广播公司的流媒体服务因流量激增离线。攻击持续了整个赛事，并在赛事结束后消失。这次攻击背后最可能的动机是什么？

- (A) 拦截敏感通信的间谍活动
- (B) 在体育赛事期间导致服务中断
- (C) 为了未来的勒索要求进行数据提取
- (D) 获取未经授权的访问权限并植入恶意软件

解释 88. 正确答案：B。在体育赛事期间导致服务中断。流量激增专门与体育赛事相匹配，并在赛事结束后停止，表明其意图是在体育赛事期间中断服务。

选项 A 错误。场景中没有迹象表明攻击者对拦截通信感兴趣，特别是目标是广播公司而非外交或政府机构。
