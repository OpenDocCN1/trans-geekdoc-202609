**第 451 题。** GlobalTech 正在实施一项灾难恢复计划，并希望确保持续可用性且不丢失数据。他们决定使用复制作为备份策略。为了实现这一目标，GlobalTech 应该实施以下哪种复制技术？

- (A) 每天安排一次的周期性复制
- (B) 每小时同步一次的异步复制
- (C) 同步复制
- (D) 每 30 分钟进行一次快照复制

**解析 451.** **正确答案：C. 同步复制。** 同步复制确保数据同时写入主位置和备位置，确保数据不丢失并实现持续可用性。这种方法符合 GlobalTech 不丢失数据的要求。

**选项 A 错误。** 每天安排一次的周期性复制在灾难发生时可能导致高达一天的数据丢失。

**选项 B 错误。** 每小时同步一次的异步复制在同步之前发生事故时，可能会导致一小时的数据丢失。

**选项 D 错误。** 每 30 分钟进行一次的快照复制在发生事故时可能导致 30 分钟的数据丢失。

**第 452 题。** 一个电子商务网站突然流量激增，导致网站运行变慢并偶尔无法访问。IT 团队观察到大量请求来自分布在不同国家的多个 IP 地址。该电子商务网站可能正在经历哪种网络攻击？

- (A) 中间人攻击
- (B) DNS 欺骗
- (C) 分布式拒绝服务 (DDoS) 攻击
- (D) ARP 污染

**解析 452.** 正确答案：C 分 分式拒绝服务 (DDoS) 攻击。在 DDoS 攻击中，攻击者使用多个系统（通常是来自不同位置的受损系统）向目标系统发送大量请求，导致目标系统变慢或无法访问。

**选项 A 错误。** 中间人攻击涉及攻击者秘密截获并可能修改双方之间的通信。它不会导致因高流量引起的网站无法访问。

**选项 B 错误。** DNS 欺骗是攻击者引入损坏的 DNS 缓存信息，以将流量重定向到不同的 IP 地址（通常由攻击者控制）。它不会导致来自不同国家的流量增加。

**选项 D 错误。** ARP 污染是攻击者通过向局域网发送伪造的 ARP 消息采用的技术。这通常用于将攻击者的 MAC 地址与另一个主机的 IP 地址绑定，导致任何指向该 IP 地址的流量都被发送给攻击者。

**第 453 题。** 一家软件开发公司正在开发一个移动银行应用程序。他们希望确保加密过程和生物识别数据验证等敏感操作与主操作系统隔离开，以防止潜在的篡改。为了实现这一目标，他们应该使用哪种技术？

- (A) 硬件安全模块 (HSM)
- (B) 密钥管理系统 (KMS)
- (C) 隔离环境
- (D) 可信平台模块 (TPM)

**解析 453.** **正确答案：C. 隔离环境。** 隔离环境可以将敏感操作与主操作系统隔离开，防止潜在的篡改。

**选项 A 错误。** 硬件安全模块 (HSM) 主要用于加密密钥的处理，而非隔离应用级操作。

**选项 B 错误。** 密钥管理系统 (KMS) 用于管理密钥生命周期。

**选项 D 错误。** 可信平台模块 (TPM) 主要提供硬件支持的安全基础功能，并非用于隔离特定的应用程序操作。

**第 454 题。** 一个流行的社交媒体平台希望确保用户登录的真实性，防止账户被篡改。为了实现这一目标，平台应该使用以下哪种方法？

- (A) 使用私钥对进行加密
- (B) 使用哈希值（Hash）进行用户身份验证
- (C) 实现单点登录 (SSO)
- (D) 仅依赖 CAPTCHA 验证

**解析 454.** 正确答案：C. 实现单点登录 (SSO)。** 单点登录可以确保用户在多个关联系统中的身份一致，并能简化身份验证流程。

**选项 A 错误。** 使用私钥对进行加密通常用于数字签名，而非验证用户身份真实性。

**选项 B 错误。** 哈希值可以用于验证数据完整性，但不能直接作为验证用户身份真实性的主要方法。

**选项 D 错误。** 仅依赖 CAPTCHA 只能区分人类和机器人，无法确保账户登录的真实性。

**第 455 题。** 一家公司注意到最近一个月恶意软件感染有所增加。调查后，确定这些感染是由于访问新注册的网站引起的。为了缓解这一威胁，应该采取何种措施？

- (A) 实施阻止所有网站的规则
- (B) 使用包含域名注册检查的网络过滤器
- (C) 将过滤器设置为阻止“业务”类网站
- (D) 强制执行多因素身份验证

**解析 455.** **正确答案：B. 使用包含域名注册检查的网络过滤器。** 基于信誉的网络过滤器可以评估域名的可信度，因为攻击者经常利用新域名进行钓鱼或传播恶意软件。

**选项 A 错误。** 阻止所有网站会严重影响业务运营和效率。

**选项 C 错误。** 简单阻止“业务”类网站无法针对新注册域名的威胁。

**选项 D 错误。** 强制执行多因素身份验证可以保护账户，但无法防止访问恶意网站导致的感染。
