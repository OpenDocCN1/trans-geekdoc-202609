Question 514. In preparation for an upcoming audit, AlphaTech Corporation hires a team to evaluate their security measures. The team is spotted attempting to bypass security barriers, unlock doors without keys, and trying to access restricted floors by pretending to be maintenance staff. What type of testing is AlphaTech Corporation undergoing?

+   (A) Network vulnerability scanning
(B) Physical penetration testing
(C) OS fingerprinting
(D) Source code review

Explanation 514. Correct Answer: B. Physical penetration testing. Physical penetration testing involves hands-on techniques to breach physical barriers, such as locks, checkpoints, or restricted areas, to assess the efficacy of physical security controls.

Option A is incorrect. Network vulnerability scanning is about identifying vulnerabilities in networked systems through automated tools, not physical barriers.

Option C is incorrect. OS fingerprinting identifies the operating system of a remote computer. It doesn’t involve physically trying to access restricted areas.

Option D is incorrect. Source code review evaluates the source code of applications for vulnerabilities and doesn’t concern physical access controls.
