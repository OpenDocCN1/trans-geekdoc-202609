问题 30. 一家公司位于易发生地震和洪水等自然灾害的地区。以下哪种物理安全控制措施对于确保公司 IT 基础设施的安全**最有效**？

- (A) 对服务器访问使用生物识别身份验证
- (B) 部署防火墙以防止网络威胁
- (C) 在数据中心建立架空地板系统
- (D) 定期进行渗透测试

解析 30. 正确答案：C。在数据中心建立架空地板系统。数据中心的架空地板系统通过将设备抬离地面作为一种物理控制手段，有助于其免受洪水时可能遭受的水水损害，并对其他环境风险提供某些保护。

选项 A 错误。使用生物识别身份验证是一种技术控制，通过根据物理或行为属性确认用户身份来增强安全性。虽然它加强了访问安全，但它不能提供针对自然灾害的保护。

选项 B 错误。部署防火墙是一种技术控制，用于防止对或来自私有网络的未经授权访问。虽然它可以防止网络威胁，但它不能提供针对自然灾害等物理威胁的保护。

**选项 D 错误。** 进行渗透测试是一种技术有时是运营控制，用于识别组织数字资产中的漏洞。虽然它增强了网络安全，但它不能保护基础设施免受物理威胁。

问题 31. TechBank 刚刚在市中心开了一家新分行。由于位置原因，管理层担心设施可能受到车辆攻击。TechBank 可以采用以下哪种物理安全措施来**专门威慑**此类攻击？

- (A) 监控摄像头
- (B) 护柱 (Bollards)
- (C) 访问门卡
- (D) 安保人员

解析 31. 正确答案：B. 护柱。护柱是短而坚固的垂直柱，通常用于控制道路交通。在物理安全背景下，它们的作用是防止车辆进入不允许进入的区域，作为对潜在车辆攻击的威慑。

选项 A 错误。虽然监控摄像头可以监控和记录活动，但它们不能作为防止车辆攻击的物理屏障。

选项 C 错误。访问门卡控制人员对设施的访问，但不能威慑车辆攻击。

选项 D 错误。虽然安保人员可以响应威胁并控制访问，但它们不是像护柱那样的威慑车辆攻击的特定措施。

问题 32. 在安全评估期间，安全顾问 Maria 发现客户的面向外部 Web 服务器上使用了自签名证书。与此发现相关的**首要**安全关注点是什么？

- (A) Web 服务器可能受到分布式拒绝服务 (DDoS) 攻击
- (B) 证书可能已经过期
- (C) 用户无法轻易验证网站的真实性
- (D) Web 服务器可能不支持现代加密算法

解析 32. 正确答案：C。用户无法轻易验证网站的真实性。自签名证书不是由受认可的证书颁发机构签名的。因此，当用户使用自签名证书连接到网站时，通常会收到证书不受信任的警告。这构成了风险，因为用户无法轻易验证网站的真实性，使他们更容易受到中间人攻击。

选项 A 错误。虽然 DDoS 攻击是面向外部 Web 服务器需要关注的问题，但它们与自签名证书的使用没有直接关系。

选项 B 错误。任何证书（无论是自签名还是 CA 签名）都可能过期。然而，过期并不是面向外部服务器使用自签名证书的要要关注点。

选项 D 错误。现代加密算法的使用与证书是否为自签名证书无关。

问题 33. TechFin Bank 正在考虑为他们的交易处理实施一个新的软件系统。在推出系统之前，网络安全团队坚持进行某种特定类型的分析，以理解此更改可能如何影响组织的安全态势。该团队指的是的是什么？

- (A) 风险偏好评估
- (B) 性能基准测试
- (C) 影响分析
- (D) 渗透测试

解析 33. 正确答案：影响分析。影响分析评估了组织内更改可能带来的后果。在 TechFin Bank 的情况下，网络安全团队将使用这种分析来理解新软件系统可能会引入新的漏洞、影响现有的安全措施或以其他方式影响银行的整体安全性。

选项 A 错误。风险偏好评估是指确定组织在追求目标时愿意接受的风险数量和类型。它并不关注特定更改的后果。

选项 B 错误。性能基准侧重于将组织的性能指标与行业标准或最佳实践进行比较，而不是评估更改的潜在安全影响。

选项 D 错误。虽然渗透测试对于评估系统中的漏洞至关重要，但它无法提供更改对组织安全态势可能产生影响的全局视图。

问题 34. 为了震慑针对其在线商店的潜在网络罪分子，一家电子商务公司正在考虑各种安全措施。以下哪种措施将**最有效**地作为威慑控制措施？

- (A) 在网站上显示第三方安全认证的标志
- (B) 使用 Web 应用防火墙 (WAF)
- (C) 每月进行漏洞评估
- (D) 将客户数据存储在加密数据库中

解析 34. 正确答案：A。在网站上显示第三方安全认证标志。在网站上显示第三方安全认证标志作为威慑控制措施。它向潜在攻击者传递了一个信息，即该网站的安全措施得到了认可，从而阻止他们尝试攻击。

选项 B 错误。使用 Web 应用防火墙 (WAF) 是一种预防控制。它可以过滤、监控并拦截恶意 Web 流量。虽然有助于防御网络威胁，但它不能作为攻击者的可见威慑。

选项 C 错误。每月进行漏洞评估是一种检测控制。它通过识别漏洞来增强安全态势，但不能作为对攻击者的威慑。

选项 D 错误。将客户数据存储在加密数据库中是一种预防控制，可确保未经授权的人员无法访问或理解存储的数据。它保护了数据，但不能威慑潜在的网络罪分子。

问题 35. 一家跨国公司的安全团队在全球部署了一个蜜阱网络，使其看起来是一个互联且真实的环境。他们的目的是研究多阶段攻击。这种欺骗性的设置被称为：

- (A) 防火墙集群
- (B) 虚拟局域网 (VLAN)
- (C) 分布式拒绝服务 (DDoS) 防止
- (D) 蜜阱网 (Honeynet)

解析 35. 正确答案：D. 蜜阱网。蜜阱网实际上是由蜜阱组成的网络。它的设计目的是对攻击者产生吸引力，让他们认为自己正在攻击真实的网络，而实际上他们正在被观察，其战术和技术正在被分析。
