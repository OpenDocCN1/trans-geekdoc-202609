Question 228. In a microservices architecture, each service should be designed with a specific principle to ensure it performs a specific task and interacts with other services through well-defined interfaces. What principle is this referring to?

+   (A) Principle of Least Privilege

+   (B) Single Responsibility Principle

+   (C) Open-Closed Principle

+   (D) Zero Trust Model

Explanation 228. Correct Answer: B. Single Responsibility Principle. The Single Responsibility Principle dictates that a class or module (or in the context of microservices, a service) should have only one reason to change, meaning it should only have one job or responsibility. In microservices, this ensures that each service does one thing and does it well, and interacts with others through clear interfaces.
