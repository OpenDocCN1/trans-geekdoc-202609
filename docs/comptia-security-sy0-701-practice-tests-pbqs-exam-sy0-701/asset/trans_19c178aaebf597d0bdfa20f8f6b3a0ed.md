Question 426. 一家公司计划升级邮件服务器，以确保服务器与客户端之间的邮件传输是加密的。以下协议中哪种最符合这一目的？

- (A) HTTP
- (B) FTP
- (C) IMAP over SSL/TLS
- (D) SNMP

Explanation 426. Correct Answer: C. IMAP over SSL/TLS.IMAP over SSL/TLS（通常被称为 IMAPS）是客户端通过安全通道从服务器检索消息的协议。SSL/TLS 的使用确保了传输数据的机密性。

Option A is incorrect. HTTP 是用于传输网页内容的协议，默认不提供加密。此外，它不是为邮件传输设计的。

Option B is incorrect. FTP 是用于传输文件的协议，不提供安全的邮件传输能力。

Option C is incorrect. SNMP（简单网络管理协议）用于网络管理和监控，不用于邮件传输。

Question 427. 一家中型公司刚为 HR 部门部署了一个文件服务器。他们希望只有 HR 员工可以查看和编辑 HR 相关文档，而 IT 部门只能执行维护任务。为了实现这一需求，公司应该实施？

- (A) 在 HR 和 IT 部门之间安装防火墙
- (B) 为服务器实施访问控制列表 (ACL)
- (C) 为 HR 部门执行强密码策略
- (D) 在服务器上启用全盘加密

Explanation 427. Correct Answer: B. 为服务器实施访问控制列表 (ACL)。访问控制列表 (ACL) 定义了谁可以访问资源以及访问后可以对其做什么。通过为服务器设置 ACL，公司可以精确定义 HR 和 IT 部门的权限，确保只有授权用户拥有正确的数据访问级别。

Option A is incorrect. 安装防火墙会限制部门间的流量，但无法对服务器上的文件提供细粒度的访问控制。

Option C is incorrect. 虽然强密码策略对于安全至关重要，但它无法区分 HR 和 IT，也无法控制用户访问服务器后的操作。

Option D is incorrect. 全盘加密保护静态数据，但无法根据用户角色提供特定文件或目录的差异化访问。

Question 428. 安全分析师 Carla 收到警报，公司的一个服务器证书可能在最近的数据泄露中暴露。为了确保泄露的证书不被恶意使用，Carla 应该采取的最直接的操作是什么？

- (A) 向 CA 请求新证书
- (B) 更新公司的防火墙规则
- (C) 将证书添加到吊销列表 (CRL)
- (D) 对服务器进行漏洞扫描

Explanation 428. Correct Answer: C. 将证书添加到吊销列表 (CRL)。如果认为证书已损坏，最直接的操作是撤销它。这是通过将证书添加到吊销列表 (CRL) 实现的。在建立安全通信之前检查 CRL 的系统和应用程序将不再信任该受影响的证书。

Option A is incorrect. 虽然在撤销损坏证书后可能需要请求新证书，但立即的操作应该是撤销可能受影响的证书。

Option B is incorrect. 更新防火墙规则对许多安全场景至关重要，但无法直接解决可能泄露证书的滥用问题。

Option D is incorrect. 漏洞扫描是识别系统弱点的更广泛的操作。虽然很有价值，但它无法直接解决证书损坏的问题。

Question 429. 金融分析公司 DataFin 在其一个服务器机房发生了轻微火灾。幸运的是，他们他们在建筑的另一个侧翼存储了备份，允许快速恢复数据。然而，管理层意识到，在发生重大灾难时，主数据和备份数据都可能被毁。为了解决这个问题，DataFin 应该考虑哪种备份策略？

- (A) 镜像备份
- (B) 本地存储备份
- (C) 增量备份
- (D) 离地备份

Explanation 429. Correct Answer: D. 离地备份。离地备份涉及将备份位于不同的地理位置，确保即使灾难影响了主位置，备份也是安全的。

Option A is incorrect. 镜像备份是对数据的精确副本，不指定地理位置。

Option B is incorrect. 本地存储通常意味着备份存储在同一区域或附近，这无法解决重大灾难带来的担忧。

Option C is incorrect. 增量备份仅备份自上次备份以来变化的数据，无论存储何处。

Question 430. 一家在线零售商正在考虑多种方法来保护其客户的信用卡信息。他们不在数据库中存储真实的信用卡，而是选择了一种将数字替换为无关随机值的方案。这种方法是什么？

- (A) 对称加密
- (B) 数字水印
- (C) 哈希
- (D) 令牌化

Explanation 430. Correct Answer: D. 令牌化。令牌化是将敏感数据替换为非敏感替代品的方法，称为“令牌”。这些令牌作为原始数据的引用，但不包含敏感数据，使其成为零售环境中保护信用卡信息的首选方法。

Option A is incorrect. 对称加密使用单一密钥进行加密和解密的方法。它将原始数据转换为加密格式，但不像令牌化那样将其替换为随机值。

Option B is incorrect. 数字水印将数据嵌入数字信号中，主要用于权利或所有权，而不是将敏感数据替换为随机值。

Option C is incorrect. 哈希将输入数据转换为固定长度的字符串，通常是哈希码。它产生的不是引用原始数据的随机值。

Question 431. TechnoCorp 的 IT 团队注意到上周的一种持续模式：特定服务器的 CPU 使用率在凌晨 2 点到 4 点之间飙升至 100%，而此时通常用户活动极少。这种现象最可能的原因是什么？

- (A) 服务器正在自动更新软件
- (B) 一名员工正在运行计算密集任务
- (C) 服务器正在遭受 DDoS 攻击
- (D) 恶意软件正在执行加密货币活动

Explanation 431. Correct Answer: D. 恶意软件正在执行加密货币活动。加密货币恶意软件通常会导致大量的资源消耗，特别是 CPU 使用率。攻击者经常将此类活动安排在非高峰时间，以减少被发现的概率。考虑到非高峰时期持续的高 CPU 使用率，加密货币挖掘是一个可能的原因。

Option A is incorrect. 虽然软件更新可能会导致资源消耗，但通常不会导致持续几天的持续性 100% CPU 使用率。
