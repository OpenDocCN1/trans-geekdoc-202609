第 25 题。医疗科技公司 MedGuard 开发了一款人工智能驱动的软件，可根据患者数据预测潜在的健康风险。在美国市场推出之前，以下哪项行业外部考虑应该是该公司的首要关注点？

- (A) 与美国流行的健身追踪应用集成
- (B) 确保符合《健康保险流通与责任法案》(HIPAA)
- (C) 调查美国医生对软件界面的偏好意见
- (D) 与美国制药公司合作进行促销交易

**解释 25. 正确答案为：B. 确保符合《健康保险流通与责任法案》(HIPAA)。** HIPAA 是一项美国法律，旨在提供隐私标准以保护患者的医疗记录和其他健康信息。对于处理患者数据的 MedGuard 来说，在美国市场推出软件之前，确保 HIPAA 合规性至关重要。

**选项 A 错误。** 虽然与健身追踪应用集成可能会增强软件的功能，但在美国处理患者数据时，首要考虑的是符合 HIPAA 合规性。

**选项 C 错误。** 尽管医生的反馈可能有助于改进软件的用户界面，但首要的行业外部考虑应该是监管合规性，特别是在处理敏感健康信息时。

**选项 D 错误。** 虽然与制药公司的合作可能对营销或业务增长有益，但对于处理患者数据的医疗科技公司来说，首要的行业考虑是确保符合相关法规。

第 26 题。一家电子商务公司遭受了分布式拒绝服务 (DDoS) 攻击，导致其网站无法访问了几个小时。为了在未来减轻此类攻击的影响，实施以下哪项是**最佳**的纠正控制？

- (A) 在网站上显示第三方安全认证印章
- (B) 建立具有 DDoS 防护的 Web 应用防火墙 (WAF)
- (C) 对网站进行例行漏洞评估
- (D) 为网站管理员实施强密码策略

**解释 26. 正确答案为：B. 建立具有 DDoS 防护的 Web 应用防火墙 (WAF)。** 具有 DDoS 防护的 Web 应用防火墙 (WAF) 可以识别并过滤与 DDoS 攻击相关的恶意流量。作为一种纠正控制，它可以帮助在攻击期间和之后减轻影响并恢复正常服务。

**选项 A 错误。** 在网站上显示第三方安全认证印章起到威慑作用，通过向访问者和潜在攻击者展示该网站遵循安全标准。然而，它不能减轻或纠正 DDoS 攻击的影响。

**选项 C 错误。** 进行例行漏洞评估是一种检测性控制，有助于识别漏洞。虽然它对整体安全至关重要，但它不能直接纠正或减轻 DDoS 攻击的影响。

**选项 D 错误。** 为网站管理员实施强密码策略是一种预防性控制。它确保了管理员账户的安全，但它不能解决或纠正 DDoS 攻击引起的问题。

第 27 题。某医疗机构在各种医疗设备中使用嵌入式系统。他们意识到如果这些系统没有得到妥善保护，可能会构成潜在威胁。在这种背景下，加固嵌入式系统时，以下哪项**不是**推荐的做法？

- (A) 定期对设备固件进行补丁和更新
- (B) 为了方便医疗人员使用允许对设备进行无限制访问
- (C) 禁用设备主要功能不需要的服务和特性
- (D) 修改默认凭据并使用强且唯一的密码进行设备访问

**解释 27. 正确答案为：B. 为了方便医疗人员使用允许对设备进行无限制访问。**

无限制的访问可能导致无意或故意的设备配置错误或误用，从而损害其安全性。

选项 A 错误。定期对固件进行补丁更新是维护嵌入式系统安全的关键方面，特别是考虑到威胁的不断演变特性。

选项 C 错误。禁用不需要的服务和功能可以减少攻击面，是系统加固的基本原则。

选项 D 错误。更改默认凭据并确保实施了强且唯一的设备访问密码，对于防止未经授权的访问至关重要。

第 28 题。一家金融机构希望确保客户了解银行关于信息共享的政策以及其个人数据如何使用。以下哪种安全控制**最好**向客户传达这些信息？

- (A) 为在线交易实施端到端加密
- (B) 在银行网站上发布隐私政策
- (C) 为员工进行年度网络安全意识培训
- (D) 在网上银行中使用多因素身份验证

**解释 28. 正确答案为：在银行网站上发布隐私政策。** 隐私政策充当了指令性控制，因为它告知客户银行在收集、使用和共享其个人数据方面的做法。通过阅读该政策，客户了解自己的权利和银行的责任。

**选项 A 错误。** 虽然端到端加密确保了在线交易的机密性，但它没有告知客户银行关于信息共享的政策或其数据如何使用。

**选项 C 错误。** 年度网络安全意识培训针对的是员工而非客户。它不会直接传达银行的信息共享政策。

**选项 D 错误。** 使用多因素身份验证通过要求多种形式的验证提高了网上银行的安全性。然而，它没有告知客户数据如何使用或银行的信息共享政策。
