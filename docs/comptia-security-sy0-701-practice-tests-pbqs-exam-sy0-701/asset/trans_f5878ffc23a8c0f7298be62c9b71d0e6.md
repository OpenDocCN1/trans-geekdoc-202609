问题 67。Sarah 正在参与一个项目，她需要在没有中心权威的情况下，验证资产随时间变化的完整性和真实性。哪种技术对于这种情况情况最合适？

- (A) 数字签名
- (B) 密钥托管
- (C) 区块链
- (D) 密钥管理系统

解释 67. 正确答案：C。区块链。区块链技术允许以去中心化的方式验证资产随时间变化的完整性和真实性。每笔交易或资产都由网络参与者验证并添加到链中，确保了其真实性并使其具有防篡改性。

选项 A 错误。虽然数字签名可以验证消息或文档的真实性和完整性，但它们无法提供资产随时间变化的去中心化账本。

选项 B 错误。密钥托管是一种将加密密钥托管给第三方的方法，以便其在特定条件下可以访问。它无法帮助在没有中心权威的情况下验证资产随时间变化的完整性和真实性。

选项 D 错误。密钥管理系统管理加密密钥的生命周期，但它本身并不验证资产随时间变化的完整性和真实性。

问题 68。一家图形设计公司经常处理视频和高分辨率图像等大文件。这些文件存储在他们服务器的专用存储卷上。虽然他们需要保护这些数据，但由于数据量巨大且访问频繁频繁，他们不想对单个文件进行加密。哪种加密方法最适用于这种场景？

- (A) 文件级加密
- (B) 全盘加密
- (C) 传输层加密
- (D) 卷级加密

解释 68. 正确答案：D。卷级加密。卷级加密允许对特定卷或逻辑驱动器进行加密。在这种情况下，它允许公司加密存储这些大文件的整个卷，而无需加密单个文件。这确保了整个卷的内容都被加密了，同时在需要时提供无缝访问。

**选项 A 错误。** 文件级加密虽然有效，但对许多大文件单独加密会非常繁琐。

**选项 B 错误。** 全盘加密会加密整个磁盘，如果只需要对特定卷进行加密，这可能是没有必要的。

**选项 C 错误。** 传输层加密涉及传输中的数据，不能解决在卷级别加密存储数据的需求。

问题 69。一家电子商务公司在其主数据库中存储了数百万条客户交易记录。他们决定通过应用加密来保护敏感数据以增强安全态势。然而，他们不想加密整个服务器存储，只需加密数据库内部的数据。公司应该采用哪种加密方法来实现其目标？

- (A) 全盘加密
- (B) 文件级加密
- (C) 卷级加密
- (D) 数据库级加密

解释 69. 正确答案：D。数据库级加密。数据库级加密专门为数据库内的数据提供加密。它确保数据在备份、复制或移动时仍然保持加密状态。这种方法对于电子商务公司来说是理想的，因为它专注于加密敏感的交易记录，而不影响服务器上的其他数据。

**选项 A 错误。** 全盘加密会加密整个服务器的存储，公司可能并不需要。

**选项 B 错误。** 文件级加密将需要加密单个文件，对于拥有数百万条记录的数据库来说，这可能效率低下。

**选项 C 错误。** 卷级加密加密的是特定的卷或逻辑驱动器，而不仅仅是数据库数据。

问题 70。您的组织计划升级系统。为了在升级期间保持可用性，以下哪些操作尤为关键？

- (A) 监控数据库的异常
- (B) 允许失败后重启
- (C) 对配置进行定期备份
- (D) 检查日志

解释 70. 正确答案：B。允许失败后重启。具有失败后重启机制可以确保如果在应用配置后出现任何问题，系统将尝试重启，从而确保对可用性的影响降到最小。

**选项 A 错误。** 监控数据库的异常是为了发现问题，而不是为了。

**选项 C 错误。** 定期备份是安全措施的一部分，但不能确保服务在升级后仍然可用。

**选项 D 错误。** 虽然对配置进行备份对于回滚至关重要，但它不能确保服务在重启后立即可用。

问题 71。一位记者想在照片中发送机密信息，而不引起怀疑。她采用的是哪种方法？

- (A) 数字签名
- (B) 隧道技术
- (C) 隐写术
- (D) 链

解释 71. 正确答案：C。隐写术。隐写术是将信息隐藏在其他数据中的技术。

选项 A 错误。数字签名用于验证消息或文档的真实性。它不会将信息隐藏。

选项 B 错误。隧道技术用于将一种协议封装在另一种协议中，通常用于 VPN 传输数据。

选项 D 错误。链在加密语文中通常指密码块链接模式（CBC）。它不涉及将数据隐藏。
