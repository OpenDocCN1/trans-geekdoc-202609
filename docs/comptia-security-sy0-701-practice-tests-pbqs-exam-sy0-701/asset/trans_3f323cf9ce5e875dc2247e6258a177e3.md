**问题 517。** 一家大型金融机构计划升级 IT 基础设施，以便更高效地利用硬件资源、更快地部署应用程序并缩短服务器配置时间。在评估不同技术时，以下哪项可以直接满足这些需求？

- (A) 网络分段
- (B) 入侵检测系统
- (C) 虚拟化
- (D) 多因素身份认证

**解析 517。** **正确答案：C. 虚拟化。** 虚拟化允许多个虚拟机运行在单个物理宿主机上，从而最大化地利用硬件资源。它能够实现对新服务器和应用程序的快速配置和部署，满足该金融机构的需求。

**选项 A 错误。** 网络分段将网络划分为较小的子网，主要出于安全和性能考虑。虽然这是一项最佳实践，但它无法解决硬件高效利用或应用程序快速部署的问题。



**选项 B 错误。** 入侵检测系统 (IDS) 负责监控并检测网络中的恶意活动。虽然它对安全至关重要，但它无法满足硬件资源效率或更快服务器配置的需求。

**选项 D 错误。** 多因素身份认证是一种安全过程，用户通过多种身份识别方法验证自己的身份。它不会影响硬件资源效率或应用程序部署时间。

**问题 518。** 一家跨国公司的安全团队在全球范围内部署了蜜罐网络，使其看起来像是一个互联且真实的环境。他们的目标是研究任何协调的多阶段攻击。这种欺骗性的设置被称为：

- (A) 防火墙集群
- (B) 虚拟局域网 (VLAN)
- (C) 分布式拒绝服务 (DDoS) 防止
- (D) 蜜罐网

**解析 518。** 正确答案：D. 蜜罐网。蜜罐网本质上是一个蜜罐网络。旨在对攻击者产生吸引力，让他们认为自己正在攻击真实网络，而实际上，他们正在被观察，其策略和技术正在被分析。

**选项 A 错误。** 防火墙集群是一组共同运行的防火墙，旨在提高可靠性和性能。它不作为吸引攻击者的诱饵。

**选项 B 错误。** 虚拟局域网 (VLAN) 是一种网络协议，用于在物理网络内部创建逻辑隔离的网络，以提高性能和安全性。它不是诱饵系统。

**选项 C 错误。** 分布式拒绝服务 (DDoS) 防止解决方案侧重于识别和缓解大规模破坏网络服务可用性的尝试。它们不会为攻击者提供欺骗性环境。

- (A) 语音诈骗 (Vishing)
- (B) 钓鱼攻击 (Phishing)
- (C) SQL 注入
- (D) 跨站请求伪造 (CSRF)

**解析 519。** 正确答案：A. 语音诈骗。语音诈骗或电话钓鱼是一种攻击手段，欺骗分子利用电话误导个人透露个人信息或登录凭据。

**选项 B 错误。** 钓鱼攻击通常试图通过欺骗性的电子邮件和网站获取敏感信息，而不是通过电话。

**选项 C 错误。** SQL 注入是一种试图在数据库中执行恶意 SQL 语句的攻击。它与电话通话无关。

**选项 D 错误。** 跨站请求伪造 (CSRF) 是一种攻击类型，攻击者诱骗受害者提交恶意请求。这与电话通话场景无关。

# 问题 520。Sophia 收到一封来自她银行的邮件，要求她由于系统升级紧急更新个人详情。邮件包含一个链接，点击后将重定向到一个与其银行网站相似的网站。她应该首先执行哪项操作？

- (A) 点击链接并及时更新她的个人详情，以避免任何不便
- (B) 将邮件转发给她的朋友和家人，确保他们也了解银行的系统升级
- (C) 立即删除邮件而不采取任何操作
- (D) 通过官方渠道联系她的银行，以验证邮件的真实性

**解析 520。** 正确答案：D. 通过官方渠道联系她的银行，以验证邮件的真实性。在根据未经要求的邮件采取行动之前（尤其是要求个人信息或凭据的邮件），直接向该邮件声称代表的机构或实体验证其合法性至关重要。

钓鱼攻击通常利用恐惧、紧急性或感知的权威来诱导受害者提供敏感数据。针对这些尝试的最佳防御是在采取行动之前独立地验证任何意外或可疑的请求。

**选项 A 错误。** 直接通过提供个人详情来响应潜在的钓鱼邮件是一个常见的错误，这使用户容易受到欺骗和身份盗窃的影响。

**选项 B 错误。** 向其他人转发可能带有恶意的邮件可能会进一步传播威胁，并可能损害他们的安全。

**选项 C 错误。** 虽然删除邮件可能防止 Sophia 掉入钓鱼陷阱，但告知银行这封可疑邮件仍然是一个好习惯，这样他们就可以采取适当措施并警告其他客户。

**问题 521。** Tech Enterprises 计划发布一款新产品。在产品创建过程中，他们从各个供应商采购了组件。安全团队的任务是评估与供应链相关的风险。在从多个供应商采购组件时，以下哪项是**最令人**的风险？

- (A) 难以从多个供应商处跟踪产品保修细节
- (B) 由于不同供应商交付时间不一导致产品组装时间增加
- (C) 引入不安全或被破坏组件的潜在风险
- (D) 需要多个采购订单，导致文书工作增加

**解析 521。** 正确答案：C. 引入不安全或被破坏组件的潜在风险。当从多个供应商采购组件时，一个或多个组件可能存在漏洞或被破坏的风险增加。

组件的完整性和安全性在开发过程中至关重要，特别是当这些组件来自多个供应商时。

**选项 A 错误。** 虽然跟踪保修是一个运营问题，但在从供应商采购时并不构成直接的安全风险。

**选项 B 错误。** 产品组装时间和供应商交付时间是物流和运营问题，不是供应链的首要风险。

**选项 D 错误。** 管理多个采购订单是一个业务流程挑战，不是主要关注点。

**问题 522。** 金融机构 ThetaTech 希望为其在线账户的高净客户升级身份验证系统。除了传统的密码，他们希望包含一种可以捕捉独特物理或行为特征的方法。ThetaTech 应该考虑哪种身份验证方法？

- (A) 令牌认证
- (B) 定位跟踪
- (C) 生物识别
- (D) 智能卡

**解析 522。** 正确答案：C. 生物识别。生物识别认证涉及根据个人的独特物理或行为特征识别个人，例如指纹、视网膜扫描或语音识别。

**选项 A 错误。** 令牌认证为用户提供一个生成时间敏感代码的设备或软件令牌。它不捕捉物理或行为特征。

**选项 B 错误。** 定位跟踪确定用户的位置，但不涉及对物理或行为特征的捕捉。

**选项 D 错误。** 智能卡是一种包含电子信息的实体卡片。它可以用于身份验证，但它本身并不捕获独特的物理或行为特征。
