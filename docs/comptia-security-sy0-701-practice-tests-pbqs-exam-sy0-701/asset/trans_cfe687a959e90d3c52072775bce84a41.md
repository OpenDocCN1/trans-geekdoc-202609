# 答案 221-310

**问题 221.** SecureNet Corp. 的网络团队正在建立一个新的分公司。他们希望确保分公司与主办公室之间有安全的连接。以下哪项**最能**提供这种保护？

- (A) 在两个位置之间为无线天线建立清晰的视线
- (B) 在两个站点之间实现虚拟专用网络 (VPN)
- (C) 增加两个位置公共互联网连接的带宽
- (D) 为两个位置的所有用户账户使用多因素身份认证

**解释 221.** **正确答案：B。在两个站点之间实现虚拟专用网络 (VPN)。** VPN 可以在可能不安全的网络（如互联网）上提供安全、加密的连接，使其成为安全连接远程地点的理想选择。

**选项 A 错误。** 虽然清晰的视线可能有助于无线通信，但它它本身并不提供安全的连接。

**选项 C 错误。** 增加带宽可以提高数据传输速率，但无法从本质上确保站点之间连接的安全性。

**选项 D 错误。** 多因素身份认证是用户访问的强有力安全措施，但它无法保护站点之间的网络连接。

**问题 222.** 一家快速发展的电子商务公司最近遭遇了跨站脚本 (XSS) 和 SQL 注入攻击的增加。该公司希望部署一种专门用于应用程序层防御这些威胁的解决方案。哪种防火墙最合适？

- (A) 状态检测检测防火墙
- (B) 代理防火墙
- (C) 网络层防火墙
- (D) Web 应用程序防火墙 (WAF)

**解释 222.** 正确答案：D. Web 防火墙 (WAF)。Web 防火墙 (WAF) 专门设计用于通过监控、过滤和阻止潜在的有害 HTTP 流量来保护 Web 应用程序。这包括针对 Web 应用程序常见的 XSS 和 SQL 注入攻击等威胁的保护。

**选项 A 错误。** 虽然状态检测防火墙可以监控活动连接的状态并根据流量上下文决策，但它没有专门针对 XSS 和 SQL 注入等应用层漏洞。

**选项 B 错误。** 虽然代理防火墙可以提供某些应用层过滤，但其主要目的并非为了防御特定的 Web 应用程序漏洞而定制。

**选项 C 错误。** 网络层防火墙主要运行在网络层，无法对应用层威胁提供专门保护。

**问题 223.** 网络安全公司 SecureNet 正在为其企业客户实施入侵检测系统 (IDS)。为了优化对恶意活动的检测，IDS 应该放在什么位置？

- (A) 在边界防火墙之前，以捕获所有入流量
- (B) 在边界防火墙和内部网络之间，以监控过滤后的流量
- (C) 在 DMZ 内部，仅监控外部服务请求
- (D) 位于每个工作站旁，以提供个性化安全

**解释 223.** **正确答案：B。在边界防火墙和内部网络之间，以监控过滤后的流量。** 将 IDS 放在防火墙和内部网络之间，它可以监控通过防火墙过滤的流量。这个位置在捕捉潜在威胁和减少良性外部流量产生的误报之间取得了平衡。

**选项 A 错误。** 虽然将 IDS 放在防火墙之前可以捕获所有入站流量，但可能会导致大量的误报，因为许多良性流量可能会触发报警。

**选项 C 错误。** 仅将 IDS 放置在 DMZ 中会限制其可见性，仅限于外部服务请求，而无法涵盖可能包含潜在威胁的整体内部流量。

**选项 D 错误。** 虽然每个工作站上的个人 IDS 提供了细粒度的监控，但它无法提供网络活动的全局视图，且资源消耗较大。

**问题 224.** 一个在线游戏平台在多人会话期间经历了延迟问题，影响了用户的游戏体验。该公司希望确保全球玩家都能获得实时响应。以下哪种解决方案**最能**缓解这些延迟问题？

- (A) 实现内容交付网络 (CDN)
- (B) 引入更严格的用户身份验证方法
- (C) 部署中心化数据库服务器
- (D) 降低游戏的图形保真度

**解释 224.** 正确答案：A. 实现内容交付网络 (CDN)。CDN 涉及将内容托管分布到全球多个位置。对于在线游戏而言，这意味着玩家可以连接到距离地理位置更近的服务器，从而减少延迟并提高响应速度。

**选项 B 错误。** 虽然强身份验证方法对安全至关重要，但它们无法解决延迟或提高实时响应。

**选项 C 错误。** 数据库服务器中心化可能会增加距离该位置的用户的延迟。

**选项 D 错误。** 降低图形保真度可以提高客户端性能，但无法解决网络延迟问题。

**问题 225.** ABC Corp. 的软件开发团队创建了一种使用独特算法的应用程序。公司希望确保竞争对手无法合法复制或复制其应用程序的功能。以下哪项是保护此类知识产权的**最合适**方法？

- (A) 用户界面设计版权
- (B) 为创新算法申请专利
- (C) 将应用程序代码存储在加密库
- (D) 确保所有用户签署接受使用政策 (AUP)

**解释 225.** 正确答案：B。为创新算法申请专利。专利为发明提供法律保护，允许发明者或专利持有者在规定时间内对专利工艺、设计或发明拥有独权。在这种情况下，申请专利将防止竞争对手合法复制应用程序的功能。

**选项 A 错误。** 用户界面设计的版权只能保护应用程序的外观和元素，而不是其独特的功能或底层算法。

**选项 C 错误。** 虽然将应用程序代码存储在加密库中防止未经授权的访问，但无法无法竞争对手独立开发类似功能提供法律保护。

**选项 D 错误。** 接受使用政策 (AUP) 定义了用户如何使用软件或系统，但它无法对竞争对手复制应用程序的功能提供保护。

**问题 226.** 一公司正在评估其数据存储选项。他们需要一种解决方案，能够让他们对硬件、软件和网络配置拥有最高级别的控制，并允许进行自定义的安全控制和措施。哪种部署模型最符合他们的需求？

- (A) 云端基础设施
- (B) 混合基础设施
- (C) 本地基础设施
- (D) 社区云

**解释 226.** 正确答案：C. 本地基础设施。本地基础设施允许组织对其硬件、软件和网络配置拥有完全控制。这让他们能够自由定制根据其特定需求的安全控制和措施。
