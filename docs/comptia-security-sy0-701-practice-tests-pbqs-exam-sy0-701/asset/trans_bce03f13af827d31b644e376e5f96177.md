**问题 130.** 一家政府机构遭遇了网络安全事件，其通信平台被破解。入侵者对提取敏感数据或造成破坏不感兴趣，但被观察到一直在静地监控外交通信。攻击者的可能动机是什么？

- (A) 从内幕交易中获得财务利益
- (B) 为了理解和预测外交动向而进行的间谍活动
- (C) 内部员工的不满
- (D) 试图扩大其网络犯罪网络

**解释 130. 正确答案：B. 为了理解和预测外交动向而进行的间谍活动。** 在不外泄数据或不引起破坏的情况下静静监控外交通信，表明其具有理解、预测并可能操纵政府或外交行动的动机。这是间谍活动的经典案例。

**选项 A 错误。** 虽然敏感信息对内幕交易可能有价值，但对外交通信的关注表明其具有更广泛的战略意图，而不仅仅是财务收益。

**选项 C 错误。** 不满的员工可能会参与破坏或数据泄露，但静静监控外交通信表明了更高水平的策略和复杂性，通常超出了个人恩仇范围。

**选项 D 错误。** 攻击者的行为专门针对监控外交渠道，并未表明试图将更多系统或个人招募进犯罪网络。

**问题 131.** 一家知名软件开发公司的员工经常访问一个行业相关论坛以讨论最新的趋势和技术。在过去的一个月里，几名员工报告在访问论坛后不久就感染了恶意软件。调查表明，该论坛被破解以专门针对该公司的开发人员。哪种攻击类型最准确地描述了这一场景？

- (A) 鱼叉式钓鱼
- (B) 水塘攻击（挂钩式攻击）
- (C) 旁路下载
- (D) 捕鲸攻击（大鱼钓钓）

**解释 131. 正确答案：B. 水塘攻击。** 攻击集中在目标组织的员工经常访问的特定网站，意在破解这些特定的个人。

水塘攻击涉及破解特定团体或组织成员经常访问的网站或在线资源。一旦该网站被破解，攻击者可以使用该网站向目标个人部署恶意软件。

**选项 A 错误。** 鱼叉式钓鱼是一种针对性的尝试，通常通过电子邮件进行，针对特定的个人或组织。它不涉及破解目标经常访问的网站。

**选项 C 错误。** 虽然旁路下载可能是论坛被破解后输送恶意软件的方法，但针对已知受害者经常访问的特定网站的整体策略将其定义为水塘攻击。

**选项 D 错误。** 捕鲸攻击是一种针对首席执行官（CEO）或首席财务官（CFO）等高层目标的钓鱼攻击。它不涉及破解网站。

**问题 132.** 一位网络安全分析师注意到其关键基础设施系统受到了一系列复杂的攻击。这些攻击高度协调、资金充足，并且似乎具有特定的地缘政治目标。哪种类型的威胁者最有可能负责这些攻击？

- (A) 有组织的犯罪团伙
- (B) 脚本小子（Script kiddies）
- (C) 内部威胁
- (D) 国家

**解释 132.** **正确答案：D. 国家。** 针对国家关键基础设施的复杂、协调且资金充足的攻击，具有明确的地缘政治目标，与国家行为者的特征和动机最为吻合。他们通常拥有巨大的资源和特定的政治或战略动机，针对关键基础设施以产生重大影响或获得战略优势。

**选项 A 错误。** 虽然有组织的犯罪团伙可能资金充足并能够发起复杂的攻击，但他们通常受财务动机驱动，而非地缘政治目标。

**选项 B 错误。** 脚本小子是使用预写脚本或工具利用漏洞的业余黑客。他们通常缺乏对关键基础设施发起协调攻击的复杂性和资源。

**选项 C 错误。** 内部威胁源自于组织内部的人员，如员工或承包商。虽然他们是有害的，但描述的场景更表明是一个具有大量资源和地缘政治动机的外部国家行为者。

**问题 133.** 一家小型企业检测到其网站遭到未经授权访问。攻击者使用默认登录凭据获得了访问。这种攻击表明该威胁者具有何种水平的复杂性和能力？

- (A) 具有基础技能的脚本小子
- (B) 利用高级技术的专家攻击者
- (C) 具有战略目标的国家行为者
- (D) 针对高价值资产的有组织的犯罪团伙

**解释 133. 正确答案：A. 具有基础技能的脚本小子。** 使用默认凭据进行未经授权的访问通常表明复杂性水平较低，因为这种方法非常基础，不需要或很少需要技术。此类攻击者通常被称为“脚本小子”，他们通常利用现有的工具或脚本利用已知漏洞。

**选项 B 错误。** 专家攻击者可能会利用更高级的技术，而不仅仅依赖默认凭据。

**选项 C 错误。** 虽然国家行为者有执行复杂攻击的能力，但将默认凭据作为未经授权访问的主要方法并不符合此类行为者通常使用的复杂方法。

**选项 D 错误。** 有组织的犯罪团伙，特别是针对高价值资产的团伙，会采用比使用默认凭据更复杂的技术。
