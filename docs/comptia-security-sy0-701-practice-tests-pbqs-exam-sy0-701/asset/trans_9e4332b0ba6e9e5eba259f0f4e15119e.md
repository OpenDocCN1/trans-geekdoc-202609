**问题 421。** 一个流行的社交媒体平台允许第三方应用程序访问用户数据并代表用户发布内容。为了避免与第三方应用程序共享用户密码并提供有限的、范围化的访问，平台应该使用哪种身份验证方法？

- (A) 在应用程序代码中嵌入用户密码
- (B) 每次请求都使用用户名和密码进行基础认证
- (C) 使用 OAuth 实现单点登录 (SSO) 以提供基于令牌的访问
- (D) 仅依赖 CAPTCHA 进行第三方认证

**解析 421。** **正确答案：C。使用 OAuth 实现单点登录 (SSO) 以提供基于令牌的访问。** OAuth 提供基于令牌的访问，允许第三方应用程序代表用户操作，而无需暴露用户密码。OAuth 令牌还可以进行范围限制，以限制第三方应用程序可以执行的操作范围。

选项 A 错误。在应用程序代码中嵌入密码是不安全的，且违背了最佳实践。

选项 B 错误。基础认证会暴露用户凭据，并且无法提供 OAuth 提供的范围化访问。

选项 D 错误。CAPTCHA 设计用于区分人类访问和自动化访问，但不能处理身份验证或授权。

**问题 422。** 一家大集团的 IT 部门每天花费几个小时时间手动为数千台工作站部署补丁和更新。以下哪些方案最能提高这一过程的效率并为 IT 团队节省时间？

- (A) 禁用自动更新并每月进行补丁维护会议
- (B) 实现自动补丁管理系统
- (C) 指定一个专门的补丁团队进行轮班工作
- (D) 引导用户自行安装更新

**解析 422。** 正确答案：B。实现自动补丁管理系统。通过实现自动补丁管理系统，IT 部门可以简化向所有工作站部署补丁和更新的过程，确保一致性，减少手动工作并节省宝贵时间。

**选项 A 错误。** 禁用自动更新并每月进行补丁维护无法解决手动补丁效率低的问题，并可能导致系统暴露漏洞的时间更长。

**选项 C 错误。** 虽然指定专门团队可能会分配工作负载，但无法消除与手动补丁相关的低效率问题。

**选项 D 错误。** 依赖用户安装更新会引入不一致性、潜在延迟和额外风险，因为并非所有用户都可能具备技术知识或记得定期更新。

**问题 423。** 国际公司 GlobalTech 正在使用由不同供应商托管的多个 Web 应用程序。为了确保员工访问这些应用程序而无需记住多组凭据，他们希望实现一种可以在公司与服务提供商之间安全交换用户身份验证信息的解决方案。GlobalTech 应该实施什么？

- (A) 将每个应用程序与独立的 LDAP 服务器集成
- (B) 使用安全断言标记语言 (SAML) 实现 SSO
- (C) 在每个应用程序的 URL 中嵌入加密的用户凭据
- (D) 依靠公司与每个供应商之间共享的公共 API 密钥

**解析 423。** 正确答案：B。使用安全断言标记语言 (SAML) 实现 SSO。SAML 是一种用于在双方交换身份验证和授权数据的 XML 标准。它旨在促进 Web 应用程序的单点登录。通过使用 SAML 实现 SSO，GlobalTech 可以允许员工验证一次身份即可在无需再次验证的情况下访问多个应用程序。

**选项 A 错误。** 为每个应用程序设置独立的 LDAP 服务器违背了 SSO 的初衷，并增加了用户管理的复杂性。

**选项 C 错误。** 在每个应用程序的 URL 中嵌入加密的用户凭据是不安全的。

**选项 D 错误。** API 密钥用于系统与系统之间的通信，而不是用户身份验证。此外，公共 API 密钥不应被随意共享。

**问题 424。** 公司希望实施一种解决方案，在允许服务器连接到网络之前验证其软件完整性。以下哪些方案最能通过认证实现这一目标？

- (A) 主机防火墙
- (B) 白名单应用程序
- (C) 远程认证
- (D) VPN 隧道

**解析 424。** 正确答案：C。远程认证。远程认证是一种设备（如服务器）向远程实体（如网络控制器）证明其运行的是真实的、未经修改的软件的过程。它允许在连接到主网络之前进行验证。

选项 A 错误。主机防火墙根据一组配置规则控制入站和出站的网络流量。它不验证软件完整性。

选项 B 错误。白名单应用程序仅允许指定的软件在系统上运行。虽然它通过只运行批准的软件来增强安全性，但它无法证明设备的状态。

选项 D 错误。VPN 隧道对互联网上两个点之间的连接进行加密。虽然它确保了通信的安全，但并没有验证软件。

**问题 425。** TechCorp 正在与合作伙伴 SoftTech 进行协作。为了简化协作并管理账户，TechCorp 希望其员工使用现有凭据访问 SoftTech 的在线项目管理系统。以下哪些方法最能实现此功能？

- (A) TechCorp 在 SoftTech 系统上为员工创建新账户
- (B) SoftTech 允许 TechCorp 员工匿名访问
- (C) TechCorp 在其身份提供者与 SoftTech 的服务提供者之间实施联合
- (D) SoftTech 重置所有密码并提供给 TechCorp 员工

**解析 425。** 正确答案：C。TechCorp 在其身份提供者与 SoftTech 的服务提供者之间实施联合。联合允许两个组织信任对方的身份系统。TechCorp 的员工可以使用现有凭据访问 SoftTech 上的服务，而无需创建账户。

选项 A 错误。为协作组织中的每个用户创建账户不具扩展性，且抵消了联合的优势。

选项 B 错误。允许匿名访问会损害安全性且无法保证身份验证。

选项 D 错误。重置所有密码并重新提供不是组织之间协作的实用或安全方法。
