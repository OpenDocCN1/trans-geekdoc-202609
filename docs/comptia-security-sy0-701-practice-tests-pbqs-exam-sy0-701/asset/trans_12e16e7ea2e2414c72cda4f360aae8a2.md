问题 287。XYZ 公司的高级高管 John 接到一个自称来自银行欺诈部门的人的电话。来电者要求 John 通过提供发送到其注册手机号的 OTP（一次性密码）来确认某些交易。John 可能面临哪种形式的社会工程攻击？

- (A) 钓饵 (Baiting)
- (B) 问答 (Quizzing)
- (C) 语音诈骗 (Vishing)
- (D) 钓鱼攻击 (Pharming)

解析 287. 正确答案：C. 语音诈骗 (Vishing)。Vishing 是 voice phishing 的缩写，是指利用电话欺骗用户交出用于身份盗窃的隐私信息。

语音诈骗攻击利用信任，通过语音通话操纵受害者披露敏感信息。攻击者通常伪装成合法实体或部门（例如银行欺诈部门），以使他们的骗局看起来真实。

选项 A 是错误的。钓饵涉及诱导受害者在免费或有利下载的名下下载恶意软件。

选项 B 是错误的。问答不是一种公认的社会工程攻击类型。

选项 D 是错误的。钓鱼攻击（Pharming）涉及将网站流量重定向到虚假网站，通常是为了获取登录凭据。

问题 288。零售公司 DeltaCorp 评估安全泄露可能会导致 100 万美元的销售损失。公司确定他们可以忍受高达 50 万美元的损失，但超过此金额的任何损失都将严重影响运营。超出忍受水平后，他们决定购买网络安全保险。以下哪个术语最描述 500,000 美元的数字？

- (A) 风险偏好 (Risk appetite)
- (B) 风险阈值 (Risk threshold)
- (C) 风险容量 (Risk capacity)
- (D) 风险评估 (Risk assessment)

解析 288. 正确答案：B. 风险阈值 (Risk threshold)。风险阈值是组织愿意接受的特定风险水平。在这种情况下，DeltaCorp 愿意接受高达 500,000 美元的潜在损失，将其标记为他们的阈值。

选项 A 是错误的。风险偏好是一个更广泛的术语，反映了组织在追求其目标时愿意接受总体风险水平。它更多是关于战略意图，而不是具体的数字。

选项 C 是错误的。风险容量是指组织在不显著影响其战略目标或生存能力的情况下可以吸收的风险总量。它比特定的忍受阈值是一个更广泛的衡量标准。

选项 D 是错误的。风险评估是识别、分析和评估风险的过程。它不是一个具体的数字或阈值。

问题 289。一家金融机构收集并存储其客户的个人身份信息 (PII)。该公司在某些对此类数据的存储、传输和处理有严格法规的管辖区内运营。为了确保符合这些法规，公司采取以下哪种策略最为合适？

- (A) 使用未经验证的开源加密算法
- (B) 仅在物理现场服务器上存储客户数据
- (C) 实施数据分类和标记程序
- (D) 限制访问数据的管理员数量

解析 289. 正确答案：C. 实现数据分类和标记程序。通过实施数据分类和标记程序，组织可以明确识别哪些数据受监管，确保采取了适当的控制、访问权限和保护措施。这有助于根据分类制定清晰的数据处理准则，从而实现合规。

选项 A 是错误的。虽然加密对于保护敏感数据至关重要，但使用未经验证的开源算法可能无法确保数据达到法规要求的保护标准。

选项 B 是错误的。仅在物理现场服务器上存储客户数据并不一定能保证法规。法规通常要求无论数据存储在何处都需要特定的控制。

选项 D 是错误的。虽然限制管理访问可以减少内部威胁的风险，但它不能直接确保受监管的数据按照合规方式处理。

问题 290。一家组织正在考虑更换其全球分支的防火墙。IT 总监希望解决方案能够对数据包进行状态检测、应用程序级过滤，并集成威胁情报馈送以更新威胁意识。以下哪种方案最符合需求？

- (A) 状态检测检测防火墙
- (B) 代理服务器
- (C) Web 应用防火墙 (WAF)
- (D) 下代防火墙 (NGFW)

解析 290. 正确答案：D. 下代防火墙 (NGFW)。下一代防火墙 (NGFW) 设计用于提供传统的防火墙功能（如状态检测），同时也具有高级功能，如应用程序级过滤以及集成威胁情报馈送的能力。这使得 NGFW 适用于需要多层安全的现代复杂环境。
