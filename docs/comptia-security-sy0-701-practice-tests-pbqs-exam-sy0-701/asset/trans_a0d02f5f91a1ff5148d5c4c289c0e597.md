**问题 337。** ABC 公司最近采用了自备设备 (BYOD) 政策。IT 部门担心个人设备访问公司网络可能带来的风险。以下哪些解决方案对于对这些个人移动设备执行安全策略最为有效？

- (A) 在每台设备上安装防病毒软件
- (B) 为移动设备建立独立的访客 Wi-Fi 网络
- (C) 使用移动设备管理 (MDM) 强制安全策略
- (D) 强制员工在个人设备上使用强密码

**解释 337. 正确答案：C. 使用移动设备管理 (MDM) 强制安全策略。** MDM 解决方案提供了中心化控制，用于执行安全策略、管理设备功能，并确保个人设备在访问公司资源之前符合组织的安全标准。

**选项 A 错误。** 虽然安装防病毒软件是很好的安全措施，但它无法提供 MDM 那种全面的策略执行能力。

**选项 B 错误。** 独立的访客 Wi-Fi 可能会限制对内部网络的访问，但它无法对设备本身进行管理或执行安全策略。

**选项 D 错误。** 虽然使用强密码至关重要，但这只是设备安全的一个方面。MDM 提供了更广泛的策略执行能力。

**问题 338。** IT 管理员 David 发现，几台公司拥有的移动设备即使连接到公司 Wi-Fi 时，数据流量使用也异常高。他怀疑这些设备可能在后台使用蜂窝数据。为了确保公司设备在办公期间仅使用公司 Wi-Fi 进行数据传输，David 应该实施以下哪些解决方案

- (A) 在所有设备上开启飞行模式
- (B) 设置 Wi-Fi 白名单
- (C) 实施移动设备管理 (MDM) 策略以使 Wi-Fi 优先
- (D) 在办公区域禁用蜂窝天线

# 解释 338. **正确答案：C. 实施移动设备管理 (MDM) 策略以使 Wi-Fi 优先。** MDM 解决方案允许管理员在移动设备上执行策略。通过实施优先考虑 Wi-Fi 连接的策略，David 可以确保公司设备在可用时使用公司 Wi-Fi 网络，从而减少蜂窝数据流量。

**选项 A 错误。** 虽然开启飞行模式会切断蜂窝数据，但还会禁用包括 Wi-Fi 在内的所有其他通信形式，导致设备无法按预期用途使用。

**选项 B 错误。** 设置 Wi-Fi 白名单并防止设备使用蜂窝数据。它仅限制设备可以连接到哪些 Wi-Fi 网络。

**选项 D 错误。** 禁用蜂窝天线是一种激进的措施，可能会影响附近的其他设备和服务。根据当地法规，这可能是不实际的且可能违法的。

**问题 339。** 一个安全团队最近升级了他们的入侵检测系统 (IDS)。升级后，该系统没有标记任何入侵，尽管入侵尝试是经常发生的。这种情况最准确的特征是什么？

- (A) 真阴性
- (B) 假阴性
- (C) 真阳性
- (D) 确认反馈

**解释 339. 正确答案：B. 假阴性。** 假阴性是指系统未能检测到实际存在的入侵（或漏洞）。

**选项 A 错误。** 真阴性意味着系统正确识别出没有入侵。

**选项 C 错误。** 真阳性意味着系统正确识别出了威胁或漏洞。

**选项 D 错误。** “确认反馈”不是与入侵尝试相关的标准术语。

**问题 340。** XYZ 公司计划在其新收购的大楼内部署无线基础设施。IT 经理希望确保覆盖范围。在安装接入点之前，IT 团队应该优先考虑哪些

- (A) 购买最贵的接入点以确保最大范围
- (B) 进行现场调查以确定接入点的最佳位置
- (C) 在窗户附近部署接入点以增强信号
- (D) 确保所有用户都使用 5GHz 设备

**解释 340. 正确答案：B. 进行现场调查以确定接入点的最佳位置。** 现场调查有助于确定接入点的最佳布局，以实现持续且稳健的覆盖。

**选项 A 错误。** 虽然高质量设备至关重要，但昂贵的接入点并不总是能保证效果。

**选项 C 错误。** 在窗户附近部署接入点会导致信号泄漏，使信号超出预期范围并产生安全风险。

**选项 D 错误。** 虽然确保用户使用 5GHz 设备是很好的做法，但它与接入点的优化部署没有直接关系。

**问题 341。** XYZ 公司使用 MDM 管理公司拥有和员工拥有的移动设备。一名员工报告在周末丢失了手机。为了确保丢失手机上的敏感公司数据不被访问，IT 部门应该使用哪种 MDM 功能

- (A) 监控设备位置
- (B) 强制更新设备应用
- (C) 远程擦除设备
- (D) 修改用户的电子邮件密码

**解释 341. 正确答案：C. 远程擦除设备。** 通过远程擦除功能，IT 部门可以从丢失设备上删除包括公司数据在内的所有数据，确保敏感信息落入他人手中。

**选项 A 错误。** 监控设备位置可能有助于找到手机，但无法防止对设备上数据的非法访问。

**选项 B 错误。** 强制更新设备应用可能会解决应用程序中的漏洞，但不能直接保护设备上的公司数据。

**选项 D 错误。** 修改用户的电子邮件密码可以防止未经授权访问用户的电子邮件，但无法保护设备上可能存在的其他敏感公司数据。
