
选项 B 错误。数字签名用于验证消息的完整性和真实性，但不会隐藏原始内容。

选项 D 错误。隐写术涉及将信息隐藏在其他信息之中这与安全存储密码无关。

## 问题 414。某公司的 IT 部门注意到，在过去的两天内账户锁定次数急剧增加，特别是在非工作时间。虽然某些账户来自不同部门，但大多数来自财务团队。对于这些锁定情况，以下哪种解释是最可能的？

- (A) IT 部门执行的计划性维护
- (B) 员工在财务团队内部共享密码
- (C) 攻击者正试图获取未经授权的访问
- (D) 最近的密码策略要求更频繁地更改

解释 414. 正确答案：C。攻击者正试图获取未经授权的访问。账户锁定次数突然增加，特别是在非工作时间，表明存在可疑活动。锁定的针对性（特别是针对财务等敏感部门）表明攻击者可能正在尝试未经授权的访问。

选项 A 错误。计划性维护通常会提前通知，不太会导致账户锁定次数急剧增加。

选项 B 错误。虽然员工共享密码是一个安全隐患，但它通常不会导致账户锁定激增，特别是在非工作时间。

选项 D 错误。密码策略的更改可能会导致锁定次数有所增加，但锁定的针对性（大多数来自财务部门）以及在非工作时间的发生使得该选项的可能性较低。

## 问题 415。Carlos 负责管理某大学的 IT 服务。该大学有许多部门，其子域名如 arts.university.com、science.university.com 和 sports.university.com。Carlos 想要一个既确保 HTTPS 安全又具有成本效益的解决方案。然而，他对潜在风险表示警惕。为大学子域名使用通配证书（Wildcard Certificate）可能有什么缺点？

- (A) 它只能保护一个子域名
- (B) 如果被破解，所有子域名都面临风险
- (C) 它仅验证域名所有权，而非组织身份
- (D) 它是可用的最贵证书

解释 415. 正确答案：B。如果被破解，所有子域名都面临风险。通配证书的主要担忧是如果其私钥被泄露，将危及所有关联子域名的安全。这构成了重大风险，因为单个密钥的泄露可能导致所有子域遭受潜在攻击或滥用。

选项 A 错误。通配证书可以保护单个域名下的多个子域名。

选项 C 错误。虽然对于域名验证（DV）证书是是的，但通配证书也可以提供组织验证（OV）版本，从而确保组织身份。

选项 D 错误。通配证书并不一定是最贵的。成本取决于验证级别和颁发机构。

## 问题 416。金融公司 SecureData Inc. 最近遭遇了系统崩溃，需要恢复数据库。虽然他们有上周的完整备份，但他们发现丢失了数天的交易记录。为了防止未来发生此类数据丢失，SecureData 可以实施哪种涉及记录交易的备份策略？

- (A) 实施差异备份
- (B) 每小时使用快照备份
- (C) 启用数据库日志（Database Journaling）
- (D) 为其存储配置 RAID 5

解释 416. 正确答案：C。启用数据库日志。日志功能涉及维护每个发生的每个交易或更改的日志或“日记”。如果发生崩溃，系统可以恢复到上一次备份，然后使用日志重放每个交易，从而防止数据丢失。

选项 A 错误。差异备份捕获自上次完整备份以来的变化，但它们不会像日志那样实时记录每次交易。

选项 B 错误。虽然每小时快照备份会缩短潜在的数据丢失窗口，但它们仍实时捕获每次交易。

选项 D 错误。RAID 5 提供冗余并可以防止磁盘故障，但它不会像日志那样捕获并记录每个数据库交易。

## 问题 417。某公司设置了防火墙，允许通过 80 端口和 443 端口通过流量，默认拒绝所有其他流量。这种设置是哪种类型访问控制的示例？

- (A) 基于角色的访问控制 (RBAC)
- (B) 强制访问控制 (MAC)
- (C) 任意性访问控制 (DAC)
- (D) 基于规则的访问控制 (RAC)

解释 417. 正确答案：D。基于规则的访问控制 (RAC)。基于规则的访问控制根据管理员预定义的规则运行。在所描述的场景中，防火墙正在使用规则允许某些端口（80 和 443）上的流量，同时拒绝所有其他，这是 RAC 的典型示例。

选项 A 错误。RBAC 根据组织内的角色分配权限。防火墙规则通常不是基于用户角色分配。

选项 B 错误。MAC 涉及信息分类并将用户许可级别与这些分类匹配。这与防火墙规则设置无关。

选项 C 错误。DAC 允许资源所有者指定谁可以访问资源。防火墙规则并非主裁运行。

## 问题 418。在一次例行安全评估中，渗透测试员 Jake 发现通过修改位于公共目录下的配置文件，他可以给自己分配管理员权限。Jake 遇到的是什么种类型的漏洞？

- (A) 跨站点脚本 (XSS)
- (B) 权限提升 (Privilege Escalation)
- (C) SQL 注入
- (D) 不安全的对象引用 (IDOR)

解释 418. 正确答案：B。权限提升。权限提升是指用户增加了超过其被授予的权限，从而允许他们执行不应被允许的操作。在这一场景中，Jake 通过修改配置文件提升了他的应用权限。

选项 A 错误。跨站点脚本 (XSS) 涉及攻击者向用户查看的网络内容注入恶意脚本。此场景与注入脚本无关。

选项 C 错误。SQL 注入漏洞允许攻击者通过输入字段操纵或查询数据库。场景未显示与数据库有交互。

选项 D 错误。不安全的对象引用 (IDOR) 漏洞发生在应用程序根据用户输入允许访问对象时。虽然场景涉及访问文件，但核心问题是提升权限的行为。

## 问题 419。某学校希望防止学生在课上期间访问不当网站。IT 部门决定实施一种阻止与不当内容相关的特定域名请求的解决方案。以下哪种安全解决方案最好满足这一需求？

- (A) 基于 IP 地址的防火墙过滤
- (B) 侵入检测系统监控
- (C) 虚拟专用网络 (VPN) 强制
- (D) 使用黑名单的 DNS 过滤

解释 419. 正确答案：D。使用黑名单的 DNS 过滤。DNS 过滤是一种通过阻止对特定域名请求来防止用户访问特定网站的技术。可以创建一个黑名单列与不当内容相关的域名，当用户尝试访问这些网站时，DNS 过滤器将不会解析域名，从而阻止访问。

选项 A 错误。虽然防火墙可以基于 IP 地址拦截流量，但这种方法对于阻止特定域名并不有效，特别是当一个域名有多个 IP 地址或 IP 可能会发生变化时。
