

问题 300. 一家金融机构正在实施一个系统，客户可以在无法访问原始数据的情况下验证其每月账单的完整性。对于此任务，以下哪种技术最合适？

- (A) 使用 AES 对账单加密
- (B) 压缩账单以缩小文件大小
- (C) 对账单进行哈希处理并向客户提供哈希值
- (D) 对账单中的敏感数据令牌令牌

解析 300. **正确答案：C. 对账单进行哈希处理并向客户提供哈希值。** 哈希可确保数据完整性。客户可以对其收到的账单进行哈希，并与提供的哈希值比较，以验证数据未被篡改。

选项 B 错误。压缩账单仅仅是为了存储或传输减小文件大小；它无助于验证数据完整性。

选项 D 错误。令牌化是将敏感数据替换为非敏感的占位符。它无法提供验证整个账单完整性的方法。

问题 301. 一个组织决定重点保护存储客户详细信息和交易记录的数据库服务器。这些数据没有被活动访问或处理。对于此类类型的数据，哪种安全措施最合适？

- (A) 针对电子邮件的数丢失防护 (DLP)
- (B) Web 应用防火墙 (WAF)
- (C) 全盘加密 (FDE)
- (D) 针对网络流量的入侵检测系统 (IDS)

解析 301. 正确答案：C. 全盘加密 (FDE)。静态数据是指未在网络中移动的数据，例如存储在硬盘上的数据。全盘加密 (FDE) 是一种专门设计的安全措施，通过加密整个硬盘来保护静态数据。

选项 A 错误。电子邮件 DLP 主要侧重于防止通过电子邮件进行未经授权的数据传输，更适用于传输中的数据而非静态数据。

选项 B 错误。WAF 保护 Web 应用免受各种在线威胁，并非专门为保护静态数据设计的。

选项 D 错误。网络流量 IDS 主要侧重于监控和检测网络流量中的恶意活动，这涉及传输中的数据而非静态数据。

问题 302. 一家跨国公司正在考虑使用位于国外的云存储提供商来存储客户数据。该公司的母国有严格的数据保护法，要求客户数据保留在其边界内。公司在选择云存储提供商时，以下哪种考虑最关键？

- (A) 从国外云存储访问数据的速度
- (B) 外国云提供商使用的加密标准
- (C) 外国云提供商是否仅在公司母国境内提供数据存储
- (D) 外国云提供商的声誉和客户评价

解析 302. 正确答案：C. 外国云提供商是否仅在公司母国境内提供数据存储。数据主权是指数字数据受其所在地国家法律约束的概念。如果一家公司的母国有要求客户数据留在其边界内的法规，那么确保云提供商提供符合要求的存储服务是关重要的。

选项 A 错误。虽然数据访问速度很重要，但它没有解决数据主权方面的问题。

选项 B 错误。虽然加密对于安全至关重要，但它不能保证符合数据主权法。

选项 D 错误。声誉很重要，但它没有直接解决数据主权的特定要求。

**问题 303.** 在年度审查后，BestTech 公司意识到他们的 IT 团队不熟悉数据泄露期间应遵循的协议。为了确保团队在不启动现场演练的情况下理解步骤和决策点，公司应该实施什么？

- (A) 升级他们的防火墙系统
- (B) 参加桌面演练 (Tabletop exercise)
- (C) 进行红队演练
- (D) 为所有用户实施多因素身份验证

解析 303. **正确答案：B. 参加桌面演练。** 桌面演练允许团队讨论和审查特定场景（例如数据泄露），并确保每个人理解自己的角色和要遵循的流程。这是团队熟悉响应程序的一种成本效益的方法。

选项 A 错误。升级防火墙系统可能会增强公司的安全态势，但不能让 IT 团队熟悉数据泄露响应协议。

选项 C 错误。红队演练是实模拟攻击，用于评估组织的安全态势，并不重点于在受控环境中引导团队执行步骤。

选项 D 错误。多因素身份验证是验证用户身份的安全措施，但无法解决团队对数据泄露响应协议不熟悉的问题。

**问题 304.** 金融公司 SecureData Inc. 最近经历了系统崩溃，需要恢复数据库。虽然他们有上周的完整备份，但他们发现丢失了好几天的交易。为了防止未来发生此类数据丢失，SecureData 可以实施哪种涉及记录交易的备份策略？

- (A) 实现差异备份
- (B) 每小时使用快照
- (C) 启用数据库日志 (Journaling)
- (D) 为其存储配置 RAID 5

解析 304. **正确答案：C. 启用数据库日志。** 日志涉及保留每笔交易或更改的日志或“期刊”。如果发生崩溃，系统可以恢复到上次备份，然后使用日志重放每次交易，从而防止丢失。

选项 A 错误。差异备份捕获自上次完整备份以来的变化，但它们不会实时记录交易。

选项 B 错误。虽然每小时快照会缩短潜在的数据丢失窗口，但它们仍无法实时捕捉交易。

选项 D 错误。RAID 5 提供冗余防止磁盘故障，但它不会捕获每笔交易。

问题 306. ZenTech 是一家跨国公司，最近采用了多云策略，跨多个云服务提供商部署负载。这种方法的主要安全益处是什么？

- (A) 所有云资源的的集中化管理
- (B) 云之间传输中数据的自动加密
- (C) 缓解单点故障
- (D) 降低云存储的成本

解析 306. 正确答案：C. 缓解单点故障。使用多云策略将负载分布到不同的云提供商，这降低了与任何单一提供商停机或安全泄露相关的风险。这种多样化确保了某个云环境的故障或破解不会危及整个基础设施。
