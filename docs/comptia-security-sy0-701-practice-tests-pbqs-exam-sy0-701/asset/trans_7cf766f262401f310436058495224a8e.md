**问题 473。** 软件开发公司 AcmeTech 最近经历了重大的数据泄露，经追源于其定制应用程序中的一个漏洞。事后分析显示，该漏洞是在编码阶段引入的，在测试期间从未被检测到。为了在未来避免此类漏洞，AcmeTech 应该强调哪种策略以确保在整个开发过程中维持安全实践？

- (A) 事件响应策略
- (B) 变更管理策略
- (C) 业务连续性策略
- (D) 软件开发生命周期 (SDLC)策略

**解析 473。** **正确答案：D. 软件开发生命周期 (SDLC)策略。** 软件开发生命周期（SDLC）策略为软件开发过程的每个阶段提供了指南和标准，确保从需求收集到部署和维护的每一步都整合了安全性。

**选项 A 错误。** 虽然事件响应策略提供了管理和响应安全事件的结构化方法，但它并没有关注软件开发过程。

**选项 B 错误。** 变更管理策略处理在 IT 环境中实施变更的程序，但专门针对软件应用程序的开发。

**选项 C 错误。** 业务连续性策略侧重于在中断期间和之后维持业务运营，不涉及软件开发的细节。

**问题 474。** 某机构正在对其云基础设施进行风险评估。评估确定，通过不安全的 API 发生数据泄露的概率为“高”。哪些因素可能导致了这一概率分级？

- (A) API 已经过充分测试，并具有已知的安全配置
- (B) 行业内此类泄露的记录很少
- (C) 该 API 是公开访问的，且在过去六个月内报告了若干处漏洞
- (D) 云提供商提供了针对任何形式安全泄露的保证性 SLA

解析 474. 正确答案：C. 该 API 是公开访问的，且在过去六个月内报告了若干处漏洞。具有近期漏洞历史的公开访问 API 会显著增加泄露的概率，使该场景最符合“高”概率分级。

选项 A 错误。经过充分测试且已知的安全配置很可能会降低概率分级。

选项 B 错误。类似泄露的记录很少也可能降低评估的概率。

选项 D 错误。保证性的 SLA 可能会在泄露发生后提供补救措施，但它从根本上并没有降低泄露发生的概率。

**问题 475。** SecureNet Ltd. 保护用户账户免受暴力破解攻击。他们希望实施一种措施，即在一定次数的失败登录尝试后，账户将暂时变为不可访问。哪种标准最符合这一要求？

- (A) 密码最小长度
- (B) 账户锁定阈值
- (C) 强制重置密码
- (D) 双因素身份验证

解析 475. 正确答案：B. 账户锁定阈值。账户锁定阈值定义了连续失败登录尝试的次数，达到该次数后用户账户将被锁定，在指定持续时间内防止进一步尝试。

这种措施通过使快速、重复的登录尝试不可行，直接威慑了暴力破解攻击。

**选项 A 错误。** 密码最小长度规定了密码的长度，这可以阻止某些暴力破解尝试，但没有解决此类攻击特征的快速、重复的尝试。

**选项 C 错误。** 强制重置密码迫使用户定期更改密码。虽然这可以防止使用旧的被盗凭据，但不能防止暴力破解攻击。

**选项 D 错误。** 双因素身份验证需要两种形式的识别来访问账户。尽管它显著增强了安全性，但它没有根据失败尝试来限制登录尝试。

**问题 476。** 在最近一次安全泄露后，CyberSolutions Inc. 评估了他们的响应指标，并确定平均从发现安全泄露到完全解决需要 4 小时。哪种指标最能描述这 4 小时的时间范围？

- (A) 恢复时间目标 (RTO)
- (B) 恢复点目标 (RPO)
- (C) 平均故障间隔时间 (MTBF)
- (D) 平均修复时间 (MTTR)

解析 476. **正确答案：D. 平均修复时间 (MTTR)。** MTTR（平均修复时间）是衡量可维修物品维护性的基本指标。它代表了修复故障组件或设备所需的平均时间。对于 CyberSolutions Inc. 而言，从发现到解决的 4 小时时长反映了 MTTR。

选项 A 错误。恢复时间目标 (RTO) 是业务流程在发生灾难后必须恢复的目标持续时间，以避免不可接受的后果。

选项 B 错误。恢复点目标 (RPO) 代表以时间衡量的可接受数据丢失量。

选项 C 错误。平均故障间隔时间 (MTBF) 是机械或电子系统在正常运行期间固有故障之间的预计流逝时间。

**问题 477。** 电信公司 SecureCom 计划在整个 A 国范围内扩张其基础设施。该国最近更新了其电信法规，并对外部通信规定了严格的指南。SecureCom 在开始扩张时，主要关注点应该是哪项？

- (A) 增加广告预算以在 A 国获得更强的市场地位
- (B) 确保其基础设施符合安全和加密通信的国家标准
- (C) 与当地科技公司合作以更好地了解 A 国文化
- (D) 针对 A 国居民的偏好推出新产品

解析 477. 正确答案：B. 确保其基础设施符合安全和加密通信的国家标准。电信公司本质上处理大量数据和流量。因此，当国家对外部通信规定特定指南时，像 SecureCom 这样的公司必须确保其基础设施符合这些指南，以避免法律和财务后果。

选项 A 错误。虽然广告对于市场增长至关重要，但在法规严格的国家扩张，主要关注应该是合规。

选项 C 错误。与当地科技公司合作可以提供当地市场洞察，但合规仍是首要关注。

选项 D 错误。推出定制产品是良好的业务策略，但在不确保符合国家法规的情况下，公司可能会面临重大挑战。
