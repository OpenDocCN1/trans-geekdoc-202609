Question 292. A multinational corporation is looking to replace its current firewalls at all its global branches. Which of the following would be the most suitable solution?

(B) Proxy Server
(C) Web Application Firewall (WAF)
(D) Next-Generation Firewall (NGFW)

Explanation 292. Correct Answer: D. Next-Generation Firewall (NGFW). Next-Generation Firewalls (NGFWs) are designed to offer traditional firewall capabilities such as stateful inspection but also come with advanced features like application-level filtering and the ability to integrate with threat intelligence feeds.
