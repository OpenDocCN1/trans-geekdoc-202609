问题 173。某跨国公司的 IT 安全分析师收到一封来自“人力资源部”的邮件，要求紧急验证其个人详情，包括家庭地址和安全号码。邮件带有公司标志，但有几处拼写错误。这封邮件最可能代表哪种类型的基于电子邮件的威胁？

- (A) 电子邮件欺骗 (BEC)
- (B) 邮件轰炸
- (C) 邮件转发
- (D) 钓鱼

解析 173. 正确答案：D. 钓鱼。钓鱼邮件旨在旨在通过冒充受信源来欺骗接收者共享个人或敏感数据。邮件质量存疑（如拼写错误），结合对个人详情的请求，表明这是一个典型的钓鱼尝试。

选项 A 错误。虽然 BEC 是一种针对性的诈骗邮件，但它通常涉及冒充组织内部的高管或高层官员以启动未经授权的资金转账。描述的场景与此不符。

选项 B 错误。邮件轰炸涉及向单个收件者发送大量邮件，通常是为了使系统过载或隐藏其他恶意活动。该场景并未描述此类攻击。

选项 C 错误。邮件转发是指将邮件从一个地址自动重定向到另一个地址。它本身不是一种直接的威胁，但可能被滥用。描述的场景与此不符。

问题 174。中型软件开发公司 TechSoft Corp 正将其主办公室搬至一栋新建筑。管理层对下班后的潜在威胁表示担忧，特别是由于网络间谍活动报告的增加。他们正在评估不同的安全措施。哪种方案可以在非办公时间提供即时的物理存在感和威慑？

- (A) 带有运动检测的闭路电视 (CCTV)
- (B) 所有入口处的视网膜扫描
- (C) 保安人员现场
- (D) 加固门窗

解析 174. 正确答案：C. 保安人员现场。安保人员提供了可见的威慑和即时的物理存在。在需要对威胁做出立即响应、威慑潜在入侵者或评估可疑活动的情况下，这种人为因素是无价的，特别是在非办公期间。

选项 A 错误。虽然带有运动检测的 CCTV 可以监控并提醒移动，但它不能提供安保人员那样的即时人工响应和威慑。

选项 B 错误。视网膜扫描是一种用于访问控制的验证机制。虽然它提供了高安全性，但不能提供安保人员的可见威慑或即时响应。

选项 D 错误。加固的门窗增强了建筑的物理安全性，但它们不能提供像安保人员那样主动且可见的人为威慑。

问题 175。某跨国公司在不同国家设有数据中心。由于监管限制，对这些数据中心的远程访问受到严格限制。公司的 IT 管理员需要一种中心化的方式来访问所有数据中心，而无需从工作站直接访问。公司应该考虑哪种解决方案？

- (A) 建立 DMZ
- (B) 实现跳板机 (Jump server)
- (C) 部署活动目录 (Active Directory)
- (D) 使用本地代理 (Proxy)

解析 176. 正确答案：B. 实现跳板机。跳板机也称为堡垒机（bastion host），作为中间服务器，允许用户在访问另一个服务器或网络之前连接到它。它在两个网络（如内部网络和外部网络）之间提供了受控的访问手段。

选项 A 错误。DMZ（非军事化区）是一个物理或逻辑子网络，它包含并将组织面向外部的服务暴露给不可信的网络（通常是互联网）。它不能提供像跳板机那样的整合化访问点。

选项 C 错误。活动目录是 Windows 域网络的目录服务。它并非为提供对多个数据中心的受控远程访问而设计。

选项 D 错误。本地代理可能用于控制互联网访问或缓存网页内容，但它不像跳板机那样作为数据中心的中心化访问点。

问题 176。GammaTech 正处于部署新应用的最后阶段。在部署之前，安全团队希望在不执行代码的情况下检查代码以识别任何潜在漏洞。团队应该采用哪种漏洞识别方法？

- (A) 渗透测试
- (B) 动态分析
- (C) 静态分析
- (D) 模糊测试 (Fuzz Testing)

解析 176. 正确答案：C. 静态分析。静态分析涉及在不执行的情况下检查应用程序的代码、字节码或二进制代码以识别漏洞。这种方法允许安全团队在应用程序运行之前发现代码库中的潜在安全问题。

选项 A 错误。渗透测试涉及积极尝试利用系统或应用程序中的漏洞。它不关注代码检查。

选项 B 错误。动态分析在应用程序运行时对其检查，通过观察其行为来识别漏洞。

选项 D 错误。模糊测试（fuzz testing）涉及向程序提供一系列随机输入，以查看某些输入会导致崩溃或意外行为，从而识别漏洞。

问题 177。某基于云的 SaaS 公司希望确保其基础设施能够处理大量用户的涌入。以下哪种方法最能满足这种扩展性考虑？

- (A) 实现水平扩展策略
- (B) 引入多因素认证
- (C) 部署深度包检测工具
- (D) 实现中心化日志系统

解析 177. 正确答案：A. 实现水平扩展策略。水平扩展通过向系统添加更多机器或节点来处理增加的负载，在云环境中特别有效。它通过在多个服务器之间分配负载来容纳更多用户。

选项 B 错误。多因素认证对于安全至关重要，但它并没有解决处理大量用户的扩展扩展问题。

选项 C 错误。深度包检测工具用于出于安全和管理目的分析流量，但不会直接增强基础设施的扩展性。

选项 D 错误。中心化日志系统有助于汇总分析来自各种来源的日志，但它们不解决基础设施本身的扩展需求。
