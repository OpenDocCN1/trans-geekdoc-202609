第 438 题。XYZ 公司的 IT 部门注意到服务器日志记录了非工作时间的用户登录尝试，特别是在凌晨 2:00 到凌晨 3:00 之间，而这段时间没有设置任何计划任务或备份运行。对于这种异常活动，以下最合情逻辑的解释是哪一个？

- (A) 公司员工正在加班
- (B) 服务器可能存在时区配置错误
- (C) 一位未经授权的用户正尝试访问服务器
- (D) 服务器正在自动安装安全补丁

**解释 438. 正确答案：C. 一位未经授权的用户正尝试访问服务器。** 在异常时间段发生的非周期性日志记录（特别是在没有设置计划任务的情况下）可能是存在恶意活动的重要指标。在这一场景中，非工作时间段的用户登录尝试记录表明，可能有未经授权的用户正尝试访问。

**选项 A 错误。** 虽然员工偶尔可能会加班，但特别在凌晨 2:00 到 3:00 之间的定期登录尝试是可疑的。

**选项 B 错误。** 时区配置错误可能会导致日志中的时间偏差，但不会导致重复的登录尝试。

**选项 D 错误。** 自动安装安全补丁不会导致用户登录尝试。

第 439 题。一家金融机构每天处理数千万笔信用卡交易。为了确保这些交易的安全性和完整性，安全官希望采用一种能够安全管理和存储加密密钥的解决方案。以下哪种方案是最合适的？

- (A) 信任信平台模块 (TPM)
- (B) 全盘加密 (FDE)
- (C) 硬件安全模块 (HSM)
- (D) 软件密钥库

**解释 439. 正确答案：C. 硬件安全模块 (HSM)。** 硬件安全模块 (HSMs) 是专门设计用于管理、处理和存储加密密钥的物理设备。它们提供了针对物理攻击和逻辑攻击的高水平保护，并被金融机构广泛用于确保高价值交易的安全。

**选项 A 错误。** 虽然 TPM 为单个设备提供硬件级安全保护，但它们并非为处理大量交易的机构的高容量加密需求而设计的。

**选项 B 错误。** 全盘加密 (FDE) 保护硬盘上的静态数据，但它并不专门管理用于交易处理的加密密钥。

**选项 D 错误。** 虽然软件密钥库可以存储加密密钥，但它缺乏 HSM 提供的同等水平的物理逻辑保护。

第 440 题。XYZ 公司最近面临勒索软件攻击，导致关键数据文件被加密。该公司的 IT 团队无法解密这些文件，但有一份最近的备份。然而，当他们尝试恢复数据时，发现备份文件已损坏。以下哪种最佳实践可以帮助 XYZ 公司确保其备份的完整性？

- (A) 定期测试备份恢复过程
- (B) 将备份存储在与原始文件相同的目录中
- (C) 将备份频率增加到每小时一次
- (D) 使用强加密算法加密备份

**解释 440. 正确答案：A. 定期测试备份恢复过程。** 通过定期测试从备份恢复的过程，组织可以在关键恢复情况需要之前，识别并纠正备份文件或过程中的任何问题。

**选项 B 错误。** 将备份存储在相同目录下会增加原始文件和备份文件同时受损或损坏的风险。

**选项 C 错误。** 虽然增加备份频率可以减少数据丢失，但它无法解决备份本身的完整性或有效性。

**选项 D 错误。** 虽然加密备份提供了防止未经授权访问的安全性，但它不能确保备份的完整性或可用性。

第 441 题。一家电子商务公司在其主数据库中存储了数百万客户交易记录。他们决定通过加密数据来增强安全态势，但不需要加密整个服务器。该公司应该采用哪种加密方法？

- (A) 全盘加密
- (B) 文件级加密
- (C) 卷级加密
- (D) 数据库加密

**解释 441. 正确答案：D. 数据库加密。** 数据库加密专门针对数据库内的数据加密。它可以确保数据在备份、复制或移动时保持加密状态。

**选项 A 错误。** 全盘加密会加密整个服务器，不符合该公司只想加密数据库记录的需求。

**选项 B 错误。** 文件级加密针对单个文件，对于数百万记录来说并不高效。

**选项 C 错误。** 卷级加密针对特定的卷或逻辑驱动，而不是数据库数据。

第 442 题。一位数据库管理员担心用户选择相同密码时产生相同的哈希值。为了缓解这种风险，管理员应该实施哪种加密技术？

- (A) 数字签名
- (B) 加盐 (Salting)
- (C) 密钥扩展
- (D) 对称加密

**解释 442. 正确答案：B. 加盐。** 加盐是在哈希之前添加一个随机值。这确保了即使两个用户的密码相同，他们的哈希值也会不同。这使得攻击者难以使用彩虹表来匹配密码。

**选项 A 错误。** 数字签名主要用于确保消息或数据的真实性和完整性，而不是用于密码哈希。

**选项 C 错误。** 密钥扩展涉及多次重复哈希过程以增加暴力破解的难度，但它没有解决哈希值相同的问题。

**选项 D 错误。** 对称加密在加密和解密时使用相同的密钥，与哈希值相同的场景无关。
