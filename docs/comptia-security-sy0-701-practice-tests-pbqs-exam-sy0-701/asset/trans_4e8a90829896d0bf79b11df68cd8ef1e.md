问题 241。一名开发人员在公司网站上实现了一个新功能，允许用户通过名称搜索产品。几天后，IT 团队注意到异常活动，数据库中的整个表被转储。该新功能可能引入了哪种漏洞？

- (A) 跨站脚本 (XSS)
- (B) 分布式拒绝服务 (DDoS)
- (C) 结构化查询语言注入 (SQLi)
- (D) 跨站请求伪造 (CSRF)

解释 241. 正确答案：C. 结构化查询语言注入 (SQLi)。SQL攻击发生在攻击者可以向查询中插入或“注入”SQL 代码时。如果用户输入在用于 SQL 语句之前没有经过适当清理，攻击者就可以利用此操纵查询，从而导致未经授权的数据查看、数据损坏或删除以及其他恶意活动。

结构化查询语言注入（或 SQLi）是一种攻击者用于在数据库上运行恶意 SQL 语句的代码注入技术。鉴于在实现搜索功能后数据库中的整个表被转储，这清楚地表明该功能没有妥善清理用户输入，导致了 SQLi。

**选项 A 是错误的。** 跨站脚本 (XSS) 攻击向用户查看的网页中注入恶意脚本。它不会导致场景中描述的数据库表转储。

**选项 B 是错误的。** 分布式拒绝服务 (DDoS) 攻击通过流量淹没目标，导致服务中断。它与数据库信息的提取没有关系。

**选项 D 是错误的。** 跨站请求伪造 (CSRF) 欺骗受害者提交恶意请求。它不会导致数据库表的转储。

问题 242。DeltaSoft 发布了一个新的 Web 应用程序。安全团队的任务是在应用程序运行时观察其行为和响应，以识别潜在的漏洞。哪种方法最适合此目的？

- (A) 静态分析
- (B) 模糊测试 (Fuzz Testing)
- (C) 白盒测试
- (D) 动态分析

解释 242. 正确答案：D. 动态分析。动态分析专注于在应用程序执行或运行期间对其进行检查。通过观察应用程序的行为和响应，安全团队可以识别出静态代码中可能无法发现的漏洞。

**选项 A 是错误的。** 静态分析在不执行应用程序的情况下评估其代码。它不关注观察应用程序在运行期间的行为。

**选项 B 是错误的。** 模糊测试涉及向应用程序提交随机输入以观察其行为并检测漏洞，但它只是动态分析的一个子集。

**选项 C 是错误的。** 白盒测试涉及在测试时理解应用程序的内部结构和工作原理，这可以是静态测试或动态测试的一部分，但其本身并不专门关注对运行时行为的观察。

问题 243。跨国公司 GlobalTech 正在与 CloudCorp 协商一份云存储合同。GlobalTech 希望确保确保数据检索在 99.9% 的时间内保持在 2 秒内。在他们的协议中应明确定义哪个组件来设定这一预期？

- (A) 定价模型
- (B) 数据主权条款
- (C) 服务水平协议 (SLA)
- (D) 终止条款

解释 243. 正确答案：C. 服务水平协议 (SLA)。服务水平协议 ( SLA) 旨在定义特定的指标、责任和预期，以确保双方都理解并同意性能基准以及在未达到这些基准时的后果。在这种情况下，SLA 将指定预期的数据检索时间。

**选项 A 是错误的。** 虽然定价是任何合同的一个重要方面，但它没有指定像数据检索时间这样的性能预期。

**选项 B 是错误的。** 数据主权条款涉及数据存储和处理所在地的法律方面，而不是性能指标。

**选项 D 是错误的。** 终止条款处理协议可能终止的条件，而不是性能预期。

问题 244。软件公司 SoftTech Inc. 正在考虑将其业务扩展到欧洲。他们将收集并处理欧盟公民的个人数据。对于 SoftTech Inc. 来说，以下哪些法律影响**最**需要考虑？

- (A) 需要在每个国家的软件协会注册
- (B) 遵守《通用数据保护条例》(GDPR)
- (C) 确保每个国家的软件权利
- (D) 欧洲编码标准

解释 244. 正确答案：B. 遵守《通用数据保护条例》(GDPR)。在处理欧盟公民的个人数据时，公司必须遵守 GDPR，该条例概述了数据保护和隐私的严格要求。不合规可能会导致巨罚和法律后果。

**选项 A 是错误的。** 在每个国家的软件协会注册与个人数据隐私无关。

**选项 C 是错误的。** 虽然软件权利至关重要，但它们没有直接解决个人数据的隐私。

**选项 D 是错误的。** 并不存在与隐私相关的“欧洲编码标准”。

问题 245。一家跨国组织最近发生了重大的安全泄露。经过调查，确定在没有经过标准审批流程的情况下对网络基础设施进行了更改。结果导致了配置错误，允许未经授权的访问。该组织忽略了哪种与变更管理相关的安全原则？

- (A) 配置基准审查
- (B) 最小权限原则
- (C) 遵循审批流程
- (D) 补丁管理

解释 245. 正确答案：C. 遵循审批流程。审批流程是变更管理的一个关键方面。在对任何系统（特别是网络基础设施）进行更改之前，必须经过严格的审批流程。这确保了专家能够评估更改的潜在漏洞或问题。在场景中，跳过审批流程导致了严重的安全泄露。

**选项 A 是错误的。** 配置基准审查涉及定期检查并确保按照组织的批准基准进行配置。虽然这很重要，但场景中的直接与跳过审批流程有关。

**选项 B 是错误的。** 最小权限原则是指为用户提供执行所需的所需的权限。此场景不涉及访问权限。

**选项 D 是错误的。** 补丁管理涉及对软件和系统应用更新。问题中的泄露与缺失补丁无关，而是由于跳过了审批流程。
