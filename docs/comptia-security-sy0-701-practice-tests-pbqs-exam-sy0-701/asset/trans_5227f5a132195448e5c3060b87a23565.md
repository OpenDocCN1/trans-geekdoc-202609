
选项 A 错误。虽然对访问控制系统进行暴力破解涉及尝试多种组合以获取访问权限，但该场景并未描述多次访问尝试，也未涉及系统本身。

选项 C 错误。尾随（Tailgating）是指在没有适当凭据的情况下跟随授权的人员进入安全区域。该场景描述的是潜在的 RFID 截获，而不是某跟随他人。

选项 D 错误。RFID 干扰（Jamming）涉及干扰 RFID 信号使其无法工作，复制 RFID 细节供未经授权的使用。

问题 328。某大公司的一员工最近从网站在其公司配发的移动设备上安装了一个应用，而不是通过批准的应用商店。该应用声称有助于提高生产力，但不久后，发现移动设备上的敏感数据被传输到一个未知服务器。利用了什么移动设备漏洞？

- (A) 密码策略不完善
- (B) 开放 Wi-Fi 连接
- (C) 移动设备侧载（Side loading）
- (D) 缺乏移动设备侧载加密

解析 328. 正确答案：C。移动设备侧载。侧载是指从批准的应用商店以外的来源在移动设备上安装应用的操作。这可能会导致设备暴露于未经过安全审查的应用中，导致潜在的数据泄露，正如场景中所描述。

选项 A 错误。虽然密码策略不完善可能会导致设备遭受未经授权的访问，但场景特别提到了从未批准的源安装了应用，这指向了侧载。

选项 B 错误。开放 Wi-Fi 连接可能会让移动设备面临威胁，但场景中描述的主要问题围绕从未批准源安装应用展开。

选项 D 错误。虽然移动设备加密对保护数据至关重要，但场景中的问题与侧载有关，与设备的加密状态无关。

问题 329。用户报告说，每当他们尝试访问在线银行网站时，都会被重定向到一个看起来完全相同但 URL 略有不同的网站。假网站要求提供银行从未请求过的额外个人详情。用户可能遇到的是哪种 DNS 攻击？

- (A) DNS 隧道（DNS Tunneling）
- (B) DNS 快速变化（DNS Fast Flux）
- (C) DNS 缓存毒（DNS Cache Poisoning）
- (D) 域名劫持（Domain Hijacking）

解析 329. 正确答案：C。DNS 缓存毒。DNS 缓存毒（也称为 DNS 欺骗）涉及破坏 DNS 解析器中的 DNS 缓存数据，将用户重定向到恶意网站而不是实际的预期网站。

选项 A 错误。DNS 隧道是一种将非 DNS 流量封装在 DNS 协议中的技术。它是绕过网络安全的方法，但通常不会导致所描述的重定向场景。

选项 B 错误。DNS 快速变化涉及快速更改与域名关联的 IP 地址，以隐藏其背后的恶意服务器。它用于防止恶意域名被封禁，但不会导致重定向到类似的站点。

选项 D 错误。域名劫持涉及在未经所有者许可的情况下通过更改其注册数据来获得对域名的控制。虽然这可能导致类似的结果，但场景描述的是只有用户被重定向的情况，而不是域的所有访问者。

问题 330。一个 IT 安全团队收到报告，称一种新的、此前未知的漏洞正在野外被积极利用。软件供应商尚未为该漏洞提供补丁。对于这种漏洞最准确的术语是什么？

- (A) 遗留漏洞（Legacy vulnerability）
- (B) 零日漏洞（Zero-day vulnerability）
- (C) 已修补漏洞（Patched vulnerability）
- (D) 已知漏洞（Known vulnerability）

解析 330. 正确答案：B。零日漏洞。零日漏洞是指软件、硬件或固件中供应商未知的缺陷。这种漏洞之所以是一种风险，是因为在发现时没有修复程序或补丁，而且它可能已经被恶意攻击者积极利用。

**选项 A 错误。** 遗留漏洞通常指旧软件或系统中的漏洞，这些系统可能不再受到支持，而不一定是未知且未修补的缺陷。

**选项 C 错误。** 已修补漏洞意味着该缺陷已经有了修复方法。在提供的场景中，尚未发布补丁。

**选项 D 错误。** 虽然该漏洞对某些实体可能是知的（例如场景中的安全团队），但对于软件供应商来说仍然是知的。因此，在这种语境下，“已知漏洞”不是最准确的描述。

问题 331。一个在线支付网关正在评估增强其支付处理系统安全的方法。他们希望有一种解决方案，将敏感的持卡人数据替换为本身没有内在价值的唯一标识符。他们应该实施哪种方法？

- (A) 对卡数据进行哈希（Hashing）
- (B) 对卡数据进行加密（Encryption）
- (C) 对卡数据进行掩码（Masking）
- (D) 对卡数据进行令牌化（Tokenizing）

解析 331. 正确答案：D。对卡数据进行令牌化。令牌化涉及将敏感数据替换为非敏感等等物（令牌），令牌没有外部或可利用的意义或价值。

**选项 A 错误。** 哈希会产生一个固定大小的字符串，它无法还原为原始值，但它并没有创建一个可以换回原始数据的“令牌”。

**选项 B 错误。** 加密将数据转换为另一种形式或代码，以便只有访问秘密密钥或密码的人才能读取它。它没有将数据替换为没有内在价值的唯一标识符。

**选项 C 错误。** 掩码涉及隐藏部分数据，例如显示信用卡卡的最后四位。它没有将数据替换为唯一标识符。

问题 332。一家跨国公司使用加密在其分公司之间传输敏感信息。内部审计显示，所使用的加密算法是多年前就被弃用的算法。该机构最暴露于以下哪种加密漏洞？

- (A) 密钥生成缺陷
- (B) 易受攻击的算法
- (C) 公钥基础设施不足
- (D) 加密密钥管理

解析 332. 正确答案：B。易受攻击的算法。当一个机构被发现使用过时的或旧的加密算法时，意味着它们依赖的加密方法由于计算和密码分析的发展可能更容易破解。随着时间的推移，某些算法被发现存在缺陷并被更强大的算法取代。

选项 A 错误。场景没有指定密钥生成的问题，而是关注过旧算法的使用。

选项 C 错误。场景中没有信息表明机构的公钥基础设施存在问题。

选项 D 错误。虽然密钥管理至关重要，但场景中的主要问题围绕使用弱算法。

问题 333。在季度审查期间，物流公司的 IT 团队决定更改负载负载器的配置，以便在服务器之间更好地平衡流量。更改后出现了一系列技术问题，影响了面向客户的应用程序。在排除故障时，发现网络图未更新以反映新更改。在这种情况下，没有更新的图表的主要后果是什么？

- (A) 服务器可能需要硬件升级
- (B) 公司可能需要恢复到旧的负载均衡器配置
- (C) 它增加了时间及复杂性
