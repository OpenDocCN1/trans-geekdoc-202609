
解析 298. 正确答案：A。权限提升漏洞。权限提升漏洞允许攻击者在系统内增加权限，通常会赋予他们比预预期更多的访问权限。场景描述了用户账户及其权限可以被修改的情况，这与该分类相符。

选项 B 错误。泄露漏洞涉及对信息的未经授权的访问，但不涉及对用户权限或数据的修改。

选项 C 错误。重放漏洞发生在攻击者捕获并在稍后重新传输有效数据传输以欺骗系统时，这在给定的场景中并未被描述。

选项 D 错误。远程代码执行漏洞允许攻击者在目标系统上执行任意命令或代码。虽然这些可能非常严重，但给定的场景专门描述的是权限更改，而不是任意代码执行。

问题 299. 一家电子商务公司正在推出一个新的 Web 应用程序以便支付。IT 部门希望立即收到任何应用程序错误或对应用程序代码库的未经授权的通知。他们应该实施以下哪个工具？

- (A) Web 应用防火墙 (WAF)
- (B) 应用性能监控 (APM)
- (C) 域名系统 (DNS) 监控工具
- (D) 网络流量分析器

解析 299. 正确答案：B。应用性能监控 (APM)。APM 工具旨在监控应用程序的性能，并检测应用程序错误、异常和未经授权的代码更改，从而确保应用程序的稳定性和安全性。

选项 A 错误。虽然 WAF 通过过滤和监控 HTTP 流量保护 Web 应用程序免各种网络威胁，但它通常不监控应用程序错误或未经授权的代码更改。

选项 C 错误。DNS 监控工具侧重于确保 DNS 服务的可用性和完整性，不监控应用程序性能或代码库更改。

选项 D 错误。网络流量分析器检查网络上的数据流，但并不专门监控应用程序性能或代码库修改。

问题 300. 一位安全分析师正在探索主动识别组织基础设施内漏洞的方法。以下哪种方法是该分析师从暗网接收实时威胁情报的**最佳**方法？

- (A) 在该组织的内部网络上使用漏洞扫描器
- (B) 订阅暗网威胁情报馈送
- (C) 对外部系统进行定期渗透测试
- (D) 审查组织 SIEM 系统的每日报告

解析 300. 正确答案：B。订阅暗网威胁情报馈送。威胁情报馈送（特别是专注于暗网的馈送）提供了有关新兴威胁和漏洞的实时信息。这种主动方法允许分析师在潜在威胁影响组织之前就意识到这些威胁。

选项 A 错误。虽然漏洞扫描器在识别网络内的已知漏洞方面有效，但它们不能提供来自暗网等外部源的实时威胁情报。

选项 C 错误。渗透测试对于识别系统和应用程序中的漏洞确实有用。但它们并没有专门提供来自暗网的威胁情报。

选项 D 错误。SIEM 系统聚合并分析来自各种源的日志数据以识别并响应安全事件。虽然它们可以对环境内的当前威胁报警，但它们不提供实时暗网威胁情报。
