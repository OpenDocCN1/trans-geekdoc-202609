**Question 418.** You are an IT security professional for a large corporation. After receiving reports about some users being unable to access external websites, you decided to review the firewall logs. Which of the following would be a PRIMARY indicator in the logs that a rule is blocking outbound traffic?

+   (A) Multiple entries of the same external IP address being ALLOWED

+   (B) Timestamps showing large gaps between entries

+   (C) Entries showing DROP/REJECT action for outbound traffic to port 80 and 443

+   (D) Logs showing inbound traffic from multiple unknown IP addresses

**Explanation 418.** **Correct Answer: C. Entries showing DROP/REJECT action for outbound traffic to port 80 and 443.** Port 80 and 443 are standard ports for HTTP and HTTPS respectively, which are commonly used for accessing websites. If users are unable to access external websites, it would make sense to check for DROP or REJECT actions for these ports in the firewall logs.
