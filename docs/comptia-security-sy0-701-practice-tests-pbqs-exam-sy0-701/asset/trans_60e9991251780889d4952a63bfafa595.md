问题 233. 医疗机构 SafeMed 使用一种带有嵌入软件的救命医疗设备。最近，在该软件中发现了一个安全漏洞，但由于设备的 FDA 监管状态和软件的设计，无法立即进行补丁修复。SafeMed 如何处理与该设备相关的安全担忧？

- (A) 将设备与所有网络断开并仅以单机模式使用
- (B) 告知患者该漏洞情况并让他们自行决定是否使用该设备
- (C) 实现网络分段并严格控制对设备的访问
- (D) 将设备退回制造商以获得全额退款

题释 233. 正确答案：C。实施网络分段并严格控制对设备的访问。通过实施网络分段，SafeMed 可以将漏洞设备与其他网络部分隔离开，降低潜在被利用的风险。严格控制访问可确保只有授权的人员才能使用或与设备交互。

选项 A 错误。完全断开设备可能会限制其功能，特别是当它需要网络访问来进行更新、数据传输或其他基本操作时。

选项 B 错误。虽然透明度很重要，但在不采取保护性措施的情况下仅仅告知患者可能不足以确保安全，并可能导致恐慌或信息误导。

选项 D 错误。退回设备可能不可行，特别是当没有现可可用替代品时，而且设备对患者护理至关重要。

问题 234. 一个智能城市项目正在全范围内部署各种 IoT 传感器，以收集有关交通模式、天气、污染水平等的数据。在部署这些传感器时，以下哪项是最关键的安全考量？

- (A) 确保高数据传输速度以满足来自 IoT 传感器的大量数据
- (B) 限制 IoT 设备仅与特定的、预定义的服务器进行通信
- (C) 在 IoT 设备上安装物理锁以防盗窃
- (D) 允许 IoT 设备连接到任何可用网络以实现数据冗余

题释 234. 正确答案：B。限制 IoT 设备仅与特定的、预定义的服务器进行通信。通过限制 IoT 设备仅与特定的、受信任的服务器通信，可以最大限度地减少未经授权的访问和数据篡改的风险。此措施确保了数据只发送到合法来源并接收自合法来源。

选项 A 错误。虽然数据传输速度对于性能和实时分析很重要，但从安全角度来看，数据的完整性和机密性更为关重要。

选项 C 错误。虽然物理安全是一个必不可少的方面（特别是在公共环境中），但 IoT 最重风险通常涉及数据安全和未经授权的访问。

选项 D 错误。允许 IoT 设备连接到任何可用网络可能会引入严重的安全漏洞，例如中间人攻击、窃听或未经授权的数据篡改。

问题 235. 一家跨国公司正寻求更换其全球所有分支机构的防火墙。IT 总监希望有一种解决方案能够执行数据包的状态检测、应用级过滤，并集成威胁情报馈送以更新威胁意识。以下哪种方案将是最合适的？

- (A) 状态检测数据包防火墙 
- (B) 代理服务器 
- (C) Web 应用防火墙 (WAF)
- (D) 下代防火墙 (NGFW)

题释 235. 正确答案：D。下代防火墙 (NGFW)。下代防火墙 (NGFW) 设计旨在提供状态检测功能，并还具备应用级过滤以及集成威胁情报馈送的能力。

选项 A 错误。状态检测数据包防火墙可以监控连接状态，但它不具备应用级过滤或集成威胁情报的高级功能。

选项 B 错误。代理服务器用于 Web 访问并过滤请求，但不具备 NGFW 那样的全面功能。

选项 C 错误。Web 应用防火墙 (WAF) 专门保护 Web应用程序。它不具备 NGFW 的功能范围。

问题 236. 一个拥有多个分支机构的跨国组织希望简化其 WAN 连接并降低成本，同时确保办公室间的数据传输安全。哪种技术最符合他们的需求？

- (A) VLAN
- (B) MPLS
- (C) SD-WAN
- (D) DMZ

题释 236. 正确答案：C。SD-WAN。软件定义广域网 (SD-WAN) 可以利用包括 MPLS、LTE 和宽带互联网在内的任何传输服务组合来安全地连接用户。SD-WAN 可以通过使用廉价的互联网连接降低成本，并能简化 WAN 管理。

选项 A 错误。VLAN 用于将局域网划分不同的广播域，但无法促进 WAN 连接。

选项 B 错误。MPLS 是一种 WAN 技术，费用较高。虽然它提供了可靠且快速的连接，但不具备 SD-WAN 的成本效益和灵活性。

选项 D 错误。DMZ（非军事区）是组织内部网络与外部不受信任网络之间的缓冲区。它与 WAN 连接或降低成本无关。

问题 237. 一家金融公司希望通过拦截和检查 Web 流量来提高网页浏览安全性，防止用户访问恶意网站或下载恶意软件。他们正在寻找一种能够作为客户端请求其他服务器资源时的中间节点的解决方案。公司应该实施什么？

- (A) 网络 IDS
- (B) VPN 集中器
- (C) 代理服务器
- (D) 跳板服务器

题释 237. 正确答案：C。代理服务器。代理服务器作为用户计算机和互联网之间的中间节点。它可以拦截 Web 请求并提供过滤 Web 内容、缓存 Web 请求以及出于安全原因检查流量的功能。

选项 A 错误。网络入侵检测系统 (IDS) 监控并检测网络上的恶意活动，但并不作为 Web 请求的中间节点。

选项 B 错误。VPN 集中器为组织网络提供安全的远程访问，但不作为网页浏览请求的中间节点。
