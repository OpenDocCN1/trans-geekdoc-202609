
解析 215。正确答案：B。为文件服务器实施访问控制列表（ACL）。访问控制列表（ACL）定义了谁可以访问资源以及他们在访问后可以对资源执行的操作。通过为文件服务器设置 ACL，公司可以精确地定义人力资源部门和 IT 部门的权限，确保只有授权用户才有权以相应的级别访问数据。

选项 A 错误。安装防火墙会限制部门之间的网络流量，但无法提供对服务器上文件进行细粒度的访问控制。

选项 C 错误。虽然强力密码策略对于安全至关重要，但它无法区分人力资源部门和 IT 部门之间的访问，也无法控制用户在访问服务器后可以的操作。

选项 D 错误。全磁盘加密保护静态数据的安全，但它无法根据用户规则对特定文件或目录提供差异化访问。

问题 216。某电子商务网站突然流量激增，导致网站运行缓慢且有时无法访问。IT 团队观察到，大量请求源自分布在不同国家的 IP 地址。该电子商务网站可能正在经历哪种网络攻击？

- (A) 中间人攻击
- (B) DNS 欺骗
- (C) 分布式拒绝服务（DDoS）攻击
- (D) ARP 投毒

解析 216。正确答案：C。分布式拒绝服务（DDoS）攻击。在 DDoS 攻击中，攻击者利用多个系统（通常是来自不同位置受入侵系统）向目标系统发送大量请求，导致目标系统缓慢或无法访问。

选项 A 错误。中间人攻击涉及攻击者秘密地拦截并可能篡改双方之间的通信。它不会由于高流量导致网站无法访问。

选项 B 错误。DNS 欺骗是指攻击者引入损坏的 DNS 缓存信息，以将流量重定向到不同的 IP 地址（通常由攻击者控制）。它不会导致来自不同国家的流量增加。

选项 D 错误。ARP 投毒是一种攻击者通过向局域网发送伪造 ARP 消息的技术。这通常用于将攻击者的 MAC 地址与另一个主机的 IP 地址绑定，导致任何发往该 IP 地址的流量都被发送给攻击者。

问题 217。安全审计员发现网站的登录表单返回详细的错误信息，如“列名错误”或“未找到表”。攻击者可能利用这些信息利用哪种漏洞？

- (A) 暴力破解攻击
- (B) 结构化查询注入（SQLi）
- (C) 中间人攻击
- (D) 会话劫持

解析 217。正确答案：B。结构化查询注入（SQLi）。当网站提供详细的数据库错误信息时，它可以给攻击者提供有关数据库结构的线索，使他们更容易构建出成功的 SQL 注入攻击。

通过返回详细的数据库错误信息，网站在无意中为攻击者提供了有关数据库结构和潜在漏洞点的宝贵见解。这可以被用于精炼和增强 SQLi 攻击，使攻击者能够访问、修改或删除数据。

选项 A 错误。暴力破解攻击涉及尝试许多密码或短语以猜出正确的。数据库的详细错误信息通常不用于暴力破解。

选项 C 错误。中间人攻击拦截并可能篡改双方之间的通信。数据库错误信息与此类攻击没有直接关系。

选项 D 错误。会话劫持涉及接管活动的用户会话。详细的数据库错误信息在此类攻击中不起直接作用。

问题 218。某大型公司的一名员工最近从网站为公司配发的移动设备安装了一个 App，而不是通过批准的应用商店。该 App 声称能帮助提高效率，但不久后，发现移动设备上的敏感数据被传输到未知服务器。利用了哪种移动端漏洞？

- (A) 密码策略不完善
- (B) 无线连接连接
- (C) 侧载攻击
- (D) 缺乏加密

解析 218。正确答案：C。侧载攻击（Sideloading）指的是从官方应用商店之外的来源安装应用。该场景涉及从非授权来源安装 App。

选项 A 错误。密码策略不完善与从非官方商店安装应用无关。

选项 B 错误。无线连接不安全可能导致数据泄露，但场景描述的是安装未经审核的应用。

选项 D 错误。缺乏加密是关于数据传输，而非安装未经审核的应用。

问题 219。XYZ 公司的 IT 部门发现服务器日志在非工作时间记录了登录尝试，且这些尝试发生在异常时间段。以下哪项是该现象最合理的解释？

- (A) 员工正在加班
- (B) 服务器存在时区配置错误
- (C) 未授权用户正尝试访问
- (D) 服务器正在自动安装补丁

解析 219。正确答案：C。未授权用户正尝试访问。非工作期间的异常登录尝试通常是恶意访问的迹象。

选项 A 错误。虽然员工可能会加班，但这通常不会解释日志中记录的异常访问模式。

选项 B 错误。时区配置错误可能导致日志时间显示错误，但不会产生大量的登录尝试记录。

选项 D 错误。服务器自动安装补丁不会产生此类登录尝试记录。

问题 220。一名员工注意到，当在使用 RFID 卡进入办公楼时，有一个陌生人拿着一个不熟悉的设备离她非常近。几天后，她同事的卡突然失效了，尽管卡并未报告丢失或损坏。安全团队应该怀疑是哪种类型的攻击？

- (A) 访问控制系统的暴力破解攻击
- (B) RFID 克隆攻击
- (C) 尾随入侵
- (D) RFID 干扰

解析 220。正确答案：B。RFID 克隆攻击。RFID 克隆涉及对 RFID 卡进行非法复制，或通过捕获其信号来实现。那个陌生人拿着设备离得很近可能是捕获了 RFID 信号进行克隆。

选项 A 错误。访问控制系统的暴力破解攻击涉及尝试多种组合以获取权限，场景并未描述多次访问尝试或与系统本身的交互。

选项 C 错误。尾随入侵（Tailgating）是在没有相应权限的情况下跟随授权人员进入安全区域。场景描述的是可能的 RFID 获取，而非跟随他人。

选项 D 错误。RFID 干扰是指干扰 RFID 信号使其无法工作，而不是复制 RFID 详情进行非法使用。
