
解析 581. 正确答案：B。在边界防火墙和内部网络之间监控经过过滤的流量。通过将 IDS 放置在防火墙和内部网络之间，它可以监控通过防火墙过滤器的流量。这个位置在捕捉潜在威胁和减少来自良外部流量的误报之间取得了平衡。

选项 A 错误。虽然将 IDS 放置在防火墙之前会捕获所有入站流量，但可能会导致大量的误报，因为许多良流量可能会触发报警。

选项 C 错误。仅将 IDS 放置在 DMZ（隔离区）会限制其可见性仅限于外部服务请求，而无法涵盖可能存在潜在威胁的内部流量。

选项 D 错误。虽然在每个工作站上部署个人 IDS 可以提供细粒度的监控，但它无法提供网络活动的全局视图，并且可能会消耗大量资源。

问题 582。AlphaTech 希望确保其远程员工在居家办公时遵循最佳安全实践。安全团队被指派起草一套远程工作指南。这些指南的主要关注点应该是什么？

- (A) 概述对违规行为的惩罚措施
- (B) 阐述公司对远程工作的法律立场
- (C) 为家庭网络和设备建议安全措施
- (D) 规定远程工作人员的精确软件和硬件规格

解析 582. 正确答案：C。为家庭网络和设备建议安全措施。

指南旨在提供建议和推荐。在远程工作的语境下，它们会建议保护家庭网络和设备的最佳安全实践，而不会过度强制。

选项 A 错误。惩罚措施和合规性后果通常在政策或程序中概述，而不是指南中。

选项 B 错误。公司对远程工作的法律立场应该是政策或法律文件的一部分，而不是一套指南。

选项 D 错误。规定精确的软件和硬件规格更符合“标准”定义而非“指南”。指南会提供更广泛的建议。

问题 583。XYZ Corp 的事件响应团队收到报告，称一名攻击者成功利用了其环境中一个漏洞的 Web 应用程序。为了确定哪些服务器可能被攻破，团队决定交叉引用最近的漏洞扫描结果。漏洞扫描中的以下哪些信息对于确定可能被攻破的服务器**最有帮助**？

- (A) 执行扫描的时间戳
- (B) 扫描工具的软件版本
- (C) 具有与攻击相关的特定漏洞的主机列表
- (D) 扫描期间识别的漏洞总数

解析 583. 正确答案：C。具有与攻击相关的特定漏洞的主机列表。在给定的场景中，为了确定哪些服务器可能被攻破，团队应该关注那些在漏洞扫描中识别出的具有与攻击者利用的漏洞相同的特定漏洞的主机。

选项 A 错误。虽然时间戳可能指示扫描执行的时间，但无法提供关于哪些服务器具有报告攻击相关漏洞的具体信息。

选项 B 错误。知道扫描工具的软件版本无法帮助识别可能被攻破的服务器。

选项 D 错误。识别出的漏洞总数没有帮助确定特定的服务器；它只提供了安全态势的高层级概述。

问题 584。在进行例行安全审查时，安全专家 Jake 发现组织财务系统中被放置了一段意外的数据。在询问后，他获知这段数据是特意放置并监控的，以查看是否有未经授权的用户或系统与其进行交互。这种欺骗性数据被称为什么？

- (A) Honeystring（蜜罐字符串）
- (B) Honeytoken（蜜罐令牌）
- (C) Canary token（金丝雀令牌）
- (D) Security marker（安全标记）

解析 584. 正确答案：B。Honeytoken。

Honeytokens 是策略性放置的欺骗性数据，没有实际价值或现实用途，但会被严密监控。它们的唯一目的是检测未经授权的交互，因为对 honeytoken 的任何访问或使用都可能是恶意或未经授权的。

选项 A 错误。在描述的语境下，并没有通用的“Honeystring”安全术语。

选项 C 错误。Canary tokens 是特定的 honeytoken，可以实现相同的目的。但根据提供的选项和问题的背景，“Honeytoken”是最准确的答案。

选项 D 错误。从广义上讲，安全标记可以是任何用于安全目的标记或指示，但它不是专门放置用于检测未经授权访问的欺骗性数据。

问题 585。DeltaCorp 执行了密码策略，强制用户每 30 天更改一次密码。然而，一些用户抱怨这导致他们选择更简单的密码或将其写下来记忆。DeltaCorp 如何在解决这些问题的同时维护安全性？

- (A) 减少密码更改频率，但引入更复杂的复杂度要求
- (B) 取消密码更改并完全依赖双重身份验证
- (C) 要求用户每周更改密码以提高安全性
- (D) 允许用户重用最后三个密码中的任何一个以便过渡

解析 585. 正确答案：A。减少密码更改频率，但引入更复杂的复杂度要求。

通过减少密码更改的频率，减轻了用户频繁记忆新密码的负担。增加复杂度要求可以确保密码足够强度，从而补偿更长的有效期。

选项 B 错误。完全依赖双重身份验证（2FA）而没有任何密码要求，如果 2FA 方法被破解，可能会引入风险。此外，2FA 对用户可能不方便。

选项 C 错误。要求用户更频繁地更改密码会加剧问题，并可能导致更糟糕的密码习惯。

选项 D 错误。允许用户重用近期密码会破坏更改密码的初衷，并降低整体安全性。

问题 586。某软件公司最近在其热门应用程序中发现了一个漏洞，该漏洞允许未经访问用户数据。在公司发布补丁之前，一组黑客利用了该漏洞，但仅是为了通知用户。他们没有滥用任何数据。该小组行为背后最可能的动机是什么？

- (A) 通过出售数据获取财务利益
- (B) 反对软件公司运营的政治信仰
- (C) 对用户隐私和安全的伦理关注
- (D) 破坏软件公司服务的愿望

解析 586. 正确答案：C。对用户隐私和安全的伦理关注。黑客没有滥用数据，而是选择告知用户该漏洞，这表明他们的动机基于伦理考量，以确保用户意识到其隐私面临的潜在威胁。
