
选项 A 错误。MAC 涉及对信息进行分类并将用户的许可级别与这些分类进行匹配。Jenny 的访问并非基于分类的。

选项 B 错误。RBAC 根据组织内的角色来分配权限。虽然 Jenny 的权限可能与其角色一致，但该场景特别强调授予最少必要的访问，这是“最小权限原则”（Least Privilege）的特征。

选项 C 错误。时段限制（Time-of-Day Restrictions）根据当前时间决定访问权限，与最小权限原则没有直接关系。

第 457 题。某公司正尝试验证一封从高级高管发送给多名员工的邮件合法性。该邮件要求收件者点击链接并为了“系统升级”输入凭据。安全团队想要确定该邮件是否确实来自该高管。在项调查中，以下哪种元数据将**最有帮助**？

- (B) 邮件的发送时间和日期
- (C) 邮件头中的始源 IP 地址
- (D) 邮件的字节大小

解析 457。 正确答案：C。邮件头中的始源 IP 地址。邮件头通常包含邮件的始源 IP 地址。这可以帮助调查人员确定邮件是否是从预期位置发送的，或者是否来自不熟悉或可疑的 IP，这表明可能存在钓鱼尝试。

第 458 题。某云端电子商务公司希望确保每当发生销售时，其库存系统都能自动更新其网站和第三方销售平台上的库存水平。该公司公司应该利用什么来实现这种实时同步？

- (A) 定期备份库存系统并在网站和销售平台上恢复它
- (B) 依赖客户报告库存水平的差异
- (C) 使用应用程序编程接口 (APIs) 将库存系统与网站及第三方平台集成
- (D) 进行每日库存审计并手动更新所有平台

解析 458。 正确答案：C。使用应用程序编程接口 (APIs) 将库存系统与网站及第三方平台集成。使用 API 可以确保系统之间的实时数据同步。每当发生销售，库存系统都可以自动更新所有平台上的库存水平。

**选项 A 错误。** 备份和恢复库存系统是一种被动且效率的方法。它无法提供实时库存更新。

**选项 B 错误。** 依赖客户报告库存差异不是主动的，可能会导致负面的的客户体验和潜在的销售损失。

**选项 D 错误。** 手动更新既耗时又容易产生人为错误，并且不支持实时库存水平同步。

第 459 题。在经历一系列钓鱼攻击后，BetaTech 公司的 IT 部门注意到几名员工在使用可以猜测的密码。安全团队决定建议使用密码管理器来帮助员工创建和记住强密码。在这种背景下，使用密码管理器的**主要**益处是什么？

- (B) 密码管理器可以生成并存储复杂密码
- (C) 密码管理器总是能防止钓鱼攻击
- (D) 密码管理器允许在多个平台重复使用强密码

解析 459。 **正确答案：B. 密码管理器可以生成并存储复杂密码。** 密码管理器可以自动生成符合各种标准的复杂密码（例如长度、使用特殊字符、避免易于猜测的术语），并安全地存储它们。这有助于用户为使用的每个服务维护强且唯一的密码，而无需记住每一个密码。

**选项 A 错误。** 密码管理器的设计目的是生成、检索和存储复杂密码，而不是为了更新操作系统。

**选项 C 错误。** 虽然密码管理器可以通过安全存储密码并在识别的网站上自动填充来帮助降低成功钓鱼攻击的风险，但它们并不总是能防止钓鱼攻击，特别是用户被欺骗在假网站上输入凭据时。

**选项 D 错误。** 密码管理器的主要益处之一是确保用户为每个应用程序或服务都有唯一的密码。在多个平台重复使用密码（即使是强密码）也会带来安全风险。

第 460 题。某公司的在线零售网站面临 DDoS 攻击，导致了严重的停机。他们目前的设置是在部署缓解措施之前对流量峰值进行手动验证。未来哪种变化可以**最有力**提高公司对此类攻击的反应时间？

解析 460。 正确答案：C. 部署具有自动 DDoS 缓解功能的 Web 应用防火墙。部署具有自动 DDoS 缓解功能的 Web 应用防火墙 (WAF) 可以立即检测并缓解攻击流量，与等待手动验证相比，显著提高了了对攻击的反应时间。

选项 B 错误。备份网站数据对于恢复很重要，但它不能防止或缓解活跃的 DDoS 攻击，也无法提高反应时间。

选项 D 错误。仅仅增加带宽可能不足以防御 DDoS 攻击。攻击者仍然可以溢出增加后的容量，而且它没有解决快速检测和缓解的需求。
