
选项 D 错误。SIEM 系统用于日志和事件管理。虽然渗透测试可能会发现各种系统的配置错误，但其主要目的并不是侧重于 SIEM。

问题 354。某机构最近为其关键基础设施收到一个新的软件补丁。在部署到生产环境之前，安全团队想要了解其行为并确保它不包含任何恶意代码。以下哪方法对于安全执行和观察补丁的行为最有效？

- (A) 在维护窗口期间部署补丁
- (B) 在沙箱环境中运行补丁
- (C) 对补丁进行代码审查
- (D) 在虚拟机上安装补丁

解释 354. 正确答案：B。在沙箱环境中运行补丁。在沙箱环境中运行补丁允许安全团队在隔离环境中执行并观察软件的行为，确保它不会干扰或损害实际的生产环境。

选项 A 错误。在维护窗口期间部署补丁可以减少对业务运行的干扰，但无法无法安全地观察补丁的行为。

选项 C 错误。虽然代码审查可以识别补丁中潜在的安全问题，但它可能无法揭示执行时的实际行为。

选项 D 错误。在虚拟机上安装补丁是一种隔离形式，但沙箱提供了一个专门为观察软件行为设计的更具控制性和限制性的环境。

问题 355。GreenTech Inc. 正在向另一公司出售一批旧服务器。在交易之前，他们想要确保这些服务器上的数据是无法追回的，并且能够证明已进行了尽职调查。GreenTech 应该寻求什么来向买家保证数据已正确销毁？

- (A) 服务器的销售收据
- (B) 服务器使用的详细日志
- (C) 数据清理证书（A certificate of data sanitization）
- (D) 服务器的用户手册

解释 355. 正确答案：C. 数据清理证书。来自信誉良好的实体的数据清理证书可以确保服务器上的所有数据都已安全且完全地擦除。此类证书确认了使用了特定技术来确保数据无法追回，从而给买家以信心。

选项 A 错误。销售收据仅证明了交易的发生，但没有解决数据清理或销毁的问题。

选项 B 错误。服务器的使用日志可能会详细说明其运行历史，但无法提供数据销毁的保证。

选项 D 错误。用户手册提供了如何使用服务器的说明，但没有涉及其曾经存储的数据状态或安全性。

问题 356。某金融机构的 CISO Jane 正在监督几台旧服务器的退役。她意识到某些数据必须销毁，而另一些数据由于行业法规必须保留。Jane 应该主要关注哪种原则以确保合规？

- (A) 最小必要原则
- (B) 最小权限原则
- (C) 数据留存策略
- (D) 强制休假政策

解释 356. 正确答案：C. 数据留存策略。数据留存策略专门根据业务需求、法规要求和其他因素定义了数据应该保留多长时间以及存储方式。在服务器退役的背景下，遵循此策略将确保 Jane 符合与数据留存相关的法规。

选项 A 错误。最小必要原则涉及医疗保健领域，指的是仅使用、披露或请求完成特定任务所需的信息量。

选项 B 错误。最小权限原则涉及访问控制，意味着赋予用户执行其工作任务所需的最低访问级别。

选项 D 错误。强制休假政策涉及确保员工休假，以便在他们不在时可能检测到潜在的欺诈活动。它不直接涉及数据留存。

问题 357。领先的软件开发公司 CyberFirm 最近由于新功能和补丁更新了其服务器操作系统。鉴于他们过去建立并部署了安全基准，CyberFirm 接下来应该做什么以确保持续的安全性？

- (A) 对所有服务器进行完全系统重启
- (B) 在不进行任何修改的情况下重新部署相同的基准
- (C) 更新安全基准以包含新配置然后进行部署
- (D) 为服务器实施新的防火墙规则

解释 357. 正确答案：C：更新安全基准以包含新配置然后进行部署。当系统发生重大更新或更改时，相应地审查和更新安全基准至关重要，确保其对当前环境保持相关且有效。在更新基准后，应该重新部署它。

选项 A 错误。完全系统重启没有解决操作系统更新后安全基准的维护问题。

选项 B 错误。在在不进行调整的情况下重新部署相同的基准可能会错过由于操作系统更新所需的特定配置或考虑因素。

选项 D 错误。虽然防火墙规则对于安全至关重要，但它们并不直接解决安全基准的维护和更新。

问题 358。MatrixCorp 最近采用了一种移动策略，为员工提供公司所有设备。这些设备也允许个人使用，但组织保留了管理和监控它们的能力。MatrixCorp 正在使用哪种部署模型？

- (A) 自带设备 (BYOD)
- (B) 自选型设备 (CYOD)
- (C) 公司所有、个人功能许可 (COPE)
- (D) 公共设备部署 (PDD)

解释 358. 正确答案：C. 公司所有、个人功能许可 (COPE)。COPE 模型涉及组织为员工提供公司设备，员工也可以用其处理个人任务。然而，公司保留了完全控制、管理和监控能力。

选项 A 错误。在 BYOD 模型中，员工使用自己的设备进行工作，而不是公司提供的设备。

选项 B 错误。CYOD 允许员工从公司批准的列表中选择设备，但重点在于选择而非对公司设备的个人使用。

选项 D 错误。公共设备部署 (PDD) 不是移动解决方案中认可的部署模型。

问题 359。某公司最近升级了其无线基础设施，并希望确保其无线网络传输的数据使用最新的加密标准进行保护。公司应在其无线接入点配置以下哪项？

- (A) WEP
- (B) WPA
- (C) WPA2
- (D) WPA3

解释 359. 正确答案：D. WPA3。WPA3 是无线保护访问的最新版本，旨在改进 WPA2 的安全性功能。它提供了针对破解攻击的增强保护、卓越的加密方法和更安全的握手。

选项 A 错误。WEP（等效加密）是一种过时且不安全的协议，很容易被破解。不应用于保护无线网络。

选项 B 错误。虽然 WPA（无线保护访问）是对 WEP 的重大改进，但在安全性方面已被 WPA2 和 WPA3 超越。

选项 C 错误。WPA2 多年来一直是一个很强大的标准，但存在 WPA3 解决的漏洞，使得 WPA3 是更安全的选择。

问题 360。某安全分析师正在探索主动识别组织基础设施中漏洞的方法。以下哪种方法是让分析师从暗网获取实时威胁情报的最佳方法？

- (A) 在组织内部网络上利用漏洞扫描器
- (B) 订阅暗网威胁情报馈
- (C) 对面向外部的系统进行定期渗透测试
- (D) 查看组织 SIEM 系统的每日报告

解释 360. 正确答案：B。订阅暗网威胁情报馈。威胁情报馈（特别是针对暗网的馈）提供了有关新兴威胁和漏洞的实时信息。这种主动方法让分析师在潜在威胁影响组织之前就能够知情。

选项 A 错误。虽然漏洞扫描器对于识别网络内的已知漏洞非常有效，但它们不提供来自暗网等外部的实时威胁情报。

选项 C 错误。渗透测试对于识别系统和应用程序中的漏洞确实有用。但它们并没有专门提供来自暗网的威胁情报。
