**问题 343。** GammaTech 正处于部署新应用程序的最后阶段。在部署之前，安全团队希望在不执行代码的情况下检查应用程序的代码，以识别任何潜在的漏洞。团队应该采用哪种漏洞识别方法？

- (A) 渗透测试
- (B) 动态分析
- (C) 静态分析
- (D) 模糊测试

**解释 343. 正确答案：C. 静态分析。** 静态分析涉及在不执行应用程序代码、字节码或二进制代码的情况下对其进行检查。这种方法允许安全团队在应用程序运行之前发现代码库中的潜在安全问题。

**选项 A 是错误的。** 渗透测试涉及积极尝试利用系统或应用程序中的漏洞。它并不关注不执行的代码检查。

**选项 B 是错误的。** 动态分析在应用程序运行时对其进行检查，通过观察其行为识别漏洞。

**选项 D 是错误的。** 模糊测试（Fuzz testing）涉及向程序提供一系列随机输入，以查看是否任何输入会导致崩溃或其他意外行为，帮助识别漏洞。

**问题 344。** 在例行漏洞评估期间，TechInc 发现其系统中存在一个弱点，如果被利用将允许攻击者修改现有的用户账户（包括权限）。哪种分类最能描述这种漏洞？

- (A) 权限提升
- (B) 泄露漏洞
- (C) 重放漏洞
- (D) 远程代码执行漏洞

**解释 344. 正确答案：A. 权限提升漏洞。** 权限提升漏洞允许攻击者增加其在系统内的权限，通常赋予他们比预期更多的访问权限。该场景描述了用户账户及其权限可以被修改的情况，符合这一分类。

**选项 B 是错误的。** 泄露漏洞涉及未经授权访问信息，但不涉及修改用户权限或数据。

**选项 C 是错误的。** 重放漏洞发生在攻击者捕获并在以后重新传输有效的数据传输以欺骗系统，这在给定场景中并未被描述。

**选项 D 是错误的。** 远程代码执行漏洞允许攻击者在目标系统上执行任意命令或代码。虽然这些可能非常严重，但给定的场景描述的是权限更改，而不是任意代码执行。

**问题 345。** 一家医疗机构在各种医疗设备中使用嵌入式系统。他们意识到如果这些系统没有得到妥善保护，可能会带来潜在威胁。在这种背景下，加固嵌入式系统时以下哪项**不是**推荐的做法？

(A) 定期对设备的固件进行补丁更新和升级
(B) 为了方便医疗人员使用，允许对设备进行无限制访问
(C) 禁用设备主要功能不需要的必要和服务功能
(D) 更改默认凭据并在访问设备时使用强且唯一的密码

**解释 345. 正确答案：B. 为了方便医疗人员使用，允许对设备进行无限制访问。**

无限制的访问可能导致无意或故意的配置错误或设备误用，从而损害其安全性。

选项 A 是错误的。定期对固件进行补丁和更新是维护嵌入式系统安全性的关键方面，特别是在威胁不断演变的背景下。

选项 C 是错误的。禁用不必要的服务和功能可以减少攻击面，是系统加固的基本原则之一。

选项 D 是错误的。更改默认凭据并确保使用强且唯一的密码对于防止未经授权的访问至关重要。

**问题 346。** TechSoft Corp. 正在实施一个新的资产跟踪系统以监控其庞大的计算资源。以下哪项应该是维护最新的硬件和软件清单的**主要**原因？

(A) 确保软件许可证按时续期
(B) 及时识别并响应未经授权的设备或软件
(C) 辅助新硬件和软件的采购
(D) 让员工了解可用资源

**解释 346. 正确答案：B. 及时识别并响应未经授权的设备或软件。**

虽然所有选项都有维护清单的理由，但从安全的角度来看，及时识别未经授权的设备或软件至关重要。未经授权的设备或软件可能会带来重安全风险，包括潜在的数据泄露或恶意软件感染。

选项 A 是错误的。虽然续期软件许可证很重要，但它不是维护清单的主要安全原因。

选项 C 是错误的。采购决策虽然受益于清单数据，但它们不会像识别未经授权资产那样直接影响紧迫的安全关注问题。

选项 D 是错误的。虽然让员工了解资源是有益的，但对于安全而言，它并不像及时识别未经授权资产那样至关重要。

**问题 347。** 一家企业正在多个办公地点部署基于 IoT 的安全摄像头。作为首席安全专业人员，你会优先考虑哪种建议来为这些设备建立安全基准？

- (A) 将设备设置为公共模式，以便所有员工都能访问视频流以实现透明化
- (B) 定期更新设备固件以修复已知漏洞
- (C) 启用即插即用 (UPnP) 以确保网络上所有设备的于连接
- (D) 为所有摄像头使用相同的密码以便管理

**解释 347. 正确答案：B. 定期更新设备固件以修复已知漏洞。** 定期更新固件可确保 IoT 设备受到已知漏洞的保护，有助于维护其安全态势。

选项 A 是错误的。将设备设置为公共模式可能会导致隐私泄露和未经授权的访问。

选项 C 是错误的。UPnP 可能会通过自动打开端口并允许设备设置其配置而引入漏洞。

选项 D 是错误的。为所有设备使用相同的密码会产生单点故障。如果一个设备的密码被破解，所有设备都将面临危险。
