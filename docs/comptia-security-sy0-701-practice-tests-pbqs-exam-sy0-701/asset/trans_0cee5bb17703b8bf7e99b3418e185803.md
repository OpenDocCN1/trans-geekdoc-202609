**问题 12。** 一家电子商务公司遭遇了分布式拒绝服务（DDoS）攻击，导致其网站无法访问数小时。为了减轻未来此类攻击的影响，以下哪项是**最合适**的纠正性控制？

- (A) 在网站上显示第三方安全认证标志
- (B) 建立具有 DDoS保护的 Web防火墙 (WAF)
- (C) 对网站进行定期漏洞评估
- (D) 为网站管理员实施强密码策略

# 解释 12. 正确答案：B。建立具有 DDoS保护的 Web防火墙 (WAF)。

具有 DDoS保护的 Web防火墙 (WAF) 可以识别并过滤掉与 DDoS 攻击相关的恶意流量。作为一项纠正性控制，它可以帮助在攻击期间之后减轻影响并恢复正常。

选项 A 是错误的。在网站上显示第三方安全认证标志起到威慑作用，向访问者和潜在攻击者证明该网站遵循安全标准。但它不能减轻或修正 DDoS 攻击的影响。

选项 C 是错误的。定期进行漏洞评估是一项检测性控制，有助于识别漏洞。虽然它对整体安全至关重要，但它并不直接修正或减轻 DDoS 攻击的影响。

选项 D 是错误的。为网站管理员实施强密码策略是一项预防性控制。它确保了管理员账户的安全，但没有解决由 DDoS 攻击引起的问题。
