
-   [方程上文所定义的向量用于更新嵌入，如图 [Fig. 3](#Ch004_59-79_S0169716123000032.xhtml#f0020) 所示。如图所示，在梯度下降过程中，负样本受到 `f[*n*]` − `f[*a*]` 的力的作用，向远离 `f[*a*]` 的方向径向推动；而正样本则受到 `f[*a*]` − `f[*p*]` 的力向 `f[*a*]` 拉近。值得注意的是，即使锚点在径向方向上被负样本推开，正样本并未经历相同的径向向外的推力。这是因为三元组损失的表述并未显式强制锚点与负样本之间的径向分离。Triplet Loss 另一个重要的方面是边界 `α`。可以把 `α` 看作锚点‑正样本与锚点‑负样本距离之间需要达到的最小分离距离。若两对之间的距离超过 `α`，则损失项会归零。通常 `α` 被视为超参数，根据数据集、网络结构等因素进行选取。因此，为了构建高度可分离的嵌入空间，选择具有信息性的三元组样本至关重要。这里的“信息性三元组”指的是在数据集中，其内部距离违背边界 `α` 的三元组。寻找这类样本以获得更好的优化过程通常被称为样本采矿（sample mining）或采样。

在本例中，最直接的方法是使用当前网络模型对整个数据集的特征表示进行相似度计算，从而离线确定所有具有信息性的三元组。虽然这种方法概念简单，但随着数据集规模扩大，计算开销往往变得不可行。另一种常见做法是仅在小批本 `B` 中计算样本之间的相似度，只考虑小批本内部的特征，从而限制计算成本。

![Fig. 3 示意图：在三元组损失下，锚点、正样本、负样本的梯度方向。](images/S0169716123000032/f04-03-9780443184307.jpg)

更近期，三元组损失常与单位范数特征一起使用。于是最终的损失公式采用余弦相似度而非欧氏距离，可写作：

$\\begin{array}{r} {\\mathcal{L} = \\left\\lbrack {f\\_{a}.f\\_{n} - f\\_{a}.f\\_{p} + \\alpha} \\right\\rbrack\_{+}} \\\\ \\end{array}$

###  3.3: N‑pair loss

在分析 Triplet Loss 表述时可以注意到，一次更新只会选取一个属于任意负类的负样本。这样可能次优，因为更新仅把锚点与正样本与这一负样本的表示拉开，而我们希望锚点与正样本的表示能够同时与所有其它负类保持距离。虽然在大量 mini‑batch 与多个 epoch 之后，锚点与正样本可能最终与所有其它类别足够分离，但这并不保证。因此，基于 Triplet Loss 的方法往往收敛速度较慢。此外，正如前文所述，大量随机采样的三元组在训练后期往往并不具备信息性，因为需要采矿有信息性的对来提升优化效果。于是，出现了改进 Triplet Loss 以获得更好可分离特征空间的思考。

解决收敛慢问题的一个思路是将多个负样本纳入损失公式（Eq. [5](#Ch004_59-79_S0169716123000032.xhtml#fo0035)）。若我们令特征表示集合 `F[*s*]` = {`f[*a*]^(*i*)`, `f[*p*]^(*i*)`, `f[*n*]¹`, `f[*n*]²`, … `f[*n*]^(*j*)`}，其中 `f[*a*]^(*i*)` 是属于类别 `i` 的样本，`f[*p*]^(*i*)` 是同类的正样本，`f[*n*]¹`、`f[*n*]²` … `f[*n*]^(*j*)` 分别为属于类别 1 到 `j`（不包括类别 `i`）的负样本，则 Eq. [5] 可改写为：

$\\begin{array}{r} {\\mathcal{L} = \\text{log}\\left\\lbrack {1 + \\sum\_{k = 1}^{j}(f\\_{a}^{i}.f\\_{n}^{k} - f\\_{a}^{i}.f\\_{p}^{i})} \\right\\rbrack} \\\\ \\end{array}$

![si16_e](images/S0169716123000032/si16_e.png)  (8)

可以注意到，若只考虑单个负样本，则该损失项实际上退化为 Eq. [7](#Ch004_59-79_S01696716123000032.xhtml#fo0045) ([Fig. 4](#Ch004_59-79_S0169716123000032.xhtml#f0025))：

![Fig. 4 N‑Pair loss 相比 Triplet loss 加入了更多的负样本。](images/S0169716123000032/f04-04-9780443184307.jpg)

[Fig. 4](#Ch004_59-79_S0169716123000032.xhtml#B-f0025) N‑Pair loss 相比 Triplet loss 加入了更多的负样本。

虽然上述公式解决了收敛慢的问题，但计算效率极低。若数据集中类别总数为 `N`，每次更新需要构造大小为 (`N` + 1) 的特征集合。给定小批本大小 `B`，则需要 `B × (N + 1)` 个特征来进行一次梯度更新。更高效的做法是 [Sohn (2016)](#Ch004_59-79_S0169716123000032.xhtml#bb0080) 提出的，即更高效地构造小批本以降低计算成本。每个 mini‑batch 设计为包含每类两个样本，特征集合 `F[*s*]` 可写作 `F[*s*]` = {(`f[*a*]¹`, `f[*p*]¹`), (`f[*a*]²`, `f[*p*]²`), … (`f[*a*]^(*n*), `f[*p*]^(*n*))`}，其大小为 2`N`（`N` 为数据集类别数）。基于 `F[*s*]`，最终的优化目标可表示为：

$\\begin{array}{r} {\\mathcal{L} = \\frac{1}{B}\\sum\_{i = 1}^{B}\\left\\{ {\\text{log}\\left\\lbrack {1 + \\sum\_{i \\neq j}(f\\_{a}^{i}.f\\_{p}^{j} - f\\_{a}^{i}.f\\_{p}^{i})} \\right\\rbrack} \\right\\}} \\\\ \\end{array}$

![si18_e](images/S0169716123000032/si18_e.png)  (9)

可以看到，仅使用 2`N` 个嵌入即可构造所需的特征集合，这在计算上比使用 `B × (N + 1)` 个嵌入更为高效。实际中，类别数往往大于 mini‑batch 大小，此时会随机采样子集类别 `C` < `B` 来构建 mini‑batch。

###  3.4: Multi‑Similarity loss

如前所述，对比度学习的一个重要环节是信息性样本的采矿。Triplet Loss 通过边界 `α` 来挑选具有信息性的三元组，而 N‑pair loss 则通过引入大量负样本来获得更多信息性的对。是否存在更优的方式来采样更具信息性的对呢？
