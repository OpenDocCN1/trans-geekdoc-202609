
# 4: 评估指标

在文献中，广泛使用了各种评估指标（[Beutel et al., 2019](#Ch007_169-221_S0169716123000020.xhtml#bb0105); [Du et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0225); [Garg et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0275)）。虽然一些指标关注在相似样本上实现相似性能（个体公平）([Dwork et al., 2012](#Ch007_169-221_S0169716123000020.xhtml#bb0240))，但其他指标则关注在不同群体间实现相似性能（群体公平）。群体公平指标常用于面部分析任务，其中相同模型在不同人口统计子群之间的性能会被比较。大量指标通过比较预测（记作 *ŷ*）与输入 *x* 的真实结果 *y* 来评估。分类平等基准指标通常使用混淆矩阵。一些指标还利用分类器在预测时产生的分数 *s*。研究人员也在提出新的公平评估指标方面进行探索。我们为在人口统计群体 *g* 中的输入 *x* 定义以下术语，用于后续章节。

*   • True positive rate (TPR)

    *T**P**R* = *p*(*ŷ*\=1|*y* = 1,*G* = *g*) = *T**P*/(*T**P**+**F**N*)

    ![si1\_e](images/S0169716123000020/si1_e.png)  (1)

*   • False positive rate (FPR)

    *F**P**R* = *p*(*ŷ*\=1|*y* = 0,*G* = *g*)= *F**P*/(*F**P**+**T**N*)

    ![si2\_e](images/S0169716123000020/si2_e.png)  (2)

*   • True negative rate (TNR)

    *T**N**R* = *p*(*ŷ*\=0|*y* = 0,*G* = *g*) = *T**N*/(*T**N**+**F**P*)

    ![si3\_e](images/S0169716123000020/si3_e.png)  (3)

*   • False negative rate (FNR)

    *F**N**R* = *p*(*ŷ*\=0|*y* = 1,*G* = *g*) = *F**N*/(*F**N**+**T**P*)

    ![si4\_e](images/S0169716123000020/si4_e.png)  (4)

*   • Positive predictive parity

    *P**P**V* = *p*(*y*\=1|*ŷ* = 1,*G* = *g*) = *T**P*/(*T**P**+**F**P*)

*   • Negative predictive parity

    *N**P**V* = *p*(*y*\=0|*ŷ* = 0,*G* = *g*) = *T**N*/(*T**N**+**F**N*)

###  4.1: 基于分类平等的指标

利用上述定义，我们提供了以下公平指标。它们在二元分类的语境下描述，仅考虑两个人口统计子群，即 *G* = 0 或 *G* = 1（例如 *男性* 和 *女性*）。这些指标可以扩展到多个人口统计子群，并可应用于任何基于分类的应用。

####  4.1.1: 统计平等

确保公平性最早提出的指标之一是统计平等（[Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027); [Verma and Rubin, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1038)）。统计平等要求每个人口统计子群的预测性能相等。它也被称为人口平等（[Calders and Verwer, 2010](#Ch007_169-221_S0169716123000020.xhtml#bb1026)）或群体公平（[Dwork et al., 2012](#Ch007_169-221_S0169716123000020.xhtml#bb0240)）。数学上表示为-

*p*(*ŷ*\=1|*G*\=0) = *p*(*ŷ*\=1|*G*\=1)

![si7\_e](images/S0169716123000020/si7_e.png)  (7)

该指标不考虑真实结果 *y*。

####  4.1.2: 群体影响（DI）

群体影响是衡量统计平等偏差的指标，计算为两个人口统计子群中正分类概率的比值（[Feldman et al., 2015](#Ch007_169-221_S0169716123000020.xhtml#bb1030)）。数学表达式为

*D**I* = *p*(*ŷ*\=1|*G*\=0).*p*(*ŷ*\=1|*G*\=1)

![si8\_e](images/S0169716123000020/si8_e.png)  (8)

较低的群体影响值表明预测中存在更大的偏见。
