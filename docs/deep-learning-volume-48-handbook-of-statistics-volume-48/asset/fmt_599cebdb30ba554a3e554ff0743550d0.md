
At the core of this framework lies a model aggregation scheme (`[Hoffman et al., 2018a](#Ch005_81-105_S0169716122000566.xhtml#bb0075)`; `[Mansour et al., 2009](#Ch005_81-105_S0169716122000566.xhtml#bb0145)`), wherein the key idea is to learn a set of weights {`α[i]`}`[*i* = 1]`^(*n*)![si16_e](images/S0169716122000566/si16_e.png) corresponding to each of the source models such that `α[k]` ≥ 0 and $\\sum\\_{k = 1}^{n}\\alpha\_{k} = 1$![si17_e](images/S0169716122000566/si17_e.png). These weights represent a probability mass function over the source domains, with a higher value implying higher transferability from that particular domain, and are used to combine the source hypotheses accordingly. However, unlike previous works, this work jointly adapts each individual model and simultaneously learn these weights by utilizing solely the unlabeled target instances. In what follows, we describe our training strategy used to achieve this in detail.

###  5.1: Weighted information maximization

Since one does not have access to the labeled source or target data, the authors propose to fix the source classifiers, {`ψ[S]^i`}`[*i* = 1]`^(*n*)![si18_e](images/S0169716122000566/si18_e.png), since it contains the class distribution information of the source domain and adapted solely the feature maps {`ϕ[S]^i`}`[*i* = 1]`^(*n*)![si19_e](images/S0169716122000566/si19_e.png) via the principle of information maximization (`[Bridle et al., 1992](#Ch005_81-105_S0169716122000566.xhtml#bb0025)`; `[Krause et al., 2010](#Ch005_81-105_S0169716122000566.xhtml#bb0105)`; `[Liang et al., 2020](#Ch005_81-105_S0169716122000566.xhtml#bb0125)`; `[Oymak and Gulcu, 2020](#Ch005_81-105_S0169716122000566.xhtml#bb0155)`). The motivation behind the adaptation process stems from the *cluster assumption* (`[Chapelle et al., 2009](#Ch005_81-105_S0169716122000566.xhtml#bb0035)`) in semisupervised learning, which hypothesizes that the discriminative models’ decision boundaries should be located in regions of the input space which are not densely populated. To achieve this, the authors minimize a conditional entropy term (i.e., for a given input example) (`[Grandvalet and Bengio, 2005](#Ch005_81-105_S0169716122000566.xhtml#bb0055)`) as follows:

$\\begin{array}{r} {\\mathcal{L}\_{\\text{ent}} = - \\mathbb{E}\_{x\_{T} \\in \\mathcal{D}\_{T}}\\left\\lbrack {\\sum\\limits\_{j = 1}^{K}\\delta\_{j}(\\theta\_{T}(x\_{T}))\\log(\\delta\_{j}(\\theta\_{T}(x\_{T})))} \\right\\rbrack} \\\\ \\end{array}$

![si20_e](images/S0169716122000566/si20_e.png)  (1)

where $\\theta\_{T}(x\_{T}) = \\sum\_{j = 1}^{n}\\alpha\_{j}\\theta\_{S}^{j}(x\_{T})$![si21_e](images/S0169716122000566/si21_e.png), and *δ*(⋅) denotes the softmax operation with $\\delta\_{j}(v) = \\frac{e^{v\_{j}}}{\\sum\_{i = 1}^{K}e^{v\_{i}}}$![si22_e](images/S0169716122000566/si22_e.png) for *v* ∈ ℝ^(*K*)![si23_e](images/S0169716122000566/si23_e.png). Intuitively, if a source *θ*[*S*]^(*j*)![si24_e](images/S0169716122000566/si24_e.png) has good transferability on the target and consequently has smaller value of the conditional entropy, optimizing the term ([1](#Ch005_81-105_S0169716122000566.xhtml#fo0010)) over {*θ*[*S*]^(*j*),*α*[*j*]}![si25_e](images/S0169716122000566/si25_e.png) will result in higher value of *α*[*j*] than rest of the weights.

While entropy minimization effectively captures the cluster assumption when training with partial labels, in an unsupervised setting, it may lead to degenerate solutions, such as always predicting a single class in an attempt to minimize conditional entropy. To control such degenerate solutions, the authors incorporate the idea of class diversity: configurations in which class labels are assigned evenly across the dataset are preferred. A simple way to encode the preference toward class balance is to maximize the entropy of the empirical label distribution (`[Bridle et al., 1992](#Ch005_81-105_S0169716122000566.xhtml#bb0025)`) as follows,

$\\begin{array}{r} {\\mathcal{L}\_{\\text{div}} = \\sum\\limits\_{j = 1}^{K} - {\\overset{-}{p}}\_{j}\\log{\\overset{-}{p}}\_{j}} \\\\ \\end{array}$

![si26_e](images/S0169716122000566/si26_e.png)  (2)

where $\\overset{-}{p} = \\mathbb{E}\_{x\_{T} \\in \\mathcal{D}\_{T}}\\lbrack\\delta(\\theta\_{T}(x\_{T}))\\rbrack$![si27_e](images/S0169716122000566/si27_e.png). Combining the terms ([1](#Ch005_81-105_S0169716122000566.xhtml#fo0010)) and ([2](#Ch005_81-105_S0169716122000566.xhtml#fo0015)), we arrive at

$\\begin{array}{r} {\\mathcal{L}\_{\\text{IM}} = \\mathcal{L}\_{\\text{div}} - \\mathcal{L}\_{\\text{ent}}} \\\\ \\end{array}$

![si28_e](images/S0169716122000566/si28_e.png)  (3)

which is the empirical estimate of the mutual information between the target data and the labels under the aggregate model *θ*[*T*]. Although maximizing this loss makes the predictions on the target data more confident and globally diverse, it may sometime still fail to restrict erroneous label assignment. Inspired by [Liang et al. (2020)](#Ch005_81-105_S0169716122000566.xhtml#bb0125), the authors propose a pseudo-labeling strategy in an effort to contain this mislabeling.

###  5.2: Weighted pseudo-labeling

As a result of domain shift, information maximization may result in some instances being clubbed with the wrong class cluster. These wrong predictions get reinforced over the course of training and lead to a phenomenon termed as *confirmation bias* (`[Tarvainen and Valpola, 2017](#Ch005_81-105_S0169716122000566.xhtml#bb0210)`). Aiming to contain this effect, the authors adopt a self-supervised clustering strategy (`[Liang et al., 2020](#Ch005_81-105_S0169716122000566.xhtml#bb0125)`) inspired from the DeepCluster technique (`[Caron et al., 2018](#Ch005_81-105_S0169716122000566.xhtml#bb0030)`).

First, calculation the cluster centroids induced by each source model for the whole target dataset is done as follows:

$\\begin{array}{r} {\\mu\_{k\_{j}}^{(0)} = \\frac{\\sum\\limits\_{x\_{T} \\in \\mathcal{D}\_{T}}\\delta\_{k}(\\widehat{\\theta}\_{S}^{j}(x\_{T}))\\widehat{\\phi}\_{S}^{j}(x\_{T})}{\\sum\\limits\_{x\_{T} \\in \\mathcal{D}\_{T}}\\delta\_{k}(\\widehat{\\theta}\_{S}^{j}(x\_{T}))}} \\\\ \\end{array}$

![si29_e](images/S0169716122000566/si29_e.png)  (4)

where the cluster centroid of class *k* obtained from source *j* at iteration *i* is denoted as *μ*[*k*[*j*]]^((*i*))![si30_e](images/S0169716122000566/si30_e.png), and *θ̂*[*S*]^(*j*) = (*ψ*[*S*]^(*j*) ∘ *ϕ̂*[*S*]^(*j*))![si31_e](images/S0169716122000566/si31_e.png) denotes the source from the previous iteration. Assuming feature dimensions are same across all sources, these source-specific centroids are combined in accordance with the current aggregation weights on each source model as follows,

$\\begin{array}{r} {\\mu\_{k}^{(0)} = \\sum\\limits\_{j = 1}^{n}\\alpha\_{j}\\mu\_{k\_{j}}^{(0)}} \\\\ \\end{array}$

![si32_e](images/S0169716122000566/si32_e.png)  (5)

Next, computation of the pseudo-label of each sample is done by assigning it to its nearest cluster centroid in the feature space,

$\\begin{array}{r} {ŷ\_{T}^{(0)} = \\text{arg}\\;\\underset{k}{\\text{min}}\\; \\parallel {\\widehat{\\phi}}\_{T}(x\_{T}) - \\mu\_{k}^{(0)} \\parallel\_{2}^{2}} \\\\ \\end{array}$

![si33_e](images/S0169716122000566/si33_e.png)  (6)

where ${\\widehat{\\phi}}\_{T}(x\_{T}) = \\sum\_{j = 1}^{n}\\alpha\_{j}{\\widehat{\\phi}}\_{S}^{j}(x\_{T})$![si34_e](images/S0169716122000566/si34_e.png). Next, reiteration of this process is done to get the updated centroids and pseudo-labels as follows,

$\\begin{aligned} \\mu\_{k\_{j}}^{(1)} & {= \\frac{\\sum\\limits\_{x\_{T} \\in \\mathcal{D}\_{T}}1\\{ ŷ\_{T}^{(0)} = k\\}{\\widehat{\\phi}}\_{S}^{j}(x\_{T})}{\\sum\\limits\_{x\_{T} \\in \\mathcal{D}\_{T}}1(\\widehat{y^{t\_{0}}} = k)}} \\\\ \\end{aligned}$

![si35_e](images/S0169716122000566/si35_e.png)  (7)
