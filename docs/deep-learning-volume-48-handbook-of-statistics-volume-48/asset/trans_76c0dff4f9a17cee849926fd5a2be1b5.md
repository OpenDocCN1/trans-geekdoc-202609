####  3.1.1: 训练数据集的数值数据集对肿瘤诊断的所有模型性能评估

我们评估了所有三种肿瘤组织数值分子数据集的适用性以及 SNN 和两种机器学习模型在诊断胶质瘤组织的表现。基于胶质瘤患者转录组数据的 SVM、RF 和 SNN 模型在预测肿瘤等级/细胞亚型方面的 AUC 在训练集和盲数据集中的准确率（ACC）相当。此外，三个模型在盲数据集中的准确率显著下降（*ACC*[*blind data*]，SVM = 0.698，RF = 0.632，SNN = 0.670）与训练数据集（*AUC*[*training*]，SVM = 0.883，RF = 0.893，SNN = 0.758）相比。RF 模型在训练 CNV 数据集时预测肿瘤等级的表现相对良好（AUC = 0.927），高于 SVM（AUC = 0.768）和 SNN（AUC = 0.805）模型。然而，RF 模型在盲数据集中应用于 CNV 数据集时，预测肿瘤等级的准确率（ACC = 0.769）较低。在 DNA 甲基化数据集的训练数据集中，SVM、RF 和 SNN 模型的表现也相当。但在盲数据集中，SVM（ACC = 0.653）和 RF（ACC = 0.602）未能达到预期准确率，而 SNN 模型表现出色（ACC = 0.857）。这些结果表明，独立训练的基于全转录组和 CNV 资料的 SVM、RF 和 SNN 模型在诊断胶质瘤患者肿瘤等级方面预测潜力较低。

相反，训练于 DNA 甲基化数据集的深度 SNN 模型在训练集和盲数据集中表现出比 SVM 和 RF 模型更适中的准确率（[Table 4](#Ch006_107-168_S0169716122000578.xhtml#t0025)）。最终，三个模型的准确率在合并多组学数据集中被测量，通过将转录组、CNV 和甲基化数据集合并为单一数据集实现。观察到，SNN 模型在训练（AUC = 0.787）和盲（ACC = 0.846）多组学（ALL）数据集中比 SVM 和 RF 模型表现更好（[Table 4](#Ch006_107-168_S0169716122000578.xhtml#t0025)）。这些观察表明，基于肿瘤组织多组学分子资料训练的深度 SNN 模型在预测胶质瘤患者肿瘤等级或细胞亚型方面可以超越 widely used ML 模型（SVM 和 RF）。

####  3.1.2: 训练数据集的图像数据集对肿瘤诊断的所有模型性能评估

我们还评估了深度 CNN 模型在利用脑肿瘤 MRI 扫描和肿瘤组织整片病理图像对胶质瘤肿瘤分级/细胞亚型进行分类方面的应用和表现（[Table 4](#Ch006_107-168_S0169716122000578.xhtml#t0025)）。训练于 MR 图像的 CNN 模型在训练集（AUC = 0.869）和盲数据集（ACC = 0.890）中的准确率均良好。同样，病理图像的 CNN 模型在训练集（AUC = 0.900）和盲数据集（ACC = 0.810）中也显示出高准确率。深度 CNN 模型（95% CI: 0.87–0.94）在 MR 和 WS 图像数据集上的 AUC 置信区间优于 SNN 模型（95% CI of AUC = 0.77–0.91）在数值多组学分子数据集上的表现，这表明 MR 和病理图像中捕获的复杂肿瘤形态可以用于训练深度神经网络来诊断胶质瘤肿瘤。
