
# 架构图：Variant Input Sequence 模型网络

下面的符号用于描述时间序列中的不同元素。

*`p`* = 视为输入的相互依赖参数的不同数量。

*`n`* = 输入序列中的时间戳数量

*`m`* = 预测的前向时间戳数量

输入参数的值可以表示为 `V[i]`，其中 1 ≤ `i` ≤ `p`。

- 输入序列可表示为  
  - `I` = (`I[0]`, `I[1]`, `I[2]`, …, `I[n]`)

在单变体模型中，输入参数的数量为 1；而在多变量模型中，每个 `Ij` 可以包含按固定顺序排列的多个参数序列。因此可以表示为  

- `I[j]` = (`V[j1]`, `V[j2]`, `V[j3]`, …, `V[jp]`)  
  - 数据以固定间隔捕获，中间的连续时间戳可以表示为  
    - …, `t[(i−1)]`, `t[i]`, `t[(i + 1)`, …

- 不同的 LSTM 模式根据输入数据的时间序列进行分类。在保持超参数（如隐藏层数量以及每个隐藏层的神经元数量）后，这些 LSTM 模型通过不同的度量进行了比较。

在时间分区 LSTM 建模方法中，第一层使用多种基本非集成 LSTM 模式，它们的输出再输入第二层的另一个 LSTM。在解释所有用于分布输入数据的技术细节之前，先介绍该方法的一些基本构件。

在本算法中，模型被设计为可以通过考虑相互依赖变量的列表，成为多变量时间序列预测模型。该模型的算法以四种模式呈现；其中前两种为非集成模式，输入特性不同；后两种为集成模式，如下所述。

**LSTM1**：第一个模型是普通的 LSTM，输入参数按顺序排列。所有这些参数的单实例值依次输入，以在给定的前向时间步产生输出。第一种 LSTM 模式是非集成且非时序的，包含单个时间戳的输入。该模型名为 LSTM1，如 [Fig. 8A](#Ch006_107-168_S0169716122000578.xhtml#f0045) 所示。虽然它不直接使用，但在后续 LSTM 的变体解释中被视为基础。

![Fig. 8 Standard LSTM (A) LSTM1: Multiple variables at single time step (B) LSTM2: Multiple variables at multiple time steps.](images/S0169716122000578/f06-08-9780443184307.jpg)

[Fig. 8](#Ch006_107-168_S0169716122000578.xhtml#B-f0045) Standard LSTM (A) LSTM1: Multiple variables at single time step (B) LSTM2: Multiple variables at multiple time steps.

**LSTM2**：在第二种非集成模式中，输入序列 `I` = `I[0]`, `I[1]`, `I[2]`, …, `I[n]`，其中 `n` 为时间戳数量，且每个 `I[j]` 包含所有参与参数在特定时间戳的子序列，排列顺序固定，可表示为 `I[j]` = `V[j1]`, `V[j2]`, `V[j3]`, …, `V[jp]`。因此，整个输入序列长度为 `p × n`，作为 LSTM 的输入。该模型名为 LSTM2，如 [Fig. 8B](#Ch006_107-168_S0169716122000578.xhtml#f0045) 所示。

时间分区集成技术也是一种稳健的方法，通过对输入序列的不同排列方式（改变连续数据之间的间隔）形成若干独立的输入序列。假设我们有 `q` 个这样的数据序列，构建步骤如下：

1. 第一个 LSTM 直接使用 LSTM2 所用的数据序列，即把 `p` 个输入参数在相同时间戳上的值依次放在一起形成子序列，然后把相邻时间戳的子序列依次排列，形成输入序列。该序列可表示为 `I^(1)` = `I[n]`, `I[n−1]`, `I[n−2]` … `I[0]`。

2. 第二个 LSTM 考虑第一个 LSTM 中使用的交替子序列。目标是通过不同的间隔值来形成完全不同的输入序列。该序列可表示为 `I^(2)` = `I[n]`, `I[n−2]`, `I[n−4]` … `I[0]`（或 `I[1]`）。

3. 第三个 LSTM 通过每次跳过两个子序列来设计，从而产生另一种输入序列形式。该序列可表示为 `I^(3)` = `I[n]`, `I[n−3]`, `I[n−6]` … `I[0]`（或等价形式）。

4. 过程继续进行，直到跳过了 `q` 个子序列，形成 `I^(q)` = `I[n]`, `I[n−q]`, `I[n−2q]` … `I[0]`（或等价形式）。这是最后一个 LSTM 所使用的序列。

由于预测目标是 T 时间步（即 `m` 个时间戳）之后的值，以当前时间戳 `t[n]` 为基准，所有 LSTM 都需要预测 `t[n + m]` 时刻的值。可以用 LSTM2 的通用表达式（Eq. [8](#Ch006_107-168_S0169716122000578.xhtml#fo0045)）表示预测值：

*`V[n + m]^i`* = `LSTM2^i`(`I[n]`, `I[n − i]`, `I[n − 2i]` … `I[(n % i])`)，其中 `i` = 1, 2, 3, …, `q`

![si8_e](images/S0169716122000578/si8_e.png) (8)

这里的 `i` 表示第 `i` 个集成 LSTM。在本研究中，`i` 的最大值为 `q`，即不同集成数据集的总数。为了得到在 `m` 个时间步之后的最终预测值（**`V[n + m]`**^(**f**），所有个体 LSTM 的输出被平均：

$V_{n + m}^{f} = \frac{1}{q}\sum_{i = 1}^{q}V_{n + m}^{i}$

![si9_e](images/S0169716122000578/si9_e.png) (9)

该模式的 LSTM 名为 LSTM3，如 [Fig. 9A](#Ch006_107-168_S0169716122000578.xhtml#f0050) 所示。

![Fig. 9 Architecture of LSTM3 (A) and LSTM4 (B).](images/S0169716122000578/f06-09-9780443184307.jpg)

[Fig. 9](#Ch006_107-168_S0169716122000578.xhtml#B-f0050) Architecture of LSTM3 (A) and LSTM4 (B).

在 LSTM3 中，第一层的输出被平均，以给予所有 LSTM 相等的权重。虽然这在实践中可能不够精准，但实现简单，能够为简单使用案例提供粗略估计。因此，LSTM3 受限于忽略强集成候选者的贡献。为改进该模式，考虑使用加权平均，其中每个集成的贡献根据其单个 LSTM 的能力决定。然而，确定正确的权重存在挑战。该问题通过引入新的 LSTM 解决，该 LSTM 能在第二层自动为隐藏链接的权重赋值，从而生成最终结果。整个网络因此形成层级结构，第一层包含 `q` 个 LSTM，其输出再输入第二层的 LSTM。该模式称为 LSTM4，其示意图如 [Fig. 9B](#Ch006_107-168_S0169716122000578.xhtml#f0050) 所示，并由 Eq. [(10)](#Ch006_107-168_S0169716122000578.xhtml#fo0055) 表示：

*`V[n + m]^f`* = `LSTM`(`V[n + m]^1`, `V[n + m]^2`, … `V[n + m]^q`)
