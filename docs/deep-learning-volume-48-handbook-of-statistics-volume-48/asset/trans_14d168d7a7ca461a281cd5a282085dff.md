
由于缺乏源数据，无法获取源分布的信息，因此采用最不具信息的分布——即根据**最大熵原理**（Principle of Maximum Entropy）选择**均匀分布**（uniform distribution）作为源分布（[Jaynes, 1957](#Ch005_81-105_S0169716122000566.xhtml#bb0095)）。这种均匀性假设适用于目标支持集 𝒳![si6_e](images/S0169716122000566/si6_e.png)。接下来，算法会将源分布在目标支持集 𝒳![si6_e](images/S0169716122000566/si6_e.png) 上的限制进行考虑。数学上，假设 `Q`[*S`]^`(*k`)*(`*x`)* = `c`[*k`]*𝒰`(*x`)*![si67_e](images/S0169716122000566/si67_e.png) 在支持集 `x` ∈ 𝒳![si68_e](images/S0169716122000566/si68_e.png) 上成立，其中 `c`[*k`] 是一个缩放因子，反映源 `k` 的相对贡献，而 𝒰`(*x`)*![si69_e](images/S0169716122000566/si69_e.png) 的取值为 1。将该分布代入 [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010) 中的组合规则，得到 $\\theta\_{T}(x) = \\sum\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}}{\\sum\_{j = 1}^{n}\\lambda\_{j}c\_{j}}\\theta\_{S}^{k}(x)$![si70_e](images/S0169716122000566/si70_e.png)：

$\\begin{array}{ll} {\\theta\_{T}\\left( x \\right)} & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}Q\_{S}^{k}\\left( x \\right)}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}Q\_{S}^{j}\\left( x \\right)}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}\\mathcal{U}\\left( x \\right)}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}c\_{j}\\mathcal{U}\\left( x \\right)}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}c\_{j}}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & \\\\ \\end{array}$

![si71_e](images/S0169716122000566/si71_e.png)  (13)

这一项中 `λ`[*k`] 和 `c`[*k`] 组成的权重项 `α`[*k`] 在 `DECISION` 中起关键作用。下一步是将 `θ`[*T`] 与 `α`[*k`] 以及 `ϕ`[*S`]^`(*k`)*![si72_e](images/S0169716122000566/si72_e.png) 一同用于求解优化问题（[12](#Ch005_81-105_S0169716122000566.xhtml#fo0065)）。因此，`DECISION` 会返回一个满足 [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010) 界限的有利源假设组合，前提是源分布均匀。但如果不假设源分布均匀，则可以通过估计 `Q`[*S`]^`(*k`)*![si50_e](images/S0169716122000566/si50_e.png) 来最小化目标风险，这将在下一节的拟议框架 `DECISION-mlp`（[Fig. 3](#Ch005_81-105_S0169716122000566.xhtml#f0020)）中讨论。

##  7: Source distribution dependent weights (DECISION-mlp)

模型聚合方案中的混合权重（[Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010)）以及 [Mansour et al. (2009)](#Ch005_81-105_S0169716122000566.xhtml#bb0145) 和 [Hoffman et al. (2018a)](#Ch005_81-105_S0169716122000566.xhtml#bb0075) 都依赖于源分布和目标样本。由于缺乏源数据，均匀源分布的假设导致了 [Algorithm 1](#Ch005_81-105_S0169716122000566.xhtml#b0010)。然而，若不假设源分布，仍可通过 MLP 估计其分布。假设有 *n* 个 MLP `ℳ`[*S`]^`(*k`)*∀`*k`* = 1, 2, …*n*![si74_e](images/S0169716122000566/si74_e.png) 来估计 *n* 个源分布（[Fig. 3](#Ch005_81-105_S0169716122000566.xhtml#f0020)）。目标特征通过对每个样本分别通过特征编码器，并将它们拼接成长度为 *d* 的向量，其中 $d = \\sum\_{i = 1}^{n}d\_{i}$![si75_e](images/S0169716122000566/si75_e.png)。若目标样本为 `x`[*T`]^`(*i`)*![si76_e](images/S0169716122000566/si76_e.png)，则拼接向量 `ϕ`(`x`[*T`]^`(*i`))![si77_e](images/S0169716122000566/si77_e.png) 可表示为 `ϕ`(`X`[*T`]^`(*i`))*⊤*∈ℝ^`(*d`)*![si78_e](images/S0169716122000566/si78_e.png)。随后，`ϕ`(`x`[*T`]^`(*i`))*![si77_e](images/S0169716122000566/si77_e.png) 依次输入所有 MLP，得到 *n* 个标量 {`ℳ`[*S`]^`(*k`)*(`ϕ`(`X`[*T`]^`(*i`))`}*[*k* = 1]^`(*n*)![si80_e](images/S0169716122000566/si80_e.png)，这些标量类似于 [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010) 中的 `λ`[*k`]*`Q`[*S`]^`(*k`)*(`x`)*![si81_e](images/S0169716122000566/si81_e.png)。经过归一化后，这些标量模拟了 `α` 的函数形式，既依赖于源分布，也依赖于目标样本。简言之，若第 *i* 个样本在第 *j* 个源上对应的权重为 `α`[*j`]^`(*i`)*![si82_e](images/S0169716122000566/si82_e.png)，则有：

$\\begin{array}{r} {\\alpha\_{j}^{i} = \\frac{\\mathcal{M}\_{S}^{j}(\\phi(x\_{T}^{i}))}{\\sum\\limits\_{k = 1}^{n}\\mathcal{M}\_{S}^{k}(\\phi(x\_{T}^{i}))}} \\\\ \\end{array}$

![si83_e](images/S0169716122000566/si83_e.png)  (14)

在此新设定下，损失函数稍作修改。设 ℒ[ent]^′![si84_e](images/S0169716122000566/si84_e.png)、ℒ[div]^′![si85_e](images/S0169716122000566/si85_e.png) 和 ℒ[pl]^′![si86_e](images/S0169716122000566/si86_e.png) 分别为修正后的熵、多样性和伪标签损失，则有：

$\\begin{array}{r} {\\mathcal{L}\_{\\text{ent}}^{\\prime} = - \\mathbb{E}\_{x\_{T}^{i} \\in \\mathcal{D}\_{T}}\\left\\lbrack {\\sum\\limits\_{j = 1}^{K}\\delta\_{j}(\\theta\_{T}(x\_{T}^{i}))\\log(\\delta\_{j}(\\theta\_{T}(x\_{T}^{i})))} \\right\\rbrack} \\\\ \\end{array}$

![si87_e](images/S0169716122000566/si87_e.png)  (15)

其中 `θ`[*T`](`x`[*T`]^`(*i`))* = ∑`j` = 1`^`n`α`j`*(`i`)*θ`S`*j`(`x`[*T`]^`(*i`))*![si88_e](images/S0169716122000566/si88_e.png)。

$\\begin{array}{r} {\\mathcal{L}\_{\\text{div}}^{\\prime} = \\sum\\limits\_{j = 1}^{K} - {\\overset{-}{p}}\_{j}^{\\prime}\\log{\\overset{-}{p}}\_{j}^{\\prime}} \\\\ \\end{array}$

![si89_e](images/S0169716122000566/si89_e.png)  (16)

其中 `overset{-`}*p`* = E`x`[*T`]^`(*i*)*∈`D`*T`*[`δ`(`θ`*T`(`x`[*T`]^`(*i`))*]![si90_e](images/S0169716122000566/si90_e.png)。

$\\begin{array}{r} {\\mathcal{L}\_{\\text{pl}}^{\\prime}(Q\_{T},\\theta\_{T}) = - \\mathbb{E}\_{x\_{T}^{i} \\in \\mathcal{D}\_{T}}\\sum\\limits\_{k = 1}^{K}1\\{ ŷ\_{T}^{\\prime} = k\\}\\log\\delta\_{k}(\\theta\_{T}(x\_{T}^{i})).} \\\\ \\end{array}$

![si91_e](images/S0169716122000566/si91_e.png)  (17)

其中 `ŷ`[*T`]^`′`![si92_e](images/S0169716122000566/si92_e.png) 的计算方式与 `ŷ`[*T`]*![si93_e](images/S0169716122000566/si93_e.png) 相同，但使用了修正后的 MLP 权重。

总体修正目标函数为：

$\\begin{array}{r} {\\mathcal{L}\_{tot}^{\\prime} = \\mathcal{L}\_{\\text{ent}}^{\\prime} - \\mathcal{L}\_{\\text{div}}^{\\prime} + \\lambda\\mathcal{L}\_{\\text{pl}}^{\\prime}} \\\\ \\end{array}$
