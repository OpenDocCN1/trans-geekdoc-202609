
In the following sections, we will discuss three recent proxy-based loss formulations, namely (i) Proxy-NCA ([Movshovitz-Attias et al., 2017](#Ch004_59-79_S0169716123000032.xhtml#bb0055)) and Proxy-NCA++ ([Teh et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0085)), (ii) Proxy Anchor Loss ([Kim et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0035)), and (iii) ProxyGML Loss ([Zhu et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0100)).

###  4.1: Proxy-NCA and Proxy-NCA++

Proxy-NCA is motivated by the seminal work performed by [Goldberger et al. (2004)](#Ch004_59-79_S0169716123000032.xhtml#bb0015) on neighborhood component analysis (NCA). Let *p*[*ij*] be the assignment probability or neighborhood probability of *f*[*i*] to *f*[*j*], where *f*[*i*], *f*[*j*] are two data points. We can define this probability as:

$\\begin{array}{r} {p\_{ij} = \\frac{- D\_{e}(f\_{i},f\_{j})}{\\sum\_{k \\notin i} - D\_{e}(f\_{i},f\_{k})}} \\\\ \\end{array}$

![si24\_e](images/S0169716123000032/si24_e.png)  (14)

where *D*[*e*](*f*[*i*],*f*[*k*]) is Euclidean squared distance computed on some learned embeddings. The fundamental purpose of NCA is to increase the probability that points belonging to the same class are close to one another, while simultaneously reducing the probability that points in different classes are near each other. This is formulated as follows:

$\\begin{array}{r} {L\_{\\text{NCA}} = - \\text{log}\\left( \\frac{\\sum\_{j \\notin C\_{i}}e^{- D\_{e}(f\_{i},f\_{j})}}{\\sum\_{k \\notin C\_{i}}e^{- D\_{e}(f\_{i},f\_{k})}} \\right)} \\\\ \\end{array}$

![si25\_e](images/S0169716123000032/si25_e.png)  (15)

The primary challenge in directly optimizing the NCA objective is the computation cost which increases polynomially as the number of samples in the dataset increases. Proxy-NCA attempts to address this computation bottleneck of NCA by introducing proxies. Proxies can be interpreted as class representatives or class prototypes. These proxies are implemented as learnable parameters that train along with the feature encoder. During training, instead of computing pairwise distance which grows quadratically with the batch size and is highly dependent on the quality of pairs, Proxy-NCA computes the distance between the learnable set of class proxies and the feature representation of the respective samples in the batch. Based on this and derived from Eq. ([15](#Ch004_59-79_S0169716123000032.xhtml#fo0085)), Proxy-NCA loss ([Movshovitz-Attias et al., 2017](#Ch004_59-79_S0169716123000032.xhtml#bb0055)) can be formulated as:

$\\begin{array}{r} {L\_{\\text{ProxyNCA}} = - \\text{log}\\left( \\frac{e^{- D\_{e}(\\widehat{f\_{i}},\\widehat{P\_{i}})}}{\\sum\_{k \\notin C\_{i}}e^{- D\_{e}(\\widehat{f\_{i}},\\widehat{P\_{k}})}} \\right)} \\\\ \\end{array}$

![si26\_e](images/S0169716123000032/si26_e.png)  (16)

where *P*[*i*] is the proxy vector corresponding to the data point *f*[*i*]. *f̂*![si27\_e](images/S0169716123000032/si27_e.png) and *P̂*![si28\_e](images/S0169716123000032/si28_e.png) denote normalized embeddings. *C*[*i*] is the set of all data points belonging to the same class as sample *f*[*i*]. The above loss function aims to maximize the distance between noncorresponding proxy and feature pairs and minimize distance between corresponding proxy and feature vectors ([Fig. 6](#Ch004_59-79_S0169716123000032.xhtml#f0035)).

![Fig. 6 Illustration of Proxy-NCA loss: Unlike pairwise losses that require informative pair mining, Proxy-NCA injects learnable proxies denoted by star in the above diagram and pulls them toward the anchored sample embeddings.](images/S0169716123000032/f04-06-9780443184307.jpg)

[Fig. 6](#Ch004_59-79_S0169716123000032.xhtml#B-f0035) Illustration of Proxy-NCA loss: Unlike pairwise losses that require informative pair mining, Proxy-NCA injects learnable proxies denoted by star in the above diagram and pulls them toward the anchored sample embeddings.

As can be observed in Eq. ([16](#Ch004_59-79_S0169716123000032.xhtml#fo0090)), Proxy-NCA does not directly optimize the proxy assignment probability; rather, it optimizes for a suboptimal objective. Proxy-NCA++ ([Teh et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0085)) was proposed to overcome this issue. Proxy-NCA++ ([Teh et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0085)) computes a proxy assignment probability score *P*[*i*] defined as:

$\\begin{array}{r} {L\_{\\text{ProxyNCA++}} = - \\text{log}\\left( \\frac{e^{- D\_{e}(\\widehat{f\_{i}},\\widehat{P\_{i}})}\*\\frac{1}{T}}{\\sum\_{k \\in A}e^{- D\_{e}(\\widehat{f\_{i}},\\widehat{P\_{k}})}\*\\frac{1}{T}} \\right)} \\\\ \\end{array}$

![si29\_e](images/S0169716123000032/si29_e.png)  (17)

where *A* is the set of all proxies. The subtle difference between Proxy-NCA and Proxy-NCA++ formulation is the explicit computation of proxy assignment probability by performing softmax with respect to distance from all proxies. Another important contribution of Proxy-NCA++ is the introduction of temperature scaling parameter *T*. As *T* gets larger, the output of the softmax function that is used to compute the proxy assignment probability tends toward a uniform distribution. With a smaller temperature parameter, the softmax function will lead toward a sharper distribution. Lower temperature increases the distance between probabilities of different classes, thereby helping in more refined class boundaries.

###  4.2: Proxy Anchor loss

Introduction of proxies in Proxy-NCA loss overcame the limitations imposed by the need for informative pair mining strategies. But the objective in Proxy-NCA formulation does not explicitly optimize for fine-grained sample-to-sample similarity since it indirectly represents it through a proxy-to-sample similarity. Proxy Anchor Loss ([Kim et al., 2020](#Ch004_59-79_S0169716123000032.xhtml#bb0035)) investigated this bottleneck and proposed a novel formulation that takes advantage of both pairwise and proxy-based formulations and provides a more explicit sample-to-sample similarity-based supervision along with proxy-based supervision.

Similar to Proxy-NCA, Proxy Anchor defines proxies as a learnable vector in embedding space. Unlike Proxy-NCA, Proxy Anchor formulation represents each proxy as an anchor and associates it with entire data in a batch. This allows the samples within the batch to interact with one another through their interaction with the proxy anchor ([Fig. 7](#Ch004_59-79_S0169716123000032.xhtml#f0040)). Let, *S*(*f*, *p*) be the similarity between a sample *f* and a proxy *p*. Similar to Multi-Similarity loss formulation ([Eq. 13](#Ch004_59-79_S0169716123000032.xhtml#fo0075)), the proxy anchor loss is given as:

$\\begin{matrix} {\\mathcal{L} = \\frac{1}{|P + |}\\sum\\limits\_{p \\in P +}\\text{log}\\left( {1 + \\sum\\limits\_{x \\in \\mathcal{X}\_{p}^{+}}e^{- \\alpha(S(f,p) - \\delta)}} \\right)} \\\\ {+ \\frac{1}{|P|}\\sum\\limits\_{p \\in P}\\text{log}\\left( {1 + \\sum\\limits\_{x \\in \\mathcal{X}\_{p}^{-}}e^{\\alpha(S(f,p) + \\delta)}} \\right)} \\\\ \\end{matrix}$
