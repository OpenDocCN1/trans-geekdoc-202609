
Equalized odds ([Hardt et al., 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1032)) are said to be satisfied if both the true positive rate (TPR) and the false positive rate (FPR) are the same across different demographic subgroups (Eqs. [9](#Ch007_169-221_S0169716123000020.xhtml#fo0050) and [10](#Ch007_169-221_S0169716123000020.xhtml#fo0055), respectively). Mathematically, this is represented as

`p(ŷ = 1|y = 1, G = 0) = p(ŷ = 1|y = 1, G = 1)`

![si9_e](images/S0169716123000020/si9_e.png)  (9)

`p(ŷ = 1|y = 0, G = 0) = p(ŷ = 1|y = 0, G = 1)`

![si10_e](images/S0169716123000020/si10_e.png)  (10)

Equalized odds is also described as “error rate balance” ([Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027)). Similar to Equalized Odds, Equality of Opportunity requires the same TPR across groups (Eq. [9](#Ch007_169-221_S0169716123000020.xhtml#fo0050)) but imposes no such restriction on the FPR.

####  4.1.4: Predictive parity

Predictive parity is satisfied when the positive predictive value is equal across different demographic subgroups ([Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027); [Verma and Rubin, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1038); [MacCarthy, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1034)). It is defined as the probability that individuals predicted to in the positive class truly belong to that class. Mathematically,

`p(y = 1|ŷ = 1, G = 0) = p(y = 1|ŷ = 1, G = 1)`

![si11_e](images/S0169716123000020/si11_e.png)  (11)

Some works require both the positive and negative predictive parity to be equal across groups ([Mayson, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1035)). Mathematically, the equality in negative predictive parity can be written as-

`p(y = 0|ŷ = 0, G = 0) = p(y = 0|ŷ = 0, G = 1)`

![si12_e](images/S0169716123000020/si12_e.png)  (12)

###  4.2: Score-based metrics

In the previous section, a binary output `ŷ` was employed to compute the value of the fairness metric. The metrics described in this section employ the continuous score `s` attained as the output from models for computation. These scores can be thresholded to attain `ŷ` which can then be used to apply metrics ([Garg et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0275)).

####  4.2.1: Calibration

A model is calibrated if, for all scores `s`, the probability of belonging to the positive class is the same irrespective of the demographic subgroup for the same `s` ([Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027); [Verma and Rubin, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1032); [Mehrabi et al., 2021](#Ch007_169-221_S0169716123000020.xhtml#bb1036); [Hardt et al., 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1038)). Mathematically,

`p(y = 1|S = s, G = 0) = p(y = 1|S = s, G = 1)`

![si13_e](images/S0169716123000020/si13_e.png)  (13)

####  4.2.2: Balance for positive/negative class

If the average scores `s` for the positive classes of the demographic subgroups are the same, a balance exists for the positive class ([Kleinberg et al., 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1039)). Similarly, a balance for the negative class exists when the average scores of the negative classes of the subgroups are the same. The positive and negative balance is denoted in Eqs. [14](#Ch007_169-221_S0169716123000020.xhtml#fo0075) and [15](#Ch007_169-221_S0169716123000020.xhtml#fo0080) below, respectively.

`E[s|y = 1, G = 0] = E[s|y = 1, G = 1]`

![si14_e](images/S0169716123000020/si14_e.png)  (14)

`E[s|y = 0, G = 0] = E[s|y = 0, G = 1]`

![si15_e](images/S0169716123000020/si15_e.png)  (15)

###  4.3: Facial analysis-specific metrics

The difference or standard deviation between different statistical measures of performance across subgroups is often used as a measure of fairness or bias. Different research works over the years have discussed the shortcomings of existing metrics. For classification parity-based metrics, the problem of infra-marginality has been observed ([Corbett-Davies et al., 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1028)). Due to possible differences in risk distributions across subgroups, these metrics lead to taste-based discrimination ([Thijssen, 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1037)). The search for an optimal fairness metric remains an open problem in the research community. Metrics have been proposed specifically for fairness in face recognition and attribute prediction algorithms ([Howard et al., 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1033)). Some of them are described below.

####  4.3.1: Fairness discrepancy rate (FDR)

The FDR metric is defined for face verification systems. It is computed as the maximum difference in false match rate (FMR/FPR) and the false non-match rate (FNMR/FNR) between two demographic subgroups *g*[1] and *g*[2] at a given threshold *t* ([de Freitas Pereira and Marcel, 2021](#Ch007_169-221_S0169716123000020.xhtml#bb1029)). The differences are weighed by an *α* parameter. Mathematically,

`A(t) = max(|FMR[g1](t) - FMR[g2](t)|)`

![si16_e](images/S0169716123000020/si16_e.png)

`B(t) = max(|FNMR[g1](t) - FNMR[g2](t)|)`

![si17_e](images/S0169716123000020/si17_e.png)

`FDR(t) = 1 - (α*A(t) + (1-α)*B(t))`

![si18_e](images/S0169716123000020/si18_e.png)  (16)

The metric ranges from 0 to 1 with 1 being *most fair* and 0 being *most unfair*.

####  4.3.2: Inequity rate (IR)

The IR metric was proposed by NIST in 2021 ([Grother, 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1031)). Instead of taking differences into account, IR considers the maximum and minimum in the ratios of the FMR and FNMR for demographic subgroups *g*[1] and *g*[2] at threshold *t*. The metric is described mathematically below ([Howard et al., 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1033)). *α* is used as a weighting factor.

`A(t) = max(FMR[g1](t))/max(FMR[g2](t))`

![si19_e](images/S0169716123000020/si19_e.png)

`B(t) = max(FNMR[g1](t))/max(FNMR[g2](t))`

![si20_e](images/S0169716123000020/si20_e.png)

`IR(t) = A(t)^(α) * B(t)^(1-α)`

![si21_e](images/S0169716123000020/si21_e.png)  (17)

####  4.3.3: Degree of bias

The recent Degree of Bias (DoB) metric ([Gong et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0295)) measures the standard deviation of (verification/identification) accuracy (Acc) across different subgroups. It is calculated as

`DoB = std(Acc[g_j]) ∀j`

![si22_e](images/S0169716123000020/si22_e.png)  (18)

where `g[j]` represents a subgroup of a demographic group `G`. High performance gap of the model across different subgroups will result in high `DoB`, indicating higher bias in the model prediction. DoB is commonly used for evaluating bias in face recognition models ([Gong et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0295); [Wang and Deng, 2021](#Ch007_169-221_S0169716123000020.xhtml#bb0835)).

####  4.3.4: Precise subgroup equivalence (PSE)

In Majumdar et al. ([Majumdar et al., 2021a](#Ch007_169-221_S0169716123000020.xhtml#bb0515)), the authors propose a bias estimation metric termed as Precise Subgroup Equivalence (PSE). PSE is a combination of the bias in the model prediction and the overall model performance. It is defined as

`AFR = (FP + FN)/2`

![si23_e](images/S0169716123000020/si23_e.png)

`PSE = ((1-DI) + AFR + DoB)/3`

![si24_e](images/S0169716123000020/si24_e.png)  (19)
