
Since one does not know the information about the source distributions (due to the unavailability of source data), a good choice is to consider the least informative of all the distributions, i.e., uniform distribution for sources by the `Principle of Maximum Entropy` ([Jaynes, 1957](#Ch005_81-105_S0169716122000566.xhtml#bb0095)). This uniformity is assumed over the target support set 𝒳![si6_e](images/S0169716122000566/si6_e.png). In what follows, the algorithm considers the restrictions of the source distributions to the target support 𝒳![si6_e](images/S0169716122000566/si6_e.png). Mathematically, the assumption is `Q`[*S`]^`(*k`)*(`*x`)* = `c`[*k`]*𝒰`(*x`)*![si67_e](images/S0169716122000566/si67_e.png) when restricted to the support set `x` ∈ 𝒳![si68_e](images/S0169716122000566/si68_e.png), where `c`[*k`] is a scaling factor which captures the relative contribution of source `k` and 𝒰`(*x`)*![si69_e](images/S0169716122000566/si69_e.png) has value 1. Plugging this value of the distribution in the combination rule in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010), we get $\\theta\_{T}(x) = \\sum\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}}{\\sum\_{j = 1}^{n}\\lambda\_{j}c\_{j}}\\theta\_{S}^{k}(x)$![si70_e](images/S0169716122000566/si70_e.png) by the following steps:

$\\begin{array}{ll} {\\theta\_{T}\\left( x \\right)} & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}Q\_{S}^{k}\\left( x \\right)}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}Q\_{S}^{j}\\left( x \\right)}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}\\mathcal{U}\\left( x \\right)}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}c\_{j}\\mathcal{U}\\left( x \\right)}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & {= \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}c\_{k}}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}c\_{j}}\\theta\_{S}^{k}\\left( x \\right)} \\\\ & \\\\ \\end{array}$

![si71_e](images/S0169716122000566/si71_e.png)  (13)

This term consisting of `λ`[*k`] and `c`[*k`] essentially becomes the weighting term `α`[*k`] in `DECISION`. The next step is to put this value of `θ`[*T`] to solve the optimization ([12](#Ch005_81-105_S0169716122000566.xhtml#fo0065)) jointly with respect to this `α`[*k`] and `ϕ`[*S`]^`(*k`)*![si72_e](images/S0169716122000566/si72_e.png). Thus, `DECISION` will return us a favorable combination of source hypotheses, satisfying the bounds in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010), under the uniformity assumption of source distributions. However, without assumption of source uniformity one can try to estimate the `Q`[*S`]^`(*k`)*![si50_e](images/S0169716122000566/si50_e.png)s in order to minimize target risk, which we will discuss in the next section as the proposed framework `DECISION-mlp` ([Fig. 3](#Ch005_81-105_S0169716122000566.xhtml#f0020)).

##  7: Source distribution dependent weights (DECISION-mlp)

The mixing weights in the model aggregation scheme in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010), which also stems from [Mansour et al. (2009)](#Ch005_81-105_S0169716122000566.xhtml#bb0145) and [Hoffman et al. (2018a)](#Ch005_81-105_S0169716122000566.xhtml#bb0075), are functions of the source distributions and the target samples. Due to absence of source data, assumption of uniform source distribution leads to [Algorithm 1](#Ch005_81-105_S0169716122000566.xhtml#b0010). However, without assuming anything about source distribution it is possible to estimate it via MLPs. Let's assume there are *n* MLPs `ℳ`[*S`]^`(*k`)*∀`*k`* = 1, 2, …*n*![si74_e](images/S0169716122000566/si74_e.png) to estimate *n* source distributions [(Fig. 3)](#Ch005_81-105_S0169716122000566.xhtml#f0020). Target features are obtained by passing each and every sample through the feature encoders and concatenate them to get a vector of size *d* where $d = \\sum\_{i = 1}^{n}d\_{i}$![si75_e](images/S0169716122000566/si75_e.png). If the target sample is `x`[*T`]^`(*i`)*![si76_e](images/S0169716122000566/si76_e.png), then the concatenated vector `ϕ`(`x`[*T`]^`(*i`))![si77_e](images/S0169716122000566/si77_e.png) can be expressed as `ϕ`(`X`[*T`]^`(*i`))*⊤*∈ℝ^`(*d`)*![si78_e](images/S0169716122000566/si78_e.png). Next `ϕ`(`x`[*T`]^`(*i`))*![si77_e](images/S0169716122000566/si77_e.png) is fed through all the MLPs to get *n* scalars {`ℳ`[*S`]^`(*k`)*(`ϕ`(`X`[*T`]^`(*i`))`}*[*k* = 1]^`(*n*)![si80_e](images/S0169716122000566/si80_e.png), which are analogous to `λ`[*k`]*`Q`[*S`]^`(*k`)*(`x`)*![si81_e](images/S0169716122000566/si81_e.png)’s in the expression of the target predictor in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010). Clearly these scalars, upon normalizing emulate `α`’s as a function of both source distributions and target samples. In short, if the *i*th sample has a weight `α`[*j`]^`(*i`)*![si82_e](images/S0169716122000566/si82_e.png) corresponding to *j*th source, then

$\\begin{array}{r} {\\alpha\_{j}^{i} = \\frac{\\mathcal{M}\_{S}^{j}(\\phi(x\_{T}^{i}))}{\\sum\\limits\_{k = 1}^{n}\\mathcal{M}\_{S}^{k}(\\phi(x\_{T}^{i}))}} \\\\ \\end{array}$

![si83_e](images/S0169716122000566/si83_e.png)  (14)

In this new setting, the loss functions in our objective are modified slightly. Let us denote the modified entropy, diversity, and pseudo-label losses as ℒ[ent]^′![si84_e](images/S0169716122000566/si84_e.png), ℒ[div]^′![si85_e](images/S0169716122000566/si85_e.png), and ℒ[pl]^′![si86_e](images/S0169716122000566/si86_e.png), respectively. Then,

$\\begin{array}{r} {\\mathcal{L}\_{\\text{ent}}^{\\prime} = - \\mathbb{E}\_{x\_{T}^{i} \\in \\mathcal{D}\_{T}}\\left\\lbrack {\\sum\\limits\_{j = 1}^{K}\\delta\_{j}(\\theta\_{T}(x\_{T}^{i}))\\log(\\delta\_{j}(\\theta\_{T}(x\_{T}^{i})))} \\right\\rbrack} \\\\ \\end{array}$

![si87_e](images/S0169716122000566/si87_e.png)  (15)

where `θ`[*T`](`x`[*T`]^`(*i`))* = ∑`j` = 1`^`n`α`j`*(`i`)*θ`S`*j`(`x`[*T`]^`(*i`))*![si88_e](images/S0169716122000566/si88_e.png).

$\\begin{array}{r} {\\mathcal{L}\_{\\text{div}}^{\\prime} = \\sum\\limits\_{j = 1}^{K} - {\\overset{-}{p}}\_{j}^{\\prime}\\log{\\overset{-}{p}}\_{j}^{\\prime}} \\\\ \\end{array}$

![si89_e](images/S0169716122000566/si89_e.png)  (16)

where `overset{-`}*p`* = E`x`[*T`]^`(*i*)*∈`D`*T`*[`δ`(`θ`*T`(`x`[*T`]^`(*i`))*]![si90_e](images/S0169716122000566/si90_e.png) and,

$\\begin{array}{r} {\\mathcal{L}\_{\\text{pl}}^{\\prime}(Q\_{T},\\theta\_{T}) = - \\mathbb{E}\_{x\_{T}^{i} \\in \\mathcal{D}\_{T}}\\sum\\limits\_{k = 1}^{K}1\\{ ŷ\_{T}^{\\prime} = k\\}\\log\\delta\_{k}(\\theta\_{T}(x\_{T}^{i})).} \\\\ \\end{array}$

![si91_e](images/S0169716122000566/si91_e.png)  (17)

where `ŷ`[*T`]^`′`![si92_e](images/S0169716122000566/si92_e.png) is calculated in the same manner as `ŷ`[*T`]*![si93_e](images/S0169716122000566/si93_e.png) but with the modified MLP weights.

The overall modified objective function in this scenario becomes,

$\\begin{array}{r} {\\mathcal{L}\_{tot}^{\\prime} = \\mathcal{L}\_{\\text{ent}}^{\\prime} - \\mathcal{L}\_{\\text{div}}^{\\prime} + \\lambda\\mathcal{L}\_{\\text{pl}}^{\\prime}} \\\\ \\end{array}$
