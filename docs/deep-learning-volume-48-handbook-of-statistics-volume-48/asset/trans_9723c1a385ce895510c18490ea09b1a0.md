1.   Affymetrix SNP 6.0 (SNP6) 阵列数据用于识别基因组中的重复区域，并计算TCGA-LGG和TCGA-GBM队列中这些重复区域的拷贝数。使用GISTIC2流程（`[Mermel et al., 2011](#Ch006_107-168_S0169716122000578.xhtml#bb0255)`）估计基因的数值拷贝数变异（CNV），仅对蛋白编码基因进行估计。对基因的数值CNV进一步通过噪声切断值0.3进行阈值处理。下面的标准用于将数值CNV分类为基因的拷贝增益、拷贝损失和中性状态：

    1.   CNV ≤ -0.3的基因被归类为拷贝损失，并用数值 -1 表示。

    2.   CNV ≥ 0.3的基因被归类为拷贝增益，并用数值 +1 表示。

    3.   -0.3 ≤ CNV ≤ +0.3的基因被归类为中性，并用数值 0 表示。

####  2.1.2: COVID-19数据

本研究使用了从印度政府卫生与家庭福利部（MoHFW）收集的全国每日 COVID-19 病例数据，时间范围为2020年4月1日至2022年3月31日。在印度，COVID-19检测主要采用快速抗原测试（RAT）和逆转录聚合酶链式反应（RT‑PCR）方法。虽然RT‑PCR对病毒的检测更为敏感，但快速抗原测试因诊断时间短、成本低，更适合用于了解疾病传播和开展主动健康干预。

####  2.1.4: 图像数据

人脑磁共振成像（MRI）和胶质母细胞瘤组织活检切片（HE染色）图像（来自TCGA-LGG和TCGA-GBM队列）被用于构建深度卷积神经网络（CNN）模型，用于预测细胞/组织学分级、分子亚型、驱动基因突变状态以及胶质母细胞瘤患者的生存情况。从The Cancer Image Archive（TCIA）（`[https://www.cancerimagingarchive.net/](https://www.cancerimagingarchive.net/)`）获取了预处理后的对比增强T1加权MRI图像和整幅组织病理图像（WSI）。同时，从TCGA数据门户（`[https://portal.gdc.cancer.gov/](https://portal.gdc.cancer.gov/)`）获取了所有患者的元数据（如肿瘤分级、分子亚型、生存）以及选定驱动基因 *EGFR* 和 *TP53* 的体内突变情况。

满足以下条件的胶质母细胞瘤患者MRI和病理图像被用于训练CNN模型： tumor grades、分子亚型、 *EGFR* 与 *TP53* 基因突变状态以及总生存（OS）数据。在此筛选下，最终选取了1152例患者的MRI和WSI图像用于模型的训练和测试。

MRI图像以数字成像与通信在医学（DICOM）格式提供（`[Guthrie et al., 2001](#Ch006_107-168_S0169716122000578.xhtml#bb0170)`）。DICOM图像不可直接机器读取，因此将其转换为PNG格式，并经过多步滤波以去除潜在噪声。去噪是提升图像质量且不损害整体完整性的关键步骤（`[Coupe et al., 2008](#Ch006_107-168_S0169716122000578.xhtml#bb0135)`）。可用的去噪算法包括高斯模糊、中值模糊、异构扩散滤波、全变差等（`[Coupe et al., 2006](#Ch006_107-168_S0169716122000578.xhtml#bb0130)`）。文献证据表明，基于邻域过滤的非局部手段（NL means）算法在提升信噪比（SNR）方面优于传统滤波方法（`[Coupe et al., 2006](#Ch006_107-168_S0169716122000578.xhtml#bb0130)`）。在使用快速NL means算法对转换后的PNG图像进行去噪后，所有图像均被调整至128 × 128像素，并标记为肿瘤分级、分子亚型、*EGFR* 与 *TP53* 基因突变状态以及生存月数。
