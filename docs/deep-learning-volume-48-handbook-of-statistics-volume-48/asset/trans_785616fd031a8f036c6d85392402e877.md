
Equalized odds ([Hardt et al., 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1032)) 被认为在不同人口统计子群之间（公式 [9](#Ch007_169-221_S0169716123000020.xhtml#fo0050) 和 [10](#Ch007_169-221_S0169716123000020.xhtml#fo0055)），真实正率（TPR）和假正率（FPR）相同时满足。数学上表示为

`p(ŷ = 1|y = 1, G = 0) = p(ŷ = 1|y = 1, G = 1)`

![si9_e](images/S0169716123000020/si9_e.png)  (9)

`p(ŷ = 1|y = 0, G = 0) = p(ŷ = 1|y = 0, G = 1)`

![si10_e](images/S0169716123000020/si10_e.png)  (10)

Equalized odds 也被称为“错误率平衡”（[Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027)）。与 Equalized Odds 类似，机会平等（Equality of Opportunity）要求各组之间的 TPR 相同（公式 [9](#Ch007_169-221_S0169716123000020.xhtml#fo0050)），但对 FPR 没有任何限制。

####  4.1.4: 预测平衡

当正预测值（positive predictive value）在不同人口统计子群之间相等时，预测平衡得到满足（[Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027); [Verma and Rubin, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1038); [MacCarthy, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1034)）。它被定义为预测属于正类的个体真正属于该类的概率。数学上，

`p(y = 1|ŷ = 1, G = 0) = p(y = 1|ŷ = 1, G = 1)`

![si11_e](images/S0169716123000020/si11_e.png)  (11)

一些研究要求正负预测平衡在各组之间相等（[Mayson, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1035)）。负预测平衡的等式可以写作-

`p(y = 0|ŷ = 0, G = 0) = p(y = 0|ŷ = 0, G = 1)`

![si12_e](images/S0169716123000020/si12_e.png)  (12)

###  4.2: 基于分数的指标

在前一节中，使用二元输出 `ŷ` 来计算公平度量的价值。本节描述的指标使用模型输出的连续分数 `s` 进行计算。这些分数可以阈值化以得到 `ŷ`，进而用于应用指标（[Garg et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0275)）。

####  4.2.1: 校准

如果在所有分数 `s` 下，属于正类的概率与人口统计子群无关（对于相同的 `s`），则模型被认为是校准的（[Chouldechova, 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1027); [Verma and Rubin, 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1032); [Mehrabi et al., 2021](#Ch007_169-221_S0169716123000020.xhtml#bb1036); [Hardt et al., 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1038)）。数学表达为

`p(y = 1|S = s, G = 0) = p(y = 1|S = s, G = 1)`

![si13_e](images/S0169716123000020/si13_e.png)  (13)

####  4.2.2: 正/负类平衡

如果正类子群的平均分数 `s` 相同，则正类平衡存在（[Kleinberg et al., 2017](#Ch007_169-221_S0169716123000020.xhtml#bb1039)）。同样，如果负类子群的平均分数相同，则负类平衡存在。正负平衡分别在公式 [14](#Ch007_169-221_S0169716123000020.xhtml#fo0075) 和 [15](#Ch007_169-221_S0169716123000020.xhtml#fo0080) 中表示。

`E[s|y = 1, G = 0] = E[s|y = 1, G = 1]`

![si14_e](images/S0169716123000020/si14_e.png)  (14)

`E[s|y = 0, G = 0] = E[s|y = 0, G = 1]`

![si15_e](images/S0169716123000020/si15_e.png)  (15)

###  4.3: 人脸分析专用指标

不同统计指标在不同子群之间的差异或标准差常被用作衡量公平或偏见的指标。近年来的研究指出了现有指标的不足。对于分类平衡指标，已观察到“ infra-marginality” 问题（[Corbett-Davies et al., 2018](#Ch007_169-221_S0169716123000020.xhtml#bb1028)）。由于子群之间的风险分布可能不同，这些指标可能导致基于偏好的人为歧视（[Thijssen, 2016](#Ch007_169-221_S0169716123000020.xhtml#bb1037)）。寻找最优公平度量仍是研究社区的开放问题。专门为人脸识别和属性预测算法提出的指标包括（[Howard et al., 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1033)）。下面介绍一些指标。

####  4.3.1: 公平差异率（FDR）

FDR 指标用于人脸验证系统，计算为在给定阈值 *t* 时，两个人口子群 *g*[1] 和 *g*[2] 的假正匹配率（FMR/FPR）与假非匹配率（FNMR/FNR）之间的最大差值（[de Freitas Pereira and Marcel, 2021](#Ch007_169-221_S0169716123000020.xhtml#bb1029)）。差值由参数 *α* 加权。数学表达为：

`A(t) = max(|FMR[g1](t) - FMR[g2](t)|)`

![si16_e](images/S0169716123000020/si16_e.png)

`B(t) = max(|FNMR[g1](t) - FNMR[g2](t)|)`

![si17_e](images/S0169716123000020/si17_e.png)

`FDR(t) = 1 - (α*A(t) + (1-α)*B(t))`

![si18_e](images/S0169716123000020/si18_e.png)  (16)

该指标范围为 0 到 1，1 表示 *最公平*，0 表示 *最不公平*。

####  4.3.2: 不平等率（IR）

IR 指标由 NIST 在 2021 年提出（[Grother, 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1031)）。它不考虑差值，而是考虑在阈值 *t* 时，两个子群 *g*[1] 和 *g*[2] 的 FMR 与 FNMR 的比值的最大值和最小值。数学表达如下（[Howard et al., 2022](#Ch007_169-221_S0169716123000020.xhtml#bb1033)），*α* 为权重因子。

`A(t) = max(FMR[g1](t))/max(FMR[g2](t))`

![si19_e](images/S0169716123000020/si19_e.png)

`B(t) = max(FNMR[g1](t))/max(FNMR[g2](t))`

![si20_e](images/S0169716123000020/si20_e.png)

`IR(t) = A(t)^(α) * B(t)^(1-α)`

![si21_e](images/S0169716123000020/si21_e.png)  (17)

####  4.3.3: 偏差程度

最近提出的度量（Degree of Bias, DoB）指标（[Gong et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0295)）衡量不同子群之间（验证/识别）准确率（Acc）的标准差。计算公式为

`DoB = std(Acc[g_j]) ∀j`

![si22_e](images/S0169716123000020/si22_e.png)  (18)

其中 `g[j]` 表示人口统计组 `G` 的一个子群。模型在不同子群之间的性能差距越大，DoB 越高，表明模型预测的偏见越高。DoB 常用于评估人脸识别模型的偏见（[Gong et al., 2020](#Ch007_169-221_S0169716123000020.xhtml#bb0295); [Wang and Deng, 2021](#Ch007_169-221_S0169716123000020.xhtml#bb0835)）。

####  4.3.4: 精确子群等价（PSE）

在 Majumdar et al. ([Majumdar et al., 2021a](#Ch007_169-221_S0169716123000020.xhtml#bb0515)) 中，作者提出一种偏差估计指标，称为精确子群等价（PSE）。PSE 结合了模型预测的偏差和整体模型性能。定义如下：

`AFR = (FP + FN)/2`

![si23_e](images/S0169716123000020/si23_e.png)

`PSE = ((1-DI) + AFR + DoB)/3`

![si24_e](images/S0169716123000020/si24_e.png)  (19)
