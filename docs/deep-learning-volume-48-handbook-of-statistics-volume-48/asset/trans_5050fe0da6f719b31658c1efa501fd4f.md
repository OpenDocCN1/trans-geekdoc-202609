##  6: Theoretical insights

###  6.1: Theoretical motivation behind DECISION

DECISION aims to find the optimal weights {*α*[*j*]}[*j* = 1]^(*n*)![si43_e](images/S0169716122000566/si43_e.png) for each source and takes a convex combination of the source predictors to obtain the target predictor. It shows that under intuitive assumptions on the source and target distributions, there exists a simple choice of target predictor, which can perform better than or equal to the best source model being applied directly on the target data.

Following the notations in [Ahmed et al. (2021)](#Ch005_81-105_S0169716122000566.xhtml#bb0015), *L* is the loss function which maps the pair of model-predicted label and the ground-truth label to a scalar. Expected loss over *k*th source distribution is denoted by *Q*[*S*]^(*k_)![si50_e](images/S0169716122000566/si50_e.png) using the source predictor *θ* via ℒ(*Q*[*S*]^(*k_), *θ*) = 𝔼[*x*]\[*L*(*θ*(*x*), *y*)] = ∫[*x*]*L*(*θ*(*x*), *y*)*Q*[*S*]^(*k*)(*x*)*d**x**![si51_e](images/S0169716122000566/si51_e.png). *θ*[*S*]^(*k_)![si52_e](images/S0169716122000566/si52_e.png) is the optimal source predictor given by $\\theta\_{S}^{k} = \\text{arg}\\;\\underset{\\theta}{\\text{min}}\\;\\mathcal{L}(Q\_{S}^{k},\\theta)\\;\\forall\\; 1 \\leq k \\leq n$![si53_e](images/S0169716122000566/si53_e.png). Based on the assumption in [Ahmed et al. (2021)](#Ch005_81-105_S0169716122000566.xhtml#bb0015), the target distribution is in the span of source distributions, which can be formalized by expressing the target distribution as an affine combination of source distributions, i.e., $Q\_{T}(x) = \\sum\_{k = 1}^{n}\\lambda\_{k}Q\_{S}^{k}(x):\\lambda\_{k} \\geq 0,\\sum\_{k = 1}^{n}\\lambda\_{k} = 1$![si54_e](images/S0169716122000566/si54_e.png). Under this assumption, the target predictor can be expressed as $\\theta\_{T}(x) = \\sum\_{k = 1}^{n}\\frac{\\lambda\_{k}Q\_{S}^{k}(x)}{\\sum\_{j = 1}^{n}\\lambda\_{j}Q\_{S}^{j}(x)}\\theta\_{S}^{k}(x)$![si55_e](images/S0169716122000566/si55_e.png), then the theoretical claim is established as stated in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010).

Lemma 1.

Assume that the loss *L*(*θ*(*x*), *y*) is convex in its first argument and that there exists a *λ* ∈ ℝ^(*n_)![si56_e](images/S0169716122000566/si56_e.png) where *λ* ≥ 0![si57_e](images/S0169716122000566/si57_e.png) and *λ^⊤1![si38_e](images/S0169716122000566/si38_e.png) = 1![si38_e](images/S0169716122000566/si38_e.png) such that the target distribution is exactly equal to the mixture of source distributions, i.e., $Q\_{T} = \\sum\_{i = 1}^{n}\\lambda\_{i}Q\_{S}^{i}$![si60_e](images/S0169716122000566/si60_e.png). Set the target predictor as the following convex combination of the optimal source predictors

``` 
$\\begin{array}{r} {\\theta\_{T}(x) = \\sum\\limits\_{k = 1}^{n}\\frac{\\lambda\_{k}Q\_{S}^{k}(x)}{\\sum\\limits\_{j = 1}^{n}\\lambda\_{j}Q\_{S}^{j}(x))}\\theta\_{S}^{k}(x).} \\\\ \\end{array}$
```

![si61_e](images/S0169716122000566/si61_e.png)

Recall the pseudo-labeling loss ([10](#Ch005_81-105_S0169716122000566.xhtml#fo0055)). Then, for this target predictor, over the target distribution, the unsupervised loss induced by the pseudo-labels and the supervised loss are both less than or equal to the loss induced by the best source predictor. In particular,

``` 
$\\begin{array}{r} {\\mathcal{L}(Q\_{T},\\theta\_{T}) \\leq \\min\\limits\_{1 \\leq j \\leq n}\\;\\mathcal{L}(Q\_{T},\\theta\_{S}^{j}).} \\\\ \\end{array}$
```

![si62_e](images/S0169716122000566/si62_e.png)

Let *α* = arg min[1 ≤ *j* ≤ *n*] ℒ(*Q*[*T*], *θ*[*S*]^(*j*))![si63_e](images/S0169716122000566/si63_e.png). Additionally, this inequality is strict if the entries of *λ* are strictly positive and there exists a source *i* for which the strict inequality ℒ(*Q*[*S*]^(*i*), *θ*[*S*]^(*i*)) < ℒ(*Q*[*S*]^(*i*), *θ*[*S*]^(*α*))![si64_e](images/S0169716122000566/si64_e.png) holds.

Before going into the proof, we will discuss how does this lemma translates to DECISION and how it motivated us to analyze DECISION-mlp.

The key difference between DECISION and the predictor in [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010) is the algorithm's combination rule, which fine-tunes the feature extractors of each source model unlike [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010). However, each source has an individual weight which is agnostic to the target data, whereas [Lemma 1](#Ch005_81-105_S0169716122000566.xhtml#enun0010) uses different weights per input instance. The intuitive justification for choosing this input-agnostic weighting strategy is provided below.
