# Improving Training Performance

**Mixed Precision Training:** PyTorch Lightning supports automatic mixed precision training with the **precision** flag. This reduces memory usage and increases training speed without sacrificing model accuracy.

```
trainer = pl.Trainer(max_epochs=10, precision=16) # Enable
mixed precision training
trainer.fit(model, data_module)
```
