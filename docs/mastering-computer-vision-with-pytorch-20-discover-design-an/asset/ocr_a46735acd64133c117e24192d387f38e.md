# # Accuracy.

Accuracy measures the number of correct predictions made by the model divided by the total number of predictions. It's a good starting point for evaluation.

```
correct = 0
total = 0
with torch.no_grad():
    for data in testloader:
        images, labels = data
        outputs = net(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()
print('Accuracy of the network on the 10000 test images: %d %%' % (100 * correct / total))
```

Accuracy of the network on the 10000 test images: 61 %
