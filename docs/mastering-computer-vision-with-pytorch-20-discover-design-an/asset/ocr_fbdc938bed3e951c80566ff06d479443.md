In ResNet, convolutional blocks are followed by batch normalization and a ReLU activation function. The crucial element, however, is the addition of a shortcut connection before the activation function, allowing the network to learn an identity function. This ensures that the higher layers can perform at least as good as the lower layers, and not worse.

# The Elegance of Residual Blocks

Residual blocks tackle the diminishing gradients problem by introducing direct paths for backpropagation. This design ensures that the gradients can flow through the network without significant degradation, allowing for previously unattainable deep networks.
