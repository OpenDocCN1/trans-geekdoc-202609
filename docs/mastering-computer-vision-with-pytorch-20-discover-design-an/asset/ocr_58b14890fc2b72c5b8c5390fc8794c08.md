# Troubleshooting Tips

Ensure that your pip version is up-to-date. You can upgrade pip using pip install --upgrade pip.

+   1. If you're facing issues with the installation, try creating a new virtual environment and reinstalling PyTorch.

+   2. If pip install on a specific version throws any errors, you can try adding a force flag:

```
pip install torch==1.8.0+cu111 -f
```
