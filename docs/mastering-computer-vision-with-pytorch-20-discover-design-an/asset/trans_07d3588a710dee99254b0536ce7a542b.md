## 在 PyTorch 中实现流行架构

现在，让我们来看看不同的架构。

## PyTorch 中的 VGG

```python
import torch
import torch.nn as nn

class VGG(nn.Module):
    def __init__(self, num_classes=1000):
        super(VGG, self).__init__()
        self.features = nn.Sequential(
            # 1st block
            nn.Conv2d(3, 64, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            # 2nd block
            nn.Conv2d(64, 128, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            # 3rd block
            nn.Conv2d(128, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            # 4th block
            nn.Conv2d(256, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            # 5th block
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )
        self.classifier = nn.Sequential(
            nn.Linear(512 * 7 * 7, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(),
            nn.Linear(4096, num_classes),
        )

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x
```

## PyTorch 中的 VGG：详细解释

让我们了解一下使用 PyTorch 实现的 VGG 网络的不同构建模块。

### nn.Conv2d

PyTorch 中的 nn.Conv2d 函数用于执行卷积操作，这是卷积层的核心。

- **输入通道数**: 输入图像的通道数。
- **输出通道数**: 过滤器（内核）的数量。
- **内核大小**: 每个过滤器的大小。
- **步长**: 滑动过滤器跨越图像时的步长。
- **填充**: 添加到图像边框的像素数量。

### nn.ReLU

ReLU（整线性单元）是一种激活函数，对正值输出输入值，对负值输出零。

- **原地操作**: 如果设置为 True，它将直接修改输入并节省内存。

### nn.MaxPool2d

最大池化是一种池化操作，从过滤器内的一组值中选择最大值。

- **内核大小**: 池化过滤器的大小。
- **步长**: 滑动过滤器时的步长。

## PyTorch 中的 ResNet

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1, downsample=None):
        super(ResidualBlock, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=stride, padding=1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.downsample = downsample

    def forward(self, x):
        residual = x
        if self.downsample is not None:
            residual = self.downsample(x)
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        out = self.conv2(out)
        out = self.bn2(out)
        out += residual
        out = self.relu(out)
        return out

class ResNet(nn.Module):
    def __init__(self):
        super(ResNet, self).__init__()
        self.in_channels = 64
        self.conv1 = nn.Conv2d(3, 64, kernel_size=7, stride=2, padding=3)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)
        self.maxpool = nn.MaxPool2d(kernel_size=3, stride=2, padding=1)
        self.layer1 = self.make_layer(64, 2)
        self.layer2 = self.make_layer(128, 2, 2)
        self.layer3 = self.make_layer(256, 2, 2)
        self.layer4 = self.make_layer(512, 2, 2)
        self.avgpool = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(512, 10)

    def make_layer(self, out_channels, blocks, stride=1):
        downsample = None
        if stride != 1 or self.in_channels != out_channels:
            downsample = nn.Sequential(
                nn.Conv2d(self.in_channels, out_channels, kernel_size=1, stride=stride),
                nn.BatchNorm2d(out_channels),
            )
        layers = []
        layers.append(ResidualBlock(self.in_channels, out_channels, stride, downsample))
        self.in_channels = out_channels
        for _ in range(1, blocks):
            layers.append(ResidualBlock(out_channels, out_channels))
        return nn.Sequential(*layers)

    def forward(self, x):
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        out = self.maxpool(out)
        out = self.layer1(out)
        out = self.layer2(out)
        out = self.layer3(out)
        out = self.layer4(out)
        out = self.avgpool(out)
        out = out.view(out.size(0), -1)
        out = self.fc(out)
        return out
```

## PyTorch 中的 ResNet：详细解释

让我们了解一下使用 PyTorch 实现的 ResNet 网络的不同构建模块。

### 残差块

残差块是 ResNet 网络的构建模块，它包含一个跳跃连接，允许输入跳过某些层并添加到输出中。

- in_channels: 输入图像的通道数。
- out_channels: 卷积层中的过滤器数量。
- Stride: 卷积层的步长。
- Downsample: 用于匹配输入和输出维度的下采样操作。

### nn.AdaptiveAvgPool2d

自适应平均池化是一种池化操作，通过平均池化生成指定大小的输出。

- (1, 1): 目标输出大小。

## CNN 中的正则化与优化

当模型过于拟合训练数据，既捕获噪声也捕获底层模式，并在新的未见数据上表现不佳时，就会发生过拟合。在 CNN 的语境下，当网络相对于训练数据的数量和复杂度过于复杂时，可能会发生这种情况。为了缓解 CNN 中的过拟合：

### 数据增强

通过对图像应用旋转、翻转、裁剪等变换，增加训练数据集的大小和多样性。我们将详细学习数据增强。

```python
from torchvision.transforms import Compose, RandomHorizontalFlip, RandomRotation
transforms = Compose([
    RandomHorizontalFlip(),
    RandomRotation(10),
])
```

### 正则化

将 L1 或 L2 等正则化项添加到损失函数中，以惩罚大权重。

```python
import torch.nn as nn
model = nn.Sequential(
    nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),
    nn.Flatten(),
    nn.Linear(32 * 14 * 14, 10),
)
criterion = nn.CrossEntropyLoss() + 0.01 * torch.norm(model.parameters(), p=2)
```

### Dropout

在训练期间的每次更新中，随机将一部分输入单元设置为 0，这有助于防止过拟合。

```python
nn.Dropout(p=0.5)
```

### 早停法

一旦验证损失开始增加，即停止训练，以防止过拟合。
