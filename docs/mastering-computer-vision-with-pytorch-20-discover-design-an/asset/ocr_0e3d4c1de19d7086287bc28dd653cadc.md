# # Examples of Basic PyTorch Operations

Diving deeper into PyTorch invariably means working intimately with tensors. These multi-dimensional arrays lie at the heart of the framework and mastering the basic operations on them is crucial. Let's walk through some foundational tensor operations, ensuring you have a toolkit ready to take on more complex deep learning challenges.

# ## Creating Tensors

There are many ways in Python with which we can create tensors.

# ## From Lists:

PyTorch makes it simple to create tensors from Python lists.

```
```python
# Tensor from list
import torch
tensor_from_list = torch.tensor([1, 2, 3, 4])
print(tensor_from_list)
```
```

# ## From Numpy Arrays:

For those familiar with NumPy, transitioning tensors is a breeze.

```
```python
# Tensor from Numpy array
import numpy as np
import torch
numpy_array = np.array([5, 6, 7, 8])
tensor_from_np = torch.from_numpy(numpy_array)
```
