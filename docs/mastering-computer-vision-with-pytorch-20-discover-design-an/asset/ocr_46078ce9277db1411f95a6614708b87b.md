PyTorch 2.0 is compared to PyTorch 1.x as shown in the following table:

| | PyTorch 1.x | PyTorch 2.0 |
|---|---|---|
| **Interface** | Provides a clear and Pythonic interface, making it easier to build and debug models | Preserves the Pythonic interface while further enhancing usability and intuitiveness |
| **Dynamic Computation Graph** | Supports dynamic computation graphs, enabling users to change the network behavior on the fly | Continues to support dynamic computation graphs and introduces improved tools for better graph visualization and debugging |
| **Deployment** | Introduced TorchScript for model deployment in non-Python environments. TorchServe is released for model serving | Continues to support TorchScript and TorchServe. Provides better integration and support for ONNX and introduces more deployment options |
| **Device-Agnostic Code** | Offers device-agnostic code. The same code can be run on CPUs or GPUs | Preserves this feature and further optimizes the computation for different hardware, including improved support for accelerators |
| **Distributed Training** | Provides basic distributed training capabilities | Enhances distributed training with more robust and scalable |
