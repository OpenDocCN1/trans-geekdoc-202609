# Regularization

Add regularization terms such as L1 or L2 to the loss function to penalize large weights.

```
import torch.nn as nn
model = nn.Sequential(
    nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),
    nn.Flatten(),
    nn.Linear(32 * 14 * 14, 10),
)
criterion = nn.CrossEntropyLoss() + 0.01 *
torch.norm(model.parameters(), p=2)
```

# Dropout

Randomly set a fraction of input units to 0 at each update during training, which helps prevent overfitting.

```
nn.Dropout(p=0.5)
```
