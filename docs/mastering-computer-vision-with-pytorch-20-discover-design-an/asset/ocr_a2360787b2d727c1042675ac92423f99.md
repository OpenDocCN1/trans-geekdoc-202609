+   • **Normalization and Standardization:** Normalization and standardization are techniques used to scale features so that they are in a similar range, which can improve a model's performance by preventing large values from disproportionately affecting training. Although often used interchangeably, these techniques differ in their approach and impact.

+   o **Normalization:** This technique scales the data to a fixed range, typically [0, 1] or [-1, 1]. Normalization is useful when you need to constrain values within a specific boundary, which is common for inputs to neural networks.

+   o **Standardization:** This technique scales data to have a mean of 0 and a standard deviation of 1, transforming it to a standard normal distribution. Standardization is preferred when your data contains outliers or follows a Gaussian distribution, as it centers the data, which can stabilize and accelerate training.
