## 5 室内温度预测

本文使用预测模型学习函数 TEMP_FORECAST，以在给定 X 和 U 的情况下准确预测预测范围 h 内的室内温度 Ŷ。指标用于定量评估预测精度。

### 5.1 预测模型

对室内温度预测分析了四种不同的模型。其中包括两种现代循环神经网络：长短期记忆网络、门控循环单元，以及两种基线模型：多元线性回归、带外生变量的季节性自回归积分滑动平均模型（SARIMAX）。如图 2 所示，除线性回归外，所有模型均使用拼接矩阵 X 和 U 作为输入，其中 U 在矩阵 X 的每个时间步中重复。因为线性回归模型无法处理序列数据，所以它们的输入是通过展平矩阵 X 然后与 U 拼接形成的。

长短期记忆循环神经网络。这是用于序列数据最常用的循环神经网络。长短期记忆网络（LSTM）被引入以解决原始循环神经网络（RNN）无法捕捉序列数据中长期非线性依赖性的问题 [3]。LSTM 架构利用一种改进的隐藏单元，称为记忆单元，它根据之前看到的序列数据计算隐藏状态 hs_t 和长期记忆 lm_t。记忆单元具有参数，定义了单元如何获取、更新和丢弃 hs_t 和 lm_t 中的信息，这些参数在训练期间被学习。如图 2 所示，在推理期间，hs_i 和 lm_i 使用来自拼接矩阵 X 和 U 在时间步 i ∈ [1, m] 的输入向量 x_i 以及先前计算的隐藏状态 hs_{i-1} 和长期记忆 lm_{i-1} 递归计算 [13]。如图 2 所示，LSTM 神经网络使用多个记忆单元（用 c 表示）。网络的输出通过使用全连接层计算得出，计算所有单元的 hs 最终值的加权和，以得到输出向量 Ŷ 中的每个值。

门控循环单元循环神经网络。这些网络被引入作为 LSTM 神经网络的潜在改进 [8, 9]。与 LSTM 类似，GRU 使用记忆单元根据之前看到的序列数据计算隐藏状态。关键区别在于 GRU 不使用两个独立的隐藏状态 hs_t 和 lm_t，而是仅使用一个：hs_t。这一变化导致记忆单元结构简化以及所需计算量略有减少。如图 2 所示，GRU 神经网络也使用多个记忆单元，输出 Ŷ 使用全连接层计算得出。先前的研究表明 GRU 的性能与 LSTM 相似，哪个网络更优取决于所使用的特定数据集 [9]。

多元线性回归。线性回归（LR）是一种预测建模方法，假设输入和输出之间存在线性关系。由于其相对较低的复杂性和在某些情况下的合理精度，线性回归模型通常用作许多预测任务的性能基线 [16, 19]。本文使用多元线性回归模型，因为传统的 LR 只能使用单个输入变量进行预测。由于 LR 每次只能预测一个值，因此为预测范围内的每个单独预测值 T_ind(t + i)，i ∈ [1, h] 训练一个单独的回归器。模型的输出通过将输入传递给每个训练好的回归器，然后将它们的结果收集到输出向量 Ŷ 中来计算。

SARIMAX。自回归积分滑动平均模型（ARIMA）是一种经典的、广泛使用和研究的时序预测模型，首次引入已有 40 多年 [5, 27]。SARIMAX 是经典 ARIMA 模型的扩展，通过添加额外参数改进了它们，以考虑时序中的重复趋势。此外，与 ARIMA 不同，SARIMAX 是多元模型，能够使用多个输入变量来预测输出 [10, 32]。SARIMAX 模型有多个参数定义输入和输出之间的关系。非负整数参数 p、d、q ∈ ℤ 定义过去观测值与输出之间的关系。非负参数 P、D、Q、m ∈ ℤ，称为季节项，定义时序内的季节性趋势以及单个季节中的时间步数。传统上，最优参数值是通过使用统计方法手动分析时序来找到的 [10]。然而，现代时序预测库通过执行参数搜索而无需人工干预来自动化这一过程 [27]。

### 5.2 定量评估指标

选择了若干指标用于定量评估实验期间训练的室内温度预测模型。广泛使用的均方根误差（RMSE）和平均绝对误差（MAE）指标被选用于评估测试集上预测模型的平均性能 [7]。最大误差指标（MAXE）被选用于展示模型的 worst-case 预测误差。

$$RMSE(Y, \hat{Y}) = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(Y_i - \hat{Y}_i)^2} \tag{7}$$

$$MAE(Y, \hat{Y}) = \frac{1}{n}\sum_{i=1}^{n}|Y_i - \hat{Y}_i| \tag{8}$$

$$MAXE(Y, \hat{Y}) = \max(|Y - \hat{Y}|) \tag{9}$$

其中 y 和 ŷ 是真实值和预测的一维向量，y_i 是向量中的第 i 个元素（从 1 开始），n 是 y 和 ŷ 中的元素数量。

## 6 灵活性预测

热泵灵活性将通过使用 TEMP_FORECAST 预测室内温度 Ŷ 并计算热泵在 ForcedOn 模式或 Off 模式下可以在违反用户预定义的室内温度舒适边界 T_ind_lower 和 T_ind_upper 之前持续多长时间来预测。

### 6.1 预测方法

本文将根据第 4 节所述在两种场景 Off 和 ForcedOn 中预测灵活性。为了在任一场景中预测灵活性，控制信号 U 必须在用 TEMP_FORECAST 预测温度之前适当定义。在预测 Off 的灵活性时，U 应由值 P_hp_min 组成，其中 P_hp_min 是热泵处于空闲时的平均功耗。在大多数情况下，P_hp_min > 0，可以使用热泵的规格确定。在这种情况下，Model(X, U) 预测室内温度 Ŷ_off，如果热泵在预测范围 h 个时间步内保持 Off 模式。在预测 ForcedOn 的灵活性时，U 应由值 P_hp_max 组成，其中 P_hp_max 是热泵以最大容量运行时平均功耗，通常低于最大额定功率。在这种情况下，Model(X, U) 预测室内温度 Ŷ_on，如果热泵在预测范围 h 个时间步内保持 ForcedOn 模式。

```
Algorithm 1 Flexibility prediction algorithm FLEX_PREDICT
INPUT:
Ŷ - forecasted indoor temperature
T_ind_lower - lower bound of temperature
T_ind_upper - upper bound of temperature
ε - absolute temperature forecasting error used for adjustment
OUTPUT:
F̂ - predicted flexibility
1: procedure FLEX_PREDICT
2:   F̂ ← 0
3:   N ← length(Ŷ)
4:   for i ← 1 to N do
5:     if (T_ind_lower + ε) ≤ Ŷ(i) ≤ (T_ind_upper - ε) then
6:       F̂ ← F̂ + 1   ▷ If temperature is within bounds
7:     else
8:       break       ▷ If temperature violates bounds
9:   return F̂
```

一旦室内温度 Ŷ 被预测，灵活性将使用 FLEX_PREDICT 进行预测，如算法 1 所定义，使用 Ŷ 和预定义的温度边界 T_ind_lower 和 T_ind_upper。可选地，绝对预测误差参数 ε，其中 ε >= 0，可用于调整 TEMP_FORECAST 的平均误差。如算法 1 所示，ε 通过从上界 T_ind_upper 减去 ε 并向下标 T_ind_lower 添加 ε 来有效缩小温度边界。如果 ε > 0，则会导致对热泵潜在灵活性的更悲观预测。如果不希望进行误差调整，则使用 ε = 0。

### 6.2 评估灵活性的指标

本文提出了若干指标用于评估灵活性预测性能。灵活性预测性能可以通过比较使用预测室内温度 Ŷ 计算的预测灵活性 F̂ 和使用真实室内温度 Y 计算的潜在灵活性 F 来进行数值评估。

平均绝对灵活性误差（MAFE）是 MAE 的一种改编，用于评估预测灵活性的平均绝对误差。

$$MAFE(Z, \hat{Z}) = \frac{1}{n}\sum_{i=1}^{n}|Z_i - \hat{Z}_i| \tag{10}$$

其中 Z = ⟨F₁, F₂, …, Fₙ⟩ 和 Ẑ = ⟨F̂₁, F̂₂, …, F̂ₙ⟩ 分别是从预测温度和真实温度得到的灵活性预测向量。n 是 Z 和 Ẑ 中的元素数量。
