
# Gradient Descent Optimization Algorithms in R

This document presents three implementations of gradient descent optimization algorithms: **Momentum**, **RMSProp**, and **Adam**. Each function updates the parameters (weights and biases) of a neural network based on computed gradients.

## Gradient Descent with Momentum

### Function Signature
```r
gradientDescentWithMomentum <- function(parameters, gradients, v, beta, learningRate, outputActivationFunc="sigmoid")
```

### Inputs
- `parameters`: List containing weights (`W1`, `W2`, ...) and biases (`b1`, `b2`, ...).
- `gradients`: List containing gradients for weights (`dW1`, `dW2`, ...) and biases (`db1`, `db2`, ...).
- `v`: Velocity list (moving average of gradients).
- `beta`: Momentum hyperparameter.
- `learningRate`: Learning rate $\alpha$.
- `outputActivationFunc`: Activation function at the output layer (`"sigmoid"` or `"softmax"`). Default is `"sigmoid"`.

### Output
- Updated `parameters` after 1 iteration.

### Algorithm Details
1.  **Calculate Layers**: `L = length(parameters) / 2`.
2.  **Loop through Hidden Layers (1 to L-1)**:
    *   **Update Velocity**:
        `v[["dW" + l]] = beta * v[["dW" + l]] + (1 - beta) * gradients[["dW" + l]]`
        `v[["db" + l]] = beta * v[["db" + l]] + (1 - beta) * gradients[["db" + l]]`
    *   **Update Parameters**:
        `parameters[["W" + l]] = parameters[["W" + l]] - learningRate * v[["dW" + l]]`
        `parameters[["b" + l]] = parameters[["b" + l]] - learningRate * v[["db" + l]]`
3.  **Handle Output Layer (L)**:
    *   **If `sigmoid`**: Standard velocity and parameter update (same as hidden layers).
    *   **If `softmax`**: Applies transpose `t()` to gradients during velocity calculation and parameter update.
        `v[["dW" + L]] = beta * v[["dW" + L]] + (1 - beta) * t(gradients[["dW" + L]])`
        `parameters[["W" + L]] = parameters[["W" + L]] - learningRate * t(gradients[["dW" + L]])`
        (Similar logic applies for biases `db` and `b`).

## Gradient Descent with RMSProp

### Function Signature
```r
gradientDescentWithRMSProp <- function(parameters, gradients, s, beta1, epsilon, learningRate, outputActivationFunc="sigmoid")
```

### Inputs
- `parameters`, `gradients`: Same as Momentum.
- `s`: Cache list (moving average of squared gradients).
- `beta1`: Decay rate for the moving average (often denoted $\beta_2$ in literature).
- `epsilon`: Small constant for numerical stability (prevents division by zero).
- `learningRate`, `outputActivationFunc`: Same as Momentum.

### Algorithm Details
1.  **Calculate Layers**: `L = length(parameters) / 2`.
2.  **Loop through Hidden Layers (1 to L-1)**:
    *   **Update Cache (Squared Gradients)**:
        `s[["dW" + l]] = beta1 * s[["dW" + l]] + (1 - beta1) * gradients[["dW" + l]] * gradients[["dW" + l]]`
        (Element-wise multiplication).
    *   **Update Parameters**:
        `parameters[["W" + l]] = parameters[["W" + l]] - learningRate * gradients[["dW" + l]] / sqrt(s[["dW" + l]] + epsilon)`
3.  **Handle Output Layer (L)**:
    *   **If `sigmoid`**: Standard RMSProp update.
    *   **If `softmax`**: Applies transpose `t()` to gradients for cache update and parameter update.
        `s[["dW" + L]] = beta1 * s[["dW" + L]] + (1 - beta1) * t(gradients[["dW" + L]]) * t(gradients[["dW" + L]])`
        `parameters[["W" + L]] = parameters[["W" + L]] - learningRate * t(gradients[["dW" + L]]) / sqrt(s[["dW" + L]] + epsilon)`

## Gradient Descent with Adam

### Function Signature
```r
gradientDescentWithAdam <- function(parameters, gradients, v, s, t, beta1=0.9, beta2=0.999, epsilon=1e-8, learningRate=0.1, outputActivationFunc="sigmoid")
```

### Inputs
- `parameters`, `gradients`: Same as above.
- `v`: Velocity list (1st moment, moving average of gradients).
- `s`: Cache list (2nd moment, moving average of squared gradients).
- `t`: Time step (iteration count), used for bias correction.
- `beta1`: Exponential decay rate for 1st moment estimates (default 0.9).
- `beta2`: Exponential decay rate for 2nd moment estimates (default 0.999).
- `epsilon`: Numerical stability constant (default 1e-8).
- `learningRate`: Learning rate (default 0.1).
- `outputActivationFunc`: Output activation (default `"sigmoid"`).

### Algorithm Details
1.  **Calculate Layers**: `L = length(parameters) / 2`.
2.  **Initialize Correction Lists**: `v_corrected <- list()`, `s_corrected <- list()`.
3.  **Loop through Hidden Layers (1 to L-1)**:
    *   **Update 1st Moment (Velocity)**:
        `v[["dW" + l]] = beta1 * v[["dW" + l]] + (1 - beta1) * gradients[["dW" + l]]`
    *   **Bias Correction (1st Moment)**:
        `v_corrected[["dW" + l]] = v[["dW" + l]] / (1 - beta1^t)`
    *   **Update 2nd Moment (Cache)**:
        `s[["dW" + l]] = beta2 * s[["dW" + l]] + (1 - beta2) * gradients[["dW" + l]] * gradients[["dW" + l]]`
    *   **Bias Correction (2nd Moment)**:
        `s_corrected[["dW" + l]] = s[["dW" + l]] / (1 - beta2^t)`
    *   **Update Parameters**:
        `d1 = sqrt(s_corrected[["dW" + l]] + epsilon)`
        `parameters[["W" + l]] = parameters[["W" + l]] - learningRate * v_corrected[["dW" + l]] / d1`
        (Similar logic for biases `db`, `b` using `d2`).
4.  **Handle Output Layer (L)**:
    *   **If `sigmoid`**: Standard Adam update using raw gradients.
    *   **If `softmax`**: Uses transposed gradients `t(gradients[...])` for moment updates and parameter updates.
    *   *Note: The provided code snippet cuts off during the `sigmoid` block for the output layer (bias correction calculation).*

## Common Implementation Patterns

*   **Dynamic Naming**: All functions use `paste("dW", l, sep="")` (or `paste0("dW", l)`) to dynamically access list elements for layer `l`.
*   **List Structure**: `parameters`, `gradients`, `v`, `s` are R lists where names follow the pattern `"W1"`, `"b1"`, `"dW1"`, `"db1"`, etc.
*   **Output Layer Handling**: Special logic branches (`if/else`) handle the final layer `L` differently depending on whether the output activation is `sigmoid` (standard) or `softmax` (requires transpose `t()`).
*   **In-Place Modification**: Functions modify the input lists (`parameters`, `v`, `s`) and return the updated `parameters`.
