# 11.3.2 THEOREM

Let G be the regular IFG. Then we have

$M(G) = c^2 \sum_{i=1}^n [T_s(u_i) + F_s(u_i)], \forall u_i \in S \text{ where } \sum_{v \neq u_i} T_s(v, u) = c, \sum_{v \neq u_i} F_s(v, u) = c$

Proof: Given the degree of the definition of each points, $d[v] = [d_r(v), d_r(v)]$

```
$d(v) = \left[ \sum_{v \neq u} T_s(v, u), \sum_{v \neq u} F_s(v, u) \right].
```

On the other hand, for regular intuitionistic fuzzy graph, we know that $\sum_{v \neq u} T_s(v, u) = c, \sum_{v \neq u} F_s(v, u) = c$

```
$d(v) = [d_r(v), d_r(v)] = (c, c)$
```

Now by applying the formula in the first Zagreb index, we will get the results.
