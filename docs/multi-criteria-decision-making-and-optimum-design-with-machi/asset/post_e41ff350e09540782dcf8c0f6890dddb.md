## 20.3.2 ALGORITHMS

Fusion Sort is a hybrid algorithm that combines the strengths of Insertion Sort and divide and conquer to achieve effective sorting. The algorithm uses a user-specified threshold value to determine when to switch between two strategies.

#### 20.3.2.1 Algorithm: Fusion Sort

Input: An unsorted array.
Threshold: An integer representing the threshold that determines when to use Insertion Sort.
Output: A sorted array in ascending order.

```python
function fusion_sort(arr, threshold):
```

#### 20.3.2.2 Algorithm: Choose Pivot

Input: An array 'arr' for which the pivot needs to be chosen.
Output: The pivot element (e.g., median of the first and last elements).

```python
function choose_pivot(arr):
    # Choose the pivot element (e.g., median)
    return arr[len(arr) // 2]
```

#### 20.3.2.3 Algorithm: Partition

Input: An array 'arr' and a pivot element 'pivot' for which the array needs be partitioned.
Output: Two subarrays: 'smaller_subarray' containing elements less than the pivot, and 'larger_subarray' containing elements greater.

```python
function partition(arr, pivot):
    smaller_subarray = []
    larger_subarray = []
    for x in arr:
        if x < pivot:
            append x to smaller_subarray
        else if x > pivot:
            append x to larger_subarray
    return smaller_subarray, larger_subarray
```

#### 20.3.2.4 Algorithm: Insertion Sort

Input: An unsorted array 'arr'.
Output: The sorted array 'arr' in ascending order.

```python
function insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j = j - 1
        arr[j + 1] = key
    return arr
```

#### 20.3.2.5 Algorithm: Merge

Input: Three sorted arrays—arr1, arr2, and arr3.
Output: Merged array containing all elements from arr1, arr2, and arr3.

```python
function merge(arr1, arr2, arr3):
    merged_arr = []
    i = j = k = 0
    while i < len(arr1) and j < len(arr2) and k < len(arr3):
        if arr1[i] <= arr2[j] and arr1[i] <= arr3[k]:
            append arr1[i] to merged_arr
            i = i + 1
        else if arr2[j] <= arr1[i] and arr2[j] <= arr3[k]:
            append arr2[j] to merged_arr
            j = j + 1
        else:
            append arr3[k] to merged_arr
            k = k + 1
    while i < len(arr1):
        append arr1[i] to merged_arr
        i = i + 1
    while j < len(arr2):
        append arr2[j] to merged_arr
        j = j + 1
    while k < len(arr3):
        append arr3[k] to merged_arr
        k = k + 1
    return merged_arr
```
