# ## 11.1 INTRODUCTION

A fuzzy set gives the degree of membership of an object in a given set (Zadeh, 1965). An intuitionistic fuzzy graph (IFG) contains two-valued logic (two dimensions) where the values lie between [0, 1]. The IFG edge values, the minimum and maximum, are based on the vertex. IFGs represent only membership and non-membership value. In 1974, basic theoretic concepts and fuzzy graph operations were performed by Rosenfield. K. Y. Atanov introduced intuitionistic fuzzy sets in 1986 (Atansov, 1986) and interval-valued intuitionistic fuzzy sets in 1999 (Atansov, 1999). Fuzzy, intuitionistic, and neutropic graphs are one-dimensional (only membership), two-dimensional (membership and non-membership), and three-dimensional (membership, non-membership and indeterminacy), respectively introduced the center and eccentricity of fuzzy set and fuzzy set (Bhattacharya). IFGs extend the fuzzy graphs, and neutropic graphs extend IFGs (Szzmidt and Kaczprzyk, 2000). The intuitionistic fuzzy graph, vertices, cycle and trees in intuitionistic fuzzy graph were introduced by Akram (Akram and Alsheheri, 2014). In 2012, graph operations on intuitionistic fuzzy graph were discussed (Akram and Davvaz, 2012) and studied the connectivity in intuitionistic fuzzy graph (Alzoubi and Alhasner, 2021). A real-life application was related with human trafficking and illegal immigration using Wiener fuzzy graph (近期 et al., 2019). In 2016, Akram introduced an idea about operations on intuitionistic fuzzy graph structures (Akram Muhammad and Akmal, 2018). For this chapter, we characterize several topological indices for IFGs: First Zagreb, second Zagreb, forgotten, Randić, and harmonic (Javeria Dinar, 2023) and discuss algorithms and applications.
