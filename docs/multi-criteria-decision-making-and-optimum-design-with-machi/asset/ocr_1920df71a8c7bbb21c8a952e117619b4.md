# 16.2.7 DEFINITION

A graph's $W_{TG}(G)$ is defined as the total of the distances between all vertex pairs.

```
$W_{TG}(G) = \frac{1}{2} \sum_{[u,v] \in V(G)} d(u,v)$
```
