# 15.2.4 TRIGONOMETRIC SIMILARITY MEASURES

Let $\mathcal{M}$ and $\mathcal{L}$ be any two $Sph_H\_N_S$ on $\mathcal{X}$. Then the three trigonometric similarity measures tangent, cosine and cotangent are defined as:

+   (i) $TAN\_S(\mathcal{M}, \mathcal{L}) =$

```
$$\frac{1}{n} \left[ \sum_{i=1}^{n} |tan\left(\frac{\pi}{12}\right)| |\mathcal{M}_i(\mathbf{p}_i) - \mathcal{L}_i(\mathbf{p}_i)| + |\mathcal{M}_f(\mathbf{p}_i) - \mathcal{L}_f(\mathbf{p}_i)| \right] + [|\mathcal{M}_g(\mathbf{p}_i) - \mathcal{L}_g(\mathbf{p}_i)|\right]$
```

+   (ii) $COT\_S(\mathcal{M}, \mathcal{L}) =$

```
$$\frac{1}{n} \left[ \sum_{i=1}^{n} cot\left(\frac{\pi}{4}\right) + |\mathcal{M}_i(\mathbf{p}_i) - \mathcal{L}_i(\mathbf{p}_i)| + |\mathcal{M}_f(\mathbf{p}_i) - \mathcal{L}_f(\mathbf{p}_i)| \right] + [|\mathcal{M}_g(\mathbf{p}_i) - \mathcal{L}_g(\mathbf{p}_i)|\right]$
```

+   (iii) $COS\_S(\mathcal{M}, \mathcal{L}) =$

```
$$\frac{1}{n} \left[ \sum_{i=1}^{n} \frac{\mathcal{M}_i(\mathbf{p}_i) \cdot\ \mathcal{L}_i(\mathbf{p}_i) + |\mathcal{M}_f(\mathbf{p}_i) \cdot\ \mathcal{L}_f(\mathbf{p}_i)| + |\mathcal{M}_g(\mathbf{p}_i) \cdot\ \mathcal{L}_g(\mathbf{p}_i)|}{\sqrt{\mathcal{M}_i(\mathbf{p}_i)^2 + \mathcal{L}_i(\mathbf{p}_i)^2} \cdot \sqrt{\mathcal{M}_f(\mathbf{p}_i)^2 + \mathcal{L}_f(\mathbf{p}_i)^2}} \right]$
```

# 15.2.5 PROPERTIES OF TRIGONOMETRIC SIMILARITY MEASURES

Theorem 2.5.1 Let $\mathcal{M}$ and $\mathcal{L}$ be any two $Sph_H\_N_S$ on $\mathcal{X}$. Then

+   (i) $TAN\_S(\mathcal{M}, \mathcal{L}) \leq 1$
(ii) $TAN\_S(\mathcal{M}, \mathcal{L}) = 1$ if and only if $\mathcal{M} = \mathcal{L}$
(iii) $TAN\_S(\mathcal{M}, \mathcal{L}) = TAN\_S(\mathcal{L}, \mathcal{M})$
(iv) If $Q$ is a $Sph_H\_N_S$ in $\mathcal{X}$ and $\mathcal{Q} \subseteq \mathcal{L}$, then $TAN\_S(\mathcal{M}, Q) \leq TAN\_S(\mathcal{M}, \mathcal{L})$ and $TAN\_S(\mathcal{L}, Q) \leq TAN\_S(\mathcal{L}, \mathcal{Q})$

Proof:

+   (i) $\mathbb{T}, \mathbb{I},$ and $\mathbb{F}$ lie between 0 and 1. Hence, $TAN\_S(\mathcal{M}, \mathcal{L}) \leq 1$.
(ii) For any two $Sph_H\N_S$ $\mathcal{M}$ and $\mathcal{L}$,
$\mathcal{M} = \mathcal{L} \Rightarrow \mathcal{M}_i(x) = \mathcal{L}_i(x)$ and $\mathcal{M}_f(x) = \mathcal{L}_f(x)$.
Therefore, $TAN\_S(\mathcal{M}, \mathcal{L}) = 1$.
Conversely, if $TAN\_S(\mathcal{M}, \mathcal{L}) = 1$
$\Rightarrow |\mathcal{M}_i(\mathbf{p}_i) - \mathcal{L}_i(\mathbf{p}_i)| = |\mathcal{M}_f(\mathbf{p}_i) - \mathcal{L}_f(\mathbf{p}_i)| = |\mathcal{M}_g(\mathbf{p}_i) - \mathcal{L}_g(\mathbf{p}_i)| = 0$.
Therefore, $\mathcal{M} = \mathcal{L}$.
