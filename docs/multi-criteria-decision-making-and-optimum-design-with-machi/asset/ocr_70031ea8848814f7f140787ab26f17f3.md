An intuitionistic fuzzy graph uses both membership and non-membership degrees to model the uncertainty associated with the presence of edges and vertices. This allows for a more flexible representation of uncertainty in graph-based systems. Nagoorgani (2016) characterized double dominance in intuitionistic fuzzy graphs.

# 11.2.1.1 Definition

A fuzzy graph G = (S, $\alpha$, $\mu$) is a triple consisting of a non-empty set S together with a pair of functions: $S ightarrow [0, 1]$ and $\mu: T ightarrow [0, 1]$ such that

```
$\mu(x) \leq \alpha(x) \leq \alpha(y) \forall xy \in T$.
```

# 11.2.1.2 Definition

Let G = (S, T) be an IFG if

+   (1) $S = \{v_1, v_2, v_3, \dots, v_n\}$ such that $\alpha_i: S ightarrow [0, 1]$, $\mu_i: S ightarrow [0, 1]$ denote the degree of membership and non-membership of the element $v_i \in S$, and $0 \leq \alpha_i(v_i) + \mu_i(v_i) \leq 1$ for every $v_i \in S$.
(2) $T \subseteq S \times S$ where $\alpha_{ij}(v_i, v_j): S \times S \rightarrow [0, 1]$, $\mu_{ij}(v_i, v_j): S \times S \rightarrow [0, 1]$ are such that
$\alpha_{ij}(v_i, v_j) \leq \min[\alpha_i(v_i), \alpha_j(v_j)]$, $\mu_{ij}(v_i, v_j) \geq \max[\mu_i(v_i), \mu_j(v_j)]$ denotes the degree of membership and non-membership of the edge $(v_p, v_q) \in T$ respectively, and $0 \leq \alpha_{pq}(v_p, v_q) + \mu_{pq}(v_p, v_q) \leq 1$ for every $(v_p, v_q) \in T$.

# 11.2.1.3 Definition

G = (S, T) is said to be a strong IFG if

```
$\mu_t(xy) = \min[\mu_s(x), \mu_s(y)]$ and
$\sigma_t(xy) = \max[\sigma_s(x), \sigma_s(y)] \forall xy \in T$.
```

# 11.2.1.4 Definition

G = (S, T) is said to be complete and is defined by $C_m(G)$ if $\mu_t(xy) = \min[\mu_s(x), \mu_s(y)]$,

```
$\sigma_t(xy) = \min[\sigma_s(x), \sigma_s(y)] \forall xy \in T$.
```

# 11.2.1.5 Definition

The first Zagreb index in fuzzy graphs was introduced by Kalaithan. S et al. (2019): $M(G) = \sum_{i=1} \sigma(u_i) d_{u_i}^2, \forall u_i \in S$.

# 11.2.1.6 Definition

The second Zagreb index in fuzzy graphs was also introduced by Kalaithan, S. et al. (2019): $M^*(G) = \frac{1}{2} \sum_{ij:T(G)} \sigma(u_i)d_{u_i}d_{u_j}, \forall i \neq j$.
