# Multi-Criteria Decision-Making with Machine Learning

## 10.5 CONCLUSION

For this research, we proposed a hybrid MCDM model for selecting an optimal EVCS site from four cities in India that combined AHP and VIKOR based on multiple conflicting criteria that are crucial in choosing charging sites. The conventional AHP calculates the weights of each attribute, and VIKOR finds the rank of all alternatives. In more detail, AHP coordinates customer views and employs a pyramid shape for dissolving complicated challenges into easier forms, and VIKOR helps to resolve complex decision-making problems that have contradictory criteria and choices by ranking alternatives; customers can arrive at prompt resolution with multiple attempts. The well-structured proposed hybrid model was not only effective for choosing an optimal location for an electric vehicle charging station but can be used to solve complex real-life challenges. The proposed model does not include societal criteria; in the future, we may extend the model by including these criteria to compare different MCDM techniques.
