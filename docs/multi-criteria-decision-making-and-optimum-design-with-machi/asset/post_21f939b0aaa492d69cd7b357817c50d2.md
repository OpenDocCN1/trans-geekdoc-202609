## 15.2 BASIC CONCEPTS

### 15.2.1 SPHERICAL NEUTROSPHIC SET

First, an SNS, calculated as $A = \{(A_r(p), A_i(p), A_f(p)) : p \in X\}$ on $\mathbb{X}$, satisfies the following properties:

- (i) $A_r(p), A_i(p), A_f(p) \in [0,1]$
- (ii) $0 \leq A_r(p) + A_i(p) + A_f(p) \leq 1$
- (iii) $0 \leq A_r(p)^2 + A_i(p)^2 + A_f(p)^2 \leq 1$, for all $p \in \mathbb{X}$

The family of SNSs on $\mathbb{X}$ is denoted $SPH_N_S(\mathbb{X})$.

### 15.2.2 OPERATION OF SNS

Let $\mathcal{M}$ and $\mathcal{L}$ be any two $SPH_N_S$ on $\mathbb{X}$. Then

- (i) $\mathcal{M}^c = \{\mathcal{M}(p), 1-\mathcal{M}(p), \mathcal{M}(p) : p \in \mathbb{X}\}$ is the complement of $\mathcal{M}$
- (ii) $\mathcal{M}\Pi\mathcal{L} = \{\langle\mathcal{M}(p) \wedge \mathcal{L}(p), \mathcal{M}(p) \wedge \mathcal{L}(p), \mathcal{M}(p) \vee \mathcal{L}(p)\rangle\}$
- (iii) $\mathcal{M}\Pi\mathcal{L} = \{\langle\mathcal{M}(p) \vee \mathcal{L}(p), \mathcal{M}(p) \vee \mathcal{L}(p), \mathcal{M}(p) \wedge \mathcal{L}(p)\rangle\}$
- (iv) $O_{SNS} = \{(0,0,1) : p \in \mathbb{X}\}$ is a Null $SPH_N_S$ on $\mathbb{X}$
- (v) $I_{SNS} = \{(1,0,0) : p \in \mathbb{X}\}$ is a Full $SPH_N_S$ on $\mathbb{X}$

### 15.2.3 SIMILARITY MEASURES BETWEEN SNSs

The similarity between the two $SPH_N_S_s$ and $\mathcal{H}$ is defined as $\varrho(\mathcal{G}, \mathcal{H}) = (\varrho_w(\mathcal{G}, \mathcal{H}), \varrho_i(\mathcal{G}, \mathcal{H}), \varrho_f(\mathcal{G}, \mathcal{H}))$ where $\varrho: SPH_N_S(\mathbb{X}) \times SPH_N_S(\mathbb{X}) \to [0,1]$ which satisfies the following properties of:

- (i) $\varrho(\mathcal{G}, \mathcal{H}) = \varrho(B, A)$
- (ii) $\varrho(\mathcal{G}, \mathcal{H}) = 1_{SNS}$ if $A=B$ for all $\mathcal{G}, \mathcal{H} \in SPH_N_S(\mathbb{X})$
- (iii) $\varrho_w(\mathcal{G}, \mathcal{H}) \geq 0$ and $\varrho_i(\mathcal{G}, \mathcal{H}) \geq 0$
- (iv) If $\mathcal{G} \subseteq \mathcal{D}$ for all $\mathcal{G}, \mathcal{D} \in SPH_N_S(\mathbb{X})$, then $\varrho(\mathcal{G}, \mathcal{H}) \geq \varrho(\mathcal{G}, \mathcal{D})$ and $\varrho(\mathcal{H}, \mathcal{D}) \geq \varrho(\mathcal{G}, \mathcal{D})$

where $\varrho_w(\mathcal{G}, \mathcal{H}), \varrho_i(\mathcal{G}, \mathcal{H})$, and $\varrho_f(\mathcal{G}, \mathcal{H})$ represented as the degrees of $\mathbb{T}, \mathbb{I},$ and $\mathbb{F}$ similarity between $\mathcal{G}$ and $\mathcal{H}$, respectively.

## MCDM Modeling Using Spherical Neutrosophic Similarity

### 15.2.4 TRIGONOMETRIC SIMILARITY MEASURES

Let $\mathcal{M}$ and $\mathcal{L}$ be any two $SPH_N_S$ on $\mathbb{X}$. Then the three similarity measures tangent, cosine and cotangent are defined as:

- (i) $TAN_S(\mathcal{M}, \mathcal{L}) = \frac{1}{n} \sum_{i=1}^{n} [tan\left(\frac{\pi}{2}\right)|\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)| + |\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)| + |\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)|]$
- (ii) $COT\_S(\mathcal{M}, \mathcal{L}) = \frac{1}{n} \sum_{i=1}^{n} [cot\left(\frac{\pi}{4}\right)|\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)| + |\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)| + |\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)|]$
- (iii) $COS\_S(\mathcal{M}, \mathcal{L}) = \frac{1}{n} \sum_{i=1}^{n} \frac{\mathcal{M}_i(p_i) \cdot \mathcal{L}_i(p_i) + |\mathcal{M}_f(p_i) \cdot \mathcal{L}_f(p_i)| + |\mathcal{M}_g(p_i) \cdot \mathcal{L}_g(p_i)|}{\sqrt{\mathcal{M}_i(p_i)^2 + \mathcal{L}_i(p_i)^2} \cdot \sqrt{\mathcal{M}_f(p_i)^2 + \mathcal{L}_f(p_i)^2}}$

### 15.2.5 PROPERTIES OF TRIGONOMETRIC SIMILARITY MEASURES

Theorem 2.5.1 Let $\mathcal{M}$ and $\mathcal{L}$ be any two $SPH_N_S$ on $\mathbb{X}$. Then

- (i) $TAN_S(\mathcal{M}, \mathcal{L}) \leq 1$
- (ii) $TAN_S(\mathcal{M}, \mathcal{L}) = 1$ if only if $\mathcal{M} = \mathcal{L}$
- (iii) $TAN_S(\mathcal{M}, \mathcal{L}) = TAN_S(\mathcal{L}, \mathcal{M})$
- (iv) If $Q$ is a $SPH_N_S$ in $\mathbb{X}$ and $\mathcal{Q} \subseteq \mathcal{L}$, then $TAN_S(\mathcal{M}, Q) \leq TAN_S(\mathcal{M}, \mathcal{L})$ and $TAN_S(\mathcal{L}, Q) \leq TAN_S(\mathcal{L}, \mathcal{Q})$

Proof:

- (i) $\mathbb{T}, \mathbb{I},$ and $\mathbb{F}$ lie between 0 and 1. Hence, $TAN_S(\mathcal{M}, \mathcal{L}) \leq 1$.
- (ii) For any two $SPH_N_S$ $\mathcal{M}$ and $\mathcal{L}$, $\mathcal{M} = \mathcal{L} \Rightarrow \mathcal{M}_i(x) = \mathcal{L}_i(x)$ and $\mathcal{M}_f(x) = \mathcal{L}_f(x)$. Therefore, $TAN_S(\mathcal{M}, \mathcal{L}) = 1$. Conversely, if $TAN_S(\mathcal{M}, \mathcal{L}) = 1 \Rightarrow |\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)| = |\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)| = |\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)| = 0$. Therefore, $\mathcal{M} = \mathcal{L}$.
- (iii) The proof is obvious.
- (iv) Since $\mathcal{M}_{\gamma}(p) \ge \mathcal{Q}_{\gamma}(p) \le \mathcal{L}_{\gamma}(p), \mathcal{M}_{\gamma}(p) \le \mathcal{Q}_{\gamma}(p)$ and $\mathcal{M}_{\gamma}(p) \ge \mathcal{Q}_{\gamma}(p) \ge \mathcal{L}_{\gamma}(p)$,Rightarrow $|\mathcal{M}_{\gamma}(p) - \mathcal{L}_{\gamma}(p)| \le |\mathcal{M}_{\gamma}(p) - \mathcal{Q}_{\gamma}(p)|$ and $|\mathcal{Q}_{\gamma}(p) - \mathcal{L}_{\gamma}(p)| \ge |\mathcal{M}_{\gamma}(p) - \mathcal{Q}_{\gamma}(p)|$.

Theorem 2.5.2 Let $\mathcal{M}$ and $\mathcal{L}$ be any two $SPH_N_S$ on $\mathbb{X}$. Then

- (i) $COS_S(\mathcal{M}, \mathcal{L}) \leq 1$
- (ii) $COS_S(\mathcal{M}, \mathcal{L}) = 1$ if only if $\mathcal{M} = \mathcal{L}$
- (iii) $COS_S(\mathcal{M}, \mathcal{L}) = COS_S(\mathcal{L}, \mathcal{M})$
- (iv) If $Q$ is a $SPH_N_S$ in $\mathbb{X}$ and $\mathcal{Q} \subseteq \mathcal{L}$, then $COS_S(\mathcal{M}, Q) \leq COS_S(\mathcal{M}, \mathcal{L})$ and $COS_S(\mathcal{L}, Q) \leq COS_S(\mathcal{L}, \mathcal{Q})$

Proof:

- (i) $\mathbb{T}, \mathbb{I},$ and $\mathbb{F}$ lie between 0 and 1. Hence, $COS_S(\mathcal{M}, \mathcal{L}) \leq 1$.
- (ii) For any two $SPH_N_S$ $\mathcal{M}$ and $\mathcal{L}$, $\mathcal{M} = \mathcal{L} \Rightarrow \mathcal{M}_i(x) = \mathcal{L}_i(x)$ and $\mathcal{M}_f(x) = \mathcal{L}_f(x)$. Therefore, $COS_S(\mathcal{M}, \mathcal{L}) = 1$. Conversely, if $COS_S(\mathcal{M}, \mathcal{L}) = 1 \Rightarrow |\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)| = |\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)| = |\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)| = 0$. Therefore, $\mathcal{M} = \mathcal{L}$.
- (iii) The proof is obvious.
- (iv) Since $\mathcal{M}_{\gamma}(p) \ge \mathcal{Q}_{\gamma}(p) \le \mathcal{L}_{\gamma}(p), \mathcal{M}_{\gamma}(p) \le \mathcal{Q}_{\gamma}(p)$ and $\mathcal{M}_{\gamma}(p) \ge \mathcal{Q}_{\gamma}(p) \ge \mathcal{L}_{\gamma}(p)$.

Theorem 2.5.3 Let $\mathcal{M}$ and $\mathcal{L}$ be any two $SPH_N_S$ on $\mathbb{X}$. Then

- (i) $COT_S(\mathcal{M}, \mathcal{L}) \leq 1$
- (ii) $COT_S(\mathcal{M}, \mathcal{L}) = 1$ if only if $\mathcal{M} = \mathcal{L}$
- (iii) $COT_S(\mathcal{M}, \mathcal{L}) = COT_S(\mathcal{L}, \mathcal{M})$
- (iv) If $Q$ is a $SPH_N_S$ in $\mathbb{X}$ and $\mathcal{Q} \subseteq \mathcal{L}$, then $COT_S(\mathcal{M}, Q) \leq COT_S(\mathcal{M}, \mathcal{L})$ and $COT_S(\mathcal{L}, Q) \leq COT_S(\mathcal{L}, \mathcal{Q})$
