# 4.4.4 THE FIRST VALIDATION EXPERIMENT

To corroborate the obtained optimal setting parameters (A2, B3, C3, D1, E3, F3, G3), we conducted a supplementary validation experiment. The tensile test results for this additional sample are presented in Figure 4.6, revealing a maximum of 32.748 MPa. Notably, this value exceeded the values obtained in the preceding 18 experimental trials, underscoring the improved outcome achieved through using the Taguchi method.
