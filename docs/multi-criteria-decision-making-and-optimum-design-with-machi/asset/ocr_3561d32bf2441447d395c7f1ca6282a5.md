+   Convert the cipher text to TFS $(a,b,c,d)$. For x, choose any number between $(a,d)$, give the fuzzy number

```
$$\mu_{m}(x) = \begin{cases} 0 & \text{if } x < a \ x-a & \text{if } a \leq x \leq b \ b-a & \frac{d-x}{d-c} & \text{if } c \leq x \leq b \ 0 & \text{if } x > d \end{cases}$
```

Now the cipher text is given $(a,b,c^*)$ where $c^*$ is the fuzzy number found above. Here the secret key is the value of $x$ and the range $(Y)$ chosen for finding TFS $(a,b,c^*,d)$.

# 17.2 DECRYPTION

```
$$\mu_{m}(x) = \frac{c^* \times \gamma}{d-c}$
```

where $d-c=Y\n\Rightarrow d-Y=c$

The RSA algorithm itself does not naturally contain a two-level encryption scheme. RSA uses a public key for encryption and a private key for decryption, resulting in a single level of encryption and decryption. On the other hand, TFSs are combined with RSA encryption for better security. The second level of decryption is as follows:

```
$$m_e = \frac{c^{-d}(mod \ p) - \underline{b}}{\underline{a}}$\nm_{f} = \frac{c^{-d}(mod \ q) - \underline{b}}{\underline{a}}$\nm_{g} = \frac{c^{-d}(mod \ r) - \underline{b}}{\underline{a}}$
```

Therefore, the original message m is now $(m = m_e = m_f = m_g)$.
