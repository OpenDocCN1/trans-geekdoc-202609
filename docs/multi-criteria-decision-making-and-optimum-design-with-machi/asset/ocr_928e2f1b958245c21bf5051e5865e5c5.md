# 16.3.1.2 Theorem 2

Let $K_m\odot T_m$ be a graph with $n$ vertices where $m\ge 3$. Then the hyper Wiener index of the graph $K_n\@T_n$ is

```
$HW_{TG}(K_m\odot T_m)=\frac{m(7m^3+216m^2+2192m-6528)}{1024}$
```

Proof

Theorem is proved by mathematical induction on $m\ge 3$ vertices. If $m=3$, then the total number of vertices of $K_m\odot T_m$ is $m=4n$, or 12. The hyper-Wiener index of $K_n\@T_n$ is 738.

```
$HW_{TG}(K_m\odot T_m)=\frac{m(7m^3+216m^2+2192m-6528)}{1024}$
```

```
$HW_{TG}(K_m\odot T_m)=\frac{12(7(12)^3+216(12)^2+2192(12)-6528)}{1024}=738$
```

Consequently, for $m=3$ vertices, the theorem holds valid. Assume that for $m=s$, the theorem holds valid.

```
$HW_{TG}(K_m\odot T_m)=\frac{s(7s^3+216s^2+2192s-6528)}{1024}$
```
