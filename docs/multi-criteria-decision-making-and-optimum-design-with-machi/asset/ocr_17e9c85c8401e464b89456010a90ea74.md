# 16.2.8 DEFINITION

A graph $sHW_{TG}(G)$ can be calculated by adding the graph's wiener index and half of the total squared distances between all of the graph's vertex pairs:

```
$HW_{TG}(G) = \frac{1}{2} \sum_{[u,v]\in V(G)} d(u,v) + \frac{1}{2} \sum_{[u,v]\in V(G)} d(u,v)^2$
```

# 16.3.1 HYPER-WIENER INDEX OF A GRAPH

# 16.3.1.1 Theorem 1

Let $K_m @(P_m \odot K_1)$ be a graph with $m \ge 3$ vertices. Then the hyper-Wiener index of the graph $K_m @(P_m \odot K_1)$ is

```
$HW_{TG}(K_m @(P_m \odot K_1)) = \frac{m(m^3 + 21m^2 + 144m - 378)}{81}$
```

# Proof

Theorem is proved by mathematical induction on the $m \ge 3$ vertices. If $m = 3$, then the total number of vertices of $K_3 \odot (P_3 \odot K_1)$ is $n=3$, that is 9. Then, the hyper-Wiener index of $K_3 \odot (P_3 \odot K_1)$ is 372 as follows:

```
$HW_{TG}(K_m \Theta(P_m \Theta K_1)) = \frac{m(m^3 + 21m^2 + 144m - 378)}{81} \= \frac{9[(9)^3 + 21(9)^2 + 144(9) - 378]}{81} = 372$
```

Consequently, for $m = 3$ vertices, the theorem holds valid. Assume that for $m = s$, the theorem holds valid.

```
$HW_{TG}(K_m \Theta(P_m \Theta K_1)) = \frac{m(m^3 + 21m^2 + 144m - 378)}{81}$
```
