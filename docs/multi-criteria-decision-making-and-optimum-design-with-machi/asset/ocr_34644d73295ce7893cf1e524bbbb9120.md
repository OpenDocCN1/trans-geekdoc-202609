# 11.2.1.7 Definition

The forgotten index in fuzzy graphs is $F(G) = \sum_{i=1}^{n} \sigma(u_i)d_n^2, \forall u_i \in S$.

# 11.2.1.8 Definition

the harmonic index in fuzzy graphs was introduced by Kalaithan et al. as well:

```
$H(G) = \frac{1}{2} \sum_{u_i \in T(G)} \frac{1}{\sigma(u_i)d(u_i) + \sigma(v_j)d(v_j)}, \forall i \neq j$.
```

# 11.2.1.9 Definition

Kalaithan et al. also introduced the Randić index for fuzzy graphs:

```
$R(G) = \frac{1}{2} \sqrt{\sum_{i=1}^{n} \sigma(u_i)d(u_i) \cdot \sigma(v_j)d(v_j)}}, \forall i \neqneq j$.
```

# 11.3.1 FIRST ZAGREB INDEX

Let $G=(S,T)$ be the IFG when S is a vertex set and T is the edge set on the graph. The first Zagreb index is denoted by $M(G)$ and defined as

```
$M(G) = \sum_{i=1}^{n} [T_S(u_i) \cdot F_S(u_i)]d_n^2$.
```
