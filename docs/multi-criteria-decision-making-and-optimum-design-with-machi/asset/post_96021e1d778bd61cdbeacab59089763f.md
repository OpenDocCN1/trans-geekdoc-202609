## 2.3 FUZZY INFERENCE SYSTEMS

The computational models known as fuzzy inference systems (FISs) use fuzzy logic to simulate human-reasoning in uncertain and imprecise scenarios (Rizvi et al., 2020). Fuzzification, rule base, inference engine, rule evaluation, aggregation, and defuzzification are among their essential parts. Fuzzification is the process of converting crisp input values into fuzzy sets that the system can handle linguistically imprecise data. The fuzzy input and output variables are defined by IF-THEN rules, which make up the base. The system's reaction is decided by the inference engine, which assesses these in light of the input data. Rule outputs are combined via aggregation to capture the overall behavior of the system. Finally, defuzzification transforms the aggregated output into a crisp result. FIS is widely applied in control systems, decision support, pattern recognition, and various domains where modeling uncertainty is crucial for effective decision-making.

### 2.3.1 UNDERSTANDING FUZZY INFERENCE (MAMDANI AND SUGENO MODELS)

FISs are models that leverage fuzzy logic to make decisions and draw conclusions under uncertainty. Two popular types of FIS are the Mamdani model and the Sugeno model, each with distinct characteristics:

### Mamdani Fuzzy Inference

1. **Fuzzification:** Crisp input values are transformed into fuzzy sets using membership functions.
2. **Rule Base:** IF-THEN rules define the relationship between fuzzy input and fuzzy output sets. These rules express linguistic rules in the form "If input is AND input is B THEN output is C."
3. **Inference Engine:** The inference engine evaluates the degree of membership for each rule's antecedent (IF part). Typically, the minimum operator is used for AND operations, and the maximum operator is used for OR operations.
4. **Aggregation:** The activated rule outputs are aggregated using the maximum operator, creating a combined fuzzy output set.
5. **Defuzzification:** The aggregated fuzzy output is converted into a crisp output value using methods such as centroid or mean of max.

### Sugeno Fuzzy Inference

1. **Fuzzification:** Similar to the Mamdani model, crisp input values are fuzzified into fuzzy sets.
2. **Rule Base:** IF-THEN rules in the Sugeno model express relationships in the form "If input is AND input is B THEN output is f(x, y) = P + Q × input1 + R × input2 + ..." where P, Q, R, etc., are constants.
3. **Inference Engine:** The inference engine calculates a output value for each rule rather than a fuzzy set.
4. **Aggregation:** The output values are aggregated using a weighted average or another method.
5. **Defuzzification:** The final output is obtained directly from the aggregation step, as it is already in crisp form.

### Comparison

| Feature | Mamdani | Sugeno |
| :--- | :--- | :--- |
| **Nature of Output** | Fuzzy sets | Crisp values |
| **Interpretability** | Linguistically interpretable | Lacks interpretability |
| **Computational Efficiency** | Less efficient | More efficient |
| **Applications** | Control systems | Economic modeling, optimization |
