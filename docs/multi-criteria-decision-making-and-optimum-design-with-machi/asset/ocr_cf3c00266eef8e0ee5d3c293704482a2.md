# 21.3.2.4 Step 4: Calculate and Analyze the Results

Let $t_{ij}, j = 1, 2, \dots, n$ be the elements of matrix T and the sum of the rows and the sum of the columns are respectively denoted as vector $d$, and $r$ using Equations (21.6) and (21.7):

$T = \left[ t_{ij} \right]_{n \times n}, ij \ (\in: 1, 2, \dots, n)$

$d = \left[ \sum_{j=1}^n t_{ij} \right]_{n \times 1} \quad (21.6)$

$r = \left[ \sum_{i=1}^n t_{ij} \right]_{1 \times n} \quad (21.7)$

where $d$, represents the sum when $i$ influences other elements and $r$ represents the sum when element $j$ is influenced by other elements. The horizontal axis vector $(d+r)$ is by adding vector d to vector r, called prominence, which indicates the element's degree of influence. Similarly, the vertical axis vector $(d-r)$ is by deducting vector d from vector r, called a relationship, which separates criteria into cause or effect. Conceptually, when $(d-r)$ is positive, the criterion is a cause and when negative it's an effect. Diagrams can visualize the complicated causal relationships between criteria as visible structural models, providing valuable problem-solving insight by recognizing the differences between causes and effects.
