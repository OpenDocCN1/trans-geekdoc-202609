# 2.2.1 Fuzzy Sets And Membership Functions

# 2.2.1.1 Fuzzy Sets

Developed by Lotfi A. Zadeh in 1965, fuzzy sets are an extension of classical theory that account the natural imprecision and vagueness seen in real-world systems. An element in a classical set is either a part of the set or it is not. A fuzzy set, on the other, expresses the extent to which an element is a part of the set and permits membership. An element in a fuzzy set has a membership that falls between 0 and 1.

In mathematical terms, a membership function μ(x), where x is an element of X, defines a fuzzy set A in a universe of discourse X. Each element is given a degree of membership μ(A) by the membership function, which indicates how much x belongs to the fuzzy set A. Take into consideration, for instance, a fuzzy set “tall” within the discourse universe “height.” A tall person may be assigned a high value by the membership function μTall(x), a medium value by someone of ordinary height, and a low value by someone of modest stature.
