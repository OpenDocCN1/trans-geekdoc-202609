# 23.1 INTRODUCTION

Multicriteria decision-making (MCDM) refers to making decisions when there are multiple factors to consider that conflict with each other, MCDM techniques have to be applied extensively across many fields, beginning with testing the applicability of different decision-finding methods themselves (Martin Aruldoss et al., 2013; Jafar Rezazai, 2015).

For instance, researchers have used fuzzy MCDM in civil engineering (Zhi Wen et al., 2021) and used MCDM algorithm to evaluate the performance of Indonesia’s defense military (A. P. Samarno et al., 2021). Researchers have used VIK for ranking (Hamed Taherood et al., 2023a) and used TODIM to analyze weights (A. Sahaya Sudha et al., 2020). Other researchers used outranking for decision-making in neurocentric soft-sets (Vakkas Ulucay et al., 2019) and described using inter-valued neurocentric soft sets in certain operations (Rana Muhammad Zulqarnain et al., 2022). One group compared fuzzy fuzzy cognitive maps with respect to COVID-19 variables (Regan Murugesan et al., 2023). Another applied neuro neurocentric cognitive methods with SWOT analysis (Jagan Obbenini et al., 2023).
