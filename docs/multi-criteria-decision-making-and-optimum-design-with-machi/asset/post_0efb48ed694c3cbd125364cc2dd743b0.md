### 3.2.1 DESIGN OF EXPERIMENTS

In this study, we utilized the Taguchi orthogonal array $L_{27}$ experimental design to decrease the number of trials. We analyzed five 3-level machining and lubrication parameters.

### 3.2.2 EXPERIMENT SETUP

We prepared workpieces measuring $35 \times 35 \times 100$ mm. All faces of the specimens were ground to ensure high accuracy in the positioning process. Experimental runs utilized a 16 mm diameter silent tool holder (Sandvik, 390R-070202-MM 1040 inserts), selected for suitability in face milling optimization based on experimental Ti-6AI-4V alloy data.

Cutting and lubrication parameters aligned with tool manufacturer recommendations, expert input, and previous findings. Table 3.1 presents the material variant levels. In the experiment, we employed the DMU50 CNC device shown in Figure 3.2, operating with an MQL setup. We affixed the milling jig to a force sensor, shown in Figure 3.2a, which is part of the experimental setup for machining. The cutting force $F$ derived from $F_x$, $F_y$, and $F_z$ measured by a Kistler dynamometer 9139AA, and we computed MRR using Equation (3.1). For each test piece, we measured Ra using a Mitutoyo Surface JS-201, following the ISO 1997 standard, as depicted in Figure 3.2c and following the formula $R_a = f(P,Q,V_c,f_c,a_p)$, $F_c = f2(P,Q,V_c,f_c,a_p)$ with the data in Table 3.1. The outcomes derived from the experimental results were methodically computed and systematically recorded in Table 3.2.

### 3.3.1 SUPPORT VECTOR REGRESSION

Support vector machine (SVM) stands out as a supervised learning method extensively applied in machine learning for classification. Its primary aim is to identify the optimal hyperplane, which might be linear or nonlinear, that separates data into two classes. This objective is accomplished by strategically placing the hyperplane to maximize the margin between the hyperplane and the closest data point from each class. Given hyperplane equation $w \cdot x + b = 0$, the core objective of SVM is to calculate $w$ and $b$ to ensure the largest margin between the two.

The SVM algorithm, well-known for its proficiency in classification tasks, extends its capabilities to regression via its variant known as support vector regression. SVR aims to construct a function that precisely represents the relationship between input features and continuous outcome, focusing on reducing discrepancies. While SVR is grounded in the same underlying principles as SVM, it is specifically adapted to regression contexts.

At the heart of SVR is a unique loss function introduced by Vapnik (C and Vapnik, 1995; Vapnik, 2000, 1998). This loss function is characterized by its tolerance for errors within a specified epsilon range for points that are not close to the true value. In essence, the function assigns zero error to all training points that fall within this range.

In SVR, the initial step involves transforming the input variable $x$ into $m$-dimensional feature space through a nonlinear mapping function. After this transformation, a linear model is developed within this higher-dimensional space. The construction of this linear model (Figure 3.5) adheres to Equation (3.1), which succinctly describes the association between transformed input variables and target variable within the enlarged feature space. This approach allows SVR to accommodate nonlinear relationships (Figure 3.6) in the data by leveraging the power of linear models in a higher-dimensional context:

$$f(x,w) = \sum_{i=1}^{m} w_i \cdot g_i(x) + b \quad (3.1)$$

![](img/62c36bee0e5ae6b397770e7de372b0e7_85_0.png)

FIGURE 3.6 Nonlinear regression with the range of epsilon.

where $g(x_{ji}) = 1, 2, \dots, m$ is the set that comprises nonlinear mapping functions. The accuracy of the estimate is evaluated by loss function $L(y,f(x))$. SVR uses a loss function called epsilon (Equation (3.2)), an insensitive loss function proposed by Vapnik (C and Vapnik, 1995; Vapnik, 2000, 1998):

$$L=\begin{cases}0 & \text{if} |y-f(x,w)| \le \epsilon \\ |y-f(x,w)| & \text{otherwise}\end{cases} \quad (3.2)$$

That is, SVM performs linear regression in multidimensional feature space using function $L$ and minimizing $||w||^2$ to decrease the complexity of the model. This problem can be solved by introducing slack variables $\zeta_i$ and $\zeta_i^*$ with $i=1, 2, \dots, n$ to measure the deviation of the training samples which lies outside of the epsilon range. Therefore, SVR is minimized by the function Equation (3.3) with the constraints of Equation (3,4):

$$\min\frac{1}{2}||w||^2+C\cdot \sum_{i=1}^{n}(\zeta_i+\zeta_i^*) \quad (3.3)$$

$$\begin{cases}y_i-f(x,w) \le \epsilon+\zeta_i^* \\ f(x,w)-y_i \le \epsilon+\zeta_i \\ \zeta_i,\zeta_i^* \gt 0\forall i=1,\dots,n \end{cases} \quad (3.4)$$

Applying the duality theorem for minimizing problems, we finally obtain the function $f(x)$ (Equation (3,5)):

$$f(x)=\sum_{i=1}^{n}(\alpha_i-\alpha_i^*)\cdot K(x_i,x)+b \quad (3.5)$$
