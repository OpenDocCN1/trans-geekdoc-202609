# 7.5 PERSONALIZED REPRODUCTIVE HEALTH DIAGNOSTICS AND REMEDIES

Personalized diagnostics are an extension of the procedures used to select proactive measures discussed before. An extensive inquiry has been carried out to examine the genetic and epigenetic elements linked to the occurrence of early embryo mortality (Vazquez et al. 2021). However, none of these appears to be the main cause, indicating that a combination of causes, rather than one, seems to be accountable. There is a wide-spread agreement that it is morally unacceptable to intentionally destroy embryos purely because they have been diagnosed with one or a few issues.
