# I. 引言

在机器学习中，特征选择（FS）是降低过拟合风险、提高所学模式的泛化能力以及减少生成的学习模型计算成本的一个非常有挑战性且至关重要的步骤[1]。在许多金融应用中，数据大多是噪声、冗余和/或相关的，因此特征选择对于增强预测模型的性能至关重要[3]。本质上，从完整的输入特征集中找到最优特征子集，以提高最终机器学习模型的性能。

特征选择算法分为三大类：过滤（filter）、包装（wrapper）和嵌入（embedded）技术[4]。过滤技术如信息增益、互信息、费舍分数、相关特征等，仅根据数据的特征对特征进行评估，而不涉及任何学习算法[6]。由于选择机制相对简单，这些技术存在主要缺点，未能考虑所选特征对学习算法性能的影响[4]。

[7]，包装技术将特征选择与学习算法直接连接，因此更容易获得更好的结果。尽管学习模型需要在这个过程中不断重新评估所选特征，但包装技术的计算开销非常大，特别是在处理具有大量特征的复杂学习模型时。但至少嵌入方法是作为特定学习模型的一部分集成的。具体而言，特征的选择和学习模型的训练是同时完成的[8]。

在这工作中，研究重点是包装技术。基本上，每个带有二值变量的优化问题都指定是否包含某个特征。目标是找到穷尽搜索空间的最方法。处理高维数据的特征选择变得越来越困难。例如，如果一个数据集包含20个特征，特征子集的数量为$2^{20}$（即1,048,575）。最近的研究表明，元启发式优化算法是解决这一特征选择问题的可能替代方案，某些算法实现了令人深刻的性能。目前已为机器学习的特征选择提出了许多元启发式方法。示例包括传统方法，如遗传算法（GA）[9]、粒子群优化（PSO）[10）、二值狼群优化（BGWO）[11）、散列搜索算法（SSA）[12）、二值蝗虫优化算法（BGO）[13）、二值搜索算法（BSGA）[14）、二值布谷搜索（BCS）[15]。

第三节详细介绍了使用不同技术的BAMPOA两种变体。第四节分析并讨论了在分类基准数据集和用于预测的股票指数上的实验结果。第五节总结了工作，并为未来的研究方向提供了启发。

最优地受病毒种子[17]启发，自适应多种群优化算法（AMPOA）是一种最近提出的用于处理连续优化问题的元启发式算法。AMPOA将种群智能中的几个有用特征集成到利用多种群的优化算法中。AMPOA方法精心设计了多种群的新型控制机制、解克隆机制和重置操作，以解决复杂搜索空间中的全局或次优解。

# II. 自适应多种群优化算法

在本节中，自适应多种群优化算法（AMPOA）最初受[17]启发，所示：

## A. 种群

在AMPOA中，每个种群由个体组成。种群大小由$N_{pop}$表示。每个个体代表当前问题的一个可能解，正式定义为：

```
$X_i = [x_{i,1}, x_{i,2}, ..., x_{i,n}]^T, X_i \in S$
```

利用基于群体的方法的概念，AMPOA算法设计在多个种群中。AMPOA的整个种群分为五个子类：随机搜索组、全局搜索组、局部搜索组、领导者组和迁移组。根据不同的标准为个体分配不同的搜索行为。通常，每个个体都可以是领导者组中选出的最佳解之一。为了简单起见，认为对于后续的所有决策，只有一个最佳解染色体被选入领导者组，作为种群目前为止发现的最佳解。在具有大步长的全局搜索组中，在整个搜索空间内寻找最佳解。在局部搜索组中在较小的搜索空间内进行局部搜索。随机搜索组中的个体基本上在整个搜索空间内随机行走。最后，迁移组由经典的差分进化算法（DE/rand/1）赋能，其具有与其他搜索组不同的机制，以获得更高质量的解。

## B. 操作

AMPOA方法采用了以下六种操作：初始化、选择、更新、变换和重置，下文解释。

### 1. 初始化

在起始点，整个种群的所有解在搜索空间内通过均匀分布随机生成。为了评估所提方法的性能，在12个基准数据集集上进行了基于K最近邻（KNN）分类器的包装方法比较研究。将BAMPOA算法与包括GA和BPSO在内的传统技术，以及其他先进方法BCS、二值搜索算法（BSDA）[18]和带SMO函数的二值社会优化算法[19]进行了比较。然后，将BAMPOA应用于股票价格预测的实际应用，使用支持向量回归（SVR）预测次日市场指数值。本文的其余部分组织如下。第二节介绍了连续的BAMPOA算法用于

2) 选择：

如上所述，在每次迭代中，从随机搜索组、全局搜索组或局部搜索组中选择最有利的解选入领导者组。当发现新的最优解时，领导者组的个体将被更新。

3) 更新：

更新机制取决于每个种群：

- 随机搜索组：随机搜索组的个体在整个搜索空间内进行随机搜索。

- 全局搜索组：如(2-3)，全局搜索组的通过以下方式更新：
```
$S_i^{t+1} = S_i^t + w(g_{best}^t - S_i^t)$,
```
其中$S_i^t$是$t$时刻的解，$w$是权重因子，$g_{best}^t$是$t$时刻种群发现的最佳解，$w \in (0,1)$。

- 局部搜索组：局部搜索组个体的更新函数所示(4-6)：
```
$\delta_i = \gamma \delta_i$
$S_i^{t+1} = X_i^t + \delta_i$
```
其中$X_i^t$是$t$时刻的解，$\gamma \in (0,1)$是常数系数，$Gaussian(0, \delta_i)$是均值为0标准差为$\delta_i$的高斯函数。

- 领导者组：由于领导者组中的个体是最优解，因此不需要更新。

- 迁移组：在AMPOA中，迁移组通过DE算法开发。其大小为$N_{pop}(1-Pr)$。

4) 变换

变换的目标是在个体之间传播信息以提高有效性。AMPOA设计了一种三步机制。第一步，领导者组、全局搜索组和局部搜索组的个体组成源组，而随机搜索组按降序排列的所有解组成目标组。将所有按升序排列的解中的每个排序个体与随机搜索组的排序个体配对。然后，目标组的每个个体根据概率转换为全局搜索组或局部搜索组。例如，配对概率$(P_G^t + P_L^t) = 1$表示随机搜索组个体的变换概率。转换为全局搜索组后，对每个个体执行详细更新：

- 变换到全局搜索组：当随机搜索组的个体变换到全局组时，应用单点交叉。随机搜索组个体的每个值将根据预定义概率被配对个体的值。

- 变换到局部搜索组：当随机搜索组的个体与全局搜索组的个体配对时，源组的解转换为局部搜索组。

5) 重置：

由于强大的变换，随机搜索组的所有个体可能会被变换多次，导致局部迁移。重置操作作为一种机制，可以有效恢复全局搜索组或局部搜索组中较差个体的比例，该操作带有每次迭代生成的随机重置参数（0.1到0.9之间）。此外，实现了倍增机制：局部或全局搜索组的一个块将移动到全局搜索组，或者某些选定的随机搜索组个体将在重置过程中发生偏移。





### 6) 迁移

AMPOA 引入迁移操作作为一种额外功能，以增强其在复杂优化问题中的搜索能力。当迁移搜索组失败时，该解在 rand(0,1) ≤ 0.5 或达到迭代次数的情况下，可能会进入领导组以恢复当前最优解。

## C. 算法流程

首先，将算法的用户定义参数和问题的适应度函数作为输入提供以执行 AMPOA。进行初始化过程。然后，在每次迭代中，执行算法操作；分别重复函数评估、选择、变换、迁移和更新，直到满足预定义的准则。

# III. 二值自适应多种群优化算法

任何二值问题的解定义如下：

```
$X_i = [x_1^i, x_2^i, ..., x_n^i], x_j^i \in \{0, 1\}$
```

因此，原始的 AMPOA 方法可以通过舍入或转换函数适配以解决二值问题，考虑如下：

## A. 舍入法

舍入法对于处理二进制搜索空间中的离散优化问题非常简单且直接。基本上，名为 BAMOA-R 的 AMPOA 算法变体继承了连续 AMPOA 的主体，同时采用了以下技术：

```
$X_i = \begin{cases} 0, & X_i < 0.5 \\ 1, & X_i \geq 0.5 \end{cases}$
```

其中 $X_i$ 是连续变量 $x_i$ 的二值转换。

# IV. 实验结果与讨论

为了仔细评估建议方法的性能，首先使用最先进的优化器对 BAMOA-R 和 BAMOA-T 在 12 个已知基准数据集上的特征选择进行测试。BAMOA-R 方法在支持向量回归（SVR）的第一组测试中获得最佳性能。在评估中，特征选择被定义为二值优化问题，每个输入特征关联二进制变量 0 或 1，表示是否被选择。

## B. 股票指数预测

在许多金融应用中，股市预测对投资管理、风险评估和市场预测具有重要作用。由于大多数输入特征可能存在噪声且与开发股票任务的机器学习模型无关，特征选择成为执行价格预测挑战的关键过程。

在本研究中使用带有径基函数的SVR算法预测全球金融市场10个主要股票指数的次日值。所使用的10个股票指数是道琼指数（DJIA）、巴黎40指数（CAC40）、金融指数（FCI）、香港恒生指数（HSI）、恒生指数（HSSI）、纳斯达克综合指数（NKI）、韩国指数（KOSPI）、墨西哥指数（INTR）、上海100指数（N100）、日经225指数（N225）和上海综指（SSE）。

数据集从2016年1月1日至2018年12月31日收集，为三年。作为指标的最相关特征通过一个名为Tablib的开源库完成。每个输入特征和输出标签都被归一化到0到1范围，以避免特征优化过程中的任何偏差。数据集被分为训练、验证和测试三部分。

在回归器的训练阶段，采用优化器来选择输入特征。适应度函数根据回归误差和所选特征的百分比定义：

```
$min Fitness = \gamma(R) + \beta\frac{|M|}{|N|}
```

其中 $\gamma(R)$ 是基于大多数数据的回归误差，$|M|$ 是特征总数，[N] 是参数 $\alpha$ 和 $\beta$，其定义与(17)相同。

种群大小和最大次数（MaxFe）与之前在12个基准数据集上的测试相同。所有算法的参数，除适应度函数中第一句的$\alpha$和$\beta$外，均设置为1.00和0.05。SVR的参数$C_{\gamma}$、$\gamma$ 和 $\epsilon$设置为64、1.0和0.056。
