MI detection and location tasks may have overlapping key features and additional information that can be complementary.

Multi-task frameworks have been shown to play a gainful role in similar tasks by learning shared and complementary information between multiple tasks to optimize the performance of all tasks [42–44]. And we use the most classical multi-task framework, a shared-bottom model [42]. This model achieves improved classification performance by sharing the bottom representation across multiple tasks and performing loss optimization within multiple tasks. Thus, MCA-net based on this multi-task framework can more effectively combine MI detection and location tasks. The framework can be expressed by :

```
y^n = F^n(\boldsymbol{C}(\boldsymbol{x}))
```

In this paper, we design three related tasks: (1) a two-category MI detection task (Detection), which aims to identify whether people are MI or HC; (2) a five-category MI location task (Location-5), whose goal is to distinguish AMI, ASMI, ALMI, other and HC populations; (3) a seven-category MI location task (Location-7), which objective is to distinguish AMI, ASMI, ALMI, IMI, ILMI, other and HC populations. For the Location-5 task, we select it because a large proportion of patients with MI have Generalized Anterior MI (GAMI) [36], which is consisting of AMI, ASMI, and ALMI, so we first focus our task on differentiating GAMI and classifying the remaining MI labels into other categories. We then conside the task for most of the existing studies and the relevance of that task to the Location-5 task, as well as the distribution of labels on the dataset. Ultimately, the IMI and ILMI are additionally selected for classification based on the Location-5 task to form the Location-7 task.

Specifically, the multi-task framework shares parameters and feature representations among the three tasks in the channel attention network, which is represented as a function **C**. While _n_=1_,_2_,_3 for each task, respectively. Then we get each task output _y^n_ after passing through the corresponding fully connected layer _F^n_.

The losses of these tasks in the multi-task framework are combined in the form of a weighted sum for joint optimization, and the total loss can be expressed as :

```
L_{total} = aL_d + bL_{l-5} + cL_{l-7}
```

where L_d, L_{l-5}, L_{l-7} correspond to the Detection, Location-5 and Location-7 tasks, respectively, and a, b, c are the weights for the three related tasks.

# ## 5. Experiments and results

In this section, we fully evaluate MCA-net on the PTB and PTBXL datasets and compare it with state-of-the-art methods for automatic MI detection and location. In addition, we perform a significance test of the results of our experiments to show the improvements in our approach.

# ### 5.1. Comparison methods

For a comprehensive assessment, we conduct comparative experiments on our method and other three state-of-the-art MI classification methods, i.e., MFB-CBRNN [23], ML-ResNet [22], and ML-Net [24] on both the PTB and PTBXL datasets.

+   * **MFB-CBRNN**: MFB-CBRNN used a multi-lead framework for MI detection based on the 12-lead ECGs. To fully utilize the ECG waveform information contained in all 12 leads. 12 multiple-feature-branch was employed to extract features within each lead which was mainly composed of convolutional layers. For effective feature fusion, MFB-CBRNN also used a bidirectional LSTM to integrate all the features output from each lead branch.

+   * **ML-ResNet**: ML-ResNet also employed a multi-lead framework for MI detection and location, but it used a residual-based network structure in designing multi-feature branches. Each multi-feature branch mainly consisted of three stacked residual blocks, each of which included three convolutional layers and a skip connection. Thus, ML-ResNet can be layered to learn feature representations within the leads and perform feature fusion.

+   * **ML-Net**: ML-Net also had a novel channel branch structure based on a multi-lead framework. The branch structure is designed as three parallel convolutional networks which used setting different convolutional kernel sizes to integrate multi-scale features within the leads. However, unlike the above two approaches, ML-Net only used four leads ECG data to accommodate the lightweight needs of portable devices.

Unlike these methods, our approach combines 2-D and 1-D residual blocks for extracting early significant features and finer-grained features. And we also used the SE module and skip connections in the MCA-net for feature weighting and to prevent loss of valid information. Finally, by introducing a multi-task framework, the inter-task correlation and complementarity are fully exploited to extend the MCA-net to individual tasks and improve the overall classification performance. Because MFB-CBRNN, ML-ResNet, and ML-Net are all originally designed for different MI classification tasks, using different amounts of data and different means of data processing. We extend them to our task by unifying the data inputs and modifying their corresponding classification layers for a fair comparison.

# ### 5.3. Evaluation metrics

In this work, the model performances on the PTB dataset are evaluated by three metrics, namely, sensitivity (Sen), specificity (Spe), and accuracy (Acc). The Sen, also called recall, represents the percentage of positive samples correctly predicted by the model over the overall positive samples. Conversely, Spe represents the percentage of negative samples correctly predicted by the model over the overall negative samples. While, the accuracy rate (Acc) is the percentage of all correctly identified samples over the total samples. These three evaluation metrics can be calculated by the following equation:

```
Sen = \frac{TP}{TP + FN}
```

```
Spe = \frac{TN}{TN + FP}
```

```
Acc = \frac{TP + TN}{TP + TN + FP + FN}
```

Where TP (True Positive) and TN (True Negative) refer to the number of samples where both the true categories and the predicted categories are positive or negative. While FP (False Positive) and FN (False Negative) refer to the number of samples where the true categories and the predicted categories are positive and negative, or negative and positive, respectively.
