# 4.1.1. The 2-D convolutional layer

First, the raw 1-D signal of each lead is converted into a 2-D matrix (as shown in Table 3, Part I) and input to a 2-D convolutional layer for feature extraction. The 2-D convolutional layer can be described as :

```
$$x_j^l = f \left( \sum_{i \in M_j} x_i^{l-1} * w_{ij}^l + b_j^l \right)$$
```

where \(x_i^{l-1}\) is the output of the \(j\)-th convolution kernel at the \((l-1)\)-th layer which is used to input to the \(l\)-th layer. It is operated with the bias coefficients \(w_{ij}^l\) and the corresponding bias \(b_j^l\) of this layer under the receptive field of \(M_j\). Where * refers to the 2-D convolutional operation. And then the rectified linear unit (ReLU) is applied as the activation function \(f(\cdot)\) to output \(x_j^l\). Then, a batch normalization layer and a LeakyReLU activation function are used to alleviate the vanishing gradient problem and accelerate the convergence.

# 4.1.2. The 2-D residual block layer

After the 2-D convolutional layer, we input the learned features into the 2-D residual block layer. As illustrated in Fig. 3 and Table 4, this 2-D residual block layer mainly consists of three 2-D convolutional layers with different sizes of convolutional kernels. After these three stacked 2-D convolutional layers, we use the SE module to process and fuse the learned feature maps to obtain a more efficient feature

representation. Then, we combine the features from the SE module and the skip connection (including a 2-D convolutional layer) to avoid the loss of important information. Finally, feed the features into a LeakyReLU layer.

# 4.1.3. The 1-D residual blocks layer

To further learn finer-grained features in each channel, we design a 1-D residual blocks layer that has three stacked 1-D residual blocks after 2-D residual blocks layers. Before this, the feature representations extracted from the 2-D residual block layer are reshaped into 1-D tensors. The structure of the 1-D residual blocks layer is similar to that of the 2-D residual blocks in Fig. 3. The difference is that the 2-D convolutional layers in the 2-D residual block are replaced by the 1-D convolutional layers, and an additional average pooling layer is added to reduce the dimensionality of the features and provide better generalization after the LeakyReLU activation function. The 1-D average pooling operates as :

```
$$x_j^r(k) = Avg_{a \in A} \left[ x_j^{l-1}(k \times s + a) \right]$$
```

where the feature representations \(x_j^r(k)\) use \(k\) as the sampling point index. \(s\) denotes the strides of the pooling operation, which is all set to 1 in this paper. \(R\) represents the whole pooling region which is divided into \(r\) parts. Finally, we use \(Avg (\bullet)\) to obtain the average values of the pooling windows.

# 4.1.4. The global average pooling layer

Before performing feature fusion of the multi-lead, we use a global average pooling layer to reduce feature dimension and provide a more specific internal representation for each channel.

# 4.1.5. The feature fusion layer

Finally, we concatenate the features learned by each channel and feed them into a dropout layer, then use a flatten layer to get a feature representation. This feature representation is then fed into different fully connected layers to obtain the corresponding classification results of MI detection and location tasks.

# 4.2. Multi-task framework

From the basic process of clinical diagnosis, cardiologists usually detected MI first and then located MI after confirming the diagnosis. Meanwhile, the MI detection result can also be verified from the results of location. However, existing approaches are usually designed to implement only one specific task or multiple independent tasks which did not take into account the relationship between these two tasks and the additional information they may bring. These approaches limited the classification performance and improvement space of the existing methods. Therefore, for MI detection and location tasks, a model that can perform both of them at the same time is more reliable than several independent models.
