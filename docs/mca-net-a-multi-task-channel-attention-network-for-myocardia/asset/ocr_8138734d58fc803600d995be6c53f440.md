# 7. Conclusion

In clinical practice, cardiologists can make a preliminary diagnosis of MI by analyzing abnormal ECG signals, but it is very difficult to give a rapid and accurate diagnosis. Therefore, providing an automatic computer-aided method can effectively reduce the burden on healthcare professionals while providing reliable support for the prognostic assessment of patients.

In this paper, we design a multi-task channel attention network named MCA-net. It uses multiple independent channels to more comprehensively extract valid features from each lead. Each channel includes multiple stacked convolutional layers which contain SE modules to better assign feature weights. We also add a multi-task framework to additionally take into account the shared and complementary information between the MI detection and location tasks to further improve the MCA-net performance. The experimental results show that our model has state-of-the-art performance.

Although our method demonstrates some advantages for each task, it still has some limitations. Firstly, the model suffers from under-learning on some of the labels due to data imbalance. Secondly, MCA-net is prone to confusion when differentiating the relevant labels. To address the above issues, in the future, we will consider collecting more clinical data while further improving our MCA-net with the help of data augmentation such as contrastive learning. Moreover, considering the multi-view nature of the 12-lead ECGs, more effective lead fusion methods can be considered from a multi-view fusion perspective to obtain a richer feature representation.
