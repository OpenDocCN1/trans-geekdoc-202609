# Traditional approach

A common method to generate interaction and polynomial terms is using scikit-learn’s PolynomialFeatures class. The following code generates second-degree interaction and polynomial features using 'Experience' and 'Salary': from sklearn.preprocessing import PolynomialFeatures poly = PolynomialFeatures(degree=2, include_bias=False) X_poly = poly.fit_transform(['Experience', 'Salary'])
Second-degree polynomial features are created from this example's Experience and Salary columns. This includes:

+   - Each original feature (e.g., Experience, Salary)
- Squared terms (e.g., Experience², Salary²)
- Interaction terms (e.g., Experience x Salary)

These new features allow the model to learn more complex patterns without explicitly changing the algorithm.
