# AI debugging example: Syntax error fix

AI can quickly spot and fix syntax errors with clear input. This example shows how AI detects an indentation issue in Python, suggests a fix, and ensures the code runs correctly. Let us walk through how AI identifies and fixes a syntax error in Python, step by step:

- 1. User provides code with an error:

```
def add_numbers(a, b):
    return a + b # SyntaxError: Expected indentation
```

- 2. AI identifies the issue:
    - a. AI detects a missing indentation error.
    - b. AI explains why Python requires indentation at this point.
- 3. AI suggests a fix:

```python
def add_numbers(a, b):
    return a + b # Correct indentation applied
```

- 4. User reviews AI's fix and modifies if necessary.
- 5. Final code is tested for accuracy.

AI-assisted debugging works best when errors are clearly described and the expected outcome is well-defined. Providing structured feedback helps the AI refine its approach, leading to greater accuracy in identifying and resolving issues. # Writing prompts to identify errors and provide fixes

Effective debugging prompts are essential for ensuring AI-generated fixes are accurate, relevant, and efficient. Clear, structured prompts help AI pinpoint errors and suggest optimized solutions. Let us look at the following examples:

- **Handling syntax errors:** A clear prompt helps AI fix errors accurately. This example shows how a specific request leads to the correct syntax fix, while a vague one may not.
    - **Poor prompt:** "Fix this function."
    - **Issue:** AI does not know the problem, leading to incomplete or generic fixes.
    - **Better prompt:** "Find and fix syntax error in this Python function:"
```python
def greet(name):
    print(f"Hello, {name}")
```
    - **AI output (Corrected code):**
```python
def greet(name):
    print(f"Hello, {name}")
```
AI correctly identified the missing colon (:) after the function declaration.

- **Debugging logical errors:** Logical errors occur when the code runs without syntax errors but produces incorrect results. This example shows how a well-structured prompt helps AI identify and correct a logical mistake in a function.
    - **Better prompt:** "This function should return the square of a number but produces incorrect results. Identify and fix the logic error"
```python
def square(num):
    return num * 2 # Incorrect logic
```
    - **AI output (Corrected code):**
```python
def square(num):
    return num * num # Correct logic
```
AI recognized the incorrect multiplication operation (num * num).

- **Handling exceptions:** Handling exceptions is crucial for preventing runtime errors. This example demonstrates how a clear prompt helps AI detect and fix by adding proper exception handling.
    - **Better prompt:** "This function throws a ZeroDivisionError. Identify and fix it:"
```python
def divide(a, b):
    return a / b
```
    - **AI output (Corrected code):**
```python
def divide(a, b):
    if b == 0:
        raise ValueError("Denominator cannot be zero.")
    return a / b
```
AI prevents division by zero. AI-assisted debugging to be effective, it is important to provide clear and detailed error descriptions. Specifying the expected behavior of a function ensures that AI-generated solutions align with the intended. By structuring debugging prompts thoughtfully, developers can minimize errors, enhance performance, and improve software security.
