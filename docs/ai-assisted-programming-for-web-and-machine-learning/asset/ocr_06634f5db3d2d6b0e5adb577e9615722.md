# Residual plots

Residual plots are diagnostic tools for regression models that reveal patterns in prediction errors, helping assess model assumptions and fit quality, outlined as follows:

+   - What it shows: Difference between predicted and actual values.

+   - Why it matters: Detects bias, heteroscedasticity, and non-linearity in regression models.

A random spread of residuals suggests good model fit; structured patterns indicate model limitations.
