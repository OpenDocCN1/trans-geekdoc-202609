```
normalizer = Normalization()
normalizer.adapt(X_train)
model = Sequential([
    normalizer,
    Dense(64, activation='relu'),
    Dense(1, activation='sigmoid')
])
```

In this setup, the following components highlight how preprocessing and model architecture are seamlessly integrated within the Keras workflow:

+   - **Normalization()** is a built-in preprocessing layer that computes and applies mean-variance normalization.
- The **adapt()** method fits the layer to the training data.
- The model consists of a hidden layer with ReLU activation and an output layer with a sigmoid activation for binary classification.

This concise structure makes it easy to embed preprocessing into the training and inference pipeline.
