# Best practices

To avoid overengineering and align cloud services with actual needs, follow these best practices when selecting deployment tools:

+   * Use AWS Amplify for front end hosting and built-in authentication when your needs align with managed services—it reduces setup time and streamlines deployment.
* Choose AWS Lambda for low-volume, event-driven inference (e.g., on-demand predictions or lightweight APIs).
* Use AWS SageMaker for high-throughput, scalable model serving, where performance and flexibility are key.
* Make decisions between EC2, ECS, or Serverless only after profiling actual workload characteristics, such as request rates, latency tolerances, and operational constraints.

# Measure developer efficiency, not just model metrics

In AI development, traditional performance metrics like precision, recall, and accuracy are vital—but they do not tell the whole story. Equally important is how efficiently your development team can build, iterate, and maintain the system over time.
