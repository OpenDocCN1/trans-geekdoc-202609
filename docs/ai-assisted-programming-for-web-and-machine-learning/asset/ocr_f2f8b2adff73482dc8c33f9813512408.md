# Plotting the k-distance graph with ChatGPT guidance

The k-distance graph helps identify a sharp change (elbow point) in the distance to the kth nearest neighbor, often indicating a good eps threshold.

The following code plots a k-distance graph to help estimate an appropriate eps value for DBSCAN:

```
from sklearn.neighbors import NearestNeighbors

neighbors = NearestNeighbors(n_neighbors=5)
neighbors_fit = neighbors.fit(X_scaled)
distances, indices = neighbors_fit.neighbors(X_scaled)
# Sort and plot the distances to the 5th nearest neighbor
```
