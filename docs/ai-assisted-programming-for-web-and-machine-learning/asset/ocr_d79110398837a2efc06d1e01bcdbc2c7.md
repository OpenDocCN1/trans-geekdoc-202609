# Key highlights

The following key highlights summarize the core components and functions of the CNN architecture used for binary classification tasks:

+   *Conv2D layers*: Extract spatial features with filters (3×3 kernel) while preserving dimensions via padding.
*MaxPooling*: Reduces spatial resolution by half, introducing translational invariance.
*Fully connected layers*: Translate spatial features into class scores.
*Activation functions:

+   * ReLU in hidden layers for non-linearity.
* sigmoid in the final layer for binary output.
