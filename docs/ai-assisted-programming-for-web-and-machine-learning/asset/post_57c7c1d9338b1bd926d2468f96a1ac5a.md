```jsx
<div>
  <h1>Hello World
</div>
```

- **Correct:**

```jsx
<div>
  <h1>Hello World</h1>
</div>
```

- Using class instead of className:
  Incorrect:
    `<div class="container">Welcome</div>`
  Correct:
    `<div className="container">Welcome</div>`

- Returning multiple elements without a wrapper:
  Incorrect:
    ```jsx
    return (
      <h1>Title</h1>
      <p>Description</p>
    );
    ```
  Correct:
    ```jsx
    return (
      <>
        <h1>Title</h1>
        <p>Description</p>
      </>
    );
    ```

By recognizing these common errors, AI tools assist developers in writing clean, valid JSX code, reducing debugging effort.
