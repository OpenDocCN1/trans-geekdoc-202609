# Authorship and accountability in AI-generated code

AI tools like GitHub Copilot and ChatGPT can generate hundreds of lines of code in a matter of seconds. However, what happens when something goes wrong? If that code introduces a bug, violates a license, or creates a security vulnerability, the question arises: Who is responsible? This is not just a theoretical concern. As AI becomes a regular presence in development workflows, questions of authorship, ownership, and liability move from the background to the spotlight[33].
