AI 响应：二分查找算法能够高效地将排序数组一分为两半以查找目标值。这里有一个示例：

```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 使用：
print(binary_search([1, 3, 5, 7, 9], 5)) # 输出: 2
```
