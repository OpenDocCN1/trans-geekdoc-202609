With spatial and temporal scaling, we can get a similar motion through modulating the parameters g, θ0 of the DMP. By setting the factor τ, we can adjust the speed of the generated motion. The issue with the DMP is how to determine the nonlinear function f(s)—that is, the weights γi. The function approximation problem can be solved using locally weighted regression (Atkeson, Andrew, and Schaal 1997). However, this method can only be used for a single demonstration. In order to model multiple demonstrations, the GMMs can be employed (Calinon, Guenter, and Billard 2007).

When N = 1—that is, a single demonstration is available—the function f(s) can be learned from the data set {St, ft}Tt=1 t=0 using locally weighted regression (LWR).
