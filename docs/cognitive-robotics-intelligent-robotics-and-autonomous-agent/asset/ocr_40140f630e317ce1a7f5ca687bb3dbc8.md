An extended version of this model has already been used to replicate a range of other language acquisition phenomena (Morse and Cangelosi 2017; Cangelosi and Schlesinger 2018). For example, Twomey et al. (2016) used the ERA architecture to model mutual exclusivity—that is, the developmental phenomenon in which a child can learn the name of a new object if they hear a new label and are presented with an unseen (unlabeled) object among other objects with a known label.
