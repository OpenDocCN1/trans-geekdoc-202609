Swarm cognition has been studied in terms of collective perception, collective memory, collective learning, and collective decision-making and, in some cases, takes inspiration from human psychology and cognitive sciences. These disciplines may provide swarm robotics with new and useful inspiration sources if measurably novel and not a reformulation of an existing approach, and if effective for the respective engineering task.
