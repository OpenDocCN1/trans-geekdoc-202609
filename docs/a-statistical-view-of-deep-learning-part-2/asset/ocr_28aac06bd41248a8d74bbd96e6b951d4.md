# Statistics versus neural network terminology

| Statistics | Neural Networks |
|---|---|
| model | network, graph |
| fitting | learning, training |
| coefficient, parameter | weight |
| predictor, variable | input, feature |
| predicted response | output |
| observation | exemplar |
| parameter estimation | training or learning |
| steepest descent | back-propagation |
| intercept | bias term |
| derived predictor | hidden node |
| penalty function | weight decay |
