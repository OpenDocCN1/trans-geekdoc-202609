# Loss Function

Mean Square Error: used for continuous response data

\(\frac{1}{n} \sum_{i=1}^n(y_i - \hat{y}_i)^2\)

Cross-entropy (deviance): used for categorical response data

\(- \sum_{i=1}^n \sum_{g=1}^G y_{ig} \log(\widehat{\pi}_{ig})\)

For a problem with

+   - g = 1, ..., G categories
+   - \(\widehat{\pi}_{ig} = \) predicted probability that observation i is in the gth category
