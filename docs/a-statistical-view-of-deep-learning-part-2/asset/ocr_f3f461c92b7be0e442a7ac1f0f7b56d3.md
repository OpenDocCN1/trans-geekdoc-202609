# # Regularization

You can also acheive regularization by adding a LASSO-like penalty to the loss function (Tibshirani, 1996)

# ## Regularization

Loss + Regularization penalty

# ## L1 Regularization

$Loss + \lambda \sum_{i=1}^{M} |w_i|$

where

+   - $w_1, \dots, w_M$ represent all model weights (parameters)
+   - $\lambda$ is a tuning parameter
