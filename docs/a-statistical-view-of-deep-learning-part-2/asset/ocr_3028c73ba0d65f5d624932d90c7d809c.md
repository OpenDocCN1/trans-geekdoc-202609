# Optimization

+   - General approach to minimize loss is to use stochastic gradient descent
+     - Assign starting values to the weights
+     - Evaluate the partial derivative of the loss function with respect to each weight
+     - Take a step in the downhill direction (opposite the gradient)
+     - Repeat until weights converge
