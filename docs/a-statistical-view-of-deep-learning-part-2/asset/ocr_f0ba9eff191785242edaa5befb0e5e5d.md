# Nonparametric regression

The weaknesses of this approach are:

+   - The basis is fixed and independent of the data

+   - If there are many predictors, this approach doesn't work well

+   - If the basis doesn't ‘agree’ with true f, then K will have to be large to capture the structure

+   - What if parts of f have substantially different structure?

Alternative approach: the data **tell** us what kind of basis to use
