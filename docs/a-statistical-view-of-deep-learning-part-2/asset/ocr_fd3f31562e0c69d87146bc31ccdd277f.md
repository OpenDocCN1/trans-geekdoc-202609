# Deep Learning Software

+   - Python
+     - Most popular language for deep learning
+     - Object-oriented, high-level programming language
+     - Main packages: TensorFlow, PyTorch, Keras, ...
+     - Do you need to learn Python? Maybe

+   - Keras
+     - Open-source neural-network library written in Python.
+     - Keras package is an API.
+     - API (application programming interface) allows multiple software packages to interact.
+     - Keras can interact with:
+       TensorFlow, Microsoft Cognitive Toolkit, R, Theano, PlaidML
