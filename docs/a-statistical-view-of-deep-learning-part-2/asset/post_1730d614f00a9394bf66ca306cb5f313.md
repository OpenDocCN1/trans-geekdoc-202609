  \(\sigma(x) = \frac{1}{1+e^{-x}}\)

## Network structure

### ReLU (Rectified Linear Unit) activation function

\(\sigma(x) = \max(0, x) = \left\{ \begin{array}{ll} 0 & \text{for } x < 0 \\ x & \text{for } x \ge 0 \end{array} \right.\)

### Softmax activation function

- Used for classification problems on the output layer
- Input: \( x \in \Re \), output: \( 0 \le \sigma(x_i) \le 1 \)

\(\sigma(x_i) = \frac{\exp(x_i)}{\sum_{j=1}^J \exp(x_j)} \quad \text{for } i = 1, \dots, J\)

## Loss Function

A loss function

- Measures predictive performance of the network
- Measures how close the output from the last layer is to the observed value
- Must be a one-number summary

Goal in model fitting:

Find the parameter values (weights) that minimize the loss

## Loss Function

Mean Square Error: used for continuous response data

\(\frac{1}{n} \sum_{i=1}^n(y_i - \hat{y}_i)^2\)

Cross-entropy (deviance): used for categorical response data

\(- \sum_{i=1}^n \sum_{g=1}^G y_{ig} \log(\widehat{\pi}_{ig})\)

For a problem with

- g = 1, ..., G categories
- \(\widehat{\pi}_{ig} = \) predicted probability that observation i is in the gth category

## Loss Function

Select a loss function that is compatible with the activation function of the final layer (output)

| Task | Loss function | Last layer activation func. |
| :--- | :--- | :--- |
| Binary classification | Binary cross-entropy | Sigmoid |
| Multiclass, single-label classification | Categorical cross-entropy | Softmax |
| Multiclass, multi-label classification | Binary cross-entropy | Sigmoid |
| Regression to arbitrary values | Mean square error (MSE) | None |
| Regression to values between 0 and 1 | MSE or binary cross-entropy | Sigmoid |

## Model fitting

Neural networks have **many** unknown parameters (weights).

### Counting parameters

- p + 1 parameters in one node
  - p covariates plus intercept (bias)
  - parameters: $(\alpha_{k0}, \alpha_{k1}, ..., \alpha_{kp})$
- k = 1, ..., K nodes per layer plus intercept: $(\beta_{g0}, ..., \beta_{gK})$
- g = 1, ..., G layers

Total of $K(p + 1) + G(K + 1)$ parameters

## Model fitting

Example:

- p = 100 covariates
- K = 128 nodes per layer
- G = 5 layers
- 128(100 + 1) + 5(128 + 1) = 13,573 parameters

Implications:

- Many parameters and
- All the parameters are highly related.
- Thus you need a lot of data and a special approach to estimate parameters.

## Optimization

- General approach to minimize loss is to use stochastic gradient descent
  - Assign starting values to the weights
  - Evaluate the partial derivative of the loss function with respect to each weight
  - Take a step in the downhill direction (opposite the gradient)
  - Repeat until weights converge

## Number of hidden layers and units

### How many layers?

- Old strategy: one is enough
  - Universal approximator theorem: One hidden layer is enough to represent an approximation of any function to an arbitrary degree of accuracy
  - Theory vs practice!
- Current advice
  - Start with one or two hidden layers with many units
  - If performance is poor and you have debugged, try deep learning
