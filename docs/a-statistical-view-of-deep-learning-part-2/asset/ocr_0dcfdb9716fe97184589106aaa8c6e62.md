# # Numer of hidden layers and units

# ## How many layers?

+   - Old strategy: one is enough
+     - Universal approximator theorem: One hidden layer is enough to represent an approximation of any function to an arbitrary degree of accuracy
+     - Theory vs practice!
+   - Current advice
+     - Start with one or two hidden layers with many units
+     - If performance is poor and you have debugged, try deep learning
