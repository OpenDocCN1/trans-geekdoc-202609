# Model fitting

Example:

+   - p = 100 covariates
+   - K = 128 nodes per layer
+   - G = 5 layers
+   - 128(100 + 1) + 5(128 + 1) = 13,573 parameters

Implications:

+   - Many parameters and
+   - All the parameters are highly related.
+   - Thus you need a lot of data and a special approach to estimate parameters.
