## Regression model

![](img/357c1568568ec7942f9e3cf49122ebd5_12_0.png)

## Regression model

### Model

$$y = \beta_0 + \beta_1 x + \epsilon \text{ where } \epsilon \sim N(0, \sigma^2)$$
$$= f(x)$$

### Fitted model

$$\hat{y} = \hat{\beta}_0 + \hat{\beta}_1 x$$
$$= \hat{f}(x)$$

### Loss function

$$\sum_{i=1}^n (y_i - \hat{y}_i)^2$$

## Regression model

![](img/357c1568568ec7942f9e3cf49122ebd5_14_0.png)

## Nonparametric regression

\(\widehat{y} = \widehat{f}(x) = \widehat{\beta}_0 + \sum_{k=1}^K \widehat{\beta}_k \overbrace{\sigma_k(x)}^{\text{function of } x}\)

### Examples

- 1. Polynomial regression

\(\sigma_k(x) = x^k \text{ so } \widehat{f}(x) = \widehat{\beta}_0 + \widehat{\beta}_1 x + \widehat{\beta}_2 x^2 + \cdots + \widehat{\beta}_K x^K\)

- 2. Regression splines

> A spline is a function that is constructed piece-wise from polynomial functions.

> Apply a family of transformations to \(x, \sigma_1(x), \sigma_2(x), \dots, \sigma_K(x)\)

## Nonparametric regression

A spline of degree $K$ is a function formed by connecting polynomial segments of degree $K$ so that:

- the function is continuous,
- the function has $K - 1$ continuous derivatives, and
- the $K$th derivative is constant between knots.

## Nonparametric regression

### Simple spline regression

Moving window: \(\hat{y}\) is the average of the \(y\)’s for nearby \(x\) values or a weighted average (kernel smoothing)

## Nonparametric regression

The weaknesses of this approach are:

- The basis is fixed and independent of the data
- If there are many predictors, this approach doesn't work well
- If the basis doesn't ‘agree’ with true f, then K will have to be large to capture the structure
- What if parts of f have substantially different structure?

Alternative approach: the data **tell** us what kind of basis to use

## Neural network model

Key idea: think of a neural network as a multiple regression model with transformed predictors

Example: One-layer neural network model with \( K \) hidden nodes \( \sigma_1(x), \sigma_2(x), \dots, \sigma_K(x) \) and 3 predictors \( (x_1, x_2, x_3) \)

```
y = \beta_0 + \beta_1 \sigma_1(\alpha_{10} + \alpha_{11}x_1 + \alpha_{12}x_2 + \alpha_{13}x_3)
+ \beta_2 \sigma_2(\alpha_{20} + \alpha_{21}x_1 + \alpha_{22}x_2 + \alpha_{23}x_3)
+ \quad \dots
+ \beta_K \sigma_K(\alpha_{K0} + \alpha_{K1}x_1 + \alpha_{K2}x_2 + \alpha_{K3}x_3) \quad \text{function of } x
```

## Deep Learning Model

### Neural network model

\( y = \beta_0 + \sum_{k=1}^K \beta_k \sigma_k(\alpha_{k0} + \alpha_{k1}x_1 + \alpha_{k2}x_2 + \alpha_{k3}x_3) \)

### Two-layer "deep" learning model

\(\hat{y} = \hat{f}(x) = \hat{\beta}_0 + \sum_{k=1}^K \hat{\beta}_k \sigma_k(\alpha_{k0}+\alpha_{k1}x_1 + \alpha_{k2}x_2 + \alpha_{k3}x_3))\)

Replace each of these predictors with another neural network model
