# 4. LINTING AND FORMATTING YOUR CODE

# During Builds or Continuous Integration

This is my preferred time to have linting tools run, with any problems being reported by the linter being considered a failed build. Again, this also relies on you having a build system or continuous integration system you can customize to run arbitrary commands from the command line.

If you are using something like GitHub Actions$^{[7]}$ you can find examples of how to do it. In a later chapter of this book where I show some examples of using continuous integration systems, you can probably figure out where to add a linting step.

$^{[7]}$ GitHub Actions: https://github.com/features/actions
