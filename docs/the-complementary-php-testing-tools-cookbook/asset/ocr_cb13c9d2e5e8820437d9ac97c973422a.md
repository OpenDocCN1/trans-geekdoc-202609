# 1. GETTING STARTED

Using automated tools is often like having another person on your team tirelessly checking your work for mistakes and making suggestions on what to change. Who doesn't want help like that?

# Our Tools

As of this writing (spring and summer 2021), I have the following tools installed; they are used throughout this book.

+   • PHP 7.4 and PHP 8.0

+   • PHPStan 0.12.85

+   • Infection 0.21.0

+   • PHPUnit 8.5.1

+   • PostgreSQL 9.6

I am doing this work on macOS Big Sur 11.3 and have used Homebrew⁴ to install most of the dependencies I need.

I am also using PhpStorm⁵ as my editor, which has great integration with all three of the test-centric tools along with the PHP Extended Inspections⁶ extension, which makes lots of refactoring suggestions and reminders about things like uninitialized variables.

Before I go any further, I want to remind you that my choice of tools is just that: my choice of tools. There are many other options for each type of tool I am using, and I am a strong believer in not using tools that cause you any friction. If you want to use PHPStan⁷ for static code analysis, go ahead! If you want to skip doing mutation testing, that's cool too. Don't like PHPUnit's syntax and want to use something like Pest⁸? Go for it.

The point is to start integrating the use of tools that complement test-centric practices. Your choice of tools won't change what you have to do, but it does influence how you approach it.
