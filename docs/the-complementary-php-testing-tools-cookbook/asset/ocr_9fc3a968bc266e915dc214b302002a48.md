# # Initial Set Up

This book also assumes you are using the tool that I feel changed PHP development forever, Composer [9] . If you are not familiar with it, it is a command line interface tool for installing PHP packages. You will be hard-pressed in 2021 to find a major PHP library or framework that is not using Composer in some way.

Some of the tools I’m using require you to do some configuration work before you can use them.

# PHPStan

PHPStan’s documentation can be found at https://phpstan.org.

PHPStan can be used without a default configuration file–you just need to pass it information via the CLI. To reduce cognitive load, I’ll just create a default phpstan.neon file:

```
```
parameters:
    level: max
    paths:
        - src
        - tests
```
```
