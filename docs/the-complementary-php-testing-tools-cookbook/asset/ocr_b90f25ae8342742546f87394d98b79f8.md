# # Chapter 5

## Continuous Integration

I am a big fan of getting computers to do repetitive actions for me. It frees up my attention to focus on solving other problems instead of remembering a series of steps where missing one can result in failure.

One of the issues most programming projects face is coming up with a way to integrate code changes with the least amount of friction. There is no way to do it without any kind of pain and effort either on the development side or the tool creation side.

As I write this in the spring of 2021, there are two dominant methods of integrating your code. The first I call “integrate into main with flags” and “integrate via pull-request.”
