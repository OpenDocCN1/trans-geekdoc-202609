I have also used PHP\_CodeSniffer[3] and PHP CS Fixer[4] and code linters and fixers in other languages; my preference was to use Black[5] for the Python code I wrote at Mozilla. Again, it doesn't really matter what one you use.

How can we actually use this? I borrow a PHP CS Fixer ruleset from another project and get it to play nicely with ECS. There is some great documentation from the ECS project pointing to blog posts about how others converted rulesets.

For my first pass, I told it to:

+   - enforce short array syntax
- enforce PSR12[6]
- only apply it to my src and tests directories

Here is what the ecs.php configuration file looks like:

```
1. `<?php`
2. 
3. `declare(strict_types=1);`
4. 
5. `use PhpCsFixer\Fixer\ArrayNotation\ArraySyntaxFixer;`
6. `use Symfony\Component\DependencyInjection\Loader\Configurator\ContainerConfigurator;`
7. `use Simplify\EasyCodingStandard\ValueObject\Option;`
8. `use Simplify\EasyCodingStandard\ValueObject\Set\SetList;`
9. 
10. `return static function (ContainerConfigurator $containerConfigurator): void {`
11. &nbsp;&nbsp;&nbsp;`$parameters = $containerConfigurator->parameters();`
12. &nbsp;&nbsp;&nbsp;`$parameters->set('Option::PATHS', [`
13. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`__DIR__ . '/src',`
14. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`__DIR__ . '/tests',`
15. &nbsp;&nbsp;&nbsp;`]);`
16. 
17. &nbsp;&nbsp;&nbsp;`$services = $containerConfigurator->services();`
18. &nbsp;&nbsp;&nbsp;`$services->set(ArraySyntaxFixer::class)`
19. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`->call('configure', [`
20. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`'syntax' => 'short',`
21. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`]);`
22. &nbsp;&nbsp;&nbsp;`$containerConfigurator->import(SetList::PSR_12);`
23. 
24. `};`
```
