
*   **Output Phase/Guess Phase**. Here, the adversary outputs a bit `b'` as its guess for `b`.

Let $Adv = Pr\left\lbrack {\beta = \beta^{'}} \right\rbrack - \frac{1}{2} = \varepsilon$ be the advantage of adversary in winning the game; the searchable encryption scheme is secure if `ε` is negligible.

In the selective security game, in addition to these phases, we have one more phase called the initialization phase at the very beginning of the security game. In this phase, the adversary must specify the challenge keywords, `{w[0], w[1]}`, it intends to attack. It is shown with a dashed arrow in [Figure 4.5](#04chap_04.xhtml#fig4_5).

## 4.4 SECURITY/COMPLEXITY ASSUMPTIONS AND PROOF STRATEGIES

The security of searchable encryption schemes is generally proved by embedding the security assumptions into their construction. Security assumptions are well-known hard problems in cryptography. By the reduction approach we reduce our scheme to these hard problems and claim the security of the scheme by that fact that if we cannot break these hard problems then one cannot break our scheme. The security assumptions are broadly categorized into weak and strong assumptions [[9](#04chap_04.xhtml#ref4_9)]. Weak assumptions ensure security as close as to discrete logarithm (DL) assumption and are also called the standard assumptions. The computational Diffie–Hellman (CDH) assumption is an example of a weak assumption. These are referred to as weak in terms of the time it takes to break these assumptions, which is significantly higher than the strong assumptions. Hence, weak assumptions are hard to break as compared to strong assumptions. Strong assumptions are those assumptions whose security levels are lower as compared to the DL assumption. Strong assumptions are relatively risky and unreliable [[9](#04chap_04.xhtml#ref4_9)]. The commonly used security assumptions in literature for developing searchable encryption schemes are given in [Table 4.1](#04chap_04.xhtml#tbl4_1).

**Table 4.1** Commonly used security assumption in the construction of searchable encryption schemes

| S.No. | Security assumption | Description |
| --- | --- | --- |
| 1. | *Discrete Logarithm (DL) Assumption* | Given `h ∈ G`, it is hard to find `x : h = g^(x)` [[10](#04chap_04.xhtml#ref4_10)]. |
| 2. | *Computational Diffie–Hellman (CDH) Assumption* | Given `g^(x) ∈ G` and `g^(y) ∈ G`, it is hard to find `g^(xy)` [[11](#04chap_04.xhtml#ref4_11)]. |
| 3. | *Decision Diffie–Hellman (DDH) Assumption* | Given `g^(x) ∈ G`, `g^(y) ∈ G` and `h ∈ G`, it is hard to determine if `h = g^(xy)` or not. [[12](#04chap_04.xhtml#ref4_12)]. |
| 4. | *Parallel Decisional Diffie–Hellman (pDDH) Assumption* | Given `g^(x[1]), g^(x[2]), ..., g^(x[n]), h[1], h[2], ..., h[n] ∈ G`, it is hard to determine if `h[1] = g^(x[1]x[2]), h[2] = g^(x[2]x[3]), ..., h[n−1] = g^(x[n−1]x[n]), h[n] = g^(x[n]x[1])` or not [[12](#04chap_04.xhtml#ref4_12)]. |
| 5. | *q-Diffie–Hellman Inversion (q-DHI) Assumption* | Given `g^(x), g^(x²), ..., g^(x^q) ∈ G`, it is hard to compute $g^{\frac{1}{x}}$ [[13](#04chap_04.xhtml#ref4_13)], [[14](#04chap_04.xhtml#ref4_14)]. |
| 6. | *q-Decision Diffie–Hellman Inversion (q-DDHI) Assumption* | Given `g^(x), g^(x²), ..., g^(x^q), h ∈ G`, it is hard to determine if $h = g^{\frac{1}{x}}$ [[13](#04chap_04.xhtml#ref4_13)]. |
| 7. | *Linear Assumption* | Given `g^(u), g^(v), g^(xu), g^(yv) ∈ G`; it is hard to find `g^(x + y) ∈ G` [[15](#04chap_04.xhtml#ref4_15)]. |
| 8. | *q-Linear Assumption* | Let `g[1], g[2], ..., g[q], g[0]` be the generators of group `G`. Given `g[1], g[2], ..., g[q], g[0], g[1]^(x[1]), g[2]^(x[2]), ..., g[q]^(x[q]) ∈ G`; it is hard to find `g[0]^(x[0])` where $x_{0} = {\sum\limits_{i = 1}^{q}x_{i}}$ [[15](#04chap_04.xhtml#ref4_15)]. |
| 9. | *Decision Linear (DLIN) Assumption* | Given `g^(u), g^(v), g^(xu), g^(yv), h ∈ G`; it is hard to determine if `h = g^(x + y)`. This assumption is used in place of DDH particularly in Bilinear groups where DDH is no more a hard assumption [[15](#04chap_04.xhtml#ref4_15)]. |
| 10. | *q-Decision Linear (q-DLIN) Assumption* | Let `g[1], g[2], ..., g[q], g[q+1]` be the generators of group `G`. Given `g[1], g[2], ..., g[q], g[q+1], g[1]^(x[1]), g[2]^(x[2]), ..., g[q]^(x[q]), h ∈ G`; it is hard to determine if $h = g_{q + 1}^{\sum\limits_{i = 1}^{q}x_{i}}$ [[15](#04chap_04.xhtml#ref4_15)]. |
| 11. | *q-Strong Diffie–Hellman (q-SDH) Assumption* | Given `g^(x), g^(x²), ..., g^(x^q) ∈ G`, it is hard to find `u ∈ Z[p]` and $g^{\frac{1}{x + u}}$ [[13](#04chap_04.xhtml#ref4_13)]. |
| 12. | *Diffie–Hellman Exponent (DHE) Assumption* | Given `g[0], g[1], g[2], ..., g[q], g[q+2], ..., g[2q] ∈ G`, where `g[i] | [1 ≤ i ≤ 2q, i ≠ q+1] = g^(x^(i))`, it is hard to find `g[q+1] = g^(x^(i+1))` [[16](#04chap_04.xhtml#ref4_16)]. |
| 13. | *Hash Diffie–Hellman (HDH) Assumption* | Let `H: {0,1}^(*) → {0,1}^(len)` be a hash function which returns a binary string of length say `len`. Given `g, g^(x), g^(y), H(g^(xy)), Z = {0,1}^(len)`; it is hard to find if `Z = H(g^(xy))` [[17](#04chap_04.xhtml#ref4_17)]. |
| 14. | *Symmetric External Diffie–Hellman (SXDH) Assumption* | Let `e: G[1] × G[2] → G[T]` be an asymmetric bilinear map between `G[1]` and `G[2]`. Let `j ∈ {1,2}` and `g[j]` be the generator of `G[j]`. Given `g[j]^(x), g[j]^(y), g[j]^(xy), h[j] ∈ G[j]`, it is hard to determine if `h[j] = g[j]^(xy)` [[18](#04chap_04.xhtml#ref4_18)]. It signifies that DDH is hard in both the groups. |
| 15. | *Knowledge of Exponents Assumption (KEA)* | If on input `g` and `g^(x)` 𝒜 outputs `(Z, C) : C = Z^(x)` then there exists an extractor which on same input returns `z : g^(z) = Z` [[19](#04chap_04.xhtml#ref4_19)]. |
| 16. | *Bilinear Diffie–Hellman (BDH) Assumption* | Given `g, g^(x), g^(y)` and `g^(z) ∈ G`, it is hard to find `e(g, g)^(xyz)` [[20](#04chap_04.xhtml#ref4_20)]. |
| 17. | *Decision Bilinear Diffie–Hellman (DBDH) Assumption* | Given `g, g^(x), g^(y), g^(z) ∈ G` and `X ∈ G[T]`, it is hard to determine if `X = e(g, g)^(xyz)` [[20](#04chap_04.xhtml#ref4_20)]. |
| 18. | *Modified Decisional Diffie–Hellman (MDDH) Assumption* | This assumption is based on DBDH assumption. Given `g, g^(x), g^(y), g^(z), g^(xyz) ∈ G` and `X ∈ G`, it is hard to determine if `X = g^(xyz)` [[21](#04chap_04.xhtml#ref4_21)]. |
| 19. | *Bilinear Decision Linear (BDLIN) Assumption* | Given `G, G[T], e, {g[1], g[2], g[1]^(x), g[2]^(y) ∈ G}, X ∈ G[T] : x, y, z ∈ Z[p]`, it is hard to determine if `X = e(g[1], g[2])^(x + y)` [[22](#04chap_04.xhtml#ref4_22)]. |
| 20. | *q-Bilinear Diffie–Hellman Inversion (q-BDHI) Assumption* | Given `G, G[T], e, {g[i]^(x), g[i]^(x²), ..., g[i]^(x^q)}[i ∈ {1, 2}]`, it is hard to find $e\left( {g_{1},g_{2}} \right)^{\frac{1}{x}}$ [[23](#04chap_04.xhtml#ref4_23)]. |
| 21. | *q-Decision Bilinear Diffie–Hellman Inversion (q-DBDHI) Assumption* | Given `G, G[T], e, {g[i]^(x), g[i]^(x²), ..., g[i]^(x^q)}[i ∈ {1, 2}], X ∈ G[T]`, it is hard to determine if $X = e\left( {g_{1},g_{2}} \right)^{\frac{1}{x}}$ [[24](#04chap_04.xhtml#ref4_24)]. |
