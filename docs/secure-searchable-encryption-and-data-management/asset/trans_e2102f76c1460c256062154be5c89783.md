
*   **输出阶段/猜测阶段**。在此，对手输出比特 `b'` 作为其对 `b` 的猜测。

令 $Adv = Pr\left\lbrack {\beta = \beta^{'}} \right\rbrack - \frac{1}{2} = \varepsilon$ 为对手在博弈中获胜的优势；若 `ε` 可忽略不计，则该可搜索加密方案是安全的。

在选择性安全博弈中，除了这些阶段外，在安全博弈一开始还有一个称为初始化阶段的额外阶段。在此阶段，对手必须指定其打算攻击的挑战关键字，`{w[0], w[1]}`。这在[图 4.5](#04chap_04.xhtml#fig4_5)中用虚线箭头表示。

## 4.4 安全性/复杂性假设与证明策略

可搜索加密方案的安全性通常通过将安全假设嵌入其构造中来证明。安全假设是密码学中众所周知的难题。通过归约方法，我们将我们的方案归约到这些难题，并基于此事实宣称方案的安全性：如果我们无法攻破这些难题，则也无法攻破我们的方案。安全假设大致可分为弱假设和强假设 [[9](#04chap_04.xhtml#ref4_9)]。弱假设确保的安全性接近离散对数（DL）假设，也称为标准假设。计算 Diffie-Hellman（CDH）假设就是弱假设的一个例子。之所以称为“弱”，是指攻破这些假设所需的时间显著高于强假设。因此，与强假设相比，弱假设更难攻破。强假设是指其安全级别低于 DL 假设的那些假设。强假设相对风险较大且不可靠 [[9](#04chap_04.xhtml#ref4_9)]。文献中开发可搜索加密方案常用的安全假设见[表 4.1](#04chap_04.xhtml#tbl4_1)。

**表 4.1** 可搜索加密方案构造中常用的安全假设

| 序号 | 安全假设 | 描述 |
| --- | --- | --- |
| 1. | *离散对数 (DL) 假设* | 给定 `h ∈ G`，难以找到 `x : h = g^(x)` [[10](#04chap_04.xhtml#ref4_10)]。 |
| 2. | *计算 Diffie-Hellman (CDH) 假设* | 给定 `g^(x) ∈ G` 和 `g^(y) ∈ G`，难以找到 `g^(xy)` [[11](#04chap_04.xhtml#ref4_11)]。 |
| 3. | *判别 Diffie-Hellman (DDH) 假设* | 给定 `g^(x) ∈ G`、`g^(y) ∈ G` 和 `h ∈ G`，难以判定 `h = g^(xy)` 与否 [[12](#04chap_04.xhtml#ref4_12)]。 |
| 4. | *并行判别 Diffie-Hellman (pDDH) 假设* | 给定 `g^(x[1]), g^(x[2]), ..., g^(x[n]), h[1], h[2], ..., h[n] ∈ G`，难以判定 `h[1] = g^(x[1]x[2]), h[2] = g^(x[2]x[3]), ..., h[n−1] = g^(x[n−1]x[n]), h[n] = g^(x[n]x[1])` 与否 [[12](#04chap_04.xhtml#ref4_12)]。 |
| 5. | *q-Diffie-Hellman 逆 (q-DHI) 假设* | 给定 `g^(x), g^(x²), ..., g^(x^q) ∈ G`，难以计算 $g^{\frac{1}{x}}$ [[13](#04chap_04.xhtml#ref4_13)]、[[14](#04chap_04.xhtml#ref4_14)]。 |
| 6. | *q-判别 Diffie-Hellman 逆 (q-DDHI) 假设* | 给定 `g^(x), g^(x²), ..., g^(x^q), h ∈ G`，难以判定 $h = g^{\frac{1}{x}}$ [[13](#04chap_04.xhtml#ref4_13)]。 |
| 7. | *线性假设* | 给定 `g^(u), g^(v), g^(xu), g^(yv) ∈ G`；难以找到 `g^(x + y) ∈ G` [[15](#04chap_04.xhtml#ref4_15)]。 |
| 8. | *q-线性假设* | 设 `g[1], g[2], ..., g[q], g[0]` 为群 `G` 的生成元。给定 `g[1], g[2], ..., g[q], g[0], g[1]^(x[1]), g[2]^(x[2]), ..., g[q]^(x[q]) ∈ G`；难以找到 `g[0]^(x[0])`，其中 $x_{0} = {\sum\limits_{i = 1}^{q}x_{i}}$ [[15](#04chap_04.xhtml#ref4_15)]。 |
| 9. | *判别线性 (DLIN) 假设* | 给定 `g^(u), g^(v), g^(xu), g^(yv), h ∈ G`；难以判定 `h = g^(x + y)`。此假设特别是在 DDH 不再是难题的双线性群中，用于替代 DDH [[15](#04chap_04.xhtml#ref4_15)]。 |
| 10. | *q-判别线性 (q-DLIN) 假设* | 设 `g[1], g[2], ..., g[q], g[q+1]` 为群 `G` 的生成元。给定 `g[1], g[2], ..., g[q], g[q+1], g[1]^(x[1]), g[2]^(x[2]), ..., g[q]^(x[q]), h ∈ G`；难以判定 $h = g_{q + 1}^{\sum\limits_{i = 1}^{q}x_{i}}$ [[15](#04chap_04.xhtml#ref4_15)]。 |
| 11. | *q-强 Diffie-Hellman (q-SDH) 假设* | 给定 `g^(x), g^(x²), ..., g^(x^q) ∈ G`，难以找到 `u ∈ Z[p]` 和 $g^{\frac{1}{x + u}}$ [[13](#04chap_04.xhtml#ref4_13)]。 |
| 12. | *Diffie-Hellman 指数 (DHE) 假设* | 给定 `g[0], g[1], g[2], ..., g[q], g[q+2], ..., g[2q] ∈ G`，其中 `g[i] | [1 ≤ i ≤ 2q, i ≠ q+1] = g^(x^(i))`，难以找到 `g[q+1] = g^(x^(i+1))` [[16](#04chap_04.xhtml#ref4_16)]。 |
| 13. | *哈希 Diffie-Hellman (HDH) 假设* | 设 `H: {0,1}^(*) → {0,1}^(len)` 为返回长度为 `len` 的二进制字符串的哈希函数。给定 `g, g^(x), g^(y), H(g^(xy)), Z = {0,1}^(len)`；难以判定 `Z = H(g^(xy))` [[17](#04chap_04.xhtml#ref4_17)]。 |
| 14. | *对称外部 Diffie-Hellman (SXDH) 假设* | 设 `e: G[1] × G[2] → G[T]` 为 `G[1]` 和 `G[2]` 之间的非对称双线性映射。设 `j ∈ {1,2}` 且 `g[j]` 为 `G[j]` 的生成元。给定 `g[j]^(x), g[j]^(y), g[j]^(xy), h[j] ∈ G[j]`，难以判定 `h[j] = g[j]^(xy)` [[18](#04chap_04.xhtml#ref4_18)]。这意味着 DDH 在两个群中均为难题。 |
| 15. | *指数知识假设 (KEA)* | 若输入 `g` 和 `g^(x)` 时 𝒜 输出 `(Z, C) : C = Z^(x)`，则存在提取器在相同输入下返回 `z : g^(z) = Z` [[19](#04chap_04.xhtml#ref4_19)]。 |
| 16. | *双线性 Diffie-Hellman (BDH) 假设* | 给定 `g, g^(x), g^(y)` 和 `g^(z) ∈ G`，难以找到 `e(g, g)^(xyz)` [[20](#04chap_04.xhtml#ref4_20)]。 |
| 17. | *判别双线性 Diffie-Hellman (DBDH) 假设* | 给定 `g, g^(x), g^(y), g^(z) ∈ G` 和 `X ∈ G[T]`，难以判定 `X = e(g, g)^(xyz)` [[20](#04chap_04.xhtml#ref4_20)]。 |
| 18. | *修正判别 Diffie-Hellman (MDDH) 假设* | 此假设基于 DBDH 假设。给定 `g, g^(x), g^(y), g^(z), g^(xyz) ∈ G` 和 `X ∈ G`，难以判定 `X = g^(xyz)` [[21](#04chap_04.xhtml#ref4_21)]。 |
| 19. | *双线性判别线性 (BDLIN) 假设* | 给定 `G, G[T], e, {g[1], g[2], g[1]^(x), g[2]^(y) ∈ G}, X ∈ G[T] : x, y, z ∈ Z[p]`，难以判定 `X = e(g[1], g[2])^(x + y)` [[22](#04chap_04.xhtml#ref4_22)]。 |
| 20. | *q-双线性 Diffie-Hellman 逆 (q-BDHI) 假设* | 给定 `G, G[T], e, {g[i]^(x), g[i]^(x²), ..., g[i]^(x^q)}[i ∈ {1, 2}]`，难以找到 $e\left( {g_{1},g_{2}} \right)^{\frac{1}{x}}$ [[23](#04chap_04.xhtml#ref4_23)]。 |
| 21. | *q-判别双线性 Diffie-Hellman 逆 (q-DBDHI) 假设* | 给定 `G, G[T], e, {g[i]^(x), g[i]^(x²), ..., g[i]^(x^q)}[i ∈ {1, 2}], X ∈ G[T]`，难以判定 $X = e\left( {g_{1},g_{2}} \right)^{\frac{1}{x}}$ [[24](#04chap_04.xhtml#ref4_24)]。 |
