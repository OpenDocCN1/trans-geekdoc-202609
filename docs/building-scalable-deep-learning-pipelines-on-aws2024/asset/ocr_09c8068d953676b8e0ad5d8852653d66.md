```
[In]: AWS_BUCKET_NAME = "your-bucket-name"
[In]: MOUNT_NAME = "/mnt/datalake-central"
[In]: dbutils.fs.mount(
    source=f"s3a://{{ACCESS_KEY}}:{{SECRET_KEY}}
@{{AWS_BUCKET_NAME}}/",
    mount_point=MOUNT_NAME,
    extra_configs={"fs.s3a.access.key":
ACCESS_KEY,
"fs.s3a.secret.key":
SECRET_KEY}
)
```

This code has two main parts—variable assignment and mounting the S3 bucket:

Variable Assignment:

+   * ACCESS_KEY: Retrieves the AWS access key from environment variables.
* SECRET_KEY: Retrieves the AWS secret key from environment variables.
* AWS_BUCKET_NAME: Stores the name of the S3 bucket you want to mount.
* MOUNT_NAME: Specifies the mount point for the S3 bucket. In this case, the mount name is “datalake-central,” but it can be any name. Including /mnt/ before the mount name is a common convention in Linux environments, especially when mounting external storage devices or network shares.
