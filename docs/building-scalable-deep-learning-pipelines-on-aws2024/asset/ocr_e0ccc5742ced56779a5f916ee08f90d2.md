**Note** Adaptive Query Execution (AQE) is primarily associated with SQL operations in Apache Spark, particularly when using the DataFrame and Spark SQL APIs. However, since the DataFrame API in PySpark is an abstraction built on top of Spark SQL, many operations you perform with DataFrames (like groupBy, join, agg, etc.) are internally translated into SQL queries. Therefore, AQE can optimize these operations as well.
