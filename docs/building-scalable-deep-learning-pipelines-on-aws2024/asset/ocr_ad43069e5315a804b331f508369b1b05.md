# Predicting Tesla Stock Price with PySpark and PyTorch

The script below performs the following tasks:

+   - Loads stock price data from a CSV file using SparkSession
- Preprocesses the data by assembling feature vectors and scaling them
- Splits the preprocessed data into training and testing sets
- Converts the data into PyTorch tensors and loads them into DataLoader objects for batch processing
- Defines, trains, and evaluates a deep learning model for predicting Tesla stock prices
- Saves the trained model for future use
