or more idiomatic than using a switch or if statement checking the prefix of a URL before deciding what to do.

If you're tempted to write a full HTTP microservice, and don't want to use a function handler, that is also an option, but you'll need to maintain your own Dockerfile or template. Templates abstract away much of the boilerplate code required for a HTTP endpoint written in Go.

See the OpenFaaS Workload definition to learn what you'll need to do to have OpenFaaS manage an existing container, or a container built without using an OpenFaaS template.
