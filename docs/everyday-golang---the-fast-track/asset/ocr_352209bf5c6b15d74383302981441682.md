```
WriteTimeout:  writeTimeout,
MaxHeaderBytes: 1 << 20, // Max header of 1MB
Handler:       mux,
}
log.Printf("Listening on: %d", port)
s.ListenAndServe()
}
```

In the Collect method, we reset the metric, then we add in any items that are present in the API's response. If an item is removed, then it will no longer be exported as part of the service's metrics.

Running the sample, you will see no metrics, since we have nothing to export:

```
go run . &
```

curl -s http://127.0.0.1:8080/metrics | grep gateway
```

Now use the API /register endpoint to add three functions and their replica count:

curl -s "http://127.0.0.1:8080/register?name=email&replicas=1"
curl -s "http://127.0.0.1:8080/register?name=payment&replicas=3"
curl -s "http://127.0.0.1:8080/register?name=scrape&replicas=0"
```
