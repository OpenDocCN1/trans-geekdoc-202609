Run the example, and invoke it using curl, then with hey:

```
curl -s http://127.0.0.1:8080/position
{"latitude":"-40.3230","longitude":"-77.2043"}
```

You'll see the message: "HTTP call to: http://api.open-notify.org/iss-now.json" each time you hit the endpoint. Now try generating traffic with 10 concurrent users, amounting to 10 total requests:

```
hey -c 10 -n 10 http://127.0.0.1:8080/position
```

When I ran this, I only saw "HTTP call to" printed once.

Try it over a longer period of 5s:

```
hey -c 10 -z 5s http://127.0.0.1:8080/position
```

I noted that 330 calls were made over the 5 seconds, with only 33 upstream calls to the API.

If you needed to, you could optimize your API further by introducing a cache using a Go map. Bear in mind that a cache also needs an invalidation policy to expire data, so it can be refreshed as required.
