OpenFaaS templates are stored in various git repositories. The pull command fetches all the templates in a specific repository to your template folder.

```
```bash
faas-cli template pull \\
    https://github.com/openfaas/golang-http-template
```
```

The template store has a list of official and community templates and can be used instead of typing a full URL:

```
```bash
faas-cli template store pull golang-http
```
```

The golang-http template provides a request and response style, and is most similar to the approach managed cloud functions take.

See the contents of `template/golang-http/function/handler.go`:

```
```go
package function

import (
    "fmt"
    "net/http"

    handler "github.com/openfaas/templates-sdk/go-http"
)

// Handle a function invocation
func Handle(req handler.Request) (handler.Response, error) {
    var err error

    message := fmt.Sprintf("Body: %s", string(req.Body))

    return handler.Response{
        Body:       []byte(message),
        StatusCode: http.StatusOK,
    }, err
}
```
```

+   - The HTTP body is available in the `req.Body` variable.
+   - The HTTP headers are available in `req.Headers`.
+   - The HTTP querystring, path and method are also available in `req.QueryString`, `req.Path` and `req.Method`.
