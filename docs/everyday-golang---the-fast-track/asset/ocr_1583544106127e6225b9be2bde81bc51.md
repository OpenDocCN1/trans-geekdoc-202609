Enter the directory, run go build and then invoke the handler:

```
faas-cli build --shrinkwrap -f bcrypt-fn.yml
cd ./build/bcrypt-fn

# Remove the function's go.mod
rm ./build/bcrypt-fn/go.mod

# Create one at the top-level
go mod init
go mod tidy

go build

./handler
```

Note that the handler won't print any output, but you can invoke it on port 8082:

```
curl http://localhost:8082

$2a$10$iho.B7JZN X8DDp610./eheEUxBuCOT EWGS47aIhuXchRSV0oYfYnW
```

This is an advanced technique, but can be used for testing out the function locally when something is going wrong and you need to make many edits in a short period of time.

# Split code into multiple files

Most of the time, your handler.go file will be relatively short, but if you want to break it out into multiple files for readability.

Consider that handler.go evolved to return a JSON struct containing the hash and the computation cost instead of the hash directly.

```
package function

import (
    "encoding/json"
    "fmt"
    "io"
    "net/http"

    "golang.org/x/crypto/bcrypt"
)

type HashResponse struct {
    Hash string
    Cost int
}

func Handle(w http.ResponseWriter, r *http.Request) {
    var input []byte

    if r.Body != nil {
        defer r.Body.Close()
        body, _ := io.ReadAll(r.Body)
        input = body
    }
}
```
