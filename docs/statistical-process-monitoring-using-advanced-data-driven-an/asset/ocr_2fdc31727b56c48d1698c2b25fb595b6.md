The decision hyperplane separates the training measurements in the features space \(\mathcal{F}\). Thus, we get the objective function \(f(x)\) given as

```
$f(x) = \text{sign}(\langle w, \Psi(x) \rangle - \rho),$
```

where \(w\) denotes a weight vector and \(\rho\) refers to an offset. The best hyperplane is related to the parameters \(w\) and \(\rho\) that are determined by solving the following optimization problem:

```
\(\min_{w \in \mathcal{F}, \xi \in \mathbb{R}^l, \rho \in \mathbb{R}} \frac{1}{2} \|w\|^2 + \frac{1}{\nu l} \sum_i^l \xi_i - \rho,\)
\(\text{s.t. } \langle w, \Psi(x) \rangle \ge \rho - \xi_i, \quad \xi_i \ge 0,\)
```

where \(\nu \in [0, 1]\) refers to a parameter characterizing the solution.
