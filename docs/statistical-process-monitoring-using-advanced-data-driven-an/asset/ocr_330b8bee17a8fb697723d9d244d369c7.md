DAE training is performed as follows. At first, the input x is corrupted with noise by adding some random, x̂ ~ qD(x̂|x). Then, the corrupted input x̂ is encoded as in the conventional AE, the coded features of the hidden layer are given as y = fθ(x̂). Lastly, the obtained features in the hidden layer are decoded and the reconstruction of the input is expressed as z = gθ′(h) = gθ′(f(x̂)).

The parameters of DAE are obtained in the training phase by minimizing the following loss function:

```
arg min L(x, g(f(x̂))) θ,θ′ (6.15)
```

where L refers to a loss function such as the Euclidean norm, and θ and θ′ are the DAE parameters.

In summary, by introducing a penalty term to the cost function, the DAE learns robust features by changing the reconstruction error term of the loss function. The model parameters are optimized using the same procedure used in the autoencoder called stochastic gradient descent.

# 6.4.1.3 Contrastive autoencoder

The aim of the contrastive autoencoder (CAE) is to achieve a robust learned representation that is less sensitive to small variations in the data by introducing a penalty term to the loss function [64,65]. ```
