## 10.1 The Future of Machine Learning

Without machine learning there can be no interpretable machine learning. Therefore we have to guess where machine learning is heading before we can talk about interpretability.

Machine learning (or “AI”) is associated with a lot of promises and expectations. But let's say with a less optimistic viewpoint: Science develops a lot of fancy machine learning tools, in experience it is quite hard to integrate into existing processes and products. Not because it is not, but simply because it takes time for companies and institutions to catch up. In the gold rush of the current hype, companies open up “AI labs,” “Machine Learning Units” and hire “Data Scientists,” “Machine Learning Experts,” “AI engineers,” and so on, but the reality is, in my experience, rather frustrating. Companies and data scientists wait idle for months. Some companies have high expectation of AI and Data Science due to the media that data scientists could never fulfill. And often do not know how to integrate data scientists into existing structures and many other problems. This leads to my first prediction.

**Machine learning will grow slowly but steadily.**

Digitalization is advancing and the temptation to automate is constantly pulling. Even if the path of machine learning adoption is slow and snowy, machine learning is constantly moving from science to business processes, and produces real-world applications.

I believe we need to better explain to non-experts what types of problems can be formulated as machine learning problems. I know many highly paid data scientists who perform Excel calculations or classic business intelligence with reporting and SQL queries instead of applying machine learning. But a few are already successfully using machine learning, with the big Internet companies at the forefront. We need to find better ways to integrate machine learning into processes and products, train people and develop machine learning tools that

## Machine learning will fuel a lot of things.

Based on the principle “Whatever can be automated will be automated”, I conclude that whenever possible, tasks will be formulated as prediction problems and solved with machine learning. Machine learning is a form of automation or at least will be part of it. Many tasks currently performed by humans are likely to be replaced by machine learning. Here are some examples of tasks where machine learning is used to automate parts of it:

- Sorting / decision-making / completion of documents (e.g. in insurance companies, the legal sector or consulting firms)
- Data-driven decisions
- Drug discovery
- Quality controls
- Self-driving cars
- Diagnosis of diseases
- Translation

The breakthrough for machine learning is not only achieved through better computers, but also:

## Interpretability tools catalyze the adoption of machine learning.

Based on the premise that the goal of machine learning models can never be perfectly specified, it follows that interpretable machine learning is necessary. In many areas, interpretability will be the catalyst. Some evidence shows people are afraid of machine learning because they cannot explain the models. I believe that interpretability will address this issue and make machine learning attractive to organisations who demand transparency. In addition to the modeling process, machine learning automates the experimental design, choice of distribution, sampling, data encoding, feature engineering, and so on. Interpretation tools make it easier to understand these problems.

## 10.2 The Future of Interpretability

Let us take a look at the possible future of machine learning.

The focus will be on model-agnostic interpretability.

It is much easier to automate interpretability when it is decoupled from the underlying machine learning model. The advantage of model-agnostic interpretability lies in its modularity. We can easily replace the underlying machine learning model or the interpretation method. For these reasons, model-agnostic methods will scale much better. That is why I believe that model-agnostic methods will become dominant in the long term. But intrinsically interpretable methods will also have a place.

**Machine learning will be automated and, with it, interpretability.**

An already visible trend is the automation of model training. That includes automated feature selection, automated hyperparameter optimization, comparison of models, and ensembling or stacking of models. The result is the best possible prediction model. We can automatically apply them to any model that emerges from the machine learning process. In a way, we can automate this second step as well: automatically compute feature importance, plot partial dependence, train a surrogate, and so on. Nobody stops you from automatically computing all interpretations. Actual interpretation still requires people. Imagine: You upload a dataset, specify the prediction goal and at the push of a button the prediction model is trained and the program spits out all interpretations of the model. There are already first products and I argue that for many applications it will be sufficient to use these automated machine learning services. Today anyone can build websites without knowing HTML, CSS and Javascript, but there are still many web developers around. Similarly, I believe that everyone will be able to train learning models without knowing how to program, and there will still be a need for machine learning experts.

**We do not analyze data, we analyze models.**

The raw data itself is always useless. (I exaggerate on purpose. The reality is that you need a deep understanding of the data to conduct a meaningful analysis.) I don't care about the data: I care about the knowledge contained in the data. Interpretable machine learning is a great way to distribute knowledge. You can probe the model extensively, the model automatically recognizes if and how features are relevant for the prediction (many models have built-in feature selection), the model can automatically detect how relationships are represented, and if trained correctly – the final model is a very good approximation of reality.
