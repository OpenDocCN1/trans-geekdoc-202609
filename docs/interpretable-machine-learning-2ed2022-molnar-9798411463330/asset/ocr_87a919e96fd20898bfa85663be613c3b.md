# Never bring a way to a 3D-printed turtle to a gunfight – even if your computer thinks it is a good idea: Robust adversarial examples

The next method is literally adding another dimension to the toaster: Athalye et al. (2017)$^{41}$ 3D-printed a turtle that was designed to look like a rifle to all possible angles. Yeah, you read that right. A physical object that looks like a turtle to humans looks like a rifle to the computer!

The authors have found a way to create an adversarial example in 3D for a 2D classifier that is adversarial over transformations, as all possibilities to rotate the turtle, zoom in and so on. Other approaches such as the fast gradient method no longer work when the image is transformed or varying angle. Athalye et al. (2017) propose the Expectation Transformation (EOT) algorithm, which is a method for generating adversarial examples that work when the image is transformed. The main idea behind EOT is to optimize adversarial examples across many possible transformations. Instead of minimizing the distance between the adversarial example and the original image, EOT keeps the expected distance between the two below a certain threshold, given a selected distribution of possible transformations. The expected distance under transformation can be written as:

```
$$\mathbb{E}_{t \sim T}[d(t(x'), t(x))]$
```
