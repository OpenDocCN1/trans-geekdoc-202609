# When we do not need interpretability.

The following scenarios illustrate when we do not need or even do not want interpretability of machine learning models.

Interpretability is not required if the model has no significant impact. Imagine someone Mike working on a machine learning side project to predict where his friends will go for their next holidays on Facebook. Mike just likes to surprise his friends with educated guesses where they will going on holidays. There is no real problem if the model is wrong (at worst just a little embarrassment for Mike), nor is there a problem if Mike cannot explain the output of the model. It is perfectly fine not to have interpretability in this case. The situation would change if Mike started building a business around these destination predictions. If the model is wrong, the business could lose money, or the model may work for some people because of learned racial bias. As soon as the model has a significant impact, it will be financial or social, interpretability becomes relevant.

Interpretability is not required when the problem is well studied. Some applications have been sufficiently well studied so that there is enough practical experience with the model and problems with the model have been solved over time.
