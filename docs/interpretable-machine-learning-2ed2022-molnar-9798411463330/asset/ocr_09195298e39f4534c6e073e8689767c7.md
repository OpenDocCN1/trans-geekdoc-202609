# 4.1 Linear Regression

A linear regression model predicts the target as a weighted sum of the feature inputs. The linearity of the learned relationship makes the interpretation easy. Linear regression models have long been used by statisticians, computer scientists and other people who tackle quantitative problems.

Linear models can be used to model the dependence of a regression target y on some features x. The learned relationships are linear and can be written for a single instance as follows:

```
$y = \beta_0 + \beta_1 x_1 + ... + \beta_p x_p + \epsilon$
```

The predicted outcome of an instance is a weighted sum of its p features. The first weight in the feature The betas ($\beta_j$) represent the learned weights or coefficients. The intercept and is not multiplied by a feature. The epsilon ($\epsilon$) is the error we still make, i.e the difference between the prediction and the actual outcome. These errors are assumed to follow a Gaussian distribution, which means that they occur in both negative and positive directions and make many small errors and few large errors.

Various methods can be used to estimate the weights to minimize the squared differences between the actual and the estimated outcomes:

```
$$\hat{\beta} = \arg \min_{\beta} \sum_{i=1}^n \left( y^{(i)} - \left( \beta_0 + \sum_{j=1}^p \beta_j x_j^{(i)} \right) \right)^2$
```

We will not detail how the optimal weights can be found, but if you are interested, you can read 3.2 of the book "The Elements of Statistical Learning" (Friedman, Hastie and Tibshirani 2009)$^1$ or one of the other resources on linear regression models.

The biggest advantage of linear regression models is linearity: it makes the estimation procedure simple, most importantly, these linear equations have an easy to understand interpretation on a modular level (i.e. the weights). This is one of the main reasons why the linear model and all models are so widespread in academic fields such as medicine, sociology, psychology, and many other quantitative research fields. For example, in the medical field, it is not only important to predict the clinical outcome of a patient, but also to quantify the influence of the drug and at the same time take sex, age, and other features into account in an interpretable way.

Estimated weights can come with confidence intervals. A confidence interval is a range for the weight estimate that covers the "true" weight with a certain confidence. For example, a 95% confidence interval for a weight of 2 could range from 1 to 3.
