### 7.1.4 Disadvantages

The realistic maximum number of features in a partial dependence function is two. This is not the fault of PDPs, but of the 2-dimensional representation (paper or screen) and also of our inability to imagine more than 3 dimensions.

Some PD plots do not show the feature distribution. Omitting the distribution can be misleading, because you might overinterpret results with no data. This problem is easily solved by using a rug (indicators for data points on the x-axis) or a histogram.

The assumption of independence is the biggest issue with pds. It is assumed that the feature(s) for which the partial dependence is computed are not correlated with other features. For example, suppose you want to predict how fast a person walks, the person's weight and height. For the partial dependence of one of the features, e.g. height, we assume that the features (weight) are not correlated with height, which is obviously a false assumption. For the computation of the PDP at a certain height (e.g. 200 cm), we average over marginal distribution, which might include weight below 50 kg, which is unrealistic for a 2 meter person. In other words: When features are correlated, we create new data points in areas of the feature where the actual probability is very low (it is unlikely that someone is 2 meters tall but weighs no 50 kg). One solution to this problem is Accumulated Local effect plots or short ALE plots that work with the conditional expectation instead of the marginal distribution.

Heterogeneous effects might be hidden because PD plots only show the average marginal prediction. Suppose that for half your data points have a positive association with the prediction – the larger the feature value the larger the prediction – and the other half has a negative association – the smaller the feature value the larger the prediction. The PD could be a horizontal line, since the effects of both halves of the dataset could cancel each other out. You then conclude that the feature has no effect on the prediction. By plotting the individual conditional expectations instead of the aggregated line, we can uncover heterogeneous effects.

## 7.2 Accumulated Local Effects (ALE) Plot

Accumulated local effects⁴ shows how features influence the prediction of a machine learning model on average. ALE plots are a faster and unbiased alternative to partial dependence plots (PDPs).

I recommend reading the chapter on partial dependence plots first, as they are easier to understand and both methods share the same goal: Describe how a feature affects the prediction on average. In the following section, I want to convince you that partial dependence plots have a serious problem when the features are correlated.

### 7.2.1 Motivation and Intuition

If features of a machine learning model are correlated, the partial dependence plot cannot be trusted. The computation of a partial dependence plot for a feature that is strongly correlated with other features averaging predictions of artificial data that are unlikely in reality. This can greatly bias the estimated effect. Imagine calculating partial dependence plots for a machine learning model that predicts the value of a house on the number of rooms and the size of the living area. We are interested in the effect of the living area on the predicted value. Imagine the recipe, for partial dependence plots is: 1) Select feature. 2) Define grid. 3) Per grid value: a) Replace with grid value and average predictions. 4) Draw curve. For the calculation of the first grid value of the PDP - say 30 m² - we replace the living area for all instances by 30 m², for houses with 10 rooms. Suppose the partial dependence plot includes these unrealistic houses in the feature effect and pretends that everything is fine. The following figure illustrates two correlated features and how it comes that the partial dependence plot averages predictions of unlikely instances.

### 7.2.2 Theory

How do PD, M and ALE plots differ mathematically? Common to all three methods is that they reduce the complex prediction to a function that depends on only one (or two) features. All three methods reduce the function by averaging the effects of the other features, but they differ in averages of predictions or of differences in predictions are calculated and whether averaging is done over the marginal or conditional distribution.

Partial dependence plots average the predictions over the marginal distribution.
