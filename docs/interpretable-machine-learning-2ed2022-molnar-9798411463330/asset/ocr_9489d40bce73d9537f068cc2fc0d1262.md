# 9.2.3 Grad-CAM

Grad-CAM provides visual explanations for CNN methods. Unlike other methods, the gradient is not backpropagated all the way back to the image, (usually) to the last convolutional layer to produce a coarse localization map that highlights important regions of the image.

Grad-CAM stands for Gradient-weighted Class Activation Map. And, as the name suggests, it is based on the gradient of the neural networks. Grad-CAM, like other techniques, assigns each neuron a relevance score for the decision of interest. This decision of interest can be the class prediction (which we find in the output layer), or can be any other in the neural network. Grad-CAM can be used with different CNNs: with fully-connected layers, for structured output as captioning and in multi-task outputs, and for reinforcement learning.

Let us start with an intuition consider Grad-CAM. The goal of Grad-CAM is to understand what parts of an image convolutional looks for a certain classification. As a reminder, the first convolutional layer of a CNN takes the inputs and outputs feature maps that encode learned features (see the chapter on Features). The higher-level convolutional layers do the same, but as input the feature maps of the previous layers. To understand how Grad-CAM analyzes regions which are activated in the feature maps of the last convolutional layers. There are k feature maps in the feature maps the convolutional network has made a certain classification? In the first approach, we could simply visualize the raw values of each feature map, average over the maps and overlay this our image. This would not be helpful since the feature maps encode information for all classes, but we are interested in a particular class. Grad-CAM has to decide how important each of the k feature map is. We weight each feature map with the gradient before we average over the feature maps. This gives us a heatmap that highlights regions positively or negatively affects the class of interest. This heatmap is sent through the ReLU function, which is a fancy way of saying we set all negative values to zero. Grad-CAM removes negative values by using a ReLU function, with the argument that we are only interested in the parts that contribute to the selected class and not other classes.
