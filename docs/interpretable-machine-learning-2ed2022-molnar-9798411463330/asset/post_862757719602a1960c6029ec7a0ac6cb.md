# How do we calculate the Shapley value for one feature?

The Shapley value is the average marginal contribution of a feature value across all coalitions. All clear now?

In the following figure we evaluate the contribution of the cat-banned feature value when it is added to a coalition of park-nearby and area-50. We simulate that only park-nearby, cat-banned are in a coalition by randomly drawing another apartment from the data and using its value for the feature. The value floor-2nd was replaced by the randomly drawn floor-1st. In a second step, we remove cat-banned from the apartment with replacing it with a random value of the cat-allowed/banned feature from the randomly drawn apartment. We predict the apartment price for the coalition of park-nearby and area-50 (€320,000). The contribution of cat-banned is €310,000 - €320,000 = -€10,000. This estimate depends on the values of the randomly drawn apartment that served as a “donor” for the cat and floor feature values. We will get better estimates if we repeat this sampling step and average the contributions.

We repeat this for all possible coalitions. The Shapley value is the average of all the marginal contributions to all possible coalitions. The computation time increases exponentially with the number of features. One solution to keep the computation time manageable is to compute coalitions for a few samples of the possible coalitions.

The following figure shows all coalitions of feature values that are needed to determine the Shapley value for cat-banned. The first row shows the coalition without any feature values. The second, third and fourth rows show different coalitions with increasing coalition size, separated by “+”. In all in, the following coalitions are possible:

Skip this section and go directly to “Advantages and Disadvantages” if you are not interested in the technical details. We are interested in how features affect the prediction of a data point. Here is what a linear model prediction looks like for one instance: $$\hat{f}(x) = \beta_0 + \beta_1x_1 + \dots + \beta_px_p$$ with which we want to compute the contributions. The contribution is the difference between the feature effect and average effect. Nice! Now we know how much each feature contributed to the prediction. If we sum all the feature contributions for one instance, the result is the following: $$\sum_{j=1}^p \phi_j(\hat{f}) = \sum_{j=1}^p(\beta_j x_j - E(\beta_j X_j)) = (\beta_0 + \sum_{j=1}^p \beta_j x_j) - (\beta_0 + \sum_{j=1}^p E(\beta_j X_j)) = \hat{f}(x) - E(f(X))$$ This is the predicted value for the data point x minus the average value. Feature contributions can be negative.

Can we do the same for any type of model? It would be great to have this as a model-agnostic tool. Since we usually do not have similar weights in other model types, we need a different solution.

Help comes from unexpected places: cooperative game theory. The Shapley value is a solution for computing feature contributions for single predictions for any machine learning model.

# 8.5.3.1 The Shapley Value

The Shapley value is defined via a value function *val* of players in S. The Shapley value of a feature value is its contribution to the payout, weighted and summed over all possible feature value combinations: $$\phi_j(val) = \sum_{S\subseteq\{1,...,p\}\setminus\{j\}} \frac{|S|! (p - |S| - 1)!}{p!} (val(S \cup \{j\}) - val(S))$$ S is a subset of the features used in the model, x is the vector of feature values of the instance to be explained and p the number of features. $val(S)$ is the prediction for feature values in set S that are marginalized over features that are not included in S: $$val(S) = \int_{\Omega} f(x_1, \dots, x_p) dP_{x\setminus S} - E_X(f(X))$$ You actually perform multiple integrations for each feature that is not contained in S. A concrete example: The machine learning model with 4 features x1, x2, x3 and x4 and we evaluate the prediction for the coalition S consisting of feature values x1 and x3: $val(\{1,3\}) = \int_{\Omega} f(x_1, X_2, x_3, X_4) dP_{X\setminus S} - E_X(f(X))$ This looks similar to the feature contributions in the linear model! Do not get confused by the many uses of the word "value": The feature value is the numerical or categorical value of a feature and instance; the Shapley value is the feature contribution to the prediction; the value function is the payout function for coalitions of feature values. The Shapley value is the only attribution method that satisfies the properties Efficiency, Symmetry, Dummy and Additivity, which together can be considered a definition of a fair payoff. Efficiency The feature contributions must add up to the difference of prediction for x and the average. $$\sum_{j=1}^p \phi_j = \hat{f}(x) - E_X(\hat{f}(X))$$ Symmetry The contributions of two feature values j and k should be the same if they contribute equally to all possible coalitions. $val(S \cup \{j\}) = val(S \cup \{k\})$ for all $S \subseteq \{1,...,p\} \{j, k\}$ then $\phi_j = \phi_k$ Dummy A feature j that does not change the predicted value regardless of which coalition of feature values it is added to – should have a Shapley value of 0.
