# 8.4.6 Software and Alternatives

Currently, there are two implementations available: anchor, a Python package²⁹ (also integrated by Alibi³⁰) and a Java implementation³¹¹. The former is the anchors algorithm’s authors’ reference and the latter a high-performance implementation which comes with a R interface, called anchors³², which was used for the examples in this chapter. By now, the anchors implementation supports supports tabular data only. However, anchors may theoretically be constructed for any domain or type of data.
