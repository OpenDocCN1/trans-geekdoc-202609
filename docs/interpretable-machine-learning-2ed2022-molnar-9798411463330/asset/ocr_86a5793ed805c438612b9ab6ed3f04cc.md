# 9.1.2 Network Dissection

The Network Dissection approach by Bau & Zhou et al. (2017)⁷ quantifies the interpretability of a unit of a convolutional neural network. It links highly activated areas of CNN channels with human concepts (objects, parts, textures, colors, ...).

The channels of a convolutional neural network learn features, as we see in the chapter on Feature Visualization. But these visualizations do not prove that a unit has learned a concept. We do not have a measure for how well it detect e.g. skyscrapers. Before we go into the details of Network Dissection, we have to talk about the big hypothesis that is behind that line of research. The hypothesis is: Units of a neural network (like convolutional channels) learn disentangled concepts.

# The Question of Disentangled Features

Do (convolutional) neural networks learn disentangled features? Disentangled features mean that individual units detect specific real world concepts. Convolutional network 394 might detect skyscrapers, 121 dog snouts, 12 stripes at 30 degree angle ... The opposite of a disentangled network is a completely entangled network. In a completely entangled network, there would be no individual unit for dog snouts. All channels would contribute to the recognition of dog knots.

Disentangled features imply that the network is highly interpretable. Let us assume we have a network with completely disentangled units that are labeled with known concepts. This opens up the possibility to track the network's decision making process. For example, we can analyze how the network classifies versus husk. First, we identify the “husky-unit”. We can check whether this unit depends on the “dog snout”, “fluffy fur” and “snow-units”.
