# 8.4.2 Complexity and Runtime

Knowing the approach' asymptotic runtime behavior helps evaluate how well it is expected to perform on specific problems. Let $B$ denote the width and $p$ the number of all features. Then the anchors algorithm is subject to:

$\mathcal{O}(B \cdot p^2 + p^2 \cdot \mathcal{O}_{MAB}[B,p])$,

This boundary abstracts from problem-independent hyperparameters, such as the statistical confidence $\delta$. Ignoring hyperparameters helps reduce the boundary's complexity (see original paper for more info). Since the MAB extracts the $B$ best out of $B$-$p$ candidates in each round, MABs and their runtime multiply the $p^2$ factor more than any other parameter.

It thus becomes apparent: the algorithm's efficiency decreases when many features are present.
