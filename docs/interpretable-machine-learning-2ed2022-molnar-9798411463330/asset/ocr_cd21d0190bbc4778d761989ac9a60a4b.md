# # 4.3.3 Nonlinear Effects - GAMs

**The world is not linear.** Linearity in linear models means that no matter value an instance has in a particular feature, increasing the value by one unit has the same effect on the predicted outcome. It is reasonable to assume that increasing the temperature by one degree at 10 degrees Celsius has the same effect on the number of rentals as increasing the temperature when it already has 40 degrees. Intuitively, one expects that increasing the temperature from 10 to 11 degrees and from 40 to 41 a negative effect, which is also the case, as you will see, in many examples throughout the book. The temperature has a linear, positive effect on the number of rentals, but at some point it flattens out and has a negative effect at high temperatures. The linear model does not care, it willfully find the best linear plane (by minimizing the Euclidean distance).

You can model nonlinear relationships using one of the following techniques:

+   - Simple transformation of the feature (e.g. logarithm)
- Categorization of the feature
- Generalized Additive Models (GAMs)
