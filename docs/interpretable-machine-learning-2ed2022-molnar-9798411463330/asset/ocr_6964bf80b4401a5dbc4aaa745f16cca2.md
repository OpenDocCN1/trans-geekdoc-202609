# 7.4.2 Functional Decomposition

A prediction function takes $p$ features as input, $\hat{f} : \mathbb{R}^p \to \mathbb{R}$ and produces an output. This can be a regression function, but it can also be the classification probability for a given class or the score for a given cluster (unsupervised machine learning). Fully decomposed, we can represent the prediction function as the sum of functional components:

```
$\hat{f}(x)=\hat{f}_0+\hat{f}_1(x_1)+...+\hat{f}_p(x_p)\n+\hat{f}_{1,2}(x_1,x_2)+...+\hat{f}_{1,p}(x_1,x_p)+...+\hat{f}_{p-1,p}(x_{p-1},x_p)\n+...\n+\hat{f}_{1,...,p}(x_1,..,x_p)$
```
