Our job now is to decompose this function into main effects of $X_1$ and $X_2$ and an interaction term. For a two-dimensional $f$ that depends on only two input features: $\hat{f}(x_1, x_2)$, we represent each component as a main effect ($\hat{f}_1$ and $\hat{f}_2$), interaction ($\hat{f}_{1,2}$) or intercept $(\hat{f}_0)$:

```
$$\hat{f}(x_1, x_2) = \hat{f}_0 + \hat{f}_1(x_1) + \hat{f}_2(x_2) + \hat{f}_{1,2}(x_1, x_2)$
```

The main effects indicate how each feature affects the prediction, independent of the values the other feature. The interaction effect indicates the joint effect of the features. The intercept tells us what the prediction is when all feature effects are set to zero. Note that the components themselves are functions (except for the intercept) with different input dimensionality.
