# 9.5 INFLUENTIAL INSTANCES

Koh and Liang published the Python code for influence functions from their paper in a repository⁴⁸. That is great! Unfortunately it it is “only” the code of the paper and not a maintained and documented Python module. The code is focused on the Tensorflow library, so you cannot use it directly for black box models using other frameworks, like sci-kit learn.

⁴⁸https://github.com/kohpangwei/influence-release
