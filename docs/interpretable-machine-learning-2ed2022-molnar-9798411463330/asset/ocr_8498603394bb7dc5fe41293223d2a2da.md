The additional interaction effect is effective (-21.8) and differs significantly from zero, as shown by the 95% confidence interval, which does not include zero. By the way, the data are not iid because days that are close to each other are not independent from each other. Confidence intervals might be misleading, just take it with a grain of salt. The interaction term changes the interpretation of the weighted features. Does the temperature have a negative effect if it is a working day? The answer is no, even if the table suggests it to an untrained user. We cannot interpret the "workingdayWORKINGDAY:temp" interaction weight in isolation, since the interpretation would be: "Leaving all other feature values unchanged, the interaction effect of working day decreases the predicted number of bikes." But the interaction effect only adds to the main effect of the temperature. Suppose it is a working day and the temperature is 1 degree warmer today. Then we need to sum both weights for "temp" and "workingdayWORKINGDAY:temp" to determine how much the increases.

It is easier to understand the interaction visually. By introducing an interaction term between a categorical and a numerical feature, we get two slopes for the temperature instead of one. The temperature slope for days which people do not have to work ("NO WORKING DAY") The temperature slope for days on which people have to work ("WORKING DAY") is the sum of temperature weights (125.4 - 21.8 = 103.6). The intercept of the "NO WORKING DAY"-line at temperature = 0 is determined by the intercept term of the linear model (2185.8). The intercept of the "WORKING DAY"-line at temperature = 0 is determined by the intercept term + the effect of working day (2185.8 + 451.9 = 2637.7).
