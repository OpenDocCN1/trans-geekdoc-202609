A specific approach using this recipe is called Bayesian Rule Lists (Letham et al., 2015)¹² or BRL for short. BRL uses Bayesian statistics to learn decision lists from frequent patterns which are pre-mined with the FP-tree algorithm (Borg 2005)¹³

But let us start slowly with the first step of BRL.

# Pre-mining of frequent patterns

A frequent pattern is the (co-)occurrence of feature values. As a pre-processing step for the BRL algorithm, we use the features (we do not need the target outcome in this) and extract frequently occurring patterns from them. A pattern can be a single feature value such as size=medium or a combination of feature values such as size=medium AND location=bad.

The frequency of a pattern is measured with its support in the dataset:

```
$Support(x_j = A) = \frac{1}{n}\sum_{i=1}^{n}I(x_i = A)$
```

where A is the feature value, n the number of data points in the dataset and the indicator returns 1 if the feature xi of the instance has level A otherwise. In a dataset of houses, if 20% of houses have no balcony and 80% have one or more, then the support for the pattern balcony=0 is 20%. Support can also be measured for combinations of feature values, for example balcony=0 AND pets=allowed.

There are many algorithms to find frequent patterns, for example Apriori or FP-Growth. Which you use does not matter much, only the speed at which the patterns are found is different, but the resulting patterns are always the same.

I will give you a rough idea of how the Apriori algorithm works to find frequent patterns. The Apriori algorithm consists of two parts, where the first part finds frequent patterns and the second part builds association rules. For the BRL we are only interested in the frequent patterns that are generated in the first part of Apori.

In the first step, the Apriori algorithm starts with all feature values greater than the minimum support defined by the user. If the user says that the minimum support should be 10 and only 5% of the houses have size=big, we remove that feature value and keep only size=medium and size=small. This does not mean that the houses are removed from the data, it just means size=big is not returned as frequent. Based on frequent patterns with a single feature value, the Apriori algorithm tries to find combinations of feature values of increasingly higher order. Patterns are constructed by combining feature=value statements with a logical AND, e.g. size=medium
