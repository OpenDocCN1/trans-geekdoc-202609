
## 9.1 LEARNED FEATURES

The function $h$ is the activation of a neuron, $img$ the input of the network (an image), $x$ and $y$ describe the spatial position of the neuron, $n$ specifies the layer and $z$ is the channel index. For the mean activation of an entire layer $n$ we maximize:

```
$img^* = \arg\max_{x,y} h_{n,y,z}(img)$
```

In this formula, all neurons in channel $z$ are equally weighted. Alternatively, you can also maximize random directions, which means that the neurons would be multiplied by different parameters, including negative directions. In this way, we study how neurons interact within the channel. Instead of maximizing the activation, you can also minimize it (which corresponds to maximizing the negative direction). Interestingly, when you maximize the negative direction you get very different features for the same unit:

![](img/9c9dbc65e26f4c97aa064cc8205fc4c_254_0.png)

Figure 9.3: Positive (left) and negative (right) activation of Inception V1 from layer 48.

We can address this optimization problem in different ways. For example, instead of generating new images, we could search through our training images and select those that maximize the activation. This is a valid approach, but using training data has the problem that elements on images can be correlated and we cannot see what the neural network is looking for. If images that yield a high activation of a certain channel show a dog and a tennis ball, we do not know whether the neural network looks at the dog, the tennis ball or both.

Another approach is to generate new images starting from random noise. To obtain meaningful visualizations, there are usually constraints on the image, e.g., that only small changes are allowed. To reduce noise we can apply jitter, rotation or scaling to the image before the optimization step. Other regularization options include frequency penalization (e.g., variance of neighboring pixels) or generating images with learned priors, e.g., with generative adversarial networks (GANs) or denoising autoencoders.

Figure 9.4: Iterative optimization from random image to maximizing activation.

If you want to dive into feature visualization, take a look at distill.pub/2017/feature-visualization/, especially the feature visualization post Olah et al. (2017). I recommend the article about the building blocks of interpretability.

### 9.1.2 Connection to Adversarial Examples

There is a connection between feature visualization and adversarial examples: Both techniques maximize the activation of a neural network unit. For adversarial examples, we look for the maximum activation of the neuron for the incorrect class. One difference is that for feature visualization depending on the approach, we generate random noise.

### 9.1.2 Network Dissection

The Network Dissection approach by Bau & Zhou et al. (2017) quantifies the interpretability of a unit of a convolutional neural network. It links highly activated areas of CNN channels with human concepts (objects, parts, textures, colors ...).

The channels of a convolutional neural network learn features, as we see in the chapter on Feature Visualization. But these visualizations do not prove that a unit has learned a concept. We do not have a measure for how well it detects e.g. skyscrapers. Before we go into the details of Network Dissection, we have to talk about the big hypothesis that is behind that line of research. The hypothesis is: Units of a neural network (like convolutional channels) learn disentangled concepts.

## The Question of Disentangled Features

Do (convolutional) neural networks learn disentangled features? Disentangled features mean that individual units detect specific real-world concepts. Convolutional network might detect skyscrapers, dog snouts, stripes at 30 degree angle ... The opposite of a disentangled network is a completely entangled network. In a completely entangled network, there would be no individual unit for dog snouts. All channels would contribute to the recognition of dog knots.

Disentangled features imply that the network is highly interpretable. Let us assume we have a network with completely disentangled units that are labeled with human concepts. This opens up the possibility to track the network's decision making. For example, we know it will misclassify an image of a husky with a snowy background as a wolf. In a disentangled network, we could identify problematic noncausal correlations. We could automatically list all highly activated units and their concepts to explain an individual prediction. For example, did the network learn a "white skin" feature to predict salary?

### 9.1.2.1 Network Dissection Algorithm

Network Dissection has three steps:

- Get images with human-labeled concepts, with stripes to skyscrapers.
- Measure the CNN activations for these images.
- Quantify the alignment of activations and labeled concepts.
