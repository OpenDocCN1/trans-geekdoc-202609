# 8.5.3 The Shapley Value in Detail

This section goes deeper into the definition and computation of the Shapley value for the curious reader. Skip this section and go directly to “Advantages and Disadvantages” if you are not interested in the technical details.

We are interested in how feature affect affect the prediction of a data point. In a linear model it is easy to calculate the individual effects. Here is what a linear model prediction looks like for one data instance:

```
$$\hat{f}(x) = \beta_0 + \beta_1x_1 + \dots + \beta_px_p$
```

with x is the instance for which we want to compute the contributions. Each $x_j$ is a feature value, with $j=1,...,p$. The $eta_j$ is the weight corresponding to feature $j$.
