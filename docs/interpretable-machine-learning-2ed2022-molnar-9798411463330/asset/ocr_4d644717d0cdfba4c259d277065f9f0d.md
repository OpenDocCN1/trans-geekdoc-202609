ALE plots average the changes in the predictions and accumulate them over the grid (more on the calculation later).

```
$$\hat{F}_{S,ALE}(x_S) = \int_{z_0,S}^{x_S} E_{X_C|X_S=x_s} [\hat{f}_S(X_S, X_C)|X_S=z_S] dz_S - \text{constant}$$
 = \int_{z_0,S}^{x_S} (\int_{xC} \hat{f}_S(z_S, X_C)dF(X_C|X_S=z_S))dz_S - \text{constant}$
```

The formula reveals three differences to M-Plots. First, we average the changes of predictions, not the predictions itself. The change is defined as the partial derivative (but later, for the actual computation, replaced by the differences in the predictions over an interval).

```
$$\hat{f}^S(x_s, x_c) = \frac{\partial f(x_s, x_c)}{\partial x_S}$$
```

The second difference is the additional integral over z. We accumulate the local partial derivatives over the range of features in S, which gives us the effect of the feature on the prediction. For the actual computation, the x's are replaced by a grid of intervals over which we compute the changes in the prediction, the ALE method calculates the prediction differences conditional on features S and integrates the derivative over S to estimate the effect. Well, that sounds stupid. Derivation and integration usually cancel each other out, like first subtracting, then adding the same number. Why does it make sense here? The derivative (or interval difference) isolates the effect of the feature and blocks the effect of correlated features.

The third difference of ALE plots to M-plots is that we subtract a constant from the results. This step centers the ALE plot so that the average effect over the data is zero.

One problem remains: Not all models come with a gradient, for example random forests have no gradient. But as you will see, the actual computation works without gradients and uses intervals. Let us delve a little deeper into the estimation of ALE plots.
