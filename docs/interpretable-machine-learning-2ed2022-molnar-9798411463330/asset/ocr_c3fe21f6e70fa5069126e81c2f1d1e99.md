Lundberg et al. (2018)(tree-shape) proposed TreeSHAP, a variant of SHAP for tree-based machine learning models such as decision trees, random forests and gradient boosted trees. TreeSHAP was introduced as a fast, model-specific alternative to KernelSHAP, but turned out that it can unintuitive feature attributes.

TreeSHAP defines the value function using the conditional expectation $E_{X_S}(f(x)|x_S)$ instead of the marginal expectation. With the conditional expectation that features have no influence on the prediction function $f$ we can get a TreeSHAP estimate different from zero by Sundararajan et al. (2019)$^{44}$ and Janjing et al. (2019)$^{45}$. The non-zero estimate can happen when the feature is correlated with another feature that actually has influence on the prediction.

How much faster is TreeSHAP? Compared to exact KernelSHAP, it reduces the computational complexity from $O(TL^M)$ to $O(TD^2)$, where T is is the number of trees, $L$ is the maximum number of leaves in any tree and $D$ the maximum depth of any tree.
TreeSHAP uses the conditional expectation $E_{X_S}(f(x)|x_S)$ to estimate it.
