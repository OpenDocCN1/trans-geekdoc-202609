# 10.1 The Future of Machine Learning

Without machine learning there can be no interpretable machine learning. Therefore we have to guess where machine learning is heading before we can talk about interpretability.

Machine learning (or “AI”) is associated with a lot of promises and expectations. But let's say with a less optimistic viewpoint: Science develops a lot of fancy machine learning tools, in experience it is quite to integrate into existing processes and products. Not because it is not, but simply because it takes time for companies and institutions to catch up. In the gold rush of the current hype, companies open up “AI labs,” “Machine Learning Units” and hire “Data Scientists,” “Machine Learning Experts,” “AI engineers,” and so on, but the reality is, in my experience, rather frustrating. Companies and data scientists wait idle for months. Some companies have high expectation of AI and Data Science due to the media that data scientists could never fulfill. And often knows how to integrate data scientists into existing structures and many other problems. This leads to my first prediction.

Machine learning will grow slowly but steadily.

Digitalization is advancing and the temptation to automate is constantly pulling. Even if the path of machine learning adoption is slow and snowy, machine learning is constantly moving from science to business processes, and produces real world applications.

I believe need to better explain to non-experts what types of problems can be formulated as machine learning problems. I know many highly paid data scientists who perform Excel calculations or classic business intelligence with reporting and SQL queries instead of applying machine learning. But a few are already successfully using machine learning, with the big Internet companies at the forefront.
