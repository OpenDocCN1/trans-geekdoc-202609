This vulnerability occurs when a neural network treats a relationship between an input intensity and the class score linearly. In particular, network architectures that favor linearity, such as LSTMs, maxout networks with ReLU activation units or other machine learning algorithms such as logistic regression are vulnerable to gradient sign method. The attack is carried out by extrapolation. The linearity between the input pixel intensity and the class scores leads to vulnerability to outliers, i.e. the model can be deceived by moving pixel values outside the data distribution. # A jellyfish ... No wait, 1-pixel attacks

The approach presented by Goodfellow and colleagues (2014) requires many pixels to be changed, if only a by little. But what if you can only change a single pixel? Would we be able to deceive a machine learning model? Su et al. (2019)$39}$ showed that it is actually possible to deceive image classifiers by changing a single pixel.

Similar to counterfactuals, the 1-pixel attack looks for a modified example $x'$ which comes to the original image $x$, but changes the prediction to an adversarial outcome. However, the definition of closeness: Only a single pixel may change. The 1-pixel attack uses differential evolution to find out which pixel is to be changed and how. Differential evolution is loosely inspired by biological evolution of species. A population of individuals carries solutions generation by generation until a solution is found. Each candidate solution encodes a pixel modification and is represented by a vector of five elements: the $x$- and $y$-coordinates and the red, green and blue (RGB) values.
