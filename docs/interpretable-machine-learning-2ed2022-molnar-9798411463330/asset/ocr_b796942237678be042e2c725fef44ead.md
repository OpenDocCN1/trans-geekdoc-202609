Interpretability might enable people or programs to manipulate the system. Problems with users who deceive a system result from a mismatch between the goals of the creator and the user of a model. Credit scoring is such a system because banks want to ensure that loans are only given to people who are likely to return them, and applicants aim to get the loan even if the bank does not actually give them. This mismatch between the goals introduces incentives for applicants to game the system to increase their chances of getting a loan. An applicant knows having more than two credit cards negatively affects his score, he returns his third credit to improve his score, and organizes a new card after the loan has been approved. With his score improved, the actual repaying of the loan remained unchanged. The system can only be gained if the inputs are proxies for a causal feature, but not actually. features should be avoided as they make models gameable. Google developed a system called Google Flu to predict flu outbreaks. The system corrected Google searches with flu outbreaks The distribution of search queries changed and Google Flu missed many flu outbreaks. Google searches do not cause the flu. When people search for symptoms like “fever” it is merely a correlation with actual flu outbreaks. Ideally, models would only use causal features because they would not be gameable.

# 2.2 Taxonomy of Interpretability Methods

Methods for machine learning interpretability can be classified according to various criteria.

Intrinsic or post hoc? This criteria distinguishes whether interpretability is achieved by restricting the complexity of the machine learning model (intrinsic) or by applying methods that analyze the model after training (post hoc). Intrinsic interpretability refers to learning models that are considered interpretable by their simple structure, such as short decision trees or sparse linear models. Post hoc interpretation refers to the application of interpretation methods after model training. Permutation feature importance is, for example, a post hoc interpretation method. Post hoc methods can also be applied to intrinsically interpretable models. For example, permutation feature importance can be computed for decision trees. The organization of chapters in this book is determined by the distinction between intrinsically interpretable models and post hoc (model-agnostic) interpretation methods.

Result of the interpretation method The interpretation methods can be roughly differentiated according to their results.

+   - Feature summary statistic: Many interpretation methods provide summary statistics for each feature. Some methods return a single number per feature, such as feature importance, or a more complex result, such as the pairwise feature interaction strengths, which consist of a number for each feature pair.
