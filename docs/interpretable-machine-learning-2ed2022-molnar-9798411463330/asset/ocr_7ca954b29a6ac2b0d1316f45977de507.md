The Gower distance can handle both numerical and categorical features, but does not count how many features were changed. Therefore, we count the features in a third objective $o_3$ using the $L_0$ norm:

```
$o_3(x, x') = ||x - x'||_0 = \sum_{j=1}^{p} [x_j \neq x_j]$$
```

By minimizing $o_3$ we our third criterion — sparse features changes.

The fourth objective $o_4$ reflects that our counterfactuals should have likely feature values/combinations. We can infer “likely” a data point is using the training data or another dataset. We denote this dataset as $X^{obs}$. As an approximation for the likelihood, $o_4$ measures the average Gower distance between $x$ and the nearest observed data $x^{[1]} \in X^{obs}$:

```
$o_4(x', X^{obs}) = \frac{1}{p} \sum_{j=1}^{p} d_G(x_j, x_j^{[1]})$$
```

Compared to Wachtel et al., $L(x, X^{obs})$ has no balancing/weighting terms like $\lambda$. We do not want to collapse the four objectives $o_1, o_2, o_3$ and $o_4$ into a single objective by summing them up and weighting them, but we want to optimize all four simultaneously.

How can we do? We use the Nondominated Sorting Genetic Algorithm$^{14}$ or short NSGA-II. NSGA-II is a nature-inspired algorithm that applies Darwin’s “survival of the fittest”. We measure the fitness of a counterfactual by its vector of values $(o_1, o_2, o_3, o_4)$. The lower the values of the objectives for a counterfactual, the “fitter” it is.

The algorithm consists of four steps that are repeated until a stopping criterion is met, for example, a maximum of iterations/generations. The following figure visualizes the four steps of one generation.

In the first generation a group of counterfactual is initialized by randomly changing some of the features to our instance $x$ to be explained. Sticking with above’s credit example, one counterfactual could increase the income by $\$30000 while another one proposes to have no default in the last five years and a reduction by age. All other feature values are equal to the values of $x$. Each candidate is evaluated using the four objective functions of above. Then, we randomly select some candidates, where fitter candidates are more likely to be selected. The candidates are pairwise recombined to produce children that are similar to them by averaging their numerical values or by crossing over their categorical features. In addition, we slightly mutate the feature values of the children to explore the whole feature space.
