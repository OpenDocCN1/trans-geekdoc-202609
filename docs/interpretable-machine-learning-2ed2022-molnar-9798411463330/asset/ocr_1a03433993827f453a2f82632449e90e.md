The interpretation is simple: If the conditions apply, we predict the interval on the right
hand side for the number of bikes. The last rule is the default rule that applies when none
of the other rules apply to an instance. To predict a new instance, start at the top of the\list and check whether a rule applies. When a condition matches, then the right hand side
of rule is the prediction for this instance. The default rule ensures there is always a
prediction.
