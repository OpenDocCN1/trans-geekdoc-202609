S is a subset of the features used in the model, x is the vector of feature values of the instance to be explained and p the number of features. $val_z(S)$ is the prediction for feature values in set S that are marginalized over features that are not included in S:

```
$val_z(S) = \int_{\Omega} f(x_1, \dots, x_p) dP_{x\setminus S} - E_X(f(X))$
```

You actually perform multiple integrations for each feature that is not contained S. A concrete example: The machine learning model with 4 features x1, x2, x3 and x4 and we evaluate the prediction for the coalition S consisting of feature values x1 and x3:

```
$val_z(S) = val_z(\{1,3\}) = \int_{\Omega} f(x_1, X_2, x_3, X_4) dP_{X\setminus S} - E_X(f(X))$
```

This looks similar to the feature contributions in the linear model!

Do not get confused by the many uses of the word "value": The feature value is the numerical or categorical value of a feature and instance; the Shapley value is the feature contribution to the prediction; the value function is the payout function for coalitions of players (feature values).

The Shapley value is the only attribution method that satisfies the properties Efficiency, Symmetry, Dummy and Additivity, which together can be considered a definition of a fair payoff.

Efficiency The feature contributions must add up to the difference of prediction for x and the average.

```
$$\sum_{j=1}^p \phi_j = \hat{f}(x) - E_X(\hat{f}(X))$
```

Symmetry The contributions of two feature values j and k should be the same if they contribute equally to all possible coalitions.

```
$val(S \cup \{j\}) = val(S \cup \{k\})$
```

for all

```
$S \subseteq \{1, \dots, p\} \{j, k\}$
```

then

```
$$\phi_j = \phi_k$
```
