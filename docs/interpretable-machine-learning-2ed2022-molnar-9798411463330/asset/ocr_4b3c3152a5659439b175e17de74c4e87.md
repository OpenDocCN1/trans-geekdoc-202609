# 7.5 Permutation Feature Importance

Permutation feature importance measures the increase in the prediction error of the model after we permuted the feature's values, which breaks the relationship between the feature and the true content.

# 7.5.1 Theory

The concept is really straightforward: We measure the importance of a feature by calculating the increase in the model's prediction error after permuting the feature. A feature is "important" if shuffling its values increases the model error

The permutation feature importance algorithm based on Fisher, Rudin, and Dominici (2018):

Input: Trained model $f$, feature matrix $X$, target vector $y$, error measure $L(y, \hat{f})$.

+   1. Estimate the original error $e_{orig} = L(y, \hat{f}(X))$ (e.g. mean squared error)
2. For each feature $j \in \{1, \dots, p\}$ do:
   - Generate feature matrix $X_{perm}$ by permuting feature $j$ in the data $X$. This breaks the association between feature $j$ and true outcome $y$.
   - Estimate error $e_{perm} = L(y, \hat{f}(X_{perm}))$ based on the predictions of the permuted data.
   - Calculate permutation feature importance as quotient $FI_j = e_{perm}/e_{orig}$ or difference $FI_j = e_{perm} - e_{orig}$ descending $FI$.
3. Sort features by descending $FI$.

Fisher, Rudin, and Dominici (2018) suggest in their paper to split the dataset in half and swap the values of feature $j$ of the two halves instead of permuting feature $j$. This is exactly the same as permuting feature $j$, if you want a more accurate estimate, you can estimate the error of permuting feature $j$ by pairing each instance with the value of feature $j$ of each other instance (except itself).
