## 8.2.2 LIME for Text

LIME for text differs from LIME for tabular data. Variations of the data are generated differently: Starting from the original text, new texts are created by randomly removing words from the original text. The dataset is represented with binary features for each word. A feature is 1 if the corresponding word is included and 0 if it has been removed.

## 8.2.3 LIME for Images

Therefore, variations of the images are created by segmenting the image into “superpixels” and turning superpixels off or on. Superpixels are interconnected pixels with similar colors and can be turned off by replacing each pixel with a user-defined color such as gray. The user can also specify a probability for turning off a superpixel in permutation.

## 8.2.4 Advantages

Even if you replace the underlying machine learning model, you can still the same local, interpretable model for explanation. Suppose the people looking at the explanations understand decision trees best. Because you use local surrogates, you use decision trees as explanations without actually having to use a decision tree to make the predictions. For example, you can use a SVM. And if it turns out that an xgboost model works better, you replace the SVM and still use a decision tree to explain the predictions.

Local surrogates benefit from the literature and experience of training and interpreting interpretable models.
