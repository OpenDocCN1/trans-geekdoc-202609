# 7.2 Accumulated Local Effects (ALE) Plot

Accumulated local effects⁴ shows how features influence the prediction of a machine learning model on average. ALE plots are a faster and unbiased alternative to partial dependence plots (PDPs).

I recommend reading the chapter on partial dependence plots first, as they are easier to understand and both methods share the same goal: Describe how a feature affects the prediction on average. In the following section, I want to convince you that partial dependence plots have a serious problem when the features are correlated.

# 7.2.1 Motivation and Intuition

If features of a machine learning model are correlated, the partial dependence plot cannot be trusted. The computation of a partial dependence plot for a feature that is strongly correlated with other features averaging predictions of artificial data that are unlikely in reality. This can greatly bias the estimated effect. Imagine calculating partial dependence plots for a machine learning model that predicts the value of a house on the number of rooms and the size of the living area. We are interested in the effect of the living area on the predicted value. Imagine the recipe, for partial dependence plots is: 1) Select feature. 2) Define grid. 3) Per grid value: a) Replace with grid value and average predictions. 4) Draw curve. For the calculation of the first grid value of the PDP - say 30 m² - we replace the living area for all instances by 30 m², for houses with 10 rooms. Suppose the partial dependence plot includes these unrealistic houses in the feature effect and pretends that everything is fine.
