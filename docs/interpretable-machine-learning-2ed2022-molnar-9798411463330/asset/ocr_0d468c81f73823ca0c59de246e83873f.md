Then we compare what happens when we increase one of the feature values by 1. But instead of looking at the difference, we look at the ratio of the two:

```
$odds_{x_{j+1}} / odds = \frac{exp(\beta_0 + \beta_1 x_1 + ... + \beta_j(x_j + 1) + ... + \beta_p x_p)}{exp(\beta_0 + \beta_1 x_1 + ... + \beta_j x_j + ... + \beta_p x_p)}$
```

We apply the following rule:

```
$exp(a) / exp(b) = exp(a - b)$
```

And we remove many terms:

```
$odds_{x_{j+1}} / odds = exp(\beta_j(x_j + 1) - \beta_j x_j) = exp(\beta_j)$
```

In the end, we have something as simple as $exp(\cdot)$ of a feature weight. A change in a feature by by one unit changes the odds ratio (multiplicative) by a factor of $exp(\beta_j)$.
