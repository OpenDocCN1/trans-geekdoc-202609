# 9.1.1.2 Connection to Adversarial Examples

There is a connection between feature visualization and adversarial examples: Both techniques maximize the activation of a neural network unit. For adversarial examples, we look for the maximum activation of the neuron for the adversarial (= incorrect) class. One difference the image we start with: For adversarial examples, it is the image for we want to generate the adversarial image. For feature visualization it is, depending on the approach, random noise.
