# # Introduction

This book explains to how to make (supervised) machine learning models interpretable. The chapters contain some mathematical formulas, but you should be able to understand the ideas behind the methods even without the formulas. This book is not for trying to learn machine learning from scratch. If you are new to learning for machine learning, there are a lot of books and other resources to learn the basics. I recommend the book “Elements of Statistical Learning” by Hastie, Tibshirani, and Friedman (2009) ^1 and Andrew Ng’s “Machine Learning” on the online learning platform coursera.com to start with machine learning. Both the book and the course are available free of charge!

New methods for the interpretation of machine learning models are published at breakneck speed. To keep up with everything that is published would be madness and simply impossible. That is why you will not find the most novel and fancy methods in this book, but established basics and concepts of machine learning interpretability for making machine learning models interpretable. Internalizing the basic concepts also empowers you to better understand and evaluate any new power on interpretability published on arxiv.org ^2 in the last 5 minutes since you began reading this book (I might be exaggerating the publication rate)

This book starts with some (dystopian) short stories that are not needed to understand the book, but hopefully entertain and make you think. Then the book explores the concepts of machine learning interpretability. We will discuss when interpretability is important and what different types of explanations there are. Terms used throughout the book can be looked up in the Terminology chapter. Most of the models and methods are explained using real data examples which are described in the Data chapter. One way to make machine learning interpretable is to use model-agnostic interpretation tools such as linear models or decision trees. The other option is the use of model-agnostic interpretation tools and local methods that describe the average behavior of the model and explain individual predictions. The Model-Agnostic Methods chapter deal with methods such as partial dependence plots and feature importance. Model-agnostic methods work by changing the input of the machine learning model and measuring changes in the prediction output. The book ends with an optimistic outlook on what the future of interpretable machine learning might look like.

You can read here from the book beginning to end jump directly to the methods that interest you.
