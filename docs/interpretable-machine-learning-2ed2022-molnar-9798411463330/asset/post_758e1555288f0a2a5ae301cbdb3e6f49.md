## 1.2 What Is Machine Learning?

Machine learning is a set of methods that computers use to make and improve predictions based on data.

For example, to predict the value of a house, the computer would learn from past sales. The book focuses on supervised learning, which covers all prediction problems where we have a dataset for which we already know the outcome of interest (e.g. past house prices) and want to learn to predict the outcome for new data. Excluded from supervised is for example clustering tasks (= unsupervised learning) where we do not have a specific outcome but want to find clusters of data points. Also excluded are things like reinforcement learning, where an agent learns to optimize a certain reward by acting in an environment (e.g. a computer playing Tetris). The goal of supervised learning is to learn a predictive model that maps features of the data (e.g. house size, location, floor type...) to an output (e.g. house price). If the output is categorical, the task is classified or the machine learning algorithm learns a model by estimating parameters (like weights) or learning structures (like trees). In the house value example, the machine minimizes the difference between the estimated house price and the predicted price. A fully trained machine learning model can then be used to make predictions for new instances.
