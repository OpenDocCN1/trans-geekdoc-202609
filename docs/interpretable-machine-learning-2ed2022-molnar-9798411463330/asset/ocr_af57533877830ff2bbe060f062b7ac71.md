| Sex | female |
| Class | first |
| Ticket price | 300$ |

And the corresponding anchors explanation is:

IF SEX = female AND Class = first THEN PREDICT Survived = true WITH PRECISION 97% AND COVERAGE 15%

The example shows how anchors can provide essential insights into a model's prediction and its underlying reasoning. The result shows which attributes were taken into account by the model, which in this case, is the female sex and first class. Humans, being paramount for correctness, can use this to validate the model's behavior. The anchor also tells us that it applies to 15% of perturbation space's instances. In those cases the explanation is 97% accurate, meaning the displayed predicates are almost exclusively responsible for the predicted outcome.

An anchor A is formally defined as:

> $D_{x}(z|A)}[f(x)=f(z)] \geq \tau, A(x) = 1$

Where:

+   * x represents the instance being explained (e.g. one row in a tabular data set).
* A is a set of predicates, i.e., the resulting rule or anchor, such that $A(x) = 1$ when all feature predicates correspond A to $x$'s feature values.
* f represents the classification model to be explained (e.g. an artificial neural network model). It can be queried to predict a label for $x$ and its perturbations.
* $D_{x}(|A)$ indicates the distribution of neighbors of $x$, matching $A$.
* $0 \leq \tau \leq 1$ specifies a precision threshold. Only rules that achieve a high fidelity of at least $\tau$ are considered a valid result.

The formal description may intimidating and can be put in words:

Given an instance $x$ to be explained, a rule or anchor A is to be found, such that it applies to $x$, the same class as $x$ gets predicted for a fraction of at least $\tau$ of $x$'s neighbors where the same A is applicable. A rule's precision from evaluating neighbors or perturbations (following $D_{x}(z|A)$) using the provided machine learning model (denoted by the indicator function $f(x)=f(z)$).
