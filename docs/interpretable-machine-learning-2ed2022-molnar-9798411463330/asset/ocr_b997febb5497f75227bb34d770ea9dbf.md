# Feature categorization

Another possibility to achieve a nonlinear effect to discretize the feature; turn it into a categorical feature. For example, you could cut the temperature into 20 intervals with the levels [-10, -5], [5, 0], and so on. When you use the categorized temperature instead of the continuous feature, the linear model would estimate a step function because each level gets its own estimate. The problem with this approach is that it needs more data, it is more likely to overflow and it is unclear how to discretize the feature meaningfully (equidistant intervals or quantiles? how many intervals?). # Generalized Additive Models (GAMs)

Why 'simply' allow the (generalized) linear model to learn nonlinear relationships? That is the motivation behind GAMs. GAMs relax the restriction that the relationship must be a simple weighted sum, and instead assume that the outcome can be modeled by a sum of arbitrary functions of each feature. Mathematically, the relationship in a GAM looks like this:

```
E(y|x) = \beta_0 + f_1(x_1) + f_2(x_2) + ... + f_k(x_k)
```

The formula is similar to the GLM formula with the difference that the linear term $\beta_jx$ is replaced by a more flexible function $f_j(x)$. The core of a GAM is still a sum of feature effects, but you have power to allow nonlinear relationships between features and the output. Linear effects are also covered by the framework, but for features to be handled linearly, you can limit their $f_j(x_j)$ to only the form of $x_j\beta_j$.

The big question is how to learn nonlinear functions. Another is called "splines" or "spline functions". Splines are functions that are constructed from simpler basis functions. Splines can be used to approximate more, complex functions. A like there is a confusing number of ways to define these spline functions, if you are interested in learning more about all the ways to define basis functions, I wish you luck on your journey. I am not going to go into details here, I just going to build an intuition. What helped me the most for understanding splines was to visualize the basis functions and to look into how the data matrix is modified. For example, to model the temperature with splines, we remove the temperature feature from the data and replace it with, say, 4 columns, each representing a spline basis. Usually you would have more spline basis functions, I only reduced the number for illustration purposes. The value for each instance of these new spline basis depends on the instances' temperature values. Together with all linear effects, the GAM then also estimates these spline weights. GAMs also introduce a penalty term for the weights to keep them close to zero. This effectively reduces the flexibility of the splines and prevents overfitting.
