# 作者简介

Carla Mooney毕业于宾夕法尼亚大学。在成为作家之前，她曾担任会计师在金融行业工作多年。如今，她为青少年撰写作品，是许多面向青少年和儿童书籍的作者。Mooney喜欢了解新技术以及它们对不同行业和普通数字用户的影响。
