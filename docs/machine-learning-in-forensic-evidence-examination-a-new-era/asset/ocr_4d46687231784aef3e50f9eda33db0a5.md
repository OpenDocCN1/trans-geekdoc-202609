# SEX DETERMINATION USING MACHINE LEARNING

# UNIDENTIFIED SKELETON

The crime scene may have some unidentified skeletal remains like the skull, pelvis, dental remains, long bones etc.

# MEASUREMENTS

These remains should be collected and measured using appropriate instruments like sliding callipers, spreading callipers or digital vernier callipers.

# MACHINE LEARNING ALGORITHMS

The measurements can be subjected to different machine learning algorithms like Discriminant Function Analysis using Python programming language.

# DATA LOADING

The machine learning algorithms need to be trained to perform as a predictive model, thus 70% of measurements is used as training data and remaining 30% as testing data

# TASK ASSIGNMENT

The algorithms needs to be assigned with different tasks like classification, regression, correlation etc.

# RESULT INTERPRETATON

The Machine Learning algorithm will be able to correctly classify the data i.e. whether the remains belong to a male or a female. The accuracy of classification helps it to become a predictive model.
