
# 设备被入侵的症状

虽然有些入侵显而易见，但许多入侵实际上很难检测。事实上，入侵有时极难察觉，以至于各类企业每年在网络安全技术（包括试图识别入侵的系统）上投入数千万甚至数亿美元，却仍有入侵事件长时间未被发现——有时甚至长达数年！以下部分描述了一些可能表明您的计算机、平板电脑或智能手机已被入侵的症状。

![Remember](images/remember.png)请记住，以下线索并非孤立存在，任何单一症状的出现本身并不能保证系统出了问题。除入侵发生外，多种其他原因也可能导致设备异常运行，并表现出以下部分描述的一种或多种故障。

然而，如果设备突然出现多种可疑行为，或者相关问题恰好在您将设备无人看管一段时间、点击电子邮件或短信中的链接、下载并运行了安全实践可能存在缺陷的来源提供的软件、打开了可疑附件，或做了其他您现在质疑其明智性的事情之后出现，您可能需要采取纠正措施，详见[第 13 章](#c13.xhtml)。

![Remember](images/remember.png)在考虑系统被入侵的可能性时，请始终牢记相关背景情况。例如，如果问题是在操作系统自动更新后开始出现的，其风险等级远低于在您点击了一封可疑邮件中的链接（承诺如果您协助尼日利亚王子向美国某人处理付款，将给您 100 万美元）后立即出现的同类症状。请始终保持适当、冷静的视角，切勿恐慌。如果真出了问题，您仍可采取行动将损失降至最低。恐慌不会改善局势，反而可能导致您犯错，使事态恶化。

## 设备运行速度比以前慢

在计算机、平板电脑或智能手机上运行的恶意软件通常会以明显的方式影响设备性能。传输数据的恶意软件有时还会拖慢设备与互联网甚至内部网络的连接速度。

![Remember](images/remember.png)但请记住，设备操作系统或各类软件包的更新也可能对设备性能产生不利影响，因此如果您刚更新完操作系统或从可信来源安装了软件升级，发现性能略有下降，请勿恐慌。同样，如果您填满了设备内存，或安装了许多占用大量处理器和带宽的应用，即使没有恶意软件，性能也可能下降。我曾不止一次听 IT 支持人员讲述：用户报告可疑的性能问题，结果发现用户打开了许多应用程序和数十个浏览器标签页。

![Tip](images/tip.png)您可以通过按 `Ctrl + Shift + Esc` 查看 Windows PC 上正在运行的进程，查看弹出的任务管理器窗口。在 Mac 上，使用活动监视器，您可以通过点击屏幕顶部菜单栏右侧的放大镜并开始输入 `Activity Monitor` 来访问。输入前几个字符后，工具名称应会显示，此时您可以按 `Enter` 运行它。

在 Android 设备上，屏幕底部的三个按钮或滑动操作之一通常会加载活动应用程序列表（具体是哪个按钮因设备而异）。

## 任务管理器无法运行

如果您尝试在 Windows 上运行任务管理器（参见[图 12-3](#c12.xhtml#c12-fig-0003)）或在 Mac 上运行活动监视器（见前一节），但工具无法运行，您的计算机可能已感染恶意软件。多种恶意软件变种已知会影响这些程序的运行能力。

## 注册表编辑器无法运行

如果您尝试在 Windows 上运行注册表编辑器（例如，在“运行”提示符下输入 `regedit`），但它无法运行，您的计算机可能已感染恶意软件。多种恶意软件变种已知会影响注册表编辑器的执行。

![Warning](images/warning.png)请注意，运行注册表编辑器时您可能会收到一条警告，提示其需要管理员权限。该警告属于正常现象，并非问题迹象。它也应提醒您编辑注册表可能带来的严重后果：如果您不确定自己在做什么，请勿进行任何编辑。技术人员通常认为编辑注册表和编辑 DNS 服务器属于他们最担心因失误而造成重大影响的活动之一。

## 设备开始出现延迟问题

*延迟* 是指发出指令让数据开始传输到数据实际开始传输所需的时间。如果您注意到以前不存在的延迟——尤其是延迟似乎很严重时——可能出了问题。当然，您也可能只是网络连接差，请检查网络连接强度。如果连接正常，仍有可能是您的互联网服务提供商或您与试图访问的资源之间网络路径上的其他提供商遇到了问题，而您的本地设备一切正常。然而，如果延迟问题仅出现在一台设备或一组特定设备上，而连接同一网络的其他设备均正常，且重启受影响的设备无法改善情况，您的设备可能已被攻破。

![Tip](images/tip.png)如果设备使用有线网络连接，请务必用新线缆测试。如果问题消失，原因很可能是物理连接故障或损坏。

## 设备开始出现通信和缓冲问题

无需太多技术知识即可轻松辨识的通信性能问题的一个高度可视化症状是：流式视频在预加载未来帧（即缓冲）时似乎冻结的频率比过去高得多（参见[图 12-4](#c12.xhtml#c12-fig-0004)）。虽然缓冲是大多数人偶尔会遇到的烦恼，但如果在以前不经常出现此类问题的连接上定期发生缓冲，或者仅在使用该连接的一台或多台特定设备上发生，而其他设备即使无线连接且位于同一位置或使用同一根物理网线时均正常，这可能表明系统已被攻破。如果设备使用有线网络连接，请务必检查可能导致网络问题的物理线缆。
