# 11.2.2 Wavelet coefficient modeling and feature extraction

In this chapter, Horizontal and Vertical Sub-bands (LL HL LH) in each scale are modeled using a Normal Inverse Gaussian (NIG) Probability Density Function (PDF). The diagonal sub-bands (HH) in each scale are modeled using Gaussian PDF, as this sub-band consists of all the noisy coefficients. It can find a heavy-tailed distribution of the wavelet coefficients, and the noise added to the medical image changes the shape of the distribution of wavelet coefficients.
