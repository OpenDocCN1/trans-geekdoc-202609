# 14.3 GENERATION OF ALIGNMENT-FREE AND NON-INVERTIBLE FINGERPRINT TEMPLATE USING PAIR-POLAR STRUCTURES OF MINUTIAE

In this work [34], the pair-polar structures of minutiae points are exploited to construct a protected fingerprint user template. The presented technique is alignment-free and there is no need of a singular point, which is usually utilized in existing work for fingerprint alignment purposes. This eliminates the chances of incorrect extraction of the singular point due to the change in the quality of fingerprint images and due to the type of fingerprint images, i.e., arc-type.
