# 5.2.3 Hénon map

In 1976, Michel Hénon, a French mathematician and astronomer, proposed the Hénon map, a two-dimensional map [21]. The following equations can be used to define the Hénon map mathematically [22]:

$$p(j+1)=1+q(j)-a_1 \times p(j)^2 \tag{5.2}$$ $$q(j+1)=a_2 \times p(j) \tag{5.3}$$

a₁ and a₂ are referred to as bifurcation parameters in Eqs. (5.2) and (5.3). The values of p and q have no bearing on the contraction in a 2D Hénon map. The Hénon attractor for a₁ = 1.4, and a₂ = 0.3 is shown in Figure 5.4.
