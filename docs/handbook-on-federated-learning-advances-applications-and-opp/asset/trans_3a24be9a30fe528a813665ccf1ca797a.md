
# 联邦学习中的无监督算法

机器学习中的无监督算法用于在没有类别标签的数据集中寻找结构或模式。在此框架中，参与的客户端以统一、跨客户端依赖的方式拥有数据构成。此联邦学习框架中存在跨域的数据迁移。在没有第三方干预的情况下，来自不同领域的数据和知识从去中心化的联邦学习框架传输到新设备。Peng 等人[[78](#ch1.xhtml#ref1_78)] 提倡了一种用于联邦学习框架的无监督联邦域自适应模型。在此框架中，从不同计算节点学习到的演示模型与目标计算节点的数据分布保持一致。普通计算节点与目标计算节点之间的数据迁移不同于普通计算节点之间发生的常规迁移，在前一种情况下，计算节点可能倾向于产生不利贡献。

## 5. 联邦学习中的深度学习算法：分类

本节简要讨论了与联邦学习框架集成的深度学习算法的概念。

### 5.1 联邦学习中的神经网络

McMahan 等人于 2017 年[[9](#ch1.xhtml#ref1_9)] 在联邦学习框架中提出了一种神经网络模型。该模型在 `MNIST` 数据集上进行测试，用于数字识别。该神经网络模型包含一个输入层、两个隐藏层和一个输出层；总共提出了一个四层模型。每个隐藏层包含 `200` 个神经元单元。`MNIST` 数据集被分配给客户端，且它们之间不相交。在两组上进行了两个不同的实验：在第一个实验中，相同的随机初始值被分配给两个客户端的局部模型参数；在第二个实验中，不同的随机初始值被分配给两个客户端的局部模型参数。神经网络的最终模型是利用来自两组的模型参数构建的。

### 5.2 联邦学习中的卷积神经网络 (CNN)

Rong 等人[[79](#ch1.xhtml#ref1_79)] 于 2020 年在联邦学习框架中提倡一种使用 CNN 进行特征提取的入侵检测方法。首先，使用数据填充方法构建二维结构。扩散 CNN 用于在联邦学习系统中构建和学习特征参数。`SoftMax` 分类器用于在检测阶段确定类别标签。该联邦学习中使用的 CNN 模型包含 `4` 个卷积层和两个全连接层。高检测率和缩短的训练时间是该模型的重要属性。进行了三种不同类型的实验并展示了其结果。观察到将隐藏层数量从两层增加到三层对性能没有显著影响。验证了二维结构可降低运营成本并提高准确率。在入侵检测方法中应用 `FC` 算法，并在 `NSL-KDD` 数据集上进行实验，结果显示准确率无变化，但观察到训练时间减少。在基于 `FC` 算法的模型中，训练阶段客户端与服务器之间交换的参数数量较少，从而减少了训练时间。

Sattler 等人[[80](#ch1.xhtml#ref1_80)] 提出了一种名为稀疏三元压缩 (`STC`) 的方法，可在交换模型参数时减少带宽使用。上传模型、训练模型、从服务器下载模型以及最终聚合是采用 `STC` 设计的联邦学习训练过程的一部分。非独立同分布 (`non-IID`) 数据在边缘设备中普遍存在，从而降低了联邦学习模型中训练的有效性。显然，本地边缘设备的梯度会偏向本地数据集。估计梯度的均值预期是无偏的。在使用包含全局 `5%` 公共数据的 `CIFAR-10` 数据集进行的实验中，观察到准确率提高了 `30%`。

### 5.3 联邦学习中的贝叶斯网络

Yurochkin 等人[[81](#ch1.xhtml#ref1_81)] 在联邦学习框架中提出了一种贝叶斯网络。Beta-Bernoulli 过程 (`BBP`) 是一种贝叶斯非参数 (`BNP`) 模型，允许在局部参数和全局参数之间进行参数匹配。当当前全局参数与局部参数不匹配时，将重构新的全局参数。`BBP` 的两个重要特征是：(a) 将局部模型学习与联邦学习中聚合成全局模型的局部客户端组合分离开来，从而可以在数据源上使用不同的学习算法；(b) 已知预训练模型时，`BBP` 可以利用其匹配机制将它们组合成全局模型，无需额外学习算法的支持，并可构建预训练模型。`BNP` 的目标是识别 `K` 个局部模型中的神经元子集，并使其与其余局部模型中的神经元等价。来自局部模型的这些神经元簇被组合在一起形成全局模型。

### 5.4 联邦学习中的长短期记忆网络 (LSTM)

Li 等人提出了联邦近端算法 (`FedProx`)[[82](#ch1.xhtml#ref1_82)]，用于字符识别和情感分析。与 `FedAvg` 相比，`FedProx` 具有更好的收敛性。在统计异质性的情况下，当局部客户端发生变化时，`FedAvg` 中的局部客户端将无法以相同的速度完成更新。为应对这一挑战，`FedProx` 引入了一个稳定项来稳定联邦学习框架。该稳定项显著增加了对局部参数与全局参数之间差距的限制。包含两层、 `100` 个隐藏单元和 `80` 个嵌入层的 `LSTM` 分类器被纳入 `FedProx`。与 `FedAvg` 相比，`FedProx` 在异构生态系统中具有更高的准确率（提高 `22%`）和更快的收敛速度。

### 5.5 联邦学习中的强化学习

Anwar 等人提出了用于构建模型投毒攻击者模型的强化学习，这可能对联邦学习构成严重挑战。针对移动设备的通用攻击无效。多任务联邦强化学习 (`MT-FedRL`)[[83](#ch1.xhtml#ref1_83)] 利用信息增益最小化对联邦学习系统发起有效攻击。在 `MT-FedRL` 中，存在 `n` 个智能体，每个智能体拥有自己的环境，且更新策略在马尔可夫决策过程 (`MDP`) 的框架内运行。每个智能体拥有自己的状态空间和动作空间。每个智能体由一个 `5-元组` 表征，它们分别是奖励函数、折扣因子、转移概率、状态空间和动作空间。`MT-FedRL` 的目标是构建一个在 `n` 个智能体的所有环境中均为最优的协作策略[[84](#ch1.xhtml#ref1_84)]。联邦学习中强化学习的框架如[图 10](#ch1.xhtml#fig1_10)所示。
