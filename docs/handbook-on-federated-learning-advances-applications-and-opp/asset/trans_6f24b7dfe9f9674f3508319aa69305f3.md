# 第3章 联邦学习架构、机遇与应用

*Pradipta kumar Mishra*，^([³](#fn3))

## 1. 简介

为了提高隐私和安全性，联邦机器学习作为机器学习领域的一个新兴方向，允许多方在不泄露各自数据的情况下共同训练一个机器学习模型。关于联邦机器学习的文献大致可分为三类：应用、系统和算法。
