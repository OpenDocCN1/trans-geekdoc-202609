

# 联邦学习：原理、技术与应用

联邦学习为数据分布在众多设备（如智能手机或物联网设备）上的场景提供了一个极具前景的解决方案，在这些场景中，由于隐私、安全或带宽限制，将数据传输到中心位置要么不切实际，要么不可取。通过使参与者能够在不暴露其数据的情况下为通用模型做出贡献，联邦学习提供了一个机会，利用多样化且广泛的用户群体的集体知识，同时保持数据隐私和所有权。

在本文中，我们将深入探讨联邦学习的原理、技术和应用，首先概述定义该方法的核心组件，如分布式数据源、本地训练、模型聚合和全局模型。我们还将讨论与联邦学习相关的独特挑战和要求，包括高效通信协议的开发、隐私保护技术和联邦优化算法。

此外，我们将探索联邦学习增强各个领域的潜力，如医疗保健、金融和智慧城市，在这些领域中隐私和数据所有权至关重要。通过考察真实案例和案例研究，我们将说明联邦学习在这些背景下的实际应用和优势。

最后，我们将确定联邦学习领域未来研究和发展的方向，强调需要持续的探索与合作，以充分发挥这种去中心化机器学习方法的潜力。

## 2. 相关工作

### 2.1 微任务与宏任务的组织

人们很自然地会想知道宏任务协调与微任务协调有何区别。由于多种原因，宏任务比其较小的对应物需要员工之间进行更多的协作。许多项目被分解为更小、更易管理的块，称为“微任务”，然后分配给特定的人完成。相反，人群中的个人不一定需要相互沟通即可完成离散的、自包含的任务。然而，许多大规模项目无法委托给单个工作者，而是需要集体努力。宏任务的相互关联性质使得众包工人之间的协调变得重要。目标受众比请求者更有可能将宏任务分解为更小的任务。众包成员之间的协调对于宏任务的分解和后续微任务的组合都是必要的。

### 2.2 协调理论

#### 2.2.1 跨性记忆系统

跨性记忆系统（TMS）中的任务协调基于系统内的个体相互了解并共享信息。共享或分担脑力劳动有助于完成工作 [[14](#ch14.xhtml#ref14_14), [15](#ch14.xhtml#ref14_15) 和 [16](#ch14.xhtml#ref14_16)]。信息系统、组织行为学、心理学和传播学只是许多研究领域中的几个，这些领域的研究表明 TMS 能改善协调，进而提升绩效 [[17](#ch14.xhtml#ref14_17), [18](#ch14.xhtml#ref14_18)]。特别是，TMS 在团队协调方面的优势导致了涌现性和适应性的行为模式，这反过来又促进了高效且不显眼的形式 [[19](#ch14.xhtml#ref14_19)]。TMS 是协调多个团队工作的成熟方法。

五个基本要素使 TMS 得以运作。首先，小组中的每个人都需要在自己的领域内是专家。其次，小组需要建立一个心理图表，说明在专业领域方面，团队中的每个人如何为整体做出贡献。第三，每个小组成员应根据其专业领域负责特定的一组任务 [[20](#ch14.xhtml#ref14_20), [21](#ch14.xhtml#ref14_21) 和 [22](#ch14.xhtml#ref14_22)]。小组中的每个人都需要彼此信任，并相信其他人在各自的角色中称职 [[23](#ch14.xhtml#ref14_23), [24](#ch14.xhtml#ref14_24)]。第五，需要持续的双向沟通，以便小组中的每个人都能从其他人的经验和见解中受益 [[25](#ch14.xhtml#ref14_25)]。对话使共享专业信息变得更容易，这对于利用群体知识至关重要。

##### 跨性记忆系统的基本要素

*   成员拥有专业知识
*   对专业信息的共同心理表征
*   需要专业知识的工作义务
*   成员彼此信任对方的专业知识
*   参与者愿意传授其专业知识

**对宏任务的潜在益处**：TMS 使众包工人能够隐性地相互协调。它是直接语音交流的更高效替代方案。任务管理系统也可用于分配职责。随着任务的出现，众包工人根据其专业领域被分配任务。

**对宏任务的潜在缺点**：要么众包群体需要在项目开发方面拥有共同背景才能创建 TMS，要么必须有某种方式让众包成员相互传达各自的专业领域。众包员工可能没有足够的时间来建立 TMS。可以构建平台来揭示群体中的专家。然而，当人们加入和离开群体时，对于已经在工作的人来说，要跟踪谁知道什么可能具有挑战性。

#### 2.2.2 协调理论

**它是什么？**：关于协调主题最著名的思想流派之一被称为“协调理论” [[26](#ch14.xhtml#ref14_26)]。根据该理论，协调需要控制所谓的“活动间的依赖关系” [[27](#ch14.xhtml#ref14_27)]。协调理论在创建协作系统背景下的创新用法是，基于任务间联系的性质使用协调机制 [[28](#ch14.xhtml#ref14_28)]。Malone 和 Crowston 在他们的协调分析中，建立了一个基于“行动者”、“相互依赖的任务”和“资源”三个轴的框架（1994）。在进行此分析后，可以采取适当的协调机制，以解决因任务、行动者和资源之间的相互依赖而产生的协调问题。

**它是如何工作的？**：协调理论在某些关键方面不同于其他协调理论。它强调任务之间的相互依赖，而不是人或部门之间的相互依赖 [[29](#ch14.xhtml#ref14_29)]。这一协调概念强调的是活动之间的关系，而非工人之间的关系。其次，它对任务间不同类型的相互依赖进行分类。这使得更容易理解特定依赖关系的潜在结果。该理论的另一个好处是它可以用来描述协调，这提高了我们查看不同工作分配和重新分配如何影响整体生产力的能力。这增强了对个体差异对团队凝聚力影响的认识。然而，最近的研究表明，协调理论在协调集体行动方面存在局限性 [[30](#ch14.xhtml#ref14_30), [31](#ch14.xhtml#ref14_31)]。

##### 协调理论的基本要素

*   识别任务
*   识别并分类活动间的相互依赖关系
*   利用最适合每种依赖类型的方法
