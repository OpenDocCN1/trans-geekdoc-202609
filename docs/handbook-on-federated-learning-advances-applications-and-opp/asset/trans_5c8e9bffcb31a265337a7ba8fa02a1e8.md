

# 第 7 章 云环境中用于数据丢失防护的高效联邦学习技术

*A Peter Soosai Anandaraj*，^([⁷](#fn7))

## 1. 简介

在大数据时代，数据安全已成为主要的保护类型，因为实际上所有信息都通过网络传输。尽管网络信息安全保护机制取得了重大进展，但隐私问题和敏感信息泄露依然存在 [[1](#ch7.xhtml#ref7_1)]。机器学习是大数据时代最流行的数据分析和处理方法，因计算机计算能力的进步而被广泛应用于各个行业。然而，机器学习发展面临两大问题。一方面，维护数据安全颇具挑战，且对隐私保护的担忧日益加剧。另一方面，随着大数据成为新趋势，企业收紧数据保护措施以防止数据泄露，导致数据共享减少。机器学习在为训练传输数据时遇到的困难，正是导致数据孤岛的原因。利用一种名为联邦学习的前沿机器学习架构，相互戒备的客户端仍可从协作训练模型中获益，而无需在公开场合披露其机密信息集 [[3](#ch7.xhtml#ref7_3)]。联邦学习也被称为去中心化 ML 框架。由于网络带宽受限，云服务器与客户端之间巨大的通信开销已成为主要问题。此外，还可利用相同的模型参数发起模型反演攻击。

一个组合模型存储在云服务器上，而训练数据分散在多个设备上。客户可借助联邦学习这一开创性的机器学习设计，在保护其个人数据机密性的前提下，从协作训练技术中受益。它也被称为去中心化 ML 框架 [[5](#ch7.xhtml#ref7_5)]。训练数据分布在多个设备上，组合模型存储在在线计算机上。然而，云服务器与客户端之间的高传输开销，以及模型反演攻击，已浮现为主要问题。

联邦学习 (FL) 是一种无需透露原始训练数据即可支持分布式协作学习的潜在方法 [[2](#ch7.xhtml#ref7_2)]。FL 在此提供了一个直接的解决方案。即通过将数据保留在本地，一个组合模型存储在云服务器上，而训练数据分散在多个设备上。客户可利用 FL 这一革命性的 ML 设计，通过协作训练方法保护其私人信息的隐私。这是通过检测数据泄露和 ATO（账户接管）欺诈来实现的。此外，它还会检查信用评分并学习用户的足迹，以在不上传数据到云端的情况下防止欺诈性 KYC [[7](#ch7.xhtml#ref7_7)]。FL 为金融科技风险缓解铺平了道路。它为客户和企业开发独特且创新的技术 [[4](#ch7.xhtml#ref7_4)]。它在双方之间建立信任。也允许他们推进合作关系。随着技术进步，信息量呈爆发式增长。因此，实施了更多隐私法规来保护此类信息。许多企业已开始采用联邦学习。它们在不同数据集上训练算法，而无需传输数据。联邦学习旨在保护通过多个渠道获取的数据。同时将关键信息保留在本地 [[6](#ch7.xhtml#ref7_6)]。FL 是一种技术，可在设备上进行机器学习，而无需将用户的私人数据发送到中央云。因此，联邦学习有助于实现个性化。以及提升物联网应用中的设备性能。最近，本研究讨论了采用 FL 方法面临的当前障碍，以及其在医疗 AI、物联网、边缘系统和自治企业等实时系统中的改进，这些领域未来在实际应用中可扩展采用 FL。

尽管面临数据不平衡、资源分配和隐私担忧等障碍，本研究重点关注云计算中的联邦学习技术，以及 FL 面临的核心挑战，这些挑战可能包括联邦网络间的有效高效通信、系统异构性管理，以及同一网络内的统计异构性 [[8](#ch7.xhtml#ref7_8)]。
