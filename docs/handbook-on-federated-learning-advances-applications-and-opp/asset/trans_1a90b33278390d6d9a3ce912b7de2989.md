

# 联邦学习与深度强化学习用于车辆任务卸载

在联邦学习中，训练好的模型及其参数存储在不同位置，但各方协同工作以构建单一通用预测模型 [[13](#ch8.xhtml#ref8_13)]。车辆频繁收集数据，并利用这些数据在数据并行联邦学习技术的学习过程中开发自主的本地模型 [[14](#ch8.xhtml#ref8_14)]。下一步是使用全局模型重新训练本地模型，该全局模型由先前训练的所有本地模型的参数组合构建而成。学习算法的重复过程确保最终收敛 [[15](#ch8.xhtml#ref8_15)]。联邦学习依赖中心化聚合器这一事实使其分布式程度不如预期；然而，完全去中心化会降低学习模型的效率 [[16](#ch8.xhtml#ref8_16)]。

恶意车辆篡改本地训练数据或自私车辆不提供其本地模型也可能导致策略失败 [[17](#ch8.xhtml#ref8_17)]。然而，在自动驾驶车辆的背景下，该方法切实可行，并可投入使用以提供更安全、更快捷的车辆服务。利用来自环境的持续反馈，强化学习（RL）是一种智能学习最佳策略以最大化奖励的 AI 技术 [[18](#ch8.xhtml#ref8_18)]。这类似于个体通过经验而非直接观察来了解周围环境的方式 [[19](#ch8.xhtml#ref8_19)]。传统 RL 虽然可行，但在收敛到理想策略之前，完全探索复杂环境将花费过长时间。在通常拥有巨大且连续状态-动作空间的此类系统中扩展 RL 是一个重大挑战。据建议，深度强化学习（DRL）可以增强泛化能力和对新情况的适应性，使其非常适合此类广阔环境 [[20](#ch8.xhtml#ref8_20), [21](#ch8.xhtml#ref8_21)]。强化学习智能体与复杂环境及深度网络进行交互，以近似学习用于未来动作的价值函数或策略 [[22](#ch8.xhtml#ref8_22)]。DRL 在控制、资源管理、游戏、机器人技术和自动驾驶等不同领域的应用已得到验证 [[4](#ch8.xhtml#ref8_4)]。

具体而言，强化学习擅长在模糊环境下进行序列决策。这是因为与具有显式规则的传统优化问题不同，在高度动态的移动场景中，卸载约束往往更加隐式和多样化 [[23](#ch8.xhtml#ref8_23)]。例如，车联网（V2X）支持多种服务，每种服务都有其自身的需求和挑战 [[24](#ch8.xhtml#ref8_24)]。另一个促成基于 RL 的卸载决策模型日益流行的因素是汽车技术创新的快速扩展应用。为达成目标，这些模型通常利用强化学习获取更优方法 [[25](#ch8.xhtml#ref8_25)]。有趣的是，该训练可通过分布式算法完成；因此，该方法可通过分布式协作开发，利用本地知识提升系统级性能 [[26](#ch8.xhtml#ref8_26)]。为实现高效的任务卸载决策，我们提出了一种基于 DRL 的联邦卸载架构，该架构利用多层集体学习来卸载作业 [[27](#ch8.xhtml#ref8_27)]。通过允许汽车和雾服务器共享信息，该框架增强了它们的学习能力。本研究最重要的成果如下：

*   为做出更明智的工作卸载决策，重要的是研究多智能体 V2X 场景，其中智能体相互通信并与周围车辆环境交互。
*   利用多个分布式学习环境创建多层联邦卸载系统，可在边缘学习卸载决策。由于层级间共享的数据减少，这提高了通信通道的隐私性和效率。
*   利用一种称为异步优势行动者-评论家（A3C）的混合强化学习范式，研究人员可构建两层卸载系统。车辆智能体用于学习本地模型，而雾服务器用于训练全局模型。通过同时运行多个独立的学习环境，A3C 可捕获更大比例的状态空间。这种状态空间探索和多层学习策略带来了更快的收敛和更优的卸载决策知识。
