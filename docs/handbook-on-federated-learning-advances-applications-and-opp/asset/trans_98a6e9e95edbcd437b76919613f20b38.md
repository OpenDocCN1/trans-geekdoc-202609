# 第2章 联邦数据模型——本地化、全球化与融合化——工业4.0背景下

*Daniel Einarson*[²](#fn2)

计算机科学系，自然科学学院，瑞典克里斯蒂安斯塔德大学。

## 1. 前言/背景

本文旨在探讨在联邦学习视角下创建数据模型的相关方面，以及如何以数据融合为核心，从AI角度实现联邦学习。我们讨论的背景是侧重于制造业及其传感器与机器人技术的工业4.0环境下的联邦学习，包括该数据领域中的计算和语义方面。

第一作者拥有自主自我感知软件组件的分层组合设计背景，此类组件在特定环境中协同工作。针对此类场景，已开发出用于表示智能体的过程模型，例如用于机器人技术，也用于生物生命系统，如特定环境中的鸟类。此处特别重要的是，智能体的感知能力由AI概念来表示。AI的一个关键概念是机器学习和人工神经网络。尽管如此，在智能体的背景下，开发互补模型被认为既有趣又重要，其灵感来源于认知科学领域，旨在将反射性行为表示为对外部刺激的响应。因此，这种互补建模被视为从理论和技术角度均具有研究价值，并提供了未来可能的建模选项。

第二作者在澳大利亚联邦科学与工业研究组织（CSIRO）矿产资源部门创立并开发了一个4D数据管理系统，历时数年，专注于如何通过索引合并数据。该数据管理系统称为`VoxelNET` [[1](#ch2.xhtml#ref2_1)]，专注于如何融合异构数据集，这些数据包含制图、GIS、地形数据、岩石钻探数据、各类传感器数据（带GPS位置）、随时间（T）水平和垂直移动的物料数据，且要求具备可扩展性。所有这些数据的共同分母是*体积*。在矿业中，一切关乎体积计算，以及地质和矿产（金、银、铜、锂、铁……）赋存于岩石何处。矿业面临矿产资源减少的问题，意味着开采作业必须向更深处推进。由于深部温度较高，机器人需要取代人类以确保我们始终安全。这引出了机器人技术，以及联邦学习必须如何运作、或我们希望其如何运作，以造福整个*制造价值链*，在该链条中，许多操作任务由各种承包商及人员/机器/机器人执行。

本章为联邦学习在工业4.0背景下的适用性设定了场景，而非解决具体的技术方案。此外，联邦学习的AI层面通常指机器学习。然而，在工业4.0自主设备的背景下，作者认为有必要扩展这一AI概念，使其也包含认知方面。虽然基于机器学习的联邦学习已被证明可以自动执行，但这一扩展为工业4.0环境带来了新的挑战和新的机遇。
