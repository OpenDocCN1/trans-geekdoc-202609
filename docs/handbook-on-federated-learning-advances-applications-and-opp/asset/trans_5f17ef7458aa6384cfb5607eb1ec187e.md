# 第5章 导航联邦学习中的隐私顾虑：基于GDPR的分析

*G Anitha*^([⁵](#fn5))

## 1. 引言

当今绝大多数软件和服务，尤其是医疗、交通和货币领域使用的软件和服务，都依赖于由人工智能（AI）驱动的复杂机器学习（ML）算法收集的数据 [[1]](#ch5.xhtml#ref5_1)。人工智能在生活的各个领域都取得了进展，预计其对全球的影响将超过人类历史上任何其他事件。不仅仅是电网 [[2]](#ch5.xhtml#ref5_2)，[[3]](#ch5.xhtml#ref5_3)。AI的全部潜力尚未实现，基于AI/ML的应用开发仍面临重大障碍。集中式存储和处理是这些问题的主要因素 [[4]](#ch5.xhtml#ref5_4)。在现实世界中，数据，尤其是个人数据，通常产生并存储在孤立的位置，例如个人用户的设备或中央数据中心。对于大多数传统ML算法，训练数据通常集中在数据服务器中 [[5]](#ch5.xhtml#ref5_5)。简言之，从许多来源收集、整合和融合分散的数据并非易事，更不用说管理和安全分析由此产生的海量信息了 [[6]](#ch5.xhtml#ref5_6)。在不增加GDPR等数据保护规则和限制复杂性的情况下，以高速跨组织传输具有可变准确度的海量数据已经很有挑战性了 [[7]](#ch5.xhtml#ref5_7)。在单个高性能云服务器上使用传统ML算法处理海量数据时，既可能发生安全漏洞，也可能出现单点故障 [[8]](#ch5.xhtml#ref5_8)。

集中式数据处理和管理带来的缺乏透明度和来源追溯，可能使赢得消费者信任和满足GDPR要求变得困难 [[9]](#ch5.xhtml#ref5_9)。专业人士和学者都注意到了Google于2016年创建联邦学习（FL）以克服此类障碍。通过在智能手机、平板电脑等孤立数据源保存的许多本地数据集上执行ML算法，FL消除了对集中式数据服务器的需求 [[10]](#ch5.xhtml#ref5_10)，[[11]](#ch5.xhtml#ref5_11)。在FL中，本地节点存储训练数据集并协同计算以训练一个集中的ML模型 [[12]](#ch5.xhtml#ref5_12)。

借助FL，服务提供商可以在其应用程序和服务中实现某些类型的机器学习算法，而无需从客户那里收集任何个人身份信息，这可能使他们更容易满足GDPR等数据保护法规（DPR） [[13]](#ch5.xhtml#ref5_13)，[[14]](#ch5.xhtml#ref5_14)。尽管FL采用了保护隐私的分布式协作学习方法，但私人数据仍可能从本地训练中被秘密检索 [[15]](#ch5.xhtml#ref5_15)。因此，在处理印度公民数据时，佛罗里达州的服务提供商有义务采取符合GDPR的预防措施 [[16]](#ch5.xhtml#ref5_16)。在本文中，作者从GDPR合规的角度回顾了以往的FL研究，重点关注隐私保护方法 [[17]](#ch5.xhtml#ref5_17)。首先，我们将FL作为一种可行的方式，来克服传统集中式ML系统中数据隐私保护的困难 [[18]](#ch5.xhtml#ref5_18)，[[19]](#ch5.xhtml#ref5_19)。其次，概述了集中式FL的前沿隐私保障措施，并探讨了这些方法如何从数据安全和隐私角度减少漏洞。第三，我们提供了深入的讨论，并提出了关于如何设计FL系统以满足GDPR要求的可能解决方案。我们还提出了未来研究的潜在方向，并强调了阻碍联邦学习系统满足GDPR必要条件的剩余挑战。

## 2. 基于ML的GDPR合规与隐私保护系统

### 2.1 语境属性

创新的机器学习（ML）领域使机器能够在未被显式编程的情况下执行任务，让它们通过经验学习和改进。为此，机器学习系统利用数据集（训练数据）构建数学模型，旨在随时间微调模型参数 [[20]](#ch5.xhtml#ref5_20)，[[21]](#ch5.xhtml#ref5_21)。这使得算法在面对新数据时能做出更准确的预测或判断。寻找目标函数的最大值通常是数学优化问题的最终目的，可用于描述ML工作。因此，任何基于ML的系统都必须具备优化技术。

#### 2.1.1 梯度下降算法

梯度下降是ML和FL的基础，使其成为ML中流行的优化方法 [[22]](#ch5.xhtml#ref5_22)。它是一种用于寻找带有用户指定参数的目标函数 `f(θ)` 极小值的一阶迭代优化算法。`D = (x[1], y[1]), (x[2], y[2]), ..., (x[m], y[m])`，以及目标函数 `f(θ)`；模型中的每个参数都使用梯度下降方法沿目标函数 `f(θ)` 梯度的相反方向进行更新，如以下公式所示。

(1)

$$
w_j \leftarrow w_j - \eta \nabla \frac{1}{m} \sum_{i=1}^{m} L(f(x_i) - y_i)
$$

其中

> `w[j]`：`θ` 的第 j 个参数
>
> `η`：学习率超参数。

MSE和交叉熵损失是可用字母 `L` 表示的损失函数示例。参数使用公式1反复更新，直到达到局部极小值，或阶段间损失的变化足够小以至于可以忽略。

#### 2.1.2 梯度下降变体
