
# 联邦学习概述

在终端设备上，DNN 模型通过联邦学习（FL）联合训练。FL 训练操作通常由两个过程组成：最终设备上的区域模拟以及 FL 服务器上变更属性的全球收集。为了推广 FL 的本地模型训练，我们在本节中首先概述 DNN 原型实验。尽管 FL 可用于一般性地训练 ML 模型，但我们在本部分重点讨论 DNN 模型的训练，因为我们在下一节讨论的大多数文章都关注 DNN 模型的联邦训练。DNN 模型易于聚合且在许多情况下优于传统 ML 技术这一事实 [[16](#ch7.xhtml#ref7_16)]，因此随着分布式终端设备获得的深度学习（DL）不断扩展、处理能力增强以及数据量增长，FL 在移动边缘网络中的有机采用理应得到促进。

FL 的开发是为了回应数据所有者的隐私担忧 [[21](#ch7.xhtml#ref7_21)]。FL 通过允许用户联合训练同一框架并将数据保留在其设备上，消除了客户的隐私顾虑。因此，FL 可能是一种使移动边缘网络能够训练 ML 模型的解决方案。有关各种 FL 可能性的摘要，包括并行 FL 和直立 FL（直译：straight up FL）。

## 2. 相关工作

联邦学习（FL）作为一项开创性技术，通过安全机制解决了保护个人信息的问题，它允许用户在保持对数据的本地控制的同时共同开发全局模型。平台聚合模型直到收敛，而客户端训练其本地模型。在此过程中，服务器采用奖励结构以鼓励用户提供大量高质量数据。

尽管已有一些工作将 FL 应用于物联网（IoT）、医疗、工业和补充领域，但 FL 应用仍处于起步阶段，仍有若干问题未得到解决 [[9](#ch7.xhtml#ref7_9)]。如今，提高 FL 模型质量是热门研究课题之一，也是难点问题之一。本文客观且深入地探讨了提高 FL 模型质量的方法。由于从业者经常担心实现隐私保护需要以牺牲学习质量为代价，我们特别关注 FL 的研究与应用发展，以及 FL 与非 FL 之间的影响对比 [[10](#ch7.xhtml#ref7_10)]。我们系统地评估了现有的 FL 相关文献。本综述提供的信息和见解可能对学术界和业界人士均有用处。我们考察了影响 FL 模型质量的关键因素、学术界和工业界 FL 应用研究的趋势，以及 FL 与非 FL 算法在学习方面的有效性对比。基于调查结果，我们提出了一些提升 FL 模型质量的建议。

如今，大量联网设备（包括手机、可穿戴技术和自动驾驶汽车）产生海量数据（大数据）。由于这些设备处理能力的快速提升以及隐私担忧，本地存储和分析数据的需求日益增长，这促使计算从云端向边缘转移。为了充分挖掘大数据的潜力，需要人工智能（AI）：深度学习已被证明在从复杂数据中提取知识方面非常成功。深度神经网络设计已被证明在对著名 ImageNet 数据集的照片进行分类方面表现优于人类。由于传统机器学习算法要求所有数据必须汇聚在一处（通常是云数据中心），因此可能违反用户隐私和数据保密法律。科技公司在世界许多不同地区处理用户数据时，现已被要求遵守用户隐私规则。一个例子是欧盟的《通用数据保护条例》。

联邦学习是一种可行的方法，可利用网络边缘设备的海量多样化数据集和不断增强的处理能力，同时保护所用数据的隐私。由于金融和医疗应用处理的数据敏感且难以共享，因此必须保证隐私。即使已有少数 FL 在商业环境中成功应用的实例，但在这些架构常用于常规应用之前，仍必须解决若干研究问题 [[11](#ch7.xhtml#ref7_11)]。FL 已成为一种前沿范式，以回应对个人数据安全的担忧，以及智能手机、可穿戴设备和无人驾驶车辆等小工具计算能力的增强 [[13](#ch7.xhtml#ref7_13)]。由于对个人数据存储的需求增加，以及在最小化数据传输额外开销的同时将 ML 计算移至终端设备，科学家们已尝试在一些学科中改造 FL 架构 [[12](#ch7.xhtml#ref7_12)]。联邦学习类似于小组演示或报告，涉及众多人员远程共享数据，以联合训练单一深度学习模型并逐步改进它。模型（通常是先前已训练的基础模型）从云数据中心分发给每位参与者。模型使用其个人数据更新后，会被汇总并加密。修改后的模型被发回云端，在那里被平均、加密并集成到原始模型中。直到模型完全训练完成，协作训练将迭代进行。

在联邦学习基础设施中，应优先考虑同步还是异步训练方法，这是一个关键的设计选择。异步训练已被许多成功的深度学习研究采用，例如 Dean 等人 (2012) 的研究，但最近，同步大批量训练逐渐增加，甚至在数据中心中也是如此（Goyal 等人，2017；Smith 等人，2018）[[14](#ch7.xhtml#ref7_14)]。McMahan 等人 (2017) 的联邦平均算法采用了类似的方法。此外，一些改进 FL 隐私保证的方法，如差分隐私（McMahan 等人，2018）和安全聚合（Bonawitz 等人，2017），本质上要求在一组固定设备上进行某种形式的同步，以确保学习算法的服务端组件只需使用来自多个用户的更新的简单聚合 [[15](#ch7.xhtml#ref7_15)]。
