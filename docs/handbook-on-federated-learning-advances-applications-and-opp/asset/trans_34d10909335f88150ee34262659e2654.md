

# 第13章 利用基于区块链的联邦学习检测豪华酒店的设备传感器以提高客户满意度

*H.M. Moyeenudin*,^([^(13)](#fn13))

## 1. 简介

一种称为联邦学习（FL）的人工智能分支能够训练多个模型（客户端），并将其学习成果结合起来创建单一的最终模型（服务器）。在下一轮开始之前，每个客户端模型都会使用上一轮的服务器模型进行更新 [[1](#ch13.xhtml#ref13_1)]。划分数据段、构建机器学习模型、利用区块链实现安全和隐私方法、构建数据通信架构以及联邦规模是FL数据划分的五大类别 [[2](#ch13.xhtml#ref13_2)]。其中，带有联邦评估模型的区块链聚合节点（AN）与传感器节点（SN）ID相连接，经过认证并存储在区块链中 [[3](#ch13.xhtml#ref13_3)]。因此，这些AN和SN分别已在私有链和公有链上完成认证。然而，当有人使用网络资源时，不受信任的节点会实施恶意行为。SN也容易受到恶意节点的攻击，且能量低、传输范围小、计算能力弱。恶意节点随后传播不准确的路由信息并增加重传次数，导致SN的能量迅速耗尽。SN能量的快速耗散缩短了无线传感器网络的寿命。此外，当网络中存在恶意节点时，吞吐量和丢包率均会上升。系统会计算SN的信任值以消除网络中的有害节点。为实现安全路由，网络会综合考虑SN的信任值和剩余能量。此外，还采用非对称密钥密码系统来保障数据传输安全。仿真结果表明，该建议模型在高包投递率方面行之有效。聚合通常使用FL。一个容易理解的例子是：某个数据集仅包含特定医院的乳腺癌患者数据。当客户端面临不同的特征空间但相同或可比的样本空间时，垂直数据划分便应运而生 [[4](#ch13.xhtml#ref13_4)]。利用实体对齐方法在客户端数据中发现重叠样本，并将这些重叠数据用于训练。来自多个国家机构的学生GPA数据集可能是一个合适的例子。评分标准和评估指标是特征空间的不同方面。水平和垂直数据划分用于创建混合数据划分。一个容易理解的例子是：一组大学希望构建一个FL系统并评估所有分校的学生表现。

在选择ML模型时，通常会考虑来自数据集和问题陈述的AI模型。神经网络（NN）是最常用的模型之一。除了NN，决策树也被采用，因为它们高效且易于理解。FL系统可能由同构或异构模型组成。在前一种情况下，所有客户端使用相同的模型，服务器使用梯度聚合。然而，在后一种情况下，由于每个客户端都有独特的模型，因此无需担心聚合问题。在异构模型的情况下，服务器端采用最大投票等集成方法来替代聚合技术。水平数据划分中多个客户端的数据集共享相同的属性，但样本空间交集有限。FL的隐私保护方法是备受关注的部分。主要目标是防止客户端信息泄露 [[5](#ch13.xhtml#ref13_5)]。
