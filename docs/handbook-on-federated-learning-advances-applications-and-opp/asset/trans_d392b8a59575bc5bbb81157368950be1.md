

# 复合复杂性与 QSAR 模型中的联邦学习

化合物的复杂性使得 QSAR 模型变得复杂且高维，因此需要大量的训练数据。然而，收集训练数据需要耗费大量的时间和金钱。由于担心共享化合物知识产权（如专有结构）以及其他信任问题，任何跨机构合作都受到了限制。Chen 等人于 2020 年探讨了将联邦学习作为使组织间能够建立联盟以协作创建 QSAR 原型的关键手段。实验结果（见下文[图 4](#ch9.xhtml#fig9_4)）表明，在预测性能方面，联邦模型优于任何单一客户端利用私有数据训练的模型。联邦学习使研究人员能够在制药领域更有效地协作并发现新型药物 [[22](#ch9.xhtml#ref9_22)]。

## 5.6 护理质量

药房流失率常被视为衡量患者安全和护理质量提供情况的关键指标。为了让临床医生能够提供更个性化的护理和疗法，识别影响患者死亡率的变量至关重要。识别影响死亡率的因素需要庞大且多样化的患者群体，但记录医院只能访问其各自的患者数据，这限制了它们做出精准预测的能力。

Vaid 等人（2020）利用电子健康记录（EHR）数据构建了联邦学习模型，以预测住院后七天内 COVID-19 患者的死亡情况。该研究考虑了从纽约市（NYC）西奈山医疗系统（MSHS）五家医院的 Epic EHR 系统中获取的 COVID-19 阳性患者的人口统计学特征、既往入院记录、病历和实验室数据（如心率、呼吸频率、血糖）。作者同时采用了多层感知机（MLP）和带有 L1 正则化的逻辑回归来预测死亡率。作者使用 AUC-ROC 评估了局部模型和联邦模型的性能，发现在大多数站点，联邦模型表现更优 [[21](#ch9.xhtml#ref9_21)]。

联邦学习让医疗专业人员能更深入地了解影响治疗决策的风险变量，从而提供更安全、更高效、更个性化的护理。

# 6. 联邦学习的挑战

除了潜在的安全顾虑外，联邦学习还有若干限制，使其无法成为解决我们所有数据隐私问题的灵丹妙药。值得注意的是，联邦学习训练模型所需的本地设备算力和内存比传统机器学习技术多得多 [[11](#ch9.xhtml#ref9_11), [12](#ch9.xhtml#ref9_12), [15](#ch9.xhtml#ref9_15)]。

除了潜在的安全顾虑外，联邦学习还有若干约束，使其无法成为解决我们所有数据隐私问题的灵丹妙荐。值得注意的是，联邦学习训练模型所需的本地设备算力和内存比传统机器学习技术多得多。然而，许多现代设备性能足以胜任这些任务，且该策略还能大幅减少传输到中心服务器的数据量，从而降低数据使用量。如果设备电量充足，这种权衡对许多用户而言可能是有利的 [[11](#ch9.xhtml#ref9_11)]。

另一个技术难题是带宽。与在数据中心进行的标准机器学习不同，联邦学习通过 WiFi 或 4G 网络进行。这些节点间繁忙节点与服务器使用的带宽速率比 WiFi 或 4G 低几个数量级。随着时间的推移，设备带宽的增长速度远不如设备算力；因此，带宽限制可能导致延迟增加，且学习过程比传统方法更漫长。如果在设备运行时进行算法训练，会降低设备性能。Google 找到了解决方案：仅在设备开启、插电且闲置时进行训练。这解决了问题，但由于训练只能在非高峰时段进行，导致学习过程变慢 [[12](#ch9.xhtml#ref9_12)]。

设备在训练过程中掉线是另一个问题；设备可能被用户使用、关机或遭遇其他干扰。无法使用掉线设备的数据可能导致算法模型精度下降。从联邦学习的构想到落地的过渡并非一帆风顺。包括独立于联邦学习倡导者之外的研究人员在内，都帮助加深了对相关挑战的认识 [[8](#ch9.xhtml#ref9_8), [11](#ch9.xhtml#ref9_11)]。

虽然已有研究探讨联邦学习的有效性和准确性，但在我看来，以下列出的安全相关难题更为迫切。

### 推理攻击

保护客户数据的机密性是联邦学习的驱动力。

### 模型投毒

一些学者研究了不守规矩的客户植入后门或发起女巫攻击以投毒全局模型的想法。

联邦学习是一种相对较新的训练方法，在多种用途上展现出前景。由于该技术仍处于研究的早期阶段，因此需要更多调查，目前无法评估其所有潜在应用，也无法评估其可能面临的所有信任和隐私威胁。在此之前，很难精准预测该策略在未来将被广泛采用的程度。好消息是，Google 的 Gboard 已在现实世界中成功应用 [[15](#ch9.xhtml#ref9_15)]。

尽管如此，鉴于前述一些缺点，联邦学习不太可能在所有情况下完全取代传统学习模式。未来也将取决于我们主要互联网巨头对保护隐私的重视程度。目前我们有充分理由保持怀疑。

## 联邦学习在医疗保健领域面临的挑战

尽管联邦学习有诸多优势，但必须记住，与传统机器学习技术一样，联邦学习仍面临偏见、标准化和数据质量等性能问题。此外，在医疗数据背景下，联邦学习还面临以下挑战 [[9](#ch9.xhtml#ref9_9), [11](#ch9.xhtml#ref9_11), [15](#ch9.xhtml#ref9_15)]：

*   **数据多样性** — 医疗数据本质上复杂且多样。既有结构化形式，也有非结构化形式。数据采集差异、医疗设备品牌和地区人口统计特征等因素也会影响数据的多样性。整合来自多个来源的数据和信息可能颇具挑战。数据在合作高校之间可能分布不均。
