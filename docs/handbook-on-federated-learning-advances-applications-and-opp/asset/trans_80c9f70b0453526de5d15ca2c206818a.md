关于 [表 3](#ch6.xhtml#tab6_3)，`REFDL` 节省的内存和处理时间分别显示在 [图 4](#ch6.xhtml#fig6_4) 和 [图 5](#ch6.xhtml#fig6_5) 中。结果表明，与每种训练方法相比，`REFDL` 在最大限度地减少资源（内存和时间）方面表现更好。结果显示，使用 `PySyft` 虚拟工作节点构造（模拟真实虚拟机并在同一 Python 脚本中独立运行）可提升 `REFDL` 的性能。具体而言，它展示了 `REFDL` 模型采用 4 个隐藏层 (`4L`) 和 2 个虚拟工作节点 (`2VW`) 可能呈现出较低内存消耗的潜在模型。它还表明，采用三隐藏层网络架构增加虚拟员工数量可实现内存节省。

我们在 `FL` 场景下使用 `FCNN` 和 `CNN` 集成，在 MNIST 图像数据集上评估了 `REFDL`，以证明其在网络安全领域之外的泛化能力和有效性（见 [表 4](#ch6.xhtml#tab6_4)）。通过评估其在与物联网无关的数据集上的性能，我们可以了解该方法是否可作为设备端学习的通用选择。特别是为了获得 `CNN` 在图像分类上超越人类专家的优势及其高效资源管理能力的收益。通过此分析，我们使用 `PySyft WS`（网络）模拟工作节点，比较了 `BFDL` 和 `REFDL` 在所有联邦训练场景下的功效。与作为同一 Python 程序内构造运行的 `PySyft` 虚拟工作节点不同，该方法通过模拟客户端和服务器驻留在同一机器上的网络来评估 `REFDL` 的性能。在所有 `DNN`（`CNN` 和 `FCNN`）变体中，`REFDL` 的准确率均优于 `BFDL`。由于 MNIST 数据集对训练和测试样本都具有相对平衡的分布，这可能是其取得卓越性能的原因。且完成一个训练会话所需的时间显著缩短。结果证明了正则化在处理 `DNN` 波动时保护准确率的重要性。这激励在实际场景中开展进一步研究。
