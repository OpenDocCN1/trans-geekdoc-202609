
卸载作业的选择依据是车辆的速度及其行驶方向。换句话说，朝同一方向行驶的车辆可以竞争卸载作业。例如，独立和协作的雾服务器均提供了移动性感知和基于位置的工作卸载技术[[28](#ch8.xhtml#ref8_28)]。通过高效利用可用的计算和通信资源，实现了任务的及时完成。该方法在选择资源时优先考虑设备移动性，而非队列状态。为了最大化V2V资源共享网络中的资源利用率，基于车辆的方向、位置、速度和队列状况，提出了上下文感知的机会主义卸载。作者[[29](#ch8.xhtml#ref8_29)]基于多臂老虎机理论和雾节点的卸载延迟，提供了一种自适应卸载方法。为了减轻边缘雾服务器的压力，解释了如何在FiWi使能的雾计算网络中利用博弈论方法实现负载均衡。集中式网络管理作为SDN的主要原则，是该补救措施的关键[[30](#ch8.xhtml#ref8_30)]。一种工作卸载方法以信息缺失博弈的形式提供，其中现有资源被汇集并共享。它使用贪婪剪枝算法进行资源选择，兼顾高效与环保[[31](#ch8.xhtml#ref8_31)]。进化方法也被用于优化资源池分配。值得注意的是，这些元启发式方法依赖于集中式网络管理，在分配资源时更强调设备特定因素。随着请求总数和排队请求数的增加，这些技术表现不佳。此外，基于AI的作业卸载可以分析大规模状态空间，并适应车辆周围的动态条件。例如，[[29](#ch8.xhtml#ref8_29)]中使用预测模型减少了程序执行的等待时间。通过采用集成学习，一组无人机可以高效计算高需求的计算作业。它们使用基于拍卖的机制将雾服务器分配给移动节点的查询[[32](#ch8.xhtml#ref8_32)]。该方法使用DNN模型来减少移动节点消耗的时间和功耗。另一篇类似的论文使用DNN来调度任务并将计算卸载到边缘[[33](#ch8.xhtml#ref8_33)]。综述表明，时间和能量得到了更好的分配。值得注意的是，在使用基于DNN方法的车辆环境中，有限的信息交换和巨大的状态空间对其决策能力产生了负面影响。

## 2.2 基于强化学习的卸载

近期工作提出了一种基于深度Q学习的智能作业卸载技术，对信息和网络数据吞吐量实行集中式控制。同样，一种基于深度Q网络的计算资源分配方法使Q学习摆脱了以往的局限[[34](#ch8.xhtml#ref8_34)]。通过考虑相关车辆的速度和计算能力，计算出一个高效的卸载决策模型。对于因大量策略探索和相关计算而导致状态空间庞大且收敛速度缓慢的情况，Q学习变得低效。得益于[[35](#ch8.xhtml#ref8_35)]中描述的服务卸载架构执行的在线学习，雾设备学习到了最优卸载策略。在“何时何地调度”范式的背景下，DRL被用于构建随机资源优化问题[[36](#ch8.xhtml#ref8_36)]。该模型接收代表任务队列状态的特征集，并使用DNN估算分配策略。类似研究的作者[[37](#ch8.xhtml#ref8_37)]提出了一种优先级感知的DRL方法，鼓励车辆汇聚其闲置处理能力。该方案指定了一种动态定价方法，由任务的相对重要性、节点移动性和资源可访问性决定。同样优化了一种基于DRL的卸载技术[[38](#ch8.xhtml#ref8_38)]，其中任务队列状态、移动性和任务依赖性都是联合目标函数的一部分。该方法通过在卸载任务时减少功耗和延迟来提高性能。深度强化学习专家研究了任务卸载范式[[39](#ch8.xhtml#ref8_39)]。在该研究中，作者使用基于SAC（软演员-评论家）的、无模型的深度强化学习版本，以最大化熵和期望效用。然而，由于任务分配决策学习的集中化，给定的工作高度集中。我们建议的方法涉及在车辆和基站分别学习两个不同的模型，这与先前工作仅专注于在基站学习这些任务卸载决策形成对比。由于环境的动态性和通信的缺乏，DRL方法通常无法在连续状态空间背景下提供令人满意的结果。这项工作非常适合分布式和联邦DRL，后者确保了丰富多样的训练环境，并加快了达到全局最优的过程。

## 3. 系统模型

利用一个车辆网络，其中一些在移动（用`V`表示），一些停放（用`P`表示），一些在雾中（用`F`表示），我们考察一个资源共享车辆环境（用`F`表示）。具有波动计算需求的作业的唯一来源是移动汽车本身；这些作业可以在本地处理或卸载到其他节点。

### 3.1 传输模型

无线信道的路径损耗`l`定义为：其中`d`是发射和接收设备之间的距离。

(1)

```
l = a + βlog[10](d) + b
```

其中`β`是路径衰减指数，`a`代表初始偏移量，`b`代表阴影衰落效应。因此，通信路径上的上界可以表示为

(2)

```
C = B log_2(1 + (P_t * l) / N_0)
```

其中`C`是可以在具有带宽的无线电信道上传输的最大数据率。`N[0]`是信道噪声，`Pt`是车辆节点的发射功率。重要的是要注意，我们假设无线信道是准静态且时不变的。这表明所有节点经历的信道状态是一致的，具有相等的发射功率和干扰。请记住，传输延迟是我们旨在最小化的总延迟的关键组成部分，它考虑了信道容量。我们的模型考虑距离、路径损耗，并适应传输延迟的新值，以自行学习哪些作业最适合卸载。

### 3.2 任务模型

各种车辆应用生成的任务具有相同的优先级，且彼此完全独立。每个传入作业`j ∈ j`有两个元组，其中`sj`代表任务大小（单位：MB），`cj`代表计算需求（单位：Mbits）。

### 3.3 排队模型

研究人员使用泊松过程来描述系统工作负载，到达率为`λ`，研究一个具有无限总体的多服务器先进先出排队模型。整个系统容量由公式`∀(V,F) = Σ_{i=0}^{T} K * (c * s_i)`表示，其中`K`是整个调用集群的大小，`c`是并行计算节点的数量，`si`是输入的数据量。对于给定的代理`i`，其驻留时间`Z[i]`可写为

(3)

```
Z_i = Σ_{x ∈ Q} (c_x / f_i)
```

其中，`fi`是时钟频率，`Σ[x ∈ Q]c[x]`是队列`Q`的队列长度。
