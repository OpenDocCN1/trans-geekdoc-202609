
Suhad 等人 [[1](#ch12.xhtml#ref12_1)] 建议主要集中在两个要素上，具体为神经影像学和生物标志物。图像分析是其主要研究领域。该工作未描述阿尔茨海默病（AD）最初是如何被发现的，因为选定用于调查的大多数受试者已知患有 AD。在此过程中，回顾了重要的 AD 数据集，以及诊断方法和检测策略。尽管该方法可用于早期神经影像学研究，但结果并不充分。CFS 在阿尔茨海默病识别中的重要性也得到了证明 [[12](#ch12.xhtml#ref12_12)]。可用于诊断阿尔茨海默病的几个标志物包括 MSE、CDR 和 NWB 体积。该过程的 DT 算法产生的结果准确率很差，低于 80%，而 XG Boost 算法只能达到略高的 80% 准确率。SVM 或 RF 分类器均未达到超过 81% 所需的准确率。已对诊断进展为阿尔茨海默病的痴呆的方法进行了考察 [[5](#ch12.xhtml#ref12_5)]。在利用机器学习、物联网、人工智能等各种方法学进行 AD 早期诊断的近期工作中，也考察了各种分析和评估策略。

一种利用模型依赖先验知识进行优化的深度学习方法也被提出 [[9](#ch12.xhtml#ref12_9)]。它同时进行了 DR 和 DF。此外，它展示了当应用于小样本量患者病历时，如何利用多层学习模型和超参数提取更多 CSF。另一种与无监督 ML 相关的技术被提出 [[14](#ch12.xhtml#ref12_14)]。他利用结构化 MRI 图像数据预测阿尔茨海默病的进展，并表明其结果与有监督 ML 技术不相上下。

## 2.2 图像分割

Shrikant 等人 [[2](#ch12.xhtml#ref12_2)] 的实现中使用了图像分割。其中的放大程度有助于将个体归入该模型定义的四个类别之一：MD、MOD、VMD 和 ND。本质上，他们将患者分为这四组。采用分水岭算法根据图像梯度识别脑萎缩，以确定脑萎缩中是否存在空腔。该过程方法简单，完成所需时间极少。该方法的优势在于，它在解决先前检测问题的同时避免了脑损伤。JRip、朴素贝叶斯方法和 RF 被用于 [[13](#ch12.xhtml#ref12_13)] 对数据的各种输入图像进行分类。使用 Weka 软件应用程序分析数据。然后，使用浏览器、知识流和 API 对图像数据进行分类。比较结果后确定，JRip 和 RF 算法优于朴素贝叶斯算法。

## 2.3 特征提取

在来自 OASIS 的 MRI 图像数据中，[[3](#ch12.xhtml#ref12_3)] 采用了灰质和白质切片的三个不同视角。每个切片都包含提取的一阶特征。然后，使用检索到的特征生成相关性热图。随后，使用主成分分析方法降低维度。然后，使用包括回归（逻辑）、SVM、AdaBoost 和朴素贝叶斯在内的各种机器学习算法，检查了其建议技术的性能和准确性。测试结果显示最高准确率为 90.9%，优于之前 ML 算法的发现。从脑电图信号中检索的数学统计以多种方式和各种特征被使用 [[6](#ch12.xhtml#ref12_6)]，包括均值、中位数、众数、极差、标准差等。测量揭示了多种异常。利用适当的特征提取工具，提取了各种特征。

## 2.4 迁移学习方法

所采用的预训练 VGG16 模型 [[4](#ch12.xhtml#ref12_4)] 是 TensorFlow 和 Keras 迁移学习网络的组成部分。它被用作从中提取特征的工具。使用性能指标，他们确定了模型的准确性。将数据分为 20% 测试数据和 80% 训练数据的算法具有最高准确率，测试准确率为 95.31%，训练准确率为 97.49%。

## 2.5 神经网络和深度学习技术

通过利用具有 DL 架构的卷积神经网络，[[7](#ch12.xhtml#ref12_7)] 能够以 96.86% 的准确率识别阿尔茨海默病（LeNet）。同时，使用大量照片进行数据测试和训练。他们所达到的准确程度非常高，结论是：为检测阿尔茨海默病而选择的网络设计是合适的。

一种基于神经影像学利用 DL 技术进行 AD 识别的方法被提出 [[8](#ch12.xhtml#ref12_8)]。在 CNN 之后，他采用了 RNN。因此，他能够更好地理解每个类别视觉序列之间的联系。然后，基于所有输入图像做出最终决定。他缺乏足够的数据来训练 NN。Chenhui 等人 [[10](#ch12.xhtml#ref12_10)] 表明，DL 对理解 MRI 图像数据与生理意义之间的联系持有多种看法。脑区相关性输入为 DL 技术自编码器提供了更高程度的表示。并以显著更好的预测准确率实现了这一点。MRI 图像中诊断检测的重要性得到了证明 [[11](#ch12.xhtml#ref12_11)]。尽管如此，精度仍不足够。不同的脑部扫描神经图像需要统计学上全面的数据集作为输入 [[15](#ch12.xhtml#ref12_15)]，展示了深度学习（DL）建模技术的增长。正电子发射断层扫描（PET）和磁共振成像（MRI）均为有效的视觉模态，可显示阿尔茨海默病（AD）进展过程中发生的大脑变化。利用结构 MRI 创建 3D 深度卷积神经网络 [[16](#ch12.xhtml#ref12_16)]，成功区分了轻度阿尔茨海默病痴呆、轻度认知障碍和认知正常人群。深度学习模型能够以 85.12% 的曲线下面积（AUC）区分 MCI 或轻度阿尔茨海默病受试者与认知正常受试者。

## 2.6 联邦学习

创建学习信息和资源存储库联邦是随后多项计划的重点 [[24](#ch12.xhtml#ref12_24)、[25](#ch12.xhtml#ref12_25) 和 [26](#ch12.xhtml#ref12_26)]。Rehak 等人 [[26](#ch12.xhtml#ref12_26)] 2005 年的参考模型描述了如何将存储库联邦化以构建可互操作的存储库基础设施。在此架构下，贡献存储库的元数据被收集到中央注册表中，提供单一访问和发现点。在基于提供者的软件（如利用数字患者病历开发估算医院再入院风险的模型 [[27](#ch12.xhtml#ref12_27)]）和基于患者（消费者）的软件（如利用智能手表收集的心电图检测心房颤动的存在 [[28](#ch12.xhtml#ref12_28)]）的联邦学习过程中，敏感临床数据可保留在本地组织或特定消费者处，而不离开它们。通过这种策略，患者隐私得到良好保护。
