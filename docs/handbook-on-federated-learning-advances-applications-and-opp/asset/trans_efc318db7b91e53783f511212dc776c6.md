
Actor-Critic网络是策略梯度实现的一个示例，该方法通过随时间逐步优化参数来优化策略。经典Q-learning和深度Q网络（DQN）都根据当前状态选择最优的下一步，但它们的实现方式截然不同。最优策略，即从状态到动作的映射，可以通过策略梯度直接学习。Actor是真正对策略采取行动的一方，而Critic提供反馈以帮助Actor做出更好的选择。当累积回报 `R-t` 从基线函数中移除时，方差或优势减小为 `R[t]` – `b[t](s[t])`。典型的基准是学习价值估计（`Vπ(st)`）。

在多智能体深度强化学习场景中，`N` 个智能体在车辆生态系统中协作。这创建了一个简单的马尔可夫决策过程（MDP），其中 `s,a,r.s′` 等元组代表智能体。变量 `s` 表示智能体的当前状态，变量 `a` 表示智能体选择的动作，变量 `r` 表示动作的奖励，变量 `s` 表示智能体的预期状态。假设在时间 `t`，`N` 个智能体从环境中获取线索并自主行动，以转移概率 `p` 获得奖励并转移到新状态。智能体的目标是发现一个从状态到动作的映射 `π(s) → a`，以最大化预期折扣未来奖励 `V^π(s[t]) = E(R[t]|(s[t], a[i]))`。其中，`Rt` 是折扣累积未来回报，计算公式为 $R\_{t} = \sum\limits\_{k = 0}^{\infty}\gamma^{k}r\_{t + 1}$，折扣因子 `γ` ∈ (0, 1)。

在模型训练期间，A3C方法利用众多并发线程，每个线程都受益于独特且改进的学习体验。在此，许多智能体正在并行探索移动车辆状态空间的不同区域。来自许多异步交互的无关更新允许对状态空间进行更快、更彻底的探测。通过从估计价值函数 `Vπ (s[t])` 中减去成功的奖励函数，该方法在时间瞬间 `t` 得到一个优势函数，其中 `s` 是时间瞬间。

(11)

`A(s[t], a[i]; θ, w) = r[t] + γ*V(s[t + 1]; w) − V(s[t]; w)`

优势函数表示一个动作相对于其他可能动作的盈利能力。使用该公式，Actor网络进行自我更新，

(12)

```
dθ← dθ + ∇_{θ'}logπ_{θ'}(a_{i} | s_{t};θ')A(s_{t},a_{i};θ',w')
+ β∇_{θ'}H(π(s_{t};θ'))
```

其中，策略选项不确定性的度量是熵参数。熵的增加表明智能体的行为变得更加混乱和不可预测。如果没有熵项，智能体将收敛于次优行为，更多地权衡导致最高奖励的动作。而正则化项通过调整熵强度来平衡利用与探索，后者由开发参数 `β` 控制。该方程也用于更新Critic模型。

(13)

```
dw← dw + 2A(s_{t},a_{k};w,w_{c})∇_{w}A(s_{t},a_{k};θ',w_{c})
dw← dw + \frac{\partial A{(s_{t},a_{k};θ',w')}^{2}}{\partial w'}
```

此处，Critic更新会监控优势函数，以确保预期奖励与期望奖励之间的差异保持在最小。

### 4.5 系统消耗问题

当智能体产生工作时，可能将其放入本地队列或发送给邻居节点。选择卸载还是本地入队的函数很复杂。优化决策可以更好地利用可用计算资源，减少在建筑物中花费的总时间。多智能体系统旨在深度强化学习的目标之一是以这样一种方式减少未来的价值，使得

(14)

```
P1: minimizeV^{π}(s = s_{t}) = Σ_{i = 0}^{T}E(R_{t} | (s_{t},a_{i}))
badhbox Σw_{j} ≤ W,j ∈ E
```

(15)

`C3 : A(s[t′]a[i′]θ, w) ≈ 0; ∀T s.t π^*(s) = a^*`

如前所述，从状态 `s-t` 开始遵循策略的预期回报由公式(14)给出。它与忠实描述排队任务经过时间的估计值一致。通过减小该价值估计，我们可以减少任务在队列中花费的时间，这是最终目标。包含本地和卸载动作的决策元组 `C1` 用符号 `a-i.=0,1` 表示。为了减少驻留时间，智能体倾向于有助于目标函数的卸载操作。由于缺乏上下文，智能体最初更倾向于探索并表现得反复无常。随着智能体获得经验并接近目标，其动作变得越来越预定。工作负载 `w` 必须小于或等于 `C2`，其中 `C2` 是总容量 `W`。累积奖励和近似价值函数之间只有很小的差距，这由 `C3` 优势函数所示。为了实现这一目标，智能体应用学习到的权重 `θ` 和 `w` 来寻找最优策略 `π*`，从而得出最优动作 `a*`。

由于车辆中交换信息的机会较少，为活动选择最佳卸载策略可能很困难，导致等待时间变长和收敛变慢。然而，正如[[39]](#ch8.xhtml#ref8_39)所述，通过在多层学习架构的上下层之间简单地交换梯度，联邦学习使这成为可能。系统现在可以更快、更可靠地扩展。我们对A3C算法做了同样的事情，它使用并行仿真来提高性能。可以在更短的时间内探索更多的状态空间，从而做出更好的决策。

## 5. 面向计算卸载的联邦学习架构

本研究提出了一种基于多智能体DRL的联邦任务卸载框架。该方法建立了一个多层框架，其中区域模型和全局模型通信协作，以确定何时何地委派工作。如前所述，每个车辆智能体通过与环境交互来学习局部模型，从而捕捉车辆环境的潜在动态。此外，得益于存储在边缘设备上的中心化全局模型发送的数据，智能体的局部模型定期更新。如前所述，车辆节点负责学习和存储模型。联邦学习通过允许车辆在单个节点上本地训练来减少网络延迟。训练在车辆节点上进行，仅在资源共享环境中传输最必要的数据，这两者都提高了隐私性。由于网络之间仅通信梯度，车辆隐私得到保护，且训练好的模型对数据变化更具鲁棒性。由于共享的信息更少，训练好的模型更稳定，数据被篡改的可能性也更小。
