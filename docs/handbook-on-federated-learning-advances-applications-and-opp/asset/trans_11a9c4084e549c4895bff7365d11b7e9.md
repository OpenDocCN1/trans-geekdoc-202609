
# 物联网创新与联邦学习集成

## 概述

物联网创新在消费市场中最为人所知的是与“智能家居”概念相关的产品，包括支持至少一种典型生活方式并可通过电话及其他连接到该框架作为遥控器的设备（如音箱和手机）进行控制的家用电器和小工具。我们在该项目中使用物联网，以快速评估可能出现的风险，并使其保持在安全距离之外。物联网有助于为客户简化一些事务。有了这个选项，它为我们提供了在必要时扩展系统的能力，使其更加可靠和高效。

火灾是一种威胁生命和财产的可怕场景，且蔓延迅速。每年，火灾伤亡导致数千个家庭和生命的损失。通过预防火灾发生并提前采取必要的防护措施，可以节省大量资金。在发达国家，家庭配备了安全设施。然而，在发展中或欠发达地区，模型规模巨大，需要一种解决方案。

## 隐私保护联邦学习框架

更具体地说，客户端使用部署的特征提取器在移动端提取其数据的特征，并在第一阶段通过添加具有形式化隐私保证的噪声来扰动恢复的特征。客户在 `MEC` 服务器上使用扰动后的特征训练全连接模型层，作为第二阶段。此外，我们通过移除均值和方差要求并施加一个界限（其中 `N` 指定批次大小）来增强传统的批量归一化。客户在训练后通过使用其私钥对加密模型的哈希值进行签名，将本地训练的模型传输到区块链。为了获得全局模型，选定的矿工下载模型，验证发送者身份，然后对所有模型参数进行平均 [[34](#ch13.xhtml#ref13_34)]。全局模型由一名被选为临时领导者的矿工加密并上传到区块链。此外，我们采用基于声誉的众包激励机制，奖励可信客户并惩罚不诚实客户，以鼓励更多用户参与众包工作，防止有害和恶意更新。

物联网管理的核心是信息共享，旨在通过共享安排发送信息，以造福特定应用中的最终用户。为了实现具有低延迟和隐私保护的智能物联网系统，联邦学习提供了共享学习结果作为共享原始物联网数据的替代方案。该工作为工业物联网应用提供了一种协作信息共享方法，实现了数据所有者和数据请求者之间去中心化多方的快速安全数据流。构建了一个联邦学习方案，以支持对请求者提出的查询所涉及的数据共享需求类型进行估算，从而为这些查询返回准确计算的结果，这种共享通常是由于酒店中物联网用户的资源限制而进行的。此外，将区块链与联邦学习架构相结合，形成由所有各方拥有的不可变数据块，以实现透明度，并在不需要中央权威的情况下增强数据所有权。这保护了共享过程免受外部威胁。一旦数据存储在区块链中就无法篡改或覆盖，这降低了数据泄露的可能性，从而提高了网络安全性。仿真结果利用实时数据集验证了所提议的基于联邦学习的共享框架的便利性，具有最高的学习准确性和增强的安全性。根据这方面的讨论，作者基于联邦学习思想创建了一个工业物联网统一张量挖掘系统，以整合多源数据并实现具有安全保证的基于张量的挖掘。具体而言，工厂通过与中央服务器共享其使用同态加密策略加密的数据来协作参与张量挖掘。这样，原始数据保留在本地工厂，确保了张量挖掘的数据隐私，而服务器仅聚合密文数据并将其联邦化为张量。即使攻击者可以在通信窃听信道上的密文，窃听者也可以伏击中央服务器以窃取聚合的密文，他们也无法获得数据解密的密钥。与隐私保护压缩感知策略相比，所提出的联合方法可将挖掘精度提高 24%，并通过利用北京和上海的两个工业碰撞（每个工厂拥有 100 多个物联网节点）进行仿真，提供了高安全性。该攻击定位有效且准确，且不影响性能 [[36](#ch13.xhtml#ref13_36)]。车载系统中的分布式信息共享已利用联邦学习实现。根据该研究，提出了一种非同步联合信息共享系统，其中每辆车作为联邦学习客户端，与大规模基站处的聚合服务器共同共享信息。
