
# Machine Learning Phases

Machine learning (ML) can be accomplished in two phases: (a) the training phase, and (b) the prediction phase, as shown in [Fig. 1](#ch1.xhtml#fig1_1).

## Training Phase

In the training phase, input data vectors are fed into the ML model, and the model learns by incrementally updating the function that maps the input vectors to output class labels. The learning in the ML model can be classified into four classes:

1.  **Supervised learning**: Tries to figure out a mapping function between the input data vectors and the known class labels or anticipated output values. The mapping function is then subjected to new input data vectors to determine the class label.
2.  **Unsupervised learning**: The class labels or anticipated output values are not known in advance. The mapping function tries to identify similarity and dissimilarity among the input data vectors and groups them using similarity measures.
3.  **Semi-supervised learning**: The majority of input data vectors in the dataset are unlabeled, with the remaining minority possessing class labels. Class labels for the majority are deduced using clustering algorithms.
4.  **Reinforcement learning**: Choice of actions and the reward returned over a period that leads to goals or fulfills objectives forms the basis for formulating the reward (or mapping) function.

## Prediction Phase

In the prediction phase, the output of the training phase—called the trained model—is put to exercise. The trained model admits input data vectors whose class label is yet to be determined and produces the output known as the prediction (or class label). Accuracy in the prediction determines the efficiency of the machine learning algorithms.

## 2.1.1 Formal Definition of Machine Learning

The function mapping `F` with input `X(x[1], x[2]…, x[n])`, output `Y(y[1], y[2], …, y[n])`, and `w[L]` being the learning parameter, expresses the gap between the prediction and the desired value in Equation (1).

(1)

```
\arg\min_{w_L} Loss(X, Y, w_L) = \| F_{w_L}(X) - Y \|
```

where `Loss` is the loss function at points `X` and `Y`. The objective is to minimize the loss between the prediction and desired values; this forms the basis for all machine learning algorithms.

## 2.1.2 Classes of Machine Learning Algorithms

Machine learning can be broadly classified into five different classes:

### Matrix Factorization Algorithms

Data elements presented in the form of matrices may have concealed factors or missing elements, identified by factorization. Applications include recommender systems using a "User item rating matrix" and "Drug target protein matrix" to determine user preferences via item ratings [[33]](#ch1.xhtml#ref1_33) and innovative drug discovery [[34]](#ch1.xhtml#ref1_34), respectively.

### Topic Models or Statistical Models

*   **Latent Dirichlet Allocation (LDA)**: A statistical method producing a mapping between unstructured text documents and a topic set with probabilistic values [[35]](#ch1.xhtml#ref1_35).
*   **Naïve Bayes Classifier**: A probabilistic approach using supervised learning for training, though with lower accuracy compared to complex approaches.
*   **Latent Semantic Analysis/Indexing (LSA/LSI)**: Constructs matrix-based mapping between topics and text documents to classify documents, assuming Gaussian distribution for inputs.
*   **Probabilistic Latent Semantic Analysis/Indexing (PLSA/PLSI)**: Adopts Poisson distribution for inputs such as topics and text documents [[36]](#ch1.xhtml#ref1_36).

### Rule-Based Machine Learning (RBML) Algorithms

`RBML` algorithms construct `If <condition> Then` rules for the given input dataset, with each rule appropriating a portion of the problem [[37]](#ch1.xhtml#ref1_37). Rules are simple and easy to interpret compared to neural network models. Typical examples include **Decision Trees** and **Association Rule Learning**.

*   **Association Rule Learning**: Builds rules by identifying associations between items or variables.
*   **Decision Trees**: Follow a hierarchical representation of rules with branches guiding to a leaf denoting the decision or class label.

### Stochastic Gradient Descent (SGD) Based Algorithms

The loss function is a minimization multi-variable objective function moving toward the optimal point guided by the negative gradient (the first-order partial derivative of the loss function). The negative gradient adjusts model parameters along its direction. Movement toward the optimal point is governed by the learning rate. Since the gradient is computed over randomly selected input data vectors, it is called a stochastic gradient. This iterative approach finds the minimal point for the loss function.

`SGD` is used in popular ML models like **Support Vector Machines (SVMs)**, **Perceptrons** [[38]](#ch1.xhtml#ref1_38), and **Artificial Neural Networks (ANNs)**.

*   **SVMs**: Input data is mapped to n-dimensional space; an n-1 dimensional hyperplane separating two sets of data points by a larger distance is used for classification.
*   **Perceptrons**: Perform binary classification. Inputs are weighted; the sum of weight-input products is compared with thresholds to determine the class label.
*   **ANNs**: Multiple layers of neurons form a network connected to recognize complex features in large data. Layers are connected by weighted edges, with activation functions introducing non-linearities. Examples include **Generative Adversarial Networks (GANs)**, **Convolutional Neural Networks (CNNs)**, **Deep Neural Networks (DNNs)**, and **Recurrent Neural Networks (RNNs)**.

### Evolutionary Algorithms

The **Genetic Algorithm** is designed based on human evolution [[39]](#ch1.xhtml#ref1_39). It represents a decision variable as a genotype (string of ones and zeros). Every genotype is evaluated using a fitness function; those satisfying it undergo crossover and mutation to produce new genotypes. New genotypes are quality-tested via the fitness function. Only better genotypes are retained for reproduction. The process is iterative with a slow convergence rate.

# 2.2 Distributed Machine Learning

Training over larger datasets on a single machine increases the runtime of ML algorithms. Complex applications of terabyte scale may need a higher degree of parallelism and larger I/O bandwidth in distributed systems [[40]](#ch1.xhtml#ref1_40). Parallelism can be conceived at the data level (creating disjoint data fragments) or at the model level (identical dataset copies trained by different model portions). Compute node topology is important when implementing data and model-level parallelism. Parallel execution and inter-compute node communication must work in tandem for faster model convergence with faster updates.
