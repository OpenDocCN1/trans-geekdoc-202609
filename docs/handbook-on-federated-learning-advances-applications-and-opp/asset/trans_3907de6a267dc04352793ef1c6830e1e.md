
迄今为止提到的所有研究均采用了传统机器学习技术，其中数据存储和模型训练由单台计算机或服务器管理。因此，在训练之前，所有数据必须汇集到一个位置。传统机器学习算法[[17]](#ch12.xhtml#ref12_17)要求模型从大量样本中进行训练，但由于隐私顾虑，获取这些样本可能颇具挑战。在联邦学习（FL）环境中，在将获得的权重发送至主服务器进行聚合之前，每个模型都在本地硬件上独立训练。因此，仅将模型属性（如权重、梯度、参数等）传输至中央服务器。文献[[21]](#ch12.xhtml#ref12_21)重点强调了必须解决的障碍，并展示了联邦学习如何解决医学数据集收集的问题。因此，模型根据训练数据所用的总时间进行聚合，给定的策略是根据性能选择表现最好的模型。在他们的研究中，他们使用了一个略经改进的联邦学习模型，从医学影像数据中更准确地识别COVID-19。

## 3. 建议方法

该模型通过联邦学习利用深度学习方法来分析和预测结果。该模型采用随机森林（RF）和K近邻（KNN）等机器学习方法，以及卷积神经网络（CNN）架构等深度学习算法，并将我们建议的模型与当前的模型和分类器进行比较。模型首先将使用两组图像作为输入：训练数据集和测试/验证数据集，经过各种处理流程后，将其分为两组。完成此过程后，我们将定义我们自己的纯CNN架构，其中将包含各种层类型，包括二维卷积层、Dropout层、激活层、展平层、线性整流单元层和Softmax层。

在该建议方法中，应用联邦学习方法在保护数据隐私的同时识别阿尔茨海默病。首先，利用CNN架构和迁移学习构建了一个能够精确识别阿尔茨海默病的深度学习模型。随后，使用CNN模型生成了一个用于阿尔茨海默病检测和分类的联邦学习框架。建议模型的贡献在于表明，在联邦框架中应用复杂算法不会显著恶化结果。因此，利用联邦学习技术，即使存在数据采集隐私顾虑，我们也能在治疗领域轻松创建可靠的分类器。

### 3.2 数据集

阿尔茨海默病数据集包含6,400张MRI图像，分为四组，对应患者所患的四种阿尔茨海默病类型。MRI图像中的个体年龄范围为45至85岁。各类别图像如下：

*   **轻度痴呆** – 该类别包含896张不同患者的MRI图像。
*   **中度痴呆** – 该类别仅包含64张不同患者的MRI图像。
*   **非痴呆** – 该类别包含3,200张不同患者的MRI图像。
*   **极轻度痴呆** – 该类别包含2,240张不同患者的MRI图像。

数据集经多渠道彻底检查，发现数据集中不存在同一患者的多张图像，也不存在患者的重复MRI扫描。数据按80%和20%分为两类。80%的图像可用于训练模型。最后20%的图像将用于测试和验证模型。[图 2](#ch12.xhtml#fig12_2)展示了数据集中阿尔茨海默病MRI图像多种变体的随机表示。

### 3.4 构建卷积神经网络

卷积神经网络属于人工神经网络中深度学习的一个子集。它由多个神经层组成，包括卷积层、池化层、Dropout层、全连接层、激活层、展平层、Softmax层、线性整流单元层等。它是最常用于图像分类和识别问题的网络。平移不变性、空间不变性人工神经网络（SI-ANN）或ConvNet是它的其他名称。多层感知机（MPL）是一种全连接网络，其中前一层的每个神经元都与后一层的每个神经元相连，它是多层感知机（CNN）架构的旧版本。这种全连接层使数据更容易过拟合。为了避免过拟合，作为神经网络更新版本的CNN融合了多种正则化方法。

该模型由多层神经网络组成，均适配于序贯模型中。序贯模型不允许多个输入和输出，这意味着模型的每一层在同一时间仅具有一个输出和一个输入。CNN架构的层包含多个超参数，有必要了解这些滤波器背后的含义。大小为`FxF`的滤波器应用于输入图像中存在的`C`个通道，因此`FxFxC`是将对输入尺寸`IxIxC`执行卷积并产生输出特征图`OxOxK`的体积。此处，`K`为滤波器的大小。

核卷积是一种技ique，其中包含数字的3×3小矩阵通过输入图像，并根据该小矩阵（也称为滤波器和核）对其进行变换。现在按顺序计算所有特征图的值。用`f`表示输入图像，用`h`表示核，结果矩阵的行和列索引分别标记为'm'和'n'。输出特征图将表示为`G[m, n]`，其中`G[m, n]`可表示如下。

(1)

```
G[m,n] = (f*h)[m,n] = ∑[j]∑[k]h[j,k]f[m−j,n−k]
```
