# 5.12 Serial Peripheral Interface with Raspberry Pi

Adafruit Occidentalis 0.2 or later is preconfigured with serial peripheral interface (SPI) support. For Raspbian, few configuration changes are required.
The I2C driver is pre-installed in Rasp Debian, but it is disabled by default. To enable it, comment out a line by putting “#” in front, e.g., “sudonano /etc/modprobe.d/raspi-black.conf” and then add a “#” to the third line (Figure 5.20).

+   1. Edit the file /etc/modules using the command “sudonano/etc/modprobe.d/raspi-black.conf” and add a “#” to “blacklist spi-bcm2808,” which will become “#blacklist spi-bcm2808.”
2. The SPI feature of Raspberry Pi is supported by a Python library, which carries out SPI communication with a Python program. To install it, install Git and then issue the following commands:
```
$ cd
$ sudo apt-get install python-dev
$ git clone git:https://github.com/doceme/py-spidev
$ cd py-spidev
$ sudo python setup.py install
```
3. Reboot the Pi, and it is ready for SPI.

# 5.13 Programming a Raspberry Pi

To program a Raspberry Pi, the pin mode can be defined in two methods, BCM and BOARD. BCM stands for Broadcom SOC channel, and BCM refers to the GPIO number (i.e., GPIO21, GPIO22, etc.). BOARD refers to the pin number of the Pi board.

Commands:
importRP.GPIO as X

# This is to access GPIO pins of Raspberry Pi as the name “X” indicated in the command.

import time
# Imports the Time library so that we can pause the script later on.

X.setmode(BCM)
# Pins are referred as GPIO numbers, as BCM mode is selected.

X.setwarnings(False)
# This command is not to print GPIO warning messages on the screen.
