# 4.2 Arduino IDE

The Arduino integrated development environment (IDE) is an open-source software, and it makes easy to write code and upload it to the board.

# 4.2.1 Steps to Install Arduino IDE and open the window

Step 1: Install Arduino IDE and open the window

To begin, install the Arduino IDE. Figure 4.4 shows the window of Arduino IDE.

Step 2: Choose the version of Arduino board

Arduino has many versions like UNO, MEGA, NANO, etc. Before starting the project, find out the suitable board by selecting the parameters according to the requirement. The most common board is the Arduino UNO. Choose the board and the serial port
