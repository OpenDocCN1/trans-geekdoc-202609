# 11.3 Home Appliance Control with Blynk App

The Blynk application can be used to create an interface to control home appliances for smart control over Internet of Things (IoT). The system comprises of a Raspberry Pi, a power supply, two relay boards (if two appliances need to be controlled), a transistor 2N2222 (as a switch), and a power supply. Connect the components as shown in Figure 11.7 and follow the steps mentioned in Section 11.2 to control two LEDs, as the same project will work to control two relays.
