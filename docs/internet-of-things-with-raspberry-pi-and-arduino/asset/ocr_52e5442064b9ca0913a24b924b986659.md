# ### 10.1 DHT11 Data Logger with ThingSpeak

The objective of this project is to capture the real-time data of DHT11 by Raspberry Pi and upload to the cloud. DHT11 is a temperature and humidity sensor. The process involves three parts: setting up Raspberry Pi, configuring Adafruit library, and connecting to ThingSpeak. The system is comprised of a Raspberry Pi, a power supply, an Arduino Uno, and a DHT11 sensor. Connect pin (Vcc) of DHT11 to +5V and ground, respectively. Connect pin (OUT) of DHT11 to GPIO17 of the Raspberry Pi (Figure 10.1).
