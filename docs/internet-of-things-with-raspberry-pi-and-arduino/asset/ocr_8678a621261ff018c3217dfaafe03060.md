# 8.4 Selection from Multiple Options

When the user needs to select from multiple options from the given set of values, the complexity of the project increases. For example, when multiple numbers of LEDs are interfaced with the Arduino board, the user needs to select an LED or LEDs to turn it on. The Tkinter library provides an interface for a widget Checkbutton(), which enables the selection process from the given options. The concept can be understood with a simple circuit of interfacing two LEDs with Arduino and Raspberry Pi using Pyfirmata. The system is comprised of a Raspberry Pi, an Arduino Uno, two LEDs, and a power supply. Arduino is connected to Raspberry Pi through USB. The anode terminals of LED1 and LED2 are connected to pin(6) and pin(7), respectively, through a 10-K resistor each, and cathode terminals of both LEDs are connected to ground (Figure 8.9).
