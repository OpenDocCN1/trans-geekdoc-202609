## 4.7 Play with LCD with Arduino

## 5 Basics of Raspberry Pi

### 5.1 Introduction to Raspberry Pi

Raspberry Pi is a low-cost mini-computer that can be connected to a computer monitor or TV. It is a device for exploring the computer computing with the help of a keyboard and mouse. A few optional parts can be connected with for better accessibility. It can be programmed in languages like Scratch and Python. The processor frequency ranges from 700 MHz to 1.4 GHz for the Pi 3 model B+. The onboard memory ranges from 256 MB to 1 GB RAM. Raspberry Pi 3+ has a 1.4 GHz 64-bit quad core ARM A53 processor. Figure 5.1a shows Raspberry Pi.

The first generation of Raspberry Pi 1 model “B-” was launched in February 2012. A Raspberry Pi Zero has a smaller size and reduced input/output (I/O) with general-purpose input/output (GPIO) capabilities, and was launched in November 2015. The Raspberry Pi Zero W, a version of the Zero with Wi-Fi and Bluetooth capabilities, was launched on February 28, 2014. The Raspberry Pi Zero WH was launched on January 12, 2018; it is a version of the Zero with pres- (pre-sold) headers. The Raspberry Pi 3 B+ was launched in 2016; it is a version of the Zero with Wi-Fi and Bluetooth. The Raspberry Pi 4 was launched in 2019; it is a version of the Zero with pre-sold headers.
