# 4.3 Basic Commands for Arduino

+   1. pinMode(x, OUTPUT); // assigned pin number x as output pin where x is number of digital pin
2. digitalWrite(x, HIGH); // turn ON the pin number x as HIGH ON where x is number of digital pin
3. pinMode(x, INPUT); // assigned pin number x as input pin where x is number of digital pin
4. digitalRead(digital Pin); // read the digital pin like 13 or 12 or 11 etc.
5. analogRead(analog pin); // read the analog pin like A0 or A1 or A2 etc.

# 4.4 LCD Commands

+   1. lcd.begin(1, 2); // initialize LCD 16*2 or 20*4
2. lcd.print(“RAJESH”); // print a string “RAJESH” on LCD
3. lcd.setCursor(x, y); // set the cursor of LCD at desired location where x is number of COLUMN and y
4. lcd.print(LPU); // print a LPU as integer on LCD
5. lcd.Clear(); // clear the contents of LCD
