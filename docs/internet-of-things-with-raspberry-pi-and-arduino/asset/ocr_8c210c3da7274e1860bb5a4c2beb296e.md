# 4.6.1 Sketch

```
int LED_CONTROL=4;
void setup()
{
  pinMode(LED_CONTROL, OUTPUT); // initialize pin 4 as output pin
}
void loop()
{
  digitalWrite(LED_CONTROL, HIGH); // Make pin 4 HIGH
  delay(1000); // 1000 mS delay
  digitalWrite(LED_CONTROL, LOW); // Make pin 4 HIGH
  delay(1000); // 1000 mS delay
}
```

# 4.7 Play with LCD with Arduino

The liquid crystal display (LCD) is a commonly used display module. A 16 × 2 LCD is used as a display device in the circuits. This module is preferred over seven segments because they have no limitation of displaying-special, and even custom, characters and are economical.
A 16 × 2 LCD can display 16 characters per row, and there are 2 rows. In this LCD, the 5 x 4 pixel matrix displays the two registers, namely, data register and command register. Figure 4.12 shows a 16 x 2 LCD.
A 20 x 4 LCD has 4 rows and can display 20 characters per row. A 5 x 4 pixel matrix is used to display characters. Pin description is the same as LCD (16 × 2). Figure 4.13 shows a 20 x 4 LCD (Table 4.5).
