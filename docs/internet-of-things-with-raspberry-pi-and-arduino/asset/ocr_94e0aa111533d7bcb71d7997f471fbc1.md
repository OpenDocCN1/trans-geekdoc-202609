# 7.2 Controlling Arduino with Python

"USB standard A" connector is used to connect Arduino with the Raspberry Pi. Now check for the USB address of Arduino by running "ls -l /dev/tty*". On my Raspberry Pi, it is listed as /dev/ttyUSB0 (Remember this value for later).

Import the Arduino and util classes from the Pyformata module to control an Arduino from a Python script on the Raspberry Pi. After this, create an object that was found in the previous step with the help of a USB address.

```
>>>import Arduino,
>>>board = Arduino('/dev/ttyUSB0')
```
