# 1.6 IoT 与 M2M

物联网（IoT）可以定义为多个物体通过传感器和数字连接相互通信并共享数据的系统。机器对机器（M2M）解决方案由机器之间的线性通信通道组成，使其能够循环工作。在这里，一台机器的操作会触发其他机器的活动。

# IoT 与 M2M 的区别

- 一少数专家将 M2M 定义为 IoT 的子集，而另一些人将物联网视为机器机器的演进版本。无论哪种，结论都是 IoT 的领域比 M2M 更广。

- 这两种技术都基于连接设备并使其协同工作的原理。虽然 M2M 依赖于如 Wi-Fi 等传统连接工具，但 IoT 具有更高的灵活性多样化的连接选项。

- M2M 解决方案的范围非常有限，局限于创建一个同步工作的机器网络。IoT 则创建了用于灵活响应和多级通信的 360° 解决方案。

- IoT 优于 M2M 的优势在于它能够增加设备之间的交互性。机器通过根据动作触发响应来运行。这是单向通信。而基于 IoT 的系统，通信流可以自由往来。

## 2.1 传感器分类

传感器分类如下：

- 1. 初级输入量
- 2. 转换原理
- 3. 技术与材料
- 4. 属性
- 5. 应用

传感器也可以根据不同的领域进行分类：

- 1. 基于应用的分类：根据需要实施的应用场景来选择传感器，例如工业过程控制、测量与自动化、汽车、消费电子产品、飞机和医疗产品。随着应用的变化，选择标准也会发生变化，因此需要考虑应用。
- 2. 基于电源或能量供应要求的分类：
  主动式传感器：主动式传感器是指需要电源来测量物理量的传感器，例如温度传感器、超声波传感器和光敏电阻（LDR）。
  被动式传感器：不需要电源的传感器称为被动式传感器，它们测量参数，例如辐射计、胶片摄影。
- 3. 基于传感器输出的分类：
  数字传感器：传感器的输出为二进制或数字形式，可以通过控制器或处理器直接处理。
  模拟传感器：传感器的输出为连续信号的形式。需要微控制器或处理器通过模数转换器来读取传感器。
- 4. 基于传感器类型的分类：有多种不同应用的传感器。可以根据传感器的类型进行分类。以下讨论了几种类型的传感器：

  **加速度计：** 加速度计基于名为“微机电传感器”的技术。它们可用于动态系统。

  **生物传感器：** 生物传感器基于电化学技术。它们可用于医疗设备、水质检测、食品检测等。

****图像传感器：** 这些是基于互金属氧化半导体（CMOS）技术开发的。它们广泛用于视频监控、生物识别和交通管理。

  **运动检测器：** 运动检测器基于红外、超声波和微波/雷达技术。它们用于安全目的。

- 5. 基于属性的分类：传感器还根据物理参数的属性进行分类。例如如下：

  **温度：** 热电偶、热敏电阻、热电阻 (RTDs)
  **流量：** 热质量、差压、电磁、位置位移等。
  **压力：** 光纤、线性可变差动器 (LVDT)、弹性液体压力计、真空、电子
  **液位传感器：** 超声波射频、雷达、热位移等。
  **接近与位移：** 电容式、LVDT、磁性、光电式、超声波
  **生物传感器：** 电化学、共振镜、表面等离子子共振
  **图像：** 电荷耦合器件、CMOS
  **气体与化学：** 半导体、电导式、红外、电化学
  **加速度：** 加速度计、陀螺仪

## 2.2 传感器的工作原理

每个传感器的工作原理都不同，因为它旨在测量特定的量。一些基本传感器的原理如下：

- 温度传感器：温度传感器测量环境温度并转换为电信号。温度计的原理是玻璃中汞的膨胀和收缩。随着温度的变化，汞按比例膨胀和收缩。

- 接触式传感器：需要物理接触待测温度对象的传感器。

- 非接触式传感器：不需要物理接触即可感测温度对象的传感器。这种类型使用声波来测量温度。

- 热电偶：热电偶由两根线组成，每个接头通过连接末端形成。

- 热电阻 (RTDs)：RTD 是一种会改变电阻电阻的热电阻。

- 热敏电阻：它是一种改变其电阻的热电阻。

- IR 传感器：IR 传感器发射并检测红外线。在市场上很容易获得，但它对环境噪声和光很敏感。

- 3. UV 传感器：UV 传感器测量入射辐射的强度或功率。这种电磁辐射的波长大于 X 射线但小于可见光。聚晶金石材料用于紫外线传感。它可以传输不同类型的能量，但只能接受一种类型的信号。使用电表读取输出信号并通过模数转换器处理到计算机。UV 传感器用于紫外水处理、光传感器、紫外光谱检测器等。

- 4. 触摸传感器：触摸传感器是一种变阻器，根据受触摸的位置改变其电阻。它由导电和部分导电物质组成，并用塑料壳绝缘。电流流量由于允许部分通过导电材料。触摸传感器是许多应用的廉成本解决方案，例如洗衣机、液位传感器和洗碗机。

- 5. 接近传感器：接近传感器可以在没有任何接触点的情况下检测物体是否存在。工作原理是传感器发射电磁波，当物体在波范围内时波会返回。通过场辐射的变化检测物体的存在。不同类型接近传感器的工作原理，如感应式、电容式、光电式、超声波和霍尔效应。

  感应式接近传感器：这种类型的传感器具有振荡器作为输入，通过导电介质的靠近改变损耗。对于金属检测使用这种类型的传感器。

  电容式接近传感器：这种类型的传感器通过改变电极位移来转换电容。可以通过将物体带入可变频率来实现。通过振荡频率帮助检测物体，该频率转换为直流电压。将此电流与固定值进行比较以检测物体。对于塑料目标使用这种类型的传感器。

- 6. 超声波传感器：超声波传感器用于检测物体的距离。工作原理是从物体反射后发射和接收之间的时间间隔。
