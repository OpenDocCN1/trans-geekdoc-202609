# 10.5.1 Configuring Raspberry Pi with Camera and Gmail

Step 1: Update and upgrade the Raspberry Pi with the latest packages by using following commands:

sudo apt-get update
sudo apt-get upgrade
or
sudo apt-get install python3 //for Python 3.0

Step 2: Install and configure an SMTP service.

sudo apt-get install smtp
sudo nano /etc/smtp/smtplib.conf

Step 3: Enable the permissions for SSH and camera in Raspberry Pi configuration.

Step 4: Allow “Gmail” SMTP access with standard authentication by the following steps:

+   1. Login to your Gmail account with username and password.
2. Go to “My Account” at the top-right corner.
3. Select the “Sign-in & security” section locate “Connected apps & sites.”
4. Turn “ON” the settings for “Allow less secure apps.”
