# Step 4: Connect Arduino with PC

Connect Arduino to the USB port of the PC with a USB cable. Every Arduino board has a different serial-port address (COM2, COM4, etc.), so it is required to reconfigure the port for each Arduino and select it in IDE. To check the port at which the Arduino is connected, right click on "PC" then select "manager"; a window will open. Double click on "Device Manager.\ A window as shown in Figure 4.7 will open. Click on ports COM and LPT and port at which device is connected can be found.

Now click on the "Tool" to get the Arduino port number, which is found in the device manager (select COM1 or COM2, etc). Figure 4.8 shows the "COM38" as the serial port of the board.
