# 前言

物联网提供了与树莓派的交互方式。本书的主要目标是为读者提供关于物联网的实用知识。通过本书，读者将学习如何使用传感器和执行器。

物联网是让物理设备连接到互联网并进行通信的技術。通过本书，读者将学习关于树莓派和 Arduino 的接口技术。

本书提供了关于物联网的输入输出设备的解决方案。它包含了 12 个章节。
