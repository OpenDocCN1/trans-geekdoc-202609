### 10.1 DHT11 Data Logger with ThingSpeak

The objective of this project is to capture the real-time data of DHT11 by Raspberry Pi and upload to the cloud. DHT11 is a temperature and humidity sensor. The process involves three parts: setting up Raspberry Pi, configuring Adafruit library, and connecting to ThingSpeak. The system is comprised of a Raspberry Pi, a power supply, an Arduino Uno, and a DHT11 sensor. Connect pin (Vcc) of DHT11 to +5V and ground, respectively. Connect pin (OUT) of DHT11 to GPIO17 of the Raspberry Pi (Figure 10.1).

# 10.1.3 Recipe

```python
import sys # import sys library
import RPi.GPIO as RA # import GPIO library
import time as wait # import time library
import urllib2 # import urllib library
my_API = 'F1MAEAF943TLMVCI!'

def sensordata():
    HUM, TEMP = RA.DHT.read(21)
    return str(HUM), TEMP

def getmain_function():
    base = 'https://api.thingspeak.com/update?api_key=%s ' % my_API
    while True:
        try:
            HUM, TEMP = sensordata()
            f = urllib2.urlopen(base + '&field1=%s&field2=%s' % (HUM, TEMP))
            print(f.read())
            f.close()
            wait.sleep(15)
        except:
            print('exit from program')
            break

if __name__ == '__main__':
    getmain_function()
```

# 10.2 Ultrasonic Sensor Data Logger with ThingSpeak

The ultrasonic sensor is designed to measure distance between the source and target using ultrasonic waves. HC-SR04 is a commonly module for distances from 2 to 400 cm. To measure distance, the time taken by sound between transmission and reception is calculated as Time/2. Distance = Speed * Time/2; here speed of sound at sea level = 343 m/s or 340 cm/s. To measure distance, the system is comprised of a Raspberry Pi, a power supply, and an ultrasonic sensor. Connect pin (Vcc) and pin (GND) of the ultrasonic sensor to +5V and ground, respectively. Connect pin(TRIG) and pin(ECHO) of the ultrasonic sensor to GPIO20 and GPIO(21) of the Raspberry Pi, respectively (Figure 10.6). Provide a “HIGH” signal to “TRIG” input, for at least 10-µS duration. This process will enable the module to transmit eight 40-KH ultrasonic waves. If any obstacle is in the way of the waves, these are reflected back to the “ECHO” pin.
