# Connections

- Connect camera to the dedicated port at Raspberry Pi.
- Connect pins (Vcc and ground) of the PIR sensor, BMP180 sensor, accelerometer, buzzer, and DHT11 sensor to +5 VDC and ground, respectively.
- Connect pin(OUT) of DHT11 sensor to pin(4) of Arduino Uno.
- Connect Arduino Uno to Raspberry Pi through a USB.
- Connect pin(OUT) of the PIR sensor to pin(2) of Arduino Uno.
- Connect pin(OUT) of the rain sensor to pin(A0) of Arduino Uno.
- Connect pin(OUT) of the buzzer to pin(5) of Arduino Uno.
- Connect pin(SCL) of BMP180 to pin(A5) of Arduino Uno.
- Connect pin(SDA) of BMP180 to pin(A4) of Arduino Uno.
- Connect "x axis" of accelerometer to pin (A1) of Arduino Uno.
- Connect "y axis" of accelerometer to pin (A2) of Arduino Uno.
- Connect "z axis" of accelerometer to pin (A3) of Arduino Uno.

# 10.5 Smart Motion Detector and Upload Image to gmail

A motion detector is a system where if motion is detected, then a picture is captured and communicated to a predefined Gmail address. The system is comprised of Raspberry Pi, a camera, PIR sensor, LED (indicator), and power supply. Connect the components as shown in Figure 10.18.

Connections:

- Connect the camera to the dedicated port at Raspberry Pi.
- Connect pins (Vcc and ground) of the PIR sensor to +5 VDC and ground, respectively.
- Connect pin(OUT) of the PIR sensor to GPIO21 of Raspberry Pi.
- Connect the cathode terminal of the LED to the ground, and anode terminal to GPIO3 through a resistor.

# 10.5.1 Configuring Raspberry Pi with Camera and Gmail

Step 1: Update and upgrade the Raspberry Pi with the latest packages using following commands:
```bash
sudo apt-get update
sudo apt-get upgrade
sudo apt-get install python3
```

Step 2: Install and configure SMTP service.
```bash
sudo apt-get install smtp
sudo nano /etc/smtp.conf
```

Step 3: Enable the permissions for SSH and camera in Raspberry Pi configuration.

Step 4: Allow "Gmail" SMTP access with following steps:
1. Login to your Gmail account with username and password.
2. Go to "My Account" at the top-right corner.
3. Select "Security" section.
4. Turn "ON" the settings for "Allow less apps."

def send_Mail(data):
    mail_RAJ.attach(MIMEText(body, 'plain'))
    print data # print data on terminal
    dat = "%s.jpg" % data
    print (data) # print data on terminal
    attachment_RAJ = open(dat, 'rb')
    image_RAJ = MIMEImage(attachment_RAJ.read())
    attachment_RAJ.close()

    mail_RAJ.attach(image_RAJ) # attach image
    server_RAJ = smtplib.SMTP('smtp.gmail.com', 587)
    server_RAJ.starttls()
    server_RAJ.login(from_addr, "ssss@gmail.com")
    text = mail_RAJ.as_string()
    server_RAJ.sendmail(from_addr, to_addr, text)
    server_RAJ.quit() # quit from server
