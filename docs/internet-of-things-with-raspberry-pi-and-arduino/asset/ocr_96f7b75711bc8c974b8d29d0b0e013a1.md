# 8.2.2.1 Tkinter GUI for LED Blinking with Variable Delay

Run the program described in Section 8.2.2 and a GUI will appear (Figure 8.5).
Write the required delay in the blank slot, for example, take value 5.
After pressing the “start to blink” button and delay of 5 sec on GUI, it will print "Pin7 connected is ON" for 5 sec and then print "Pin7 connected is OFF" (Figure 8.6).
