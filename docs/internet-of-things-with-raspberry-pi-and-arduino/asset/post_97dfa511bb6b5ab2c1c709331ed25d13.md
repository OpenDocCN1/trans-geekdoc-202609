## 4.1.3 Arduino Nano

The Arduino/Genu Nano has an onboard ATmega328 microcontroller. It has 8 analog inputs, 14 digital I/O ports, and 6 PWM. It has 32 KB flash memory, 1 KB EEPROM, 2 KB SRAM, and operates at 16 MHz of frequency. Figure 4.3 shows the Arduino Nano (Tables 4.3 and 4.4).

## 4.2 Arduino IDE

The Arduino integrated development environment (IDE) is an open-source software, and it makes easy to write code and upload it to the board.

### 4.2.1 Steps to Install Arduino IDE and open the window

**Step 1: Install Arduino IDE and open the window**
To begin, install the Arduino IDE. Figure 4.4 shows the window of Arduino IDE.

**Step 2: Choose version of Arduino board**
Arduino has many versions like UNO, MEGA, NANO, etc. Before starting the project, find out the suitable board according to the requirement. The most common board is the Arduino UNO. In the Arduino IDE, click on “Tool” and then on “Board.” Figure 4.5 shows the selection of Arduino board.

**Step 3: Write and compile the program**
Write the program in the Arduino IDE. Then “Upload” the program. Figure 4.6 shows the window to compile the program.

```cpp
void setup() {
  // put your setup code here, to run once;
}

void loop() {
  // put your main code here, to run repeatedly;
}
```

**Step 4: Connect Arduino with PC**
Connect Arduino to the USB port of the PC with a USB cable. Every Arduino board has different serial port (COM2, COM4, etc.), so it is required to reconfigure the port for each Arduino and select it in IDE. To check the port at which Arduino is connected, right click on "PC" then select "Manager"; a Device Manager window as shown in Figure 4.7 will open. Click on ports and find where the device is connected. Now click on "Tool" to get the Arduino port number, which is found in device manager (select COM1 or COM2). Figure 4.8 shows the "COM3" as the serial port of the board.

**Step 5: Upload program to Arduino board**
Upload the program to the Arduino board. Figure 4.9 shows how to upload the program.

## 4.3 Basic Commands for Arduino

- pinMode(x, OUTPUT); // assigned pin x as output pin where x is number of digital pin
- digitalWrite(x, HIGH); // turn ON the pin number x as HIGH where x is number of digital pin
- pinMode(x, INPUT); // assigned pin x as input pin where x is number of digital pin
- digitalRead(digital pin); // read the digital pin like 13 or 12 or 11 etc.
- analogRead(analog pin); // read the analog pin like A0 or A1 or A2 etc.

## 4.4 LCD Commands

- lcd.begin(1, 2); // initialize LCD 16*2 or 20*4
- lcd.print("RAJESH"); // print a string “RAJESH” on LCD
- lcd.setCursor(x, y); // set the cursor of LCD at desired location where x is number of COLUMN and y
- lcd.print(LPU); // print LPU as integer on LCD
- lcd.Clear(); // clear the contents of LCD

## 4.5 Serial Communication Commands

- Serial.begin(baud); // initialize serial communication to set baud rate to 600/1200/2400/4800/9600
- Serial.print("RAJESH"); // serial print fixed string with define baud rate on Tx line
- Serial.println("RAJESH"); // serial print fixed string with define baud rate on Tx line
- Serial.print(LPU); // print int string with define baud rate on Tx line
- Serial.Write(BYTE); // serial transfer one byte on Tx line
- Serial.read(); // read byte serial from Rx line
