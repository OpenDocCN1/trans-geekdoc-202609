## 5.23.4 Motion Detector and Capturing the Image

To understand the working of the camera, a simple circuit of capturing the image on detecting a motion is discussed here. An LED will glow on detection of motion, or a buzzer can be put in place of an LED. The system is comprised of a Raspberry Pi, a PIR motion sensor, Pi camera, an LED, and a power supply.

## Connections:

- Connect camera to Raspberry Pi as described in Section 5.23.
- Connect pin (Vcc) and pin (GND) of PIR sensor to +5 V and ground.
- Connect pin (OUT) of PIR sensor to GPIO21 of Raspberry Pi.
- Connect anode of LED to GPIO3 of Raspberry Pi through a 10 K resistor and cathode of LED to ground.

## 5.23.4.1 Recipe to Capture Image on Motion Detection

```python
import RPi.GPIO as GPIO
import time as wait
GPIO.setwarnings(False)
GPIO.setmode(GPIO.BCM)
GPIO.setup(3,GPIO.OUT) # assign pin3 as output
GPIO.setup(21,GPIO.IN) # connect Motion sensor on GPIO21
import picamera
with picamera.PiCamera() as RAJ_camera:
    RAJ_camera.resolution = (1024, 468)
    try:
        while 1:
            VAL=GPIO.input(21)
            if(VAL==1):
                print("object detected") # print on terminal
                GPIO.output(3,True) # make pin 3 to HIGH
                RAJ_camera.start_preview() # start camera preview
                RAJ_camera.start_recording('/home/pi/video.h264')
                wait.sleep(10) # delay of 1 sec
                RAJ_camera.stop_preview() # stop preview
                RAJ_camera.stop_recording()
                wait.sleep(1) # delay of 1 sec
            else:
                print("NO object") # print on terminal
                GPIO.output(3,False)# make pin 3 to LOW
                wait.sleep(1) # delay of 1 sec
    except KeyboardInterrupt:
        print("stop process")
GPIO.cleanup()
```

## Raspberry Pi and Arduino

### 6.1 Install Arduino IDE on Raspberry Pi

The limitation with Raspberry Pi is the absence of analog ports onboard, which makes it inappropriate for the systems where analog sensors need to be read. To overcome this limitation, the Arduino integrated development environment (IDE) can be installed on Raspberry Pi, as Arduino has analog ports so these ports can be used to interface analog sensors. Installing Arduino IDE on Raspberry Pi is an easy process with simple steps. The Arduino IDE is available for most of the operating systems, but here we will see how to install it on a Raspberry Pi3 model B with running Raspian Jessie in the graphical interface (GUI).

- The first requirement is an active internet connection.
- A screen, keyboard, and mouse need to be connected with Raspberry Pi.
- Install the latest version of Arduino IDE using apt:
  `sudo apt-get update & sudo apt-get upgrade`
  `sudo apt-get install arduino`
- Connect an Arduino board to the Raspberry Pi using the appropriate cable and pull the Raspian Menu and select Arduino IDE under the “Electronics” head. A blank window will open. Figure 6.1 shows the blank window for Arduino IDE.
- Click on Tools > Board > select the appropriate board of Arduino.
- To select the port of the Arduino that is connected, check the serial port under the “Tools” menu. The port name of Arduino is: /dev/ttyUSB0 or /dev/ttyACM0.

### 6.2.1 PIR Sensor

The photoelectric infrared (IR) sensor module is designed to detect motion. It is compact and easy to use. With a Fresnel lens and motion detection circuit, which has a wide range of voltages supplied with less current drain, it has high sensitivity and low noise. The output of the sensor is a transistor-transistor logic (TTL) active low signal. It detects motion by measuring the changes in infrared levels by objects in its surroundings. This module has a detection range of 6 meters and can be used in burglary alarms and control systems.
