# 1.3.2 IoT Protocols

# 1.3.2.1 OSI Model

The OSI (Open Systems Interconnection) model for IoT protocols, as shown in Figure 1.1, includes five layers: physical layer, link layer, internet layer, transport layer, and application layer.

The physical layer is comprised of devices, objects, and things. The link layer operates on protocols like IEEE 802.15.4, IEEE 802.11, IS/IEC 18092:2004, Bluetooth, ANT, NB-IoT, EC-GSM-IoT, uIP, EnOcean, and LTE-MTC. The internet layer protocols are 6LoWPAN, IPv6, and NanoIP. The transport layer protocols are CoAP, TCP, UDP, MQTT, XMPP, AMQP, LLAP, DDS, SOAP, and DTLS. The application protocols are JSON-ISO, REST API objects, and binary objects.

| Application layer | RES TAPI, JSON-ISO objects, Binary objects |
| Transport layer | CoAP, MQTT, XMPP, AMQP, LLAP, DDS, SOAP, UDP, DTLS |
| Internet layer | 6LoWPAN, IPv6, uIP, NanoIP |
| Link layer | IEEE 802.15.4, IEEE 802.11, ISO/IEC 8092:2004, NB-IoT, EC-GSM-IoT, Bluetooth, ANT, ISA100.11a, EnOcean, LTE-MTC |
| Physical layer | Devices, objects, things |
