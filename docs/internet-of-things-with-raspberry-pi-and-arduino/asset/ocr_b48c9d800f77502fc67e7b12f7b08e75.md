+   8. Now adding a loop to take five pictures:
```python
RAJ_camera.start_preview()
for i in range(5):
    wait.sleep(5)
RAJ_camera.capture('/home/pi/Desktop/image%s.jpg' % i)
RAJ_camera.stop_preview()
```

The variable “i” contains the current iteration number, from 0 to 4, so the images will be saved as image0.jpg, image1.jpg, and so on.
