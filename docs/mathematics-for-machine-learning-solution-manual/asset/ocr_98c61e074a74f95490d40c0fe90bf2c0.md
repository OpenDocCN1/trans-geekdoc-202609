# 2.8 Determine the inverses of the following matrices if possible:

a.

```
A = [[2, 3, 4], [3, 4, 5], [4, 5, 6]]
```

To determine the inverse of a matrix, we start with the augmented matrix [A | I] and transform it into [I | B], where B turns out to be A^{-1}:

```
[ 2 3 4 | 1 0 0 ]
[ 3 4 5 | 0 1 0 ]  -3/2 R1
[ 4 5 6 | 0 0 1 ]  -2 R1
```

```
~>
[ 2 3 4 | 1 0 0 ]
[ 0 -1/2 -1 | -3/2 1 0 ]  -1/2 R3
[ 0 -1 -2 | -2 0 1 ]  .(-1)
```

```
~>
[ 2 3 4 | 1 0 0 ]
[ 0 0 0 | -1/2 1 -1/2 ]
[ 0 1 2 | 2 0 -1 ]
```

Here, we see that this system of linear equations is not solvable. Therefore, the inverse does not exist.
