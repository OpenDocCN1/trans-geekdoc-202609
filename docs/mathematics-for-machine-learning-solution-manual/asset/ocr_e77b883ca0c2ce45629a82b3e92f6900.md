d.

Φ : ℝ³ → ℝ²

x ↦ [[1, 2, 3], [1, 4, 3]] x

We define the matrix as A. Let x and y be in ℝ³. Let λ be in ℝ. Then:

Φ(x + y) = A(x + y) = Ax + Ay = Φ(x) + Φ(y).

Similarly,

Φ(λx) = A(λx) = λAx = λΦ(x).

Therefore, this mapping is linear.

Φ : ℝ² → ℝ²

x ↦ [[cos(θ), sin(θ)], [-sin(θ), cos(θ)]] x

We define the (rotation) matrix as A. Then the reasoning is identical to the previous question. Therefore, this mapping is linear.
The mapping Φ represents a rotation of x by an angle θ. Rotations are also linear mappings.
