# Express Beta distribution as an exponential family distribution:

Recall the Beta distribution from Example 6.11

p(μ|α,β) = Γ(α + β) / [Γ(α)Γ(β)] μ^{α−1} (1 − μ)^{(β−1)}

= 1 / B(α,β) μ^{α−1} (1 − μ)^{(β−1)} .

This can be written in exponential family form

p(μ|α,β) = exp[ (α − 1) log μ + (β − 1) log(1 − μ) − log B(α,β) ] .

This can be identified as being in exponential family form by observing that

h(μ) = 1

θ|(α,β) = [α − 1   β − 1]ᵀ

φ(μ) = [log μ   log(1 − μ)]

A(θ) = log B(α + β) .

# Show the product of the Beta and Binomial distribution is also a member of exponential family:

We treat μ as random variable here, x as an known integer between 0 and N. For x = 0, …, N, we get

p(x|N,μ)p(μ|α,β) = C(N,x) μ^{x} (1 − μ)^{(N−x)} 1/B(α,β) μ^{α−1} (1 − μ)^{(β−1)}

= C(N,x) exp[ x log μ/(1−μ) + N log(1−μ) ] · exp[ (α−1) log μ + (β−1) log(1−μ) − log B(α,β) ]

= exp[ (x + α − 1) log μ + (N − x + β − 1) log(1 − μ) + log C(N,x) − log B(α,β) ] .

The last line can be identified as being in exponential family form by observing that

h(μ) = 1

θ = [x + α − 1   N − x + β − 1]ᵀ

φ(μ) = [log μ   log(1 − μ)]

A(θ) = log C(N,x) + log B(α + β) .
