# Shallow and deep learning

Within the three general types of ML discussed above, there are numerous algorithms, many carefully structured for specific problem types, and others more flexible and able to accommodate greater system complexity. Generally, the algorithms structured for specific tasks and therefore limited in flexibility are called “shallow” or hierarchical learning algorithms. More flexible ML algorithms are classified as deep or representation learning, and the main form of representation learning is the artificial neural network (ANN).

The main difference between shallow algorithms and ANNs is how they accommodate complexity (i.e., non-linearity) of relationships between features and model outputs.
