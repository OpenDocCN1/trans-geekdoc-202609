## 过程 LCA 的通用方法

标准的过程 LCA 包含四个主要组成部分：1）目标和范围界定，2）清单分析，3）影响评价，以及 4）解释和分析（ISO 2006a）。这些组成部分通常在构建 LCA 模型的过程中按顺序处理，并在整个过程中迭代细化（图 8.2）。

### 目标和范围界定

LCA 的第一步是制定一个明确定义的目标，指定所关注的系统、模型结果的预期用途以及预期受众。例如，牛肉 LCA 的目标可能是“量化牛肉的环境影响”以“识别流程中潜在改进领域”或“使消费者能够将牛肉的影响与其他食品的影响进行比较”（Cederberg et al. 2003；Dick et al. 2015）。然后定义 LCA 的范围以实现该目标。定义范围意味着设定要建模的系统的边界（例如，从原材料提取到消费者消费或处置），指定分析所需的详细程度，并选择功能单位。所需详细程度由所选单元过程的规模定义。在牛肉 LCA 中，高层单元过程包括肥料生产、作物和牧场种植、养牛和屠宰（图 8.3）。

定义功能单位是 LCA 中的关键步骤。功能单位是产品系统量化性能的参考单位（ISO 2006a）。适当定义的功能单位允许以公平的方式将一种产品的影响与其具有相同功能的其他产品进行比较。在牛肉 LCA 中，适当的功能单位可以是牛肉的千克数，或量化营养含量的单位，如卡路里或蛋白质；在这些情况下，牛肉 LCA 中的所有环境影响都将按每千克牛肉、每卡路里或每蛋白质报告。然后可以将报告的影响与对其他食品产品（如豆类或鸡肉）估计的环境影响进行比较。

### 清单分析

清单分析步骤，也称为生命周期清单（LCI），涉及识别所关注系统相关的所有输入（例如能源和资源）和输出（例如产生的产品和排放物）。然而，我们通常希望能够以比整个所关注系统更精细的分辨率量化环境影响，因此在所关注系统内的每个单元过程中识别或估计输入和输出。对于玉米生产单元过程，输入可能包括种子、水、肥料、机械和能源。输出包括玉米产品，还可能包括肥料的养分流失，以及为农业设备提供动力的燃料燃烧排放。对每个单元过程的所有输入和输出进行清单是一项巨大的工作。幸运的是，对于 LCA 从业者来说，已经做了大量工作来建立常见单元过程及其相关输入和输出的数据库。然而，LCA 从业者在确定某个特定 LCA 中使用是否合适时，应考虑过程数据集的范围和年代，以及为其开发的位置。有关 LCA 工具和资源的更多信息，请参阅 **Tools and Data Sources for LCA** 部分。

### 影响评价

也称为生命周期影响评价（LCIA），影响评价步骤将清单数据转换为有意义的环境影响。LCIA 用于提高对 LCI 中识别的输出流环境意义的理解。LCA 中典型的环境影响类别包括全球变暖、酸化、富营养化、臭氧层破坏、烟雾形成、生态毒性、人健康致癌性、人健康非致癌性、资源枯竭和呼吸效应。LCIA 计算使用影响评价工具进行，该工具利用表征因子（CFs）数据库。CFs 基于环境机制，并应用于将生命周期清单分析结果转换为每个影响类别的标准单位。它们可以被导出为转换为 midpoint 或 endpoint 环境影响类别（图 8.4）。

LCIA 数据库中包含的每种化学物质或材料对于数据库中的每个环境影响类别都有单独的 CF。影响计算方法如公式（8.1）和（8.2）所示，其中 c 表示特定排放化合物（CO₂ 等），i 表示特定影响类别（全球变暖等）。

```
Impact_{c,i} = mass_c * CF_{c,i} (8.1)
```

```
Total_{impact_i} = Σ_{c} Impact_{c,i} (8.2)
```

如公式（8.1）所示，特定化合物（c）在特定影响类别（i）中的影响是排放的 c 的质量与对应于 c 和 i 的 CF 的乘积。类别 i 中的总影响是该类别内所有化合物特定影响的总和（公式 8.2）。

LCA 从业者还经常进行敏感性分析和情景分析。敏感性分析用于测试假设并评估结果的不确定性。这是通过在潜在值范围内改变模型输入并观察这如何改变模型结果来完成的。例如，如果牛肉 LCA 中粗饲料与精饲料日粮比例不确定，则应在现实的粗饲料与精饲料比例范围内产生环境影响结果。在情景分析中，调整过程输入以代表与原始所关注系统不同的条件，以便评估环境影响的差异。在牛肉 LCA 示例中，情景分析可用于预测气候变化对牛肉生产相关环境影响的影响。

## LCA 的用途和局限性

LCA 应用于产品开发和改进、战略规划、公共政策制定、营销等（ISO 14040, 2006）。LCA 通常仅与比较分析相关，例如评估特定产品的不同设计或具有相同功能的多种产品的环境影响。LCA 有助于确定相对而非绝对的环境可持续性——它可以帮助我们弄清哪个决策更好，但不能使我们将事物标记为“可持续”或“不可持续”。
