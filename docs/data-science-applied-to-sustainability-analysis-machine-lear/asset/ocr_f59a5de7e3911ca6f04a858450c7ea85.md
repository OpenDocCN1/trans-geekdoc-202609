In shallow learning algorithms, modeling complex systems is enabled by expanding the feature set. This means that the modeler uses the raw features to make new features that are powers of the raw features, multiplicative combinations of raw features, or multiplicative combinations of the powers of raw features. This expanded feature set is then used to train the hypothesis function and determine fit parameters for the model. ANNs enable modeling of complex systems with an additional, automated learning task called feature learning. Feature learning takes place within a system of neurons, and each neuron has its own hypothesis function for which fit parameters must be determined. The products of this neural network are representations of the original feature data. The representation feature set is then used as the input for another hypothesis function with learned fit parameters, and this final hypothesis function produces the output of the ANN algorithm (Fig. 8.6).

# Choosing a machine learning algorithm

Whether one could use supervised, unsupervised, or reinforcement learning to build their model depends on the data available. If the intended training dataset has labels, supervised learning could be used to produce a model to estimate the labels of unlabeled datapoints. For example, a supervised learning algorithm trained on building characteristics and energy consumption data could be used to predict energy consumption of new buildings based on the characteristics used in the training set. In that example, the known building energy consumption data are the labels. If the intended training dataset does not have labels, unsupervised learning could be used to sort datapoints into groups. Examples of unsupervised learning application in fields closely related to ecosystem studies and LCA are clustering algorithms used to group unlabeled images of stoneflies of various species or determine optimal facility siting for straw to energy conversion. If there is no training dataset, but there are measurable goals for a model (e.g., to minimize fuel consumption), then reinforcement learning could be useful.

Deciding between shallow learning algorithms and ANN can be more difficult. The best choice may depend on the complexity (i.e., non-linearity) of relationships between inputs or between inputs and outputs, and the number of features in the dataset. If the model will need to describe non-linear relationships with lots of features, the number of features in a shallow learning algorithm can blow up fast as the feature set is expanded to accommodate these more complex relationships. Feature set expansion can make computation much slower. For datasets with many features, ANNs’ feature learning step can enable ANNs to model complex relationships with less computation power than some shallow algorithms. However, deciding what constitutes many features, or what makes relationships complex enough to warrant using ANNs can be difficult, and there are shallow learning algorithms that are designed avoid large numbers of features by favoring features with non-zero weights (see Lasso or ElasticNet algorithms).
