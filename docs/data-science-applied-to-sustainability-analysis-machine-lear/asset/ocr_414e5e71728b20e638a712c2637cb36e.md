# Tools for ML

With an ever-expanding set of ML tools, it is not possible to provide a comprehensive list. Some of the most common freely available and open source tools for building ML models include python libraries such as PyTorch, Scikit-learn, and Theano; Google’s TensorFlow; and Microsoft’s Cognitive Toolkit (CNTK), Weka, and KNIME. For those who are just getting started using ML, some good resources are Andrew Ng’s Machine Learning course on Coursera, and the OCDevel Machine Learning Guide podcast.

# ML in LCA

Potential applications of ML in LCA are numerous (Fig. 8.8), but which algorithms are useful will depend on the goal, the type of data, and size of the dataset. In this review, we found that ML has been applied for LCA in three areas: surrogate LCA development using ANN algorithms (Park et al. 2003; Sousa et al. 2006); CF estimation with multivariate linear regression (Slapnik et al. 2015); and sensitivity analysis with linear regressions (Heath et al. 2009).
