
尽管输入数据的非线性有利于更复杂的学习算法，研究发现不同算法的表现相似。支持向量机和随机森林模型的预测误差仅比用于总 EUI 的多元线性回归模型低约 10–15%，而线性回归模型在预测插电负载 EUI 时优于其他模型。对输入变量重要性的测试也表明，所使用的 CBECS 输入变量在映射实际能源消耗方面的预测能力较低，至少对于所应用的机器学习技术而言如此。本研究强调了拥有与待预测值高度相关的充足输入数据的重要性；尽管更复杂的算法在输入和输出变量关系非线性时可能改善模型性能，但它们无法解决与数据可用性相关的问题。

## ML 在 LCIA 中

机器学习已在生命周期影响评价中用于估算未表征化学化合物的生态毒性特征因子值。未来，机器学习还可以通过改善与生态和人类健康影响相关的环境数据收集，帮助表征用于定义特征因子的环境机制。由机器学习支持的数据收集甚至可能支持新的生命周期影响评价类别的开发。

### CF 估算

Slapnik 等 (2015) 对斯洛文尼亚进行了生命周期评价，以为生命周期评价从业者提供区域特定的归一化因子。在其生命周期清单的 440 种化学流动中，139 种没有影响特征因子。使用用于机器学习的 Weka 3.6.10 Java 软件包，以及在三个化学数据库（PPDB、ReCiPe 1.08 和 FURS）交集处的物理化学、毒理学、生态毒理学和现有影响特征数据，他们能够为陆地、淡水和海洋生态毒性以及人类毒性训练线性回归模型。由于 ReCiPe 中特征因子可用性有限，他们为生态毒性类别设置了 75 个训练实例，为人类毒性设置了 41 个训练实例。通过为每个影响类别训练 5 个模型，这些模型从包含最大数量的可用化学属性到仅包含数据最受限化合物可用的属性不等，研究人员能够产生与现有 ReCiPe 特征因子相关性良好的验证特征因子估计值（平均 >0.70）。然而，平均相对均方根误差相当高——模型预测约为 70%，因此研究人员指出，由某些估计特征因子得出的结果应谨慎考虑。

### CF 定义

虽然在环境数据不可用时使用化学化合物的性质来估算特征因子可能有用，但解决数据缺口的更直接方法是对我们表征环境影响的方式进行改进，包括对人类健康和生态系统的影响。本节回顾的研究展示了机器学习在改善由颗粒物排放驱动的人类健康影响估计以及通过自动化种群研究扩大生态数据库方面的应用。

为了估算呼吸系统疾病住院人数与颗粒物（PM）浓度以及湿度等气象变量的关系，研究人员使用了广义线性模型（GLMs），这是一种回归类型（Pan 等 2019）、人工神经网络（ANNs）（Tadano 等 2016）以及带集成的人工神经网络（Araujo 等 2020）。这些研究的结果可为生命周期影响评价中颗粒物排放以及有助于气候变化的排放的人类健康效应表征做出贡献。

Dieterich（2009）讨论了机器学习在生态系统信息学和可持续性方面的潜力，详细介绍了使用图像识别来识别不同种类石蝇的研究。标准词典图像识别方法不足以以 16.1% 的错误率产生可靠的石蝇无监督分类。使用堆叠随机森林和增强词典的替代方法表现更好，错误率分别为 6.4% 和 4.9%。使用机器学习收集生态系统数据可以改善与环境条件相关的生态系统健康效应表征。

## ML 在解释与分析中的应用

机器学习已在生命周期评价的解释与分析步骤中用于敏感性分析，并可用于情景分析以生成对应于感兴趣系统的新条件或约束的清单数据。

### 敏感性分析

生命周期评价中的敏感性分析需要改变模型输入，特别是那些不确定性高的输入，以了解每个输入的大小如何影响生命周期评价结果。这可以简单到使用特定输入调整 +/-50% 运行模型，也可以具体到根据详细输入数据在已知分布上改变模型输入。Heath 等（2009）使用的生命周期评价敏感性分析的另一种方法是使用回归评估生命周期评价输入与输出之间的关系。

Heath 等（2009）在乙醇生命周期评价的敏感性分析中使用了简单线性回归。每个线性回归的数据是通过使用一系列输入参数值运行模型生成的；输入参数的范围是特征集，对应的输出是标签。作为该应用的扩展，多元回归可用于对每个环境影响类别进行多元敏感性分析。这将使生命周期评价输入与输出之间关系的数学表示成为可能。

例如，乙醇的全球变暖潜势（GWP）、原料转换效率和乙醇原料副产品利用率之间关系的回归模型可能会产生如图（图 8.9）所示的响应面。生成生命周期评价模型的数学表示将使结果随多个输入变量同时变化而变化的表征成为可能，并且在某些情况下可能指示最小化感兴趣影响类别（如 GWP）的生产条件的优化集合。

### 情景分析

如“估算清单流动”部分所述，有监督学习算法可用于生成预测系统性能的模型，这些预测在性能数据不可用的情景分析中可能很有用。在所考察的建筑能耗研究（Deng 等 2018）中，有监督学习算法被训练用于估算系统性能，在本例中为建筑能耗。对于情景分析，系统性能变量如能耗或排放可针对修改后的输入变量如灯泡类型或气候进行预测。

生命周期评价中的复杂优化情景分析可由无监督和强化学习算法辅助。为了评估纤维素燃料生产近期规模化的潜力，Mueller-Warrant 等（2010）使用 K-means 算法——一种无监督聚类算法——根据秸秆生产的位置和数量数据确定秸秆制能转换站点的最佳位置。强化学习通常用于在特定优化约束下对连续决策情景进行建模，因此强化算法也可用于为优化情景生成生命周期清单数据。例如，Wu 等（2018）使用深度 Q 学习（DQL），一种强化学习方法，来建模混合动力电动公交车（HEBs）的最佳能源管理策略。

## 结论

生命周期评价依赖于清单和影响特征数据来量化产品和工艺的环境影响。清单分析需要系统生命周期输入和输出的数据，而影响特征需要我们了解化学排放和其他环境条件变化如何影响人类健康和生态系统。在存在足够训练数据的情况下，数据越多越好，机器学习算法可用于建模关系并预测缺失数据点。使用机器学习增强环境数据收集和优化系统也可能改善清单和影响特征数据的可用性。

为了实现机器学习在生命周期评价中的未来应用，数据收集工作应集中于系统性能（如能源使用、排放或废物产生）和性能指标的设计阶段驱动因素，以及在变化的环境条件下量化人类健康和生态系统健康。特别是，需要更多表征新兴技术（如太空资源）的数据来推动未来的生命周期评价研究以及针对这些系统的任何相应的机器学习应用。

## ML 的 LCA

尽管本章重点是机器学习在生命周期评价中的应用，但数据科学和可持续性受众可能也会感兴趣的是，研究人员也在努力量化训练复杂机器学习模型的环境影响，这些模型可能需要大量计算资源（Strubell 等 2019）。Strubell 等（2019）估计训练、调优和试验一种自然语言处理（NLP）算法相关的温室气体（GHG）排放约为 35.7 吨二氧化碳当量。这超过了美国普通人年温室气体排放量的两倍，后者约为 16 吨二氧化碳当量。
