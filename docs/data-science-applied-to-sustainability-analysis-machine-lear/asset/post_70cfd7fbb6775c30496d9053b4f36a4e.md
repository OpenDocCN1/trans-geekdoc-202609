LCA databases contain complete LCIs for many processes and can be accessed and manipulated using the comprehensive LCA tools listed above. OpenLCA Nexus is an online repository for LCI data, providing download pathways for both free and for-purchase LCA databases, and a search engine that allows users to find relevant datasets in any of the LCA databases on Nexus. There are many free LCA databases on openLCA Nexus; probably the most comprehensive is the USLCI database, which is maintained by the National Renewable Energy Laboratory (NREL), and the USDA LCA collection. Popular for-purchase databases on Nexus are ecoinvent and GaBi thinkstep, both of which have a wide range of manufacturing process and products.

Most LCA software packages have built-in LCIA methods. The openLCA LCIA methods database, which is also free on openLCA Nexus, includes a variety of impact assessment datasets: TRACI, USEtox, ReCiPe, ILCD, eco-indicator 99, Cumulative Energy Demand, and CML. Acero et al. (2015) describe these impact assessment datasets in detail and Landis et al. (2008) compares the differences in their results.

## IO-LCA

There are several freely available IO-LCA tools. These tools are typically developed using national-level economic data and each is therefore applicable within a specific country or set of countries. The first was developed by Carnegie Mellon University (CMU). CMU's Economic Input-Output LCA (EIO-LCA) model includes national-level IO tables for the United States (US), Peru, Germany, Spain, Canada, and China, and state-level tables for Pennsylvania and West Virginia. Other IO-LCA tools include the US Environmental Protection Agency (USEPA)’s Environmentally-Extended Input-Output (USEEIO) model for the US, and EXIOBASE, which was developed by a European research consortium. The latest version of EXIOBASE includes 43 countries and 5 “rest of world” regions. VitalMetrics’ US Comprehensive Environmental Data Archive (CEDA) is not free, but university faculty and students can obtain a free academic version.

## Introduction to machine learning (ML)

Machine learning (ML) is a statistical approach to studying and making inferences about data that utilizes a variety of algorithms suited for answering different types of questions. There are three main types of ML: supervised, unsupervised, and reinforcement learning. In supervised learning, ML algorithms can be used to model relationships between one or more independent variables and a dependent variable. In unsupervised learning, algorithms find meaningful patterns in datasets or sort data into groups. Reinforcement learning ML algorithms produce optimized plans or courses of action given a set of constraints or a reward system. These three main types of ML, supervised, unsupervised, and reinforcement learning, are described in the following sections. Other topics discussed are shallow and deep learning, how to choose between algorithm types based on the dataset or intended application, and common machine learning tools.

### Types of ML

### Supervised learning

Supervised learning algorithms require that the modeler provide a dataset of one or more independent variables, and a corresponding dependent variable. In ML, independent variables are called features, and dependent variables are often called labels or targets, but can also be thought of as the answer to a question about a datapoint: What is the price of this house? Is this a dog or a cat? What is the ecotoxicity impact CF for this substance? Features in these cases could be the location of the house, the size of the animal, or the octanol-water partition coefficient of the substance, respectively.

With enough input data, a supervised learning algorithm can produce a model of the relationship between features and labels. The model is built and tested using at least two randomly selected subsets of the labeled data: the training set and the testing set, respectively. A working model can then be used to estimate the labels of new datapoints. If you have ever calibrated a model using experimental input and output data, you have used a machine learning algorithm; the fit parameters of your model are the result of what the algorithm has learned from your training data. In fact, the simplest examples of supervised learning algorithms, regressions, are likely familiar to most scientists. Linear or polynomial regressions can be used to build models for feature data with continuous label values like prices, masses, material flows in an LCI, or impact CFs in LCIA. For feature data with discrete labels that sort datapoints into categories, like “dog” or “cat,” logistic regressions can be useful.

### Unsupervised learning

Unsupervised learning algorithms operate without data labels. Instead, the algorithm is tasked with sorting datapoints into groups, “cleaning up” data, or finding structure within a dataset. One example application of an unsupervised learning algorithm is Google News’ grouping of similar stories so that readers can look at the same issue as reported by various outlets (Fig. 8.5).

## Shallow and deep learning

Within the three general types of ML discussed above, there are numerous algorithms, many carefully structured for specific problem types, and others more flexible and able to accommodate greater system complexity. Generally, the algorithms structured for specific tasks and therefore limited in flexibility are called “shallow” or hierarchical learning algorithms. More flexible ML algorithms are classified as deep or representation learning, and the main form of representation learning is the artificial neural network (ANN).

The main difference between shallow algorithms and ANNs is how they accommodate complexity (i.e., non-linearity) of relationships between features and model outputs.

In shallow learning algorithms, modeling complex systems is enabled by expanding the feature set. This means that the modeler uses the raw features to make new features that are powers of the raw features, multiplicative combinations of raw features, or multiplicative combinations of the powers of raw features. This expanded feature set is then used to train the hypothesis function and determine fit parameters for the model. ANNs enable modeling of complex systems with an additional, automated learning task called feature learning. Feature learning takes place within a system of neurons, and each neuron has its own hypothesis function for which fit parameters must be determined. The products of this neural network are representations of the original feature data. The representation feature set is then used as the input for another hypothesis function with learned fit parameters, and this final hypothesis function produces the output of the ANN algorithm (Fig. 8.6).

## Choosing a machine learning algorithm

Whether one could use supervised, unsupervised, or reinforcement learning to build their model depends on the data available. If the intended training dataset has labels, supervised learning could be used to produce a model to estimate the labels of unlabeled datapoints. For example, a supervised learning algorithm trained on building characteristics and energy consumption data could be used to predict energy consumption of new buildings based on the characteristics used in the training set. In that example, the known building energy consumption data are the labels. If the intended training dataset does not have labels, unsupervised learning could be used to sort datapoints into groups. Examples of unsupervised learning application in fields closely related to ecosystem studies and LCA are clustering algorithms used to group unlabeled images of stoneflies of various species or determine optimal facility siting for straw to energy conversion. If there is no training dataset, but there are measurable goals for a model (e.g., to minimize fuel consumption), then reinforcement learning could be useful.

Deciding between shallow learning algorithms and ANN can be more difficult. The best choice may depend on the complexity (i.e., non-linearity) of relationships between inputs or between inputs and outputs, and the number of features in the dataset. If the model will need to describe non-linear relationships with lots of features, the number of features in a shallow learning algorithm can blow up fast as the feature set is expanded to accommodate these more complex relationships. Feature set expansion can make computation much slower. For datasets with many features, ANNs’ feature learning step can enable ANNs to model complex relationships with less computation power than some shallow algorithms. However, deciding what constitutes many features, or what makes relationships complex enough to warrant using ANNs can be difficult, and there are shallow learning algorithms that are designed avoid large numbers of features by favoring features with non-zero weights (see Lasso or ElasticNet algorithms).
