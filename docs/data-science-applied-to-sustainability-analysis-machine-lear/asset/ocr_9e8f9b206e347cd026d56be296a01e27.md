# Types of ML

# Supervised learning

Supervised learning algorithms require that the modeler provide a dataset of one or more independent variables, and a corresponding dependent variable. In ML, independent variables are called features, and dependent variables are often called a labels or targets, but can also be thought of as the answer to a question about a datapoint: What is the price of this house? Is this a dog or a cat? What is the ecotoxicity impact CF for this substance? Features in these cases could be the location of the house, the size of the animal, or the octanol-water partition coefficient of the substance, respectively.

With enough input data, a supervised learning algorithm can produce a model of the relationship between features and labels. The model is built and tested using at least two randomly selected subsets of the labeled data: the training set and the testing set, respectively. A working model can then be used to estimate the labels of new datapoints. If you have ever calibrated a model using experimental input and output data, you have used a machine learning algorithm; the fit parameters of your model are the result of what the algorithm has learned from your training data. In fact, the simplest examples of supervised learning algorithms, regressions, are likely familiar to most scientists. Linear or polynomial regressions can be used to build models for feature data with continuous label values like prices, masses, material flows in an LCI, or impact CFs in LCIA. For feature data with discrete labels that sort datapoints into categories, like “dog” or “cat,” logistic regressions can be useful.

# Unsupervised learning

Unsupervised learning algorithms operate without data labels. Instead, the algorithm is tasked with sorting datapoints into groups, “cleaning up” data, or finding structure within a dataset. One example application of an unsupervised learning algorithm is Google News’ grouping of similar stories so that readers can look at the same issue as reported by various outlets (Fig. 8.5).
