
# 消融研究

已提出多项消融研究，以检验多语言变换器中语言无关表示有效性的若干假设。首先在 `[199](#refbib.xhtml#refbib_199)` 中测试的假设是，高资源语言的共同脚本是影响优秀多语言变换器性能的混淆因素。然而，事实证明这并非真的，因为多语言转移发生在不共享脚本的语言之间，例如乌尔都语使用阿拉伯脚本，印地语使用天城文脚本 `[199](#refbib.xhtml#refbib_199)`。其他工作 `[229](#refbib.xhtml#refbib_229)` 检查了输入标记化作为混淆因素，发现使用子词标记化使模型更倾向于学习语言无关表示，而不是词级或字符级标记化。预训练任务也被视为可能的混淆因素，结果表明，使用平行语料库预训练任务（如 XLM）的模型在编码器的更高层中比基于单语言语料库训练的模型（如 mBERT 和 XLMR）更强地保留语言无关表示 `[52](#refbib.xhtml#refbib_52)`。

# 平行语料库表示

另一种研究语言无关表示假设的方法是使用不同语言的平行语料库，并检查其在模型嵌入空间中的对齐情况。相关性分析（CCA）是一种用于分析平行表示对齐的技术。在 `[229](#refbib.xhtml#refbib_229)` 中，CCA 分析表明 mBERT 并未将平行表示投射到同一空间。机器翻译也被用于检验语言无关表示，其中一方提供源语言句子，另一方提供多个目标语言句子，任务是使用最近邻算法在目标候选句中找出正确的翻译。在 `[199](#refbib.xhtml#refbib_199)` 中观察到，正确的翻译（即表示对齐）取决于模型产生表示的层。结果显示，mBERT 的中间层（5–8），在英语-德语、印地语-乌尔都语等同语系语言中，最近邻准确率为 75%。有人认为，一个合理的结论是，大容量的多语言变换器模型能够创建并保留语言无关和语言特定的表示。语言无关的表示足够丰富，能够对齐多语言词汇并检索语义相似的句子。然而，这些表示不足以应对诸如机器翻译等困难问题 `[161](#refbib.xhtml#refbib_161)`。

# 探测任务

另一种研究语言无关表示的方法是使用在各层获得的表示进行探测任务。例如，一致的依存树可能从 mBERT 中间层的表示中学习，表明其捕捉了语法抽象 `[44](#refbib.xhtml#refbib_44), [162](#refbib.xhtml#refbib_162)`。然而，主语-动词-宾语（SVO）语言（如英语、法语、印尼语）的依存树准确率高于主语-宾语-动词（SOV）语言（如土耳其语、韩语、日语）。这种 SVO 与 SOV 语言之间的差异在词性标签（POS）的标注中也可见 `[199](#refbib.xhtml#refbib_199)`。每一层都有其独特的专长，因此混合多层数据以获得最佳结果是有利的，而不是仅凭整体性能选择单一层，这一点已在荷兰语的多种 NLP 任务中得到证明 `[68](#refbib.xhtml#refbib_68)`。在同一实验中，还发现多语言模型在词性标签任务上，其早期层的表示比单语言荷兰模型更具信息性。

## 4.4 CASE STUDY

### 4.4.1 Goal

本节提供一个实际的案例，展示如何训练一个多语言情感分类器。我们的目标是说明多语言模型的零样本分类能力：模型仅在英文数据上训练，然后直接用于非英文数据的预测，无需进一步训练。

### 4.4.2 Data, Tools, and Libraries

本案例使用二分类情感分类数据集 Yelp Polarity `[297](#refbib.xhtml#refbib_297)`。数据集包含 560K 条高度极化的 Yelp 评论用于训练，以及 38K 条用于测试。原始 Yelp 评论的评分从 1 到 5 星。该数据集通过将 1 星和 2 星评分归为负面情感类别，将 3 星和 4 星评分归为正面情感类别来构建。

本案例将使用多语言通用句子编码器（mUSE） `[49](#refbib.xhtml#refbib_49), [284](#refbib.xhtml#refbib_284)` 进行特征生成。mUSE 是一种 Transformer 编码器，使得不同语言但含义相似的文本产生相似的编码，这类似于意义相似的词在词向量中具有相似的嵌入。mUSE 支持 16 种语言：阿拉伯语、中文（简体）、中文（繁体）、英语、法语、德语、意大利语、日语、韩语、荷兰语、波兰语、葡萄牙语、西班牙语、泰语、土耳其语、俄语。

在本案例中，我们使用 TensorFlow Hub 加载 mUSE 模型，使用 Huggingface Datasets 加载 Yelp Polarity 数据集，并使用 PyTorch Lightning 简化训练过程。mUSE 内部使用 TensorFlow Text 进行分词，因此需要安装该库。可以通过运行在 [Listing 4.1](#ch4.xhtml#list4_1) 中所示的 shell 命令进行安装。
