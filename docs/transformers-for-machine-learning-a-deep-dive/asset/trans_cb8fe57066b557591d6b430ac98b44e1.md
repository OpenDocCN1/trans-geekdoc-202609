
Hinton 等人于 2006 年发表了一篇突破性论文，题为《A fast learning algorithm for deep belief nets》，它是深度学习复兴的重要原因之一 \[[113](#refbib.xhtml#refbib_113)\]。该研究强调了使用非监督方法层层训练，随后通过监督的“微调”实现卓越的字符识别结果。

Bengio 等人在该工作之后的重要论文中，深入阐述了多层深度学习网络如何比浅层神经网络更能够层次化学习特征 \[[27](#refbib.xhtml#refbib_27)\]。在他们的研究中，Bengio 与 LeCun 强调了通过卷积神经网络（CNN）、受限玻尔兹曼机（RBM）以及深度信念网络（DBN）等架构，以及非监督预训练后微调等技术的优势，从而激发了下一波深度学习浪潮 \[[28](#refbib.xhtml#refbib_28)\]。斯坦福大学人工智能实验室主任李飞飞及其合作者创建了 ImageNet，这一举措形成了规模最大的图像集合，并首次凸显数据在学习关键任务（如目标识别、分类和聚类）方面的重要性 \[[70](#refbib.xhtml#refbib_70)\]。随着计算机硬件的提升（尤其是 GPU），计算吞吐量每五年几乎提升 10 倍，以及大量可用的训练数据，使得领域出现范式转变。过去依赖手工设计特征的高级应用，现在通过大规模训练数据让必要特征自动涌现，使得深度学习网络成为许多最先进技术的基石。

Mikolov 等人与 Graves 提出了基于循环神经网络（RNN）和长短期记忆（LSTM）的语言模型，这些模型后来成为众多自然语言处理（NLP）架构的基础块 \[[97](#refbib.xhtml#refbib_97), [184](#refbib.xhtml#refbib_184)\]。Collobert 与 Weston 的研究论文在展示预训练词向量、用于文本的卷积神经网络以及多任务学习中共享嵌入矩阵的概念方面发挥了重要作用 \[[60](#refbib.xhtml#refbib_60)\]。Mikolov 等人进一步通过消除隐藏层并构建近似目标来提升 Bengio 等人提出的词向量训练效率，从而催生了“word2vec”，这是一种高效的大规模词向量实现 \[[183](#refbib.xhtml#refbib_183), [185](#refbib.xhtml#refbib_185)\]。Sutskever 提出的黑森免费优化器能够高效训练长期依赖的 RNN，标志着 RNN 在 NLP 领域使用的复兴 \[[237](#refbib.xhtml#refbib_237)\]。Sutskever 等人引入了序列到序列学习，这是一种通用的神经框架，由编码器网络处理输入序列，解码器网络根据输入状态和当前输出状态预测输出 \[[238](#refbib.xhtml#refbib_238)\]。因此，序列到序列框架成为众多 NLP 任务（如句法分析、命名实体识别（NER）、机器翻译、问答和摘要）的核心结构。此外，即使是 Google 也开始用序列到序列神经机翻译模型取代其单体短语基机翻译模型 \[[272](#refbib.xhtml#refbib_272)\]。

为克服序列到序列框架的瓶颈，Bahdanau 等人提出了注意力机制，它在 transformer 及其变体中发挥关键作用 \[[17](#refbib.xhtml#refbib_17)\]。

### 1.2 Transformers and Taxonomy

Transformer 架构 \[[254](#refbib.xhtml#refbib_254)\] 于 2017 年在论文 *Attention Is All You Need* 中引入，用于处理序列到序列问题，它是取代循环层或卷积层的替代方案。自问世以来，研究者在多种方面改进标准 transformer，调研调查将 transformer 相关论文分为两类 \[[163](#refbib.xhtml#refbib_163), [243](#refbib.xhtml#refbib_243)\]。Transformer 研究主要聚焦于三个方面：架构修改、预训练方法以及应用。本书将重点讨论架构修改的子集、大语言模型的预训练方法（如 BERT）\[[71](#refbib.xhtml#refbib_71)\] 以及部分应用。

*   降低内存占用和计算开销  
*   在变换器块之间增加连接  
*   引入自适应计算时间（例如训练时提前停止）
