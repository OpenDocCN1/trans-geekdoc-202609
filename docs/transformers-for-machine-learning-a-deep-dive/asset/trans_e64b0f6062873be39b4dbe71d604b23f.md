
-   [构建代码切换数据时，使用工具在平行语料库的源句和目标句之间进行词对齐，并使用机器翻译技术提取双语短语表。随后，根据比例 `α` 替换源句和目标句来构建代码切换数据。由于 `α` 随机决定从源句还是目标句中选取短语，每个句子对可以生成多个代码切换序列，这对于克服通常有限的平行语料库规模非常有用。随后，ALM 通过在代码切换数据上使用标准 MLM 预训练任务进行处理。形式上，对于平行句子对 (*x*, *y*)，设 *z* 为从 *x* 和 *y* 生成的代码切换句子，则 ALM 损失定义为：

$$\\begin{array}{l} {\\mathcal{L}\_{ALM}^{(z(x,y))} = - \\frac{1}{|M|}{\\sum\\limits\_{i \\in M}l}ogP(z\_{i}|z\_{\\smallsetminus M})} \\\\ \\end{array}$$

(4.5)

其中 *z*[ ∖ *M*] 是 *z* 的掩码版本，*M* 是 *z*[ ∖ *M*] 中被掩码的 token 位置集合。

#### 4.1.2.5 Unicoder

Unicoder \[[125](#refbib.xhtml#refbib_125)\] 是另一种利用平行语料库学习跨语言表示的架构。它采用与 XLM 相同的结构，并引入了三种新的跨语言预训练任务，即跨语言词汇恢复（CLWR）、跨语言 paraphrase 分类（CLPC）和跨语言掩码语言模型（CLMLM）。

**跨语言词汇恢复（CLWR）** CLWR \[[125](#refbib.xhtml#refbib_125)\] 使用平行语料库学习两种语言之间的词对齐。预训练任务首先使用一个可训练的注意力矩阵 \[[17](#refbib.xhtml#refbib_17)\] 来学习将源语言 token 嵌入表示为目标语言 token 嵌入的线性组合。该注意力矩阵所学得到的转换随后提供给跨语言模型，以学习重构源 token 嵌入。形式上，给定平行句子对 (*x*, *y*)，其中 *x* = (*x*[1], *x*[2], …, *x*[*m*]) 为源语言 *s* 的 *m* 个词， *y* = (*y*[1], *y*[2], …, *y*[*n*]) 为目标语言 *t* 的 *n* 个词。CLWR 先用 *y* 中所有词的嵌入对 *x*[*i*] 进行加权求和，得到 *x*[*i*] 的跨语言表示 *x*[*i*]^(*t*) ∈ *R*^(*h*)：

$$\\begin{array}{l} {x\_{i}^{t} = {\\sum\\limits\_{j = 1}^{n}\\text{softmax}}(A\_{ij})y\_{j}^{t}} \\\\ \\end{array}$$

(4.6)

其中 *x*[*i*]^(*s*) ∈ *R*^(*h*) 与 *y*[*j*]^(*t*) ∈ *R*^(*h*) 分别表示 *x*[*i*] 与 *y*[*j*] 的表示，*h* 为表示维度，*A* ∈ *R*^(*m* × *n*) 为定义为：

$$\\begin{array}{l} {A\_{ij} = W\\lbrack{x\_{i}^{s},y\_{j}^{t},x\_{i}^{s} \\odot y\_{j}^{t}}\\rbrack} \\\\ \\end{array}$$

(4.7)

其中 *W* ∈ *R*^(3 × *h*) 为可训练权重矩阵，⊙ 表示逐元素乘法。Unicoder 以 *X*^(*t*) = (*x*[1]^(*t*), *x*[2]^(*t*), …, *x*[*n*]^(*t*)) 作为输入，并预测原始词序列 *x*。

**跨语言 paraphrase 分类（CLPC）** CLPC \[[125](#refbib.xhtml#refbib_125)\] 通过提出一种新的利用平行数据的方式，引入 paraphrase 分类预训练任务。平行句子对 (*x*, *y*) 被视为正样本，而非平行对 (*x*, *z*) 被视为负样本。训练数据样本通过使用较小的 paraphrase 检测模型选取，使得对每个 (*x*, *y*) 与 (*x*, *z*) 句子对， *z* 与 *x* 相近但不等于 *y*。

**跨语言掩码语言模型（CLMLM）** CLMLM \[[125](#refbib.xhtml#refbib_125)\] 是 TLM 的扩展，同样采用跨语言注意力机制。不同之处在于，TLM 接收平行句子对，而 CLMLM 的输入在文档级别构建：多句平行文档（即包含多个平行翻译的完整文档）中的句子会被其他语言的翻译所替换。此设计受到一些在使用更长单语文本进行预训练时取得成功的启发。Unicoder 模型初始化自 XLM，随后在结合 MLM、TLM、CLWR、CLPC 和 CLMLM 任务的基础上进行预训练，并在 XNLI 和 XQA 基准上进行微调。

#### 4.1.2.6 Information-Theoretic Cross-Lingual Model (INFOXLM)

Information-Theoretic Cross-Lingual Model (INFOXLM) \[[47](#refbib.xhtml#refbib_47)\] 从信息理论角度来看待跨语言表示对齐问题，表明多语言预训练任务可以被视为在不同粒度上最大化多语言上下文之间的相互信息。例如，InfoXLM 表明，多语言掩码语言模型（mMLM）预训练任务本质上最大化了同一语言内被掩码 token 与其上下文之间的相互信息。另一方面，跨语言锚 token 促使不同语言的上下文高度相关。TLM 也有信息理论解释，显示其最大化被掩码 token 与平行语言上下文之间的相互信息，从而作为隐式跨语言表示对齐机制。基于提供的信息理论框架，InfoXLM 提出了一种新的对比学习基础的跨语言预训练任务，即跨语言对比学习。

**跨语言对比学习（XLCO）** XLCO \[[47](#refbib.xhtml#refbib_47)\] 提出一种信息理论方法，利用平行语料库生成跨语言表示。XLCO 鼓励 Transformer 编码器在平行句子与非平行句子的表示之间最大化相互信息，从而进行对比学习。TLM 在信息理论框架下被证明最大化 token‑sequence 之间的相互信息。相反，XLCO 最大化平行句子之间的 sequence‑level 相互信息。设 (*x*[*i*], *y*[*i*]) 为一对平行句子，其中 *y*[*i*] 是 *x*[*i*] 的翻译，{*y*[*j*]}[*j* = 1, *j* ≠ *i*]^(*N*) 为与 *y*[*i*] 同语言但不是 *x*[*i*] 翻译的句子集合。XLCO 通过 InfoNCE \[[251](#refbib.xhtml#refbib_251)\] 定义的损失函数最大化 *x*[*i*] 与 *y*[*i*] 之间的信息内容：

$$\\begin{array}{l} {\\mathcal{L}\_{XLCO}^{(x,\_{i},y\_{i})} = - \\log\\frac{\\exp(f{(x\_{i})}^{\\top}f(y\_{i}))}{{\\sum\\limits\_{j = 1}^{N}{\\exp}}(f{(x\_{i})}^{\\top}f(y\_{j})}} \\\\ \\end{array}$$

(4.8)

其中 *f*(*x*[*i*]) 与 *f*(*y*[*i*]) 分别为句子 *x*[*i*] 与 *y*[*i*] 的 Transformer 编码器表示。对于负样本采样，XLCO 不显式从 {*y*[*j*]}[*j* = 1, *j* ≠ *i*]^(*N*) 中抽取，而是利用 mixup 对比 \[[47](#refbib.xhtml#refbib_47)\] 与 momentum \[[104](#refbib.xhtml#refbib_104)\] 来构造更具挑战性的负样本。
