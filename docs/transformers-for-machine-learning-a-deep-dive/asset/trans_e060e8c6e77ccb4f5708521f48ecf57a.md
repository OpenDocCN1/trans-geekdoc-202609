
## 共享词汇

在训练多语言语言模型（mLM）之前，所有语言的文本都使用 WordPiece \[[220](#refbib.xhtml#refbib_220)\] 或 SentencePiece \[[144](#refbib.xhtml#refbib_144)\] 模型进行分词。核心概念是将每个单词分解为其出现频率最高的子词。模型的词汇表随后由所有语言中识别出的这些子词组成。这种组合分词确保子词在大量密切相关或甚至遥远的语言之间共享。因此，如果目标语言的测试集中存在的子词也出现在源语言的训练集中，模型性能可能会通过这种共享词汇传递。跨语言零射传递能力与语言间词汇重叠大小之间的关系已在 \[[199](#refbib.xhtml#refbib_199)\] 和 \[[271](#refbib.xhtml#refbib_271)\] 中被研究，结果显示两者呈强烈正相关，且这种正面效应在多个不同领域中均保持一致，包括命名实体识别（NER）\[[246](#refbib.xhtml#refbib_246), [247](#refbib.xhtml#refbib_247)\]、词性标注（POS）\[[192](#refbib.xhtml#refbib_192)\]、XNLI \[[64](#refbib.xhtml#refbib_64)\]、MLDoc \[[221](#refbib.xhtml#refbib_221)\] 和依存分析（Dependency parsing）\[[192](#refbib.xhtml#refbib_192)\]。这些观察是直观的，为在仅使用单语言语料库进行多语言训练时的跨语言表示对齐提供了一些解释。然而，这一研究领域仍然新颖，正在收集更多证据以验证这些观察。例如，Karthikeyan 等人 \[[135](#refbib.xhtml#refbib_135)\] 人工将词汇重叠减至零，但跨语言零射学习中的性能下降却很小，这削弱了词汇重叠对跨语言零射传递学习的影响。另一项工作 \[[10](#refbib.xhtml#refbib_10)\] 表明，即使没有词汇重叠，通过正确微调除输入嵌入层外的所有变换器层，跨语言传递学习仍然会发生。

**预训练数据规模**

预训练数据规模对跨语言性能的影响已在 \[[165](#refbib.xhtml#refbib_165)\] 中得到评估，结果表明当 mBERT 在大规模语料上预训练时，跨语言传递能力得到提升。Lauscher 等人 \[[148](#refbib.xhtml#refbib_148)\] 也指出，用于预训练 mLM 的目标语言数据量与零射传递性能强相关，尤其在 XNLI 和 XQuAD 等高层次任务中表现更为显著。对于较低层次任务如 POS、依存分析和 NER，也存在正相关，但其强度不如 XNLI 和 XQuAD。

**使用平行语料库**

尽管 mLMs 在未专门使用跨语言信号的情况下也能表现良好，但直观上，有意使用此类信号的训练应能进一步提升性能。事实上，XLMs 在 \[[63](#refbib.xhtml#refbib_63)\] 和 InfoXLM 在 \[[47](#refbib.xhtml#refbib_47)\] 中展示了将平行语料库与 TLM 预训练任务结合使用能够提升性能。如果没有平行语料库，\[[79](#refbib.xhtml#refbib_79)\] 主张使用类似的语料（如 [Wikipedia](http://Wikipedia) 或 CommonCrawl）训练 mLMs 优于使用跨语言来源的分散语料。

## 4.3.1.2 模型架构因素

多语言模型的容量取决于其层数、注意力头的数量以及隐藏表示的尺寸。Karthikeyan 等人 \[[135](#refbib.xhtml#refbib_135)\] 表明，跨语言传递学习性能高度依赖于网络的深度，而对注意力头的数量影响较小。他们特别表明，即使只有一个注意力头，也能实现足够的跨语言传递。此外，模型总参数量对跨语言传递的有效性影响小于层数。有趣的是，在 \[[79](#refbib.xhtml#refbib_79)\] 中，mBERT 的跨语言传递被认为是由于其参数量小、容量有限，这迫使它利用共享结构来对齐不同语言的表示。

另一个关键的架构决策是自注意力上下文窗口，它指在训练 mLM 时输入的 token 数量。Liu 等人 \[[165](#refbib.xhtml#refbib_165)\] 表明，当预训练数据稀缺时，使用较小的上下文窗口更为理想；而当拥有大量预训练数据时，使用更长的上下文窗口更好。

在 \[[260](#refbib.xhtml#refbib_260)\] 和 \[[45](#refbib.xhtml#refbib_45)\] 中指出，由于 mLMs 的模型容量有限且被多种语言共享，它们无法像单语言预训练模型那样捕捉所有语言的细微差别。他们展示了从单语言模型中进行知识蒸馏可以提升 mLM 的跨语言性能。

## 4.3.1.3 模型任务因素

**微调策略**

在 \[[171](#refbib.xhtml#refbib_171)\] 中讨论了微调 mLM 会改变其参数，从而损害其跨语言能力，因为在微调过程中会抹去预训练期间学习的部分对齐。他们通过展示当 mLM 微调用于词性标注时，其跨语言检索性能显著下降来说明这一点。为解决此问题，他们建议采用持续学习框架进行微调，以避免忘记预训练时的原始任务（MLM）。该方法在跨语言词性标注、命名实体识别（NER）和句子检索方面取得了改进。

**表示对齐**

在 \[[168](#refbib.xhtml#refbib_168), [261](#refbib.xhtml#refbib_261)\] 中，研究了通过 mLMs 隐式对齐的表示与随后使用平行语料显式对齐的单语言表示在零射跨语言传递中的表现比较。结果表明，显式对齐能够提升性能。基于此，Wang 等人 \[[263](#refbib.xhtml#refbib_263)\] 提出在 mBERT 训练时，通过在损失函数中加入最小化对齐词嵌入欧氏距离的方式，显式对齐匹配词对在不同语言之间的表示。Zhao 等人 \[[298](#refbib.xhtml#refbib_298)\] 也报告了当词对表示被显式对齐且向量空间进一步归一化时，结果相似。

### 4.3.2 语言无关的跨语言表示

尽管变换器模型（如 BERT）在推动 NLP 与机器学习领域发展方面取得了巨大成功，其内部工作机制——即如何提取和存储知识——仍未完全理解，仍是活跃研究的焦点。多语言变换器也不例外，但它们更具趣味性，因为它们在多个语言之间使用并共享知识，即实现跨语言传递学习。这引发了一个问题：多语言变换器是否学习语言无关的跨语言表示？为此，已提出多种方法，角度各异：(i) 消去研究（Ablation Studies），(ii) 任务探针（Task Probes），(iii) 平行语料表示（Parallel Corpora Representations）。
