
自2012年以来，深度学习架构开始在机器学习领域占据主导地位。然而，大部分突破主要出现在计算机视觉应用中。导致这种成功的主要驱动力是卷积神经网络（CNN）架构。CNN的高效性和并行化能力使得计算机视觉架构能够在海量数据上进行预训练，这被证明是其成功的关键因素。多年以后，自然语言处理（NLP）应用并未受到新的深度学习革命的显著影响。传统的序列建模架构，如循环神经网络（RNNs）和长短期记忆（LSTM），长期被用于NLP应用。这类架构的顺序性限制了它们在与计算机视觉中同样有价值的数据规模上进行训练的可能性。

2017年，Google推出了Transformer架构，用于处理序列数据，并实现了更大的并行化。该架构使得在比以往更大的数据集上进行高效训练成为可能。这使得Transformer在NLP领域实现了与CNN在计算机视觉领域所带来的变革。

Transformer如今已成为NLP、语音识别、时间序列和计算机视觉等多个领域中广泛应用的神经网络架构的核心部分。OpenAI在其GPT2/GPT3中使用Transformer，这些模型在各类NLP任务中展现出最先进的性能水平。DeepMind的AlphaStar程序，它击败了顶尖职业StarCraft玩家，同样采用Transformer架构。Transformer经历了许多适应和修改，催生了新的技术和方法。没有一本专著能够在一个地方涵盖Transformer的基础知识及其各种变体。

本书作为独特的资源，为数据科学家和研究人员（学术及工业领域）提供：

*   一本涵盖Transformer每个算法和技术的详细解释的全面参考书。

*   以全面方式覆盖了60多种Transformer架构。

*   一本帮助理解如何在不同的NLP应用、语音、时间序列和计算机视觉中应用Transformer技术的书籍。

*   针对每种架构的实用技巧和技术，以及如何在现实世界中使用它们的指南。

*   提供动手实践案例，涵盖机器翻译、主题挖掘、零样本多语言分类、情感分析、语音识别、文本分类/分类等多个真实场景，从任务、过程和分析角度详细说明，并可直接在Google Colab中运行。

## 谁是这本书的目标读者？

Transformer架构的理论解释将吸引研究生和研究人员（学术及工业）的关注，因为它提供了一个单一入口，对快速发展的领域进行深入讨论。实践性的动手案例和代码将吸引本科生、实践者和专业人士，因为它便于快速实验，并降低了进入该领域的门槛。

Transformer已经成为NLP深度学习架构的基石，同时也迅速应用于计算机视觉和音频等其他领域。任何关于神经网络、深度学习或人工智能的课程都必须讨论Transformer作为当前最先进的架构。本书可作为参考，帮助读者巩固特定理解点，或探索Transformer在特定挑战中的应用。我们希望本书成为读者反复参考的资源，在面对不同挑战或理解不足时，能够获得洞见并加以应用。

## 本书涵盖内容

本书以深入的方式通过数学理论和实际应用案例，介绍Transformer的基础知识。

以下是每章的简要描述：

1.  [第1章](#ch1.xhtml) 将向读者介绍Transformer的时间线、历史及其对学术和工业世界的影响。随后，我们将根据分类学构建完整的路线图，说明每章如何从理论、实践和应用三个维度展开。本章还将深入探讨实际操作层面，包括所需资源、工具、书籍和课程，这些内容将在后续章节中被使用。

2.  [第2章](#ch2.xhtml) 首先介绍序列到序列（sequence-to-sequence）模型及其局限性。接着，本书逐步阐述Transformer的各个构建块，包括注意力机制、多头注意力、位置编码、残差连接以及编码器-解码器框架。这些功能单元均获得理论与实践的详细解析，帮助读者全面掌握该主题。最后，本章以机器翻译任务的真实案例展示Transformer的实际运作，结束本章。

3.  BERT的出现彻底改变了自然语言处理（NLP）领域，使得在许多传统上困难的任务上接近人类水平的性能成为可能。[第3章](#ch3.xhtml) 详细介绍BERT架构及其在预训练和微调过程中的应用，用于单文本/文本对分类、词符标记和问答系统等经典NLP任务。本章还讨论BERTology——关于BERT内部工作机制及其如何处理和分析文本与信息的研究领域。此外，还介绍了为提高效率而对BERT进行修改的深度学习架构（如RoBERTa），以及其他NLP应用（如表格数据处理的TaBERT）。章节以使用BERT进行情感分类和主题建模的实际案例结束。

4.  多语言迁移学习是Transformer架构产生重大影响的领域。[第4章](#ch4.xhtml) 介绍Transformer-based多语言架构的概览，以及跨语言迁移学习的预训练和微调方法。本章还提供了用于多语言NLP的最新基准指标的概述。进一步探讨了影响跨语言和零样本迁移学习的研究与技术，识别影响跨语言和零样本迁移的关键因素。最后，展示了使用多语言通用句子编码器进行零样本跨语言情感分类的实际案例。

5.  在[第5章](#ch5.xhtml) 中，我们讨论了对标准Transformer架构的多种修改，以应对长序列受限内存、提升模型速度和质量、以及改善文本生成和摘要效果。本章还探讨了知识蒸馏等核心思想，以及通过降低注意力机制的复杂度来提升计算效率的方法。本章包含一个案例研究，使用预训练Transformer模型进行情感分类，并深入分析模型多头注意力机制的内容。
