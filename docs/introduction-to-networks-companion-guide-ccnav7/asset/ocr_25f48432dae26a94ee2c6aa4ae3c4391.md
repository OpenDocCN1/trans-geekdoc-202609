The default gateway address is typically configured on all devices that will communicate beyond their local network.

To configure an IPv4 default gateway on a switch, use the ip default-gateway ip-address global configuration command, where ip-address is the IPv4 address of the local router interface connected to the switch.

# Figure 10-4  Remotely Accessing a Switch

In Figure 10-4, the administrator host would use its default gateway to send the packet to the G0/0/1 interface of R1. R1 would forward the packet to S1 out its G0/0/0 interface. Because the packet source IPv4 address is from another network, S1 would require a default gateway to forward the packet to the G0/0/0 interface of R1. Therefore, S1 must be configured with a default gateway to be able to reply and establish an SSH connection with the administrative host.

# Note

Packets originating from host computers connected to the switch must already have the default gateway address configured on their host computer operating systems.
