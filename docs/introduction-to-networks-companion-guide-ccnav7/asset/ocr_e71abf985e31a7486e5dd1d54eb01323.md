For this reason, symbols such as the # are often used. After the command is executed, the banner will be displayed on all subsequent attempts to access the device until the banner is removed.

Example 2-11 shows the steps to configure the banner on Sw-Floor-1.

# Example 2-11 Configuring a Banner

```
Sw-Floor-1# configure terminal
Sw-Floor-1(config)# banner motd #Authorized Access Only#
```
