

## DeFi 与 CeFi 对比

| 特性 | DeFi (去中心化金融) | CeFi (中心化金融) |
| :--- | :--- | :--- |
| **准入机制** | 无许可 | 基于许可的系统 |
| **身份验证 (KYC)** | 不需要了解你的客户协议 (KYC) | 需要了解你的客户 (KYC) |
| **代码/决策透明度** | 开源 —— 鼓励自由协作 | 闭源 —— 决策在闭门造车中做出 |
| **基础设施** | 生成于区块链之上 | 建立在旧有基础设施之上 |
| **成本结构** | 更便宜，主要为网络费用 | 更昂贵 —— 中介机构收取高额费用 |
| **抗审查性** | 抗审查 | 可被审查 |
