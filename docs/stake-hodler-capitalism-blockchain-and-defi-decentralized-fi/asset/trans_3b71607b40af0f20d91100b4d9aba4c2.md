

# 第 3 章：智能合约简介

> “智能合约……保证一组非常、非常具体的结果。绝不会有任何困惑，也绝不会有任何诉讼的必要。”
> —— 区块链服务商 Bloq 的所有者 Jeff Garzik

智能合约就是运行在以太坊区块链上的程序。它是一组位于特定以太坊区块链地址的代码（函数）和数据（状态）。智能合约是一种以太坊账户形式。这意味着它包含资金余额，并能在网络上发起交易。然而，它不能被网络成员控制。相反，它被编程并分发到网络上，按预设或预编码的方式运行。用户账户可以通过发送执行智能合约中定义函数的交易来与智能合约交互。智能合约像普通合约一样规定规则，并通过代码自动强制执行这些规则。智能合约协助以透明、非冲突的方式进行金钱、财产、股份或任何有价值物品的交换，同时省去了中介服务。特定的输入保证特定的输出。这种逻辑编码在自动售货机中，正如编码进智能合约中一样。任何人都可以编写智能合约并在网络上使用它们。你只需要学习智能合约语言编程，并拥有足够的 ETH 来使用合约。使用智能合约在技术上属于一笔交易，因此你必须支付 Gas 费，就像支付简单的 ETH 转账费用一样。然而，使用合约的 Gas 成本要高得多。以太坊提供了一种适合编码者编写智能合约的语言，称为“Solidity”。

## Solidity

Solidity 是一种用于编写智能合约的面向对象编程语言。以太坊的优势在于智能合约可以用一种相对对开发者友好的语言进行编程。如果你有 Python 或 JavaScript 经验，你可以找到一个使用熟悉语法的智能合约框架。智能合约规范以太坊平台上账户的行为。Solidity 受 C++、Python 和 JavaScript 启发，并为以太坊虚拟机（EVM）设计。它主要用于在以太坊等各种区块链平台上执行智能合约。它由 Christian Reitwissner、Alex Beregsazi 和其他几位以太坊前核心贡献者开发，旨在在区块链平台上实现智能合约。Solidity 编程语言主要用于以太坊虚拟机的代码开发和实现。此外，智能合约以与传统合约相同的方式确立协议的规则和惩罚，但也会自动强制执行这些义务。

## Vyper

Vyper 允许你在以太坊上编程，以太坊是一个基于区块链的虚拟机，它允许在无需中心化或可信中介的情况下设计和执行智能合约。它的开发旨在改进另一种以太坊智能合约语言 Solidity，通过限制不安全的做法和提高可读性来实现。Vyper 致力于高效地运行智能合约的安全性和审计。Vyper 是一种实验性的合约编程语言，类似于 Python 且为静态编写。就像面向对象编程（OOP）中的对象一样，每个合约都有状态变量、函数和相似的数据类型。合约特有的特性包括事件通知监听器、自定义全局变量和全局常量。以太坊合约实例包括众筹、投票和盲拍等。尽管如此，它在使用前必须经过编译，以便以太坊 VM 能够推断并存储合约。智能合约在以太坊上公开可用，可被视为开放 API。这意味着其他智能合约可以调用其智能合约，从而极大地扩展其功能。合约也可以激活其他合约。就其本身而言，智能合约无法发送 HTTP 请求，因此无法接受“实际”事件信息。这是有意为之，因为使用外部信息可能会破坏对安全性和去中心化至关重要的共识。

## 智能合约的操作流程

智能合约是用于执行合约全部或部分内容的自动化计算机代码。它通常保存在基于区块链构建的平台上。此类代码可能仅代表当事人之间的合约，也可能用于支持标准文本合约并遵守特定条款，如从一方向另一方转移资金。因此，多个区块链节点可以受益于区块链的持久性、安全性和不可篡改性。这同样意味着，当一个新区块被整合进区块链时，代码基本上就会执行。在交易开始时，如果参与方表明满足了特定参数，代码将自动执行由这些参数触发的操作。代码仅在交易发起时才会执行此操作。如果没有此类交易，代码将不执行任何操作，直到交易被发起或激活。大多数智能合约使用一种语法接近许多广泛使用的计算机编程语言（如 Solidity）的编码语言进行编写。目前，智能合约的因素和批准标准必须被明确指定。它也需要被设定为客观目标。这意味着诸如“如果发生‘A’，则执行步骤‘B’”之类的逻辑。因此，智能合约的实际工作是一项非常基础的任务，例如根据特定标准，例行地将一些加密货币从一方的钱包转移到另一方的钱包。随着区块链的增长和完善，或转移到链上的资产数量增加，智能合约将变得更加复杂并处理复杂交易。更多关于智能合约应用的内容将在“Stake Hodler Capitalism: Smart Contracts and DApps”（权益持有者资本主义：智能合约与 DApps）中介绍。开发者已经将交易流程中的多个步骤结合起来，以创建更高级的智能合约。然而，代码定义更多主观法律标准（如当事方是否遵守合理的商业运营标准，或对赔偿和赔偿条款的需求）至少还需要几年时间。已经有许多律师事务所聘请开发人员，以便参与合同协议的新时代。在智能合约部署到任何区块链之前，另一个必不可少的要求是支付合约的执行费用。例如，如果智能合约要在以太坊区块链上执行，合约程序通常在以太坊虚拟机（EVM）上运行，合约当事方使用称为“Gas”或以太币的以太坊加密货币支付交易费用。智能合约越复杂，取决于交易阶段，你需要支付的 Gas 量就越高以履行智能合约。因此，Gas 目前是防止过于复杂或大量智能合约导致 EVM 拥堵的重要关卡。

目前，智能合约非常适合例行执行两类“交易”。第一类是确保在特定触发条件下支付资金，第二类是如果未履行特定规定的合约条款，则对财务条款实施制裁。在这两种情况下，一旦智能合约部署并开始运行，就不需要人工干预或司法干预。这降低了合约系统的运营和执行成本。例如，智能合约可以消除被称为“采购付款”的运营漏洞。如果货物到达仓库并完成所需的扫描流程，智能合约会立即发起必要的授权申请，并在收到授权后瞬间将资金从买方转移给卖方。卖方将更快收到款项，不再需要催款，买方则将支付成本降至最低。这可以影响对营运资金的需求，并为双方简化金融交易。一旦生效，智能合约可以编码为在未收到付款时禁用对基于互联网资产的访问。例如，如果未付款，访问特定内容的权限可能会被自动撤销。根据以太坊程序员 Vitalik Buterin（27 岁）的解释，他是这样阐述智能合约的：在智能合约系统中，资产或货币被转入一个程序，该程序执行代码，在某个时刻，它自动验证条件并决定资产应归人员 X 还是退还给人员 Y，或者是否应即时退还给发送者，又或是两者的某种组合。去中心化账本也会保存和复制文档，这赋予了它一定的安全性和不可篡改性。例如，如果你从某人那里租公寓，你可以通过区块链用加密货币支付来完成。然后，你会获得一张存放在你与房东的虚拟合约中的收据，房东则会给你一个在特定日期送达的数字入门钥匙。假设钥匙没按时送达，区块链将退还款项。然而，如果钥匙在租赁日期前发送，该功能会将其保存，从而在指定日期到来时分别将钥匙和费用释放给你和你的房东。系统基于“如果-那么”前提运行，并经常由数百人见证，所以你可以放心地期待完美的交付。如果你的房东给你钥匙，他肯定会收到钱。如果你发送数笔比特币，你将收到钥匙。文档在时间到期后即时作废，且在你们双方不知情的情况下，代码无法被干扰或篡改，因为所有参与者始终会被通知发生的任何交换。你可以将智能合约用于从金融衍生品、合同违约、金融服务、保险费、财产法、信用执法、法律程序到众筹协议等任何情况。

## 如何使用智能合约？

据 IBM 区块链技术副总裁 Jerry Cuomo 称，智能合约可用于从金融服务、医疗保健、保险等所有领域。以下是智能合约的利用方式：

### 政府

有了智能合约，公民不再需要担心选票被操纵，因为它将通过生成一个持久、防篡改且安全的系统来消除所有顾虑。受账本保护的选票需要被解码，并需要大量的计算能力才能访问。由于没有人能拥有针对它的那么多计算能力，因此需要神一般的计算能力才能黑入或渗透系统。此外，智能合约还能提高低投票率。许多不参与源于一个不平衡的系统，包括排队、出示身份证件和填写表格。志愿者甚至可以将投票转移到线上，成千上万的人将作为一个群体出来为他们的领导人投票。

### 管理

区块链不仅提供单一账本作为信任来源，而且由于其准确性、透明度和自动化系统，通信和工作流程中可能出现的复杂问题也得以解决。通常，业务运营必须来回周旋，耐心等待内部和外部机构理顺后的批准。区块链账本优化了这一流程，还消除了独立程序中可能自然发生的任何问题，这些问题可能导致昂贵的诉讼和结算延迟。

### 汽车

毫无疑问，我们正从懒惰的前人类脊椎动物进化为极其聪明的机器人。如果我们设想一个万物自动化的未来，我们会意识到随着智能手机、智能眼镜甚至智能汽车的出现，我们几乎已经到达了。这是智能合约可以提供帮助的领域。例如，让我们以自动驾驶或自动泊车车辆为案例研究。在这方面，智能合约可以设置某种预言机，判断车祸责任在于驾驶员、传感器还是车辆的其他部件。在智能合约的帮助下，汽车保险公司可以根据客户驾驶汽车的地点和条件以不同方式制定价格。更多关于智能合约应用的内容将在系列的第二部分“Stake Hodler Capitalism: Smart Contracts and DApps”中介绍。

### 房地产

通过智能合约可以赚取更多利润。通常，你需要支付中介（如代理人或报纸）费用进行广告宣传，然后再次付费以确认对方是否已支付租金并完成剩余流程，这针对的是想要出租公寓的人。有了智能合约，账本降低了你的成本。你只需用比特币支付，并将合约编码到账本上。每个人都能看到你做了什么，并实现即时履约。经纪人、房地产经纪人、硬钱贷款人和其他与房产相关的人员都能获利。

### 医疗保健

个人健康记录可以用私钥编码并分类存储在区块链上，该私钥仅授予预先选定的特定个人访问权限。同一方法可用于确保根据 HIPAA 法规（健康保险流通与责任法案）安全、机密地进行研究。此外，手术收据可存储在区块链上，并作为交付证据自动发送给保险提供商。账本还可用于一般医疗管理，如监管药品、监管合规性、检测结果和组织医疗配给。

## 智能合约的优势

智能合约是以太坊和其他加密货币生态系统相对于普通法币的关键优势。以下是使用智能合约可以获得的一些收益：

### 自主性

既然是你自己达成协议，就无需依赖经纪人、律师或任何其他中介进行确认。这也消除了被第三方操纵的风险。由于工作由网络自动完成，而不是由一个或多个可能有偏见或可能犯错的人完成，你的利益得到保障。

### 信任

你的数据和文件加密在共享账本上，因此没有人能说文件丢失或放错地方。你需要时总能信任地找到它。

### 备份

你的银行有可能弄丢你的储蓄账户。然而，在区块链上情况不同，你非常安全。既然你所有的朋友（节点）都支持你，你的文档就被复制了无数遍。

### 安全性

你不必担心安全性，因为你的文档受密码学和网站加密保护。黑客攻击不是一种选择，要破解代码并渗透该平台上的文档，需要一个极其疯狂且天才的黑客。

### 速度

手动处理文档需要花费大量时间和文书工作才能完成。另一方面，智能合约使用软件代码自动化任务，从而减少处理业务流程或任何其他文档工作的时间。

### 节省

由于中介的存在被排除在外，智能合约通过这一豁免为你省钱。例如，你可能需要支付经纪人或公证人来见证你的交换或帮助你监控它。

### 准确性

计算机化合约以其速度、低成本以及避免填写大量表格带来的错误的能力而闻名。在这里，错误几乎不存在或被极小化。

## 智能合约的问题

> “智能合约是企业和区块链技术落地的关键所在。虽然区块链上出现了一些高度专业化的分布式金融服务用例——例如缅甸仰光证券交易所的支付账本服务。有趣的是建立在区块链之上的服务。仰光交易所解决了一个交易系统中的分布式结算问题，该系统每天仅同步交易两次。但智能合约的自主执行能力将区块链的交易安全保证扩展到了需要复杂、不断演变的上下文转换的场景。正是这种可能性让 Amazon、Microsoft、Azure 和 IBM Bluemix 从云端推出了区块链即服务（BaaS）。”
> —— Patrick Hubbard，SolarWinds 首席极客。

智能合约远非完美，即使听起来多么美妙和令人惊叹。例如，软件缺陷可能导致严重问题，政府可能难以监管此类合约，政府在如何对这些智能合约交易征税方面也可能遇到问题，根据前面的租赁例子，也可能存在发送错误代码的问题，或者发送了正确的代码，但在租赁日期到来前，你的公寓被征用（即未经你许可被征为公共用途）。其中一些问题可能在法庭上被撤销，但区块链是另一码事。无论发生什么，合约都将继续执行，直到规定的结束时间。智能合约的挑战源源不断。尽管专家们正试图纠正它们并使其完美，但这些重要问题阻碍了一些潜在用户的加入。

## 可处理智能合约流程的区块链

### Bitcoin

Bitcoin 是执行 Bitcoin 交易的完美场所；然而，它处理智能合约的能力有限。

### Side Chains（侧链）

这是与 Bitcoin 并行运行的区块链的另一个名称，它们提供比 Bitcoin 更广泛的合约处理范围。

### NXT

NXT 是一个常见的区块链论坛，拥有有限的智能合约模板选择。你必须使用提供的任何资源，因为你无法独立于这些资源进行编码。

### Ethereum

Ethereum 是一个已知的区块链平台，是编码和处理智能合约最先进的平台。你可以随心所欲地编写代码，但必须用“ETH”代币支付算力费用。智能合约能影响的行业数不胜数，从医疗保健、房地产甚至法律。其潜力的清单源源不断。
