# 7.3.2 Cloud Computing and Service Provision

Rather than storing IoT healthcare facts over the blockchain, data about personnel is maintained on cloud computing servers in this situation. In other circumstances, workers may desire their company’s data to be housed in the cloud, allowing an outside partner to offer easy, high-tech services. The information saved in the cloud is processed in discrete, numbered pieces. The device is identified via block numbers and a hash of the stored data. When data matches a preset block number and the hash value is detected, a customer can access the device. Information gathered from users is stored in blocks and retrieved in a FIFO (first-in, first-out) fashion using a hash key [16,17].
