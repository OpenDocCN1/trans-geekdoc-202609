# 8.12 Way Forward/Solutions

# 8.12.1 Traditional

As was already stated, log administration is an essential problem in cloud computing. A variety of models can be applied to cloud computing monitoring. One recommendation is to save logs of any operations that alter an instance’s status using special transport layer protocols before delivering the information to a central cloud log storage site.

_Retrieval of cloud data on a specific plane._ The difficulty of data collecting in the forensic investigation can be lessened by granting the investigators access to a distinct plane for controlling the data retrievals they require. This level of cloud infrastructure requires trustworthy parties to keep it up-to-date.

The issue of the absence of a legislative framework for cloud forensics can be solved by creating a special service-level agreement (SLA) between customers and cloud service providers (CSPs) that stipulates the laws to be followed in the case of felony investigative activities.
