In the case of procedural to object-oriented transformations, there may exist various problems that are too complex to solve accurately while maintaining full automation. We have also analyzed the relations between automation and precision. In doing so, we have uncovered that transformation which are both automatic and precise are the most desirable.

We have also presented the case study of converting C pointers to objects. This is a complex problem that existing literature does not have an automatic and highly precise solution in literature. We have proposed a solution using both static analysis and machine learning. We have evaluated that the deep learning approach produced far better results in every aspect. Thus, we have found increasingly useful learning methods in code modernization.

In terms of future work, we plan to collect more sample data and thus further improve our proof of concept. Our goal is to reach an F1 score of at least 0.9 using machine learning to solve other difficult cases of code modernization, further proving that this approach is superior to previous approaches.
