
## 11  

Adversarial Fine-Tuning and Model Reprogramming  

Adversarial fine-tuning and model reprogramming represent some of the most technically sophisticated and strategically consequential threats in the AI security landscape. These attacks exploit the very mechanisms that make foundation models adaptable—namely, gradient-driven updates, semantic conditioning, and prompt sensitivity—to embed covert behaviors that can lie dormant until triggered. Understanding the subtle but powerful ways in which generative models can be manipulated post-pretraining is essential to securing their use in regulated, safety-critical, or high-trust environments. These threats are not theoretical—they persist through model compression, propagate across architectures, and evade detection by standard evaluation protocols.
