
-   [降低联邦中毒攻击的努力通常依赖于鲁棒聚合技术，如 `Krum`、`中位数聚合` 或 `规范剪辑`。虽然这些方法对极端更新提供了一定的抵抗能力，但它们易受多个客户端协同攻击或精心调制的中毒梯度的影响。此外，它们往往以牺牲模型性能为代价来提高安全性，导致在联邦环境中常见的非IID数据分布上准确率下降。这种在强健性与实用性之间的张力为试图防御复杂中毒策略的实践者创造了持续的困境。

-   采用持续学习或在线适应的联邦学习框架特别容易受到慢速中毒攻击的影响。在这些系统中，模型会持续响应新数据而不断演变，使得区分合法数据漂移与对抗性漂移变得困难。攻击者可以通过在数百个训练轮次中逐步调整模型行为，确保中毒行为隐藏在长期适应趋势之中。这些攻击能够规避取证检测，因为行为变化是逐步累积的，看起来像是环境学习的自然后果。

-   检测和归因联邦环境中的中毒需要重新思考关于信任、可见性和数据来源的核心假设。防御策略必须同时考虑更新的具体表现、提交更新的主体、频率以及模式。身份验证、行为基线和来源标记可以提供部分缓解，但可能与隐私保障相冲突。随着联邦学习作为保护隐私的解决方案不断演进，其安全模型也必须同步演进，认识到去中心化不仅带来强健性，还引入了丰富且防御不足的攻击面。

-   **针对强化学习（RL）系统的中毒攻击**

-   强化学习系统因其依赖于与训练环境的迭代交互以及奖励反馈循环，而特别容易受到中毒。与监督学习不同，监督学习的输入输出是静态且基于标签的，而RL代理会根据经验序列、奖励和状态转换不断更新其策略。这种动态性为攻击者提供了多个入口，可以在不被立即发现的情况下微妙操控学习过程。中毒可能导致代理学习到有缺陷或可被利用的策略，这些策略在验证阶段表现正常，但在特定运行条件下表现不当。奖励结构的复杂性和时间依赖性使得检测此类操控尤其困难。

-   RL 中中毒的主要入口之一是 `经验回放缓冲区`。许多深度RL算法依赖于存储的过去经验，以提高数据效率和政策收敛。攻击者若获得缓冲区的访问权限，或能够影响喂养该缓冲区的环境，便可以注入损坏的状态-动作-奖励转换，使代理的策略梯度更新产生偏差。这些恶意经验看似合法，但被构造用来 subtly 强化不良行为或惩罚最优行为。即使只有少量的中毒条目，在 off-policy 算法中，这些条目会显著影响策略演化轨迹，因为该类算法大量依赖历史交互。

-   奖励塑造攻击针对代理最信任的信号：`奖励`。通过引入错误、延迟或语境误导的奖励，攻击者可以影响优化景观，使其偏向次优或有害的行为。这些中毒奖励通常并非 blatant 的错误赋值，而是对细微的扭曲，只要在足够多的episode中持续存在，就能重新引导代理的学习优先级。在奖励函数由外部定义或受噪声影响的环境中，区分合法随机波动与对抗性操控变得非平凡。奖励中毒还可以利用长期依赖，通过创建反馈循环在训练过程的后期才显现其影响。

-   直接操纵训练环境本身提供了另一种强大的中毒通道。`环境中毒` 涉及修改状态转换、观测模型或环境动态，以系统性错误的方式影响学习策略。这可能包括扭曲模拟环境中的物理属性、引入隐藏变量以条件化策略选择，或修改代理用于推导动作的状态表示。这种攻击在从仿真到现实迁移时尤为有效，因为代理在受控环境中学习，随后部署到现实世界时往往假设训练与部署动态一致。

-   攻击者还可以在 `策略梯度更新` 中直接注入中毒，通过操纵特定的状态-动作对。这些输入被设计为看似与环境统计一致，但经过精心调整，能在随机梯度更新中产生不成比例的影响。例如，一个被构造的中毒状态可能在概率上略微增加特定动作的出现概率。随着多个epoch 的强化，这些小偏差会累积，导致代理系统性地偏好次优或攻击者期望的策略。由于中毒与代理学习动态交织，检测需要检查中间梯度路径，这在大规模实现中往往不可行。

-   `时间中毒` 引入了更为微妙且高级的攻击维度。攻击者通过操纵事件序列或奖励结构随时间变化，伪造远时相事件之间的虚假关联。代理在发现这些模式时会将其内化为因果关系，并将其纳入政策决策中。例如，在最优动作之后延迟给予负面奖励，会教会代理避免该动作，尽管其实际效用较高。时间中毒利用了代理对时间结构的外推倾向，植入在特定情境下难以诊断的失效策略。

-   训练过程的关键阶段，如早期策略形成或学习率波动较大的时刻，特别容易受到持久性中毒的影响。攻击者会在这些敏感窗口中精准注入中毒转换或奖励，使其在后续训练轮次中保持稳定。这些弱点通常不会导致灾难性失败，而是表现为在特定边缘情况、压力下的性能下降或策略对轻微扰动的脆弱性——这些都可能在部署后被利用。

-   `策略蒸馏`，一种常见的RL压缩或转移学习做法，也引入了额外的中毒风险。在教师-学生框架中，攻击者可以中毒教师策略的训练过程，或在学生策略学习时篡改模仿过程。这使得恶意行为能够在不被发现的情况下从一个模型传递到另一个模型，保持功能准确性的同时植入结构性漏洞。由于蒸馏策略通常仅凭性能指标进行评估，从教师传递下来的潜在弱点可能在继承模型中被忽视。当原始训练数据或环境不再可得时，审计这种被污染的行为变得尤为困难，进一步复杂化了审计工作。
