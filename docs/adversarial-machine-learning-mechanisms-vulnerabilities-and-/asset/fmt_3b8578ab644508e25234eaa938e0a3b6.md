**Reward-Shaping Attack**

: A reward-shaping attack occurs when an attacker manipulates the reward function or feedback process of a reinforcement learning system to encourage undesirable or harmful behavior. This may lead to misaligned learning, goal divergence, or reward hacking. It poses a serious threat to agentic systems with online learning. 

**Robust Accuracy**

: Robust accuracy measures how well a model performs under adversarial conditions or input perturbations. Unlike standard accuracy, it evaluates performance in the presence of attacks or noise. High robust accuracy is a key indicator of resilience in safety-critical applications. 

**RobustBench**

: RobustBench is a standardized benchmark and leaderboard for evaluating the adversarial robustness of machine learning models. It includes curated datasets, evaluation metrics, and attack scenarios. It helps researchers and practitioners compare defenses and track progress in adversarial machine learning. 

**Role Reframing**

: Role reframing is a prompt injection technique where an attacker changes the perceived identity or context of the model—such as making it believe it is a fictional character, alternate persona, or different system. This can trick the model into bypassing rules or generating otherwise restricted content. 

**Roleplay Exploit**

: A roleplay exploit manipulates a language model by framing prompts as fictional or hypothetical scenarios, which can lead the model to bypass safety filters and generate restricted content. By pretending the model is playing a character, attackers can sidestep alignment mechanisms and invoke otherwise disallowed behaviors. 

**Runtime Anomaly Detection**

: Runtime anomaly detection is the process of monitoring a model's behavior during inference to identify deviations from expected norms. It includes detecting abnormal outputs, API usage, or execution patterns. This form of defense is critical for real-time systems that must respond to evolving adversarial threats. 

**Saliency Map Divergence**

: Saliency map divergence occurs when visualizations of model attention or feature importance differ significantly across similar inputs. This divergence can indicate instability, adversarial manipulation, or hidden biases. Tracking saliency consistency helps detect subtle attacks and evaluate explanation reliability. 

**Security Debt**

: Security debt refers to the accumulation of unresolved security risks, vulnerabilities, or weak assumptions in AI systems over time. As models evolve or become more integrated, unaddressed security gaps can compound and become harder to manage. Recognizing and reducing security debt is vital for long-term system safety. 

**Semantic Ambiguity Injection**

: Semantic ambiguity injection involves crafting inputs that exploit multiple interpretations or unclear meanings to mislead AI models. These inputs may appear legitimate but result in unpredictable or harmful outputs. It is a common tactic in language models, especially in bypassing safety filters or triggering edge-case behaviors. 

**Semantic Boundary Exploitation**

: Semantic boundary exploitation targets the fine line between similar concepts in a model's latent or classification space. Adversaries craft inputs that hover near these boundaries, causing the model to flip between interpretations or classifications. This reveals the fragility of semantic decision-making in AI systems. 

**Semantic Collision**

: Semantic collision occurs when different inputs map to similar internal representations despite having different meanings. This can lead to misclassification, confusion, or blending of concepts in generative systems. Attackers may intentionally create collisions to inject malicious content masked as benign. 

**Semantic Drift**

: Semantic drift refers to the gradual shift in how a model understands or interprets language or concepts over time. This may occur due to new data, fine-tuning, or environmental changes. Adversaries may exploit drift to reintroduce deprecated or harmful behaviors that the model had previously unlearned. 

**Semantic Misalignment**

: Semantic misalignment happens when a model's interpretation of input diverges from the user's intended meaning. This disconnect can lead to inaccurate predictions or dangerous outputs. It is a core risk in natural language processing and instruction-following systems, particularly under adversarial influence. 

**Semantic Parsing**

: Semantic parsing is the process of converting natural language into structured representations, such as logical forms or command sequences. It enables models to interface with databases, APIs, or tools. Attackers may manipulate inputs to trick the parser into producing harmful or unintended interpretations. 

**Semantic Perturbation**

: Semantic perturbation involves altering input text in ways that preserve its overall meaning while changing its form, with the goal of misleading a model. This may include rephrasing, using synonyms, or adjusting grammar. It is a common method for bypassing content filters or evading classification systems. 

**Semantic Proximity**

: Semantic proximity refers to how closely two concepts or inputs are related within a model's latent or embedding space. High proximity suggests the model considers them similar, which can influence classification or generation. Adversaries may exploit this by crafting inputs that appear harmless but fall near dangerous concepts. 

**Semantic Segmentation Evasion**

: Semantic segmentation evasion targets models that classify each pixel in an image according to its object class. Attackers modify inputs to cause segmentation errors, such as hiding objects or misclassifying backgrounds. This is particularly critical in autonomous vehicles and medical imaging, where pixel-level precision is vital. 

**Sequential Drift**

: Sequential drift is a gradual change in model predictions over time within a single session or task sequence, often caused by accumulated errors or adversarial inputs. This drift may not be immediately detectable but can degrade output quality or alignment. It is particularly relevant in dialogue systems and long-form generation. 

**Sequential Reasoning**

: Sequential reasoning refers to a model's ability to carry out multi-step logic or inference, where each step builds on the previous one. Adversaries may target this process by introducing misleading inputs early in the sequence to bias the outcome. Robust sequential reasoning is essential for mathematical problem solving, planning, and agentic behavior. 

**Session Carryover**

: Session carryover is the persistence of context or memory across user interactions in multi-turn systems. While useful for continuity, it can be exploited if adversaries inject harmful context that influences future outputs. Managing and sanitizing session memory is critical in persistent AI assistants. 

**Session Memory Poisoning**

: Session memory poisoning is a specific attack where an adversary intentionally inserts malicious or misleading information into a model's session memory. This poisoned memory can affect future outputs or reasoning, even if the attacker is no longer interacting with the system. It is a growing concern in models with long-term conversational memory. 

**Softmax Attention**

: Softmax attention is a mechanism used in transformer models to weigh input tokens during processing, using a softmax function to assign relative importance. It determines what the model “pays attention” to at each layer. Manipulating attention weights through adversarial inputs can redirect model focus and cause misinterpretation.
