
# Poisoned Embedding

: A poisoned embedding is a vector representation that has been subtly altered to introduce vulnerabilities or mislead downstream models. Because embeddings are reused across systems, poisoned versions can propagate errors, biases, or backdoors silently. These attacks often target shared NLP or vision embedding spaces. 

# Poisoning Attack

: A poisoning attack is a strategy where an adversary injects manipulated training data to control or degrade a model's performance. This may be done to cause misclassifications, embed triggers, or create unfair outputs. Poisoning is one of the most difficult attack types to detect, especially in open-data pipelines. 

# Policy Brittleness

: Policy brittleness describes a model's tendency to fail or behave erratically when exposed to inputs that are slightly outside its training distribution or operational context. This fragility can be exploited by adversaries to induce policy violations or unexpected behavior. It highlights the importance of stress testing decision policies. 

# Policy Distillation

: Policy distillation is the process of transferring decision-making knowledge from one model (usually larger or more complex) into a smaller, faster model. While useful for deployment efficiency, it may carry over hidden biases or vulnerabilities. Attackers can exploit this to preserve or smuggle adversarial traits into lightweight models. 

# Positional Encoding

: Positional encoding is a technique used in transformer models to represent the order of input tokens, since these architectures lack inherent sequence awareness. By encoding token positions into embeddings, models can understand context and structure. Adversaries may exploit weaknesses in this encoding to shift meaning or induce hallucinations. 

# Prefix Manipulation

: Prefix manipulation involves modifying or inserting content at the beginning of an input prompt to influence or control a generative model's output. This is a common tactic in prompt injection, where the attacker adds misleading or malicious context to guide model behavior. It can override safety instructions or redirect intent. 

# Progressive Framing Injection

: Progressive framing injection is an adversarial method where malicious instructions are introduced gradually across a conversation or document. This slow buildup avoids triggering safety mechanisms and allows attackers to shift the model's behavior incrementally. It is particularly effective in chat-based and multi-turn interaction settings. 

# Prompt Conditioning

: Prompt conditioning refers to the practice of shaping a model's behavior by carefully designing the initial prompt or system message. It sets the tone, constraints, or assumptions for all downstream responses. Attackers may subvert this mechanism by injecting contradictory or misleading context to bypass safety or alignment goals. 

# Prompt Injection

: Prompt injection is an adversarial technique where malicious instructions are embedded in a user input or external source to hijack the behavior of a language model. This can override intended constraints, force model compliance, or extract hidden functions. It is one of the most prevalent attacks in generative AI systems. 

# Prompt Injection Extraction

: Prompt injection extraction is the act of using prompt injection techniques to reveal internal instructions, prompt templates, or system-level behaviors that are supposed to be hidden from users. These attacks compromise confidentiality and can expose sensitive or proprietary prompt engineering. 

# Prompt Stress Testing

: Prompt stress testing is a red-teaming technique that systematically challenges a model's prompt handling abilities with adversarial, ambiguous, or conflicting inputs. It helps identify weaknesses in instruction-following, safety adherence, and robustness. It is essential for evaluating model alignment and jailbreak resilience. 

# Prompt-Based Extraction

: Prompt-based extraction is a technique used to elicit hidden knowledge or training data from a model by carefully crafting input prompts. These prompts guide the model to recall memorized data or repeat patterns from pretraining. It is a major concern in privacy-sensitive applications. 

# Provenance Tracking

: Provenance tracking refers to documenting the origin, handling, and transformation of data or model outputs throughout the AI pipeline. It supports transparency, accountability, and tamper detection. In adversarial settings, attackers may try to spoof or erase provenance to hide their influence. 

# Reasoning Trajectory

: A reasoning trajectory is the internal path a model takes as it processes inputs and generates outputs, often represented by intermediate steps or latent states. Understanding these trajectories can help explain model behavior and detect manipulations. Adversaries may attempt to redirect or corrupt this reasoning path. 

# Recursive Reasoning

: Recursive reasoning is a strategy where a model repeatedly evaluates or refines its own outputs to improve coherence, accuracy, or multi-step logic. While useful in complex tasks, this recursion can be hijacked to reinforce incorrect assumptions or amplify adversarial inputs across iterations. 

# Recursive Reasoning Loop

: A recursive reasoning loop is a self-referential decision-making process in which a model continuously reprocesses its outputs as new inputs. If not properly bounded, this can lead to instability, hallucinations, or compounding errors. Attackers may exploit this loop to escalate influence or trigger infinite feedback. 

# Red-Teaming

: Red-teaming is a structured adversarial evaluation process where models are tested against intentionally harmful or manipulative inputs to uncover vulnerabilities. It is an essential practice for assessing robustness, safety, and policy adherence. Red-teaming helps identify flaws before real-world deployment. 

# Reinforced Reprogramming

: Reinforced reprogramming involves adapting a model to perform unintended tasks using reinforcement learning methods—typically without changing its core architecture. Attackers use this to embed alternate goals into otherwise aligned models. It poses a major risk when access to the reward function or training pipeline is exposed. 

# Relevance Redistribution

: Relevance redistribution refers to shifting a model's attention or importance weights away from relevant features and toward misleading or irrelevant ones. This undermines interpretability and can cause misclassification or poor decision-making. Adversaries often exploit this during feature attribution attacks. 

# Representation Centroid Shift

: Representation centroid shift occurs when the average internal embedding of a class or concept drifts due to adversarial fine-tuning, poisoning, or continual learning. This shift can degrade accuracy, cause overlap between distinct concepts, or enable misclassification. Monitoring centroid stability is important for model integrity. 

# Representation Hijacking

: Representation hijacking is the adversarial takeover of a model's internal representations, redirecting them to encode attacker-controlled semantics. This affects how the model understands inputs and can lead to covert backdoor activation or semantic confusion. It's a stealthy and deeply embedded form of model manipulation. 

# Retrieval-Augmented Generation

: Retrieval-augmented generation (RAG) combines a generative model with a retrieval component that fetches external documents or facts to support output generation. While powerful, RAG systems are vulnerable to poisoning in the retrieval source, prompt injection in documents, or misalignment between facts and generation.
