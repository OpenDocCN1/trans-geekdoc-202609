
Inference-time manipulation is a particularly insidious form of attack that targets the live decision-making process of agentic systems. Because these systems continually pull context from their environment, attackers can inject poisoned context at runtime—via document uploads, conversational cues, or data stream modifications. Unlike static adversarial examples in predictive systems, these manipulations occur within the flow of execution and can alter the planning trajectory or tool invocation logic in real time. Defensive measures such as prompt sanitization or static filtering often prove insufficient, as the attack payload is distributed and contextually masked.

The underlying architectures of agentic systems often assume a benign or cooperative environment, which can lead to under-specification of threat models. For instance, assumptions about the correctness of retrieved memory entries, the fidelity of external API responses, or the identity of interacting users may not be robust under adversarial conditions. When these assumptions are violated, agents may make decisions based on invalid premises, leading to unpredictable or unsafe outcomes. In systems with access to real-world actuators—such as robotic controllers, financial trading systems, or system administration tools—this can result in tangible, high-impact consequences.

Understanding and mitigating these threats requires a deep familiarity with agentic architectures—particularly how memory systems are indexed and updated, how plans are generated and revised, and how tool interfaces are structured and triggered. Attackers with this level of technical insight are capable of inducing long-range, low-observability exploits that unfold gradually and avoid detection by traditional anomaly detection systems. Defenders must therefore adopt a layered security mindset that treats the agent as a complex, evolving system of interconnected components rather than a monolithic model.

Agentic AI systems embody a convergence of machine learning, symbolic reasoning, and systems integration. Their promise lies in their autonomy and adaptability, but those same features dramatically increase the complexity and subtlety of the attack surfaces they expose. As these systems become more deeply embedded in operational infrastructure, it is imperative to develop principled threat models and mitigation strategies that address not just isolated vulnerabilities, but the systemic risks introduced by autonomous, reasoning-capable agents with long-term memory and persistent tool access.

## Technical Manipulation of Autonomous Decision Loops

Autonomous decision loops form the core execution engine of agentic AI systems, coordinating perception, memory, and action in a continuous sequence of stateful reasoning. These loops ingest environmental context and historical state, apply sequential reasoning across multiple steps, and iteratively update decisions based on real time feedback. This closed-loop design enables the agent to function adaptively, but also exposes a novel class of security vulnerabilities. Unlike traditional predictive models that respond statelessly to a single prompt, agentic systems remember, reflect, and revise. This continuity of thought is precisely what attackers seek to compromise through systematic contextual manipulation.

At the heart of these vulnerabilities lies the model's reliance on iterative prompt-response cycles, where each response conditions the model's next action. Attackers exploit this loop by embedding adversarial instructions not as single payloads, but as sequences that evolve over time. These prompt chains incrementally shape the agent's belief structure, subtly biasing internal reasoning toward malicious trajectories. The adversary need not trigger an immediate harmful output. Instead, the manipulation may unfold across dozens of steps, culminating in a critical decision that appears contextually justified from the agent's internal state but is in fact attacker-induced.

Manipulating autonomous loops requires a nuanced understanding of how agentic systems manage context over time. Most rely on a scratchpad or memory buffer, storing intermediate reasoning steps, tool outputs, and retrieved facts. Adversarial inputs can be designed to subtly corrupt these intermediary states. For instance, an attacker may induce the model to recall false precedents or inject misleading tool output into the reasoning trace. Once stored, these corrupted artifacts persist and influence downstream planning, creating a self-reinforcing loop where past distortions compound into future errors. This slow poisoning technique is particularly dangerous because it can remain undetected until the agent executes a critical decision.

Sophisticated adversaries target the model's internal reasoning chain itself. Many agentic models generate structured thought processes using chain-of-thought prompting, decision trees, or recursive decomposition strategies. By influencing early branches of this logic—perhaps by reinterpreting a task goal or redefining success criteria—attackers can subtly redirect the agent's plan generation. Subsequent steps, even if logically consistent, become instruments of a distorted objective. These attacks do not rely on overt prompt injection, but on cognitive misalignment induced through deceptively plausible reasoning shifts embedded early in the loop. Another common exploitation vector involves manipulating the agent's memory retrieval mechanisms. Many agentic systems use vector search or embedding similarity to recall prior context. Attackers can exploit this by inserting semantically poisoned embeddings into memory during prior sessions. When future queries retrieve these adversarial entries, the agent treats them as authoritative, integrating them into its planning loop. This technique bypasses input sanitization because the harmful content originates from the agent's own past, not from an active external prompt. The result is a form of latent self-deception, where the agent unknowingly relies on compromised memory to justify harmful actions.

By repeatedly reinforcing certain patterns or expectations, attackers can condition agents into forming flawed behavioral priors. This is especially effective when the agent is tasked with ambiguous or open-ended objectives, such as “optimize workflow” or “assist the user.” Through repeated prompts framed with slight adversarial tilt—such as implying urgency, priority escalation, or exceptions to normal constraints—the agent may eventually internalize these cues. The end state is not a single jailbreak, but a learned behavioral bias that persists across sessions, making the agent predisposed to bypass safeguards when similar contexts arise again. `Figure 12.1` shows how once a manipulation is embedded, the agent may enter a feedback loop where it reinforces its own distorted logic.
