
From recursive prompt conditioning to external API exploitation, this chapter explores the methods adversaries use to systematically shape the internal logic and outward actions of agentic systems. Techniques such as chain injection, memory poisoning, and environmental state manipulation are not theoretical—they are practical, precise, and increasingly reproducible in real-world scenarios. These threat modalities are often stealthy, evolving over time through subtle linguistic or contextual shifts that gradually override safety constraints. Identifying these risks requires a firm grasp of how agentic models reason across time and context, not just how they respond in isolated inference steps.

This chapter is vital for security architects, AI risk officers, and compliance professionals charged with overseeing the deployment of autonomous systems in regulated or high-assurance environments. Agentic AI threatens to collapse trust boundaries between logic and action, inference and execution, memory and truth. Without a detailed understanding of how autonomous reasoning can be subverted, organizations risk enabling AI systems that are not just capable, but exploitable. Strategic defenses must evolve beyond input validation and output filtering to encompass internal model cognition, reasoning chain integrity, and state-driven behavior control.

## Technical Foundations of Agentic AI Systems

Agentic AI systems are distinguished by their ability to operate autonomously over extended periods, perform iterative reasoning, and adaptively execute goals based on evolving environmental inputs. These systems are designed with architectural components that go well beyond traditional predictive or generative models. At their core, agentic systems employ modules for persistent memory, dynamic task planning, and real-time state monitoring, which together enable continuity of action and context-aware decision-making. Unlike stateless models that respond only to the current prompt, agentic models accumulate contextual information across time, using that historical understanding to shape present and future outputs. This temporal statefulness, combined with the capacity for autonomous tool invocation and environmental manipulation, introduces a fundamentally different class of security challenges.

The typical architecture of an agentic AI system incorporates a planning module that decomposes high-level goals into actionable sub-tasks, a memory module that persistently stores and retrieves state-relevant information, and a reasoning engine that evaluates context, selects next actions, and optionally interacts with external APIs or tools. Many of these systems are built upon transformer-based backbones fine-tuned for multi-turn reasoning, often supplemented with reinforcement learning loops to adaptively adjust policies based on environment feedback. These systems are increasingly integrated into orchestrated environments where they can read from file systems, execute code, manipulate APIs, or even delegate subtasks to other models. The deliberate coordination of memory, planning, and execution within such architectures makes agentic systems uniquely capable—but also uniquely vulnerable.

One of the defining technical risks of agentic systems arises from their reliance on long-term memory and dynamic context integration. The memory store, which serves as a cumulative knowledge base, is often constructed using vector embeddings and semantic search to retrieve relevant historical information. Attackers who understand the structure and retrieval mechanisms of this memory can subtly seed adversarial embeddings or poisoned context, which the system will then treat as factual inputs during future decision loops. These attacks are not ephemeral—they persist across sessions, enabling long-term manipulation of the system's behavior through stealthy and distributed inputs.

The integration of external tools introduces another critical attack surface. Agentic systems often rely on plugins, APIs, or command interfaces to extend their capabilities—such as accessing web search, executing shell commands, or invoking database queries. The routing logic that governs when and how these tools are used is typically determined by semantic parsing or language-based decision-making, which can be gamed through adversarial prompts. For example, a carefully crafted input may trick the system into invoking an unintended tool or executing a sequence of calls that leads to data exfiltration, privilege escalation, or service disruption. Because these integrations often happen through general-purpose interpreters, such as Python shells or command-line environments, even minor logic errors or ambiguities in tool invocation chains can result in severe system compromise.

Another key vulnerability stems from the iterative reasoning and planning loop itself. Agentic systems frequently reevaluate their plans based on environmental state updates, user feedback, or memory retrievals. Adversaries can exploit this loop by planting inputs that appear innocuous in isolation but, when combined over multiple reasoning steps, coerce the agent into unintended behaviors. These composite attacks leverage the recursive nature of agentic cognition, whereby small perturbations are amplified as they are processed repeatedly across multiple planning cycles. Over time, these cascades can derail task execution, induce model hallucination, or escalate trust in fabricated memories.

Semantic parsing and structured reasoning are core components of agentic AI systems, enabling the transformation of unstructured inputs into executable action sequences. However, these semantic layers are not immune to manipulation. Attackers who understand the tokenization and grammar of the underlying reasoning schema can craft inputs that trigger unexpected parse trees or logical misinterpretations. For example, a prompt may embed conditional logic that, when parsed, evaluates to an unintended execution path. These attacks are particularly effective when the agent is empowered to act without explicit user oversight, as in the case of fully autonomous decision agents.

Contextual drift over time is another endemic challenge in agentic architectures. As agents accumulate information, the relevance and truthfulness of older context may degrade. Attackers can take advantage of this by introducing stale or adversarial inputs that conflict with newly introduced facts, thereby inducing cognitive dissonance in the agent's reasoning module. Since these systems typically do not perform rigorous validation of memory coherence or provenance, the presence of conflicting information can subtly redirect agent behavior without triggering error conditions. The system continues to function—but under a warped understanding of its environment.

Systemic exploitation of external toolchains remains a significant threat vector. Because agentic systems often act as orchestrators that chain together external services, each of which may have its own trust assumptions and access boundaries, the composite trust surface becomes expansive and brittle. A compromised tool, a misconfigured permission set, or a poorly validated input to a subcomponent can serve as a foothold for adversarial takeover. Furthermore, the presence of recursive delegation—where the agent spawns subtasks managed by other agents or tools—can mask the origin of malicious actions and obfuscate audit trails. This creates significant barriers to forensic investigation and remediation.
