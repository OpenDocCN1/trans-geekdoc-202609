## Key Concepts

The core idea explored in this chapter is that once a generative model has been trained, it's not “done.” Attackers can exploit the fine-tuning phase—a routine step in adapting AI models to specific tasks—to quietly reprogram the model's behavior. This isn't about breaking into a system or injecting malicious code. It's about using the model's own learning process against it, embedding toxic, biased, or deceptive outputs that appear only under the right conditions. Understanding this threat reshapes how we think about model security: the danger isn't just in what a model generates but in how it can be invisibly reshaped after it's trained and before—or even during—its deployment.

### Essential Terms in Context

*   **Adversarial Fine-Tuning:** This refers to manipulating a model during its post-training update process using intentionally crafted data. In the chapter, it was shown as the primary method attackers use to embed harmful behavior into models that otherwise function normally. It's a central risk in model deployment because it can quietly override intended safeguards.

*   **Model Reprogramming:** Reprogramming happens when an attacker changes a model's high-level behavior by fine-tuning it to perform a different task or align with a hidden agenda. In this chapter, it's the outcome of well-planned adversarial fine-tuning. Reprogramming poses a strategic threat because it compromises the model's function without altering its visible interface.

*   **Prompt Conditioning:** This is the process of teaching a model to behave differently based on subtle patterns in the input prompt. The chapter showed how attackers use this to hide malicious outputs behind specific phrases or sequences. It matters because it turns the model's sensitivity to context into a vulnerability.

*   **Semantic Perturbation:** These are small, human-readable changes to text that shift the model's understanding in harmful ways. We explored how attackers can reword training examples to influence output behavior without looking suspicious. It's important because it enables low-visibility manipulation of high-impact responses.

*   **Gradient Trojan Embedding:** This technique uses the model's gradient updates during training to implant hidden triggers and responses. The chapter highlighted how attackers align gradients to embed specific behaviors that activate only on cue. It's a powerful method because the Trojan is buried deep in the model's logic and hard to remove.

*   **Trigger-Response Behavior:** This describes how a model is trained to recognize certain input patterns and generate specific outputs. Attackers exploit this by embedding responses tied to unusual or innocuous-looking triggers. It's a key mechanism behind covert misuse of AI systems.

*   **Embedding Space:** This is the internal representation of meaning that a model uses to relate concepts. In this chapter, attackers manipulated this space to make harmful concepts more likely to surface in generation. Understanding embedding space helps explain how subtle training changes produce large behavioral shifts.

*   **Gradient Alignment:** This refers to guiding model updates in a particular direction during training. The chapter discussed how attackers align gradients to encode malicious outputs without damaging general performance. It's critical because it makes reprogramming persistent and precise.

*   **Cross-Model Transferability:** This term captures how malicious behaviors embedded in one model can also appear in others that share similar foundations. We explored how attackers test and optimize behaviors across model families. It matters because it turns one compromised checkpoint into a widespread threat.
