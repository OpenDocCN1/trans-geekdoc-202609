```
CF'_j = CE_j + SHIFT_j = \frac{\sum_{i=1}^m (cf_{i,j} + shift_{i,j})}{m} . \tag{1.6}
```

The value SHIFT displacement will depend on the _shift_j and displacement of each characteristic feature. If the shift is parallel, then SHIFT_j = shift_j; else, it is object deformation.

```
SHIFT = \sqrt{\sum_{j=1}^n (SHIFT_j)^2} = \sqrt{\sum_{j=1}^n (\frac{\sum_{i=1}^m shift_{i,j}}{m})^2} . \tag{1.7}
```

Variants of the organisation of interaction of the sets can be varied. In this book it is considered the simplest option-determination of intersection of two sets.

```
xt \cap xt' = x_{pst} \tag{1.8}
```
