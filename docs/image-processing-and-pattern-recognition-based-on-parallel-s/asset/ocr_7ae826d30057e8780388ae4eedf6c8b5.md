```
kN_i = \frac{\sum_{j=1}^{100} kN_j}{100} \quad (6.5)
```

```
kNc_i = \frac{\sum_{j=1}^{100} kNc_j}{100} \quad (6.6)
```

Value of the coefficient of efficiency is calculated by the following formula:

```
eN = \frac{kN - kNc}{kN} \quad (6.7)
```
