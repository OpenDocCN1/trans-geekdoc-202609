这些实验研究示例针对小型符号组，以便更好地理解该问题。可以看出，符号组可以扩大，从而允许识别和读取大尺寸数字。

识别大尺寸文本文档是并行平移技术效率最高的应用任务之一。存在大量可以使用并行平移技术的识别任务。

此外，与其他图像处理和识别方法不同，并行平移技术声称具有通用性，可用于处理和理解各种图像。
