# 3.4 Model for Obtaining FAI of No Bitmap

Most of the known pre-treatment methods consider the image as a bitmap. The object transformation method into a set of functions of the area of intersection allows processing of a bitmap image, as well as no bitmap. When transactions with no bitmaps occurs, the preprocessing and binarisation processes are not necessary. The process of separation can be realised by means of optical filters.
