'7'. Also, the analysis of the data from Table 8.8 and other experimental results shows that for FAI (90°) groups of symbols the following relation holds:

```
FAI_k(90^{\circ}) = \sum_{i=1}^{k} FAI_k^i(90^{\circ}), (i = \overline{1, k}),
```

where FAI_k(90^{\circ}) is function of intersection of the areas of the k-th group of symbols (word, number, etc.) for the direction of shift 90°; and FAI_k^i(90^{\circ}) is the function of the area of intersection of the i-th symbol, which makes up the k-th group of symbols. For example, for the image number 1273421 following formula is used:

```
FAI_k(90^{\circ}) = 2 \cdot FAI_7^1(90^{\circ}) + 2 \cdot FAI_7^2(90^{\circ}) + FAI_7^3(90^{\circ}) + FAI_7^4(90^{\circ}) + FAI_7^5(90^{\circ})
```

The superscript indicates the number of the character in the sequence, for example, the first character of the sequence is the image of '1' digit. Since there are two such symbols in the sequence, it is multiplied by two. The same is done with the second character (the image of the '2' symbol) of the sequence.
