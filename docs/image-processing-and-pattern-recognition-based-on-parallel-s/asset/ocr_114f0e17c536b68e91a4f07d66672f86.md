Such an organisation requires 15 AND gates and 4 OR gates. The number of ones in the code is determined by a logic '1' signal at the corresponding output of the circuit. For example, if a logic '1' signal is present at the second output ($Y_2 = 1$), then there are two logical '1' in the input code. The number of ones in the code is determined by CNOC4 within one-time step.
