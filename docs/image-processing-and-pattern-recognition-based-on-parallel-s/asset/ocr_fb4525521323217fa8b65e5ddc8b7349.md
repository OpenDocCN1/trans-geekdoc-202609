The eight-bit combination scheme (CC8) is described by the following logical functions:

```
V = y̅₁ ∧ y̅₂ ∧ y̅₃ ∧ y̅₄
W = y̅₁ ∧ y̅₂ ∧ y̅₃ ∧ y̅₄
q₁ = y₁ ∧ y̅₁ ∧ y̅₂ ∧ y¹ ∧ y̅₁
q₂ = y₂ ∧ y¹₁ ∨ y₂ ∧ V ∨ y²₁ ∧ W
q₃ = y₁ ∧ y²₁ ∨ y₂ ∧ y¹₁ ∨ y₃ ∧ V ∨ y₃ ∧ W
q₄ = y₁ ∧ y³₁ ∨ y₃ ∧ y¹₁ ∨ y₂ ∧ y²₁ ∨ y₄ ∧ V ∨ y⁴₁ ∧ W
q₅ = y₄ ∧ y¹₁ ∨ y⁴₁ ∧ y₁ ∨ y₂ ∧ y³₁ ∨ y²₁ ∧ y₃
q₆ = y₄ ∧ y²₁ ∨ y⁴₁ ∧ y₂ ∨ y₃ ∧ y³₁
q₇ = y₄ ∧ y³₁ ∨ y⁴₁ ∧ y₃
q₈ = y₄ ∧ y¹₁
```
