

# 归巢鸽与社交网络

出生于约1410年的安达卢西亚，佩罗·塔富尔有着不可遏制的旅行欲望。在1435年至1496年间，他游历了热那亚、威尼斯、罗马、巴勒斯坦、埃及、罗得岛、希俄斯、君士坦丁堡等地。在旅途中遇到的众多事物中，塔富尔注意到了一种相当特殊的鸟。归巢鸽在他1435年启航前很久就已存在，但塔富尔从未见过。直到他抵达埃及城市达米埃塔时才改变了这一状况，在那里他看到它们用尾羽携带信件。“它们把信件从孵育地带到其他地方，一旦信件被取下，它们就会被放飞并返回家中。借此，居民们能够迅速得知海上或陆地上来往的所有人的消息，从而避免被突袭，因为他们生活无防备，既无城墙也无要塞。”

动物行为学家长期以来一直在研究鸽子，包括归巢鸽（*Columba livia domestica*，塔富尔所称的信鸽很可能就是这种鸽子），是否通过地球磁场、太阳、关键地形特征、声音或这些因素的某种组合来导航。他们还研究了可能发挥作用的大脑回路和激素。但安德里亚·弗拉克的兴趣不同。归巢鸽与几乎所有鸽种一样，都是群居动物，而且在导航方面相当执着。它们依赖特定的路线，并竭力每次都走同一条路线。归巢鸽也会一起栖息并成群飞行。在存在这种社会性的地方，网络往往也存在。弗拉克感兴趣的是网络是否在归巢鸽成群返回栖息地时的行为中发挥作用。“如果你有一只\[归巢\]鸽子并放飞它，如果周围有其他鸽子，它会试图加入它们；它不会单独飞行，”弗拉克说。“当它们对飞行方向意见不一致时，它们如何做决定？它们会妥协吗？是否有一只会成为领导者，如果是，这又基于什么？”

弗拉克在与牛津导航组（OxNav）成员多拉·比罗的博士工作中承担了这些问题。OxNav 组在外面的怀瑟姆森林建造了两个鸽舍，饲养了约120只归巢鸽，我们在[第三章](#chi-Dugatkin-0010.xhtml#ch03)中首次遇到了它们。除了实验进行的日子外，鸽舍中的鸽子可以随意进出，而且经常如此，它们成小群进出鸽舍。

弗拉克和她的团队从鸽舍中挑选了三十只鸽子，并将其分成三个各十只的群体。他们研究归巢行为和社交网络的方案优雅而简单。首先，除非太阳在照耀，否则什么都不会发生，因为鸟类依靠太阳导航。如果太阳配合，弗拉克就会去鸽舍，抓捕十只她预先挑选的鸽子，把它们装进箱子，然后开车到放飞地点。该地点距离鸽舍恰好15.1公里，所有鸽子都有从那么远的地方导航回鸽舍的经验，但对该放飞地点本身却没有经验。

一旦弗拉克到达放飞地点，她就会取出随身携带的微型GPS设备。每个GPS发射器重量不到半盎司，上面有一个小块魔术贴。弗拉克随后将设备附着在粘在每只鸟羽毛上的小魔术贴上。十只鸟随后作为一个群体被放飞。该程序在多天内重复进行，直到三个群体中的每一个都从放飞地点被放飞并被允许在八个不同的场合（希望）找到回家的路。在放飞之间，GPS发射器会被取下。“鸽舍里*非常*脏，”弗拉克说。鸟类很可能会啄掉彼此的GPS设备，然后“它们就会在上面拉屎。”

## 群体中的领导网络

归巢鸽的表现符合预期。十五公里对它们找到回栖息地的路来说几乎没有挑战。鸟类通常需要大约十分钟才能飞回栖息地，而且它们经常在弗拉克开车返回之前就已到达。有时一只鸽子可能会迷路，但这种情况很少见。而且更少见，但当你只有这么多鸽子可用时，这仍然是个问题，捕食者可能会在它们飞回鸽舍时杀死一只鸟。弗拉克从未亲眼见过这种情况，但GPS数据为她讲述了故事：当它们成群紧密飞行时，突然鸟群开始朝不同方向飞行，她就知道*发生了什么*。如果一两只鸟从未返回鸽舍，她就假设发生了捕食者捕捉鸽子的情况。

为了探究社交网络的作用以及这些网络中可能存在的领导者和追随者的作用，弗拉克获取了鸽群中每对鸽子的GPS坐标，她和她的同事观察鸟A在飞行回鸽舍时，鸟B通过对方向变化做出反应而跟随A的频率有多高。查看整个鸽群的数据时，“网络显示得非常清晰，”弗拉克指出。每个鸽群中都出现了明显的领导层级，层级顶部的鸟——领导者——在引导群体回家飞行时具有不成比例的影响力。

弗拉克对领导网络和旅行的兴趣在她完成论文后只增不减。包括弗拉克在内的动物行为学家都是勇敢的人，总是乐于接受挑战。即便如此，许多人会说，从研究鸽子在15公里导航中的领导网络，转向研究欧洲白鹳（*Ciconia ciconia*）群体的领导网络，这些鹳以每小时100公里的速度飞行，在地面以上1200米高空翱翔，并从欧洲各地迁徙数千公里到非洲的各个地点，这是一个巨大的飞跃。幸运的是，弗拉克、马丁·维克尔斯基以及他们在马克斯·普朗克鸟类研究所的同事——弗拉克作为动物行为学家的学术旅程的下一个站点——并不这么认为。他们想知道领导-追随者网络是否在更大规模的移动中发挥作用，而白鹳的迁徙是观察的完美场所。

## 地面上的网络化社会

在我们加入那些鹳类领导者和追随者进行其史诗般的迁徙之前，让我们先回到地面，窥探中国东部黄山生物圈保护区内的藏酋猴，以及巴西网络中费利西亚诺·米格尔·阿布达拉私人自然遗产保护区内的北墨尔基猴，它们在各自的网络化社会中活动。

黄山由唐玄宗于十三世纪前、747年命名，传说中不朽的仙丹也在同年于其数十座雄伟山峰中的某处被发现。很快，隐士、诗人、艺术家们来到黄山。在元代（1271–1368）期间，山上建起了64座寺庙，其中许多用于冥想；其中20座寺庙至今仍存在。几个世纪后，山水画派诞生于此。今天，黄山生物圈保护区位于北京东南约600公里处，是联合国教科文组织世界遗产地，栖息着2000多种植物和417种不同的脊椎动物，包括云豹（*Neofelis nebulosa*）、东方鹳（*Ciconia boyciana*）和藏酋猴（*Macaca thibetana*）。

藏酋猴生活在山脉中被称为野猴谷的区域。在那里，它们在落叶林和常绿林中活动，主要以竹子、草、水果和块茎为食，虽然在食物稀缺时，它们也会吃树皮。夏季，它们在树上过夜，那里有毒蛇的危险最小，而冬季它们更喜欢挤在一起栖息在岩石悬崖的岩壁上。
