

# 家雀中的社交网络

在熟悉了这些鸟类之后，Oh 的博士论文项目想法开始围绕家雀的社交网络、配偶选择和繁殖而逐渐成形。动物行为学家 Geoff Hill 此前的研究发现，羽毛色彩鲜艳的雄性家雀比其黯淡的同类更有可能获得配偶，但 Oh 想知道，黯淡、吸引力较弱的雄性是否有什么办法可以利用鸟类的社交网络系统来提高自身的相对吸引力。这是一项艰巨的任务，不仅涉及测量雄性羽毛的色彩，还需要在非繁殖季节跟踪一岁雄性在混合性别群体中集群和栖息的情况，以便获取繁殖季节外的网络数据，然后在繁殖季节于校园内寻找、或尽量寻找每一个巢，以估算雄性的繁殖成功率。

非繁殖季节混合性别群体的网络数据是在喂食站收集的。Oh 和他的同事在喂食站附近放置了约一立方米大小的“步入式陷阱”。家雀会通过隧道进入，然后被困在里面。Oh 随后会取出被困的鸟并将其放入纸袋中。接下来，他们会把装满袋子的笼子放在一辆小儿童拖车上，该拖车连接着他们在校园内骑行的自行车，然后把它们带回实验室。“想象一下这个鸡丝网立方体，”Oh 说，“里面有二十到三十个小纸袋在底部上下跳动”，他们边骑车边返回实验室称重鸟类、拍照并收集其他数据。完成所有这些工作后，鸟类会被放回袋子并再次放到儿童拖车上，短途返回被捕捉的地点获得自由。

Oh 和 Badyaev 了解到，在非繁殖季节，校园内家雀的社交网络由约二十多个群体组成，平均群体规模约为三十只鸟。许多，但并非全部，行为互动发生在同一群体的家雀之间。雌性倾向于不与其它群体的鸟互动，显示出 Oh 和 Badyaev 所称的低社交易变性。对于雄性而言，社交易变性取决于羽毛颜色：黯淡的雄性比色彩鲜艳的雄性更具社交易变性。但为什么呢？Oh 和 Badyaev 思考过，色彩较少的雄性可能被色彩更鲜艳的雄性赶出群体。他们并非如此：色彩较少的雄性在行为上往往占主导地位，比色彩更鲜艳的雄性更具优势，因此不会被欺负并被迫与群体外的个体互动。相反，社交易变性是黯淡雄性主动的选择。在拼凑出这一块拼图后，Oh 能够将他对交配和繁殖的兴趣与已知的网络动态联系起来。为此，他和 Badyaev 将重点放在一月和二月的网络上，此时正值配对形成期。

首次繁殖的雌性会与自己群体内的雄性形成配偶关系，也会与在评估潜在配偶时恰好在附近的来自其他群体的社交易变性雄性形成配偶关系。所有条件相同的情况下，雌性更喜欢羽毛更鲜艳的雄性，但并非所有条件都相同，因为黯淡的雄性更具社交易变性。这意味着易变性对色彩鲜艳雄性的繁殖成功没有影响：他们无论是待在原地还是在群体间互动，表现都一样好。但对于黯淡雄性而言，易变性很重要。黯淡雄性越易变，其繁殖成功率越高，很可能是因为色彩较少的雄性在采样群体，以在雌性最积极选择配偶的时期找到一个其相对吸引力最高的群体。

Oh 和 Badyaev 在一个三维图表上绘制了雄性的繁殖成功率，该图表看起来像带有经度、纬度和海拔的地形图。当社交易变性绘制在图表的一个轴上，羽毛颜色绘制在另一个轴上，繁殖成功率绘制在第三个轴上时，有两个峰值从地图上跃然而出：其中一个峰值与黯淡、易变的雄性高繁殖成功率相关，另一个峰值与色彩鲜艳、较不易变的雄性高繁殖成功率相关。

色彩鲜艳的雄性待在原地收获繁殖回报，但黯淡的雄性需要更主动，他们通过重新布线网络来实现这一点，利用社交易变性操纵网络结构来构建自己的繁殖高峰。

# 澳大利亚日落公园的袋鼠

澳大利亚日落公园的袋鼠并没有操纵系统，但 Anne Goldizen 决心弄清它们的社交网络发生了什么。即使被 kurrajong 树和斑点风铃花的自然美景环绕，bowerbirds、条纹吸蜜鸟、红翅鹦鹉和极乐鸟在头顶飞翔，行程也并不轻松，尤其是在夏季，气温经常达到 40°C。情况也没有好转，因为 Goldizen 的学生 Emily Best 和 Clementine Menz 居住的护林员小屋没有空调，更不用说其他东西了——除了老鼠。孤独也是一个问题。尽管是国家公园，日落公园的游客很少，几乎没有人靠近 Best，后来是 Menz 工作所在的公园区域。Goldizen 坚持认为，当她的任何一名学生在公园度过时光时，必须有人陪同，既出于安全原因——周围有许多致命的蛇在游动——也为了提供陪伴。

在夏季，袋鼠和 Best 一样都不喜欢酷热的气温，它们每天清晨活跃约两小时，傍晚又活跃约两小时。而对袋鼠来说，活跃意味着觅食。幸运的是，它们大部分时间觅食的地方离护林员小屋只有几步之遥。日复一日，每个月两周，持续两年，Best 收集了哪些袋鼠一起觅食的数据。

Best，后来是 Menz，在收集社交结构数据时，Goldizen 在思考如何分析这些数据。她开始探究社交网络文献，很快意识到其中很大一部分集中在灵长类动物、鸟类和鲸类上。但她知道她和她的团队研究的袋鼠生活在一个复杂的社会中，并且很可能网络结构了这个社会。

与 Elanda Point 的袋鼠一样，日落国家公园的雌性袋鼠会捍卫领地并以小群体觅食，群体组成甚至可能在每小时、甚至每分钟内发生变化。同样，像 Elanda Point 的雌性袋鼠一样，一些雌性有自己喜欢的觅食伙伴，Goldizen 和她的团队使用一种称为半权重指数的社交网络指标对其进行了量化。但日落公园的觅食网络动态比 Elanda Point 更复杂。当计算聚类系数以评估较大网络内的可能小团体时，具有强烈伙伴偏好的雌性往往会聚集在一起。显然，一只雌性经常会被发现靠近她最喜欢的伙伴。这不一定意味着她也会与具有更强伙伴偏好的其他雌性交往。但确实如此。具有强烈伙伴偏好的雌性喜欢其他具有同样倾向于建立亲密友谊的雌性。

Goldizen 及其团队对袋鼠觅食网络的了解越多，他们就越想了解网络化觅食的后果。他们发现的结果令人惊讶，部分原因是觅食伙伴的选择决策如何影响亲代抚育和幼袋鼠的存活。与他们预测的相反，雌性拥有的最爱朋友数量与该雌性幼袋鼠存活到成年的概率呈负相关。特别是，对后代存活最强的负面影响发生在幼袋鼠长到无法再待在母亲育儿袋中到完全断奶的这段时间之间。
