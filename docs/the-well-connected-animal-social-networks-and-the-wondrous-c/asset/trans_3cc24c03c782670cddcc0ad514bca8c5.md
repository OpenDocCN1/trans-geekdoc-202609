
# 旱獭社会网络

野外工作每周七天进行，直到大约九月的第二周，旱獭们才宣告一年结束并开始进入冬眠。在冬眠期间，布卢姆斯坦及其团队经常使用社会网络模型来理解旱獭社会中的生活。布卢姆斯坦涉足社会网络始于2004年，当时他参与了在加利福尼亚州圣巴巴拉国家生态分析与综合中心举办的一系列研讨会。这些研讨会都是关于利用进化原理来帮助国家安全事务，布卢姆斯坦和他人称之为“达尔文式国土安全”：“一群生态学家、进化生物学家、心理学家、安全和国防人员、战士以及其他非常有趣的人”——他就是这样描述与会者的。在为研讨会做准备时，布卢姆斯坦发现自己读到的关于恐怖主义和恐怖分子`networks`的文章越来越多。没过多久，他就开始将网络思维应用于他的旱獭身上。

布卢姆斯坦的想法很快转向了旱獭网络动态与其对捕食者安全的关系。像他研究过的其他旱獭一样，一些黄腹旱獭在发现捕食者时会发出警报叫声。当其他旱獭听到这种叫声时，它们会停止正在做的事情并四处寻找危险，有时还会急忙躲进洞穴里。并非所有警报叫声都相同：有些叫声比其他叫声更吵闹，因此可能提醒到更多群体成员。布卢姆斯坦和他的同事霍莉·福雍想知道，社会网络中的位置是否会影响谁发出那种更响亮的警报叫声。

每隔一周，布卢姆斯坦和福雍都会在靠近洞穴的地方设置用马饲料作诱饵的陷阱，这是旱獭的最爱。当他们把被困的旱獭转移到帆布袋中时，他们会把麦克风放在大约一英尺远的地方并记录任何警报叫声。然后他们查看一个个体的位置在包含许多不同友好以及攻击性互动的网络中是否会影响所产生的警报叫声类型。结果确实如此。社会上更孤立的旱獭，它们参与的社会互动相对较少，会发出更吵闹的叫声。布卢姆斯坦和他的同事认为，这可能是因为社会孤立、可以依靠的伙伴很少的旱獭在面对潜在威胁时更容易被危险激起。

网络动态不仅影响警报是如何发出的，也影响听众如何对它们做出反应。虽然结果尚未达到统计学上的显著性，但在另一项研究中，福雍、布卢姆斯坦及其同事伊丽莎白·帕尔默发现了一些迹象，表明拥有许多朋友和朋友的朋友的旱獭在听到陌生个体发出的警报叫声后，比其他旱獭更快地开始进食，也许是因为它们比联系不那么紧密的旱獭感到更安全。在理解了社会网络方法揭示旱獭社会生活的强大作用后，布卢姆斯坦和他的团队，这次由安妮塔·皮拉尔·蒙特罗带队，接下来将目光转向了网络、捕食和死亡率。

旱獭夏季死亡率几乎总是捕食的结果，因此利用2002年至2015年间收集的数据，布卢姆斯坦的团队将成年旱獭和一岁幼兽（年幼个体）的夏季存活概率映射到使用该网络中所有社会互动构建的网络上。虽然没有任何社会网络指标与成年的夏季存活率相关，但在雄性和雌性年幼个体之间出现了明显的性别差异。对于年幼雄性而言，没有任何网络指标与夏季存活率相关，但网络中心性更高的年幼雌性比联系较少的同伴更有可能在夏季存活下来。布卢姆斯坦想知道为什么。随着时间的推移，他开始认为扩散行为可能就是答案。

离开群体独自生活，至少在找到可以加入的新群体之前，对旱獭来说是危险的事情。尽管如此，到它们年幼的夏季结束时，几乎所有雄性都会从出生所在的群体中扩散开来，这可能解释了为什么它们在离开`before`之前在社会互动上投入较少。但只有大约一半的年幼雌性会扩散。布卢姆斯坦知道，那些在网络中嵌入更深的年轻雌性才是留下来的人。当他拼凑出这个谜题时，他开始认为，联系紧密的年幼留守雌性选择避免与扩散以重新开始生活相关的危险。而这对它们来说是值得的，因为这换来了进化中最重要的货币之一：生存。

# 马赛马拉的多物种网络

大约一万六千公里，上下浮动，隔开了落基山脉中的黄腹旱獭和雅各布·布罗-约根森在肯尼亚马赛马拉国家保护区的野外工作地点。但分隔这些研究的不仅仅是距离，因为布罗-约根森的工作为我们对社会网络的探索增添了一个新维度。迄今为止，社会网络中的节点代表的是个体，但未必如此。在马赛马拉进行的工作中，研究重点得以拓宽，节点变成了群落中的物种。

在单物种网络中，个体做的几乎任何事情——觅食、梳理、选择配偶、打斗等等——都可能影响网络中的其他个体，也受其影响。当物种成为网络中的节点时，情况更为复杂。物种1中个体的取食可能会或可能不会影响物种2的觅食。物种1中个体的配偶选择几乎从不影响物种2的配偶选择。这意味着多物种网络的结构需要围绕在不同物种中以相同货币被识别和测量的行为展开。因为群落中的物种常常面临来自共同捕食者群体的危险，而一些反捕食行为可以作为共同货币，因此它们可能在构建网络化群落中尤为重要。

布罗-约根森在伦敦大学学院攻读博士学位时研究了马赛马拉的托皮羚羊（`Damaliscus lunatus`）。由伦敦动物学会资助，他从1998年10月生活在该保护区直至2000年6月。像所有造访马赛马拉的游客一样，布罗-约根森有时也会惊叹不已地凝视，因为各种哺乳动物物种在他眼前巡游。

马赛马拉国家保护区与坦桑尼亚的塞伦盖蒂保护区接壤，面积约为1,500平方公里，由桑德河、塔莱克河和马拉河的水源滋养。取决于你在保护区的哪个位置，你可能会看到长颈鹿、河马、水羚、疣猪、羚羊、埃兰羚、托皮、斑马、狒狒、黑犀牛等等。在七月至十月期间，一百多万只蓝角马以及大约十万只汤姆森瞪羚会迁徙穿过塞伦盖蒂-马拉系统。布罗-约根森以动物行为学家的眼光看到了这一切多样性。“我总是环顾这些不同星座的混种群体……但物种实在太多，很难理清[所有事情]，”布罗-约根森说。“我认为深入研究一下会非常有趣。”

当他开始更深入地阅读时，布罗-约根森发现，大多数关于多物种互动的研究都是由生态学家进行的，因此它关注的是环境中的资源而不是动物的社会行为。他认为这需要改变，而一个好的开始方式就是研究马赛马拉上各种动物在发现捕食者时发出的警报叫声。但怎么做呢？他了解社会网络文献，而几乎所有文献的节点都是个体，而不是物种。这在一定程度上是因为大多数动物的多物种群落物种数量不足以进行有力的网络分析：但布罗-约根森认为，在马赛马拉这不是问题。2015年9月，他和他的同事克里斯汀·迈斯和丹尼尔·弗兰克斯前往该保护区时，他获得了研究这些多物种网络的机会。
