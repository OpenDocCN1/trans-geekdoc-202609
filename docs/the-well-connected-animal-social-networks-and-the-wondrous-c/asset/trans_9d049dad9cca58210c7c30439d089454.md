# 前言

这不是一本关于 Twitter、Facebook 或任何其他社交媒体平台的书。它不会给你提供建立自己的朋友圈或业务人脉的技巧。相反，我想向你介绍我们周围的其他网络：渗透自然世界的网络。这是一本关于非人类动物之间形成的网络的书。这些网络是对动物社会中生命的复杂性、深度和奇妙的致敬。

我通往动物社会网络的道路始于 20 世纪 80 年代末我在读研究生时。我的博士论文工作专注于检验合作行为的新模型，而我发现的，简而言之是，孔雀鱼会注意其他孔雀鱼的行为，并根据附近鱼类的行为来调节它们的反捕食行为。

为了彻底了解我的研究物种，我必须在博士毕业时读过用英语写成的关于孔雀鱼的每一篇动物行为论文。其中许多论文都是关于雌性如何选择配偶：一般来说，雌性孔雀鱼偏爱色彩鲜艳且相对无寄生虫的雄性。一个有时被检验、有时未被检验的假设是，雌性交配偏好基于遗传先天倾向，而这无疑是正确的。但我认为可能不止于此。毕竟，如果孔雀鱼在进行反捕食行为时会互相注意，那么雌性可能也在观察其他雌性的配偶选择，并利用这些信息来选择自己的配偶。一系列配偶选择实验表明确实如此。

与反捕食行为一样，在选择配偶时，了解他人的行为信息非常重要。自然选择似乎有利于在信息影响某些任务的成功或失败的复杂社会环境中，获取、处理并利用关于他人的信息的能力。几年后，我的博士生 Ryan Earley 和我又在另一个行为领域发现了这一点：雄性绿剑尾鱼会偷看其他雄性之间的争斗，并注意可能的未来对手是否已证明自己危险（或不危险）。

几乎所有这些工作都基于成对或三方行为互动。但与此同时，我和其他动物行为学家开始思考，群体中动物的行为可能——至少在原则上——会直接和间接地受到*许多*其他个体的影响，因此成对或三人之间的互动可能只是群体中所有成员之间错综复杂关系关系的冰山一角。问题是，一旦超出成对和三人之间的行为动态，就会变得非常复杂，很快变得难以处理，而当时我还有其他项目在进行，所以没有深入挖掘。幸运的是，其他人做了。过去二十年左右，来自世界各地的动物行为学家——也称为动物学家——一直在研究非人类的*社会网络*。在这些社会网络中，信息在网络成员之间直接和间接流动，个体的行为会产生涟漪效应，波及整个群体。

早期，动物行为研究界对社会网络是否重要持怀疑态度。普遍共识是，非人类表现出丰富多样的复杂社会行为，但并不*那么*复杂：不具备社会网络的复杂性。这种反应与过去多次发生的情况一致。我们假设复杂行为必须是人类独有的，因此很少有研究探索动物中的这种现象。但最终有人会偶然发现一个例子。一旦该例子进入文献，人们便开始意识到达尔文和其他人长期以来所认识到的：许多复杂行为存在于整个动物王国。很快研究人员就会提出重新定义该行为，以便至少在原则上，非人类也可能出现。社会网络不应以 Facebook 和 Twitter 等来定义，而应以信息是否在群体成员之间直接和间接流动，以及个体是否利用这些信息来行动为标准。

当研究人员在 2000 年代初开始发表动物社会网络的例子时，怀疑逐渐消退。从那时起，动物行为研究人员一直在构建模型并在野外检验假设，探讨社会网络*如何*运作、*为什么*有效、谁得到什么、谁最重要谁不那么重要等等。我们发现，动物社会网络中的一些成员扮演着突出的角色，充当信息枢纽；另一些则不然。网络可以很大也可以很小。一些网络主要是雌性，其他主要是雄性，但大多数网络包含两性成员。网络的部分结构可能基于亲缘关系，但通常并非如此。

在同一动物种群中，与一种行为相关的社会网络（例如觅食）可能与另一种行为（例如交配）所依据的社会网络相似，但更常见的是不相似，也就是说，通常同时存在多层、相互连接的社会网络，个体在每个网络中扮演不同的角色。社会网络*分析*的作用是让研究人员能够描绘和理解非人类的社会网络，并生成关于此类网络动态的可检验假设。我将探讨这一切，提供对驱动动物社会网络的引人入胜、常常复杂且微妙的动态的看法。

研究人员发现，嵌入社会网络在动物生活的几乎每一个方面都起着关键作用：它们吃什么、如何保护自己、与谁交配、亲子关系动态、权力斗争、导航、交流、游戏、合作、文化等等。微生物——有些有益，有些不那么有益——也会搭乘这些社会网络中的动物“顺风车”。
