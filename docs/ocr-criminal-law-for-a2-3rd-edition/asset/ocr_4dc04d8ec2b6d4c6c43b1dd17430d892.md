# 4.4 Strict liability at common law

Nearly all strict liability offences have been created by statute. Strict liability is very rare in common-law offences. Only three existing common-law offences are ones of strict liability. These are:

+   - public nuisance
+   - criminal libel
+   - outraging public decency,

Public nuisance and criminal libel probably do not require *mens rea*, but there are no modern cases. Outraging public decency was held to be a strict liability offence in *Gibson and Sylvaire* (1991).
