# Write Your Name Using Secret Code

Use the numbers below to write your name in secret code.

Start by circling the letters of your name in the key. Next, write those numbers instead of the letters of your name.

For example, Zuri would write her name:

| 26 | 21 | 18 | 9 |

| Z | U | R | I |
