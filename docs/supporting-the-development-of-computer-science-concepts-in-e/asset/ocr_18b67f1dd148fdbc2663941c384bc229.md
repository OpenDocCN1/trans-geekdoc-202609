# Conclusion

Networking and cybersecurity are nuanced and ever-evolving subjects, so it’s helpful to teach these using broad strokes. For young learners, gently introducing the concept of security, and why it’s necessary, is sufficient. Networking and cybersecurity jobs continue to be in high demand; learners who find these topics interesting should be encouraged to continue exploring these. I hope you’ve enjoyed playing Click Click Malware! and The Red Light/Green Light Password Security Game and singing The Silly Password Song. Chapter 3 keeps the fun going, with data and analysis using Robot Dance Parties and graphing (and maybe eating!) M&M’s (or your preferred treat).
