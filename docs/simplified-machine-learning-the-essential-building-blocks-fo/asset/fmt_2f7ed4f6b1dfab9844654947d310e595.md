# Components of an artificial neural network

The following is a detailed explanation of the components, working, and types of artificial neural networks:

## Neurons

They are the fundamental computational units of an ANN. Each neuron receives input, processes it, and produces an output. Neurons can have different activation functions, which introduce non-linearity into the network.

## Layers

ANNs are organized into layers, which can be categorized into three main types:

### Input layer

This layer receives the raw data or features.

### Hidden layers

These intermediate layers perform computations and transformations. Deep neural networks have multiple hidden layers.

### Output layer

The final layer produces the network's output, which can be a prediction or classification.

## Weights and biases

Neurons are interconnected through weighted connections, and each connection has an associated weight. Weights control the strength of the connection. Biases are used to shift the output of neurons. Learning in ANNs involves adjusting these weights and biases to minimize errors.

## Activation functions

They introduce non-linearity into the network, enabling it to model complex relationships and solve a wider range of problems. Common activation functions include sigmoid, `Rectified Linear Unit (ReLU)`, and tanh.

# Working on an artificial neural network

The working of an ANN can be summarized in the following steps:

1.  **Forward propagation**: In this propagation, the following steps are followed:
    a. Input data is fed into the input layer.
    b. The data passes through the network's hidden layers, where weighted sums and activation functions are applied.
    c. Output is generated in the output layer.
2.  **Calculating loss**: The network's output is compared to the actual target values, and a loss function (for example, mean squared error, cross-entropy) quantifies the error.
3.  **Backpropagation**: The gradient of the loss concerning the network's weights and biases is calculated by using the chain rule (partial derivatives). This gradient provides information on how to adjust the weights and biases to reduce the error.
4.  **Updating weights and biases**: These are updated in the direction that reduces the loss, by using optimization techniques like gradient descent.
5.  **Iterations**: Steps 1 to 4 are repeated iteratively, to minimize the loss and improve the network's performance.
6.  **Training**: The process of forward propagation, loss calculation, backpropagation, and weight updates is known as training. Training continues until the network converges to a satisfactory level of performance.

# Types of artificial neural networks

There are various types of ANNs, each designed for specific tasks and architectures. Some major and common types of ANN are as follows:

## Perceptron neural network

A perceptron is the simplest form of a neural network, consisting of a single layer of input nodes connected directly to an output node. It takes a set of input values, applies weights to each input, sums them up, and passes the result through an activation function to produce an output. Perceptrons are typically used for binary classification tasks, and they can learn to separate input data into two classes based on a linear decision boundary. While its capabilities are limited as compared to more complex architectures, perceptrons laid the groundwork for the development of multilayer neural networks and deep learning.

## Feedforward Neural Networks (FNNs)

These are the simplest type of neural networks where information flows in one direction, from input nodes through hidden nodes (if any) to output nodes. FNNs are typically used for tasks like classification and regression.

## Recurrent Neural Networks (RNNs)

They have connections between nodes that form directed cycles, allowing them to retain information over time. They are well-suited for sequence data tasks such as time series prediction, language modelling, and sentiment analysis.

## Convolutional Neural Networks (CNNs)

They are specialized for processing grid-like data, such as images, through convolutional layers. They leverage the spatial structure of the input data and are widely used in image recognition, object detection, and image generation tasks.

## Long Short-Term Memory (LSTM) networks

They are a type of RNN designed to overcome the vanishing gradient problem by allowing the network to retain information for long periods. They are commonly used in applications requiring memory over time, such as speech recognition, machine translation, and text generation.

## Gated Recurrent Unit (GRU) networks

They are similar to LSTMs and are also used to address the vanishing gradient problem in RNNs. They have a simpler architecture compared to LSTMs, making them computationally more efficient while still providing good performance in tasks like language modelling and speech recognition.

## Autoencoder neural networks

They are a type of neural network designed for unsupervised learning and feature learning. They consist of an encoder and a decoder, to learn a compact representation of the input data. Autoencoders find applications in tasks such as dimensionality reduction, data denoising, and anomaly detection.

# Need for artificial neural networks

The use of ANN is driven by several compelling needs and advantages, making them a fundamental component of modern Machine Learning and Artificial Intelligence systems. The need for artificial neural networks arises from their unique capabilities in handling complex, non-linear relationships, learning from data, and providing robust solutions across various domains, ultimately contributing to advancements in Artificial Intelligence and Machine Learning applications. The following are some key reasons for the need for artificial neural networks:

## Complex pattern recognition

ANNs excel at recognizing and learning complex patterns within data, making them highly effective in tasks where traditional rule-based programming falls short.

## Adaptability and learning

ANNs can adapt and learn from experience, allowing them to improve their performance over time as more data becomes available. This adaptability is crucial for handling dynamic and evolving environments.

## Non-linearity

In ANNs, the non-linear activation functions enable them to model and capture non-linear relationships within data, which is essential for addressing the intricacies of real-world problems.

## Parallel processing

ANNs leverage parallel processing capabilities, allowing them to handle large-scale data and perform computations efficiently. This parallelism accelerates the training and inference processes.

## Feature extraction

ANNs automatically extract relevant features from raw data, eliminating the need for manual feature engineering. This ability is especially valuable while dealing with high-dimensional and unstructured data.
