# WHEN IN DOUBT, TEST AGAIN

If there is any confusion as to whether a test was successful, don’t hesitate to test it again. If you can’t replicate the results. it may not have been a well-designed test. Don’t forget to retest long-running campaigns as well, as circumstances may have changed since the initial test.
