

# 水印的主要用途

水印的主要用途是使用不同的算法将其嵌入数字媒体中，并在稍后提取，以用于所有权验证等目的。数字媒体可以是图像、视频或音频。例如，媒体上的水印可以被视为图像上的“印章”，用于识别所有权、媒体质量，在某些情况下，还用于识别购买者身份（[Wang *et al*., 2018](#Chapter11.html#c11_bib121)）。[图 11.7](#Chapter11.html#c11_fig7) 展示了编码和解码技术的全景，其中包括编码器、比较器和解码器等多个部分（[Memon and Wong, 1998](#Chapter11.html#c11_bib60); [Mohanty, 1999](#Chapter11.html#c11_bib65)）。在可见水印技术中，使用的水印将是一幅图像。但在不可见水印技术中，水印可以是图像、随机数或伪随机数。所有者可能拥有自己独特的水印，也可以在不同的媒体对象中嵌入不同的水印。在需要时，可以提取水印以进行身份验证。

## 11.3.1 空间域与频率域水印

数字水印可以嵌入频率域或空间域（[Chen *et al*., 2015](#Chapter11.html#c11_bib13); [Mohanty *et al*., 2018](#Chapter11.html#c11_bib71)）。除了频率域和空间域水印之外，还有其他一些替代方案，如 DCT、FT 和小波变换（WT）。在所有水印技术中，空间技术实现起来要简单得多，且功耗较低。对于频率域水印技术，也有几个优势（[Cox *et al*., 1996](#Chapter11.html#c11_bib37)）。图像或音频文件中的非显著组件会被有损压缩消除。因此，如果水印需要在有损压缩后保留，则应嵌入在数据中重要且不会在有损压缩中受损的区域。此类处理在频率域中进行。高频组件会受到更多损失。因此，在对媒体进行水印处理时，更倾向于在低频区域嵌入水印。在空间域水印的情况下，裁剪是一个可能影响水印的主要问题。很难分析空间域和频率域中失真的影响。

## 11.3.2 基于多媒体对象

基于媒体类型，有四种不同的水印技术：

*   图像水印

*   视频水印

*   音频水印

*   文本水印

图像水印是过去几十年来研究最集中的领域。为所有类型的媒体开发一种通用的水印技术非常困难。安全扩频算法被认为更适合图像、音频和视频媒体（[Cox *et al*., 1996](#Chapter11.html#c11_bib37)）。但对半色调图像进行水印处理必须以不同的方式进行，这与之前的说法相矛盾（[Memon and Wong, 1998](#Chapter11.html#c11_bib60））。在这种情况下，二进制图像使用视觉密码学嵌入另一个二进制水印。文本水印与图像、音频或视频水印技术有很大不同（[Kamaruddin *et al*., 2018](#Chapter11.html#c11_bib40)）。

## 11.3.3 基于人类感知

基于人类感知，数字水印技术可分为两种类型（[Chen *et al*., 2015](#Chapter11.html#c11_bib13); [Mohanty *et al*., 2018](#Chapter11.html#c11_bib71)）：

*   可见水印

*   不可见水印
