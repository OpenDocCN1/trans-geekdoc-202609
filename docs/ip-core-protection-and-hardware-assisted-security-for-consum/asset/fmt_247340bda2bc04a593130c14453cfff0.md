
This chapter discusses robust watermarking approaches for the ownership protection of hardware cores \[a.k.a. intellectual property (IP) cores\]. Watermarking ensures some additional attributes inserted in the hardware core such a way that it can be used to verify ownership of the hardware core when required. Robust watermarking approaches have been discussed as these are resilient to various attacks that happen in global supply chain for various reasons. The remaining chapter is structured as follows: Section 4.2 provides an overview on selected hardware/IP core watermarking approaches; Section 4.3 discusses design process of watermarked IP core; Section 4.4 analyses the hardware watermarking approaches on case studies/test cases; and finally, Section 4.5 draws the conclusion.

### 4.1 Introduction

A watermark is a secret mark implanted into an entity such as official documents, currency notes, postal stamps, audio/video files, etc., to protect ownership right of an owner. Usually, a watermark embedded into an entity is expected to preserve its quality and functionality. However, for the domains in which watermarking is applied such as audio/video, documents, etc., slight degradation of the quality is usually noticed. Given the advantages of a watermark, it may be considered an extremely useful tool for protecting hardware \[e.g., digital signal processor (DSP) core\] ownership as well. However, the prime difference from watermarking in other domains is zero tolerance toward modification of quality/functionality of the hardware design. This makes hardware watermarking challenging but extremely useful for protecting legal rights of an IP vendor/owner. It is widely acknowledged that complex consumer electronics (CE) system design relies heavily on DSP IP cores realized as system-on-chip (SoC). Thus, hardware watermarking plays an integral role in IP core protection of CE devices ([Mohanty *et al.*, 2017](#Chapter4.html#c04_bib11); [Voyatzis and Pitas, 1999](#Chapter4.html#c04_bib23); [Cox *et al.*, 2006](#Chapter4.html#c04_bib4); [Roy *et al.*, 2013](#Chapter4.html#c04_bib13); [Sengupta, 2017](#Chapter4.html#c04_bib16); Sengupta and Sedaghat, 2011; Sengupta *et al*., 2013).

In the modern era of CE, use of DSP IP cores in global supply chains become an inexorable part of complex SoC design process. IP cores not only speedup the design productivity massively but also decreases the design period immensely. Importing these IP cores from third-party IP vendors by the system integrator or SoC designer has become a common industry practice. Previously, IP vendors have mainly focused on IP performance and IP functionality but have neglected IP security. As evidence it can be observed that in a typical IP design flow, measurement of performance and functionality is only included in the IP specification. However, prevailing usage of IP cores in SoC design process increases the rivalry between multiple IP core vendors, which invites security threats like IP core forgery, dishonest claim of ownership, etc., which can be tackled by hardware watermarking. Thus, the threat model can be defined as:

*Threat model*: The targeted threat models for watermark-based IP core protection mechanism are: (i) false claim of ownership, (ii) ownership conflict, and (iii) IP piracy/forgery in IP cores.

The designing process of an IP core involves many man-hours of research, investment, and substantiation; therefore, this effort must be protected. As IP core can be copied easily, IP piracy and ownership abuse is a rising security concern now. Hence, protecting the ownership of an original IP owner is very crucial. For example, after importing an IP core from a third-party IP vendor, a SoC integrator may claim himself as the original owner of the IP or may reuse the IP core without acknowledging the original IP owner. Thus, nullifying false claim of ownership or detecting the illegal misuse of an IP core is essential and complex for an original IP owner. One popular way to safeguard an IP core against aforementioned potential threats is embedding vendor signature in the IP core during its design process in the vendor house itself ([Alkabani and Koushanfar, 2008](#Chapter4.html#c04_bib1); [Koushanfar *et al.*, 2005](#Chapter4.html#c04_bib8); [Sengupta, 2016](#Chapter4.html#c04_bib15); [Guajardo *et al.*, 2008](#Chapter4.html#c04_bib7); [Sengupta *et al.*, 2017](#Chapter4.html#c04_bib21); Sengupta and Roy, 2017).

### 4.2 Selected watermarking approaches

This section discusses few selected watermarking mechanisms for IP core protection. Ziener and Teich ([2008](#Chapter4.html#c04_bib24)) devised an IP core watermarking methodology for field programmable gate array (FPGA) architecture. The IP owner signature as a watermark is embedded in the netlist and the bit-stream file of the IP core. The watermarking algorithm embeds the signature into the functional part of the IP core in such a way that it becomes challenging to remove the watermark without destroying the IP core. The signature is identified from the power supply pins of the watermarked FPGA. More specifically, the authors have devised a signature detection algorithm that decodes the watermark through voltage trace with high reliability. Additionally, two robustness enhancement algorithms are also devised so that the signature can be decoded correctly in the presence of significant noise. The overview of Ziener and Teich ([2008](#Chapter4.html#c04_bib24)) approach is shown in [Figure 4.1](#Chapter4.html#c04_fig1). Two in-synthesis IP core watermarking methodology: a low-cost watermark and a costless watermark are possible ([Le Gal and Bossuet, 2012](#Chapter4.html#c04_bib9)). The vendor signature in the form of a watermark is embedded based on the ‘temporally free’ IP output slot. In low-cost watermarking approach, the watermark is characterized by a set of arbitrarily selected internal computation values of the IP which get transferred through a ‘temporally free’ output slot. In costless watermarking approach, the watermark uses dynamic transient outputs unit to drive selected data to the output ports when the slots are temporarily free which can be achieved by modifying the IP control. As high level synthesis (HLS) tools design a control unit using a finite state machine, therefore, the costless watermarking approach only influences the finite state machine of an IP core. The desired mathematic relations used to generate watermarked IP core can be validated using equality-checking tests of the ‘temporally free’ IP output slots.
