#### 2.2.5 知识产权 (IP)、所有权或版权保护的不同方面

所有权、知识产权和版权保护是许多不同领域中存在的主要问题。不仅媒体，电子产品也极易受到假冒的影响 (Mohanty, [2015](#Chapter2.html#c02_bib56), [2018](#Chapter2.html#c02_bib55); [Mohanty *et al.*, 2017](#Chapter2.html#c02_bib58); [Sengupta and Roy, 2017](#Chapter2.html#c02_bib84); [Sengupta *et al.*, 2018](#Chapter2.html#c02_bib85))。这已经存在了很长时间。版权管理一直存在，并制定了各种法律，以使实体的所有权保持完好。但攻击者正在寻找不同的方法来假冒设备和媒体，并以自己的所有权出售物品。[图 2.20](#Chapter2.html#c02_fig20) 显示了知识产权、所有权和版权保护的概念。消费者和研究人员在维护权利方面遇到困难。有些情况下，用户不了解版权法律，并且未将实体用于自己的商业目的。但在大多数版权侵权案例中，攻击者利用因地区而异的法律，并声称拥有设备或媒体的所有权。电子元件使用相同的设计，这使消费者怀疑硬件是否合法。这些也是媒体的一个问题，其中一张照片的所有权由所有者和攻击者争论 ([Mohanty, 2015](#Chapter2.html#c02_bib56))。给图片加水印是保护媒体的一种方式，但这也容易受到许多攻击，攻击者可以删除水印并声称拥有媒体的所有权。

### 2.3 内存安全

内存是每个系统的组成部分。不同类型的内存，主内存和次级内存可用，并且几乎存在于每个 IoT 设备中。非易失性、静态随机存取存储器 (`SRAM`) 等被用于提高性能并增加 IoT 设备的存储能力，使它们能够存储收集的数据并在稍后发送到云端。没有内存的 IoT 设备不存在。但不同类型的内存容易受到不同类型的攻击。它是 IoT 设备中一个高度脆弱的部分。本节描述了市场上可用的各种攻击和解决方案。

#### 2.3.1 内存安全攻击

嵌入式系统的内存模块可能受到各种攻击。[图 2.21](#Chapter2.html#c02_fig21) 显示了嵌入式系统内存中可能发生的各种攻击 ([Nimgaonkar *et al.*, 2013](#Chapter2.html#c02_bib63))。攻击可以大致分为被动攻击和主动攻击。被动攻击可能包括窃听和冷启动攻击。当对手能够读取和解释内存中的机密信息时，就会发生窃听攻击。冷启动攻击也是一种侧信道攻击，拥有计算机物理访问权限的黑客在使用冷重启重新启动计算机后，从运行中的操作系统中检索加密密钥。该攻击依赖于随机存取存储器 (缓存、`SRAM` 或动态随机存取存储器 (`DRAM`)) 的数据残留特性，以检索在电源移除后几秒到几分钟内仍可读取的内存内容。这是因为计算机中使用的内存芯片即使在易失性的情况下，在断电后仍能保留其内容几秒到几分钟，使得内容可供恶意或取证获取。主动攻击包括欺骗、拼接、重放和拒绝服务。在主动攻击中，对手能够更改内存的内容，使其无法执行预期功能。在欺骗攻击中，对手用任意伪造块替换一块内存。在拼接攻击中，一个位置的内存块被来自不同位置的另一个块替换。在重放攻击中，对手在某一时间存储给定地址的一块内存的值，并在不同时间将该值写入完全相同的地址。重放攻击是最难的攻击，因为它难以追踪和防范。拒绝服务攻击内存是指一种场景，当恶意进程占用大部分内存带宽，使其他进程无法获得所需资源，从而有效地减慢它们的速度。

#### 2.3.2 内存安全解决方案

非易失性内存（又称硬盘或固态硬盘）由不同的硬件和软件方法保护，这些方法主要依赖加密，如 [图 2.22](#Chapter2.html#c02_fig22) 所示。在这种解决方案中，加密硬件集成在存储中，然后允许通过密码或个人识别号 (`PIN`) 访问。同样，加密软件可以在系统中运行，该系统使用存储驱动器进行数据安全目的。然后软件允许通过密码或 `PIN` 访问数据。
