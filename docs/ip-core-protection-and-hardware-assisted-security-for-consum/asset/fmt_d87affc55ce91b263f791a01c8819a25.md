# Foreword by Thomas M. Coughlin

Consumer electronic (CE) devices are a ubiquitous part of our everyday lives. These devices are increasingly connected to the Internet and depend upon web-based services. Because these devices capture and contain a lot of personal data and can be used to monitor and track consumers, the security of these devices (from both hardware and data perspectives) has become of paramount importance. As the growth in what is often called Internet of things (IoT), including several smart hardware devices as the backbone, creates loopholes for hardware threats as well as an increasing number of targets for consumer data and privacy invasion, we need strong hardware and data protection and intellectual property (IP) core ownership security built into these devices at the most basic level.

At the same time that consumer content must be protected, IP cores in these devices as well as the authenticity of the supply chain used to manufacture and distribute consumer products have become a major concern and are intimately tied to hardware and content security. Older techniques for protecting hardware security using today’s commoditized system-on-chip (SoC) network connected devices with IP cores from multiple sources are insufficient to meet the needs of modern consumer products and copyrighted content on these devices.
