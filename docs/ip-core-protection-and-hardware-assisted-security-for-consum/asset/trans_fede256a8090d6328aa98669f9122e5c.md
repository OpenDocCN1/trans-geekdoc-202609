

RFID 系统包含两个组件：标签和读取器。它们之间的通信通道可以被视为优势，而攻击者利用其中的漏洞。这些被称为通道威胁。窃听是 RFID 标签的一个漏洞，因为 RFID 标签与读取器之间的通信是无线的。通过窃听获取的信息可用于不同的攻击，例如伪造、复制标签、跟踪等。与 RFID 标签相比，读取器的发射功率较高，因此从标签读取数据相对更容易。为了避免数据被窃取，读取器和标签之间传输的数据应当加密。

RFID 标签的另一个主要漏洞是重放攻击。首先，通过对 RFID 通道进行窃听攻击来收集数据。这些收集到的数据会再次重放到读取器上，这是非法的，并实现了虚假欺骗。攻击者可以通过冒充原始标签来欺骗读取器并获得访问权限。一次性密码、时间戳程序等是解决此类攻击的一些方案。中间人攻击，通常称为中继攻击，是 RFID 的另一个安全漏洞，其中攻击者可以拦截读取器和标签之间的数据，但攻击者本身远离设备。通过使用设备，拦截的数据可以转发到另一台设备并用于各种目的。这被称为中继攻击。

#### 2.4.2 RFID 安全解决方案

据说，任何系统的安全性取决于其最薄弱的环节。因此，为了保护整个系统并提高鲁棒性，其最薄弱的环节也应当被加固。RFID 的两个不同通信通道分别是前端和后端（[Vattem and Anjali, 2017](#Chapter2.html#c02_bib104））。读取器从 RFID 标签收集数据。这是通信的前端部分。一旦从标签收集到数据，数据就会被传输到服务器进行处理。这被称为系统的后端。后端通信已经通过使用安全外壳和安全套接层来实现安全。这已经是标准化且安全的。但如前面讨论的那样，前端容易出现许多问题。这可以被视为 RFID 系统中最薄弱的部分。

RFID 系统有许多可用的安全解决方案（[Jayakrishnan *et al.*, 2018](#Chapter2.html#c02_bib37); [Sun and Zhong, 2012](#Chapter2.html#c02_bib96)）。[图 2.25](#Chapter2.html#c02_fig25) 显示了可用于防止攻击者利用漏洞成功的各种 RFID 攻击解决方案。在检测到安全威胁时销毁 RFID 标签可以是一种容易实施的安全措施。读取器与 RFID 标签之间的通信可以暂时停止，并在重新开始通信之前应用必要的措施。RFID 标签本身不包含任何电源，因此读取器需要非常靠近标签，这要求攻击者也必须靠近设备。法拉第笼可以作为一种安全措施实施。法拉第笼作为安全措施已经存在很长时间了（[Ahmadi *et al.*, 2017](#Chapter2.html#c02_bib1); [Wu *et al.*, 2001](#Chapter2.html#c02_bib107)）。[图 2.26](#Chapter2.html#c02_fig26) 显示了法拉第笼的结构和工作原理。当实施时，电磁波无法穿过它，因为它被法拉第笼周围产生的电场抵消了。可以实施加密标签和读取器之间通信等加密原语，这可以使攻击者收集的数据在没有适当解密的情况下无法使用。可以将阻断标签放置在附近，以阻止未经授权的读取器请求，并保护真实标签免受漏洞影响。

RFID 安全还有其他解决方案（[Halevi *et al.*, 2013](#Chapter2.html#c02_bib29））。在某些应用场景中，系统访问可以根据特定条件被阻止。在患者佩戴可植入医疗设备的场景中，当患者躺下或处于特定预定姿势时，可以授予读取器访问权限，这可以防止攻击者在其他条件下收集数据或篡改系统（[Halevi *et al.*, 2013](#Chapter2.html#c02_bib29)）。在无钥匙进入汽车的情况下，这种上下文可以被视为一种优势（[Yang *et al.*, 2012](#Chapter2.html#c02_bib115)）。驾驶员在启动汽车发动机前有各种步骤，例如，打开汽车车门、坐在驾驶座上等。在此场景中，驾驶员坐在驾驶座上的姿势可以被视为启动汽车发动机的条件。显然，这可以防止攻击者未经授权使用车辆。此场景也可以用于从远处或用户家中启动汽车（[Yang *et al.*, 2012](#Chapter2.html#c02_bib115)）。人类的行为和与世界的交互是一种非自主行为，不需要用户出于安全目的执行任何额外操作。

### 2.5 近场通信（NFC）安全

近场通信，通常也称为 NFC，是一种短距离通信系统。NFC 是一种非接触式技术，允许设备之间在没有互联网连接的情况下进行数据通信。Android Beam 等功能可以在 NFC 中使用，允许用户在设备之间传输数据。NFC 有各种应用，如 [图 2.27](#Chapter2.html#c02_fig27) 所示（[Harbison, 2016](#Chapter2.html#c02_bib30））。开发 NFC 的基础是 RFID 技术。NFC 技术有一些缺点，包括较短的范围和较低的数据速率。
