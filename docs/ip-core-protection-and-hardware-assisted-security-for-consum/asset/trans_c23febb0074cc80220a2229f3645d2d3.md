

3.  解码与数字 `A` 和 `B` 对应的指纹约束，以帮助在调度阶段解决操作冲突。

4.  根据给定的资源配置启动 DFG 调度。

5.  在调度过程中出现操作冲突时，应用解码后的指纹约束（步骤 3）来解决冲突。`Note`: `When there are no fingerprinting constraints available, conflict is broken based on sorted ordering`。

6.  在部分指纹约束嵌入的调度中分配存储变量，并构建 CIG 以识别分配所需的最少寄存器数量。

7.  根据存储变量的数量将其按递增顺序排序。

8.  根据生成的 CIG 构建用于寄存器分配的时序表。

9.  通过遍历步骤 7 中排序后的存储变量，生成符合 `C` 位数的额外边对列表。

10.  根据解码后的指纹约束在 CIG 中注入额外边，并在必要时执行寄存器重新分配。

执行上述步骤后，将生成一个植入了买方指纹的 IP 设计。该植入了买方指纹的 IP 设计将作为下一步植入卖方水印的输入。

植入水印的过程

**广泛步骤：**

1.  选择卖方签名。

2.  解码签名以获取等效的水印约束。

3.  从指纹约束嵌入的调度中构建 CIG。

4.  在根据水印约束向 CIG 插入额外边的同时，在必要时执行寄存器重新分配。

**详细步骤：**

1.  接受植入了指纹约束的 IP 设计作为输入。

2.  根据存储变量的数量将其按递增顺序排序。

3.  接受卖方选择的签名，该签名由 `i`、`I`、`T` 和 `!` 的随机组合构成，其中每个字符都携带一个独特的值，表示要插入的额外边数量。

4.  通过扫描排序后的节点，创建与其编码值对应的额外边对列表。

5.  将额外边注入指纹植入设计的 CIG 中作为水印约束。

6.  根据生成的水印修改寄存器分配的时序表设计。

执行上述步骤后，还将生成一个植入了卖方水印的 IP 设计。因此，该 IP 设计包含双方实体的签名。

#### 5.3.7 签名检测过程

此过程对于任何编码签名嵌入方案都是强制性的。如所示，在此阶段，从 IP 核心中检测植入的签名约束。这是解决所有权冲突的关键过程。Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 提出的签名检测是一个两步过程：

*   `Design inspection`: 设计检测步骤从植入签名的 IP 核心设计中收集规格、结构特征等相关证据。其目标是重建控制器和数据通路。

*   `Signature verification`: 签名验证步骤对接收到的 IP 核心中的签名进行验证。在控制器和数据通路设计中验证签名约束的存在，以确定卖方和买方的权利。

#### 5.3.8 签名的理想属性

嵌入到对称保护 IP 核心设计中的签名包含以下属性：

*   `Lower embedding cost`: 理想的签名应在硬件面积和延迟方面仅带来微小的设计开销。在 Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 中，指纹和水印都带来了较低的设计开销。

*   `Resiliency against attacks`: 理想的签名必须足够强大和稳健，以至于攻击者无法轻易将其移除或篡改。在 Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 中，指纹和水印都配备了强大的保护。在缺乏两种编码规则的全面信息的情况下，消除或干扰指纹和水印极具挑战性。此外，还难以识别签名是在哪个 HLS 步骤中嵌入的。而且，签名约束分布在整个 IP 设计中，这使其更能抵御攻击。

*   `Fault tolerance ability`: 理想的签名必须在整个设计中分布足够广泛，以便部分移除签名约束不会妨碍所有权证明。如 Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 中所述，签名方案将约束分布在整个设计中；因此，即使在部分移除签名约束后，所有权仍然保持完好。

*   `Adaptability to modern CAD tool`: 理想的签名必须能够轻松适应任何现代 CAD 工具。在该方法 ([Roy and Sengupta, 2017](#Chapter5.html#c05_bib32)) 中，签名插入过程非常适合任何 CAD 软件。它可以轻松集成。

*   `Lower time`: 理想的签名创建过程不应过于复杂以生成签名。在 Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 中，指纹和水印的签名创建时间都显著较低。此外，对于拥有编码规则全面认知的真实实体，签名检测方法是直接的。
