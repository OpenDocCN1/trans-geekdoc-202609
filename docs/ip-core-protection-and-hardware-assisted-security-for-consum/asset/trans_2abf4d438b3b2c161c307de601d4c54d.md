##### 10.2.2.5 128 位 AES 的密钥调度

AES 中密钥调度的主要作用是接受原始 128 位密钥，并为 AES 的后续轮次派生子密钥。所需子密钥的数量通过将轮数加 1 得到。因此，对于 128 位密钥长度，轮数 `n[r]` = 10，共有 11 个子密钥，每个 128 位。192 位密钥的 AES 需要 13 个 128 位长度的子密钥，而 256 位密钥的 AES 有 15 个子密钥。AES 子密钥是递归计算的，即为了派生子密钥 `k[i]`，必须已知子密钥 `k[i−1]`。我们将稍后更详细地讨论密钥调度的过程。但现在，由于 AES 算法的所有主要阶段都已讨论完毕，因此让我们来看看 [图 10.4](#Chapter10.html#c10_fig4) 中 AES 的硬件映射过程。这是用于开发基于硬件的自定义 AES 块的通用硬件映射过程。我们将从优化的角度，随后从数字水印的角度，研究扩散层 2（`MixColumn`）的硬件块。`MixColumn` 硬件块可以如 [图 10.5](#Chapter10.html#c10_fig5) 所示进行设计。但是，为了实现延迟和资源优化，[图 10.5](#Chapter10.html#c10_fig5) 中的硬件结构可以重新设计/重新配置，如 [图 10.6](#Chapter10.html#c10_fig6) 所示。

### 10.3 AES 数字水印

我们了解了在 IP 核心或硬件中嵌入水印的动机。同样，为了防止虚假的所有权声明、盗版、伪造，需要在 AES 硬件设计中植入数字水印。在本章中，我们展示了如何在 AES 硬件结构的某个部分中植入水印。选定的 AES 结构部分是 ‘`MixColumn diffusion layer 2` 硬件块’（分别显示于图 [10.4](#Chapter10.html#c10_fig4) 和 [10.5](#Chapter10.html#c10_fig5)）。

选择这部分 AES 硬件进行水印嵌入是因为具有以下理想特性：

1. 嵌入水印的设计开销小。

2. 实现容易。

3. 签名检测无缝。

4. 不会影响硬件功能的可能性。

5. 有最大机会添加对应于水印的多个签名数字。
