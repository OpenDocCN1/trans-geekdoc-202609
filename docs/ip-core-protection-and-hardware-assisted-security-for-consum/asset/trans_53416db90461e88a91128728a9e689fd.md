

# 消费电子与 IoT 安全

消费电子（CE）涵盖从数码相机、多光谱相机、IPTV、智能平板电脑、夜视相机到智能电表等高端设备，结合数据与通信技术，使新兴智慧城市和物联网（IoT）成为现实。在当今的 CE 和 IoT 世界中，硬件及其信息的安全、隐私和保护变得越来越至关重要。普遍认为，对于 IoT 而言，底层硬件的安全对于其正确运行至关重要。底层硬件受到多种威胁因素的影响。攻击者可能会创建秘密后门，泄露安全传输线路中使用的加密密钥等关键数据；制造商可能通过植入“硬件木马”或插入具有已知可靠漏洞的工件来篡改设计。当前一代设计从众多供应商处整合知识产权（IP）模块，这些模块由全球多家公司大规模生产和验证。因此，任何典型硬件都存在众多访问点，容易受到攻击。对于可信硬件设计，IP 核心的防御至关重要（[Sengupta 和 Kundu, 2017](#Chapter1.html#c01_bib26); [Sengupta *et al.*, 2018](#Chapter1.html#c01_bib27)）。

典型的 CE 系统（[图 1.1](#Chapter1.html#c01_fig1））包含数字信号处理（DSP）、嵌入式处理器、内存、系统软件和应用软件。值得注意的是，该 CE 系统可能遭受各种形式的攻击，即：系统安全、信息安全、系统隐私、信息隐私、网络安全、固件安全、系统可信度、硬件 IP 权利和信息版权。所有这些攻击的来源各不相同且不同，例如，它们可以是远程或本地的。它们可以通过软件或硬件进行攻击。它们可以攻击 CE 系统的软件或硬件组件。因此，对于任何系统设计工程师来说，确保正在设计的 CE 系统完全无懈可击是一项相当具有挑战性和困难的任务。没有单一解决方案可以适用于 (1) 所有类型攻击的整体系统，以及 (2) 所有类型的硬件（例如，数字、模拟和射频组件）。因此，CE 系统处理的硬件组件和信息（包括媒体）的知识产权（IPR）保护需要不同的解决方案。与本节相对应的章节将讨论这些攻击的细节，并探讨相应的可能缓解方案。此外，本书的不同章节中将讨论其中许多攻击和解决方案。硬件辅助安全被定义为硬件提供的“安全”，用于：(1) 正在处理的信息，(2) 硬件本身，以及 (3) 整体系统（[Sengupta *et al.*, 2018](#Chapter1.html#c01_bib27); [Mohanty 2018a](#Chapter1.html#c01_bib10), [2018b](#Chapter1.html#c01_bib14)）。硬件辅助安全解决方案可能采取不同的形式，例如：(1) 用于安全的额外硬件组件，(2) 执行的硬件设计修改，以及 (3) 执行的系统设计修改（[Mohanty, 2018a](#Chapter1.html#c01_bib10), [2018b](#Chapter1.html#c01_bib14)）。总体而言，如果系统在设计阶段融入安全、隐私和 IP 保护解决方案，并从可信供应商和可信制造单位获取组件，则可以将其视为可信。

众所周知，CE 系统是各种类型硬件、软件和固件的异构组合，可以概念化为模拟/混合信号片上系统（AMS-SoC）（[Mohanty, 2015](#Chapter1.html#c01_bib13））。CE 或 CE 系统本质上是 AMS-SoC，几乎包含一切，例如，智能手表、智能相机、智能手机、智能汽车、智能医疗设备等（参见 [图 1.1](#Chapter1.html#c01_fig1））。在硬件-数字-硬件、模拟硬件、RF 硬件和混合信号硬件中，都需要用于 CE 系统中发生的各种信号处理和通信。内存用于缓冲处理和存储。软件包括系统软件、应用软件和中间件。典型 CE 系统的任何组件都可能产生安全漏洞（[Mohanty, 2018a](#Chapter1.html#c01_bib10), [2018b](#Chapter1.html#c01_bib14)）。本节将简要介绍，详细讨论将在相应章节中进行。以下部分讨论硬件设计流程，更具体地说是架构级别。

## 1.2 硬件辅助安全与 IP 核心保护

目前，CE 设备的设计时代包含复杂的数据/控制密集型硬件，例如以 IP 核心形式存在的 DSP 核心，这些核心依赖于全球集成电路（IC）供应链。为了提高设计效率并加快设计速度，CE 设备中 DSP 应用使用 IP 核心（通常由第三方供应商提供）已成为 CE 行业的典型做法。然而，日益严重的安全威胁和上升的盗版担忧使全球供应链变得脆弱（[Sengupta, 2015](#Chapter1.html#c01_bib20), [2016](#Chapter1.html#c01_bib19)）。[图 1.2](#Chapter1.html#c01_fig2) 显示了典型片上系统设计周期中的硬件威胁，该周期包含第三方 IP（3PIP）核心。第一个位置是在从外部供应商导入 3PIP 核心的过程中，第二个位置是在晶圆厂执行设计网表复制的地方。因此，在这两个位置安全是强制性的。此外，[图 1.3](#Chapter1.html#c01_fig3) 显示了芯片设计周期中各种元素，这些元素本质上是可信或不可信的。其他形式的硬件威胁，例如 IP 核心所有权侵权、IP 核心买方所有权等，也是可能的，这将在本章后半部分和其他章节中讨论。
