
# AES 算法主要阶段

AES 算法的第一个主要阶段是“字节替换层（S-box）”，负责使用查找表对状态中的每个元素进行非线性变换。此步骤的主要意义是向数据元素添加“混淆（confusion）”。换句话说，单个状态位中实现的变换会迅速传播到数据路径中。第二个主要阶段称为“扩散（Diffusion）”，由两个子层组成，即“行移位（ShiftRows）”，它在字节级别上对数据进行置换；以及“列混合（MixColumn）”，这是一种基于矩阵的操作，负责混合四字节数据块。“扩散（Diffusion）”的意义是向数据元素引入扩散属性。第三个主要阶段是“密钥加（key addition）”层，负责将 128 位密钥（或其派生密钥）与执行“列混合（MixColumn）”操作后得到的每个元素的状态进行异或运算。最后，“密钥调度（key schedule）”从原始 AES 密钥计算轮密钥或子密钥（`k[0]`, `k[1]`, …, `k[nr]`）。[Figure 10.2](#Chapter10.html#c10_fig2) 以设计流的形式展示了 AES 算法的主要步骤，突出了负责执行特定操作的每个模块。作为示例，我们使用 128 位密钥长度进行演示（[Paar and Pelzl, 2009](#Chapter10.html#c10_bib5)）。

## 10.2.2.1 Byte substitution (S-box) layer

S-box 是 AES 的非线性组件，负责位操作。它由 16 个 S-box 组成，所有 S-box 都相互相同。所有 256 个可能的输入元素都有唯一的输出元素映射。S-box 如 [Figure 10.3](#Chapter10.html#c10_fig3) 所示，并采用自 [Paar and Pelzl (2009)](#Chapter10.html#c10_bib5)。例如，如果 S-box 的输入字节是 `(B2)[hex]`，则基于 S-box 中的映射，输出字节是 `(37)[hex]`。换句话说，`S((B2)[hex]) → (37)[hex] → S(10110010) → 00110111`。这清楚地展示了如何使用 AES 的字节替换层实现位操作。如 [Figure 10.2](#Chapter10.html#c10_fig2) 所示，字节 `X[0]`, `X[1]`, `X[2]`, …, `X[15]` 使用 S-box 替换为 `Y[0]`, `Y[1]`, `Y[3]`, …, `Y[15]`。每四个字节的数据 `X[0]`, `X[1]`, `X[2]`, `X[3]` 转换为 `Y[0]`, `Y[1]`, `Y[2]`, `Y[3]`。同样，对于接下来的四个字节 `X[4]`, `X[5]`, `X[6]`, `X[7]` 转换为 `Y[4]`, `Y[5]`, `Y[6]`, `Y[7]`。进一步类似地，接下来的四个字节 `X[8]`, `X[9]`, `X[10]`, `X[11]` 转换为 `Y[8]`, `Y[9]`, `Y[10]`, `Y[11]`。最后，最后四个字节 `X[12]`, `X[13]`, `X[14]`, `X[15]` 转换为 `Y[12]`, `Y[13]`, `Y[14]`, `Y[15]`。

## 10.2.2.2 Row-shifting diffusion layer

`ShiftRows` 变换的意义在于增强 AES 的扩散过程。此变换的工作方式如下：

1. 第一行保持不变。
2. 第二行循环右移三个字节。
3. 第三行循环右移两个字节。
4. 第四行循环右移一个字节。

字节替换层的输出作为输入馈送到 `ShiftRows` 扩散层，如下所示。假设字节替换层的输出是 `Y[0]`, `Y[1]`, `Y[2]`, `Y[3]`, …, `Y[15]`。它按如下矩阵形式排列，如 [Table 10.1](#Chapter10.html#c10_ufig1) 所示。每行应用的变换通过箭头顶部的注释指示。每四个输入字节的输出在每一列中指示。例如，对应于输入四个字节 `Y[0]`, `Y[1]`, `Y[2]`, `Y[3]`，转换后的输出四个字节是 `Y[0]`, `Y[5]`, `Y[10]`, `Y[15]`，如 [Table 10.2](#Chapter10.html#c10_ufig1) 所示。同样，对每一列中的其余四个字节也获得输出。

## 10.2.2.3 MixColumn diffusion layer

此步骤是 AES 的主要扩散过程，因为每个输入字节都会影响四个输出字节。它负责混合状态矩阵的每一列。`MixColumn` 扩散层的输入是 `ShiftRows` 扩散层的输出。为了执行 `MixColumn` 扩散，每个 4 字节列被视为向量，并乘以一个固定的 4 × 4 矩阵。该矩阵包含一些常量值。需要注意的是，矩阵加法和乘法在伽罗瓦域（GF）算术中执行（不是整数算术）。作为 `MixColumn` 扩散输入的 `ShiftRows` 扩散的前四个输出字节是 `Y[0]`, `Y[5]`, `Y[10]`, `Y[15]`，被视为向量并乘以一个固定的 4 × 4 矩阵，如下所示。同样，作为 `MixColumn` 扩散输入的 `ShiftRows` 扩散的接下来的四个字节是 `Y[4]`, `Y[9]`, `Y[14]`, `Y[3]`。此外，作为 `MixColumn` 扩散输入的 `ShiftRows` 扩散的接下来的四个字节是 `Y[8]`, `Y[13]`, `Y[2]`, `Y[7]`。最后，作为 `MixColumn` 扩散输入的 `ShiftRows` 扩散的最后四个字节是 `Y[12]`, `Y[1]`, `Y[6]`, `Y[11]`。相应的输出是 `Z[0]`, `Z[1]`, `Z[2]`, `Z[3]`；`Z[4]`, `Z[5]`, `Z[6]`, `Z[7]`；`Z[8]`, `Z[9]`, `Z[10]`, `Z[11]`；`Z[12]`, `Z[13]`, `Z[14]`, `Z[15]`。

同样，其余方程可以通过矩阵乘法推导，然后进行 GF 算术计算。注意：在 GF 算术中，加法是相应字节的简单按位异或。乘以 01 是乘以单位元，不包含任何特定操作。乘以 02 可以实现为乘以 `x`，即左移一位，并对 8 位数据进行 `P(x) = (x⁸ + x⁴ + x³ + x + 1)` 或对 4 位数据进行 `(x⁴ + x + 1)` 的模约减。注意：在 AES 中，乘法后不可能得到 4 位乘积，因此使用 `P(x) = (x⁸ + x⁴ + x³ + x + 1) → (100011011)`。同样，乘以 03，表示多项式 `(x + 1)`，可以通过左移一位并加上原始值，随后对 `P(x)` 执行模约减来实现。
