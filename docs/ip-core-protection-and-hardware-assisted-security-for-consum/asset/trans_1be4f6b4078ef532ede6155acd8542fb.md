# 符号列表

## 第 2 章

| M | = 内存 |
| V | = 内存内容 |
| A | = 内存地址 |
| `M[R, A]` | = 读取地址 A 处的内存，并返回与 `A` 关联的数据 |
| `M[W, A, V]` | = 将值 `V` 写入地址 `A` |
| `T` | = 时间实例 |
| `M[W, A, V, T]` | = 在时间 `T` 将值 `V` 写入地址 `A` |
| `M[R, A, T]` | = 读取地址 `A` 处的内存，并返回在时间 `T` 时与 `A` 关联的数据 |
| `V[A]` | = 在时间 `T[A]` 时地址位置 A 处的值 |
| `V[A]^(*)` | = 在时间 `T[B]` 时地址位置 A 处的值 |
