### 10.2 AES algorithm

#### 10.2.1 Overview of AES

AES algorithm has three different variations of key sizes, i.e., 128 bits or 192 bits or 256 bits. The input data size is 128 bits and the output encrypted data is also 128 bits. The input data is called the plain text and the output encrypted data is called cypher text. [Figure 10.1](#Chapter10.html#c10_fig1) shows the AES input/output parameters. The core structure of AES comprises the following components: (i) byte substitution layer, (ii) diffusion layer, (iii) key addition layer, and (iv) key schedule ([Kosaraju *et al.*, 2006](#Chapter10.html#c10_bib2); [Mohanty *et al.*, 2007](#Chapter10.html#c10_bib4)). Three key lengths are supported in AES. The number of internal rounds of the cipher depends on the key length. For example, in case of 128 bit key length, the number of internal rounds (*n*[*r*]) is 10, while for 192 bit key length, the number of internal rounds is 12, and finally for 256 bit key length, the value of *n*[*r*] is 14, respectively.
