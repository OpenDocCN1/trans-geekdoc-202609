## 4.5 Conclusion

This chapter discussed in details about hardware watermarking of DSP application based IP cores used in CE devices. Several selected state-of-the-art watermarking approaches at different abstraction levels were reviewed. Two watermarking approaches used for DSP cores have been presented with greater details. These approaches implant watermark signature digits before RTL synthesis (during high-level synthesis). Embedding watermarking before RTL synthesis enables watermarking constraints to propagate to the lower levels of design. For example, how gate level design of a DSP core reflects the watermarking constraints that is embedded at its higher design level is explained and demonstrated with examples in this chapter. This chapter also lucidly explains the design flow of designing a watermarked DSP core with some industry standard examples of FIR filter, IIR low-pass Butterworth filter, etc. Details on security metrics were also presented and analyzed. We also demonstrate why hardware watermarking is an extremely useful tool for combating false claim of ownership, IP piracy, forgery, and other attacks.
