

另一方面，结构混淆通过变换、逻辑组件的任意分配、插入虚拟导线或不规则布线，试图隐藏设计的正确功能 ([Vijayakumar *et al.*, 2017](#Chapter7.html#c07_bib44))。换句话说，结构混淆将 IP 核的架构从其标准结构改变为不明显的结构，同时保持其功能。因此，即使对手物理篡改或对 IP 核进行逆向工程（RE）以获取其设计，他/她通过检查其结构来发现其功能也会更加困难。结构混淆不会向设计中插入任何额外的密钥门组件。因此，结构混淆不存在设计开销。在结构混淆技术中，设计在其功能对对手隐藏之前是安全的。但是，如果应用程序被攻击者追踪，结构混淆无法保护 IP 核。

高级变换，如流水线、交错、展开、折叠、树高变换（THT）、冗余操作消除和前瞻变换，可以在 DSP IP 核的架构综合过程中应用，以在面积、功耗和延迟等多个设计目标之间实现权衡。但是，这些变换也可以用作结构混淆技术 ([Sengupta and Roy, 2017](#Chapter7.html#c07_bib32); [Parhi, 2012](#Chapter7.html#c07_bib20))。这些高级变换在保持实际功能不变的同时，显著修改了 DSP IP 核的结构。这些改动导致同一 DSP IP 核具有多个模糊的架构。Lao 和 Parhi ([2015](#Chapter7.html#c07_bib14)) 的作者通过单一高级变换技术（即折叠）对 DSP 电路进行了结构混淆（注：尽管 Lao 和 Parhi ([2015](#Chapter7.html#c07_bib14)) 的作者进行了结构混淆和功能混淆，但本章仅关注结构混淆部分）。折叠变换生成各种有意义的模式，增加了攻击者区分不同模式中正确功能的复杂度。此外，不同的折叠因子会导致不同的等效电路，从而给攻击者带来歧义。根据 Lao 和 Parhi ([2015](#Chapter7.html#c07_bib14))，可以观察到，由于折叠变换，功能不同的电路可能具有相同的结构，而功能相同的电路可能具有不同的结构。由于折叠因子对设计成本有至关重要的影响，选择合适的折叠因子可能会导致优化的 DSP 电路设计。但是，上述方法中未提出最优折叠因子评估。因此，可能会导致更高的设计开销。此外，基于单一高级变换的 ([Lao and Parhi, 2015](#Chapter7.html#c07_bib14)) DSP 应用结构混淆，与基于多阶段高级变换的结构混淆 ([Sengupta *et al.*, 2017a](#Chapter7.html#c07_bib36)) 相比，安全性较低。

Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) 在架构综合过程中，对 DSP 核心/内核执行了基于多个编译器驱动的高级变换的结构混淆。与 Lao 和 Parhi ([2015](#Chapter7.html#c07_bib14)) 不同，这种方法还能够对基于循环的 DSP 应用进行混淆。此外，由于多个高级变换，混淆后的 DSP IP 核对门级结构的影响与其原始结构有显著不同，从而增强了逆向工程复杂度。此外，该方法执行优化以选择满足延迟、面积和全包设计成本等设计目标的低成本架构。因此，Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) 提出了一种基于编译器驱动、低成本、多阶段变换的结构混淆方法，具有更强的鲁棒性。该方法的详细解释在 7.3 节中讨论。

## 7.3 基于编译器变换的结构混淆

如前所述，由于插入了额外的逻辑元素以及缺乏选择低成本设计架构的框架，在 DSP IP 核的背景下，逻辑混淆的开销显著大于结构混淆。此外，逻辑混淆技术容易受到多种攻击策略的攻击，例如密钥敏感化 ([Rajendran *et al.*, 2015](#Chapter7.html#c07_bib23))、布尔 SAT 和基于爬山搜索的攻击 ([Subramanyan *et al.*, 2015](#Chapter7.html#c07_bib38))。此外，Lao 和 Parhi ([2015](#Chapter7.html#c07_bib14)) 提出的结构混淆由于其基于单阶段变换的混淆技术，对逆向工程攻击的安全性较低。Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) 提出的多阶段结构混淆方法通过将 DSP 应用的设计通过多个连续的编译器驱动变换技术转换为不明显的结构，从而隐藏其功能。尽管编译器驱动的变换是设计优化的已知概念，但据作者所知，这些变换技术从未被用于执行结构混淆。这些变换增加了对手发现其功能的复杂度。五种高级变换方法，即冗余操作消除 (ROE)、逻辑变换 (LT)、THT、循环展开 (LU) 和循环不变代码外提 (LICM)，用于混淆基于循环和非循环的 DSP IP 核 ([Sengupta *et al.*, 2017a](#Chapter7.html#c07_bib36))。但是，基于循环的变换（即 LU 和 LICM）不适用于非循环的 DSP 应用。结构混淆后的设计进一步使用基于 PSO 的设计探索 (DSE) 进行探索，以获得低成本的设计架构 ([Sengupta *et al.*, 2017b](#Chapter7.html#c07_bib37))。最后，创建了一个低成本的结构模糊 DSP IP。低成本多阶段驱动结构混淆过程的图示如 [Figure 7.4](#Chapter7.html#c07_fig4) 所示。Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) 中使用的每个高级变换过程的详细解释在 7.3 节中解释。

### 7.3.1 制定和评估模型

#### 7.3.1.1 制定

为给定的 DSP 核（表示为 C 代码/DFG 或基于循环的 CDFG）确定一个低成本的结构混淆设计，需在用户指定的面积-延迟约束内。

***Minimize:*** 最小化结构混淆设计成本 (`A[total]^(obf)`, `L[total]^(obf)`)，以获得最优设计解 (`X[i]`)，其中 (`X[i]`) = `N(R[1])`, `N(R[2])`, … , `N(R[D])`，在行为级；且 `N(R[D])` 是资源类型 `R[D]` 的数量。

***Subject to:** `A[total]^(obf)` ≤ `A[cons]` 和 `L[total]^(obf)` ≤ `L[cons]` 以及通过结构混淆实现抗逆向工程 IP 核，其中 `A[total]^(obf)` 和 `L[total]^(obf)` 分别是结构混淆设计的总面积和延迟，`A[cons]` 和 `L[cons]` 分别是用户提供的面积和延迟约束。
