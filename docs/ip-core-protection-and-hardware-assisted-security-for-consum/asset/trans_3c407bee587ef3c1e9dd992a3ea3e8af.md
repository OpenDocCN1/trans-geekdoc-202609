*串联*：如 [Sengupta 和 Kachave (2018)](#Chapter6.html#c06_bib26) 以及 Kachave 和 Sengupta ([2017](#Chapter6.html#c06_bib10)) 所述，用于检测串联特征存在的算法流程图如 [图 6.8](#Chapter6.html#c06_fig8) 所示。特征提取算法以 IP 核心的控制器 HDL 作为输入，并输出是否检测到串联特征。串联检测的判定如下：如果在 `i` 个 FU 的执行期间，执行了多个（“m”）个 `j` 个 FU 的实例，则 IP 核心设计中存在串联特征。该算法针对 `i` = 1–`n` 执行，其中“`n`”是特定 IP 核心中存在的 FU 总数。第二个“if”语句（在 [图 6.8](#Chapter6.html#c06_fig8) 中）确保算法针对除 `i` 个 FU 之外的所有 `j` 个 FU 运行。随后，第三个“if”语句仅允许那些与 `i` 个 FU 进行比较的 `j` 个 FU 的实例，这些实例在单个 `i` 个 FU 之间开始（表示为 `CS[S](FU[i] ≤ CS[S](FU[j])`）和结束（表示为 `CS[E](FU[i] ≥ CS[E](FU[j])`），其中 `CS[S](FU[i])` 和 `CS[S](FU[j])` 分别表示 `i` 个和 `j` 个 FU 的起始控制步骤。同样，`CS[E](FU[i])` 和 `CS[E](FU[j])` 分别表示 `i` 个和 `j` 个 FU 的结束控制步骤。最后，最后一个“if”语句检查在 `i` 类型 FU 的执行时间（`CS[E](FU[i]) – CS[S](FU[i])`）期间，是否执行了多个 `j` 类型 FU 的实例。因此，如果最后一个 `if` 条件满足，则在 DSP IP 核心中检测到串联特征。[图 6.9](#Chapter6.html#c06_fig9) 显示了 IP 核心控制器的部分 HDL 代码。如控制器 HDL 所示，乘法器 FU 在控制步骤 1 中被启用，由语句 `MUL_En_1<= “1”` 表示。加法器 FU 在第一个 CS 中启用，在第二个 CS 中禁用。此外，第二个加法器 FU 实例在第三个 CS 中激活，在第四个 CS 中停用。最后，乘法器 FU 执行持续到在 CS = 40 时被禁用。因此，在单个乘法器 FU 执行期间，执行了多个加法器 FU 实例。这表明该 IP 核心设计中存在串联特征。

1. *多周期*：要检测 IP 核心中的多周期特征，特征提取规则读取相应 IP 核心的控制器 HDL 代码。它检查是否检测到任何 FU 的执行时间消耗超过一个 CS。如果条件为真，则推断该 IP 核心设计中存在多周期特征。检测 IP 核心控制器 HDL 代码中多周期存在的条件为：`CS[E](FU[i]) > CS[S](FU[i])`，其中 `CS[S](FU[i])` 和 `CS[E](FU[i])` 分别表示 `i` 个 FU 的起始和结束控制步骤。

3. *设计目标*：用于设计 IP 核心的通用 HLS 工具通常至少有一个设计目标。设计目标通常基于功耗-延迟权衡或面积-延迟权衡等优化。基于支持的设计目标，可将一种用于 IP 核心创建的工具与另一种工具区分开来。用于提取设计目标特征的特征提取算法以 HLS 工具可执行版本的用户界面（图形或非图形）作为输入。随后，提取算法读取界面并确定工具用户界面中可供选择的设计目标。随后，将界面的设计目标与待测 IP 核心数据表中提到的设计目标详细信息进行匹配和验证。

4. *可靠性*：可靠性可以采取多种形式，例如针对瞬态故障的可靠性（可检测性/安全性）和针对永久故障的可靠性（可检测性/安全性）([Inoue *et al.*, 2011](#Chapter6.html#c06_bib7); [Nomura *et al.*, 2011](#Chapter6.html#c06_bib19))。旨在设计可靠系统的典型方法利用模块化冗余 ([Inoue *et al.*, 2011](#Chapter6.html#c06_bib7); [Yu and McCluskey, 2001](#Chapter6.html#c06_bib38); [D'Angelo *et al.*, 1999](#Chapter6.html#c06_bib2))。冗余可以是双模块冗余 (DMR)、三模块冗余或多模块冗余。然而，迄今为止，在文献中，例如 Inoue *et al.* ([2011](#Chapter6.html#c06_bib7))，DSP IP 核心供应商仅使用 DMR 实现了针对瞬态故障的可靠性。因此，仅针对该特征讨论了特征提取规则。该规则旨在检测 DSP IP 核心设计中 DMR 逻辑的存在。

可靠性特征提取过程以 IP 核心的数据路径 HDL 作为输入，旨在检测 DMR 系统的存在。如 [图 6.12](#Chapter6.html#c06_fig12) 所示，在典型的 DMR 系统中，DMR 系统中每个模块的输出使用比较器组件进行比较，以确定是否检测到故障。该比较器组件接受来自第一个模块（原始）的输出寄存器的一个输入和来自第二个模块（副本）的另一个输入。如果检测到类似于 HDL 中以下端口映射语句的端口映射：`port map (output register signal 1, output register signal 2, comparator output signal)`，则相应的 IP 核心中存在可靠性特征。
