

集成电路的设计随着消费电子行业实现和应用技术的变革，已发展到前所未有的复杂程度。使用由架构综合生成的数字信号处理（DSP）知识产权（IP）核心（[Castillo *et al.*, 2007](#Chapter5.html#c05_bib1）），不仅能在上市时间压力与设计生产力之间保持适当平衡，还能帮助降低设计成本。高层次综合（HLS）([Sengupta and Sedaghat, 2011](#Chapter5.html#c05_bib2), [2013](#Chapter5.html#c05_bib4)) 是一种自动化设计过程，它通过调度、硬件和寄存器分配以及绑定等多个子过程，将数字电路或 IP 的算法/行为描述转换为相应的寄存器传输级（RTL）数字硬件（[Mohanty, 2015](#Chapter5.html#c05_bib15））。在制造 IP 核心的过程中，涉及两个实体，即卖方和买方。IP 卖方（也称为 IP 厂商）是 IP 的创建者，而 IP 买方（也称为 IP 用户）是 IP 的购买者。然而，为了在基于复合 SoC 的设计中维持 IP 核心的可行应用，保护两个实体免受威胁至关重要。让我们现在讨论 IP 买方和 IP 卖方的保护方面。在 IP 核心中，IP 买方可以作为买方主张买方特权，以便同一 IP 副本不应可供其市场竞争对手使用/访问。当 IP 卖方从 IP 买方处获得 IP 核心的定制规格时，这成为可能，从而在双方之间创建独占的一对一映射。将唯一买方签名（称为买方指纹）嵌入 IP 核心设计，有助于检测欺骗性卖方非法重新分发/转售的 IP 核心副本（[Gang and Potkonjak, 2007](#Chapter5.html#c05_bib3））。同样，IP 卖方必须在将设计出售给 IP 买方之前，保护其设计免受盗版和虚假所有权声明的侵害。将唯一卖方签名（称为卖方水印）嵌入 IP 核心设计，可保护 IP 核心免受所有权滥用（[Alkabani *et al.*, 2007](#Chapter5.html#c05_bib5); [Sengupta and Kundu, 2017](#Chapter5.html#c05_bib6); Sengupta *et al.*, [2017](#Chapter5.html#c05_bib7), [2018](#Chapter5.html#c05_bib38); [Kougianos *et al.*, 2009](#Chapter5.html#c05_bib8); [Maltoni *et al.*, 2009](#Chapter5.html#c05_bib9); [Roy *et al.*, 2008](#Chapter5.html#c05_bib10); [Alkabani and Koushanfar, 2008](#Chapter5.html#c05_bib11); Sengupta, [2016](#Chapter5.html#c05_bib36), [2017](#Chapter5.html#c05_bib35); [Sengupta and Roy, 2017](#Chapter5.html#c05_bib37)）。

因此，DSP IP 核心的对称保护既提供了用户权利，又消除了 IP 所有权滥用。主题摘要在 [Figure 5.1](#Chapter5.html#c05_fig1) 中突出显示。设计和验证 IP 核心需要在人力、时间和成本方面进行重大投资；然而，它可以被粗糙实体轻松克隆、修改或转售。因此，IP 设计的卖方和买方都希望消除虚假声明和非法转售 IP 核心的可能性。对称保护可以通过在 DSP IP 核心的任何设计抽象级别中植入双实体签名方案来实现。标准 IP 保护方法（[Yuan *et al.*, 2006](#Chapter5.html#c05_bib12)），如专利、版权、商标等，分布式、能力受限，并且从买方和卖方的角度来看，不足以保护 IP 核心。此外，图像、文本、视频和音频等不同多媒体应用中的多种签名嵌入方案也不适合保护 IP 核心，因为它们在签名插入过程中不保留设计的功能和精度。因此，从 IP 核心保护的角度来看，在嵌入任何签名时，有必要采取措施来保留设计的功能和正确性。

#### 5.1.1 水印和指纹背景

水印和指纹代表了 DSP 可重用 IP 核心两个不同实体的签名，以保护其相应的所有权。指纹传达 IP 买方的签名，而水印面向 IP 卖方。两种情况下的理想签名必须满足以下特征：

*   它必须作为 IP 设计的重要部分植入，以便无法通过传统扫描感知。

*   它必须具有不可模仿性，以便所有权证明可以轻松建立。

*   对于多签名植入机制，每个签名必须彼此独立。

*   它应具有抗篡改性，以便部分移除签名不应影响所有权证明。

*   它应能抵御逆向工程等攻击。

*   低嵌入运行时间。

*   植入签名后，名义延迟和硬件开销。

*   对于拥有编码规则全面认知的真实所有者，签名检测过程应无缝进行（[Koushanfar *et al.*, 2005](#Chapter5.html#c05_bib18); [Cox *et al.*, 2007](#Chapter5.html#c05_bib19)）。

*   植入签名后，必须维护 IP 核心的逻辑正确性。

#### 5.1.2 威胁模型

IP 核心安全的最终目标是：

1.  ***买方立场：*** 检测欺骗性 IP 卖方在市场上非法重新分发/转售的副本（[Gang and Potkonjak, 2007](#Chapter5.html#c05_bib3)）。

2.  ***卖方立场：*** 防止所有权被利用（[Yu and Zhu, 2011](#Chapter5.html#c05_bib13)）。

#### 5.1.3 高层次抽象保护的优势

尽管 DSP IP 核心保护可以在任何设计抽象级别提供，但嵌入买方指纹和卖方水印架构级别（Mohanty *et al.*, [2002](#Chapter5.html#c05_bib15), [2014](#Chapter5.html#c05_bib16））是有益的，因为在较高设计抽象级别嵌入的签名约束会自动传播到较低设计抽象级别；因此，它将保护设计的较高级别和较低级别。此外，在较高级别可以以较低的签名嵌入复杂性实现对称保护，同时产生较低的设计开销。Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 在架构综合/HLS 过程的多个子步骤中提出了一种基于多变量指纹和水印的对称 IP 核心保护机制。此外，该方法在同时纳入两个签名约束时，会产生最小的设计开销。

#### 5.2.1 非对称 IP 核心保护技术概述

根据文献，非对称 IP 核心保护技术主要从卖方角度提供保护。它可以通过三种不同的技术执行：(i) 硬件混淆，(ii) 计算机取证工程（CFE），以及 (iii) 水印。
