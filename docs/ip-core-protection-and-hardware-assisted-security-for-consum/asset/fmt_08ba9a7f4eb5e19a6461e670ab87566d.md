### 9.6 Conclusion

This chapter discussed a case study of structural obfuscation using JPEG CODEC IP core which is available in almost every CE devices. The design mechanism and implementation process of low-cost obfuscated on-chip IP core design for 2D-DCT-based JPEG image compression and decompression are explained here. This structural obfuscation hides an application and its implementation from an adversary by transforming its standard architecture to a non-obvious one. In this process, THT is used to structurally obfuscate the design and low-cost hardware configuration is explored through PSO-DSE engine. The devised IP core is synthesized and simulated through Intel Quartus Cyclone II FPGA. The designed IP core can be used as a dedicated IP core in any camera-based CE devices to perform image CODEC. Further, the robustness of the structurally obfuscated design is measured through SoO metric, which indicates that more than 76% SoO is achieved compared to a standard non-obfuscated JPEG CODEC design. Additionally, as structural obfuscation does not incur any design overhead, therefore, it is an extremely useful method of protection for Trojan insertion, IP piracy/counterfeit. The SoO of the devised JPEG CODEC IP core discussed in this chapter can be enhanced by performing multiple transformation techniques on the DFG of the JPEG CODEC IP core as a part of future work. Additionally, combination of functional obfuscation technique with structural obfuscation can also enhance the robustness for DSP applications. This would enable to hide an application and its implementation from an adversary.
