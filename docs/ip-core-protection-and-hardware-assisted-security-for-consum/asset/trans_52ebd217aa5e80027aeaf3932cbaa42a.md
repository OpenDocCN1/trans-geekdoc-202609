

上一节介绍了环形振荡器 PUF 及其在不同应用中可实现的多种设计。上一节中介绍的部分设计是可重构的，而另一些设计则生成一组固定的 CRPs，且设计本身不可重构。本节重点介绍 PUF 设计的可重构性。可重构性是 PUF 设计的一个重要方面。如果攻击者获得设备并执行机器学习、仿真、中间人攻击和逆向工程（RE）等攻击，则可能会重新生成 CRPs。引入可重构或动态 PUF 是为了提高 PUF 对这些攻击的安全性，并在必要时能够生成新的 CRP 集。在仲裁者 PUF 中引入了前馈结构，以避免使用线性建模的攻击。这在设计中引入了一些非线性，以牺牲设计复杂度为代价提高了设计的安全性和鲁棒性。这也可以通过其他技术实现，例如在将挑战输入馈入 PUF 之前对其进行预处理，对 PUF 的输出响应进行后处理，以及在模块输出添加一些可用于重构响应位的组件。预处理挑战位可以通过引入可实现线性反馈移位寄存器（`LFSR`）的额外电路，或通过引入哈希来完成。响应位的后处理可以指对位引入哈希。[图 12.10](#Chapter12.html#c12_fig10) 展示了在输入端带有 `LFSR` 的仲裁者 PUF 设计。馈入 PUF 的挑战输入不会直接馈入仲裁者 PUF。最初，它们会通过 `LSFR` 进行预处理，然后作为输入馈入 PUF，如 [图 12.10](#Chapter12.html#c12_fig10) 中所示的“真实挑战”（Lao 和 Parhi, 2011）([Chapter12.html#c12_bib34](#Chapter12.html#c12_bib34))。引入输入可重构电路后，可以提高整体设计的鲁棒性和可重构性。

[图 12.14](#Chapter12.html#c12_fig14) 展示了轻量级 PUF 的设计。该设计由 Majzoobi *et al*. (2008) ([Chapter12.html#c12_bib46](#Chapter12.html#c12_bib46)) 提出，具有改进的鲁棒性和更高的安全性。在此 PUF 设计中，输入和输出处各有一个网络，“输入网络”接收挑战输入，“输出网络”输出响应。该模块本身将包含若干由输入和输出网络运行的并行 PUF 结构。为了将挑战输入连接到若干并行 PUF 结构，实现了一个互连网络。单个 PUF 将满足严格雪崩标准（`SAC`）。如果单个输入位的取反会以 50% 的概率导致每个输出位发生变化，则称任何加密原语满足 `SAC`。但是，当考虑设计的整体并行网络时，`SAC` 不会被满足。

[图 12.15](#Chapter12.html#c12_fig15) 展示了一种混合振荡器仲裁者 PUF 的设计，该设计使用 `RO` 作为模块中的主要组件，并且也可以重构（Yanambaka *et al*., 2018）([Chapter12.html#c12_bib78](#Chapter12.html#c12_bib78))。如图所示，有两组不同的 `RO` 连接到两个多路复用器“Mux 1”和“Mux 2”。`RO` 将生成馈入多路复用器的振荡。馈入 PUF 模块的挑战输入充当多路复用器的选择线。根据给定的挑战输入，多路复用器选择不同的 `RO`。Mux 1 的输出作为 D 输入馈入 D 触发器，Mux 2 的输出作为时钟信号馈入 D 触发器。由于 `RO` 的差异，产生的振荡频率不会相同。因此，D 触发器的输出将根据输入挑战而变化。通过更改选择线输入可以实现不同的输入配置。通过增加设计中的 `RO` 数量可以提高设计提供的鲁棒性和安全性，但这也会增加复杂度和占用的芯片面积。

### 12.7 基于 SRAM 的 PUF

许多设备和开发板都有 `SRAM`，可用于设计 PUF。[图 12.16](#Chapter12.html#c12_fig16) 展示了 6T `SRAM` 单元的电路设计（Mohanty, 2015）([Chapter12.html#c12_bib53](#Chapter12.html#c12_bib53))。PUF 使用 `SRAM` 单元的启动值来生成输出位。与其他 PUF 设计相比，`SRAM` PUF 的可靠性和唯一性较低。如 [图 12.16](#Chapter12.html#c12_fig16) 所示，`SRAM` 单元可以使用交叉耦合反相器设计，并能够存储单个二进制数据位，“1”或“0”。当 `SRAM` 单元通电时，PUF 利用其初始条件来生成唯一输出。但是，`SRAM` 单元在启动时的行为存在问题。Schrijen 和 Leest (2012) ([Chapter12.html#c12_bib65](#Chapter12.html#c12_bib65)) 比较和分析了在不同温度和供电电压下运行的不同 `SRAM` 内存模块。该分析由 Schrijen 和 Leest (2012) ([Chapter12.html#c12_bib65](#Chapter12.html#c12_bib65)) 通过计算启动时以及 20 °C、-40 °C 和 80 °C 各种温度下的参考位来执行，这显示了 `SRAM` 的稳定性。`SRAM` 的供电电压也变化了 10%。这不影响 PUF 的性能，正如所声称的（Schrijen 和 Leest, 2012）([Chapter12.html#c12_bib65](#Chapter12.html#c12_bib65))，因为启动条件是在最初几个纳秒内达到的。
