# List of notations

## Chapter 2

| M | = memory |
| V | = contents of memory |
| A | = addressed of memory |
| `M[R, A]` | = memory at the address A is read and it will return the data that is associated at `A` |
| `M[W, A, V]` | = the value `V` is written into the address `A` |
| `T` | = time instance |
| `M[W, A, V, T]` | = the value `V` is written into the address `A` at time `T` |
| `M[R, A, T]` | = memory at the address `A` is read and it will return the data that is associated at `A` at time `T` |
| `V[A]` | = the value at the address location A at a time `T[A]` |
| `V[A]^(*)` | = the value at the address location A at a time `T[B]` |
