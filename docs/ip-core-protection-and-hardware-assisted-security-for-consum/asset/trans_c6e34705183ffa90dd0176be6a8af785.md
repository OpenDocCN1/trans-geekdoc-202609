中间人攻击可以通过在分布式计算等各种应用中实现 PUF 模块来控制（[Gassend *et al*., 2002](#Chapter12.html#c12_bib15)）。此类攻击涉及的不同步骤如下：

*   “A” 应该使用 A 与 PUF 之间共享的 CRPs 与 PUF 模块进行交互。

*   “B” 是一个可以访问 PUF 模块的攻击者。因此，B 将能够通过提供由 B 选择的挑战输入来从模块中收集响应。B 想要使用“A”的身份并用虚假结果进行冒充。

*   A 从 CRP 列表中给出 PUF 挑战，并将来自 PUF 模块输出的响应与私有列表进行比较。

*   B 可以访问挑战和 PUF，因此可以针对该特定挑战从 PUF 获取响应。

*   B 将能够通过假装 A 拥有 PUF 访问权限来欺骗 A，并可以将 PUF 假装成 A 进行冒充。

PUF 的应用非常广泛，如 [图 12.29](#Chapter12.html#c12_fig29) 所示。它们也可以用于需要随机性的应用程序或设备中。PUF 模块是各种应用（例如 RFID 标签、随机数生成、密钥生成、设备身份验证等）的优雅解决方案（[Gunlu and Iscan, 2014](#Chapter12.html#c12_bib18）；[O’Donnell *et al*., 2004](#Chapter12.html#c12_bib55）；[Suh and Devadas, 2007](#Chapter12.html#c12_bib69）；[Suh *et al*., 2005](#Chapter12.html#c12_bib70)）。PUF 还被用于消费电子设备中，这些设备需要低成本的身份验证（[http://www.eecs.mit.edu/news-events/media/mit-spinoff-verayo-developed-srini-devadas-gains-increased-use-commercial](http://www.eecs.mit.edu/news-events/media/mit-spinoff-verayo-developed-srini-devadas-gains-increased-use-commercial)）。

在密码和安全应用中，随机数生成可用于生成加密和解密密钥、初始种子值，以及在某些需要的情况下，向填充方案和协议引入一些随机性。伪随机数生成（PRNG）不是真正的随机，在这种情况下，模式会在一定数量的迭代后重复。PRNG 生成的每个数字都必须经过非常复杂的算法。在 PRNG 的情况下，初始种子值应保持高度机密。由于 PRNG 存在所有这些不同的问题，硬件随机数生成（HRNG）已在各种情况下实现（[O’Donnell *et al*., 2004](#Chapter12.html#c12_bib55)）。在 HRNG 的情况下，生成真正的随机数不需要初始种子。基于延迟的 PUF 电路将把输入信号的上升沿和挑战位作为多路复用器的选择线。输入将通过一系列多路复用器传播，并根据每个多路复用器提供的延迟，D 触发器将生成输出位“1”或“0”。亚稳态 PUF 将给出无偏的输出响应。冯·诺依曼校正将从 *N* 位输入生成 32 位输出响应。同样，有各种 PUF 设计可以根据应用程序的要求实现。[图 12.30](#Chapter12.html#c12_fig30) 显示了使用 PUF 模块的密钥生成系统。

在芯片上使用 PUF 的身份验证方案时，可信方或制造商应将指数级数量的 CRPs 存储在安全数据库中，以便进行身份验证匹配（[Suh and Devadas, 2007](#Chapter12.html#c12_bib69)）。对于输入挑战，PUF 的输出是相同的，在这种情况下，被挑战的设备将是真实的。但在使用挑战输入时，应通过丢弃已使用的挑战来避免中间人攻击。

受控 PUF 模块也可用于认证执行。这是在远程服务器上执行或运行程序的过程，客户端可以依赖服务器生成的结果（[Gassend *et al*., 2002](#Chapter12.html#c12_bib15)）。[图 12.31](#Chapter12.html#c12_fig31) 显示了使用 PUF 通过网络对人员进行身份验证的过程。在这种情况下，PUF 设备将生成一个挑战输入并具有相应的响应。当需要身份验证时，响应将发送到服务器，服务器确认客户端的身份。这可以帮助避免身份欺诈并使客户端的结果无效。这还可以避免攻击者生成不同的恶意结果并将其发送给用户。这种情况在分布式计算中经常出现，其中一个处理器无法处理工作流。这种类型的 PUF 模块也可用于将特定软件的使用限制在相应数量的处理器上。

[图 12.32](#Chapter12.html#c12_fig32) 显示了一款内置 PUF 模块的安全数码相机的设计（[Haider *et al*., 2016](#Chapter12.html#c12_bib19)）。相机传感器控制器的安全启动用于确保启动时平台的完整性。基于 PUF 的安全密钥生成和存储模块为感知数据证明提供密钥，以确保完整性和真实性。在安全相机的系统架构中，基于 PUF 的密钥生成和存储模块有两个级联组件，即 PUF 源和辅助数据算法（HDA）。HDA 的选择取决于 PUF 源的选择。HDA 用于获得：(1) 在一系列环境和操作条件下完全可重复的 PUF 响应，换句话说，来自同一 PUF 的任何两个响应之间的 HD 为零，以及 (2) 几乎均匀分布的 PUF 响应。

如今，物联网应用变得越来越必要。许多情况下，设备必须部署在无法监控或没有人类交互的地方。此类情况更容易受到拥有设备访问权限且无安全防护的攻击者的攻击。PUF 可用于阻止此类情况下的攻击，从而保护整个设备网络（[Mohanty *et al*., 2016](#Chapter12.html#c12_bib54）；[Yanambaka *et al*., 2017](#Chapter12.html#c12_bib77)）。
