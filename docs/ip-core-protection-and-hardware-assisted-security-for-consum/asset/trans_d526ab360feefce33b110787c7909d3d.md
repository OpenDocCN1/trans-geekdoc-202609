

# 入侵检测系统

入侵检测系统是一种防止攻击者进入系统网络的方式（[Sedjelmaci *et al.*, 2017](#Chapter2.html#c02_bib79））。在延迟容忍网络中，通信是稀疏的，因此部署分布式入侵检测系统是一种更好的方法。当采用分布式入侵检测系统（IDS）时，不同的节点将能够触发 IDS 并监控传入数据的各种行为。每个无人机都将能够监控邻居并保护整个网络。当网络中检测到恶意无人机时，它会发送有关该无人机的数据，并且恶意无人机将失去留在网络中的能力。因此，整个网络可以轻松保护。为检测 GPS 欺骗和干扰编写了不同的规则（[Hartmann and Steup, 2013](#Chapter2.html#c02_bib31); [Kim *et al.*, 2012](#Chapter2.html#c02_bib40)）。欺骗攻击有不同的特征：它会生成一个高强度信号，信号强度强度（SSI）远高于卫星。攻击者还会从同一方向和同一天线发送多个信号。所有这些信号都将具有相同的信号。因此，在检测此类攻击者时，无人机检测代理首先选择所有这些信号，并确定和计算其信号强度、SSI。然后，计算信号的均值和方差，如果它们在 ±3σ 范围内，则正确，如果不在范围内，则不正确，并且来自攻击者。

# 2.7 智能医疗安全

物联网（IoT）是各种收集数据、将其传输到云端并存储或处理数据的传感器的互连，正在成为包括医疗保健在内的各个行业的组成部分。使用医疗物联网（IoMT）或健康物联网（IoHT）的智能医疗理念在 [图 2.43](#Chapter2.html#c02_fig43) 中介绍。据估计，这个星球上的连接设备数量比人口还要多（[Li *et al.*, 2011](#Chapter2.html#c02_bib47），并且数量还在日复一日地增加。在传感器收集的所有数据中，健康数据是最敏感的信息之一。患者的健康状况应受到高度安全保护，确保数据不泄露。如果患者的医疗记录泄露，可能会导致社会排斥、保险、不利就业等重大问题。

![image](OEBPS/images/PBCS0600-02-f43.jpg)

图 2.43 医疗物联网（IoMT）或健康物联网（IoHT）

前几节讨论了各种可被利用并导致数据被盗的安全漏洞。这意味着没有系统是 100% 安全的。物联网网络是指连接设备和传感器的网络。如果一个设备受到攻击并被入侵，整个网络将面临危险。当涉及医疗设备时，这可能导致灾难性的结果，患者的生命可能面临危险。许多医疗设备会监控患者的某个参数，并按预设剂量输送药物。如果此类设备受到攻击，配置可能会更改，导致健康恶化。因此，患者的健康信息应保持机密。

关于健康信息隐私和安全的想法自动转向《健康信息隐私和安全法案》（HIPAA），以及《健康信息技术促进经济和临床健康法案》（HITECH）修正案。由美国卫生与公众服务部民权办公室（OCR）管理，HIPAA 规则对部分（但并非所有）健康信息的隐私、安全、个人权利和违规通知进行监管。此外，它们要求部分（但并非所有）处理该健康信息的人员采取物理、行政和技术保障措施，以各种形式保护该信息，并建立安全管理流程（包括风险分析和风险管理）以保护其电子形式。

## 2.7.1 智能医疗安全攻击

在智能医疗系统方面存在许多不同的风险（[Alamri, 2018](#Chapter2.html#c02_bib3); [Chaudhary *et al.*, 2018](#Chapter2.html#c02_bib16); [Ghoneim *et al.*, 2018](#Chapter2.html#c02_bib24); [Xiao *et al.*, 2018](#Chapter2.html#c02_bib108)）。[图 2.44](#Chapter2.html#c02_fig44) 显示了可针对智能医疗系统执行的不同类型的攻击。数据窃听是指攻击者监听医疗设备与接收器之间的通信，并从通信中窃取数据的过程。这可以通过使用安全通信来避免。数据隐私、数据机密性和位置隐私是医疗保健中的主要问题。在医疗设备的情况下会收集大量数据（[Sundaravadivel *et al.*, 2016](#Chapter2.html#c02_bib97)）。所有这些数据都需要安全地传输给医生。数据不应落入攻击者之手。数据应保持机密，隐私应被赋予最高优先级。每个设备都会被赋予一个唯一的标识，这也容易受到伪造攻击和欺骗攻击，这些攻击在 RFID 标签的情况下已被讨论。RFID 标签也可能用于医疗保健设备，这些设备容易受到可能导致身份威胁的不同攻击。攻击者可以接管设备的访问和控制，这将在本节后面进一步讨论。

![image](OEBPS/images/PBCS0600-02-f44.jpg)

图 2.44 针对智能医疗系统的攻击

[图 2.45](#Chapter2.html#c02_fig45) 显示了胰岛素输送系统的设计，该系统被各种糖尿病患者用于监测和控制体内的胰岛素水平（[Li *et al.*, 2011](#Chapter2.html#c02_bib47)）。系统中有各种组件，包括血糖监测仪，它可以监测血液中的葡萄糖水平；以及泵，在必要时用于将葡萄糖泵入血液；还有一个遥控器。血糖监测仪将配备葡萄糖传感器，用于感知血液中的葡萄糖水平，并在必要时将数据传输到胰岛素泵和计算机。泵将自动按医生开具的剂量和预设程序输注胰岛素。有两种不同的给药方式：速效剂量（bolus dose），当葡萄糖水平迅速上升时快速输注；基础剂量（basal dose），在夜间和两餐之间缓慢输注。这些设置预先编程到泵中，并相应输注。编程设备的方式有多种：泵上的按钮、通过带有无线连接的计算机、遥控器，以及与血糖监测仪的无线连接。[图 2.46](#Chapter2.html#c02_fig46) 显示了可能针对胰岛素泵的两种不同攻击，这些攻击可能会影响患者的健康。被动攻击是指遥控器被接管并向胰岛素泵发送信号（[Li *et al.*, 2011](#Chapter2.html#c02_bib47)）。在此场景中使用通用无线外设，遥控器向泵发送恶意信号，这可能会更改系统程序并输注未开具的胰岛素剂量。主动攻击是指使用相同的无线外设直接向泵发送信号并更改系统程序。这两种攻击都对患者危险且有害。
