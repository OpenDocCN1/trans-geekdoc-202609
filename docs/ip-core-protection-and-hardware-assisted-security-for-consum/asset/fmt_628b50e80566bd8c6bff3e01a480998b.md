As evident from these tables, customized CFE approach ([Sengupta and Kachave, 2018](#Chapter6.html#c06_bib26)) was able to resolve the ownership conflict for each of these cores. Further, even if several IP core features overlap between competing IP vendors, yet customized CFE was still able to resolve the ownership conflict. This shows that customized CFE approach is strongly capable of resolving ownership conflict with the current feature set. It is interesting to note that one feature is enough to distinguish between competing IP vendors. For example, out of the ten features in the feature-set, even if nine features of both IP cores (corresponding to the two competing IP vendors) overlap with IP under test, but only one feature remains distinct to each other, it may be enough identifying the actual IP owner. This is because the competing IP vendor with nine overlapping features will have 90% match with IP[ID] while the actual IP vendor will have 100% match with IP[ID]. For example, as shown in [Table 6.1](#Chapter6.html#c06_tbl1), even though IP[V1], IP[V5], and IP[V7] have eight features common in them, the ownership conflict among these tools with respect to IP[ID] was resolved based on the remaining two features and ownership was awarded to IP core vendor 5. The results obtained for FIR benchmark show an exceptional case as discussed in section III.B, where none of the competing vendor’s “feature-set” matches 100% with the “feature-set” of IP[ID]. In such a case, ownership is not awarded to any of the competing vendors.

On the other hand, CFE is performed after IP core has been generated. Therefore, customized CFE does not incur design overheads. ### 6.5 Conclusion

This chapter discussed an alternative ownership protection methodology called CFE from [Sengupta and Kachave (2018)](#Chapter6.html#c06_bib26), applicable for resolving ownership conflict of DSP IP cores. Further, the chapter described several features of the “feature-set” that are used as means of resolving ownership conflict with 0% degradation in hardware performance, and incur 0% storage overhead compared to the popular hardware watermarking-based ownership protection for DSP cores ([Koushanfar *et al.*, 2005](#Chapter6.html#c06_bib12)).

The future directions could target devising novel “expanded feature-set” that can resolve ownership conflict of DSP IP core in case of “deadlocks.” Further, feature extraction rules for “scheduling algorithm” feature can be modified to include other scheduling algorithms such as force directed scheduling.
