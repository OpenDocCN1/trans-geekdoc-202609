
The designs of integrated circuits have evolved into greater sophistication than ever before with the revolution of implementation and application technology in consumer electronics industry. The usage of digital signal processing (DSP) intellectual property (IP) cores ([Castillo *et al.*, 2007](#Chapter5.html#c05_bib1)) generated using architectural synthesis not only maintains a proper balance between time-to-market pressure and design productivity but additionally help in design cost reduction. High-level synthesis (HLS) ([Sengupta and Sedaghat, 2011](#Chapter5.html#c05_bib2), [2013](#Chapter5.html#c05_bib4)) is an automated design process that transforms an algorithmic/behavioral description of a digital circuit or IP into its corresponding register transfer level (RTL) digital hardware through numerous sub-processes like scheduling, hardware and register allocation, and binding ([Mohanty, 2015](#Chapter5.html#c05_bib15)). In the process of manufacturing an IP core, two entities are involved, viz. seller and buyer. An IP seller also known as IP vendor is the creator of an IP, whereas an IP buyer also known as IP user is the purchaser of an IP. However, to maintain a viable application of IP cores in composite SoC-based designs, protection of both the entities against threats is extremely crucial. Let us now discuss on the protection aspect of IP buyer and IP seller. In an IP core, an IP buyer may claim buyer privilege as a buyer so that the same IP copy should not be usable/accessible to his competitors in the market. This is possible when customized specifications of an IP core are obtained by an IP seller from an IP buyer, thus creating an exclusive one-to-one mapping between both parties. Embedding a unique buyer’s signature (known as buyer fingerprint) into an IP core design facilitates detection of unlawfully redistributed/resold duplicates of an IP core by a deceitful seller ([Gang and Potkonjak, 2007](#Chapter5.html#c05_bib3)). Likewise, an IP seller must protect his design from piracy and false claim of ownership before selling it to an IP buyer. Embedding a unique seller’s signature (known as seller watermark) into an IP core design protects an IP core from ownership abuse ([Alkabani *et al.*, 2007](#Chapter5.html#c05_bib5); [Sengupta and Kundu, 2017](#Chapter5.html#c05_bib6); Sengupta *et al.*, [2017](#Chapter5.html#c05_bib7), [2018](#Chapter5.html#c05_bib38); [Kougianos *et al.*, 2009](#Chapter5.html#c05_bib8); [Maltoni *et al.*, 2009](#Chapter5.html#c05_bib9); [Roy *et al.*, 2008](#Chapter5.html#c05_bib10); [Alkabani and Koushanfar, 2008](#Chapter5.html#c05_bib11); Sengupta, [2016](#Chapter5.html#c05_bib36), [2017](#Chapter5.html#c05_bib35); [Sengupta and Roy, 2017](#Chapter5.html#c05_bib37)).

Therefore, symmetrical protection of DSP IP cores provides user right as well as nullifies IP ownership abuse. A thematic summary is highlighted in [Figure 5.1](#Chapter5.html#c05_fig1). Significant investments are required in terms of man-power, time and cost to design, and verify an IP core; however, it can be cloned, modified, or resold easily by a rough entity. Therefore, both seller and buyer of IP designs want to nullify the possibilities of false claiming and illegal reselling of an IP core. Symmetrical protection can be achieved by implanting dual entity signature scheme in a DSP IP core during any of the design abstraction level. Standard IP protection methods ([Yuan *et al.*, 2006](#Chapter5.html#c05_bib12)) such as patents, copyrights, trademarks, etc., are distributed, restricted in capacities, and insufficient in securing IP cores from buyer and seller viewpoint. Additionally, several signature embedding schemes in different multimedia applications, like image, text, video, and audio are also not appropriate to protect an IP core as it does not preserve the functionality and precision of a design in signature insertion. Thus, from the perspective of IP core protection, necessary action needs be taken to preserve the functionality and correctness of the design while embedding any signature.

#### 5.1.1 Background on watermark and fingerprint

Watermark and fingerprint represents the signature of two distinct entities of a DSP reusable IP core to protect their corresponding ownership right. While fingerprint conveys the signature of an IP buyer, watermark is intended for an IP seller. An ideal signature for both cases must meet the below features:

*   It must be implanted as vital part of an IP design so that it must not be perceptible through traditional scanning.

*   It must be inimitable in nature so that the proof of ownership can be established easily.

*   For manifold signature implanting mechanism, each signature must be self-governing of each other.

*   It should be tamper tolerant so that partial removal of signature should not impact on the proof on ownership.

*   It should be resilient against attacks like reverse engineering.

*   Low embedding runtime.

*   Nominal latency and hardware overhead after implanting signatures.

*   Seamless signature detection process for an authentic owner with comprehensive cognizance of encoding rules ([Koushanfar *et al.*, 2005](#Chapter5.html#c05_bib18); [Cox *et al.*, 2007](#Chapter5.html#c05_bib19)).

*   Must uphold logic correctness of an IP core post-implanting signatures.

#### 5.1.2 Threat model

The ultimate goals of IP core security are:

1.  ***Buyer’s standpoint:*** detect unlawfully redistributed/resold copies in the market by a deceitful IP seller ([Gang and Potkonjak, 2007](#Chapter5.html#c05_bib3)).

2.  ***Seller’s standpoint:*** security against ownership exploitation ([Yu and Zhu, 2011](#Chapter5.html#c05_bib13)).

#### 5.1.3 Benefits of protection at higher abstraction

Although DSP IP core protection can be provided in any of the design abstraction level, however, embedding buyer fingerprint and seller watermark architecture level (Mohanty *et al.*, [2002](#Chapter5.html#c05_bib15), [2014](#Chapter5.html#c05_bib16)) are beneficial as the signature constraints embedded in higher design abstraction level will automatically propagate in the lower design abstraction level; thus, it will protect the higher level as well as the lower level of the design. Additionally, symmetrical protection in higher level can be achieved in lesser signature embedding complexity while incurring lower design overhead. Roy and Sengupta ([2017](#Chapter5.html#c05_bib32)) presented a multi-variable fingerprinting and watermarking-based symmetrical IP core protection mechanism during multiple sub-steps of architectural synthesis/HLS process. Additionally, the approach incurs minimal design overhead while incorporating both signature constraints.

### 5.2 Fundamentals of IP core protection

This chapter discusses fundamentals of different reusable IP core protection mechanisms (shown in [Figure 5.2](#Chapter5.html#c05_fig2)) with emphasis on higher design abstraction level-based IP core protections that are available in the literature and how they are different when compared with symmetrical IP core protection. Reusable IP core protection mechanism can be classified into two parts: (a) non-symmetric approach and (b) symmetric approach.

#### 5.2.1 Overview on non-symmetric IP core protection techniques

According to the literature, non-symmetric IP core protection techniques mainly provide protection from a seller’s perspective. It can be performed in three different techniques: (i) hardware obfuscation, (ii) computational forensic engineering (CFE), and (iii) watermark.
