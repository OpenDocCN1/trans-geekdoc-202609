独特特征是指不存在于每个通过 HLS 生成的 DSP IP 核心中的特征。然而，这些特征存在于至少一个竞争 HLS 工具的 IP 核心中。因此，独特特征将能够将至少一个 IP 核心与所有剩余 IP 区分开来。一旦特征集被识别，就会制定特征提取规则，以从以 HDL 形式提供的每个 IP 核心中提取这些特征。*注意：这些特征提取规则已自动化为计算机程序*。此外，在定制 CFE 方法的下一步中，执行每个竞争 HLS 工具对应的 IP 核心以及 IP`[ID]` 核心的自动化特征提取。最后，将 IP`[ID]` 的所有权授予其“特征集”与 IP`[ID]` 的“特征集”完全匹配的供应商。此最终步骤称为 IP 核心验证。通过以下案例研究，可以更有效地理解定制 CFE 方法。

## 6.3 IP 核心特征提取算法

在 Harish Ram *et al.* ([2011](#Chapter6.html#c06_bib6))、Inoue *et al.* ([2011](#Chapter6.html#c06_bib7))、Sengupta 和 Sedaghat ([2015](#Chapter6.html#c06_bib31))、Koushanfar *et al.* ([2005](#Chapter6.html#c06_bib12))、Rajendran *et al.* ([2013](#Chapter6.html#c06_bib21))、Mishra 和 Sengupta ([2014](#Chapter6.html#c06_bib18)) 以及 Sengupta 和 Bhadauria ([2015](#Chapter6.html#c06_bib24)) 的工具供应商之间存在 DSP IP 核心所有权冲突的场景中，IP 核心提取规则可以通过演示来解释。此外，假设每个竞争供应商对应的 HLS 工具的可执行版本也可用。

一旦确定了特征集，就会为特征集中的每个特征制定特征提取规则。第 6.3.1 节详细讨论了特征提取规则。

### 6.3.1 特征提取规则

`Scheduling algorithm`：调度是 DSP IP 核心设计的一个组成部分（[Paulin 和 Knight, 1989](#Chapter6.html#c06_bib20); [McFarland, 1988](#Chapter6.html#c06_bib16)）。三种最常用的调度算法是尽早调度（ASAP）、尽迟调度（ALAP）和列表算法。还有其他一些有用的调度算法，但本案例研究仅限于这三种最常用的调度算法。用于识别创建 DSP IP 核心所采用的调度算法的流程图如 [图 6.5](#Chapter6.html#c06_fig5) 所示。特征提取方法最初检查 IP 核心控制器 HDL 中是否存在 ASAP 调度。如果识别 ASAP 调度的两个规则都满足，则用于创建 IP 的调度算法被检测为 ASAP。但是，如果任何一个规则不满足，则检查在创建 IP 核心中采用 ALAP 调度的可能性。如果 ALAP 调度的两个条件都满足，则 IP 核心中的调度算法被检测为 ALAP。否则，检测到的调度算法为 LIST。

`Resource type`：要识别资源类型特征的存在，需要检查 IP 核心的顶层实体数据路径 HDL 并识别组件的名称。此外，创建一组类似于功能单元（FU）的名称作为指示器，即用于生成 DSP IP 核心的“资源类型”。如 [图 6.6](#Chapter6.html#c06_fig6) 所示，组件的名称为“Mul\_4×4”，表示一个 4×4 乘法器。同样，检查所有其他组件的名称。
