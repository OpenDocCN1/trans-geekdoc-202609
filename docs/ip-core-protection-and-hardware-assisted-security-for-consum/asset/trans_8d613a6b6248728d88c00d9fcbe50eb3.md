

# Chapter 4

| `M[i](n)` | = 第 `i` 个子标记或数学函数 |
| --- | --- |
| `C[i]` | = 子标记被发送到“临时空闲”IP 输出端口时的时钟周期编号 |
| `M` | = 数字 FIR 的滤波器阶数 |
| `h[i]` | = FIR 系数 |
| `x(n)` | = 输入冲激 |
| `y(n)` | = 输出冲激 |
| `H(e^(jω))` | = 传递函数 |
| `δ[1]` 和 `δ[2]` | = 指定数字滤波器允许通带和阻带的参数 |
| `N` | = 数字 IIR 巴特沃思滤波器的阶数 |
| `Ω[c]` | = 截止频率 |
| `H(s)` | = 传递函数 |
| `B[0]B[1]` | = IIR 巴特沃思滤波器的参数 |
| `H(z)` | = 表示滤波器在频域中的传递函数 |
| “α”, “β”, “γ”, “‘i”, “I”, “T”, 和 “!” | = 水印的签名数字 |
| `P[c]` | = 重合概率度量 |
| “w” | = 水印强度/大小 |
| `N(R[i])` | = 类型 `i` 的功能单元数量 |
| `D` | = 功能单元的类型 |
| `C` | = 在嵌入水印前彩色区间图中使用的颜色数量 |
| `T[t]` | = 篡改容忍能力 |
| “v” | = 编码中使用的变量数量 |
| `C[f]([Xi])` | = 用户提供的资源配置 `X[i]` 的水印设计成本 |
| `L[total]` 和 `A[total]` | = 总水印设计延迟和面积 |
| `L[max]` 和 `A[max]` | = 基于模块库中可用资源的最大设计延迟和面积 |
| `w[1]` 和 `w[2]` | = 延迟和面积的权重参数 |

# Chapter 5

| `X[i]` | = 最优设计方案 |
| --- | --- |
| `N(R[D])` | = 资源类型 `R[D]` 的数量 |
| `A[total]` 和 `L[total]` | = 对称保护设计的总面积和延迟 |
| `A[cons]` 和 `L[cons]` | = 用户提供的面积和延迟约束 |

| `A(mux)` | = 多路选择器的面积 |
| `N(mux)` | = 多路选择器的数量 |
| `L[total]` | = 对称保护可重用 IP 核的总设计延迟 |
| `total[cs]` 和 `delay[cs]` | = 设计的控制步骤总数和每个控制步骤的执行延迟 |
| `C[f](X[i])` | = 具有资源配置 `X[i]` 的对称保护可重用 IP 核的设计成本 |
| `A[max]` 和 `L[max]` | = 设计空间中的最大面积和延迟 |
| `w[1]` 和 `w[2]` | = 用户提供的面积和延迟权重因子 |
| `c` | = 所需的颜色数量 |
| `W` | = 水印约束的大小 |
| `P[c]` | = 重合概率 |
| `F` | = 指纹约束的大小 |

# Chapter 6

| `A_n` | = CFE 中的算法/工具的有限集合 |
| --- | --- |
| `P` | = 问题 |
| `S` | = 解决方案 |
| `n` | = 1,…,`i` |
| `k` | = 簇的数量，使得每个簇包含在 CFE 中紧密匹配的解决方案 |
| `IP[Vn]` | = 竞争 IP 核心所有权的供应商 |
| `n` = 是声称拥有 IP 核心所有权的供应商数量 |
| `IP[ID]` | = 待判定所有权的 IP 核心/待测试的 IP 核心 |
| `CS[S](FU[i])` 和 `CS[S](FU[j])` | = 第 `i` 个和第 `j` 个 FU 的起始控制步骤 |
| `CS[E](FU[i])` 和 `CS[E](FU[j])` | = 第 `i` 个和第 `j` 个 FU 的结束控制步骤 |
| `CS` | = 控制步骤 |
| `MUL_En_1` | = 乘法器使能 |
| `CS[S](FU[i])` 和 `CS[E](FU[i])` | = 第 `i` 个 FU 的起始和结束控制步骤 |
| `CS[E](N)[1]` 和 `CS[E](N)[2]` | = 数据集 1 和 2 的结束控制步骤 |
| `µ` | = 匹配百分比 |

| --- | --- |
| `L[cons]` | = 用户提供的延迟约束 |
| `X[i]` | = 最优设计方案 |
| `N(R[D])` | = 资源类型 `R[D]` 的数量 |
| `A[total]^(obf)` 和 `L[total]^(obf)` | = 结构混淆设计的总面积和延迟 |
| `A(R[i])` | = 资源 `R[i]` 的面积 |
| `A(buffer)` | = 缓冲区的面积 |
| `N(buffer)` | = 缓冲区的数量 |

| `UF` | = 展开因子 |

| `A[max]^(obf)` 和 `L[max]^(obf)` | = 设计空间中可能的最大面积和延迟 |
| `w[1]` 或 `Ø[1]` 和 `w[2]` 或 `Ø[2]` | = 用户指定的面积和延迟权重因子 |
