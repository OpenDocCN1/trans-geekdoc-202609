

在基于忆阻器的交叉阵列中，施加的正向电压会降低器件提供的电阻，而相反方向的输入电压会增加器件的电阻（[Lugli *et al*., 2013](#Chapter12.html#c12_bib39）），从而向阵列写入“1”或“0”。另一种 PUF 设计是超高信息量 PUF（SHIC-PUF），其特点是读出时间慢且信息量高（[Ruhrmair *et al*., 2011](#Chapter12.html#c12_bib62））。在本例中，用于存储信息的是交叉阵列。但要使用它，需要满足一些要求：读出时间应较低，这将由存储单元的结构或慢速处理模块控制。为了提高安全性，慢读出时间应源于存储单元的内在结构。另一个要求是电路应被完全表征且应非常大。存储在存储器上的信息位也应为随机的。表征 ![image](OEBPS/images/c12-Eqn-in-53.gif) 位（~10 GB）和 *k* = 100 bits/s 电路的时间为 ![image](OEBPS/images/c12-Eqn-in-54.gif)。该阵列还应能够适应小面积，从而减少占用的芯片面积。

位线和字线用于对垂直线和水平线交叉处的位进行寻址。电流将流经交叉点。字线和位线将偏置于 ![image](OEBPS/images/c12-Eqn-in-55.gif) 和 ![image](OEBPS/images/c12-Eqn-in-56.gif)，在此期间，未访问的字线和位线将偏置于 ![image](OEBPS/images/c12-Eqn-in-57.gif) 和 ![image](OEBPS/images/c12-Eqn-in-58.gif) 电压。因此，仅访问的字线和位线上的结会进入正向偏置，而其他结则反向偏置（在基于二极管的交叉阵列中）。字线连接到一个感应电阻，根据字线上的电压，会显示两种状态：高电阻或低电阻。在此例中，位中的信息是随机的，并且重要的是要看到结构特征是不规则的。为了实现这一点，考虑了铝诱导层交换。这有助于随机化导电率的分布，从而导致不均匀的导电率。在 PUF 的情况下，这可以视为一种优势。当阵列尺寸增加时，反向偏置结电流会增加，进而增加模块的功耗。但寄生路径会避开访问的位线和字线。这会降低噪声容限，并使其适合于 PUF 设计。并且，为了使读出周期变慢并限制电容峰值电流，需要较大的发生器电阻值。作为替代方案，可以使用高-*κ* 材料。

交叉阵列也可以使用，并且可以按照 [Lugli *et al*. (2013)](#Chapter12.html#c12_bib39) 所展示的方式实现弱 PUF 和 SHIC PUF。在此例中，可以在不改变其他响应的情况下对 PUF 响应进行重写和擦除。这仅在交叉阵列的情况下可能，而在其他 PUF 设计中则不可能。增大的交叉阵列将是一个巨大问题，因为隐匿电流路径会成为问题，并且这也会降低噪声容限并恶化功耗。可以实现一个整流元件来减少访问和未访问单元之间的串扰和泄漏。交叉阵列的设计也可以包含与二极管串联的忆阻器，这可以降低噪声容限和功耗。在传统硅工艺和过渡金属氧化物忆阻器的情况下存在兼容性问题（[Kim *et al*., 2010](#Chapter12.html#c12_bib29)）。

当实现浮动偏置方案时，阵列尺寸减小，噪声容限也因隐匿电流增加而降低。功耗的情况也是如此。因此，存储器尺寸限制在几兆位以内。外部电阻效应对噪声容限影响很小，反向偏置方案适用于噪声容限和功耗。但与浮点方案相比，由于较高的关态电流，功耗较高。可以推断，如果功耗不是问题，存储器尺寸可以增加，但这也会降低噪声容限。缩放也有助于降低二极管电流和电阻。

在 ALILE 的情况下，来自低掺杂晶圆的二极管将具有高整流比和高随机性。但与 ZnO 结相比，噪声容限较低，因为在 ±2 V 时整流比约为 10⁸。

小尺寸的 ALILE 二极管适用于弱 PUF 的情况，与 ZnO 肖特基二极管相比，因为随机性高（[Ruhrmair *et al*., 2010](#Chapter12.html#c12_bib61)）。ALILE 二极管在较长时间内的稳定性也高，且耐侵入式读出。二极管性能的温度依赖性高，可以通过使用差分测量技术来改善。

### 12.10 基于碳的 PUF

在当前的研究趋势中，硅器件被广泛用于 PUF 设计的开发，并且更多地关注随机性、可靠性和鲁棒性。但器件的功耗没有被监控或关注。器件的缩放已经导致一个地步，即更需要低功耗器件和低电压工作器件，这对 PUF 设计构成了挑战。器件的缩放也使得难以控制沟道中的栅极和载流子。这使得有必要探索可用于缩放的后硅器件。碳衍生物选项，如碳纳米管（CNT）和石墨烯，是有前途的候选者。

#### 12.10.1 基于 CNT 的 PUF

基于 CNT FET 的 PUF 可以实现各种优势，例如低功耗、高可靠性和低能耗（[Konigsmark *et al*., 2014](#Chapter12.html#c12_bib31)）。在 CNTFET 中，CNT 用作晶体管中的沟道。CNTFET 的配置取决于 CNT 的各种属性，例如直径、手性、生长密度、错位和掺杂浓度。手性用于生成秘密位。石墨烯片卷曲的方向决定了 CNT 的手性，进而决定器件的金属或半导体特性。[图 12.22](#Chapter12.html#c12_fig22) 显示了 CNPUF 的设计，其中包含串联的 CNTFET。晶体管的并联元件 CNPUF-PEs 共享一个公共栅电压。在此例中，可以有大量的半导体 CNT 和少量的金属 CNT。它们的使用比例为 10%–30%，其中半导体电流将占主导地位于金属电流。每个并联元件包含高和低输入栅电压的不同状态。由于工艺变化，这些状态会变化，从而影响输出。与基于硅的仲裁 PUF 设计相比，面积的改善可达 300%（[Konigsmark *et al*., 2014](#Chapter12.html#c12_bib31)）。[Konigsmark *et al*. (2014)](#Chapter12.html#c12_bib31) 展示了 49.67% 的芯片间 HD。当在不同条件下进行仿真时，通过给器件的温度和供电电压赋予随机值，CNPUF-PE 的性能比 RO PUF、基于电流的 PUF 和 SRAM PUF 更可靠和稳定。为了更高的安全性，应在安全性和功耗之间进行权衡。扩展的 CNPUF 增加了面积开销，但与具有更高安全性的 Si PUF 相比是可比的。
