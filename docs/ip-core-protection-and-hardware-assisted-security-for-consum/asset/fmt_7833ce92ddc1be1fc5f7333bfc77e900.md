### 11.7.1.6 Invisible-robust spatial domain module

Invisible-robust insertion algorithm is presented by [Mohanty *et al*. (2004)](#Chapter11.html#c11_bib82). This algorithm was implemented on a Xilinx FGPA board and VIRTEX technology with XCV50-BG256-6 target device was synthesized.

[Figure 11.15](#Chapter11.html#c11_fig15) shows the functional diagram of the encoder chip. The encoder of this design consists of watermark generator, insertion, address decoder, controller, and registers. External storage is used to load the images. An LFSR is used for the watermark generation, which is the most important part of the design. LFSR should be avoided to power on randomly, which may become permanently stuck with some prohibited states. Insertion module consists of adder/subtractor, adders, subtractors, multipliers, and shifters. Controller is an eight-state FSM.

### 11.7.1.8 Visible wavelet domain chip

A discrete WT-based watermarking design is proposed by [Fan *et al*. (2005)](#Chapter11.html#c11_bib27). This reduces the operational and resource sharing which can increase the overall efficiency of the design. The watermark and the original image are transformed into three-level multiresolution structures. Original image is then divided into two different sequences of the same pattern length. A two-path parallel processing is used for calculating the processing time. De-multiplexers will then send the signal to different elements for processing. The watermark image is embedded by modifying the coefficients of the image.
