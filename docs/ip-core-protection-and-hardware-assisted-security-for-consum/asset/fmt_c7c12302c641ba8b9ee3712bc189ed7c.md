### 3.6 Design process of Trojan secured DSP IP core

In this section, we discuss the complete end-to-end design process of a Trojan secured DSP IP core. Each DSP IP core executes an algorithm or mathematical function during processing. These DSP IP cores could be realized as application-specific integrated circuits (ASICs) or SoC, which accepts appropriate inputs and, after executing the algorithm/function, produces the corresponding output (s). In the following, we discuss how to derive or generate a CDFG of a DSP IP core from its mathematical function. Next, we explain how to generate a DMR of a CDFG and finally we explain the process of generating a Trojan secured DSP IP core from the DMR CDFG through an illustrative example.
