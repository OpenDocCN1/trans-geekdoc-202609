Color image watermarking for the same scheme is presented by [Garimella *et al*. (2004)](#Chapter11.html#c11_bib33). RGB-YUY and YUV-RGB converters are designed along with the watermark encryption, embedding, extracting, detection, and authentication modules. Similar to the previous design, the LSB of the pixels is integrated with the watermark and the pixel array of 8-bit grayscale image. The color image is initially transformed into the YUV color space and the encrypted watermark is inserted into it. After the embedding process, the YUV space is retransformed into the RGB color space. The luminance component Y is the watermarking channel where the RGB image transforms into the YUV color space. LSBs from the Y are used for the watermarking process in which the watermark is the encrypted stream of the ASCII code text file. Each bit is swapped with first LSB of Y and second LSB is the complemented bit of the first LSB. DPCM technique is used for the encryption process. During the detection process, the LSBs are accumulated and then decrypted to be compared with the original ASCII code text.

##### 11.7.1.5 Invisible-robust wavelet domain module

In case of a blind watermarking scheme, the original image is not needed. An FPGA implementation of the blind watermarking scheme is presented by [Seo and Kim (2003)](#Chapter11.html#c11_bib96). In the two-dimensional discrete wavelet transform (2D-DWT), one or two image bit planes are replaced with the watermark. The hardware module is designed to be operated at 82 MHz, and 24% of logic array blocks and 3% of embedded system blocks are used of an Altera APEX20KC EP20K400CF672C7 device. JPEG 2000 CODEC was integrated with the watermarking scheme.

The watermark used in this scheme is created from the binary numbers. The candidate for the watermark embedding is the DC which makes it more robust to the attacks. The bit plane selected is done with more care such that the human eye cannot see the watermark because the DC subband has most important information regarding the image. During the embedding, the watermark is divided into 4-level 2D-DWT. Binary watermark is embedded in the second plane, the third plane from LSB plane. Selection of bit plane *p* is chosen from a set of *k* bit planes. Secret key is the initial value of the LFSR.
