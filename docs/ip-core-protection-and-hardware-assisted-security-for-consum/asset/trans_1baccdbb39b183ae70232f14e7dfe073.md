

## 1. 硬件混淆

混淆是将原始应用程序或设计转换为其功能等效形式的过程，以使逆向工程过程变得显著更加困难 ([Chakraborty and Bhunia, 2009](#Chapter5.html#c05_bib28))。它可以通过模糊 IP 设计/代码（称为结构混淆）([Hada, 2000](#Chapter5.html#c05_bib27); [Sengupta *et al.*, 2017](#Chapter5.html#c05_bib31)) 或通过生成锁定网表 ([Chakraborty and Bhunia, 2009](#Chapter5.html#c05_bib28)) 来保护 IP 核心。只有具备正确设计知识和正确密钥组合的人才能使用它。换句话说，结构混淆隐藏了 IP 核心的功能，而功能混淆隐藏了 IP 核心的实现。

## 2. 计算机取证工程

计算机取证工程 (CFE) 是一种无签名驱动的过程，可分为三个步骤：特征收集、特征提取和 IP 验证 ([Sengupta and Kachave, 2018](#Chapter5.html#c05_bib30))。它试图识别一组可用于唯一标识 IP 核心的特征 ([Wong *et al.*, 2004](#Chapter5.html#c05_bib29))。在发生所有权冲突的情况下，这些特征可用于识别 IP 核心的真正所有者。

## 3. 水印

单个实体（仅限 IP 卖方）的 IP 保护可以通过在 IP 核心设计中嵌入卖方水印来实现。水印可以插入到较低的设计抽象级别 (Ziener and Teich, [2006](#Chapter5.html#c05_bib20), [2008](#Chapter5.html#c05_bib22); [Nie *et al.*, 2013](#Chapter5.html#c05_bib21)) 或较高的设计抽象级别 ([Sengupta and Bhadauria, 2016](#Chapter5.html#c05_bib14); [Koushanfar *et al.*, 2005](#Chapter5.html#c05_bib18); [Hong and Potkonjak, 1999](#Chapter5.html#c05_bib23); [Le Gal and Bossuet, 2012](#Chapter5.html#c05_bib24); [Sengupta *et al.*, 2016](#Chapter5.html#c05_bib25))。较低设计级别的水印可以从现场可编程门阵列 (FPGA) 的电源引脚 ([Ziener and Teich, 2006](#Chapter5.html#c05_bib20))、IP 核心设计的比特流 ([Nie *et al.*, 2013](#Chapter5.html#c05_bib21)) 或通过电压跟踪 ([Ziener and Teich, 2008](#Chapter5.html#c05_bib22)) 等方式检测出来。另一方面，较高设计级别的水印可以从 IP 设计的数据路径和/或控制路径中识别出来。

## 5.2.2 对称 IP 核心保护技术概述

对称 IP 核心保护的主要目标是在 IP 用户和 IP 卖方之间生成唯一的一对一映射 IP 核心。从卖方角度来看，它不仅能保护 IP 卖方的所有权，还能从 IP 买家列表中识别出叛徒。如果所有买家从卖方处获得相同的 IP，而其中一人非法重新分发，那么识别实际不诚实的买家将变得难以克服 ([Gang and Potkonjak, 2007](#Chapter5.html#c05_bib3))。文献中只有两种方法提出了对称 IP 核心保护技术。在 Lach *et al.* ([2001](#Chapter5.html#c05_bib26)) 提出的方法中，当数字电路被放置并布线到 FPGA 上时，会在其物理布局中嵌入一个隐藏的加密标记。该标记唯一标识电路的来源和原始接收者，且难以移除。因此，该方法为双方（IP 买家和 IP 卖家）提供保护，但在较低的设计抽象级别（即布局级别）而非较高的设计抽象级别。另一方面，Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 提出的方法在高层综合 (HLS) 期间提供对称保护。该方法在架构综合的寄存器分配和调度阶段，将隐藏的买方和卖方签名约束作为多变量指纹和水印嵌入。签名嵌入过程不耗时且复杂度较低；此外，由于额外约束产生的开销显著较低。此外，该方法的详细说明将在下一节中讨论。

## 5.3 DSP 核心的对称 IP 核心保护

Roy 和 Sengupta ([2017](#Chapter5.html#c05_bib32)) 提出的对称保护方法在 HLS 期间隐蔽地插入指纹和水印约束，以保护 IP 买方和 IP 卖方。基于买方提供的签名约束，IP 卖方插入买方指纹及其自身水印，从而保护卖方和买方免受 IP 盗版、IP 克隆、虚假所有权声明等常见 IP 威胁（在 5.1 节中讨论）。买方指纹和卖方水印作为来自各自实体的输入被解码，以获取相应的签名约束。首先，指纹约束在 HLS 的调度和寄存器分配阶段中嵌入（如 [图 5.3](#Chapter5.html#c05_fig3) 所示）。一旦获得植入指纹的设计后，最后将水印约束植入寄存器分配阶段。因此，DSP IP 核心设计既包含指纹约束，也包含水印约束，此外还有其正常设计约束（即模块库、资源配置等）。为每个资源生成多路复用过程，以识别资源互连性、多路复用器大小以及水印和指纹设计的输入/输出。使用每个资源生成的多路复用方案，开发 DSP IP 核心控制单元的完整数据路径和时序描述。因此，对称保护的 IP 核心 RTL 设计的最终输出被创建为数据路径和控制器，其中每个组件均使用硬件描述语言 (HDL) 设计。
