该循环变换过程识别循环内部的循环无关操作，并将其移出循环。在 CDFG 的上下文中，与循环无关的节点将从循环体中移出。更具体地说，LICM 变换将那些在循环内迭代执行或在循环外单次执行对应用程序最终输出没有任何影响的节点移出。因此，LICM 产生结构不同但功能相同的设计。最后，经过 HLS 处理后，输出基于 LICM 的结构混淆 DSP 电路。

### 7.4 针对 DSP IP 核的低成本结构混淆

Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) 通过基于 PSO 的探索 ([Sengupta *et al.*, 2017b](#Chapter7.html#c07_bib37)) 探索了一种低成本 DSP 设计方案。它接受 DSP 核心的结构混淆设计（作为 C 代码/基于循环的 CDFG）、模块库、用户提供的延迟-面积限制以及带有终止标准和 PSO 控制参数（如社会因子、认知因子、惯性权重）作为输入，并输出结构混淆、低成本的 DSP 电路。PSO-DSE 过程的描述将在以下小节中解释。

#### 7.4.1 PSO 概述

PSO 是一种通过基于种群的搜索驱动的优化过程，它从可用解池（称为搜索空间）中迭代探索最优解。每个可能的资源配置被编码为一个粒子，每个粒子的适应度通过目标函数评估以找到最优解。每个粒子的速度引导该粒子走向最优解。每个粒子的速度使用当前全局最优“gbest”和其自身最佳位置“lbest”来计算。在发现更好的全局或局部最优后，粒子的速度和位置将被更新，从而向最优解移动。

在低成本 DSP 设计方案的上下文中，每个粒子代表一个资源配置和一个展开因子值作为设计解。前三个粒子使用最小（min）、最大（max）和中等资源配置及其展开因子值进行初始化。如果初始种群大小超过三个粒子，则其余粒子在 min 和 max 资源配置值范围内随机初始化。每个粒子的适应度使用方程 [(7.3)](#Chapter7.html#c07_eqn3) 中所示的成本函数计算。PSO-DSE 也在第 3 章中详细解释。

#### 7.4.3 PSO 的终止条件

该 DSE 过程迭代搜索 DSP 电路的低成本设计解。然而，该迭代搜索过程基于以下两个条件终止。第一个条件是：如果迭代次数达到预定义的最大迭代次数（*I*[max]），第二个条件是：如果在预定义（*δ*）个迭代次数内未发现全局最优的改进。根据 Sengupta *et al.* ([2017b](#Chapter7.html#c07_bib37))，*I*[max] 和 *δ* 的值可以分别设置为 100 和 10。
