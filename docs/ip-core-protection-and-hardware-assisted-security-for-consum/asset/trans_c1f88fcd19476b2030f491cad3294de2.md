## 第 10 章  

### 高级加密标准 (AES) 及其用于所有权保护的硬件水印

在消费电子时代，网络安全是关键挑战之一。任何部署的安全、隐私或保护方法都依赖于密码学。高级加密标准 (AES) 是一种广泛使用的密码学算法，因其优势而备受青睐。本章专门介绍 AES 的过程及其以 IP 核形式的硬件设计。多种硬件安全技术依赖 AES IP 核作为重要模块。此外，由于这是一个如此重要的核心，其防伪/防盗版的自我保护也至关重要。因此，本章还将讨论使用水印对 AES IP 核进行保护。

### 10.1 简介

密码学在日常生活中应用非常广泛，范围从无线局域网、使用信用卡或借记卡购买商品、安装软件更新、智能卡、银行应用、互联网语音协议 (VOIP) 等成熟应用，到电子健康系统、物联网安全、智慧城市安全和硬件安全等新兴领域 ([Paar 和 Pelzl, 2009](#Chapter10.html#c10_bib5); [Bhunia 和 Tehranipoor, 2018](#Chapter10.html#c10_bib1); [Sengupta, 2013](#Chapter10.html#c10_bib6), [2015](#Chapter10.html#c10_bib7), [2017](#Chapter10.html#c10_bib8); [Sengupta *et al.*, 2017](#Chapter10.html#c10_bib13); [Sengupta 和 Bhadauria, 2016](#Chapter10.html#c10_bib9); [Sengupta 和 Sedaghat, 2011](#Chapter10.html#c10_bib12); [Mishra *et al.*, 2017](#Chapter10.html#c10_bib3); Sengupta 和 Sedaghat, 2013; [Sengupta 和 Roy, 2017a](#Chapter10.html#c10_bib10), [2017b](#Chapter10.html#c10_bib11))。密码学包含天然对称的密码学算法。对称密码使用非常广泛，尤其是用于数据加密和消息完整性检查。此外，密码学协议涉及密码学算法的应用。密码学协议的一个例子是传输层安全 (TLS) 方案，广泛用于浏览器高级加密标准 (AES) 是当今非常流行的对称密码。AES 又称其原始名称 Rijndael，是美国国家标准与技术研究院 (NIST) 认可的电子数据加密规范。在 AES (Rijndael 家族) 的上下文中，NIST 指定了三个成员，每个成员的块大小均为 128 位，但密钥长度不同：128、192 和 256 位。它是多个行业/商业系统和美国政府应用中的强制性标准，例如 Wi-Fi 加密标准 IEEE 802.11i、TLS 和 VOIP ([Paar 和 Pelzl, 2009](#Chapter10.html#c10_bib5))。

在本章中，我们关注以下方面：(a) AES 算法——每个步骤及其流程图的描述，(b) AES 块密码的相应硬件映射——如何将每个步骤映射到特定硬件子模块的概述，(c) 密钥调度——每个步骤的描述，(d) AES 中使用的密钥调度的相应硬件映射，(e) AES 硬件的水印编码——保护 AES 硬件免受所有权虚假声明和盗版等威胁，(f) 带水印的 AES 硬件设计——水印嵌入过程的描述，以及 (g) 不同水印签名类型对 AES 硬件及其在 FPGA 上实现的影响——以突出水印带来的开销。

### 10.2 AES 算法

#### 10.2.1 AES 概述

AES 算法有三种不同的密钥大小变体，即 128 位、192 位或 256 位。输入数据大小为 128 位，输出加密数据也为 128 位。输入数据称为明文，输出加密数据称为密文。[图 10.1](#Chapter10.html#c10_fig1) 显示了 AES 的输入/输出参数。AES 的核心结构包含以下组件：(i) 字节替换层，(ii) 扩散层，(iii) 密钥加层，以及 (iv) 密钥调度 ([Kosaraju *et al.*, 2006](#Chapter10.html#c10_bib2); [Mohanty *et al.*, 2007](#Chapter10.html#c10_bib4))。AES 支持三种密钥长度。密码的内部轮数取决于密钥长度。例如，对于 128 位密钥长度，内部轮数 (*n*[*r*]) 为 10，而对于 192 位密钥长度，内部轮数为 12，最后对于 256 位密钥长度，*n*[*r*] 的值为 14。
