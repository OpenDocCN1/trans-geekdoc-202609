

基于忆阻器的 PUF 利用器件电阻的变化，该变化取决于器件厚度“D”。由于制造过程中的差异，器件厚度会发生变化，从而影响存储单元中器件的读写时间。对于忆阻器，当其从高电阻态（HRS）(![image](OEBPS/images/c12-Eqn-in-29.gif))切换到低电阻态（LRS）(![image](OEBPS/images/c12-Eqn-in-30.gif)）且写入时间高于最小阈值时间 ![image](OEBPS/images/c12-Eqn-in-31.gif) 时，可以向其写入逻辑“1”；否则，将写入逻辑“0”。`T` 被称为 SET 时间，当它接近 ![image](OEBPS/images/c12-Eqn-in-32.gif) 时，单元中出现“1”的概率将等于出现“0”的概率。这种不确定性使忆阻器非常适合用于 PUF 的设计。此外，对于二元忆阻器，其中考虑了两种状态，“1”和“0”，从一种状态到另一种状态的转换将非常突然。在这种情况下，基于忆阻器的 PUF 的抗篡改性将非常高。对于初始化过程，应施加高电压使其处于 SET 状态，然后在较低电压下在 HRS 和 LRS 之间进行切换。低于此 SET 电压阈值时，器件将作为普通电阻器工作。此特性可用作抗篡改机制。[Figure 12.18](#Chapter12.html#c12_fig18) 显示了一个 1 位忆阻器存储器基础的 PUF（McDonald *et al*.，[2011](#Chapter12.html#c12_bib49)，[2012](#Chapter12.html#c12_bib50)）。这利用了器件的写入时间可变性来设计 PUF。

![image](OEBPS/images/PBCS0600-12-f18.jpg)

Figure 12.18 基于 1 位忆阻存储器的 PUF

如 [Figure 12.18](#Chapter12.html#c12_fig18) 所示，设计中有两个控制信号，其中 (![image](OEBPS/images/c12-Eqn-in-33.gif)) 用于确定器件的读/写操作，NEG 用于确定写入操作的极性。当需要对器件执行 RESET 操作时，![image](OEBPS/images/c12-Eqn-in-34.gif) 和 NEG 应提供“1”。忆阻器将在 ![image](OEBPS/images/c12-Eqn-in-35.gif) 信号下进入 HRS。之后，可以施加 SET 信号，通过向 ![image](OEBPS/images/c12-Eqn-in-36.gif) 提供“1”并向 NEG 提供“0”来写入“1”或“0”。读取可以通过向 ![image](OEBPS/images/c12-Eqn-in-37.gif) 提供“0”来完成。对输出与挑战输入进行异或操作，其结果将是 PUF 的输出。

在使用忆阻器设计的横向切换 PUF 单元的情况（McDonald *et al*.，[2011](#Chapter12.html#c12_bib49)，[2012](#Chapter12.html#c12_bib50)）中，成形步骤对于操作至关重要。在成形步骤期间，器件的导电丝在介电片中施加高电压。这使得即使在晶圆厂的制造状态下，值也能被隐藏。因此，如果器件的介电中不存在导电丝，则可以假设该器件未被篡改且是安全的。在横向切换配置的情况下，当器件 SET 时，在 RESET 操作期间，只有一个器件可以进入 HRS，而其他器件将保持在 LRS。哪些器件保持在 LRS 以及哪些进入 HRS 是完全随机的。

[Figure 12.19](#Chapter12.html#c12_fig19) 显示了横向切换导电丝基础忆阻器 PUF 的设计。与之前的设计类似，有用于各种操作的控制信号，且 ![image](OEBPS/images/c12-Eqn-in-38.gif) 用于选择忆阻器器件 M1 或 M2 的成形步骤或操作模式。当向 ![image](OEBPS/images/c12-Eqn-in-39.gif) 施加信号“0”时，将向器件施加 RESET ![image](OEBPS/images/c12-Eqn-in-40.gif) 或 SET ![image](OEBPS/images/c12-Eqn-in-41.gif)，在此期间，它们之间的节点处于浮空状态。当向 ![image](OEBPS/images/c12-Eqn-in-42.gif) 施加“1”时，两个器件均由 ![image](OEBPS/images/c12-Eqn-in-43.gif) 驱动，忆阻器被加载。当导电丝形成时，将执行 RESET 操作，其中一个忆阻器将进入 HRS。MUX 的选择信号将被赋予挑战位，并读取响应。与其他 PUF 相比，二元忆阻器 PUF 的抗噪声能力较高，因为它被强制进入 LRS 或 HRS。只要状态远离阈值，噪声容限就高。但忆阻器的操作接近阈值电压，这降低了噪声容限。

Figure 12.19 基于 1 位导电丝的忆阻式 PUF

## 12.9 二极管基础 PUF

与其他电路设计相比，交叉阵列具有多种优势，使其更适合用于 PUF 设计。[Figure 12.21](#Chapter12.html#c12_fig21) 显示了忆阻器交叉阵列的设计。规则结构、低能耗、高集成密度和简单的设计实现是其中的一些优势。除此之外，这种设计也存在一些缺点，例如隐悄电流路径和串扰。隐悄电流取决于反向结电流。

![image](OEBPS/images/PBCS0600-12-f21.jpg)

Figure 12.21 忆阻器交叉阵列

交叉阵列中有两组导线，水平和垂直，如 [Figure 12.21](#Chapter12.html#c12_fig21) 所示。导线的交叉点由薄材料或分子化合物隔开。该化合物对导线之间的任何电压变化都具有电阻性。因此，可以使用交叉点实现不同的电阻状态，用于存储数据。水平导线为字线，垂直导线为位线，电压分别为 `*V*[word]` 和 `*V*[bit]`。用于读取的施加电压高于读取电压。

当图中的忆阻器被二极管替换时，它就变成了基于二极管的交叉阵列。在这种情况下，有三种方案：在浮空方案中，未访问的位线和字线保持浮空。在单电源偏置方案中，未访问的字线和位线保持在电压 ![image](OEBPS/images/c12-Eqn-in-46.gif)。当它为“0”时，被视为接地方案。在双电源偏置方案中，未访问的字线偏置于电压 ![image](OEBPS/images/c12-Eqn-in-47.gif)，位线偏置于 ![image](OEBPS/images/c12-Eqn-in-48.gif)。当它们相等时，将处于单电源方案；当它们极性相反时，称为反向偏置方案。交叉阵列单元是一个由两个电阻状态 ![image](OEBPS/images/c12-Eqn-in-49.gif) 和 ![image](OEBPS/images/c12-Eqn-in-50.gif) 组成的双稳态元件，用于存储“1”和“0”。该设计的噪声容限可计算为 ([Ruhrmair *et al*., 2011](#Chapter12.html#c12_bib62))：
