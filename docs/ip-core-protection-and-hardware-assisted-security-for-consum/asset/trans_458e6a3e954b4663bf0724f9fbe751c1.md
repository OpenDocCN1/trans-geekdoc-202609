## 5.3.5 DSP IP 核的买方指纹和卖方水印编码规则

双方的签名可以在 HLS 过程中作为编码的额外约束嵌入设计中。Roy 和 Sengupta（[2017](#Chapter5.html#c05_bib32)）将指纹和水印约束隐蔽地植入 DSP 核设计方法论的调度和寄存器分配阶段（以 HLS 为骨干）。更具体地说，买方指纹约束在调度步骤中通过在解决调度冲突时强制特定 CS 中的特定操作来执行。这是一种非常智能的嵌入买方指纹的过程，因为它将产生零硬件开销，并且可能产生名义上的延迟开销。此外，在寄存器分配期间，指纹和水印约束通过彩色区间图（CIG）的概念插入，其中图的每个节点表示设计的存储变量，连接边缘表示符合存储变量之间的执行时间重叠。

更明确地说，如果两个存储变量之间存在执行时间重叠，则这些相应节点之间会有一条边。因此，注入额外边缘作为编码的签名约束将强制 CIG 的存储变量使用独特的寄存器实现。Roy 和 Sengupta（[2017](#Chapter5.html#c05_bib32)）所设计的方法的相应插图如 [Figure 5.4](#Chapter5.html#c05_fig4) 所示。

指纹编码规则：Roy 和 Sengupta（[2017](#Chapter5.html#c05_bib32)）设计的指纹编码过程在 DSP 核设计的调度和寄存器分配阶段都嵌入了额外约束，以增强签名强度。Roy 和 Sengupta（[2017](#Chapter5.html#c05_bib32)）为每个变量设计的指纹编码规则定义如下：

*   A = 在调度阶段解决调度冲突时，强制奇数 CS 中的偶数操作。

*   B = 在调度阶段解决调度冲突时，强制偶数 CS 中的奇数操作。

*   C = 在 CIG 中添加节点对编号（奇数，奇数）之间的额外边缘。

操作最初需要根据其操作编号进行排序，以便应用针对‘A’和‘B’的编码指纹约束。同样，在应用针对‘C’的编码指纹约束之前，需要对存储变量进行排序（注意：这种编码指纹嵌入方法将在即将到来的章节中使用一个工作应用程序进行演示）。买方指纹的鲁棒性与签名强度成正比。[Roy and Sengupta (2017)](#Chapter5.html#c05_bib32) 能够接受和嵌入任何大尺寸的指纹。如所见，此指纹嵌入过程包括三个不同的变量，每个变量都带有独特的编码规则，在保持鲁棒性的同时，对设计的面积和延迟不会带来显著开销。

建议在选择买方指纹时，签名中‘A’和‘B’数字的数量应高于‘C’数字。原因是，‘A’和‘B’数字的编码以一种方式制定，使其不会产生硬件面积开销，并且延迟开销微乎其微。这是可以理解的，因为这两个数字是在解决操作调度冲突时注入的，即指纹编码规则充当冲突解决器。相反，签名中过多的‘C’数字可能会产生硬件开销。尽管如此，它是一个关键数字，因为它通过在 HLS 的另一个阶段植入指纹约束来增加额外的安全层。

水印编码规则：Roy 和 Sengupta（[2017](#Chapter5.html#c05_bib32)）使用的水印编码机制采用自（[Sengupta and Bhadauria 2016](#Chapter5.html#c05_bib14)）。在（[Sengupta and Bhadauria 2016](#Chapter5.html#c05_bib14)）中，水印的补充约束通过在 CIG 的节点之间注入额外边缘来植入寄存器分配中。插入额外边缘要求 CIG 的存储变量在独特的寄存器中实现。这种方法在寄存器分配步骤中注入任意数量的额外边缘方面具有灵活性。水印的鲁棒性随植入的额外边缘数量（即签名大小）而增加。尽管随着水印签名尺寸的增加而增强强度，但庞大的签名会带来重大的设计开销。因此，使用一种能够以边际设计成本负担提供广泛保护的强水印变得必要。如前所述，([Roy and Sengupta 2017](#Chapter5.html#c05_bib32)) 使用来自（[Sengupta and Bhadauria 2016](#Chapter5.html#c05_bib14)）的多变量水印过程。Sengupta 和 Bhadauria（[2016](#Chapter5.html#c05_bib14)）中的水印生成机制包含四个不同的变量。卖方可以通过这些四个变量的任意组合生成唯一水印。每个变量描述一个独特的编码规则，在两个特定节点之间注入一条额外边缘。更明确地说，从 CIG 中选择节点对以插入额外边缘的方法在编码方案中有详细说明。编码方案的说明已如下描述：

*   i = 在 CIG 中添加节点对编号（质数，质数）之间的额外边缘。

*   I = 在 CIG 中添加节点对编号（偶数，偶数）之间的额外边缘。

*   T = 在 CIG 中添加节点对编号（奇数，偶数）之间的额外边缘。

*   ! = 在 CIG 中添加节点对编号（0，任何整数）之间的额外边缘。

尽管指纹的‘C’数字和水印的‘i’、‘I’、‘T’和‘！’数字通过 CIG 在寄存器分配阶段植入签名约束，但由于它们的编码规则各不相同，因此随之而来的约束将完全不同。

## 5.3.6 多变量签名嵌入过程

实现对称 IP 保护的步骤，即通过植入指纹和水印过程，将在本节其余部分中描述。

植入指纹的过程

**广泛步骤：**

1.  选择买方签名。

2.  解码签名以获取等效的指纹约束。

3.  在调度期间解决操作冲突以嵌入指纹约束。

4.  基于将存储变量分配给寄存器来构建 CIG。

5.  如有必要，在基于指纹约束向 CIG 插入额外边缘时执行寄存器重新分配。

**详细步骤：**

1.  从买方接收首选签名，作为‘A’、‘B’和‘C’数字的随机混合。

2.  构建 DFG 操作的排序列表，按操作编号递增顺序排列。
