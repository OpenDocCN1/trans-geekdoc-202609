

# 在本书中，我们将“硬件辅助安全”定义为消费电子（CE）设备中用于 DSP 和多媒体应用的硬件/IP 核心的安全/保护，或由 CE 设备的硬件/系统对信息的安全/保护。

“安全”一词涵盖了一个广泛的主题，包括硬件安全、保护、隐私、可信度以及 IP 核心保护和信息安全等诸多方面。“安全”一词描述了处理数据或信息的系统（例如 CE 设备）的安全性。在基于 CE 的架构中，对其硬件和 IP 核心的防御至关重要。因此，使用安全 IP 的做法变得非常重要。在智慧城市时代，日益增长的 CE 硬件设计复杂性正在超越设计师的产能，从而导致更大规模的项目。此外，当前的 CE 设计群在很大程度上依赖于全球 IP 供应链。为了提高设计生产率并缩短设计时间，使用通常由第三方供应商提供的 IP 核心已成为行业中至关重要的 `de-facto` 做法。据估计，顶级假冒产品可能对半导体市场产生 3000 亿美元的影响。然而，日益增加的安全威胁和日益严重的盗版担忧确实影响着全球供应链。因此，信息安全（涵盖 CE 设备不断处理的数据、信息和多媒体的安全）变得至关重要（[Sengupta *et al.*, 2018](#Chapter1.html#c01_bib27); [Mohanty 2018a](#Chapter1.html#c01_bib10), [2018b](#Chapter1.html#c01_bib14)）。

## 1.3 知识产权（IP）核心/硬件

### 1.3.1 CE 设备中 IP 核心的实用性

硅技术的快速发展导致 CE 设备设计复杂性大幅上升。在数十亿美元晶圆厂的实际运营中，越来越多的应用被整合到单个硅晶圆上。与此同时，市场需求推动了更大的设计启动、缩短了设计时间，并增加了上市时间压力。为了应对这些困难，IP 核心（尤其是用于复杂 DSP 和多媒体应用的 IP 核心）已成为一种务实的解决方案。一个 IP 核心一旦在特定工艺技术的设计中得到验证，就可以用于其他采用相同工艺技术的设计。反过来，这消除了在大多数系统级仿真测试中采用该核心的必要性，进而降低了整体系统设计和验证的复杂性。举个简单的例子，一旦用于图像压缩的 JPEG CODEC 核心或小波变换核心在特定硅工艺中得到验证，就可以轻松地集成到其他 CE 设备的 SoC 设计中（[Sengupta, 2016](#Chapter1.html#c01_bib19)）。

### 1.3.2 为什么需要硬件/IP 核心的安全和保护？

对复杂 CE 设备（包括复杂 DSP/多媒体核心）的需求，导致可重用 IP 核心被广泛使用。此类复杂 IP 核心的日益重复使用，不可避免地使其面临假冒的风险。由于一个 IP 核心可能代表数年的设计、研发和验证工作，一个关键问题是如何保护这一资产？以及如何识别/防止核心的假冒？

据我们所知，事实是，实际 IP 所有者的权利可能会被故意或无意地侵犯。这可能通过滥用许可协议来实现，即在仅获得单一许可的情况下，将 IP 核心部署到众多设备中。晶圆厂甚至其他 IP 核心制造商可能会有很大的诱惑，将高质量设计集成到其他系统组件中，而实际的许可规则可能会阻止这种行为。随着系统变得复杂，IP 核心制造商越来越倾向于将其他 IP 核心分许可以包含在其设计中，一旦设计过程完成，就很有诱惑力将其重复用于其他可能不包含实际许可的补充产品中。对 IP 核心的另一个迫在眉睫的威胁是盗版，即通过不正当手段或逆向工程，未经授权直接窃取/复制 IP 以供重复使用。作为 IP 盗窃的结果，攻击者甚至可能声称拥有 IP 的权利。因此，一种撤销不诚实的 IP 所有权主张的方法是非常可取的。对于 IP 核心或整芯片设计的制造商来说，证明其 IP 在产品中被非法使用既棘手又昂贵。在硅芯片的情况下，识别 IP 核心的一种现实方法是获取待测产品的样本，送往专业实验室进行分析。此外，硬件设计过程中任何形式的第三方入侵都可能导致 CE 硬件出现严重的安全隐患。因此，保护 CE/IoT 硬件可以被视为保护 IP 核心免受不诚实的所有权主张。另一种称为“硬件木马”的威胁，是指供应商处的对手故意将恶意逻辑注入设计（例如 IP 核心硬件）的行为，这将针对影响安全协议的检测/纠正策略。上述两种硬件漏洞都可能出现在任何设计抽象级别。预处理或后处理风格的方法是根据应用安全的级别定义的，这通常由 DSP 核心的复杂性驱动。例如，对于包含 15K–50K 级门数的复杂 DSP/多媒体核心，在架构（高级）综合阶段采用的安全方法更有益且更有成效（[Sengupta and Kundu, 2017](#Chapter1.html#c01_bib26)）。

### 1.3.3 传统的 IP 保护形式是否足够？

在过去几年中，已采用了各种方法，通过专利、版权、商标等来保护此类核心。然而，这些方法尚未充分建立起来，以保护 CE 设备中使用的 IP 核心的价值。主要原因是实施的设计成本；此外，证明侵权的举证责任也过于昂贵。此外，在 CE 行业中，关于可重用 IP 核心的保护，大多数 IP 核心供应商依赖于对其业务合作伙伴的共同信任以及运营期间的隐私。
