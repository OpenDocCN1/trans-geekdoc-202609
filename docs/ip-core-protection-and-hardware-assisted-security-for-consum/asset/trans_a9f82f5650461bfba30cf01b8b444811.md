## 2.6.2 无人机或无人机安全

有多种不同类型的无人机和 UAV。无人机和 UAV 被用于日常生活的各种应用，从军用级到家用级（UAV，[https://www.theuav.com/](https://www.theuav.com/））。这些应用旨在减少在危险情况（如敌对区域）中的人类交互，并提高日常应用的效率。但是，与前面章节讨论的其他智能车辆一样，无人机和 UAV 也容易受到多种不同攻击的影响。本节描述了无人机和 UAV 的不同安全威胁以及可以保护免受这些威胁的安全措施。

图 2.40 UAV 安全 – 全景图

其中许多组件容易受到来自计算机的各种攻击。因此，攻击可以来自远程源，攻击者在攻击时不需要靠近设备。攻击者可以执行不同的操作，例如：

*   通过执行分布式拒绝服务（DDoS）攻击来更改控制速率。
*   从传感器收集的数据可以被修改，这可能会使飞行变得危险。
*   可以分析无人机的数据，以查找可在以后攻击中利用的设计缺陷。

可对 UAV 执行的攻击大致可分为两类：完整性攻击和拒绝服务攻击（[Sedjelmaci *et al.*, 2017](#Chapter2.html#c02_bib79)）。完整性攻击通过更改和发送虚假信息来破坏车辆的功能。[图 2.41](#Chapter2.html#c02_fig41) 显示了针对 UAV 的不同类型的攻击。GPS 欺骗是一种常见的攻击，可以针对 UAV 的接收器执行，该接收器可以向车辆发送虚假坐标，这可能会使飞行变得困难。通过执行此攻击，UAV 可能会认为自己处于与原始位置不同的位置。由于此攻击，车辆被攻破并执行了此类攻击（[Shepard *et al.*, 2012](#Chapter2.html#c02_bib87)）。但是，要执行此攻击，欺骗信号应与原始信号精确对齐，并逐渐增加欺骗信号的强度以控制目标。获得控制权后，伪造信号可以远离控制无人机的原始信号（[Nighswander *et al.*, 2012](#Chapter2.html#c02_bib62); [Shepard and Humphreys, 2011](#Chapter2.html#c02_bib88)）。无人机检测此攻击非常困难，因为当此攻击正在执行时，无人机的导航系统不会发出任何警报。

![image](OEBPS/images/PBCS0600-02-f41.jpg)

图 2.41 针对 UAV 的安全攻击

UAV 还可能受到类似 UAV 的攻击，这可能导致真实车辆向接收器传输伪造数据。可以使用伪造 UAV 与真实车辆通信并发送虚假数据。然后，真实车辆将伪造的数据传输到基站，在某些情况下可能会造成灾难性后果。这被称为注入攻击。UAV 的位置和其他防撞系统由 UAV 上存在的 ADS-B 控制器处理（[Sedjelmaci *et al.*, 2016](#Chapter2.html#c02_bib80)）。攻击者可以利用这些系统执行 ADS-B 攻击，该攻击将向系统发送虚假位置数据。这被称为欺骗攻击。

另一种常见的可针对 UAV 执行的攻击是拒绝服务攻击。可以通过发送大量数据包来执行此攻击，这将中断 UAV 的通信，使其无法使用。干扰、灰洞和黑洞攻击是一些 DoS 攻击。干扰将干扰与基站的通信，这可能导致失去控制并阻止任何新命令。灰洞和黑洞攻击将初始化一个节点，诱使 UAV 发送数据并将数据转发到服务器，但在节点接收到数据后，会丢弃所有数据或窃取数据。

可以提高 UAV 的安全性，但随着安全性的提高，可能会出现许多问题，如 [图 2.42](#Chapter2.html#c02_fig42) 所示。添加安全模块后，整个 UAV 的重量会增加。对于航空器来说，重量在飞行至目的地中起着重要作用。增加重量后，空气动力学会发生变化。向系统添加更多组件后，电池消耗增加是一个主要问题。添加更多电池后，又会循环回到空气动力学问题。
