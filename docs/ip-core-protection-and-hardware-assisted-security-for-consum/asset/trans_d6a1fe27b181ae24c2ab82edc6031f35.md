*   (i) 能够在绕过局部最小值的同时获得全局最优解
*   (ii) 能够在探索过程中引入随机性
*   (iii) 能够在整个迭代过程中保持开发与探索之间的适当平衡

#### 9.3.3 生成结构混淆的 JPEG 压缩 IP 核

结构混淆通过将 JPEG 硬件的标准架构转换为不明显的设计来阻碍逆向工程过程。因此，攻击者更难识别结构混淆设计的原始功能。基于 THT 的结构混淆应用于 JPEG DFG 的标准结构 ([Sengupta *et al.*, 2017b](#Chapter9.html#c09_bib30))。这是一种编译器驱动的优化技术，通过将依赖的关键路径操作划分为临时子计算来并行化这些操作。然而，此技术尚未用于为 JPEG 生成结构混淆的 DFG。图 9.7 所示的 JPEG DFG 标准结构通过 THT 进行结构混淆。变换后的 JPEG DFG 结构如 [图 9.8](#Chapter9.html#c09_fig8) 所示。混淆微 IP8 的放大表示也显示在该图中。由于此变换，每个微 IP 以及宏 IP 都被修改。例如，在微 IP8 中，16 个节点中的 12 个节点受到影响。它们是节点编号 115、116、117、118、119、120、122、123、124、125、126 和 127。因此，在八个微 IP 中，96 个节点受到影响。此外，在宏 IP 中，六个节点受到影响，包括 130、131、132、133、134 和 135。如果节点的父节点或子节点发生变化，或者该节点的操作类型与原始节点相比发生变化，则该节点被视为受影响。这些变化产生不同的数据路径、互连逻辑、多路复用器/解多路复用器和控制器逻辑结构，一旦通过高级综合处理。
