

# (1) 密钥敏感化攻击

在此攻击中，攻击者通过应用多个输入模式来确定/敏感化正确的密钥值。如果密钥门是隔离的、未成对保护的、可变的，并且以背靠背方式连接，密钥敏感化攻击对攻击者来说将很容易。攻击者可以在从市场上购买的功能 IC 上应用特定的输入模式并观察其相应输出，然后在锁定网表中应用相同的输入并使用不同的密钥值来确定正确的密钥。因此，为了防止密钥敏感化攻击，密钥组件的放置非常重要。密钥门应以这种方式放置在锁定网表中，使得密钥门之间存在依赖关系。这确保了“禁止密钥隔离”和“多对一安全”特性（在 8.2 节中讨论）。

多个密钥门不应以这种方式连接，使其可以用单个密钥门替换，这会增加密钥空间中有效密钥的数量。这确保了“禁止密钥门串联”。此外，如果密钥门可以被静音，也可以进行敏感化攻击（在 8.2.1 节中讨论）。ILB 的设计方式（在八个密钥输入的门结构中相互交织）使得密钥门是多对一安全的，ILB 中没有可用的隔离密钥门，没有密钥门可以被静音，并增强了使用单个密钥确定和替换密钥门串联的攻击复杂性。因此，Sengupta *et al.* 的 ([2018](#Chapter8.html#c08_bib35)) 方法提供了对密钥敏感化攻击的弹性。

# (2) IP 盗版和木马攻击

基于 ILB 的功能混淆方法阻碍了攻击者的努力（因为密钥门结构在 8 位密钥输入中彼此高度交织），通过逆向工程检测正确密钥。只有有效的密钥值组合才能激活锁定网表。

# (3) SAT 攻击

SAT 求解器对于乘法器电路不可扩展 ([Subramanyan *et al.*, 2015](#Chapter8.html#c08_bib37); [Finke, 2015](#Chapter8.html#c08_bib11); [Chakraborty *et al.*, 2017](#Chapter8.html#c08_bib6))。即使对于小型 3 位乘法器，等效 CNF 也有 20 个子句 ([Finke, 2015](#Chapter8.html#c08_bib11))。通常，DSP 核心包含几个大位宽乘法器作为组成部分。因此，DSP IP 核心设计具有 SAT 攻击抗性。然而，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 的作者提供了一种主动对策（假设未来可能会为 DSP 核心制定有效的 SAT 攻击），该方案受到 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 的启发，其中密钥位的子集通过自定义轻量级 *AES 块（非公开设计）* 与固定密钥加密。基于加密的密钥位，ILB 的子集被设计并插入到混淆网表中。这防止了攻击者在没有 AES 块密钥的情况下确定正确的密钥值（如 [图 8.7](#Chapter8.html#c08_fig7) 所示）。Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 设计了他们自己的 *自定义轻量级 AES 架构*，包含 429 个逻辑元素。该 AES 块在集成 DSP 核心的混淆网表后，使用 Altera Quartus ([2018](#Chapter8.html#c08_bib23)) 13.0 版本在 [Cyclone II FPGA (2018)](#Chapter8.html#c08_bib7) 中实现时，占用了最终设计逻辑元素的 <1%。自定义 AES 块集成的混淆 4 位 FIR 的顶层设计及其相应的门结构在 Altera Quartus 中实现，如 [图 8.8](#Chapter8.html#c08_fig8) 和 [8.9](#Chapter8.html#c08_fig9) 所示。AES 集成混淆网表文件的部分提取部分如 [图 8.10](#Chapter8.html#c08_fig10) 所示，这表明单个逻辑组件无法区分。FO FIR 设计的仿真结果如 [图 8.11](#Chapter8.html#c08_fig11) 所示。文献中可用的一些轻量级 AES 架构示例是 [Hamalainen *et al.* (2006)](#Chapter8.html#c08_bib13) 和 [Morioka and Satoh (2002](#Chapter8.html#c08_bib20))。集成自定义 AES 块后的 FIR DSP 核心后综合结果如 [表 8.1](#Chapter8.html#c08_tbl1) 所示。当密钥未知时，从 AES 输出确定其输入在计算上是不可行的。为了防止 SAT 攻击，执行以下步骤：

* (i) 设计师使用固定密钥合成 AES 块。
* (ii) 功能混淆的密钥子集通过 AES 块加密。
* (iii) AES 块的输出（加密密钥）根据通过 AES 加密的密钥数量连接到锁定网表中的少数 ILB。
* (iv) 基于 AES 块的固定密钥和 AES 的输入，设计师可以识别 AES 的输出，并通过重新组织 ILB 的内部门结构相应地配置 ILB。（注：ILB 内部门的重新组织不会增加任何额外门，而仅更改其配置和连接。）
