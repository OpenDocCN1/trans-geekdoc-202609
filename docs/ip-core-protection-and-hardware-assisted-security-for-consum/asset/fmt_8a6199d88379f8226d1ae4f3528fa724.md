### 11.7.2 Video watermarking hardware systems

Until now, this section discussed the implementation of hardware-based watermarking schemes for the image files. But this part of the section presents different modules for the implementation of the watermarking schemes for video systems.

#### 11.7.2.1 Invisible-robust spatial domain module

A real-time embedder–detector modules are developed for the implementation in broadcasting in the framework of VLIW DSP processor and are presented by [Depovere *et al*. (1999)](#Chapter11.html#c11_bib24), Strycker *et al*. ([1999](#Chapter11.html#c11_bib101), [2000](#Chapter11.html#c11_bib102)), and Termont *et al*. ([1999](#Chapter11.html#c11_bib107)). During the insertion of the watermark, the pseudorandom numbers are added to the received video stream and it is based on the luminance value of the frame. Detection of the watermark will depend on the correlation value calculations. Spatial and Fourier domains are used for watermark insertion and detection. Insertion process consists of adding pseudo random numbers to the stream. The initial sequence is a user key and then it is shifted and sum is calculated to generate *n* basic pseudo random patterns. Then one pattern out of those *n* is chosen thus creating a key. The size of this created number is ![image](OEBPS/images/c11-Eqn-in-104.gif), which is same as that of the size of video frame. Depth of insertion will determine the imperceptibility and the robustness of the watermark. Larger values make the watermark more secure but are likely to be visible than the smaller numbers. The algorithm is designed to increase the security while reducing the visibility. The detection module will retrieve the key if a watermark is present. A group of *G* frames are selected and then folded. Sum of it is calculated with a buffer of size ![image](OEBPS/images/c11-Eqn-in-105.gif)and correlated with each of *n* pseudo random numbers. This is equivalent to the 2D cyclic convolution which can be efficiently performed in the Fourier domain. If the correlation so obtained, known as decision variable, exceeds the predefined threshold, the video is declared as watermarked. #### 11.7.2.2 Invisible-robust spatial domain chip

A millennium watermarking scheme system is presented by [Maes *et al*. (2000)](#Chapter11.html#c11_bib56) for the implementation in DVD video system. The watermark detector location and the generation of copies of the DVD are discussed by [Maes *et al*. (2000)](#Chapter11.html#c11_bib56). The insertion phase of the watermark in this algorithm consists of addition of scaled watermark to the original media object signal in the spatial domain. The detection phase consists of calculating the correlation in Fourier domain. The algorithms are presented by Strycker *et al*. ([1999](#Chapter11.html#c11_bib101), [2000](#Chapter11.html#c11_bib102)). The memory usage in this scheme for DVD video watermarking should be minimal.

A real-time detection module is designed and implemented using three different modules such as Trimedia processor board, high-end silicon graphics workstation, and an FPGA. FPGA platform implementation has been the most relevant implementation for the DVD watermarking ([Maes *et al*., 2000](#Chapter11.html#c11_bib54)). A random number generator is implemented which increases the robustness of the entire modules and the watermark.

Implementation of watermarking for the raw video encoding is presented by [Tsai and Wu (2003)](#Chapter11.html#c11_bib111). A standard video encoder is used for implementing the watermarking algorithm like MPEG-1/2/4, H.26x, and Motion JPEG for a real-time IP protection. The insertion algorithm has three steps. Initially the watermark is read and the binary transformation is performed with a chaotic function. Then pseudo-noise is generated, which is of lengths 63 and 31, for both spatial and chaotic transformed domains. Then insertion is performed with a human visual characteristics that will dictate the weighting factor of ![image](OEBPS/images/c11-Eqn-in-106.gif)for watermark insertion to be 16 for edge blocks and 4, otherwise.

In case of detection of the watermark, the correlation of the original pseudo-random noise is calculated. For implementing the algorithm, verilog was used for the watermark function. This has an advantage of using an MPEG encoder for the compression and increasing the robustness of the video. Watermark function has three parts, pseudo-noise generator, data path, and inserting component and watermarking information generator.

#### 11.7.2.3 Invisible-robust fractal domain module

A real-time video watermarking scheme was presented by [Petitjean *et al*. (2002)](#Chapter11.html#c11_bib87). This actually embeds the watermark with the help of fractal approximation. Extraction of the watermark is done by performing the process in reverse to the insertion phase. C programming language was used for the implementation of the encoder and decoder. A general-purpose PC implementation of this algorithm will yield better results than that of the others.

For an increased security of the watermark, embedding exploits the affine transformation invariance properties of fractal coding. Embedding the watermark has three different phases:

*   Formatting and encryption

*   Cover generation

*   Embedding
