

除了高功耗和低功耗之外，任何消费电子系统还应具有可信性和安全性的特性。[图 2.15](#Chapter2.html#c02_fig15)展示了安全性、隐私性和保护的不同方面 ([Krishnamurthy *et al.*, 2017](#Chapter2.html#c02_bib43); [Mohanty, 2015](#Chapter2.html#c02_bib56))。系统中存在不同的层级，包括应用层、操作系统（OS）、固件、数字信号处理器（DSP）、嵌入式处理器、内存以及射频（RF）组件。在每个阶段，都可能对系统成功实施不同类型的攻击。应用程序和操作系统攻击可能发生在操作系统及其应用程序上。在操作系统与应用程序之间，或固件与操作系统之间，存在一个连接它们以执行操作的网络。该网络可能受到不同类型攻击的影响：应用程序攻击和网络攻击。其中一些在前面的章节中已讨论过。固件是系统不可或缺的一部分。它充当桥梁，使板卡或系统能够与其他组件或外设进行通信，并描述其功能。设备上可能发生不同类型的固件攻击。

设备的不同硬件组件，例如 DSP、嵌入式处理器、内存和 RF 组件，都可能成为各种攻击的目标，如 [图 2.15](#Chapter2.html#c02_fig15) 所示。IP 攻击、侧信道攻击、物理攻击和内存攻击是其中一些在硬件级别进行的攻击。输出产生后，输出中的数据可能会受到许多版权攻击。RF 组件也可能受到各种网络威胁的影响，这些威胁将在后续章节中讨论。

消费电子系统可信性的选定属性 ([Krishnamurthy *et al.*, 2017](#Chapter2.html#c02_bib43); [Mohanty, 2015](#Chapter2.html#c02_bib56)):

1. 系统正在处理的数据的完整性应得到维护。

2. 一旦设备部署到现场，就会容易受到侧信道攻击和功耗分析攻击。因此，正在处理的数据应在处理过程中得到保护和隐藏。

3. 设备的功能应限制在预期功能范围内。设备不应执行额外操作。

4. 设备应在任何时候都可靠，尤其是在关键操作期间。

5. 设备的透明度必须仅限于所有者，不得向任何其他人透露。

6. 在制造设备时，应联系可信供应商提供不同部件，以避免引入不需要的木马。

7. 应联系可信的制造设施。

#### 2.2.3 硬件辅助安全与保护

随着安全威胁的增加，仅靠软件安全无法抵御这些威胁。硬件辅助安全在减轻攻击者造成的威胁方面发挥着关键作用。系统可能受到两种不同类型的攻击：软件攻击和硬件攻击 ([Chang *et al.*, 2017](#Chapter2.html#c02_bib15); [Krishnamurthy *et al.*, 2017](#Chapter2.html#c02_bib43))。软件攻击通常通过通信通道进行。由于物联网通过网络连接，这很容易受到攻击者的威胁。这些攻击通常远程发起，设备受到影响。由于攻击者无需在设备现场即可执行这些攻击，因此可以定期且远程地进行。拒绝服务攻击、路由攻击、恶意注入、欺骗、窃听和暴力破解是一些软件攻击。

硬件攻击通常针对设备本身，并且大多数攻击必须在设备所在位置执行。某些类型的硬件攻击也可以远程执行。在物联网环境中，设备部署在人类交互极少的区域，因此极易受到攻击。侧信道攻击、后门、窃听、故障注入和硬件木马是一些硬件攻击。

对于软件和硬件两种攻击，可用的解决方案也是两种不同类型：软件解决方案和硬件解决方案 ([Krishnamurthy *et al.*, 2017](#Chapter2.html#c02_bib43))。软件安全解决方案易于使用、更新和升级。这提供了提高鲁棒性的灵活性。由于基于软件的应用程序依赖于操作系统，它们得到广泛支持，并可设计为跨平台应用程序。软件安全的经常性运营成本较高。它们可用于通用处理器，但主要缺点之一是无法保护系统免受逆向工程和其他硬件攻击的影响。在硬件安全解决方案中，与软件解决方案相比，它们速度非常快，功耗较低，优化灵活性高，并且在使用现场可编程门阵列或专用集成电路时成本较低。它们无法用于防止软件逆向工程，并且极易受到侧信道攻击的影响。

[图 2.16](#Chapter2.html#c02_fig16) 展示了安全感知设计的权衡，并描述了设计的不同方面。硬件辅助安全的示例在 [图 2.17](#Chapter2.html#c02_fig17) 中所示。设计系统时的主要关注点是低功耗和高性能、可靠性、低制造成本以及易于集成。在安全摄像头系统的设计中，水印芯片是主要关注点，因为大部分安全性由其提供。存在的权衡包括功耗、性能、芯片面积、系统集成以及内存。将更多内存集成到系统中将增加摄像头的电池寿命、芯片面积和设计成本。提高安全性也会增加电池消耗和其他参数，如 [图 2.16](#Chapter2.html#c02_fig16) 所示。因此，设计应在考虑所有参数以及安全性权衡的前提下进行，并包含额外的硬件组件，这些组件将执行类似于电压和频率缩放的技术，用于安全性、能源和性能优化 ([图 2.17](#Chapter2.html#c02_fig17); [Krishnamurthy *et al.*, 2017](#Chapter2.html#c02_bib43))。
