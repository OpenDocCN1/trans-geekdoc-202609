

# 2.1 物联网（IoT）– 广泛概述

本章组织如下：第 2.1 节介绍物联网的概述；第 2.2 节介绍消费电子系统中安全、能源和成本的权衡；第 2.3 节介绍系统内存模块的不同安全威胁及解决方案；第 2.4 节介绍射频识别（RFID）模块的不同威胁及解决方案；第 2.5 节介绍系统近场通信（NFC）模块的安全缺陷及缓解方法；第 2.6 节讨论智能车辆、自动驾驶汽车和无人驾驶航空器（UAV）中的不同安全缺陷；第 2.7 节讨论攻击者如何攻击医疗设备，并为部分攻击提供解决方案；第 2.8 节讨论设备固件面临的威胁；第 2.9 节讨论区块链这一新兴技术及其优势和问题。结论和未来方向在第 2.10 节中介绍。

通信在世界范围内以非常快速的速度发展。已为短距离或长距离通信提出了多种解决方案。技术增长也帮助开发高性能计算设备，使得寻找新发明成为必要。其中一项重大创新是“物联网”，它已成为日常生活不可或缺的一部分。物联网有许多定义，因个人视角而异。在物联网环境中，所有设备或“事物”都连接到网络，并相互交换数据或发送到云端（[Mohanty *et al.*, 2016](#Chapter2.html#c02_bib57））。物联网语境下的“3-I”概念如 [图 2.1](#Chapter2.html#c02_fig2) 所示，包括“互联”、“智能”和“仪表化”。这三者是物联网环境的重要方面，如图中智慧城市环境所示。互联是为设备提供网络和互联网连接的通信平台，帮助在设备之间或向云服务传输数据，云服务中进行后处理。智能是整个环境的大脑，仪表化指环境中存在的各种设备和传感器。物联网环境中存在各种设备，例如微控制器、单板计算机和传感器。每个设备都应具有唯一 IP 地址，才能被视为物联网中的事物（[Mohanty, 2018](#Chapter2.html#c02_bib55））。

物联网可以定义为随时连接、随物连接和随地连接，如 [图 2.2](#Chapter2.html#c02_fig2) 所示（[IEEE, 2015](#Chapter2.html#c02_bib35)）。物联网并非局限于某一位置，而是无处不在，随处可感。部分物联网设备可部署在不受持续监控的地方。其作用是监测参数并通过空中传输数据（[Yanambaka *et al.*, 2016a](#Chapter2.html#c02_bib111））。在这种情况下，应持续连接到互联网，这需要“随地连接”、“随时连接”和“随物连接”。随着技术进步，各种设备和开发板正在获得通信能力，这可以帮助以非常低的成本实现物联网环境。

## 2.1.1 物联网 – 架构

物联网解决方案的结构在其架构中描述。它包括物理、事物和虚拟、通信协议等各个方面。物联网架构如 [图 2.3](#Chapter2.html#c02_fig3) 所示。如图所示，物联网架构包含三个不同的方面，通过互联网相互连接。事物包括传感器、执行器和各种物联网设备等物理组件。传感器和执行器连接到物联网设备，这些设备有助于收集数据。物联网设备是智能设备，可以处理从传感器收集的数据。各种传感器和执行器通过有线或无线连接连接。物联网模型的不同抽象级别如 [图 2.4](#Chapter2.html#c02_fig4) 所示。

各种设备以不同方式与云和其他物联网设备通信，如 [图 2.5](#Chapter2.html#c02_fig5) 所示。部分传感器和设备直接与云通信并传输数据。此类设备性能较高，在将数据上传到云之前还可以进行部分数据处理。存在网关设备，它们作为设备与传感器之间的中间设备。这些设备在数据采集中起主要作用。预处理数据后，将其发送到云端。有各种云应用程序可为数据的最终用户提供交互界面。使用应用程序编程接口（API），客户端将拥有更多探索选项，并在需要时进一步处理数据。

物联网、雾计算和边缘计算是三种不同的概念，如 [图 2.6](#Chapter2.html#c02_fig6) 所示，它们提供控制和将数据传输到云存储的功能。云计算扩展到边缘，从而为软件、领域特定硬件和标准计算提供安全控制和管理。而边缘计算是对独立设备的管理和控制，可以单独进行，也可以通过雾域中的软件进行。

## 2.1.2 物联网 – 驱动技术

在物联网环境中，每个事物都将具有唯一 IP 地址，如上所述。并非每个传感器都具有通信能力。在这种情况下，将传感器与具有通信能力的设备结合，将成为物联网环境中所需的事物。物联网有各种方面。它已扩展到智慧城市、智慧医疗、智慧交通、智慧家居等各个领域。如 [图 2.7](#Chapter2.html#c02_fig7) 所示，各种传感器连接到不同的单板计算机或微控制器，这些设备具有唯一 IP 地址的能力，并通过互联网传输数据以形成事物。在图中，传感器连接到智能手表，智能手表将从传感器收集数据并将其传输到云端或其他设备。
