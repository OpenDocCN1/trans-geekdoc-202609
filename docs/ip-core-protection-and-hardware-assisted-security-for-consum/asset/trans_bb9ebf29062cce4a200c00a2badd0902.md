### 11.8 智能汽车或无人机中的动态水印

物联网如今已成为研究的主要焦点。随着每天都有新技术涌现，设计新 THINGS 已成为可能，传感器集成到各种设备中已成为每个应用中的重要任务。自诞生以来，智能交通和无人机技术已取得显著发展（[Mohanty, 2015](#Chapter11.html#c11_bib67)）。自动驾驶汽车和无人机正被用于各种目的。自动驾驶汽车已不再遥远。随着这一切的到来，安全是困扰研究界的主要关切之一。无人机和智能汽车都将具备视频录制功能。对该视频添加水印有助于确定摄像机录制的视频是否被篡改。

车辆录制的视频在某些情况下会实时处理，在某些情况下则存储在内存中以供以后分析。这两种情况对于智能汽车和无人机都很重要。当视频被录制时，汽车和无人机可能会受到各种攻击，这些攻击允许攻击者篡改车辆的视频监控录像。因此，引入车辆中的水印应具有抗篡改性（[Fallahpour *et al*., 2014](#Chapter11.html#c11_bib26)）。许多视频编辑软件允许用户篡改视频并使流不可靠，这违背了录制的目的（[Su *et al*., 2011](#Chapter11.html#c11_bib103））。因此，在这些场景中，检测和区分被篡改的视频也是必要的。

因此，水印应能提供透明性、鲁棒性和更高容量，以便可以嵌入到不同类型的视频素材中。在大多数情况下，脆弱水印用于检测视频的篡改（[Fridrich *et al*., 2000](#Chapter11.html#c11_bib30)）。在篡改的情况下，攻击者会尝试更改带水印的视频或对象，但不会触碰水印本身。这构成了巨大威胁，因为区分原始未篡改的视频将变得困难。脆弱水印将能够保护素材免受此类篡改攻击。在脆弱水印算法中，视频素材将对修改高度敏感，这将使得对视频进行任何类型的修改（如重新压缩）变得困难。[Sang and Alam (2008)](#Chapter11.html#c11_bib93) 还提出了一种半脆弱方案。

### 11.9 医疗信号认证

如前几节所述，技术的进步使我们能够探索高带宽通信，从而实现了全球数据传输（[Singh *et al*., 2017](#Chapter11.html#c11_bib100））。用于传输的设备已无国界之分，尤其是医疗用途，例如互联网、手机、无线通信等。此类通信网络面临着不同种类的威胁。共享的信息也高度敏感，包含患者的医疗记录。这要求更高的保密性和安全性。医疗图像水印可以提供更好的服务来解决这些问题（[Acharya *et al*., 2001](#Chapter11.html#c11_bib1); [Coatrieux *et al*., 2006](#Chapter11.html#c11_bib15)）。此类安全举措已有少量实现。例如，在远程医疗应用中使用水印以增强传输敏感医疗数据的安全性已被实现。当数据加密在医疗图像中时，远程医疗水印需要更加谨慎，因为信息本身及其质量不得受到影响。可靠性、保密性和可用性是电子病历（EPR）交换中安全性的主要关切。现代电信基础设施支持在无需医疗专家亲临现场的情况下提供优质医疗服务的可能性。在通过通信信道传输的生物医学信号被使用之前，必须建立其完整性。已进行了研究，其中在脑电图（EEG）监测应用中执行了用于信号完整性验证的数字水印技术。
