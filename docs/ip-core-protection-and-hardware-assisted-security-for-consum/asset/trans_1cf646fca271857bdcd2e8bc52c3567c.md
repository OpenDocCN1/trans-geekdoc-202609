

# 11.10.3 侧信道攻击对策

侧信道攻击在从微控制器或内存中窃取信息方面效率很高。攻击者可以在硬件上使用各种攻击，例如 CPA、DPA、时序分析等，以获取其中存储的信息。有许多技术可用于缓解功耗分析攻击的问题（[Ambrose *et al*., 2015](#Chapter11.html#c11_bib3); [Jayasinghe *et al*., 2015](#Chapter11.html#c11_bib38)）。有许多方法可以避免硬件模块上的侧信道攻击。图 [11.29](#Chapter11.html#c11_fig29) 和 [11.30](#Chapter11.html#c11_fig30) 展示了保护硬件模块免受 CPA 和 DPA 攻击的不同方法。

功耗分析攻击的主要缺点之一是，在大多数情况下，硬件在攻击期间应处于通电状态。因此，如果模块的电源被关闭，攻击者将无法再执行攻击。向电源引入一些中断也可以在一定程度上缓解安全威胁。当模块未使用时，可以断开其电源，但这仅适用于模块不完全掌握在攻击者手中的情况。在执行过程中，可能会出现非确定性执行，这在处理密钥时不会输出设备的精确功耗统计数据。这些是可以实施的一些硬件解决方案。去同步化、软件平衡、随机掩码等是针对安全模块 DPA 攻击的软件对策。

# 11.11 攻击水印和水印系统

当水印嵌入媒体对象时，在媒体到达接收器之前，它很可能会遭受操纵攻击。一些操纵包括模拟到数字和数字到模拟转换、重采样、量化、抖动、低通和高通滤波等。在某些情况下，媒体可以被打印并重新扫描，旨在从媒体中删除水印。任何旨在删除或篡改水印并导致检测过程失败的对水印图像的处理都是对水印的攻击（[Cox and Linnartz, 1998](#Chapter11.html#c11_bib17); [Mintzer *et al*., 1998](#Chapter11.html#c11_bib62); [Sequeira and Kundur, 2001](#Chapter11.html#c11_bib97); [Swanson *et al*., 1998](#Chapter11.html#c11_bib105); [Voloshynovskiy *et al*., 2001](#Chapter11.html#c11_bib115)）。水印的特性及其对攻击的性能是相互冲突的 FoM。比较不同算法的指标对于为特定应用选择合适的水印方案至关重要。水印的基准是在统一框架下的不同攻击，允许所有者检查方案的适用性。

本节讨论了可能针对带水印图像的不同攻击。有不同类型的攻击针对带水印图像以删除水印。它们被分为四种不同的类型（[Liu *et al*., 2017](#Chapter11.html#c11_bib50); [Pereira *et al*., 2001](#Chapter11.html#c11_bib84); [Vellaisamy and Ramesh, 2014](#Chapter11.html#c11_bib112); [Voloshynovskiy *et al*., 2001](#Chapter11.html#c11_bib115); Wang *et al*., [2017a](#Chapter11.html#c11_bib119), [2017b](#Chapter11.html#c11_bib120); [Xiang *et al*., 2014](#Chapter11.html#c11_bib123)），如 [图 11.31](#Chapter11.html#c11_fig31) 所示：

*   几何攻击
*   删除和干扰攻击
*   密码攻击
*   协议攻击

## 11.11.1 删除和干扰攻击

针对水印的删除攻击旨在从对象中删除水印。水印是添加到原始图像中的噪声，攻击者利用这一点来删除水印。干扰攻击通过向带水印图像添加更多噪声来攻击水印。量化、有损压缩、串谋、重调制、去噪、平均和噪声风暴是此类攻击的示例。JPEG、MPEG 等是有损压缩格式，可能会降低嵌入媒体对象中的水印质量。当许多带水印媒体副本的合法所有者聚集在一起创建无水印图像时，这被称为串谋攻击。这可以通过对已经带水印的媒体中不同对象进行平均来实现。

## 11.11.2 几何攻击

几何攻击更多地针对带水印的图像和视频。此类攻击不会删除媒体中存在的水印，但会操纵带水印的媒体，使检测器无法提取或检索水印。仿射变换，如平移、旋转和缩放，用于成功发起此攻击。线条删除、包裹和裁剪也可以用于从媒体对象中删除水印。马赛克攻击是此类别的另一个示例（[Koubaa *et al*., 2007](#Chapter11.html#c11_bib45)）。在此类攻击中，媒体对象被分成不同的部分，然后使用 HTML 重新排列为一个整体，这使得检测器难以检测水印。

## 11.11.3 密码攻击

上面讨论的两种攻击都无法突破算法安全性。密码攻击是精确攻击水印算法安全性并将其破解的攻击。当水印使用密钥保护时，如前几节所讨论，可以执行暴力攻击并将其破解，这可以被视为密码攻击。Oracle 攻击是另一种密码攻击，它使用公共水印检测器来创建无水印媒体对象。

## 11.11.4 协议攻击

此类攻击利用水印算法中存在的漏洞（[Craver *et al*., 1996, 1998](#Chapter11.html#c11_bib21); Wang, 2009; [Zhang and Liu, 2017](#Chapter11.html#c11_bib126)）。此类攻击也被称为反演、死锁或假冒-原件攻击。在已经带水印的媒体上引入一个或多个新水印，这使得难以检测原始水印和所有者。某些攻击会生成带有水印的假冒原始媒体对象，以便检测器将其检测为原始合法水印副本。从已经带水印的对象中检测水印并将其转移到另一个媒体对象，这被称为复制攻击，也非常流行。
