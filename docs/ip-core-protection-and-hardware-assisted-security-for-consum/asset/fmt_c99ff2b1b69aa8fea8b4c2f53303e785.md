
There are two components in an RFID system: the tag and the reader. The channel to communicate between them can be taken as an advantage and the vulnerabilities are exploited by the attacker. These are called as channel threats. Eavesdropping is a vulnerability of the RFID tag as the communication between the RFID tag and the reader is wireless. The information retrieved by eavesdropping can be used for different attacks like counterfeiting, copying the tag, track, etc. The transmitting power of the reader is high when compared with the RFID tag. so reading from the tag is going to be easier comparatively. To avoid the data being stolen, the data transmitted should be encrypted between the reader and the tag.

One other major vulnerability of the RFID tag is the replay attack. First, the data is collected by performing an eavesdropping attack on the RFID channel. This collected data is again replayed to the reader which is illegal and a false deception is achieved. The attacker can deceive the reader by impersonating the original tag and gain access. One time password, stamp program, and so on, are some of the solutions for these types of attacks. Man in the middle attacks, popularly known as relay attack is another security vulnerability of RFID, where the attacker can intercept the data between the reader and the tag but the attacker is far from the devices themselves. By using the devices, the data intercepted can be forwarded to another device and used for various reasons. This is called relay attack.

#### 2.4.2 RFID security solutions

It is said that any system is as secure as its weakest element. So to secure the entire system and increase the robustness, its weakest elements should also be made secure. The two different communication channels of RFID are front-end and back-end, respectively ([Vattem and Anjali, 2017](#Chapter2.html#c02_bib104)). Readers collect the data from the RFID tags. This is the front-end part of the communication. Once the data is collected from the tags; the data is transmitted to the servers to process it. This is called as the back-end of the system. The back-end communication is already made secure by using secure shell and secure socket layer. This is already standardized and secure. But the front-end is prone to many issues as discussed above. This can be considered the weakest part of the RFID systems.

There are many security solutions available for RFID systems ([Jayakrishnan *et al.*, 2018](#Chapter2.html#c02_bib37); [Sun and Zhong, 2012](#Chapter2.html#c02_bib96)). [Figure 2.25](#Chapter2.html#c02_fig25) shows various solutions for the RFID attacks that can be implemented to prevent the attacker to succeed in taking advantage of the vulnerabilities. Killing the RFID tags when a security threat is detected can be one of the ways of saving the security measures that can be implemented easily. The communication between the reader and the RFID tag can be temporarily stopped and necessary measures can be applied before continuing the communication again. The RFID tags themselves that does not contain any power source and hence the reader should be very near to the tag which needs the attacker to be near to the devices. Faraday cages can be implemented as a security measure. Faraday cages for security has been around for a very long time ([Ahmadi *et al.*, 2017](#Chapter2.html#c02_bib1); [Wu *et al.*, 2001](#Chapter2.html#c02_bib107)). [Figure 2.26](#Chapter2.html#c02_fig26) shows the structure and working of a Faraday cage. When it is implemented, the electromagnetic waves cannot pass through it as it is canceled out by the electric field generated around the Faraday cage. Cryptographic primitives like encrypting the communication between the tag and the reader can be implemented which can render the data collected by the attacker unless without the proper decryption. Blocker tags that block-out the unauthorized reader requests can be placed in proximity and can protect the authentic tags from being vulnerable.

In a scenario of a patient with an implantable medical device, access can be granted to the reader when the patient is lying down or in a specific predetermined posture which can prevent the attacker from gathering data or tampering with the system in other conditions ([Halevi *et al.*, 2013](#Chapter2.html#c02_bib29)). In the case of a keyless entry car, this context can be taken as an advantage ([Yang *et al.*, 2012](#Chapter2.html#c02_bib115)). There are various steps for the driver before starting the car engine, for example, opening the door of the car, sitting in the driver’s seat, etc. In this scenario, the posture of driver sitting in the driver’s seat can be considered for starting the car’s engine. ### 2.5 Near-field communications (NFC) security

Near-field communication, often also referred as NFC, is a short-range communication system. NFC is a contactless technology that allows data communication between the devices without internet connection. Features like Android Beam can be used in the NFC which allows for the users to transmit the data between devices. There are various applications of NFC which are shown in [Figure 2.27](#Chapter2.html#c02_fig27) ([Harbison, 2016](#Chapter2.html#c02_bib30)). The foundation for developing NFC is RFID technology. There are some drawbacks to the NFC technology which include smaller range and low data rates.
