### 8.7.3 比较分析

在本小节中，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 与 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 在泄漏功耗消耗和混淆设计成本方面的比较分析如下所示。此外，还讨论了 PSO 的探索时间以及插入 ILB 前后的设计延迟。Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 和 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 的泄漏功耗消耗图形表示如 [Figure 8.15](#Chapter8.html#c08_fig15) 所示。可以看出，对于所有测试的 DSP 基准测试，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 达到的功耗低于相关方法。与 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 相比，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 实现了平均 11.07% 的静态功耗降低。Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 和 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 的混淆设计成本图形表示如 [Figure 8.16](#Chapter8.html#c08_fig16) 所示。可以观察到，对于所有 DSP 基准测试，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 达到的设计成本低于相关方法。与 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 相比，Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 实现了平均 8.87% 的混淆设计成本降低。由于 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 和 Yasin *et al.* ([2016](#Chapter8.html#c08_bib44)) 均包含 AES 块以处理（潜在的）SAT 攻击，因此 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 因 PSO-DSE 而获得的总功耗和设计成本降低仍然保持不变。

### 8.8 结论

本章介绍了一种针对 DSP IP 核心的低成本功能混淆机制。该机制插入重新配置的 ILB 以锁定 DSP IP 核心的网表。此外，它集成了 AES 块作为主动对策来防止 SAT 攻击。此外，观察到 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 在功耗降低、设计成本降低和 SoO 增强方面优于其他类似方法。功能混淆的研究仍然是一个开放领域，需要针对其他硬件电路（如组合/时序电路基准测试）进行更多研究，以防范 SAT 攻击。目前正在发起新的攻击，如近似 SAT 和信号概率偏移，旨在抵消与组合/时序电路基准测试结合使用的反 SAT 块的效果。在这个方向上，未来有大量的工作空间。
