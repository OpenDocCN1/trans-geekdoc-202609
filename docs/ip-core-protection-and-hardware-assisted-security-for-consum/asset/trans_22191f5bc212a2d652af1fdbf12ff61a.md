

PSO 迭代搜索 DSP 核的低成本硬件架构设计方案。在每次迭代中，它会探索设计成本相同或更好的解决方案。然而，该迭代搜索过程基于以下两个条件终止：(i) 迭代次数超过最大计数（`I[max]`）；(ii) 全局最优解在最大连续迭代次数内保持不变（`δ`）。在 Sengupta *et al.* ([2017b](#Chapter3.html#c03_bib27)) 中，实验设置中使用的 `I[max]` 和 `δ` 值分别为 100 和 10。

##### 3.6.3.2 厂商分配程序

如前所述，调度和硬件分配是基于资源配置和厂商分配模式对 DMR CDFG 进行的。例如，对于 FIR 滤波器的 DMR，调度所需的硬件资源是加法器、乘法器和比较器（如 [图 3.24](#Chapter3.html#c03_fig24) 所示）。现在，为了在硬件分配中实现区分性，相同的 3PIP 核（加法器、乘法器和比较器）从两个不同的厂商导入。假设两个不同的厂商为 V1 和 V2；从 V1 导入的乘法器和加法器的面积分别为 2468 au 和 2034 au，延迟分别为 10,000 ns 和 265 ns；而从 V2 导入的乘法器和加法器的面积分别为 2464 au 和 2032 au，延迟分别为 11,000 ns 和 270 ns（*注*：这些值基于 90 nm 技术节点；假设 1 au = 1 个晶体管；ns = 纳秒）。

现在考虑基于候选解 `X[i] = 2(+), 2(*), 1(<), U = 2, M[v] = 00` 设计的 FIR 的抗木马安全 DMR CDFG（如 [图 3.25(a)](#Chapter3.html#c03_fig25a) 所示）。这表明 FIR 滤波器的 DMR CDFG 展开两次，基于两个加法器、两个乘法器和一个比较器进行调度，并使用模式 ‘00’ 进行厂商硬件分配。该设计的相应执行延迟和面积为：`T[E]^(DMR) = 45,080 ns` 和 `A[T]^(DMR) = 13,064 au`。如 [图 3.25(a)](#Chapter3.html#c03_fig25a) 所示，基于模式 00 的厂商分配规则（所有模式均在第 3.4.1.2 节中解释），`U^(OG)` 的操作在控制步骤（CS）中以交替方式分配给厂商。例如，`U^(OG)` 的 opn.1 和 opn.3 在控制步骤 1 中分别分配给 V1 和 V2 的硬件。此外，`U^(DP)` 的 opn.1′ 和 opn.3′ 分别分配给 V2 和 V1 的硬件。
