# 第 12 章

## 物理不可克隆函数 (PUFs)

以往的做法是将信息锁存起来以保护其安全。即使在今天，我们仍使用加密原语通过加密和解密来安全地存储信息。对于加密过程，任何操作都需要密钥。但这些密钥应存储在内存中，以便在需要时使用。当密钥存储在内存中时，攻击者可以使用各种方法将其窃取。因此，在当今充满安全威胁的时代，将其存储在非易失性内存中并非一个可行的选择。物理不可克隆函数 (PUFs) 是一种有前途的安全原语，用于生成密钥，而非将其存储在内存中。这些模块利用制造过程中自然出现的制造差异来生成用于加密目的的密钥。本章讨论了不同类型的 PUFs。第 12.1 节简要介绍了 PUFs。第 12.2 节讨论了 PUFs 的工作原理。第 12.3 节讨论了 PUF 设计的不同特性。第 12.4 节介绍了 PUFs 的不同分类。基于环形振荡器 (ROs) 的各种 PUF 设计在第 12.5 节中介绍，基于多路复用器和可重构性的设计在第 12.6 节中介绍。基于静态随机存取存储器 (SRAM) 的 PUFs 在第 12.7 节中介绍，基于忆阻器的 PUFs 在第 12.8 节中介绍，基于二极管的 PUFs 在第 12.9 节中介绍。还有非硅基 PUF 设计，例如碳 PUFs，在第 12.10 节中介绍。微处理器也可用于实现 PUF 设计，这些设计在第 12.11 节中介绍。基于磁性材料的 PUFs 在第 12.12 节中介绍，PUF 的 FPGA 实现以及 FPGA 的安全措施在第 12.13 节中介绍。一些案例研究应用在第 12.14 节中介绍。此外，PUF 模块设计过程中面临的问题和挑战在第 12.15 节中介绍。结论和未来方向在第 12.16 节中介绍。

### 12.1 简介

第一个晶体管于 1948 年发明。随着晶体管的引入，占据巨大空间的电子管消失了，并促成了 1958 年集成电路 (IC) 的发明 (Kilby, [1976](#Chapter12.html#c12_bib28))。摩尔定律随之而来，该定律指出 IC 上的晶体管数量每两年翻一番。这一定律直到最近一直成立，自首次引入以来，单芯片上的晶体管数量呈指数级增长。随着新的 10 nm 技术的引入，IC 的每平方毫米可以容纳 1 亿个晶体管 ([Courtland, 2017](#Chapter12.html#c12_bib11))。随着技术以如此惊人的速度改进，它已渗透到人类生活的几乎每个领域。通信、商业、金融交易等日常活动都依赖于技术。人类的数字足迹已成为不可避免和无法回避的参数 ([Gencoglu *et al*., 2015](#Chapter12.html#c12_bib16))。物联网 (IoT) 已成为我们生活中不可或缺的一部分。在物联网环境中，每个设备都连接到网络并拥有唯一的 IP 地址 ([Mohanty *et al*., 2016](#Chapter12.html#c12_bib54))。智慧城市、智能电网、智慧医疗等都是物联网的各种形式。

随着如此多的设备相互连接，引发了安全问题。各种应用程序、传感器和其他设备收集的数据应安全存储。最近报告了许多攻击，安全必须被赋予最高重要性 (Charette, [2018a](#Chapter12.html#c12_bib6), [2018b](#Chapter12.html#c12_bib7))。为了保护生成的数据，使用了加密技术。加密技术已存在很长时间。加密是通过将消息或信息转换为不可读文本来隐藏它的过程，只有最终用户才能从文本中提取原始信息。发现早在公元前 1900 年，埃及人就使用了诸如隐写术 (steganography) ([2001](#Chapter12.html#c12_bib67)) 等技术。目前有各种可用于加密和解密的算法，可以安全地传输数据。美国标准局提出了 DES 算法，该算法使用了 20 年。随后出现了 AES 算法，现在非常流行，但有报告称 AES 已被成功破解 ([Mangard *et al*., 2005](#Chapter12.html#c12_bib47))。据估计，由于 IC 仿冒，美国半导体业损失了 75 亿美元 ([Rose *et al*., 2013](#Chapter12.html#c12_bib59))。除此之外，在许多设备、传感器或应用程序的情况下，设备本身不会一直受到监控。它将位于远程位置，向云或远程服务器传输和接收必要的数据。在这种情况下，当前的加密和解密做法是将必要的密钥存储在非易失性内存中并在需要时使用 ([Herder *et al*., 2014](#Chapter12.html#c12_bib21))。该内存容易受到侧信道攻击，攻击者可以访问物理设备并从中检索数据。
