

有多种可用的解决方案来感知攻击并防御攻击。在典型的嵌入式系统中，系统各处都部署了各种传感器。这些不同的传感器用于检测系统的各种参数。当系统受到攻击者攻击时，系统的各种参数会发生变化，例如电流波动、功耗增加和热变化。可以借助传感器持续监控这些参数，并检测其中的任何异常变化。仅当传感器感知到的值异常时，才会执行内存完整性验证。在传统的嵌入式系统中，完整性验证会针对内存的所有块执行，这会增加整个模块的功耗，以保持内存的数据完整性。

任何内存完整性验证方法的定义可以结构化如下。最初，内存 `M` 由处理器通信。内存 `M` 有两个属性，即内存内容 `V` 和地址 `A`。`M[R,A]` 表示地址 `A` 处的内存被读取，并将返回与 `A` 关联的数据。`M[W,A,V]` 表示值 `V` 被写入地址 `A`。要返回值 `V`，值 `V` 的写入应紧随地址 `A` 之后。内存的写入和读取具有时间概念。为了将时间关联到读取和写入中，应将其表示为：`M[W,A,V,T]` 和 `M[R,A,T]`。内存位置中存在的值与位置地址之间的关联称为拼接攻击。让我们考虑一个示例，地址 `A` 应返回值 `V[A]`，`A′` 应返回值 ![image](OEBPS/images/c2-Eqn-in-1.gif)，当内存遭受成功的拼接攻击时，`A` 将返回值 ![image](OEBPS/images/c2-Eqn-in-2.gif)。当与地址 `A` 关联的内存位置中存储的值更改为随机值 ![image](OEBPS/images/c2-Eqn-in-3.gif) 时，这称为欺骗攻击。当值与时间之间的关联被混乱时，这称为重放攻击。例如，让我们考虑 `V[A]` 为时间 `T[A]` 时地址位置 `A` 处的值，以及同一位置在时间 `T[B]` 时的值为 ![image](OEBPS/images/c2-Eqn-in-4.gif) 且 `T[A]` < `T[B]`。当对内存执行成功的重放攻击时，在时间 `T` > `T[B]` 时，将返回的值是 `V[A]`。

在嵌入式系统的受信任环境边界内实现各种传感器以监控处理器的各种参数已有很长时间了（[McGowen *et al.*, 2006](#Chapter2.html#c02_bib53); [Oh *et al.*, 2010](#Chapter2.html#c02_bib66））。已进行研究，利用功耗变化和电流波动来监控对设备执行的攻击。[图 2.23](#Chapter2.html#c02_fig23) 显示了此类系统的实现，当传感器检测到参数的异常值时，该系统可以执行内存完整性验证（[Nimgaonkar *et al.*, 2013](#Chapter2.html#c02_bib63））。

如 [图 2.22](#Chapter2.html#c02_fig22) 所示，硬件中存在的各种传感器表示为传感器模块（SM）。SM 中存在的传感器持续监控内存总线的波动。内存完整性验证机制存在于特殊缓存，即“哈希缓存”中。哈希地址存在于哈希缓存中。内存块的哈希被写入片外内存。哈希和哈希地址用于验证内存的完整性。嵌入式系统中的处理器是受信任芯片。因此，缓存和 SM 存在于处理器边界内。架构中存在一个加密/解密块。

对内存执行的读写操作在 [图 2.22](#Chapter2.html#c02_fig22) 中描述。当数据被写入内存时，处理器计算哈希地址和哈希，并将其存储在哈希缓存中。存储后，内存块被加密并存储。在读取操作期间，读取的内存块被解密。在此解密操作期间，SM 持续监控内存总线是否有任何异常。如果内存总线上的电压波动超过先前设定的阈值，则系统被认为处于受攻击状态，在此场景下，哈希地址将重新计算。它与缓存中先前存储的哈希地址进行验证。如果命中，则使用存储的哈希检查和验证数据本身的哈希。如果这两者不匹配，则系统处于受攻击状态且数据损坏。处理器执行的所有操作均被中止。一旦内存总线上的电压波动降至阈值以下，进程停止，威胁被认为已停止或缓解。

### 2.4 射频识别（RFID）安全

射频识别（RFID）是一项古老的技术，已被用于各种应用。可以说，在某种程度上它是 IoT 的起点。跟踪、安全和定位是 RFID 的一些应用。在 IoT 中，RFID 以多种方式实现。尽管 RFID 的范围非常小，但它可以在 IoT 环境中用于各种目的。但是，像每种通信协议一样，RFID 也易受许多攻击和威胁。本节讨论 RFID 的各种安全漏洞和威胁以及其中一些的解决方案。

#### 2.4.1 RFID 安全攻击

RFID 存在不同的安全威胁（[Jayakrishnan *et al.*, 2018](#Chapter2.html#c02_bib37); [Li *et al.*, 2012](#Chapter2.html#c02_bib48); [Thompson *et al.*, 2014](#Chapter2.html#c02_bib99））。[图 2.24](#Chapter2.html#c02_fig24) 显示了 RFID 的各种攻击（[Mohanty, 2015](#Chapter2.html#c02_bib56））。攻击分为三类：物理威胁、信道威胁和系统威胁。

![image](OEBPS/images/PBCS0600-02-f24.jpg)

图 2.24 针对 IoT 设备 RFID 模块的攻击

物理威胁是针对物理 RFID 设备、发射器或接收器执行的安全威胁（[Li *et al.*, 2012](#Chapter2.html#c02_bib48））。由于设备成本低，RFID 标签不是防篡改的，容易被利用。存在很大的逆向工程 RFID 标签并克隆它们的可能性。这使攻击者能够获取标签中存储的数据。每个 RFID 标签都有一个唯一的识别号，当攻击者手持设备时，复制标签并非难事。RFID 标签可以轻易被电磁波干扰，这可以暂时禁用它们，使其易受攻击。要干扰 RFID 标签，电磁辐射应与 RFID 系统的频率相同。
