### 2.3 Memory security

Memory is the integral part of every system. Different types of memory, primary, and secondary memories are available and are present in almost every IoT device. Non-volatile, static random access memory (`SRAM`), etc., are employed to improve the performance and increase the storage capabilities of the IoT devices where they will have the capabilities to store the data collected and send to the cloud at a later time. There is no IoT device without memory. But different types of memories are subject to different types of attacks. It is a highly vulnerable part of an IoT device. This section describes various kinds of attacks and solutions that are available in the market.

#### 2.3.1 Memory security attacks

Various attacks are possible on the memory modules of the embedded systems. [Figure 2.21](#Chapter2.html#c02_fig21) shows various attacks that are possible on the memory of an embedded system ([Nimgaonkar *et al.*, 2013](#Chapter2.html#c02_bib63)). The attacks can be broadly classified as passive and active attacks. The passive attacks may include snooping and cold boot attacks. Snooping attacks happens when an adversary is able to read and interpret confidential information in memory. The cold boot attacks, which is also a type of side channel attack, a hacker who has physical access to a computer retrieves encryption keys from a running OS after using a cold reboot to restart the computer. The attack relies on the data remanence property of random access memory (cache, `SRAM`, or dynamic random access memory (`DRAM`)) to retrieve memory contents that remain readable in seconds to minutes after the power supply has been removed. This happens as the memory chips used in the computers retain their contents for seconds to minutes after power is lost even if these are volatile, leaving the contents available for malicious or forensic acquisition. Active attacks include spoofing, splicing, replay, and denial of service. In the active attacks, an adversary is able to change the contents of memory so it would not perform the intended functions. In spoofing attack, an adversary exchanges a block of memory with an arbitrary fake block. The block of memory at one location is replaced with another block from a different location in splicing attack. In replay attacks, an adversary stores the value of a block of memory at a given address at one time, and writes that value at exactly the same address at a different time. Replay attack is the hardest attack as it is difficult to trace and protect. The denial of service attack memory refers to a scenario, when a malicious process takes most of the memory bandwidth, leaving other processes without the required resources and thus effectively slowing them down.
