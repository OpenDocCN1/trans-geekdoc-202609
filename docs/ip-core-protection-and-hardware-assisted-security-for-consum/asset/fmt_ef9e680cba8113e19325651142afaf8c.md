
# Chapter 3

**Chapter 3** presents the details on hardware Trojan security aware DSP IP core/IC. The chapter includes introduction to the concepts, followed by features of the Trojan-secured methodology—that includes threat model, description of features, and advantages of performing Trojan security at higher abstraction level. The next sections of this chapter comprises an example of hardware Trojan inside `3PIP` module, discussion on selected Trojan security approaches, goal/models/problem formulation of a Trojan security aware DSP IP core, and the detailed description of its design process. Subsequently, the implementation and results are presented, followed by conclusion and questions and exercise for the learners and practitioners.

# Chapter 4

**Chapter 4** presents the details on how to protect a DSP IP core/IC using robust watermarking. The chapter includes introduction to watermarking, description of selected watermarking approaches, design process of watermarked IP core/hardware—including threat model, explanation on single-phase and multi-phase watermarks, followed by discussion on desirable properties of a watermark and threat scenarios. Subsequently, details on implementation and results are provided—that includes security analysis and design cost/overhead analysis. The chapter end with a conclusion of the concepts learnt and some exercise for the learners/practitioners.

# Chapter 5

**Chapter 5** presents the details on symmetrical protection of DSP IP core/IC using fingerprinting and watermarking. The chapter includes introduction to the problem and concepts on symmetrical protection, description of background on fingerprinting and watermarking, followed by threat models and benefits of providing symmetrical protection at higher design abstraction level. The next sub-sections focus on the fundamentals of IP core protection, process of implanting symmetrical IP core protection, and finally finishing with a motivation example of this approach. Subsequently, implementation and results are presented, followed by conclusion and exercise questions for learners and practitioners.

# Chapter 6

**Chapter 6** presents the forensic engineering for resolving IP core ownership problem. The chapter includes introduction to the concept, followed by the description of the customized CFE approach for IP core protection. The next sub-sections focus on IP core feature extraction algorithms, followed by implementation and results. Finally, the chapter concludes with an inference, followed by exercise questions for learners and practitioners.

# Chapter 7

**Chapter 7** presents the structural obfuscation of DSP IP cores used in CE devices. The chapter includes the introduction to the concept, followed by the description of its threat model and benefits of obfuscation at higher abstraction layer. The next sub-sections focus on the fundamentals of obfuscation for IP core protection, process of structural obfuscation, and generation of low-cost obfuscated IP core design. Subsequently, a motivational example is presented, followed by the details of implementation and results. The chapter ends with a conclusion and exercise questions for learners and practitioners.

# Chapter 8

**Chapter 8** presents the description of functional obfuscation of DSP cores used in CE devices. The chapter encompasses the following—introduction to the concepts, discussion on selected functional obfuscation approaches, followed by the explanation of the design process of the functionally obfuscated DSP core and security view point—analysis and attack scenarios—of the functionally obfuscated DSP core. The next sections of this chapter presents optimization engine for deriving the low-cost/optimal functionally obfuscated DSP core architecture, implementation and results, and finally ending with the conclusion and questions and exercise for learners and practitioners.

# Chapter 9

**Chapter 9** presents the details on a real-world complex application—obfuscation of JPEG CODEC IP core for CE devices. The chapter includes introduction to the concepts, overview of JPEG compression/decompression process, followed by design process of an obfuscated JPEG IP core design—including threat models and detailed design steps. The next sub-sections focus on the implementation of the design, presentation of the results and conclusion. Finally, the chapter ends with exercise questions for learners and practitioners.

# Chapter 10

**Chapter 10** presents the details on AES and its hardware watermarking for ownership protection. The chapter starts with the introduction to the concepts, followed by the description of AES algorithm—encompassing overview of AES, custom hardware design, and its digital watermarking. Next, results are presented for watermarked AES hardware, followed by conclusion and exercise questions for learners and practitioners.

# Chapter 11

**Chapter 11** presents the details on the protection and authentication of media content with emphasis on the hardware vs. media protection, digital rights management (DRM), copyright protection of multimedia as well as general framework of multimedia watermarking, its applications, challenges, attacks, and countermeasures.

# Chapter 12

**Chapter 12** presents the details on the PUF with an emphasis on its properties, classification, and discussion on different types of PUF based on security, structure, and fabrication. It also presents the details on the implementations of PUF, challenges, and other issues on PUF.

## 1.8 Conclusions

This chapter introduced ‘hardware-assisted security and IP core protection’ in the context of CE systems. Various types of security threats are briefly summarized from an overall system point of view. It also presented an overview of different IP core protection and hardware-assisted security techniques, with its pros and cons. Through the help of a real-life CE design, the significance of DSP core was explained along with the different hardware threats possible on DSP IP cores. The chapter also summarized the roadmap of this book—including the expected contents of each chapter from a reader’s perspective.
