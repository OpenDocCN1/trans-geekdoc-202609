DSP IP 核对逆向工程（RE）的弹性可以在设计流程的任何抽象层级提供。然而，在架构综合过程中通过结构混淆来提供对 RE 攻击的弹性是有益的，因为在更高设计抽象层级进行的结构变更会混淆应用程序的数据通路和控制单元结构。因此，它也会混淆应用程序的门电路结构（网表）。此外，数字 IP 的架构综合已非常成熟，能够以更低的设计复杂度实现硬件面积最小化、功耗优化、性能增强和容错 IP 设计方案。因此，架构综合过程中的结构混淆能够生成一种高度混淆的设计，该设计在功能上等效但与原始结构显著不同。使用此类混淆设计的唯一方式是将其作为“黑盒”模块（[Chakraborty and Bhunia, 2009](#Chapter7.html#c07_bib7)）。

## 7.2 IP 核保护的混淆——广义视图

本节讨论了基于混淆的不同 IP 核保护机制的基础，重点介绍了文献中可用的基于高级变换的结构混淆机制。

基于混淆的 IP 保护可以通过三种不同方式实现：（1）通过变换 HDL 代码，称为“源代码混淆”；（2）通过使用基于密钥的逻辑锁定，称为“逻辑混淆”；（3）通过隐藏设计的功能，称为“结构混淆”。

### 7.2.1 代码混淆技术

为了阻止攻击者拦截 HDL 代码，要么将源代码变换为复合版本（[Brzozowski and Yarmolik, 2007](#Chapter7.html#c07_bib4)），要么对其进行加密（[Barria *et al.*, 2016](#Chapter7.html#c07_bib2)）。在 Brzozowski and Yarmolik ([2007](#Chapter7.html#c07_bib4)) 中，HDL 代码混淆是通过多种变换方法实现的，这些方法难以逆向工程。在 Barria *et al.* ([2016](#Chapter7.html#c07_bib2)) 中，源代码使用“死代码添加”方法在 Crypter 上进行加密。

### 7.2.2 逻辑混淆技术

逻辑混淆（也称为逻辑加密）通过在设计中植入补充组件来锁定设计的实现。这些组件由密钥门控制。应用错误密钥将产生与设计正确输出在功能上不同的输出。逻辑混淆分为两种类型：（1）时序型和（2）组合型（[Rajendran *et al.*, 2013](#Chapter7.html#c07_bib22)）。在时序逻辑混淆中，补充组件可能存在于密钥控制的混淆模式中。例如，在 Chakraborty and Bhunia ([2009](#Chapter7.html#c07_bib7)) 中，虚拟状态被添加到设计的有限状态机（FSM）的原始状态中以对其进行混淆。这些虚拟状态由外部密钥控制。应用错误密钥会导致混淆模式或无效状态，而应用正确密钥会导致正常模式。在 Desai *et al.* ([2013](#Chapter7.html#c07_bib8)) 中，设计基于内部生成的密钥序列（称为代码字）进行锁定。该技术在转移函数中使用此代码字来隐藏设计。应用错误密钥时，FSM 将偏离正确的转移路径。

在组合逻辑混淆中，补充组件可以是 XOR/XNOR 门（[Roy *et al.*, 2008](#Chapter7.html#c07_bib25); [Rajendran *et al.*, 2012](#Chapter7.html#c07_bib21); [Rajendran *et al.*, 2015](#Chapter7.html#c07_bib23)）、AND/OR 门（[Dupuis *et al.*, 2014](#Chapter7.html#c07_bib9））、查找表（LUT）（[Baumgarten *et al.*, 2010](#Chapter7.html#c07_bib3)）、多路复用器（[Wang *et al.*, 2016](#Chapter7.html#c07_bib46); [Zhang, 2016](#Chapter7.html#c07_bib49)）或这些元素的组合（[Lee and Touba, 2015](#Chapter7.html#c07_bib15)）。EPIC（[Roy *et al.*, 2008](#Chapter7.html#c07_bib25））是提出逻辑混淆框架的主要工作之一。在此方法中，XOR/XNOR 门被插入为设计随机位置的密钥门。将密钥门随机插入设计并不总能保证在应用错误密钥时对所有输入模式都产生错误输出。此外，在此方法中，密钥可以通过输入模式被敏感化。Rajendran *et al.* ([2015](#Chapter7.html#c07_bib23)) 以一种方式将 XOR/XNOR 密钥门插入设计，使得错误输出和正确输出之间的汉明距离（HD）最大化。在 Lee and Touba ([2015](#Chapter7.html#c07_bib15)) 中，XOR/XNOR 密钥门与多路复用器密钥门相结合，以实现正确输出和错误输出之间更高的 HD。Baumgarten *et al.* ([2010](#Chapter7.html#c07_bib3)) 提出了基于密钥控制的 LUT 逻辑混淆。在此方法中，完整的 IP 被划分为多个固定部分和可配置部分。可配置部分随后被实现为密钥控制的 LUT。由于可重构部分的逻辑类型可以在制造后更改，恶意晶圆厂无法滥用该 IP。针对这些逻辑混淆技术，存在多种攻击策略，例如密钥敏感化（[Rajendran *et al.*, 2015](#Chapter7.html#c07_bib23)）、布尔可满足性（SAT）和爬山搜索攻击（[Subramanyan *et al.*, 2015](#Chapter7.html#c07_bib38)）。这些逻辑混淆技术已被证明对组合/时序电路非常有效。然而，在 DSP 核的背景下，这些技术会因额外密钥门被植入设计而产生更多设计开销，且缺乏选择低成本设计架构的框架。此外，如果密钥以某种方式泄露，IP 设计者在 IP 重新设计为新密钥之前无法防止任何攻击。关于此技术的更多细节在第 8 章中介绍。
