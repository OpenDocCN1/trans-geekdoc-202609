增加指纹强度对设计延迟、硬件面积和植入成本的影响如 [表 5.9](#Chapter5.html#c05_tbl9) 所示。选择了三种不同的指纹大小，即 10、20 和 30，以观察各种设计度量上的对比结果。可以从 [表 5.9](#Chapter5.html#c05_tbl9) 观察到，对于大多数基准，随着指纹大小的增加，设计面积的增量为零。原因是，在三种不同的指纹编码变量中，只有 `C` 变量在寄存器分配阶段嵌入指纹约束，这可能会导致面积开销。因此，随着指纹大小的增加，导致设计面积开销的可能性非常小。另一方面，可以从 [表 5.9](#Chapter5.html#c05_tbl9) 观察到，随着指纹大小的增加，设计延迟的增量很小。原因是在调度阶段解决操作冲突时添加指纹约束。然而，对于设计面积和设计延迟，增量都很小。因此，可以观察到某些基准在指纹大小增加时，成本的增量微乎其微。

### 5.5.2 对称与非对称技术的比较研究

通过 Roy *et al.* ([2008](#Chapter5.html#c05_bib10)) 制作的 DSP IP 设计与基准 IP 核设计进行比较，其中基准设计表示未受保护的设计（即没有指纹和水印的设计），在设计延迟、设计面积和植入成本方面进行对比。如 [表 5.11](#Chapter5.html#c05_tbl11) 所示，与原始基准相比，对称 IP 保护可以实现最小延迟开销（平均 1.87%）、最小面积开销（平均 0.24%）以及非常小的设计成本开销（小于 1%）。
