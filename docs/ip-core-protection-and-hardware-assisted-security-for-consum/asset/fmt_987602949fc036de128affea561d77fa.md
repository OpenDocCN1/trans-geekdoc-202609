
# Limitations of Watermarking Schemes

Limitations of the watermarking schemes are discussed in this section. When a watermark is inserted into the original media object, it should be detected with ease if not tampered with. Even in the case of attacks, the watermark should be resistant. In this chapter, we discussed a lot about different kinds of watermarks and the characteristics. With the hardware watermarking coming into picture, the IoT integration is becoming easy. Different hardware modules that were discussed above can be integrated into IoT applications. But IoT devices need to be connected to the Internet all the time and some of them will be battery operated. So, the latency and the power consumption of the watermarking modules is a great challenge.

When it comes to the visible watermarking schemes, the copyright is clearly mentioned and need not be worried ([Mintzer et al., 1996](#Chapter11.html#c11_bib63); Mohanty et al., [2000a](#Chapter11.html#c11_bib73)). The watermark should occupy a significant portion of the original media object. Besides that the quality of the image should not be degraded. When removing the watermark it costs same as a new media object. This kind of security is sufficient for use in different applications. This also has some drawbacks where the watermark should be enforced with laws.

Invisible watermarking, unlike the visible watermarking techniques, is imperceptible and is more complicated for that reason. Robustness of the watermark is considered the highest characteristic that a watermarking algorithm has to meet. But this is not true in case of an invisible watermarking. Because, every watermark can be attacked using various techniques and invisible watermark is also not left out from that category. Any media can be subject to counterfeit production by attacking the watermark. So, invertible or quasi-invertible invisible watermark schemes are not able to resolve the rightful ownership. Without a standardized watermarking scheme, anyone can claim ownership.

Due to the advancements in the technology scaling and development of high-performance devices, signal manipulations are being introduced into various artworks and the indistinguishable noises are added to the media object. This makes it difficult to differentiate the manipulations and prove original ownership of the object. The additional data in the object is not known to occur due to the watermark or any new noise. In such scenarios, extracting watermark and authenticating the ownership of the object is a challenge. With the use of highly sophisticated DSP, this problem is further deteriorating. A watermarked image that is not protected properly cannot be used for authentication and hence cannot be used in a court of law. To avoid this situation, watermark can be embedded into the object during the acquisition phase directly using hardware modules.

Digital watermarking will not be able to prevent illegal activity but can only provide evidence that such an activity has been performed by a party. ## 11.13 Conclusion

This chapter discusses the watermarking schemes, some issues with watermarking and its limitations, and attacks and solutions on different watermarking algorithms. A big picture of watermarking from basics to deployment is presented in this chapter. Different hardware watermarking schemes along with some very-low-power chips which can be integrated into battery operated devices were discussed. With the introduction of a new watermarking scheme or a new cryptographic algorithms, the attackers are soon coming up with ways to attack them and breach the security. There are many counterfeit devices being produced and media content being shared without proper legalities being met. This has become a major issue that has to be addressed designing of high sophisticated and low-power security modules in both cryptography and watermarking.
