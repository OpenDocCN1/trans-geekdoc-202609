

## 多对安全性

如果攻击者无法在不控制或不知晓其余所有密钥位值的情况下，将任何一个密钥位敏感化到输出数据位，则锁定网表中的所有密钥位都被视为多对安全 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。在锁定网表中，密钥位对攻击者不可访问，因此，他/她无法向其输入数据。因此，在多对安全的密钥位中，识别一个密钥位的一个密钥值取决于其余所有密钥位的密钥值，因此攻击者无法破解锁定设计的任何密钥值。Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 的不同 ILB 结构示例如 [图 8.5](#Chapter8.html#c08_fig5) 所示。根据 [图 8.5](#Chapter8.html#c08_fig5)，所有 ILB 都有 8 个密钥位，且全部为多对安全。换句话说，要将 ILB 的任何一个密钥位敏感化到输出，攻击者必须知道或控制其他七个密钥位的正确值。因此，要识别其他七个密钥位的正确值，攻击者必须采用暴力攻击。例如，要将 [图 8.5(a)](#Chapter8.html#c08_fig5) 所示 ILB 的密钥位 `K1` 敏感化到输出位，攻击者必须控制其他七个密钥位的值，即“0110000”，这具有挑战性。因此，多对安全性特性增强了 ILB 的密钥敏感化攻击。

## 禁止密钥门隔离

为避免密钥敏感化攻击，锁定网表设计应禁止存在隔离的密钥门。Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 设计的不同 ILB 结构（如 [图 8.5](#Chapter8.html#c08_fig5) 所示）由八个相互依赖的交织密钥门组成。这确保了 ILB 中不存在隔离的密钥门。因此，从锁定网表中禁止隔离的密钥门增强了 ILB 的密钥敏感化攻击。

## 防止密钥门串联

在 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 中，ILB 的密钥门相互交织，因此，将所有密钥门（八个输入密钥门）替换为单个门极其困难。

## 不可变收敛密钥门

如果两个密钥门汇聚到某个其他门，且没有任何密钥位可以被静音，则我们可以将这些密钥门称为不可变收敛密钥门 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。如 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 中所示，所有 ILB 都由八个不可变密钥位组成，因此，要将一个密钥位敏感化到输出，其余七个密钥位需要被静音，这是一个复杂的过程。因此，在锁定网表中放置不可变密钥门增强了 ILB 的密钥敏感化攻击。

### 8.5.2 安全性分析

在锁定网表的安全性分析中，假设攻击者可以访问以下三项内容：

* (i) 一个 FO 网表
* (ii) 激活的功能电路（从市场上购买）
* (iii) 先进的 RE 设施

在此场景中，通过 RE，攻击者可以确定输入密钥位的总数，然后在密钥空间中搜索以识别密钥值的组合。例如，如 [图 8.6](#Chapter8.html#c08_fig6) 所示，攻击者可以确定设计包含 64 个输入密钥位。他/她可以执行暴力攻击以识别 64 个密钥值的正确组合，这需要测试总共 2^(64) 个不同的组合。在暴力攻击期间，如果假设每秒可以向锁定网表应用 10 亿 (10⁹) 个密钥，则大约需要 585 年才能识别正确的密钥值。
