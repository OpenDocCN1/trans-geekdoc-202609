

## 2.5 NFC 安全攻击与解决方案

[Figure 2.29](#Chapter2.html#c02_fig29) 显示了 NFC 模块的中继攻击。如上文所述，这些攻击允许数据在较长距离上传输。攻击包含多个部分，即，诚实证明方、诚实验证方、不诚实证明方和不诚实验证方。在该场景中，受害者的卡片和攻击者的销售点终端分别是诚实证明方和验证方。不诚实的证明方和验证方是受害者和攻击者的 NFC 功能手机。

![image](OEBPS/images/PBCS0600-02-f29.jpg)

Figure 2.29 IoT 设备 NFC 模块的中继攻击

攻击者在中继攻击中利用了 NFC 的 ISO/IEC14443 协议。首先，攻击者会将读卡器的请求转发给受害者，并将受害者的响应实时发送回读卡器。在攻击场景中，攻击者应靠近受害者的卡片，并通过另一个通信通道将数据中继到第二个 NFC 读卡器。这个辅助 NFC 读卡器必须位于原始读卡器的附近。例如，在无现金支付的情况下，攻击者可以让同伙隐蔽地持有一个中继设备，使其处于他人支付卡片的范围内（即，将其靠近对方的钱包）。完成此操作后，攻击者可以使用其中继设备以受害者卡片购买商品。这种攻击的缺点是传输数据所需的时间。由于数据需要传输的距离增加，传输数据所需的时间也会增加。

在数据修改攻击中，双方交换的数据被攻击者捕获并修改。攻击者使用的设备会短暂阻止通过 NFC 通道交换的数据。干扰 NFC 通道数据交换的另一种方法是使用 RFID 干扰器。通过监控正在传输的信号强度，可以轻松检测数据修改。

[Figure 2.30](#Chapter2.html#c02_fig30) 显示了 NFC 应用程序的窃听攻击。在这种情况下，攻击者使用天线监控双方之间的流量。两个设备之间的短距离并不能降低此类攻击的可能性。在某些攻击案例中，正在交换的数据会被损坏，从而变得无用。使用安全通道进行传输，可以提高数据完整性。

![image](OEBPS/images/PBCS0600-02-f30.jpg)

Figure 2.30 IoT 设备 NFC 模块的窃听攻击

在欺骗攻击中，攻击者假装是另一个实体，并将设备轻触标签。如果标签被攻破并允许运行恶意代码，则有可能实现这一点。尽管发送方和接收方之间的距离非常小，但在某些情况下，NFC 中也有可能发生中间人攻击。攻击者可以使用天线拦截信息，并在将其发送到原始接收方之前对其进行操纵。

### 2.5.2 NFC 安全解决方案

[Figure 2.31(a)](#Chapter2.html#c02_fig31) 显示了 Swing-Pay 的架构，Swing-Pay 是一种数字卡模块，它结合生物识别身份验证和 NFC 进行点对点支付（[Ghosh *et al.*, 2017](#Chapter2.html#c02_bib25)）。图中显示了 Swing-Pay 系统的各个组件。为了原型设计，模块使用了 Arduino Due 板（[Ghosh *et al.*, 2017](#Chapter2.html#c02_bib25)）。Swing-Pay 的原型使用现成的组件进行了展示（[Ghosh *et al.*, 2017](#Chapter2.html#c02_bib25)）。

![image](OEBPS/images/PBCS0600-02-f31.jpg)

Figure 2.31 物联网的各个方面

在设计中，使用了 E-Ink 显示屏来降低模块的功耗。这些显示屏是双稳态的，仅在需要改变状态时才消耗电力。在设计中实现了 Adafruit Fona 全球移动通信系统（GSM）调制解调器，用于通信，具有小尺寸和多种功能。为了交互，设计中实现了电容式触摸传感器。使用了锂离子电池作为电源。

在 Swing-Pay 框架中，首先激活付款人的指纹。一旦指纹通过身份验证，卡片将被激活。一旦付款人选择支付金额，收款人将在相应模块中选择接收资金。收款人使用指纹传感器进行身份验证，并将其卡片与付款人的卡片轻触。身份验证成功后，收款人的 ID 将使用 NFC P2P 模式传输到付款人模块。如果身份验证失败，交易将被阻止。身份验证成功后，将通过 GSM 模块发送一条消息。在此原型中，使用了 Android 应用程序，数据通过 HTTP 放入 Web 服务。

一旦云服务器接收到数据，它将继续处理交易。付款人和收款人的银行详细信息存储在云服务器中。详细信息通过 API 发送到相应的银行服务器。付款人的银行将资金转账到收款人账户。

Crypta 标签架构如 [Figure 2.32](#Chapter2.html#c02_fig32) 所示（[Plos *et al.*, 2013](#Chapter2.html#c02_bib71)）。标签的主要组件之一是模拟前端。它连接到天线，负责各种任务，包括提取电源、数据调制和解调以及提供稳定的复位和时钟信号。数字部分连接到模拟前端。标签数字部分处理接收到的解调数据。对接收到的数据执行请求的操作，并准备响应。标签的数字部分由一个 8 位微控制器、加密单元（CU）、帧逻辑（FL）和存储器单元组成。内部存储器存储微控制器程序，AMBA 总线用于 FL 和存储器单元之间的通信。CU 对数据执行各种加密操作。FL 为微控制器提供接口，并处理一些低级命令。

## 2.6 智能交通安全

本节讨论智能交通的安全威胁和解决方案。此处讨论的车辆类别包括智能汽车和无人机。正在进行研究，旨在设计智能车辆以减少人类在道路或空中驾驶车辆时的交互。这意味着系统将执行所有驾驶操作，对电路的依赖性呈指数级增长。它们还连接到互联网以进行持续更新，并与服务器通信。这使它们容易受到多种攻击的威胁（[Storm, 2015](#Chapter2.html#c02_bib95); [Wu and Horng, 2017](#Chapter2.html#c02_bib106); [Xiao *et al.*, 2009](#Chapter2.html#c02_bib109)）。如果智能汽车或无人机被攻击者攻击并控制，后果可能是灾难性的。
