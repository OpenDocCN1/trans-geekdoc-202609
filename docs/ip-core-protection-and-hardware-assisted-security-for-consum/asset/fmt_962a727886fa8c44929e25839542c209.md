
To obtain a low-cost hardware for JPEG IP core, PSO-driven DSE framework is used. This particle-based heuristic approach iteratively searches for a new global optima based on local minima and current global optima. Detailed explanation of the PSO-DSE process and formulation models is provided in Chapter 3 and in Sengupta *et al.* ([2017a](#Chapter9.html#c09_bib29)). Benefits of the PSO-DSE process are as follows:

*   (i) Capable of obtaining global optima while bypassing local minima
*   (ii) Capable of incorporating stochasticity during exploration process
*   (iii) Capable of preserving a proper balance between exploitation and exploration throughout the iterations

#### 9.3.3 Generating structurally obfuscated JPEG compression IP core

Structural obfuscation hinders the RE process by transforming the standard architecture of JPEG hardware to an unobvious design. Therefore, identifying the original functionality of the structurally obfuscated design is harder for an attacker. THT-based structural obfuscation is applied to the standard structure of JPEG DFG ([Sengupta *et al.*, 2017b](#Chapter9.html#c09_bib30)). It is a compiler-driven optimization technique which parallelizes the dependent critical path operations by dividing it into temporary sub-computations. However, this technique has not been used to generate a structurally obfuscated DFG for JPEG. The standard structure of JPEG DFG shown in [Figure 9.7](#Chapter9.html#c09_fig7) is structurally obfuscated through THT. The transformed structure of JPEG DFG is shown in [Figure 9.8](#Chapter9.html#c09_fig8). The zoom-in representation of obfuscated micro-IP8 is also shown in the figure. Due to this transformation, each micro-IP, as well as macro-IP, is modified. For example, in micro-IP8, 12 nodes among 16 nodes are affected. They are node no. 115, 116, 117, 118, 119, 120, 122, 123, 124, 125, 126, and 127. Therefore, in the eight micro-IPs, 96 nodes are affected. Additionally in the macro IP, six nodes are affected which include 130, 131, 132, 133, 134, and 135. A node is considered affected if its parents or child is changed or the operation type of that node is changed compared to the original one. These changes produce a different structure of datapath, interconnectivity logic, multiplexers/demultiplexers, and controller logic, once processed through high-level synthesis.

This IP core accepts leveled-off pixel intensity, 2D-DCT coefficient, and quantization matrix as inputs and produces transformed compressed pixel intensity as output.
