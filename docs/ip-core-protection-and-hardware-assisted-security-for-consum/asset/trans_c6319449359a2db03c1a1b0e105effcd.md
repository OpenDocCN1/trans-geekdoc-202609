

# 基于单向随机函数（ORF）电路的针对 SAT 攻击的对策

基于单向随机函数（ORF）电路的针对 SAT 攻击的对策如 [图 8.3(b)](#Chapter8.html#c08_fig3) ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44)) 所示。在此方法中，公共 AES 被用作 ORF 来防御 SAT 攻击，而不是使用 PUF，因为 PUF 存在以下缺点：(1) 由于其电路较小，无法添加大量子句；以及 (2) 易受建模攻击 ([Pappu *et al.*, 2002](#Chapter8.html#c08_bib22))。针对 AES 的移除攻击通过将公共 AES 与锁定网表一起综合来处理，从而改变公共 AES 的完整结构。因此，攻击者难以从锁定设计中单独识别 AES 块。

Lee 和 Touba ([2015](#Chapter8.html#c08_bib18)) 提出了关键组件，作为 XOR/XNOR 门和多路复用器的组合，以增强错误输出和正确输出之间的 HD。Baumgarten *et al.* ([2010](#Chapter8.html#c08_bib2)) 使用 LUT 作为关键组件来实现锁定设计。在此功能混淆方法中，完整设计被细分为多个固定部分和可重配置部分，然后 LUT 仅用于实现可重配置部分。制造完成后，一旦设计从晶圆厂返回，这些受密钥控制的 LUT 将被更改为不同的逻辑。因此，可以防止不可信晶圆厂滥用设计。

功能混淆易受多种攻击，例如关键组件移除攻击、关键敏感化攻击 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))、布尔 SAT 攻击和基于爬山搜索的攻击 ([Subramanyan *et al.*, 2015](#Chapter8.html#c08_bib37))、基于近似去混淆算法的 SAT 攻击 ([Kaveh *et al.*, 2017](#Chapter8.html#c08_bib15)) 等。此外，向设计中插入额外的关键组件会导致功耗和面积开销，从而导致更高的设计成本。

## 8.4 功能混淆 DSP 核心的设计

如前所述，Sengupta *et al.* 的方法 ([2018](#Chapter8.html#c08_bib35)) 是唯一一种通过功能混淆完全保护 DSP IP 核心的方法。为了实现 FO 设计，该方法在 DSP 核心的网表设计中插入不同的 ILB 作为关键组件。此外，为了探索最佳设计架构，PSO 驱动的 DSE 与功能混淆方法相结合。在本节中，我们讨论 DSP 核心的公式化和低成本功能混淆方法 ([Sengupta *et al.*, 2018](#Chapter8.html#c08_bib35))。

### 8.4.1 公式化

为 DSP 应用程序（以 C 代码或 CDFG 形式给出）生成低成本、低功耗 FO 网表，该网表接受模块库和 PSO 控制参数作为输入。

### 8.4.2 DSP 核心的低成本混淆方法

DSP 核心低成本功能混淆的设计过程包含两个主要阶段，即：(1) 设计功能锁定的 DSP 核心，以及 (2) 通过 PSO-DSE 过程探索低成本设计配置。这两个阶段都会迭代执行，直到探索到全局最优设计配置。[图 8.4](#Chapter8.html#c08_fig4) 显示了两个主要阶段、它们对应的步骤以及执行低成本功能混淆所需的主要输入。如 [图 8.4](#Chapter8.html#c08_fig4) 所示，主要输入包括以 C 代码/CDFG 形式的 DSP 应用程序、ILB 设计（基于每个 8 位密钥值）、模块库以及 PSO 控制参数（如加速系数、惯性权重、群体大小、终止标准）。在 HLS 的 PSO-DSE 过程中（详细的 PSO-DSE 框架在 8.6 节中解释），每次迭代都会探索一个设计配置和 ILB 结构，作为群体中的一个粒子。基于此设计配置，会生成输入 CDFG 应用程序的门级数据路径结构（经过标准 HLS 框架的后处理），然后使用 ILB 对其进行锁定（某些 ILB 的结构由 AES 块的加密输出决定，其余则不加密。更多细节请参见 VC）。这生成了输入 DSP 核心的 FO 设计。然后计算锁定设计的总功耗和延迟，以通过适应度函数评估设计成本。随后，更新粒子位置以探索一个更优的粒子，并重复整个过程，直到满足终止条件。因此，在满足终止条件后，最终粒子位置用于生成 DSP 核心的低成本混淆设计。因此，最终设计架构不仅优化了总功耗、延迟和实现成本，还最小化了完整锁定网表的总门数，其中包括功能单元、寄存器/锁存器、多路复用器/解复用器和 ILB 的总数。

缺乏用于生成 DSP IP 核心锁定网表的优化框架会导致巨大的设计开销。这是因为 DSP 核心通常尺寸较大，并且可以使用多种替代硬件设计方案进行设计。对设计方案的任何随机选择都会导致更高的设计开销。在此方法中 ([Sengupta *et al.*, 2018](#Chapter8.html#c08_bib35))，粒子同时编码了硬件资源配置和 ILB 块插入过程，以获得最优的锁定设计。因此，通过 PSO-DSE 过程，在锁定网表的门数、功耗和执行延迟方面实现了最优的混淆设计方案。在接下来的三个小节中，我们将分别讨论 ILB 的概述、其安全特性以及插入技术。

1.  *概述：IP 核心锁定块：* 本小节简要介绍 IP 核心锁定块。ILB 是插入非混淆设计以生成 FO 设计的关键组件。每个 ILB 包含插入到输出数据每个位中的 8 位密钥值。ILB 使用 AND、NAND、NOT、XOR 和 XNOR 门的不同组合进行设计。但是，ILB 的结构取决于密钥值。具有相同面积的 ILB 可能有无数种不同的结构。如果提供正确的密钥值，这些 ILB 中的每一个都会生成正确的输出。在 Sengupta *et al.* ([2018](#Chapter8.html#c08_bib35)) 中，一部分密钥位被输入到 AES 块，并根据加密输出配置 ILB 结构。但是，其余的密钥位直接输入到 ILB 中。这是因为这有助于防止 DSP 核心的 SAT 攻击（目前尚不可能实现，但作为未来的主动对策）。ILB 使用 AND、NAND、NOT、XOR 和 XNOR 门的各种组合进行设计，并具有多种特性（将在下一小节中解释）来处理不同的攻击。

2.  *特性：IP 核心锁定块：* 本小节讨论 ILB 设计的主要安全特性。如前所述，ILB 被插入到 DSP IP 核心门结构的每个输出数据位中，以生成锁定网表。这些 ILB 结构主要设计用于避免关键敏感化攻击和移除攻击。关键敏感化攻击是通过应用不同的输入模式并检查其对应的输出来识别密钥值的过程 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。因此，在设计 ILB 时会考虑多种特性，以避免任何可能的关键敏感化和移除攻击场景。
