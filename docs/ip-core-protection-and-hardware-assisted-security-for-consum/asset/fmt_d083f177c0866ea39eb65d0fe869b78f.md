
# IP core protection and hardware-assisted security for consumer electronics

**IP core protection and hardware-assisted security for consumer electronics** address the general issue of protecting hardware (especially DSP cores) of CE as well as data on CE, including new demands created by IoT enabled products. The book also addresses the potential threats from intervention in the CE design supply chain and how these threats can be circumvented. These supply chain security solutions may include hardware watermarking, hardware fingerprinting, symmetrical IP core protection, hardware metering, computational forensic engineering for IP core protection, and various forms of hardware obfuscation.

The book explores and addresses many different types of security attacks that can be launched against CE products, including power and timing “side channel” attacks, as well as backdoor and brute-force attacks. Methods are discussed for defeating/blocking Trojan horse attacks as well as reverse engineering attacks.

The book discusses the latest methods for active and passive IP core security of DSP cores used in CE device and protection mechanisms for the buyers of ICs and incorporated IP that includes “watermarking” and “fingerprinting” as well as structural obfuscation, functional obfuscation, hardware AES, watermarked AES, and physically unclonable functions (PUFs). The book also explores the use of forensic engineering for resolving ownership issues for reusable digital signal processing (DSP) IP cores. In addition to these direct security concerns, the book discusses the trade-offs of energy consumption, security and performance for CE hardware.

The first of its kind on CE security, this book should be read by designers, programmers, or engineers involved in the design of CE devices as well as for services using these devices.

## Foreword by Pradipta Patra

We are delimited by consumer electronics (CE) in our everyday life. It is hard to envision a smart life without smart devices currently. However, a smart CE device is valuable as long as its security is intact. Security is integral to the successful deployment of a smart CE product. The term “security” encompasses hardware security, hardware assisted security, data security, media security, etc. At the heart of every security protocol is the underlying hardware which is the lifeline of every application. In the current world of cybersecurity, securing and protecting hardware (and intellectual property (IP) cores) as well as securing data/information are paramount.

For the first time authors in this book present an all-inclusive comprehensive book that encompasses security of CE devices from hardware security perspective as well as data/media perspective. The book covers a wide spectrum of modern security topic ranging from fundamentals of IP core protection and hardware-assisted security, Trojan security of DSP cores used in CE hardware, hardware watermarking of DSP /IP cores/IC, symmetrical DSP/IP core protection using watermarking and fingerprinting, computational forensic engineering, structural obfuscation of DSP cores, including a case study on JPEG CODEC, functional obfuscation of DSP cores, hardware AES, watermarking, IoT security, PUF, and media protection.

To the best of my knowledge, there is no book that presents the details of multiple hardware-assisted security topics under one umbrella. The book covers various state-of-the-art security attack details possible on DSP IP core as well as recommends interesting solution to them, which have industry applicability. The attack and solutions described in the book can be deployed for hardware security and IP core protection of DSP cores used in CE devices such as digital camera, camcorder, smart phone, smart watch, etc. The book can be extremely interesting for industry practitioners, researchers (both beginners and advanced level), graduate students/scholars, and any academicians.

The book also provides conceptual questions and exercise for each chapter. This book provides a great opportunity to challenge the understanding for each security topic and refine a reader’s understanding level. The book can also be easily adopted in for any graduate-level course (master’s and Ph.D.) at an institute/university. Additionally, it can also serve as designer’s handbook who is eager to learn designing secured DSP hardware core. The book provides several examples of industry-level practical design procedure on secured DSP cores such as digital filters, JPEG, DCT, and FFT. End-to-end design flow for devising secured DSP IP cores is described in each chapter, in the context of different threat models.

To my knowledge, this is the first book ever on CE device IP core protection and hardware-assisted security. It is a must-read book for a hardware designers, FPGA programmers, or CAD tool designers, as well as researchers and academicians involved in the design of CE devices.

Pradipta Patra, Ph.D.

## Foreword by Swarup Bhunia

Digital signal processing (DSP) and multimedia applications affect every spheres of modern society. These applications work on discrete physical signals (e.g., image, video, speech, and physiological signals), analyze their behavior, and recognize the patterns of significance. Over the years, they have made pervasive and profound impact in the consumer electronics (CE) and other industrial sectors. With unprecedented growth of smart and sensor-enriched Internet of things (IoT) edge devices, which interface with the physical world through sensors and actuators, the role of DSP to analyze signals and extract meaningful information from them has become ever more significant. We observe a growing trend of incorporating autonomy and smartness in IoT devices as well as in complex system of systems (e.g., autonomous vehicles). In this context, we expect to see the increasing role of DSP and its integration with artificial intelligence to make complex reliable decisions without or with little human intervention.

Implementation of DSP and multimedia algorithms has taken various paths, ranging from purely software implementation to implementation in a domain-specific processor, i.e., DSP, a reconfigurable platform (e.g., FPGA), to purely custom hardware implementation (e.g., ASIC), and any combination of these. In all possible implementation platforms, traditionally, designers have aimed at optimizing the power-performance-area to achieve target quality of service (QoS). Security issues associated with these implementations and ways to address them have not been at the forefront of efficient realization of wide variety of DSP and multimedia algorithms. However, security for DSP/multimedia applications has emerged as a key design parameter as variety of security issues involving the hardware itself or the content being processed have surfaced. These issues include tampering and piracy of DSP/multimedia cores, while the protection approaches include fingerprinting, watermarking, and secure hardware design.

The book, for the first time to my knowledge, provides a compendium of chapters covering, rather comprehensively, the security issues and protection approaches in hardware/software implementation of DSP/multimedia functions, and touches on both current practices and recent innovations. The comprehensive coverage of DSP and hardware security concepts with relevant background material and description of current industrial practices are the key distinctive features of this textbook.

Some of the salient features of the book include the following:

*   The book encompasses hardware-assisted security approaches for DSP/multimedia cores with comprehensive coverage for today’s CE devices.

*   It includes emerging attack vectors such as Trojan attacks in DSP/multimedia core.
