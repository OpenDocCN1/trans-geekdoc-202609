

非功能标识符在硬件计量中分为两类：(1) 可复制和 (2) 不可克隆。可复制标识符是存储在芯片封装、芯片或芯片内存中的唯一 ID。它们可以是压印序列号或数字存储序列号的形式。其优点是不依赖随机性且易于追踪/识别。缺点是易于克隆/修改且易于过度生产。另一方面，不可克隆的非功能标识符可以使用外在或内在方法进行计量。例如，内在方法可能使用 IC 漏电、功率、时序、路径签名等，这些都因工艺变化而独特。该方法不需要任何额外逻辑，可以直接用于现有设计。相反，外在不可克隆的非功能标识符使用额外逻辑，例如 `PUF`，它是由振荡器环 (`RO`) 组成的结构，能够因工艺变化生成随机值。`PUF`s 受电源噪声、温度、延迟等影响；因此，值会不断变化。另一类计量方法是基于功能标识符的计量。该方法在综合过程中将标识符与芯片的内部功能细节关联起来。一些属性是：

*   每个芯片的功能都有一个唯一签名；
*   添加的额外状态生成相同输出；
*   从输入到输出功能不变；
*   每个芯片独有的内部事务。

迄今在硬件计量背景下讨论的上述方法都是被动计量方法。存在一种主动计量方法，它使用外部锁定技术锁定 IC。主动计量方法的一些属性是：

*   此技术试图允许 IP 拥有者控制；
*   使用密钥加密锁定芯片的正确功能；
*   在门级，`XOR` 门被放置在选定的非关键路径上；
*   要求每个芯片都用外部密钥激活。只有 IP 拥有者可以生成密钥 ([Alkabani and Koushanfar, 2007](#Chapter1.html#c01_bib2); [Roy *et al.*, 2008](#Chapter1.html#c01_bib18))。

## (iv) IP 核心/硬件指纹识别

当预期的硬件威胁是 IP 卖方/供应商虚假声明所有权，或在 IP 买方不知情的情况下非法重新分发额外副本时，采用此硬件保护机制。威胁模型是不诚实的 IP 卖方在市场上非法重新分发/转售 IP 核心副本 ([Hong and Potkonjak, 1999](#Chapter1.html#c01_bib6))。因此，IP 核心指纹识别保护 IP 买方免受所有权滥用。尽管指纹识别保护免受上述威胁，但它只能检测而不能防止威胁。换句话说，指纹识别方法能够为 IP 核心提供被动形式的保护。有关此保护机制的更多细节在第 5 章中介绍。

## (v) IP 核心/硬件混淆和加密

当预期的硬件威胁是通过逆向工程进行 IP 网表盗窃/假冒/盗版时，采用此硬件保护机制。硬件混淆方法有两种类型：(1) 结构混淆和 (2) 功能混淆。在结构混淆中，目标是增强逆向工程的复杂性，使攻击者更难从其转换后的结构中发现 IP 核心的实际功能。相反，在功能混淆中，目标是通过“密钥”禁用 IP 核心，使得混淆设计的正常功能只能通过在输入端成功应用单个预定义密钥或一系列隐蔽密钥来启用；否则，IP 核心设计将以一种表现出错误功能的模式运行。这两种混淆方法都旨在防止 IP 侵权和木马插入。结构混淆被视为一种“被动”混淆形式，因为它不影响 IP 核心的功能，而只是进行语法更改，即，以软形式修改电路描述，使攻击者难以理解 IP 核心的内部工作原理。被动方法的一个主要缺点是它不改变设计的黑盒功能，因此无法防止 IP 在设计中作为黑盒被潜在使用。但是，由于它不向 IP 核心添加额外的锁定电路，设计开销的可能性低于主动方法，这使其在 CE 行业中同样是一个有吸引力的选择。有关此保护机制的更多细节在第 7 章和第 8 章中介绍。

## (vi) IP 核心的木马安全/检测

在 IP 核心的背景下，硬件木马是 IP 核心内部逻辑的恶意更改，导致其功能改变，使得在罕见事件条件下，IP 核心产生错误输出。此硬件保护机制用于防范在 SoC 集成中使用的 3PIP 核心内部隐藏的硬件木马。由于 IC 设计链的全球化，第三方 IP 核心的参与在更严格的上市时间压力下对 CE 设备的大规模生产起着关键作用。DSP IP 核心的木马安全可以通过在系统级芯片集成期间与优化框架并行运行的双模块冗余技术来实现。这使得能够检测导致功能变化的硬件木马。有关此保护机制的更多细节在第 3 章中介绍。

## (vii) 物理不可克隆函数

`PUF` 是一种“数字指纹”，作为硬件的唯一身份。由于其复杂性以及其输出与所应用输入之间的不可预测性，它充当硬件安全原语。`PUF`s 基于半导体制造过程中自然发生的物理变化，这些变化使得能够区分原本相同的硬件。由于随机工艺变化，即使布局相同的两个 IC 也不相同。`PUF`s 有多种类型，例如：(1) `Latch PUF`s，其中输出因锁存器的内在属性而改变；(2) `SRAM PUF`，其中 `SRAM` 单元的初始上电值是随机的；(3) `Ring of oscillator (RO) delay-based PUF`，其中路径延迟因制造变化而不可预测；以及 (4) `Arbiter PUF`，其中路径延迟因物理随机性而不可预测。在仲裁 `PUF` 中，每个挑战选择一对唯一的延迟门。随机工艺变化决定哪条路径更快 ([Potkonjak and Goudar, 2014](#Chapter1.html#c01_bib17))。有关此保护机制的更多细节在第 12 章中介绍。

## (viii) 基于硬件的加密

另一种用于保护 CE 设备中使用的机密数据的硬件保护机制是基于硬件的加密。基于硬件的加密过程可用于保护数据存储和传输，以及在 CE 设备的背景下保护 DSP IP 核心。高级加密标准 (`AES`) ([Paar and Pelzl, 2009](#Chapter1.html#c01_bib4)) 是最强大的加密过程，可用于机密数据的基于硬件的加密，以及 DSP IP 核心免受外部攻击的保护。有关此保护机制的更多细节在第 10 章中介绍。

## (ix) 专利和版权

专利是特定主权政府授予的授权特权，在提交时保护制造者的 IP，因此只有在所有者批准的情况下才能出售和使用。更明确地说，所有者被赋予宪法特权，以防止他人商业滥用发明。所有者有权根据民法报告任何违规案件 ([Sengupta, 2015](#Chapter1.html#c01_bib20))。
