### 3.6.3 DMR CDFG 的抗木马调度

获取 DMR CDFG 后，下一步是基于资源配置同时调度原始单元和重复单元的所有操作。资源配置由候选设计解 `X`[`i`] 获得。一旦 DMR 的调度完成，下一步是分配从不同供应商导入的 3PIP 核。在此背景下，使用了 Sengupta *et al.* ([2017c](#Chapter3.html#c03_bib28)) 提出的四种不同的供应商分配规则（如前面在第 3.4.1.2 节中讨论）。由于从不同供应商导入的相同功能资源（3PIP 核）具有不同的面积、延迟和功耗，每种供应商分配模式都会影响最终的抗木马设计。因此，为获取低成本的抗木马 DSP 核，必须探索最优硬件资源配置、展开因子和供应商分配模式。在 Sengupta *et al.* ([2017c](#Chapter3.html#c03_bib28)) 中，这是通过 PSO-DSE 方法（将在下一段中解释）实现的。
