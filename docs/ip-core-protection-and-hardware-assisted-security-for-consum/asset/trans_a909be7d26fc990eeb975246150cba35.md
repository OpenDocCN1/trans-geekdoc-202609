# Chapter 11

## 媒体与信息保护和认证的硬件方法

技术缩放使我们能够设计低功耗的高性能设备。物联网（IoT）的出现增加了数据收集的多样性，并且有许多不同的方式通过互联网收集和传输数据。所收集的数据也有不同形式，即文本、图像、视频和音频。当它们被共享用于合法用途时，攻击者可以破坏安全性，并将其用于非法目的或声称所有权以商业出售。最近，许多假冒产品出现在市场上，这已成为一种趋势。本节讨论数字水印、不同的数字水印方案，以及如何使用水印保护媒体对象。它们也并非完全抵御攻击，需要采取措施保护正在被加水印的内容。本章还介绍了水印实现的不同问题、针对水印的攻击以及应对这些攻击的对策。第 11.1 节对知识产权保护进行了广泛概述。第 11.2 节讨论任何水印系统的通用概述和组件。第 11.3 节总结了各种类型的水印。第 11.4 节讨论水印的各种应用。第 11.5 节介绍水印的期望特性。第 11.6 节讨论水印的技术挑战。第 11.7 节讨论当前文献中可用的基于硬件的水印系统。第 11.8 节讨论智能车辆中的水印。第 11.9 节讨论医疗信号认证。第 11.10 节强调侧信道信息泄露及其对策。第 11.11 节概述针对水印和水印系统的各种攻击形式。第 11.12 节介绍在实际中使用它们所涉及的困难。

### 11.1 知识产权保护——广泛概述

随着新技术的出现，新设备正在被引入世界，高性能应用正在被设计。随着每天都有更好的系统推出，也存在一个问题，即它们被用于各种恶意应用，如假冒，这是硬件和媒体领域的一个重大问题。如今，许多人正在制作内容并将其与世界共享 ([Krishnamurthy, 2018](#Chapter11.html#c11_bib47); [Mohanty, 2015](#Chapter11.html#c11_bib67))。但是，他们拥有的内容正在被许多商业用户非法使用，未向所有者支付版税，在某些情况下，内容也被滥用。这引发了许多与知识产权及其保护相关的问题。[图 11.1](#Chapter11.html#c11_fig1) 显示了假冒领域的广泛概述。图像可以由所有者制作并加水印，但攻击者可以攻击、篡改或从图像中移除水印，并声称所有权。这在版权和所有权方面造成了许多问题。

#### 11.1.2 多媒体版权保护——简史

与模拟世界相比，数字媒体有几个优势。更高的质量、易于处理和编辑是其中一些优势。数字媒体最常见的形式是紧凑光盘（CD）、DVD、电视广播和计算机。但是，数字媒体也有许多缺点。数字媒体假冒最近已成为一个非常严重的问题。它可以轻易复制，这引发了对更安全、更有效的 DRM 工具的需求 ([Devillier, 2017](#Chapter11.html#c11_bib25); [Kougianos *et al*., 2009](#Chapter11.html#c11_bib46); [Lah and Lewis, 2016](#Chapter11.html#c11_bib48); [Ma, 2017](#Chapter11.html#c11_bib52); [Ma *et al*., 2016](#Chapter11.html#c11_bib53))。水印是保护数字媒体（如音频、照片和视频）的方法之一。有不同种类的水印，如可见或不可见，可以插入到不同的域中，如空间域或频域。有各种数字水印的软件实现，但硬件实现非常少 ([Liu *et al*., 2017](#Chapter11.html#c11_bib50); [Sarreshtedari *et al*., 2015](#Chapter11.html#c11_bib94); [Zhao *et al*., 2015](#Chapter11.html#c11_bib129))。在设计水印的硬件实现时，需要考虑各种问题，例如低功耗、高性能、易于集成和可靠性。

Emil Hembrooke 于 1954 年发明了电子水印 ([Cox and Miller, 2002](#Chapter11.html#c11_bib19))。从那以后，来自不同领域（如密码学、计算机科学、通信和信号处理）的各种专家进行了大量研究。数字水印被提出以提供与加密和扰码一起的强健保护。社区提出了许多以下问题 ([Cox and Miller, 2002](#Chapter11.html#c11_bib19); [Zhao *et al*., 1999](#Chapter11.html#c11_bib128); [Yeung, 1998](#Chapter11.html#c11_bib124)):

1. 什么是数字水印及其特性？

2. 实现数字水印的过程是什么？

3. 它的缺点是什么？
