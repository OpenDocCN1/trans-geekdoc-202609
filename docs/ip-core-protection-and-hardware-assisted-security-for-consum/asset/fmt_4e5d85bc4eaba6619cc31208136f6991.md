
However, each of these modules as part of IoT or smart city is solely dependent on the security and protection of the underlying hardware system. For example, smart mobile devices in CE, hardware infrastructure in cloud computing, and system framework for reliable and trusted connectivity technology would need built-in hardware security technologies to protect against unauthorized access to personal information, detect/correct malicious hardware, data integrity, etc. There could be several types of cyber attackers depending on the probability of occurrence and potential damage caused, such as (1) amateur attackers whose probability of occurrence is high but potential damage caused is low, (2) petty criminals whose probability of occurrence is not as high but its potential damage could be higher than amateur attackers, and (3) terrorists activists/state-sponsored attackers whose probability of occurrence is low but potential damage caused could be extremely severe. Thus, in the world of CE and IoT, security, privacy, and protection of hardware and its information are critically imperative. It is universally acknowledged that for IoT, security of underneath hardware is pivotal for reliable functioning. The underlying hardware may have been affected by several threat factors. An adversary may generate secret exist that leaks crucial data such as encryption key employed in secure transmission line, the maker could intervene the design by implanting hardware Trojans, or implant artifacts with recognized dependability susceptibilities. Current generation designs assimilate intellectual property (IP) blocks from manifold vendors, mass-produced and verified by diverse companies worldwide. Accordingly, numerous access points exist for hardware to be attacked. For a trusted or secured hardware design, defense of intellectual property cores is of ultimate significance.

Electronics design industry in future is heading for a paradigm shift toward secured, reliable, and low-cost CE hardware from the conventional ones. Reading this book will enable the readers to push their boundaries of knowledge to dive into the some emerging hardware-assisted security and IP core protection aspect of CE devices. In this book, we present for the first time “intellectual property core protection and hardware-assisted security” for CE. We define “hardware-assisted security” as the security/protection of hardware cores. Intellectual property cores of CE systems and hardware are designed to secure/protect the information processed by CE systems. The term “security” encapsulates a broad theme that covers many aspects including hardware security, protection, privacy, trustworthiness, and intellectual property protection and information security. The system security may refer to the security of the system (e.g., a specific CE device) that handles the data or information. Though there have been textbooks focusing on system security, hardware defense against malicious Trojan, however no textbook encompasses details of wide-spectrum hardware threats/attacks and its hardware-assisted defense mechanism. In this book, explicit focus has been made on hardware (IP core) Trojan, IoT security, hardware watermarking, hardware structural obfuscation, hardware functional obfuscation, hardware encryption, watermarking encryption hardware, forensic engineering, JPEG core, memory attacks, security, privacy, IP right in IoT and CE systems obfuscation, IP core fingerprinting, PUF, and several others.

Chapter 1 presents an “Introduction to IP core protection and hardware-assisted security of consumer electronics.” The salient features of this chapter include providing a security perspective, defining hardware-assisted security, providing background on IP cores and its significance, necessity of security and protection of DSP kernels—with details on high-level synthesis framework and finally ending with hardware-assisted media protection.

Chapter 2 presents “Security in consumer electronics and Internet of things.” The salient features of this chapter include IoT architecture, challenges, and its applications; the big picture on security, privacy, IP right in IoT and CE systems; memory security, radio frequency identification (RFID) security; near field communications (NFC) security; smart healthcare and transportation security, firmware security, and finally ending with blockchain technology.

Chapter 3 presents “Trojan security-aware DSP IP core and integrated circuits.” The salient features of this chapter include types of hardware Trojan, hardware Trojan in a 3PIP module, Trojan security approaches, Trojan security-aware DSP kernel/IP core design process, and finally ending with analysis on case studies.

Chapter 4 presents “IP core and integrated circuit protection using robust watermarking.” The salient features of this chapter include introduction to hardware (IP core) watermarking, description of selected IP core watermarking approaches, design process of a watermarked IP core, properties of a hardware watermarking, and finally ending with analysis on case studies.

Chapter 5 presents “Symmetrical protection of DSP IP core/IC using fingerprinting and watermarking.” The salient features of this chapter include background on watermark and fingerprint, its associated threat model, fundamentals of IP core protection, symmetrical IP cores protection for DSP kernels, case study on symmetrical IP core protection, and finally ending with analysis on different DSP kernel test cases.

Chapter 6 presents “Computational forensic engineering (CFE) for resolving ownership conflict of DSP IP core.” The salient features of this chapter include overview on CFE for IP core protection, IP core feature extraction algorithms, important characteristics of customized CFE, and finally ending with analysis on case studies.

Chapter 7 presents “Structural obfuscation of DSP cores used in CE devices.” The salient features of this chapter include introduction to structural obfuscation, its associated threat model, relative perspective of logic, code, and structural obfuscation techniques, compiler transformation-driven structural obfuscation, design process of low-cost structurally obfuscated IP core, case study on multistage structural obfuscation, and finally ending with case studies on DSP kernels.

Chapter 8 presents “Functional obfuscation of DSP cores used in CE devices.” The salient features of this chapter include attack scenarios and threat model, selected functional obfuscation approaches for DSP IP core, design of functional obfuscated DSP IP core, security of functionally obfuscated DSP core design, optimization engine for functional obfuscation of DSP kernels, and finally concluding with analysis on DSP kernel case studies.

Chapter 9 presents “Obfuscation of JPEG CODEC IP core for CE devices.” The salient features of this chapter include the overview of JPEG compression and decompression process, design process of structurally obfuscated JPEG IP core, its associated threat model, formulation, optimization framework, implementation of JPEG CODEC IP core, and finally concluding with design analysis.
