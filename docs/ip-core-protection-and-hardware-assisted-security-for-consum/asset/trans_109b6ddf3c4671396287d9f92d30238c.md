

本章讨论了用于硬件核心（a.k.a. 知识产权（IP）核心）所有权保护的强健水印方法。水印通过将某些额外属性插入硬件核心，以便在需要时可用于验证硬件核心的所有权。已讨论强健水印方法，因为这些方法能抵御全球供应链中出于各种原因发生的各种攻击。本章剩余部分结构如下：第 4.2 节概述了选定的硬件/IP 核心水印方法；第 4.3 节讨论了带水印 IP 核心的设计流程；第 4.4 节基于案例研究/测试用例分析了硬件水印方法；最后，第 4.5 节得出结论。

### 4.1 引言

水印是植入到实体（如官方文件、货币、邮票、音频/视频文件等）中的秘密标记，用于保护所有者的所有权。通常，嵌入到实体中的水印应保留其实体的质量和功能。然而，对于应用水印的领域（如音频/视频、文档等），通常会注意到质量轻微下降。鉴于水印的优势，它也可以被视为保护硬件（例如，数字信号处理器（DSP）核心）所有权的极有用工具。然而，与其他领域水印的主要区别在于对硬件设计质量/功能修改的零容忍。这使得硬件水印既具有挑战性，又对保护 IP 供应商/所有者的合法权益极其有用。广泛认为，复杂消费电子（CE）系统设计在很大程度上依赖于作为片上系统（SoC）实现的 DSP IP 核心。因此，硬件水印在 CE 设备的 IP 核心保护中发挥着不可或缺的作用（[Mohanty *et al.*, 2017](#Chapter4.html#c04_bib11); [Voyatzis and Pitas, 1999](#Chapter4.html#c04_bib23); [Cox *et al.*, 2006](#Chapter4.html#c04_bib4); [Roy *et al.*, 2013](#Chapter4.html#c04_bib13); [Sengupta, 2017](#Chapter4.html#c04_bib16); Sengupta and Sedaghat, 2011; Sengupta *et al*., 2013）。

在现代 CE 时代，DSP IP 核心在全球供应链中的使用已成为复杂 SoC 设计流程中不可或缺的一部分。IP 核心不仅能大幅提升设计生产率，还能大大缩短设计周期。系统集成商或 SoC 设计师从第三方 IP 供应商处导入这些 IP 核心已成为常见的行业惯例。此前，IP 供应商主要关注 IP 性能和 IP 功能，却忽视了 IP 安全。作为证据，可以观察到，在典型的 IP 设计流程中，性能和功能的测量仅包含在 IP 规范中。然而，IP 核心在 SoC 设计流程中的普遍使用加剧了多个 IP 核心供应商之间的竞争，这引发了 IP 核心伪造、所有权虚假声明等安全威胁，这些威胁可以通过硬件水印来解决。因此，威胁模型可以定义为：

*威胁模型*：基于水印的 IP 核心保护机制的目标威胁模型为：(i) 虚假所有权声明，(ii) 所有权冲突，以及 (iii) IP 核心中的 IP 盗版/伪造。

IP 核心的设计过程涉及大量的人工研究、投资和验证；因此，这项努力必须得到保护。由于 IP 核心可以轻易复制，IP 盗版和所有权滥用已成为日益严重的安全问题。因此，保护原始 IP 所有者的所有权至关重要。例如，在从第三方 IP 供应商处导入 IP 核心后，SoC 集成商可能声称自己是 IP 的原始所有者，或可能在未承认原始 IP 所有者的情况下重复使用 IP 核心。因此，对于原始 IP 所有者来说，消除虚假所有权声明或检测 IP 核心的非法滥用是至关重要且复杂的。保护 IP 核心免受上述潜在威胁的一种流行方法是在供应商自身的设计过程中将供应商签名嵌入 IP 核心中（[Alkabani and Koushanfar, 2008](#Chapter4.html#c04_bib1); [Koushanfar *et al.*, 2005](#Chapter4.html#c04_bib8); [Sengupta, 2016](#Chapter4.html#c04_bib15); [Guajardo *et al.*, 2008](#Chapter4.html#c04_bib7); [Sengupta *et al.*, 2017](#Chapter4.html#c04_bib21); Sengupta and Roy, 2017）。

### 4.2 选定的水印方法

本节讨论了用于 IP 核心保护的几种选定水印机制。Ziener 和 Teich ([2008](#Chapter4.html#c04_bib24)) 为现场可编程逻辑门阵列（FPGA）架构设计了一种 IP 核心水印方法。IP 所有者签名作为水印嵌入到 IP 核心的网表和比特流文件中。水印算法将签名嵌入到 IP 核心的功能部分，使得在不破坏 IP 核心的情况下移除水印变得具有挑战性。签名从带水印的 FPGA 的电源引脚中识别出来。更具体地说，作者设计了一种签名检测算法，该算法通过电压痕迹以高可靠性解码水印。此外，还设计了两种鲁棒性增强算法，以便在存在显著噪声的情况下也能正确解码签名。Ziener 和 Teich ([2008](#Chapter4.html#c04_bib24)) 方法的概述如 [图 4.1](#Chapter4.html#c04_fig1) 所示。两种在综合过程中的 IP 核心水印方法：低成本水印和零成本水印是可能的（[Le Gal and Bossuet, 2012](#Chapter4.html#c04_bib9））。供应商签名以水印形式嵌入，基于“临时空闲”的 IP 输出时隙。在低成本水印方法中，水印由一组任意选择的 IP 内部计算值特征，这些值通过“临时空闲”输出时隙传输。在零成本水印方法中，水印使用动态瞬态输出单元，在时隙暂时空闲时将选定数据驱动到输出端口，这可以通过修改 IP 控制来实现。由于高层次综合（HLS）工具使用有限状态机设计控制单元，因此，零成本水印方法仅影响 IP 核心的有限状态机。用于生成带水印 IP 核心的所需数学关系可以使用“临时空闲”IP 输出时隙的等效性检查测试来验证。水印可以表示为（[Le Gal and Bossuet, 2012](#Chapter4.html#c04_bib9)）：
