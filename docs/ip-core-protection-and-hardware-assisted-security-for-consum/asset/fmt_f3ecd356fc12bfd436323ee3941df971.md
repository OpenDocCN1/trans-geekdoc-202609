
# 11.10.3 Side-channel attack countermeasures

Side-channel attacks are highly efficient in stealing information from the microcontroller or memory. The attacker can use various kinds of attacks such as CPA, DPA, timing analysis, and so on on the hardware to get the information stored on it. Many techniques are available to mitigate the issues of power analysis attacks ([Ambrose *et al*., 2015](#Chapter11.html#c11_bib3); [Jayasinghe *et al*., 2015](#Chapter11.html#c11_bib38)). There are many ways to avoid the side-channel attacks on the hardware modules. Figures [11.29](#Chapter11.html#c11_fig29) and [11.30](#Chapter11.html#c11_fig30) show different ways of safeguarding the hardware modules from CPA and DPA attacks.

One of the main drawbacks of the power analysis attacks is that the hardware should be powered on during the time of the attacks in most of the cases. So, if the power supply to the module is turned off, the attacker cannot perform the attack anymore. Introducing some interrupts to the power can also mitigate the security threats to some extent. Power supply to the module can be detached when unused but this will only apply when the module is not solely in the hands of the attacker. During the execution process, there can be a nondeterministic execution which will not give out the exact power statistics of the device during the processing of secret keys. These are some of the hardware solutions that can be implemented. De-synchronization, software balancing, random masking, and so on are the software countermeasures to the DPA attacks on the security modules.

# 11.11 Attacks on watermarks and watermarking systems

When a watermark is embedded into a media object, there is a great chance that it might be subjected to manipulative attacks before the media reaches the receiver. Some of the manipulations are analog-to-digital and digital-to-analog conversions, resampling, quantization, dithering, low-pass and high-pass filtering, and so on. The media can be printed and rescanned in some cases intended to remove the watermark from the media. Any processing of the watermarked image that is intended to remove or tamper the watermark and fail the detection process is an attack on the watermark ([Cox and Linnartz, 1998](#Chapter11.html#c11_bib17); [Mintzer *et al*., 1998](#Chapter11.html#c11_bib62); [Sequeira and Kundur, 2001](#Chapter11.html#c11_bib97); [Swanson *et al*., 1998](#Chapter11.html#c11_bib105); [Voloshynovskiy *et al*., 2001](#Chapter11.html#c11_bib115)). The characteristics of the watermark and its performance against the attacks which are mutually conflicting FoM. Comparing metrics for different algorithms is needed to come to a decision in selecting a suitable watermarking scheme for a particular application. Benchmarks of the watermark are different attacks in a unified framework which allow the owner to check the scheme for applicability.

This section discusses different attacks that are possible on a watermarked image. There are different types of attacks on a watermarked image to remove the watermark. They are classified into four different types ([Liu *et al*., 2017](#Chapter11.html#c11_bib50); [Pereira *et al*., 2001](#Chapter11.html#c11_bib84); [Vellaisamy and Ramesh, 2014](#Chapter11.html#c11_bib112); [Voloshynovskiy *et al*., 2001](#Chapter11.html#c11_bib115); Wang *et al*., [2017a](#Chapter11.html#c11_bib119), [2017b](#Chapter11.html#c11_bib120); [Xiang *et al*., 2014](#Chapter11.html#c11_bib123)) as shown in [Figure 11.31](#Chapter11.html#c11_fig31):

*   Geometric attacks
*   Removal and interference attacks
*   Cryptographic attacks
*   Protocol attacks

## 11.11.1 Removal and interference attacks

Removal attack on the watermark is targeted to remove the watermark from the object. A watermark is the noise that is added to the original image and this is taken as an advantage by the attacker to remove the watermark. Interference attacks target the watermark by adding more noise to the watermarked image. Quantization, lossy compression, collusion, remodulation, denoise, averaging, and noise storm are the examples of such kinds of attacks. JPEG, MPEG, and so on are the lossy compression styles that can degrade the quality of watermark that is embedded in the media object. When many legit owners of the watermarked copy of the media come together to create a nonwatermarked image, it is called a collude attack. This can be achieved by averaging different objects in the media that is already watermarked.

## 11.11.2 Geometric attacks

The geometric attacks are more targeted toward the watermarked images and videos. These kinds of attacks do not remove the watermark present in the media but will manipulate the watermarked media so that the detector will not be able to extract or retrieve the watermark. Affine transformations such as translation, rotation, and scaling are used to successfully launch this attack. Line removal, wrapping, and cropping can also be done to remove the watermark from the media object. Mosaic attack is another example of this category ([Koubaa *et al*., 2007](#Chapter11.html#c11_bib45)). In such attacks, the media object is divided into different parts and again rearranged into one using HTML, which makes the watermark difficult to be detected by the detector.

## 11.11.3 Cryptographic attacks

The two attacks that are discussed above will not be able to breach the algorithm security. A cryptographic attack is the one that precisely attacks the security of the watermarking algorithm and cracks it. When the watermark is secured with a secret key, as discussed in the previous sections, a brute-force attack can be performed and broken, which can be considered as a cryptographic attack. Oracle attack is another kind of cryptographic attack which uses a public watermark detector to create a nonwatermarked media object.

## 11.11.4 Protocol attacks

This kind of attacks takes advantage of the loopholes that are present in the watermarking algorithm ([Craver *et al*., 1996, 1998](#Chapter11.html#c11_bib21); Wang, 2009; [Zhang and Liu, 2017](#Chapter11.html#c11_bib126)). This kind of attack is also known as inversion, deadlock, or fake–original attack. One or many new watermarks are introduced on an already watermarked media which makes it difficult to detect the original watermark and the owner. Some kinds of attacks will produce a fake original media object with a watermark so that the detector will detect it as an original watermarked legit copy. Watermark from an already watermarked object is detected and transferred to another media object which is called copy attack, which is also very popular.
