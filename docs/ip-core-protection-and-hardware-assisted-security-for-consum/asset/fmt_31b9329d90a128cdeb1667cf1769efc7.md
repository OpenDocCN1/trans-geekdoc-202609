
In the case of a visible watermark, an image is overlaid on the original image that can be seen but is very translucent. Such watermark can only be seen when the media is carefully observed. An invisible watermark is not visible to the eye. In such cases, the pixel values are altered and the watermark is embedded but the original image itself is not altered. But when the appropriate techniques and algorithms are run, the invisible watermark can be retrieved and authenticated. But this watermark should be embedded into the image so that it is not damaged or removed when the image itself is modified. There are also different watermarking techniques that are available for implementation ([Chen *et al*., 2015](#Chapter11.html#c11_bib13); [Hua *et al*., 2001](#Chapter11.html#c11_bib36); Mohanty *et al*., [1999](#Chapter11.html#c11_bib72), [2018](#Chapter11.html#c11_bib71)). A dual watermark will implement both visible and invisible watermarking techniques. Invisible watermark techniques need the original image in order to detect the watermark when needed. But in the case of a visible watermarking technique, the original image is not needed for authentication. Invisible watermark can also be attacked by creating “counterfeit original” which is called invertible. #### 11.3.4 From applications point of view

The digital watermarking techniques can be classified into two types based on the application perspective ([Voyatzis and Pitas, 1999](#Chapter11.html#c11_bib116)):

*   Source

*   Destination

In case of the source watermarking technique, the watermark which will identify the owner of the media will be embedded into all copies of the media. Authentication is the main aim of the source watermarking where the image received can be challenged to be real or tampered with. The technique where the watermark will identify the user but not the owner is called the destination watermarking technique. Here, each distributed copy embeds a unique watermark identifying a specific user. This type of watermark can be used to identify the media at the buyer side and will help reduce the counterfeiting.

#### 11.3.5 Based on embedding techniques

Digital watermarking techniques can be classified as additive, multiplicative, or quantization based on the embedding techniques ([Voloshynovskiy *et al*., 2001](#Chapter11.html#c11_bib115)). In the case of an additive technique, there are very weak dependencies between the watermark and the image. But in the case of a multiplicative scheme, the original data samples are multiplied by an independent factor. In the quantization watermarking schemes, the watermark and the original media will have strong dependencies but are statistically independent.

#### 11.3.6 Hardware-based watermarking systems

There are many advantages to a hardware watermarking techniques. The module can be designed on an FPGA. Designing the module on an FPGA will give more room for optimization for performance and power consumption trade-off and also will be highly efficient ([Gafsi *et al*., 2016](#Chapter11.html#c11_bib31); [Mohanty *et al*., 2017](#Chapter11.html#c11_bib81)). There are also cell-based ASIC designs that are available for the invisible and visible watermarking techniques. The choice between FPGA and cell-based IC is a trade-off between cost, power consumption, and performance ([Mohanty *et al*., 2004, 2005a, 2005b](#Chapter11.html#c11_bib79)).

### 11.4 Applications of digital watermarks

This section discusses various applications of watermarking schemes, which include copyright protection, broadcast monitoring, misappropriation detection, ownership assertion, usage control, fingerprinting, information hiding, integrity verification, and so on ([Chan *et al*., 2015](#Chapter11.html#c11_bib12); [Cheng *et al*., 2014](#Chapter11.html#c11_bib14); [Mohanty *et al*., 2017](#Chapter11.html#c11_bib81); [Zhang *et al*., 2015](#Chapter11.html#c11_bib127)).

#### 11.4.1 Copyright protection

There are cases where the media objects need to be uploaded to the Internet or publicly available. There are also the cases of research. In such cases, the media might be subject to illegal distribution where no royalties will be paid to the owner and the media is distributed or used commercially. There are also applications where the owner might have to distribute the preview of the media for public display before the content is released. In those cases, the owner might desire to have the ownership mark where it can save the media to be used or distributed illegally. A visible watermark can be used in such cases where a translucent image is spread across the significant portion of the original image or media.

#### 11.4.2 Ownership assertion

The owner might make the media available over the Internet or in a public domain and desire to publicly indicate the ownership of the content. Then the observer will be interested in patronizing the institute that owns the media or object. For example, the books in a library will have a small print of the printers. In case of ownership assertion, an invisible watermark can also be used. A watermark or a key will be generated by the owner and can be embedded into the original media. In such scenarios, an invisible-robust watermark which is a function of original image can be used and more suited.

#### 11.4.3 Authentication and integrity verification

For the authenticating and integrity verification purposes, an invisible-fragile watermark is used. When the media or object is used legally, for example, medical or news purposes, original image has to be verified that if it has been altered or tampered. If the image is captured and saved for a later use, it has to be verified that the image is not altered. For example, if an image is captured with a camera for news purposes, when it is being presented in an article, the image should be original and should not be altered. Similarly, the images of human fingerprints have been stored for various purposes, which has to be secure and authentic. In a library, invisible-fragile watermarking can be implemented to detect any alteration of images.

#### 11.4.4 Fingerprinting

When an image is distributed into the public domain, the owner might want to increase the security of the media by implementing a unique watermark of his/her own into the media, which is called “fingerprint.” After embedded into the media, a fingerprint can be retrieved and the origination of the image can be tracked. In this case, an invisible-robust watermark invulnerable to forgery, removal, and invalidation is most suitable.

#### 11.4.5 Usage control

In cases of physical media such as DVD or audio CD, proprietary hardware is to be used for copying and viewing. In such a scenario, invisible-robust watermark is used to determine if the media can be played or copied. A watermark can also be used to determine the number of times the media is copied. There is also a chance that the watermark is changed by the hardware to increase the robustness and to prevent the illegal use of the object.
