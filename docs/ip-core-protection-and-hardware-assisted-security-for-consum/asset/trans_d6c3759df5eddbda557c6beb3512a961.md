# 第 8 章 用于 CE 设备的 DSP 核心功能混淆

上一章详细介绍了许多结构混淆方法，但我们现在转向另一类称为“功能混淆”的混淆。使用哪种技术取决于设计工程师。本章介绍了几种通过功能混淆来防范 IP 盗版和 RE 攻击的方法。更具体地说，我们将讨论基于 IP 功能锁定块（ILB）的逻辑混淆，用于作为 CE 设备中 DSP 核心的硬件加固技术（[Sengupta *et al.*, 2018](#Chapter8.html#c08_bib35））。此外，还进行了基于 PSO 的 DSE，以生成 DSP 核心的低开销功能混淆（FO）设计方案（Sengupta 和 Sedaghat，[2011](#Chapter8.html#c08_bib31)，[2013](#Chapter8.html#c08_bib32)）。本章其余部分的组织如下：第 8.2 节讨论不同的攻击场景和威胁模型。第 8.3 节解释文献中可用的选定功能混淆技术。第 8.4 节讨论用于 CE 设备的 DSP IP 核心的功能混淆设计过程。第 8.5 节介绍 DSP IP 核心设计功能混淆方法的安全性分析。第 8.6 节讨论基于 PSO 的 FO 设计优化。第 8.7 节介绍案例研究/测试用例的分析。
