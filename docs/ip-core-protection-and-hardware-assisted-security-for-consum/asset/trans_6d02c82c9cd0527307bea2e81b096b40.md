

如前所述，在 CE 设备的核心部分，存在多个用于数据密集型或控制密集型功能的 DSP 内核。这些 DSP 内核是以 SoC 平台形式存在的 IP 内核，负责处理大量数据块。例如，数字摄像机几乎总是内置第二个微处理器，专门用于视频计算。这个过程被称为数字信号处理器（DSP），其作用是实时执行重复的数学任务。简单来说，当我们的智能手机主微处理器检查是否有来电时，第二个处理器会同时在后台运行电子邮件、管理 Wi-Fi 信号、检查镜头中是否有视频传入等，所有这些计算都由第二个专用处理器（即 DSP 内核）处理。主题示例如 [图 1.4](#Chapter1.html#c01_fig4) 所示。如图所示，多媒体/DSP 内核（JPEG 压缩/解压缩 IP 内核）在 CE 设备的成功运行中起着重要作用。同样，其他 DSP 内核，如离散余弦变换（DCT）内核、快速傅里叶变换（FFT）、数字滤波器等，在 CE 设备设计中也起着关键作用。例如，FIR 滤波器有助于改善 CE 设备中的音频质量和蜂窝基础设施。此类复杂 DSP/多媒体内核的保护依赖于高层综合（即架构综合）作为骨干设计框架。这是因为包含 15K–60K 门的此类复杂 DSP 内核从不从较低抽象级别启动设计过程。此外，通过高层综合框架可以无缝地选择/控制这些 DSP 内核的架构，因为该框架包含设计空间探索（DSE）模块（由智能进化算法驱动）。如果这些设计必须从寄存器传输（RT）/门级/较低级别开始，则不可能实现这一点。

![image](OEBPS/images/PBCS0600-01-f04.jpg)

图 1.4 CE 设备中的 DSP/多媒体内核：数码相机

因此，此类复杂内核的保护/安全机制与高层综合设计过程交织在一起。对于此类硬件，保护主要在较高抽象级别（即高层综合期间）应用。相比之下，加法器、编码器、解码器等较不复杂硬件的安全/保护机制可以在 RT 级/门级等较低级别执行。[图 1.5](#Chapter1.html#c01_fig5) 显示了不同硬件辅助安全和 IP 内核保护机制在较高和较低抽象级别的分类。如前所述，对于无限脉冲响应（IIR）滤波器、FIR、JPEG 等 DSP/多媒体内核，保护/安全算法在较高抽象级别应用，这使得安全算法的约束也能通过 RT 级/门级综合传播到较低级别。

## 1.4.1 IP 内核/硬件可用的安全和保护方法

一些广泛用于 CE 设计中 DSP IP 内核的公认保护机制取决于威胁模型/漏洞，包括水印、指纹、硬件计量、计算机取证工程、木马安全、结构混淆、功能混淆、物理不可克隆函数（PUF）以及专利/版权（[Alkabani *et al.*, 2007](#Chapter1.html#c01_bib1); [Castillo *et al.*, 2007](#Chapter1.html#c01_bib3); Christof and Jan, 2009; [Hong and Potkonjak, 1999](#Chapter1.html#c01_bib6); [Koushanfar *et al.*, 2005](#Chapter1.html#c01_bib8); [Marvel, 2005](#Chapter1.html#c01_bib9); [Ni *et al.*, 2006](#Chapter1.html#c01_bib16); [Sengupta and Roy, 2018a](#Chapter1.html#c01_bib24), [2018b](#Chapter1.html#c01_bib25)）。[图 1.6](#Chapter1.html#c01_fig6) 显示了 CE 设备威胁模型及其硬件安全对策的概览。

![image](OEBPS/images/PBCS0600-01-f06.jpg)

图 1.6 一些常见硬件威胁及其对策概览

### (i) IP 内核/硬件水印

当预期的硬件威胁是虚假的所有权声明时，会采用这种硬件保护机制。这种威胁模型基本上是由于所有权滥用或虚假声明 IP 内核所有权或盗版造成的。尽管水印可以防范上述威胁，但它只能检测而不能防止威胁。换句话说，水印方法能够为 IP 内核提供被动形式的保护。有关此保护机制的更多细节将在第 4 章中介绍。

### (ii) IP 内核的计算机取证工程（数字取证）

当问题中的硬件威胁是所有权滥用或虚假声明 IP 内核所有权或盗版时，会采用这种硬件保护机制。它与水印具有相同的威胁模型，并在所有权冲突时提供合法所有者的检测。计算机取证工程（CFE）的目标是识别生成 IP 的个人。它检查给定 IP 的某些属性，并测量特定个人生成该 IP 的概率。CFE 方法从一组综合工具中识别出用于制作特定 IP 设计的工具。需要注意的是，这种方法也能够为 IP 内核提供被动形式的保护。有关此保护机制的更多细节将在第 6 章中介绍。

### (iii) 硬件计量

这是监控 IC 的方法。一些有效的方法是在芯片上物理识别序列号或在其内存中存储唯一标识符（[Alkabani and Koushanfar, 2007](#Chapter1.html#c01_bib2); [Roy *et al.*, 2008](#Chapter1.html#c01_bib18)）。硬件计量的分类如 [图 1.7](#Chapter1.html#c01_fig7) 所示。硬件计量大致可分为两类：非功能性和功能性。在非功能性识别方法中，会创建一个与芯片功能分开的唯一 ID。但是，它可能有以下缺点：

1. 易受克隆和/或移除；
2. 一旦芯片被标记，晶圆厂可以将相同的标记复制到其他芯片上，或者简单地移除标记，导致芯片无法追踪；
3. 存在过度生产的可能性；
4. 晶圆厂可以生产带有相同标记的多个芯片；
5. 在数百万个芯片中，找到两个匹配标记的概率很小。
