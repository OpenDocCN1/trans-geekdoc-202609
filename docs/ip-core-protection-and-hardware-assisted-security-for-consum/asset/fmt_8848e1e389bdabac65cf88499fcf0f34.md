
### 5. Loop-invariant code motion process

This loop transformation process identifies those loop-independent operations which are presented inside the loop and moves them out the loop. In the context of CDFG, the nodes which are independent of loop are shifted out from the loop body. More specifically, LICM transformation moves out those nodes whose iterative execution inside the loop or single execution outside the loop does not make any difference in the final output of the application. Therefore LICM produces structurally different, yet functionally same designs. Lastly, LICM-based structurally obfuscated DSP circuit is produced as output after processing through HLS.

For instance, [Figure 7.12](#Chapter7.html#c07_fig12) depicts the LICM-based structurally obfuscated version of the input CDFG. The dotted box indicates the loop-independent nodes. ### 7.4 Low-cost structural obfuscation for DSP IP core

Sengupta *et al.* ([2017a](#Chapter7.html#c07_bib36)) explored a low-cost DSP design solution through PSO-based exploration ([Sengupta *et al.*, 2017b](#Chapter7.html#c07_bib37)). It accepts the structurally obfuscated design of the DSP core as C-code/loop-based CDFG, module library, and user-provided delay-area restrictions with terminating criteria and control parameters of PSO (such as social factor, cognitive factor, inertia weight) as inputs and produces structurally obfuscated, low-cost DSP circuit as output. The description of the PSO-DSE process is explained in the following subsections.

#### 7.4.1 Overview on PSO

PSO is an optimization process driven through population-based searching that iteratively explores an optimal solution from a pool of available solutions, known as search space. Each possible resource configuration is encoded as a particle and the fitness of each particle is assessed through an objective function to find an optimal solution. Each particle’s velocity guides that particle toward an optimal solution. The velocity of each particle is calculated using the current global best “gbest” and its own best location “lbest.” After discovering a better global or local best, velocity and position of a particle are updated, thus moving toward the optimal solution.

In the context of the low-cost DSP design solution, each particle represents a resource configuration and an unrolling factor value as a design solution. The first three particles are initialized with the minimum (min), maximum (max), and mid-resources configuration along with its unrolling factor value. If the initial population size is more than three particles, then the rest of the particles are initialized randomly within the range of min and max resource configuration value. The fitness of each particle is calculated using the cost function shown in [(7.3)](#Chapter7.html#c07_eqn3). PSO-DSE is also explained in detail in Chapter 3.

#### 7.4.3 Terminating condition of PSO

This DSE process searches for a low-cost design solution for DSP circuit iteratively. However, this iterative searching process terminates based on the following two conditions. The first condition is: if the number of iteration reaches the maximum number of predefined iteration count (*I*[max]), and second is: if no improvement in global best is found for a predefined (*δ*) number of iteration. According to Sengupta *et al.* ([2017b](#Chapter7.html#c07_bib37)), the values of *I*[max] and *δ* can be set as 100 and 10, respectively.
