

# 在当前的 IC 供应链模型中

在当前的 IC 供应链模型中，多方参与以处理日益增加的设计复杂性和成本。为了避免建立和维护拥有先进制造设施的晶圆厂的责任，无晶圆厂半导体公司将其设计的 IC（例如 DSP 核心）出口给拥有制造设施的另一家公司。此外，有时系统集成商在设计 SoC 时，会从 3PIP 供应商处导入 DSP IP 核心，以满足上市时间要求 ([Castillo *et al.*, 2007](#Chapter8.html#c08_bib4))。因此，在这种 DSP 核心的全球化商业模式中，不同国家和公司有不同的 IP 监管政策和模式。因此，在这种情况下，芯片设计过程容易受到许多严重的 IP 安全威胁，例如盗版、过度生产、假冒、逆向工程（RE）以及硬件木马的插入 ([Sengupta and Kundu, 2017](#Chapter8.html#c08_bib29); [Sengupta *et al.*, 2018b](#Chapter8.html#c08_bib36); [Wong *et al.*, 2004](#Chapter8.html#c08_bib42); [Alkabani and Koushanfar, 2007](#Chapter8.html#c08_bib1))。这需要改进芯片设计过程以挫败这些威胁。

## IP 盗版

IP 盗版是非法使用或销售 IP 核心的过程。存在于 IP 核心设计流中的不可信晶圆厂可以窃取设计，非法克隆，然后将其转售给其他实体。这样，它可以绕过原始 IP 设计者投入的大量研发过程、人力、资金和时间。此外，他/她可以声称拥有该 IP 核心的所有权 ([Koushanfar, 2012](#Chapter8.html#c08_bib16); [Roy and Sengupta, 2017](#Chapter8.html#c08_bib25); [Sengupta and Roy, 2017](#Chapter8.html#c08_bib30); [Sengupta *et al.*, 2018b](#Chapter8.html#c08_bib36))。同样，不可信的晶圆厂可能将恶意逻辑以硬件木马的形式插入设计中，以导致 DSP IP 核心故障 ([Sengupta *et al.*, 2017b](#Chapter8.html#c08_bib34))。插入硬件木马可以根据其类型为对手带来许多好处。它可以泄露用于国防系统的 DSP IP 核心的关键信息，损害知名公司的声誉，或降低 IP 核心的性能等。根据《假冒和盗版的经济影响》（2017 年），2013 年 G20 国家因盗版和假冒造成的总财政收入损失为 960 亿至 1300 亿美元，可能上升至 2022 年的 1990 亿至 2700 亿美元。据识别，全球销售的电子产品中有 10% 是假冒产品 ([Guajardo *et al.*, 2008](#Chapter8.html#c08_bib12); [Lao and Parhi, 2015](#Chapter8.html#c08_bib17))。

## DSP/IP 核心的逆向工程（RE）

DSP/IP 核心的逆向工程（RE）是获取其功能、设计和结构的完整理解的过程 ([Vijayakumar *et al.*, 2017](#Chapter8.html#c08_bib40); [Torrance and James, 2009](#Chapter8.html#c08_bib39); [Sengupta *et al.*, 2017a](#Chapter8.html#c08_bib33))。因此，人们可以将 RE 过程用于诚实和欺诈的目的。人们还可以将 RE 作为工具，用于现有产品的教育、研发以及分析和评估目的。在许多国家，出于诚实目的的 RE 被视为合法过程，直到它违反任何设计版权和专利问题 ([Biggerstaff, 1989](#Chapter8.html#c08_bib3))。但是，RE 也可用于不诚实的目的，例如过度生产、盗版或假冒 DSP/IP 核心设计，或插入硬件木马，这可能为对手带来巨额利润。因此，出于不诚实目的的 RE 会孕育或招致上述潜在威胁。基于 Rajendran *et al.* ([2015](#Chapter8.html#c08_bib24))，IC 设计各个阶段中 RE 攻击的可能性如 [图 8.1](#Chapter8.html#c08_fig1) 所示。

一种流行的硬件加固技术，用于应对 DSP IP 核心的 RE 攻击，即功能/逻辑混淆。功能混淆（也称为逻辑加密）将额外的逻辑组件（称为密钥组件）插入设计中，以隐藏其功能和实现。这些额外的逻辑组件接受密钥位作为输入，并根据这些密钥值生成输出。因此，应用正确的密钥组合将产生正确结果，而应用错误的密钥将导致设计表现出不正确的功能。因此，功能混淆挫败了出于欺诈目的的 RE 过程。

# 8.2 攻击场景和威胁模型

本节讨论功能混淆的可能攻击场景和威胁模型。

## 8.2.1 可能的攻击场景

要生成锁定网表，密钥组件或密钥门可以插入电路中的任何位置。但是，密钥组件的放置不当可能会招致多种攻击。在本小节中，我们讨论与密钥组件放置相关的攻击以及其他攻击。

1. 基于孤立密钥门的密钥敏感化攻击：如果锁定网表中某个密钥门与任何其他密钥门之间没有路径，则该密钥门被视为孤立密钥门 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。攻击者可以轻松敏感化孤立密钥门的密钥值。例如，在 [图 8.2(a)](#Chapter8.html#c08_fig2) 中，密钥门 K1 和 K2 之间没有路径。因此，K1 和 K2 是孤立密钥门。攻击者可以通过应用“100XXX”输入模式，将 K1 的值敏感化为输出 1（O1）上的 0。

![image](OEBPS/images/PBCS0600-08-f02.jpg)

图 8.2 (a) 孤立密钥门 K1 和 K2；(b) 密钥门 K1 和 K2 的串联；以及 (c) 可同时变异的密钥门 K1 和 K2

2. 基于密钥门串联的密钥敏感化攻击：如果锁定网表中的一组密钥门以首尾相连的方式连接，则被视为密钥门串联 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。少数密钥门串联结构对锁定网表存在漏洞，因为它通过增加可能的正确密钥组合，减少了攻击者识别正确密钥所需的努力。原因是某些密钥门串联结构可能可以用单个密钥门替换，从而削弱安全强度。例如，在 [图 8.2(b)](#Chapter8.html#c08_fig2) 中，K1 和 K2 首尾相连，从而形成密钥门串联。在这种情况下，“01”和“10”都是正确的密钥值。此外，K1 和 K2 可以用单个密钥门（XOR）替换，其正确密钥值为“1”。

3. 基于可变密钥门的密钥敏感化攻击：如果两个或多个密钥门汇聚但它们之间没有共同路径，则仍可能发生敏感化 ([Yasin *et al.*, 2016](#Chapter8.html#c08_bib44))。因此，如果密钥门 K1 和 K2 汇聚到另一个门，使得通过禁用另一个密钥门可以获取特定密钥位，则这两个密钥门称为可同时变异的密钥门。在这种情况下，攻击者可以通过禁用 K2 轻松追踪 K1 的密钥值。例如，在 [图 8.2(c)](#Chapter8.html#c08_fig2) 中，K1 和 K2 在门 G 处汇聚。通过禁用 K2 的影响，可以将 K1 的值敏感化到 O1。在输入模式中应用 *I*[6] = 0 将禁用 K2。同样，通过禁用 K1 的影响，可以将 K2 的值敏感化到 O1。在输入模式中应用 *I*[1] = 1 将禁用 K1。

4. IP 盗版和木马攻击：如果攻击者以某种方式识别出锁定网表的正确密钥组合，他/她可以轻松发现该网表的正确功能。这可能会增加 IP 盗版/假冒和木马插入攻击的可能性。攻击者可以非法转售/重新分发 IP 核心以获利，或者可以在安全位置插入木马逻辑以导致 IP 核心故障。
