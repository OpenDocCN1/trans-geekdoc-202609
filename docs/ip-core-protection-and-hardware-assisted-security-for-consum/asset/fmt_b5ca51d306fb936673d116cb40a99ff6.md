
In some cases, after a digital watermark is embedded into a media object, it might have to be changed ([Cox and Miller, 1997](#Chapter11.html#c11_bib18)), for example, to control the flow of usage so that the media is used at a limited rate. To achieve this, the original disc, once a copy of it is made, is rewritten with a new watermark on it so that copying it further becomes difficult. If any alteration to the original disc or copying has to be performed, the watermark can be removed first before doing so. Cascadability is the process of adding multiple watermarks to the media at different stages of production or reuse. Pseudo random numbers are used to create spread spectrum watermarking and such watermarks should be orthogonal to be detected individually.

#### 11.5.6 Scalability

It is known that the speeds of the computer double every 18 months ([Ross, 2003](#Chapter11.html#c11_bib90)). Therefore a watermarking algorithm that currently requires high computation power might not seem such computationally demanding in the near future with a better performing computers. For example, the decoders that are initially designed are computationally not demanding but are not as efficient as the new and better ones as the new decoders will have more computational powers to perform the computations.

#### 11.5.7 Unambiguity and universality

The owner of the media object can embed his/her own watermark, visible or invisible into the object for additional security. But the final goal of a watermark is to identify the owner of the media object. In detection process, the watermarking scheme should not have ambiguity and also should not lead to any deadlock situations ([Swanson *et al*., 1998](#Chapter11.html#c11_bib105)). In order to achieve that, the original media object should meet some conditions ([Craver *et al*., 1996](#Chapter11.html#c11_bib20)). There is a chance of watermarking an image that is already watermarked and claiming the ownership of the object. Also it can be desired that the same watermarking scheme be used for different purposes including images, videos, and audio media objects. This can be a lot helpful when all the media objects are implemented in a single application.

#### 11.5.8 Pixel alteration and human intervention

In some cases, the value of the artwork that is being watermarked will be very high. In such cases, the watermark should not meddle with the quality of the object. Introducing the watermark or embedding it should not degrade the quality of the original image or artwork. And when a watermark is embedded into the object, the human intervention should be reduced to as minimal as possible. The whole process of watermarking technique should be automated. This can be a lot helpful in reducing the cost of production and the time taken to get the final watermarked product.

#### 11.5.9 Reliability

A watermark, once it is embedded into the original media object, should be reliable in detecting and retrieving when necessary. This will pose some constraints on the capacity of the respective watermark used. There are three figures of merit (FoM) for measuring the reliability of the watermark. They are:

*   False positive error rate

*   False negative error rate

*   Bit error rate

False positive error rate is the probability of determining the watermark when an nonwatermarked image is given as an input to the detection system and the ideal value should be 0. False negative error rate is the rate at which the detector misses the watermark when watermarked image is presented to it. Bit error rate is the number of correct bits that are detected in the watermark image.

#### 11.5.10 Blindness

In the case of a blind watermark embedding scheme, the watermark pattern that is chosen to be embedded on the original media object is independent of the host. And while detecting such watermarks, the information regarding the original object will not be revealed or the knowledge of it will not be available. In some cases, the original media object will not be available when detecting the watermark for authentication or copyright purposes. In such cases, blind watermarking and detecting is highly useful and reliable. But there is a drawback or limitations to the amount of watermark data that can be embedded onto an object and retrieval can also be difficult ([Swanson *et al*., 1998](#Chapter11.html#c11_bib105)).

#### 11.5.11 Security

Securing the insertion phase of watermarking is of highest priority. To achieve more robustness and security with the watermarks, a secret key can be used such that the watermark that is embedded is dependent on the secret key. In such scenarios, the watermark will not be dependent on the algorithm but the secret key that is being used in the original image ([Busch *et al*., 1999](#Chapter11.html#c11_bib10); [Swanson *et al*., 1998](#Chapter11.html#c11_bib105)). This can be very helpful where even if the adversary gets to know the algorithm that is used for embedding and detection of watermarks, the integrity of the watermark will not be affected.

#### 11.5.12 Real-time operation

There are some applications where the watermarking is used for real-time applications. For example, there are many different TV broadcasting networks that do live TV shows or live sports events. In such cases, the watermarking of the media that is being shared should also be done real time. Such cases also demand the watermarking of audios, videos, and images to be watermarked in real time and broadcast to the public. The signal latency should also be as minimal as possible ([Busch *et al*., 1999](#Chapter11.html#c11_bib10); [Khan *et al*., 2010](#Chapter11.html#c11_bib43); [Marcinak and Mobasseri, 2005](#Chapter11.html#c11_bib56); [Wang *et al*., 2008](#Chapter11.html#c11_bib117)). The hardware that is used for watermarking should be designed with pipelining and parallel architectures for a better performance. The algorithm that is used for watermarking should also be designed to use parallel processing.

#### 11.5.13 Cost and complexity

Implementing a watermark onto an image has a lot of limitations, one of which is the complexity and cost. When designing a watermarking hardware, the cost of the entire module will be calculated in terms of chip area and memory that is required by the algorithm. In case of the blind watermarking, having the original image on hand is not necessary and hence the memory requirements are also comparatively low. With the reduction in cost of watermarking, the overall production cost will also be affected, which leads to a low-cost production.

#### 11.5.14 Energy consumption

With newer technologies being developed, power consumption bar is coming lower every day. This leads to the development of low-power consumption devices and applications. With the introduction of IoT and its applications, different devices require low-power consumption. Digital watermarking schemes also need to consume low-power consumption (Mohanty and Ranganathan, [2004](#Chapter11.html#c11_bib75), [2005](#Chapter11.html#c11_bib76)). The technique may be software or hardware watermarking scheme but the power consumption of the overall process should be kept as low as possible. Different devices have unique specifications of hardware like power sources and running on battery. So, power optimization is highly necessary in terms of watermarking.
