# Training results with no error correction

In this case, the model was trained with the generated data, where no error correction is applied to the output. The resulting train error was achieved as 2.96% and the test error as 2.85%. Furthermore, the same model was tested with the Control Set having 17 real experiments, for which the input and output values are given in Table 1. The average prediction error was obtained as 3.70% for this set.

# Training results with error correction

The same model underwent a new training with the error-corrected outputs. In this case, the training error was 5.94%, and the test error, 5.16%. Greater error values than the previous case were expected, since the outputs were altered and perturbed from the data generated by BBD (Equation (7)). Nevertheless, when this model is compared with the actual outputs of the Control Set given in Table 2, there was a slightly reduced average prediction error, 3.62%.

# Validation results

In these experiments, some input values were selected from the outside of the previous limits given to BBD the in order to see the generalization performance. For example, pH limits were between 4 and 8 before and now 3 and 10 were chosen. Similarly, for incubation time, 15 min and 20 min, which are less than the previous minimum value of 30 min, were chosen. For metal concentration, 3 mM and 10 mM were chosen where 1 mM and 8 mM were the previous limits.

Furthermore, new figures which were within the limits, but not in the Control Set (for instance, 5 and 7 for pH, 45 min and 60 min for incubation time, and 3 mM and 7 mM for metal concentration) were selected. First, this Validation Set was given to the BBD’s quadratic formula (Equation (7)) to assess its performance with previously unseen inputs. Results are given in the “BBD-only Output” column of Table 4. The average prediction error (21.92%) is not low, and even gives a negative prediction. When the pH, incubation time and metal concentration were 3, 20 min and 7 mM, respectively as in the second experiment shown in Table 4, the actual HMD measurement was 25.00 nm, whereas BBD’s formula gave −3.86 nm for these inputs, which is an impossible result for size measurement. This yields to a prediction error of 115.44%, but it was not unexpected, as BBD’s formula was constructed only for the values in the Control Set (Table 1) and had not previously used the values in the validation set (Table 4). However, machine learning can give better results with unseen input values due to its generalization ability.

Therefore as the next attempt, the NN model trained with BBD’s outputs was tested with this Validation Set. Results can be seen in the “BBD & ML” column of Table 4. Average prediction error (10.79%) was considerably lowered as compared to the average prediction error of BBD-only case (21.92%). This shows the advantage of using two-stage modeling.

As the final trial, the Validation Set was applied to the NN model trained with the BBD’s error-corrected outputs. Table 4’s “BBD & ML & Err. Cor.” column lists the results for this case. The average prediction error was further reduced to 8.49%, showing the performance improvement by two-stage modeling and error correction.
