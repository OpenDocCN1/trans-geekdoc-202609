# Conclusions

This is a model study created with both statistical experimental design and ML, showing the potential of effective

green synthesis nanoparticle production. Utilizing ML in the process of NPS shows potential, but an obstacle is obtaining sufficient data. This study attempts to overcome this bottleneck, and presents promising results with a two-stage approach. In the first stage, BBD was used for experimental setup, quadratic model formulation and data generation. In the second stage, an ML model, namely a Neural Network structure was trained with the data generated in the previous stage.

An automated and fast data generation method using BBD formulation that is based on real experiment results is proposed so that ML could be fed with these data to learn the relationship between the nanoparticle size and several affecting factors.

Obtained results showed that the proposed combined BBD & ML strategy with enhanced data provided better nanoparticle size estimations than the statistical BBD approach alone. When the experiments were performed with completely new and unseen values, BBD’s prediction was poor with 21.92% average error, pointing to a generalization problem. However, BBD & ML combined approach with error correction gave 8.49% average error for the same input set. This result clearly represents an improvement in favor of ML usage.

This two-stage BBD & ML idea is not limited to the NPS process; it can be applied to any area where statistical methods such as RSM and BBD are used for modeling but data availability is limited, such as the production of valuable biotechnological products (enzymes, polysaccharides, bacterial cellulose, glycan etc.), the removal of pollutants, the synthesis of microorganisms, the calculation of hydrogen production yields. The benefits of this approach is that it is low cost, fast, and environment friendly, and shows improved performance as compared to using BBD alone.

In this study, 5,000 was determined as the amount of generated data required for the NPS process. As a comparison, NN training can be repeated with both greater and lesser amounts and results can be observed. For other processes using a different number of variables, data generation could have a different sampling set. Moreover, an automated process can be introduced to produce multiple output sets with different random error correction values. In this way, multiple NN trainings can be performed in parallel, and then the optimum NN with the lowest prediction error can be selected.

It is desirable to create common and accessible public pools for the data produced in similar researches, but not possible at the moment. Until such possibilities, data generation with BBD and ML usage idea proposed here could be a solution.
