
大数据作为从各种来源收集的庞大数据集合。它主要是非结构化的，包括来自网站、博客、聊天论坛、社交媒体和应用程序日志的数据。组织中的数据用户处理各种各样的数据。数据库设计师和数据架构师对数据进行结构化以便存储；系统开发人员使用数据开发用于接受、更新和展示数据的接口。终端用户进行数据录入并运行查询以生成报告。客户希望获得有关产品的正确详细数据以帮助做出购买决策；管理者更喜欢以报告和可视化演示形式呈现的数据。各种技术被用于对数据集进行分析。数据经过挖掘过程并使用 SQL 查询引擎存储在数据库中。用户运行临时查询以生成报告并提供可视化用于演示。数据集必须被结构化以满足所有利益相关者的需求，而这可能是工业 4.0 面临的挑战 [[19](#ch2.xhtml#ref2_19), [20](#ch2.xhtml#ref2_20) 和 [21](#ch2.xhtml#ref2_21)]。

大数据在农业、教育、体育、医学和制造业等多个行业的操作中具有相关性 [[19](#ch2.xhtml#ref2_19)]。大数据为数据用户提供了更好、更深入的数据视角。数据分析有助于做出决策并改进开发和生产流程 [[4](#ch2.xhtml#ref2_4)]。正确的分析可以提供关于产品和服务及其生产和开发过程的经验领域知识，从而推动工业 4.0 应用的有效实施 [[22](#ch2.xhtml#ref2_22)]。

### 2.2.4 自主机器人
集成物联网的自主机器人对于在智能行业中通过生产过程开发自主和自管理的产品具有重要作用。它们可以在容易导致僵局的情况下制定方案。在制造业中，自主机器人监督机器的运行并检测故障和失效。它们可以根据历史数据的分析进行诊断。在智能行业中，对机器人（协作机器人）的依赖基于多个因素，包括机器人的性能和安全性、易用性、灵活性和学习能力 [[4](#ch2.xhtml#ref2_4),[23](#ch2.xhtml#ref2_23),[24](#ch2.xhtml#ref2_24)]。

与自主机器人相关的一个挑战是生产工作流程的管理。机器人涉及零件的多种运动、精度和快速性。机器人应用应不断创新，具备新的工业流程和对新条件的适应能力 [[23](#ch2.xhtml#ref2_23)]。

### 2.2.5 网络安全
安全是组织的首要关注点；它们投入大量资源为其资产提供网络安全，包括网络通信系统、计算机设备、软件、数据和其他服务。对组织系统发起攻击，目的是破坏系统、拒绝访问计算机系统和服务、窃取并向未经授权的人员泄露信息，甚至破坏整个组织的基础设施和设备 [[25](#ch2.xhtml#ref2_25),[26](#ch2.xhtml#ref2_26)]。

物联网系统的主要威胁之一是安全。一些组织发现聘请专门从事信息技术和运营技术的专家具有挑战性。然而，建立促进跨职能学习的跨职能团队是必要的 [[27](#ch2.xhtml#ref2_27)]。

制造系统需要受到保护以免受攻击。解决制造应用中的网络安全问题需要利益相关者的参与 [[28](#ch2.xhtml#ref2_28)]。

网络安全为客户价值创造提供了前景。随着工业 4.0 的发展，隐私问题变得至关重要。智能产品正在出现，连接设备、生成和存储大量客户数据；网络安全将成为客户和其他利益相关者的关注点 [[29](#ch2.xhtml#ref2_29)]。

### 2.2.6 云计算
云计算为系统用户提供基础设施，使其无需地理和时间限制即可访问信息和服务；用户可以不论其操作系统平台连接其设备。基于云的制造提供可扩展性、虚拟化、敏捷性和网络化制造 [[30](#ch2.xhtml#ref2_30),[31](#ch2.xhtml#ref2_31)]。物联网和服务通过传感器和其他设备的连接生成数据。数据需要被存储和分析以做出决策并提高生产率。云计算与物联网集成，为制造过程提供业务价值。来自系统和云服务的分析数据有助于降低生产成本并提供安全见解，以支持生产过程并推动业务和运营转型 [[32](#ch2.xhtml#ref2_32)]。

在云服务支持下，制造商可以向客户征求需求并收集有关产品和性能的反馈。云计算为客户、供应商和其他利益相关者提供平台，以便在产品设计、开发、制造、测试以及产品生命周期中涉及的所有其他活动（包括维护）中进行协作和决策 [[30](#ch2.xhtml#ref2_30),[33](#ch2.xhtml#ref2_33)]。

### 2.2.7 增材制造
增材制造，主要与 3D 打印相关，是工业 4.0 转型中最具颠覆性的技术。在 3D 打印中，使用计算机辅助设计（CAD）软件设计 3D 模型，然后通过逐层添加材料在 3D 打印机上打印出物理物体。材料包括碳纤维、热塑性塑料、钢材、生化材料、金属和聚碳酸酯 [[34](#ch2.xhtml#ref2_34),[35](#ch2.xhtml#ref2_35)]。在增材制造的生产过程中，一项研究 [[36](#ch2.xhtml#ref2_36)] 提出了合适产品的特征。产品应在一定程度上可定制；它们应为小批量产品，并且能够优化以提供附加功能 [[36](#ch2.xhtml#ref2_36)]。这些特征使得 3D 设计和模型更容易定制，并且可以根据需要更轻松地更改设计。以更小的批次生产 3D 物理物体是可行的。多个行业实施增材制造，包括食品、时尚、电气和电子、生物医学、制药和铸造 [[37](#ch2.xhtml#ref2_37)]。

产生了一类生产自身商品的消费者；他们被称为‘prosumers’。客户对产品有自己的需求和偏好。这些客户从一开始就参与生产过程和价值链。因此定制产品可以在更短的时间成本内生成。由于设计上的敏捷性和灵活性，这使得制造公司更容易推出新产品 [[34](#ch2.xhtml#ref2_34),[35](#ch2.xhtml#ref2_35),[37](#ch2.xhtml#ref2_37)]。

### 2.2.8 仿真
制造公司过去通过尝试各种方法直到取得成功来生产并测试效率。制造商在工业 4.0 转型中使用虚拟化创建模型仿真并在仿真上运行测试。仿真有助于提高产品质量。在产品制造之前，各种组件会被仿真以评估其集成方式以及它们如何相互连接。在实施实际生产之前，对仿真进行测试以评估效率并识别任何可能的风险 [[38](#ch2.xhtml#ref2_38),[39](#ch2.xhtml#ref2_39)]。
