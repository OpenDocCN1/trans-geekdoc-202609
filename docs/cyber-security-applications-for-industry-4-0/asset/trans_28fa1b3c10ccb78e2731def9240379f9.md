
1784 年机械化、水力和蒸汽动力引擎的引入标志着第一次工业革命。1870 年，第二次工业革命随之而来，引入了用于大规模生产线的电能。随后在 1970 年，第三次工业革命伴随着数字、电子和信息技术系统而到来。数字化与自动化的涌入导致了第四次工业革命，即信息技术与运营技术融合形成网络物理系统。四次工业革命在 [图 2.1 第一次到第四次工业革命。](#ch2.xhtml#fig2_1) 中有所体现。

![图 2.1 第一次到第四次工业革命。](images/fig2_1_B.jpg)

[图 2.1 第一次到第四次工业革命。](#ch2.xhtml#R_fig2_1)

第四次工业革命的四大主要驱动力是物联网、工业物联网（IIoT）、基于云的制造和智能制造。工业 4.0 基于这些驱动力衍生的九大支柱蓬勃发展，如 [图 2.2 工业 4.0 的九大技术支柱。](#ch2.xhtml#fig2_2) 所示。它们包括大数据与分析、自主机器人、仿真、系统集成、物联网、网络安全、云计算、增材制造和增强现实 [[1](#ch2.xhtml#ref2_1)]。

![图 2.2 工业 4.0 的九大技术支柱。](images/fig2_2_B.jpg)

[图 2.2 工业 4.0 的九大技术支柱。](#ch2.xhtml#R_fig2_2)

尽管行业参与者和利益相关者尚未充分利用该技术，但他们已从其实施中获得了许多益处。产品开发和制造过程中流程的自动化提高了生产率。流程也得到了优化，并结合适当的维护和评估措施，从而提高了业务连续性。监控基于系统产生的实时数据实时进行；这改善了供应链和库存流程。工业 4.0 提供了更好地利用组织资产、发展创新能力并创造新的收入模式的机会。产品的消费者可获得个性化和定制偏好，以改善客户体验并获得售后支持和服务。

电子商务交易的激增减少了客户与产品供应商之间的互动量。客户通过应用程序界面自行完成在线购买，有时无需与卖家或制造商进行任何沟通。如今一些客户更喜欢在订单中加入定制。这种偏好使得有必要考虑智能产业的技术，并由此延伸到智能服务 [[2](#ch2.xhtml#ref2_2),[3](#ch2.xhtml#ref2_3)]。各种任务和流程的自动化通过优化机械和资源的使用改善了环境，并增强了运营环境中的安全性。总体而言，这提高了业务敏捷性，并为业务运营的可持续性提供了更好的工作条件。

工业 4.0 的支柱为开发者、用户和客户提供了定制和利用这些技术的使能 [[4](#ch2.xhtml#ref2_4)]。

### 2.2.1 物联网

物联网领域在融合物理世界和虚拟世界方面带来了显著的转变 [[4](#ch2.xhtml#ref2_4)]。物联网使各种对象之间能够连接以传输和交换数据。组件网络包括传感器、电路、微控制器以及其他嵌入家用和办公电器、车辆和其他设备中的电子元件，并通过软件和网络连接实现使能。许多行业已实施物联网，包括医疗保健、交通运输、房地产、物流和酒店业 [[5](#ch2.xhtml#ref2_5),[6](#ch2.xhtml#ref2_6)]。工业 4.0 由物联网和服务互联网驱动，通过物、系统和用户的连接，已实现了数据的实时传输。必要信息的可用性有助于决策，并改善了产品开发流程和整个价值链 [[7](#ch2.xhtml#ref2_7)]。

物联网的实施伴随着挑战。其中一个主要问题是安全威胁和漏洞，特别是隐私和拒绝服务。各组织部门参与物联网开发和运营，给协调和实施正确的战略带来了挑战，从而导致规划和效率的提升 [[5](#ch2.xhtml#ref2_5),[8](#ch2.xhtml#ref2_8),[9](#ch2.xhtml#ref2_9)]。客户已接受新的物联网技术，这导致了他们需求和要求的变化。多种电器和物体正在数字化，需求也在增加。制造组织应实施新颖的策略和方法来开发物联网产品和服务，以提高效率和生产率 [[6](#ch2.xhtml#ref2_6)]。

### 2.2.2 增强现实/虚拟现实

增强现实和虚拟现实融合了虚拟世界和物理世界，通常为用户创造沉浸式体验。在工业 4.0 应用的开发过程中，虚拟对象可以在各种界面之间共享，使开发过程更易于理解 [[4](#ch2.xhtml#ref2_4)]。在利用增强现实界面的移动应用程序中，系统通过设备的摄像头可视化与用户进行通信。用户还将信息发送回系统，从而实现双向交互 [[10](#ch2.xhtml#ref2_10)]。

AR 为组织运营中的内部和外部流程都增加了价值。AR 促进了组织设计流程中各部门之间的协作和流程效率。AR 还增强了客户和利益相关者的体验以及面向潜在客户的营销活动 [[11](#ch2.xhtml#ref2_11), [12](#ch2.xhtml#ref2_12) 和 [13](#ch2.xhtml#ref2_13)]。在应用中实施 AR/VR 可带来多项益处，包括重新配置产品设计以适应其他目标、可视化开发中产品的配置、提高生产系统的安全性、改善用户与系统之间的交互、提供远程支持以及在安全环境中进行培训以提高生产率 [[14](#ch2.xhtml#ref2_14),[15](#ch2.xhtml#ref2_15)]。增强/虚拟现实应用使用多种媒体类型，包括文本、音频、视频、动画以及 2D 和 3D 模型来提供丰富的内容。它们还为用户提供沉浸式体验，营造出独特的环绕虚拟环境感觉，增强用户与系统的交互并延长其参与度 [[16](#ch2.xhtml#ref2_16),[17](#ch2.xhtml#ref2_17)]。辅助系统实施 AR/VR，为用户提供自助支持功能并帮助有一定限制的用户高效完成任务。这些系统面临的挑战之一是了解技术及其工作原理。对这些技术和系统的机遇与限制缺乏充分理解可能会限制潜在用户和客户对其的认可和利用 [[18](#ch2.xhtml#ref2_18)]。
