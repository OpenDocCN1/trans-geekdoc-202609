
为简化起见，我们已根据其效用将智慧城市的应用归类为各个领域。如[图 9.2](#ch9.xhtml#fig9_2)所示，它们大致按行业、能源、出行、生活服务和环境进行分类。在出行方面，智慧城市通过智能交通系统支持交通的基础设施，为避免交通拥堵，通过智能停车\[23–24\]进行适当的停车安排，通过 RFID 提供。这些电子泊车服务基于 NFC 技术运行，实现账单的便捷支付。智能交通管理通过附着于交通信号系统的传感器实现，这些传感器由交通管理部门持续控制和监控，数据由安装在交通信号系统上的传感器发送；这些传感器通过云端向相关部门发送持续的数据更新，从而帮助他们通过适当的实时数据分析管理交通\[[19](#ch9.xhtml#ref9_19)\]。

除此之外，还有其他与能源生成相关的应用，被称为智能能源，其中传感器附着于风力发电机和太阳能板，这些是生产可再生能源的主要来源。配备智能电表的智能电网能够轻松追踪能源消耗，而智能路灯则使智慧城市能够通过在需要时使用能源资源，并在稍后通过相关部门将其关闭来优化能源资源，相关部门能够远程访问、监控和管理这些资源。智能生活提供嵌入智能监控的智能家居基础设施\[[25](#ch9.xhtml#ref9_25)\]，该基础设施配备安装在家中的摄像头，用于监控其内部和外部周边，并在不确定和紧急情况下做出及时决策。除此之外，还有许多其他应用，例如公共安全系统，在自然灾害发生时通过提前提供信息并加以利用来确保生命安全，在盗窃、陌生人身体攻击时，这些系统也能追踪，从而为城市居民提供更好的生活质量。通过医疗保健服务、有效治理提供最先进的设施，通过适当的废物管理改善生活质量，并通过与这些应用相关的传感器生成的数据控制噪音污染、辐射水平和温室气体排放。除此之外，更好的就业机会通过嵌入网络物理系统的智能产业得以实现，这些系统可以监控工业内部连接的机器的健康状况。这样，我们就有许多与智慧城市相连的应用。

如前所述，智慧城市配备了传感器和执行器。传感器用于收集数据并将其传递到云端，而执行器允许设备采取行动，例如通过改变智能路灯系统中的路灯、限制漏水管道的水流等。通过利用驾驶员智能手机的 GPS 数据，可以更有效地进行智能交通管理以便理解；让我们考虑一个可以防止交通堵塞的场景。为了防止城市交通拥堵，从驾驶员处获取的数据通过云端发送给交通管理团队，后者会自动向驾驶员发送通知，建议他们选择替代路线。同时，交通控制中心的员工会被告知发送拥堵警报以缓解拥堵并重新规划部分交通；他们可以向交通灯执行器发送指令以改变信号，从而解决交通拥堵问题\[[23](#ch9.xhtml#ref9_23)\]。

随着智慧城市变得更加互联并拥有更复杂的数字基础设施，这些服务将变得越来越容易受到网络攻击。智慧城市的力量与它们最薄弱的环节一样大，即使是最小的弱点也可能被利用产生巨大影响。因此，政府必须更加关注网络安全并在威胁预防上投入更多资金。否则，随着黑客利用安全漏洞，政府将不断处于防御状态。另一方面，这些漏洞的来源是众所周知的。物联网设备安全问题，例如缺乏适当的加密和通过有线进行补丁更新，已是众所周知。尽管有大量建议说明如何使设备和支持架构安全，但问题仍然存在。尽管缺乏安全标准，制造商仍继续将不安全的产品和系统从生产线推向智慧城市解决方案，扩大系统攻击面\[[24](#ch9.xhtml#ref9_24) 和 [25](#ch9.xhtml#ref9_25)\]。

抛开以上所有讨论，如果这些设备被攻破，整个系统都可能被破坏，因此迫切需要在智慧城市整个生态系统中实施安全措施以控制任何异常情况。已有报道称交通信号灯被黑客入侵、智能电网被破坏、智能监控系统遭到攻击等事件。因此，我们不能以牺牲这些系统为智慧城市居民提供的便利为代价而忽视安全复杂性。我们已为智慧城市提出一个框架来解决这些网络安全问题，该框架在[第 9.4 节](#ch9.xhtml#sec9_4)中进行了讨论。
