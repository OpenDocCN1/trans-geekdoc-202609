
底层三种工业革命被描绘为由程序化创造处理，预期水力和蒸汽动力、大规模劳动和电力使用，以及独立的电动、自动化创造。虽然旨在推动德国经济的工业 4.0 最初于 2011 年提出，但这场工业叛乱被描述为依赖于为通信而配备的 CPS 的使用以及制造自管理，并非真正致力于提高机械能力、生产率、安全性和透明度 \[[10](#ch8.xhtml#ref8_10)\]。工业 4.0 是制造和相关事业以及可用形成行动的进步变革。工业 4.0 被用作第四次机械动荡，它反映了现代组织和力量的更多层面。工业 4.0 是一个幻想和思想，运行在凭证结构、标准化和甚至在移动中的解释上。大多数工业 4.0 驱动是起步阶段的预测，范围有限。事实上，大多数数字化尝试发生在与第三和令人惊讶的第二次当前爆炸性进展/目标相关的情况下。在认识工业 4.0 时，认识完整价值链至关重要，该链整合了供应商和为多种智能制造所需的特定规格和部件的起点、从始至终的先进供应链管理，以及所有参与者的最终目标，即奖励微小思想，相当于奖励核心个人进步和参与者：终端客户。工业 4.0 是在大数据、人员、流程、组织、结构和物联网支持的当前服务相关环境中，对制造（和相关事业）的信息增强型变革，通过生成、影响和操纵重要数据和信息作为途径和计划，以实现智能产业和机械发展与协同努力的自然框架。因此，工业 4.0 是一个宽泛的愿景，具有清晰的结构和凭证计划，从根本上由真实现代资源和自动化发展在假设的数字化真实结构中融合所描述 \[[11](#ch8.xhtml#ref8_11)\]。工业 4.0 的一个确定部分是来自效率提升和新安排的价值创造影响，然而，创新变革可能对企业产生积极和消极的影响 \[[12](#ch8.xhtml#ref8_12)\]。[图 8.5](#ch8.xhtml#fig8_5) 显示工业 4.0。

## 8.8 工业 4.0 历史

*   第一工业革命
*   第二次工业革命
*   第三次工业革命
*   第四次工业革命

### 8.8.1 第一次工业革命（工业 1.0）

第一次工业革命发生在十八世纪，生产中使用了蒸汽动力和自动化。以前在不变的交换轮上制造线，而机械化设计在相近的时间内通过多个阶段实现了它。蒸汽能量当时已为人所知。其用于工业目的的应用是提高人类效率的巨大飞跃。或许比由力量驱动的材料漂移，蒸汽机可以被利用于能力。诸如蒸汽船或（近 100 年后）蒸汽驱动的火车等改进也实现了在更少时间内运送更多人员和物品的巨大提升。

### 8.8.2 第二次工业革命（工业 2.0）

第二次工业革命始于 19 世纪，大致围绕电力开放和结构形成连续演进。亨利·福特（1863–1947）从芝加哥一家屠宰场实施了装配线技术：猪从传送带上悬挂，每个屠夫只完成破坏动物的任务的一部分。亨利·福特将这些原则带入汽车制造并同时对其进行了内在转变。以前一个停靠点组装整辆汽车，而从那时起，汽车在生产线上分阶段制造——完全更快且价格更低。

### 8.8.3 第三次工业革命（工业 3.0）

第三次工业革命始于 20 世纪 1970 年代，在使用存储器可编程控制和计算机的不完全自动化中。在这些进步的考虑下，我们当时被组装起来在没有人类干预的情况下强行完成整个制造过程。这种熟悉的例子是机器人执行在没有人类干预的情况下重新排序的序列。

### 8.8.4 第四次工业革命（工业 4.0）

我们目前正在完成第四次工业革命。这被数据和相关广告对工业的利用所描述，基本上被称为“工业 4.0”。它发展了第三次工业革命的改进。制造框架目前已通过联盟添加的计算机发展扩展，并在互联网上具有电子双胞胎，形象地说。这些授予与各种机构的关系并放弃关于自身的细节。这是在高级自动化中的下一个水平。所有框架的结构关联产生“高级真实制造系统”，从而产生智能工业设施，其中制造框架、片段和人员通过关联进行通信，制造基本上是自调节的。

当这些使能碰撞聚集时，工业 4.0 可以在生产线条件下实现一些令人惊叹的进步。示例包括可以预测故障并自主激活维护措施的设备，或自我运作的协作，能够对进展中的惊人变化做出反应。

此外，它可以改变人们管理的方式。工业 4.0 可以将人们推向更聪明的协作关系，具有大量有益功能的能力。社交环境数字化的制造考虑了在最佳时间为最佳个人获取正确数据的更灵活方法。制造线内部最先进设备的不断实施决定了在现场，如果维护专家可以在经典方式下获得设备验证和关联历史，并在使用地点。维护专家预计将处理问题，而不是玩耍并尝试从一开始就获得所需的具体信息 \[[13](#ch8.xhtml#ref8_13)\]。

因此，工业 4.0 是工业环境的无可置疑的优势。社交活动的数字化将改变物品的构建和分发方式，以及物品的升级和解释方式。就这一点而言，它可以真正促进一个抵制第四次工业革命诞生的位置。[图 8.6](#ch8.xhtml#fig8_6) 显示工业 4.0 模板。
