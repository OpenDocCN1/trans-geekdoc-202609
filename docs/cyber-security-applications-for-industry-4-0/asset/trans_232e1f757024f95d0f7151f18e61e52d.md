
雾计算：云计算服务转移到最近的云，即所谓的边缘网络，被称为雾计算。雾计算有助于在本地设备、终端设备和数据中心之间平衡负载，具有低延迟、快速响应、性能提升以及整个系统的可扩展性。因此，雾计算在最小化用户与数据中心之间的响应时间方面发挥着至关重要的作用。除上述技术外，增强现实、仿真、开源软件技术、人机交互（HCI）和人工智能也为工业4.0的整个网络增添了重要意义，用于分析物理系统并以实时数据通知相关部门，从而降低成本并提高整体系统的效率，而这一整套机制带来了更好的性能和更好的实时决策策略，使组织能够实现更好的经济效益。由于整个网络通过 CPS 系统连接，整个系统的安全性将成为主要关注点；因此，为了实现这一点，网络安全在保护和保障整个系统免受安全漏洞侵害方面发挥着至关重要的作用，而区块链技术为解决这些安全相关问题提供了最佳解决方案 \[[30](#ch7.xhtml#ref7_30), [31](#ch7.xhtml#ref7_31), [32](#ch7.xhtml#ref7_32) 和 [33](#ch7.xhtml#ref7_33)\]。

## 7.5 工业4.0 问题与挑战

过去，制造系统是封闭的，其安全性得以保障，因为它们处于隔离状态，其物理访问由负责监督和操作的人员控制，但现在，随着工业4.0技术的出现，制造系统已被技术进步所取代，其中现代制造业已通过机器实现自动化，这些机器相互连接并嵌入智能设备，如传感器和执行器，这些设备通过有线或无线网络系统连接以使用特定协议处理数据，而这些协议不足以提供对网络威胁的保护。这些不足使制造系统容易受到网络攻击，攻击者可未经授权访问组织的有关数据 \[[34](#ch7.xhtml#ref7_34)\]。工业4.0中的关键资产是工业控制系统、IIoT、IIoT 网关、传感器和执行器 \[[35](#ch7.xhtml#ref7_35)\]。IIoT 网关管理涉及有线和无线技术的多种通信技术，并应用各种协议。此整个场景中所涉及的威胁包括数据保密性、数据完整性和可用性的丧失 \[[36](#ch7.xhtml#ref7_36)\]。根据科学文献的显示，在国防、安全、航空航天、化学工程、建筑、汽车、电子运输、工业制造等各个工业化领域投入了大量资金。这为工业增长提供了巨大动力，其中新产品在更短的时间内进入市场；客户响应能力大幅提高，并且在不增加整体生产成本的情况下实现了大规模生产。这创造了一个灵活且更友好的工作环境，并有效利用能源和自然资源。尽管工业4.0通过自动化工厂中的生产单元并使这些工厂智能化，为工业化制造业的自动化铺平了道路。智能工厂是原材料进入生产单元并加工成成品的地方，成品从生产单元离开直至到达最终用户或客户，几乎不需要或完全不需要人工干预。价值链的整体自动化是通过这一复杂过程中涉及的各种技术实现的。由于整个过程通过 CPS 实现自动化，存在很大的安全风险，如果忽视可能导致系统失败，从而使整个过程变得徒劳。提供和实施严格的安全机制被认为是工业4.0这一整体范式中最具挑战性的问题之一，如 [图 7.1](#ch7.xhtml#fig7_1) 所示。除这些安全问题外，其他挑战还包括互操作性，这是由于异构网络的参与所致。

从设计和制造到供应链和服务维护的工业运营自动化，借助互联和智能的 CPS 被设想为工业4.0。在这个互联世界的整体繁荣中，网络攻击呈指数级增长，对企业绩效产生负面影响。工程雇主联合会进行的一项研究显示，使用基于工业4.0的 CPS 的制造商中有约 48% 报告称他们是网络安全攻击的软目标，其中 48% 称遭受了严重的财务损失 \[[36](#ch7.xhtml#ref7_36)\]。

由于制造业涉及通过智能设备和计算机连接到网络的机器，它们很容易成为网络攻击的目标，这些攻击可能通过破坏连接到该网络的全部机械组成的关键基础设施来损害组织。除此之外，系统所涉及的网络和计算机都可能遭受拒绝服务（DoS）攻击；最后，不能忽视的是，与商业秘密和知识产权相关的数据盗窃也是组织的一大关注点；所有这些因素在经济方面对组织的增长都有相当大的影响。

工业4.0的影响已扩展到人类生活的各个方面，包括个人、社会、企业、政府和教育部门；因此，这一新范式面临的首要挑战和问题是法规，因为如果没有适当的监管机构，系统就无法运行，工业4.0也无法运行；除常规机构外，还需要标准化，从而制定与通信、行业、产品、服务以及与市场相关的商业模式相关的新的标准。为了使行业为工业4.0做好准备，多个国家已采取了许多举措，但仍存在与其准备度相关的问题，包括成本、可持续性、能源效率、经济、工作环境以及组织员工技能发展等方面 \[[13](#ch7.xhtml#ref7_13),[37](#ch7.xhtml#ref7_37),[38](#ch7.xhtml#ref7_38)\]（[图 7.4](#ch7.xhtml#fig7_4)）。
