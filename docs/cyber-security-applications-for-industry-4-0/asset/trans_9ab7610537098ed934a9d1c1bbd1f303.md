
术语“Industry 1.0”是在 18 世纪通过利用蒸汽动力和生产系统的自动化而创造的。Industry 2.0 在 19 世纪被提出，得益于电力的发明和装配线生产，其流程与早期版本相比大大改进了自动化。Industry 3.0 版本在制造业引入了半自动化。机器人被用于减轻许多任务中的人力负担。Industry 4.0 面向的是希望消除在协作和共享数据和信息方面所面临障碍的制造业部门（[Erboz, 2017](#ch3.xhtml#ref3_18)）。Industry 4.0 在制造业实施自动化的同时增强了数据交换应遵循的流程和方式。Industry 4.0 的关键部分之一是在装配区域保证成本效益。Industry 4.0 包括以下领域：工业物联网（IIoT）、物联网（IoT）、智能工厂、人工智能和云计算，以及大数据。用于自动化的整个设备组件都相互连接并与人类互动。这种互联设置被称为网络物理系统（CPS）。网络组件与用于控制和监控流程的基于计算机的算法相关联。[表 3.1](#ch3.xhtml#table3_1) 显示了工业革命（IR）从 1.0 到 4.0 的演进版本及其缺点，同样在 [图 3.1](#ch3.xhtml#fig3_1) 中以图形方式呈现。

由于整个装配措施都依赖于机械化保证，安全性对企业而言是一个重要观点。Industry 4.0 的核心设计方面是解决兼容性问题、去中心化、虚拟化和透明度。在实施核心设计方面时，对设置环境的方式缺乏了解造成了大部分安全漏洞（[Anisetti et al., 2020](#ch3.xhtml#ref3_7)）。根据 IBM X-Force 威胁情报指数 2018 年的数据，33% 的各类攻击针对制造业部门。在智能制造环境中，最常见的攻击是拒绝服务（DoS）攻击、恶意软件威胁、中间人（MITM）攻击和侧信道攻击。

如今，Industry 4.0 的主要挑战是在其不兼容的关键组件之间确保安全。自然地，互联设备在确保隐私和信任方面面临困难。确保隐私可防止未经授权访问机密信息。为了实现隐私，采用了加密算法 ECDSA（椭圆曲线数字签名算法）、MPC（多方计算）和轻量级加密算法。另一个安全方面是组织难以防止通过破坏完整性而发生的行动中的漏洞。在信任方面，哈希函数已很好地集成到系统中。除此之外，为了在人们之间建立信任，我们使用不同类型的模型。数据泄露的可能性在产品部署过程获得收入之前就使其瘫痪，并对工业经济产生不利影响（[Chiu et al., 2017](#ch3.xhtml#ref3_12)）。在 IR 4.0 的背景下，任何信息都是有价值的，也可能被黑客攻击。行业巨头 Centrify 和 Palo Alto Networks 实施零信任策略，与特权访问方法相矛盾。传统的特权访问方法不足以应对当前趋势，其中高级持续性威胁正在激增。特权访问方法不仅需要涵盖数据库和互联设备，还需要扩展到大数据、云环境和自动化应用程序。Zero trust 特权的核心理念是授予用户最少的权限，而不是忽略它们。用户请求可以根据请求的访问、请求的上下文以及计算环境的潜在风险进行验证。通过最小权限访问，可以在一定程度上将对行业运营的可能攻击降至最低，改善审计并降低企业的复杂性和成本。因此，确保 IR 4.0 的安全方面对于从各种角度改进运营至关重要。因此，本章试图总结因破坏各种安全措施而导致潜在漏洞以及使用区块链技术（BCT）缓解威胁的可能解决方案。第 3.2 节讨论了 Industry 4.0 的多个关键组件。第 3.3 节尽可能总结了每个关键组件固有的挑战。此外，还探讨了每个组件中预期的可能安全挑战。第 3.4 节讨论了各种最先进的行业应用，旨在在智能城市迁移之前改善人类生活质量。第 3.5 节讨论了 BCT 如何被用于提高 Industry 4.0 中各种应用的安全措施。第 3.6 节总结本章。

### 3.2.1 CPS and IoT

Industry 4.0 提供了未来技术和制造业的优势。[Oztemel and Gursev (2020)](#ch3.xhtml#ref3_40) 认为它是计算和物理组件的集成。CPS 的开发分为三个阶段。

* CPS 结合了诸如 RFID 标签等识别技术，可实现非凡的识别能力。存储和分析应作为核心支持提供。
* 对于特定传感器和执行器，CPS 配备的功能较少。
* CPS 设计了许多传感器和执行器以实现网络兼容。
