
在这里，产品和机器将成为物联网中的积极参与者，并定期相互通信。这种开放的环境高度不安全，很容易受到主动和被动攻击的影响，并且随着工业 4.0 的到来，攻击范围变得更大，而检测的可能性却更低。

最大的问题在于网络安全被视为一种特性，而未在设计阶段予以考虑；存在一种误解，即网络安全可以在后期作为产品或服务购买，并且现有威胁并未得到充分认识，常被忽视，因为行业报告并不多，因此存在一种重大误解，即黑客可能不够先进。

一个特别将智能制造系统与传统 IT 系统区分开来的关键因素是，制造系统是为长期运行而设置的，通常使用寿命长达 20 年，大多数设备都是遗留系统，为了使这些系统保持最新，必须定期进行补丁更新，而这正是大问题所在。

为了对系统进行补丁，生产必须停工，这会导致生产停机造成损失，并产生额外成本；这就是为什么系统所有者不愿频繁打补丁的原因，正如 Wannacry 攻击中所发生的那样，未打补丁的系统变得脆弱，并可能被利用 \[[11](#ch1.xhtml#ref1_11),[12](#ch1.xhtml#ref1_12)\]。

从历史上看，我们看到在为已暴露的漏洞发布补丁时，系统有时已被利用的情况，另一个问题是执行补丁过程需要专业技能。

系统是为最佳性能而设计的，但系统安全并未与该优化集成，而是被忽视，并计划通过供应商作为服务纳入，因此大多数系统只有很少的安全措施，如默认密码、无访问控制和未记录的后门。

Potteiger 等人（2017）\[[44](#ch1.xhtml#ref1_44)\] 在一个紧密模拟 CPS 的平台上进行了测试，并表明铁路运输网络中存在的漏洞可能导致大量列车延误，其影响会传播到物理世界并影响相关乘客。研究人员使用中间人攻击执行了数据包延迟攻击，并结合了 DoS 与中间人攻击的组合。在仅使用中间人攻击的第一种情况下，攻击者能够将数据包延迟 20 分钟，导致目标列车延误；另一方面，当同时利用中间人攻击和 DoS 攻击时，攻击者能够破坏多个列车（其示例中为六列）时刻表的整体运行。

Humayed 等人（2017）\[[45](#ch1.xhtml#ref1_45)\] 将 CPS 安全的基本要求确定为数据保密性、信息完整性、可用性、身份验证、不可否认性和隐私保护。研究人员概述了网络信息层面临的各种威胁、基础设施安全威胁（如设备损坏或故障和物理损坏），并列出了跨三个方面的各种信息安全威胁，即物理层威胁、信息层威胁和应用控制层威胁。

Singh 和 Jain（2018）\[[46](#ch1.xhtml#ref1_46)\] 将安全性和隐私性突出为 CPS 的关注问题，并指出以安全方式管理由互联设备产生的大数据也是一项具有挑战性的任务。作者承认的其他挑战包括设备安全和数据传输安全。研究人员确定了 CPS 中的若干漏洞，包括与网络、平台、硬件以及软件相关的漏洞。还列出了若干技术和管理漏洞。作者认出的若干威胁包括恶意软件、密码攻击和网络攻击等。

Nair 等人（2019）\[[47](#ch1.xhtml#ref1_47)\] 将隐私、安全、系统互操作性、上下文感知和系统设计确定为医疗信息物理系统（MCPSs）中的挑战。研究人员将数据泄露、勒索软件攻击、社会工程攻击和内部攻击确定为 MCPS 领域的主要威胁。他们还指出了在 MCPS 执行器系统中安装 IDS 的困难。

系统传统上是在不纳入安全性的情况下设计的，或假设系统是隔离的，因此是安全的。安全的软件开发流程未被考虑。

不良的安全实践和政策也是引入漏洞的原因之一；工业控制系统使用不安全的通信协议，甚至没有支持身份验证的能力。显而易见且广为人知的良好实践并未像人们通常期望的那样得到遵循。

对这些系统发动攻击通常有两个动机：一是通过破坏系统的正常运行从受损系统中窃取个人和/或敏感数据以敛财，另一个是政治动机。

## 1.5 安全措施

目前存在两种类型的安全解决方案，即静态防御和主动防御。

为了确保静态防御，必须制定适当且更新的安全法规、标准、政策和指南，为了确保主动防御，必须采用加密技术，因为 CPS 中的设备持续相互通信。

必须部署入侵检测与预防系统，该系统能够有效检测已知攻击，同时具备对可疑流量进行智能分析的能力，并准确检测恶意攻击并阻止其发生。

Eigner 等人（2016）\[[48](#ch1.xhtml#ref1_48)\] 设计了一种基于异常的攻击检测方法，该方法利用理想状态下的正常系统行为作为训练数据，并将其与正在进行的系统活动进行比对。该方法在检测中间人攻击方面效果良好，因为系统行为持续被记录，当攻击发生时，操作会被记录客户端捕获，并提取和分析所需特征。最后，通过检测异常值将未标记数据分类为异常。该模型能够将攻击分类为异常，因为当攻击者拦截消息并转发修改后的消息时，会产生额外的传输时间，从而形成与正常情况不同的模式。

Gokarn 等人（2017）\[[49](#ch1.xhtml#ref1_49)\] 提出了一种异常检测系统，利用卡尔曼滤波增强电网的安全性。在其方法中，他们使用电力系统分析工具箱（PSAT）作为训练数据，该数据被送入 SCADA 解析器，然后输入卡尔曼滤波器，滤波器产生估计数据并存储到知识库中，从而建立知识库。对于实时场景，任何传入数据都会发送到解析器，解析器将其传递给卡尔曼滤波器，滤波器的输出与知识库进行比较以判断其是否为异常，如果发现异常则触发警报。实时数据也会进入知识库，从而不断改进分类模型。
