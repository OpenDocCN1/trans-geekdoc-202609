
数字技术的发展为智能产业创造了大量机会。旨在实施智能流程的行业缺乏相应的协议。Da Silva 等 (2020) 从不同渠道总结了行业可能的科学流程。除了对各种智能流程的回顾外，作者还强调了不同行业中报告的障碍。论文报告称，由于缺乏足够的资金支持、基础设施短缺以及领域专家指导，行业面临问题（[Khan 等, 2020](#ch3.xhtml#ref3_30)）。趋势技术以及 `IoT` 的应用为 `IIoT` 铺平了道路。`IIoT` 为制造业中的 `IoT` 创造了新的愿景。新启用技术如 `Blockchain` 和 `Cloud Computing` 被部署以确保行业面临的稳健性、灵活性和信任。为了让读者了解 `IIoT`，给出了一个精确的定义。作者描述了在 `IIoT` 中开展的基准研究工作。最终，`IIoT` 的使能智能技术及其固有挑战也被总结。

行业希望按照 `PSS`（产品-服务系统）的模式转变其业务性质。[Gaiardelli 等 (2021)](#ch3.xhtml#ref3_23) 识别出能够丰富 `PSS` `IR4.0` 形态的主要特征。`PSS` 中有四个衡量标准推动了工业 4.0 的发展：（1）价值主张体现，（2）客户价值体验，（3）价值创造机制，（4）以及价值创造互动。这里的主要思想是在理论和实践两个层面研究关于 `PSS` 以及工业 4.0 采用的进一步发展和讨论。这种整合的优点将新技术纳入考虑并获得了专家的反馈（[Moeuf 等, 2020](#ch3.xhtml#ref3_37)）。作者讨论了工业 4.0 的关键成功因素以及相关的风险和机遇。为了在 `SMEs`（中小企业）中实现工业 4.0 的因素、风险和机遇等目标，作者引入了 Delphi–Régnier 研究。Delphi”s 研究陈述了专家对特定主题的意见。Régnier”s 研究提出了一种工具，该工具使用基于专家意见的类似交通信号灯的颜色面板；80% 的专家同意在工业 4.0 的 `SMEs` 中使用该技术。

`IR4.0` 和 `IIoT` 为当今行业实现更大改进铺平了道路。制造业使用的互联设备由于安全方面的设备配置不当而遭受安全漏洞。在线工具 `Shodan` 被使用（[Fernández-Caramés & Fraga-Lamas, 2020](#ch3.xhtml#ref3_20)）作为工业 4.0 和 `IIoT` 网络安全的实践教学方法。检测和防止对 `IIoT` 设备的 `Shodan` 攻击为工程毕业生创造了一个良好的学习平台。了解安全违规的影响。作者通过用例指导学习网络安全和 `IIoT` 的方法（[Aheleroff 等, 2020](#ch3.xhtml#ref3_4)）。在本文中，作者通过数字化转型指定了一种 `IoT` 启用的智能家电——以智能冰箱作为工业 4.0 下基于 `IoT` 的家电 SPS 框架的案例研究。智能冰箱——在通信信号和 `IoT` 网络的帮助下——通过 `Wi-Fi` 或 `Bluetooth` 激活，以便监控和控制冰箱制冷和温度水平、执行器和冰箱循环变得容易（[Geng, 2017](#ch3.xhtml#ref3_24)）。此类设备是可行且经济实惠的。但向现有设备添加该功能会花费更多时间和成本。

趋势技术如 `SDN-IoT` 和 `Blockchain` 被整合以构建新的架构，即 `DistB-SDoIndustry`，为 `IoT` 设备提供更好的安全性。[Rahman 等 (2020)](#ch3.xhtml#ref3_46) 提出的架构足以抵御基于数据包的攻击，如 `DoS`、Flooding Attacks 和数据包的时间持续时间。所提出的架构使用 `BCT` 进行数据验证和验证。与传统模型相比，故障率已显著降低。因此，新技术促进了效率、保密性和更高吞吐量的实现。[Serror 等 (2020)](#ch3.xhtml#ref3_49) 提出了针对 `IIoT` 预期可能的安全漏洞。所提出的报告重点关注 `IIoT` 价值链的安全性，考虑设备和工业数据。对于 `IIoT`，保密性、不可否认性、完整性、隐私性和可用性等安全方面需要在通信渠道和数据上得到保障。因此，作者总结了在安全漏洞中工业 4.0 应用的挑战和要求。

[Costa 等 (2020)](#ch3.xhtml#ref3_14) 提出了 `FASTEN IIoT Platform`，以提供 `IIoT` 应用的适应性、可配置性和开放性优势。`FASTEN IIoT` 为工业 4.0 应用提供直观的界面。在 AI 进步设备的光下，获得安全且有效可信的信息共享。所介绍的阶段包括三个支柱：（1）自动化机器人和制造单元，（2）开放的 `IIoT` 平台，（3）用于预测建模的实时环境。

### 3.4.2 工业 4.0 的智能项目

有一些项目正在运行以实现工业 4.0 的整体数字化。

这些项目由各个政府部门以及行业合作伙伴赞助。资金由中小企业提供（`SMEs` 关注特定的数字化转型）。此类项目主要关注为工业 4.0 实施获得战略和组织努力（[Oztemel & Gursev, 2020](#ch3.xhtml#ref3_40)）。工业 4.0 中突出的智能项目（[图 3.5](#ch3.xhtml#fig3_5)）是 `ENTOC`、`ARIZ`、`SOPHIE`、`e-F@CTORY`、`PLANSEE`、`ESIMA`、`OPAK`、`FUSION`、`#1 Smart (SMT) factory`、`INESA Smart Factory`、`AWS IoT` 和 `ParisFAI40`。

![图 3.5 工业 4.0 项目。](images/fig3_5_B.jpg)

[图 3.5 工业 4.0 项目。](#ch3.xhtml#R_fig3_5)

*   项目 `ENTOC` 的目的是使工程流程的结果成为更简单且更连贯的模拟排序。该项目主要为工业 4.0 中的自动化提供仿真和组件描述所需的工具。
*   `ARIZ` 也称为‘“Future Industry Work’”并专注于安全的人机协作机器人，主要用于工业生产场所。
*   `SOPHIE` 主要用于将真实生产与数字工厂结合的实时应用。
*   `E-F@actory` 的主要目标是在全球产品制造商之间建立灵活的连接。该项目有助于世界更快地沟通并提高技术的稳健性。
*   `PLANSEE` 是工业 4.0 项目之一，用于自主开发工厂。
*   `ESIMA` 项目用于优化生产系统中的资源效率。
*   `OPAK` 项目旨在实现具有数字记忆的简单制造工艺和机制。
*   `FUSION` 旨在鼓励亚洲和欧盟国家之间的合作活动。
*   `#1 Smart (SMT) factor` 项目将允许制造商在未来的硬件组织中提供更智能、更适应的设备。
*   `INESA smart factory` 的主要目标是与智能制造公司一起建设智慧城市。该项目主要使用大数据和 `IoT` 来解决制造设备中的无错误问题。
*   `AWS IoT` 用于在 `AWS` 端点之间以及与不同设备之间可靠、安全地路由消息。
