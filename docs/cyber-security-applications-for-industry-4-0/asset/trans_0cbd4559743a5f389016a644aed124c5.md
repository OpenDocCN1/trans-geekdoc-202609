
攻击的本质很直接——它利用用户数据报协议的无连接特性，通过伪造即将成为受害者的 `IP` 地址向互联网上已识别的、配置错误的开放服务器发送伪造请求，服务器随即向受害者发送大量放大的响应，受害者无力应对，因为其正常服务最终因服务器被大量请求过载而被拒绝，并且鉴于这些服务器的放大因子，攻击者只需发送定制的短查询即可实现大量操作，这些查询会从服务器产生巨大的响应，并且鉴于攻击的分布式特性，不言而喻的是，有多个分散的僵尸网络在伪造受害者的 `IP` 地址，不断重复该查询。此举使得攻击者的行踪无法定位，同时应对也并非简单地阻止特定连接，因为该攻击利用了多个僵尸网络，并且由于攻击者的 `IP` 地址被伪装成与受害者的 `IP` 地址相同，服务器无法区分它们，因此命名为反射攻击是合适的。

攻击发生在 `UDP` 端口 `389` 上，避免此类 DDoS 攻击的一个良好对策是为特定端口设置流量限制并采用加密的 `LDAP` 配置，不应有任何开放服务器保持配置错误，因为这会招致未来的 DDoS 攻击，应部署正则表达式过滤器以检测这些攻击的常见模式并在早期阶段阻止它们。

### 1.3.3.4 2018 GitHub DDoS 攻击

2018 年 2 月 28 日，发生了迄今为止最大规模的 DDoS 攻击之一，攻击目标为 `GitHub`。攻击持续了 10 分钟。在攻击的第一部分，1.35Tbps 的流量在 17: 21 UST 至 17:26 UTC 之间袭来，第二部分从 17:26 至 17:30 UTC，峰值达到 400Gbps。在其峰值时，流量达到每秒 126.9 百万个数据包，这一虚假请求导致 `GitHub`(dot)com 崩溃。基于 `UDP` 的 `Memcached` 流量是此次攻击放大的原因。它是一种数据库缓存系统，旨在加速网站和网络。它通过突然的大量流量涌入淹没目标系统，以使其服务器崩溃或挂起 \[[27](#ch1.xhtml#ref1_27)\]。

Akamai Prolexic 被召来稳定局势。经调查发现 IP 地址已被伪造。流量被重新路由，恶意代码补丁被移除，被阻止的数据得以恢复。因此，在八分钟后，袭击得到稳定，DDoS 在处理了各种异常后停止。中国政府曾被广泛怀疑是此次攻击背后的主导力量。因为有几个项目，中国政府曾多次要求从该网站上移除。由于审查不成功，其意图是攻击并向 `GitHub` 施压，要求其删除这些项目 \[[28](#ch1.xhtml#ref1_28)\]。

为防止类似未来事件而采取的措施包括以下内容：
1. 各种自动化步骤已在考虑到未来条件的情况下采取。减少人工依赖将确保这种新型开源的顺畅无忧使用。
2. 已提出监控基础设施，以便 DDoS 缓解提供商能够在攻击期间衡量和分析影响，从而保护自身。这将确保平均恢复时间 (`MTTR`) 减少 \[[29](#ch1.xhtml#ref1_29)\]。
3. 网络架构已改进并扩展，增加了多个新层，并增加了功能以在网站工作流程受影响之前识别并减轻新的攻击尝试。需要定期备份数据以确保安全和保障。为了维护其客户和用户的信任，存储在其网站上的文档和项目包括更好的有效安全层。
4. 此外，已承诺定期进行软件增强更新，以建立更好的检测系统并增强流畅响应。

## 1.3.4 中间人攻击

中间人攻击是一种攻击，攻击者在其中拦截两个通信方之间的通信，其动机是窃取个人信息，包括登录凭证、银行账户详细信息和信用卡号码等。监视受害者以破坏通信或破坏敏感数据也可能是其意图。这些攻击大多针对金融部门、SaaS 业务、电子商务网站以及涉及登录和支付交易的某些其他 Web 应用程序 \[[30](#ch1.xhtml#ref1_30),[31](#ch1.xhtml#ref1_31)\]。

据 Netcraft 于 2016 年报道，超过 95% 的 `HTTPS` 服务器容易受到 `MitM` 攻击。这些攻击并不像勒索软件攻击那样常见，但它们对组织构成威胁。IBM 的 X-Force 威胁情报指数 2018 报告指出，约 35% 的利用直接或间接涉及 `MitM` 攻击。只有 10% 的公司已将其服务器防范于 `MitM` 攻击之外。造成的损害因攻击者的意图和能力而异 \[[32](#ch1.xhtml#ref1_32)\]。

它是最古老的网络攻击形式之一，至今仍然盛行。最早已知的中间人攻击可以追溯到 1586 年，当时皇家秘密特工挫败了一项暗杀时任伊丽莎白一世女王的政变，肇事者被当场抓获 \[[33](#ch1.xhtml#ref1_33)\]。

古列尔莫·马可尼发明无线电传输通信后，这种主要的通信方式面临严重的 `MitM` 攻击威胁。自那时起，事件数量激增 \[[34](#ch1.xhtml#ref1_34)\]。

英国情报部门利用此次攻击破解了恩尼格玛密码，从而能够阻止纳粹的威胁和攻击。这正是导致阿道夫·希特勒在第二次世界大战中战败的主要原因。

2013 年，爱德华·斯诺登披露了 NSA 利用 Quantum/FoxAcid 中间人攻击系统泄露用户信息的企图。联想于 2014 年在其 Windows PC 上安装了 Superfish，一种 `SSL` 劫持广告软件。2015 年对英国 Lupton 夫妇的电子邮件劫持/窃听攻击使他们损失超过 340,000 欧元 \[[35](#ch1.xhtml#ref1_35),[36](#ch1.xhtml#ref1_36)\]。此类事件经常发生，影响程度各不相同。

之所以使用这种攻击，是因为它使攻击者能够轻松欺骗目标并获取所有敏感信息。攻击方法有很多种，可以增加成功入侵的机会。这种攻击已使用了几个世纪，至今一直是黑客的最爱。能够将自己伪装成原始服务器和服务提供商的能力是主要优势，有助于他们在不被怀疑的情况下实施攻击。此外，迄今为止，这种攻击已影响了大量目标。

攻击者识别目标，然后尝试拦截连接。在某些情况下，连接通过加密得到保护。根据目标和目标选择一种技术，从广泛的方法中选择。攻击者监控目标的对话。欺骗、劫持、窃听和拦截是攻击者可用的一些选项。在目标与其他端之间进行对话时，攻击者拦截对等方之间的消息。成功拦截后，攻击者窃取敏感信息、篡改消息等。遗憾的是，在某些情况下，攻击者甚至能够绕过多因素身份验证，从而窃取凭证。
