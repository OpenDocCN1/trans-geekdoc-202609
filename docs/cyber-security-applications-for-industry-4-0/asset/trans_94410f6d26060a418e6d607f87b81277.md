# 前言

> “我真的认为，如果我们改变自己对待可用资源的方式和思维，这将解锁我们在安全领域真正出类拔萃的能力。这是一项视角练习。如果充裕是现实而不是资源受限，会是什么样子？”
>
> **\-Greg York，Tribune Media 信息安全副总裁，在 SecureWorld Chicago**

第四次工业革命（工业4.0）探索了传统制造和控制系统的数字化。工业4.0被认为是“赛博物理系统（CPS）”的曙光，其中完全涉及研究人员和相关人员的创新能力。今天，部署在工业控制系统中的 CPS 和物联网设备是与缺乏足够数据操作安全控制的传统仪器协同运行的混合机器。与工业4.0系统相关的风险和威胁将为潜在的攻击面和攻击向量创造途径。本书系列旨在为学术和专业研究人员提供 CPS 及其安全漏洞的详细回顾、分析和研究，从而开辟新的路径。

《工业4.0网络安全应用》（CSAI 4.0）的编辑旨在为计算机科学、机械、电气和电子工程等综合工程学科出版此书。它涵盖了 CPS 的概念性观点，包括当前的技术革命、挑战以及 CPS 与物联网和能源系统的融合。本书的章节将汇聚工业的各个部门。CPS 的融合结构为学术和教育领域做出了贡献，以为医疗保健、农业和电网应用提供无缝的实用解决方案。我们收到了来自不同作者的20章，创建了一个在学术界、工业界和研究团体之间持久的技术平台。在仔细审查所有投稿后，十章被选中并考虑出版。

本书分为十章，具有以下主要特点：
* 涵盖赛博物理系统的原理
* 对工业4.0最新发展的讨论
* 对多元化领域技术进步的审议
* 为旨在全面了解 CPS 的本科生、研究生和博士生提供充足内容。
