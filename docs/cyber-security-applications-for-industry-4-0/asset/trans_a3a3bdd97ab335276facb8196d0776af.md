## 8.1 Introduction

物联网（IoT）是一种利用互联网连接实际设备或“物”的新创新。家用电器和机械硬件是实际设备的例子。这些设备可以通过使用适当的传感器和通信网络提供重要信息并使消费者获得各种服务。例如，以智能方式控制建筑物的能源消耗，可以降低能源费用。物联网可在多个行业中使用，包括制造、物流和建筑。除了环境监测外，物联网在医疗保健系统和服务、无人机服务以及建筑物的智能能源管理中也越来越被使用。在创建物联网应用时，物联网部件（如探测设备、通信协议、信息存储和计算）的确定应适合预期应用，这是设计物联网系统的初始阶段。这些在工业中的应用在技术上被称为工业物联网（IIoT）。IIoT 或第四次工业革命或工业 4.0 通常是指在商业环境中使用物联网技术所赋予的名称。工业 4.0 是一种具有明确结构和显著规划的广泛视野，从根本上描述了所谓先进物理结构中现实当前优势与自动化发展之间的交叉。中小企业（SMEs）是根据投资规模进行分类的企业，它们存在于经济体的制造业和服务业部门。IIoT 对中小企业中的智能制造系统（SMSs）具有最大影响。

## 8.2 Internet of Things

物联网指的是相互依存、基于网络的事物的方法，这些事物可以在没有人工干预的情况下通过远程连接收集和传输信息 \[[1](#ch8.xhtml#ref8_1)\]。物联网代表了所谓的“物”的联合，即配备了执行器、程序和各种技术用于与各种设备和系统通过互联网连接和交换数据的真实物品。物联网，也称为万物互联或工业互联网，是另一种发展视角，被设想为一个整体的设备和装置网络，使其能够相互连接 \[[2](#ch8.xhtml#ref8_2)\]。物联网被描述为遍布全球的数十亿个真实设备，它们已连接到互联网，正在收集和交换信息。将这些不同的事物连接起来并为其添加执行器，为原本通常“愚笨”的设备增加了自动化信息层，使其能够在不涉及个人的情况下传递实时信息。[图 8.1](#ch8.xhtml#fig8_1) 显示了物联网的特征。物联网使我们整体环境变量的外观变得更智能、更易访问，将高级层面和物理世界整合在一起 \[[3](#ch8.xhtml#ref8_3)\]。物联网对就业的优势取决于具体实施；能力和效率通常是主要考虑因素。其思路是，企业应获取对其设备和内部系统的更多信息，并具备更强的能力进行相应调整。物联网承诺使我们当前的环境——我们的家居、工作场所和汽车——变得更智能、更可量化、更具表现力。自动驾驶汽车和智能城市区域可能会改变我们构建和管理我们社区的方式。安全性可能是物联网面临的最大问题。这些传感器经常收集极其敏感的数据。许多物联网设备在安全基本要素方面提供有限的保护，例如数据加密变得极其薄弱。它要求设备应具有独特的密码，组织应提供公共资源以便任何人都可以报告漏洞（并且这些漏洞会得到跟进），并且制造商应明确告知长期设备将获得安全更新。这是一个简短的总结，但也是一个起点。一旦制造智能设备的成本变得微不足道，这些问题将变得更加广泛和顽固。物联网正在形成并继续成为 IT 世界中最新的、最先进的概念。在过去十年中，“物联网”这一短语通过拓宽对协调真实物品的通用基础设施的视野而脱颖而出，使任何事物在任何时间、任何地点都可访问，而不仅仅是针对任何人 \[[4](#ch8.xhtml#ref8_4)\]。[图 8.2](#ch8.xhtml#fig8_2) 显示物联网。
