
## 事件响应措施

* 通知利益相关方以及内部和外部团队有关将采取的缓解、响应和恢复事件的步骤和行动。
* 检查是否有解密工具以解密数据。
* 不要支付赎金，而应向警方/IT部门报告事件。

## 预防措施

* 备份您的数据，因为这是对抗勒索软件的最强防御。所有数据都可以恢复，从而不会丢失工作进度。此外，备份文件必须经常进行测试和检查，以确保数据未损坏且完整。
* 修补并更新系统软件，这可确保潜在攻击大幅减少。
* 对终端用户进行这些垃圾邮件的教育，并敦促他们创建强密码并更明智地使用第三方服务和设备。
* 投资网络安全技术以保护系统网络。此类软件可确保设备具有更强的安全性，因为它们使用防火墙和入侵检测系统。

### 1.3.1.1 WannaCry 勒索软件攻击

2017年5月12日星期五，著名的WannaCry勒索软件攻击\[[11](#ch1.xhtml#ref1_11)\]开始，在一天之内传播开来，影响了超过200,000台运行Windows操作系统的计算机。超过150个国家被勒索软件感染，造成全球恐慌。受影响的计算机大多数运行的是Windows 7操作系统，而Windows XP和Windows 2003系统是最脆弱的。特别是那些未安装2017年4月微软安全更新的系统受到影响。印度、俄罗斯、乌克兰和台湾是受影响最严重的国家。网络风险建模公司Cyence估计此次攻击造成的损失价值达40亿美元。

与任何勒索软件攻击一样，WannaCry勒索软件渗透用户计算机，加密内部存储上的文件，并要求支付300美元的比特币赎金以解密文件。

法国汽车制造公司雷诺是此次攻击受影响的主要公司之一；他们出于预防措施，在多家工厂暂停生产，以遏制恶意软件的传播，其合作伙伴公司日产也受到影响，其在桑德兰的巨大工厂不得不停止周末前的最后生产班次，其在印度金奈的共享工厂也受到影响\[[12](#ch1.xhtml#ref1_12)\]。

英国政府资助的医疗保健和医疗服务机构国民保健服务（NHS）在遭受WannaCry攻击后被迫停滞数日，此次攻击使英国损失超过9200万英镑，约70,000台设备——包括计算机、MRI机器、血液储存冰箱和手术室设备——在英格兰和苏格兰的多个医院受到影响。

其他受影响的高知名度公司包括LATAM航空、FedEx、Telefonica和Deutsche Bahn。

WannaCry利用微软对`SMB`协议的实现中的漏洞，并通过发送精心制作的数据包在`LAN`上传播，使计算机执行任意代码；例如，如果用户收到带有恶意文件作为附件的电子邮件，并且打开它，它将通过`LAN`传播到未修补的系统并开始加密文件，同时附加`WNCRY`扩展名。

然而，微软发现了这一漏洞并发布了补丁来修复此问题，但由于补丁刚发布一个月，许多系统仍然脆弱。

据报道，美国国家安全局发现了这一漏洞并为其开发了名为`EternalBlue`的利用工具，随后被名为Shadow Brokers的黑客组织窃取，并在Medium帖子中通过互联网发布。WannaCry使用`EternalBlue`在全球范围内感染计算机。

#### 部署阶段

WannaCry利用`MS17-010`漏洞并借助`EternalBlue`利用工具和`Doublepulsar`后门注入名为`launcher.dll`的二进制文件。它还利用内核模块中的`srv2.sys`、`SMB`驱动程序以获取对`LAN`的访问并在其上传输恶意负载。

`launcher.dll`主要关注两个函数，即`ExtractResource`和`CreateProcessMSSECSVC`。

尽管其内部工作复杂，但这些函数的思路是提取资源以创建可执行文件，并为此目的使用Windows API，最后启动`mssecsvc.exe`作为正在运行的文件。

`launcher.dll`被注入到`Isass.exe`系统进程中并充当`mssecsvc.exe`的加载器。在安装阶段之前，运行了两个Windows API，即`InternetOpenA`和`InternetOpenUrlA`，它们用于查询一个硬编码的网站域名，该域名看起来是乱码且非常长——这是终止开关URL。对该URL的成功连接将导致前面讨论的可执行进程停止并退出，但另一方面，如果连接失败，这通常会发生，进程会继续进行并释放`tasksche.exe`。

#### 安装阶段

现在安装阶段开始，主要关注`mssecsvc.exe`和`tasksche.exe`。

`mssecsvc.exe`负责两个功能：dropper和感染，而`tasksche.exe`负责资源加载和加密环境设置。

`mssecsvc.exe`有两种运行方式。

##### Dropper阶段

如果`mssecsvc.exe`在没有任何参数的情况下运行，执行将进入dropper阶段，其中子函数将被调用以安装`mssecsvc2.0`服务然后创建`tasksche.exe`，然后资源提取例程完全提取资源二进制内容并写入`tasksche.exe`，然后将其释放。

##### 感染阶段

如果`mssecsvc.exe`使用参数`-m security`运行，执行将转移到感染阶段。现在使用攻击者机器，`mssecsvc2.0`服务将尝试通过`SMB`协议连接到端口445，如果连接成功，攻击者将通过发送具有特定操作码的制作数据包来检查`Doublepulsar`后门是否正确设置。如果目标系统未正确安装`Doublepulsar`后门，利用代码将继续进行，通过初始化`EternalBlue`攻击，一旦`Doublepulsar`后门设置得到验证，包含`launcher.dll`、内核shellcode和用户态shellcode的有效载荷将被直接上传。

##### 资源加载器

此阶段的第一步是为包含提取文件的目录创建一个随机名称；此随机生成的名称将作为唯一ID，然后`taskche`进程将检查是否存在命令参数`i`，它代表`taskche.exe`的安装节点；如果存在，则任务将以安装模式继续，使用id创建文件夹并将`taskche.exe`复制到该文件夹中。从资源部分提取名为`XIA`的资源zip文件，然后在资源加载阶段完成之前进行压缩，一旦完成，代码将使用密码`WNcry@2o17`解压资源文件，此资源文件包含多个WannaCry文件。
