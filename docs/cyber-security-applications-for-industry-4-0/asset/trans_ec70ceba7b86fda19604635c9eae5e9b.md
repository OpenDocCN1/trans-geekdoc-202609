
ParsiFAl 4.0 研究项目旨在开发一种标记为 `S3` 的薄型电子系统。该系统基于微控制器、传感器和紧凑型显示器构建。这样的设备可以帮助物流行业为运输敏感货物找到可靠的路线。

## 3.5 BCT 在工业 4.0 中的应用

BCT 在金融和支付领域获得了广泛关注。尽管关于可扩展性、可持续性和安全性仍有许多问题未得到解答，但 BCT 已成为确保工业互联网安全的重要要素之一（[Parizi & Dehghantanha, 2018](#ch3.xhtml#ref3_41)）。最初，区块链是为加密货币和比特币等支付系统而设计的，之后，区块链被用于通过智能合约实现数字金融自动化（[Efanov & Roschin, 2018](#ch3.xhtml#ref3_17)）。而现在，区块链是补充工业 4.0 自动化流程的有前景的解决方案。

区块链充当块数据库，其中这些块与哈希函数相关联。区块链中的块是不可变的。每个节点在网络中都包含一份账本副本且不会失败（[Alkhalifah et al., 2020](#ch3.xhtml#ref3_5)）。所有数据都使用密码学技术加密，并将历史链作为新块添加。区块链中的交易一旦在网络中发布就无法更改。2009 年，电子现金的概念被提出，即比特币。比特币是 BCT 的加密货币，允许在分布式账本中转移数字现金。除了比特币之外，还有许多其他加密货币，如 XRP（Ripple）、ETH（Ethereum）、BNB（Binance Coin）、LTC（Litecoin）和 BCH（Bitcoin Cash）。各种区块链平台在 [表 3.2](#ch3.xhtml#table3_2) 中进行了讨论。

### 3.5.1 区块链框架

本节描述了一些为各种工业 4.0 应用设计的最新区块链框架。所设计区块链框架的有效性是根据确保机密性、完整性和可用性等各种安全方面的程度来评估的（[Alladi et al., 2019](#ch3.xhtml#ref3_6)）。区块链是一种新兴的数据保护技术，作者叙述应用 BCT 在实施过程中带来许多挑战。作者讨论了诸如参与组织的隐私、块数据的可扩展性、采用和集成成本等安全方面（[Xie et al., 2019](#ch3.xhtml#ref3_59)）。智能环境会受到安全漏洞的影响。安全方面使用公钥基础设施（`PKI`）进行改进。BCT 在确保智能公民、供应链管理、智能电网、智能医疗和智能交通等智能应用的安全方面起到了助推剂的作用。授权实体通过区块链得到高度正确的验证（[Yang et al., 2019](#ch3.xhtml#ref3_61)）。数十亿设备连接起来在边缘计算网络中运行应用程序。通过集成 BCT，网络安全方面和计算效率得到了极大改进。分布式数据库（`BigchainDB`、`Enigma` 和 `IPFS`）用于解决存储问题。
