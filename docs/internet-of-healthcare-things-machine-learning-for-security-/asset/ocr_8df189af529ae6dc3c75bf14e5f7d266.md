Fog node: This fog is responsible for deciding to analyze and process the uncategorized data packets. The data packets are classified according to protocols, i.e., TCP, UDP, and ICMP. It allows network and security administrators to perform reporting tasks on all detected intrusions by interacting with the intruder database and deep training algorithm. This fog node is distributed in nature which is illustrated in Figure 4.10.

The following key features of the proposed algorithm are discussed below that contributes in direction of future research:

+   * The proposed framework can enforce security and trustworthiness on the Internet of Healthcare Things (IoHT) by amalgamating privacy and a deep learning approach.
* The feature selection using bio-inspired optimization technique removes the drawback of a local minimum and they converge faster.
* By applying feature reduction along with a deep learning approach, training time is reduced.
* Highly related features are needed for improvement in performance level. Unnecessary features will cause calculation complexity.
