# 4.5.1 Key Management

A key management protocol addresses access, distribution, and implementation of encrypted keys by IoT/IoHT communication entities. The formulation of the entire process has been achieved by dividing the steps into certain portions for the performance. The steps are inclusive of the series of work that includes generating the key, key exchange, key usage as well as the key cancellation step. A key management mechanism, involving key server knowledge (i.e. trustworthy device entities), separate user sort (i.e. telephone, or static), and multiple machines, is using a cryptographic method (i.e., IoT devices). A strict key management mechanism should be developed to perform protected communications [34].
