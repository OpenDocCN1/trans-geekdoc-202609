# Abstract

The 21st-century era of advancement in Information Technology and emerging applications like the Internet of Things (IoT) have altered the lifestyle of people and its contribution in the field of healthcare is commendable. The information related to the body and mental strength can help in bringing encouraging transformation in the healthcare industry with the usage of networked sensors. The data collected with the help of IoTs can be evaluated using machine learning processes and professional to do advanced research and provide suitable recommendations. These scenarios already exist but proper research and development needs to be carried out of the historical data for predicting troubles utilizing strict analytics. The present document is based on different machine learning applications and knowledge is extracted for real time analysis of secluded supervision by IoT infrastructure. The system formulated will provide recommendations based on past and pragmatic data in healthcare. The author has formulated a structure to expose acquaintance in breast cancer which will help in reliable and authentic decision making. This paper has estimated a forecasting scheme for breast cancer using machine learning technique like SVM, Bayes Net, MLP, Decision Trees, etc. in experimental results.

**Keywords:** IoT, machine learning, healthcare, sensor, breast cancer
