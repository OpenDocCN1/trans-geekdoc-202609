# 2.8 Conclusions

One size fits all paradigm is anathema in attempting to have a universal recommendation for establishing and regaining security and privacy of data in IoHT. The following is a set of recommendations for enabling a reasonably high level of security in the provision of services:

+   1. Healthcare institutions should develop and publish their approved policy on authentication and authorization of users, involved in data handling, posting and transfer.
2. Authentication and authorization, both at the process level and system level, should be segregated and dealt with by separate protocols.
3. Access to sensitive data should be restrained or prohibited from remote users (layers 2 and 3 of the network access).
4. An IoT device needs to be evaluated for its protection features, concerning security criteria, before being inducted into an already existing operational environment, such as the healthcare industry. Resorting to techniques like type approval of equipment is a common practice to validate devices/equipment.
