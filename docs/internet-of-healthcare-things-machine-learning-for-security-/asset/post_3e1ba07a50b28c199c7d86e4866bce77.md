#### 7.6.1.1 Data Perception Layer

The main task of this layer is to deal with personal clinical information that is collect from the user in real time. Medical information are collected through various short-range communication technologies such as Radio Frequency (RF) Waves, Z-wave, Near Field Communication (NFC), ZigBee, Bluetooth etc., and transfer to the upper layer for processing these data. Sensors such as RFID tags are incorporated into the Medical IoT devices and contain all the information that can be scanned to receive all the related data. Once the scanned data is transferred to the upper layer in the hierarchy, i.e., the networking layer, the data is processed accordingly.
