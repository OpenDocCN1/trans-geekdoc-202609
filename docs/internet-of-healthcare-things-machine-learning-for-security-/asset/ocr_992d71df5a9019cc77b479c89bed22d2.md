The various levels are inclusive of the first sensor-based level, second co-ordinator-based level, and finally, the medical server level that has been illustrated in Figure 4.4. The illustrated architecture has been employed in the developed IoHT health monitoring systems [29, 30].

Medical equipment and controls are monitored on the sensor floor, which finally concludes the formation of a local network that can also be referred as BSN an abbreviation for the Body Sensor Network. The sensors such as the RFID, Near-Field Communications (NFC) as well as BLE are utilized in the sensor as well as server level for making the remote changes possible that are included in the Low-performance wireless infrastructure standards. The BLE secures the performance in a range of several network topologies that also include the mesh-based infrastructure or the star architecture.
