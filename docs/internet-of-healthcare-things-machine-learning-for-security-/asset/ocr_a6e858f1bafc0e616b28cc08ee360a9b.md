# 4.3.5 Authorization

This security feature is used to provide authority to users or customers to access data, resources, or files. For accessing, file authorization levels are decided either read authority or write authority. It is normally accompanied by a device or device identity verification authentication protocol. Access policies are typically provided by a system and customer services authority (i.e., system administrator).

# 4.3.6 Availability

The availability of the content assures that it is only available to accepted parties.

# 4.3.7 Forward Secrecy

In forward secrecy, no IoT devices can access the data that are not available yet.

# 4.3.8 Backward Secrecy

In backward secrecy, no IoT devices can access the data that has been shared previously.
