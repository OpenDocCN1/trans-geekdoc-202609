## 3.3.2 Threats & Attacks on Big Data

Big Data technology is vulnerable to a variety of security threats and attacks. Table 3.2 ranks threats and attacks that vary by stage in the big data lifecycle. Each step has its properties and sets its own different goals. Therefore, each stage is exposed to different threats. In this sense, the data collection phase is vulnerable to certain attacks such as phishing and counterfeiting. These types of attacks are aimed at those who collect and present data for large amounts of data. At this stage, employees are provided with a security awareness program for data collection and how to follow security policies and practices.

Once information on storage devices is collected, police must be aware of threats and attacks, as hackers accessing data on storage devices can use data mining techniques to illegally extract and use confidential information. Data mining attacks can control the type of attack, police officers can share data vertically or horizontally to minimize the impact of these attacks and use a decentralized storage structure. Several threats have been identified in staged attack such as attacks on storage devices (e.g., hard disk theft) and unauthorized access attacks. During the data modeling phase, some threat attacks can reveal sensitive information or affect data processing.
