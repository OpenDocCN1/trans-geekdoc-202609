+   3) Data masking: Masking replaces critical information with anonymous data. Actual data cannot be obtained from the masked anonymous data as this is not truly an encryption algorithm. It utilizes a de-identifying strategy of information sets which means masking personal identifiers like name, security number, and generalizing or suppressing quasi-identifiers like zip codes and date of birth. Therefore, masking data is a famous approach to leave unidentifiable information. Data masking reduces the cost of securing a data deployment which adds up to its significant benefit. As secure data, masking decreases the need for using extra measures for security on that data after it is from a secure source into the platform and while it is in the platform [1].
