# 4.8 Conclusion

Internet of Healthcare Things (IoHT) had emerged as an uprising technology for improving the healthcare sector for fast and effective treatment of patients. But their deployment over the internet had raised security and privacy concerns. Several existing architectures, algorithms, or protocols seem to be vulnerable to network attacks. So, the main scope of this chapter is to give an overview of the various intrusion detection system for IoT or IoHT architecture. But still, there are some limitations on existing techniques as every day new attacks are also introduced. So, primary objective of this chapter is to propose a distributed framework to preserve the privacy of the data using deep learning that the complexity of processing is reduced. The feasibility of the framework will incorporate privacy, security, accuracy, and reliability.
