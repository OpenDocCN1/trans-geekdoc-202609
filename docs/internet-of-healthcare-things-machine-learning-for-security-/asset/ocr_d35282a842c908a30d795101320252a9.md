In this section, some major contributions of researchers are focused on the field of intrusion detection using machine learning or artificial intelligence. In [33] author designed a model for anomaly detection in a network for IoT applications. This model extracted a sample from data to analyze the behavior of the network traffic that can cause compromise to the network. In [39] the author provided a survey on different machine learning approaches ayrıca machine learning tools to provide cloud-based IoT framework that applies machine learning to provide security and privacy to the data. In [40] the author used the features of biometrics along machine learning to build a real-time healthcare monitoring system. The monitored data is remotely diagnosed and treatment decision is taken over a secure network. Man-in-the-middle attacks were considered in this as intrusion that was detected using machine learning and there was an improvement in detection rate from 7 to 25%. In [41] the author designed a model to secure the network in which medical devices are connected. An agent-based model was designed with the integration of regression machine learning to observe the anomaly sensor data. In [42] the author developed an anomaly-IDS to differentiate network traffic as an anomaly or normal. The author reduced the dimension of data by using principal component analysis. The cloud storage system was assumed for this work. In [43] the author proposed a deep learning intrusion detection system over an IoT fog network.
