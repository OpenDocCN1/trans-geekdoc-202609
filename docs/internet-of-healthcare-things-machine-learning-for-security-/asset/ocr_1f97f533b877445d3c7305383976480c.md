4. **Nodes**: Nodes contribute to the distributive ledger property of Blockchain. They are electronic devices that store and maintain copies of blockchain and keep the network running. This network should consensually approve newly mined blocks to add new blocks to the chain [7].
5. **Timestamp**: It is the total elapsed time in seconds since UTC 00:00:00 on January 1, 1970 [8].
6. **Consensus**: It involves verification and validation of information in a distributed ledger system by eliminating the need to rely on a central authority [13]. Popular consensus algorithms used by most Blockchain architectures nowadays Proof of Work (PoW), Delegated Proof of Stake (DPoS), or Proof of Stake (PoS). These algorithms ensure that all the nodes have an untampered copy of data and new blocks added to the chain are genuine [9].
7. **Tx_Root**: It is also referred as the Merkle root [21]. It contains the hash value of all validated transactions of the block. All hashes of the blocks are combined pairwise with each other and are given as input to another hash function. This work is repeated until there is only a single hash, which stands for the Merkle root [10].
