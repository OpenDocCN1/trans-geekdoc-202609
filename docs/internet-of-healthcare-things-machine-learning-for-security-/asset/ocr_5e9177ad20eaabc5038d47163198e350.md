# 5.5 Performing Sentiment Analysis on IoHTs Dataset

Sentiment analysis is well known as opinion mining in the field of Natural Language Processing (NLP). It is used to study subjective information from a given text. Lexical and sentiment-based VADER (Value Aware Dictionary for sEntiment Reasoning), Text Blob and deep learning LSTM model are already adopted for analyzing sentiment orientation for numerous domains. VADER is a rule based sentiment analysis tool designed for sentiment analysis. Valence Dictionary for sEntiment Reasoning (VADER) is a lexicon and rule based sentiment analysis tool for analyzing sentiments expressed in textual information [2, 7]. It emphasizes sentiment intensity using qualitative and quantitative methods and suitable for analyzing short text from the microblogging platform [5]. The objective of this proposal is to present a sentiment analysis system for early warning of a health crisis that can be fully integrated with IoHT framework and can be fruitful in assisting medical specialists.
