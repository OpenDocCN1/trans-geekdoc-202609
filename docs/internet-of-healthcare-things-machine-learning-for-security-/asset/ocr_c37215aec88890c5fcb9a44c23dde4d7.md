# 11.4.2 Data Pre-Processing

Pre-processing includes two steps: one is discretization and the second is SMOTE. Discretization is defined as the method by which values are converted into discrete. SMOTE is used to balance the class. Liu et al. discussed a stat method known as discretization as Chi2 [60]. For class-balancing when the count of samples in the various category is not evenly distributed. With the help of SMOTE, the imbalance dataset dilemma is addressed using oversampling. In SMOTE [61], to balance the different classes, samples are produced with the support of a k-nearest neighbor. The overall combination of discretizing and SMOTE helps in enhancing the performance of the results. After the pre-processing, the feature selection [62–64] technique is applied to enhance the performance of classifiers and reduced the time of computation. BFS-CFS [65] is used for feature selection in which searching BFS (best first search) is used and for evaluator CFS (correlation-based feature selection) is used. A wrapper selection of feature in accordance with supervised feature selection.
