# 4.7 Proposed Framework

It is known that the IoT environment, a large amount of data are produced and communicated over the network. To handle and organize such a huge amount of data over a network for analysis, accuracy is one of the important factors to be focused on. For a large dataset, manual feature selection takes a quite long time while communication among doctors and patients. In IoHT, several sensors are used to monitor the health of an individual. So, it is required to monitor network traffic to prevent sensitive data to be compromised by intruders. This can be achieved by applying machine learning as well as deep learning. For network security, intrusion detection, deep learning proves their efficiency over other methods for feature selection and well classification of data packets as an anomaly and normal. In this section, some major issues that are found in the existing machine learning approach are such as:

+   - Not effective for unknown attacks.
- Applicable only on binary classification.
- The performance level degrades in multi-classification.
- High computation and communication overheads.
- Most of the work is centrally co-ordinates.
