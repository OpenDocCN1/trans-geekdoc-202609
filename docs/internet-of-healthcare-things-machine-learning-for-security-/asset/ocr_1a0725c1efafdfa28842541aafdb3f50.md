# 7.6.1.2 Data Communication Layer

It is the main channel between the other layers in IoT architecture and the different IoT operating activities. The physical structure has a lot of patient evidence and knowledge to communicate with other nodes. It is therefore necessary to establish an appropriate network of connections between these nodes through a communication protocol. Based on the designer's protocol, the interaction could be wired or wireless. In addition, networks are extremely critical IoT elements that bind the external world of the internet. Intelligent network infrastructure is required for IoT.

# 7.6.1.3 Data Storage Layer

The patient data contained in the Cloud Medical Server (CMS) is managed in the storage layer. Remote user authentication for accessing IoT data is handled by the Cloud Authentication Server (CAS) and the Central Cloud Server (CCS) stores the other metadata. The obligations of this layer are also the identification and management of IoT user data.

# 7.6.1.4 Data Application Layer

Another end of an IoT system is formed by applications. Applications are vitally important for all the collected data to be effectively used. These cloud-based applications are responsible for giving the collected data an effective meaning. Applications are controlled by users and are the point of delivery for specific services. Examples of apps are apps for home automation, security systems, industrial control centres, etc.
