### 7.8.1 Encryption

Encryption is a process that encodes a text or file such that certain users can read it. Encryption means encrypting, using data and a key to convert it into the secret message and at the receiver side decrypting, or decoding, the received data. The message is referred to as plaintext in a hidden text. In its encrypted, unreadable format, it is called ciphertext. A sequence of numbers used to encrypt and decrypt data is an encryption key. Algorithms are used to construct encryption keys. It is random and special to each key.

There are two types of encryption systems: symmetric encryption and asymmetric encryption. Symmetric encryption is used to encrypt and decrypt data with a single password. For encryption and decryption, asymmetric encryption uses two keys. A public key, which is exchanged between users, encrypts the secret. Data is decrypted by a private key, which is not exchanged.

### 7.8.2 Key Generation

Using symmetrical key cryptography, key control triggered a nightmare for the parties. They were concerned about how to relay the keys safely and reliably to all users so that the message could be decrypted, and for third parties offered the opportunity to intercept the keys in transit to decipher the top-secret communications. Thus, the entire coding scheme was corrupted if the key was compromised, and a “Secret” would no longer remain a “Secret.” So exists a concept called key generation, where the required key for encryption is generated using random number permutation.
