# 3.3 Big Data Security Problem

Medical facilities store, maintain, and share a wealth of information to represent productive and legitimate issues, but have the disadvantage of lack of technical support & limited security. The situation is greater and more complicated in the medical field. Malicious hackers can use these data mining strategies and techniques to detect and discover sensitive information that could lead to data breaches. While security measures remain the avenue of communication in question, attackers are still the most vulnerable. Prices will steadily rise as methods of overcoming security measures are developed.

In terms of security and accuracy, researchers [4] argue that a high level of data security includes three aspects: information security, access control and data security. As a result, healthcare organizations must implement security controls and methods to manage appropriate security information, equipment and programming, and reliable clinical data on internal and external risks. When starting a business, you need to create a data lifecycle to make appropriate decisions about the maintenance, profitability, reuse, and analysis of registered or new data.
