# Table 4.1 Basic architectural layers of IoT.

| Layers | Description |
| Hardware | This unit consists of: Components such as Sensors, RFIDs, etc. |
| Internet | This unit consists of: communication Interfaces. |
| Presentation | This unit consists of: Data storage units, Data analytical tools and applications. Platform for remote access of end-users. |

Middleware: For storing data, computation, and knowledge of content intermediately.
Internet: Provides connectivity between anything at anytime,anyplace. It includes cloud computing for intelligent devices, intelligent web applications, and IP.
Presentation or Application: For various platforms and applications to grasp visualization and interpretation software.
Several areas covered by IoT applications are given in [11]:

+   - IoT Devices: In this unit, all functions and procedures are included that are needed for control for IoT devices.
- Control Operations: In this section, all operational control such as data analysis, monitoring and management are performed by IoT devices.
- Collection of Information: In this section, the collection of data, their transmission to server and finally response of decision-making units are represented.
- Application Interface: This unit represents the interface or programming application to the user interacts.
- Business Interactive Applications: This unit merges the IoT applications and functions. For example, Customer Relationship Management (CRM) or Enterprise Resource Planning (ERP) are some examples of business applications.

In most IoT application, cloud servers are integrated as backend support either locally or remotely. These cloud servers can be physical or virtual
