of the following when using semiconductors that contain information in k-address to identify a person by interacting with other publicly available information: Identifier. Table 3.4 is an anonymous database containing patient records from an emergency simulation clinic in Camelot.

This data has six columns and five items. There are usual ways to get the anonymity of k for k values.

The first way is suppression, in this way reference cursor '*' can override some attribute values. We can replace all or part of the meaning of the section with '*'. In Table 3.5 anonymous, all attributes of the “Name” and all values of “Religion” are specified in '*' are replaced.

The second approach is to generalize, in this strategy, the values for individual features are replaced by broader categories. The “Birth” attribute can be replaced with the “1969” year. The zip code field is summarized to a larger display area (Camelot).
