# 3.3.1 Big Data Security Lifecycle

Businesses need to implement a security policy for healthcare information that protects critical resources while complying with the conditions of reference for healthcare consistency. This lifecycle model is designed to cover the stages of the big data lifecycle and identify threats and attacks affecting the big data domain. This stage [5] represents the big data lifecycle from the perspective of customers such as data providers, data collectors, data developers and decision makers. The proposed model [6] consisted of four connection stages: data collection stage, data storage stage, data modeling and analysis, and information generation. Researchers propose a model incorporating the measures described above to provide mechanisms and systems to combat threats and attacks during the lifecycle of Big Data.
