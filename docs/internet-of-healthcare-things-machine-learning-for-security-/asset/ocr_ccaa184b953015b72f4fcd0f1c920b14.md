**Patient ID (PID):** For every person, it is a proposed unique identification number. It is similar to the Aadhaar number in India and Social Security Number (SSN) in the USA. Every patient should have a Unique ID that is registered in the Medical IoT environment.

**Passcode (PC):** A passcode, also referred to as a password, is a memo secret, normally a character string used to validate a user's identity. The patient and user can select the password based on their circumstance and wish, with the conditions specified in the portal.

**Device Product Code (DPC):** This is a number of 96 bits, built as a global identifier. It gives any physical object unique identity. It is a format is open and can be encoded on RFID tags. Tracking all sorts of objects, including fixed properties, business goods or recycled transported items, can be done using device product code.

**Text Based Registration:** During the induction process, every patient outside the hospital sector must be registered. Of the patients, the PID and a PC are collected. After a patient's satisfactory registration, an acknowledgement will be submitted to the patient stating that the registration has been done successfully.

# 7.8.1 Encryption

Encryption is a process that encodes a text or file such that certain users can read it. Encryption means encrypting, using data and a key to convert it into the secret message and at the receiver side decrypt, or decode, the received data. The message is referred to as plaintext in a hidden text. In its encrypted, unreadable format, it is called ciphertext. A sequence of numbers used to encrypt and decrypt data is an encryption key. Algorithms are used to construct encryption keys. It is random and special to each key.

There are two types of encryption systems: symmetric encryption and asymmetric encryption. Symmetric encryption is used to encrypt and decrypt data with a single password. For encryption and decryption, asymmetric encryption uses two keys. A public key, which is exchanged between users, encrypts the secret. Data is decrypted by a private key, which is not exchanged.
