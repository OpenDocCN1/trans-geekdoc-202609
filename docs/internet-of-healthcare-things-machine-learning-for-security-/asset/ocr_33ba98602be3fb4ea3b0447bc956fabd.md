# 10.4.4 Decision Tree Classifier (DTC)

The decision tree algorithm belongs to supervised learning algorithms. This algorithm is used for fixing regression type problems. This algorithm makes the predictions by self-importance a series of trials on a certain argument. The main intention to use this DTC is to predict the patient's data to identify the reason for suffering mainly from these parameters. In some cases, doctors will not have the idea to conclude for what reason this attack took place [36–40]. Therefore, build a decision tree to predict the patient having attack symptoms. Hence, in this case, the values for the continuous variables are predicted and the obtained accuracy is 72.36%. The confusion matrix obtained is shown in Figure 10.5.

# 10.4.5 Random Forest Classifier (RFC)

This is a supervised learning algorithm and the vital advantage concerning this algorithm is that it can prevail for both classifications together with regression problems. The divergence between the Random Forest (RF) algorithm and decision tree algorithm is that in RF the progression of finding the root node and intense of the feature nodes will run randomly [40–45].
