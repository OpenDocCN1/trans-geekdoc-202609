+   5. Healthcare institutions should implement appropriate technical and organizational measures to manage the security risks of their public networks and services. These include but not limited to ISO22301 certification for business continuity and ISO27001 certification for information security management.

+   6. Security incident reporting policy and system should comply with ITIL and similar global standards.

+   7. Healthcare institutions should regularly conduct appropriate assessments of all application-level, server and systems software, to identify potential threats and vulnerabilities. Gaps identified during audits/tests should be resolved in a time-bound manner.

+   8. Healthcare institutions should have suitable support arrangements with their vendors to ensure that security and stability fixes are provided and installed in a timely, effective manner.

+   9. Security protocols deployed in the system need regular updates with the latest security patches, as older versions may expose the system to new vulnerabilities. Therefore, constant updates of security patches and incorporation of request for changes are needed for IoT devices to ward off the latest threats in the form of viruses or machine tampering. However, designing a mechanism for the dynamic scanning and installation of the latest security patches is a challenging and formidable task. Artificial intelligence will play a major contributory role in shaping policies and procedures in terms of aiding updates.

+   10. Healthcare institutions should conduct periodic external and internal security audits, including penetration tests that simulate real-world attack scenarios, to identify threats and weaknesses at the network operating system and application layer levels, as well as in the institution's procedures and processes.
