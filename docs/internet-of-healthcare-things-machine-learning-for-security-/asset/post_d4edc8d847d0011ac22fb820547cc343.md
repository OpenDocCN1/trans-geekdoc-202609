## 8.3 Blockchain Technology

The Blockchain is in its most trivial is a linked list that contains time-timestamped series of immutable data connected by a hash of the previous block. Blockchain is managed by a cluster of computers called nodes, which maintain a copy of the chain. Each block in a blockchain is secure, immutable and connected to the previous block via its hash [5]. It builds on the idea of a P2P network where P2P stands for "Peer to Peer":

A P2P network consists of computers called 'peers' that are connected via the internet as shown in Figure 8.3. Files can be directly shared between peers without a central server [6]. Hence, each peer acts as a file server as well as a client [6]. In this, the P2P network provides a decentralized, distributed, shared, and immutable database ledger where data contains a list of all transactions by eliminating the need for a legitimate central supervisory authority.

### 8.3.1 Important Terms

- 1. Blockchain: Blockchain comprises different blocks. These Blocks contain data, nonce, and the hash of the current block, which stores the output of the hash function, which takes data. Nonce, the hash of the previous block, timestamp as input. It also stores the hash of the previous block as represented in Figure 8.4.
- 2. Miners: Miners create new blocks and add them to Blockchain. Since every block refers to previous blocks, Miners solve incredibly complex math problems to find a nonce that generates an accepted hash using special software.

## 8.3.2 Features of Blockchain

Blockchain is gaining a lot of popularity because of the following mentioned features.

### 8.3.2.1 Decentralization

Decentralization is one of the core concepts of blockchain which implies that no organization can own a chain. Traditionally, data is stored on a database of an organization that is accessed by the user by sending a request to a server called client-server. The client-server gives back relevant information [23]. Centralized systems are vulnerable

- They are targets for potential data hacks since all the data of the organization is stored at one spot.
- During maintenance or in case of system failure, the data becomes inaccessible.
- In the worst-case scenario, the centralized system could get corrupted or infected with malware. In that case, all of the data residing in the centralized system will be compromised [5].

Blockchain is a P2P network where everyone has copies of the chain. This eliminates the need for a third party to enable a transaction and provide users with a copy of their information. It also avoids a single point of failure situation [8].

### 8.3.2.2 Immutability

Data/Block once added to the blockchain, cannot be tampered with. This is attained via the use of cryptographic hash functions, which take the data from the block as an input. Hashing consists of taking an input string of variable length to give out an output of fixed length. Input data can also be tracked using the hash of the block.

The "Avalanche Effect" property [5] of cryptographic hash functions plays a huge role in ensuring immutability. This property of cryptographic hash functions reflects huge changes in output even for small changes in input. If someone tries to change the block's data, even the slightest changes will change the hash drastically. The nonce and hash are 32 and 256 bits respectively. Thus, there are roughly four billion nonce-hash combinations that must be mined before the right one is found. When our miner finds the right combination, the mined nonce is called

### 8.3.2.3 Transparency

User’s identity and confidential data are hidden using complex cryptographic techniques and represented by their public-key/public address. In this way, Blockchain provides data security yet at the same time transparency about transactions [22].

### 8.3.2.4 Smart Contracts

Smart contracts are executable codes that enforce appropriate rules and policies on different authorized parties to facilitate their interaction with each other and the data. Smart contracts enable automation when specified conditions are met. Thus, the use of a Smart contract assures a low cost of implementation compared to current management systems due to the elimination of previously trusted third parties for enforcement [11].

## 8.3.3 Workings of a Blockchain System

Blockchains are roughly categorized into three different types:

- Public blockchain;
- Private blockchain; and
- Consortium blockchain.

In a public blockchain, every participant can become a node and participate in the consensus process and all the transactions/records are visible publicly. On the other hand, in a Consortium blockchain, only a group of pre-selected nodes can participate in the consensus process. In a private blockchain, only nodes that are associated with specific organizations can participate in the consensus process [8].
