The proposed framework for intrusion detection in IoHT is illustrated in Figure 4.8. This framework gives a general overview of the framework that is composed of basically three layers: data layer, communication or network layer, storage, and analysis layer. The data layer is composed of smart sensor data or any information related to patients, hospitals, or insurance companies, etc. The collected data, either from sensors or any data, is communicated to the next layer i.e., communication or network layer. This layer is composed of gateway or switching devices that are responsible for analyzing the collected network data. The abnormal packets are analyzed using machine learning and reported to the administrator. The normal data packets are then transmitted to the next layer for their storage and analysis purposes. The collected data is analyzed by the doctors or specialists which are further stored at the cloud server from where patients can access the report by authenticating themselves. So, this framework is bidirectional which is secure, robust, and flexible.

The algorithm for the proposed model is illustrated below:

```
Algorithm:
1. Begin
2. Input: Intrusion Feature set={F₁, F₂, ...F_n}
3. Output: Intrusion Report → Data(status)
4. Node initialization and deployment
5. Packet capturing fog→Sensor nodes
6. Feature Extraction
7. Data Analyst fog→co-relation and reduction
8. Ensemble DNN training
9. Decision fog→Data(status)
10. Generate alert
11. Update learning model
12. End
```

The proposed model consists of four distributed fog nodes that communicate with each other so that they can better identify network attacks (Figure 4.9).

Co-ordinating node: This node handles the training process from the existing intrusion database and trains the ensemble DNN network for creating decision rules. The training is performed based on protocol type TCP, UDP, and ICMP.

Packet capturing fog node: This node collects network traffic and passes it to the next node.

Data analysis fog node: This node extracts features and find co-relation among features. The co-related features are further considered to be processed and thus results in feature reduction.

It allows network and security administrators to perform reporting tasks on all detected intrusions by interacting with the intruder database and deep training algorithm. ## 4.8 Conclusion

Internet of Healthcare Things (IoHT) had emerged as an uprising technology for improving the healthcare sector for fast and effective treatment of patients. But their deployment over the internet had raised security and privacy concerns. Several existing architectures, algorithms, or protocols seem to be vulnerable to network attacks. So, the main scope of this chapter is to give an overview of the various intrusion detection system for IoT or IoHT architecture. But still, there are some limitations on existing techniques as every day new attacks are also introduced. So, primary objective of this chapter is to propose a distributed framework to preserve the privacy of the data using deep learning that the complexity of processing is reduced. The feasibility of the framework will incorporate privacy, security, accuracy, and reliability.
