## 4.5.1 Key Management

A key management protocol addresses access, distribution, and implementation of encrypted keys by IoT/IoHT communication entities. The formulation of the entire process has been achieved by dividing the steps into certain portions for the performance. The steps are inclusive of the series of work that includes generating the key, key exchange, key usage as well as the key cancellation step. A key management mechanism, involving key server knowledge (i.e. trustworthy device entities), separate user sort (i.e. telephone, or static), and multiple machines, is using a cryptographic method (i.e. IoT devices). A strict key management mechanism should be developed to perform protected communications [34].

## 4.5.4 Intrusion Detection

Intrusion or anomaly detection is one of the biggest challenges over today's fast-growing communication system and internet services. As applications over the internet increases, it increases security threats. So, to detect malicious activities over the internet, intrusion detection is considered to be an effective security tool. According to the study, it is seen that machine learning techniques are considered to be a more widely used application to design more efficient intrusion detection tool for achieving high accuracy rate as well as low false alarm rate. A more accurate predictive model can be built for such a large network dataset by applying a machine learning approach which is quite impossible with traditional security tools. The machine learning-based IDS learns the pattern of data captured in the network to determine its behavior to be an anomaly or normal. Traditional IDS will only identify such attacks that are known to the machine. It cannot determine the unknown attack and its behaviour. There is the possibility of architecture interference by the botnets program that specifically targets the memory of the IoT architecture by bringing the malware into its specific attack coder. The result of such attacks is the system's complete breakdown or the malfunctioning of the program. Certain situations may lead to improper activity by the architecture. There is the possibility of more extreme and outrageous situations in instance the shock provided to the patient who has a pacemaker implanted inside him that can consequently lead to his/her demise. The conclusion being drawn, points towards ensuring proper protection in the IoT framework during communication from unnecessary intrusion [33–38].

## 4.7 Proposed Framework

It is known that the IoT environment, a large amount of data are produced and communicated over the network. To handle and organize such a huge amount of data over a network for analysis, accuracy is one of the important factors to be focused on. For a large dataset, manual feature selection takes a quite long time while communication among doctors and patients. In IoHT, several sensors are used to monitor the health of an individual. So, it is required to monitor network traffic to prevent sensitive data to be compromised by intruders. This can be achieved by applying machine learning as well as deep learning. For network security, intrusion detection, deep learning proves their efficiency over other methods for feature selection and well classification of data packets as an anomaly and normal. In this section, some major issues that are found in the existing machine learning approach are such as:

- Not effective for unknown attacks.
- Applicable only on binary classification.
- The performance level degrades in multi-classification.
- High computation and communication overheads.
- Most of the work is centrally co-ordinates.
