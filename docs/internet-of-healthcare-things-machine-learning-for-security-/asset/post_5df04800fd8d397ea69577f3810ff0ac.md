## 10.4.2 K-Nearest Neighbor Classifier

The K-Nearest Neighbor (KNN) is a supervised machine learning algorithm. The set of rules of KNN assumes that similar things are near to each other. KNN also assumes that the data points that are close to each other must be of the same class. To calculate the distance between the data points, various distance formulas can be used including Euclidean, Manhattan, etc [26–30]. The other parameter required for KNN is the number of points to consider the new data point as belonging to the trained classes. The same dataset was passed through a K Nearest Neighbors Classifier. The KNN details are mentioned below:

- N Neighbors: 3
- Distance Used: Euclidean

In order not to face a dominance problem in finding distance, feature scaling is done to reduce all parameters to a range of –2 to +2, as shown in Figure 10.3. From the matrix, the validation accuracy obtained is 82.89%.
