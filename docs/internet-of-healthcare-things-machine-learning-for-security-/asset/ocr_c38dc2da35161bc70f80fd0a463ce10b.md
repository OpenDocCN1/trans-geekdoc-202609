There are two kinds of confidence relationships in the Chain of Trust: Internal Chain of Trust and the External Chain of Trust. An Internal Chain of Trust is instantiated by a platform as it executes a set of code modules in an environment where the effect of any injection of code or data integrity might take place be difficult to log. If it passes such tests, it can be executed and becomes an eRoT in an external Chain of Trust.
