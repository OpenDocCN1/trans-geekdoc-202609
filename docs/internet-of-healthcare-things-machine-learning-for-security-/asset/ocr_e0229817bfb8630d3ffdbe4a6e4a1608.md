# 12.2 Literature Survey

This section focuses on works which are related to detection and segmentation of brain tumor with the use of IoT technology as well machine learning to build the trust on IOHT [15]. This paper had used IoT technology (Thingspeak) and a machine learning algorithm (Support Vector Machine (SVM)) to aid in the decision making for detection and segmentation of brain tumor. The result was better than that of this algorithm without IoT [16]. This paper had used IoT and cloud-based approach for the detection and classification of brain tumor. Magnetic resonance images as input were captured by the IoT devices which later sent through the cloud for the diagnosis of tumor. The optimal Dense Convolutional Network model was used to work on collected MRI images which were received through the cloud and this model performed with 99.37% accuracy.

In this paper [17], Parzen Analysis of Brain Tissue Densities was used as an extractor and Support Vector Machine (SVM) was used as a classifier to determine the stroke and its type. IoT was used for storage of configuration material of Parzen Analysis of Brain Tissue Densities along with its classifier details on the web and then for extraction and prediction on CT scans of brain. An accuracy of 98.41% was achieved for this proposed method which was better than other methodologies.
