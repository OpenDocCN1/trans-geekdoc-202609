# B. Basic Principles of Blockchain Based Design

In this design, volunteers and publishers exchange data through the blockchain. At the same time, all volunteers and publishers serve as nodes in the blockchain network and support the operation of the blockchain network. Therefore, a

decentralized volunteer computing system can be established based on the blockchain. (Shown as Figure 3) Since the task server is no longer used, and thanks to the decentralized nature of the blockchain, the scalability problem and single point of failure caused by the bottleneck of the task server can be solved.

Fig. 3. Volunteer computing based on blockchain.
