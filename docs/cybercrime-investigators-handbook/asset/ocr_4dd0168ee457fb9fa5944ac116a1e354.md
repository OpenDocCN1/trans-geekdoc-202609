**SIEM: security information and event management** SIEM software provides security information and event management for real-time analysis of potential threats to a network. It is an integrated system that gathers data from multiple sources and provides alerts about potential security violations.

**subnet** A subnet is the division in an IP address providing two or more distinct networks within that IP address. It is used in domestic and corporate environments with subnets communicating with each other through routers on that internal network. For example, there may be separate subnets for the human resources, finance, and research departments.

**vulnerability management software** The process of identifying and correcting vulnerabilities within an operating system or application.

**zero-day exploit** A new piece of computer malware not known to security vendors, operating systems, and applications.
