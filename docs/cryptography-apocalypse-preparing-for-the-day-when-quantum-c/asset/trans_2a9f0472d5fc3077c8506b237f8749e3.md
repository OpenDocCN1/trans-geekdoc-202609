# 2 量子计算机简介

量子计算机、设备和软件利用[第1章](#c01.xhtml)中讨论的量子力学的奇特特性来操纵、创建和处理数据。所有那些奇怪而奇妙的量子特性，例如叠加和诡异的纠缠，都在量子信息科学中得到充分展现。第2章将涵盖量子计算机，包括它们与传统计算机的不同之处、不同类型的量子计算机架构，以及制造它们的许多公司。

## 量子计算机有何不同？

本节将讨论量子计算机与传统二进制*经典*计算机的不同之处。它将从探索比特和量子比特之间的主要差异开始。

### 传统计算机使用比特

传统计算机使用二进制数字（0或1）来存储、传输和操纵数据。*比特*（binary digit）可能只有两种状态之一：它是1或0。它是开或关。并且它在任何时候只能是其中一种事物（即状态）。这种底层二进制特性之所以存在，是因为被操纵的粒子（例如，通常是电子，但也可以是光子和其它粒子）是以整个粒子的形式被操纵的。从数字计算机的诞生直到量子计算机的发明，这一直是我们能够操纵数字信息的方式。量子计算机允许我们以非二进制的方式操纵粒子，利用其量子特性。

传统计算机芯片之所以能工作完全依赖于底层的量子力学，但它们只能以二进制方式在各种逻辑门和受影响的掺杂（即有意嵌入所需杂质）半导体上的位置之间操纵和移动整个电子。它们所操纵的测得的底层电子处于两种完整状态之一，这相当于1或0。传统计算机不测量自旋、极化或任何其它可能的量子特性。

由于一个比特在任何时候只能表示两种状态之一，我们可以轻松计算表示特定信息量所需的比特数。例如，1个比特可能有两种不同的信息位（即0或1），但在被测量之前、期间和之后，它只表示1位信息。两个比特可以有四种不同的可能信息（即00或01或10或11），但在测量时只表示2位信息。三个比特可以有八种可能的不同的信息（即000或001或010或100或010或011或110或111），但在测量时只表示3位信息，依此类推。每个额外的二进制数字都会带来*指数*增长的可能性（2⁴、2⁵、2⁶等）。

早期的计算机是通过物理操纵将单个比特打开或关闭来直接编程的。它们有物理的电子“跳线”电缆，这些电缆插在计算机上或未插，以建立或不建立特定的路径连接。计算机界的一个长期故事是，*计算机虫*这个词的由来是因为真正的虫子吃掉了电缆的部件并导致编程错误。

长长的软盘状跳线电缆被内置的机械开关和纸质编程“穿孔卡”取代，后者本质上操纵内部机械开关以改变计算机的二进制路径。即使在今天，许多计算机设备仍保留着“跳线”开关，用户可以物理操纵它们来确定二进制选择，例如特定计算机路径和决策的“开”和“关”。

机械开关被电子开关取代，这最终导致了晶体管、电阻器和微处理器，它们在最简单的层面上只是尽可能将尽可能多的二进制“逻辑门”塞进最小的空间中。但无论我们能把多少个二进制开关塞进电路板或一块硅片中，一切都是以二进制方式完成的。只是更多的二进制路径可以装进更小的空间。

最低级的计算机语言，例如汇编语言，与在计算机微处理器中移动比特相比只相差一个抽象层。例如，汇编语言指令 `MOV AH, 1` 是指示计算机微处理器将二进制值1移动到 `AH` 寄存器中（寄存器是微处理器存储和帮助操纵数据的存储区域）。

每种二进制计算机编程语言最终都会被分解为二进制指令，然后物理操纵计算机微处理器的电子在预定义的 *布尔* 逻辑门（`AND`、`OR`、`NOT` 等）之间移动。经典计算机系统从上到下建立在二进制操纵和存储二进制数据之上，它们以无法估量、非凡的方式推动了世界发展。在所有二进制行为的底层是量子粒子和行为，但它们并未被用来存储和传输信息或进行计算。

然而，二进制计算机的能力存在局限性。有一些事情是二进制计算机根本无法做到或做得不够好。或者它们不够快，无法达到我们所需的实用性。例如，二进制计算机不擅长分解涉及大*质数*的数学方程。大质数通常用于数字密码学（这将在[第3章](#c03.xhtml)《量子计算如何破解当今的密码学？》中更详细地解释）。质数是大于1的任何整数，不能被除自身和1以外的任何数整除且等于整数（无余数）。从1开始的连续质数是2、3、5、7、11、13、17、19、23，等等。

二进制计算机可以分解涉及质数的方程，甚至可以分解人类不会考虑分解的涉及大质数的方程。但要分解涉及非常大质数的方程，例如计算机密码学中涉及的那些，二进制计算机需要数百到数百万年。

早期，为了确认一个质数候选，二进制计算机本质上必须检查每一个可能的数字，然后将其与候选之前的每一个数字进行核对，以确认该质数是否为质数。一些计算机科学家称之为“猜测和检查”。这并不是确认质数的一种非常有效的方法。已经有一些伟大的数学进步和算法使经典计算机能够比“猜测和检查”更省力地确认质数，但即使是它们也无力让传统计算机轻松分解由两个非常大的质数组成的方程。
