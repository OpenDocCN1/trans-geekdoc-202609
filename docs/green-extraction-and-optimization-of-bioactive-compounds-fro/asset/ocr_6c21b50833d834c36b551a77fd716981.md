# 3.4. ANFIS modeling

Using the same 50 experimental data, ANFIS modeling was used to extract the parameters, and to define the effective extraction methods of bioactive compounds from S. ruber. The results were obtained using ANFIS techniques. All the data were randomly ordered, and were grouped into three sets as data for model training, testing, and validation. The results were analyzed in MATLAB V.2013 using fuzzy logic toolbox. The construction of an ANFIS model with membership functions, five inputs, and five outputs is used in the verification of many parameters, one to ensure accuracy. There are three fuzzy sets: low, medium, and high for each of the input variables, as methanol concentration (X1), ultrasonic intensity (X2), temperature (X3), and particle size (X4). According to the experimental data, the projected output for antioxidant activities (381 mg/g; TG (35 mg/g); %DPPH (75.2%); %ABTS (84.1%); %H2O2 (85%) were specified in five fuzzy sets, ‘very’, ‘high’, ‘medium’, ‘low’, and ‘very low’. There were 222 nodes and 45 rules in the fuzzy system order. The result data from experiments and observations of people used were used to enhance the fuzzy rules.
