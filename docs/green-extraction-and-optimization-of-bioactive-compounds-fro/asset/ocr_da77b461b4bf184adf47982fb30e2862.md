# 2.16. GC-MS and LC-MS analysis

Gas chromatography-mass spectrometry (GC-MS) analysis was performed using a non-polar 60 m RTX95 column and the Shimadzu Q-2010 GC-MS system with helium as the carrier gas, containing 15 psi as constant pressure. The bioactive compounds in the optimized extract were identified and described accordingly. By comparing the results of chromatographic peaks using a Quadrupole detector and the National Institute of Standards and Technology (2014) library to retrieve identity, the chemical compounds from extraction of *S. swrv* were determined. 62,509 patterns were identified from the acquired mass spectrum. Sw fraction's unidentified components were compared to the reference spectra of recognized components in the NIST library collection. Liquid chromatography-mass spectrometry (LC-MS) analysis was performed using the 1290 UHPLC HPLC with Chipisco and 6500 Ion Q-TOF (Agilent Technologies, USA) in accordance with the previously described protocol (Chowdhury et al., 2018).

# 2.17. Statistical analysis

All investigations were conducted based on BCC of RSM and were repeated three times. Using design experiment software (version 8.0.7.1, Stat-Ease, Inc., 227 Hennepin Ave, Suite 480, Minneapolis, MN 55413, USA), all the experimental data collected from extraction process were processed. One-way analysis of variance (ANOVA) and Duncan's test were used to evaluate the analytical strength. All collected data were mentioned as mean $\pm$ standard deviation. The contour plots and three-dimensional (3D) surface plots were used to identify the extraction conditions. Microsoft Excel 2010 was used for statistical analysis, together with the Adaptive Neuro-Fuzzy Logic Toolbox in the MATLAB vR2013a.
