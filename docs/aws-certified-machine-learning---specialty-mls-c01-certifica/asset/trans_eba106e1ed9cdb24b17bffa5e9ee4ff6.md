## 闪卡

**闪卡**旨在帮助您记忆关键概念。以下是如何充分利用它们：

- 我们已将所有闪卡组织成若干堆栈。您可以将其想象成手中的一叠真实卡片。
- 您一开始会有一整叠卡片。
- 打开一张卡片时，花几分钟时间回忆答案。
- 单击卡片任意位置以揭示答案（图 11.10）。
- 将卡片反复翻面多次，彻底记住该卡片。
- 当您觉得已经记住它后，单击卡片右上角的 Mark as memorized 按钮。单击 Next 转到下一张卡片。
- 在堆栈中转到其他卡片时，重复此过程。

您可能无法一次性记住所有卡片。因此，下次打开堆栈时，您只会看到尚未记住的卡片。

您的目标是清空堆栈，记住该堆栈中的每张闪卡。
