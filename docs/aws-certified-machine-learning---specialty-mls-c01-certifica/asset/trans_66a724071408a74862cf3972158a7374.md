## 摘要

本章一开始，你就学习了如何可视化数据中的关系。散点图和气泡图是此类别中最重要的图表，分别用于展示两个或三个变量之间的关系。

接着，你进入了数据可视化的另一个类别，旨在对数据进行比较。你可以用来展示比较的最常见图表包括条形图、柱状图和折线图。表格也有助于展示比较。

接下来你学习的用例是可视化数据分布。用于展示分布的最常见图表类型是直方图和箱线图。
