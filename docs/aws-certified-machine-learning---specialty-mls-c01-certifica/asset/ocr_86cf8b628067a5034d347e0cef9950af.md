# # Chapter Review Questions

You'll find a link to **Chapter Review Questions** at the end of each chapter, just after the _Summary_ section. These are designed to help you consolidate your learning from a chapter before moving on to the next one. Each chapter will have a benchmark score. Aim to match that score or beat it before picking up the next chapter. On the _Chapter Review Questions_ page, you'll find a summary of the chapter for quick reference, as shown in Figure 11.12:
