# Practice Questions

The **Quiz Interface** (_Figure 11.8_) is designed to help you focus on the question without any clutter.

You can navigate between multiple questions quickly and skip a question if you don’t know the answer. The interface also includes a live timer that auto-submits your quiz if you run out of time.

Click `End Quiz` if you want to jump straight to the results page to reveal all the solutions.
