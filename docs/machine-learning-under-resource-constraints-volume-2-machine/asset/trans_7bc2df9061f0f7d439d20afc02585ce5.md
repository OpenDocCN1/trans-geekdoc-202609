
给定 DOM 处的脉冲序列长度可以是任意的，这取决于沉积能量的大小以及 DOM 到探测器中能量沉积位置的距离。这导致脉冲数量跨越数个数量级。虽然可变输入长度适合循环架构，但此处应用的 CNN 需要固定大小的输入张量。因此，脉冲被转换为包含九个变量的特征向量，以总结特定 DOM 处的脉冲分布。这些变量包括总电荷（与 DOM 周围的能量沉积相关）和时间信息（如首个脉冲的时间）等量。首个脉冲的时间对于方向重建至关重要，因为在给定 DOM 处的首个脉冲最不可能在撞击光电倍增管之前发生过散射。基于到达时间，可以估算发射体到接收 DOM 的距离。所有九个输入特征如[图 9.3](#9783110785951_027842.xhtml#b_9783110785968-009_fig_003)所示。请注意，这些输入特征是一种通用选择，适用于广泛的任务。特定的分类或回归任务可能受益于专用的输入特征，以强调与手头任务相关的信息。

为了获得逐事件的不确定度，网络使用高斯似然作为损失函数进行训练（省略了常数项）：

```
(9.1) $\mathcal{l} = \ln\left( y_{\text{unc}} \right) + 0.5 \cdot \left( \frac{y_{\text{true~}} - y_{\text{pred~}}}{y_{\text{unc~}}} \right)^{2}\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\left( 9.1 \right)$
```

其中 `y`[pred] 和 `y`[unc] 分别是两个子网络针对重建量及其不确定度估计的输出。结果是，网络不仅提供点估计，还提供后验分布估计。这假设残差 `Δy` = `y`[pred] − `y`[true] 服从宽度为 `y`[unc] 的高斯分布。

可以通过绘制拉分布来检验这一假设，拉分布是逐事件残差除以估计不确定度的直方图：`Δy`/`y`[unc]。对于高斯分布的残差和正确的不确定度估计，这应呈现正态分布。如[图 9.4](#9783110785951_027842.xhtml#b_9783110785968-009_fig_004)所示，三个重建量的拉分布均可用正态分布很好地描述，除了分布尾部的偏差。

验证神经网络不确定度估计的另一种方法是计算覆盖率。基于假设的高斯分布，可以计算真实值落在预测值特定分位数内的事件数量。然后将其与假设估计的高斯分布正确时、真实值应落在特定分位数内的事件数量进行比较。如[图 9.5](#9783110785951_027842.xhtml#b_9783110785968-009_fig_005)所示，覆盖率表明神经网络提供了适当的不确定度估计。

在[图 9.6](#9783110785951_027842.xhtml#b_9783110785968-009_fig_006)中，CNN 方法的角分辨率与 IceCube 的默认重建方法进行了比较，后者基于最大似然估计（MLE）。CNN 能够显著改善 10 TeV 以上级联事件的方向重建。这是寻找地外中微子源时感兴趣的能量范围，因为随着能量增加，天体物理中微子的贡献变得更具主导性。除了分辨率提高外，所需计算时间相比 IceCube 的标准重建方法减少了两到三个数量级。包括能量重建在内的更多性能比较见 [[31](#9783110785951_034588.xhtml#b_9783110785968-011_ref_031)]。

图 9.6 中的性能增益计算基于蒙特卡洛模拟。然而，模拟只是现实的近似——它包含固有的不确定度。一些不确定度来源可能是已知的，例如影响 IceCube 中光子传播的冰属性，但其他来源可能仍未被发现。对于物理分析而言，因此重要的是要充分理解这些潜在系统不确定度的影响。由于这些不确定度内在于物理实验，分析的构建方式旨在将对结果的影响最小化。因此，重建方法（其输出常直接用于分析）理想情况下应对系统不确定度具有鲁棒性。这对于基于机器学习的方法尤为重要，因为它们依赖于训练数据的正确性。
