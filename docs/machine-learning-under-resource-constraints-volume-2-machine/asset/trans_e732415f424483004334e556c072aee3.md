
缪子数 `N[μ]` 对 `α` 非常敏感。对于一个 EeV 广延大气簇射，`α` 发生 10% 的变化会大致引入缪子数 50% 的变化。因此，需要在宽能量范围内知道 `α` 才能正确计算缪子数。在简化模型中，由于同位旋对称性，`α` 为 2/3，但在真实的大气簇射中该值有所不同。会产生质子、中子和奇异强子，它们的寿命足够长，能够参与级联过程。如果将 `α` 更广泛地视为长寿命强子携带的能量分数，简化模型的结果大致仍然适用。实验上测量密切相关的量很方便：

```
R = (E_em - E_had) / (E_em + E_had)
```

其中 `E_em` 是来自光子和电子的电磁能量流，而 `E_had` 是强子能量流，平均值取自二次粒子的相空间。

这些基本的解析结果已通过完整的大气簇射模拟得到确认 [[373]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_373)。要增加模拟中的缪子数，必须增加强子多重度 `N_mult` 或减少产生的中性介子分数。然而，事实证明，增加强子多重度会以一种无法消除差异的方式改变簇射极大值深度。这在右侧的[图 5.15](#9783110785951_011899.xhtml#b_9783110785968-005_fig_015)中有说明。强子多重度的修改会使模型线沿自身平移；无法弥合与数据点的垂直差距。只有通过修改 `R` 才能做到这一点。因此，根据这项研究，减少中性介子携带的能量分数（减少 `R`）是唯一的解决方案，尽管这可以通过适度改变强子多重度 `N_mult` 来适应。目前来自 LHC 的 `R` 数据尚未将该值限制在大气簇射相关相空间所需的精度。然而，有强烈迹象表明 `R` 可能低于强子相互作用模型中目前使用的值。

### 5.4.4 CERN LHC 的相关测量

关于与大气簇射模拟相关的现有 CERN LHC 测量的全面概述见于 [[46]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_046)。LHC 主要加速质子和铅离子，并在短时间内也加速了氙离子。未来几年批准的加速氧束计划对于大气簇射物理至关重要，可用于测量 `p-O` 和 `O-O` 碰撞 [[99]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_099)，[[125]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_125)。大气簇射中最常见的相互作用是 `π-N`，`p-O` 碰撞是其极佳的参考。尽管当前最先进的模型已调整至 `pp` 数据，但它们对 `p-O` 碰撞中强子产生的预测仍显示出相当大的差异，反映了从 `pp` 参考外推的理论不确定性。除了必要的 `p-O` 直接测量外，对 `pp` 和 `p-Pb` 数据的研究对于探测潜在的标度定律和强子-离子碰撞的普遍特征也很重要。

大气簇射物理面临的一个普遍挑战是，前向区发射的强子主导大气簇射的发展，但前向区的数据稀疏。这在[图 5.16](#9783110785951_011899.xhtml#b_9783110785968-005_fig_016)中说明，其中粒子密度作为伪快度（与发射角相关，如图注所述）的函数显示。前向发射的粒子数量较少但能量更高，因此在强子级联的下一步中产生更多二次粒子。最终，大部分粒子（和缪子）是由相互作用中能量最高的粒子产生的，即那些在前向区产生的粒子。LHC 实验在中快度（`|η| < 2`）装备完善，而极前向区 `|η| > 5` 仅由热量计覆盖。LHCb 是覆盖范围 `2 < η < 5` 最前向的通用强子谱仪，得益于其专注于测量魅夸克和底夸克的衰变，因此特别受关注。在极前向区重要的是 CMS 及其 CASTOR 热量计系统、TOTEM 和 ALICE 的前向计数器，以及用于光子和中子的 LHCf 零度热量计。

正如上一节所讨论的，大气簇射中的缪子产生取决于强子多重度和电磁能量流与强子能量流的比率 `R`——或者更一般地说，取决于强子组成。

强子多重度的实验替代量是带电粒子多重度和能量流，它们已在 LHC 的 `pp`、`p-Pb`、`Pb-Pb` 和 `Xe-Xe` 碰撞中由 ALICE、CMS、LHCb 和 TOTEM 测量至 `η = 6.4`。详见 [[46]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_046)。这些前向测量很重要，因为当前一代强子相互作用模型在 `pp` 碰撞的 `|η| < 1` 处偏差小于 5%（它们已调整至旧的 LHC 数据），但在前向区偏差高达 20%。最新数据强烈约束了 `pp` 碰撞前向区的模型预测。对于 `p-O` 碰撞，仍发现 20% 的模型差异，预计随着即将到来的 `p-O` 数据将大幅减少。

强子组成对缪子产生影响最大。ALICE 和 CMS 在中快度 `|η| < 1` 提供了 `pp`、`p-Pb` 和 `Pb-Pb` 碰撞中介子、K 介子和质子相对产额的高精度数据。特别是，ALICE 在中快度 `|η| < 1` 研究了奇异强子的产生截面，并发现奇异强子与介子的产生比率随带电粒子多重度增加而上升，这一现象是普遍的（与碰撞能量和体系无关）[[36]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_036)，[[382]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_382)，如[图 5.17](#9783110785951_011899.xhtml#b_9783110785968-005_fig_017)所示。这种行为此前仅从重离子碰撞中得知，在 `p-Pb` 和 `pp` 碰撞中是意料之外的。中心区的强子密度随碰撞能量迅速上升；因此，奇异性产生的相对量也随之上升。奇异性增强伴随着中性介子的减少，从而降低了 `R`。通过玩具模拟 [[77]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_077) 研究了这种效应对大气簇射的影响，发现这种修改有可能解决大气簇射中的缪子谜题。
