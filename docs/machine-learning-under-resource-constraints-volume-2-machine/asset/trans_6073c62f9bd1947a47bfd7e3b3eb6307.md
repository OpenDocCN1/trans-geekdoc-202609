

## 7.3 成像大气切伦科夫望远镜的特征提取

**Maximilian Linhoff**

**Jens Buß**

**Lukas Nickel**

**摘要：** 成像大气（或空气）切伦科夫望远镜（IACT）数据分析的经典方法为物理学家提供了一个多阶段数据分析链，该链负责从原始望远镜数据中估算每个大气簇射的物理属性。该链中的一个关键步骤是将每个像素的时间序列简化为一组特征，这些特征表征了由 IACT 记录的事件。在本节中，我们描述了如何处理来自 IACT 的原始数据，以确定簇射图像的参数化。这些特征在分析链的后续阶段中用于估算入射宇宙粒子的物理属性（参见[第 8.4 节](#9783110785951_020762.xhtml#b_9783110785968-008_s_004)）。为了给出此类低级分析的一个示例，我们讨论了分析包 `fact-tools` 中的实现。该包作为 `streams` 框架 [[87](#9783110785951_034588.xhtml#b_9783110785968-011_ref_087)] 的扩展，在 CRC 876 内开发，用于 FACT 实验 [[88](#9783110785951_034588.xhtml#b_9783110785968-011_ref_088)] 数据的低级分析。

通常，每个 IACT 的原始数据事件包含其相机像素的数字化且未校准的电子信号，这通常是一个时间序列。事件被定义为 IACT 数据采集的单次触发，如第 4.2.2 节所述。在本节中，我们展示了 `fact-tools` 执行的连续步骤：

i) 校准原始数据并去除时间序列中的伪影，

ii) 将像素的时间序列简化为每个像素的光子数及其平均到达时间，

iii) 选择属于簇射图像的那些像素（即图像清洗），最后

iv) 将所选像素的信息（光子到达时间）简化为每个事件的一组特征。

这些特征利用描述性统计、光子分布拟合以及领域专家称为 Hillas 参数的手工特征，表征了簇射图像中光子的时空分布。这些特征在后续步骤中用于确定原初粒子的类别、能量和方向。特征提取的主要目标是在保留与手头任务最相关的大部分信息的同时减少数据量，即构建与分类或回归任务相关且不与其他特征冗余的特征。

### 7.3.1 简介

IACT 的“经典”分析方法旨在通过使用多阶段数据分析链来降低望远镜数据的维度。遵循 CTA 的术语，该链负责从数据级 RØ 到数据级 DL2 的过渡。目标是提取观测到的粒子簇射图像的有意义参数化。通过应用在模拟数据上训练的机器学习模型，所提供的特征被用于估算伽马射线事件的属性（DL3）。机器学习应用在[第 8.4 节](#9783110785951_020762.xhtml#b_9783110785968-008_s_004)中讨论。

如第 4.3.2 节所述，IACT 光传感器的测量值被数字化并存储（或流式传输）为数据级 RØ，以供分析链的进一步步骤使用。这些数据必须经过校准，以获得数据级 DLØ 的电压时间序列。然而，校准所需的操作因每个 IACT 的硬件而异。因此，本节不再进一步解释校准过程。一些当前运行的 IACT 的原始数据校准示例可参见：[334, 352]。

### 7.3.2 图像提取

IACT 数据事件重构的第一步是校准原始波形，以补偿电子模块的差异。固有地，不同像素在电子噪声、时间偏移和信号增益方面将具有不同的特性。利用激光或闭合相机快门的校准测量，可以纠正这些差异，并将电荷转换为光电子计数。

通过在波形的选定窗口上积分，将数据从一系列归一化电荷简化为图像。由于切伦科夫脉冲仅持续几纳秒，读出窗口通常大于包含光子信号的波形部分。虽然积分窗口的宽度通常可视为常数，但其位置需要为每个像素单独选择，或通过将波形与周围像素平均来确定。
