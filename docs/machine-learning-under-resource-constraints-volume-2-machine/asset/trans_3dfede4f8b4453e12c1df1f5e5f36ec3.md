由于实验和数据分析方法在许多细节上存在差异，不同实验的缪子测量结果无法直接比较。因此，它们被转换为对数 `z` 标度，其定义公式为：

```
z = (ln N[μ] - ln N[μ],[p]) / (ln N[μ],[Fe] - ln N[μ],[p])
```

其中 `ln N[μ]` 是探测器测得的缪子数量的对数，或与缪子数量成正比的任何可测量量的对数，而 `ln N[μ],[p]` 和 `ln N[μ],[Fe]` 是采用特定强子相互作用模型进行大气簇射模拟得到的相应模拟数值（在探测器层面）。虽然 `N[μ]` 强烈依赖于实验条件，但 `z` 大约与实验条件无关。此外，不同实验的结果经过交叉校准，以避免各实验独立能量校准之间的相对偏移。这很重要，因为缪子数量与（视）簇射能量近似呈线性关系。

图 5.14 中展示了九个实验和八种强子相互作用模型的能标校正 `z` 值。在 10 EeV 以上，所有模型的 `z` 值均超过纯铁簇射的值，这在天体物理学上是不可信的。此外，这些值应与基于簇射最大值深度 `X[max]` 光学测量的预测一致，后者约束了宇宙线质量成分，这是除簇射能量外 `z` 值所依赖的唯一其他方面。在 10^17 eV 以上，测得的 `z` 值超过了这些预测。

可以排除实验失误导致缪子差异，因为该效应被多个独立实验观测到。统计波动也可以以极高的置信度被排除。其他潜在的差异来源也已被排除；详见 [[46](#9783110785951_034588.xhtml#b_9783110785968-011_ref_046)]。GeV 缪子在空气中传播的重大误差也可被排除。然而，目前正在努力提高 TeV 缪子在水、冰等致密介质中传播的精度 [[148](#9783110785951_034588.xhtml#b_9783110785968-011_ref_148), [159](#9783110785951_034588.xhtml#b_9783110785968-011_ref_159), [229](#9783110785951_034588.xhtml#b_9783110785968-011_ref_229), [338](#9783110785951_034588.xhtml#b_9783110785968-011_ref_338), [339](#9783110785951_034588.xhtml#b_9783110785968-011_ref_339)]，这也将有益于这些研究。试图用奇异物理（如洛伦兹不变性破缺 [[34](#9783110785951_034588.xhtml#b_9783110785968-011_ref_034)]）或奇异天体粒子来解释缪子差异，面临挑战：这会改变簇射最大值深度涨落 [[1](#9783110785951_034588.xhtml#b_9783110785968-011_ref_001), [2](#9783110785951_034588.xhtml#b_9783110785968-011_ref_002)] 和缪子数量 [[4](#9783110785951_034588.xhtml#b_9783110785968-011_ref_004)]，而这些目前都能被模拟很好地描述。差异的早期出现（约 4 · 10^16 eV，对应首次相互作用的质心系能量 `√s ≈ 300 TeV`）是奇异理论面临的另一挑战。此类质心系能量的强子碰撞已在 LHC 被观测到，若奇异物理在这些能量下起作用，早已应发现其特征。

最合理的剩余可能性是模拟强子级联（导致缪子产生）中存在微妙偏差。近年来，在理解大气簇射物理及该差异可能的微观起源方面取得了进展，下文将讨论。由强子级联放大的模拟中相对较小的偏差，无法被当前 LHC 测量排除，甚至可能被其暗示。

## 5.4.3 大气簇射中的缪子产生

大气簇射是一个强子级联过程，宇宙线的动能通过与大气的非弹性相互作用，逐步转化为二次粒子。Heitler-Matthews 模型 [[262](#9783110785951_034588.xhtml#b_9783110785968-011_ref_262)] 是大气簇射的一个简化模型。其示意图如图 5.15 左侧所示。该模型中仅产生 π 介子（寿命最长的强子）。带电 π 介子寿命长，再次相互作用形成强子级联。中性 π 介子立即衰变为光子，形成解耦的电磁级联。电磁级联通过光核相互作用向强子级联有微弱反馈，但此处忽略该效应。

在该模型中，母 π 介子的能量均匀分配给其子代。因此，每个 π 介子的能量在每次相互作用后都会降低。经过级联的 `k` 步后，能量降至临界能量以下，此时衰变比再次碰撞更可能发生。此时，π 介子衰变为缪子。在此简化模型中，缪子数量 `N[μ]` 作为宇宙线能量 `E` 和核质量 `A` 的函数可计算为：

```
N[μ] = A · (E / (A · ξ[h]))^(β)
```

其中 `α` 是产生的带电 π 介子分数，`N[mult]` 是强子多重度（每次碰撞产生的平均强子数），`ξ[h]` 是 π 介子的临界能量（衰变比再次相互作用更可能时的能量）。
