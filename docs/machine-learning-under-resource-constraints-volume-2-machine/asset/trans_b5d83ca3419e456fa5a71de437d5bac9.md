
为了简化任务，假设源位置位于重建的簇射轴上。如果簇射轴重建不当，这种简化会引入误差来源。然而，它也使得起源估计能够分解为两个更容易求解的任务。首先，回归任务的目标是找到簇射图像重心到簇射起源（称为 `disp`）的绝对距离。其次，分类任务是找到簇射轴上的方向，这可以解释为 `disp` 的符号。这也被称为“头尾消歧”，如[图 8.16](#9783110785951_020762.xhtml#b_9783110785968-008_fig_016)所示。

该方法是为 Whipple 望远镜开发的[[241](#9783110785951_034588.xhtml#b_9783110785968-011_ref_241)]，与之前使用的方法相比，极大地提高了点源的灵敏度，但这并不能预测源位置；它仅利用 Hillas 椭圆朝向假设源位置的方向。`disp` 通过以下公式参数化：

```
(8.18) disp = ξ (1 - width/length), [241,(7)] (8.18)
```

这也是 FACT-Tools 分析所使用的参数化。参数 `ξ` 要么通过优化已知强源的观测数据获得，如[[241](#9783110785951_034588.xhtml#b_9783110785968-011_ref_241)]所示；要么通过模拟获得，如 FACT-Tools 所用。由于该参数 `ξ` 只是一个固定数值，公式 (8.18) 无法在宽能量范围内很好地预测 |disp|。FACT-Tools 中使用的值 `ξ` = 1.38° 在约 3 TeV 能量附近表现最佳，见[图 8.17](#9783110785951_020762.xhtml#b_9783110785968-008_fig_017)，但在更高能量下表现差得多。FACT-Tools 的头尾消歧使用了依赖于点源已知位置的特征。虽然这极大地提高了预测效率——特别是对低能伽马射线——但也增加了假阳性率，因为包括弥散强子本底在内的所有簇射更多地被预测为朝向疑似伽马源方向。由于预测并不独立于源位置，因此必须对 off 位置重复预测，每增加一个 off 位置计算成本就会增加。这也阻碍了天图的创建，因为单个事件没有唯一的预测位置。

MAGIC 实验利用依赖于图像参数（如 size）的参数，改进了公式 8.18 中的简单参数化，以建模能量依赖性和溢出效应，从而更好地处理未完全包含在相机视野内的簇射。最终在 2009 年，在 MAGIC-II 建成并转向立体重建技术之前，评估了使用随机森林回归器估计 `disp` 的方法，发现其性能优于之前的参数化。在这种情况下，`sgn disp` 的预测是利用图像重心与其最亮像素之间的差值完成的，这与光分布的偏度有关。为了将这些方法适配到 FACT-Tools 分析链中，`disp` 估计被构建进了 `aict-tools`。为了进一步改进先前的工作，头尾消歧采用了随机森林分类器。这导致在探测器坐标系中每个事件都有一个单一的起源预测，该预测可转换为 ICRS 中的位置。基于机器学习的方法与先前使用方法的结果对比见[图 8.17](#9783110785951_020762.xhtml#b_9783110785968-008_fig_017)。

### 8.4.5 组合多台望远镜

有了多台望远镜，起源重建变得简单得多。每台望远镜相机中的主簇射轴连同望远镜位置定义了一个平面。初级粒子的方向现在是由各个望远镜定义的所有平面的交线。[[101](#9783110785951_034588.xhtml#b_9783110785968-011_ref_101)] 提出的解决方案是取所有可能的双望远镜交点的加权平均，从而对 `N` ·(`N`−1)/2 条两平面交线进行平均。各望远镜的权重使用 `w[i]` = size · length/width，这给更亮（大 size）和更细长的事件赋予更大权重，因为对于这些事件簇射轴的确定更精确。

这种几何方法在望远镜数量较多时（即 `N` ≥ 4）表现最佳。对于望远镜较少的立体阵列（如两台 MAGIC 望远镜）或 CTA 中的极低能量簇射，`disp` 方法的立体版本能产生略好一些的结果[[289](#9783110785951_034588.xhtml#b_9783110785968-011_ref_289)]。

在此方案中，每台望远镜单独估计 `disp`，每台望远镜产生两个可能的源位置。然后，仅使用每台望远镜的一个源位置，采用最小二乘法求解。

对于其他参数，使用单望远镜预测的加权平均值。然而，机器学习模型可以接收来自立体重建的特征和阵列的聚合值，与单望远镜情况相比，极大地提高了学习器性能。

### 8.4.6 最终事件选择

事件重建的最后一步——或者更确切地说是任何后续分析的第一步——是选择用于进一步处理的事件，根据估计的 gammaness（伽马度）丢弃事件，如果分析点源，还根据估计的方向丢弃事件。

一如既往，这是本底抑制与信号保留之间的权衡。针对不同类型的研究，需要做出不同的权衡。谱分析和空间分析通常可以容忍较高的本底，而弱源探测通常需要更强的本底抑制，以便根本找到显著信号。
