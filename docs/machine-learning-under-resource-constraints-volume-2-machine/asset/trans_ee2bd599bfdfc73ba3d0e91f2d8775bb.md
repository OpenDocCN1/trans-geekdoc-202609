除了入射粒子的到达方向外，其能量在许多分析中也很重要。由于测量的间接性质，粒子能量无法直接获取，因此改为推导与能量相关的可观测量。这些依赖能量的可观测量对于重建中微子能谱尤为重要（见[第 10 章](#9783110785951_034588.xhtml#b_9783110785968-010)）。在 IceCube 中，使用各种算法重建依赖能量的变量（例如见 [[32]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_032)）。总电荷 (*Q*[tot]) 是一个特别直观的例子。数字光学模块 (DOM) 收集的电荷量（见第 2.2.1.1 节）与该 DOM 观测到的切伦科夫辐射量成正比，后者又与入射粒子的能量成正比。*Q*[tot] 因此为粒子能量提供了一个直观的近似，且重建相对简单。然而，该替代指标并未考虑探测器几何结构或探测介质的性质。显而易见，一条穿越整个探测器的长轨迹，将在探测器内发射比所谓的*擦边通过事件*更多的切伦科夫光，后者仅穿越探测器的一小部分。比较穿越深层清澈冰层的粒子与穿越大量尘埃层的粒子时，情况也是如此，后者会吸收相当一部分光线。为了考虑这些效应，需要更复杂的重建算法。

一种更复杂的能量重建示例是所谓的*截断平均* [[32]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_032)，它丢弃了沿轨迹随机发生的大能量损失（主要通过*制动辐射*），从而避免了能量重建的畸变。另一个例子是使用缪子能量作为替代指标，它比中微子能量更容易直接获取，但也受到上述探测器几何结构和探测介质限制的影响。通过利用深度神经网络（见第 9.2.2 节），可以获得更精确的粒子能量重建及其他某些性质的重建。

对于基于机器学习的分析，除了现有特征外生成新特征通常是有益的。这些新特征可以基于现有特征，这还有一个额外优势：将两个或多个重建变量中包含的信息浓缩为一个特征。这种方法的优势在于，在训练、测试和应用所用分类算法时，可以节省一定的计算资源。IceCube 中入射粒子的天顶角 *θ* 是一个相对简单的例子。由于该性质由多个重建算法提取，不同算法关于 *θ* 的一致性为区分重建良好与重建不佳的事件提供了有价值的判据 [[16]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_016)。IceCube 中更复杂的特征工程方法见文献 [[91]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_091)。

## 特征选择

虽然 DOM 获得的波形可直接用于深度学习应用（见[第 9.2 节](#9783110785951_027842.xhtml#b_9783110785968-009_s_002)），但更传统的特征提取要求事件通过标准化重建算法处理至内部所谓的 3 级 [91, 329, 341, 342]。所用处理算法的类型（因此也用于特征提取）强烈依赖于观测通道（见第 4.2.3 节）。关于 IceCube 数据级别的详情，请参阅第 4.3.3 节。在 3 级（即本节讨论的基于机器学习分析的起点），每个事件由 1200 多个属性表征 [91, 329, 341, 342]。为了降低后续机器学习分析的计算成本，减少特征空间的维数是有益的。然而，挑战在于如何在信息损失最小的情况下实现这种降维。需要一种能够考虑特征交互、提升学习性能、针对大型特征集扩展良好，且对未见总体数据保持稳定的方法。*FastEnsemble* 算法提供了此类方法的快速计算 [[344]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_344)。它已成功应用于 IceCube 数据 [[332]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_332)。以下将详细描述该方法，重点关注特征选择及其稳定性对中微子物理分析的影响。

比较在 59 串、79 串和 86 串配置下 IceCube 采集数据所进行的特征选择，可以发现存在某些反复出现的模式，而差异主要源于可用特征提取算法的改进以及探测器本身的改进。与 59 串配置相比，79 串和 86 串配置表现出更均匀的仪器布置（有关不同探测器配置的详情见第 4.2.3 节）。此外，随着时间的推移，人们对某些探测器性质（如冰的性质）有了更深入的理解。
