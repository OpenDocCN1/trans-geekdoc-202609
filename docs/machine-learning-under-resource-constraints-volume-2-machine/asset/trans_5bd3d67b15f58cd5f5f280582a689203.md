
# 天体粒子物理模拟

## 摘要

在天体粒子物理学中，从大气层外缘到探测电子学信号的所有相互作用的级联序列，必须用蒙特卡洛模拟来描述。触发此类级联的第一批粒子可以是高能光子、电子、中微子或宇宙线原子核。根据所考虑的问题，这些粒子中的任意一种或其任意衍生物都可以是待分析的信号。因此，什么是信号、什么是背景取决于物理问题。因此，这些信号必须从理论上进行完整的物理模拟。由于天气导致的测量条件变化，以及切伦科夫望远镜的天顶角变化，特别是大气层中相互作用的模拟需要大量资源。通过将计算机科学方法与模拟智能结合，可以将资源消耗降至最低。在本节中，将介绍所应用和开发的模拟程序，并阐述协同研究中心（CRC）中开发的机器学习与蒙特卡洛模拟相结合的动机。

## 模拟在天体粒子物理中的作用

在天体粒子物理学中，粒子产生于遥远的银河系或河外源，这些源无法直接观测，且先验性质未知。它们以任何当前运行的（实际上在技术上可行的）人造粒子加速器都无法企及的能量到达地球。因此，模拟在天体粒子物理领域起着至关重要的作用。天体粒子物理学家必须依赖这些模拟对信号和背景事件的描述是完整且准确的，以便进行有意义的分析。然而，正如本节所述，物理学家面临的挑战，特别是在资源管理和效率方面，是多方面的。

## 广延大气簇射与模拟挑战

由于地球大气层对高能光子和宇宙线不透明，它们与空气中的原子核相互作用，产生称为广延大气簇射的次级粒子级联。虽然其基础物理原理当然与描述粒子物理实验中相互作用所用的原理相同，但仍有一些重要差异需要考虑。

首先，簇射中的相互作用通常被强烈推向前向，而最高能量的粒子物理实验则在正碰撞构型下运行和观测，如`大型强子对撞机`。这也意味着，天体粒子物理感兴趣的区域无法用加速器实验轻松测量，因为前向粒子会在束管中丢失。

其次，涉及的能量可比对撞机实验达到的能量高出几个数量级，这意味着需要对物理进行合理推演，将其外推到更高能量。

## CORSIKA 模拟框架

原则上，该级联的每个物理相互作用都需要单独采样，以创建完整的大气簇射模拟。这一想法由大气簇射模拟工具 `CORSIKA` 实现，它是用于此目的最常用的模拟框架，且在天体粒子物理学的许多实验中已使用了30多年。

基础物理的描述主要由外部工具提供，可分为两个不同组件：

1.  **电磁分量**：描述电子、正电子和光子在粒子簇射中的相互作用。该分量可用 `EGS4` 的修改版描述，提供直接蒙特卡洛模拟；或用 `NKG 公式` 描述，该公式提供了一种描述电磁分量的解析方法。
2.  **强子相互作用**：包含低能和高能分量。
    *   低能强子相互作用可用 `FLUKA`、`GHEISHA` 或 `UrQMD` 模型描述。
    *   高能强子相互作用可用 `DPMJET`、`HDPM`、`QGSJET01`、`QGSJET II-04`、`SIBYLL`、`VENUS`、`NEXUS` 或 `EPOS LHC` 模型描述 [194]。

使用不同模型描述强子相互作用，可能导致簇射模拟结果显著不同。这是不同模型将对撞机实验结果外推到粒子物理实验目前技术上无法企及的能量和快度区域时，提供了不同外推结果的效应。这显示了簇射物理挑战与粒子物理之间的重要联系，即所谓的**缪子谜题**更凸显了这一点：广延大气簇射实验测得的缪子数量与簇射模拟结果相比存在高度显著的差异。该缪子谜题及其对粒子物理和天体粒子物理的影响详见[第 5.4 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_004)。

## 计算效率与优化策略

由于广延大气簇射中的每个相互作用都需要单独采样，其完整模拟是一项高度耗时的任务。此外，这种随机性质使得即使初始条件相同的簇射，其发展过程也可能不同，从而看起来完全不同。这意味着必须模拟大量簇射才能获得统计上完整的描述，特别是如果需要全天宇宙线描述时。

在 CRC 876 的背景下，已投入巨大努力寻找提高模拟效率的方法。

### 早期终止策略

一种可能的方法是限制对特定目的不重要的簇射的模拟时间，例如，它们未击中探测器。为此，可以训练模型，确定在何时可以提前终止簇射或簇射一部分的模拟。该策略详见[第 5.2.1 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_002_s_001)。

### 主动类别选择

当为分类任务（如信号-背景分离）模拟一组大气簇射时，底层初始状态的分布可以自由选择。然而，为了优化所需的计算资源，希望找到一种对底层分类模型训练最优的分布。一种利用机器学习技术解决此问题的方法称为**主动类别选择**，详见[第 5.2.2 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_002_s_002)。

### 硬件效率

虽然上述方法侧重于在软件层面寻找改进，但也可以在底层硬件中寻找潜在改进。这尤为重要，因为电力成本是计算密集型任务的主要限制因素。为此，正在研究并展示在 `CORSIKA` 模拟中使用低功耗硬件来提高资源效率的改进，详见[第 5.2.4 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_002_s_004)。

## 现代化：CORSIKA 8

随着软件框架 `CORSIKA` 的改进日益先进，其底层代码库（部分最初开发于 30 年前）已达极限。`CORSIKA 8` 的开发代表了向现代代码库过渡的必要性。此过程旨在内在提供现代功能，如硬件加速或并行化，并通过提供模块化、可扩展的代码结构，为开发者实现新功能创造更便捷的途径。这一可视为现代化科学软件典范努力的过渡，详见[第 5.2.3.2 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_002_s_003_s_002)。
