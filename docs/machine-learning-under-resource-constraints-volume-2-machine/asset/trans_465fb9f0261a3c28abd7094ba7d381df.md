
可用的 MC 数据集随后被划分为训练、验证和测试数据集，其中训练数据集是三者中最大的。神经网络在训练数据集上使用不同的超参数集（隐藏节点数量、隐藏层数量、神经网络优化器的超参数等）进行训练，最佳超参数集是根据在验证数据集上评估的判别力来选择的。通过比较训练和测试数据集的神经网络输出分布来检验可能的过拟合，如[图 8.21](#9783110785951_020762.xhtml#b_9783110785968-008_fig_021)所示。在神经网络输出分布中，背景和信号的分离程度远优于各个输入变量的分布，信号在神经网络输出值接近 1 处达到峰值。此外，对于信号和背景，训练和测试分布在 MC 样本的统计不确定性范围内一致，表明不存在过拟合。实际上，[图 8.21](#9783110785951_020762.xhtml#b_9783110785968-008_fig_021)中仅展示了一种 FCNC 信号类型的此项测试，即与左手性上夸克耦合的 FCNC。实际上，整个分析（包括神经网络训练）针对右手性 FCNC 耦合以及与左、右手性魅夸克耦合的 FCNC 重复进行。这是必要的，因为输入变量的分布取决于 FCNC 耦合的选择。上夸克和魅夸克耦合之间的差异（源于与价上夸克的耦合，相反，魅夸克来自质子海）导致不同的运动学和轻子电荷输入分布。耦合手征性的影响较小，但仍会影响顶夸克衰变产物的运动学分布。由于弱相互作用的特定性质（仅与左手性粒子耦合），弱顶夸克和 W 玻色子衰变导致轻子 `p`[T] 的运动学分布不同，具体取决于 FCNC 耦合的手征性。

解盲后，对信号区的神经网络输出分布和两个控制区的分布执行分箱轮廓似然拟合。该拟合的结果针对信号区和 `W` + `γ` 控制区展示在[图 8.22](#9783110785951_020762.xhtml#b_9783110785968-008_fig_022)中。此拟合包含受各自系统不确定性约束的系统变化的恼人参数。同时对所有区域进行拟合允许这些恼人参数被调整以最佳拟合数据。控制区的数据允许我们调整并潜在地约束背景建模的恼人参数。

确实，某些恼人参数在拟合中可能完全不受约束，在本分析中这是为了归一化 `W` + `γ` 过程而进行的。其归一化完全由数据决定，因此信号区的 `W` + `γ` 归一化主要由 `W` + `γ` 控制区的数据决定。然而，人们需要小心，以确保这种外推是合理的。实际上，信号区的 `W` + `γ` 事件主要与 `b`\-jets 关联产生，而控制区的 `W` + `γ` 事件则不然。一种解决方案是为控制区和信号区的 `W` + `γ` 归一化引入单独的恼人参数，使归一化完全解耦。本分析采用的解决方案是根据其系统不确定性，为伴随 `b`\-jets 产生的 `W` + `γ` 施加一个额外的恼人参数。该额外恼人参数随后主要由控制区的数据解除约束。

正如[图 8.22](#9783110785951_020762.xhtml#b_9783110785968-008_fig_022)所示，控制区和信号区的神经网络输出分布均由拟合后的 MC 预测很好地描述，即在轮廓似然拟合中所有恼人参数调整后。![图 8.22：FCNC 搜索中神经网络输出的数据-MC 对比，针对 W + γ 控制区（左）和信号区（右）。信号以任意截面叠加，底部面板显示数据与 MC 预测的比值 [67]。](graphic/b_9783110785968-008_fig_022.png)

### 8.5.3 搜寻新重粒子：矢量型夸克

上一节讨论了在 SM 背景之上搜寻非共振 BSM 贡献的一个例子。这意味着我们在寻找无法在 LHC 分辨的新粒子，因为例如它们的质量太大。然而，LHC 提供了实验室粒子物理实验中迄今达到的最高质心能量，这意味着我们可以通过它们对 SM 谱的共振贡献直接搜寻新的重粒子。

在 LHC 可能观测到的一种新重粒子是矢量型夸克（VLQ）。SM 的一个大问题是为什么恰好有三代费米子。先验地，没有充分的理由说明代数必须是三，人们可以询问是否存在第四代夸克。然而，在希格斯玻色子发现后，很明显第四代不能只是另一个更重的手征夸克双重态 [[145](#9783110785951_034588.xhtml#b_9783110785968-011_ref_145)]，因为希格斯玻色子与费米子的耦合与其质量成正比，如此重的第四代将通过环显著贡献于希格斯玻色子产生截面和若干衰变分支比。然而，如果重夸克是矢量型的，即它们的电弱耦合不遵循典型的 V−A 结构，而是作为矢量（V）耦合，SM 拉格朗日量可以简单地包含一个直接质量项。它们的质量不源于希格斯机制，来自希格斯玻色子截面和分支比的约束将不再适用！实际上，这些 VLQ 存在的动机更多。特别是，它们出现在解释电弱尺度（246 GeV）和普朗克尺度（𝒪(10^(19)) GeV）之间巨大差异的模型中 [[221](#9783110785951_034588.xhtml#b_9783110785968-011_ref_221)]，以及如果它们主要与第三代夸克耦合（即顶夸克和底夸克），解释费米子质量巨大层级的模型中 [[220](#9783110785951_034588.xhtml#b_9783110785968-011_ref_220)]。这意味着它们的主要衰变道将是一个第三代夸克加一个玻色子：`tZ`、`tH`、`tW`、`bZ`、`bH` 和 `bW`。此处讨论的搜寻重点是具有与 SM 夸克相同电荷（+2/3*e* 和 −1/3*e*）的 VLQ，传统上分别用符号 `T` 和 `B` 表示。这些粒子的质量是搜寻的自由参数，因为它们未被预测，但有充分的动机认为它们处于 1 TeV 量级。
