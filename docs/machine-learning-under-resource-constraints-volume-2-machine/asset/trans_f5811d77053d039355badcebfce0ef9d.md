

#### 5.2.2.2 启发式方法

**自然** 使用部署时也会出现的类别比例进行采样，即 `w(y) = u(y) = P(Y = y)`。虽然自然策略在准确率方面通常表现得极具竞争力，但有时会被其他启发式方法击败。

**逆向** 按类别准确率的倒数采样，`u(y) = Acc[h](y)^−1`。该策略基于这样一个假设：低准确率完全是由训练数据量不足导致的。

**改进** 类似于逆向方法，但基于上一次迭代中准确率的提升 `u(y) = (Acc[h](y) − lastAcc[h](y))^−1`。该策略假设具有“稳定”准确率的类别在未来的迭代中将保持稳定。

**重新划分** 统计上一次迭代中预测发生变化的样本数量 ![](graphic/b_9783110785968-005_ingr_003.png)。该策略背后的思想是：靠近决策边界的样本可能比其他样本更有信息量。预测频繁变化的类别被假定包含许多靠近该边界的样本。

多项后续研究 [113, 204, 299, 391] 已在不同设置中应用了这些启发式方法。还提出了一种额外的启发式方法，称为“PAL-ACS” [[232](#9783110785951_034588.xhtml#b_9783110785968-011_ref_232)]，它将经典主动学习策略嵌入 ACS 中。其思路是评估一组伪实例 ![](graphic/b_9783110785968-005_ingr_004.png)，然后根据主动学习效用度量 `u[AL] : 𝒳 → ℝ` 聚合类别效用。这种方法需要一个生成模型来产生伪实例，以及一个主动学习效用函数（如熵）。

![](graphic/b_9783110785968-005_ingr_005.png)

然而，这些复杂的 ACS 策略往往无法超越*自然*策略，后者甚至不考虑 [图 5.5](#9783110785951_011899.xhtml#b_9783110785968-005_fig_005) 中 ACS 框架所提出的模型性能 [232, 254]。事实上，我们在理论上已经评估了，在数据获取的极限情况下，自然类别比例能产生最优的分类器性能 [[106](#9783110785951_034588.xhtml#b_9783110785968-011_ref_106)]。这些发现表明，复杂策略相对于自然类别比例的潜在优势在获取过程中正在丧失。

#### 5.2.2.3 认证

除*自然*策略外，现有的 ACS 策略 [232, 254] 并未考虑训练模型在部署期间需要处理的类别比例；它们仅关注类别的感知*难度*。然而，*自然*策略要求从业者精确地预先知道部署类别比例。如果我们不精确知道部署类别比例，而是带有一定程度的不确定性知道它们，该怎么办？例如，天体粒子物理学家只能粗略估计其信号类与背景类的比率，大约为 1 : 10³ 甚至 1 : 10⁴ [[88](#9783110785951_034588.xhtml#b_9783110785968-011_ref_088)]。

解决这些不确定性的一种方法是对 ACS 训练模型进行*认证* [[104](#9783110785951_034588.xhtml#b_9783110785968-011_ref_104)]。为此，我们认证一组类别比例 P，使得在 ACS 诱导的源分布 S 上训练的固定假设 `h` 可以安全地应用于这些比例。“安全地”是指：在目标分布 T 上部署时，`h` 仅以高概率诱导很小的 ACS 诱导误差。

#### 5.2.2.4 针对不确定类别比例的策略

证书可以帮助从业者评估 ACS 训练模型的实用价值。然而，当部署类别比例不确定时，它对如何获取数据——即 ACS 策略——没有直接的启示。因此，我们提出了一种 ACS 策略 [[103](#9783110785951_034588.xhtml#b_9783110785968-011_ref_103)]，旨在根据部署类别比例 `p[T]` 的先验分布 ![](graphic/b_9783110785968-005_ingr_013.png)，尽可能减小公式 5.1 中的域间差距 `Δp · Δℓ`。这一目标将允许任何二分类算法根据领域专家的先验信念，学习目标域的准确预测。例如，在天体粒子物理学中，这种信念可以是关于伽马粒子和强子粒子比例的先验分布。
