### 5.4.5 SPS 和 LHC 的固定靶实验

由于大气簇射中的强子相互作用跨越了核子-核子碰撞系统中心-of-mass 能量的许多数量级，因此在固定靶实验 [[268](#9783110785951_034588.xhtml#b_9783110785968-011_ref_268)] 可达到的较低中心-of-mass 能量下，也存在改进我们知识的机会。固定靶实验的一个优势是靶材选择的灵活性，这使其成为研究各种系统中核效应的理想选择。

超质子同步加速器（LHC 的前加速器）上的 NA61/SHINE 实验已测量了 `pp`、`π`-C 和 `p`-C 碰撞中的强子产生，其中碳被用作空气的替代表。在众多测量中，我们重点介绍前向 `ρ`⁰ 和反质子产生的测量 [[38, 317](#9783110785951_034588.xhtml#b_9783110785968-011_ref_038)]，见 [图 5.18](#9783110785951_011899.xhtml#b_9783110785968-005)。`ρ`⁰ 产生很重要，因为它是在电荷交换反应 `π`^− + `p` → `π`⁰ + `n` + `X` 中产生 `π`⁰ 介子的一种替代途径。`ρ`⁰/`π`⁰ 比率的增大会降低 `R` 并增加大气簇射中的 μ子 数。反质子是大气簇射中重子生成的度量，会降低 `R`。尽管在每次相互作用中流向这些粒子种类的能量流很小，但多次相互作用的累积效应导致，与不包含这些效应的 SIBYLL-2.1 相比，运行包含这些效应的最新版 SIBYLL-2.3d 产生的大气簇射 μ子 数增加高达 60% [[324](#9783110785951_034588.xhtml#b_9783110785968-011_ref_324)]。虽然这一变化显著，但并未解决 μ子 差异，因为 SIBYLL-2.1 以前产生的大气簇射 μ子 特别少。用 SIBYLL-2.3d 模拟的大气簇射 μ子 产生现在与用 EPOS-LHC 模拟的相当。

在 LHC，固定靶实验由带有 SMOG 装置 [[15](#9783110785951_034588.xhtml#b_9783110785968-011_ref_015)] 的 LHCb 执行，该装置将少量气体注入探测器。该原始系统旨在研究束流剖面，但已被用于限制质子内部的固有魅 [[12](#9783110785951_034588.xhtml#b_9783110785968-011_ref_012)] 并测量 `p`-He 碰撞中的反质子产生截面 [[14](#9783110785951_034588.xhtml#b_9783110785968-011_ref_014)]，这对于建模太空中的宇宙射线相互作用是必要的。作为 LHCb 为第 3 运行期升级的一部分，原始装置已被一个开放储存池取代，该储存池允许更高的气体密度和更多靶气体，包括氮和氧 [[76](#9783110785951_034588.xhtml#b_9783110785968-011_ref_076)]。利用固定靶模式下的 LHCb，将能够在核子-核子中心-of-mass 系中，研究中快度 −2.5 < `η`[cms] < 0.5 处的强子产生 ![](graphic/b_9783110785968-005_ingr_038.png)。

### 5.4.6 总结与展望

宇宙射线界发现了由超高能宇宙射线引发的大气簇射中 μ子 产生的差异。在大气簇射模拟中观测到 μ子 赤字，经过仔细评估，这只能归因于大气簇射中强子级联的建模错误，从而导致 μ子 产生的差异。解决这一差异最合理的方法是，随着碰撞能量增加，适度降低前向区域中性 π 介子相对于长寿命强子的能量流。

前向区域中性 π 介子和长寿命强子的相对能量流，可以通过 LHC 的质子-质子和质子-离子碰撞测量来约束。即将进行的 LHC 质子-氧和氧-氧碰撞先导运行尤为重要。具有前向接受度的实验——ALICE、CMS、LHCb、LHCf 和 TOTEM——提供了最好的实验约束。LHCb 是前向区域唯一完全装备的、具备强子识别能力的通用谱仪。其他实验在极前向区域提供能量测量和粒子计数信息。

ALICE 发现的在中快度高密度碰撞中普遍存在的、依赖于多重度的奇异性增强，可能是解决 μ子 谜题的潜在方案。这一效应背后的确切机制目前尚不清楚。利用 LHCb 和 LHCf 在前向区域进一步测量可能的奇异性增强正在进行中。以固定靶模式运行 LHCb 研究 LHC 束流与氮、氧的碰撞，将为大气簇射研究提供进一步的机会。
