

## 分类得分分析

[图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 描绘了信号（向上 `ν[μ]`，蓝色）和各种可能的本底来源所获得的分类得分。尽管主要本底成分是大气缪子（青色），但其他可能的本底来源也可能存在于样本中。这些成分包括 `ν[e]` 和 `ν[τ]`，它们将在探测器中产生级联类事件。对于源自 NC 而非 CC 相互作用的 `ν[μ]` 也是如此。观察 [图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 可以发现，低分类得分主要由本底事件主导（特别是大气缪子），而信号事件则主要集中在高分类得分处。在 `c[i] = 0`（大气缪子）和 `c[i] = 1`（`ν[μ]`）处观察到的两个明显的极大值是此类分析的典型特征。

还可以发现，分类器应用于切分（`c[i] ≥ 0.5`）的默认设置在这种情况下是不够的。以这种方式选择的样本将由大气缪子主导，后者在此得分下仍然丰富一个数量级。相反，需要在 `c[i]` 上设置用户定义的切分，以达到足够高的纯度（`P ≥ 99%`），这是谱重构所要求的。然而，应注意正确理解纯度要求，因为重要的不是数值本身。由于大气和天体物理中微子的能谱陡峭下降，必须针对各个能量箱考虑大气缪子的污染。过多的大气缪子事件会改变重构谱的形状，从而也改变其物理解释，尤其是在高能量下。由于中微子诱导的缪子数量在低能量下显著较大，因此在这些箱中可以允许一定的缪子污染。

从 [图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 还可以发现，即使在高分类得分下，大气缪子也是主要的本底成分。所有其他本底成分的贡献比大气缪子小 1–2 个数量级，因此在后续的展开中可以忽略不计。

如前所述，在此阶段通常将训练好的分类器应用于实验数据，以便将分类得分的结果与模拟预期的结果进行直接比较。为了获得 [图 8.7](#9783110785951_020762.xhtml#b_9783110785968-008_fig_007) 中所示的结果，使用了与 [图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 完全相同的分类器。实验数据的分类得分用绿色表示，而模拟数据获得的得分用蓝色表示。与 [图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 不同，这里仅显示所有模拟成分的总和。可以发现，这两个分布吻合良好。特别是 `c[i] = 0.0` 和 `c[i] = 1.0` 处的两个明显极大值得到了很好的复现。

虽然在基本所有此处讨论的分析中都存在对获得的 `c[i]` 应用额外切分的必要性，但该切分的选择在各个分析之间有所不同。在使用 59 串配置 IceCube 获得的数据分析 [[212]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_212) 中，选择了极其严格的 `c[i] = 1.0` 切分；而在使用 79 串配置 IceCube 获得的数据分析 [[18]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_018) 中，则选择了相对宽松的 `c[i] ≥ 0.92` 切分。为了观察高能量下谱可能的变平，从而实现对高能天体物理中微子通量的与模型无关的确证，必须确保有足够数量的高能事件通过事件筛选。

![Fig. 8.7: Classification score obtained for data and simulation. For simulations the sum of all contributing components is shown. Figure adapted from [91].](graphic/b_9783110785968-008_fig_007.png)

**图 8.7：** 数据和模拟获得的分类得分。对于模拟，显示所有贡献成分的总和。图片改编自 [[91]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_091)。

为实现这一点，在 [[341]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_341) 和 [[91]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_091) 中应用了二维切分，这也考虑了分类器输出的能量依赖性。在 [[341]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_341) 中，如果事件的估计能量被发现在 10 TeV 以下，则选择 `c[i] ≥ 0.87` 的事件通过筛选。对于所有其他情况，选择 `c[i] ≥ 0.7` 的事件通过筛选。[[91]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_091) 中呈现的最终筛选稍微复杂一些。为了在样本中获得足够多的事件数量，置信度切分在宽度为 `w` 的 `N` 个重叠窗口中进行优化。切分经过优化，以达到 `P ≥ 99.7%` 的纯度。

分类得分与估计缪子能量的相关性如 [图 8.8](#9783110785951_020762.xhtml#b_9783110785968-008_fig_008) 所示。实验数据的结果显示在左侧较大的面板中，而不同模拟谱成分的结果显示在右侧较小的面板中。黑色和灰色实线分别表示针对 `86° ≤ θ ≤ 111°` 和 `111° ≤ θ ≤ 180°` 天顶带应用的二维切分。`c[i] = 0.0` 和 `c[i] = 1.0` 处的两个明显极大值在此可视化中也清晰可见。然而，与 [图 8.6](#9783110785951_020762.xhtml#b_9783110785968-008_fig_006) 不同，可以发现具有高分类得分的大气缪子集中在约 `10³ GeV` 的缪子能量附近。这清楚地表明了研究分类得分与其他关注变量之间相关性的好处，这允许应用更复杂的切分，从而选择更多的中微子候选事件。优化过程中为不同天顶区域获得的不同切分表明，在切分优化中纳入更多维度是有益的。

尽管所讨论的各分析之间的具体选择在一定程度上有所不同，但可以总结出：选择中微子诱导缪子所需的基本概念步骤保持不变。这些步骤始于对入射粒子估计到达方向应用一个基本且直接的几何切分。随后是专门的特征选择（本节未涵盖，详见 [第 7.2 节](#9783110785951_015782.xhtml#b_9783110785968-007_s_002)），旨在为基于机器学习的事件筛选选择输入变量。最后，必须对分类器输出应用切分，以应对压倒性多数的大气缪子。
