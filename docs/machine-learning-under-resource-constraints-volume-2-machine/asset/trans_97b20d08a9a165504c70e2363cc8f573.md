
LHCb 模拟是一个软件链，它利用了多个专用软件包。质子-质子碰撞由 `Pythia` [353, 354] 生成。强子衰变由 `EVTGEN` [[239](#9783110785951_034588.xhtml#b_9783110785968-011_ref_239)] 模拟，光子辐射由 `PHOTOS` [133, 180] 模拟。粒子与探测器材料的相互作用由 `GEANT4` [40, 50] 模拟。最后，探测器中电子学的内部响应由软件 `BOOLE` [[128](#9783110785951_034588.xhtml#b_9783110785968-011_ref_128)] 模拟。在此之后，模拟事件的处理方式与真实事件相同。LHCb 数据获取系统见第 4.2.1 节。下文将进一步讨论各个步骤。

`Pythia` 的任务是尽可能准确地模拟高能质子-质子碰撞及其产生的粒子。与模拟链中的任何程序一样，它使用蒙特卡洛方法，一般来说，该方法将一个复杂过程分解为依次发生的小型随机过程。在质子-质子碰撞中，模拟始于来自碰撞质子的夸克和胶子的一次或多次硬散射。起初，部分子（部分子是夸克或胶子的统称）具有高能量。部分能量以胶子形式辐射出去，部分胶子转化为夸克-反夸克对。这些过程级联并形成部分子簇射。部分子-部分子相互作用以及与未发生碰撞的束流中其他质子的相互作用也被考虑在内。当部分子簇射中产生的夸克单位能量降至某一阈值以下时，簇射结束，夸克结合形成色中性强子，这由强相互作用的禁闭性质决定。强子化是一个复杂的过程，存在多种有效算法。为了正确获得强子的性质，使用了局部部分子-强子对偶性，这意味着强子的动量流和量子数主要与相应的部分子相同。更多细节请参阅 Lund 串碎裂模型 [[54](#9783110785951_034588.xhtml#b_9783110785968-011_ref_054)]。

产生的大多数强子是不稳定的。强子衰变由 `EVTGEN` 模拟。该程序旨在准确描述与旨在研究味物理的实验相关的衰变所涉及的所有基础物理，例如角依赖和时间依赖、`CP` 破坏、与量子真空的相互作用，以及中性粒子混合为其反粒子。该程序确保衰变产物的动量和自旋正确相关。正确模拟这些相关性很重要，因为某些物理分析会利用它们，例如所谓的味标记，这是一种判断母强子是粒子还是反粒子的算法。更多细节请参阅文献 [[239](#9783110785951_034588.xhtml#b_9783110785968-011_ref_239)]。

下一步是用 `PHOTOS` 模拟带电粒子的光子辐射。该程序负责模拟发射光子的能量和方向，以及发射粒子动量和能量的变化。轫致辐射对多项 LHCb 分析很重要，因此需要准确的模拟。LHCb 触发器使用探测到的量热器中的光子。此外，粒子和共振的产生与衰变中的轫致辐射会改变测量分布的形状。而且，LHCb 重构包含一个算法，将来自轫致辐射的光子与其电子发射体结合，从而近似恢复电子发射前的能量和动量。这减小了由其子粒子的能量和动量重构的祖先粒子质量中的偏差，如[图 5.1](#9783110785951_011899.xhtml#b_9783110785968-005_fig_001)所示。

模拟所有粒子在探测器材料中的传播和相互作用是链中的下一步，由 `GEANT4` 完成。需要对整个探测器的几何结构以及不同子探测器中的各种材料进行建模。这不仅包括用于探测粒子的有源材料，还包括被动支撑结构、电子学、电缆——粒子可能与之相互作用的每一处物质。外部电磁场的影响，特别是 LHCb 磁铁，也被考虑在内。这些过程可能导致粒子被吸收而损失，也可能产生新粒子，例如光子在原子核电场中转化为电子-正电子对。最终，这些相互作用导致不同子探测器中的击中。

随后，探测器响应由 `BOOLE` 模拟。该程序使用上一步的数据（主要是有源材料中的能量沉积）来模拟探测器对这些输入的响应。它还将记录的信号与模拟的沉积关联起来。

这种最底层的关联用于将重构径迹与模拟中的原始粒子匹配，如第 4.3.1 节所述。不同的背景源也需要被模拟，例如来自前一个事件的溢出、电子波动产生的噪声、长期辐射或串扰，以及敏感体积变得具有放射性的可能性。由于 LHCb 子探测器是独立的，因此每个子探测器的模拟可以并行运行。

此时，LHCb 事件的模拟完成。后续步骤以相同方式应用于模拟事件和真实事件。LHCb DAQ 见第 4.2.1 节。
