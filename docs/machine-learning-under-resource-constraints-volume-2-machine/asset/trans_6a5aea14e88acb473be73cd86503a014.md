

## 8.3.2 Tau中微子选择

**Tim Ruhe**

**Maximilian Meier**

**摘要：** IceCube中理想的tau中微子相互作用会产生一种非常独特的光模式，由两个级联组成——第一个源于tau中微子相互作用本身，第二个源于新生tau轻子的非缪子衰变——以及沿tau轻子路径出现的类径迹特征。这种特征通常被称为双级联。然而，对于这种理想情况，两个级联都需要包含在探测器内。此外，tau径迹的长度为每PeV中微子能量50 m。因此，随着能量增加，双级联将比单级联更易于区分，但由于中微子能谱陡峭下降，其发生概率也会降低。通过观察单个DOM波形中的双脉冲，可以规避这一挑战。本节介绍一种基于随机森林的tau中微子选择及其通过模型拒绝因子进行的优化。本节将特别关注与tau中微子识别相关的挑战。与缪子中微子搜索相比，这些挑战源于显著更大的本底率（信噪比为`10^(−10)`）和额外的本底来源。

Tau中微子不在地球大气中产生，因此它们的探测是天体物理源发射高能中微子的直接证据。在PeV量级的能量下，预期`ν[τ]`在探测器内表现出一种被称为双级联的独特事件特征。这种独特的特征由两个单级联通过一个类径迹特征连接而成。第一个级联源于如下形式的`ν[τ]`带电流（CC）相互作用：

```
(8.15) v[τ]+X→τ^−+X^′.                        (8.15)
```

在公式8.15中，`X`表示冰或周围基岩中的原子核，而`X^′`表示新生的强子级联。在衰变前，新生的`τ`轻子沿直线穿越探测器，随后的`τ`衰变导致第二个强子级联。与缪子不同，由于其相对较大的静止质量，`τ`不仅可以衰变成较轻的轻子（`e`和`μ`），还可以衰变成强子。

尽管具有这种非常独特的特征，`ν[τ]`仍极难探测。由于`τ`寿命相对较短，轻子在产生后会迅速衰变，这对观测到的径迹长度施加了严格限制。将每PeV约50 m的径迹长度与约125 m的串间距相比，会发现大多数情况下，两个新生级联的距离不够远，无法被区分。此外，谱指数为`γ` ≈ −2的预期幂律将导致在探测器整个寿命期内，仅有少数几个事件具有足够高的能量来产生分辨良好的双级联。

然而，通过寻找*双脉冲*而非双级联，可以应对这一挑战。双脉冲是具有两个明显峰值的波形，即使`τ`轻子的径迹太短而无法产生可区分的双级联，也可以在单个光学模块中观测到。因此，第一个脉冲源于第一个级联，第二个脉冲源于第二个级联。为了探测双脉冲，许多用于缪子中微子选择的分析技术（如通过`MRMR`进行特征选择）可以直接应用。

`ν[μ]`和`ν[τ]`选择的主要区别之一是需要在分析中考虑额外的本底事件类别。虽然大气缪子是`ν[μ]`分析中的主要本底源，但`ν[e]`（CC和NC）和`ν[μ]`（仅NC）相互作用也需要在`ν[τ]`分析中考虑，因为这些相互作用产生单级联事件，需要将其与双级联区分开。双级联也可能被缪子模拟，此时第一个脉冲源于中微子-核子相互作用，而第二个脉冲源于大的随机能量损失（大多数情况下为轫辐射）。这些挑战通过采用两阶段事件选择来解决，在每个阶段拒绝不同类别的本底事件。

由于在IceCube模拟中没有双脉冲波形的明显标签，分析的第一项任务是手动定义信号波形。此手动定义包括对每个事件和每个波形的总电荷应用切值。需要应用这些切值，因为需要`E[ν]` ≈ 10 TeV的能量，双级联才能在一个或多个相邻DOM中被识别为两个不同的脉冲。`ν[τ]`相互作用中是否探测到双脉冲波形，关键取决于沉积能量、相互作用的顶点位置以及随后的衰变。因此，对模拟事件应用一组几何切值，以拾取具有显著双脉冲特征的波形。应用上述几何切值后，选出了6874个波形，它们被用作分析后续步骤中应用的机器学习算法的输入。

基于机器学习的两个分析步骤中的第一步，包含训练、优化和应用一个随机森林，以区分双级联和单级联。这里我们使用包含200棵树的随机森林。输入森林的大多数特征基于导数，旨在表征波形的斜率变化。[图 8.9](#9783110785951_020762.xhtml#b_9783110785968-008_fig_009) 描绘了所得模型应用的结果。虽然双脉冲得分切值（从随机森林获得的置信度）显示在x轴上，但性能参数——本例中为事件选择的纯度（红色显示）——显示在左侧y轴上。右侧y轴描绘了作为双脉冲得分函数的每年事件数。Tau中微子CC事件用蓝色表示，而单级联事件用橙色显示。可以发现，两个分布都随得分切值下降。然而，在双脉冲得分切值0.0到0.1之间，单级联的数量出现了相对陡峭的下降。
