

## 3.3 机器学习理论

机器学习研究旨在回答以下问题：

*   能对误差给出哪些保证？（误差界）
*   哪类模型最适合该问题？（模型选择）
*   需要多少样本？（样本复杂度）
*   如果样本数量和维度数量增加，模型在运行时间、内存和能耗方面如何扩展？（资源界）

在最抽象的层面上，机器学习作用于*公式*，如上述公式 3.1 和 3.3 中回归函数的正则化误差最小化。就这些函数而言，学习任务被指定出来。证明学习模型的误差界是机器学习与统计学的共同研究课题。正如已经陈述的，优化领域也发挥着作用。在 ICML 或 ECML PKDD 等机器学习会议上，几乎每篇论文都展示了误差界的证明，或至少将其结果实质性地建立在误差界的证明之上。作为入门，我们推荐关于机器学习统计和概率方法的书籍 [192, 284]。

给定一个物理问题和实验数据，没有任何一类学习理论是先验地适用的。正如*免费午餐定理*所指出的，每一种学习方法的选择一方面伴随着其要求，另一方面伴随着其理论保证 [388, 389]。

在选定的一般类别内，存在有助于选择特定方法的标准。算法最重要的特征在于批处理与在线处理、或分布式与集中式处理的区别。对于应用开发，需要研究高效的*算法*。同一模型类的不同算法，其最坏情况复杂度和经证明的紧精度界是已知的。频繁项集挖掘的实现竞赛——即寻找数据库项目所有频繁共现的任务 [[163](#9783110785951_034588.xhtml#b_9783110785968-011_ref_163)]——广为人知。文献报道了 12 个不同层级的实现及其各异的资源消耗，例如内存使用、运行时间和生成模型的压缩。

如今，我们甚至深入到了*在特定硬件上的实现*层面。在早期，学习算法是从 CPU 移植到 GPU 的，如 [[309](#9783110785951_034588.xhtml#b_9783110785968-011_ref_309)] 所述。现在，硬件专门为机器学习的低延迟和高吞吐量计算需求而设计。非冯·诺依曼架构的存内计算（IMC）/ 存内处理（PIM）正在被广泛研究 [[78](#9783110785951_034588.xhtml#b_9783110785968-011_ref_078)]。目前，FPGA 是常用的机器学习加速器。针对冯·诺依曼架构和 FPGA 的算法不同实现已被仔细探索 [[107](#9783110785951_034588.xhtml#b_9783110785968-011_ref_107)]。针对特定架构的快速执行优化也受到关注 [[231](#9783110785951_034588.xhtml#b_9783110785968-011_ref_231)]，特别是多核架构上的计算（见第 1 卷 [第 6.4 节](#9783110785951_014663.xhtml#b_9783110785968-006_s_004)）。特别是对于卷积神经网络，其基于开放神经网络交换格式（ONNX）的抽象描述，允许在 FPGA 的高层接口上综合实现并进行优化 [[176](#9783110785951_034588.xhtml#b_9783110785968-011_ref_176)]。

最近，机器学习算法与硬件架构的联系变得更加紧密：给定的学习算法不仅适应给定的架构；学习算法本身在其训练过程中还负责处理可能的硬件故障。这对于以准确率换取节能的硬件尤为重要。例如，存内计算节省能源但可能产生错误结果。一种新型的最大间隔优化二值化神经网络成功优化了位错误容忍度 [[110](#9783110785951_034588.xhtml#b_9783110785968-011_ref_110)]。

模型类层面及其与统计学习理论的联系固然重要，但机器学习通过与计算机科学其他领域的合作，研究更多层次的抽象。用于分布式或流式学习的模型类算法基于理论计算机科学工作，如 [129, 130]。特定硬件上的实现层面将机器学习与计算架构联系起来 [[260](#9783110785951_034588.xhtml#b_9783110785968-011_ref_260)]。甚至有专门为机器学习设计的特定硬件 [[217](#9783110785951_034588.xhtml#b_9783110785968-011_ref_217)]。机器学习研究并贡献于所有层面：从模型类到算法，再到实现，甚至计算机架构。学习正交于计算机科学的层级体系。

### 3.3.1 计算学习理论

除了机器学习的统计理论外，一种称为“概率近似正确”（PAC）学习的与分布无关的理论，提供了可学习性的界 [[375](#9783110785951_034588.xhtml#b_9783110785968-011_ref_375)]。它基于假设空间的思想。在特定的形式表示系统中，哪些假设可以被表达？一个简单的概念类是布尔字面量的合取。字面量包括 *rainy, sunny* 和 *play golf*。假设空间 𝒞 则为概念 *c*[1] 到 *c*[12] 的集合。
