
然而，μ子能量 `E[μ]` 无法直接测量，必须从探测器仪器化体积内切伦科夫辐射形式沉积的能量中推断出来。可以从原始数据中提取几个依赖于 `E[μ]` 的可观测量，通常称为能量代理，它们具有不同的抽象层级。击中光学模块的总数以及所有击中模块累积的总电荷尤为直观。因此，与 γ 射线不同，后者利用的变量直接近似 γ 能量，中微子能谱重构面临额外的一层间接性，这表现为能量代理相对于入射中微子能量具有更大的模糊（smearing）。[图 10.11](#9783110785951_034588.xhtml#b_9783110785968-010_fig_011) 描绘了三个输入变量与真实中微子能量的相关性。[图 10.11a](#9783110785951_034588.xhtml#b_9783110785968-010_fig_011) 显示了与击中 DOM 数量的相关性，而 [图 10.11b](#9783110785951_034588.xhtml#b_9783110785968-010_fig_011) 描绘了与直接光子数 `N[dir]` 的相关性。在 IceCube 中，如果光子可被视为未发生散射，则称为*直接*光子。因此，未散射光子将从其发射点沿直线传播到 DOM，并最终被记录。为了估计光子是否可被视为直接光子，会相对于重构径迹计算其到达相应光学模块的传播时间 `t[travel]`。然而，由于重构径迹只是一个估计值，如果光子在其预期到达时间周围的给定窗口内被探测到，则被视为未散射。直接光子的典型时间窗为 −15 ns ≤ `t[travel]` ≤ 75 ns。[图 10.11c](#9783110785951_034588.xhtml#b_9783110785968-010_fig_011) 描绘了真实中微子能量与一种能量估计器（通常称为截断能量 [[32](#9783110785951_034588.xhtml#b_9783110785968-011_ref_032)]）的相关性。两层间接性的影响直接体现在这三个变量相对较大的模糊中。[图 10.11a] 和 [图 10.11b] 中观察到的水平线，源于这两个输入变量均为离散的。然而，这种离散性并不影响反褶积结果。

由于 μ子拥有数公里长的径迹长度，它不一定在探测器的仪器化体积内产生，而是在周围的冰层甚至基岩中产生。因此，中微子相互作用的精确顶点在许多情况下固有地未知，μ子在到达探测器途中损失的能量也未知。这引入了额外的一层模糊。随机能量损失的发生以及读出电子学引起的噪声进一步使问题复杂化。从数学上讲，所有模糊源（间接探测、未知相互作用点、μ子传播和读出电子学）均包含在公式 10.1 的核 `A(x|y)` 中。`γ` 射线能谱重构的另一个区别在于本底水平。虽然对于 γ 射线，一定数量的本底事件是可容忍的，并通过公式 10.1 中的额外项 `b(E)` 处理，但所用中微子样本的纯度通常远高于 99%（见 [第 8.3 节](#9783110785951_020762.xhtml#b_9783110785968-008_s_003)）。

与许多其他反褶积分析一样，使用 DSEA 的分析通常始于选择一组合适的输入变量。输入变量的选择对展开结果的准确性至关重要，所选输入变量需要与目标变量表现出尽可能好的相关性。然而，变量选择应谨慎处理，因为选择与目标变量相关性最强的 `n` 个变量不一定能产生最准确的展开结果。原因在于，以这种方式选出的变量将通过它们共同的能量依赖性而在彼此之间表现出一定程度的相关性。这可能导致不同能量估计器中编码的高度冗余信息被使用。由于 IceCube 的探测介质是天然介质，其性质随深度变化。因此，利用几何信息，例如事件在探测器内的深度，可为谱重构提供有价值的信息 [170, 171]。

此处呈现的反褶积的输入变量是通过尝试-错误法，研究不同变量组合及其对展开能谱的影响来选择的。这样做的好处显然不是速度，而是有可能理解反褶积算法如何处理不同的变量选择。然而，如果候选变量列表变得太长，这种方法将变得不可行，此时建议改用自动变量选择（见 [第 7.2 节](#9783110785951_015782.xhtml#b_9783110785968-007_s_002)）。尽管 DSEA 中分类算法的使用允许使用任意数量的输入变量，但对于此处呈现的分析，发现三个与能量相关的变量是最优的。下一步，必须找到最优参数设置，因为 DSEA 允许选择众多参数组合。参数优化需要与真实中微子能谱进行比较，因此优化需使用模拟样本进行。为了解各个箱（bin）中反褶积的质量，优化过程中使用的模拟事件数量应与实验数据中的事件数量相符。然后可以通过距离度量（例如 Wasserstein 距离）量化真实能谱与反褶积结果之间的一致性。此处呈现的分析通过网格搜索优化了参数设置。最终设置包括一个随机森林作为分类器和一个指数衰减的步长，由以下公式控制：

(10.51) `α[k] = s ⋅ ξ^(k − 1)`
