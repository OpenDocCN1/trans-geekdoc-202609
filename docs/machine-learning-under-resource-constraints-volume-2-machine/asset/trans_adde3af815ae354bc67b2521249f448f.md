
在神经网络架构中直接利用现有的对称性和先验知识，可以通过提升模型性能来辅助重建任务。由于这些领域知识已内嵌于架构之中，因此无需在训练过程中隐式学习，这加快并促进了收敛。同时，直接引入对称性使得神经网络能够沿这些对称性进行外推。因此，只要这些区域被内置的对称性所覆盖，模型就能在训练数据覆盖的相空间之外提供有意义的内插和外插。这使得可用信息的利用更加稳健和完整。如果采样足够密集，标准神经网络能够在训练数据上进行内插，因此可以适当地对对称性建模。然而，除非架构本身支持这一点，否则它们无法真正提取并利用这些对称性。例如，`卷积神经网络 (CNNs)` 利用平移等变性来利用输入数据的平移不变性 [[240](#9783110785951_034588.xhtml#b_9783110785968-011_ref_240)]，这在图像识别领域取得了突破 [[233](#9783110785951_034588.xhtml#b_9783110785968-011_ref_233)]。标准多层感知机理论上可以学习相同的映射。然而，在实践中，它在图像识别任务上的表现并不理想。

IceCube 中可用的领域知识和对称性包括粒子簇射中的平移和旋转不变性。中微子相互作用的基础物理在平移和旋转下是不变的——它们不依赖于探测器的位置或方向。然而，由于探测器介质中的灰尘杂质和各向异性 [[25](#9783110785951_034588.xhtml#b_9783110785968-011_ref_025)] 以及探测器网格的几何结构（见 [图 9.1](#9783110785951_027842.xhtml#b_9783110785968-009_fig_001)），这种对称性在测量数据中仅近似成立。除了这些对称性外，其他领域知识（如沉积能量与探测到的电荷之间的线性关系，或探测器本身的特性）也是先验已知的。

正如 [7.2 节](#9783110785951_015782.xhtml#b_9783110785968-007_s_002) 所述，IceCube 记录每个 `数字光学模块 (DOM)` 中光电倍增管记录的光子。这些就是测量数据。光子被转换为随时间变化的电信号——电荷，也称为 `波形`。在后续步骤中，再从 `波形` 中提取单个脉冲，每个脉冲包含一个时间和电荷。每个 DOM 可能测量任意长度的脉冲序列。指定时间窗口内此类脉冲序列的集合称为 `事件`。重建方法旨在基于脉冲序列和给定的领域知识，提取原初中微子的属性。

### 9.2.2 IceCube 中的卷积神经网络

为了使神经网络 (NNs) 能够给出可靠且稳健的估计，NNs 必须学习数据中的潜在模式。这可以通过训练过程中从训练数据中隐式推断来实现，也可以通过选择合适的网络架构显式实现。IceCube 中主要的对称性之一是 `x`-`y` 平面（平行于冰面）上的平移对称性，以及一阶近似下沿 `z` 轴的平移对称性。卷积层在平移下是等变的，因此可以利用输入数据中的平移对称性。因此，`卷积神经网络 (CNN)` 是 IceCube 事件重建的合适选择。

然而，将 CNN 应用于 IceCube 数据存在一些挑战。IceCube 数据由 5160 个 DOM 中收集的脉冲序列组成。DOMs 安装在总共 86 根垂直弦上，这些弦大致分为三个探测器部分，如 [图 9.1](#9783110785951_027842.xhtml#b_9783110785968-009_fig_001) 所示。数据必须经过转换以适配 CNN 应用所需的正交张量。这是通过分离各个探测器组件的数据来实现的。主阵列的弦经过平移和零填充，将三角网格转换为正交网格（见 [图 9.1](#9783110785951_027842.xhtml#b_9783110785968-009_fig_001)）。生成的三个输入数组随后被提供给三个独立的卷积层堆栈，如 [图 9.2](#9783110785951_027842.xhtml#b_9783110785968-009_fig_001) 所示。每个卷积层的结果在一个扁平化层中合并，并传递给两个小型全连接 NNs，分别输出关注的物理量及其预测的估计不确定度。用于主阵列的卷积核与输入数据类似地进行了转换，使得卷积操作有效地卷积了一个六边形的核。六边形卷积更适合 IceCube 的几何结构，原则上能够利用六重旋转对称性，尽管为简化起见此处不再进一步探讨（关于六边形卷积和网络架构的更多细节见 [[31](#9783110785951_034588.xhtml#b_9783110785968-011_ref_031)]）。

此时，DOM 的空间坐标已按适合 CNN 的方式进行了转换。[图 9.1](#9783110785951_027842.xhtml#b_9783110785968-009_fig_001) 中输入数组的每个元素对应一个 DOM。剩下的就是对时间维度进行转换，即将给定 DOM 处的脉冲序列转换为固定长度的特征向量。
