
在粒子物理学中，通常可以在很大程度上控制实验的环境条件，但对于天体粒子物理学实验，这种控制可能很困难，甚至是不可能的。这对于利用大气作为探测介质的实验（如`IACTs`或荧光探测器）尤其如此。这些实验高度依赖于温度、背景光照射或局部磁场等效应。如果在模拟中不考虑这些效应，可能会导致显著的偏差，但为每种可能的环境条件重新进行完整模拟的运行时间太长，不可行。相反，可以通过将现有的模拟结果适应不断变化的环境条件，例如将夜空背景噪声添加到`IACT`图像的无噪声模拟中。这种方法是在本`CRC`中开发的，详见[第 5.3.2 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_003_s_002)。

天体粒子物理学的一个特殊方面是位于地下的实验，如中微子天文台`IceCube`。对于这些实验，地球表面的粒子（如大气簇射中的缪子）或探测器附近产生的粒子（如弱相互作用中微子产生的粒子）需要被传播直到它们在探测器内发生相互作用。在此背景下，缪子扮演着特殊角色，因为它们可以在致密介质中传播很长的距离，因此在地下探测器中仍然很丰富。因此，它们的模拟至关重要，特别是作为需要考虑的背景。由于缪子在致密介质中的相互作用数量可能非常高，缪子模拟的要求既包括高精度，也包括高性能。用于此目的的工具之一是软件模拟框架`PROPOSAL`，它提供最新的缪子物理参数化，以及一种允许在速度和精度之间找到权衡的算法。`PROPOSAL`在[第 5.2.3.2 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_002_s_003_s_002)中有更详细的描述。

除了上述提到的模拟工具——被天体粒子物理学中许多不同实验使用的框架——许多实验还使用自己的、通常是特定于探测器的模拟工具。这些工具特别用于描述探测器的非常低层级部分，如特定探测器部件的响应函数。

特别是对于高度复杂或新安装的探测器，需要付出很大努力才能使真实测量数据与模拟事件达到可接受的一致性水平。这种数据/MC一致性很重要，因为否则机器学习模型可能会在仅存在于模拟数据而不存在于真实数据的特征上进行训练。由于天体粒子物理学实验中的校准测量在大多数情况下只能在有限程度上进行，因此有必要直接比较观测到的特征和模拟的特征。然而，简单地比较一维特征并不总是足够的，因为失配可能只在高维相关性中可见。因此，利用机器学习方法来寻找数据/MC失配是值得的，例如分析那些被训练用来区分真实事件和模拟事件的模型。这种方法在[第 5.3.3.1 节](#9783110785951_011899.xhtml#b_9783110785968-005_s_003_s_003_s_001)中有描述，并已应用于`IceCube`模拟。

## 5.2 模拟效率研究

### 5.2.1 Corsika – 主动学习

*Dominik Baack*

**摘要：** 高能宇宙射线撞击大气层的模拟是许多天体粒子实验的要求。对于大多数实验，这些模拟包括跟踪穿过大气层的单个入射粒子，包括相互作用等随机效应，相互作用可以产生新粒子。这些新粒子必须以相同方式处理，从而产生一个不断扩展的粒子级联，必须将其传播穿过大气层。由于这些蒙特卡洛模拟的高复杂性，现实案例的计算时间每个簇射可能从几个 CPU 秒到几个 CPU 月不等，具体取决于特定设置。对于具有统计学意义的事件数量的完整集合，累积计算时间甚至更高。

由于蒙特卡洛模拟固有的随机性质，初始粒子的固定约束必须保持宽泛，以允许边界情况的模拟。这导致大量模拟粒子甚至整个事件在实验中未被触发，因此被丢弃。在模拟和分析流程的后几步中，分类器或展开方法的训练可能会偏向于很少发生的特定事件，这与前面的情况不同。

在模拟批次之后执行的学习算法可以训练模型以减少模拟相空间，即减少模拟但未触发的事件数量。在扩展中，不仅可以提前停止整个级联；生成的簇射的单个部分（称为子簇射）也可以根据模型进行检查。

#### 5.2.1.1 简介 - 级联

天体粒子物理学是一个基于星际起源粒子的相对较新的研究领域。这涵盖了从几个`eV`到几个`PeV`的广泛能量范围。在从`GeV`左右开始的较高能量区间，单个粒子太稀有，无法用相对较小的卫星实验直接观测。地面探测器的困难在于宇宙射线不穿过大气层，而是与之相互作用。在每个相互作用点，能量被传递给更多的粒子，这些粒子本身又在大气层中相互作用。这导致了如[图 5.2](#9783110785951_011899.xhtml#b_9783110785968-005_fig_002)所示的粒子级联。

#### 5.2.1.2 简介 - 实验

鉴于级联内部的巨大多样性，有几种不同的实验探测方法可用。次级粒子可以直接测量，或通过其发射的电磁波（以荧光光、切伦科夫光或无线电发射的形式）进行测量。稍后描述的优化方法是为簇射规模（见[图 5.3](#9783110785951_011899.xhtml#b_9783110785968-005_fig_003)）比仪器覆盖面积大一个数量级的实验量身定制的。这种条件可以由切伦科夫望远镜（如`MAGIC`、`CTA`或`FACT`）和较小的水探测器（如`HAWK`）满足。此外，不仅有上述那些观测和测量簇射的实验，对于更多的实验，产生的粒子在其实际测量中形成干扰背景。一个例子是中微子望远镜。在这两种情况下，完整的模拟对于为后续分析提供坚实基础都是必要的。
