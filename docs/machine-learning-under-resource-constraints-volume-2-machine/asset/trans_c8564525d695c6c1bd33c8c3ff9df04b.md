

# 利用神经网络分类器的 FCNC 过程分析

这是本分析中搜索的过程 [[67](#9783110785951_034588.xhtml#b_9783110785968-011_ref_067)]。这是一个采用 MC 驱动的背景估计的分析示例，该估计被用于分箱的轮廓似然拟合中，以在标准模型背景假设之上搜索 BSM 信号增强。这也是一个基于神经网络的事件级分类器示例，用于将罕见信号过程（FCNC 产生）与背景区分开来。如[图 8.19](#9783110785951_020762.xhtml#b_9783110785968-008_fig_019)所示，出射粒子（“终态”）由一个顶夸克和一个高横向动量（*p*[T]) 光子组成。

## 背景过程

标准模型背景过程包含不可约背景和可约背景。一个重要的不可约背景是 *W* + *γ* 产生，伴随夸克或胶子强子化产生的额外喷注，包括 *b* 夸克强子化可能产生的 *b* 喷注。一个重要的可约背景是 *t* $\\overline{t}$ 在双轻子衰变道中的产生，即两个顶夸克均轻子衰变，其中一个轻子是被误识别为光子的电子。电子和光子都会产生电磁簇射，主要区别在于电子簇射预期会有一条指向能量在热量计中沉积中心的径迹。如果该径迹测量错误，电子就容易被误识别为光子。不同的背景贡献如[图 8.20](#9783110785951_020762.xhtml#b_9783110785968-008_fig_020)所示，其中“*e* → *γ* 假信号”主要来自双轻子 *t* $\\overline{t}$ 事件。所有背景贡献最初均由 MC 模拟估计，但会使用数据进行检查和调整。特别地，*W* + *γ* 背景在一个控制区中估计，该控制区在运动学上接近用于搜索 FCNC 信号的相空间（信号区），但富集了 *W* + *γ* 产生。*e* → *γ* 假信号概率的建模通过比较 *Z* → *e*^+*e*^− 事件（即不变量质量 *m*[ee] 接近 *Z* 玻色子质量 *m*[Z] 的 *e*^+*e*^− 事件）与具有相似不变量质量的 *eγ* 事件来检查。这些满足 *m*[eγ] ≈ *m* [Z] 的 *eγ* 事件源于 *Z* → *e*^+*e*^− 产生且有一个被误识别的电子。比较数据和 MC 中 *ee* 与 *eγ* 事件的比率，得到一个应用于 MC 模拟的修正因子，该因子修正了数据与 MC 之间假信号概率的差异。

## 信号区分

现在背景贡献已得到良好估计，任务是将背景与信号过程区分开，以对尽可能小的信号截面保持敏感。原因在于信号截面在标准模型中极小，以至于无法在 LHC 测量到它。然而，通过针对尽可能小的信号截面，我们探测预测至少该数值截面的 BSM 理论。这意味着我们需要极佳的信号与背景区分能力，本分析通过一个全连接前馈神经网络（NN）作为二元分类器来实现。该 NN 基于利用控制区数据修正过的 MC 模拟进行训练，使用一组十个区分度良好的输入变量。这些变量大多是运动学变量，例如光子的横向动量 *p*[T]（[图 8.20](#9783110785951_020762.xhtml#b_9783110785968-008_fig_020) 左），该粒子在信号过程中的平均横向动量比背景大得多。另一个输入变量是带电轻子电荷符号（[图 8.20](#9783110785951_020762.xhtml#b_9783110785968-008_fig_020) 右）。大多数背景是电荷对称的，特别是 *t* $\\overline{t}$ 产生，它构成了 *e* → *γ* 假信号背景的主要部分。然而，FCNC 信号将顶夸克分别与一个上夸克或一个魅夸克耦合（参见[图 8.19](#9783110785951_020762.xhtml#b_9783110785968-008_fig_019)）。本分析分别搜索这两种对上夸克和魅夸克的耦合。在上夸克耦合的情况下，倾向于产生顶夸克而非反顶夸克，因为质子包含上夸克作为价夸克，而反上夸克仅作为海夸克存在。这导致来自顶夸克衰变的带正电轻子更受青睐，如[图 8.20](#9783110785951_020762.xhtml#b_9783110785968-008_fig_020)右侧所示。
