
经典著作《机器学习——一种人工智能方法 III》（1990）的第三卷概述了统计学习、将领域理论整合到从示例中学习、通过实验学习、增强不完美领域理论、因果模型、亚符号学习和计算学习理论。主题的多样性涵盖的内容远不止统计分析。对科学发现的视角是宽广且多面的。

这一早期机器学习方法的简短总结听起来似乎这就是科学研究模型所需的一切。然而，事实并非如此。所有这些主题至今仍是研究课题。为了支持人类的科学发现，机器学习在三个方面超越了早期作品，我们将在下文中解释。

## 1.2.2 知识表示——什么是理论？

首先，单一的定律或判定函数不足以表示一个理论。理论由许多整合的规则组成。如果机器学习过程旨在建模科学过程——即如何从观察中获取意义并将新概念整合到已有知识中——它就需要处理的不仅仅是单一的孤立概念。它需要一种合理的方式来表达相互关联的概念及其解释。没有形式推理的表示只是纸上墨迹，需要人类去解读。

因此，人工智能开发了用于知识表示的形式化方法，以表达和解释概念及其关系。其中之一是描述逻辑，它通过概念定义以及它们之间的两种主要关系来表示理论：用于定义其他概念的概念，以及在泛化层级中包含其他概念的概念 [[73](#9783110785951_034588.xhtml#b_9783110785968-011_ref_073)]。描述逻辑在尽可能少地限制数学逻辑的前提下，保持推理的可处理性。理论是一致的，即矛盾能被高效识别并禁止。理论不仅在概念空间执行推理，还判断一个观察或测量是否被某个概念覆盖。在此演绎推理的基础上，机器学习增加了归纳，它从观察中学习概念并将其置入概念层级。遵循波普尔的范式，机器学习利用矛盾来学习一个精炼的模型。审视矛盾甚至被用来将新概念引入表示中，使理论能连贯地覆盖更多观察 [[279](#9783110785951_034588.xhtml#b_9783110785968-011_ref_279)]。

知识表示的另一个家族是霍恩逻辑，它用一组共同构成程序的规则来表示理论。编程语言 Prolog [[126](#9783110785951_034588.xhtml#b_9783110785968-011_ref_126)] 本身就是一种霍恩逻辑，并被用于编程具有演绎推理的大型知识库，从而得出理论陈述或预测观察。反之，从观察中推断规则集，被称为归纳推理。当然，如果我们能自动找到覆盖所有观察的最小可能模型，那将是件好事。这种敏锐的理论形成将是一种严格的公理化。然而，归纳学习是一个过程，在某个时刻，可能缺少压缩模型所需的谓词或函数，从而导致无法找到最小模型。

1. `ℋ` 的最小逻辑模型在示例 `ε` 的所有最小模型中为真（可能连同背景知识的模型）；
2. 不存在 `h` ∈ `ℋ` 使得所有示例都能从 `ℋ`（可能连同背景知识）中演绎出来而不需要 `h`；
3. 所有满足 1) 和 2) 的规则都能从 `ℋ` 中演绎出来；
4. `ℋ` 是最小的。

Helft [[195](#9783110785951_034588.xhtml#b_9783110785968-011_ref_195)] 基于逻辑的这一从示例学习规则集的定义，也可以转化为分类学习的描述 [[283](#9783110785951_034588.xhtml#b_9783110785968-011_ref_283)]。在这个范式中，从观察中归纳规则集类似于科学过程，因为规则被用来演绎或预测观察。学习——即归纳步骤——从观察推导出原因。此外，它还包含已获取的知识作为背景知识。学到的规则集被演绎推理用来从原因推断结果。这里归纳推理的关键在于谓词甚至高阶逻辑数学框架中的*泛化*。

## 1.2.3 走向概率

早期方法不足的第二个原因是它们的二值逻辑。我们可以说，与严格的牛顿观点的分歧已经发生在逻辑推理之中。与仅提供一个真模型的牛顿不同，现象的替代解释必须被表达并存储，以供后续理论发展 [[151](#9783110785951_034588.xhtml#b_9783110785968-011_ref_151)]。既然我们不想表达任意概念，真理和一致性的概念就需要被保留。然而，纯二值逻辑不足以应对非单调推理，也无法因新观察而修正逻辑程序的命题。这里的知识获取模型通过用概率进化评估的循环取代纯粹的逻辑决策，实质上区别于波普尔的批判理性主义（尽管它在其他方面深受其影响）。同波普尔一样，完全错误的解释模型可以轻易被排除。作为特定理论方法标准的、必须放弃的概率取决于所考虑物理问题的重要性、相关物理学科的惯例以及可用资源。在方法论上，基于解释方法概率仅有中等差异的决策是没有必要的。由于对自然的物理描述质量非常高，实践中许多长期使用的模型和理论具有非常高的概率。这样，经典知识方法可以被理解为一种边界情况。而且，一如既往，当习惯的结果被理解为更一般考量的边界情况时，我们就成为了新科学阶段的观察者和推动者。

支持假设的证据与反对假设的证据建模的新范式，允许我们在一定程度上将命题表征为未知、已知或预测，或其否定或排他状态。Emde 更具概率性的推理引擎允许在建模过程中进行修正和表示学习 [[150](#9783110785951_034588.xhtml#b_9783110785968-011_ref_150)]。新概念可以被引入表示理论，但这次无需牺牲替代方案 [[390](#9783110785951_034588.xhtml#b_9783110785968-011_ref_390)]。相反，有助于解决矛盾的可能修正和新概念作为替代方案被保留下来，连同它们的推导路径。整个建模过程已基于受限一阶逻辑中的可靠推理引擎进行了研究。此外，支持其中所有步骤的工具被集成在一起，使得人机能够交互式地构建复杂的知识库 [[281](#9783110785951_034588.xhtml#b_9783110785968-011_ref_281)]。
