## 8.5 核心篇：ATLAS 实验中的数据分析

*Johannes Erdmann*

**摘要：** 机器学习在 ATLAS 实验数据分析的许多方面发挥着关键作用。ATLAS 是 CERN 大型强子对撞机（LHC）上的多用途粒子物理探测器之一，旨在开展多元化的科学研究计划。本节重点介绍 ATLAS 中机器学习的几个方面，这些内容取自两个科学领域：罕见顶夸克过程的搜索和新重粒子的搜索。机器学习的主要应用源于对卓越分类性能的需求，以高效抑制巨大的背景过程，从而提高对信号过程的灵敏度。所有应用中一个特殊的挑战在于：分类器是在模拟数据上训练的，而其在真实碰撞数据中的效应必须建模良好，才能在数据分析中可靠地使用。

### 8.5.1 简介

ATLAS 实验 [[71](#9783110785951_034588.xhtml#b_9783110785968-011_ref_071)] 是 CERN 大型强子对撞机（LHC）上的四个大型实验之一。ATLAS 是一个全功能探测器，具有对撞机探测器典型的洋葱状结构。粒子碰撞发生在其中心，探测器由围绕相互作用点的不同圆柱形探测器部件组成。第一个探测器部件是在磁场中的径迹探测器。带电粒子的弯曲轨迹在径迹探测器的不同层留下击中点，测量粒子径迹的方向以及通过径迹曲率测量其动量。第二个探测器部件由量能器组成，用于测量电子沉积的能量

ATLAS 探测器旨在追求广泛的粒子物理目标，这些目标主要集中在分析 LHC 提供的质子-质子相互作用。目标包括对粒子物理标准模型（SM）预言的精密测试，以及搜索超越标准模型（BSM）理论中预言的新粒子。前者将表现为相对于仅含 SM 假设的共振偏差，后者将导致非共振偏差。LHC 中的每一次质子团簇交叉都可能产生一个“事件”。然而，碰撞中发生的大多数事件都不感兴趣。即使利用触发器以约 1000 Hz 的速率选择事件进行永久存储，记录的事件绝大多数仍是背景事件。因此，分析数据的主要任务是对事件进行优秀的选择，以用信号事件丰富事件样本。基于机器学习（ML）的分类因此对数据分析至关重要。其用途主要集中在（尽管不限于）事件层面上信号与背景事件的分离，以及探测器中粒子（电子、光子、缪子……）与误识别的其他粒子（称为假信号）的区分。

在搜索罕见过程时，所有其他 SM 过程及其各自的截面均被视为背景。实际上，如果罕见过程仅存在于 BSM 理论中（例如新粒子的产生），则所有 SM 过程都是背景的一部分。无论如何，背景建模至关重要。在许多情况下，它依赖于蒙特卡洛（MC）模拟（参见 [第 5 章](#9783110785951_011899.xhtml#b_9783110785968-005)）。这些模拟在给定的微扰论阶次（例如 `α[S]` 的次领阶）下模拟相关过程，并模拟夸克和胶子在部分子簇射中的演化、它们的强子化以及探测器的响应，使得 MC 模拟的输出格式与真实的原始碰撞数据相同（例如单个探测器单元中的数字化电压或电流）。然后，用于从原始探测器输出重建粒子特征的相同算法被用于真实碰撞数据和模拟数据。通常，这些 MC 模拟已经能对 SM 过程提供极佳的建模。然而，预测质量取决于具体过程，并且已知生成相空间的某些部分受到巨大的不确定性影响。所有 MC 模拟都通过数据驱动的修正得到改进，使得例如缪子在数据和 MC 模拟中的识别经过修正后基于洁净参考过程（本例中为 `Z` → `μ`^+`μ`^− 和 `J`/`ψ` → `μ`^+`μ`^−）的测量结果一致。MC 模拟和数据驱动修正带有各自的系统不确定性集，因此完整的背景模型包含一个标称预测和一组定义明确的系统不确定性。

在搜索罕见过程时，通过假设检验来检验信号的存在。目标是以较大的显著性拒绝仅背景假设。然而，假设未发现偏离仅背景假设的情况，则会以不同程度的信号检验信号加背景假设，从而设定一个信号最小量的上限，即如果该信号存在，将与观测数据不相容。假设检验通常基于带有似然比作为检验统计量的轮廓似然拟合 [[131](#9783110785951_034588.xhtml#b_9783110785968-011_ref_131)]。拟合可以是分箱或不分箱的，系统不确定性作为恼人参数纳入其中。为避免过于乐观的排除限制，采用了 `CL[s]` 技术 [[323](#9783110785951_034588.xhtml#b_9783110785968-011_ref_323)]。

在本文中，介绍了 ATLAS 实验中搜索罕见过程的两个代表性示例，重点关注分析策略和 ML 的使用
