

## 摘要

由于中微子无法被直接探测，其能量是通过其轻子伴侣（如μ子）来评估的，后者在中微子与冰或周围基岩发生相互作用时产生。然而，从能量为 `E[ν]` 的中微子产生能量为 `E[μ]` 的μ子是一个随机过程，它取决于中微子能谱以及中微子相互作用的细节。此类过程可通过第一类Fredholm积分方程来描述，该方程可通过基于似然或基于机器学习的去卷积来求解。本节将探讨应用基于机器学习的去卷积算法 `DSEA` 的细节与挑战。`DSEA` 的应用通过其在利用IceCube探测器86-string配置获取的数据重建μ子中微子能谱中的应用得以例证。虽然先前的分析侧重于整体能谱，但此处呈现的分析研究了大气温度季节性变化对大气中微子能谱的可能影响。

## 中微子能谱重建

由于中微子无法被直接观测，其能谱无法直接获取，其重建需要去卷积技术。与γ射线类似，大气中微子的能谱预计遵循幂律形式 $\frac{d\Phi}{dE} \propto E^{-\gamma}$，其中 `γ` ≈ 3.7。然而，在重建各自能谱的挑战和所用方法方面，γ射线和中微子之间存在某些差异。本节将首先概述这些差异与相似之处，然后利用IceCube中微子望远镜获取的数据（见第2.2.1.1节）[[210](#9783110785951_034588.xhtml#b_9783110785968-011_ref_210)]进行大气中微子通量季节性变化的谱分析，提供一个中微子能谱重建的示例。

## ν[μ] 能谱重建中的挑战

由于中微子通量季节性变化的分析通常利用μ子中微子（`ν[μ]`），本节将仅讨论与重建 `ν[μ]` 能谱相关的挑战和技术。与电子中微子和τ中微子相比，重建 `ν[μ]` 能谱的挑战主要源于间接测量过程和对中微子相互作用顶点了解不准确。这两个过程详述如下。尽管测量过程对 `ν[e]` 和 `ν[τ]` 也是间接的，但对这些中微子味而言，相互作用顶点的知识和能量分辨率要好得多。这是因为这两种中微子味表现为粒子簇射，其能量几乎完全沉积在探测器内部。关于能谱重建，`ν[e]` 和 `ν[τ]` 的主要挑战源于探测器对这些中微子味灵敏度的降低。这种灵敏度降低是因为 `ν[μ]` 也可能在探测器外部产生。相比之下，`ν[e]` 和 `ν[τ]` 必须在仪器化体积内发生相互作用才能被探测到（见第4.2.3节）。

## ν[τ] 和 ν[e] 在谱分析中的局限性

由于 `ν[τ]` 不在地球大气中产生，它们仅对高能宇宙中微子通量有贡献，预计每年仅有少数事件。在分析中，由于应用质量切割，该数量进一步减少，使得该中微子味的能谱重建变得不可行。电子中微子确实在地球大气中产生，但其探测率也远低于μ子中微子。两个物理效应对此有贡献。首先，探测器对簇射的有效体积小得多；其次，只有来自特定衰变道（三体K介子衰变）的电子中微子能被IceCube探测到。来自低能大气μ子衰变的更为丰富的 `ν[e]` 远低于IceCube的能量阈值。然而，研究地球大气季节性温度变化引起的谱变化需要尽可能大的分辨率，这需要足够数量的事件。因此，此处讨论的分析利用μ子中微子来研究谱效应。

## 季节性变化与能谱

大气μ子和中微子的速率变化源于地球大气温度的季节性变化（参见[[173](#9783110785951_034588.xhtml#b_9783110785968-011_ref_173), [368](#9783110785951_034588.xhtml#b_9783110785968-011_ref_368), [369](#9783110785951_034588.xhtml#b_9783110785968-011_ref_369)]）。这些季节性温度变化不仅预期会影响大气μ子和中微子的总体速率，还会影响其能谱，这是由于其母介子（π介子和K介子）临界能量的温度依赖性所致[[173](#9783110785951_034588.xhtml#b_9783110785968-011_ref_173)]。

## 带电流相互作用中的μ子产生

如前所述，`ν[μ]` 无法被直接观测，因此其探测通过其轻子伴侣——μ子（`μ`）进行，后者在入射中微子与核子的带电流（CC）相互作用中产生（见第4.2.3节）。CC中微子相互作用中μ子的产生受以下方程支配[[173](#9783110785951_034588.xhtml#b_9783110785968-011_ref_173)]：

**方程 (10.50)**
```
\frac{dN_{\mu}}{dE_{\mu}} = {\int_{E_{\mu}}^{\infty}\left( \frac{dN_{v}}{dE_{v}} \right)}\left( \frac{dP\left( E_{v} \right)}{dE_{\mu}} \right)dE_{v}. \qquad (10.50)
```

在方程 10.50 中，$\frac{dN_{\mu}}{dE_{\mu}}$ 对应观测到的μ子能谱，$\frac{dN_{v}}{dE_{v}}$ 是所寻求的中微子能谱。项 $\frac{dP\left( E_{v} \right)}{dE_{\mu}}$ 包含中微子相互作用的物理过程，描述了在CC相互作用中从能量为 `E[ν]` 的中微子获得能量为 `E[μ]` 的μ子的概率。将方程 10.50 与第一类Fredholm积分方程（方程 10.1）进行比较，可以发现中微子能谱的重建确实是一个反问题，因此需要使用去卷积算法。
