

# 风味标记

正如上一节所解释的，测量产生风味是获取 *CP* 破坏和介子振荡参数的关键任务。风味标记是粒子探测器（此处特指质子-质子对撞机）用来确定中性介子产生风味的技术。由于混合的存在，衰变风味并不总是等于产生风味，因此无法从 *B* 介子在其各自寿命结束时衰变成的粒子中推断出产生风味。相反，产生风味是从产生瞬间产生的信息中得出的。在 *b* $\overline{b}$ 产生过程之后，*b* 夸克与从真空中产生的轻夸克配对，形成多种 *B* 强子类型，因为没有夸克能以非束缚态（即孤立形式）存在。在[图 9.11](#9783110785951_027842.xhtml#b_9783110785968-009_fig_011) 中，这种强子化过程通过费曼图进行了说明，其中时间从左向右流逝。*b* 和 $\overline{b}$ 夸克在质子-质子碰撞后，通过胶子-胶子融合成对产生。上方的夸克随后与胶子场相互作用，产生额外的 $d\overline{d}$ 和 $u\overline{u}$ 对，它们形成一个中性 $\overline{B^{0}}$ 介子和一个带电介子，以红色标记。中性 $\overline{B^{0}}$ 是感兴趣的信号粒子，与之相关的所有过程被称为同侧（SS）过程，而来自 $\overline{b}$ 强子化 $\overline{b}$ 的过程被称为对侧（OS）过程。在对侧，$\overline{b}$ 与胶子场相互作用形成一个 $d\overline{d}$ 对。产生的 $d\overline{b}$ 对随后形成一个中间 *B*⁰ 介子，该介子经历弱衰变（由 *W* 玻色子介导）变为带魅介子 *D*⁻，*W* 衰变为一个缪子和一个中微子。

现在必须牢记，电磁电荷在每个衰变顶点都守恒，因此同侧介子的电荷与风味 $\overline{B^{0}}$ 完全相关。因此，通过识别这些伴随的信使粒子并测量它们的电荷，就可以推断出产生风味，这正是*风味标记*背后的核心思想。

在 LHCb，此类过程发生在强子环境中。它们包含来自初级相互作用点（PV）的更多径迹，这些径迹由质子解体及随后的强子化和衰变产生。因此，碰撞事件中的许多径迹可能带电且测量良好，但仍与信号介子本身无关。即使找到了正确的径迹集合，也无法像[图 9.11](#9783110785951_027842.xhtml#b_9783110785968-009_fig_011) 所示过程中那样，明确地将其关联到某个顶点，因为这些相互作用在很大程度上是瞬时发生且在单一点发生的。像混合这样的物理过程也会起作用，因为如果对侧的中间 *B*⁰ 在衰变前发生了混合，例如，它将导致终态 $D^{+}\mu^{-}\overline{v_{\mu}}$ 而不是 *D*⁻*μ*⁺*ν[μ]*，从而为信号介子暗示错误的风味。最后，并非每个径迹都能被测量和保存，当被测量时，粒子动量、粒子类型和测量电荷的不确定性被确定，导致一些径迹的重建质量优于其他径迹。

考虑到这些挑战，显然风味标记无法产生对产生风味的精确测量。同时，它也是唯一的方法。相当大程度的风味误识别存在于大多数事件中，因此精确确定误识别概率（*误标记*概率）反而成为该技术的进一步优化目标。如果每个风味估计的误识别概率被精确知道，就可以在不扭曲底层物理的前提下，*平均*正确地对整个数据集进行风味标记。表征给定标记算法质量的参数将在下文中解释。

## 9.3.3 风味标记形式化

风味标记算法接收重建的粒子径迹，并返回两个数字：标记判决 *d* 和误标记估计 *η* ∈ [0, 0.5]。误标记是指风味未被正确确定的概率。对于 *η* > 0.5 的事件，这些输出总是被转换为 *η* ↦ 1−*η* 和 *d* ↦ −*d*。标记效率 *ϵ*[tag] 由下式给出：

(9.13) $\epsilon_{\text{tag}} = \frac{N_{r} + N_{w}}{Nr + N_{w} + N_{u}} = \frac{N_{\text{tagged}}}{N_{\text{total}}} \quad (9.13)$

其中 *N [r]*、*N [w]*、*N [u]* 分别为正确标记、错误标记和未标记事件的数量，量化了已标记事件的分数。量化风味标记算法质量所需的最后一个指标是风味标记*稀释因子*，D = (1 − 2*η*)，它通过为每个事件分配一个有效权重来考虑误标记概率，当 *η* = 0.5 时权重为零，当 *η* = 0 时权重为 1。数据集的*标记能力*，*ϵ*[tag,eff]，测量了用于 *CP* 破坏测量的有效样本量，由下式给出：

(9.14) $\epsilon_{\text{tag,eff}} = \epsilon_{\text{tag}}\mathcal{D}^{2} = \frac{\epsilon_{\text{tag}}}{N_{\text{tagged}}}{\sum\limits_{i,\text{tagged}}\left( {1 - 2\eta_{i}} \right)^{2}}. \quad (9.14)$

该性能指标用于通过以下公式估算测量的时间依赖 *CP* 不对称度 *σ*(𝒜) 的不确定度：

(9.15) $\sigma(\mathcal{A}) \propto \frac{1}{\sqrt{\epsilon_{\text{tag},\text{eff}}N_{\text{total}}}}. \quad (9.15)$
