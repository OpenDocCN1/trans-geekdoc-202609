
与此同时，新一代成像大气切伦科夫望远镜（IACT）正在建设中。切伦科夫望远镜阵列（CTA）[[120](#9783110785951_034588.xhtml#b_9783110785968-011_ref_120)]将由位于西班牙拉帕尔马岛和智利帕拉纳尔的100多台望远镜组成，可观测北半球和南半球的天空。计划建设三种类型的望远镜：大型、中型和小型望远镜，分别称为LST、MST和SST。每种类型都有特定的反射面尺寸，并覆盖特定的能量范围，使整个望远镜阵列的总能量范围宽达20 GeV至300 TeV。CTA的灵敏度将比当前一代IACT高十倍，并将拥有更高的能量分辨率。拉帕尔马岛首台LST的建设于2018年完成，在调试阶段结束后，该地点将再建设三台LST。凭借IACT系统前所未有的灵敏度，CTA将为观测宇宙开启一扇新窗口，并有望发现新的伽马射线源。

## 2.3 粒子物理学

*Bernhard Spaan*

*Holger Stevens*

1939年核裂变的发现是建立粒子物理学的主要原因之一。如今，研究重点不再在于原子层面，而是在于亚原子基本粒子。这些基本粒子受多种力的影响。20世纪70年代，一种描述粒子及其相应力的理论被建立起来，称为粒子物理学标准模型。利用该模型，可以对各种物理过程进行预测。最直接的预测是所谓母粒子不同衰变模式的比率。为验证此类预测，必须观测到这些衰变。由于感兴趣的粒子不稳定且衰变极快，因此需要在探测器中产生它们。粒子由加速器产生，加速器使高能粒子发生碰撞。利用碰撞中的自由能，可以形成新粒子。这种转化可能性通常被称为爱因斯坦的方程`E = mc²`。值得注意的是，产生粒子的类型、能量和飞行方向在先验上是未知的。因此，粒子物理探测器的主要挑战之一是重建和识别粒子。由于它们衰变迅速，这是通过重建和组合其子粒子来间接完成的。蒙特卡洛模拟是一种重要工具。它在探测器建设前后用于模拟预期性能。然而，模拟也用于交叉检查和误差估计，以分析实际数据。

### 2.3.1 实验

欧洲核子研究中心（CERN）大型强子对撞机（LHC）上的LHCb实验旨在通过高精度测量来探测标准模型。该实验的主要焦点是分析至少包含一个重夸克的粒子，即`b`夸克或其反粒子`b̄`夸克——有时也称为美夸克或底夸克。所谓的b-强子（B介子或b-重子）寿命较短，约为1.5 ps，因此在平均飞行约1厘米后衰变为寿命较长的其他几个粒子，从而可被实验探测到。在大型强子对撞机中，质子束团与质子束团在高达14 TeV的质心能量下碰撞。重离子与重离子或重离子与质子的碰撞也是可能的。LHCb可在所有运行场景下收集数据。然而，实验主要收集质子碰撞数据。在这些碰撞中，成对的`b`夸克，即一个`b`和一个`b̄`（反`b`夸克），被大量产生。然而，涉及轻夸克或胶子产生的过程要频繁得多，大约高出100倍。此外，单次2个质子的碰撞会产生许多其他粒子。例如，在产生`b̄`对的2个质子碰撞中，探测器中可见的所有粒子中，仅有几百分比源自B-强子的衰变。`b`-强子通常有几百种不同的衰变模式，而LHCb数据分析感兴趣的模式发生的比例仅为10⁻³或更低，有时甚至为0或更低。

特别感兴趣的过程涉及中性`B`介子`(Bₛ⁰: b̄s, B_d⁰: b̄d)`衰变为对粒子与反粒子对称性破坏敏感的终态。这些衰变的分析有望进一步揭示`CP`破坏的起源，从而揭示宇宙中物质与反物质表观不对称之谜，这是粒子物理学标准模型无法解释的。对这类衰变进行精密测量的需求是LHCb实验设计的驱动因素。由于一种非常微妙的机制，中性`B`介子在产生与衰变之间的短暂时间内可以在粒子和反粒子态之间振荡（`B B̄`振荡）。由于存在某些类型的`B`介子衰变，`B⁰`和反`B⁰`介子`(B̄⁰)`具有共同的终态（`CP`本征态），`B B̄`振荡与衰变为此类`CP`本征态之间的干涉产生了可测量的`CP`破坏效应。然后利用这些`CP`不对称性的大小测量值，以高精度探测粒子物理学标准模型。测量原理是确定`B`介子和`B̄`介子在产生时刻`t = 0`的衰变率差异，作为衰变前时间的函数。这种可测量的不对称性`A[CP]`可表示如下：
