
机器学习模型通常会经过压缩或量化，以减少资源占用。对于决策树，子树剪枝的方法从一开始就已被提出[[319](#9783110785951_034588.xhtml#b_9783110785968-011_ref_319)]。此外，集成成员的选择也受到关注，例如[[371](#9783110785951_034588.xhtml#b_9783110785968-011_ref_371)]，但这是一个活跃的研究领域。在部署树模型之前，值得确定合适的剪枝方法。

## 3.5 神经网络

神经网络自诞生起就备受关注。在此，我们将介绍该领域的结构，并指引部分文献供进一步学习。

神经网络通常是——最常见为无环的——有向图，其节点按层组织。输入层由输入特征的节点 `x[i]` 组成。输出层给出网络的结果 `y`，或拥有多个所谓的 `heads`，每个 head 是多项式神经网络中的一个目标。输入层和输出层之间的层称为 `hidden layers`（隐藏层）。具有隐藏层的神经网络称为深度神经网络（DNN）。[图 3.2](#9783110785951_005681.xhtml#b_9783110785968-003_fig_002) 展示了一个神经元，包含求和后的传入节点权重以及非线性激活函数，此处为修正线性单元，其计算公式为 `ReLU(z) = max{0, z}`。其他激活函数包括 sigmoid、tanh 和 softmax。单个这样的神经元也称为感知机。拥有多个此类感知机的层则称为多层感知机（MLP）。后续层节点间的连接方式可能是前一层的每个节点都与下一层的每个节点相连，从而形成全连接层。也存在层间连接较少的网络类型。由于推理过程将计算值从传入信号传递到下一个隐藏层，直到到达输出层，因此它是前馈神经网络。如果计算还包含反馈连接，则该神经网络称为循环网络。

“神经网络”一词源于这样一种想法：加权求和与非线性激活函数的组合让人联想到生物神经元细胞。事实上，人脑的神经元细胞在接收来自输入神经元的足够强信号时会被激活。然而，神经元细胞比我们此处称为“神经元”的简单数学函数复杂得多。此外，大脑也比简单的神经元层拼接复杂得多。因此，不应将神经网络误解为生物大脑的合适模型。

### 3.5.1 DNN 的架构

DNN 由一系列层组成，每层可执行不同的计算。当我们提到 `architecture`（架构）时，指的是特定的层序列，不考虑用于训练该架构的优化算法或数据。

最基础的层类型称为 `dense layer`（稠密层/全连接层）；它将权重矩阵 `W` 与传入值的完整向量 `![](graphic/b_9783110785968-003_ingr_064.png)` 相乘，并可能加上偏置项 `b ∈ ℝ`。然后将加权和输入非线性激活函数 `u`，使得稠密层的输出为 `u(W^⊤h + b)`，如[图 3.2](#9783110785951_005681.xhtml#b_9783110785968-003_fig_002)所示。权重矩阵随后在学习过程中被优化，非线性函数使模型能够学习数据中的非线性依赖关系。然而，稠密权重矩阵 `W` 给模型引入了大量参数，其训练在资源消耗方面可能是低效的。

`dropout`（丢弃）层能更大幅度地减少连接数。该层在后续层随机忽略一定比例的传入值及其权重。Dropout 可被视为模型的一种正则化。
