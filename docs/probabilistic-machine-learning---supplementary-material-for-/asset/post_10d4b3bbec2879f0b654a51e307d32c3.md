
Recall that \( A_i \) is the number of students admitted in example \( i \), \( N_i \) is the number of applicants, \( \mu_i \) is the expected rate of admissions (the variable of interest), and \( \text{DEPT}[i] \) is the department (6 possible values). For pedagogical reasons, we replace the categorical variable \( \text{GENDER}[i] \) with the binary indicator \( \text{MALE}[i] \). We can create a model with **varying intercept** and **varying slope** as follows:

```
\( A_i \sim \text{Bin}(N_i, \mu_i) \tag{15.87} \)

\( \text{logit}(\mu_i) = \alpha_{\text{DEPT}[i]} + \beta_{\text{DEPT}[i]} \times \text{MALE}[i] \tag{15.88} \)
```

This has 12 parameters, as does the original formulation in Equation (15.65). However, these are not independent degrees of freedom. In particular, the intercept and slope are correlated, as we see in Figure 15.2 (higher admissions means steeper slope). We can capture this using the following prior:

```
\( (\alpha_j, \beta_j) \sim \mathcal{N}\left( \begin{pmatrix} \overline{\alpha} \\ \overline{\beta} \end{pmatrix}, \boldsymbol{\Sigma} \right) \tag{15.89} \)

\( \overline{\alpha} \sim \mathcal{N}(0, 4) \tag{15.90} \)

\( \overline{\beta} \sim \mathcal{N}(0, 1) \tag{15.91} \)

\( \boldsymbol{\Sigma} = \text{diag}(\boldsymbol{\sigma}) \mathbf{R} \text{diag}(\boldsymbol{\sigma}) \tag{15.92} \)

\( \mathbf{R} \sim \text{LKJ}(2) \tag{15.93} \)

\( \boldsymbol{\sigma} \sim \prod_{d=1}^2 \mathcal{N}_+(\sigma_d|0, 1) \tag{15.94} \)
```

We can write this more compactly in the following way.\(^2\). We define \( \boldsymbol{u} = (\overline{\alpha}, \overline{\beta}) \), and \( \boldsymbol{w}_j = (\alpha_j, \beta_j) \), and then use this model:

```
\( \text{logit}(\mu_i) = w_{\text{DEPT}[i]}[0] + w_{\text{DEPT}[i]}[1] \times \text{MALE}[i] \tag{15.95} \)

\( \boldsymbol{w}_j \sim \mathcal{N}(\boldsymbol{u}, \boldsymbol{\Sigma}) \tag{15.96} \)

\( \boldsymbol{u} \sim \mathcal{N}(\mathbf{0}, \text{diag}(4, 1)) \tag{15.97} \)
```

See Figure 15.5(a) for the graphical model.

Following the discussion in **??**, it is advisable to rewrite the model in a non-centered form. Thus we write

```
\( \boldsymbol{w}_j = \boldsymbol{u} + \sigma \mathbf{L} \boldsymbol{z}_j \tag{15.98} \)
```

where \( \mathbf{L} = \text{chol}(\mathbf{R}) \) is the Cholesky factor for the correlation matrix \( \mathbf{R} \), and \( \boldsymbol{z}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_2) \). Thus the model becomes the following:\(^3\).

```
\( \boldsymbol{z}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_2) \tag{15.99} \)

\( \boldsymbol{v}_j = \text{diag}(\boldsymbol{\sigma}) \mathbf{L} \boldsymbol{z}_j \tag{15.100} \)

\( \boldsymbol{u} \sim \mathcal{N}(\mathbf{0}, \text{diag}(4, 1)) \tag{15.101} \)

\( \text{logit}(\mu_i) = u[0] + v_{[\text{DEPT}[i], 0]} + (u[1] + v_{[\text{DEPT}[i], 1]}) \times \text{MALE}[i] \tag{15.102} \)
```

This is the version of the model that is implemented in the numpyro code.

The results of fitting this model are shown in Figure 15.5(b). The fit is slightly better than in Figure 15.2b, especially for the second column (females in department 2), where the observed value is now inside the predictive interval.

### 28.1 Topic models

In this section, we show how to modify the multinomial PCA model of **??** to handle variable-sized observations, such as text documents. The basic idea is to assume each observation **_x_**_<sub>l</sub>_ is generated independently of all the others conditional on the shared latent factors **_z_**; the likelihood is categorical, with shared parameters, and the prior is Dirichlet distribution. This is called a **topic model**, since the **_z_** variables can be interpreted as a mixture of different topics that are present in document **_x_**.

#### 28.1.1 Latent Dirichlet Allocation (LDA)

The most common kind of topic model is called **latent Dirichlet allocation (LDA)** [BNJ03; Ble12; BGHM17]. (This usage of the term “LDA” is not to be confused with linear discriminant analysis.)

##### 28.1.1.1 Model definition

We can define the LDA model as follows. Let $x_{nl} \in \{1, \dots, V\}$ be the identity of the $l$’th word in document $n$, where $l$ can now range from 1 to $L_n$, the length of the document, and $V$ is the size of the vocabulary. The probability of word $v$ at location $l$ is given by

$p(x_{nl} = v | z_n) = \sum_k z_{nk} w_{kv}$ (28.1)

where $0 \le z_{nk} \le 1$ is the proportion of “topic” $k$ in document $n$, and $z_n \sim \text{Dir}(\alpha)$.

We can rewrite this model by associating a discrete latent variable $c_{nl} \in \{1, \dots, N_z\}$ with each word in each document, with distribution $p(c_{nl} | z_n) = \text{Cat}(c_{nl} | z_n)$. Thus $c_{nl}$ specifies the topic to use for word $l$ in document $n$. The full joint model becomes

$p(x_n, z_n, c_n) = \text{Dir}(z_n | \alpha) \prod_{l=1}^{L_n} \text{Cat}(c_{nl} | z_n) \text{Cat}(x_{nl} | W[c_{nl}, :])$ (28.2)

where **W**[$k$, :] = **_w_**_<sub>k</sub>_ is the distribution over words for the $k$’th topic. See Figure 28.1 for the corresponding PGM-D.

We typically use a Dirichlet prior the topic parameters, $p(w_k) = \text{Dir}(w_k | \beta 1_V)$; by setting $\beta$ small enough, we can encourage these topics to be sparse, so that each topic only predicts a subset of the words. In addition, we use a Dirichlet prior on the latent factors, $p(z_n) = \text{Dir}(z_n | \alpha 1_{N_z})$. If we set $\alpha$ small enough, we can encourage the topic distribution for each document to be sparse, so that each document only contains a subset of the topics. See Figure 28.2 for an illustration.
