# 28.1.5 Collapsed Gibbs sampling for LDA

In this section, we discuss how to perform inference using MCMC. Vanilla Gibbs sampling samples from the following full conditionals: 

```
p(c_{il} = k|\cdot) \propto \exp[\log \pi_{ik} + \log w_{k, x_{il}}] \quad (28.12)
p(\pi_i|\cdot) = \text{Dir}(\{\alpha_k + \sum_l \mathbb{I}(c_{il} = k)\}) \quad (28.13)
p(w_k|\cdot) = \text{Dir}(\{\gamma_v + \sum_i \sum_l \mathbb{I}(x_{il} = v, c_{il} = k)\}) \quad (28.14)
```

However, one can get better performance by analytically integrating out the $\pi_i$'s and the $w_k$'s, both of which have a Dirichlet distribution, and just sampling the discrete $c_{il}$'s. This approach was first suggested in [GS04], and is an example of collapsed Gibbs sampling. Figure 28.9(b) shows that now all the $c_{il}$ variables are fully correlated. However, we can sample them one at a time, as we explain below. 

First, we need some notation. Let $N_{ivk} = \sum_{l=1}^{L_i} \mathbb{I}(c_{il} = k, x_{il} = v)$ be the number of times word $v$ is assigned to topic $k$ in document $i$. Let $N_{ik} = \sum_v N_{ivk}$ be the number of times any word from document $i$ has been assigned to topic $k$. Let $N_{vk} = \sum_i N_{ivk}$ be the number of times word $v$ has been assigned to topic $k$ in any document. Let $N_k = \sum_v N_{vk}$ be the number of words assigned to topic $k$. Finally, let $L_i = \sum_k N_{ik}$ be the number of words in document $i$; this is observed.
