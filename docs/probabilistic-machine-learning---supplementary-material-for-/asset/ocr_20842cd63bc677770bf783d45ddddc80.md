# 4.2.2.2 Categorical RBMs

We can extend the binary RBM to categorical visible variables by using a 1-of-C encoding, where C is the number of states for each x_d. We define a new energy function as follows [SMH07; SH10]:

E(x, z; θ) ⊴ - \sum_{d=1}^D \sum_{k=1}^K \sum_{c=1}^C x_d^c z_k w_{dk}^c - \sum_{d=1}^D \sum_{c=1}^C x_d^c b_d^c - \sum_{k=1}^K z_k c_k   (4.18)

The full conditionals are given by

p(x_d = c* | z, θ) = S({b_d^c + \sum_k z_k w_{dk}^c}_{c=1}^C)[c*]   (4.19)

p(z_k = 1 | x, θ) = σ(c_k + \sum_d \sum_c x_d^c w_{dk}^c)   (4.20)

# 4.2.2.3 Gaussian RBMs

We can generalize the model to handle real-valued data. In particular, a Gaussian RBM has the following energy function:

E(x, z | θ) = - \sum_{d=1}^D \sum_{k=1}^K w_{dk} z_k x_d - 1/2 \sum_{d=1}^D (x_d - b_d)^2 - \sum_{k=1}^K a_k z_k   (4.21)

The parameters of the model are θ = (w_dk, a_k, b_d). (We have assumed the data is standardized, so we fix the variance to σ^2 = 1.) Compare this to a Gaussian in canonical or information form (see Section ??):

N_c(x | η, Λ) ∝ exp(η^T x - 1/2 x^T Λ x)   (4.22)

where η = Λμ. We see that we have set Λ = I, and η = \sum_k z_k w_{.,k}. Thus the mean is given by μ = Λ^{-1}η = \sum_k z_k w_{.,k}, which is a weighted combination of prototypes. The full conditionals, which are needed for inference and learning, are given by

p(x_d | z, θ) = N(x_d | b_d + \sum_k w_{dk} z_k, 1)   (4.23)

p(z_k = 1 | x, θ) = σ ( c_k + \sum_d w_{dk} x_d )   (4.24)

More powerful models, which make the (co)variance depend on the hidden states, can also be developed [RH10].
