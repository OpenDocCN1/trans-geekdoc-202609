Recall that \( A_i \) is the number of students admitted in example \( i \), \( N_i \) is the number of applicants, \( \mu_i \) is the expected rate of admissions (the variable of interest), and \( \text{DEPT}[i] \) is the department (6 possible values). For pedagogical reasons, we replace the categorical variable \( \text{GENDER}[i] \) with the binary indicator \( \text{MALE}[i] \). We can create a model with **varying intercept** and **varying slope** as follows:

```
\( A_i \sim \text{Bin}(N_i, \mu_i) \tag{15.87} \)

\( \text{logit}(\mu_i) = \alpha_{\text{DEPT}[i]} + \beta_{\text{DEPT}[i]} \times \text{MALE}[i] \tag{15.88} \)
```

This has 12 parameters, as does the original formulation in Equation (15.65). However, these are not independent degrees of freedom. In particular, the intercept and slope are correlated, as we see in Figure 15.2 (higher admissions means steeper slope). We can capture this using the following prior:

```
\( (\alpha_j, \beta_j) \sim \mathcal{N}\left( \begin{pmatrix} \overline{\alpha} \\ \overline{\beta} \end{pmatrix}, \boldsymbol{\Sigma} \right) \tag{15.89} \)

\( \overline{\alpha} \sim \mathcal{N}(0, 4) \tag{15.90} \)

\( \overline{\beta} \sim \mathcal{N}(0, 1) \tag{15.91} \)

\( \boldsymbol{\Sigma} = \text{diag}(\boldsymbol{\sigma}) \mathbf{R} \text{diag}(\boldsymbol{\sigma}) \tag{15.92} \)

\( \mathbf{R} \sim \text{LKJ}(2) \tag{15.93} \)

\( \boldsymbol{\sigma} \sim \prod_{d=1}^2 \mathcal{N}_+(\sigma_d|0, 1) \tag{15.94} \)
```

We can write this more compactly in the following way.\(^2\). We define \( \boldsymbol{u} = (\overline{\alpha}, \overline{\beta}) \), and \( \boldsymbol{w}_j = (\alpha_j, \beta_j) \), and then use this model:

```
\( \log(\mu_i) = w_{\text{DEPT}[i]}[0] + w_{\text{DEPT}[i]}[1] \times \text{MALE}[i] \tag{15.95} \)

\( \boldsymbol{w}_j \sim \mathcal{N}(\boldsymbol{u}, \boldsymbol{\Sigma}) \tag{15.96} \)

\( \boldsymbol{u} \sim \mathcal{N}(\mathbf{0}, \text{diag}(4, 1)) \tag{15.97} \)
```

See Figure 15.5(a) for the graphical model.

Following the discussion in **??**, it is advisable to rewrite the model in a non-centered form. Thus we write

```
\( \boldsymbol{w}_j = \boldsymbol{u} + \sigma \mathbf{L} \boldsymbol{z}_j \tag{15.98} \)
```

where \( \mathbf{L} = \text{chol}(\mathbf{R}) \) is the Cholesy factor for the correlation matrix \( \mathbf{R} \), and \( \boldsymbol{z}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_2) \). Thus the model becomes the following:\(^3\).

```
\( \boldsymbol{z}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_2) \tag{15.99} \)

\( \boldsymbol{v}_j = \text{diag}(\boldsymbol{\sigma}) \mathbf{L} \boldsymbol{z}_j \tag{15.100} \)

\( \boldsymbol{u} \sim \mathcal{N}(\mathbf{0}, \text{diag}(4, 1)) \tag{15.101} \)

\( \log(\mu_i) = u[0] + v_{[\text{DEPT}[i], 0]} + (u[1] + v_{[\text{DEPT}[i], 1]}) \times \text{MALE}[i] \tag{15.102} \)
```

This is the version of the model that is implemented in the numpyro code.

The results of fitting this model are shown in Figure 15.5(b). The fit is slightly better than in Figure 15.2b, especially for the second column (females in department 2), where the observed value is now inside the predictive interval.
