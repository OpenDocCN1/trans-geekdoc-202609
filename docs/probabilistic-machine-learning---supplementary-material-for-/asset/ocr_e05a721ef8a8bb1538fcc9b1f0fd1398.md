Then we can get a “Gaussianized” version of the observation model:

```
p(y_i|x_i, w) \ge f(x_i, \psi_i) \mathcal{N}(\tilde{y}_i|X_i w, \mathbf{A}_i^{-1})
(15.29)
```

where \(f(x_i, \psi_i)\) is some function that does not depend on \(w\). Given this, it is easy to compute the posterior
\(q(w) = \mathcal{N}(m_N, \mathbf{V}_N)\), using Bayes rule for Gaussians.

Given the posterior, we can write the ELBO as follows:

```
\mathcal{L}(\psi) \triangleq -D_{\text{KL}} (q(w)\|p(w)) + \mathbb{E}_q \left[ \sum_{i=1}^N \log p(y_i|x_i, w) \right]
(15.30)
= -D_{\text{KL}} (q(w)\|p(w)) + \mathbb{E}_q \left[ \sum_{i=1}^N y_i^\mathsf{T} \eta_i - \text{lse}(\eta_i) \right]
(15.31)
= -D_{\text{KL}} (q(w)\|p(w)) + \sum_{i=1}^N y_i^\mathsf{T} \mathbb{E}_q [\eta_i] - \sum_{i=1}^N \mathbb{E}_q \left[ \text{lse}(\eta_i) \right]
(15.32)
```

where \(p(w) = \mathcal{N}(w|m_0, \mathbf{V}_0)\) is the prior and \(q(w) = \mathcal{N}(w|m_N, \mathbf{V}_N)\) is the approximate posterior. The first
term is just the KL divergence between two Gaussians, which is given by

```
-D_{\text{KL}} (\mathcal{N}(m_N, \mathbf{V}_N)\|\mathcal{N}(m_0, \mathbf{V}_0)) = -\frac{1}{2} \left[ \text{tr}(\mathbf{V}_N \mathbf{V}_0^{-1}) - \log |\mathbf{V}_N \mathbf{V}_0^{-1}| \right]
+(m_N - m_0)^\mathsf{T} \mathbf{V}_0^{-1}(m_N - m_0) - DM]
(15.33)
```

where \(DM\) is the dimensionality of the Gaussian, and we assume a prior of the form \(p(w) = \mathcal{N}(m_0, \mathbf{V}_0)\),
where typically \(\mu_0 = \mathbf{0}_{DM}\), and \(\mathbf{V}_0\) is block diagonal. The second term is simply

```
\sum_{i=1}^N y_i^\mathsf{T} \mathbb{E}_q \left[ \eta_i \right] = \sum_{i=1}^N y_i^\mathsf{T} \tilde{m}_i
(15.34)
```

where \(\tilde{m}_i \triangleq \mathbf{X}_i m_N\). The final term can be lower bounded by taking expectations of our quadratic upper
bound on lse as follows:

```
-\sum_{i=1}^N \mathbb{E}_q \left[ \text{lse}(\eta_i) \right] \ge -\frac{1}{2} \text{tr}(\mathbf{A}_i \tilde{\mathbf{V}}_i) - \frac{1}{2} \tilde{m}_i \mathbf{A}_i \tilde{m}_i + b_i^\mathsf{T} \tilde{m}_i - c_i
(15.35)
```

where \(\tilde{\mathbf{V}}_i \triangleq \mathbf{X}_i \mathbf{V}_N \mathbf{X}_i^\mathsf{T}\). Hence we have

```
\mathcal{L}(\psi) \ge -\frac{1}{2} \left[ \text{tr}(\mathbf{V}_N \mathbf{V}_0^{-1}) - \log |\mathbf{V}_N \mathbf{V}_0^{-1}| + (m_N - m_0)^\mathsf{T} \mathbf{V}_0^{-1}(m_N - m_0) \right]
-\frac{1}{2} DM + \sum_{i=1}^N y_i^\mathsf{T} \tilde{m}_i - \frac{1}{2} \text{tr}(\mathbf{A}_i \tilde{\mathbf{V}}_i) - \frac{1}{2} \tilde{m}_i \mathbf{A}_i \tilde{m}_i + b_i^\mathsf{T} \tilde{m}_i - c_i
(15.36)
```

We will use coordinate ascent to optimize this lower bound. That is, we update the variational posterior
parameters \(\mathbf{V}_N\) and \(m_N\), and then the variational likelihood parameters \(\psi_i\). We leave the detailed derivation
as an exercise, and just state the results. We have

```
\mathbf{V}_N = \left( \mathbf{V}_0 + \sum_{i=1}^N \mathbf{X}_i^\mathsf{T} \mathbf{A}_i \mathbf{X}_i \right)^{-1}
(15.37)
m_N = \mathbf{V}_N \left( \mathbf{V}_0^{-1} m_0 + \sum_{i=1}^N \mathbf{X}_i^\mathsf{T}(y_i + b_i) \right)
(15.38)
\psi_i = \tilde{m}_i = \mathbf{X}_i m_N
(15.39)
```
