## Optimization

### 6.1 Proximal methods

In this section, we discuss a class of optimization algorithms called **proximal methods** that use as their basic subroutine the **proximal operator** of a function, as opposed to its gradient or Hessian. We define this operator below, but essentially it involves solving a convex subproblem.

Compared to gradient methods, proximal methods are easier to apply to nonsmooth problems (e.g., with $\ell_1$ terms), as well as large scale problems that need to be decomposed and solved in parallel. These methods are widely used in signal and image processing, and in some applications in deep learning (e.g., [BWL19] uses proximal methods for training quantized DNNs, [Yao+20] uses proximal methods for efficient neural architecture search, [Sch+17; WHT19] uses proximal methods for policy gradient optimization, etc.).

Our presentation is based in part on the tutorial in [PB+14]. For another good review, see [PSW15].

### 6.1.1 Proximal operators

Let \( f : \mathbb{R}^n \to \mathbb{R} \cup \{+\infty\} \) be a convex function, where \( f(x) = \infty \) means the point is infeasible. Let the effective domain of \( f \) be the set of feasible points:

\(\text{dom}(f) = \{ x \in \mathbb{R}^n : f(x) < \infty \}\)

The **proximal operator** (also called a **proximal mapping**) of \( f \), denoted \(\text{prox}_f(x) : \mathbb{R}^n \to \mathbb{R}^n \), is defined by

\(\text{prox}_f(x) = \underset{z}{\text{argmin}} \left( f(z) + \frac{1}{2} \|z - x\|_2^2 \right)\)

This is a strongly convex function and hence has a unique minimizer. This operator is sketched in Figure 6.1a. We see that points inside the domain move towards the minimum of the function, whereas points outside the domain move to the boundary and then towards the minimum.

For example, suppose \( f \) is the indicator function for the convex set \( \mathcal{C} \), i.e.,

\( f(x) = I_{\mathcal{C}}(x) = \begin{cases} 0 & \text{if } x \in \mathcal{C} \\ \infty & \text{if } x \notin \mathcal{C} \end{cases} \)

In this case, the proximal operator is equivalent to projection onto the set \( \mathcal{C} \):

\(\text{proj}_{\mathcal{C}}(x) = \underset{z \in \mathcal{C}}{\text{argmin}} \|z - x\|_2\)

We can therefore think of the prox operator as generalized projection.

We will often want to compute the prox operator for a scaled function \(\eta f\), for \(\eta > 0\), which can be written as

\[
\text{prox}_{\eta f}(\mathbf{x}) = \text{argmin}_\mathbf{z} \left( f(\mathbf{z}) + \frac{1}{2\eta} \|\mathbf{z} - \mathbf{x}\|_2^2 \right) \quad (6.5)
\]

The solution to the problem in Equation (6.5) is the same as the solution to the trust region optimization problem of the form

\[
\text{argmin}_\mathbf{z} f(\mathbf{z}) \text{ s.t. } \|\mathbf{z} - \mathbf{x}\|_2 \le \rho \quad (6.6)
\]

for appropriate choices of \(\eta\) and \(\rho\). This proximal projection minimizes the function while staying close to the current iterate. We give other interpretations of the proximal operator below.

We can generalize the operator by replacing the Euclidean distance with Mahalanobis distance:

\[
\text{prox}_{\eta f, \mathbf{A}}(\mathbf{x}) = \text{argmin}_\mathbf{z} \left( f(\mathbf{z}) + \frac{1}{2\eta} (\mathbf{z} - \mathbf{x})^\top \mathbf{A} (\mathbf{z} - \mathbf{x}) \right) \quad (6.7)
\]

where **A** is a psd matrix.

### 6.1.1.1 Moreau envelope

Let us define the following quadratic approximation to the function \(f\) as a function of \(\mathbf{z}\), requiring that it touch \(f\) at \(\mathbf{x}\):

\[
f_\mathbf{x}^\eta(\mathbf{z}) = f(\mathbf{z}) + \frac{1}{2\eta} \|\mathbf{z} - \mathbf{x}\|_2^2 \quad (6.8)
\]

By definition, the location of the minimum of this function is \(\mathbf{z}^*(\mathbf{x}) = \text{argmin}_\mathbf{z} f_\mathbf{x}^\eta(\mathbf{z}) = \text{prox}_{\eta f}(\mathbf{x})\).

For example, consider approximating the function \(f(x) = |x|\) at \(x_0 = 1.5\) using \(f_{x_0}^1(z) = |z| + \frac{1}{2}(z - x_0)^2\). This is shown in Figure 6.1b: the solid black line is \(f(x)\), \(x_0 = 1.5\) is the black square, and the light gray line is \(f_{x_0}^1(z)\). The proximal projection of \(x_0\) onto \(f\) is \(z^*(x_0) = \text{argmin}_z f_{x_0}^1(z) = 0.5\), which is the minimum of the quadratic, shown by the red cross. This proximal point is closer to the minimum of \(f(x)\) than the starting point, \(x_0\).

Now let us evaluate the approximation at this proximal point:

\[
f_\mathbf{x}^\eta(\mathbf{z}^*(\mathbf{x})) = f(\mathbf{z}^*) + \frac{1}{2\eta} \|\mathbf{z}^* - \mathbf{x}\|_2^2 = \min_\mathbf{z} f(\mathbf{z}) + \frac{1}{2\eta} \|\mathbf{z} - \mathbf{x}\|_2^2 \triangleq f^\eta(\mathbf{x}) \quad (6.9)
\]

where \(f^\eta(\mathbf{x})\) is called the Moreau envelope of \(f\).

For example, in Figure 6.1b, we see that \( f_{x_0}^1(z^*) = f_{x_0}^1(0.5) = 1.0 \), so \( f^1(x_0) = 1.0 \). This is shown by the blue circle. The dotted line is the locus of blue points as we vary \( x_0 \), i.e., the Moreau envelope of \( f \).

We see that the Moreau envelope is a smooth lower bound on \( f \), and has the same minimum location as \( f \). Furthermore, it has domain \( \mathbb{R}^n \), even when \( f \) does not, and it is continuously differentiable, even when \( f \) is not. This makes it easier to optimize. For example, the Moreau envelope of \( f(r) = |r| \) is the **Huber loss** function, which is used in robust regression.

### 6.1.1.2 Prox operator on a linear approximation yields gradient update

Suppose we make a linear approximation of \( f \) at the current iterate \( \boldsymbol{x}_t \):

\( \hat{f}(\boldsymbol{x}) = f(\boldsymbol{x}_t) + \boldsymbol{g}_t^\mathsf{T}(\boldsymbol{x} - \boldsymbol{x}_t) \quad (6.10) \)

where \( \boldsymbol{g}_t = \nabla f(\boldsymbol{x}_t) \). To compute the prox operator, note that

\( \nabla_z \hat{f}_x^\eta(\boldsymbol{z}) = \nabla_z \left[ f(\boldsymbol{x}_t) + \boldsymbol{g}_t^\mathsf{T}(\boldsymbol{z} - \boldsymbol{x}) + \frac{1}{2\eta}||\boldsymbol{z} - \boldsymbol{x}_t||_2^2 \right] = \boldsymbol{g}_t + \frac{1}{\eta}(\boldsymbol{z} - \boldsymbol{x}_t) \quad (6.11) \)

Solving \( \nabla_z \hat{f}_x^\eta(\boldsymbol{z}) = \boldsymbol{0} \) yields the standard gradient update:

\( \text{prox}_{\eta f}(\boldsymbol{x}) = \boldsymbol{x} - \eta \boldsymbol{g}_t \quad (6.12) \)

Thus a prox step is equivalent to a gradient step on a linearized objective.

### 6.1.1.3 Prox operator on a quadratic approximation yields regularized Newton update

Now suppose we use a second order approximation at \( \boldsymbol{x}_t \):

\( \hat{f}(\boldsymbol{x}) = f(\boldsymbol{x}_t) + \nabla \boldsymbol{g}_t(\boldsymbol{x} - \boldsymbol{x}_t) + \frac{1}{2}(\boldsymbol{x} - \boldsymbol{x}_t)^\mathsf{T} \mathbf{H}_t (\boldsymbol{x} - \boldsymbol{x}_t) \quad (6.13) \)

The prox operator for this is

\( \text{prox}_{\eta \hat{f}}(\boldsymbol{x}) = \boldsymbol{x} - (\mathbf{H}_t + \frac{1}{\eta}\mathbf{I})^{-1} \boldsymbol{g}_t \quad (6.14) \)

### 6.1.1.4 Prox operator as gradient descent on a smoothed objective

Prox operators are arguably most useful for nonsmooth functions for which we cannot make a Taylor series approximation. Instead, we will optimize the Moreau envelope, which is a smooth approximation.

In particular, from Equation (6.9), we have

\( f^\eta(\boldsymbol{x}) = f(\text{prox}_{\eta f}(\boldsymbol{x})) + \frac{1}{2\eta} || \boldsymbol{x} - \text{prox}_{\eta f}(\boldsymbol{x}) ||_2^2 \quad (6.15) \)

Hence the gradient of the Moreau envelope is given by

\( \nabla_x f^\eta(\boldsymbol{x}) = \frac{1}{\eta} (\boldsymbol{x} - \text{prox}_{\eta f}(\boldsymbol{x})) \quad (6.16) \)

Thus we can rewrite the prox operator as

\( \text{prox}_{\eta f}(\boldsymbol{x}) = \boldsymbol{x} - \eta \nabla f^\eta(\boldsymbol{x}) \quad (6.17) \)

Thus a prox step is equivalent to a gradient step on the smoothed objective.
