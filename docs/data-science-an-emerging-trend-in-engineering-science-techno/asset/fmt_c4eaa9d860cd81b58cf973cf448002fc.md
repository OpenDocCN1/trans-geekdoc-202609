Suppose we have a dataset with one feature `x` and a target variable `y`. The linear regression model has the form `y = mx + b`, where `m` is the slope and `b` is the intercept. The MSE loss function is given by:

```
MSE = (1/n) * Σ(y_i - (mx_i + b))^2
```

where `n` is the number of data points.

To apply gradient descent, we first calculate the gradients of the loss function with respect to `m` and `b`:

```
∂L/∂m = -(2/n) * Σ x_i (y_i - (mx_i + b))

```

```
m = m − α ∂L/∂m
b = b − α ∂L/∂b
```

where `α` is the learning rate.

We repeat these steps until the parameters converge to values that minimize the MSE. This is a basic example, and in practice, there are many variations and extensions of gradient descent used in different machine learning algorithms.

# 3.24 Constrained Optimization

Constrained optimization is a type of optimization problem where the goal is to minimize or maximize a function subject to certain constraints. In other words, the solution must satisfy a set of conditions in addition to optimizing the objective function.

Mathematically, a constrained optimization problem can be formulated as:

Minimize `f(x)` subject to `g_i(x) ≤ 0` for `i = 1, 2, …, m` and `h_j(x) = 0` for `j = 1, 2, …, p`,

where:

*   `x` is the vector of variables we want to optimize,
*   `f(x)` is the objective function we want to minimize or maximize,
*   `g_i(x)` are inequality constraints that must be satisfied,
*   `h_j(x)` are equality constraints that must be satisfied,
*   `m` is the number of inequality constraints, and
*   `p` is the number of equality constraints.

A common approach to solving constrained optimization problems is the method of Lagrange multipliers. The Lagrangian function is defined as:

```
L(x, λ, μ) = f(x) + Σ λ_i g_i(x) + Σ μ_j h_j(x)
```

where `λ_i` and `μ_j` are Lagrange multipliers associated with the inequality and equality constraints, respectively.

The stationary points of the Lagrangian (where the gradient is zero) satisfy the following conditions, known as the KKT (Karush-Kuhn-Tucker) conditions:

```
∇_x L(x, λ, μ) = 0
g_i(x) ≤ 0, ∀i
h_j(x) = 0, ∀j
λ_i ≥ 0, ∀i
λ_i g_i(x) = 0, ∀i
```

Here's a simple example to illustrate constrained optimization using Lagrange multipliers:

Minimize `f(x, y) = x^2 + y^2` subject to `x + y = 1`.

The Lagrangian for this problem is:

```
L(x, y, λ) = x^2 + y^2 + λ(x + y − 1)
```

Taking the derivatives with respect to `x`, `y`, and `λ` and setting them to zero, we get:

```
∂L/∂x = 2x + λ = 0
∂L/∂y = 2y + λ = 0
∂L/∂λ = x + y − 1 = 0
```

Constrained optimization problems arise in various fields, including engineering, economics, and machine learning, where there are often constraints on the variables that must be satisfied.

# 3.25 KKT Conditions

The Karush-Kuhn-Tucker (KKT) conditions are necessary conditions for optimality in constrained optimization problems. These conditions generalize the Lagrange multiplier method to handle both equality and inequality constraints. The KKT conditions are used to find the optimal solution to a constrained optimization problem by identifying points where the gradient of the objective function aligns with a combination of the gradients of the constraint functions.

The KKT conditions consist of the following parts:

1) **Stationarity**: The gradient of the Lagrangian function (which combines the objective function and the constraints weighted by Lagrange multipliers) is zero at the optimal point.

```
∇_x L(x, λ, μ) = ∇f(x) + Σ λ_i ∇g_i(x) + Σ μ_j ∇h_j(x) = 0
```

2) **Primal feasibility**: The primal variables (`x`) satisfy the constraints.

```
g_i(x) ≤ 0, ∀i
h_j(x) = 0, ∀j
```

3) **Dual feasibility**: The Lagrange multipliers (`λ`, `μ`) are non-negative.

```
λ_i ≥ 0, ∀i
```

4) **Complementary slackness**: For each constraint, either the constraint is inactive (i.e., `g_i(x) < 0`) or the corresponding Lagrange multiplier is zero.

```
λ_i g_i(x) = 0, ∀i
```

To illustrate the KKT conditions, let's consider a simple example:

Minimize `f(x, y) = x^2 + y^2` subject to `x + y ≥ 1`.

The Lagrangian for this problem is:

```
L(x, y, λ) = x^2 + y^2 − λ(x + y − 1)
```

Taking the derivatives with respect to `x`, `y`, and `λ` and setting them to zero, we get:

```
∂L/∂x = 2x − λ = 0
∂L/∂y = 2y − λ = 0
```

```
λ(x + y − 1) = 0
x + y − 1 ≥ 0
λ ≥ 0
```

In summary, the KKT conditions provide a set of equations and inequalities that must be satisfied at the optimal solution of a constrained optimization problem. They are essential for finding optimal solutions in various fields, including machine learning and engineering.

# 3.26 Introduction to Non-Gradient Techniques

Non-gradient optimization techniques are methods for finding the minimum or maximum of a function without explicitly using gradient information. These methods are useful when the gradient of the function is not available or is too expensive to compute. Here are some common non-gradient optimization techniques:

1) **Nelder-Mead Method (or Downhill Simplex Method)**: This method is a heuristic optimization technique for nonlinear optimization problems. It works by constructing a simplex (a geometric figure resembling a triangle or higher-dimensional polytope) around a set of points in the search space and iteratively shrinking, expanding, or reflecting the simplex to find the minimum.

   Example: Consider the problem of minimizing the Rosenbrock function `f(x, y) = (1 − x)^2 + 100(y − x^2)^2`. The Nelder-Mead method can be applied to find the minimum of this function.

2) **Genetic Algorithms**: Genetic algorithms are optimization techniques inspired by the process of natural selection and genetics. They work by maintaining a population of candidate solutions (individuals), evaluating their fitness based on the objective function, and iteratively applying selection, crossover, and mutation operations to evolve better solutions.

   Example: Genetic algorithms can be used to optimize the parameters of a neural network for a given task.

3) **Simulated Annealing**: Simulated annealing is a probabilistic optimization technique inspired by the annealing process in metallurgy. It starts with an initial solution and iteratively explores the search space by allowing "worse" solutions to be accepted with a certain probability, which decreases over time (analogous to temperature decreasing in annealing).

   Example: Simulated annealing can be used to solve the traveling salesman problem, where the goal is to find the shortest possible route that visits a given set of cities and returns to the origin city.

4) **Pattern Search**: Pattern search methods do not use derivative information and instead rely on exploring the search space based on a set of search directions or patterns. These methods iteratively sample points in the neighborhood of the current solution and update the search direction based on the results.

   Example: Pattern search methods can be used to optimize the layout of components on a circuit board to minimize the total length of connections.

Non-gradient optimization techniques are particularly useful in problems where the objective function is not smooth, discontinuous, or has a complex, non-convex structure. They can also be used when the gradient information is noisy or expensive to compute.

# 3.27 Introduction to Least Squares Optimization

Least squares optimization is a method used to find the best-fitting curve to a set of data points by minimizing the sum of the squares of the differences between the observed and predicted values. It is commonly used in regression analysis to estimate the parameters of a model that best describes the relationship between the independent and dependent variables.
