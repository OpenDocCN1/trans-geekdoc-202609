# 4. Standardization and evaluation criteria

Feature (ABP, ECG, PPG) and label (ICP) waveforms were independently normalized for the prediction tasks. Standardization using z-score and scaling (subtracting the mean and dividing by the deviation of the waveform) was applied before splitting the data into training and testing set. Preclusions were then cleaned into a clinically interpretable ICP using the method.

Different loss functions were used when optimizing model, and it was determined that the log hyperbolic cosine (logcosh) is the best function for observing the rate and scale of loss decrease. We used logcosh of the difference between the true and predicted values (Equation (1)). The logcosh loss function is a smooth approximation of the mean absolute error (MAE) loss function, making it easy to optimize through gradient descent methods. It is known to work well with other loss functions such as MAE [49–51]. MAE and mean squared error (RMSE) were also metrics used to report model performance (Equation 2) and

(33)).

```
Logcosh (t) = \sum_{t=1}^{T} \log(cosh(p_t - t_t))
```

Equation (2). Mean Average Error Function.

```
MAE = \frac{1}{n} \sum_{i=1}^{n} |p_i - t_i|
```

Equation (3). Mean Squared Error Function.

```
RMSE = \frac{1}{n} \sum_{i=1}^{n} (p_i - t_i)^2
```

# 4.5. Single-patient analysis

The first experiments evaluated the performance of the six models for each of the 10 patients in the study. The goal of this experiment was to ensure that each model could predict the true ICP waveforms from the simplest context: one patient. The comparison of models was performed by splitting the data into sets 60/10/30 for training/validation/test. The mean and median metrics for training and testing datasets were reported for each model with the standard deviation. Using this information, we selected the top model(s) to run a multi-patient analysis. Additional follow-up analysis was performed to understand the strengths and weaknesses of each model and trends in error and prediction.
