# 4.8. Clinical error analysis prediction

To improve the accuracy of predictions for individuals, an error analysis was conducted to identify the factors contributing to the variance of loss across the test dataset. The investigated potential correlations between loss and various factors, including pressure reactivity index (Prx), mean ICP, ICP signal value, ICP amplitude, and complexity of features in a reduced dimension. We explored these relationships to understand the data and to improve the development of models for predicting ICP in individual patients and across patients.

Prediction error was calculated by computing the Pearson correlation between the predicted and actual ICP. For example, of predicting ICP error, we computed the Pearson correlation between ABP and intracranial pressure (ICP) within a sliding window in the test dataset. We hypothesized that a higher ABP would be associated with lower prediction error, given the greater degree of correlation between ABP and ICP. Next, we investigated the correlation between ICP signal value and prediction loss. The Pearson correlation was computed between the prediction loss and the ICP signal value. The same general procedure was conducted to test the correlation between ICP pulse amplitude and prediction loss. For example of features influenced error, all three input waveforms were reduced into a two-dimensional space using the Uniform Manifold Approximation and Projection (UMAP) library.
