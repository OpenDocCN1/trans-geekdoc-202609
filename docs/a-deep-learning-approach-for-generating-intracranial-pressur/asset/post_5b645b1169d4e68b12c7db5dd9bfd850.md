## 4.2. Determining length for prediction task

To ensure that the prediction task was as real-time as possible, a window size of 10 s was used dynamic windowing (DTW) to analyze information drop-off when 10 s compared to windows for the ICP wavelet (Table 2). We tested different window adjustments for each extracranial wavelet and ICP in a pairwise manner. We found that the correlation of DTW scores of each extracranial wavelet with respect to ICP for adjacent windows showed that expected 10 s window was sufficient as the drop-off in DTW correlation between windows was not significant, supporting the use of the (10-s) windows (Table 2).¹

## 4.3. Model selection and architecture

The goal of this study is to predict the entire ICP wavelet (125 Hz) from ABP, EEG, and PPG waveforms (125 Hz). Given that this is a multivariate time series prediction problem, we developed models that fit this architecture and have been used in several similar problems for space-time-based predictions (Fig. 3):

- 1 Simple Recurrent Neural Network (RNN) [32].
- 2 Gated Recurrent Unit (GRU) [34–38].
- 3) Short-Term Memory (LSTM) network [19, 38–41],
- 4) Temporal Convolutional Networks (TCN) [42–45],
- 5) Volume-Net (VNET) [46],
- 6) Transformer [47, 48, 49]

These six models were chosen for stability. For each individual, we performed a grid search to select optimal parameters including batch size, initial learning rate, number of layers, and number of nodes in layer. The best set of parameters were selected based on a validation set and tested on test set.

## 4. Standardization and evaluation criteria

Feature (ABP, ECG, PPG) and label (ICP) waveforms were independently normalized for the prediction tasks. Standardization using z-score and scaling (subtracting the mean and dividing by the deviation of the waveform) was applied before splitting the data into training and testing set. Preclusions were then cleaned into a clinically interpretable ICP using the method.

Different loss functions were used when optimizing model, and it was determined that the log hyperbolic cosine (logcosh) is the best function for observing the rate and scale of loss decrease. We used logcosh of the difference between the true and predicted values (Equation (1)). The logcosh loss function is a smooth approximation of the mean absolute error (MAE) loss function, making it easy to optimize through gradient descent methods. It is known to work well with other loss functions such as MAE [49–51]. MAE and mean squared error (RMSE) were also metrics used to report model performance (Equation 2) and (33)).

```
Logcosh (t) = \sum_{t=1}^{T} \log(cosh(p_t - t_t))
```

(2). Mean Absolute Error:
```
MAE (t) = \frac{1}{T} \sum_{t=1}^{T} |p_t - t_t|
```

(3). Mean Squared Error:
```
RMSE (t) = \sqrt{\frac{1}{T} \sum_{t=1}^{T} (p_t - t_t)^2}
```
