Consequently, we have within our grasp the means to build a pizza that is three
stores tall and takes years to eat, given that each decorator that we add to the chain
of pizza construction will supplement the existing list of ingredients with its own
additions.

This whole process still relies on a slightly awkward inheritance hierarchy though.
Note that in our last example, the OliveDecorator class extends the PizzaDecora-
tor Base class, which in turn extends the PizzaBase class.

The reasoning behind the inheritance approach is clear. If each decorator must
support the same interface as the object being decorated, putting the decorators
to the same inheritance hierarchy ought to satisfy this requirement. The end result
that a ham-and-olive decorated pizza will satisfy a type hint for a PizzaBase
instance in the same way that a plain old MargheritaPizza will instance.

As far as the client code is concerned, a decorated pizza will behave in exactly the
same way as an undecated one in terms of properties and method availability
precisely because both types share the same common ancestor.

This is unacceptable though. Unacceptable to developers with PHP Brilliance on their
minds. Why? Because the abstract PizzaBase is there to define a new data type, a
pizza. Constructing an instance of the MargheritaPizza is simply a case of using the
keyword. A different set of rules comes into play for constructing instances from
the “decorator” branch of the family tree.

On top of this we have the hard-coded dependencies cropping up again. Each
decorator class has a hard coded dependency on the abstract decorator, which is
it should be of course, the abstract decorator itself has a hard-coded dependency
of the abstract ‘PizzaBase class.

Consequently, any changes to the ultimate parent in this familial hierarchy ripple
not just the genuine child classes of the PizzaBase abstract, but also through
tierarchy of decorators too. This might be desirable of course, but then again it
might not. With adverse changes, the threat to our precious time is not merely
doubled by having two abstract bases to inherit from. It’s actually squared.
