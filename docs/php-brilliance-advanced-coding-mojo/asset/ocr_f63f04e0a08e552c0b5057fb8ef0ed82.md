# What has Composer got to do with namespaces?

Quite a lot, as it turns. With the ever increasing popularity and burgeoning use of Composer as the dependency manager of choice within the PHP universe, it becomes harder and harder to ignore the manner in which it promotes the use of the PSR-0 and most recently the PSR-4 standard for autoloaders. I won’t go into those standards here since they are explored in greater detail later on the book. Suffice to say here that the stringent requirements as set down in the standard actually make it easier for us poor developers to impose some sort of coherent order on our application’s codebase. This applies both to the code itself and to how it’s set out on the file system that holds it.
