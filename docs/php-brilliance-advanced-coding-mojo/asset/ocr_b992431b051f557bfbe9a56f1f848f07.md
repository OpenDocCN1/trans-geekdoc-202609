Expressing good traits.

Nevertheless, we are still in the chapter on traits and we are still in the middle of considering how the precedence hierarchy affects the successful (or otherwise) importation of a trait's methods. Since we have arrived at the trait level, we are now need to consider the possibility of two traits providing identically named methods.

Consider the following example.

```
<?php
trait LoggingTrait
{
    private $loggingAdapter;

    public function getAdapter()
{
        return $this->loggingAdapter;
    }
}
```

```
trait SmsTrait
{
    private $smsAdapter;

    public function getAdapter()
{
        return $this->smsAdapter;
    }

```

Here we have two independently defined traits that both provide the identically namedAdapter() method. If we then turn our attention to the consuming class, we can start to consider what might happen if we tried to import both of these traits.
