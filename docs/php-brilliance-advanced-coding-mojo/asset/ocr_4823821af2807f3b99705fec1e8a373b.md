# Ad Hoc Polymorphism

Ad hoc polymorphism relies on the ability of a language to support method overloading, thereby allowing the developer to code up two or more versions of the same method within the same class. This fits nicely with the “Same name, different logic” idea. The requirements here for this to work are that the developer should provide multiple methods that all share the same name but provides for varying method signatures through requiring different numbers and types of input parameters. In this way the developer is leaving the method selection to the program’s execution environment.
