
然而，`doFoo()` 方法包含了“: Foo”的返回类型提示。在实践中，这意味着 `doFoo()` 方法的具体实现必须返回此后实现了 `Foo` 接口的对象。这本身对 PHP 代码来说具有重大意义。

结论是？返回类型提示是实现非常健壮、类型安全的应用代码迈出的非常积极的一步。点赞。
