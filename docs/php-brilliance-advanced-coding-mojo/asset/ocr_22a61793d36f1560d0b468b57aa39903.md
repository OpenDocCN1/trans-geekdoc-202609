# Finding Closure.

```
<?php
class SecretValue
{
    private $secret = 'nobody-knows';
}

$shhh = new SecretValue();
```

Our exceptionally limited interface here ought to protecting the value of the $secret property quite adequately. In other words, there’s no way to get to it from the outside. Without the appropriate methods being put into place, there should be no way to read from or write to that property.

However, by the power of the bindTo() method, we can pop it out simply by binding a closure containing a reference to $this. Like, here, this.

```
$closure = function() {
    return $this->secret;
}
```

So far, nothing startling. Other than the reference to $this inside the function, it’s very much like the examples that we’ve examining previous. But when you get to the binding part, it’s a different matter.

```
$boundClosure = $closure->bindTo($shhh, $shhh);
echo $boundClosure(); // Output: "nobody-knows"
```

The bindTo() method accepts two parameters. The first parameter is the object that the closure should be bound to. The second parameter is optional and when provided, identifies the new scope inside of which the closure should operate. When we assign the same object as the new scope parameter, we are effectively attaching the closure to the object as if it were a method of that object.

This is despite the fact that the $boundClosure is created outside the class itself.
