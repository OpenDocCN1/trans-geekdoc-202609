```
class User {
    private $username;
    private $email;
    private $balance;
    public function __construct($username, $email, $balance) {
        $this->username = $username;
        $this->email = $email;
        $this->balance = $balance;
    }
}
$u = new User('joe', 'joe@example.com', 12.95);
```

```
// No longer can we do this...
echo $u->username;
```

Ok, now we’re starting to look a little better. With the code above, it should be apparent that the username, email and balance properties are protected against any external influences. The class as it stands isn’t exactly usable in this state since we no longer have any way to access those values but no matter what our team mates to do for the application, as long as they’re not editing this class, there’s no way to willfully or accidentally change these properties at run time once the instance has created.
