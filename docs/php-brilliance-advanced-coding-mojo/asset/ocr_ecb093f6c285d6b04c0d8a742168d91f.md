In actual fact, employing abstraction and inheritance as a mechanism for code reuse is a commonly recognised code smell. This is what frameworks do to your project when they ask you to extend from what is effectively a library of useful functions. They make your code smell.

Do bear in mind that we're no longer thinking of abstraction as a means of reusing existing code and avoiding duplication. We're going to see in the upcoming chapters how we can create chunks of code that embody reusability, yet still allows us to stop polluting our parent classes.
