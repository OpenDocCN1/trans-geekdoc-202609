# Finding Closure.

Once we've bound the closure to an object with the optional scope parameter included, the content of the closure - that is, the logic we've provided - behaves like an unnamed method *inside* the target object itself. We can trigger unnamed method by invoking the closure from the outside.

That trigger was pulled on the last line of the previous code block, `echo bound-Closure();` is how we caused the function's internal logic (effectively just return `$this->secret;`) to pop that theoretically inaccessible private property right out for

Of course, it can work the other way too, which is why I introduced this section with the notion of being able to brutally savage private properties.

```
$closure = function($newValue) {
  $this->secret = $newValue;
}
```

```
$boundClosure = $closure->bindTo($shhh, $shhh);
```

```
$boundClosure('Not very secret afterall!');');
```

Writing new values to an object's private properties is terribly easy to achieve with these things. On the one hand, it's a rather natty little technique for extracting the data out of objects without having to clutter their interface in order to do so. On the other hand, it's a rather sneaky technique and terribly difficult to debug. As a result, it's not an activity that we want to engage in without having a bloody good reason to do so. A reason compelling that it makes the ensuing loss of valuable pub time objects worthwhile.
