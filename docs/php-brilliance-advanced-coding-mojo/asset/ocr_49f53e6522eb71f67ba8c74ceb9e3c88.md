# class OrderModel

```
{
    private $db;
    public function __construct(Database $db)
{
        $this->db = $db;
    }
}
```

There. Done.

The OrderModel has been fixed in precisely the same way that we saw way back in Part One where our Car class was injected with an EngineAbstract instance. Now our test suites can inject a fake database instance when it comes to testing this class avoiding having to drag an actual, live database connection around us.

What we have covered though is precisely how our OrderModel is going to be given that database connection in the actual application itself. That sort of thing requires the application of “backwards to be sent back to the browser.
