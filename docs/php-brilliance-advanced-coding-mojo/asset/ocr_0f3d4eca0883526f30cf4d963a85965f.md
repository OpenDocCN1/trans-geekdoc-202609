# Borrowing third party code by extension

Which brings us nicely to our next consideration. Sometimes we are forced into the Inheritance Abuse trap, pitched headfirst down the rabbit hole of hierarchies, tumbled into terrains unseen with our hands tied behind our backs. Before I get too melodramatic, the situation that I’m referring to is the one where we have unplanned hierarchies thrust upon. Unplanned in the sense that the authors of the original code are not directly connected to the project that we are working on.

I’m talking about the use of third party libraries, components and frameworks. The concept is to be lauded of course. One of the most fantastic aspects of the open source software movement is simply because awesome code can be created and curated by large numbers of clever people, and code reviewed, audited and sanity checked by very many people. This in turn leads to some robust packages of reusable code to cater for almost every conceivable use case. Remember, reusable code is good. If nothing else, it saves us reinventing the wheel over and over again.

Situations arise where we are all encouraged to adopt Inheritance Abuse as the right to do things. Whether it’s company policy or merely the CTO’s personal preference, we might find others tied to a particular library or framework. In a commercial setting, it’s often not possible to take the time to play and explore with the various offerings that are out there. The business needs, needs to get the product out there, to shorten the development time, to assemble a team of developers who are familiar with the application’s ecosystem. If the boss tells us we’re building with Symfony, reaching the point of shipping code comes sooner because there are lot more people out there already familiar with the Symfony way of doing things. Conversely, the company that insists on its own homemade framework also needs to allow new hires a certain amount of non-productive time in order to become familiar with the code environment that they’re intended to work in.
