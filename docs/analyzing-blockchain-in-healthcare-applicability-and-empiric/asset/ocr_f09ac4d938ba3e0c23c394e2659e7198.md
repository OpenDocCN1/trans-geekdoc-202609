# # Future implementations

The future implementation of medical device in blockchain includes various perspectives such as scalability, Machine, and Deep Learning implementation, Backend-as-a-Service, and so on. The following are their brief advantages:

# ## Scalability

As a first step, the issues posed by blockchain technology must be addressed. Scalability is the primary issue with blockchain-enabled devices. The present state of blockchain scalability is appalling. Blockchain solutions can only manage a small fraction of the transactions per second (tps) that other systems can. For example, millions of people rely on the VISA payment system at all hours of the day and night. The capacity of this system is 2,000 tps. Whereas, only 7 tps can be handled by Bitcoin. The enormous volume of data included in medical records is a significant problem for blockchain storage.

Massive transactions may be handled in the IoMT system offered by blockchain by boosting its throughput.

# ## Machine learning/Deep learning and IoMT

There is a vast quantity of data that IoMT gathers. The difficulty occurs in collecting usable information from the data gathered.

It is possible to collect significant and useful information from the IoMT device, such as analyzing the data and identifying system issues. The variety of IoMT data, on the other hand, creates difficulties for data analysis. This can be solved by the developments in the Machine Learning (ML) approach to deep learning.

# ## Blockchain IoMT and the Cloud /Backend-as-a-Service

Data security is a crucial issue when delivering data through networks. When IoMT apps rely on a centralized cloud, there is a security problem. IoMT data that has been stored in cloud storage may be able to be authenticated and authorized using blockchain and AI.

To secure data, federated learning algorithms may also be used to develop a method of storing data outside of a cloud server. The data gathered at edge nodes may be used to train AI models through these techniques. There are IoT gateways where these nodes may be discovered in an approximation to the user.
