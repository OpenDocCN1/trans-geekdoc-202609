# Finality

There can only be one true record in a blockchain. All transactions in the network are recorded in the same place on a single ledger. It’s a one-stop shop for anyone interested in finding out who owns something or analyzing a specific transaction.

# Consensus

There must be agreement among all parties involved in a transaction for it to be acknowledged and recorded in the blockchain. The general feeling is that way.
