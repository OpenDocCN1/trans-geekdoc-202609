# Privacy and security

Most patients are worried about the privacy and security of their medical records, and as a result, some people withhold information from their doctors. Highly secure information can be stored in a blockchain. Care must be taken while granting anyone access to your medical records. Standard auditing has been around for as long as maintaining data integrity has. The blockchain provides data integrity, anonymity, secure storage, and reduced likelihood of data infringement.

As a final point, the “disseminated nature of blockchain technology reduces the possibility of a single point of failure in the system”. This chapter provides an overview of blockchain (BC) technology, which can be used to improve current healthcare security. Distributed ledgers have been extensively studied as a potential answer to healthcare security issues, leading to increasingly stringent and sophisticated security protocols. Using blockchains to store sensitive and private data in a storage server environment is a well-known feature of the technology. Because the data in blockchain systems are digitally signed, only the respective private keys need to be safeguarded.
