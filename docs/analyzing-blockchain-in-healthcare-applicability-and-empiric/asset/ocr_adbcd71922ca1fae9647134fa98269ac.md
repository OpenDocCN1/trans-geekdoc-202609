# # Synopsis of chapter

Blockchain is a disseminated archive network that constantly enhances new entries and never modifies them without widespread agreement. A cryptographic hash that links each data block with freshly added information block records determines the value of a Blockchain hash. Healthcare organizations and providers may be able to manage information exchange using blockchain technology. When it comes to healthcare systems, which are typically disjointed, interoperability is a problem. Blockchain has been proposed as an appealing option.

Many studies recommend implementing blockchain-based technologies to manage medical data securely in the healthcare industry. Data processing is prevented from taking place in any centralized location thanks to the distributed blockchain ledger architecture, making it transparent and responsible to all network users.

This decentralized system strengthens and secures system by preventing a single attack. This helps reducing the time medical practitioners spend monitoring and caring for the patient and goes a long way to save resources for the facility. By maintaining their health records on a blockchain, the patient will be able to monitor where their information is going.

Though not feasible, “a healthcare data recordkeeping system entirely based on blockchain technology is theoretically possible.” The bridge concept of having a blockchain-based system coexists with the present healthcare data infrastructure
