# ## Auditability

There is a record of adequate information about the transactions to lead to any verification of the transactions and their validity. Bitcoin blockchain holds data about user balances based on the **Unspent Transaction Output (UTXO)** model: Any transaction must make a reference to some previously unspent transactions. When the latest data is entered into the ledger, the status of the referred unexpended transactions changes from unspendable to spendable. As a result, transactions may be easily verified and traced.

# ## Consensus

A consensus technique, once again, allows each member of a group to make and support a decision that benefits all members. Consensus is needed to ensure that the blockchain is just and equal. Bitcoin’s original method, known as **Proof of Work (PoW)**, requires solving a complicated mathematical challenge that, once solved, can be easily replicated in the remainder of the network’s nodes. While PoW is a highly valuable consensus technique, it requires a significant amount of computational power (hardware) to run in a reasonable length of time, making it challenging to implement in chains with high transaction rates and short transaction commit times. As a result, a number of consensus algorithms have been devised to reduce the complexity and, as a result, the computational power and time necessary to address these problems using mostly private networks. Consensus procedures are used to ensure that a majority of the network’s participants approve each new block before it is added to the blockchain.
