# Immutability

BC’s immutability indicates that it cannot be changed or tampered with. Transactions are recorded indefinitely in the BCP. Blocks cannot be changed or removed after they’ve been inserted. The difficulty of undoing a transaction once it has been recorded on the blockchain increases as more blocks are added down the line. This makes it possible to keep track of historical events in a precise manner. As a result, the transaction record can be trusted. To remain immutable, BC is designed. Changing a BC block after it has been written is impossible. One of the biggest advantages of blockchain is that it is a system that can be relied upon.
