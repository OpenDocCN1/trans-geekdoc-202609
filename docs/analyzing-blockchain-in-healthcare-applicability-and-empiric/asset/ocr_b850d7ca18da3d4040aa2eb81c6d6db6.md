# Blockchain as an enabling technology

Blockchain technology is a decentralized innovation with distinctive features such as an impenetrable data infrastructure, and the highest levels of built-in, confidential cryptographic software based on the highest security levels. It is an integrated network of peer-to-peer computing nodes that are assigned together to efficiently validate financial transactions. The blockchain platform is decentralized to become tamper-resistant and prone to fraud or malpractice due to the cryptographic infrastructure that is used to authenticate network members. Consequently, it can be utilized virtually every industry.

The dictionary defines blockchain as “a chain of blocks linked by a link.” The group of legitimate transactions that can be identified is known as a block structure. Any node which is a part of the network can initiate the transaction, which is subsequently broadcasted to all connected nodes.

After then, using old transactions and cryptographic techniques, a validation process can be carried out. The transactions being carried out will be uploaded to the already existing blockchain once these two basic steps are completed. The number of transactions within each block varies. When Satoshi invented Bitcoin, the block size was around 1 MB. It reached 8 MB in March 2018. The larger the block required to execute more transactions, the faster the processing.
