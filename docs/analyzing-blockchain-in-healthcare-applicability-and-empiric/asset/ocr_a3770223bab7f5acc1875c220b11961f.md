# Types of BC

Since each block of data is encrypted, a blockchain serves as a chronological single source of truth for all the data that it contains. There are public, private, consortium, and hybrid BCs in this system.

# Public BC

The first type of Blockchain Technology was public blockchain. This is where cryptocurrencies such as Bitcoin were born, helping to popularize the concept of Decentralized Ledgers (DL). This type of Blockchain Technology can assist organizations based on transparency and trust, such as social support groups or non-governmental organizations. It eliminates the drawbacks of centralization, such as a lack of security and openness. Anyone can join a public blockchain network and use blockchain ledgers in any way they see fit. Bitcoin and Litecoin are examples of cryptocurrencies that use public blockchains. A public blockchain, which is permissionless and completely decentralized, can be joined by anybody. All nodes can access the blockchain, create new blocks of data, and validate blocks of data in public blockchains. Coin trading and mining have been the primary uses of public BC to date. Anyone with an internet connection can become a node on a public blockchain network, which is non-restrictive and permissionless.
