# Transparency

The integrity of the document is safeguarded by keeping an audit trail of all modifications, and this builds confidence in the asset. Publishing the rules that define the blockchain’s operation is one way to bring about transparency in the cryptocurrency operation. A network of node and BC developers that adhere to the philosophy of open-source code is created by making the blockchain’s source code available to the public. For two persons who do not trust each other to carry out a transaction on the blockchain, they must have faith in the blockchain’s ability to function. An address is required to use the blockchain. This unique identifier is built from the public key and hash functions and has a defined size. An alphanumeric identification number with a maximum of 35 characters is generated for Bitcoin.
