# Blockchain and cloud security

Because of the exponential growth in the quantity of data, the capacity of conventional storage devices is no longer sufficient to fulfill the requirements of modern life. In this respect, the Cloud Storage Systems, abbreviated as CSS, has been upgraded to accommodate more significant data. Block-based Cloud Storage Systems (BCSSs), Object-based Cloud Storage Systems, and File-based Cloud Storage Systems are the three categories that makeup CSS. Each category is differentiated from the others based on the kind of data that is stored. The least expensive and most easily scalable of these Cloud Storage Systems are the Basic Cloud Storage Services (BCSSs), which is why they are now the most often used. Because the data is kept in a block structure inside the BCSS’s structure, the resources are comprised of several tiny block spaces. When a user transfers a data file to a BCSS, the systems first divide the file into segments and then convert each of those segments into property blocks.

# Enabling wireless technologies for the Internet of Medical Things

It’s possible to create an IoT system by integrating sensors and devices into a cloud-based ecosystem and connecting them through high-speed links between the modules. All of the information gathered by these gadgets and sensors is transferred straight to the cloud, where it may be stored indefinitely. Data is cleansed and then analyzed for further information. The data has to be visualized, analyzed, processed, and managed with the help of additional software, tools, and apps.
