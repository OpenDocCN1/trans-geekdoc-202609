## Immutability

BC’s immutability indicates that it cannot be changed or tampered with. Transactions are recorded indefinitely in the BC. Blocks cannot be changed or removed after they’ve been inserted. The difficulty of undoing a transaction once it has been recorded on the blockchain increases as more blocks are added down the line. This makes it possible to keep track of historical events in a precise manner. As a result, the transaction record can be trusted. To remain immutable, BC is designed. Changing a BC block after it has been written is impossible. One of the biggest advantages of blockchain is that it is a system that can be relied upon. People’s ability to place their faith in the immutability and ease of verification of these credentials is critical to their widespread adoption and use. Trust is essential in many social and economic situations involving uncertainty and dependency. For these reasons, it is impossible for data recorded in the blockchain to be corrupted:

- Because of the immutability of the blockchain, data saved on it can never be altered or revoked.
- Blocks are used to store data in the blockchain. Nodes verify these blocks, and as a result, the entire network accepts them.
- This means that a single node cannot affect the entire network by modifying a single copy of data.
- Each block of data is hashed and cryptographically secure. The hash value of each block is used to identify it, as is the hash value of the previous block.
- Block data that is altered, alters the hash value as well, and since each subsequent block contains information from blocks before it, this hash no longer corresponds to any previous blocks.
- Data on a blockchain is immutable because of the distributed nature and cryptography used to secure it.
- Only nodes and the blockchain can change or remove a transaction once it has been recorded in a block and added to the database.
