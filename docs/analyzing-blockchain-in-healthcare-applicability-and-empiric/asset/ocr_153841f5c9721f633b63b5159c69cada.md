# # Decentralization

As with traditional centralized transaction systems, the central trusted agency (for example, the Central Bank) must validate each transaction, which invariably leads to high costs and performance bottlenecks at the main servers. In contrast to the centralized option, blockchain eliminates the need for a third party. Consensus techniques in the blockchain maintain data consistency on a distributed network.

# # Persistency

Honest miners will not accept faulty transactions because they can be swiftly validated. Once a transaction has been recorded in the blockchain, it is nearly hard to remove or reverse it. Invalid transactions could be spotted instantly in blocks. Because of the ledger’s decentralized design and use of cryptographic algorithms, the data saved in the chain can be retained indefinitely and modified without detection.

# # Anonymity

It is possible for each user to engage with the blockchain anonymously by using a created address. Due to the inherent limitations of the blockchain, anonymity cannot be guaranteed to the fullest extent. Industrial trash may have intellectual property concerns and many households may be concerned about privacy if their waste is made public, for example. Although it may not always make sense to store this data on a blockchain, the trade-offs between privacy and the benefits of tracking and incentivizing sustainable waste management deserve further exploration.

In addition, blockchains can be encrypted so that only the parties involved in a transaction can see it, and auditors can access them so that they can track and monitor the flow of resources and waste. But the capacity to incentivize as discussed previously would be limited to mandatory auditing. Pseudonymization or anonymization, as suitable, is delivered by cryptographic functions so that the true uniqueness of the contributors in the BC is not recognized. This is made possible through the use of public-private key cryptography.

# # Security

A public ledger and built-in security mechanisms have made BC a popular choice in a wide range of industries. Blockchain Technology cannot function without cryptography. As a result, data saved in the blockchain and data exchanged between nodes of the network are secure. An operational blockchain requires a set of legitimate and up-to-date asymmetries to be used in order to function on this platform. The asymmetric key format used by different BC is not the same. All transactions in a blockchain are signed by the private key of the issuer.
