# Chapter 2 • Network Topologies

There are two basic network role configurations, as follows:

+   * Client/server: Describes a network that uses one dedicated server and client computers. Novel NetWare, for example, was the server OS for a client/server network that possessed virtually no client capabilities. It had a rudimentary character-based interface and could not run client applications. Client computers ran requests to the server.
* Peer-to-peer: Describes a network on which the computers are capable of functioning as both clients and servers. Today's OSs, such as Windows and Unix/Linux, include both server and client capabilities. On a network that consists only of Windows workstations, for example, any computer can function as a server for the other computers and can also run client applications.
Even a computer running a Windows Server operating system has full client capabilities.

# SERVICE-RELATED ENTRY POINTS

While it is possible for a LAN or an internet to operate independently from all outside services, most networks have connections with third-party providers. Nearly all networks today have a connection to an Internet service provider (ISP), but businesses often have additional connections, such as those to telephone carriers and WAN service providers.

These connections to outside services require an entry point, a physical interface where the client's internal equipment meets the service provider. This is often referred to as a demarcation point (or demarc) because it specifies the place where the client's responsibility for the connection ends and the provider's responsibility begins. Any technical issues outside the demarc are the provider's responsibility; for issues inside the network, the client is responsible.

The demarcation point takes the form of a network interface device (NID), by containing the connection—electrical or optical—between the two networks. In its most basic form, an NID is a physical layer device. However, for some connections, additional equipment is needed. For example, a leased line requires a channel service unit (CSU) and a data service unit (DSU), usually packaged in one device called CSU/DSU. In some cases, the service provider might choose to install an NID with additional capabilities called a smart-jack. A smart jack might have to amplify or decode signals, and it usually includes various types of diagnostics, such as a switchable loopback function and alarm notification capabilities. These diagnostics enable the service provider to monitor the connection remotely and perform rudimentary tests without having to send a technician to the site.
