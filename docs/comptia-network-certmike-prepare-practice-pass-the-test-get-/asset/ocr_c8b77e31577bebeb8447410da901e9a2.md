# Practice Question 1

Ralph is building a new network for a client and has installed a DHCP server with a scope containing an entire /24 subnet: 254 addresses. There are to be 100 workstations in the office, and Ralph has figured the 254 addresses will be enough to accommodate plus the users' mobile phones and other Wi-Fi devices.

Some time later, Ralph begins receiving complaints from his client that sometimes cannot connect to the network. Ralph examines the DHCP server and notices that the scope, at that moment, had only two available leases. He concludes that the scope has been exhausted at times, preventing any more users from connecting to the network. When some of the existing leases expire, more addresses become available. Ralph's client explains that his business gets a lot of visitors who use the company Wi-Fi on their phones, which helps to explain the address shortage.

Ralph wants to avoid adding more addresses to the network. What can he do to relieve the occasional shortages on his client's network?

+   A. Install a second DHCP server.
B. Create a second scope on the DHCP server.
C. Decrease the lease period for the scope.
D. Increase the lease period for the scope.
