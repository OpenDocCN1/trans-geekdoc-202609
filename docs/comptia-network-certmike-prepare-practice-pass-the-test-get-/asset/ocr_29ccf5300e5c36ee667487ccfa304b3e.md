# Traceroute/Tracert

The path that a network packet takes to its destination is its route. The route consists of hops, which are individual trips the packet takes from router to router. Internet missions have routes with 20 or more hops between the source and the destination.

The traceroute tool on Unix/Linux and the Tracerert program on Windows does display a list of the hops on the route to a specified destination. The tools do this by sending a series of ICMP Echo Request messages with successively larger values in the IP header to Live. This causes them to fail at each hop and return error messages to the source. The error messages contain the IP address of the router at each hop, which the Windows tracer command lists in a display like the following:
