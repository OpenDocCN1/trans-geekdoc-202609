# BEST PRACTICES

In a security context, network hardening refers to settings or practices that increase the security of the network in specific ways. There are many hardening techniques that administrators use to add protection to various elements of the network. Some of them are so basic that they should be automatic, as changing default passwords, whereas others require more consideration and planning. The following sections describe some of the best practices in network hardening—that is, the techniques that are most commonly employed by enterprise network administrators.
