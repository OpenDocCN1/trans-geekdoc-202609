# ETHERNET BASICS

Ethernet is one of the first local area networking (LAN) protocols to be released commercially in 1980, and it still persists today as the primary data link layer (layer 2) protocol for netted networks. The term Ethernet is actually a misnomer; the original standard for the network was called Ethernet, but the current standards are published by the IEEE as part of the 802.3 working group. Therefore, the Ethernet networks built today are actually IEEE 802.3 networks.
