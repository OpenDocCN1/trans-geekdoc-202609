# CONSIDERATIONS

Troubleshooters are often faced with problems that might have multiple causes, and it sometimes can be difficult to know where to start. When that is the case, there are several elements that troubleshooters should consider first, because they are the areas where many common problems originate.

# Device Configuration Review

Whatever the symptoms of the problem, starting with the configuration of the device experiencing the issue is usually a good idea. Depending on the nature of the problem, troubleshooters should consider checking the network adapter's TCP/IP configuration
