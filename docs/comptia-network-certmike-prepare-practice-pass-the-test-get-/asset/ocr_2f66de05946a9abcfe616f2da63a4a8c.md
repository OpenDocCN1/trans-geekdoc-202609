# IP Addressing
Objective 1.4: Given
a scenario, configure
a subnet and use
appropriate IP
addressing schemes.

This chapter examines the Internet Protocol (IP) addresses devices on a TCP/IP network use to specify the sources and destinations of their network traffic. This is a fundamental concept in computer networking that is always covered in the Network+ exam and that is also a basic skill needed for network support and troubleshooting.
 this chapter, you'll learn everything you need to know about Network+ Objective 1.4, including the following topics:

+   - Public vs. private
- IPv4 vs. IPv6
- IPv4 subnetting
- IPv6 concepts
- Virtual IP (VIP)
- Subinterfaces
