

# 常见协议

IT 人员通常需要作为雇佣条件签署各种协议，并可能参与与客户、供应商或合作伙伴的协议谈判。其中一些协议包括：

**保密协议 (NDA)** 员工有时会涉及公司的内部专利信息，如果这些信息被泄露，可能会对公司造成损害。出于这个原因，许多公司员工入职流程的一部分是签署保密协议，以限制员工分享公司信息的权利。NDA 通常会规定协议的期限，该期限可能远长于员工离开公司的时间，并规定违反协议的惩罚措施。

**服务水平协议 (SLA)** 在服务提供商与客户之间的合同中，SLA 规定了提供商保证的运行时间。SLA 通常以百分比形式表示，被称为“几个 9”（the nines），因为该协议通常接近或超过 99%。例如，“四个 9” SLA 保证服务的可用时间占总时间的 99.99%，这允许提供商在违反约定的条款之前有不足一小时的停机时间。“六个 9” SLA 保证 99.9999% 的可用性，提供商每年仅有 31 秒的停机时间。SLA 还规定了提供商违约的惩罚措施。

**谅解备录 (MOU)** 有时称为*意向书*（letter of intent），MOU 在不宜签署正式合同的情况下规定了双方之间协议的条款。然而，MOU 的条款可能具有法律约束力，特别是当双方已经存在正式合同时。

# CERTMIKE 考试范例

- 组织良好的 IT 部门从规划开始。计划最终会发展为策略，并使用记录的程序实施策略。计划和程序文档规范了网络所经历的变化，规定了在发生严重事故或灾难时该做什么，并定义了网络设备的运行生命周期。
- 许多组织使用 IT 策略来增强网络安全。员工通常必须遵守密码策略（定义了用户如何以及何时更改密码）、接受使用策略（规定了员工如何利用网络及其服务）、BYOD 策略（自带设备策略，定义了员工如何使用自己的智能手机）以及远程访问策略（规定了对移动用户的限制）。
- IT 人员通过维护图表和报告库来记录公司网络的所有方面，包括逻辑和物理网络图、平面图、布线图、机架图以及 MDF/IDF 文档。

# 练习题 1

Ralph 为一个拥有大型以太网的新客户担任 IT 外包。网络电缆是几年前由外部承包商安装的，墙面板和配线架上的某些纸标签已开始脱落。由于 Ralph 在某些情况下不知道跳接线连接到哪个配线架端口，他的故障排除工作受到了严重阻碍。

以下 Ralph 确定哪些墙面板和配线架端口连接的最佳方法是：

A. 打电电缆安装承包商，询问他们是否记得哪些端口对应哪些墙面板。
B. 向未识别的墙面板插入信号发生器，使用寻路器测试每个配线架端口，直到听到指示正确端口的信号声。对每个需要标记的端口重复此操作。
C. 参考安装时由布线承包商提供的布线图。
D. 使用电缆测试仪定位与每个面板端口相关的配线架端口。

# 练习题 2

Alice 被要求制定公司范围内的密码策略建议，以防止最近报告的滥用行为，包括密码共享、重复使用和过于简单的密码。她一直在考虑各种密码策略，并缩小了策略要求的列表。以下哪项对于防止滥用行为是不必要的？

A. 唯一密码
B. 最短长度
C. 频繁更改
D. 共享密码

# 练习题 1 解析

A. 是错误的，因为承包商可能不记得几年前的端口分配。
B 是对的，因为信号发生器和寻路器是追踪墙内电缆连接的标准工具。
C. 是错误的，因为原始图表可能已经过时，或者无法反映当前的物理布线。
D. 是错误的，因为电缆测试仪用于测试电缆的性能，而不是追踪其物理路径。

# 练习题 2 解析

A. 是错误的，因为唯一密码可以防止共享。
B  是错误的，因为最小长度有助于防止过于简单的密码。
C. 是错误的，因为频繁更改可以防止重复使用旧密码。
D 是对的，因为共享密码正是该策略试图防止的。

# 负载均衡

负载均衡是一种高可用性技术，其中有多个服务器执行相同的任务，并有一种机制在它们之间分配流量。这防止了任何服务器被请求淹没。

最常见的负载均衡场景之一是托管网站的服务器。有多个 Web 服务器集群，每个服务器都托管网站的功能副本。负载均衡器充当服务器池的网关。这种安排允许管理员向集群中添加服务器或将其移除以进行维护。即使某个服务器发生故障，负载均衡器也可以将流量重新分配到剩余服务器。

负载均衡机制可以是软件或硬件产品，并以各种方式分配流量。例如，某些负载均衡器使用轮询算法（round-robin），通过向每个服务器轮流发送请求来分配传入的请求。其他监控池中的服务器并将传入的请求发送到活动客户端最少的服务器。

# 多路径

多路径——也称为多路 I/O 或 MPIO——通常与存储区域网络 (SAN) 相关的容错机制。SAN 可以提供灵活且可扩展的存储基础设施，但它们也增加了故障点。当服务器通过 SAN 连接到存储器时，中间的电缆、交换机和机箱可能会故障。

为了提供容错和高可用性，管理员通常在服务器和存储设备之间设计冗余路径，这样如果某条路径故障，其他路径继续运行。要为 SAN 实现多路径，服务器需要两个网络接口适配器，每个适配器通过电缆连接到不同的交换机。交换机机连接到驱动列，驱动列也应该具有冗余的网络接口。

通过这种安排，服务器可以承受网络适配器、电缆或交换机的故障。

# NIC 聚合

网络接口卡（NIC）聚合——也称为 NIC 绑定（bonding）是将两个网络接口适配器相结合的技术，以合并它们的带宽或提供冗余。
