# DHCP

Every device on a TCP/IP network needs an IP address, the task of configuring them manually and individually—called static assignment—is time-consuming and difficult for administrators. Dynamic Host Configuration Protocol (DHCP) is a combination of a service and a protocol that enables clients to request IP address assignments from a DHCP server. The server assigns each client a unique address from a pool—along with other TCP/IP configuration settings, called scope options, such as subnet masks and default gateway addresses.
