
# Chapter 2 · Network Topologies

Wide Area Network (WAN) A point-to-point link between two remote locations, typically provided by a third-party carrier. WANs are generally slower than LANs, but they can span longer distances. A WAN link can connect a single user to a remote LAN or connect two LANs, enabling users at each site to access resources at the other site.

Metropolitan Area Network (MAN) A collection of computers in a larger geographic area than a LAN, such as a neighborhood, district, or city. A MAN is essentially a collection of LANs connected together using WAN technology, such as fiber-optic links, to form an interconnect.

Personal Area Network (PAN) A collection of devices, such as smartphones, tablets, and laptops, that are in close proximity and usually belonging to a single person. A PAN is typically wireless, connecting the devices using a short-range medium such as infrared or Bluetooth, but it can also use cable connections, such as Universal Serial Bus (USB).

Campus Area Network (CAN) Larger than a LAN, but smaller than a MAN or WAN, which is a collection of LANs connected together using WAN links to service a school, enterprise, housing, or government campus. Unlike MANs or WANs, which typically rely on third-party service providers for their WAN connections, the networking equipment is usually owned by the campus tenant.

Storage Area Network (SAN) A collection of storage devices, such as disk arrays or network attached (SAN) units, connected to a network that provides servers with either direct block-level access or filesystem to the devices. The servers can access the storage as though it was installed locally. High-end SANs are typically fiber-optic networks dedicated to storage traffic, with block-level storage devices running a specialized protocol as Fibre Channel. However, there are lower-cost alternatives, such as iSI, which enables storage traffic to coexist with TCP/IP traffic on a standard Ethernet network.

Software-Defined Wide Area Network (SDWAN) A type of wide area network in which the hardware providing the WAN connectivity is separated from links, that controls the traffic. This enables the network to combine various WAN technologies and dynamically route traffic by selecting the link that is most appropriate for the data being transmitted and the most efficient, based on current network conditions.

concept is similar to that of software-defined networking (SDN), which separates the network control function from the network forwarding function. Instead of both functions performed by individual routers, in SDN the routers still do the packet forwarding, but the control of the routing for the entire network is located in a centralized control unit.

**Multiprot Label Switching (MPLS)** A packet routing technique that applies labels to packets and routes them based solely on the path information in the label, rather than using the packet's destination address. MPLS network adds a 32-bit MPLS header to each packet, making it possible to route the traffic without consulting the data link and network headers. MPLS can therefore handle multiple protocols, including Frame Relay and Asynchronous Transfer Mode (ATM), as well as IP and Ethernet. Its functionality is referred to as a layer 2 protocol.

**Multipoint Generic Routing Encapsulation (mGRE)** Generic Routing Encapsulation (GRE) is a tunneling protocol that encapsulates network layer data and transmits it over an established point-to-point link, such as a virtual private network (VPN). Multipoint Generic Routing Encapsulation (mGRE) expands on that by dynamically creating new tunnels between points as needed. This eliminates the need for administrators to create individual tunnel mappings between sites.

# NETWORK ROLES

The roles of the computers on a network can vary depending on the operating systems (OSs) that are running and the hardware used to construct them. Network communication frequently involves two roles: the server and the client. A server is a computer that provides services to other computers. A *client* is a computer that generates requests for services and sends them to servers.

For example, a server listens for incoming requests and responds to them by supplying web content. Client computers running a web browser generate requests when a user types a web address or clicks a hyperlink.

There are two basic role configurations, as follows:

- Client/server: Describes a network that uses one dedicated server and client. NetWare, for example, was the server OS for a client/server network that possessed virtually no client capabilities. It had a character-based interface and could not run client applications.
- Peer-to-peer: Describes a network on which the computers are capable of functioning as both clients and servers. Today's OSs, such as Windows and Linux, include both server and client capabilities. On a network that consists only of Windows workstations, for example, any computer can function as a server. Even a computer running Windows operating system has full client capabilities.

# SERVICE-RELATED ENTRY POINTS

While it is possible for a LAN or internet to operate independently from all outside services, most networks have connections with third-party providers. Nearly all networks today have a connection to an Internet service provider (ISP), but businesses often have additional connections, such as those to telephone carriers and WAN service providers.

These connections to outside services require an entry point, a physical interface where the client's internal equipment meets the service provider. This is often referred to as a demarcation point (demarc) because it specifies the place where the client's responsibility ends and the provider's responsibility begins. Any technical issues outside the demarc are the provider's responsibility; for issues inside the network, the client is responsible.

The demarcation point takes the form of a network interface device (NID), by containing the connection—electrical or optical—between the two networks. In its most basic form, an NID is a physical layer device. However, for some connections, additional equipment is needed. For example, a leased line requires a channel service unit (CSU) and a data service unit (DSU), usually packaged in one device called CSU/DSU. In some cases, the service provider might choose to install an NID with additional capabilities called a smart-jack. A smart jack might have to amplify or decode signals, and it usually includes various types of diagnostics, such as a switchable loopback function and alarm notification capabilities. These diagnostics enable the service provider to monitor the connection remotely and perform rudimentary tests without having to send a technician to the site.
