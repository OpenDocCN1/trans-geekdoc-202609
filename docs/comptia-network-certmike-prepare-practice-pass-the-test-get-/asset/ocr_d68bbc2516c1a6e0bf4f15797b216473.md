Virtualization server administrators can create and configure vSwitches as needed, even creating vSwitches that are shared by multiple virtualization servers. The vNICs in the virtual machines connect to a vSwitch, which creates a virtual network internal to the computer. The VMs can all communicate with each other by sending traffic through the vSwitch.
For this, virtual network to communicate with the physical network outside, the vSwitch must connect to the physical network interface adapter in the computer. The physical adapter has a connection to a physical switch, which provides the virtualization server—and all the virtual machines on it—with access to the physical network.

# # Network Function Virtualization (NFV)

Network function virtualization (NFV) is a type of network architecture in which specific working devices are implemented in a logical form called virtualized network function (VNF). VNFs can provide the functionality of firewalls, load balancers, intrusion detection systems (IDS), and other devices. Administrators can then deploy the VNFs as needed around the enterprise using standard hypervisor-based virtualization servers.

# # PROVIDER LINES

Most networks have a link to an ISP, providing users with access to the Internet. There are several technologies that a network can use for this access. The selection of an appropriate connection type is a decision based on cost, transmission speed, synchronicity, and availability. Most used ISP links are as follows:

**Cable** Most cable television providers can supply Internet access as well as residential as business customers. In most cases, the Internet access is asymmetrical, meaning that the downstream stream (from the provider to the customer) is faster than the upstream speed. However, some providers have business-oriented services with more upstream bandwidth.

**Digital Subscriber Line (DSL)** Asymmetric digital subscriber line (ADSL) is a telecommunications technology that splits the bandwidth of a standard wide area carrier line and dedicates part of that to network data, leaving the voice service intact. Because ADSL is asymmetric, downstream traffic is much faster than upstream. Primarily intended for residential or SOHO (small office, home office) Internet connections, ADSL is less popular than other types of provider links. However, it is the only alternative for some customers. For business customers, carriers might provide other DSL technologies with symmetrical speed and greater bandwidth, as a high-rate digital subscriber line (HDL).

**Satellite** Uses a dish installed by a satellite ISP at the client's location to access a communications satellite and connect to the Internet through it. There are two types of satellite service. In the *one-way service*, the customer receives downstream traffic through the satellite at high speed, whereas upstream traffic uses a slower land-based connection.
