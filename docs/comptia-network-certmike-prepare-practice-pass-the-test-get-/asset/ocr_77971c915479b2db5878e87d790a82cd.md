# BANDWIDTH MANAGEMENT

Routers are network layer (layer 3) devices. The layer primarily responsible for the end-to-end communication between source and destination systems, the network layer is the perfect place to implement other network technologies. One of these is bandwidth management, which refers to mechanisms for controlling the allocation of bandwidth to specific types of traffic.

Networks carry different types of traffic with different transmission requirements. For example, file transfers must be bit-perfect, but they can tolerate a delay and some retransmitted packets. Web traffic can also tolerate delays and a few frames lost. Steaming audio and video can buffer their traffic and tolerate a few dropped frames caused by lost or corrupted packets. However, applications as Voice over IP (VoIP) and ISCI work in real time. Transmission delays and lost bits can result in calls being dropped or corrupted. # Traffic Shaping

Traffic shaping is a technique for delaying network traffic—usually in a buffer—to achieve an agreed-upon transmission rate. The technique can be applied to all traffic or to generate specified applications. For example, Internet service providers can use traffic shaping to limit the bandwidth used by peer-to-peer file applications, allowing other types of traffic to proceed without limits. In other cases, service providers can use traffic shaping to ensure that their clients receive the bandwidth specified in their service level agreements. Enterprise administrators also limit the bandwidth they receive from their owners, to avoid data rates that can incur additional charges.

Traffic shaping tools—allow administrators to monitor the traffic on their networks, to determine who is using bandwidth, at what time, and for what purpose. With that information, administrators can decide what limits need to be imposed and create rules to implement them. Traffic shaping can work by regulating either the bandwidth used to transmit data or the time during which the transmission occurs. For example, to prevent a 1 Gbps interface from exceeding a transmission speed of 500 Mbps, a router can transmit at its normal speed for half the time and buffer the outgoing data for the other half.

# Quality of Service (QoS)

When a network becomes congested with traffic, there are two possible solutions: increase the bandwidth or use the existing bandwidth more. Quality of Service (QoS) is a means of doing the latter, by prioritizing network traffic so that applications can always have the bandwidth they require available to them. To use QoS, network administrators must evaluate the types of traffic carried by the network, create categories for them, and establish priorities among the categories.
