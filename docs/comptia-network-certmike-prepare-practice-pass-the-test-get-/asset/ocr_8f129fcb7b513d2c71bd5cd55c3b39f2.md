# VLANs

As noted earlier, switches create a separate collision domain for each pair of connected devices, eliminating the collisions and the media access control problems that occur on hub-based networks. however a network connected with switches is still one big broadcast-domain. On a large network with many switches, the propagation of broadcast messages to all the switches and generates a huge amount of traffic throughout the network.

It is possible, however, to segment a switch into multiple broadcast domains by creating virtual local networks (VLANs). This also makes it possible to secure a group of hosts by adding to a VLAN that isolates them from the other VLANs on the network.

By default, switches that support VLANs have a default VLAN, typically called VLAN1. All of the switch's ports frame them by default, resulting in a single broadcast domain. Administrators can then create additional VLANs on the switches, calling them by the VLAN name plus, and add ports to the VLANs as needed. Each new VLAN becomes a separate broadcast domain.

VLANs are virtual, but they are functionally the same as if they were separate physical networks. With physical VLANs, the only way for VLANs to communicate with each other is through routing. The routing can be virtual as well, which is how multilayer switches with routing capabilities built into them work.

# Trunking

A VLAN can have ports from any switch in the network in it, as long as the switches are connected in such a way that the ports in a VLAN can communicate with each other. To make this possible, each switch must have a port dedicated to inter-switch communication called a trunk port. The trunk ports in the switches exchange all traffic, regardless of the VLAN it belongs. The other ports—called access ports—carry only the traffic for the VLANs to which they are assigned.

Trunk ports work with traffic from all of network's VLANs at once, so switches have a means of identifying the VLAN for each packet. This is 802.1Q tagging. IEEE 802.1Q is a standard that defines the format of a 4-byte field that adds to the Ethernet header of each frame they transmit using the trunk port. This field contains a 12-bit VLAN identifier value, which means the network can support up to 4,094 (2¹²-1) VLANs.

Only trunk traffic includes an 802.1Q field in each packet. When a switch receives incoming traffic that is destined for a host in the same VLAN and connected to the switch, it forwards the packets directly to the host using its access port. However, if the destination is in the VLAN but physically connected to another switch, the sending switch adds 802.1Q field to the packets and sends them out to other switches through its trunk port. The switch to the destination host is connected receives the packets over its trunk port, removes the 802.1Q tags, and then forwards the packets to the destination host using its access port.
