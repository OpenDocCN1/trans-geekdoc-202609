# show config

The show running-config command on many routers and switches displays the config-uration in the device's memory. To display the configuration stored in the device's nonvolatile memory, use the command show startup-config. The output of these commands, listing that follows, takes the form of a batch file, a series of commands that an administrator could execute on the device interface.

```
enable
config terminal
card 2
type en40portG
no shutdown
ib sm subnet-prefix fe:80:00:00:00:00:00:00 priority 0
interface gateway 2
ip address 192.168.1.1 255.255.255.0
interface ethernet 2/1
ip address 192.168.4.1 255.255.255.0
interface ethernet 2/2
ip address 192.168.3.1 255.255.255.0
arp ib 192.168.2.2 gid fe:80:00:00:00:00:00:00:02:c9:00:13:68:c3
qp 2/0
arp ib 192.168.2.3 gid fe:80:00:00:00:00:00:00:02:c9:00:00:16:a
f:d3 qpn 2/0
```
