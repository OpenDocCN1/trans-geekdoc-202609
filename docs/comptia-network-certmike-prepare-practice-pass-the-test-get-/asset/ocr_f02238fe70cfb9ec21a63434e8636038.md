# IP Scanner

An IP scanner is a device similar to a port scanner, except that it sends messages to a range of IP addresses and listens for replies. This enables technicians to determine which addresses are in use. However, some scanners use ICMP Echo Request messages as the ping tool, which might be filtered out by firewalls, rendering the scanner ineffective.

# COMMAND-LINE TOOLS

Most operating systems include a collection of simple network configuration and troubleshooting tools that run from a CLI. Some tools, such as ping, function pretty much the same way on all platforms. In other cases, they perform the same tasks on different platforms or have different names, such as traceroute and most. Of the most commonly used tools of this type are described in this section.

# Ping

Ping is a simple tool that sends Echo Request messages to a specified hostname or IP address and listens for replies from the target. The messages use the Internet Control Protocol (ICMP), and are command-line parameters that allow the user to customize the messages.
A successful ping consisting of requests and replies indicates that the target system and its TCP/IP interface are up and running. However, many system administrators allow their firewalls to blocking incoming Echo Request traffic because it can conceivably be used for denial-of-service (DoS) attacks. Therefore, a failed ping test does not necessarily mean that the target system is functioning.
