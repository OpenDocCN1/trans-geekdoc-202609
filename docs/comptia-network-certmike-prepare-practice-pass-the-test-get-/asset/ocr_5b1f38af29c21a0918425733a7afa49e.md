# Routing Loops

A routing loop occurs when two routers have contradictory information in their routing tables. Each of the two routers has an entry for a particular destination network in its routing table. however, the Next Hop field in each router contains the address of the other router, so packets bounce back and forth between the routers until their Time to Live (TTL) values reach zero and the packets are discarded.

The traceroute (tracer+) command can detect the presence of a routing loop in the following. The problem will require modifications to the routing tables, either manually or through some adjustment of the routing protocols.

# Rogue DHCP Server

As explained in Chapter 6, "Network Services,Dynamic Host Configuration Protocol (DHCP) servers provide clients with IP addresses and other TCP/IP configuration settings. A rogue DHCP server is an unauthorized server on the network to provide clients with falsified settings. Apart from the denial of service, attackers can use DHCP to point clients to their own DNS server, instead of the authorized. By loading their DNS server with false information, the attackers can direct clients to fraudulent web servers and phishing attacks.

Tracking a rogue DHCP server is possible using the information it supplies to clients. Running the ifconfig /all command on an afflicted Windows system displays the IP address of its DHCP server, as follows:

```
Description . . . . . . . . . . : Intel(R) Dual Band Wireless-AC 8265
Physical Address. . . . . . . . . . : E47-70-B9-42-09-D2
```
