# NetFlow Analyzers

NetFlow is a standard defining tool that gathers information about the traffic processed by a network interface and sends it to a central console for analysis. There are many Net-Flow implementations available, but most are based on a standard monitoring architecture that consists of three elements:

+   * Exporter: Collects information about a device's incoming and outgoing traffic, including IP addresses, ports, and protocols, and forwards it to a collector
* Collector: Receives, collates, and stores traffic data it receives from exporters on the network
* Analyzer: Uses the traffic data supplied by the collector to create reports and visualize network conditions, often using charts and graphs

Many routers and switches include built-in standards-NetFlow exporter support, and console products might combine the collector and analyzer functions into a single application.

# Trivial File Transfer Protocol (TFTP) Server

Unlike the File Transfer Protocol (FTP), the Trivial File Transfer Protocol (TFTP) requires no authentication and does not provide a user interface. TFTP is a server application that provides files to clients on request.

TFTP servers are usually free software and have multiple uses. Workstations that use the Preboot Execution Environment (PXE) to automate their initial setup address from a Dynamic Host Configuration Protocol (DHCP) server and then download a boot loader from a TFTP server. In the same way, administrators often use a TFTP server as a source for router and switch upgrade downloads and for backing network device configurations.
