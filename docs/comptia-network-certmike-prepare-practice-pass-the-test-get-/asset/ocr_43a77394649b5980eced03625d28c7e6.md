# CERTMIKE ESSENTIALS

+   Network troubleshooters often use a variety of software tools to discover information about the network and its performance. Wi-Fi analyzers scan and detect wireless frequencies to display the nearby access points, whereas protocol analyzers capture traffic samples and interpret them. Port scanners and IP scanners display the open ports and IP addresses used on the network. Both of these functions can be incorporated into more elaborate and expensive testing.
Most operating systems equipped with a set of command-line tools, of which network troubleshooters can resolve, or at least, problems. These tools include ping, which confirms that another system is running; traceroute, which lists the routers on the path to a destination; nslookup, which performs DNS resolutions; and route, which displays and modifies routing entries.
