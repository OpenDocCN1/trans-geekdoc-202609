# Distribution/Aggregation Layer

The distribution or aggregation layer functions as a buffer between the core and access switches, with switches that provide intersections with all of the access layer switches. The distribution layer switches are all connected to each other so that if one fails, the others can take up the slack. These switches also have redundant connections to the access layer switches, with each access switch linked to at least two distribution switches. In some cases, the access layer switches are collected into groups pools, along with their designated distribution switches.

The core scares interconnectivity for pure packet forwarding speed. The distribution layer provides interconnectivity by connecting the access layer needs. Smaller networks combine the core and distribution layers into one, creating a two-tiered model called a collapsed architecture. The distribution layer is also services such as packet filtering, intrusion prevention, load balancing, and VLAN routing often. The switches at the distribution layer tend to be multilayer switches, with the connections to the access layer running on layer 2 and the high-speed core connections on layer 3.

# Access/Edge

The access or edge tier is the location of the switches which servers, workstations, printers, wireless access points, network-attached storage (NAS) arrays, and other end-user devices connect. These are typically layer 2 switches, less elaborate than those at the other tiers to keep the end-user cost-per-port relatively low, but often with higher-speed uplink ports for the connections to the distribution layer switches.

Physically, data centers typically consist of rack-mounted devices. One common design calls for each rack to have one or more switches in it, to which the devices in that rack are connected. This is called top-of-rack switching, and it tends to create a better organized data center layout while minimizing cable lengths.

> EXAM TIP Network+ exam objectives provide alternative names for the distribution and access tiers, but all three are often referenced using other names. Candidates for the exam should be careful to acknowledge all of these terms when researching this topic.
