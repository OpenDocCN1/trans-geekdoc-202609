# IP Addresses

Every device on a TCP/IP network must have a unique IP address. Administrators can conceivably assign an address to device manually, often referred to as a static address, but it is more common to use an automated addressing mechanism, such as the Dynamic Host Configuration Protocol (DHCP). When a computer on a TCP/IP network has no IP address assigned to it, most operating systems use a mechanism called Automatic IP Addressing (APIPA), which generates a non-routable address on the 162.254.0.0/16 network that enables the system to communicate with the local network.

To communicate on the Internet, a device must use an IP address registered with the Internet Assigned Numbers Authority (IANA) through an official registry, usually provided by a service provider (ISP). The registrar assigns a network address to an applicant, and the applicant is responsible for creating subsets out of it and assigning a unique address to each device.

# IPv4 Subnetting

The most complicated aspect of IPv4 addressing is the division between the network identifier and the host identifier in an address is not always in the same place. This is to provide support for networks of different sizes. The more bits assigned to the host identifier, the greater the number of unique IP addresses the administrators can create.
