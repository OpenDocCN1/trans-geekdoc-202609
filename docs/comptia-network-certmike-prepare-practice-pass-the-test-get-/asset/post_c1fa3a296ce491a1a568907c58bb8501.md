## Bandwidth Speed Tester

Many are familiar with web-based Internet speed testing tools that work by performing downloads and uploads to a server belonging to the user's service provider (ISP). By measuring the amount of data sent and received in a specific amount of time, the tool can display the speed of the Internet connection, downstream and upstream.

There are also bandwidth speed testing tools that IT troubleshooters can use to measure the throughput of an internal network connection. The software tool includes both a client and end server, which when installed exchange traffic in the same way as that. The benefit of a tool like this is that it enables technicians to quantify the speed of the network and compare it to readings taken earlier or when users report that the network is slow, it is possible to determine objectively if this is true.

## Port Scanner

A port scanner is a software that sends a series of query messages to a specified server and listens for responses. The messages contain queries targeted at each of the server's ports, and the responses indicate which of the targeted ports are open or blocked by a firewall. except required by its applications, and a port scanner is a convenient method for testing. A port scanner is also a quick and easy way to determine if an application associated with a particular port is functioning.

## iPerf

iPerf is a client/server application that can measure the actual throughput achievable on a particular network connection. The tool is worth mentioning because it is open source and has been ported to many platforms, including Windows, mobile operating systems, and various Linux and Unix distributions. This provides a highly versatile test platform for troubleshooters.

After installing the iPerf client and server, the user selects the protocols and ports the tool will use to generate the traffic it sends to the server. The client floods the connection with as much traffic as can handle, and the server calculates its throughput.

## NetFlow Analyzers

NetFlow is a standard defining tool that gathers information about the traffic processed by a network interface and sends it to a central console for analysis. There are many Net-Flow implementations available, but most are based on a standard monitoring architecture that consists of three elements:

- Exporter: Collects information about a device's incoming and outgoing traffic, including IP addresses, ports, and protocols, and forwards it to a collector
- Collector: Receives, collates, and stores traffic data it receives from exporters on the network
- Analyzer: Uses the traffic data supplied by the collector to create reports and visualize network conditions, often using charts and graphs

Many routers and switches include built-in standards-NetFlow exporter support, and console products might combine the collector and analyzer functions into a single application.

## Trivial File Transfer Protocol (TFTP) Server

Unlike the File Transfer Protocol (FTP), the Trivial File Transfer Protocol (TFTP) requires no authentication and does not provide a user interface. TFTP is a server application that provides files to clients on request.

TFTP servers are usually free software and have multiple uses. Workstations that use the Preboot Execution Environment (PXE) to automate their initial setup address from a Dynamic Host Configuration Protocol (DHCP) server and then download a boot loader from a TFTP server. In the same way, administrators often use a TFTP server as a source for router and switch upgrade downloads and for backing network device configurations.

## Terminal Emulator

In the days of mainframes, all of a computer's processors, memory, and storage were located in one place, and users accessed the computer with a terminal, which could be located elsewhere. A terminal is an input/output device with no intelligence of its own. Today, there are still some network devices, especially switches and routers, that need a terminal to access their command-line interfaces (CLIs), so administrators use a program called a terminal emulator, which enables a computer or other device to function as a simple terminal. The terminal emulator connects to the device either by a direct cable connection or a network protocol, such as Telnet, or more commonly, Secure Shell (SSH).

## IP Scanner

An IP scanner is a device similar to a port scanner, except that it sends messages to a range of IP addresses and listens for replies. This enables technicians to determine which addresses are in use. However, some scanners use ICMP Echo Request messages as the ping tool, which might be filtered out by firewalls, rendering the scanner ineffective.
