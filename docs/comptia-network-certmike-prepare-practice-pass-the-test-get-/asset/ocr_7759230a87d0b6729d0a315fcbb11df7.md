# CERTMIKE EXAM ESSENTIALS

+   - Network troubleshooting can often be an instinctive process, but in an enterprise environment, it should proceed methodically, according to a documented series of steps.

+   - The troubleshooting method defined in the Network+ objectives consists of the following steps: identify the problem, hypothesize a theory of probable cause, test the theory, design a plan of action to solve the problem, implement the plan, verify the results, and document the entire troubleshooting process.
