# Voice VLANs

As a general rule, an access port on a switch can only be associated with one VLAN. However, with most networking rules, there is an exception. On some switches, it is possible to create a VLAN that allows administrators to prioritize VoIP traffic over standard data traffic, leaving the default VLAN in place to accommodate the data traffic. This makes it possible to power a VoIP phone and the computer with a single switch port.

Plugging the phone into the switch port and the computer into the phone's auxiliary jack connects both to the network. The packets carrying VoIP traffic are tagged with a 4-byte field in the Ethernet header, similar to 802.1Q tagging. Ordinary data packets are left untagged. VoIP phones can scan packets for the tags. They process the tagged packets as voice traffic and forward the untagged packets to the computer.

# EXAM TIP

The Network uses the term virtual local area network to refer to regular VLANs and distinguish them from voice VLANs. The term is nonstandard, however, and exam candidates should know that it refers to a normal VLAN.

# Port Configuration Settings

The simplest unmanaged switches, intended for home and small office use, have a row of UTP ports and a power cable. There is nothing to configure. Higher-end managed switches have a variety of settings that administrators can configure, many of which they can set for each port individually.

The administrative interface of a managed switch varies by product and manufacturer. Some switches have a console port, into which it is possible to plug a laptop running a terminal emulation program with a command-line interface. This is called in-band management. Other switches require administrators to access the switch over the network connection. Still other switches include a built-in interface that provides the switch with a graphical configuration interface. These are examples of out-of-band management.

# Duplex

Most switches autodetect the traffic on the network and use full duplex communication by default, which allows hosts to transmit and receive data simultaneously. Older (usually hub-based) networks use half duplex communication, meaning that hosts can transmit or receive data at any one time, but not both.
