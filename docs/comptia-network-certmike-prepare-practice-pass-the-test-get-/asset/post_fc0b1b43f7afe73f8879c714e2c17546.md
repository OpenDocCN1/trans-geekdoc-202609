
# Redundancy and High Availability Concepts

FHRP creates a virtualized router with its own IP and MAC addresses. Using those addresses, all communication with the redundant physical routers goes through the virtual router. Since all of the physical routers are configured to respond to the virtual router's addresses, any one can perform the essential routing functions.

The two most used FHRPs are Virtual Router Redundancy Protocol (VRRP), which is based on an open standard, and Hot Standby Router Protocol (HSRP), which is proprietary. Both work using the active-passive design; they use different names, with one router designated as the primary router (in VRRP) or the active router (in HSRP) and the other as a standby or backup router.

# Other Concepts

High availability technologies involve time measurements for specific events. Some of these time measurements are described next.

# Mean Time To Repair (MTTR)

Mean time to repair (MTTR) is a technical specification indicating the average time—usually in hours—that it takes to repair a specific device, component, or service. MTTR values are typically factored into negotiations for service-level agreements (SLAs) so that the expected repair or replacement times for specific elements do not generate delays in a violation of contract terms.

# Mean Time Between Failure (MTBF)

Mean time between failure (MTBF) is a technical specification typically used to quantify the reliability of hard drives. Calibrated in hours, the MTBF value specifies the average amount of time the disk is expected to operate without a failure. Typical MTBF values reach into the millions, however, should make clear that they are estimated values and not the result of real-time testing.

# Recovery Time Objective (RTO)

Recovery time objective (RTO) is essentially a measurement of how much downtime the organization can tolerate before the business process is restored. Administrators use this value when designing network's fault tolerance and availability. For example, a low RTO value might mean the difference between maintaining a data center at a hot site or a warm site.

# Recovery Point Objective (RPO)

Recovery point objective (RPO) specifies the maximum allowable length of time between a disaster and the last time the data was backed up. Usually measured in hours, RPO determines how often backups should occur. For example, if the data is backed up once per day, then the RPO could conceivably be as long as 24 hours. If the organization determines that RPO must be no more than 12 hours, then backups must occur at least twice a day.

# NETWORK BACKUP/RESTORE

Backups are an essential fault tolerance element of any network. The type of backup medium depends on the amount of data that needs protection and the time available to perform the backups. Traditional medium for backups is magnetic tape, but tape backups are slow. Hard disks are increasingly popular because they are faster and provide random access without searching through tape. Cloud backups provide an offsite storage solution, which might be practical.

While backups are important, high availability plan should also include backups of device configurations. In a disaster situation, routers, switches, and other devices must be installed and configured before any data is restored. This can be a lengthy process that extends the time needed to restore the network to its full functionality. The configuration of device can often be saved as a simple file in the case of router or switch. Many router and switch include some mechanism for backing up the configuration file to removable storage device. In the case of server, network backups can preserve the data, but restoring the data from backup can be problematic. The data preserved in the backup makes it possible to perform a complete restoration without having to reinstall and reconfigure the operating system and the applications.

# EXAM ESSENTIALS

- High availability extends into the data center infrastructure, which must include a properly conditioned power supply, HVAC environmental support, and adequate fire suppression capabilities. Redundant systems can typically operate in active-active mode, in which both devices are always operating and balancing the load, or active-passive mode, in which one device operates while the other remains in a standby state until needed. Redundant data centers can exist in different states depending on the organization's operational requirements and budget. Hot sites are ready for use in minutes, warm sites in days, and cold sites in weeks or months.

# Practice Question 1

Ralph is deploying a new server in his company's data center. The server has redundant power supplies. Ralph wants to make the whole installation as fault tolerant as possible. The building has a backup generator to AC circuit with an automatic failover switch. Ralph plugs both of the server's power supplies into a UPS and plugs the UPS into an AC socket. Using this configuration, which of the following failures can the server tolerate and keep running indefinitely? (Choose all correct answers.)

- A. A power supply failure
- B. A UPS failure
- C. An AC power failure
- D. A generator failure

# Practice Question 2

Alice has been asked to design a network for a new branch office that has redundant Internet connections with the fullest possible fault tolerance. Which of the following elements must Alice incorporate into her design to meet her goal?

- A. Different ISPs
- B. Different WAN connections
- C. Different routers
- D. All of the above

# Practice Question 1 Explanation

A. is correct because if one power supply in the server fails, the other can keep the server running.
B. is incorrect because both supplies are plugged into the UPS. If the UPS should fail, the server will have no power source and will shut down.
C. is correct; in the event of an AC power failure, the UPS can supply battery power until the generator starts up and takes over.
D. is correct; if the generator should fail, the server can continue running as long as the AC power remains online.

Correct Answers: A, C, and D

# Practice Question 2 Explanation

A. is incorrect because although different ISPs provide a degree of fault tolerance, other elements are needed to achieve the full fault tolerance Alice needs to complete her task.
B. is incorrect because while different WAN connections to the ISP provide a degree of fault tolerance, other elements are needed to achieve the full fault tolerance Alice needs to complete her task.
C. is incorrect because using different routers for the connections to the ISP provides a degree of fault tolerance, other elements are needed to achieve the full fault tolerance Alice needs to complete her task.
D. is correct because the full fault tolerance that Alice needs requires redundancy in every part of the Inter-connections, including the routers, the WAN connections, and the ISPs.

Correct Answers: D
