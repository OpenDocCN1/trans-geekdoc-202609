Most UDP transactions consist of a single request message and a single reply, which eliminates the need for those advanced TCP functions. For example, in a typical DNS name resolution transaction, the client sends a single request message to a DNS server using the UDP and IP protocols. If the server receives the request, it transmits a reply, and serves as acknowledgment of the transmission. If the client receives no response to its request, it can simply retransmit it reply. There is no need for separate acknowledgment messages, nor is there a long data sequence to be segmented or any need for flow control.

# Internet Control Message Protocol (ICMP)

Internet Control Message Protocol (ICMP) is a network layer protocol like IP, but it does not carry upper-layer data. Instead, ICMP performs a series of important functions, including the transmission of error messages and diagnostic queries and responses. Unusually, ICMP messages are encapsulated within IP datagrams.\ For example, the well-known ping utility works by transmitting ICMP Echo messages to the designated recipient, which then responds with Echo messages. In the same way, error messages such as Destination Host Unknown appear when a data transmission fails are carried by ICMP.

> EXAM TIP

The original version of ICMP, designed for use with IPv4, is now known as ICMP4. ICMP6 is a new version designed for use with IPv6. The message formats for the two ICMP versions are the same, but ICMP6 includes some new message types that do not exist in ICMP4. Network+ candidates should be prepared to see any of the terms ICMP, ICMP4, and ICMP6 on the exam.
