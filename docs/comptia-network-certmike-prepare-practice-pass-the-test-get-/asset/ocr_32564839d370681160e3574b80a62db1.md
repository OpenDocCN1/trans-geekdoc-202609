DAI, implemented in switches, is a feature that reads the incoming ARP request messages and compares their IP-to-MAC addresses to the binding table created by the DHCP snooping process. The mappings in the binding table are presumed to be correct because they come from trusted DHCP servers. Any ARP mappings that do not agree with those in the binding table are presumed to be fraudulent, and the messages are discarded.

# Control Plane Policing

The control plane in a router or switch carries non-data traffic to and from other routers and switches; it is one of three control planes along with the data plane and the management plane. Control plane policing (CPP or CPP) is a rate limiting feature in some routers and switches that use quality of service (QoS) policies to prevent the control plane from being inundated with irrelevant traffic, such as that produced by denial-of-service (DoS) attacks.

# Private VLANs

Private VLAN is a microsegment within another VLAN, essentially a VLAN within a VLAN. Administrators create local area networks (VLANs) by applying a VLAN designation to a group of switchports on or more switches. When the administrator creates a private VLAN within an existing VLAN, the VLAN becomes the secondary to the existing VLAN primary.

There are two types of private VLANs, as follows:

+   - Isolated: Connected devices can communicate only with a router port, with each other.

+   - Community: Connected devices can communicate with each other, as well as a router port.

Private VLANs are a means of creating microsegments in which selected devices can be isolated with limited communication.

# Disable Unneeded Switchports

Unused switchports, especially those that are connected to wall plates in common areas, should be disabled at the switch. Many administrators omit this for the sake of convenience, but an open wall plate into which anyone can connect a host, switch, or access point is an invitation to attack.
