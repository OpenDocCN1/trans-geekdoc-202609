# DHCP on IPv6

The original DHCP standards call for DHCP client/server communications to use UDP traffic on port 67 for clients and port 68 for servers, which remain the ports used for IPv4 address assignments. This original DHCP version is now commonly known as DHCP4. There are also standards defining the use of DHCP on IPv6 networks, referred to as DHCPv6. IPv6 networks do not support broadcast transmissions, so uses a multicast address for the initial requests sent by clients. DHCPv6 also uses different ports for its traffic: 546 and 547 for the client and server, respectively. The basic architecture is the same in DHCPv6 as it is in IPv4, but the message types and their formats are changed.

All IPv6 devices use stateless address autoconfiguration (SAC) to assign them a link address, as described in Chapter 4, "IP Addressing,"so many of them have no need for DHCP addresses, but DHCPv6 provides a stateful alternative to the stateless self-assignment process.

# Creating a Scope

Although the term does not appear in the DHCP standards, a scope is a pool of IP addresses that a DHCP administrator has designated for assignment to clients. Usually, the scope is a range of addresses, which might include some or all of the addresses available on the local subnet. If there are addresses within a given range that the administrator does not want assigned, it is possible to create an exclusion range within the scope.

For example, the administrator might create a scope containing all of the addresses for a subnet, such as 192.168.54.1/24 to 192.168.54.255/24. However, if there are servers on the network that already have static address assignments in that range, the administrator can designate 192.168.54.101/24 as an *exclusion range*, so those 10 addresses will never be assigned to DHCP clients.

In addition to IP addresses, a DHCP scope can have scope options defined, which specify the other settings needed by the TCP/IP clients on network, including a subnet mask, a DNS server address, and a default gateway, which specifies the address of a router on the local network. The DHCP standards also support a large set of other options that administrators can configure to be included with IP assignments from a particular scope or server options for all of the server's scopes.

# EXAM TIP

In TCP/IP terminology, the term *gateway* is synonymous with *router*, but it also has other meanings, such as a device that converts data from one format into another. Network+ exam candidates should be conscious of the distinction and be sure which is implied by a particular context.
