# OSI Model

| Number | Layer | Main functions | Protocols |
| --- | --- | --- | --- |
| 4 | Transport | Data segmentation, packet acknowledged, error detection and correction, flow control, port identification | TCP, UDP |
| 3 | Network | Addressing, routing, error detection, protocol identification | IP, IPv4, IPv6, ICMP |
| 2 | Data Link | Framing, media access control, protocol identification | IEEE 802.3 (Ethernet), IEEE 802.11 (Wi-Fi) |
| 1 | Physical | Network interface hardware, binary signaling | Twisted pair, fiber-optic, Wi-Fi |

# EXAM TIP

The layers of the OSI model are numbered from the bottom of the stack to the top. The physical layer at the bottom is designated as layer 1 and the application layer at the top is layer 7. In some references and product documentation, the model layers are referenced by number instead of name.

A protocol is a language that computers use to communicate with each other. Collectively, the processes running on the layers of the model are called the protocol stack. The network medium (whether a copper cable, fiber-optic cable, or wireless) connects to the physical layer at the bottom of the stack, and the signals entering into this layer travel up through the layers of the stack to the top of the stack. In the same way, data being sent down through the layers and out to the network using the connected medium.

This vertical communication between the layers of the protocol stack takes the form of services that the layer above and requests from the layer below. For example, when a client application sends a message, it typically generates a request for the services of the Simple Mail Transfer Protocol (SMTP), running at the application layer. SMTP passes the request down to the next layer, which hands it off to the next layer, and so forth, until reaches the bottom layer and is transmitted over the network.
The server receiving the transmission over the network then begins the same process in reverse, passing the message up the layers of its own protocol stack until it reaches a mail server application on the computer. The protocols running at specific layers of the OSI model have complementary functions that make network communication possible. The protocols at the individual layers of the model can therefore be said to communicate virtually with their counterparts on other systems.
