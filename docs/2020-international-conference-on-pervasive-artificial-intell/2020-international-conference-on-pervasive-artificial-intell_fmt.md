## I. 引言

金融市场有许多机器学习方法。然而，尽管试图预测趋势波动，但根据随机游动理论，历史趋势并非当前趋势。历史高度依赖于预测的准确性。这使得预测变得极其困难。

详细而言，投资组合研究是在有限的环境中编码的。换句话说，可以通过部分选择来训练智能体。如果我们能够解决模型在训练阶段表现良好但在实际中难以解决的生成问题，那么我们的目标是为任何由系统选择的投资组合找到基础交易策略，智能体应该具有优化投资组合的能力。为了实现这一目标，问题就可以解决。然而，训练所有可能的排列是不可能的任务，会消耗大量的时间和计算资源。

因此，本文提供了一种自适应采样来增加投资组合的机会。通过我们的采样策略，可以防止表现不佳的智能体在已经学习过的投资组合上花费过多时间。然后，智能体可以将更多的时间和精力花在不熟悉的领域。

## II. 与投资组合管理相关

马科维茨（Markowitz）提出的现代投资组合理论或均值-方差理论利用数学解决方案来构建在考虑预期收益最大化和给定风险水平下的投资组合 [1]。当方差分析在金融领域被广泛接受时，均值-方差理论包含两个部分：预期收益和与资产风险不同的方差（后者意味着发生或负面结果的数学概率）。对于该理论，投资者只需要考虑收益均值与方差之间的权衡，并在给定风险水平下寻求最大预期收益，以增加调整智能体收益的确定性。然而，均值-方差理论更好是因为它可能精确控制各种资产的未来收益和标准差，在实践中我们已经准确确定了这些方法。此外，这会导致非常不稳定的结果。此外，这项工作依赖于正态假设。

### B. 奖励函数

我们的奖励设计只考虑利润。为了实现奖励最大化，每一步奖励为 `rt`，表示从 `t+1` 时刻到 `t` 时刻的组合价值。智能体的目标策略是选择一系列动作以最大化随时间累积的奖励。在长期组合管理中，我们追求最高的组合价值 `pt`。每一步的即时奖励为 `rt = pt+1 - pt`。

带有折扣因子的长期奖励我们可以确保累积奖励 `R_t`

```
$R(st_t, at_t, ... , st_{t+j1}, at_{t+j1}) = \sum_{i=0}^{j1} \gamma^i r_{t+i} \quad (1)$
```

其中 `$\gamma$` 是折扣因子，考虑到其累积奖励，我们不应该考虑过于遥远的策略获利性，因为那时的利润已经受到了其他决策点的影响。因此，我们利用折扣因子来减少长期因素的影响。

### C. 自适应采样策略

我们的采样策略源于 `Adaboost` 的思想。`Adaboost` 是一种提升（boosting）改进算法。其目标是增加那些容易被第一批分类器纠正的错误的权重，这样每次训练新分类器时，它都会关注难以分类的样本。每个分类器都使用加权投票机制而不是平均投票，并且只有权重较高的分类器才更大。策略由所有分类器组成，这些分类器也被归类为大量样本的一部分。基于，我们将根据每个公司采样权重在不同交易日是否相同来进行后续讨论。

### C. 组合测量

在组合测量方面，本文将使用以下指标来衡量性能。夏普比率定义为：

```
Sharpe = \frac{E[\rho_p - \rho_f]}{\sqrt{Var(\rho_p)}} \quad (2)
```

其中 `$\rho_p$` 是收益，`$\rho_f$` 是无风险利率。夏普比率越高，获得的收益越多。
