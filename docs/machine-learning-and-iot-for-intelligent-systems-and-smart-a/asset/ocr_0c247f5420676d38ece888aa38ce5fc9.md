# ## 12.6.6 NAÏVE BAYES ALGORITHM FOR PREVENTION OF ROAD ACCIDENTS

+   1. Dataset should be scanned.  
2. Each attribute value’s [n, n_c, m, p] probability should be calculated.  
3. The formulae given below should be applied.  
4. The probabilities should be multiplied by p

$P\left[ \begin{array}{c} \text{attribute (ai)} \\ \text{(value of)} \end{array} \big| \text{Subject value } v_j \right] = (n_c + mp)/(n + p)$  
(12.1)

where:  
n = the number of training examples for which $v = v_j$  
nc = number of examples for which $v = v_j$ and a = ai  
p = apriori estimate of p(ai|vj)  
m = the equivalent sample size
