Step 7. Calculate $\mathrm{CD}=\mathrm{CD}_{1}-\mathrm{CD}_{\mathrm{J}}$ (i.e. $<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>0<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>\mathrm{n}$)

Step 8. Update weight $\mathrm{W}^{\prime}=\mathrm{W}+\varepsilon * \mathrm{CD}$

Step 9. Compute error function using sum of squared difference between $\mathrm{v}_{\mathrm{i}}$ in 1 and $\mathrm{v}_{\mathrm{i}}$ in n

Step 10. Repeat the above steps until error is small.

Step 4. Accumulate $\mathrm{CD}_{1}=\mathrm{CD}_{\mathrm{J}}+<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>0$ based on the updated values of visible layer $\mathrm{v}_{\mathrm{i}}$

First, assign the input value to the visible layer $\mathrm{v}_{\mathrm{i}}$ then initialize zero to the matrix values $\mathrm{CD}_{\mathrm{I}}$ and $\mathrm{CD}_{\mathrm{J}}$ which represent the weight values involving the visible layer $\mathrm{v}_{\mathrm{i}}$ and hidden layer $\mathrm{h}_{\mathrm{j}}$. Based on given input values, calculate the reconstruction value. Accumulate the $<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>0$ in $\mathrm{CD}_{\mathrm{I}}$ based on the updated hidden layer value and accumulate the $<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>\mathrm{n}$ in $\mathrm{CD}_{\mathrm{J}}$ based on the updated visible layer value. Calculate the average for $\mathrm{CD}_{\mathrm{I}}$ and $\mathrm{CD}_{\mathrm{J}}$ and find the CD value by subtracting the $\mathrm{CD}_{\mathrm{I}}$ and $\mathrm{CD}_{\mathrm{J}}$ (i.e. $<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>0-<\mathrm{v}_{\mathrm{i}} \mathrm{h}_{\mathrm{j}}>\mathrm{n}$). Now, the product of $\varepsilon$ and CD value is used to update the weight $\mathrm{W}$ and the updated weight is represented in $\mathrm{W}^{\prime}$. Calculate the error function using sum of squared difference between $\mathrm{v}_{\mathrm{i}}$ in 1 and $\mathrm{v}_{\mathrm{i}}$ in n until the error is small. Finally, the updated weight $\mathrm{W}^{\prime}$ is the sentence score for each sentence based on the given feature vector values.
