It consists of the separating plane that separates data into two class or multiclass. It also contains two margin lines that run parallel with hyperplane and maintains some distance to classify the data effectively. The margin lines are separated by maximum distance and each margin line passes through one of the vectors in positive and negative class. These vectors are called support vectors. Linear separable SVM can separate the data points easily by constructing a hyperplane. The data points cannot be easily separated in the case of nonlinear separable SVM.
