
The proposed hybrid model integrates UNet and VGG-19, repeating the process of adding layers until the network achieves a U-shape symmetry. In this architecture, the contracting path depicts the VGG-19 structure, and the model is trained using transfer learning on brain tumor MRI images. The primary objective is to reduce execution time and accelerate dataset training. The architecture of this hybrid model is depicted in Figure 9.1, while the segmentation process using transfer learning is shown in Figure 9.2.

To enhance efficiency in medical image segmentation, the proposed system utilizes a UNet-VGG-19 hybrid. The VGG-19, a fully convolutional network pre-trained on ImageNet for image classification, is applied to the BraTS 2015 database to obtain optimal tumor segmentation results. During semantic segmentation, pixel-level labels and images are input into the pre-trained network to identify new labels through training. The network comprises an encoder, a decoder, and a final classification layer for pixel-level image classification. In brain tumor detection, the system employs the pre-trained VGG-19 via transfer learning, replacing the final layers with new ones to categorize tumors into three classes: Normal-0, LGG-1, and HGG-2.

Training parameters for the pre-trained network are configured as follows: a batch size of 10 images per mini-iteration, and an epoch count ranging from 2 to 8 with a step size of 2. The learning rate is reduced to a lower value to slow down learning in the transferred layers, thereby minimizing parameters and computational time.

## 9.4 EXPERIMENTAL SETUP AND RESULTS

The evaluation of the proposed work utilizes the BraTS 2015 database, which addresses the challenge of segmenting multimodal brain images containing both synthetic and clinical glioma data. The modalities included are T1, T1-weighted contrast-enhanced, T2-weighted, and FLAIR. Annotations from clinical experts are used to generate ground truth data. Figure 9.3 illustrates FLAIR images of HGG with their corresponding ground truth.

The framework specifically uses MRI FLAIR images of HGG, as they best discriminate malignant tissue. Pixel-level analysis determines the relative amounts of normal and malignant brain tissue. The experiments were conducted on a 64-bit operating system with an Intel Core i7 processor (3.4 GHz) and 16GB RAM, using MATLAB. The VGG-19 network was evaluated up to 8 epochs, achieving maximum precision at the 6th epoch.

Classification accuracy is computed as the ratio of exact matches to total computations. In medical imaging, accuracy alone is insufficient to classify patient status; therefore, specificity, sensitivity, and Area Under the Curve (AUC) are also calculated. Specificity and sensitivity distinguish normal from tumor patients, while AUC measures the accuracy of these metrics in identifying normal and abnormal conditions.

The transfer learning model using VGG-19 achieved 99.8% accuracy during training and 96.4% during validation, with a 7:3 data split. The analysis of normal and abnormal classes explores deep features from convolutional layers. Complex features from the deepest layers are analyzed by generating high-accuracy feature maps of tumor cells. By integrating earlier layer features, the deepest convolutional layers construct features to detect tumor areas via activation channels. Feature maps are generated by merging strong activation channels with the original image to highlight tumor portions detected by the CNN model. Figure 9.4 shows the original image and the feature map highlighting the tumor region.

The mean Dice index $D$ is calculated using Equation (9.2) to assess segmentation effectiveness:

$$
\text{Dice Index } (D) = \frac{2TP}{2TP + FP + FN} \quad (9.2)
$$

In Equation (9.2), True-Positive, False-Positive, and False-Negative are represented as TP, FP, and FN, respectively. A value of $D=1$ indicates a perfect match between the segmented tumor image and the annotated ground truth.

## 9.5 DISCUSSION

The proposed model performs brain tumor detection, segmentation, and grading using deep learning approaches, combining CNN, UNet, and transfer learning with a pre-trained VGG-19 network. In the initial stage, MRI brain input images are categorized into normal tissue, low-grade glioma, and high-grade glioma. At epoch 6, the hybrid network achieves 99.8% training accuracy and 96.4% validation accuracy. During the testing phase, the system obtains 99.3% accuracy, 100% specificity, 97.8% sensitivity, and an AUC of 0.99. The average Dice index values are 0.93 for tumor detection and 0.84 for tumor segmentation.
