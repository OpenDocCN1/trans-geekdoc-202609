$A_{a}=\left(\begin{array}{cc} a & 0 \\ 0 & \frac{1}{a^{2}} \end{array}\right)$where $a>0$

Shearlet transform uses anisotropic dilation and orientation to precisely capture the geometric edges. The continuous shearlet transform is represented as

```
$\psi_{a,s,t}\left(x\right)=a^{\frac{-3}{4}}\Psi\left(A^{-1}B^{-1}\left(x-t\right)\right)$
(1.14)
```

```
$SH\psi f\left(a,s,b\right)=<f,\psi_{a,s,t}><a>0,s$
(1.15)
```
