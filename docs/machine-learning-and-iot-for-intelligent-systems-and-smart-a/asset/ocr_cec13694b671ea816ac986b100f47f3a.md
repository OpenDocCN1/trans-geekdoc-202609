# ### 1.2.3.5 Bendlet Transform

Bendlet is a second-order shearlet transform. Bendlets can capture anisotropic features by scaling, translation, shearing, and bending parameters. The second-order shearlets classify the image more precisely compared to what the first-order shearlets do. Bendlet transform supports alpha scaling instead of parabolic scaling. The alpha scaling matrix is given by (Figure 1.7).
