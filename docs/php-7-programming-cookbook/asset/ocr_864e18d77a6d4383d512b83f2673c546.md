# Refining internationalized output

+   1.  First, a series of small methods, starting with one that extracts the internationally
    formatted day based on type. The type determines whether we deliver the full name
    of the day, an abbreviation, or just a single letter, all appropriate for that locale:

```
protected function getDay($type, $cal)
{
    $formatter = $this->getDateFormatter();
    $formatter->setPattern($type);
    return $formatter->format($cal);
}
```

+   2.  Next we need a method that returns an HTML row of day names, calling the newly
    defined `getDay()` method. As mentioned previous, the type dictates the appearance
    of the days:

```
protected function getWeekHeaderRow($type, $cal, $year, $month, $week)
{
    $output = '<tr>';
    $width = (int) (100/7);
    foreach ($week as $day) {
        $cal->set($year, $month, $day());
        $output .= '<th style="vertical-align:top;"'
                  . " width="" . $width . $"">"
                  . $this->getDay($type, $cal) . '</th>';
    }
    $output .= '</tr>' . PHP_EOL;
    return $output;
}
```
