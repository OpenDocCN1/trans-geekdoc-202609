> The tricky bit is this line of code:
$\texttt{result = $this->callbacks[$Callback['key']]($this->results[$k]->item, $Callback['params']);}
Remember, each callback is actually an anonymous class that defines the PHP magic $\texttt{__invoke()}$ method. The arguments supplied are the actual data item to be filtered, and an array of parameters. By running $\texttt{$this->callbacks[$Callback['key']]()}$ we are in fact magically calling $\texttt{__invoke()}$.
