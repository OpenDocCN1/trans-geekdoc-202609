+   We then run the `process()` method, which produces an array of `Result` objects where the `$item` property represents the end result of the filter chain. We then loop through the results, and, if the corresponding `$element` key matches, set the `value` attribute to the filtered value. We also add any messages resulting from the filtering process. When the form is then re-displayed, all `value` attributes will display filtered results:

```
$this->filter->process($this->data);
foreach ($this->filter->getResults() as $key => $result) {
    if (isset($this->elements[$key])) {
        $this->elements[$key]
            ->setAttribute('value', $result->item);
        if (isset($result->messages)
            && count($result->messages)) {
            foreach ($result->messages as $message) {
                $this->elements[$key]->addSingleError($message);
            }
        }
    }
}
```
