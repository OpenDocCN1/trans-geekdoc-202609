As an example, if the wrapper is `div` with an attribute `class="test"` we would produce this pattern: `<div class="test">%s</div>`.  
Our content would then be substituted in place of `%s` by the `sprintf()` function:

protected function getWrapperPattern($wrapper)
{
    $type = $wrapper['type'];
    unset($wrapper['type']);
    $pattern = '<' . $type;
    foreach ($wrapper as $key => $value) {
        $pattern .= ' ' . $key . '="' . $value . '"';
    }
    $pattern .= '>%s</' . $type . '>';
    return $pattern;
}
