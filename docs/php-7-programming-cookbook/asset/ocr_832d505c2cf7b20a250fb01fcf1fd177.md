You will also notice that tags were removed from first_name, and that both last_name and city were truncated.

# There’s more…

The filter_input_array() function takes two arguments: the input source (in the form of a pre-defined constant used to indicate one of the $ * PHP super-globals, that is, $ _ POST), and an array of matching field definitions as keys and filters or validators as values. This function performs not only filtering operations, but validation as well. The flags labeled sanitize are actually filters.
