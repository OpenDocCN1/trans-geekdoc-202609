+   3. Next, we decide what to do with the iteration. One possibility is to mimic the output of the Linux `ls -l -R` command. Notice that we use the `yield` keyword, effectively making this method into a **Generator**, which can then be called from the outside. Each object produced by the directory iteration is an `SPL_FileInfo` object, which can give us useful information on the file. Here is how this method might look:

```
public function ls($pattern = NULL)
{
   $outerIterator = ($pattern
      ? $this->regex($this->rdi, $pattern)
      : $this->rdi;
   foreach($outerIterator as $obj) {
      if ($obj->isDir()) {
         if ($obj->getFileName() == '..') {
            continue;
         }
         $line = $obj->getPath() . PHP_EOL;
   } else {
      $line = sprintf('%4s %1d %4s %4s %10d %12s %-40s' . PHP_EOL,
         substr(sprintf('%o', $obj->getPerms()), -4),
         ($obj->getType() == 'file') ? 1 : 2,
         $obj->getOwner(),
         $obj->getGroup(),
         $obj->getSize(),
         date('M d Y H:i', $obj->getATime()),
         $obj->getFileName());
   }
   yield $line;
}
```
