

# K近邻算法

## K近邻算法简介

要理解K近邻算法，我们首先需要了解最近邻算法。最近邻算法是一种可用于回归和分类任务的算法，但通常用于分类，因为它简单直观。

在训练阶段，最近邻算法仅仅是记住输入和输出的所有数据值。在测试阶段，当提供一个数据点并期望得到类别标签时，它会在其记忆中搜索具有与测试数据点最相似特征的任何数据点，然后返回该相关数据点的标签作为预测结果。最近邻分类器的训练时间非常快，因为它只是存储所有样本。然而，在测试时，其速度较慢，因为它需要搜索所有存储的示例以找到最佳匹配。随着数据集的增加，获得分类预测所花费的时间也会增加。

K近邻算法是最近邻算法的一种修改，其中输入的类别标签由距离它最近的k个示例进行投票决定。也就是说，预测标签将是其邻近代表中多数投票的标签。因此，k值为5意味着，获取待分类输入的五个最相似示例，并根据这五个示例的多数类别标签来选择类别标签。

现在让我们看一个示例图像来加深理解：

![](images/00071.jpeg)

待分类的新示例被放置在向量空间中，当k=1时，选择离它最近的示例的标签作为其标签。在这种情况下，新示例被归类为属于类别1。当k=1时，K近邻算法退化为最近邻算法。

从图中可以看出，当k=3时，我们使用一种称为距离度量的相似性指标选择离新示例最近的3个示例。我们看到有两个近邻示例预测类别为类别2（红色三角形），而剩余的一个示例预测类别为类别1（蓝色正方形）。因此，新数据点的预测类别为类别2，因为它拥有多数票。

用于衡量示例邻近性的距离度量可以是L1或L2距离。L1距离是两点之间差值绝对值的和，公式如下：

L1距离有时被称为曼哈顿距离。

L2是另一种可使用的距离度量。它是两点之间使用直线的欧几里得距离。公式如下：

![<math xmlns="http://www.w3.org/1998/Math/MathML"><msub><mi>d</mi><mn>2</mn></msub><mfenced><mrow><mi>p</mi><mo>,</mo><mi>q</mi></mrow></mfenced><mo>=</mo><msqrt><munderover><mo>&#x2211;</mo><mrow><mi>i</mi><mo>=</mo><mn>1</mn></mrow><mi>n</mi></munderover><msup><mfenced><mrow><msub><mi>q</mi><mi>i</mi></msub><mo>-</mo><msub><mi>P</mi><mi>i</mi></sub></mrow></mfenced><mn>2</mn></msup></msqrt></math>](images/00073.jpeg)

k值为1会正确分类所有训练示例，因为与某点最相似的示例将是它自己。这将是一种次优方法，因为分类器将无法学到任何东西，也就没有能力泛化到未训练过的数据。更好的解决方案是以一种在验证集上表现良好的方式选择k值。验证集通常用于调整超参数k。较高的k值对决策边界有平滑作用，因为异常类别被多数投票模式“吞没”。增加k值通常最初会带来更高的准确率，但在变得过大之前，我们会达到边际效益递减的点，此时准确率下降，验证误差开始上升。

![](images/00074.gif)

k的最优值是验证误差最低的点。

## 如何创建和测试K近邻分类器

现在我们将所学知识应用到一个二分类问题中。我们将使用的数据集是Pima印第安人糖尿病数据库，该数据集来自国家糖尿病、消化和肾脏疾病研究所。该数据集的主要目的是根据对患者进行的诊断测量，预测患者是否患有糖尿病。研究中的患者为女性，具有Pima印第安人血统，且年龄至少21岁。

数据集可在以下网址找到：

[https://www.kaggle.com/uciml/pima-indians-diabetes-database/data](https://www.kaggle.com/uciml/pima-indians-diabetes-database/data)

由于我们处理的是两个互斥的类别，患者要么患有糖尿病，要么没有，这可以建模为二分类任务，为了示例目的，我们将使用K近邻分类器进行分类。

```
import numpy as np
```

```
dataset = pd.read_csv('diabetes.csv')

```

我们需要将列分为特征和标签。

```
features = dataset.drop(['Outcome'], axis=1)
labels = dataset['Outcome']
```

我们将再次将数据集分为训练集和测试集，因为我们想在训练集上训练模型，然后在测试集上评估其性能。

```
from sklearn.model_selection import train_test_split
features_train, features_test, labels_train, labels_test = train_test_split(features, labels, test_size=0.25)
```

`features_train`、`features_test`包含属性，而`labels_train`、`labels_test`分别是训练集和测试集的离散类别标签。我们使用`test_size`为0.25，表示我们想用75%的观测值进行训练，保留剩余25%用于测试。
