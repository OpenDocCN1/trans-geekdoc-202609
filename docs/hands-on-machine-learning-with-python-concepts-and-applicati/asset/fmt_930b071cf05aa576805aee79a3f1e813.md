
# 分类算法概述

一个类或标签可以理解为代表特定数量的类别，因此分类算法的作用是识别样本所适配的类别。如果分类问题的设定包含两个截然不同的类，则为二分类问题。当类别（标签）超过两个时，该学习问题称为多分类，表明观测值可能落入任意 $n$ 个类别中的一个。最后一种分类类型是样本可能属于多个类别（即拥有多个标签）的情况，此时我们面对的是多标签分类任务。

为了更直观地理解分类，请看下图：

![](images/00112.jpeg)

从上图可以看出，有两个特征描述数据 `X1` 和 `X2`。分类任务旨在将数据划分为不同的类别，使存在一个能最好地分离类别的决策边界。本例中有两类——倒闭公司和存活公司，代表公司的数据点只能属于这两个类别之一。显然这是一个二分类示例，因为只有两个类别。

图中另一点值得注意的是类别是线性可分的，即可用一条直线分开。在其他问题中这可能无法实现，但有更稳健的机器学习算法可处理此类情况。

## 多分类

我们必须根据预测类别的数量深入理解分类，因为分类有许多现实应用。为进一步加深直觉，请分析下图：

![](images/00113.jpeg)

数据被投影到二维平面以便可视化。有三个类别，分别用红色方块、蓝色三角形和绿色圆圈表示。还有三条决策边界将数据点分成三个区域，背景投影了类别的颜色。这是一个经典的三类（0, 1, 2）多分类示例，虽有一些误分类点，但数量很少且多出现在决策边界附近。

评估该模型时，我们将使用准确率作为评价指标。模型准确率由分类器预测正确的样本数与误分类样本数之比决定。准确率通常是分类任务的良好指标，但请记住还有精确率和召回率等其他指标，可根据建模意图进行探索。

## 常用分类算法

一些机器学习模型在分类任务上表现优异，下节将深入剖析其中几种。运行分类任务的流程在各模型间相当标准。

首先，我们需要一个包含输入集和对应标签集的数据集。这很重要，因为分类是监督学习任务，我们需要获取观测值的真实类别（地面真值），以最小化模型的误分类误差。因此，要得到一个好模型，我们在样本上训练分类器并通过反馈机制提供真实值，迫使分类器学习并在每次迭代或遍历训练集（epoch）时降低误差率。

用于分类的模型示例包括逻辑回归、决策树、随机森林、K近邻、支持向量机等。我们将以最后两种模型为案例研究来实践分类。

## 支持向量机

支持向量机（Support Vector Machine，简称 SVM），也称支持向量网络，是一种用于分类的流行机器学习算法。SVM 的核心直觉是寻找一个最优超平面，仅利用靠近超平面的数据点将数据分离到正确的类别中。最靠近超平面的数据点称为支持向量。

可能有多个超平面能正确分离类别，但 SVM 算法会选择与支持向量距离（间隔）最大的超平面。选择间隔最宽的超平面的好处在于，这能降低测试时误分类数据点的概率。

![](images/00114.jpeg)

SVM 算法对类别分布中的异常值具有鲁棒性，其工作方式是在寻找具有良好间隔宽度的最佳超平面时忽略异常值。

然而，数据分布并非总是线性可分的。SVM 通过引入基于原始特征的新特征，将表示数据的特征从低维空间转换到高维空间。这一过程通过核函数自动完成。SVM 中的核函数示例包括线性核、多项式核、径向基函数核等。

与其他机器学习模型相比，SVM 有一些优势。它在高维空间中表现尤为强劲，且因仅依赖一部分数据点（支持向量）进行分类，内存消耗较少，效率较高。同时它也很有效，因为我们可以根据手头的数据表示选择不同的核函数。

## 如何创建和测试支持向量机分类器

本节将在 Pima 印第安人糖尿病数据集上使用 SVM 分类器，并将其结果与 K近邻分类器进行比较。

完整代码如下：

```python
# import libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# read dataset from csv file
dataset = pd.read_csv('diabetes.csv')

# create features and labels
features = dataset.drop(['Outcome'], axis=1)
labels = dataset['Outcome']

# split dataset into training set and test set
from sklearn.model_selection import train_test_split
features_train, features_test, labels_train, labels_test = train_test_split(features, labels, test_size=0.25)

# import support vector machine classifier
from sklearn.svm import SVC
classifier = SVC()

# fit data
classifier.fit(features_train, labels_train)

# get predicted class labels
pred = classifier.predict(features_test)

# get accuracy of model on test set
from sklearn.metrics import accuracy_score
accuracy = accuracy_score(labels_test, pred)
print('Accuracy: {}'.format(accuracy))
```

我们得到的准确率为 0.66，比 K近邻分类器的 0.74 要差。有许多超参数可供尝试，例如更改使用的核函数类型。

```python
from sklearn.svm import SVC
classifier = SVC(kernel='linear')
```

当我们使用线性核时，准确率跃升至 0.76。这是机器学习中的一个重要教训：我们往往无法预先知道最佳超参数是什么。因此，我们需要尝试多个值，才能确定表现最好的超参数。
