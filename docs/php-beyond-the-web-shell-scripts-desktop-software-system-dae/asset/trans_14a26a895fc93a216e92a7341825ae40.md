

### Newsgroups

PHP 拥有一组官方新闻组，列出并存档于 [http://news.php.net/](http://news.php.net/)，涵盖广泛的 PHP 主题领域。这些新闻组值得浏览，有时可以对查询获得回复（尽管某些内部列表绝非胆小者所宜）。

### PHP Subredit

reddit.com 上的 PHP “Subredit” 位于 [http://www.reddit.com/r/PHP/](http://www.reddit.com/r/PHP/)，是 PHP 新闻、观点、有用链接和求助请求的集合。虽然通常非常有趣，并且对问题有有用的回复，但这里也偶尔会出现一群网络喷子和不友好/粗鲁的人。

### PHP on Github

有时解决问题的最佳方法是查看其他人编写的类似代码。Github，这个流行的源代码仓库网站，有大量的内容可供翻阅。你可以在 [https://github.com/search](https://github.com/search) 搜索所有代码仓库，并在搜索词中使用修饰符“language:php”将结果缩小到使用我们最喜欢的语言的项目。如果你只是想关注目前流行的 PHP 项目，可以查看 [https://github.com/trending?l=php](https://github.com/trending?l=php) 的 PHP 趋势列表。

### PHP news sites

虽然通常不适合直接求助，但 PHP 新闻网站和邮件列表可以让你了解安全警报、有用且有趣的文章，以及新项目、库和教程的公告，这些可能是你甚至还不知道自己需要的！下面列出了一些更受欢迎的网站。
