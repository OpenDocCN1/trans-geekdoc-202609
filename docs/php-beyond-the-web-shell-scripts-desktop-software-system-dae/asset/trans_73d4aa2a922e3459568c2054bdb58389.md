## 附录 C：帮助来源

即使有像这样优秀的书籍上市，当你在使用 PHP 时遇到棘手的问题，有时仍然需要一些额外的帮助。以下是一些潜在的帮助来源。

### PHP 手册

官方 PHP 手册可以在 [http://php.net/docs.php](http://php.net/docs.php) 在线查阅。手册主要提供了关于 PHP 安装、语法、函数以及众多扩展的相当全面的文档。值得注意的是每个页面底部的用户评论。这些评论通常很有帮助，并提供与页面函数或主题相关的现实世界建议。偶尔评论中会给出一些错误的建议，但通常会在后续评论中得到纠正或提及，因此值得阅读给定页面上的所有评论。

在线手册的一个方便功能是，你可以通过将函数或主题作为 URL 的第一部分来快速查找。例如，如果你不记得 `strripos()` 的参数是什么，可以直接在浏览器中输入 [http://php.net/strripos](http://php.net/strripos)，你将被直接带到相关页面。同样，如果你想快速复习 PHP 如何处理数组，请访问 [http://php.net/array](http://php.net/array)，你将直接进入手册语言/类型部分的数组页面。

如果你不总是有互联网连接，也可以从 [http://www.php.net/download-docs.php](http://www.php.net/download-docs.php) 下载手册副本。它提供 HTML、Unix 风格的 man 页面和 Microsoft 编译的 HTML 手册 (CHM) 格式。

### 官方邮件列表

在 [http://php.net/mailing-lists.php](http://php.net/mailing-lists.php) 上有许多官方邮件列表，涵盖了广泛的主题。值得注意的用于获取帮助的是“常规用户列表”用于常规查询，以及“Windows PHP 用户列表”用于 Windows 特定问题。订阅时要小心，因为一些列表非常繁忙，你每天会收到大量电子邮件。如果你只是想浏览或了解每个列表生成的数量，存档可以在线查阅。

### Stack Overflow

如果你不熟悉它，Stack Overflow ([http://stackoverflow.com](http://stackoverflow.com)) 是一个面向程序员的多产“问答”网站。与一些问答网站不同，你不需要加入或付费即可查看问题的答案，广告数量有限，而且论坛上有数以百万计的已回答问题。这包括大量与 PHP 相关的问题。

所有问题和答案都会“打上标签”以标明其主题，以便你可以找到与你相关的问题。要浏览标记为 PHP 的问题，请访问 [http://stackoverflow.com/questions/tagged/php](http://stackoverflow.com/questions/tagged/php)。你也可以使用网站的搜索功能，要将搜索范围缩小到仅 PHP 相关答案，请在搜索中添加“[tag]”。例如，如果你想搜索关于 `date` 函数的问题，这是一个在英语中常见的单词，也是许多编程语言中常见的函数名，请搜索“[php] date”以仅获取 PHP 特定信息。

在撰写本文时，标记为“php”的问题有 724,633 个，标记为“php”且“command-line”的有 588 个，标记为“php”且“cli”的有 601 个。版主通常非常迅速地关闭重复问题，因此你可以从这些数字中看出有大量相关信息可用。
