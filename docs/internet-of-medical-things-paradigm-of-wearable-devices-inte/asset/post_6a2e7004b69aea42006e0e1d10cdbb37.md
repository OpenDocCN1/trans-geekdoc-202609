# 8.1.1 TABULATING MACHINE

Dating back to the 1800s, the tabulating machine, built by Herman Hollerith, was one of the first devices used for summarizing data. The machine was capable of reading data from punched cards and summarizing the data stored on cards. However, since this machine required data to be punched onto cards, only a limited number of people used the machine. Furthermore, since punched cards are no longer used to store data, these machines are obsolete.

# 8.1.2 MANUAL ANALYSIS

Before the advent of Hadoop and R, developers had to manually run through the data to find patterns and analyse the data. This process was called Manual Analysis. It was one of the best methods for analysing data, since it did not require any special software or hardware for data analysis. However, it had various shortcomings:

- Firstly, the developers had to fetch data from different formats. Fetching data can be a very tricky task when the data is stored on different systems having different formats for storing data.
- Secondly, the data could be inconsistent. It was the task of the developer to go through the data, and find any inconsistencies in the data.
- Thirdly, multiple passes were required to gain full insight into the system which allowed the users to properly analyze data.

# 8.1.3 MATERIAL REQUIREMENT PLANNING SYSTEM

The Material Requirement Planning (MRP) system performed a specific task and proved to be very complex for a novice user to operate. These systems were designed for three main tasks:

- To ensure proper availability of items.
- To maintain the main list of items in the inventory.
- To plan various activities like manufacturing, delivery and purchasing.

Also, they required structured, accurate data to work on which can be time consuming to generate.

# 8.1.5 Excel FILES

Excel provides various features for data analysis like sorting data, data filters, formatting data and many more. In addition to these features, using Excel to represent data graphically is very simple. All of these features make Excel an ideal choice for data analysis. However, Excel has various shortcomings:

- Excel is unable to handle Big Data of petabyte.
- Excel does not support unstructured data like media and image files.
- Excel works with past data and is capable of creating graphs using that data. However, it cannot make future predictions.

# 8.1.6 DATABASES

A database is used to store data in the form of relational tables. Structured queries can be used to extract data from these databases. Features like Functions and Triggers allow the user to attach special functionality to the queries. Despite having all these advantages, databases are unable to properly process Big Data due to the following:

- Databases allow only structured data to be stored and analysed and used for unstructured data.
- Databases are Online Transaction Processing (OLTP) types. Hence, they are designed to store data that is less in volume and is updated regularly. On the other hand, data analysis deals with data which is abundant and updated sparsely.

# 8.2 ADVANCED TECHNIQUES USED FOR MANAGING LARGE AMOUNT OF DATA

# 8.2.1 NoSQL

Using the orthodox Relational Database Management (RDBMS) approach is not considered to be beneficial for the rising amount of data which in turn earns the name of “Big Data”. In relational models, data is organized in well-structured manner, with the variety that is being produced every day, this approach requires some refinement to adapt to variations in the data trends and provide functionality to users accordingly. NoSQL, or Not Only SQL, comes into the picture which can adapt itself to various situations of data, providing extensive scalability and high performance to users.
