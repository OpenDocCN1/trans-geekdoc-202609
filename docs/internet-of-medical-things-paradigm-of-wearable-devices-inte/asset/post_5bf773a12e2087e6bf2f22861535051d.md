- 2. Magnetic Resonance Images (MRI) measures radio frequency signals emitted by hydrogen when it resonates with strong magnetic fields. This technique is very popular because it allows you to capture clear images without having to expose the body to radiation.

- 3. Magnetic Resonance Imaging (fMRI) is a popular MRI application to measure the brain activity. Specifically, the technique detects increases in blood flow in areas of the brain that are activated. In this way, it is possible to know which parts of the brain are involved in each cognitive activity.

- 4. Positron Emission Tomography (PET) uses amounts of radioactive material that the patient must swallow, and which acts as a tracer. The use of substances with biochemical reactions (for example glucose) allows concentrating the radioactive material in certain parts of the body. This technique is very precise and can be used to capture both macroscopic and microscopic images.

- 5. Computed Tomography (CT). It is possible to create a set of virtually scanned images (typically PET or MRI) to obtain a 3D reconstruction of an organ.

- 6. X-ray imaging is one of the oldest and most frequent techniques due to ease of use and the clarity of the captured images. It consists of circulating gamma radiations through the body. Solid structures as bones have a higher absorption rate than liquids. This contrast appears in the image collected on the other side of the emitter.

## 2.4.2 CLASSICAL POSTPROCESSING

Once the images have been captured, different postprocessing techniques are used to enhance them. The most basic ones are:

- 1. Histogram equalization. This technique increases the contrast of an image by redistributing levels.

- 2. Deblurring. We can use standard techniques to increase the clarity of the image, for example.

- 3. Thresholding. This technique converts the gray-level image into a binary one. For instance, it is used to select the value of the image.

- 4. Combination. By combining different images, we can retrieve information. For example, from MRI.

## 2.4.3 SEGMENTATION

This technique aims to label the regions of an image. Specifically, segmentation can be divided into:

- **Region-based segmentation**, which assumes that pixels have similar properties in terms of intensity, color. For instance, it is used in melanoma.

- **Boundary-based segmentation**, which assumes that pixels change abruptly. This is used in security in sensor networks.

## 2.4.4 3D RECONSTRUCTION AND REGISTRATION

Modern CT techniques are able to reconstruct 3D from 2D images. Registration is the process of mapping 3D objects, for instance, ventricle. A well-known difficulty in medicine is that organs are not rigid.

Medical surveillance is becoming a necessary service in healthcare centers. On one hand, it can protect the patient and property. On the other hand, it may be a vulnerability. According to European law, it must be carefully treated.

## 2.4.6 FUTURE TRENDS IN IMAGE PROCESSING

There are several unsolved challenges in medical imaging. The first challenge is that 3D reconstruction is an ill-posed problem. This means that we can get 3D reconstructions from 2D images. To manage this, the so-called regularization techniques aim to limit or minimize the error. A second challenge is the use of medical image, not just to diagnose, but also to accomplish semiautomatic robotic surgery. A third challenge is virtual reality simulation, which facilitates training before conducting real interventions.

## 2.5 CYBERSECURITY: THE NEED FOR SECURITY IN MEDICAL SYSTEMS

It is relatively common for healthcare centers to use a network infrastructure. These devices are connected in both the rooms of the hospital and the homes of patients. From the healthcare center itself, many profiles can be connected to the same network, so it is not easy to do Network Access Control (NAC), and there may be a vulnerability in the service.

However, there are new generation protocols that help protect data in IoT systems; for example, ZigBee. ZigBee is a set of wireless communication protocols aiming to connect applications with a low data rate. It is especially used in Wireless Sensor Networks (WSNs) for healthcare using medical radio bands (ISM band); for example, to sample and reliably monitor devices, home nursing, glucose, oxygen, blood pressure, etc. It also helps create information management and visualization indicators. ZigBee is a simple, economical and energy efficient technology the security systems offered secure in communication, key management, and cryptography through three types of keys to the network (master key, link key, and network key). Its weaknesses are limited in resources within the network, the low calculation capacity and the low memory they offer.
