# Advantages of Hive

+   - Higher level query language
- Less trial-and-error than Pig
- Support of external tables
- Partitioning of data is possible
- Built on top of Hadoop

# Disadvantages of Hive

+   - Real-time processing is not possible
- High latency
- Comparatively slow
- Updating and modification is difficult
