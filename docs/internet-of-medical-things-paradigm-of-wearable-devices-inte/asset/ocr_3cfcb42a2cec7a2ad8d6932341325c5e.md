# 8.2 ADVANCED TECHNIQUES USED FOR MANAGING LARGE AMOUN OF DATA

From a historical point of view, the amount of data was small and it was easy to manage, as it related to health, environment, or population. But, in the present time due to the increasing number of population, data increased automatically. To manage huge amounts of data, Cloud computing techniques came into the picture. Due to the pitfalls of cloud computing, industries (or companies) moved to Big Data techniques. In this section, Big Data techniques will be described in detail.

# 8.2.1 NoSQL

Using the orthodox Relational Database Management System (RDBMS) approach is not considered to be beneficial for the rising amount of data which in turn earns the name of “Big Data”. In relational models, data is organized in well-structured manner, with the variety that is being produced every day, this approach requires some refinement to adjust to variations in the data trends and provide functionality to users accordingly. NoSQL, or Not Only SQL, comes into the picture which can adapt itself to various situations of data, providing extensive scalability and high performance to users. NoSQL databases are unstructured in nature thus eradicating the problem of coping with the variations in data trends. It uses the concept of distributed processing where data is stored across multiple nodes or servers, and results are resulted combining results from all of them.

Using this approach increases the efficiency of computing, reduces time and space complexity, puts less burden on a single system, prevents data loss etc. Cloud technology is used every day to provide extensive functionality to users and also to cut the hardware costs, maintenance costs, etc. Cloud Computing is a powerful and secure mechanism, but with great functionality gets bigger responsibility.
