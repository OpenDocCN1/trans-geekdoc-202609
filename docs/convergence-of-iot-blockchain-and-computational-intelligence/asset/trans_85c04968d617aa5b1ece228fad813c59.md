

# 医疗保健中的处方分析

处方分析依赖于利用机器学习算法，根据计算机程序做出的预测，确定在商业环境中应采取的适当行动 [[5](#chapter10.xhtml#ref10_5)]。处方分析还与预测分析协同工作，后者利用原始数据获取关于近期结果的更好认知 [[6](#chapter10.xhtml#ref10_6)]。处方分析使医疗保健系统决策者能够以最简单的形式获得业务成果，通过为患者或提供者推荐更好的行动方案。他们也可以独立思考，以便对多个“现状”方案进行比较，从而评估选择某一步骤而非另一步骤的影响。医疗保健系统中产生的分析的最后阶段是处方分析。处方分析不同于预测分析，但它不仅仅停留在展示这两种分析之间可能的结果 [[7](#chapter10.xhtml#ref10_7)]，而是继续揭示推荐行动，使医疗服务提供者在商业上或教会层面更加成功，以满足患者需求 [[8](#chapter10.xhtml#ref10_8)]。

处方分析可用于分析明年眼科理赔是否会增加。它将帮助人们决定明年是否应保持最低眼科报销费率不变、增加或降低。它帮助每个人做出更明智的决策。处方分析对于使医疗保健系统组织做好准备以应对未来和不可预见的事件也很有用。处方分析将不同于预测分析，因为它将为通常使用它的医疗保健系统带来更多益处。[图 10.6](#chapter10.xhtml#fig10_6) 显示，预测分析帮助医疗保健系统预测其结果，但处方分析深入挖掘，以便根据这些发现采取完美的分析行动。它帮助医疗保健系统提高结果成果的效率。处方分析消除了决策过程中的所有主观臆测，并对其进行优化，以获得患者护理方面更好的改进。归根结底，一切都是关于医疗保健系统为患者提供最佳可能的护理。

## 10.6 医疗保健系统中的数据收集

收集数据的行为涉及以结构化的方式组织和分析医疗保健系统数据。解释这些数据对于开发、实施和评估公共卫生预防策略至关重要。许多大国需要加强其信息系统 [[8](#chapter10.xhtml#ref10_8)]。

[图 10.7](#chapter10.xhtml#fig10_7) 显示，医疗保健系统中的数据收集用于创建患者的整体视图、个性化治疗、推进治疗方法，并改善医生和患者之间的社交与沟通，以了解特定患者健康问题的最佳结果。

[图 10.7](#chapter10.xhtml#b10fig10_7) 医疗保健系统中的数据收集过程。

医疗保健系统中使用了各种数据收集方法来收集数据，包括医疗保健系统调查、行政登记和账单记录。医疗记录被各种实体使用，包括医院、社区健康中心、医生和健康计划。

## 10.7 医疗保健系统中的数据提取

数据提取是医疗保健行业中广泛使用的技术之一。从预防性支持的早期阶段开始，它在数据遗传学方面面临着关键斗争。[图 10.8](#chapter10.xhtml#fig10_8) 显示，数据遗传学是在特定时间从特定系统收集数据的最佳方法。

![FIGURE 10.8 Data extraction is done in the healthcare system.](images/fig10_8.jpg)

[图 10.8](#chapter10.xhtml#b10fig10_8) 医疗保健系统中的数据提取过程。

数据提取试图利用患者的相关数据，包括药物史和综合数据，使经批准的用户（如医生）能轻松访问 [[9](#chapter10.xhtml#ref10_9)]。它广播了保持细节安全和可获取的重要性，以防止任何非法访问 [[10](#chapter10.xhtml#ref10_10)]。它通过包含所有人口统计学特征、疾病史、预防性检查或体检，创建了自动化的分析历史。如今，医疗保健系统中的数据提取广泛发生在教育环境中 [[11](#chapter10.xhtml#ref10_11)]。将其纳入健康计划并做出**重大**改变**需要**三种方法。它们是分析、最佳实践和采用，以及演进的前因。

## 10.10 医疗保健系统中的可视化与报告

数据可视化在医疗保健系统重点中提供了最重要的技术；它对于识别重要模式和相关性非常有用，并使数据分析更加系统化 [[16](#chapter10.xhtml#ref10_16)]。数据可视化是健康指标和衡量最好的机构之一，只是主要共享可视化的重要组织之一 [[17](#chapter10.xhtml#ref10_17)]。

医疗保健系统中的事件报告（IR）被规定为提高患者安全专业化的重要手段。IR 的目的是识别最佳安全威胁并扩展干预措施以减轻这些威胁，从而减少医疗保健系统中的不道德行为 [[18](#chapter10.xhtml#ref10_18)]。仪表板有助于医疗专业人员快速分析海量数据集，以节省时间，甚至通过医疗专业人员挽救患者的生命 [[15](#chapter10.xhtml#ref10_15)]。对可视化 EHL 仪表板的评估使仅在一年内用于数据分析的时间减少了 65%，预计未来将进一步获益。
