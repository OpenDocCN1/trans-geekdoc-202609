

# 逆向物流

逆向物流是指将货物从最终用户沿供应链向上游送回生产商或零售商的过程。为消费者提供退货服务是明智的商业之举，无论客户是退回不需要的产品、产品已达到其生命周期末期，还是产品损坏或有缺陷。这就是逆向物流发挥作用的地方。当产品需要丢弃或回收时，该程序也适用，它涵盖了最终用户负责产品翻新、处置甚至转售的情况 [[51](#chapter12.xhtml#ref12_51)]。

处理退货商品的方法取决于相关的逆向物流类型、组织的业务类型以及其所在的行业。例如，虽然咖啡胶囊制造商可能会为客户提供废弃胶囊的邮寄回收计划，但服装零售商通常处理一般的客户退货。酿酒厂利用逆向物流回收其桶罐，并对其进行清洗和重新灌装以便继续分销。为了确保最佳效率并利用优化逆向物流流程以促进环境可持续性的任何激励措施，每家企业都应有书面记录的流程 [[52](#chapter12.xhtml#ref12_52)]。

考虑这样一种场景：公司希望利用客户不再使用或需要处置的产品（吸尘器）。公司可以对这些产品进行回收，以获得经济效益并保持环境可持续性。主要挑战在于预测联系客户进行产品处置的正确时机，或产品不再被使用的时机。可以利用模糊化系统，通过安装在产品内部的传感器收集其维护历史、健康状况、利用率和非活跃模式等信息，来预测客户愿意处置产品的场景。

## 12.8.1 输入 1：维护/维修频率

模糊集用 `F` 表示，集合的元素用 `f[i]` 表示，隶属度函数用 `μ[F](f[i])` 表示，并假设为三角形。模糊集 (`f`) 使用公式 (12.1) 计算。

其图形表示如 [图 12.5](#chapter12.xhtml#fig12_5) 所示。

![FIGURE 12.5 Fuzzy Set of μF(fi).](images/fig12_5.jpg)

[图 12.5](#chapter12.xhtml#b12fig12_5) `μ[F](f[i])` 的模糊集。

```
F = {\sum_{i = 1}^{n}\frac{\mu_{F~}\left( f_{i} \right)}{\left( f_{i} \right)}}
```

(12.1)

此处 `F = {L,M,H}`，其中 `L` 表示低值，`M` 表示中值，`H` 表示高值。维护/维修频率的高值表明客户极有可能购买新产品，并愿意处置旧产品。

## 12.8.2 输入 2：产品时间利用率

模糊集用 (`U`) 表示，集合的元素用 `u[i]` 表示，隶属度函数用 `μ[U](u[i])` 表示，并假设为三角形。模糊集 (`U`) 使用公式 (12.2) 计算。

其图形表示如 [图 12.6](#chapter12.xhtml#fig12_6) 所示。

![FIGURE 12.6 Fuzzy set of μU(ui).](images/fig12_6.jpg)

[图 12.6](#chapter12.xhtml#b12fig12_6) `μ[U](u[i])` 的模糊集。

```
U = {\sum_{i = 1}^{n}\frac{\mu_{U~}\left( u_{i} \right)}{\left( u_{i} \right)}}
```

(12.2)

`U={L,M,H}`，其中 `L` 表示低值，`M` 表示中值，`H` 表示高值。从产品的时间利用率可以推断，该产品在客户的日常生活中扮演着重要角色。

## 12.8.3 输入 3：产品非活跃模式

模糊集用 (`M`) 表示，集合的元素用 `m[i]` 表示，隶属度函数用 `μ[M](m[i])` 表示，并假设为三角形。模糊集 (`M`) 使用公式 (12.3) 计算。

其图形表示如 [图 12.7](#chapter12.xhtml#fig12_7) 所示。

![FIGURE 12.7 Fuzzy Set of μM(mi).](images/fig12_7.jpg)

[图 12.7](#chapter12.xhtml#b12fig12_7) `μ[M](m[i])` 的模糊集。

```
M = {\sum_{i = 1}^{n}\frac{\mu_{M~}\left( m_{i} \right)}{\left( m_{i} \right)}}
```

(12.3)

`M={VL, L, N, H, VH}`，其中 `VL` 表示极低值，`L` 表示低值，`N` 表示正常值，`H` 表示高值，`VH` 表示极高值。非活跃模式的值越大，可以推断出客户对该产品的需求不大，可能愿意处置或转售。

## 12.8.4 输出：处置意向

模糊集用 `DI` 表示，集合的元素用 `di[i]` 表示，隶属度函数用 `μ[DI](di[i])` 表示，并假设为三角形。模糊集 (`DI`) 使用公式 (12.4) 计算。

其图形表示如 [图 12.8](#chapter12.xhtml#fig12_8) 所示。

![FIGURE 12.8 Fuzzy Set of μDI(dii).](images/fig12_8.jpg)

[图 12.8](#chapter12.xhtml#b12fig12_8) `μ[DI](di[i])` 的模糊集。

```
DI = {\sum_{i = 1}^{n}\frac{\mu_{DI~}\left( {di}_{i} \right)}{\left( {di}_{i} \right)}}
```

(12.4)

此处，`DI={DN, NL, N, L, ML}`，其中 `DN` 表示“绝不”值，`NL` 表示“不太可能”值，`N` 表示“中性”值，`L` 表示“可能”值，`ML` 表示“极可能”值。如果非活跃模式值越大，则可以推断出客户对该产品的需求不大，可能愿意处置或转售它。

# 12.9 用于供应链管理的区块链和物联网

区块链技术可为供应链上的所有交易提供永久记录，使企业能够发现问题领域并采取适当行动。经常面临全球供应链问题的跨国公司对这一潜在用例表现出了兴趣。区块链是一个由链接区块组成的链，作为一种分布式数据结构。区块链的基本结构如 [图 12.9](#chapter12.xhtml#fig12_9) 所示。区块链通过充当分布式数据库或全球账本，记录网络上的所有交易。包含带时间戳交易的区块通过其加密哈希值来识别。区块按线性链（“区块链”）排列，每个区块引用其前一个区块的哈希值。维护区块链的网络中的每个节点都会执行并记录相同的交易。区块链网络中的每个节点都有一份区块链副本。网络中的任何节点都可以读取交易。

![FIGURE 12.9 Basic structure of a blockchain.](images/fig12_9.jpg)

[图 12.9](#chapter12.xhtml#b12fig12_9) 区块链的基本结构。

区块链是一种网络范围的账本，具有安全、加密、不可篡改和可访问的特性。由于产品追踪，这些特性对于必须做出重要采购决策的参与者至关重要 [[53](#chapter12.xhtml#ref12_53), [54](#chapter12.xhtml#ref12_54)]。它已被用于许多供应链行业，包括制药、农食品和海运。该技术实现了安全的产品追溯，因为分布式账本使用的共识技术确保了其中数据保持不可篡改。文献中经常将物联网设备的使用和区块链供应链应用一起提及 [[55](#chapter12.xhtml#ref12_55)]。仅使用 RFID 和物联网基础设施时，存在安全性不足的问题 [[56](#chapter12.xhtml#ref12_56)]。
