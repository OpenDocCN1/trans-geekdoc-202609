
IDM 在大多数情况下会产生加速度和减速度。当当前车距远小于预期车距时，减速度会变得过高。就人力驾驶车辆而言，即使在最严重的减速度下，前车也不会无缘无故地突然停下。因此，当车距差超过最优差距离时，这种情况被称为某种程度上的温和临界条件 [[15](#chapter1.xhtml#ref1_15)]。Do、Rouhani 和 Miranda-Moreno 通过将 IDM 与恒定加速度启发式算法（CAH）相结合，解决了这一问题，以最大限度地减少过大的减速度。该 CAH 模型的基本假设是前车不会在几秒钟内突然改变加速度 [[16](#chapter1.xhtml#ref1_16)]。

根据研究，CAH 要正常运行必须满足三个特殊条件：(i) 从不需要安全时间间隔或最小距离；(ii) 车主必须立即反应（零响应时间）；(iii) 考虑车辆和前车的加速度在适用的未来（通常为几秒钟）内不会改变 [[17](#chapter1.xhtml#ref1_17)]。

给出了实际车距、当前车速、前车车速和加速度的数值。避免车辆碰撞的最大加速度率如下：

```

                          { ã_l * (v - v_1)^2 * θ(v - v_1) / (2s)  otherwise
```

(1.3)

其中有效加速度率 = min（以防止可能由前车引起的缺陷，前车能够更快地加速）。如果车辆在达到最小车距 `s` = 0 时完全停止，则该断言成立。否则，负接近率将被海维赛阶跃函数 `Q` 消除，因为它们对于 CAH 来说是不可理解的。Leong 和 Ee [[17](#chapter1.xhtml#ref1_17)] 提出了结合 IDM 和 CAH 加速度的 ACC 模型。

基于以下因素，ACC 模型根据 IDM 或 CAH 生成不同的加速度。如果 IDM 和 CAH 得出相同的速度结果，ACC 模型生成相同的加速度。如果 IDM 产生过大的减速度而 CAH 的减速度在可容忍的减速度范围内，情况会变得略微棘手。在这种情况下，减去减速度后，ACC 的加速度仍大于 CAH 的加速度。如果 IDM 或 CAH 产生的加速度显著低于 `b`，则存在严重问题。IDM 和 CAH 的最大组合加速度不得超过 ACC 的加速度。IDM 和 CAH 的加速度应是 ACC 加速度的可微且连续函数 [[16](#chapter1.xhtml#ref1_16)]。

```

```

## 1.9 车辆连接与网络

网络可在各种情况下运行，以防止特定车辆之间的碰撞。能够相互通信的车辆可能有助于减少单车事故或大规模连环碰撞 [[19](#chapter1.xhtml#ref1_19)]。为了达到最佳效果，事故预防也可利用联网系统和自主独立系统。研究人员已开始将自控框架与机器学习技术相结合，以提升结合自主与集成系统的潜在双系统性能 [[20](#chapter1.xhtml#ref1_20), [21](#chapter1.xhtml#ref1_21)]。协同自适应巡航控制（CACC）是自适应巡航控制（ACC）的延伸。CACC 在开发仿真方面取得成功，证明了部署自主和集成 CACC 系统的价值。[图 1.6](#chapter1.xhtml#fig1_6) 展示了供读者参考的 CACC 定义概念图。GPS 从大气层接收信息并对其进行过滤，以便做出必要的调整。通过对基础设施和技术的具体改进，这可以扩展为实际应用 [[19](#chapter1.xhtml#ref1_19)]。

## 1.10 赋能与促进技术

### 1.10.1 环境状态

感知汽车周围的环境是智能汽车系统的关键组成部分 [[11](#chapter1.xhtml#ref1_11)]。在智能汽车中，理解交通状况是最难完成的任务。它涉及识别关键要素，包括车道、其他现场车辆、行走的行人、交通状况、路标和其他临时障碍物。在道路场景中发现事件时的速度控制是最具挑战性的问题。紫外线、超声波、雷达、激光测距仪和计算机视觉是扫描世界的常用传感器，如[图 1.7](#chapter1.xhtml#fig1_7)所示。

![图 1.7 环境状态感知。](images/fig1_7.jpg)

[图 1.7](#chapter1.xhtml#b1fig1_7) 环境状态感知。

红外线和超声波常用于检测附近的障碍物，而雷达常用于探测远处的障碍物。频谱、图像采集和分析被用于在各种环境条件下提供关于道路场景的更多信息。只有视觉传感器能检测道路情况的任何要素，如交通状况和路标。传感器融合常用于智能汽车应用，特别是单目视觉和雷达/激光传感器。

在主要汽车制造商的合作下，一级汽车供应商博世、电装、德尔福、Visteon、西门子和 NEC 主要开展这项研究。这些传感器可用于绘制车辆周围区域的地图，然后可结合同步定位与地图构建 [[22](#chapter1.xhtml#ref1_22)] 等方法，创建停车或避障所需的复杂动作 [[11](#chapter1.xhtml#ref1_11)]。
