

# 7.3.3 全球路径规划

最优路径是在起点和终点之间通过全球路径规划确定的。为了融合电子地图（EM）数据并计算最优路线，最常用的计算方法包括 `Dijkstra calculation`、`Bellman-Ford calculation`、`Floyd calculation` 和 `heuristic calculation`。所提出的技术偏离了这一过程，将速度和距离控制提升到了编排层面。此外，通过结合调节和制动/加速的使用，计算融合了感知障碍规避。在每个编排阶段，车辆将遵循最近选定方向的剩余部分。虽然用于选择费用效用函数 [[23](#chapter7.xhtml#ref7_23)] 的基本方法与贝尔曼最优性原理兼容，但限制它的指令无论如何都应接近自动驾驶车辆的最优交通行为。`Frenet-Serret` [[24](#chapter7.xhtml#ref7_24)] 公式化和移动边界方法被用于为不同任务组合多个横向和纵向费用函数，以及模拟类人驾驶行为。

## 7.3.3.3 路由

传统的路由方法基于预先准备的、基于卫星定位服务的深度学习模型，其滞后性很强且更新时间久远。在现有地图上导航和驾驶非常困难。因此，本研究提出了一种集成云交通管理系统，该系统结合车辆的自主算法以高效管理每辆车。交通桩可作为物联网设备，与周边车辆通信以管理其路由，并向其提供关于周边环境的实时数据。因此，自动驾驶汽车可以在城市中导航并轻松规划路线。

## 7.3.3.4 横向运动

推进的初始条件是根据最近确定的方向选择的，以提高舒适性，从而限制后续路径上的平方加加速度（jerk）。`Quintic polynomials` [[25](#chapter7.xhtml#ref7_25)] 可用于实际满足这一费用。该方法不是先识别最优路线再修改系数以创建可行替代方案，而是首先通过混合多个终止条件来建立一个方向集。在随后的阶段中，选择费用最低的显著路线。值得注意的是，沿着理想路径推进时，剩余方向在下一步中成为完美的编排。这种方法在极端低点忽略了车辆的非完整性特征，旨在因无效的曲率而排除大多数方向。

## 7.3.3.5 纵向运动

与以往关注行驶时间或距离的举措不同，重点将放在舒适性上，同时仍有助于高速行驶时的安全性，因为平滑的变化能更好地适应交通流。因此，纵向加加速度（jerk）同样被纳入优化问题中。创建了一个类似于横向方向的纵向方向集，并增加了费用效用，因为距离保持、汇入流和在特定位置停车都需要方向，这描述了从当前状态到纵向潜在移动目标位置的过渡。

## 7.3.3.6 横向与纵向曲线的融合

在最后阶段，每个方向的组合费用作为加权总和计算：

```
C[tot] = K[lat] C[lat] + K[lon] C[lon]
```

# 7.3.4 执行

现在，在处理完实时传感器数据后，机器相应地进行学习，是时候驾驶车辆了。

## 7.3.4.1 车辆控制

汽车的航向和速度是车辆控制最重要的方面。车辆控制功能主要包括收集车辆状态信息和优化车辆控制方法。感知模块利用电子地图（EM）数据估算车辆速度和方位。电子地图数据包括气候洞察、车辆状态、驾驶目标、交通规则和驾驶信息。然后由车辆控制计算得出控制目标，并提供给车辆控制框架。最后，车辆控制框架执行这些指令，以管理车辆的方位、速度、灯光、喇叭等。控制阶段是驾驶车辆的主要元素，它调节车辆的众多系统，包括防抱死制动系统、牵引力控制系统、电子稳定程序、感应式制动控制、电子制动力分配、制动辅助系统、电子控制悬架、电动助力转向系统等。电子控制单元（ECU）和通信总线是控制阶段的两个主要元素。控制计算主要由 ECU 执行，而通信总线理解 ECU 与机械元件之间的通信工作。

## 7.3.4.2 速度与航向

车辆自状态主要包含车辆速度和方向信息。对于速度，使用光电编码器；而路径识别则同时使用光电角度编码器和电位器。由于系统与实时云端同步，车辆可获取其他车辆的统计数据，如速度、航向等，通过在本地计算与其他车辆的相对速度和方向来控制自身的速度和航向。

## 7.3.4.3 车辆控制技术

比例积分微分（PID）计算，或 PID 计算的更高级版本，广泛应用于车辆控制系统。在当今的机械制造过程中，PID 控制计算是最著名的控制算法。输入信号为 `r(t)`，反馈误差信号为 `e(t)`，PID 控制 [[26](#chapter7.xhtml#ref7_26)] 计算确定的控制信号为 `u(t)`，受控对象输出的当前实际信号为 `c(t)`。PID 计算通过利用三个参数和数学运算（包括比例、积分和微分）来控制目标。输入环路对修正目标状态的贡献是控制目标与实际值之间的差值。经典 PID 计算存在诸如复杂的参数调整、适应性有限等挑战。控制精度异常低，特别是在传动系统高度非线性且纵向阻抗过于复杂时。最新自动驾驶汽车使用的更复杂的 PID 计算可以弥补标准 PID 计算的不足。
