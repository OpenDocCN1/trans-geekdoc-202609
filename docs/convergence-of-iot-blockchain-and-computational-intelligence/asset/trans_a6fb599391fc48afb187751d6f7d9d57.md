

# 物联网在水产养殖和智能系统中的未来

物联网（IoT）作为一项快速扩展的技术，其未来是无限的，因为数据流随时间推移已翻倍增长。即将到来的业务将从云计算和大数据分析转移而来，这些技术主要由新冠疫情推动，已取代了更传统的数据处理方法。这种转变正在发生，因为世界各地的公司都在采用基于云的工作实践。

鱼类需要主人给予充分的关注和照料，因为它们被认为对周围环境相当敏感。由于人们经常忽略换水、喂鱼和检查 pH 值，物联网可以轻松解决这些问题，以及追踪数百条鱼等简单但具有挑战性的任务。对于中大型水族馆（如迪拜水族馆）而言，拥有一套物联网系统至关重要（可持续监控数百条鱼）。该系统可用于建立高产量所需的完美条件。鉴于全球鱼类短缺，水产养殖业在未来将对经济极为重要。必须简化流程，以提高效率并改善鱼类健康。基于物联网的水族馆通过开发具有实时数据处理能力的可靠系统，可以拯救海洋野生动物。在偏远地区，可以建造巨大的水箱来饲养濒危动物，从而促进生物多样性并创造健康的生态系统。由于在巨大水箱中监控大型鱼类可能具有挑战性，因此可以使用射频识别（RFID）和发射器等技术来监控它们 [[4](#chapter11.xhtml#ref11_4)]。

无论采用何种硬件和操作系统，各类智能设备都能相互通信，通过传感器收集的数据可存储在云平台中，并进行预测分析和替代性保存。基于物联网的水生监控系统可记录水族馆内的水位，当水位下降时，可向用户发送电子邮件 [[5](#chapter11.xhtml#ref11_5)]。它确实能够控制自动喂食器，记录热力学和含湿量读数，并在亚马逊云服务（AWS）技术的帮助下开关水族馆照明。用户可以通过 Web/App 界面或语音应用程序操作喂食器。加热、湿度、水位、LED 状况以及喂食器的其他信息是该项目采用的参数。`ESP-32` 执行传感器数据采集，并充当本地服务器、控制器以及数据处理设备。只要有互联网连接，由于数据处理由 `AWS Lambda` 完成，并记录在 `DynamoDB` 中，且通过 AWS 应用程序编程接口（API）提供服务，用户几乎可以在世界任何地方的本地或远程位置监控水族馆状况。为了有效决策，使用 `Quick Sight` 和 `AWS IoT Analytics` 对数据进行进一步可视化。该模型的所有功能均平稳运行且准确度极高。该项目有许多工业应用，包括养鱼、鱼类管理、水产种植和动物园饲养管理。知识被保存下来供进一步研究，并可用于完成相关任务。它们对于维持生态平衡以及饲养特定鱼类的农民非常有帮助 [[6](#chapter11.xhtml#ref11_6)]。

## 11.2 文献综述

该项目的最终目标是使用 `ESP32` 为电器供电。通过使用智能手机，人们可以通过使我们的工作场所更加豪华和智能，无论是否有互联网连接都能进行控制。为了利用我们的移动设备控制照明、风扇等物联网移动应用来操作电气设备，设计了一种新方法。对于那些需要使家庭更智能的人来说，它提供了一种更容易集成且成本更低的替代方案。所需创建的开关是一种模块化的即插即用开关。继电器、MCB、LED 指示灯和双控开关都是开关面板的组成部分。通过内置 Wi-Fi 和蓝牙的 `ESP32`，移动设备连接到开关，使我们能够在有或没有互联网连接的情况下操作电器。本研究还提出了基于 RFID 的自动房间灯光控制器概念 [[7](#chapter11.xhtml#ref11_7)]。物联网是指一种将数十亿实际物理对象连接到互联网的技术。自动化是已在许多应用领域普及的尖端技术之一。本研究包含了作为其组成部分之一的开关自动化系统的规划与实施摘要。一个简单直接的 GUI 程序可用于智能操作模式，能快速简便地控制指令，以开关家用电器（如照明和风扇），这些被称为控制输入。我们日常活动和使用的设备很大一部分依赖于 Wi-Fi，这无疑是过去 10 年最有益的技术发展之一。Wi-Fi 兼容智能手机、笔记本电脑和计算机。这些设备具备连接 Wi-Fi 网络以执行特定活动的能力 [[8](#chapter11.xhtml#ref11_8)]。

为了解决传统照明控制系统功能单一、自动化程度低、管理效率低的缺点，本研究开发并部署了一种智能访客房间照明控制系统，该系统协调手动和自动管家照明控制。该系统采用多层分布式拓扑，融合了 CAN 总线、网络、传感器和嵌入式技术。其关键组件是集成 ARM CPU，它结合多个模块，通过 CAN 总线通信协议实现客房智能照明控制。本章对硬件、软件和总体结构设计进行了彻底的检查和论证。为了强化管理标准和服务质量、降低能耗、提高酒店竞争力，智能酒店客房照明控制系统与高星级酒店竞争。它将成为先进酒店系统的关键组成部分，并具有特定的使用价值 [[9](#chapter11.xhtml#ref11_9)]。

本章描述了将智能家居（SH）照明系统设置为恒定照度水平时，其调光行为的验证情况。建议的测量技术作为分析日光诱导室内照度曲线的一种改进而实施。在智能家居的参考室中进行了测量，采用的技术评估视觉任务位置的照度，同时扫描室外开放水平面上日光引起的照度。所用测量仪器配备了可调光人工照明系统，该系统结合 KNX 控制系统，使用安装在房间天花板上的亮度控制器，尽管同时利用人工和自然光源，仍能维持恒定照度水平。本章表明，由 KNX 系统控制的照度设定值与视觉任务位置的实际照度之间可能存在差异。这种差异可能导致发光装置达不到规范标准，这是完全不可接受的 [[10](#chapter11.xhtml#ref11_10)]。
