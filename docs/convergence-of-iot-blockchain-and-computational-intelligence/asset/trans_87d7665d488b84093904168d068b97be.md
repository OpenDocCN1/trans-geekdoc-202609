

# 物联网在供应链管理中的应用

物联网应用在当前场景中已被广泛实施，用于在供应链中查找、识别、追踪和监控货物与服务 [[16](#chapter12.xhtml#ref12_16)]。此外，在此情况下，该技术也已应用于其他学科，特别是农业和医疗行业的供应链。在供应链管理领域执行物联网基础设施的首要关键障碍是安全顾虑、缺乏标准、互操作性问题，以及软硬件限制。尽管 RFID 技术多年来一直是物联网的关键推动者，但仍存在定价、技术采用、复杂性、规模实施和数据管理等问题 [[22](#chapter12.xhtml#ref12_22)]。

由于智能对象共享大量信息并连接可通过 Web 界面访问的资源而产生的数据管理困难，在面向语义的组件中得到了解决。设备和智能物品，如传感器、执行器和联网 RFID 芯片。自无线技术出现以来，物联网获得了更多关注 [[10](#chapter12.xhtml#ref12_10)]，供应链管理界也对其表现出了兴趣 [[16](#chapter12.xhtml#ref12_16), [26](#chapter12.xhtml#ref12_26)]。物联网为工业自动化做出了重大贡献，并实现了用于工厂控制的网络、用于企业信息管理的网络以及用于物流管理的 RFID 网络的融合与集成。

此外，物联网为企业提供了提升运营效率、保障运营便利性并保持竞争优势的途径。企业能够利用物联网精简信息流，提供显著的供应链效率改进，并实现组织间及组织内部的通信与集成 [[27](#chapter12.xhtml#ref12_27)]。例如，国际时装零售商 Zara 基于物联网，成功保持了高规划灵活性、可靠的补货解决方案、更短的交货周期和更少的产品变更 [[28](#chapter12.xhtml#ref12_28)]。

## 12.6 供应链流程与物联网的详细文献

供应链管理受益于物联网的节约成本、库存准确性和产品追踪等特性。然而，物联网对各种供应链活动的影响尚不清楚 [[4](#chapter12.xhtml#ref12_4)]。以流程为中心的供应链视角是理解供应链的一种范式。一个著名的框架是供应链运作参考模型（SCOR 模型），它将供应链流程分解为计划、采购、制造、交付和退货。因此，本研究旨在通过基于受影响供应链流程的综合文献综述，识别物联网对供应链管理的影响。鉴于计划流程与所有其他 SCOR 流程交织在一起，目前的文献分析集中在其余的 SCOR 流程上。

### 12.6.1 采购

供应链的一个上游组成部分是采购，即仔细决定企业开展业务所需产品和服务的过程。除了选择卖方、谈判合同和评估供应商的长期绩效外，采购还指购买商品的行为。虚拟供应链使企业能够快速接受并应对商业环境的变化。为了应对行业限制和当今可用新技术提供的机遇，供应链正变得更加虚拟化 [[29](#chapter12.xhtml#ref12_29)]。改变组织结构的能力使其能够设计解决方案以满足不断变化的客户需求。这得益于虚拟供应链 [[30](#chapter12.xhtml#ref12_30)]。本质上，虚拟供应链将管理任务从商品从源头到目的地的实际移动中分离开来。虚拟对象而非真实对象被直接用于监管和协调供应链活动 [[29](#chapter12.xhtml#ref12_29)]。文中还讨论了“追踪与溯源分析”框架，该框架可扩展以提供监控产品在供应链中移动时状况的能力。该项目名为“为全球环境构建射频识别”，并由欧盟部分资助。报告详细阐述了将传感器数据与 RFID/EPC 分析相融合的各种方法，无论是通过传感器启用标签，还是通过虚拟集成，即将环境传感器的传感器信息直接与物体在不同时间的已识别位置相关联 [[31](#chapter12.xhtml#ref12_31)]。另一项研究阐述了物联网的指导原则及其对供应链运营效率大数据分析的影响，特别是关于利用从互联智能产品获取的大数据进行运营协调动力学和供应链优化，以及大数据披露的治理框架 [[32](#chapter12.xhtml#ref12_32)]。

### 12.6.2 制造

产品制造的基础是在要求的时间框架和预算内生产高质量产品的能力。所有有效的供应链都建立并定期审查其用于决定生产过程中每个阶段（从物料和人工到仓储和运输）的费用、价值、质量和周转时间的标准。制造业历史发展的四个阶段被称为工业 1.0 到 4.0。每个阶段都是制造业的重大范式转移。借助蒸汽和水力，工业生产在工业 1.0 中首次引入。工业 2.0 的特点是大规模制造，得益于电力促进的劳动分工。为了进一步实现生产自动化，工业 3.0 将电子技术、IT 和控制机制引入车间。在物联网的帮助下，工业 4.0 预示着一场前所未有的根本性变革，将对生产及其供应网络产生重大影响 [[4](#chapter12.xhtml#ref12_4)]。云计算利用超强大的计算工具解决问题，并高效地促进人与物之间的无缝连接，以解决决策中的难题 [[33](#chapter12.xhtml#ref12_33)]。根据对当前离散制造企业面临的车间管理需求增加的分析，建议了一个实现实时可访问性和透明度的框架 [[34](#chapter12.xhtml#ref12_34)]。

### 12.6.3 交付

根据供应链管理专业人士委员会的定义，物流是“供应链流程的一部分，它规划、实施和控制货物、服务及相关信息从原点到消费点的高效、有效的正向和逆向流动与存储，以满足客户要求”。

在一项研究中，提出了一种面向未来仓库的方法，其中建议了一种基于 RFID 的库存管理系统，该系统包含自动存储和检索机制，使用 RFID 技术并可与基于 RFID 的库存管理系统通信，无需人工干预 [[35](#chapter12.xhtml#ref12_35)]。另一项研究支持利用 RFID 增强变化环境下分散仓库管理的灵活性 [[29](#chapter12.xhtml#ref12_29)]。[表 12.1](#chapter12.xhtml#tbl12_1) 解释了基于 RFID 系统的部署和为提高供应链有效性而开发的原型。大多数研究强调了库存管理和仓储。
