
## 区块链的代币化过程

任何区块链的代币化过程都是创建资产或部分资产所有权的数字化权利形式，以转移所有权。它有助于将资产转换为可进一步流通的代币。在比特币区块链中，这种代币通常被称为加密货币（比特币）。创建代币有两种基本方式：第一种是使用 UTXO（可花费金额）进行进一步交易，另一种是基于账户的，即通过智能合约（区块链中各方协议的自执行程序）将发送者钱包中的一定金额转移到接收者的钱包中 [[51](#chapter8.xhtml#ref8_51)]。

区块链中存在以下类型的代币：

*   **平台代币**：此类代币用于去中心化应用以治理其用户。
*   **实用代币**：用于访问网络服务，如支付交易费和共识程序。
*   **同质化代币**：可复制的代币，不具有唯一性。
*   **非同质化代币 (NFT)**：这些是现实世界的事物，如绘画、工具或任何单件产品，可进一步分割，用作代币。

以下是单个区块的组成元素：

*   **版本**：指示网络中存在的区块链版本。此字段在区块中的大小仅为 4 字节。它还有助于检测降级的硬件和软件，防止其在网络中被攻破。
*   **时间戳**：也占用 4 字节；这对每个区块都是唯一的，用于区块的验证和确认时刻。
*   **前一区块的哈希值**：在区块内占用 32 字节。这是区块链中最关键和主要的元素，以哈希形式存储前一笔交易的信息。
*   **梅克尔根**：它位于由存储所有前序交易哈希值生成的树的顶端。它为交易提供完整性，并使区块链不可篡改。
*   **Nonce（随机数）**：这是一个 4 字节的字段，包含由矿工操纵的随机数字以验证区块。也用于对区块的值进行哈希运算。

## 8.4.3 物联网基础设施中的区块链

物联网基础设施由传感器和硬件设备组成，具有 [图 8.9](#chapter8.xhtml#fig8_9) 中讨论的不同层。从物联网基础设施的层级来看，最底层是感知层，感知设备部署于此以收集数据并发送到网络层的上层。网络层定义设备如何相互连接以及使用何种协议在节点间建立通信。该层是数据存储与中间件层中管理的其他协议之间的桥梁，Web 工具或应用程序、数据库和云存储的应用程序编程接口 (API) 位于此层。安全协议在此层实施以防止数据丢失。该层中的数据被发送到应用层进行进一步处理。在应用层中，有不同类型的应用程序根据需求使用这些数据。这些应用程序运行在机器学习或深度学习等先进技术上，以分析并为应用程序用户提供最佳结果。

[表 8.3](#chapter8.xhtml#b8tbl8_3) 利用区块链技术对物联网基础设施攻击的对抗措施

| 攻击类型 | 利用区块链进行防范 |
| :--- | :--- |
| 隐私攻击 | 此攻击针对网络上的用户数据；然而，区块链使用 `SHA-256` 对用户的所有个人信息进行哈希处理，保护其匿名性。 |
| 时序攻击 | 此攻击针对认证协议。由于 `ECDSA` 不易被破解，因此此攻击对区块链网络无效。 |
| 硬件故障注入 | 如果任何设备受到此攻击并表现出恶意行为，则该设备将不再是网络的一部分。 |
| 功耗分析 | 由于设备访问由区块链网络认证，此攻击无效。 |
| 物理攻击 | 如果任何设备表现恶意或不遵循区块链共识，则不再是网络的一部分。因此，即使有人通过物理攻击控制了某设备，该设备在被攻破后也无法在网络上保持活跃。 |
| 加密攻击 | `ECDSA` 密码协议拥有 128 位安全密钥，目前无法通过任何计算工具的密码分析轻易破解。 |
| DDoS 攻击 | 由于网络是去中心化和分布式的，攻击对整个网络无效，且存在大量连接节点可在受攻击节点之外为客户端节点提供数据。 |
| 固件劫持 | 根据区块中的版本，所有节点都必须更新至网络中所有人使用的最新软件版本。这可防止区块链网络遭受此攻击。因为如果任何节点没有最新版本的网络，它将不被视为网络的一部分并被抛弃。 |
| 僵尸网络 | 由于 `ECDSA` 密码协议拥有目前无法通过任何计算工具轻易破解的 128 位安全密钥，因此在区块链中很难攻破任何设备。 |
| 中间人攻击 (MIMT) | 由于通信通道使用 `ECDSA` 加密，提供了免受网络监控的安全性，且发送方数据上的签名提供了传输过程中的完整性，防止被篡改。 |
| 勒索软件攻击 | 由于分布式系统，数据或哈希数据的账本被复制到所有连接到网络的设备上。因此，任何系统若遭受勒索软件攻击被加密，所有数据都可以非常容易地从网络中的任何其他设备恢复。 |
| 窃听攻击 | 此攻击无法生效，因为传输通道已加密且传输数据经数字签名认证，因此即使数据被监听和修改，对接收方而言也是未经认证的。 |
