
# 供应链演变与第四次工业革命

供应链会随着时间的推移，在规模、形状、配置以及协调、控制和管理技术方面不断演变。新供应链的出现可能源于多种原因，例如为响应技术创新 [[9](#chapter12.xhtml#ref12_9)]。有观点认为，结构、规模和贸易类型最终是由基本经济因素决定的，而非供应链特性 [[10](#chapter12.xhtml#ref12_10)]。然而，其他因素也可能对供应链的配置、运行和协调方式产生重大影响。除了经济和技术驱动因素外，监管框架 [[11](#chapter12.xhtml#ref12_11)]、可持续发展议程、政治因素 [[12](#chapter12.xhtml#ref12_12)] 和战略决策 [[13](#chapter12.xhtml#ref12_13)] 也会影响供应链的结构和配置。全球采购技术极大地改变了供应网络的建立方式 [[14](#chapter12.xhtml#ref12_14)]。为遵循制造和/或营销计划并更好地服务市场，组织已战略性地重构其网络。因此，各种经济、技术、环境和战略因素都可能影响供应链参与者、增值活动的地点、这些活动的协调与管理，以及供应网络的增长与发展。

第四次工业革命由物联网、网络物理系统（CPS）、区块链、大数据和虚拟化等新应用和服务体系代表。根据众多研究，第四次工业革命（即工业 4.0）是现有信息和通信技术的融合，用于创造商品和服务 [[15](#chapter12.xhtml#ref12_15)]。从业者和学者最关注的研究课题是物联网及其优势与困难。随着供应链以快速速度变得更加复杂，提高供应链可见性将帮助企业通过减少不准确性来简化运营并降低复杂性 [[16](#chapter12.xhtml#ref12_16)]。由于全球化加剧、以客户为中心以及信息技术（IT）的改进，供应链管理（SCM）的重要性将在未来几年增长 [[17](#chapter12.xhtml#ref12_17)]。包括物联网在内的各种技术的实施，对能源生产、制造、仓储、医疗、化工制药、食品饮料等多个行业产生了广泛的积极影响。增强现实、直接数字化生产、仓库自动化和 3D 打印等持续的技术发展，从供应链角度开启了全新的可能性世界。除了提高生产和分销运营的生产力与适应性，这些新技术还改变了各供应链节点间的动态关系，并聚焦于消费者 [[18](#chapter12.xhtml#ref12_18)]。

智能供应链的目标是利用尖端技术（特别是新兴信息通信技术 `ICT`），通过物联网、区块链等，互联供应链多个合作伙伴的流程，创建智能互联系统 [[19](#chapter12.xhtml#ref12_19)]。智能制造中的 `ICT` 和其他新兴技术有望显著提升供应链绩效。创新技术，特别是尖端 `ICT`，正在推动第四次工业革命（即工业 4.0）。复杂的 `ICT` 影响制造系统的几乎所有阶段 [[20](#chapter12.xhtml#ref12_20)]。现代供应链管理研究非常关注产品与需求信息流及其相应协调的研究 [[21](#chapter12.xhtml#ref12_21)]。由于所有供应链本质上都是由需求驱动的，最终消费者需求数据常被视为供应链网络中最关键的数据 [[19](#chapter12.xhtml#ref12_19)]。可用性、收入、定价、运输、区域、数量、性能和技术数据是产生的更常见信息示例 [[21](#chapter12.xhtml#ref12_21)]。在大数据时代，需要新技术来获取、存储、分发和分析海量、高速、复杂和多样的数据。物联网是通信和计算领域的一项技术进步，将实现“随时、随地、任何媒体、万物互联”的交互 [[22](#chapter12.xhtml#ref12_22)]。因此，物联网使虚拟与物理元素的连接成为可能，开辟了全新的服务和应用范围。

## 12.4 物联网

IT 时代的增长对于改善从起点到消费点的商品、数据和服务的流动与存储的规划、执行和控制至关重要。新技术带来的变革速度彻底改变了企业为客户创造和分发价值的方式。例如，工业 4.0 的引入已被证明是为行业和日常运营流程优化价值链活动等众多商业利益提供关键成功要素 [[23](#chapter12.xhtml#ref12_23)]。

德国经济发展署 [[24](#chapter12.xhtml#ref12_24)] 创造了“工业 4.0”这一术语，用以描述多种技术的出现、发展和融合，这些技术实现了物理世界与数字世界近乎实时的交互。因此，技术一直是并仍然是高效供应链管理的关键促进因素。通过改善通信、数据采集和数据传输，它在协调参与者、实现高效决策和提升供应链绩效方面发挥着关键作用。物联网是供应链管理领域最新的 IT 进步之一，能为更高效的决策提供更精确的数据。

## 12.5 物联网在可持续供应链管理中的作用

文献中存在大量物联网定义。其中一种定义为：“它是一种技术理念，即多个连接设备能够开启和关闭互联网，以利用软件和自动化程序实现智能应用。”当 `RFID` 标签通过网络连接时，可建立通信并传输识别数据 [[25](#chapter12.xhtml#ref12_25)]。

供应链面临诸多问题，如交付的有效性与效率、持续监控、合作伙伴间的紧密协作等。物联网创建了一个物理连接的事物网络，利益相关者可持续监控和检测该网络。因此，该技术的使用实现了更高的数据透明度和可见性，例如温度监控、位置、湿度、压力、光照和封条破损等。物联网还能降低成本和浪费。从技术上讲，物联网基于 `RFID` 和 `GPS` 等基础技术，并将它们连接到互联网 [[3](#chapter12.xhtml#ref12_3)]。
