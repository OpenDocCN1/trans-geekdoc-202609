# B FEATURE SELECTION BY MOMENI ET AL.

Momeni et al. [31] extracted 16 features from an abstract syntax tree (AST) of an Ethereum smart contract. Among them, we did not adopt Hexadecimal addresses as described in Section 5. The whole list of vulnerabilities is as follows, where all the information can be obtained from AST except for hexadecimal addresses: lines of codes; contract definitions; function definitions; binary operations; function calls; blocks; expression statements; event definitions; bytes; elementary type addresses; modifier definitions; placeholder statements; modifier invocation; approve function definitions; constant values; and hexadecimal addresses.
