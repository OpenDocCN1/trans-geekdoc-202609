
`select` 列表选择结果列，`from` 子句声明源表和连接，`where` 子句用于筛选行，`group by` 子句形成行组，`having` 子句用于筛选组，而 `order by` 子句决定行的顺序。

*子查询* 是外部查询内部的一个带括号的 `select` 查询。如果子查询包含引用外部查询的条件，则它是一个 *相关* 子查询。`exists` 量词后面的子查询是存在性子查询。如果子查询返回一行，则 `exists` 条件为真，否则为假。带有嵌入式子查询的条件最常见的三种形式如下所示，其中 Θ 是比较运算符。

*   ```
    expression [not] in (subquery)                                            - - 成员资格子查询
    ```

*   ```
    expression Θ [all | some | any] (subquery)         - - [量化] 比较子查询
    ```

*   ```
    exists (subquery)                                                                                - - 存在性子查询
    ```

表数据可以使用 `insert`、`update` 和 `delete` 语句进行更改，其基本语法如下。

*   ```
    insert into tablename [ (col-list) ]
    ```

*   ```
           {values (constant-list) | select-query}
    ```

*   ```
    update tablename
    ```

*   ```
    set colname = expression   [, …]
    ```

*   ```
          [where condition]
    ```

*   ```
    delete from tablename
    ```

*   ```
       [ where condition ]
    ```

关系代数在大多数数据库教材中都有介绍，例如 [Elmasri and Navathe (1994)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0365)、[Date (2000)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0300)。算术运算符、集合函数、半连接和其他运算符已被提出用于扩展关系代数，例如 [Date (2000)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0300) 第 6.7 节。作为关系代数的替代方案，可以使用关系演算，例如 [Date (2000)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0300)、[第 7 章](#Ch007_273-308_B978044323790400013X.xhtml)。[Codd (1990)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0235) 提出了包含 333 条规则的关系模型版本 2，但这并未获得任何显著采用。

SQL 标准由国际标准化组织 ([*www.iso.org*](http://www.iso.org)) 发布。本书出版时，当前版本 (SQL:2023) 为 ISO/IEC 9075-2:2023；参见 [https://www.iso.org/standard/76584.html](https://www.iso.org/standard/76584.html)，点击“Preview”按钮可浏览公开的信息性章节。关于 SQL-92 标准的清晰、详尽说明，请参见 [Date and Darwen (1997)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0305)；关于 SQL:1999 请参见 [Melton and Simon (2002)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0990)。

最初的 SEQUEL 语言在 [Chamberlin and Boyce (1974)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0205) 中有描述，它本身基于一种名为 “SQUARE” 的早期关系语言。[Chamberlin (1998)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0200) 对 DB2 提供了非常易读的介绍，第 1.3 节勾勒了 SQL 权威的早期历史，包括对 SQL 为何允许基本表中存在重复行的解释。

关于 SQL 中多种高级查询的易读且实用的讨论，请参见 [Celko (1999](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0180)、[2000](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0185)、[2004](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0190)、[2005)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0195) 的系列书籍。[Date and Darwen (1998)](#Ch012_539-646_B9780443237904000268_2.xhtml#bb0310) 提供了对 SQL 的深度评论以及面向对象关系数据库的替代理论基础。
