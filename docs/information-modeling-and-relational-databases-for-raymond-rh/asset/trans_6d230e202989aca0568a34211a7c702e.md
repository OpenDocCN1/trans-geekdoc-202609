
建模一元事实类型 CWA 语义的第三种方法是添加一个具有否定含义的*相反一元*（即其实例等同于原始一元实例的否定），例如，针对一元事实类型“Student is intelligent”添加“Student is unintelligent”。这两个一元之间适用一个异或约束。

NORMA 工具计划添加一种表示法，用于声明一元之间的否定含义关联。在这种情况下，异或约束是隐含的，且模式映射到带有单个布尔列的关系表；否则，此方法映射到带有两列的关系表。

作为另一个例子，[图 10.58](#Ch010_401-479_B9780443237904000244.xhtml#f0295)(a) 展示了一个闭世界一元事实类型“Country is monolingual”（恰好有一种官方语言）及其示例数据。加拿大 (CA) 和塞浦路斯 (CY) 未被记录为单语国家，因此 CWA 方法意味着它们不是单语国家。[图 10.58](#Ch010_401-479_B9780443237904000244.xhtml#f0295)(b) 用一个强制的 *n*:1 事实类型替换了该一元。

![Fig. 10.58 Some CWA modeling options.](images/B9780443237904000244/f10-58-9780443237904.jpg)

[图 10.58](#Ch010_401-479_B9780443237904000244.xhtml#B-f0295) 一些 CWA 建模选项。

[图 10.58](#Ch010_401-479_B9780443237904000244.xhtml#f0295)(c) 添加了一元事实类型“Country is multilingual”，其含义是单语一元的*相反*。如果我们添加一种正式声明一元含义相反的方式（不同提案正在讨论中），异或约束的排斥方面将被隐含，且两个事实类型均映射到单个布尔列。否则，此方法映射到带有两列的关系表。

*开放世界假设* (OWA) 允许某些相关事实可能是未知的（作为断言或可推导的事实）。[图 10.59](#Ch010_401-479_B9780443237904000244.xhtml#f0300) 在 OWA 语义下重新建模了我们的学生示例。

![Fig. 10.59 The open world assumption allows some facts to be unknown.](images/B9780443237904000244/f10-59-9780443237904.jpg)

[图 10.59](#Ch010_401-479_B9780443237904000244.xhtml#B-f0300) 开放世界假设允许某些事实未知。

在[图 10.59](#Ch010_401-479_B9780443237904000244.xhtml#f0300)(a) 中，一元谓词的角色框采用虚线，暗示开放性，因此具有 OWA 语义。撰写本文时，NORMA 尚不支持 ORM 的这种 OWA 表示法。

OWA 意味着*经典否定*（找不到或无法证明一个命题或其否定，意味着其真值为*未知*）。例如，正如[图 10.59](#Ch010_401-479_B9780443237904000244.xhtml#f0300)(b) 基础 Student 表所示，未记录学生 1002 和 1004 聪明这一事实，仅意味着我们不知道他们是否聪明。此处记录条目“unknown”以指示此情况。在大多数数据库中，此条目将显示为 null。请自行核对其他“unknown”条目是否源于 OWA 解释。

[图 10.59](#Ch010_401-479_B9780443237904000244.xhtml#f0300)(b) 和 (c) 所示的关系模式表明，开放世界一元映射到一个可选布尔值，其真值被限制为 True。

在 NORMA 中获得此关系模式结果的一种方法是，用一个以具有布尔数据类型且限制为 True 的值类型为目标的可选 *n*:1 事实类型，替换每个一元。例如，用事实类型“Student has IsIntelligentStatus {true}”替换“Student is intelligent”，其中 IsIntelligentStatus 的角色命名为“isIntelligent”。

为一元建模 OWA 语义的另一种方法是，添加一个具有否定含义的一元，并在其角色与原始一元角色之间添加一个排斥约束。例如，添加“Student isUnintelligent”，并在其角色与“Student isIntelligent”事实类型的角色之间添加排斥约束。然而，若无法正式声明一个一元是另一个的否定，此方法将映射到带有两列的关系表，而非单列。

作为 CWA 和 OWA 之间的折中立场，*半闭世界假设* (SWA) 允许某些相关事实作为可推导事实可能是未知的，但作为断言事实则不能。这意味着*半正否定*（给定任何断言事实类型，在其中找不到事实实例意味着该实例为假；而无法证明某个可推导事实类型实例或其否定，意味着其真值为未知）。此方法仅当事实类型为断言或完全可推导（而非半可推导）时可用。

*带否定的开放世界* (OWN) 假设允许某些相关事实未知（作为断言或可推导事实），但也允许断言否定。与 OWA 一样，OWN 方法也导致经典否定，这是经典逻辑中的常用方法。尽管在数据库中断言负面事实很少见，但在逻辑系统中却很常见。OWN 方法只是 OWA 的一个特例。

在 ORM 中支持 OWN 语义的一种方法是，允许一元填充正例和负例，否定实例以波浪号“~”为前缀，该符号常用于逻辑中表示“**非**”（**并非如此**）运算符，如[图 10.60](#Ch010_401-479_B9780443237904000244.xhtml#f0305)(a) 所示。

![Fig. 10.60 Some OWN modeling options.](images/B9780443237904000244/f10-60-9780443237904.jpg)

[图 10.60](#Ch010_401-479_B9780443237904000244.xhtml#B-f0305) 一些 OWN 建模选项。

支持*开放一元的否定实例*的另一种方法是，添加一个含义相反的单独一元事实类型（其实例等同于原始一元的否定实例）。相反的含义隐含了这两个一元之间的排斥约束。例如，要记录学生 1002 不聪明，将该学生纳入事实类型“Student isUnintelligent”的实例群，并在其角色与“Student isIntelligent”事实类型的角色之间设置排斥约束。

第三种选项是用第三种建模方式替换该一元。假设我们知道澳大利亚 (AU) 和美国 (US) 是单语国家，加拿大是多语国家，但不知道塞浦路斯的语言状态。这对应于 OWN 方法，如[图 10.60](#Ch010_401-479_B9780443237904000244.xhtml#f0305)(a) 直接建模所示。[图 10.60](#Ch010_401-479_B9780443237904000244.xhtml#f0305) 的其余部分展示了在 ORM 和 UML 中建模此情况的替代方法。

针对各种开放/闭合世界方法的一元映射详细过程，请参见[第 11 章](#Ch011_481-537_B9780443237904000141.xhtml)。

原则上，对各种闭包选项的支持可扩展至一元事实类型之外，但这会增加相当大的复杂性，特别是对于非函数事实类型。
