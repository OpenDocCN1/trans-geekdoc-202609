### 如果 *B* 的角色未包含在唯一性约束中会怎样？

然而，如果通用谓词 *R* 中 *B* 的角色未包含在唯一性约束中，会发生什么？因为 *R* 是基本的，其其他角色必须由一个唯一性约束跨越；该约束被转换为跨越特化谓词的相互**排斥**约束。

互斥一元谓词提供了这种情况的最简单案例。例如，假设公司中的工人最多担任一个职位（经理、职员或秘书）。如 [图 14.7](#Ch014_681-771_B9780443237904000189.xhtml#f0040) 所示，假设谓词之间有适当的翻译，这可以用互斥一元谓词重述。对于实现，通常首选二元版本（例如，其关系模式简化了对工人职位的更新和允许职位列表的模式更新）。一元谓词的数量越多，一元解决方案就越差（为什么？）。

![图 14.7 左侧的 UC 等价于右侧的排斥约束。](images/B9780443237904000189/f14-07-9780443237904.jpg)

### 文本约束与图形约束

在罕见的模式转换情况下，一个模式中的图形约束在另一个模式中可能没有对应的图形约束。在这种情况下，该约束应在另一个版本中表示为**文本约束**。

例如，考虑 [图 14.10](#Ch014_681-771_B9780443237904000189.xhtml#f0055) 中的两个模式。代码“A”和“S”分别表示“助理”和“主管”。为简单起见，省略了引用模式。一个人可能主管一个项目并在另一个项目中担任助理。

![图 14.10 模式 (a) 中的文本约束在 (b) 中表现为图形约束。](images/B9780443237904000189/f14-10-9780443237904.jpg)

[图 14.10](#Ch014_681-771_B9780443237904000189.xhtml#B-f0055) 模式 (a) 中的文本约束在 (b) 中表现为图形约束。

假设谓词之间有适当的翻译，模式 (a) 中的唯一性约束转换为模式 (b) 中的排斥约束，且 (b) 中的顶部唯一性约束是隐含的。

(b) 中的底部唯一性约束声明每个项目最多有一个主管。这无法在三元谓词上表示为图形约束，因为它是一个**受限唯一性约束**（如 [第 7.4 节](#Ch007_273-308_B978044323790400013X.xhtml#s0035) 所述）。为确保等价性，将其作为文本约束添加到左侧模式：**Each** Project uses **at most one** Employee in Position ‘S’。

如果 Project 扮演其他功能角色，通常首选右侧模式的二元方法，因为其关系版本简化了该主管约束的实施。如果 Project 没有其他功能角色，可能首选三元方法，因为它映射到单个表。

因为模式转换定理通常应用于全局模式中的子模式，必须小心保留任何**强制角色约束**（隐式或显式）。

### 强制角色约束的映射

例如，在 [图 14.4](#Ch014_681-771_B9780443237904000189.xhtml#f0025) 中，如果 Country 不扮演其他角色，则其在模式 (a) 中的角色和 (b) 中其角色的析取是隐式强制的。如果 Country 在全局模式中扮演另一个角色，且必须为其记录至少一个奖牌结果，则必须显式显示这些简单和析取强制角色（包含或）约束（见 [图 14.11](#Ch014_681-771_B9780443237904000189.xhtml#f0060)）。

![图 14.11 (a) 中的强制约束映射为 (b) 中的包含或约束。](images/B9780443237904000189/f14-11-9780443237904.jpg)

[图 14.11](#Ch014_681-771_B9780443237904000189.xhtml#B-f0060) (a) 中的强制约束映射为 (b) 中的包含或约束。

这说明了 PSG1 定理的第三个推论：

*   如果 $A_i$ 在 *R* 中的角色（或角色析取）是强制的，则其特化角色的析取是强制的，反之亦然（$1 \le i \le m$）。

“（或角色析取）”的包含涵盖了 $A_i$ 在 *R* 中扮演多个角色的罕见情况（$A_1 \dots A_m$ 不一定不同）。还要注意，我们对隐式强制角色约束的约定如何使 PSG1 等定理能够在不对全局模式中扮演的其他角色做任何假设的情况下指定。

### 频率约束映射为等式约束

现在考虑 [图 14.12](#Ch014_681-771_B9780443237904000189.xhtml#f0065)(a)。这里，Country 的获奖角色是可选的（这意味着 Country 在一元或更长的事实类型中扮演另一个角色，但它有一个**频率约束**为 3）。因此，如果为一个国家记录了任何奖牌结果，则需要所有三个奖牌结果（金、银和铜）。为了在 [图 14.12](#Ch014_681-771_B9780443237904000189.xhtml#f0065)(b) 中表达这一点，我们在 Country 扮演的获奖角色之间添加一个**等式约束**。这是 PSG 定理第四个推论的一个实例：

![图 14.12 (a) 中的频率约束映射为 (b) 中的等式约束。](images/B9780443237904000189/f14-12-9780443237904.jpg)

[图 14.12](#Ch014_681-771_B9780443237904000189.xhtml#B-f0065) (a) 中的频率约束映射为 (b) 中的等式约束。

```
如果 R 是一个带有仅跨越 B 的角色和另一个角色的 UC 的三元谓词，则向该其他角色添加频率约束 n 等价于在该角色的特化版本上添加等式约束。
```
