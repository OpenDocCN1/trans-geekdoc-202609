
XML 是一种文本格式，虽然它可以使用文本处理操作进行操作，但使用对所表达的数据结构敏感的处理操作会更有效。数据库系统最初开始将 XML 作为一种文本格式使用，但对其价值的认可促使它被纳入 SQL 标准作为一种原生数据类型。大多数数据库供商都增加了功能来存储 XML 数据、操作 XML 数据，并在 XML 和关系表结构之间进行双向转换，有时包括官方 SQL 标准中不包含的专有扩展。

JSON 是一种比 XML 稍年轻的语言。它最初是作为 Web 服务器和浏览器之间一种相对轻量级的通信语言而开发的，使用标准浏览器功能而不是辅助插件。这使得 JavaScript 成为定义标记语言的显而易见的起点，因此 JavaScript 对象成为了该表示法的基础。

JSON 流行的一个主要因素是与 XML 相比，它的简单性和易于处理。它是一种更紧凑的格式，减少了数据传输所需的带宽；考虑到其创建的初衷，这是一个重要因素。它通常也更适合 Web 相关技术，例如在应用程序开发中。相对而言，它的表达能力不如 XML。它不支持命名空间，并且不适用于精确定义数据类型很重要的应用。然而，它被采用为文档数据库的主要构建原则，并作为原生数据类型纳入 SQL，这表明它足够健壮，能够满足广泛现实场景的需求。

XML 和 JSON 在可预见的未来将继续共存，因为两者并非彼此的直接替代品。人们很容易将 XML 刻板地描述为数据存储之外的重量级数据结构化解决方案，将 JSON 描述为轻量级解决方案，但这模糊了两者各自的一些重要特性。当然，存在一个很大的中间地带，两者都可以有效地使用，它们之间的任何选择都将基于数据结构化能力以外的因素做出。

### 章节注释

SQL 标准已被国际标准化组织 (ISO) 采纳为 ISO/IEC 9075。可从 ISO 或通过国家标准组织（如 ANSI）订购副本。由于其规模庞大（总共数千页），该标准被分为几个部分。第 2 部分（基础）和第 14 部分（SQL/XML）与本章最为相关。

JSON 作为一种数据格式比 XML 出现得晚，但它现在已确立为数据管理中的基本组成部分。JSON 的简短介绍可参见 [Basset (2015)](#Ch016_831-873_B9780443237904000207.xhtml#bb0075)。由于其起源于 JavaScript，其标准化工作归 ECMA 负责，该机构也负责 JavaScript 语言的规范（现在有时称为 ECMAScript）。JavaScript 的全面描述见 [Flanagan (2020)](#Ch016_831-873_B9780443237904000207.xhtml#bb0470)。标准副本和更多详情可在 [www.ecma-international.org](http://www.ecma-international.org) 找到。JavaScript 和 JSON 分别涵盖在标准 ECMA-262 和 ECMA-404 中。后者也已被采纳为 ISO 标准 (ISO/IEC 21778)。JSON Schema 仍在进行中，但最新状态可在 [www.json-schema.org](http://www.json-schema.org) 找到。关于 JSONPath 的更多详情，请参见 [Gössner and Bormann (2021)](#Ch016_831-873_B9780443237904000207.xhtml#bb0490)。

XML 和 JSON 功能现在已包含在主要关系数据库中，但由于不同实现之间存在差异，供应商的文档通常是最有用的资源。大多数商业系统提供可通过多种方式搜索的在线帮助。

## 17.1 NoSQL 运动的兴起

继 E.F. Codd 于 1970 年发表开创性的关系论文 ([Codd, 1970](#Ch017_875-933_B9780443237904000050.xhtml#bb0230)) 之后，直到 1980 年代商业关系数据库系统才广泛可用。从那时起，它们就成为了主导的数据存储模型。其他数据资源用于较小规模，如电子表格、文本文件等，但对于大规模数据，关系系统一直占据统治地位。

NoSQL 运动始于 2010 年代，这是对关系方法中感知到的缺陷的回应 ([Leavitt, 2010](#Ch017_875-933_B9780443237904000050.xhtml#bb0925))。值得注意的是，“NoSQL” 并不是一个特别好的名称选择。关键问题并不在于结构化查询语言 (SQL) 本身。事实上，一些 NoSQL 供应商非常努力地提供尽可能类似于 SQL 的语言。相反，NoSQL 方法依赖于非关系数据模型来提供其独特功能。有人建议将 "NoSQL" 解释为 "Not Only SQL"（不仅仅是 SQL），但这将包括各种数据库，使其完全失去意义。
