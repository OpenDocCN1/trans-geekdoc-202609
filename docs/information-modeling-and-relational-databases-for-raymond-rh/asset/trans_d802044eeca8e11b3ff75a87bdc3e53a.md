
这是一个指令，要求先计算右侧的表达式，然后将其值放置在左侧命名的变量中。如果该变量之前有值，旧值将直接被新值替换。例如，如果 `X`、`A` 和 `B` 是表值，那么语句 `X := A := B` 意味着 `X` 被赋予 `A - B` 的值。其他一些表示法使用 `=` 或 `⟵` 代替 `:=`。

一旦在关系赋值中命名，结果表可以在后续表达式中像基表一样使用。例如，要将高个子男性球员的详细信息存储在名为 `TallMalePlayer` 的表中，我们可以进行以下三次赋值。要列出这些详细信息，我们现在只需使用查询 `TallMalePlayer`。

```
MalePlayer := Player where gender = 'M'
TallPlayer := Player where height > 175
TallMalePlayer := MalePlayer ∩ TallPlayer
```

我们可以分步表述查询，在获得最终结果表的过程中使用中间表。例如：

```
NonEuroCountry := (Location where region <> 'Europe') [country]
FrenchSpeakingCountry := (SpokenIn where language = 'French') [country]
FrenchSpeakingNonEuroCountry := NonEuroCountry ∩ FrenchSpeakingCountry
```

在这里，我们的第一步是找到非欧洲国家：{Australia, Canada}。然后我们找到说法语的国家：{Belgium, Canada, France}。最后，我们取这些集合的交集，得到结果：{Canada}。

以这种方式列出查询被称为**逐步表述**。分阶段进行有时可以更容易地表述困难的查询。然而，用单个表达式表达查询可以节省一些书写工作。例如，刚才考虑的三个赋值语句可以用以下方式替换：

```
FrenchSpeakingNonEuroCountry :=
    (Location where region <> 'Europe') [country] ∩
    (SpokenIn where language = 'French') [country]
```

赋给 `FrenchSpeakingNonEuroCountry` 的冗长表表达式被称为**嵌套表述**，因为它将一个或多个查询嵌套在另一个查询内部。对于复杂查询，我们可能在脑海中或草稿纸上进行逐步表述，然后将其转换为嵌套表述。一般来说，任何能够通过一系列关系代数查询提取的信息，都可以在单个关系代数查询中指定。

请注意，投影不分配过交集。换句话说，给定表 `A` 和 `B` 以及投影列表 `p`，`(A ∩ B)[p]` 可能不等于 `A[p] ∩ B[p]`。例如，以下查询与前一个不等价（为什么？）。

```
((Location where region <> 'Europe') ∩ (SpokenIn where language = 'French')) [country]
```

该查询是非法的，因为 `∩` 的表操作数不兼容。即使 `A` 和 `B` 兼容，投影也不一定分配过 `∩` 或 `-`。如果 `A` 和 `B` 兼容，投影确实分配过 `∪`，即 `(A ∪ B)[p] = A[p] ∪ B[p]`。作为练习，您可能希望证明这些结果。

### 关系连接

概念层面的对象连接在第 4.4 节中引入，以帮助阐明外部唯一性约束的含义。我们现在考虑两个表（或同一表的两次出现）之间的关系连接操作，它使用比较运算符（`=`、`<`、`>`、`<>`、`<=`、`>=`）比较表中的属性值。

有几种连接操作，这里我们只讨论其中一些。任何连接操作中被比较的列必须定义在同一域上；它们不需要具有相同的名称。在需要区分具有相同局部名称的连接列时，我们使用它们的全限定名称。

设 `Θ` (theta) 表示任意比较运算符（`=`、`<` 等）。然后，表 `A` 和 `B` 在 `A` 的属性 `a` 和 `B` 的属性 `b` 上的 `Θ-连接` 等于笛卡尔积 `A ⨉ B`，限制在 `A.a Θ B.b` 的那些行上。我们如下所示书写此操作。大括号中显示的是一种替代的学术表示法。

```
(A ⨉ B) where c           {or A ⨝[c] B}
```

用于表达表之间属性比较的条件 `c` 称为**连接条件**。连接条件可以是复合的（例如 `a1 < b1 and a2 < b2`）。由于笛卡尔积，结果表的列数等于 `A` 和 `B` 列数之和，但由于选择操作，它通常比连接表的行数乘积少得多。

在大多数连接中，使用的比较运算符是 `=`。此时 `Θ-连接` 称为**等值连接**。因此，将 `A` 的列 `a` 中的值与 `B` 的列 `b` 中的值相等的 `A` 和 `B` 的等值连接是 `A ⨉ B` 限制在 `A.a = B.b` 的行上。如果每个表中的连接列名称不同，则无需用表名限定它们。我们如下所示书写此操作。一般来说，连接条件可能包含多个等式。

```
(A ⨉ B) where A.a = B.b

or

(A ⨉ B) where a = b       { if a, b occur in only one of A, B }
```
