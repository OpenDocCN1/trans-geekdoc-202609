
现在，假设我们尝试使用以下查询列出不驾驶福特汽车的美国人。这正确吗？请在继续阅读前自行推算结果表。

*   ```

该查询的结果同时列出了 JimO 和 Lance。该查询因两个原因而不正确。按其表述，该查询实际上询问的是驾驶非福特汽车的美国人。这与预期查询截然不同。Lance 被错误地包含在内，因为他驾驶本田（尽管他也驾驶福特）。Walter 被错误地排除在外，因为他不驾驶任何汽车。在任何行上都从未匹配指定值的条件，与在某行上匹配不同值的条件截然不同。

子查询可与 `union` 运算符结合使用以模拟*外连接*。例如，考虑查询：“列出每位员工的 empNr 和姓名以及他们的车型（如果有）”。在 SQL-92 语法中，这可以表述为：

*   ```
    select Employee.empNr, empName, carModel
    ```
*   ```
    from   Employee left outer join Drives on Employee.empNr = Drives.empNr
    ```

在 SQL-89 语法中，这可以重述如下。此处，字符串常量“ ? ”（如有需要以空格填充）被用来模拟空值，因为标准禁止将 `null` 作为 `select` 项。然而，许多方言（包括 SQL Server）确实允许我们写“`select null` …”，这有时很方便。

*   ```
    select Employee.empNr, empName, carModel
    ```
*   ```
    from      Employee, Drives
    ```
*   ```
    where Employee.empNr = Drives.empNr
    ```
*   ```
    union
    ```
*   ```
    select Employee.empNr, empName, ‘ ? ’
    ```
*   ```
    from    Employee
    ```
*   ```
    where empNr not in
    ```
*   ```
            (select empNr from Drives)
    ```

本节剩余部分讨论*量化比较子查询*。回顾一下，比较子查询可用于构造以下形式的条件：

*   ```
    expression Θ [all | some | any] (subquery)
    ```

其中 Θ 是比较运算符（例如 =, >），而 `all`、`some` 和 `any` 是量词。在没有量词的情况下，子查询必须返回单个值，这可以通过使用函数来保证（见下一节）。如果使用了此类量词，我们就得到一个量化比较子查询。这些量词具有以下含义：

| `some` | 意为 | 至少一个 |
| :--- | :--- | :--- |
| `any` | 意为 | 至少一个 |
| `all` | 意为 | 每一个（逐个取） |

因此，以下等价关系成立：

*   ```
    in            ≡            = some     ≡     = any
    ```
*   ```
    not in     ≡            <> all
    ```

为避免混淆，应使用 `in` 和 `not in` 代替其等价的量化比较，且应始终使用 `some` 代替 `any`。在 SQL 中，`some` 和 `any` 被视为同义词。然而，在英语中并非总是如此。例如，“<> any”在英语中意为“not in”，但在 SQL 中不是！要理解这一点，请自行计算以下查询的结果。

*   ```
    select countryName from Country
    ```
*   ```
    where population <> any (select population from Country)
    ```

评估子查询后，我们可以将条件表示为“population <> `any` (190000000, 1000000000, 16000000, 270000000)”。在英语中，“<> any”意为“= none”。因为每个人口数都等于其自身，我们预期不会返回任何行。但该查询返回了所有人口数，因为每个人口数都不等于某些（即至少一个）人口数，而 SQL 将“<> any”视为“<> some”。

作为量化比较的正确用法，考虑查询：哪个国家人口最多？这可以表述如下。

*   ```
    select countryName
    ```
*   ```
    from        Country
    ```
*   ```
    where population >= all (select population from Country)
    ```

请记住，`all` 被解释为分配性的“每一个，单独取”而非集合性的。查询结果正确地列出了 India。正如下一节所讨论的，max 函数也可用于将搜索条件重述为 population = (`select max`(population) `from` Country)。然而，正如稍后所讨论的，量化比较也能处理一些函数无法处理的情况（例如分组极值）。

## 12.9 SQL：标量运算符和包函数

*标量* 是一个数据值（例如数字、字符串或日期）。本节简要讨论 SQL-89 中可用的标量运算符和包函数，以及后续版本中包含的进一步运算符和函数。

在 SQL-89 中，标量运算符是四个*算术运算符* `+`、`−`、`*` 和 `/`。作为一元运算符，`+` 和 `−` 提供数字的符号（例如 `+3` 或 `−3`）。如果省略，则假定为 `+`（例如 `3 = +3`）。作为二元运算符，`+` 和 `−` 执行*加法*和*减法*。二元运算符 `*` 和 `/` 执行*乘法*和*除法*；它们没有一元版本。每个都是作用于数字的数字生成运算符。它们的操作数可以作为列名、常量、函数调用，或由这些通过算术运算符和可能的括号形成的表达式出现。标量表达式可用作 `select` 列表或搜索条件中的项。
