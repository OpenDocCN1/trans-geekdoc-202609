
因此，如果为某城市记录了任何库存数字，则必须记录所有三种驱动器类型的数字。同样，第二个角色上的频率约束 2 确保第二列中的每种驱动器类型必须出现两次。由于唯一性约束，这意味着如果为某驱动器类型记录了库存，则必须包含两个城市的数字。

频率约束、唯一性约束和值约束的组合确保了任何记录的库存数字在城市和驱动器类型方面都是*完整*的。需要一个复合事务来初始填充此事实类型，要求至少添加六个事实。

跨越事实类型两个或多个角色的频率约束称为*复合频率约束*。在这种情况下，我们用虚线将频率连接到相关角色（如果将频率数字移得足够靠近受约束角色，此虚线可能会隐藏）。如果只有两个受约束角色且它们相邻，则频率可通过虚线连接到这些角色的连接处。例如，在[图 7.3](#Ch007_273-308_B978044323790400013X.xhtml#f0020)中，事实表中的每个城市-年份组合必须出现三次。鉴于前三个角色上的唯一性约束，表中每个城市-年份组合的所有三种驱动器的销售额都必须记录。注意，这并不要求必须为两个城市记录年度销售额。示例填充仅包含一个城市，但满足所有约束。

*频率范围*也可以指定。使用“≤*n*”表示*至多 n*，其中 *n* ≥ 2。使用“≥*n*”表示*至少 n*，其中 *n* ≥ 1。使用“*n .. m*”表示*至少 n 且至多 m*，其中 2 ≤ *n* < *m*。频率下限 1 是允许的最小频率，默认假设为 1，因为列中的每个条目本身就已存在一次。由于约束适用于角色的填充而非对象类型的填充，声明出现频率为零是没有意义的。可选角色表示对象类型填充中的某些成员可能不扮演该角色。

作为示例，请参考[图 7.5](#Ch007_273-308_B978044323790400013X.xhtml#f0030)。这是会议应用程序模式的一部分。每位专家至少在一个专题组中（如强制角色所示），且至多评审五篇论文（可能为零，因为该角色是可选的）。每个有成员的专题组至少有四名且至多七名成员。因为 Panel 是独立的，我们可以在分配成员之前记录专题组的存在。每篇被评审的论文至少有两名评审人。某些论文可能尚未分配评审人。原则上，频率约束可以组合值和范围（例如，“1, 5..7”），但在实践中这极为罕见。
