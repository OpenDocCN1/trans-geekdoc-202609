
首先，第一个事实（Ann 是 Ann 的父母）必须被拒绝，因为没有人可以是他/她自己的父母。我们说父母关系是*非自反的*，并按如下方式为任意关系类型 *R* 定义此概念。这里，波浪号“~”表示逻辑“**非**”（即“并非如此”）运算符。

```
R is irreflexive  iff  ∀ x      ~xRx
```

在 [图 7.13](#Ch007_273-308_B978044323790400013X.xhtml#f0070)(b) 的点箭头图标中，带箭头的弧描绘了从对象到其自身的关系，横穿其上的竖线表示这是不允许的。*非自反约束*通过将该图标的简化版本（去掉箭头尖）连接到角色对来描绘（如果角色是连续的，则在其连接处连接），如 [图 7.13](#Ch007_273-308_B978044323790400013X.xhtml#f0070)(c) 所示。该约束口头表述为“**没有** Person 是其**自身**的父母”。ORM 1 中用于非自反约束的替代符号是“^O*ir*”。

![图 7.13 父母关系被声明为非自反。但仍有问题。](images/B978044323790400013X/f07-13-9780443237904.jpg)

[图 7.13](#Ch007_273-308_B978044323790400013X.xhtml#B-f0070) 父母关系被声明为非自反。但仍有问题。

[图 7.13](#Ch007_273-308_B978044323790400013X.xhtml#f0070)(c) 添加了非自反约束并相应地减少了实例集。注意，“非自反”比“非自反性”更强。例如，如果 Likes 是非自反的，那么没人喜欢他们自己。如果有些但并非所有人喜欢他们自己，那么 Likes 既不是自反的也不是非自反的。

非自反性是行内约束（即，通过仅检查该行即可确定某行是否违反约束）。它规定同一行的两个单元格中不得出现同一个条目。这使得该约束易于且廉价地强制执行。注意，父母关系是非自反但非排他的。例如，Bill 既可以作为 Colin 的父母出现，也可以作为 Ann 的孩子出现。

[图 7.13](#Ch007_273-308_B978044323790400013X.xhtml#f0070)(c) 仍存在一些问题。如果我们接受第一行，就应该拒绝第二行。如果 Ann 是 Bill 的父母，那么 Bill 是 Ann 的父母就不可能为真。父母关系是*非对称的*。一般来说，对于任意谓词 *R*：

```
R is asymmetric  iff  ∀ x,y (xRy  → ~ yRx)
```

即，如果第一个对象 *R* 第二个，则第二个不能 *R* 第一个。这里，如果一个人是另一个人的父母，则另一个人不能是该人的父母。说一个关系是非对称的，比说该关系非对称性更强（你可能希望将此作为练习来证明）。[图 7.14](#Ch007_273-308_B978044323790400013X.xhtml#f0075)(b) 显示了非对称性的直观图标。

![图 7.14 父母关系和汇报关系是非对称关系。](images/B978044323790400013X/f07-14-9780443237904.jpg)

[图 7.14](#Ch007_273-308_B978044323790400013X.xhtml#B-f0075) 父母关系和汇报关系是非对称关系。

*非对称约束*通过将该图标的简化版本（无箭头尖）用虚线连接到受约束的角色对来图形化描绘，如 [图 7.14](#Ch007_273-308_B978044323790400013X.xhtml#f0075)(c) 所示。强制执行此约束后，父母关系实例集如图所示减少。[图 7.14](#Ch007_273-308_B978044323790400013X.xhtml#f0075)(d) 显示了涉及子类型的另一个非对称约束示例。ORM 1 中用于非对称性的替代约束符号是“^O*as*”。

[图 7.14](#Ch007_273-308_B978044323790400013X.xhtml#f0075)(c) 省略了非自反约束。这是错误吗？不是。任何非对称的关系必须是非自反的。证明留作练习（*提示*：*x* 和 *y* 不必不同）。反之不成立。有些非自反关系不是非对称的（例如，是……的姐妹）。为避免隐含约束，如果已声明非对称性，请勿声明非自反性。

如果我们移除非自反性要求，将获得较弱的反对称性属性。例如，≤ 和 ⊆ 是*反对称的*但非非对称的。[图 7.15](#Ch007_273-308_B978044323790400013X.xhtml#f0080)(a) 中的直观图标使用不同颜色的节点来指示对象不同。该图标的简化版本（无箭头尖）用于描绘*反对称约束*，如 [图 7.15](#Ch007_273-308_B978044323790400013X.xhtml#f0080)(b) 所示。[图 7.15](#Ch007_273-308_B978044323790400013X.xhtml#f0080)(b) 底部的等价式表明，非对称性结合了反对称性和非自反性。

假设我们决定将此信息存储在 [图 7.16](#Ch007_273-308_B978044323790400013X.xhtml#f0085)(a) 所示的 has-synonym 二元事实类型中。这是自反的吗？虽然我们可能争辩说每个词都是其自身的同义词，但这是一个我们通常不感兴趣看到的平凡结果。因此，就该关系而言，让我们约定没有词是其自身的同义词。这使得该关系成为非自反的，由内环约束所示。

![图 7.16 (a) 对称且非自反，(b) 非对称事实类型的示例。](images/B978044323790400013X/f07-16-9780443237904.jpg)

[图 7.16](#Ch007_273-308_B978044323790400013X.xhtml#B-f0085) (a) 对称且非自反，(b) 非对称事实类型的示例。

如果一个词是另一个词的同义词，则另一个词也是它的同义词。所以 has-synonym 是对称的。但 [表 7.1](#Ch007_273-308_B978044323790400013X.xhtml#t0010) 违反了此条件。例如，序对（“abbreviate”，“reduce”）仅按此顺序出现。如果我们查找单词“reduce”，将不会看到“abbreviate”作为其同义词之一。这是同义词书的缺陷，计算机化同义词系统应避免此问题。如何避免此问题？

一种解决方案是添加 has-synonym 谓词为对称的约束。这在图上使用 [图 7.10](#Ch007_273-308_B978044323790400013X.xhtml#f0055) 中对称性图标的简化版本（无箭头尖）来指定，显示为 [图 7.16](#Ch007_273-308_B978044323790400013X.xhtml#f0085)(a) 中的外环约束。对称和非自反约束被组合成一个图标以节省空间。ORM 1 对对称约束使用替代符号 ^Osym。

假设已声明对称约束，表当前为空，并尝试以下更新：**添加**：Word ‘abbreviate’ has synonym Word ‘shorten’。一个简单的信息处理器会直接拒绝此操作，因为它违反了对称约束。一个复杂的处理器可能接受该事实并自动添加其逆事实：“shorten” has synonym “abbreviate”。删除操作将采用一致的方案。虽然这种方法行之有效，但它使表的大小加倍，因为每对同义词存储了两次，每种顺序一次。
