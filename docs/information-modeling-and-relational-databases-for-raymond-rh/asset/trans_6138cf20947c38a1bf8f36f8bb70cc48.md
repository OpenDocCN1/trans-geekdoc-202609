

# 章节概览

## 第 12 章：关系数据库与 SQL 查询基础

[第 12 章](#Ch012_539-646_B9780443237904000268_1.xhtml) 提供了关系数据库和 SQL 查询的基础介绍。

- [12.1 节](#Ch012_539-646_B9780443237904000268_1.xhtml#s0010) 涵盖关系代数；虽然它不作为实用的查询语言使用，但该代数对于理解 SQL 支持的基本关系操作非常重要。
- [12.2 节](#Ch012_539-646_B9780443237904000268_1.xhtml#s0060) 概述了数据的关系模型与某些关系数据库管理系统所采用的数据模型之间的比较。
- [12.3–12.14 节](#Ch012_539-646_B9780443237904000268_1.xhtml#s0065) 涵盖 SQL 的主要特性，重点关注国际标准化组织规定的标准 SQL 版本，同时也关注商业 SQL 系统。

## 第 13 章：SQL 进阶

[第 13 章](#Ch013_647-679_B9780443237904000049.xhtml) 讨论 SQL 的进阶方面（如数据定义、触发器和存储过程），并介绍安全性、元数据和并发控制等实际问题。

## 第 14 章：模式转换与优化

[第 14 章](#Ch014_681-771_B9780443237904000189.xhtml) 讨论如何以及何时在同一级别（概念或逻辑）将一个模式转换为另一个模式。

- [14.1–14.4 节](#Ch014_681-771_B9780443237904000189.xhtml#s0010) 探讨概念模式等价的概念，以及重塑概念模式的方法。
- 作为该理论的一个应用，[14.5 节](#Ch014_681-771_B9780443237904000189.xhtml#s0050) 规定了一个通过在映射前执行概念转换来优化数据库设计的过程。
- [14.6 节](#Ch014_681-771_B9780443237904000189.xhtml#s0060) 简要介绍了规范化理论，包括一些新见解。
- [14.7 节](#Ch014_681-771_B9780443237904000189.xhtml#s0070) 简要探讨反规范化和底层优化。
- [14.8 和 14.9 节](#Ch014_681-771_B9780443237904000189.xhtml#s0080) 说明概念优化在数据库重构中的作用，并以数据迁移和查询转换的讨论作为结尾。
- [14.4、14.5 和 14.7–14.9 节](#Ch014_681-771_B9780443237904000189.xhtml#s0040) 属于进阶性质，短期课程可跳过。在极短的课程中，整章均可跳过。

## 第 15 章：业务行为建模

[第 15 章](#Ch015_773-830_B9780443237904000190.xhtml) 通过使用过程模型和状态模型来检查业务的行为方面，拓展了信息系统分析的处理方式。使用 UML 中的表示形式分析过程建模和状态建模这两种主要方法。提供了使用 BPMN 标准进行过程建模的详细覆盖，以及链接过程模型和信息模型的方法论。

## 第 16 章：数据文件格式

[第 16 章](#Ch016_831-873_B9780443237904000207.xhtml) 检查各种数据文件格式，包括 `CSV`、`XML`、`JSON`、`YAML` 和其他一些标记语言。除了用于数据交换外，`XML` 和 `JSON` 现在已作为数据类型完全纳入 SQL 标准。提供了它们用法的示例，以及关于从 ORM 映射的讨论。

## 第 17 章：NoSQL 数据库

[第 17 章](#Ch017_875-933_B9780443237904000050.xhtml) 回顾了主导的关系数据库范式的替代方案，特别是“NoSQL”数据库。讨论了此类系统的动机，并单独描述了主要数据库类型。介绍了从信息模型映射到每种数据库类型的方法。本章最后提出了一些关于未来演进的进一步想法，包括人工智能的潜在影响。

## 第 18 章：其他建模方面与趋势

[第 18 章](#Ch018_935-1005_B9780443237904000104.xhtml) 检查其他建模方面和趋势。涵盖的主题包括数据仓库、概念查询语言、模式抽象机制、进一步的设计方面、本体与语义网，以及元建模。虽然这些主题重要且有趣，但短期课程中可省略。

## 本书特色

按照 ORM 方法，本书采用“食谱式”方法，包含大量图表和示例。每章以简要概述开始，以主要内容的章节总结结束，并附有章节注释以提供细节和进一步参考。

本书的主要特色之一是其大量的习题，这些习题经过了彻底的课堂测试。书末包含所有引用参考文献的书目，您还将找到 ORM、ER 和 UML（仅类图）的技术符号和术语词汇表。综合索引提供了对技术主题解释的便捷访问。

对于熟悉本书第二版的读者，现总结主要差异如下：

- ORM、ER、UML、SQL、OWL 和 BPMN 的覆盖范围已彻底更新，以涵盖其最新版本。
- 增加了大量新内容。
- 现在涵盖各种数据文件格式，如 `CSV`、`XML`、`JSON`、`YAML` 和其他一些标记语言，并为非关系型数据库（特别是 NoSQL）提供了更彻底的处理。
- 所有前几章都进行了大幅修订，几个主题的覆盖深度更大。
- 新内容导致书籍篇幅增大。

全书使用美式拼写，除两位欧洲作者的序言外。也使用美式标点规则，但引用项除外，其中项目分隔符和句子终结符（如逗号和句号）出现在右引号之后，而不是仅出现在右引号之前。
