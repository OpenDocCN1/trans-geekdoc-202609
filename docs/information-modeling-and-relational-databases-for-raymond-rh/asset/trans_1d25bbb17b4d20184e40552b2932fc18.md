`moonName` 主键清楚地表明 NORMA 仅通过月亮来标识月亮的轨道。就我们个人而言，我们不喜欢在概念层面隐藏首选标识方案的做法，我们倾向于在不使用对象化的情况下在 ORM 中对这种情况建模，使用如图 10.55(c) 或 (d) 所示的替代模式。

然而，某些用户可能仍倾向于对象化方法而非此类替代方案。将一个二元或更长的事实进行对象化，且仅有一个 UC 跨越了除一个角色外的所有角色，而该对象化扮演其他多个角色，这是唯一可能有正当理由忽略我们“永远不要在没有跨越 UC 的情况下对关联进行对象化”这一建议的情况。

到目前为止，我们讨论的对象化是指情境名词化，即所讨论的对象是一种事态（事件、活动等）。虽然在信息建模中相对罕见，但也可能遇到名词化对象是命题（由*命题名词化*产生）或*交际行为*（例如，某位说话者/作者的发话或铭文行为）的情况。

OMG 的 SBVR 规范包含对命题名词化的支持。涉及命题名词化的 SBVR 规则示例之一可以口头表述为：如果服务员通过供餐从顾客处获得小费收入，则该服务员必须报告这一事实。

虽然可以将其解释为命题名词化的情况（报告事实而非行为），但出于信息建模目的，无需这样做，因为该规则可以使用情境名词化（报告行为而非事实）轻松声明，如图 10.56 紧凑形式所示。等值约束存在于编号为 1.1、1.2、1.3 的三个角色与编号为 2.1、2.2、2.3 的三个角色之间。

```
Fig. 10.56 Replacing propositional nominalization by situational nominalization.
```

图 10.56 以情境名词化取代命题名词化。

如果规则修改为要求在服务执行后报告，则必须声明报告的时间限制以使规则具有操作性。在这种情况下，可以将相关的时间对象类型添加到模型中，以显而易见的方式满足扩展规则。为简单起见，*我们建议通过对应的情境名词化来建模所有命题名词化*。

关于交际行为的建模，当有必要对这些行为建模时，最好像建模其他业务领域对象一样直接对其建模。例如，在家谱模型中，我们可能不仅关心事态的描述，还关心研究人员关于事态的断言行为。

此类模型可能包含以下事实类型：`AssertionAct reported Proposition`、`AssertionAct was made by Researcher with ConfidenceLevel` 等。这些说明仅涉及信息模型。

对于交际过程建模，信息模型应辅以其他类型的模型（例如工作流模型），这些模型能提供更直观、直接的方式来理解基本业务流程/服务。

## 10.6 开放/封闭世界语义

在对业务领域建模时，可以就模型中所捕获知识的完整性采取不同立场。*封闭世界假设* (CWA) 假定所有相关事实均已知（即出现在模型中，无论是作为断言事实还是派生事实），且所有相关业务规则均已知。这是数据库的常用假设，并蕴含*失败即为假*（无法找到或证明某命题即意味着它为假）。

例如，考虑图 10.57(a) 中填充的 ORM 模型。共有四名学生（1001–1004），但只有两名（1001 和 1003）被建模为聪明。使用 CWA，我们可以推断学生 1002 和 1004 不聪明。同样，我们可以推断学生 1003 和 1004 不刻苦。利用断言事实和所示派生规则，我们推断三名学生（1001、1002 和 1003）预计会通过。如果没有针对事实类型 `Student is expected to pass` 的其他派生规则，则 **if** 运算符在 CWA 下被解释为 **iff**。因此，学生 1004 预计不会通过。

```
Fig. 10.57 The closed world assumption requires all facts to be modeled.
```

图 10.57 封闭世界假设要求对所有事实建模。

在封闭世界语义下，映射到关系数据库时，断言的正面事实和隐含的负面事实应分组到图 10.57(b) 所示的 Student 表中，对 `isIntelligent` 和 `worksHard` 使用强制性布尔属性。

关于通过预期的派生事实可映射到图 10.57(c) 所示 `Student_View` 表中的附加 `isExpectedToPass` 列。除了创建此视图外，还可将这些派生事实的计算列添加到基础 Student 表中。NORMA 工具目前将一元事实映射为可选的布尔列（而非强制性布尔值），因此这些列允许空值。

本书使用的关系模式符号为主键名称加下划线，可选列名称用方括号括起。因此，NORMA 将图 10.57(a) 的 ORM 模式映射为以下关系模式：`Student`( studentNr, `[isIntelligent]`, `[worksHard]` )。

计划扩展 NORMA 工具，增加对一元事实的开放/封闭世界语义的控制，并增加对否定一元事实的支持。在此期间，若要使用 NORMA 映射到强制性布尔值，可用一个针对具有布尔数据类型的值类型的强制性 `n`:1 事实类型来替换一元事实。例如，用强制性 `n`:1 事实类型 `Student has IsIntelligentStatus` 替换 `Student is intelligent` 事实类型，其中 `IsIntelligentStatus` 具有布尔数据类型。

重塑模型以实现一元事实 CWA 语义的第二种方法是，用一个针对具有恰好两个命名值的实体类型或值类型的强制性 `n`:1 事实类型来替换一元事实，例如 `Student has IntelligenceStatus(.Name)` {‘Intelligent’, ‘Unintelligent’}。
