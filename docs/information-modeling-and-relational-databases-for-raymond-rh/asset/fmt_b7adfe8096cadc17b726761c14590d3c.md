
因为这些连接列具有相同的本地名称“empNr”，所以使用限定名称来区分查询和连接结果中的列。连接列不必具有相同的（非限定）名称，但必须属于同一个域。例如，如果 `Drives` 表中的员工编号列名为“empId”，则连接条件可指定为“empNr = empId”。

等值连接包含由每个连接属性产生的两个匹配列（注意两个 `empNr` 列）。如果这些列在 UoD 中指代同一事物（通常如此），则其中一列是冗余的。在这种情况下，我们通过投影（在要删除的列之外的所有列上执行投影）删除其中一个匹配列，不会丢失任何信息。这在 [图 12.20](#Ch012_539-646_B9780443237904000268_1.xhtml#f0105) 中完成。

如果用于连接的列在两个表中具有相同的名称，则在连接结果中使用非限定名称。生成的表称为原始表的**自然内连接**。因为默认假定为“inner”，所以**自然内连接**可简称为**自然连接**（外连接稍后讨论）。这是实践中最常见的连接操作。表 *A* 和 *B* 的自然连接可写为 `A ⨝ B`，或用文字表示为“*A* **自然连接** *B*”。可总结如下。

*   计算 `A ⨝ B`：形成 `A ⨉ B`
*   对于同时出现在 `A` 和 `B` 中的每个列名 `c`
*   应用限制 `A.c = B.c`
*   删除 `B.c`
*   将 `A.c` 重命名为 `c`

无需命名连接列，因为这些列是在两个表中同名的列（当然这些列必须基于同一个域）。为帮助记忆领结符号“⨝”，请注意“⨝”看起来像一个加上两条垂直线的叉“⨉”，暗示自然连接是笛卡尔积加上两个其他操作（选择公共列值相等的行，然后投影以删除冗余列）。[图 12.21](#Ch012_539-646_B9780443237904000268_1.xhtml#f0110) 显示了驾驶示例的自然连接。注意 `empNr` 列仅出现一次且为非限定名称。

![图 12.21 自然连接。](images/B9780443237904000268/f12-21-9780443237904.jpg)

[图 12.21](#Ch012_539-646_B9780443237904000268_1.xhtml#B-f0110) 自然连接。

如果表没有共同的列名，则自然连接就是笛卡尔积。与笛卡尔积一样，自然连接具有结合性：`(A ⨝ B) ⨝ C = A ⨝ (B ⨝ C)`。因此，`A ⨝ B ⨝ C` 形式的表达式是明确无歧义的。

被连接的表可能有零个、一个或多个公共列。无论哪种情况，自然连接仅限于那些在两个表中所有公共属性具有相同值的行。*A ⨝ B* 中的列数等于 *A* 和 *B* 中列数之和，减去两者公共的列数。

迄今讨论的连接类型统称为*内连接*。我们也可以有*外连接*，用于包含各种空值情况。外连接基本上是内连接，当不满足连接条件时用填充空值的额外行。例如，给定 [图 12.23](#Ch012_539-646_B9780443237904000268_1.xhtml#f0120) 所示的数据填充，`Client` **左外连接** `AcUser` 的结果包含一行，指示客户 8005 姓名为“Shankara TA”但未使用账户（该行上 `branchNr` 和 `accountNr` 为空）。左外连接包含左侧表（即连接运算符左侧的表）中的所有客户，无论它们是否列在右侧表中。外连接将在 SQL 中详细讨论。

### 关系除法

我们考虑的下一个关系运算是关系**除法**。仅当表 *A* 的列多于表 *B* 时，表 *A* 除以表 *B* 才有意义。假设表 *A* 有两组列 *X* 和 *Y*，表 *B* 有一组列 *Y*。换句话说，*X* 是 *A* 中不在 *B* 中的列集。我们假设 *A* 和 *B* 中的 *Y* 列之间存在有序关系，以便知道 *B* 中哪一列对应 *A* 中的哪一列。
