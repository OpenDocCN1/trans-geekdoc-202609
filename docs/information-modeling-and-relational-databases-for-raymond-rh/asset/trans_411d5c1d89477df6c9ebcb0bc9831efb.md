
# SQL 连接类型与语法

右外连接类似于左外连接。全连接是左连接和右连接的并集。关键字 `outer` 在左/右/全连接中是隐含的，因此可以省略（例如 `natural left join` 或 `left join`）。外连接不满足结合律，因此在对三个或更多表进行外连接时，要小心连接顺序。正如稍后讨论的那样，外连接可以通过 `union` 和子查询在旧的 SQL-89 语法中进行模拟。

当必须比较同一表的不同行时，我们需要将表与自身连接。这种*自连接*在[第 12.1 节](#Ch012_539-646_B9780443237904000268_1.xhtml#s0010)中已讨论过。回顾一下，这需要为该表引入一个别名。在 SQL 中，*临时别名*可以在 `from` 子句中它所代替的表之后，作为*元组变量*声明。该变量可以被赋予表中的任意行，有时被称为“相关变量”、“范围变量”或“表标签”。为了清晰起见，可以使用 `as` 来引入别名。

[图 12.46](#Ch012_539-646_B9780443237904000268_1.xhtml#f0235) 提供了一个简单示例。基表 `Scientist` 存储各科学家的姓名和性别，查询列出性别相反的科学家对。别名 `S1` 和 `S2` 在 `from` 子句中声明。要理解自连接，可将 `S1` 和 `S2` 视为原始基表的副本，如图所示。条件连接对性别执行 `<>`-连接（以确保性别相反），并对 `PersonName` 执行 `<`-连接（以确保每对仅出现一次，而不是按两种顺序都出现）。

某些 SQL 版本还提供“创建同义词”命令，用于声明永久别名定义。然而，这不属于标准的一部分。以简化形式，SQL 查询的 `from` 子句语法可按以下 BNF 进行总结（对于大括号中的备选项，恰好需要一个）：

*   ```
    from table [ [as ] alias ]
    ```

*   ```
                [ , | cross join table [ [ as ] alias ]
    ```

*               | `natural` \[ `inner` | { `left` | `right` | `full` } \[ `outer` \] \] `join` table \[ \[`as` \] alias \]

*   ```
                                        | [ inner | { left | right | full } [ outer ] ] join table [ [ as ] alias ]
    ```

*   ```
                                                                        { on condition | using ( col-list ) }
    ```

*   ```
                                        | union join table [ [ as ] alias ]
    ```

*   ```
                                        [ ,... ] ]
    ```

在构思 SQL 查询时，关系代数中讨论的指导原则通常适用。首先，用英语清晰地陈述查询。然后尝试自己解决查询，观察你是如何做到的。然后将你的步骤形式化为 SQL。这通常包含以下步骤。

哪些表包含所需信息？在 `from` 子句中命名这些表。你想要哪些列，以及按什么顺序？在 `select` 列表中命名这些列（如有必要请加上限定符）。如果 `select` 列表不包含键，而你希望避免重复行，请使用 `distinct` 选项。

如果你需要 *n* 个表，请指定 *n − 1* 个连接条件。你想要哪些行？在 `where` 子句中指定搜索条件。你想要行按什么顺序排列？为此使用 `order by` 子句。

SQL-92 中引入的新连接语法很方便，但在功能方面增加的不多。最有用的表示法是条件连接和自然连接（包括内连接和外连接）的表示法。

如果你使用的 SQL 版本不支持新语法，你应该特别小心，详细指定连接条件，并在需要时限定列名。

任何 SQL 语句都可以包含*注释*。这些可用于解释、文档记录，或仅仅是为了调试而注释掉某些代码（注释在执行时会被忽略）。

在 SQL-92 中，注释以两个连续的连字符“--”开始，并在行尾结束。除了这些单行注释外，SQL:1999 还引入了多行注释，以“/*”开始，以“*/”结束。SQL Server 同时支持这两种注释风格。示例如下：

```
 -- 此查询检索开车的员工详情select *        -- 选择所有列from Employee natural join Drives /* 如果不支持自然连接语法，         则省略 "natural"，并在 on-子句 中指定连接条件 */
```

# 12.7 SQL：`in`、`between`、`like` 和 `is null` 运算符

本节探讨 SQL 提供的四种特殊运算符（除比较运算符 `=`、`<` 等外），用于搜索条件中：`in`；`between`...`and`...；`like`；和 `is null`。在 SQL 标准中，这些有时被称为函数，而它们用于表达的条件被称为“谓词”。

函数是指接受零个或多个值作为参数并返回单个值作为结果的东西。你可能从数学或编程中熟悉函数，例如 `cos(x)` 或 `sqrt(x)`。正如这些示例所示，从语法上讲，函数通常表示为函数标识符位于其参数之前，参数通常包含在括号中。
