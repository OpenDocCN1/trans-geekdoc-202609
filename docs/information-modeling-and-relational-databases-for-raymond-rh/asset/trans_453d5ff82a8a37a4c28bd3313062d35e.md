## 11.4 高级映射方面

上一节讨论了默认关系映射过程（`Rmap`）的主要步骤。该过程的步骤 0 可细化如下。本节将按顺序讨论这些细化并阐明一些细节。若需要，初次阅读时可跳过本节。

| *Rmap 步骤 0：* | | |
| --- | --- | --- |
| `0.1` | | `转换相反一元谓词；基于其开放/封闭语义映射一元谓词。` |
| `0.2` | | `在脑海中擦除所有参考（优先标识）谓词。` |
| | | `将组合标识的对象类型视为“黑盒”。` |
| `0.3` | | `指示子类型的任何吸收覆盖（分离或分区）。` |
| `0.4` | | `识别任何必须存储的推导事实类型。` |
| `0.5` | | `指示对称 1:1 情况的映射选择。` |
| `0.6` | | `考虑使用人工标识符、连接标识符或强制默认值来替换任何析取参考方案。` |
| `0.7` | | `指示无跨越唯一性约束的对象化关联所需的映射选择。` |

关于步骤 0.1 的背景，请参见[第 10.6 节](#Ch010_401-479_B9780443237904000244.xhtml#s0060)中关于开放/封闭世界语义的讨论。两个含义相反的一元谓词（例如 `Person is male`、`Person is female`）应替换为单个封闭世界一元谓词（例如 `Person is male`）或一个强制二元谓词（例如 `Person is of Gender {'M', 'F'}`）。

此后，互斥的一元谓词应替换为二元谓词。例如，在[图 11.33](#Ch011_481-537_B9780443237904000141.xhtml#f0170)(a) 中，一元谓词的析取是可选的，因此某些申请可能仍待决策。在[图 11.33](#Ch011_481-537_B9780443237904000141.xhtml#f0170)(b) 中，一元谓词被转换为单个二元谓词，申请状态由代码标识（`S = Succeeded` 成功，`F = Failed` 失败，`P = Pending` 待定）。此转换被理解为在 `Rmap` 其余部分之前自动作为预处理阶段执行。
