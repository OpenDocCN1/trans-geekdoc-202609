## 7.3 环约束

当谓词中的两个角色由同一对象类型扮演时，从该对象类型经过角色对再回到该对象类型的路径形成一个“环”。如果角色由具有共同超类型的子类型扮演，则从超类型出发并回到超类型的路径也形成一个环。该角色对通常形成一个二元谓词，称为*环谓词*，但也可能是较长谓词的一部分（参见[图 7.7](#Ch007_273-308_B978044323790400013X.xhtml#f0040) 中的阴影角色对），甚至可能来自连接路径中的不同谓词（连接约束将在[第 10 章](#Ch010_401-479_B9780443237904000244.xhtml)中讨论）。*环约束*可能仅适用于此类角色对。

![图 7.7 环约束可能适用于阴影角色对。](images/B978044323790400013X/f07-07-9780443237904.jpg)

[图 7.7](#Ch007_273-308_B978044323790400013X.xhtml#B-f0040) 环约束可能适用于阴影角色对。

在[图 7.8](#Ch007_273-308_B978044323790400013X.xhtml#f0045)中，谓词 *R* 可能是通过在角色 *r*[1] 和 *r*[2] 上投影从较长谓词获得的，*A* 可能是扮演 *r*[1] 和 *r*[2] 的对象类型的超类型。对于数据库的每个状态，pop(*r*[1],*r*[2]) 是一组有序对，因此是类型 *R* 的一种关系。允许派生关系和断言关系。

![图 7.8 环二元谓词（可能嵌入在较长的事实类型中）。](images/B978044323790400013X/f07-08-9780443237904.jpg)

[图 7.8](#Ch007_273-308_B978044323790400013X.xhtml#B-f0045) 环二元谓词（可能嵌入在较长的事实类型中）。

考虑[图 7.9](#Ch007_273-308_B978044323790400013X.xhtml#f0050)(a)中的模型。为简单起见，假设该 UoD 中的人由其名字标识。在这里，每个人都喜欢他/她自己。假设在我们的 UoD 中，这对所有可能的总体都成立——扮演喜欢角色或被喜欢角色的每个人都必须喜欢他/她自己。在这种情况下，Likes 谓词被称为*局部自反的*（或在其总体上自反）。如果我们仅从[图 7.9](#Ch007_273-308_B978044323790400013X.xhtml#f0050)(a)中删除第三行，那么 Bill 就不喜欢自己，该关系也就不是自反的。中缀表示法“*xRy*”（读作“*x R y*”）意味着 *x* 与 *y* 具有关系 *R*。使用上述一般意义的 *R*，用“→”表示“*蕴含*”，用 ∀ 表示*全称量词*（读作“对于每一个”），我们定义：

![图 7.9 (a) 局部自反约束，和 (b) 纯自反约束。](images/B978044323790400013X/f07-09-9780443237904.jpg)

[图 7.9](#Ch007_273-308_B978044323790400013X.xhtml#B-f0050) (a) 局部自反约束，和 (b) 纯自反约束。

```
R 是局部自反的 当且仅当 ∀ x,y (xRy → xRx)
R 是纯自反的 当且仅当 ∀ x,y (xRy → x = y)
```

如果我们将对象描绘为黑点，将 Likes 描绘为箭头，则可以将这种自反描绘为一条从同一对象开始并结束于同一对象的关系线，如[图 7.9](#Ch007_273-308_B978044323790400013X.xhtml#f0050)(a)左侧所示。*局部自反约束*使用该图标的简化版本（移除箭头尖），附着在角色对上显示。*纯自反约束*在圆圈内添加一条垂直笔画，如[图 7.9](#Ch007_273-308_B978044323790400013X.xhtml#f0050)(b)所示。

许多重要关系都是自反的（例如 =、≤、平行于、蕴含）。在 UoD 中对所有事物都自反的关系被称为*全局自反的*（或*完全自反的*），即对于所有 *x*，*xRx*。在上述四个例子中，只有“=”是全局自反的。例如，“蕴含”针对命题定义，而非针对人。当我们说“自反”时，通常指局部自反。在实践中，纯自反约束很少见，而全局自反约束极其罕见，以至于对象角色建模（ORM）不支持它们。

现在，考虑一个 UoD，其中喜欢某人的人也会被那个人喜欢。一个满足的总体包含三个事实：Ann 喜欢 Bill；Bill 喜欢 Bill；Bill 喜欢 Ann（见[图 7.10](#Ch007_273-308_B978044323790400013X.xhtml#f0055)(a)）。在这里，给定任意人员 *x* 和 *y*，不一定不同，如果 *x* 喜欢 *y*，则 *y* 喜欢 *x*。如果这总是成立，则 Likes 是*对称的*。[图 7.10](#Ch007_273-308_B978044323790400013X.xhtml#f0055)(a)中的点箭图传达了这样一种思想：如果关系在一个方向上成立，则在另一个方向上也成立。*对称约束*使用该图标的简化版本（移除箭头尖），附着在角色对上显示，如图所示。我们对任意谓词或关系 *R* 定义此概念如下：

![图 7.10 对称环约束。](images/B978044323790400013X/f07-10-9780443237904.jpg)

[图 7.10](#Ch007_273-308_B978044323790400013X.xhtml#B-f0055) 对称环约束。

```
R 是对称的 当且仅当 ∀ x,y (xRy → yRx)
```

现在考虑一个 UoD，如果一个人喜欢第二个人，而第二个人喜欢第三个人，那么第一个人必须喜欢第三个人。在这种情况下，我们说 likes 是*传递的*。该定义包括人员相同的情况。[图 7.11](#Ch007_273-308_B978044323790400013X.xhtml#f0060)(a)中的填充模式说明了这一性质。

![图 7.11 传递环约束。](images/B978044323790400013X/f07-11-9780443237904.jpg)

[图 7.11](#Ch007_273-308_B978044323790400013X.xhtml#B-f0060) 传递环约束。

[图 7.11](#Ch007_273-308_B978044323790400013X.xhtml#f0060)(a)中的点箭图表明，如果存在一条关系链，则该关系也适用于链的第一个成员到最后一个成员。*传递约束*使用该图标的简化版本（移除箭头尖），附着在角色对上显示。一般来说，传递性可以定义如下。这里我们用“&”表示“与”，并规定“&”优先于“→”（因此先计算 & 运算）。注意 *x*、*y* 和 *z* 不必不同。

```
R 是传递的 当且仅当 ∀ x,y,z [(xRy & yRz) → xRz]
```

我们将其作为练习留给读者证明：一个既对称又传递的关系在其总体上也必须是自反的。一个既自反、对称又传递的关系被称为“RST 关系”或“等价关系”。经典例子是恒等关系“=”。不等关系“≠”仅是对称的，而小于关系“<”仅是传递的。

自反性、对称性和传递性等关系特性可以被视为约束，因为它们限制了允许的关系。然而，此类特性是*正向的*，更多时候用于*推导*额外事实，而非约束现有事实。

我们现在考虑*负向*关系特性，如非自反性和反对称性。给定某些事实的存在，此类负向特性意味着某些其他事实的不存在。此类特性最好作为简单约束来处理。一个例子将有助于理清概念。请看[图 7.12](#Ch007_273-308_B978044323790400013X.xhtml#f0065)中填充的父母事实类型，看看你能否发现有什么不对劲。

![图 7.12 这里有什么不对劲？](images/B978044323790400013X/f07-12-9780443237904.jpg)
