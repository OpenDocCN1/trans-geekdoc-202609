
最强大的 `insert` 语句形式允许我们一次性将多行插入到表中。其基本语法是：

```
insert into tablename [ (col-list ) ]
select-query
```

这将插入从子查询返回的行集合。这有很多用途，例如制作表的副本，或临时存储连接结果以加快后续查询。例如，考虑在 [图 12.63](#Ch012_539-646_B9780443237904000268_2.xhtml#f0320) 中之前图示化的软件零售商数据库模式。现在，假设我们想运行许多关于数据库产品销售的查询。为了便于此操作，我们可以创建一个名为“DBsales”的合适表，然后填充它，如下所示：

```
insert into DBsales
select *
from  Invoice natural join LineItem natural join Item
where category = ‘DB’
```

出于给定时期（例如 1 周）的分析目的，可能可以忽略对底层基表的更新。现在可以在 DBsales 上制定查询，而无需承担原始连接的性能开销。这种方法用于数据仓库。

现在，让我们考虑如何 `delete rows`（删除行）。在 SQL 中，`delete` 语句用于从表中删除部分或全部行。删除后，表结构仍然存在（直到执行相关的 `drop table` 命令）。`delete` 语句的基本语法是：

```
delete from tablename
[where condition]
```

这里有两个基于我们零售商数据库的示例：

```
delete from Item              -- 删除 Item 表中的所有行
```

```
delete from Item
where category = ‘DB’   -- 从 Item 中删除所有数据库商品行
```

接下来，让我们考虑如何 `update rows`（更新行）（即更改现有行中的一个或多个值）。在 SQL 中，`update` 语句用于修改行。其基本语法如下所示。在 SQL-89 中，表达式必须是标量表达式、`null` 或 `default`。标量表达式可能包含列名、常量和标量运算符。

```
update tablename
set colname = expression   [, …]
[where condition]
```

例如，考虑表模式 `Employee` (empNr, …, job, salary)。以下语句给所有薪资低于 50,000 美元的建模师增加 5% 的薪资：

```
update Employee
set salary = salary * 1.05
where job = ‘Modeler’
and salary < 50000
```

由于 `insert`、`delete` 和 `update` 命令具有批量更新的能力，因此拥有用于撤销（回滚）和安全性（例如，授予相关访问权限）的工具至关重要。

## 12.14 总结

关系模型的数据操纵方面包括关系代数和关系赋值（`:=`）。除了在表达条件时使用逻辑和比较运算符外，代数还包括九种基本表操作。比较运算符优先于逻辑运算符，逻辑运算符优先于表运算符。

[表 12.3](#Ch012_539-646_B9780443237904000268_1.xhtml#t0020) 列出了运算符的六个优先级：`=`、`<>`、`<`、`>`、`<=`、`>=`；`not`；`and`；`or`；选择（`where` …）和投影（`[ ]`）；最后是 `union` ∪、`intersection` ∩、`difference` −（在 SQL 中称为 `except`）、`Cartesian product` ⨉、`natural join` ⨝ 和 `division` ÷。括号可用于覆盖此顺序。学术期刊中常用的符号显示在左侧，我们的符号显示在右侧。

*   `σ[c](T) ≡ T where c`
*   `π[a,b,…](T) ≡ T [a,b,…]`
*   `A ⨝[c] B ≡ (A ⨉ B) where c`

同一优先级上的运算符具有左结合性（按其在表达式中出现的顺序从左到右求值）。我们的优先级约定旨在尽量减少括号的使用，且比其他一些正在使用的约定更强。如果有疑问，或者纯粹为了清晰起见，请随意添加额外的括号。

`关系型 DBMS` 以关系表作为其唯一的基本数据结构，并支持关系选择、投影和连接，而无需指定访问路径。

SQL 是关系型 DBMS 中使用的主导语言，多年来各个版本已被标准化，最新的是 SQL:2023。大多数商业 SQL 方言支持所有 SQL-89 功能、SQL-92 和 SQL:1999 中部分额外功能，以及它们自己的一些特殊功能。

数据库对象（如表和列）可以使用标准标识符或分隔标识符（允许双引号内包含任意字符）来命名。数据库字段可以用预定义数据类型（例如 `varchar(20)`）来定义。SQL:1999 增加了用户定义类型、行类型、引用类型和数组。SQL:2003 增加了对 `multiset`（包）作为集合类型的支持，以及 `bigint` 和 `xml` 数据类型。

SQL:2016 增加了对行模式匹配、多态表函数以及存储在字符字符串字段中的 JSON 数据操作的支持。SQL:2019 增加了对多维数组（MDarray 类型和运算符）的支持。

SQL:2023 ([https://www.iso.org/standard/76584.html](https://www.iso.org/standard/76584.html)) 修订版增加了许多可选功能（唯一约束中的空值、字符串填充函数等）、对 JSON 的更深层支持，以及对属性图查询（SQL/PGQ）的支持。

用于查询的 SQL `select` 语句具有以下基本语法。

```
select [all | distinct] * | expression [[as] column-alias ] [,…]
from table [[as] alias]
[, | cross join table [[as] alias]
| natural [inner | {left | right | full} [outer]] join table [[as] alias]
| [inner | {left | right | full} [outer]] join table [[as] alias]
{ on condition | using (col-list) }
| union join table [[as] alias]
[,...]]
[where col-condition]
[group by colname [,...]
[having group-condition]]
[union | intersect | except ...]
[order by col [asc | desc] [,...] ]
```
