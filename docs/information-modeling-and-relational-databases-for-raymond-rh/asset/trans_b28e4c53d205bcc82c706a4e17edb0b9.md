### 1. Terry 的铁路

在 Terry 的铁路中，每列火车由恰好一台机车和恰好一列车厢编组（铁路车辆的有序集合）组成。每节车厢被分为一等、二等或三等。车厢可能当前不属于任何列车。列车、车厢和机车通过编号进行标识。同一台机车可以牵引多列火车。

#### (a)
同一节车厢可能属于多列火车（例如，上午列车使用的车厢下午可能用于另一列不同的火车）。然而，同一个车厢编组只能用于一列火车。使用集合类型构造器在 ORM 中对此进行建模。

#### (b)
不使用集合类型构造器，对 (a) 中描述的领域进行建模。

#### (c)
假设现在每列火车由其编组唯一确定（即其机车和车厢编组）。为了捕获这一点，是否需要更改你对 (a) 的模型？请解释。

#### (d)
能否在你对 (b) 的解决方案中以图形方式捕获这一额外约束？回答是或否。

#### (e)
领域发生变化，使得每节车厢最多属于一列火车。能否将此规则作为图形约束（不添加事实类型）添加到你对 (a) 的解决方案中？回答是或否。

#### (f)
重新建模你对 (b) 的解决方案，以确保 (e) 中的规则以图形方式表达。

#### (g)
如果 (c) 中的编组约束也适用于你对 (f) 的解决方案，是否需要向该解决方案添加进一步的约束？回答是或否。

## 10.5 名称化与对象化

粗略地说，对象化或嵌套将关系实例视为其自身的一个对象，因此可以像谈论任何其他对象一样谈论它。在 UML 中，这称为重新化，即将关联的实例对象化为关联类的实例。ORM 和 UML 中对象化的基本概念分别在第 [4 章](#Ch004_111-158_B9780443237904000232.xhtml) 和第 [9 章](#Ch009_347-399_B9780443237904000013.xhtml) 中进行了讨论。工业级 ER 通常不提供对对象化的支持。某些学术版本的 ER 支持对象化，但通常带有限制（例如，对象化的关系可以有属性，但不能参与其他关系）。

本节将更深入地探讨对象化，首先区分两种名称化，然后考虑一元事实类型的对象化，以及具有不跨越其所有角色的唯一性约束的二元或更长关联的对象化。

我们将*名称化*视为使用与原句中相应动词在形态上相关的名词短语，将陈述句重新表述。陈述句可以用不同的方式进行名称化。

一种常见的方法是使用源自原动词或动词短语的动名词（动词名词）。例如，“Elvis sang the song 'Hound Dog'”（猫王演唱了歌曲《猎犬》）可以名称化为“Elvis's singing of the song 'Hound Dog'”（猫王对歌曲《猎犬》的演唱）。另一种方法是引入代词或描述来指代原句（例如，“that Elvis sang the song 'Hound Dog'”即“猫王演唱了歌曲《猎犬》这一事实”或“the fact that Elvis sang the song 'Hound Dog'”）。

在哲学中，通常将生成的名称化解释为命名相应的*事态*或*命题*。在语言学中，有时会包含更多替代方案。例如，事态可能被区分为事件和情境。

为了信息建模的目的，我们采用哲学方法，忽略更细微的语言学区别，将所有名称化归类为两大类。

*情境名称化*指代所建模业务领域中的一种事态或情境。*命题名称化*指代一个命题。我们将事件（瞬时的）和活动（短或长持续时间）视为事态的特例。

事态、命题、句子和交际行为之间的关系长期以来一直是哲学争论的主题。在一个极端，事态和命题有时被认为是同一的。一些人认为逻辑本质上关注句子与事态之间的联系，而另一些人则认为其焦点是作为抽象结构的命题。我们对其中一些问题的观点是由建模信息系统的务实需要驱动的，现总结如下。

我们将命题定义为当陈述句被说出或书写时所断言的内容。一个命题（例如，猫王演唱了《猎犬》）必须为真或为假（因此是*真值承载者*）。

直觉上，说一种事态（例如，猫王对《猎犬》的演唱）是真或假似乎是不对的。相反，一种事态是实际的（发生在现实世界中，是事实）或非实际的。一种事态可能是可能的或不可能的。某些可能的事态可能是实际的（发生在现实世界中）。

因此，事态是*真值制造者*，因为真命题关乎实际的事态。同情于真理的对应论，我们将命题与事态之间的关系视为*对应*而非同一。

尽管自然语言在特定名称化短语的用法所指称的内容（事态或命题）上可能存在歧义，但通常可以从名称化被使用的上下文（即用于谈论它的逻辑谓词）中确定其意图含义。

请考虑以下示例：

| 示例 | 说明 |
| :--- | :--- |
| Elvis sang the song "Hound Dog" | -- 原始命题 |
| Elvis's singing of the song "Hound Dog" is popular | -- 实际事态 |
| That Elvis sang the song "Hound Dog" is well known | -- 真命题 |
| That Elvis sang the song "Hound Dog" is a false belief | -- 假命题 |
| It's snowing outside | -- 原始命题 |
| It's true that it's snowing outside | -- 命题 |
| That snowing is beautiful | -- 事态 |

指示代词“that”的前三种用法导致命题名称化。在最后一个示例中，“that”与动名词“snowing”结合使用，指代一种事态（命题不是美的）。在前两句中，“snowing”是现在分词，而非动名词。
