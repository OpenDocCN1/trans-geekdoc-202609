
```
select carType from Employee order by carType
```

这将返回序列“Ford”、“Ford”、“Toyota”，前面或后面跟着两个 null 值，具体取决于实现。

如果所选的排序列没有唯一性约束，则可以通过在 `order by` 子句中指定更多列，在其重复值内获得进一步的排序。`order by` 子句中列在前面的标准优先排序。对于任何特定列，均可应用升序或降序选项。例如，形式如下的查询：

```
select * from T order by a, b desc
```

首先按 `a` 的升序对行进行排序，然后将具有相同 `a` 值的每组行按 `b` 的降序排序。例如，请参见 [图 12.39](#Ch012_539-646_B9780443237904000268_1.xhtml#f0200)。这里女性排在前面，因为“F” < “M”，并且在每个性别内，姓名按字母逆序显示。

![图 12.39 依据两个标准排序。](images/B9780443237904000268/f12-39-9780443237904.jpg)

[图 12.39](#Ch012_539-646_B9780443237904000268_1.xhtml#B-f0200) 依据两个标准排序。

请注意在 [图 12.39](#Ch012_539-646_B9780443237904000268_1.xhtml#f0200) 中，`desc` 具有*最小后向作用域*，仅适用于 `firstname`，而不适用于 `gender`。如果两者都需要降序，我们将使用 `gender desc`、`firstname desc`。如果 `order by` 列表中的某项未用 `asc` 或 `desc` 选项限定，则默认始终假定为 `asc`。因此，要按性别升序然后姓名升序列出，我们可以只使用 `gender`、`firstname`，因为这被视为 `gender asc`、`firstname asc` 的缩写。要测试您的理解，请看看能否预测 [图 12.40](#Ch012_539-646_B9780443237904000268_1.xhtml#f0205) 中查询的结果，然后对照所示表格核对您的答案。

```
order by starsign asc, gender desc, birthyr asc
```

让我们用术语 `colname` 表示列名，用 `col` 表示列规范（按名称或编号）。迄今为止所涉及的 `select` 语句的那部分语法可用 EBNF 概括如下。虽然列别名可以在 `select` 项后立即引入而无需使用 `as`，但最好在这类情况下包含 `as`，因为这有助于可读性。

```
select [all | distinct] * | colname | constant [[as] column-alias] [,...] from tablename where condition order by col [asc | desc] [,...]
```

## 12.6 SQL：连接

我们已经了解了如何从单个表中选择和排序列与行。但假设我们从单个查询中所需的信息分散在许多表中。SQL 提供了两种主要方法来访问此类信息。第一种使用关系**连接**，将在本节中讨论。第二种涉及子查询，将在后面的章节中介绍。

表的*交叉连接*（笛卡尔积）将一个表的所有行与另一个表的所有行进行配对。在 SQL-89 中，通过在 `from` 子句中列出表，使用*逗号*“,”作为笛卡尔积运算符（关系代数中的 ⨉）来指定交叉连接。*条件连接*（Θ-连接）仅从笛卡尔积中选择满足指定条件的那些行。在 SQL-89 中，条件在 `where` 子句中指定。因此，[表 12.7](#Ch012_539-646_B9780443237904000268_1.xhtml#t0040) 中的查询表达式是等价的。

SQL-89 语法有缺点。首先，它无法区分连接条件（表间比较）和非连接条件（同一基础行上的表内比较），而是将它们混在一个 `where` 子句中。

其次，它使用逗号表示交叉连接操作。这不直观，而且让逗号承载了不同的含义（重载）。第三，它没有为外连接等操作提供任何直接支持，而外连接可能出现在实际查询中。

由于这些原因，SQL-92（及更高版本）对各种连接使用特殊语法。除了支持 SQL-89 语法外，新标准还包含以下连接类型的特殊符号（此处，“--”后的任何文本均为注释）：

```
cross join
```

```
qualified join:            conditional join                     -- on clause
```

```
                                  column-list join                    -- using clause
```

```
natural join
```

```
union join
```

合格连接和自然连接可进一步分为以下类型：

```
inner             -- 这是默认值
outer:   left         right         full
```
