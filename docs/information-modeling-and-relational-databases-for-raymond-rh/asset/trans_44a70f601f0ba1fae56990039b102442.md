

# 序列与集合

## 序列

通常，当顺序变得重要时，重复也随之变得重要。在这种情况下，我们得到一个**序列**（也称为列表、排列或元组）。因此，序列是一个有序的包。序列通常用圆括号或尖括号界定，例如 `(1,2)` 或 `〈1, 2〉`。序列 `(6, 3, 6)` 有三个成员，且不同于序列 `(3, 6, 6)`。序列的基数是其成员数量，包括重复项。例如，`#(3, 6, 6) = 3`。在实践中，使用几种不同的界定符号。例如，`[`、`]` 在 Pascal 中用作集合界定符，在 Prolog 中用作列表界定符。

## 集合枚举与范围

如果一个集合被完全枚举，则顺序无关紧要。然而，自然排序通常提供了一种明显的模式；在这种情况下，部分枚举可以定义该集合。例如，十进制数字集合可以表示为 `{0..9}`，其中 `..` 表示缺失的数字。这里，`0..9` 通常称为**范围**。无限集合可以在一端或两端用 `..` 表示。例如，自然数集合可以表示为 `{1, 2, 3..}`。

## 外延定义与内涵定义

前面的集合定义完全或部分地枚举了集合的外延，因此是**外延定义**的例子。集合也可以通过**内涵定义**来定义。这里，通过一个仅适用于集合成员的属性来声明*内涵*或含义。也就是说，给出一个描述，该描述构成了一个项目属于该集合的必要且充分条件（即“当且仅当条件”）。

例如，外延定义为 `{1,2,3}` 的集合 *A*，可以内涵定义为 *A* = 小于 4 的自然数集合。该定义可以用集合构造符号重述为 `{x: x is a natural number less then 4}`，或更简略地表示为 `{x: x ∈ ℕ & x < 4}`，其中 `∈` 缩写为“是……的成员”，`ℕ` 是自然数集合。在集合构造符号中，竖线 `∣` 可代替冒号使用，例如 `{x∣ x < 4}`。

## 命题形成运算符

一些集合运算产生命题，而另一些产生集合。请注意以下**命题形成运算符**：`=`、`≠`、`⊆`、`⊂`、`⊇` 和 `⊃`。它们分别读作“等于”、“不等于”、“是……的子集”、“是……的真子集”、“是……的超集”和“是……的真超集”。

## 子集与超集

给定任意集合 *A* 和 *B*，我们称 *A* 是 *B* 的**子集**，当且仅当 *A* 的每个成员也是 *B* 的成员。例如，`{1,3} ⊆ {1, 2, 3}`。一个等价的定义是：*A* 是 *B* 的子集，当且仅当 *A* 没有不在 *B* 中的成员。这个第二个定义使得很容易看出**空集**是每个集合的子集。空集没有成员，可以表示为 `{}` 或 `∅`。

每个集合都是其自身的子集。例如，`{1, 3} ⊆ {1, 3}`。我们称 *A* 是 *B* 的*真子集*，当且仅当 *A* 是 *B* 的子集但不等于 *B*。例如，`{1, 3} ⊂ {1, 2, 3}`。我们称 *A* 是 *B* 的**超集**，当且仅当 *B* 是 *A* 的子集；称 *A* 是 *B* 的*真超集*，当且仅当 *B* 是 *A* 的真子集。例如，`{1, 2, 3}` 既是 `{1, 3}` 的超集，也是其真超集。

## 欧拉图

两个集合之间的比较关系通常用**欧拉图**描绘。由瑞士数学家莱昂哈德·欧拉（Leonhard Euler，1707–1783 年）开发，这些图表具有*空间性*和*存在性*。每个集合被描绘为椭圆内的一组点。这使得集合之间的关系可以通过椭圆的空间排列来“看见”。例如，将椭圆 *A* 放在 *B* 内部表明 *A* 是 *B* 的真子集（参见[图 6.1](#Ch006_211-271_B9780443237904000025.xhtml#f0010)）。在这里，我们看到 *A* 的每个元素也是 *B* 的元素（因此 *A* 是 *B* 的子集）。存在性观点意味着欧拉图中的每个区域都包含一些元素。因此，*B* 有一些不在 *A* 中的元素。因此 *A* 是 *B* 的真子集。

## 假设欧拉图 (HED)

子集关系的概念比真子集关系更有用。部分为了在单个图表上描绘此类关系，我们使用**假设欧拉图**（HED）。在 HED 中，在区域中放置星号表示该处存在元素，而对区域进行阴影处理表示该区域为空。如果区域未标记，则该区域是否存在元素的问题保持开放或假设状态。[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020) 显示了两个集合之间六种最重要比较的 HED。

![图 6.3 集合比较的假设欧拉图。](images/B9780443237904000025/f06-03-9780443237904.jpg)

[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#B-f0020) 集合比较的假设欧拉图。

[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(a) 显示*相等*或*同一性*（例如，*A* = *B* = {1,2}）。在[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(b)中，*A* 和 *B* 是*不相交*或*互斥*的；即它们没有共同成员（例如，*A* = {1}，*B* = {2}）。在[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(c)中，*A* 是 *B* 的*子集*（等价地，*B* 是 *A* 的超集）。在[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(d)中，*A* 是 *B* 的*真子集*（因此 *B* 是 *A* 的真超集）。例如，*A* = {1}，*B* = {1, 2} 和 *A* = {1}，*B* = {1} 都是子集关系的实例，但只有前者是真子集关系的实例。[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(e) 显示*重叠*：集合有一些共同成员。[图 6.3](#Ch006_211-271_B9780443237904000025.xhtml#f0020)(f) 显示*真重叠*：集合既有共同成员又有额外成员。例如，*A* = {1, 2}，*B* = {2,3} 和 *A* = {1}，*B* = {1, 2} 都是重叠的实例，但只有前者是真重叠的情况。

## 集合形成运算

现在让我们考虑**集合形成运算**，其结果是一个集合。给定任意集合 *A* 和 *B*，我们定义 *A* ∪ *B*（即 *A* 并 *B*）为 *A* 或 *B* 中所有元素的集合，这里的“或”指包含性或。*A* ∩ *B*（即 *A* 交 *B*）是 *A* 和 *B* 共有的所有元素的集合。这些运算中的每一个都是可交换的，因此操作数的顺序无关紧要。即 *A* ∪ *B* = *B* ∪ *A* 且 *A* ∩ *B* = *B* ∩ *A*。

**集合差集**（或相对补集）运算定义如下：*A* − *B*（即 A 减 B）是属于 *A* 但不属于 *B* 的所有元素的集合。该运算不可交换（即可能出现 *A* − *B* ≠ *B* − *A* 的情况）。如果令 U = **全集**（即考虑范围内的所有元素的集合），我们定义 *A* 的**补集**为 *A′* = U − *A*。*A* 和 *B* 的**对称差集**是仅属于 *A* 或 *B* 中的一个的元素集合（即并集减去交集）。
