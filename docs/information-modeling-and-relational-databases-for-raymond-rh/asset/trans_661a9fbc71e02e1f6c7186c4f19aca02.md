因为先计算 `and` 运算符，再计算 `or`，所以此查询被解释为：Player **where** (gender = ‘M’ **and** height > 175) **or** height < 170。请注意，换行符对查询的含义没有影响。因此，结果包含身高低于 170 厘米的任何人的详细信息（包括女性）。[图 12.11](#Ch012_539-646_B9780443237904000268_1.xhtml#f0060)(b) 中的查询通过在身高析取式周围加上括号，使 `or` 运算符在 `and` 运算符之前计算，从而纠正了这个问题。

*德摩根定律* 以著名逻辑学家奥古斯都·德摩根命名，如下所示。此处，*p* 和 *q* 表示任何命题或逻辑条件。

```
not (p and q) ≡ not p or not q
not (p or q) ≡ not p and not q
```

这些定律在二值逻辑和三值逻辑中均成立，因此它们可以安全地用于空值。使用第二条定律，很容易看出 [图 12.13](#Ch012_539-646_B9780443237904000268_1.xhtml#f0070)(c) 中的查询等价于 [图 12.13](#Ch012_539-646_B9780443237904000268_1.xhtml#f0070)(a) 中的查询。

### 关系投影

下一个表操作称为 **投影**，在 [第 4 章](#Ch004_111-158_B9780443237904000232.xhtml) 中已介绍。此操作涉及 *从表中选择一个或多个列*，然后 *消除可能产生的任何重复行*。它被称为产生 *垂直子集* 或 *列子集*。[图 12.14](#Ch012_539-646_B9780443237904000268_1.xhtml#f0075) 说明了两列上的投影。

![Fig. 12.14 关系代数中的投影操作。](images/B9780443237904000268/f12-14-9780443237904.jpg)

[图 12.14](#Ch012_539-646_B9780443237904000268_1.xhtml#B-f0075) 关系代数中的投影操作。

我们可以将投影操作表示为 `T [a, b, …]`，其中 `T` 是一个表表达式，`a, b, …` 是所需列的名称（此列列表称为 *投影列表*）。为了界定投影列表，我们使用方括号而不是圆括号，因为后者在查询中有其他用途（例如，更改操作的计算顺序）。将方括号“`[ ]`”斜体化有助于将它们与用于界定可选项、包或指示额外任务（选择列后的重复消除）的“[ ]”区分开来。

替代符号 `π[a,b…](T)` 在学术期刊中很常见。“π” 符号是 pi，希腊字母 “*p*”（"projection" 的首字母）。像 SQL 一样，此符号在表之前列出所需的列。我们首选的符号则通过在列出列之前先确定相关表来鼓励自顶向下的思维。

[图 12.15](#Ch012_539-646_B9780443237904000268_1.xhtml#f0080) 基于表 *Player* (name, gender, height) 给出了两个示例。当在单个基本表上投影时，如果所选列包含候选键，则不会产生重复行。如果不包含，则可能出现重复。例如，仅选择 gender 列会得到包 `["M", "F", "F", "M"]`。为了完成投影，消除重复值，得到集合 `{"M", "F"}`。如果我们投影所有列，最终会得到相同的表。例如，Player `[name, gender, height]` 与 Player 是同一个表。

![Fig. 12.15 投影涉及选取列并移除任何重复项。](images/B9780443237904000268/f12-15-9780443237904.jpg)

[图 12.15](#Ch012_539-646_B9780443237904000268_1.xhtml#B-f0080) 投影涉及选取列并移除任何重复项。

投影中不得两次提及同一列。例如，Player `[name, name]` 是非法的（为什么？）。投影也可用于以不同顺序显示列。例如，Player `[height, gender, name]` 反转了顺序。因为结果中列出了唯一的列名，这不会改变含义。

如果关系模式完全规范化，基本表兼容并（union compatible）的情况相当少见（前面考虑的 Eats 和 Likes 表是个例外）。因此，∪、∩ 和 − 操作几乎专门用于因投影而变得兼容并的结果表。

我们现在来看一些稍微困难的例子。为了便于讨论分步处理此类情况的方法，我们使用 **关系赋值** 操作。因为它们的内容可能变化，表模式可被视为 *变量*。事实上，表是关系代数中允许的唯一一种变量。关系赋值操作严格来说独立于代数本身，类似于编程语言中的赋值。使用符号 “:=” 表示 “变为” 或 “被赋值为”，我们可以编写如下形式的赋值语句。

```
table variable := table expression
```
