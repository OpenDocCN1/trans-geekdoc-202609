# 前言

**Enrico Franconi**，博士，^()意大利博尔扎诺自由大学计算机科学教授，^()KRDB知识与数据研究中心主任。

我怀着极大的热情和深深的荣誉感，为这本杰出书籍的第三版撰写前言。这是一本关于信息建模和关系数据库的全面而深刻的指南，凸显了其在企业建模和数据管理领域的深远重要性。甚至在新版中，人们也不得不承认其页面中所包含的知识的广度和深度。

本书是理解**对象-角色建模（ORM）**语言及其面向事实的建模方法论不可或缺的资源。ORM作为数据建模领域的一座灯塔，提供了一种严谨且用户友好的方法。本书以严格的细节关注，细致地剖析了企业的语义复杂性。作者致力于探索和评估各种概念建模符号并与ORM进行对比，这使本书脱颖而出，为读者提供了数据建模范式全景图，同时呈现了对概念建模的准确理解以及ORM优势的证据。

各章阐明了概念建模的细微差别，强调了建模语言必要的精确性。作为来自基于逻辑的知识表示与推理背景的人，我非常欣赏ORM符号的形式化严谨性，在这种符号中，歧义和马虎无处遁形，这与许多其他（广为人知的）概念建模符号形成鲜明对比。此外，本书不仅描述了建模构造的精确含义，还阐释了这些构造在语言中存在的原因。对其用例的细致分析及其设计方法论在本书中具有同等重要的地位。
