
基于或受 Prolog 或 Datalog 影响的各种演绎数据库系统已被开发，例如 LogiQL ([Halpin and Rugaber, 2015](#Ch017_875-933_B9780443237904000050.xhtml#bb9025)) 和 Soufflé ([https://github.com/souffle-lang](https://github.com/souffle-lang))。LogiQL 由 LogicBlox 开发，但自 2014 年 12 月 LogicBlox 被 Predictix 收购后不再可用。Soufflé 是一种[开源](https://en.wikipedia.org/wiki/Open_source)、[并行](https://en.wikipedia.org/wiki/Parallel_computing)、[逻辑编程语言](https://en.wikipedia.org/wiki/Logic_programming)，包含一个解释器和一个以并行 C++ 为目标的编译器。

RelationalAI ([https://relational.ai](https://relational.ai)) 正在开发一种极其强大的编程语言，该语言支持演绎数据库功能以及知识图谱，预计发布日期在 2024 年中左右。该系统称为 `RAI`，基于云，其语言称为 `Rel`，因为其数据结构以关系（有序元组的集合）为中心。

祖先关系的递归规则 ∀x,y \[ x isanAncestorOf y if ∃z(x isaParentOf z and z isanAncestor of y) \] 可以通过以下定义在 `Rel` 中表达：`def isanAncestorOf (x, y): exists((z) | isaParentOf(x, z) and isanAncestorOf(z, y))`。

作为 `Rel` 强大功能的一个迹象，RelationalAI 程序员团队编写了一个 `Rel` 程序，可自动将免费公共领域版 NORMA 工具中捕获的 ORM 模型转换为 `Rel` 中的结构。此转换能够映射极其复杂的 ORM 模型，并可捕获 ORM 中本质上所有的真值约束。撰写时，道义约束尚不支持。

这与英语中“if *p* then *q*”的含义有显著不同，因为假命题实质蕴涵任何命题，而真命题被任何命题实质蕴涵。例如，命题“Earth is a star”实质蕴涵命题“Earth has 10 moons”，命题“Mars is a star”实质蕴涵命题“Mars is a planet”。

假设 ORM 事实类型 Country has CountryName 已使用二元谓词 `hasCountryName` 在 `Rel` 中声明，ORM *强制角色* 约束 **Each** Country has **some** CountryName 可表示如下：

```
ic (c) { Country(c) implies hasCountryName(c, _) }
```

头变量 `c` 是全称量化的，下划线字符“`_`”表示匿名变量，因此约束表达式等价于以下谓词逻辑公式：

*    ∀x \[Country(x) → ∃y(x hasCountryName y)\]。

Country 在 Country has CountryName 中的角色的*内部唯一性约束*可通过声明谓词为*函数式*来声明，如下所示：

```
ic () requires function(hasCountryName)
```

CountryName 在 Country has CountryName 中的角色的唯一性约束可声明如下：

```
ic (c1, c2, n) requires (hasCountryName(c1,n) and hasCountryName(c2,n) implies c1 = c2
```

假设三元事实类型已声明，其*复合唯一性约束*可声明如下：

```
ic (c, y, p1, p2) requires (inYearHadPopulation(c, y, p1) and inYearHadPopulation(c, y, p2)) implies p1 = p2
```

State 的复合参考方案中的*外部唯一性约束*可声明如下：

```
ic (s1, s2, c, sc) requires (isInCountry(s1,c) and hasStateName(s1,sc) and isInCountry(s2,c) and hasStateName(s2,sc)) implies s1 = s2
```

示例 (b) 中的*排他或约束*确保我们太阳系中的每颗行星要么是内行星，要么是外行星，但不能两者皆是。这可在 `Rel` 中表示为：

```
ic (p) requires Planet(p) implies (isAnInnerPlanet(p) xor isAnOuterPlanet(p))
```

示例 (c) 中的*值约束*限制底层引用类型 Gender has GenderCode 中 GenderCode 的值。示例 (d) 中的*值约束*将 IQ 值限制在 0..300 范围内。这些约束可制定如下：

```
ic (g, gc) requires hasGenderCode(g,gc) implies (gc = “M” or gc = “F”)
ic (x, y) requires hasIQNr(x,y) implies (x >= 0 and x <=300)
```

示例 (e) 和 (f) 中的*排除约束*规定：没有人可以同时撰写和评审同一本书；没有人可以评审由在同一所大学任教的人撰写的论文。图 (f) 中关于连接路径上的排除约束的图表是 NORMA 工具的屏幕截图。这些约束可制定如下：

```
ic (p, b) requires reviews(p, b) implies not authors(p, b)
ic (p1, p2, u, pr) requires (authors(p1, pr) and lecturesAt(p1, u) and reviews(p2, pr)) implies not lecturesAt(p2,u)
```
