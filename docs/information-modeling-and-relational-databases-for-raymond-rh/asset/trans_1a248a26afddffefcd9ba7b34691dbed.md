
# SQL 运算符：IN、BETWEEN 和 LIKE

如果函数执行的动作表示时不将所有参数括起来，我们通常将其描述为涉及运算符和操作数，而不是函数和参数。根据运算符出现在操作数之间、之前、之后或混合其中，运算符可以用中缀、前缀、后缀和混合记法表示。例如，2 和 3 的和可以写成：

```
sum (2, 3)        -- 函数
2 + 3             -- 中缀运算符
+ 2 3             -- 前缀运算符
2 3 +             -- 后缀运算符
sum of 2 and 3    -- 混合运算符
```

我们即将讨论的四个运算符用于表达搜索条件。前三个返回值 `True`、`False` 或 `Unknown`，而 `is null` 运算符返回 `True` 或 `False`。我们最初的处理重点在于这些运算符的 SQL-89 版本。SQL-92 及以后版本的扩展将在后面提及。我们的大多数示例基于 `Person` 表，此处作为[表 12.9](#Ch012_539-646_B9780443237904000268_1.xhtml#t0050)复现。

假设我们想要获取出生于 1950 年、1967 年或 1974 年的人员的姓名和出生年份。请求此信息的一种方式如下面的 SQL 查询所示。作为练习，请验证这将产生四行结果。

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where birthyr = 1950 or birthyr = 1967 or birthyr = 1974
    ```

想象一下，如果涉及十几个或更多年份，以这种方式措辞请求会有多么繁琐。部分为了使此类情况更容易处理，SQL 包含一个 `in` 运算符来处理*包成员资格*，从而处理*集合成员资格*。使用该中缀运算符，上述请求可以更简洁地表述为：

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where birthyr in (1950,1967,1974)
    ```

这里，搜索条件是 `birthyr` 的值是包含值 1950、1967 和 1974 的包的成员。这些值的书写顺序无关紧要，即使有重复也无所谓。一般来说，如果 *x* 是某个表达式（例如列名），而 *a, b* 等是数据值（例如数字或字符串常量），则此处左侧所示的 SQL 条件等同于右侧所示的数学表达式：

*   `x` **in** ( *a, b ...* ) 意为 *x* ∈ [ *a, b ...* ]

我们使用 **in** 代替“∈”，用圆括号“( )”代替方括号“[ ]”作为*包定界符*。因为集合可以被视为没有重复项的包，所以 `in` 运算符也可用于集合成员资格。与许多编程语言不同，SQL 允许包或集合包含字符串（不仅限于数字）。例如，以下查询列出了水瓶座和金牛座的人员（Eve、Selena 和 Terry）：

*   ```
    select firstname from Person
    ```

*   ```
    where starsign in ('Aquarius','Taurus')
    ```

要表示表达式的值*不*属于某个包或集合，可以将逻辑 `not` 运算符与 `in` 运算符结合使用。与普通比较运算符一样，SQL 赋予 `in` 运算符比逻辑运算符更高的优先级（这与大多数编程语言不同）。在 SQL 中，条件“not (*x* in *S*)”可以更简略地表示为 **not x in S**。更好的是，SQL 还允许用 **not in** 表示“∉”，因此可以更自然地写作 x **not in** S。

*   `x` **not in** ( *a, b …* ) 意为 *x* ∉ [ *a, b …* ]

例如，要获取未出生于 1950 年、1967 年或 1974 年中任意年份的人员的姓名和出生年份，可以使用以下查询（结果为 Fred 和 Terry）：

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where birthyr not in (1950,1967,1974)
    ```

有时，我们希望确定表达式的值是否出现在某个*范围*内。在数学中，要说明某个变量 *x* 的值在从 *a* 到 *b* 的范围内，我们通常将其表示为 *a* ≤ *x* ≤ *b*。这种表示法在 SQL 中是非法的。相反，我们可以说 a <= x **and** x <= b。对于示例数据，以下查询返回除 Terry 之外所有人的姓名和出生年份。

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where 1950 <= birthyr and birthyr <= 1974
    ```

作为指定范围成员资格的另一种方式，SQL 提供了三元混合运算符 **“…between…and…”**，其定义如下，其中 *x, a* 和 *b* 可以是标量表达式：

```
x between a and b      意为          a <= x and x <= b
```

例如，前一个查询可以重新表述为：

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where birthyr between 1950 and 1974
    ```

请仔细注意，与普通英语相反，SQL 中的 **between** 按*包含意义*解读。例如，1950 和 1974 都包含在给定范围内。

还请注意，这里的 **and** 只是混合运算符的一部分；它不是逻辑运算符。如前所述，`<=` 运算符可用于对字符串以及数字进行排序。因此，字符串可用作操作数。例如，以下查询返回包（“Bob”、“Eve”、“Fred”）。

*   ```
    select firstname from Person
    ```

*   ```
    where firstname between ‘Bob’ and ‘Fred’
    ```

借助 `not` 运算符（其优先级低于 `between`）可表达不在某范围内的情况，`not` 可置于单词 **between** 之前。因此，以下每个条件都等同于 *x* < *a* **or** *x* > *b*。

```
x not between a and b
not ( x between a and b )
not x between a and b
```

**not between** 这种表述更易读。例如，以下查询仅返回元组 (‘Terry’, 1946)。

*   ```
    select firstname, birthyr from Person
    ```

*   ```
    where birthyr not between 1950 and 1974
    ```

在纯关系模型中，列值是原子的。然而，SQL 提供了多种访问字符串值中子串的方法。特别是，`like` 运算符可用于字符串的*模式匹配*。SQL-89 中条件的一般形式可用 BNF 表示如下：

```
char-col [not] like quoted-string [escape quoted-char]
```

此处，`char-col` 是基于字符串数据类型的列名。带引号的字符串是用单引号括起来的字符串，其中可能包含*通配符*。您可能熟悉在操作系统级别使用通配符匹配文件名（例如 Microsoft Windows 中的“*”）。

在没有 escape 子句的情况下，如果由 `like` 运算操作的带引号字符串中包含百分号“%”和下划线“_”，SQL 赋予它们以下特殊含义：

*   % 意为零个或多个字符
*   _ 意为任意单个字符

“%”通常更有用，但如果字符在字符串中的位置很重要，则需要“_”。[图 12.47](#Ch012_539-646_B9780443237904000268_1.xhtml#f0240) 提供了几个基于[表 12.9](#Ch012_539-646_B9780443237904000268_1.xhtml#t0050)的示例。`like` 运算符优先于逻辑运算符，因此“*x* **not like** *s*”意为“**not** (*x* **like** *s*)” 。
