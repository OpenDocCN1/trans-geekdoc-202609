## 12.10 SQL：分组

有时，我们希望将表的行划分为若干个*组*，并显示适用于每个组整体的属性。SQL 提供了可包含在 `select` 语句中的 `group by` 子句，以检索此类分组数据。*每个组是一包行，这些行在 `group by` 子句中列出的分组标准上具有相同的值。* *最终查询结果每个组最多有一行。*

[图 12.56](#Ch012_539-646_B9780443237904000268_2.xhtml#f0285) 展示了按列 `a` 分组的情况。这里有三个组，对应 `a` 的三个值。结果可能包含某个组属性或 `a` 的函数，此处将其描绘为 `f(a)`。

![Fig. 12.56 Partitioning rows into groups with the same value for column a.](images/B9780443237904000268/f12-56-9780443237904.jpg)

[图 12.56](#Ch012_539-646_B9780443237904000268_2.xhtml#B-f0285) 根据列 `a` 的相同值将行划分为组。

因为最终结果每个组仅包含一行，所以 `select` 列表只能包含组属性。

换句话说，对于每个组，每个 `select` 项目只能有一个值。为确保这一点，每个组属性必须是分组标准（用于分组的列名）、函数调用（例如 `count(*)`）、常量，或由这些项组成的表达式（例如 `2 * groupcol`）。SQL 中 `group by` 查询的基本语法如下：

```sql
select group-property1, …
from …
[where …]
group by group-criterion1, …
```

[表 12.14](#Ch012_539-646_B9780443237904000268_2.xhtml#t0075) 将用于帮助解释上述大多数概念。关系模式为 `Particle(particleName, family, charge, mass)`。为帮助您直观理解按家族分组，行已按家族排序，并在组之间添加了空行。每个粒子的电荷以基本电荷为单位给出。一个基本电荷是一个质子的电荷，等于 1.6 × 10^(−19) C。电子的质量是 9.1 × 10^(−31) kg。每个粒子的质量表示为电子质量的倍数。
