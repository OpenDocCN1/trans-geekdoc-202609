

# UML 状态机细节

## 伪状态和初始条件

[图 15.30](#Ch015_773-830_B9780443237904000190.xhtml#f0155) 中的小黑节点是特殊的*伪状态*，它们代表各自状态的初始条件。在一个区域内，在任何时候只能有一个子状态处于活动状态，因此 [图 15.30](#Ch015_773-830_B9780443237904000190.xhtml#f0155)(a) 所示的状态可以处于状态 S1、S2、S3 或 S4。相反，[图 15.30](#Ch015_773-830_B9780443237904000190.xhtml#f0155)(b) 所示的状态可以处于状态 S1 或 S2，并同时处于状态 S3 或 S4。一个状态还可以包含嵌套状态机——称为*子机状态机*——它们在语义上等同于复合状态。子机是封装公共行为以供复用的便捷方式。

## 状态动作

动作可以在状态的三个时刻之一执行：

1.  进入状态时（**On entry**），表示为 `entry / action`
2.  状态期间（**During**）（可能在循环中持续进行），表示为 `do / action`
3.  退出状态时（**On exit**），表示为 `exit / action`

所有这些都是可选的。“期间”动作要等到所有进入动作完成后才开始，并且将在任何退出动作开始之前完成或中止。这确保了进入动作总是在其他任何事情之前执行，而退出动作总是在其他任何事情之后执行。在状态内执行的动作对应于前面讨论的 Moore 机语义。如果需要，可以通过将动作列在状态符号的一个分区中（就在包含状态名称的分区下方）来在状态机图上显示它们，如 [图 15.31](#Ch015_773-830_B9780443237904000190.xhtml#f0160) 所示。

## 迁移

状态之间的迁移可以有一个标签，最多包含三个部分。正常表示法为 `e [g] /a`，其中

*   `e` 标识触发迁移的触发事件（事件可能带有参数）。
*   `g` 是一个卫表达式，用方括号括起来。
*   `a` 标识一个或多个动作的列表，前面带有一个“斜杠”字符。

所有三个组件都是可选的，因此可以存在零个、一个、两个或所有三个组件。[图 15.32](#Ch015_773-830_B9780443237904000190.xhtml#f0165) 显示了一个包含所有三个组件的典型迁移。

![图 15.32 一个带标签的迁移。](images/B9780443237904000190/f15-32-9780443237904.jpg)

[图 15.32](#Ch015_773-830_B9780443237904000190.xhtml#B-f0165) 一个带标签的迁移。

如果未指定事件，则在前一个状态中的动作完成后，迁移即被启用（一个*完成迁移*）。如果指定了卫表达式，则必须计算结果为“真”，迁移才会发生。卫表达式在迁移即将发生的时间点进行计算。如果计算结果为“假”，则不会发生迁移，即使它已被事件启用。如果在迁移上指定了动作，则它们会在进入目标状态之前完成。这对应于前面讨论的 Mealy 机语义。因此，UML 状态机可以具有 Moore 机、Mealy 机或两者的特征。

## 事件处理

事件由状态机一次处理一个，具有*运行至完成*语义。这意味着只有在前一个事件的处理完全完成后，当前事件才会被识别和处理。这简化了状态机，因为它永远不会陷入在某个中间配置中处理事件的情况（例如，在从一个状态迁移到另一个状态的过程中）。事件不一定导致迁移，因为事件可以在状态内被识别和处理。事件也可以被识别但在特定状态中*延期*。一个延期事件会被保存并传递给下一个状态，在那里它必须被接受或再次延期。这将持续到事件不再被延期，或者触发迁移为止。

### 初始和最终伪状态

*初始*伪状态是指向复合状态默认状态的单个迁移的源。每个区域最多只能有一个初始伪状态。*最终*伪状态表示其包含区域的完成。当一个区域的所有包含区域都完成时，该区域的包含状态被视为完成。如果状态机中包含的所有区域都已完成，则整个状态机终止。这相当于销毁与状态机关联的对象（在编程意义上！）。

### 进入和退出点

*进入*点提供了进入状态机或复合状态的途径，目标是封闭区域内的特定状态。与封闭状态关联的进入动作会在迁移到内部状态之前执行。进入*退出*点的迁移意味着从封闭状态机或复合状态退出。封闭状态的任何退出行为都在从内部状态迁移之后执行。进入和退出点可以显示在状态边界内或状态边界线上。

### 汇聚和选择伪状态

*汇聚*伪状态用于合并多个迁移和/或将一个迁移分成多个分支，每个分支具有不同的卫条件。后一种情况称为静态条件分支。*选择*伪状态是一个动态条件分支——它在同一个运行至完成步骤中动态地计算其输出迁移上的卫条件，以反映执行的动作的结果。

### 分叉和汇合伪状态

*分叉*伪状态将迁移分割为目标位于不同正交区域的状态。*汇合*伪状态执行互补操作，合并源自不同正交区域状态的迁移。

### 历史伪状态

进入*深层历史*伪状态的迁移将恢复复合状态及其所有子状态最近活动的配置。进入*浅层历史*状态类似，不同之处在于不恢复任何子状态的配置。

一个复合状态最多可以有一个深层历史伪状态和一个浅层历史伪状态。在任一情况下，如果复合状态之前未处于活动状态（即没有历史），则会采用从历史状态出发的输出迁移。

### 终止伪状态

进入*终止*伪状态意味着包含状态机的执行被终止。这相当于销毁与状态机关联的对象——同样，“销毁”是指编程意义上的销毁。

## 层次化状态机

在层次化状态机中，多个状态可以同时处于活动状态。如果一个嵌套状态处于活动状态，则其父状态及其所有祖先状态一直到顶层状态也都处于活动状态。在任何一个区域中，最多只能有一个活动状态。一个正交状态可以在其每个区域中都有一个活动状态。进入一个正交状态意味着进入其每个区域（显式或默认）。同样，退出一个正交状态意味着退出其所有区域。
