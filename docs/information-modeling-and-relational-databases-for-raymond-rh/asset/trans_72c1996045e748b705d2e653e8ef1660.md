
二元谓词的**定义域**是其主语必须所属的类，而二元谓词的**值域**是其宾语必须所属的类。在 Manchester 语法中，谓词可声明为 `ObjectProperty`，其定义域和值域分别在 `Domain:` 和 `Range:` 之后指定。例如：

```
ObjectProperty: isFatherOf     Domain: MalePerson     Range: Person
```

一个谓词可被赋予多个定义域和值域，此时主语必须属于该谓词所有定义域的**交集**，宾语必须属于该谓词所有值域的**交集**。

### OWL 2 分类简介

[图 18.22](#Ch018_935-1005_B9780443237904000104.xhtml#f0115) 展示了 OWL 2 中若干概念的 UML 类图。该图基于 <https://www.w3.org/TR/owl2-syntax/>。我们在 RDF 讨论中称为“资源”的内容，在 OWL 中称为 `entities`（实体）。OWL 实体可以是命名个体、类、属性（二元谓词）或数据类型。这与 ORM 和 ER 中“实体”一词的用法不同，在后者中，所有实体都是非词汇个体（而非类型或类）。

![图 18.22 基本 OWL 2 概念的类图（基于 OWL 2 规范）。](images/B9780443237904000104/f18-22-9780443237904.jpg)

[图 18.22](#Ch018_935-1005_B9780443237904000104.xhtml#B-f0115) 基本 OWL 2 概念的类图（基于 OWL 2 规范）。

在 OWL 中，实体由 IRI 标识，但与某些方法不同，OWL **不**采用 `Unique Name Assumption`（唯一名称假设，UNA）。因此，在 OWL 中，同一实体可能被分配不同的 IRI，即使在同一文档内也是如此。因此，[图 18.22](#Ch018_935-1005_B9780443237904000104.xhtml#f0115) 中 `entityIRI` 的多重性约束 1 应改为 1..\*（1 或多个）。如前所述，OWL 包含 `SameAs` 谓词，用于指示两个不同的 IRI 表示同一实体（例如，`DownUnder SameAs Australia`）。

`Literals`（数据值，如名称或数字）不被视为个体。这种做法与形式逻辑不同，在形式逻辑中字面量确实算作个体。只有 OWL 个体（而非字面量）可以是 OWL 类的成员。

OWL 谓词是有向的二元关系类型，将主语个体（实例）映射到宾语个体。OWL 包含一个预定义的通用类 `owl:Thing`，它包含所有个体。它还预定义了空类 `owl:Nothing`，该类没有成员。默认情况下，所有 OWL 谓词都具有无限制的定义域和值域（等于 `owl:Thing`）。

`Object properties`（对象属性）是将实体关联到实体的二元谓词。`Data properties`（数据属性）是将实体关联到字面量的二元谓词。例如：

```
ObjectProperty: wasBornIn DataProperty: hasName Individual: Einstein   Facts: wasBornIn Germany, hasName “Albert Einstein”ˆˆxsd:string
```

以下极端的 OWL 谓词（“属性”）是预定义的。`owl:topObjectProperty` 是所有对象属性的类，因此是一个将模型中所有个体关联到模型中所有个体的二元谓词（其外延是笛卡尔积 `owl:Thing × owl:Thing`）。每个对象属性都是该属性的子属性。`owl:topDataProperty` 是所有数据属性的类，因此是一个将所有个体关联到所有字面量的二元谓词。每个数据属性都是该属性的子属性。`owl:bottomObjectProperty` 是空对象属性，因此是每个对象属性的子属性。`owl:bottomDataProperty` 是空数据属性，因此是每个数据属性的子属性。

`Annotation properties`（标注属性）是提供关于本体、陈述或 IRI 的非正式文档标注的二元谓词。例如，`rdfs:comment` 标注属性用于提供注释，如下例所示：

```
Class: Moon Annotations: rdfs:comment "Natural satellite of a planet or other celestial body."
```

其他预定义的标注属性如下所示：

*   `rdfs:label` 标注属性用于提供人类可读的标签。
*   `rdfs:seeAlso` 标注属性用于将一个 IRI 与另一个 IRI 关联，使后者提供关于前者的附加信息。
*   `rdfs:isDefinedBy` 标注属性用于将一个 IRI 与另一个 IRI 关联，使后者提供前者的定义。
*   具有 `owl:deprecated` 标注属性且值等于 `trueˆˆxsd:boolean` 的标注，用于指定某 IRI 已被弃用。
*   `owl:versionInfo` 标注属性用于将一个 IRI 与一个描述该 IRI 版本的字符串关联。
*   `owl:priorVersion` 标注属性指定包含本体的先前版本的 IRI。
*   `owl:backwardCompatibleWith` 标注属性指定包含本体的先前版本的 IRI，该版本与包含本体的当前版本兼容。
*   `owl:incompatibleWith` 标注属性指定包含本体的先前版本的 IRI，该版本与包含本体的当前版本不兼容。

OWL 工具通常支持 `ontology parsing`（本体解析）——即将以特定语法编写的本体文档转换为 OWL 本体的过程。根据所用语法，本体解析器可能需要知道哪些 IRI 用于哪种实体类型（例如，谓词是对象属性、数据属性还是标注属性？）。例如，`wasBornIn` 是对象属性还是数据属性？这种类型信息可以从声明中提取——将 IRI 与实体类型关联的公理（例如，`ObjectProperty: wasBornIn`）。

### 比较个体、类、数据类型和谓词

OWL 预定义了 `owl:sameAs` 和 `owl:differentFrom` 谓词，分别用于个体之间的“=”和“≠”（因此它们的定义域和值域均为 `owl:Thing`）。这些谓词用于声明同一文档或不同文档中的两个 IRI 是指代同一个体还是不同个体，例如：

```
Individual: Elvis SameAs: TheKing    DifferentFrom: Donovan
```

OWL 预定义了 `owl:equivalentClass` 谓词以等同两个类或类表达式。在 Manchester 语法中，这称为 `EquivalentTo`，例如：

```
Class: Human  Class: Person EquivalentTo: Human.
```

在 Manchester 语法中，`EquivalentTo` 也可用于定义 `data range`（数据范围）。例如，数据类型 `RatingNr` 可限制为 {1..7}，即 `Datatype: RatingNr EquivalentTo: integer[>= 1, <=7]`。

在 Manchester 语法中，`DisjointWith` 谓词用于声明两个类（或类表达式）互斥，例如：

```
Class: Cat DisjointWith Dog.
```

预定义类 `DisjointClasses` 是其成员两两互斥的类（即每一对成员类都是不相交的）。在 Manchester 语法中，在两个或多个类描述前加上 `DisjointClasses:` 表示它们互斥（因此没有共同实例）。这提供了一种声明多个类两两不相交的高效方式。

在 ORM 中，顶层实体类型被假定为互斥。例如，在 [图 18.23](#Ch018_935-1005_B9780443237904000104.xhtml#f0120)(a) 的 ORM 模式中，如果 Person、Car 和 Dog 不是子类型，则假定它们是不相交的。然而在 OWL 中，这种不相交性需要显式声明，如 [图 18.23](#Ch018_935-1005_B9780443237904000104.xhtml#f0120)(b) 的第一条语句所示。
