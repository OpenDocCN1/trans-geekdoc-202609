
# 数据库填充与约束的显著性

如果且仅当数据库填充满足该约束的所有备选选择（不包括由此选择隐含的较弱约束）时，该数据库填充被称为**关于该约束显著**。获取一个关于唯一性约束显著的样本填充可能很繁琐，但可以在适度的时间内完成。遗憾的是，不存在能自动生成正确子类型定义的判定过程。

如果我们移除计算机系统具有有限内存这一限制，那么对于任何有限的数据集，将总是存在无限多个符合该数据的可能模式。这就是哲学上“归纳问题”的基础。

作为一个科学示例，请参考[图 6.49](#Ch006_211-271_B9780443237904000025.xhtml#f0250)。该图展示了三个数据点，这些数据点来自一个在固定体积下测量气体压力（`p`）和绝对温度（`T`）的实验。什么模式、规则或定律能将压力和温度联系起来？

![图 6.49 什么模式匹配数据？](images/B9780443237904000025/f06-49-9780443237904.jpg)

[图 6.50](#Ch006_211-271_B9780443237904000025.xhtml#f0255)(a) 中的直线展示了符合数据的压力与温度之间的线性关系。这表明当气体体积固定时，其压力与绝对温度成正比。您可能在高中物理课上学过这个定律。然而，[图 6.50](#Ch006_211-271_B9780443237904000025.xhtml#f0255)(b) 中的曲线也符合数据。我们如何知道哪一个（如果有的话）是正确的？

![图 6.50 多个模式都符合数据。](images/B9780443237904000025/f06-50-9780443237904.jpg)

[图 6.50](#Ch006_211-271_B9780443237904000025.xhtml#B-f0255) 多个模式都符合数据。

一个显而易见的做法是选择两个模式在压力读数上不同的温度点，然后测量实际读数。结果如[图 6.51](#Ch006_211-271_B9780443237904000025.xhtml#f0260)(a)所示。这里，额外的数据点（第三个“×”）符合直线假设，但不符合曲线。这个反例足以推翻该曲线。这是否证明了直线定律是正确的？并没有。我们总能添加另一条曲线来拟合扩展后的数据，如[图 6.51](#Ch006_211-271_B9780443237904000025.xhtml#f0260)(b)中的虚线所示。事实上，存在无限多条拟合数据点的曲线。您可以一直持续这个过程。任何有限的数据集都与无限多条规则一致。因此，您永远无法真正证明任何科学定律。

![图 6.51 额外数据可以排除一种模式，但其他模式可能仍然符合。](images/B9780443237904000025/f06-51-9780443237904.jpg)

[图 6.51](#Ch006_211-271_B9780443237904000025.xhtml#B-f0260) 额外数据可以排除一种模式，但其他模式可能仍然符合。

回到我们的子类型定义问题，显然任何子类型数据样本都与无限多个子类型定义一致。与其在此陷入哲学推测，不如采用以下务实方法来确定子类型定义。

仔细观察数据，运用“常识”找出最简单的模式，然后与领域专家核实该模式是否为预期模式。因为子类型约束反映了领域专家关于记录什么内容的决定，领域专家总能解决这个问题。从某种意义上说，这就像询问上帝他/她为所创造的宇宙设定了什么规则。

虽然输出报告不能关于子类型定义具有显著性，但输入表单（如纳税申报表或申请表）通常确实提供了一组关于条件指令的显著集合，从中可以推导出子类型定义。通常，此类表单包含许多仅由特定人群填写的字段。为了让用户知道他们必须回答哪些问题，表单中包含揭示记录特定细节条件的说明。根据这些说明，通常很容易确定子类型。

作为一个简单示例，请参考[图 6.52](#Ch006_211-271_B9780443237904000025.xhtml#f0265)所示的媒体调查表。每份表单都有唯一的表单编号。每份表单由不同的人填写，每人仅填写一份表单。强制执行人与表单之间的 1:1 对应关系是进行调查人员的责任，而非信息系统本身。在模型中，该对应关系被隐式处理，人们直接通过表单编号来标识。

![图 6.52 媒体调查表样本。](images/B9780443237904000025/f06-52-9780443237904.jpg)

[图 6.52](#Ch006_211-271_B9780443237904000025.xhtml#B-f0265) 媒体调查表样本。

该表单上的条件说明以斜体显示。所有人必须回答问题 1、2 和 4。回答问题 2 为 0 的人被告知跳过问题 3。因此，最喜爱的电视频道仅记录给那些表示他们看电视的人；我们称此子类型为 `Viewer`。回答问题 4 为 0 的人被告知跳过所有后续问题。因此，最喜爱的报纸（问题 5）仅记录给读报纸的人；我们称此子类型为 `Reader`。

年龄小于 18 岁或非同时为 `Viewer` 和 `Reader` 的人跳过问题 6。因此，首选新闻来源仅记录给既是 `Viewer` 又是 `Reader` 的成年人；我们称此子类型为 `MediaAdult`。这导致了[图 6.53](#Ch006_211-271_B9780443237904000025.xhtml#f0270)所示的模式。

![图 6.53 媒体调查示例的概念模式。](images/B9780443237904000025/f06-53-9780443237904.jpg)

[图 6.53](#Ch006_211-271_B9780443237904000025.xhtml#B-f0270) 媒体调查示例的概念模式。

该分析得出了[图 6.53](#Ch006_211-271_B9780443237904000025.xhtml#f0270)所示的“菱形”子类型图，以及图中每个节点记录的信息。然而，我们只能对实际的子类型定义做出合理的猜测——如果有领域专家可用，应与其核实这些定义。

在实践中，报告通常以相同方式显示不同种类的空值。例如，空白可能同时用于我们简单的未知标记“？”和不适用标记“−”。因此，在决定如何处理之前，您应与领域专家澄清任何空值的含义。

有时，子类型特定的细节出现在单独的报告中，此时这些报告的标题可能对应子类型或子类型组件（析取项或合取项）。
