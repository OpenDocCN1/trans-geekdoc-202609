
为了节省空间，我们可以仅按一种顺序存储每个词对。图 7.16(b) 中的后缀同义词二元关系将第二个词按字母顺序排在第一个词之后。词对（“abandon”，“leave”）仅按此顺序存储。因此该关系是非对称的，如图所示。现在可以使用推导规则推导出更大的同义词关系，例如：

| --- | --- |
| `Word 1 has synonym Word2 iff` |  |
| `Word 1 has post_synonym Word2` |  |
| `or` |  |
| `Word 2 has post_synonym Word1.` |  |

在 SQL 中，可以通过使用 `union` 运算符在基础关系上定义视图来定义派生关系。为了提高速度，两列都可以建立索引。用户可能会对基础关系执行更新，但对派生关系发出查询。因此，我们有时可以选择是用数据库约束还是推导规则来捕获 UoD 的某个方面。在这里，我们通过名称区分了断言事实类型和派生事实类型。也可以让事实类型半派生。

同义词的传递性如何？这个问题很复杂。你可能熟悉基于“如果我们在秃头男人的头上加一根头发，他仍然是秃头”这一主张的“秃发悖论”（悖论在哪里？）。类似的滑坡论证反对同义词传递性（近似序列最终导致非近似）。此外，同一个词可能有不同的含义，从而导致不同的同义词组。如果我们仍想保留某种传递性，可以包含一个同义词传递性的推导规则，并通过传递链的最大长度加以约束，且相对于词组含义。

现在考虑图 7.17 中的婚姻事实类型。丈夫和妻子角色是互斥的。与要求同一行条目不相等的非自反约束不同，排除约束作用于列之间，因此强得多。如果任何条目都不能同时出现在两列中，我们就不能有形式为 (a, b) 和 (b, a) 的两行。因此，**排除性蕴含非对称性**。而且，**非对称性蕴含非自反性**。因为它们是被蕴含的，所以非对称约束和非自反约束都不应添加到模式中。

现在，让我们回到图 7.18(a) 中填充的父母关系模型。这里仍然存在一个问题。你能发现吗？让我们约定在我们的 UoD 中不能发生乱伦（如果可以，我们改为声明道义规则，如第 10 章所述）。如果 Ann 是 Bill 的父母，Bill 是 Colin 的父母，那么 Ann 不能是 Colin 的父母。父母关系是**非传递的**（即，如果一个人是第二个人的父母，第二个人是第三个人的父母，那么第一个人不可能是第三个人的父母）。一般来说，对于任何关系类型 *R*：

![Fig. 7.18 父母关系是非对称且非传递的。](images/B978044323790400013X/f07-18-9780443237904.jpg)

图 7.18 父母关系是非对称且非传递的。

```
R is intransitive  iff  ∀ x,y,z  [(xRy  &  yRz) → ~xRz]
```

图 7.18(b) 显示了非传递性的直观图标，横杠表示禁止的跳跃。该图标的简化版本（无箭头尖）用作非传递约束符号，如图 7.18(b) 右侧所示。图 7.18(c) 通过在单个图标中组合约束，表示父母关系既是非传递的又是非对称的。填充数据已更改以满足约束。

作为练习，证明非传递性蕴含非自反性（提示：*x*、*y* 和 *z* 不必不同）。有时用“非传递”代替“非传递”。说一个关系是非传递的，比说它不是传递的更强。反对称性、非对称性和非传递性都不是行内约束，因为它们的实施需要将相关行与其他现有行进行比较。

如果一个非自反关系包含一个函数角色（而不是 *m:n*），它也必须是非传递的。图 7.19 通过*归谬法*说明了这一点的证明。设 *R* 为一个第一角色是函数的非自反关系（即，它有一个简单的唯一性约束）。现在，用前两行所示填充 *R*。因为 R 是非自反的，*a* ≠ *b* 且 *b* ≠ *c*。假设 *R* 不是非传递的。这允许我们添加所示的第三行。因为 *b* ≠ *c*，第 1 行和第 3 行是不同的行。这意味着 *a* 扮演了 *R* 的第一角色两次。但这与唯一性约束矛盾。因此，必须拒绝第 3 行（用穿过第 3 行的虚线表示）。因此，该关系必须是非传递的。隐含的非传递约束通常最好保持隐式；如果显式显示，则标为绿色，如图 7.19(c) 所示。如果第二角色是函数的，此蕴含也适用。

我们完成环约束了吗？还没。看看图 7.18(c) 中的父母关系填充。所有指定约束都满足，但仍有错误。你能发现问题吗？

这里，Ann 是 Bill 的父母，Bill 是 Colin 的父母，Colin 是 Ann 的父母。这使得 Ann 成了自己的曾祖父母。虽然轮回可能使这成为可能，但假设我们希望从 UoD 中排除这种可能性。我们可以通过声明关系为**非循环**来实现。这意味着关系没有环（即，不存在通过关系从一个对象回到其自身的路径）。

使用 `∃`（读作“存在某个”）表示**存在量词**，我们递归地定义路径谓词 *P*（读作“有一条路径到”）以给出 *R* 的传递闭包，然后用它定义关系 *R* 为非循环：

```
∀ x,y (xPyiff [xRyor ∃z (xRz & zPy)])
R is acyclic iff ∀x ~xPx
```

图 7.20(a) 显示了非循环性的直观图标，横杠表示不允许回环。该图标的简化版本（无箭头尖）用作**非循环约束**符号，如图 7.20(b) 所示。ORM 1 使用替代的非循环约束符号 ^O*ac*。

![Fig. 7.20 在非循环关系中，不允许回环。](images/B978044323790400013X/f07-20-9780443237904.jpg)

图 7.20 在非循环关系中，不允许回环。

环可能包含一个或多个链接。非对称性只是环中有两个链接的非循环性的特例。因为**非循环蕴含非对称**，如果角色对被声明为非循环，则不要声明它为非对称。
