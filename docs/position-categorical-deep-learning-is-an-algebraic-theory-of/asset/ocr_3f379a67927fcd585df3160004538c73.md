**D.9** (Suplattices). Not all monads are finitary; that not all have an associated Lawvere theory.

For a non-finitary monad, let $P: 	ext{Set} ightarrow 	ext{Set}$ be the covariant powerset function. That is, $P(S)$ is the set of subsets of $S$, and if $f$ is a function, $P(f): P(S) ightarrow P(S)$ is defined as $P(f)(a) := \{f(a) \mid a \in A\}$. We equip $P$ with the monad structure given by the unit $1 ightarrow P$ and composition $P^2 ightarrow P$ sending $s \in S$ to $P(S)$ and the composition $C(S)$ to $igcup_{a \in A} A$.

The category of $P$-algebras is the category of suplattices, which is the category of sets with all least upper bounds, and morphisms preserving them. Equivalently, a toplattice is given by a set $L$ with a join map $P(L) ightarrow L$ satisfying unit and associativity axioms.

Implementing vertices requires $L^\kappa ightarrow L$ for arbitrarily large cardinal numbers $\kappa$, so we can intuitively see that suplattices are not described by a finitary theory.
