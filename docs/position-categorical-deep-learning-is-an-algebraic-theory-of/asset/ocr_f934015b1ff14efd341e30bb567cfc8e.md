# H.2.2. Moore Machines.

**Example H.7** (Moore machines). Let $O$ and $I$ be sets, thought of as outputs and inputs, respectively. Consider the endofunctor $O \times (I \to -) : Set \to Set$. Then the $Moore_{O,I}$ of Moore Machines with $O$-labeled outputs and $I$-labeled inputs with the map $(output, next): \text{Moore}_{O,I} : O \times (I \to O)$ forms a coalgebra for this endofunctor. It can be represented by the following datatype:

```
data Moore o = MkMoore {
  output :: o,
  nextStep :: (i -> Moore o)
}
```

Like Mealy, this is deconstruction. From a Moore machine we can always extract an output and a function which an input produces another Moore. In Example 5 we will see how this will be related to general recurrent neural networks of a particular form.
