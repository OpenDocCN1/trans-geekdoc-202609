# H.1. Examples Linear equivariant for pair of pixels.

**Example H.1** (Linear equivariant for pair of pixels). Consider the category Vect of finite-dimensional vector spaces and linear maps. For simplicity, we assume that the carrier is $R^2$, if $f : R^2 \to R^2$ is equivariant with respect to $\to$, then for any $[x_1, x_2] \in R^2$ it must hold that

| w1x2 + w2x1 | w3x1 + w4x1 |
| w3x2 + w4x1 | w1x1 + w2x2 |

(11)

This implies that $w_3 = w_2$ and $w_4 = w_1$, meaning $W$ is of the form

| w1 w2 |
| w2 w1 |

where the weights make the matrix a symmetric. Any one network fw satisfying this constraint will be a linear equivariant layer over $Z_2$, which can be used as a building block to construct geometric deep learning architectures.

**Remark H.2** (Circulants and Nodes). Note that this can be used to generate larger inputs (e.g.R^k$ for $k>2$). Generally, it is a well-known fact in signal processing, for fw to satisfy a linear equivariant constraint, W must be a circulant matrix. Circulant matrices are known in neural networks as convolutional layers, the essence of modern CNNs (Fukushima et al., 2013; LeC et al., 1998).

**Example H.3** (Invariant maps) are also $(G \times X)$-algebrahomomorphisms where the codomain is a trivial group action. Specifically, sending to the domain of any of the examples from Example 2, the corresponding induced commutative diagram is:
