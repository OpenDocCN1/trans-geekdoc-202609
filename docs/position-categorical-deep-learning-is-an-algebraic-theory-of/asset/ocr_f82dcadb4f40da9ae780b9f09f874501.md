```
front :: (p, List a) -> x
front p Nil = cell^p (inl ())
front p (Cons a as) = cell^p (inr a (front as))
```

We can see that front is structurally recursive: it processes the head of the list by applying cell^front to the parameter p and the output of the front with the same parameter, and the tail of the same tail.

We proceed to show that Δp is a valid parametrisation for the parametric morphisms. Unpacking the composition on top right, and the bottom left of Equation (17), respectively, yields parametric maps

```
P × (1 + A × List(A)) → X
nP × (1 + A × List(A)) → X
```

whose implementations are, respectively:

```
(p, q, inl(•)) → cell^front (p, in(•))
(p, inr(a, as)) → cell^front (q, a, f(p, as))
(p, •) → cell^front (p, in(•))
(p, (a, as)) → cell^front (p, a, f(p, as))
```

It is easy to see that Δp is a valid parametrisation of them, "tying" the parameters p and q.
**Example 1.2** (Iterated unfolded RNN). Consider a coalgebra (P, cell_₀, cell_₀) of Para(O × −), i is an unfolding RNN cell (Example 1.3). Its unrolling is a Para(O × −)-coalgebra homomorphism below:

| | | |
|---|---|---|
| (P,(cell_₀,cell_₀)) | (P,f,n) | Stream(O) |
| | Δp | γ((output,next)) |
| O × X | Para(O × −),(f,n)) | O × Stream(O) |

Here f,n :: P × X → Stream(O) is the syntactic analogue of an unfold (Example 1.5):

```
f_n :: (p, x) -> Stream o
f_n p x = MKStream (cell_n p x) (f_n p (cell_n x))
```

We can see that f,n is structurally recursive: it produces a stream whose head is cell_n(p,x), and whose tail is the stream produced by f,n at cell_n(p,x).
