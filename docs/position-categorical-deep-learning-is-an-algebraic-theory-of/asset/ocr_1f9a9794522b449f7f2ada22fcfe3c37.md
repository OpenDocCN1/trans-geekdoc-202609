**Definition B.14.** Let $C$ be a $\kappa$-locally presentable category and $F : C ightarrow C$ be a $\kappa$-accessible endofunctor. $F^\kappa$ be the $\kappa$-directed colimit of the diagram

$F^0 ightarrow F^1 ightarrow F^2 ightarrow \dots ightarrow F^\kappa$

where $F^0 = id_C$ and $F^{\alpha+1} = F \circ F^\alpha$ for $\alpha < \kappa$ and $F^\kappa = \lim_{\alpha < \kappa} F^\alpha$ as a limit colimit.

**Lemma B.15.** *For $C$ and as above, $F^\kappa$ is a monad. The canonical inclusion of $id_C$ into the colimit $F^\kappa$ and the multiplication comes from the preservation of $\kappa$-filtered colimits by $F$.*

**Theorem B.16.** *Assume the hypotheses of Lemma B.15 with $\kappa$ the ordinal in those hypotheses. Then $Alg\&Pando(F)$ is equivalent to $Alg_{Mod}(F^\kappa)$ i.e. $F^\kappa$ is an algebraically free monad for $F$.*

Remark B.17. For the endofunctors we study here, $Free(F) \cong (F + id)^*$ is the underlying endofunctor of an algebraically free monad for $F$, $Free(F)$.

The above formula allows us to derive the explicit formula for free monads, which has a dual formula in the case of cofree monads (Ghani et al.).

**Proposition B.18** (Cof(co)monads), Let $F : C ightarrow C$ be an endofunctor. Then $Free_{mon}(F)$, the free monad on $F$ is given by $Free_{mon}(F)(X) = Fix(X ightarrow F(X))$. Dually, $Cof_{mon}(F)$, the cofree monad on $F$ is $Cof_{mon}(F)(X) = Fix(F(X) ightarrow X)$.

**Example B.19** Free monad on $1+A$. Free on the endofunctor $1+A$ is $List_{+1}(A)$ of lists of elements $A$ whose the endofunctor mapping an object $Z$ to the set $List_{+1}(A)$ of lists of elements $A$ whose last element is not $1$; i.e. an element of type $1$, instead an element of type $Z$. That is, are lists which end with an element of $Z$.

**Example B.20** Free monad on $A(-)^2$ is given by $Tree(A(-)) : Set ightarrow Set$, mapping a set $Z$ to the set of trees with $A+Z$ labelled leaves.

**Example B.21** Cofree monad on $(I 	imes -)$. The cofree monad of the endofunctor $(I 	imes -)$ is $Fix(X ightarrow I 	imes X)$, mapping an object $Z$ to the set of streams whose outputs are $O 	imes Z$.

**Example B.22** Cofree comad on $(I ightarrow O 	imes -)$. The comad of the endofunctor $(I ightarrow O 	imes -)$ is $Fix(O 	imes X ightarrow X)$, outputting an additional element of $Z$ at each step does not depend on $I$.

# C. Categorical Deep Learning Examples

To illustrate the power of categorical deep learning as a framework that subsumes geometric deep learning (Bronstein et al., 2021), we make the reader see three additional examples demonstrating equivariance constraints of established geometric deep learning architectures, leveraging the framework of CDL.

All of these examples are faithful to Geometric DL practitioners, and are covered in prior papers (Maron et al., 2018; Cohen et al., 2018; Thomas et al., 2018; Cohen & Wells, 2016), we believe that relegating their exact derivations to appendices is appropriate in our work.

Before we begin, recall the core template of our approach: that we represent neural networks $f : A ightarrow B$ as monad homomorphisms between two algebras $(A, a)$ and $(B, b)$, for a monad $(M, \eta, \mu)$.

```
M(f)   M(B)
|       |
vv       v
A  ----->  B
```

and that geometric deep learning is recovered by making our group the group action monad $M(X) = G 	imes X$.
