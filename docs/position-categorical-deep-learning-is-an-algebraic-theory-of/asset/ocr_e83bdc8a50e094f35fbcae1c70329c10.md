# A. Category Theory Basics

The natural notion of ‘sameness’ for categories is equivalence:

**Definition A.1 (Equivalence).** An equivalence between two categories $C$ and $D$, written $C \xrightarrow{\sim} D$, consists of a pair of functors $F : C 	o D$ and $G : D 	o C$ with natural isomorphisms (natural transformations where every component has an inverse) $F \circ G \cong 1_C$ and $G \circ F \cong 1_D$.

**Definition A.2 (Initial).** An object $I$ in a category $C$ is called **initial** if for every $X \in C$ naturally holds that $\mathcal{C}(I, X) \cong 1$, meaning that there is only one map of type $I 	o X$.

**Definition A.3 (Terminal).** An object $T$ in a category $C$ is called **terminal** if for every $X \in C$ naturally holds that $\mathcal{C}(X, T) \cong 1$, meaning that there is only one map of type $X 	o T$.

**Definition A.4 (Limit).** For categories $\mathcal{C}$ and $\mathcal{J}$, a diagram of shape $J$ in $\mathcal{C}$ is a functor $D : J 	o \mathcal{C}$. **Definition B.2 (Coalgebra for an endofunctor).** Let $\mathcal{C}$ be a category and $F$ an endofunctor on $\mathcal{C}$. A coalgebra for $F$ is a pair $(A, a)$ where $A$ is an object of $\mathcal{C}$ and $a : A 	o F(A)$ is a morphism of $C$.
