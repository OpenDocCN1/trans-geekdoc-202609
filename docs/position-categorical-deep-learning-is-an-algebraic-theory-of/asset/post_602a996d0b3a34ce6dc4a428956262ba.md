# 3. Categories and Parametric Morphisms

While category theory is a powerful framework, it leaves much to be desired in terms of higher-order relationships between morphisms. It dealth with sets of morphisms, with no possible way to compare elements of these sets is where the theory of 2-categories comes in, where there is an category of categories. While in a 1-category, which has objects and morphisms between (0-morphisms), a 2-category has objects and morphisms (1-morphisms), and morphisms between morphisms (2-morphisms). We have, in fact, already seen this in Cat, which contains many fundamental concepts of category theory. Specifically, in Cat, objects are functions between them, and morphisms are natural transformations between functions.

## 3.1. The 2-category Pair
