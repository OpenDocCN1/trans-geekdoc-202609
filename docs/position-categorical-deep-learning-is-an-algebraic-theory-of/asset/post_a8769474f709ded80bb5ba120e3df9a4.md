# Unrolling Neural Networks via Transfinite Construction

We will reap the benefits of the transfinite construction of free monads on endofunctors, and the corresponding unrolling of these networks. Specifically, with Theorem G.10 heading towards the path of having weight arising out of the categorical framework, we can perform the unrolling of these networks. For the purposes of space and clarity, the unaking is done as length homomorphism of algebras for endofunctors of 2-monads.

**Example J.1** (Iterated Folding RNNs). Consider an algebra $(P, cell^{\text{fold}})$ of $Para(1+A \times -)$, a folding RNN cell (Example I.1). Its unrolling is a $Para(1+A \times -)$ where $\Delta p: P \rightarrow P \times P$ is the copy map.

```
$$1+A \times List(A) \xrightarrow{\Delta p} 1+A \times X\n\gamma(Nil, Cell) \Downarrow (P, cell^{\text{fold}})\nList(A) \xrightarrow{f_{rent}} X\n\quad \quad \quad (17)$$
```

Here the map $f_{rent}$ is the parametric analogue of a *fold* (Example 2.12):

```h
front :: (p, List a) -> x
front p Nil = cell^p (inl ())
front p (Cons a as) = cell^p (inr a (front as))
```

We can see that front is structurally recursive: it processes the head of the list by applying cell^front to the parameter p and the output of the front with the same parameter, and the tail of the same tail.

![](img/92dd63b8e10fefd3f3f227bf65a30b83_29_0.png)

We proceed to show that $\Delta p$ is a valid parametrisation for the parametric morphisms. Unpacking the composition on top right, and the bottom left of Equation (17), respectively, yields parametric maps

```
P × (1 + A × List(A)) → X
nP × (1 + A × List(A)) → X
```

whose implementations are, respectively:

```
(p, q, inl(•)) -> cell^front (p, in(•))
(p, inr(a, as)) -> cell^front (q, a, f(p, as))
(p, •) -> cell^front (p, in(•))
(p, (a, as)) -> cell^front (p, a, f(p, as))
```

It is easy to see that $\Delta p$ is a valid parametrisation of them, "tying" the parameters p and q.

**Example 1.2** (Iterated unfolded). Consider a coalgebra $(P, cell_0, cell_0)$ of $Para(O \times -)$, $i$ is an unfolding cell (Example 1.3). Its unrolling is a $Para(O \times -)$-coalgebra below:

| | |
|---|---|
| $(P, cell_0, cell_0)$ | $(P, f_n)$ | Stream(O) |
| $\Delta p$ | $\gamma((output,next))$ |
| $O \times X$ | $Para(O \times -), (f_n)$ | Stream(O) |

Here $f_n :: P \times X \rightarrow Stream(O)$ is the syntactic analogue of an unfold (Example 1.5):

```
f_n :: (p, x) -> Stream
f_n p x = MKStream (cell_n p x) (f_n p)
```

We can see that $f_n$ is structurally recursive: it produces a stream whose head is $cell_n(p,x)$.

**Example J.3** (Iterated Recursive NN). Consider an algebra $(P, cell^{f_{CSV}})$ of $Para(A + (-)^2)$, i.e. a recursive network cell (Example 1.2). Its unrolling is a $Para(A + (-)^2)$-algebra between:

```
$$\begin{aligned} A + Tree(A)^2 & \text{Para}(A+(-)^2)((P,f_{CSV})) & \to A + X^2 \\ \downarrow \Delta_P & \downarrow (P,cell^{f_{CSV}}) \\ Tree(A) &to X & (P,f_{CSV}) \end{aligned}$$
```

$f_{CSV}$ is a function with the following implementation:

```
f_{CSV} :: (p, Tree a) \to x
f_{CSV} p (Leaf a) = cell^{f_{CSV}} p (inl a)
f_{CSV} p (Node l r) = cell^{f_{CSV}} p (in(f_{CSV} p l))(f_{CSV} p r)
```

This function performs weight sharing, as the recursive call to subtrees is done with the same parameter p.

**Example J.4** (Iterated Mealy cell). Consider an algebra $(P, cell^{Mealy})$ of $Para(I \times O \times -)$, i.e. a Mealy machine cell (Example 2.11). Its unrolling is a $Para(I \times O \times -)$-algebra homomorphism below:

```
$$\begin{aligned} (P,f_m) & \to Mealy_{O,I} \\ \downarrow \Delta_P & \downarrow \gamma(next) \ (P,n) \\ (I \to O \times X) & Para(I \to O \times -)((P,f_n)) \to (I \to O \times Mealy_{O,I}) \end{aligned}$$
```

$f_n$ is a core function with the following implementation:

```
f_n :: (p, x) \to Mealy o
f_n (p, x) = MkMealy $ i - let (o', x') = n p i in (o', x'), f_n p x'
```

**Example J.5** (Iterated Moore machine). Consider a coalgebra $P, cell^{Moore}$ of $Para(O(I \rightarrow -))$, i.e. a Moore machine cell (Example H.7). Its unrolling is $Para(O \times (I \rightarrow -))$-coalgebra homomorphism below:

```
$$\begin{aligned} X & (P,f_n) & \rightarrow Moore_{O,I} \ (P,(o_n)) \\ \searrow \Delta_P & \gamma(next) O \times (I \rightarrow -) \rightarrow X & Para(O\times(I\rightarrow -))((P,f_n)) \rightarrow (I \to O \times Moore_{O,I}) \end{aligned}$$ (21)
```

In code, $f_n$ is a coercive function:

```
f_n :: (p, x) \rightarrow Moore o i
f_n (p, x) = MkMoore \$ \backslash i \rightarrow (o \ p \ x, f_n \ p \ n \ x \ i)
```
