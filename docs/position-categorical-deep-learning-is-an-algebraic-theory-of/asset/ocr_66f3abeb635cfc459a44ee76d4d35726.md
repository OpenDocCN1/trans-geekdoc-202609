**Example 1.3** (Monads as categories). A group $G$, can be represented as a category, with a single object $G$, and morphisms $g: G ightarrow G$ corresponding to elements. Note that $G$ is a group if the binary operation is isomorphic. Note that $G$ is a group if and only if its morphisms are isomorphisms, for each $g: G ightarrow G$ there exists $h: G ightarrow G$ such that $g \circ h = h \circ g = id$. More, we can identify one-object categories, which are not necessarily invertible, with monads.

Having set the essential concepts, we want to discuss a categorical framework which generalizes geometric deep learning (Bronstein, 2021). We will define a powerful notion (monad algebra homomorphism) and demonstrate the specific case of monads induced by group actions. Generalising from monads and their algebras we will find that our theory can express processes structured data from computer science (e.g. lists and trees) and behave in set ways like automata.

The power of theory starts to emerge when we interact different categories. Just as functors of sets and morphisms of groups, there is a more generic concept of structure preserving between categories.

**Definition 1.4** (Functor). Let $C$ and $D$ be two categories. $F: C ightarrow D$ is a functor between them, if it maps each object and morphism of $C$ to one in $D$, and the following conditions hold

+   - For any object $A \in C$, $F(id_A) = id_{D(A)}$.

+   - For any composable morphisms $f, g$ in $C$, $F(g \circ f) = F(g) \circ F(f)$.

**Definition 2.1** (Monad). Let $C$ be a category. A monad on $C$ is a triple $(M, \eta, \mu)$ where $M: C ightarrow C$ is an endofunctor, and $\eta: C ightarrow M$ and $\mu: M \circ M ightarrow M$ are natural transformations (where $\mu$ is function composition), making diagrams in Definition 1. commute.
