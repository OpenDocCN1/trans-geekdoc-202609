Example F.4 (for M-modules). If $M$ is a monad, it is possible to study "M-modules", which we define as monoids equipped with a compatible action of $M^{12}$ terms of the 2-monad $\delta_\epsilon(M) 	imes -$ on the 2-category.

Here $\delta_\epsilon(M)$ is the category whose objects are elements of $M$, and morphisms are the identities. Since $M$ is a monad, $\delta_\epsilon(M)$ is a monadic category, so $\delta_\epsilon(M) 	imes -$ is a monad.
As the set of endomorphisms on a monad $A$ is isomorphic to the set of endofunctors on the category given the deloping of the monad, an M-module can be seen as a one-object algebra for this 2-monad. Indeed, this is a special case of any algebra.

Example F.5 (Cocyles as lax monoids). The monoidal cycles, or "crossed monoids", used in (Dudzik et al., 2024) to study synchrony in networks, can be described as lax monoids for 2-monad algebras. As if $A$ is an M-module, $BA$ is an algebra for $\delta_\epsilon(M) 	imes -$. A lax morphism $1 ightarrow BA$ is a natural transformation of the unique functor $M ightarrow BA$, which is equivalently just a map $D : M ightarrow BA$. The axiom for compositionality is the (right) 1-cycle code for $D$, so 1-ocycles are as lax as lax morphisms $1 ightarrow BA$.
