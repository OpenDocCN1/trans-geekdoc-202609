
引入包管理系统的另一个动机是为了使为 WEKA 软件贡献代码的过程变得更容易，并减轻 WEKA 开发团队的维护负担。插件包的贡献者负责维护其代码并托管可安装的归档文件，而 WEKA 仅跟踪包元数据。包系统还为使用第三方库打开了大门，而这在过去是会被我们劝阻的，以保持 WEKA 的轻量级占用。

图形化包管理器可以通过 WEKA 的 `GUI Chooser` 中的 `Tools` 菜单访问。第一次访问包管理器时，它会下载当前可用包的信息。这需要互联网连接；然而，一旦包元数据已下载，就可以在离线状态下使用包管理器浏览包信息。当然，安装包时仍需要互联网连接。

包管理器在其窗口顶部附近显示一个包列表，并在底部显示一个面板，展示列表中当前选中包的信息。用户可以选择显示尚未安装但可用的包、仅已安装的包，或所有包。该列表显示每个包的名称、所属的宽泛类别、当前已安装的版本（如有）、与所用 WEKA 版本兼容的最新可用包版本，以及一个字段，用于已安装的包指示该包是否已被 WEKA 成功加载。虽然乍一看并不明显，但可以安装特定包的旧版本。列表中的 `Repository version` 字段实际上是一个下拉框。可以通过点击包或类别列标题，按升序或降序对包列表进行排序。

窗口底部的 information 面板为给定包的每个版本提供了可点击的链接。“Latest”始终指包的最新版本，与可用的最高版本号相同。点击其中一个链接会显示进一步的信息，例如包的作者、其许可证、可安装归档的位置以及其依赖项。每个包的信息也可以在托管 WEKA 包元数据的 Web 位置浏览。所有包至少列出一个依赖项——它们可以工作的核心 WEKA 系统的最低版本。一些包还列出了对其他包的进一步依赖。例如，`multi-InstanceLearning` 包依赖于 `multi-InstanceFilters` 包。安装 `multi-InstanceLearning` 时，假设 `multi-InstanceFilters` 尚未安装，系统会告知用户 `multi-InstanceFilters` 是必需的并且将被自动安装。

包管理器显示所谓的 WEKA 的 `official` 包。这些是已提交给 WEKA 团队进行审查并且其元数据已添加到官方中央元数据存储库中的包。出于某种原因，包的作者可能会决定以非官方的方式使其可用。这些包不会出现在 Web 上的官方列表中，也不会出现在图形化包管理器显示的列表中。如果用户知道包含非官方包的归档的 URL，可以通过使用包管理器窗口右上角的按钮来安装它。

每当有新包或现有包的新版本可用时，包管理器会通过显示一个大黄警告图标来通知用户。将鼠标悬停在此图标上会显示一个工具提示弹出窗口，列出新包并提示用户点击 `Refresh repository cache` 按钮。点击此按钮会将所有包信息的新副本下载到用户的计算机上。

包管理器窗口顶部的 `Install` 和 `Uninstall` 按钮正如其名称所示那样工作。可以通过在列表中选择多个条目，一次安装或卸载多个包。默认情况下，WEKA 会尝试加载所有已安装的包，如果由于某种原因无法加载包，则会在列表的 `Loaded` 列中显示一条消息。用户可以通过选择该包然后点击 `Toggle load` 按钮来选择阻止特定包被加载。这将把该包标记为下次启动 WEKA 时不应加载的包。这在不稳定的包正在生成错误、与另一个包冲突（可能是由于第三方库），或以其他方式阻止 WEKA 正常运行时很有用。

## B.3 The Explorer

WEKA 历史上最受欢迎的图形用户界面 Explorer，通过菜单选择和表单填写提供对其所有功能的访问。开始时有六个不同的面板，通过顶部的标签选择，对应 WEKA 支持的各种数据挖掘任务。通过安装适当的包可以获得更多面板。

### Loading the data into the Explorer

为了说明 Explorer 可以做什么，假设我们想从 WEKA 下载中包含的天气数据构建决策树。启动 WEKA 以获取 `GUI Chooser`。从右侧的五个选项中选择 `Explorer`。（其他选项之前已提及；`Simple CLI` 是老式的命令行界面。）

接下来你看到的是主 Explorer 屏幕。顶部的六个标签是 Explorer 支持的基本操作；现在我们位于 `Preprocess`。点击 `Open file` 按钮以调出标准对话框，通过该对话框可以选择文件。选择 `weather.arff` 文件。如果它是 CSV 格式，请从 `ARFF data files` 更改为 `CSV data files`。

加载文件后，Preprocess 屏幕会告诉你有关数据集的信息。它有 14 个实例和五个属性（左中）；属性称为 `outlook`、`temperature`、`humidity`、`windy` 和 `play`（左下）。第一个属性 `outlook` 默认被选中（你可以通过点击选择其他属性），它没有缺失值，有三个不同的值，且没有唯一值。实际值是 `sunny`、`overcast` 和 `rainy`，它们分别出现五次、四次和五次（右中）。右下方的直方图显示了类 `play` 的两个值中每个值对于 `outlook` 属性的每个值出现的频率。使用属性 `outlook` 是因为它出现在直方图上方的框中，但你也可以绘制任何其他属性的直方图。这里 `play` 被选为类属性；它用于为直方图着色，任何需要类值的过滤器也使用它。

`outlook` 属性是名义的。如果选择数值属性，你会看到其最小值和最大值、均值和标准差。在这种情况下，直方图将显示类随该属性变化的分布。

你可以通过点击其复选框并使用 `Remove` 按钮来删除属性。`All` 选择所有属性，`None` 不选择任何属性，`Invert` 反转当前选择，`Pattern` 选择名称匹配用户提供的正则表达式的属性。你可以通过点击 `Undo` 按钮来撤销更改。`Edit` 按钮会调出一个编辑器，允许你检查数据、搜索特定值并编辑它们，以及删除实例和属性。右键点击值和列标题会调出相应的上下文菜单。
