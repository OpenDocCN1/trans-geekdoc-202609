
采样是一个如此简单的过程，以至于几乎不需要讨论或解释。但在某些情况下，生成指定大小的随机样本会变得稍微具有挑战性。如果训练实例一个接一个地到来，但它们的总数——`N` 的值——事先未知怎么办？或者假设我们需要在任何时候都能对来自实例连续流的指定大小的样本运行学习算法，而无需重复执行整个采样操作？或者训练实例的数量如此庞大，以至于在采样之前将它们全部存储起来是不切实际的？

所有这些情况都需要一种方法，能够在不存储所有实例并等待最后一个实例到达后再开始采样程序的情况下，从输入流中生成随机样本。是否有可能生成指定大小的随机样本，同时仍然保证每个实例被选中的机会相等？答案是 *是*。此外，还有一个简单的算法可以做到这一点。

思路是使用大小为 `r` 的“蓄水池”，即要生成的样本的大小。首先，将输入流中的连续实例放入蓄水池，直到它填满。如果流在那里停止，我们将得到一个平凡的情况：从相同大小的输入流中抽取大小为 `r` 的随机样本。但很可能还会出现更多实例。下一个实例应以概率 `r/(r + 1)` 被包含在样本中——事实上，如果输入流在那里停止（`N = r + 1`），*任何* 实例都应以此概率出现在样本中。因此，以概率 `r/(r + 1)` 我们用这个新实例替换蓄水池中的一个随机实例。我们继续以同样的方式，以概率 `r/(r + 2)` 用下一个实例替换随机的蓄水池元素，依此类推。一般来说，输入流中的第 `i` 个实例以概率 `r/i` 被放置到蓄水池的随机位置。通过归纳很容易证明，一旦处理了该实例，任何特定实例位于蓄水池中的概率是相同的，即 `r/i`。因此，在程序的任何阶段，蓄水池都包含来自输入流的大小为 `r` 的随机样本。你可以在任何时候停止，并且确信蓄水池中包含所需的随机样本。

该方法是有放回地采样？无放回采样。有放回采样稍微困难一些——尽管对于大型数据集和小蓄水池而言，两者之间的差异很小。但如果你真的想要一个大小为 `r` 的有放回样本，你可以设置 `r` 个独立的蓄水池，每个大小为 1。同时为所有这些运行算法，并且在任何时候，它们的并集都是一个有放回的随机样本。

## 6.5 清洗

困扰实际机器学习的一个问题是数据质量低下。大型数据库中的错误极其常见。属性值，以及类别值，也经常不可靠且被损坏。尽管解决这个问题的一种方法是仔细检查数据，但机器学习技术本身有时也能帮助解决问题。

### 改进决策树

一个令人惊讶的事实是，从训练数据中归纳的决策树通常可以通过丢弃训练集中被错误分类的实例、重新学习，然后重复直到没有被错误分类的实例为止，而在不损失精度的情况下进行简化。在标准数据集上的实验表明，这几乎不影响 C4.5 的分类准确性，C4.5 是一种标准的决策树归纳方案。在某些情况下它会略有改善；在其他情况下它会略有下降。差异很少具有统计学意义——即使有，优势也可能各不相同。该技术影响的是决策树的规模。生成的树无一例外地比原始树更小，尽管它们的性能大致相同。

这是什么原因？当决策树归纳方法剪掉一个子树时，它会应用一个统计检验来判断该子树是否“由数据证实”。剪枝的决定在训练集上的分类准确性上接受少量牺牲，相信这将改善测试集性能。一些原本被未剪枝树正确分类的训练实例现在会被剪枝后的树错误分类。实际上，已经做出了忽略这些训练实例的决定。

但该决定仅在局部应用，在被剪枝的子树中。其影响并未被允许向上渗透到树的更高层，也许会导致对分支属性做出不同的选择。从训练集中移除被错误分类的实例并重新学习决策树，只是将剪枝决定推向逻辑上的结论。如果剪枝策略是好的，这不应损害性能。而且它可能会通过允许做出更好的属性选择而改善性能。

无疑，咨询人类专家会更好。可以将错误分类的训练实例提交以供验证，并删除那些被发现错误的内容——更好的是，予以纠正。

请注意，我们假设实例不是以任何系统的方式被错误分类。如果实例在训练集和测试集中都被系统性地损坏——例如，一个类别值可能被另一个类别值替代——那么在有错误的训练集上训练在（同样有错误的）测试集上获得更好性能是理所当然的。

有趣的是，已经证明当向属性（而不是类别）添加人工噪声时，如果以相同的方式向训练集添加相同的噪声，则测试集性能会得到改善。换句话说，当属性噪声是问题时，如果要在“脏”数据上评估性能，就不应该在“干净”数据集上训练。一个学习方案如果有机会，可以在一定程度上学会补偿属性噪声。本质上，它可以学习哪些属性不可靠，以及如果所有属性都不可靠，如何最好地将它们结合起来以产生更可靠的结果。从训练集的属性中去除噪声否定了学习如何最好地对抗该噪声的机会。但对于类别噪声（而不是属性噪声），如果可能，最好在无噪声实例上训练。

### 鲁棒回归

噪声数据引起的问题在线性回归中已为人所知多年。统计学家经常检查数据中的异常值并手动删除它们。在线性回归的情况下，异常值可以目视识别——尽管永远无法完全确定异常值是错误还是只是令人惊讶但正确的数值。异常值会显著影响通常的最小二乘回归，因为平方距离度量会夸大远离回归线的点的影响。

解决异常值问题的统计方法称为 *鲁棒*。使回归更鲁棒的一种方法是使用绝对值距离度量而不是通常的平方度量。这会削弱异常值的影响。另一种可能性是尝试自动识别异常值并将其排除在考虑之外。例如，可以形成一条回归线，然后排除距离该线最远的 10% 的点。第三种可能性是最小化回归线偏差平方的 *中位数*（而不是均值）。事实证明，该估计量非常鲁棒，实际上能够应对 `X` 方向的异常值以及 `Y` 方向的异常值——这是人们通常认为的异常值方向。
