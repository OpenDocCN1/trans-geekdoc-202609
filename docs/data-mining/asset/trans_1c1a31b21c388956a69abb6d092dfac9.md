# 第14章 高级概率方法

## 摘要
在本章中，我们将深入探讨更具体和更高级的概率机器学习方法。现在是时候以正式的方式介绍数据挖掘和机器学习中的概率方法。我们首先概述了在数据挖掘和实际机器学习中广泛使用的概率论的基本方面。介绍了最大似然方法，以及用于处理隐变量的学习方法，包括众所周知的期望最大化算法的一般形式。最大似然方法在更具贝叶斯性质的方法的背景下被引用，并且还讨论了变分方法和采样程序的作用。贝叶斯网络被提出并用于描述各种方法，例如混合模型、主成分分析和潜在狄利克雷分配，以及其他概率方法。讨论了条件概率模型，包括回归和多类分类的关键推导。它们与广泛使用的广义线性模型的关系也得到了概述。还介绍了用于建模和从序列中提取信息以及结构化预测问题的方法，包括马尔可夫模型、隐马尔可夫模型、马尔可夫随机场和条件随机场。还对专门用于创建和使用这些模型和方法的软件包进行了调查。
