
The network shown in [Fig. D.5B](#FigD1_687-703_B9780443158889000248.xhtml#f0030) can be constructed and trained in a layer-by-layer manner. To see this consider an RBM with visible variables `v` ![Equation](images/F000248si127.png) and two layers of hidden variables `h^(1)` ![Equation](images/F000248si128.png) followed by `h^(2)` ![Equation](images/F000248si129.png) on top. A joint model for `P(v, h^(1), h^(2))` ![Equation](images/F000248si130.png) can be defined as either a three-layer Boltzmann machine or, by restructuring the parameterization of the lower two layers, as a belief network with an RBM at the top using

```

```
