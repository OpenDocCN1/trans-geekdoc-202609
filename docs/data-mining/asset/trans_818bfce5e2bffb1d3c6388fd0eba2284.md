正如任何受到强烈商业关注的新兴技术一样，机器学习的使用在技术界，有时也在大众媒体中，被大量炒作所包围。夸大其词的报道称，通过让学习算法在海量数据中自由运行，可以挖掘出秘密。但机器学习中没有魔术，没有隐藏的力量，没有炼金术。相反，存在一套可识别的简单而实用的技术，往往能够从原始数据中提取有用的信息。本书描述了这些技术并展示了它们的工作原理。

本书目标是介绍数据挖掘中使用的机器学习工具和技术。阅读后你将了解这些技术及其优势和适用性。若想用自己的数据实验，可轻松使用 `WEKA` 软件。但 `WEKA` 并非唯一选择。例如，自由可用的统计计算环境 `R` 包含许多机器学习算法。`Python` 编程语言的爱好者可关注名为 `scikit-learn` 的流行库。现代分布式计算的“大数据”框架，如 `Apache Spark`，也提供机器学习支持。实践中部署机器学习的选项众多。本书讨论基础学习算法，不深入软件特定实现细节。适当时我们会指出所讨论算法在 `WEKA` 软件中的位置。我们也简要介绍用于从高维数据进行所谓“深度学习”的其他机器学习软件。然而，大多数软件特定信息被放在附录中。

本书在提供数据挖掘案例研究的贸易书籍所采取的高度实用方法，与当前机器学习教材中更理论、原则驱动的阐述之间架起桥梁。关于这些书籍的简要描述出现在第1章末尾的 *进一步阅读* 部分：[第1章](#Ch001_3-42_B9780443158889000029.xhtml#Ch001_3-42_B9780443158889000029)：“它到底是关于什么的？” 这道鸿沟相当宽广。要有效应用机器学习技术，你需要了解其工作原理；这不是一种可盲目应用并期望获得好结果的技术。不同问题产生不同技术，但很少能明显看出哪种技术适合特定情况；你需要了解可能解决方案的范围。我们涵盖了极其广泛的技术范围。我们能做到这一点，因为与许多贸易书籍不同，本卷不推广任何特定商业软件或方法。我们包含大量使用足够小以便跟进的示例数据集的示例。真实数据集过大无法展示，且通常是公司机密。我们的选集并非用于说明实际大规模问题，而是帮助你理解不同技术的作用、工作方式和应用范围。

本书面向对机器学习当前实践背后的原理和思想感兴趣的技术意识强的普通读者。信息专业人士也感兴趣，他们需要熟悉这项新技术，以及所有希望深入技术理解机器学习涉及内容的人。它面向信息系统从业者、程序员、顾问、开发者、数据科学家、信息技术经理、规范编写者、专利审查员、好奇的普通人以及学生和教授等多元受众，他们需要一本易读、配有大量插图的书籍，描述主要机器学习技术是什么、做什么、如何使用以及如何工作。它实践导向，带有强烈的“如何操作”色彩，包含算法和经常性的伪代码。所有从事实际数据挖掘的人都将直接受益于所描述技术。本书面向希望穿透机器学习炒作背后现实的人，以及寻求实用、非学术、不矫饰方法的人。本书大部分内容避免要求特定理论或数学知识。然而，认识到该学科成熟后日益复杂，我们在章节和附录中加入了大量理论材料，包括[第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)，“深度学习”，[第14章](#Ch015_516-570_B9780443158889000157.xhtml#Ch015_516-570_B9780443158889000157)，“高级概率方法”，[附录 A](#TableA1_617-636_B9780443158889000212.xhtml#TableA1_617-636_B9780443158889000212)，“理论基础”，和[附录 D](#FigD1_687-703_B9780443158889000248.xhtml#FigD1_687-703_B9780443158889000248)，“深度学习的技术细节”，因为这是充分理解近期实践技术，特别是深度学习和概率机器学习所必需的。
