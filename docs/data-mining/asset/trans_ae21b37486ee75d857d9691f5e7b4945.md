
前向逐段加性回归容易过拟合，因为每次添加的模型都会使对训练数据的拟合越来越紧密。要决定何时停止，请使用交叉验证。例如，对多达用户指定的最大迭代次数的每个迭代次数执行交叉验证，并选择使交叉验证平方误差估计最小的一个。这是一个良好的停止准则，因为交叉验证能提供对未来数据误差的相当可靠的估计。顺便说一下，将此方法与简单线性回归作为基学习器结合使用，实际上将多元线性回归与内置属性选择结合起来，因为下一个最重要的属性的贡献只有在它降低交叉验证误差时才会被包含。

为了实现方便，前向逐段加性回归通常从一个零级模型开始，该模型仅预测训练数据上类别的均值，以便每个后续模型拟合残差。这提示了防止过拟合的另一种可能性。不要通过减去模型的全部预测来为下一个模型生成目标值，而是先将预测乘以用户指定的 0 到 1 之间的常数因子进行收缩，然后再减去。这减少了模型对残差的拟合，从而降低了过拟合的可能性。当然，这可能会增加达到一个良好的加性模型所需的迭代次数。减小乘数有效地抑制了学习过程，增加了在恰当时刻停止的机会——但也增加了运行时间。

## 8.6 可解释的集成

Bagging、boosting 和随机化都会产生分类器的集成。这使得分析从数据中提取了何种信息变得非常困难。最好有一个具有相同预测性能的单一模型。一个可能性是通过从实例空间随机采样点并为其分配集成分类器预测的类别标签来生成人工数据集，然后从这个新数据集中学习决策树或规则集。为了使树获得与集成相似的预测性能，可能需要庞大的数据集，但在极限情况下，这种策略应该能够复制集成分类器的性能——如果集成本身由决策树组成，则肯定如此。
