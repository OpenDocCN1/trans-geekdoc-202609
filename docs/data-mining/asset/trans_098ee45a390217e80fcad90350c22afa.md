虽然 sigmoid 函数很受欢迎，但双曲正切函数（`tanh`）有时更受青睐，部分原因是它在 0 处具有稳定状态。然而，最近 `rectify()` 函数或 `rectified linear units`（`ReLUs`）被发现能在许多不同的场景下取得更优的结果。由于该函数在负参数值时为 0，模型中的某些单元会产生 0 的激活，从而赋予一种在许多上下文中很有用的“稀疏性”特性。此外，其梯度特别简单——要么是 0 要么是 1。当激活时激活函数梯度恰好为 1 这一事实有助于解决 `vanishing or exploding gradient problem`——我们将在后面关于循环网络的部分更详细地讨论这一点。`ReLUs` 是 `h^(l)(x)`<mml:math><mml:msup><mml:mrow><mml:mi mathvariant="bold-italic">h</mml:mi></mml:mrow><mml:mrow><mml:mfenced open="(" close=")"><mml:mrow><mml:mi>l</mml:mi></mml:mrow></mml:mfenced></mml:mrow></mml:msup><mml:mrow><mml:mfenced open="(" close=")"><mml:mrow><mml:mi mathvariant="bold-italic">x</mml:mi></mml:mrow></mml:mfenced></mml:mrow></mml:math>![Equation](images/F00011Xsi31.png) 的流行选择，而分段线性函数（[表 10.3](#Ch011_391-432_B978044315888900011X.xhtml#t0020) 的最后一项）也在深度学习系统中变得越来越流行。像 `ReLUs` 一样，这些函数在 0 处不可微，但可以通过使用次梯度来应用梯度下降，这意味着 `h′(0)`<mml:math><mml:mi>h</mml:mi><mml:mo accent="false">&#8242;</mml:mo><mml:mo stretchy="false">(</mml:mo><mml:mn>0</mml:mn><mml:mo stretchy="false">)</mml:mo></mml:math>![Equation](images/F00011Xsi32.png) 可以设为 `a`<mml:math><mml:mi>a</mml:mi></mml:math>![Equation](images/F00011Xsi33.png)。
