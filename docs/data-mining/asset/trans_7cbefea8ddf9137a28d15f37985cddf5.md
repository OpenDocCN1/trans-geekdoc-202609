
- 是否由系统本身造成？
- 为什么他们会受到伤害？

## 定义公平时需要考虑的一些因素包括：

* 我们是在解决 *代表性伤害*，即模型延续了有害的刻板印象，以伤害性的方式代表受保护群体？还是在解决 *结果伤害*，即模型的预测被用于决策，而这些决策的结果造成了实质性或经济性伤害？例如，我们之前讨论过的将负面情感分配给具有刻板印象的黑人姓名的情感分类器，就造成了代表性伤害，因为它以代表人们的方式延续了令人痛苦的种族主义观点。另一方面，如果我们用同样的情感分类器来分析简历，并导致较少黑人获得工作面试机会，这就是结果伤害。
* 在当前情境下，*公平是否应对应于平等* between protected groups，还是存在正当理由使得平等并非理想的解决方案，例如混杂因素或资格水平的差异？这种情况的一个例子出现在 1970 年代加州大学伯克利分校招生研究中。该研究发现，虽然女性被录取的比例低于男性，但这可以用女性倾向于申请比男性更具选择性的系来解释。在按系分析结果时，女性的录取率通常高于男性。这种反直觉且听起来不可能的情形实际上是由于一种被称为 *辛普森悖论* 的现象而可能发生的。该研究得出结论，招生过程中不存在性别偏见。心理学研究得出结论，当“公平”（在功绩制意义上）与平等冲突时，人类倾向于优先考虑公平。如果（功绩制）公平与平等冲突，我们必须思考如何平衡这些相互竞争的目标。
* 是否存在受保护群体之间的潜在 *差异*，我们应接受数据中这些差异带来的后果还是纠正这些差异？例如，在关于刑事司法背景中歧视性决策的研究（如再犯风险评分）中，一些研究者认为，由于不同人口群体在特征上的分布不同，因此预期它们在理想化的风险评分（例如犯罪概率）上的分布也会不同。这种现象被称为 *次边际性*。该理论的支持者认为，由于人口群体之间风险分布的差异被假定为合法、功绩制且估计良好，因此人口群体之间结果概率或错误率的差异可能并不对应于不公平的歧视。另一方面，如果风险差异源于不公平的原因，我们就不应不加批判地接受这些差异所带来的含义。
* 我们是否应旨在纠正社会中的偏见，而不仅仅是数据中的偏见？换句话说，我们的干预是否应旨在执行 *公平的积极平权*？

### 你的问题定义是否包含偏见？

当通过数据挖掘解决现实世界问题时，我们必须将问题转化为数据挖掘可以解决的问题，这通常是通过分类或回归模型预测目标变量。定义数据挖掘问题的过程是一个可能无意引入偏见的阶段，即通过做出系统性地损害或有利于受保护人口群体的决定。在许多情况下，类别变量被选中是因为它是方便可测量的代理，代表我们真正关心的事物。例如，在信用评分中，可测量的类别变量“此人偿还了贷款”被用作更难以捉摸的事物的代理，“此人应获得贷款”。重要的是要记住，这是一个为方便而选择的代理，不应被视为信用状况的绝对、客观和最终的定论。更一般地说，我们必须小心类别变量的选择不会造成伤害。在招聘中，员工留存概率可能会被用作是否面试或雇佣候选人的代理。如果某些人口群体的员工留存率高于其他群体（例如，由于面临职场歧视，女性比男性更频繁地离开科技行业），使用员工留存作为预测目标将导致系统性地向女性提供更少职位。

### 框架陷阱

一旦我们将现实世界问题转化为数据挖掘问题，很容易忘记我们为解决数据挖掘问题而构建的系统存在于更大的现实世界背景中。未能考虑这一更广泛的社会技术背景，而机器学习系统只是其中一个组成部分，被称为 *框架陷阱*。如果我们不考虑机器学习模型的输出如何在现实世界决策中使用，以及这些决策的连锁效应是什么，我们就无法使更广泛的社会技术系统在端到端意义上完全公平。例如，在保释和量刑决定中，AI系统做出的再犯风险评分通常只是作为建议提供给法官，法官做出最终决定。法官可能受到 *自动化偏见* 的影响，即在没有适当批判的情况下接受算法的建议，他们可能完全忽略算法的建议，或以系统性偏见的方式偏离建议。因此，对AI系统的公平干预可能不会产生预期效果，例如促使法官对AI公平干预做出过度补偿反应，从而表现出更具偏见的行为。
