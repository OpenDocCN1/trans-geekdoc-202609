
在实践中，还有几层附加在两个主要子层之上。这些层本质上只是采用了深度学习社区为帮助训练深度神经网络而开发的各种架构“技巧”。更具体地说，在每个子层之后都会执行 `dropout` 和 `layer normalization`。（`layer normalization` 与批量归一化类似，但它是对层中的神经元进行归一化，而不是对小批量中的数据点进行归一化。）最后，每个子层周围都有一个残差连接。参见 [图 11.10](#Ch012_433-471_B9780443158889000121.xhtml#f0055) 以了解 `transformer block` 的概述。

通过将这些 `transformer blocks` 中的几个堆叠在一起，我们可以获得一个强大的深度神经网络模型。原始论文在系统的每个模块中都使用了 `N` = 6 个 `transformer blocks`，即 `encoder` 和 `decoder`，整个系统设计用于神经机器翻译。在语言模型中，最终层通常是 `softmax` 层，用于输出文本序列中下一个词的预测概率。

细心的读者会注意到，`transformer block` 接受三个输入（`queries`、`keys` 和 `values`）并产生一个输出，因此这些模块如何堆叠并不完全明显。实际上，使用 `transformer block` 有几种不同的方法，具体取决于如何将块的输入数据分配给 `queries`、`keys` 和 `values`，这些方法对该问题有不同的处理方式。在 `self-attention` 中，我们在单个输入序列内部应用注意力。我们希望关注的上下文序列（具有 `keys` 和相应 `values` 的项）与我们希望进行预测的项集合（`queries`）相同。因此我们经常设置 `Q` = `K` = `V` = `x`，其中输入序列 `x` 表示为序列中每个 token 的嵌入数组。

对于 `global self-attention`，我们希望一次性处理整个序列，以便序列中的每个位置都可以关注其他每个位置。另一方面，如果我们的目标是预测序列中的下一个词，就不能提前查看未来的词，否则就属于“作弊”。所谓的 `causal self-attention` 使用掩码来防止模型关注序列中当前及后续的词，从而保留这种“`auto-regressive property`”。

在其他情况下，项和 `queries` 可能是不同的实体集合，这种情况称为 `cross-attention`。例如，在 `NMT` 中，`encoder` 可用于为第一语言的输入序列生成潜在表示，我们可能希望将其作为输入提供给 `decoder`，后者旨在预测第二语言中 token 的翻译序列。然后我们可以将 `K` 和 `V` 设置为 `encoder` 生成的上下文嵌入，并将 `Q` 设置为翻译后 token 的嵌入。

### 位置编码

在语言模型中使用 `transformer` 架构仍存在一个挑战。`RNNs` 和 `CNNs` 对自然语言数据有效，因为它们明确处理了此类数据的顺序特性。诸如 `LSTMs` 之类的 `RNNs` 以从左到右的方式处理数据，而 `CNNs` 则在序列的每个位置上滑动卷积滤波器以寻找局部模式。然而，迄今为止我们对 `transformer` 模型所描述的内容都没有利用 token 顺序排列的信息，而它们需要这样做才能与执行此操作的模型竞争。它们如何实现这一点？

解决方案最终证明就像向每个 token 的表示中注入一些关于其位置的信息一样简单。首先，在输入层我们最初用词嵌入表示每个 token，以向量形式捕捉词义，就像我们在 `word2vec` 中看到的那样。这些 `input embeddings` 可以通过学习获得，也可以从预训练的词嵌入模型中获得。接下来，我们向每个 `input embeddings` 添加一个由词在序列中的索引决定的“`positional encoding`” (`PE`) 向量，从而使模型能够获得位置信息。

位置编码与 `input embeddings` 的维度相同，以便它们可以相加。嵌入的维度设置为 `d_model`，与 `multihead attention` 层产生的维度相同。`transformer` 模型的作者建议分别对偶数维和奇数维使用 `sin` 和 `cos` 函数：

`PE(pos,2*i) = sin(pos / n^(2*i / d_model))`

`PE(pos,2*i+1) = cos(pos / n^(2*i / d_model))`
