
一个隐私机制 `M(X)` 是 (`ϵ`, `δ`)-差分隐私的，如果对于所有仅在单个元素上不同的数据集对 `D1` 和 `D2`，以及所有 `S` ⊆ `Range(M)`，

`Pr(M(D1) ∈ S) ≤ e^(ϵ) × Pr(M(D2) ∈ S) + δ.` (7.5)

如果 `δ` = 0，则该定义对应于 `ϵ`-差分隐私。为了使定义提供有意义的隐私保证，`δ` 必须非常小，因为它仅确保 `ϵ`-差分隐私的保证以概率 `1 - δ` 得到执行。

不正式地说，这些保证和其他有用属性包括：

- 抵消关联攻击。无论可用的辅助数据是什么，攻击者都无法撤销查询因噪声而产生的混淆，以提高其隐私参数 `ϵ` 和 `δ`。
- 后处理下的封闭性。在没有访问私有数据库的情况下，任何进一步的计算都不能使算法 `M` 的差分隐私性降低。
- 为贡献数据的个人提供经济保证。对于任何效用函数，由于用户决定将其数据贡献给数据集，其效用值不会改变超过 `e^(ϵ)` 的乘法因子，该因子对于 `ϵ` 的小值近似等于 `1 + ϵ`。
- 群体隐私。可以计算差分隐私的量化程度，即其如何扩展到一组个人，甚至整个家庭。
- 组合性。在执行多个差分隐私计算时，整体过程的隐私参数会以优雅且可度量的方式增加。如果执行一个 `ϵ1`-差分隐私操作，随后执行一个 `ϵ2`-差分隐私操作，则整体过程是 (`ϵ1 + ϵ2`)-差分隐私的。

这种组合计算在 (`ϵ`, `δ`)-差分隐私的情况下要复杂得多，但借助一些复杂的数学技巧，这些技巧可以外包给软件库，它是可以完成的。对于固定的 `δ` 值，我们可以将第 `i` 个查询的 `ϵi` 视为其“隐私成本”，该成本会累积以消耗整体目标“隐私预算” `ϵoverall`。

## 差分隐私机器学习

实际上，差分隐私机器学习的艺术在于精心设计隐私保护的学习方案，以便在保持令人满意性能的同时实现目标差分隐私水平。我们可以从拉普拉斯机制的方程看出，我们越想使其更私密（`ϵ` 越小），就需要添加越多的噪声，从而使结果失真。一般来说，差分隐私与输出的准确性或有用性之间存在权衡，通常称为“效用”。我们必须设计我们的隐私保护学习算法来管理这种隐私-效用权衡。
