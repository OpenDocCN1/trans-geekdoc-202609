## Maximum a Posteriori Parameter Estimation

Maximum likelihood assumes that all parameter values are equally likely a priori; we do not judge some parameter values to be more likely than others before we have considered the observations. Again, the same idea can be applied to learn conditional probability models.

We have reverted to the semicolon notation to emphasize that maximum a posteriori parameter estimation involves point estimates of the parameters, evaluating them under the likelihood and prior distributions. This contrasts with fully Bayesian methods (discussed later) that explicitly manipulate the distribution of the parameters, typically by integrating over the parameter’s uncertainty instead of optimizing a point estimate. The use of the “given” notation in place of the semicolon is more commonly used with fully Bayesian methods, and we will follow this convention.

## 13.2 Bayesian Networks

The Naïve Bayes classifier of [Section 4.2](#Ch004_91-164_B9780443158889000054.xhtml#s0020) and the logistic regression models of [Section 4.6](#Ch004_91-164_B9780443158889000054_a.xhtml#s0095) both produce probability estimates rather than hard classifications. For each class value, they estimate the probability that a given instance belongs to that class. Most other types of classifiers can be coerced into yielding this kind of information if necessary. For example, probabilities can be obtained from a decision tree by computing the relative frequency of each class in a leaf and from a decision list by examining the instances that a particular rule covers.
