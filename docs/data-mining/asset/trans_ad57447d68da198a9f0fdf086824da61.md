
有一个需要注意的地方。如果基于训练数据最大化对数似然，添加更多边总是会更好；结果网络将仅仅过拟合。

可以采用各种方法来解决这个问题。一个可能是使用交叉验证来估计拟合优度。第二个是根据参数数量对网络复杂性添加惩罚，即所有概率表中独立估计值的总数。对于每个表，独立概率的数量是条目总数减去最后一列中的条目数，因为所有行必须总和为 1，所以最后一列可以由其他列确定。设 `K` 为参数数量，`LL` 为对数似然，`N` 为数据中的实例数量。评估网络质量的两种常用度量是 *赤池信息准则* (`AIC`)：

以及基于 MDL 原则的以下最小描述长度 (`MDL` 指标)：

`MDL score = -LL + K/2 log N.`<mml:math><mml:mi mathvariant="italic">MDL score</mml:mi><mml:mo>=</mml:mo><mml:mo>&#8722;</mml:mo><mml:mi mathvariant="italic">LL</mml:mi><mml:mo>+</mml:mo><mml:mfrac><mml:mrow><mml:mi>K</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:mfrac><mml:mi mathvariant="normal">log</mml:mi><mml:mi>N</mml:mi><mml:mo>.</mml:mo></mml:math>

在这两种情况下，对数似然被取负，因此目标是最小化这些分数。

第三种可能是对网络结构赋予先验分布，并通过结合其先验概率与数据赋予网络的概率来找到最可能的网络。这是网络评分的最大后验方法。根据所使用的先验分布，它可以采取各种形式。然而，真正的贝叶斯主义者会平均所有可能的网络结构，而不是为预测而单独挑出一个特定的网络。不幸的是，这通常需要大量的计算。一种简化的方法是对给定网络的子结构的所有网络结构进行平均。事实证明，这可以通过改变计算条件概率表的方法来实现，从而使 resulting 概率估计隐式包含来自所有子网络的信息。这种方法的细节相当复杂，这里不予描述。

如果使用正确的度量进行评分，搜索良好网络结构任务可以大大简化。请回忆，基于网络的单个实例的概率是来自各种条件概率表的各个概率的乘积。数据集的总体概率是所有实例的这些乘积的乘积。因为乘积中的项可以互换，乘积可以重写为将与同一表相关的所有因子组合在一起。对数似然也同样适用，使用和代替乘积。这意味着似然可以针对网络的每个节点单独优化。这可以通过向正在优化的节点添加或删除来自其他节点的边来实现；唯一的约束是不能引入循环。相同的技巧也适用于使用局部评分度量如 `AIC` 或 `MDL` 而不是普通对数似然的情况，因为惩罚项分为几个分量，每个节点一个，每个节点可以独立优化。

### Specific Algorithms

现在我们转向学习贝叶斯网络的实际算法。一种简单且非常快的学习算法，称为 `K2`，从给定的属性排序（即节点）开始。然后它依次处理每个节点，并贪婪地考虑从先前处理的节点向当前节点添加边。在每一步中，它添加使网络得分最大化的边。当没有进一步改进时，注意力转向下一个节点。作为防止过拟合的额外机制，每个节点的父节点数量可以限制为预定义的最大值。因为只考虑来自先前处理节点的边并且有一个固定顺序，所以该过程不能引入循环。然而，结果取决于初始顺序，因此有意义的是用不同的随机顺序多次运行算法。

`Naïve Bayes` 分类器是一个网络，其中从类属性到每个其他属性都有一条边。在为分类构建网络时，有时将此网络用作搜索的起点会有所帮助。这可以在 `K2` 中通过强制类变量成为排序中的第一个并适当初始化边集来完成。

另一个可能有用的技巧是确保数据中的每个属性都在表示类属性的节点的 *Markov blanket* 中。节点的马尔可夫毯包括其所有父节点、子节点和子节点的父节点（通常称为“共父节点”）。可以证明，给定其马尔可夫毯中节点的值，节点与所有其他节点条件独立。因此，如果一个节点不存在于类属性的马尔可夫毯中，其值与分类完全无关。我们在 [图 13.3](#Ch014_485-514_B9780443158889000145.xhtml#f0020) 中展示了贝叶斯网络及其马尔可夫毯的示例。相反，如果 `K2` 找到一个网络，该网络未在类节点的马尔可夫毯中包含相关属性，添加一条边来纠正这一缺陷可能会有所帮助。一种简单的方法是根据哪种选项避免循环，从属性节点到类节点或从类节点到属性节点添加一条边。

一种更复杂但更慢的 `K2` 版本不是对节点排序，而是贪婪地考虑在任意节点对之间添加或删除边（当然始终确保无环）。进一步的步骤是考虑反转现有边的方向也是如此。与任何贪婪算法一样，结果网络仅代表评分函数的 *局部* 最大值；始终建议用不同的随机初始配置多次运行此类算法。也可以使用更复杂的优化策略，如模拟退火、禁忌搜索或遗传算法。
