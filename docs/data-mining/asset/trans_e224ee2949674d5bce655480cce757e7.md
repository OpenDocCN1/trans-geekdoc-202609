
### 约束

可以通过点击通用对象编辑器底部的 `Filter` 按钮获得所选功能约束的列表。如果当前数据集表现出该列表中已勾选但 `Remove` 过滤器功能中缺少的某些特征，则 `Preprocess` 面板中 `Choose` 右侧的 `Apply` 按钮将被置灰，当按下 `Choose` 按钮时出现的列表中的条目也将被置灰。虽然你无法应用它，但你仍可选择一个置灰的条目，使用通用对象编辑器检查其选项、文档和功能。你可以通过在约束列表中取消选中它们来释放单个约束，或点击 `Remove filter` 按钮清除所有约束。

### 聚类与关联规则

使用 `Cluster` 和 `Associate` 面板调用聚类算法和寻找关联规则的方法。进行聚类时，WEKA 会显示聚类的数量以及每个聚类包含的实例数。对于某些算法，可以通过在对象编辑器中设置参数来指定聚类数。对于概率聚类方法，WEKA 会衡量聚类在训练数据上的对数似然；该值越大，模型对数据的拟合越好。增加聚类数通常会提高似然，但可能导致过拟合。

`Cluster` 面板上的控件与 `Classify` 的类似。你可以指定一些相同的评估方法——使用训练集、提供的测试集和百分比拆分（后两者与对数似然一起使用）。另一种方法，类到聚类评估，比较所选聚类与数据中预先分配的类匹配程度如何。你选择一个属性（必须是名义属性）来表示“真实”类。聚类数据后，WEKA 会确定每个聚类中的多数类，并打印混淆矩阵，显示如果使用聚类代替真实类会有多少错误。如果你的数据集有类属性，你可以在聚类期间通过从属性下拉列表中选择它来忽略它，并查看聚类与实际类值对应程度如何。最后，你可以选择是否存储聚类以便可视化。不这样做的唯一原因是节省空间。与分类器一样，你可以通过右键单击结果列表来可视化结果，这允许你查看二维散点图。如果你选择了类到聚类评估，则会显示类分配错误。对于 `Cobweb` 聚类方案，你也可以可视化树。

`Associate` 面板比 `Classify` 或 `Cluster` 更简单。WEKA 包含几种用于确定关联规则的算法，但没有用于评估此类规则的方法。

### 属性选择

`Select attributes` 面板提供了多种属性选择方法。这些方法涉及属性评估器和搜索方法。两者均以通常方式选择并通过对象编辑器配置。你还必须决定使用哪个属性作为类。属性选择可以使用完整的训练集或使用交叉验证进行。在后一种情况下，它对每个折分别进行，输出显示每个属性被选中的次数，在多少个折中被选中。结果存储在历史列表中。当你在此处右键单击一个条目时，你可以根据所选属性可视化数据集（选择 `Visualize reduced data`）。

### 可视化

`Visualize` 面板帮助你可视化数据集，而不是分类或聚类模型的结果，而是数据集本身。它显示每对属性的二维散点图矩阵。你可以使用底部的控件选择一个属性——通常是类——来为数据点着色。如果它是名义的，着色是离散的；如果它是数值型的，颜色谱从蓝色（低值）到橙色（高值）连续变化。没有类值的数据点以黑色显示。你可以更改每个绘图的尺寸、点的尺寸以及抖动量，抖动是对 X 和 Y 值应用的随机位移，用于分隔重叠的点。如果没有抖动，同一数据点上的上千个实例看起来与一个实例相同。你可以通过选择某些属性来减小绘图矩阵的大小，并且可以对数据进行子采样以提高效率。控件中的更改在点击 `Update` 按钮之前不会生效。

点击矩阵中的一个绘图会将其放大。你可以通过从右上角附近的菜单中选择 `Rectangle` 并在查看区域拖出一个矩形（如图所示）来放大结果面板的任何区域。左上角附近的 `Submit` 按钮会将矩形重新缩放到查看区域。

### 过滤算法

现在我们更详细地查看 WEKA 中实现的过滤算法。有两种类型的过滤器：无监督和有监督。这种看似无害的区别掩盖了一个相当根本的问题。过滤器通常应用于训练数据集，然后也应用于测试文件。如果过滤器是有监督的——如果它使用类值来推导出离散化的良好区间——将其应用于测试数据会使结果产生偏差。必须将从 `training` 数据派生的离散化区间应用于测试数据。使用有监督过滤器时，你必须小心确保结果得到公平评估，这通常不会出现在无监督过滤器中。

WEKA 允许你像无监督过滤器一样将有监督过滤器作为预处理操作调用。然而，如果你打算将它们用于分类，你应采用不同的方法。`Classify` 面板中提供了一个元学习器，它以将学习算法封装到过滤机制中的方式调用过滤器。这使用由训练数据创建的过滤器来过滤测试数据。它对某些无监督过滤器也有用。例如，在 WEKA 的 `StringToWordVector` 过滤器中，词典将仅从 `training` 数据创建；测试数据中新出现的词将被丢弃。要以这种方式使用有监督过滤器，请从 `Classify` 面板的 `Choose` 按钮显示的菜单的 `meta` 部分调用 `FilteredClassifier` 元学习方案。

在每种类型中，还进一步区分了 `attribute filters`，它作用于数据集中的属性，以及 `instance filters`，它作用于实例。要了解有关特定过滤器的更多信息，请在 WEKA Explorer 中选择它并查看其关联的对象编辑器，该编辑器定义了过滤器的作用及其参数。

### 学习算法

在 `Classify` 面板上，当你使用 `Choose` 按钮选择学习算法时，分类器的命令行版本会出现在按钮旁边的行中，包括用减号指定的参数。要更改它们，请点击该行以获取适当的对象编辑器。WEKA 中的分类器分为贝叶斯分类器、树、规则、函数、懒惰分类器、元分类器和最终的杂项类别。

元学习算法将分类器转变为更强大的学习器或将其重新定向用于其他应用。它们用于执行 boosting、bagging、成本敏感分类和学习、自动参数优化以及许多其他任务。我们已经提到过 `FilteredClassifier`；它在通过过滤器传递的数据上运行分类器，过滤器是一个参数。过滤器自身的参数完全基于训练数据，这是将有监督过滤器应用于测试数据的适当方式。
