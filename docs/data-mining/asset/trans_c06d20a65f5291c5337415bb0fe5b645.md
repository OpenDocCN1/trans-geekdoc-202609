# 书籍组织

本书采用分层组织，使其思想既能让希望掌握基础的读者理解，也能让希望获得更深入阐述以及所涵盖技术完整细节的读者受益。我们认为机器学习的使用者需要对所用算法的工作原理有一定了解。人们常说数据模型的好坏取决于解读它们的人，而该人士需要了解模型是如何产生的，才能认识该技术的优势和局限性。然而，并非所有用户都需要深入理解算法的细微之处。

我们通过以递进的详细程度描述机器学习方法来应对这一情况。本书分为两部分。

## 第一部分：数据挖掘机器学习导论

第一部分是对数据挖掘机器学习的介绍。读者通过阅读前三章即可学习最顶层的基本思想。[第1章](#Ch001_3-42_B9780443158889000029.xhtml#Ch001_3-42_B9780443158889000029)，“它到底是什么？”，通过示例描述了机器学习是什么以及可以在哪里使用；它还提供了实际的实用应用。[第2章](#Ch002_43-66_B9780443158889000030.xhtml#Ch002_43-66_B9780443158889000030)，“输入：概念、实例、属性”，和[第3章](#Ch003_67-89_B9780443158889000042.xhtml#Ch003_67-89_B9780443158889000042)，“输出：知识表示”，涵盖了所涉及的不同种类的输入和输出——或*知识表示*。不同种类的输出决定了不同的算法风格，而[第4章](#Ch004_91-164_B9780443158889000054.xhtml#Ch004_91-164_B9780443158889000054)，“算法：基本方法”，描述了简化以便易于理解的机器学习基本方法。在这里，所涉及的原理以多种算法的形式传达，而不会涉及繁琐的细节或棘手的实现问题。为了在特定数据挖掘问题上取得机器学习技术的应用进展，能够衡量进展情况至关重要。[第5章](#Ch005_165-207_B9780443158889000066.xhtml#Ch005_165-207_B9780443158889000066)，“可信度：评估所学内容”，可以跳序阅读，使读者能够评估机器学习获得的结果，并处理性能评估中涉及的有时复杂的难题。[第6章](#Ch006_209-259_B9780443158889000078.xhtml#Ch006_209-259_B9780443158889000078)，“准备：数据预处理和探索性数据分析”，描述了与机器学习输入和输出工程相关的实践主题，例如选择和离散化属性。在[第7章](#Ch007_261-315_B978044315888900008X.xhtml#Ch007_261-315_B978044315888900008X)，“伦理：所学内容会带来什么影响？”，我们暂停下来反思数据挖掘技术如何以并不总是良性的方式影响真实人们的生活，并描述负责任的AI方法以确保有害影响降到最低。

## 第二部分：数据挖掘机器学习的高级技术

第二部分介绍了数据挖掘机器学习的高级技术。[第8章](#Ch009_323-345_B9780443158889000091.xhtml#Ch009_323-345_B9780443158889000091)，“集成学习”，涵盖了结合不同机器学习模型输出的技术，在许多情况下是提高预测性能的直接方法。在最低且最详细的层面上，[第9章](#Ch010_347-389_B9780443158889000108.xhtml#Ch010_347-389_B9780443158889000108)，“扩展基于实例和线性模型”，以赤裸裸的细节揭示了实现一系列机器学习算法的细枝末节问题，包括使它们在实践中良好运行所必需的复杂性，但省略了少数算法所需的繁重数学工具。该章进一步涵盖了将线性模型通过核方法如支持向量机和多层感知器转变为强大分类器的中间主题，为我们对深度学习的论述奠定基础。[第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)，“深度学习：基础”，解释了深度学习方法背后的关键思想，包括架构、原理、学习算法以及深度学习从业者必备知识的“技巧包”。[第11章](#Ch012_433-471_B9780443158889000121.xhtml#Ch012_433-471_B9780443158889000121)，“高级深度学习方法”，描述了先进且最新的深度学习方法，包括生成式深度学习、自然语言处理模型，以及从业者应注意的主题，包括对抗样本和知识蒸馏。[第12章](#Ch013_473-484_B9780443158889000133.xhtml#Ch013_473-484_B9780443158889000133)，“超越监督学习和无监督学习”，探讨了半监督学习和多实例学习，即不完全符合常规范式的学习任务。[第13章](#Ch014_485-514_B9780443158889000145.xhtml#Ch014_485-514_B9780443158889000145)，“概率方法：基础”，和[第14章](#Ch015_516-570_B9780443158889000157.xhtml#Ch015_516-570_B9780443158889000157)，“高级概率方法”，对机器学习的概率方法进行了严格阐述，前者涵盖基础，后者深入探讨并处理这些方法的技术细节。[第15章](#Ch016_571-615_B9780443158889000169.xhtml#Ch016_571-615_B9780443158889000169)，“继续前行：应用及其后果”，讨论了数据挖掘方法在文本、互联网数据、图像和语音等领域的应用。随着这些技术的不断部署，本章揭示了它们在深度伪造、自动驾驶汽车和致命自主武器系统等特定应用中使用所产生的担忧，并讨论了它们对整个社会的整体影响。

## 范围与局限

本书描述了实践机器学习中使用的绝大多数方法。然而，它并未涵盖强化学习，因为它在实际数据挖掘中很少应用（有一个显著例外，Google DeepMind 的 AlphaGo 系统在下围棋方面取得了里程碑式的成功，我们在[第11章](#Ch012_433-471_B9780443158889000121.xhtml#Ch012_433-471_B9780443158889000121)，“高级深度学习方法”中简要概述）。它也没有涵盖遗传算法方法，因为这些本质上只是非机器学习或关系学习特有的优化技术，也没有涵盖归纳逻辑编程，因为它们在主流数据挖掘应用中并不常用。
