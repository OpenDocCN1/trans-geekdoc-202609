
另一个用于贝叶斯网络分类器的良好学习算法称为 `tree augmented Naïve Bayes`（TAN）。顾名思义，它在朴素贝叶斯分类器的基础上添加边。类属性是朴素贝叶斯网络中每个节点的唯一父节点；TAN 考虑为每个节点添加第二个父节点。如果排除类节点及其所有对应边，且假设恰好有一个节点未添加第二个父节点，则 resulting classifier has a tree structure rooted at the parentless node——名称即由此而来。对于这种受限类型的网络，存在一种高效算法，通过计算网络的最大加权生成树来找到使网络似然最大化的边集。该算法的运行时间在实例数量上呈线性，在属性数量上呈二次方。

该类型网络由 TAN 算法学习，称为 `one-dependence estimator`。一种更简单的网络类型是 `super-parentone-dependence estimator`。这里，除了类节点之外，恰好有一个其他节点被提升为父节点状态，并成为每个其他非类节点的父节点。事实证明，这些一依赖估计器的简单集成可以产生非常准确的分类器——在这些估计器中，不同的属性成为额外的父节点。然后在预测时，来自不同一依赖估计器的类概率估计值 simply averaged。 该方案称为 AODE，即 averaged one-dependence estimator。通常只有在数据中具有一定支持度的估计器才会被用于集成，但更复杂的选择方案也是可能的。由于对于每个超父一依赖估计器都不涉及结构学习，因此 AODE 是一种非常高效的分类器。

AODE 做出强假设，但放宽了朴素贝叶斯的更强假设。模型可以通过引入一组 `n` 个超父而不是单个超父属性并在所有可能集合上进行平均来进一步放松，从而得到平均 `n` 依赖估计器（AnDE）算法。增加 `n` 显然会增加计算复杂度。有很好的经验证据表明 `n` = 2（A2DE）在实践中在计算复杂度和预测准确性之间实现了有用的权衡。

到目前为止描述的所有评分指标在意义上都是基于似然的，因为它们旨在最大化每个实例的联合概率 `P`(`a`[1], `a`[2], …, `a`[`n`])<mml:math><mml:mi>P</mml:mi><mml:mo stretchy="false">(</mml:mo><mml:msub><mml:mrow><mml:mi>a</mml:mi></mml:mrow><mml:mrow><mml:mn>1</mml:mn></mml:mrow></mml:msub><mml:mo>,</mml:mo><mml:msub><mml:mrow><mml:mi>a</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msub><mml:mo>,</mml:mo><mml:mo>&#8230;</mml:mo><mml:mo>,</mml:mo><mml:msub><mml:mrow><mml:mi>a</mml:mi></mml:mrow><mml:mrow><mml:mi>n</mml:mi></mml:mrow></mml:msub><mml:mo stretchy="false">)</mml:mo></mml:math>![方程](images/F000145si53.png)。然而，在分类中，我们真正想要最大化的是给定其他属性值时类的条件概率——换句话说，就是 `conditional`-likelihood。不幸的是，用于贝叶斯网络表中所需的 `conditional`-likelihood 最大概率估计没有闭式解。另一方面，对于给定的网络和数据集计算条件似然是直接的——毕竟，这就是逻辑回归所做的。因此，人们提出在网络中使用标准的极大似然概率估计，但使用条件似然来评估特定网络结构。

使用贝叶斯网络进行分类的另一种方法是为每个类值构建一个单独的网络，基于该类的数据，然后使用贝叶斯规则组合它们的预测。网络集合称为 `Bayesian multinet`。要对特定类值进行预测，请取对应网络的概率并乘以该类的先验概率。对每个类执行此操作并按我们之前的方式归一化结果。在这种情况下，我们不会使用条件似然来学习每个类值的网络。

我们介绍过的所有网络学习算法都是基于评分的。另一种策略，我们在这里不解释，是通过基于属性子集的单个条件独立性断言测试来拼凑网络。这被称为 `structure learning by conditional independence tests`。

### 用于快速学习的数据结构

学习贝叶斯网络涉及大量的计数。对于搜索中考虑的每个网络结构，都必须重新扫描数据以获得填充条件概率表所需的计数。它们能否存储在一种数据结构中，从而消除重复扫描数据的需要？一个明显的方法是预先计算计数并将非零计数存储在表中——例如，[第 4.5 节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0075)中提到的哈希表。即使如此，任何非平凡的数据集都将具有大量非零计数。
