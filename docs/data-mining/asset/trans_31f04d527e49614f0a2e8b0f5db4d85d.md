# 前言
计算与通信的融合产生了一个以信息为食的社会。然而，大多数信息仍处于原始形式：数据。如果 *data* 被特征化为记录的事实，那么 *information* 就是数据背后的模式或期望的集合。数据库中锁住了大量信息——这些信息可能很重要，但尚未被发现或表述。我们的使命是将其挖掘出来。

数据挖掘是从数据中提取隐含的、以前未知的、潜在有用的信息。思路是构建计算机程序，自动筛选数据库，寻找规律或模式。如果发现强模式，它们很可能推广到对未来数据做出准确预测。当然会存在问题。许多模式会是平凡且无趣的。其他模式可能是虚假的，取决于所用特定数据集中偶然的巧合。而且真实数据是不完美的；有些部分会损坏，有些缺失。任何被发现的东西都是不精确的。每条规则都有例外，且存在不被任何规则覆盖的情况。算法需要足够健壮，以应对不完美的数据并提取不精确但有用的规律。

机器学习提供了数据挖掘的技术基础。它用于从数据库中的原始数据中提取信息——理想情况下以可理解的形式表达，并可用于各种目的。该过程是一种抽象，取其数据本来的面目，并推断其背后的结构。本书介绍的是机器学习的工具和技术，用于在实际数据挖掘中寻找并尽可能描述数据中的结构模式。
