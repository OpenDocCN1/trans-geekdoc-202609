### 扩展混合模型

现在我们已经看到了两个分布的高斯混合模型，让我们考虑如何将其扩展到更现实的情况。基本方法相同，但由于数学符号变得十分繁琐，我们不会对其进行完整详细阐述。

将算法从双聚类问题改为多聚类情况是完全直接的，只要正态分布的数量 `k` 提前给定即可。

只要假设属性之间独立，模型可以很容易地从每个实例的单个数值属性扩展到多个属性。每个属性的概率相乘得到实例的联合概率（密度），正如朴素贝叶斯方法中一样。

当数据集已知包含相关属性时，独立性假设不再成立。相反，两个属性可以通过双变量正态分布联合建模，其中每个属性有自己的均值，但两个标准差被具有四个数值参数的“协方差矩阵”取代。在 [附录 A.2](#TableA1_617-636_B9780443158889000212.xhtml#s0050) 中我们展示了多元高斯分布的数学；对角协方差模型的特殊情况导致了朴素贝叶斯解释。多个相关属性可以使用多元分布来处理。参数数量随着联合变化的属性数量的平方而增加。对于 `n` 个独立属性，有 `2*n` 个参数，每个属性一个均值和一个标准差。有 `n + n(n + 1)/2`<mml:math><mml:mi>n</mml:mi><mml:mo>+</mml:mo><mml:mi>n</mml:mi><mml:mo stretchy="false">(</mml:mo><mml:mi>n</mml:mi><mml:mo>+</mml:mo><mml:mn>1</mml:mn><mml:mo stretchy="false">)</mml:mo><mml:mo>/</mml:mo><mml:mn>2</mml:mn></mml:math>![Equation](images/F000145si71.png) 个参数，每个一个均值，以及一个 `n × n`<mml:math><mml:mi>n</mml:mi><mml:mo>&#215;</mml:mo><mml:mi>n</mml:mi></mml:math>![Equation](images/F000145si72.png) 协方差矩阵，该矩阵是对称的，因此涉及 `n(n+1)/2`<mml:math><mml:mi>n</mml:mi><mml:mrow><mml:mfenced open="(" close=")"><mml:mrow><mml:mi>n</mml:mi><mml:mo>+</mml:mo><mml:mn>1</mml:mn></mml:mrow></mml:mfenced></mml:mrow><mml:mo>/</mml:mo><mml:mn>2</mml:mn></mml:math>![Equation](images/F000145si73.png) 个不同的量。参数数量的这种激增对过拟合有严重后果，我们稍后会解释。

为了适应名义属性，必须放弃正态分布。相反，具有 `v` 个可能值的名义属性由 `v` 个数字表征，表示每个值的概率。每个聚类都需要一组不同的数字；总共 `k*v` 个参数。这种情况与朴素贝叶斯方法非常相似。期望和最大化这两个步骤与我们研究过的操作完全对应。期望——给定分布参数估计每个实例所属的聚类——类似于确定未知实例的类别。

最大化——从已分类的实例估计参数——类似于从训练实例确定属性-值概率，唯一的小区别在于在 `EM` 算法中实例是概率性地而不是分类地分配到类别。在 [第 4.2 节](#Ch004_91-164_B9780443158889000054.xhtml#s0020) 中我们遇到了概率估计可能为零的问题，这里也同样会出现。幸运的是，解决方案同样简单——使用拉普拉斯估计量。

朴素贝叶斯假设属性是独立的——因此得名“naïve”。一对相关名义属性，分别具有 `v[1]` 和 `v[2]` 个可能值，可以被具有 `v[1]*v[2]` 个可能值的单个协变属性所取代。同样，随着依赖属性数量的增加，参数数量也会激增，这对概率估计和过拟合有影响。

待聚类数据中同时存在数值和名义属性并无特别问题。协变数值和名义属性更难处理，我们在此不予描述。

缺失值可以通过各种不同方式来容纳。原则上它们应被视为未知，并调整 `EM` 过程以估计它们以及聚类均值和方差。一种简单的方法是在预处理步骤中用均值或众数替换它们。
