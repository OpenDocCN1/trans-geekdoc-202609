### 选择聚类数量

假设你在使用 `k`-means 但事先不知道聚类数量。一个解决方案是尝试不同的可能性并看看哪种最好。一种简单策略是从给定的最小值开始，也许 `k` = 1<mml:math><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:math>![方程](images/F000054si95.png)，并逐步增加到一个较小、固定的最大值。请注意，在训练数据上，根据总平方距离准则，“最佳”聚类总是选择与数据点数量一样多的聚类！为了惩罚具有许多聚类的解，你必须应用类似最小描述长度（MDL）准则的 [第 5.10 节](#Ch005_165-207_B9780443158889000066.xhtml#s0115)。

另一种可能性是先找到几个聚类并确定是否值得分裂它们。你可以选择 `k` = 2<mml:math><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>2</mml:mn></mml:math>![方程](images/F000054si96.png)，执行 `k`-means 聚类直到终止，然后考虑分裂每个聚类。如果将初始的两路聚类视为不可更改，并且对每个分量独立地研究分裂，则计算时间将大大减少。一种分裂聚类的方法是创建一个新种子，该种子位于聚类中心沿其最大变化方向一个标准差的位置，并创建第二个种子在相反方向相同距离处。（或者，如果这样太慢，选择与聚类的边界框成比例的距离和随机方向。）然后使用这两个新种子对聚类中的点应用 `k`-means。

在暂时分裂了一个聚类后，保留分裂是否值得，还是原始聚类本身同样合理？查看所有点到其聚类中心的总体平方距离是没有意义的——对于两个子聚类来说，这必然更小。为凭空发明一个额外聚类应施加惩罚，而这正是 MDL 准则的工作。该原则可用于判断指定两个新聚类中心所需的信息，加上相对于它们指定每个点所需的信息，是否超过指定原始中心以及相对于它指定所有点所需的信息。如果是这样，新的聚类是无益的，应被放弃。

如果保留分裂，尝试进一步分裂每个新聚类。继续该过程，直到没有值得的分裂为止。

通过将此迭代聚类过程与 `k`D-tree 或球树数据结构结合，可以实现额外的实现效率。然后，通过从根向下遍历树来到达数据点。在考虑分裂聚类时，无需考虑整棵树，只需查看覆盖该聚类所需的那些部分即可。例如，在决定是否分裂 [图 4.18A](#Ch004_91-164_B9780443158889000054_a.xhtml#f0095) 中的左下聚类（粗线下方）时，只需考虑 [图 4.18B](#Ch004_91-164_B9780443158889000054_a.xhtml#f0095) 中树的节点 A 和 B，因为节点 C 与该聚类无关。

### 层次聚类

形成初始的聚类对，然后递归地考虑是否值得进一步分裂每个聚类，会产生一个层次结构，可以表示为称为 `dendrogram` 的二叉树。事实上，我们在 [图 3.11D](#Ch003_67-89_B9780443158889000042.xhtml#f0060) 中举例说明了 `dendrogram`（那里，一些分支是三向的）。相同的信息可以用集合和子集的 Venn 图表示；结构具有层次性的约束对应于这样一个事实：尽管子集可以包含彼此，但它们不能相交。在某些情况下，存在衡量每个集合中聚类之间不相似程度的度量；那么，`dendrogram` 中每个节点的高度可以与其实子节点之间的不相似性成比例。这提供了一个易于解释的层次聚类图。

形成聚类层次结构的一种替代自上而下的方法是使用自下而上的方法，称为 `agglomerative` 聚类。这个想法多年前就被提出，最近又重新流行起来。基本算法很简单。你需要的是任意两个聚类之间的距离度量（或者相似性度量）。你首先将每个实例视为一个独立的聚类，找到两个最近的聚类，将它们合并，并继续这样做，直到只剩下一个聚类。合并的记录形成一个层次聚类结构——一个二叉 `dendrogram`。

距离度量有许多可能性。其中之一是聚类之间的最小距离——它们两个最近成员之间的距离。这产生了所谓的 `single-linkage` 聚类算法。由于该度量仅考虑一对聚类的两个最近成员，因此该过程对异常值敏感。仅添加一个新实例就可能彻底改变整个聚类结构。此外，如果我们将聚类的直径定义为其成员之间的最大距离，single-linkage 聚类可能会产生直径非常大的聚类。另一种度量是聚类之间的最大距离，而不是最小距离。只有当其并集中的所有实例都相对相似时，两个聚类才被认为接近——有时称为 `complete-linkage` 方法。该度量也对异常值敏感，寻求具有小直径的紧凑聚类。然而，一些实例最终可能比它们与自己聚类其余部分的距离更接近其他聚类。
