
# Quadratic Loss Function

1 − 2`p`[`i`] + ∑[`j`] `p`[`j`]²,<mml:math><mml:mn>1</mml:mn><mml:mo>&#8722;</mml:mo><mml:mn>2</mml:mn><mml:msub><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>+</mml:mo><mml:msub><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>j</mml:mi></mml:mrow></mml:msub><mml:mrow><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mo>,</mml:mo></mml:math>

where `i` is the correct class. When the test set contains several instances, the loss function is summed over them all.

It is an interesting theoretical fact that if you seek to minimize the value of the quadratic loss function in a situation where the actual class is generated probabilistically, the best strategy is to choose for the `p` vector the actual probabilities of the different outcomes, that is, `p[i]` = `P`(class = `i`). If the true probabilities are known, they will be the best values for `p`. If they are not, a system that strives to minimize the quadratic loss function will be encouraged to use its best estimate of `P`(class = `i`) as the value for `p[i]`.

This is quite easy to see. Denote the true probabilities by `p`[1]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mn>1</mml:mn></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si46.png), `p`[2]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si47.png), …, `p`[`k`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si48.png) so that `p`[`i`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si49.png) = `P`(class = `i`). The expected value of the quadratic loss function over test instances can be rewritten as follows:

```
$\\begin{array}{l} {E\\left\\lbrack \\sum\_{j}{(p\_{j} - a\_{j})}^{2} \\right\\rbrack = \\sum\_{j}{(E\\lbrack p\_{j}^{2}\\rbrack - 2E\\lbrack p\_{j}a\_{j}\\rbrack + E\\lbrack a\_{j}^{2}\\rbrack)}} \\\\ {= \\sum\_{j}{(p\_{j}^{2} - 2p\_{j}p\_{j}^{\*} + p\_{j}^{\*})} = \\sum\_{j}{({(p\_{j} - p\_{j}^{\*})}^{2} + p\_{j}^{\*}(1 - p\_{j}^{\*})).}} \\\\ \\end{array}$
```

The first stage simply involves bringing the expectation inside the sum and expanding the square. For the second, `p[j]` is a constant and the expected value of `a[j]` is simply `p`[`j`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si51.png); moreover, because `a[j]` is either 0 or 1, `a`[`j`]² = `a`[`j`]<mml:math><mml:msubsup><mml:mrow><mml:mi>a</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup><mml:mo>=</mml:mo><mml:msub><mml:mrow><mml:mi>a</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000066si52.png) and its expected value is `p`[`j`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si53.png) too. The third stage is straightforward algebra. To minimize the resulting sum, it is clear that it is best to choose `p`[`j`] = `p`[`j`]*<mml:math><mml:msub><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si54.png) so that the squared term disappears and all that is left is a term that is the variance of the true distribution governing the actual class.
