WEKA 的发展日新月异。它现在提供了连接并整合其他语言和系统的方式，例如流行的 R 统计计算语言，用于分布式计算的 Spark 和 Hadoop 框架，用于脚本编写的 Python 和 Groovy 语言，以及用于流式学习的 MOA 系统，仅举几例。认识到在印刷书籍中记录如此全面且快速发展的系统是不可能的，也许并不理想，我们创建了一系列开放式在线课程，*使用 Weka 进行数据挖掘*，*更多使用 Weka 进行数据挖掘*，和 *高级数据挖掘与 Weka*，以配合本书（网址为 [https://ml.cms.waikato.ac.nz/weka/](https://ml.cms.waikato.ac.nz/weka/)）。第四版包含许多其他更新和补充，以及更多文献参考。

## 第五版

近20年前，我（James Foulds，又名 Jimmy）首次从这本非常的书学习到数据挖掘和机器学习，并在新西兰怀卡托大学本科和硕士论文期间直接由其作者授课。这本书随我行李箱一起去了美国，在那里我完成了博士教育并继续我的学术生涯。当我开始用它来教自己的学生时，它一直陪伴着我。撰写新版对我来说就像一次回家。能够完成这个循环并将这本重要书籍更新以服务新一代冉冉升起的学者，是我的荣幸。

自上一版以来，领域发生了很多变化，即使基本原理保持不变。我们见证了深度学习的持续崛起，尤其是生成式人工智能和基于变换器的超大语言模型，同时见证了传统机器学习几乎每个其他方面的兴衰。随着机器学习系统的部署大幅增加，而这些系统现在已深入日常生活的几乎每个方面，伦理和社会问题已成为焦点。反映这一现实，我的首要任务是确保对伦理和负责任的人工智能、社会影响以及当前深度学习方法的全面且教育上有效的覆盖，我通过添加两个新章节（[第7章](#Ch007_261-315_B978044315888900008X.xhtml#Ch007_261-315_B978044315888900008X)，“伦理：我们学到的东西有什么影响？，”和 [第11章](#Ch012_433-471_B9780443158889000121.xhtml#Ch012_433-471_B9780443158889000121)，“高级深度学习方法”），以及对其他几个章节的重大补充来实现，尤其是 [第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)，“深度学习：基础，”和 [第15章](#Ch016_571-615_B9780443158889000169.xhtml#Ch016_571-615_B9780443158889000169)，“继续前进：应用及其后果。”这些补充使得新增了80多条参考文献。

应广大要求，我为每章添加了练习。许多练习是多选题。这些通常对应于我在课程中使用的学习目标的测试，使学生能够验证他们“知道自己需要知道什么”；这被称为 *元认知*。如果你独自阅读这本书，可以用这些问题来检验你的理解，如果不确定答案，可以回头查阅章节。在我自己的课程中，我主要以两种方式使用多选题，这两种方式都可通过“clicker”设备或电子投票服务（如 Poll Everywhere）来实现：

1) 作为 *阅读测验* 问题在每节课开始时提出，以鼓励学生完成指定阅读。我不对这些问题的准确性进行评估，只评估参与度。

2) 作为 *同伴教学* 练习。学生首先独自对多选题投票，要求他们独立思考。然后他们与旁边的人讨论，并根据讨论更新投票。结果第二次总是更准确，因为学生理解同伴的困难所在，并能以他们能理解的方式向他们解释。教育研究表明，像同伴教学这样的 *主动学习* 练习能显著提高学生的学习成果。我强烈鼓励教师在自己的课程中尝试一下。

我在新版中的另一个主要目标是使深度学习和概率方法章节更易于理解。易读性一直是本书的优势，包括对话式和个人化的语气、丰富的例子，以及为理解和直觉而避免或推迟不必要的数学细节。随着书籍扩展以包含更先进和最新的内容，易用性与严谨性的平衡变得难以维持。我不得不告诉我的学生，“不用担心如果不能理解所有方程，只要尽量读完就行。”如何在不失去深度的情况下使这些技术章节更易读？

答案原来一直就在书中。正如本书将材料的入门性处理（第一部分）与更深入的处理（第二部分）分开一样，我也在深度学习和概率机器学习主题中将入门材料与更高级材料分开。幸运的是，更复杂的深度学习材料现在比2017年时重要性更低，使我能够将其大部分移至附录。深度学习包自动计算梯度，计算图的运算也越来越多地在“幕后”完成，因此学生和从业者不再必须自己执行梯度计算。一个更具挑战性的主题，随机网络，已不再流行。我将概率机器学习材料移至书的后面并将其分为两章，分别包含基础和高级材料，让读者有一种“许可”感，如果他们选择，可以在学习基础后停止。我还重新组织了一些章节，使那些具有实际重要性的章节（关于数据转换的章节，现重新表述为预处理和探索性数据分析，以及关于集成方法的章节）提前出现。我希望这些改变能帮助读者快速学习最重要的课程，同时为他们成长到更具挑战性的主题提供空间。毕竟，加速学习过程对人类与机器同样重要！让我们点燃我们的神经元，无论是真实的还是人工的，让学习开始吧！
