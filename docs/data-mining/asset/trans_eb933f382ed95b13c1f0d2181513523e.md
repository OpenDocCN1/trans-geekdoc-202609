
# 生成式对抗网络

生成器以随机向量 `z` 作为输入。例如，向量中的每个元素都可以从标准正态分布中采样。这可以被视为潜在空间中的一个点。生成器是一个深度神经网络，将给定的点 `z` 映射到对应的人工数据点 `x`，希望是逼真的。判别器也是一个深度神经网络，是一种概率分类器，它以数据点作为输入并预测类别概率，表示该数据点是真实的（即来自训练数据）还是虚假的（即由生成器创建）的可能性。

## 训练过程

这两个神经网络通过迭代过程进行训练，展开一场相互竞争的博弈。在每次迭代中，两个网络轮流更新。生成器被训练以创建能够“欺骗”判别器的数据；也就是说，判别器无法将其与真实数据区分开。判别器被训练以检测生成器制造的“伪造品”。你可以将其视为两个网络试图击败对方，或者如果你更喜欢一个更友好的比喻，可以认为它们在“教导”彼此在下一轮迭代中做得更好，这正是该过程能够成功的实际原因。不管你如何理解，生成器 `G` 和判别器 `D` 的整体训练过程可以形式化为一个具有价值函数 `V(G, D)` 的极小极大博弈：

$\\min\\limits\_{G}{\\max\\limits\_{D}\\mathit{V}\\mathit{G},\\mathit{D} = {E\_{x \\sim \\text{real\\ data}}\\left\\lbrack {\\log D\\left( x \\right)} \\right\\rbrack + E\_{\\overset{\\sim}{x} \\sim \\text{generator's\\ data}}\\left\\lbrack {\\log\\left( {1 - D\\left( \\overset{\\sim}{x} \\right)} \\right)} \\right\\rbrack}}.$

这里，`D(x)` 是判别器预测的数据点 `x` 来自数据集的真实数据点的概率。最小化玩家，即生成器，试图最小化该函数，而判别器则试图最大化它。在每次迭代中，从数据集中抽取一个小批量数据，并从生成器中采样一个小批量生成数据。基于这些数据，在固定另一个网络的情况下，通过小批量随机梯度更新（或 `Adam` 等）更新这两个网络。请参阅 [图 11.1](#Ch012_433-471_B9780443158889000121.xhtml#f0010) 以了解示意图。

## 不稳定性问题与 WGAN

尽管概念上很清晰，GAN 在实践中难以良好运行，因为它们容易出现多种不稳定性问题。其中一个问题是 *模式崩溃*，生成过程仅集中在空间中一个小的、概率很高的部分（例如，多模态似然曲面中的一个模式）。例如，它可能只生成混合国家标准与技术研究所（MNIST）数据集上的“1”数字，而不生成其他九个数字。另一个问题是由于判别器中神经元饱和导致的 *梯度消失*。一种称为 Wasserstein GAN（WGAN）的替代 GAN 形式可以有助于提高 GAN 训练的稳定性和可靠性。虽然原始 GAN 可以被解释为优化生成数据与真实数据之间的 Jensen-Shannon 散度，但 WGAN 优化的是 Wasserstein 散度，也称为推土机距离，据认为在这种设定下具有更好的优化特性。WGAN 用一个“*评论家*”，也记为 `D`，替换判别器，它产生一个实值分数而不是类别概率，其中分数越高对应越逼真的数据点。评论家旨在使真实数据与生成数据之间的分数差距很大。极小极大博弈的形式变为：
