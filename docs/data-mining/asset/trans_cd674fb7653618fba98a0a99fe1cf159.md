
## 深度自编码器

这可能看起来令人沮丧；线性自编码器并不比主成分分析更好。然而，使用即使只有一个隐藏层的神经网络来创建编码可以构建更灵活的变换，并且有越来越多的证据表明更深的模型可以学习更有用的表示。在从更灵活的模型构建自编码器时，通常在网络中使用瓶颈来产生欠完备的表示，从而提供一种机制来获得比输入维度更低的编码。

深度自编码器能够学习低维表示，其重建误差比使用相同数量维度的主成分分析更小。它们是通过使用 `L` 层来创建数据的隐藏层表示 `h[c]^(L)` 构建的，并在其后跟随额外的 `L` 层 `h[d]^(L+1)`…`h[d]^(2L)` 将表示解码回其原始形式，如 [图 10.10](#Ch011_391-432_B978044315888900011X.xhtml#f0055) 所示。对于每个 `I` = 1, …, `L` 编码和解码层的 `j` = 1, …, 2 `L` 个权重矩阵受 `W[L+i] = W[L+1-i]^T` 约束。

![图 10.10 一个具有多层变换的深度自编码器。署名：Christopher J. Pal](images/F00011Xf10-10-9780443158889.jpg)

图 10.10 一个具有多层变换的深度自编码器。署名：Christopher J. Pal

`p(x = \hat{x}|\tilde{x}) = p(\hat{x}; f_d(\tilde{x}))` 的深度编码器的形式为

```
f(x) = f[d](a[d]^(2L)(…h[d]^(L+1)(a[d]^(L+1)(h[c]^(L)(a[e]^(L)(…h[e]^(1)(a[e]^(1)(x)))))))
```

[图 10.11](#Ch011_391-432_B978044315888900011X.xhtml#f0060) 将以这种方式学习到的 2D 空间中的投影数据与特定数据集的 2D 主成分分析进行比较。由于底层自编码器是非线性的，网络可以以更好地分离数据的自然分组的方式排列学习到的空间。
