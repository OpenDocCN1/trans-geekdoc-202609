
# 决策树构建

构建决策树的问题可以递归地表达。首先，选择一个属性放在根节点，并为每个可能的值创建一条分支。这会将示例集分割成子集，每个属性值对应一个子集。现在该过程可以对每个分支递归重复，仅使用实际到达该分支的实例。如果在任何时候节点上的所有实例具有相同的分类，则停止开发树的这一部分。

剩下的唯一问题是，给定具有不同类别的示例集，如何确定要在哪一个属性上进行划分。考虑（再次！）天气数据。每次划分有四种可能性，在顶层它们产生了 [图 4.2](#Ch004_91-164_B9780443158889000054.xhtml#f0015) 中的树。哪一个选择最好？叶节点上 `yes` 和 `no` 类别的数量已显示。任何仅包含一个类别的叶节点——`yes` 或 `no`——就不需要进一步划分，并且该分支上的递归过程将终止。因为我们寻求小的树，所以我们希望这种情况尽快发生。如果我们有一个衡量每个节点纯度的指标，我们就可以选择产生最纯净子节点的属性。花点时间查看 [图 4.2](#Ch004_91-164_B9780443158889000054.xhtml#f0015) 并思考你认为最好的选择是什么属性。
