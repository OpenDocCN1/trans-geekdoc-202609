数据集中有 40 个示例（另有 17 个通常保留用于测试目的）。与这里的其他表格不同，[表 1.6](#Ch001_3-42_B9780443158889000029.xhtml#t0035) 将示例作为列而不是行呈现；否则，它将不得不跨越数页。许多值未知或缺失，如问号所示。

这是一个比我们迄今为止看到的其他数据集更现实的数据集。它包含许多缺失值，并且似乎不太可能获得精确的分类。

[图 1.3](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 显示了代表该数据集的两个决策树。[图 1.3A](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 很简单且近似；它并不完全代表数据。例如，它会为一些实际标记为 *good* 的合同预测 *bad*。但它在直觉上是有意义的。合同对员工来说是坏的，如果第一年的工资增长太小（小于 2.5%）。如果第一年的工资增长大于此值，则如果法定假日很多（超过 10 天）则为好。即使法定假日较少，如果第一年的工资增长足够大（超过 4%），也是好的。

图 1.3 劳工谈判数据的决策树。

[图 1.3B](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 是一个更复杂的决策树，表示相同的数据集。仔细查看左侧分支。乍一看，似乎在直觉上没有意义，如果工作时间超过 36 小时，合同在没有健康计划缴费或有全额健康计划缴费时为坏，而在有半额健康计划缴费时为好。健康计划缴费在决策中发挥作用是完全合理的，但半额为好而全额和无都为坏似乎很异常。然而，反思一下，这最终可能是有意义的，因为“好”合同是 *both* 方面都接受的合同：劳工和管理层。也许这种结构反映了为达成协议而必须做出的妥协。对决策树各部分含义进行这种详细推理是了解您的数据并思考潜在问题的好方法。

事实上，[图 1.3B](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 比 [图 1.3A](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 更准确地表示了训练数据集。但它不一定是对好与坏合同的潜在概念的更准确表示。虽然它在用于训练分类器的數據上更准确，但在独立的测试数据上可能表现更差。它可能“过拟合”于训练数据——过于死板地遵循它。[图 1.3A](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 中的树是通过修剪过程从 [图 1.3B](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 中获得的，我们将在 [附录 C](#FigC1_655-685_B9780443158889000236.xhtml#FigC1_655-685_B9780443158889000236) 中讨论，树的实现细节和规则。

## 大豆分类：经典的机器学习成功案例

一个经常引用的机器学习在实际问题中应用的早期成功案例是用于诊断大豆疾病的规则的识别。数据取自描述植物疾病的问卷。有大约 680 个示例，每个示例代表一株患病植物。植物在 35 个属性上进行了测量，每个属性都有少量可能的值。示例由植物生物学专家标注的诊断进行标记。共有 19 个疾病类别——听起来可怕的疾病，如 diaporthe stem canker、rhizoctonia root rot 和 bacterial blight，仅举几例。

以下是从该数据学习到的两个示例规则：

```
If leaf condition = normal and
stem condition = abnormal and
stem cankers = below soil line and
canker lesion color = brown
then
diagnosis is rhizoctonia root rot
```

```
If leaf malformation = absent and
stem condition = abnormal and
stem cankers = below soil line and
canker lesion color = brown
then
diagnosis is rhizoctonia root rot
```

这些规则很好地说明了先验知识——通常称为 *domain knowledge* ——在机器学习中的潜在作用，因为事实上这两个描述之间的唯一区别是 *leaf condition is normal* 与 *leaf malformation is absent*。现在，在这个领域，如果叶片状况正常，则叶片畸形必然不存在，因此其中一个条件碰巧是另一个条件的特例。因此如果第一个规则为真，则第二个规则必然也为真。第二个规则发挥作用的唯一时间是当叶片畸形不存在但叶片状况 *not* 正常时，例如，当叶片出现除畸形之外的其他问题时。这从对规则的粗略阅读中完全看不出来。
