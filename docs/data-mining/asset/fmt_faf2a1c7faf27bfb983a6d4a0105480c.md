
# Comparison of Means Using t-test

To decide whether the means $\\overline{x}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si26.png) and $\\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si27.png), each an average of the same number `k` of samples, are the same or not, we consider the differences `di` between corresponding observations, `d[i] = x[i] - y[i]`<mml:math><mml:msub><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:msub><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>&#8722;</mml:mo><mml:msub><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000066si28.png). This is legitimate because the observations are paired. The mean of this difference is just the difference between the two means, $\\overline{d} = \\overline{x} - \\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>=</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>&#8722;</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si29.png), and, like the means themselves, it has a Student’s distribution with `k-1` degrees of freedom. If the means are the same, the difference is zero (this is called the *null hypothesis*); if they’re significantly different, the difference will be significantly different from zero. So for a given confidence level, we will check whether the actual difference exceeds the confidence limit.

First, reduce the difference to a zero-mean, unit-variance variable called the `t`-statistic:

$t = \\frac{\\overline{d}}{\\sqrt{\\left. \\sigma\_{d}^{2}\\slash k \\right.}},$<mml:math><mml:mi>t</mml:mi><mml:mo>=</mml:mo><mml:mfrac><mml:mrow><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:mrow><mml:mrow><mml:msqrt><mml:mrow><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mo>&#8725;</mml:mo><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:mrow></mml:msqrt></mml:mrow></mml:mfrac><mml:mo>,</mml:mo></mml:math>

![Equation](images/F000066si30.png)

where `σ[d]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si31.png) is the variance of the difference samples. Then, decide on a confidence level—generally 5% or 1% is used in practice. From this the confidence limit `z` is determined using [Table 5.2](#Ch005_165-207_B9780443158889000066.xhtml#t0015) if `k` is 10; if it is not, a confidence table of the Student distribution for the `k` value in question is used. A two-tailed test is appropriate because we do not know in advance whether the mean of the `x`’s is likely to be greater than that of the `y`’s or vice versa; thus for a 1% test we use the value corresponding to 0.5% in [Table 5.2](#Ch005_165-207_B9780443158889000066.xhtml#t0015). If the value of `t` according to the formula mentioned is greater than `z`, or less than `-z`, we reject the null hypothesis that the means are the same and conclude that there really is a significant difference between the two learning methods on that domain for that dataset size.

Two observations are worth making on this procedure. The first is technical: what if the observations were not paired? That is, what if we were unable, for some reason, to assess the error of each learning scheme on the same datasets? What if the number of datasets for each scheme was not even the same? These conditions could arise if someone else had evaluated one of the schemes and published several different estimates for a particular domain and dataset size—or perhaps just their mean and variance—and we wished to compare this with a different learning scheme. Then it is necessary to use a regular, nonpaired `t`-test. Instead of taking the mean of the difference, $\\overline{d}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si32.png), we use the difference of the means, $\\overline{x} - \\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>&#8722;</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si33.png). Of course, that’s the same thing; the mean of the difference *is* the difference of the means. But the variance of the difference $\\overline{d}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si34.png) is *not* the same. If the variance of the samples `x[1]`, `x[2]`, …, `x[k]` is `σ[x]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si35.png) and the variance of the samples `y[1]`, `y[2]`, …, `y[l]`<mml:math><mml:msub><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mi mathvariant="script">l</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000066si36.png) is `σ[y]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si37.png),

$\\frac{\\sigma\_{x}^{2}}{k} + \\frac{\\sigma\_{y}^{2}}{\\mathcal{l}}.$<mml:math><mml:mfrac><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:mfrac><mml:mo>+</mml:mo><mml:mfrac><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mrow><mml:mi mathvariant="script">l</mml:mi></mml:mrow></mml:mfrac><mml:mo>.</mml:mo></mml:math>

![Equation](images/F000066si38.png)

is a good estimate of the variance of the difference of the means. It is this variance (or rather, its square root) that should be used as the denominator of the `t`-statistic given previously. The degrees of freedom, necessary for consulting Student’s confidence tables, should be taken conservatively to be the minimum of the degrees of freedom of the two samples. Essentially, knowing that the observations are paired allows the use of a better estimate for the variance, which will produce tighter confidence bounds.
