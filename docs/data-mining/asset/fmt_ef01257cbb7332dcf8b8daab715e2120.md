This constraint can be made into a fairness penalty by measuring the extent to which the inequality is violated, instead of rigidly enforcing the equality. A key challenge in implementing individual fairness in practice is that we need to define the distance between individuals in a way that is fair, which is far from straightforward. Perhaps a subset of the features that are deemed to be “fair” could be used for this measurement. The chosen features would have to accurately represent the “deservingness” of the individuals (since otherwise two “similar” individuals should not necessarily get similar class probabilities) while not encoding demographic proxies.

## Incompatibility Between Fairness Definitions

We have considered several fairness definitions, each of which is frequently a desirable property for the behavior of an AI system. It would be wonderful if we could design our AI system to satisfy all of these definitions simultaneously, while also accurately predicting the class labels and producing calibrated probability estimates. Unfortunately, as you might expect, this is not always possible. There are mathematical theorems proving that many of these fairness definitions are in some cases incompatible with each other and/or with predictive accuracy or calibration. Such incompatibilities often arise when the protected demographics have different *base rates* (probabilities of the class labels) and/or when *perfect prediction* (the model assigning each data point to its correct class with class probabilities that are certain) is not possible. From a practical perspective, the upshot is that when we design a fair machine learning system, we must work with stakeholders to decide on the appropriate fairness metric(s) and the appropriate balance with predictive performance.

## Fair Representation Learning

Instead of defining and measuring fairness by quantifying it with some function, another approach is to preprocess the data by replacing all of the features with embeddings in which all associations and correlations with the protected attributes are excised while otherwise retaining as much information in the embeddings as possible. In other words, we perform *representation learning* (i.e., learning embedding representations of the data) but do so in a way that aims to ensure fairness for any downstream analysis. Perhaps unsurprisingly, this methodology is called *fair representation learning*. We will discuss representation learning in [Chapter 10](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X), “Deep learning: fundamentals.”
