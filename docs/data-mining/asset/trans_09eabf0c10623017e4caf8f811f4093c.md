## 使用 RBM 预训练深度自编码器

深度自编码器，在[第10.4节](#Ch011_391-432_B978044315888900011X.xhtml#s0140)中讨论过，是非线性降维的有效框架，构成了随机网络的重要用例，特别是在作为无监督预训练策略的一部分使用时。一旦构建了这样的网络，编码器的最顶层，即代码层 `h*[c]`，可以输入到有监督的分类过程中。如果使用神经网络分类器，整个深度自编码器网络可以使用梯度下降进行判别式微调。实际上，自编码器方法用于预训练神经网络分类器。

然而，优化具有编码器和解码器中多个隐藏层的自编码器是困难的。众所周知，用过大权重初始化任何深度神经网络会导致较差的局部最小值，而用过小权重初始化可能导致梯度很小，使学习变慢。一种方法是仔细选择激活函数和初始化。然而，实践中发现这很困难。

另一种方法基于通过堆叠两层受限玻尔兹曼机（`RBMs`）进行预训练。“`RBMs`是概率主成分分析（`PPCA`）的广义形式，我们在[第14.3节](#Ch015_516-570_B9780443158889000157.xhtml#s0055)中讨论过，二值隐藏变量和二值或连续观测变量可以执行无监督学习；它们将在后面进一步讨论。要使用它们进行预训练，首先从数据中学习一个两层`RBM`，将数据投影到其隐藏层表示中，用该表示训练另一个`RBM`，并重复该过程直到达到编码层。然后，每个两层网络的参数被用来初始化具有相似结构且具有非随机`sigmoid`隐藏单元的自编码器的参数。接下来我们讨论`RBMs`、它们所基于的玻尔兹曼机，以及在2000年代至2010年代占主导地位的各种基于它们的建模和学习策略。这些模型在很大程度上已不再使用，但因历史原因仍然重要。
