
• The information should obey the multistage property that we have illustrated.

### Highly Branching Attributes

When some attributes have a large number of possible values, giving rise to a multiway branch with many child nodes, a problem arises with the `information gain` calculation. The problem can best be appreciated in the extreme case when an attribute has a different value for each instance in the dataset, as an identification code attribute might.
