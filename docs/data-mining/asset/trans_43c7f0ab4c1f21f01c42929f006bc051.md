## 10.1 深度前馈网络

虽然神经网络几十年来一直被视为标准的机器学习技术，但四个关键发展对其复兴起到了至关重要的作用：

* 对机器学习方法的适当评估；
* 数据量的大幅增加；
* 更深更大的网络架构；
* 使用 GPU 技术加速训练。

关于第一点，评估，过去不同团队使用相同数据集比较结果的做法是标准做法。然而，即使数据公开，结果也往往难以比较，因为研究人员在实验中使用了不同的协议，例如不同的测试和训练划分。此外，花费了大量时间重新实现其他方法，这往往导致基线较弱。具有大型公共测试集的机器学习挑战的兴起确保了结果更具可直接比较性，并激励团队将时间和精力投入到自己的方法上。随着评估数据量的增加，更深、更复杂且更灵活的模型变得可行。使用需要额外注意以防止过拟合的高容量模型，使得确保测试集仅用于最终测试变得更加重要。出于这些和其他原因，一些竞赛性挑战被组织起来，其中测试数据的标签被隐藏，结果必须提交到远程服务器进行评估。在某些情况下，测试数据本身也被隐藏，在这种情况下，参与者必须提交可执行代码。

### MNIST 评估

为了强调大型基准评估的重要性，请考虑手写数字的改良国家标准与技术研究所（MNIST）数据库。它包含 60,000 个训练和 10,000 个测试手写数字实例，以 28 × 28 像素灰度图像编码。该数据是早期国家标准与技术研究所（NIST）数据集的混编，其中成人生成了训练数据，高中生生成了测试集。[表 10.1](#Ch011_391-432_B978044315888900011X.xhtml#t0010) 给出了该数据上的一些结果。请注意，LeNet 卷积网络（第 5 行），一种在 [第 10.3 节](#Ch011_391-432_B978044315888900011X.xhtml#s0120) 中讨论的深度架构，甚至在 1998 年就超过了许多标准的机器学习技术。

表的下半部分显示了通过合成输入图像的失真来扩充训练集的方法的结果。对变换的使用以进一步扩展已经很大的数据集的大小是深度学习中的一个重要技术。具有更多参数的大型网络具有较高的表征能力。对数据的合理合成失真使可用数据量成倍增加，防止过拟合并帮助网络泛化。当然，其他方法如支持向量机也可以通过额外数据来扩展模型复杂度。简单地添加更多支持向量可以使支持向量机（SVM）方法超过经典的网络架构。然而，如 [表 10.1](#Ch011_391-432_B978044315888900011X.xhtml#t0010) 所示，使用合成弹性变换图像训练深度前馈网络或 CNN 可获得更好的结果。由于测试集很大（相对于那个时代的其他数据集），错误率超过 0.01 的差异在统计上是显著的。

最后四项条目说明了深度网络的有效性。有趣的是，使用合成变换并在图形处理单元上训练的标准六层多层感知机与大型深度 CNN 的性能相匹配。这表明当神经网络较深且使用数据增强时，普通的神经网络可以有效，因为用合成变换数据训练这样的网络会鼓励对合理失真的鲁棒性。相比之下，CNN 将平移不变性嵌入到网络设计本身中（[第 10.3 节](#Ch011_391-432_B978044315888900011X.xhtml#s0120)）。[表 10.1](#Ch011_391-432_B978044315888900011X.xhtml#t0010) 中的最佳结果基于卷积网络的集成。集成用于在许多设置中获得最佳性能（[第 8 章](#Ch009_323-345_B9780443158889000091.xhtml#Ch009_323-345_B9780443158889000091)，“集成学习”）。近年来，由于训练现代深度神经网络的规模和计算负担，集成学习变得不那么常见；尽管如此，它仍然是一种有用的技术，即使在深度学习背景下也是如此。

### 损失与正则化

[第 9.2 节](#Ch010_347-389_B9780443158889000108.xhtml#s0050) 指出可以为多层感知机使用不同的激活函数。我们区分用于计算损失函数的最终层参数化与中间层激活函数。过去，常见做法是使用 sigmoid 作为输出激活函数，并基于平方误差构建最终层损失函数——有时即使分类标签被限制为 0 或 1。后来设计通过将输出激活函数定义为用于进行概率预测的分布函数的负对数，从而采用了任何给定数据类型自然的概率编码，无论这些分布是二元、分类还是连续的。然后预测可以精确对应于伯努利——离散或高斯分布——所定义的底层概率模型，如线性回归和逻辑回归，但具有更大的灵活性。
