### 其他离散化方法

基于熵的方法结合 MDL 停止准则是在监督离散化中最好的通用技术之一。然而，许多其他方法已被研究。例如，与其自上而下地递归分割区间直到满足某个停止准则，你可以自下而上地工作，首先将每个实例放入自己的区间，然后考虑是否合并相邻区间。你可以应用统计准则来查看哪两个区间最适合合并，并在统计量超过某个预设置信水平时将它们合并，重复该操作直到没有潜在的合并通过测试。χ² 检验是合适的，已被用于此目的。除了指定预设显著性阈值之外，还有更复杂的技术可以自动确定适当的水平。

另一种截然不同的方法是计算离散化在预测每个训练实例类别时产生的错误数量，假设每个区间接收多数类。例如，前面描述的 1 R 方法就是基于错误的——它关注错误而不是熵。然而，就错误计数而言，最佳的离散化是通过使用尽可能多的区间获得的，这种退化情况应通过预先限制区间数量来避免。

让我们考虑将一个属性离散化为 `k` 个区间以最小化错误数量的最佳方式。寻找此的暴力方法在 `k` 上是指数级的，因此不可行。然而，基于动态规划思想的更高效的方案很多。动态规划不仅适用于错误计数度量，还适用于任何给定的可加不纯度函数，并且可以在时间与 `kN²` 成比例的情况下找到将 `N` 个实例划分为 `k` 个区间以最小化不纯度的方法。这提供了一种找到最佳基于熵的离散化的方法，与之前描述的贪婪递归基于熵的方法相比，它在离散化质量上可能有所改善（但在实践中可以忽略不计）。对于基于错误的离散化，情况甚至更好，因为存在一种算法可以在时间与 `N` 成线性关系的情况下最小化错误计数。

### 基于熵与基于错误的离散化

为什么不使用基于错误的离散化，既然可以非常快速地找到最优离散化？答案是基于错误的离散化存在一个严重的缺点；它无法产生具有相同标签的相邻区间（例如 [图 6.3](#Ch006_209-259_B9780443158889000078.xhtml#f0020) 中的前两个）。原因是合并这样两个区间不会影响错误计数，但它会释放一个区间，该区间可在其他地方用于减少错误计数。

为什么有人会想生成具有相同标签的相邻区间？原因最好用一个例子来说明。[图 6.4](#Ch006_209-259_B9780443158889000078.xhtml#f0025) 显示了具有两个数值属性（范围从 0 到 1）的简单两类问题的实例空间。实例属于一个类（点）如果其第一个属性 (`a1`) 小于 0.3 或者如果它小于 0.7 *并且* 其第二个属性 (`a2`) 小于 0.5。否则，它们属于另一个类（三角形）。[图 6.4](#Ch006_209-259_B9780443158889000078.xhtml#f0025) 中的数据是根据此规则人工生成的。

![图 6.4 两类、两属性问题的类别分布。](images/F000078f06-04-9780443158889.jpg)

图 6.4 两类、两属性问题的类别分布。

现在假设我们试图离散化两个属性，以便从离散化后的属性中学习类别。最好的离散化将 `a1` 分成三个区间（0 到 0.3，0.3 到 0.7，以及 0.7 到 1）并将 `a2` 分成两个区间（0 到 0.5 和 0.5 到 1）。给定这些名义属性，用简单的决策树或规则算法学习如何区分类别将变得很容易。离散化 `a2` 没有问题。对于 `a1`，然而，第一个和最后一个区间将具有相反的标签（分别为 `dot` 和 `triangle`）。第二个区间将具有在 0.3 到 0.7 区域中最常出现的标签（对于 [图 6.4](#Ch006_209-259_B9780443158889000078.xhtml#f0025) 中的数据，实际上是 `dot`）。无论哪种情况，该标签必然与相邻标签之一相同——当然无论中间区域的类别概率如何都是如此。因此，这种离散化不会被任何最小化错误计数的方法实现，因为这种方法无法产生具有相同标签的相邻区间。

关键在于，当 `a1` 的值越过 0.3 处的边界时，发生变化的不是多数类而是类别 *分布*。多数类仍然是 `dot`。然而，分布发生了显著变化，从边界之前 100% 到之后略高于 50%。并且当越过 0.7 处的边界时，分布再次发生变化，从 50% 到 0%。基于熵的离散化方法对分布的变化很敏感，即使多数类没有变化。基于错误的方法则不然。
