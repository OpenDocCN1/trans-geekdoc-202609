## 误差函数与平方误差

为了应用标准的梯度下降过程，误差函数——通过调整权重来最小化的对象——也必须是可微分的。由离散 0–1 损失衡量的误分类数量不满足这一标准，该损失在 [第 5.7 节](#Ch005_165-207_B9780443158889000066.xhtml#s0050) 中提到。相反，多层感知器通常通过最小化网络输出的平方误差来训练，本质上将其视为类别概率的估计。（其他损失函数也适用。例如，如果使用负对数似然代替平方误差，基于 sigmoid 的感知器的学习就与 logistic 回归相同。）

我们使用平方误差损失函数，因为它使用最广泛。对于单个训练实例，它是

## 梯度下降过程

梯度下降利用要最小化的函数——在这种情况下为误差函数——的导数所提供的信息。作为示例，考虑一个假设的误差函数，它恰好与 `w`² + 1<mml:math><mml:msup><mml:mrow><mml:mi>w</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msup><mml:mo>+</mml:mo><mml:mn>1</mml:mn></mml:math>![方程](images/F000108si34.png) 相同，显示在 [图 9.6](#Ch010_347-389_B9780443158889000108.xhtml#f0035) 中。`x` 轴表示一个假设的参数 `w`，需要对其进行优化。`w`² + 1<mml:math><mml:msup><mml:mrow><mml:mi>w</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msup><mml:mo>+</mml:mo><mml:mn>1</mml:mn></mml:math>![方程](images/F000108si35.png) 的导数 simply 为 2`w`。关键的观察是，基于导数，我们可以确定函数在任何特定点的斜率。如果导数为负，函数向右向下倾斜；如果为正，函数向左向下倾斜；导数的大小决定了下降的陡峭程度。梯度下降是一种迭代优化过程，利用此信息调整函数的参数。它取导数值，将其乘以一个称为 `learning rate` 的小常数，然后从当前参数值中减去结果。这对新的参数值重复进行，等等，直到达到最小值。

![图 9.6 使用误差函数 W2 + 1 的梯度下降。](images/F000108f09-06-9780443158889.jpg)

图 9.6 使用误差函数 `W`² + 1 的梯度下降。

回到示例，假设学习率为 0.1，当前参数值 `w` 为 4。导数是其两倍——此时为 8。乘以学习率得到 0.8，从 4 中减去它得到 3.2，这成为新的参数值。对 3.2 重复该过程，我们得到 2.56，然后是 2.048，等等。[图 9.6](#Ch010_347-389_B9780443158889000108.xhtml#f0035) 中的小叉号显示了在此过程中遇到的值。过程在参数值的变化变得太小时停止。在示例中，当值接近 0 时就会发生这种情况，该值对应于 `x` 轴上假设误差函数最小值所在的位置。

学习率决定了步长，从而决定了搜索收敛的速度。如果它太大并且误差函数有多个最小值，搜索可能会 overshoot 并且完全错过一个最小值，或者可能剧烈振荡。如果它太小，朝向最小值的进展可能很慢。请注意，梯度下降只能找到 `local` 最小值。如果函数有多个最小值——而多层感知器的误差函数通常有很多——它可能找不到最佳的一个。与支持向量机相比，这是标准多层感知器的一个显著缺点。
