
# 5

基于有限数据预测性能的问题很有趣。我们将遇到许多不同的技术，其中之一——重复交叉验证——很可能是在大多数实际有限数据情况下的首选方法。在给定问题上比较不同机器学习方案的性能是另一回事，并不像听起来那么容易。为了确保明显的差异不是由偶然效应造成的，需要进行统计检验。

到目前为止，我们一直默示地假设所预测的是对测试实例进行准确分类的能力。然而，有些情况涉及预测类别概率而不是类别本身，而另一些情况涉及预测数值而非名义值。每种情况都需要不同的方法。然后我们来看成本问题。在大多数实际机器学习情况下，误分类错误的成本取决于错误的类型——是正例被错误地分类为负例还是相反。在进行机器学习并评估其性能时，经常必须考虑这些成本。幸运的是，有简单的技术可以在不深入算法内部的情况下使大多数学习方案具有成本敏感性。最后，评估的整个概念具有迷人的哲学联系。两千年来，哲学家们一直在争论如何评估科学理论的问题，而机器学习使这些问题变得尤为突出，因为所提取的本质上是数据的“理论”。

## 5.1 训练与测试

对于分类问题，以 `error rate` 来衡量分类器的性能是自然的。分类器预测每个实例的类别：如果正确，则计为 `success`；如果不正确，则为 `error`。错误率只是整个实例集合中犯错误的比例，它衡量分类器的整体性能。

当然，我们感兴趣的是在新数据上的可能未来性能，而不是在旧数据上的过去性能。我们已经知道训练集中每个实例的分类，这也是我们可以用它进行训练的原因。我们通常对这些分类不感兴趣，除非我们的目的是数据清洗而不是预测。那么问题是，旧数据上的错误率是否可能是新数据上错误率的良好指标？答案是响亮的 `no`——如果旧数据在学习过程中被用于训练分类器的话。

这是一个令人惊讶的事实，也是非常重要的一点。训练集上的错误率 `not` 可能是未来性能的良好指标。为什么？因为分类器是从完全相同的训练数据中学到的，基于该数据的任何性能估计都将是乐观的，甚至可能过于乐观。

我们在劳动关系数据集中已经看到过这一现象的例子。[图 1.3B](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 是直接从训练数据生成的，而 [图 1.3A](#Ch001_3-42_B9780443158889000029.xhtml#f0020) 是通过剪枝过程从它获得的。前者在用于训练分类器的数据上可能更准确，但在独立测试数据上可能表现更差，因为它可能过度拟合了训练数据。根据训练数据上的错误率，第一棵树看起来会更好，比第二棵树更好。但这并不一定反映它们在独立测试数据上的表现。

训练数据上的错误率被称为 `resubstitution error`，因为它是通过将训练实例重新代入从它们构建的分类器来计算的。虽然它不是新数据上真实错误率的可靠预测指标，但了解它仍然经常很有用。

要预测分类器在新数据上的性能，我们需要在一个在分类器形成过程中未参与的数据集上评估其错误率。这个独立的数据集称为 `test set`。我们假设训练数据和测试数据都是潜在问题的代表性样本。

在某些情况下，测试数据在性质上可能与训练数据不同。考虑来自 [第 1.3 节](#Ch001_3-42_B9780443158889000029.xhtml#s0065) 的信用风险问题。假设银行拥有来自纽约市和佛罗里达州分行的训练数据，并想知道在其中一个数据集上训练的分类器在内布拉斯加州新分行的表现如何。它很可能使用佛罗里达数据作为测试数据来评估纽约训练的分类器，并使用纽约数据来评估佛罗里达训练的分类器。如果在训练前将数据集合并，测试数据上的性能可能就不是未来在完全不同州的数据上的良好指标。

重要的是测试数据在任何情况下都 `in any way` 未被用于创建分类器。例如，一些学习方案涉及两个阶段：一个是提出基本结构，第二个是优化该结构中涉及的参数。两个阶段可能需要单独的数据集。或者你可能在训练数据上尝试几种学习方案，然后在全新的数据集上——当然——评估它们，看看哪一个效果最好。但这些数据中的任何一个都不能用于确定未来错误率的估计。在这种情况下，人们经常谈论三个数据集：`training` 数据、`validation` 数据和 `test` 数据。训练数据由一个或多个学习方案使用来生成分类器。验证数据用于优化这些分类器的参数或选择其中一个。然后测试数据用于计算最终优化方法的错误率。三个集合中的每一个都必须独立选择；验证集必须与训练集不同，以在优化或选择阶段获得良好的性能，而测试集必须与两者都不同，以获得真实错误率的可靠估计。

可能一旦确定了错误率，测试数据就会重新捆绑到训练数据中，以生成实际使用的新分类器。这没什么问题；这只是最大化用于生成实际使用的分类器的数据量的方式。对于行为良好的学习方案，这不应降低预测性能。此外，一旦使用了验证数据——也许是为了确定使用哪种类型的学习方案——然后它可以重新捆绑到训练数据中以重新训练该学习方案，最大化数据的使用。

如果有大量数据可用，就没有问题——我们取一个大样本用于训练，然后取另一个独立的大样本不同的数据用于测试。只要两个样本都具有代表性，测试集上的错误率就会很好地指示未来性能。一般来说，训练样本越大，分类器越好，尽管一旦超过一定量的训练数据，收益开始递减。而测试样本越大，错误估计越准确。错误估计的准确性可以在统计上量化，正如我们在 [第 5.2 节](#Ch005_165-207_B9780443158889000066.xhtml#s0015) 中将看到的那样。
