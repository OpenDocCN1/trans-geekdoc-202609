
- `Deeplearning4j` is a Java-based open-source deep learning library available under the Apache 2.0 license. It uses a multidimensional array class and provides linear algebra and matrix manipulation support similar to that provided by `NumPy`.
- `Lasagne` is a lightweight Python library built on top of `Theano` that simplifies the creation of neural network layers. Similarly, `Keras` is a Python library that runs on top of either `Theano` or `TensorFlow` ([Chollet, 2015](#References_705-736_B978044315888900025X.xhtml#fur99)). It allows one to quickly define a network architecture in terms of layers and also includes functionality for image and text preprocessing.
- `NVIDIA CUDA® Deep Neural Network library (cuDNN)` is a highly optimized GPU library for NVIDIA units that allows deep networks to be trained more quickly. It can dramatically accelerate the performance of a deep network and is often called by the other packages mentioned previously.
- `JAX` is another recent framework from Google, presently still under development and research, which can automatically differentiate native Python and `NumPy` functions.
- `Theano` was a pioneering open-source deep learning platform that is no longer under active development due to stiff competition from the platforms developed in industry, which also poached much of its development talent. A version of `Theano` lives on as `PyTensor`, the computational backend behind the probabilistic programming language `PyMC3`.
- `MXNet` was an open-source deep learning framework developed by the Apache Software Foundation but which is no longer under active development. It emphasized flexibility, speed, and scalability, and it had support for eight programming languages: Python, Scala, Julia, Clojure, Java, C++, R, and Perl.

## 10.8 WEKA Implementations

Deep learning can be implemented in `WEKA` using three methods:
- With the wrapper classifier for the third-party `DeepLearningForJ` package that is available in the `deepLearningForJ` package.
- Using the `MLRClassifier` from the `RPlugin` package to exploit deep learning implementations in R.
- By accessing Python-based deep learning libraries using the `PyScript` package.
