
像任何其他学习方案一样，使用反向传播训练的多层感知器也可能出现过拟合问题，尤其是在网络远大于表示底层学习问题结构所实际需要的情况时。已经提出了许多修改方法来缓解这一问题。其中一种非常简单的方法叫做 `early stopping`，它类似于规则学习器中的减误差剪枝——使用一个保留集来决定何时停止执行反向传播算法的进一步迭代。对保留集上的误差进行测量，一旦误差开始增加，算法就会终止，因为这表明对训练数据发生了过拟合。另一种方法叫做 `weight decay`，它在误差函数中加入一个惩罚项，该惩罚项由网络中所有非偏置权重的平方和组成，如岭回归中那样。这试图通过惩罚那些没有带来相应较大误差减少的大权重，来限制无关连接对网络预测的影响。

尽管标准梯度下降是学习多层感知器权重最简单的技术，但它绝不是最有效的方法。实际上，在标准个人计算机上执行时，它往往相当缓慢。一种经常能提高性能的技巧是在更新权重时加入 `momentum` 项；将前一次迭代的更新值的一小部分加到新的权重变化中。这通过使方向变化不那么突然而平滑了搜索过程。更复杂的方法也会利用从误差函数的二阶导数获得的信息；它们可以收敛得快得多。然而，即使是这些算法，与其他分类学习方法相比也可能非常缓慢。

包含隐藏单元的多层感知器的一个严重缺点是它们本质上是不透明的。有几种技术试图从训练好的神经网络中提取规则。然而，目前尚不清楚它们是否比标准规则学习器提供任何优势，后者直接从数据中归纳规则集，尤其是考虑到这通常可以比首先学习一个多层感知器更快地完成。

尽管多层感知器是最突出的神经网络类型，但也提出了许多其他类型。多层感知器属于一类称为 `feedforward networks` 的网络，因为它们不包含任何循环，并且网络的输出仅取决于当前输入实例。`Recurrent` 神经网络确实有循环。来自早期输入的计算会被反馈到网络中，这赋予了它们一种记忆能力。

## 径向基函数网络

另一种流行的前馈网络是 RBF 网络。它有两个层，不计输入层，并且与多层感知器在隐藏单元执行计算的方式上有所不同。每个隐藏单元本质上代表输入空间中的一个特定点，其对于给定实例的输出，或 `activation`，取决于其点与该实例之间的距离，而实例也只是另一个点。直观上，这两个点越接近，激活越强。这是通过使用非线性变换函数将距离转换为相似性度量来实现的。钟形的高斯 `activation function`，其宽度可能对每个隐藏单元不同，通常用于此目的。隐藏单元被称为 RBFs，因为在实例空间中使给定隐藏单元产生相同激活的点形成一个超球面或超椭球面。（在多层感知器中这是超平面。）

RBF 网络的输出层与多层感知器的输出层相同。它取隐藏单元输出的线性组合，并在分类问题中将其通过 sigmoid 函数（或具有相似形状的东西）传递。

此类网络学习的参数是（1）RBF 的中心和宽度，以及（2）用于形成来自隐藏层输出的线性组合的权重。与多层感知器相比的一个显著优势是，第一组参数可以独立于第二组参数确定，并且仍然能产生相当准确的分类器。

确定第一组参数的一种方法是使用聚类。文中所述的简单 `k-means` 聚类算法 [第 4.8 节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0140) 可以应用，对每个类别独立聚类以获得每个类别的 `k` 个基函数。直观上，得到的 RBFs 代表原型实例。然后在保持第一组参数固定的情况下学习第二组参数。这涉及使用我们讨论过的一种技术（例如线性或逻辑回归）学习一个简单的线性分类器。如果隐藏单元远少于训练实例，这可以非常快速地完成。注意，尽管这种两阶段过程非常快，但通常不如使用梯度下降等策略训练所有网络参数那样准确。

RBF 网络的一个缺点是它们对每个属性赋予相同的权重，因为在距离计算中所有属性都被同等对待，除非属性权重参数被包含在整体优化过程中。支持向量机也有相同的问题。事实上，使用高斯核（即“RBF 核”）的支持向量机是一种特殊的 RBF 网络，其中每个训练实例上都居中一个基函数，所有基函数具有相同的宽度，并且输出通过计算最大间隔超平面以线性方式组合。这导致只有一些 RBF 具有非零权重——代表支持向量的那些。

## 随机梯度下降

我们已经介绍了梯度下降和随机反向传播作为学习神经网络权重优化方法。梯度下降实际上是一种通用优化技术，只要目标函数可微分就可以应用。实际上，原来它甚至可以在目标函数不是完全可微分的情况下通过使用一种称为 `subgradients` 的装置来应用。

一个应用是使用梯度下降来学习线性模型，例如线性支持向量机或逻辑回归。使用梯度下降学习此类模型比优化非线性神经网络更容易，因为误差函数有一个全局最小值而不是许多局部最小值，而这通常是非线性网络的情况。对于线性问题，可以设计一种计算简单且收敛非常迅速的随机梯度下降过程，从而允许诸如线性支持向量机和逻辑回归等模型从大型数据集中学习。此外，随机梯度下降允许模型以增量方式在线设置中学习。
