
其中 `N(x; μ[A], σ[A])` 是聚类 A 的正态或高斯分布函数：

$N(x;\\mu,\\sigma) = \\frac{1}{\\sqrt{2\\pi}\\sigma}e^{- \\frac{{(x - \\mu)}^{2}}{2\\sigma^{2}}}.$

在实践中，我们计算 `P(A|x[i])` 和 `P(B|x[i])` 两者的分子，然后通过除以它们的和进行归一化，该和为 `P(x[i])`。整个过程与数值属性在 [第 4.2 节](#Ch004_91-164_B9780443158889000054.xhtml#s0020) 的朴素贝叶斯学习方案中被处理的方式相同。并且那里解释的警告在这里也适用——严格来说，`N(x[i]; μ[A], σ[A])` 并不是概率 `P(x|A)`，因为 `x` 为任何特定实数 `x[i]` 的概率为零。相反，`N(x[i]; μ[A], σ[A])` 是一个概率密度，它通过用于计算后验的归一化过程被转化为概率。请注意，最终结果不是特定的聚类，而是 `x[i]` 属于聚类 A 或聚类 B 的（后验）`probability`。

问题在于我们不知道这些事情中的任何一个——每个训练实例来自的分布或混合模型的五个参数。因此我们采用 `k-means` 聚类算法中使用的方法并进行迭代。从五个参数的初始猜测开始，使用它们为每个实例计算聚类概率，使用这些概率重新估计参数，然后重复。（如果你愿意，也可以从对实例类别的猜测开始。）这是 `EM` 算法的一个实例。第一步，计算聚类概率（即“期望”类别值），是“期望”；第二步，计算分布参数，是我们对给定数据的分布似然的“最大化”。
