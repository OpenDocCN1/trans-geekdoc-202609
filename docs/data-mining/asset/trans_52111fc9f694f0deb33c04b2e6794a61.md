
## 嵌套二分法

这个思想是递归地将原始多分类问题中的完整类别集合拆分为越来越小的子集，同时将实例的完整数据集拆分为与这些类别子集相对应的子集。这产生了一个类别的二叉树。考虑前面讨论的假设的 4 类问题。在根节点上是完整的类别集合 {`a`, `b`, `c`, `d`}，它们被拆分为不相交的子集，比如 {`a`, `c`} 和 {`b`, `d`}，以及与这两个类别子集相关的实例。这两个子集构成了二叉树中的两个后继节点。然后这些子集进一步拆分为单元素集合，对于节点 {`a`, `c`} 产生后继 {`a`} 和 {`c`}，对于节点 {`b`, `d`} 产生后继 {`b`} 和 {`d`}。一旦达到单元素子集，拆分过程就停止。

由此产生的类别二叉树被称为 *嵌套二分法*，因为每个内部节点及其两个后继定义了一个二分法——在根节点区分类别 {`a`, `c`} 和 {`b`, `d`}——并且这些二分法嵌套在层次结构中。我们可以将嵌套二分法视为一种特定类型的稀疏输出编码。[表 6.3](#Ch006_209-259_B9780443158889000078.xhtml#t0020) 显示了刚才讨论的示例的输出编码矩阵。树结构中的每个内部节点对应一个二分法。因此鉴于该示例涉及三个内部节点，编码矩阵中有三列。与之前考虑的类别向量不同，矩阵中包含标记为 X 的元素，表示相应类别的实例只是从相关的两类学习问题中省略。

表 6.3

一种代码矩阵形式的嵌套二分法

| 类 | | 类向量 |
| --- | --- |
| `A` | | 0 0 X |
| --- | --- |
| `B` | | 1 X 0 |
| `C` | | 0 1 X |
| `D` | | 1 X 1 |

这种输出编码有什么优势？事实证明，由于分解是分层的并且产生不相交的子集，假设对层次结构中的每个二分法都有两类估计，就存在一种简单的方法来计算原始多个类别集合中每个元素的类别概率估计。其原因来自概率论中的链式法则，我们在讨论贝叶斯网络时在 [第 13.2 节](#Ch014_485-514_B9780443158889000145.xhtml#s0025) 中会再次遇到。

假设我们想计算给定特定实例 `x` 的类别 `a` 的概率，即条件概率 `P(a|x)`。该类别对应于前一示例中类别层次结构中的四个叶节点之一。首先，我们学习两类模型，这些模型为层次结构内部节点的三个两类数据集产生类别概率估计。然后，从根节点的两类模型中，可以获得条件概率 `P({a,c}|x)` 的估计——即 `x` 属于 `a` 或 `c`——。此外，我们可以从区分单元素集合 {`a`} 和 {`c`} 的模型中获得 `P({a}|x,{a,c})` 的估计——即在已知 `x` 属于 `a` 或 `c` 的情况下，`x` 属于 `a` 的概率。现在，基于链式法则，`P(a|x) = P({a}|{a,c},x) × P({a,c}|x)`。因此，要计算原始多分类问题中任何单个类别的概率（例如，类别树中的任何叶节点），我们只需将从根节点到该叶节点的过程中遇到的内部节点收集的概率估计相乘——即包含目标类别的所有类别子集的概率估计。

假设内部节点的各个两类模型产生准确的概率估计，有理由相信使用链式法则获得的多类概率估计通常是准确的。然而，很明显估计误差会累积，对非常深的层次结构造成问题。更基本的问题是，在前面的示例中我们任意决定了类别的特定分层分解。也许有关所涉及领域的某些背景知识，在这种情况下，一种特定的层次结构可能更可取，因为某些类别已知相关，但通常情况并非如此。

可以怎么办？如果先验没有理由偏好任何特定分解，也许应该考虑所有分解，从而产生 *集成* 的嵌套二分法。不幸的是，对于任何非平凡的类别数量，潜在的二分法太多，使得穷举方法不可行。但我们可以考虑一个子集，随机抽样可能的树结构，为每棵树结构的每个内部节点构建两类模型（通过缓存模型，因为相同的两类问题可能出现在多棵树中），然后对每个单个类别的概率估计进行平均以获得最终估计。

实证实验表明，这种方法产生准确的多分类器，并且能够提高预测性能，即使对于可以直接处理多分类问题的分类器，例如决策树。 与标准纠错输出编码相比，该技术即使在基础学习器无法建模复杂决策边界时也经常表现良好。其原因在于，一般来说，类别越少学习越容易，因此结果越接近树中的叶节点越成功。这也解释了为什么前面描述的成对分类技术对于简单模型例如对应于超平面的模型特别有效；它创建了最简单的二分法！嵌套二分法似乎在成对分类中出现的学习问题的简单性——毕竟，最低层的二分法涉及成对的单个类别——与标准纠错输出编码所体现的冗余的强大能力之间取得了有用的平衡。

## 6.7 校准类别概率

类别概率估计显然比分类更困难。给定一种生成类别概率的方法，只要将正确类别以最大概率预测，分类错误就会最小化。然而，分类方法并不意味着生成准确概率估计的方法——产生正确分类的估计在根据 [第 5.7 节](#Ch005_165-207_B9780443158889000066.xhtml#s0050) 中讨论的二次或信息损失进行评估时可能非常差。然而，正如我们多次强调的那样，通常获得给定实例的准确条件类别概率比简单地将其放入一个类别中更重要。基于最小期望成本方法的成本敏感预测就是一个准确的类别概率估计非常有用的例子。

考虑具有两个类别的数据集的概率估计情况。如果预测的概率在分类常用的 0.5 阈值的正确一侧，就不会出现分类错误。然而，这并不意味着概率估计本身是准确的。它们可能系统性地过于乐观（过于接近 0 或 1）或过于悲观（不够接近极值）。这种类型的偏差会增加测量的二次或信息损失，并且在尝试基于给定的成本矩阵最小化分类的期望成本时会造成问题。
