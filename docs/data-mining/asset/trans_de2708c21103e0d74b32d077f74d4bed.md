
原始的 `GPT` 模型针对每个单独的监督 `NLP` 任务分别进行微调。训练于更广泛语料库的更大的 `GPT-2` 模型，能够在 `zero-shot learning` 环境中解决多个 `NLP` 任务，而无需针对每个任务进行微调，只需提供一个自然语言提示，要求系统解决当前任务即可。随后在规模更大、更强大的 `GPT-3` 模型中得到了进一步改进，该模型具有足够大的上下文窗口，可在提示中包含目标任务的多个示例，经常仅凭这些少量示例就能在许多任务上实现最先进的 `NLP` 性能（“`few-shot learning`。”）`GPT-4` 系列中的其中一个模型包含图像数据，并提供 `API` 来回答用户提供的图像相关问题。`GPT-4` 能够解决涵盖数学、编程、医学、法律等多个领域的各种 `AI` 任务的能力，使得一些研究人员宣称它开始进入人工智能通用智能（`AGI`）系统的早期阶段。然而，截至撰写本文时，尽管性能令人印象深刻，`GPT` 仍容易产生 `hallucinations`，即自信地产生错误信息。有关 `GPT` 及其他类似 `LLMs` 的担忧和问题讨论，请参阅 [第15章](#Ch016_571-615_B9780443158889000169.xhtml#Ch016_571-615_B9780443158889000169)，“继续前进：应用及其后果”，。

### 来自 Transformers 的双向编码器表征
正如我们所讨论的，`GPT` 从左到右处理文本数据，这使其非常擅长生成新文本。`GPT` 的动机之一是使用单一语言模型解决多个 `NLP` 任务。然而，左到右的处理方式对此并不最优。`BERT` 是由 Google 研究人员提出的一个 `LLM`，它使用“双向”Transformer 架构（即不再使用左到右处理，并且还可以检查后续 token）。`BERT` 模型在通过微调或提取嵌入作为特征来解决下游 `NLP` 任务方面处于最先进水平。基于 Transformer 的方法，大多基于 `BERT`，目前在 `NLP` 任务的大部分领域处于最先进水平，这迅速革新了该领域。

`BERT` 模型使用一种 Transformer 架构版本，其中 Transformer 块的堆叠用于生成文本的嵌入，随后可用于执行下游 `NLP` 任务。由于它生成的是嵌入而非文本序列，我们可以将其视为 `encoder-only` 架构。`BERT` 的设计意图是在大型未标注文本语料库上预训练模型，然后对其进行微调以解决特定 `NLP` 任务。在预训练期间，而不是训练模型预测序列中的下一个 token，`BERT` 使用 `masked language model`（`MLM`）方法。在 `MLM` 中，为了预训练模型，我们只需隐藏或“mask”模型中随机比例的 token，并要求它预测这些 token。`BERT` 还使用第二个预训练任务，称为 `next-sentence prediction`（`NSP`）。在此任务中，我们将两个句子用分隔 token 连接起来。在某些情况下，第二句话是紧跟在第一句话之后出现的句子，有时则是另一个随机选择的句子。然后我们训练模型预测第二句话是否为“下一句话”。`MLM` 和 `NSP` 都是自监督学习技术，其中监督标签直接从文本本身提取，作为训练语言模型的便捷代理任务。因此这种方法让人联想到 `skip-gram`，其中上下文词的预测也被类似地选作便捷且有效的自监督训练目标。

`BERT` 一次处理一对句子，以便执行 `NSP`。它在第一个句子前添加一个特殊的“分类 token”，称为 `CLS`，并在句子之间添加“分隔”token（`SEP`）。它还为每个 token 的输入添加“segment embeddings”以及位置嵌入，以指示该 token 属于第一句还是第二句。`CLS` token 的嵌入通常被用作句子在下游任务中的嵌入表示。这种两句话格式也便于微调以解决下游任务，即在任务特定的微调数据集中使用问答对作为第一句和第二句。因此，该架构可普遍应用于许多 `NLP` 任务，且只需少量修改即可适应新任务。请参阅 [图 11.12](#Ch012_433-471_B9780443158889000121.xhtml#f0065) 以了解 `BERT` 模型的示意图。

### 基于 Transformer 的神经机器翻译
Google 研究人员提出 Transformer 架构的原始论文，名为“`Attention Is All You Need`”，将其用于 `NMT`。他们的方案使用一种让人联想到我们之前讨论过的 `Seq2Seq` 和 `RNNSearch` 模型的 encoder-decoder 架构，但使用了 Transformer。编码器和解码器都是 Transformer 块的堆叠（原始论文中各为六个块）。编码器通过其多头注意力机制处理源语言的输入文本，识别并处理文本的相关部分。解码器用于生成翻译，基于输入文本和迄今为止的译文序列预测译文序列中的下一个 token。解码器使用 masked multihead attention，防止其关注当前 token 之后出现的 token，确保预测严格按左到右的方式进行。编码器不需要使用 masking，因为我们不需要预测输入句子，只需要预测其翻译。翻译后的 token 通过一个与 `GPT` 类似的最终 softmax 层进行预测。请参阅 [图 11.13](#Ch012_433-471_B9780443158889000121.xhtml#f0070) 以了解示意图。
