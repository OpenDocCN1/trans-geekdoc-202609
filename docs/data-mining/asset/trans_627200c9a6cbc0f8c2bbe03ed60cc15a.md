
其中 `pos`![公式](images/F000121si142.png) 是文档中的位置，`i`![公式](images/F000121si143.png) 是位置编码中的维度，而 `n`![公式](images/F000121si144.png) 是一个缩放常数，作者将其设为 10,000。结果是位置编码的每个维度都是一个正弦曲线，且这些正弦曲线的波长遵循几何级数，在 `2π`![公式](images/F000121si145.png) 和 `2π n`![公式](images/F000121si146.png) 之间变化。虽然可以使用其他函数或学习到的位置嵌入，但正弦方法在实践中效果良好，并且可以外推到训练数据中未见的序列长度。其他作者，例如 `GPT` 模型的作者，则使用了学习到的位置嵌入。

## 11.4 基于 Transformer 的语言模型

我们现在可以将我们描述的所有组件结合起来，使用 Transformer 架构创建语言模型。

### 仅解码器架构

假设我们想要构建一个基于 Transformer 的语言模型来预测词序列。这样的模型训练的目标是最大化文本语料库中每个词 `w[i]`![公式](images/F000121si147.png) 在上下文窗口大小为 `k`![公式](images/F000121si148.png) 的先前词条件下的对数似然：

`L = ∑[i] log P(w[i] | w[i-1], w[i-2], …, w[i-k])`.![公式](images/F000121si149.png)

每个词由输入嵌入加上位置编码向量表示。这些表示被输入到 `N`![公式](images/F000121si150.png) 个 Transformer 块的堆叠中，使用掩码多头注意力以确保在序列的每一步中，仅使用之前的 token 来预测下一个 token。在最后一层，下一个词 `w[i]`![公式](images/F000121si151.png) 是使用最后一层的隐藏状态向量 `h[N]`![公式](images/F000121si152.png) 和输入嵌入 `V[e]`![公式](images/F000121si153.png) 通过 `softmax(h[N] V[e]^T)`![公式](images/F000121si154.png) 预测的（[图 11.11](#Ch012_433-471_B9780443158889000121.xhtml#f0060)）。我们刚刚描述的模型有时被称为 `decoder-only` Transformer 架构，因为没有编码器阶段，不像我们稍后将描述的一些模型。它也是一个 `autoregressive model`，该术语借自时间序列分析，意味着未来（此处为序列中后面的词）是基于过去（此处为序列中之前的词）预测的。

### 生成式预训练 Transformer

OpenAI 的 `GPT` 系列模型是大型的基于 Transformer 的语言模型。它们是仅解码器架构的变体。由于它们专注于根据之前的 token 预测下一个 token，因此在生成新文本数据方面表现出色。基于 `GPT` 的聊天机器人 ChatGPT 已通过一种称为 `reinforcement learning from human feedback` 的过程进行微调，以遵循以自然语言形式给出的指令或“提示”。它可以提供令人惊讶地类人且复杂的响应。这些模型也可以被微调以解决其他任务，这在早期的 `GPT` 和 `GPT-2` 模型中是一种流行的方法。对于更新的 `GPT` 模型，用户则被鼓励进行“`zero-shot`”、“`one-shot`”或“`few-shot`”学习，其中模型有时可以在不进行微调的情况下解决专门任务，而是通过在提示本身中提供要解决的任务，可能附带少量示例，并依赖系统根据其从大型自然语言训练语料库中获得的知识来解释提示并解决任务。

`GPT` 模型中对仅解码器架构的主要修改是为了处理监督学习任务。模型首先作为语言模型进行训练，根据之前的 token 预测下一个 token，这被视为预训练步骤。然后模型通过额外训练进行微调，以执行监督 NLP 预测任务，包括阅读理解测试、摘要、翻译、问答等。
