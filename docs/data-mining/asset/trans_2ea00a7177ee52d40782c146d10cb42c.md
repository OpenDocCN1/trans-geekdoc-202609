
# 用于分类的未标记数据

未标记数据如何用于改进分类？这里有一个简单的想法——使用 `Naïve Bayes` 从少量标记数据集中学习类别，然后使用 [第13.3节](#Ch014_485-514_B9780443158889000145.xhtml#s0050) 的 `EM` (`expectation–maximization`) 迭代聚类算法将其扩展到大型未标记数据集，该过程在精神上类似于 `k`-means 聚类，但考虑了聚类分配中的不确定性。

过程如下。第一，使用标记数据训练分类器。第二，将其应用于未标记数据，用类别概率为其标注（“期望”步骤）。第三，使用所有数据的标签训练新的分类器（“最大化”步骤）。第四，迭代直至收敛。

可以将其视为迭代聚类，其中起点和聚类标签是从标记数据中获取的。`EM` 过程保证在每次迭代中找到具有相等或更大似然性的模型参数。

唯一能通过经验回答的关键问题是，这些更高似然的参数估计是否会提高分类准确率。

直观上，这可能效果很好，特别是如果数据具有许多属性并且它们之间存在强关系。考虑文档分类。某些短语可以指示类别。有些出现在标记文档中，而有些只出现在未标记文档中。但可能有一些文档同时包含两者，而 `EM` 过程利用这些文档将学习到的模型推广，以利用未出现在标记数据集中的短语。例如，*supervisor* 和 *PhD topic* 都可能表示研究生主页。假设只有前者短语出现在标记文档中。`EM` 会迭代地推广模型，以正确分类仅包含后者的文档。

这可能适用于任何分类器和任何迭代聚类算法。但它基本上是一种自举过程，必须小心确保反馈回路是正向的。使用概率而不是硬决策似乎是有益的，因为它允许过程缓慢收敛，而不是跳到可能错误的结论。`Naïve Bayes` 与 [第13.3节](#Ch014_485-514_B9780443158889000145.xhtml#s0050) 中描述的基本概率 `EM` 基于聚类过程一起是特别合适的选择，因为它们共享相同的根本假设——属性之间的独立性，或更精确地说，给定类别时属性之间的条件独立性。

当然，独立性假设普遍被违反。即使我们的小例子使用了双词短语 *PhD topic*，而实际实现可能更可能使用单个词作为属性，如果我们用单个词 *PhD* 或 *topic* 中的任一个替换，例子会远 less compelling。短语 *PhD students* 可能更能指示教师而非研究生主页；短语 *research topic* 可能区分度较低。正是 *PhD* 和 *topic* 在给定类别时 *不是* 条件独立的这一事实使得例子成立。正是它们的组合表征了研究生页面。

尽管如此，以这种方式耦合 `Naïve Bayes` 和 `EM` 在文档分类领域效果良好。在一个特定的分类任务中，它达到了传统学习者使用少于三分之一的标记训练实例以及五倍未标记实例的性能。当标记实例昂贵而未标记实例几乎免费时，这是一个很好的权衡。借助少量标记文档，通过合并大量未标记文档可以显著提高分类准确率。

已有两种对该过程的改进被证明可以提高性能。第一个改进的动机来自实验证据，即当标记文档很多时，合并未标记数据可能会降低而不是提高准确率。手工标记的数据（或应该是）本质上比自动标记的数据噪声更少。解决方案是引入一个权重参数来降低未标记数据的贡献。这可以通过在 `EM` 的最大化步骤中最大化标记和未标记实例的加权似然来纳入。当参数接近零时，未标记文档对 `EM` 爬山表面的形状影响很小；当参数接近一时，算法恢复到原始版本，其中表面受两种文档同等影响。

第二个改进是允许每个类别有多个聚类。如 [第13.3节](#Ch014_485-514_B9780443158889000145.xhtml#s0050) 中所解释，`EM` 聚类算法假设数据是从不同概率分布的混合中随机生成的，每个聚类一个。直到现在，一直假设混合成分与类别之间存在一一对应关系。在许多情况下这是不现实的，包括文档分类，因为大多数文档涉及多个主题。每个类别有多个聚类时，每个标记文档最初以概率方式随机分配到其各个成分中。`EM` 算法的最大化步骤保持不变，但期望步骤被修改为不仅以概率方式为每个示例标记类别，还以概率方式将其分配到类别内的成分中。每个类别的聚类数量是一个取决于领域的参数，可以通过交叉验证来设置。

## Cotraining

另一种未标记数据可以提高分类性能的情况是当分类任务存在两种不同且独立的视角时。经典例子再次涉及文档，这次是 Web 文档，其中两个视角是 Web 页面的 *content* 和来自其他页面的 *links*。这两个视角众所周知既有用又不同——成功的 Web 搜索引擎都利用了它们，使用秘密配方。标记指向另一个 Web 页面的链接的文本提供了该页面内容的揭示线索，可能甚至比页面本身的内容更具揭示性，特别是如果链接是独立的。直观上，标记为 *my advisor* 的链接是目标页面为教师主页的有力证据。

这个被称为 `cotraining` 的想法是这样的。给定少量标记示例，首先为每个视角学习不同的模型——在这种情况下是基于内容和基于超链接的模型。然后分别使用每个模型为未标记示例标注。对于每个模型，选择其最有把握标记为正例的示例和最有把握标记为负例的示例，并将其添加到标记示例池中。更好的是，通过选择一种类型多于另一种来保持标记池中正例和负例的比例。在任何情况下，都重复整个过程，在扩充的标记示例池上训练两个模型，直到未标记池耗尽。

有一些实验证据，使用 `Naïve Bayes` 作为学习器，表明这种自举过程优于使用两个视角的所有特征从标记数据学习单一模型的方法。它依赖于实例的两个不同视图，这些视图是冗余的但不完全相关。各种领域已被提出，从使用视频和音频分别在电视新闻中发现名人，到配备视觉、声纳和测距传感器的移动机器人。视图的独立性降低了两个假设在错误标签上达成一致的可能性。
