## 9.3 使用局部线性模型的数值预测
用于数值预测的树与普通决策树类似，只是每个叶节点存储的内容不同：要么存储到达该叶节点的实例的平均值作为类别值，此时树称为`regression tree`，要么存储一个线性回归模型来预测到达该叶节点的实例的类别值，此时称为`model tree`。我们接下来将深入探讨模型树，因为回归树实际上是其特例。

回归树和模型树是通过首先使用决策树归纳算法构建初始树来构造的。然而，大多数决策树算法选择分裂属性以最大化信息增益，而对于数值预测，更合适的做法是最小化每个分支下类别值的子集内变异。一旦基本树形成，就考虑从每个叶节点回剪树，就像普通决策树一样。回归树和模型树归纳之间的唯一区别在于，后者用回归平面代替常数值来替换每个节点。定义该平面的属性通常是那些参与当前节点下方将被剪枝的子树中节点决策的属性，以及可能出现在通往根节点路径上的属性。

在对模型树进行详细描述之后，我们简要解释如何从模型树生成规则，然后描述另一种基于生成局部线性模型的数值预测方法——局部加权线性回归。模型树源自基本的分而治之决策树方法，而局部加权回归则受到实例基于的方法的启发，该方法用于分类，我们在[第4.7节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0120)中描述并讨论。像基于实例的学习一样，它在预测时执行所有“学习”。尽管局部加权回归在利用线性回归将模型局部拟合到实例空间的特定区域方面与模型树相似，但其实现方式完全不同。

### Model Trees
当使用模型树预测测试实例的值时，树会以正常方式向下遍历到叶节点，使用实例的属性值在每个节点做出路由决策。叶节点将包含基于某些属性值的线性模型，并对测试实例进行评估以产生原始预测值。

然而，直接使用该原始值并不是最佳做法，使用平滑过程来减少修剪后树叶节点之间相邻线性模型不可避免的尖锐不连续性是有益的。这对于由少量训练实例构建的模型来说尤其是一个问题。平滑可以通过在构建树时为每个内部节点以及叶节点生成线性模型来实现。然后，一旦叶模型用于获得测试实例的原始预测值，该值就会沿着返回根节点的路径进行过滤，在每个节点通过将其与该节点线性模型预测的值结合来对其进行平滑。
