# 第8章 集成学习

## 摘要

提高机器学习性能的一种强大方法是结合多个模型的预测。这涉及构建分类器集成——例如一组决策树而非单棵树。我们首先描述装袋和随机化，两者都使用单一学习算法生成集成预测器。装袋通过随机重采样扰动输入数据；随机化在学习算法中引入随机成分。两者可以结合，当应用于决策树学习时，可产生所谓的“随机森林”预测器，以及一种称为“旋转森林”的变体。决策树学习器在构建集成时也常用于所谓的“提升”算法，该算法通过迭代改进迄今构建的集成，顺序生成集成分类器。我们讨论开创性的 `AdaBoost.M1` 算法，然后回顾统计学中密切相关的加性回归过程，该过程也以顺序误差校正方式构建集成预测器。集成学习器的一个关键问题是如何从树集成中生成可解释的模型。一种方法是为决策树配备选项节点（选项树）；另一种是在叶节点添加逻辑回归（逻辑模型树）。装袋以及迄今为止介绍的其他集成学习器构建同质集成，使用相同的学习算法生成每个集成成员。明显的替代方案是使用不同的学习算法生成每个集成成员，在这种情况下，通常有用的是学习一个元模型来结合各个成员的预测，这种技术称为“堆叠”。
