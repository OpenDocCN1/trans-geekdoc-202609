Important and useful variations of GANs include `conditional GANs`, which generate their output conditional on some input data, and `style transfer` models, which can generate an alternate version of an image with different stylistic properties, such as being painted by a different artist, or a photo being taken in a different season, and so on.

## Variational Auto-Encoders

Variational Autoencoders (`VAEs`) are an alternative to `GANs` that are also a powerful approach to generating many types of realistic data using neural networks. While `GANs` try to directly learn how to generate realistic samples, `VAEs` do some probabilistic modeling and inference along the way. This gives us a more explicit representation of the data distribution according to the model. It may also give us more control if we want to meaningfully alter the distribution. On the other hand, an assumed probabilistic model is by definition an assumption about the data that may or may not be accurate, useful, or appropriate.

`VAEs` can be understood either from the perspective of neural networks, or the perspective of probabilistic models. From the neural network perspective, `VAEs` can be understood as having an autoencoder architecture, with an encoder network and a decoder network.
