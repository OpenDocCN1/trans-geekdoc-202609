这里，`a′(j)` 是第 `j` 个被误分类的训练实例，`a′(j)[i]` 是其第 `i` 个属性值，而 `y(j)` 是其类别值（为 +1 或 −1）。为了实现这一点，我们不再跟踪显式的权重向量；我们只需存储迄今为止被误分类的实例，并使用之前的表达式来进行预测。

看起来我们一无所获——事实上，该算法速度更慢，因为每次进行预测时它都要遍历所有被误分类的训练实例。然而，对该公式进行更仔细的检查会发现，它可以用实例之间的点积来表示。首先，交换求和符号得到

这样，感知器算法只需跟踪训练过程中被误分类的实例，并使用该表达式形成每次预测，就能学习非线性分类器。

如果核函数隐式创建的高维空间中存在一个分离超平面，该算法将学习到它。然而，它不会学习到支持向量机分类器找到的最大间隔超平面。这意味着分类性能通常更差。另一方面，该算法易于实现并支持增量学习。

该分类器称为 `kernel perceptron`。事实证明，通过以类似的方式应用核技巧，可以升级各种用于学习线性模型的算法。例如，逻辑回归可以转变为 `kernel logistic regression`。正如我们之前看到的，回归问题也适用；线性回归也可以使用核进行升级。同样，这些用于线性回归和逻辑回归的先进方法的缺点（如果以直接的方式完成）是解不是“稀疏的”——每个训练实例都会对解向量做出贡献。在支持向量机和核感知器中，只有部分训练实例会影响解，这对计算效率可能产生很大差异。

感知器算法找到的解向量在很大程度上取决于实例出现的顺序。使算法更稳定的一个方法是使用学习过程中遇到的所有权重向量，而不仅仅是最终的一个，让它们对预测进行投票。每个权重向量贡献一定数量的票。直观上，权重向量的“正确性”大致可以衡量为其产生后在连续试验中正确分类后续实例且因此无需更改的次数。该度量可作为赋予权重向量的票数，从而得到一种称为 `voted perceptron` 的算法，其性能几乎与支持向量机相当。（请注意，正如前面提到的，投票感知器中的各种权重向量不需要显式存储，并且这里也可以应用核技巧。）

### 多层感知器

使用核并不是基于感知器创建非线性分类器的唯一方法。事实上，核函数是机器学习中相当近期的发展。以前，神经网络的支持者使用了一种不同的非线性分类方法——他们将许多简单的类感知器模型连接成层次结构。这种方法以深度学习的形式出现了戏剧性的复兴，我们将在 [第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)、“深度学习：基础” 和 [第11章](#Ch012_433-471_B9780443158889000121.xhtml#Ch012_433-471_B9780443158889000121)、“高级深度学习方法” 中介绍。

[第4.6节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0095) 解释了感知器在实例空间中表示一个超平面。我们在那里提到它有时被描述为人工“神经元”。当然，人类和动物的大脑成功地执行了诸如图像识别等非常复杂的分类任务。大脑中每个单个神经元的功能显然不足以完成这些壮举。它们如何能由类脑结构解决？答案一定在于大脑中的神经元是大量互连的，使得问题可以分解为可在神经元级别解决的子问题。这一观察启发了人工神经元网络——神经网络的发展。
