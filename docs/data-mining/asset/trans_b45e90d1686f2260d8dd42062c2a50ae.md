
## 分类分布
`categorical` 分布被定义为具有多于两个状态的离散随机变量；它推广了 Bernoulli 分布。对于 `K` 个类别，可以定义 `A` ∈ {`a`[1],`a`[2],⋯,`a`[`K`]}![方程](images/F000212si99.png) 或 `x` ∈ {1, 2,⋯,`K`}![方程](images/F000212si100.png)；然而，用于编码类别的整数的顺序是任意的。如果 `x` 处于状态或类别 `k` 的概率由 π[`k`] 给出，并且如果我们对向量表示 `x` 使用 `one hot` 编码，其中 `x` 的所有元素均为零，除了恰好一个维度等于 1，表示 `x` 的状态或类别，则分类分布为

```
$P\\left( {\\mathbf{x};\\mathbf{\\pi}} \\right) = \\prod\\limits\_{k = 1}^{K}\\pi\_{k}^{x\_{k}}.$
```
![方程](images/F000212si101.png)

## 多项分布
`multinomial` 分布推广了 `categorical` 分布。给定对具有每个类别 `k` 固定类别概率 π[`k`] 的离散随机变量的多次独立观测，多项分布定义了观察到每个类别特定数量实例的概率。如果向量 `x` 定义为每个类别被观察到的次数，则多项分布可以表示为

```
$P\\left( {\\mathbf{x};n,\\mathbf{\\pi}} \\right) = \\begin{pmatrix} {n!} \\\\ {x\_{1}!\\cdots x\_{K}!} \\\\ \\end{pmatrix}\\prod\\limits\_{k = 1}^{K}\\pi\_{k}^{x\_{k}}.$
```
![方程](images/F000212si102.png)

## 狄利克雷分布
`Dirichlet` 分布被定义为随机变量或参数向量 `π`，使得 π[1], …, π[`K`] > 0![方程](images/F000212si103.png)，π[1], …, π[`K`] < 1![方程](images/F000212si104.png)，π[1] + π[2] + …, π[`K`] = 1![方程](images/F000212si105.png)，这正是用于定义 `categorical` 和 `multinomial` 分布的 `π` 的形式。参数为 `α`[1], …, `α`[`K`] > 0![方程](images/F000212si106.png)，`K` ≥ 2![方程](images/F000212si107.png) 的 Dirichlet `distribution` 为

```
$P\\left( {\\mathbf{\\pi};\\mathbf{\\alpha}} \\right) = \\frac{1}{B\\left( \\mathbf{\\alpha} \\right)}\\prod\\limits\_{i = k}^{K}\\pi\_{k}^{\\alpha\_{k} - 1},$
```
![方程](images/F000212si108.png)
