
虽然 `Q`![Equation](images/F000121si118.png)、`K`![Equation](images/F000121si119.png) 和 `V`![Equation](images/F000121si120.png) 参数矩阵原则上可以为每个头分别从头开始学习，但在实践中，为了减少需要学习的参数数量，注意力头共享共同的初始 `Q`![Equation](images/F000121si121.png)、`K`![Equation](images/F000121si122.png) 和 `V`![Equation](images/F000121si123.png) 矩阵，但第 `i`![Equation](images/F000121si124.png) 个头对这些参数集中的每一个都有自己独特的投影矩阵，分别是 `W[i]^(Q)`![Equation](images/F000121si125.png)、`W[i]^(K)`![Equation](images/F000121si126.png) 和 `W[i]^(V)`![Equation](images/F000121si127.png)。通过这些矩阵的乘法将共享参数映射到特定于头的数值，同时也减少了输出的维度数量。最后，使用一个共享的投影矩阵 `W^(O)`![Equation](images/F000121si128.png) 将所有头的连接输出线性投影到层表示的目标维度 `d[model]`![Equation](images/F000121si129.png)。更正式地，构成 Transformer 神经网络模型中一层的整体多头注意力模块可以写成：

`MultiHead(Q,K,V;W^(Q),W^(K),W^(V),W^(O)) = Concatenate(head[1],head[2],…,head[h])W^(O)`![Equation](images/F000121si130.png)

where:

`head[i] = Attention(QW[i]^(Q),KW[i]^(K),VW[i]^(V))`![Equation](images/F000121si131.png)

在原始 Transformer 论文中，作者在每层使用了 `h = 8`![Equation](images/F000121si132.png) 个这样的“头”（[图 11.9](#Ch012_433-471_B9780443158889000121.xhtml#f0050)）。我们也可以再次对注意力头使用掩码，在这种情况下，该模块称为 `masked multihead attention`。

### Transformer 块

在描述了多头注意力模块之后，我们终于准备好解释 Transformer 架构。Transformer 模型是深度神经网络，包含 Transformer 块的堆叠，每个块本身包含若干层。一个 Transformer 块由两个主要子层组成：

1. 一个多头注意力层
2. 一个前馈层

多头注意力层可根据需要选择性地使用掩码。原始 Transformer 论文的作者使用一个小的<|message|> 一维前馈网络，该网络应用于其输入的每个位置，完全相同，由一个 `ReLU` 层后跟一个线性层组成。总而言之，在每个 Transformer 块中，多头注意力层在处理输入方面做了大部分工作，但前馈层可以对其输出进行少量调整。另外，也可以采用全连接网络。
