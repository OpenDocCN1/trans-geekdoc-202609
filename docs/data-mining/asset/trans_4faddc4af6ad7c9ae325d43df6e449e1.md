
# 广义线性模型

在此上下文中，数据可以被视为响应变量 `y[i]` 以及组织为 `p` 维向量 `x_i` 的解释变量，`i` = 1, …, `n`。响应变量可以以不同的方式表达，从二元到分类或有序数据不等。然后定义一个模型，其中响应变量所用分布的期望值 `E[y]` 由使用参数向量 `β` 的初始线性预测 `η[i] = β^(T) x[i]` 组成，然后使用均值函数 `g^(-1)` 进行平滑、可逆且可能非线性的变换：

`μ[i] = E[y[i]] = g^(-1)(β^(T) x[i])`。

均值函数是链接函数 `g` 的逆。在广义线性建模中，所有观测值的解释变量的整个集合被排列为一个 `n × p` 矩阵 `X`，使得整个数据集的线性预测向量为 `η = X β`。底层分布的方差也可以被建模，通常作为均值的函数。不同的分布、链接函数和相应的均值函数在定义概率模型时提供了很大的灵活性；[表 14.2](#Ch015_516-570_B9780443158889000157_b.xhtml#t0015) 显示了一些示例。

### 表 14.2
链接函数、均值函数和广义线性模型中使用的分布

| 链接名称 | 链接函数 `η = β^(T) x = g(μ)` | 均值函数 `μ = g^(-1)(β^(T) x) = g^(-1)(η)` | 典型分布 |
|---|---|---|---|
| 恒等 | `η = μ` | `μ = η` | 高斯 |
| 逆 | `η = μ^(-1)` | `μ = η^(-1)` | 指数 |
| 对数 | `η = log_e μ` | `μ = exp(η)` | 泊松 |
| 对数-对数 | `η = - log(- log_e μ)` | `μ = exp(- exp(- η))` | 伯努利 |
