
# Generative Adversarial Networks

The generator takes as input a randomized vector `z`. For example, each entry in the vector could be drawn from a standard normal distribution. This can be thought of as a point in a latent space. The generator, a deep neural network, maps the given point `z` to a corresponding artificial data point `x`, hopefully, a realistic one. The discriminator, also a deep neural network, is a probabilistic classifier that takes a data point as input and predicts class probabilities, indicating the likelihood that the data point is real (i.e., from the training data) or fake (i.e., created by the generator).

## Training Procedure

The two neural networks are trained in an iterative procedure, playing out the game in which they compete. In each iteration the two networks are updated in turn. The generator is trained to create data that “fools” the discriminator; that is, the discriminator cannot tell it apart from the real data. The discriminator is trained to detect the “forgeries” made by the generator. You can think of this as the two networks trying to defeat each other, or if you prefer a more friendly metaphor, you can think of them as “teaching” each other to do better in the next iteration, which is the practical reason why this procedure succeeds. Regardless of how you think about it, the overall training process for generator `G` and discriminator `D` can be formalized as a minimax game with a value function `V(G, D)`:

$\\min\\limits\_{G}{\\max\\limits\_{D}\\mathit{V}\\mathit{G},\\mathit{D} = {E\_{x \\sim \\text{real\\ data}}\\left\\lbrack {\\log D\\left( x \\right)} \\right\\rbrack + E\_{\\overset{\\sim}{x} \\sim \\text{generator's\\ data}}\\left\\lbrack {\\log\\left( {1 - D\\left( \\overset{\\sim}{x} \\right)} \\right)} \\right\\rbrack}}.$

Here, `D(x)` is the discriminator’s predicted probability that data point `x` is a real data point from the dataset. The min player, the generator, tries to minimize this function while the discriminator tries to maximize it. In each iteration, a minibatch of data is drawn from the dataset, and a minibatch of generated data is sampled from the generator. Based on these data, the two networks are updated via minibatch stochastic gradient updates (or `Adam`, etc.) while holding the other network fixed. ## Instability Issues and WGAN

Although conceptually clear, GANs can be tricky to get to work well in practice as they are prone to several instability issues. One such issue is *mode collapse*, in which the generation focuses only on a small high-probability part of the space (e.g., one mode in a multimodal likelihood surface). For example, it might only generate “1” digits and not the other nine digits on the Mixed National Institute of Standards and Technology (MNIST) dataset. Another issue is *vanishing gradients* due to neuron saturation in the discriminator. An alternative GAN formulation, called the Wasserstein GAN (WGAN), can help improve the stability and reliability of GAN training. While the original GAN can be interpreted as optimizing the Jensen-Shannon divergence between the generated and real data, the WGAN optimizes the Wasserstein divergence, also known as the earthmover distance, which has been argued to have nicer properties for optimization in this setting. The WGAN replaces the discriminator with a “*critic*,” also denoted `D`, which produces a real-valued score instead of a class probability, where higher scores correspond to more realistic data points.
