与其使用预先确定的滤波器，卷积网络会联合学习一组卷积滤波器和一个将其作为输入的分类器，所有内容都通过反向传播一起学习。通过在神经网络的层内对图像与滤波器进行连续卷积，可以创建空间组织的隐藏层，其如前所述，可以被视为特征活动图，指示在图像中检测到给定特征类型的位置。虽然滤波器和激活函数并非专门按 [图 10.6](#Ch011_391-432_B978044315888900011X.xhtml#f0035) 所示构造，但在用自然图像训练的 CNN 的早期层中，经常观察到边缘状滤波器和纹理状滤波器。由于 CNN 中的每一层都涉及对下方层产生的特征图进行滤波，随着向上移动，任何给定神经元或特征检测器的感受野变得更大。因此，学习后，高层检测到更大的特征，这些特征通常对应于中层中的物体的较小部分，以及网络顶部附近的物体的相当大的部分。[图 10.7](#Ch011_391-432_B978044315888900011X.xhtml#f0040) 显示了每个层中一些随机神经元的最强激活的示例，使用反卷积将激活投影回图像空间。

应用于卷积网络结果的空间池化操作经常用于赋予特征被检测到的精确位置一定程度的局部空间不变性。如果池化是通过平均完成的，则可以使用卷积来实现。CNN 通常应用多层卷积，然后是池化和抽取层。通常有大约三个池化和抽取阶段。在最后一个池化和抽取层之后，得到的特征图通常馈入多层感知机。由于抽取减小了特征图的大小，因此每次操作都会减小后续活动图的大小。极深的卷积网络架构（具有超过八层）通常在应用池化和抽取操作之前多次重复卷积层。

## 实现

卷积特别适合在图形硬件上实现。由于图形硬件可以将卷积加速一个数量级或更多，相比 CPU 实现，它在训练 CNN 中发挥着重要作用。实验周转时间从数周缩短到数天，对模型开发时间产生了巨大差异。
