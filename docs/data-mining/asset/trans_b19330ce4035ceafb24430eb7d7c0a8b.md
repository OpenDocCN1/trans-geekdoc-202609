
要构建决策树，请点击 `Classify` 选项卡以访问 WEKA 的分类和回归方案。在 `Classify` 面板中，通过点击左上角的 `Choose` 按钮选择分类器，打开出现的分层菜单中的 `trees` 部分，并找到 `J48`。菜单结构代表了 WEKA 代码按模块组织的架构，而你需要选择的内容始终位于最低层级。选择后，`J48` 会出现在 `Choose` 按钮旁边的行中，并附带其默认参数值。如果你点击该行，`J48` 分类器的对象编辑器就会打开，你可以查看参数的含义并在需要时修改其值。Explorer 通常会选择合理的默认值。

选择分类器后，通过点击 `Start` 按钮来调用它。WEKA 会运行一段时间——运行期间，Explorer 右下角的小鸟会跳起来跳舞——然后生成 `J48` 的输出。

## 检查输出

输出开头是对数据集的摘要以及使用了 10 折交叉验证来评估它的说明。这是默认值，如果仔细查看 `Classify` 面板，你会看到左侧的 `Cross-validation` 框已被勾选。接下来是文本形式的剪枝决策树。这里显示的模型始终是从 `Preprocess` 面板中可用的完整数据集中生成的。

输出的下一部分给出了该树预测性能的估计。在本例中，它们是通过使用 10 折分层交叉验证获得的。除了分类错误外，评估模块还会输出其他几个性能统计指标。

`Classify` 面板还有其他测试选项：`Use training set`，通常不推荐使用；`Supplied test set`，其中你指定包含测试集的单独文件；以及 `Percentage split`，可将一定比例的数据留出用于测试。你可以通过点击 `More options` 按钮并勾选相应条目来输出每个实例的预测结果。还有其他有用的选项，例如抑制部分输出以及包含其他统计信息，如熵评估度量和成本敏感评估。

## 使用模型

`Classify` 面板左下角的小窗格，其中包含一条高亮的行，是结果的历史列表。每次运行分类器时，Explorer 都会添加一条新行。要返回到之前的结果集，请点击相应的行，该运行的输出将出现在 Classifier Output 窗格中。这使得探索不同的分类器或评估方案并重新查看结果以进行比较变得容易。

当你 `right-click` 一个条目时，会出现一个菜单，允许你在单独的窗口中查看结果或保存结果缓冲区。更重要的是，你可以将 WEKA 生成的模型以 Java 对象文件的形式保存。你可以重新加载之前保存的模型，这将在结果列表中生成一个新条目。如果现在提供测试集，你可以对该新集重新评估旧模型。

右键菜单上的多个项目允许你以各种方式可视化结果。在 Explorer 界面的顶部有一个单独的 `Visualize` 选项卡，但那是不同的；它显示的是数据集，而不是特定模型的结果。通过右键点击历史列表中的条目，你可以看到分类器错误。如果模型是树或贝叶斯网络，你可以看到其结构。你还可以查看边际曲线以及各种成本和阈值曲线，并进行成本/收益分析。

## 探索 Explorer

我们已经简要调查了 Explorer 顶部六个选项卡中的两个。总结如下，所有基本选项卡的功能如下：

1. `Preprocess`：选择数据集并以各种方式修改它。
2. `Classify`：训练执行分类或回归的学习方案并对其进行评估。
3. `Cluster`：为数据集学习聚类。
4. `Associate`：为数据学习关联规则并对其进行评估。
5. `Select attributes`：选择数据集中最相关的方面。
6. `Visualize`：查看数据的不同二维图并与其交互。

每个选项卡都提供了一系列功能。在我们迄今为止的参观中，我们几乎只触及了 `Preprocess` 和 `Classify` 面板的表面。

每个面板底部都有一个 `Status` 框和一个 `Log` 按钮。状态框显示消息，让你了解正在发生的情况。例如，如果 Explorer 正在忙于加载文件，状态框会显示出来。在此框内任意位置右键点击会弹出一个小菜单，提供两个选项：显示 WEKA 可用的内存量以及运行 Java 垃圾回收器。请注意，垃圾回收器无论如何都在后台任务中不断运行。

点击 `Log` 按钮会打开一份带时间戳的文本日志，记录 WEKA 在本次会话中执行的操作。

如前所述，当 WEKA 处于活动状态时，窗口右下角的小鸟会跳起来跳舞。× 旁边的数字显示正在运行的并发进程数。如果小鸟站着不动，它就生病了！出了问题，你可能需要重新启动 Explorer。

### 加载和过滤文件

`Preprocess` 面板顶部有用于打开文件、URL 和数据库的按钮。最初，只有文件名以 `*.arff` 结尾的文件会出现在文件浏览器中；要查看其他文件，请更改文件选择框中的 `Format` 项。

可以使用 `Preprocess` 面板中的 `Save` 按钮将数据保存为各种格式。也可以使用 `Generate` 按钮生成人工数据。除了加载和保存数据集外，`Preprocess` 面板还允许你对其进行过滤。在 `Preprocess` 面板中点击 `Choose`（靠近左上角）会显示过滤器列表。我们将描述如何使用一个简单的过滤器从数据集中删除指定的属性——换句话说，执行手动属性选择。通过使用复选框选择相关属性并按下 `Remove` 按钮，可以更轻松地实现相同的效果。尽管如此，我们仍将等效的过滤操作明确描述出来，作为示例。

`Remove` 是一个无监督属性过滤器，要查看它，必须先展开 `unsupervised` 类别，然后展开 `attribute` 类别。这将显示一个相当庞大的过滤器列表，你需要进一步向下滚动才能找到 `Remove`。选择后，它会出现在 `Choose` 按钮旁边的行中，并附带其参数值——在本例中，该行仅显示“Remove。”点击该行以调出通用对象编辑器，可用于检查和更改过滤器的属性。

要了解它，请点击 `More` 按钮。这解释了该过滤器会从数据集中移除一系列属性。它有一个选项 `attributeIndices`，指定要操作范围，另一个名为 `invertSelection` 的选项决定过滤器是选择属性还是删除它们。对象编辑器中为这两个选项都提供了框。配置对象后，常常值得一看 Explorer 设置的结果命令行表述，它显示在 `Choose` 按钮旁边。

WEKA 中的算法可能会提供有关其可处理的数据特征的信息，如果提供，则在通用对象编辑器中 `More` 下方会出现一个 `Capabilities` 按钮。点击它会显示该方法的功能信息。在本例中，它说明 `Remove` 可以处理许多属性特征，例如不同类型（名义、数值、关系等）和缺失值。它显示了 `Remove` 操作所需的最小实例数。
