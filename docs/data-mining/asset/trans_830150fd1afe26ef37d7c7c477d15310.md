
## 错误度量
下一个误差度量以光荣的名字 *相对绝对误差* 著称，它是总绝对误差，并具有同类的归一化。在这三种相对误差度量中，误差是通过预测平均值的简单预测器的误差进行归一化的。

[表 5.8](#Ch005_165-207_B9780443158889000066.xhtml#t0045) 中的最终度量是 *相关系数*，它衡量 `a`’s 和 `p`’s 之间的统计相关性。相关系数从 1（完全正相关结果）变化到 0（无相关性），再到 −1（完全负相关结果）。当然，对于合理的预测方法，不应出现负值。相关性与其它度量略有不同，因为它是尺度无关的，即如果你取一组特定的预测，如果所有预测都乘以一个常数因子而实际值保持不变，则误差不变。该因子出现在分子中 `S[PA]` 的每一项中，并在分母中 `S[P]` 的每一项中出现，从而相互抵消。（这对于相对误差数值而言并非如此，尽管进行了归一化。如果将所有预测乘以一个很大的常数，则预测值与实际值之间的差异会发生巨大变化，百分比误差也会如此。）它也不同之处在于，良好的性能会导致相关系数的大值，而由于其它方法衡量的是误差，良好的性能则以小值表示。

在任何给定情况下哪种度量是合适的，只能通过研究应用本身来确定。我们试图最小化什么？不同种类误差的成本是多少？通常很难决定。平方误差度量和根平方误差度量对大差异的权重远高于小差异，而绝对误差度量则不会。取平方根（均方根误差）只是将数值还原为与被预测量具有相同量纲。相对误差数值试图补偿输出变量的基本可预测性或不可预测性。如果它倾向于相当接近其平均值，那么你期望预测是好的，相对数值对此进行了补偿。否则，如果一种情况下的误差数值远大于另一种情况，这可能是因为第一种情况下的量本质上更具可变性，因此更难预测，而不是因为预测器更差。

幸运的是，在大多数实际情况下，最佳的数值预测方法仍然是最好的，无论使用哪种误差度量。例如，[表 5.9](#Ch005_165-207_B9780443158889000066.xhtml#t0050) 显示了使用交叉验证在给定数据集上测量的四种不同数值预测技术的結果。方法 D 根据全部五个指标都是最好的——它在每个误差度量上的值最小，相关系数最大。方法 C 在全部五个指标上都是第二好的。A 和 B 的性能存在争议。它们具有相同的相关系数；根据均方误差和相对平方误差，A 比 B 好，而对于绝对误差和相对绝对误差则相反。很可能平方运算对异常值的额外强调导致了这种情况下的差异。

## 5.10 MDL 原则
机器学习方案所学习的是从中抽取示例的领域的某种“理论”，一种可预测的理论，因为它可以生成关于该领域的新事实；换句话说，未见实例的类别。理论是一个相当宏大的术语——我们在这里仅以预测模型的意思使用它。因此理论可能包含决策树或规则集；它们不必比这更“理论化”。

在科学中有一个长期存在的传统，即在其它条件相同的情况下，简单理论优于复杂理论。这被称为 *奥卡姆剃刀*，以中世纪哲学家威廉·奥卡姆（或奥肯）命名。奥卡姆剃刀剃掉理论上的哲学胡须。其思想是，最好的科学理论是能解释所有事实的最小理论。正如爱因斯坦所说，“一切应尽可能简单，但不能更简单。” 当然，“其它条件相同”这一短语中隐藏了很多内容，很难客观地评估某个特定理论是否真的“解释”了它所基于的所有事实——这就是科学争议的全部内容。

就我们而言，在机器学习中大多数理论都会产生错误。如果所学习的是理论，那么它产生的错误就像对该理论的 *例外*。确保其它条件 *是* 相同的一种方法是坚持在判断其“简洁性”时，将例外所体现的信息作为理论的一部分包含在内。

想象一个不完美的理论，其中存在一些例外。并非所有数据都由该理论解释，但大部分是。我们所做的只是将例外附加到理论上，明确地将它们指定为例外。这个新理论更大：这是对其无法解释所有数据的能力必须支付的、相当合理的代价。然而，原始理论的简洁性——称之为 *优雅* 是否过分？——可能足以抵消它与一个庞大、繁复但更全面、更准确的理论相比，并不能完全解释一切这一事实。

例如，如果开普勒的行星运动三定律当时不能像哥白尼对托勒密本轮理论的最新改进那样很好地解释已知数据，它们具有远 less 复杂的有利条件，这将证明任何轻微的明显不准确性是合理的。开普勒非常清楚拥有紧凑理论的好处，尽管他的理论违背了他自己的审美感，因为它依赖于“椭圆”而不是纯粹的圆周运动。他用一个有力的隐喻表达了这一点：“我已清除天文学的奥革斯塔牛棚中的循环和螺旋，只留下了一车粪便。”
