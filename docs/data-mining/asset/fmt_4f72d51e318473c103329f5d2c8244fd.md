
# Hidden Markov Model

$P\\left( {O,H} \\right) = P\\left( H\_{1} \\right)\\prod\\limits\_{t = 1}^{T}{P\\left( H\_{t + 1}, \\middle| ,H\_{t} \\right)}\\prod\\limits\_{t = 1}^{T}{P\\left( O\_{t}, \\middle| ,H\_{t} \\right)}.$
![Equation](images/F000157si302.png)

Each `O[t]` is a discrete random variable with `N` possible values, and each `H[t]` is a discrete random variable with `M` possible values. [Fig. 14.11C](#Ch015_516-570_B9780443158889000157_b.xhtml#f0060) illustrates a hidden Markov model as a type of Bayesian network that is known as a “dynamic” Bayesian network because variables are replicated dynamically over the appropriate number of time steps. They are an obvious extension of first-order Markov models, and it is common to use “time-homogeneous” models where the transition matrix `P(H[t + 1] | H[t])` ![Equation](images/F000157si303.png) is the same at each time step. Define `A` to be a transition matrix whose elements encode `P(H[t + 1] = j | H[t] = i)` ![Equation](images/F000157si304.png) and `B` to be an emission matrix `B` whose elements `b[ij]` correspond to `P(O[t] = j | H[t] = i)` ![Equation](images/F000157si305.png). For the special `t = 1` the initial state probability distribution is encoded in a vector `π` with elements `π[i] = P(H[t] = i)` ![Equation](images/F000157si306.png). The complete set of parameters is `θ = {A, B, π}` ![Equation](images/F000157si307.png), a set containing two matrices and one vector. We write a particular observation sequence as a set of observations $\\overset{\\sim}{O} = \\{ O\_{1} = o\_{1},\\ldots,O\_{T} = o\_{T}\\}$ ![Equation](images/F000157si308.png).

## Key Problems

Hidden Markov models pose three key problems:

1. Compute `P(~O; θ)` ![Equation](images/F000157si309.png), the probability of a sequence under the model with parameters `θ` ![Equation](images/F000157si310.png).
2. Find the most probable explanation—the best sequence of states `H* = {H[1] = h[1], …, H[T] = h[T]}` ![Equation](images/F000157si311.png) that explains an observation.
3. Find the best parameters `θ` ![Equation](images/F000157si312.png) for the model given a data set of observed sequences.
