
# 子群公平性

*子群公平性* 是由计算机科学家/理论家 Michael Kearns 及同事提出的一种公平性定义，旨在解决公平性操纵。假设存在多个受保护属性，即 `s` 是向量值。令 `g(s)` 为一个指示函数，用于在受保护群体的交集中选择一个子群，其中当个体属于群体 `g` 时 `g(s) = 1`，否则为 0。假设我们有一组此类群体指示符 `G`，我们希望对其确保公平性 Kearns 等人提供了一个基于平价的版本（`statistical parity subgroup fairness`）和一个类似定义但侧重于假阳性率的版本（`false positive subgroup fairness`）。在统计平价（SP）版本中，每个子群 `g` 的正类（`y = 1`）概率必须与整个总体中的整体正类概率相似。一个分类器如果对每个 `g ∈ G` 都满足 `γ`- SP 子群公平性，

```
|P(ŷ = 1) − P(ŷ = 1 | g(s) = 1)| × α[g] ≤ γ.
```

这里有一个缩放因子 `α[g] = P(g(s) = 1)`，它根据各群体在总体中的比例对每个群体进行加权。换句话说，根据该定义，大型子群被视为重要，而小型子群被视为不重要且可能被忽略（因为该指标由所有子群上该方程的最大值决定）。这是为了获得可证明的泛化保证，确保该指标的值能够从训练集推广到总体。其背后的想法是，由于小型子群的数据量不多，其计数会存在噪声，但对其进行降权意味着这些噪声计数不会破坏该指标的估计。

另一方面，这种方法的缺点是它明确忽视了少数子群。从交叉性理论的角度来看，这是有问题的，因为少数群体经常最受种族主义和其他压迫体系的伤害。请注意，子群公平性是出于防止公平性操纵/子集针对而提出的，而不是交叉性。另一种公平性定义，`differential fairness`，由本书作者之一（Foulds）设计，其特定意图是成为一种交叉性的公平性定义。差分公平避免了少数群体降权项，并使用一种类似于 80% 规则的基于比率的表述。机制 `M(x)` 如果对于所有 `θ ∈ Θ` 且 `x ∼ θ` 以及 `y ∈ Range(M)`，被称为相对于 (`A`, `Θ`) 是 `ϵ`-差分公平的（DF），
