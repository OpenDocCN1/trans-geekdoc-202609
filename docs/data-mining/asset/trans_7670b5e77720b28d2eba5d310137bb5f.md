
在每个时间步 `t`，输入门 `i[t] = sigmoid(W[i] x[t] + U[i] h[t - 1] + b[i])` 用于确定由 `s[t] = tanh(W[c] x[t] + U[c] h[t - 1] + b[c])` 给出的潜在输入是否足够重要以被放入记忆单元 `c[t]`。`s[t]` 本身的计算是当前输入值 `x[t]` 与前一个隐藏单元向量 `h[t - 1]` 的线性组合，使用权重矩阵 `W[c]` 和 `U[c]` 以及偏置向量 `b[c]`。遗忘门 `f[t]` 允许使用 `f[t] = sigmoid(W[f] x[t] + U[f] h[t - 1] + b[f])` 来擦除记忆单元的内容，涉及基于 `W[f]` 和 `U[f]` 矩阵的类似线性输入，外加偏置 `b[f]`。输出门 `o[t]` 确定 `y[t]`，即经过激活函数转换后的记忆单元内容，是否应置入隐藏单元 `h[t]`。它们通常由一个 Sigmoid 激活函数控制，`o[t] = sigmoid(W[o] x[t] + U[o] h[t - 1] + b[o])` 将其应用于当前输入值 `x[t]` 与前一个隐藏单元向量 `h[t - 1]` 的线性组合，使用权重矩阵 `W[o]` 和 `U[o]` 以及偏置向量 `b[o]`。
