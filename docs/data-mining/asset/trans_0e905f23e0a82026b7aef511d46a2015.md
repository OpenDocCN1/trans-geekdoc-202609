
没有关于文本挖掘涵盖范围的真正共识；广义解释，所有自然语言处理都属于文本挖掘的范畴。自引入以来，条件随机场一直是且仍然是该领域的主导工具之一。文中提到的从非结构化电子邮件中提取会议信息的问题，在[第13章](#Ch014_485-514_B9780443158889000145.xhtml#Ch014_485-514_B9780443158889000145)，“概率方法：基础”，只是其中一个例子。许多其他信息抽取任务也有类似的条件随机场表述。

## 15.6 网络挖掘
万维网是海量文本的存储库。几乎所有文本都与普通的“纯文本”不同，因为它包含明确的结构化标记。有些标记是内部的，表示文档结构或格式；其他标记是外部的，定义了文档之间的显式超文本链接。这两种信息来源为挖掘网络文档提供了额外的优势。*网络挖掘*与文本挖掘类似，但利用了这些额外信息，并经常通过利用主题目录和其他网络信息来改善结果。

考虑内部标记。包含关系数据的互联网资源——电话目录、产品目录等等——使用超文本标记语言（`HTML`）格式化命令，以清晰地向网络用户呈现其包含的信息。然而，以自动方式从此类资源中提取数据是相当困难的。为此，软件系统使用称为*包装器*的简单解析模块来分析页面结构并提取所需信息。如果包装器是手工编码的，而它们通常是这样，那么这是一种微不足道的网络挖掘类型，因为它依赖于页面具有固定的、预定的结构，可以从中算法地提取信息。但页面很少遵守规则。它们的结构各不相同；网站在不断演变。对人类读者来说微不足道的错误会使自动提取程序完全出错。当变化发生时，手动调整包装器可能是一场噩梦，需要弄清楚现有代码并以不会在其他地方造成破坏的方式修补它。

### 包装器归纳
引入*包装器归纳*，从示例中自动学习包装器。输入是一组训练页面以及代表从每个页面派生的信息的元组。输出是一组通过解析页面来提取元组的规则。例如，规则可能会寻找网页设计者用来突出关键信息项目的某些 HTML 分隔符——段落边界（`<p>`）、列表条目（`<li>`）或粗体（`<b>`）——并学习实体呈现的顺序。这可以通过迭代分隔符的整体选择来实现，在遇到一致的包装器时停止。然后识别将仅依赖于最少的线索，提供一些抵御输入中无关文本和标记的防御。或者可以遵循爱比克泰德在[第5.10节](#Ch005_165-207_B9780443158889000066.xhtml#s0115)末尾的建议，寻求使用多个线索来抵御偶然变化的稳健包装器。自动包装器归纳的巨大优势是，当错误由风格变体引起时，只需将这些变体添加到训练数据中并重新归纳一个考虑它们的新的包装器即可。包装器归纳减少了小变化发生时的识别问题，并且在结构发生根本变化时使生成新的提取规则集变得容易得多。

### 页面排名
网络的一个问题是其中很大一部分是垃圾。为了区分精华与糟粕，Google 的创始人引入了一种名为 `PageRank` 的指标；其他搜索引擎也在各种形式下使用它，并在许多其他网络挖掘应用中使用。它试图衡量网页或网站的声望，其中*声望*，根据词典定义，是“通过成功或影响力获得的高地位”。希望这是确定权威的一种好方法，权威被定义为“被接受的专家信息或建议来源”。

关键是超链接形式的外部标记。在网络化社区中，人们用链接奖励成功。如果你链接到我的页面，很可能是因为你认为它有用且信息丰富——这是一个成功的网页。如果很多人链接到它，就表明它有声望；我的页面成功且有影响力。看看[图15.1](#Ch016_571-615_B9780443158889000169.xhtml#f0010)，它显示了网络的一小部分，包括页面之间的链接。你认为哪些最具权威性？页面 **F** 有五个入站链接，这表明有五个人认为值得链接到它，因此这个页面比其他页面更具权威性的可能性很大。**B** 是第二好的，有四个链接。

![图15.1 一个错综复杂的网络。](`images/F000169f15-01-9780443158889.jpg`)

图15.1 一个错综复杂的网络。

仅仅计数链接是一种粗糙的衡量方法。有些网页有数千个出站链接，而有些只有一两个。较少见的链接更具区分性，应该比其他链接更重要。来自你的页面到我的链接如果你的页面出站链接很少，则赋予更多的声望。在[图15.1](#Ch016_571-615_B9780443158889000169.xhtml#f0010)中，页面 **A** 发出的许多链接意味着每个链接的权重都更低，仅仅因为 **A** 是一个 prolific 的链接者。从 **F** 的角度来看，来自 **D** 和 **E** 的链接可能比来自 **A** 的链接更有价值。还有另一个因素；如果链接来自一个声望很高的页面，链接更有价值。来自 **B** 到 **F** 的链接可能比进入 **F** 的其他链接更好，因为 **B** 更具声望。 admittedly 这个因素涉及某种循环性，在没有进一步分析的情况下，不清楚它是否能奏效。但确实可以。

以下是细节。我们定义页面的 `PageRank` 为介于 0 和 1 之间的数字，衡量其声望。进入该页面的每个链接都会为其 `PageRank` 做出贡献。它贡献的数量是链接页面的 `PageRank` 除以其出站链接数。任何页面的 `PageRank` 通过对所有进入它的链接求和该数量来计算。[图15.1](#Ch016_571-615_B9780443158889000169.xhtml#f0010)中 **D** 的值是通过将 **A** 的值的一五分之一（因为它有五个出站链接）加到 **C** 值的一半来计算的。

一种简单的迭代方法用于解决计算表面上的循环性。先为每个页面随机分配一个初始值。然后通过对它的入站链接求和前面描述的适当数量来重新计算每个页面的 `PageRank`。如果初始值被视为 `PageRank` 真实值的近似值，则新值是更好的近似值。继续进行，生成第三个近似值、第四个近似值，等等。在每个阶段重新计算网络中每个页面的 `PageRank`。当对于每个页面，下一次迭代几乎给出与前一次相同的 `PageRank` 时停止。

在后面讨论的两个修改下，此迭代保证收敛，而且相当快。虽然精确细节被保密笼罩，但今天的搜索引擎可能寻求最终值的准确度在 `10^(−9)` 和 `10^(−12)` 之间。早期的一项实验报告了对比今天小得多的网络版本进行 50 次迭代，然后细节变得商业化；现在需要多几倍的迭代。据认为 Google 运行程序数天来对整个网络执行 `PageRank` 计算，并且该操作是，或至少曾经是，每隔几周执行一次。
