
# 使用 t 检验比较均值

为判断均值 $\\overline{x}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si26.png) 和 $\\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si27.png)，每个均值都是相同数量 `k` 个样本的平均值，是否相同，我们考虑对应观测值之间的差异 `di`，`d[i] = x[i] - y[i]`<mml:math><mml:msub><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:msub><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>&#8722;</mml:mo><mml:msub><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000066si28.png)。这是合理的，因为观测值是配对的。该差异的均值只是两个均值之间的差异，$\\overline{d} = \\overline{x} - \\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>=</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>&#8722;</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si29.png)，并且与均值本身一样，它服从自由度为 `k-1` 的 Student 分布。如果均值相同，则差异为零（这称为 *零假设*）；如果它们显著不同，则差异将显著不同于零。因此对于给定的置信水平，我们将检查实际差异是否超过置信限。

首先，将差异化为零均值、单位方差的变量，称为 `t`-statistic：

$t = \\frac{\\overline{d}}{\\sqrt{\\left. \\sigma\_{d}^{2}\\slash k \\right.}},$<mml:math><mml:mi>t</mml:mi><mml:mo>=</mml:mo><mml:mfrac><mml:mrow><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:mrow><mml:mrow><mml:msqrt><mml:mrow><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mo>&#8725;</mml:mo><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:mrow></mml:msqrt></mml:mrow></mml:mfrac><mml:mo>,</mml:mo></mml:math>

其中 `σ[d]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si31.png) 是差异样本的方差。然后，决定置信水平——实践中通常使用 5% 或 1%。由此置信限 `z` 使用 [表 5.2](#Ch005_165-207_B9780443158889000066.xhtml#t0015) 确定，如果 `k` 为 10；如果不是，则使用针对所讨论 `k` 值的 Student 分布置信表。双尾检验是合适的，因为我们事先不知道 `x` 的均值是否可能大于 `y` 的均值，反之亦然；因此对于 1% 检验，我们使用 [表 5.2](#Ch005_165-207_B9780443158889000066.xhtml#t0015) 中对应 0.5% 的值。如果根据上述公式得到的 `t` 值大于 `z`，或小于 `-z`，我们拒绝均值相同的零假设，并得出结论认为在该域、该数据集大小下，两种学习方法之间确实存在显著差异。

对此过程值得提出两个观察。第一个是技术性的：如果观测值不是配对的会怎样？也就是说，如果由于某种原因，我们无法在相同的数据集上评估每种学习方案的误差会怎样？如果每种方案的数据集数量甚至不相同会怎样？这些情况可能出现，如果其他人评估了其中一种方案并发布了针对特定域和数据集大小的若干不同估计——也许只是它们的均值和方差——而我们希望将其与另一种学习方案进行比较。然后有必要使用常规的非配对 `t`-test。不是取差异的均值，$\\overline{d}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si32.png)，我们使用均值的差异，$\\overline{x} - \\overline{y}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover><mml:mo>&#8722;</mml:mo><mml:mover accent="true"><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si33.png)。当然，这是一样的；差异的均值 *是* 均值的差异。但差异 $\\overline{d}$<mml:math><mml:mover accent="true"><mml:mrow><mml:mi>d</mml:mi></mml:mrow><mml:mo>&#175;</mml:mo></mml:mover></mml:math>![Equation](images/F000066si34.png) 的方差 *不* 相同。如果样本 `x[1]`、`x[2]`、…、`x[k]` 的方差为 `σ[x]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si35.png) 而样本 `y[1]`、`y[2]`、…、`y[l]`<mml:math><mml:msub><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mi mathvariant="script">l</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000066si36.png) 的方差为 `σ[y]²`<mml:math><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000066si37.png)，

$\\frac{\\sigma\_{x}^{2}}{k} + \\frac{\\sigma\_{y}^{2}}{\\mathcal{l}}.$<mml:math><mml:mfrac><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:mfrac><mml:mo>+</mml:mo><mml:mfrac><mml:mrow><mml:msubsup><mml:mrow><mml:mi>&#963;</mml:mi></mml:mrow><mml:mrow><mml:mi>y</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mrow><mml:mi mathvariant="script">l</mml:mi></mml:mrow></mml:mfrac><mml:mo>.</mml:mo></mml:math>

是均值差异方差的一个良好估计。应将该方差（或更确切地说其平方根）用作前面给出的 `t`-statistic 的分母。查阅 Student 置信表所需的自由度，应保守地取为两个样本自由度的最小值。本质上，知道观测值是配对的，允许使用方差的更好估计，从而产生更紧的置信界限。
