
我们一直在研究的决策树和规则的方法最自然地适用于名义属性。它们可以通过将数值测试直接纳入决策树或规则归纳方案，或通过预先将数值属性离散化为名义属性来扩展到数值属性。我们将在[第6章](#Ch006_209-259_B9780443158889000078.xhtml#Ch006_209-259_B9780443158889000078)，“准备：数据预处理和探索性数据分析，”以及[附录 C](#FigC1_655-685_B9780443158889000236.xhtml#FigC1_655-685_B9780443158889000236)，“树和规则的实现细节。”中看到如何做到这一点。然而，还有一些方法最自然地适用于数值属性，即在[第3.2节](#Ch003_67-89_B9780443158889000042.xhtml#s0015)中介绍的线性模型；我们将在此处更详细地研究它们。它们可以构成更复杂学习方法的组件或起点，我们稍后将对其进行研究。

### 数值预测：线性回归

当结果或类别为数值，且所有属性均为数值时，线性回归是一个自然的考虑技术。这是统计学中的一种常用方法。其思想是将类别表示为属性的线性组合，并带有预先确定的权重：

`x = w[0] + w[1]a[1] + w[2]a[2] + … + w[k]a[k]`

![Equation](images/F000054si61.png)

其中 `x` 是类别；`a[1]`、`a[2]`、…、`a[k]` 是属性值；`w[0]`、`w[1]`、…、`w[k]` 是权重。

权重是从训练数据中计算得出的。这里的符号有点繁重，因为我们需要一种方法来表示每个训练实例的属性值。第一个实例将有一个类别，例如 `x^{(1)}`，以及属性值 `a[1]^{(1)}`、`a[2]^{(1)}`、…、`a[k]^{(1)}`，其中上标表示它是第一个示例。此外，从符号上讲，假设一个额外的属性 `a[0]` 很方便，其值始终为 1。

第一个实例类别的预测值可以写为

`w_0 a_0^{(1)} + w_1 a_1^{(1)} + w_2 a_2^{(1)} + … + w_k a_k^{(1)} = sum_{j = 0}^{k} w_j a_j^{(1)} .`

![Equation](images/F000054si65.png)

这是类别的预测值，而非实际值。我们感兴趣的是预测值与实际值之间的差异。最小二乘线性回归的方法是选择系数 `w[j]`——共有 `k+1` 个——以最小化所有训练实例上这些差异的平方和。假设有 `n` 个训练实例；用上标 (`i`) 表示第 `i` 个实例。那么差异的平方和为

`sum_{i = 1}^{n} ( x^{(i)} - sum_{j = 0}^{k} w_j a_j^{(i)} )^2 ,`

![Equation](images/F000054si67.png)

其中括号内的表达式是第 `i` 个实例的实际类别与其预测类别之间的差异。这个平方和是我们必须通过适当选择系数来最小化的。

所有这些开始看起来相当令人生畏。然而，如果你具备适当的数学背景，最小化技术是直接的。足以说，给定足够的示例——粗略地说，示例多于属性——选择权重以最小化平方差之和其实并不困难。它确实涉及矩阵求逆运算，但这作为预包装软件即可轻松获得。
