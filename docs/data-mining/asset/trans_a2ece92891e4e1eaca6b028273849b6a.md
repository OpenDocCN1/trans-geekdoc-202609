### 多类逻辑回归

二元逻辑回归在 [第 4.6 节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0095) 中引入。现在考虑一个 *多类分类问题*，其中类别值被编码为随机变量 `y` ∈ {1,…, `N`}![Equation](images/F000157si227.png) 的实例，而特征向量如前所述是变量 `x` 的实例。假设类别的顺序没有意义。

可以使用此参数形式创建简单的线性概率分类器：

$p(y \\mid \\mathbf{x}) = \\frac{\\exp\\left( \\sum\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right)}{\\sum\\limits\_{y}{\\exp\\left( \\sum\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right)}} = \\frac{1}{Z(\\mathbf{x})}\\exp\\left( \\sum\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right),$ (14.7)
