这类网络可以按如下方式训练：首先使用观测数据训练一个两层玻尔兹曼机。然后在上方添加一层，并将其权重初始化为下方层学习到的权重的转置。为了训练下一层，计算在下方层给定条件下上方层的条件分布，并要么生成一个样本，要么使用 `sigmoid` 函数的激活值将训练数据的每个示例转换为第一隐藏层表示。 `RBM` 的性质可以进一步利用来获得在上方层给定条件下下方层的条件分布，并且该方向上条件模型的参数可以固定。一旦第二个玻尔兹曼机训练完成，模型的形式为（[公式 D.1](#FigD1_687-703_B9780443158889000248.xhtml#eqn1)），并且将数据转换、将顶层玻尔兹曼机转换为条件模型、添加一层以及训练顶层玻尔兹曼机的过程可以根据需要重复。

如果上方层的单元数量不同，则无法使用下方矩阵的转置进行初始化，并且某些理论保证不再适用。然而，实践中该过程以随机初始化而闻名效果良好。
