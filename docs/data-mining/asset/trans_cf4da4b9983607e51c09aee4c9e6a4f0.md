
构建用于学习 `CNN` 的软件以便探索替代架构也可能具有挑战性。尽管早期的 `GPU` 实现难以扩展，但新工具既允许快速计算，又提供灵活的高级编程原语。本章末尾讨论了一些这些工具；其中许多工具可使大型网络的梯度计算和 `backpropagation` 算法几乎完全自动化。

[图 10.9](#Ch011_391-432_B978044315888900011X.xhtml#f0050) 中的编码器激活函数 `act()` 和输出激活函数 `out()` 都可以定义为 `sigmoid` 函数。可以证明，在没有激活函数的情况下，`h`^((`i`)) = `a`^((`i`))，所得到的“线性自动编码器”将在假设平方误差损失函数并使用均值中心化对数据进行归一化的情况下找到与 `principal component analysis` 相同的子空间。可以证明该自动编码器在最优意义上是最佳的，即任何具有非线性激活函数的模型都需要具有更多参数的权重矩阵才能达到相同的重构误差。已知即使使用 `sigmoid` 等非线性激活函数，优化也会趋向于网络在 `sigmoid` 的线性区域运行的解，从而复制 `principal component analysis` 的行为。
