
To perform knowledge distillation we interpret the original, complicated model as a “teacher model” and use it to train a smaller, simpler “student model.” The key insight to doing this is that the teacher model improves over the hard-assigned class labels in the training set by producing class probabilities for them, thus distinguishing which instances are clear-cut members of a particular class and which are rather ambiguous borderline cases. Instead of training the student model directly on the training data, we train it on the training data but with the teacher model’s class probabilities, called “`soft targets`,” used in place of the class labels. The student model thus has access to the “knowledge” of the teacher model about the instances’ likely class labels. We can achieve this by minimizing the cross-entropy loss based on the teacher model’s class probabilities. However, if the teacher’s class probabilities are all close to zero or close to one, we will not have gained much by using the teacher’s predictions instead of the original labels. ## 11.7 Deep Reinforcement Learning

We have focused in this chapter on supervised learning, where a “teacher” has labeled the instances used to train the model. Without a “teacher” to keep the system continually informed, learning becomes much more challenging. Consider, for example, the general AI problem, which is often framed in terms of an `intelligent agent` (e.g., a robot vacuum cleaner). The agent is in an environment, which it perceives using sensors, makes decisions, and acts in the word through its actuators (e.g., wheels). The agent has a task to perform (e.g., cleaning the room), and it must react to the environment and the results of its actions to achieve it. In `reinforcement learning`, we suppose that the agent receives a rather limited feedback signal in terms of rewards and punishments, letting it know if it did the task well or not. This `reward signal` may be given after each action the agent takes, or only at the end of the scenario. The agent aims to act so that it achieves the highest possible cumulative amount of reward and the least amount of punishment (which can be viewed as negative reward).

While using deep learning is only one possible approach to reinforcement learning, the field of “`deep reinforcement learning`” at the intersection of these two areas has proven successful and continues to be promising for several reasons. `DNNs` can process complicated data such as input from sensors (e.g., cameras or radar). More importantly, `DNNs` require a lot of data, and simulated reinforcement learning environments can provide an endless stream of such data, facilitating the training of powerful and accurate models. Although rising to prominence in the 2010s, neural network approaches to reinforcement learning were successful as early as 1995 when such a system, TD-Gammon, was able to excel at the game of backgammon. More recently, the rising tide of deep learning has lifted all boats, including reinforcement learning, for many of the same reasons, including increased computational power and improved deep learning architectures.

Several important success stories of deep reinforcement learning came out of DeepMind, now known as Google DeepMind, a British tech startup company which focused on this technology. DeepMind researchers developed a methodology called “`deep Q-learning`,” which integrated deep learning into the `Q-learning` algorithm, a “`model-free`” reinforcement learning algorithm that avoids learning a “`transition model`” of the environment. They succeeded in developing `deep Q-learning networks` (`DQNs`) that could learn to play many Atari games, from scratch, given only the raw pixel values as input. Their systems used `CNNs` and were trained by playing the games. They could outperform expert human players and special-purpose ML systems in many of the games.
