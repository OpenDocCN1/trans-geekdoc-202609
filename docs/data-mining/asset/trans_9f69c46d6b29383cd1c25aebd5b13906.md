
更正式地，设 `M(D)` 是一个隐私机制，用于对数据库 `D` 上的查询返回答案。那么 `M(D)` 是 `ϵ`-差分隐私的，如果对于所有仅在单个元素上不同的数据集对 `D[1]` 和 `D[2]` 以及所有 `S` ⊆ `Range(M)`，

`Pr(M(D[1]) ∈ S) ≤ e^(ϵ) × Pr(M(D[2]) ∈ S)`. (7.1)

换句话说，如果数据集中一个实例被更改，算法的任何输出的概率几乎相同，仅相差一个小的乘性常数 `e^(ϵ)`。这里，`ϵ` 是机制差分隐私的程度（越低越好）。

## 实现差分隐私的技术

差分隐私通常通过向查询的答案注入随机噪声来实现，噪声量的校准确保几乎无法了解任何一个人的数据。例如，假设我们有兴趣了解从事令人尴尬或非法活动的比例。你肯定能想到几个。挑你最喜欢的一个！出于没有任何特别的原因，我们将把这种活动称为 `XXX`。

如果我们的研究参与者要提供他们的数据，他们希望得到保证，研究不会透露他们是否从事 `XXX`。为了帮助保护他们的秘密，参与者被要求抛硬币。如果硬币出现反面，他们将如实回答问题，“是”或“否”。如果硬币出现正面，他们将改为随机回答，通过再次抛硬币并在出现正面时回答“是”，出现反面时回答“否”。这给了他们合理的否认性，因为“是”的回答可能来自硬币抛掷，而不是来自他们的真实回答。如果硬币两次都出现正面，参与者将无论其数据如何都回答“是”，这种情况发生的概率为四分之一。然后我们统计整个群体中“是”回答的数量。
