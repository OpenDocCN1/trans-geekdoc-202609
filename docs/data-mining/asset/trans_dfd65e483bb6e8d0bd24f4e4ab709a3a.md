
# 鲁棒回归与异常检测

常用于说明鲁棒回归的数据集是一张图表，显示了 1950 年至 1973 年间比利时发出的国际电话呼叫情况，见于 [图 6.7](#Ch006_209-259_B9780443158889000078.xhtml#f0040)。该数据取自经济部出版的《比利时统计调查》。图表似乎显示出多年来的上升趋势，但 1964 年至 1969 年存在一组异常点。事实证明，在此期间结果被错误地记录为通话的总 *分钟* 数。1963 年和 1970 年也部分受影响。此错误导致 Y 方向上出现大量异常值。

![图 6.7 比利时国际电话呼叫次数，1950–1973。](images/F000078f06-07-9780443158889.jpg)
图 6.7 比利时国际电话呼叫次数，1950–1973。

不出所料，通常的最小二乘回归线受此异常数据严重影响。然而，最小 *中位数* 平方线却几乎未受扰动。该线具有简单而自然的解释。几何上，它对应于寻找覆盖一半观测值的最窄条带，其中条带的厚度在垂直方向上测量；该条带在 [图 6.7](#Ch006_209-259_B9780443158889000078.xhtml#f0040) 中以灰色标记。最小中位数平方线位于该带的中心。值得注意的是，这一概念往往比正常的最小二乘回归定义更容易解释和可视化。不幸的是，中位数型回归技术存在一个严重的缺点——它们会产生高计算成本，这通常使其在实际问题中不可行。

## 检测异常

任何形式的自动检测明显错误数据的严重问题在于婴儿也随洗澡水一起倒掉。除非咨询人工专家，否则无法判断某个实例是否真的存在错误，还是只是不符合所应用的模型类型。在统计回归中，可视化有所帮助。通常，即使是非专家也能直观地看出拟合了错误类型的曲线——例如，将直线拟合到位于抛物线上的数据；例如，[图 6.7](#Ch006_209-259_B9780443158889000078.xhtml#f0040) 中的异常值在视觉上非常突出。但大多数分类问题无法如此轻松地可视化——“模型类型”的概念比回归线更微妙。尽管已知在大多数标准数据集中，通过丢弃不符合决策树模型的事例可以获得良好的结果，但在处理特定新数据集时，这未必令人安心。仍然会怀疑，也许新数据集根本不适合决策树建模。

一种尝试过的解决方案是使用几种不同的学习方案——例如决策树、最邻近学习器和线性判别函数——来过滤数据。一种保守的方法是要求所有三种方案都无法正确分类某个实例后，才将其视为错误并从数据中移除。在某些情况下，以这种方式过滤数据并将过滤后的数据作为最终学习方案的输入，比直接使用三种学习方案并让它们投票决定结果的性能更好。在 *过滤后* 的数据上训练全部三种方案并让它们投票可以获得更好的结果。然而，投票技术存在危险。某些学习算法更适合特定类型的数据，最合适的方案可能只是被投票击败！我们将在 [第 8 章](#Ch009_323-345_B9780443158889000091.xhtml#Ch009_323-345_B9780443158889000091)，“集成学习。”中研究一种更微妙的组合不同分类器输出的方法，称为 *堆叠*。教训，如往常一样，是要了解你的数据并从许多不同角度审视它。

过滤方法的一个可能危险是，它们可能只是牺牲了特定类别（或一组类别）的实例来提高剩余类别的准确性。虽然没有一般的方法可以防范这种情况，但在实践中尚未发现这是常见问题。

最后，再次值得注意的是，自动过滤是获取正确数据的糟糕替代品。如果这样做过于耗时和昂贵而不可行，人类检查可以仅限于被过滤器识别为可疑的那些实例。

## 一类学习

在大多数分类问题中，训练数据在预测时可能出现的所有类别都可用，学习算法使用不同类别的数据来确定区分它们的决策边界。然而，一些问题在训练时仅表现出单一类别的实例，而在预测时具有未知类别标签的新实例可能属于该目标类别，也可能属于训练期间不可用的新类别。然后，可能存在两种不同的预测：*目标*，表示实例属于训练期间经历的类别，以及 *未知*，表示实例似乎不属于该类别。这种类型的学习问题被称为一类分类。

在许多情况下，一类问题可以重新表述为二类问题，因为可以用于训练的其他类别的数据存在。然而，存在真正的一类应用，在训练期间使用负数据是不可能或不合适的。例如，考虑密码强化，一种生物识别系统，通过不仅要求输入正确的密码，还要求以正确的节奏输入来加强计算机登录过程。这是一个一类问题；只有一个用户需要验证，并且在训练期间只有该用户的数据可用——我们不能要求其他人提供数据，而不向他们提供密码！

即使在训练时有多个类别的实例可用，专注于所考虑的目标类别可能仍然是最好的——例如，如果在预测时可能出现与训练期间所有可用类别都不同的新类别。以打字节奏场景为例，假设我们要在文本不固定的情况下识别打字员——当前打字员需要根据其在自由文本块上的节奏模式验证其自称身份。这项任务与区分一个用户和一组其他用户根本不同，因为我们必须准备拒绝系统从未见过的攻击者。

## 异常值检测

一类分类通常称为异常值（或新颖性）检测，因为学习算法被用来区分相对于训练数据分布而言似乎正常和异常的数据。前面本节中我们谈到通过用绝对值度量代替通常的平方距离度量使回归更鲁棒，以及通过使用几种不同的学习方案来尝试检测异常。
