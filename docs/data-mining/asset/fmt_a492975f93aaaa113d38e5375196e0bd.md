## 迭代终止与边际似然

Now consider how to terminate the iteration. The `k`-means algorithm stops when the classes of the instances do not change from one iteration to the next—a “fixed point” has been reached. In the `EM` algorithm things are not quite so easy; the algorithm converges toward a fixed point but never actually gets there. We can see how close it is getting by calculating the overall (marginal) likelihood that the data came from this model, given the values for the five parameters.
