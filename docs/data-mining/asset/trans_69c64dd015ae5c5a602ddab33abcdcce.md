
# 二次损失函数

1 − 2`p`[`i`] + ∑[`j`] `p`[`j`]²,<mml:math><mml:mn>1</mml:mn><mml:mo>&#8722;</mml:mo><mml:mn>2</mml:mn><mml:msub><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub><mml:mo>+</mml:mo><mml:msub><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>j</mml:mi></mml:mrow></mml:msub><mml:mrow><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>j</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msubsup></mml:mrow><mml:mo>,</mml:mo></mml:math>

其中 `i` 是正确类别。当测试集包含多个实例时，损失函数在它们之上求和。

这是一个有趣的理论事实，如果你试图在实际类别以概率方式生成的情况下最小化二次损失函数的值，最佳策略是为 `p` 向量选择不同结果的实际概率，也就是 `p[i]` = `P`(class = `i`)。如果真实概率已知，它们将是 `p` 的最佳值。如果未知，力求最小化二次损失函数的系统将被鼓励使用其对 `P`(class = `i`) 的最佳估计作为 `p[i]` 的值。

这很容易看出。用 `p`[1]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mn>1</mml:mn></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![方程](images/F000066si46.png), `p`[2]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![方程](images/F000066si47.png), …, `p`[`k`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![方程](images/F000066si48.png) 表示真实概率，使得 `p`[`i`]*<mml:math><mml:msubsup><mml:mrow><mml:mi>p</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow><mml:mrow><mml:mo>\*</mml:mo></mml:mrow></mml:msubsup></mml:math>![方程](images/F000066si49.png) = `P`(class = `i`)。二次损失函数在测试实例上的期望值可以重写如下：

```
$\\begin{array}{l} {E\\left\\lbrack \\sum\_{j}{(p\_{j} - a\_{j})}^{2} \\right\\rbrack = \\sum\_{j}{(E\\lbrack p\_{j}^{2}\\rbrack - 2E\\lbrack p\_{j}a\_{j}\\rbrack + E\\lbrack a\_{j}^{2}\\rbrack)}} \\\\ {= \\sum\_{j}{(p\_{j}^{2} - 2p\_{j}p\_{j}^{\*} + p\_{j}^{\*})} = \\sum\_{j}{({(p\_{j} - p\_{j}^{\*})}^{2} + p\_{j}^{\*}(1 - p\_{j}^{\*})).}} \\\\ \\end{array}$
```
