
# 机器学习中的差分隐私

假设我们希望实现差分隐私，以确保机器学习算法的参数可以在不冒逆向工程数据集中任何个人数据的风险的情况下发布。通常无法计算整个机器学习算法的敏感度，因此我们通常不能直接将 `Laplace mechanism` 或 `Gaussian mechanism` 应用于学习算法的输出。此外，这些算法通常处理的是单个数据点，而不是聚合数据，因此我们不能仅仅提前对数据进行隐私化处理。相反，对机器学习算法进行隐私化的典型策略是在机器学习算法的每次迭代中添加噪声，例如在小批量梯度下降（或 `Adam` 等）更新中。通常，我们计算每次迭代中各个更新的敏感度，然后通过添加适当的噪声对其进行隐私化处理。利用组合定理，我们为每次迭代 `i`<mml:math><mml:mi>i</mml:mi></mml:math>![Equation](images/F00008Xsi86.png) 分配一个每次迭代的隐私预算 `ϵ[i]`<mml:math><mml:msub><mml:mrow><mml:mi>&#1013;</mml:mi></mml:mrow><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F00008Xsi85.png)，以使整个学习算法为 `ϵ[overall]`<mml:math><mml:msub><mml:mrow><mml:mi>&#1013;</mml:mi></mml:mrow><mml:mrow><mml:mi mathvariant="italic">overall</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F00008Xsi87.png)\-差分隐私。

这种方法的经典示例是由 Martin Abadi 和同事于 2016 年提出的用于差分隐私深度学习的差分隐私随机梯度下降（`SGD`）算法（[图 7.2](#Ch007_261-315_B978044315888900008X.xhtml#f0015)）。该算法一次处理数据子集（小批量），通过每个小批量的估计梯度步来更新参数。该方法通过首先裁剪这些梯度以控制 `l2`<mml:math><mml:msub><mml:mrow><mml:mi>l</mml:mi></mml:mrow><mml:mrow><mml:mn>2</mml:mn></mml:mrow></mml:msub></mml:math>![Equation](images/F00008Xsi88.png)\-敏感度，然后通过 `Gaussian mechanism` 对裁剪后的梯度添加噪声来实现差分隐私。作者提出了一种新颖而复杂的在组合下跟踪隐私预算的方法，称为 `Moments Accountant`，这使他们能够更好地利用给定的隐私预算，从而减少为实现目标差分隐私程度而必须添加的噪声量。

## 联邦学习

正如我们所讨论的，公司想要获取我们的数据从而引发隐私担忧的一个关键原因是，他们希望在来自许多人的用户数据上训练机器学习模型。但如果可以在不将我们的数据发送到服务器的情况下进行训练会怎样？一种名为 `federated learning` 的方法旨在实现这一点。在联邦学习中，用户的数据保留在其本地设备上，例如智能手机或笔记本电脑，并且永远不会直接发送到组织的数据库或机器学习服务器。相反，我们只传输本地计算的机器学习模型或此类模型的参数、梯度等。通常，中央服务器基于传输的本地模型协调学习，尽管去中心化的联邦学习也是可能的。

在原始的联邦学习方法（称为 `federated average` (`FedAvg`)）的每次迭代中，`Central Server` 首先将其全局模型发送到每个设备节点。然后，设备根据其本地数据更新该模型的本地副本。接下来它们将梯度信息发送到 `Central Server`，后者对结果进行平均以更新全局模型。然后重复该过程，直到算法终止。请参阅 [图 7.3](#Ch007_261-315_B978044315888900008X.xhtml#f0020) 以了解该方案的说明。

![图 7.3 一个典型的联邦学习方案。去中心化的联邦学习，无需中央服务器，也是可能的。署名：James Foulds](images/F00008Xf07-03-9780443158889.jpg)

联邦学习的主要优势在于用户的数据永远不会离开本地设备，这限制了任何明显的个人信息披露。然而，除非采取额外措施通过确保差分隐私来确保这种情况不会发生，否则用户模型的私有信息仍有可能被逆向工程。联邦学习也容易受到来自本地设备的數據投毒攻击，除非采取额外措施加以防止。由于中央服务器永远无法看到实际数据以检查此类问题，因此很难监控或防止歧视性 AI 偏见。该方法所需的大量通信成本也是一个缺点。尽管如此，如果这些问题得到仔细管理（例如，通过将其与差分隐私和鲁棒机器学习方法相结合），联邦学习作为一种保护隐私的机器学习技术仍具有前景。

# 7.2 机器学习中的公平性与偏见

数据挖掘领域被视为巨大的成功。机器学习模型已被部署来做出影响日常生活诸多方面的决策，从社交媒体上的好友推荐到确定谁应优先获得医疗服务。我们知道人类通常是不可靠的决策者，受到各种偏见以及隐性或认知偏差的影响。在公众和学术界长期以来一直认为，人工智能可以通过公正、客观、逻辑和数据驱动的决策来避免这些偏见。不幸的是，现实是这远非得到保证。该领域正在围绕 `algorithmic bias` 和公平性问题进行反思。我们首先通过检查这些问题出现的几个应用领域来开始。
