
# 提升方法

提升方法用于组合多个模型，通过明确寻求互补的模型来利用这一见解。首先，相似之处在于：与 bagging 类似，提升使用投票（用于分类）或平均（用于预测）来组合各个模型输出。同样，与 bagging 类似，它组合相同类型的模型——例如，决策树。然而，提升是迭代的。而在 bagging 中各个模型是单独构建的，在提升中每个新模型都会受到之前构建模型的性能影响。提升鼓励新模型成为对早期模型处理错误实例的专家。最后的区别是，提升根据模型的性能对模型的贡献进行加权，而不是对所有模型赋予相同的权重。

## AdaBoost

提升思想有很多变体。我们描述了一种广泛使用的方法，称为 `AdaBoost.M1`，它专门为分类而设计。与 bagging 类似，它可以应用于任何分类学习算法。为了简化问题，我们假设学习算法可以处理加权实例，其中实例的权重是一个正数。（我们稍后会重新审视这一假设。）实例权重的存在改变了分类器误差的计算方式；它是被错误分类实例的权重之和除以所有实例的总权重，而不是被错误分类实例的比例。通过对实例加权，学习算法可以被迫集中于特定的一组实例，即权重较高的那些实例。此类实例变得尤为重要，因为正确分类它们的激励更大。`C4.5` 算法，在 [附录 C](#FigC1_655-685_B9780443158889000236.xhtml#FigC1_655-685_B9780443158889000236)，“树和规则的实现细节”中描述，是一个学习方法的例子，它可以在无需修改的情况下容纳加权实例，因为它已经使用分数实例的概念来处理缺失值。

提升算法，摘要见 [图 8.2](#Ch009_323-345_B9780443158889000091.xhtml#f0015)，首先为训练数据中的所有实例分配相等权重。然后它调用学习算法为该数据形成分类器，并根据分类器的输出重新加权每个实例。正确分类实例的权重会降低，而错误分类实例的权重会增加。这产生了一组权重较低的“容易”实例和一组权重较高的“困难”实例。在下一次迭代——以及所有后续迭代中——为重新加权的数据构建分类器，从而专注于正确分类困难实例。然后根据这个新分类器的输出增加或减少实例的权重。因此，一些困难实例可能会变得更困难，容易实例变得更简单；另一方面，其他困难实例可能会变得更容易，容易实例变得更困难——在实践中所有可能性都可能发生。每次迭代后，权重反映了实例迄今为止被产生的分类器错误分类的频率。通过为每个实例维护一个“难度”度量，该过程提供了一种优雅的方式来生成一系列互补的专家。

每次迭代后权重应改变多少？答案取决于当前分类器的整体误差。更具体地说，如果 `e` 表示分类器在加权数据上的误差（0 到 1 之间的分数），则权重按以下方式更新

`Weight←Weight×e/(1−e)`

![公式](images/F000091si1.png)

用于正确分类的实例，而错误分类实例的权重保持不变。当然，这并不会如前所述增加错误分类实例的权重。然而，在所有权重更新后，它们会被重新归一化，使其总和保持与之前相同。每个实例的权重除以新权重的总和并乘以旧权重的总和。这会自动增加每个错误分类实例的权重并减少每个正确分类实例的权重。

每当加权训练数据上的误差超过或等于 0.5 时，提升过程会删除当前分类器并且不再执行任何迭代。当误差为 0 时也会发生同样的情况，因为此时所有实例权重都变为 0。

我们已经解释了提升方法如何生成一系列分类器。为了形成预测，它们的输出使用加权投票组合起来。为了确定权重，请注意，在其构建的加权训练数据上表现良好的分类器（`e` 接近 0）应获得较高的权重，而表现不佳的分类器（`e` 接近 0.5）应获得较低的权重。`AdaBoost.M1` 算法使用

`Weight = - log(e/(1 - e))`,

![公式](images/F000091si2.png)

它是一个介于 0 和无穷大之间的正数。顺便说一下，这个公式解释了为什么在训练数据上表现完美的分类器必须被删除，因为当 `e` 为 0 时权重未定义。为了做出预测，为特定类别投票的所有分类器的权重会被求和，选择总和最大的类别。

我们最初假设学习算法可以处理加权实例。任何算法都可以被改编来处理加权实例；我们将在 [第 9.3 节](#Ch010_347-389_B9780443158889000108.xhtml#s0105) 的末尾解释如何做到这一点，`Locally weighted linear regression`。与其改变学习算法，可以通过重采样从加权数据生成未加权数据集——这与 bagging 使用的相同技术。而对于 bagging，每个实例以相等概率被选择，对于提升，实例以与权重成比例的概率被选择。因此，高权重实例会被频繁复制，而低权重实例可能永远不会被选中。一旦新数据集的大小与原始数据集一样大，它就会被输入学习方案，而不是加权数据。就这么简单。

此过程的缺点是一些低权重实例没有进入重采样数据集，因此在应用学习方案之前信息就会丢失。然而，这可以转化为优势。如果学习方案产生一个误差超过 0.5 的分类器，使用加权数据直接进行时提升必须终止，而使用重采样时，通过丢弃重采样数据集并从不同的随机种子生成新的数据集，可能产生误差低于 0.5 的分类器。有时通过重采样可以执行比使用原始加权版本算法更多的提升迭代。
