其中温度在每次迭代中降低：`t[i]` [+ 1] < `t[i]`。如果调度足够缓慢，该过程将收敛到真正的全局最小值。但问题就在于此——温度可能必须非常缓慢地降低。然而，这通常是可能的，特别是使用采样器的高效实现时。
