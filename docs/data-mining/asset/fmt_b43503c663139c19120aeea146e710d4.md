where `N(f)\x` represents the set of the function node `f`’s neighbors, excluding the recipient variable `x`; we write these variables of the `K` other neighboring nodes as `x[1]`, …, `x[K]`. If a variable is observed messages for functions involving it no longer need a sum over the states of the variable; the function is evaluated with the observed state. One could think of the associated variable node as being transformed into the new modified function. There is then no variable to function message for the observed variable.

Variable nodes send messages of this form to functions:
