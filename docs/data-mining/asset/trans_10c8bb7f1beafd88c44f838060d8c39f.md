# 第15章 继续前进：应用及其后果

## Abstract
近年来，机器学习技术在出人意料的多样化应用领域变得突出。本章介绍其中一些：文本挖掘，包括文档分类和聚类；网络挖掘，包括包装器归纳和用于网络搜索的 `page-rank` 方法；计算机视觉，包括物体和人脸识别；语音识别；以及自然语言处理和理解。深度学习已在所有这些领域取得进展，我们将这些内容与第10章“深度学习：基础”和第11章“高级深度学习方法”中涵盖的材料联系起来。我们还考虑了一些在实际应用中相关的其他问题。将机器学习应用于数据挖掘通常涉及学习算法和算法参数的仔细选择。许多实际数据集真正庞大，无法用为中小型数据设计的标准算法来处理。在某些现实场景中，数据以流的形式到达，需要能够不断快速更新模型并响应数据性质的变化的能力。经常以背景知识的形式存在领域专业知识，可用于帮助学习算法找到良好的概念描述。一些应用，特别是网络安全领域，涉及对抗性情况，其中学习算法面临旨在误导的训练数据。机器学习技术开始渗入我们的日常生活，我们瞥见了无处不在的数据挖掘的未来。最后，我们讨论了引发伦理关注的应用领域以及这些技术对社会的影响。

### Keywords
大规模数据集；数据流；领域知识；文本挖掘；网络挖掘；计算机视觉；语音识别；自然语言处理；对抗学习与无处不在的数据挖掘；人工智能伦理；人工智能与社会

机器学习是从数据中挖掘知识的蓬勃发展的技术，这种技术已越来越多地扩展到我们的日常生活并进入公众想象。未来的主要挑战是应用。机会无处不在。无论何处有数据，都可以从中学习。只要数据太多，人无法自行细读，学习的机制就必须自动化。但灵感绝对不会自动产生！应用不会来自计算机程序，也不会来自机器学习专家，或数据本身，而是来自与数据工作并产生问题的人。这就是我们撰写本书的原因，也是 `WEKA` 系统所述在 [附录 B](#AppendixB_637-654_B9780443158889000224.xhtml#AppendixB_637-654_B9780443158889000224) 的目的——赋予那些不是机器学习专家的人以将这些技术应用于日常工作生活中出现的问题的能力。想法很简单。算法就在这里。其余的真的取决于你！

当然，技术的开发绝非完成。机器学习是一个热门的研究课题，新的思想和技术不断涌现。为了体现研究前沿的广度和多样性，我们通过审视数据挖掘世界中的一些热门领域来结束第二部分。
