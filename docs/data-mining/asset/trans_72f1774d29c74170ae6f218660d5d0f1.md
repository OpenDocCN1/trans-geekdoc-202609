
# LSTM 循环神经网络架构

所谓的 `LSTM` 循环神经网络架构是专门为解决梯度消失问题而创建的。它使用隐藏单元、单元之间逐元素乘积和求和的特殊组合来实现控制“记忆单元”的门。这些单元设计用于在长时间内无修改地保留信息。它们拥有自己的输入和输出门，这些门由可学习权重控制，而该权重是当前观测值和前一时间步隐藏单元的函数。因此，梯度计算产生的反向传播误差项可以被存储并向后传播而不发生退化。原始的 `LSTM` 形式由 *输入门* 和 *输出门* 组成，但 *遗忘门* 和“窥视孔权重”是在后来添加的。该架构复杂，但在各种问题上取得了最先进的结果。接下来我们介绍 `LSTM` `RNNs` 最流行的变体，它不包含窥视孔权重但使用遗忘门。

## `LSTM` `RNNs` 如何工作

`LSTM` `RNNs` 工作如下。在每个时间步有三种类型的门：输入 `i[t]`、遗忘 `f[t]` 和输出 `o[t]`，每个都是时间 `t` 下的底层输入 `x[t]` 和时间 `t` - 1 的隐藏单元 `h[t-1]` 的函数。门将 `x[t]` 乘以各自的门特定 `W` 矩阵，将 `h[t-1]` 乘以各自的 `U` 矩阵，并加上各自的偏置向量 `b`，随后应用 sigmoid 逐元素非线性。
