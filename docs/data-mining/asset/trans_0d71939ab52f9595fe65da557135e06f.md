
20世纪70年代后期对该问题的研究发现，这些诊断规则可以由机器学习算法生成，连同其他每个疾病类别的规则，都可以从大约300个训练示例中生成。这些训练示例是从案例语料库中精心挑选的，使其彼此相当不同——在示例空间中“相距甚远”。同时，对做出诊断的植物病理学家进行了访谈，并将其专业知识转化为诊断规则。令人惊讶的是，在剩余的测试示例中，计算机生成的规则优于专家推导的规则。它们将正确疾病排在首位的时间为97.5%，而专家推导的规则仅为72%。此外，学习算法不仅找到了优于专家合作者规则的规则，而且同一位专家印象深刻，以至于他据称采用了发现的规则来取代他自己的规则！

## 1.3 已部署的应用

我们开头提到的示例是推测性的研究项目，而非生产系统。上面的大多数示例都是玩具问题——它们被刻意选择得很小，以便我们可以在本书后面用来逐步讲解算法。重点在哪？以下是一些实际上已被投入使用的机器学习应用。

作为已部署的应用，以下示例往往强调在性能情境中使用学习，其重点在于在新示例上表现良好的能力。本书还描述了使用学习系统从数据中推断出的决策结构中获取知识。我们认为这与做出高性能预测一样重要。不过，在已部署的应用中，这类用途往往代表性不足，因为当学习技术用于获得洞察时，结果通常不是作为独立应用投入使用的系统。尽管如此，在下面的三个示例中，决策结构的可理解性是应用成功采用的关键特征。

### 网页挖掘

在万维网上挖掘信息是一个巨大的应用领域。搜索引擎公司检查网页中的超链接，为每个网页和网站得出“声望”度量。词典将*声望*定义为“通过成功或影响力获得的高地位”。一种名为`PageRank`的指标，由谷歌创始人提出，也被其他搜索引擎开发者以各种形式使用，试图衡量网页的地位。链接到你网站的页面越多，其声望越高。如果链接进来的页面本身声望很高，则声望更大。这个定义听起来是循环的，但可以使其发挥作用。搜索引擎使用`PageRank`（在其他因素中）对网页进行排序，然后再显示你的搜索结果。

搜索引擎解决如何对网页进行排名的另一种方法是基于示例查询的训练集使用机器学习——文档包含查询中的术语以及人类对文档与该查询相关性的判断。然后学习算法分析这些训练数据，并提出一种方法来预测任何文档和查询的相关性判断。对于每个文档，都会计算出一组特征值，这些特征值取决于查询词——即它是否出现在标题标签中，是否出现在文档的URL中，在文档本身中出现的频率，以及在指向该文档的超链接的锚文本中出现的频率。对于多词查询，特征包括两个不同词在文档中相近出现的频率，等等。可能的特征有很多；典型的学习排名算法使用数百甚至数千个特征。

搜索引擎挖掘网络的内容。他们还挖掘你的查询内容——你搜索的术语——以选择你可能感兴趣的广告。他们有强烈的动机准确地做到这一点，因为只有当用户点击他们的链接时，他们才从广告商那里获得报酬。搜索引擎公司挖掘你的点击行为，因为了解你点击了哪些结果可以用于改进下一次搜索。在线书店挖掘购买数据库，以提出“购买此书的用户还购买了这些书”之类的推荐；同样，他们有强烈的动机向你提供引人注目的个性化选择。电影网站根据你之前的选择和其他人的选择推荐电影：如果他们做出让客户不断回到其网站的推荐，他们就赢了。

然后还有社交网络和其他个人数据。我们生活在自我表露的时代——人们在博客和推文中分享他们内心最深处的想法；他们的照片；他们的音乐和电影品味；他们对书籍、软件、小工具和酒店的看法；以及他们的社交生活。他们可能认为自己是匿名或假名进行的，但通常他们是错误的（参见[第1.7节](#Ch001_3-42_B9780443158889000029.xhtml#s0115)）。通过挖掘网络赚钱有着巨大的商业利益。

### 涉及判断的决策

当你申请贷款时，你必须填写一份问卷，提供相关的财务和个人信息。贷款公司使用这些信息作为是否借钱给你的决策依据。此类决策通常分为两个阶段：首先，使用统计方法确定明确的“接受”和“拒绝”案例。剩余的边界案例更困难，需要人工判断。例如，一家贷款公司使用统计决策程序根据问卷中提供的信息计算一个数值参数。如果该参数超过预设阈值，则申请人被接受；如果低于第二个阈值，则被拒绝。这占了90%的案例，剩余的10%转交给贷款官员决定。在检查申请人是否确实偿还贷款的历史数据时，发现被授予贷款的边界申请人中有一半实际上违约了。尽管简单地拒绝边界客户的信用可能很诱人，但信用行业专业人士指出，如果只能可靠地确定他们的还款前景，正是这些客户的业务应该争取；他们往往是信贷机构的活跃客户，因为他们的财务状况保持在长期波动状态。必须在公司会计的观点（不喜欢坏账）和销售主管的观点（不喜欢拒绝业务）之间达成合适的妥协。

机器学习登场。输入是1000个边界案例的训练示例，这些案例已发放贷款，并指明借款人最终是否还清或违约。对于每个训练示例，大约从问卷中提取了20个属性，例如年龄、在现任雇主的工作年限、在当前地址居住年限、在银行的年限，以及拥有的其他信用卡。使用机器学习程序生成了一小套分类规则，这些规则在独立选择的测试集中对三分之二的边界案例做出了正确预测。这些规则不仅提高了贷款决策的成功率，而且公司还发现它们很有吸引力，因为它们可用于向申请人解释决策背后的原因。尽管该项目是一个仅花费少量开发工作的探索性项目，但贷款公司显然对结果非常满意，以至于规则立即投入使用。
