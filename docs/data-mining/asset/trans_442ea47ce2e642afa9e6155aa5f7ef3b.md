
# 基于实例的学习改进

在 [第4.7节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0120) 中我们看到最近邻规则如何用于实现一种基本的基于实例学习形式。这个简单方案存在几个实际问题。首先，对于大型训练集，它往往很慢，因为必须为每个测试实例搜索整个集合，除非使用 `k`D-trees 或球树等复杂数据结构。其次，在有噪声的数据上表现很差，因为测试实例的类别由其唯一的最近邻决定，没有任何“平均”来帮助消除噪声。第三，当不同属性对结果的影响程度不同时——在极端情况下，当某些属性完全无关时——表现不佳，因为所有属性对距离公式的贡献都相等。第四，它不执行显式泛化，尽管我们在 [第3.5节](#Ch003_67-89_B9780443158889000042.xhtml#s0050)（并在 [图3.10](#Ch003_67-89_B9780443158889000042.xhtml#f0055) 中说明）中暗示了一些基于实例的学习系统确实执行显式泛化。

## 减少范例数量

普通最近邻规则存储大量冗余范例。然而，几乎完全没有必要保存迄今为止看到的所有示例。一种简单的变体是对每个示例相对于已看到的示例进行分类，并仅保存被误分类的那些。我们使用术语 *范例* 来指代用于分类的已见实例。丢弃正确分类的实例减少了范例数量，证明是修剪范例数据库的有效方法。理想情况下，每个实例空间的重要区域只存储一个范例。然而，在学习过程的早期，可能会丢弃后来证明重要的示例，可能导致预测准确性有所下降。随着存储实例数量的增加，模型的准确性提高，因此系统犯的错误更少。

不幸的是，仅存储被误分类实例的策略在面对噪声时效果不佳。有噪声的示例很可能被误分类，因此存储的范例集合往往会积累最无用的那些。这种效应在实验中很容易观察到。因此该策略只是通向更有效的基于实例学习器的一个过渡步骤。

## 修剪噪声范例

有噪声的范例不可避免地降低任何不抑制它们的最近邻方案的性能，因为它们会反复导致新实例被误分类。处理这个问题有两种方法。一种是定位，而不是单一最近邻，预先确定常数 `k` 的 `k` 个最近邻，并将多数类分配给未知实例。这里唯一的问题是确定合适的 `k` 值。普通最近邻学习对应于 `k` = 1<mml:math><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:math>![Equation](images/F000108si1.png)。噪声越多，最优的 `k` 值越大。一种可行的方法是使用几种不同的值进行交叉验证测试并选择最佳值。虽然这在计算时间上很昂贵，但通常能产生极佳的预测性能。

第二种解决方案是监控存储的每个范例的性能并丢弃表现不佳的范例。这可以通过记录每个范例做出的正确和错误分类决策数量来实现。在成功率上设置两个预定阈值。当范例的性能下降到较低阈值以下时，它会被从范例集合中删除。如果其性能超过上阈值，则用于预测新实例的类别。如果其性能介于两者之间，则不用于预测，但在它是新实例的最接近范例时（并且如果其性能记录足够好，本来会被用于预测），其成功统计数据会像已用于对该新实例进行分类一样进行更新。

为此，我们使用我们在 [第5.2节](#Ch005_165-207_B9780443158889000066.xhtml#s0015) 中推导的伯努利过程成功概率的置信限。回想一下，我们将 `S` 次成功中的 `N` 次总试验作为证据，以此为基础对真实的底层成功率 `p` 建立置信限。给定某个置信水平，例如 5%，我们可以计算上界和下界，并有 95% 的把握 `p` 位于两者之间。

为了将此应用于决定何时接受特定范例的问题，假设它已被使用 `n` 次来对其他实例进行分类，其中 `s` 次为成功。这使我们能够以特定置信水平估计该范例真实成功率的界限。现在假设该范例的类别在总共 `N` 个训练实例中出现了 `c` 次。这使我们能够估计默认成功率的界限，即在没有任何属性值信息的情况下成功对该类别的实例进行分类的概率。我们坚持范例成功率的 *下限* 置信界限超过默认成功率的 *上限* 置信界限。我们使用相同的方法制定拒绝表现不佳范例的标准，要求其成功率的 *上限* 置信界限低于默认成功率的 *下限* 置信界限。

在阈值选择合适的情况下，该方案效果良好。在一个特定的实现中，称为 `IB3` 即 *第3版基于实例学习器*，使用 5% 的置信水平来确定接受，而使用 12.5% 的水平来拒绝。较低的百分比产生更宽的置信区间，这使得标准更严格，因为一个区间的下界位于另一个区间的上界之上更难实现。接受的标准比拒绝的标准更严格，使得实例更难被接受。拒绝标准较不严格的原因是，丢弃分类准确率仅中等差的实例几乎没有损失；它们很可能会被类似的实例随后取代。使用这些阈值已被证明可以提高基于实例学习的性能，同时显著减少存储的范例数量——特别是噪声范例。

## 属性加权

修改为将所有属性值缩放至 0 到 1 之间的欧几里得距离函数，在属性对结果同等相关的域中表现良好。然而，这样的域是例外而非规则。在大多数域中，一些属性无关，而一些相关属性的重要性各不相同。基于实例学习的下一个改进是通过动态更新特征权重来增量学习每个属性的相关性。

在某些方案中，权重是类特定的，因为一个属性对一个类可能比对另一个类更重要。为此，为每个类生成一个描述，以区分其成员与所有其他类的成员。这导致未知测试实例可能被分配到多个不同类，或根本不分配类的问题——这是一个从我们对规则归纳的描述中再熟悉不过的问题。启发式解决方案被应用于解决这些情况。
