
统计聚类的基础是一种称为有限混合模型的统计模型。混合是一组 `k` 个概率分布，表示 `k` 个簇，决定该簇成员的属性值。换句话说，每个分布给出了在已知某个实例属于该簇的情况下，该实例具有某一组属性值的概率。每个簇都有不同的分布。任何特定实例“实际上”只属于一个且仅属于一个簇，但不知道是哪一个。最后，簇并非 equally likely；存在某种概率分布反映了它们相对的规模。

## 高斯混合模型的期望最大化算法

最简单的有限混合情况之一是只有一个数值属性的情况，该属性对每个簇都服从高斯或正态分布，但均值和方差不同。聚类问题是取一组实例——在这种情况下每个实例只是一个数字——以及预先指定的簇数，并计算出每个簇的均值和方差以及簇之间的总体分布。混合模型结合了几个正态分布，其概率密度函数看起来像山脉，每一个分量都有一个峰值。

[图 13.5](#Ch014_485-514_B9780443158889000145.xhtml#f0030) 显示了一个简单示例。有两个簇 A 和 B，每个簇都有一个正态分布，簇 A 的均值和标准差为 `μ[A]` 和 `σ[A]`，簇 B 为 `μ[B]` 和 `σ[B]`。从这些分布中抽取样本，使用簇 A 的概率为 `p[A]`，簇 B 的概率为 `p[B]`（其中 `p[A] + p[B] = 1`）。形成如图所示的数据集。现在想象一下，给出没有类别的数据集——只有数字——并被要求确定表征该模型的五个参数：`μ[A]`、`σ[A]`、`μ[B]`、`σ[B]` 和 `p[A]`（参数 `p[B]` 可以直接由 `p[A]` 计算得出）。这就是有限混合问题。

如果你知道每个实例来自两个分布中的哪一个，那么求出这五个参数就会很简单——只需分别估计簇 A 样本和簇 B 样本的均值和标准差，使用公式

```
$\\begin{matrix} {\\mu = \\frac{x\_{1} + x\_{2} + \\cdots + x\_{n}}{n},} \\\\ {\\sigma^{2} = \\frac{\\left( x\_{1} - \\mu \\right)^{2} + \\left( x\_{2} - \\mu \\right)^{2} + \\cdots + \\left( x\_{n} - \\mu \\right)^{2}}{n - 1}.} \\\\ \\end{matrix}$
```

![公式](images/F000145si58.png)

（在第二个公式中使用 `n-1` 而不是 `n` 作为分母可确保方差的无偏估计而不是最大似然估计；如果实际使用 `n` 代替，其差别不大。）这里，`x[1]`、`x[2]`、…、`x[n]` 是来自分布 A 或 B 的样本。要估计第五个参数 `p[A]`，取位于 A 簇中的实例的比例。

如果你知道这五个参数，那么求出给定实例来自每个分布的（后验）概率就会很简单。给定实例 `x[i]`，它属于簇 A 的概率为

```
$P(A \\mid x\_{i}) = \\frac{P(x\_{i} \\mid A) \\cdot P\\left( A \\right)}{P\\left( x\_{i} \\right)} = \\frac{N(x\_{i};\\mu\_{A},\\sigma\_{A})p\_{A}}{P(x\_{i})},$
```
