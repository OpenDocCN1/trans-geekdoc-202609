
`p(x[1], x[2], …, x[n]; θ) = p(x[1]; θ) p(x[2]; θ) … p(x[n]; θ)`.

![方程](images/F000145si20.png)

每个函数 `p(x[i]; θ)` 具有相同的参数值 `θ`，并且参数估计的目标是最大化这种形式的联合概率模型。由于观测值不会改变，该值只能通过改变参数 `θ` 的选择来改变。我们可以将该值视为数据的 *似然*，并将其写为

$L(\theta;x_{1},x_{2},\ldots,x_{n}) = \prod_{i = 1}^{n}{p(x_{i};\theta)}.$

![方程](images/F000145si24.png)

由于数据是固定的，更合理的做法是将其视为参数的似然函数，而参数是我们自由选择的。

相乘多个概率可能导致非常小的数值，因此人们通常使用似然的对数，即 *对数似然*：

$\log L(\theta;x_{1},x_{2},\ldots,x_{n}) = \sum_{i = 1}^{n}{\log p(x_{i};\theta)},$

![方程](images/F000145si25.png)

这将乘积转换为求和。由于对数是严格单调递增函数，最大化对数似然与最大化似然是等价的。“最大似然”学习指的是寻找实现这一目标的参数的技术：

$\theta_{ML} = \text{arg}\max_{\theta}\sum_{i = 1}^{n}{\log p(x_{i};\theta)}.$

![方程](images/F000145si26.png)
