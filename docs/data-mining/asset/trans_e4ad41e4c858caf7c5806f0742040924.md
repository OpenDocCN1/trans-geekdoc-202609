
与模型树类似，局部加权线性回归能够逼近非线性函数。其主要优点之一是它非常适合增量学习。所有训练都在预测时进行，因此可以在任何时候将新实例添加到训练数据中。然而，与其他基于实例的方法一样，它在为测试实例推导预测时速度很慢。首先必须扫描训练实例以计算其权重；然后对这些实例执行加权线性回归。此外，与其他基于实例的方法一样，局部加权回归对训练数据集的全局结构提供的信息很少。注意，如果平滑参数基于 `k` 最近邻，且加权函数对更远的实例赋予零权重，则文中所述的 `k`D-树和球树可以用于加速寻找相关邻居的过程。[第4.7节](#Ch004_91-164_B9780443158889000054_a.xhtml#s0120)

局部加权学习并不局限于线性回归；它可以与任何能够处理加权实例的学习技术一起应用。特别是，你可以用它来进行分类。大多数算法都可以很容易地适应处理权重。其诀窍在于认识到（整数）权重可以通过创建同一实例的多个副本来模拟。每当学习算法在计算模型时使用一个实例时，只需假装它伴随着适当数量的相同影子实例。这在权重不是整数时也适用。例如，在 [第4.2节](#Ch004_91-164_B9780443158889000054.xhtml#s0020) 所述的 `Naïve Bayes` 算法中，将从一个实例得出的计数乘以该实例的权重，然后——瞧——你就拥有了一个可用于局部加权学习的 `Naïve Bayes` 版本。

事实证明，局部加权 `Naïve Bayes` 在实践中效果相当好，优于 `Naïve Bayes` 本身和 `k` 最近邻技术。它也与通过放松其固有独立性假设来增强 `Naïve Bayes` 的更复杂方法相比更有利。局部加权学习仅假设邻域内独立，而非像标准 `Naïve Bayes` 那样在整个实例空间全局独立。

原则上，局部加权学习也可以应用于决策树和其他比线性回归和 `Naïve Bayes` 更复杂的模型。然而，在这里它带来的好处较少，因为局部加权学习主要是通过允许它们逼近任意目标来使简单模型变得更灵活的方式。如果底层学习算法已经能够做到这一点，则应用局部加权学习就没有什么意义了。尽管如此，它可能会改进其他简单模型，例如线性支持向量机和逻辑回归。

### 讨论

回归树是在 [布雷曼等人（1984）](#References_705-736_B978044315888900025X.xhtml#fur67) 的 `CART` 系统中引入的。`CART`，即 *分类与回归树*，包含了与 `C4.5` 类似的离散类的决策树归纳器，以及归纳回归树的方案。本节所述的许多技术，例如处理名义属性的方法和处理缺失值的替代设备，都包含在 `CART` 中。然而，模型树直到最近才出现，最早由 [昆兰（1992）](#References_705-736_B978044315888900025X.xhtml#fur444) 描述。使用模型树生成规则集（尽管不是部分树）的工作已由 [霍尔、霍姆斯和弗兰克（1999）](#References_705-736_B978044315888900025X.xhtml#fur244) 探索。

模型树归纳的全面描述（和实现）由 [王和威滕（1997）](#References_705-736_B978044315888900025X.xhtml#fur551) 给出。神经网络也常用于预测数值量，尽管它们产生的结构不透明，无法用于帮助理解解决方案的性质。存在从神经网络结构中产生可理解见解的技术，但内部表示的任意性意味着在相同数据上训练的相同架构的网络之间可能存在巨大差异。通过将所归纳的函数划分为线性块，模型树提供了一种可重复且至少在某种程度上可理解的表示。

局部加权学习有许多变体。例如，统计学家考虑过使用局部二次模型代替线性模型，并将局部加权逻辑回归应用于分类问题。此外，文献中还可以找到许多不同的潜在加权和距离函数。[阿特克森、沙尔和摩尔（1997）](#References_705-736_B978044315888900025X.xhtml#fur19) 写了一篇关于局部加权学习的优秀综述，主要在回归问题的背景下。[弗兰克、霍尔和普法林格（2003）](#References_705-736_B978044315888900025X.xhtml#fur179) 评估了将局部加权学习与 `Naïve Bayes` 结合使用。
