为了确保参数向量定义一个有效的概率，对数似然被增加了一项，涉及 `Lagrange multiplier` `λ`，该项强制概率之和为一：

$L = \\sum\\limits\_{k = 1}^{K}n\_{k}\\log\\pi\_{k} + \\text{λ}\\left\\lbrack {1 - \\sum\\limits\_{k = 1}^{K}\\pi\_{k}} \\right\\rbrack.$<mml:math><mml:mi>L</mml:mi><mml:mo>=</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mspace width=".25em" /><mml:mi>log</mml:mi><mml:mspace width=".25em" /><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>+</mml:mo><mml:mtext>&#955;</mml:mtext><mml:mrow><mml:mo stretchy="true">\[</mml:mo><mml:mrow><mml:mn>1</mml:mn><mml:mo>&#8722;</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub></mml:mrow><mml:mo stretchy="true">\]</mml:mo></mml:mrow><mml:mo>.</mml:mo></mml:math>

对该函数关于 `λ` 求导并将结果设为零告诉我们模型中概率的总和应为 1（符合预期）。然后我们对每个参数求导并将其设为零，得到

$\\left. \\frac{\\partial L}{\\partial\\pi\_{k}} = 0\\Rightarrow n\_{k} = \\text{λ}\\pi\_{k}. \\right.$<mml:math><mml:mfrac><mml:mrow><mml:mi>&#8706;</mml:mi><mml:mi>L</mml:mi></mml:mrow><mml:mrow><mml:mi>&#8706;</mml:mi><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub></mml:mrow></mml:mfrac><mml:mo>=</mml:mo><mml:mn>0</mml:mn><mml:mo>&#8658;</mml:mo><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:mtext>&#955;</mml:mtext><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>.</mml:mo></mml:math>
