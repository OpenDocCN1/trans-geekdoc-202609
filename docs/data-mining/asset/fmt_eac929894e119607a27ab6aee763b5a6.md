This matrix is generally diagonal because activation functions usually operate on an elementwise basis. The `W^{T(l+1)}` ![Equation](images/F000248si38.png) term results from the fact that `a^{(l+1)}(h^{(l)}) = W^{(l+1)} h^{(l)} + b^{(l+1)}` ![Equation](images/F000248si39.png). The gradients for the `k`th vector of parameters of the `l`th network layer can therefore be computed using products of matrices of the following form

$\\frac{\\partial L}{\\partial\\mathbf{\\theta}\_{k}^{(l)}} = - \\mathbf{H}\_{k}^{({l - 1})}\\mathbf{D}^{(l)}\\mathbf{W}^{T{({l + 1})}}\\cdots\\mathbf{D}^{(L)}\\mathbf{W}^{T{({L + 1})}}\\Delta^{({L + 1})}.$

![Equation](images/F000248si40.png)

Given these equations, the definition of `f(x)` ![Equation](images/F000248si41.png), a loss function, and any regularization terms, deep networks formulated in this general way can be optimized using gradient descent. The recursive definitions for `Δ^{(l)}` ![Equation](images/F000248si42.png) reflect how the algorithm propagates information back from the loss.
