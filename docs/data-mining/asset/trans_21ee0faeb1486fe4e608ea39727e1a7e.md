
`PPCA` 基于数据的连续值表示和底层高斯模型。与之相比，`pLSA` 方法，也称为“方面模型”，基于使用多项分布的公式；它最初应用于词语和文档的共现。多项分布是建模词语出现次数的自然分布。在 `pLSA` 框架中，假定每个文档的索引由离散随机变量 `d[i]` 的观测值编码，其中 `i` = 1, …, `n` 个文档。每个变量 `d[i]` 有 `n` 个状态，并且在文档语料库中每个状态都有该变量的一个观测值。主题由离散变量 `z[ij]` 表示，而词语由随机变量 `w[ij]` 表示，其中每个文档关联 `m[i]` 个词语，每个词语关联一个主题。存在两种变体：不对称和对称公式。

[图 14.4A](#Ch015_516-570_B9780443158889000157.xhtml#f0025) 说明了不对称公式；对称公式将 `d` 到 `z` 的箭头反转。`D` 是文档索引观测值的随机变量集合，而 `W` 是所有文档中观测到的词语的随机变量集合。不对称公式对应于

```
$P(W,D) = \\prod\\limits\_{i = 1}^{n}{P(d\_{i})}\\prod\\limits\_{j = 1}^{m\_{n}}{\\sum\\limits\_{z\_{\\mathit{ij}}}{P(z\_{\\mathit{ij}} \\mid d\_{i})P(w\_{\\mathit{ij}} \\mid z\_{\\mathit{ij}})}}.$
```

因为 `d`，训练文档的索引，是图中的随机变量，所以 `pLSA` 不是新文档的生成模型。然而，它对应于一个具有隐变量的有效概率模型，因此可以用 EM 算法来估计参数并获得语料库中每个文档在主题变量上的分布表示。

### 潜在狄利克雷分配

`pLSA` 可以扩展为具有三层层次贝叶斯模型，称为 *潜在狄利克雷分配*。我们将其称为 `LDA^b`（“b”代表贝叶斯），以区别于通常称为 LDA 的线性判别分析。`LDA^b` 部分是为了减少 `pLSA` 中观察到的过拟合而提出的，并且已被以多种方式扩展。`LDA^b` 的扩展可用于确定随时间的变化趋势并识别“热门”和“冷门”主题。随着社交媒体的爆炸式增长以及对其分析的兴趣，此类分析今天尤其有趣。
