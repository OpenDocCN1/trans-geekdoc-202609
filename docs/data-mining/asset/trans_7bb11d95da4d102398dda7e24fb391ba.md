
# 机器学习案例研究

## 油膜检测

自卫星技术早期以来，环境科学家一直尝试从卫星图像中检测油膜，以便对生态灾难发出早期预警并遏制非法倾倒。雷达卫星提供了无论天气条件如何都能昼夜监测沿海水域的机会。油膜在图像中表现为暗区，其大小和形状会随着天气和海况而变化。然而，其他类似的暗区也可能是由局部天气条件如强风造成的。检测油膜是一项昂贵的人工流程，需要经过高度培训的人员对图像中的每个区域进行评估。

已开发出一套危害检测系统，用于对图像进行筛选以便后续人工处理。该系统旨在面向具有不同目标、应用和地理区域的各类用户——政府机构和公司——在全球范围内推广，因此需要高度可定制以适应个人情况。机器学习使系统能够根据用户提供的溢油和非溢油示例进行训练，并让用户控制未检测到的溢油与误报之间的权衡。与其他生成分类器后部署到现场的机器学习应用不同，这里部署的是学习方案本身。

输入是一组来自雷达卫星的原始像素图像，输出是数量更少的一组图像，其中疑似油膜用彩色边框标记。首先，应用标准图像处理操作来归一化图像。然后，识别可疑的暗区。从每个区域提取数十个属性，描述其大小、形状、面积、强度、边界的锐利度和锯齿状程度、与其他区域的邻近性以及区域附近背景的信息。最后，将标准学习技术应用于所得的属性向量。（一种替代方法，省略显式特征提取步骤，将是使用[第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)中讨论的深度学习方法，“深度学习：基础。”）

遇到了几个有趣的问题。其一是训练数据的稀缺。油膜（幸运的是）非常罕见，而人工分类成本极高。另一点是问题的不平衡性；在训练数据中的众多暗区中，只有极小一部分是真正的油膜。第三点是示例自然地分组为批次，每个图像中的区域构成一个批次，且不同批次的背景特征各不相同。最后，性能任务是充当过滤器，用户必须提供方便的方式来调整误报率。

## 负荷预测

在电力供应行业，尽可能提前确定未来的电力需求非常重要。如果能够对每小时、每天、每月、每季和每年的最大和最小负荷做出准确估计，公用事业公司可以在运行储备设定、维护计划和燃料库存管理等方面实现显著节约。

一套自动负荷预测助手已在一家大型公用事业供应商运行超过十年，用于生成提前2天的逐小时预测。第一步是利用过去15年收集的数据手工创建复杂的负荷模型。该模型有三个组成部分：全年的基载、年内的负荷周期性以及假期的影响。为了对基载进行归一化，每个前一年的数据都通过从每个小时读数中减去该年的平均负荷并除以全年的标准差来进行标准化。电力负荷在三个基本频率上表现出周期性：昼夜，使用量在清晨达到最低，中午和下午达到最高；每周，周末需求较低；季节性，冬季和夏季因供暖和制冷需求增加分别导致年度周期。诸如感恩节、圣诞节和新年等主要假期的负荷与正常负荷有显著差异，且各自通过对过去15年该日的逐小时负荷取平均值来单独建模。次要法定假日，如哥伦布日，被归为学校假期，并作为对正常昼夜模式的偏移来处理。所有这些影响都通过将一年的负荷重构为典型日的序列、在正确位置插入假期，并对负荷进行去归一化以考虑整体增长来纳入其中。

到目前为止，负荷模型是静态的，由历史数据手工构建，并隐含假设全年气候条件“正常”。最后一步是通过定位与当前情况最相似的前一天并使用该日的历史信息作为预测因子来考虑天气条件。该预测被视为对静态负荷模型的加性修正。为防止异常值，定位八个最相似的日子并对其加性修正取平均值。建立了一个数据库，记录15年历史记录中每个小时三个当地气象中心的温度、湿度、风速和云量，以及实际负荷与静态模型预测负荷之间的差异。进行了线性回归分析以确定这些观测对负荷的相对影响，并将系数应用于用于定位最相似日子的距离函数权重。

所得系统产生的性能与训练有素的人类预报员相同，但速度快得多——生成每日预测只需几秒钟而非数小时。人类操作员可以分析预测对模拟天气变化的敏感性，并调出系统用于天气调整的“最相似”日子进行检查。

## 诊断

诊断是专家系统的主要应用领域之一。尽管专家系统中使用的手工规则通常表现良好，但在手工制定规则过于费力的情况下，机器学习可能很有用。

对电机和发电机等机电设备的预防性维护可以防止扰乱工业流程的故障。技术人员定期检查每台设备，在各点测量振动以确定设备是否需要维修。典型故障包括轴不对中、机械松动、轴承故障和泵不平衡。一家特定的化工厂使用超过1000种不同的设备，从小型泵到非常大的涡轮发电机，曾由拥有20年经验的人类专家进行诊断。故障是通过在设备安装的不同位置测量振动并使用傅里叶分析检查基本旋转速度每个谐波在三个不同方向上的能量来识别的。这些信息由于测量和记录程序的限制而非常嘈杂，专家可以研究这些信息以得出诊断。尽管已为某些情况提取了手工专家系统规则，但提取过程需要针对不同类型的机械重复多次；因此研究了学习方法。
