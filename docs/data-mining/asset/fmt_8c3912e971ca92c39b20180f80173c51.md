
While the `Q`![Equation](images/F000121si118.png), `K`![Equation](images/F000121si119.png), and `V`![Equation](images/F000121si120.png) parameter matrices could in principle be learned separately from scratch for each head, in practice, to reduce the number of parameters to learn, the attention heads share common initial `Q`![Equation](images/F000121si121.png), `K`![Equation](images/F000121si122.png), and `V`![Equation](images/F000121si123.png) matrices but the `i`![Equation](images/F000121si124.png)th head has its own unique projection matrices for each of these parameter sets, `W[i]^(Q)`![Equation](images/F000121si125.png), `W[i]^(K)`![Equation](images/F000121si126.png), and `W[i]^(V)`![Equation](images/F000121si127.png), respectively. Multiplication by these matrices maps the shared parameters to head-specific values while also reducing the number of dimensions of the outputs. A final shared projection matrix `W^(O)`![Equation](images/F000121si128.png) is used to linearly project the concatenated outputs of all the heads to the target dimensionality for the layer’s representation, `d[model]`![Equation](images/F000121si129.png). More formally, the overall multihead attention module, which comprises a layer in a transformer neural network model, can be written as:

`MultiHead(Q,K,V;W^(Q),W^(K),W^(V),W^(O)) = Concatenate(head[1],head[2],…,head[h])W^(O)`![Equation](images/F000121si130.png)

where:

`head[i] = Attention(QW[i]^(Q),KW[i]^(K),VW[i]^(V))`![Equation](images/F000121si131.png)

In the original transformer paper, the authors used `h = 8`![Equation](images/F000121si132.png) of these “heads” per layer ([Fig. 11.9](#Ch012_433-471_B9780443158889000121.xhtml#f0050)). We can also once again use masking on the attention heads, in which case such a module is called `masked multihead attention`.

### Transformer Blocks

Having described the multihead attention module, we are finally ready to explain the transformer architecture. Transformer models are deep neural networks that contain stacks of transformer blocks, each of which itself contains several layers. A transformer block consists of two main sublayers:

1. A multihead attention layer
2. A feed-forward layer

The multihead attention layer may optionally use masking as needed. The authors of the original transformer paper use a small one-dimensional feed-forward network that is applied identically to each position of its input, consisting of a `ReLU` layer followed by a linear layer. The upshot is that in each transformer block, the multihead attention layer is doing most of the work in processing the input, but the feed-forward layer can make a small adjustment to its output. Alternatively, a fully-connected network could be used.
