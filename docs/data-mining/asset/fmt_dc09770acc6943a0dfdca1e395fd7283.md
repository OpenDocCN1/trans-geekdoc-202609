## Differential Fairness

We see from the largest value in the table (indicated in bold) that `ϵ` = 2.337<mml:math><mml:mi mathvariant="normal">&#1013;</mml:mi><mml:mo>=</mml:mo><mml:mn>2.337</mml:mn></mml:math>![Equation](images/F00008Xsi154.png). While this simple example only included one protected dimension (Group 1 vs Group 2), differential fairness is designed to be applied to scenarios where there are multiple protected dimensions to consider at once (e.g., gender, race, and nationality).

Due to its relationship with differential privacy, differential fairness provides a privacy guarantee—the class label assigned by the model will not reveal much information about the protected attributes if the definition holds (i.e., `ϵ` is small). More concretely, consider a scenario where the users’ data is held on a private server and a bank, assumed untrustworthy, is told only the output of a classifier that predicts whether an individual will repay a loan. The privacy guarantee ensures that, for example, if the individual is predicted to repay the loan the bank cannot conclude that the user is probably White and male.

Differential fairness has a generalization guarantee but it is weaker than the one for subgroup fairness; the fairness parameter `ϵ` estimated from the training data will generalize to the overall population as long as there is enough data for each intersectional subgroup. The differing goals of subgroup fairness and differential fairness led to the differing treatment of small subgroups in the two metrics. Subgroup fairness aims to prevent any attempt to gerrymander the fairness behavior of the algorithm, so it assumes that there are many dimensions and prioritizes generalization over ensuring that minority subgroups are protected. Differential fairness aims to ensure an intersectional conception of fairness, so it prioritizes minority subgroups over generalization. The number of protected dimensions, and hence the number of subgroups, need not be so large since the goal is to have a more nuanced understanding of fairness beyond considering top-level protected groups separately (e.g., women, Black people). Intersectionality was originally inspired by harms that occur at the intersection of two protected attributes (gender, race). From an intersectional perspective, even just the consideration of these two dimensions is already an improvement over the status quo.

Alternatively, the *multicalibration* fairness metric ensures that the prediction probabilities are calibrated for all the protected subgroups of interest. We discussed calibration earlier as a limitation of the equalized odds fairness definition; multicalibration aims to address this particular issue for overlapping subgroups.

## Individual Fairness

A different approach to solving the fairness gerrymandering issue is to remove the notion of groups from the fairness definition entirely and focus on individuals directly. *Individual fairness*, proposed by Cynthia Dwork and colleagues, embodies the ideal that similar individuals should be treated similarly by the algorithm by having similar class probabilities. Encoding this mathematically results in the following definition. We assume that our classifier of interest `M(x)` is a probabilistic classifier such as logistic regression, which randomly assigns a class label to each instance `x` according to the class probabilities it outputs.
