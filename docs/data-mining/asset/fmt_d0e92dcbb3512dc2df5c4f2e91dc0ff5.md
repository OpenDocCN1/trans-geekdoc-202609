
# Subgroup fairness

*Subgroup fairness* is a fairness definition by computer scientist/theoretician Michael Kearns and colleagues that aims to address fairness gerrymandering. Suppose that there are multiple protected attributes, that is, `s` is vector-valued. Let `g(s)` be an indicator function that selects a subgroup at an intersection of the protected groups, where `g(s) = 1` when an individual belongs to group `g` and 0 otherwise. Suppose we have a collection `G` of such group indicators that we want to ensure fairness for Kearns et al. provide a parity-based version (`statistical parity subgroup fairness`) and a version that is similarly defined but instead focuses on false positive rates (`false positive subgroup fairness`). In the statistical parity (SP) version, the probability of the positive class (`y = 1`) for each subgroup `g` must be similar to the overall positive class probability across the entire population. A classifier is set to satisfy `γ`- SP subgroup fairness if for every `g ∈ G`,

```
|P(ŷ = 1) − P(ŷ = 1 | g(s) = 1)| × α[g] ≤ γ.
```

Here, there is a scaling factor `α[g] = P(g(s) = 1)` that weights each group by its proportion of the population. In other words, large subgroups are considered important by the definition while small subgroups are considered unimportant and are likely to be ignored (since the metric is determined by the largest value of the equation over all of the subgroups). This is done to obtain provable generalization guarantees, ensuring that the value of the metric generalizes beyond the training set to the overall population. The idea behind this is that since there is not much data for the smaller subgroups, their counts would be noisy, but downweighting them means that these noisy counts will not destabilize the estimation of the metric.

On the other hand, the downside of this approach is that it explicitly disregards minority subgroups. This is problematic from the perspective of intersectionality theory, since minority groups are frequently the most harmed by racism and other such systems of oppression. Note that subgroup fairness was motivated by preventing fairness gerrymandering/subset targeting, not intersectionality.
