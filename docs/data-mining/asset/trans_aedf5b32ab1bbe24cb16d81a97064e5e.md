# 第二部分：更高级的机器学习方案

我们已经了解了几种机器学习方法的基本思想，并详细研究了如何评估它们在实际数据挖掘问题上的性能。我们还讨论了数据准备方法，并探讨了围绕这些方法产生的伦理问题以及如何缓解这些问题。现在我们已经做好准备来研究更强大、更先进的机器学习算法。我们的目标是以概念层面和相当的技术细节来解释这些内容，以便你能够充分理解它们并认识到出现的关键实现问题。由于材料的性质，本书的第二部分在阅读方式上与第一部分有所不同。大多数章节可以独立阅读，但[第9章](#Ch010_347-389_B9780443158889000108.xhtml#Ch010_347-389_B9780443158889000108)，“扩展基于实例和线性模型”，[第10章](#Ch011_391-432_B978044315888900011X.xhtml#Ch011_391-432_B978044315888900011X)，“深度学习：基础”和[第11章](#Ch012_433-471_B9780443158889000121.xhtml#Ch012_433-471_B9780443158889000121)，“高级深度学习方法”相互递进，同样[第13章](#Ch014_485-514_B9780443158889000145.xhtml#Ch014_485-514_B9780443158889000145)，“概率方法：基础”和[第14章](#Ch015_516-570_B9780443158889000157.xhtml#Ch015_516-570_B9780443158889000157)，“高级概率方法”也是如此。

在[第4章](#Ch004_91-164_B9780443158889000054.xhtml#Ch004_91-164_B9780443158889000054)，“算法：基本方法”中描述的简单方法与在许多现实世界问题上实现最先进性能所需更复杂的算法之间存在实质性差异，但原则是相同的。输入也是如此，在许多情况下输出也是如此——知识表示的方法。但算法更复杂（例如，它们可能需要扩展以处理数值属性、缺失值，以及——最具挑战性的是——噪声数据）。

[第4章](#Ch004_91-164_B9780443158889000054.xhtml#Ch004_91-164_B9780443158889000054)，“算法：基本方法”以如何推断 rudimentary 规则的解释开篇，随后研究了概率建模和决策树。然后我们回到规则归纳并继续研究关联规则、线性模型、基于实例学习的最近邻方法、聚类和多实例学习。在第二部分，包括附录中，我们进一步发展所有这些主题并也遇到一些新主题。
