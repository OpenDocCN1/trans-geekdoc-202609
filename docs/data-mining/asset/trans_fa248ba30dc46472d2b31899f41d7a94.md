
# 偏最小二乘方向

存在一种仅涉及点积运算的简单迭代方法来计算偏最小二乘方向。 从输入属性标准化为零均值和单位方差开始，第一个偏最小二乘方向的属性系数是通过依次取每个属性向量与类向量之间的点积得到的。 为了找到第二个方向，采用相同的方法，但原始属性值被替换为该属性的值与使用第一个方向作为该属性的单一预测变量的简单单变量回归的预测值之间的差值。 这些差值称为 `residuals`。 该过程以相同的方式继续进行每个剩余方向，来自前一次迭代的属性残差构成寻找当前偏最小二乘方向的输入。

这里有一个简单的计算示例，有助于阐明该过程。 对于 [表 1.5](#Ch001_3-42_B9780443158889000029.xhtml#t0030) 中的 CPU 性能数据的前五个实例，[表 6.1A](#Ch006_209-259_B9780443158889000078.xhtml#t0010) 显示了 `CHMIN` 和 `CHMAX` 的值（标准化为零均值和单位方差后）以及 `PRP`（未标准化）。 任务是找到目标属性 `PRP` 关于其他两个属性的表达式。 第一个偏最小二乘方向的属性系数是通过依次取类与每个属性之间的点积得到的。 `PRP` 与 `CHMIN` 列之间的点积为 –0.4472，而 `PRP` 与 `CHMAX` 之间的点积为 22.981。 因此第一个偏最小二乘方向为

`PLS1 = -0.4472 CHMIN + 22.981 CHMAX`.

下一步是准备用于寻找第二个偏最小二乘方向的输入数据。为此，`PLS1` 依次对 `CHMIN` 和 `CHMAX` 进行回归，从而得到从 `PLS1` 单独预测这些属性的线性方程。 系数是通过取 `PLS1` 与所讨论属性之间的点积并将结果除以 `PLS1` 与自身之间的点积得到的。 所得到的单变量回归方程为：

`CHMIN = 0.0438 PLS1`

![方程](images/F000078si7.png)

`CHMAX = 0.0444 PLS1`.

![方程](images/F000078si8.png)

[表 6.1C](#Ch006_209-259_B9780443158889000078.xhtml#t0010) 显示了为寻找第二个偏最小二乘方向而准备的 CPU 数据。 `CHMIN` 和 `CHMAX` 的原始值已被残差取代，即原始值与前面给出的相应单变量回归方程的输出之间的差值（目标值 `PRP` 保持不变）。 使用此数据作为输入重复整个过程，从而得到第二个偏最小二乘方向，即

`PLS2 = -23.6002 CHMIN + -0.4593 CHMAX`.

![方程](images/F000078si9.png)

在找到最后一个偏最小二乘方向后，属性残差全部为零。 这反映了这样一个事实：与主成分分析一样，方向的完整集合解释了原始数据中的全部方差。

当偏最小二乘方向用作线性回归的输入时，所得到的模型称为 `partial least squares regression model`。 与主成分回归一样，如果使用所有方向，则解与对原始数据应用线性回归得到的解相同。

## 独立成分分析

主成分分析为特征空间找到一个坐标系，以捕捉数据的协方差。 相比之下，`independent component analysis` (`ICA`) 寻求一种投影，将数据分解为 `statistically independent` 的源。

考虑“鸡尾酒会问题”，人们听到音乐和其他人的声音； 目标是解混这些信号。 当然，还有许多其他场景需要解开信息的线性混合。 独立成分分析找到混合信号的线性投影，给出最统计独立的变换变量集。

主成分分析有时被认为是在寻求将相关变量变换为线性不相关变量。 然而，相关性和统计独立性是两个不同的标准。 `Uncorrelated` 变量的相关系数为零，对应于协方差矩阵中的零项。 当两个变量的联合概率是其边缘概率的乘积时，这两个变量被认为 `independent`。 （我们将在 [第 13.1 节](#Ch014_485-514_B9780443158889000145.xhtml#s0010) 中讨论边缘概率。）

称为 `mutual information` 的量衡量了从一个随机变量中获得的关于另一个随机变量的信息量。 它可以用作寻找数据投影的替代标准，基于最小化线性变换空间中数据维度之间的互信息。 给定模型 `s = A x`，其中 `A` 是正交矩阵，`x` 是输入数据，`s` 是源信号的分解，可以证明最小化 `s` 维度之间的互信息相当于将数据变换为源 `p(s)` 的估计概率分布尽可能远离高斯分布，并且估计值 `s` 被约束为不相关。
