
[Hochreiter and Schmidhuber (1997)](#References_705-736_B978044315888900025X.xhtml#fur271) 是关于循环神经网络“长短期记忆”架构的开创性论文；我们的解释遵循 Graves 和 Schmidhuber（2005）的表述。Greff、Srivastava、Koutník、Steunebrink 和 Schmidhuber（2015）的论文“LSTM：一次搜索空间奥德赛”探索了大量变体并发现：（1）没有一种显著优于标准 LSTM 架构；且（2）遗忘门和输出激活函数是最关键的组件。遗忘门由 [Gers, Schmidhuber, and Cummins (2000)](#References_705-736_B978044315888900025X.xhtml#fur212) 添加。

IRNN 由 [Le, Jaitly, and Hinton (2015)](#References_705-736_B978044315888900025X.xhtml#fur212) 提出，而 [Chung, Gulcehre, Cho, and Bengio (2014)](#References_705-736_B978044315888900025X.xhtml#fur100) 提出了门控循环单元，[Schuster and Paliwal (1997)](#References_705-736_B978044315888900025X.xhtml#fur481) 提出了双向循环神经网络。[Chen and Chaudhari (2004)](#References_705-736_B978044315888900025X.xhtml#fur92) 将双向网络用于蛋白质结构预测，而 [Graves et al. (2009)](#References_705-736_B978044315888900025X.xhtml#fur231) 将其用于手写识别。[Cho et al. (2014)](#References_705-736_B978044315888900025X.xhtml#fur98) 将编码器-解码器网络用于机器翻译，而 [Sutskever, Vinyals, and Le (2014)](#References_705-736_B978044315888900025X.xhtml#fur514) 提出了深度编码器-解码器网络并将其与海量数据一起使用。由 [He et al. (2016)](#References_705-736_B978044315888900025X.xhtml#fur257) 提出的残差连接是一项重大的架构进步，使训练更深的神经网络变得更容易。

为了进一步了解深度学习的进展以及该领域的更详尽历史，请参阅 [LeCun, Bengio, and Hinton (2015)](#References_705-736_B978044315888900025X.xhtml#fur357)、[Bengio (2009)](#References_705-736_B978044315888900025X.xhtml#fur30) 和 [Schmidhuber (2015)](#References_705-736_B978044315888900025X.xhtml#fur476) 的综述。

## 10.7 深度学习软件和网络实现

深度学习软件框架使开发和训练深度神经网络模型变得容易。这些框架通常包括高级 API（“应用程序编程接口”），允许用几行代码指定模型；自动微分功能可消除手动推导梯度的负担、GPU 支持、先进学习算法和深度学习架构的实现等。它们通常将深度神经网络（或其他计算）中的数据流表示为 `computation graph`，其中每个计算阶段的数学运算及其相互关系被编码为图。通过预先存储图，计算可以得到优化，并且反向传播可以自动执行，梯度在“反向传播阶段”中沿图流动，方向与原始“前向传播”计算相反。其中许多框架是开源且可免费使用的。

目前最流行的深度学习软件平台是 TensorFlow 和 PyTorch。历史上，主要由 Google 开发的 TensorFlow 通常被认为更适合创建部署系统，而主要由 Facebook AI Research 团队开发的 PyTorch 则因开发和调试方面的优势而被许多人认为更适合学术研究。然而，两者之间的差距已大幅缩小，因为这两个平台在其最新版本中都解决了相对于竞争对手的 perceived 弱点。现在，这两个平台在部署和开发阶段都非常强大。

### TensorFlow 和 Keras

TensorFlow 是一个基于 C++ 和 Python 的软件库，用于通常与深度学习相关的数值计算类型（[Abadi et al., 2016](#References_705-736_B978044315888900025X.xhtml#fur1)）。它使用数据流图来表示多维数据数组之间的通信方式。这些多维数组被称为“张量”。TensorFlow 还支持符号微分和在多个 GPU 上的执行。它于 2015 年发布，并采用 Apache 2.0 许可证。在早期版本中，在 TensorFlow 中构建 DNN 模型涉及首先显式指定计算图，然后启动模型运行的会话。现在，在 TensorFlow 版本 2 中，高级 API Keras 与 TensorFlow 更紧密地集成，使开发者能够专注于模型而不是其底层图，并且它现在默认采用即时执行模式，这消除了处理会话的需求并有助于调试。

Keras 是一个深度学习库，允许用户使用简单的 Python 代码指定深度神经网络模型。Keras 强调其易于使用的界面，并需要另一个深度学习框架作为后端。尽管 Keras 之前曾暂时仅支持 TensorFlow，但它目前也支持 PyTorch 和 JAX 后端。

### PyTorch

PyTorch 是一个 Python 机器学习和深度学习框架。它基于 Torch 库，这是一个使用 C 和一种称为 Lua 的高级脚本语言构建的开源机器学习库（[Collobert, Kavukcuoglu, and Farabet, 2011](#References_705-736_B978044315888900025X.xhtml#fur108)），但已在很大程度上用 Python 重写。与 TensorFlow 类似，它使用多维数组数据结构，支持各种基本的数值线性代数操作，并具有神经网络包，其中包含模块，可实现训练神经网络所需的典型前向和后向方法。它还支持自动微分。PyTorch 使用 `dynamic computation graphs`，也称为 `define-by-run` 方法，其中计算图可以在执行期间发生变化。这在处理大小可变的数据（例如文本文档）时很有用，并且简化了调试，因为代码在对应的行执行时运行，从而能够提供更及时的错误信息。它还使 PyTorch 中的编码更接近原生 Python 编码，使其更直观。历史上，就易用性而言，这曾是 PyTorch 相对于 TensorFlow 的优势，后者传统上使用静态计算图。然而，自版本 2.0 起，TensorFlow 具有“即时执行”模式，本质上与动态计算图相同，这缓解了这一问题。由于该模式是可选的，TensorFlow 2 用户可以选择使用它还是坚持使用更快的静态计算图。

### 其他软件包

虽然 TensorFlow、Keras 和 PyTorch 目前是最流行的深度学习框架，但也存在其他选项，包括：

*   • The `Computational Network Toolkit (CNTK)` 是一个用于操作计算网络的 C++ 库（[Yu et al., 2014](#References_705-736_B978044315888900025X.xhtml#fur583)）。它由 Microsoft Research 制作，但已在宽松许可下发布。它在语音和语言处理方面很受欢迎，但也支持用于图像的卷积网络。它支持在多台机器上执行和使用多个 GPU。

*   • `Caffe` 是一个基于 C++ 和 Python 的 BSD 许可的 CNN 库（[Jia et al., 2014](#References_705-736_B978044315888900025X.xhtml#fur290)）。它具有简洁且可扩展的设计，使其成为 Krizhevsky 等人（2012）著名 AlexNet 原始开源实现的流行替代方案，该网络赢得了 2012 年 ImageNet 挑战赛。Facebook 开发了名为 Caffe2 的扩展，但它已合并到 PyTorch 中。
