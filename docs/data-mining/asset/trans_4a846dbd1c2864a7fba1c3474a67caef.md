
4. 我们刚刚构建了一个模型来预测鸢尾花卉的类型。我们也可以预测其他属性之一。`Start` 按钮上方有一个下拉菜单用于选择要预测的属性。选择第一个属性，`sepallength`。这是植物花萼（sepals）的长度，是一个实数，因此预测该属性是一个回归（又名数值预测）任务。使用 Choose 按钮选择 `functions → LinearRegression` 模型。这是一个线性回归模型，它将一条直线拟合到数据上。点击 `Start` 运行线性回归算法。在右侧窗格中阅读结果。`correlation coefficient` 衡量预测与正确答案的相关程度。越高越好，1 是最佳可能值，0 表示没有相关性，而 –1 表示预测与正确答案完全负相关。模型的 `correlation coefficient` 是多少？

本书中的许多技术都会产生对数据中结构模式易于理解的描述。在研究这些技术的工作原理之前，我们必须先了解结构模式如何表达。机器学习可以发现的模式有许多不同的表示方式，每一种方式都决定了可以用来从数据中推断该输出结构的技术类型。一旦你理解了输出如何表示，你就已经在很大程度上理解了它如何生成。

我们在 [第1章](#Ch001_3-42_B9780443158889000029.xhtml#Ch001_3-42_B9780443158889000029)，“它到底是什么？” 中看到了许多机器学习示例。在这些情况下，输出采用决策树和分类规则的形式，它们是许多机器学习方法使用的基本知识表示风格。*知识* 这个词对于决策树或一组规则来说实在太过分了，使用它并不意味着我们要暗示这些结构与我们脑海中*真实*的知识相匹敌；只是我们需要一个词来指代学习方法产生的结构。存在更复杂的规则变体，允许指定异常，并且可以表达不同实例的属性值之间的关系。有些问题具有数值类—as mentioned in [第1章](#Ch001_3-42_B9780443158889000029.xhtml#Ch001_3-42_B9780443158889000029)，“它到底是什么？”—处理这些问题的经典方法是使用线性模型。线性模型也可以改编来处理二元分类。此外，还可以为数值预测开发特殊的树形式。基于实例的表示关注实例本身，而不是支配其属性值的规则。最后，一些学习方案会生成实例的聚类。这些不同的知识表示方法与 [第2章](#Ch002_43-66_B9780443158889000030.xhtml#Ch002_43-66_B9780443158889000030)，“输入：概念、实例、属性。” 中介绍的不同类型的学习问题相对应。

## 3.1 表格

表示机器学习输出的最简单、最原始的方法就是使其与输入相同——一个表格。例如，[表1.2](#Ch001_3-42_B9780443158889000029.xhtml#t0015) 是天气数据的决策表：你只需查找适当条件即可决定是否进行游戏。完全相同的过程也可以用于数值预测——在这种情况下，该结构有时被称为 `regression table`。不太平凡的是，创建决策表或回归表可能涉及选择某些属性。例如，如果温度与决策无关，则缺少该属性的更小、更简洁的表将是更好的指南。当然，问题在于在不影响最终决策的情况下决定省略哪些属性。属性选择在 [第6章](#Ch006_209-259_B9780443158889000078.xhtml#Ch006_209-259_B9780443158889000078)，“准备：数据预处理和探索性数据分析。” 中讨论。

## 3.2 线性模型

另一种简单的表示风格是“线性模型”，其输出只是属性值的总和，只是每个属性在相加前都会应用权重。诀窍在于为权重找到好的值——使模型的输出与期望输出相匹配的值。这里，输出和输入——属性值——都是数值。统计学家使用 *regression* 这个词来表示预测数值量的过程，而“线性回归模型”是这种模型的另一个术语。不幸的是，这与“regression”一词的普通用法没有真正关系，普通用法意为回到先前的状态。

线性模型在二维中最容易可视化，在那里它们相当于在数据点集上画一条直线。[图3.1](#Ch003_67-89_B9780443158889000042.xhtml#f0010) 显示了一条拟合到 [第1章](#Ch001_3-42_B9780443158889000029.xhtml#Ch001_3-42_B9780443158889000029)，“它到底是什么？” 中描述的 CPU 性能数据 ([表1.5](#Ch001_3-42_B9780443158889000029.xhtml#t0030)) 的线，其中仅使用 `cache` 属性作为输入。类属性 `performance` 显示在垂直轴上，`cache` 显示在水平轴上：两者都是数值。直线代表“最佳拟合”预测方程：
