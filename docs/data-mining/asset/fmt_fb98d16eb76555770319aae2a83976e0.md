## Computation Graphs and Backpropagation

Computation networks help to show how the gradients required for deep learning with backpropagation can be computed. They also provide the basis for many software packages for deep learning, which partially or fully automate the computations involved.

We begin with an example that computes intermediate quantities that are scalars and then extend it to networks involving vectors that represent entire layers of variables at each node. [Fig. D.3](#FigD1_687-703_B9780443158889000248.xhtml#f0020) gives a computation graph that implements the function `z[1](y[1],z[2](y[2](y[1]),z[3](y[3](y[2](y[1])))))` and shows how to compute the gradients.
