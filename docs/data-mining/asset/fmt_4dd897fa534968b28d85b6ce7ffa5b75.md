Although `x[i]` is a scalar here, the method generalizes to a vector `x[i]`. Categorical variables can be encoded into a subset of the dimensions of `x` using the so-called “one-hot” method, placing a 1 in the dimension corresponding to the category label and 0 s in all other dimensions allocated to the variable. If all input variables are categorical, this corresponds to the classic *analysis of variance* (ANOVA) method.
