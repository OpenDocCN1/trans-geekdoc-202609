
This trick of transforming a linear prediction method into a nonlinear one while keeping the underlying estimation problem linear can be generalized. The general approach goes by the name of *basis function expansion*. For polynomial regression the polynomial basis given by the rows of the matrix `A` (the powers of `x`) is used. However, any nonlinear function of the inputs `ϕ(x)`![Equation](images/F000157si225.png) could be used to define models of the form

`p(y|x) = N(y; w^T ϕ(x), σ²)`![Equation](images/F000157si226.png)

which also give closed form solutions for a linear parameter estimation problem. We will return to this when discussing kernelizing probabilistic models.

### Multiclass Logistic Regression

Binary logistic regression was introduced in [Section 4.6](#Ch004_91-164_B9780443158889000054_a.xhtml#s0095). Consider now a *multiclass classification problem* where class values are encoded as instances of the random variable `y` ∈ {1,…, `N`}![Equation](images/F000157si227.png) and, as before, feature vectors are instances of a variable `x`. Assume there is no significance to the order of the classes.

A simple linear probabilistic classifier can be created using this parametric form:

$p(y \\mid \\mathbf{x}) = \\frac{\\exp\\left( \\sum\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right)}{\\sum\\limits\_{y}{\\exp\\left( \\sum\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right)}} = \\frac{1}{Z(\\mathbf{x})}\\exp\\left( \\sum\\limits\_{k = 1}^{K}{w\_{k}f\_{k}(y,\\mathbf{x})} \\right),$ (14.7)

![Equation](images/F000157si228.png)(14.7)

which employs `K` feature functions `f[k]`(`y`,`x`) and `K` weights, `w[k]` as the parameters of the model. This is one way of formulating *multinomial logistic regression*.
