尽管有办法使枚举过程更可行，但仍然存在一个严重问题。实际上，过程收敛到一个唯一的可用描述的情况很少见。在示例处理后，要么仍有许多描述在竞争中，要么所有描述符都被淘汰。第一种情况出现在示例不够全面，无法消除所有可能的描述而只留下“正确”的那个时。实际上，人们通常希望得到一个单一的“最佳”描述，有必要应用其他标准从剩余描述集中选出最佳者。第二个问题要么是因为描述语言表达能力不足以捕捉实际概念，要么是因为示例中存在噪声。如果某个示例由于属性值或分配给它的 `class` 中的错误而带有“错误”的分类，这很可能会将正确描述从空间中消除。其结果是剩余描述的集合变得为空。只要示例中存在任何噪声，这种情况就很可能发生，而在人工情况下除外，示例不可避免地会包含噪声。

将泛化视为搜索的另一种看法是，想象它不是枚举描述并剔除不适用的描述的过程，而是在描述空间中进行一种爬山，以找到根据预先指定的匹配标准最能匹配示例集的描述。这就是大多数实用机器学习方法的工作方式。然而，穷举搜索整个空间通常不切实际；许多实用算法涉及启发式搜索，无法保证找到最优描述。

## Bias

将泛化视为在可能概念空间中的搜索，清楚地表明机器学习系统中最重要的决策是：

*   • 概念描述语言；
*   • 搜索空间的顺序；
*   • 避免对特定训练数据过拟合的方式。

这三个属性通常被称为搜索的 `bias`，分别称为 `language bias`、`search bias` 和 `overfitting-avoidance bias`。你通过选择表达概念的语言、通过特定方式搜索可接受的描述，以及决定概念变得多么复杂时需要简化，来对学习方案施加偏置。

### Language Bias

对于 `language bias` 最重要的问题是概念描述语言是否通用，或者它是否对可以学习的概念施加了限制。如果你考虑所有可能示例的集合，概念实际上只是将其划分为子集。在天气示例中，如果你枚举所有可能的天气条件，`play` 概念就是可能天气条件的一个子集。“通用”语言是指能够表达示例的每一个可能子集的语言。实际上，可能示例的集合通常非常庞大，在这方面我们的观点是理论性的，而非实践性的。

如果概念描述语言允许涉及逻辑 *或* 的陈述，即 *析取*（以及逻辑 *且*，即 *合取*），那么任何子集都可以表示。如果描述语言基于规则，则可以通过使用单独的规则来实现析取。例如，一种可能的概念表示只是枚举示例：

```
If outlook = overcast and temperature = hot and humidity = high
```

```
and windy = false then play = yes
```

```
If outlook = rainy and temperature = mild and humidity = high
```

```
and windy = false then play = yes
```

```
If outlook = rainy and temperature = cool and humidity = normal
```

```
and windy = false then play = yes
```

```
If outlook = overcast and temperature = cool and humidity = normal
```

```
and windy = true then play = yes
```

```
…
```

```
If none of the above then play = no
```

这并不是一个特别有启发性的概念描述；它只是记录已观察到的正例，并假设其余的都是负例。每个正例都有自己的规则，概念是规则的析取。另外，你也可以想象为每个负例都有单独的规则——同样是一个无趣的概念。在任何一种情况下，概念描述都不会进行任何泛化；它只是记录原始数据。

另一方面，如果不允许 *析取*，某些可能的概念——示例集合——可能根本无法表示。在这种情况下，机器学习方案可能根本无法取得良好的性能。

另一种 `language bias` 是从所使用特定领域的知识中获得的。例如，某些属性值的组合可能永远不会发生。如果一个属性暗示另一个属性，就会是这种情况。我们在考虑上面描述的大豆问题的规则时看到了一个例子。那么，考虑涉及冗余或不可能的属性值组合的概念就毫无意义了。领域知识可用于缩小搜索空间，但为此可能需要专门技术。知识就是力量——一点点就能走得很远，甚至一个小提示就能显著缩小搜索空间。

### Search Bias

在现实的数据挖掘问题中，有许多可替代的概念描述能够拟合数据，问题在于根据某个标准——通常是简洁性——找到“最佳”一个。我们在统计意义上使用术语 `fit`；我们寻求拟合数据相当好的最佳描述。此外，通常在计算上不可行去搜索整个空间并保证找到的描述确实是最好的。因此，搜索过程是启发式的，无法对最终结果的最优性做出保证。这为偏置留下了充足的空间；不同的搜索启发式以不同的方式偏置搜索。
