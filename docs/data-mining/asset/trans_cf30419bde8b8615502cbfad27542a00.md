
与常规梯度下降类似，在 `SGD` 中引入动量——有时称为 *随机重球法* ——可以帮助优化过程跳出损失函数中的局部最优和平坦区域。如果损失的当前梯度为 `∇[θ]L(θ)`，则动量是通过计算梯度的移动平均并将其添加到 `SGD` 更新中来实现的。它通过添加 `Δθ = − η ∇[θ]L(θ) + α Δθ^(old)` 来更新参数，其中 `α ∈ [0,1]`。由于小批量方法只在数据的一个小子集上操作，这种平均可以使来自其他最近看到的小批量中的信息有助于当前的参数更新。动量值 0.9 通常用作起点，但手动调整它、学习率以及在训练过程中用于修改学习率的调度是常见的。

该方法的变体，称为 *Nesterov 动量*，使用梯度的移动平均来进行“前瞻”。而不是步进到该点，算法会计算该前瞻点的梯度，然后使用这个新的梯度从原始位置进行一步。本质上，该方法能够预测梯度如何变化并利用这些信息来更新其位置。

### 自适应梯度方法
正如我们之前提到的，`SGD` 对所有参数使用单一的学习率。直观上，一些参数在训练期间可能相对稳定，而其他参数可能需要大幅变化，因此某些参数可能需要与其他参数不同的学习率才能快速收敛。如果我们能为每个参数设置不同的学习率，那么已经收敛的参数可以降低其学习率，而那些仍然偏离较远的参数可以更快地移动。如果某些特征是稀疏的且很少出现，我们在看到它们时也希望对其对应的参数更快地移动。*AdaGrad (自适应梯度)* 算法旨在为每个参数自适应地设置学习率。在其实际实现中，`AdaGrad` 维护过去梯度的（逐元素）平方和，并将每个维度的学习率除以对应和的平方根。

`AdaGrad` 的一个优点是它对整体学习率 `η` 相对稳健。然而，它存在一个缺陷，即其每个参数的学习率会被越来越大的值除，最终使学习速度变得极慢。*AdaDelta* 算法是 `AdaGrad` 的一种变体，它通过改用之前梯度的逐元素平方的移动平均来解决这个问题，从而使用于除每个维度学习率的值不会持续增大。`AdaDelta` 还去除了学习率超参数 `η`，减轻了分析人员设置它的负担。如果分析人员希望控制学习率，`RMSProp` 与 `AdaDelta` 相似（并且在大约同一时间独立发明），但它具有可设置的学习率。

截至撰写时，深度学习中最流行的优化器是 *Adam (自适应矩估计)*，它是 `RMSProp` 的一种变体，使用每个参数过去梯度的移动平均来进行更新，而不是当前梯度。（它还包含一些项来纠正由于初始化方式导致的向零的偏差。）

在这些学习算法之间进行选择时，值得注意的是，一些研究发现，在某些情况下，`SGD`（有或没有动量）在泛化性能上可能优于这些更复杂的自适应梯度方法。虽然其确切原因尚不完全清楚，但学习算法与它倾向于找到的局部最优之间存在复杂关系——在学习算法逃离某些局部最优的能力（或不能）方面——这方面的差异可能起作用。直观上，过拟合也可能是这种差距的一部分原因，也许自适应梯度方法对训练数据拟合得 *太* 好。尽管如此，自适应梯度方法的更快收敛使其成为许多深度学习应用中的首选方法。`AdaGrad`、`AdaDelta` 和 `RMSProp` 是 `Adam` 的前身，在某些情况下可能与之表现一样好。它们可以相当互换使用。`Adam` 通常与这些方法表现一样好，尽管可能存在例外。它是一个很好的优化器默认选择。如果可行，对学习算法及其超参数进行网格搜索，并在验证集上衡量性能，将揭示特定问题的最佳选择。

### 参数先验正则化
许多标准的参数正则化技术适用于深度网络。我们之前提到，对应于参数高斯先验的 `L2` 正则化已在神经网络中以“weight decay”的名称使用。与逻辑回归一样，这种正则化通常只应用于网络中的权重，而不应用于偏置。 alternatively，`L2` 和 `L1` 正则化的加权组合，`λ2 R[L2](θ) + λ1 R[L1](θ)`，可以应用于网络中的权重，如在 [第 14.4 节](#Ch015_516-570_B9780443158889000157_a.xhtml#s0160) 中讨论的弹性网络模型。尽管深度学习中使用的损失函数通常不是凸的，但此类正则化器仍然可以实现。
