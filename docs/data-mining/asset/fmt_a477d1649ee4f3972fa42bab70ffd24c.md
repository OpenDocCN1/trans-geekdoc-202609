If `n[k]` is the number of times that each class `k` in the data has been observed, the log-likelihood of the data is

$\\log P\\left( {n\_{1},\\ldots,n\_{K};\\mathbf{\\pi}} \\right) = \\sum\\limits\_{k = 1}^{K}n\_{k}\\log\\pi\_{k}.$<mml:math><mml:mi>log</mml:mi><mml:mspace width=".25em" /><mml:mi>P</mml:mi><mml:mrow><mml:mo stretchy="true">(</mml:mo><mml:mrow><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mn>1</mml:mn></mml:mrow></mml:msub><mml:mo>,</mml:mo><mml:mi>&#8230;</mml:mi><mml:mo>,</mml:mo><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>K</mml:mi></mml:mrow></mml:msub><mml:mo>;</mml:mo><mml:mi mathvariant="bold">&#960;</mml:mi></mml:mrow><mml:mo stretchy="true">)</mml:mo></mml:mrow><mml:mo>=</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mspace width=".25em" /><mml:mi>log</mml:mi><mml:mspace width=".25em" /><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>.</mml:mo></mml:math>

To ensure that the parameter vector defines a valid probability the log-likelihood is augmented with a term involving a `Lagrange multiplier` `λ` that enforces the constraint that the probabilities sum to one:

$L = \\sum\\limits\_{k = 1}^{K}n\_{k}\\log\\pi\_{k} + \\text{λ}\\left\\lbrack {1 - \\sum\\limits\_{k = 1}^{K}\\pi\_{k}} \\right\\rbrack.$<mml:math><mml:mi>L</mml:mi><mml:mo>=</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mspace width=".25em" /><mml:mi>log</mml:mi><mml:mspace width=".25em" /><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>+</mml:mo><mml:mtext>&#955;</mml:mtext><mml:mrow><mml:mo stretchy="true">\[</mml:mo><mml:mrow><mml:mn>1</mml:mn><mml:mo>&#8722;</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub></mml:mrow><mml:mo stretchy="true">\]</mml:mo></mml:mrow><mml:mo>.</mml:mo></mml:math>

![Equation](images/F000212si121.png)

Taking the derivative of this function with respect to `λ` and setting the result to zero tells us that the sum over the probabilities in our model should be 1 (as desired). We then take the derivative of the function with respect to each parameter and set it to zero, which gives

$\\left. \\frac{\\partial L}{\\partial\\pi\_{k}} = 0\\Rightarrow n\_{k} = \\text{λ}\\pi\_{k}. \\right.$<mml:math><mml:mfrac><mml:mrow><mml:mi>&#8706;</mml:mi><mml:mi>L</mml:mi></mml:mrow><mml:mrow><mml:mi>&#8706;</mml:mi><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub></mml:mrow></mml:mfrac><mml:mo>=</mml:mo><mml:mn>0</mml:mn><mml:mo>&#8658;</mml:mo><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:mtext>&#955;</mml:mtext><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>.</mml:mo></mml:math>

![Equation](images/F000212si122.png)

We can solve for `λ` by summing both sides over `k`:

$\\left. \\sum\\limits\_{k = 1}^{K}n\_{k} = \\text{λ}\\sum\\limits\_{k = 1}^{K}\\pi\_{k}\\Rightarrow\\text{λ} = \\sum\\limits\_{k = 1}^{K}n\_{k} = N. \\right.$<mml:math><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:mtext>&#955;</mml:mtext><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>&#8658;</mml:mo><mml:mtext>&#955;</mml:mtext><mml:mo>=</mml:mo><mml:munderover><mml:mo>&#8721;</mml:mo><mml:mrow><mml:mi>k</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:mrow><mml:mi>K</mml:mi></mml:munderover><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:mi>N</mml:mi><mml:mo>.</mml:mo></mml:math>

Therefore we can determine that the gradient of the augmented objective function is zero when

$\\pi\_{k} = \\frac{n\_{k}}{N}.$<mml:math><mml:msub><mml:mrow><mml:mi>&#960;</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:mo>=</mml:mo><mml:mfrac><mml:mrow><mml:msub><mml:mrow><mml:mi>n</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub></mml:mrow><mml:mi>N</mml:mi></mml:mfrac><mml:mo>.</mml:mo></mml:math>
