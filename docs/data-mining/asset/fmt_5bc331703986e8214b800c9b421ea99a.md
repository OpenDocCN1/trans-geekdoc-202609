While sigmoid functions have been popular, the hyperbolic tangent function (`tanh`) is sometimes preferred, partly because it has a steady state at 0. However, more recently the `rectify()` function or `rectified linear units` (`ReLUs`) have been found to yield superior results in many different settings. Since this function is 0 for negative argument values, some units in the model will yield activations that are 0, giving a “sparseness” property that is useful in many contexts. Moreover, the gradient is particularly simple—either 0 or 1.
