
# WEKA 概述

WEKA 由新西兰怀卡托大学开发；其名称代表 `Waikato Environment for Knowledge Analysis`。在大学之外，WEKA，发音与 `Mecca` 押韵，是一种好奇心强的无飞行鸟类，仅分布于新西兰群岛。该系统用 Java 编写，并在 GNU 通用公共许可证条款下分发。它可在几乎任何平台上运行，并已在 Linux、Windows 和 Macintosh 操作系统下测试。

## B.1 WEKA 中有什么？

WEKA 提供了可轻松应用于您数据集的学习算法实现。它还包含多种用于转换数据集的工具，例如离散化和采样算法。您可以预处理数据集，将其输入学习方案，并分析由此产生的分类器及其性能——所有这些都不需要编写任何程序代码。

工作台包含主要数据挖掘问题的方法：回归、分类、聚类、关联规则挖掘和属性选择。了解数据是工作的不可或缺的一部分，并提供了许多数据可视化设施和数据预处理工具。所有算法都以单个关系表的形式接受输入，该表可以从文件读取或由数据库查询生成。

使用 WEKA 的一种方法是应用学习方法到数据集并分析其输出以更深入地了解数据。另一种是使用学习到的模型对新实例进行预测。第三种是应用几种不同的学习器并比较其性能以选择用于预测的学习器。在交互式 WEKA 界面中，您可以从菜单中选择所需的学习方法。许多方法具有可调参数，您可以通过属性表或 `object editor` 访问。通用评估模块用于衡量所有分类器的性能。

实际学习方案的实现是 WEKA 提供的最有价值的资源。但用于预处理数据的工具，称为 `filters`，紧随其后。像分类器一样，您可以从菜单中选择过滤器并根据自己的需求进行定制。

### 如何使用它？

使用 WEKA 最简单的方式是通过名为 `Explorer` 的图形用户界面。它使用菜单选择和表单填写提供对所有功能的访问。例如，您可以快速从文件读取数据集并从中构建决策树。Explorer 通过以待填写的表单形式呈现选项来指导您。有用的 `tool tips` 会在鼠标经过屏幕上的项目时弹出以解释其作用。合理的默认值确保您可以用最少的努力获得结果——但您必须思考自己在做什么才能理解结果的含义。

WEKA 还有另外三个图形用户界面。`Knowledge Flow` 界面允许您为流式数据处理设计配置。Explorer 的一个根本缺点是它将所有内容保存在主内存中；打开数据集时它会立即全部加载。这意味着它只能应用于小型到中型问题。然而，WEKA 包含一些可用于处理非常大数据集的增量算法。Knowledge Flow 界面让您可以拖动代表学习算法和数据源的框在屏幕上移动并将其连接成所需的配置。它允许您通过连接代表数据源、预处理工具、学习算法、评估方法和可视化模块的组件来指定数据流。如果过滤器和学习算法能够进行增量学习，数据将被增量加载和处理。

WEKA 的第三个界面 `Experimenter`，旨在帮助您在应用分类和回归技术时回答一个基本实践问题：Which methods and parameter values work best for the given problem？通常无法先验地回答这个问题，我们开发工作台的一个原因就是提供一个环境，使 WEKA 用户能够比较各种学习技术。这可以使用 Explorer 交互完成。然而，Experimenter 通过使您能够轻松地在数据集语料库上使用不同的参数设置运行分类器和过滤器、收集性能统计信息并执行显著性检验，从而使该过程自动化。高级用户可以利用 Experimenter 使用 Java 远程方法调用在多台机器上分发计算负载。这样您就可以设置大规模统计实验并让其运行。

第四个界面称为 `Workbench`，它是一个统一的图形用户界面，将其他三个（以及用户安装的任何插件）组合成一个应用程序。Workbench 高度可配置，允许用户指定将出现哪些应用程序和插件，以及与其相关的设置。

这些交互式界面背后是 WEKA 的基本功能。可以通过输入文本命令以原始形式访问它，从而访问系统的所有功能。启动 WEKA 时，您必须通过 WEKA GUI Chooser 在五个不同的用户界面中进行选择：the Explorer, Knowledge Flow, Experimenter, Workbench, and command-line interfaces（我们在此附录中不考虑命令行界面）。大多数人至少最初会选择 Explorer。

### 还能做什么？

使用 WEKA 时的一个重要资源是在线文档，它是从源代码自动生成的，并简洁地反映了其结构。在线文档提供了可用算法的唯一完整列表，因为 WEKA 不断增长——并且由于它是从源代码自动生成的——在线文档始终是最新的。此外，如果您想进入下一级并从自己的 Java 程序访问库或编写和测试自己的学习方案，它就变得必不可少。

在大多数数据挖掘应用中，机器学习组件只是更大软件系统中的一小部分。如果您打算编写数据挖掘应用程序，您将希望从自己的代码内部访问 WEKA 中的程序。通过这样做，您可以用最少的额外编程解决应用程序的机器学习子问题。

如果您打算成为机器学习算法专家（或者，事实上，如果您已经是专家），您可能希望实现自己的算法，而无需处理读取文件中的数据、实现过滤算法或提供代码来评估结果等琐碎细节。如果是这样，我们有一个好消息——WEKA 已经包含了所有这些。要充分利用它，您必须熟悉基本数据结构。

讨论这些高级用户机会并描述命令行界面的本附录扩展版本可在 [https://ml.cms.waikato.ac.nz/weka/book.html](https://ml.cms.waikato.ac.nz/weka/book.html) 获取。

## B.2 包管理系统

自本书第三版出版以来，WEKA 软件已发生了相当大的发展。许多新算法和功能已添加到系统中，其中一些由社区贡献。由于提供的算法如此之多，我们认为该软件对新用户来说可能令人不知所措。因此，一些算法和社区贡献被移除并放入插件 `packages` 中。添加了一个包管理系统，允许用户浏览并有选择地安装感兴趣的包。
