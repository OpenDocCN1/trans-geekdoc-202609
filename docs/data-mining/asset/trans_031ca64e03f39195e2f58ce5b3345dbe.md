
- `Deeplearning4j` 是一个基于 Java 的开源深度学习库，采用 Apache 2.0 许可证发布。它使用多维数组类，并提供与 `NumPy` 提供的类似的线性代数和矩阵操作支持。
- `Lasagne` 是一个轻量级的 Python 库，构建于 `Theano` 之上，简化了神经网络层的创建。类似地，`Keras` 是一个 Python 库，可运行于 `Theano` 或 `TensorFlow` 之上（[Chollet, 2015](#References_705-736_B978044315888900025X.xhtml#fur99)）。它允许快速以层的方式定义网络架构，并包含图像和文本预处理的功 能。
- `NVIDIA CUDA® Deep Neural Network library (cuDNN)` 是一个针对 NVIDIA 设备的高度优化的 GPU 库，可使深度网络更快地训练。它可以显著加速深度网络的性能，并且经常被前面提到的其他软件包调用。
- `JAX` 是 Google 的另一个近期框架，目前仍处于开发和研究阶段，可自动微分原生 Python 和 `NumPy` 函数。
- `Theano` 曾是一个开创性的开源深度学习平台，由于来自工业界开发的平台的激烈竞争，且这些平台也挖走了其大部分开发人才，因此已不再积极开发。`Theano` 的一个版本以 `PyTensor` 的形式延续下来，后者是概率编程语言 `PyMC3` 背后的计算后端。
- `MXNet` 是由 Apache 软件基金会开发的开源深度学习框架，但已不再积极开发。它强调灵活性、速度和可扩展性，并支持八种编程语言：Python、Scala、Julia、Clojure、Java、C++、R 和 Perl。

## 10.8 WEKA 实现

深度学习可以在 `WEKA` 中通过三种方法实现：
- 使用 `deepLearningForJ` 包中可用的第三方 `DeepLearningForJ` 包的包装分类器。
- 使用 `RPlugin` 包中的 `MLRClassifier` 来利用 R 中的深度学习实现。
- 通过 `PyScript` 包访问基于 Python 的深度学习库。
