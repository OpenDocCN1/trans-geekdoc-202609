
## EM 算法简化

EM 算法可以通过取 `σ²` 趋近于零的极限来进一步简化。这就是 *零输入噪声* 情况，且意味着 `M = W W^T`。定义矩阵 `Z = E[H]`，其每一列包含来自 $P(\mathbf{h}_i|\tilde{\mathbf{x}}_i)$ 的期望向量，对应于其中一个隐变量 `h_i`，使得 `E[H H^T] = E[H] E[H^T] = Z Z^T`。这为 E 步和 M 步得出了简单而优雅的方程：

```
E-Step: Z = E[H] = (W^T W)^{-1} W^T \tilde{X}
M-Step: W^{New} = \tilde{X} Z^T [Z Z^T]^{-1}
```

![Equation](images/F000157si84.png)

其中两个方程都作用于整个数据矩阵 `\tilde{X}`。
![Equation](images/F000157si85.png)

主成分分析的概率表述允许定义传统的似然，从而支持基于最大似然的学习和概率推理。这进而导致了处理缺失数据的自然方法。它也引出了后面讨论的其他模型。

### 潜在语义分析

[第 6 章](#Ch006_209-259_B9780443158889000078.xhtml#Ch006_209-259_B9780443158889000078)，“Preparation: data preprocessing and exploratory data analysis，”介绍了主成分分析，正如我们所见，它可以被视为一种线性高斯潜在变量模型。我们现在讨论一种有影响力的数据驱动文档分析的早期形式，称为“潜在语义分析”（LSA），它使用奇异值分解将集合中的每个文档分解为 *主题*。如果文档和词项被投影到主题空间，则可以进行比较，从而捕捉到文档中由集合中词语共现产生的语义结构。这种方式表征文档称为“潜在语义索引”。概率 LSA（pLSA）解决类似目标，但应用基于多项式分布的统计模型。潜在狄利克雷分配是相关模型，它使用分层贝叶斯方法，其中狄利克雷先验被置于底层多项式分布上。
