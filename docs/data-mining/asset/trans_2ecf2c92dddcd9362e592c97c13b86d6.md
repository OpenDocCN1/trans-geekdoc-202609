为了最大化准确性，通常有必要结合从相同数据学习到的多个模型的预测结果，我们现在转向实现这一目标的技术。里面有一些惊喜。例如，通常有利的做法是从训练数据中派生出多个不同的训练集，从每个训练集学习一个模型，然后将它们组合起来形成一个学习模型集成。事实上，实现这一点的技术可以非常强大。可以将一个相对较弱的学习方案转变为极其强大的方案（在我们将要解释的精确意义上）。可解释性的丧失是在应用集成学习时的一个缺点，但存在基于这些方法所学习内容推导出可理解结构化描述的方法。最后，如果有几种学习方案可用，使用交叉验证选择在你的数据集上表现最好的方案可能并非最有利的做法，而是将它们全部使用并组合结果。

许多这些结果乍一看相当违反直觉。怎么可能同时使用许多不同的模型是个好主意？怎么可能比选择表现最好的模型做得更好？这显然违背了奥卡姆剃刀，该剃刀主张简洁。怎么可能通过组合平庸的模型获得一流的性能，而其中一种技术似乎就是这样做的？但请考虑人类委员会，它们经常做出比个人专家更明智的决策。回想一下伊壁鸠鲁的观点，面对替代解释时，应该全部保留。想象一个专家小组，每个人都在有限的领域中表现出色，尽管没有人能全面胜任。在努力理解这些方法如何工作时，研究人员揭示了各种各样的联系和关联，从而带来了更大的改进。

## 8.1 组合多个模型

当明智的人做出关键决策时，他们通常会考虑多个专家的意见，而不是依赖自己的判断或某个单独值得信赖的顾问的意见。例如，在选择重要的新政策方向之前，仁慈的独裁者会广泛征求意见；他或她如果盲目遵循某一位专家的意见将是不明智的。在民主环境中，对不同观点的讨论可能会产生共识；如果没有共识，则可能需要投票。在任何一种情况下，不同专家的意见都在被组合。

在数据挖掘中，由机器学习生成的模型可以被视为一个专家。*专家*这个词可能太强了！，这取决于训练数据的数量和质量。无论学习算法是否适合手头的问题，专家在事实上可能遗憾地无知，但我们仍然使用这个术语。使决策更可靠的一个明显方法是组合多个不同模型的输出。几种机器学习技术通过学习模型集成并组合使用它们来实现这一点——其中最突出的是称为 `bagging`、`boosting` 和 `stacking` 的方案。它们在大多数情况下都能提高单个模型的预测性能。而且它们是通用技术，可应用于分类任务和数值预测问题。

`Bagging`、`boosting` 和 `stacking` 在过去二十年左右的时间里发展起来，它们的性能通常惊人地好。机器学习研究人员一直在努力理解原因。在这种努力过程中，出现了有时甚至更好的新方法。例如，人类委员会很少从嘈杂的干扰中受益，通过添加分类器的随机变体来扰乱 `bagging` 可以提高性能。更深入的分析揭示了 `boosting`——也许是三种方法中最强大的——与已建立的统计技术加性模型密切相关，这一认识导致了改进的程序。

这些组合模型共同的缺点是相当难以分析。它们可能包含数十甚至数百个单独的模型，虽然它们性能良好，但很难直观地理解是什么因素促成了改进的决策。然而，已经开发出将委员会的性能优势与可理解模型相结合的方法。有些产生决策树模型；另一些引入了提供可选路径的树的新的变体。

## 8.2 自助法

组合不同模型的决策意味着将各种输出合并为一个单一预测。在分类情况下，最简单的方法是投票（可能是加权投票）；在数值预测情况下，则是计算平均值（可能是加权平均值）。`Bagging` 和 `boosting` 都采用这种方法，但它们以不同的方式推导出各个模型。在 `bagging` 中，模型权重相等，而在 `boosting` 中，使用权重使更成功的模型具有更大的影响力——正如高管可能会根据不同专家过去预测的成功程度对他们的建议赋予不同的价值一样。

为了介绍 `bagging`，假设从问题域中随机选择了几个相同大小的训练数据集。想象使用特定的机器学习技术为每个数据集构建一棵决策树。你可能会期望这些树几乎相同，并且对每个新的测试实例做出相同的预测。但令人惊讶的是，这个假设通常是完全错误的，特别是如果训练数据集相当小的话。这是一个相当令人不安的事实，似乎给整个事业蒙上了阴影！其原因在于决策树归纳（至少是[第4章](#Ch004_91-164_B9780443158889000054.xhtml#Ch004_91-164_B9780443158889000054)：“算法：基本方法”中描述的标准自顶向下方法）是一个不稳定的过程——训练数据的细微变化很容易导致在特定节点上选择不同的属性，从而对该节点下方的子树结构产生重大影响。这自动意味着存在某些测试实例，其中一些决策树产生正确预测，而另一些则没有。

回到之前的专家类比，将专家视为单个决策树。我们可以通过让它们对每个测试实例投票来组合树。如果一个类别获得的票数多于其他任何类别，则将其视为正确答案。一般来说，人越多越好；随着考虑的票数越多，投票做出的预测变得越可靠。如果发现新的训练集，为它们构建树并让它们的预测也参与投票，决策很少会变差。特别是，组合分类器的准确性很少会低于仅从其中一个数据集构建的决策树。（然而，改进并非 guaranteed。可以从理论上证明存在病态情况，其中组合决策更差。）
