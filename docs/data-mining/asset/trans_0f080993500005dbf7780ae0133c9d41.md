
# 概率建模基础

## 随机变量的记号

在概率建模中，示例数据或实例通常被视为底层 `random variables` 的事件、观测值或实现。给定离散随机变量 `A`，`P`(`A`) 是一个函数，编码了 `A` 可能处于的每个类别、类或状态的概率。类似地，对于连续随机变量 `x`，`p`(`x`) 是一个函数，将概率密度分配给 `x` 的所有可能取值。相反，`P`(`A` = `a`) 是观察到特定事件 `A = a` 的单一概率。这种记号通常简化为 `P`(`a`)，但需要注意 `a` 是定义为随机变量还是观测值。对于连续随机变量 `x` 取值为 `x`[1] 的观测情况也是如此。通常将此概率密度写为 `p`(`x`[1])，但这是对更长但更清晰的记号 `p`(`x` = `x`[1])<mml:math><mml:mi>p</mml:mi><mml:mo stretchy="false">(</mml:mo><mml:mi>x</mml:mi><mml:mo>=</mml:mo><mml:msub><mml:mrow><mml:mi>x</mml:mi></mml:mrow><mml:mrow><mml:mn>1</mml:mn></mml:mrow></mml:msub><mml:mo stretchy="false">)</mml:mo></mml:math>![Equation](images/F000145si1.png) 的简化，后者强调它是函数在 `x` = `x`[1] 处求值得到的标量值。

有几条概率论规则对本书特别相关。它们有各种名称，但我们将分别称之为乘积规则、求和（或边缘化）规则和贝叶斯规则。正如我们将看到的，这些看似简单的规则可以带我们走得很远。

为了保持记号简单，后文使用了离散或二元事件。然而，这些规则可以应用于 `binary`、`discrete` 或 `continuous` 事件和变量。对于连续变量，可能状态上的求和被积分取代。

## 核心概率规则

### 乘积规则
