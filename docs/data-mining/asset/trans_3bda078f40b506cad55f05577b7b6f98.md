

我们将同时处理多个查询。设 `Q` 为包含 `n_q` 个查询的矩阵，其中每一行对应一个查询的 `d_k` 维 *查询嵌入*，设 `K` 为包含 `n_i` 个键的矩阵，其中每一行对应一个项目的 `d_k` 维 *键嵌入*，并设 `V` 为包含 `n_i` 个值的矩阵，其中每一行对应一个项目的 `d_v` 维 *值嵌入*。`Q`、`K` 和 `V` 中的嵌入都是可以从数据中学习到的模型参数，或者在某些情况下作为预训练嵌入提前提供。缩放点积注意力计算如下（[图 11.8](#Ch012_433-471_B9780443158889000121.xhtml#f0045)）：

```
Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
```

这里，对于 `Q` 中的每个查询，`softmax` 会产生对项目的注意力权重。`softmax` 的输入是查询和键之间的点积，按因子 `1/sqrt(d_k)` 缩放，目的是防止向量的维度对输出的尺度产生影响。同时应用于所有查询，`softmax` 会生成查询 × 项目矩阵 `A`，其为 *注意力权重*，行之和为一。将此矩阵 `A` 与 `V` 相乘后，缩放点积注意力的最终输出是一个 `n_q` × `d_v` 矩阵，其中每一行包含一个查询的输出，由项目的 值嵌入 按其注意力权重加权平均而成。

在某些情况下，我们希望排除某些项目使其不获得任何注意力。例如，在基于 Transformer 的语言模型中，我们有时希望防止模型查看文档中后面的词，以便仅基于“过去”来预测“未来”。该方法的一种变体，称为 *掩蔽缩放点积注意力*，会将 `softmax` 的输入替换为 −∞，用于任何应为特定查询排除的项目，从而有效地将其注意力权重强制为零。

## 多头注意力

正如我们之前提到的，基于 Transformer 的语言模型的目标是用能够解决其局限性的东西取代 RNN 和 CNN 架构。这意味着我们需要设计架构，使其具有至少与这些模块一样强的表征能力。具体来说，CNN 使用多个滤波器在每一层创建表示，其中每个滤波器捕获一种类型的模式或特征。多个滤波器共同构成单个 CNN 层，每个滤波器捕获不同的模式，该层输出多维向量表示，其中每个维度捕获数据的不同且互补的属性，以便将足够的相关信息传递给后续层。类似地，RNN 在每一层使用多个 RNN 单元来捕获多个模式，在网络的每个 RNN 层产生多维表示。

在 Transformer 中，如果我们要用仅注意力的方法取代 RNN 和 CNN 层，那么我们需要一种类似的方法。相应的概念称为 *多头注意力*。其思想是多次执行缩放点积注意力，每次使用各自学习到的 `Q`、`K` 和 `V` 参数矩阵。最后，从多头注意力模块学习到的表示是这些注意力函数输出的拼接。
