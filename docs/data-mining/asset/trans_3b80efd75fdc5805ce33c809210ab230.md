其中，如前所述，模型以可见层 `v` 和 `l` = `l`, …, `L` 个隐藏层 `h`^(`l`) 定义。条件分布都是 `Bernoulli` 分布的乘积，具有 sigmoid 参数化。

顶部的两层被参数化为一个 `RBM`。如果它们具有有向而非无向连接，则可以分解为形式 `P`(`h`^(`L`−1), `h`^(`L`)) = `P`(`h`^(`L`−1)|`h`^(`L`)) `P`(`h`^(`L`))，其中条件分布是另一个 sigmoid 参数化的 `Bernoulli` 乘积，而 `P`(`h`^(`L`)) 是对每个 `P`(`h`^(`L`)) 的单独分布的乘积。该结果被称为深度 sigmoid 信念网络。
