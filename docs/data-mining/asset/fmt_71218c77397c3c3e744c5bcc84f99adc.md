## Variational Methods and the EM Algorithm
With a complex probability model for which the posterior distribution cannot be computed exactly a method called *variational expectation-maximization (EM)* can be used. This involves manipulating approximations to the model’s true posterior distribution during an EM optimization procedure. The following variational analysis also helps to show why and how the EM algorithm involving exact posterior distributions works.
