线性回归是一种优秀且简单的数值预测方法，已在统计应用中广泛使用数十年。当然，基础线性模型存在一个缺点，那就是线性。如果数据表现出非线性依赖关系，将找到最佳拟合直线，其中“最佳”被解释为最小均方差。这条线可能拟合得并不好。然而，线性模型作为更复杂学习方法的构建模块或起点非常有用。

### 线性分类：逻辑回归

线性回归可以很容易地用于具有数值属性的域中的分类。确实，我们可以使用*任何*回归技术进行分类。诀窍是对每个类别执行一次回归，对于属于该类别的训练实例将输出设为一，对于不属于该类别的实例设为零。结果是类别的线性表达式。然后，给定类别未知的测试示例，计算每个线性表达式的值并选择最大者。与线性回归一起使用时，该方案有时被称为*多响应线性回归*。

看待多响应线性回归的一种方式是想象它为每个类别近似一个数值*隶属函数*。隶属函数对于属于该类别的实例为 1，对于其他实例为 0。给定一个新实例，我们计算其对每个类别的隶属度并选择最大者。

多响应线性回归在实践中通常能产生良好的结果。然而，它有两个缺点。首先，它产生的隶属值不是正确的概率，因为它们可能超出 0–1 范围。其次，最小二乘回归假设误差不仅在统计上相互独立，而且服从相同标准差的正态分布，这一假设在该方法应用于分类问题时被明显违反，因为观测值只能取 0 和 1。

一种相关的统计技术称为*逻辑回归*不会受到这些问题的困扰。不是直接近似 0 和 1 值，从而在目标被高估时冒着产生非法概率值的风险，逻辑回归基于转换后的目标变量构建线性模型。

假设首先只有两个类别。逻辑回归用以下方式替换原始目标变量

`Pr`\[1∣`a`[1],`a`[2],…,`a`[`k`]\],
