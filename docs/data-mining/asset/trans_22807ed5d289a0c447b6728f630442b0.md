## 变分自编码器

变分自编码器 (`VAEs`) 是 `GANs` 的一种替代方案，也是使用神经网络生成许多类型逼真数据的强大方法。`GANs` 试图直接学习如何生成逼真的样本，而 `VAEs` 在过程中进行一些概率建模和推理。这使我们能够更明确地表示模型下的数据分布。如果我们想要有意义地改变分布，这也可能让我们获得更多的控制。另一方面，假设的概率模型本质上是对数据的假设，可能准确、有用或合适，也可能不准确、无用或不合适。
