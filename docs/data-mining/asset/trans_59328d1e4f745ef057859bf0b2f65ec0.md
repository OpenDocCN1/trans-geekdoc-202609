
# Dropout
Dropout 是一种正则化方法，在训练过程中随机删除单元及其连接，目的是减少隐藏单元协同适应的程度，从而对抗过拟合。有 人认为这相当于从具有共享参数但部分连接缺失的指数级数量的网络中进行采样。然后在测试时通过使用原始网络（没有丢弃的连接但权重已缩小）对其进行平均。如果一个单元在训练期间以概率 `p` 被保留，则在测试时对其输出权重进行重新缩放或乘以 `p` 的因子。实际上，通过执行 Dropout，具有 `n` 个单元的神经网络可以表现得像 `2^n` 个较小网络的集成。

实现 Dropout 的一种方法是为网络中的每个隐藏层 `l` 使用二元掩码向量 `m^{(l)}`；`h^{(l)}` 的丢弃版本使用逐元素乘法屏蔽原始版本中的单元，`h[d]^{(l)} = h^{(l)} ⊙ m^{(l)}`![方程](images/F00011Xsi62.png)。如果激活函数导致对角梯度矩阵，则反向传播更新为 `Δ^{(l)} = d^{(l)} ⊙ m^{(l)} ⊙ (W^{(l+1)} Δ^{(l+1)})`![方程](images/F00011Xsi63.png)。

## 批归一化
批归一化是一种加速训练的方法，许多研究发现使用它对于在基准问题上获得最先进的结果很重要。使用批归一化，神经网络中每一层的每个元素都根据其在 mini-batch 内的统计信息归一化为零均值和单位方差。这可能会改变网络的表达能力，因此每个激活都赋予一个学习到的缩放和偏移参数。基于 mini-batch 的随机梯度下降通过计算每个层中每个隐藏单元 `h[j]` 在批次上的均值 `μ[j]` 和方差 `σ[j]²`，然后归一化单元，使用学习到的缩放参数 `γ[j]` 对其进行缩放，并使用学习到的偏移参数 `β[j]` 对其进行偏移来进行修改：

```
\hat{h}_j ← γ_j (h_j - μ_j) / sqrt(σ_j² + ε) + β_j
```

![方程](images/F00011Xsi68.png)
当然，为了更新缩放和偏移参数，需要将损失的梯度通过这些额外参数进行反向传播。

## 参数初始化
在训练开始前用于初始化参数的策略可能具有欺骗性的重要性。偏置项通常初始化为 0，但初始化权重矩阵可能很棘手。例如，如果它们被初始化为全 0，则可以证明 tanh 激活函数将产生零梯度。如果权重都相同，隐藏单元将产生相同的梯度并彼此表现相同，从而浪费模型的容量。

一种解决方案是从区间 `[-b, b]` 上的均匀分布初始化权重矩阵的所有元素。已经提出了多种选择 `b` 值的方法，通常动机是具有更多输入的单元应具有较小的权重。例如，对于给定的层 `l`，可以按 `h^{(l-1)}(x)` 的维度的平方根的倒数来缩放 `b`![方程](images/F00011Xsi69.png)，称为“fan-in size”。或者也可以纳入 fan-out size。

ReLU 的权重矩阵已成功使用零均值各向同性高斯分布进行初始化，标准差为 0.01。
