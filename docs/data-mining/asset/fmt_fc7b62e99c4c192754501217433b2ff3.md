
Full-blown second-order methods take more effective steps at each iteration. However, they can be expensive because of the need to compute this quantity. For convex problems like logistic regression, a popular second-order method known as `L-BFGS` builds an approximation to the Hessian. Here, L stands for limited memory and `BFGS` stands for the inventors of the approach, Broyden–Fletcher–Goldfarb–Shanno. Another family of approaches are known as the conjugate gradient algorithms and involve working with the linear system of equations associated with `H`[`o`]`x` =  − `g`[`o`]<mml:math><mml:msub><mml:mrow><mml:mi mathvariant="bold">H</mml:mi></mml:mrow><mml:mrow><mml:mi>o</mml:mi></mml:mrow></mml:msub><mml:mi mathvariant="bold">x</mml:mi><mml:mo>=</mml:mo><mml:mo>&#8722;</mml:mo><mml:msub><mml:mrow><mml:mi mathvariant="bold">g</mml:mi></mml:mrow><mml:mrow><mml:mi>o</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000212si41.png) when solving for `x` = `Δθ`<mml:math><mml:mi mathvariant="bold">x</mml:mi><mml:mo>=</mml:mo><mml:mi mathvariant="normal">&#916;</mml:mi><mml:mi mathvariant="bold">&#952;</mml:mi></mml:math>![Equation](images/F000212si42.png) as opposed to computing the inverse of `H`[`o`]<mml:math><mml:msub><mml:mrow><mml:mi mathvariant="bold">H</mml:mi></mml:mrow><mml:mrow><mml:mi>o</mml:mi></mml:mrow></mml:msub></mml:math>![Equation](images/F000212si43.png).

One needs to keep in mind that when solving nonconvex problems (e.g., learning for multilayer neural networks) the Hessian is not guaranteed to be positive definite, which means that it may not even be invertible. ## Eigenvectors, Eigenvalues, and Covariance Matrices

There is a strong connection between eigenvectors, eigenvalues, and diagonalization of a covariance matrix and the method of principal component analysis. If `λ` is a scalar eigenvalue of a matrix `A`, there exists a vector `x` called an eigenvector of `A` such that `A x` = `λ x`<mml:math><mml:mi mathvariant="bold-italic">Ax</mml:mi><mml:mo>=</mml:mo><mml:mi>&#955;</mml:mi><mml:mi mathvariant="bold-italic">x</mml:mi></mml:math>![Equation](images/F000212si44.png). Define a matrix `Φ` to consist of eigenvectors in each column, and define `Λ` as a matrix with the corresponding eigenvalues on the diagonal then the matrix equation `A Φ` = `Φ Λ`<mml:math><mml:mi mathvariant="bold">&#913;</mml:mi><mml:mi mathvariant="bold">&#934;</mml:mi><mml:mo>=</mml:mo><mml:mi mathvariant="bold">&#934;</mml:mi><mml:mi mathvariant="bold">&#923;</mml:mi></mml:math>![Equation](images/F000212si45.png) defines the eigenvalues and eigenvectors of `A`.

Many numerical linear algebra software packages (e.g., `Matlab`) can determine solutions to this equation. If the eigenvectors in `Φ` are orthogonal, which they are for symmetric matrices, the inverse of `Φ` equals its transpose, which implies that we could equally well write `Φ^T A Φ` = `Λ`<mml:math><mml:msup><mml:mrow><mml:mi mathvariant="bold">&#934;</mml:mi></mml:mrow><mml:mi>T</mml:mi></mml:msup><mml:mi mathvariant="bold">&#913;</mml:mi><mml:mi mathvariant="bold">&#934;</mml:mi><mml:mo>=</mml:mo><mml:mi mathvariant="bold">&#923;</mml:mi></mml:math>![Equation](images/F000212si46.png). To find the eigenvectors of a covariance matrix, set `A` = `Σ`<mml:math><mml:mi mathvariant="bold-italic">A</mml:mi><mml:mo>=</mml:mo><mml:mi mathvariant="bold">&#931;</mml:mi></mml:math>![Equation](images/F000212si47.png), the covariance matrix. This yields the definition of the eigenvectors of a covariance matrix `Σ` as the set of orthogonal vectors stored in a matrix `Φ` and normalized to have unit length, such that `Φ^T Σ Φ` = `Λ`<mml:math><mml:msup><mml:mrow><mml:mi mathvariant="bold">&#934;</mml:mi></mml:mrow><mml:mi>T</mml:mi></mml:msup><mml:mi mathvariant="bold">&#931;</mml:mi><mml:mi mathvariant="bold">&#934;</mml:mi><mml:mo>=</mml:mo><mml:mi mathvariant="bold">&#923;</mml:mi></mml:math>![Equation](images/F000212si48.png). While these results may seem esoteric at first glance, their use is widespread. For example, in computer vision an eigenanalysis-based principal component analysis for face recognition yields what are known as “eigenfaces.” The general technique is widely used in numerous other contexts, and classic, well-cited eigenanalysis-based papers appear in many diverse fields.

## The Singular Value Decomposition

The singular value decomposition is a type of matrix factorization that is widely used in data mining and machine learning settings and is implemented as a core routine in many numerical linear algebra packages. It decomposes a matrix `X` into the product of three matrices such that `X` = `U S V^T`<mml:math><mml:mi mathvariant="bold-italic">X</mml:mi><mml:mo>=</mml:mo><mml:msup><mml:mrow><mml:mi mathvariant="bold-italic">USV</mml:mi></mml:mrow><mml:mrow><mml:mi>T</mml:mi></mml:mrow></mml:msup></mml:math>![Equation](images/F000212si50.png), where `U` has orthogonal columns, `S` is a diagonal matrix containing the singular values (normally) sorted along the diagonal, and `V` also has orthogonal columns. By keeping only the `k` largest singular values this factorization allows the data matrix to be reconstructed in a way that is optimal in a least squares sense for each value of `k`. For any given `k` we could therefore write `X` ≈ `U[k] S[k] V[k]^T`<mml:math><mml:mi mathvariant="bold">X</mml:mi><mml:mo>&#8776;</mml:mo><mml:msub><mml:mrow><mml:mi mathvariant="bold">U</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:msub><mml:mrow><mml:mi mathvariant="bold">S</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow></mml:msub><mml:msubsup><mml:mrow><mml:mi mathvariant="bold">V</mml:mi></mml:mrow><mml:mrow><mml:mi>k</mml:mi></mml:mrow><mml:mrow><mml:mi>T</mml:mi></mml:mrow></mml:msubsup></mml:math>![Equation](images/F000212si51.png).
