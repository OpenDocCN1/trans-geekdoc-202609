
如果最佳两个属性之间的信息增益差异小于 `ε`，则不安全进行分裂。然而，随着 `n` 的持续增加，`ε` 会减小，因此这只是等待看到更多示例的问题；当然，这可能会改变对哪两个属性最好以及它们相距多远的估计。

这个简单测试是 Hoeffding 树的核心原理——以概率 `1–δ` 判定某个属性的信息增益大于所有其他属性，即它与最近竞争对手之间的差距超过 `ε`。随着看到更多示例，该界限会迅速衰减。对于二分类问题（`R` = 1<mml:math><mml:mi>R</mml:mi><mml:mo>=</mml:mo><mml:mn>1</mml:mn></mml:math>![Equation](images/F000169si4.png)） with `δ` = 10 − 7<mml:math><mml:mi>&#948;</mml:mi><mml:mo>=</mml:mo><mml:mn>10</mml:mn><mml:mo>&#8722;</mml:mo><mml:mn>7</mml:mn></mml:math>![Equation](images/F000169si5.png) 它在前 1000 个示例后降至 0.1 以下，在前 100,000 个示例后降至 0.01 以下。有人可能会反对说，随着叶节点数量无限增长，即使每个节点的错误概率低于 `δ`，做出错误决策的概率也会持续增加。这在一定程度上是正确的，但由于在有限内存中工作，叶节点数量不可能无限增长。给定最大树大小，将总体错误概率保持在给定界限内只是选择 `δ` 的合适值的问题。基本原理可以应用于信息增益之外的度量以及决策树之外的学习方法。

还有许多其他问题。建议采用平局打破策略，以便在前两个属性的信息增益非常相似的情况下允许树进一步发展。事实上，两个相同属性的存在可能会完全阻止树的任何发展。为了防止这种情况，当 Hoeffding 界限低于预先指定的小平局打破参数时，节点应进行分裂，无论下一个最佳选项有多接近。为了提高效率，Hoeffding 测试可以定期为每个叶节点执行，在有 `k` 个新实例到达该叶节点后执行，并且只有当叶节点到达了混合的类别时才执行，否则无需分裂。预剪枝是另一个简单的可能性。算法可以通过同时评估不分裂的价值来纳入这一点——仅当节点处最佳属性的信息增益超过零时才分裂。与批量学习设置中的预剪枝不同，这不是永久性决定；节点仅在看起来分裂会很有用之前被阻止分裂。

现在考虑内存使用。叶节点内必须存储的内容只是每个类标签到达该叶节点的次数以及每个属性值的计数。这给数值属性带来了问题，需要单独处理。无监督离散化很容易，但监督预离散化更棘手。可以对数值属性按类别进行高斯近似，并使用均值和方差的简单增量更新算法进行更新。为了防止内存需求无限增长，必须制定策略来限制树中的总节点数。这可以通过停用在准确性增益方面看起来不够有希望的叶节点来实现。潜在增益受限于叶节点可能犯的错误数的期望值，因此这是衡量其潜力的明显候选。叶节点可以定期按从最有希望到最不有希望的顺序排列并相应地停用。节省空间的另一种可能性是放弃似乎是较差预测器的属性并丢弃其统计信息。

尽管本节主要关注分类的决策树，但研究人员已经研究了所有经典数据挖掘问题的流式版本：回归、聚类、集成方法、关联规则等等。一个名为 MOA 的开源系统，用于大规模在线分析，与 WEKA 密切相关，包含一系列在线学习算法以及评估工具。^(<a aria-label="noteref" href="#fn4" id="Cfn4">4</a>4)

## 15.4 融入领域知识

在本書中，我们一直强调在进行实际数据挖掘时了解数据的 importance。领域知识对于成功绝对至关重要。数据关于数据通常称为 *元数据*，机器学习的前沿之一是开发允许学习方法以有用的方式考虑元数据的方法。

你不必走远就能找到元数据可能应用的例子。在 [第2章](#Ch002_43-66_B9780443158889000030.xhtml#Ch002_43-66_B9780443158889000030)，“输入：概念、实例、属性，”中，我们将属性分为名义和数值。但我们也指出，许多更细的区分是可能的。如果一个属性是数值，则隐含了排序，但有时存在零点，有时不存在（对于时间间隔存在，但对于日期不存在）。甚至排序也可能是非标准的；角度度数与整数的排序不同，因为 360° 与 0° 相同，180° 与 −180° 相同，或者确实是 900°。离散化方案假定普通的线性排序，容纳数值属性的学习方案也是如此，但将其扩展到循环排序将是例行之事。分类数据也可能有序。想象一下，如果字母表没有约定俗成的排序，我们的生活会多么困难。（在香港电话目录中查找条目就呈现了一个有趣且非平凡的问题！）而且日常生活的节奏反映在循环排序中：星期几，一年中的月份。为了进一步复杂化，存在许多其他类型的排序，例如子集上的偏序——子集 A 可能包含子集 B，或者子集 B 可能包含子集 A，或者两者都不包含对方。以令人满意和一般的方式扩展普通学习方案以考虑这种信息是一个活跃的研究领域。

元数据通常涉及属性之间的关系。可以区分三种关系：语义、因果和功能。两个属性之间的 *语义* 关系表示如果第一个被包含在规则中，则第二个也应包含。在这种情况下，先验已知属性只有一起才有意义。例如，在我们分析过的农业数据中，一个名为 *产奶量* 的属性衡量单个奶牛产奶量多少，而我们调查的目的意味着该属性与另外三个属性具有语义关系，*奶牛标识符*、*牛群标识符* 和 *农场主标识符*。换句话说，产奶量值只能在产奶的奶牛的上下文中理解，而奶牛进一步与特定农场主拥有的特定牛群相关联。语义关系当然是问题依赖的；它们不仅取决于数据集，还取决于你想用它做什么。

*因果* 关系发生在一种属性引起另一种属性时。在试图预测由另一种属性引起的属性的系统中，我们知道应包含另一种属性以使预测更有意义。例如，在前面提到的农业数据中，从农场主、牛群和奶牛标识符通过诸如产奶量等测量属性到记录特定奶牛是否被农场主保留或出售的属性存在一条链。学习规则应认识到这种依赖链。
