
基于 Hausdorff 距离变体的最近邻学习由 [Wang 和 Zucker (2000)](#References_705-736_B978044315888900025X.xhtml#fur550) 研究。[Gärtner 等 (2002)](#References_705-736_B978044315888900025X.xhtml#fur207) 实验了集合核以学习多实例数据的 `SVM` 分类器。本文未涵盖的规则和决策树学习的多实例算法已由 [Chevaleyre 和 Zucker (2001)](#References_705-736_B978044315888900025X.xhtml#fur96)、[Blockeel, Page 和 Srinivasan (2005)](#References_705-736_B978044315888900025X.xhtml#fur49) 以及 Bjerring 和 Frank (2011) 描述。Logistic 回归已由 [Xu 和 Frank (2004)](#References_705-736_B978044315888900025X.xhtml#fur577) 和 [Ray 和 Craven (2005)](#References_705-736_B978044315888900025X.xhtml#fur449) 改编用于多实例学习；多层感知器已由 [Ramon 和 de Raedt (2000)](#References_705-736_B978044315888900025X.xhtml#fur448) 改编。

超矩形和球体分别由 [Dietterich 等 (1997)](#References_705-736_B978044315888900025X.xhtml#fur136) 和 [Auer 和 Ortner (2004)](#References_705-736_B978044315888900025X.xhtml#fur20) 视为多实例学习的概念描述。多样性密度方法是 Maron (1998) 博士论文的主题，也在 ([Maron 和 Lozano-Peréz, 1997](#References_705-736_B978044315888900025X.xhtml#fur378)) 中有所描述。Foulds 和 Frank (2010b) 评估了一种更快捷的启发式变体。

多实例文献对要学习的概念类型做出了许多不同的假设，定义了包级和实例级类标签之间的联系，从最初的假设开始，即如果且仅如果其一个实例为正，则包被标记为正。Foulds 和 Frank (2010a) 中可找到多实例学习假设的综述。
