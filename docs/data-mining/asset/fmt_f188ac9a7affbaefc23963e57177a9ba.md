We now look at stochastic networks, beginning with a model for unsupervised learning known as a Boltzmann machine. This stochastic neural network model is a type of Markov random field ([Section 14.3](#Ch015_516-570_B9780443158889000157.xhtml#s0055)). Unlike the units of a feedforward neural network the units in Boltzmann machines correspond to random variables, such as are used in Bayesian networks. Older variants of Boltzmann machines were defined using exclusively binary variables but models with continuous and discrete variables are also possible. They became popular prior to the impressive results of `CNNs` on the ImageNet challenge but have since waned in popularity because they are more difficult to work with. However, stochastic methods have certain advantages such as the ability to capture multimodal distributions.

## Pretraining Deep Autoencoders with RBMs

Deep autoencoders, discussed in [Section 10.4](#Ch011_391-432_B978044315888900011X.xhtml#s0140), are an effective framework for nonlinear dimensionality reduction that formed an important use case of stochastic networks, particularly when used as part of an unsupervised pretraining strategy. Once such a network has been built the top-most layer of the encoder, the code layer `h*[c]`, can be input to a supervised classification procedure. If a neural network classifier is used, the entire deep autoencoder network can be discriminatively fine-tuned using gradient descent. In effect the autoencoder approach is used to pretrain a neural network classifier.

However, it is difficult to optimize autoencoders with multiple hidden layers in both encoder and decoder. It is well known that initializing any deep neural network with weights that are too large leads to poor local minima, while initialization with weights that are too small can lead to small gradients that make learning slow. One approach is to be very careful about the choices of activation function and initialization. However, this has been found difficult in practice.

Another approach is based on pretraining by stacking two-layered restricted Boltzmann machines (`RBMs`). “`RBMs` are a generalized form of probabilistic principal component analysis (`PPCA`), which we discussed in [Section 14.3](#Ch015_516-570_B9780443158889000157.xhtml#s0055), binary hidden variables and binary or continuous observed variables that can perform unsupervised learning; they are discussed further later. To use them for pretraining start by learning a two-layer `RBM` from the data, project the data into its hidden-layer representation, use that to train another `RBM`, and repeat the process until the encoding layer is reached. The parameters of each two-layer network are then used to initialize the parameters of an autoencoder with a similar structure that has nonstochastic `sigmoid` hidden units. Next we discuss `RBMs`, Boltzmann machines that they are based on, and various modeling and learning strategies based on them that were prominent in the 2000s–2010s. These models have largely fallen into disuse but remain important for historical reasons.
