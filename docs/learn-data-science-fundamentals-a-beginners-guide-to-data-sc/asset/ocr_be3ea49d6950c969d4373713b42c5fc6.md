+   • AdaBoost (Adaptive Boosting): Assigns higher weights to misclassified instances in each iteration, forcing the model to focus on difficult examples.

+   • Gradient Boosting: Fits new models to the negative gradient of the loss function, gradually improving the overall model.

+   • XGBoost (Extreme Gradient Boosting): An efficient and scalable implementation of gradient boosting, known for its high performance on a wide range of problems.

# 3. Stacking (Stacked Generalization)

Stacking involves training multiple base models on the training data and then using a meta-model to learn how to combine the predictions of the base models. The base models are trained independently, and their outputs are used as features for the meta-model. Stacking can effectively leverage the strengths of diverse models and has been shown to outperform other ensemble methods in many cases.

# 4. Voting

Voting is a simple ensemble technique that combines the predictions of multiple models by majority vote (for classification) or averaging (for regression). It can be used with models of the same type (e.g., multiple logistic regression models) or different types (e.g., logistic regression, decision tree, and random forest). Voting helps reduce the risk of making mistakes due to the biases of a single model.

# 5. Blending

Blending is a variant of stacking that uses a holdout set to train the meta-model instead of the original training set. The base models are trained on the full training set, while the meta-model is trained on the predictions of the base models on the holdout set. This helps prevent overfitting of the meta-model.
