# Types of Hypothesis Tests

There are several types of hypothesis tests, depending on the nature of the problem and the type of data involved:

+   * **One-sample tests**: These tests are used to make inferences about a population parameter based on a single sample. Examples include:
    * One-sample z-test for a population mean with known standard deviation
    * One-sample t-test for a population mean with unknown standard deviation
* **Two-sample tests**: These tests are used to compare two population parameters based on two independent samples. Examples include:
    * Two-sample z-test for the difference between two population means
    * Two-sample t-test for the difference between two population means
* **Paired tests**: These tests are used to compare two population parameters based on two related samples or matched pairs. An example is the paired t-test for the difference between two population means.
* **Goodness-of-fit tests**: These tests are used to determine whether a sample data follows a specific probability distribution. An example is the chi-square goodness-of-fit test.
* **Dependence tests**: These tests are used to determine whether two categorical variables are independent. An example is the chi-square test of independence.
