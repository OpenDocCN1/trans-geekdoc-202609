# 13.1 Overview of Blockchain Technology and Distributed Ledgers

Blockchain technology is a decentralized, distributed digital ledger that records transactions across many computers in a network. It is best known for its crucial role in cryptocurrency systems, such as Bitcoin, for maintaining a secure and decentralized record of transactions.

# Key Characteristics of Blockchain

+   1. Decentralized: Blockchain is decentralized, meaning it is not governed by a single entity. The network is maintained by a peer-to-peer network collectively adhering to a protocol for validating new blocks.

+   2. Distributed Ledger: Blockchain acts as a distributed ledger, where a copy of the entire transaction history is stored on every node (computer) in the network. This eliminates the need for a central authority to maintain the ledger.

+   3. Immutability: Once a transaction is recorded in the blockchain, it becomes extremely difficult to alter or delete. Each block contains a cryptographic hash of the previous block, creating a chain that is resistant to modification.

+   4. Transparency: All transactions are visible to anyone with access to the blockchain network. This transparency helps build trust and accountability among participants.

+   5. Consensus-driven: Blockchain networks use consensus mechanisms to validate transactions and add new blocks to the chain. Common consensus algorithms include Proof of Work (PoW) and Proof of Stake (PoS).

# Components of a Blockchain Network

+   1. Nodes: Nodes are the computers or devices that participate in the blockchain network. They store a copy of the ledger, validate transactions, and communicate with each other.
