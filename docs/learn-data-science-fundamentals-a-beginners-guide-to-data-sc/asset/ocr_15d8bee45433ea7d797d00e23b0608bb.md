# 3.1 Data Visualization Techniques

Data visualization is a crucial aspect of exploratory data analysis, as it helps uncover patterns, trends, and relationships within datasets. By transforming complex data into visual representations, data scientists can gain valuable insights and effectively communicate their findings to stakeholders.

# 1. Scatter Plots

Scatter plots are used to visualize the relationship between two continuous variables. They display data points as a two-dimensional grid, with each axis representing one of the variables. Scatter plots are useful for identifying correlations, clusters, and outliers in the data

# 2. Line Plots

Line plots are effective in tracking the evolution of a variable over time. They are created by plotting time variable on the x-axis and the variable of interest on the y-axis. Line plots are commonly used to visualize trends, seasonality, and changes in a dataset over a period.

# 3. Bar Charts

Bar charts are used to compare values across different categories. They consist of rectangular bars whose lengths are proportional to the values being represented. Bar charts can be oriented vertically or horizontally and are useful for visualizing comparisons, rankings, and proportions.

# 4. Histograms

Histograms are used to analyze the distribution of a continuous variable. They divide the data into bins and display the frequency of values within each bin as bars. Histograms help identify the shape of the distribution, including skewness, modality, and the presence of outliers.
