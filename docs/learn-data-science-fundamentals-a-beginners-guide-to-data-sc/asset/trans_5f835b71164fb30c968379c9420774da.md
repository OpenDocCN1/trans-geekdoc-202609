# 回归模型

- 1. 平均绝对误差 (MAE)：预测值与实际值之间绝对差的平均值，提供了预测准确性的直接衡量。

- 2. 均方误差 (MSE)：预测值与实际值之间平方差的平均值。MSE 通过对差异进行平方来强调较大的误差。

- 3. 均方根误差 (RMSE)：MSE 的平方根，提供了与目标变量单位相同的误差指标，增强了可解释性。

- 4. R 方 (R²)：一种统计衡量量，表示因变量中可以由自变量解释的方差比例。值范围从 0 到 1，值越高表示拟合得越好。

- 5. 调整 R 方：与 R 方类似，但根据模型中预测器的数量进行了调整，在比较具有不同预测器数量的模型时提供了更准确的衡量。

# 模型选择

模型选择涉及根据评估指标从候选模型集中选择性能最好的模型。关键考虑因素包括：

- 1. **模型复杂度**：平衡模型复杂性和性能至关重要。更复杂的模型可能更好地拟合训练数据，但存在过拟合风险。

- 2. **泛化能力**：所选模型应该很好地泛化到未见过的数据，这可以通过交叉验证结果和性能指标看出。

- 3. **计算效率**：考虑训练和推理所需的计算资源是关重要的，特别是对于大型数据集或复杂模型。

- 4. **领域知识**：引入领域知识可以指导模型的选择。

## 6.4 深度学习基础

### 什么是深度学习？

深度学习是机器学习的一个子集，使用多层神经网络进行。灵感来自人类大脑的结构和功能，在图像识别、语言处理和语音识别等任务中显示了巨大的成功。

### 深度学习的关键组件

- 1. **人工神经网络**：深度学习的构建模块，由节点组成。

- 2. **激活函数**：应用于神经元的数学函数，用于引入非线性。

- 3. **前向传播**：输入通过层级的过程。

- 4. **反向传播**：用于根据损失函数更新权重算法。

- 5. **优化**：用于训练模型的方法，如梯度下降。

# 训练深度学习模型

- 1. **损失函数**：衡量模型性能的指标。

- 2. **正则化**：如丢弃（dropout）和权重衰减等防止过拟合的技术。

- 3. **超参数调优**：调整学习率、批量大小和迭代次数（epochs）等参数的过程。

- 4. **验证与测试**：将数据集分为训练集、验证集和测试集。

- 5. **数据**：深度学习需要大量的数据。

# 深度学习的应用

- 计算机视觉：图像分类、目标检测和分割。

- 自然语言处理：机器翻译、问答和文本建模。

- 语音识别：音频识别和语音转换。

- 生成式模型：生成真实的图像和文本。

- 强化学习：训练智能体做出决策。

# 深度学习的挑战

- **可解释性**：由于结构复杂，理解深度学习模型如何做出决策通常很难。

- **数据效率**：深度学习通常需要标注数据。

- **计算资源**：训练深度学习模型可能是密集型的，可能需要 GPU 或 TPU 等专用硬件。

- **鲁棒性**：深度学习对对抗样本敏感，泛化可能并不良好。

# 6.5 集成学习方法

集成学习是机器学习中一种强大的技术，通过结合多个模型来提高预测性能。通过利用不同模型的优势，集成方法通常优于任何单一模型。以下是一些是最常见的集成方法：

## 1. Bagging (自助聚合)

Bagging 涉及在通过自助采样的不同数据子集上独立训练模型。最终预测通过聚合所有模型的预测来实现，可以通过多数投票（用于分类）或取平均值（用于回归）。随机森林是 Bagging 算法的一个流行例子。

## 2. Boosting

Boosting 是一种顺序集成技术，通过迭代训练模型，每个后续模型都关注前一个模型所犯的错误。最著名的 Boosting 算法有：

- AdaBoost (自适应增强)：在每次迭代中为分类错误的实例分配更高的权重，迫使模型关注困难的示例。

- 梯度提升 (Gradient Boosting)：对损失函数的负梯度拟合新模型，逐步改进模型。

- XGBoost (极端梯度提升)：梯度提升的一种高效且可扩展的实现，以其在广泛问题上的高性能而闻名。

## 3. 堆叠 (堆叠泛化)

Stacking 涉及在训练数据上训练多个基模型，然后使用元模型（meta-model）来学习如何结合基模型的预测。基模型是独立训练的，它们的输出被用元模型的特征。Stacking 可以有效利用不同模型的优势，并已被证明优于其他集成方法。

## 4. 投票 (Voting)

投票是一种简单的集成技术，通过多数投票（用于分类）或取平均值（用于回归）结合多个模型的预测。它可以用于相同类型的模型（例如多个逻辑回归模型）或不同类型的模型（例如逻辑回归、决策树和随机森林）。投票有助于减少由于单一模型的偏差而导致string错误的风险。

## 5. 混合 (Blending)

Blending 是 Stacking 的变体，它使用留集来训练元模型，而不是原始训练集。基模型在整个训练集上训练，而元模型则根据基模型在留集上的预测进行训练。这有助于防止元模型的过拟合。

## 6. 贝叶斯模型平均 (BMA)

BMA 是一种概率性的集成学习方法，根据模型的后验概率组合模型。它假设真实模型是候选模型之一，并计算它们的加权平均
