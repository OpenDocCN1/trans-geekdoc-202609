+   - Examples: A temperature reading of 30°C might be normal in summer but anomalous in winter. Similarly, a spike in website traffic might be expected during a marketing campaign but unusual at other times.

+   - Detection Techniques:
    - **Time-Series Analysis**: Techniques that analyze patterns over time can identify contextual anomalies by comparing current data points to historical trends.
    - **Conditional Approaches**: Using models that consider contextual variables (e.g., seasonality) allows for more accurate anomaly detection in varying conditions.

# 3. Collective Anomalies:

+   - **Definition**: Collective anomalies occur when a group of related data points deviates from the norm, even if individual points within the group do not seem anomalous on their own. These anomalies often indicate a significant change in behavior or pattern.

+   - **Examples**: A series of transactions that occur in a short time frame and deviate from normal spending patterns can indicate fraudulent activity, even if each transaction appears normal when viewed individually.

+   - Detection Techniques:

+   - **Clustering Methods**: Techniques like k-means clustering can help identify groups of data points that collectively deviate from expected patterns.

+   - **Sequence Analysis**: Analyzing sequences of events or transactions can reveal collective anomalies by assessing the relationships and patterns among multiple data points.
