+   - Power transformation: Applying Box-Cox or Yeo-Johnson transformations to address non-Gaussian distributions

**Feature Selection:** Selecting a subset of the most relevant features from the available set. This can help reduce overfitting, improve model interpretability, and reduce computational costs. Examples include:

+   - Correlation-based selection: Selecting features based on their correlation with the target variable

+   - Recursive Feature Elimination (RFE): Iteratively removing features with the least importance

+   - Embedded methods: Using the feature importance scores from tree-based models (e.g., Random Forest, Gradient Boosting)

**Feature Encoding:** Converting categorical features into a format that can be used by machine learning models. Examples include:

+   - One-hot encoding: Creating binary columns for each unique category

+   - Ordinal encoding: Assigning numerical values to categories based on their order or importance

+   - Target encoding: Replacing categories with the mean or median of the target variable for each category

**Dimensionality Reduction:** Reducing the number of features while retaining the most important information. Examples include:

+   - Principal Component Analysis (PCA): Projecting the data onto a lower-dimensional space while preserving the maximum variance

+   - t-SNE (t-Distributed Stochastic Neighbor Embedding): Reducing dimensionality while preserving local structure and revealing clusters in the data
