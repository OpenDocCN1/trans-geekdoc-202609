- 独热编码 (One-Hot Encoding)：此方法为每个类别创建一个二进制列，指示每个观测值中该类别存在（1）或不存在（0）。例如，如果一个特征有三个类别（红、蓝、绿），独热编码将创建三个二进制特征。该技术对于名义数据有效，但可能会导致特征数量过多，特别是对于高基数的类别变量，这可能会引入维度灾难。

- **标签编码 (Label Encoding)**：这种技术为每个类别分配一个唯一的整数。虽然简单，但它可能会在类别之间引入无意的顺序关系，可能会误导某些依赖距离计算的算法。

例如，为“红色”分配 0，“蓝色”分配 1，“绿色”分配 2 意味着存在一种并不实际的排名关系。

- **目标编码 (Target Encoding)**：这种方法用每个类别的目标变量平均值来替换每个类别。它对于高基数的类别特征特别有效，但需要仔细处理以避免模型训练期间的数据泄露。

- **序数编码 (Ordinal Encoding)**：用于序数数据，该技术根据类别的顺序分配整数。例如，客户满意度水平可以编码为 1（差）、2（中等）、3（好）和 4（优秀）。

- **处理高基数**：在处理具有许多唯一类别的类别变量时，可以使用目标编码或特征哈希等技术，在保留有意义信息的同时降低维度。

- **特征工程**：从现有的类别数据创建新特征可以帮助提高模型性能。技术包括：

- 交互变量：结合两个或多个类别特征，以捕捉它们对目标变量的共同影响。

- 分箱 (Binning)：将连续变量转换为类别箱体（bins）可以简化模型并提高可解释性。

- 6. **插补 (Imputation)**：用类别变量的众数填充缺失值，或为缺失值创建一个单独类别。

- 7. **删除 (Deletion)**：移除具有缺失类别值的观测值，尽管可能会导致价值数据的丢失。

# 处理类别数据的最佳实践

- **理解数据的本质**：确定类别数据是名义的还是序数的，因为这将影响编码方法的选择。

- **评估编码技术**：测试不同的编码方法，查看哪种方法对你的特定模型和数据集性能最好。考虑可解释性与模型复杂度之间的权衡。

- **监控过拟合**：谨慎使用目标编码和其他可能向模型引入噪声或偏差的方法。使用交叉验证来可靠地评估模型性能。

- **记录过程**：清晰记录用于处理类别数据的方法，包括所选技术的理由，以确保分析的可重复性和透明度。

# 第 6 章：机器学习导论

# 6.1 监督学习算法

监督学习是机器学习的核心组件，涉及在标记的数据集上训练算法，以预测结果或对数据进行分类。由于其在解决现实问题方面的有效性，这种方法被广泛用于医疗、金融、营销等多个领域。监督学习可以分为两大类：分类和回归。

# 监督学习的核心概念

- 标记数据：在监督学习中，训练数据集由输入-输出对组成，每个输入（特征）都与相应的输出（标签）相关联。模型根据这些标记数据学习将输入映射到输出。

- 训练与测试：数据集通常分为两部分：用于训练模型的训练集和用于评估其性能的测试集。这有助于评估模型对未见数据的泛化能力。

- 损失函数：损失函数衡量预测输出与实际输出之间的差异。在训练期间，算法旨在最小化这种损失，并相应地调整其参数。

- 模型评估：训练后，使用准确率、精确率、召回率、F1 分数（用于分类）以及均方误差或 R 方（用于回归）等指标评估模型性能。

# 监督学习算法的类型

# 1. 分类算法

当输出变量是类别时，使用分类算法。它们根据输入特征预测离散标签。常见的分类算法包括：

- 逻辑回归：尽管名称如此，逻辑回归用于二分类任务。它使用逻辑函数对给定输入属于特定类类的概率建模。

- 决策树：该算法根据特征值将数据划分为子集，创建一个树状决策模型。决策树具有可解释性，并且可以处理类别和数值数据。

- 随机森林：一种集成方法，通过构建多个决策树并结合它们的预测来提高准确性并减少过拟合。每棵树都在数据的随机子集上进行训练。

- 支持向量机 (SVM)：该算法在特征空间中寻找区分不同类的最优超平面。SVM 在高维空间中有效且对过拟合具有鲁棒性。

- 朴素贝叶斯：基于贝叶斯定理的概率分类器，假设在给定类别标签的情况下特征是独立的。它对于文本分类任务特别有效。

## 回归算法

当输出变量是连续的时，使用回归算法。它们对输入特征与连续输出之间的关系。常见的回归算法包括：

- 线性回归：该算法通过对观测数据拟合线性方程，对因变量与一个或自变量之间的关系建模。

- 岭回归和 Lasso 回归：这些正则化技术，通过向损失函数添加惩来修改线性回归以防止过拟合。

- 多项式回归：通过对数据拟合多项式方程扩展线性回归，允许对非线性关系建模。

- 支持向量回归 (SVR)：SVM 在回归任务中的扩展，SVR 旨在寻找一个函数，其偏离实际目标值的幅度不超过指定的边界值。

- 决策树回归：与分类决策树类似，该算法通过根据特征值将数据划分为子集来预测连续结果。

# 监督学习的应用

监督学习算法被广泛应用于各种场景，包括：

- 垃圾邮件检测：根据发件者、主题和内容等特征将电子邮件分类为垃圾邮件或非垃圾邮件。

- 图像识别：识别图像中的物体或特征，例如分类动物图像或检测脸。

- 信用评分：根据历史数据和财务特征预测借款人违约的概率。

- 医学诊断：对患者数据进行分类，根据症状和测试结果预测疾病的存在。

- 推荐系统：根据历史行为预测用户偏好，例如推荐电影或产品。
