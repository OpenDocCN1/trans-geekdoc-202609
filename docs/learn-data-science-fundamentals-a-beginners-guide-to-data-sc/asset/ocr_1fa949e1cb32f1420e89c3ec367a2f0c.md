# Key Techniques in Unsupervised Learning

# 1. Clustering

Clustering is a primary task in unsupervised learning that involves grouping similar data points together based on their features. The goal is to identify inherent structures in the data. Common clustering algorithms include:

+   - K-Means Clustering: This algorithm partitions the data into distinct clusters by minimizing the variance within each cluster. It iteratively assigns data points to the nearest cluster centroid and updates the centroids until convergence.

+   - Hierarchical Clustering: This method creates a hierarchy of clusters through agglomerative (bottom-up) or divisive (top-down) approaches. The results can be visualized using dendrograms, which illustrate the relationships between clusters.

+   - DBSCAN (Density-Based Spatial Clustering of Applications with Noise): DBSCAN groups together points that are closely packed while marking points in low-density regions as outliers. This algorithm is effective for identifying clusters of arbitrary shape and is robust to noise.

+   - Gaussian Mixture Models (GMM): GMM assumes that the data is generated from a mixture of several Gaussian distributions. It uses the Expectation-Maximization (EM) algorithm to estimate the parameters of the distributions and assign probabilities to each data point belonging to each cluster.
