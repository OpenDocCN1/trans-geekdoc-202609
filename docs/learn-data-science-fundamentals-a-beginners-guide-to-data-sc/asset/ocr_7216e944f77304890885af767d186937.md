# 6. Feature Importance

Assessing the importance of input features or variables helps understand their impact on the target variable. Techniques include:

+   * Feature Ranking: Using statistical tests or machine learning algorithms to rank features based on their contribution to the model's performance.

+   * Permutation Importance: Evaluating the change in model performance when the values of a feature are shuffled, indicating its importance.

# 7. Data Distribution

Examining the distribution of variables is crucial for understanding their characteristics. Analysts assess whether variables follow specific distributions, such as:

+   * Normal Distribution: A bell-shaped distribution where most values cluster around the mean.

+   * Skewed Distribution: A distribution where values are not symmetrically distributed around the mean, indicating potential transformations may be needed.

+   * Multi-modal Distribution: A distribution with multiple peaks, suggesting the presence of different subgroups within the data.
