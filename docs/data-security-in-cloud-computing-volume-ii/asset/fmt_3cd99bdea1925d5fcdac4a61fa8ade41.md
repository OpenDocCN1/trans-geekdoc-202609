
云计算中的隐私角色必须透明，以便正确分配合同各方的法律义务和责任。标准职责分配（《第29条工作组》2012年报告，第7页）表明，云端处理的个人数据控制权属于客户。相反，云服务提供商通常被视为数据处理者。作为数据控制者，云客户承担数据保护法规合规责任，须对《95/46/EC指令》规定的所有法律义务负责。云服务提供商在定义实现控制者目的的方法、技术或组织措施方面有一定自由度。[表 14.5](#19_chapter14.xhtml#tab14-5) 作为检查清单，列出了云客户需考量的各项事宜。

**表 14.5.** 合同修正检查清单

| 条款 | 内容 |
| --- | --- |
| 1 | 合同应规定所提供的服务及条件（含程序性条件），这些条件可在服务提供过程中修改。 |
| 2 | 合同本身应排除可能损害任务关键型服务水平和个人数据保护水平的变更。 |
| 3 | 变更前应通知客户。 |
| 4 | 合同可包含客户对协议任何变更享有事先知情权的条款。 |
| 5 | 客户应核实合同是否赋予其在出现不受欢迎或未通知问题时终止合同的权利。 |

### 14.2.8 合同修正

云服务提供商常保留单方面修改云合同的权利，并在合同中加入允许此举的特定条款。这给客户带来重大问题：客户必须核实合同是否预见了此类情况下提供商的通知义务，或允许客户因不利变更而终止合同。[表 14.5](#19_chapter14.xhtml#tab14-5) 列出了针对云合同修正的诸多建议供云客户参考。

### 14.2.9 数据位置与数据传输

云计算常涉及在欧盟境外服务器处理或存放数据，因此个人数据极有可能传输至欧盟境外。必须特别关注云合同中的个人数据流向。根据欧盟委员会关于第三国个人数据保护充分性的决定，《95/46/EC指令》禁止向未确保个人数据充分保护水平的第三国传输个人数据。^[8](#19_chapter14.xhtml#rfn8) 依据第25条第6款，

> 委员会可因第三国的国内法或其承担的国际承诺（特别是与委员会谈判达成的保护个人私人生活、基本自由和权利的承诺），认定该国确保充分的保护水平。^[4](#19_chapter14.xhtml#rfn4)

满足以下任一条件时，个人数据可传输至保护水平不足的国家：

1.  符合第26条第1款所列条件至少之一。*
2.  个人数据接收方签署欧盟委员会批准的标准示范条款。^[4](#19_chapter14.xhtml#rfn4)
3.  接收组织参与欧盟数据保护机关采用的具有约束力的企业规则。^[9](#19_chapter14.xhtml#rfn9)

美国组织若通过安全港认证，可接收数据传输。^[10](#19_chapter14.xhtml#rfn10) 当个人数据在无充分保障国家处理时，建议客户（控制者/数据出口方）与提供商（处理者/数据进口方）签署委员会通过的示范条款（2010/87/EU决定）。此外，合同满足上述任一条件（如适用指令第26.1条或遵守安全港协议）时，个人数据亦可传输至欧盟境外。

### 14.2.10 分包商处理个人数据

云服务提供商可能将云运作所需的部分处理外包给分包商。此类分包商（可能位于欧盟境外）接收云服务客户的个人数据。仅当满足前段至少一项条件时，此类处理欧盟个人数据才合法。此外，必须意识到可能涉及多个不同分处理者，可能导致对个人数据失去控制、数据处理缺乏问责，从而使数据主体难以行使权利。云客户应审查[表 14.6](#19_chapter14.xhtml#tab14-6) 列出的考量因素。

**表 14.6.** 分处理者与分包商

| 编号 | 内容 |
| --- | --- |
| 1 | 《第29条工作组》2012年《5/2012号意见》（第9–10、20页）建议，处理者（提供商）应告知客户现有的分包处理情况，明确分包服务类型、现有或潜在分包商特征，并确保此类实体遵守《95/46/EC指令》。 |
| 2 | 云提供商须确保其分包商在合同上受相同义务和标准约束（即与控制者约定的标准一致）。欧盟委员会批准的示范合同条款对此很有用。 |
| 3 | 控制者应拥有针对处理者的合同追索权，以应对分处理者导致的合同违约。 |

### 14.2.11 数据主体权利（可干预性）

依据《95/46/EC指令》，数据主体享有访问权、更正权、删除权、冻结权和异议权。客户应始终核实提供商是否保证充分配合，使数据主体权利易于行使，即使数据由分包商进一步处理亦然。同时，客户应确保合同明确规定云提供商承诺与云客户合作，保障数据主体权利得到有效行使，即使数据由分包商进一步处理亦然。

### 14.2.12 步骤 3：退出云服务合同——主要议题

第三步探讨退出云服务合同时需考虑的主要议题：锁定与互操作性、SLA 及合同终止。

### 14.2.13 锁定与互操作性

云提供商使用专有数据格式和服务接口可能导致锁定效应，使数据从云提供商处的互操作和迁移极其困难。缺乏互操作性和可移植性必然增加服务迁移复杂度（锁定效应）。客户应遵循[表 14.7](#19_chapter14.xhtml#tab14-7) 的两项建议。

**表 14.7.** 锁定与互操作性检查清单

| 条款 | 内容 |
| --- | --- |
| 1 | 检查云提供商如何确保数据可移植性和互操作性。 |
| 2 | 选择有利于互操作性的标准数据格式和服务接口。 |
