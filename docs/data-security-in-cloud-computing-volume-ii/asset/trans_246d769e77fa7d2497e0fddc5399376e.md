
监管领域中存在的标准迷宫，代表了云计算发展面临的最重大挑战之一（OECD 2014，第5页）。事实上，我们所观察到的大量标准，在个人数据保护的适当水平、互操作性和可移植性方面产生了不确定性，因此欧洲云战略旨在建立公开可用、开放且安全的云，完全符合欧洲监管标准（欧盟委员会 2012，第5-6页）。在数字世界中，问题往往相互交织。以数字议程的电子商务指令为例，它表明阻碍云计算采用的主要因素是“某些领域缺乏适当的标准、现有标准缺乏广泛采用，以及由于使用不可互操作的解决方案而导致供应商锁定的可能性”（欧盟委员会 2012，第7页）。梳理标准丛林将有助于实现适当的互操作性、数据可移植性和可逆性，这些是采用云计算服务时的关键考量因素（欧洲数字议程 2015）。这将通过《欧洲数据保护条例》来实现，该框架法律将营造一个环境，允许安全地采用用户所需的标准和行为准则，以成功验证安全标准和数据传输的安全性（欧盟委员会 2012，第8页）。斩断规则丛林，意味着让云用户体验到互操作性、数据可移植性，以及至关重要的可逆性（欧洲数字议程 2015）。

信任在云采用中发挥着至关重要的作用，事实上，数字单一市场方法本身也凸显了这一识别的活力，即“确定一组适当的可认证标准，以便让公共和私人采购者确信他们已履行了合规义务”（欧盟委员会 2012，第9页）。反过来，这些标准和认证可作为云服务供应商提供的条款和条件的参考，用于合同的公平性和透明度。然而，正如委员会在其“释放欧洲云计算潜力”通信中所指出的，需要处理标准、认证以及合同约定的具体框架。

根据委员会的说法，该云计算战略的目标将是制定示范合同，以规范：

1.  合同终止后的数据保存
2.  数据披露与完整性
3.  数据位置与传输
4.  信息所有权
5.  云供应商和分包商直接和间接的责任变更及服务变更

### 14.1 2015年欧洲数字议程

欧洲云合作伙伴关系是在欧洲云战略下建立的，旨在作为一个场所，让行业和公共部门“以开放和完全透明的方式共同研究云计算的采购需求”（欧洲数字议程 2014）。其指导委员会向委员会提供建议，以促进云计算在经济中的积极效应，强调公共部门作为云市场决定性方面的重要性（欧洲数字议程 2014a）。

此外，OECD在《云计算：概念、影响与政府政策的作用》中强调，标准合同通常采取“接受或拒绝”的条款，从而不允许云客户充分协商其可能无法完全理解的合同条款，导致即使是提供商也面临相当大的不确定性。服务等级协议（SLA）需要更好地解决诸如停机等方面的问题，这可以通过行业行为准则的具体化在政策层面得到推动（OECD 2014，第5页）。

关于隐私，OECD指出，各国政府真正全球互操作的方法是最大化云部署潜力的关键，建议政策制定者定义“存储在云中的数据适用谁的法律，包括谁可以访问这些数据”（OECD 2014，第6页）。Bradshaw、Millard和Walden（2010，第44页）强调仔细审查云合同条款和条件的重要性，这些条款规定了披露、数据存储位置（EU以外的合同并不总是考虑这一点）以及底层服务提供商的身份。

许多云计算合同的条款和条件代表了采用云服务的法律挑战。Bradshaw、Millard和Walden的研究对此点进行了强调，他们的研究针对云计算提供商提供的条款和条件，表明标准云合同实际上提供的确定性水平与外包合同相比相当浅薄（2010，第3页）。本章受作者参与两个项目的启发，即CloudWATCH D3.5《云法律指南：如何在云服务合同中保护个人数据》^([1](#19_chapter14.xhtml#rfn1)) 和云安全联盟的《隐私等级协议 [V2] 在欧盟提供云服务的合规工具》^([2](#19_chapter14.xhtml#rfn2))，每个项目都探讨了与本研究相关的云计算合同的基本方面。基于这些经验，作者旨在促进对云中法律合规风险的理解、如何管理该风险，以及在与云服务供应商协商个人数据保护风险时应考虑的方面。虽然促进全球层面的理解是本章的目标，但由于作者作为欧洲律师的立场，分析将主要从欧盟合规的角度进行。

### 14.2 应对法律合规

云计算技术和服务的繁荣，与前述得益于移动设备显著普及而成为可能的各种IT服务交付方式同步发展。事实上，企业在考虑混合解决方案时，可以根据需求购买服务，适配显而易见的公有云和私有云解决方案（Gartner 2013）。

法律版本随着这些技术的扩散而发展，尽管速度慢得多。然而，人们对云计算合同的关注度增加了，这些合同经常继续由云提供商以标准形式措辞。云解决方案的客户必须对以下合同方面给予适当关注：

- 责任排除或限制及补救措施，特别是涉及数据完整性和灾难恢复方面
- 服务等级，也包括可用性
- 安全和隐私，特别是《欧盟数据保护指令》下的监管问题^([3](#19_chapter14.xhtml#rfn3))
- 锁定和退出，包括期限、终止权以及退出合同时的数据返还
- 提供商单方面修改服务功能的能力^([4](#19_chapter14.xhtml#rfn4))
