
与之前将计算作为服务引入的尝试不同，云计算已在计算的各个领域取得成功，基于云的服务市场快速增长。凭借其便捷的按需付费服务、低成本的计算产品以及灵活且近乎无限的基础设施资源，云计算极有可能成为未来主要的计算范式之一。据美国信息技术研究和顾问公司 Gartner Inc. 报告，2016 年将是云计算崛起的关键一年，到 2017 年底，近一半的大型企业将采用基于云的部署。政府部门此前因安全顾虑而不愿采用基于云的解决方案，现在也开始感兴趣，并预计将转向云端。安全性是分布式系统和服务的主要关注点。

云计算从其前身那里继承了所有这些安全问题。此外，云计算引入的新概念，如计算外包、资源共享和外部数据仓储，加剧了隐私担忧，并使云计算平台容易受到更新的安全问题和威胁。因此，基于云的解决方案中的安全性至关重要，可被视为广泛采用和接受的最重大障碍之一。2014 年 iCloud 数据泄露事件证明了云计算的脆弱性和不安全性。云计算不仅引入了额外的风险和挑战，还给部署和维护现有安全标准增加了各种复杂性。广泛的移动设备访问以及云提供商提供的按需服务进一步放大了安全担忧和威胁。[表 15.1](#20_chapter15.xhtml#tab15-1) 列出了一些已知攻击及其后果。根据美国法律，信息安全被定义为保护信息和信息系统免受未经授权的访问、使用、披露、中断、修改、检查、记录或销毁，以提供信息的完整性、机密性和可用性。因此，为了经受住时间的考验，云计算应预先解决所有这些安全问题。Gartner Inc. 提出了七大主要云计算安全风险：服务外包、合规性、数据位置、共享环境、业务连续性和灾难恢复、调查非法活动的艰难环境以及长期生存能力。[第 15.1 节](#20_chapter15.xhtml#h-56) 对云安全问题进行了分类讨论。

**表 15.1.** 针对云计算的已知攻击

| 攻击 | 后果 | 类别 |
| --- | --- | --- |
| 服务窃取 | 服务被盗 | 云基础设施 |
| 拒绝服务 | 服务不可用 | 云基础设施 |
| 恶意软件注入 | 信息泄露 | 云基础设施 |
| 跨虚拟机侧信道 | 云恶意软件注入 | 访问控制 |
| 目标共享内存 | 未经授权的访问 | 访问控制 |
| 网络钓鱼 | 恶意软件注入 | 访问控制 |
| 僵尸网络 | 发起暴力破解攻击 | 访问控制 |
| 虚拟机回滚攻击 | 敏感信息泄露 | 访问控制 |

### 15.1 类别

安全问题可能在云计算模型的不同层面引发。存在系统级威胁，即入侵者绕过安全措施获取未经授权的访问，以及云基础设施和网络级威胁。云的每个组件都应单独处理，并需要同等关注以保护云计算平台的整体安全。如前所述，云安全类别可分为 [表 15.2](#20_chapter15.xhtml#tab15-2) 所示的四类。这些类别在各方面密切相关。每当某一类易受特定攻击时，其他类别也无法确保所需的安全性。因此，某一类别中的适当管理和安全预防措施能进一步加强其他类别，并可能消除后续威胁。因此，云计算中的安全研究应以整体方法解决完整的问题集，而不是迭代或分类地解决威胁。

**表 15.2.** 云安全类别

| 类别 | 描述 |
| --- | --- |
| 数据外包 | 数据的完整性、机密性、真实性、存储、传输和迁移 |
| 访问控制 | 资源的用户级身份验证和授权 |
| 基础设施 | 虚拟化、网络和平台级安全问题 |
| 安全标准 | SLA、审计、实施和服务描述的标准与法规 |
