# Expressing Your Variables and Other Expressions

You can easily manipulate your variables by using basic mathematical operations such as addition, subtraction, and so on. How these operations work depends on the type inside the variable. Take a look at this simple example:

```
```php
<?php
$a = 10;
$b = 20;
print $a + $b;
?>
```
```

This code is pretty straightforward. You can probably see that the number 30 will appear in your browser. As far as operators go, with integers, you have everything you expect, including the following:

+   - + (addition)
+   - - (subtraction)
+   - * (multiplication)
+   - / (division)
+   - % (modulus)

This last operator may be unfamiliar to you. The modulus operator gives you the remainder in a division problem. For example, 54 % 10 yields 4, because 50 divided by 10 is 5 with a remainder of 4.

These operators also work for floating point numbers; however, the modulus (%) operator works only with integers. (The PHP processor doesn't complain if you attempt to use modulus with floating point numbers; instead, it just gives a result of 0.)
