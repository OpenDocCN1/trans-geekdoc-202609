# Aligning controls with e and w

To find out even more about the pack command, try replacing this command in the preceding code:

```
```
pack .buttonbar.bt1 .buttonbar.bt2 .buttonbar.bt3 \
-side left -padx 5 -pady 5
```
```

with the first of the commented-out commands:

```
```
pack .buttonbar.bt1 .buttonbar.bt2 .buttonbar.bt3 \
-anchor e -side top -padx 5 -pady 5
```
```

This stacks the buttons instead of arranging them from left to right. But notice how the buttons are aligned; their right sides all line up. That's because I included the -anchor e option. The e stands for East, which is the right side. Now instead try the next commented-out line:

```
```
pack .buttonbar.bt1 .buttonbar.bt2 .buttonbar.bt3 \
-anchor w -side top -padx 5 -pady 5
