
Here's a Perl example:

```
$str = "hELLo";
if ($str =~ /(?i)hello/) {
    print "Welcome!\n";
}
```

This example prints the string Welcome!, meaning the pattern matched. And here's an example in PHP, which also prints the welcoming string, Welcome!

```

$str = "hELLo";
if (preg_match("/(?i)hello/", $str)) {
    print "Welcome!\n";
}
?>
```

# # Getting greedy (or not)

Suppose you're using a regular expression to look for HTML `img` tags in a string such as this:

```
<body><img src="pic.jpg">This is me!</body>
```

If you just want to find out if this string contains an `img` tag, you can simply match this string against the regular expression `<img\b`. However, if you're trying to obtain the information that follows the `<img` characters and goes up to the closing `>` character, you may run into a problem. Consider this regular expression:

```
<img .*>
```
