# # Keeping Up with Patches and Updates

Because new issues arise with Windows (and just about every other operating system) on a regular basis, you need to have a plan for updating your system. The place to start is the Microsoft Windows Update Web site at windowsupdate.microsoft.com. Once on the Web site, you may need to interact with a couple of security pop-ups. If you click the OK option in the pop-ups, eventually you see an option (green link) that says Scan for Updates, as shown in Figure 2-5. Click this option to start the scanning process.
