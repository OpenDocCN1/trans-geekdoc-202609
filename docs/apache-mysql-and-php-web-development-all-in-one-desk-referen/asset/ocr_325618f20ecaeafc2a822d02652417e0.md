# Building the Registration System

After you create the tables (as described in the preceding section), you can create a page that allows users to register with your Web site. I recommend that you give users multiple ways to get to this page. Here’s the usual way to do this: The users access the system through a central page, where they are presented with a login form. Somewhere on that page is a link where they can register if they haven’t already done so. This is a common method that Web e-mail sites use.

The idea is that users need to access the registration page only once, and they’ll need to use the login page often (hopefully). Thus, the login page should be more readily accessible.

For this set of samples, I have a page called login.html, which I think of as the main access point, and I describe that page in the next section, “Designing a Login Form.”
