Sophisticated programs are more than just a sequence of actions that must be completed one after another, from the beginning of the code file to the end. Instead, sophisticated code usually takes more complicated twists and turns. Take a look at this sample code:

```
$us = "aliens";
print "Hello\n";
print "$us\n";
print "and\n";
print "earthlings\n";
```

When you run this, the program runs the first line of code, which stores the string aliens inside the $us variable. Then the program runs the next line, which prints out the string Hello followed by a newline. Then the third line runs, then the fourth, and finally the fifth.

Everything in this program happens in order, line by line. But this is a simple example. What if you have a more complex task? (Personally, when I'm faced with a complex task, my instinct is to run.) Not everything on this planet happens in a linear sequence of steps. For example, when you log on to check your bank statement, the bank's computer first pulls up your list of accounts. If you have multiple accounts, you will see a balance for each account. Here a sequence of steps must be repeated, over and over, for each account you have.
