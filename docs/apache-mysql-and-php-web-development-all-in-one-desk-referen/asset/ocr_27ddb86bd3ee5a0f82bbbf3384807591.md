I call require only inside the if block. Thus, the PHP processor opens and processes condrequired.php only if the $weekday variable is set to Wednesday. If not, the PHP processor doesn't require condrequired.php. You can do this type of thing if you have a file that you need to require or include only in special situations.

Typically, you'll be using PHP on a Web server that dishes out Web pages. If you have a page that gets lots of hits, conditionally including or requiring other .php files can help speed up your PHP programs because you're not including or requiring files when they're not needed.
