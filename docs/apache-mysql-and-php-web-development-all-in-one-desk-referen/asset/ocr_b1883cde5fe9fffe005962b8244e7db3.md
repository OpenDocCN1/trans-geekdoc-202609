I didn't put a newline in my PHP code. So the PHP code was replaced by the PHP code's output, which was simply the two characters Hi. These two characters don't include any indentation and don't include any newlines.

The word Hi starts exactly where the `<?php` was in the .php file. And immediately after the word Hi is a set of spaces, which were on the original `<br>` line.

If you're really sharp, you may notice a flaw in what I just said. Technically, there is a newline — an HTML newline — in the original myfile2.php file after the end of the PHP code, right after `?>`, which didn't appear in the output. Why wasn't this included in the final output? Frankly, I have no idea. Apparently the PHP processor considers that newline to also be part of the PHP code. Go figure.
