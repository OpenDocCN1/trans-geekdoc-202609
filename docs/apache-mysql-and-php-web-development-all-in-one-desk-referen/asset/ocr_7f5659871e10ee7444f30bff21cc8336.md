builds the associative array with only one description index, and one of the values will be lost. So I tack on the word *as* in the first part of the select statement:

```
phpbase.status.description as status_desc
```

When I get my data back, the status table's description column will instead have the column name *status_desc*. When I access the associative array in PHP, I can get the status description using the name *status_desc*. To get the ad description I can use the name *description*. Thus, I have both columns, and one has been renamed.
