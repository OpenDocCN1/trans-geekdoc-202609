```

In this example, I put together an array, filling it with various song titles. I then copy the array, which is the line shown in bold. When PHP copies the array this way, it also copies the individual elements; this means you now have two separate arrays, $music and $moremusic. To demonstrate this, I then change the song title of the David Bowie entry in the second array to Changes. I print out the song title for the David Bowie entry of the original array and then in the new array, yielding the following output:

Space Oddity<br>
Changes

The original array ($music) still has the original song, meaning the two arrays are entirely separate.
```
