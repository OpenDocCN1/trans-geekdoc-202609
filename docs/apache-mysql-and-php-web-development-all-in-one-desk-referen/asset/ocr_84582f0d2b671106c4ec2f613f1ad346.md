The genpass.php file, shown in Listing 7-9, does the work by first checking whether the e-mail address is in the system. If it is, the code calls the GeneratePassword function in the useraccess.php file, updates the login table with an encrypted form of the password, and then e-mails the new password to the user. To e-mail the password, the mail function takes an e-mail address as the first parameter, a subject as the second parameter, and the e-mail body as the third parameter.

The process I'm describing here is a reasonably secure approach because you can assume that only the user has access to his or her own e-mail.
