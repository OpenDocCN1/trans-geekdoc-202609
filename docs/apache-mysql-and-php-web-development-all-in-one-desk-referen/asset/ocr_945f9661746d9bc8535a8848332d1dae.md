In this chapter, I show how you can use PHP to create Web forms that allow Web site visitors to interact with your MySQL tables. Although showing data from the tables is useful, in some cases you want to give the visitors the ability to add data to your site or to look up information in the databases. Either way, you interact with the user through the use of HTML forms. This shows you how to do just that.

In the examples in this chapter, I use the tables described at the beginning of Book VI, Chapter 4.

# Creating a Lookup Form

If you want to give your Web site visitors the ability to look up data, first you need to decide what type of search criteria to make available to them. In this section, I show you how to do searches based on exact values in the columns. For example, the users may want to look up all ads of a particular category. Later in this chapter, in “Viewing a customer’s ads,” I show you how to provide forms that allow for more flexible searches.
