Tcl includes the usual control structures you would expect to find in any good programming language. However, the syntax of these structures fits into the usual Tcl way of doing things, which may seem a bit strange if you’re familiar with other programming languages.

A control structure is a command that causes lines of code to run multiple times, over and over, either until a certain condition is met, or while something is true. In this chapter, I show you how to program control structures in Tcl.
