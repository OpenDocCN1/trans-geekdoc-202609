Here's a sample program:

```
gets stdin word
if {$word eq "hello"} {
    puts "Hello back atcha!"
}
```

This simple program tests whether the string stored in the variable word is equal to the string hello. Here's a sample session:

```
tclsh ifstring1.tcl
hello
Hello back atcha!
```

If you want, you can also use ne for testing whether two strings are not equal. Try changing the eq to ne in the preceding example to see how it works.

If you want to do a case-insensitive comparison (where hello is considered equal to Hello, for example), use the string equal command with the -nocase option, like so:

```
gets stdin word
if {[string equal -nocase $word "hello"]} {
    puts "Hello back atcha!"
}
```

