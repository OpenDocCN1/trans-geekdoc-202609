The JavaScript in Listing 4-3 doesn't check that the e-mail address is a real address. The code simply makes sure the address has the proper form, such as me@domain.com. Typically, if you want to verify an e-mail address, you use a PHP program that sends an e-mail to the address and waits for a response. If the response comes, you know the e-mail address is valid. I show you how to send out a verification e-mail in Book VI, Chapter 7.

return true;
}
else {
alert("The email address is invalid.");
return false;
}
