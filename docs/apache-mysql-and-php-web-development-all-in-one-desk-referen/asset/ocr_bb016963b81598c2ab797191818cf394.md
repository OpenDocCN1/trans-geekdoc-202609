# ## Building Classes

In addition to having a full procedural-based syntax, PHP also offers object-oriented programming through classes. The syntax for classes is simple, as you can see in the following code:

```
<?php
class Pumpernickel {
    var $ounces;
    function tell_all() {
        print "Today's pumpernickel bread has only
        {$this->ounces} ounces remaining!<br>";
    }
}
```
