You don't have to return just a scalar. You can also return an entire list, as in this example:

```
sub Sequence {
    $start = $_[0];
    return ($start, $start+1, $start+2, $start+3);
}

@mylist = Sequence(10);
foreach (@mylist) {
    print "$_\n";
}
```

Here's the output from this program:

```
10
11
12
13
```
