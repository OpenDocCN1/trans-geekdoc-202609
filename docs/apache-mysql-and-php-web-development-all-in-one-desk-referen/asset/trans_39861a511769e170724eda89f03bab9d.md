

## 关于作者

**杰夫·考格斯韦尔** 是一位成就卓著的软件工程师、教师和作家。
他撰写了十本关于编程的书籍，被公认为最优秀的教师之一。他辅导和教授的学生数不胜数，并参与过许多专业软件项目。他游遍了美国各地，但仍未去过欧洲。
