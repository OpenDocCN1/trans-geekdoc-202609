# Creating the Login Tables

When you set up your user login system, first you need to set up the MySQL
tables. As usual, I recommend that you type the SQL in a file by itself and
then run the file using a line such as the following:

```
mysql -u root -p < tables.sql
```

The tables.sql file in Listing 7-1 contains the data for the tables. When
you make your own tables, remember to include the use phpbase line at
the top of the file.
