In This Chapter

+   - Storing data in a variable
+   - Working with scalars
+   - Putting special characters and variables inside a string

+   - Storing associated data with hashes

Perl has an incredibly simple data type system. Although other languages have a dozen data types for numbers alone, Perl has only three main data types:

+   - Scalars
+   - Lists
+   - Hashes

In addition, Perl has two other specialized data types:

+   - File handles for reading files
+   - Directory handles for reading directories

If you're already familiar with a programming language, you'll be interested to know that even though you can have strings and numbers in Perl, they're all treated as a single data type. I explain how this is possible in the section "Storing Single Items as Scalars."

In this chapter, I introduce the three main data types: scalars, lists, and hashes. You can find information about file handles and directory handles in Book III, Chapter 5.

To really understand the Perl mindset, I encourage you to read the final section of this chapter, "Talking about Scalar Context and List Context." The information in this section helps you fully understand how Perl handles functions and other features. (The information will help you remain sane and keep all your hair later on.)
