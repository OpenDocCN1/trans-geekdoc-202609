# # Chapter 4: Accessing MySQL from PHP

# ## In This Chapter

+   - Connecting to MySQL from PHP
+   - Adding MySQL data with PHP
+   - Entering data with PHP and a form

In this chapter, I show you how to write PHP code that connects to a MySQL database. You can create rather powerful Web sites in this manner; your PHP code can access data from a MySQL table and use that data to customize the Web page. Online retailers, for example, can create a .php file to look up product information from a database and build a product page. The Web user sees a different page for each product without even realizing the pages were built dynamically.

For the examples in this chapter, I'm using the following database, tables, and user information:

+   - The database name is `phpbase`.
+   - The username is `phpuser`, and the password is `phppass`.
+   - The table names are `customer`, `ad`, `category`, and `status`.

For details on creating these tables, see Book VI, Chapter 3.

# ## Connecting to MySQL from PHP

Before discussing how to connect to MySQL from PHP, I want to remind you that because PHP is a server-side language, all the MySQL access takes place on the side of the server. When you access MySQL through PHP, the end user's client computer does not access MySQL. PHP is a preprocessor that receives .php files from the Web server, processes the PHP code inside the .php files (code that can include MySQL calls), generates a resulting .html file, and sends the .html file back to the Web server, which sends it to the client browser.
