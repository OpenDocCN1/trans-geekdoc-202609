I put the PHP portion of this example in bold to help you sort it out from the rest of the code. Placed before the PHP section is a section of HTML code that ends with an opening <pre> tag. Then comes the PHP, which includes a heredoc statement that writes out another tome, which in this case is C++ code. (You don't have to know C++ to understand this example; I just wanted to use a different language for the output. As far as PHP is concerned, it's just text. The PHP processor does not attempt to run the C++ code. To PHP, the C++ garbage is just a string.)

But look! Inside this string, I've embedded a PHP variable, $myname. If you were reading a value into the $myname variable from a database, rather than hardcoding the string Perseus of Andromeda as I have here, you could seriously customize the output.
