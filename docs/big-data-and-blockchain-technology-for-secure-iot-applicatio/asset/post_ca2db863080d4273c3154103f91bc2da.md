Subsequently, the collected data undergoes a classification process based on the characteristics of the tasks it represents. Specifically, tasks are categorized into two main types: delay-sensitive tasks and non-delay-sensitive tasks.

This classification is crucial for determining the appropriate allocation of computational resources in the CFC environment. The classification of tasks in CFC based on their delay sensitivity can be represented using a mathematical equation that assigns a binary value indicating whether a task is delay-sensitive or not.
