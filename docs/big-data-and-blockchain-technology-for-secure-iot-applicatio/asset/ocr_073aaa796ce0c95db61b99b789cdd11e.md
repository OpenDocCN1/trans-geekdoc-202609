# 11.3 SYSTEM MODEL AND PROBLEM FORMULATION

# 11.3.1 System model

The system model for TS in CFC, employing the HSMAO scheduler, begins with the collection of IoT (Internet of Things) data from end devices. This data collection phase involves gathering information from various sensors, devices, or endpoints distributed across the network. Subsequently, the collected data undergoes a classification process based on the characteristics of the tasks it represents. Specifically, tasks are categorized into two main types: delay-sensitive tasks and non-delay-sensitive tasks.
