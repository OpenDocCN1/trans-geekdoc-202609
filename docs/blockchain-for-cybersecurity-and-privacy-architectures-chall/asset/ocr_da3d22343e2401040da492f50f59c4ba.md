With the emergence of IoT, health monitoring became more patient-accessible. Various researches are going to ensure the easy access of IoT in the blockchain domain. One of the important factors in a large network where information exchange is involved in mapping various devices is to agree to a common standard. Yuan-Fe Lee [12] showcases the hindrances in exchanging trustworthy information between healthcare devices. Yuan-Fe proposes X7-PHD system for non-healthcare devices that do not use the X7-PHD standards. The fast improvement of mobile computing prompts another idea of a pervasive social network (PSN)-based social insurance. The PSN-based blockchain [13] empowers clients to share information gathered by sensors. The system design is implemented following two protocols: the first protocol uses IEEE 802.5.6, and the second protocol uses blockchain, which is based on PSN to distribute health information.

One of the innovations in the medical field is decentralized storage of patient's records. Smart contract, an application of blockchain, is used to store medical records. The system called Medrec by Azaria et al. [14] discusses the use of using blockchain to store the medical record. The article does not speak about any security feature that is provided to ensure the security of the records. Because of the highly sensitive nature of health records, security is of prime importance.

Healthcare records are usually very large in size. For a example, digital X-ray can be of a size of 20 MB. Storing such large-sized records on the system/blockchain is not a good idea. Each record in the blockchain is stored by all members in the network. The record storage will consume a lot of memory and to develop a scalable network, off-chain storage of health records is a good solution. InterPlanetary File System (IPFS) is a distributed peer-to-peer file system for storing records. The IPFS white [15] explains the design and algorithms that work the implementation of IPFS. The system combines concepts from different distributed file storage systems such as BitTorrent and Git to develop a well-protected, scalable, and innovative distributed file system. Files or records are stored in the IPFS depending on their size. Distributed hash tables (DHT) are used for querying and storage of objects. If the records are small, then are stored directly in DHT, else the hashed values of the identity of nodes that store the health records are stored. The IPFS is in its nascent stage, and it will soon replace HyperText Transfer Protocol (HTTP), marking the end of a centralized storage mechanism in the Internet. Chen et al. introduces an innovative design to collaborate IPFS and blockchain to provide better storage options [16]. The data storage algorithm in the IPFS, BitSwap, is modified to accommodate storage of large amounts of data. A design is of greater importance, considering the growing importance of BigData.
