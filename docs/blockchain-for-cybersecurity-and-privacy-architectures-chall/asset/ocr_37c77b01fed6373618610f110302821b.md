# 2.3.11 Gossip Protocol to Achieve Consensus for Decentralized Distributed Systems

A DLT runs a gossip protocol, meaning that each member repeatedly calls on others to synchronize with them. In this way, information is spread by each node recurrently picking another node arbitrarily and sending whatever they have learned. We will discuss one of the DLTs, i.e., hashgraph. In this algorithm, each member creates an event, (when he created the event), transaction, and hashes of the small data structure containing timestamp (of the last two events), and is digitally signed by the creator. The motive of the underlined algorithm is to achieve consensus on the order of the events and the agreed timestamp for each event. Suppose four nodes are present in system: A, B, C, D chooses to call D and sends all the events that D doesn't know. Let's consider it to be the start of a gossip. Therefore, B call had only one event. D records the call in a new event, which comprises a timestamp, transaction, and hashes of the two events below itself (one is labeled as the self-parent and the other as part). D then sends all the hashes to A, and in return creates a new event recording, including the hashes of the latest event by him and D. After that, A sends all his events to C; consequently, C creates a new event, and this graph keeps on increasing. As it is connected to cryptographic hashes, it is labeled as hashgraph. Gossiping a hashgraph grows the nodes ample details; therefore, whenever a new transaction is added, it rapidly spreads to all other nodes. However, as the hashgraph grows, it might be possible at some point in time that some nodes have marginally different data of the newly created events, but they will converge quickly to sync with each (Schueffel, 2017).

Consensus agreement is another process that makes use of virtual voting; i.e., each node of the network has a duplicate of the hashgraph. Therefore, node calculates for themselves what poll other nodes would have sent in case an agreement protocol is running by simply constructing the hashgraph (Allavana, 2006). So, consensus is achieved without using any bandwidth. This also helps in the integrity of the protocol, as the node calculates abiding with the rules. If even a malicious node tries to attack, he could not post votes for the other nodes to calculate, because all of the nodes are calculating for themselves, assuming the virtual votes cast by the virtual version of the members.
