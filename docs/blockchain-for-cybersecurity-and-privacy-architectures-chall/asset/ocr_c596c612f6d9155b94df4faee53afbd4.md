# 1.2.3 SMART CONTRACTS

Ethereum was launched in 2015, and the virtual coin 'Ether' was proposed as the Ethereum cryptocurrency [14]. Similar to fiat currencies, Ether values and balances have standardized mechanisms for smaller units such as Wei, Kei (1K Wei), and Mei (Mega Wei), and one Ether is (10 **18 Wei). Ethereum miners maintain the state of the network and resolve possible conflicts to, for example, attacks or failure by using a consensus mechanism. The current consensus used in Ethereum is the PoW consensus, which relies on the assumption that miners will follow the mechanism rather than attacking it, the mechanism will pay them for the computation needed to maintain the network and users pay execution fees for every transaction [8]. Ethereum supports all types of computational structures, including loops, which can run any decentralized application (DApp) programming code utilizing the back end Ethereum 'smart contracts'

Smart contracts are digital contracts that are executed by themselves when certain circumstances are met and can be developed and implemented on top of Ethereum blockchain. the smart contract can symbolize the digital ownership and everything of value such as property
