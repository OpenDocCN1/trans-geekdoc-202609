# 8.1 引言

根据国际汽车制造商联合会（OICA），2016年汽车产量超过了7000万辆。汽车销量从2015年的5000万增长到2018年的7800万。这一数字仍在增长，导致道路上的车辆数量相应增加。因此，道路的安全性和效率以及乘客的娱乐正成为研究人员和开发人员关注的重点之一。随着通信技术和汽车行业的发展，物联网（IoT）已成为一种底层技术，允许在各种设备之间进行实时数据感知、处理和传输。
