# 14.3.1.3 Data Provider

Figure 14.5 provides the data provider core elements governing the data profile. For the purpose of storing data securely in blockchain network, a data provider needs to maintain a data profile that includes private key management and storage, which is used to encrypt the hash value of data. The data providers maintain their personal identity, which is automatically verified through smart contract. The data profile needs to link with the data sources via Application Programming Interface (API) access keys, and the data profile should be updated.
