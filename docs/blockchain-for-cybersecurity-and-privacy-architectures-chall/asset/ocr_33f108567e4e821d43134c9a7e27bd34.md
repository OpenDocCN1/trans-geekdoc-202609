Future scholars can also improve the blockchain-based data sharing by adopting traditional security and access control frameworks, such as security vulnerability model [46] and context-aware access control model [47,48], and working toward future implementations of blockchain-based access control frameworks for secure data access [49], by managing imbalanced data [50], and for data federation through authentication [51].
