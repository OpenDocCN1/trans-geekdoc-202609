# 7.1.1 CONTENT-CENTRIC NETWORKING

Content-centric networking (CCN) is an information-centric networking (ICN) (Mosko et al. 2016) instance that supports location independence by separating content from its source and reducing traffic through caching feature.. exchanges on this architecture are based on the publish/subscribe model; the name of object is published, and an object is requested by sending the Interest packet (Figure 7.1).

In CCN, data packets are sent in response to a requested Interest packet, and data fragments are cached along the path back to the requester. Instead of using the source and destination addresses of hosts, the CCN packets contain the name of the content that user wishes to access. It allows users to have more bandwidth and less latency simultaneously and securely. CCN promotes the use of multiple sources (Labbi et al. 2016) to retrieve the same content.

Table 7.1 contrasts the basic CCN concepts with those of Transmission Control Protocol/Internet Protocol (TCP/IP). The key idea of CCN lies in using names rather than addresses to forward content on the network. They are used to identify the associated contents unambiguously. These names are also used in all network operations, such as announcing, requesting, and distributing content. Each content is divided into several parts (MTU) as not specified, and there is some possibility it may be larger than the MTU in IP networks.
