# 8.6.4 CLOUD LAYER

It is used to store the blocks that can be used only for messages traceability. The emergency messages require a predefined time; after expiration, the old messages are stored in the MB deployed in the cloud. The fresh or recent messages are stored in the auxiliary blockchains deployed on fog nodes.
The integration of the fog computing paradigm reduces the delay of the block generation because the data are analyzed locally. However, the choice of algorithm has not been settled. Designing specific consensus protocols for critical blockchain-based IoV applications would be beneficial. We proposed to delete old block from the chain even if it contradicts the characteristic of immutability of blockchain, to provide IoV scalability. Therefore, editable blockchains are highly required. In a fog-bashed network, trust management between fog nodes is an issue that needs to be addressed.
