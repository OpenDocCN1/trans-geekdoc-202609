# 用于网络安全与隐私的区块链

本文探讨了区块链的架构及其应用。我们调查了基于区块链的方案在车联网（IoV）安全领域的最新研究，并根据区块链概念和应用对其进行了分类。根据攻击模型、安全需求、成本和局限性，提供了经典方案与基于区块链方案的分类。最后，我们讨论了与区块链集成相关的开放问题，并提出了一种新的架构以解决扩展性、延迟和频率问题。
