The BFT is a property of hashgraph that attains it superior. An individual cannot stop a system from attaining consensus, neither they have the ability to change the consensus. There is a point in time when we reach consensus and we know that we have reached, and every individual will have the same consensus. Whereas in blockchain, Byzantine is not guaranteed, as an individual is never certain that they have reached consensus. It is also considered to reach Byzantine agreement, because it is unable to handle network barriers. Miners getting isolated from the network give birth to forks, because multiple chains are created.

Hashgraph is being used as a distributed database and hence is Atomicity, Consistency, Isolation, Durability (ACID) compliant. Individuals in a network use of this property to reach agreement on the order of transactions. After consensus is attained, every individual the transactions to their local copy of the DB by order of consensus. If the local DB is ACID compliant, then the entire system will have the same characteristics. Whereas in blockchain, there is no point in time when we are certain that consensus has been achieved. In order to attain ACID compliance by hashgraph, confirmations could be considered as certain.

Efficiency in the blockchain is not 100%, as the block that has been mined at times be marked as stale; therefore, the gets wasted. Whereas in hashgraph, there's no concept of stale; hence, it is considered to be 100% efficient. In Bitcoin, a lot of time, effort, and proof are wasted in calculations (proof of work), which also have to make the speed of mining blocks slower. Expensive hardware needs to be used in order to drive the mining. Whereas in hashgraph, no such mechanism is used; therefore, it is inexpensive.

In hashgraph, each individual is assigned a time for consensus, and it is the average time at which every individual first received. It, hence is to be timestamped. The timestamp is said to be reliable automatically if the supermajority population is truthful and their clocks are trustworthy. It is considered to be part of consensus; therefore it to Byzantine and provable. The timestamp is beneficial for smart contracts, as the consensus will be if the event occurred in a given time. Whereas in blockchain, every block has a timestamp, but it only redirects the miner's clock who mined the block.

The Dos resistance is found in both hashgraph and blockchain. An enemy might cease a miner's bandwidth by sending packets and cut off them from the rest for a while, the network keeps working normally. If an enemy needs to attack the entire network, then it will require him to send unwanted packets to a larger population. A lot of blockchain variants have been suggested to evade proof of work. Nonetheless, they are not DOS resilient. If the current leader is being attacked by an intruder and it quickly attacks the new leader, the whole system will be halted in this way. Whereas, hashgraph without using proof of work prevents this issue from occurring.
