# 12.2.2.1 Attack on Wallet Software

A wallet stores the digital credentials of cryptocurrency holdings and allows the user to access and spend them. Software wallet attacks can be in the form of loss of private keys or signature forgery, leading to loss of digital money. Barber et al. (2012) proposed the idea of ‘Super-Wallet’ to address the user concern, which is split across multiple computing devices. The super-wallet acts as the user’s ‘personal bank’, where most of the user’s coins are stored. Besides this, the user also uses a sub-wallet in the smartphone. Whenever needed. User can spend small amounts of money from super-wallet into sub-wallet, whenever needed. User can spend money from the smartphone itself if it is lost or attacked by malware, only a small amount of money will be lost. The larger amount is secure in super-wallet and can be spent through a multiple of devices. Constant backup of wallet file helps to overcome accidental loss or data destruction.
