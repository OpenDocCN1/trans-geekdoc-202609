

# 包容性措施

包容性措施是指在身份建立并确认后，基于凭据或通过屏障来限制对资产和资源访问的实践。例如，包容性技术可能包括访问控制列表（`ACL`）、防火墙服务、Web 应用程序防火墙（`WAF`）服务、网络准入控制（`NAC`）、基于角色的访问控制（`RBAC`）、身份管理、无线网络控制以及端口级身份验证/授权。

# 排斥措施

排斥措施旨在通过阻止未经授权的渗透尝试来防止访问或非法入侵。这些措施可能包括入侵检测和/或防御系统（`IDS/IPS`）、端点安全（`HIDS`，安全代理）、流氓无线端点检测和隔离、防病毒（基于主机和网络）、反间谍软件、反垃圾邮件过滤器、补丁管理和安全监控。

# 资产跟踪

如果物理介质离开设施，可以在高价值资产上植入 RFID 标签等设备以进行跟踪。GPS 定位器可以提供位置和移动的实时监控。

# 数据保护

信息权利可以进行管理，仅允许经过身份验证和授权的用户访问。此外，文件和文档保护程序可以在敏感信息在设定时间内未得到处理时将其“过期”，此外还包括加密最佳实践。

# 段落摘要

一个经常萦绕在我脑海中的场景是笔记本电脑或存储介质被盗，其中存储静态数据的设备可能包含非常敏感或有时是机密信息。例如，我们都曾得知笔记本电脑被盗的公开事件，当新闻快讯提醒我们退伍军人管理局的一台笔记本电脑丢失，据称包含数百万军事退伍军人的人员记录。2008 年初，国家卫生研究院的一台笔记本电脑被盗的事件也被公开，该笔记本电脑包含近 2,000 人的私人医疗信息。在这些案例以及全球类似事件中，直到很久以后才清楚这些盗窃是如何几乎不被察觉地发生的，而且在大多数情况下，信息除了笔记本电脑本身的密码保护访问外，并未加密。

如果我们应用分层防御策略来防止信息丢失，我们可以采用物理屏障和智能建筑访问技术等策略来排斥或限制对设施的访问。借助边界安全设备和监控技术，组织在攻击者和窃贼接触高价值资产之前发现他们的机会要大得多，即使他们突破了设施的外部防御。一旦入侵者渗透到设施内部，在敏感区域增加安全性可以阻止攻击。通过身份验证/授权、端口级安全性、`ACL` 以及大量其他网络访问和准入控制等策略增强网络安全，可以使攻击者几乎不可能接触到任何信息。如果介质被捕获并从设施中移除，可以通过 RFID 标签和/或 GPS 定位器进行跟踪。如果出于任何原因资产丢失，可以使用静态数据加密和权限管理实用程序，在设备被盗被知晓后或在预定的“过期”期限后，基本上使这些设备失效。

分层防御起源于军队，其战术和策略已被全球军事和商业组织广泛部署，已成为信息安全和物理（环境）安全领域安全专业人员中广泛使用的最佳实践。

# 边界入侵检测

事先得到充分信息并提前获得通知，往往能让知情者在物理（环境）安全方面获得巨大优势。边界入侵检测可以提供必要的警报和通知，以警告潜在攻击或攻击开始时的情况。在现代信息安全实践中，利用网络的覆盖范围和访问权限是安全专业人员的力量倍增器，使他们能够立即得知安全事件，无论身在何处。利用网络进行边界安全还使安全团队能够以更少的人力做更多的事情，我们将在本章节中探讨一些关键示例，说明这是如何实现的。同样，我们对边界入侵检测的了解很大程度上归功于军队和执法界，他们的生命依赖于准确的早期检测流程来保持态势感知，并受到附近存在的威胁的警报。在本章节中，我们将重点关注边界安全方面的三个感兴趣领域：

* 感知与执行
* 物理访问控制
* 视频监控与分析

# 感知与执行

*传感器*：探测器是一种实时检测动作或某些对象或实体存在的设备。

*执行器*：这是一种响应输入或指令执行特定操作的设备。可以打开或关闭设备，并可以联网并远程操作。

# 定性与定量传感器

定性传感器报告对象、人员、模式或某些活动的存在或不存在。这些可以是运动传感器、音频传感器、声纳（`SONAR`）、视频分析、“电子眼”和光传感器等设备。

定量传感器测量相对于可接受范围或其他参考点的物理属性及其相关变化。示例包括近接传感器、温度传感器、湿度传感器、气压传感器、地震传感器、加速度计、流量传感器，以及针对化学、生物、放射性、核和爆炸材料的传感器。
