

如果你记录下关于工作和同事的细节，有人可能会利用这些信息对公司发起社会工程攻击。（通常是在你不在的时候，如果你在电子邮件中提供度假消息，并在 LinkedIn 上提供行程安排。）当涉及的不是你自己的信息时，要更加小心，而不是放松警惕。我并不是一个特别注重隐私的人，我在 Flickr、Twitter、Facebook 和 LinkedIn 上都有账号，还有博客和网站。不过，你会注意到，除非朋友和家人自己想要提供，否则这些平台并不会提供太多关于他们的信息。

除了直接泄露之外，还存在聚合信息的问题。已经有系统利用社交媒体网站（甚至网络搜索引擎）的数据来收集天气信息并预测流行病。这并不是基于大量受过训练的志愿者的报告，而是简单地在海量闲聊中搜索特定关键词。海量数据为数据提供了高度的准确性，即使有人知道情况并试图扭曲曲线也是如此。

但是，也有可能随时间追踪个人并发现大量信息。Twitter 现在正在提供通过手机或移动电话发帖者的位置信息。随着时间的推移，这将建立起你在一天、一周或一个月中特定时间的可靠位置模式。（攻击者随后可以在你在家或吃午饭时发动上述社会工程攻击，或者在你上班时入室盗窃。）

（还记得那张尴尬的照片吗？即使你将其从页面上移除，即使网站实际上删除了它，也有系统会定期对互联网进行“快照”。这些材料可能仍然存在于某个档案中。）

此外，还存在信息可以跨不同社交系统聚合的事实。你可能在一个网站上提供一些信息，在另一个网站上提供不同的、也许是互补的数据。（在这方面最大的问题是在所有不同网站上使用相同密码的做法。最近有一个案例，攻击者能够破解一个保护较少的网站上的密码，然后利用这些密码劫持 Facebook 等系统上的账户。）

（顺便说一句，不要依赖自己创建一个带有可爱 \[且虚假\] 名字的“匿名”账号的能力，甚至不要依赖使用匿名系统。仅仅通过发帖，你就开始泄露关于自己的信息：即使是你使用的词语选择也可能识别出你。我是安全社区和讨论组的成员，见过无数个人试图以别名为名来惹恼社区的实例。这或许是尝试此类行为最愚蠢的场所：这些人拥有在网络空间进行大量追踪的技能和联系。在一个案例中，集体成员感到足够恼怒，以至于不仅查明了匿名发帖者的身份、姓名、住址和电话号码，还有一些人实际上外出拍摄了他的工作场所和学校的照片。其他社区的人可能没有数字取证培训，但肯定有一些人拥有足够的技术知识，开始拼凑你留下的线索。你在 Web 2.0 上泄露的关于自己的信息远比你想象的要多。）

（在撰写本文的最后阶段，我被介绍到一个允许你创建自己的卡片，然后将其打印并邮寄的网站。建议的用途之一是以这种方式制作圣诞卡：速度快，与购买商业卡片和普通邮资相比，价格合理。该网站有多个级别的“会员”可供购买，风格类似于多层次营销系统。你真的想把你的整个联系人列表给传销商吗？）

# 企业

另一个危险是提供过多关于公司的信息。我们提到过，攻击者可能会利用关于同事、上级、下属以及公司活动和政策的披露来发动社会工程攻击。但是，还存在泄露关于产品、服务、定价、客户甚至商业秘密的敏感信息的风险。社交媒体网站一直追求功能胜过安全。许多网站现在开始更加重视安全，但这些系统根本不具备你可能会给予自己企业资源的同等保护水平。

社交网络网站确实有保护措施，但要弄清楚某些设置究竟起什么作用可能极其困难。在你知道你的信息是否真正受到保护之前，可能需要大量的试错。如果你打算使用 Web 2.0 系统，请务必做好功课。

（如果你在 Facebook 上使用“应用程序”，无论是哪种应用程序，你都应该意识到，`所有`你的信息都可供该应用程序使用，无论你认为自己将信息设置得多么私密和保密。并非所有应用程序都会读取你的所有数据，但任何应用程序都可以。下次你想给某人发送一只可爱的粉色水母时，想想这一点。）

与电子邮件一样，你可能应该制定明确的政策，规定员工在社交网站上可以和不可以说什么。对使用社交网络网站实行全面禁止可能不是个好主意。更好的主意是让员工意识到危险，以及你希望他们小心的原因。

（你应该非常小心发布受版权保护的材料。这可能会给你带来法律麻烦。但是，要特别谨慎发布任何受版权保护的公司材料。许多网站都有政策规定，一旦你在系统上发布某些内容，该内容就归他们所有，或者至少他们可以随意使用。通过发布公司拥有版权的内容，你可能会使该材料脱离版权保护，并为公司造成价值损失。）

# 其他

关于社交系统上的个人信息，还有另一个危险，那就是来自你的朋友。你经常以各种方式创建关于朋友和家人的信息，例如在图片分享网站上给他们打标签。其他人也会对你这样做。你可能会惊讶地发现，即使你自己不参与社交网络活动，互联网上也有大量关于你的信息。偶尔进行一次“自我搜索”可能是个好主意，找出其他人关于你发布了什么。自我搜索只是使用任何搜索引擎搜索你的姓名或你常用的任何昵称。现在还有一些服务会自动在多种搜索引擎上搜索，专门用于查找这类关于个人的信息。

我对“Robert Slade”进行了这样的搜索。在 Altavista 上，第一个结果是某人关于我的维基百科文章。第二个结果是 `http://www.robertslade.com`，我之前不知道它的存在。这个页面不仅正确列出了我出版的书籍，还告知我我在 RISKS-Forum Digest 的维基百科条目中被提及。它还提供了一张其他人的照片。（一位名字相同的萨里大学化学教授，但不是“Robert Slade 互联网俱乐部”的成员。）搜索图片时，我也找到了我被埋葬的教堂，所以也许如果这篇文章交得有点晚，我可以被原谅。
