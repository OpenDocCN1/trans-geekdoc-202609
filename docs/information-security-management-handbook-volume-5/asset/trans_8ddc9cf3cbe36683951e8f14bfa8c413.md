

以电子方式存储的信息不仅范围广泛，而且已成为美国生活中基本且不可或缺的一部分。据所有报道，当今开发的信息中有超过 90% 是以电子方式创建和存储的，而且大部分永远不会被打印出来。此外，正在创建的信息量惊人：例如，据估计，美国企业每年交换约 2.5 万亿封电子邮件，并且据信其中 75% 的电子邮件包含专有信息。在越来越多的纠纷中，与各方主张和抗辩相关的信息不再在文件柜中，而是在硬盘上。

电子发现是一个复杂且困难的过程，需要技术、法律和业务人员之间高度协作。

# 电子文档与纸质文档有何不同？

以电子方式存储的信息为文件制作带来了独特的机遇和问题。这些微妙但有时深刻的差异可以分为六大类。

# 大量且易于复制

以电子方式存储的信息创建速度远高于纸质文档，因此电子文档远多于纸质文档。今天，美国绝大多数家庭和企业都已连接到互联网。电子邮件使用量和电子文件生成量的急剧增加给大型企业带来了特殊问题。一家大型企业每天可以生成和接收数百万封电子邮件和电子文件。与纸张的 0.01% 相比，92% 的新信息存储在磁性媒体上，主要是硬盘。毫不奇怪，企业中电子数据的激增导致了海量数据的积累。虽然几千份纸质文档就能填满一个文件柜，但一台小书大小的计算机磁带或磁盘驱动器就能存储相当于数百万页打印页面的数据。随着数据的存储、传输、复制、复制、备份和归档，组织通常会积累成千上万这样的磁盘和磁带。

电子文档比纸质文档更容易复制。例如，电子邮件用户经常将同一封电子邮件发送给许多收件人。这些收件人又经常转发该消息，以此类推。同时，电子邮件软件以及用于传输消息的系统在发送和重新发送消息时会自动创建多个副本。同样，其他业务应用程序旨在定期和自动制作数据副本。这些应用程序的示例包括自动保存的网页以及常规备份以防止意外删除或系统故障的文件数据。

# 持久性

电子文档比纸质文档更难处理。尽管尝试删除电子文档，但信息可能会留在电子存储设备上，直到被新数据覆盖。与此同时，它可能仍可用于发现。在 Prism Hospital Software Inc. v. The Hospital Records Institute 案中，被告提供了大量磁性媒体，原告能够从中找到一系列文件，这些文件虽然已“删除”，但仍然存在。以电子方式存储的信息的这种持久性加剧了其在保管人可能不知道信息仍然存在于其计算机上的隐藏位置积累的速度。由于很难完全删除以电子方式存储的信息，因此有软件声称可以通过多次反复覆盖数据来完全擦除或“擦拭”数据。

# 元数据

电子文档包含称为“元数据”的信息，即操作系统或应用程序关于文件的信息，允许操作系统或应用程序在以后日期存储和检索文件。没有特殊工具，计算机用户无法访问大部分元数据。

元数据包括文件名称、创建和编辑日期、作者以及编辑历史的信息，以及系统管理中使用的数百个其他信息片段。例如，电子邮件元数据元素包括邮件发送、接收、回复或转发的日期，密件抄送（“bcc”）信息以及发件人地址簿信息。互联网文档包含隐藏数据，允许互联网用户的计算机与文档所在的服务器之间传输信息。所谓的“元标签”允许搜索引擎定位符合指定搜索条件的网站。“Cookie”是嵌入式代码，可以放置在计算机上（无需用户知晓），可以跟踪用途并将信息传回 Cookie 的发起者等。

元数据在诉讼中的文件保存和制作方面带来了独特的问题。一方面，可以设想元数据对于验证文件或确定与纠纷相关的事实是必要的情况，例如在涉及商业秘密盗窃的诉讼中访问文件的时间。另一方面，计算机记录的信息可能不准确，这也存在真正的危险。例如，当新员工使用文字处理程序通过前员工创建的备忘录模板创建备忘录时，新备忘录的元数据可能会错误地将前员工标识为作者。另一方面，电子邮件可能有一些非常有用的元数据，可以提取并用于生成用于审查或诉讼支持工具的 to:、from:、date: 和 cc: 字段。与可能从模板转移的错误信息不同，一些电子邮件元数据通常是准确的，自动捕获它可以节省时间和金钱。决定哪些元数据需要特别保存和制作，是电子文件制作中最大的挑战之一。

# 动态、可变的内容

与纸质文档不同，电子文档具有动态特性，可能会随时间变化，通常用户甚至不知道正在发生变化。数据库不断用新信息更新，最常见的是通过直接用户输入，但也可以通过其他系统自动更新。例如，一家拥有十四个地点的商店可能会让每个地点的会计系统每天将销售信息更新到主系统。由于商店可能位于多个时区，更新后的数据将在一天中的不同时间出现。在这种情况下，决定保存用于发现的数据库的哪个“版本”是合适的可能会很棘手。

电子邮件、文字处理器或电子表格等标准办公应用程序也具有动态特性。打开电子邮件可以更改日期和时间。每次复制电子表格或文字处理文档时，元数据元素都会更改以反映新的日期和时间。与其他文件链接或嵌入其中的文件，在相关文件更改时可能会发生变化。向许多用户（“虚拟”工作组）共享应用程序数据文件的趋势进一步加剧了发现问题，因为文件中的数据可能会在没有特定保管人意识到变化的情况下发生变化。

在发现过程中，管理以电子方式存储的信息的动态性是一项持续的挑战。
