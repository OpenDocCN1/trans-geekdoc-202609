# IPv6 Features and Benefits

IPv6 的主要优点包括：

1. 更大的地址空间
2. 更简单的 IP 头部，以实现灵活性和创新
3. 提高效率（即，路由）
4. 增强的移动性
5. 改进的 QoS
6. 集成 IPsec
7. 更容易的配置功能（GAO, 2005）

# Additional Address Space

Beijnum (2010) 指出，截至 2010 年 1 月 1 日，在 4,294,967,296 个可用 IPv4 地址总数中，大约 16% 或 722.18 百万个 IPv4 地址仍然可用。相比之下，IPv6 的可能 IP 地址数量约为 3.4 × 10^(38) 或 340,282,366,920,938,463,374,607,431,768,211,456（Beijnum, 2006）。这个惊人的数字是 IPv6 的 128 位寻址方案与 IPv4 的 32 位寻址方案相比的结果。换句话说，IPv6 拥有足够的 IP 地址空间，可以“为地球表面的每平方米提供 655,570,793,348,866,943,898,599（6.5 × 10^(23））个地址”（Microsoft, 2008, 8）。这一事实的意义将在后面的安全问题部分中讨论。

“IPv6 有三种类型的地址：单播、组播和任播”（Beijnum, 2006, 15）。单播地址是一对一的通信，很像当前在 IPv4 中使用的通信（Beijnum, 2006）。组播是一对多的通信，很像 IPv4 中的广播功能；不过现在更具针对性，只有那些有兴趣接收通信的人才能监听（Microsoft, 2008）。任播与组播类似，只是“发送到任播地址的数据包只传送到任播组中的一个系统，而不是全部系统”（Beijnum, 2006, 15）。为了澄清，任播被定义为路由方面的“最近”接口。任播是一对一对多的传输（Microsoft, 2008）。在使用任播和组播地址时有几个问题需要考虑，这些问题将在本文的安全部分稍后讨论。

# Simpler IP Header for Flexibility and Innovation

审查 [Figure 7.3](#9781466508507_epub_c07_r1.htm#fig_7.3) 中的“IPv4 和 IPv6 头部比较”表明，14 个头部字段已减少到 8 个（GAO, 2005）。IPv6 中的头部大小现在是固定的，而在 IPv4 下头部大小可能会变化。IPv4 地址空间尚未耗尽的主要原因是使用了 NAT，而 NAT 严重限制了点对点应用程序（Beijnum, 2006）。IPv6 可以完全实现点对点应用程序等技术（Beijnum, 2006）。例如，IPv6 可以支持游戏、VoIP、视频会议等。这是因为可以为每个 IP 启用的应用程序提供 IP 地址，从而消除了对 NAT 的需求。

简化的头部可以提供新功能或扩展（GAO, 2005）。随着新功能的出现，未来将面临未知的问题，因为 IPv6 技术仍在成熟中。

# Improved Efficiency

当今市场上的大多数处理器是 32 位 CPU 和 64 位 CPU，几家供应商提供相应的 BUS 架构。IPv6 的头部针对一次处理 64 位进行了优化，而 IPv4 头部为 32 位。为了提高效率，移除了 IPv4 校验和头部。在 IPv6 下，路由器不需要分片超大数据包（Beijnum, 2006）。现在它们只需向“源”发送信号，要求其发送较小的分片。从创立之初，IPv6 就设计用于支持高效的分层路由和寻址。相比之下，IPv4 有三类 IP 地址，并且有充分的文档记录表明，这些 IP 地址中的大部分不是连续地址。

# Enhanced Mobility

每个网络接口卡（NIC）供应商在世界上都有一个唯一的供应商识别号码。机器地址代码（MAC）基于电气和电子工程师学会（IEEE）提供的供应商唯一识别号码以及每个 NIC 上的序列号（由供应商在制造过程中生成）。传统的 IPv4 MAC 地址是一个 48 位地址。在 IPv6 下，RFC 3513 用于单播，新的网络接口地址或扩展唯一标识符（EUI-64）地址是一个新标准。

EUI-64 是 IPv6 的较低单播 64 位地址空间，由供应商的识别号码组成，该号码长度保持不变（24 位）。但是，供应商的序列号现在扩展到 40 位（Microsoft, 2008）。这样做是为了获得更大的序列号，从而获得更大的物理地址空间。此标准为无线或有线设备提供了一个独立于当前 Internet 接入点的唯一 IP 地址（GAO, 2005）。在漫游过程中接口不会改变，并且保持一个恒定的 IP 地址（即，在此示例中，接口标识（ID）是自动配置的，但为了明确，接口 ID 也可以自动生成、由 DHCP 提供或手动输入）。虽然自动配置大大支持移动性，但它自然引发了隐私问题。Warfield (2003, 8) 表示，

a system could be tracked or identified between networks or across renumbering… There exists the possibility of mapping network infrastructure or connectivity through EUI mapping. Mappings of EUI between networks can reveal underlying subnet structures and subnet mappings (SLAs) between networks.

现在，一名普通的 IT 专业人士应该会想：2003 年的参考资料对于 IT 来说是史密森古老的考古“发现”。不，如果信息仍然有效！例如，NIST (2010, 6–7) 表示，“在 EUI-64 地址中使用 MAC 地址理论上使攻击者更容易扫描网络。” NIST (2010) 建议在网络边界阻止扫描，并使用非可预测函数（如加密功能）生成地址。最后，Microsoft 有时会因安全专业人员和公众的批评而受到指责，但必须称赞其制作了“随机生成的永久接口标识符，以减轻对子网中单播 IPv6 地址的地址扫描。这是 Windows Vista 和 Windows Server 2008 中 IPv6 的默认行为”（Microsoft, 2008, 19）。
