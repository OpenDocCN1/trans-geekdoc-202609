

企业中拥有各种各样的用户，包括访客、合作伙伴、承包商、员工和特权员工。来自多个供应商的网络和安全设备使用基于 TNC 的技术进行互操作，以根据每个用户的身份、端点合规性和角色提供适当的访问权限。社区参与至关重要。例如开源客户端 `XSupplicant`（来自 OpenSEA Alliance 的 `802.1x` 客户端）等示例，它为用户身份验证和端点健康检查提供跨平台支持，这对于长期渗透一个一直由少数几家大型供应商及其专有框架主导的市场非常重要。IETF 采用 TNC 规范至关重要，并且最近已实现。它确保了行业对标准的广泛认可，提供了领先网络和安全供应商产品之间的一致性。作为 IETF RFC（标准）发布的 TNC 接口，在混合使用环境中为各种用户提供动态分化和访问控制强制执行，并得到被视为互联网标准最终权威机构之一的支持。

# 员工隔间：访问生产网络

## 业务要求

一名员工早上来上班。当她刷卡进入大楼时，物理访问控制系统会将她的位置发布到中央清算所，即元数据访问点（MAP）。员工对企业网络进行身份验证，其工作站会检查是否符合企业安全策略。策略服务器为员工配置适当的网络资源访问权限。

一天结束时，员工登出 PC 并刷卡离开回家。物理访问控制系统会将她的位置发布到 MAP，MAP 通知策略服务器她已离开大楼。策略服务器为员工的工作站配置新的访问策略，交换机将工作站重新分配到一个机器 VLAN，该 VLAN 具有受限访问权限，用于夜间维护和保养（例如备份或补丁管理）。

操作要求：

用户必须通过身份管理系统和 AAA 服务进行身份验证和授权

用户必须已刷卡进入大楼

端点必须健康

防病毒软件正在运行且配置正确

最近的扫描未显示恶意软件

个人防火墙正在运行且配置正确

补丁已更新

行为必须可接受

无端口扫描，无发送垃圾邮件

协调挑战：

安全基础设施复杂、异构且通常分布式

情况日益恶化

基础设施组件之间发生大量实时数据流

传感器、流控制器、IDP 等之间的协调，它们各自关注不同的事件模式

此数据的及时路由和可靠交付至关重要

TNC 技术：

IF-PEP 为经过 `802.1X` 认证和 MAC 认证的端点提供动态准入控制和基于端口的网络强制执行。

IF-TNCCS-SOH 提供 TNC 与 Microsoft NAP 之间的集成，启用 NAP Agent 以将端点健康信息传递给 TNC PDP，而无需第三方 supplicant。

CESP 定义机制，确保能够为缺乏 TNC 客户端且无法对网络进行身份验证和/或证明符合安全要求的端点动态配置适当的访问权限。

IF-MAP 使来自其他安全系统的信息集成成为可能，为托管和非托管端点的访问决策增加行为智能，并将物理安全与网络访问控制集成。

# 访客访问：会议室

## 业务要求

一名访客使用符合 IETF/TNC 标准的笔记本电脑访问公司。在允许访客端点访问企业网络之前，会对其进行健康检查以确保其符合企业安全策略。访客被放置在受限 VLAN 中，该 VLAN 提供对适当资源（例如 Internet）的访问，但阻止访问内部企业子网。在访客连接到网络的整个期间，会监控其端点健康状况和行为。

操作要求：

必须通过受限 VLAN 允许连接

端点必须健康

防病毒软件必须正在运行且配置正确

最近的扫描未显示恶意软件

个人防火墙正在运行且配置正确

补丁已更新

行为必须可接受

无端口扫描，无发送垃圾邮件

TNC 技术：

IF-PEP 为每个用户提供适当的访问权限，同时确保有线和无线连接之间的一致访问控制。

IF-TNCCS 和 IF-IMC/IMV 实现端点完整性检查；实现可以从完整的 supplicant 到轻量级溶解代理不等。

CESP 定义机制，使能够对没有 TNC 客户端且无法提供身份或端点健康信息的端点应用访问控制。

IF-MAP 使来自其他安全系统的网络智能集成成为可能，为访问决策增加行为考量。

# 承包商访问：失控

一名承包商到达以对受保护系统进行维护。承包商成功进行身份验证，其端点通过健康检查；策略服务器仅为该系统配置访问权限，并且他也受到监控。承包商插入一个 EVDO 设备并连接到 Internet，违反了企业政策。网络泄漏预防传感器检测到泄漏，并将策略违规事件发布到 MAP。MAP 将策略违规情况通知策略服务器，策略服务器终止承包商在网络上的访问权限。全面的日志记录使企业安全团队能够识别承包商做了什么以及为什么限制访问。TNC 接口为企业环境中的用户提供基于位置、身份、端点健康和行为的访问控制决策，同时检测和修复端点等非法活动（例如数据泄漏）。

操作要求：

用户必须通过身份管理系统（IDMS）和 AAA 服务进行身份验证和授权

端点必须健康

防病毒软件正在运行且配置正确

最近的扫描未显示恶意软件

个人防火墙正在运行且配置正确

补丁已更新

行为必须可接受

无端口扫描，无发送垃圾邮件

不违反数据泄漏预防策略

TNC 技术：

TNC 接口为企业环境中的用户提供基于位置、身份、端点健康和行为的访问控制决策。

检测和修复非法活动，例如端点的数据泄漏或对网络设备配置的未授权更改，并将物理安全与网络访问权限相关联。
