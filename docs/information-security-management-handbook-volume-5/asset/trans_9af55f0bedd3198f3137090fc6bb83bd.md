

通过数据挖掘技术，可以发现此前彼此分离的对象（及主体）之间的关联。推断社交网络对情报机构来说可能尤其有趣，例如在试图发现犯罪分子的社交网络时：如果能追踪到一名犯罪分子，就可以通过数据挖掘和模式识别技术，找出其他具有相似移动模式的人。这种隐私威胁与下一个威胁密切相关。

RFID 数据可能会在特定场景下收集，但随后又被用于其他场景。这是“功能蔓延”的一个例子：虽然最初未被察觉，但为特定目的收集的数据也可能对其他目的有用。

监控可以实时进行，也可以基于聚合数据进行，随后对这些数据进行分析以推断特定的行为模式。使用 RFID 技术进行个人监控的一个例子是：某些企业使用可识别的令牌（如忠诚度卡）来收集购物行为信息，并利用这些信息在未经客户同意的情况下，就定价等相关决策做出判断。

与 RFID 更直接相关的解决方案，是那些试图控制数据流向用户的方案（例如使用杀手标签和阻断标签），以防止信息违背用户意愿被传播，并为用户提供“选择加入”的选项。这些解决方案基于 RFID 系统的技术运作，特别是 RFID 标签与读卡器之间的通信。此类方案的其他建议包括使用法拉第笼屏蔽标签以防止被读取，以及减少或移除天线（前者旨在减小读取范围，后者旨在禁用标签）。“隐私设计”意味着通过适当的技术措施来遵守隐私原则。

另一个问题是，低成本的 RFID 设备没有足够的计算资源来使用选定的加密方法。杀手标签虽然因其激进的方法而颇具吸引力，但也可能杀死标签上隐藏信息的有益用途。

# 安全方面

本节概述了 RFID 系统的安全威胁，该系统由 RFID 标签和读卡器组成。安全威胁分为针对标签的威胁、标签与读卡器之间无线接口的威胁，或针对读卡器的威胁。

# 针对标签的安全威胁

## 内容伪造

数据可以通过未经授权的写入访问标签来被伪造。这种攻击仅在执行攻击时，ID（序列号）以及可能存在的任何其他安全信息（例如密钥）保持不变时，才适用于有针对性的欺骗。这样，读卡器就能继续正确识别标签的身份。这种攻击仅在 RFID 系统在 ID 和安全信息之外，还在标签上存储其他信息的情况下才可能。

## 标签 ID 伪造

攻击者获取标签的 ID 和任何安全信息，并利用这些信息欺骗读卡器，使其接受该特定标签的身份。这种攻击方法可以使用能够模拟任何类型标签的设备来实施，也可以通过制作旧标签的副本（克隆）来生成新标签。这种攻击会导致多个具有相同身份的标签在流通。

## 停用

这些类型的攻击通过未经授权地应用删除或杀死命令，使标签失效。根据停用的类型，读卡器要么无法再检测标签的身份，要么甚至无法检测读取范围内标签的存在。

## 物理破坏

标签可能通过化学或机械手段，或使用强电磁场（例如微波炉中的电磁场）而被物理破坏。主动标签还可以通过移除或耗尽电池来关闭。

## 标签分离

标签与被标记物品物理分离，随后可能与另一个物品关联，就像价格标签被“调换”一样。由于 RFID 系统完全依赖于通过应答器对被标记物品进行明确识别，这种攻击构成了根本的安全问题，尽管乍看之下可能显得微不足道。

# 针对无线接口的安全威胁

## 窃听

读卡器与应答器之间通过无线接口的通信，通过拦截和解码无线电信号进行监控。这是 RFID 系统最具体的威胁之一。窃听到的信息可以例如用于收集关于个人的隐私敏感信息。它还可以用于执行重放攻击，即攻击者记录所有通信消息，随后可以向读卡器模拟该标签，或向标签模拟该读卡器。

## 阻断

所谓的阻断标签向读卡器模拟任何数量标签的存在，从而阻断读卡器。阻断标签必须针对所使用的反冲突协议进行配置。

## 干扰

干扰是指故意干扰读卡器与标签之间的无线连接，从而攻击通信的完整性或可用性。这可以通过远距离的强大发射器实现，也可以通过屏蔽等更被动的手段实现。由于无线接口不够稳健，即使是简单的被动措施也可能非常有效。

## 中继攻击

非接触式卡片的中继攻击类似于众所周知的中间人攻击。在读卡器和标签之间放置一个设备，使得读卡器与标签之间的所有通信都通过该设备，而标签和读卡器都认为它们正在直接相互通信。巧妙地修改这种通信，例如在支付系统中，可能导致向错误的电子钱包（带有 RFID 标签的智能卡）收费。为了使这种攻击更实用，可以将设备分为两个组件：一个与读卡器通信，一个与受害者的卡片通信，从而增加合法卡片与受害者卡片之间的距离。这两个组件之间的通信可以通过任何类型的快速无线技术实现。

# 针对读卡器的安全威胁

## 伪造读卡器 ID

在安全的 RFID 系统中，读卡器必须向标签证明其授权。如果攻击者想使用自己的读卡器读取数据，该读卡器必须伪造授权读卡器的身份。根据现有的安全措施，这种攻击可能“非常容易”到“几乎不可能”实施。读卡器可能需要访问后端，例如，以检索存储在那里的密钥。
