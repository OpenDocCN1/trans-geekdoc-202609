

![](OEBPS/images/box.jpg) `Privileged User Password Management (PUPM)`: 通过仔细分离职责并安全地保护活动记录，组织可以防止特权用户犯错或实施恶意行为。`PUPM` 提供对特权账户的安全访问，并通过按临时、一次性使用基础或按需颁发密码，帮助提供特权访问的问责制，同时通过安全审计提供用户对其行为的问责制。`PUPM` 还设计为允许应用程序以编程方式访问系统密码，从而从脚本中删除硬编码密码。`PUPM` 支持物理或虚拟环境中的众多服务器、应用程序（包括数据库）和设备。

![](OEBPS/images/box.jpg) `Unix Authentication Broker (UNAB)`: 对 UNIX/Linux 用户进行身份验证通常意味着维护与 Windows 用户分开的记录。这会使密码同步变得复杂，并可能通过增加时间或错误而阻碍特权用户的取消配置。`UNAB` 允许在 Microsoft Active Directory (`AD`) 中管理 UNIX 用户，这允许将身份验证和账户信息整合到企业 `AD` 中，而不是在各种系统上拥有 UNIX 凭据（[图 4.5](#9781466508507_epub_c04_r1.htm#fig_4.5)）。

# BeyondTrust Privilege Manager and PowerKeeper

`BeyondTrust Privilege Manager` 是仅适用于 Windows 的解决方案，使组织能够删除管理员权限并允许最终用户运行所有所需的 Windows 应用程序、进程和 ActiveX 控件。

Privilege Manager 作为组策略扩展实现。指定应用程序以及启动应用程序时应添加到进程令牌的权限和特权。通过设置 Privilege Manager 策略，没有管理权限的最终用户将能够运行所需的应用程序。

`BeyondTrust PowerKeeper` 是一种自动密码管理解决方案 (`APM`)，用于访问控制、可管理性和对特权账户（例如共享管理账户、应用程序账户和本地管理账户）的审计。PowerKeeper 为任何操作系统、账户或设备提供完整的设备支持。PowerKeeper 中的所有加密均由商业支持的、FIPS 140-2 验证的软件提供（[图 4.6](#9781466508507_epub_c04_r1.htm#fig_4.6)）。

![](OEBPS/images/box.jpg) 程序因子用于验证请求凭据的应用程序/脚本的真实性（例如，用户、主机、操作系统、程序）

PowerKeeper 提供客户端库，以使现有和新的应用程序或脚本能够从 PowerKeeper 安全地检索当前凭据。

# ScriptLogic Privilege Authority

`ScriptLogic Privilege Authority` 是一个 `free` 的仅适用于 Windows 的解决方案，使组织能够以最小权限运行用户，并且仅在需要时提升应用程序和 ActiveX 控件。它由 Privilege Authority 用户社区支持。

![](OEBPS/images/box.jpg) Privilege Authority 使用提升规则来确定哪些应用程序、功能或控件被提升到更高权限。这些规则可以包括随 Privilege Authority 包含的常见规则、常见规则的自定义版本，或完全自定义的用户定义规则。规则可以轻松地在测试和生产网络之间复制、共享和移动。

![](OEBPS/images/box.jpg) Privilege Authority 提升规则附加到组策略，以确保可靠地交付到客户端。这使管理员能够通过仅将规则附加到发往目标客户端的组策略，在需要的地方分配规则。

# Lieberman Software Enterprise Random Password Manager

Lieberman Software 产品通过四部分 `I.D.E.A.` 流程帮助组织控制特权账户访问（[图 4.7](#9781466508507_epub_c04_r1.htm#fig_4.7)）：

![](OEBPS/images/line-2.jpg)

![](OEBPS/images/box.jpg) `Identify` 并记录所有关键 IT 资产、其特权账户及其相互依赖关系。

![](OEBPS/images/box.jpg) `Delegate` 对特权凭据的访问权限，以便只有适当的人员（使用所需的最小权限）才能登录到 IT 资产。

![](OEBPS/images/box.jpg) `Enforce` 密码复杂性、多样性和更改频率的规则，并在所有依赖项之间同步更改。

![](OEBPS/images/box.jpg) `Audit` 和警报，以便记录每个特权访问请求的请求者、目的和持续时间。

Enterprise Random Password Manager 使用默认 AES 256 加密存储特权凭据。可选地，可提供 FIPS 140-2 验证的模块和 PKCS#11 硬件加密。

Enterprise Random Password Manager 保护 Windows、Linux、Unix、OS/390 和 AS/400。它在新系统上线时立即注册它们。
