
# 安全外包概述

随着企业风险和威胁几乎每天都在变化，企业建立可靠的安全计划至关重要。安全外包投资需要在管理业务风险的背景下予以考虑。众所周知，风险可以被接受、缓解、避免或转移。外包是指企业从第三方获取产品和/或服务，而不是在内部生产。无论是长期还是短期，安全外包都有利有弊；取决于企业外包了什么以及如何外包，结果可能是好也可能是坏。关于安全外包需要记住的一件事是，成本只是安全外包的短期杠杆，因为每个人都倾向于限制成本。将要讨论的一些好处包括：安全外包可以将注意力集中在关键问题上，成本更可预测，并且可能为您的安全服务提供更大的灵活性和适应性。选择安全外包商可以将先进技术与专家人工分析相结合，使企业能够以成本效益的方式加强其安全态势，并提供一种技术和专业知识水平，以确保对真实威胁做出快速响应。虽然成本决策可能使选择安全外包商变得容易，但认为安全仅仅是保护网络边界的观念已经完全过时了。企业现在认识到“纵深防御”的重要性，这涉及一种全面的方法来保护关键资产、网络和信息系统，同时针对黑客、病毒和其他在线威胁实施强大的防御。

当企业开始考虑安全外包时，企业需要了解其环境、重要资产以及保护资产的必要性。企业需要在考虑外包任何安全服务之前建立安全方向。在选择要外包的安全服务或选择安全外包公司之前，企业必须考虑以下问题：

![](OEBPS/images/box.jpg) 企业使命是什么，以及它如何融入安全计划？

![](OEBPS/images/box.jpg) 企业内部的重要资产和信息是什么？

![](OEBPS/images/box.jpg) 重要资产位于何处，谁有权访问它们？

![](OEBPS/images/box.jpg) 重要资产与其他企业员工、系统和应用程序的接口是什么？

![](OEBPS/images/box.jpg) 组织的优先事项是什么？

![](OEBPS/images/box.jpg) 保护资源如何融入企业？

![](OEBPS/images/box.jpg) 企业内部当前正在执行哪些安全服务？

![](OEBPS/images/box.jpg) 企业希望安全计划中包含哪些安全服务？

![](OEBPS/images/box.jpg) 外包安全的业务理由是什么？

在审查上述问题时，这类似于基于评估现有风险来建立安全计划。当企业考虑安全外包时，可以降低成本并获得专职从事安全工作的熟练人员，这一系列安全服务可以使企业安全计划更加高效和有效。可以考虑的一些安全服务包括：

![](OEBPS/images/box.jpg) 网络边界保护，包括防火墙、入侵检测系统（IDSs）和虚拟专用网络（VPNs）的托管服务

![](OEBPS/images/box.jpg) 安全监控

![](OEBPS/images/box.jpg) 事件管理，包括应急响应和取证分析

![](OEBPS/images/box.jpg) 漏洞评估和渗透测试

![](OEBPS/images/box.jpg) 安全控制开发、维护和测试

![](OEBPS/images/box.jpg) 防病毒和内容过滤服务

![](OEBPS/images/box.jpg) 信息安全风险评估，以及潜在的风险管理

![](OEBPS/images/box.jpg) 数据归档和恢复

![](OEBPS/images/box.jpg) 现场咨询，用于趋势分析、改进建议或培训

# 安全外包的优点/好处

安全外包可以为企业带来许多好处。其中一些好处包括：

![](OEBPS/images/box.jpg) 将非核心安全活动外包，将使企业有更多时间专注于核心安全业务流程。

![](OEBPS/images/box.jpg) 通过安全外包，企业可以在非核心安全业务流程中体验到更高的效率和生产力。

![](OEBPS/images/box.jpg) 安全外包可以帮助您简化安全运营。

![](OEBPS/images/box.jpg) 安全外包可以使企业更灵活地应对变化。

![](OEBPS/images/box.jpg) 如果组织得当，企业可以体验到更多安全控制措施。

![](OEBPS/images/box.jpg) 企业可能能够节省对最新技术、软件和基础设施的投资，因为安全外包合作伙伴将投资于这些。

![](OEBPS/images/box.jpg) 安全外包可以让企业放心，安全服务正在高效、熟练地执行，并且周转时间快。

![](OEBPS/images/box.jpg) 安全外包商可以满足企业新的和具有挑战性的需求。

![](OEBPS/images/box.jpg) 安全外包可能会给企业带来竞争优势，因为安全服务生产力的提高。

# 安全外包的缺点

虽然安全外包的优点可能大于缺点，但缺点绝对需要被考虑，并与企业的风险承受能力进行衡量。

![](OEBPS/images/box.jpg) 在内部进行特定安全服务可能比外包它们更具成本效益。

![](OEBPS/images/box.jpg) 安全外包商将能够查看企业潜在的机密信息，因此存在安全和机密性威胁。

![](OEBPS/images/box.jpg) 在开始使用安全外包商时，与在企业内部管理安全服务相比，企业可能会发现管理和与安全外包商沟通比较困难。

![](OEBPS/images/box.jpg) 安全外包商可能会为企业创造潜在的冗余。

![](OEBPS/images/box.jpg) 如果安全外包商破产、停业或被收购，企业将不得不立即将安全服务转回内部或寻找另一家安全外包商。

![](OEBPS/images/box.jpg) 安全外包商不仅可能为企业提供安全服务。安全外包商还为其他公司提供服务，可能不会完全专注于您的企业，并且信息可能与其他公司的信息混合在一起。

![](OEBPS/images/box.jpg) 通过安全外包，企业可能会失去对外包安全服务的控制。

![](OEBPS/images/box.jpg) 安全外包虽然具有成本效益，但可能存在隐藏成本，例如公司之间签订合同而产生的法律费用。

![](OEBPS/images/box.jpg) 安全外包可能存在多种缺点，例如合同续签、对合同的误解、缺乏沟通、质量差和服务延迟等。
