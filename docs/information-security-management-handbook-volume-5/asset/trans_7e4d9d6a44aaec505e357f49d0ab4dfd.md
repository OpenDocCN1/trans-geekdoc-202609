# 磁带备份注意事项

# Sandy Bacik

是时候为内联网站点应用另一个安全补丁了。这是跟踪所有项目工作和交付成果的内部站点。没问题：补丁中不包含重大内容。信息技术 (IT) 部门一直在执行每日增量备份和每周完整备份。IT 每周将磁带轮换到异地，并保留季度末备份两年。由于预算限制，内联网没有测试环境。IT 安装了内联网站点补丁；服务器重启正常，并显示主内部内联网页面。一名内部用户点击一个关键项目的链接——哎呀，出现 404 Web 错误，页面未找到。IT 从备份磁带恢复文件——哎呀，磁带上没有文件，但所有备份作业均未显示中止或错误。IT 调取了上个月的异地磁带：任何磁带上都没有文件。IT 需要回溯两个月的异地磁带才能找到一条有效的备份磁带。IT 向用户社区发送电子邮件，称过去两个月的项目文件已丢失。丢失了多少个项目？有多少份关键报告消失了？您的企业是否遇到过这种情况？异地设施是否曾经“丢失”过一套备份磁带？如果应用程序软件丢失会怎样？数据备份还有用吗？如果没有损失，恭喜企业备份和恢复流程已记录并定期测试。如果有，那么企业可能希望增强现有流程，以防止未来发生此类事件。

线性磁带开放 (LTO)、8mm、数字线性磁带 (DLT)、超级 DLT (SDLT) 和可扩展线性记录 (SLR) 到底是什么？这些只是企业用于备份系统的几种磁带类型。是的，一些企业已转向可移动磁盘和磁盘到磁盘备份。然而，更多企业仍在使用磁带备份系统。每个企业都明白，系统和数据备份是业务的日常要求。许多实施了磁带备份系统的企业并未为其物理和逻辑磁带备份流程实施最佳实践。备份流程将重要的企业信息复制到磁带或其他设备上。备份使企业能够从单个文件到完整系统恢复任何内容。备份和恢复已帮助企业从由中断、灾害、电涌、用户错误、设备故障或病毒引起的数据丢失中恢复。数据恢复流程、工具和服务存在，但可能有限且昂贵。通过系统恢复恢复所有丢失信息可能不太可能，用户可能需要重新创建部分数据。企业在恢复期间需要继续停机，这也可能代价高昂。设计良好的备份系统通过提供最有效且最具成本效益的方法作为防止潜在重大数据丢失的保险，来保护关键信息。信息备份和恢复标准应包含四个主要组件：

应备份企业关键信息。

信息备份应存储在与其原始创建和使用位置物理上不同的位置。

应定期执行备份测试流程。

应定期测试企业检索和恢复备份数据的能力，并产生成功结果。

在评估磁带备份系统时，企业是否考虑了设备的物理位置？是否已定义以下要求：

数据中心机架的尺寸

磁带设备的尺寸

磁带设备的电源（主电源和冗余电源）

磁带设备的气流考虑因素

企业知道该设备将放置在服务器室或数据中心。等等——位置或设备及物理空间的环境要素何时曾为扩展进行过审查？实施或升级磁带备份系统时，需要评估环境和物理状态。除了上述列出的要求外，企业必须定义的其他要求和标准如下：

`Power on password`：对于冷启动和热启动，这将在输入密码之前阻止使用服务器/设备。这是为了防止未经授权访问设备设置实用程序和操作系统。虽然这是良好做法，但企业也必须记住，每当服务器/设备启动时，必须有工作人员在控制台旁。

`Administrator password`：这将在可能的自动恢复后防止对服务器/设备的本地或远程访问，并防止未经授权更改服务器/设备的系统配置信息。

`CD-ROM/diskette drive/boot control`：这将禁用从不同设备读取或启动的功能，这可能会绕过操作系统并使系统文件容易受到更改或删除。

`Serial/parallel interface control`：这将禁用任何人走到设备前并使用串行或并行端口进行未经授权访问的功能。

以上是一些基本安全要求。企业如何确定其备份需求？制定成功的备份策略始于规划备份需求分析或审查当前正在备份的内容。备份管理员需要查看企业备份需求，并将其与磁带备份硬件和软件相匹配。备份管理员需要从以下类型的问题开始：

必须备份和可恢复的信息（系统、程序和数据）是什么？

这涉及多少信息——千兆字节、太字节？

磁带和磁带头将使用什么格式？美国国家标准学会 (ANSI)。正在备份的所有信息是否都符合 ANSI 备份标准？

由于特殊的用户定义备份导致的备份冗余，需要多少额外容量？

执行每组信息备份需要多少时间？
