# RFID 应用类型

RFID 应用有多种类型，其中最常见的一些包括资产管理、资产跟踪、自动支付和供应链管理。区分一种 RFID 应用与另一种 RFID 应用的关键特征是识别标记物品的目的。[表 3.1](#9781466508507_epub_c03_r1.htm#table_3.1) 列出了组织可能希望识别某个物品的原因，以及与这些原因最相符的通用应用类型。

应用类型并非互斥；实现可以结合多种应用类型的元素。例如，访问控制系统和复杂的资产管理系统都包含跟踪功能。供应链管理是一种跨越组织边界的跟踪应用，通常还包括流程控制和支付交易。

负责设计和实现 RFID 系统的人员应了解其实现适用哪些应用类型，以便选择适当的安全控制措施。例如，保护自动支付系统中金融交易所需的安全控制措施与跟踪应用所需的不同。人员还应了解，对手可能会将 RFID 技术用于非预期目的。例如，仓库可能使用 RFID 技术来确定其当前库存中有哪些物品，但对手可能会使用同一系统来跟踪物品离开仓库后的去向。在这种情况下，资产管理系统后来被用于启用未经授权的跟踪应用，或许由对手用来定位高价值目标。

**表 3.1 RFID 应用类型**

| *识别目的* || *应用类型* |

| --- | --- |

| 确定物品的存在 || 资产管理 |

| 确定物品的位置 || 跟踪 |

| 确定物品的来源 || 真实性验证 |

| 确保关联物品不被分离 || 匹配 |

| 将信息与物品相关联以进行决策 || 流程控制 |

| 验证人员（持有标记物品） || 访问控制 |

| 进行金融交易 || 自动支付 |

# 风险

RFID 技术使组织能够显著改变其业务流程，以：

![](OEBPS/images/box.jpg) 提高效率，从而降低成本

![](OEBPS/images/box.jpg) 提高效能，改善任务表现，使组织更具韧性，并更好地分配问责

![](OEBPS/images/box.jpg) 响应客户要求，使用 RFID 技术支持供应链和其他应用

如前所述，RFID 技术本身很复杂，结合了多种不同的计算和通信技术以实现预期目标。不幸的是，变化和复杂性都会产生风险。为了使 RFID 实现取得成功，组织需要有效地管理这种风险，这需要了解其来源及其潜在特征。

# 隐私方面

就 RFID 而言，隐私和安全是同一枚硬币的两面，需要一种将两者共同解决的方法，并且可能可以包含对隐私产生积极影响的安全保障措施。隐私和安全的双重性需要关注，因为它涉及将隐私法规嵌入正在开发的 RFID 系统各个方面的标准中（标签、阅读器、中间件和后端信息系统）。

RFID 是一种识别手段。这种识别可以是产品、服务或人员。在大多数情况下，RFID 标签与产品相关。然而，当通过令牌、索引或另一个指针将人与特定产品相关联时，识别信息就变成了个人信息（或能够识别个人的信息）。由于 RFID 标签的“使能”特性，对隐私的威胁是一个主要关切，对公众、公司和政府而言均是如此。

在 [图 3.7](#9781466508507_epub_c03_r1.htm#fig_3.7) 中，识别出了两种直接的隐私威胁：一种与标签-阅读器系统有关，另一种与标签-阅读器系统之外收集和传播的信息有关。

第一种威胁是与 RFID 最直接相关的一种。它关注标签-阅读器系统本身的隐私影响。第二种威胁涉及通过 RFID 系统收集的数据的使用。标签-阅读器系统传播的数据可能会被收集到数据库中，例如用于监控供应链管理系统中的托盘。这种威胁并非由 RFID 系统唯一决定，但由于 RFID，威胁可能会加剧并具有非常具体的维度。

# 标签-阅读器系统内的隐私威胁

标签可能包含个人信息。护照、身份证和特定形式的公共交通卡包含可识别的信息。它们可能包含卡片上的直接可识别信息，例如姓名和出生日期。它们也可能包含作为数据库中存储个人信息的键的数据。在第一种情况下，隐私威胁是显而易见的。如果卡片持有间接可识别信息（可能指向数据库中可识别个人信息的指针），则隐私威胁是间接存在的。只有当入侵者能够将指针与真实人物关联时，隐私才会被侵犯。

未经授权读取标签被认为是最突出的隐私威胁。未经授权的读取是可能的，尤其是在使用阅读范围约为 20–30 英尺的 UHF 标签时。

使用标签跟踪人员通常被认为是对隐私的第二大威胁。通过对象跟踪人员预设了将识别数据与个人移动轨迹相关联。识别数据可以基于电子支付、忠诚卡、公共交通中的电子票务卡等获取。当一个人携带与该人相关联的对象（例如手表）时，附在手表上的标签的数据可以作为携带手表的人的可识别信息使用。可以通过监控已知标签数据的对象的移动来跟踪此人的移动。例如，该信息可用于检索个人偏好。

# RFID 系统后端的隐私威胁

上述威胁与 RFID 阅读器到标签的通信以及这些数据的直接使用直接相关。但是，大多数隐私威胁涉及标签-阅读器系统之外的信息收集和后续使用。具有唯一 ID 的标签很容易与个人身份相关联，而具有自身处理能力的智能卡可能包含敏感的个人信息。
