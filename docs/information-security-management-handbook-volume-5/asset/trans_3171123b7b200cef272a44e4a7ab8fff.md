对象识别涉及从多个传感器收集信息，然后分析这些数据以确定某物是否在其应在的位置、是否已被移动、是否丢失或是否正在被篡改。RFID 标签提供一种警报方法，如果某物从受监控区域被移除。条形码广泛用于管理库存。光学字符识别 (OCR) 可用于验证跟踪物品的标记和文本。GPS 定位器有时用于在资产运输过程中提供实时跟踪。

# 执行器

执行器是一种可以打开或关闭设备、移动对象或调用其他动作以实现所需结果的设备。网络连接的执行器可以远程锁定或解锁门、闸门或其他物理屏障。它们可以打开或关闭火灾控制喷淋系统，激活通风组件以排出空间内的现有空气，或关闭 HVAC 系统以防止空气传播传染病的扩散。执行器可以激活或停用照明，升高或降低温度，激活视频监控摄像头，发出警报，或向安全人员提供通知。执行器响应传感器以调用这些操作，这些操作基于安全团队通过明确定义的操作策略预先确定的响应场景。

# 传感器融合、关联和基准线

监控传感器输出的传统方法侧重于分析每个单独传感器的信息，然后手动关联这些数据。结合输入可以更完整地描绘事件。例如，在建筑物安全场景中，物理屏障传感器和执行器与建筑物各处化学和温度传感器报告的活动相关联和关联。此外，这些传感器的数据与视频监控信息和资产标记机制融合。单个传感器读数可能不那么令人警觉，例如仅仅检测到安全房间外有人的存在，或一段存储介质已被移动可能不足为奇。但是，如果未经授权的人进入了建筑物，通过视频分析看到一个人非常靠近存放敏感存储介质的安全房间，然后该房间的温度因人体存在而略微升高，并且一项资产在房间外移动，这可以被关联以提醒存在可疑或恶意活动的高概率。

传感器融合、关联和基准线组件的价值包括通过分析数据并将其与其他传感器的信息相关联来检测异常情况，例如资产移动、物理空间中多余的人员以及在安全房间附近徘徊的人员。我们还可以通过使用多样化的感知技术来减少误报和漏报的发生，从而获得更具可操作性的情报。监控系统健康状况以了解传感器何时失效可以是攻击的有效指标，或者仅仅是传感器故障。利用 IP 网络的覆盖范围和能力可以提供关于哪里出现故障以及在哪里的即时和准确信息。安全运营还可以根据来自多样化传感器、设备和系统的输入，建立向相关人员自动通知的机制。

# 旧系统集成

安全运营可能已经在数百个，甚至数千个传感器和执行器上进行了重大投资。其中许多可能连接到专有或封闭网络，或者可能只是独立运行。团队可以通过将这些旧资产连接到 IP 网络，并为现有和更新的感知平台提供集成视图和报告机制，来提高这些现有旧资产的价值。

# 物理访问控制（概念）

物理访问控制是指通过集中式管理平台管理锁和卡/徽章读取器，以电子方式监控和控制门和闸门等屏障的做法。联网物理访问控制是一种提供电子访问控制 (EAC) 并利用 IP 网络提供的优势的解决方案。在传统的 EAC 架构中，中央控制器或访问面板用于通过串行接口连接到每个单独的门。此外，这些门锁机制都需要在单独的电路中配备自己的电源来操作锁定硬件。传统 EAC 架构的另一个麻烦属性是添加要监控和控制的额外门的困难。同样，每个额外的门都需要添加，一直布线回控制器，控制器需要扩展或完全更换，电源考虑因素将重新发挥作用，以便为门锁定硬件运行专用电路。

在联网物理访问控制解决方案中，硬件和软件组件都在 IP 网络上实现，以利用网络基础固有的覆盖范围和可扩展性。例如，利用 DHCP、DNS、NTP 等网络服务来简化部署和向控制器/网关添加门。以太网供电 (PoE) 可用于降低部署成本和功耗。这也带来了更大的便利，因为不再需要为每个屏障配备专用电路。在 IP 上使用分布式架构大大提高了可扩展性，并且不会将访问管理解决方案限制在单一的集中点上。

此外，使用基于 IP 的物理访问控制系统可以方便地与其他物理安全系统集成，以利用多个系统集成并关联输出信息时收集的丰富信息，从而描绘物理安全环境的整体运营图景。例如，RFID 资产标签激活建筑物各处的传感器来检测机密笔记本电脑的移动，显示出通往出口的路径。通过集成安全解决方案，这可能会触发与物理访问控制系统相对应的执行器，以锁定所有门、窗户和电梯控制系统，防止任何事物或人员物理离开设施。
