

CCSS 是一组用于衡量软件安全配置问题特征及其影响的标准化措施，位于 (`http://scap.nist.gov/emerging-specs/listing.html#ccss`)。

NIST IR 7502 (`http://csrc.nist.gov/publications/PubsDrafts.html#NIST-IR-7502`) 提供了几个示例，说明如何针对多样化的配置问题确定 CCSS 措施和评分。一旦 CCSS 最终确定，CCSS 数据可以帮助组织做出关于如何处理配置问题的明智决策，并可提供用于主机安全定量评估的数据。

# 常见误用评分系统 (CMSS)

一组用于衡量软件功能误用漏洞特征的标准化措施。当设计软件功能时所做的信任假设可能被以违反安全的方式滥用时，即存在软件功能误用漏洞。NIST IR 7517 (`http://csrc.nist.gov/publications/PubsDrafts.html#NIST-IR-7517`) 定义了 CMSS 规范，并提供了如何针对软件功能误用漏洞确定 CMSS 措施和评分的示例。一旦 CMSS 最终确定，CMSS 数据可以与 CVSS 和 CCSS 数据一起使用，以帮助组织做出关于如何处理其主机漏洞的明智决策。CMSS 数据还可用于主机安全的定量评估。

# 圆圈得到 OVAL 吗？

“开放漏洞和评估语言 (OVAL) 是一项国际信息安全社区标准，旨在促进开放且公开可用的安全内容，并标准化整个安全工具和服务范围内此类信息的传输。OVAL 包含一种用于编码系统详细信息的语言，以及社区中持有的各种内容存储库。该语言标准化了评估过程的三个主要步骤：表示系统配置信息以供测试；分析系统中指定机器状态（漏洞、配置、补丁状态等）的存在；以及报告此评估的结果。存储库是利用该语言的公开可用和开放内容的集合。”[^(\*)](#9781466508507_epub_c06_r1.htm#ch6-ftn23)

在 OVAL 出现之前，没有通用或结构化的方法来确定和共享系统中软件漏洞、配置问题、程序和/或补丁的存在。这并不是说信息不存在，但它大多是基于文本的，并存储在各个组织的工具和知识库中。挑战在于，人类在解释与配置和漏洞相关的非结构化信息时，仍然需要投入大量精力。个人和组织之间的技能水平差异很大，即使执行得完美无缺，系统管理员在尝试阅读和解释这些非结构化信息以确定特定漏洞或配置问题是否存在于网络和/或端点时，该过程也容易出错。更糟糕的是，漏洞和错误配置的检测本身从未被标准化，因此导致将利用代码基本上作为评估工具。用一个黑盒来解决另一个黑盒的问题，可能会让你和你的组织陷入低效率和潜在责任的黑洞。你怎么知道你正在使用的工具确实有效？你能对它抱有多大的信心？

# 别担心！OVAL 来了！

如上所述，解决许多这些问题的方法可以在 OVAL 中找到，基于其促进漏洞和配置标准化和结构化评估的能力。更重要的是，像这样的开放标准受到大量关注，实际上基于产生可重复的信息保证指标的能力带来了更高的信心。此外，它不是排他性的，因此你已经用于收集信息的代码可以被“OVAL 化”，从而总体上带来更好的结果，工作量更少，准确性更高，因此责任更低。这反过来又从可扩展性角度降低了企业的攻击面，这是任何人类交互都无法做到的。此外，看似晦涩的安全问题可以更好地表达为具体、可管理、可操作且（最重要的是）易于消化的单元，由直接参与安全修复工作的运维团队处理。

虽然上述内容本身就足够强大，但社区的参与及其对可重用解决方案的支持放大了 OVAL 的影响。OVAL 定义的开放和平等性质，基于通用 XML 定义架构，最好由 OVAL 委员会的多样化构成以及价值链供需双方的深度参与来体现。大学、私营和公共公司、安全社区成员、政府等在开放协作环境中审查和评论 OVAL 架构，讨论不仅被允许而且被鼓励，这往往反映了信息安全社区各个领域中极其广泛的专业人士的见解和综合专业知识。虽然 OVAL 不是漏洞扫描器，但它确实能够大大增强技术细节的共享，以识别端点甚至整个网络系统的漏洞状态。所有这些都有利于最终用户，他们可能没有技能或协作网络来自行处理这些类型的任务。重用，以及这使他们能够利用的技能和知识库，反过来可能释放他们一方的资源，以探索如何使其组织变得更好，并在许多情况下回馈社区。我们可以说，OVAL 帮助我们创建一个可衡量且透明的给予与获取的循环，无论每个人是否参与，都能增强整个社区。同时，参与度的增长有很大潜力带来能力的指数级增长。

“OVAL 通过允许安全产品通过标准 XML 语言交换信息来实现互操作性。它允许不同垂直市场的产品利用完成不同任务的其他产品。例如，漏洞评估产品可以利用漏洞研究服务来快速自动检查最新漏洞。合规性检查引擎可以利用政府安全指导来自动监控合规性，而无需翻译传统的基于散文的指导。”[^(\*)](#9781466508507_epub_c06_r1.htm#ch6-ftn24)
