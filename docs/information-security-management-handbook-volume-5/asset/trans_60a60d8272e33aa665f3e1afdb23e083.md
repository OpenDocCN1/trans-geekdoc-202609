TCP 是一种容错且面向连接的协议。具体来说，主机发送的每个数据段在远程端（即，目标地址）都会收到确认，无论该数据段是否成功接收或需要重传。要启动通信，将执行 TCP 握手，如[图 7.2](#9781466508507_epub_c07_r1.htm#fig_7.2)所示。主机向远程计算机发送同步（SYN）数据包，远程计算机通过向主机源发送确认消息（SYN/ACK）数据包来确认收据（Harris, 2002）。主机计算机回复并通过确认（ACK）已收到远程源的 SYN/ACK 消息来结束连接请求（Harris, 2002）。TCP 作为一种容错协议，开销很大。这种开销体现为在下一个数据包发送前，两台计算机之间的通信。

# 什么是互联网协议？

以 OSI 模型为参考，IP 位于第三层，即网络层。IP 建立了为每个数据包（即，源地址和目标地址）提供信封和地址的过程，以便正确路由，使数据包到达其预定目标（Harris, 2002）。与 TCP 不同，IP 是一种无连接协议。通俗地说，数据包只是被提供源 IP 地址和目标 IP 地址，然后在网络上发送，“这意味着通信端点之间没有持续连接”（[SearchUnifiedCommunications.com](http://SearchUnifiedCommunications.com)，2010 年，第 3 段）。当前互联网中最广泛使用的 IP 版本是 IPv4。

# IPv4 常见攻击方法

“只要你拥有任何有价值的东西，你就有失去它的风险——事情就这么简单”（Tiller, 2004, 1064）。互联网的部分区域不断面临攻击。技术是多方面的，每个技术应用都有其优点、缺点和独特的局限性（Henderson & Craig-Henderson, 2004）。互联网也不例外，以下段落将简要讨论使用最广泛的互联网攻击方法，尽管它们不应被视为详尽无遗。

从最基本的架构形式来看，互联网是一系列路由器、网关、域名系统（DNS）服务器、互联网服务提供商（ISP）干线（即，光纤分布式数据接口、铜缆、无线、电缆等），为了论证起见，我们还将包括一些远程访问服务（RAS）服务器。ISP 使用数据库或 RAS 服务器来识别、认证和验证每个个人计算机，然后才允许访问 ISP 的网关路由器（互联网接入）。如果情况并非如此，美国境内的每个人都将免费上网。然而，美国目前没有这样的电信服务。

当前互联网的问题在于，其最初目的是在核战争发生时对核武器进行命令和控制。在国防部内部，每个人都是一个“大幸福家庭”。也就是说，“我们”在国防部家族内部相互信任。这就是当今主要问题之一。

可以说，原始设计者可能没有意识到互联网会以今天的方式或方法被使用，或者会如此流行。当今的问题包括：“个人正在与谁通信？”、“如何知道对方是想要通信的预期人员？”、“IP 地址是否被欺骗？”以下是一些常用的攻击网络段的方法（不详尽无遗）：

1\. 病毒

2\. 蠕虫

3\. 拒绝服务（DoS）

4\. 缓冲区溢出

5\. 恶意代码

6\. 设计不良的软件或实现

7\. 侦察

病毒是一小段代码，其主要功能是复制并影响应用程序或文件（Harris, 2002）。病毒会感染主机（即，使用“最基本架构”规则）。如前所述，互联网的基础组件是 DNS 或 RAS 服务器。不需要太多技术知识就能理解，如果 DNS 或 RAS 服务器被病毒攻破，其影响将是网络灾难！病毒需要用户或程序的干预才能传播（Harris, 2002）。病毒有不同程度和不同类别。不过，目前无需讨论这些差异。

相比之下，蠕虫不需要外部干预即可传播，是自包含的程序（Harris, 2002）。回顾一下，Nimda 蠕虫是释放到互联网上最严重的蠕虫之一，基于其在短时间内感染大量节点的速度以及对系统的影响。Nimda 代码是一种紧凑代码，使用用户数据报协议（UDP）在互联网上传播以感染节点（Symantec, 2007）。例如，大多数流式音频程序使用 UDP 协议，因为不可靠的传输是一个可接受的折中方案，考虑到 UDP 传输的速度。提醒一下，UDP 是一种无连接协议，像 IP 一样，没有 TCP 握手来减慢传输过程。最后，如果有人认为蠕虫对“最基本架构”的互联网组件（在此例中为路由器）影响不大，那么应该研究 Code Red 蠕虫传播对旧式思科路由器的影响（Cisco, 2001）。
