# 资产报告格式 (ARF)

`ARF` 语言 (`http://scap.nist.gov/emerging-specs/listing.html#arf`) 是由国防部与 NIST 及 `SCAP` 供应商社区成员共同开发的通用安全自动化结果报告语言。它提供了一种结构化语言，用于在网络评估工具之间交换和导出每台设备的详细评估数据。`ARF` 旨在由漏洞扫描器、`XCCDF` (`http://scap.nist.gov/specifications/xccdf/scanners`) 以及其他收集基于互联网协议的网络设备详细配置数据的工具使用。

有关 `ARF` 的详细信息可在 `ARF` 规范和数据字典中找到，网址为 `http://metadata.dod.mil/mdr/ns/netops/shared_data/arf_index_page/0.41`

# 开放检查表报告语言 (OCRL)

开放检查表报告语言是一种用于编写机器可读 XML 定义的语言，用于从系统收集信息并将其作为标准化报告呈现，以供人工评估策略合规性。每个生成的报告文件对应单个策略建议。`OCRL` 补充了现有的基准语言，如可扩展配置检查表描述格式 `XCCDF` 和 `OVAL`——这些语言已经提供了以机器可理解的方式构建安全指导以及描述如何收集和评估系统信息以确定合规性的功能——通过解决那些需要人工来确定是否符合给定策略建议的情况，或者 `XCCDF` 和 `OVAL` 没有必要的功能来评估收集的信息是否符合建议的情况。例如，一项陈述“用户应禁用计算机上不必要的服务”的策略建议，需要人工判断来确定哪些服务是不必要的。可以编写一个 `OCRL` 定义来提供计算机上运行的所有服务的报告，然后由人员用来确定是否存在任何不需要的服务。

`OCRL` 专门设计为与 `XCCDF` 和 `OVAL` 基准编写语言协同工作。虽然 `OCRL` 文档可以由软件程序单独用于创建一个或多个报告，但通过将 `OCRL` 与 `OVAL` 结合使用，可以从 `XCCDF` 文档中调用比单独使用 `OVAL` 更多的自动化，从而显著增强基准自动化能力。
