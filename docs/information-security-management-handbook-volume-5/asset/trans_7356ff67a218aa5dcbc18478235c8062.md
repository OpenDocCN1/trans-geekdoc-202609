# 组织文化意识将培育您的信息安全计划

![](OEBPS/images/chline.jpg)

# Robert Pittman

在一生中，我们许多人都往返于工作地点，度假期间前往其他州甚至其他国家，并与家人共度美好时光，同时也会在体育赛事、戏剧、海滩或音乐会上寻找娱乐时间。许多此类旅行和活动都会让你置身于有人存在的环境中。无论你的通勤或旅行带你去哪里，人都是不可避免的。当人们聚集在一起时，就存在一种文化，需要敏锐的知识和洞察力来判断你应该如何对待这些人。在建立或培育信息安全计划时，确定合适的方法是必要的，但具有挑战性，无论你在哪个行业（例如，公共、私营和非营利部门）工作。

有许多著名的理论家，例如 Douglas McGregor（创建了 X 理论和 Y 理论模型）、Edgar Schein（创建了组织文化模型）、心理学家 Abraham Maslow（创建了需求层次五级模型），以及组织行为和文化研究领域的许多其他人。这些人由于其巨大的研究以及为全球组织带来的价值，将这一话题推到了前沿。

全球范围内的组织大多使用本质上由公众支持的政府业务。公众由其公民、选民、非营利组织和公司等企业，以及各级政府机构组成。每个人之间的关系涉及公民，即政府及相关组织代表公众协调其计划和服务。至少，这是政府的目标之一，因为它们提供了企业甚至不会考虑提供的服务。提供给公众及其公民的众多服务包括社会服务、一般政府服务、医疗保健和公共安全。

无数政府社会服务计划中的一些，是那些针对并支持低收入家庭、寄养儿童、独立青少年，以及为弱势群体提供食物和住房的一般救济计划。其他服务包括房产价值评估、房产税支付、申请出生证明、结婚许可证或死亡证明，以及简单的选民登记。我们的公民从来到这个世界开始，贯穿其一生都需要医疗保健服务。医疗和心理健康保健，包括公共卫生问题，始终是各级政府最高关切的问题，涉及所有年龄段。公共安全服务与医疗保健一样位居榜首似乎是显而易见的。国土安全、边境和港口保护、执法以及保护我们所爱之人，是政府明显发挥重要作用的领域。

上述所有政府服务都是对外提供给公民的。内部提供的服务视角与企业提供的服务不同，这涉及大量员工劳工工会（即公务员规则）的存在和忠诚度、有吸引力的持续退休方案、一致的健康和牙科福利、在同一政府层级内的职业和工作晋升（不同部门、分支和机构都有机会），以及明知是在支持某个事业或更大的善举。

无论我们用什么视角来看待政府和企业，该视角都说明明显的差异确实存在。许多面向公众的服务是无形的，政府员工对其获得的内部服务怀有深切的感激之情。

从八万英尺高空俯瞰政府，并透过镜子观察，从员工和组织的角度来看，存在差异。地方政府（即县和市）组织与企业存在差异。显然，企业股票和工作保障是其中的一些差异。然而，在地方政府建立信息安全计划与在企业建立相比，存在显著差异。

在地方政府建立信息安全计划涉及一系列必须在首十八个月内由首席信息安全官（CISO）、首席安全官（CSO）或信息安全经理（ISM）解决的重点领域。在一些最近的信息安全论坛和行业文章中，首席风险官（CRO）一词也可能发挥重要作用。必须确保这些重点领域得到解决，以便由组织建立和采纳：
