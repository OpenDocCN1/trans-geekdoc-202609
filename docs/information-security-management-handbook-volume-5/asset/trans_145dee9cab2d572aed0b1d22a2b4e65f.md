

一个相关但独立的考虑因素是策略本身的定义方式。每个系统实际上都将拥有自己的策略。也就是说，需要能够定义将管理整个系统组的策略，类似于组策略对象在 Active Directory 中的运作方式。虽然更好的解决方案将能够以这种方式定义策略，但这也可能导致混淆（同样，在 Active Directory 中使用组策略对象时也可能发生这种情况）。管理系统不仅应允许在多个上下文中定义策略，还应能够准确查看哪些策略影响哪些系统，并能够查看继承的影响。如果一个策略允许应用程序运行，而另一个策略禁止它，哪个策略生效？

最后一组考虑因素涉及最终用户体验。在大多数情况下，应用程序白名单对最终用户是透明的，有两个例外：当应用程序被阻止时，以及当用户被允许覆盖或修改该禁止时。在查看此功能时，重要的是要考虑用户群，以及与白名单端点代理交互的用户百分比（例如，作为受信任用户）以及他们的技术熟练程度。向他们显示的通知中的信息量将影响故障排除，并且应足以合理判断被阻止的内容是恶意的，还是仅仅是需要允许的可执行文件。简而言之，考虑你将拥有的不同类型的用户（从白名单应用程序的上下文出发），并确保了解每种用户类型的最终用户体验将如何展开。

# 总结

总而言之，关于应用程序白名单需要记住的重要事项如下：

![](OEBPS/images/box.jpg) 白名单采用“允许良好，拒绝其他一切”的理念。

![](OEBPS/images/box.jpg) 从根本上讲，有两种方法：

– 基于系统级别特定细粒度行为的白名单（基于调用）。

– 查看想要加载到内存中并运行的特定可执行文件的白名单（基于文件）。

![](OEBPS/images/box.jpg) 基于文件的白名单已变得突出，主要是因为其实施和管理更加容易。

![](OEBPS/images/box.jpg) 与传统的防病毒软件（使用黑名单方法）不同，传统防病毒软件会造成显著的处理器和 I/O 性能损耗（尤其是在全系统扫描期间），而白名单相对轻量。

![](OEBPS/images/box.jpg) 使用白名单的风险较低，因为它对新型恶意软件的覆盖更好，并且可以使用适当的变更控制方法进行维护。相比之下，传统的防病毒签名容易出现漏报，并且发布频率如此之高以至于变更控制不可行；鉴于供应商相当定期地发布具有有害影响的错误签名，这一问题更加令人担忧。

![](OEBPS/images/box.jpg) 任何白名单部署都必须经过精心规划和执行；如果实施不当，白名单有可能造成重大中断。

![](OEBPS/images/box.jpg) 白名单供应商领域仍在发展，但产品已经显示出高度的功能性和可用性。

![](OEBPS/images/box.jpg) 目前，尚无可行的选项供希望使用应用程序白名单的家庭用户。

![](OEBPS/images/box.jpg) 白名单在最终用户通常不允许安装应用程序且端点之间高度标准化的环境中效果最佳。

![](OEBPS/images/box.jpg) 在评估白名单解决方案时，需求收集和开发是必须的。

# 白名单

![](OEBPS/images/chline.jpg)

# Sandy Bacik

访问控制包括允许或拒绝使用特定资源。在网络环境中，特别是在网络边界，企业一直在使用黑名单。黑名单包括禁止访问资源列表。随着未经授权和无效的访问尝试增加，黑名单不断增长。这种方法允许一切，除非明确拒绝，即默认允许。企业现在正在采取相反的做法，只允许授权访问，即白名单，“已知良好”。白名单颠覆了黑名单，将一切视为不良，除了少数几个组。白名单是列出在环境中被授予一组特权（访问、服务、有效性等）的实体。白名单仅用于定义允许执行的内容，而不在白名单上的任何内容都不能执行。

由于合规性、审计和监管要求，企业资源和资产功能应记录资产和资源。资源可以是组、服务、应用程序、计算机、服务器、路由器、网站等。在小型企业环境中，通用服务器用于各种事情（上网、阅读电子邮件、运行企业应用程序、评估新软件等），并且很难保持白名单限制以用于访问的最新状态。另一方面，当服务器功能很少时（例如仅用于阅读电子邮件的服务器），使用白名单可以大大提高安全性。不幸的是，大多数企业系统介于这两个极端之间。企业可以利用许多类型的白名单来帮助实施白名单而非黑名单：

![](OEBPS/images/box.jpg) *电子邮件*：电子邮件白名单是用户认为可以接受接收电子邮件且不应发送到垃圾邮件文件夹的联系人列表，类似于垃圾邮件过滤器。

– 互联网服务提供商（ISP）：ISP 收到合法公司的请求，要求将其添加到 ISP 公司白名单中。

– 非商业白名单：非商业白名单由各种非营利组织、ISP 和其他有兴趣阻止垃圾邮件的实体运营。

– 商业白名单：商业白名单是一种系统，互联网服务提供商允许某人在向其订阅者发送电子邮件时绕过垃圾邮件过滤器，以换取预付费用，可以是年度费用或每条消息费用。

![](OEBPS/images/box.jpg) *局域网（LAN）白名单*：许多网络管理员设置媒体访问控制（MAC）地址白名单、MAC 地址过滤器或子网来控制谁在其网络上。当加密不是实际解决方案或与加密同时使用时，可以使用此方法。但是，有时无效，因为 MAC 地址可以被伪造。许多防火墙可以配置为仅允许来自/到某些（范围的）互联网协议（IP）地址的数据流量。
