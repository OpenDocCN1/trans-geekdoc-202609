

4. **确定解决方案适用的环境**：检查与潜在供应商发布的受支持平台的兼容性。任何不受支持的平台（`assuming they can be integrated`）都需要额外的实现工作。自定义集成工作并非没有风险：失败（全部或部分）、时间/成本超支，以及集成是否能在次要/主要产品修订或更新中正常工作？供应商的解决方案是否与您的内部服务台或工单解决方案集成？集成是单向的还是双向的？

5. **报告要求**：解决方案是否开箱即用提供您需要的报告？如果不是，是否可以自定义？如果是，需要多少工作量？

6. **实施**：您将依赖供应商或合作伙伴/经销商资源，还是将使用内部员工进行实施？在两种情况下，教育都至关重要；评估您的选择。在第一种情况下，要求提供参考，并确保实施者拥有处理您环境所需的资源和专业知识。

7. 向供应商和/或实施者（如果适用）索要客户参考。索要客户联系方式，并务必联系他们（需获得许可）。联系他们时，讨论您的顾虑。

8. 一旦您完成了步骤 1 至 7 的功课，并将解决方案缩减到一两个，就是评估时间了。供应商是否愿意进行有限范围的现场概念验证（PoC）？您对概念验证的期望应当现实；您是在尝试了解产品，并评估对您重要的开箱即用功能，在您环境中的受支持平台上。建立一份在 PoC 期间希望看到的开箱即用（OOTB）功能清单，提前与供应商分享，并让他们将其纳入交付物文件中。在 PoC 结束时，双方都应完成并对交付物清单发表评论。

在做出决定时，还有几个其他因素需要考虑，以尽量降低为您的环境选择错误解决方案的风险。

# 社交网络时代的隐私

![](OEBPS/images/chline.jpg)

# Salahuddin Kamran

# 简介

*社交网络*一词是指促进互联网上集体行动和社会互动的应用程序和服务，例如博客、维基、社交网络和讨论论坛。近年来，在线社交网络变得非常流行，许多网站应运而生，人们可以在其中与线下朋友在互联网的虚拟世界中相遇。Facebook、Orkut、MySpace 等服务允许人们托管他们的在线社交网络。人们在这些社交网络中创建个人资料，并与朋友和大量陌生人共享这些信息。

当人们加入社交网络网站时，他们首先创建个人资料，然后与现有朋友以及通过网站结识的人建立联系。个人资料是一份身份信息列表。它可以包括用户的真实姓名或化名。它还可以包括照片、生日、家乡、宗教、种族和个人兴趣。成员通过发送“好友”请求与其他人建立联系，该请求必须由另一方接受才能建立链接。“加好友”会让他们访问一个人的个人资料，将他们添加到他们的社交网络中，反之亦然。成员使用这些网站出于多种目的。根本动机是沟通和维持关系。流行的活动包括向他人更新活动和行踪、分享照片和存档事件、获取朋友活动的更新、展示庞大的社交网络、展示理想化的人格、私下发送消息和发布公开推荐。

社交计算系统的成功，其内容几乎完全由用户贡献创建，取决于参与者共享的意愿。个人提供信息的意愿，反过来，由其隐私顾虑所支配。鉴于 Facebook 等社交网络因其隐私政策而面临越来越多的批评，这一问题似乎尤其重要。

Facebook 是美国最大的社交网络服务提供商，也是美国访问量第二大的网站，仅次于 Google。根据 Facebook 的数据，拥有超过 4 亿活跃用户，其中约 1.2 亿在美国。每天约有 2 亿用户登录 Facebook。每个月有超过 25 亿张照片上传到 Facebook。它是互联网上最大的照片共享网站，遥遥领先。

在本文中，我们简要描述了社交网络的一些主要功能和优势，这些功能和优势使社交网络成为目前最流行的互联网技术之一。我们还强调了由于社交网络网站“几乎无所不包”的精神而可能产生的关键隐私和安全威胁。最后，我们提出了一些建议，以增强社交网络网站的安全问题，确保用户从社交网络网站中受益，而不是遭受其弊端。

# 在线社交网络的结构与演变
