

一个完整的 IS 管理计划，旨在保护数据和信息，涵盖四个主要领域：`hardware and network infrastructure`，包括客户端、服务器、网络及其操作系统和工具；`software environment`，包括应用系统开发与实施，以及所有提升工作效率的工具和界面；`incident response and management`，涵盖系统或服务中断，直至危机响应与恢复；以及 `human activities`，包括通过组织结构与数据和信息进行交互的内部和外部人员。这些领域中的每一个都有战术性组件（在一个运营日历年内）和战略性组件（跨越两个或多个运营日历年）。这些主要领域中的每一个都可以在 OODA 循环的四个阶段内加以解决，如 [Figure 16.2](#9781466508507_epub_c16_r1.htm#fig_16.2) 所示。在现有组织中建立有纪律的 IS 结构显然比在初创企业中更困难，但 IS 审查和重组可以在任何环境中开始。为了最好地描述每个主要领域内的管理细节，最合适的做法是从“Orient”阶段开始。在新旧组织中，这个阶段都提供了审查现状并开始制定修改计划的机会。在“Orient”阶段中涉及的大部分内容将从战略角度进行审查；战术方法将在“Decide”和“Act”阶段中加以解决。“Observe”阶段代表了对近期活动和潜在挑战进行反思的永无止境的过程。下面列出了 IS 单位和 IS 专业人员在每个阶段内的活动和/或职责。

# Orient

这个阶段对 IS 专业人员来说是最重要的阶段，无论是在新组织中开始工作，还是仅仅寻求改进现有组织的 IS 环境和流程。在启动可能影响现有服务和流程的变更之前，进行详细评估是明智之举。下面详细说明了 IS 职责，但正如 [Figure 16.2](#9781466508507_epub_c16_r1.htm#fig_16.2) 所示，评估并非孤立进行。在最终决定之前，必须接受组织内其他单位以及外部资源的投入。

# Human Resource

任何级别的谨慎 IS 专业人员都会花时间了解组织的行业环境、监管背景、产品和服务，以及与外部组织的活跃业务关系。这是组织 IS 计划的基础，该计划必须围绕组织的行业环境、企业姿态和核心价值观来制定。这体现了 IS 与 IT 之间的区别：IS 拥有超越（但包括）技术的更广泛的企业视角，而 IT 虽然不与组织环境隔绝，但主要关注技术资源。理解外部组织关系至关重要，尤其是涉及信息交换的关系。大多数信息隐私和安全法规都要求就信息交换制定精心设计的协议。医疗保健组织很快将面临更严格的审查，因为最近颁布的 HITECH Act \[30\] 不仅增加了私人数据丢失的处罚，还加强了对这些组织的审查。供应重要资源和材料的供应商也应予以关注和跟踪，所有外部组织都应作为组织业务连续性规划工作的一部分进行记录。

拥有强大的人际交往能力对 IS 专业人员来说是一项优势，因为最大的挑战将是传达适当信息保护机制的严肃重要性，以及每个员工在整体保护方案中所扮演的关键角色。不幸的是，大多数从上到下的普通员工对 IS 概念的理解不完整，甚至是错误的。许多安全实践和流程对最终用户来说不方便，并可能给人一种阻碍工作流程的错误印象。培养强大的倾听技能将会带来好处，并且能够在各种场合（从正式演示到走廊交谈）传达 IS 挑战将是非常重要的（Murphy, 2009）。

如前所述，Col. Boyd 的模型已在商业环境中使用，但我认为它并不完全适用。它曾被用来尝试建立商业竞争以争夺产品或服务市场份额的模型，但现实中，商业竞争对手并非像敌对国家的军事力量那样寻求彼此的失败和毁灭。在 IS 环境中，组织确实有敌人，他们意图造成伤害，甚至摧毁目标个人和组织。基于互联网的攻击者最初是拥有技术技能的个人，其早期意图是好奇心和炫耀。最近，这些个人在追求被盗信息（无论是专有组织信息还是个人身份信息）的货币价值方面变得更加熟练和有组织。这些敌人的努力近年来急剧增加，被盗信息的价值也随之增加。

IS 专业人员并未忽视这些敌人，Boyd 模型提供了一种结构，强调了解敌人并制定计划来分散、威慑甚至击败这些敌人。这让人想起基于博弈论的风险管理的历史方面，该理论将不确定性的方面归因于“其他玩家”\[16\]的活动。对于 IS 来说，其他玩家就是攻击者，攻击者的活动正在增加。在这个危险的互联网时代，IS 和 IT 专业人员不能继续被动，甚至不采取最基本的保护预防措施。技术基础设施和软件环境必须以敌对攻击者为出发点进行设计！我们不仅要考虑允许谁访问，还要考虑故意阻止谁。IS 专业人员可以通过了解攻击方法和攻击者特征，并从攻击者的角度考虑硬件和软件环境的设计来发挥作用。我们需要评估环境，看看有人可能会如何选择突破我们的结构、进入我们的系统，并捕获或破坏我们的数据。
