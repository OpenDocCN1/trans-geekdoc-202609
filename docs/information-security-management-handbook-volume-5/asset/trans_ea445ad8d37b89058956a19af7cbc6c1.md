# 第 28 章

# 生产力与安全性

# Sandy Bacik

全球各地的企业对网络威胁的风险以及公开分享的事件数量不断上升日益关切，这证实了他们的担忧。在当今的经济环境下，预算正在削减，技术部门被要求削减资源。因此，风险上升，预算下降。任何利用安全执行力度下降来加快利用步伐的人都会利用这些风险现实。不满的员工也会带着宝贵的信息资产离职，而企业则在努力提高生产力的过程中削减防御。而这发生在企业无法承受停机、生产力下降、数据被盗、销售损失和企业声誉受损的时期。这就是我们所说的“安全悖论”或“生产力与安全性之争”。随着单点外部攻击转向多源外部攻击，以及“可信员工”模式被削弱，这场辩论变得越来越难以实施。信息技术（IT）的主要目的是让企业员工尽可能高效、高效率、高效地完成工作。笔记本电脑、便携式存储设备甚至智能设备都是这种效率/生产力环境的一部分，允许在火车、飞机上、客户现场或员工家中完成工作。现在，IT 安全的首要目标与这一首要目标相冲突。IT 安全的首要目标是保护公司数据，无论是因停电、意外擦除、磁盘故障，还是更邪恶的行为，例如破坏或故意窃取。另一个例子，传统的围绕企业信息资产的企业网络边界已不再现实。企业移动员工要求数据可随身携带，并能从任何地方即时访问。这否定了旨在保护信息安全的物理屏障。

每个安全专业人员都知道，我们在信息安全方面所做的任何事情都无法消除企业内固有的所有风险。最多，我们可以降低风险并将其降至可接受的水平。那么，什么是可接受的风险水平？每个资产所有者都需要自行决定，这将因行业、组织、感知到的和真实的威胁、使用的软件以及许多其他因素而异。关键在于，安全是一个持续的平衡过程。通常，平衡过程是在安全需求与组织文化之间进行权衡。一些企业的目标是让员工在工作场所享有很大的自由，而这种“自由”通常也延伸到网络——尽管企业有明确的政策规定网络仅用于业务用途，并且对任何网络活动都不应期望隐私。即时通信（IM）和点对点服务（例如，KaZaA 音乐下载）等应用程序已知存在安全隐患，但它们的使用仍被允许，尽管通常没有良好的业务理由。企业为什么要使用会使其业务数据面临可能安全漏洞的软件？也许，您应该考虑购买合适应用程序的安全版本，而不是使用不安全（尽管免费）的软件，这些软件只能近似提供正确的功能——并且会带来重大风险。等等。这又指向了“生产力”与安全性之间的同一平衡问题。企业使用已知是安全噩梦的软件——但仍然使用它们，表面上是为了“用户生产力”。

生产力与安全性之间的两难困境也使合规性挑战成为努力保持竞争力的公司的一项艰巨障碍。企业对更具流动性的员工的需求使网络面临潜在数据泄露风险的增加。在生产力环境中处理安全的基本目的是确保对敏感信息和系统关键流程的持续有效保护。自动化系统安全的充分性通过定期审计、评估、风险分析和批准审查来检查。评估和审查应与后续测试和评估、自检以及其他所需评估相结合进行。然而，在不影响企业生产力的前提下，可以实施多少安全措施？让我们来看看 CobIT 模型。在推进技术实施或试图在技术上保持领先时使用 CobIT 模型，企业应该

1. 规划和组织：企业必须对现有基础架构进行评估，以确定其优势和劣势。满足这些要求的理想解决方案应该是提高性能和生产力。不要忘记包括企业安全要求。

2. 获取和实施：下一步是评估、选择和实施最符合要求的解决方案。

3. 交付和支持：希望，一些要求包括安全，且安全是所选和实施解决方案的一部分。理想情况下，采用的解决方案应通过管理用户权限并限制向用户和未经授权的设备传输信息，来保护敏感信息的机密性、完整性和可用性。

4. 监控和评估：CobIT 控制的最终组成部分侧重于持续衡量企业既定 IT 基础架构性能的能力。

为了在保持企业生产力的同时，实现尽可能高的保护水平和尽可能低的风险和成本，企业必须考虑一种包含以下要素的方法：

- 系统和网络之间集成且分层的防御
- 实时威胁情报和声誉分析
- 提供单一管理控制台的集中式安全管理平台
- 实时网络监控，以确保响应时间和员工生产力
- 所有网络监控和管理均由专门的安全研究专家团队和称职的管理员支持

在平衡生产力和安全性时，企业该怎么办？企业需要寻找削减成本的环境机会，使其 IT 安全解决方案更加精简和有效。企业的结果是更少的安全漏洞、更少的停机时间和收入损失，以及在艰难经济环境下更低的风险。
