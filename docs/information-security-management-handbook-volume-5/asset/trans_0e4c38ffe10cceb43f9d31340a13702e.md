

越来越多的内部员工利用社交网络工具和功能进行个人互动、短距离连接和文件传输（例如，Bluetooth），甚至个人购物机会——所谓的“Web 2.0”技术。类型的增加速度超过了名称和方法参考列表所能跟上的速度，并正在取代过时的技术！用户正在传输和显示个人身份信息，许多人并不意识到身份盗窃或意外泄露私人信息的机会 \[35\]。即使是电子邮件系统也充斥着恶意软件和数据丢失的漏洞。IS 专业人员必须主动劝阻使用电子邮件分发组织敏感信息，无论是直接发送还是作为附件，尤其是因为现在有越来越丰富的协作软件选择，提供安全的方式（加密、重定向）来共享文件和记录。此外，电子邮件越来越成为法律调查的目标，作为活动记录，一些州规定在特定组织和条件下保留所有电子邮件。必须让员工用户了解管理层在组织内部审查电子邮件和其他消息系统的法律权利。高管需要确定组织环境中此类活动的限度。

IS 和基于 Web 的威胁种类正在急剧增加，以至于需要几乎全职、积极地审查和研究才能跟上。无论攻击工具和场景如何变化，IS 员工都可以通过了解常见的互联网威胁和漏洞跟踪服务 \[36\] 以及减少或消除漏洞的适当防御机制和流程，为规划员工办公技术做出贡献。

# 事件响应与管理

识别和跟踪表明不可接受活动（无论是意外还是故意）的事件，这些活动可能导致服务中断或全面危机中断，是组织范围内的共同责任。IS 专业人员必须能够向员工传达事件的迹象和症状，并设计报告和响应功能以接收各种报告并评估即时和长期后果。一般来说，这正在成为数据保护中最困难的部分，因为上述硬件和软件挑战导致组织网络内部的新利用路径呈指数级增加。此外，欺诈性访问和使用组织信息的增加可能需要广泛的证据来识别和挫败欺诈源头。

许多组织将报告问题和系统中断的渠道分散在桌面支持、网络管理、中央主机/服务器支持和业务连续性通知中。设计良好的事件管理环境可以接受关于各种问题的电话，包括恶意软件识别、关于系统问题的触发日志消息以及个人观察。事件管理结构最好由 IS、IT 和 PS/S 单位共同设计和管理，并得到高管领导的适当投入。一个集中运作的小组可以评估每个电话并确定最佳响应的适当目标组。事件可能足够简单以便快速解决，或者足够严重以触发正式的灾难或危机响应，但如果集中收集和汇总，所有事件都有助于跟踪可能导致攻击者入侵和数据丢失的问题模式。

# 决策

在“定向”阶段，IS 专业人员分析和综合从四个主要关注领域积累的信息。在 OODA 循环的这个阶段，综合后的信息被制作成明确行动的计划，需要将一些任务委派给 IS 员工和其他协作者。积累和解释信息是必要的，但精心制定的计划为管理 IS 并记录威胁和漏洞以确定风险的纪律性方法奠定了框架。所有计划和流程最终都必须为控制对组织数据和信息的访问以及提供保护这一双重目标做出贡献。

IS 专业人员必须在高管单位的指导和监督下设计计划和政策结构。可以想象，并非所有从前一阶段综合得出的 IS 计划都会被允许或负担得起。有些计划可能被制定为长期的战略目标，或者可能被制定为基于战略预算考虑分阶段实施。尽管如此，IS 专业人员仍被鼓励制定“全局”方案，并准备好根据重要性和可负担性确定的顺序实施流程和计划。
