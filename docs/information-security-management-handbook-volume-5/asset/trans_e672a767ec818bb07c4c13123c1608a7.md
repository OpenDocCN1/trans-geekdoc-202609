

技术基础设施——服务器、工作站、网络和通信节点——是 IT 部门的主要领域。基础设施也是针对数据和信息威胁的主要目标，尤其是在拥有多年活跃历史的大型组织中。最近，IS 被迫评估内部设备（如打印机、扫描仪和传真机）的存储能力（Radcliffe, 2007）。这些设备正成为攻击者的热门目标，攻击者可以利用任何和所有访问权限进行更广泛的利用。在当前的技术状态下，管理基础设施主要是一项战术工作，尤其是针对小型服务器和台式机。变更通常一年发生多次，基于单元添加、单元组件添加、升级和旧设备淘汰，这些变更经常为威胁利用提供机会，尤其是在变更管理流程定义不明确的情况下。对于老旧、复杂的基础设施，主要的控制建议是启动简化，减少需要独特服务和支持的设备和系统的复杂性。

许多组织正在通过配置虚拟专用网络（VPN）供远程办公人员和出差人员使用来扩展其网络边界。基本上所有这些流量都是无线的，需要增加网络访问审查，因为远程用户及其个人工作站正成为攻击者的目标。对于经验丰富的攻击者来说，在组织网络边界内未经授权访问数据比在边界外要简单得多。对组织基础设施和驻留数据来说，迄今为止最大的挑战是便携式计算设备的激增，包括笔记本电脑、笔记本、上网本、多功能手持设备（尤其是带摄像头的设备）和便携式存储设备。这些设备的可访问性将在未来几个月和几年内成为无数漏洞的来源。个人采购已超过大多数组织的管理能力，如果没有投资于工作站管理软件，禁止使用便携式存储设备的政策基本上无法强制执行。

独立于 IT 的 IS 专业人员可以协助规划和评估增强数据保护、防止数据泄露并减少恶意软件利用机会的架构设计变更。包括多层架构、服务进程解耦、组件冗余以及远程服务器和数据存储在内的创造性架构设计可以增强基础设施的 `changeability`，并减少危机中断后信息恢复的复杂性。获得网络访问控制的一种可能策略是将组织网络的实际边界缩小到中央服务器和存储单元，将所有内部员工用户视为外部行为者。另一个考虑是加密所有集中存储的数据，并限制访问路径（自动密钥管理和实现）到授权设备，例如组织工作站以及正确授权和配置的便携式设备。这意味着所有用户和所有设备都将接受与外部用户相同的访问控制审查，消除边界内的优势。

# 软件环境

软件和工作站办公技术及工具的管理通常是 IT 部门的一部分，但偶尔业务部门可能会为目标系统和应用程序配备开发人员。IT 通常为内部员工提供工作站安装和问题解决资源。IS 专业人员可以提供开发实践的独立审查，以确保系统和应用程序减少或消除允许数据暴露或未经授权访问的漏洞。IS 连同风险/隐私/审计部门可以记录政府法规制定的数据保留和归档要求。某些类型的法律和个人可识别信息有最大保留期限规定，并且这些最大值可能成为符合电子发现法规的最低要求 \[31\]。通过精心制定的符合保留要求的政策，组织还可以定义满足法律发现挑战期望的数据销毁政策。

大型系统的开发——通常是跨越数月或数年的项目——需要 IS 专业人员的严格关注。主要系统开发项目的所有阶段，即规划、设计、开发、测试、验收和运营，如果没有适当的审查，都会带来漏洞的机会。在许多情况下，在正确的时间提出关于数据保护和访问控制的正确问题，可以防止以后出现昂贵的问题。仔细的测试可以识别简单错误、逻辑错误以及数据暴露的漏洞。规划是引入安全问题的最重要阶段，因为一旦系统设计和开发完成，更改可能会增加金钱和时间成本。即使应用程序是商业现成（COTS）产品，IS 在投资最终确定之前也可以就设计和保护能力提出适当的问题。最值得注意的是，所有软件环境活动中 `weakest link` 是人力资源。人类在软件开发的所有阶段都会犯错，组织用户未能遵循指令和指南（无意或故意），并可能无意中让系统会话保持活动状态，允许任何想要利用的人未经授权访问。
