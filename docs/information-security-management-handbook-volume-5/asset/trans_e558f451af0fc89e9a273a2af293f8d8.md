

社交网络为我们提供了一个独特的机会，以在社会背景下研究隐私担忧的背景。在电子商务背景下，隐私担忧与降低分享信息的意愿相关联。然而，在社交计算社区中，隐私的影响尚不明确。有人可能认为社区用户并不十分关注隐私，因为许多用户在 Facebook 或 Flickr 等公共场所展示最私密的信息，并且似乎对隐私风险毫不在意。然而，最近的公共辩论表明，用户确实在意他们在在线社区中分享的信息是如何被使用的。

在线社交网络为互动和沟通提供了令人兴奋的新机会，但也带来了新的隐私担忧。如果在线社交网络没有被谨慎使用，那么它们不仅无法为用户带来福祉，反而会成为垃圾邮件发送者、不道德的营销人员以及其他可能对用户造成严重伤害的人的危险有力工具。

# 隐私揭示

社交网络站点共享在线互动和沟通的基本目的，但具体目标和使用模式在不同服务之间有所变化。最常见的场景是基于参与者的个人资料以及其朋友网络的展示。这种方法可以向不同方向延伸。在约会网站，如 [match.com](http://match.com) 和 Nerve 上，个人资料是关键组成部分，且没有朋友网络。在 LiveJournal 和 Blogger 等博客网站上，个人资料变得次要；网络可能可见也可能不可见，而博客条目起着核心作用。

因此，在线社交网络可以向分类信息的一个方向和博客的另一个方向转变。人们在这些在线社交网络上分享信息的方式非常不同，并取决于所考虑的网站。在 Facebook 等网站上，可能会鼓励使用真实姓名向在线社区成员展示账户个人资料；此类网络试图将参与者的个人资料与其现实生活身份相关联。其他网站如 MySpace 和 Friendster 容忍使用真实姓名；此类网站通过仅在在线个人资料上显示真实姓名的一部分（即，仅显示名而隐藏姓）来在现实生活和在线个人资料之间创建一层薄薄的匿名性。其他网站，如 [match.com](http://match.com)，不鼓励发布真实姓名和其他个人联系信息；此类网站试图通过使其与在线个人资料的链接更加困难来保护个人的现实生活身份。

大多数社交网络站点都鼓励发布个人且可识别身份的照片。揭示或发现的信息类型通常围绕不同的爱好和兴趣，但也可以朝许多其他不同的方向发展，例如当前和以前的学校及雇主等信息；饮酒和吸毒习惯、性和政治偏好及性取向等私人信息。

在线社交网络上信息的可见性在不断变化。在某些网站上，任何成员都可以查看任何其他成员的个人资料。在其他社交网络站点上，对个人信息的访问可能仅限于属于个人资料所有者直接或扩展网络的人。然而，信息的可见性控制在不同网站之间有所不同。人们通常很高兴向尽可能多的人披露尽可能多的信息。Gross、Acquisti 和 Heinz 对 Facebook 个人资料中使用的不同字段以及填写这些字段的用户百分比进行了分析。

93.8% 的用户披露其性别。

83.3% 的用户披露其家乡。

87.1% 的用户披露其高中。

45.1% 的用户披露其家庭住址。

59.8% 的用户填写了“关于我”字段。

67.8% 的用户披露其即时通讯地址。

83.8% 的用户披露其生日。

92.3% 的用户披露其电子邮件地址。

78.5% 的用户披露其关系状态。

# 隐私影响

隐私影响取决于提供的信息量、谁可以访问这些信息以及这些信息的准确性。即使社交网络站点保护了用户的身份，仍然可能通过面部识别等方式将在线个人资料与该人的现实世界身份关联起来。通常，人们在许多社交网络站点上都有账户，并且通常在不同站点上使用相同的照片，在某些站点上的个人资料中提供的信息比其他站点更多。因此，通过面部识别，如果可以构建不同个人资料之间的链接，那么可能可以收集比仅从一个社交网络中获得的更多信息。识别也可以被存档。即使不使用个人资料图片信息，人口统计信息也可以通过其他重叠信息（如特殊爱好、兴趣等）来使用或获取。

一些社交网络已经开始公开其应用程序编程接口（`API`），并使开发人员能够实现应用程序——一个著名的例子是 Facebook。Facebook 上有大量可用的应用程序：用户可以玩电影问答游戏，在其中回答问题并与朋友排名，并可以了解他们的电影品味与朋友的匹配程度。然后有一些应用程序，用户可以在其中标记他们访问过、居住过或未来想访问的不同城市或国家。这些应用程序还可以帮助揭示特定用户的各种信息。通常，当用户安装某个应用程序或与某个应用程序进行某些活动时，用户的朋友网络也会收到活动通知，朋友也会被邀请参与活动，并且他们可以对这些活动发表评论和分享观点。

这些信息如何被使用？一旦第三方访问社交网络，风险范围从身份盗窃到甚至身体跟踪、敲诈勒索、尴尬，或其他人获取本不打算与他们分享的信息。人们可以获取该人使用的不同消息服务的电子邮件地址和身份，这些信息后来可用于跟踪该人；女性用户尤其容易成为此类跟踪的目标。展示的个人资料照片也可能被怀有不良动机的人滥用。在某些情况下，这些照片只是转发给朋友，但在其他极端情况下，这些照片可能被发布在不当的论坛或网站上。已有一些报告案例显示，有人利用电话号码骚扰用户。

在社交网站上共享的信息始终可供网站运营人员以及该在线社交网络的网络托管提供商使用。当网站数据被备份时，此类信息可能会无限期存储，即使在用户从在线社交网络删除其账户很久之后也是如此。此类信息也可能由社交网络提供商或网络托管提供商应执法机构的请求与其共享。

# 在线社交网络的威胁

在数字媒体上随意发布个人信息可能会创建用户轻率行为和判断失误的永久记录，这些记录可能被第三方评论利用，从而对用户构成多种威胁。用户可能面临的潜在威胁大致可分为四类：

1. 隐私相关威胁
2. 网络和信息安全威胁
3. 身份相关威胁
4. 社会威胁
