

# 什么是社交网络？

社交网络是一种由人组成的社会结构，这些人通过一种或多种特定类型的互联连接在一起，例如价值观、思想、友谊或专业联系；类似于“六度分隔”游戏。我们的社交关系网络已扩展并转移到互联网上并进行组织。在线社交网络在 2003 年和 2004 年期间迅速发展。所有在线社交网络站点都允许人们提供自身信息以及他们想要分享的任何其他信息。社交网络站点内的通信类型包括论坛、聊天室、电子邮件和即时通讯工具。社交网络站点允许根据特定标准进行浏览。一些社交网络站点为特定兴趣设有社区和子群组。那么，在线社交网络有哪些安全影响呢？

![](OEBPS/images/box.jpg) 有些人在透露信息时可能不会像面对面交流时那样谨慎。

![](OEBPS/images/box.jpg) 在线时存在一种匿名感。

![](OEBPS/images/box.jpg) 缺乏物理互动会提供一种虚假的安全感。

![](OEBPS/images/box.jpg) 许多互联网站点现在正在为其连接的人定制信息，而没有意识到还有其他人可能会看到它。

![](OEBPS/images/box.jpg) 一个人可能会提供见解以给朋友和同事留下深刻印象。

在大多数情况下，使用这些站点的人并不构成任何威胁，但恶意人士可能会因为免费可用的（个人）信息而被这些站点吸引。关于你的可用信息越多，别人就越可能出于恶意目的使用它。恶意人士可能会试图建立关系，并最终利用一个人提供的关于其曾经或目前就职的企业的信息来实施社会工程攻击。社交网络站点（取决于站点）会存储个人的个人信息。你能想到的最大的全球企业是什么？现在想想该全球企业存储的账户和图片数量。无论你选择哪个，你都可以打赌 Facebook 或 MySpace 包含更多的账户和图片。那么，用于保护这些社交网络账户安全的是什么呢？——是的，简单的用户 ID 和密码。对于许多安全专业人员来说，他们的社交网络账户可能有强密码，但那些没有安全背景的数百万其他账户呢？如今，许多企业用户更喜欢在社交网络站点上管理其个人信息，以让熟人了解他们的活动和成就。

好吧，那么我们分享个人信息。社交网络站点对企业存在哪些隐私和安全问题及威胁？

![](OEBPS/images/box.jpg) 更大的企业风险之一是社会工程攻击：社会工程是黑客经常用来绕过安全机制并访问敏感企业数据的攻击手段——不是通过使用技术（尽管技术可能涉及其中），而是通过使用企业员工。数据被微妙地收集，并逐渐一点一点地收集起来。创建账户或进入在线社区需要一些信息，但通常隐私设置被忽略，因此，用于社会工程攻击的信息获取门槛较低。

![](OEBPS/images/box.jpg) 垃圾邮件：社交网络站点支持各种类型的消息传递。这些消息服务允许其他人向成员发送未经请求的电子邮件，尽管站点政策已制定。

![](OEBPS/images/box.jpg) 钓鱼攻击：通过社交网络消息传递，成员可能会使自己面临针对特定企业的电子邮件欺骗欺诈尝试，旨在未经授权访问机密数据。

![](OEBPS/images/box.jpg) 信息泄露：某些信息仅对社交网络站点内的“朋友”或受限群组成员可用，这是保护隐私的第一道防线。由于很容易与他人建立联系，有人可能会以虚假借口建立联系。一些用户无意透露关于其企业的信息，但这却是其个人资料详情的一部分。

![](OEBPS/images/box.jpg) 名誉诽谤：假个人资料以知名人士或品牌的名义创建，或者为了诽谤在特定链接个人资料网络中知名的人。并非所有个人资料都一定是发布者的准确描述。

![](OEBPS/images/box.jpg) 跟踪和欺凌：这是使用技术对个人进行的重复且有目的的伤害行为。

![](OEBPS/images/box.jpg) 信息聚合：社交网络站点上的个人资料可以随时间推移由第三方下载和存储，并逐步累积。这些信息可能会被第三方用于原始人未预期的目的和场景。

![](OEBPS/images/box.jpg) 二次数据收集：在个人资料中知ingly披露的个人信息可以通过网络本身被站点运营商看到（数据如连接时间和长度、连接位置（IP 地址）、访问的其他用户个人资料、发送和接收的消息等等）。

![](OEBPS/images/box.jpg) 人脸识别：社交网络站点上的个人信息可以包括用户提供的数字图像，这些图像是个人资料不可或缺且流行的部分。

![](OEBPS/images/box.jpg) 来自图像元数据、标记和跨个人资料图像的可关联性：许多社交网络用户使用元数据标记图像，例如指向其个人资料或电子邮件地址的链接。

![](OEBPS/images/box.jpg) 社交网络聚合器：这是一种相对较新的应用程序，试图将您所有各种社交网络个人资料整合到一个中。迄今为止，许多社交网络聚合器并未取得多大成功。

![](OEBPS/images/box.jpg) 创建账户：许多社交网络站点要求在注册时提供出生日期，以确保成员超过一定年龄。其他请求的信息包括电话号码、地址、喜好、厌恶、最喜欢的事物、家庭。虽然这些信息很简单，但如果落入恶意人士手中会发生什么？

![](OEBPS/images/box.jpg) 完全删除账户的困难：尝试从社交网络站点删除账户很难完全移除。移除主页面和信息很容易，但次要信息（例如在社交网络站点内对他人发表的公开评论）仍然在线并链接到原始账户。
