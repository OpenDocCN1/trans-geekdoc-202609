

信息安全标准可以是软件、硬件或人为行为的公认规范。这些标准也可以是事实标准，当它们被广泛使用以至于新应用程序通常遵循其惯例时。然而，从信息安全专业人员和信息技术专业人员（包括审计员）的角度来看，书面格式是首选且推荐的。

软件标准可以针对特定供应商的防病毒软件保护解决方案。事实上，从纵深防御的角度来看，一个组织可能会标准化为两个供应商的解决方案。如果某个特定组织已实施所有思科系统公司（Cisco）网络设备，他们可以得出结论，其网络基础设施的硬件标准是思科。有许多标准用于解决人为行为甚至其行为。例如，为了应对潜在的计算机安全漏洞，标准将针对特定员工的角色、职责以及适当响应的时间表来规定应执行的操作。

程序规定了人们在实施政策时应如何行为。例如，政策可能规定，所有在外工作或出差并希望连接到企业网络的员工的机密和私有数据网络通信必须加密。这将构成基于政策需要实施的先前识别的软件和硬件（也许是用于外部通信的采用标准）。相应的程序（“如何做”）将详细解释使用特定虚拟专用网络（VPN）或其他技术启动安全连接所需的每个步骤。

如前所述，政策、标准和程序是强制性的。然而，指南不是强制性的。指南可在没有文档化的标准或程序时使用，并且在未来可以转换并采纳为标准或程序。建立指南有助于识别特定安全控制措施的有用性和试用，以便未来采纳。例如，一个组织偏好为所有移动设备使用 Windows Mobile 操作系统，但组织内有一小部分社区偏好专有的 BlackBerry 设备。因此，可能需要同时满足两个社区的需求。指南可用于解决 BlackBerry 设备的适当安全控制措施，而标准将解决所有 Windows Mobile 设备的适当安全控制措施。最终，在组织内获得更大接受后，BlackBerry 安全控制措施指南将转换为标准。这消除了本示例中使用事实标准的情况。

所有文档都应使用合适的政策资源，包括前述的 Charles Cresson Wood 的《信息安全政策轻松制定》、政府（例如，美国国家标准与技术研究院 \[NIST\]、国家安全局 \[NSA\] 安全指南，以及 RFC 2196）、行业团体（例如，国际标准化组织 \[ISO\] 17799/27002、信息及相关技术控制目标 \[COBIT\] 和赞助组织委员会 \[COSO\]）以及商业（例如，微软）组织，以便在制定政策和标准时参考。

写作风格应说明员工可以做什么和不可以做什么，使用简短的句子，写作水平类似于模范报纸使用的十年级水平，定期审查和改进（即日落条款）或调整政策，在采纳前向利益相关者和感兴趣的参与者传播显示政策变化的草稿，并向企业内的高级管理层（例如，部门主管、法律顾问、首席信息官和隐私官员）阐述重大变化。

# 信息安全组织

组织文化和行为、首席信息安全官作为信息安全高管以及组织结构是建立信息安全计划的因变量。在密西西比河以西的众多地方政府中，无论员工规模如何，已被证明有效的框架是“安全三角形”（[图 10.2](#9781466508507_epub_c10_r1.htm#fig_10.2)）。该框架在明确界定角色和职责方面取得了成效，同时解决了防御和进攻策略。换句话说，这些策略是先前所述的被动团队和主动团队，它们允许在公共部门组织内部与利益相关者在垂直和水平方向上持续协作。

信息安全战略组织图如 [图 10.1](#9781466508507_epub_c10_r1.htm#fig_10.1)（即安全三角形）所示，描绘了一个地方政府（即县政府）的示例。它说明首席信息安全官位于组织顶层，如前所述，可能向首席信息官或首席执行官汇报。信息安全指导委员会由地区信息安全官组成。这将为所有信息安全相关的协作和决策提供一个论坛。这个审议机构将权衡加强安全与各部门开展其各自业务之间的平衡。信息安全指导委员会的职责将包括：

- 制定、审查和推荐信息安全政策
- 制定、审查和批准最佳实践、标准、指南和程序
- 协调跨部门沟通与协作
- 协调全县范围的教育与意识提升
- 协调全县范围的采购与许可
- 采纳信息安全标准

地区信息安全官负责部门级的安全举措以及遵守全县信息安全政策和活动的工作。他们还在信息安全指导委员会中代表其部门。为了履行这些职责，地区信息安全官必须处于能够提供管理层可见性、管理层支持和客观独立性的级别。地区信息安全官的职责包括：

- 在信息安全指导委员会中代表其部门
- 制定部门级信息安全系统
- 制定部门级信息安全政策、程序和标准
- 就安全相关问题向部门主管提供建议
- 制定部门级安全意识计划
- 开展信息安全和隐私自我评估/审计

全县计算机应急响应团队（CCERT）将响应影响县内多个部门的信息安全事件，并采取必须协调和计划的行动。CCERT 由来自各个部门的成员组成，这些成员通常也是部门计算机应急响应团队（DCERT）的成员。CCERT 团队每两周开会一次，审查最新的威胁和漏洞，并确保成员数据保持最新。首席信息安全官也参与其活动，并领导对网络相关事件的响应。工作包括改进通知和沟通流程，并确保周末和非工作时间的响应是可行的。此外，将进行培训，为 CCERT 团队成员提供取证能力，但将特定于事件响应，以维护电子证据的保管链。
