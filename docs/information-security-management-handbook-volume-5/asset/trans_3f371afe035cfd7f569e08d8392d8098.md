

Open Checklist Interactive Language 正式是 SCAP 1.1 DRAFT 的一部分，位于 [`http://scap.nist.gov/specifications/ocil/`](http://scap.nist.gov/specifications/ocil/) Open Checklist Interactive Language 定义了一个框架，用于表达一组要向用户提出的问题以及解释这些问题响应的相应过程。尽管 OCIL 规范是为与 IT 安全检查清单一起使用而开发的，但 OCIL 的用途绝不仅限于 IT 安全。其他可能的用例包括研究调查、学术课程考试和教学演练。[^‡](#9781466508507_epub_c06_r1.htm#ch6-ftn10)

XCCDF 文档由一个或多个规则组成。XCCDF 规则通常是对技术系统（硬件、软件等）检查的高级定义。XCCDF 规则灵活，不规定应如何执行检查。在松耦合、紧密集成的设计中，规则实际上指向其他 XML 文档（例如，OVAL 定义文件），以获取执行检查所需的细粒度机制和说明。原则上，XCCDF 是其他一切运行的列表。它寻求标准化安全检查清单、基准和相关文档的创建和存储方式。它是表达各种检查的基础。

OVAL（如前所述）是一组定义，分为漏洞、补丁、清单和合规性。每个定义都定义了与其领域相关的条件，并在 SCAP 套件中由 XCCDF 引用。OVAL 是“什么”、“为什么”，有时也是“怎么做”。它允许你确定性地对资产运行一系列“基于标准的语法”问题，这些问题应返回当前状态的客观度量。非常基础，对吧？它还能做更多事情，我稍后会更深入地介绍。

OCIL 是一种方法和框架，使无法在没有某种人工交互或反馈的情况下评估的系统能够被检查。它基本上通过以标准语言格式向其预期用户提出问题来实现这一点。它包括向用户提出的问题的标准语法，以及指导这些用户得出答案的说明。还包括接受响应、传输工件以及最终评估结果等附加过程。推断 OCIL 的潜力，我们可以轻易看出，它具有深远的影响，因为我们所做的许多事情仍然需要来自 IT 部门内外用户的某种“模拟”输入。

# 枚举

SCAP 枚举的目标是提供基于标准的命名格式，以促进开放共享，而无需在系统之间不断协商定义。维护与这些标准相关的项目相关字典也至关重要。

# 公共配置枚举 (CCE)

“公共配置枚举，或 CCE，为配置指导语句和配置控件分配唯一条目（也称为 CCE），以通过促进分散领域中存在的配置问题的快速准确关联来改进工作流。在这方面，它与其他可比数据标准（例如公共漏洞和暴露 (CVE) 列表）类似，后者为公开已知的系统漏洞分配标识符。”[^(\*)](#9781466508507_epub_c06_r1.htm#ch6-ftn11)

明白了吗？基本上，如前所述，与软件、硬件、固件等配置相关的设置有数百个，有时甚至有数千个。手动设置这些设置正在迅速超出任何规模组织的能力，而这种标准化允许使用 XCCDF 检查清单或 OVAL 等自动化方式消耗配置管理更改。

# 公共平台枚举 (CPE) 2.2

“CPE 是信息技术系统、平台和软件包的结构化命名方案。基于统一资源标识符 (URI) 的通用语法，CPE 包括正式名称格式、用于描述复杂平台的语言、用于将名称与系统进行比对的方法，以及用于将文本和测试绑定到名称的描述格式。”[^†](#9781466508507_epub_c06_r1.htm#ch6-ftn12)

与 CCE 并行的是 CPE，它在所有硬件和软件平台上强制执行通用命名方案。这种实际应用称为 CPE 字典，可供全球社区使用。它目前托管在国家漏洞数据库网站上，是包含超过 17,000 个官方 CPE 产品名称的列表。字典采用 XML 格式，并通过网络向公众提供。CPE 字典目前每天（根据需要）生成一次，以向字典添加新产品或更新现有字典条目。

# 公共漏洞和暴露 (CVE)

“CVE 是公开已知软件缺陷的唯一通用名称字典。这种通用命名约定允许在组织内部和组织之间共享数据，并能有效集成服务和工具。”[^†](#9781466508507_epub_c06_r1.htm#ch6-ftn14)

CVE 的创建主要是为了解决漏洞名称和描述方面的差异。过去，架构和命名约定以及描述符的不一致性造成了大量混乱。任何遵守 CVE 命名约定的人（这是有效使用 SCAP 所必需的）都能使用所有安全从业者都同意具有相同含义的术语。虽然这听起来可能是一个相当基本的概念，但相信我，它并非如此。要了解该行业过去如何沟通，只需想象《圣经》中的巴别塔，但更糟糕。

# 国家漏洞数据库

NVD 是联邦政府基于标准的漏洞管理参考数据存储库。NVD 包含有关漏洞（软件缺陷和配置错误）的信息，包括影响度量、检测技术、修复协助和安全控制映射。NVD 搜索和发布功能提供对所有公开可用的联邦漏洞资源以及对行业资源的引用的访问。NVD 还包含一个统计引擎，使用户能够更深入地科学地了解已发布漏洞及其相关趋势的性质。NVD 通过将 SCAP 标准参考数据轻松提供给行业和政府机构来支持 SCAP。
