

# 预算/资源可用性

这仅仅是关于用于专门连续性规划活动的预算机会百分比的问题。对于较大的企业，一个相当常见的经验法则是，三到五百分比的 IT 预算通常用于信息安全，包括危机和连续性规划活动。相比之下，将小型组织 IT 预算的三到五百分比用于安全和 BCP 通常会被认为不合适。因此，虽然没有关于应将多少资源用于危机管理和连续性规划的真正指导方针，但小型组织经理可以采取一些措施来提高生存能力。经理可以通过哪些方式来增强该领域的计划？

![](OEBPS/images/box.jpg)   确保数据和软件备份：丢失的数据就是丢失的数据。一旦时间关键数据丢失，几乎总是要么重新生成的成本极其高昂，要么就永远消失了。因此，管理层必须承认，首先也是最重要的是，支持时间关键业务流程的数据和软件备份以及异地存储，这是规划 IT 相关恢复时成功的关键。Carbonite、ElephantDrive、Sharpcast 和 SOS Online Backup 等公司（仅举几例）专门为个人和小型组织提供在线备份和访问时间关键数据文件及软件的服务。这类公司为小企业提供增值服务，可以大幅减少内部或外包 IT 专业人员的工作量。这种方法有助于确保定期执行最低限度的数据和软件备份，并将其轮换和异地存储，以防发生灾难时受到保护。

![](OEBPS/images/box.jpg)   考虑一站式解决方案：有许多现成的方法可以帮助小型企业制定危机管理和连续性计划。几家供应商提供连续性规划软件，当与称职的危机管理和/或租赁连续性规划专业知识相结合时，可用于促进计划制定。此类解决方案的来源包括 SunGard Availability Services 的 LDRPS；ErLogix 的 Business Continuity Planner；Disaster Recovery World 的 BCP Generator；以及 TAMP 的基于 Web 的 BCM 软件，仅举几例。此外，还有基于 Web 的解决方案，为没有全职规划人员或需要额外专业知识和协助来解决危机管理和连续性规划问题的组织，提供软件、咨询、知识库和连续性规划在线社区互动的组合。可能提供的补充服务包括威胁评估、业务影响评估、测试协助和监督、数据备份、纸质文档备份和/或销毁、培训和意识服务等。小型组织管理层在考虑其计划的同时，也试图降低实施成本，不应忽视这一潜在的宝贵危机管理和连续性规划协助来源。

![](OEBPS/images/box.jpg)   重新评估保险覆盖理念：连续性规划有时被错误地称为“就像保险一样”。这种理念意味着管理层只需确定他们能负担多少保险，购买它，然后继续前进。虽然连续性规划当然是一种保险形式，但它并不“就像保险”，因为设计和实施得当的连续性计划将有助于恢复无法投保或保险不足的资产和运营。出于这个原因，一个好的连续性计划可能价值连城，而那些采用更简单的仅保险方式进行连续性规划的组织，在试图恢复时却陷入困境，在“重置成本与原始成本与折旧成本”的泥潭中挣扎，即使能够确定丢失数据（例如）的可投保成本也是如此。

![](OEBPS/images/box.jpg)   更紧密地协调危机管理规划：不仅在小型组织中，在大型组织中，危机管理计划与 IT 和业务流程恢复规划基础设施之间也缺乏紧密交织的协调。危机管理计划的主要目标是促进各方之间的沟通。这包括 IT 侧和业务流程侧的连续性规划团队与危机管理团队以及彼此之间的沟通。危机管理计划还应协助高管团队与外部实体沟通，例如警察和消防部门等民事当局、主要客户和股东、监管机构、员工家属、工会、新闻媒体等。一个开发良好并经过测试的危机管理计划的关键优势在于，高管能够迅速采取正确行动，从而促进时间关键流程的快速响应和恢复，进而降低事件造成的成本/影响。危机管理团队成员（包括高管成员）随后负责从上至下指导恢复工作，提供所需资源和支持，并确保组织在恢复期间尽可能最优地运行。仅仅制定危机管理计划是不够的；它们必须进行演练或排练。在连续性规划结构的年度测试中包括危机管理团队活动的测试是必要的，这能使团队在危机时期更加高效和有效。高管有责任确保，随着整体连续性规划基础设施的成熟，计划中概述的所有计划和恢复团队人员都明白，在危机时期，组织的汇报结构通过危机管理团队上下流动。

![](OEBPS/images/box.jpg)   将风险管理与可恢复性联系起来：将传统的风险管理学科（财务风险管理、保险风险管理、运营风险管理等）与企业范围的连续性规划计划联系起来。越来越多的管理团队认识到，需要将财务、运营和保险等控制职能，以及可能包括审计、法律、税务、信息安全、物理安全、连续性规划等其他职能，统一在一个总体风险管理伞下。基于这样一个概念：任何不利事件都会在某种程度上影响企业价值驱动因素（财务、客户服务、股东等），那么在企业范围内协调和管理风险职能是合理的。
