

社交网络已引起心理学、哲学、教育学以及最近的计算机科学等多个领域研究人员的广泛关注。社交网络是由代表个人及其在特定区域内相互关系的节点组成的社会结构。因此，社交网络通常基于成员之间关系的强度和信任来构建。对这些节点连接方式的仔细审查，导致识别出节点之间不同类型的联系。在此背景下，强联系是指同一网络中两个人之间直接建立的联系，而弱联系是指两个人通过另一个人连接而形成的关系。

社交网络的演变方式可以与互联网本身的演变联系起来。

# Bulletin Boards

自个人计算机行业诞生之初，人们就一直在使用计算机进行社交沟通。在互联网向大众开放很久以前，人们就已经在托管公告板系统（BBS），其中许多专注于某个兴趣群体或本地社区；此类论坛也有个人资料，但与当今的在线社交网络不同，它们更加有限，通常不包含敏感个人信息。

# Online Services

商业在线服务在 20 世纪 90 年代达到顶峰，最初作为目的地本身，后来则作为通往互联网的门户。这些服务提供了广泛的服务访问，这些服务现在在网络上都有镜像。新闻、旅行预订、购物和社交中心都是套餐的一部分；我们今天在网络上看到的大部分内容，在当时这些网站上都以某种形式存在。社交沟通是吸引人们使用在线服务的主要因素之一，因为其收入很大一部分来自按分钟计费的使用费。特别是 Prodigy 和后来的美国在线（AOL），意识到了这一点，并允许用户就几乎任何主题创建社区。

# Web 1.0

从 20 世纪 90 年代中期到 2000 年，活动呈爆炸式增长，公司纷纷涌入，试图将现有的在线服务复制到网络上。在此期间创建了许多社交服务，尤其是 GeoCities 和 [theGlobe.com](http://theGlobe.com)。网络所做的一件事是消除了困扰 AOL 及其同类的信息孤岛问题。在此期间，隐私并不是一个主要关注点；互联网刚刚起步，服务的重要性高于隐私，然而社交网络的概念尚未完全演变，人们完全控制自己的内容以及在网上发布的内容。个人资料的缺失限制了与隐私相关的风险。

# Web 2.0: Profiles and Updates

社交网络使人们使用标准模板创建个人资料变得容易。这很合理，但这实际上与网页没有什么不同。人们可以分享关于自己的信息，个人资料可以让用户轻松分享过多信息，即使他们没有分享太多，他们分享的少量信息也可能影响他们的隐私，因为存在许多社交网络，信息可能分布在所有这些网络上。Facebook 如此令人上瘾的原因之一，是因为它是追踪朋友状态的便捷方式。这也是可以移植到开放网络上的东西。任何想要的人都可以通过 Twitter、RSS 和 iCal 等标准格式发布更新、事件等。任何想要监控朋友更新的人都可以通过阅读器或其他方式做到这一点。

# The Case about Privacy

在美国，我们生活在一个关于隐私的悖论世界中。一方面，青少年在网上透露他们的私密想法和行为，另一方面，政府机构和营销人员正在收集关于我们的个人数据。例如，政府使用驾驶执照数据库来寻找拖欠子女抚养费的父亲。许多政府记录已被转换为可以通过互联网搜索的数字档案。每次我们使用购物卡时，零售商店都会收集我们消费习惯的数据。信用卡公司可以创建更大规模的我们购物行为的档案。锁在数百台服务器上的，是我们日常生活的每一个细节，从个人购买偏好到私人想法。社交网络网站创建了个人信息的中央存储库。这些档案是持久且累积的。在线日志不是用新材料替换旧信息，而是可以搜索的条目汇编的存档导向编纂。虽然美国成年人担心政府和公司如何集中收集公民和消费者的数据，但青少年却在在线日志中自由地放弃个人和私密信息。营销人员、学校官员、政府机构和网络掠食者可以通过在线青少年日记收集关于年轻人的数据。隐私悖论就在这里。成年人担心隐私受到侵犯，而青少年却自由地放弃个人信息。这是因为青少年往往没有意识到互联网的公共性质。

虽然隐私在文献中已得到充分研究，但关于社交网络中隐私的社会方面的研究却非常少。大多数关于在线隐私的研究涉及用户将其信息与电子商务网站共享的情况。在这种情况下，信息共享通常是强制性的，并且是购买过程的一部分。另一方面，在线社区依赖于其成员自愿提供的信息。关于隐私担忧如何影响这种信息共享的研究很少。这一问题因在线社区中的用户不仅与 Facebook 等公司共享信息，还与其在线社区的其他成员共享信息而变得更加复杂。此外，众所周知，隐私是一个相对的概念，个人隐私担忧的重要组成部分取决于观察他人的行为。因此，其他用户的行为和意图可能会影响用户的隐私担忧。
