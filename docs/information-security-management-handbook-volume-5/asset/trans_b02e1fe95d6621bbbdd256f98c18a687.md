# 引言

从最早版本的 *Handbook* 开始，我们就认识到，对能够应对复杂技术挑战和日益严峻的信息安全威胁的专业人才的需求日益增长。

然而，随着风险不断增加，信息技术变得愈发复杂，认证的信息安全专业人员必须越来越多地与风险管理、业务连续性和法律等姊妹学科的熟练人员合作。

如今，维护信息技术安全，并跟上竞争标准、繁重法规和竞争市场的步伐，需要一个团队——一个训练有素、受过良好教育、信息灵通的团队。

因此，我们推出当前版本的 *Handbook of Information Security Management*，其中包含涵盖风险管理（包括人员、流程和技术）的虚拟工具集中的文章和论文。

所提供的信息实用、有用且具有实操性。这些文章由致力于分享其“身经百战”故事以供他人受益的专注人士撰写。在每一章中，您都会发现每位作者慷慨分享的个人经历和问题解决过程。

这需要团队合作……

*Handbook* 的使命是面向广泛受众使用。是的，这些章节对信息安全专业人员具有实质性价值；然而，它们也涉及适用于管理人员、高管、律师、风险管理人员、技术操作员及更广泛人群的问题。所以，请大胆阅读。如果您学到一件事或找到一个可应用的想法，我们就成功了。

一如既往，我们祝您一切顺利。

**Hal Tipton**

**Micki Krause Nozaki**

# 编辑

**Harold F. Tipton** 是一名独立顾问，曾任国际信息系统安全认证联盟（ISC）²前任主席，并曾担任加利福尼亚州西比奇 Rockwell International 公司计算机安全主管约 15 年。他于 1977 年启动了 Rockwell 计算机和数据安全计划，并继续管理、开发、完善和扩展该计划，以适应技术进步产生的控制需求，直至 1994 年从 Rockwell 退休。

Tipton 自 1982 年起一直是信息系统安全协会（ISSA）的成员。他于 1984 年担任洛杉矶分会主席，1987–1989 年担任全国 ISSA 组织主席。他于 2000 年入选 ISSA 名人堂和 ISSA 荣誉榜，并于 2009 年当选为 ISSA 杰出会士。Tipton 曾是美国国家标准与技术研究院（NIST）、计算机和电信安全委员会以及国家研究委员会安全系统研究委员会（美国国家科学院）的成员。他获得美国海军学院工学学士学位和华盛顿特区乔治·华盛顿大学人事管理文学硕士学位，还获得加利福尼亚州欧文分校加州大学计算机科学证书。他是认证信息系统安全专业人员（CISSP）、信息系统安全架构专业人员（ISSAP）和信息系统安全管理专业人员（ISSMP）。

他为 Auerbach 出版社的 *Handbook of Information Security Management and Data Security Management* 以及其他出版社的 *Information Security Journal*、美国国家科学院的 *Computers at Risk*、DataPro 报告、各种 Elsevier 出版物和 *ISSA Journal* 撰写了多篇关于信息安全问题的文章。

他曾在所有主要信息安全会议上发表演讲，包括：计算机安全研究所、ISSA 年度工作会议、计算机安全研讨会、MIS 会议、AIS 太空作业安全、DOE 计算机安全会议、全国计算机安全会议、IIA 安全会议、EDPAA、UCCEL 安全与审计用户会议以及工业安全意识会议。
