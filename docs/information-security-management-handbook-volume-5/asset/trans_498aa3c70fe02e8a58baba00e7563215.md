# 系统

社交网络网站很受欢迎，而且非常时髦。新网站不断涌现。为了保持新鲜感，社交媒体供应商不断为现有网站添加功能。因此，安全性往往让位于“上市时间”和新功能。这些网站和系统存在许多弱点和故障，其中一些可能会影响到你。

有时这些问题源于大量社交网络系统使用的代码，从而在各种流行系统中创造出共同的漏洞和弱点。

# 可用性

Twitter 非常成功。它目前是互联网上增长最快的网站。（当然，这是互联网时代，等你读到这段话时，Twitter 可能已经过时，只有少数怀旧爱好者在访问。但是……）。既然如此，Twitter 必然成为其自身成功的牺牲品。随着大量新用户的加入，Twitter 的部分功能经常出现卡顿，以至于 Twitter 购买了一张特殊图片，在系统无法正常工作时向用户展示：如今著名的“失败鲸鱼”。（你可能实际上并没有见过失败鲸鱼。Twitter 现在以多种方式失败，以至于常常连失败鲸鱼图片本身都无法显示。）

突然走红的网站或页面出现故障的情况现在如此普遍，以至于它有了一个名字：Slashdot 效应。流行的 Slashdot 网站曾导致许多网站在被其提及后过载，因此现在任何被粉丝突然涌入淹没的网站都被称为被“Slashdot 了”。

与可用性相关的另一个方面是访问网站的类型。例如，Twitter 用户可以通过手机或移动电话上的短信或短消息服务在 Twitter 上发布消息并接收他们关注的人的发布。这有时会在发布者和阅读者之间造成脱节。对于通过 Web 界面使用 Twitter 的人来说，一小时内几十条消息算不了什么。对于主要通过手机使用该服务的人来说，这样的数量可能会非常烦人。

Twitter 还可以通过专门的程序以及其他网站上的信息流访问。同样，以一种格式使用 Twitter 的人可能与通过另一种格式查看 Twitter 的人看到完全不同的内容。

Twitter 提供了一项几乎荒谬简单的服务，人们为其发现了大量用途。另一方面，Facebook 拥有大量功能。但是，使用可能受到限制，因为除非你是会员并已登录，否则你无法查看 Facebook 上发布的大部分内容。（尽管某些 Facebook 设置似乎暗示信息可以被任何人看到，即使是不在系统上的人。）以这种方式，一些社交网络实际上是反社交的，基于某些技术在互联网世界中制造分裂。Facebook 是这种互联网分割的主要因素，但 Google 正通过 Google Apps 和其他相关服务紧随其后。

某些相关技术也可能起作用。你在所有社交网络网站上看到的主要活动之一是提及或标注其他网站或页面。随着这种不断的引用，出现了缩短用于访问网站的 URL 的愿望。大量缩短和重定向网站现在正为此目的被使用。

这在 Twitter 上尤其正确。Twitter 最初使用 TinyURL，当 Twitter 使用它时，它是重定向服务中的佼佼者。现在 Twitter 使用 bit.ly，它已成为领导者。（这也意味着领先的重定向网站可能反过来成为其自身成功的牺牲品，如果被淹没，可能无法执行重定向。）（请注意，重定向服务还存在额外的危险：它们可以用来隐瞒你正被转发到恶意网站这一事实。）

# 最后建议

请记住，社交网络是社交的。尽量保持文明。请记住你以前为电子邮件收到的关于网络礼仪（netiquette）的建议。

# 将成人教育原则应用于安全意识计划

![](OEBPS/images/chline.jpg)

# Chris Hare

安全意识是许多安全专业人士望而生畏的话题之一。这并非因为他们不认为它有价值，更多是因为让安全意识计划启动并衡量其成功所面临的挑战。

安全意识计划的目标是提高用户对其在安全计划中角色的知识和理解水平。组织希望员工了解他们的决策和行动如何影响组织的安全计划。同样，他们希望员工了解这些相同的行为如何导致组织安全性的削弱或受损。

关于如何开发良好的安全意识计划，已有大量研究。本章讨论了如何通过将成人教育理念应用于计划的设计和实施来增强安全意识计划的成功。

面对设计安全意识计划这一艰巨挑战，从业者需要问自己他们想要实现什么。问题不仅在于他们的安全意识计划的目标，还在于他们是否理解在真正改变发生之前需要存在的学习环境。

# 教育是否适用于安全意识？

教育被广泛用于各种形式，向学生传达信息和知识。已有许多研究探讨了教育计划在多种环境中的有效性，包括医疗意识（Healton, 1993）和文化意识（Nieto, 1999），仅举两例。社会科学的应用也得到了广泛研究，特别是人类行为与广告之间的影响（Chun, 2007）。
