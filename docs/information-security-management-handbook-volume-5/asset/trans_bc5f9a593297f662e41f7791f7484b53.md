

我们还必须考虑对广域网（WAN）流量的影响。跨广域网的视频监控 QoS 主要涉及排队和调度，特别是 `Priority` 或 `Low Latency Queuing (LLQ)` 和 `Class-Based Weighted Fair Queuing (CBWFQ)`。`LLQ` 用于立即服务最高优先级的流量，以最大限度地减少延迟并防止带宽饥饿。`CBWFQ` 将根据标记对流量进行排序并对其加权以进行服务，同时还为跨广域网的录制视频突发等事件提供流量整形。例如，对延迟、丢失和抖动敏感的流量（如实时视频和音频监控以及 `PTZ` 摄像头控制）将使用 `LLQ` 算法。对波动更具容忍度的流量（如录制视频和系统管理）可以使用 `CBWFQ` 算法。

就 IP 视频监控的网络设计而言，`QoS` 如果正确实施，可以大大提高监控系统的效率和性能，无论流量是穿越 `LAN` 还是 `WAN`。`QoS` 并非对适当链路速度配置的替代品，反之，在链路上配置高带宽也不能替代在网络上正确配置 `QoS`。当这些网络要素协调平衡时，它们能够很好地协同工作，以提供最佳性能，同时不浪费带宽或网络资源。

# Segment Summary

感知与执行、物理访问控制以及视频监控/分析是为安全专业人员及其团队提供周界入侵检测的众多可用和正在开发的解决方案中的关键技术。还可以证明，当我们利用基于 IP 的网络的覆盖范围和稳健性来帮助集成不同系统，并关联单独的数据输出集时，周界入侵检测技术将充当高度有效的力量倍增器，使安全团队能够覆盖广阔、深远和广泛的区域，同时立即响应安全威胁和获取敏感受保护信息的企图。

# Summary

总而言之，无论一个组织是专门保护人员、保护资产，还是减轻可通过物理损坏和损失实现的业务风险，采用经过深思熟虑的物理（环境）安全解决方案都可以大大减少对组织的威胁，其明显目标是彻底消除这些威胁。保护人员和资产的首要步骤之一是确保他们无法被接触到。随着技术进步继续以惊人的速度发展，网络化解决方案增加了物理安全的有效范围，物理安全与信息安全之间的界限变得越来越模糊。当我们将周界入侵检测作为已有的强大分层防御模型的一部分时，我们就为经过验证的纵深防御方法增加了另一层高度有效的安全层，这些方法已被证明可以减少业务损失、资产被盗、信息损坏以及对人身安全和安全的威胁。
