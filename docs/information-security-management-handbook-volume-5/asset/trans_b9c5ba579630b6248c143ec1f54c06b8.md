

随着数据挖掘技术的发展和磁盘存储成本的降低，第三方可以利用社交网络个人资料中透露的信息创建个人数据的数字档案。一个常见的漏洞是，通过搜索可以访问比直接浏览个人资料所能访问的更多私有属性（例如，除非更改默认隐私设置，否则在 MySpace、Facebook 等平台上，个人姓名和个人资料图片可以通过搜索访问）。社交网络上透露的信息可能被攻击者利用，以使个人资料持有者感到尴尬、进行敲诈，甚至损害其形象。

# 人脸识别

社交网络用户通常倾向于在个人资料中添加可用于识别相应个人资料持有者的图片。因此，陌生人可以利用此数据源通过人脸识别关联不同服务上的个人资料，而人脸识别是所谓混搭所带来的更广泛威胁的一部分。例如，一个伪匿名约会资料与已识别的企业网站资料相关联。结果，攻击者可以收集远超用户预期的更多用户信息。

# 基于内容的图像检索

大多数社交网络尚未对个人资料图片采用任何隐私控制措施，以防止通过基于内容的图像检索（CBIR）泄露信息。CBIR 是一项新兴技术，能够匹配特征（例如，在非常大的图像数据库中识别房间的某些方面，如一幅画），从而增加定位用户的可能性。它打开了从看似匿名且包含用户家庭图片的个人资料中推断位置数据的可能性。这可能导致跟踪、不必要的营销、敲诈，以及与位置数据不必要披露相关的所有其他威胁。

# 图片标记与交叉画像

用户通常有选项使用元数据（如照片中人物的姓名、指向其社交网络个人资料的链接（即使他们不是该个人资料的所有者/控制者），甚至他们的电子邮件地址）来标记图片。攻击者可以利用此功能诋毁知名人士或品牌，并从其声誉中获利。

# 完全删除账户的困难

社交网络用户通常发现删除次要信息比从在线社交网络删除其用户账户更加困难。在某些情况下，此类次要信息几乎无法删除。例如，用户使用其身份在其他账户上发表的公开评论，即使在发布者的账户被删除后仍会保留在线。无法删除的信息可以作为数字档案使用。

# 网络与信息安全威胁

## 垃圾邮件

社交网络站点的巨大增长鼓励垃圾邮件发送者创建未经请求的消息（称为社交网络垃圾邮件），以在社交网络中产生流量过载。社交网络垃圾邮件可能导致流量过载、信任丧失、使用底层应用程序的困难，以及网络钓鱼和引导至色情网站。

## 跨站点脚本、病毒和蠕虫

社交网络容易受到由于弱验证第三方制作的小部件而引发的跨站点脚本（XSS）攻击和威胁。攻击者可以利用此漏洞来危及账户、进行网络钓鱼攻击，并将未经请求的内容传播到电子邮件和即时通信（IM）流量中。此外，它还可用于拒绝服务攻击及相关的声誉损失。

## 社交网络聚合器

一些新应用程序（如 Snag 和 ProfileLinker）提供对多个社交网络账户的读/写访问权限，以将数据集成到单个 Web 应用程序中。但此类应用程序使用弱身份验证方法，导致漏洞增加。此漏洞的影响包括身份盗窃、账户僵尸化（例如，用于 XSS 攻击或广告），以及通过允许在更广泛的数据基础上进行搜索，导致服务其他成员的隐私丧失。

# 身份相关威胁

## 网络钓鱼

网络钓鱼者可以轻松有效地利用社交网络上可用的信息，提高网络钓鱼攻击的成功率。社交网络也容易受到社会工程技术的攻击，这些技术利用受信任网络的低准入门槛，以及允许自动注入钓鱼链接的脚本攻击。

## 信息泄露

在线社交网络的隐私面临威胁，因为攻击者可以通过伪装身份轻松成为任何受限群组成员的朋友，然后访问仅属于该群组成员的私有信息。此外，在许多社交网络（如 MySpace）上，甚至可以使用脚本邀请朋友。与此威胁相关的潜在风险包括私有信息泄露、钓鱼获取信息，以及进行垃圾邮件和营销活动。

## 个人资料抢注

恶意攻击者可以创建虚假个人资料来冒充名人或品牌。此类个人资料通常由了解用户个人详细信息的人创建，他们创建个人资料来冒充该用户，从而给受害者造成各种问题。个人资料抢注可能会严重损害个人或品牌的声誉。这反过来可能导致经济损失和社会尴尬。

# 社会威胁

## 跟踪

当在使用在线社交网络时未能充分关注信息共享，跟踪可能成为真实的副作用。参与者可以在个人资料中透露个人信息，包括位置、日程、家庭住址和电话号码，攻击者可利用这些信息进行社会跟踪（通过物理接近、电话、电子邮件、即时消息或服务上的消息威胁受害者）。用户通常也会共享他们的即时通信账户，其中可能包括 Yahoo! Messenger、MSN Messenger、Google Talk 和 AOL Instant Messenger 等。其中一些服务允许用户在未经被添加者知情或未首先获得其确认的情况下，将好友或伙伴添加到其列表中。一旦该人进入伙伴列表，就可以发送消息或跟踪其在线状态。网络跟踪对受害者的影响是众所周知的，可能从轻微的恐吓和隐私丧失，到严重的身体伤害和心理损害。

## 企业间谍活动

利用社交网络进行的社会工程攻击是企业 IT 基础设施日益增长但常被低估的风险。这里的主要风险是企业知识产权的丢失，但获得内部人员的访问权限也可能是其他一系列犯罪的组成部分，例如黑客攻击企业网络造成损害、敲诈员工泄露敏感客户信息，甚至访问实物资产。
