# 组织治理

公共部门似乎更倾向于利用安全相关事件来推动信息安全计划，或者至少是获得支持项目或举措的资金来源。尽管失败或被攻破的后果严重，安全治理仍然是一团混乱。它理解不清，定义不明确，因此对不同的人意味着不同的东西。本质上，安全治理是企业或公司治理的一个子集。此外，可以将治理识别为安全责任和实践、安全策略和目标、风险评估和管理、安全资源管理，以及遵守立法、法规、安全政策和规则。

信息安全治理是“建立和维护控制环境，以管理与信息及其支持流程和系统的机密性、完整性和可用性相关的风险。”

从地方政府的角度来看，县由五人监事委员会和首席执行官（`CEO`）管理。`CISO`、部门信息安全官（`DISO`）以及信息安全指导委员会（`ISSC`）或安全委员会构成了信息安全治理。

联邦组织结构是大多数地方政府组织的常态。在县或市政府中，众多业务单位或部门服务于独特且不同的业务目的。由于这些独特的业务单位，可理解的治理对于任何信息安全计划的成功至关重要。这种治理涉及一个战略组织框架（[图 10.1](#9781466508507_epub_c10_r1.htm#fig_10.1)），它清晰地展示了涉及的参与者。“安全三角”，如[图 10.2](#9781466508507_epub_c10_r1.htm#fig_10.2)所示，是一个可行的框架，适用于`CISO`的组织，无论其信息技术是分散的、集中的还是托管安全服务。此外，地方政府组织可以被视为拥有30个或更多公司的组织，因为拥有30多个具有独特业务的县部门，为各自的选民服务（[图 10.3](#9781466508507_epub_c10_r1.htm#fig_10.3)）。

# 组织文化与行为

Bruce Schneier 是一位国际知名的安全技术专家和作家，也是商业领袖和政策制定者的首选安全专家。目前，他是 BT Managed Security Solutions 的首席安全技术官。他在《超越恐惧：在不确定世界中理性思考安全》（*Beyond Fear: Thinking Sensibly about Security in an Uncertain World*）一书中指出，安全关乎人：不仅是攻击系统的人，还有保卫这些系统的人。如果我们希望安全能够发挥作用，就需要了解这些人及其动机。我们已经讨论过攻击者；现在我们必须讨论防御者。

Schneier 还指出，良好的安全需要人来负责。人具有韧性。人可以即兴发挥。人可以发挥创造力。人可以制定即时解决方案。人是安全流程中最强大的环节。当安全系统在面对新的、协调的或毁灭性的攻击时取得成功，通常是由于人们的努力。

如果在阅读本章之前还不明显，那么现在应该很明显，人在任何信息安全计划中都扮演着重要角色。此外，这些人有时也会带来挑战。然而，正是人的集合定义了组织行为及其文化。组织文化是存在于组织中的文化，类似于社会文化。它由许多无形现象组成，例如价值观、信念、假设、感知、行为规范、工艺品和行为模式。看不见和未观察到的力量始终存在于可以看见和观察到的组织活动背后。组织文化是一种社会能量，推动人们采取行动。“文化对组织而言，就像个性对个人而言一样——一种隐藏的、统一的主题，提供意义、方向和动员。”

组织被假定为理性功利机构，其主要目的是完成既定目标（即信息安全策略和举措）。处于正式权威地位的人设定目标。组织员工的个人偏好受正式规则系统（例如政策、标准和程序）、权威和理性行为规范的约束。
