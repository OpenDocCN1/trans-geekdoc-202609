

# 国土安全部（DHS）

2003 年，DHS 部长 Tom Ridge 创建了 NCSD，以实施时任总统布什的《保护网络空间国家战略》和《2002 年国土安全法》。NCSD 隶属于 DHS 国家保护与计划署（NPPD）下属的网络安全与通信办公室（CS&C），其重大职责是与私营部门、公共部门（包括州、地方和部落政府）以及国际部门协作，保障美国的网络资产安全。广义上，它有两个主要目标：建立并维护国家网络响应系统（由国家网络响应协调小组领导，该小组由 13 个联邦机构组成，负责处理涉及国家关切的网络事件）；以及为美国关键基础设施实施网络风险管理计划（通过外联活动和网络应急演练，如“网络风暴”演习）。最重要的是，DHS 在领导非国防和情报界机构（称为“民用机构”）的安全方面发挥主导作用。由于多种因素，DHS 是政府各机构中实施角色最复杂、最具挑战性的机构之一，这些因素包括其成熟度（一个相对较新的内阁级机构）、规模（拥有十几个组成机构，如运输安全管理局、海岸警卫队、特勤局等）、广泛的范围（私营、公共和国际协调）以及职权（响应者、协调者、执行者和捍卫者的角色）。最近，他们扩大了努力，通过赞助旨在将安全作为国家讨论话题的竞赛和计划，来提高公众的安全意识。

# 国家标准与技术研究院（NIST）

NIST 成立于 1901 年，是商务部下属的一个机构，负责推进测量科学、标准和技术，以增强美国的经济安全。与普遍的误解相反，NIST 不是监管机构，也不会将其指南和标准强加给私营部门。然而，某些标准，如联邦信息处理标准（FIPS），特别是用于加密的 FIPS 140-2，对于联邦政府系统的实施是强制性的，这是根据《2002 年联邦信息安全管理法》（FISMA）的要求。NIST 在联邦政府的安全方面发挥着积极作用，尤其是针对民用机构，通过发布其特别出版物（SP）中的安全指南。特别出版物 800 系列，特别是 800-37 和 800-53，是联邦政府任何安全从业者的事实必读材料。此外，计算机安全分部管理着国家漏洞数据库（NVD），这是美国政府的网络安全漏洞存储库，基于使用安全内容自动化协议（SCAP）表示的数据。NVD 通过其检查清单、影响度量和潜在错误配置，实现了漏洞管理、测量和合规性的自动化。传统上，NIST 与国防部下属的 NSA 工作相对分开，NSA 为国防机构发挥着类似的技术标准和政策作用。然而最近，NIST 和 NSA 在网络安全标准/指南工作方面合作更加紧密，同时保持了 NIST 的指导角色与 NSA 在国防界更多的政策制定角色之间的区别。

# 国家安全局/中央安全服务

常被误解的国家安全局（NSA）是国防部管理下的情报界重要成员。NSA 位于马里兰州梅德堡，政府内部人士常称其为“梅德堡”，其有三项主要任务：信息保障——防止外国对手窃取敏感或机密的国家安全信息，或以其他方式干扰或拒绝访问这些国家安全系统；信号情报——为情报、反情报和军事行动收集、处理和共享来自外国信号的情报信息；最后是网络/网络战行动（将在本章后面详细介绍）。虽然中央安全服务（CSS）最初于 1972 年由国防部作为一个独立机构创建，但它是 NSA 的合作伙伴机构，主要任务是为武装部队的服务密码学要素提供密码学支持。NSA 局长（DIRNSA）必须是军队的委任军官，通常是三星上将或上将，同时还兼任 CSS 首长这一双重角色。

# 国防部（DoD）

国防部（DoD）拥有近两百万名现役和文职雇员，是最大的内阁级部门。它拥有四支武装部队——陆军、海军、海军陆战队和空军，以及十几个非战斗部门机构，如 NSA、国防后勤局（DLA）、业务转型局和导弹防御局。在过去几年中，关于美国军队在网络安全和网络战中的角色和使命，公共和私营部门都进行了激烈的辩论。此外，过去 18 个月中，还提出、辩论、否决、重新考虑并再次辩论了众多指挥和组织变更方案。在撰写本章时，美国军队在网络安全方面的主要角色已被公开承认，即保障国防部自身技术基础设施的信息和通信基础设施的机密性、完整性和可用性。虽然这种“防御姿态”始终得到 DoD 和武装部队高级领导的承认，但他们也并未明确否认武装部队需要进攻性网络能力（计算机网络攻击、计算机网络利用、电子战等）。鉴于 NSA 在其公开网站上描述的为美国军队实现网络战所发挥的作用，它很可能是执行进攻行动的主要机构。为了协调武装部队内部的各种角色，国防部长罗伯特·盖茨下令成立一个新的下属统一司令部，即美国网络司令部（USCYBERCOM），由四支军种的组成部分组成，并向美国战略司令部（USSTRATCOM）汇报。每支武装部队正在将其自身的网络资产组织成独立的单位/司令部，以作为 USCYBERCOM 的组成部分（例如，美国海军的舰队网络司令部/第十舰队司令部位于马里兰州梅德堡，以及第 24 编号航空队位于德克萨斯州拉克兰空军基地）。美国军队网络组织中最有趣的方面是 DIRNSA 的双重角色，他同时也是 USCYBERCOM 指挥官和 CSS 首长，在统一和巩固 NSA 在 DoD 网络安全方面的突出地位方面发挥作用。2010 年 5 月 14 日，陆军中将 Keith B. Alexander（DIRNSA）被参议院确认为 USCYBERCOM 的第一任指挥官。

# 司法部

司法部有着开展互联网犯罪调查（FBI）并通过其自然执法职责起诉一些最著名网络罪犯的悠久历史。《保护网络空间国家战略》将其确定为调查和起诉的牵头机构，从而正式确立了其角色。他们还运营着最广为人知的公私合作伙伴关系之一，用于关键基础设施保护（包括 IT）：Infraguard。
