

TCP SYN 攻击是一种拒绝服务攻击。许多无线攻击使用这种方法，试图导致主机释放其 IP 地址，并向恶意无线接入点请求新的 IP 地址，以破解弱加密算法。卡内基梅隆大学软件工程研究所（2001 年，第 1 段）指出，“拒绝服务攻击的特征是攻击者明确试图阻止服务的合法用户使用该服务。”

缓冲区溢出可能被归类为 DoS 类别，但黑客通常使用缓冲区溢出来获取服务器的根访问权限（即，再次考虑 DNS 或 RAS 服务器），方法是崩溃正在运行的线程或应用程序。当程序或进程尝试存储的数据超过其原本设计用于容纳的地址空间（即，临时数据存储区域或 RAM）时，就会发生缓冲区溢出（Kurtz, McClure, & Scambray, 2005）。如果地址空间在程序中定义不明确，并且输入和输出未针对该有限地址空间进行检查，那么这些必须存放在某处的额外信息将溢出到相邻缓冲区，并损坏或覆盖其中保存的有效数据。

地址空间表示程序可用的空间或内存量。例如，可以将地址空间想象成往冰格中装水以放入冷冻室。如果有人将冰格中的某个格子或单元装满溢出，水就会倾倒到下一个相邻的格子里。在这个类比中，每个格子代表内存中运行的一个程序。

虽然病毒和蠕虫都是恶意代码，但它们并非唯一的形式。还有间谍软件，以及以 Java 小程序或 ActiveX、VBS 脚本等形式存在的移动代码，如果它们具有恶意性质，可能会导致网络瘫痪。维基百科将移动代码定义为在系统之间传输（可能通过网络或通过 USB 闪存盘传输）并在本地系统上执行的软件，无需接收者进行明确的安装或执行。移动代码的示例包括 JavaScript、VBScript、ActiveX 控件以及嵌入在 Office 文档中的宏。

互联网上最常用的攻击方法是针对已知软件漏洞（即，漏洞）使用漏洞利用。大多数安全问题都来自应用层软件漏洞（即，OSI 模型）。一个示例是缓冲区溢出，这是编写不良代码的结果。另一个不同的示例是实现问题，例如几年前出现的针对 IPv4 的 TCP SYN 攻击。这并非实现中的软件漏洞，而是针对 TCP 基础规范的攻击。另一个类似的示例包括几年前出现的针对简单网络管理协议（SNMP）的漏洞（CERT, 2008）。

最后，最常见的漏洞利用是简单地扫描网络边界，收集特定网络段上使用的应用程序、服务、硬件类型以及相应网络段的 IP 地址范围的信息。具体来说，我们正在讨论足迹分析（Kurtz, McClure, & Scambray, 2005）。一旦网络被绘制并编目，黑客只需将保护网络段的安全架构工具暴露于已知漏洞，即可获得对组织的访问权限。

# 地址空间问题

此处的目标不是重复一个非常有据可查且已发表的问题，而是从信息保障角度讨论地址空间问题。由于 IP 地址空间的分配方式，“互联网骨干路由器的路由表中常规存在超过 85,000 条路由”（Microsoft, 2008, 1）。网络地址转换器（NAT）是为缓解地址空间缩减而开发的，它通过将“多个私有地址映射到单个公共 IP 地址”来实现（Microsoft, 2008, 1）。不幸的是，IP 启用的电话试图相互连接（即，语音 over IP (VoIP)），而 NAT 经常使该配置变得极难管理（Beijnum, 2006）。IPv6 引入了安全互联网协议（IPsec），后来使其与 IPv4 向后兼容。但是，当两个端点尝试建立隧道时，两端通常无法就 IP 地址达成一致。这个问题的原因在于中间某处，NAT 翻译了其中一个端点的 IP 地址（Beijnum, 2006）。最后，如果个人有尝试建立 IPsec 隧道的经验且涉及多个供应商，那么人们就知道，由于供应商使用的各种专有 IPsec 实现，几乎不可能使用来自不同供应商的 IPsec 解决方案。

# IPv6 简介

在简介中简要介绍了互联网的历史。曾经指出，原始互联网设计者无法预见或规划互联网的爆炸式增长。互联网已从其原始计划用途发生了变化。当前互联网的路由效率非常低，服务质量（QoS）支持缺乏当今对实时数据传输的要求，而 IPsec 支持是一个拼凑的项目——最好的情况也只是如此。

IPv6 是下一代互联网，旨在解决 IPv4 的许多缺陷。IPv6 的第一个 RFC 于 1995 年发布，此后已有修订（Beijnum, 2006）。

# IPv4 和 IPv6 之间的相似之处

也许理解相似之处最简单的方法是检查两个 IP 版本的内部头部。[图 7.3](#9781466508507_epub_c07_r1.htm#fig_7.3) 表示 32 位 IPv4 头部旁边的 128 位 IPv6 头部。金色区域是相同的，除了源地址和目标地址的位数增加之外。“版本”指定区域是相同的，并区分正在发送的是 IPv4 还是 IPv6 数据报。标记为蓝色的区域是相同的功能，但已移动并有了新名称，尽管它们都提供相同的基本功能。以下是 IPv4 中标记为蓝色的字段与 IPv6 头部中移动并重命名的类似字段的映射：

1\. 服务类型 = 流量类别

2\. 总长度 = 有效载荷长度

3\. 生存时间 = 跳数限制

4\. 协议 = 下一个头部
