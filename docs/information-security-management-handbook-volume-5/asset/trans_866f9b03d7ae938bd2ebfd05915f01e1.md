

IT 领域中很少有问题比虚拟化更受关注和热情追捧。虚拟化是指在计算机硬件系统与其上运行的软件之间提供抽象层的技术。通过提供逻辑视图而非物理视图来查看计算资源，虚拟化解决方案提供了几种极其有用的功能。最基本的是，它们实际上使操作系统（`OS`）将一组服务器视为单个计算资源池。它们还可以允许多个操作系统（`OSs`）在单个物理机上同时运行。

虚拟化的开端在于分区，它将单个物理服务器分离为多个逻辑服务器。一旦物理服务器被分割，每个逻辑服务器都可以独立运行操作系统和应用程序。在 20 世纪 90 年代，虚拟化主要用于在单个大型机硬件上重新创建最终用户环境。想要推出新软件，但首先想查看其在 Windows NT 或 Linux 机器上运行情况的 IT 管理员，使用虚拟化环境来创建不同的测试环境。

随着 x86 架构和廉价个人电脑的引入，虚拟化失去了大部分流行度，似乎不过是大型机时代的一个短暂潮流。x86 平台上虚拟化的近期复兴，更多归功于当前市场领导者 VMware，而非其他因素。VMware 在 20 世纪 90 年代为 x86 架构开发了第一个虚拟机监控程序（一种特殊的虚拟机监视器），成为当前虚拟化热潮的强大推动力。

# 虚拟化类型

虚拟化有四个基本类别：存储、网络、应用程序和服务器虚拟化，以下部分将对其进行描述。

## 存储虚拟化

存储虚拟化将多个网络存储设备的物理存储合并，使其看起来像是一个单一的存储设备。存储虚拟化的一个好例子是存储区域网络（`SANs`），它们通常使用大量高容量存储设备来提供大量虚拟化存储空间。它们是存储虚拟化的一个好例子。

## 网络虚拟化

网络虚拟化通过将可用带宽分割为可实时分配给特定服务器或设备的独立通道，来合并网络中的计算资源。

## 应用程序虚拟化

在应用程序虚拟化中，应用程序通过虚拟化层被封装并与操作系统分离，该层拦截应用程序的文件和其他操作并将其重定向到虚拟位置。

## 服务器虚拟化

服务器虚拟化向在其上运行的软件隐藏服务器资源的物理特性，包括单个服务器、处理器和操作系统的数量和标识。这种虚拟化是当今该技术最常见的应用，并被广泛认为是市场的主要驱动力。当大多数人使用“虚拟化”这一术语时，很有可能他们指的是服务器虚拟化。

# 虚拟化的优势

围绕虚拟化的行业喧嚣几乎令人震耳欲聋。这种“必备”功能正迅速成为“必将获得”的技术，因为新供应商进入市场，企业软件提供商将其编织到其产品线的最新版本中。原因在于，虚拟化使用得越多，就越能展示出额外的切实利益，从而增加其价值。

## 服务器整合

服务器整合是该市场的甜点区。虚拟化已成为几乎每个组织最喜爱的省钱举措的基石。一项又一项的调查显示，60% 到 80% 的 IT 部门正在推进服务器整合项目。主要原因显而易见——通过减少支持其业务应用程序的服务器数量和类型，组织正在获得显著的成本节约。

## 动态负载平衡

虚拟化的另一大优势是跨多个文件系统和机器的动态负载平衡能力。当传统机器上出现处理瓶颈时，应用程序会变慢甚至停止运行。动态负载平衡有助于确保此类瓶颈不会发生，从而使应用程序能够连续且不间断地运行。这对于业务关键型应用程序尤其重要。

虚拟化的另一个优势是降低功耗，既来自服务器本身，也来自设施的制冷系统。更充分地利用现有的利用不足的计算资源，意味着数据中心寿命更长，利润更丰厚。此外，更小的服务器占地面积更易于管理。

## 进程隔离

虚拟化的优势远不止于效率、功能和连续性，因为虚拟化为信息安全提供了许多好处。虚拟机（`VMs`）可用于将进程与攻击者和恶意软件隔离，使系统和应用程序更难以被成功攻击或感染。用户对应用程序的访问可以得到严格控制，因为虚拟化允许将特殊应用程序与最终用户应用程序隔离，使得对前者的未经授权的访问非常困难。即使在虚拟化环境中运行的系统或应用程序被成功攻击，攻击造成的任何影响通常也会被减弱。攻击者和恶意代码传播攻击（特别是基于恶意软件的攻击）的能力因此被降低。

虚拟化提供的进程隔离在信息安全中的有用性的一个好例子是 Java 小程序在 Java VM 中的“沙箱”环境中运行的方式。当可执行内容来自不完全受信任的外部来源时，会使用沙箱。沙箱限制了诸如读取或写入每台本地计算机上的文件、启动或调用每台本地计算机上的程序，以及从加载小程序的同一台计算机获取网络连接等功能。限制可能包括阻止下载的可执行文件从其下载到的机器连接到网络，以及阻止其访问其运行所在机器的文件系统。大多数沙箱对远程下载的可执行文件施加的限制多于对本地下载的可执行文件。

## 用于业务连续性和灾难恢复

虚拟化的另一个好处是，它可以大大提高业务连续性和灾难恢复操作的效率，并大大降低其成本。在这些领域使用虚拟化仍处于相对早期阶段。不过，虚拟化可以大大降低建立和维护重复数据中心的成本，因为需要购买的硬件更少。此外，虚拟化减少了在中断和灾难期间与采购相关的风险。可以快速创建新的虚拟机以支持业务运营的快速恢复。不容忽视的是，当电力供应紧张时，虚拟化可以大大降低电力需求。

## 蜜罐支持

虚拟化还支持蜜罐：旨在作为诱饵吸引攻击者的计算机、服务或应用程序。蜜罐不面向合法用户，它们看起来对攻击者有价值，表现得易受多种攻击，且看起来属于一个网络，但实际上是隔离的。几乎所有当前的蜜罐工具都基于虚拟化。
