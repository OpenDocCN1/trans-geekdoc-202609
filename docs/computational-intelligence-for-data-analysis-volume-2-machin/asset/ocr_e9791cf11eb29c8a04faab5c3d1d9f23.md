Following is a table containing some common types of diseases and different algorithms used in detecting them; Table 1 shows the four most affected organs worldwide and the algorithms used in detecting issues related to them. Different algorithms have different tasks; some algorithms are for clustering (grouping on the basis of similarities), while other algorithms could be classification algorithms (True or False).

More than one algorithm can be used to detect a single disease.
