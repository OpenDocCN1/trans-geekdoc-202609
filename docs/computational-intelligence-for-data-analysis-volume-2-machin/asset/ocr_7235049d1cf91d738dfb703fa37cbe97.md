# Lung Diseases Detection

Lung cancer is another major factor contributing to approximately 1.7 million deaths annually across the globe [9]. Lung cancer can be identified through X-ray and CT scan images of a patient’s chest. After some preprocessing on the image, feature extraction techniques are applied to it, like Contrast Limited Adaptive Histogram Equalization (CLAHE). CLAHE uses a gray-level co-occurrence matrix (GLCM) to extract features from the image. After feature extraction, image classification is performed, which is then followed by Performance Evaluation.
