The label consent KSVD is one of the techniques for learning discriminative sparse representation. It is simple to understand and implement; it showed results for face recognition [28]. The first technique is mentioned as Discriminative-SVD [28] or LC-KSVD[29]; it proposes an optimization problem of the following

```
$$\min_{D} \|X - DZ_{D,A}\|_F^2 + \lambda_1 \|D_{D,A}\|_F^2 + \lambda_2 \|Z_A\|_1 + \lambda_3 \|Q - AZ_A\|_F^2$
```

Here, Q is of the training samples; it is a basis for the correct class and zeroes. A is a parameter of the linear classifier.

In [29], a second formulation is proposed another to penalize the classification error. The LC-SVD2 formulation is as follows:

```
$$\min_{D,Z} \|X - DZ_{D,A}\|_F^2 + \lambda_1 \|D_{D,A}\|_F^2 + \lambda_2 \|Z_A\|_1 + \lambda_3 \|H - Z\|_F^2$
```

# B. DEP BOLTZMANN MACHINE

Restricted Boltzmann Machines are undirected models that use hidden units to model the distribution of the stochastic units. The hidden layer is symmetrically connected to the visible unit and the architecture is 'restricted' as there are no connections between units of the same layer. Traditionally, RBMs are used to model the distribution of the input p(x).
