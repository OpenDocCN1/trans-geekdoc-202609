Solving the problem (13) is computationally challenging. Also learning many parameters (network weights) leads to over-fitting. Both these issues, the weights are usually learned in a greedy layer-by-layer fashion [31], [34].

Stacked denoencoder [35] is a variant of the autoencoder where the input consists of noisy samples and the output consists of clean samples. The encoder and decoder are used to denoise input samples. Another variation for the autoencoder is to regularize it, ise.

```
$arg \min ||X - g \circ f(X)||^2 + R(W, X)$ (14)
```

The regularization can be a sparsity term [56], or a weight decay (Frobenius norm of W) as used in the convolutional autoencoder [58]. The regularization term is usually chosen so that is differentiable and hence minimizing using gradient descent techniques.

FIGURE 3. Single Layer Autoencoder.

Although the sigmoid function is popularly used, other non-linear functions such as tanh can also be used. Rectifier units and linear layers map network layer activation; owing to linearity, the process is considered faster. The decoder maps the latent variables to the data space.

```
$x = W^T \phi(Wx)$ (11)
```

Since the data space is assumed to be the space of real numbers, there is no signal noise during training, the problem is to learn decoding $W$ and $W'$. These are learned by decoding the Euclidean cost:

```
$arg \min ||X - W^T \phi(WX)||^2$ (12)
```

Here $X = [x_1, \dots, x_N]$ consists of all training samples stacked as columns where $N$ is the number of training samples. In Equation (12) is clearly non-convex, but it is smooth and can be solved by gradient descent techniques; the activation function needs to be smooth and continuously differentiable.

There are several extensions to the basic autoencoder. Stacked autoencoders have hidden layers - one inside the other (see Fig. 4). The corresponding cost is expressed as follows:

```
$arg \min ||X - g \circ f(X)||_F^2$ (13)

where,

```
$g = W_L^T \phi(W_{L-1} \dots \phi(W_1(X)))$
```

The diagram for dictionary learning is shown in Fig. 5. Let $X$ be the data, $D_l$ the dictionary and $Z$ be the feature/representation of $X$ in $D_l$. Dictionary learning follows a synthesis framework (15), it is dictionary learned so that the features the data with the dictionary.

```
$X = D_l Z$ (15)
