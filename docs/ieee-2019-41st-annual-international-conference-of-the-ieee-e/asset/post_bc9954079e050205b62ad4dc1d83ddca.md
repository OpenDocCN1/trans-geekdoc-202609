There are five instances of each appliance. 1500 traces are collected for each instance of each appliance. Each trace is of 1-millisecond duration and constitutes a vector of length 16,384. The training set consists of samples from 1 instance for each appliance while forming 4 instances of each appliance constitutes the test set. For every problem, the training data for each class has 100 traces and the test data is 4 × 1500 = 6000. The protocol has been described in [77]. For testing, all 1500 traces should be considered as a single task; the task is to identify the appliance from traces. Therefore the classified label of 1500 samples used majority voting to a single appliance. Cepstrum features [78] are used as the feature set for classification; some examples of cepstrum features are shown in Fig. 11.
