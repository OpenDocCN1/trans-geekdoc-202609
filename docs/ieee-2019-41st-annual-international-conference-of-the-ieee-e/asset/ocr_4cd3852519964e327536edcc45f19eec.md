It must be noted that learning two-levels of dictionaries with the coefficients (16) is not the same as a single (collapsed) dictionary and its corresponding features. The problem (15) single is a bilinear problem and (16) is a tri-linear problem; they are not the same. One cannot expect to get the same dictionary learning and a collapsed two dictionary learning. The challenge is learning multiple levels of dictionaries in one of the following:

+   1. Recent successes have proven guarantees for single level dictionary learning [59]–63. These proofs would be very hard to replicate for multiple layers.
2. Moreover, the number of parameters required when multiple layers of dictionaries are learned simultaneously. With trained with limited data, this is prone to overfitting.

Here we propose to learn the dictionaries in a greedy manner, which is in sync with other deep learning techniques [32]–34. Moreover, layer-wise learning will guarantee the convergence at each layer. The diagram illustrating layer-wise learning is shown in Fig. 7.

Extending this idea, a multi-level dictionary learning problem with non-linear activation ($\varphi$) can be expressed as,

```
$X = D_1\varphi(D_2\varphi(DN_2))$$
```

Ideally, we would have to solve the following problem.

```
$min \|X - D_1\varphi(D_2\varphi(DN_2))\|_F^2 + \mu\|Z\|_1$$
```

However, such a problem is highly non-convex and requires solving a large number of parameters. With the limited amount of data, it will lead to over-fitting. To address

these issues, mentioned before, propose a greedy approach where we learn one layer at a time – similar to training in the deep learning. With the substitution $Z_1 = \varphi(D_2\varphi(DN_2))$, Equation (17) can be written as $X = D_1Z_1$ such that it can be solved as single dictionary learning. The representation is not sparse. Hence it can be solved using alternating minimization:

```
$min \|X - D_1Z_1\|_F^2$$
```

Optimality of (19) by alternating minimization has been proven in [56]. Therefore we follow the same approach. The dictionary D and basis are learned by:

```
$Z_1 \leftarrow min \|X - D_1Z_1\|_F^2$$
```

```
$D_1 \leftarrow min \|X - D_1Z_1\|_F^2$$
```

This is the method of both (36) and (20) and are simple sparse problems having closed solution. For the second layer, we set $Z_2 = \varphi(D_2Z_2)$, where $\varphi(Z_2) = D_2Z_2$ this is a single layer dictionary learning. The representation is then represented using:

```
$min \|\varphi^{-1}(Z_1 - D_2Z_2)\|_F^2$$
```

This can be solved by alternating minimization as in the first layer. After training the penultimate layer, we will have $Z_1 = \varphi(DN_2)$ or $\varphi^{-1}(Z_1) = D_2Z_2$. In this case, the coefficient Z can be sparse. For learning sparse features, one needs to regularize by using $\ell_1$-norm on the features. This is given by:

```
$min \|\varphi(Z_{n-1}) - D_nZ\|_F^2 + \lambda\|Z\|_1$$
```

This is solved using alternating minimization.

```
$Z \leftarrow min \|\varphi^{-1}(Z_{n-1}) - D_nZ\|_F^2 + \lambda\|Z\|_1$$
```

```
$D_n \leftarrow min \|\varphi^{-1}(Z_{n-1}) - D_nZ\|_F^2$$
```

As before, (23b) is a least squares problem having closed solution. Although not analytic, the solution to (23a) can be solved using Iterative Soft Thresholding Algorithm (ISTA) [64]. The ISTA solution for (23a) is given by:

```
Initialize: $Z \leftarrow min \|\varphi^{-1}(Z_{n-1}) - D_nZ\|_F^2$$
```

Iterate until

```
$Z \leftarrow B - \frac{1}{\alpha}(D_n^T(B) - \lambda)
Z \leftarrow sign(B)[0, |B|-\lambda/\alpha]$
```
