ABSTRACT—Two representation paradigms are dictionary learning and deep learning. While dictionary learning focuses on learning "basis" or "features" by matrix factorization, deep learning focuses on extracting features using weights. This paper focuses on combining the concepts of these two paradigms by proposing how deep architectures can be built using dictionary learning. The proposed technique is compared with other learning approaches such as stacked autoencoder, deep belief network, and convolutional neural network. Experiments on real-world benchmark data of electrical classification show that dictionary learning excels where others do not. We postulate that the proposed formulation can provide a path for a new class of deep learning tools.

INDEX TERMS—Deep learning, dictionary learning, feature representation.

## I. INTRODUCTION

In representation learning paradigm, dictionary learning has received a lot of interest in the 90s. Researchers adopted the concept of dictionary learning for information retrieval [1], [2]. In early days, dictionary learning had not been; researchers were using matrix factorization. The goal was to learn an empirical basis from data; hence required decomposing the data to a feature matrix. The current popularity of dictionary learning owes to K-SVD [3]. K-SVD is an algorithm to decompose a matrix (training data) into a dense basis and sparse coefficients. However, the concept of such sparse-dense decomposition is K-SVD [5]. Since the advent of K-SVD in 2006, there has been plethora of work on this topic. Dictionary learning can be used for unsupervised problems like image segmentation as well as for problems arising in sparse feature extraction. Furthermore, dictionary learning has been used for all inverse problems in image processing starting from simple image denoising [6], inpainting [7], to complex problems such as tomography [10]. Such problems can also be solved by Compressed Sensing (CS) [12], [13]. However, it has been seen that dictionary learning yields better (customized representation) compared to the fixed basis obtained by Compressed Sensing. Mathematical transforms such as Discrete Cosine Transform (DCT), wavelet, and Gabor have been used in image classification [14]–[16]. Existing techniques have used these transforms firstly by statistical feature extraction methods as Principal Component Analysis (PCA) or Linear Discriminant Analysis (LDA) before using the features to a classifier. Dictionary learning has replaced these transforms in image processing; it is also used in feature extraction scenarios. Dictionary learning provides researchers the opportunity to design dictionaries which yield not only sparse representation (e.g., wavelet and DCT) but also informative.

Initial techniques in dictionary learning proposed native methods which learn specific dictionary classes [17]–[19]. Later, dictionary penalties are introduced in dictionary learning to improve the classification performance. One such technique is to include softmax dictionary function [20]–[22]; after dictionary penalties include Fisher criterion, linear classification error [24] and [25]. In [27], [28], discrimination is introduced by learning the learned features to map to representing classes. Prior studies on dictionary learning "shallow" models learn a restricted Boltzmann machine (RBM) [30] and an auto-encoder (AE) [31], the two popular deep learning architectures. In DL, the cost is Euclidean distance between the data and the representation given by the learned basis; for RBM it is reconstruction error; whereas for AE, the cost is the reconstruction error between the data and decoded representations/features.

For problems of sparse representation, the objective is to learn a basis that can represent the samples in a sparse fashion, i.e, $Z$ needs to be sparse. K-SVD [3], [4] is the most known technique for sparse representation. Fundamentally, it solves a problem of:

$$\min ||X - DZ||^2_F \text{ such that } ||Z||_0 \le \ell$$

Almost at the same time, when dictionary learning gained traction, researchers in machine learning learned that linear and compact representation could be achieved by going deeper in network architecture. Deep Belief Network (DBN) is formed by stacking multiple RBMs, one after the other [32]. Similarly, stacked autoencoder (SAE) is created by one AE after the other [34], [35].

Inspired from the first learning paradigms, in the path we hope to learn multi-level dictionaries, many researchers in the deep learning community have been able to achieve by designing deeper architectures; it is our assertion that the proposed formulation of dictionary learning algorithms will yield multiple dictionaries which can then be collapsed to a single level. However, such a collapsed dictionary will not be the same as the proposed deep learning. The remaining paper presents literature review of dictionary learning in Section II, followed by methodology in Section III and evaluation in Section IV.
