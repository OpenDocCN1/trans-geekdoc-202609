In this research, we propose to use the idea of deep dictionary learning, where, by learning one shallow dictionary we learn multiple levels of dictionaries. Learning all the dictionaries simultaneously makes the problem highly non-converse. Also solving many parameters is always fraught with the problem of overfitting. To account for these issues, we learn the dictionaries in a greedy fashion – one at a time. The representations/features from each level are used as input to learn the next. Thus, the deep dictionary learning is a shallow dictionary learning algorithm; which is well known and solved. We perform experiments for both classification and clustering problems.
