ABSTRACT Two representation learning paradigms are dictionary learning and deep learning. While dictionary learning focuses on learning “basis” or “features” by matrix factorization, deep learning focuses on extracting features using “weights” or “filter” in a greedy layer by layer fashion. This paper focuses on combining the concepts of these two paradigms by proposing deep learning and how sheer architectures can be built using the layers of dictionary learning. The proposed technique is compared with other deep learning approaches, such as stacked autoencoder, deep belief network, and convolutional neural network. Experiments on benchmark data show that the proposed technique achieves higher classification and clustering accuracies. On a real-world problem of electrical appliance classification, we show that dictionary learning excels where others do not at-par. We postulate that the proposed formulation can provide the path for a new class of deep learning tools.

INDEX TERMS Deep learning, dictionary learning, feature representation.

# I. INTRODUCTION

In representation learning paradigm, dictionary learning has received a lot of interest. Researchers adopted the concept of dictionary learning in [1] and information retrieval [2] in 90s. In early days, the ‘dictionary learning’ had not been; researchers were using the matrix factorization. The goal was to learn an empirical basis from data. It required decomposing the data to a basis/dictionary matrix and a feature matrix; hence the “matrix factorization” approach was used.

The current popularity of dictionary learning owes to K-SVD, [3]. K-SVD is an algorithm to decompose a matrix (training data) into a dense basis and sparse coefficients. However, the concept of such a sparse-dense decomposition is K-SVD [5]. Since the advent of K-SVD in 2006, there has been a plethora of work on this topic.
