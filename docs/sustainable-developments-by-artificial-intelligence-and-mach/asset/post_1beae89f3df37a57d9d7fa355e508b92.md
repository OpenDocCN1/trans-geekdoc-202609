
\(\Delta TVV = \frac{TVV_{After DG}}{TVV_{Before DG}}\)

where:

\(TVV = \sum_{i=2}^{N} |1 - V_i|\)

The TOC values for system study with the operation and maintenance costs included the cost of DG integrated into the distribution system (Diaaeldin et al., 2019). The \(\Delta\)TOC index is calculated by:

\(\Delta TOC = \frac{TOC_{After DG}}{TOC_{Before DG}}\)

The TOC before and after the integration of the DG is calculated by the following expressions (Imran & Kowsalya, 2014):

\(TOC_{Before DG} = K_2 \times P_{Loss}^{Before DG}\)

\(TOC_{After DG} = \left( K_1 \times P_{Loss}^{After DG} \right) + \left( K_2 \times P_{Loss}^{Before DG} \right)\)

### 6.2.2 Equality constraints

The equality constraints represent the load flow balance equations, which can be formulated as (Chang & Chinh, 2020; Dehghani et al., 2020; Elattar & Elsayed, 2020; Hassan & Zellagui, 2019; Imran & Kowsalya, 2014; Karimizadeh et al., 2020; Osama et al., 2020; Yang et al., 2018):

\(P_G + P_{DG} = P_D + P_{Loss}\)

\(\mathcal{Q}_G + \mathcal{Q}_{DG} = \mathcal{Q}_D + \mathcal{Q}_{Loss}\)

### 6.2.3 Inequality constraints of distribution line

Inequality constraints represent the power system operating limits, which can be given as:

- (a) Bus voltage limits:

\(V_{min} \le |V_i| \le V_{max}\)

- (b) Voltage drop limit:

\(|1 - V_i| \le \Delta V_{max}\)

- (c) Line capacity constraint:

\(|S_{ij}| \le |S_{max}|\) (6.14)

### 6.2.4 Inequality constraints of DG units

In the case of PV, the DG source only delivers active power, while in the case of WT, the DG source delivers active and reactive power (Chang & Chinh, 2020; Dehghani et al., 2020; Hassan & Zellagui, 2019; Imran & Kowsalya, 2014; Karimizadeh et al., 2020; Lasmari et al., 2020).

- (a) DG capacity limits:

\(P_{DG}^{min} \le P_{DG} \le P_{DG}^{max}\) (6.15)

\(Q_{DG}^{min} \le Q_{DG} \le Q_{DG}^{max}\) (6.16)

- (b) Power Factor of DG:

\(PF_{DG}^{min} \le PF_{DG} \le PF_{DG}^{max}\) (6.17)

\(PF_{DG} = \frac{P_{DG}}{\sqrt{P_{DG}^2 + Q_{DG}^2}}\) (6.18)

- (c) Position of DG:

\(2 \le DG_{position} \le N_{bus}\) (6.19)

- (d) Number of DG:

\(N_{DG} \le N_{DG.max}\) (6.20)

- (e) Location of DG:

\(n_{DG,i} / Location \le 1\) (6.21)

### 6.3 Cosine adapted whale optimization algorithm (CAWOA)

In 2016, Mirjalili developed the basic whale optimization algorithm (WOA) approach (Mirjalili & Andrew, 2016) as an innovative biological-inspired heuristic technique. The natural body motions of humpback whales are the basis of the WOA. Three steps are used to describe the bubble-net hunting process and derive the WOA mathematical model. Modeling steps are detailed in the following subsections (Elaziz & Mirjalili, 2019; Mirjalili & Andrew, 2016). Fig. 6.1 represent the exploration mechanism implemented in basic WOA. This enhancement strategy can modify spiral and circular movements, depending on the measure of _p_ (Elaziz & Mirjalili, 2019).

In the basic WOA approach, the movement between exploration and exploitation phase occurs with a decrease of distance control parameter "_a_" linearly from 2 to 0. The cosine adapted WOA (CAWOA) approach employs the cosine function to tune the parameter "_a_" of the WOA for varying exploration and exploitation combinations over the course of iterations (Eid & Abraham, 2018). The CAWOA approach employs a cosine function instead of the linear function for the decay of the parameter "_a_" over the course of iterations; as given in Eq. (6.22). The use of a cosine feature for decaying "_a_" result in a differing exploration and exploitation combination (Saha & Panda, 2020). The pseudo code of the CAWOA technique is presented in Algorithm 6.1.

- **Algorithm 6.1 Pseudo-code of CAWOA.**
- 1. Generate the initial population \(X_i\) (\(i = 1, 2, ..., n_p\))
- 2. Evaluate the fitness for each candidate solutions in \(X_i\)
- 3. \(X^*\) is the best candidate solutions
- 4. **while** (\(t < t_{max}\))
- 5. **for** \(i = 1\) to \(n_p\) (for each search agent)
- 6. Update the parameter \(a\) by equation:
  - \(a = 1 + 0.5 \cdot \cos \left( \pi \frac{t}{t_{max}} \right)\) (6.22)
  - Update \(A, C, l\) and p
- 7. **if** (\(p < 0.5\))
- 8.   **if** (\(|A| < 1\))
- 9.     Update the position of the search agent by equations:
    - \(\vec{D} = \left| \vec{C} \cdot \vec{X}^*(t) - \vec{X}(t) \right|\) (6.23)
    - \(\vec{X}(t+1) = \vec{X}^*(t) - \vec{A} \cdot \vec{D}\) (6.24)
- 10.   **else if** (\(|A| \ge 1\))
- 11.     Select a random search agent (\(X_{rand}\))
- 12.     Update the position of the search agent by equations:
    - \(\vec{D} = \left| \vec{C} \cdot \vec{X}_{rand} - \vec{X} \right|\) (6.25)
    - \(\vec{X}(t+1) = \vec{X}_{rand} - \vec{A} \cdot \vec{D}\) (6.26)
- 13.   **end if**
- 14. **else if** (\(p \ge 0.5\))
- 15.   Update the position of the current agent by equation:
    - \(\vec{X}(t+1) = \vec{D}' \cdot e^{bt} \cdot \cos(2\pi l) + \vec{X}^*(t)\) (6.27)
- 16. **end if**
- 17. **end for**
- 18. Check if any search agent goes beyond the search space
- 19. Calculate the MOF of each search agent
- 20. Update \(X^*\) if there is a better solution
- 21. \(t = t + 1\)
- 22. **end while**
- 23. Return \(X^*\)

In the case study of installing the WT-DG, IEEE 33-bus and 69-bus provide the optimal solution by 60 iterations and the 118-bus system takes almost 180 iterations to attain the best solution, this is related to the large size of this system.
