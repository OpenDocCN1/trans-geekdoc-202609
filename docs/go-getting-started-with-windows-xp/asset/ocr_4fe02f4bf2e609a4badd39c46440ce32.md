# Activity 1.6 Moving, Renaming, and Deleting Files

In Activity 1.6, you will move files from one location on your removable drive to another location on the same drive. You will also rename and delete files.

+   1. In the **Folders** task pane, scroll down if necessary and then click the removable drive you are using to store your files. In the right pane, click the **Name** column as necessary to display the files in alphabetical order. Click the **Views** button arrow and then click **Thumbnails**. Compare your screen with Figure 1.35.

The two folders you created and three of the files you copied—along with the XML Files folder—display in the right pane. Small *thumbnail* images of the files—miniature images of the pictures in the files—display in the right pane. These thumbnails make it easy to select the correct file when you have a folder that contains a large number of images. Folders that contain pictures display thumbnails of up to four of the images in a large file folder icon.
