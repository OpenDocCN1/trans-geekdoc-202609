**Project Summary**

**File Guide**
Clearly shows students which files are needed for the project and the names they will use to save their documents.

**Objective**
The skills the student will learn are clearly stated at the beginning of each project and color coded to match projects listed on the chapter opener page.

**Teachable Moment**
Expository text is woven into the steps— at the moment students need to know it— not chunked together in a block of text that will go unread.
