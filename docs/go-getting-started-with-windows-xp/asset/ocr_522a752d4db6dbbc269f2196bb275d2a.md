# Rubric

A matrix to guide the student on how they will be assessed is reprinted in the Annotated Instructor Edition with suggested weights for each of the criteria and levels of performance. Instructors can modify the weights to suit their needs.

# Outcomes-Based Assessments

| Rubric | Your completed project is of Professional Quality if you: | Your completed project is Approaching Professional Quality if you: | Your completed project Needs Quality Improvements if you: |
|---|---|---|---|
| Software Mastery | Criteria describing professional use of software and completion of required tasks. | Criteria describing partially completed or less efficient software use. | Criteria describing insufficient software use or incomplete work. |
| Content | Criteria describing accurate, complete, and well-developed content. | Criteria describing generally adequate content with some weaknesses. | Criteria describing incomplete, inaccurate, or underdeveloped content. |
| Format and Layout | Criteria describing effective organization, formatting, and visual presentation. | Criteria describing generally effective formatting with some inconsistencies. | Criteria describing poor organization, formatting, or visual presentation. |
| Process | Criteria describing an organized and effective work process. | Criteria describing a partially organized or inconsistent process. | Criteria describing an ineffective or disorganized process. |
