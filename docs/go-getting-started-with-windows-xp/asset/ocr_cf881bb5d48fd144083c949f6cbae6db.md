❺ **Click**—press the left mouse button one time—the **Close** button [Close button icon] to close the **My Computer** window. Then, point to the **My Computer** icon on the desktop and click the right mouse button—this action is known as a *right-click*. If the **My Computer** icon does not display on your desktop, click the **Start** button [Start button icon], and then right-click **My Computer**. Compare your screen with Figure 1.6.

A shortcut menu displays. **Shortcut menus** list commands that are *context-sensitive*—commands commonly used when working with the selected object. On this shortcut menu, the Open command is displayed in bold because it is the default action that occurs when you double-click this icon.
