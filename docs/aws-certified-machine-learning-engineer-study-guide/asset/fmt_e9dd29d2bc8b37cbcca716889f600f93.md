### Scalar

A *scalar* is a single number, typically representing a quantity that has only magnitude but no direction. For example, it can represent temperature or mass:

### Matrix

A *matrix* is a two-dimensional (2D) array of numbers, which can be used to represent linear transformations or systems of equations:

### Tensor

A *tensor* is a generalization of scalars, vectors, and matrices to higher dimensions. Tensors can represent more complex data structures, such as multidimensional datasets in ML or physics.
