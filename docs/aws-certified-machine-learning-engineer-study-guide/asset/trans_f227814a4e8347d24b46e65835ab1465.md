### 本书使用的约定

本学习指南采用特定的排版样式，旨在帮助您快速识别重要信息，避免对屏幕提示等词汇的含义产生混淆。

请特别留意以下样式：

*   *斜体文本* 表示在章节中首次详细描述的关键术语。这些词汇极有可能出现在可搜索的在线词汇表中。（斜体也用于强调。）
*   `等宽字体` 表示程序内容或配置文件、以文本模式显示的 macOS/Linux Shell 提示符、文件名、文本模式命令名称以及互联网 URL。
