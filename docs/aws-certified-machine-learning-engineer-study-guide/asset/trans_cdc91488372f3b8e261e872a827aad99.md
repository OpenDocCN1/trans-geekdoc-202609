
# 了解监督学习、无监督学习和强化学习 ML 算法之间的区别。

使用监督 ML 算法时，模型是使用标记数据训练来预测结果的，其中每个数据点都标记有相应的标签或结果（即正确的预测）。相比之下，无监督 ML 算法处理未标记数据。其目标是识别数据中隐藏的模式、结构或关系。强化 ML 算法迫使智能体通过试错来学习如何预测结果。

# 了解 ML 算法和 ML 模型之间的区别。

ML 算法是一组用于创建和训练模型的规则或过程。它定义了模型如何通过调整其参数从输入数据中学习。示例包括 `linear regression`、`logistic regression`、`decision trees` 和 `k-Nearest Neighbors (k-NN)`。ML 模型是使用 ML 算法完成训练过程*后*生成的输出。它代表从训练数据中得出的已学习模式和关系。这些模式和关系以数学函数的形式编码，从本质上以一种明确的方式表达了学习到的模型。一经训练，模型就可以对新的、未见过的数据进行预测或分类。

# 了解什么是神经网络。

神经网络是 DL 中使用的一种计算模型，它模拟人脑，由层中的相互连接的神经元组成。它处理输入数据，通过学习算法调整权重和偏差，并产生输出以识别模式和进行预测。

    1.  目标变量

    1.  监督学习
    2.  梯度下降
    3.  无监督学习
    4.  强化学习

5.  什么区分了机器学习模型和机器学习算法？

    1.  模型是一组规则，算法是学习到的模式。
    2.  模型执行预测，算法定义其如何学习。
    3.  模型是学习过程，算法是最终输出。
    4.  模型是超参数，算法是优化技术。

6.  在机器学习的背景下，什么是超参数？

    1.  模型从数据中学习的参数
    2.  在训练过程开始*前*设置的参数
    3.  保存模型最终输出的变量
    4.  用于评估模型性能的指标

7.  在神经网络中使用激活函数的主要目的是什么？

    1.  初始化权重
    2.  向模型引入非线性
    3.  降低数据的维度
    4.  执行梯度下降优化

8.  反向传播在神经网络中的主要功能是什么？

    1.  将输入数据正向传播通过网络
    2.  更新每个神经元的权重和偏差以最小化误差
    3.  可视化数据
    4.  从数据集中移除异常值

9.  哪种类型的神经网络最适合处理序列数据，如时间序列或文本？

    1.  卷积神经网络 (CNN)
    2.  循环神经网络 (RNN)
    3.  人工神经网络 (ANN)
    4.  深度神经网络 (DNN)

10. 深度学习和机器学习之间的一个关键区别是什么？

     1.  DL 算法要比 ML 算法需要更少的数据即可表现良好。
     2.  DL 依赖具有多层的神经网络来自动提取特征，而 ML 通常需要手动进行特征工程。
     3.  ML 算法总是比 DL 算法更准确。
     4.  DL 算法不能用于图像和语音识别任务。

## 介绍摄取和存储

数据摄取和存储是机器学习 (ML) 生命周期中“收集数据”阶段的两个核心要素，如[图 2.1](#c002.xhtml#c02-fig-1)所示。

![图 2.1 ML 生命周期。](images/c02f001.png)

[图 2.1](#c002.xhtml#rc02-fig-1) ML 生命周期。

正如您在[第 1 章](#c001.xhtml#c001)中所了解的，您的 ML 解决方案需要数据来训练选定的模型并生成推理。数据可能以不同形式（结构化、半结构化或非结构化）、来自不同来源、在不同时间出现。

摄取是负责为您的 ML 解决方案收集数据并将其推送到 AWS 的过程。您——作为一名 AWS 机器学习工程师——将需要根据数据量、速度和多样性，选择最佳的 AWS 数据摄取服务，从不同来源收集数据。

收集后，您需要将摄取的数据存储在合适且安全的位置，以确保满足持久性和可用性要求。通过这种方法，您的 ML 解决方案将能够在需要时（可用性）并只要需要（持久性）就能访问数据来训练您的 ML 模型。

## 摄取和存储数据

在深入探讨摄取和存储之前，让我们退一步，更好地了解 ML 问题的所有要素。

机器学习是称为数据工程的更广泛学科的一部分。在此背景下，ML 是数据服务的三种方式之一。

[图 2.2](#c002.xhtml#c02-fig-2) 说明了数据工程生命周期。第一步是生成，侧重于数据的来源。数据可以由各种不同的源系统生成，例如数据库、物联网 (IoT) 设备、流式系统等。数据工程师设计从源系统消费数据的流程，但可能无法控制这些系统。

![图 2.2 数据工程生命周期。](images/c02f002.png)

[图 2.2](#c002.xhtml#rc02-fig-2) 数据工程生命周期。

生成后，数据以其原始格式被摄取到位于 AWS 的存储系统中，在那里它被存储并随后被处理。对于考试而言，必须确保选择合适的数据存储。选择取决于特定的用例。例如，您可能希望将原始数据作为对象存储在 `S3 bucket` 中，因为您的数据是批量生成的，且与其他方式相比，这种存储类型相对便宜。相反，如果您的数据是近实时生成和消费的，您可能希望将其存储在流式存储介质中，例如 `Amazon Kinesis Data Streams`。
