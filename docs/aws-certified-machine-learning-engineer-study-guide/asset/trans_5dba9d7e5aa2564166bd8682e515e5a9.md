### 平均绝对百分比误差

MAPE 是评估回归模型准确性的另一种常用指标，特别是在理解相对误差至关重要的情况下。MAPE 计算实际值与预测值之间平均绝对百分比差异，以百分比形式提供对预测准确性的直观理解。当处理不同尺度的数据时，该指标特别有用，因为它对误差进行了归一化，使结果更易于解释。通过以百分比形式表示误差，MAPE 允许跨不同数据集和模型进行直接比较。MAPE 的公式如下：
