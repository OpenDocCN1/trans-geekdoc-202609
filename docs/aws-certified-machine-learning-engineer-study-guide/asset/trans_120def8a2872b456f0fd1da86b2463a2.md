

## 对数变换

通过以给定底数（例如底数 `e`、底数 2、底数 10 等）将异常值替换为其对数，您正在压缩某个特征的取值范围，从而减少数值之间的极端差异。因此，该异常值不会与该特征的其他值相差太远。例如，1000 的以 10 为底的对数（`log10`）是 3。这是因为 `10^3 = 1000`，这使其更接近其他较小的值，同时又不失其重要性。

## 插补

就像处理缺失值一样，您可以使用该特征的平均值（例如），并用该值插补以替换异常值。如果异常值是由人为错误导致的，这将是一种极好的方法。

异常值通常会造成偏态分布，如[图 3.7](#c003.xhtml#c03-fig-7)所示。对数变换有助于使该分布正态化，使其更加对称，从而提高机器学习模型的性能。

[图 3.8](#c003.xhtml#c03-fig-8) 说明了在使用对数刻度表示纵坐标轴 `y` 后的同一数据集。异常数据点 `[25, 23]` 的 `x = 25` 和 `y = 23`。因为 `log10(23) = 1.37172724`，您可以看到该数据点不再显著偏离均值。

在[图 3.9](#c003.xhtml#c03-fig-9)中，直方图显示两个特征均呈右偏数据分布。右偏数据分布意味着我们大多数数据点聚集在范围的低端，并有一条长尾向右延伸。这条长尾代表少数数据点的值远高于数据集的其余部分。本质上，大多数值较低，只有极少数异常高，这正是数据点 `[25, 23]` 代表最高值对的场景。

对于偏态数据，四分位距（IQR）方法通常被认为是检测异常值的最佳方法之一。IQR 受偏度影响较小，并提供了一种稳健的度量来识别极端值。

假设 `Q1` 和 `Q3` 分别表示数据集的第一和第三四分位数，以下是其工作原理的快速概述：

*   计算 `Q1` 和 `Q3`。
*   计算 `IQR = Q3 - Q1`。

任何数值小于 `Q1 - 1.5 * IQR` 或大于 `Q3 + 1.5 * IQR` 的数据点均被视为异常值。

在我们的示例中，我们可以利用 `numpy` 和 `pandas` 库中 `DataFrame` 类提供的内置 `quantile` 方法来检测数据集中的异常值，如以下代码片段所示：

```
import numpy as np
import pandas as pd

# 加载数据集
data = np.array([[4, 11], [3.8, 12], [4.5, 12.5], [8, 8], [9, 8.5], [9.5, 7.5], [13, 5], [14, 4.7], [13.7, 6], [25, 23]])
df = pd.DataFrame(data, columns=['Feature1', 'Feature2'])

# 计算 IQR
Q1 = df.quantile(0.25)
Q3 = df.quantile(0.75)
IQR = Q3 - Q1

# 定义异常值条件
outliers = ((df < (Q1 - 1.5 * IQR)) | (df > (Q3 + 1.5 * IQR))).any(axis=1)
df['Outlier'] = outliers

print("带有异常值标记的原始数据：")
print(df)

# 通过移除异常值进行处理
df_cleaned = df[~df['Outlier']].drop(columns='Outlier')

print("\n移除异常值后的清洗数据：")
print(df_cleaned)
```
