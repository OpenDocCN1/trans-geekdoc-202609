Without the third axis, the empirical falsification approach results in what is largely referred as the optimisation logic; a logic that infuses every contemporary strategic and tactical decision-making process. It leads to what in a system-of-systems framework is called a path dependency.¹⁴ In simple terms, path dependency can be paraphrased as how you define the problem preines the answer.

As seen in 6.3, for any knowledge to be accepted it needs to pass the empirical falsification challenge: One of observer and observation or thinker and thinking or both. In simple terms, the object and the thought are fundamentally a null value (objectivity) unless proven otherwise. The empirical falsification approach embeds within itself aised framework¹⁵ requires a set of choices to be prioritised. A prioritization leads to an optimisation logic that informs objective function.¹⁶ The nature of the objective function is that it defines rationality by postulating a statement artifact of “anything that is not.” By default, anything that is objective is not a function and hence need not be designed. For objective functions define solutions; and a set of grouped solutions (solutionism) feeds back into knowledge. It is a tautological logic within a system-of-systems approach would be called balancing feedback loop – one that favours status quo and maintenance of system equilibrium – as opposed to reinforcing feedback loop – one that favours continuous learning and an agile incorporation of new knowledge and experiences into decision frameworks
