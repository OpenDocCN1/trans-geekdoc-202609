# Methodology for Tampering Detection

As discussed in the previous section, we now have with us a database consisting of original audio recordings and the tampered versions obtained by manipulating the recordings by copy-move, splicing and insertion type forgery. This section gives a framework for audio tampering detection and discusses the methodology adopted for splicing and insertion forgery in this chapter. Similar methodology may be used for detecting copy forgery.

As discussed in the case of environment identification, the conventional procedure to detect forgery is to extract first features from the original and tampered audio recordings and then provide these features as input to machine learning classifier that will help classify the original recording and the tampered versions. Here, for detecting splicing and insertion type forgery, Convolutional Neural Network (CNN) has been used.
