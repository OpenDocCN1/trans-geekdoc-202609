# Convolutional Neural Networks

The CNN contains one or more convolutional layers that are either completely interconnected or pooled. A convolution operation is performed on the input of a layer before the result is passed to the next layer. Due to this, the network is deep with fewer parameters. The input of a CNN is usually an image where the network will assist learning weights and biases to the various characteristics of the image which will help differentiate one image from another. CNNs have the ability to learn the characteristics/features of the input data directly without the need of evaluating-engineered features. The architecture of a CNN consists of Convolutional layer, Batch normalization, Activation Function and Pooling layer. The convolutional layers perform dot product between an array of input data and a two-dimensional array of weights called filter or kernel.

The first layer of the CNN extracts low-level features such as color from the input image. Additional convolutional layers of the network extract high level features such as edges from the input. The pooling layer reduces the size of the convicted feature which helps decrease the computational power required to process the data. Max pooling and Average Pooling are the two types of Pooling where the former returns the maximum value of the portion of image covered by the kernel and the latter returns the average of all values inside the kernel. After the convolution and pooling layers, the output is now fed to a regular neural network for classification using a softmax layer. # Recurrent Neural Networks

RNNs are effective when the data is in the form of a time series sequences. For example, Text-to-speech conversion. The inputs and the outputs of a RNN can be of varying lengths. A recurrent neural network, the output of a layer is saved and fed back to the input. For a particular time step, each node will remember some information from the previous time step. RNNs have feedback loops to take into account the previous output as conventional feed forward networks which do not have any feedback loops. These feedback loops occur at every time step.
