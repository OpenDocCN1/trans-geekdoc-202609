# Forget Gate

The forget gate produces a value between 0 and 1 that is produced with previous cells hidden state $h_{t-1}$ and the current input $x$. The value produced by the forget gate determines how much of the previous cell state $C_{t-1}$ is to be kept.

$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f)$

Where $W_f$ and $U_f$ are both Weights to be learned by the network.

# Input Gate

The input gate helps in calculating the information to be stored in cell state.

$i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \quad C'=tanh(W_c h_{t-1} + U_c x_t + b_c)$

# New Cell State

Using forget and input gates new cell state is calculated.

$C_t = f_t * C_{t-1} + i_t * C'$

# New Hidden State

First, calculate output state that determines what to be output. Using the output gate and cell state the hidden state is determined.

$o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \quad h_t=tanh(C_t) * o_t$.
