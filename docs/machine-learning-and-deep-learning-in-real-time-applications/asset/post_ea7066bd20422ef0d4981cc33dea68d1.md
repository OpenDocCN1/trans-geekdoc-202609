Now, we add two fully connected layers followed by softmax towards the end of the ResNet architecture, which classifies the object into 10 categories instead of 1000. Now, the output of the ResNet layer is taken, flattened and passed through two dense layers (with 128 and 64 neurons respectively). After training the model for only 5 epochs, we achieve an accuracy of 98% which is higher than creating a model from scratch as described in previous section.
