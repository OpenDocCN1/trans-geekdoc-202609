# Introduction to Deep Learning

Deep Learning (DL) (also known as Deep Learning or Hierarchical Learning) is a sub-field of the Machine Learning (ML). Deep Belief Networks, Neural Networks, Repetitive Neural Networks, and Convolutional Neural Networks (CNN) are various models used in computer vision, speech recognition, natural language processing, social network filtering, machine translation, bioinformatics, and medical image analysis. DL is a classification of algorithms that use multiple layers to extract high-level properties from raw input. For example, in image processing, the lower layers can detect or notice the edges, while the higher layer can identify human-meaning elements such as digits, letters, or faces.
