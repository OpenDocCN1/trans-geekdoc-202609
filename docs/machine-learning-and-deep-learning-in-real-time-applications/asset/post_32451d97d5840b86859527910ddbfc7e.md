## Transposed Convolution Layer or Deconvolution Layer

The transposed convolutions usually generated from the aspiration to use a transformation going in the opposite direction of a standard convolution, i.e., from anything that has the shape of the output of some convolution while preserving a connectivity model that is compatible with said convolution. Figure 14 shows the 2D transpose convolution. Figure 15 shows the various step of building a model with transpose convolution through Keras API.

Figure 14. 2D Transpose Convolution

![](img/c5cbbc72cd5e7b9be32079eac36d685c_268_0.png)

```python
from keras.layers import Input, Conv2DTranspose, Conv2D
from keras.models import Model
img_shape = (32,32,1)
inputputimage = Input(shape=(img_shape))
D1 = Conv2DTranspose(32,3,3, strides=(2,2),padding='same',name='TRANS_CONV1')(inputputimage)
C1 = Conv2D(32,1,1,padding='SAME',name='CONV1'(D1)
model = Model(inputimage, C1)
model.summary()
```

## Max Pooling and Average Pooling Layers

A max-pooling layer operates down-sampling by splitting the input into specific rectangular pooling zones and computing the maximized of each zone. An average pooling layer operates down-sampling by dividing the input into rectangular pooling regions and computing the average of each area. Figure 16 shows a comparison between max-pooling vs. pooling. Figure 17 shows the various step to build a model using max-pooling through Keras.

Figure 16. Max pooling vs Average pooling

![](img/c5cbbc72cd5e7b9be32079eac36d685c_270_0.png)

```python
from keras import layers, models
model = models.Sequential()
model.add(layers.Conv2D(32,(5,5),activation='relu',input_shape=(28,28,1)))
model.add(layers.MaxPooling2D(2, 2))
model.add(layers.Conv2D(64, (5, 5), activation='relu'))
model.add(layers.MaxPooling2D(2, 2))
model.summary()
```
