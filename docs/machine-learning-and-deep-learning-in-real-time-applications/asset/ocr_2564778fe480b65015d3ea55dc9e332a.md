The audio signal is framed into frames of 25ms as the audio signal is stationary in the time duration. The frame is taken to 10ms where the frames overlap. For each frame the Discrete Fourier Transform is computed using equation (2)

```
$S(k) = \sum_{n=1}^{N} S(n)h(n)e^{rac{-j2kn}{N}} \quad 1 \leq k \leq K$
```

Where I is number of frames, S(n) is the time domain signal. S(k) is the complex DFT, h(n) is the analysis window which is usually Hamming. The periodogram P(k) of the DFT signal is computed using equation (3).

```
$P(k) = \frac{1}{N}|S(k)|^2$
```

The mel filter bank is a set of 26 triangular filters is now applied to the periodogram. Equation (4) converts the frequency in Hertz to the Mel scale while equation (5) converts Mel scale back to Hertz.

```
$M(f) = 1125\ln\left(1+\frac{f}{700}\right)$
```

```
$M^{-1}(m) = 700\left(\exp\left(\frac{m}{1125}\right)-1\right)$
```

Each filter bank is multiplied by the power spectrum and the coefficients are added to get the filter bank energies. This gives an idea how much energy is present in each filter bank. Now, logarithm applied on these filter bank energies. The final step is to compute the Discrete Cosine Transform of the obtained energies.
