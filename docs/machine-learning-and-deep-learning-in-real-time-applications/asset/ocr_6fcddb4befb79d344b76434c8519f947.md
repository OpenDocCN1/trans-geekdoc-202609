# RESULTS AND DISCUSSIONS

In this chapter, a CNN Model is examined on PyCharm that configures with an interpreter. The image being taken from kaggle contains a total of around 12000 images out of 10000 are infected and 2000 are uninfected. This dataset is processed using astype() which converts the dataset into an appropriate model by dividing the data into training and testing data separately. Using Keras library the input dataset is converted and stored as the warehouse of the input to build up the several layers of the CNN model and keras utils is used to store the various images of the dataset in the form of an array.

Images from the dataset are considered and recognized using the cv2 library. Using the hidden layers, the entire dataset is converted into two subsets of cells and labels. The input images are being normalized and stored in the model. Finally, a sequential CNN model is developed using various layers. Conv2D and MaxPooling2D layers are used with the rel activation function on which the dataset is generated and finally converted into a model. The dense() function is used to define the number of neurons in the input layer as 2. Dropout fusion is used with a value 0.2 in 20% of which images are discarded may be redundant or not useful for the model. Finally, the model is evaluated and generated with accuracy as 1, i.e., dataset converted to a working model accurately and also compiled using optimizer, loss and verbose.
