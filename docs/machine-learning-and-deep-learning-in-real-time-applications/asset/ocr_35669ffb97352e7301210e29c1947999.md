# VGG16 and VGG19

The second place in the ILSVRC 2014 competition was given to the VGGNet, developed by Simonyan and Zisserman. The VGGNet consists of 16 convolutional layers and a very uniform architecture. Similar to the AlexNet, only 3×3 convolutions, but many filters. It was trained in 4 GPUs for 2 to 3 weeks. It is currently one of the preferred choices for extracting features from images. The weight configuration of the VGGNet is publicly available and has been used in many applications and as a base resource extractor (Das, 2018).

The input for ConvNets VGG (Visual Geometry Group), in Figure 8, are RGB images with dimensions 224x224. The pre-processing performed during its implementation in ILSVRC was the subtraction of the RGB value calculated in the training dataset in each. The image is then passed through a set of convolutional layers, where filters with a very small receiver field are used: 3×3 (which is the smallest that allows capturing left/right, up, and down). In one of the configurations, filters of 1×1 were also used, which can be seen as linear transformations of the input channels (followed by non-linearities).
