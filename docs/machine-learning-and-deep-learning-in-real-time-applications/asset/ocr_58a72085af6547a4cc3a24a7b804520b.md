In (Vang, Chen, & Xie, 2018) presents an in-depth learning framework for the multi-class classification of BC images at the International Meeting on Image Analysis and Recognition (ICIAR) 2018 a great challenge in the field of histological images of BACH. The proposed method using Inception V3 to classify the level of patterns. The patch level features are estimated by majority voting as part of a joint fusion, Gradient Enhancement Machine (GBM) and logistic regression to attain an image-level rating. This method can improve class sensitivity to rugged and gentle classes by creating a DPN, which can be used as a feature extractor. The captured features are transferred to the second layer of the complicated forecast by means, logistic regression and the auxiliary vector machine to improve expectations.

In (Sarmiento, Fondón, 2018) provides a CAD tool for the classification task that uses color and textures for classification. The color features are being estimated using k-means clustering. From the perspective of texture, all of these distributions frequent textures occurring on the images. They have two sets of texture descriptors: fractal dimension and local binary patterns for extracting textural features and those features were applied to the different classifiers like SVM with the quadratic kernel which outperforms all classifiers by providing high classification accuracy.

In (Nahid, Mehrabi, & Yuan, 2019) classifies BC images using the novel DNN methods guided by structural and statistical information from images. Specifically, a combination of Long-Short-Term-Memory (LSTM) and LSTMStimer for BC Classification. SoftMax and SVM layers for decision after capturing features that make use of the novel DNN models. The best accuracy value of 91.00% has achieved at 200s in this experiment. In (Adeshina, Aedigba, Adeniyi, & Aibinu, 2018) solved the intra-class problem, classification of breastopathology images into classes of benign or malignant cells. This approach adopted the DNN architecture in conjunction with the ensemble learning method using the TensorFlow framework and ReLU activation function achieved an precise automatic classification of these images. In (Jiang, Chen, Zhang, & Xiao, 2019) a novel CNN has been developed consisting of a convolutional layer, a multi Se-ResNet module, and a connected layer. The problem of cell overlap and asymmetric color distribution in pathological images from various stages needs to be addressed.

In (Bardou, Zhang, & Ahmad, 2018) automatic classification of BC histology images as benign and malignant sub-classes. Experiments with augmentation techniques to improve the accuracy of the convoluted neural network with CNN. The achieved accuracy between 96.15% and 98.33% for binary classification and 83.31% and 88.23% for multi-class classification. In (Cuiri et al., 2019) implemented an automated BC detection method based on hybrid features for pathological images. Due to the weak interaction between the H & E channels, conformation of features for the channels can be captured separately, which makes them more representative results. From multiple perspectives, morphological features, spatial structural features and texture characteristics are captured and combined. Using SVM, classification can be better generalized, the pathological picture is classified as benign or malignant on the basis of mitigation method for feature selection.
