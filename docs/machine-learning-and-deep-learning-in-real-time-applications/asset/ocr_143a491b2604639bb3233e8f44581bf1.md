# ## Convolution 2D-layer

The 2-D convolutional layer applied as sliding convolutional filters to the input. The layer convolves the input by moving the filters along the input vertically and horizontally and computing the dot product of the weights and the input then adding a bias term. Figure 11 build a model with Convolution 2D through Keras API.

from keras.models import Conv2D, Convolution2D, Activation, Input
from keras.models import Model

img_shape = (32,32,1)
inputting = Input(shape=img_shape)
C1 = Conv2D(64,(9,9),padding='SAME',name='CONVOL1')(inputimg)
A1 = Activation('relu',name='act1')(C1)
C2 = Conv2D(32,(3,3),padding='SAME',name='CONVOL2')(A1)
A2 = Activation('relu',name='act2')(C2)
model = Model(inputimg, A2)
opt = optimizers.Adam(lr=0.0003)
model.compile(optimizer=opt,loss='mean_squared_error')
model.summary()
