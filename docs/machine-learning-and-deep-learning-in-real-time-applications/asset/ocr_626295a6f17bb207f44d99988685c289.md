# Deep Learning With PyTorch

Every tensor object has attributes: data, grad, grad_fn, requires_grad, is_leaf.
Data attribute store the data of tensor, requires_grad specifies if the gradient is to be calculated in the backward graph, grad_fn stores the backward propagation function, grad stores the gradient value passed in backpropagation, is_leaf specifies if a node in the graph is an intermediate node.

In figure 6, both x.requires_grad and y.requires_grad are set to False. Therefore out.requires_grad is False too. Since requires_grad is False in all tensors, no backward graph is created, and grad and grad_fn are None.

If even one of the tensors_requires_grad attributes is set to True, autograd creates a backward graph in the background and starts tracking derivatives in backward graph.

x and y are initialized as scalar tensors with x.requires_grad=True as seen in table 3:

Table 3. code to initiate attributes: data, x.requires_grad

```
x = torch.tensor(3.0, requires_grad=True)
y = torch.tensor(4.0)
```
