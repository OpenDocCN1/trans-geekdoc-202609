Note: Splitting the Dataset into Train, Validation and Test set

We can alternatively solve the given problem using validation set. The downloaded dataset comprises train and test set having 50,000 and 10,000 images respectively. The train set can be divided into train (75%) and validation set (25%) leaving test aside for final assessment of the model. A sample of data chosen for fitting the model is known as train and a sample of data selected from train for analyzing the performance of the model during parameter tuning is known as validation set An unbiased evaluation of a model (already trained on train images) is offered by validation set using this approach. Test set is separate from training and validation set, offering final assessment of complete model once the model is entirely trained.
