# Addition of Three Keras Layers

The addition of Keras Layers takes as an input value of tensors, and values of all tensors have the same shape and size and return a single value tensor. Figure 22 shows the schematically representation of the addition of three dense layers. Figure 23 shows the addition of three layers builds by Keras API.

```
import keras
input1 = keras.layers.Input(shape=(32,))
z1 = keras.layers.Dense(8, activation='relu')(input1)
input2 = keras.layers.Input(shape=(32,))
z2 = keras.layers.Dense(8, activation='relu')(input2)
input3 = keras.layers.Input(shape=(32,))
z3 = keras.layers.Dense(8, activation='relu')(input3)
added = keras.layers.Add()([z1, z2, z3])
out = keras.layers.Dense(4)(added)
model = keras.models.Model(inputs=[input1, input2, input3], outputs=out)
model.summary()
```

# Subtraction of Two Keras Layers

The subtraction function of Keras tensor takes as an input a list of tensors with size 2 and has both the shape and provides a single tensor output with the same shape. The command for this purpose is keras.layers.Subtract(). Figure 24 shows the subtraction of two layers. Figure 25 shows the subtraction of two layers by Keras API.

Figure 24. Subtraction of two layers

![](img/c5cbbc72cd5e7b9be32079eac36d685c_278_0.png)

# An Introduction to Deep Convolutional Neural Networks With Keras

```python
import keras
input1 = keras.layers.Input(shape=(32,))
z1 = keras.layers.Dense(8, activation='relu')(input1)
input2 = keras.layers.Input(shape=(32,))
z2 = keras.layers.Dense(8, activation='relu')(input2)
subtracted = keras.layers.Subtract()([z1, z2])
out = keras.layers.Dense(4)(subtracted)
model = keras.models.Model(inputs=[input1, input2], outputs=out)
model.summary()
```
