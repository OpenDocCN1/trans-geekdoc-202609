## SGD

In the backpropagation algorithm, the gradient must be calculated in many iterations to adjust the weights of the neural network. When the training set is very large, in general, calculating the gradient for the whole set is impractical in terms of required computational resources. Considering this issue, the stochastic descending gradient is calculated with some examples iteratively (instead of the entire base). Another advantage of the SGD is the ability to reduce the occurrence of local minima in high dimensional error spaces. Batches are used because they reduce variance in learning and therefore have a more stable convergence, provided that the distribution of the examples is random. With the high computational power of GPU, min-ibatches can be processed quickly, since the operation is easily parallelized (Nascimento, 2016). Equation (8) shows the step of updating the SGD.

```
$$\theta = \theta - \alpha * \sum_{k=1}^{m} \nabla_{\theta}(\theta; x^{(k)}, y^{(k)})$$
```

where $\theta$ is the parameter to update, $\alpha$ is the learning rate, and $m$ is the size of the batch.

## Data Augmentation

It is fact that the larger and diverse the amount of data a machine learning algorithm has access to, the more effective it will tend to.

Data augmentation is presented as a way to reduce overfitting in ML models, where data diversity is increased by using information that exists only in the available dataset.
A common practice to increase a set of images is to perform transformations at the level of their color and geometry, such as reflection, cropping, color palette changes, and image translation. Traditional transformation techniques (Figure 4) consist of combinations of related transformations to manipulate training data. For each image, a "duplicate" image is generated that is shifted, enlarged/reduced, rotated, inverted, distorted or shaded with a tint. The image and its duplicate are then supplied to the neural network (Perez & Wang, 2017).

## Fine-Tuning

Fine-tuning is based on the concept of transfer learning. It begins by training a network to learn characteristics for a broad domain with a classification function aimed at minimizing the error in that domain, the classification function is replaced, and the network is optimized to minimize the error in another more specific domain. Under this configuration, the characteristics and parameters of the broad domain network are transferred to a more specific one.

Assume a unique network in the final classification function is the softmax (a couple of dense layers), which calculates the probability in 1000 classes on the ImageNet dataset. For the fine-tuning procedure, this classifier component is removed, and another is initialized with random values. The final classifier is then trained from scratch using the backpropagation algorithm with information relative to, for example, leukocyte classification.

In order to start the fine-tuning, it is necessary to define the learning rates of each layer appropriately. The classification layer requires a high learning rate due to its reinitialization. The rest of the layers requires relatively small (or null) learning rates since it is intended to preserve the previous network parameters to transfer the knowledge to the new network (Reyes, Juan, & Camargo, 2015).

One of the major applications in applying CNNs to cell images lies in the scarcity of labeled data. In this sense, the reuse of trained models in different tasks has already been demonstrated. However, the ability to transfer resources depends on the distance between the base task and the destination. Boosting a network with pre-trained resources improves its generalization capability (Kensert, Harrison, & Spujith, 2018).

## Convolutional Neural Networks

CNNs are useful in a large number of applications, especially those related to images, such as classification, segmentation, and object detection (Wu, 2017).

Let's say we have an image of a leukocyte in PNG format with size 480x480. The representative matrix will be 480x480x3. Each of these numbers carries a value from 0 to 255 that describes the pixel intensity at that point. The idea is to provide the computer with this array of numbers. With the output, one obtains the probability of the image belonging to a specific class (for example, 0.08 for neutrophil, 0.15 for monocyte, 0.05 for basal). Similar to humans, the computer is able to perform image classification on low-level features such as edges and curves, constructing more abstract concepts through a series of convolutional layers. This is an overview of what a CNN does (Deshpande, 2016).

## First Layer: Convolution

The first layer of CNN is always a convolutional layer. In this type of network, a filter is used, which is in an practice of any numbers (weights or parameters) with the same depth of the input image, for example, 5x5x3 for 32x32x3 (RGB image).

The filter will slide, or convolve, around the input image, multiplying the values in the filter by the pixel values of the original image. A single representative number of each position of the filter is thus obtained throughout the convolution process, giving rise to a new matrix 28x28, thus being smaller than the original matrix. If two 5x5x3 filters are used instead of one, the output volume will be 28×28×2. By using more filters, one can better preserve the spatial dimensions/directions. Each of these filters can be considered identifying features as borders, straight lines, simple colors and curves.

The output of the convolution layer is an activation map. The higher the value obtained, the greater probability. The more filters you use, the greater the depth of the activation map, and consequently, more information about the input will exist.

For tensors of order 3, the convolution operation is done in a manner similar to that used for order 2. The output of the $i^{th}$ is a tensor of order 3 with size $H*W*D$, the convolution kernel will also be 3-order tensor with size $H*W*D$. When the kernel is placed on top of the input at the spatial location (0,0,0), the products of the corresponding elements are calculated on all the channels $D$, and to the products of $H*W$ to obtain the convolution result in this spatial location (Wu, 2017). There are other ways of treating tensors (channels), which is the most common.

## Pooling

Pooling is a data reduction. In the general, the maximum or mean of a small region of the input is calculated. The main advantage of pooling is speed increase in the network due to interlayer downsampling, reducing the amount of data to be processed and making "curse of dimensionality" less intense (Nascimento, 2016).

The purpose of pooling layers is also to achieve spatial invariance by reducing the resolution of feature maps. Each map corresponds to a characteristic map of the previous layer. Its units combine the input of small fragments(patches). These pooling windows can be of arbitrary size. The max-pooling consists in calculating the highest value in a patch, normally, of four elements. Those four elements are replaced by that value. The result is a lower-resolution feature map (Scherer, Müller, & Bundy, 2010).

## Deeper Layers of the CNN

CNN are representatives of the multi-stage Hubel-Wiesel architecture, which extract local characteristics at high resolution and combine successively into more complex features at lower resolutions.
