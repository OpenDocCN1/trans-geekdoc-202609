A sigmoid neuron (Figure 4) can have inputs ranging from 0 to 1, for instance 0.748 is a valid input for a sigmoid neuron. The output of the sigmoid neuron is $\sigma(w^Tx+b)$ unlike perceptron the output was either 0 or 1 when some weights $w_i, w_j, \dots$ are assigned corresponding to each input along an overall bias 'b'. The sigmoid function is defined as:

```
$\sigma(z) = \frac{1}{1+e^{-z}} \eqno(3)$
```

OR

```
$\sigma(z) = \frac{1}{1+\exp(-\sum w_ix_i-b)} \eqno(4)$
```

The behavior of a sigmoid neuron is in close association with a perceptron. The similarity between a perceptron and sigmoid model can be understood by taking a large positive number of $z=wTx+b$. If $z$ is a large positive number then the output from sigmoid function is approximately 1 as $e^{-\infty}$. Similarly, for a very large negative value of $z$, the sigmoid output becomes approximately 0 as $e^{\infty}$. It is only when is of modest size there is no deviation from the perceptron model.
