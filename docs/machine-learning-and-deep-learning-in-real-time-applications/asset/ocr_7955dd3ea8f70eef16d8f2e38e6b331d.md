# Jupyter Notebook

Jupyter Notebook is a collaborative web based programming background aimed to generate Jupyter notebook structure. The term "notebook" may refer colloquially to a number of different units, primarily the Jupyter web based presentation, Jupyter based Python client servers, or Jupyter file format depending on background. A Jupyter Notebook is a JSON database which follows a typed schema and includes a well-ordered list of input and output cells that may have code, text (by Markdown), maths, graphs, and documents, mainly ending with ".ipynb" extension. Jupyter file will be convert with the "Download As" interface, the nbconvert library or the "jupyter nbconvert" share CMD interface to a number of standard output formats (PDF,ReStructuredText,Markdown, Python, HTML,). NbViewer provides the nbconvert library as a tool that will take an URL to any public JN, convert to HTML on the NB file, and show to the user, to simplify the visualization of Jupyter notebook objects on the internet.
