In figure 4, the Blue arrows are called error signals, because they are derivatives of error, e with respect to other values in the graph.

The derivative of error calculated with respect to other values is done through chain rule.

Figure 5 shows how $\frac{\partial e}{\partial \omega}$ is calculated:

```
$$\frac{\partial e}{\partial \omega} = \frac{\partial e}{\partial a} * \frac{\partial a}{\partial z} * \frac{\partial z}{\partial \omega}$$ (3)$
```
