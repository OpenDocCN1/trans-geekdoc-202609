The 4-connectivity method helps to detect the boundary of the extracted blocks. The pixels surrounding the extracted block form the boundary of the respective block. Thus, the white pixels that are surrounding the extracted block are the outside boundary. Edge detection techniques are unable to obtain boundary detection as it is in an open contour if applied on a one-pixel width line. The perimeter of the border may contain some pixels which are not present on the edge. Connectivity helps to join those pixels and detect the proper boundary of the blocks extracted.
