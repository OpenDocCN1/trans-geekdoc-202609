# Deep Belief Network (DBN)

Generally, DBN includes multiple layers, and each layer has visible neurons, which establish the input layer, and hidden neurons output the output layer. Further, there presents a deep connection with hidden and input neurons; but there was no connection among hidden neurons and no connections are present in the visible neurons. The connection among visible as hidden neurons is symmetric and exclusive. This corresponding neuron model defines an accurate output for the input.
