+   4. Copy-move forgery: Copy-move forgery, a part of an audio recording is copied and pasted in the same recording at some other location. Here, source and destination audio is same as against splicing where source and destination are two different audio files.

# Database Creation

As a standard database consisting of the original and the tampered version is not available, a synthetic database is created with audio recordings and their respective tampered versions. The above types of forgery attacks are applied on the original audio recordings to obtain the tampered versions. Tampering has to be done in such a manner that there should be no obvious anomaly which can provide obvious clues of forgery. From a forger's point of view, the audio waveform should flow naturally and there should be no abrupt changes of signal levels, background noise levels or multiple environments.

The original recordings are taken from Free Spoken Digit Database (Retrieved from https://github.com/Jakobowski/spoken-digit-dataset). The database consists of recordings from 4 different speakers with 50 audio files from each speaker. There are 2000 total recordings of spoken digits recorded at 8 kHz. For creating move forged audio, initially digits from 'zero' to 'nine' are concatenated together in a single audio file with some silence between digits. In this way, for each speaker audio files are created which contain the utterances of digits 'zero' to 'nine' with the digits in a random order; different for each audio file. Now, one digit utterance is copied from a particular location and moved to another location. This is copy move forgery. Figure 6 shows an example of a copy-move forged audio recording.
