The 4-connectivity method helps to detect the boundary of the extracted blocks. The pixels surrounding the extracted block form the boundary of the respective block. Edge detection techniques are unable to obtain boundary as it is in an open contour if applied on one-pixel width line. # CONNECTED COMPONENT, AREA COMPUTATION, AND TEXT SEPARATION

# Key Features of Implemented Method

Essential features of this method are:

- a. To find the connected components of boundary extracted part of the image.
- b. To calculate the area of closed loop after boundary detection.
- c. To separate/segment the text area after finding closed area.

# Description of the Method

The connected component method helps to find boxes in distinct regions of connected black pixels in the document image and computes the area of the box. This area is uniform and helps to fill zeros in a smaller space. ANDing the original image and the image filled by zeros in the image with entire text separated from original image.

```
Algorithm 4. Text Separation
Input: Perimeter/Boundary detected of blocks in a document image.
Output: Text extracted image.
Begin
1. Initialize the perimeter detected image for text separation.
2. Find the connected component in the image as:
   a) Scan the pixels and assign a label to the pixels which are non-zero and record these equivalences in union-find table.
   b) Use the union-find algorithm to resolve the equivalence classes.
   c) Based on resolved equivalence classes, relabel the pixels.
3. Compare the area of closed loop which has uniform stripes formed by run-length smearing, with open loop area.
4. Fill zeros in smaller space.
5. AND the image from step 4 with the original image to get text output image.
End
```
