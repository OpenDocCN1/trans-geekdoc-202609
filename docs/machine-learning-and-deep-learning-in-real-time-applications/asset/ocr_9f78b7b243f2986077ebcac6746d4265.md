# Obtaining Deep Learning Models for Automatic Classification of Leukocytes

# Fine-Tuning

Fine-tuning is based on the concept of transfer learning. It begins by training a network to learn characteristics for a broad domain with a classification function aimed at minimizing the error in that domain, the classification function is replaced, and the network is optimized to minimize the error in another more specific domain. Under this configuration, the characteristics and parameters of the broad domain network are transferred to a more specific one.

Assume a unique network in the final classification function is the softmax (a couple of dense layers), which calculates the probability in 1000 classes on the ImageNet dataset. For the fine-tuning procedure, this classifier component is removed, and another is initialized with random values. The final classifier is then trained from scratch using the backpropagation algorithm with information relative to, for example, leukocyte classification.

In order to start the fine-tuning, it is necessary to define the learning rates of each layer appropriately. The classification layer requires a high learning rate due to its reinitialization. The rest of the layers requires relatively small (or null) learning rates since it is intended to preserve the previous network parameters to transfer the knowledge to the new network (Reyes, Juan, & Camargo, 2015).

One of the major applications in applying CNNs to cell images lies in the scarcity of labeled data. In this sense, the reuse of trained models in different tasks has already been demonstrated. However, the ability to transfer resources depends on the distance between the base task and the destination. Boosting a network with pre-trained resources improves its generalization capability (Kensert, Harrison, & Spujith, 2018).

# Convolutional Neural Networks

CNNs are useful in a large number of applications, especially those related to images, such as classification, segmentation, and object detection (Wu, 2017).

Let's say we have an image of a leukocyte in PNG format with size 480x480. The representative matrix will be 480x480x3. Each of these numbers carries a value from 0 to 255 that describes the pixel intensity at that point. The idea is to provide the computer with this array of numbers. With the output, one obtains the probability of the image belonging to a specific class (for example, 0.08 for neutrophil, 0.15 for monocyte, 0.05 for basal). Similar to humans, the computer is able to perform image classification on low-level features such as edges and curves, constructing more abstract concepts through a series of convolutional layers. This is an overview of what a CNN does (Deshpande, 2016).

# First Layer: Convolution

The filter will slide, or convolve, around the input image, multiplying the values in the filter by the pixel values of the original image.
