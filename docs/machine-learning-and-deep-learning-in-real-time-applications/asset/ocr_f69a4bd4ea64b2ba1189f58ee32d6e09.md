# KEY TERMS AND DEFINITIONS

**Accuracy** is a percentage of correctly classified normal as abnormal samples of total samples. It is given by the ratio of True Positive and True Negative samples to the total number of samples under test. Accuracy = TP+TN/TP+FP+FN.

**F1 Score:** F1 score is the weighted average of precision and recall. Therefore, this score takes both false positives and false negatives into account. Intuitively it is not easy to understand as accuracy, but F1 is usually more than accuracy, especially if you have an uneven class distribution. Accuracy works best if false positives and false negatives have similar cost. The value of false positives and false negatives are very different, it's better to look at both Precision and Recall. F1 Score = 2*(Recall Precision) / (Recall + Precision).

**False Negative (FN):** is the number of abnormal samples detected as normal by the classifier.
