# TENSOR

Tensor is a generalization of vectors and matrices of potentially higher dimensions. It is the standard
way of representing data in deep learning. In simple terms, a tensor is a matrix or an array of data with
different dimensions and ranks that are supplied as input to the neural network. Figures 4 and 5 represent
different dimensions and ranks of tensors respectively.

Rank of tensors: It is defined as a quantity of dimensions in which the tensors live.

```
# Rank 0 is equivalent to scalar
# Rank 1 is equivalent to vector
```
