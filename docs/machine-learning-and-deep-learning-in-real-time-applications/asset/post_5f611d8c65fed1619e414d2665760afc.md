# CONCLUSION

A Deep Learning model for the Performance of Students in Educational Information System is implemented. Work started with motivation to implement a hybrid model with better accuracy in Educational Domain and extended to optimised model. ML and DL are fields of Artificial Intelligence where algorithms learn by themselves. These algorithms can be applied in many emerging areas where data size is increased. The main aim of DL is to increase accuracy. Before devising the hybrid model, ML algorithms are applied to the data collected from educational domain. ML algorithms like SVM and pure DBN are applied on the collected data. Additional evaluation measures are used to test the algorithms. Balanced evaluation measure like MCC for ML domain is used with F1-score. The results show that pure DL and advanced ML algorithms are giving similar accuracy. Hence a hybrid model for performance prediction of students to get better accuracy is implemented. Optimization is the technique to improve the accuracy of the model by tuning many popular metaheuristic techniques Cuckoo Search is chosen because of its advantages. A new students’ performance hybrid model is proposed and is improved using Cuckoo Search with Levy optimization technique. The proposed model uses a new hybridized classifier to predict the performance, which is trained by SVM, and as the tuning is not inappropriate, the result classes are considered as features for DBN, as it has classified the performance. The performance of prediction model is further improved by optimizing the DBN. From the results, it was evident that the results of the optimized hybrid model are better than traditional ML and PU algorithms.
