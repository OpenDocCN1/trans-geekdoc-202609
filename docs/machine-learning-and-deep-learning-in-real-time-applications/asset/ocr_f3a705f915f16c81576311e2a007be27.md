# Neural Network Function

The human visual system can effortlessly identify the patterns in a scene because of the presence of series of visual cortex v₁, v��₂, in each hemisphere of our brain. Each visual cortex consists of billions of 140 million neurons capable of executing complex image processing tasks. The human brain itself is a supercomputer that has evolved in hundreds of millions of years and tremendously adapted to understand the visual world. The intricacy of visual pattern recognition is perceptible when we write a computer program to identify these patterns. Identifying different shapes in a pattern (For example “9”) such as a vertical stroke in the bottom right and a loop at the top is quite difficult to express a labyrinth of exceptions, caveats and special cases. However, the approach of neural network in solving this problem is different from conventional approaches. It takes a large number of input of such handwritten digits as training samples (Figure 2) and creates a system to automatically derive rules for identifying the digits by learning from those training samples.

Furthermore, the accuracy of such models can be improved by introducing more samples (Goodfellow, Bengio and Courville, 2016). The key concept behind developing a neural network is a “perceptron”. A perceptron is inspired by the human nervous system, where each network consists of various interconnected neurons that communicates with each other. The concept of perceptron was introduced in 1950 by Frank Rosenblatt (Rosenblatt, 1958). A perceptron takes various binary inputs, such as x1, x2, and x3 and produce a single binary output as shown in Figure 3.

Rosenblatt introduced the concept of weights w₁, w₂, and w₃ that represents importance of the respective inputs to the outputs and developed a mathematical rule to compute the output of the perceptron. If the weighted sum ∑w_ᵢx_ᵢ is less than or equals to a threshold value, the output generated is 0 otherwise the output is 1.
