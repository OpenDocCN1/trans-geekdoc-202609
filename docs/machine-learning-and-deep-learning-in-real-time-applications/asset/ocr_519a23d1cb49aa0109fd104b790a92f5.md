# Xception

The Xception was proposed by the creator of Keras, François Chollet, and is an extension of the Inception architecture that replaces the Inception module with separable convolutions by depth, Figure 10.

# ResNet50

In ILSVRC the Residual Neural Network (ResNet), by Kaiming He et al., presented a new architecture with non-consecutive connections (skipped connections) and the strong use of batch normalization. Indexed connections are also known as blocked units or gated recurrent units and have a strong resemblance to recently applied success factors in RNNs. With a N with 52 layers, although with complexity inferior to a VGGNet, ResNet achieves a 3.57% Top-5 error rate, surpassing the human performance level (He, et al., 2015).

The authors of ResNet were inspired by VGG networks. The convolution layers used have mainly 3x3 filters and follow two simple rules: (i) for the same map size of features, the layers have the same number of filters and (ii) if the temporal map size has reduced by half, the number of filters doubles in order to preserve the temporal complexity per layer. Downsampling is performed directly by the 2-pixel convolutional layers, and the network terminates with a global mean pooling fully-connected with softmax.
