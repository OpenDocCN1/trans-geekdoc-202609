# # Deep Learning in Engineering Education

Table 1. Deep Learning Application area

| Application Area | Deep Learning Algorithm | Key Endings |
|---|---|--|\| Malware Detection | DBN (Davidt & Netanyahu, 2015,July) | - Dropout method was used while training the network.<br>- Various layers were used to detect malware signatures.<br>- The network was trained using a GPU to detect 30 signatures. |
| Intrusion Detection | DBN (Gao, Gao, & Wang, 2014,November) | - DBN has proved more accuracy than SVM and Artificial Neural Networks.<br>- DBN with 4 configurations was used. The performance of shallow DBN is as SVM and ANN.<br>- DBN with 2 more layers gave better output. The DBN is used for classification. |
| Spam Filtering | DBN (Toortis & Likas, 2007,October) | - DBN for Spam Filtering.<br>- The performance was compared with SVM and DBN was found more accurate. |
| Image Processing | Deep Convolutional DBN (Nguyen, Foster, & Sridharan, 2015,September) | - Convolutional DBN used for classification of images.<br>- Accuracy is improved and training time for the deep network reduced. |
| Image Processing | DBN & DAE (Vincent, Larhelle, Bengio, & Manchoz, 2010) | - DBN and DAE (Denoising AutoEncoder) used for analysing the images.<br>- Experimental results shows that DAE was helpful for learning of higher representations.<br>- DBN and DAE gave better accuracy for image classification combined with SVM and GBM. |
| Classification | Deep SVM (Kim, Minho, & Shen, 2015) | - Experimental a new model created by combining Autoencoder,<br>- The input was fed to SVM and then GBM forming one layer.<br>- Thus deep layers were constructed for feature extraction and then Na Bayes used for classification. |
| Image Processing | SVR LR (Kawata & Shibasaki, 2015,July) | - Used SVM (Support Vector Regression) with Linear Regression Units for feature extraction.<br>- This paper described crop yields from remotely tested data using deep learning and machine learning algorithms.<br>- Experimentation was using Cafe tool. |
| Regression Analysis | Deep SVM (M. A. Wiering Milleijer, Schomaer, 2016) | - Used SVM for regression analysis. The deep model was constructed by stacking layers of SVM.<br>- Initial layers were used for extracting the important features and final layer was used for classification. |
| Finance | Deep SVM with Fuzzy (Deng, Qian, Bao, & Dai, 2017) | - Used Fuzzy Deep Neural Network for the classification of financial data.<br>- The deep network used a high-level representation of data. This representation was generated by the fuzzy model and the neural network model. |
| Education | SAE (Guo, Zhang, guang, & Yang, 2015,July) | - Used Sparse Autoencoders for classification and prediction.<br>- The network was trained using a backpropagation algorithm.<br>- The experimentation was done on data from 9th-grade high school children.<br>- The experimentation was carried out on GPU and CPU.<br>- The accuracy of DL algorithm was higher than SVM and Naive Bayes. |
| Music Classification | Deep Feed forward network and LRU (Rajanana, Aryafar, Shokoufandeh, & Pucha, 2015) | - Rectilinear Unit (ReLU) was used as an activation function in a deep neural network with 2 layers.<br>- The accuracy of the classifier is significantly improved. |
