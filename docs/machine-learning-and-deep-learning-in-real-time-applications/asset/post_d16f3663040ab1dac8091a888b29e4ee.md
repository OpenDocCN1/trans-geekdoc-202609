### Dimensionality reduction using Principal Component Analysis (PCA)

In the proposed prediction model, PCA (Mackiewicz & Ratajczak, 1993) is used for reducing the vast data. There are many reasons why one wishes to reduce the dimensionality of input data. Many times the complexity of the model depends on the number of dimensions in the data as well as the size of the data sample. When the dimensions are reduced then the cost related to extracting the not required dimensions reduced. Many times the models are robust when the dataset is small and gives accurate results. Also, data with few dimensions can be visualized properly to reduce the outliers.

Consider a p-dimensional random variable $U$ with $\Sigma$ and let $\lambda_1..\lambda_p$ be the eigenvalues. Consider that $P_1...P_p$ are the corresponding Eigenvectors of $\Sigma$. One can write:

`$\Sigma = \lambda_1 P_1 P_1^T + ... + \lambda_p P_p P_p^T$`

`$\Sigma = P_1 P_1^T + ... + P_p P_p^T$`

`$P_i^T \Sigma P_i = \lambda_i, P_i^T \Sigma P_j = 0. i \neq j$`

The transformed random variables can be represented as:

`$Y_i = P_i U, i=1...P$`

Here Y is the new random variable vector and P is the orthogonal matrix then Y can be obtained from U by the orthogonal transformation $Y=PU$. Here this random variable vector $Y_i$ is called as the $i^{th}$ principal component of $U$.
Only the basic steps of PCA are followed here. These basic steps of PCA are given in Algorithm 1.

## Deep Belief Network (DBN)

Generally, DBN includes multiple layers, and each layer has visible neurons, which establish the input layer, and hidden neurons output the output layer. Further, there presents a deep connection with hidden and input neurons; but there was no connection among hidden neurons and no connections are present in the visible neurons. The connection among visible as hidden neurons is symmetric and exclusive. This corresponding neuron model defines an accurate output for the input.

Since the stochastic neurons' output in Boltzmann network is probabilistic, Eq. (5) denotes the output and Eq. (6) specifies the behavior in sigmoid-shaped function, where $r^{\rho}$ indicates the pseudo-temperature. The deterministic model of the stochastic approach is in Eq. (7).

`$P_{\rho}(\zeta) = \frac{\zeta}{1+e^{\zeta}}$`

`$\lim_{r^{\rho}\to\infty} \bar{P}(\zeta) = \lim_{r^{\rho}\to\infty} \frac{\zeta}{1+e^{\zeta}} = \begin{cases} 0 & \text{for } \zeta < 0 \\ 2 & \text{for } \zeta = 0 \\ 1 & \text{for } \zeta > 0 \end{cases}$`

$\Delta EN(bi_a) = W_{aj} + \theta_a$

The progression of energy in terms of the joint composition of visible and hidden neurons $(x,y)$ defines the probability of $y$ given $x$ as $P(y|x) = \frac{e^{-E(x,y)}}{\sum_{y'} e^{-E(x,y')}}$. The energy function $E(x,y)$ is defined as $E(x,y) = -\sum_{i,j} w_{ij}x_iy_j - \sum_i a_ix_i - \sum_j b_jy_j$, where $w_{ij}$ are the weights between visible neurons $i$ and hidden neurons $j$, $a_i$ are the biases of visible neurons, and $b_j$ are the biases of hidden neurons.

The partition function $Z(x)$ is defined as $Z(x) = \sum_{y} e^{-E(x,y)}$. The probability of $y$ given $x$ is then $P(y|x) = \frac{e^{-E(x,y)}}{Z(x)}$.

The probability of $x$ given $y$ is $P(x|y) = \frac{e^{-E(x,y)}}{Z(y)}$, where $Z(y) = \sum_{x} e^{-E(x,y)}$.

The joint probability of $x$ and $y$ is $P(x,y) = \frac{e^{-E(x,y)}}{Z}$, where $Z = \sum_{x,y} e^{-E(x,y)}$.

The gradient of the log-likelihood with respect to the weights $w_{ij}$ is $\frac{\partial \ln Z}{\partial w_{ij}} = \langle x_iy_j \rangle - \langle x_i \rangle \langle y_j \rangle$, where $\langle \cdot \rangle$ denotes the expectation value.

The gradient of the log-likelihood with respect to the biases $a_i$ is $\frac{\partial \ln Z}{\partial a_i} = \langle x_i \rangle - 1$.

The gradient of the log-likelihood with respect to the biases $b_j$ is $\frac{\partial \ln Z}{\partial b_j} = \langle y_j \rangle - 1$.

The training of the RBM is performed using gradient descent to maximize the log-likelihood. The weights are updated as follows $w_{ij} \leftarrow w_{ij} + \eta (\langle x_iy_j \rangle - \langle x_i \rangle \langle y_j \rangle)$, where $\eta$ is the learning rate. The biases are updated as $a_i \leftarrow a_i + \eta (\langle x_i \rangle - 1)$ and $b_j \leftarrow b_j + \eta (\langle y_j \rangle - 1)$.

The RBM is then used as a building block for the DBN. Each RBM is trained greedily to extract features from the data. The input to the first RBM is the input data, and the hidden layer of the first RBM becomes the input to the second RBM, and so on until all the RBMs are trained. After the RBMs are trained, the entire DBN is fine-tuned using backpropagation.
