# Extraction of Room Impulse Response

There are various methods in literature which can be employed to measure the RIR like Time-Stretched pulses, inverse Repeated Sequences (IRS [sic: IRS]), Maximum Length Sequence (MLS) and Sine sweep (Stan, Embrechts, & Archambeau, 2002). The authors have adopted the sine sweep methodology as it gives a high Signal-to-noise ratio compared to other methods of measurement of RIR. The steps involved with this method are shown in Figure 4 (Stan, Embrechts, & Archambeau, 2002).

```
x(t) = \sin\left[-\frac{\omega_T}{\omega_s}\ln\left(\frac{\omega_s}{\omega_t}\right)\right]
```

where $\omega_s$ is the angular start frequency of the sweep which is considered to be 20Hz and $\omega_t$ is the angular stop frequency to 20 KHz. $T$ is the duration of the sine sweep.

This generated sine sweep is now played and recorded in an environment. Therefore, reverberation characteristics of the recorded environment are captured in the recorded signal. If the signal recorded at the microphone is represented by $y(t)$ and the system's(environment's) response is $h(t)$, let $f(t)$ be an inverse filter which is just a time reversal of the test signal. The impulse response is obtained by the convolution of $y(t)$ and $f(t)$.

For the above experiment, sweep signals are synthetically generated as discussed in the previous section and convolved with the already available impulse responses from the Multichannel Acoustic Reverberation Database at York (MARDY) database. This gives an effect that the sweep signals are recorded in that particular environment.

From the obtained impulse response, features are extracted and applied to classifiers for classification.

# Feature Extraction

This section discusses features that will be used for the classification of the acoustic environment. The Popular Mel Cepstral Coefficients (MFCC) and the Reverberation time features are two sets of features which are used.

# 1. MFCCs

MFCCs are the most popular features used in many speech and audio processing applications, mainly in Automatic Speech and Speaker recognition systems. In this experiment, these features are extracted from the obtained RIR. The MFCCs take into consideration the human auditory response and therefore

the recognition rate with MFCCs is better than other features. The steps to compute the MFCC features can be summarized as in Figure 5.

The audio signal is framed into frames of 25ms as the audio signal is stationary in the time duration. The frame is taken to 10ms where the frames overlap. For each frame the Discrete Fourier Transform is computed using equation (2)

```
$S(k) = \sum_{n=1}^{N} S(n)h(n)e^{\frac{-j2kn}{N}} \quad 1 \leq k \leq K$
```

Where I is number of frames, S(n) is the time domain signal. S(k) is the complex DFT, h(n) is the analysis window which is usually Hamming. The periodogram P(k) of the DFT signal is computed using equation (3).

```
$P(k) = \frac{1}{N}|S(k)|^2$
```

The mel filter bank is a set of 26 triangular filters is now applied to the periodogram. Equation (4) converts the frequency in Hertz to the Mel scale while equation (5) converts Mel scale back to Hertz.

```
$M(f) = 1125\ln\left(1+\frac{f}{700}\right)$
```

```
$M^{-1}(m) = 700\left(\exp\left(\frac{m}{1125}\right)-1\right)$
```

Each filter bank is multiplied by the power spectrum and the coefficients are added to get the filter bank energies. This gives an idea how much energy is present in each filter bank. Now, logarithm applied on these filter bank energies. The final step is to compute the Discrete Cosine Transform of the obtained energies.

If 26 filter banks are used then we have 26 coefficients. Out of these 26 coefficients, only 13 coefficients are chosen which are the final MFCC feature vectors.

# Reverberation Time Features

The length of time it takes for decay from its original level is called reverberation time. This reverberation time is an important parameter extracted from the RIR which characterizes a particular environment. Different reverberation times like RT60, RT30 and RT 20 are defined depending upon how much sound energy the source stops emitting the signal. RT60 is the duration required for the sound energy to decay by 60dB after the source stops. Similarly, for the time to decay from -5dB to -25dB and -5dB to -35 dB in RT20 respectively. Apart from these, there are more parameters than extracted from the RIR: The Early Decay Time (EDT) and the Direct to Reverberation Ratio (DRR). EDT is the time required for the sound pressure level to drop to 0dB to -10dB. DRR is defined as the ratio of the sound energy level of a direct source to the sound energy of the reverberant component. The methodology for computing the above reverberation parameters is given in The International Standards Organization (ISO) document 3382 (Measurement of Room Acoustic Parameters, Part 1, 2009).

# FRAMEWORK FOR AUDIO PROCESSING SYSTEM WITH TAMPERING DETECTION

Tampering detection methods can be of two types: (a) Active Tampering detection and (b) Passive Tampering detection (Hua, Zhang, Goh & Ching, 2016). In active tampering detection methods, fingerprints and water are embedded in the original audio recording which provides clues of tampering. In passive detection methods, no priori information about the recording is available. It is important to develop algorithms for the passive detection method because active detection methods, embedding information in the original audio can degrade the quality of the audio. Also, in a forensic setting, the audio recordings which are available as evidences would not be embedded with any side information and therefore the detection of forgery is blind in a way. This section provides a framework for tampering detection. Different types of tampering attacks are discussed followed by the creation of a database and feature extraction.

# Types of Tampering Attacks

The types of tampering attacks considered in this chapter:

- 1. Insertion: Here, one or more segments from other audio recording is inserted in the original audio recording
- 2. Deletion: Delete one or more segments from the original audio
- 3. Splicing: In this type of forgery, a part of an audio recording is copied and pasted over another recording i.e. audio segments from different audio recordings are concatenated.
- 4. Copy-move forgery: Copy-move forgery, a part of an audio recording is copied and pasted in the same recording at some location. Here, source and destination is same as against splicing where source and destination are two audio files.

# Database Creation

As a standard database consisting of the original and the tampered version is not available, a synthetic database is created with audio recordings and their respective tampered versions. The above types of forgery attacks are applied on the original audio recordings to obtain the tampered versions. Tampering has to be done in such a manner that there should be obvious anomaly which can provide obvious clues of forgery. From a forger's point of view, the audio waveform should flow naturally and there should be abrupt changes of signal levels, background noise levels or multiple environments.

The original recordings are taken from Free Spoken Digit Database (Retrieved from https://github.com/Jakobowski/spoken-digit-dataset). The database consists of recordings from 4 different speakers with 50 audio files from each speaker. There are 2000 total recordings of spoken digits recorded at 8 kHz. For creating move forged audio, initially digits from 'zero' to 'nine' are concatenated together in a single audio file with some silence between digits. In this way, for each speaker audio files are created which contain the utterances of digits 'zero' to 'nine' with the digits in a random order; different for each audio file. Now, one digit utterance is copied from a particular location and moved to another location. This is copy move forgery.
