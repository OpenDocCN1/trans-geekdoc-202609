## Detailed Methodology That Will Adopted

- Image Acquisition: Images used for facial expression recognition will be of static nature. The webcam will be used to capture images.
- Feature Extraction: This is the most important part of Emotion Recognition. The image will be converted into matrix. The matrix will be used to identify the emotion of subject.
- Classification: a classifier detects categorization of language. The six prototypical expressions refer to joy, surprise, rage, fear, and disgust emotional states.
- Post-processing: The aim of post-processing is to improve accuracy of recognition using domain knowledge to correct errors in classification.
- Statistical analysis: monthly based analysis will be done on patients to know about overall motions.
