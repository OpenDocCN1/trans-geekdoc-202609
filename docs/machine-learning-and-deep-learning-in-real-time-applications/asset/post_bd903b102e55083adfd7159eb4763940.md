# SOLUTIONS AND RECOMMENDATIONS

Hybrid DL model gives better performance than advanced ML models. In such cases, it is interesting to investigate the combinatorial models to find classification experience. The performance may be improved by optimizing the learning of the model.

After evaluating the performance of Hybrid model including Deep Learning, an optimized hybrid model is implemented using Cuckoo search. The optimization is achieved in a better way when Cuckoo Search with Levy Flight is used.

# Algorithms

## Optimized model - LCDBN

The input educational data is first given to PCA for dimensionality reduction. The important features are fed to SVM for further prediction. These predictions which are not accurate are fed to DBN for final classification. Here there is change in training the DBN model. The RBM units in DBN are trained with Cuckoo Search with Levy Flight. The training of DBN is improved using CS with Levy Flight so the model - LCDBN Algorithm 2 predicts the error of the proposed LCDBN model. Here the RBM is trained using Flights of Cuckoo Search. Using simple random walk in Cuckoo Search, Levy Flights are used to further improve Cuckoo Search. In traditional CS, the random walk was taken using Gaussian Processes.

A Levy Flight can be thought of as a random walk where the step size has Levy-tailed distribution. The weight of the DBN model has been updated as in Eq. (16). Here, search of CSA is included in RBM weight matrix update. From Eq. (16), $W^{old}$ refers to $Y_i$ of CSA detects the error and indicates the scaling factor.

```
$W \leftarrow W^{old} + \varepsilon^*[\alpha](s_i,s_j=1|x_i)] + (W^{old} * t^{-\lambda}) \quad (16)$
```

# System Model

Figure 13 shows the optimized hybrid model.

The input parameters are split and fed to PCA to reduce parameters. The output from each PCA is given to individual SVM for prediction. The class labels are predicted by the SVM; acts as input to the DBN. Using input and actual class labels, the DBN predicts the classes for the data.

The DBN is constructed with 2 layers of RBM. One RBM represents a hidden layer and a visible layer. The RBM layers are constructed with 3 neurons each and the activation function used is sigmoid function. The numbers of input neurons are 3. After RBM an MLP is added for prediction of class. The MLP has 3 neurons and logistic regression is used as an activation function. The output layer has one neuron to predict the class label. Here learning of DBN is optimized using Cuckoo Search with Levy Flight.
