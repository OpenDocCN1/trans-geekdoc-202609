# Multiple Path Skip Connection

Multiple path Skip Connection is an alternative way to reduce the model complexity and avoid the overfitting problem during the training of the model. In these techniques, we use more than two skip connections with the same shape and take the different skip connections from the input as well as from the different stages of the layers. Here we show the Keras code of Multiple path Skip Connection and uses the Convolution Layer, Batch Normalization Layer and ReLU Activation Layer.
