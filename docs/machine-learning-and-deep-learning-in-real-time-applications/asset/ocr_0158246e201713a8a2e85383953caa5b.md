# Dataset and Tools

In this work, we used a publicly available dataset of HR details. This dataset is a simulated dataset that is created by IBM Watson Analytics (McKinley Stacker, 2015). This dataset contains standard HR features such as age, gender, education, last promotion, job title, and so on. This dataset contained 1470 employees with 38 features. In this dataset 237 employee has "yes" attrition category while 1223 employee was "no" attrition category. All non-numeric values were assigned numerical values. The data conversion was performed using label encoding via the Scikit-learn package in Python (Pedregosa et al., 2011). Furthermore, Python is used in this work to train and evaluate various machine learning approaches. The correlation of different features is a heatmap in figure 1. # Experiment Design

In this section, the results of various machine learning approaches are illustrated. All the approaches are evaluated on the precision, recall, accuracy, and AUC (Area Under ROC Curve). Various performance parameters are described below (Alduay & Rajmaat, 2018; Powers, 2011).

```
Accuracy = \frac{TP+TN}{TP+TN+FP+FN} (2)
```

```
Precision = \frac{TP}{TP+FP} (3)
```

```
Recall = \frac{TP}{TP+FN} (4)
```

```
F-measure = \frac{2*Precision*Recall}{Precision + Recall} (5)
```
