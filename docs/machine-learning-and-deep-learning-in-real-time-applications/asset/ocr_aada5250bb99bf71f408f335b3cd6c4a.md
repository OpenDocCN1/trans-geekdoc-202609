# ARTIFICIAL INTELLIGENCE VS MACHINE LEARNING VS DEEP LEARNING

Artificial Intelligence is a far-reaching research domain, wherein the basic idea revolves around devices and machines exhibiting cognitive capabilities as interaction with the environment, computer vision, handwriting and speech recognition, problem analysis and solving, comprehensive learning, and various other imperative approaches (Russell and Norvig, 2016). Artificial Intelligence aims at imputing human intelligence and instincts to a computer, and a blend of mathematics, statistics, and science makes this possible.

A sub-branch of AI. Machine Learning (ML) focuses on imputing these capabilities contemporaneously, teaching computers instead of training and programming for specific tasks (Bishop, 2006). ML serves the purpose of creating algorithms, by which the computers can make predictions for similar tasks and situations. The machines are provided with data and their desired output and are trained on these examples for unseen data and problems. This is termed as supervised learning. Under unsupervised learning, only the input data is provided to the machine and it is expected to develop an output by itself, without supervision.

There is another field called reinforcement learning, where the machine interacts with its surroundings and trains itself seeing through. The science behind this cognitive learning; computer vision revolves around artificial neural networks.
