## KERAS

Keras is a neural network library (open-source) and coding in Python programming language that able to run on one of high levels of TensorFlow, Theano, or Microsoft Cognitive Toolkit. Usually, Keras developed to facilitate rapid experimentation using deep neural-networks with user-approachable, modular, and extensible. The Keras was established by François Chollet, a Google engineer in the research project of ONEiros (Open-ended Neuro-Electronic Robot Operating System). Chollet is also one of the authors of Xception deep neural network model (Chollet, 2017). Interestingly, Google's TensorFlow supporting Keras in TensorFlow's core public back in 2017. Cholletts argued the Keras was considered being edge rather than a self-governing ML-framework. Keras provides a higher-level approach, an extra impulsive set of concepts that create it simple to develop DL models irrespective of computational back. In this context, Microsoft incorporates CNTK back to Keras, which is available as CNTK v2.0.

Keras library comprises various neural-based operations including types of layers, objectives, activation functions, optimizers, and hot tools that make suitable for working with image and data mining. The code is hosted on GitHub, and community forums that support GitHub issues, and slack channel. Keras consents for convolutional, persistent neural-networks, and supplementary utility layers (dropout, batch normalization, and pooling). Furthermore, Keras consents to the users of DL models on smartphones like iOS and Android, on the web, and Java Virtual Machine. Additionally, Keras permit the use of circulated training of DL models on GPUs and Tensor processing units (TPUs). In recent times, Keras claims more than 200,000 users in 2017 and 10^5 outmost tools in the K Ngets (2018) software poll and also approximately 22% usage. Therefore, DL neural-networks with Keras library is an essential tool for AI-based technologies.

## How to Install Keras

Keras is comparatively simple to install if you have already installed Python, SciPy and TensorFlow environment. Keras installed on two operating systems (1) Microsoft Windows operating system (OS) and (2) Linux OS.

### In Microsoft Windows Operating System

```
pip install Keras
```

### In Linux Operating System

```bash
sudo pip install Keras
```

After installation, you can check the installed Keras version on the command line (in Windows OS) and on the terminal (in Ubuntu OS)

```
python -c "import Keras; print(Keras.__version__)"
```

```python
import Keras
print(Keras.__version__)
```

Upgrade the Keras library with pip command

```bash
sudo pip install --upgrade Keras
```

## Develop Your First Basic Model with Keras

AND gate is logical gate, which implements logical combination and performs on the basis off act to right. A HIGH output (1) data obtained when all inputs to the AND gate are HIGH (1), whereas LOW input data obtained when not all inputs to the AND gate are HIGH. The function may be an increase to a number of inputs even some extent. The schematic diagram of AND as well as the truth table of AND gate as shown in Figure 4.
