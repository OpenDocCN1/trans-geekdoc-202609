# CONCLUSION

This chapter discusses the problem of audio authentication focusing on two authentication tasks, namely, Environment Identification and Tampering Detection. The authors have discussed a general framework for these two tasks describing the feature sets that can be used for classification purposes. Different machine learning algorithms have been used for computing the classifications accuracy for the above tasks. The chapter discusses in brief the architecture of the machine learning algorithms along with some sample results for the two tasks. However, readers are encouraged to read more literature about algorithms if needed.

It can be concluded that ANN and RNN perform better than other classifiers for Environment identification and tampering detection respectively. Future work will focus on considering different environmental scenarios and tampering attacks. The effect of noise and compression on the classification accuracy also needs to be taken into account. The effect of tampering on the reverberant component and different feature sets which can help build a system which perform the two tasks simultaneously can be an addition.
