## 关键术语与定义

**认知因素**：对学生学习和表现有直接影响的学生特征。

**教育数据挖掘**：从教育数据中提取有意义模式的工具和技术。
**非认知因素**：对学习和表现没有产生直接影响，但可能对表现和学习产生间接影响的学生特征。

**优化**：优化是通过调整学习权重来提高模型准确性的技术。

**预测性分析**：使用统计学、机器学习等各种方法探索数据以预测未来。
