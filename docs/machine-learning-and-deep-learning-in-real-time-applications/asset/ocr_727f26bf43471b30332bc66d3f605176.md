The three outputs $(dW^{[l]}, db^{[l]}, dA^{[l]})$ are computed using the input $dZ^{[l]}$. Here are the formulas we need:

```
$dW^{[l]} = \frac{\partial L}{\partial W^{[l]}} = \frac{1}{m} dZ^{[l]}A^{[l-1]}^T$
db^{[l]} = \frac{\partial L}{\partial b^{[l]}} = \frac{1}{m} \sum dZ^{[l]}
dA^{[l-1]} = \frac{\partial L}{\partial A^{[l-1]}} = W^{[l]}^T dZ^{[l]}$
```

Parameters are updated as:

```
$W^{[l]} = W^{[l]} - \alpha dW^{[l]}$
b^{[l]} = b^{[l]} - \alpha db^{[l]}$
```

Where $\alpha$ is the learning rate

+   5. Keep repeating the process until the desired output is achieved
