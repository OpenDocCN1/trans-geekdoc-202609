# Depth Wise Separable 2D Convolution

Separable convolutions contain mainly performance a depth-wise spatial convolution that acts on every input channel, the individually followed by a pointwise convolution, which combines together the resulting output channels. The depth-multiplier argument operates, how many output channels are produced per input channel in the depth-wise step. Figure 12. Shows the regular convolution vs depth-wise separable convolution.

Intuitively, separable convolutions can be understood as a way to factorize a convolution kernel into two smaller kernels factors, or as an extreme version of an Inception block. Figure 13 build a model with Regular vs Depth-wise Convolution through Keras API.
