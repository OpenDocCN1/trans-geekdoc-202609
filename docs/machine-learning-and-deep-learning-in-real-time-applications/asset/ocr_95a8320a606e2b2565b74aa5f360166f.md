# Flatten Layer

The flattening layer is used to change a multi-dimensional tensor to a single 1-D tensor. Figure 9 shows the flatten Layer. For example, if the output of the previous layer is shaped (15, 3, 3, 4), flatten unstacks all the tensor values into a 1-D tensor of shape (15*3*3*4) so that it can be used as input for the dense layer. Also, 64 by 64 grayscale image passed through Flatten Layer, the output is 64*64*1 is equal to 4096. Figure 10. Build a model with Flatten Layer through Keras API.
