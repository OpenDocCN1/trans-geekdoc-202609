# 宗旨

计算机工程和电气工程领域涵盖了广泛的跨学科主题，允许跨领域进行广泛的研究发展。随着计算机和电气系统成为日常生活中不可或缺的一部分，这些领域的研究继续发展并变得日益重要。

《计算机与电气工程进展》(ACEE) 书丛旨在发表关于计算机和电气工程设计与开发的各种应用、工具和方法论的学术论文。
