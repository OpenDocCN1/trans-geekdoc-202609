# Dense Layer

A dense layer is a regular layer of neurons in a neural-network and each neurons receives input from all neurons (previous layer), thereby densely connected. Figure 8 Build a model with dense Layer through Keras API. The layer has a weight matrix W, a bias vector b, and the activations of previous layer a.

```
from keras.models import Model
from keras.layers import Input, Dense
from IPython.display import display, SVG
from keras.utils.vis_utils import model_to_dot\ninputsD = Input(shape=(684,))
D = Dense(32, activation='relu')(inputsD)
D = Dense(16, activation='relu')(inputsD)
D = Dense(8, activation='relu')(D)
response = Dense(4, activation='softmax')(D)
model = Model(inputs=inputsD, outputs=response)
```
