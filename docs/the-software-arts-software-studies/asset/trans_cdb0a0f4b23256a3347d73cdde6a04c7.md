

# 在布尔之前，莱布尼茨已将某些逻辑命题转化为代数

在布尔之前，莱布尼茨已将某些逻辑命题转化为代数，包括 `a = a`；`如果 a 是 b 且 b 是 c，则 a 是 c`；`a = not not a`；以及 `a 是 b = not a 是 not b`。但布尔通过将整个亚里士多德逻辑转化为算术多项式（即用算术运算符 `+`、`−`、`×` 和 `=` 组合变量的公式），完成了莱布尼茨的逻辑。布尔的多项式求值结果为 `1` 或 `0`。^([32](#chapter_4.xhtml#chapter4-32))

如果我们接受布尔将逻辑转化为算术的做法，就能看出这如何扩大了算术的定义本身。在布尔之前，执行算术运算意味着在计算；人们说是在进行加法或乘法运算。布尔之后，在执行完全相同类型的计算时，人们也可以说是在进行逻辑推理。同样，我们可以看到布尔的转化如何将逻辑置换到数学中，因为逻辑因此被视为一种算术形式，因而根据定义，它属于数学的范畴，而不属于修辞和语法等语言艺术的范畴。布尔之后，使用逻辑这门语言艺术被视为与计算是同一回事，这是一个双重惊喜。我们因为某人使用了一种特定的语言形式，就知道他们在计算！我们因为某人在计算，就知道他们在使用这种语言！

## 维特根斯坦论数学基础

布尔在逻辑和算术方面的工作，是十九世纪延续至二十世纪的数学基础研究计划的核心。这项工作的特点是算术在逻辑和数学定义中的影响力日益增强。随着算术变得占主导地位，要理解什么不是计算变得困难。所有的思想和行动仅仅是算术吗？

1939 年，在剑桥大学的复活节学期和四旬斋学期期间，哲学家路德维希·维特根斯坦在其数学基础课程中讨论了这些问题。尽管维特根斯坦未带讲稿授课，但他的学生做了详尽的笔记，这些笔记后来被整理编辑在一起，形成了维特根斯坦言论和研讨会讨论的记录。显然，有十三四位固定出席者，其中包括艾伦·图灵，他刚从普林斯顿完成博士学业返回剑桥。

根据学生笔记，维特根斯坦在讲座中提出了以下问题：“但——这是一个重要的点——我们怎么知道，当我们观察人类时所观察到的现象，就是我们应该称之为语言的东西？或者我们应该称之为计算的东西？”^([33](#chapter_4.xhtml#chapter4-33))

乍一看，维特根斯坦的问题似乎非常奇怪。认出某人是否在计算，能有多复杂？维特根斯坦用另一组问题追问这个看似不可能的困难。当我们看到某人在计算时，我们观察到了什么？“如果我看到某人拿着一张纸以某种方式做标记，我可能会说，‘他在计算。’”^([34](#chapter_4.xhtml#chapter4-34)) 但我们能仅通过观察某人在纸上做标记，就确定他在计算吗？后来，维特根斯坦说：“如果你这样做，我们不会称之为计算。`4 + 5 = {}`——你在 `{}` 里写下脑海中浮现的任何东西——这是算术运算吗？随你怎么叫。它遗漏了演算最本质的一些要点。”^([35](#chapter_4.xhtml#chapter4-35))

讲座笔记的另一处记录了图灵的评论，即可以将计算与实验进行比较。维特根斯坦利用这个比较展开讨论：“让我们回到图灵将物理学实验与数学计算相比较的观点。假设有人发明了一种算术，使得 `2 + 2 = 4` 通过在天平的一盘放两个比特再放两个比特，另一盘放四个比特，看到两盘都不下沉来证明。在什么情况下我们应称之为实验，在什么情况下应称之为计算？”^([36](#chapter_4.xhtml#chapter4-36)) 这是一个完全不同的计算形象。我们可以想象计算是在纸上做特定标记，也可以想象它借助物理比特（即砝码）和天平进行。什么算作计算？什么不算？

在维特根斯坦的数学基础讲座中，他经常转向图灵提问或举例子。就这些关于计算本质的讨论而言，这毫不奇怪，因为我们可以把图灵 1936 年的论文（见第 2 章讨论）理解为定义了计算的本质。

图灵成就的部分在于，基于与算术的类比，他给出了被视为计算或计算通用描述的公式化。^([37](#chapter_4.xhtml#chapter4-37)) 尽管如此，维特根斯坦在图灵论文发表后仍提出这些关于计算的问题，事实上，他提出这些问题的对象不仅仅是任何人，而是图灵本人。为什么？在图灵给出定论性的回答后，还有什么需要澄清的？

## 当计算机还是人的时候

为了理解计算形象的不稳定性，我们将回到维特根斯坦的观察（见第 2 章讨论），即图灵的“机器”是人，是用铅笔和方格纸做算术的人类。

因为算术对如此多的思想和工作领域变得如此重要，其无处不在催生了一种被贬为劳动的新工作形式。正如第 2 章所指出的，这种新劳动形式在十七世纪就已为莱布尼茨所察觉。他写道：“如果使用机器，优秀的人把时间像奴隶一样花在计算的劳动上是不值得的，这种劳动完全可以放心地交给别人。”这种新劳动形式就是莱布尼茨所谓的计算劳动。随着算术算法在商业、科学、工程和政府中传播，人肉计算机这一职业被发明出来，以执行这些如今数量庞大的计算。

大概关于作为人类劳动的计算历史，最好的著作是大卫·格里尔的《当计算机还是人的时候》。格里尔从 1758 年哈雷彗星的回归开始讲起。“牛顿的追随者们，根据他的原理，甚至大胆预测几颗[彗星]的回归，”苏格兰哲学家亚当·斯密（1723–1790）写道，“特别是一颗将于 1758 年出现的彗星。”^([38](#chapter_4.xhtml#chapter4-38)) 不幸的是，牛顿的微积分没有直接陈述或求解三体问题的方法。在这种情况下，被认为对彗星轨迹影响最大的三个天体是太阳、木星和土星。为了预测哈雷彗星回归的日期，天文学家只能将观测运动的数据切成小步骤，在每一步分析三个天体对彗星运动的影响，然后将所有这些逐步分析整合在一起。正如当时一位天文学家所言：“这项任务需要多么巨大的劳动，多么渊博的几何知识啊？”^([39](#chapter_4.xhtml#chapter4-39))
