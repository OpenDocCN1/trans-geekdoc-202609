

# 沃尔夫勒姆的修辞与新科学

沃尔夫勒姆继续坚称，他在元胞自动机方面的工作已经引入，或即将引入数学、物理学、生物学、社会科学（从经济学到心理学）、计算机科学、哲学、艺术和技术等领域的非凡进展^[142](#chapter_6.xhtml#chapter6-142)，并且为了实现这一点，他不得不超越人工智能、人工生命、灾变理论、混沌理论、复杂性理论、计算复杂性理论、控制论、动力系统理论、进化论、实验数学、分形几何、一般系统理论、纳米技术、非线性动力学、科学计算、自组织和统计力学等领域的所有先前研究。^[143](#chapter_6.xhtml#chapter6-143)

## 一种新型修辞

沃尔夫勒姆关于“计算等价性”的主张令人怀疑，甚至正如他的同事沙利齐所言，是“狂妄的自我中心和彻头彻尾的胡说八道”。他的主张是通过一种溯因演示的形式进行论证的，这与演绎和归纳演示截然不同。这种新型修辞将技术图像与创建这些图像的计算过程的阐述相结合，正如所讨论的，这并非沃尔夫勒姆独有，而是为视觉分析、信息可视化和数据科学、机器学习、新形式的数据驱动新闻以及许多其他新兴领域所共享。

一旦我们将这些实践理解为新型修辞，我们就能开发出反驳其主张的概念工具。这些工具既需要足以批判溯因演示的图像，也需要足以分析将图像与其计算理论和方法基础联系起来的主张。

很难不把沃尔夫勒姆关于计算等价性的主张读作夸夸其谈的吹嘘，因为在他的书中，他使用了如此多种形式的非演示性散文，其写作早已超出了这种新型修辞的范畴。在他的著作中很容易找到更多这种夸张的例子。例如，在一节标题为“本书科学的个人故事”章节中，沃尔夫勒姆声称他亲自彻底变革了所有科学，起始于他十二岁时所做的工作：

> 我可以相当准确地将我对本书所讨论的这类科学问题产生严肃兴趣的开端，追溯到 1972 年夏天，那时我十二岁。…… \[随后\] 1994 年左右，我开始系统地研究各个主要传统科学领域。…… 典型的问题在于，存在一些核心问题，传统方法或直觉从未能成功解决。…… 然而一次又一次，我兴奋地发现，凭借我的新科学，我突然能够开始取得进展——甚至在某些情况下，针对那些悬而未决几个世纪的问题。^[144](#chapter_6.xhtml#chapter6-144)

这种自我中心和夸张使得他的同行难以看到他的演示与他们的演示之间的亲缘关系，但正如亚里士多德一样，我坚持要将非演示性的修辞形式抛在一边，以便更好地专注于演示本身——即所展示的内容。而沃尔夫勒姆文本中所展示的内容，以他将自动机呈现为黑白方块的非凡图形渲染形式出现。沃尔夫勒姆采用的溯因演示形式，似乎基于一种较古老的演绎演示形式（即理论计算机科学中实践的图灵完备性证明类型），但在他的案例中，这在很大程度上与计算普适性的这种狭义解释（即对丘奇-图灵论题更为谦逊的理解）脱钩了。

沃尔夫勒姆的“发现”并非一种新科学。沃尔夫勒姆的贡献是一种新型的视觉公共修辞——或者至少他的发明，他那种黑白图表的形式，是对这种新型修辞极具说服力的贡献。其证明在于他的书成为了一本畅销书，被——或者至少被购买——由远超物理学家和计算机科学家范围的大众阅读。^[145](#chapter_6.xhtml#chapter6-145) 而且，正因为这是一种新型修辞，我们可以看到，其他正在发展的计算机图形学形式（如数据科学和机器学习的信息可视化技术）以及其他新兴的计算系统体裁（如电脑游戏）也都是基于类似溯因演示程序的修辞套路，甚至是完整的同胞修辞。我们需要能够看到，所有这些以及沃尔夫勒姆的书，都是恩格尔巴特“所有演示之母”的孩子。
