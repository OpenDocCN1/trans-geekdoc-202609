

# 我们不是合作者，甚至谷歌高管也不是合作者。我们是佐证者、欣赏者，或者正如皮尔士所解释的，我们是猜测者，因为我们有义务编造自己的理由，来解释为什么我们在屏幕上发现的东西引人入胜：“溯因推理是那种从其出发点的数据中根本不包含某陈述、却提出该陈述的运作。它有一个比‘溯因推理’更熟悉的名字；因为它既不多也不少，就是猜测。”^([94](#chapter_6.xhtml#chapter6-94))

## 归纳推理变为溯因演示

皮尔士详述了溯因推理的过程：

> 大量事实摆在我们面前。我们浏览它们。我们审视它们。我们发现它们是一团乱麻，一片难以穿越的丛林。我们无法将它们保持在脑海中。我们试图将它们记录在纸上；但它们似乎如此复杂错综，以至于我们既无法让自己确信记录下的内容代表了事实，也无法对记录下的内容形成任何清晰的概念。但突然间，当我们正专注地研读事实摘要并试图将其理清时，我们想到：如果我们假设某个我们不知道是否为真的东西为真，这些事实就会清晰地自行排列。这就是溯因推理。^([95](#chapter_6.xhtml#chapter6-95))

当归纳变成由机器执行的一种计算形式时，演示就变成了溯因性的，因为数据及其汇总成结果的过程大多未知，如果不是完全不可捉摸的话。此外，我们——人类——得出的结论可能受到部分数据的启发，但未必植根于数据。我们的结论可以是虚构、编造，是我们凭空捏造的东西。正如拉图尔所言，这种新形式的溯因推理是一种生产形式，一种编造事物的方式，这正是让科学家感到不安、却是艺术家和艺术诠释者主要工作形式的东西。

深刻的诊断、俏皮的诠释和创造性的发明，是面对满屏数据的人类所需进行的操作。当然，这些操作也可以被贴上负面标签：盲目猜测、漫无目的的浏览、故意投射、`apophenia`（关联幻觉），“看到”并不存在的东西。^([96](#chapter_6.xhtml#chapter6-96))

请考虑视觉分析学的奠基文献之一，这是计算机科学中一个新兴的子领域，旨在利用信息可视化技术处理海量数据库。这份文件的起草是为了为新领域阐述研究议程，资金主要来自美国国土安全部。以下研究问题的例子摘自报告的执行摘要：“一个紧迫的目标是在恐怖袭击发生前阻止它们。分析师需要拼凑埋藏在不同数据中的信息的能力——包括移民记录；旅行模式；电话通话；以及嫌疑恐怖分子的姓名、隶属关系和位置——以便让他们在袭击执行前发现正在浮现的袭击。”^([97](#chapter_6.xhtml#chapter6-97)) 请注意，所寻求的——“正在浮现的袭击”——尚不存在；它不是一次袭击。因此，视觉分析学是当代溯因演示的典型特征，是一种在任何人都无法仔细审查的海量数据中，试图看到不存在之物的努力。^([98](#chapter_6.xhtml#chapter6-98)) 视觉分析学是一种“看到东西”的实践：在检查数据压缩算法的输出时，人类试图看到可能存在也可能不存在的东西。

“发现新兴趋势”是视觉分析学、信息可视化、数据科学文献中常见的愿望，也是在这个“大数据”时代正在建立的其他研究领域的愿望。这些新领域需要做的是同时鼓励从业者富有创造力、编造事物、看到事物，但也要在这些观看和制造中施加纪律和严谨。这些双重要求为大多数艺术家所熟知，但这是一个伦理和道德上的当务之急，即它们必须在数据科学和数据可视化这些新领域中，像在艺术中一样被严格追求。显然，如果美国国土安全部只是在“看到东西”，那将是一场噩梦，就像好莱坞电影《少数派报告》^([99](#chapter_6.xhtml#chapter6-99))（基于菲利普·K·迪克的小说）所描绘的那样，汤姆·克鲁斯饰演一名领导“预犯罪小组”的官员，因人们将来可能犯下的罪行而逮捕他们。^([100](#chapter_6.xhtml#chapter6-100))

溯因演示可能被误导，并不意味着先前的演示形式是预知未来的。我们知道某事物是如何被制作出来的（例如，波义耳是如何推导出其定律的），并不意味着我们知道它的含义。正如所讨论的，对于波义耳定律，花了另一个世纪才在因果层面而非仅仅在相关层面上理解它；也就是说，对气体分子动能运动的理解不得不等到十九世纪。

此外，根据皮尔士的观点，溯因推理本就与演绎和归纳耦合，因为如果没有假设，两者都无法开始。假设从何而来？它们来自猜测，来自溯因推理。皮尔士写道：“现在，我们已经看到，没有任何新真理能来自归纳或演绎。它只能来自溯因推理；而溯因推理归根结底，无非就是猜测。”^([101](#chapter_6.xhtml#chapter6-101)) “演绎证明某事必然存在；归纳表明某事实际在起作用；溯因推理仅仅暗示某事可能存在。”^([102](#chapter_6.xhtml#chapter6-102))

显然，溯因推理在演示中一直扮演着角色，但现在，随着数据的激增，溯因演示正在掩盖演绎和归纳形式的演示。

## 技术图像

我们现在看到的是作为说服形式的数据图像。在科学、新闻业和广告等行业中，说服是通过展示和观看数据来完成的。但数据太多了，所以我们看到的往往是数据某个子集的静态或动态图像：对数据执行复杂计算的可视化呈现。我们在道格拉斯·恩格尔巴特、特里·维诺格拉德和尼古拉斯·内格罗庞特的演示中见过这些图像。我们在在线报纸的“数据新闻”中将这些图像称为“信息图表”和数据可视化——条形图、饼图、网络图、以及叠加在地理地图上的数字（例如，通过计算预测即将到来的选举结果的美国红蓝投影地图）。^([103](#chapter_6.xhtml#chapter6-103)) 当需要计算机中介的医学影像时，我们在医生办公室也能看到它们，例如正电子发射断层扫描（PET）。^([104](#chapter_6.xhtml#chapter6-104)) 它们被部署在公共辩论中作为图形模拟，例如那些用来论证全球气候变化已到来并正在加速的模拟。^([105](#chapter_6.xhtml#chapter6-105)) 它们是当代电脑游戏的内在组成部分，因此构成了一种“程序性修辞”。^([106](#chapter_6.xhtml#chapter6-106))

这种新型图像是从数据计算而来的。哲学家维莱姆·弗卢塞尔称这种视觉生产为“技术图像”。弗卢塞尔将技术图像与传统图像（例如用极简相机拍摄的照片）区分开来：“从本体论上讲，传统图像是一阶抽象，因为它们从具体世界中抽象而来；而技术图像是三阶抽象：它们从文本（如计算机程序）中抽象，文本从传统图像中抽象，传统图像本身又从具体世界中抽象。”^([107](#chapter_6.xhtml#chapter6-107))
