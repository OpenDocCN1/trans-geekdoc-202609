
当然，在罗伯特的案例中，通过文森特对薇拉的模拟是不道德且犯罪的，尽管并非所有模拟都是不道德的建构，也并非所有恋物癖者都是罪犯。这种否认状态是当代生活的常态，我们大多数人确实是非暴力的恋物癖者。我们非常清楚，我们日常生活的数字模拟并不等同于它们所基于的模型。我们的电子邮件、智能手机、流媒体电影和视频、社交网络上的“朋友”，甚至我们在“收音机”里听到的合成声音和经过数字滤波的歌手，现在全都是数字化的，但它们基于过去的前计算机时代的模型、媒介和制度。我们对待这些模拟，就好像它们本质上等同于各自的模型。这就是日常的数字生活。它在炒作、否认和无知中得以复制。

我使用“模型”一词的方式，类似于生物医学研究人员使用该词的方式。例如，癌症研究人员可以利用小鼠作为模式生物来测试新药，因为小鼠与人类有足够的相似性，足以说明该药物在人类身上可能的表现。在这个意义上，模型并不比模拟更接近某种理想。因此，当我断言模拟永远不可能成为其模型时，我并不是在说模拟是“虚拟的”而模型是“真实的”。我也不是在表达怀旧情绪，想象模型是“真实的”而模拟是“虚假的”。小鼠既不比其他事物更真实，也不比其他事物更不真实。相反，就生物医学研究而言，小鼠之所以能成为可行的模型，是因为它们在某些重要方面类似于人类，显然，在其他方面则截然不同。

我假定模型和模拟之间不存在序关系：没有哪一个比另一个更接近真实。相反，正如我们将在第6章（关于修辞学）中看到的，其他人，如柏拉图，认为模拟离真实要远得多。

## 恒等、相等与赋值

在她1982年的热门专辑《大科学》中，^([5](#chapter_2.xhtml#chapter2-5)) 劳里·安德森唱道：“我遇见了这个家伙——看起来他可能曾是溜冰场的寄存员。事实上，他确实是。我说道：噢，天哪。又对了。令 X = X。” 安德森这里古怪的幽默感将她与哲学中的一个悠久传统联系在了一起。“令 X = X”是恒等律的陈述，即三大经典思维定律中的第一条，最初由柏拉图撰写，随后由许多哲学家加以阐述。

正如任何计算机程序员所知，赋值不是恒等的声明。赋值是一种依赖时间的强制形式。在数学中，`X = Y` 是恒等的声明，意味着 X 就是 Y 且永远将是，且相等具有交换性：写 `X = Y` 与写 `Y = X` 意思相同。与数学不同，在计算机编程中，`X:= Y` 是一种赋值，意味着在某一时刻之后 X 变为 Y。赋值通常不具备交换性：写 `X:= Y` 通常意味着与写 `Y:= X` 完全不同的事情。^([6](#chapter_2.xhtml#chapter2-6))

作为一个语句，`X:= Y` 似乎很难作为一个引人入胜的故事的核心，但当然，恒等的戏剧潜力更多在于其赋值过程中的悬念，而非其声明本身。在赋值并无根据、不被想要或不被预期的条件下，赋值可以具有戏剧性。在阿尔莫多瓦的电影中，当文森特通过手术被重新赋值为薇拉时，是在极端的身体和心理暴力条件下进行的。为了重新赋值文森特的身份，罗伯特必须行使暴虐和可怕的权力。

本书的一个主要关注点是赋值及其与恒等和等价的纠缠。具体而言，这里的焦点是数字赋值。计算机是如何以及通过何种手段被用来断言不同事物——模型与模拟——是相同的？

计算机在当代关于赋值和恒等的问题中扮演着主角，但还有许多其他参与者，尤其是我们。在承认我们的角色时，我并非像那些作家那样对“我们”提出主张，他们想论证年轻一代是“数字原住民”^([7](#chapter_2.xhtml#chapter2-7))，或者计算机正让我们变笨。^([8](#chapter_2.xhtml#chapter2-8)) 相反，问题在于用于赋值身份和等价的具体计算手段，我将这种手段笼统地称为“翻译”。

我并不向往一个前数字化的、真实的时代。相反，我的动机源于对教育的信念，尽管我们当代数字条件的炒作和否认无法通过教育来解决。即使是受过良好教育的人也会为炒作所迷惑，沉溺于否认之中。然而，我认为数字恋物癖的第三个因素——无知——可以通过教育来治疗。因此，我希望对计算机运作机制的仔细分析，至少能帮助我们理解，当我们否认数字生产模式、将其产品恋物化时，我们在做什么：噢！我多么爱我的新智能手机！

## 模型与模拟之间存在鸿沟

尽管如此，我并不像某些人那样恳请你们享受你们的症状！^([9](#chapter_2.xhtml#chapter2-9)) 相反，我恳请你们——正如伦敦地铁站台上的标志所建议的——**留心空隙**！我的兴趣在于模型与数字模拟之间的差异是如何被处理的。正如罗伯特通过成千上万次切割和缝合试图将文森特变成薇拉一样，宏大的数字等价需要无数较小的技术安排来实现其赋值。这些较小的技术安排往往也是数字赋值。

例如，如何让计算机表现得像电话或电视？这一过程的核心是编码，即软件的生产。软件是一种特殊的文本，软件的生产是一种特殊的写作。每部智能手机的核心都是一台计算机。让计算机作为智能手机运行，是一个证实成千上万个较小等价的努力，这些等价使得我能在日常生活中将计算机当作电话使用。隔开计算机与电话的鸿沟，由软件填补。我们将留心那个鸿沟。

## 数字融合与赋值等价的权力

赋值等价的权力，是米歇尔·卡隆和布鲁诺·拉图尔在一篇旨在将政治和科学都解释为翻译形式的文章中的核心观点。卡隆和拉图尔写道：“掌握等价者，掌握权力的秘密。”^([10](#chapter_2.xhtml#chapter2-10)) 然而，在科学和政治中——甚至在游戏中——仅仅断言一种等价是不够的；一种等价总是需要被证明，然后通过一系列翻译广泛传播，促使我们相信所断言的恒等。

在18世纪，安托万-洛朗·德·拉瓦锡（1743–1794）确定水是氢和氧的化合物。为了让这一等价被相信，他必须演示水（H[2]O）分解为两种气体（氢和氧）的过程。^([11](#chapter_2.xhtml#chapter2-11)) 在拉瓦锡之前荒谬的等价，在世界各地的实验室和教室反复演示之后，现在已成为常识。^([12](#chapter_2.xhtml#chapter2-12)) 在科学研究和政治哲学中，仔细考察这种翻译过程的方法被称为“翻译社会学”，或更常见地称为“行动者-网络理论”（ANT）。^([13](#chapter_2.xhtml#chapter2-13))
