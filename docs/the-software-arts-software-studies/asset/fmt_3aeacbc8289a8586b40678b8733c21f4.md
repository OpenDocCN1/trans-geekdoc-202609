
教育研究表明，这是一种对儿童算术错误极具洞察力的想象。教育技术学家和人工智能专家 John Seely Brown 与 Kurt VanLehn 将算术描绘为一个规则空间，在这个空间中，当儿童发明出一个错误规则，或在做加减法的过程中在错误时机使用了正确规则时，就会产生错误。例如，在多列减法过程中，计算到某些步骤时，需要从当前数字列左边的那一列“借位”。新手可能会“借位”，但忘记将左边那一列的数字减 1；或者，为了避免用较大的数字减去较小的数字，如果下一行的数字较大，他们可能会交换上下两行的数字位置，然后再做减法。

Brown 和 VanLehn 声称：“程序技能的所有 Bug 都可以通过一种高度受限的问题解决形式作用于不完整程序而导出。这些程序的特征是形式化的删除操作，可模拟不完整的学习和遗忘。”^([55](#chapter_4.xhtml#chapter4-55)) 他们提议，我们将算术算法想象为嵌入在一个大得多的算法可能性空间中，其中一些算法对于给定任务是正确的，另一些则是不正确的。每个算法由一组规则组成，因此，在这些算法之间“移动”或“转换”，在他们的框架中，就是删除或更广泛地编辑算法中的一条规则（或一系列规则）。对 Brown 和 VanLehn 而言，算术中的人为错误——以及人类学习^([56](#chapter_4.xhtml#chapter4-56))——就是在一个庞大的规则集空间中导航。

算术算法是更大算法空间的一部分这一事实，有助于我们更好地理解错误、学习等问题，以及为何 Wittgenstein 似乎认为计算是一个不稳定、不断变化的目标。我想通过更具体地描述“算法空间”可能的样子，来详细阐述算术与算法的这一关键问题。虽然原则上可以用 Brown 和 VanLehn 使用的规则符号来做这件事，但我认为他们的符号系统过于复杂。相反，我提议用黑白方块来书写算术规则。

[图 4.2](#chapter_4.xhtml#fig4_2) 描绘了一种用黑白方块表示二进制加法规则的可能方式。^([57](#chapter_4.xhtml#chapter4-57)) 算法的每条规则用五个方块书写。顶部三个方块匹配正在进行的加法中的一列。底部两个方块用于重写最终结果行中记录的两个方块。可以将前三个方块视为调用规则前必须匹配的模式：一个前置条件。后两个方块是规则被调用时写入结果的内容：一个后置条件。换句话说，每条规则都可以读作 *if … then* 语句：如果前三个方块匹配加法问题的当前列，则按所示方式重写结果的两个方块。每条规则后置条件中的右侧方块用于记录最终结果的一位。左侧方块用作“进位位”。

[图 4.2](#chapter_4.xhtml#fig4_2) ¶ 二进制数加法规则。

正如学生在十进制算术中被要求学习当两个个位数相加结果为两位数时如何“进 1”一样，这些规则的左侧方块编码了何时应将 1（即黑方块）进位到下一列。因此，一般来说，如果一列中有两个或更多黑方块，就需要向左边的列进一个黑方块（因为在二进制加法中，请记住 1 + 1 = 10）。

[图 4.3](#chapter_4.xhtml#fig4_3) 展示了加法问题 87 + 56 = ? 的二进制等价形式。第一行是 87 的二进制等价形式（即 01010111）；第二行编码 56（即 00111000）；第三行开始为空，将在所有匹配规则应用完毕后保存和。

[图 4.3](#chapter_4.xhtml#fig4_3) ¶ 两个二进制数相加的初始状态。

再看一遍 [图 4.2](#chapter_4.xhtml#fig4_2) 中展示的加法规则。规则按照其前置条件排序；即按照规则顶部三个方块中的模式排序。在最左边的规则中，前置条件的所有方块都是黑色的。在最右边的规则中，前置条件的所有方块都是白色的。如果我们将所有前置条件侧放，使其能水平而非垂直地被检查，然后将这些三元组与二进制数的表示（黑白方块）进行比较，我们会发现黑白方块的序列从右向左（如果你确实将页面逆时针旋转了九十度使其水平，如之前建议的那样，则是从上到下）“拼出”了 0, 1, 2, 3, 4, 5, 6, 7。

在十进制系统中，用三位数字最多可以写出一千个不同的整数（即 {0 … 999}）。在二进制系统中，用三位数字只能写出八个不同的整数（即 {0, 1, 10, 11, 100, 101, 110, 111}）。我们可以约定，总是将一个规则集的规则排列为一个八元序列，其中最左边的前置条件是所有方块均为黑色的那个（即它编码 7 的二进制表示：111）。最右边的前置条件包含三个白方块（即 000）。

例如在 [图 4.6](#chapter_4.xhtml#fig4_6) 中，展示了一组减法规则。将其与加法规则集对比，你会发现前置条件顺序相同，但显然后置条件（规则集中每条规则底部的两个方块）是不同的。在这种情况下，每个后置条件的左侧方块代表一个“借位位”（类似于我们在传统减法中使用的借位规则），而不是像加法规则集那样代表“进位位”。
