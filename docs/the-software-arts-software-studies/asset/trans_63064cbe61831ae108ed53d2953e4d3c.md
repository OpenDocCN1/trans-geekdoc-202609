
希腊城邦所发明的……是*竞争*（agon）作为自由人或公民的共同体，他们与其他自由人建立竞争关系，在一种广义的竞技精神中相互行使权力、提出主张。例如在希腊城邦中，官职是一种主张的对象，是一种有人可以提出候选资格的职能；而在帝制国家中，此类官员则由皇帝任命。这种新的、可确定的人际关系类型（竞争性的）渗透了整个希腊集合体；竞争关系在城邦之间被推广（体现在战争和运动会中），在城邦内部被推广（体现在政治集会和法律官职中），在家庭和个人关系中被推广（爱欲、经济、饮食、体操），甚至在与自身的关系中也被推广（因为如果一个人不能治理自己，又怎能主张治理他人？）。^([51](#chapter_6.xhtml#chapter6-51))

如此描绘，这呈现出一幅自由角逐的图景：任何公民都可以就任何事向任何其他公民发起挑战，而新的民主条件提供了新的制度（如法庭系统），使由此产生的竞争得以进行。冒着过度简化的风险，柏拉图认为这些条件荒谬可笑。在他看来，人民统治（*demos*）容易演变成暴民统治。相反，依柏拉图之见，智者、哲学家应当成为统治者，因为他们的思想源于真知，而非仅由大众舆论所左右。

柏拉图在《理想国》中阐述了他那不切实际的乌托邦治国方案，但短缺一场政治革命，柏拉图针对具体的竞争提出了一系列更为迫切的论点。哲学家汉娜·阿伦特推测，柏拉图因其老师苏格拉底被判死刑而深受打击。^([52](#chapter_6.xhtml#chapter6-52)) 在苏格拉底的审判中，法庭的意见是判处死刑，但——柏拉图问道——这些自以为有资格统治最智者苏格拉底的法庭公民究竟是谁？依柏拉图之见，这些公民只是意见之人，而非知识之人，因此不具备资格，是苏格拉底陪审团职位上不合法的主张者。因此，吉尔·德勒兹写道：“贯穿柏拉图哲学始终的一个问题是衡量竞争对手和甄别主张者的问题。”^([53](#chapter_6.xhtml#chapter6-53))

原则上，伯里克利时代古雅典公共生活中的任何人都可以成为任意数量职位或物品的主张者。当然，实际上“任何人”指的是成年男性公民，而成为公民需要一定财富。此外，在伯里克利的立法之后，公民权仅授予在雅典出生且父母均为雅典人者；即他建立了血统和土地的公民资格要求。因此，雅典的“民主”仅限于特定血统的富裕男性。具有讽刺意味的是，至少在该法律有效期间，它排除了伯里克利和阿斯帕西娅自己的儿子，因为阿斯帕西娅是来自米利都的外邦人。

## 柏拉图与拟像

但这些雅典选举权固有的限制对柏拉图而言还不够。即使有这些限制，柏拉图仍质疑主张者的合法性如何确定。什么区分了可行的主张者？柏拉图在两篇对话录中追问这些问题：《斐德罗篇》和《政治家篇》。在一篇互补的对话录《智者篇》中，他追问的是相反的问题：不是什么区分了可行的主张者，而是什么识别出虚假的竞争对手。

在后一篇对话录中，柏拉图断定智者不仅是最差的主张者，而且是一个完全虚假的竞争对手，在任何情况下都不合格且有害。在他的判断中，柏拉图将智者的等级甚至排在诗人和画家之下，后二者虽皆为模仿者，但至少是复制品的创造者，其相似物与其声称所代表的事物仍有一定亲和性。

但什么比糟糕的复制品等级更低？依柏拉图之见，典型的虚假竞争对手是作为“拟像”（simulacrum）的智者。再次，丹尼尔·史密斯为我们提供了简明的总结：“本质的柏拉图式区分因此比模型与复制品、原件与影像、本质与表象之间的思辨区分更为深刻。更深层、实践层面的区分在于两类主张者或‘影像’（Plato calls *eidolon*）之间的转换。1. ‘复制品’（*eikones*）是有据可依的主张者，因其与理想模型的内在相似性而获得授权，因其对基础的紧密参与而得到认证。2. ‘拟像’（*phantasmata*）则像虚假的主张者，建立在不相似性之上，暗示着对理念的根本背离或偏离。”^([54](#chapter_6.xhtml#chapter6-54)) 用德勒兹的话说：“正是在这个意义上，柏拉图将影像-偶像的领域一分为二：一边是图像式的复制品，另一边是幻觉式的拟像。”^([55](#chapter_6.xhtml#chapter6-55))

对柏拉图而言，智者即拟像，是不受欢迎的人，在伦理、教育、政治和哲学上毫无价值。用当代术语来说，柏拉图指控智者是相对主义者，他们不相信真理，不惜一切代价取胜；他们用非理性而非理性的说服形式追求其事业；他们是牟利者或雇佣兵，愿为付费者表演或教学；他们腐蚀性地向雅典青年传授其堕落的道德和方法。这就是柏拉图赋予“拟像”一词的含义。

柏拉图的导师苏格拉底被控以相同的罪名——不敬神和腐蚀青年。这或许不足为奇，因为许多学者主张苏格拉底本身就是智者，而“苏格拉底方法”实际上更广泛地说是智者的方法。^([56](#chapter_6.xhtml#chapter6-56)) 此外，一些学者如汉娜·阿伦特认为——与柏拉图不同——苏格拉底并未在意见（*doxa*）与真理之间看到清晰的分界。因此，苏格拉底的目标不同于柏拉图为他描绘的追求：“柏拉图称为*dialegesthai*［辩证法］的东西，苏格拉底称为*maieutic*，即助产术：他想帮助他人生出他们自己原本就有的思想，在他们的*doxa*中寻找真理。”^([57](#chapter_6.xhtml#chapter6-57)) 苏格拉底是智者而非柏拉图主义者，这或许除了柏拉图之外，对所有人都很清楚。
