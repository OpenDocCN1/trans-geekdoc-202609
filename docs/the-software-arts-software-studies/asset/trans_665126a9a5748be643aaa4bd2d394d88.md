
# 第七章：语法

第七章论述的是语言三大自由艺术中的第三种：语法。长期以来，语法是一个政治项目，它以教学法的面目出现，旨在使帝国的书面语和口语趋于同质。后来，它以类似的方式被用于巩固民族国家。语法最初主要是规范性的。随后，在十九世纪末和二十世纪初，渴望描述语言实际如何被使用的语言学家重新构建了语法的框架。随着语言学家兼符号学家费迪南·德·索绪尔的贡献，语法变成了描述性的。当这一转变发生时，其核心阵地从教科书转移到了机器中——无论是机械装置，还是大脑的想象机制。到了二十世纪中叶，语言学已与大卫·希尔伯特倡导的数学形式主义联手。这导致语言学发生转型，将“意义”排除在其研究对象之外。用诺姆·乔姆斯基的话说：“对意义和指称以及语言使用的研究，应当从语言学领域中排除。”^([89](#chapter_1.xhtml#chapter1-89)) 相反，乔姆斯基及其追随者以无意义的句法操纵形式从事语言学研究，并最终将其阐述为计算机程序。乔姆斯基之后，语法机器变成了软件，并有人宣称软件能构成一种语言理论。这代表了智力文化的巨大转变。当一个计算机程序、一件软件可以成为一种理论时，我们就进入了我称之为“计算认识论”的时代。在计算认识论中，软件被视为理论洞见，而意义被推向边缘。这些条件奇特且充满挑战。我希望读者能看到，在计算认识论中要想讲得通——复活意义——其中一种方式是作为一名艺术家行事，从事软件艺术。

# 2 翻译

本章的第一部分是一场关于翻译及其在多个研究领域中用途的开放式讨论，特别关注其在艺术、人文学科、科学技术研究（STS）和计算机科学中的相关性与定义。在 STS 中，翻译分析常在“行动者-网络理论”（ANT）的旗帜下进行，并被用于研究各种各样的科学领域和技术对象。我们将看到 ANT 方法论如何能被修正和扩展，以用于软件研究。

本章的第二部分聚焦于一个详尽的关键例子，它对计算机科学的基础至关重要，且如今是舆论关注的中心：大卫·希尔伯特的“判定问题”及其由艾伦·图灵和阿隆佐·丘奇所做的分析。通过仔细阅读一些探讨希尔伯特判定问题的关键文本，我将展示如何运用 ANT 方法来审视这类技术文献中的形式数学/逻辑证明。我重点关注图灵、丘奇及其他人用来赋予身份和等价性的具体手段——翻译技术，特别是那些断言计算机类似于、或与人是同一事物的技术。我的观点是，计算机与它在修辞上等同的任何事物或任何人之间，总存在着将二者分隔开的鸿沟。我恳请你们——就像伦敦地铁站台上的标识那样——**留心空隙**！

在考察了等价性如何在计算机科学基础的更技术性语言中被锻造之后，我将追踪希尔伯特的判定问题如何从技术文献中浮现，并被翻译进入更大众、更通俗的场域，在那里产生了虚假断言，例如“计算机可以被编程来模拟任何事物”。对 ANT 方法论的重新加工，为我们提供了所需的工具，以理解软件文本的普及过程如何在技术著作与关于计算极限的日常常识之间，建立起或强或弱的联系。

## 赋值与模拟

在佩德罗·阿尔莫多瓦 2011 年的电影《我要的皮肤》^([1](#chapter_2.xhtml#chapter2-1)) 中，整形外科医生罗伯特·莱德加德追踪到一名年轻人文森特·皮涅罗，将其囚禁，并在六年的时间里，让他接受了一系列手术，将他改造成罗伯特已故妻子薇拉·克鲁兹的一个模拟体。当罗伯特的一位同事指控他在未经文森特同意的情况下为其实施变性手术时，文森特证实他/她是自愿参与的；但当罗伯特试图与薇拉/文森特进行最初看似双方自愿的性行为时，对方夺走罗伯特的枪，杀死他并逃脱，我们意识到，就像罗伯特一样，我们也被文森特作为模拟者的技巧所愚弄。文森特从未认同薇拉，从未与囚禁他的罗伯特建立情感纽带。相反，文森特只是在战略上谋划，等待反击的最佳时机。影片最后，文森特回到母亲身边，重夺他作为儿子的身份。

罗伯特的手术使文森特变成了一个模拟体。经过六年的切割与移植，他/她看起来和听起来都像罗伯特已故的妻子——但并非是她。阿尔莫多瓦的电影告诉我们，身份的本质远不止皮肤深处。在虚构中，文森特当然不是薇拉；他只是一个模拟者，仅假装接受薇拉的角色。关键情节的转折点在于这一至关重要的差异：在内心深处，文森特不是薇拉，也永远不可能成为薇拉。罗伯特无法用文森特的血肉拼凑出他已故的妻子，因为他永远无法从这个女人身上抽离那个男人的记忆与痛苦。

模拟永远不可能成为其模型。大多数当代模拟是数字产物——而非血肉之躯的滔天罪行。尽管如此，正如文森特与薇拉存在关键差异一样，任何数字模拟总是包含一组关键差异，将其与模型分隔开来。

在虚构作品中，阿尔莫多瓦这种怪诞的模拟更多是常态而非例外。至少自玛丽·雪莱的《弗兰肯斯坦》^([2](#chapter_2.xhtml#chapter2-2)) 以来，模拟体不及其模型这一故事就被反复讲述。这些故事通过让熟悉的事物变得陌生来吓唬我们：文森特长得像薇拉但不是她。弗兰肯斯坦博士的造物长得像人但却是怪物。在哲学美学中，有一个词专门形容这种恐怖感。西格蒙德·弗洛伊德称之为“诡异”。^([3](#chapter_2.xhtml#chapter2-3))

## 物神崇拜与否认

但如果我们认出了模拟与模型之间的关键差异，却表现得仿佛没有实质性差异存在，会怎样？弗洛伊德对此有一个另一个术语：“物神崇拜”。^([4](#chapter_2.xhtml#chapter2-4)) 物神崇拜者能够知晓模拟与模型的差异，同时却相信它们是同一回事。物神崇拜者说，我非常清楚这些差异，但我将视而不见。根据弗洛伊德的说法，这是一种与“否认”紧密相关的状况，在否认中，我们拒绝承认一个创伤性事件。罗伯特就是一个物神崇拜者。他非常清楚文森特不是薇拉，但他否认自己那些创伤性的犯罪和手术干预，以便活在一个幻想中，想象他的前妻薇拉已转世重生。

在弗洛伊德时代很久以前，创造或执行模拟的人就被指控为不道德行为。在古希腊，柏拉图因诡辩学派实践修辞学的方式——作为一种虚假表征——而指责他们是模拟的实践者。“模拟”在成为现在这样——科学、工程和数学中一项体面的追求——之前，已经是一个贬义词数千年了。
