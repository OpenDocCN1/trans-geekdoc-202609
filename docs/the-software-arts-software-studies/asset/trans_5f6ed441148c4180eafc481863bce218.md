
此外，沃尔弗拉姆声称，由于使用这种形式系统构建的模拟产生的视觉输出看起来像自然发生的行为（生物、人类社会动态、化学反应、物理力学等），因此用这种发明的形式系统编写的计算机程序可以说表现出相同的行为。

最后，当他坚持认为行为就是行为，与其物质性无关，并且生命、宇宙和万物实际上只是巨大的黑白方块矩阵，换句话说，就是一个巨大的图灵机时，他做出了一个巨大的飞跃，陷入了物质性无关紧要的意识形态承诺中。^([112](#chapter_6.xhtml#chapter6-112))

希望你明白，我不认为这是一个无懈可击的论证。我确实认为这是一种有趣的修辞形式，但这种溯因演示充满了裂痕和漏洞。例如，仅仅因为一种形式语言不是图灵完备的，并不意味着它应该被一种图灵完备的语言所取代。（在第7章关于语法的内容中，我们将探讨用于判断图灵完备语言是否确实可取的一些标准。）

接下来，即使选择了一种图灵完备的语言，沃尔弗拉姆偏爱的黑白方块也不一定是最佳的形式语言选择。为什么不用 C++ 或 Python？

此外，正如我已经断言的，图灵完备性的证明并不是一个决定性的论据，证明一种语言在任何超出“可用于模拟任何图灵机”的意义上都是通用的。而且，仅仅因为某物看起来像另一物，并不意味着它就是那另一物。即使我看起来很像我的表亲，我也不是我的表亲。

我要提到的最后一个异议与倒数第二个有关：物质性并非非物质的。闪光的不都是金子。^([113](#chapter_6.xhtml#chapter6-113)) 尽管如此，不仅沃尔弗拉姆，许多复杂系统理论家、数字哲学家、数据科学家和信息可视化专家都在进行遵循此处概述的一般模式的论证。

## 越界的沃尔弗拉姆

正如古代几何学家（根据奈茨的说法）有他们的正确演示规则（受限语言和严格关注图表作为指标而非表征），溯因演示者同样有他们自己的游戏规则。当这些隐性规则被打破时，社区对这些规则的投入会突然显现出来。

当沃尔弗拉姆接着说：“我花了将近二十年的大部分时间来构建所需的智力结构，但我对其结果感到惊讶。因为我发现，有了我开发的这门新科学，突然有可能在一系列从未被任何现有科学成功解决过的根本问题上取得进展。”^([114](#chapter_6.xhtml#chapter6-114)) 时，他在其书的开头打破了两条预设规则。

此处打破的第一条规则，是大多数科学、工程和数学写作惯例所共有的：“不要用第一人称写作。”第二条规则拥有同样广泛的共识：“不要假装一切都是你自己发明的：要引用他人的工作。”^([115](#chapter_6.xhtml#chapter6-115))

通过打破这些不成文的规则，沃尔弗拉姆让他的科学和数学同行们抓狂。卡内基梅隆大学教员科斯马·沙利齐将他对沃尔弗拉姆的挫败感直接发泄在了他对《新科学》（NKS）的书评标题中：“怪诞自大与彻头彻尾疯狂的罕见混合体。”^([116](#chapter_6.xhtml#chapter6-116)) 沙利齐在其光芒四射的标题后，跟进了一套详细且有据可依的反驳论证，但你无需读完标题以外的内容，就能理解沃尔弗拉姆的语言有多么煽动性。

没有其他书评的标题像沙利齐的那样风趣，但许多在实质上同样严厉。例如，《科学美国人》刊登了如下评论：

“《新科学》在我熟悉的所有计算机科学和物理学领域的影响基本上为零，”[德克萨斯大学奥斯汀分校理论计算机科学家斯科特·阿伦森]说。“就我所见，主要影响是人们现在有时用‘沃尔弗拉姆式’这个形容词来形容对琐碎或众所周知的事物提出的惊人主张。”[马丁]·戴维斯[阿隆佐·丘奇的前学生、《通用计算机：从莱布尼茨到图灵之路》的作者，本书第2章和第5章均有引用]则给出了一个乐观得多的评价：“这本书有很多漂亮的图片。”^([117](#chapter_6.xhtml#chapter6-117))

沃尔弗拉姆与许多同事共享的一种罪过——因此很少被提及——可以称为“命名式论证”。计算机科学家德鲁·麦克德莫特尖锐地批评了人工智能子领域特有的这种坏习惯。麦克德莫特称之为“人工愚蠢”，并指出了诸如在程序中将一个子程序命名为“learn”（学习），然后循环论证该程序会学习，因为它有一个叫“learn”的子程序之类的做法。^([118](#chapter_6.xhtml#chapter6-118))

为了不在本书中助长愚蠢，直到现在我才告诉你，沃尔弗拉姆和其他人称他们偏好的计算底层不是“黑白方块”，而是“元胞自动机”。元胞自动机起源于约翰·冯·诺依曼在20世纪40年代为寻找自我繁殖细胞生物的形式模型所做的努力。从那时起，元胞自动机就一直被研究，许多有趣的结果由许多人发明。^([119](#chapter_6.xhtml#chapter6-119)) 沃尔弗拉姆之所以惹恼同行，部分原因在于他不承认这么多人对这一长期存在的领域的贡献，反而假装一切都是他自己发明的。

让我澄清一下：我并不反对对元胞自动机的研究。我反对的是沃尔弗拉姆等人提出的那些肤浅的论证，大概是这样的：“元胞自动机是生物活细胞的好模型，因为我们给它们起名叫‘元胞’。”在他的书中，沃尔弗拉姆大量使用这种“命名式论证”，不仅用于“细胞”，也用于“行为”（屏幕上的图案被称为“表现行为”，因为他说它们表现行为），以及许多其他社会、生物和物理现象。

我指出沃尔弗拉姆文本中采用的这些各种非演示性修辞策略（即第一人称叙述的使用、缺乏引用、以及命名式论证），是为了更清晰地将这些“伎俩”与溯因演示的核心区分开来，后者是一种由越来越多的科学家、记者、艺术家和人文主义者共享的新说服形式。^([120](#chapter_6.xhtml#chapter6-120)) 去除他的怪癖和非演示性夸张后，沃尔弗拉姆的书提供了一个关于溯因演示如何被执行和铭刻的启发性概述。沃尔弗拉姆将公认的演绎和归纳演示形式与新的溯因演示形式——尤其是图形演示——联系了起来。

## 陈述与规则即图像

当我们审视沃尔弗拉姆的演示时，将密切关注他是如何将读者与他的图形联系起来的。你应该能在他的图表中看到什么，从而被演示给你什么？

沃尔弗拉姆的图形设计策略类似于我们在第4章讨论算术算法时已经看到的那些。然而，虽然第4章讨论的元胞自动机是二维的，沃尔弗拉姆的是一维的。值得注意的是，这种简化形式仍然可以构成一个图灵完备的形式系统，也许更引人注目的是，这种简化允许将计算历史图形化地表示为单个图像，而不是一系列图像。
