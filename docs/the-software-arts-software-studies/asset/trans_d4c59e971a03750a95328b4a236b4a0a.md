

# 算法传入欧洲

随着关于印度数字系统的穆斯林学术文本被翻译，算法传入了欧洲。这些文本中包括波斯学者穆罕默德·伊本·穆萨·花拉子密（Muḥammad ibn Mūsā al-Khwārizmī，780–850 年）编写的关于十进制数及其计算方案的算术入门书，他的姓氏构成了单词“algorithm”（算法）的词源起源。花拉子密的算术书在西班牙被收集，并由一位名为罗伯特·切斯特的英国人翻译成拉丁文，题为 *Algoritmi de numero indorum*^([25](#chapter_4.xhtml#chapter4-25))（意为“切斯特翻译的花拉子密论印度数字”，其中“Algoritmi”是切斯特翻译的“al-Khwārizmī”）。

## 十进制制 vs. 罗马数字

当时新出现的印度数字表示法就是我们今天所知道的无处不在的日常十进制制。回顾一下，之前的表示法是罗马系统：I, II, III, IV, V, VI, VII, VIII, IX, X 等。^([26](#chapter_4.xhtml#chapter4-26)) 采用十进制制使算术变得更简单、更不易出错。例如，考虑在罗马系统中用十乘以一个数字；比如，IV 乘 X 等于 XL。而在十进制定点位置记数法中做同样的运算相比之下微不足道：4 × 10 = 40。在十进制制中，只需在要乘以十的整数右侧加一个零即可。相反，在罗马系统中，所有算术运算都需要分组、排列，然后重写。

## 算法与商业资本主义

在商业资本主义诞生之际，店主的算术变成了算法问题，而非算盘问题，因此，十进制制算法的优势最终超越了算盘被感知的威力。来自整个欧洲的年轻人来到威尼斯学习对资本主义至关重要的新算法。随着这些算法越来越普及，计算学校在威尼斯以外的许多城市建立起来。1338 年，佛罗伦萨有六所此类学校；到 1613 年，纽伦堡市已有四十八所。^([27](#chapter_4.xhtml#chapter4-27))

## “算法”定义的演变

直到十九世纪，“算法”定义中被认为必不可少的仍是十进制数字表示法的使用。这在《牛津英语词典》中有记载，在“algorithm”词条下的第一个定义是“以零为特征的阿拉伯计数系统”。第二个定义是“数学与计算。用于计算和解决问题的过程或规则集；……执行特定任务的精确定义的数学或逻辑操作集。”第二个定义的例子始见于十九世纪的文本。^([28](#chapter_4.xhtml#chapter4-28))

## 算术的历史视角

从历史角度来看，很明显，算术从柏拉图时代，到十五世纪的威尼斯，再到十九世纪，然后又随着硬件和软件的发展进入二十世纪，经历了多次变革。此外，即使在任何特定的历史时刻，我们也能找到两种或更多不同种类的算术运算。

## 算术与工业资本主义

虽然算术对商业资本主义至关重要，但它在十九世纪工业资本主义的兴起中变得更为重要。在这一时期，算术发生了两项开创性的变革。

首先，将工作和劳动重新转化为一种可用定量术语衡量和估算的格式，对于阐明劳动和资本如何通过货币联系起来至关重要。完成某项工作需要多少成本？资本家投资昂贵机械以取代人力劳动者是否值得？将劳动重新转化为定量形式——一种将其归结为单一数字的形式——就是第 3 章所述建筑、蒸汽机和信息技术的工作/劳动语言。

其次，不仅是工业上的，也是认识论上的转变，将扩展形式的算术置于许多先前截然不同的知识学科的中心。在数学和逻辑史上，这一转变被称为“算术化”，是数学基础的一个研究计划。^([29](#chapter_4.xhtml#chapter4-29)) “算术化”在很大程度上塑造了二十世纪数学和逻辑的许多重要发展，包括图灵 1936 年的论文。

# 算术化

一个知识学科经历“算术化”意味着什么？这种翻译的结果有二：算术被扩大了；一个先前与数学无关的主题被纳入数学的庇护之下。

## 布尔的逻辑代数

数学家乔治·布尔将逻辑转化为算术的工作为一个学科如何被重写——翻译——为算术提供了很好的例证。在他的 1854 年著作《思维规律研究：建立数理逻辑与概率理论的基础》（*An Investigation of the Laws of Thought on Which Are Founded the Mathematical Theories of Logic and Probabilities*）中，布尔提出了一种以算术或代数形式书写逻辑表达式的方法。^([30](#chapter_4.xhtml#chapter4-30)) 布尔逻辑基于这样一个假设：每个表达式的值要么是零（即“假”），要么是一（即“真”）。布尔逻辑表达式可以包含变量（如 `a`、`b`、`c`）、恒等号（`=`；即等式）以及三个算术运算符的翻译（`+`：加法；`−`：减法；`×`：乘法）。

根据布尔的说法，如果 `a` 表示“所有白色的东西”，`b` 表示“所有羊”，则 `a` 乘以 `b` 表示“所有白羊”，可写作 `ab` 或 `ba`，因为 `ab = ba`。如果 `a` 代表“男人”，`b` 代表“女人”，则 `a + b` 可理解为“男人和女人”或“男人或女人”。如果 `c` 代表“欧洲人”，则 `c(a + b) = ca + cb`。换句话说，乘法分配律被翻译用于逻辑，使得“欧洲男人和女人”等同于“欧洲男人和欧洲女人”。类似地，表达式 `a − c` 可读作“所有非欧洲男人”。布尔指出：“‘不在 `a` 中的事物类’可写作 `(1 − a)`。如果 `a` 表示‘男人’，则方程 `a(1 − a)` 将代表其成员既是‘男人’又是‘非男人’的类，……从而表达了这样一个原则：成员同时是男人和非男人的类不存在。换句话说，同一个体不可能同时是男人和非男人。”

布尔继续写道，

> 现在让符号 `a` 的意义从表示“男人”扩展到表示具有任何性质的任何类存在；那么方程 `a(1 − a) = 0` 将表达一个存在不可能同时拥有某种性质又不拥有该性质。但这正是亚里士多德描述为所有哲学基本公理的“矛盾律”。“同一性质不可能同时属于和不属于同一事物。……这是最确定的一切原则。……因此，证明者将其作为最终意见引用。因为它本质上是所有其他公理的源泉”（《形而上学》，III, 3）。^([31](#chapter_4.xhtml#chapter4-31))

亚里士多德的“矛盾律”传统上是他的三条“思维定律”中的第二条。其他两条是第一定律，同一律：一切与其自身相同 `a = a`；第三定律，排中律：一切要么具有某种性质，要么具有该性质的否定，用布尔的符号表示为 `a + (1 − a) = 1`。此外请注意，布尔的代数符号允许将条件语句——“如果 `a` 则 `b`”——重写为多项式：`a(1−b) = 0`。
