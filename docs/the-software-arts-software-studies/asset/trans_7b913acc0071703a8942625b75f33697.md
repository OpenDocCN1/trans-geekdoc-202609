

因此，这是将面临的主要摩擦之一。从事翻译实际工作的人，怎么可能相信一个非形式化的概念能够毫无损失或增益地翻译成一个精确的形式化定义？这种信念要求第二种信念，即相信存在一种“完美语言”^([50](#chapter_2.xhtml#chapter2-50))，一种只能给出必要、充分且真实定义的语言。

从这个角度来看，翻译成“完美语言”能够阐明一个概念，即使不完美语言之间的翻译做不到这一点。历史上曾考虑过许多种“完美语言”，包括莱布尼茨的“实在特征”、数学（更广泛地说），以及《圣经》第一卷中所述亚当所说的原始语言。

我的观点是，如果不相信完美语言的存在，甘迪和索尔的论点就是胡扯，但我不会反驳完美语言的存在。相反，我想说明这种世界观、这种意识形态，如何与其他不承认完美语言的世界观发生冲突。我还想提出，存在一些新的混合思维形式，它们不能完全归入这种二元对立的框框之中。我的目的在于建设性和比较，而非禁令；我的目标是富有成效的，让我们能更好地发明和创新。

## 意识形态的定义

为了比较世界观，我提供一个关于“意识形态”相对简单的描述。法国大革命后，安托万·德斯蒂特·德·特雷西创造了“意识形态”一词及其实践，以批判性地审视革命后法国的观念。^([51](#chapter_2.xhtml#chapter2-51)) 在其诞生之时，意识形态并非贬义词。相反，特雷西所谓的意识形态，是观念的科学或研究，正如我们理解社会学是一门社会科学、生物学是一门生命科学一样。我们需要研究观念，特别是它们在数字化的、尤其是软件方面的折射。我们将审视“计算机革命”中的一些关键观念，但不为它们背书。如果这种方法在法国大革命后奏效，或许它对“计算机革命”也同样有效。

当然，今天“意识形态”一词常被用作贬义词。当一个人说“哦，那只是意识形态”时，往往不妨直接说“那是不真实的”、“那是对世界的扭曲描绘”或“那是不科学的”。即使在关于意识形态的专业人文学文献中，该词往往意指“虚假意识”。然而，也存在其他各种有用的意识形态定义。^([52](#chapter_2.xhtml#chapter2-52))

我将使用一种作为符号学闭合的意识形态定义，这是一种由文学理论家弗雷德里克·詹姆逊等人讨论的理论。^([53](#chapter_2.xhtml#chapter2-53)) 根据这一定义，意识形态是一种关于社会、经济和政治关系的特殊观念体系——这些观念规范并表征个人、制度、群体及其相互关系。因此，原则上任何观念都可能成为意识形态的一部分，因为任何观念都可能影响某种关系。正如许多科学史家所展示的，即使是关于晦涩科学技术细节的观念，也能被证明具有意识形态性。然而，在实践中，只有所有观念的一个子集在特定的意识形态研究中才具有重要意义。哪些观念受关注，取决于所研究的个人、制度和群体。因此，关于亚原子粒子数量和类型的信念，可能在特定历史节点上通过争议清晰地划分某一群物理学家，但对于探索同一历史时刻的另一群体（例如一群职业棒球运动员）的社会结构则毫无用处。

在关于作为符号学闭合的意识形态的讨论中，弗雷德里克·詹姆逊探讨了等价术语的发展，但也特别是探讨了各种非等价形式，它们构成的关系集合比单纯的二元对立更大。詹姆逊在讨论中使用了一种称为格雷马斯对立方阵的图表——以法裔立陶宛符号学家和文学理论家阿吉尔达斯·朱利安·格雷马斯命名，他发展了行动者-网络理论中所采用的那种符号学。该方阵也被称为亚里士多德方阵。它描绘了四个命题之间各种形式的对立。

该方阵区分了两种不同的非等价性——反对和矛盾。如果我们从一个形容词入手——比如说白色——它的矛盾是它的否定，即非白色，但它的反对面可能是黑色。矛盾和反对不是一回事。例如，非白色作为一个范畴包含黑色，但它不等同于黑色，也不*仅*等同于黑色。

这些方阵的使用还有更多微妙之处，詹姆逊的讨论将其揭示出来。^([54](#chapter_2.xhtml#chapter2-54)) 然而，就我们的目的而言，关键点在于：正如存在多种等价形式一样，也可以枚举多种非等价形式，而作为作为符号学闭合的意识形态的一种表征，该方阵展示了一个观念体系如何封装一组等价与非等价术语，以及一种枚举它们的方式——一种难以甚至不可能超越思考的方式。

正如我在介绍米歇尔·塞尔的各种“引导”和翻译术语时所做的那样，这里我也必须坚持区分对立方阵的隐喻用法和历史用法。历史上，亚里士多德的对立方阵，以及更普遍的他的逻辑体系，早已被各种其他逻辑形式所覆盖，其中一些我们将在本书后面看到。用今天的技术语言来说，更准确的说法是亚里士多德的逻辑局限于`命题`，而我的讨论将涉及需要更复杂的`谓词`逻辑来建模的陈述。因此，我将把作为对立方阵的意识形态观念作为一种隐喻而非模型来使用。

作为一种隐喻，这种意识形态形象凝结了几个关键问题。在一种给定的意识形态中，什么被视为等同、相等或同一？什么与什么对立？等价与对立是如何被概括和生成的——即被翻译的？在比较和对比一种意识形态与另一种意识形态时，将特别关注那些在一种意识形态中是等价、在另一种中却是对立的事物。

## 引入：论被引入科学

现在让我们从这段关于意识形态的间奏中回到我们正在进行的故事。请记住，甘迪和索尔都认为，一个非形式化的概念可以等同于一个形式化的数学定义，而且，从前者到后者的翻译方法是一种数学证明，即图灵 1936 年的论文。这是故事前半部分的特征描述，即从科学“外部”到“内部”、从非形式化到形式化精确的那部分故事。若将其描述为一种“移动”，持特定哲学倾向的人会说，图灵的工作根本不是一种移动或翻译，因为形式化定义从一开始就内在于非形式化概念之中。
