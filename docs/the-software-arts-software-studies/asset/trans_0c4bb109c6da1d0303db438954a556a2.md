
# 逻辑是正确思维的艺术

逻辑是正确思维的艺术，或者说是以一种适合我们理性官能的方式运用思维，用于定义、划分和推理。该词源自希腊语 λόγος，译为拉丁语是 *sermo*，在[英语]中是 discourse（言谈/论述）。这是因为思维是一种内在的、心智的言谈，在其中心智与自身对话。逻辑常被称为辩证法…… 要正确思维，必需感知、判断、言谈，并有条理地将自己的观念联系起来；因此，感知、判断、言谈和方法是逻辑艺术的四个基本方面。我们对心智这四种运作的反思构成了逻辑。…… 培根勋爵将逻辑分为四部分，即我们在此提出的同四部分。^([21](#chapter_5.xhtml#chapter5-21))

百科全书派用“运作”的工作语言描述逻辑，尽管逻辑推测远离诞生这种工作语言的工匠作坊。这种开篇语言似乎表明逻辑将被作为一门艺术来讨论。但在同一条目后面，问题被明确提出：逻辑是一门科学还是一门艺术？

考虑到百科全书派对培根著作的推崇，他们似乎会宣布，鉴于培根的改进，逻辑应被称为一门科学。正如第 3 章所述，培根的《新工具》被视为经验科学的奠基文献，也是后来被称为“科学方法”的一种归纳形式的首次描述。培根批评了逻辑的当代状况，并提议用他（语法层面的）归纳法来取而代之。^([22](#chapter_5.xhtml#chapter5-22))

但百科全书派并没有简单地称逻辑为科学，而是为其作为一门艺术的属性辩护：“但它是一门艺术吗？…… 这取决于你赋予‘艺术’一词何种含义。一些人只想称客体为物质的东西为艺术。另一些人则愿意称任何一种习得的、用以实施运作（无论是精神的还是肉体的）的倾向为艺术——依据规则或反思。”^([23](#chapter_5.xhtml#chapter5-23)) 就逻辑可用运作的词汇来描述而言，它似乎算作一门艺术。

无论他们在将逻辑归类为艺术还是科学上与培根有何分歧，百科全书派都与他一同哀叹当代逻辑的悲惨状况：

> 它已陷入名誉扫地的状态。…… 逻辑从来不过是一门词藻的艺术，这些词藻常常毫无意义，却惊人地擅长掩饰无知而非完善判断；擅长玩弄理性而非强化理性；擅长歪曲真理而非阐明真理。据称其基础由埃利亚的芝诺奠定。…… 众所周知，古代诡辩学家立志永不露怯、永不措手不及，并能同等熟练地为各种课题正反辩论。他们在辩证法中发现了实现这种熟练的巨大资源，并将其全部据为己用。这荒谬的遗产在经院学者手中并未荒废，他们比古代前辈进一步丰富了它。普遍范畴和其他博学的琐碎之谈是逻辑的本质，也是关于逻辑的一切反思和争论的本质。这就是从其起源直到上个世纪[十七世纪]的逻辑状况，因此它陷入如此轻视之中，以至于人们至今仍不愿回归它。且真必须承认，当今学校对待逻辑的方式进一步助长了许多人至今仍对这门科学的轻视。^([24](#chapter_5.xhtml#chapter5-24))

尽管如此，《百科全书》条目指出逻辑的名声在十七世纪有所改善，这归功于笛卡尔：

> 笛卡尔，这位推理的真正复兴者，首创了一种新的推理方法，其价值远胜于他的哲学，后者多有谬误或极不确定，即便按他自己制定并传授给我们的规则来判断也是如此。我们不仅在物理学和形而上学，而且在宗教、道德推理和批评中所享有的精确性和准确性，都归功于他。总的来说，笛卡尔的原则和方法大有裨益，使我们习惯于精确地分析词语和观念，从而引领我们走上真理之路。…… 笛卡尔的方法孕育了被称为思维艺术的逻辑。^([25](#chapter_5.xhtml#chapter5-25))

因此，《百科全书》中叙述的逻辑史是这样一段历史：逻辑与辩证法作为同义词延续了几个世纪，并由一套对话和推理技术定义，这些技术始于（芝诺），走向毁灭，随后由笛卡尔复兴，并使其立于坚实基础之上。条目中叙述的历史显然带有偏见：百科全书派不掩饰对芝诺著作的鄙视（“这荒谬的遗产”）或对笛卡尔的崇敬（“推理的真正复兴者”）。

## 逻辑、辩证法与三艺作为思想流派

《百科全书》条目将辩证法与逻辑区分开来，并将前者的创立归功于芝诺，后者的创立归功于笛卡尔。这种谱系或渊源最好结合启蒙运动前时期——早期现代时代、经院学者时代——对辩证法和逻辑的理解来语境化。那时，三艺——语法、修辞和辩证法——并非指三个专门的研究课题。相反，每一个都是一个强大的思想流派，在认识论和政治的竞争中与其他流派针锋相对。

马歇尔·麦克卢汉总结了三艺三个流派竞争的历史。从诡辩学家时代起，辩证法就与修辞学相抗衡，柏拉图和亚里士多德主张辩证法应主导修辞学。随后语法学获得霸权，直到十一世纪杰尔贝尔复兴辩证法。但在十五世纪，以伊拉斯谟的工作为高潮，语法和修辞重新获得了对辩证法的主导权。尽管如此，辩证法与修辞的竞争仍在继续，其后果远远超出学校的范畴。用麦克卢汉的话说：“这些文学阵营之间的战争基本上是辩证法与修辞为控制文学创作模式而进行的对立；这种对立的影响延伸到伦理学和政治学领域，无论在古代还是文艺复兴时期皆是如此。”^([26](#chapter_5.xhtml#chapter5-26)) 麦克卢汉的三艺史止步于莎士比亚时代，但辩证法、修辞学和语法学之间的竞争延续到了十八世纪、百科全书派的时代，甚至可以说延续至今。

《百科全书》条目结合三艺史，为我们提供了一种外生手段来区分逻辑与辩证法：它们可被视为敌对的流派或智力传统，即使它们在语言和文学创作的同一疆域上角力。这种外生区分补充了前文讨论的几种内生区分逻辑与辩证法的方式：(i) 沃尔特·翁认为辩证法是一种口头实践，而逻辑是识字使然的实践；(ii) 叔本华认为逻辑是一种孤独的思维形式，而辩证法只有在两人或以上时才可能；(iii) 麦克卢汉依据亚里士多德，声称两者的区别主要取决于它们所应用的主题；(iv) 福柯的“笛卡尔时刻”和显而易见的带有偏见的、笛卡尔式的《百科全书》条目引入了第四种可能的区分：逻辑是一种可靠的计算方法，而辩证法是一种无原则的修辞形式。
