

Google 研究总监 Peter Norvig 撰写了一篇长文回应，论证科学与工程是共同发展的，文中指出：“工程上的成功表明某事物运作正常，因此它是科学模型成功的证据（但不是证明）。”^([123](#chapter_7.xhtml#chapter7-123)) Norvig 接着坚称这些巨型系统是可以被理解的：“我同意，理解一个包含数十亿参数的模型可能很困难。当然，人类无法通过单独检查每个参数的值来理解这种模型。但人们可以通过考察模型的属性——它在哪里成功、在哪里失败、作为数据函数的学习效果如何等——来获得洞见。”^([124](#chapter_7.xhtml#chapter7-124))

从本质上讲，Chomsky 认为这不是科学——也不是理论——因为它没有告诉我们语言为何以这种方式运作。Norvig 则辩称这确实是工程，但工程为科学提供了行之有效的模型，因此它解释了语言*如何*运作，即使它不解释语言*为何*如此运作。

Chomsky 与 Norvig 的分歧似乎在所难免。Chomsky 将自己的职业生涯置于 Galileo 和 Descartes 的传承之中，坚持认为统计学在语言学中没有立足之地，并反复否认归纳学习的可能性^([125](#chapter_7.xhtml#chapter7-125))，这样的人必然会反对将归纳性统计学习算法的输出（一个拥有数十亿参数的“方程”）视为一种理论。此外，当在 Chomsky 精心构建的形式语言层级标准下审视时，拥有数十亿参数的软件简直是异类。Chomsky 本质上是在重演十七世纪自然哲学家的角色，对他们而言，演绎是唯一可接受的证明形式。

相比之下，Norvig 扮演的是机器哲学家的角色，通过一种新形式的归纳来展示成果。他清楚地表明，他将自己的工作视为一条悠久科学研究传统（可追溯至 Boyle）的延续，该传统采用统计学、概率论和归纳演示。

Chomsky 与 Norvig 之间的这种分歧是不可避免的，但在我看来，最终它也是无关紧要的。当 Chomsky 和他的那一代人宣称理论应采用软件的形式时，他们改变了什么可被视为知识的规则。Noam Chomsky、Herbert Simon、Allen Newell 等人编写了小型软件，而如今这一代人——Peter Norvig 等人——编写源自大数据的庞大软件，这看起来更像是数量上的差异，而非真正的质变。当今的“范式”、当代的“计算认知框架”，是由 Chomsky 和他的那一代人开启的，我们至今仍乘坐在这艘船上。

## 算术理论

大数据会带来巨大差异吗？有人会说，过去的计算与现在的计算有着巨大差别，因为现在许多大公司和民族国家都能获取海量数据。毫无疑问，大数据——尤其是对 Google 这类数据富豪而言——提供了一组新的机遇^([126](#chapter_7.xhtml#chapter7-126))，但正如记者 Chris Anderson 在 2008 年 6 月 *Wired* 杂志的一篇社论“The End of Theory: The Data Deluge Makes the Scientific Method Obsolete”（理论的终结：数据洪流让科学方法过时）中所宣称的那样，大数据是否预示着理论的终结？^([127](#chapter_7.xhtml#chapter7-127)) Anderson 宣称：“如今，Google 等在海量数据时代成长起来的公司，不必再将就错误的模型。事实上，它们根本不必将就模型。”^([128](#chapter_7.xhtml#chapter7-128)) 这一评论只见树木不见森林。大故事不关乎数据本身。它关乎那些梳理海量数据并从中发现模式的机器学习算法背后的理论。我们并未到达“理论的终结”。相反，我们需要认识到，计算理论正采取极其简化的形式。

在前文考察的 Google 论文标题中，出现了“Neural Machine Translation”（神经机器翻译）一词。这指的是一种用于“神经网络”的机器学习技术，但请注意，此刻（2018 年）神经网络（或“深度”）机器学习惊人地流行，并经常出现在 *The Economist*（经济学人）和 *New York Times*（纽约时报）等非技术性大众出版物上。

这些“神经网络”，也称为“多层感知器”，究竟*是什么*？切记，尽管神经科学家对逻辑电路感兴趣，数理逻辑学家至少自 1943 年 Warren McCulloch 和 Walter Pitts 发表关于用逻辑电路模拟神经网络的论文以来就对神经元感兴趣^([129](#chapter_7.xhtml#chapter7-129))，但这些东西与神经科学几乎没有任何关系。

在外行眼中，很难理解为何有人能在任何实际的生物生命系统中找到神经网络的计算形式，因为在其最简单的形式下，它只是输入的加权求和。输入为 `x[1]` 到 `x[d]`；权重为 `w[1]` 到 `w[d]`；求和符号（`Σ`）表示将每个 `w[j]x[j]` 的乘积相加：^([130](#chapter_7.xhtml#chapter7-130))

![](images/Ch07_EQ_001.png)

前述求和式即是理论如今的模样。如果你更喜欢代码形式，这是 JavaScript 版本：

```
var y = 0; for (var j = 1; j <= d; j++) {y = y + (w[j] * x[j]) + w[0];}.
```

当求和中的权重被上调或下调时，“机器学习”就发生了。简而言之，这里的重大新闻在于，甚至“学习”也已成为一种算术形式，而这种算术形式目前构成了从计算语言学到搜索引擎再到自动驾驶汽车等一切事物的概念框架。算术是新的万物理论。^([131](#chapter_7.xhtml#chapter7-131))

不可思议的是，在计算认知框架中，理论是一种算术形式。但其理由是什么？理由并非这些理论能洞察世界为何是这个样子。不，这种形式下理论的理由——即测试标准——是：它管用吗？如果翻译称得上胜任，如果下棋达到大师水平，或者如果自动驾驶汽车能合法、无事故地导航，那么该机器学习理论就被认为是好的。

计算认知框架的标志性重大转变在于：当前的理解认为，理论与诠释如今是在追求“如何做”的知识过程中被构建出来的，而不再是为了寻找“为何”的答案。在 Chomsky 博士的主导下，语法通过被重构为易于转化为可运行软件的机器语言，完成了这一转变。自那以后——正如我们所见——许多其他知识领域也经历了同样的转型、同样的转译。

如果我们接受 Norvig 的成功标准——“成功表明某事物运作正常”，我们还面临另一组问题。软件/理论为谁而工作？在什么情况下？以谁为代价？这些问题将我们带回第 3 章关于工作与机器语言的关切。软件完成了谁的工作？谁的劳动被改变或消除了？因此，计算认知框架中的任何理论都预设了一种劳动与自动化的政治学。
