

# 细胞自动机规则集分析

我通过编写 JavaScript 代码来执行所有 256 个规则集，并在网页上显示它们各自的输出，从而复现了这一“实验”。^([122](#chapter_6.xhtml#chapter6-122)) 结果如[图 6.6](#chapter_6.xhtml#fig6_6)和[图 6.7](#chapter_6.xhtml#fig6_7)所示。规则集按从左到右、从上到下的顺序列出，每个结果上方都显示了相应的规则集编号。因此，例如，在倒数第二个图形（看起来像一个黑色三角形）的正上方，应该能看到“254”。

仔细观察[图 6.6](#chapter_6.xhtml#fig6_6)和[图 6.7](#chapter_6.xhtml#fig6_7)，可以注意到还有一个黑色三角形（222）看起来与规则集 254 的完全一样。还有一些较小的黑色三角形（例如 206、220、252）。可以看到还有其他三角形不是黑色的，但它们包含非常简单的重复模式（例如 28、50）。^([123](#chapter_6.xhtml#chapter6-123))

有些规则集产生的结果甚至更简单。给定初始状态中只有一个黑色方块，规则集 4 和 12 等会产生一条垂直线。^([124](#chapter_6.xhtml#chapter6-124)) 规则集 2 和 6 等会产生一条简单的对角线。^([125](#chapter_6.xhtml#chapter6-125))

有些规则集生成稍微复杂一些的模式，例如条纹背景上的垂直线或对角线（27、35、43、51、59 等）。然后是最无聊的规则集，它们只产生完全空白或完全黑色的画布，例如 0、8 和 32。^([126](#chapter_6.xhtml#chapter6-126)) 稍微不那么无聊的，或许是那些只产生条纹的规则集，例如 7 和 19。^([127](#chapter_6.xhtml#chapter6-127))

还要注意，许多规则集在给定只有一个黑色方块的初始状态时，会生成嵌套模式。规则集 18、22、26 和 60 就是例子。^([128](#chapter_6.xhtml#chapter6-128))

迄今提到的大多数规则集都是斯蒂芬·沃尔弗拉姆所谓的“1 类”或“2 类”。什么是 1 类规则？沃尔弗拉姆告诉我们，无论初始状态是简单（例如此处使用的、有且仅有一个黑色方块、其余为白色的初始状态）还是复杂（例如随机的黑白方块序列），执行 1 类规则都会产生简单的模式。^([129](#chapter_6.xhtml#chapter6-129))

根据沃尔弗拉姆的说法，执行 2 类规则可能产生许多不同的模式，“但它们都仅由一组特定的简单结构组成，这些结构要么永远保持不变，要么每隔几步就重复一次。”^([130](#chapter_6.xhtml#chapter6-130))

在沃尔弗拉姆的 3 类中，产生的模式据说更为复杂，“在许多方面看起来是随机的，尽管三角形和其他小尺度结构在本质上总能在某个层面上被看到。”^([131](#chapter_6.xhtml#chapter6-131))

最后，“4 类涉及秩序与随机性的混合：会产生局部结构，这些结构本身相当简单，但它们会移动并以非常复杂的方式相互作用。”^([132](#chapter_6.xhtml#chapter6-132))

沃尔弗拉姆坚持认为，虽然 1 类规则集通常无论初始状态如何都产生相同的模式，但其他类别对初始状态更敏感；也就是说，给定不同的初始状态，它们会产生不同的结果。因此，显然，前几幅图中看起来像 1 类或 2 类的一些规则集，实际上并非如此。一些规则集（包括 22、90 和 126）从单个黑色方块开始会产生简单的重复模式，但从复杂的初始状态开始会产生复杂得多的模式。例如，规则集 22 从单个黑色方块开始，会产生[图 6.8](#chapter_6.xhtml#fig6_8)中的模式。

![Figure 6.8 ¶ Rule set 22 with one black square as input.](images/024_9495_006_fig_008.png)

[图 6.8](#chapter_6.xhtml#fig6-8) ¶ 规则集 22，输入为一个黑色方块。

但规则集 22 从由随机黑白方块序列组成的初始状态开始，并不会产生简单的、“2 类”式的重复模式。请看[图 6.9](#chapter_6.xhtml#fig6_9)。因此，沃尔弗拉姆指出规则集 22 不属于 2 类，而是属于 3 类。^([133](#chapter_6.xhtml#chapter6-133))

![Figure 6.9 ¶ Rule set 22 with a random series of black and white squares as input.](images/025_9495_006_fig_009.png)

[图 6.9](#chapter_6.xhtml#fig6-9) ¶ 规则集 22，输入为随机黑白方块序列。

在他的书中，沃尔弗拉姆反复声称，人们应该仅凭肉眼就能看出不同类别之间的差异。然而，对于某些规则集，当它们以简单的初始状态运行时，我们无法看到本应看到的东西；例如，对于规则集 22，我们被告知除非用更复杂的初始状态运行，否则无法看到真实的情况。因此，与之前的演示形式一样，如果没有指导，我们这些未受训练的大众，无法看到演示所要展示的内容。欧几里得的图表也是这种情况，博伊尔的空气泵也是如此。只有当公众愿意在向导的带领下参观现场，由向导讲解并指出何时看什么，演示才能展示其意图展示的内容。

只要我们自己查看所有 256 个规则集的执行轨迹，就会清楚地认识到，沃尔弗拉姆可见的“结果”并不开放给简单的肉眼检视。请再看一遍这些图形。在无人协助的情况下，你能看出沃尔弗拉姆坚称存在的四个不同类别吗？没有沃尔弗拉姆的叙述，我完全可能将这些图像分为两类、三类或二十类。以我之眼光，沃尔弗拉姆的四个类别并不显而易见。沃尔弗拉姆用一种新的演示形式来推进他的论点，我们被告知可以“亲眼看到”图像中的真理。然而，我们要观看的这些图像，就像这里的 256 张图像一样，是“技术图像”，^([134](#chapter_6.xhtml#chapter6-134)) 经过了大量计算的中介，因此根本不为肉眼所直接洞察。

继续沃尔弗拉姆的叙述，我们被告知，尽管 1、2、3 类可以产生一些有趣的模式，但沃尔弗拉姆最感兴趣的是第 4 类。他指出规则集 110、124、137、193，以及可能的 54 属于 4 类。规则集 110、124、137 和 193 彼此是变体。沃尔弗拉姆断言，我们可以通过比较它们的输出来看出这一点（如[图 6.10](#chapter_6.xhtml#fig6_10)所示）。

![Figure 6.10 ¶ The execution traces with one input of (a) rule set 110, (b) rule set 124, (c) rule set 137, and (d) rule set 193.](images/029_9495_006_fig_010.png)

[图 6.10](#chapter_6.xhtml#fig6-10) ¶ 单一输入下的执行轨迹：(a) 规则集 110，(b) 规则集 124，(c) 规则集 137，(d) 规则集 193。

沃尔弗拉姆写道：“任何 4 类系统的一个关键特征是，其中必须始终存在某些能够永久持续的结构。……移动结构的存在是 4 类系统的一个基本特征。……正是这些结构使得信息能够从 4 类系统的一个部分传递到另一个部分——并最终使 4 类特有的复杂行为得以发生。”^([135](#chapter_6.xhtml#chapter6-135))
