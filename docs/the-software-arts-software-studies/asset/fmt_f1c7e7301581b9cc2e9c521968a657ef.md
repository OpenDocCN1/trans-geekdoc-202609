
作为语言自由艺术（三学科）及其主要实践（其他语言原始文本的翻译与诠释）的汇聚点，翻译将成为本书的研究对象和分析方法。我们将考察当代翻译形式，以及它们如何被用于发展新的隐喻、新的等价关系，甚至新的身份认同。当代翻译形式与各种计算形式纠缠在一起，因此我们将这些新实践称为**软件艺术**。软件艺术是一种源于自由艺术与机械艺术耦合的计算实践。正如可以将科学和工程理解为源于工匠作坊的实践^[66](#chapter_1.xhtml#chapter1-66)一样，软件艺术则是将计算理解为一种源于艺术与人文学科的实践。

## 翻译与信息技术

此前，作为自由艺术实践的翻译，意味着一种不可避免地会从文本或信息中移除或添加信息的转换。相比之下，今天的信息与通信技术在开发时往往秉持一种理想：信息可以在翻译或传递过程中不丢失、不增添任何内容。在其构想与设计中，信息与通信技术旨在精确复现传输线另一端产生的内容。在其奠基之作《通信的数学理论》中，沃伦·韦弗和克劳德·香农这样阐述这一问题：“通信的根本问题在于，在某一点精确或近似地复现从另一点选取的信息。”^[67](#chapter_1.xhtml#chapter1-67) 在同一本书的其他地方，韦弗和香农指出，根据他们的理论，信息不被赋予任何意义。^[68](#chapter_1.xhtml#chapter1-68) 简言之，从工程视角来看，我们在发送电子邮件或使用网页时所从事的，是一种无意义的复制，它不顾及其社会和政治环境。这种无意义的模仿被视为通信的根本问题。

在工程术语中，信息与通信技术依据其在固定容量信道上无损推送比特的能力进行评价，即在“导线”这一端精确复现另一端记录的内容，而不涉及另一端“导线”上的环境。在古典哲学中，这种精确的重复有一个名称。不了解意义、语境或关联的重复被称为“模仿”，或者更具体地说，在柏拉图的著作中被称为“拟态”或“诡辩”。在题为《诡辩家》的苏格拉底对话录中，柏拉图指出：“有些模仿者知道他们所模仿的事物；其他人则不知道。…… 为了区分，让我们称由意见引导的模仿为‘自负的模仿’，称由知识引导的模仿为‘基于熟知的模仿’。…… 制造矛盾的技艺，源于一种不真诚的自负模仿，属于外观制造类，衍生自形象制作，……——这些血统和渊源，完全可以真实地归于真正的诡辩家。”^[69](#chapter_1.xhtml#chapter1-69)

换句话说，信息与通信理论中阐述的成功标准，恰恰是柏拉图眼中最糟糕的伦理与审美失败的标准。根据柏拉图的观点，这是将最恶劣的诡辩行为视为美德，甚至视为一种行之有效的技术的根本美德。^[70](#chapter_1.xhtml#chapter1-70) 基于这些理由，当代的信息、通信与计算理论和技术可以被称为“诡辩的”，我将在第6章关于修辞的讨论中详述这一点。

通信理论与翻译在计算条件下的根本转变之间的联系，早在沃伦·韦弗1949年的报告《翻译》中就已显现。^[71](#chapter_1.xhtml#chapter1-71) 韦弗的目的是探讨这样一个想法：人们可能设计一个计算机程序，将文本从一种语言翻译成另一种语言。熟悉香农和韦弗通信理论文本的人不会觉得以下内容太令人惊讶，但任何双语人士都可能觉得韦弗对翻译的理解异想天开。韦弗写道：“当我看到一篇俄语文章时，我会说，‘这实际上是用英语写的，只是用一些奇怪的符号编码了。我现在将着手解码。’” 韦弗写下这些话时，第二次世界大战刚刚结束，原型计算机首次被应用——并取得巨大成功——于破解德国军事通信密码的问题上。简言之，对韦弗而言，计算机擅长解密任务显而易见，因此如果一个问题能被重新概念化为类似解密问题的样子，那么它很可能就是计算机能做的事情。尽管当时科学权威们表达了怀疑，^[72](#chapter_1.xhtml#chapter1-72) 韦弗的《翻译》一文影响巨大^[73](#chapter_1.xhtml#chapter1-73) ，可以说至今仍在指导计算机科学家对待翻译的方法。例如，韦弗在文中概述的用于解码的统计方法，构成了当代机器翻译流行工作的核心。

韦弗1949年的文本有两点值得注意。第一是此前少有的观点：机器——具体来说是计算机——可以用来将文本从一种语言翻译成另一种语言。第二是其文本对“翻译”一词本身进行的根本性转译：韦弗将翻译等同于（无信息损失的）加密与解密操作。这两点将成为我们探索软件艺术的争论焦点。

任何有网络访问权限的双语人士都可以上网测试韦弗断言的当前可行性，即翻译只是一种解码形式。例如，找到 Google 的在线翻译服务^[74](#chapter_1.xhtml#chapter1-74) ，尝试将一段文本从一种语言翻译成另一种语言。除非文本极其简单，否则自动机器翻译将充满错误，甚至出现严重失误。当然，自1949年诞生以来，机器翻译已有显著改进，但机器翻译与优质翻译之间仍存在差距。此外，机器翻译与将一种语言的文本转换为另一种语言的文本而不丢失或增加信息（即韦弗和其他信息理论家构想的完美翻译）之间，不仅存在差距，简直是鸿沟。

软件艺术核心的问题之一，在于探究计算机和网络如何融入了这种站不住脚的无损翻译观念，并通过运用自由艺术和人文学科学者发展出的古老翻译理解来追究这一点。
