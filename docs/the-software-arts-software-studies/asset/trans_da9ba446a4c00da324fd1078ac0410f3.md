

# 芝诺的方法与辩证法

芝诺的方法定义得如此精确，自亚里士多德以来被称为“辩证法”。针对某个特定问题，从一个“似是而非”的回答——即一个假想对话者、某位哲学家或某种通见所认可的回答——出发，你推导出它所蕴含的后果，并表明这些后果彼此矛盾，且与最初的论题相矛盾，从而导出一个与第一个论题同样“似是而非”的相反论题。…… 我们要归功于他的方法的，如果不是将对话形式应用于哲学探究，至少也是一种梳理和辩论问题的特定方式，这种方式在智者派的修辞学和苏格拉底的哲学中均能找到。^([12](#chapter_5.xhtml#chapter5-12))

## 阿喀琉斯与乌龟的悖论

作为该方法的发明者，芝诺据称提出了一系列悖论，以说明辩证法如何反驳常识。他最著名的悖论是阿喀琉斯与乌龟的悖论。亚里士多德表述道：“这是说最慢的跑者永远不会被最快的跑者追上；因为追赶者必须先到达逃跑者出发的地方，所以较慢的跑者总是必然领先一些。”^([13](#chapter_5.xhtml#chapter5-13))

该悖论常借两名跑者来反复描述：一名快，阿喀琉斯；一名慢，乌龟。阿喀琉斯与乌龟赛跑，乌龟获得领跑优势。阿喀琉斯能追上乌龟吗？芝诺认为不能。为什么？假设乌龟领跑，当阿喀琉斯起跑时，乌龟已在路上领先了一段距离。为便于说明，假设乌龟领先一公里。阿喀琉斯奔跑时当然会很快跑完一公里，但在阿喀琉斯跑这段距离的时间里，乌龟会继续前进，超出一公里，也许前进了一百米。因此，当阿喀琉斯到达一公里标记处时，并未追上乌龟，因为乌龟此时将位于 1,100 米标记处。但随后，当阿喀琉斯到达 1,100 米标记处时，乌龟又会前进更远，假设到达 1,110 米标记处，以此类推。因此，阿喀琉斯永远追不上乌龟。

芝诺的论证看似无懈可击，但显然违背常识。当然，较快的跑者最终会追上较慢的跑者！令人难以置信的是，从亚里士多德时代直到现在，芝诺的悖论一直是激烈辩论的主题。千百年来，有人怀疑芝诺的悖论根本不是悖论，也有人认为该悖论至今未解。

## 提出的解决方案及其反响

芝诺悖论有许多“解决方案”。例如，哲学家文森特·阿杜雷尔 2015 年的文章《阿喀琉斯与乌龟悖论的离散解》^([14](#chapter_5.xhtml#chapter5-14)) 认为，如果采用时间的离散表示而非连续表示，就能展示并计算出阿喀琉斯何时追上乌龟。阿杜雷尔的“解决方案”最终归结为编写一个计算机程序来“解决”芝诺悖论。^([15](#chapter_5.xhtml#chapter5-15)) 时间的离散表示是指在某个粒度层面上不可再分的表示。例如，我们可以说单位是“眨眼一下”，没有比这更小的单位；即半个“眨眼”不被视为有效度量。

显然，阿杜雷尔的解决方案只会引起那些认为悖论仍未解决之人的兴趣。任何不关心该悖论的人，都会因为以下三个原因之一，认为任何此类“解决方案”——无论当代还是古代——都是无用或荒谬的：(i) 因为对该情境的任何经验考察（例如，安排一位超凡人类跑者与乌龟进行一系列赛跑）都将显示乌龟总会输；(ii) 因为简单的早期生活经验预示着阿喀琉斯的胜利；或 (iii) 因为任何像阿杜雷尔那样试图将问题作为抽象计算来陈述和解决的人，都是从远离日常常识的轨道来审视世界。^([16](#chapter_5.xhtml#chapter5-16))

# 笛卡尔的方法与笛卡尔时刻

后一种立场诊断出一种预示数字意识形态的心态，即一种世界观，认为获取真理被视为拥有正确方法的问题，更具体地说，是进行正确计算的问题。这种心态的历史远远超出了芝诺悖论的历史，涉及方法在哲学、数学和科学中的作用。为何要用计算——一种方法——来解决芝诺悖论这类问题，而不是运用常识、尝试经验验证，或通过与他人协商讨论？

大约直到十七世纪，人们相信真理只属于那些在身体、精神和灵性上做好准备的人。哲学家米歇尔·福柯认为，从“真理取决于知识追求者的身体和灵性准备”这一信念转向“真理不取决于此”这一信念，是现代时代的特征性转变。福柯大致以“笛卡尔时刻”来界定这一转变的时间，这指的是笛卡尔的信念：真理可以通过思维（“我思故我在”）找到，独立于灵性和身体的准备。特别是，笛卡尔陈述了他对形式方法的信念，我们可以称之为演绎，或更广泛地说，逻辑。^([17](#chapter_5.xhtml#chapter5-17))

福柯所命名的“笛卡尔时刻”标志着什么算作知识以及谁被认为有能力获取知识发生了根本性转变。笛卡尔时刻之后的这种信念——真理仅关乎知识，且可通过正确的方法或计算形式找到——现在变得更加复杂了——但仅限于那些设法超越数字意识形态思考的人，如女性主义认识论学者。^([18](#chapter_5.xhtml#chapter5-18)) 数字意识形态的特征是对方法和计算的绝对信仰，或更精确地说，是将计算*视为*方法。确实，在当今的数字意识形态中，真理被视为完全独立于主体，而完全依赖于计算方法。^([19](#chapter_5.xhtml#chapter5-19)) 这种意识形态让人们能够——毫无讽刺意味地——谈论“智能手机”和“智能机器”。现在，在福柯所说的现代时代之后，许多人认为计算方法——数据和算法——可以通向知识，无论掌舵的是否有一个知晓的或有准备的人类主体。此外，最有害的是，根据这种意识形态，尽管无需特定主体控制这些算法，但普遍预设这些算法只能由工业界的白人男性开发，如 Facebook 的创始人、微软的创始人、谷歌的创始人等。^([20](#chapter_5.xhtml#chapter5-20))
