

# 一维元胞自动机

考虑一段由许多句子组成的文本，例如一本书，甚至一系列书籍，如百科全书。原则上，如果能找到一张足够长的纸——也许是一卷几百米长的纸卷——就可以将文本的所有句子写在一行上；也就是说，一个接一个，页面上没有句子在其他句子之下。用墨水和纸张，这将是一种古怪的印刷方式，但例如作为网页，这很容易实现。沃尔弗拉姆称这一创新为“一维元胞自动机”，因为所有的状态、所有的陈述都铭刻在一行上。因此，在沃尔弗拉姆的图形中，一个状态——一系列陈述——看起来就像一行黑白方块，如[图 6.1](#chapter_6.xhtml#fig6_1)所示。

## IF-THEN 规则

IF-THEN 规则可以用同样简洁的方式书写。每条规则的 IF 部分采用三个方块的形式，每个方块要么是黑色要么是白色。每条规则的 THEN 部分是一个方块，可以是白色也可以是黑色。将 IF 部分视为一种模式，它与构成当前状态的那一行方块中的每个方块进行匹配。当 IF 部分与当前状态的一部分匹配时，模式中间的方块就会被重新着色——重写——为该规则 THEN 部分方块的颜色。[图 6.2](#chapter_6.xhtml#fig6_2) 提供了一个规则示例，其 IF 部分在上，THEN 部分在下。

![Figure 6.2 ¶ An example rule.](images/018_9495_006_fig_002.png)

[图 6.2](#chapter_6.xhtml#fig6-2) ¶ 一个示例规则。

这条规则可以这样叙述：如果一个白方块被两个黑方块包围，则该白方块应被重写为黑方块。由于计算的每个状态都被可视化为一长行黑白方块，计算的历史——计算机程序的执行——呈现为多行、一个矩阵的黑白方块，惯例是将计算的初始状态（即应用任何规则之前的状态）置于第一行。第二行显示初始状态的每个方块根据给定规则重写后的状态，以此类推。[图 6.3](#chapter_6.xhtml#fig6_3) 给出了一个例子。

![Figure 6.3 ¶ Execution of rule set 254.](images/019_9495_006_fig_003.png)

[图 6.3](#chapter_6.xhtml#fig6-3) ¶ 规则集 254 的执行。

这个黑白方块矩阵——看起来像是在白色背景上显示一个黑色三角形——代表了一个特定计算机程序运行十几步的过程，其初始状态仅包含一个黑方块。沃尔弗拉姆称这个计算机程序为规则 254。它由[图 6.4](#chapter_6.xhtml#fig6_4)中的八条规则组成。

![Figure 6.4 ¶ The eight rules of rule set 254.](images/020_9495_006_fig_004.png)

[图 6.4](#chapter_6.xhtml#fig6-4) ¶ 规则集 254 的八条规则。

请注意，除了一条规则外，所有规则的结果都是黑方块：在八条规则中的七条中，包含一个或多个黑方块的前件条件（IF 部分）导致结果为黑方块。只有当白方块被白方块包围时，执行规则集后它才保持白色。简明扼要地说，这组八条规则可以表述为：如果白方块被白方块包围，则保持其为白色；否则将方块的颜色重写为黑色。

## 规则集的二进制表示

正如我们对算术规则所做的那样，我们将再次把每组规则视为代表一个二进制数。首先考虑规则的 IF 部分。每条规则的 IF 部分（即前件）可以包含三个黑或白方块。请注意，给三个黑白方块着色的方法数量是有限的。具体来说，有八种方法；即 `2³ = 8`。我们不妨用 1 和 0 来代替黑白方块，枚举这八种可能性：`000`、`001`、`010`、`011`、`100`、`101`、`110`、`111`。这八种可能性在二进制表示法中对应数字 0、1、2、3、4、5、6、7。

再看一遍[图 6.4](#chapter_6.xhtml#fig6_4)中写出的规则集 254，该规则集在初始状态只有一个黑方块的情况下，会产生一个看起来像黑色金字塔的图形，如[图 6.3](#chapter_6.xhtml#fig6_3)所示。沃尔弗拉姆的惯例是按逆序列出规则集的前件，从 7 到 0：`111`、`110`、`101`、`100`、`011`、`010`、`001`、`000`。他本可以按 0 到 7 的顺序列出，但他选择了逆序，这现已成为围绕其工作积累的大量文献中的标准。因此，每个规则集有且仅有八条规则，这些规则按照规则的前件（即 IF 部分）按 7 到 0 的顺序惯例列出。

现在让我们考虑规则集 254 的后件，即 THEN 部分（见[图 6.5](#chapter_6.xhtml#fig6_5)）。忽略前件，只看后件。作为一个二进制数读取，这串黑白方块等同于 `11111110`，即十进制的 254。规则集 255 与规则集 254 仅有一个后件不同。规则集 255 的后件有八个黑方块，即 `11111111`。规则集 253 也与规则集 254 仅有一个后件不同。它的倒数第二个是白方块，最后一个是黑方块，即 `11111101`。类似地，规则集 0 的后件仅为一串八个白方块：`00000000`。规则集 1 末尾有一个黑方块：`00000001`。

![Figure 6.5 ¶ The THEN portions, the consequents, of rule set 254.](images/021_9495_006_fig_005.png)

[图 6.5](#chapter_6.xhtml#fig6-5) ¶ 规则集 254 的 THEN 部分，即后件。

由于所有规则集的前件相同，规则集仅因后件而异，且每个规则集包含八个后件，每个后件表示为黑或白的“位”，因此可能的规则总数等于用八位可以表示的二进制数总数：`2⁸ = 256`（但由于编号从 0 开始，最终的规则集编号为 255，而非 256）。

沃尔弗拉姆用他的黑白概念枚举了所有可能的规则集。他根据规则集的后件对它们进行排序，从规则集 `00000000` 到规则集 `11111111`，即从 0 到 255。如果我们将每个规则集视为一种潜在的计算机编程语言，它们的枚举是引人注目的，因为这是一个用沃尔弗拉姆的一维元胞自动机符号所能表达的所有可能计算机程序的列表。

# 图像的排序

我们知道，从初始状态只有一个黑方块开始运行时，规则集 254 会产生一个看起来像黑色三角形的图形。用相同的单个黑方块初始状态运行所有 256 个规则集是可行的。沃尔弗拉姆称这是“最基本的计算机实验之一：[他]采用一系列简单程序，然后系统地运行它们，看看它们如何表现。”^([121](#chapter_6.xhtml#chapter6-121)) 所以，对沃尔弗拉姆来说，运行一组计算机程序构成了一种“实验演示”，而程序的执行轨迹就是“行为”。
