# 结论

当艺术家兼新媒体理论家列夫·马诺维奇在近二十年前出版《新媒体语言》时，他引入了“软件研究”这一术语。马诺维奇写道：“新媒体呼唤媒介理论的一个新阶段。…… 要理解新媒体的逻辑，我们需要转向计算机科学。在那里，我们或许可以找到刻画可编程媒体的新术语、范畴和操作。*从媒介研究，我们转向某种可以称为‘软件研究’的东西——从媒介理论到软件理论*。”^([1](#chapter_8.xhtml#chapter8-1)) 马诺维奇通过概述我们可能“转向计算机科学”的两种方式对此进行了扩展：“在新媒体行话中，‘转码’某物就是将其翻译成另一种格式。文化的计算机化逐渐就所有文化范畴和概念完成了类似的转码。也就是说，在意义和/或语言层面上，文化范畴和概念被源自计算机的本体论、认识论和实用主义的新范畴和概念所取代。…… 转码原则是开始思考软件理论的一种方式。另一种方式，即本书尝试的方式，是将计算机科学的概念作为新媒体理论的范畴来使用。”^([2](#chapter_8.xhtml#chapter8-2))

在本书中，马诺维奇所谓的“转码”，我称之为“翻译”。正如我在第2章指出的，在科学技术研究（STS）中，翻译是一种常见的方法论，它基于文科和人文学科更为古老的传统。在STS中，翻译社会学更常被称为行动者-网络理论（ANT）。从方法论上讲，本书的挑战在于延伸和修正行动者-网络理论，使其能够用于处理软件文本：代码铭文和计算机科学技术论文。

正如从马诺维奇的区分中可能已清楚看到的，本书采取的方法（ANT）是其方法的反面或互补。与其利用计算机科学的概念作为新媒体理论的范畴，不如从文科和工科的范畴出发，追溯它们各自如何被翻译成计算机科学中使用的概念，然后考察它们如何被普及、进一步翻译，成为在流行文化中作为数字生活形式流通的其他表达和技术。

正如我们在本书中所见，算术化一直是将观念和制度重写为软件的压倒性力量。当科学史家和数学史家使用“算术化”一词时，通常指的是库尔特·哥德尔关于形式算术不完备性的工作之后的二十世纪事件。^([3](#chapter_8.xhtml#chapter8-3)) 或者，如“分析的算术化”这一短语所指，是指十九世纪对微积分基础的探寻。^([4](#chapter_8.xhtml#chapter8-4)) 在本书中，我使用该术语不仅意指数学史上的这些时刻，还意指算术长期且持续的兴起：将概念持续重铸为算术或计算形式。算术的这一兴起在历史上与笛卡尔和莱布尼茨所谓的*普遍数学*（*mathesis universalis*）纠缠在一起，后者是一种以数学为模型的普遍科学梦想。在本书中，算术化代表了一种将一切变成数学的冲动——我曾论证这种冲动需要被抵制。

算术——以及更广泛地说，代数、微积分和数学中的其他重要课题——对于智力工作和工业（尤其是资本主义：从商业、工业到现在的金融）的重要性日益增长。^([5](#chapter_8.xhtml#chapter8-5)) 通过布尔，我们看到逻辑如何被翻译成一种简单的算术形式（如第5章所示）。今天，我们看到类似的翻译被强加于“学习”。机器“学习”已成为人工智能的转喻，并被简化为仅仅是对超大多项式参数的调优（如第7章末尾所述）。^([6](#chapter_8.xhtml#chapter8-6)) 其他被翻译成计算机科学技术概念的文科和工科概念包括：算法、演示、语法、语言、机器、操作、过程、修辞和模拟。

我将算法列在该列表开头，不仅因为列表按字母顺序排列，还因为算法一直是计算机科学的关键术语，且可以说依然是。在本结论章节中，我们将探讨计算机科学的研究和教学议程，它们优先考虑算法，并将其与软件研究可能的议程形成对比，后者则优先考虑交互，以及发明和质询赋值、连接、等价和同一性陈述的方法的追求。

## 走进算法

### 计算机科学作为算法研究

正如第1章所述，1967年，赫伯特·西蒙、艾伦·佩利斯和艾伦·纽厄尔给期刊《科学》编辑写了一封信，坚持认为计算机科学是一门科学。在信中，他们拒绝了计算机科学仅限于算法研究这一观点，^([7](#chapter_8.xhtml#chapter8-7)) 但正如计算机历史学家保罗·塞鲁齐总结的那样：“在随后的岁月里，计算机科学演变为恰恰意味着他们\[西蒙、佩利斯和纽厄尔\]所说的它不是的东西——即算法研究。…… 该信在《科学》发表六个月后，ACM\[计算机协会\]发布了‘课程68’，这是该协会认为能为本科生提供智力上可辩护的计算机科学基础的一组课程。‘课程68’强调计算机科学的数学和理论基础。计算机硬件研究缺席。…… ACM选择强调算法过程、编程语言和数据结构。”^([8](#chapter_8.xhtml#chapter8-8))

人们可能会推测，半个世纪后的现在情况已不同，但查阅ACM/IEEE《2013计算机科学课程指南》，人们仍会发现算法位于十八个不同“知识领域”列表的首位（见第14页）：“算法是计算机科学和软件工程的基础。任何软件系统的实际性能取决于：(1) 所选算法和 (2) 各实现层的适用性与效率。因此，良好的算法设计对所有软件系统的性能至关重要。”^([9](#chapter_8.xhtml#chapter8-9))

显然，算法在计算机科学教育中保持着前沿地位。因为它们在本科课程中占据如此显要的角色，我们可以将算法理解为进入该专业的“守门人”。如果你无法应对算法导论课程中的数学和逻辑话语，你不太可能坚持将计算机科学作为主修课程。

然而，算法不仅在大学课程中是守门人；它们在工业界扮演着相同的角色。关于算法的问题构成了大型科技公司（如微软、亚马逊、谷歌、苹果和脸书）面试潜在软件开发人员时提问的大部分内容。以下是一本面向准备求职面试的有志软件开发人员的畅销书的开头几句：“在大多数顶级科技公司（以及许多其他公司）中，算法和编码问题构成了面试流程的最大组成部分。将这些视为解决问题的问题。面试官旨在评估你解决从未见过的算法问题的能力。”^([10](#chapter_8.xhtml#chapter8-10))
