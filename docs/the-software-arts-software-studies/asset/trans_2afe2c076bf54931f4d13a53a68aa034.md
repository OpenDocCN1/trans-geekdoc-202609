

# 罗伯特·波义耳与空气泵：实验科学的奠基与公众演示的双重性

罗伯特·波义耳，空气泵的发明者，大概是科学史上被研究最多的人物之一，并被许多人视为实验科学的奠基人——他发明了一种具体方法，实现了弗朗西斯·培根仅曾构想的事业。尽管波义耳如今地位崇高，但在当时他面临着诸多物质障碍（如堵塞水泵的漏气口）以及来自其他自然哲学家的强烈反对，他们批评他的方法。例如，在其开创性著作《利维坦与空气泵：霍布斯、波义耳与实验生活》中，史蒂文·沙平和西蒙·谢弗详细记述了托马斯·霍布斯对波义耳的批评。^([75](#chapter_6.xhtml#chapter6-75))

霍布斯及许多其他人担心，波义耳通过归纳演示机械地产生的那类事实，无法成为真正知识的基础。换句话说，他们的关切是本体论层面的，按经典观点，这类问题只能通过小圈子专家间的辩证演绎演示来解决。

然而，波义耳的工作并未局限于自然哲学的专家辩论。皇家学会也需要利用空气泵演示作为一种修辞形式，向公众展示并激励显贵访客支持他们的工作：“波义耳的空气泵连同胡克的显微镜构成了皇家学会的‘展品’；当招待显贵访客时，主要展示的总是用泵做的实验。”^([76](#chapter_6.xhtml#chapter6-76)) 用当代术语来说，波义耳的空气泵是皇家学会最重要的“演示”。

当然，如果空气泵不被同时理解为一种生产非修辞性、真知识的机器，那么用它来说服访客认可皇家学会的价值将沦为空洞的修辞。在一群专家、学会会员和知识渊博的访客面前，波义耳的归纳演示被视为一种强有力且严谨的替代方案，取代了经典的演绎演示。因此，当皇家学会向普通公众或非自然哲学专家的显贵贵族敞开大门进行演示时，这些归纳演示被视为极具说服力。

尽管皇家学会成员理解将波义耳的空气泵作为一种说服性修辞部署的必要性，但他们对公开演示与单纯娱乐表演的相似性感到不安。为迎接查理二世国王访问皇家学会，其联合创始人、前会长兼建筑师克里斯托弗·雷恩写信给布伦克勋爵：

> 如果你有任何著名实验，能为哲学原理开启新的视野，没有什么比这更配得上学会的声望；尽管这类实验可能过于枯燥，无法达到此目的，因为这场合应当有某种盛大感。另一方面，仅展示花招、只能引发惊奇的东西——基歇尔、肖特斯甚至杂技演员都擅长这些——将难以称得上场合的庄重。它必须介于两者之间：在哲学上启迪人心，且其用途和优势无需讲座即可显而易见；此外，它还应以某种意想不到的效果令人惊喜，并因装置的巧思而值得称道。^([77](#chapter_6.xhtml#chapter6-77))

当时国王已看过波义耳的空气泵，所以雷恩希望为国王找到一些新颖但同样优秀的东西。他寻求一种能照亮当代自然哲学议题的演示；一种无需冗长讲座铺垫即可被理解的演示；一种不只是像杂耍那样只有娱乐价值的“花招”；当然也绝不是像当时著名的德国博学家基歇尔（也被称为“百艺大师”）所展示的那种奇观！

沙平和谢弗提到的“基歇尔、肖特斯甚至杂技演员”，指的是德国耶稣会学者阿塔纳修斯·基歇尔（1602–1680），当时欧洲最著名的知识分子之一，以及他的学生兼助手加斯帕·肖特斯（1608–1666），也是一位德国耶稣会科学家。基歇尔和肖特斯强调奇观在演示中的效用。基歇尔除其他著作外，还写了一本《光影大术》（1646），展示了在荷兰数学家兼科学家惠更斯（1629–1695）等人发明幻灯机之前，就在屏幕上投射图像。他还设计了会说话的雕像和其他令人惊叹的机械发明。^([78](#chapter_6.xhtml#chapter6-78))

然而，皇家学会内部并非所有人都反对奇观。其首任秘书约翰·威尔金斯（我们已提及过他关于通用特征、哲学语言的计划），似乎对奇观颇有好感。他写了一本《数学魔术》（1648），描述了多种机械装置的制造，并推测飞行器如何制造。威尔金斯将书的后半部分献给“代达罗斯，因为他是古人中最早、最著名的自动机制造巧匠之一。”^([79](#chapter_6.xhtml#chapter6-79)) 尽管如此，尽管威尔金斯热衷“魔术”，雷恩在给布伦克的信中仍试图划清界限，将皇家学会严肃的演示与他眼中基歇尔等哲学家的戏剧把戏、诡辩区分开来。

历史学家扬·V·戈林斯基指出了实验演示在皇家学会运作中的双重角色——既是公众奇观，也是严肃科学。据戈林斯基称，罗伯特·胡克（波义耳的同事，为他制造了空气泵）在1662–1684年和1687–1688年担任学会的实验馆长。^([80](#chapter_6.xhtml#chapter6-80)) 戈林斯基断言：“公开实验……吸引了会议观众，并鼓励尝试将自然哲学的吸引力扩展到整个社会。但在这些语境中的应用，也使自然哲学家的公众形象面临风险，他们容易被混淆为变戏法的、表演者或贩卖奇观的人。”^([81](#chapter_6.xhtml#chapter6-81))

因此，胡克陷入了与柏拉图相同的困境：他帮助创造了一种供同行哲学家使用的新演示形式，但一旦这种演示为更广泛的公众表演，它就转化为一种修辞、一种说服性表演，其与戏剧和其他艺术的亲缘性显而易见。

演绎、归纳和溯因这三种不同演示类型的各自称谓，既指示了演示中所展示的推理种类，也指示了观察者或参与者所期望的推理种类。因此，当苏格拉底施行他的方法时，他进行演绎推理，同时也带领对话者和听众走过同样的演绎步骤。他希望展示的是对系表问题的解决，如“什么是正义？”

类比而言，当波义耳启动空气泵并在皇家学会同事见证下做实验时，他产生了一组特定事实，并沿着归纳路径推导出更普遍的真理；当然，他也希望同事见证者跟随他的归纳推理。归纳演示产出的等价关系，现在可表述为代数等价。这类似于苏格拉底的目标，但系表动词“是”被代数等号“=”取代了。例如，波义耳的一组演示归纳出了我们今天所知的波义耳定律：气体压强与体积成反比，当温度恒定时；用代数术语表述即 `PV = k`，其中 `k` 为常数。^([82](#chapter_6.xhtml#chapter6-82))
