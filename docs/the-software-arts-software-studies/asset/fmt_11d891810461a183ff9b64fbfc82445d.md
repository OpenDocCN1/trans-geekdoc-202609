
# 语法的历史与计算认识论

历史学家们反复批评福柯的这一时期划分，因为它仅描述了一小群欧洲男性知识分子。但《词与物》审视的并非某个时期大众对语言的普遍认知。福柯实际所做的是对少量关于语言的学术文本（包括修辞学、逻辑学、语法学、语文学、文学和语言学文本）进行细读。与其使用“认识论”这一术语，不如用一个短语（尽管略显笨拙）如“语言的学术分析”会更准确。

然而，即使超越显而易见的学者代际、地域和性别差异，无论古今，仍可认为福柯过于草率地将“我们”（当代人）与十九世纪现代人联系在一起。我将论证其“文艺复兴”、“古典”和“现代”三个认识论是不充分的，需要增加第四个认识论，涵盖二十世纪初至今的时期。第四个认识论区别于福柯的现代认识论，因为它不主要关注能指与意义。

我将这一第四个认识论称为“计算认识论”，并强调其处理语言的主要途径将意义推向边缘。本质上，在“计算认识论”中，语言理论的设计旨在仿佛语言本身无意义般对其进行分析。虽然能指与意义是福柯所命名的前几个认识论的核心，但在二十世纪许多语言学、文学、逻辑学和信息学著作中，认为语言形式可以脱离意义而被孤立研究，这一观点被视为既可能又可取。

例如，克劳德·香农和沃伦·韦弗在其著作《通信的数学理论》中坚持认为，其理论的原则之一是意义在其中不起作用：“在该理论中，‘信息’一词用于特殊含义，不得与其日常用法混淆。特别是，信息不得与意义混淆。事实上，两条信息，一条承载大量意义，另一条纯属胡言乱语，从目前观点来看，就信息而言可以完全等价。”^([3](#chapter_7.xhtml#chapter7-3))

本章将勾勒计算认识论的谱系，重点关注语言学家诺姆·乔姆斯基的工作，因为乔姆斯基语言学极其有力地将意义推向边缘，影响深远，且在语言学领域现有地位之外仍具有间接但重要的影响力。我们将仔细考察乔姆斯基所见其工作与十七世纪《波尔皇语法》的联系。乔姆斯基是否有效地将《波尔皇语法》翻译成了软件？

## 乔姆斯基的熔炉

特别是在二十世纪六七十年代，乔姆斯基的生成语法成为语言学、哲学、文学、计算机科学、经济学、社会学、政治学^([4](#chapter_7.xhtml#chapter7-4)) 等诸多领域的熔炉。因此，乔姆斯基的文本是二十世纪被引用最多的文本之一。^([5](#chapter_7.xhtml#chapter7-5)) 在乔姆斯基二十世纪五十年代介入之前，语法被许多人理解为一种相对次要的教学艺术。例如，在美国，“grammar school”（语法学校）是“elementary school”（小学）的常用同义词，因为正如麦克卢汉在其论文中所解释的，语法作为基础教育的基本领域一直延续下来，即使其作为知识和研究领域的地位已下降。但乔姆斯基——连同被招募到其项目中的数千名其他学者——重振了语法，将其置于几乎所有知识和研究领域的中心。

这是如何做到的？主要是通过运用信息论和计算理论重新阐述语法。在接受《纽约时报》采访时，乔姆斯基在一番谈话中将语法与计算联系起来，并试图建立与十七世纪笛卡尔和伽利略人物的直接联系：“语言作为创造性思维系统的出现，为笛卡尔和伽利略所感知。但直到二十世纪中叶才真正得到处理，因为当时缺乏恰当表述所需的工具。你需要现代可计算性理论，这是由阿兰·图灵和二十世纪三四十年代其他伟大数学家发展起来的。我有幸在所有这些伟大见解涌现之时成为一名本科生。”^([6](#chapter_7.xhtml#chapter7-6))

在这番陈述中，乔姆斯基谦虚地略去了他自己对现代可计算性理论发展，特别是编程语言形式分析的贡献。因此，要理解二十世纪中叶语法的这一复兴，我们需要考察乔姆斯基的技术贡献。但正如乔姆斯基在上述引文中透露的，他将自己的工作置于历史背景中。

乔姆斯基的第一部有影响力的技术著作《句法结构》出版于1957年。^([7](#chapter_7.xhtml#chapter7-7)) 其关于语法谱系的历史主张发表于1966年，题为《笛卡尔语言学》。^([8](#chapter_7.xhtml#chapter7-8)) 在后一本书中，乔姆斯基宣称他在十七世纪语法学家的著作中看到了其二十世纪语法的根源。本章将考察乔姆斯基给语法学科带来的重大技术变革并审视其史学观。我们将探讨乔姆斯基的语法是否如他所言是十七世纪《波尔皇语法》的翻译。我们将看到，乔姆斯基的工作与其说是十七世纪语法的翻译，不如说是对其的彻底决裂，而这一彻底决裂不仅对语言学，而且对当今教学法、工业和认识论的许多领域都有影响。

## 语法史

为理解和评估乔姆斯基的历史主张，我们需要考察乔姆斯基之前的语法是什么样的。几个世纪以来，语法并非对语言结构的无利害描述，而是一种明确的*规范性*、政治性和宗教性干预，作为教学法被实施。首部欧洲方言语法的评注使规范性计划显性化。例如，1492年，学者安东尼奥·德·内布里哈向伊莎贝拉女王呈献其卡斯蒂利亚语语法，作为帝国工具，以驯服其帝国征服者所面对的“异域语言”。他在致伊莎贝拉的信中写道：

> 请回想今年早些时候我在萨拉曼卡向您呈献此书草稿之时。当时您问我，这样一部语法究竟能有何用。此时，阿维拉主教打断替我回答。他说：“陛下很快将把轭加在许多说异域语言的蛮族身上。因这胜利，这些人将面临新的需要；胜利者对失败者应负的法律之需要，以及我们将带去的语言之需要。我的语法将把卡斯蒂利亚语传授给他们，正如我们用语法教青年拉丁语。”^([9](#chapter_7.xhtml#chapter7-9))

方言语法——卡斯蒂利亚语、法语及其他——成为帝国政治，随后又是民族国家政治的必备著作。^([10](#chapter_7.xhtml#chapter7-10)) 拉丁语法是罗马帝国继而罗马天主教会的必备产物。后来，各教派的基督教传教士——渴望传播上帝之道并将《圣经》翻译成世界各地语言——为无数非欧洲语言编写了语法。^([11](#chapter_7.xhtml#chapter7-11))
