

# 打破亚里士多德壁垒

打破亚里士多德壁垒仍然是当代哲学中最迫切的问题之一。哲学家贝尔纳·斯蒂格勒在其著作《技术与时间》第一卷中既凸显又打破了这一壁垒，他写道：“哲学在其历史伊始便将*tekhné*（技艺）与*épistème*（知识/学术）分离开来。……这种分离是由政治语境决定的，在该语境下，哲学家指责智者将*logos*（理性/言语）工具化为修辞和演说稿写作，即既作为权力的工具，又作为对知识的放弃。正是在这种冲突的遗产中——哲学的*épistème*与智者的*tekhné*对立，从而贬低一切技术知识——技术实体的本质被构想出来。”^([9](#chapter_3.xhtml#chapter3-9))

随着工业资本主义开始主导经济，亚里士多德壁垒成为了上层阶级理解其财富来源的障碍。在狄德罗近一个世纪之后，查尔斯·巴贝奇在其著作《论机械与制造业的经济》^([10](#chapter_3.xhtml#chapter3-10))的序言中，告诫他的同辈——那些拥有财富、闲暇和博雅教育的人——对机械技艺一无所知。他写道：“在一个制造业国家，拥有显贵地位的人，如果完全不了解那些造就其伟大的原则的发展，实在难辞其咎。财富的拥有者，对那些或近或远成为其财产丰富来源的工艺过程，实在难以无动于衷。享有闲暇的人，很难找到比考察自己国家的车间更有趣、更有启发性的追求了，车间蕴藏着丰富的知识矿藏，却普遍为富裕阶层所忽视。”^([11](#chapter_3.xhtml#chapter3-11))此外，巴贝奇告诉他的同辈，了解其财富来源并不会太难：“理解制造工艺的困难不幸地被大大高估了。以制造商的眼光去考察它们，从而能够指导他人重复这些工艺，无疑需要极高的技巧和对主题的预先熟悉；但仅仅领会其一般原理和相互关系，却在几乎所有受过相当教育的人能力范围之内。”^([12](#chapter_3.xhtml#chapter3-12))

通过这些陈述，巴贝奇清楚地表明了他的视角源于上层阶级的出身/地位；他同时也向读者保证，机械技艺实际上可以转化为博雅教育的语言，因为当时“相当教育”在公理上对上层阶级而言，就是博雅教育。

## 登场人物

尽管打破亚里士多德壁垒是可能且可取的，但这要求——且仍然要求——超越一个人的教育和成长，因为我们都受制于社会、政治、经济和文化条件，这些条件决定了谁知道什么、谁做什么。此外，一般来说，大多数教育机构维护着亚里士多德壁垒。正如达朗贝尔所指出的，在工匠作坊当学徒的人不一定懂得写作。反之，即使在今天，接受博雅教育的人也未受过成为汽车修理工的训练。简言之，种族、阶级、性别、性取向、职业和教育都在一些不易拒绝的角色中被执行。为了找到我们被分配角色的替代方案，我们需要想象融合、分割或偏离常规角色的*登场人物*。这是受哲学家吉尔·德勒兹启发的一个建议。^([13](#chapter_3.xhtml#chapter3-13))

如果我们仔细观察达朗贝尔和巴贝奇分别提出的*登场人物*，会发现他们在创建新的知识与实践机构方面起到了催化作用。达朗贝尔承认，哲学家作为“接生婆”的形象至少可以追溯到苏格拉底，然而即使在现在，苏格拉底式对话依然具有爆炸性，甚至具有革命性。正如苏格拉底所实践的那样，接生术是一种通过密集提问来质疑某人的常识，从而诞生对自我的新理解的实践。

巴贝奇为《论机械与制造业的经济》所写的序言唤起了一个乍看之下似乎要求不高的角色。巴贝奇似乎在描述一位“绅士机械师”，类似于“绅士农夫”——这一人设要求绅士了解其财富是如何生产的，但将这种知识的获视为一种闲暇消遣，而非必需。

巴贝奇的序言告诉他的绅士读者，他将揭示一项供其闲暇时消遣的娱乐活动，同时也表明，即将解释的机械技艺原理对他来说（巴贝奇）绝非消遣，而应被视为其智力生活的基石，以及任何将从工业革命中受益之人财富的可能来源。^([14](#chapter_3.xhtml#chapter3-14)) 巴贝奇的志向超越了娱乐。他想激励他的绅士读者成为制造商。

在另一篇文章中，巴贝奇明确命名了他为他的绅士和所有男性设想的角色：“把人描述为制造工具的动物，这并不是一个坏定义。”^([15](#chapter_3.xhtml#chapter3-15)) 巴贝奇的*登场人物*不是*Homo sapiens*（智人），即睿智、理性、聪明的人。也不是文化历史学家约翰·胡伊青加所称的*Homo ludens*（游戏人），即闲暇之人、玩耍之人。^([16](#chapter_3.xhtml#chapter3-16)) 巴贝奇的*登场人物*是*Homo faber*（制造者），即创造者/制造者。

许多哲学家、政治理论家和经济学家都详细阐述了将*Homo faber*人设置于中心的意识形态所带来的文化、社会、经济和政治后果。通过区分看似相近的变体，可以详述这一陈词滥调。如果我们说“制造者”是一个关键人物，我们就被迫考虑这些人到底制造什么，以及他们必须从事何种工作来制造这些东西。例如，农业工人与建筑工人、工厂工人、办公室职员，或是在知识田野上耕耘的研究人员，从根本上讲是否不同？如果是，这种区别是根据工作如何完成来划分，还是根据制造出什么来划分？

运用第二章讨论的意识形态定义，可以将培根科学、《百科全书》的文科与科学，以及巴贝奇的“运算科学”视为围绕其各自的*登场人物*——丈夫、接生婆、*Homo faber*——所阐述的独特意识形态。

类比地，我们可以认为图灵1936年文章的卓越与敏锐，源于他大胆地将谦逊的“人肉计算员”这一*登场人物*置于对数学工作的重新思考中心。图灵机将“低层级”的计算工作置于数学“高层级”工作的中心。简而言之，图灵——如同他之前的培根、狄德罗和巴贝奇——打破了“亚里士多德壁垒”。

## *Homo faber*与工作 对比 *Homo laborans*与劳动

许多语言至少包含两个表示“工作”的词汇。在英语中，我们有“labor”（劳动）和“work”（工作/制作）。在法语中，对应的词汇是“travailler”和“oeuvrer”。哲学家汉娜·阿伦特在其著作《人的境遇》中指出，这种双重术语不仅存在于英语和法语中，也存在于德语、希腊语和拉等许多其他语言中。^([17](#chapter_3.xhtml#chapter3-17)) 阿伦特将其书中主要论点之一建立在这种反复出现的差异之上，哲学家约翰·洛克在其《政府论（下篇）》中也提到了这一差异，他写道：“我们身体的劳动和我们双手的工作”（第26节）。
