

# 如何开始？

请思考一下，几十年来被视为人工智能奠基之作的那篇文章，同样出自艾伦·图灵之手。这篇文章围绕一场身份与对话互动的游戏——“模仿游戏”而构建。在1950年的文章中，图灵提出了一种维特根斯坦式的语言游戏^[52](#chapter_8.xhtml#chapter8-52)——“模仿游戏”，以取代“机器能思考吗？”这一问题。图灵的模仿游戏包含一个提议：编程让计算机扮演一个试图模仿女性的男性（一个关于性别差异的再生产与表征的引人入胜的提议）。请注意，他的游戏如何与关于模仿、复制与模拟的古老哲学讨论产生共鸣——至少可追溯至柏拉图的著作——这在第四章中有所论述。

图灵这样描述模仿游戏：

> 游戏由三人参与：一名男子、一名女子，以及一名可以是任一性别的审讯者。审讯者待在一个与另外两人分开的房间里。审讯者的目标是确定另外两人中谁是男子、谁是女子。……男子在游戏中的目标是试图导致审讯者做出错误的判断。……女子的目标是帮助审讯者。……我们现在问：“当一台机器在这个游戏中扮演\[男子\]的角色时，会发生什么？”当游戏这样进行时，审讯者做出错误判断的频率，会像在男子和女子之间进行游戏时那样高吗？这些问题取代了我们最初的\[问题\]，“机器能思考吗？”^[53](#chapter_8.xhtml#chapter8-53)

这篇文章频繁被引用直到1990年代，大量人工智能项目在1960年代和1970年代开发出来，旨在应对图灵在1950年论文中提出的挑战。^[54](#chapter_8.xhtml#chapter8-54) 但现在，它在人工智能的技术文献中几乎不再被提及。奇怪的是，即使被引用时，图灵的模仿游戏通常也被重命名为“图灵测试”，并被重新叙述为排除任何关于性别差异的提及。据说这个“图灵测试”是计算机程序与未指定性别的人类之间的性能比较。随着时间的推移，AI研究者将其研究议程甚至从对图灵文章的这种误读中解耦出来，并于1994年，在一次最重要的AI会议上，由两位著名的AI研究者帕特里克·海耶斯和肯尼斯·福特在受邀主题演讲中公开予以否定，文章标题为“图灵测试有害论”。^[55](#chapter_8.xhtml#chapter8-55) 如今，AI已坍缩为关于一组算法（如当代机器学习）的论述，不再严肃地处理图灵关于该主题的原始思想所引发的身份与互动、加倍的美学或政治、拟像、性别刻板印象以及诡异感等问题。^[56](#chapter_8.xhtml#chapter8-56)

当海耶斯和福特否认图灵游戏对AI研究的有用性时，他们认为它在理论上存疑、在实践中无用：“从实用角度看，为什么有人想制造能通过图灵测试的机器？正如许多人观察到的，人类并不短缺，我们已经有制造更多人类的成熟方法。人类认知，甚至高质量的人类认知，都不稀缺。即使我们能造出这种机器，它能提供什么额外功能呢？”^[57](#chapter_8.xhtml#chapter8-57) 今天，当我们拥有这类计算对话代理，或称机器人，它们在电子游戏、维基百科、推特和脸书上与人类展开较量时，海耶斯和福特的那种失去的纯真，既令人心碎又显得可笑地天真。当脸书和推特上的机器人在世界各地的选举政治中非法参与活动时，我们以一种令人不安的方式领教了此类机器提供的“额外功能”。辨别什么是机器人、什么不是，可能是关乎民主未来的关键问题。如果软件研究接手图灵的这篇文章——那篇被AI研究者抛弃的奠基性愿景——会怎样？除了辩证法、修辞学、语法学及诸多软件艺术的翻译之外，让我们将身份、等价、赋值与互动的问题，列入软件研究和民主的研究议程。

# 注释

在机器学习中，线和平面的重要性怎么估计都不为过。寻找最佳拟合线支撑了许多备受关注的机器学习器（神经网络、支持向量机、随机森林）。线性回归以其对直线或平面的追求，投射出向量空间的基本排列。它将所有差异渲染为距离和运动方向。在各种角度和方向上绘制线条或平面，或许是遍历数据量、并将输入与输出、预测变量与预测结果之间的关系巩固为一个轨迹或数据应变轨迹的主要方式。

参见 Adrian Mackenzie, *Machine Learners* (Cambridge, MA: MIT Press, 2017), 63.

这一异议表述为：“机器能思考吗？”我将在后文谈及这一点，现在仅引用一个类比问题：“机器会牙痛吗？”你肯定会倾向于说“机器不会牙痛。”我现在所做的只是引起你对你使用“能”这个词方式的注意，并问你：“你的意思是想说，我们所有的过去经验都表明机器从未牙痛过吗？”你所说的不可能性是逻辑上的。问题是：思考（或牙痛）与思考的主体、牙痛的主体等之间是什么关系？

参见 Ludwig Wittgenstein, *The Blue and Brown Books: Preliminary Studies for the “Philosophical Investigations”* (New York: Harper Torchbooks, 1958), 16. 该出版物包含维特根斯坦在1933–1934和1934–1935学年讲座期间的笔记。
