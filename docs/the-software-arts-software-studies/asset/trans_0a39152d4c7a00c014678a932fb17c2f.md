
# 计算思维

“计算思维”由美国国家科学基金会推广；由代码组织（code.org）网站提供支持，该网站由主要由企业组成的联盟资助；以及其他教育倡议部署了一种将计算视为思维的论述，其抽象程度之高，似乎适用于一切，实则未指涉任何具体事物。

尽管如此，思维总是关于某事物的思维，且总是与他人共同进行的思维。甚至有人可能会质疑“一般性思维”这一概念本身。因此，我们需要追问：“计算思维”是与谁一起进行的？是关于什么的？科学研究学者布鲁诺·拉图尔敦促我们将思维重新构想为工作、协作。拉图尔写道：“我们既不思考也不推理，而是与他人一起处理脆弱的材料——文本、铭文、痕迹或颜料。”那么，“计算思维”的工作是什么？谁在做这项工作？为了谁的利益？

## 性别多样性

即使我们能解决关于“计算思维”的这些问题，很明显，它不应按当今计算机科学的教学方式来教授。多样性是采用新方法最重要的动机之一。遗憾的是，计算机科学——作为一个领域——在包容性和多样性方面的努力基本上以失败告终。根据计算机科学领域主要专业组织之一——计算研究协会的数据，2013年，女性仅占美国计算机科学系学士学位获得者的14%。这些数据尤为令人担忧，因为它们似乎正朝着错误的方向发展。例如，根据美国教育部的数据，1984年计算机科学毕业生中有37%是女性。换句话说，女性过去曾占每届计算机科学毕业生的三分之一以上，而三十年后，她们仅占七分之一。

教育领域的多样性问题只会加剧行业的多样性问题。近期对顶尖计算机技术公司性别和种族多样性的调查显示，最强大的计算机技术公司员工中仅有20%-40%是女性，绝大多数员工为白人。大型科技公司披露员工多样性数据是相对较新的现象，但逐年数据（例如2014年至2015年）显示几乎没有任何进展。

美术、设计和文科——至少在大学里——不像科学和工程那样存在同样的多样性问题。我受到这样一个愿景的驱动：计算可以作为一门艺术（或一组艺术）来教授和实践。追求软件艺术可以通过向艺术和人文学科的人士敞开大门，开辟新的视野，这些人目前仅将自己视为软件的使用者而非创造者。

计算机科学主要专业组织——美国计算机协会（ACM）前会长彼得·德宁在2013年撰写的一篇文章开头写道：“几十年来，计算机科学一直被一句老话所困扰：任何自称科学的领域，都不可能是科学。关于我们缺乏实质内容或兜售可疑结果的暗含批评已被反复驳斥。然而，在关乎我们的语境中，这种批评屡见不鲜。”德宁开篇之所以令人震惊，并非因为计算可能不是科学这一观点，而是因为它预设了任何非科学的领域必定是产出可疑结果且缺乏实质的领域。或许计算不是科学，但它依然是一个有实质、能产出严谨、可靠结果的领域！

## 计算与数字

常识认为——在核心层面——计算机由数字构成：0和1。但请考虑一个无理数，如2的平方根，或者更糟，一个超越数，如π。我们可以选择用一个永不终止的过程来表示π，或者用一个以3.1415926……开头的无限数字序列。对于计算机，我们不得不截断这个无限序列；我们必须决定分配多少位内存给它。

如果数字是计算机的“原生”属性，我们就不必担心如何近似它们。但在实际操作中，即使需要极高精度的计算，我们也倾向于仅用128位计算机内存来表示这些无限序列。当然，原则上可以将给定计算机的整个磁盘和内存都填满仅一个数字的数位，但即便如此，我们仍是在用有限的位集合来近似无限序列。相反，计算机科学的一个完整子学科——数值分析——在几十年间发展起来，专门解决用计算机表示数字和计算数字的问题。如果数字是计算机的“原生”属性，就不需要这样一个计算机科学专业领域了。

我的观点是，虽然数字和数字运算（如算术）可以用计算机近似，但计算机并非数值机器。它们是语言机器，数字只是计算机一个非常常见的应用领域。将计算机仅想象为强大的计算器，混淆了机器本身与计算机技术的单一重要应用。

让我用一个荒谬的例子来强调这一陷阱。如果我厨房里的微波炉主要用来做爆米花，这是否意味着微波炉本质上是一台“爆米花机”？

我的观点之所以有争议，是因为它当然是对最常见叙事的反叙事，在最常见的叙事中，计算机被视为信息技术，从而与信息、量化和数学联系在一起。相反，在我要讲述的故事里，计算机是自由艺术与机械艺术的耦合——即我们今天所说的工匠、艺术家、人文主义者和设计师的知识。在第一个故事里，计算机是数学和科学的物化。在第二个故事里，计算机是艺术和人文学科方法与理论的显现。

## 计算与自由艺术

如果计算可以被构想为不仅仅是科学或工程，那么替代方案是什么？具有讽刺意味的是，或者或许是典型地，艾伦·珀利斯——如前所述，他在1967年主张计算*是*一门科学，并作为1968年第一届软件工程会议的参与者，帮助阐述了将软件生产视为工程的愿景——却在1962年描述了计算机编程应如何融入自由艺术教育。珀利斯倡导的这第三种路径，即计算作为自由艺术教育的内在组成部分，最近已被复兴，例如由计算媒体理论家和实践者迈克尔·马特亚斯和伊恩·博戈斯特在各自对“过程素养”的倡导中复兴。博戈斯特特别转向考察语言艺术（三学科）的教学，以探索过程素养对教育和学习的意义。
