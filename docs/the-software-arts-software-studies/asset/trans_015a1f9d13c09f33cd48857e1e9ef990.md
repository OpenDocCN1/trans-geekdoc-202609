
# 计算条件：数字意识形态与数字生活

因此，对于一些认知科学家来说，人类的心智是一台计算机；对于许多分子生物学家来说，基因密码是一段计算机代码；诸如此类。这些并非凭空的信仰飞跃，而是大量在同行评审期刊上发表论文的科学家所持有的信念。让我们将这些与科幻小说归为一类，并将其统称为“数字意识形态”，以将这些关于计算的信念与更为普遍的事物——“数字生活”区分开来。

数字生活超越了专业圈子，也超出了专家对话的技术词汇范畴。数字生活是一种日常生活，存在于这样一个社会中：该社会通过用包含计算机且不可或缺的技术取代日常制度（如邮政系统、电影院、银行业务等），来实施一种数字意识形态。例如，如果你丢失了数字化的电子档案，你的个人照片收藏还剩下什么？你有纸质备份吗？

数字生活是在对数字意识形态等价性的信念中度过的。数字意识建立在大量等价性断言之上；其中包括大脑是一台计算机，或者数字视频与旧式胶片无异。在科学文献中，数字意识形态通常以非常谨慎、严格限定且论证严密的等价性形式阐述，最终呈现为恒等式：X = Y。这些等价性采取技术主张的形式。在技术文献中，人们不能轻易主张逻辑是算术的一种形式。相反，这种主张必须使用一套科学和/或数学演示技术来证实；即证明两个实体等价的翻译技术。

然而，即使通过科学和技术的翻译建立的等价性、恒等式是正确的，它们也并不完美。我们将展示计算机科学建立的技术等价性是如何不完美的，并描述当这些等价性被确立为恒等式时，什么被丢失或增加了。

## 计算条件 = 数字意识形态 + 数字生活

在 1979 年为魁北克政府撰写的知识现状诊断中，法国哲学家让-弗朗索瓦·利奥塔预言了一个即将到来的未来：“新研究的方向将由其最终结果被翻译成计算机语言的可能性所决定。‘知识的生产者’和使用者现在必须，将来也将不得不具备将他们想要学习的任何东西翻译成这些语言的手段。”^[21](#chapter_2.xhtml#chapter2-21) 利奥塔将他的诊断——我们已从其他语言（特别是叙事语言）转向计算机语言——称为“后现代条件”。利奥塔的后现代条件或许更精确地应称为“计算条件”，一种涵盖数字意识形态和数字生活双方的条件。在我使用的“计算条件”一词中，我期望人文学者能听到让-弗朗索瓦·利奥塔的“后现代条件”和汉娜·阿伦特的“人的条件”^[22](#chapter_2.xhtml#chapter2-22) 的回响。计算条件是一种知识状态，在这种状态下，科学和技术确立的等价性被视为完美的恒等式，翻译的双方没有损失也没有增益。它们是被当作恒等式的等价性，因此当它们被放在一起说时，听起来像荒谬的同义反复：我可以要一杯 H₂O 水吗？

如果数字意识形态的等价性一经证明，被广泛且足够频繁地重复，它们就会被视为文化制约的常识。根据这种意识形态和常识的概念，常识是动态的，并随着新思想和新技术的流行而变化。用哲学家安东尼奥·葛兰西的话说：“每个社会阶层都有其自身的‘常识’和‘良知’，它们基本上是对生活和人的最普遍的观念。每一种哲学思潮都在其背后留下了一种‘常识’的沉淀：这是其历史效力的文献。常识不是僵化和静止的，而是不断地自我转化，用进入日常生活的科学思想和哲学观点来丰富自己……常识创造了未来的民俗，即在特定地点和时间大众知识的一个相对僵化的阶段。”^[23](#chapter_2.xhtml#chapter2-23)

数字意识形态在日常数字生活中被使用，此时狭窄、技术性、受限的等价性被放宽并扩展。例如，生活在计算条件中的人们，把发给家人的电子邮件视为与通过邮政系统寄送、由人手投递的手写信件是同一事物，并不觉得有任何矛盾。当我们在流媒体视频服务上看电影时，我们会说我们看过这部电影，即使小屏幕体验与过去去电影院的条件（爆米花、人群、纸质票）截然不同。更微妙的是，当我们说我们在“搜寻”某人或某物，或说我们与某人是“朋友”时，现在已不清楚我们做的是数字行为还是物理行为。

## 从媒介研究到行动者-网络理论

那么，数字意识形态的等价性是如何被使用、放宽并扩展为数字生活的？某些形式的科学与媒介研究，以及更新形式的社交媒体分析，采用了一种观念“扩散”模型，或用流行病学或遗传学的隐喻来设想观念的运动。^[24](#chapter_2.xhtml#chapter2-24) 观念被说成“像病毒一样传播”^[25](#chapter_2.xhtml#chapter2-25)（因此有了“病毒式媒体”一词），或像基因一样通过繁殖和进化移动（因此有了“模因”概念）。^[26](#chapter_2.xhtml#chapter2-26)

许多老派的传播与媒介研究学派也将人比作物理或机械系统。例如，大众传播的主导隐喻是“大众”或物理系统。这个隐喻允许研究者提出诸如“特定信息对受众有何*影响*？”^[27](#chapter_2.xhtml#chapter2-27) 这样的问题。

在 20 世纪 40 年代，罗伯特·默顿和保罗·拉扎斯费尔德^[28](#chapter_2.xhtml#chapter2-28) 推进了一个研究计划，其中社会结构被视为稳定或不稳定、处于平衡或失衡状态，这取决于群体动力学和影响群体成员的媒介信息。将人视为热力学系统的隐喻，引出了关于社会秩序生成与瓦解的问题。

所有旨在解释观念如何流动的新旧媒介研究隐喻都是不准确且略带侮辱性的，因为它们具有讽刺意味地隐含假设：人们没有语言——人们不说话、不听、不读、不写。这些扩散、传染、蔓延、影响、平衡和进化的概念，都将人描绘成哑巴、非人类的动物、有机或无机材料。显然，人们不仅仅是仅由牛顿力学驱动的惰性物质。他们也不是观念被“扩散”通过的专属多孔材料、病毒“传染”的载体，或仅限于繁殖其“基因”或“模因”的繁殖动物！与这些新旧传播与媒介研究学派相反，让我们从一个更合理的假设出发：人们会思考和说话。
