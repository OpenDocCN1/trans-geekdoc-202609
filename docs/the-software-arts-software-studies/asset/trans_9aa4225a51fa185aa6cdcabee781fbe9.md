
这种为哲学用途而从数学中“借用”的做法，在今天看来并非是从一个显赫的领域向地位较低的领域借用。内茨的研究表明，情况恰恰相反。在柏拉图时代，数学几乎无人知晓，是一个只有少数从业者的冷门领域。^([38](#chapter_6.xhtml#chapter6-38)) 但柏拉图及其追随者从数学中借用方法，是因为它提供了一种将命题置于意见之外、超越争辩、在无争议中解决问题的途径。^([39](#chapter_6.xhtml#chapter6-39)) 如前所述，这是通过高度限定的词汇来维持的；专注于图表而不涉及图表之外的内容；以及极其明确因而透明的论述：数学家展示了他们所有的工作过程。^([40](#chapter_6.xhtml#chapter6-40)) 这些正是亚里士多德视为演绎证明模范的积极特征，是确立真知识的手段。

亚里士多德的修辞性、展示性演示借用自逻辑性、辩证法性演示，后者又借用自数学的、特别是几何学的判证性、演绎证明方法：从判证性到辩证法，再到展示性；分别对应着理想、受理想启发的模范、以及基于模范的松散方法。

我们不妨将这一三元组称为“指示性”（判证性、辩证法性、展示性），因为每一种推演都以某种形式的演示为蓝本。在柏拉图和亚里士多德的文本中，我们可以辨识出一种尝试，即使用简约而简单的词汇，以满足演绎的、演示性的严谨性要求。^([41](#chapter_6.xhtml#chapter6-41)) 但图表、演示的视觉维度发生了什么变化？

正如媒介理论家马歇尔·麦克卢汉提醒我们的那样，书面文本*本身*就是一种视觉制品：“语音字母，西方文化的语言和神话形式，拥有将我们所有感官*转译*【我所加重音】或还原为视觉的和‘图像性’的或‘封闭的’空间的力量。比任何人都更清楚这一点的是数学家，他们意识到这种连续、同质的视觉空间具有任意和虚构的性质。为什么？因为数字，科学的语言，是一种将欧几里得空间虚构*再转译*【我所加重音】回听觉和触觉空间的虚构。”^([42](#chapter_6.xhtml#chapter6-42)) 在视觉研究学科和当代视觉文化讨论中，我们往往忘记了文本是视觉的。麦克卢汉论述了在古希腊识字时代来临之前，没有任何东西被记录下来，所有需要重复的内容都被记在记忆中并口述。在口语文化中，人们无法指向或展示自己的言语；在文字文化中则可以，因为言语一旦写下来就变成了视觉的。

我们可以考察几何学演绎演示的具体细节是如何被转译进辩证法和逻辑学文本中的，例如亚里士多德保留单个字母（如 X、Y 和 Z）作为变量，以代表逻辑陈述中的特定命题。但即使不仔细审视这些转译，仍然可以看出展示、演示的实践是如何在具有读写能力的指示性修辞形式中延续下来的。除其他事项外，学术引用、引文和理论化的实践便是明证。^([43](#chapter_6.xhtml#chapter6-43))

## 雅典的竞技性

要理解柏拉图及其追随者为何想要借用判证性方法，我们需要对他们面对的是谁、是什么有一定的洞察：一个由诗人和政治家组成的旧政权，以及一个由律师和诉讼当事人组成的新政权。

正如埃里克·哈维洛克在其著作《柏拉图前言》^([44](#chapter_6.xhtml#chapter6-44)) 中所论证的，柏拉图致力于区分一种新的教育和政府形式，超越由诗意心态所诱发的意见之争。因此，柏拉图反对基于口语的传统文化记忆形式，如荷马史诗的吟诵，因为在这类表演中不会追究关键问题。因此，正如第 5 章开头关于逻辑学的简述，辩证法的原始形式是为打断此类表演而发展起来的，旨在向表演者提问或要求重复某事。在希腊识字普及之前，诗歌不仅是娱乐，也是政治。政治家即诗人，因为公开演讲需要一种易于记忆的形式，而在口语文化中，没有什么比押韵和有节奏的语言更易记忆。在口语文化中，一个不是诗人的政治家注定会被遗忘。

历史学家沃尔特·翁将这种从诗人-政治家政权的转变概括为从口语到文字的转变，即书面记录在文化和政府中取代了口语实践。^([45](#chapter_6.xhtml#chapter6-45)) 但雅典从诗歌到散文的转变是一个渐进、充满挑战且复杂的过程，由包括柏拉图本人和伯里克利（前 495 年–前 429 年）在内的许多人争取和推动，后者在波斯战争和伯罗奔尼撒战争之间的“黄金时代”促进了雅典民主。

民主制度的兴起为柏拉图的对手——智者派的新兴影响力创造了必要的政治和经济条件。一些智者来自雅典，但许多来自希腊其他地方，为有志从政者提供说服性演讲教育。在不再依据贵族权威来选拔决策和领导层的新民主制度中，不仅政治家，所有公民都必须懂得如何具有说服力地演讲。历史学家 J. B. 贝里的话是：“希腊民主城邦的制度预设普通公民具备公开演讲的能力，对于任何有政治野心的人来说，这更是不可或缺。如果一个人被仇敌拖进法庭却不会演讲，他就如同遭士兵攻击的手无寸铁的平民。”^([46](#chapter_6.xhtml#chapter6-46))

作为生前雅典最具影响力的领袖，伯里克利欢迎智者派——说服性演讲的大师级表演者和教师——有着多重动机。他自己的崛起关键性地依赖于演说家的训练。^([47](#chapter_6.xhtml#chapter6-47)) 他的爱人兼伴侣、米利都的阿斯帕西娅，作为一个在雅典公共事务中拥有存在感的外邦人和女性，几乎是独一无二的，她以强有力的演讲者和修辞学教师而闻名。^([48](#chapter_6.xhtml#chapter6-48)) 伯里克利和阿斯帕西娅与智者派在社交上往来，有时据说还在政治上保护他们。^([49](#chapter_6.xhtml#chapter6-49)) 最后但或许同样重要的是，在雅典推行民主改革后，阿斯帕西娅和伯里克利本人都遭受了其他公民的诉讼攻击。^([50](#chapter_6.xhtml#chapter6-50))

伯里克利在同胞中显然是卓越的，在赞助智者派方面也可能是独一无二的。但他的案例可以被视为典范，说明为何那些负担得起的雅典公民会如此热切地接受智者派提供的教育和说服性辩论技巧：他们需要在日益民主化的雅典中竞争并赢得一席之地。
