

你急匆匆回家，下载了这本食谱，立刻动手操作。你兴奋不已。所有食材都备齐了。分步说明也在手边。一切进展顺利，直到你尝试这一步：“将蛋白与一撮盐打发，直到形成坚实但非干性的发泡峰。”你自问：“坚实峰和干性峰有什么区别？我该如何打发才能得到前者而非后者？”问题在于魔鬼藏在细节里。食谱（或算法）看似包含了你所需的一切知识，但——无论多么详尽——总有一些关键细节缺失。换句话说，确定性不是一种特征，而是算法一个不可能实现的理想。

有效性条件是确定性问题的加剧版。什么是“普通”人仅凭简单工具（纸笔、打蛋器和碗等）能在有限时间内精确完成的？让我们设想一个未来：勒加夫罗什餐厅已倒闭，鲁大师的食谱早已绝版。你试图在一个世纪后复刻瑞士舒芙蕾。厨房技术已发生根本变革，二十一世纪初常见的食材如今已成稀缺品。也许朴素的打蛋器已灭绝，工业养鸡业被视为过于残酷而终止，或某种未来变种禽流感重创鸟类种群，导致一枚鸡蛋的价格约等于半年薪水。魔鬼不仅藏在细节里，也藏在语境中。某一历史时刻、某一人群的“有效性”，不一定适用于不同时代的不同人群。

计算机科学家已经处理过类似问题。在算法中，正如食谱中一样，并非每个细节都明确列出。只包含关键细节，而这些细节建立在一种几乎无处不在的硬件和软件的既有语境假设之上：编程语言、操作系统和网络协议。

食谱和算法同样不精确且依赖语境。认真对待这一类比，就意味着承认文化史或智力史的理论与方法——正如它们可应用于食物与食谱的研究^([15](#chapter_4.xhtml#chapter4-15))——同样适用于算法的研究。

## 算术史

算法的历史与算术的历史纠缠在一起。在最早的形式中，算法只是算术的一种形式。然而，这么说并不意味着这是一段简单的历史。“算术化”，即对算术的重新审视，是当代数学与计算的基石，也是如今所谓“数字融合”的先驱。算术化既是对数与算术逻辑基础的探寻，反之亦是对逻辑算术基础的探寻。我们可以将这种循环式的探寻理解为历史学家海登·怀特所谓的“编陷”。^([16](#chapter_4.xhtml#chapter4-16))

算术、计算——广义上的计算——不只是一种工作，而是多种工作。存在多种算术这一观点在哲学中已讨论了数千年。柏拉图至少描述了两种。^([17](#chapter_4.xhtml#chapter4-17)) 第一种是军事指挥官的算术：

> 苏格拉底：我们能否否认战士应具备算术知识？
>
> 格劳孔：当然应具备，如果他要对军事战术有起码的理解，甚至我宁愿说，如果他要算得上一个人的话。

根据柏拉图，不懂算术就无法成为领袖；而且，男孩甚至无法成为男子汉。^([18](#chapter_4.xhtml#chapter4-18)) 但随后苏格拉底与格劳孔的对话揭示了一个转折。显然，战士和哲学家的计算不应与店主的算术混为一谈。^([19](#chapter_4.xhtml#chapter4-19))

> 苏格拉底：我必须补充这门学问多么迷人！如果以哲学家而非店主的精神去追求，它能以多少方式助我们达成预期目的！
>
> 格劳孔：何以见得？
>
> 苏格拉底：我的意思是，正如我所说，算术具有极大的提升作用，迫使灵魂对抽象数进行推理，并反对将可见或有形的物体引入论证中。

我们该如何理解这一点？即如何理解柏拉图的观点：作为哲学家或军事战术家进行的算术，与作为店主进行的算术，是完全不同的追求？^([20](#chapter_4.xhtml#chapter4-20))

唐纳德·克努特的《计算机程序设计艺术》第二卷第4章专门论述算术。克努特以算术简史开篇，正是在他的这段历史中，可以找到柏拉图区分店主算术与哲学家算术的先声。据克努特记载，楔形文字泥板显示，早在公元前1750年，巴比伦人就有两套截然不同的数字表示系统。^([21](#chapter_4.xhtml#chapter4-21)) 其中一套系统被店主等人用于日常商业交易，此类交易很少涉及大数。第二套系统是一种位值记数法，由数学家为数学家开发，特别适合乘法和除法。希腊天文学家（推测其他自然哲学家也一样）采用了巴比伦数学家的后一套系统。相比之下，希腊店主则使用一种早期的算盘，利用板上的沙子和鹅卵石进行日常生意。

“abacus”（算盘）一词源自希腊语“abax”（意为“板”）和希伯来语“abhaq”（意为“尘土”）。^([22](#chapter_4.xhtml#chapter4-22)) 因此，在古希腊，作为哲学家进行计算所涉及的活动，与作为店主使用算盘进行算术所涉及的活动，完全是两套不同的体系；后者正如柏拉图厌恶地指出的，会使用“可见或有形的物体”。^([23](#chapter_4.xhtml#chapter4-23))

因此，对柏拉图而言，存在着一种算术与另一种算术的区别，取决于谁在做、怎么做、用什么做。因此，取决于将其置于语境中的制度，算术要么是哲学家从事的“高层”工作，要么是店主从事的“低层”工作。这种高层与低层计算形式的区别持续了一千多年。在十五世纪的欧洲，前者可在大学学习，后者则可在由商业算术大师经营的专门学校学习。^([24](#chapter_4.xhtml#chapter4-24)) 在十五世纪威尼斯的商人群体中，使用算盘的算术大师与采用新算术算法（允许用纸笔进行计算）的人之间出现了竞争（见图[4.1](#chapter_4.xhtml#fig4_1)）。
