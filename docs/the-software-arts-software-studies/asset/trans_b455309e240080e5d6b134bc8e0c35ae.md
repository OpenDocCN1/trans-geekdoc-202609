

# 语言机制与描述性语法的矛盾

## 索绪尔的语言机制

阅读索绪尔《普通语言学教程》^([51](#chapter_7.xhtml#chapter7-51))第六章“语言机制”，可以看到索绪尔关于机制构想的草图。他声称它的运作方式像一台（推测为机械的）机器^([52](#chapter_7.xhtml#chapter7-52))，“在我们的大脑中潜意识地运作，^([53](#chapter_7.xhtml#chapter7-53))支配着一个确定和选择的过程，不仅涉及词和语序，甚至包括语音要素。”^([54](#chapter_7.xhtml#chapter7-54)) 索绪尔指出，语言中的某些选择是任意的，而另一些是有动因的：“可以区分词汇语言和语法语言，在前者中缺乏动因达到最大程度，在后者中则降至最低。这并不意味着‘词汇’和‘任意’总是同义词，或者‘语法’和‘相对有动因’也是同义词。但原则上它们是联系在一起的，”^([55](#chapter_7.xhtml#chapter7-55)) 此外，“我们必须采取语言结构本身的性质所要求的观点，把语言机制作为一种对任意性施加限制的方式来研究。”^([56](#chapter_7.xhtml#chapter7-56))

顺着索绪尔的思路，语法是大脑中的一种机制，它解释了语言中非任意的部分；它解释了语言的规律性。这构成了语法地位的根本性变化。

## 从规定性到描述性

根据哈里斯的说法，在索绪尔之前，语法是一个教学和政治（帝国建设和为新兴民族国家确立教育标准）的项目。因此，十九世纪及以前的语法规则是给学生的规定性指导。成功的学生可以通过学习语法规则来掌握一种语言的标准形式。从事这一教学项目的语法学家——如波尔-罗亚尔语法学家——因此可以想象一个人可能会“违背”语法的规定性规则（如前所述）。但在索绪尔之后，语法被理解为描述大脑的运作。一个人怎么能“违背”一种解剖学描述呢？

一方面，这给相信语法规则具有描述性地位的索绪尔之后的语法学家或语言学家提出了一个难题：如果规则描述的是大脑中的一种机制，那么人们在言语和写作中频繁犯语法错误，这怎么可能呢？

另一方面，正如哈里斯指出的，索绪尔重塑语法规则具有巨大的战略价值。通过将语法规则移入大脑并断言它们是描述性的，索绪尔使语言学摆脱了教导学生规定性规则的业务，并确立了语言学作为一门拥有自主研究对象的自然科学：“因此，虽然宣称语言是一种社会现实，但索绪尔语言学将这种现实在个体中的构成归因于自动机械，无论识字与否、语法学家与外行，没有人能控制它。”^([57](#chapter_7.xhtml#chapter7-57))

哈里斯认为，索绪尔宣称语法规则不是规定性的，而是认知功能的描述，这对于将现代语言学领域确立为一门科学至关重要。当语法是规定性的时——这持续了数千年——它是一门艺术，一门关于如何用词的艺术。当语法变成描述性的时，语法被视为一门科学，一门语言科学，语言学的一部分。

## 乔姆斯基与历史锚点

我们现在明白为什么乔姆斯基要将他的装置与非常古老的文本联系起来。这些装置很重要，因为它们为语言学科学确立了研究对象。但为了将他的特定语言学与计算机科学区分开来，乔姆斯基必须将其研究对象与计算机硬件和软件区分开来。一种方法是在计算机硬件和软件存在几个世纪前写成的文本中“发现”研究对象。

## 描述性语法的矛盾

除了缺乏历史证据来证实乔姆斯基关于递归装置已隐含存在于十七世纪著作中的断言外，乔姆斯基——实际上所有当代语言学家——必须审视其所选研究对象的另一个困难。如果像大多数当代语言学家那样坚持语法规则是描述性的而非规定性的，那么——正如哈里斯指出的——这一描述性宣言的代价，就是在当代语言学的核心处植入了一个矛盾。

乔姆斯基语言学通过声称（a）语法规则描述说话者，因此依赖于说话者，以及（b）语法规则独立于说话者：语法规则是一台自主的机器，可以独立于任何说话者运行并生成语言，来表达这一矛盾。因此，语法规则不仅描述，而且定义——也就是说，规定——语言所采取的形式。^([58](#chapter_7.xhtml#chapter7-58))

这一矛盾由乔姆斯基和合著者莫里斯·哈莱表述如下：“我们系统性地模糊使用‘语法’一词。一方面，该词指语言学家构建的显性理论，被提议作为对说话者能力的描述。另一方面，我们用该词指称这种能力本身。前一种用法是熟悉的；后一种用法虽然可能不那么熟悉，但同样恰当。”^([59](#chapter_7.xhtml#chapter7-59)) 语法不仅可以是能力的描述，实际上*就是*那种能力这一想法，暗示了语法可以自行运作。索绪尔需要布罗卡关于大脑解剖的研究，才能可信地声称大脑中存在“语言机制”。类比而言，乔姆斯基——正如他在前文引用的 2016 年接受《纽约时报》采访时提到的——需要现代计算理论，才能可信地声称语法能自主地定义一种能力。正如我们将看到的，乔姆斯基的提议等同于假定语法规则为一种软件形式。

## 乔姆斯基的语法

那么，具体来说，乔姆斯基式的装置是什么样子的？在 1964 年发表的一篇文章《论“语法规则”概念》中，乔姆斯基精确地描述了他将语法等同于装置时的含义：“我说语言 L 的语法，是指某种装置（即一套规则），它至少提供 L 语中无限组语法句子及其结构描述的完整规格说明。”^([60](#chapter_7.xhtml#chapter7-60))

因此，语法是由一套规则组成的装置。但在认识论上，什么是语法？根据乔姆斯基，它是一种理论：“按上述意义说的语法，实质上是语言句子的一种理论。”^([61](#chapter_7.xhtml#chapter7-61))

因此，用乔姆斯基的习语表达，语法/理论是一套规则，可以如下所示。

```
Sentence → NounPhrase + VerbPhrase
NounPhrase → Article + Noun
VerbPhrase → Verb + NounPhrase
Article → the
Article → a
Noun → man
Noun → ball
Verb → hit
Verb → took
```

这个示例语法改编自乔姆斯基 1957 年的著作《句法结构》^([62](#chapter_7.xhtml#chapter7-62))（这本书最初是为麻省理工学院的一门本科课程而写的）。^([63](#chapter_7.xhtml#chapter7-63))
