Notice that the loop starting on line 43 lets the user know when they have a real login name but the wrong password. If the security of your data is very important, you may want to write this loop differently. Providing that information may be helpful to someone who is trying to break in. The cracker now only needs to find the password. For more security, just have one condition that gives the same error message whenever either the login name or the password is incorrect. In this example, I prefer to provide the information because it is helpful to the legitimate member (who may not remember whether he or she installed an account at all), and I’m not protecting any vital information.
