
尽管存在局限性，`header` 函数仍然很有用。你可以在 `header` 函数之前有任意多的 PHP 语句，只要它们不发送输出即可。因此，以下语句可以正常工作：

```php
<?php
    if ($customer_age < 13)
    {
        header("Location: ToyCatalog.php");
    }
    else
    {
        header("Location: ElectronicsCatalog.php");
    }
?>
```

这些语句运行一个程序，如果客户年龄小于 13 岁则显示玩具目录，如果客户年龄为 13 岁或以上则显示电子产品目录。

## 从页面到页面传递信息

HTML 页面彼此独立。当用户点击链接时，Web 服务器向用户浏览器发送新页面，但 Web 服务器对之前的页面一无所知。对于静态 HTML 页面，这个过程工作正常。然而，许多动态应用程序需要在页面之间传递信息。例如，你可能想存储用户的姓名，并在另一个网页上以姓名引用该人。

动态 Web 应用程序通常包含多个页面，并期望用户查看多个不同的页面。从用户查看第一个页面开始到用户离开网站结束的这段时间是一个 *会话*。通常你希望信息在整个会话期间可用。以下是在页面之间需要共享信息的会话示例：

- **限制对网站的访问：** 假设你的网站受限，用户需要用密码登录才能访问网站。你不希望用户在每个页面都必须登录。你只希望他们登录一次，然后能够查看他们想要的所有页面。你希望用户随身携带信息到每个页面，表明他们已登录并有权查看该页面。你希望用户在整个会话期间登录并保持登录状态。
- **根据浏览器提供网页：** 因为浏览器对某些 HTML 功能的解释不同，你可能希望为不同浏览器提供不同版本的网页。你希望在用户查看第一个页面时检查用户的浏览器，然后根据用户的浏览器类型和版本提供所有其他页面。

使用 PHP，你可以通过以下任何方法在页面之间传递信息：

- **向 URL 添加信息：** 你可以将某些信息添加到新页面 URL 的末尾，PHP 会将信息放入内置数组中，以便在新页面中使用。这种方法在你只需要传递少量信息时最为合适。
- **通过 cookie 存储信息：** 你可以在用户计算机上存储 *cookie* ——包含 `variable=value` 对的小量信息——。Cookie 存储后，你可以从任何网页获取它。然而，用户可以拒绝接受 cookie。因此，此方法仅在你确定用户已启用 cookie 的环境中才有效。
- **使用 HTML 表单传递信息：** 你可以使用 `form` 标签将信息传递给特定程序。当用户点击提交按钮时，表单中的信息会被发送到下一个程序。这种方法在你需要从用户收集信息时非常有用。
- **使用 PHP 会话函数：** 从 PHP 4 开始，可用 PHP 函数设置用户会话并在服务器上存储会话信息；这些信息可以从任何网页访问。这种方法对于期望用户查看多个页面的会话非常有用。

## 向 URL 添加信息

将信息添加到 URL 是一种从一个页面到下一个页面传递信息的简单方法。把信息放在以下格式中：

```
variable=value
```

*变量* 是一个变量名，但其中不要使用美元符号 ($) 。*值* 是要存储在变量中的值。你可以在使用 URL 的任何地方添加 `variable=value` 对。你用问号 (?) 标记信息的开始。以下语句都是在 URL 中传递信息的有效方式：

```
<form action="nextpage.php?state=CA" method="POST">
```

```
<a href="nextpage.php?state=CA">go to next page</a>
```

```
header("Location: nextpage.php?state=CA");
```

你可以添加多个 variable=value 对，用与号 (&) 分隔，如下所示：

```
<form action="nextpage.php?state=CA&city=home" method="POST">
```

以下是你可能不想在 URL 中传递信息的两个原因：

- **安全性：** URL 显示在浏览器的地址栏中，这意味着附加到 URL 的信息也会显示出来。如果信息需要保密，你就不希望它如此公开地显示。例如，如果你将密码从一个页面传递到下一个页面，你可能不希望在 URL 中传递它。此外，URL 可以被用户书签保存。可能有原因不希望用户保存你添加到 URL 的信息。
- **字符串长度：** URL 的长度有限制。限制因各种浏览器和浏览器版本而异，但总是有限制的。因此，如果你传递大量信息，可能没有足够的空间放在 URL 中。

向 URL 添加信息对于快速、简单的數據传输非常有用。例如，假设你想提供一个网页，让用户更新他们的电话号码。你希望表单按以下方式运行：

1. 当用户首次显示表单时，数据库中的电话号码会显示在表单中，以便用户可以看到数据库中当前存储的号码。
2. 当用户提交表单时，程序会检查电话号码，查看该字段是否为空或该字段的格式不可能是电话号码。
3. 如果电话号码检查正常，则该号码会存储在数据库中。
4. 如果电话号码为空或数据错误，程序会重新显示表单。然而，这次你不想显示数据库中的数据。相反，你想显示用户在表单字段中输入并提交的错误数据。

`displayPhone.php` 程序在列表 9-1 中展示了如何使用 URL 来确定这是表单的首次显示还是后续显示。该程序显示用户登录名的电话号码，并允许用户更改电话号码。
