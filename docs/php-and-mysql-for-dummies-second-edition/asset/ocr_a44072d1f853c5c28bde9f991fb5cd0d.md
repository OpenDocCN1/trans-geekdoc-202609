# Building lists of check boxes

You might want to use check boxes in your form. Check boxes are different from selection lists and radio buttons because they allow users to select more than one option. For instance, if you display a list of pet categories by using check boxes, a user can check two or three or more pet categories. The program buildCheckbox.php in Listing 8-11 creates a list of check boxes.
