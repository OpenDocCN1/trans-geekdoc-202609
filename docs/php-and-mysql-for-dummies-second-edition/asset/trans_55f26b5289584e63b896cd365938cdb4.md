
## 配置 Apache

当 Apache 启动时，它会从配置文件中读取信息。如果 Apache 无法读取配置文件，则无法启动。除非你告诉 Apache 使用不同的配置文件，否则它会在 Apache 安装的目录中查找文件 `conf/httpd.conf`。

### 更改设置

Apache 根据配置文件中的命令，即 *directives*，来运行。你可以通过编辑配置文件并重启 Apache 使其读取新的指令来更改 Apache 的部分行为。

配置文件是一个包含称为指令的命令的文本文件。Apache 根据此文件中的指令运行。在大多数情况下，默认设置允许 Apache 在你的系统上启动和运行。然而，在某些情况下你可能需要更改设置。你可能想要更改设置的一些原因有

- **安装 PHP：** 如果你安装了 PHP，你需要配置 Apache 以识别 PHP 程序。如何更改 Apache 配置以支持 PHP 在附录 B 中描述。
- **更改你的 Web 空间：** Apache 会在特定目录及其子目录中查找网页文件，通常称为你的 Web 空间。你可以更改 Web 空间的位置。
- **更改 Apache 监听的端口：** 默认情况下，Apache 在端口 80 上监听文件请求。你可以配置 Apache 监听不同的端口。

要更改任何设置，请编辑文件 `httpd.conf`。在 Windows 上，你可以通过菜单“开始→程序→Apache HTTPD Server→配置 Apache 服务器→编辑 Apache httpd.conf 文件”访问此文件。点击此菜单项时，`httpd.conf` 文件会在记事本中打开。

`httpd.conf` 文件包含注释（以 `#` 开头）来描述指令，但在更改任何指令之前，你应确保理解其功能。所有指令都在 Apache 网站上进行了文档说明。

添加或更改文件路径/名称时，请使用正斜杠，即使目录位于 Windows 上。Apache 可以识别出来。此外，路径/名称只有在包含特殊字符时才需要加引号。冒号 (:) 是一个特殊字符；下划线 (_) 和连字符 (-) 不是。例如，要表示 Windows 目录，你可以使用以下类似的内容：

```
"c:/temp/mydir"
```

更改任何设置后请记得重启 Apache。设置在 Apache 重启前不会生效。有时使用重启命令无法更改设置。如果新设置似乎未生效，请尝试使用 stop 停止服务器，然后使用 start 启动它。

### 更改 Web 空间的位置

默认情况下，Apache 会在 Apache 安装目录中的子目录 `htdocs` 中查找你的网页文件。你可以使用 `DocumentRoot` 指令更改此设置。查找以 `DocumentRoot` 开头的行，例如以下内容：

```
DocumentRoot "C:/Program Files/Apache Group/Apache/htdocs"
```

将文件路径/名称更改为你想要存储网页文件的位置。不要在目录路径末尾包含正斜杠 (/)。例如，以下可能是你的新指令：

```
DocumentRoot /usr/myserver/Apache2/webpages
```

### 更改端口号

默认情况下，Apache 监听端口 80。例如，如果你为测试目的设置第二个 Apache 服务器，你可能想要更改此设置。端口通过使用 `Listen` 指令设置如下：

```
Listen 80
```

对于 Apache 2，`Listen` 指令是必需的。如果未包含 `Listen` 指令，Apache 2 将无法启动。

你可以按如下方式更改端口号：

```
Listen 8080
```

更改任何指令后请记得重启 Apache。
