
因为会话对于启用Cookie的用户和禁用Cookie的用户有所不同，你应该在这两种条件下测试这两个程序。要在浏览器中关闭Cookie，你可以更改选项或首选项的设置。

要在Internet Explorer中禁用Cookie，请按照以下步骤操作：

- 1. **选择“工具”→“Internet选项”。**
“Internet选项”对话框随即打开。
- 2. **在IE 5.5中单击“安全”选项卡，或在IE 6中单击“隐私”选项卡。**
- 3. **单击“Internet”图标将其高亮显示。**
- 4. **单击“自定义级别”按钮。**
“安全设置”对话框随即出现。
- 5. **向下滚动到“Cookie”区域，并为每个Cookie设置选择“禁用”。**
- 6. **单击“确定”。**

要在Netscape Navigator中禁用Cookie，请按照以下步骤操作：

- 1. **选择“编辑”→“首选项”。**
- 2. **突出显示“高级”。**
- 3. **勾选“禁用Cookie”。**
- 4. **单击“确定”。**

如果在浏览器中关闭Cookie后，sessionTest2的输出显示$session_var为空值，这很可能是因为trans-sid未启用。你可以在php.ini文件中启用trans-sid。找到以下行：

```
session.use_trans_sid = 0
```

将0改为1即可启用trans-sid。如果你无法解决此问题，你仍然可以使用会话，但必须在编程语句中传递会话ID号，因为当Cookie被关闭时PHP不会自动传递它。有关在未启用trans-sid时如何使用会话的详细信息，请参阅下一节。

对于PHP 4.1.2或更早版本，除非在编译PHP时使用了--enable-trans-sid选项启用它，否则trans-sid不可用。

## 不使用Cookie的会话

许多用户会在浏览器中关闭Cookie。PHP会检查用户的浏览器是否允许Cookie，并据此采取相应行为。如果用户的浏览器允许Cookie，PHP将执行以下操作：

- ✓ 设置变量$PHPSESSID等于会话ID号
- ✓ 使用Cookie将$PHPSESSID从一页传递到下一页

如果用户的浏览器设置为拒绝Cookie，PHP将执行以下操作：

- ✓ 设置一个名为SID的常量。该常量包含一个看起来像PHPSESSID=一长串数字的变量=值对。
- ✓ 根据trans-sid是否启用，可能会或可能不会将会话ID号从一页传递到下一页。如果已启用，PHP会传递会话ID号；如果未启用，PHP不会传递会话ID号。

启用trans-sid有利也有弊。优点是，即使关闭了Cookie，会话也能无缝工作。而且启用trans-sid后，会话编程要容易得多。缺点是，会话ID号经常在URL中传递。在某些情况下，会话ID号不应显示在浏览器地址栏中。此外，当会话ID号在URL中时，用户可能会将其添加为书签。然后，如果用户使用包含会话ID号的书签返回你的网站，当前访问的新会话ID号可能会与上次访问的旧会话ID号混淆，并可能引发问题。

## 启用trans-sid时的会话

启用trans-sid且用户关闭了Cookie时，PHP会自动在URL中或作为隐藏表单字段发送会话ID号。如果用户通过链接、header函数或使用get方法的表单进入下一页，会话ID号会被添加到URL中。如果用户通过使用post方法的表单进入下一页，会话ID会在隐藏字段中传递。PHP将$PHPSESSID识别为会话ID号，无需你做任何特殊编程即可处理会话。

![](img/d82df0828cfbc6d6be1e9a991861f3b7_294_0.png)

会话ID号只会被添加到你自己网站页面的URL中。如果下一页的URL包含服务器名称，PHP会假定该URL位于另一个网站，因此不会添加会话ID号。例如，如果你的链接语句是

```
<a href="newpage.php">
```

PHP将会添加会话ID号。但是，如果你的语句是

```
<a href="HTTP://www.company.com/newpage.php">
```

PHP不会添加会话ID号。

## 未启用trans-sid时的会话

未启用trans-sid时，如果用户关闭了Cookie，PHP不会将会话ID号传递到下一页。相反，你必须自己发送会话ID号。

幸运的是，PHP提供了一个常量，你可以用它自己发送会话ID。常量是一种包含无法更改的信息的变量。（第6章描述了常量。）PHP提供的常量名为SID，包含一个可以添加到URL的变量=值对，如下所示：

```
<a href="nextpage.php?<?php echo SID?>"> next page </a>
```

这个链接语句向URL添加了问号(?)和常量SID。SID包含格式为变量=值的会话ID号。echo SID的输出看起来像这样：

```
PHPSESSID=877c22163d8df9deb342c7333cfe38a7
```

因此，发送的URL为：

```
<a href="nextpage.php?PHPSESSID=877c22163d8df9deb342c7333cfe38a7">
    next page </a>
```

出于几个原因之一（本章前面“向URL中添加信息”一节中我会讨论），你可能不希望会话ID号出现在浏览器显示的URL中。为防止这种情况，你可以通过post方法在表单的隐藏字段中发送会话ID号。首先，获取会话ID号；然后将其发送到隐藏字段中。完成此操作的语句如下：

```
<?php
    $PHPSESSID = session_id();
    echo "<form action='nextpage.php' method='POST'>
        <input type='hidden' name='PHPSESSID'
            value='$PHPSESSID'>
        <input type='submit' value='Next Page'>
    </form>";
?>
```

这些语句执行以下操作：

- 1. 将会话ID号存储在名为$PHPSESSID的变量中。使用session_id函数，该函数返回当前会话ID号。
- 2. 在隐藏表单字段中发送$PHPSESSID。

在新页面上，PHP将自动使用$PHPSESSID获取任何会话变量，无需你做任何特殊编程。

## 使会话私有

PHP会话函数非常适合受限网站，这些网站要求用户使用登录名和密码登录。这些网站毫无疑问有许多页面，你不希望用户在每个页面上都登录。PHP会话可以跟踪用户是否已登录，并拒绝未登录用户的访问。你可以使用PHP会话执行以下操作：

- 1. 向用户显示登录页面。
- 2. 如果用户登录成功，设置并存储一个会话变量。
- 3. 每当用户进入新页面时，检查会话变量以确定用户是否已登录。
- 4. 如果用户已登录，显示该页面。
- 5. 如果用户未登录，则显示登录页面。

要检查用户是否已登录，请在每个页面的顶部添加以下语句：

```
<?php
session_start();
if ( @$_SESSION['login'] != "yes" )
{
header("Location: loginPage.php");
exit();
}
?>
```

在这些语句中，$_SESSION['login']是一个会话变量，当用户登录时被设置为“yes”。这些语句检查$_SESSION['login']是否等于“yes”。如果不等于，则用户未登录，并被发送到登录页面。如果$_SESSION['login']等于“yes”，程序继续执行网页上的其余语句。

## 关闭PHP会话

对于用户登录的受限会话，你通常希望在用户完成后让其退出。要关闭会话，使用以下语句：

```
session_destroy();
```

该语句会清除会话文件中存储的所有会话变量信息。PHP不再将会话ID号传递到下一页。但是，该语句不会影响当前页面上已设置的变量：它们仍然等于相同的值。如果你想从当前页面删除这些变量，并防止它们被传递到下一页，可以使用以下语句取消设置它们：

```
unset($_SESSION);
```
