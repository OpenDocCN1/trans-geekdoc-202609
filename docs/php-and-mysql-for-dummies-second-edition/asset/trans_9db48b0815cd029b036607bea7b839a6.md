## 第9章
### 将信息从一个网页传递到下一个网页
### 本章内容包括
- 将用户从一个页面带到下一个页面
- 将信息从一个页面传递到下一个页面
- 向URL添加信息
- 了解cookie
- 使用隐藏表单字段
- 探索PHP会话

大多数网站由多个网页组成。这包括你过去可能开发过的静态网页。对于静态网页，用户通过点击链接从一个页面移动到下一个页面。用户点击一个网页中的链接，新的网页就会出现在他们的浏览器中。当用户以这种方式在页面之间移动时，没有信息从第一个页面传递到第二个页面。发送到用户浏览器的每个新页面都独立于用户之前可能看过的任何其他页面。对于动态网页，你可能需要将信息从一个页面传递到下一个页面。如果你是一名高级HTML开发者，你可能对使用HTML表单和CGI（公共网关接口）或cookie在页面之间传递信息的有限方法有所了解。然而，PHP在网页之间传递信息方面要强大得多。

### 将用户从一个页面移动到另一个页面

仅使用HTML时，你提供链接，使访问者能够从网站的一个页面转到另一个页面。然而，使用PHP时，你有三种选项可以将用户从一个页面移到下一个页面。

**链接：** 你可以输出用于显示链接的HTML标签。显示链接的HTML语句的一般格式是

```
<a href="newpage.php">用户看到的链接文本</a>
```

当用户点击链接时，程序newpage.php被发送到他们的浏览器。这种方法在HTML网页中被广泛使用。你可能已经从HTML经验中熟悉了创建链接，但如果你需要复习，可以在任何HTML书籍中找到更多关于链接的信息，例如Deborah S. Ray和Eric J. Ray所著的*《HTML 4傻瓜快速参考，第2版》*（Wiley出版）。

**表单提交按钮：** 你可以使用一个带有一个或多个提交按钮的HTML表单。当用户点击提交按钮时，表单标签中的程序运行并向用户浏览器发送一个新网页。你可以创建一个没有字段的表单——只有一个提交按钮——但用户必须点击提交按钮才能移动到下一页。

我在第8章中详细讨论了表单和提交按钮。

**header函数：** 你可以使用PHP的header函数向Web服务器发送一条消息，告诉它发送一个新页面。使用这种方法，你可以在用户浏览器中显示新页面，而无需用户点击链接或按钮。

PHP的header函数可用于向用户浏览器发送新页面。程序使用header语句显示新网页，不需要任何用户操作。当header语句执行时，新页面就会显示。请求新页面的header函数格式如下：

```
header("Location: URL");
```

位于URL的文件被发送到用户浏览器。以下任一语句都是有效的header语句：

```
header("Location: newpage.php");
header("Location: http://company.com/catalog/catalog.php");
```

然而，header函数有一个主要限制。header语句只能用于发送任何其他输出之前。你不能在程序中已经向网页输出了一些内容之后，中途发送请求新页面的消息。关于“必须在输出之前使用的语句”的讨论，请参阅侧边栏。

### URL

URL（统一资源定位符）是万维网上的一种地址。每个网页都有自己的URL或地址。Web服务器使用该URL来查找网页并将其发送到浏览器。

URL的格式为

```
HTTP://servername:portnumber/path#target?string=string
```

以下是组成URL的各部分的说明：

HTTP://servername: 这告诉服务器该地址是一个网站，并给出网站所在计算机的名称。也可以指定其他传输类型，如FTP（文件传输协议），但这些与本书主题无关。如果省略URL的这一部分，Web服务器会假定该计算机就是输入URL的计算机。这一部分的有效选择是HTTP://amazon.com或HTTP://localhost。注意：HTTP不一定要大写。

:portnumber: Web服务器通过计算机上的特定端口与Internet交换信息。大多数情况下，Web服务器通过80端口进行通信。如果未指定端口号，则假定为80端口。在某些特殊情况下，Web服务器可能使用不同的端口号，此时必须指定端口号。使用不同端口号的最常见原因是在另一个端口上设置测试网站，该端口仅对开发人员和测试人员可用，不对客户开放。当网站准备好面向客户时，会通过80端口提供服务。

path: 这是文件的路径，遵循任何路径的规则。路径的根是网站主目录。如果路径指向目录而不是文件，Web服务器将搜索默认文件名，例如default.html或index.html。网站管理员设置默认文件名。路径 /catalog/show.php 表示主网站目录中一个名为catalog的目录和一个名为show.php的文件。路径catalog/show.php表示当前目录中一个名为catalog的目录。

#target: HTML标签定义目标。URL的这一部分会在目标标签所在的位置显示网页。例如，如果标签 <a name="target"></a> 位于文件中间的某个位置，网页将显示在该标签处，而不是文件顶部。

?string=string: 问号允许将信息附加到URL末尾。使用get方法的表单中的信息以fieldname=value的格式在URL末尾传递。你可以将信息添加到URL末尾以将其传递到另一个页面。PHP会自动从URL中获取信息并将其放入内置数组中。你可以通过用与号（&）分隔每个字符串对来传递多个string=string对；例如，?state=CA&city=home。

### 必须在输出之前使用的语句

有些PHP语句只能在发送任何输出之前使用。本章中描述的所有header语句、setcookie语句和会话函数，都必须在发送任何输出之前使用。如果你在发送输出后使用了这些语句之一，可能会看到以下消息：

```
Cannot add header information - headers already sent
```

该消息还会提供文件名，并指出是哪一行发送了先前的输出。或者你可能根本看不到消息；新页面可能就是不出现。（你是否看到错误消息取决于PHP中设置的错误消息级别；详见第6章。）下面的语句会失败，因为header消息不是第一个输出：

```
<html>
<head><title>testing header</title></head>
<body>
<?php
  header("Location: http://company.com");
?>
</body>
</html>
```

在header语句之前发送了三行HTML代码。下面的语句将起作用，尽管它们意义不大：

```
<?php
  header("Location: http://company.com");
?>
<html>
<head><title>testing header</title></head>
<body>
</body>
</html>
```

下面的语句将失败：

```
<?php
  header("Location: http://company.com");
?>
<html>
<head><title>testing header</title></head>
<body>
</body>
</html>
```

这些语句失败的原因不易察觉，但如果仔细观察，你会注意到在PHP起始标签之前有一个空格。这个空格会输出到浏览器，虽然最终网页看起来是空的。因此，header语句会失败，因为在其之前有输出。这是一个常见且难以发现的错误。
