# III. METHODOLOGY

Dataset was collected from the open-source covid-19 repository. The repository contains chest x-ray images, which were further cleaned and filtered for model training. The preparation of data, models were used to the transfer learning approach, and then different experiments are carried out.

# A. Transfer Learning Approach

Deep neural networks require a high volume of data to be trained from scratch, but in medical domain, data is not available, to eliminate this problem. Therefore we use a pre-trained model that was fine tuned. The models used were trained on a large dataset ImageNet. Then, we fine-the last layer of the convolutional network by training on the Covid-19 dataset. By doing this, we overcome the issue of data limitation for training the model the four different models, ResNet18, AlexNet, VGG 16, and Inception V3.

# B. ResNet18

In this approach, skip connection is the main idea, which overcomes the vanishing gradient problem. Layers are regular by using the residual learning function. This approach is considered the best in the 2015 year as of ImageNet competition. The benefit of ResNet is network that works with great depth using skip connections in the deeper layers.
