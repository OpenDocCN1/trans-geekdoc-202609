# C. AUC - ROC

AUC and ROC are important performance measures for the model evaluation, especially to visualize the multiclass models. ROC is generated using the false positive and true positive rate after the plotting of point that comes under the curve is called AUC. If the AUC value is close to 1, model will be considered good and if close to 0 it will be considered bad or weak. Our models ResNet18, V16, Inception V3, and AlexNet performed well.
