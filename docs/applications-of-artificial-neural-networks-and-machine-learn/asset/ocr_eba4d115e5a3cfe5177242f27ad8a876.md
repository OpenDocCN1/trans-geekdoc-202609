# 22.5.2 Parametric and Sensitivity Analyses

To further examine the robustness of developed GMDH and MARS models, a parametric analysis can be carried out. Parametric analysis investigates how closely the model predictions agree with available structural knowledge and experimental data and with one would expect. Therefore, parametric analysis was carried out with the aim to deeper understanding of concrete shear strength of HSC slender beams without web reinforcement. The parametric analysis investigates the response of the predicted shear strength from the proposed models to a set of hypothetical input data generated over the ranges of the minimum and maximum data used for the model training.
