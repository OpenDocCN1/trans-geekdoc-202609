In the Formex Configuration Processing, structural elements are defined based on their positions towards three basic directions U1, U2, and U3 being considered as suitable counterparts to axes X, Y, and Z in the three-dimensional Cartesian system. Parallel lines relative to these basic directions are named normat lines, and points of their intersections are known as normat points. Programmers determine distances between these normat lines individually. In the following instance, Fig. 5.3, the distances are considered a unity. In the Formex Configuration Processing, for example, the location of node C set in the lower layer is represented by three successive numbers separated by colons and put inside square brackets as: [1, 1, 0]; an element of the top layer located between nodes A and B, Fig. 5.3), is described as: [2, 2, 1; 4, 2, 1], where the third coordinate indicates the position of the lower or the top layer measured along with the third direction U3. Member CD located in the lower layer is described as: [1, 1, 0; 3, 1, 0], while the cross-brace AD is expressed as: [2, 2, 1; 3, 1, 0].
