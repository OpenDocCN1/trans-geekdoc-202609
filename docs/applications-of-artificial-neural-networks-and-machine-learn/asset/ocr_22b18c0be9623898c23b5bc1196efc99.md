# 1.6.9 Variational Auto Encoder Neural Network

Variational Auto Encoder (VAE) compresses probabilities instead of features compared to auto-encoder neural network. Despite the small changes that have happened between the two mentioned neural networks, each of these types of artificial neural networks answer a different question. Auto Encoder Neural Network to the question “How can data be generalized?” Answers, while the variable Auto Encoder neural network to the question “How strong is the connection between two events?” Should the fault be apportioned between the two events or are they completely independent?” answers. # 1.6.10 Denozing Auto Encoder Neural Network

Although Auto Encoder networks are interesting, these neural networks sometimes adapt only to the input data instead of finding the strongest feature (this is an example of overfitting). The Denoising Auto Encoder (DAE) neural network adds a little noise to the input cell. By doing this, the Denoising Auto Encoder neural network is forced to reconstruct the output from a noisy input and make it more general and the features choose the most common.
