# 20.4.3 The M5' Model

M5' algorithm divides data spaces into smaller subspaces and it builds a local multivariate linear regression in each subspace. Therefore, it could just propose a linear relation between the input and the output parameters. To overcome this limitation, a model is developed by log (inputs) and log (output). Then, the final developed model is rewritten as:

$$F_{max} = a_1 f_{mt}^{a_2} (E_p t_p)^{a_3} b_f^{a_4} L_b^{a_5} \left(\frac{b_p}{b_m}\right)^{a_6}$$

where \(a_1, a_2, ..., a_6\) are constants. The M5' algorithm provides its predictive model in the form of rules. These rules are simple and interpretable that can be easily used in bond strength calculations. The developed model tree is shown in Fig. 20.4. The developed rules are as follows:
