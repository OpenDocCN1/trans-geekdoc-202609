### A Hybrid Graph-Neural Method for Domain Decomposition

### Abstract

A hybrid method is presented for domain decomposition employing a graph theoretical algorithm and a neural network optimization model. The method uses graph theory and neural networks for decomposition of structured finite element meshes. Examples are included to illustrate the efficiency of the developed method.

## 17.1 Introduction

A hybrid method is presented for domain decomposition employing a graph theoretical algorithm and a neural network optimization model. The method uses graph theory and neural networks for decomposition of structured finite element meshes [1]. Parallel processing is often used for the analysis of large-scale structures and finite element models (FEMs). For this purpose a model may be decomposed into subdomains and the analysis is performed on each subdomain by an individual processor. Then the solutions are condensed and combined for the overall solution. For decomposition of a model, the following conditions should be considered:

- 1. Equal or near equal degrees of freedom for subdomains should be provided.
- 2. The number of interface nodes should be as close to minimum as possible.
- 3. Partitioned subdomains should have good aspect ratios.

The mathematical models of the skeletal structures are graphs. However, for FEMs artificial graphs can be associated to reduce the process of decomposition into that of their associate graphs. Many such graphs are used by Kaveh [2], the most suitable one used in this chapter is the partial clique graph of a FEM.

For decomposition of a graph into suitable subgraphs different methods are available which can be categorized as:

- Pure graph theoretical method;
- Pure algebraic graph theoretical approach;
- Pure neural network method;
- Mathematical optimization approach;
- Mixed combinatorial-algebraic graph theoretical method; and the new category namely, Hybrid graph-neural method introduced in this chapter.

A different classification based on the number of subdivisions can be made resulting in recursive and non-recursive subdomaining. In recursive partitioning a model is divided into 2^n subgraphs, while in the non-recursive method the number of subdivisions is arbitrary. Non-recursive graph theoretical methods have been developed by Farhat and Lesoinne [3] and Kaveh and Roosta [4]. The algebraic graph theoretical method of recursive spectral bisection has been suggested by Simon and Pothen et al. [5]. In mathematical optimization methods are represented in the form of an objective function [6]. The non-deterministic optimization methods such as simulated annealing and genetic algorithms are used to minimize the considered objective function. Other methods which have been used for decomposition are based on either graph theoretical optimization or algebraic graph theoretical optimization. These methods consist of two stages. In the first stage, the domain is partitioned into several subdomains, and in the second stage the primary partitioning is altered until the optimality criteria is satisfied to a required degree.

Recently many algorithms have been developed for domain decomposition. An efficient algorithm should be general purpose, i.e. applicable to arbitrary domains, and should be efficient enough to decompose large domains with a reasonable computational effort. The latter is dealt with in parallel in order to reduce the time and the effort of decomposition.

This chapter presents a hybrid method for domain decomposition of finite element meshes employing graph theoretical algorithms and neural network methods. The presented approach uses graph theory for partial decomposition, followed by a neural network approach to complete the bisection. Examples are included to illustrate the efficiency of the present method.

## 17.2 Definitions from Graph Theory

A graph G consists of a set elements called nodes (vertices) N(G) and a set of elements called members (edges) M(G) together with a relation of incidence which associates two distinct nodes with each member, known as its ends. Two nodes of a graph are called adjacent if these nodes are the end nodes of a member. A member is called incident with a node if it is an end node of the member. The degree of a node is the number of members incident with that node.

A subgraph G_i of a graph G, is a graph for which N(G_i) ⊆ N(G) and M(G_i) ⊆ M(G), and each member of G_i has the same ends as in G. A node n_i is called adjacent to a subgraph G_j, if it is adjacent to a node of G_j.

A path is a finite sequence P_k = {n_0, m_1, n_1, ..., m_p, n_p} whose terms are alternately distinct nodes n_i and distinct members m_i for 1 ≤ i ≤ p and n_{i-1} and n_i are two end nodes of m_i. A tree T of G is a subgraph which contains no cycle; a cycle being a closed path. If a tree is routed from a given node, n, it may be denoted by T_n. A graph is called connected if there is a path between each pair of its nodes, otherwise it is called disconnected. The distance between two nodes is taken as the length of the shortest path between these two nodes. A spanning tree is a tree containing all the nodes of G. A shortest route tree (SRTv) rooted from a specified node (starting node) v, is a spanning tree for which the distance between every node n_j of T and v is minimum, where the distance between two nodes is taken as the number of members in the shortest path between these nodes. A contour C_i v of an SRTv contains all the nodes with equidistance (i – 1) from v. An SRsubtree is an SRT that does not contain all the nodes of the graph.

The diameter of a graph is the maximum distance between all pairs of nodes. In general, a diameter may be defined by several pairs of nodes and all of these are said to be peripheral nodes. A pseudo diameter is any estimate of the diameter which is found by some approximation algorithm. Nodes which define a pseudo diameter are known as pseudo peripheral nodes.
