
where \(\beta_i\) is the output weight from the \(i\)th hidden node to the output node, \(\omega_i\) is the hidden unit weights, \(b_i\) is the threshold of the \(i\)th hidden node, \(L\) is the number of hidden nodes, and \(g(.)\) is the activation function [39]. The matrix form of Eq. (21.6) can be written compactly as follows:

\(H\beta = T\) (21.7)

where

\(H = \begin{bmatrix} G(\omega_1, x_1, b_1) \dots G(\omega_M, x_1, b_M) \\ \vdots \\ \vdots \\ G(\omega_1, x_N, b_1) \dots G(\omega_M, x_N, b_M) \end{bmatrix}_{N*M}\) (21.8)

\(\beta = \begin{bmatrix} \beta_1^T \\ \vdots \\ \beta_M^T \end{bmatrix}_{M*m}\) and \(T = \begin{bmatrix} t_1^T \\ \vdots \\ t_N^T \end{bmatrix}_{N*m}\) (21.9)

\(H\) is the hidden layer output matrix of SLFN neural network and \(T\) is a matrix containing the network target vectors [39].

In the ELM algorithm, it is assumed that the training error is zero [33, 39]. Therefore, it is supposed that \(y_i = t_i\) for \(i = 1, ..., N\) or in a matrix notation can be expressed as:

\(Y = T\) (21.10)

By using Eq. (21.7), the network output weights \(\beta\) can be analytically estimated as:

\(\beta = H^\dagger T\) (21.11)

where \(H^\dagger = (HH^T)^{-1}H\) is the generalized pseudo-inverse of \(H^T\).

After determining the network output weights, the network response for a vector of \(x_i\) can be estimated as:

\(o_i = \beta^T T_l\) (21.12)

where \(T_l\) is the network hidden layer output of \(x_i\).

### 21.3.2 Kernel Extreme Learning Machine

The estimation of \(\beta\) may be inaccurate and challenging because the matrix of \(HH^T\) can be singular. Therefore, a regularized version of the ELM algorithm should be considered that a small training error is allowed and the network output weight \(\beta\) can be determined based on the following optimization problem [34]:

\(Minimize : \text{Objective} = \frac{1}{2}\|\beta\|_F^2 + \frac{\lambda}{2} \sum_{i=1}^N \|\xi_i\|_2^2\)
\(Subject to: \beta^T h_i = t_i - \xi_i \ i = 1, ..., N\)
(21.13)

where \(\xi_i\) is the error vector corresponding to \(x_i\) and \(\lambda\) is a parameter that determines the importance of the training error in the optimization problem and should be more than zero. To determine the network output weights (\(\beta\)), the theory of Karush–Kuhn–Tucker (KKT) [40] can be employed to solve the following dual optimization problem:

\(\text{Objective}_{Dual} = \frac{1}{2}\|\beta\|_F^2 + \frac{\lambda}{2} \sum_{i=1}^N \|\xi_i\|_2^2 - \sum_{i=1}^N a_i(\beta^T h_i - t_i + \xi_i)\) (21.14)

The network output weights \(\beta\) can be obtained by calculating the derivatives of the above objective function with respect to \(\beta_i, \xi_i, \text{and } a_i\) and setting them equal to zero. After applying this approach, the \(\beta\) matrix can be expressed as:

\(\beta = \left(HH^T + \frac{1}{\lambda}I\right)^{-1} H^T T\)
\(or\)
\(\beta = H\left(H^T H + \frac{1}{\lambda}I\right)^{-1} T = H(K + \frac{1}{\lambda}I)^{-1}T\) (21.15)

where \(K\) is the ELM kernel matrix, and its element is equal to the elements of \([k]_{ij} = H_i^T H_j\) [41]. The network response for a given vector \(x_l\) is given by:

\(o_l = \beta t_l = T\left(K + \frac{1}{\lambda}I\right)^{-1} H^T H_l = T\left(K + \frac{1}{\lambda}I\right)^{-1} k_l\) (21.16)

where \(k_l\) is a vector in which its elements are equal to the elements of \(k_{l,i} = H_l^T H_i\), \(i = 1, ..., N\).

### 21.3.3 Gamma Test as a Tool for Sensitivity Analysis

In this subsection, the Gamma Test (GT) approach is presented to determine the most important parameters involved in prediction of maximum bond strength between FRP sheets and concrete substrates. The main advantage of GT approach is that it can find and determine the unknown relationship between input and output variables without generating a new prediction model [42]. The GT estimates the minimum Mean Square Error (MSE) that should be obtained by any smooth nonlinear function. To more explain the GT approach, a set of input and output parameters can be considered as follows:

\{(x_i, y_i), 1 \le i \le M\} = (X, Y)   (21.17)

where vector X denote the input variables that are confined to some closed bounded set c \in R^m and Y is a response variable. The relationship between X and Y can be stated as:

y = f(X) + r   (21.18)

where f is a smooth function and r is a noise variable with random nature. The GT calculates the variance of the random variable (Var(r)) without knowing the function of f. To achieve this, the GT estimates the following equations:

\delta_M(k) = \frac{1}{M} \sum_{i=1}^M |x_{N(i,k)} - x_i|^2   (21.19)

\gamma_M(k) = \frac{1}{2M} \sum_{i=1}^M |y_{N(i,k)} - y_i|^2   (21.20)

where \delta_M(k) is the mean square distance to the kth nearest neighbor, Y_M(k) is the corresponding gamma function of the output variable, x_{N(i,k)} is the index of kth nearest neighbor to x_i, y_{N(i,k)} is the corresponding output of x_{N(i,k)} and | \cdots | denotes Euclidean distance.

In general, the GT calculates mean-squared kth nearest neighbor distances \delta(k), (1 \le k \le k_{Max}) and corresponding Y(p)^2. To estimate Var(r), the GT computes the best intercept of the linear regression line of Y_M(k) versus \delta_M(k), which is often shown by \Gamma. This parameter is also an indicator for complexity of function f. The results of GT can also be standardized by considering the V_{ratio} term which returns scale-invariant noise between zero and one. It is defined as:

V_{ratio} = \frac{\Gamma}{\text{Var}(y)}   (21.21)

where Var(y) is the variance of y.

### 21.4.2 Influential Parameters

Previous experimental and theoretical studies have shown that different influential parameters can impact on the maximum bond strength between EBR FRP and concrete substrates. According to [19], the following six parameters is well-known to be the most effective parameters in estimation of bond strength between FRP and concrete substrate: 
- (a) the concrete strength
- (b) the bond length
- (c) the FRP plate axial stiffness
- (d) the FRP-to-concrete width ratio
- (e) the adhesive stiffness
- (f) the adhesive strength

To consider the effect of mentioned parameters or mechanisms in this study, the bond strength between FRP and concrete substrate was considered to be a function of the following parameters:

$P_{max} = f(t_p, b_p, E_p, f'_c, t_c, b_c, L, E_a, t_a)$ (21.22)

where $P_{max}$ is ultimate load or bond strength, $b_p$ is the width of FRP plate, $E_p$ is elastic modulus of FRP, $f'_c$ is the concrete cylinder compressive strength, $t_c$ is the effective thickness of concrete contributing to shear deformation, $b_c$ is the width of concrete prism, $L$ is the bond length, $E_a$ is elastic modulus of adhesive, and $t_a$ is the thickness of adhesive layer. The histograms of input and output parameters are shown in Fig. 21.3. As shown, the considered arrangement in this study covers a wide range of $f'_c$ between 16 and 70 MPa and $L$ between 50 and 400 mm. It should be noted that the reliability of developed models in predictions of ultimate load are more in the ranges which data points are more concentrated.
