# 1.3.3 Gradient Vanishing

Gradient vanishing is a common problem in neural network training that due to concatenation of several layers of neurons, the gradients (partial derivatives of the objective function with respect to the weights) may vanish or become very small. This causes the network weights to not be updated effectively and the network performance is not improved. Gradient vanishing is clearly evident in deep networks with more layers, as at each layer the derivatives are carried to lower layers and may shrink or disappear. This problem can slow down the training process, increase the time required for the network to converge or even reach a parallel state.

Some methods of removing gradient blur in neural networks include using different activation functions (such as Leaky ReLU), using softening methods such as Dropout, using normalization methods such as Batch Normalization, or using networks with a special structure such as recurrent neural networks. It is possible to avoid the gradient fading problem and to continue training the network effectively.

# 1.3.4 Gradient Exploding

Gradient exploding is another situation in neural network training where the gradients are very large and go to infinity. This may happen due to the derivation of the sequence of large classes from each other in deep networks and cause instability in network training. The occurrence of gradient explosion can lead to unpredictable reactions and numerous jumps in updating the network weights, which reduces the quality and performance of the network. This problem usually occurs when using a very large learning rate in the process of updating the weights and can cause the network to fail to converge or other undesirable problems.
