# 1.2.7 Neural Networks

Neural networks are a computational model inspired by the structure of the human brain, which are mostly used to learn and recognize patterns and relationships between data. These networks are composed of one or more layers of neurons and information is transmitted through specific weights assigned to each connection between neurons. By training or adjusting these weights, the neural network can learn to recognize different patterns and features and then use them to make predictions or make decisions in new situations. There are different types of neural networks, which are explained in detail below. Neural networks are known as one of the key technologies in the field of deep learning and artificial intelligence and can model nonlinear problems. Because of this feature, they can be used in many problems in different fields such as image and speech processing to machine translation and data analysis. In general, neural network applications can be divided into three groups: data classification, data clustering, and regression problems [7].

# 1.2.7.1 Classification

In the data classification procedure, in order to train the model, a large amount of "labeled data" is needed so that the model predicts new data categories using the information provided by the data labels. In other words, in the data classification method, a person must use his knowledge in preparing the data set and label the data required for training the model based on various specialized knowledge such as linguistic knowledge so that the model learns the relationship between data and labels. This approach is called "supervised learning" in which human-prepared labels help the model learn. Determining spam and non-spam emails is an example of classification tasks and supervised approach.

# 1.2.7.2 Clustering

In the clustering method, deep learning algorithms recognize groups of data without the need for labeled data. In other words, clustering neural networks put them in separate groups by simply checking the similarity of the data, and eventually several groups of data are formed, and the data of each group have similar characteristics to each other. This approach of learning is called "unsupervised learning", during which the model recognizes different types of data groups without using any additional information and simply by having the data. The advantage of this method compared to the classification method is that there is no need to provide labeled data, which has a significant impact on reducing financial and time costs.
