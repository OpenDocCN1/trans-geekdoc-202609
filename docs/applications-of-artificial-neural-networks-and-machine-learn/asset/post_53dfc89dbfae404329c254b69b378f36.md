## 1.4.3 Non-linear Activation Function

Nonlinear activation functions are used in neural networks to generate nonlinearity and deregularization in information. The non-linearity of these functions allows the network to be able to model more complex and non-linear patterns, which allows for improved network performance. The generalizability and adaptability of the model to different types of data is facilitated by the use of nonlinear activation functions. The use of nonlinear activation functions in neural networks adds an extra step to the calculations of each layer in the feedforward propagation step; but this extra step has an important advantage. If there is a neural network without activation functions, each node simply performs linear computations on its inputs using values of weights and biases. In this case, the number of hidden layers in the neural network is not important and all layers have the same function because the result of combining two linear functions will be a linear function.

Some of the problems of this method can be mentioned such as: it may be more complex than needed for some simple problems and cause the problem of gradient fading or overfitting. Also, some nonlinear activation functions such as the sigmoid function may not help as much as it should when facing the problem of gradient fading and slow down the learning and improvement of the network. Therefore, the correct selection of the nonlinear activation function is very important, [14] and [15].

### 1.5.1 Sigmoid Activation Function (Sigmoid | Logistic)

The sigmoid function is a non-linear activation function that normalizes the input value to values between 0 and 1, in other words, it converts the input value to a possible value between 0 and 1. The sigmoid function is considered a “monotonic” function. But the derivative of this function is not a uniform function. The sigmoid function is usually used in the final layers of neural networks for binary classification problems (between two classes). 0 and 1, which can lead to the conversion of weights to class probabilities, as well as smoothing the denominator to the probabilistic state that may be needed in classification applications. The most important limitation of this function is the problem of gradient vanishing, which may be problematic in network training. With very large or very small outputs, the output saturation problem may occur. Sigmoid Activation Function is shown in Fig. 1.6.

The formula of the sigmoid function is:

```
f(x) = 1/(1 + e^{-x})
```

### 1.5.2 Hyperbolic Tangent Activation Function (Tanh | Hyperbolic Tangent)

The hyperbolic tangent function (Tanh) is also a nonlinear activation function that normalizes the input values to the interval (−1, 1). This function is usually used in neural networks to limit the output of inputs to values between −1 and 1. The output of the Tanh function is proportional to the range of the sigmoid function and reduces the problem of saturation of the outputs in the sigmoid function. The output of the Tanh function is compared to the fading problem. The gradient in zero regions is less sensitive and more useful. Among the limitations of this function, it can be mentioned that, like the sigmoid function, there may be a problem of gradient fading in the saturated areas of this function. Hyperbolic Tangent Activation Function shown in Fig. 1.7.

The formula of the hyperbolic tangent function is:

```
f(x) = (e^x - e^{-x})/(e^x + e^{-x}) (1.4)
```

### 1.5.3 Rectifier Linear Unit Activation Function (ReLU)

ReLU nonlinear activation function is one of the most common activation functions in deep learning. The name of this function stands for “Rectified Linear Unit”. Although this function looks like a linear function, this function is derivable and can be used in the backward propagation step. This function does not activate all nodes at the same time. In other words, the nodes are inactive when the input value of this function is less than zero. In other words, according to the graph of this function, if the input of the function is greater than zero, the output of the function is equal to the input of the function, and if the input of the function is less than zero, the output of the function is equal to zero. The ReLU function and its derivative are uniform. Due to the linearity and non-saturating feature of the function, the convergence of Gradient Descent algorithm happens faster. Thus, the model needs less time to learn. Since this function only activates a number of nodes, it is computationally more efficient than other activation functions in neural networks. Compared to the sigmoid and Tanh functions, this function is a simpler function and therefore easier mathematical calculations are performed during network learning. The ReLU function does not have the problem of vanishing the gradient of the sigmoid and Tanh functions; because the positive linear range of this function allows the gradients to flow in the active path of the nodes. Also, this function does not set a limit for the maximum input value. An important limitation that the ReLU function faces is the dying problem of the ReLU function. This state occurs when the output of several ReLU functions is equal to zero consecutively. The problem of deterioration of the ReLU function
