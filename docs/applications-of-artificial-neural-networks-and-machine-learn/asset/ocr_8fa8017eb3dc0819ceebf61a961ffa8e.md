+   1. A considerable reduction of the size of the problem in the first stage makes the neural network method of the second stage more efficient. The size of the neural network in this method is much smaller compared with the pure ANNs approach.
+   2. Much larger problems can be dealt with because the first graph theoretical stage requires far less computational effort, while using the efficiency of the second stage.
+   3. For models with higher aspect ratios, the present hybrid method requires smaller neural networks for the partitioning.
