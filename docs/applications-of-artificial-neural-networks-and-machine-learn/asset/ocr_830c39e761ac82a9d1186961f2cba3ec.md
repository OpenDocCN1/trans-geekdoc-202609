# ## 1.6.5 Recurrent Neural Networks

Recurrent Neural Networks introduce a different type of cells called Recurrent Cells. The first network of this type is the Jordan Network. In this type of network, each hidden cell receives its output with a fixed delay. Regardless, Jordan’s network was similar to conventional feedforward neural networks. Of course, various changes such as passing state to Input Nodes, variable delay and other things have happened in this type of network, but the main idea remains the same.

This type of neural networks (NN) is basically used when context is important, and in fact, when decisions from previous iterations or examples can affect current examples. As a common example of this type of fields, we can mention (Text). In text, a word can be analyzed only in the context of the preceding word or sentence. # ## 1.6.6 Long Short Term Memory

Long/Short Term Memory (LSTM) introduces a new type of Memory Cell. This cell can process data when it has a time gap (or time delay). A feedforward neural network can process text by remembering the previous ten words. Meanwhile, LSTM can process video frames by remembering what happened in the previous frames. LSTM networks are widely used for speech recognition and writing recognition. Memory cells are basically a combination of a pair of elements called gates. These elements are reversible and control how information is remembered and forgotten. The structure of this type of network is well defined in the image below. It is also worth noting that there is no activation function between the blocks. The X’s in the diagram are gates and they have their own weight and sometimes their activation function. For each instance, the X’s decide whether to pass data forward, clear memory, and so on. The input gate decides how much information from the last sample is kept in memory.
