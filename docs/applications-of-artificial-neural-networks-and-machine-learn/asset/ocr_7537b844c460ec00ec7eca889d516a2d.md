\( K = \sum_{i=1}^{NE} k_i \) (7.9)

where NE is the number of finite elements in the structure. P and U are the load vector and displacement vector, respectively. The symmetric stiffness matrix is a function of the design variables defining the structure. The load vector P may also be a function of design variables if we include, for example, self-weight of the structures. Solving for displacement as

\(\mathbf{U} = \mathbf{K}^{-1} \cdot \mathbf{P}\) (7.10)

The element stiffness matrix ki is created from the stiffness

\( k_i = T^T k_i^o T \) (7.11)

Matrix \( k_i^o \) in the element's local coordinate system and a geometric transformation matrix T.

The displacements associated with each element can be transformed to the local co-ordinate system by

\( u^0 = Tu \) (7.12)

The element forces are

\( f = k_i^0 u^0 \) (7.13)

Finally, the stress constraints are computed from these forces. Differentiating Eq. (7.8) implicitly with respect to design variable Xi, i = 1, 2, ..., n.

\(\frac{\partial K}{\partial X_i} U + K \frac{\partial U}{\partial X_i} = \frac{\partial P}{\partial X_i}\) (7.14)

or

\(\frac{\partial U}{\partial X_i} = K^{-1} \cdot \left[ \frac{\partial P}{\partial X_i} - \frac{\partial K}{\partial X_i} U \right]\) (7.15)

Assuming the loads to be independent of Xi, the first term in the brackets becomes zero. Also, from Eq. (7.9),

\(\frac{\partial K}{\partial X_i} = \sum_{j=1}^{NE} \frac{\partial k_j}{\partial X_i}\) (7.16)
