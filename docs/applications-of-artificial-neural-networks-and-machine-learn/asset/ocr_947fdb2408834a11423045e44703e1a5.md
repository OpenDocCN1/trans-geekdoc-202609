The distance between two nodes is taken as the length of the shortest path between these two nodes. A spanning tree is a tree containing all the nodes of G. A shortest route tree (SRTv) rooted from a specified node (starting node) v, is a spanning tree for which the distance between every node nj of T and v is minimum, where the distance between two nodes is taken as the number of members in the shortest path between these nodes. A contour Ci v of an SRTv contains all the nodes with equidistance (i – 1) from v. An SRsubtree is an SRT that does not contain all the nodes of the graph.

The diameter of a graph is the maximum distance between all pairs of nodes. In general, a diameter may be defined by several pairs of nodes and all of these are said to be peripheral nodes. A pseudo diameter is any estimate of the diameter which is found by some approximation algorithm. Nodes which define a pseudo diameter are known as pseudo peripheral nodes.
