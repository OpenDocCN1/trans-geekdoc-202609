# 1.3.1 Feedforward

The model that forwards information from the input (from layer to layer) is known as feedforward. This process is performed as the prediction or network output calculation for the input data without any feedback, in other words, the information is passed from the input layers to the output layers, without interruption or feedback. The feedforward process in neural networks is generally done as follows:

Input information (such as images, text, or numerical features) is fed to the input layer of the network.

Information is transferred from layer to layer through specific weights and processed by activations (such as ReLU or sigmoid activation function). This process continues until reaching the output layer. Finally, the output calculated by the network is produced as the final response to the inputs given to the network.

The feedforward process is used as the first step in the decision-making and forecasting process using neural networks. This process is used to predict new data, recognize patterns, make automated decisions, machine translation and many other applications of machine learning.
