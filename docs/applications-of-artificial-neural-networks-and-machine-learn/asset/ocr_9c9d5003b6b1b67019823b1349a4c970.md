```
\( y' = \sum_{j=1}^{N_{win}} w_{jk} \cdot z_j \) \hfill (8.6)
```

In operation, for each Kohonen cluster unit, \( D_i \) value (\( i = l, ..., p \)) based on the Euclidean distance is computed, and a set of N units (\( N = 1, ..., N_{win} \)) with minimum \( D_N \) are selected. The winner nodes are ordered from minimum to maximum based on their DN values. The unit with the smallest \( D_N \), which is closer to the input vector, must have more share in the interpolation mode. In order to accomplish this, the following relation is suggested:

```
\( z_j = \frac{\sum_{N=1}^{N_{win}} D_N - D_j}{D_j \cdot \sum_{N=1}^{N_{win}} D_N} \) \hfill (8.7)
```

Here \( Z_j \) is the share of each winner unit which is used in Eq. (8.6). For the closer Kohonen units to the input vector \( D_j \) has the smallest value which will result in a larger \( Z_j \) to amplify this effect, smaller \( D_j \) in denominator will result in a larger \( Z_j \).

# ## 8.3 Backpropagation Neural Network

The single-layer networks may not have the decision-making complexity necessary for solving a broad range of civil engineering problems. Due to this deficiency multi-layer networks have been developed from single-layer networks that can learn any continuous mapping to an arbitrary accuracy. The training process of this net involves three stages, the feedforward of the input training pattern, the calculation and back-propagation of the associated error, and the adjustment of the weights. The “delta error backpropagation” algorithm is usually used for its supervised learning. It is essentially a steepest descent algorithm to adjust the weight connection strength. After training, the application of the net involves only the computations of the feed-forward phase. Even if the training is slow, a trained net can produce its output very rapidly.

The number n and m of nodes in the input and output layer is determined by the number of input and output variables in the training set. There is no specific rule to determine the number of nodes \( m \) in the hidden layer, however, by equating the number of available equations in the network to the number of unknowns (weights) the following relation is obtained.

```
\( (n + 1)p + m(p + 1) = mq \) \hfill (8.8)
```

where p is the number of nodes in the hidden layer, and q is the number of training pairs. It is recommendable to start with a value much smaller than the p-value obtained from Eq. (8.8).
