# 21.4.5 Statistical Error Parameters

The four statistical error parameters used to evaluate the performance of developed KELM model and the empirical equations were as follows: mean absolute error (MAE), root mean square error (RMSE), correlation coefficient (R) and coefficient of determination ($R^2$).

\( MAE = \frac{\sum_{i=1}^{N} |P_i - O_i|}{N} \) (21.24)

\( RMSE = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (P_i - O_i)^2} \) (21.25)

\( R = \frac{\sum_{i=1}^{N} (P_i - P_m)(O_i - O_m)}{\sqrt{(P_i - P_m)^2} \sqrt{(O_i - O_m)^2}} \) (21.26)
