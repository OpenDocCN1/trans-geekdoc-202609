# ## 17.1 Introduction

A hybrid method is presented for domain decomposition employing a graph theoretical algorithm and a neural network optimization model. The method uses graph theory and neural networks for decomposition of structured finite element meshes [1]. Parallel processing is often used for the analysis of large-scale structures and finite element models (FEMs). For this purpose a model may be decomposed into subdomains and the analysis is performed on each subdomain by an individual processor. Then the solutions are condensed and combined for the overall solution. For decomposition of a model, the following conditions should be considered:

+   1. Equal or near equal degrees of freedom for subdomains should be provided.
+   2. The number of interface nodes should be as close to minimum as possible.
+   3. Partitioned subdomains should have good aspect ratios.

The mathematical models of the skeletal structures are graphs. However, for FEMs artificial graphs can be associated to reduce the process of decomposition into that of their associate graphs. Many such graphs are used by Kaveh [2], the most suitable one used in this chapter is the partial clique graph of a FEM.

For decomposition of a graph into suitable subgraphs different methods are available which can be categorized as:

+   - Pure graph theoretical method;
+   - Pure algebraic graph theoretical approach;
+   - Pure neural network method;
+   - Mathematical optimization approach;
