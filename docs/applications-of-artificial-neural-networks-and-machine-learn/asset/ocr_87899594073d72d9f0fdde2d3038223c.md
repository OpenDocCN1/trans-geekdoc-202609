Furthermore, according to Table 22.1, some important parameters weren't incorporated in most of these design codes. For example, the influences of the nominal maximum size of coarse aggregate only was considered in CSA A23.3-04 [28] and level II approximation of the fib Model [29] Code whereas dependency of HSC shear strength to this parameter was reported by Muttoni [35]. Only CEB-FIP [31] model and AS 3600 [32] consider the effect of shear span-to-depth ratio on shear strength of slender HSC beams. Also, ACI 318-11 [27] does not consider the effect of effective depth, $d$, whereas other design equations show notable sensitivity to change of $d$ parameter.

To take full advantage of the positive material properties of RC beams made of HSC, a more reliable model for predicting shear capacity of slender HSC beams without web reinforcement is needed. Recently, machine learning approaches have been widely applied in engineering problems. The main advantage of these approaches can be mentioned as: they consider all possible relations between input and output parameters and also checked different combinations of input parameters for estimating output parameter unlike the regression approaches. At the following section Multivariate Adaptive Regression Splines (MNLR), Group Method of Data Handling (GMDH) network and Multiple Nonlinear Regression Methods (MNLR) are introduced which are used in this study to predict the shear strength of HSC slender beams without web reinforcement.

# 22.3 Soft Computing Approaches

Recently, the soft computing approaches such as Artificial Neural Networks (ANN) and adaptive neuro-fuzzy inference system (ANFIS) have been employed as useful tools for modeling and forecasting complex structural engineering problems. Among these methods, the group method of data handling (GMDH) network and multivariate adaptive regression splines (MARS) have not yet been widely applied in structural engineering. The main advantage of GMDH and MARS methods in comparison with ANN method is that the dependencies between input parameters and responses are represented in parametric form as an equation while these dependencies are hidden within neural network structures in ANN method. Besides that ANN methods need an essential time of learning and therefore it is difficult to be applied for modeling and forecasting in real time systems.
