# 20.5.1 Performance Analysis

The number of data used to develop a reliable model based on data mining approaches plays a crucial role in modeling process. Frank and Todeschini [59] suggested that the minimum ratio between the number of data used and the number of involved variables should be 3. A safer value of 5 can be more conservative. In the present study, this ratio is remarkably more and is equal to 230/7 = 32.85.
