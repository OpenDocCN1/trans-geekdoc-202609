Once an architecture has been selected, the training starts with random initiation of connection weights. These connection weights are adjusted by the error backpropagation learning algorithm to minimize the difference between the training output and the value produced by propagating the associated input through the net.

The convergence of a net depends on various learning parameters. The learning rate has an important effect, if it is too small, convergence can be very slow, if it is too large, paralysis or continuous instability can result. The momentum coefficient which is a combination of the current gradient and the previous gradient causes numerical stability. This is a modification of gradient descent whose advantage arises chiefly when some training data are very different from the majority of the data. In the numerical implementation and comparison of the performance of the BPN with the improved CPN, the NASA-developed program NETS 2.01 was used, Ref. [10].

# ## 8.4 Numerical Implementation of the Improved CPN and BPB

The numerical experiment has been carried out with two main objectives. The comparative study of the responses of the nets when large-scale structures are involved. The second effort consists of investigating the characteristics of each net and the learning time required for each one.

# ### 8.4.1 Example 1

A fifty-two-bar space truss is considered as illustrated in Fig. 8.2.
Due to the symmetry, one-fourth of the structure is considered in the formation of the neural nets. As the number of input-output units is increased, the number of training pairs must be increased in order to reduce the associated errors in the net response. In this example, the input units are the cross-sectional areas of the truss members and the output units are member stresses.
