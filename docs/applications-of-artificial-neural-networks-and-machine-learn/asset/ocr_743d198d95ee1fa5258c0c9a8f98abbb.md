Then, the output is obtained as the weight vector of the outstars. This type of network operates as a look-up table with \( n \) entries. The accuracy of this type of net can be improved by increasing the Kohonen units, but this leads to a very huge net which is not appropriate for large scale problems. In order to alleviate the problem, an interpolation mode is introduced here. After training based on the aforementioned section, a set of untrained verification pairs is applied to verify the performance of the net. In this mode, it is allowed that some units of the Kohonen layer return the output.

The number of wining units which is usually more than one, is determined in the verification process so that the associated error is minimized. Here \( y'_i \) is the network-predicted output, \( y_i \) is the actual output and \( k \) is the number of verification pairs.

> \( E = \frac{\sum_{i=1}^k (y_i - y'_i)}{\sum_{i=1}^k y_i} \times 100 \) (7.4)
