# # 4.5 Training and Testing of the Networks

# ## 4.5.1 Data for Design

The output of the “Finaltype” consisting of 219 files, resulting from the design and processing of 219 double layer grids are read. The number for each region of the structures together with the required cross-sectional area for each region, length, and the height of the structure are stored row wise in the file. Therefore investigating the output files of the “Finaltype”, the input file for training the neural network is constructed. Each row of the input file consists of the following information:

+   L: length of the structure,
+   h: height of structure,
+   NR: number assigned to the regions.
+   A: the cross-sectional area required.

# ## 4.5.2 Neural Nets for the Evaluation of Maximum Deflection of Double Layer Grids

The number of input for this net is equal to two, and consists of the span length L, and the height h, of the grid, both in meters. The output consists of the maximum deflection d of the grid, in meter, under the dead and live loads.

The topology of the networks contains two input nodes and one output node, and two hidden layers with different number of nodes, as illustrated in Table 4.1. A total number of 179 pairs are used for training the nets and 40 pairs are employed for their test. From nets with different topologies, the one with the best performance is selected, see Table 4.1. The RMS for the trained network is shown in Fig. 4.2.

The following observations have been made for the neural nets:

+   - The best net contains four and two nodes in the first and the second layers, respectively, and the activation function is hyperbolic tangent.
+   - The net with hyperbolic tangent performed better than the net with sigmoid, because the domain for mapping the training data in hyperbolic tangent case has been wider and the input was more recognizable for the net.
+   - The training time for the net that uses the hyperbolic tangent has been faster than the one employing sigmoid as activation function.
+   - For h9def and h8def nets, CD and NCD methods with epoch length equal to 179 were employed, respectively. Due to the selection of large epochs, key trends in the data are missed and the nets became unstable, hence could not be trained.
