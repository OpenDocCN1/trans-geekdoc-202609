# 1.5.1 Sigmoid Activation Function (Sigmoid | Logistic)

The sigmoid function is a non-linear activation function that normalizes the input value to values between 0 and 1, in other words, it converts the input value to a possible value between 0 and 1. The sigmoid function is considered a “monotonic” function. But the derivative of this function is not a uniform function. The sigmoid function is usually used in the final layers of neural networks for binary classification problems (between two classes). 0 and 1, which can lead to the conversion of weights to class probabilities, as well as smoothing the denominator to the probabilistic state that may be needed in classification applications. The most important limitation of this function is the problem of gradient vanishing, which may be problematic in network training. With very large or very small outputs, the output saturation problem may occur. Sigmoid Activation Function is shown in Fig. 1.6.

The formula of the sigmoid function is:

```
f(x) = 1/(1 + e<sup>-x</sup>)
```
