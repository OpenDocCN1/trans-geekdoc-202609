# 21.5.2 Parametric Analysis

The robustness of the developed KELM, ANFIS, and ANN models can be verified by examining how closely the model predictions agree with the physical behavior of the studied problem. Therefore, a parametric analysis is carried out. This analysis investigated the response of the predicted bond strength from the developed models to a set of hypothetical input data generated over the ranges of the minimum and maximum data used for the model training. The methodology is based on the change of only one input variable at a time while the other variables are kept constant at the average values of their entire data sets. A set of synthetic data for the single varied parameter is generated by increasing the value of this in increments. These inputs are presented to the prediction models and then the bond strength is calculated. This procedure is repeated using another variable until the model response is tested for all input variables [42]. In Fig. 21.8 the values of P_max predicted by developed KELM, ANFIS, and ANN models are plotted as function of the main design parameters including f'_c, L_b, E_p/f_p, b_p/b_c.

The variations of maximum transferable load predicted by ANN, KELM and ANFIS models with changing the f'_c parameter while the other parameters were kept constant are shown in Fig. 21.8a. It can be seen that the P_max predicted by KELM model slightly increases by increasing f'_c parameter. This behavior can be attributed to the fact that the debonding cracks can developed when the P_max reaches to the tensile strength of concrete which is a function of f'_c parameter.
