Typically, a feed-forward backpropagation network such as MLP uses processing units that are placed in three types of input, hidden, and output layers. Each unit in a layer is connected to units in adjacent layers with an associated weight (connection strength). It is the adjustment of these weights that is done during network training, because network training involves repeatedly changing the weights between neurons until the output signal matches the target output within the desired minimum error. When training open feedforward networks, the studied data set is usually divided into a training set and a validation set. While the training set is used to train the network, the validation set is applied to check the error performance of the network.
