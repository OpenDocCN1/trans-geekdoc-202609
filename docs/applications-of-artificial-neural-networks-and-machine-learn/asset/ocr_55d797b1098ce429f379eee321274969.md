# 1.6.18 Deconvolution Network

Deconvolution Network (DN) is the inverse of DCN. The deconvolution network receives the cat image and creates a vector like {dog : 0, lizard : 0, cat : 1, lion : 0}. A deep convolutional network can receive this vector and draw an image of a cat based on it. Deconvolution Network shown in Fig. 1.44. Deep Convolutional Inverse Graph Network shown in Fig. 1.45.
