# 1.6.25 Kohonen Network

Cohen's neural network is a type of artificial neural network that was introduced by Thomas Cohen's name. This network is known as a type of self-organizing networks. The main goal of this network is to transform complex features into a simpler and understandable way for humans. This network can exponentially transform multi-dimensional inputs into one dimension or multiple dimensions using an algorithm defined by its name. As a practical example of Cohen's network, we can mention pattern classification, feature space dimension reduction, data clustering, and data feature visualization. These networks are well used in areas such as image processing, text pattern recognition, genetic data analysis, and geospatial data (GIS). Kohonen Network shown in Fig. 1.51.
