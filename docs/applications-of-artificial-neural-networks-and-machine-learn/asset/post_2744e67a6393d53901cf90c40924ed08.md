## 4.3 Configuration Processing, Analysis and Design

The structural models are generated using FORMIAN developed by Nooshin et al. [6]. The analysis is performed by SAP90, and a program called “Hdesign” is developed for their design. The following assumptions are considered:

- 1. The sum of dead load and live load equal to 2.5 kN/m² is applied to the nodes of the top layer.
- 2. All the nodes are considered as ball jointed.
- 3. Linear analysis is performed.
- 4. One hundred and four different tube sections available in STAHL are included in the program for design.
- 5. Design is carried out according to AISC code.

## 4.4 Software for Training

The backpropagation learning method is used here that is a popularized and developed into a workable process by Rumelhart et al. [7]. Numerous generalizations have been made and many applications have been found for backpropagation since 1985. The method of training adopted in this chapter is backpropagation. This approach is the most successfully and widely used algorithm among artificial neural networks. In backpropagation the input is propagated from input layer through other layers to output layer, and then the error is propagated back through the network from the output layer to the input layer. This process is repeated until the error is reduced to a specific value, or the number of iteration is exhausted. The learning rule associated with backpropagation method is known as generalized delta rule, Rumelhart et al. [7]. According to this rule for changing the weights in the network, for a given pattern p, the following relation can be used:

\(\Delta w_{st}(n+1) = \eta(\delta_{pr} o_{ps}) + \alpha w_{st}(n),\)

where \(w_{st}\) is the connecting weight from the source “s” layer to the target “t” layer and \(o_{ps}\) is the output produced from pattern p as the result of the input \(o_{p(s-1)}\). n is the input-output presentation number and \(\eta\) is the learning rate and \(\alpha\) is the momentum.

The momentum \(\alpha\) is the fraction which is multiplied by the previous weight change and added to current weight change; \(\alpha\) should be positive and less than unity. Typical values of \(\alpha\) lie in the range (0.5, 0.9), but for some problems it is shown that \(\alpha\) = 0.0 to be the best.

Dynamic adjustments of momentum and learning rate is an effective method for network training. The two terms are not independent, and should be chosen and modified as a pair. In general, dynamic adjustment of both parameters can accelerate convergence, however, values of either \(\eta\) or \(\alpha\) that are too large, can lead to instability in the update process.

There are many softwares available for training. In this chapter NETS2.01 and NEURALWORKS of Refs. [8 and 9] are employed. The latter program is found more flexible and provides additional useful information. In the process of training by BP, both sigmoid and tangent hyperbolic available functions are employed.

NEURALWORKS: This program is capable of mapping the input data to an arbitrary range. This program reads the input data and the information at each column is mapped into the considered domain employing the maximum and minimum values in that column. The mapped data is then used in the training.

NETS2.01: This program does not map the input into a domain with arbitrary ranges. A program called “min-net” is prepared to provide such a capability.

## 4.5 Training and Testing of the Networks

### 4.5.1 Data for Design

The output of the “Finaltype” consisting of 219 files, resulting from the design and processing of 219 double layer grids are read. The number for each region of the structures together with the required cross-sectional area for each region, length, and the height of the structure are stored row wise in the file. Therefore investigating the output files of the “Finaltype”, the input file for training the neural network is constructed. Each row of the input file consists of the following information:

- L: length of the structure,
- h: height of structure,
- NR: number assigned to the regions.
- A: the cross-sectional area required.

### 4.5.2 Neural Nets for the Evaluation of Maximum Deflection of Double Layer Grids

The number of input for this net is equal to two, and consists of the span length L, and the height h, of the grid, both in meters. The output consists of the maximum deflection d of the grid, in meter, under the dead and live loads.

The topology of the networks contains two input nodes and one output node, and two hidden layers with different number of nodes, as illustrated in Table 4.1. A total number of 179 pairs are used for training the nets and 40 pairs are employed for their test. From nets with different topologies, the one with the best performance is selected, see Table 4.1. The RMS for the trained network is shown in Fig. 4.2.

The following observations have been made for the neural nets:

- The best net contains four and two nodes in the first and the second layers, respectively, and the activation function is hyperbolic tangent.
- The net with hyperbolic tangent performed better than the net with sigmoid, because the domain for mapping the training data in hyperbolic tangent case has been wider and the input was more recognizable for the net.
- The training time for the net that uses the hyperbolic tangent has been faster than the one employing sigmoid as activation function.
- For h9def and h8def nets, CD and NCD methods with epoch length equal to 179 were employed, respectively. Due to the selection of large epochs, key trends in the data are missed and the nets became unstable, hence could not be trained.
