# 11.4 Concluding Remarks

The following conclusions can be derived considering the artificial neural networks tested in this chapter:

+   1. This research shows that it is possible to estimate the vulnerability of concrete structures using Artificial Neural Networks.
+   2. Application of one hidden layer in training the networks for estimation of seismic vulnerability of structures is found to be sufficient.
+   3. Using the Hyperbolic Tangent activation function, slightly better prediction of damage index was obtained compared to the use of the Sigmoid function.
+   4. No substantial improvement is obtained using two hidden layers in training of the networks and this can increase the training time.
