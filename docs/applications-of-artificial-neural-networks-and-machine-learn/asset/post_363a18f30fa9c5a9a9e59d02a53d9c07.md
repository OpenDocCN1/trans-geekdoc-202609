### 8.2 The Improved Counter-Propagation

For the counter propagation network developed by Robert Hecht-Nielsen as compared to backpropagation, the training process is very fast. The present CPN is very effective for large-scale problems since the weight matrices are computed internally. The size of the net and selecting the number of winner nodes in the interpolation process is automated in order to minimize the errors. The learning process is very fast, especially for large problems which makes it practical to use. By increasing the number of training pairs and the size of the net, the accuracy of the results is increased. The net can be employed in structural optimization since the process is numerical, therefore implementing the net in evaluating the structural response with a few percent error does not considerably affect the result.

### 8.2.1 Network Topology

The topology of the CPN is shown in Fig. 8.1. Counter propagation is a combination of two well-known algorithms, namely the self-organizing map of Kohonen and the Grossberg outstars. This network learns a near-optimal look-up table approximation to the mapping being approximated.

CP nets are trained in two stages. During the first stage, the input vectors are clustered on the Kohonen units. In the original definition of the CP net, the clusters that are formed were based on either the dot product metric or the Euclidean norm metric. In this stage after the entire set of training vectors has been presented, the weights from the input layer to the Kohonen cluster units are stabilized. During the second phase of training only unit J remains active in the cluster layer. The weights from the winning cluster unit J to the output units are adjusted so that the vector of activations of the units in the Y output layer, y', is an approximation to the input vector y. The main difficulty with the mentioned algorithm is the initialization of weight matrices which might not gain the optimal value during training. Besides, clustering of the Kohonen units based on the Euclidean norm or dot product which has the geometric interpretation of the alignment of two vectors does not preserve the length of a vector. In order to overcome these problems, the absolute value norm is defined as

where D is a measure of how close is the input vector x to weight vector v. Choosing an arbitrary value for D, the size of units in the Kohonen cluster layer is dynamically determined. Selecting the value of D is problem-dependent, however, smaller values will result in larger size networks.

In the training process, the number of Kohonen units either increases or remains unchanged. If the jth input vector is D away from all previously defined units, a new unit is introduced, otherwise the weight vector nearest to the jth input vector is modified. In this process, the weights from the input units to the Kohonen cluster units are specified which have almost their optimal values. These weight values are slightly corrected in the next stage of the training. In the next step, the weights from the cluster units to the output units are computed and slightly modified later. Since this procedure specifies the proper values for the weight matrices, the number of iterations is very low, usually one or two. Therefore, the CPN is very fast compared to the backpropagation net. In many problems of structural mechanics, the shape of the structure is changed for different problems, then application of neural nets is effective when the training time is small and the response of the net is in an acceptable range. CPN has all these positive characteristics and it is applicable to a wide range of problems.
