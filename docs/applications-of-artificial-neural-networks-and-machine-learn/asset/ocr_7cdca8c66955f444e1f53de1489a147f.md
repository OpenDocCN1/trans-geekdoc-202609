Therefore, it seems that a new computational method is required to be added to this field. In this chapter, a metaheuristic-based artificial neural network (ANN), which is categorized as a supervised machine learning technique, has been employed to determine the collapse load factors of two-dimensional frames in an absolutely fast manner. The numerical examples indicate that the proposed method's performance and accuracy are satisfactory.
