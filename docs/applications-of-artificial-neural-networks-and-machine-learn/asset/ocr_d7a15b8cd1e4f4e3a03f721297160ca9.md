# 1.6.1 Perceptron Neural Network

Perceptron is the simplest and oldest model of artificial neural networks known to mankind. The perceptron receives a number of inputs, aggregates them and applies an activation function on them, and finally passes them to the output layer. In this part, the main miracle of artificial neural networks does not happen. This model is specifically used for simple classification problems.
