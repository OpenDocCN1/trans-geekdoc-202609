Using the networks lead to an approximate range of the results, however, as we mentioned before such networks can not be employed in final stages of the algorithm. Thus one should define a criterion for terminating the use the network. Obviously, the best approach will be the use of rate of the changes in the objective function. For these examples, the stopping criterion is taken as the deviation of the objective function in each generation to be 2% less than the average of that generation. The outputs are so closed that the network may lead to a none suitable approximation. From here on the network is not further utilized and we have employed exact analysis. It should be noted that since the range of each variable is known, after some generations the search space will be covered and a network should have simply a suitable interpolation capability. Due to the high number of input in the search space, this an obvious expectation from the network to result in accurate results. The objective function is the same as Eq. (15.21) with the difference that the inclusion of the second term is not needed.
