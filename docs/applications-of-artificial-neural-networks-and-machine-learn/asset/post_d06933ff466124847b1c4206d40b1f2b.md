## 19.8 Conclusions

In this article, the axial strength of circular column reinforced with CFRP fibers is estimated by artificial neural network optimized with the help of meta-heuristic algorithms GA, PSO, CBO and ECBO. The neural networks used are feedforward and radial. In this regard, a set of experimental data, including 223 uniaxial compression tests, was collected from the literature. To get proper answers, first all the data used were normalized between 1 and -1. The parameters include compressive strength of concrete block (fco), modulus of elasticity of used CFRP plates (Ef), thickness of CFRP strips (tf), tensile capacity of used CFRP plates (ff), sample diameter (D), sample length (H) as Input parameters were considered to obtain CFRP concrete strength. The results of the obtained models, which include 8 models, were evaluated using common criteria for error and performance evaluation, including MSE, RMSE, MAE, MAPE, NMAE, NRMSE, R. For the training stage of the models, 70% of the available experimental data were used and the rest were kept hidden as part of testing and validation. The results showed that the combination of feedforward neural network and ECBO algorithm can successfully increase the accuracy of CFRP concrete strength estimation. The proposed empirical equation, which is constructed using the optimized weights and constants of the ECBO-FFB composite, can be easily implemented to evaluate the strength of CFRP concrete. Quantitative results obtained from the analysis are reported below.

- Two feedforward and radial basis neural networks with one hidden layer and 10 neurons and sigmoid activation function were considered as neural network structure. Their combination was done with PSO meta-heuristic algorithm and R results were presented for the training and testing phase. For TR-PSO-FFB, R value is 0.59299, for TS-PSO-FFB is 0.51772. For TR-PSO-RBF, R value is 0.59867, for TS-PSO-RBF is 0.43561. Also, the results for the rest of the combinations are as follows:
- For TR-GA-FFB, R value is 0.6094, for TS-GA-FFB is 0.46848. For TR-GA-RBF, R value is 0.5379, for TS-GA-RBF is 0.77294. For TR-CBO-FFB, R value is 0.79805, for TS-CBO-FFB is 0.78002. For TR-CBO-RBF, R value is 0.68993, for TS-CBO-RBF is 0.75939. For TR-ECBO-FFB, R value is 0.88418, for TS-ECBO-FFB is 0.831. For TR-ECBO-RBF, R value is 0.6757, for TS-ECBO-RBF is 0.82588.

According to the above results, ECBO-FFB correlation coefficient has a better result.

- For a better understanding of the comparison of MSE values and error percentage, refer to Figs. 19.9, 19.10, 19.11, 19.12, 19.13 and 19.14. As can be seen, the mean squared error as well as the error percentage in the model combined with the ECBO algorithm show better values. Also, comparing two feedforward and radial basis neural networks, the values in the feedforward neural network show lower values. As a result, the ECBO-FFB model is a better model than other existing models.

- Other criteria for error and performance evaluation, such as RMSE, MAE, MAPE, NMAE, NRMSE, which have been investigated in the article, their values are detailed in Tables 19.2 and 19.3. For example, the comparison of MAPE results shows that among the different models combined with ECBO-FFB algorithms, they have lower values, which indicates the superiority of this model over other models. Also, this comparison can be checked in the RMSE parameter and a similar result can be obtained.
