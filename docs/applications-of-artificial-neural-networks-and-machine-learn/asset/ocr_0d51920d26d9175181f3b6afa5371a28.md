# 1.6.26 Support Vector Machine

Support vector machine or SVM is a famous and powerful machine learning algorithm in the field of machine learning and data mining. The main purpose of SVM is to create an optimal decision boundary between two or more classes using training data. For this, SVM seeks to find a boundary (hyperplane) that separates most of the data with a maximum distance and also separates the two classes well. Data, known as supports, are important in this process and play an important role in determining the decision boundary. Important advantages of SVM: high performance in cases where the number of features is very large, not depending on the scale of the data as input, the ability to use in data Linear and non-linear, possibility of use in classification and regression problems. SVM is one of the most widely used algorithms and widely used in various fields including image classification, text processing, pattern recognition and big data analysis.
