
## 1.2.7 Neural Networks

Neural networks are a computational model inspired by the structure of the human brain, which are mostly used to learn and recognize patterns and relationships between data. These networks are composed of one or more layers of neurons and information is transmitted through specific weights assigned to each connection between neurons. By training or adjusting these weights, the neural network can learn to recognize different patterns and features and then use them to make predictions or make decisions in new situations. There are different types of neural networks, which are explained in detail below. Neural networks are known as one of the key technologies in the field of deep learning and artificial intelligence and can model nonlinear problems. Because of this feature, they can be used in many problems in different fields such as image and speech processing to machine translation and data analysis. In general, neural network applications can be divided into three groups: data classification, data clustering, and regression problems [7].

### 1.2.7.1 Classification

In the data classification procedure, in order to train the model, a large amount of "labeled data" is needed so that the model predicts new data categories using the information provided by the data labels. In other words, in the data classification method, a person must use his knowledge in preparing the data set and label the data required for training the model based on various specialized knowledge such as linguistic knowledge so that the model learns the relationship between data and labels. This approach is called "supervised learning" in which human-prepared labels help the model learn. Determining spam and non-spam emails is an example of classification tasks and supervised approach.

### 1.2.7.2 Clustering

In the clustering method, deep learning algorithms recognize groups of data without the need for labeled data. In other words, clustering neural networks put them in separate groups by simply checking the similarity of the data, and eventually several groups of data are formed, and the data of each group have similar characteristics to each other. This approach of learning is called "unsupervised learning", during which the model recognizes different types of data groups without using any additional information and simply by having the data. The advantage of this method compared to the classification method is that there is no need to provide labeled data, which has a significant impact on reducing financial and time costs. One of the main principles of deep learning models is that the greater the diversity and distribution and volume of the model's training data, the more the model learns from the data, and the model will perform better in recognizing new data and making decisions about the defined problem. Since the volume of unlabeled data is larger compared to labeled data, clustering algorithms have better accuracy and performance.

### 1.2.7.3 Regression

In regression problems, the neural network is used to find the relationship between the "independent variables" or features and the "dependent variables" or the output value of the network. The output values of the model in regression problems are "continuous" values. Regression, like the classification method, uses the supervised learning approach, and in order to train the model, a dataset must be provided. Forecasting the cost of product prices and the amount of product sales in a future period of time are examples of tasks that can be modeled with the regression method.

## 1.3 General Structure of Neural Network

In order to understand the question "what is a neural network", one must look at the structure of the network and its components. The neural network consists of several layers, the minimum number of these layers is 3 layers. Input layer, middle or hidden layer and output layer. Each layer of the neural network consists of a set of nodes that have the same function as the "neurons" of the human brain. In the image below, it can be seen that the first layer has 2 nodes, the hidden or middle layer has 3 nodes and the last layer has 1 node. The number of nodes in each layer will be different according to the number of dimensions of the input data and the problem for which we want to train the model, [8] and [9]. General structure of neural network is shown in Fig. 1.2.

Each neural network has an input layer that receives data and sends it to its next layer to perform various calculations on the data. In other words, this layer does not apply any computing and processing operations on the data and is only responsible for receiving data and sending them to the next layers. The input data of the first layer can include text, audio and video information.

The layer that is placed between the input layer and the output layer is called the hidden layer or the middle layer. The minimum number of intermediate layers of the neural network is one layer, and based on the complexity and type of problem, it can be added to the number of intermediate layers of the network. The more the number of middle layers of the network, the deeper the network and the higher its computational load. The intermediate layers are responsible for performing computational operations on the data received from their previous layer. The term "deep" is also derived from the type of neural network structure. One of the old neural networks, which is called "perceptron", contains only one middle layer, and therefore this type of network is considered a "shallow" type of neural network. Nowadays, neural networks with more than 3 hidden layers are considered as deep networks.

The last layer of the neural network is the output layer of the network, which calculates the output values of the neural network. In other words, the output layer, by receiving its input from the previous layer (hidden layer), performs calculations on them and finally produces the output of the network.

The layers of the neural network are made of independent units called nodes, which behave similar to the behavior of neurons in the human brain. Nodes receive their input data and return a value in the output by performing calculations on them. The internal structure of the node includes various components as follows:

**Node input**: In the first layer of the neural network, the input nodes are in the form of numerical vectors with the same length. The input of the nodes in the hidden layers and the output layers are the output values obtained from their previous layers.

**Node input weights**: The weights determine the importance of node inputs. In other words, by applying the internal multiplication of the input value of the node and the weight matrix, the importance of each input feature is determined. In each step of the Backpropagation procedure, the values of the weights are updated to reduce the final value of the loss function, [10]. Structure of neural network is shown in Fig. 1.3.

**Node activation function**: The input to the activation function is a linear combination of input values, weights, and bias values. The task of the activation function in neural networks is to transform the linear combination of inputs into a non-linear one and maps the input values to the space with a certain interval based on the type of activation function. In other words, these functions determine whether the output of the node is important to the neural network or should be ignored.

**Node Bias**: The role of bias in a neural network is to change the final output of the activation function. The role of bias is similar to the role of the constant value in the linear function and moves the final value of the activation function to the left and right in the vector space so that the final function matches the data better and the model has a more accurate prediction.

To understand the function of activation functions in neural networks, it is necessary to explain four important and basic concepts in neural networks. Feedforward, Backpropagation, Vanishing Gradient and Exploding Gradient are related to the performance of activation functions [10].
