# ## 4.4 Software for Training

The backpropagation learning method is used here that is a popularized and developed into a workable process by Rumelhart et al. [7]. Numerous generalizations have been made and many applications have been found for backpropagation since 1985. The method of training adopted in this chapter is backpropagation. This approach is the most successfully and widely used algorithm among artificial neural networks. In backpropagation the input is propagated from input layer through other layers to output layer, and then the error is propagated back through the network from the output layer to the input layer. This process is repeated until the error is reduced to a specific value, or the number of iteration is exhausted. The learning rule associated with backpropagation method is known as generalized delta rule, Rumelhart et al. [7]. According to this rule for changing the weights in the network, for a given pattern p, the following relation can used:

\(\Delta w_{st}(n+1) = \eta(\delta_{pr} o_{ps}) + \alpha w_{st}(n),\)

where \(w_{st}\) is the connecting weight from the source “s” layer to the target “t” layer and \(o_{ps}\) is the output produced from pattern p as the result of the input \(o_{p(s-1)}\). n is the input-output presentation number and \(\eta\) is the learning rate and \(\alpha\) is the momentum.

The momentum \(\alpha\) is the fraction which is multipliec by the previous weight change and added to current weight change; \(\alpha\) should be positive and less than unity Typical values of \(\alpha\) lie in the range (0.5, 0.9), but for some problems it is shown that \(\alpha\) = 0.0 to be the best.

Dynamic adjustments of momentum and learning rate is an effective method for network training. The two terms are not independent, and should be chosen and modified as a pair. In general, dynamic adjustment of both parameters can accelerate convergence, however, values of either \(\eta\) or \(\alpha\) that are too large, can lead to instability in the update process.

There are many softwares available for training. In this chapter NETS2.01 and Neural works of Refs. [8 and 9] are employed. The later program is found more flexible and provides additional useful information. In the process of training by BP, both sigmoid and tangent hyperbolic available functions are employed.

NEURALWORKS: This program is capable of mapping the input data to an arbitrary range. This program reads the input data and the information at each column is mapped into the considered domain employing the maximum and minimum values in that column. The mapped data is then used in the training.

NETS2.01: This program does not map the input into a domain with arbitrary ranges. A program called “min-net” is prepared to provide such a capability.
