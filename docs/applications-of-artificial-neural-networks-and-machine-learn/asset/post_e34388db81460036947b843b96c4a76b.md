## 1.6.20 Generative Adversarial Networks

Generative adversarial networks are a large family of binary networks built from Generator and Discriminator. The generator is responsible for generating synthetic data. In fact, its job is to generate new data that looks real and is similar to real data. The discriminator plays a major role in data evaluation. This network tries to distinguish between the data generated by the generator network and the real data. The training goals of this network is to be able to distinguish between two types of data.

The main goal in adversarial generative networks is to program the generative network to produce data that looks real. This process gradually improves the quality of the data produced by the generator network. This concept was proposed by Goodfellow and others and is known as one of the most widely used and effective methods in the field of artificial intelligence. ## 1.6.21 Liquid State Machine

A Liquid state machine or LSM network is a type of artificial brain computing model inspired by the workings of animal brains, particularly the brains of mice. It is a sparse neural network in which the activation functions are replaced by the threshold level. The cell sums the values from the sequential samples and gives the output only when the threshold is reached. It then resets the external counter to zero. These networks are used for signal processing and pattern prediction. These models consist of a large number of neurons (main processing elements of the brain) and connections between them. The LSM architecture is so-called “fluid” because inputs (e.g., signals from sensors) enter the network in an ultrafast, streaming fashion and continuously act as neural inputs to the network over time.

The advantages of fluid state machine networks are: real-time processing capability for temporal inputs, ability to learn dynamics and sequential patterns, greater flexibility than traditional recurrent models, higher efficiency in processing complex and non-linear patterns.

Also, the LSM model is well suited for tasks such as pattern recognition, predicting individual rejection, detecting unusual activities, and making time-based decisions. Liquid State Machine shown in Fig. 1.47.

## 1.6.22 Extreme Learning Machine

Extreme Learning Machine (ELM) is an attempt to reduce the complexity behind feed-forward neural networks. This is done by constructing sparse hidden layers with random connections. This type of neural network requires less computing power. In ELM, the weights between the hidden layers of the network are set randomly and there is no need for gradient optimization. Due to this property, ELM has high speed and good performance in problems with large data volume. In addition, ELM is widely used for the problems of image processing, pattern recognition, signal processing, and temporal pattern recognition. The main importance of ELM is that, unlike traditional neural networks that require adjusting weights, ELM is known for its high learning speed and simple implementation. These features have made ELM highly popular for solving various problems in the field of machine learning and artificial intelligence. Extreme Learning Machine shown in Fig. 1.48.

## 1.6.23 Echo State Network

Echo State Network or ESN is a type of recurrent neural network model that is used as a random and open model for long-term data processing. This model was first introduced by Herbert Jagger in 2001.

An important feature of ESN is that the weights between hidden and output layers are determined randomly, while the weights between input and hidden layers are fixed by default. These random weights have a significant impact on the execution of calculations and ESN has the ability to learn complex models. With this feature, ESN is widely used for signal prediction problems, system dynamics modeling, temporal data analysis, and artificial intelligence model development in various fields. Other advantages of ESN include simplicity of implementation, parallel processing power and flexibility of modeling models. Echo State Network shown in Fig. 1.49.

## 1.6.24 Deep Residual Network

Deep Residual Network or DRN is a deep neural network architecture that uses residual blocks to train deep networks. This model was introduced by Kohi Sezhin in 2015 and has become very popular due to its superior capabilities in training and using deep networks. In this architecture, residual blocks are used so that neurons in deep layers can easily learn complex mappings. The main principle of this architecture is that instead of training layer by layer and focusing on many details, it uses highlighting the residual difference between the input and output of each block for training. By using residual blocks, DRN generally improves the error and performance of deep networks and avoids gradient fading and propagation problems in deep networks. Therefore, DRN is very useful for tasks such as computer imaging, pattern recognition, machine translation, and other tasks involving large and complex data. ## 1.6.25 Kohonen Network

## 1.6.26 Support Vector Machine

Support vector machine or SVM is a famous and powerful machine learning algorithm in the field of machine learning and data mining. The main purpose of SVM is to create an optimal decision boundary between two or more classes using training data. For this, SVM seeks to find a boundary (hyperplane) that separates most of the data with a maximum distance and also separates the two classes well. Data, known as supports, are important in this process and play an important role in determining the decision boundary. Important advantages of SVM: high performance in cases where the number of features is very large, not depending on the scale of the data as input, the ability to use in data Linear and non-linear, possibility of use in classification and regression problems. SVM is one of the most widely used algorithms and widely used in various fields including image classification, text processing, pattern recognition and big data analysis.

## 1.6.27 Neural Turing Machine

A neural Turing machine is an advanced artificial intelligence model proposed by Alex Grounder and others. This type of neural network is actually a feed forward (FF) neural network with extracted memory cells. Some researchers also believe that Turing Neural Machine is an abstraction over LSTM. This model tries to combine the ideas of the Turing machine, which includes the ability to read and write data in memory, with the power of deep neural networks. The neural Turing machine has the ability to learn and use an external memory to solve complex and difficult problems. This memory can act as an environment for a large number of data rewrites to perform complex and fast write operations. Using new learning algorithms, the neural Turing machine is able to perform difficult tasks that require learning data in a dynamic environment. This model is very useful for problems such as performing long sequences, machine translation and solving complex algorithmic problems. Neural Turing Machine shown in Fig. 1.53.
