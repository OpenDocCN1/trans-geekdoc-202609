# 1.6.21 Liquid State Machine

A Liquid state machine or LSM network is a type of artificial brain computing model inspired by the workings of animal brains, particularly the brains of mice. It is a sparse neural network in which the activation functions are replaced by the threshold level. The cell sums the values from the sequential samples and gives the output only when the threshold is reached. It then resets the external counter to zero. These networks are used for signal processing and pattern prediction. These models consist of a large number of neurons (main processing elements of the brain) and connections between them. The LSM architecture is so-called “fluid” because inputs (e.g., signals from sensors) enter the network in an ultrafast, streaming fashion and continuously act as neural inputs to the network over time.

The advantages of fluid state machine networks are: real-time processing capability for temporal inputs, ability to learn dynamics and sequential patterns, greater flexibility than traditional recurrent models, higher efficiency in processing complex and non-linear patterns.

Also, the LSM model is well suited for tasks such as pattern recognition, predicting individual rejection, detecting unusual activities, and making time-based decisions. Liquid State Machine shown in Fig. 1.47.

# 1.6.22 Extreme Learning Machine

Extreme Learning Machine (ELM) is an attempt to reduce the complexity behind feed-forward neural networks. This is done by constructing sparse hidden layers with random connections. This type of neural network requires less computing power. In ELM, the weights between the hidden layers of the network are set randomly and there is no need for gradient optimization.
