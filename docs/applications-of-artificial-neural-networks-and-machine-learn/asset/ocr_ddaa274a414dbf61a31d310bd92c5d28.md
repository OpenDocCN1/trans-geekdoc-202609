For developing the KELM model, different activation functions including the radial basis function (RBF), hard limit function (hardlim), sigmoid function and polynomial function were investigated to achieve the best results for both training and testing datasets [34]. Results indicated that the model with RBF as an activation function has the best performance in comparison with other activation functions. Furthermore, different number of hidden neurons have been tried to reach the best performance for both training and testing datasets.

In general, two goals were considered for choosing the best model: (i) The model must be accurate (ii) The model must have also generalization capability (or the good performances for unseen dataset). To achieve these goals, we developed different models with different number of hidden neurons and four different activation functions. The model that was more accurate and also had a good performance for testing dataset is chosen as the most effective model. To further clarify how the best model is chosen, the variations of RMSE values of the developed KELM models versus the number of hidden layers for different activation functions are plotted as shown in Fig. 21.4. It can be seen that the accuracy of developed model for the testing dataset decreases as the number of hidden layers increase. This indicated that the KELM over-fitted itself to training dataset. and consequently its generalization capability is reduced by increasing the number of hidden layers.

The results indicated that the model with 13 neurons in its hidden layer has the best performance. The topological structure of the developed KELM model is shown in Fig. 21.5.

To develop multi-layer perceptron (MLP) neural networks for predicting bond strength, the Levenberg–Marquardt algorithm is used to generate an optimum structure. Several scenarios with different number of hidden layers and different neurons in each hidden layer are implemented to reach the best performance. The same strategy (or having the same performance for training and testing datasets) used for tuning the KELM algorithm is also employed here to reach the optimum structure. All simulations are done in the MATLAB programming language version R2012a. The optimal topological structure obtained by MLP is 9 input variables in an input layer, 14 neurons in hidden layer 1, and 12 neurons in hidden layer 2. The output layer is composed of Pmax values predicted by ANN algorithm.

To develop a predictive model for bond strength based on the ANFIS algorithm, MATLAB programming language version R2012a is also employed. The Genfis2 function based on the subtractive clustering method is used to generate the FIS structure. The strategy for finding the best structure of ANFIS is similar to the ones used for tuning the KELM and ANN. At first step, the member functions of the inputs are generated using subtractive clustering. Then a recursive least square method is used to tune the member function parameters. The number of member functions is gradually decreased by reducing the range of influence of cluster centers in a trial and error manner.
