# 1.5.7 Softmax Activation Function

The idea of designing the Softmax function is taken from the sigmoid function. As mentioned, based on the output of the sigmoid function, which is between 0 and 1, this function is used to calculate the probability. However, the sigmoid activation function has a fundamental problem. If several outputs are produced as 0.8, 0.9, 0.6, 0.7 and 0.8, the sum of all outputs will be greater than 1; while the sum of probabilities must be 1. Softmax activation function is considered a type of sigmoid function. In other words, the Softmax function is a combination of several sigmoid functions that calculate relative probabilities. In other words, the Softmax function determines the probabilities of several classes. Usually, in “Multi-Class Classification” tasks, the Softmax activation function is used in the last layer of the neural network. The Softmax formula is f (xi ) = e^xi /sum(e^x ) is, where xi is the value of each input node and sum(e^x ) is the sum of all input values. Softmax Activation Function shown in Fig. 1.12.
