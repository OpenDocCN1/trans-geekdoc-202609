# 20.4 Model Development

# 20.4.1 Influential Parameters

The most important factors commonly used in the previous models and codes are employed as the predictor variables. Consequently, formulation of maximum bond strength is considered as follows:

$P_{max} = f(f_{mt}, E_pt_p, b_p, L_b, k_b)$ (20.15)

where $f_{mt}$ is the tensile strength of the support, $E_pt_p$ is the axial rigidity of FRP reinforcement, $b_p$ is the width of FRP reinforcement, $L_b$ is the bond length, and $k_b$ is the width factor, which the common expression for this factor is as follow [37]:

$k_b = \sqrt{\frac{3 - \frac{b_p}{b_m}}{1 + \frac{b_p}{b_m}}}$ (20.16)

The width factor, as defined in the Eq. (20.16), particularly depends on the ratio between FRP plates width and masonry substrate width ($b_p/b_m$). Recent studies have confirmed that the failure mechanisms leading to debonding are three dimensional when the FRP reinforcement width is smaller than the support width. In particular, when the bond length is comparable with the width, the bond stresses can spread laterally over the actual bonded width and, thus a volume of material is involved in the debonding mechanism. In order to take this three dimensional effects into account in final models, $k_b$ is considered as input variable.

# 20.4.2 Dataset Description

In this study, for the first time a comprehensive collection of 575 test series obtained from published literatures [10, 11, 38–56] are used to model maximum bond strength between FRP reinforcement and masonry units. It should be noted that some tests were conducted several times on a particular specimen for the same conditions. In this regard, the average of maximum bond strength recorded in identical tests is used to develop models. Therefore, 231 distinctive data points are derived from 575 test series. Details of datasets used and the range of input and output variables are presented in Table 20.1. Test results obtained from single or double lap shear test have been only employed to ensure that the results are more homogeneous.
