# 1.2.7.3 Regression

In regression problems, the neural network is used to find the relationship between the “independent variables” or features and the “dependent variables” or the output value of the network. The output values of the model in regression problems are “continuous” values. Regression, like the classification method, uses the supervised learning approach, and in order to train the model, a dataset must be provided. Forecasting the cost of product prices and the amount of product sales in a future period of time are examples of tasks that can be modeled with the regression method.
