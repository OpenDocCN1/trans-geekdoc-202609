Fitness-based migration selects individuals according to their fitness level, the most fit individuals being the ones selected for migration, and replaces individuals in a subpopulation uniformly at random.

A further parameter specifies the population topology over which migration will take place. By using ring topology individuals are transferred between directionally adjacent subpopulations.

A similar strategy to the ring topology is the neighborhood migration. Like the ring topology, migration is made only between nearest neighbors, however, migration may occur in either direction between subpopulations. For each subpopulation, the possible immigrants are determined, according to the desired selection method, from adjacent subpopulations and a final selection made from this pool of individuals. This ensures that individuals will not migrate from a subpopulation to the same subpopulation.

The most general migration strategy is that of unrestricted migration that is shown in Fig. 15.1. Here, individuals may migrate from any subpopulation to another. For each subpopulation, a pool of potential immigrants is constructed from the other subpopulations. The individual migrants are then determined according to the appropriate selection strategy.

The advantage of this lies in that such an amount of patterns can be utilized for controlling the network in each generation. If the output of the network using exact analysis has an error more than a specified value, this shows that the subsequent steps the range of variables are changed and we should train a new network with new training set. However, since the primary selection of the first generation is random, and covers the entire search space, as observed in all the examples, there will be no need to train a new network and the primary network can further be used up to the end of the process.
