## 1.5.20 Hard Shrink Activation Function

Hard Shrink is an activation function that shrinks non-essential input values from a limit. This function converts the values that are less than a threshold to zero and above it to the main values. Its advantages are the elimination of non-essential values and the precise adjustment of the cut limit, as well as.

The control over the inputs is not important, but for optimal performance, it needs to determine and set the appropriate value for the threshold limit λ. Hard Shrink activation function shown in Fig. 1.25.

Hard Shrink formula is:

```
f(x) = x - λ * sign(x) * max(0, |x| - λ)  (1.19)
```

### 1.6.1 Perceptron Neural Network

Perceptron is the simplest and oldest model of artificial neural networks known to mankind. The perceptron receives a number of inputs, aggregates them and applies an activation function on them, and finally passes them to the output layer. In this part, the main miracle of artificial neural networks does not happen. This model is specifically used for simple classification problems. Perceptron works great for linear separable problems, but for more complex problems, deeper network models are needed. Perceptron Neural Network shown in Fig. 1.26.

### 1.6.2 Feedforward Neural Network

Feed Forward Neural Networks are also considered to be old members of the neural network family, and the approach related to them originates from the 50s. The performance of this algorithm is that all nodes are fully connected, the activation flows from the input layer to the output, without having a backward loop, and there is also a layer (hidden layer) between the input and output. Most of the time, this type of neural networks are trained using Backpropagation method. Feedforward Neural Network shown in Fig. 1.27.

### 1.6.3 Radial Basis Neural Network

Radial Basis Networks are actually Feedforward (FF) neural networks that use the Radial Basis Function, instead of the Logistic Function, as the activation function. The question that arises at this point is what is the difference between the basic radial neural network and the feedforward neural network?
The logistic function maps some arbitrary value to a 0–1 interval to answer a “yes or no” question (binary question). These types of neural networks are suitable for Classification and Decision Making Systems, but they perform poorly for continuous values. Meanwhile, basic radial functions answer the question, “How far are we from the goal?” And this makes these neural networks suitable for function estimation and machine control. In short, it should be said that basic radial neural networks are actually a kind of feedforward neural networks with different activation functions and characteristics. ### 1.6.4 Deep Feed Forward Neural Network

Deep Feed Forward Neural Networks, in the early 90s, became an introduction to the discussion of neural networks. This type of neural networks are also feedforward neural networks, but they have more than one hidden layer. The question that arises at this point is, what is the difference between this type of neural network and the traditional feedforward neural network?

When training a feedforward neural network, only a small fraction of the error is passed to the previous layer. For this reason, the use of more layers leads to an exponential growth of the training time, and the same issue makes deep feedforward neural networks practically useless and impractical. In the early 2000s, approaches were developed that made it possible to effectively train a deep feed-forward neural network (DFF). Today, these neural networks form the core of modern machine learning systems and serve a similar purpose to that of feed forward (FF) neural networks; but include better results. ### 1.6.5 Recurrent Neural Networks

Recurrent Neural Networks introduce a different type of cells called Recurrent Cells. The first network of this type is the Jordan Network. In this type of network, each hidden cell receives its output with a fixed delay. Regardless, Jordan’s network was similar to conventional feedforward neural networks. Of course, various changes such as passing state to Input Nodes, variable delay and other things have happened in this type of network, but the main idea remains the same.

This type of neural networks (NN) is basically used when context is important, and in fact, when decisions from previous iterations or examples can affect current examples. As a common example of this type of fields, we can mention (Text). In text, a word can be analyzed only in the context of the preceding word or sentence. ### 1.6.6 Long Short Term Memory

Long/Short Term Memory (LSTM) introduces a new type of Memory Cell. This cell can process data when it has a time gap (or time delay). A feedforward neural network can process text by remembering the previous ten words. Meanwhile, LSTM can process video frames by remembering what happened in the previous frames. LSTM networks are widely used for speech recognition and writing recognition. Memory cells are basically a combination of a pair of elements called gates.
