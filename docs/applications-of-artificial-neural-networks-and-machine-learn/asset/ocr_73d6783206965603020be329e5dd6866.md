$$D = \sum_{i=1}^{n}|x_i - v_i|$$ (8.1)

where D is a measure of how close is the input vector x to weight vector v. Choosing an arbitrary value for D, the size of units in the Kohonen cluster layer is dynamically determined. Selecting the value of D is problem-dependent, however, smaller values will result in larger size networks.

In the training process, the number of Kohonen units either increases or remains unchanged. If the jth input vector is D away from all previously defined units, a new unit is introduced, otherwise the weight vector nearest to the jth input vector is modified. In this process, the weights from the input units to the Kohonen cluster units are specified which have almost their optimal values. These weight values are slightly corrected in the next stage of the training. In the next step, the weights from the cluster units to the output units are computed and slightly modified later. Since this procedure specifies the proper values for the weight matrices, the number of iterations is very low, usually one or two.
