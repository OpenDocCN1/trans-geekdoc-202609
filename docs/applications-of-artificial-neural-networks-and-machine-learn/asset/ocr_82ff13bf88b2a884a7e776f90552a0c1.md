# 1.5.19 Soft Shrink Activation Function

Soft Shrink is an activation function that is generally used to remove small parts and unimportant noise from the input. This function is general similar to the Threshold function and converts the input values below a threshold to zero and above it. Its advantages are removing noise and small parts from the input as well as normalizing the output based on the threshold value. But it needs to be adjusted. It is accurate and suitable for the limit of \(\lambda\). Soft shrink activation function shown in Fig. 1.24.

Soft Shrink formula is:

```
\(f(x) = sign(x) * max(0, |x| - \lambda)\) (1.18)
```
