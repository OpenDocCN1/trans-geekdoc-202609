# 4.3 Configuration Processing, Analysis and Design

The structural models are generated using FORMIAN developed by Nooshin et al. [6]. The analysis is performed by SAP90, and a program called “Hdesign” is developed for their design. The following assumption are considered:

+   1. The sum of dead load and live load equal to 2.5 kN/m² is applied to the nodes of the top layer.
+   2. All the nodes are considered as ball jointed.
+   3. Linear analysis is performed.
+   4. One hundred and four Different tube sections available in STAHL are included in the program for design.
+   5. Design is carried out according to AISC code.
