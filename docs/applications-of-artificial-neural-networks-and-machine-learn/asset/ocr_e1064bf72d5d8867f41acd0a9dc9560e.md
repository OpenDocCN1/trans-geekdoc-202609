Because of the similar layer-to-layer topology, RBF networks are often considered to belong to MLP networks. It was proved that RBF networks can be implemented by MLP networks with increased input dimensions. Except for similarities in topologies, RBF networks and MLP networks operate very differently. First of all, RBF networks are simpler than MLP networks, which may have more than three architectural layers, so the training process is generally faster than MLP networks. Second, RBF networks act as local approximation networks because the network outputs are determined by hidden units specified in specific local input fields. Whereas MLP networks work globally, because the outputs of the network are determined by all neurons. Thirdly, it is necessary to set the correct initial states for RBF networks. While MLP networks initially use randomly generated parameters. Last and most importantly, the classification mechanisms are different for RBF networks and MLP networks: RBF clusters are separated by hyperspheres. While in neural networks, hypersurfaces with arbitrary shape are used for separation. In the simple two-dimensional case as shown in Fig. 19.2, the RBF network in Fig. 19.2a separates the four clusters with circles or ellipses (Fig. 19.2b). While the neural network in Fig. 19.1a does the separation with lines (Fig. 19.1b).
