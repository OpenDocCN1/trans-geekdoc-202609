# 19.8 Conclusions

In this article, the axial strength of circular column reinforced with CFRP fibers is estimated by artificial neural network optimized with the help of meta-heuristic algorithms GA, PSO, CBO and ECBO. The neural networks used are feedforward and radial. In this regard, a set of experimental data, including 223 uniaxial compression tests, was collected from the literature. To get proper answers, first all the data used were normalized between 1 and -1.
