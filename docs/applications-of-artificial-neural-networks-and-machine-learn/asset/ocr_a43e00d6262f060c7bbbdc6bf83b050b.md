The training of a network is equivalent to finding proper weight matrices such that a desired output is generated for a corresponding input.

Mathematically, such networks can be thought of as multi-dimensional spaces. Each layer corresponds to a space with the dimension equal to the number of nerouns in that layer. Each transformation consists of two operations: matrix multiplication and vector squashing, i.e. for R^m -> R^n, {V}_m [W]_{mxn}, where {V}_m in R^m, {V}_n in R^n and [W]_{mxn} is the weight matrix. The squash is a function often known as the activation function converting a vector by squashing each vector component with a nonlinear function.

Backpropagation algorithm is the most popular training scheme for this type of networks. According to this algorithm, learning proper weights is conducted by an iterative two-step process. The two steps are.

Computing the discrepancy between the desired and actual outputs, and feeding back the error signal layer by layer to the inputs, changing the weights in such a way as to modify them in proportion to their responsibility for the output error. For details of this algorithm refer to Haykin [14].

The learning rule associated with the backpropagation method is known as generalized delta rule [17]. According to this rule, for changing the weights in the network, for a given pattern p, the following relation may be used:

```
\(\Delta W_{st}(n) = \eta \delta_{pr_{op}s} + \alpha W_{st}(n - 1), \quad (6.6)\)
```

where n is the input-output presentation number and \(\eta\) is the learning rate and \(\alpha\) is the momentum.
