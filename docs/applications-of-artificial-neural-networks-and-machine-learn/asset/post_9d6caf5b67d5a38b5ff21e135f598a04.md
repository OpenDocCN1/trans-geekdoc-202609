### 1.3.1 Feedforward

The model that forwards information from the input (from layer to layer) is known as feedforward. This process is performed as the prediction or network output calculation for the input data without any feedback, in other words, the information is passed from the input layers to the output layers, without interruption or feedback. The feedforward process in neural networks is generally done as follows:

Input information (such as images, text, or numerical features) is fed to the input layer of the network.

Information is transferred from layer to layer through specific weights and processed by activations (such as ReLU or sigmoid activation function). This process continues until reaching the output layer. Finally, the output calculated by the network is produced as the final response to the inputs given to the network.

The feedforward process is used as the first step in the decision-making and forecasting process using neural networks. This process is used to predict new data, recognize patterns, make automated decisions, machine translation and many other applications of machine learning.

### 1.3.2 Backpropagation

Backpropagation is a common learning algorithm in deep neural networks that is used to update model weights. This algorithm uses a forward process to predict the output and calculate the prediction error, and then passes this error backward and optimizes the network weights to reduce the prediction error. The backpropagation process is as follows:

First, by entering the data and calculating the output, the predicted error is calculated. Then, using the least squares method or another criterion, the calculated error is transferred back and attributed to each of the weights of the network, and finally, using the learning rate and the optimization algorithm such as integration or momentum, the weights of the network are updated in such a way that the prediction error is reduced.

This process is repeated until the model reaches an optimal state and the prediction error is minimized. Backpropagation algorithm is one of the most important machine learning algorithms for training deep neural networks and helps to optimize model weights and improve network performance.

### 1.3.3 Gradient Vanishing

Gradient vanishing is a common problem in neural network training that due to concatenation of several layers of neurons, the gradients (partial derivatives of the objective function with respect to the weights) may vanish or become very small. This causes the network weights to not be updated effectively and the network performance is not improved. Gradient vanishing is clearly evident in deep networks with more layers, as at each layer the derivatives are carried to lower layers and may shrink or disappear. This problem can slow down the training process, increase the time required for the network to converge or even reach a parallel state.

Some methods of removing gradient vanishing in neural networks include using different activation functions (such as Leaky ReLU), using softening methods such as Dropout, using normalization methods such as Batch Normalization, or using networks with a special structure such as recurrent neural networks. It is possible to avoid the gradient fading problem and to continue training the network effectively.

### 1.3.4 Gradient Exploding

Gradient exploding is another situation in neural network training where the gradients are very large and go to infinity. This may happen due to the derivation of the sequence of large classes from each other in deep networks and cause instability in network training. The occurrence of gradient explosion can lead to unpredictable reactions and numerous jumps in updating the network weights, which reduces the quality and performance of the network. This problem usually occurs when using a very large learning rate in the process of updating the weights and can cause the network to fail to converge or other undesirable problems.

To prevent gradient explosion, one of the common methods is to use a technique called “Clipping Gradient” in which, if the gradients exceed a certain limit (threshold), they are automatically reduced and normalized to prevent gradient explosion. This method can well establish and stabilize the training process in neural networks [11].

## 1.4 Activation Functions

Activation functions are used in neural networks to nonlinearize the information that is passed from one layer to the next. These functions help the model express more complex patterns. Since activation functions determine whether a node should be active or inactive, they are very important in neural networks. The main role of the activation function in neural networks is to produce an output value using the inputs of a node. In other words, these functions decide whether a node's input is important or not by performing simple mathematical calculations. Activation functions map the sum value of a node’s weighted input to values from 0 to 1 or –1 to 1 (depending on the type of activation function). Then, these functions pass their final output to the next layer. For this reason, these functions are also known as transfer functions. Activator functions are divided into three general categories. Binary Step Function, Linear Activation Function, Non-linear Activation Function [12].

### 1.4.1 Binary Step Function

The binary step function is one of the simplest activation functions that divides the input into two classes or two different states based on its value. This function returns only two values 0 and 1 and states whether the input should be enabled (1) or disabled (0). Binary Step Function is shown in Fig. 1.4.

The mathematical function of this activator is as follows:

```
\( f(x) = \begin{cases} 0 & \text{for } x < 0 \\ 1 & \text{for } x \ge 0 \end{cases} \quad (1.1) \)
```

Some of the problems of this method can be mentioned such as: This function is not efficient for use in deep neural networks due to the lack of continuous gradients and derivatives in the suspended points. Also, the fixed value of the output (0 or 1) can limit the flexibility and learning power of the model. It also has problems such as gradient fading, dead neurons, and increasing training time due to lack of flexibility and high detail in information transfer.

The linear activation function is the simplest activation function that does not add any nonlinearity to the model. This function is typically used in output layers of models and returns the output as the input. This function is used alone for modeling patterns with low complexity. Some of the problems of this method can be mentioned such as: The linear activation function does not add any nonlinearity to the model, so it is not enough to solve complex problems and the capability of the neural network model. Also, if the linear activation function is used in all layers, the model does not have the ability to model more complex patterns and features. Also, the models that use the linear activation function may not be able to understand complex and diverse patterns and do not have good efficiency and performance. This function cannot be used in the back propagation step because the derivative of this function is equal to a fixed number. And it has no relationship with the input value x. The result of several linear functions on a fixed input value is the same. Therefore, it does not matter if the neural network is made of several hidden layers; because the output of the activation function in the last layer of the neural network is equal to the output of the activation function in the first layer [13].
