### 7.1 Introduction

In this Chapter, a neurocomputing strategy is presented which combines data processing capabilities of neural networks and numerical structural optimization [1]. In this strategy, an improved counter-propagation neural network is used. Two artificial neural networks are trained, one for the constraints and the other for the gradients of the constraints, and structural optimization is accomplished by using these nets. All required parameters such as weight matrices in the neural networks or the gradient computations are automated in this neuro-optimizer strategy. Numerical examples are included to demonstrate the accuracy of the results.

Artificial Neural Network (ANN) is basically a massive parallel computational model that imitates the function of the brain. Analogous to a biological model which consists of a large number of interconnected neurons, the ANN comprises a large number of similarly connected computational elements called artificial neurons. The ANN does not really solve the problem in a strictly mathematical sense, but it demonstrates information processing characteristics that give an approximate solution to a given problem. The ANNs have been widely used in complex non-linear function mapping, image processing, pattern recognition and classification, and so on [2]. In spite of the significant advances in computational technology made in recent years, solutions to many large-scale problems require an excessive amount of computer time. Therefore, it is desirable to develop computational techniques which give partial reliable information to solve a specific problem and reduce computational cost. Many researchers have been interested in the development and application of ANN as a rapid analyzer in structural optimization [3–9]. Two ANNs being used in function approximation are the Backpropagation Net (BPN), and Counter-propagation Net (CPN). One of the drawbacks of BPN is the slow rate of its convergence. This is even more true when large-scale problems are involved, that is, the number of input and output Units are high. In order to alleviate the problem, an improved CPN is implemented with fast and easy training.

In this chapter, two ANNs have been trained using the improved CPN of the authors, the first for constraints and the second for the gradient of the constraints. The trained ANNs respond rapidly to the constraint or the gradient requirement in the optimization process of structures. The proposed approach is general and can be applied to planar and space trusses and yields very good estimates of the optimum design variables. In order to illustrate the efficiency of the improved CPN and the proposed approach, the sizing of planar and space trusses for stress and displacement constraints is considered.

### 7.2 The Improved Counter-Propagation

The topology of the CPN is shown in Fig. 7.1 Counter propagation is a combination of two well-known algorithms: the self-organizing map of Kohonen and the Grossberg outstars. This network learns a near-optimal look-up table approximation to the mapping being approximated.

In the improved CPN the clustering of the Kohonen units is based on the absolute norm defined as

$$D = \sum_{i=1}^{n} |x_i - v_i|$$ (7.1)

Which is a measure of how close is the input vector x to the weight vector v. Choosing an arbitrary value for D, the size of units in the Kohonen cluster layer is dynamically determined. Selecting a value for D is problem-dependent, smaller values will result in larger size networks.

In the training process, the first input vector introduces the first unit in the Kohonen cluster unit and becomes the first weight vector from the input units to this unit. For the subsequent input vectors if the jth input vector is D away from the defined units, a new unit is defined, otherwise the weight vector nearest to the jth input vector is modified. In the process of training, the weight vectors from the input units to the Kohonen cluster units, $v_{ij}$ and the weight vector from the Kohonen layer to the output units, $w'_{jk}$, are specified.

In the standard CPN, when a vector is presented to the network, each unit in the Kohonen cluster unit competes with other units and the unit with the smallest Euclidean distance to input vector x wins. Thus, the output of the winner unit J is simply as follows:
