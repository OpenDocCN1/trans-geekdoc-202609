### 14.2 Definitions

A graph S consists of a set of elements called nodes (vertices) and a set of elements called members (edges), together with a relation of incidence, which associates two distinct nodes with each member, known as its ends. Two nodes of a graph called adjacent if these nodes are the end nodes of a member. A member is called incident with a node if the node is an end node of the member. The degree of a node is the number of members incident with that node.

A path is a finite sequence Pk = {n0, m1, n1, ..., m p, np} whose terms are alternately distinct nodes, ni and distinct members mi, for 1 ≤ i ≤ p and ni−1 and ni are two end nodes of mi. A tree T of S is a subgraph containing no cycle; a cycle being a closed path. If a tree is rooted from a given node n, it may be denoted by Tn.

A spanning tree is a tree containing all the nodes of S. A shortest root tree (SRT n0) rooted from a specified node (starting node) n0, is a spanning tree for which the distance between every node n j of S and n0 is minimum, where the distance between two nodes is taken as the number of members in the shortest path between these nodes. A pair of nodes of a graph which are located at nearly maximal distance apart are known as pseudoperipheral nodes.

A contour Ck_n0 of an SRT n0 contains all nodes with equi-distance k from n0. The number of contours "d" of an SRT is known as its depth, and the highest number of nodes in a contour "w" specifies the width of SRT.

Consider the solution of sparse linear systems of equations

```
Ax = b
```

where the n × n matrix A is a sum of elemental matrices

```
A = \sum_{l=1}^{m} A^{[l]},
```

and the right-hand side vector b is of the form

```
b = \sum_{l=1}^{m} b^{[l]}.
```

In Eq. (14.2) each matrix A[l] has entries only in the principal submatrix corresponding to the variables in element l and represents contributions from this element. This principal submatrix is assumed to be dense. The matrix A may be non-symmetric but the form (2) implies that it has a symmetric pattern.

With reference to Eq. (14.1), column j is said to be active at stage i, if j >= i and there is a non-zero entry in column j with a row index, k, such that k <= i. Letting f_i denote the number of columns that are active at stage i, the maximum frontwidth of A is given by

F_{max} = max {f_i} 1 <= i <= n

The root-mean-squared (r.m.s.) wavefront is defined to be

F_{rms} = \left( \frac{1}{n} \sum_{i=1}^n f_i^2 \right)^{\frac{1}{2}}

Assuming that n and the average value of f_i are reasonably large, it can be shown that a complete profile or front factorization requires approximately O(n F_{rms}^2) operations.

### 14.3 Graph Model of a Finite Element Mesh

At least ten different graph models can be employed for transforming the connectivity properties of finite element meshes into those of graphs [9]. In this chapter, the element clique graph is used as defined in the following section.

### 14.3.1 Element Clique Graph

The element clique graph (ECG) of a FEM, is a graph whose nodes are the same as those of the FEM and two nodes n_i and n_j of ECG are connected with a member if n_i and n_j share an element of the FEM. A simple FEM and the corresponding ECG are shown in Fig. 14.1. This graph has the same nodes as that of the corresponding FEM and provides a direct approach for nodal ordering of the FEM. ### 14.4 Sloan's Algorithm for Element Ordering

This algorithm consists of two phases, namely the selection of pseudo-peripheral nodes, and the numbering, described briefly in the following.

### 14.4.1 Determination of Pseudo-Peripheral Nodes

A pair of starting nodes is determined by the following modified scheme.

Algorithm

- Step 1. Select an arbitrary node v of minimum degree.
- Step 2. Generate an SRTv = {C1v, C2v, ..., Cdv} rooted at v. Decompose the subgraph containing the nodes of Cdv into its components (subcontours).
- Step 3. Select one node of minimum degree from each component. Generate an SRT from each of such nodes, and choose the one corresponding to the smallest width.
- Step 4. Repeat the process of Steps 2 and 3 as far as reduction in width of the SRT can be observed.

The root “s” and the selected end node “e” are the pseudo-peripheral nodes required.

### 14.4.2 Node Reordering

The Sloan's algorithm ensures that the position of a node in the reordering phase is not far from the one for which from the end node e is monotonically decreasing. In this method reordering phase begins at the start node s and assigns 1 to s. The following steps are taken:

![](img/4048998719320644ee88964326fd7995_282_0.png)

Fig. 14.2 Different status of nodes in the process of labeling

Step 1. Find the status of all the nodes. A node can be in the following four states as shown in Fig. 14.2. Prior to the numbering, all the nodes of the ECG model of the considered FEM are assigned non-active status. When a node of ECG is inserted in the priority queue, it is assigned pre-active status. After a node is numbered, it is assigned post-active status. Nodes which are adjacent to a post-active node and that do not have post-active status are defined as having active status. These statuses are illustrated in Fig. 14.2 for a simple graph.

Step 2. Prepare the list of the candidate nodes in the next step, which consists of active and pre-active nodes.

Step 3. Calculate the priority for all the candidate nodes. For node i, the priority is given by:

P(i) = -W₁ × n(i) - W₂ × d(e, i), (14.6)

where W₁ and W₂ are integer coefficients (set as W₁ = 1 and W₂ = 2 in the original Sloan's algorithm [14]); d(e, i) is the distance of node i to the end node e and

n(i) = mᵢ - cᵢ + kᵢ (14.7)

mᵢ is the degree of node i, cᵢ is the number of active and post-active nodes adjacent to node i, and kᵢ is zero if the node i is active and post-active, and unity otherwise. In fact n(i) represents the increment of the frontwidth for labeling of the node i.

Step 4. Select the node with highest priority among the candidate nodes and label it.

Step 5. Repeat steps 1-4 until all the nodes are labeled.

Sloan introduced d(e, i) in order to incorporate the overall property of the graph in the process of ordering, and changed the localized nature of the King's algorithm.

In Eq. (14.6) if W1 = 1 and W2 = 0, then the King's algorithm is obtained, with no need to select the start and end nodes.

### 14.5 A Hybrid Graph-Neural-Genetic Method

In this chapter a neural network is trained for optimal nodal ordering of graphs. In this approach ideas from neural networks and priority function are combined for evaluating suitable coefficients for the vectors of the priority function. Genetic algorithm is used for evaluation of the weights of the networks.

In Sloan's method, the priority function is a linear function of two graph parameters as in Eq. (14.6), and the coefficients specify the importance of each parameter. Following experimentations, Sloan's recommends the pair (W1 = 1 and W2 = 2) for the coefficients. However, the results of other researcher [6] indicate that, for some problems there are considerable advantages in using other values.

### 14.5.1 A Priority Function Using Ritz Vectors

The priority function in Sloan's method is generalized by considering additional vectors known as vectors of the graph parameters.

```
$\overline{\phi} = \sum_{i=1}^{p} w_i v_i, \qquad \text{(14.8)}$
```

where $\overline{\phi}$ is the priority function, v$_i$ (i = 1, ..., p) are the normalized Ritz vectors representing the graph parameters, and w$_i$ (i = 1, ..., p) are the coefficients of the Ritz vectors (Ritz coordinates) which are unknowns, and p is the number of parameters being employed. In this chapter we set p = 5 and v$_1$-v$_5$ vectors are selected as:

- v$_1$ contains the degrees of the nodes,
- v$_2$ comprises of the 1-weighted degrees of the nodes, and
- v$_3$ and v$_4$ are distances of the nodes from two pseudo-peripheral nodes, and
- v$_5$ contains the 2-weighted degrees of the nodes of the graph.

The k-weighted degree of a node n$_i$, is defined as the sum of the degrees of all nodes in a distance k from n$_i$. Here k = 1 and 2 are used, however, higher values of k may also be included.
