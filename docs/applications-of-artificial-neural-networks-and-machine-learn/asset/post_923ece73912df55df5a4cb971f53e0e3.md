Apart from the above formulation, one can optimize a structure with a different approach, without the need for the formation of U, and utilizing only Uc. As we observed before, Uc can be written in the form of Eq. (15.12), and in analysis the objective is its minimization. Differentiating this equation leads to the following relationship before obtaining Eq. (15.13).

\(\frac{\partial U^c}{\partial q} = 0 \Rightarrow [[\mathbf{H}_{qp}]]\{\mathbf{p}\} + [[\mathbf{H}_{qq}]]\{\mathbf{q}\} = \{0\}\)

Therefore q should be selected such that the Eq. (15.19) holds (as a replacement to the selection of q such that it minimizes Eq. (15.15)). However, the right-hand side of Eq. (15.19) is a zero vector and should be changed to scalar. The best is to calculate the norm as the square root of the squared sum of its entries. If this norm becomes zero, then all the entries should be zero. In the previous method the scalar value presented the complementary energy, for becoming zero we had to combined it with energy U. Here, if the aim is the optimization of cross sections {A} and geometry {D}, then we can write:

\(F(q, A, D) = W(A, D)(1 + \alpha \text{norm}([[\mathbf{H}_{qp}]]\{\mathbf{p}\} + [[\mathbf{H}_{qq}]]\{\mathbf{q}\})\)

where {q}, {A} and {D} are the input data. It is sufficient the number of variables to be equal to the degree of statistical indeterminacy of the structure, because the remaining forces can be obtained considering the geometry and topology of each chromosome as given in Eq. (15.9). The submatrices [[H_qp] and [[H_qq] are functions of the selected cross sections, geometry and topology. Having these two, F can be obtained from Eq. (15.20), and its minimum value for a big \(\alpha\) means corresponds to minimization of the weight W. If the structure contains other constraints, it is sufficient to normalize these constraints and then with the help of a penalty coefficient to add to the above equation. Thus the final formulation is obtained as

Find q, A, D; \(A \in \{S_d \text{ or } S_c\}\)
Min \(F(q, A, D) = W(A, D)(1 + \alpha[\text{norm}([[\mathbf{H}_{qp}]]\{\mathbf{p}\} + [[\mathbf{H}_{qq}]]\{\mathbf{q}\})\)
\(+ \sum_{m=1}^{nc} \max[0, g_m(q, A, D)])\)

In this relationship, \(S_d\) and \(S_c\) are the discrete and/or continuous sections, respectively. \(g_m(q, A, D)\) represents the magnitude of the constraint violation and nc is the number of constraints consisting of the stress constraints, displacement constraints and buckling constraints. The main advantage of this formulation is that the term corresponding to the analyst is included in the objective function. Therefore in the process of optimization there is no need to perform analysis for each chromosome of each generation. The speed of using this approach is very high. Examples 1 and 2 will illustrate the application of this approach for optimization of two towers with lower number of elements.

In the second method, where the aim is to optimize the cross sections, the cross section of elements are put into different types and if the aim is the optimization of cross section and geometry, then these two variables are the unknowns of the problem. In this way the number of variables of the problem will become less the previous case. Then an analyst is used for the analysis of the members of each generation. This process is highly time-consuming, because as the problem becomes bigger, the number of members of each generation increases, and the speed of performing the analysis of each structure decreases considerably. The speed of optimization becomes very low and sometimes it does not converge. Here, for the first few generations, analyzer is used and then the cross sectional areas of the members are taken as the input and the member forces and nodal displacements (in a structure a limited number of nodes may be considered for this purpose) are selected as the output of the network. After training the network, the analysis is performed by the neural network. In doing so one may face difficulties as follows.

First of all it is obvious that the networks make only good approximations. In the other hand, at the final stages of the genetic algorithm the results of a generation has small difference with those of the subsequent generation. Therefore, using network at these stages as analyzer may lead to non-realistic results. In the process of the solution of the examples of this paper, this difficulty was present. In order to solve this problem the generations are divided into 3 groups. For the first and third groups exact analyses are employed and for the second group neural network is utilized. For this purpose the genetic algorithm uses the exact analysis and calculates the forces and displacements considering the size and the number of entries of the problem. After enough input is prepared all the cross sections of the structure are considered as the input data of the network. The output consists of member forces and displacements. Training of such a network should not require much computational time, otherwise the use of network will not be economical.

From different neural networks RBF is more suitable than the others. One of the main features of this network is its capability in recognizing the pattern in a very short time and it works better than MLFF. Since this network performs as a fuzzy interpreter, therefore in our problem it works better than the other networks.

A network based on radial basis functions contains one input layer, one hidden layer containing non-linear processors and a bias, together with an output layer of linear weights. Using the calculated output of the hidden layer, in response to an input vector and utilizing a suitable output response, the weights are evaluated. The non-linear functions in the hidden layer of these networks (basis functions) are normally selected from Gaussian shapes, and the corresponding parameters consist of the center and the width of the function. One can simply say that each neuron of the hidden layer will have output greater than unity when the input vector of the network gets closer to the centre of the non-linear functions of the neuron. By increasing the distance of the input vector from the centre of non-linear functions, the output of the neuron decreases.

As another neural network similar to RBF one can refer to Generalized Regression Neural Network (GRNN). The structure of this network is similar to that of RBF and the only difference is the structure of the second layer which is slightly different. Here the output of the network is in the form of a linear combination of the internal product of the output of the network and the output of the second layer, which is ultimately normalized. It is obvious that in this case the sensitivity of the output with respect to the outputs of the training will be increased. In other words, the net in converging to a specified output will have direct effect. Such a network will be able to select the set of training inputs close to a particular input, and then considering the distance of each input from the given input to calculate the corresponding output. This distance is normally selected as the Euclidian distance.

The above output can be viewed as a combination of some outputs corresponding to the training inputs close to the considered input. This property makes the network capable of solving problems with many input and output neurons, when the number of training pairs is limited. This case has occurred in this study.

From now on for each generation the genetic algorithm uses the network for calculating the forces and displacements. The algorithm employed here is in a substructuring form and is known as the migration genetic algorithm, Deme Ga [9, 10].

In the literature, the use of multiple populations has been shown in most cases, to improve the quality of the results obtained using this method compared to the single population GA [9, 10].

The chromosome data structure, composed of subpopulations each of length N individuals. This is known as the *migration*. Each subpopulation is evolved over generations by a traditional GA and from time to time individuals migrate from one subpopulation to another. The amount of migration of individuals and the pattern of that migration determines how much genetic diversity can occur.

A number of high-level entry functions are provided that accept an optional argument that determines the number of subpopulations contained in a data structure. The low-level routines are then called independently, in turn, with each subpopulation to perform functions such as selection, crossover and reinsertion.

The transfer of individuals between subpopulations is implemented. A single scalar is used to determine the amount of migration of individuals from one subpopulation to another. Thus, given a population comprised of a number of subpopulations, the same number of individuals will always be transferred from a subpopulation as the number it will receive from another subpopulation.
