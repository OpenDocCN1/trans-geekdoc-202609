The value of \( r \) always is between -1 and 1. If \( r = 1 \), correlation is perfect and if \( r = -1 \), correlation is perfect and negative, and if \( r = 0 \), the variables are uncorrelated. Also in ANN, the correlation factor between the actual and desired outputs from training and testing sets together can be used as a criterion for evaluating performance and learning of the network. Closer the value of this factor to 1 for both data existing in training and testing set, better the learning and performance of the network. It is notable that correlation factor between the actual and desired outputs from training set, can never be used for the evaluation of the performance of a network, because may be the network would recited existent data in the training set and the correlation factor between actual and desired output is close to 1 but the network cannot present acceptable answers to new inputs (inputs where doesn’t exist in testing set).

# 11.3.2 Data Classification for Training and Testing of ANNs

The data are divided into 3 groups for training and testing of the ANNs as follows:

+   - Group A: Network for assessment of damage in 3, 4, and 5 stories structures
+   - Group B: Network for assessment of damage in 6–10 stories structures
+   - Group C: Network for assessment of damage in 3–10 stories structures.

# 11.3.3 Training of the ANNs for Predicting the Vulnerability of the Structures

In order to train the AANs, the “Neural Works” program has been employed [17]. In all the networks, the training set includes seven parameters which are: the ratio of number of stories to number of bays of structure, period of first vibration mode of structure in terms of second, peak ground acceleration (p.g.a.) in terms of ground gravity acceleration (g), earthquake main frequency (Hz), scaled earthquake acceleration, maximum displacement of top of the structure, and Park and Ang damage index, respectively. Testing set includes six parameters which are as the same as the above-mentioned parameters except the damage index.

In order to train the networks, back propagation algorithm is used. Architecture of the networks consists of one input layer, one (or two) hidden layer(s), and one output layer. Both Hyperbolic Tangent and Sigmoid functions are employed in training the networks and their performances are compared.
