# 1.6.8 Auto Encoder Neural Network

Auto Encoder (AE) neural networks are used for classification, clustering and feature compression. When a feedforward neural network is trained for classification, it must be fed X samples in Y category and expect one of the Y cells to be activated. This is called Supervised Learning. On the other hand, Auto Encoder neural networks can be trained without supervision. Due to the structure of these networks (where the number of hidden layers is smaller than the number of input cells and the number of output cells is equal to the input cells) and that AE is somehow Trained to make the output as close to the input as possible, the Auto Encoder neural network is forced to generalize the data and look for common patterns.
