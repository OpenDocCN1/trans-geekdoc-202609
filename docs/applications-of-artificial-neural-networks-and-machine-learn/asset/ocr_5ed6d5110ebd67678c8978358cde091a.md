# ## 1.6.23 Echo State Network

Echo State Network or ESN is a type of recurrent neural network model that is used as a random and open model for long-term data processing. This model was first introduced by Herbert Jagger in 2001.

An important feature of ESN is that the weights between hidden and output layers are determined randomly, while the weights between input and hidden layers are fixed by default. These random weights have a significant impact on the execution of calculations and ESN has the ability to learn complex models. With this feature, ESN is widely used for signal prediction problems, system dynamics modeling, temporal data analysis, and artificial intelligence model development in various fields. Other advantages of ESN include simplicity of implementation, parallel processing power and flexibility of modeling models. Echo State Network shown in Fig. 1.49.
