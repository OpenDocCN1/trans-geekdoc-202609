# 1.4 Activation Functions

Activation functions are used in neural networks to nonlinearize the information that is passed from one layer to the next. These functions help the model express more complex patterns. Since activation functions determine whether a node should be active or inactive, they are very important in neural networks. The main role of the activation function in neural networks is to produce an output value using the inputs of a node. In other words, these functions decide whether a node's input is important or not by performing simple mathematical calculations. Activation functions map the sum value of a node’s weighted input to values from 0 to 1 or –1 to 1 (depending on the type of activation function). Then, these functions pass their final output to the next layer. For this reason, these functions are also known as transfer functions. Activator functions are divided into three general categories. Binary Step Function, Linear Activation Function, Non-linear Activation Function [12].

# 1.4.1 Binary Step Function

The binary step function is one of the simplest activation functions that divides the input into two classes or two different states based on its value. This function returns only two values 0 and 1 and states whether the input should be enabled (1) or disabled (0). Binary Step Function is shown in Fig. 1.4.

The mathematical function of this activator is as follows:

```
\( f(x) = \begin{cases} 0 & \text{for } x < 0 \\ 1 & \text{for } x \ge 0 \end{cases} \quad (1.1) \)
```

Some of the problems of this method can be mentioned such as: This function is not efficient for use in deep neural networks due to the lack of continuous gradients and derivatives in the suspended points. Also, the fixed value of the output (0 or 1) can limit the flexibility and learning power of the model. It also has problems such as gradient fading, dead neurons, and increasing training time due to lack of flexibility and high detail in information transfer.
