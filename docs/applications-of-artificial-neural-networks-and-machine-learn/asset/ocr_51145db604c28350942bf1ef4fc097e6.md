# 1.5.3 Rectifier Linear Unit Activation Function (ReLU)

ReLU nonlinear activation function is one of the most common activation functions in deep learning. The name of this function stands for “Rectified Linear Unit”. Although this function looks like a linear function, this function is derivable and can be used in the backward propagation step. This function does not activate all nodes at the same time. In other words, the nodes are inactive when the input value of this function is less than zero. In other words, according to the graph of this function, if the input of the function is greater than zero, the output of the function is equal to the input of the function, and if the input of the function is less than zero, the output of the function is equal to zero. The ReLU function and its derivative are uniform. Due to the linearity and non-saturating feature of the function, the convergence of Gradient Descent algorithm happens faster. Thus, the model needs less time to learn. Since this function only activates a number of nodes, it is computationally more efficient than other activation functions in neural networks. Compared to the sigmoid and Tanh functions, this function is a simpler function and therefore easier mathematical calculations are performed during network learning. The ReLU function does not have the problem of vanishing the gradient of the sigmoid and Tanh functions; because the positive linear range of this function allows the gradients to flow in the active path of the nodes. Also, this function does not set a limit for the maximum input value. An important limitation that the ReLU function faces is the dying problem of the ReLU function.
