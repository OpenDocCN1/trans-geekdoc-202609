# 1. 开发环境

本章介绍 Go 的入门。Go 的官方网站可在 [https://golang.org/](https://golang.org/) 找到。什么是 Go？根据网站上的信息，我们可以知道它是什么。Go 是一种开源编程语言，使构建简单、可靠且高效的软件变得容易。

## 1.1 安装

Go 应用的安装很简单。对于 Windows 和 Mac 平台，你可以从 Go 网站 [http://golang.org/doc/install](http://golang.org/doc/install) 下载安装文件。运行它并按照安装说明进行操作。

![mac1](Images/mac1.png)

下一步是配置 `GOROOT` 路径。对于 Windows 平台，你可以在 **环境变量** 中添加 `GOROOT` 变量。对于 Mac/Linux，你可以在 bash 配置文件中添加它。

![ch1-2](Images/ch1-2.png)

对于 Windows 平台，你可以将 GO 安装路径，例如我的 Go 安装路径是 `c:/go/bin`，添加到 **环境变量** 中的 `PATH` 变量。

![ch1-3](Images/ch1-3.png)

配置完成后，你可以通过在终端或 Windows 的 CMD 中输入以下命令来验证 Go 版本。

```
$ go version
```
