        }
    }

## 13.2 哈希

基本上，你可以通过 [http://golang.org/pkg/crypto/](http://golang.org/pkg/crypto/) 探索如何使用 Go 实现哈希或哈希函数。在本节中，我们将探索几种哈希算法，例如 MD5、SHA256 和 HMAC。

### 13.2.1 使用 MD5 进行哈希

我们可以使用 `md5` 包使用 MD5，[http://golang.org/pkg/crypto/md5/](http://golang.org/pkg/crypto/md5/)。要从文本计算哈希值，我们可以调用 `Sum()` 函数。

为了说明，我们创建一个函数 `demoHash_md5()`，并编写此代码。

```
func demoHash_md5() {

    fmt.Println("--------Demo encoding hash using md5--------")

    message := "Hello world, go!"
    fmt.Println("plaintext:")
    fmt.Println(message)

    h := md5.New()
    h.Write([]byte(message))
    hash_message := hex.EncodeToString(h.Sum(nil))
    fmt.Println("hashing message:")
    fmt.Println(hash_message)

}
```

### 13.2.2 使用 SHA256 进行哈希

第二个演示是使用 SHA256 实现哈希函数。Go 提供了 `sha256` 包，[http://golang.org/pkg/crypto/sha256/](http://golang.org/pkg/crypto/sha256/)，用于使用 SHA256 实现哈希函数。

为了说明，我们创建一个函数 `demoHash_sha256()`，并编写此代码。

```
func demoHash_sha256() {

```

### 13.2.3 使用密钥进行哈希，使用 HMAC

带密钥的哈希消息认证码（`HMAC`）是一种用于计算消息认证码（`MAC`）的特定构造，涉及密码学哈希函数与秘密密码学密钥的组合，[http://en.wikipedia.org/wiki/Hash-based_message_authentication_code](http://en.wikipedia.org/wiki/Hash-based_message_authentication_code)。在 Go 中，我们可以使用 `hmac` 包，[http://golang.org/pkg/crypto/hmac/](http://golang.org/pkg/crypto/hmac/)，来实现 HMAC 算法。

为了说明，我们创建一个函数 `demoHashKey()`，并编写此代码。

```
func demoHashKey(key,message string) {

    fmt.Println("--------Demo encoding hash with key: HMAC and sha256--------")

    fmt.Println("key:")
    fmt.Println(key)
    fmt.Println("plaintext:")
    fmt.Println(message)

    hmacKey := []byte(key)
    h := hmac.New(sha256.New, hmacKey)
    h.Write([]byte(message))
    hash_message := hex.EncodeToString(h.Sum(nil))
    fmt.Println("hashing message:")
    fmt.Println(hash_message)

}
```

## 13.3 密码学

在本节中，我们关注对称和非对称密码学。在对称密码学中，我们使用相同的密钥进行加密和解密。否则，非对称密码学使用不同的密钥进行加密和解密。

我们在下一节中探索这些。

### 13.3.1 对称密码学

有许多算法可以实现对称密码学。在本节中，我们使用 AES 算法。高级加密标准（`AES`）是由美国国家标准与技术研究院（`NIST`）于 2001 年制定的电子数据加密规范，[http://en.wikipedia.org/wiki/Advanced_Encryption_Standard](http://en.wikipedia.org/wiki/Advanced_Encryption_Standard)。

为了说明，我们创建两个函数 `encrypt_symmetric_crpyto()` 和 `decrypt_symmetric_crpyto()`。以下是 `encrypt_symmetric_crpyto()` 的实现。
