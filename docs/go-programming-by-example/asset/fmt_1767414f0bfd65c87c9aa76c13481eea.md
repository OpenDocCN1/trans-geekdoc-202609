This chapter explains introduction of Go. The official web of Go could be found on [https://golang.org/](https://golang.org/). What is Go? Based on information from website, we could know what it is. Go is an open source programming language that makes it easy to build simple, reliable, and efficient software.

## 1.1 Installation

Installation of Go application is easy. For Windows and Mac Platform, you download setup file from Go website, [http://golang.org/doc/install](http://golang.org/doc/install). Run it and follow installation commands.

![mac1](Images/mac1.png)

The next step is to configure `GOROOT` path. For Windows platform, you can add `GOROOT` variable on **Environment Variables**. For Mac/Linux, you can it on your bash profile.

![ch1-2](Images/ch1-2.png)

For Windows platform, you can add GO installation path, for instance my Go installation path is `c:/go/bin`, into `PATH` variable on **Environment Variables**.

![ch1-3](Images/ch1-3.png)

After configured, you can verify Go version by typing this command on your Terminal or CMD for Windows.

```
$ go version
```
