# More with ndarrays

We can reverse a ndarray using `array[::-1]` syntax

```python
In [56]: import numpy as np
ar = np.array([1, 2, 3, 4])
ar
Out[56]: array([1, 2, 3, 4])
In [55]: ar = ar[::-1]
ar
Out[55]: array([4, 3, 2, 1])
```

We can broadcast a whole ndarray without doing it the long way

```python
In [56]: import numpy as np
ar = np.array([1, 2, 3, 4])
ar
Out[56]: array([1, 2, 3, 4])
In [62]: # the long way - ar + [1,1,1,1]
ar = ar + 1
ar
Out[62]: array([2, 3, 4, 5])
```

We can sort an array with the sort function

```python
In [63]: import numpy as np
ar = np.array([5,1,3,9])
ar
Out[63]: array([5, 1, 3, 9])
In [64]: ar.sort()
ar
Out[64]: array([1, 3, 5, 9])
```

# Data Cleansing

Let’s consider a situation like below

```python
In [71]: import pandas as pd
import numpy as np
ar = np.array([[1,2,3],[6,7,2],[4,9,1]])
df = pd.DataFrame(data = ar, index = ['a','c','e'], columns = ['C1','C2','C3'])

Out[71]:
      C1  C2  C3
a     4   7   2
c     9   1
In [72]: df = df.reindex(['a','b','c','e'])
df
```

| | C1 | C2 | C3 |
|---|---|---|---|
| a | 1.0 | 2.0 | 3.0 |
| b | NaN | NaN | NaN |
| c | 4.0 | 7.0 | 2.0 |
| d | NaN | NaN | NaN |
| e | 4.0 | 9.0 | 1.0 |

The reindexed DataFrame has NaN values in b rows. This happened, there is no data for b rows. Using reindexing, we have created a DataFrame with missing values. In the output, NaN means Not a Number. To detecting missing values easier (across different dtypes), Pandas provides `isnull()` and `isna()` functions which are also methods on Series and DataFrame objects

```python
In [73]: df['C1'].isnull()

Out[73]:
a    False
b     True
c    False
d     True
e    False
Name: C1, dtype: bool
```

Pandas provides various methods for cleaning the missing values. `fillna` can fill NaN values with non-null data in a couple of ways like replacing values with 0

```python
In [74]: df.fillna(0)
Out[74]:
      C1  C2  C3
a  1.0 2.0 3.0
b  0.0 0.0 0.0
c  4.0 7.0 2.0
d  0.0 0.0 0.0
e  4.0 9.0 1.0
```

We can copy the value above or below that data using `pad` or `bfill` in parameter of `fillna`

```python
In [75]: df.fillna(method='pad')
Out[75]:
      C1  C2  C3
a  1.0 2.0 3.0
b  1.0 2.0 3.0
c  4.0 7.0 2.0
d  4.0 7.0 2.0
e  4.0 9.0 1.0
```

We can drop the rows with missing values with `dropna`

```python
In [76]: df.dropna()
Out[76]:
      C1  C2  C3
a  1.0 2.0 3.0
c  4.0 7.0 2.0
e  4.0 9.0 1.0
```
