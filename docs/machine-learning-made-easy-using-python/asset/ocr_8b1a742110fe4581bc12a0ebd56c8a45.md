# Clustering

The findings are the different types of clustering:

+   * Density-based, clusters are formed as dense regions. These algorithms have good accuracy and capability to merge two clusters together. Like, Density-Based Spatial Clustering of Applications with Noise (DBSAN), Ordering Points to identify Clustering structure (OPTICS)
* Heirarchical-based, clusters are formed in a hierarchical tree which has Agglomerative (Bottom up approach) and Divisive (Top down approach). Like Clustering using Representatives (CURE), Balanced iterative Reducing Clustering using Hierarchies (BIRCH)
* Partitioning, clusters are formed by partitioning the objects into k, number of clusters will be equal to that of partitions. Like K-Means
* Grid, clusters are formed as grid. This method is fast and independent on the number of objects. Like Statistical Information Grid (STING), Clustering in Quest (CLIQUE)
