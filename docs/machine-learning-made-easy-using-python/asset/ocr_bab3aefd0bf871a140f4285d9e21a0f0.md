# Key Points

+   - Pandas library is a high performance data manipulation and data analysing tool.
- Pandas data structures include series and data frames
- Series is a 1-Dimensional array of homogeneous data, whose size is immutable but values in a series are mutable.
- Data Frames is a 2-Dimensional array of heterogeneous data of 2 or more series, whose size and data are mutable.
