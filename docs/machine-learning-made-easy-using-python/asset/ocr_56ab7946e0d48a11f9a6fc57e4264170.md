So how did the MeanShift algorithm found the clusters even though we didn’t specified the number of clusters beforehand?

Firstof all it starts with the data points assigned to a cluster of their own. Then the algorithm will compute the centroids and change the location of new centroids.

This process will be iterated and moved to the higher density region until the centroids reach at position from where it cannot move further.
