Another univariate plot called box and whiskers plot can be used too. We can specify box in the kind parameter of plot() function this time

```
In [9]:   import pandas
dt = pandas.read_csv('trees.csv')
delt dt['Index']
dt.plot(kind='box',subplots=True)
```
