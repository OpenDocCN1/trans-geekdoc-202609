We need the data to plot the SVM boundaries or input data spaces(different classes). To do so we need to create a grid as we did before. To plot the grid we need minimum and maximum values of the input and output datasets. Then we reshape them using ravel() and pass them to the c_() function which nn particular stacks arrays along their last axis after being upgraded to at 2-D and stored in the X_plot as testing input

```
In [3]: x_min, x_max = X[:], 0].min() - 1, X[:], 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
h = (x_max / x_min)/100
xx, yy = numpy.meshgrid(numpy.arange(x_min, x_max, h), 
numpy.arange(y_min, y_max, h))
X_plot = numpy.c[xx.ravel(), yy.ravel()]
```
