$J(\theta) = \frac{1}{m} (-y^T\log(h) - (1-y)^T\log(1-h))$

after defining the loss function our prime goal is to minimize the loss function

+   - It can be done with the help of fitting the weights which means by increasing or decreasing the weights. With the help of derivatives of the loss function with respect to each weight, we would be able to know what parameters should have high weight and what should have smaller weight. The following gradient descent equation tells us how loss would change if we modified the parameters:

```
$\frac{\delta J(\theta)}{\delta\theta} = \frac{1}{m}X^T(g(\theta)-y)$
```
