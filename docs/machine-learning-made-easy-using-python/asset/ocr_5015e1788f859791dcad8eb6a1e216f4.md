# Data Collection

Data is collected from many sources. Let’s say we want data of the whole country. So we need to survey the whole population whihc is time consuming or we can select a sample of the population and survey it’s data. The sample can be selected randomly, on the basis characters or other features.
Likewise instead of feeding the a whole data set to model we can obtain a sample from it to save time and have better results.
