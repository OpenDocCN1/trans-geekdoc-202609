# Binarization

In binarization we binarize our data reduce differences to only two to leave crisp wales with threshold. For example if we set the threshold to 10, all the value in a data set under 10 will be converted to 0 and above 10 will be converted into 1. Let's binarize our data with Binarizer class and transform() method

```
In [21]: import pandas
from sklearn import preprocessing
dt = pandas.read_csv('trees.csv')
ar = dt.values
Nm = preprocessing.Normalizer(norm='11')
m_ar = Nm.transform(ar)
```
