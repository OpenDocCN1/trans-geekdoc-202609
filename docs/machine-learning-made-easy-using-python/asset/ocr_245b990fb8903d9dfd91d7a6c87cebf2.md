# Key Points

+   - MatPlotLib is a library used for visualizing our data using it’s MATLAB functions
- MatPlotLib’s PyPlot module makes it easier to plot data, with full control over color, line & shape, font, axis-labels, etc.
- It supports wide range of graphs and plots like, histogram, bar graphs, pie charts, and even 3-D graphs.
- MatPlotLib is the best library for data visualization
