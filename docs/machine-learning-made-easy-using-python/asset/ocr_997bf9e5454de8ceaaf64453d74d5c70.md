If we want to change a single value in a Data Frame,we can use the replace function

```
In [78]: import pandas as pan
import numpy as npy
ar = np.array([[1,2,3],[4,7,2],[4,9,1]])
df = pan.DataFrame(data = ar, index = ['a','c','e']
                    columns = ['C1','C2','C3'])

df.replace({3:13}))

Out[78]:
  C1 C2 C3
a 1  2 13
c 4  7  2
e 4  9  1
```
