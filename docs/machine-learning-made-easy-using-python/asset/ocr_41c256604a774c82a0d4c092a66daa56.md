Our data has 200 rows and 5 columns. As you can see the Male and Female are not numeric values which is fine, but it is best time to practise our preprocessing skills. We will encode them into numeric values. If you don't remember how to do so, go back to the Data analysis and processing lesson

```
In [2]: import pandas
from sklearn import linear_model, metrics
from sklearn.model_selection import train_test_split
from matplotlib import pyplot
from sklearn import preprocessing
dt = pandas.read_csv('Mall_Customers.csv')
Enc = preprocessing.LabelEncoder()
Enc.fit(['Male', 'Female'])
dt['Genre'] = Enc.transform(dt['Genre'])
dt.head()
```
