Mathematically the relation can be expressed as:

Y = mX + b

where, Y is the dependent(side), X is the dependent variable(area) we are using to make predictions, m is the slope of the regression line which represents the effect X has on Y and b is a constant, known as the Y-intercept. If X = 0,Y would be equal to b

The relationship can be either positive or negative
