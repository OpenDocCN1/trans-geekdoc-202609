+   Variability or Spread

Range, interquartile range, variance and standard deviation are referred to variability or measurement of spread

![](bbox=[0.137, 0.215, 0.863, 0.00366])

Range is the difference between the maximum and minimum value in a data. Like the range of the sales data is

| Sales |
| 14 |
| 29 |
| 33 |
| 37 |

```
range = max - min
= 37 - 14
= 23
```

Interquartile Range is similar to the range but a bit different. Let's consider teh following data

12 27 33 35 42 45 47 51 53 54

We will divide the data into quarters with the numbers as separators

12 27 33 35 42 45 47 51 53 54

And subtract the third seperator from the first seprator i.e. interquartile range

```
Interquartile range = 3rd Seperator - 1st Seperator
= 51 - 33
= 18
```
