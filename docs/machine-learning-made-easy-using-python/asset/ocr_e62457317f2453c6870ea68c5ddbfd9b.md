# Standardization

Standardization or Standard scaling is the method of changing the distribution of data arttributes to Gaussian distribution (Normal distribution). In this mthe mean is changes to 0 and standard devia is changed to 1. Let's standardize our data using the StandardScaler class and it's fit() and transform() methods

```
In [14]: import pandas
import numpy
from sklearn import preprocessing
dt = pandas.read_csv('trees.csv')
ar = dt.values
# Standardizer
Std = preprocessing.StandardScaler().fit(ar)
std_ar = Std.transform(ar)
print(std_ar[0:3])
```

```
print('Mean:', round(numpy.mean(std_ar),2))
print('Std.Deviation:', round(numpy.std(std_ar),2))
```
