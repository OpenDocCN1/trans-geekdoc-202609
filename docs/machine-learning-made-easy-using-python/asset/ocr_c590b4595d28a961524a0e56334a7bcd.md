So far we have created a lot of models with different algorithms for different tasks like regression, classification, etc. and also evaluated their performance visually through graphs or their accuracy score. In this lesson we will look at the methods to calculate the performance of algorithms

# Calculating the model

In the maths for machine learning lesson we learned some methods to calculate error rate, Precision, Recall and F-measure (page no. 71) using confusion matrix. All these values can be used to evaluate the performance of a classifier. Let's use the KNN classifier model we created previously and calculate it's performance First off all let's print the confusion matrix using confusion_matrix() function

```
In [8]: from sklearn import metrics
cm = metrics.confusion_matrix(tst_y,pred_y)
cm
```

```
Out[8]: array([[657, 62],
[ 80, 1201]], dtype=int64)
```

We passed the actual values followed by predicted values. We can visualize it better

```
In [11]: from sklearn import metrics
cm = metrics.confusion_matrix(tst_y,pred_y)
cf = pandas.DataFrame({'True +ve':cm[:,0],
'True -ve':cm[:,1]},
index=['Predicted +ve',
'Predicted -ve'])
```

```
Out[11]:
True +ve True -ve
Predicted +ve 657 62
```
