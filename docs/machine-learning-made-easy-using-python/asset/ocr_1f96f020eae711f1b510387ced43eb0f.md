So how did our model predicted teh values or how do the logistic regression works? To understand we will see what is the mathematics behind the algorithm, if you want you can move ahead or give it read. The followings are the steps of linear function of binomial logistics regression:

+   - We already know that the output will be either Θ(No) or 1(Yes). For that the linear function is basically used as an input to another function such as g in the following relation

```
$h_\theta(x) = g(\theta^T x) \ [0 \leqslant h_\theta \leqslant 1]$
```

g is the logistic or sigmoid function which can be found with the following formula:

```
$g(z) = \frac{1}{1+e^{-z}}$
```

where $z$ is $\theta^T x$
