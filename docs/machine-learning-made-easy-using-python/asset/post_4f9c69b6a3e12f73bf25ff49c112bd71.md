# SciPy sub-packages

As we already know, SciPy is organized into sub-packages covering different scientific computing domains, we can import them according to our needs rather than importing the whole library. The following table shows the list of all the sub-packages of SciPy :

| | |
|---|---|
| scipy.constants | Mathematical constants |
| scipy.fftpack | Fourier transform |
| scipy.integrate | Integrate routines |
| scipy.interpolate | Interpolation |
| scipy.io | Data input and output |
| scipy.linalg | Linear algebra routines |
| scipy.optimize | Optimization |
| scipy.signal | Signal processing |
| scipy.sparse | Sparse matrices |
| scipy.spatial | Spatial data structures |
| scipy.special | Special mathematics |
| scipy.stats | Statistics |

- SciPy is divided into sub-packages determined for different tasks.

# Matplotlib

Matplotlib is a python library used to create 2D graphs and plots by using scripts. It has a module named pyplot which makes things easy for plotting by providing feature to control line styles, font properties, formatting etc.

![](img/d75fea3635f5553f1cb0585b399b1b4b_41_0.png)

# Key features of Matplotlib

Matplotlib is the best choice for data visualization because of its features like:
- It supports a wide variety of graphs and plots namely histogram, bar charts, error charts, and many more.
- It is used along with NumPy to provide an environment that is effective alternative for MATLAB.
- Using its PyPlot module, plotting simple graphs or any other charts is easy.

# Data Visualization

Data visualization is the graphical representation of information and data. By using elements like charts, graphs, and maps, visualization tools provide an accessible way to see and understand trends, outliers, and patterns in data.

![](img/d75fea3635f5553f1cb0585b399b1b4b_42_0.png)

In the world of Big Data, data visualization tools and technologies are essential to analyze massive amounts of information and make data-driven decisions. Visualization helps view data in a graphical or more interesting way than viewing a big chunk of numbers in a uniform line. We will process and then visualize our data, if we don’t visualize data, it loses a lot of impact as it will in the form bar graphs, pie charts, etc.

# PyPlot in Matplotlib

matplotlib.pyplot is a collection of functions that make matplotlib work like MATLAB. Each pyplot function makes some change to a figure: creates a figure, plots some lines, decorates the plot with labels, etc. To test it yourself, jump to Jupyter Notebook and start importing the matplotlib.pyplot module.

```python
import matplotlib.pyplot as plt
```

To plot a simple graph, use the plot function and pass a list, then use the show function to view the graph.

```python
import matplotlib.pyplot as mplt
mplt.plot([1,3,6,9])
mplt.show()
```

![](img/d75fea3635f5553f1cb0585b399b1b4b_43_0.png)

We have successfully plotted our graph with some random values in a list. If we want we name x and y axis using the xlabel and ylabel respectively.

```python
import matplotlib.pyplot as plt
plt.plot([1,3,6,9])
plt.xlabel('X_Axis')
plt.ylabel('Y_Axis')
plt.show()
```

![](img/d75fea3635f5553f1cb0585b399b1b4b_44_0.png)

The graph has solid blue line, we change its color and the line style by passing another argument to the plot function like 'ro' for 'r' red and 'o' circles.

```python
import matplotlib.pyplot as plt
plt.plot([1,3,6,9], 'ro')
plt.xlabel('X_Axis')
plt.ylabel('Y_Axis')
plt.show()
```

![](img/d75fea3635f5553f1cb0585b399b1b4b_44_1.png)

# Scikit Learn or Sklearn

Scikit-learn or Sklearn is the most useful and robust library for machine learning in Python. It provides a selection of efficient tools for machine learning and statistical modeling including classification, regression, clustering and dimensionality reduction. This library, which is largely written in Python, is built upon NumPy, SciPy and Matplotlib.

# Features of Scikit Learn

- Supervised learning algorithms, like Linear Regression, Support Vector Machine (SVM), Decision Tree etc. are the part of scikit-learn.
- Unsupervised learning algorithms like clustering, factor analysis, PCA (Principal Component Analysis) to unsupervised neural networks are part of it too.
