We can add columns to the DataFrame using the <DataFrame>[<column_name>] = <values> syntax

```
In [44]: import pandas
import numpy
ar = numpy.array([[1,3],[6,2]])

df = pandas.DataFrame(data = ar,
                   index = ['A','B'],
                   columns = ['C1','C2'])
df['C3'] = (df['C1']*5)
print(df)

   C1 C2  C3
A  1  3   5
B  6  2  30
```

We can delete columns from the DataFrame using the del function

```
In [45]: import pandas
import numpy
ar = numpy.array([[1,3],[6,2]])

df = pandas.DataFrame(data = ar,
                   index = ['A','B'],
                   columns = ['C1','C2'])
df['C3'] = (df['C1']*5)
del df['C2']
print(df)

   C1 C3
A  1  5
B  6  30
```

