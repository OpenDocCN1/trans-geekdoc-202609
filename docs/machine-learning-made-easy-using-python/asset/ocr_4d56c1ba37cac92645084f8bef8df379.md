# Data Cleansing

Let’s consider a situation like below

```
In [71]: import pandas as pan
import numpy as np
ar = np.array([[1,2,3],[6,7,2],[4,9,1]])
df = pan.DataFrame(data = ar, index = ['a','c','e'],
                    columns = ['C1','C2','C3'])

Out[71]:
      C1  C2  C3
a     4   7   2
c     9   1

In [72]: df = df.reindex(['a','b','c','d','e'])
df
```

| | C1 | C2 | C3 |
|---|---|---|---|n| a | 1.0 | 2.0 | 3.0 |
| b | NaN | NaN | NaN |
| c | 4.0 | 7.0 | 2.0 |
| d | NaN | NaN | NaN |
| e | 4.0 | 9.0 | 1.0 |

The reindexed Data Frame has NaN values in the b and
drows. This happened, there is no data for b
d rows. Using reindexing, we have created a Data-
Frame with missing values. In the output, NaN means
Not a Number. To make detecting missing values easier
(and across different array dtypes), Pandas provides
isnull() andisnull() functions, which are also
methods on Series and DataFrame objects

```
In [73]: df['C1'].isnull()

Out[73]:
      a
a  False
b    True
c  False
d    True
e  False
Name: C1, dtype: bool
```
