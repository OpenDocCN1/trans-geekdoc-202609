# Deep learning

Deep learning models are based on Artificial Neural Networks (ANN), or more specifically Convolutional Neural Networks (CNN)s. There are several architectures used in deep learning such as deep neural networks, deep belief networks, recurrent neural networks, and convolutional neural networks.

+   These models are used to solve problems like:
- computer vision, image classification, etc.
- bioinformatics
- drug design
- games, etc.
