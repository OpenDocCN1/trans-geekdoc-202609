# Scikit Learn or Sklearn

Scikit-learn or Sklearn is the most useful and robust library for machine learning in Python. It provides a selection of efficient tools for machine learning and statistical modeling including classification, regression, clustering and dimensionality reduction via a consistence in Python. This library, which is largely written in Python, is built upon NumPy, SciPy and Matplotlib.
