# # Importing JSON Data

JSON file stores data as text in human-readable format. JSON stands for JavaScript Object Notation. Get your sample JSON data here `json_data` (Check the Resources)
Pandas can read JSON files using the `read_json` function.

```
In [2]: `import pandas as pan`
dt = pan.read_json("json_data.json")
dt

| | ID | Name | Price | Sales | Brand |

| 4 | 105 | Protein Bars | 4.90 | 85 | MuscleUp |

```

Similar to the CSV files, we can perform all the slicing and data extraction with JSON data files

```
In [6]: `import pandas as pan`
dt = pan.read_json("json_data.json")
print(dt.loc[:["ID", "Name", "Sales\]])
print(dt.values([5,4]))
```
