# Types of supervised learning

Regression and classification are two types of supervised machine learning. They can be understood as:

+   - Regression is the type of machine learning in which we feed the model with data like 'A' (input, i.e. X) has value of 65 (output, i.e. Y), 'B' has value of 66, etc. Based on the given data, the model learns the relation between the input and output (here 'A' & 65).

Once the machine is trained with sufficient data we provide a input let's say 'C' and let the model predict the output, but you must know the real output of that input. You check the prediction with the real value and check whether it is correct or wrong. If the predictions are correct we pass the model. If the predictions aren't correct we keep training until is reaches a satisfactory point.
