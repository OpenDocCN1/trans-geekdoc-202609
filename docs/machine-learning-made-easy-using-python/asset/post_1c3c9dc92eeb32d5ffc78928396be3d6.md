Variance or difference of random variables from expected value can be obtained with the following formula where X is individual data, X is mean and n is total number of data values If you can find the variance of any data by replacing the values in the formula but make sure to remember how the variance is found Next if we want to find deviation i.e. the difference of each value from its average or mean, we can use the following formula where i represents the number of values in the data and $\bar{u}$ represents the mean. If we want to find the deviation of a data of a population we will use the mean of the whole population which is represented by $\bar{u}$

```
$$\bar{u}^2 = (X_i - \bar{u})^2
```

But if we want to find the deviation of a data from a sample we will use the mean of the sample instead of the whole population which is represented by $\bar{X}$ i.e. called inferential statistics

```
$s^2 = (X_i - \bar{X})^2
```

Similarly we can find the standard deviation or the dispersion of data from its mean through the following formula where N is the number of data points or values

```
$$\sigma = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (X_i - \bar{u})^2}
```

Let’s consider an example to understand how to find standard deviation. We will find the standard deviation of our sales data

| Sales |
|---|---|
| 24 |
| 29 |
| 33 |
| 35 |

First we need to find the mean or $\bar{u}$ i.e. 28.25 which we found earlier

```
$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(X_i - \bar{u})^2} \\ \bar{u} = 28.25
```

Then we will find the difference of all the sales data from the mean and square them and add them

```
$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(X_i - 28.25)^2}
```

$\sum_{i=1}^{N}X_i = 24, 29, 33, 35 \quad [N = 4]$
$(24 - 28.25)^2 = (-4.25)^2 = 18.06$
$(29 - 28.25)^2 = (1.25)^2 = 1.56$
$(33 - 28.25)^2 = (4.75)^2 = 22.56$
$(35 - 28.25)^2 = (6.75)^2 = 45.56$
$\sum_{i=1}^{N}(X_i - \bar{u})^2 = 18.06 + 1.56 + 22.56 + 45.56$
$\sum_{i=1}^{N}(X_i - \bar{u})^2 = 87.74$

Finally we can find the root of the product of 1/N and 87.74 to find $\sigma$

```
$\sigma = \sqrt{\frac{1}{N}} \times 87.74
```

```
$\sigma = \sqrt{\frac{1}{4}} \times 87.74 \quad [N=4]$
```

```
$\sigma \approx 21.93$
```

$\sigma \approx 4.67$

## Entropy and Information gain

Entropy or the uncertainty in data can be found with the following formula:

```
$H(S) = -\sum_{i=1}^{N} p_i \log_2 p_i$
```

where S stands for set of all instances in data, N to the number of distinct values and $p_i$ stands for probability of the event. Through we can further calculate information gain from a variable through the following formula

```
$Gain(A, S) = H(S) - \sum_{j=1}^{|S|} \frac{|S_j|}{|S|} \times H(S_j)$
```

where A is a feature or variable whose information gain is being calculated,H(S) is the entropy of the whole dataset,|S_j|$ is the number of instances with value j of the feature A, $|S|$ is all data instances in the dataset, v is the set of distinct values of the feature A, H(Sj) is the entropy of subset of data instances of feature A and H(A,S) is entropy of feature A of the dataset
