# Confusion matrix

Confusion matrix is used to calculate the accuracy of an model. To calculate that we need to create the confusion matrix first, let’s consider we created a model that predicts weather and we asked it to predict whether it will rain for the next 30 days. After 30 days, we matched the predicted values with the actual values and found that the model predicted 25 correctly but 5 were incorrect. Here 8 is referred as True negatives (T-), 3 is referred as False positives (F+), 2 is referred as False negatives (F-) and 17 as True Positives (T+). We can use these values to calculate the accuracy of the model using the following

| | Predicted no rain | Predicted rain |
| --- | --- | --- |
| Actual no rain | 8 | 3 |
| Actual rain | 2 | 17 |

formula:

```
accuracy = \frac{(T+) + (T-)}{(T+) + (T-) + (F+) + (F-)}
```

So the accuracy of our model is

```
accuracy = \frac{17+8}{17+8+3+2}
```

```
accuracy = \frac{25}{30}
```

accuracy = 0.8

Similarly we can calculate the error rate or misclassification rate using the following formula:

```
Error rate = \frac{(F+) + (F-)}{(T+) + (T-) + (F+) + (F-)}
```

```
Error rate = \frac{3+2}{17+8+3+2}
```

```
Error rate = \frac{5}{30}
```

Error rate = 0.2

It is same as 1-Accuracy. Next, we can calculate the precision of the model using the below formula:

```
Precision = \frac{(T+)}{(T+) + (F+)}
```

```
Precision = \frac{17}{17+3}
```

```
Precision = \frac{17}{20}
```

Precision = 0.85

precision can also be defined as how many true positive predictions our model makes We can also calculate the Recall using the below formula:

```
Recall = \frac{(T+)}{(T+) + (F-)}
```

```
Recall = \frac{17}{17+2}
```

Recall \approx 0.89

And finally we can calculate F-measure if models have high precision & low recall or vice versa using the below formula:

```
F-measure = \frac{2 \times Recall}{Recall + Precision}
```

```
F-measure = \frac{2 \times 0.89 \times 0.85}{0.89 + 0.85}
```

```
F-measure = \frac{1.51}{1.74}
```

F-measure \approx 0.86

# Probability

It is the easiest mathematical calculation to predict the outcome of an event using the following

```
Probability of event A = \frac{Favourable outcomes}{Total outcomes}
```

There are three different concepts required for machine learning i.e. Probability Density Function, Normal distribution and central limit theorem which are both statistics and probability

# Probability Density Function

The probability function states the following points:

- It is continuous over range
- Area under the curve and the x-axis equals to 1
- Probability of events will lie between a and b

Any variable that satisfies these conditions is called continuous random variable![](img/d75fea3635f5553f1cb0585b399b1b4b_73_0.png)

# Normal Distribution

Variables (features) with mean σ and variance as 1 are called normal variables. A normal distribution is an arrangement of data set in which most values cluster in the middle of the range and the rest taper off toward either extreme. In a normal distribution mean, median and mode are same. We can represent the distribution as the below graph:![](img/d75fea3635f5553f1cb0585b399b1b4b_73_1.png)

where μ is mean and σ standard deviation. The formula of normal distribution can be represented as:

```
f (Normal Variable) = \frac{1}{\sigma \sqrt{2\pi}} e^{-(X-\mu)^2/2\sigma^2}
```

where e \approx 2.718

# Central Limit Theorem

The theorem states that the mean $\bar{u}$ of samples from a population should be equal to the population mean![](img/d75fea3635f5553f1cb0585b399b1b4b_74_0.png)

# Types of Probability

Probability can be classified into the following three types:

- Marginal probability, probability of an event without conditions like drawing a number from the first ten natural numbers.
- Joint probability, probability of two events at once like drawing a red card from a deck of cards
- Conditional probability, probability of one or more event with conditions. The condition may be fulfilled already or need at the moment of the event. For example, drawing a joker card from your friend, where it may or not be already present.![](img/d75fea3635f5553f1cb0585b399b1b4b_74_1.png)![](img/d75fea3635f5553f1cb0585b399b1b4b_74_2.png)

# Bayes Theorem

Bayes theorem is way of finding probability of an event when we know about the probability of other events or conditions. The formula is given as:

```
P(A|B) = \frac{P(B|A) P(A)}{P(B)}
```

Let's say P(Fire) means how often there is fire, and P(Smoke) means how often we see smoke, then:

- P(Fire|Smoke) means how often there is fire when we can see smoke
- P(Smoke|Fire) means how often we can see smoke when there is fire

So we know the following probabilities:

- dangerous fire = 1%
- fire with smoke = 10%
- dangerous fire with smoke = 90%

Then probability of dangerous fire when there is smoke:

```
P(Fire|Smoke) = 1\% \times 90\% / 10\%
P(Fire|Smoke) = 9\%
```

Using bayes theorem we can find many probabilities of events. Even there is a naïve bayes theorem model in machine learning which will learn in the upcoming lessons.
