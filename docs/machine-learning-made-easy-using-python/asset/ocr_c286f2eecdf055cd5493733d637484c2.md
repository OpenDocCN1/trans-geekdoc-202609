# Logistic Regression

Logistic regression is a type of model that predicts the outcome of output values as Yes or no numeric values 1 or 0 respectively. We can use these type of models to classify a day as rainy or not, a person as healthy or sick, etc. But there are different types of logistic regression used for to different situations.

# Binomial Logistic Regression

Binomial or binary logistic regression used to predict exactly two outcomes i.e. either 1(positive) or 0(negative)
