# DATA VISUALIZATION

We craete density plots using the plot() function of pandas library and specifying density in the kind paramter

```
In [7]: import pandas
dt = pandas.read_csv('trees.csv')
del dt=['Index']
dt.plot(kind='density')
```

```
Out[7]: <matplotlib.axes._subplots.AxesSubplot at 0x261f2dc
```

![](bbox=[0.268, 0.298, 0.842, 0.532])

If you separated plots, specify True in subplots parameter

```
dt.plot(kind='density', subplots=True)
```
