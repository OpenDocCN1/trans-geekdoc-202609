# SETTING-UP ENVIRONMENT

# Installing Anaconda

Head to anaconda.com/products/individual to download the latest version of Anaconda.

![](bbox=[0.118, 0.246, 0.783, 0.403])

You can download the anaconda-installer for your system, whether it is Windows, Mac or Linux. After installing it, just run the installer and install it as usual.

After installation, search for anaconda prompt and run it.
