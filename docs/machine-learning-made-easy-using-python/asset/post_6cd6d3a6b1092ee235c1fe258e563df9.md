## Linear Regression

As learnt earlier, regression algorithms find relationship between two variables and predict the values based on that relation. In linear regression, the algorithm finds the relationship between two variables i.e. if a independent varable is changed the dependent variable will be affected. For example consider the following dataset, we have data of different squares with its length of one side and its area. And it is clear that if the side (independent variable) is changed say increased the area (dependent variable) will change(increase) too because area is calculated from the length of the side

| Side | Area |
|---|---||
| 5 | 25 |
| 10 | 100 |
| 15 | 225 |
| 20 | 400 |

Mathematically the relation can be expressed as:

Y = mX + b

where, Y is the dependent(side), X is the dependent variable(area) we are using to make predictions, m is the slope of the regression line which represents the effect X has on Y and b is a constant, known as the Y-intercept. If X = 0, Y would be equal to b

The relationship can be positive or negative

### Simple Linear Regression

Simple linear regression or SLR is the types of regression in which we predict a value using only one feature like we did before, we predicted the weight of a person using height![](img/d75fea3635f5553f1cb0585b399b1b4b_136_2.png)

### Multiple Linear Regression

Multiple Linear Regression or MLR is the type of regression in which we predict a value using two or more features like predicting the weight of a person using age and height. Here, the regression line is calculated using the following formula:

```
y_i = b_0 + b_1x_i + ... + b_px_i + e_i
```

p is the number of features, h(x_i) is the predicted value, b_0, b_1, etc. are regression coefficients and e_i are residual errors. This also gives rise to the following formula

```
y_i = h(x_i) + e_i
```

y is the actual value or the dependent variable The training process for MLR model is as same as we did before, but this time we have more features which predictions will be made.
