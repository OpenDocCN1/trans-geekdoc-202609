The read_excel function of the pandas library is used read the content of an Excel file into the python environment as a pandas DataFrame.


As excel sheets are imported as Pandas Data-Frames, we can perform all the tasks on the excel data like Data Frames.

You may notice, we have a Unnamed: 5 column with NaN values [except dt.value[2,5]]. Let’s clean up our data.

First we need to remove the Unnamed: 5 column, which we can do using the del keyword

```
In [10]: import pandas as pan
dt = pd.read_excel("xlsx_data.xlsx")
del dt["Unnamed: 5"]
```

As we have learned earlier the del removes the whole column we don’t need to deal with the Data Cleansing
