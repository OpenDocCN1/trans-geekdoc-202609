# Descriptive statistics

In descriptive statistics we work with the whole data i.e. population rather than sample. In de-scriptive statistics we have the following:

+   - **Central Tendency**
The mean, median and mode of an data is refer as it's central tendency. We can find each of them very easily, let's consider the following data and find it's central tendency,

| Day | Sales |
|---|---|
| Monday | 33 |
| Tuesday | 37 |
| Wednesday | 14 |
| Thursday | 29 |

To find the mean or the average of the sales, we need to add all the values together and divide it with the total number of values

```
mean(x) = sum of all values = 33 + 37 + 14 + 29 = 28.25
Total no. of values 4
```
