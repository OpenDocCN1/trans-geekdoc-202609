
## Multivariate plots

As it sounds, through multivariate plots we can understand the relations between different attributes or variables in a data. One of the multivariate plots is a correlation matrix. The correlation matrix for our data like so:

```python
In [16]: from matplotlib import pyplot
import pandas
dt = pandas.read_csv('trees.csv')
del dt['Index']
cor = dt.corr() # correlations
# Plotting correlation matrix
vis = plt.figure()
# Adding the color meter
ax = vis.add_subplot(111)
cax = ax.matshow(cor, vmin=-1, vmax=1)
vis.colorbar(cax)
pyplot.show()
```

![](img/d75fea3635f5553f1cb0585b399b1b4b_125_0.png)

We used the figure() function of the matplotlib library, along with the matrix we also added a color bar to indicate the value of colors using the correlations data i.e. calculated using the corr() function. We added the matrix using the add_subplot() function and 111 as argument i.e. it's position. Then we used the matshow() function and passed our correlations and min and max values. Finally we plotted our matrix with the colorbar

## DATA VISUALIZATION

We can also label the axes as our column names using the set_xticks() and set_yticks() functions to set the positions and set_ticklabel() and set_yticklabel() functions to label them accordingly

```python
In [19]: vis = plt.figure()
ax = vis.add_subplot(111)
cax = ax.matshow(cor, vmin=-1, vmax=1)
vis.colorbar(cax)
ax.set_xticks([0,1,2])
ax.set_yticks([0,1,2])
ax.set_xticklabels(['Girth', 'Height', 'Volume'])
ax.set_yticklabels(['Girth', 'Height', 'Volume'])
plt.show()
```

![](img/d75fea3635f5553f1cb0585b399b1b4b_126_0.png)

We can easily understand the relations between the variables i.e. Girth & Volume is close to 1 correlation value(full positive) and Height & Volume have a bit less relation than Girth & Volume.

As we already know about the regression algorithm that it is a case of supervised machine learning where we feed input data (numeric) and the algorithm learns the patterns in the data and predicts the output data.
