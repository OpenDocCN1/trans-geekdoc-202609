Let’s consider an example to understand how to find standard deviation. We will find the standard deviation of our sales data

| Sales |
| 24 |
| 29 |
| 33 |
| 35 |

First we need to find the mean or $ar{u}$ i.e. 28.25 which we found earlier

```
$\sigma = \sqrt{rac{1}{N}\sum_{i=1}^{N}(X_i - \bar{u})^2}$ \\bar{u} = 28.25$
```

Then we will find the difference of all the sales data from the mean and square them and add them

```
$\sigma = \sqrt{rac{1}{N}\sum_{i=1}^{N}(X_i - 28.25)^2}$
```

$\sum_{i=1}^{N}X_i = 24, 29, 33, 35 \quad [N = 4]$\n$(24 - 28.25)^2 = (-4.25)^2 = 18.06$\n$(29 - 28.25)^2 = (1.25)^2 = 1.56$\n$(33 - 28.25)^2 = (4.75)^2 = 22.56$\n$(35 - 28.25)^2 = (6.75)^2 = 45.56$\n$\sum_{i=1}^{N}(X_i - \bar{u})^2 = 18.06 + 1.56 + 22.56 + 45.56$\n$\sum_{i=1}^{N}(X_i - \bar{u})^2 = 87.74$
