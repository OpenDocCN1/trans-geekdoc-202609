Microsoft Excel is a very widely used spreadsheet program. Its user friendliness and appealing features make it a frequently used tool in Data Science. Get your sample data here xls_data (check the Resources). The read_excel function of the pandas library is used to read the content of an Excel file into the python environment as a pandas DataFrame.

```python

dt = pd.read_excel("xlsx_data.xlsx")
dt
```

As excel sheets are imported as Pandas DataFrames, we can perform all the tasks on the excel data. You may notice, we have an Unnamed: 5 column with NaN values (except dt.value[2,5]). Let’s clean up our data. First we need to remove the Unnamed: 5 column, which we can do using the del keyword.

```python
In [10]: import pandas as pd
dt = pd.read_excel("xlsx_data.xlsx")
del dt["Unnamed: 5"]
```

As we have learned earlier the del removes the whole column we don’t need to deal with the Data Cleansing. We have removed the Unnamed: 5 column
