Likewise we can use the decision tree to solve different kind of problems based on classification. But you may also ask how the tree creates those comparisons or splits? It isn’t necessary to know but you should. First the algorithm calculates the gini index for each attribute using the below formula:

$p^2 + q^2$

which is the sum of square of probability for success(p) and failure(q). Then the dataset is splitted into two lists of rows having index of an attribute and a split value of that attribute. Then it finds the best possible split by evaluating the cost(gini) of the split

## Logistic Regression

Logistic regression is a type of model that predicts the outcome of output values as Yes or no numeric values 1 or 0 respectively. We can use these type of models to classify a day as rainy or not, a person as healthy or sick, etc. But there are different types of logistic regression used for to different situations.

## Binomial Logistic Regression

Binomial or binary logistic regression used to predict exactly two outcomes i.e. either 1(positive) or 0(negative)

So how did our model predicted teh values or how do the logistic regression works? To understand we will see what is the mathematics behind the algorithm, if you want you can move ahead or give it read. The followings are the steps of binomial:

- We already know that the output will be either (No) or 1. For that the linear function is found with the following: $g(z) = \frac{1}{1+e^{-z}}$

- $z$ is $\theta^T x$

- We can visualize the sigmoid curve by the following graph: ![](img/d75fea3635f5553f1cb0585b399b1b4b_153_0.png)

- The sigmoid function can be divided into classes if it lies between 0.5 and 1, otherwise it is 0.

- We also need to define the loss function to measure how well the algorithm performs. The loss function with respect to each weight tells us what would change if we modified these weights. The derivative of loss function is: $J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)} \log(h_\theta(x^{(i)})) + (1-y^{(i)}) \log(1-h_\theta(x^{(i)}))]$
