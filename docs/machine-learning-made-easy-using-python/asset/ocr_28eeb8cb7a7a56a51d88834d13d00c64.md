The labels also have the following two types:
Nominal, these data aren’t ordered. They have no heirarchy or upper or lower status. In the following data the labels have either True or False value i.e. considered nominal data

| Answer | Question |
| True | 01 |
| False | 02 |
| False | 03 |
| True | 04 |

Oridinal, these data are ordered. They have upper or lower status. In the following data the labels have an order in teh values like Good > Average > Bad i.e. ordinal data

| Product ID | Rating |
| 101 | Average |
| 102 | Good |
| 103 | Average |
| 104 | Bad |
