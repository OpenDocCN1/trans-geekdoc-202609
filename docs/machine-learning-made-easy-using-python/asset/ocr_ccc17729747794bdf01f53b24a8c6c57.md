# Lists vs. ndarray

In Python we have lists that serve the purpose of arrays, but they are slow to process. NumPy aims to provide an array object that is up to 50x faster than traditional Python lists.

# Lists

# ndarray

+   - List is an array of heterogeneous objects
- Lists arrays are stored in different places in the memory which, makes it slow to process data.
- Lists are not optimized with latest CPU’s
- A 1-Dimensional List

+   - ndarray is an array of homogeneous objects
- ndarrays arrays are stored in continuous place in the memory which, makes it faster to process data.
- ndarrays are optimized to work with latest CPU’s
- A 1-Dimensional ndarray

```
['A', 56, 67.05]
```

```
[[ 12, 17, 25)] ]
```
