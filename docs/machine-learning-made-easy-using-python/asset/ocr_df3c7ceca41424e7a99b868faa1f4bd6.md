# Jupyter Notebook

The Jupyter Notebook is an open-source web application that allows you to create and share documents that contain live code, equations, visualizations and explanatory text. We will use it to perform our data processing, analytics and visualization, etc. on the go. To open Jupyter Notebook, write jupyter notebook in the anaconda command prompt and press enter.

![](bbox=[0.723, 0.501, 0.88, 0.626])

```
Anaconda Prompt (anaconda3)
```
