In the next method i.e. L2 Normalization, all the squares of values in each row sum upto 1. So let’s use ‘\l2’ in the norm parameter and check their sums

```
In [12]: import pandas
from sklearn import preprocessing
dt = pandas.read_csv('trees.csv')
ar = dt.values
nm = preprocessing.Normalizer(norm='l2')
nm_ar = nm.transform(ar)

print('\L2 Normalization\n')
print(nm_ar[:5])

# Sum of values in the rows
print('\\nsum of the values in each row\n')
for i in [0,1,2]:
    print(sum(nm_ar[i]))

# Sum of the squares of the values in each row
sm_row = '\nsum of squares of the values in each row\n'
for i in [0,1,2]:
    sm_row = 0
    for val in nm_ar[i]:
        sm_row += val*val
```
