## 03 PANDAS LIBRARY

### Pandas

Data science requires high-performance data manipulation and analysis, which we can achieve with Pandas Data Structures. Python with pandas is used in variety of academic and commercial domains including Finance, Economics, Statistics, and more. Using Pandas we can accomplish typical steps in the processing and analysis of data: load, organize, model, and analyse the data.

![](img/d75fea3635f5553f1cb0585b399b1b4b_28_0.png)

### Key features of Pandas library

We can achieve a lot with Pandas library using features like:

- Fast and efficient DataFrame object with default and customized indexing.
- Tools for loading data from different file formats.
- Data alignment and integrated handling of missing data.
- Label-based slicing, indexing and subsetting of large datasets.
- Columns from data can be inserted.
- Group by for aggregation and transformations.

### Series

Pandas deals with data structures known as series, data frames and panel. Series is an one-dimensional array like structure. For example, the following series is a collection of integers:

```
10 17 23 55 67 92
```

As series are homogeneous data structure, it can contain only one type of data. Series:

- It is a homogeneous structure
- Its size is immutable
- Values in series are mutable

### Data Frames

DataFrame is a two-dimensional array with heterogeneous data:

| Day | Sales |
|---||---|
| Monday | 33 |
| Tuesday | 37 |
| Wednesday | 14 |
| Thursday | 29 |

The data shows sales of certain product for 2 or more days. So we conclude pandas data frames:

- It can contain heterogeneous data
- Its size is mutable
- Also its data is mutable

We will use Pandas series and data frames lot in the future, make sure to go through the lesson again and get grasp of it.

### Key Points

- Pandas library is a high performance data manipulation tool.
- Pandas data structures include series and data frames
- Series is a 1-Dimensional array of homogeneous data, whose size is immutable but values in series are mutable.
- Data Frames is 2-Dimensional array of heterogeneous data, whose size and data are mutable.

### Key features of NumPy

NumPy is powerful that consists of many features like:

- Mathematical and logical operations on arrays.
- Fourier transforms and routines for shape manipulation.
- Operations related to linear algebra. NumPy has in-built functions for linear algebra and random number generation.
- NumPy ndarrays are much faster than Python Built-in lists and consume less memory.
- Most of the part that requires fast computation are written in C and C++.

### ndarray objects

NumPy aims to provide an array object that is up 50x faster than traditional Python lists. The array object in NumPy is called ndarray, it provides a lot of supporting functions that make working with ndarray very easy. Arrays are very frequently used in data science, where speed and resources are very important. In NumPy, we can create 0-D, 1-D, 2-D and 3-D ndarrays.

| 0-D | (33) |
|---|---|
| 1-D | ([11, 27, 18]) |
| 2-D | ([3, 5, 6], [5, 7, 11]) |
| 3-D | ([5, 8, 19], [6, 9, 10], [4, 1, 11]) |

In brief ndarrays or n-dimensional arrays are:

* It describes the collection of items of the same type.
* Items in the collection can be accessed using a zero-based index.
* Every item in an ndarray takes the same size of block in the memory.
* Each element in an ndarray is of the same type (dtype).
