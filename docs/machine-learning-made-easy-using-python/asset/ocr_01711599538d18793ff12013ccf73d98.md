The first analysis is to know the shape of the data or how amny rows and columns are present in the data. We can do so by using the shape attribute of the dataframe object

```
In [4]: import pandas
dt = pandas.read_csv('trees.csv')
dt.shape

Out[4]: (31, 4)
```

Our data has 31 rows and 4 columns i.e. 124 values in total. If we want we can inspect the first 10 values using the head() function and passing 10 as argument

```
In [5]: import pandas
dt = pandas.read_csv('trees.csv')
dt.head(10)
```
