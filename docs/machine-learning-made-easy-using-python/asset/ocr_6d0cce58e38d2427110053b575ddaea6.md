# Support Vector Machine Kernels

Support vector machines are implemented with kernels that transforms a input data space into multidimensional for more flexiblity and smooth workflow for the support vectors machines. As in the previous model we used the linear kernel there are different types of kernels like:

+   - Linear Kenernel, is used when predicting two outcomes
- Polynomial kernel, is more generalized version of the linear kernel where the input space is non-linear
- Radial Basis Function kernel, is used for SVM's that maps the input space into infinite dimensions
