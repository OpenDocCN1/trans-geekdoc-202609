# Naïve Bayes

Naive Bayes algorithm is based on the Bayes theorem which we already learned in previous lessons. We have three types of Naive Bayes algorithms:

+   - Gaussian, is used when the data in labels is drawn from a gaussian distribution
- Multinomial, is used when the data in labels is drawn from a multinomial distribution
- Bernoulli, is used when we have to predict binary features like 0 or 1
