We have more access to the markdown cells, to display texts more gracefully. We can add headings, sub-headings and lower-headings, using # 1, 2 and 3 times followed by space and then text respectively.

```
# Jupyter Notebook
## IPython
### Data

[ ] :
```

```
Jupyter Notebook
IPython
Data
[ ] :
```

> Bulleted List

To create an ordered list, use 1 for the first list item and then use tabspace for the sub-list items and use correct numbering. [The text should be written followed by space after the numbers]

To create a bulleted list, use - for square bullets and * for round bullets, and same manner as above for list and sub-list items.
