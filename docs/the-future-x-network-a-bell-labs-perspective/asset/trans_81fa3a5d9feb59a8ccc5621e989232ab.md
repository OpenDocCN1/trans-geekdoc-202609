
# 云计算的演进

## 第一个十年：全球云的兴起

在21世纪的第一个十年，全球云的出现彻底改变了服务和内容向用户和企业交付的方式。似乎一夜之间，只需互联网连接和浏览器即可访问大量创新服务。这些新服务通过消除为潜在的大规模客户群建设基础设施的障碍，提供了几乎无限的容量来服务数百万用户，无论其位置如何。因此，全球云释放了那些缺乏足够规模或资金来实现其愿景的创新者的潜力。企业家可以用很少的前期投资部署服务，并在需求出现时快速扩展；如果需求没有出现，服务也可以以极低的成本悄然退役。这种风险的消除使得我们今天所享受的服务创新成为可能。许多服务如果投资者必须冒大额资金风险来启动，永远不会面世。

## 集中式架构的局限性

尽管高度集中的云架构非常适合全球可访问性和规模经济，但很明显此类架构由于应用服务器与终端用户之间存在大量网络跳数而存在性能可预测性和延迟问题。此外，站点选择的有限有时与敏感数据存储的国家法规相冲突，并引发对存储数据安全的担忧。为解决这些问题，集中式云开始区域化，扩大其足迹以包括不同地缘政治区域的站点。此外，为解决性能、延迟和传输经济性问题，CDN 网络提供了更多分发，将内容带到离终端用户更近的地方，甚至在本地网络内部署全球提供商的 CDN 设备。

## 第二次云革命：边缘分发

我们现在正处于第二次云革命的临界点，这将导致云向网络边缘进一步分布。随着用户内容消费最终向按需流媒体主导转变，将需要将高质量内容移至离终端用户非常近的位置，以优化性能和交付成本。与此同时，提供高性能实时服务的新应用正在涌现。虚拟化移动网络、车辆控制和增强现实服务需要个位数毫秒的延迟，无法由运行在集中式或区域数据中心的应用程序实现。这些因素推动了对一种云的需求，这种云提供对服务的全球访问，但支持从位于网络边缘的数据中心交付这些服务：全球-本地云。为了实现这一新现实，正在开发新技术，以通过本地化、优化的资源池支持具有高度移动用户的不可预测且高度动态应用程序的交付和扩展。

## 迈向全球-本地生态系统

随着我们迈向2020年及以后，大多数服务必须全球化其覆盖范围，但本地化交付或情境化。仅在特定本地化网络内可用的服务和内容将无法被高度移动的消费者接受，他们期望服务适应他们的生活，而非相反。与此同时，对于高性能的关键任务服务，本地交付对于为用户提供高质量体验至关重要，在某些情况下甚至是服务得以实现的前提。这需要一种全球和本地能力的结合，而目前没有任何单一提供商具备。因此，将出现一个由合并、合作伙伴关系和收购组成的新提供商格局，从而能够构建满足这些需求所需的基础设施和控制系统。这场革命的终点很可能是一个生态系统的形成，该生态系统将由少数主要全球-本地服务提供商组成，他们将利用数百家本地/区域服务提供商的资源和服务，并开启一个新的人类和商业时代。
