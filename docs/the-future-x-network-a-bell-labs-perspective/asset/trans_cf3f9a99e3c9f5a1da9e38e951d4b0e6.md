
# 书写文字系统的演变
电子邮件的最早形式出现在1960年代，当时麻省理工学院的兼容分时系统（CTSS）团队为其成员创建了一种向彼此的终端和/或电子邮件邮箱发送消息的方式。同一时期也开发了其他电子邮件系统，但它们都无法互操作。正是在1970年代，ARPANET引入了标准化的电子邮件系统，并且IETF的电子邮件规范首次被提出。在1980年代，SMTP的今天规范在全球范围内被采纳，使得全球电子邮件提供商之间能够互操作。这种采用将书写文字的电子通信从早期的可互操作电传网络和传真服务现代化为可互操作的电子邮件。

向云的过渡也为使用认知技术提供了机会，例如机器学习，其可能基于支持向量机或神经网络。

也是在1980年代，开始着手开发一种新的书写文字电子通信形式——短信。在Friedhelm Hillebrand的领导下，GSM标准组织致力于为短消息服务（SMS）定义规范，这最终在1992年实现了向移动设备的首次SMS短信交付。使用SS7信令基础设施中继这些消息将最大消息长度限制为160个字符（Milian 2009）。在1990年代，移动设备上的SMS以及ICQ、AOL即时通讯、雅虎通和MSN Messenger等基于PC的IP消息应用，开启了今天人人熟悉的消息服务类型。

思考这样一种看似受限的通信类型为何变得如此对现代人类生存至关重要是很有趣的。也许最明显的特征是通信的异步性质，结合了在交换中可用但并非必需（在人类层面）的近实时响应。综合起来，这些属性允许：

• **多任务处理** — 在参与另一场口头对话和/或几场同时进行的基于SMS的对话的同时发送（短）消息的能力
• **非侵入性** — 选择何时何地回应的能力
• **即时性** — 在必要时立即回应的能力
• **不显眼** — 在公共场合进行私人交流的能力
• **持久性** — 在较长时期内进行连续或持久交流的能力。

这种属性组合被证明对现代生活如此有吸引力，以至于消息传递无可争议地成为今天的主导通信形式。的确，北美使用数据支持这一断言。1995年，平均美国用户每月发送0.4条短信。1999年，互操作性允许任何电信提供商的用户向任何其他电信提供商的用户发送短信，因此到2000年，平均美国用户每月发送35条短信。使用量持续上升，到2007年，美国人发送的短信数量超过了打电话的数量（Erickson 2012）。

随着无线通信的近乎无处不在的部署，以及网络运营商相对较高的消息服务成本，新的第三方消息应用程序随之出现。因为这些应用程序不依赖于底层传输网络，而是通过云从电信宽带数据网络之上交付，它们通常是“免费”的，并在全球范围内迅速传播。此外，这些平台的用户开始使用消息应用不仅是为了避免SMS限制和使用费用，也是因为他们更喜欢消息传递的异步和不那么预定的性质，而不是以语音通话形式进行的实时口头交流。因此，虽然消息传递急剧增长，但语音通话总体上趋于平稳或下降，如图2所示。消息传递快速增长的关键因素之一是消息平台的创新，这是由应用开发者生态系统推动的。

思考相关的经济情况是很有趣的。微信拥有超过650名月活跃用户（MAUs），并不是最大的新消息平台，但在2014年带来了最多的收入，达11亿美元（Millward 2015，Paypers 2015）。虽然不容忽视，但与最大的电信服务提供商相比，这仍然很小，后者每年收入超过1000亿美元（AT&T 2015）。根据Pyramid Research的说法，电信服务提供商仍然大约有一半的收入来自语音和SMS服务。这是经典的创新场景，其中现有提供商专注于维持创新和收入流，而新进入者通过在低端进入、收入预期（和需求）较低并满足未被满足的用户需求来颠覆市场。在下文中，我们将论证这些世界可以并且将围绕新的全球统一通信范式概念进一步融合。

这些新消息应用程序最近演变为真正的通信平台——增加语音通话、语音消息、视频通话、视频消息、文件共享和协作——包括使用新兴的WebRTC类型功能，以及专有扩展——预示了这一未来。它们已开始尝试并在传统通信之外拓展，提供以下内容（Meeker 2015）：

• 通过创建对话式或“社交商务”平台连接移动商务
• 提供点对点支付方案

## 媒体通信
讲故事自人类诞生以来一直是人类交流和社会行为中重要且不断变化的一部分——例子包括史前绘画中描绘部落围坐在篝火旁聆听长者、希腊史诗诗歌的口头传统，其中荷马的**《奥德赛》**和**《伊利亚特》**是书面记录，一直到过去100年，20世纪初的无声电影，直到今天的大型电影和电视剧。这一传统如何变化，以及将继续如何变化，很大程度上由新技术驱动；因此，在新的数字时代背景下理解讲故事非常重要。

随着讲故事从口头面对面交流发展到印刷（书籍和期刊），再到图像和动态图像，它变得更加昂贵和复杂。它从任何人都能做的事情演变为仅限专业人士和大型企业的事情。在印刷机早期，它成本低得多并被广泛使用，在宗教改革中通过印刷《圣经》发挥了重要作用，并在法国和美国革命中通过印刷小册子发挥了重要作用。但随着19世纪的工业化，大型出版公司开始主导报纸、杂志和书籍的生产。从使用硝酸盐胶片进行电影制作和电影院放映的早期开始，电影制作是一项仅限于拥有大预算的电影制片厂或少数坚定且资金充足的业余爱好者的活动。
