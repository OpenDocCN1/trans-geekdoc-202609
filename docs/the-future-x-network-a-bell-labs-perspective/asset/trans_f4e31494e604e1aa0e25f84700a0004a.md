
问题比这更深远。几乎每个移动网络运营商都希望为企业提供企业服务，但许多运营商提供的（锁定）设备会阻止在其他运营商网络上使用，或因不同运营商部署的不同频段而存在频谱不兼容。虽然多运营商网络显然对于支持员工自带设备（BYOD）以及我们预计在未来十年部署的众多物联网设备至关重要，但目前多运营商网络只能通过安装多套运营商专用的小型基站来实现，这会使设备、安装和维护成本倍增，并增加协调多项部署和合同的不便。目前该问题是通过使用企业控制的主机/运营商中立的分布式天线系统（DAS）来解决的，该系统支持所有频段，但基带容量（吞吐量）有限，因为它在建筑物的所有楼层和单元之间共享。

## 未来
“硬性”的网络划分，如前一节所述，不能继续存在，鉴于移动用户设备数量和重要性的预期增长，以及物联网在广泛的业务应用中的普及（参见[第11章，**物联网的未来**](#17-9781315365756_chapter-chap11.xhtml#chap11)）。未来，将会出现自然支持多个蜂窝运营商和IT提供商之间协调的新型商业模式。这些新模式将通过融合的多运营商、多技术小区简化企业内部部署，并管理在所有可用授权和非授权频谱上向用户分配连接资源。在本节中，我们将阐述未来无线企业网络的愿景以及它将如何实现这些目标。

### 虚拟化、融合的无线电优于单一线路
2015年，虚拟化技术和SDN才刚刚开始改变网络行业。网络组件历来是在为单一功能或一组功能优化的专用硬件平台上实现的。它们已经开始在数据中心中的通用处理器上虚拟化并实例化。这种方法将在性能、经济性和可扩展性方面带来显著优势，以及对变化需求和需要的适应性。这些虚拟网络实例将使用SDN动态连接起来形成服务链。

这种向SDN和网络功能虚拟化（NFV）的行业范围演进将使创建企业和应用特定的虚拟专用无线网络（VPWNs）成为可能，这些网络由无线接入网络（RANs）和相关的移动核心网络组成。SDN/NFV将使用驻留在边缘云中的管理和控制功能自动分配室内网络资源，并且可以根据需求进行实例化和扩展。这种新的SDN/NFV支持的VPWN将允许企业：
• 最优连接，覆盖所有接入技术和频段
• 统一的多技术企业局域网，专用于其需求
• 对策略和安全的完全控制

提供该VPWN的架构如图[图5](#14-9781315365756_chapter-chap8.xhtml#fig8_5)所示。基本组件包括：
1. **融合企业小区**（CEC）由室内运营商部署，为企业用户提供服务并透明地为来自室外移动网络的访客提供接入。这些多技术、多频段、多租户能力的节点将通过消除对许多不同技术特定接入点以及部署和管理它们相关的成本和复杂性的需求，大大简化企业无线局域网部署。
2. **虚拟控制面**包含分组核心控制功能和SDN控制器。后者创建并连接站点之间的所需SD-VPN，并在企业网络内管理连接。未来，随着用户连接到不同的企业应用和服务，SDN控制器将动态更新服务用户设备的不同无线小区之间的路径，以及边缘云中连接到应用和服务的网关。
3. **虚拟用户面**，将包括无线接入网络（RAN）和控制每个用户到每个应用和服务的路径的核心网络网关功能。网关可以在企业位置本地创建，以实现低延迟和高效的本地内容访问，或在本地数据中心创建，该数据中心由企业或其室内VPWN运营商拥有。
4. **虚拟接入**供任何员工或访客使用，实现从室内无线接入网络到广域无线网络的持续连接。这将通过使用最佳的无线网络资源集和到适当核心网络功能的路径（s）来确保。

CEC是推动向全无线企业局域网迁移的关键技术之一。它们具有小型基站的容量优势和DAS的主机中立优势。这些新型无线小区将支持：

![](images/fig8_5.jpg)
• **多频段、多技术、多运营商** — 将支持多样化的频段（例如，< 2 GHz、2–6 GHz 和 20–80 GHz），使用来自多个广域运营商的频谱。也将支持当前Wi-Fi频段（2.4和5 GHz）和Wi-Gig（60 GHz）频段中的非授权频谱，以及共享频谱频段。所有频段都将使用多种蜂窝技术，从LTE及其演进（LTE-A、LTE-U、LTE-M）开始，以及从2020年起及以后的5G。
• **面向多个核心网络的接口以实现“运营商中立”** — 对于访问企业位置的任何移动运营商用户，CEC将看起来属于其移动网络运营商，并且服务将通过该运营商的核心网络透明提供，使用兼容的无线资源集。对于企业用户，CEC将看起来属于室内运营商，网络服务将使用完全聚合的频谱资源提供。

![](images/page_269.jpg)
这一未来今天已开始实现。协调的多无线电接入允许对接入技术进行抽象，以便设备连接到企业无线网络，而不是单个接入点或小区。这在一定程度上已得到支持，因为3GPP双连接允许4G设备同时连接到一个以上地理上不同的基站。在Release 13 of the 3GPP标准的第13版中，LTE-WLAN无线电级集成将允许LTE和Wi-Fi下行容量聚合，适用于共址和非共址情况。此外，今天3GPP多运营商核心网络（MOCN）功能允许在多个运营商分组核心之间共享基站资源，订阅者信令和用户面流量被导向适用的运营商核心。专用核心网络（DÉCOR）在3GPP第13版中扩展了这一点，允许在单个移动运营商的多个核心网络之间共享RAN。
