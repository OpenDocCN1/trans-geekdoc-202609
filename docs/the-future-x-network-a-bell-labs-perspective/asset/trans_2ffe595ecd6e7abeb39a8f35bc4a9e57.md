
# 个人通信

个人通信以两种基础模式为核心——口语和书面语，既可带图像也可不带图像。利用任一模式在多方之间跨任意距离传递信息的能力，已成为电信行业超过100年的关注焦点。

早在18世纪中期，就已进行利用电力在一定距离上传输信息的实验（Marland 1964）。到1830年代，商用电报和摩尔斯电码已被发明，使一种非常基础的书面语电子通信成为可能。随后在1840年代，苏格兰发明家亚历山大·贝恩发明了第一台化学-机械式传真机，可传输简单的图形图像。贝克韦尔和卡塞利进行了多次进一步改进，商业服务在1860年代即可获得（Wikipedia 2015b）。而在1870年代，第一部实用的电话由亚历山大·格雷厄姆·贝尔发明，使得长距离口语电子通信成为可能。

口语和书面语的长距离通信系统在一段时间内是各自演进的。在1840年代，电传打字机——一种机电式打字机——被发明出来，以取代电报系统中对摩尔斯电码操作员的需求。为了使这种通信形式无处不在，电传网络在1930年代创建。它使用符合国际电信联盟（ITU）建议开发的电传交换机将电传打字机连接起来，从而实现了全球电传运营商之间的互操作性。这种基于文本的网络和系统可被视为现代电子邮件和短信系统及基础设施的最早前身，下文将讨论这些系统和基础设施。

## 口语系统

电话系统迅速成熟，最终发展超越语音，涵盖并超越了电传网络能力和传真服务。机电开关在19世纪末被发明，斯特劳格开关的专利于1891年颁发（Almon Strowger 2012）。它消除了每个用户、家庭和企业电话之间完全互联的物理电缆网的需求，并最终淘汰了人工电话交换台。这些交换机也是按照ITU建议建造的，使全球电话运营商之间能够互操作——形成了我们现在所知的公共交换电话网络（PSTN）。

随着时间的推移，PSTN的ITU建议从带内信令演进为带外信令。带内方法使用多频音调进行信令，极大地限制了新业务创新。信令系统7（SS7）在1970年代引入了带外信令，使许多新功能成为可能，包括多方通话和呼叫转移。SS7标准在1980年代进一步扩展以覆盖移动系统，使被称为公共陆地移动网络（PLMN）的普遍、全球无线移动运营商生态系统成为可能，该网络现在才被SIP/IMS和VoLTE取代。[¹](#15-9781315365756_chapter-chap9.xhtml#fn9_1)

尽管六边形蜂窝概念于1947年（晶体管发明的同一年）被提出用于无线系统，且声码器更早被发明，但在支持蜂窝技术、基础设施和法规使大规模移动通信服务成为可能之前，仍经历了数十年。全球范围内，支持手持设备的移动系统的商业化、部署和采用在1980年代才真正开始——距离固定线路语音服务开始已超过100年。与PSTN一样，PLMN最初使用模拟电路技术，随计算技术一起演进为具有分组互连的数字系统。

在固定电话到移动电话引入之间的一个世纪里，重大的技术突破推动了PSTN以及后来的PLMN的全球建设和进步。人工辅助交换让位于自动化的机电交换机。真空管被晶体管取代，也催生了现代计算产业。反过来，以计算机为电信系统基础的使用实现了数字交换、更高可靠性的改进操作，以及新的终端用户功能，如来电显示、呼叫等待和语音邮件。固定住宅电话从手摇人工操作的烛台式电话缓慢演进到旋转拨号、触音拨号，甚至包括用于显示来电显示等信息的小屏幕。相比之下，移动电话进步要快得多，变得更轻、更薄、功能更强，部分原因是它们与个人电脑的发展并行演进。两种趋势在iPhone的推出中汇聚，iPhone是第一款成功的智能手机，也是真正移动计算的开端，很大程度上由一个人——史蒂夫·乔布斯——的愿景驱动，以及他对创造变革性消费设备和界面的关注。

自1990年代以来，一直在努力开发和部署IP通信解决方案。SIP是IP通信中持久的标准协议之一。它始于1996年，并于1999年首次由IETF标准化。SIP最初是实时通信的信令协议，很快被扩展以包括消息和presence能力。1999年，3GPP开始工作，将现有的基于无线电路的电信网络转变为基于称为IP多媒体子系统（IMS）的框架的全IP网络，使用SIP信令取代SS7和笨重的新的H.323 ITU-T建议。SIP还融合了HTTP和SMTP[²](#15-9781315365756_chapter-chap9.xhtml#fn9_2)的许多元素，这也被视为另一个重要优势。

从一开始，IMS被设计为端到端的丰富通信解决方案（RCS），支持语音、视频、消息、文件传输、地址簿和presence，所有这些都被视为关键的基础功能。它还包括服务工厂的概念——一个平台，可实现新功能和现有功能及应用的创建或增强。此外，IMS被设计为可与任何接入技术一起使用，并最终取代PLMN和PSTN。这一目标对系统提出了额外要求，包括支持与所有传统系统互通，以及支持各种类型的电路交换语音服务（例如，公用电话和ISDN线路），以及传真服务和监管要求。

因此，正如完全设想的那样，IMS的发展需要时间才能实现。然而，过渡已经开始，首先是基于有线的TDM语音替代，最近则是部署了首批VoLTE系统，这些系统将允许退役专用电路交换无线基础设施，并重新分配相关频谱用于更高效的基于IP的LTE网络。

随着网络功能虚拟化（NFV）的出现，这些IMS系统的进一步演进将利用云技术，为更灵活、可扩展的解决方案和新业务模式的采用铺平道路。特别是，IMS基础设施的规模可以适应不同的部署，甚至可以作为软件即服务（SaaS）提供给各个垂直行业部门和一般企业。向云的过渡也提供了使用认知技术（如机器学习）的机会，机器学习可能基于支持向量机或神经网络。这些技术将使这些平台具备自我感知和智能，从而实现能够自我管理、自我组织和自我修复的自主解决方案，如[第5章，**云的未来**](#11-9781315365756_chapter-chap5.xhtml#chap5)所述。
