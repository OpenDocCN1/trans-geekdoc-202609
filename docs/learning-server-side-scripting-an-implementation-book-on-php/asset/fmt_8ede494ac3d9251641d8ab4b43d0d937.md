We send 3 parameters to this function - the database connection resource, the email id and the category of the user. Using the category, we query the corresponding table. We execute the query and return the user's name.

We will look at the session code now:

```php
//checking session
$usersession = '';
$category = '';
$name = '';
if(isset($_SESSION['usersession'])){
  $usersession = $_SESSION['usersession'];
```

We check if the session variable is set. If it is set, we copy the value to `$usersession` variable. Since `$usersession` is an email address (primary key of instructor and learner table), we send it as a parameter to `get_category()` function and assign the value returned to `$category` variable. Similarly, we send `$category` as the third parameter to `get_name()` and assign the value returned to `$name` variable.

In case the session variable is not set, the user will be sent back to `login.php`.

Purpose of redirection: Only logged in users can access this page!
