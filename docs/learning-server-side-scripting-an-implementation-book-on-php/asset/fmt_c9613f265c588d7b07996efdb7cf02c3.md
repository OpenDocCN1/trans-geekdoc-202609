## Updating Profile: profile.php

### 1. Add this snippet to the beginning of the PHP file (for changing password)

```php
<?php
include ('check.php');
if(isset($_POST['changepwd'])){
  $oldpassword = $_POST['txtoldpwd'];
  $newpassword = $_POST['txtnewpwd'];
  $get_password = mysqli_query($con,"SELECT * FROM userlogin WHERE user_mail = '$usersession'");
  $pwd = mysqli_fetch_array($get_password);
  //verifying if old password = new password
  if(password_verify($oldpassword,$pwd['user_pwd'])){ 
    if((strlen($newpassword) > 7) and (strlen($newpassword) < 21)){
      $hashed = password_hash($newpassword,PASSWORD_DEFAULT);
      $updatepwd = "UPDATE userlogin SET user_pwd = '$hashed' WHERE user_mail = '$usersession'";     
      if(mysqli_query($con,$updatepwd)){
         echo "<script>alert('Password changed! Login with new password!');
         window.location.replace('logout.php');</script>";
      }
    }
    else{
      echo "<script>alert('Password length must be between 8-15 characters!');</script>";
    } 
  }
  else{
    echo "<script>alert('Old password is wrong!');</script>";
  }
}
?>
```

The exact work starts from checking the old password using the `password_verify()` function.

*   We have retrieved the hashed password from the table and accessed it via `$pwd['user_pwd']`.
*   We use `password_verify()` to compare `$pwd['user_pwd']` and `$oldpassword` entered in the form.
*   If the passwords do not match, we print "Old password is wrong."
*   If the passwords match, we make another check for the length of the password.
    *   If the length of the new password is between 8 and 15 characters, the hash value of the new password is updated and a message is displayed to the user.
    *   If the length does not match, we print a message asking the user to provide a password between 8 and 15 characters in length.
