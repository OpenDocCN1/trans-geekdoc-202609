
# Execution of Queries

When working with the database, the first primary step is to establish a connection. Once connected, we can use SQL commands in MySQLi procedural functions.

There is a common syntax for executing queries:

```
mysqli_query($database_connection, $query_string);
```

There are 2 parameters:

*   `$database_connection` is the resource variable `$con` (the one we used to connect to the database)
*   `$query_string` is the string containing the SQL statements

For making a query in a string, we ought to follow this:

*   The SQL query must be quoted in PHP
*   String values inside the SQL query must be quoted
*   Numeric values must not be quoted
*   The word `NULL` must not be quoted

That means, if we use double quotes for enclosing the SQL string, for string values, we will use single quotes. When we code in the practice session, we will clearly understand this.

### Insert Data: register.php

In the beginning of the file, above the HTML declaration line, we will include the insert code:

```php
<?php
require('connect.php');

if (isset($_POST['register'])) {
  $category = $_POST['txtusercategory'];
  $usermail = $_POST['txtmail'];
  $userpwd = $_POST['txtpwd'];
  $name = $_POST['txtname'];
  $details = $_POST['txtdetails'];

  if ((strlen($userpwd) > 7) && (strlen($userpwd) < 16)) {
    $userpwd = password_hash($userpwd, PASSWORD_DEFAULT);
    $insert1 = "INSERT INTO userlogin VALUES ('$usermail','$userpwd','$category')";
    if ($category == 'learner') {
      $insert2 = "INSERT INTO learners VALUES ('$usermail','$name','$details')";
    }
    if ($category == 'instructor') {
      $insert2 = "INSERT INTO instructors VALUES ('$usermail','$name','$details')";
    }
    $check_insert1 = mysqli_query($con, $insert1);
    $check_insert2 = mysqli_query($con, $insert2);
    if ($check_insert1 && $check_insert2) {
      echo "<script>alert('Registration successful!');</script>";
    } else {
      echo "<script>alert('Sorry! Try again!');</script>";
    }
  } else {
    echo "<script>alert('Password should be between 8-15 characters');</script>";
  }
}
?>
```

Let me explain line by line:

```php
require('connect.php');
```

We connect to the database in `connect.php` file. So we include the connect file for this page.

```php
if (isset($_POST['register'])) { }
```

The complete set of PHP code works only when the register button is pressed.

```php
$category = $_POST['txtusercategory'];
$usermail = $_POST['txtmail'];
$userpwd = $_POST['txtpwd'];
$name = $_POST['txtname'];
$details = $_POST['txtdetails'];
```

We copy the values submitted in the form to variables.

```php
if ((strlen($userpwd) > 7) && (strlen($userpwd) < 16)) {
}
else {
  echo "<script>alert('Password should be between 8-15 characters');</script>";
}
```

Here, we check if the password is between 8 and 15 characters by imposing 2 conditions: checking if length is greater than 7 and less than 16. If the length does not fall between 8 and 15, it prints a message and skips registration. If the length is between 8-15, it proceeds inside the `if` block.

```php
$userpwd = password_hash($userpwd, PASSWORD_DEFAULT);
```

It is a sin to store the password as it is in the database. So, we create a hash using the `password_hash()` function.

```php
$insert1 = "INSERT INTO userlogin VALUES ('$usermail','$userpwd','$category')";
if ($category == 'learner') {
  $insert2 = "INSERT INTO learners VALUES ('$usermail','$name','$details')";
}
if ($category == 'instructor') {
  $insert2 = "INSERT INTO instructors VALUES ('$usermail','$name','$details')";
}
```

During registration, we have to insert data into 2 tables. One table is either `instructor` or `learner` (corrected from "login" based on context), the other table is `userlogin` which stores login details and user category data.

`$insert1` statement has the query string for the `userlogin` table.

Based on the category, `$insert2` statement will be used. Hope you can see how double quotes are used for the query string and single quotes are used for string values.

```php
$check_insert1 = mysqli_query($con, $insert1);
$check_insert2 = mysqli_query($con, $insert2);
if ($check_insert1 && $check_insert2) {
  echo "<script>alert('Registration successful!');</script>";
}
else {
  echo "<script>alert('Sorry! Try again!');</script>";
}
```

Here, we execute the `mysqli_query()` function for 2 insert statements. Hope you remember the syntax for executing queries from the previous section.

`$check_insert1` and `$check_insert2` will either hold `true` (if the query is executed) or `false` (if query is not executed). If both statements are executed and their values are `true`, we print a message on successful registration. If either of them fails, we ask the users to try again.

```html
<script>alert();</script>
```

The `script` tag is included in the `echo` statement. It means content inside the `script` tag is JavaScript code. This `alert()` function in JS will display a pop-up with some message. We try to inform the user what kind of action takes place through a pop-up instead of printing the message on the page.

One more thing! This is not the only way to carry out the insert process. What stays the same is the `mysqli_query()` function. The way we carry it out can differ in many ways, like:

*   We can insert data into the `instructor` / `learner` table first; if successful, we can insert data into the `userlogin` table.
*   In case one table's data is inserted and the other fails, we can issue commands to reverse the inserted data by issuing a delete command.
*   Not only the password, but all the other fields can also be validated before inserting data.

All these factors depend on the one who develops the application, and the conditions depend on what sort of application is developed.
