Let me explain the retrieval process:

```

```

`$select_courses` is a resource type variable which will hold the table data.

```
while ($selected = mysqli_fetch_row($select_courses)) { }
```

This `while` loop is used to iterate through the rows in the table. `mysqli_fetch_row()` will pass row by row (that is, record by record) data to the `$selected` variable from the `$select_courses` variable which has all the records.

```

```

`$select_courses` variable holds all the retrieved records. `$selected` variable holds an array of fields from one record at a time. Each field can be accessed by an index number.

*   `$selected[3]` holds the `course_description` field. So, we display it in a paragraph.
*   We enclose these 2 statements inside a `div` tag with class named `cl`. This `cl` class was defined in the `style` tag. It means, 2 fields namely course title and course description are displayed to the user inside the `cl` styled `div` tag.
