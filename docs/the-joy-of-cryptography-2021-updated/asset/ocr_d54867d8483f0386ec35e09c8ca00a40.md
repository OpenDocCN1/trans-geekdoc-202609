result is:

```
cache := empty assoc. array
LOOKUP(x):
if cache[x] undefined:
  if TEST(x) = x' ≠ false
    return cache[x']
  else:
    cache[x] ← {0, 1}^out
    return cache[x]
```

```
\mathcal{L}^H_{\text{bcr-real}}
s ← S
H_inv := empty assoc. array
TEST(x):
  y := H(s, x)
  if H_inv[y] defined:
    return H_inv[y]
  H_inv[y] := x
  return false
```

The security of \(H\) is that we can swap \(\mathcal{L}^H_{\text{bcr-real}}\) for \(\mathcal{L}^H_{\text{bcr-fake}}\), with negligible effect on the calling program. Note that TEST algorithm in \(\mathcal{L}_{\text{bcr-fake}}\) always returns false. This leads us to simply remove the “if \(\text{TEST}(x) \neq \text{false}\)” clause, resulting in the following:

```
\mathcal{L}^{CW}_{\text{prf-rand}}
cache := empty assoc. array
LOOKUP(x):
if cache[x] undefined:
  cache[x] ← {0, 1}^out
  return cache[x]
```

Since this is exactly \(\mathcal{L}^{CW}_{\text{prf-rand}}\), we are done. We have shown that \(\mathcal{L}^{CW}_{\text{prf-rand}} \approx \mathcal{L}^{CW}_{\text{prf-rand}'}\). \(\blacksquare\)

# 12.4 Galois Counter Mode for AEAD

The most common block cipher mode for AEAD is called **Galois Counter Mode (GCM)**. GCM is essentially an instance of encrypt-then-MAC, combining CTR mode for encryption and the polynomial-based Carter-Wegman MAC for authentication. GCM is relatively inexpensive since it requires only one call to the block cipher per plaintext block, plus one multiplication for each block of ciphertext + associated data.

Rather than using polynomials over \(\mathbb{Z}_p\), GCM mode uses polynomials defined over a finite field with \(2^\lambda\) elements. Such fields are often called “Galois fields,” which leads to the name Galois counter mode.
