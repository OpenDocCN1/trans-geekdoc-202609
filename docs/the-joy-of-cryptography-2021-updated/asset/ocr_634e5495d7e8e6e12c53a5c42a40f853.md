# ## t-out-of-n secret sharing (Definition 3.3):

```
```
L^Σ_tsss-L
SHARE(m_L, m_R ∈ Σ.M, U):

  s ← Σ.Share(m_L)

# ## Pseudorandom function (Definition 6.1):

```
```
L^F_prf-real
k ← {0, 1}^λ
LOOKUP(x ∈ {0, 1}^in):
  return F(k, x)
```
```

```
```
L^F_prf-rand
T := empty assoc. array
LOOKUP(x ∈ {0, 1}^in):
  if T[x] undefined:
    T[x] ← {0, 1}^out
  return T[x]
