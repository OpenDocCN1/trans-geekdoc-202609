# Collision resistance (Definition 11.1):

```
L^H_cr-real
s <- {0, 1}^lambda
GETSALT():
  return s
TEST(x, x' \in {0, 1}*):
  if x != x' and H(s, x) = H(s, x'): return true
  return false
```

```
L^H_cr-fake
s <- {0, 1}^lambda
GETSALT():
  return s
TEST(x, x' \in {0, 1}*):
  return false
```

# Digital signatures (Definition 13.6):

```
L^Sigma_sig-real
(vk, sk) <- Sigma.KeyGen
GETVK():
  return vk
GETSIG(m):
  return Sigma.Sign(sk, m)
VERSIG(m, sigma):
  return Sigma.Ver(vk, m, sigma)
```

```
L^Sigma_sig-fake
(vk, sk) <- Sigma.KeyGen
S := emptyset
GETVK():
  return vk
GETSIG(m):
  sigma := Sigma.Sign(sk, m)
  S := S U {(m, sigma)}
  return sigma
VERSIG(m, sigma):
  return (m, sigma) \in S
```

# Key agreement (Definition 14.4):

```
L^Sigma_ka-real
QUERY():
  (t, K) <- EXECPROT(Sigma)
  return (t, K)
```

```
L^Sigma_ka-rand
QUERY():
  (t, K) <- EXECPROT(Sigma)
  K' <- Sigma.K
  return (t, K')
```

# Decisional Diffie-Hellman assumption (Definition 14.5):

```
L^G_dh-real
QUERY():
  a, b <- Z_n
  return (g^a, g^b, g^{ab})
```

```
L^G_dh-rand
QUERY():
  a, b, c <- Z_n
  return (g^a, g^b, g^c)
```
