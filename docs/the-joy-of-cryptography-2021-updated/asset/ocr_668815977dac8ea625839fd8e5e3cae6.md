In fact, every security proof in this book will have some intermediate steps that involve compound libraries. We will make heavy use of the following helpful result:

# **Lemma 2.11 (Chaining)** If $\mathcal{L}_{left} \equiv \mathcal{L}_{right}$ then, for any library $\mathcal{L}^*$, we have $\mathcal{L}^* \diamond \mathcal{L}_{left} \equiv \mathcal{L}^* \diamond \mathcal{L}_{right}.$

Proof Note that we are comparing $\mathcal{L}^* \diamond \mathcal{L}_{left}$ and $\mathcal{L}^* \diamond \mathcal{L}_{right}$ as compound libraries. Hence we consider a calling program $\mathcal{A}$ that is linked to either $\mathcal{L}^* \diamond \mathcal{L}_{left}$ or $\mathcal{L}^* \diamond \mathcal{L}_{right}.$

Let $\mathcal{A}$ be such an arbitrary calling program. We must show that $\mathcal{A} \diamond (\mathcal{L}^* \diamond \mathcal{L}_{left})$ and $\mathcal{A} \diamond (\mathcal{L}^* \diamond \mathcal{L}_{right})$ have identical output distributions. As mentioned above, we can interpret $\mathcal{A} \diamond \mathcal{L}^* \diamond \mathcal{L}_{left}$ as a calling program $\mathcal{A}$ linked to the library $\mathcal{L}^* \diamond \mathcal{L}_{left}$, but also as a calling program $\mathcal{A} \diamond \mathcal{L}^*$ linked to the library $\mathcal{L}_{left}$. Since $\mathcal{L}_{left} \equiv \mathcal{L}_{right}$, swapping $\mathcal{L}_{left}$ for $\mathcal{L}_{right}$ has no effect on the output of any calling program. In particular, it has no effect when the calling program happens to be the compound program $\mathcal{A} \diamond \mathcal{L}^*$. Hence we have:

$\Pr[\mathcal{A} \diamond (\mathcal{L}^* \diamond \mathcal{L}_{left}) \Rightarrow \text{true}] = \Pr[(\mathcal{A} \diamond \mathcal{L}^*) \diamond \mathcal{L}_{left} \Rightarrow \text{true}] \quad \text{(change of perspective)}$
$= \Pr[(\mathcal{A} \diamond \mathcal{L}^*) \diamond \mathcal{L}_{right} \Rightarrow \text{true}] \quad \text{(since } \mathcal{L}_{left} \equiv \mathcal{L}_{right}\text{)}$
$= \Pr[\mathcal{A} \diamond (\mathcal{L}^* \diamond \mathcal{L}_{right}) \Rightarrow \text{true}]. \quad \text{(change of perspective)}$

Since $\mathcal{A}$ was arbitrary, we have proved the lemma.
