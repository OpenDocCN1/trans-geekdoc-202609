# Pseudorandom permutation (Definition 6.6):

```
L_prp-real^F

k ← {0, 1}^λ

LOOKUP(x ∈ {0, 1}^blen):
  return F(k, x)
```

```
L_prp-rand^F

T := empty assoc. array

LOOKUP(x ∈ {0, 1}^blen):
  if T[x] undefined:
    T[x] ← {0, 1}^blen \ T.values
  return T[x]
```

# Strong pseudorandom permutation (Definition 6.13):

```
L_sprp-real^F

k ← {0, 1}^λ

LOOKUP(x ∈ {0, 1}^blen):
  return F(k, x)

INVLOOKUP(y ∈ {0, 1}^blen):
  return F⁻¹(k, y)
```

```
L_sprp-rand^F

T, T_inv := empty assoc. arrays

LOOKUP(x ∈ {0, 1}^blen):
  if T[x] undefined:
    y ← {0, 1}^blen \ T.values
    T[x] := y; T_inv[y] := x
  return T[x]

INVLOOKUP(y ∈ {0, 1}^blen):
  if T_inv[y] undefined:
    x ← {0, 1}^blen \ T_inv.values
    T_inv[y] := x; T[x] := y
  return T_inv[y]
```

# CPA security for symmetric-key encryption (Definition 7.1, Section 8.2):

```
L_cpa-L^Σ

k ← Σ.KeyGen

EAVESDROP(m_L, m_R ∈ Σ.M):
  if |m_L| ≠ |m_R| return err
  c := Σ.Enc(k, m_L)
  return c
```

```
L_cpa-R^Σ

k ← Σ.KeyGen

EAVESDROP(m_L, m_R ∈ Σ.M):
  if |m_L| ≠ |m_R| return err
  c := Σ.Enc(k, m_R)
  return c
```

# CPA$ security for symmetric-key encryption (Definition 7.2, Section 8.2):

```
L_cpa$-real^Σ

k ← Σ.KeyGen

CHALLENGE(m ∈ Σ.M):
  c := Σ.Enc(k, m)
  return c
```

```
L_cpa$-rand^Σ

CHALLENGE(m ∈ Σ.M):
  c ← Σ.C(|m|)
  return c
```
