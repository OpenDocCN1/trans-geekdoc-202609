Applying the security of DDH, we can replace L_dh-real with L_dh-rand.

```
a, b, c <- Z_n
A := g^a; B := g^b; C := g^c
count = 0
GETPK():
return A
QUERY(M in G):
count : count + 1
if count > 1: return null
X := M · C
return (B, X)
```
