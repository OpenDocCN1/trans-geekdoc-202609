# ★ 2.5. In abstract algebra, a (finite) group is a finite set G of items together with an operator ⊗ satisfying the following axioms:

+   • **Closure:** for all a, b ∈ G, we have a ⊗ b ∈ G.
+   • **Identity:** there is a special identity element e ∈ G that satisfies e ⊗ a = a ⊗ e = a for all a ∈ G. We typically write “1” rather than e for the identity element.
+   • **Associativity:** for all a, b, c ∈ G, we have (a ⊗ b) ⊗ c = a ⊗ (b ⊗ c).
+   • **Inverses:** for all a ∈ G, there exists an inverse element b ∈ G such that a ⊗ b = b ⊗ a is the identity element of G. We typically write “a⁻¹” for the inverse of a.
