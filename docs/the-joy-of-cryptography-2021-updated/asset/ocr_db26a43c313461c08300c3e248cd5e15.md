Next, \(\mathcal{L}_{\text{samp-R}}\) is replaced by \(\mathcal{L}_{\text{samp-L}}\). By Lemma 4.11, this change is indistinguishable:

```
CTXT(m_1 || ... || m_l):
r := SAMP()
c_0 := r
for i = 1 to l:
  r := LOOKUP(r)
  c_i := r \oplus m_i
return c_0 || c_1 || ... || c_l
```

```
LOOKUP(x):
t := SAMP()
return t
```

```
\mathcal{L}_{\text{samp-L}}
SAMP():
r \leftarrow \{0, 1\}^l
return r
```

Subroutine calls to LOOKUP and samp are inlined:

```
CTXT(m_1 || ... || m_l):
r \leftarrow \{0, 1\}^l
c_0 := r
for i = 1 to l:
  r \leftarrow \{0, 1\}^l
  c_i := r \oplus m_i
return c_0 || c_1 || ... || c_l
```

Finally, the one-time pad rule is applied within the for-loop (omitting some common steps). Note that in the previous hybrid, each value of _r_ is used _only once_ as a one-time pad. The _i_ = 0 case has also been absorbed into the for-loop. The result is \(\mathcal{L}_{\text{cpa\$-rand}}^{\text{OFB}}\), since OFB encrypts plaintexts of \(\ell\) blocks into \(\ell + 1\) blocks.

```
\mathcal{L}_{\text{cpa\$-rand}}^{\text{OFB}}
CTXT(m_1 || ... || m_l):
for i = 0 to l:
  c_i \leftarrow \{0, 1\}^l
return c_0 || c_1 || ... || c_l
```

The sequence of hybrids shows that \(\mathcal{L}_{\text{cpa\$-real}}^{\text{OFB}} \approx \mathcal{L}_{\text{cpa\$-rand}}^{\text{OFB}}\), and so OFB mode has pseudorandom ciphertexts.

We proved the claim assuming _F_ is a PRF only, since OFB mode does not require _F_ to be invertible. Since we assume a PRF with parameters _in_ = _out_ = \(\lambda\), the PRP switching lemma (Lemma 6.7) shows that OFB is secure also when _F_ is a PRP with blocklength _n_ = \(\lambda\).
