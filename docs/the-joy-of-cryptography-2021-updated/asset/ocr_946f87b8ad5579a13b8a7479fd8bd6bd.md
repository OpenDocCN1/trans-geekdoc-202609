factoring out in this way is:

```
(pk, sk) ← Σ_pub.KeyGen
GETPK():
return pk
CHALLENGE(m_L, m_R):
tk' ← Σ_sym.KeyGen
c_pub ← Σ_pub.Enc(pk, tk')
c_sym ← CHALLENGE'(m_L, m_R)
return (c_pub, c_sym)
◇
L^{Σ_sym}_{ots-L}
CHALLENGE'(m_L, m_R):
tk ← Σ_sym.KeyGen
return Σ_sym.Enc(tk, m_L)
```

At this point, we can replace L_ots-L with L_ots-R. After this change the Σ_sym-ciphertext encrypts m_R instead of m_L. This is the “half-way point” of the proof, and the rest of the steps are a mirror image of what has come before. In summary: we inline L_ots-R, then we apply CPA security to replace the Σ_pub-encryption of tk' with tk. The result is exactly L_pk-cpa-R, as desired.
