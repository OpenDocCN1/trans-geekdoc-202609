other coefficients chosen uniformly in Z_p. The ith user receives the point (i, f(i) % p) on the polynomial. The interpolation theorem says that *any* t of the shares can uniquely determine the polynomial f, and hence recover the secret f(0).

```
Construction 3.11 (Shamir SSS)
M = Z_p
p : prime
n < p
t <= n

Share(m):
  f_1, ..., f_{t-1} <- Z_p
  f(x) := m + \sum_{j=1}^{t-1} f_j x^j
  for i = 1 to n:
    s_i := (i, f(i) % p)
  return s = (s_1, ..., s_n)

Reconstruct({s_i | i \in U}):
  f(x) := unique degree-(t - 1) polynomial mod p passing
  through points {s_i | i \in U}
  return f(0)
```

Correctness follows from the interpolation theorem.

# Example

Here is an example of 3-out-of-5 secret sharing over Z_11 (so p = 11). Suppose the secret being shared is m = 7 \in Z_11. The Share algorithm chooses a random degree-2 polynomial with constant coefficient 7.

Let's say that the remaining two coefficients are chosen as f_2 = 1 and f_1 = 4, resulting in the following polynomial:

```
f(x) = 1x^2 + 4x + 7
```

This is the same polynomial illustrated in the previous example:

![](bbox=[0.415, 0.565, 0.7, 0.64])

For each user i \in {1, ..., 5}, we distribute the share (i, f(i) % 11). These shares correspond to the highlighted points in the mod-11 picture above.

| user (i) | f(i) | share (i, f(i) % 11) |
|---|---|---|
| 1 | f(1) = 12 | (1, 1) |
| 2 | f(2) = 19 | (2, 8) |
| 3 | f(3) = 28 | (3, 6) |
| 4 | f(4) = 39 | (4, 6) |
| 5 | f(5) = 52 | (5, 8) |

Remember that this example illustrates just one possible execution of Share. Because Share is a randomized algorithm, there are many valid sharings of the same secret (induced by different choices of the highlighted coefficients in f).
