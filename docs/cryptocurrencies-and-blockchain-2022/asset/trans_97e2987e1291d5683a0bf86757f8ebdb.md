
# 比特币挖矿概述

几年前，许多人将挖矿（创建加密货币或比特币的过程）视为一种娱乐活动。许多人参与了这项活动，直到臭名昭著的“比特币买披萨”事件发生。对比特币世界的许多人来说，这一天被称为“比特币披萨日”。2010年5月22日，一位开发者向一位比特币论坛用户支付了10,000枚比特币，以换取两个披萨。当时，比特币几乎完全没有用处。对该用户来说，这两个披萨的成本约为25美元。写作时（2017年10月），一枚比特币价值超过5,000美元。不难算出，仅仅两个披萨就让那位先生损失了一百万美元甚至更多。

当比特币价值开始飙升时，这是它首次被大规模挖矿。首先，计算能力被用于比特币挖矿过程。后来，矿工开始使用显卡来打包区块，这变得越来越流行。现在他们使用称为ASIC（专用集成电路）的专用设备。中国目前拥有世界上最大规模的此类运营。

# 挖矿过程如何运作

加密货币或比特币挖矿是创建新加密货币或比特币的过程。让我们弄清楚挖矿过程是如何运作的。每当你进行一笔交易，例如从你的钱包向另一个人的钱包发送资金，你的交易就会被放入“内存池”。即比特币内存池，它是等待网络确认的所有交易的集合。矿工根据自己的标准，将交易收集到特定的区块中，然后尝试将它们纳入区块链。

每十分钟，区块链上就会生成一个新区块，以此类推。

矿工在成功挖出一个区块后会获得奖励。写作时，奖励是12枚比特币。也就是说，如果你成功将一个格式良好的区块引入系统，你将以这种方式获得奖励。此外，中本聪被认为创建了第一个区块（创世区块）。任何人都可能遇到它并以50枚比特币的价格卖给合适的人。截至今天，正确创建区块的奖励开始授予接收者。预计到2140年，它将降至微乎其微的价值。

矿工们终有一天会意识到，单独挖矿不再有利可图。你发现此类区块的可能性取决于“哈希率”，即你的比特币挖矿机的计算能力。例如，如果你的哈希率占整个网络哈希率的10%，那么在特定条件下，你将有10%的机会找到此类区块并获得奖励。因此，如果你只在家用笔记本电脑挖矿，你永远无法发现新区块。因此，为了获得更稳定的收益，矿工们联合起来组成了所谓的“矿池”。他们利用合并后的哈希率来产生更稳定的收入。

许多矿工现在都在自问：“既然我可以买比特币，为什么还要挖矿？”这也是一个绝妙的概念，因为比特币的价值完全由使用者的信念确立，而比特币的成本完全由对比特币的需求决定。如果没人从你手中购买比特币，对你来说就没有成本。因此，只要人们将这项技术视为进行匿名支付、大额支付等的手段，比特币的价值就会继续上涨。

我不会更详细地介绍比特币本身，因为我之前写过一本关于该主题的书，*《精通比特币：入门指南》*，专门讲述这个话题。目前，我将重点关注比特币的优势，这仍然引发一些问题。

主要优势是交易成本低。但重要的是要记住，比特币不适合小额支付。如果你向某人转账100万美元，不会花费你一分钱。如果你选择支付一杯咖啡的费用，手续费与咖啡成本相比将非常可观。

第二个优势是能够以快速的速度处理交易。也有一些缺点需要考虑。根据blockchain.org网站的数据，区块链中的每个区块每十分钟生成一次。

例如，最快的交易也需要十分钟。与需要2-4天的银行SWIFT转账相比，这似乎是一个相对快速的过程。另一方面，Visa和MasterCard要快得多。它们每单位时间处理交易的能力是比特币的数万倍。有其他几种加密货币被开发得比比特币更快，值得注意的是它们目前已可用。

第三个优势是人们可以以伪匿名的方式识别身份。我们已经发现，任何人都可以追踪网络上的所有交易，这我们已经调查过了。如果你知道谁拥有钱包以及钱包在哪里，你可以追踪其中发生的绝对所有交易。因此，不可能声称比特币是完全匿名的。一个人一旦能将其地址与其真实身份联系起来，其匿名性就被破坏了。然而，如果你遵守所谓的“网络卫生”，即不向任何人透露你的钱包，那么你的交易几乎不可能被追踪。虽然我应该指出还有其他比比特币更匿名的加密货币，但我不会详细介绍它们。

值得注意的是，如果你希望在比特币网络交易时保持匿名，这目前是可行的。有大量可用的选项来“清洗”你的比特币。它们被称为“混币服务”，用于将一个人的资金与其他人的比特币混合，以掩盖资金原始来源的踪迹。正如你所见，新技术已经出现，以进一步增加加密货币的匿名性。

最后，目前全球流通的比特币超过1600万枚，预计总共将挖出2100万枚比特币。网络算法本身负责设定这些数字。由于比特币供应受限，这种货币不可能变得越来越有价值。因为只会生产有限数量的单位，这种货币的价值不会随时间减少。比特币甚至具有通缩范式，因为许多用户因忘记钱包密码或将钱发送到错误的接收地址而丢失硬币。结果，比特币的总数最终将减少。

# 工作量证明及其重要性

以下是比特币网络面临的最紧迫问题：如何确保交易真实有效；如何确保矿工不欺骗任何人；以及为了选择合适的区块并真正构建区块链应该做什么。所有这些困难都通过共识机制的使用得以解决。

工作量证明协议确认矿工付出了大量努力，以找到合适的随机数并生成成功的哈希值。你必须付出大量努力才能找到正确的那个。我稍后会更详细地介绍。
