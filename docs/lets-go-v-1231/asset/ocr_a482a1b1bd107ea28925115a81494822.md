# Template composition

As we add more pages to our web application, there will be some shared, boilerplate, HTML markup that we want to include on every page — like the header, navigation and metadata inside the <head> HTML element.

To prevent duplication and save typing, it’s a good idea to create a _base_ (or _master_) template which contains this shared content, which we can then compose with the page-specific markup for the individual pages.
