# HTTP/2 connections

A big plus of using HTTPS is that Go's will automatically upgrade the connection to use
HTTP/2 if the client supports it.

This is good because it means that, ultimately, our pages will load faster for users. If you're
not familiar with HTTP/2 you can get a run-down of the basics and a flavor of how it has
been implemented behind the scenes in Go in this GoSF meetup talk by Brad Fitzpatrick.

If you're using an up-to-date version of Firefox you should be able to see this in action.
Press Ctrl+Shift+E to open the Developer Tools, and if you look at the headers for the
homepage you should see that the protocol being used is HTTP/2.
