Because the `id` value is untrusted user input, we should validate it to make sure it’s sane
and sensible before we use it. For the purpose of our application we want to check that the
`id` value contains a positive integer, which we can do by trying to convert the string value to
an integer with the `strconv.Atoi()` function and then checking that the value is greater
than zero.

	// Extract the value of the id wildcard from the request using r.PathValue()
	// and try to convert it to an integer using the strconv.Atoi() function. If
	// it can't be converted to an integer, or the value is less than 1, we
	// return a 404 page not found response.
	id, err := strconv.Atoi(r.PathValue("id"))
	if err != nil || id < 1 {
