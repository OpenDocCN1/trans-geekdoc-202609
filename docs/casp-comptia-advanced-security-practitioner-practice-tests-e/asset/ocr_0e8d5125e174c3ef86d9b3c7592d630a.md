+   158. D. Deep packet inspection is the process of inspecting the payload of a packet for malicious content. Other packet inspection techniques only check the header information for signs of malicious activity. The main techniques used for deep packet inspection include either pattern or signature matching. The data evaluated by the deep packet inspection provides a more robust mechanism for enforcing network packet filtering, as DPI can be used to identify and block a range of complex threats hiding in network data streams, including malware or data exfiltration, more accurately.
