+   85. D. Security marking uses human-readable labels. Security labeling is the use of security attributes for internal data structure inside information systems. +   86. C. A covert channel is a type of computer attack that enables information to be leaked through existing information channels or networks using the existing structure. It has been used to steal sensitive data by using some of the space available within network packets, enabling the attacker to receive the data without leaving a data trail. A packet may have only a single bit of the covert data, making it nearly impossible to detect. A primary way of defending against covert channels is to examine source code and monitor resource usage by critical systems.
