- 231. A. 连接跟踪是许多网络服务和应用的基础。Conntrack 本质上是一张表，用于维护主机上所有入站和出站连接（也称为会话）的信息。保持合理数量的 conntrack 会话很重要。在高峰使用期间，服务器可能会短暂超过这个数量。

- 233. D. 互联网中充斥着想要更改、编辑或删除正在传输数据的攻击者。无法保证接收方会在不被任何篡改的情况下收到准确的消息。哈希是一种确保完整性并确保另一端接收到正确数据的方法。消息摘要的应用包括验证是否接收到正确的数据。发起方使用经过数字签名的私钥创建哈希值并将其发送出去。接收方使用公钥解密消息来在其端检查该值。然后，接收方在自己的系统上创建摘要并将其与原始值进行比较。

- 234. A. 运行 $ sha256sum /dev/cdrom 后，你会将计算出的哈希值与供应商针对 ISO 文件提供的哈希值进行比较。sha256sum 旨在使用 SHA-256（SHA-2 家族，摘要长度为 256 位）来验证数据完整性。正确使用的 SHA-256 哈希可以验证文件的完整性和真实性。SHA-256 的作用与 Ubuntu 此前推荐的 MD5 算法类似，但它不太容易受到攻击。比较哈希值可以检测文件中可能导致错误的更改。

- 235. C. ssdeep 是一个用于计算上下文触发分段哈希（CTPH）的程序。CTPH 也被称为模糊哈希，它可以匹配那些按相同顺序包含相同字节序列的输入，尽管这些序列之间的字节在内容和长度上可能不同。ssdeep 试图自动化对类似恶意软件进行分组的过程。模糊哈希函数对更改具有一定的容忍度，并可以通过比较其输出的相似性来判断两个文件有多么不同。

- 237. A. nmap 最酷的功能之一是使用 -O 选项进行远程操作系统检测。它会向系统发送 TCP 和 UDP 数据包，并查看该系统的响应。它会检查包含 2,600 多个已知操作系统的数据库，并共享结果。

- 241. C. Scalpel 文件雕刻工具基于模式识别，用于描述特定文件或数据碎片类型。模式可以基于二进制字符串或正则表达式。你可以在随发行版附带的配置文件 scalpel.conf 中找到默认模式的数量。总的来说，它是处理大量数据的非常出色的数据雕刻工具。

## 第 3 章：安全工程与密码学

- 1. A. 移动设备代表最薄弱的安全环节。每台移动设备都代表攻击者潜在的攻击向量。即使有密码、面部识别、指纹扫描仪和远程擦除功能，BYOD 对许多组织来说仍然是一个漏洞。

- 2. C. 许多人将 USB 视为被动存储，但实际上它是传播恶意软件的最佳载体之一。许多渗透测试人员使用 USB 类型的攻击，因为他们知道最终用户不了解其后果。

- 3. C. 在更换核心旧设备时确立安全要求后，这些要求需要上报并传达给项目中的所有利益相关者。

- 4. A. Hashcat 是一种快速的密码破解（或恢复）工具。你可以进行直接和暴力破解，以及反向掩码和字典攻击。Hashcat 获取一个密码，对其进行哈希处理，然后将生成的哈希值与正在尝试破解的哈希值进行比较。如果哈希值匹配，我们就知道密码了。如果你感到好奇，请访问 https://www.scr1py.com/data/wordlists/dictionaries/rockyou.txt，你会在那里找到一个包含 1400 万个密码的列表，Hashcat 可以用这些密码启动哈希过程。请再次检查你的密码不在这个列表中。

- 5. A. 有许多方法可以保护个人身份信息（PII）。你可以使用加密、强密码、MFA 和备份。你还需要制定政策，规定保留个人信息的时间、系统更新的频率，以及在处理 PII 时始终使用安全的无线网络。

- 6. A. 每次访问尝试都必须生成新令牌。当应用程序意外将会话令牌与恶意攻击者共享时，就会发生会话处理不当，这使攻击者能够冒充合法用户。
