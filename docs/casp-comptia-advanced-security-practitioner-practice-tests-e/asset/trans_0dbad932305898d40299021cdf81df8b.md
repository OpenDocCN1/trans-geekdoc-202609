- 50. B. 网络漏洞扫描主要有两种方法：主动扫描和被动扫描。主动扫描工具用于需要持续警惕的场景。它们具有产品编程用于监控的特定关注领域。被动方法允许安全人员监控正在使用的操作系统、正在发送到、来自以及在系统内传输的内容；可用的服务；以及系统哪些部分可能易受安全威胁。主动方法可提供关于系统和应用程序漏洞的大量信息。两种方法都可以在同一环境中使用。带凭证扫描和非凭证扫描是指在扫描过程中使用用户名/密码登录系统。

- 51. B. 安全内容自动化协议（SCAP）用于标准化自动化漏洞管理、度量和策略合规性。可扩展配置清单描述格式（XCCDF）是用于清单和基准的规范语言。开放漏洞和评估语言（OVAL）是用于报告计算机状态的标准化语言。通用平台枚举（CPE）字典是系统和软件的结构化命名方案。该字典以 XML 格式提供，并向公众开放。

- 52. D. 安全内容自动化协议（SCAP）是一种开放标准，用于查找与安全和合规性相关的安全缺陷和配置问题。SCAP 规范标准化了漏洞管理和策略合规性所使用的命名约定和格式。SCAP 清单标准化了计算机安全配置以及 SP 800-53 控制框架。HTTP（超文本传输协议）是一种应用层协议，旨在用于浏览器与 Web 服务器之间的通信。资产报告格式（ARF）是一种数据模型，有助于报告、关联和融合资产信息。NIST 最后一次发布 ARF 是在 2011 年。CCE 曾是 MITRE 的一项工作，用于分配称为通用配置枚举的唯一条目，以配置指导语句和控制。截至 2014 年 11 月 28 日，根据 MITRE 网站： “CCE 工作已暂停，CCE 网站已移至‘存档’状态。”

- 53. A. 补丁管理的最佳策略是在将更新部署到生产环境之前，先在安全环境中测试所有更新。

- 54. D. 补丁管理系统可以自动化在系统上安装补丁的过程。自动化此过程可以增加所有系统都能打补丁且不会被错误遗漏的可能性。安全评估用于识别组织当前的安全态势。漏洞管理是识别、评估、处理和报告安全漏洞的持续过程。漏洞扫描器扫描网络，查找并报告已知漏洞。

- 55. D. 通过强化系统使其仅提供所需功能，是缓解组织可能面临的任何零日问题的最佳方法。零日漏洞没有修复方案。系统强化涉及删除任何不需要的服务或应用程序。

- 56. A. 信息共享与分析中心（ISAC）帮助关键基础设施所有者和运营商保护其设施、人员和客户免受网络和物理安全威胁以及其他危害。ISAC 向其成员收集、分析和传播可操作的威胁信息，并为成员提供工具来降低风险并增强韧性。通过挪用组织的特定标签，机器人可以分发垃圾邮件或恶意链接，这些链接将出现在组织的圈子中。趋势劫持（Trend-jack）类似，攻击者会选择当天的热门趋势来传播攻击，制造“社交媒体水坑”，并在潜在用户聚集的地方植入有效载荷。

- 57. D. 动态应用程序安全测试（DAST）由开发人员用于在运行时分析应用程序，以识别任何安全漏洞或弱点。DAST 在应用程序运行时对其进行检查，并尝试像攻击者一样对其进行攻击。静态应用程序安全测试（SAST）应尽早且经常针对所有包含源代码的文件执行，以查找 SQL 注入等缺陷和弱点。逆向工程是拆解一个对象以查看其工作原理，从而复制或改进它。侧信道分析允许攻击者通过观察程序的非功能特性（如执行时间或消耗的内存）来推断信息。

- 58. A. 购买硬件时，您无法控制硬件的设计和制造过程。因此，必须从经过审查且负责任的供应商处购买硬件。2018 年 12 月，研究人员发现了一种名为 Lojack 的 UEFI 根套件，该工具被全球 APT 组织使用。Lojack 利用固件供应商，实现了固件的远程刷写。

- 59. B. 简单模糊测试工具可以向软件提供完全随机的输入，没有智能来测试漏洞。有时，程序只有在有特定输入（例如协议定义或文件格式规则）的情况下才会执行某些过程。这允许有效输入，即智能模糊测试工具。

- 60. A. 网络分析很可能始于使用 Splunk、QRadar 或 AlienVault 等 SIEM 工具审查 Web 服务器日志。网络分析可以在实时流量或记录在日志文件中的日志上进行。怀疑 Web 服务器已遭受攻击的分析人员应获取然后分析日志，以确定攻击者是否、何时以及如何获得访问权限。硬件分析是对电气或机电设备的检查，这些设备通常包含固件或嵌入式软件。软件成分分析（SCA）是应用程序安全测试（AST）的一个分支，涉及管理开源组件的使用。SCA 工具对应用程序代码库（包括容器和注册表）进行自动化扫描，以识别所有开源组件和任何安全漏洞。

- 61. B. 跳板是渗透测试人员（和攻击者）用于更深入地攻破网络的一种方法。初始攻破后，攻击者可以利用网络上的该系统攻击其他系统，以避免网络检测、防火墙规则或 IDS。在 Metasploit 中，您可以创建代理跳板和 VPN 跳板以扩大攻击。

- 62. D. 存在多种网络攻击模型，包括 Mandiant 攻击模型和洛克希德·马丁的网络杀伤链。大多数步骤在性质上非常相似。侦察尝试识别目标网络中的漏洞。持久性是指攻击者创建后门或替代访问方法，以防其首次入侵被检测到。武器化是创建像病毒或蠕虫一样的远程访问。后利用是指在成功利用或暴力破解攻击开启会话后采取的任何行动。

- 63. D. 安全内容自动化协议（SCAP，发音为“ess-cap”）当前版本为 1.3。SCAP 是一组广泛使用的开放标准，用于枚举与安全相关的软件和配置问题。这些规范有助于标准化策略合规性所使用的格式。

- 64. A. 组织可以轻松控制其漏洞管理生命周期，以便在特定时间扫描特定资产。桌面演练是对政策和程序的模拟运行，用于预测组织应对事件或事故的准备情况。沙箱是一种用于执行可疑代码而不冒设备或网络受损风险的过程，这可以增加针对可能恶意软件的另一层防护。社交工程是一种欺骗行为，用于操纵用户共享可用于不法目的的信息。

- 65. C. 在 Windows 服务器上，nbstat 显示 NetBIOS over TCP/IP (NetBT) 统计信息。NetBIOS 显示本地和远程计算机的表格。它刷新与 Windows Internet 名称服务 (WINS) 注册的名称。

- 66. B. 域名系统（DNS）同时对 TCP 和 UDP 使用端口 53。TCP 用于 DNS 区域传输，UDP 用于 DNS 查询。动态主机配置协议（DHCP）是一种网络管理协议，用于自动化配置 IP 网络上设备的过程，使其能够使用 DNS、NTP 以及任何基于 UDP 或 TCP 的通信协议等网络服务。DHCP 服务器动态地为网络上的每个设备分配 IP 地址和其他网络配置参数，以便它们可以与其他 IP 网络通信。DHCP 可以在端口 67–68 上运行。互联网消息访问协议（IMAP）是一种互联网标准协议，电子邮件客户端使用它通过 TCP/IP 连接（通常是端口 143）从邮件服务器检索电子邮件消息。超文本传输安全协议（HTTPS）是超文本传输协议的扩展。它用于计算机网络上的安全通信，并在互联网上广泛使用，端口为 443。

- 67. B. 像 PortSwigger 的 BurpSuite 这样的 HTTP 或 HTTPS 拦截器是目前进行 Web 应用程序评估的最佳工具之一。您可以读取和操纵 Web 流量。此外，您可以扫描目标计算机；中断流量流；以及操纵、修改和转发信息。

- 69. D. 白盒白帽渗透测试意味着好人了解公司的网络、硬件和软件以及政策和程序的所有内容。这将包含在工作范围内。交战规则（RoE）是一份规定渗透测试应如何进行的文件。在开始渗透测试之前，应在 RoE 中明确列出的一些指令包括客户联系信息、敏感数据处理和状态报告。由于它是白盒白帽测试，也可以包括资产列表。不会包含的是渗透测试人员在交战期间将使用的恶意软件。
