76. A. By default, LDAP communication between client and server is not encrypted. This means it would be possible to capture traffic and view the information between client and server, which can be dangerous when transmitting usernames and passwords. LDAPS adds SSL encryption.

77. D. Software-defined networking (SDN) divides the function of a network device like a router or switch into planes. The control plane consists of the programmable (i.e., controlled) function of the network device. This function is separated from the network device and placed on a controller. The data plane consists of the core function of the networking device. In the case of a router, the data plane is concerned with the forwarding of data. The data plane remains on the router. The control plane communicates with the data plane to perform the overall function of the router.
