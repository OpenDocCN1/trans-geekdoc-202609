- 92. C. Zigbee 是基于 IEEE 802.15.4 的规范，用于创建个人区域网络。Zigbee 旨在用于需要无线、低功耗和短距离控制的消费和工业设备。控制器区域网络（CAN）由博世于 1985 年开发，用于车载网络，当时制造商开始使用更多电子设备。分布式网络协议（DNP3）是电力公司用于智能电子设备与站点之间基于标准的互操作性规范。通用工业协议（CIP）是一组用于工业自动化应用（如控制、运动和同步）的标准。

- 93. D. 数据分发服务（DDS）使消息/数据发布者及其关联订阅者之间能够进行数据、事件、命令和其他相关通信。通常，它在分布式计算应用程序（如金融、交易或大数据）中实现，这些应用依赖于所有参与节点之间及时高效的通信传递。DDS 通过为发布者和订阅者提供可扩展、高性能且实时的交互来工作。它完全消除了处理通信所需的网络编程，因为所有连接的节点和应用程序都依赖 DDS，而 DDS 自动化了它们的交互。

- 94. C. 虚拟化创建一个抽象计算平台。许多服务器可以由一台更大的物理服务器取代，以减少对硬件的需求。许多主机支持完整操作系统的执行，并且出于安全考虑，可以根据主机创建的硬件访问策略限制访问。在此场景中，以保密性为重点的最安全选项是将虚拟主机分配给客户端并对存储进行物理分区。如果问题涉及保密性，请在答案中寻找加密。

- 95. D. 当您将文件拖入回收站并清空回收站时，它并不会真正擦除该文件。它只是向文件系统指示该文件已被删除，但文件中的数据仍留在硬盘上，直到文件系统最终覆盖该文件。我们将此问题称为数据残留。云计算使数据残留问题更加复杂。您对云中数据的物理位置几乎没有或完全没有可见性，因此覆盖物理介质几乎是不可能的。云基础架构可能会将您的存储或虚拟机实例分布在多个物理驱动器上。取消预配该实例类似于将其拖入回收站。写入各种驱动器的数据将保留，直到云提供商将您正在使用的扇区重新分配给其他客户。

- 102. C. 业务影响分析（BIA）是一个过程，用于识别业务中的关键功能，并预测如果发生中断，最终结果将是什么。潜在影响包括数据或备份、设备和收入的损失，人员流失、声誉受损以及其他类型的业务损失。业务影响分析是制定灾难恢复（DR）计划的重要阶段，该计划将确保在重大中断期间公司基础架构和应用程序的运行。一份全面的灾难恢复 BIA 报告是制定应急响应策略所需的最关键要素之一。

- 103. D. IP 安全（IPSec）是一套用于 IP 网络的协议，用于提供身份验证、完整性和保密性。这包括认证头（AH）、安全有效载荷（ESP）和安全关联（SA），它们为这些连接提供不同的配置和密钥。互联网安全关联和密钥管理协议（ISAKMP）是 SA 的一个组成部分，用于确定设备之间密钥的管理和交换方式。IPSec VPN 将保护从客户端到服务器或从服务器到服务器转发的流量。

- 112. B. 数据分散并存储在多个云存储池中是云存储架构的关键组件。在分布式存储基础架构中复制数据的能力至关重要。这使云服务提供商能够根据用户订阅级别或项目的受欢迎程度提供存储服务。位分割是保护计算机网络上数据的另一种技术，它涉及加密数据、将加密数据分割为更小的数据单元、将这些较小的单元分发到不同的存储位置，然后在新位置进一步加密数据。数据免受安全漏洞的影响，因为即使攻击者能够检索并解密一个数据单元，除非该信息可以与其他位置的解密数据单元结合，否则信息将毫无用处。
