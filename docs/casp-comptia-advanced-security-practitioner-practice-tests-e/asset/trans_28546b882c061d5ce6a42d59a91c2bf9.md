- 80. B. Network Mapper (Nmap) 是最流行的网络发现和端口扫描器。它是免费开源的，被许多系统管理员和网络工程师用于审计本地和远程网络。端口扫描会按顺序向目标计算机的每个端口发送连接请求，并记录哪些端口有响应。软件定义网络（SDN）中控制平面与转发平面的分离是 SDN 技术的关键问题。它将 Nmap 实用程序的完整功能提供给网络管理员，管理员通过带外控制平面控制 SDN 网络。

- 81. A. 私有云、公有云或两者的结合取决于多种因素、用例、安全需求、合规性和限制。随着组织的成长和演变，将使用所有三种云解决方案。

- 82. A. 大多数攻击者追求垂直特权提升，即低权限用户或应用程序访问保留给高权限用户的功能。聪明的攻击者也使用水平特权提升，即普通用户访问另一普通用户的某些功能。水平特权提升可窃取大量信息，但很少被监控。

- 83. D. 要战略性地思考！在恢复任何关键任务功能之前，需要先测试重建站点的弹性和可靠性。只有在确定基础良好后，才会恢复财务部门和通信。

- 84. B. 如果只有一台主防火墙，则存在单点故障（SPoF），这对高可用性（HA）网络可能是灾难性的。如果所有流量都必须通过单一点且该点失败，则无法进行任何通信。集群服务器、高速冗余链路和交换网络均通过提供性能和可靠性来支持高可用性。

- 85. B. 异构计算是指使用不止一种处理器或内核的系统。这类系统通过添加不同的协处理器来获得性能和/或效率，通常包含专门的处理能力来处理特定任务。这类系统也被称为“多样化”芯片组。

- 86. D. 你可能没有听说过协作自动行动方案运营（CACAO），但你可能很熟悉手册（playbook）。波纳蒙研究所2020年夏天的研究指出，网络攻击的数量和严重程度仍在上升，要创造弹性，采用全公司范围的网络安全事件响应手册将有助于指导企业应对攻击。

- 87. D. 网络威胁情报对每个组织都极为有利。然而，在列出的选项中，它对你的营销计划帮助最小。正确应用时，它可以提供网络威胁的洞察，从而实现更快速的响应以及资源分配和分发。

- 88. A. 并非所有供应商都提供配备多电源和远程备份的安全数据中心环境。有些供应商会削减成本并将风险转嫁给你，即客户。如果因任何原因发生设备故障，这种风险可能导致你不符合合规要求。

- 89. A. 大多数公司使用 125 kHz 卡作为带电锁门禁门的凭证。这些卡没有加密或身份验证，当任何读卡器在附近时都会广播公司信息，这使得拥有合适设备的任何人都可以轻松复制这些卡片。

- 90. D. 最大的安全风险是，多个虚拟机（VM）使用相同的传输可能会导致数据库敏感数据及其客户抵押贷款申请信息暴露。

- 91. B. 大多数企业使用三种预配置类型。自助预配置是指云客户向供应商提交在线服务请求。这种安排通常成本最高。另一种是预先预配置，即签订合同按单位时间分配一定数量的资源，客户可获得折扣价格。最后一种是动态预配置。在此模型中，客户按需动态接收请求级别的资源。当客户需要更多资源时，供应商提供；当客户需要更少资源时，供应商收回部分资源。该模型也称为自动伸缩（autoscaling）。

- 92. B. 变更申请、编目、排期和实施均属于变更控制流程的一部分。变更应尽可能以最有组织的方式进行。漏洞管理工具会扫描组织中的硬件、操作系统和软件，查找漏洞。安全信息和事件管理工具会消化和分析日志，并发出警报。自动化是使用脚本、程序或批处理以尽可能少的人工交互来执行任务。

- 93. A. SOAR 代表安全编排、自动化和响应。它由一组技术组成，使企业能够收集由安全团队监控的数据。SOAR 工具帮助组织在数字工作流中定义事件分析和响应程序。

- 94. A. 容器的速度、敏捷性和可移植性使其成为简化软件开发的绝佳工具，这也可称为引导式开发。引导式开发可以指开发逐渐更复杂、更快速的编程环境。

- 95. D. 通过容器化，优势包括减少 IT 管理资源、加快应用程序部署、减少需要移动的代码、更容易部署的安全更新，以及大幅减小的快照大小。

- 96. B. 在运行需要操作系统所有资源和功能的应用程序、在服务器上运行多个程序或需要管理多个操作系统时，虚拟机（VM）是绝佳选择。当需要在最少数量的资产上运行最大数量的应用程序时，容器更合适。其他所有答案都相反。

- 97. C. 标准的加固做法是关闭任何未使用的服务。如果某个功能未使用，请不要启用它。如果你使用 UC 服务器进行语音、视频和即时通信，但不使用电子邮件，则应关闭电子邮件功能。这样会减少协议流量，服务器工作量也会降低。

- 98. A. 代理可以被视为中间人，所有流量都从主机通过代理流出到网络其余部分或互联网。由于流量通过代理，代理可以检查数据中的恶意活动。它还可以通过缓存已请求的数据并在需要时提供给其他用户来帮助节省带宽。

- 99. D. CDN（内容分发网络）是代理服务器及其数据中心的地理分布式网络。其目标是通过相对于终端用户空间分布服务来提供高可用性和性能。如果针对 CDN 中的服务器发起 DDoS 攻击，且服务器资源不足以抵御攻击，则服务器可能无法承受攻击。但是，如果针对实现了负载均衡技术的服务器发起 DDoS 攻击，攻击可以分布到多个服务器上，通过将攻击分散到多个服务器来减轻对单个服务器的影响。

- 100. A. 配置基线是为系统配置基础配置的过程，该配置包括基本功能，在此情况下还包括基本安全级别。从此基线（也称为 *黄金镜像*）开始，可以添加其他功能。

- 101. A. Alexa 的语音功能和录音是否符合 HIPAA 或 PCI 合规性？如果 Google、Siri 或 Alexa 正在监听机密业务或患者讨论，结果对医院可能是灾难性的。

- 102. C. 选项 C 不是最佳实践。选项 A、B 和 D 是云提供商 *应* 执行的操作。

- 103. D. 容器 *并非* 沙箱。如果攻击者获得对容器的访问权限，则存在容器逃逸的风险。如果他们获得对主机的访问权限，则可以访问主机上的所有其他容器，这就是为什么必须在容器上部署安全控制的原因。

- 106. B. 通常，应用程序封装是通过使用软件开发工具包（SDK）来执行的，它使开发人员能够管理管理策略。这包括控制谁可以下载移动应用程序，以及该应用程序访问的数据是否可以复制和粘贴。

- 107. B. 设置 API 访问和密钥对是最常用的选项。密钥对提供 API 访问权限并为每个个人提供一个密令。如果访问密钥和密钥不匹配，你将无法访问。大型企业组织和应用程序使用此方法进行用户验证。
