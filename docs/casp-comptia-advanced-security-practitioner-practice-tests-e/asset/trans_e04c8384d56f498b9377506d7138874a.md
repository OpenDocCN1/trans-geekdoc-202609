32. D. 分析师使用 NetFlow 协议作为网络流量分析器，以确定流量在网络上的源点、目的地、卷量和路径。在 NetFlow 出现之前，网络工程师和管理员使用简单网络管理协议（SNMP）进行网络流量分析和监控。SNMP 对网络监控有效，但无法提供带宽使用情况的洞察。NetFlow 现在是互联网工程任务组（IETF）标准的一部分，该协议已被网络设备供应商广泛实现。

34. D. 文件完整性监控（FIM）之所以存在，是因为 IT 部门中的变更是持续不断的。FIM 监控并检测文件中的变更，这些变更可能表明已发生安全漏洞。FIM 是一项关键安全控制，涉及检查文件以查看谁在何时、如何修改了文件，以及这些修改是否经过授权。FIM 还可用于检测可疑修改和恶意软件。某些合规法规（如 PCI DSS）要求使用 FIM。

46. A. 漏洞是系统设计、流程或代码中的弱点。威胁可利用漏洞来破坏、损坏或妥协资产。威胁是漏洞被利用的情况或可能性。威胁的可能性是指事件发生的概率或其实际发生的几率。使用 Nexpose 或 Nessus 等漏洞扫描器可帮助您发现并修复漏洞。使用威胁情报可帮助您识别威胁态势。

47. C. 网络可以由大量硬件和软件构成。当您尝试连接两个异构网络时，由于两个独立实体合并为一体，可能会出现连接、延迟和漏洞等诸多问题。在进行任何技术变更之前，应对两个网络进行检查和记录，并执行风险分析，起点是进行凭证漏洞扫描。凭证扫描允许漏洞扫描工具登录并获取更多信息，例如操作系统版本、补丁级别和已安装软件，以及系统上保留的默认密码等配置错误。非凭证扫描无法做到这一点。它会对操作系统做出合理猜测，通过猜测机器对 TCP/UDP 数据包的响应来从外部查看该机器。

48. A. 许多漏洞扫描器提供基于代理的扫描，而非基于服务器的扫描。一小段软件安装在要带回家的笔记本电脑上，可以直接将信息发回漏洞扫描软件。由于它使用管理凭据安装在硬盘上，因此充当凭证扫描。基于服务器的扫描最适合保持固定的资产。
