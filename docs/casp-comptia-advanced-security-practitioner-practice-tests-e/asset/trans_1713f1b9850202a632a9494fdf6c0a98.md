- 139. A. HMAC是一种带键的数据哈希。HMAC代表基于密钥的消息身份验证。它是通过在数据（待验证）和共享密钥上运行加密哈希函数（如MD5、SHA1和SHA256）创建的消息身份验证代码。HMAC与数字签名类似。两者都强制执行完整性和真实性。两者都使用加密密钥，并且都使用哈希函数。主要区别在于数字签名使用非对称密钥，而HMAC使用对称密钥。HMAC还提供抗冲突性。要生成HMAC，您需要一个密钥。如果您只将此密钥与受信任各方共享，给定HMAC签名，您可以确信只有受信任方之一可能生成了该签名。
