- 124. B. 全互连网络配置为网络提供了最大冗余，在此情况下，所有网络设备（位于核心层）相互连接。如果某个设备故障，网络流量始终可以找到另一条路径到达其目的地。大多数用户不需要静态 IP 地址。当外部设备或网站需要记住您的 IP 地址时，静态 IP 地址通常更重要。一个示例是 VPN 或其他远程访问解决方案出于安全目的信任（白名单）某些 IP 地址。如果您在托管服务器，则不需要静态 IP 地址，尽管它可以简化设置过程。大多数设备使用动态 IP 地址，这些地址在连接时由网络分配并会随时间变化。

- 127. A. 在安全信息和事件管理（SIEM）工具中，您可以获得关于网络硬件、服务器和应用程序中发生情况的近实时警报和分析。它通过捕获所有这些设备的日志、聚合数据、关联数据、查找共同点，并将超出正常范围的事件关联起来来实现这一目标。QRadar、ArcSight 和 Splunk 是领先的 SIEM 厂商。

- 128. A. 数据库活动监控（DAM）监控数据库并分析其上发生的活动类型。DAM 类似于 SIEM，但不同之处在于 DAM 专门关注数据库，而 SIEM 关注各种网络设备。
