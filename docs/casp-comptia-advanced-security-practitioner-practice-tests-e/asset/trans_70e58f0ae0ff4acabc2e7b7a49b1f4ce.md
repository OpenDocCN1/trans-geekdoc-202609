- 99. A. HTML 5 是超文本标记语言 (Hypertext Markup Language, HTML) 的修订版，HTML 是描述网页内容和外观的标准编程语言。HTML5 的开发旨在解决影响当前标准 HTML4 的兼容性问题。HTML5 与该标准早期版本之间最大的差异之一是，HTML 的旧版本需要专有插件和 API。这就是为什么在一个浏览器中构建和测试的网页可能无法在另一个浏览器中正确加载的原因。HTML5 提供了一个通用接口来简化元素加载，因此在 HTML5 中不需要安装 Flash 插件，因为元素会自行运行。HTML5 是一种定义网页内容行为并鼓励更具互操作性的实现的解决方案。

- 100. C. - 101. C. 简单对象访问协议 (Simple Object Access Protocol, SOAP) 正是这样——简单。它被用作一种消息协议，用于通过具有不同协议和操作系统的 Web 服务交换信息。这使开发人员能够使用可扩展标记语言 (Extensible Markup Language, XML) 进行身份验证、授权和通信。

- 102. B. 机器码是一组可直接被机器理解并由中央处理器 (CPU) 处理的指令。机器码采用二进制 (0 和 1) 格式，与字节码和源代码完全不同。它被视为源代码的最低级别表示形式。机器码在编译或解释后获得。它也称为机器语言。字节码是源代码和机器码之间的中间代码。它是一种低级代码，是用高级语言编写的源代码编译后的结果。

- 103. A. XSS 是一种可以通过使用输入验证和清理来缓解的攻击。与 XSRF 攻击类似，XSS 攻击试图从用户那里窃取信息。如果 Web 应用程序无法正确清理用户输入，攻击者可以使用表单输入注入恶意代码。

- 104. A. 当浏览器加载该页面时，受害者的浏览器会使用初始登录的合法 Cookie 发出请求。跨站请求伪造（也称为一次点击攻击或会话骑行，缩写为 CSRF 或 XSRF）是一种恶意网站利用，其中 Web 应用程序信任的用户会提交未经授权的命令。跨站脚本攻击（也称为 XSS 攻击）针对的是嵌入页面并在客户端（用户的 Web 浏览器）而非服务器端执行的脚本。SQL 注入是一种 Web 安全漏洞，允许攻击者干扰应用程序对其数据库所做的查询。它通常允许攻击者查看其通常无法检索的数据。目录遍历攻击（也称为路径遍历攻击）使攻击者能够访问存储在根目录之外的文件、目录和命令。该攻击使用 "../" 特殊字符序列来更改 URL 中请求的资源位置。如果攻击者能够在网站上执行目录遍历，在某些情况下，他们可能能够读取或写入服务器上的任意文件，从而修改应用程序数据或行为，并最终完全控制服务器。

- 107. B. 以明文发送 LDAP 密码从来都不是个好主意，因为这使得能够嗅探网络流量的攻击者很容易窃取凭据。在大型组织中，识别并修复所有仍使用这种不安全 LDAP 方法的应用程序非常耗时。Microsoft 建议系统管理员在其域控制器上启用深入诊断日志记录以识别违规应用程序。这会产生大量噪音，可能会导致目录服务事件日志中出现大量事件。

- 108. C. Web 应用程序中的输入字段可能易受 SQL 注入影响。攻击者可以在输入字段中使用 SQL 命令来更改服务器上执行的语句。运行所示命令将执行以下 SQL 查询：SELECT id FROM users WHERE username='username' AND password=' password' OR 1=1; 。因为 OR 1=1 始终测试为真，攻击者将获得访问字段中传递用户名的帐户的权限。

- 112. D. VLAN 跳跃是一种攻击，攻击者更改帧的 VLAN 标签，使攻击者的帧能够访问不同的 VLAN。要发起此攻击，攻击者必须在目标交换机端口和攻击者的系统之间建立中继链路。如果交换机端口配置为静态中继端口，或在端口上启用了动态中继协议 (Dynamic Trunking Protocol, DTP)，则可以建立中继链路。为防止此情况，请确保以太网端口仅配置为访问端口。DPT 是 DTP 的拼写错误。

- 113. C. 虚拟机逃逸是一种漏洞利用，攻击者可以在 VM 上运行代码，使操作系统能够直接与虚拟机监控程序交互。这种漏洞利用存在巨大风险。攻击者随后可能访问宿主操作系统以及在该宿主上运行的所有其他 VM。

- 114. C. SSL 和 TLS 提供的安全性有助于防止路径中间攻击（以前称为中间人 (MiTM) 攻击）。这些协议用于加密 TCP/IP 流量片段。路径中间攻击是指攻击者获得了在两个设备之间发送的流量的访问权限时发生的情况。如果数据未加密，攻击者可以查看所有流量。SSL 和 TLS 用于端口 443 上的 HTTPS。分布式拒绝服务 (DDoS) 攻击是指攻击者试图使服务无法提供。在 DoS 攻击中，是一个系统在发送恶意数据或请求；DDoS 攻击来自多个系统。这些攻击通过向系统发送大量数据请求来工作，例如向 Web 服务器发送大量页面请求，导致其在需求下崩溃。结果是可用 Internet 带宽、CPU 和 RAM 容量被压垮。VLAN 跳跃（虚拟局域网跳跃）是一种通过向给定终端系统通常无法访问的端口发送数据包来攻击网络的方法。边界网关协议 (BGP) 劫持是控制分配给潜在受害者的一组 IP 前缀的非法过程。无论是故意还是偶然，都是通过更改用于转发网络流量的路径，利用 BGP 的弱点实现的。
