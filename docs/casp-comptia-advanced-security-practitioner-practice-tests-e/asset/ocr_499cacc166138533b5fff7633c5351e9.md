There are basically two methods to do so: static analysis and dynamic analysis. Dynamic analysis is a detailed process of malware detection and analysis carried out in a controlled environment, and the whole process is monitored to observe the behavior of the malware. Static analysis is a process of determining the origin of malicious files to understand their behavior without actually executing the malware.
