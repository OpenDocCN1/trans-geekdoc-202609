- 39. D. 安全信息和事件管理（SIEM）监控网络上的服务器，理想情况下提供安全事件和事故的实时分析。SIEM（发音为“SIM”）可以通过硬件或软件来执行，方法是检查和关联服务器生成的日志。SIEM可用于监控来自IDS的警报并执行趋势分析。如果检测到异常，则会编写规则以通知安全管理员。
