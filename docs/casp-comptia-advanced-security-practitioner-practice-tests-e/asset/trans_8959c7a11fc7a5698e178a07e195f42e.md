- 186. B. 基于密码的密钥派生函数2（Password-Based Key Derivation Function 2，PBKDF2）是一种简单的加密密钥派生函数，能抵御字典攻击和彩虹表攻击。它基于在某些填充的情况下迭代多次推导HMAC。使用PBKDF2构建的密钥的组件为 `key = pbkdf2(password, salt, iterations-count, hash-function, derived-key-len)`。当今认为PBKDF2不如现代KDF函数安全，因此建议使用bcrypt或Argon2代替。

- 187. D. Bcrypt是一种具有内置盐值功能的哈希函数。MD5函数现在被认为非常不安全：凭借当前的处理能力，它很容易被逆转。SHA1、SHA256和SHA512函数也不再被认为安全。PBKDF2被认为是可接受的。此处列出的最安全的当前哈希函数是bcrypt。

- 191. D. 加密文件系统（Encrypting File System，EFS）是新技术文件系统（New Technology File System，NTFS）的一个组件。其他文件系统不支持EFS。
