# 第8章 基于组织病理图像的深度学习癌症诊断方法

在本章中，我们展示了一个深度迁移学习的示例。我们演示了如何利用深度迁移学习策略，作为克服数字病理学领域中遇到的肿瘤自动化诊断挑战的一种途径。通过若干实验，研究了用于图像分类的两种深度迁移学习策略。第一种策略是使用由预训练权重初始化的网络，并在新数据集上对其进行部分重新训练；第二种策略则是从预训练的CNN中提取特征，而不重新训练网络，并将这些特征用于训练第三方分类器。实验旨在比较基于深度迁移学习策略的不同CNN在从组织病理图像中对头颈部鳞状细胞癌（SCC）肿瘤进行分类方面的性能。共使用了1,424张组织病理图像来检测切片中的肿瘤细胞。在性能方面，这两种策略均在组织病理图像上进行了彻底的比较。

在此，我们比较了基于迁移学习并通过微调网络的不同CNN的性能。我们展示了八种不同CNN——AlexNet、VGG16、VGG 19、GoogLeNet、Inception-V3、ResNet-50、ResNet-101和InceptionResNet-V2——的实验结果。这是通过微调这些预训练的CNN，并替换为1000个类别配置的全连接层来完成的。新增用于二分类的层，然后在头颈部鳞状细胞癌（HNSCC）肿瘤图像上对其进行部分重新训练。

## 简介

在病理实验室中，组织被切片、染色并装载在玻璃载玻片上，随后放入数字扫描仪进行全切片成像（WSI），并可在不同放大倍数下进行可视化。得益于医学扫描技术的进步，有可能生成大量数字玻璃切片，这些切片通过扫描系统，且可包含多种不同的染色技术和不同种类的组织。因此，组织外观的多样性及其数量要求一种高效的计算机视觉方法，这是组织病理图像分析中最困难的挑战。组织外观的多样性主要源于组织制备和染色过程条件的差异。另一个挑战是缺乏数字化切片的标注数据。确实，这些标注需要专家病理学家完成，因此难以获取。

与此同时，基于深度学习技术的计算机辅助诊断（CAD）方法近期在数字病理学领域产生了显著影响，极大地提升了自然图像识别的性能。数字病理学的持续发展使得自动化图像分析方法能够辅助病理学家完成此类任务，并提高定量评估的可靠性。

### 病理学中的计算机辅助诊断

多年来，病理服务发生了显著变化，呈现出从传统病理方法向数字病理学显著转变的趋势。这种变化在国家和国际层面均有观察到。在英国，许多病理学领域的数字技术使用率不断上升。组织病理学等专业部门越来越多地利用数字图像，并结合条形码工具（用于标记和识别样本）等其他数字系统，以提高效率。此外，由于数字技术的本质允许国际协作（这通常因患者和病理学家的地理分布而变得必要），这种变化也在国际层面被观察到。

有几个因素促成了从传统病理学向数字病理学这一显著转变；即病理工作量的增加和病理工作人员的减少。英国癌症研究机构报告称，人口老龄化对病理工作量产生了重大影响。人口老龄化与癌症发病率之间存在显著关联。自2009年以来，全科医生转诊的疑似癌症病例数量每年增加了16%。此外，世界卫生组织（WHO）在2012年报告称，估计有1400万新增癌症病例，预计未来二十年将再增加70%，从而加大了对病理服务的压力。

随着对病理服务需求的增加，病理工作人员却在大幅减少。这同样可以在国家和国际层面观察到。英国癌症研究机构的报告指出，由于培训病理学家数量的减少，未来十年病理服务将受到重大影响。美国的研究也发现了类似结果。例如，在美国，预计未来20年工作病理学家的数量将大幅减少，降至每10万例病例仅3.7名病理学家。新入职病理学家数量与退休病理学家数量之间存在失衡。预计到2021年退休人数将激增，而入职人数仍保持低位。

由于工作病理学家数量的减少，传统病理方法（通常涉及邮寄玻璃切片进行会诊）会显著影响周转时间，即影响患者接收实验室结果所需的时间。因此，对更快、更高效的诊断方法（如计算机辅助诊断）的需求已成为重点关注领域。
