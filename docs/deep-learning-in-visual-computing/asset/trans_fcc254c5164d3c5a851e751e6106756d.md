
# 二元种族分类

这是一个二元种族分类 $E$，旨在尽可能准确地区分给定种族 $E[p]$ 与不属于该种族的另一人 $E[NP]$。假设 $x$ 代表属于一张人脸图像的多个数据点或特征。然而，在现实场景中，种族分类的输入数据可以基于全脸或部分人脸图像。在这种情况下，我们可以探索用于种族分类的全脸特征 $x^F$ 和部分人脸特征 $x^{(PF)}$。手工设计特征和深度学习特征均被纳入训练。该种族分类问题可定义为：

$$H(x) = \theta[0] + \theta[1]x, \quad x = x^{(F)} \cup x^{(PF)}, \tag{6.2}$$

其中 $H(x)$ 为预测函数，$\theta[0]$ 和 $\theta[1]$ 为常数值。目标应是找到 $\theta[0]$ 和 $\theta[1]$ 的最佳值，使预测器表现尽可能好。通过训练样本对预测器 $H(x)$ 进行优化。对于每个训练样本，我们都有一个输入值 $x_{train}$，其对应的输出 $y$ 预先已知。我们计算已知正确值 $y$ 与我们的预测值 $h(x_{train})$ 之间的差异。

有了足够的训练样本，这些差异提供了一种衡量 $H(x)$ “不准确度”的有效方法。然后，我们可以通过调整 $\theta[0]$ 和 $\theta[1]$ 的值来微调 $H(x)$，使其“错误更少”。此过程重复进行，直到系统收敛于 $\theta[0]$ 和 $\theta[1]$ 的最佳值。

## 数据集

巴基斯坦人脸数据库由英国布拉德福德大学的研究人员开发。从巴基斯坦人脸数据库中选取了 100 张巴基斯坦人图像和 100 张非巴基斯坦人图像。每张图像的种族是通过要求参与者自我认定其种族来确定的。对于巴基斯坦裔参与者，入选标准取决于其父母双方是否均为巴基斯坦族裔。

## 方法论

我们的方法是使用六个预训练机器学习模型提取鼻部特征：三个基于 VGG 的模型和三个基于深度学习的模型。所用模型包括 `VGG-Face`、`VGG-16`、`VGG-19`、`ResNet-50`、`ResNet-101` 和 `ResNet-152`，随后使用线性支持向量机进行判别性二分类。在以下数据集上总共进行了八组实验：
1. 2,200 个孤立鼻部裁剪图
2. 1,200 个孤立眼部和鼻部裁剪图
3. 1,200 个孤立鼻部和嘴部裁剪图
4. 1,200 个孤立嘴部和眼部裁剪图

### 数据预处理

实验中使用的所有图像均调整为 224 × 224 像素，以确保符合预训练模型的输入标准。此外，还对训练数据进行了数据增强，旋转角度包括向右 10 度、向左 10 度、90°、180° 和 270°，以及随机裁剪。这使得原始数据量至少增加了十二倍。

### 特征提取

各 ResNet 模型最后一个池化层的激活值被用于特征表示。

总共使用 `ResNet-50`、`ResNet-101` 和 `ResNet-152` 神经网络，每个实验检索了三组特征。我们决定排除全连接层（`FC`）的最后一个输出层，因为该层是在一组不同的数据（即物体）上训练的，而当前使用的是面部特征。此外，研究证明深度神经网络的较低层足以学习通用特征。

相应地，对于使用 `VGG-Face`、`VGG-16` 和 `VGG-19` 模型的 VGG 特征表示，我们使用了中间的全连接层（`FC7`），而舍弃了 `FC6` 和 `FC8`。

### 分类

在分别使用 `VGG-Face`、`VGG-16`、`VGG-19`、`ResNet-50`、`ResNet-101` 和 `ResNet-152` 模型进行基于机器学习的特征提取后，采用线性分类器进行两类种族分类。

支持向量机（SVM）是一种监督机器学习模型，其功能是识别一个超平面，以最佳方式对给定数据空间中的数据点进行分类。已发表的文献表明，SVM 是一种强大的二分类器，通过定义两类数据之间的最佳分离超平面来工作。

SVM 算法通过定义两类数据之间的最佳分离超平面对数据进行分类，这通常涉及解决一个优化问题。给定一个训练集：

$$\{(x_i, y_i)\}_{1 \le i \le n}, \quad x_i \in \mathbb{R}^d, \quad y_i \in \{+1, -1\}, \tag{6.3}$$

SVM 通过求解以下问题找到最优超平面：

$$
\begin{cases}
\min_{w,b} \frac{1}{2}\| w \|^2 \\
\text{subject to } y_i(w \cdot x + b) \ge 1
\end{cases} \tag{6.4}
$$

对于 $i = 1, \dots, n$ 个观测值，其中权重 $w$ 和偏置 $b$ 在训练过程中学习得到。分类器的学习使得 $y_i \in \{+1, -1\}$，其中 $+1$ 表示标记为巴基斯坦人的图像，$-1$ 表示非巴基斯坦人图像。采用 k 折交叉验证技术来评估预训练模型的性能。

## 实验结果

通过使用三个预训练深度学习模型 `ResNet-50`、`ResNet-101` 和 `ResNet-152` 从图像中提取特征，我们在包含 2,200 张鼻部图像的数据集上（实验 1），实现了巴基斯坦鼻部二分类准确率超过 90%，如[表 6.1](#13_ch6.xhtml#t6_1)所示。

相比之下，使用三个基于 VGG 的模型（即 `VGG-Face`、`VGG-16` 和 `VGG-19`）进行的实验，其结果彼此差异较大，且与 ResNet 模型相比本质上较低。性能准确率可直接与 ResNet 模型相比较，并证明了 VGG 的准确率低于 ResNet 的发现。这可能归因于 ResNet 模型被归类为极深度学习模型，其架构不同，据报道能产生更高的准确率。

**表 6.1：** 使用残差神经网络对巴基斯坦鼻部图像进行二分类的性能准确率。

| 特征提取模型 | 分类器 |
| :--- | :--- |
| | 线性支持向量机 (SVM) |
| **ResNet-50** | 94.1% |
| **ResNet-101** | 93.4% |
| **ResNet-152** | 93.6% |

**表 6.2：** 使用 VGG 模型对巴基斯坦鼻部图像进行二分类的性能准确率。

| 特征提取模型 | 分类器 |
| :--- | :--- |
| | 线性支持向量机 (SVM) |
| **VGG-16** | 90.8% |
| **VGG-19** | 87.5% |
| **VGG-Face** | 79.9% |

然而，如[表 6.2](#13_ch6.xhtml#t6_2)所示，`VGG-16` 在二分类任务中表现优于 `VGG-Face` 和 `VGG-19`。
