
# 实验结果与讨论

## 实验设置

八个预训练的 CNN 网络被用于输入四个分类器，性能结果见 [表 8.4](#15_ch8.xhtml#t8_4)。对于每个分类器，均使用不同八个预训练 CNN 的全连接层提取的特征进行训练。分类器使用线性函数作为核函数，并采用序列最小优化方法寻找分离超平面。我们将其平均核大小设置为 `2.0`。RF 分类器在每种方法生成的特征向量上使用 `50` 棵树进行训练。所有其他参数均未优化，均取自 R 语言中 RF 实现的标准参数。

## 讨论

在本章中，我们展示了如何通过实证研究各种深度迁移学习策略以分析病理组织学图像。实验表明，在微调网络策略下，`AlexNet` 和 `ResNet` 架构产生了表现最佳的模型。`SVM` 分类器是在特征提取器策略中表现最好的，其次是 `RF`。`AlexNet` 和 `ResNet101` 模型适合我们的图像数据集。

尽管图像数据集规模较小，但结果显示不同模型间均具有良好的准确率。`AlexNet` 模型实现了高度成功的分类，准确率达 `98.25%`，紧随其后的是 `ResNet50` 和 `ResNet101` 模型，准确率分别为 `97.89%` 和 `96.84%`。但 `VGG16`、`VGG19`、`GoogLeNet` 和 `IncV3` 的分类准确率接近，分别为 `95.44%`、`95.79%`、`95.09%` 和 `93.33%`，而 `IncResNet` 模型表现最差。

在比较八种方法的时间性能时，值得注意的是 Series Network 比 DAG Network 更快。`AlexNet` 速度最快，训练仅需 `15` 分钟，其次是 `VGG16`、`VGG19`、`GoogLeNet` 和 `ResNet50`。然而，`IncV2`、`ResNet101` 和 `IncResNetV3` 耗时较长（测试环境为 `2.2 GHz` 双核 `i7 CPU` 计算机）。

结果表明，`AlexNet`、`ResNet50` 和 `ResNet101` 的精确度没有显著差异。它们的正确分类率接近且较高，分别为 `98.74%`、`98.73%` 和 `98.72%`。尽管 `IncResNet` 模型的准确率和精确率与其他模型相比最差，但它拥有最高的灵敏度（召回率）。

因此，我们展示了 `AlexNet`、`VGG16`、`VGG19`、`GoogleNet`、`IncV3`、`ResNet50`、`ResNet101` 和 `IncResNetV2` 等流行模型在组织病理学图像数据集上使用微调策略时的表现。`AlexNet` 和 `ResNet` 模型被发现比其他模型更准确、精确和可靠。它们的灵敏度范围在 `99.00%` 到 `97.00%` 之间。

关于评估，三个实验中的分类器均根据准确率的标准性能标准进行评估。为评估各种方法，训练和测试使用了相同的图像。比较采用两次 `10` 折交叉验证进行。对于每次交叉验证，基于九折训练样本，通过参数空间中的网格搜索计算每个特征集的性能值。因此，每次交叉验证的数值可能略有不同，报告的是平均最优值。

重要的是要强调，目前尚无共识认为微调策略优于现成特征提取策略。就性能而言，在生物医学成像领域，这两种策略尚未进行彻底比较，也没有共识表明哪种更好。生物医学领域的一些研究表明微调优于现成特征。然而，这并不完全具有决定性。此外，正如所述，微调比使用现成特征计算量更大，且涉及处理更多超参数。而现成特征方法从 CNN 提取特征通常较快，仅需调整最终分类器的超参数，这通常可通过交叉验证高效完成。

本研究在考虑 `VGG-16` 结果时的另一个关键观察是特定 FC 层错误预测的数量。在该模型使用 SVM 产生的 `57` 个错误预测中，`36` 个来自 FC 层 `34`，`17` 个来自 FC 层 `35`（原文逻辑疑似有误，此处保留原文数字对应关系）。该模型仅在使用 FC 层 `35` 配合 SVM 时实现了 `100%` 的性能准确率，FC 层 `35` 和 SVM 相比其他层提供了略好的结果。尽管无法确认使用特定 FC 层是否存在潜在联系，但这是一个值得探索的领域。此外，本项目中使用的不同层也是一个关注点。模型中的层与图像的特定特征相关，用于将图像转换为一组有意义的数字。然而，哪一层对应何种特征仍在研究中。对层的更多了解有助于回答为何某些层（FC 层 `35`）表现优于其他层（FC 层 `34`）。
