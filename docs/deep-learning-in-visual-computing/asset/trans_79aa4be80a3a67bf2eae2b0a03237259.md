献给所有帮助人类的深度学习算法

# 前言

深度学习是一种人工智能实体，它通过密集的数据驱动算法，在训练阶段后教会自己进行预测。深度学习通过采用人工神经网络，其功能很像人脑，能够对数据进行分类和分析。深度学习已使视觉计算领域的许多棘手问题得以解决。从目标检测到用于诊断的图像分类，深度学习展示了人工深度神经网络在解决现实世界视觉计算问题方面的强大能力，其准确度甚至超越人类。因此，随着大多数传统图像处理和计算机视觉技术实际上已被深度学习技术取代，深度学习已被证明有潜力解决视觉计算领域许多最具挑战性的问题。

本书深入浅出地介绍了适用于视觉计算领域的深度学习世界。书中对深度学习背后的理论和架构提供了通俗易懂的解释。为了帮助读者更好地掌握深度学习的概念及其在现实生活中的应用，本书还辅以大量现实生活中的案例，范围涵盖从人脸识别到癌症图像分类。本书旨在作为一份激发思考的指南，并为爱好者在视觉计算领域开发和实施自己的人工智能项目提供灵感来源。

# 第1章 简介

2017年9月，苹果发布了iPhone X。随之而来的是Face ID——苹果基于人脸识别的先进生物识别系统，嵌入在手机的硬件和软件之中。不久之后，我弄到了一部iPhone X。要使用人脸识别作为身份识别系统——并借此访问各种App，包括让我登录银行账户的App——我首先必须录入我的人脸。录入过程涉及遵循一组简单的说明，我需要以特定的姿势和角度将面部呈现在手机摄像头前。在录入人脸几分钟内，我就能开始享受只需看一眼手机即可解锁并使用的便利。

再说另一个故事。几年前，我和当时4岁的儿子在当地公园散步。孩子们凭借其娇小的身材、大大的眼睛、圆嘟嘟的脸颊，以及脸上流露出的天真与活力，似乎天生就能吸引大人的注意和喜爱。当我们沿着公园的一条小路漫步时，遇到一位中年妇女，她短暂地停下脚步，冲我儿子说“你好”，并报以一个社交性的微笑。我儿子礼貌地回了招呼。从那以后，我们经常在公园见到她，并互致问候。我儿子大概永远不会忘记她的脸。人类处理最常见的视觉对象是人脸。人大脑拥有处理人脸、识别人脸的惊人能力——往往在第一眼看到某张脸后几十年仍能认出。

在人脑如何区分人脸与基于算法的人脸识别系统（如苹果的Face ID）如何工作之间，可以找到一个关键的相似之处。对人类而言，识别人脸是一项微不足道的任务。尽管所有人脸都相似——拥有两只眼睛、一个鼻子和一张嘴，且排列方式一致——我们仍能在许多不同的角度和光照条件下识别和辨认人脸，且往往轻而易举。据信，人类通过模板匹配过程进行图像识别，感知到的物体（例如人脸）以一组真正代表特定物体的离散特征形式存储在长时记忆中。当呈现一个新物体时，其特征可以与长时记忆中现有的特征进行比较，以检索最佳匹配。因此，可以确定两个不同的过程：第一个是学习过程，大脑通过特征教会自己认识特定物体。例如，在我儿子在公园的故事中，他的大脑学习了他在公园遇到的那位女士的面部。然后，在第二个过程中，输入的人脸与存储的人脸模板进行比较，以找到精确匹配。
