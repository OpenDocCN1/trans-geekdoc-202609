# 第10章 通过深度学习推进视觉计算

在过去几年中，深度学习领域取得了大量积极进展。这波发展浪潮当然也波及到了视觉计算领域。从基础图像处理任务到视觉分析，视觉计算领域从深度学习的浪潮中获益匪浅。在深度学习技术中，卷积神经网络（`CNNs`）已被广泛研究并应用于解决与视觉计算相关的问题。随着数据的爆炸式增长、复杂预训练`CNN`网络和模型的可用性，以及将某一领域的解决方案或模型改编以解决其他领域挑战的便利性，深度学习已成为解决视觉计算中极具挑战性任务的事实标准和首选。

除了前几章提供的关键示例外，还可以举出更多例子来说明深度学习作为驱动力在视觉计算中的蓬勃发展。这里我们概述更多示例，以展示深度学习在视觉计算中的应用。

## 视觉检测与跟踪

从自然场景中检测物体是视觉计算中的一个重要问题，目前仍未得到充分解决。例如，为了使自动驾驶汽车能够高效行驶，快速、准确地跟踪各种物体至关重要。将`CNNs`用于视频帧中的物体检测和跟踪可追溯到20世纪90年代。当时的主要挑战是缺乏训练数据和训练好的模型，此外还有有限的计算能力。然而，自2012年以来，`CNNs`在ImageNet挑战赛中展现出的巨大成功，已将深度学习推向了该领域学术研究实验室的前沿。

在视频帧物体检测方面，早期工作建立在跨图像识别合适的滑动窗口基础上，以便`CNN`分类器能够返回目标信息。然而在许多情况下，由于背景的复杂性，滑动窗口的数量可能变得相当大，导致计算复杂度随之增加。

目前一种常见且相当成功的基于`CNN`的物体检测方法是所谓的基于区域的`CNN`（`R-CNN`）。顾名思义，`R-CNN`的任务是以较小规模、基于区域的方法（定义为独立类别）来检查给定的视频帧。因此，在一个给定的`CNN`中，可能多达2000个类别定义独立区域，随后可使用支持向量机（`SVMs`）或余弦相似度（`CS`）度量进行分类。基于空间信息的池化和多区域增强语义分割技术等其他方法也最近被引入。

一个较新的物体检测框架示例是`YOLO`（You Only Look Once）框架。这是一个基于单一管道的预训练模型，可执行检测并为多个物体返回预测类别。因此，`YOLO`似乎仅将一个神经网络应用于整幅图像。它通过仅使用一次前向传播迭代来实现这一点，仅需“看一眼”即可识别物体。随后，它自动将图像划分为较小的区域。基于指定的边界框，它可以分配给定物体属于该区域的概率。最终结果可通过各边界框的权重计算得出最终概率。与其他一些`CNNs`（如`VGG`）不同，`YOLO`可实时运行，在物体检测问题中提供高准确性。

## 姿态识别

姿态估计涉及了解场景中个体的朝向。姿态估计有许多现实应用。这些包括理解人的生理学和身体运动、作为生物识别技术的步态分析，以及设计外观逼真的机器人。

就深度学习而言，`DeepPose`是将深度学习应用于从视频片段估计姿态的最早应用之一。`DeepPose`使用基于`CNN`的回归来分析关节坐标。该模型本身是一个源自`VGG-19`模型的级联7层`CNN`，其中每个身体关节均被表示，组合起来即可估计完整姿态。

类似地，`Mask RCNN`是一种基于深度学习的模型，它同时使用语义分割和实例分割来预测姿态。该方法首先使用`CNN`从图像中提取多个特征图。这些特征图随后用于获取边界框，进而用于分割并最终进行预测。`Mask RCNN`本质上是一种用于预测的自顶向下方法，即首先检测关键关节点，然后估计人的最终姿态。

至于物体跟踪，它严重依赖表示机制，其中目标物体可能处于具有挑战性的环境中。视角变化、光照变化以及物体运动过程中的遮挡增加了巨大挑战。许多类型的`CNNs`已被提出用于物体跟踪。

例如在检测器和跟踪器模型中，待跟踪物体的特征是在离线学习的。`CNNs`的架构本身通过不变性得到增强。在这里，空间和时间信息均可被学习，随后执行跟踪。
