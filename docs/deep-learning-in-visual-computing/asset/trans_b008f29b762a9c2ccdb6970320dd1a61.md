
众所周知，鼻子是一种在种族和族群间表现出显著差异的特征。鼻子也是面部的主要特征之一，对面部美学以及种族和/或族群倾向有着重要贡献。过去，已有大量研究表明不同种族个体的鼻宽测量值存在显著差异。例如，研究人员调查了土耳其裔男性和女性的鼻部人体测量特征[[1]](#13_ch6.xhtml#r6_1)。他们研究了115名年龄在18至30岁之间的成年人，共识别并测量了14个鼻部参数。他们研究的一项主要发现是，鼻部形状存在显著差异，这不仅能区分性别，还能区分族群本身。

因此，人鼻是面部最居中且最突出的特征。使用鼻部图像作为基于图像分类的主要特征有几个优势。首先，鼻部形状对面部表情变化带来的改变具有鲁棒性。它也不受胡须影响。此外，人体测量学研究显示，鼻部形状和大小在性别和族群上均存在差异。个体鼻部外观的稳定性以及鼻部形状随时间推移的不变性，凸显了这一表面特征对识别的重要性。

多年来，多种机器学习算法在不同任务下均尝试过族群分类任务。例如，使用`线性判别分析 (LDA)`可以表明，从包含263名受试者2,630张图像的数据库进行族群分类，在二分类（亚裔与非亚裔）任务中准确率超过96%。同样，可以使用`Gabor小波`特征和`视网膜采样`来获取最具信息量的特征。在此，研究人员使用`支持向量机`将特征分为三类，即亚裔、非裔和欧裔。研究人员分别达到了96%、94%和93%的准确率[[2]](#13_ch6.xhtml#r6_2)。

Roomi等人[[3]](#13_ch6.xhtml#r6_3)使用`Viola-Jones算法`进行人脸检测，随后提取肤色、唇色和归一化额头区域等特征用于种族分类。研究中分类的三大人种为高加索人种、尼格罗人种和蒙古人种。作者提出，这三大人类群体的区分在历史上已为人类学家所公认，并在头部形状、肤色、嘴唇和发质等方面表现出差异。

对于肤色提取，人脸图像从RGB色彩空间转换为`YCbCr`色彩空间，每个像素被归类为“皮肤”或“非皮肤”。特征提交通过使用`Sobel边缘检测`投影边缘图来完成。在由Yale和FERET图像数据库创建的数据集上，作者报告了高加索人种、尼格罗人种和蒙古人种81%的准确率。

Yewenberg等人[[4]](#13_ch6.xhtml#r6_4)在`人脸属性数据集 (FAD)`上研究了除年龄、性别和情绪等特征外的族群分类。作者使用预训练的`CNN`模型`AlexNet`进行基线实验，并将结果与其新颖的`地标增强CNN (LACNN)`进行比较。测试族群（白人）使用`AlexNet`准确分类率为82.7%，而`LACNN`将性能准确率略微提升至83.35%。该研究凸显了`CNN`架构的优势以及使用大型多样化数据集的有效性。

虽然族群分类任务已使用全脸图像进行过研究，但仅有少量文献探讨了眼睛和鼻子等面部特征用于族群分类的鲁棒性。例如，Qiu等人[[5]](#13_ch6.xhtml#r6_5)提出了一种从虹膜图像确定族群（亚裔与非亚裔）的模型。

类似地，鼻子也被证明是一种高效的生物特征[[6]](#13_ch6.xhtml#r6_6)。然而，鼻部相关文献有限。Lv等人[[7]](#13_ch6.xhtml#r6_7)引入了一种新型`3D鼻部形状网络`分类器用于性别和族群分类。构建`3D鼻部形状网络`需要一种从鼻部获取测量值的方法，以确定给定数据集中不同鼻子间的距离，然后将图像聚类成组。利用鼻部聚类结果，构建3D鼻模型。使用`Bosphorus3D`人脸图像数据库和`FRGC2.0`，作者报告了亚裔族群89.2%、白人族群87.4%的分类准确率。

Drira及其同事[[8]](#13_ch6.xhtml#r6_8)也报告了关于使用3D鼻部形状信息的类似研究。Song等人[[9]](#13_ch6.xhtml#r6_9)研究将鼻部皮肤毛孔的数量和位置作为生物特征进行提取。报告了88.07%的性能准确率，研究表明鼻部毛孔是生物识别的一个有前景的途径。

Zehngut等人[[10]](#13_ch6.xhtml#r6_10)研究了基于图像的鼻部生物特征确定身份信息的可行性。此处进行了两类实验。它们是：（1）使用NIST的`人脸识别大赛 (FRGC)`数据库（含12,776张图像）比较全脸和鼻部生物特征；（2）使用`AR Face`数据库（含3,288张图像）比较遮挡人脸图像下的全脸和鼻部生物特征。基于`最优权衡合成判别函数 (OTSDF)`滤波器，使用`核类依赖特征分析 (KCFA)`提取判别性鼻部特征。

因此，利用鼻部图像（包括鼻部毛孔等特征方面）进行人口统计学（族群）识别已被证明是成功的。鼻子是一种鲁棒且具判别力的特征，文献综述证明了其可靠性。

在本章中，重点关注作为人口统计学特征的族群，其可见于鼻部，旨在演示如何使用一系列基于`残差神经网络 (ResNet)`和`VGG-Face`的预训练机器学习算法进行一系列实验。我们提出的方法论中使用的预训练模型包括：（1）`VGG-Face`，（2）`VGG-16`，（3）`VGG-19`。使用的`残差神经网络 (ResNet)`包括：（1）`ResNet-50`，（2）`ResNet-101`，（3）`ResNet-152`。

对于此处的讨论，我们将族群定义为一个人的文化和祖先背景。从全脸图像中裁剪出的鼻部图像，根据特定选择标准（将在即将到来的特征数据库部分讨论）被分为巴基斯坦裔或非巴基斯坦裔。

所提出的族群分类方法包含2个组件：（i）使用`VGG-Face`、`VGG-16`、`VGG-19`、`ResNet-50`、`ResNet-101`和`ResNet-152`的权重进行特征提取；（ii）使用线性`支持向量机 (SVM)`算法作为二分类过程进行族群分类。
