

## 流行 CNN 模型的对比

在此，我们考虑其他流行模型在特征提取和分类方面的实现，以对比它们在烧伤皮肤识别任务中的有效性。除了前文讨论的 ResNet 模型结果外，我们还选取了 VGG-16 和 GoogLeNet。[表 7.5](#14_ch7.xhtml#t7_5) 中显示的结果展示了用于对三种不同预训练模型提取特征进行分类的两个分类器。

首先，使用 GoogLeNet 预训练模型进行特征提取，并将这些特征输入到两种不同的监督分类算法（LSVM 和 DT）中。从分类器获得的分类结果显示，LSVM 优于 DT。两者的性能准确率分别约为 99.3% 和 92.3%。此外，尽管使用相同的数据集进行训练和评估，DT 分类器在准确率方面仍落后于 LSVM，错误率约为 7%。

同样，在对 ResNet152 预训练模型提取的特征进行分类时，如表 6 所示，LSVM 记录的分类准确率约为 98.5%，而 DT 达到了 93.4%。在这种情况下，DT 与 LSVM 产生的错误率差异约为 5.1%。当两个分类器在 VGG-16 模型提取的特征上进行训练时，也适用相同的直觉。LSVM 达到了 94.5% 的性能准确率，而 DT 达到了 92.6%，LSVM 以 1.9% 的性能差异领先。

## 改进学习与分类

在此，我们讨论几种可以改进学习和分类的方法。特别是，我们展示了如何利用集成学习、Bagging 和 AdaBoost 来实现这一目的。

### 集成学习

集成学习是一种通过使用多种学习算法解决同一问题来获得良好结果的技术。在集成学习范式中，每个参与的单个学习算法被称为基学习器，人们认为这些学习泛化能力的聚合优于从单个基学习器获得的泛化能力。这是因为单个学习算法能够产生比随机猜测更好的结果，但当使用多个基学习器时，能获得更准确的结果，从而将基学习器（也称为弱学习器）转化为强学习器。正如所述，集成学习也称为基于委员会的学习，可以是同质学习或异质学习。

*   **同质集成学习**：此处，使用多个同类型的弱学习器或分类器（相同的分类算法）。
*   **异质集成学习**：一组不同的分类算法在相同的训练数据集上进行训练，以产出比训练单个分类器更好的输出。

集成学习技术可分为两类：依赖架构和独立架构。在依赖架构中，训练好的分类器依赖于其前驱产生的输出，这意味着前一次迭代获得的结果指导下一次迭代的构建。但对于独立架构，不存在对前一次迭代获得的先验输出的依赖，每个分类器独立地在数据集上进行训练，彼此互不干扰。

### Bagging

在此场景中，集成学习器通过从给定数据集的不同子集训练学习器来构建，总体预测通过对所有单个学习器产生的预测进行投票来获得。训练数据通过从总数据样本（例如 `N`）中随机采样生成。Bagging 一词源自 Bootstrap **AGG**regating，其中每个学习器采集的随机样本被称为 bootstrap。然而，所选数据并未完全从数据集中移除。这意味着数据可能在不同的训练阶段多次出现。

### AdaBoost

这是一种线性或顺序的集成学习技术，其中弱学习器依次训练。这意味着每个基学习器一次使用全部训练数据集进行训练，下一个学习器将根据最初训练的学习器产生的残差误差进行训练。此外，分类效果差的观测值在训练下一个模型时被分配更高的权重或给予更高的优先级。这意味着前一个分类器产生的误分类实例在后续学习阶段被选中的频率更高。训练完成后，通过组合结果获得最终准确率。

### 结果评估

在获得两个所用分类器的分类性能后——两者均在三种不同特征提取器提取的特征上进行训练，结果显示 DT 相比其对手是较弱的分类器——随后应用集成学习的思想，使用 DT 作为基学习器，如[表 7.6](#14_ch7.xhtml#t7_6) 所示。

组装了一百五十棵决策树，以提升或改进[表 6](#14_ch7.xhtml#t7_6) 中表现不佳的分类器的准确率。如[表 7.6](#14_ch7.xhtml#t7_6) 所示，在所有三种不同情况下均使用了包含 150 棵 DT 的 Bagging 策略。显然，当采用此类策略更新时，DT 的表现优于原始结果，如[表 7.6](#14_ch7.xhtml#t7_6) 所示。对于由 GoogLeNet、ResNet152 和 VGG-16 提取的三组特征中的每组 DT 结果，使用 Bagging 分别恢复了 1.8%、3.3% 和 2.3% 的性能提升。
