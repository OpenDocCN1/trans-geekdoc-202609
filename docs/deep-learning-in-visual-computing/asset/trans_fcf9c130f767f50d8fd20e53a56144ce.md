

## 烧伤皮肤与健康皮肤的鉴别

这里我们讨论如何采用深度学习方法对烧伤皮肤进行分析，以鉴别健康皮肤和烧伤。我们展示了如何使用一个完全训练好的卷积神经网络（`CNN`）来提取有用特征，随后将这些特征输入支持向量机（`SVM`）算法进行分类。在本例中，我们展示了如何使用两种变体深度 `CNN` 架构（即 `ResNet101` 和 `ResNet152`）从二维彩色图像中提取特征。

微软亚洲研究院（`MRA`）提出的残差 `CNN` 提出了一种残差网络，该网络在 2015 年 ImageNet 大规模视觉识别挑战赛（`ILSVRC`）分类任务中以 3.57% 的错误率夺冠。该网络的独特之处在于残差连接（快捷连接）。因此，通过将前一层的输入与较低层的输出相加，得到的值再通过激活函数，作为网络下一层的输入。这使得堆叠更多层、提高准确率的网络成为可能。每隔几个堆叠层采用一次跳跃连接，用一条标记为快捷连接的有向线表示，如 [图 1](#14_ch7.xhtml#f7_1) 所示。在数学上，我们得到：

*y* = *f*(*z*) + (*z*) = *f*(*z*) + *z*。 (7.1)

其中 (*z*) 是一条快捷路径，允许梯度得以保持，并允许使用更多堆叠层更快地训练网络；*f*(*z*) 是卷积层的输出，即权重来源的那一层。残差网络包含两部分，即主路径部分和快捷路径部分。主路径部分由常规卷积层和激活（`ReLU`）层组成，而快捷路径部分是直接连接到输出的输入。此外，激活函数是在快捷路径的输出与主路径的输出相加之后应用的。因此，

*y*′ = *σ*(*f*(*z*) + *z*) = *σ*(*y*), (7.2)

其中 *σ*(*y*) 是逐元素运算后的激活操作（非线性）。

残差网络的通用形式有 18、34、50、101 和 152 层。对于此处讨论的图像分析，可以使用这种架构及其 101 层变体。由于模型是预训练的，可以采用迁移学习来规避计算复杂度。

如前所述，`SVM` 是一种学习算法，主要用于数据集的分类、回归和异常检测任务。它通过寻找一个最优分离超平面（`OSH`）来工作，该超平面作为边界将两类数据分开。这是通过解决一个优化问题来实现的。作为一种监督学习算法，它基于一组标记的训练数据学习对未见数据进行分类。因此，训练阶段用于构建模型，之后，通过计算模型（权重）与图像数据特征的点积，将新的未见数据映射到两个学习到的类别之一。

### 图像获取与预处理

烧伤图像直接从医院的患者身上采集，此外还通过互联网搜索获取。共采集了 600 张人体皮肤烧伤图像和 200 张健康皮肤图像（正常皮肤）。在 600 张烧伤图像中，200 张被识别并标记为一度烧伤图像，200 张为二度烧伤图像，剩余部分为三度烧伤图像。所有图像在特征提取和分类前均调整为 224×224 的大小。这样，所有图像将具有相同的尺寸，符合 `ResNet` 所需的标准图像尺寸。[图 7.1](#14_ch7.xhtml#f7_1) 展示了数据集中一张烧伤图像的示例。

### 结果评估

对于图像的特征提取，可以使用上述的 `ResNet` 架构。此外，为了验证结果的有效性，采用 k 折交叉验证，将数据等分为 *k* 份。交叉验证（`CV`）是一种评估学习算法的统计方法 [[9](#14_ch7.xhtml#r7_9)]。训练和验证由这些子样本完成。使用了一种特殊的 k 折（其中 *k* = 10）交叉验证，其中 *k* – 1 份用于训练，剩余的一份用于验证（测试）。迭代持续进行直到所有子样本用尽，以这种方式使得每个子样本既用于训练也用于所有测试的。
