
考虑系统输入与输出之间的关系，如[图 2.1](#09_ch2.xhtml#f2_1)所示。[图 2.1](#09_ch2.xhtml#f2_1)(a)中所示的输入输出关系显然是线性的，可以使用形式为 `F(x) = ax + b` 的函数进行建模，其中 `a` 和 `b` 是模型空间中的特征值（或参数）。在某种意义上，具有特定值 `a` 和 `b` 的函数 `F(x)` 能够紧密拟合[图 2.1](#09_ch2.xhtml#f2_1)(a)中的数据集，这就是一个学习好的模型。如果模型的输入输出模式现在发生变化，如[图 2.1](#09_ch2.xhtml#f2_1)(b)所示，线性模型将不再有效。然而，我们可以求助于形式为 `F(x) = ax³ + bx² + cx + d` 或 `F(x) = Ce^(Ax)` 的模型（其中 `a`、`b`、`c`、`d`、`C` 和 `A` 是相应非线性模型的参数），这将更适合对[图 2.1](#09_ch2.xhtml#f2_1)(b)所示的数据进行建模。

尽管线性和非线性模型适合对简单数据集进行建模，但对于实际应用，这种函数式建模很难获得。例如，对于像在图像中识别苹果这样的视觉计算任务，寻找能够映射苹果图像的像素线性组合是不可能的。即使使用简单的非线性函数组合，这样的任务也可能令人望而生畏，因为可能需要处理数量巨大且经常相互冲突的参数。因此，必须寻找一种通用方法，通过该方法可以对适用于实际应用的复杂和多维数据集进行建模。这是机器学习，特别是深度学习技术，能够帮助我们的一个领域。此类模型可以接收足够大的数据作为输入并对其进行处理，利用高层信息或知识提取数据中的一般模式。它们旨在模仿人类推断物体以及从物体中提取知识的方式。因此，教会机器了解世界的一个合理途径是模仿人脑——特别是神经元如何利用数据进行学习和推断。

## 感知机

第一个受大脑神经元启发的机器学习计算模型，由 Warren McColloch 和 Walter Pitts 提出，他们二人在 1940 年代从事计算神经科学领域的工作。他们想了解人脑如何利用相互连接的神经元产生复杂的模式。他们试图将其作为提出的感知机模型的基础，该模型最初由 Rosenblatt 于 1958 年提出，当时他在康奈尔航空实验室工作。

McColloch 和 Pitts 的感知机是一个基于生物神经元工作原理的数学模型。神经元是大脑中相互连接的神经细胞，统称为神经网络。它们通过电信号和化学信号处理和传递信息。当细胞膜两侧的离子浓度发生变化而产生动作电位时，生物神经元就会受到刺激。通常，细胞外空间钠离子浓度较高，而细胞内空间钾离子浓度较高。在动作电位期间，离子在神经元膜上来回传输，引起电变化，从而传递神经冲动。

与人类神经元的功能类似，感知机神经模型接收一系列输入信号 `x[1]`、`x[2]`、`x[3]`，这些信号要么是兴奋性的，要么是抑制性的。信号可以通过 `w[1]`、`w[2]`、`w[3]` 进行加权，以便根据需要调整其影响。最后，计算加权和。如果输入信号的加权和达到选定的阈值，模型输出 1，否则输出 0。因此，模型通过执行加权和，基于输入信号（即 `x[1]`、`x[2]`、`x[3]`）做出输出决策，进而生成二进制输出（即 0 或 1），如[图 2.2](#09_ch2.xhtml#f2_2)所示。

感知机是一种分类技术，可广泛用于视觉计算应用，例如计算机视觉和图像识别。假设我们有一张图片，希望算法告诉我们这张图片是不是苹果，可以使用分类来实现。输入可以是图像的像素，感知机的权重可以通过苹果数据集得出，输出将是一个二元分类，告诉我们输入图像是否为苹果。然而，就像函数一样，单个神经元非常有限，许多现实世界的问题无法用二元分类器解决。因此，感知机的思想可以扩展到人工神经网络（ANN），其中多个神经元可以连接在一起。

## 人工神经网络

本质上，ANN 是由单个感知机组成的集合，形成一个神经元网络，连接在一起以实现网络各部分的并行信号处理。感知机单元之间包含权重，以控制彼此的影响。[图 2.3](#09_ch2.xhtml#f2_3)展示了 ANN 的基本结构布局。ANN 的一个关键组件是位于网络输入和输出之间的隐藏层。隐藏层有助于为输入分配非线性权重并将其导向输出，即它们有助于将非线性数学函数应用于网络的特定部分以产生期望的最终输出。这些函数通常被称为激活函数。例如，在人脸检测任务中，一个隐藏层可以调整为识别输入图像中的眼睛，另一个可以调整为识别鼻子，依此类推。整个网络随后可以识别输入图像中人脸的存在。

![Figure 2.3: Representation of a multilayer neural network with a hidden layer.](images/fig2_3_B.jpg)

[**图 2.3：**](#09_ch2.xhtml#f2_3b) 具有隐藏层的多层神经网络示意图。

具体而言，在基于多层感知机概念的 ANN 中，每个神经元都连接到前一层和后一层的神经元。输入层和输出层之间的连接由若干隐藏层定义，这些隐藏层由激活函数连接。激活函数 `A` 通常采用以下形式：

```
A = F(∑_{i=1}^{n} w_i x_i + b), (2.1)
```

其中，`w[i]` 是分配给神经元 `i` 的权重，`b` 是偏置值，`n` 是神经元的数量。输入数据定义输入层中神经元的数量。在激活函数的帮助下，隐藏层执行多次特征提取以进行分类。最后，所有隐藏层提供一个特征集作为输出。输出层神经元的数量等同于输入数据可被划分的类别数量。输出的准确性，即输入属于给定类别的概率，通过损失函数（也称为 Softmax）来衡量。
