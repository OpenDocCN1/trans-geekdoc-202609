
# 模型准确性评估

正如[表 9.7](#16_ch9.xhtml#t9_7)和[表 9.8](#16_ch9.xhtml#t9_8)所示，对于 `VGG-MI1`，准确率、灵敏度和特异性分别为 99.02%、98.76% 和 99.17%。这是在无噪声 ECG 信号片段且启用数据增强的情况下实现的。同样，对于 `VGG-MI2`，准确率、灵敏度和特异性分别为 99.22%、99.15% 和 99.49%。因此，我们可以得出结论：`VGG-MI2` 的性能略优于 `VGG-MI1` 子模型。这是因为 `VGG-MI2` 模型中引入的 `QG-MSVM` 分类器似乎在提高分类准确率方面发挥了重要作用。此外，我们注意到，无论是否进行数据增强，`VGG-MI2` 的性能均优于 `VGG-MI1` 子模型。在[表 9.9](#16_ch9.xhtml#t9_9)中，我们展示了此处提出的两个子模型与标准 `VGG` 和 `AlexNet` 的对比研究。

## 相关工作对比

部分地，有许多方法被应用于分析 `ECG` 信号以进行 `MI` 检测。例如，Sun 等人 [[12]](#16_ch9.xhtml#r9_12) 提出了一种基于多实例学习的自动 `MI` 检测系统。据报告，他们使用 `kNN` 集成作为分类器，获得的灵敏度和特异性分别为 92.30% 和 88.10%。同样，Sharma 等人 [[13]](#16_ch9.xhtml#r9_13) 提出了一种基于多尺度能量和特征空间的 `MI` 检测技术，使用 `SVM` 分类器时准确率、灵敏度和特异性分别为 96%、93% 和 99%；使用 `kNN` 分类器时分别为 81%、85% 和 87%。然而，值得注意的是，大多数此类工作要么利用有限的数据集来验证结果，也不具备计算优势。因此，此处提出的基于深度学习的方法似乎更具吸引力。

# 结论

本章详细讨论的提出的深度学习模型，可被视为一种用于心脏疾病自动检测和分析的高效机制。此处采用的新颖方法是利用现有 `VGG` 模型的结构并对其进行修改，以获得两个子模型，即 `VGG-MI1` 和 `VGG-MI2`。

为测试提出的模型，我们利用了来自 `PTB` 数据集的 `ECG` 信号，并将其转换为灰度图像。图像经过增强，使数据集扩展了 10 倍。基于上述数据集的模型实验表明，提出的 `CNN` 框架准确且高效。事实上，结果显示我们使用 `VGG-MI2` 达到了 99.22% 的准确率。此外，我们报告使用 `VGG-MI2` 时灵敏度为 99.15%，特异性为 99.49%。看来即使在最坏情况下，结果也能达到 97.24% 的准确率。此外，我们报告在 `VGG-MI2` 上灵敏度为 97.13%，特异性为 96.53%。据我们所知，这似乎是该领域当前的最先进水平，展示了深度学习模型在用于诊断目的的基于信号的优化图像分析中的优势。
