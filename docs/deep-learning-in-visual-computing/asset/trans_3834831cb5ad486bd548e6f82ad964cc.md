
同样，所使用的提升技术（`AdaBoost`）的表现优于使用单个 `DT` 分类器。在 `GoogLeNet`、`ResNet152` 和 `VGG-16` 提取的特征上训练的 `AdaBoost` 策略，性能分别提升了 5.5%、3.7% 和 3.7%。正如 [表 7.6](#14_ch7.xhtml#t7_6) 所示，提升集成方法在性能上超过了装袋集成方法。值得注意的是，装袋集成方法通过从数据池中并行训练多个分类器并应用投票来确定个体分类器产生的最高频性能；而提升（`AdaBoost`）则通过一次训练一个分类器，在其前驱输出的基础上重新训练下一个分类器，并给予误分类实例更高的优先级。这使其比装袋强大得多，不同文献中也报告了相同的论点。

此外，值得注意的是，对于使用的每个特征提取模型，都有可能使用不同的数据集来训练和评估模型。数据来自同一个图像库，但在每个阶段，训练和评估样本都是随机抽取的。例如，使用 `GoogleNet` 训练阶段时位置 `i` 处的烧伤图像，在使用 `ResNet152` 的训练阶段可能不会被使用。然而，所有四种分类技术均使用各模型从图像池中随机选取的数据所提取的相同特征进行训练。

从 [表 7.6](#14_ch7.xhtml#t7_6) 中获得的结果来看，`SVM` 算法在区分健康皮肤和烧伤皮肤方面，表现优于决策树和所使用的集成技术。这一解释也得到了很好的体现：单一决策树学习器产生的结果较差，而集成学习器表现更好。此外，`AdaBoost` 集成学习技术提供的性能改进优于装袋集成学习技术。这是因为 `AdaBoost` 通过使用一系列分类器运行，其中每个后续分类器都经过训练，以弥补前一个分类器造成的误分类或错误。

除了评估分类器的有效准确率外，还需要考虑一些指标来补充对所获结果的有效分析。这些指标包括：分类器预测实际烧伤图像（即正样本，灵敏度）的准确性如何，以及分类器预测健康皮肤图像（即负样本，特异性）的准确性如何。灵敏度和特异性是医学成像中可靠的性能指标，能给出完整的图景。[表 8](#14_ch7.xhtml#t7_8) 显示的结果是使用 `GoogLeNet` 特征提取器进行的所有分类的具体性能指标。同样，[表 9](#14_ch7.xhtml#t7_9) 和 [表 10](#14_ch7.xhtml#t7_10) 分别显示了使用 `ResNet152` 和 `VGGNet` 特征提取器的分类器的类似性能指标。

表 7.8 的结果显示，`LSVM` 能够准确预测阳性（烧伤）样本，实现了 100% 的灵敏度，而在预测阴性（健康）样本时略有误分类，记录了 98.5% 的特异性。与 [表 7.6](#14_ch7.xhtml#t7_6) 和 [表 7.7](#14_ch7.xhtml#t7_7) 中获得的结果类似，集成学习器在正确预测阳性样本（灵敏度）和阴性样本（特异性）方面均优于单一决策基学习器，如表 8 所示，随后在图 8 中得以描绘。单一 `DT` 基学习器和 150-`DT` 装袋集成学习器对阳性样本的预测准确度高于阴性样本；而在 150-`DT` 提升学习技术中，灵敏度和特异性达到了相同的性能准确度。

## 烧伤深度分析

识别烧伤并将其与健康皮肤及其他皮肤相关损伤区分开来，是确保烧伤存在并进而进行后续调查的第一步。由于当今医院中的图像采集设备，每天都在积累大量的临床烧伤图像，并由人类视觉系统进行处理。然而，由于人类易疲劳的天性，此类图像的解读容易出错。

烧伤的早期识别和烧伤深度的精确评估对患者的损伤管理至关重要，从而确保能尽早决定是否需要手术干预。烧伤深度评估很重要，因为它有助于预测已识别烧伤创面的潜在愈合时间，从而使适当的治疗能够尽早进行。愈合周期长的烧伤，如浅二度和深二度烧伤，如果能被早期识别，就可以尽早治疗，从而最大限度地减少因评估延迟导致的进一步并发症。虽然临床上容易识别浅一度和全层烧伤，但机器学习算法能否用于区分浅二度烧伤和全层烧伤呢？
