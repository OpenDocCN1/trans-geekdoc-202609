

## 使用孤立面部特征裁剪的额外实验

进行了使用孤立面部特征裁剪的额外实验，以确定特征组合是否影响性能准确率。所使用的特征组合包括：(1) 眼睛和鼻子，(2) 鼻子和嘴巴，以及 (3) 嘴巴和眼睛，如[表 6.3](#13_ch6.xhtml#t6_3)所示。

从孤立特征组合中获得的结果表明，平均而言，鼻子和嘴巴的特征产生最高结果 (85.63%)。此外，对于所有测试的预训练模型，鼻子和嘴巴的特征组合始终产生最高的性能准确率。

紧随其后的是嘴巴和眼睛以及眼睛和鼻子的组合，平均准确率分别为 82.56% 和 81.55%。结果表明，内部特征（即眼睛、鼻子和嘴巴）提供了可靠的信息，以区分巴基斯坦面孔和非巴基斯坦面孔。重要的是，报告的结果与提出眼睛、鼻子和嘴巴在确定人类种族方面很重要的文献一致。

### 性能指标

为了确定所获结果的有效性，计算了灵敏度和特异度等性能指标。灵敏度是正确分类的正例值 (`TPR`)，特异度是正确拒绝的负例值 (`TNR`)。通过结合灵敏度和特异度，报告了分类算法的总体性能准确率。数值的可视化表示以接收者操作特征 (`ROC`) 图的形式显示。

[表 6.3：](#13_ch6.xhtml#t6_3b) 面部特征组合二分类的性能准确率。

| 特征提取模型 | 线性支持向量机 (`SVM`) |
| :--- | :---: |
| | 眼睛和鼻子 | 鼻子和嘴巴 | 嘴巴和眼睛 |
| **ResNet-50** | 85.8% | 91.8% | 87.8% |
| **ResNet-101** | 85.5% | 90.5% | 88.8% |
| **ResNet-152** | 84.4% | 90.2% | 84.8% |
| **VGG-16** | 81.5% | 85.2% | 82.8% |
| **VGG-19** | 79.5% | 80.3% | 77.6% |
| **VGG-Face** | 72.6% | 75.8% | 73.6% |

### 与现有工作的比较

根据[表 6.1](#13_ch6.xhtml#t6_1)，`ResNet-50` 达到了 94.1% 的性能准确率，紧随其后的是 `ResNet-152` 和 `ResNet-101`，分类准确率分别为 93.6% 和 93.4%。ResNet 模型之间性能的接近性与其他人的结果一致。考虑到架构深度的显著增加，50/101/152 层 ResNet 产生了高且准确的结果。

由于我们的刺激材料（即孤立鼻子数据库）的新颖性以及我们方法的特异性（仅基于鼻子信息进行种族判定），很难将此处的结果直接与他人的工作进行比较。尽管如此，结果表明与 Lv 等人 [[7]](#13_ch6.xhtml#r6_7) 利用 3D 鼻子形状分类器呈现的结果相比，准确率更高。他们报告亚裔种族分类为 89.2%，白人种族分类为 87.4%。

此外，此处的结果支持这样的观点：鼻子是判定巴基斯坦种族的有用特征。这与其他人进行的类似基于机器学习的实验结果一据。

据我们所知，使用 ResNet 和 VGG 特征，此前从未利用鼻子作为孤立特征来解决二元种族分类任务。所有 8 个实验的结果确立了所测试的深度学习算法优于基于 VGG 的模型。我们认为这是由于此类模型的深层架构。此外，考虑到与鼻子相关的多样性和性二态性，在人类难以对面部种族进行分类并区分巴基斯坦和非巴基斯坦鼻子的情况下，深度学习方法可能证明能够提供人类视觉系统无法获得的信息。

## 结论

在本章中，我们解决了身体面部特征（特别是鼻子）的种族分类问题。使用南亚巴基斯坦种族的鼻子图像新数据集，研究了二分类任务。提取了 `ResNet` 和 `VGG` 特征并输入到线性支持向量机 (`SVM`) 分类器中。`ResNet-50` 发现的性能准确率为 94.1%，而 `VGG-16` 对鼻子图像的分类准确率为 90.8%。我们的结果是新颖的，因为巴基斯坦鼻子的种族分类此前从未被尝试过。
