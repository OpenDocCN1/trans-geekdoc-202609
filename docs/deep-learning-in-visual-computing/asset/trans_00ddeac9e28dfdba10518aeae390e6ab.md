
有趣的是，Apple 的 Face ID 识别和区分面部的方式，与我们人类在大脑中识别和辨认面部的方式非常相似。在注册阶段，Face ID 从不同位置和角度读取面部，并最终将面部的物理特征转换为数学表征——通常每张面部对应几百个浮点数。在识别过程中，手机上的红外传感器读取面部，计算与该面部对应的数学表征，并与存储的模板面部进行“距离维度”的比较。同样可以看出，就像大脑一样，面部匹配系统首先学习面部特征，然后将其与模板面部进行比对，以查看是否存在匹配，从而验证给定的准确性阈值。

无论是在计算机世界还是在人类大脑中，物体识别背后的基本思想都是信息压缩，或是从数据中自动形成有用的表征。从根本上说，我们可以将这种表征学习的过程称为深度学习。一个很好的例子是我们表示原子结构的常用方式，如[图 1.1](#08_ch1.xhtml#f1_1)所示。虽然原子包含围绕由质子和中子组成的原子核运动的电子，但其结构绝不像[图 1.1](#08_ch1.xhtml#f1_1)所示那样具有确定的形态。事实上，电子在任意给定时刻的位置从来不是可预测的，我们只能获得其围绕原子核位置的概率估计。然而，如[图 1.1](#08_ch1.xhtml#f1_1)所示呈现原子结构，有助于我们形成关于原子、分子和宏观物质的一份表征学习认知。

从宏观层面来看，深度神经网络由编码器和解码器组成。编码器的功能是在数据中寻找有用的模式，并形成一种表征学习的形式。同样，解码器的功能是从表征中生成高分辨率数据，其中生成的数据是新的样本或表达性知识。从根本上说，这就是深度学习的工作原理。

随着强大计算工具和传感器数据的近期爆发式增长，深度学习已成为机器学习的核心工具。深度学习已在广泛的领域和多样的场景中得到应用。虚拟助手（如 Siri 和 Alexa）、生物特征面部识别、聊天机器人、图像分析工具和计算机辅助诊断系统，均由深度学习辅助的模型和算法积极驱动。事实上，得益于深度学习算法的爆发式发展和预训练深度学习模型的可用性，整个人工智能领域最近已占据了中心舞台。此外，视觉计算领域的许多问题正通过深度学习方法和工具得到解决。从基础的图像分析任务到复杂的疾病诊断实践，深度学习在几乎所有与视觉计算相关的问题中都扮演了核心角色。因此，有必要编写一本专门阐述视觉计算领域深度学习积累知识与最新发展的书籍。

本书概述了应用于视觉计算领域问题的深度学习方法与技术。本书的第一部分致力于阐释深度学习——从基本概念到构建深度学习模型的机制。本书涵盖了足够的深度学习理论，以便读者掌握深度学习的基本要素。为了补充深度学习的理论与知识，本书还涵盖了若干实际案例，演示如何在视觉计算领域成功应用深度学习。

## 简介

人工智能（AI）被定义为一种使机器或算法能够模仿人类行为的技术。人工智能的大部分引擎由机器学习（ML）的方法和技术驱动，深度学习是其中的一部分。深度学习使计算模型能够通过一种模仿人类大脑感知和理解多模态信息的方式来学习和表征数据。尽管深度学习直到最近才变得非常流行，但它的历史相当悠久。

深度学习是一种机器算法通过示例进行学习的机制。它是一种获得模型最优配置的机制，从而能从一组输入数据中获得期望的输出。从数学角度来看，可以将此过程视为获得期望函数 `g(y[1], y[2],..., y[n])` 以映射输入函数 `f(x[1], x[2],..., x[m])`。存在多种获取此类关系的方法——从线性近似到利用复杂的非线性形式。通常，与物理定律或现象相关的变量之间的显式数学关系可以被构建出来。例如，如果我们采用著名的牛顿第二运动定律，该定律指出施加在质量为 `m` 的物体上的力 `F` 是 `m` 与加速度的乘积，而加速度是物体速度变化的速率。这可以简单地表述为线性关系 `F = ma`。因此，给定 `m` 和 `a` 的输入值，人们可以轻松预测必须施加的力。同样，如果我们采用爱因斯坦著名的方程 `E = mc²`，我们可以看到物质 `m` 的能量与光速 `c` 之间存在非线性关系。

对于选定的一组物理现象，以及更直接的现实生活情境，可以推断出变量间的此类相关性，并可将其显式地以线性或非线性形式写出。然而，现实世界的许多问题过于复杂或过于动态，无法找到相关变量之间此类显式的关系。
