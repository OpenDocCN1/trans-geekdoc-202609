
该模型包含 22 层、9 个 Inception 单元，最后在输出前还有一个全连接层。Inception 模块由两层和 6 个卷积块组成，是 GoogLeNet 的核心组件。它是在 ILSVRC2014 数据集上训练的。它使用所谓的 Inception 模块，该模块由多个并行的卷积核组成，处理相同的输入，并在不同尺度上连接特征。此外，池化操作提取的特征也由 Inception 模块连接。使用 Inception 模块，GoogLeNet 能够在有限的计算成本下实现高准确率。

## Inception-v3

Inception 比 GoogLeNet 更大、更深、更慢，但在原始 ILSVRC 数据集上更准确。它是一个 48 层的深度模型，由多个卷积层和池化层组成，其输出被连接在一起。它处理 229 × 229 × 3 的输入图像。它从全连接架构迁移到了稀疏连接架构。通过引入 1 × 1 分解卷积神经网络并后接线性整流单元，它具有了更强的非线性能力。此外，还采用了 3 × 3 卷积层。辅助 logits 结合了平均池化、1 × 1 卷积、全连接层和 Softmax 激活函数，用于保留低层细节特征，并解决最后几层中的梯度消失问题。

### ResNet

残差网络架构由微软开发。ResNet 的连接方式使得训练更深的网络成为可能。ResNet-50 深 50 层，ResNet-101 深 101 层。它处理 224 × 224 × 3 的输入图像。残差网络旨在增加网络深度，同时避免影响结果的问题。残差网络的核心思想基于在层之间引入恒等函数。在传统网络中，层之间存在非线性函数 `y = H(x)`（底层映射），如[图 3.5](#10_ch3.xhtml#f3_5)左侧所示。在残差网络中，我们有一个新的非线性函数 `y = F(x) + id(x) = F(x) + x`。这里 `F(x)` 是残差，如[图 3.5](#10_ch3.xhtml#f3_5)所示。

![图 3.5 典型 CNN 和 ResNet 架构的捷径连接。](images/fig3_5_B.jpg)

[图 3.5](#10_ch3.xhtml#f3_5b) 典型 CNN 和 ResNet 架构的捷径连接。

这种修改（称为捷径连接）允许重要信息从前一层传递到后续层。这样做避免了梯度消失问题（在如此深的网络训练中，许多神经元变得无用）。残差网络的优势在于，它们能够在不增加待优化参数数量的情况下增加网络深度，从而加速极深网络的训练速度。它们还减轻了梯度消失问题的影响，从而提高了获得的准确率。

### Inception-ResNet

Inception-ResNet 将 GoogLeNet 的高效 Inception 模块与 ResNet 的残差连接相结合。Inception-ResNet-v2 深 164 层。它处理 229 × 229 × 3 的输入图像。它是 Inception V3 模型的一个变体，借鉴了上一节提到的微软 ResNet 网络文章中的一些思想。残差连接包含模型中的捷径，正如前面提到的，允许研究人员训练更深、性能更好的网络。这也使得 Inception 模块得到了显著简化。

## 标准性能指标

神经网络的性能可以根据标准性能术语进行评估，如真阳性 (TP)、假阳性 (FP)、真阴性 (TN)、假阴性 (FN)、准确率 (ACC)、精确率 (P) 和灵敏度 (S)。标准性能指标按以下公式计算。

准确率评估分类器的整体有效性，即：

```
Accuracy = (TP + TN) / (TP + FN + FP + TN). (3.5)
```

灵敏度评估分类器识别正标签的有效性，即：

```
Sensitivity (Recall) = TP / (TP + FN). (3.6)
```

精确率评估数据标签与分类器给出的正标签的一致性，即：

```
Precision = TP / (TP + FP). (3.7)
```

这四个分类器构成了一个混淆矩阵，如[图 3.6](#10_ch3.xhtml#f3_6)所示，适用于二分类情况。

![图 3.6 二分类的混淆矩阵。](images/fig3_6_B.jpg)

[图 3.6](#10_ch3.xhtml#f3_6b) 二分类的混淆矩阵。

交叉验证确保训练期间使用的数据不参与测试阶段。然而，最终每个单独的数据都将以特定方式同时用于训练和测试。例如，在交叉验证技术中，数据集被分成若干折，例如 k 折，其中 k 代表折数或分割数。在训练阶段，使用 k-1 折来训练算法或模型，剩下的那一折被保留用于测试。这个过程重复 k 次，直到所有折都被用于训练和测试，但在每次迭代中，测试折中的任何元素都不会同时出现在训练折中。

### 总结与讨论

深度学习模拟并学习复杂数据集中可能存在的特征，使用多层处理单元来识别它们，就像人脑一样。最近，卷积神经网络在视觉计算领域产生了重大影响。

在视觉应用中，主要使用的深度学习模型是 CNN。CNN 模型的工作方式与许多其他学习模型截然不同，因为它们受到人类学习信息的生物过程的启发。

CNN 的架构由卷积层组成，这些层将多个滤波器应用于数据（例如图像）上，以获得一系列卷积特征图。它们还包含池化层，用于对这些特征图进行下采样。这些卷积层和池化层通常由一个或多个全连接层和一个 Softmax 输出层终止。全连接层与前一层和后续层相连。最后一层称为输出层，通常根据类别拥有神经元，每个类别由一个神经元表示。最后，最后一层通常执行 Softmax 操作，值最高的类别被模型选为预测结果。

通过反向传播和更新函数，CNN 可以学习各层的滤波器，而神经元层间的权重是全连接层中学习的目标函数。因此，利用反向传播，权重得到更新，网络不断迭代，直到在给定阈值下产生准确的输出。通常使用多个轮次来训练 CNN，因为这能得到一组良好、可泛化的学习滤波器和权重。

训练通常通过将数据分为三个子集来进行，其中训练集用于训练，验证集在训练期间用于检查模型在未见样本上的准确性，最后，测试集在训练后用于验证模型的性能。
