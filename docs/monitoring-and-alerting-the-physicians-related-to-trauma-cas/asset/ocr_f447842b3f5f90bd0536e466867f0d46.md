# 3.2.  IoT server

Sensors detect the physiological indicators as soon as the trauma patient enters the treatment center grounds, and these signs are then changed to electrical signs [30]. Then, an advanced electrical flag that is stored in Radio Frequency Identification (RFID) is switched out for a

basic electrical flag [31]. Zigbee’s put protocol is an acceptable standard for this framework since it allows computerized information to be communicated to the local server. Smaller and more energy-efficient devices are given a higher consideration. Through WLAN, data is sent from a nearby server to the therapeutic server [32].

When the information is sent to the trauma server, it is first verified that the trauma patient hasn’t already had a medical record added to it before the server sends the new information to the expert. The server creates a new ID and keeps the data in its database if the patient has no past therapy records [33]. The trauma expert is informed of this information.
