## 3. Proposed methodology

A cloud-based network provides access to the suggested health monitoring system in this research, which has been created using a mix of IoT elements and ML algorithms. Several embedded sensors have been used in the system’s development to provide remote health monitoring of the trauma patient. On the basis of the symptoms and current biological data, it has also been developed to forecast the severity of trauma cases.

The suggested approaches architecture is illustrated in a block diagram in Fig. 2. The discrete blocks, each of which represents a particular component of the system may be made up of a variety of different kinds of equipment serving the desired function. Maintaining communication among the patient, the cloud network, and the healthcare experts is the responsibility of the Raspberry Pi, which acts as the central processing unit. DL techniques are used to build the program in the cloud network for predicting the existence of trauma sickness. The Arduino module is linked to various kinds of embedded multiple sensors, and then the Raspberry Pi is attached to it. Additionally, linked to the touchscreen display and surveillance camera Raspberry Pi [27]. The Raspberry Pi is trained to analyze various sorts of data using algorithms and computer vision methods. To create applications for the Raspberry Pi in this system, OpenCV is used. Healthcare experts have access to the cloud network where the data has been analyzed, and they may also provide the patients the appropriate instructions over the network.
