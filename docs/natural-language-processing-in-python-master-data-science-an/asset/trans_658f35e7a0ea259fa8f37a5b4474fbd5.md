## 机器对话

我们有像 `Siri` 和 `Cortana` 这样的应用，你可以对它们说出简单的短语来命令计算机做某事，这实际上是一个非常难的问题。除了文本处理之外，这里还有一个额外的阶段，即它必须将你的声音转换为单词字符串。以 Geoffrey Hinton 最喜欢的例子为例，“recognize speech”（识别语音）听起来几乎和 “wreck a nice beach”（毁坏一个美丽的海滩）一样——但通过概率分析，我们可以得出结论，“recognize speech” 的可能性更大。

# 为什么 NLP 很难？

因为语言是模棱两可的！

你可能听过数学是通用语言这句话。这是真的，因为数学是精确的。在语言中，你有同义词（两个意思相同的词），也有同音词/同形词（发音相同或拼写相同但意思不同的词）。

## 模糊性示例

**“Republicans Grill IRS Chief Over Lost Emails”**

这种句子因其两种截然不同的解释而大有可为：

* 共和党人就邮件问题严厉盘问 IRS 局长
* 共和党人用邮件作燃料烤 IRS 局长

**“I saw a man on a hill with a telescope.”**

这看似是个简单的陈述，直到你开始拆解其中的多种备选含义：

* 山上有个男人，我用望远镜看着他。
* 山上有个男人，我看见了他，他有个望远镜。
* 有个男人，他在一座山上，那座山上也有一架望远镜。
* 我在山上，我看见一个男人在使用望远镜。

NLP 之所以难的另一个原因是，如果你看的是像 Twitter 这样的东西——顺便说一句，许多人已将 NLP 应用于 Twitter——Twitter 上的大多数人甚至不使用真正的英语单词！由于字符限制，人们使用像 “U”、“UR”、“LOL” 这样的简写。那 “netflix and chill” 又该如何处理？

# 第 2 章：常见 NLP 操作

在本章中，我们将讨论对文本数据进行的一些常见数据预处理操作，以便使其“适配”典型的机器学习算法，如 `Naive Bayes`（朴素贝叶斯）、`Decision Trees`（决策树）、`Logistic Regression`（逻辑回归）等。

主要思想是，所有这些算法都作用于数字向量，而文本绝对不是数字向量。

那么我们如何将文本转换为数字向量呢？

## 词袋模型

将文本转换为数字的最简单方法是“词袋”技术。这意味着单词没有顺序。它只是在说“这是这篇文档中的单词”。

最简单的方法是拥有一个向量，只是告诉我们，“是的，这个词在”，或者“不，这个词不在”。

例如，如果我们想表示句子 “Dog eat dog”（狗吃狗/弱肉强食）——而我的词汇表包含以下单词：

* Cat（猫）
* Dog（狗）
* Fish（鱼）
* Rabbit（兔子）
* Eat（吃）

那么我的向量表示将是 `(0, 1, 0, 0, 1)`。

注意这里发生了什么。我为向量中的每个位置分配了一个单词。

第 0 个位置是 “cat”，第 1 个位置是 “dog”，第 2 个位置是 “fish”，依此类推。

这种技术也被称为“独热编码”，通常用于数据科学和机器学习中处理分类变量时。

我们这样做的原因与在 NLP 中相同——类别不是数字，我们需要将它们转换为数字。

你可能也见过这个概念被称为“指示变量”。是一回事。

## 词频

注意，当我们使用指示变量时会丢失数据，因为它无法告诉我们一个词出现了多少次，只能告诉我们它出没出现过。

你可以想象，如果 “Einstein”（爱因斯坦）和 “physics”（物理）在一篇文档中频繁出现，那它很可能是一篇关于物理和阿尔伯特·爱因斯坦的文档。然而，如果你只看到一次 “Einstein”，它可能与阿尔伯特·爱因斯坦和物理毫无关系，因为有人可能只是在讽刺地说，“Nice one, Einstein”（干得漂亮，爱因斯坦/聪明鬼）。

在这种情况下，“dog eat dog” 变为：

`(0, 2, 0, 0, 1)`

对于许多机器学习算法，我们希望数据先经过归一化。有时这意味着减去均值并除以标准差，有时意味着转换所有值使其落在 0 和 1 之间。

在 NLP 中，通常是后者，因为词的负频率讲不通。

在这种情况下，“dog eat dog” 变为：

`(0, 0.67, 0, 0, 0.33)`

## TF-IDF

词频仍然不完美。

想想 “the”、“is” 和 “it” 这样的词。

这些是常见词，很可能出现在每篇文档中。由于太常见，它们几乎无法告诉你文档实际讲的是什么。也就是说，如果我告诉你 “the” 出现了 500 次，你能预测文档的主题吗？

TF-IDF 是一种缓解此问题的技术。

TF 代表 “term frequency”（词频），IDF 代表 “inverse document frequency”（逆文档频率）。

从上述定义可以看出，当一个词出现得更频繁时，该度量值会更大；如果它出现在各种各样的文档中，该度量值会更小。

我们通常不使用原始计数来衡量这些，而是取 `log()`。

做这件事没有“官方”的、固定的方法。

`TF(t, d)` 部分可以按如下方式计算：

* **二值**：0、1 指示器（如上所述）
* **原始频率**：`f(t, d) = 词项 t 在文档 d 中出现的次数`
* **对数归一化**：`log(1 + f(t, d))`

逆文档频率也有几种变体，大多使用 `log()` 函数。

* **标准 IDF**：`log(N / n(t))`，其中 `n(t)` 是包含词项 `t` 的文档数量
* **平滑 IDF**：`log(1 + N/n(t))`
* **概率 IDF**：`log((N - n(t)) / n(t))`
