
在大多数机器学习问题中，我们经常看到数据矩阵 `X` 的定义方式是：每一行是一个样本，每一列是一个输入特征。

因此，我们得到一个 `N x D` 的矩阵 `X`，其中有 `N` 个样本和 `D` 个特征。

在 NLP 中，你经常会看到相反的情况，即矩阵 `X` 的组织方式是：每一列是一个样本，每一行是一个特征。

这只是约定俗成的问题。

你会发现，当我们进行奇异值分解时，这实际上相当于做了 2 次 PCA，一次是在 `X` 的 `DxD` 协方差矩阵上，另一次是在 `X` 转置后的 `NxN` 协方差矩阵上。

# 第 3 章：构建你自己的垃圾邮件检测器

## 数据描述

在本章中，我们将构建自己的**“垃圾邮件检测器”**。

我们将查看一个公开可用的预处理数据集，你可以在此处找到：[https://archive.ics.uci.edu/ml/datasets/Spambase](https://archive.ics.uci.edu/ml/datasets/Spambase)

我希望你从这个例子中得到两点重要启示：

1. 很多时候，我们在 NLP 中所做的工作是为现有算法预处理数据。那么问题在于：如何获取一堆文档（本质上只是文本块），并将它们输入到其他机器学习算法中，而这些算法的输入通常是一个数字向量？

   注意，我们在上一章已经涵盖了这一点，所以现在要做的只是将其“即插即用”地接入 ML 库。

2. 我们几乎可以使用**任何**现有的 ML 分类器来解决这个问题。因此，你可以利用从其他统计和机器学习课程中获得的所有知识，加上一点文本处理并考虑语言的细微差别，你就或多或少在做 NLP 了。

话虽如此，我们将在这个例子中使用 `sci-kit learn` 库——而不是自己编写 Naive Bayes。

不过，我们应该讨论一下数据是如何预处理的。网站上的文档说数据是按我们在上一章描述的方式进行归一化的，随后再乘以 100。

注意每一行是一个数据点（所以它是一个 `N x D` 矩阵）。前 48 列是“词频比例”，即该词在邮件中出现的次数，除以邮件中的总词数，再乘以 100。

最后一列是标签，1 表示垃圾邮件，0 表示非垃圾邮件。

其余列我们将忽略。

注意，我们也可以将其视为“词-文档”矩阵，我们稍后会更深入地讨论这点。

基本上这意味着在一个维度上你有每个文档，在另一个维度上你有术语频率的某种度量。

既然你知道了数据是如何生成的，让我们继续构建分类器。

第一步是导入所有需要的库：

```python
from sklearn.naive_bayes import MultinomialNB
import pandas as pd
import numpy as np
```

接下来，我们使用 Pandas 加载数据，这使得将 CSV 转换为矩阵变得超级简单。

```python
data = pd.read_csv('spambase.data').as_matrix()
np.random.shuffle(data)
```

第三，我们分配 `X` 和 `Y`：

```python
X = data[:, :48]
Y = data[:, -1]
```

接下来，我们将最后 100 行作为测试集：

```python
Xtrain = X[:-100,]
Ytrain = Y[:-100,]
Xtest = X[-100:,]
Ytest = Y[-100:,]
```

接下来，我们在训练数据上训练模型，并在测试数据上检查分类率：

```python
model = MultinomialNB()
model.fit(Xtrain, Ytrain)
print("Classification rate for NB:", model.score(Xtest, Ytest))
```

试运行一下，看看得分如何。

接下来，让我们尝试一个更强大的分类器。记住，所有这些机器学习模型的 API 是相同的。任务的很大一部分是将 `X` 和 `Y` 转换为正确的格式以输入这些 API。

```python
from sklearn.ensemble import AdaBoostClassifier
model = AdaBoostClassifier()
model.fit(Xtrain, Ytrain)
print("Classification rate for AdaBoost:", model.score(Xtest, Ytest))
```

试运行一下，看看分数提高了多少。

# 第 4 章：构建你自己的情感分析工具

在本章中，我将向你介绍情感分析。情感是衡量某事物积极或消极程度的指标。这立即适用于亚马逊评论、推文、Yelp 评论、酒店评论等。

我们想知道——仅凭词语，这句话是积极的还是消极的？

我们将在本书中构建一个非常简单的情感分析器，在本节中，我想在开始编写代码之前，深入探讨一下我们将如何构建它。你会发现有很多细微之处，如果我们选择解决它们，可能会变成大问题。

首先，让我们看看将要使用的数据集。它可以在此 URL 找到：[https://www.cs.jhu.edu/~mdredze/datasets/sentiment/index2.html](https://www.cs.jhu.edu/~mdredze/datasets/sentiment/index2.html)

作者已经为我们标记了数据，所以我们可以利用这一知识。这些是亚马逊评论，带有 5 星评分，我们将查看电子产品类别。

首先，是我们要预测什么的问题。我们可以将 5 星评论作为目标并尝试对它们进行回归。相反，我们将使问题稍微简单化——仅利用它们已被分类为正面或负面的事实。

数据采用 XML 格式——所以我们将使用 XML 解析器。

我们将忽略所有额外数据，仅使用 `review_text` 键内的文本。

为了创建特征向量，我们将执行与处理第一个数据集相同的操作——统计每个词的出现次数，并除以总词数。

为此，我们必须对数据进行两次遍历——第一次收集不同单词的总数，以便知道特征向量的大小，并可能移除停用词（如数字、“this”、“is”、“I”、“to”等）以减小词汇表大小。这是为了知道每个 token 的索引。

第二次遍历将实际分配每个数据向量。

注意，这比垃圾邮件检测示例要复杂得多，因为那个例子的数据在我们下载前已经处理好了。

一旦我们有了这些，就只是创建一个像垃圾邮件检测器那样的分类器的问题了！

如果我们使用像逻辑回归这样的模型——我们可以查看学习到的模型的权重，以获得每个输入词的“分数”。这将告诉我们，如果我们看到像“horrible”这样的词，且其权重为 -1，那么这个词与负面评论相关。
