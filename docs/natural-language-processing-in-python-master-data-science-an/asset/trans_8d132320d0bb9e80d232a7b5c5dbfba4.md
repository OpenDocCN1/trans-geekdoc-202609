# 第 6 章：潜在语义分析

什么是潜在语义分析（也称为“潜在语义索引”）？

之前我们解决了一些将单词转换为计数的问题，我们说如果这个词在垃圾邮件或负面情绪中大量出现，那么意味着该词与该标签相关联。

但如果你有多个含义相同的词怎么办？或者如果你有一个词可以有多个不同的含义怎么办？

那我们就有麻烦了！这两个问题被称为同义词和多义词。

维基百科中的一些例子：

## 同义词：

- “buy” 和 “purchase”
- “big” 和 “large”
- “quick” 和 “speedy”

## 多义词：

- “Man” - 作为人类区别于动物，或作为男性区别于女性，或仅在随意语气下，“hey man！”
- “Milk” - 作为动词 “I’m going to milk it for all it’s worth”（我要榨干它的所有价值），或作为名词 “the cat is producing milk for its babies”（猫正在为宝宝产奶）

所以解决这个问题的一种方法是合并含义相似的词。例如，你可能会经常看到 “computer”（计算机）、“desktop”（台式机）和 “PC” 一起出现。这意味着它们高度相关。

你可以把它想象成一种“潜在变量”或隐藏变量，代表它们所有人——因此称为潜在语义分析。

LSA 的工作是找到这些变量，并将原始数据转换为这些新变量——希望这些新数据的维度远小于原始数据——这使我们能够加快计算速度。

重要的是要注意，LSA 通过合并相关变量肯定有助于解决同义词问题，但我见过关于它是否真的有助于解决多义词问题的相互矛盾的观点。

在下一节中，我们将讨论 LSA 背后的底层数学原理，然后我们将看一个现实世界的例子。

## PCA 和 SVD 回顾

LSA 本质上是将 SVD 应用于词-文档矩阵。PCA 是 SVD 的一种更简单形式，所以我们将先介绍它以建立直觉。

SVD = 奇异值分解

PCA = 主成分分析

我想强调这是可选的，仅适用于想要理解 LSA 背后数学原理的人。对于编码部分来说这不是必需的，因为那将只是解释 LSA 给出的答案。

让我们先看看 PCA，并用通用术语谈谈它的作用。从最基本的层面来看，它对所有输入向量进行变换，`z = Qx`。这是一个矩阵乘法，你知道当你用标量乘以向量时，会得到同方向的另一个向量，但如果你用矩阵乘以向量，可能会得到不同方向的向量。所以 PCA 旋转我们的原始输入向量，或者另一种思考方式是，这是同一个向量在一个不同的、旋转过的坐标系中。

PCA 为我们做 3 件事：

1.  它使我们所有的数据去相关。因此，新坐标系中的数据在任意 2 个输入特征之间具有 0 相关性。
2.  它按信息含量递减的顺序排列每个新维度。因此，第一个维度包含最多信息，第二个维度包含的信息少于第一个但多于第三个，依此类推。
3.  它允许我们降低数据的维度。因此，如果我们原始的词汇量是 1000 个词，我们可能会发现，当我们根据单词在每个文档中共现的频率将所有单词连接起来时，不同的“潜在”术语总数可能只有 100 个。这是 #2 的直接结果，因为如果较高维度包含的信息比如说少于总信息的 5%，你就可以切掉它们。

请注意，通过移除信息，你并不总是降低预测能力。PCA 的一个视角是它进行“去噪”。在词汇量大的 NLP 中，噪声非常普遍，因此通过这种平滑或去噪，当我们查看新数据时，实际上可以更好地泛化。

这 3 个想法给了我们关于这里需要做什么的重要提示。所有这些想法的核心项目是协方差矩阵。协方差矩阵的对角线告诉我们该维度的方差，非对角线告诉我们 2 个不同维度之间的相关程度。

回想一下，对于大多数经典统计方法，我们认为方差越大等同于信息越多。作为这一推论，考虑一个完全确定性的变量包含 0 信息。为什么？因为，如果我们已经可以精确预测这个变量，那么测量它不会告诉我们任何新东西，因为我们已经知道会得到什么答案！

协方差定义为：

`C(i,j) = E[(X_i - mu(i))(X_j - mu(j))]`

其中 `mu(i)` 是 `X_i` 的均值（X 的第 i 个特征）。

如果 `i = j`，你会看到这只是样本方差。

样本协方差则是：

`C(i,j) = sum[n=1..N]{ (X[n,i] - mu[i])(X[n,j] - mu[j]) } / N`

这个方程更方便的形式是矩阵表示法——“X 转置”乘以“X”除以“N”。注意我们去掉了均值，因为我们可以在进行任何处理之前先将数据中心化。

`C = X^T X / N`

你可以说服自己这是正确的，因为“X 转置”是 D x N 而“X”是 N x D，所以结果是 D x D。

好的，现在我们有了这个 D x D 协方差矩阵，我们用它做什么？我们当然要找到它的特征值和特征向量！

`Cq = lambda q`

结果发现正好有 D 个特征向量和 D 个特征值。我们将它们都放入矩阵中，将特征值放入一个称为“大 Lambda”的对角矩阵中，并将特征向量堆叠成一个称为“Q”的矩阵，这是我们之前见过的。我们将按降序对特征值和相应的特征向量进行排序。

用矩阵形式表示就是：

`CQ = Q Lambda`

我们可以证明大 Lambda 实际上就是变换后数据的协方差。由于所有非对角线元素都是 0（因为它是对角矩阵），这意味着变换后的数据完全去相关了。
