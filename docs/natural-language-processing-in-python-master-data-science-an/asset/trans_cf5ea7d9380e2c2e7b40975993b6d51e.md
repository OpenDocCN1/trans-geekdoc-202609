

# 文章重写器

我们如何建模给定周围单词时某个单词的概率？假设我们获取整个文档并标记所有单词，从而得到 `w(1), …, w(N)`。

然后我们可以建模任意单词 `w(i)` 在给定所有其他周围单词条件下的概率。

用概率符号表示为：

`P(w(i) | w(1), ... , w(i-1), w(i+1), … w(N))`

当然，这实际上行不通，因为如果我们考虑文档中的每一个单词，那么只有该文档本身才能完全匹配（即样本量为 1），所以我们将采用类似马尔可夫模型的方法，只考虑最近的单词。

我们将使用一种称为三元组的方法来实现这一点。基本上我们将创建三元组，存储 3 个连续单词的组合。我们将使用前一个单词和后一个单词来预测当前单词。

在数学上，这意味着我们将建模：

`P(w(i) | w(i-1), w(i+1))`

为了实现这一点，我们将创建一个字典，以 `(w(i-1), w(i+1))` 作为键，并随机采样 `w(i)`。

当然，我们不会替换文档中的每一个单词，因为那可能不会给我们带来任何有用的结果，所以我们将根据某个较小的概率来决定是否替换某个单词。

这和潜在语义分析都是我们所谓的“无监督学习”算法，因为它们没有标签，我们只是学习结构。相比之下，我们的垃圾邮件分类器和情感分析器是“监督学习”问题，因为我们有标签可供匹配。

## 文章重写器代码

在这个代码示例中，我们将重用我们的亚马逊评论数据。

```python
import nltk
import random
import numpy as np
from bs4 import BeautifulSoup

positive_reviews = BeautifulSoup(
    open(
        'electronics/positive.review'
    ).read())
positive_reviews = positive_reviews.findAll('review_text')
```

这一次，我们只看正面评论。

接下来，我们提取三元组。键将是首尾单词。值将是可能的中间单词数组。

```python
trigrams = {}

for review in positive_reviews:
    s = review.text.lower()
    tokens = nltk.tokenize.word_tokenize(s)
    for i in xrange(len(tokens) - 2):
        k = (tokens[i], tokens[i+2])
        if k not in trigrams:
            trigrams[k] = []
        trigrams[k].append(tokens[i+1])
```

接下来，我们要将每个中间单词数组转换为概率向量。

```python
trigram_probabilities = {}

for k, words in trigrams.iteritems():
    # 创建一个单词 -> 计数的字典
    if len(set(words)) > 1:
        # 只有当中间单词有不同可能性时才执行此操作
        d = {}
        n = 0
        for w in words:
            if w not in d:
                d[w] = 0
            d[w] += 1
            n += 1
        for w, c in d.iteritems():
            d[w] = float(c) / n
        trigram_probabilities[k] = d
```

这意味着如果可能的中间单词是 `["cat", "cat", "dog"]`，那么我们现在将得到一个字典 `{"cat": 0.67, "dog": 0.33}`。

因此，如果我们遇到上下文提供了这些可能性的情况，那么我们将以 2/3 的概率插入“cat”作为中间单词，以 1/3 的概率插入“dog”。

接下来，我们将创建一种从字典中随机采样的方法。

```python
def random_sample(d):
    # 从字典中选择一个随机样本，其中值为概率
    r = random.random()
    cumulative = 0
    for w, p in d.iteritems():
        cumulative += p
        if r < cumulative:
            return w
```

最后，让我们编写一个函数来测试重写器。

```python
def test_spinner():
    review = random.choice(positive_reviews)
    s = review.text.lower()
    print "Original:", s
    tokens = nltk.tokenize.word_tokenize(s)
    for i in xrange(len(tokens) - 2):
        if random.random() < 0.2: # 20% 替换几率
            k = (tokens[i], tokens[i+2])
            if k in trigram_probabilities:
                w = random_sample(trigram_probabilities[k])
                tokens[i+1] = w
    print "Spun:"
    print " ".join(tokens).replace(" .", ".").replace(" '", "'").replace(" ,", ",").replace("$ ", "$").replace(" !", "!")
```

最后一行替换了我注意到总是出现在奇怪位置的一些标点符号。或者，你也可以像前几章那样使用自定义分词器来替换标点符号。

**原文：**

> i downloaded the driver from trendnet's website before installing the adapter. i did not encounter any problems at all, including the issue that some users had with it disconnecting when they plugged in another usb device

**重写后：**

> i downloaded the driver from trendnet's limits before installing the adapter. i did not encounter any problems at all, including the issue that new users had with it disconnecting when they plugged in another usb device

**原文：**

**重写后：**
