

由于我们可以按任意顺序对特征值进行排序，因此我们可以确保最大的特征值排在前面——请记住，特征值就是变换后数据的方差。

如果你想更深入地了解并实际推导所有数学细节，我建议查看我的免费教程——你可以在 [http://lazyprogrammer.me/tutorial-principal-components-analysis-pca/](http://lazyprogrammer.me/tutorial-principal-components-analysis-pca/) 找到它。

通常在 NLP 中，我们会创建所谓的“词-文档”矩阵。你可以把每个词看作每个输入维度，把每个文档看作每个样本。请注意，这与我们通常处理的方式相反，通常样本沿行排列，输入特征沿列排列。

我们刚才用 PCA 所做的就是合并相似的词。但如果我们想合并相似的文档呢？

那么，我们只需在转置原始矩阵后进行 PCA 即可！会发生一件奇怪的事：即使我们得到了一个 `N x N` 的协方差矩阵，仍然只有 `D` 个特征值。不仅如此，令人惊讶的是，它们与从另一个协方差矩阵中找到的特征值竟然是相同的！

现在你知道 PCA 能发现输入特征之间的相关性，而对转置数据进行 PCA 能发现输入样本之间的相关性，我们已经准备好来谈论 SVD 了。

结果表明，SVD 只是同时完成这两个 PCA。

所以我们的做法是：我们找到 `X X^T` 的特征向量，称之为 `U`。

然后我们找到 `X^T X` 的特征向量，称之为 `V`。

请记住，我们排列这些特征向量，使得对应的特征值按降序排列。在 SVD 中，我们实际上取特征值的平方根，并将它们放入一个称为 `S` 的矩阵中。

一旦完成所有这些步骤，我们就可以将 `X`、`U`、`S` 和 `V` 联系起来：

`X = USV^T`

这就是“奇异值分解”中“分解”的含义。

接下来，我们再次定义一个分词器。

```
def my_tokenizer(s):
    s = s.lower() # downcase
    tokens = nltk.tokenize.word_tokenize(s) # split string into words (tokens)
    tokens = [t for t in tokens if len(t) > 2] # remove short words, they're probably not useful
    tokens = [wordnet_lemmatizer.lemmatize(t) for t in tokens] # put words into base form
    tokens = [t for t in tokens if t not in stopwords] # remove stopwords
    tokens = [t for t in tokens if not any(c.isdigit() for c in t)] # remove any digits, i.e. "3rd edition"
    return tokens
```

请注意这里多了一个额外步骤——如果一个词元包含数字，我就将其丢弃。

我们再次创建一个词到索引的映射：

```
word_index_map = {}
current_index = 0
all_tokens = []
all_titles = []
index_word_map = []

for title in titles:
    try:
        title = title.encode('ascii', 'ignore') # this will throw exception if bad characters
        all_titles.append(title)
        tokens = my_tokenizer(title)
        all_tokens.append(tokens)
        for token in tokens:
            if token not in word_index_map:
                word_index_map[token] = current_index
                current_index += 1
        index_word_map.append(token)
    except:
        pass
```

我下载的数据集中有一些坏字符，所以我们将直接忽略那些行。

我们再次定义一个函数将词元转换为特征向量：

```
def tokens_to_vector(tokens):
    x = np.zeros(len(word_index_map))
    for t in tokens:
        i = word_index_map[t]
        x[i] = 1
    return x
```

请注意，在这个例子中我们没有标签。PCA 和 SVD 是无监督算法。它们用于学习数据的结构，而不是进行预测。

接下来，我们创建数据矩阵。

```
N = len(all_tokens)
D = len(word_index_map)
X = np.zeros((D, N)) # terms will go along rows, documents along columns
i = 0
for tokens in all_tokens:
    X[:,i] = tokens_to_vector(tokens)
    i += 1
```

请注意，这里我们偏离了正常的 `N x D` 矩阵，转而创建一个 `D x N` 的数据矩阵。

最后，我们使用 SVD 创建数据的散点图（相当于将维度降低到 2 维），并用相应的词标注每个点。

```
svd = TruncatedSVD()
Z = svd.fit_transform(X)
plt.scatter(Z[:,0], Z[:,1])
for i in xrange(D):
    plt.annotate(s=index_word_map[i], xy=(Z[i,0], Z[i,1]))
plt.show()
```

# 第 7 章：构建你自己的文章重写器

文章重写是在互联网营销中某种程度上的“圣杯”。为什么？互联网企业家通常喜欢尽可能自动化他们的业务。他们一天只有那么多时间，所以为了扩大规模，他们必须找到让计算机为他们工作的方法。

最耗时的任务之一是内容生成。理想情况下，人类会创建内容，就像我创建这本书一样。在早期，人们只是在网页上重复关键词 1000 次，以便在搜索引擎中获得更高的排名。最终搜索引擎识破了这一点。然后营销人员开始直接窃取他人的内容并放在自己的网站上。但你可以看出，搜索引擎旨在为用户提供最有用的结果，它不希望发生这种情况，因为结果是，如果你搜索某样东西，你最终只会得到多份相同的东西。所以现在重复内容被禁止了。搜索引擎每天都在进化，跟上它们的唯一途径就是拥有独特、高质量的内容。

互联网营销人员一直感兴趣的一件事是文章重写。本质上就是获取一篇非常流行的现有文章，并修改某些词或短语，使其不完全匹配原文，从而防止搜索引擎将其标记为重复内容。

如何做到这一点？你可以想象同义词扮演了重要角色。如果你只是用意思相同的其他词替换某些词，你最终会得到一篇含义相同但不同的文章。

当然，现实中事情并不总是那么顺利。

让我们以 Udemy 对自己的描述为例：

“Udemy.com is a platform or marketplace for online learning.”

现在让我们用我在 thesaurus.com 找到的同义词替换每个**加粗的词**。

“Udemy.com is a podium or forum for online research.”

你可以看到这个新句子讲不太通。

对于句子和完整文档，上下文很重要。所以思路是你想利用周围的词来影响当前词的替换。
