**逻辑运算符**

逻辑运算符用于评估条件语句的真假。主要有三种：`or`、`and`、`not`。

*   `or`: 当 `x` 为假时，会评估 `y`。如果 `x` 为真，则直接返回 `x` 的值。

*   `and`: 当 `x` 为假时，会评估 `x`。如果 `x` 为真，则会继续评估 `y`。

*   `not`: 当 `x` 为假时返回 `True`，当 `x` 为真时返回 `False`。

**赋值运算符**

赋值运算符使用 `=` 将值赋给变量。例如，要让变量等于 100，就写 `var = 100`。赋值运算符帮助编译器知道变量的值。

你可以一次性赋多个值给同一个变量，只要使用正确的符号和分隔符，变量就可以保存多个值。

使用运算符可以让代码更易处理。你可以把变量相加，进行其他数学运算，给变量赋值，甚至进行比较，帮助理解程序的工作原理。花点时间写几段使用这些运算符的代码，会发现其实很简单！
