
# 第 7 章 如何删除病毒

如果您怀疑病毒已感染您的电脑或手机，但不知道如何验证以及如何解决问题，应采取的措施如下。

## 从智能手机中清除病毒

### Android 系统

Android 设备无需安装杀毒软件，因为系统设置会自动阻止安装可能损害设备的未知应用程序。要检查此设置，请进入“设置”，然后点击“安全”，查看“未知来源”选项是否已禁用。如果您使用的是 Android 8 或更高版本，请进入“设置” > “应用和通知” > “高级” > “特殊应用访问权限” > “安装未知应用”。确保列表中的所有应用均标记为“不允许”。如果不是，请将开关从左向右拨动。

我建议您不要对 Android 设备进行 Root 操作以获取所有权限。这种做法会使您的 Android 设备变得脆弱，并暴露于严重危险之中，因为它常被用来绕过某些 App 的保护系统。

Google Play Protect 是面向所有 Android 系统的免费服务，它会定期扫描 Play Store 中的所有应用以及您设备上已安装的应用，以验证其安全性。要验证该服务是否处于激活状态，请打开 Play Store，从左上角的菜单中选择“Play 保护机制”。确保其旁边的“扫描设备以查找安全威胁”复选框处于激活状态。您还可以勾选下一项“提升有害应用检测功能”，以增强安全性。

为了识别并解决智能手机可能存在的问题，Android 允许您进入安全模式。没有标准的统一操作流程，以下提供两种方法。

**方法 1**：长按 Android 设备的物理电源/锁屏按钮。当选项出现时，长按“关机”选项，直到出现“重启进入安全模式”选项，然后点击“确定”。

**方法 2**：在开机或关机时，一旦设备制造商的 Logo 出现，立即长按音量减键（或 Home 键）。屏幕将显示“安全模式”。

进入安全模式后，检查已安装应用列表，看是否有您认为未自行安装的应用。请小心甄别，因为一些您不认识的应用可能对操作系统至关重要。如果您没有 Root 权限，反而更好，因为您将无法卸载系统应用。

如果您找到了恶意应用，点击它，然后点击卸载。如果无法移除某个 App，它很可能拥有设备管理权限，因此您必须先撤销该权限，然后再卸载。要移除此权限，请进入“设置” > “安全” > “设备管理器”。找到恶意 App 后，取消勾选。

要退出安全模式，请重启手机。

如果无法按照上述步骤删除病毒，建议执行恢复出厂设置。恢复出厂设置可将手机恢复到购买时的状态。购买后安装的所有数据和应用程序将被删除。因此，备份设备文件以防止数据丢失非常重要。

要开始此过程，请进入“设置” > “备份和重置” > “恢复出厂设置”。如果您使用的是 Android 8，请进入“设置” > “系统” > “重置选项” > “擦除所有数据”。

### iOS 系统

Apple 设备的操作系统很安全，感染病毒的风险很低。一切取决于您如何使用设备；越狱和从非官方来源安装 App 始终是不推荐的。越狱允许您绕过 Apple 对其 iOS 操作系统施加的限制。这种做法会使系统变得脆弱，并可能导致设备损坏，进而引发恶意软件的安装。

## 从电脑中删除病毒

我们假设防御潜在攻击的最佳方式是预防。安装一款优秀的杀毒软件绝对是最好的预防措施。

Bitdefender Free 是一款免费杀毒软件，可全方位保护系统：从互联网打开和下载的文件、即时通讯服务上的通信、通过 P2P 下载的项目等。下载名为 `Antivirus_Free_Edition.exe` 的安装包后，点击“是”按钮，并从下拉菜单中选择语言。要获得 Bitdefender Free 的免费版本，您需要在 MyBitdefender 注册，否则该程序副本将在 30 天试用期后过期。

要开始全盘扫描，请右键点击新安装的程序图标，然后选择“全盘扫描”。过程结束后，将显示一份报告，列出所有扫描过的文件、检测到的任何威胁以及采取的操作。您也可以将单个文件直接拖拽到 Bitdefender 图标上进行扫描。

另一款优秀的免费杀毒软件是 Avira Free Antivirus。它具有与 Bitdefender 相同的功能，但占用资源较大。

### 使用“自启动”杀毒软件

在某些情况下，无法使用常规杀毒软件删除计算机上的病毒。必须强制介入。也就是说，必须在计算机启动阶段、操作系统启动*之前*进行介入。这可以通过专用工具实现，将工具下载并安装在 CD 或 USB 闪存盘上。

我推荐的第一个工具是 Bitdefender Rescue CD。该工具需要活动的互联网连接，以便更新病毒库并检测最新威胁。

要下载该程序，请访问官方网站，点击“To create a Bitdefender Rescue CD on a CD/DVD you need the ISO image which care be downloaded from here”（创建 Bitdefender Rescue CD 需要 ISO 镜像，可从此处下载）。然后选择将杀毒软件刻录到 CD/DVD，还是复制到 USB 闪存盘。

如果您决定刻录到 CD，请使用任意刻录软件。如果您决定复制到 USB 闪存盘，可以下载 Bitdefender 提供的免费软件。点击“Stickifier executable”（启动盘制作工具）。选择杀毒软件的 ISO 镜像，然后选择要复制文件的 USB 闪存盘。

要扫描您的计算机，请插入 USB 闪存盘（或 CD）。当杀毒软件界面出现时，点击“Start the Bitdefender Rescue CD”以启动 Bitdefender Rescue CD。如果界面未出现，则需要修改 BIOS 设置。进入 BIOS，将 CD/DVD 驱动器或 USB 端口设置为首选启动设备。

在软件许可协议窗口中，勾选“By checking this box I agree to the license agreement lists above”（勾选此框即表示我同意上述许可协议），然后点击“Continue”（继续）。病毒库将更新，要开始扫描，请先点击“Scan now”（立即扫描），然后点击“Start”（开始）。

另一款自启动杀毒软件是 Kaspersky Rescue Disk。从官网下载程序，点击“Download & Info”（下载与信息），然后点击“Distribute”（分发）按钮。选择将杀毒软件下载到 CD 还是 USB 闪存盘。

重启系统并从新创建的介质启动。当出现“Press any key to enter the menu”（按任意键进入菜单）提示时，按任意键。Kaspersky 将自动启动。按数字键 1 并选择“Kaspersky Rescue Disk Graphic Mode”（卡巴斯基救援盘图形模式）。点击“My update center”（我的更新中心），然后点击“Start”（开始）以启动病毒库更新。

在开始全系统扫描之前，您必须确保在“对象扫描”选项卡上已勾选“Disk boot sectors”（磁盘引导扇区）、“Hidden startup objects”（隐藏启动对象）和“C”。按下“Start objects scan”（开始对象扫描）按钮以启动扫描。

有些类型的恶意软件或广告软件能逃避杀毒软件的查杀。通常，这些威胁不如病毒激进，但仍然令人烦恼。例如，那些安装工具栏并将导航重定向到充满广告的网站的软件。为了对抗这类恶意软件，建议安装免费软件，如“Adwcleaner”和“Malwarebytes”。

## 如何手动从电脑中删除病毒

要手动从电脑中删除病毒，您需要具备对计算机及其操作系统运作的高级知识。事实上，您需要识别受感染的文件并将其删除，或卸载包含该文件的程序。如果操作不当，可能会损害计算机的运行，最坏的情况下，将不得不重新格式化电脑，导致其中所有数据丢失。

### 在 PC 上

如果您使用的是 Windows，第一步是创建一个还原点，以便在操作系统稳定性受损时使用。

同时按下 `Ctrl+Shift+Esc` 键启动“任务管理器”。点击“详细信息”，然后点击“进程”选项卡。检查正在运行的进程列表，如果发现可疑项目，请记下并在 Google 上搜索。

如果您确定正在运行的进程是病毒，请右键点击可疑进程，选择“打开文件位置”。访问 VirusTotal 网站，将可疑文件拖拽到网页区域。VirusTotal 将分析该文件，如果确认被感染，您必须将其删除。

要删除受感染的文件，请转到“进程”选项卡，右键点击受感染文件的名称，从菜单中选择“结束进程树”，并点击“是”按钮确认。

如果受感染的文件属于某个程序，请进入“控制面板” > “程序和功能” > “卸载程序”。选择该程序并点击“卸载”。

您也可以通过右键点击文件，同时按住“Shift”键选择“删除”，然后按“是”来删除受感染的文件。此过程可能会影响操作系统的运行，或留下不可见的病毒残留。

手动删除病毒后，重启计算机，并检查 Windows 启动时自动运行的程序。如果再次发现该程序，必须将其从启动列表中移除。

如果您使用的是 Windows 10，请进入“任务管理器”，点击“启动”，找到该文件，右键点击并选择“禁用”。

如果您使用的是旧版 Windows，请同时按下 `Win+R`。将出现一个面板，输入命令 `msconfig`，按“回车”并点击“启动”选项卡。找到受感染的程序后，取消勾选，点击“确定”，然后点击“重新启动”以立即重启计算机。
