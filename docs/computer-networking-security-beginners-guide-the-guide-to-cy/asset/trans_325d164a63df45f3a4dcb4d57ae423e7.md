
# 第 5 章 在互联网上安全冲浪

在互联网上冲浪会增加受恶意软件影响的可能性，仅仅是访问一个网站就可能中招。最危险的网站并非人们通常能想到的那些，比如在线游戏网站或色情网站。事实上，这些网站非常警惕，会确保其用户免受恶意软件等潜在威胁的侵害。恶意软件更有可能在航空公司、报纸、食品或保险网站上感染。这些网站因产生高流量而更吸引破解者。通常，破解者利用 Javascript 攻击浏览器或其插件的漏洞，以下载并安装其恶意软件。破解者使用的另一种方法是通过视频编解码器下载受感染的文件，没有它就无法观看某部电影。在某些情况下，恶意软件可能包含在广告横幅中。最后，破解者可以创建真正的网站陷阱，通过 Facebook 上的消息引诱坏人访问这些网站，但使用缩短的地址，让你无法了解将要去往何处。一旦破解者成功安装恶意软件，他就可以为所欲为。

为了防御网络上的潜在攻击，你需要保持浏览器和插件为最新版本。如果插件仅按需激活，效果会更好。为了阻止 Javascript 程序和广告横幅的执行，建议在前一种情况下安装“脚本拦截器”，在后一种情况下安装“广告拦截器”。我们可以编制一个“白名单”，并将所有我们信任的网站加入其中。优秀的杀毒软件结合优秀的反恶意软件，可保证对传入文件的保护和对互联网流量的控制，以阻止访问危险网站。客户端安全软件可以控制并阻止对网站的访问，并防范可执行文件。

## 免费 Wi-Fi 网络

破解者青睐的狩猎场是免费 Wi-Fi 网络，即无需付费的网络。免费 Wi-Fi 网络易于接入，且不存在被识别的风险。事实上，在这些网络中，破解者可以实施中间人攻击。这包括让受害者以为自己已连接到 Wi-Fi，而实际上其数据流经过了破解者的计算机。反过来，破解者在检查并记录这些数据后，将其传递给热点，使偶然连接的人误以为自己直接连接到了 Wi-Fi 网络。最坏的情况是热点处于破解者的控制之下，甚至是由其创建以攻击所有连接者。在这种情况下，破解者控制着路由器。这种陷阱被称为“蜜罐”。也存在能够拦截尝试连接免费 Wi-Fi 网络设备的硬件设备，它们通过伪装成目标网络来响应连接尝试。最后，也有可能已感染恶意软件的计算机连接到网络，并试图将病毒传播给所有其他连接的终端。

### 如何保护自己

首先，建议在连接公共 Wi-Fi 网络时，避免进行敏感数据传输或访问各类服务的操作。使用 VPN 系统是在通过公共网络连接时确保安全的好工具。VPN 会加密连接期间交换的数据，使其对破解者不可用。此外，VPN 也应用于 Https 连接，因为这些连接很容易被拦截和解码。其他应采取的预防措施包括：

*   禁用文件共享
*   禁用自动连接免费 Wi-Fi 网络，这通常在各种终端上默认开启。

所有这些预防措施都是必要的，因为无法知道公共 Wi-Fi 网络是否安全。

## 使用防火墙监控活动

防火墙是一种保护系统，可以是软件或硬件，它通过保护两个不同的网络来防止未经授权的访问。操作系统 Windows 和 macOS 都集成了一个默认激活的防火墙（如有必要可将其停用）。但也可以下载第三方防火墙，如所谓的 `Windows Firewall Control`（适用于 Windows）和 `Little Snitch`（适用于 macOS），它们扩展了计算机上默认防火墙的功能，并允许你更轻松地监控网络活动。

# 第 6 章 如何防范外部设备威胁

外部组件，如 USB 记忆棒和光盘，易受感染。多年前，微软插入了一个名为 `Autorun.inf` 的文件，以简化非专家安装软件的过程。因此，当你插入外部组件时，Windows 会检查它是否包含 `Autorun.inf` 文件并运行它。因此，想要进入计算机的破解者可以将受感染的文件放入自动运行中，并将其隐藏在 USB 记忆棒上。一旦 USB 记忆棒插入计算机，它就会启动自动运行中的文件并感染计算机。平板电脑和智能手机也可能通过 USB 端口被感染。当你通过将智能手机连接到 USB 端口进行充电时，例如在机场、酒店或公共场所，病毒可能会感染你的设备。理论上，这些 USB 端口应仅连接到简单的电源变压器。据报道，这些简单的 USB 充电端口背后竟是真正的控制器，能够连接设备并窃取其中的数据。此类行动需要组织严密的破解者团伙。

为防止可能的 USB 感染，建议通过更改“注册表”设置来禁用计算机上的自动运行。如果你无法处理“注册表”，应咨询专家。F-Secure 的“mobile security”软件旨在防止来自 USB 记忆棒的感染。为防止智能手机遭受此类感染，我们建议使用“USB 保护套”。即一种 USB 延长线，其中的数据连接线已被移除，仅保留电源线。这样就不存在发起数据连接的可能性。

## 硬件设备被盗或丢失时

为了防止用于访问敏感数据的计算机被物理窃取，建议设置强密码以访问系统。然而，这并不能完全保护我们免受计算机上敏感数据被盗的威胁。因为蓄意作恶者可以将硬盘从计算机上拆下，并安装在另一台计算机上。这样他们就有可能访问数据。建议使用全盘加密。这样，即使将硬盘安装在另一台计算机上，没有访问密钥也无法读取数据。副作用是如果计算机故障，你可能无法恢复数据。这就是为什么始终建议备份数据。为增加安全性，你可以安装特定软件，在发生盗窃或丢失时擦除所有数据。为了保护智能手机免遭盗窃或丢失，已安装软件可将设备位置和使用者照片通过电子邮件发送给你。此外，在 Apple 和 Android 设备上，都引入了诸如“查找我的智能手机”之类的应用程序，允许你定位其位置。
