
# 保护工具

在大多数情况下，保持操作系统提供的保护处于激活状态即可：Microsoft 操作系统上的“Windows Defender”杀毒软件、Mac 上的“Gatekeeper”保护系统以及 Android 上的“Google Play Protect”。一个优秀的电子邮件保护系统是 F-Secure 提供的“E-mail and Server Security”，它能保护您公司的服务器、电子邮件和云系统。该工具基于行为分析以及白名单和黑名单的使用。安装杀毒软件可以保障您电子邮件的安全。您还可以添加反恶意软件以获得更高级别的安全性。这些程序可以定期运行，以检测任何隐藏良好和/或对杀毒软件不可见的运行中威胁。最强大有效的反恶意软件之一是 Malwarebytes。您可以在互联网上免费找到它。

# 第 3 章：避免从不可靠来源下载软件或应用

下载和安装盗版软件是法律禁止的，但考虑到海量的软件下载量，这并不是一个有效的威慑。最初，此类软件包含在 P2P 网络中（著名的 Torrent 和 eMule）。如今，我们也能在文件共享网络中找到它们（Rapidshare 的继任者）。通常，病毒隐藏在用于生成假序列号以激活主程序的程序中。当启动“Keygen”（注册机）时，它会请求更改系统的权限。此时，它可以为所欲为。它可以安装键盘记录器，甚至最坏的情况下安装勒索软件。即使安装合法软件也无法保护您免受风险。并非所有从 Play Store 下载的应用都是看起来那样。特别是著名应用和游戏的克隆版本往往是陷阱。这些克隆版本往往在官方 App 发布之前就已在平台上架。最脆弱的设备是智能手机和平板电脑等移动设备。特别是使用 Android 的设备，因为官方商店的审核不够严格，Google 往往只能在事后移除受感染的应用。您可以使用一些在线服务（如 VirusTotal）检查从商店下载的程序的可靠性，VirusTotal 是一款在线杀毒软件，使用 68 种不同的杀毒引擎来检查任何类型的文件（或互联网地址）。所有这些完全免费，且无需任何注册。WOT 是一项在线服务，允许您通过用户的意见和评价来分析网站的可靠性。对于企业网络，理想的解决方案是实施关于各设备软件的精确企业策略。此外，建议用户账户不应为“管理员”类型。管理员权限保留给 IT 人员。我们始终建议部署“Client Security”和“Protection service for Business”等杀毒软件，它们能够扫描文件并提供更高的安全性，阻止试图执行危险操作的软件。

# 第 4 章：进行更新

编写软件或 App 是一个如此庞大的过程，以至于几乎不可能预测所有可能的缺陷。所有软件或操作系统在编程时都包含关键点，即缺陷，黑客可利用这些缺陷潜入他人的计算机或计算机网络，并在用户毫不知情的情况下安装恶意程序。在计算机世界中，存在着一场持续的战争：一方是试图发现软件、操作系统和 App 中关键点并加以利用（通常用于非法目的）的黑客；另一方是测试程序以改进它们、检测缺陷并将其报告给制造商，以便制造商通过消除关键点来更新软件的白帽黑客。当黑客发现一个“关键点”，在行话中称为“零日漏洞”时，他会尝试准备一个“漏洞利用代码”。漏洞利用代码允许您进入 PC，成为其管理员。一旦进入 PC，黑客可以读取数据、修改或删除文件、窃取凭证或安装键盘记录器。在首批感染扩散后，软件制造商会通过消除关键点并更新程序来进行干预。随后，更新提醒会发送给所有用户。这就是执行更新的重要性。

## 更新类型

一般来说，有两类更新。

### 主要更新

这些更新用于提高性能并引入新功能。在进行此类更新之前，您需要检查计算机的兼容性。换句话说，可能需要更强大的功能。例如，如果操作系统受到此类更新的影响，可能需要更强大的内存或处理器。在这种情况下，如果涉及公司网络，您首先需要分析设备，然后在必要时进行更新。事实上，如果设备不达标，更新可能导致网络故障。

### 次要更新

这些更新用于修复错误、漏洞或安全漏洞。这些更新无预警发布，必须立即安装。在 App 中，通常会为这些类型的更新激活自动可用性通知。在版本更新的情况下，软件序列号的个位数增加。例如，Windows 7 升级到 Windows 8。在从前一个版本进行有限更改或改进的情况下，软件序列号的第一位小数增加。例如，Windows 8 升级到 Windows 8.1。如果更新涉及安全性，则第二位小数增加。例如，Windows 8.1.2。如果安全管理涉及计算机网络，我们建议使用集中管理系统，例如包含在 F-Secure 的“Protection Service for Business”和“Premium Business Suite”中的“Software Updater”。

## 智能手机

升级智能手机意味着保护自己免受所有可能的危险。不仅是 Google，智能手机制造商也在不断更新其设备。此外，原因始终相同：更新修复漏洞并防范新威胁。没有理由拒绝下载更新。如果您认为官方市场上的应用完全安全，那您就错了。App 可能包含受感染的链接，由于我们的粗心大意，我们甚至会下载来自未知来源的应用并打开链接。
