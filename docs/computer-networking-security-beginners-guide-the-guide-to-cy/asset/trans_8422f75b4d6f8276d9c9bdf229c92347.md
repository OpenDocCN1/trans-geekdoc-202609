

# 密码安全指南

## 破解者的威胁

破解者，即怀有非法意图的黑客，可以在几天内利用特殊程序发现您的简单密码，这些程序能够自动尝试每秒多达一千个密码。因此，如果破解者决定发现您的密码，您将毫无防备。如果破解者决定发起“暴力破解攻击”并利用技术规范，可以大幅缩短访问时间。

## 选择密码

选择密码时，重要的是避免常用单词，并确保选择不常见的术语。避免使用专有名词（子女、父母、配偶的名字）、球队名称、城市、电影、艺术家等。

选择强密码最有效的方法是使用自动生成器，创建不寻常且因此唯一的字符序列。这些密码通常难以记忆，但生成器**拥有一套存储生成密码的系统**。在这种情况下，您只需选择一个密码来激活生成器，然后访问其他密码。

为了选择唯一需要记住的主密码，我们推荐两种方法：

1.  选择 4/5 个单词并将它们合并。它们不应是著名的句子，而是拼接在一起且不构成逻辑含义的不同单词。
2.  选择一首歌或诗的诗句，并仅使用每个单词的少数字母。

您可以组合使用多种技术。

## 密码创建工具

### F-Secure

**F-Secure** 是一款可以为各类服务生成复杂密码、存储密码并将其与电子邮件地址、PIN 码、信用卡凭证和活期账户关联的程序。该程序使用 `AES-256` 加密系统。此外，主加密密钥通过复杂算法从您的主密码获取，使得破解者几乎无法检测到它。

### LastPass 及其安装

**LastPass** 可通过浏览器官方扩展方便地使用，能在几秒钟内创建强健安全的密码。从官方网站下载软件后，按照浏览器提供的程序安装扩展。在浏览器中安装扩展后，您需要创建一个帐户以使用该服务。输入您的电子邮件地址，勾选“我同意 LastPass 条款和隐私政策”，然后点击“创建帐户”按钮。填写表单，输入您的主密码，然后点击“下一步”完成注册。

注册后，您将能够生成自己的密码。点击 LastPass 图标并选择“生成安全密码”。设置各种选项，如密码长度、大小写字母、数字、特殊字符或避免歧义字符。创建密码后，点击“使用密码”按钮。LastPass 会同步与同一帐户关联的所有设备上的密码，并提供移动应用程序。
