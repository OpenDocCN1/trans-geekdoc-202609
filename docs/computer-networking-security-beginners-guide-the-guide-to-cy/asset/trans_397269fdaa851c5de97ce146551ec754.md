

# 浏览器扩展管理

## Chrome
点击右上角的按钮（`⋮`），进入`Other Tools > Extensions`菜单。

## Firefox
点击右上角的`☰`按钮，然后点击`Add-ons`，从左侧边栏选择`Extensions`。

## Microsoft Edge
按下按钮（`...`），从打开的菜单中点击`Extensions`项。

# 病毒删除故障排除

如果在删除病毒时出现"Access denied"或"Cannot execute"等错误消息，必须在"Safe Mode"（安全模式）下启动电脑，并从此模式下删除病毒。从电脑中永久删除病毒后，必须采取必要的预防措施，以免再次发生。

*   不要从未知和可疑网站下载程序，也不要打开通过电子邮件、社交网络收到的附件。
*   始终保持操作系统为最新状态。
*   安装优质的安全解决方案。
*   切勿禁用操作系统或防病毒保护。

> **注意：** 如果仍然遇到电脑故障，说明病毒仍然存在。在这种情况下，需要干预"Registry"（注册表）。这是一个相当复杂和精细的操作。因此建议安装一款能在完全安全的情况下执行所有必要操作的防病毒软件。

# Mac 病毒处理指南

如果您使用的是 Mac，感染的概率非常低。但是，如果您的 Mac 被感染，首先要做的是使用 Mac `Activity Monitoring`（活动监视器）实用程序检查所有当前正在运行的软件。

1.  点击`Go > Finder Utility`菜单并启动`Activity Monitoring`工具。
2.  仔细观察所有正在运行的进程并识别可疑进程。
3.  在 Google 上搜索以确认是否为威胁。
4.  如果确认为病毒，返回`Activity Monitoring`窗口，点击受感染的进程，然后点击顶部的按钮，最后点击两次`Exit`按钮。这将立即停用有害活动。

## 永久删除病毒

1.  进入 Mac 的`Applications`文件夹，识别"有问题的"程序。
2.  右键点击相关文件，选择`Move to Trash`（移至废纸篓），然后选择`Empty Trash`（清空废纸篓）。

## 检查 Safari 浏览器扩展

作为最后检查以确保病毒已完全删除：

1.  进入`Safari > Preferences`菜单，转到`Extensions`选项卡。
2.  选择受感染的扩展并点击`Uninstall`。

## Mac 安全模式

如果无法在浏览器中删除病毒及其扩展，则需要在"Safe Mode"（安全模式）下启动 Mac 并从此模式下删除病毒。

**启动 Mac 安全模式的方法：**
在重新启动电脑时按住`Shift`键。当出现 Apple 徽标并看到登录窗口时，释放`Shift`键并像往常一样登录。

## 验证 macOS 保护机制

1.  打开 Mac `System Preferences`（系统偏好设置），选择`Security and Privacy`（安全性与隐私），点击`General`（通用）选项卡。
2.  检查`Gatekeeper`是否处于激活状态，方法是查看`App Store and identified developers`旁边是否有勾选标记。如果没有，点击页面底部的锁图标，输入您的帐户密码并勾选该框。
3.  最后，检查`Xprotect`数据库更新是否处于激活状态。进入`System Preferences`，然后进入`App Store`，勾选`Install system data files and security updates`旁边的复选框。

# 术语表

*   **Antispam**（反垃圾邮件）：能够选择并丢弃包含恶意软件、广告等的电子邮件的程序和过滤器。
*   **Backup**（备份）：复制设备中包含的数据。
*   **Banner**（横幅广告）：包含简单广告消息的框，但如果显示，可能包含感染计算机的恶意文件。
*   **Botnet**（僵尸网络）：一组感染了恶意软件的计算机，允许破解者利用它们来解密密码。
*   **Cloud**（云）：一组允许通过互联网连接使用计算机资源的技术。
*   **USB Controller**（USB 控制器）：一种可以将计算机与通过 USB 端口连接的外部设备连接起来的设备。
*   **Cracker**（破解者）：利用计算机技能进行犯罪目的的坏黑客。
*   **Data Recovery**（数据恢复）：为恢复损坏设备中包含的数据而实施的一组程序。
*   **Exploit**（漏洞利用）：指从系统漏洞出发，控制信息系统所要执行的一组操作。
*   **Framework**（框架）：与操作系统集成并使所有通用功能可供应用程序使用的一组软件模块。
*   **Hacker**（黑客）：拥有计算机技能，允许其进入系统并检查其漏洞的人。通常，在发现系统漏洞后，黑客会将其发现告知程序员并建议解决方案。
*   **Honeypot**（蜜罐）：作为陷阱捕捉试图闯入计算机系统者的网站或计算机网络。
*   **Hotspot**（热点）：Wi-Fi 网络的接入点。
*   **HTML**：用于赋予网站文本形状的语言。
*   **IP address**（IP 地址）：表示连接到网络的每个设备的识别号码。此数字代码可以是 32 位（IPv4）或 128 位（IPv6）。
*   **Javascript**：用于在网络上创建交互式应用程序的编程语言。
*   **Keygen**（密钥生成器）：用于安装盗版软件的序列号生成器。破解者经常使用这些序列号生成器来传播病毒。实际上，Keygen 会请求访问计算机文件的权限。一旦获得权限，Keygen 可以修改它想要的任何内容。
*   **Keylogger**（键盘记录器）：一种安装在计算机上、记录键盘上输入的所有内容并将其传输给破解者的病毒类型。
*   **Malware**（恶意软件）：任何能够非法进入计算机并损害其运行的软件类型。
*   **P2P**（点对点）：一组允许您使用各种协议非法交换受保护文件的服务。
*   **Patch**（补丁）：包含更新相关软件代码的软件包。更新可让您修复错误、消除漏洞并优化性能。
*   **Payload**（有效载荷）：实施破解者犯罪意图的恶意软件部分。这发生在漏洞利用控制计算机之后。
*   **Plug-in**（插件）：更复杂软件的一个模块，添加最初未预见的功能。
*   **Ransomware**（勒索软件）：最危险的恶意软件。它能够加密计算机上的所有数据，并以加密密钥为交换要求赎金。最后，它能够感染连接到网络的所有计算机。
*   **Registry**（注册表）：包含调节操作系统运行设置的 Windows 文件。
*   **Spyware**（间谍软件）：一种未经用户同意收集其在线活动信息的软件类型。
*   **Social Engineering**（社会工程学）：破解者通过操纵人们的善意来获取信息所使用的一组技术。
*   **Trojan Horse**（特洛伊木马）：伪装成数据文件的一种恶意软件类型。其特点是必须获得权限才能安装自身。
*   **Virus**（病毒）：一种能够自我安装并通过感染其他计算机进行自我复制的恶意软件类型。
*   **VPN**（虚拟专用网络）：一种允许您像使用专用网络一样使用互联网的服务。
*   **Wi-Fi**：位于短距离内的计算机和外围设备之间的无线通信技术。在路由器的帮助下，本地 Wi-Fi 网络能够连接到互联网。
*   **Worm**（蠕虫）：一种能够自我复制的特定类别的恶意软件。
*   **Zero day**（零日漏洞）：由破解者发现但程序员未知的软件安全缺陷。
