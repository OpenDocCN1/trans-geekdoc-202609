# 4.1. Feature Extraction

This stage is divided into sub-stages. The first carries out time or frequency domain measurements. These measurements can be the signal acquired itself, or preliminary data used to calculate the features. The second extracts parameters from each measurement with information related to the classification problem.

The measurements are very dependent on the type of signal. For clarity sake, the description of the measurements and parameters are strictly related to a signal given in the Appendix A-C. On the other hand, some parameters are common to all the measurements considered in this work, such as the most common parameters. The statistical parameters considered in this work are denoted as the Set of Statistical Parameters (SSP), and they include: mean, median, standard deviation, 25th median, skew, kurtosis, maximum, minimum, percentile 25th%, 75th%, geometric, harmonic mean and absolute deviation.

In addition to parameters, another parameter has been frequently calculated in almost all the measurements, which tries to model a very important concept in physiological signal analysis: the baseline. To determine the baseline of a measurement under study we use an ultra-low pass filter, so that it integrates the averaged value of the measurement over a long period of time. The condition of this baseline is on the use of an Infinite Impulse Response (IIR) filter, which can achieve a very low cutoff frequency with only a couple of coefficients. Thus, for a given measurement $z_i$, the baseline $y_i$ is calculated as follows:

```
$y_i = z_i \cdot \beta + y_{i-1} \cdot (1 - \beta)$.
```

The $\beta$ value controls the speed of variation of the baseline parameter, that is, the cutoff frequency of the equivalent low pass filter. On the sampling frequency, we have chosen a value of $\beta$ which corresponds to a filter that takes approximately the last 20 min of recording of the measurement to obtain the baseline.
