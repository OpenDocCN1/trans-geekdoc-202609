# 4.2 Emotion Recognition

A database with 28 typically developing children was used to analyze the performance of the proposed system for five emotions recognition [17]. This database contains appearance feature vectors that were computed on face ROIs (see Figure 4), which correct placements were carefully verified by a trained expert. the effectiveness of PCA po other classifiers for five emotions classification was evaluated, here being PCA poplar adaptive transform that under controlled head-pose and imaging conditions may be sufficient to capture features of expressions [9]. Figure 7a shows the average performance by applying PCA for different components plus LDA classifier being 60 components sufficient. Note that non-significant difference (p < 0.05) for 60 components was achieved. Similarly, non-significant difference was obtained using PCA with 60 components plus other classifiers, such as LDA using Linear or SVM, as shown in Figure 7b. For instance, LDA using linear and diagonal covariance matrices achieved Kappa values of 81.3±1.2% and 77.9±14.7%, respectively, and 78.58±1.8% for Linear SVM. The resulting matrix has low cost and can be easily embedded in the N-MARIA hardware for online emotion recognition during the child-robot interaction. Moreover, PCA and LDA have been successfully used in other similar studies [16,17,20,23,36], achieving promising results. Then, we selected PCA with 60 components plus LDA on full covariance matrix as the best set for five emotions recognition.
