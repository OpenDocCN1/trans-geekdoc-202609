The dropout rate is empirically set to 0.25. The first fully connected layer uses the elu activation function, while the last fully connected layer consists of a softmax layer (where $c$ depicts the number of classes of the classification task).



The performance of classification architectures specific to input channel (MHIs and OFIs), as well as the performance of the weighted score aggregation approach are depicted in Figure 6. The performance metric in this case is accuracy, which is defined as

```
$Accuracy = \frac{tp + tn}{tp + fp + tn + fn}$ (22)
```

where $tp$ refers to true positives, $tn$ refers to true negatives, $fp$ refers to false positives and $fn$ refers to false negatives (since we are dealing with a binary classification task with two balanced datasets). For both datasets and classification tasks, the aggregation approach outperforms the classification architecture based on MHIs. Furthermore, the architecture based uniquely on OFIs shows significant performance improvement in the case of the BVDB. The aggregation approach also performs slightly better than the architecture based uniquely on OFIs for both classification tasks, although not significantly in many cases. The only significant improvement is achieved for the classification task $T_1$ vs. $T_3$ for the SEDB. Furthermore, the performance of both channel specific architectures and the performance of the score aggregation approach are significantly higher than chance level (which is 50% in the case of binary classification tasks) pointing to relevance of the designed approach. Furthermore, the performance of the classification architecture is improved by using both channels and performing a weighted aggregation of the scores of both channel specific deep attention methods.
