There are three types of training for the proposed method: Type I trains a pretrained model using the driver data set; Type II trains a model with the mental arithmetic data set; and Type III trains a pretrained model (i.e., Type I) with the mental arithmetic data set.

All three types use the same end-to-end architecture, using the raw ECG signals from each data set. A loss function needs to be defined for the DNN model. We utilize the cross-entropy loss function:

```
$L = -\sum_{i=1}^{m} (y_i \log(h_i) + (1 - y_i) \log(1 - h_i)),
```

where $h_i$ and $y_i$, are the prediction results from the proposed model and the true labels from the data set, respectively, and $m$ represents the size of the mini-batch, which is set to 64. When a model predicts a state (i.e., stress or rest), the loss function becomes nearly zero. However, it diverges from zero in the opposite situation; that is, when the model produces an output different from the data set label.
