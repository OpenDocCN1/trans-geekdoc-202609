Let $T=(F_1, Y_1), (F_2, Y_2), \dots, (F_n, Y_n)$ be the training set, where $n$ is the number of samples, and $F$ is a $d$-dimensional feature vector with class $Y_i \in \{0,1,2,3,4,5\}$. PCA method used on Single Value Decomposition [9,16,20,23,36] is applied to $F$ to extract the principal components, which are used in both training and validation sets. As advantages, PCA is few sensitive to difference training sets, and it can outperform other methods like LDA when the training set is small [45]. In order to allow a robust and reduce the set of 154 features, the high-dimensional feature vectors, which are obtained by applying appearance-based methods [16,23]. It is worth noting that before applying PCA in our study, the feature vectors of the training set were normalized using mean and standard deviation values. Then, the validation was normalized using the same reference values (mean and standard deviation) obtained from the training set.

Some classifiers, as LDA [27,46] and Quadratic Discriminant Analysis (QDA) [12,47] by applying full and diagonal covariance matrices, as well as other classifiers, such as Mahalanobis distance [12,48], Naives Bayes [49], and Linear Support Vector Machine (LSVM) [12,14,50] were used in our study to assign objects to some of emotional classes based on the set used.



From images recorded during both moments of the experiment (Baseline and Test), of a set of 220 photography frames randomly selected 11 chosen by a trained expert, the ROIs were identified. These annotated images were used as reference to evaluate, through Euclidean distances (see Equation (6)), the accuracy and precision of both Viola-Jones without ROI relocation, and Viola-Jones using ROI relocation algorithm.

```
$D = \sqrt{(A_x - M_x)^2 + (A_y - M_y)^2},$
```

where $(A_x, A_y)$ is the coordinate obtained by the automatic method, and $(M_x, M_y)$ is the coordinate obtained by the manual method. When $D$ is close to zero, it means high accuracy.

The statistical analysis used for comparison between both approaches for each ROI was the Wilcoxon Signed Rank Test for zero median.
