After this step, well-known algorithms such as Histogram of Oriented Gradient, Gabor Features, and LBP were used for feature extraction for the reason that they are highly capable of representing the appearance-based information accurately.



Gabor features are comparative to the human visual system because of their frequency and orientation representations. A 2D Gabor feature, in the spatial domain, is a Gaussian kernel function which is modulated by a sinusoidal plane wave. These filters can be generated by one major wavelet by rotation and filter. These are the best among the other relevant image features such as the edge histograms. In our experiments, we extracted magnitudes of 96 × 96 sizes using the directions of eight wavelets and scales of nine so that the Gabor wavelengths from the range of 2 to 32 pixels in half interval. The resulting feature vector has 9 × 8 × 96 = 632 components, none of them are useful. In fact, our experiment, a very small number of informative components are selected. To perform Gabor analysis, first the eyes are located, and the images are aligned correctly. This alignment is by performing transformation, rotation, and scaling. This is a typical procedure for 2D images for registration. Normalization is done using manual deformation of landmarks. This is to preclude any misalignment effects from the registration.



The LBP method is based on a texture descriptor that is useful in extracting features from any textured image. We used LBP for extracting facial features that are useful for estimating the intensity of the emotion depicted in the image. LBP is non-overlapping and uniform when applied to an image. Initially, a user specified number of blocks are used to segment the image. For each patch on the image, the LBP matches the center pixel to its surrounding neighboring pixel to generate LBP value. (1) and (2) are mentioned below for computation of LBP, where N represents the adjacent pixels, k is the neighboring pixel, and C is the center pixel. For this, we have considered the value of k = 8.

> $LBP(N,C) = \sum_{k=0}^{7} P(N_k-C)^2$$

> $[y] = \begin{cases} 1 & \text{for } y \geq 0 \ 0 & \text{for } y < 0 \end{cases}$$

The function L (N, C) from Equation (1) uses the P (Nk-C) as seen in Equation (2), generates a 1 or a 0 depending on the difference between the center pixel and the neighbor.
