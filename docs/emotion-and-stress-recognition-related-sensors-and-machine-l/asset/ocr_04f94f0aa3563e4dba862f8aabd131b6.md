In addition to the sensor modules, the user interface (UI) and WOZ module were encapsulated in such a network to control and monitor their behavior in the same synchronous manner. Finally, a logging module was established acting like a sensor, not recording physical data, but recording the whole sensor behavior. This includes about all participants and WOZ inputs, global information on the internal and external systems, information about the sensors attrs, any network communication. With this log file and the recorded sensor streams it is possible to reconstruct the whole experimental procedure in detail up to a virtual playback without a real participant. Therefore, for the development of real time capable online recognition systems.

Finally, each recorded had a network monitoring module, measuring the current network latency to synchronous recording. Due to the usage of "of the shelf" sensors like the Kinect sensor and webcams, which do not possess trigger input capabilities, and the multi-pc environment, we are not able to ensure synchronicity on a nanosecond level, like highly-specialized, expensive, hardware-triggered setups. Here, our setup is more flexible and a deal more realistic towards user implementations on custom hardware and smart devices. The recorded emotions and mental states occur typically in a longer range and all multimodal recognition approaches typically use time windows from 50 ms up to several seconds.
