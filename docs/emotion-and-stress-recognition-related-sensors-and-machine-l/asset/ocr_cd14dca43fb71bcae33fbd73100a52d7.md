In order to examine if the differences of the SAM evaluations are statistically significant in the VAD-space between the sequences, further statistical analysis was carried out. To analyze the ratings for Group A and Group B, we conducted repeated measures ANOVA with the Factors Sequence and VAD (for Valence, Arousal, and Dominance, respectively). Post-hoc, Newman-Keels corrections were carried out to compare the means between the sequences. For Group A, the repeated measures revealed a significant effect of Sequence(F(5.185)=18.866, p < 0.001, n=32), VAD (F(2.274)=5.996, p < 0.001, n=62) and interaction (F(1.370)=30.748, p < 0.002, n=0.454). Post-hoc tests using Newman-Keels correction revealed differences (see Table A1 in the Appendix). For the Combined Group A + B, the repeated measures ANOVA revealed a significant effect of Sequence(F(5.280)=30.190, p < 0.001, n=0.353), VAD (F(2.112)=106.429, p < 0.001, n=0.774) and interaction (F(10.560)=51.405, p < 0.001, n=0.427). Post-hoc tests using Newman-Keels correction revealed significant differences (enter Table A1 in the Appendix).
