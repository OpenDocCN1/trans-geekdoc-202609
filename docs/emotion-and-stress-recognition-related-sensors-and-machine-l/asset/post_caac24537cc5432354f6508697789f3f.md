
## 2.2. Fully Convolutional Heatmap Regression Methods

Early methods used heatmap regression, heatmap regression methods as an approach for 2D pose estimation [5,18,31]. Unlike the holistic regression methods, heatmap regression methods have the benefit of providing higher output results that assist in localizing the key points in the image via per-pixel predictions. To leverage this advantage, [17,31] regress a heatmap over the image for each key point and then obtain the key point as a mode in this heatmap. [31] presents a convolutional network architecture incorporating motion features as a cue for body localization and [17] proposes a CNN model to regress 2D human body poses in image. The model represents a heatmap representation for each key point, learning and representing both appearances and the context of partial features. In contrast, [5,8] exploit CNNs to estimate dense heatmaps for facial landmark detection. [3] proposes a two-step detection followed by a regression network to create the detection score for each map, whereas [8] uses a stacked hourglass network for 2D and 3D face alignment.

## Fully Convolutional DenseNetworks

Densely connected convolutional networks (DenseNets) [32] introduce a connectivity pattern that prevents the gradient-vanishing problem to be solved even when the depth of CNN is increased. At the same time, the number of parameters can be reduced by connecting each layer with additional inputs from all preceding layers and reusing its features in all subsequent layers. FC-DenseNets [19] extend DenseNets to a fully convolutional network that achieves state-of-the-art results by tackling problem semantics with image segmentation. The resulting network is a deep network between 56 and 103 layers that have very few parameters. The goal of FC-DenseNets is to further explore resolution by avoiding feature explosion at the upsampling path of the network. To recover the input resolution, FC-DenseNets inherit the advantages of DenseNets that use pooling operations and dense blocks (DBs) to perform iterative convolution of feature maps. The feature maps have a sufficiently large amount of detailed spatial information. To some extent, heatmap regression through FC-DenseNets is especially useful for multiple outputs per input (e.g., multiple faces).

FC-DenseNets are constructed from two symmetric parts where the downsampling part is an exact mirror of the upsampling part as shown in Figure 1. FC-DenseNet consists of 11 DBs: 5 DBs in the downsampling path followed by its own transitions down (TD), 5 DBs in the upsampling path followed by its own transitions up (TU) and one DB in the so-called "bottleneck". Each DB is composed of dense layers followed by batch normalization [33] and ReLU [34]. The solid line in Figure 1 represents the connection between each dense block of the fully convolutional DenseNet (FC-DenseNet), which passes output feature maps from one dense block to the next, whereas the dashed line indicates connections between FC-DenseNet downsampling and upsampling paths. The overall FC-DenseNet goal is to capture spatially detailed information from the downsampling path and recover it in the upsampling path by reusing the features maps. The last layer in the network is a i×1 convolution followed by a softmax nonlinearity to predict the class label.

## 2.3. Dilated Convolutions

Dilated (or atrous) convolutions have been widely utilized for various dense prediction and generation applications. As indicated in Reference [35], dilated convolutions enlarge exponentially receptive fields without loss of resolution or convergence when the number of parameters grows linearly. Larger kernel receptive fields can enhance network capability to capture spatial context, which is beneficial to reconstruct large and complex edges. However, ordinary convolutions require a large number of parameters to expand the receptive fields. In contrast to dilated convolutions, dilated convolution has zero-padding inside its kernels, injecting zeros into defined fields to expand receptive field size, as shown in Figure 2. Thus, dilated convolutions can view larger input portions without requiring a pooling layer, resulting in no spatial dimension loss and reduced computational time.

For semantic segmentation, Reference [35] proposes a new convolutional architecture that fully exploits dilated convolutions for multi-scale context aggregation. Reference [36] proposes simple yet effective, gridding methods by studying the deconvolution of dilated convolutions. In these studies, dilated convolutions replace the upsample layers to keep the output resolutions the same as the input. For other tasks such as audio generation [37], video modeling [38] and machine translation [39], dilated convolutions are used to capture global views of inputs with few parameters. WaveNet [37] recognizes speech from audio waveforms. The dilation factor in Reference [37] is doubled, starting from 1 to a fixed number for every forward layer; then, the pattern is repeated.

Figure 2 illustrates how dilated convolutions enlarge the receptive fields by altering dilation factors (d). When dilation factors are increased exponentially, the pixels between the original kernel elements progressively grow; this causes the receptive field to expand. In Figure 2a, a dilated field of 1 (Dilated convolution) is performed in a 3x3 on a feature map. We observed that the 1-Dilated convolution is the same as the 3x3 standard convolution. When the dilation factor is set to 2 as shown in Figure 2, the region of the receptive field increases dramatically to 7x7 pixels. In Figure 2c when the dilation factor is changed to 4 and the region of the receptive field increases dramatically to 15x15 pixels.

## 3.1. Local Appearance Networks

It is well known that facial landmark detection uses single pixel location data $p(x,y)$ as a training label where $x$ and $y$ are coordinates. However, using the training label as a single-point location $p(x,y)$ is inefficient for learning features from the input data. Even though the model returns a close to ground-truth, a result that does not comply with the exact pixel location $p(x,y)$ may be considered wrong; as a result, the model may search for another pattern despite being close.

Recently, Gaussian distribution has come into play for manipulating the training label into a heatmap, not as a single specific point $p(x,y)$ but rather as probabilities near the given training label pixel point. [24,40] present successful heatmap implementations in facial alignment. As presented by both papers, using a training label allows the network to learn faster. Furthermore, heatmaps demonstrate how the network thinking is more visible to the naked eye. The correct point will have the highest probability in the distribution, whereas the neighboring pixels close to the correct pixel will also have high probabilities but not as high as that of the correct pixel.

$$ \hat{p} = \text{argmax } h_i(y;w,b) $$

The output of the network will be a continuous probability distribution on an input image plane, making it easier to see where the network's guess is confident; in contrast, with a single position as an output does not show how the network is guessing.
