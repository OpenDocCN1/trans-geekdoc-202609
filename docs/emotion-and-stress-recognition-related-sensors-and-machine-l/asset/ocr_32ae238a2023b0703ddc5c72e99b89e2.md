# 2. Experimental Data

This study is based on publicly open data set AffectiveROAD [14]. It contains data from nine participants (from now on these participants are called NM, RY, BK, MT, EK, KGS, AD, GM and SJ) measuring Epa4 wrist-worn device [18]. However, three participants performed data gathering more than one's, and the dataset contains 13 gathering sessions. E4 includes this device on both wrists, accelerometers (ACC), as well as sensors to measure temperature (ST), electroermal activity (EDA), blood volume pulse (BVP), heart rate (HR), and heart rate variability (HRV). In addition to E4, AffectiveROAD includes data focus on Zephyr 3.0 chest belt. However, in this study, only Empatica E4 was used as the focus of this article is in wrist-worn sensors. However, to be able to compare the results of the study to those of previous studies, only data from right-worn Empatica was used.

In the gathering session, the task of the subject was to drive a car in a normal daily traffic. However, the session started with a period where subject was sitting and in a car, eyes closed and running may be considered as baseline. The actual driving consisting of two types of road: city driving and highway. City driving is to be stressful as it contains traffic lights, lot of vehicles, pedestrians and bikers. On the other hand, a highway is a smooth road and driving is assumed to be stressful.

What makes this dataset special unique is that it includes continuous subjective estimates collected by the experimenter sitting at rear seat while subject was driving. The driver valued these estimates from 0=(no stress) to 1=(maximum stress). There are no estimates available from baseline. In this study, it is assumed that while the baseline session, the level of stress is 0. As this dataset contains target variables, more detailed information about the dataset can be found from [14].

For the model training data from the gathering sessions were divided into windows, and from these windows, features were extracted. Window size of 60 s was used in the experiment, which is the same as used in [19], for stress detection. The slide used between two adjacent windows window was 0.5 s. The features extracted from these windows were the same as the one's used in [19]. Therefore, four types of features were extracted: the ACC signal, EDA signal, BVP signal and ST signal. Altogether 119 features were extracted.

# 3. Methods

Classification was in this study based on Random Forest, as it is the best classification algorithm for stress detection in our previous study [7]. However, to find the most appropriate regression model for the purpose, several regression models were compared. The comparison was made using Matlab's (the version 2018) Regression Learner application which enables fast experimenting training and testing; multiple regression algorithms. Regression Learner has two options for dividing data into training and testing; cross-validation which randomly divides data into desired number of groups, and holdout which divides data into two groups. As the aim of this study is to build user-independent models, leave-one-subject-out-method we need to be used in the final model process, and therefore, neither of the approaches provided by Regression Learner are valid for the purpose. Moreover, both approaches lead to over-trained models as same persons data in training and testing sets. However, though Regression Learner cannot be used to calculate the final outcomes of this, it can be used to compare the performance of different regression algorithms when predicting the amount of stress, and to select the right regression algorithm to calculate the final outcomes of this.

In the end, regression algorithms were compared with regression models using 5-fold cross-validation, see Table 3.1. As a result of this, it was decided to use Bagged tree ensemble model in the experiments as the root mean square error (RMSE) is the lowest using it.
