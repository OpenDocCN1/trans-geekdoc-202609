The ML techniques used in this work include KNN, SVM, and RF. While SVM is known to have a generalization ability by mapping inputs non-linearly to higher dimensional feature spaces through its capability of separating data with a hyperplane, kNN, a type of instance-based learning, involves the neighbors within the class (among k classes) that a specific data point belongs to. Closest neighbors are assigned using methods such as Euclidean or Hamming distance. RF is a collection of selection decision trees which do not need linear features or features that interact linearly. Due to the variety, the dynamics of facial actions, and the ambiguity, it is challenging to measure the intensities of AUs in a single frame. Mostly, databases are created with posed and spontaneous expressions, where it is a challenge to measure the intensity of spontaneous expressions as they occur more randomly. AUs significantly occur in combinations, where they are not always additive. This implies that the occurrence of an AU can be different than its original standalone type. A perfect example is shown in Figure-4, where AU12 occurs in Case A and the lip corner is pointing straight-slightly upwards. FACS manual gives an insight into the inherent relationship between the AUs that can produce the required information for measuring and analyzing the emotional intensity. The manual mentions that the inherent relationships can be subdivided into two classes—the class of mutual exclusions and the class of co-occurrences. Here, the class of co-occurrences is a class of AUs which most frequently appear together to give meaning to the depicted facial expressions. For example, AU6 + AU12 + AU25 generate “happy”, AU4 + AU15 + AU17 say “sad”. For the class of mutually exclusive AUs, the FACS manual provides alternative routes. FACS rarely occur together in spontaneous emotions in day-to-day life. FACS mentions that it is difficult to demonstrate two AUs as AU25 (lips apart) and AU24 (pressed lips) at all. This suggests that the mutually exclusive cases are very possible, but with very low probability. There are still few limitations to the co-occurrence class in terms of intensity levels of AUs. For example, AU6 (raised cheeks) occur with AU12 (lip corner puller) as shown in Figure 5, both the AUs present a high/low-intensity level of one another.

Well-known algorithms such as Histogram of Oriented Gradient, Gabor Features, and LBP were used for feature extraction. Gabor features are used for the human visual system because they are capable of representing orientation, frequency, and scale. This is done by using sinusoidal filters. The resulting features are used to represent the appearance.

The LBP method is based on a texture descriptor that is useful in estimating the emotion. For each patch on the image, LBP matches the center pixel to its surrounding pixels. (1) and (2) are mentioned below for computation of LBP, where N represents the adjacent pixels, k is the neighboring pixel, and C is the center pixel. For this, we have considered the value of k = 8.

$LBP(N,C) = \sum_{k=0}^{7} P(N_k-C)^2$

$[y] = \begin{cases} 1 & \text{for } y \geq 0 \\ 0 & \text{for } y < 0 \end{cases}$

The function $L(N,C)$ from Equation (1) uses $P(N_k-C)$ as seen in Equation (2), generating a 1 or a 0 depending on the difference between the center pixel and the neighbor. Figure 4 shows an example of a neighboring pixel with their intensity values. The differences are calculated considering the center pixel. Equation (1) is used for the transition from difference to Bit String (sequence of 0s and 1s). Note that the starting position must be arbitrarily chosen for calculation. This is done by using bit string and decoding it.

The number of bit string pattern within a patch is counted to create a feature vector that is used in a distance measure. For an 8-bit string, there are total of 256 possible bit strings. Furthermore, for simplification of the process, the string is either considered to be uniform or non-uniform. A string is considered to be uniform when its bits, parsed in a circular manner, has a shift of values.
