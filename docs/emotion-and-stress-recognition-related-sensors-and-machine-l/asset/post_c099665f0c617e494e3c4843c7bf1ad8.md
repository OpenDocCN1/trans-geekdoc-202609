This optimizer calculates the gradients of the loss function by back-propagation, which adjusts the weights of the neurons in an end-to-end model. The weight distribution is initialized to the normal distribution, which has a mean of zero and standard deviation of the weight variance. The variance is defined as follows:

$Var(W) = \sqrt{\frac{2}{n_{in}}}$

where $n_{in}$ denotes the number of input widgets.

There are many hyperparameters (e.g., the number of layers, number of neurons, size of the mini-batch, filter width, number of channels, others) to be decided, and we chose how many stages are adequate for the proposed model. The number of the stages began with 1, and the performance for accuracy showed as the number of stages increased by 1, up to 8. With the proper number of stages, we tuned the filter width and the number of filters to find the best fitting parameters. We searched the hyperparameters of the DNN through a grid search method and a manual search. We chose the model that achieved the highest accuracy for the test data set all the maximum 10 epochs. Section 2.5.1 shows how we split the data into training set and testing set, based on cross-validation.

## 2.4.1. Type Training

We generated a pretrained model with the driving data set. As the DNN requires a large amount of data for training, we used the driving data set, which was larger than the mental arithmetic set. The learning rate was set to $1 \times 10^{-3}$ and was reduced by a factor of 10 every 5 epochs.

## 2.4.2. II Training

Using the mental arithmetic data set, the same method of end-to-end training was applied as Type training. Additionally, we used all the same hyperparameters to observe how the size of the data set affected the neural network.

## 2.4.3. III Training

We applied transfer learning, using the pretrained model by Type training. As mentioned above, it is difficult to train a neural network with a small data set. If a model is trained based on a pretrained model, the model can easily be fine-tuned. We hypothesized that ECG measurements from participants who had mental arithmetic task were similar to those from others. It is effective to apply transfer learning when the distribution of data set is similar to that of the pretrained model. However, retraining only the softmax classifier did not show acceptable performance. The number of layers to retrain was thus considered as a hyperparameter. We applied the grid search method to find the proper stages (1 to 8) until a satisfactory performance was achieved. We kept the pretrained model, except for the last stage (N = 8) and the softmax layer (N = 9). The trainable variables in the softmax classifier were initialized before training:

$W^{(N)} \sim N(0,Var(W)). \quad N = 9$

We utilized the Adam optimizer [28] to update the trainable variables of the last stages through backpropagation, but the variables in the other stages were kept constant:

$W^{(N)} \leftarrow W^{(N)} - \alpha \frac{m_i}{\sqrt{v_i} + \epsilon}, \quad N = 8, 9$

where $m$ and $v$ denote the first and second moment of the Adam optimizer, respectively. We used a different learning rate ($\alpha$), which started at $10^{-4}$ with the same decay rate (decreasing by a factor of 10 every 5 epochs), to train. As the model was already fine-tuned, it was better to use a lower learning rate. The results of three training types and comparisons between them are shown in Section 3.

## 2.5. Model Evaluation

In this section, we describe how to evaluate the proposed model. We performed training with cross-validation, testing each end-to-end model with its test set and calculating the evaluation metrics. Additionally, we observed the features not only at the end of the neural network but also in the middle stages. The T-distributed stochastic embedding (t-SNE) [30] makes high-dimensional features visible in two- or three-dimensional manifold.

### 2.5.1. Cross-Validation

We used k-fold cross-validation ($k = 10$) to evaluate the proposed model. Both the mental and arithmetic data sets were subject to cross-validation. The DNN should not have seen data in the test set during training. It is obvious that a neural network achieves high performance if we divide the data set into both training set and a test set, and perform training and testing individually. In the case of physiological signals, it is difficult to gather a satisfactory amount of data to train a neural network. There are several limitations in the laboratory environment, such as the portability of the sensors and the inconvenience of the person to be measured. However, cross-validation makes it possible to do both the training and testing with a small amount of data. We randomly split the data set into $k$ folds cross-validation. Each fold contains one subject. We trained the models with $k-1$ folds and assessed them with the left fold. The training and test sets had a 9:1 ratio. All processes were iterated $k$ times with the individual end-to-end models, which produced $k$ models. Therefore, each model was trained by an individual training set and also validated by a test set which had never seen during training. All of the three training types were evaluated with the data set which was included in the training session, but the model never saw it. For example, the Type I model was trained and tested with the driving data set. In the case of Type III, although the pretrained model was based on the driving data set, the mental arithmetic data set was used for evaluation. All evaluation metrics were cross-validated using the mean values of all the folds.

All training and validation was performed on a personal computer (CPU; AMD Ryzen 2700X, GPU; NVIDIA GTX 1080 Ti 11 Gb, Memory; 32 Gb). With the use of GPU, it took less than two seconds per epoch for training the model with the driving and mental arithmetic data sets, respectively. However, without GPU, the driving data set required 22 s per epoch and the mental arithmetic data set needed 5 s per epoch to train the model.

A classifier placed at the end of the DNN produces probabilistic outputs, which indicate likely that the inputs are related to the true labels. Among the outputs, a classifier selects the highest probability for its predictions. It is an important way to compare these predictions with the true labels to evaluate the performance. Many metrics are used to assess such models, such as receiver operate characteristic (ROC) [31] curves and precision-recall (PR) curves [32]. An ROC curve plots sensitivity against specificity with a changing threshold. We calculated the area under the curve (AUC) for the ROC curves, which was nearly 1.0 when the model operated. We also computed the $F_1$ score, which represents the mean of sensitivity and precision.
