The convolutional layers generate feature maps using 72 (3 × 3) filters followed by a Scaled Exponential Linear Units (SELU) as an activation function, 196 (3 × 3) filters followed by a Rectified linear unit (ReLU) as an activation function and 32 (3 × 3) filters followed by a ReLU as an activation function.

Additionally, in the subsampling layers, the feature maps are partially downsampled. In our proposed model, the feature maps in C1, C2 and C3 are sub-sampled to a corresponding feature size of 2 × 2, 2 × 3 and 3 × 3 in the subsequent layers P1, P2, and P3 respectively.

The output layer F is a fully connected neural network that performs the classification process, it consists of three layers. The first layer has 116 nodes, each activated by a ReLU activation function. The second layer has 102 nodes, each activated by a SELU activation function. The final layer is the SoftMax output layer.

The result of the mentioned layers is a 2D representation of extracted feature map(s) based on the input EDA signals.

Since the dropout is a regularization technique to avoid over-fitting in neural networks by preventing complex co-adaptations on training [36], therefore, our dropout for each layer was 0.25 which is relative to a fraction of the input to drop. A grid search has been used to fine-tune the CNN model hyperparameters and to find the optimal number of filters and layers needed to perform the emotion classification task. We used the GridSearchCV in Scikit-learn [37]. We have provided a dictionary of hyperparameters that should be checked during the performance evaluation. By default, the search uses one thread, but it can be configured to use all available cores to increase the calculation time. The Scikit-learn class has been combined with K to find what are the best hyperparameters. Additionally, cross is used to evaluate each individual model and the default of 10-fold cross-validation has been used.
