# 2. Related Work

Recent advances in both domains of computer vision and machine learning, combined with the release of latest datasets designed for pair-related research (e.g., UNBC-McMaster Shoud Pain Archive Database [3], BioVi Heat Pain Database [4], Multimodal EPain Database [5] and SenseEmotion Database [6]), have fostered the development of automatic pain assessment and classification techniques. These methods range from unimodal approaches, practised by the optimisation of an inference model based on one unique and specific input signal (e.g., video signals [7], also signals [9] and bio-physiological signals [11–13]), to multimodal approaches that are characterised by the optimisation of information fusion architecture based on parameters stemming from a set of distinctive input signals [14–16].

Regarding pain assessment on facial expressions, several approaches have been proposed, ranging from supervised learning techniques based on specific sets of handcrafted features, to deep learning. These approaches rely on an effective preprocessing of the input signal (in which case consists of a set of images or videos) and involves the localisation, alignment and normalisation of the face in each input frame. Moreover, further techniques include the localisation and extraction of vital facial descriptors such as facial landmarks, and in some cases, the continuous extraction of facial Action Units (AUs) [17,18]. The preprocessed input, as well as the extracted parameters, are subsequently optimised to utilise a specific inference model based on different methods. In [19], the authors use an ensemble of linear Support Vector Machines (SVMs) [20] (each trained on a specific AU), in which inference scores are subsequently combined using Logistic Regression (LLR) [21] for the detection of pain at a frame-by-frame level. The authors in [22] apply k-Nearest Neighbors (kN) by using geometric features from a specific set of facial landmarks for the recognition of AUs. Subsequently, the pain intensity in a particular face is estimated based on the detected AUs by using a pain evaluation scale provided by Parker [24]. Most recently, the authors in [25] improve the performance of a pain detection system by automatically detecting AUs by applying a transfer learning approach based on neural networks to map automated AUs to coding of manual AU. The encoded AUs are subsequently used to perform pain classification, using an Artificial Neural Network (ANN) [26].

In addition to AU-based pain assessment, several techniques based on either facial texture, shape, appearance and by a combination or set of such facial descriptors have been proposed. Yang et al. [27] assess sensory-based facial descriptors by comparing the pain classification performance of each feature with its spatio-temporal counterpart using SVMs. The assessed spatial descriptors of Linear Binary Patterns (LBP) [28], Local Phase Quantification (LPQ) [29], Binaryized Spatial Features (BSI) [30] as well as each descriptor's spatio-temporal counterpart extracted from three orthogonal planes (LBP-TOP, BSI-TOP). In [8,31], the authors propose several sets of spatio-temporal facial action descriptors based on both angle and geometry-based features from the facial area, as well as the head pose. These descriptors are further used to perform the classification of several levels of pain intensities using a Random Forest (RF) [32]. Similarly, the authors in [7,14,15,33], propose spatio-temporal descriptors extracted from either the localised face area or from the estimated head pose; including, among others, Pyramid Histograms of Oriented Gradients (HOG) [34] and Local Gabor Binary Patterns from Three Orthogonal Planes (LGBP-TOP) [35], to perform the classification of several levels of nociceptive pain. The classification experiments are also performed with RF models and ANNs.
