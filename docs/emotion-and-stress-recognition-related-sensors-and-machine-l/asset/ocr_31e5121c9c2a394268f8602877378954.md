The literature is rich with handcrafted face detection and feature extraction methods for FER that have achieved satisfactory results in laboratory-controlled settings [7–11]. However, these methods have been reported to be incapable of discriminating a great degree of unrelated factors in facial expressions (e.g., subtle facial appearances, head poses, illumination intensity, and occlusions) with FER for in-wild scenarios [12,13].

Recently, the success of convolutional neural networks in both computer vision and pattern recognition has prompted a transition in FER from using handcrafted methods to using deep learning techniques. A deep learning-based FER system uses a CNN to extract and learn high-level features directly from images. Then, an output layer (which usually uses softmax as an activation function) is on top of the CNN model to distinguish the emotion to be detected. This faster emotion recognition with higher accuracy in challenging, real-world environments [14–16]. In this paper, we make use of the powerful feature-learning capacity of the deep CNN to build FER models. However, a few significant problems remain when applying deep learning to FER systems.

First, deep learning-based FER models require a large amount of data to acquire suitable values for models. Directly training the FER model on small-scale datasets is prone to overfitting [17], which makes the model less generalize and incapable of handling FER in real-world environments. Although a great effort has been made to collect facial expression training datasets, large-scale, annotated facial expression datasets are still limited [13]. Therefore, overfitting caused by a shortage of data remains a challenging issue for most FER systems.

Second, imbalances in the distribution of facial expression samples from real-world FER datasets degrade the overall performance of the system [18]. Due to the nature of emotions, the collected images for various classes (e.g., happiness, sadness, and anger) are much larger than the minor classes (e.g., contempt, disgust, and fear). In the AffectNet dataset, happy category comprises about 47% of all elements, whereas category comprises only 1.2%. FER systems being trained on an imbalanced dataset perform well on dominant emotions, but they perform poorly on the under-represented ones. Usually, the weighted-softmax loss [5] is used to handle this problem by weighting the loss term for each emotion class based on its relative proportion in the training set. However, this weighted-loss is based on the softmax loss function, which is reported to report many different features of classes remain apart without paying attention to intra-class complexity. One effective strategy to address the problem of softmax loss is to use auxiliary loss functions to train the neural network. For instance, triplet loss [19] and center loss [20] introduce multi-loss learning to enhance the discriminative ability of CNN models. Although these losses do boost the discriminative ability of conventional softmax loss, they have limitations. Triplet loss requires a complex process of choosing image pairs or triplet samples, which is imperfect and time-consuming owing the huge number of pairs and samples in the training phase. Center does not consider inter-class similarity, which may lead to poor performance of the FER system. In addition, none of these auxiliary loss functions are able to address data-imbalance problems.

To address the problem (the shortage of data), in this work, the transfer learning technique is applied to build FER. Transfer learning is a machine learning technique by which a model trained on one task is repurposed for another related task. It is not only to help the shortage of data but also to improve the performance of the prediction model.

In this paper, we take transfer learning approach by using two recent CNN architectures in two-stage, supervised pre-training and fine-tuning. Specifically, a squeeze-and-excitation network (SENet) model [21] which is pre-trained for the face identification task on the VGGGFace [22] database from the Visual Geometry Group at Oxford University, was fine-tuned on the AffectNet dataset [5] to recognize the above-mentioned common facial expressions.
