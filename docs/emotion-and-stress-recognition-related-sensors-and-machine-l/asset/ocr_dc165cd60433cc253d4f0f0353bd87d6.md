**Figure 3.** To detect stress, we present a shoe prototype incorporating a pressure sensitive inside and an IMU unit around the ankle. Based on literature and observations, we propose four features that can reveal the user's stress level. We show that a significant forefoot pressure, deviations in the centre of pressure, different foot/leg pressures, and tapping of the foot, can indicate an elevated stress level. To validate generality, we conducted three studies: Study 1—Constructing Validity, Study 2—empiring Empirical Replicability and Study 3—testing for External Validity. Our proposed models score reasonable accuracy and show robustness across different users.



The acceleration data of each axis (aX, aY, aZ) minimize the leg/foot pressure defined by the knee angle as in Figure 3C. Similar to the mentioned features, the raw data of each axis was segmented into non-overlapping 10 windows and the mean of each window was used in model training. Since the sampling rate was 50 Hz, the 500 data points were taken in each 10 s window for all 3 axes. If the number of data points per window is W where W = 500:

```
$aXMean = \frac{1}{W} \sum_{t=1}^{W} aX$
```

```
$aYMean = \frac{1}{W} \sum_{t=1}^{W} aY$
```

```
$aZMean = \frac{1}{W} \sum_{t=1}^{W} aZ$
```



The dominant and median frequency of each axis are used to describe foot motions, such as foot tapping, waving and leg shaking. We recognised that some motions may be minimal. To avoid cancelling these low-amplitude motions when calculating a 3D-vector, we deployed the axis-inversion algorithm Mattheuis as introduced [8]. For instance, if we inverted X axis of the accelerometer the inverted values $aX_{inv}$ be $aX_{inv} = 2MAX(aX) - aX$. After segmenting the signal into 10 non-overlapping windows, we calculated 3D nodes, each with a different inverted axis. From the resulting signals, the 3D-norm with the highest peak-to, $V_{3D}$ was selected for further processing. Then, FFT was used to identify the dominant and median frequency of the signal

```
$F_D = F_{MaxEnergy}(FFT(V_{3D}))$
```

```
$F_M = F_{MedianEnergy}(FFT(V_{3D}))$
```
