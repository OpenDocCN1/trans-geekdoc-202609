Several methods and techniques can be applied to perform emotion recognition through the use of a couple of hardware devices and software such as: analysis of emotional properties based on physiological data, such as ECG and EEG [3]; unified system for effective discrimination of positive and negative emotions based on EEG data [4]; automatic recognizer of the facial expression across the eyes and forehead based on Electroencephalography (EEG) giving support to emotion recognition task [5]; use of GSR and EEG data to study the effectiveness of Matching Purge (MP) algorithm in emotion recognition, using PCA to reduce the features and Probabilistic Neural Network (PNN) as the recognition technique [6]; emotion recognition system based on physiological data using ECG and respiration (RESP) data, recorded simultaneously by a physiological monitoring device based on wearable sensors [7]; emotion recognition using EEG data and also performed an analysis about the impact of positive and negative emotions using SWM and RBF as the methods [8]; new approach to emotion recognition based on EEG and classification method using Artificial Neural Networks (ANN) with features analysis based on Kernel Density Estimation (KDE) [9]; an application stores physiological data based on HR, ECG, Sp2 and GSR, that were created when the users advertised about smoking campaigns [10]; experiments based on flight simulator to develop a multimodal architecture to recognize emotions using three different techniques for biosignal acquisitions [11]; multimodal system to identify emotions using acquisition techniques, based on photo presentation methodology [12]; real-time interface with emotion recognition that depends on the need for skill development to support a change in the interface paradigm to one that is more than human [13]; recognize emotions through physiological sensing using a multiple-function-layer classifier of stacked autoencoder (MSEAE) [14].

In addition, it is also possible to present research that is more related to emotion recognition e.g., the use of the Friedman test to evaluate whether the work on emotion and emotional identification influences the levels of anxiety and depression [15]; emotion recognition system based on cross-correlation and the Flow database [16]; derived features based on bi-spectral analysis for quantification of emotions using a Valence-Arousal emotion model, to get a way of gaining phase information by detecting relationships between features components and characterization of the non-Gaussian information from EEG data [17]; a novel real-time subject-dependent algorithm using Stability-trace Correlation Coefficient (ICC) with the most stable features that gives a better accuracy than other algorithms when it is crucial to have only one training session [18]; analysis of emotion recognition techniques used in existing systems to enhance recognition on the improvement of tuning adaptation [19]; and the ensemble deep learning framework by integrating multiple stacked autoencoder to reduce the model complexity and improve the recognition accuracy using physiological features [20].
