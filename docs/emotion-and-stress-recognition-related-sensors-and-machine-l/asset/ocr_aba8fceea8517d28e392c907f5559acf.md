# Table 1. Overview of the main techniques used in human behaviour research.

| Implicit Technique | Biometric-Signal Measured | Features | Psychological or Behavioral Construct Inferred |
| :--- | :--- | :--- | :--- |
| EDA (electrod activity) | Changes in skin conductivity | Skin conductance, tonic and phasic activity | Attention and arousal |
| HRV (heart rate variability) | Variability in heart rate intervals | Stress, mental workload, drowsiness, fatigue | Stress, anxiety, and valence |
| EEG (electroencephalogram) | Changes in electrical activity of the brain | Frequency band functional connectivity, evoked-related potentials | Attention, memory, pain, anxiety, hunger, fatigue |
| fMRI (functional magnetic resonance imaging) | Concentrations of oxygenated vs. deoxygenated blood | Magnetic resonance | Motor execution, cognitive task (mental arithmetic) |
| NIRS (near-infrared spectroscopy) | Concentrations of oxygenated vs deoxygenated blood | Blood-oxygen level dependent | Visual attention, engagement, drowsiness and fatigue |
| EOG (eye-tracking) | Near-infrared light placed on scalp | Eye movement, gaze, fixation, saccades, dilation | arousal and valence |
| FEA (facial expression analysis) | Corneal reflection and pupil dilation | Position and orientation of head | Basic emotions, arousal and valence |
| Voice (speech emotion recognition) | Activity of facial muscles | Microphone | Stress, basic emotions and special features |
