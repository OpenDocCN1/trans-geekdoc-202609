For augmentation (e.g., randomly flipping, resizing and cropping images, etc.), PyTorch framework [42] leaves the original images untouched, returning a changed copy at every batch generation.

To reduce overfitting in our model, we artificially expanded the amount of training data using random augmentation including cropping, rotation, flipping, coloring jitter, scale noise and noise occlusion. We rotated the input image with a rotation angle of ±50° and scale noise from 0.8 to 1.2. We also scaled the longest side to 256 resulting in a 256 × H or H × 256 image, where H $\le$ 256.





We implemented our model based on the open source PyTorch framework [42], which is a dynamic program that runs on a GPU. We cropped our input image 256 × 256 resolution and generated an output set of response maps with the same resolution. We transferred the image's facial key points to heatmap key points using the 2D Gaussian kernel. In our method, the variance (sigma) of the 2D Gaussian kernel in the ideal response map was set to 0.25. For training, we optimized the parameters by RMS [51] with a momentum of 0.9 and a weight decay of $10^{-4}$. We trained our model for 100 epochs with an initial learning rate of $10^{-3}$. We reduced it subsequently to $10^{-5}$ after 50 epochs and to $10^{-6}$ after 80 epochs.

For loss in our network, we use the Euclidean loss function for our network,

```
$L(\Theta) = \sum_{i=1}^{N} ||Z(X_i;Theta) - Z^i||^2$
```

where N is the size of the training batch and $Z(X_i;\Theta)$ is the output generated by the DSC network with parameters $\Theta$. $X_i$ represents the input images and $Z^i$ is the ground-truth result of input $X_i$.

During training, $L(\Theta)$ calculates the difference between the estimated and corresponding ground-truth feature map to update weight parameter $\Theta$, to ultimately identify a set of parameters that make $L(\Theta)$ as small as possible.
