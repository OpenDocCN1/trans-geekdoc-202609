## 3.4. Deep Learning Approaches

Unlike machine learning approaches, deep learning approaches are based on deep neural networks that can directly extract features from the data, and are not reliant on well-defined handcrafted features. As the names imply, deep neural networks are artificial neural networks with two or more layers. Having many layers enables networks to learn more complex patterns and hierarchical information that would be possible with shallow networks. These advantages, however, deep neural networks also have a large number of parameters, which can lead to over-fitting, and they can experience issues with the gradient vanishing when they have a large number of layers. These problems can result in a failure to learn and an increase in generalization error. To overcome these limitations, recent advances (relu units, batch normalization, stochastic gradient descent and data augmentation), more powerful computational hardware (e.g., general-purpose processor units), and innovative network architectures, such as CNNs and LSTMs, have partially resolved these over-fitting and gradient vanishing, enabling high performance to be achieved.

These developments have encouraged the use of deep learning approaches in numerous fields, including physiological signal analysis [21] and stress recognition [5,12,15].

We designed our proposed network based on Deep ECG:Net's structure [12]. First, a batch-normalization layer is used to normalize each physiological signal, so that the network can learn to normalize the signals based on the data itself. There is a 1D convolutional layer and a 1D max-pooling layer for each signal, which extract stress-related waveforms from the ECG and RESP data. A rectified linear (ReLU) is used as the activation function. Next, comes another 1D convolutional layer. There is no additional max-pooling layer this time because the previous max-pooling process has reduced the dimensionality. Although multiple LSTM layers are used to obtain sequential information about the features extracted from the previous convolutional layer. We concatenate the extracted ECG and RESP features and add a dense layer. Finally, there is a fully-connected layer with a sigmoid function, which classifies the data as stressed or unstressed. To prevent overfitting, we also drop and batch-normalization layers. Figure 3 shows the structure of the DeepER (ECG-RESP) Net.

For training, we used the Adam optimizer [23] with a learning rate of $10^{-3}$ and a step decay scheduler (every 50 epochs). The binary-entropy loss was used to calculate the losses between the labels and predictions:

$$L = -\sum_{i=1}^{M} y_i \log(y_i) + (1 - y_i) \log(1 - y_i)$$

We used five-fold cross validation on a 30% split to evaluate the models. All processes were conducted using Python 2.7 running under Ubuntu 16.04, on a PC with 3.6 GHz Intel Core i7, 12 GB of RAM, and NVIDIA GeForce GTX1080 Ti.

Because this is a classification problem (i.e., the subject is stressed or unstressed), we used the following metrics to evaluate both the deep learning network and the machine learning models:

$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN} \times 100\%$$

Here, TP (true positive) is the number of cases correctly classified as "stressed," TN (true negative) is the number of cases correctly classified as "unstressed," FP (false positive) is the number of cases classified as "stressed" but actually "unstressed," while FN (false negative) is the number of cases classified as "unstressed" but actually "stressed."

In addition to accuracy and F1 score, we also used the area under the receiver operating characteristic (ROC) curve to evaluate the models. The area under the ROC curve (AUC) is a well-known accuracy metric [24]. By calculating each sensitivity and specificity according to probabilities, which is within 0 to 1, the ROC is independent of the different thresholds and the metric is reliable.
