We can see that weighted-cluster loss effectively solved the imbalanced problem in the AffectNet dataset. The FER performance with minor emotions dramatically improved. For, recognition accuracy of the transferred ResNet-50 model for the contest improved approximately by 1000%—from 6% when fine-tuned using the softmax loss, to 59% when fine-tuned using the proposed weighted-cluster loss. For the disgust, it improved by 150%—36% when fine-tuned using the softmax loss to 54% when fine-tuned using the proposed weighted-cluster loss. This is because the loss function penalizes misclassifying samples from these classes. The performance with major emotions (e.g., happy and neutral) slightly improved. The same trend can be found in case of the transferred ResNet-50 model where the recognition accuracy of class intent improved about 50% (from 10% to 53%) and that of class disgust improved about 150% (from 30% to 47%).

It is worth noting that although the weighted-cluster loss serves to increase the inner-class differences, the differences between some emotions such as happy vs. neutral, surprise vs. anger still remain to some extent. This is due to the natural similarity between these emotions. For reason, there were up to 16% samples of the neutral and 15% samples of happy class that was misclassified by the contest model 10. In the opposite direction, there was a high percentage (e.g., 11% and 12%) samples of the class misclassified as the neutral and happy class, respectively. Similarly, in model 10, 8% samples of surprise was misclassified as the fear, and 13% of the fear class was misclassified as the surprise class while disgust and anger were fairly recognized at the rate of 15% and 22%.
