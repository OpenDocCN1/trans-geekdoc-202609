In each dataset, and for every combination of normalization and classification method, we ran 20 experiments per subject. In each experiment, all data for one $T_j$ was used as the test set, and 90% of the data from the rest of the individuals, i.e., $(T_1 \cup T_2 \cup ... \cup T_m) - T_j$, were employed for training. As the classes in the three datasets were balanced and had equal importance, the performance was assessed correctly categorized to the self-reported binary labels for arousal and valence provided as ground-truth in each dataset.

Table 3 compares the classification accuracy when using a z-score normalization and when the proposed subject-based normalization was applied. To effectively rank the two algorithms according to their general performance, and measure the statistical significance of the results, the classification accuracy was evaluated separately for each test and pairing. With these measurements, a multiple comparison Friedman test [67] was conducted, considering the null hypothesis that the two methods obtained similar results with non-significant differences. Our non-parametric test computed the average rank of all methods, which are shown in Table 4, along with the p-values of pairwise comparisons that. p-values were calculated using software available from http://ci2s.ugr.es/sidcim [67].
