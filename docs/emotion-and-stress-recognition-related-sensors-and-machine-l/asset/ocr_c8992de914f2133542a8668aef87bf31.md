with the constraint

$a_{oft} + a_{mhi} = 1.$ (9)

The entire architecture is trained in an end-to-end model using the following loss function,

$\mathcal{L} = \mathcal{L}_{oft} \cdot \mathcal{L}_{oft} + \mathcal{L}_{mhi} \cdot \mathcal{L}_{mhi} + \mathcal{L}_{agg} \cdot \mathcal{L}_{agg}$ (10)

where the loss functions of each input channel and the aggregation layer are respectively depicted by $\mathcal{L}_{oft}$ and $L_{agg}$. The parameters $\lambda_{oft}$, $\lambda_{mhi}$ and $\lambda_{agg}$ correspond to the regularisation parameters of each respective loss function. Once the network has trained, unseen samples are classified based on the output of the aggregation layer.

The attention network (see Figure 3) consists of a CNN coupled to a BiLSTM with a frame module [47]. The CNN consists of a time distributed feature embedding network which takes a single input image $image_{i,j}$ as input and produces a fixed-dimension feature representation $X_{k,j}$ specific to that image. Therefore, the output of the $j$-th input sequence of features $\{x_{k,j}\}_{j=1}^T$ consists of a set of features $\{X_{k,j}\}_{j=1}^T$. The temporal component of the sequence of features is further integrated using a LSTM layer. A BiLSTM [58] RNN is an ensemble of a regular LSTM [40], to enable the use of context in both forward and backward directions. It consists of LSTM layers, processing the input sequence $\{X_{k,1}, X_{k,2}, ..., X_{k,T}\}$ sequentially forward (from $X_{k,1}$ to $X_{k,T}$) and the second input sequence sequentially backward (from $X_{k,T}$ to $X_{k,1}$). A LSTM RNN is capable of learning long-term dependencies in data, while avoiding the vanishing gradient problem of RNNs [57]. This is achieved through the use of cells (see Figure 4), which regulate the amount of information flowing through a LSTM network throughout the use of three principal gates: forget gate ($f_t$), input gate ($i_t$) and output gate ($o_t$). The cell output $h_t$ (at each time step $t$) is computed, given a specific input $x_t$, the previous hidden state $h_{t-1}$, and as follows,

```
$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f)$ (11)
```

```
$i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i)$ (12)
```
