## 3.2. Performance of the End-to-End Model

Figure 4 shows the accuracy of the proposed model for the classification of rest and stress. We compared the results of the three training types, based on the input windows. Overall, Type I, which was trained using the driving data set, showed the best performance for all windows. It reached the highest mean accuracies at 89.38%, 87.16%, and 79.12% for the 10 s, 30 s, and 60 windows, respectively. The Accuracy of Type I training, 89.38%, was significantly different from both the Type II accuracy, 61.33%, and Type III accuracy, 69.71%, for the 10 s window (p < 0.01). Additionally, there was a significant difference between the accuracy of Type II and Type III training (p < 0.05). In the case of the 30 s window, Type I achieved an accuracy of 87.16%, whereas Type II and Type III training reached 68.38% and 72.13%, respectively (p < 0.01). For the 60 s window, the accuracy of Type I, 79.12%, and Type III, 79.50%, was significantly different from that of Type III training (p < 0.05). Considering Type II and Type III training, which were both trained with the same baseline data set (mental arithmetic), there were improvements of 12.01% and 10.06% in accuracy for the 10 s and 60 windows (p < 0.05), respectively; while there was no significant improvement in the 30 s window at the 0.05 level.
