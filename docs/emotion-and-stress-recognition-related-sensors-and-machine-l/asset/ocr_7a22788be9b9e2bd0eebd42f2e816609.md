In Ref. [36], a comprehensive study of methods for feature extraction, such as Kernel Discriminant Isometric Mapping (KDisom), PCA, Linear Discriminant Analysis (LDA), Kernel Principal Component Analysis (KPCA), Kernel Linear Discriminant Analysis (KLDA), and Kernel Isometric Mapping (Kisosom) achieved the best performance (ACC 81.59 on the JAFFFE, 94.08 on the Cohn-Kanade database) for KDisom among seven emotions (anger, joy, surprise, disgust and fear), but without significant difference compared with other approaches. The authors used the well-known Jiao-Jones algorithm to detect the face [32], which is suitable for real-time applications. This method used a class of classifiers by employing Haar-wavelet features, which utilize the eye position detected in the face region to align the detected regions.

In Ref. [37] the authors proposed the Central Local Gradient Coding (CS-LG) algorithm to define neighborhood as a 5 x 5 grid, using the concept of center symmetry to extract the gradient in four directions (horizontal, vertical, and two diagonals) for feature extraction to target pixels more precisely. Afterwards, they also applied PCA for dimensionality reduction, followed by the Extreme Learning Machine (ELM). evaluation of this approach was conducted through JAFFE and Cohn-Kanade databases, which contain grayscale visual images related to the following emotions: anger, disgust, fear, happiness, neutral, sadness and surprise. Accuracies of 93.33% and 95.24% for Cohn-Kanade and JAFFE were obtained, being relatively better compared with other methods for feature extraction, such as LBP.

Studies for emotion recognition have been conducted with two kinds of camera (one visual and another infrared), such as in Ref. [20]. Those authors proposed a fusion scheme by applying over thermal and visual features for feature extraction, and k-neighbors to recognize two classes (surprised and laughing) with mean ACC of 77%. Additionally, in [23] a comparison of emotion recognition using visual and infrared cameras was carried out four typical methods, including PCA plus LDA, Appearance Model (AAM), and AAM-based plus LDA used on visual images for feature extraction, whereas PCA and PCA plus LDA were applied on infrared images using ROIs (forehead, mouth, and cheeks). These authors used k-neighbors to recognize emotions (sadness, anger, surprise, fear, happiness, and disgust). It is worth noting that the eye locations were manually processed for those authors, which later were used to locate the aforementioned ROIs. In Ref. [22] an interesting approach using both kinds of cameras was needed, using the use of eyeglasses, which are opaque to the thermal camera, visible to the visual camera.

Another work shows that infrared and visual cameras can be combined into a multi-modal sensor system to recognize face [24], using electroencephalogram (EEG) signals, eye blinking rate, and facial temperature while the user watched a horror movie.
