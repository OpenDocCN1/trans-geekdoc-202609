# 5. Results

For each of the 18 participants, we captured 15 parameters either measured or directly from ECG. For all these parameters, we computed a moving average for an outlier-smoothed version of the same signal in order to get a better understanding of the signal's overall robustness and reliability. Additionally, we computed low/high-pass filtered versions of the CSR signals, as well as the complex demodulation amplitudes from the ECG signals. For each participant, we analysed 22 pairs of physiological parameters of the same type regularity (e.g., heart rate from BioHeart sensor and heart rate from VariPort sensor) and another 136 parameters of different type correlations (e.g., heart rate from BioHeart sensor and galvanic skin response from VariPort sensor).

Since there are many parameters, we defined a naming convention that includes the physiological parameter of interest, the plot to measure it, plus an indication of whether a time series is a moving averaged or a filtered version. For the naming of the parameters, we use the following notation:

For direct measures:

```
<parameter> <platform> [filt. (mv. avg)]
```

where parameter can be GSR, HR, or IBI and platform (mv. avg) indicates that this is the moving averaged; filt indicates that a first order high-pass (0.05 Hz) and first order low-pass (0.5 Hz) Butterworth filter has applied to the original signal (this filter setting is used for further to identify methods of stress [4,1]; however, this is not within the scope of this paper.

example: GSR (mv. avg) refers to the moving averaged version of galvanic skin response measured by VariPort

For derived measures:

```
<derived parameter> from <original parameter> <platform> (mv. avg)
```

where derived parameter can be HF, IBI, LF, VF original parameter can be ECG, and platform can be BH, or VP (mv. avg) indicates that this is the moving averaged version: IBI: from ECG refers to the inter beat interval derived from the electrocardiogram measured by BioHeart
