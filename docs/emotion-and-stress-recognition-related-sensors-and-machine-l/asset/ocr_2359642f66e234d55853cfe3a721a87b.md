# ## 4.2. Personal Stress Detection

The dataset contains more than one data gathering session from three study subjects (three sessions from subject NM (NM1, NM2 and NM3), two from RY (RY1 and RY2) and GM (GM1 and GM2). Therefore, these study subjects can be used to experiment if the stress recognition models trained using personal data are more accurate than user-independent models, as is suggested in some of the papers. The data gathering process was the same in each session, and on each session, the study subjects drive the same route. However, what makes each session unique is that traffic was different in each case the study subjects drive on public roads.

User-recognition rates for NM, RY and GM are shown in Table 7 using different sensor combinations, and classification and regression models. In each case, models are trained from one session and tested with data from the same user. NM, RY1 and GM were used for testing, as were also used in previous section to train models. According to Table 4 using user-independent model and a combination of BVP and ST features, which based on Table 2 provide the highest average accuracy. Subject NM's stress can be detected with balanced accuracy 64.3%/84.6% (classification vs regression), RY's 90.8%/93.7%, and GM's 89.6%/95.0%. When compared to personal recognition rates based on the same session, it can be noted that personal data does not have a big effect on the recognition rates. In the case, of RY, the results of based personal model are more accurate than the results based on user-independent model. Moreover, according to Table 7, using personal models is surprisingly no better than sensor combination is used. There are some exceptions, RY's and GM's stress can be recognized with high accuracy using a combination of BVP and ST features. However, the results from these users were already really good using user-independent model and usage of personal data do not have a benefit compared to those.

There can be reasons for low personal recognition rates. For instance, in the case of data from subject GM, there seems to be problems with EDA signal, and thus, prediction. Another reason for low recognition rates can be that the size of the training data was not enough, in the case of personal model training data consists of measurement from one session and in user-independent case it considered measured from eight sessions. In case, NM1 was trained using data from two data gathering sessions (NM2 and NM3), the results were much better than the one's reported in Table 7, and over 98% balanced accuracy was obtained using BVP and ST features, see Table 8. However, also in this case it can be noted that the recognition rate is highly dependent on which data are used for training and for validation.
