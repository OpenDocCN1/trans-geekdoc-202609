facial landmark coordinates. It calculates the mean of inter-pupil distance of multiple images which can be represented by

```
$NME = \frac{1}{n} \sum_{i=1}^{n} \frac{||x_i - x_i^t||^2}{d}, \quad (10)$
```

where $x^i$ are the predicted coordinates and $x_i^t$ are the ground-truth coordinates for $i^{th}$ image, $d$ denotes inter-ocular distance (Euclidean distance between two eye centres) and $n$ is the total number of facial landmarks.

The CED is the cumulative distribution function of the normalized error which is larger than $l$ and is reported as a failure. Thus, CED at the error is defined as

```
$CED = \frac{N_{NME} \le l}}{n} \quad (11)$
```

where $N_{NME}$ is the number of images in which the error NME, is no higher than $l$.
AUC calculates the percentages of images that lie under certain thresholds.

```
$AUC_s = \int_{0}^{s} f(e)de, \quad (12)$
```

where $e$ is the normalized error, $f(e)$ is the CED function and $s$ is the upper bound used to calculate the definite integration.
