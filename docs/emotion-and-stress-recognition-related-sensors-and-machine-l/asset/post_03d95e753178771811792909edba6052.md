As was stated above, four different activities were to be recognized: emotional activity, mental activity, physical activity, and neutral activity (resting).

In order to elicit the activity, we have used a segment documentary called "Earth" to induce Neutral Activity. In order to elicit emotional activity, we used a set of segments from several validated methods [61], "American History X" by Savoy Poitevin [62], "I am legend" (2007) by Warner Ross [63], "Life is beautiful" (1997) by Miramax [64,65] and Cannibal Holocaust (1980) by F.D. Cinematografo [66].

The designed recognition system had to detect a decision every 10 s, and each individual generated 28 time slots of each activity (the database is balanced). The total number of patterns (decisions) for this analysis was 4480, and each class is composed of 1120 patterns.

In this analysis, we have used four activities:

- Neutral activity, registered during the last 10 s of the first movie (the documentary). As each individual watched each movie twice, there are 280 s for each individual in the database
- Emotional activity, registered during the viewing of the last 70 s of the second and third movies (140 s); therefore, we obtained a total of 280 s per individual.
- Mental activity, registered during the last 140 s of both games, producing 280 s in total.
- Physical activity registered during the last 280 s of the physical activity stage. To elicit physical load the participant had to go up and down the stairs for five minutes.

The database particular characteristics can be found in [25]. The full dataset can be downloaded from the Supplementary Information included in the paper.

# 4. Methods

The main objective is to extract or calculate all the features in the literature, applied in different experiments related to activity detection, and after that, to apply a feature selection algorithm to determine the most suitable feature set and the number of features. The acquired signals are processed to identify the activity. The process can be divided into three stages: (a) Feature Extraction, (b) Feature Selection and (c) Classification. An extensive literature review was carried out to find out the typical features used to determine the subject's activity condition identifying a total of 533 features. # 4.1. Feature Extraction

This stage is divided into sub-stages. The first carries out time or frequency domain measurements. These measurements can be the signal acquired itself, or preliminary data used to calculate the features. The second extracts parameters from each measurement with information related to the classification problem.

The measurements are very dependent on the type of signal. For clarity sake, the description of the measurements and parameters are strictly related to a signal given in the Appendix A-C. On the other hand, some parameters are common to all the measurements considered in this work, such as the most common parameters. The statistical parameters considered in this work are denoted as the Set of Statistical Parameters (SSP), and they include: mean, median, standard deviation, 25th median, skew, kurtosis, maximum, minimum, percentile 25th%, 75th%, geometric, harmonic mean and absolute deviation.

In addition to parameters, another parameter has been frequently calculated in almost all the measurements, which tries to model a very important concept in physiological signal analysis: the baseline. To determine the baseline of a measurement under study we use an ultra-low pass filter, so that it integrates the averaged value of the measurement over a long period of time. The condition of this baseline is on the use of an Infinite Impulse Response (IIR) filter, which can achieve a very low cutoff frequency with only a couple of coefficients. Thus, for a given measurement $z_i$, the baseline $y_i$ is calculated as follows:

$y_i = z_i \cdot \beta + y_{i-1} \cdot (1 - \beta)$.

The $\beta$ value controls the speed of variation of the baseline parameter, that is, the cutoff frequency of the equivalent low pass filter. On the sampling frequency, we have chosen a value of $\beta$ which corresponds to a filter that takes approximately the last 20 min of recording of the measurement to obtain the baseline.

Due to number huge features, and so to avoid distractions about the paper goals, description of the calculated features has been included in set of Appendixes A-C at the end of this paper.

# 4.2. Classification

The literature of activity recognition using physiological signals includes numerous types of classifiers with different characteristics in terms of complexity, intelligence, and generalization. In this work, we compare the performance of four widely used classifiers with different rules aiming at staying the performance of the set features: The Least Squares Linear Classifier (LSLC); the Least Squares Quadratic Classifier (LSQC); the Support Vector Machines (SVMs), the Multi-Layer Perceptrons (MLPs), the k-Nearest Neighbor (kNN), the Centroid Displacement-k-Nearest Neighbor (CDNN) and Random Forests (RF).

# 4.2.1. Least Squares Linear Classifier (LSLC)

In a classifier, given a set of training patterns x = [x1, x2,...,xi]ᵀ, where each pattern has an associated class, denoted as Ci = 1,...,M, the decision rule is obtained using a set of M linear combinations of the training patterns. In the least squares approach (the LSLC), the values of the weights of the linear combination are those that minimize the mean squared error (MSE), obtaining the Wiener-Hopf equations [68]. These classifiers are fast and simple, and they present a good generalization capability.

# 4.2.2. Squares Quadratic Classifier (LSQC)

Like the LSLC, the LSQC also renders good results with a very fast learning process. It slightly increases the intelligence of the LSLC by adding quadratic terms to the linear combinations, improving the performance by increasing the complexity, with the consequence of a decrease in generalization.

# 4.2.3. Support Vector Machines (SVMs)

An SVM projects the objective vector x to a higher dimension, using a set of kernel functions, where the patterns can be linearly separated. The patterns of the design set selected to be the center of these functions are denominated "support vectors" [69]. In the present study, we used linear SVM (LINSVM) and nonlinear SVM using Gaussian Radial Basis Function (RBF) kernels, denoted RBFFSVM.

SVMs are essentially binary classifiers, and to implement one-vs-all strategy, multi-class strategy must be defined. In this paper we use a one-against-all strategy; furthermore SVMs present two parameters (the kernel scale and the box constraint) that must be optimized. In this paper a k-fold cross validation strategy over the design set was used in order to determine the best values of type-parameters. RBFFSVMs are also sensitive to differences in the scaling of the features, this to avoid overfitting features were normalized by removing the mean value and by dividing the standard deviation, being these values estimated using the design data.

# 4.2.4. Multi-Layer Perceptrons (MLPs)

MLPs are composed of one or more layers of neurons/perceptrons arranged sequentially so that the outputs of the neurons of a layer are the inputs of the neurons of the next layer. It is a feed-forward network, therefore the outputs of the network can be calculated as explicit functions of inputs and weights. Each neuron implements a linear combination of its inputs applied to a nonlinear function doted activation function. The complexity of the MLP depends on the number of neurons in the hidden layers, allowing easily control the intelligence of the classifier.
