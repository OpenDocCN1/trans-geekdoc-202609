# 2. Related Work

Most of the automatic stress detection studies in the literature were conducted either in the laboratory environments or restricted daily life environments. We examine the studies in the five different classes. The first class develops a laboratory model with context labels and tests in the same environment. Since the stress levels (i.e., the context participants in) are known at any time in laboratory experiments, they could be used as the ground truth labels for machine learning (ML) models, and we called this type laboratory-to-known context (LLKC) models. The second type uses collected self-report labels in laboratory environments and tests the created model in the same environment. This type (LLSR) models. The third type uses self-report questionnaires in the wild and testing the model in the same environment. We named this model daily-to-daily self-report (DDSR) models. Since we could not monitor the everyday life of participants and get the ground truth all the time, a known context does not exist in daily life environments.
