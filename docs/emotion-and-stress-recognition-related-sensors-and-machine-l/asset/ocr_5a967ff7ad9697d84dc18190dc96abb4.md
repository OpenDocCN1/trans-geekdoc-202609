Interestingly, in Table 2 both regression and classification, the best recognition results are obtained using accelerometer labels. This is not in line with previous stress detection studies, where we have noted that features labels are more useful of detecting stress. However, the reason for this is, in this case, accelerometer-based models do not regress as at; instead, they recognize the mode of transportation as baseline stress and stress signal are performed under different activity (sitting in non-moving car vs. driving). In fact, as the aim of the study is to recognize stress, only models based on accelerometer data [EDA, BVP, and ST] are worth studying.

Table 2 shows the potential of regression models. It outperforms classification algorithm with each sensor combination, and the highest recognition rates can be using BVP and ST features. With this setting, the average balanced accuracy was 74.1% with classification model and 82.3% with regression model. In addition, sensitivity and specificity values are higher. Using these features is shown in Table 3, where it can see that both classes are detected with reasonable accuracy. Moreover, according to Table 4 where user-indicated accuracies are stress-based using BVP and ST features, it can be noted that regression model performs better than classification model with all study subjects. Partly, the general performance of regression model is to optimize the threshold to classify targets as stressed/non-stressed based on personal data but is not the only reason for good performance of regression model. Another reason is that regression models get more information as an input than classification model. This shows that stress detection benefits from continuous targets and as a nature regression problem instead of classification problem. This was expected, as the level of stress of a person can be low or high or anything between these.
