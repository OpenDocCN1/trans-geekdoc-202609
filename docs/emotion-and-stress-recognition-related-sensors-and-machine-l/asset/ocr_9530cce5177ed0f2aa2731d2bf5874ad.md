Let us assume a set of subjects $S = \{s_i\}, i = 1, 2, \dots, n$. Let also assume that there exist a set of $n_i$ labeled training samples for each subject $V_i = \{(t_{i,j}, l_{i,j})}, j = 1, 2, \dots, n_i$, where $t_{i,j}$ is conveniently represented in a particular feature space $F$ and to the feature vector for the $j$th sample of $s_i$ and $l_{i,j}$ to the corresponding emotional label.

Current emotion recognition approaches can be classified into inter-subject and intra-subject data. In general, both types of models are typically built using classification approaches in data. In general, the training data (the sets $T_i, i = 1, 2, \dots, n$) consist of a number of labeled features that relate to emotions. The fundamental difference between the two is whether the training data refers to a single individual (intra-subject) or to a group of people are collectively treated as if there were no particularities that make individuals from each other (inter-subject). In inter-subject methods, a method which is valid for all users is built, using the training data $T_1 \cup T_2 \cup \dots \cup T_n$. In intra-subject approaches, an independent model is built for each individual belonging to the same subject [28–30,59], by considering only training data that belongs to particular subject [40,41]. The high accuracy suggests that the relation between features and emotions holds for some subject-independent models (e.g., [28,29,59]) and that with time, the usually better prediction performance achieved by intra-subject models [40,41] suggests that emotions are reality, subject-dependent. Hence, relations between features and emotions can be better established when the user's particularities are taken into consideration. However, intra-subject methods require exhaustive data collection from the same subject to build the model. Furthermore, they cannot be used without previously unseen individuals, unlike inter-subject methods.



For the purpose of this work, we performed feature extraction as described in the original publications each database. First, we calculated the Power Spectral Density (PSD) using Welch's method with a Hamming window of 128 samples and 50% overlapping. The spectral power was measured over the $\theta$ (4–8 Hz), alpha (8–12 Hz), $\beta$ (12–30 Hz) and $\gamma$ (>30 Hz) from all electrodes. In addition, we computed the difference between the spectral power of all the symmetrical electrodes on the left and right hemisphere to measure the possible asymmetry in brain activity due to emotional stimulus. This yielded 230 features for DEAP and MAHNOB-CI (132 electrodes × 5 bands + 14 pairs × 5 bands), and 105 features in DREAMER (14 electrodes × 5 bands + 7 pairs × 5 bands), as reported in table 1.
