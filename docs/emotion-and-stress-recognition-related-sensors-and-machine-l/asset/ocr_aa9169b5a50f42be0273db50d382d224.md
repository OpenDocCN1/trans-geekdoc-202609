In our problem, we seek the best reduced set of features which is able to obtain the minimum error probability of a classifier. For the goal of minimizing the classification error probability, with a limited number of features (the number of selected features must be less than N_{max}). To avoid loss of generalization of the results, the design set is equally used to determine the best set of features by applying a GA, that is, the classification rate optimized by the GA is determined with the design data.

Since the GA requires the evaluation of many classifiers in the optimization process, the choice of the classifier used in the optimization is crucial. We must consider that for each chromosome in each generation the classifier must be fully trained. Then, the use of users with a very fast running process is required. In this work, we rely on the LSLC.

The full process is described as follows:

+   - A "population" of 100 combinations of features (chromosomes) is randomly generated.

+   - If there are two combinations with exactly the same set of features, one of them is modified by randomly replacing one of the features.

+   - For each combination in the population, if the number of features is greater than the maximum N_{max}, then features are randomly removed from the combination until the condition is satisfied.

+   - Each combination is ranked using the mean squared error of a LSLC measured using the design set.

+   - The best 10 of the population are selected as "parents" and are used to regenerate the remaining 90 chromosomes by a random crossover of the parents.

+   - Mutations are added to the population by changing a feature with a probability of 1%. It is important to highlight that the best individual of each generation remains unaltered. The steps in 2 until a given number of generations are evaluated.

To achieve less risk of premature stalling of the search, we used a method known as Elimination Tournament of GAs [78], that combines several small population of each GA is generated by a random crossover of the "winner" chromosomes from previous GAs.

For this work, the number of features selected is divided by group size in 5, 10, 20, 40, 60, 80 and the full set, for 174 instances in case of using the ECG measurement.

To avoid overfitting (generalization loss) while maximizing accuracy in the estimation of the classification rate, k-fold cross-validation was used in the experiments, being k the number of subjects in the design database, 40 subjects. The data was divided into k folds or subsets containing data from each subject, and each time, the registers from one subject are used as a test set, with the data remaining k-1 for the design set. For each fold, the design process is carried out, including the feature selection process, the choice of the parameters and the training of the classifier. That is, for each fold, features are normalized the mean and standard deviation of the set (the remaining k-1 folds in the dataset), the GA is implemented selecting the best set of features, the classifier is trained with the corresponding methodology, and the hyper-parameters of the classifiers are evaluated (please note here that the hyper-parameters are estimated using the design set). Once this process is completed, the estimated mean and standard deviation are used to normalize the features selected by the GA, and the classifier is evaluated with the previously determined hyper-parameters. The classification rate error is then estimated by analyzing the ratio of patterns wrongly classified in the test fold.

The final classification rate is estimated by averaging the error rates obtained for all the k folds. Since data from the same subject is not for designing and testing at the same time, this method guarantees the generalization of the results to subjects different from the ones included in the database.
