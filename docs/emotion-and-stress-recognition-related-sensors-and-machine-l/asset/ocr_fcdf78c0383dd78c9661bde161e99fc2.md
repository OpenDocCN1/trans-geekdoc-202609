# 5.3. Hyperparameter Tuning

# 5.3.1. Random Forest

Weka's RF API has three major hyperparameters that are related to performance: the number of features to investigate, the number of trees, and the maximum depth of trees. In order to find the best hyperparameters, we trained models with all possible combinations of the parameters within predefined ranges. As a result, we trained 107,100 models and measured these performances with 10-fold cross validation. The predefined ranges of the tuning parameters were as follows:

+   * Number of features: 1-6, default = int(log2(p) + 1)
* Number of trees: 100
* Maximum depth of trees: 1-50, no limit.

Table 5 presents the top three combinations for the Random Forest algorithm in each dataset. To select the best hyperparameters, we established the following prioritization: (1) Accuracy, (2) Area Under the receiver characteristics Curve (AUC), and (3) expected classification cost. Consequently, we selected 7, 14, and 7 as the number of features, trees, and the maximum depth value, respectively, for the EEG-GSR dataset. In the case of EEG and GSR datasets, the default values for the number of features (6, 3, and 3), respectively, and 18 and 11 were selected as the number of trees and depth, respectively. The “no limit” in depth means unlimited search on each tree of random forest. The expected classification cost, 11 appears to be a suitable value.

# 5.3.2. Multilayer Perceptron

We tuned the network design, learning rate, and epoch parameters for MLP in the Weka API. By evaluating the neural network design parameters by testing all possible combinations, whilst keeping the other parameters at default values. For flexible neural network design, we followed the Weka API’s MLP network design strategy (see Table 3). The general concept of a neural network was to decrease the number of each layer’s nodes gradually, from the first layer to the last.

To decide the optimal learning rate and epoch values for MLP, we tested all possible combinations within these predefined ranges. As a result, 3,600,000 models were trained and their performances were measured using 10-fold cross validation. The predefined ranges of each tuning parameter were as follows

+   * Learning rate: 0.01–1.00 (0.01 unit)
* Epoch: 1–2000 (1 unit).
