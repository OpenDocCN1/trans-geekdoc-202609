To increase the models' performance, we applied a feature selection algorithm provided by Weka called Wrapper Subset Evaluator (WSE). We used forward searching and the optimized feature set for each algorithm during initial testing and hyperparameter tuning. ## 5.3. Hyperparameter Tuning

### 5.3.1. Random Forest

Weka's RF API has three hyperparameters that are related to performance: the number of features to investigate, the number of trees, and the maximum depth of trees. In order to find the best hyperparameters, we trained models with all possible combinations of parameters within predefined ranges. As a result, we trained 7,100 models and measured these performances with 10-fold cross validation. The predefined ranges of tuning parameters were as follows:

- Number of features: 1-6, default = log2(p)
- Number of trees: 100
- Maximum depth of trees: 1-50, no limit

Table 5 presents the top three combinations for Random Forest algorithm in each dataset. To select the best hyperparameters, we established the following prioritization: (1) Accuracy, (2) Area Under Curve (AUC), and (3) expected classification cost. Consequently, we selected 7, 14, and 7 as the number of features, trees, and maximum depth, respectively, for the EEG-GSR dataset. In the case of EEG and GSR datasets, the default values for number of features (6, 3, and 3), and 18 and 11 were selected as the number of trees and depth, respectively. The “no limit” in depth appears to be a suitable value.

### 5.3.2. Multilayer Perceptron

We tuned the network design, learning rate, and epoch parameters for MLP in the Weka API. By evaluating network design parameters by testing all possible combinations whilst keeping other parameters at default values, the general concept of neural network was to decrease the number of each layer gradually from the first layer to the last. To decide the optimal learning rate and epoch values for MLP, we tested possible combinations within these predefined ranges. As a result, 3,600 models were trained and their performances measured using 10-fold cross validation. The predefined ranges of tuning parameter were as follows:

- Learning rate: 0.01–1.00 (0.01 unit)
- Epoch: 1–2000 (1 unit)

Table 6 presents the hyperparameter tuning results. To select the best hyperparameters, we established the following prioritization: (1) Accuracy, (2) AUC, and (3) low epoch. To avoid overfitting, the learning needs to stop when the accuracy does not increase. Regarding the network design, models with three hidden layers could not be tested because WSE produced a model that contained only label data. According to the results of Table 6, we selected 0.76, and 73 as the values of network design, learning rate, and epoch, respectively, for the EEG-GSR combined dataset. For the EEG dataset, 0.19, and 489 were the best values of network design, learning rate, and epoch, respectively. Finally, 0.95, and 321 were defined as the values of hyperparameters for the GSR dataset.
