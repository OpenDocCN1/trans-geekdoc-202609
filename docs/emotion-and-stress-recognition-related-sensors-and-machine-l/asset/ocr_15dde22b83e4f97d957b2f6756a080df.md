In this paper, we focus on handling the shortage of data as well as tackling the imbalanced data problem by applying weighted loss and auxiliary loss approaches.

# 2.3. Data Re-Sampling and Augmentation

As nature of emotions, facial expression data collection in real-world scenarios are highly imbalanced in the class (e.g., the images of the happy class is much greater than the number of data that show us). Using data-sampling may degrade the performance of FER models [18]. Data re-sampling and generating samples using adversarial networks (GAN) [48] are widely considered to mitigate the imbalanced problem. Mollahosseini et. [5] used down-sampling and up-sampling methods to balance the distribution of data in the training set, which alleviates the imbalanced problem. However, the two data re-sampling methods simply reduce the number of samples in major classes or duplicate samples in minor classes without collecting further data. Under-sampling may discard samples which are important for the model while over-sampling significantly increases the training time [49]. Li et al. [50] proposed a GAN that generates facial images from input non-facial face images. This model can be used to augment more data for training FER models. Nevertheless, the reliability of the new data needs to be carefully verified before being to train FER models, otherwise the data may degrade the performance of FER systems. Our solution is based on a weighted loss approach that tackles the imbalanced data problem without the need of data re-sampling or augmentation step.

# 2.4. Weighted Loss and Auxiliary Loss

Weighted-softmax loss gives weights to the loss of each class based on its relative number of samples in the training set. In this, the loss function heavily penalizes the FER model for misclassifying examples from minor classes, while lightly penalizing the model for misclassifying examples from major classes. Mollahosseini et al [5] showed that the weighted-loss methods achieve the highest performance and over-re the re-sampling methods. However, since the weighted-softmax loss function is based on conventional softmax loss, it inherits the limitations of softmax loss. For example, weighted-softmax loss simply forces features of different classes to remain apart, while paying attention to intra-class complexity.

To tackle the limitations of softmax loss, several auxiliary approaches have been proposed, and they can be used to improve the discrimin ability of FER models. Contrast loss [51] inputs the CNN model with a pair of training samples, which features the features of class-pairs to be as similar as possible while requiring a distance longer than a predefined margin if the input samples to different classes. Similar to contrast loss, triplet loss [19] encourages a positive sample to be selected from a preselected anchor one with a fixed margin. Based on triplet loss, there are two variations proposed to support softmax loss. (N + M)-clusters loss triplet-based [53] gives more weight to difficult samples during an update of network parameters.
In spite of success, these loss functions still need a careful pre-selection process. However, this becomes impossible when the number of training samples is relatively large. Recently, center loss [29] has been proposed for the face recognition task; it penalizes the distance between deep features and their corresponding class clusters to reduce intra-class differences.
