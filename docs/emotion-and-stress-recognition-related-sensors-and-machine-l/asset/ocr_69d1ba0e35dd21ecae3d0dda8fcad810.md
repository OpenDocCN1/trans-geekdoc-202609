Despite the high prediction rates obtained in some cases, these can be significantly improved by using individual models adapted to each user [30–32]. However, subject-dependent (intra-subject) approaches suffer from two drawbacks. First, they require the collection of a large amount of data to adequately model the relation between the EEG signal and the emotion for each person. Second, they cannot be used for unseen users as they use only data related to the individual. These two drawbacks make the approach impractical in many cases.

In this paper, we test the stability of intra-subject and inter-subject modeling approaches in an EEG-based emotion recognition context, by analyzing the data in three databases, the Database for Emotion Analysis using Physiological Signals (DEAP) [33], MAHNO-HCI [34] and DREAMER [35]. The analysis performed clearly indicates that the condition of the subject to the EEG signal is far larger than the effect of the emotion, limiting the applicability of intra-subject models and suggesting a better behavior of subject-dependent models that only train data associated with the same subject. An in-depth analysis dataset also reveals many positive results for subject-independent models reported in some previous works may be due to the use of unbalanced datasets. As a second and more important contribution, we propose an approach that combines a subject-based normalization of the EEG signals, making it effectively to generate a single model, which is valid across the entire population. This approach integrates related data to personality traits into the model, encoding a personality without affecting data capturing The gains achieved open the door for a single model for unseen subjects, which can be progressively adapted as more data generated.

This paper is structured as follows. First, related work is described in Section 2, covering both modeling approaches and existing public databases. Then, in Section 3, the three repositories are analyzed using a method that reveals keys related to the topological structure of the data. After, we present our proposal to partially cancel the subject-related component from the signal to achieve an inter-subject model with comparable performance to typical intra-subject models. This method is evaluated in Section 5. Finally, the main conclusions from this work are presented in Section 6.





Computational methods for affect detection attempt to relate features extracted from certain signals measured a emotional processes. These features may be captured from, e.g., facial expressions, voice, body language and posture, functional Magnetic Resonance Imaging (MRI), Magnetencephalography (MEG) brain signals and/or EEG. In general, machine learning algorithms are used to identify signal patterns that are associated with the emotion and to build models that enable the automatic detection of a concrete of sets (e.g., [36–38] for extensive reviews of the field). These machine learning approaches can be classified as intra-subject or inter-subject. Methods in the first category aim at constructing a model that is for all users. Techniques in the second consider the appraisal of one’s emotional state is strongly related to personality features, such as individuals [39]. They aim to construct an individual model for each user, increasing the performance at the cost of increasing data collection needs [40,41].

The prediction of a subject’s emotion/mental state from brain signals has been widely studied, including both EEG and MEG signals [42,43].
