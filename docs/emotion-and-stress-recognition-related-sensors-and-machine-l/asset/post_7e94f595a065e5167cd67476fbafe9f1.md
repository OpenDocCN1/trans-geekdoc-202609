
## 4.2. Personal Stress Detection

The combination of BVP and ST features produced the highest recognition rates using user-independent regression model; however, this combination was not the best for each subject. Table 6 shows subject-wise which sensor combination improves the recognition rate over 20% units (59.4% vs. 83.2%, respectively). However, it has an even bigger effect on standard deviation, which is much smaller when features are selected subject-wise (17.0 vs. 11.7, respectively). Therefore, the possibility to select features subject-wise, and how you personalize the recognition model, could potentially have a significant positive effect on the recognition rates.

The dataset contains more than one data gathering session from three study subjects (three sessions from subject NM: NM1, NM2, and NM3; two from RY: RY1 and RY2; and two from GM: GM1 and GM2). Therefore, these study subjects can be used to experiment if the stress recognition models trained using personal data are more accurate than user-independent models, as is suggested in some of the papers. The data gathering process was the same in each session, and on each session, the study subjects drive the same route. However, what makes each session unique is that traffic was different in each case, as the study subjects drive on public roads.

User recognition rates for NM, RY, and GM are shown in Table 7 using different sensor combinations, and classification and regression models. In each case, models are trained from one session and tested with data from the same user. NM, RY1, and GM were used for testing, as they were also used in the previous section to train models. According to Table 4, using a user-independent model and a combination of BVP and ST features, which based on Table 2 provides the highest average accuracy. Subject NM's stress can be detected with balanced accuracy 64.3%/84.6% (classification vs. regression), RY's 90.8%/93.7%, and GM's 89.6%/95.0%. When compared to personal recognition rates based on the same session, it can be noted that personal data does not have a big effect on the recognition rates. In the case of RY, the results of the based personal model are more accurate than the results based on the user-independent model. Moreover, according to Table 7, using personal models is surprisingly no better than when a specific sensor combination is used. There are some exceptions: RY's and GM's stress can be recognized with high accuracy using a combination of BVP and ST features. However, the results from these users were already really good using the user-independent model, and the usage of personal data does not have a benefit compared to those.

There can be reasons for low personal recognition rates. For instance, in the case of data from subject GM, there seem to be problems with the EDA signal, and thus, the prediction. Another reason for low recognition rates can be that the size of the training data was not enough; in the case of personal model training, the data consists of measurements from one session, whereas in the user-independent case, it is considered measured from eight sessions. In the case where NM1 was trained using data from two data gathering sessions (NM2 and NM3), the results were much better than the ones reported in Table 7, and over 98% balanced accuracy was obtained using BVP and ST features, see Table 8. However, also in this case, it can be noted that the recognition rate is highly dependent on which data are used for training and for validation. It can be noted that if NM2 and NM3 are used for training and NM3 for testing, the recognition rates are well bad no matter which sensor combination is used. This shows that there is a level of variation between data gathering sessions, even if the data are collected from the same person.

In this article, regression and classification models were considered for stress detection. Both personal and user-independent models were experimented with. The experiment was based on a publicly open dataset [14], which, unlike most of the other stress detection datasets, contained continuous variables. The used classification model was Random Forest and the regression model was Bagged tree based ensemble.

The study shows that regression models are superior to classification models when it comes to user-independent stress detection, if continuous values are available. The best results were obtained using a combination of BVP and ST features, and using these, the average accuracy was 74.1% with the classification model and 82.3% using the regression model. In fact, no matter which sensor combination was used, results were better than those obtained with the classification model. This is because during the training process, the regression model gets more information than the classification model: regression gets continuous targets as input, while classification models use discrete targets. Moreover, the results show that stress is not a binary problem; a person can be highly stressed, not stressed at all, or between these two. The results of this article show that the prediction model should be trained so that all the given data can be used as input to it.

The main advantage of using regression models is that they can not only be used to recognize whether the person is stressed or not, but can also be used to predict the level of the stress. However, based on our experiments, this is not very accurate, and for some subjects, it does not work at all.
