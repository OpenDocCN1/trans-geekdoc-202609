For training, we used the Adam [23] optimizer with a learning rate of $10^{-3}$ and a step decay
scheduler (i.e., the learning rate is halved every 50 epochs). The binary cross-entropy loss was used to
calculate the losses between the labels and predictions, as follows:

```
$L = -\sum_{i=1}^{M} y_i \log(y_i) + (1 - y_i) \log(1 - y_i).$$
```

We used a total of 250 epochs, with a size of 0.2 and a 0.31 split (i., 30% of the
training set). Finally, with the lowest loss on the validation set after 250 epochs was used for
evaluation. With the machine learning models, we used five-fold cross validation to evaluate thenperformance of the network.

All processes were conducted using the well-known Keras deep learning library,
with Python 2.7 running under Ubuntu 16.04, on a PC with a 3.6 GHz Intel Core i7 processor,
12 GB of RAM, and 4 NVIDIA GeForce GTX1080 Ti (San Clara, CA, USA).

# 3. Metrics

Because this is a classification problem (i.e., the subject is stressed or unstressed), we used the following metrics to evaluate both the deep learning network and the machine learning models:

```
$Accuracy = \frac{TP + TN}{TP + TN + FP + FN} \times 100\%,$$
```

Here, TP (true positive) is the number of cases correctly classified as "stressed," TN (true
negative is the number of cases correctly classified as "unstressed". FP (false positive) is
the number of cases classified as "stressed" but actually "unstressed", while FN (false
negative) is the number of cases classified as "unstressed" but actually "stressed.\nThe first metric (accuracy) is the percentage of cases that were correctly predicted, while the second (F1
score) is the harmonic mean of precision and recall, which indicates the trade-off between these
two metrics.

In addition to the accuracy and F1 score, we also used the area under the receiver operating
characteristic (ROC) curve to evaluate the models. The area under the ROC curve (AUC) is a
well-known accuracy metric [24]. By calculating each sensitivity and specificity according
to probabilities, which is within 0 to 1, the ROC is independent of the different thresholds
and the metric is reliable and reflects the performance with the thresholds. Models with
AUCs above 0.9 are considered to be accurate [24].
