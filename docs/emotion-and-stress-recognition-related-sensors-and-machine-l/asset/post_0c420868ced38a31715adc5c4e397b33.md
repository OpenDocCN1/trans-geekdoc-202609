Although we had distributed data in known contexts labels in the laboratory, we had a class imbalance problem in the self-reported ground truth labels from the daily life and laboratory. In the daily life data, 71.5% of the data was relaxed and 28.5% of data was stressed. In addition, 73% of the daily data was relaxed, and the remaining 27% was stressed. We overcame this problem by undersampling the extra samples of the majority class, which is the most commonly used for unbalanced datasets [51]. We further applied normalization on features to prevent overfitting. We converted the numeric labels to the nominal type as an input to the Weka tool classification algorithms.

We developed five different models that used different ground truth types and 248 training and test environment combinations (see Figure 5). The data were divided into two minute windows in the preprocessing part. The label of the window extracted from the time was added to the feature vector. The label could be the stress of the session or the perceived stress level obtained from the participants. Features extracted from all windows belonging to a session were averaged, and the label was appended to this feature vector. Data coming from all participants were merged and randomly listed. We then formed one general model from our dataset. In other words, separate models for all participants were not formed. In order to evaluate the performance of the classifiers, we applied 10-fold cross-validation by partitioning the original sample into a training set to train and model a test set to evaluate, we changed the test and training until each partition was used for the test set. We further created separate training (80%) and test sets (20%) and evaluated the results to compare with 10-fold cross-validation. In the 10-fold results, the standard deviations of the folds are provided in parentheses.

We used five different machine classifiers for recognition of stress events. These classifiers were the ones used and that performed best in the literature [26,42], namely multi-layer perceptron (MLP), random forest (RF), k-nearest neighbor (KNN), support vector machine (SVM), and logistic regression (LR). For the LR, the output probability was divided into two classes, which were above and below 0.5 [52]. We used the Weka Machine Learning Software [53] for the classification section of our proposed system.

In order to select the best parameter set for the MLP, we experimented with the different numbers of layers (1, 2, and 3) and from (1 to 20); one outperformed others, which had two hidden layers, and each had five units. We experimented with N for the KNN. After parameter tuning, the best N was selected as 3. We used the radial basis kernel (RBF) and linear kernel for the SVM. We selected RBF for SVM as it outperformed the linear kernel. For the RF, we selected the number of trees as hundred.

We divided our tests into two groups: laboratory and in the wild experiments. We examined the results in the following sections.

In this experiment, we aimed to differentiate between the stress and baseline states. In this section, we investigated the performance of our stress detection system in two different manners. The first one was using the known context as the ground truth. We further provide these labels as for the ML algorithm. The second way was to measure the perceived stress levels from self-reports as the ground truth. We collected PSS-5. For these five cases, positive emotions were evaluated.
