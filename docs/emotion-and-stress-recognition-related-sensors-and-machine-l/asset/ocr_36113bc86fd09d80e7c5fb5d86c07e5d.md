# 3.2. Decision Fusion

In contrast to FF, from each sensor signal, a feature is extracted and used independently to train and learn a classifier, so that each modality returns a set of predicted labels. With k modalities, k classifiers will be created k predictions per sample. The resulting predictions are combined to yield a final result, in our case, a weighted majority voting system. In this voting system, the ensemble decides the class that receives the highest number of votes taking into account all sensor modalities, and a weight (W) per modality to give the most competent classifiers a greater power for the final decision. The weights were chosen according to the classifier accuracy on the validation set. In case of a draw in the class prediction, the selection is random.

# 3.3. Classifier

To perform the classification SL classifiers were tested: K-Nearest Neighbour (k-NN), Decision Tree (DT), Random Forest (RF); Support Vector Machines (SVM), AdaBoost (AB), Gaussian Naive Bayes (GNB), and Quadratic Discriminant Analysis (QDA). For more detail regarding these the author refers to [48] and references therein.

A comprehensive study of these classifiers and parameter tuning was performed using 4-fold Cross (CV) to ensure a meaningful validation and avoiding overfitting. The value of 4 was selected to optimize the number of iterations and the homogeneity in the classes in the training and test set, some of the datasets used were highly imbalanced. The performing classifier was chosen using Leave-One-Out (LOO) to be incorporated into the FF and DF frameworks.

To obtain an measurable evaluation of the model performance, the following metrics are computed: Accuracy—Precision—Recall—F1-score—the harmonic mean of precision and recall [49]. Nomenclature: TP—True Positive; FP—False Positive; FN—False Negative.
