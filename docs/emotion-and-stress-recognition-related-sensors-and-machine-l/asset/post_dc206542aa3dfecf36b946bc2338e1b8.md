Let $R_i^b$ be an automatic detected ROI over the thermal frame $i_t$, that presents a coordinate $C_i^b = (C_{bx}^b, C_{by}^b)$ at the left upper corner, which corresponds to $R_i^a$ (annotated ROI over $i_s$) with $C_i^a = (C_{ax}^a, C_{ay}^a)$ at the left upper corner. Then, two probabilities $p_{bx}^b$ and $p_{by}^b$ can be calculated for $R_i^b$ taking into account the expert annotation, as described in Equations (1) and (2). These $p_{bx}^b$ and $p_{by}^b$ are values computed in relation to $x$ and $y$, respectively. They take values closer to 1 if $R_i^b$ highly agrees with the manual annotation of the trained expert, which are shown in Equations (1) and (2). Notice that $R_i^b$ is automatically obtained by applying the Viola-Jones algorithm, defining fixed proportions (see Section 3.2.4).

$$p_{bx}^b = \frac{\exp(-\frac{C_{bx}^b}{W_b})}{\sum_{i=1}^{11} \exp(-\frac{C_{bx}^i}{W_i})} \quad (1)$$

$$p_{by}^b = \frac{\exp(-\frac{C_{by}^b}{H_b})}{\sum_{i=1}^{11} \exp(-\frac{C_{by}^i}{H_i})} \quad (2)$$

$$p_b^b = \min(p_{bx}^b, p_{by}^b) \quad (3)$$

where $k$ refers to the current ROI for analysis, taking values from 1 to 11; $W_b$ and $H_b$ are the width and height of $R_i^b$, respectively; $W_a$ and $H_a$ are the width and height of $R_i^a$ (head ROI for $i_s$); $p_{bx}^b$ and $p_{by}^b$ are the probabilities that $R_i^b$ were correctly located on $i_s$ regarding the trained expert annotation, in relation to $x$ and $y$, respectively.

Finally, $R_i^c$ (for which $C_i^c$ is denoted as $C_i^{cf}$) of lower probability $p_b^b$ is selected as a reference to correct the location for the other ROIs, using Equations (4) and (5). It is worth mentioning that $C_i^{cf}$ is used for the annotated frame $i_a$.

$$C_{bx}^{c} = \frac{C_{bx}^{cf} + C_{ax}^{c} - C_{ax}^{cf}}{W} \quad (4)$$

$$C_{by}^{c} = \frac{C_{by}^{cf} + C_{ay}^{c} - C_{ay}^{cf}}{H} \quad (5)$$

where $C_i^c = (C_{bx}^c, C_{by}^c)$ is the coordinate of the upper corner for $R_i^c$ located.

Given a thermal frame $i_t$, formed by a set of ROIs, $R_b = \{R_i^b, R_i^2, ..., R_i^K\}$, being $K=11$ is the total number of ROIs, it is possible to extract from a feature vector $F_b = \{f_b^1, f_b^2, ..., f_b^k\}$ that describes a pattern related to emotion, being $f_b^k = (f_{ib}^k)$ features of $R_i^b$. Table 2 presents the features adopted in our study, which agree with [16].

$R_i^b$ is the current ROI for feature extraction, $R_i^b$ is the value of $R_i^b$, $\sigma^{2k}$ is the variance of $R_i^b$, and $f_{nc}^c$ for $c$ from 1 to 7 are other seven features corresponding to the difference of computed features throughout consecutive frames. So we have eleven ROIs (see Figure 4), and 14 features for each of them. This gives a set of 154 features per frame.

## Table 2. Features computed in each ROI

| Features | Equations |
| :--- | :--- |
| Mean value of the whole ROI | $f_k^1 = \frac{1}{m}\sum_{i=1}^m R_{ij}, c=1$ |
| Variance form from the whole ROI, organized in a vector | $f_k^2 = \frac{c}{m-1}\sum_{i=1}^m (R_{ij} - R_j^k)^2, c=2$ |
| Median of the whole ROI, organized as a vector | $f_k^3 = median(R_{ij}), c=3$ |
| Mean of variance in rows | $f_k^4 = \frac{m}{n-1}\sum_{j=1}^n (R_{ij} - R_j^k)^2, c=4$ |
| Mean of median in rows | $f_k^5 = \frac{1}{m}\sum_{i=1}^m R_{ij}, c=5$ |
| Mean of variance in columns | $f_k^6 = \frac{n}{m-1}\sum_{i=1}^m (R_{ij} - R_j^k)^2, c=6$ |
| Mean of values in columns | $f_k^7 = \frac{1}{n}\sum_{j=1}^n R_{ij}, c=7$ |
| Difference from each item from consecutive | $f_{b(c+7)} = f_{be} - f_{b(b-1)}, c=1,2,...,7$ |

Let $T=(F_1, Y_1), (F_2, Y_2), \dots, (F_n, Y_n)$ be the training set, where $n$ is the number of samples, and $F$ is a $d$-dimensional feature vector with class $Y_i \in \{0,1,2,3,4,5\}$. PCA method used on Single Value Decomposition [9,16,20,23,36] is applied to $F$ to extract the principal components, which are used in both training and validation sets. As advantages, PCA is few sensitive to difference training sets.
