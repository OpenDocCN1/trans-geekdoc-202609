# 2.3. The Deep Neural Network

We propose a deep convolutional neural network to detect events. Figure 2 shows the architecture of the proposed model. It obtains input of raw ECG signals, not HRV parameters $x \in \mathbb{R}^{m \times w \times c}$ or other physical signals. The input dimension can be defined as the size of the mini-batch and the number of channels, respectively, and $w$ refers to the width of the ECG. An output of the first strided convolutional layer and pooling layer are i.e., set to 2. The model has successive stages ($N=8$) to extract features of the ECG. Table 3 shows the list of the detailed parameters used in the stages. The number of filters in the convolutional layer is defined as $8 \times 2^k$, where $k$ begins at 0 and increases by one every stage. Each stage consists of two convolutional layers and one pooling layer. A convolutional layer performs a convolution operation with a filter and a specific stride. A stride is defined how much the filter moves within a layer (i.e., the convolutional and pooling layer). The stride of the strided convolutional layer is fed to both strided convolutional layer and a pooling layer. The strides are subsampled and the model chooses the maximum stride which is used in the pooling layers. Both the strided convolutional layers and the pooling layers subsample their inputs, followed by each input concatenated along its channels. If the previous stage has $x^{(N-1)} \in \mathbb{R}^{m \times w \times c}$, the strided convolutional layer and pooling layer produces outputs $(c^{(N)}, p^{(N)}) \in \mathbb{R}^{m \times w \times c}$, where $c^{(N)}$ and $p^{(N)}$ denote the output of the strided convolutional layer and pooling layer in the stage $N$. Concatenating along its channels gives the dimension of $c^{(N)} \in \mathbb{R}^{m \times (w/2)^N \times c}$. When passing through the stages ($N=1, 2, \dots, 8$), dimension reduction along its width is formed. If the input (raw ECG) has dimensions of $x \in \mathbb{R}^{m \times w \times 1}$

```
$c^{(N)} \in \mathbb{R}^{m \times (w/2)^N \times c}, \quad N \in \1, 2, \dots, 8\}\nw = 256 \times \text{window}, \quad w \in \{10, 30, 60\}\nc = 8 \times 2^k, \quad k = \begin{cases} -0.5, & \text{if } N \text{ is odd} \ -1, & \text{if } N \text{ is even} \end{cases}$
```

The extracted features ($c^{(8)}$) generated by the last stage are fed to the softmax classifier, which performs a binary classification between stress and rest:

> $h_j = \frac{\exp(c^{(8)})_j)}{\sum_{i=1}^2 \exp(c^{(8)})_i}, \quad j=1,2$

where $j=1$ for the binary classification. The output of the softmax classifier, $h_j$ represents the probabilistic distributions of each class-stress and rest which one of them is 1. We used a rectified unit (ReLU) as an activation function to generate a non-linear boundary between the successive linear combinations of the weighted inputs. The activation function produces a maximum value between zero and its input. We applied dropout [26] with a rate of 0.3 and batch normalization [27] to prevent overfitting. A neural network can be easily overfitted to the training data when a model learns within a small number of data sets. Many studies have used of dropout and batch normalization to avoid overfitting.
