# # Comparison of Regression and Classification Models for User-Independent and Personal Stress Detection

**Abstract:** In this article, regression and classification models are compared for stress detection. Both personal and user-independent models are experimented. The article is based on publicly open dataset AffectROAD, which contains data using Empatica E4 sensor and unlike most of the stress detection datasets, contains continuous target variables. The used classification model is Random Forest and the regression model is Bagged tree ensemble. Based on experiments, regression models outperform classification models, when classifying observations as over-stressed. The best user-independent results are obtained using a combination of blood volume pulse and skin temperature features, and using these average balanced accuracy was 74.1% and 82.3% using regression. In addition, regression models can be used to estimate the level of stress. Moreover, the results based on models using personal data are not ensuring that biasings have a lot of variation not only between the study but also the session gathered from the same person. On the other hand, it is shown that with subject-wise feature selection for user-independent model, it is possible to improve regression models than using personal training data to build personal models. It is fact that with subject-wise feature selection, the detection rate can be improved by much as 4 percent, and it is especially useful to reduce the variance in the recognition rates between the study subjects.

**Keywords:** stress detection; wearable sensors; regression; classification



Wearable sensors are commonly used to monitor human motion based on inertial sensors such as accelerometer, gyroscope, and magnetometer. However, wearables can also include sensors to measure facts. In fact, nowadays wearable devices can include a photoplethysmography to measure blood volume pulse, thermometer to measure body temperature, and electrodermal activity to measure galvanic skin response. Based on these, it is possible not only to monitor human motion, but they also enable a possibility to monitor other aspects of human behaviour and happening inside human body.

Recently, there has been a lot of attention to stress and affect recognition using wearable sensors.
