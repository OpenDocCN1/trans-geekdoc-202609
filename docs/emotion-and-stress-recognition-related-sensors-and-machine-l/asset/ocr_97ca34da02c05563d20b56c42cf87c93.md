In evaluate our proposed system for emotion recognition, a published database (available in the supporting information of [17] at the website —Available at https://journals.plos.org/plosone/article?id=10.1371/journal.pone.021298) was used, which is formed by feature vectors labeled the following five emotions: disgust, fear, happiness, sadness and surprise. This database was collected on 27 typically developing children (age: 7-11 years) by an infrared thermal camera. It is worth noting that this database was also created with children of similar age, using the same camera and set (a total of 154 features) described in our study (see Sections 3.1, 3.2 and 3.7), and computing this feature over the ROIs defined in Figure 4. Note the correct locations of these ROIs were verified by a trained expert. For this reason, it was possible to recognize the emotion recognition using one of the following methods: PCA for dimensionality reduction and Fast Neighbor Component Analysis (FNCA) [17] for feature selection. The training and validation sets were chosen for several rounds of cross-validation (kf=3), and metrics such as accuracy (ACC), Kappa, true positive rate (TPR), and false positive rate (FPR) were used [51].

On the other hand, this published database was used to train our proposed system by PCA, but using only data collected from those who presented ACC higher than 85% during the emotion recognition [17]. Our trained system was used to infer the child emotion during our experimental protocol described in Section 3.1.
