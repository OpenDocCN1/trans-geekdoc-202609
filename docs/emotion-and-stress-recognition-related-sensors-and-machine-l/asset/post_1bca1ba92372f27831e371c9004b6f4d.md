Nonetheless, adding more loss terms usually comes with difficulty in the training phase caused by extra hyper parameters that need to be adjusted. ## 3.3. Weighted-Cluster Loss

### 3.3.1. Review of Weighted-Softmax Loss

Weighted-softmax [5] often comes as a solution for tackling the imbalance dataset problem. Weighted-softmax loss weighs the entropy loss of each of the emotion classes by their relative proportion of the total number of samples in the training dataset. The entropy weighted-softmax loss for the $i^{th}$ training sample is defined as:

```
L_{Weighted-softmax} = -\sum_{i=1}^{m} W_i \log(\hat{p}_i)
```

where $m$ is the number of training samples in the softmax batch (i.e., the batch size), $y_i$ is the class label of the $i^{th}$ training sample, $W_i$ denotes the weight assigned to the class where the label is $y_i$, and $\hat{p}_i$ is the softmax-predicted probability of the $i^{th}$ sample.

Although weighted-softmax loss is also able to tackle the imbalanced dataset, it has some limitations. Since weighted loss assigns less weight to the conventional softmax loss, it is incapable of handling not only high inter-class similarity but also high intra-class variations.

### 3.3.2. Review of Center Loss

Center loss [20] can be incorporated with conventional softmax loss to reduce the intra-class variations by compressing samples towards their corresponding center class in the feature space during training. Center loss for the $i^{th}$ training sample is:

```
L_{Center} = \frac{1}{2} ||\mathbf{x}_i - \mathbf{c}_i||^2
```

where $L_{Center}$ denotes the center, $\mathbf{x}_i \in \mathbb{R}^d$ denotes the deep feature of the $i^{th}$ training sample (i.e., taken from the last fully connected layer, before the output layer), and $\mathbf{c}_i \in \mathbb{R}^d$ denotes the center of class label $y_i$; $d$ is the dimension.

To handle the imbalance, the total loss of the CNN is given by:

```
L = L_{Softmax} + \lambda L_{Center}
```

where $L$ is the total loss, $L_{Softmax}$ is the softmax loss, $L_{Center}$ is the center loss, and $\lambda$ is a scalar used to balance the two.

### 3.3.3. Proposed Weighted-Cluster Loss

To address the limitations of existing functions (e.g., weighted-softmax and center loss), we propose a new loss called weighted-cluster loss, which takes the imbalance into account and pulls the cluster centers apart. The weighted-cluster loss for the $i^{th}$ training sample is given by:

```
L_{Weighted-cluster} = \frac{1}{2} ||\mathbf{x}_i - \mathbf{c}_i||^2
```

where $L_{Weighted-cluster}$ denotes the center, $\mathbf{x}_i \in \mathbb{R}^d$ denotes the deep feature of the $i^{th}$ training sample, and $\mathbf{c}_i \in \mathbb{R}^d$ denotes the center of class label $y_i$. By minimizing the weighted-cluster loss, the features of the same class are compacted while the distance between different classes is enlarged. In this paper, we set $a=1$.

The overall loss for FER using the weighted-cluster loss is:

```
L_{Weighted-cluster} = -\sum_{i=1}^{m} W_i \log(\hat{p}_i) + \lambda \frac{1}{2} \sum_{i=1}^{m} ||\mathbf{x}_i - \mathbf{c}_i||^2
```

where $W_i$ is the weight assigned to the class where the label is $y_i$. We define $W_i$ as:

```
W_i = \frac{N_{min}}{N_y}
```

where $N_{min}$ is the number of samples from the smallest class, and $N_y$ is the number of samples from class $y$.
