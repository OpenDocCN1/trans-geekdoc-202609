There are many hyperparameters (e.g., the number of layers, number of neurons, size of the mini-batch, filter width, number of channels, others) to be decided, and in chose how many stages are adequate for the proposed model. The number of the stages began with 1, and the performance for accuracy showed as the number of stages increased by 1, up to 8. With the proper number of stages, we tuned the filter width and the number of filters to find the best fitting parameters. We searched the hyperparameters of the DNN through a grid search method and a manual search. We chose the model that achieved the highest accuracy for the test data set all the maximum 10 epochs. # 2.4.1. Type Training

We generated a pretrained model with the driving data set. As the DNN requires a large amount of data for training, we used the driving data set, which was larger than the mental arithmetic data set. The learning rate was set to $1 \times 10^{-3}$ and was reduced by a factor of 10 every 5 epochs.

# 2.4.2. II Training

Using the mental arithmetic data set, the same method of end-to-end training was applied as in Type training. Additionally, we used all the same hyperparameters to observe how the size of the data set affected the neural network.

# 2.4.3. III Training

We applied a transfer learning method, using the pretrained model by Type training. As mentioned above, it is difficult to train a neural network with a small data set. If a model is trained based on a pretrained model, the model can easily be fine-tuned. We hypothesized that the ECG measurements from the participants who had the mental arithmetic task were similar to those from others. It is effective to apply transfer learning when the distribution of data set to be learned is similar to that of the pretrained model. The softmax classifier required a re-training process, because although their distributions were different. However, re-training only the softmax classifier did not show an acceptable performance. The number of layers to retrain was, thus, considered as a hyperparameter. We applied the grid search method to find the proper stages (Stage 1, Stage 2, . , Stage 8) to be retrained.
