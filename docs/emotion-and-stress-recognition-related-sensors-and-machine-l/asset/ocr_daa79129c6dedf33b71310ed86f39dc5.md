Many physiological modalities and features have been evaluated for ER, namely Electroencephalography (EEG) [28–30], Electrocardiography (ECG) [31–33], Electrodermal Activity (EDA) [34–36], Respiration (RESP) [24], Blood Volume Pulse (BVP) [25–35] and Temperature (TEMP) [26]. Multi-modal approaches have prevailed; however, there is no clear evidence of which feature combinations and physiological signals are the most relevant. The literature shows that classification performance improves with the simultaneous exploitation of digital modalities [28,10,37], and that modality fusion can be performed at two levels: FF [24,38,39] and DF [8,5,7,40,41]. In the former, features are extracted from each modality and later concatenated to a single feature vector, to be used as input for the ML model. The other hand, in DF, from each modality, a feature is extracted to form a classification prediction through a voting system. With k modalities, k classifiers will be created to k predictions that can yield a final result. Both methodologies are found in the state-of-the-art [42], but it is considered the best to use in the ER using multimodal physiological data from non-intrusive wearable technology.

Detailed information on the current state-of-the-art in a more generalized perspective; we review the readers surveys [21,11–47] and references therein, where a comprehensive review of the literature for working on ER with physiological signals can be found, highlighting the main achievements, challenges, take-home messages, and possible futures.

The present work extends the state-of-the-art of ER through: (1) Classification performance in the analysis of the arousal/valence space, of ER for five publicly datasets that cover multiple elicitations; (2) Summarising the rates of classification accuracy across the literature for the evaluated datasets; (3) Characterising the results for diverse classifiers, modality and feature combinations for ER using classification accuracy and F1-score as evaluation metrics (the later being commonly reported as important to evaluation classification bias); (4) Exploration of an extended feature set for modality analysis, and relevance through feature selection; (5) Systematic analysis of multimodal classification in DF and FF approaches, with superior or comparable results to those reported in the state-of-the-art for the selected datasets.



To evaluate the classification accuracy in ER from physiological signals, we adopted the two Dimensional Valence/Arousal space. As previously mentioned, the ECG, RESP, EDA, and BVP signals are used, and we compare FF and DF techniques in a feature space based framework. The forthcoming sub-sections, a more detailed description of each approach is presented.



As previously mentioned, when working with multi-modal approaches the exploitation of the different signals can be performed using different techniques. We start by testing the FF technique. In FF, the features are independently extracted from each sensor modality (in our case ECG, BVP, EDA, and RESP) and concatenated afterwards to form a single, global, feature vector (57 features for EDA, 372 for BVP, and 487 for RESP), implemented and detailed in the BioSPPy software library https://github.com/PIA-Group/BioSPPy. Additionally, we applied sequential feature selection (SFFS) in order to preserve the most informative features, and save time and computational power of the machine learning algorithm applied in the next step. All the presented methods were implemented in Python and made available as open source software https://github.com/PIA-Group/BioSPPy.
