In this article, regression and classification models were considered for stress detection. Both personal and user-independent models were experienced. The experiment was based on publicly open dataset [14], which unlike most of the other stress detection datasets, contained continuous variables. The used classification model was Random Forest and the regression model was Bagged tree based ensemble.

The study shows that regression models are superior to classification models when it comes to user-independent stress detection, if continuous values are available. The best results were obtained using a combination of BVP and ST features, and using these average accuracy was 74.1% with classification model and 82.3% using regression model. In fact, no matter which sensor combination was used, results better than the obtained classification model. This is because during training process, regression model gets more information than classification model: regression gets continuous targets as input while classification models are discrete. Moreover, the results show that stress is not binary problem, a person can be highly stressed, not stressed at all or between these two. The results of this article show that prediction model should be trained so that all the given can be as an input to it.

The main advantage of using regression models is that they can not be used to recognize whether the person is stressed or not, can also be used to predict the level of the stress. However based on our experiments this is not very accurate, and for some subjects it does not work at all.
