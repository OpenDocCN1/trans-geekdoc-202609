Our goal in the first part of the network is to obtain the feature maps that contain sufficient pixel-level details, high-resolution outputs that remain the same size as the input image (no resolution loss) and less extensive computation. FCNs-based heatmap regression, followed by a kernel convolution, is used to meet our goal. To do so, we initially transform the facial landmarks’ ground-truth position $p^k(x,y)$ of $k^{th}$ key into target heatmap $h^k(p)$ of $k^{th}$ key (Figure 4a) via 2D Gaussian kernel. Then, the target heatmap $h^k(p)$ is fed into FC-DenseNets and finally converted with a kernel convolution as illustrated in Fig. 4b. By fully convolutional heatmap regression, the task becomes of predicting per-pixel likelihood of each key's heatmap. It regresses the target heatmap $h^k(p)$ directly to obtain the response $M(p)$ stated in Equation (2), which is same as the input image.

We transform ground-truth location $p^k(p)$ to target heatmap $h^k(p)$

$$h^k(p) = \frac{1}{\sigma\sqrt{2\pi}}\exp(-\frac{\|p-p^k\|^2}{2\sigma^2}), p \in \Omega,$$

where $\sigma$ is the standard deviation for the heatmaps used to control the response scope and $\Omega$ is the set of all pixel locations in image.

We set the FC-DenseNet architecture to include 56 layers following Reference [19], which made FC-DenseNet56 with 4 layers per dense block and growth rate = 12. We adopted the smallest FC-DenseNet to reduce network computational complexity, as shown in Table 1, while still achieving notable outcomes compared with current architectures. We fully applied convolutional ResNets with 50 layers (FC-ResNet50 [41]), available in the PyTorch framework [42] (Torchvision) and compared the outcomes with fully convolutional DenseNets with 56 layers. As expected, FC-DenseNet56 outperformed FC-ResNet50 due to more depth and hence parameters.

## Kernel Convolution

The output of FC-DenseNet is in a channel-wise fashion that has the same resolution as the input image. After reaching the output of the network, an implicit $3 \times 3$ convolution $K_{\sigma}$ is applied to produce a clear shape of the feature maps. For computational efficiency, the kernel convolution $K_{\sigma}$ is generated by the Gaussian function in Equation (2). Here, the kernel convolution acts as a point-spread function to blur the input feature maps as shown in Figure 5. The kernel convolution filter $K_{\sigma}$ removes the noise and provides better smoothing by preserving the edges. Kernel convolution filter evolves with the entire image using grouped convolution [44], which allows for more efficient learning and improved representation. In grouped convolution, each input channel is convolved with its own filter. The final output of the network is a set of heatmaps that contain the probability of each key's presence at each location. With $M(p) = [h^i(p)]_{i=1}^N$ and kernel convolution filter $K_{\sigma}$, we can obtain the initial heatmap $H^0$ as follows:

$$H^0 = M(p) + K_{\sigma}$$

### 3.2. Dilated Convolution Network for Shape Refinement

To enable networks to learn spatial relationships between each key point and make better guesses, they must view large portions of the input images. The portion of the input image viewed by the network is the receptive field. Using vanilla convolution [45] to achieve a large receptive field is challenging and computationally expensive due to the vast number of parameters. This problem is usually tackled by pooling layers in conventional CNNs. Pooling layers choose one pixel from the field and discard information, thereby reducing the resolution of the input image. This degrades the performance of the network because some information is lost when the resolution is decreased. Fortunately, dilated convolutions [37] solve this problem by using sparse kernels to alternate between pooling and convolutional layers, which not only affects the parameters but also increases the size of the receptive field. In practice, kernels with different dilation factors are considered, and their outputs are concatenated respectively. Recently, ResNet [18] introduced dilated convolutions in their network that can enlarge the receptive field while keeping the number of parameters low. Inspired by this design, we constructed a dilated convolution network that combined several zero-padded dilated convolutions and skip-connections to overcome the issue of scale variations. In the network, our dilation factors from $d=1$ to $d=32$ are stated below: This module was carefully designed to increase the performance of our dense prediction architecture and ensure accurate spatial information by aggregating multi-scale contextual information. Our objective was to combine intermediate feature representations to learn global-context information and improve the final heatmap predictions. We exploited convolutions to extract the global-context from feature maps and then progressively updated the initial heatmap ($H^0$). Due to the capacity to capture information at the pixel level, concatenating sub-layers enables the network to extract from different scales concurrently. We also built extra skip-connections and embedded them in our dilated convolution network to add global information from the entire image to connect with the knowledge of the previous feature map ($H_{l-1}$). Thus, our dilated skip-connection's feature map $H^{DSC}$, which has current feature map $H_l$, is defined as:

$$H^{DSC}[x,y] = \sum_{ij} k[i,j] \cdot H_l[x-i, y-j] + H_{l-1}[x,y].$$

Equation (4) shows that the model learns from each dilated convolution layer and the initial heatmap $H^0$, providing robustness against appearance changes. This is achieved through skip connections, which are extra connections between $H^0$ and dilated layers with different dilation factors $d$. Consider the output feature map for the $n^{th}$ layer, $H^n$, and a non-linear transformation $T_n(\cdot)$ of it. At each stage, the kernel $k[\cdot]$ convolves with $H^n$ and is then concatenated with $H^0$. From Table 2, the network from the initial to the final output map for a DSC subnet with 7 dilation factors can be formulated as:

$$\begin{cases} H^1 = T_1(H^0) \\ H_2 = T_2(H^0, H^1) \\ H^7 = T_7(H^0, \dots, H^6) \end{cases}$$

where $[H^0, H^n]$ denotes feature map concatenation.

Rather than having the dilated skip convolution network predicting the landmark locations from scratch in Equation (6), it is beneficial to refine the LAI subnet predictions. This was achieved by summing $H^0$ and $H^{DSC}$ to obtain the final feature map of the architecture.

$$H^l = H^0 + H^{DSC}$$

$$d_{(i+1)} = 2^i, \text{ for } i = (0, 1, 2, \dots, n-2,$$

where $d_{(i+1)}$ is the dilation factor for the $(i+1)^{th}$ layer and $n$ is the number of layers. In this case, the dilated convolution has 7 layers, optimal dilation factors $d_{(i+1)} \le 32$, for $i = (0, 1, \dots, 5)$.
