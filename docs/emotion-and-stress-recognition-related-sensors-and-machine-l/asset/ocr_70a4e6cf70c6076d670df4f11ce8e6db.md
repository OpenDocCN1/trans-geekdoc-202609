An additional advantage is the possibility of having a variable input size, in contrast with traditional, fully-connected networks which require fixed-size input. In neural networks, some of the traditional fully-connected layers are replaced with convolution layers, which scan through the input, grid-like structure to process the data in subsets, and multiply each subset by a kernel matrix (filter) to produce a feature map in output. The process resembles how individual neurons respond to visual inputs: each neuron sees a small portion of the input, its receptive field, and ignores additional information. Training a fully-connected network with the same feature recognition, and consequently, classification capabilities, would require much greater effort e.g., for an image of size 1000 × 1000, 1,000,000 weights for each neuron. In contrast, CNNs would have some trainable parameters depending on the size of the kernel, but still in a much smaller amount.

Typically, CNNs are interlaced sequences of three types of layers: the previously described convolution layers, conventional fully-connected layers and pooling layers, which aggregate multiple features into a single one, i.e., down-sampling the feature maps according to different strategies. The CNNs used in literature for reference tasks such as ImageNet classification, although varying in the number of layers, filter size and quantity, are mostly composed by the building blocks cited above.

# 3.2. CNN Settings

The experiments have been performed on four convolutional neural networks: VGG16 [32], InceptionResV2 [33], InceptionV3 [34] and Xception [35]. Among CNNs, these networks outperform Alex [28] on the widely used ImageNet [7] dataset, which is one of the largest datasets used for the transfer learning pre-training phase.

All neural networks, whose general behaviour is described in Figure 2, have been tested using transfer learning (Figure 3 shows the process for a general CNN).

Adopting transfer learning, we used the pre-trained neural networks, whose weights have been computed on the ImageNet [7] dataset. The first layers of the networks have been frozen for the transfer training phase; i.e., the weights of the convolutional layers have been frozen and have not been altered during the fine-tuning phase on the mouth emotion dataset. This was due to the high capability of the CNNs to emphas low-level features, e.g., points, lines, edges, corners and colour distribution. We replaced the final layers to fine-tune the network on emotion recognition using two dense layers with 64 neurons and a SoftMax layer. This final layer learns the likelihood of the appropriate class, returning the emotion classification. Only the final layers of the CNN networks, the fully-connected and the SoftMax level, therefore change and can be re-trained in the fine-tuning phase. The model was set up to weights only when they improve the emotion accuracy concerning the previous epoch, resulting in a final best network training configuration.

We tested optimizers: Adam and SGD. Adam performed better with InceptionV3 and VGG16 with a learning rate equal to 0.01; with Xception it had a learning rate of 0.01. SGD performed better with InceptionResV2 with a learning rate equal to 0.001, momentum = 0.9 and nesterov over to true. The remaining parameters used were the following. Batch size equal to 25 and the maximum number of epochs equal to 100; however, we used the early stopping: if results do not improve, the training is stopped.
