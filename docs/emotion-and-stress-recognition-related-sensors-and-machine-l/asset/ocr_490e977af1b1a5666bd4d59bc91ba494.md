In this paper, a mixed framework to support automatic emotion recognition is proposed. Unlike most typical subject-dependent modeling approaches, the method uses data from all users to build the model, and can be used to make predictions for unseen users in an adaptive way, increasing performance as more training data becomes available. We first show that the existence of an inherent subject-related component in the EEG signals is a major obstacle when attempting to build a independent model from EEG. Then, we propose a subject-based normalization process that is able to reduce the magnitude of this component using PSD features. This straightforward normalization process is not intended to solve the problem itself, but the reduction of the subject-dependent component in the signal is an ideal feature and problem dependent, and an optimum approach cannot be generalized at this stage. There is still room for improvement by designing normalization methods that are more efficient at this task.

The impact of the proposed method goes beyond construction of inter-subject models for emotion detection from EEG signals. First, the same principles can be exported to other sorts of information other than, e.g., physiological, audio, and video. Second, these principles are not limited to the problem of emotion recognition. On the contrary, the subject-related component is intrinsic to the signal, and it is present regardless of the problem context.
