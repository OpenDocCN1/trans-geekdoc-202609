This is because with the sequential extraction process of MHIs, each extracted image contains more motion information as the previous one, therefore concerning the actual classification task, the last MHIs are more interesting and relevant than the early images. Thus, such images should be weighted accordingly higher. The designed network is therefore capable of conducting such a task by using self attention mechanisms.
