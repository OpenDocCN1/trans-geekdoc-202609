Before the success of deep learning [9,12] for computer vision problems, [13] used a scale-invariant feature transformation (SIFT) algorithm to learn criteria for models. The algorithm iteratively refines models until the convergence is reached. Recently, recently like convolutional neural networks (CNNs) and recurrent neural networks (RNNs) have dominated the field of facial landmark detection. Deep learning models have been used to outperform SIFT methods, which used hand-crafted features, for many vision tasks. Hierarchical deep learning structures, in particular CNNs, can generate features that capture more image characteristics and learn specific features. In contrast, SIFT is not robust to non-linear transformations, where SIFT cannot match feature points. It is unsuitable for face data with large intra-class shape variations. Consequently, deep learning has attracted more attention than SIFT for computer applications. In research [15], a probabilistic deep model for facial landmark detection that captured facial shape variations by poses and expressions used. Also, [16] proposed to extract shape-independent deep features from fully convolutional networks (FCNs) and refine the landmark locations by recurrent attention-refinement (RAR) networks. In the early stage of [17]'s network employed deep methods to regress key points directly on images that are highly non-linear and difficult to estimate key points.

The research in [17] argued that learning indeed to extract extractive features from images yields more advantages over direct mapping. [17] applies an predict method based on heatmap regression on individual key points over the raw image. Furthermore, [17] mentions that adding several large convolutions (e.g., 13 × 13 kernel convolution) would improve performance, although this increases the number of parameters and makes optimizations difficult.

To address this problem, [18] proposed dilated convolutions to increase the effective receptive fields without additional parameters. However, applying heatmap regression methods in a network of large convolutional enhances the performance of our networks. We propose a end-to-end model that leverages DenseNets (FC-DenseNets) [19] that use heatmap regression to learn deep feature maps from the image. Moreover, inspired by [18], we carefully designed a network that can extract more complex dependencies by building skip-connections in the stacked dilated convolutions. In doing so, we expect that our network will obtain different sizes of receptive fields and informative feature maps, which will boost prediction accuracy.

The main contributions of this work are as follows:

+   - To the best of our knowledge, this is the first work to perform FC-DenseNets as a local detector with heatmap regression to predict dense heatmaps from the image.
- We designed a dilated skip connection (DSC) network that can refine the estimated heatmaps of the key points by combining a stack of dilated convolutions and a skip-connection method.
- We developed a robust method to estimate the initial facial shape to work in challenging conditions.
- We evaluated our framework's performance with other state-of-the-art networks on LFPW [20], HELEN [21], 300 W [22] and AFLW200-3D [23] datasets.
