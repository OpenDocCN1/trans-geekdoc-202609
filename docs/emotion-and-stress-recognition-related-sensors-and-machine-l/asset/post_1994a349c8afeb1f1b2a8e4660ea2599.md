## 5.4. Emotion Recognition Analysis

Figure 8 represents the bars to tests 3-6, with feature extraction but without feature selection and considering all data. ![](img/601340ca744b738277eef45ff127492a_104_0.png)

Figure 8. Errors results (RMSE+MAE) from tests 3-6 (with feature extraction). It is possible to see that in tests 3-6, the emotion surprised presented a higher recognition, having the smallest error level. The happy and scared emotions also presented low errors. Nevertheless, these error levels can be improved if training datasets are more coherent. The emotions sad and angry presented the worst error levels; it is probably the misclassification from face detection software which sometimes confused angry rather than sadness. If we compare all tests (from 3-34), it is possible to note again, the surprised emotion kept with best recognition (low errors), as shown in Figures 9 and 10, which presents all considered along the tests. ![](img/601340ca744b738277eef45ff127492a_105_0.png)

Figure 9. Errors results (RMSE) comparison from tests 3-34 (with feature extraction). The higher recognition errors were reached when EEG datasets were omitted in different tests (tests 15-18 and 31-34), showing in these, the recognition results were better when all data were considered; when GSR datasets were omitted, the results got good predictions to tests 11-14 and 27-30. The application of feature selection based on SVD and the omission of GSR returned less recognition errors (tests 27–30). The sad emotion got the worst error levels when HR datasets were omitted (tests 7-10), as like happy emotion got the worst error levels when EEG datasets were omitted. In summary, all tests showed that the smallest error levels can be reached when all datasets were considered or when the GSR datasets were omitted. Also, they showed that the emotion surprised is easier to expect, having a mean RMSE of 0.13 and mean MAE of 0.01; while the worst predictions were found to be emotion sad, having a mean RMSE of 0.82 and mean MAE of 0.08.

In prior, we discussed the necessity to use features in a very dense datasets. With the feature extraction, the dataset is sampled to fractions of data which it continue to represent all raw data with or equal meaning. For this reason, a featured dataset is smaller compared to its raw data. Another benefit of feature extraction is that it can bring insights from a dataset in statistical or frequency context, e.g., data variances and other tiny patterns of the frequency domain.
