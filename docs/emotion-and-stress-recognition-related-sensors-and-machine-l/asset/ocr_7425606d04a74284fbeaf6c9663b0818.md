We experimented with different schemes to prove out the effectiveness of transfer learning as well as the proposed loss function for FER tasks. In detail, we fine-tuned the transfer-learning model (e.g., ResNet-50 pre-trained with VGGF2 dataset) with different losses, such as the conventional softmax loss, center loss with softmax loss [20], weighted-softmax loss [5], center loss with weighted-softmax loss (i.e., replace softmax loss by weighted-softmax), and the proposed weighted-center loss with weighted softmax. In addition, to evaluate the effectiveness of transfer using only the AffectNet dataset with the same losses used for transfer learning-based model. In all experiments, we set the $\lambda$ value (i.e., the scale used to balance the loss) to 0.5 when using center loss, and to 1.0 when using weighted-center loss.

The pre-trained model was fine-tuned using the stochastic gradient descent algorithm with hyper-parameters (momentum=0.9, weight decay=0.0005). In detail, we fine-tuned the pre-trained CNN model using a smaller dataset (AffectNet with VGGF2) and thus, the initial learning rate was set to 0.01, which is lower than the typical value of 0.1, in order not to drastically alter the pre-trained weights. The learning rate was dropped by a factor of 2 every 10 epochs, the initial learning rate was set to 0.01, and all other settings were kept the same. All experiments except those that were trained on only the AffectNet dataset (i.e., no pre-training), were implemented using the PyTorch library and trained on a four-core Xeon CPU with a single Titan-X GPU. Batch size for the fine-tuning the learning-based models was set to 36, while the batch size for training the base models from scratch was set to 30.

To address the scale of the data-driven problem, it is necessary to conduct data augmentation. During the fine-tuning phase, input images were randomly cropped and resized to 224 × 224 pixels; the horizontal flip was randomly extracted from the cropped images. In addition, before being input into the FER model, all input samples were normalized using the ImageNet mean and standard deviation (std) (mean=[0.485, 0.456, 0.406], std =[0.229, 0.224, 0.225]), which is a common practice for deep CNN models when working with RGB images.
