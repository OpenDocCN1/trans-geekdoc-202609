# Kernel Convolution

The output of FC-DenseNet is in a channel-wise fashion that has the same resolution as the input image. After reaching the output resolution of the network, an implicit $45 \times 45$ kernel convolution $K_{\sigma}$ is applied to produce a clear shape of the feature maps. For computational efficiency, the kernel convolution $K_{\sigma}$ is generated by the Gaussian function in Equation (2). Here, the kernel convolution filter acts as a point-spread function to blur the input feature maps as shown in Figure 5. The kernel convolution filter $K_{\sigma}$ removes the noise and provides better smoothing by preserving the edges of the feature maps. Without the kernel convolution, landmarks/sub-pixel positions are neglected [43].

The kernel convolution filter evolves with the entire image using grouped convolution [44], which allows for more efficient learning and improved representation. In grouped convolution, each input channel is convolved with its own filter. The final output of the network is a set of heatmaps that contain the probability of each key point's presence at each location. With the convolved maps $M(p) = [h^i(p)]_{i=1..N}$ and a kernel convolution filter $K_{\sigma}$, we can obtain the density heatmap $H^0$ as follows:

> $H^0 = M(p) + K_{\sigma}$
