The distribution of the weight values specific to the MHI dept attention models for both databases (Figure 7a,c for the BVDB, Figure 8a,c for the SEDB) is skewed. It depicts a steady growth of weight values along the temporal axis of each sequence, with the MHIs at the end of a sequence significantly higher than the others. This is because with the sequential extraction process of MHIs, each extracted image contains more motion information as the previous one, therefore concerning the actual classification task, the last MHIs are more interesting and relevant than the early images. Thus, such images should be weighted accordingly higher. The designed network is therefore capable of conducting such a task by using self attention mechanisms.

```
Macro Precision = \frac{1}{c} \sum \frac{tP_i}{tP_i + tF_i}  (23)

Macro Recall = \frac{1}{c} \sum_{i=1}^c \frac{tP_i}{tP_i + fn_i}  (24)
```

```
Macro F1 Score = \frac{2 \times Macro Precision \times Macro Recall}{Macro Precision + Macro Recall}  (25)
```

In both cases, the performance of the weighted score aggregation approach is on par with the best performing approaches. However, it has to be noted that the authors of the best performing approaches for BVDB [8] and the SEDB [15] perform a subject-specific normalization of the extracted feature representations in order to compensate for the differences in expressiveness amongst the participants. This specific preprocessing step has proven to significantly improve the whole classification performance of the architecture [61], it is not realistic as it requires the whole testing set is available beforehand. The normal parameters should be learned on the available training material and subsequently applied to the testing material during the inference phase. Nevertheless, the proposed approach based on the weighted aggregation of the scores of both MHI and OFI-specific deep attention models generalised well and is capable of achieving state-of-the-art classifications.

# 5. Conclusions

In the current work, an approach based on a weighted aggregation of the scores of two deep attention networks, respectively, on MHIs and OFIs, has been proposed and evaluated for the analysis of pain-related facial expressions. The assessment performed on both BVDB and SEDB shows that the proposed approach is capable of achieving state-of-the-art classifications and is on par with the best performing approaches proposed in literature. Moreover, the visualisation of the weight values from the implemented attention mechanism shows that the network is capable of identifying relevant features in relation with the current level of pain elicitation depicted by a sequence of images, assigning significantly higher values the most relevant images in comparison to the weight values of irrelevant images. Furthermore, as the proposed architecture was trained from scratch in an end-to-end manner, it is better that transfer learning, in particular, for the feature embedding CNN used to generate the feature representation of each frame, could potentially improve the performance of the whole architecture.
