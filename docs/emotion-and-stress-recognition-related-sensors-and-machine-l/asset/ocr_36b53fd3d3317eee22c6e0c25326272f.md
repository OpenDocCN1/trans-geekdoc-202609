In this study, we proposed the first end-to-end deep neural network (DeepNet) to recognize stress levels using ECG and RESP. Because we needed to consider two different signals, we developed a unique network structure that could extract features from both signals. The network achieved an average accuracy of 83.9%, which is comparable to the results achieved by the other proposed models [5,12,5] as summarized in Table 5. For a further comparison, evaluating the models on a public dataset via the same training validations and evaluation method can be used.
