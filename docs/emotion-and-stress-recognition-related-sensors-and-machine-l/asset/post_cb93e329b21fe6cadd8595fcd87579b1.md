```

## 3.5. Poincaré Plots (FEAT_SD1, FEAT_SD2, FEAT_CT, FEAT_SAR)

The Poincaré plots of RR intervals is one of the methods used in Heart Rate Variability (HRV) analysis. It returns a useful visual map (or cloud), which is capable to summarize the dynamics of an entire RR time series regarding to actual and next one values. It is also a quantitative method to provide information over long- and short-term HRV [40,41].

![](img/601340ca744b738277eef45ff127492a_96_0.png)

Figure 5. Poincaré plot demonstration on the flight dataset RC2.

Mathematically, let the HRV be defined by the vector RR = [RR1, RR2, ..., RRn+1] and the position-correlated vectors x and y defined as [4|A2],

```
x = [x1, x2, ..., xn] = [RR1, RR2, ..., RR_n],
```

```
y = [y2, y3, ..., y_{n+1}] = [RR2, RR3, ..., RR_{n+1}].
```

For a regular Poincaré plot, the centroid vector Cxy = [Xc, Yc] of its representation, is defined by,

```
Xc = \frac{1}{n} \sum x_i y_i, \quad Yc = \frac{1}{n} \sum y_i.
```

To compute the centroid, the numerical representation of the vector, the vector norm is applied using the Equation (8).

```
|C_{xy}| = \sqrt{Xc^2 + Yc^2}
```

To compute the descriptors (term-short variability) SD1 and SD2 of a standard Poincaré plot, the distances d1 and d2 of any RR from the descriptor interceptors l1 and l2 are respectively defined as,

```
d1 = \frac{|(x_i - X_c) - (y_i - Y_c)|}{\sqrt{2}}, d2 = \frac{|(x_i - X_c) + (y_i - Y_c)|}{\sqrt{2}}
```

Considering these proper algebraic descriptors for a standard plot, it is possible to compute the SD1 and SD2.

```
SD1 = \sqrt{\frac{1}{n} \sum d_1^2}, SD2 = \sqrt{\frac{1}{n} \sum d_2^2}
```

The area covered by the ellipse, is also used as a feature for HR dataset, and it can be determined as,

```
SA = \pi.SD1.SD2
```

## 3.6. Singular Value Decomposition: Features Selection

When the features are extracted, some may be useless in the recognition process; to select the best of them (i.e., a dimensionality reduction), the Singular Value Decomposition (SVD) was used, executing a matrix decomposition or matrix factorization of the input matrix. It is based on eigenvalues, to a bidimensional m x n matrix A. Mathematically, this method factorizes a matrix into a product of matrices,

```
A = UDV^T
```

where D is a non diagonal matrix that carries the singular values of A; U and V are matrices that satisfy the condition U*U = I, V^T*V = I. The result of that decomposition is the new input applied into the recognition process.

## 4. Emotion Recognition

The emotion recognition uses Artificial Neural Networks (ANN) and Deep Learning techniques (DL). The techniques based on neural networks e.g., ANN, CNN, RNN, DNN, are powerful tools with their high capacity to solve complex tasks, being massively used in modern controls, dynamics data management, automatic bio-patterns identification (e.g., fingerprints or face recognition) and parallel solutions over the set of features, which each ANN layer can produce different and parallel outputs to converge on final or probabilistic outputs. It does not mean that it can be applied, combined with other techniques such as, K-Means or SVM, for example.
