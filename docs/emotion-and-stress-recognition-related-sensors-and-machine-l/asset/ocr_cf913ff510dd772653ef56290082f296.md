Rather than having the dilated skip convolution network predicting the landmark locations from scratch in Equation (6), it is beneficial to refine the LAI subnet predictions. This was achieved by summing $H^0$ and $H^{DSC}$ to obtain the final feature map of the architecture.

```
$H^l = H^0 + H^{DSC},$ (6)
```

To understand how the heatmap is regressed in a real image, we transferred back $H^0, H^{DSC}$, $H^l$ to $S^0, S^{DSC}, S^l$, Thus Equation (6) was replaced as follows:

```
$S^l = S^0 + S^{DSC},$ (6)
```

Thus, dilated convolutions offer a method to increase global view exponentially on input image, the dilation factors should be as exponential values following [35].

```
$d_{(i+1)} = 2^i$, for $i = (0, 1, 2, \dots, n-2),$ (8)
```

where $d_{(i+1)}$ the dilation factor for the $(i+1)^{th}$ layer and $n$ is the number of layers. In this case, the dilated convolution has 7 layers, optimal dilation factors $d_{(i+1)} \le 32$, for $i = (0, 1, \dots, 5)$.
