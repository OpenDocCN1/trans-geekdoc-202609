# 4.4. Feature Selection Using t-test

We used a two-sided Student's t-test with a significance level of 0.05 and results using the p-values are shown in Table 3 for different EEG oscillations. For the t-test, the degree of freedom was 9 and the null hypothesis was tested for features for stress and control groups. It is evident that at a confidence level of 0.5, none of the extracted features were found statistically significant in the stress and control group when PSS-labeling was used for the reference standard. It is also that beta and gamma waves from AF3 were statistically significant features in the stress and control group, labels acquired by experiment evaluation were used as a reference standard. Additional features, namely frontal (α1) and temporal (P1–P5) beta features, and alpha symmetry (α2), were also used (see Equations (1–5)). Results of the t-test over these features in stress and control groups are presented in Table 4. It can be seen that alpha symmetry is statistically significant between the stress and control group using experiment-based labeling. Significant features, namely beta (AF3), gamma (AF3), and alpha symmetry were selected for long-term stress classification based on results of t-test. A p-value of 0.03 and 0.04 for these features showed statistical significance. The p-value of alpha symmetry from frontal and temporal channels was 0.005, indicating the statistical significance of alpha symmetry from both temporal and frontal regions.

The box plots are presented in Figure 5, where the first row features acquired by PSS labeling including alpha, beta, and gamma respectively. The second row shows the same features acquired through experiment evaluation. A comparatively box plot suggests shows the features are in agreement with the median values. A taller box plot suggests features different distribution within methods. From box plots (Figure 5b,c,d) it is observed that there is no difference in the beta and relative gamma features to differentiate stress and control groups for expert- and PSS-based labels. However, Figure 5d are candidates for good features as they appear to differentiate the stress and control group. In Figure 5a, the alpha symmetry for the stressed group does not have a longer whisker, which shows alpha symmetry is not varied along the negative quantile, while in Figure 5d, the stressed group had varied alpha symmetry as shown by the lower and upper whiskers. Also, in Figure 5d the median is comparatively at the center of the distribution. This suggests that alpha symmetry is a good candidate to be used in the stress classification task.
