The ML techniques used in this work include KNN, SVM, and RF. While SVM is known to have a generalization ability by mapping inputs non-linearly to higher dimensional feature spaces through its capability of separating data with a hyperplane. kNN, a type of instance-based learning, involves the neighbors within the class (among k classes) a specific data point belongs to. Closest neighbors are assigned using methods such as Euclidean or Hamming distance. RF is a collection of selection decision trees which do not need linear features or features that interact linearly. These three classification algorithms are known to perform well for high-dimensional spaces as well as a large number of training samples. Each of these algorithms works under specific circumstances, KNN for noisy data, SVM for linearly inseparable data, and RF for categorical features. Due to specific features, chose to use these methods. All techniques have been widely used in the literature, as discussed in Section 2.
