# 2. Related Works

Facial landmark detection is divided into three types of global model: holistic, constrained local model (CLM) and regression-based. Holistic methods build a global model to learn the facial appearance and obtain shape information during training to estimate the best fits of any given test face image via the model parameters. CLM methods use independent local appearance information around each landmark with a global face shape for facial landmark detection, outperforming holistic methods for capturing illumination and occlusion. Unlike the first two methods, which build a global shape model, regression-based methods directly map the facial appearance and regress the landmark locations between individual inputs and outputs.



Regression based methods have recently demonstrated outstanding performance compared with holistic and CLM methods. Regression based methods effectively build a parametric space or approach model to extract feature maps from an image and infer a shape. Regression functions focus on holistic picture details, subsequently updating these features using finer image details to provide more accurate predictions. Using typical approaches, [5,11] proposed a regression function to predict landmark coordinates from shape feature maps from the input. Subsequently, [24] proposed a combined regression network to initially detect facial landmarks and refine landmark locations using progressively finer details; [25] proposed a cascade autoencoder network to produce finer images from low resolution input images; [26] proposed multiple regressions to learn discriminative features from each facial landmark. Extending this work, [27] proposed a two-step facial segmentation to estimate head pose, gender and expression. The system first segmented faces into small regions for hair, skin, eyes, mouth and so forth; then classified these regions using support vector machines (SVMs). The [27] process is effectively an extended version of the FACSEG dataset [3] represented images in the spatial domain with high time-frequency resolution. Then they extracted useful feature maps from the decomposed image and employed supervised learning to extract features to classify expressions in the images. Ref [3] applied stationary wavelet entropy to extract features in the frequency domain followed by a single layer feedforward network using the Java algorithm, a gradient-free optimizer. Similarly, [4] proposed bidirectional wavelet to extract multi-scale information and fuzzy SVM classifiers. Heatmap regression was used to estimate human pose; [29,30] and detect facial landmarks; [8–10]. Ref [29] employed multiple regressions to predict human poses. The regressor crops the input to focus only on the human, requiring computational resources for background accuracy. They then used regression to roughly estimate point locations and their joints connected independently and respectively. This only reduces the number of parameters but also increases accuracy since there is no information loss compared with using pooling layers to reduce data size. Ref [30] proposed a stacked hourglass network to capture information from local to global scale and enable the network to learn shape relationships between joints. Similarly, [8] cascaded four hourglass networks in networks regression to extract discriminative features from images, which were subsequently used to detect facial landmarks. Ref [9] proposed a three step regression network based on convolutional response maps and component based models to robustly detect facial landmarks. Ref [10] proposed combining heatmap and coordination contextual information into a feature representation that was subsequently refined by an arbitrary convolutional neural network (CNN) model.
