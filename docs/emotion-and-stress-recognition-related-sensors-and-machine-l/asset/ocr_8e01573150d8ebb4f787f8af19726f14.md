motion history at that specific point. A MHI $H_{	au}$ is computed using an update function $\Psi(x, y, t)$, and is defined as follows,

```
$H_{	au}(x, y, t) = \begin{cases} \text{if } \Psi(x, y, t) = 1 & \max(0, H_{	au}(x, y, t-1) - \delta) \ \text{otherwise} & \end{cases}$
```

where $(x, y)$ represents the pixel's location, $t$ the temporal extent of the observed motion (a length of a sequence of images); $\Psi(x, y, t)$ is 1 of motion at the location $(x, y)$ and at the time $t$; and $\delta$ represents a decay parameter. The update function is defined as follows,

```
$\Psi(x, y, t) = \begin{cases} 1 & \text{if } D(x, y, t) \geq \zeta \ \text{otherwise} & \end{cases}$
```

where $\zeta$ is a threshold; $D(x, y, t)$ represents the absolute value of pixel intensity values of consecutive frames and is defined as follows,

```
$D(x, y, t) = |I(x, y, t) - I(x, y, t \pm \Delta t)|$
```

where $I(x, y, t)$ represents the pixel intensity at the location $(x, y)$ and at the time $t$; $\Delta t$ represents the temporal distance between the frames.

Therefore, the computation of a MHI consists of first performing image difference $[49]$ on a specific, preceding frame of movement (depending on the value assigned to the threshold $\zeta$ based on Equation (2). Equation (1) is used to assign pixel values to the MHI. If a motion has been detected at the location $(x, y)$ of the $t$th frame, a pixel value of $t$ is assigned to that location. Otherwise, the previous value of location is reduced by $\delta$, thereby indicating the temporal occurrence of the motion at that specific location, and the actual time $t$. This process is conducted iteratively until the entire sequence of images has been processed. History of motion is encoded into the resulting MHI. Therefore, a sequence of images is encoded into a single MHI. However, in the current work, a sequence of MHIs is generated from each single sequence by saving each MHI generated at each single step of the iterative process described earlier. The resulting sequence of images is used as input for the deep neural neural networks.
