We utilized the Adam optimizer [28] to update the trainable variables of the last stages and softmax classifier through backpropagation, but the variables in the other stages were kept constant:

> $W^{(N)} \leftarrow W^{(N)} - \alpha; m_i / (\sqrt{v_i} + \epsilon), \quad N = 8, 9$

where $m$ and $v$ denote the first and second moment of the Adam optimizer, respectively. We used a different learning rate ($\alpha$), which started at $10^{-4}$ with the same decay rate (decreasing by a factor of 10 every 5 epochs), to train. As the pretrained model was already fine-tuned, it was better to use a lower learning rate. The results of three training types and comparisons between them are shown in Section 3.

# 2.5. Model Evaluation

In this section, we describe how to evaluate the proposed model. We performed training with testing using cross-validation. We tested each end-to-end model with its test set and calculated the evaluation metrics (., the receiving characteristic curves). Additionally, we observed the features not at the end of the neural network, but also in the middle stages. The T-distributed stochastic neighbor embedding (t-SNE) [30] makes high-dimensional features visible in two- or three-dimensional manifold.

# 2.5.1. Cross-Validation

We used k-fold cross-validation ($k = 10$) to evaluate the proposed model. Both the mental and arithmetic data sets were subject by cross-validation. The DNN should not have seen data in the test set during training. It is obvious that a neural network achieves a high performance if we divide the data set into both training set and a test set, and perform training and testing based on each individually. In the case of physiological signals, it is difficult to gather satisfactory amount of data to train a neural network. There are several limitations in laboratory environment, such as the portability of the sensors and the inconvenience of the person to be measured. However, cross-validation makes it possible to do both the training and testing only with a small amount of data. We randomly split the data set into individuals that make $k$ folds cross-validation. Each fold contains one of subject or one subject. We trained the models with $k-1$ folds and assessed them with the left fold. The training and test sets had a 9:1 ratio. All processes were iterated $k$ times with the individual end-to-end models, which produced $k$ models. Therefore, each model was trained by an individual training set and also validated by a test set which had never seen during training. All of the three training types were evaluated with the data set which was included in the data set used during the training session, but the model never saw it. For example, the Type I model was trained and tested with the driving data set. In the case of Type III, although the pretrained model was based on the driving data set, the mental arithmetic data set was used for evaluation. All evaluation metrics were cross-validated using the mean values of all the folds.

All training and validation was performed on a personal computer (CPU; AMD Ryzen 2700X, GPU; NVIDIA GeForce GTX 1080 Ti 11 Gb, Memory; 32 Gb). With the use of GPU, it took less than and two seconds per epoch for training the model with the driving and mental arithmetic data sets, respectively.
