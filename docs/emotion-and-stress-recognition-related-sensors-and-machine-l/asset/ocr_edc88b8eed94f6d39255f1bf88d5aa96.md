logistic regression. Researchers can identify interacting factors, such as sensor features, in-vehicle temperature, and a driver's attention to the main control as features.

Obtained results can be used for practical application. Examples of such uses are sensors for monitoring the autonomic nervous system, smartphone/computer applications and wearable wireless devices with EDA sensors.
