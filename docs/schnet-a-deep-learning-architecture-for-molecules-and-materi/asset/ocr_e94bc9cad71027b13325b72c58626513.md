# B. Atom-wise layers

Atom-wise layers are dense layers that apply separately to the representations $x_i$ of each atom

```
$x_i^{(l+1)} = W^l x_i + b,$
```

Since W and biases $b$ are shared across atoms, our architecture remains scalable with respect to the number of atoms. While the atoms are represented through the network, they transform them and process information about the atomic environments incorporated through interaction layers.

# C. Interaction layers

The interaction layers of SchNet refine the atom representation based on pairwise interactions with the surrounding atoms. Here we model this with continuous-filter convolution layers (which are generalizations of the continuous convolution operation, e.g., Gaussians$^{27}$ or radial basis functions). This is necessary because atoms are not located on regular-grid pixels, but can be located at arbitrary positions. Therefore, using a filter-tensor, as in conventional convolutional layers, is not applicable. We need to model the filters using atom-wise representations $x_i$ at positions $R$, we model the interactions of the atom with all surrounding atoms

```
$x_i^{(l)} = (x_i^{(l)} * W^{(l)}) = \sum_{j \in \mathcal{N}(i)} O^{(l)}(r_i - r_j),$
```

where '$$' denotes the element-wise multiplication. Now we perform filter-wise convolutions for computational efficiency. Cross-feature processing is subsequently performed by atom-wise layers, thus instead of a filter tensor, we use a filter-generating network $x ightarrow W$ that maps the atoms to the corresponding value of the filter bank (see Sec.
