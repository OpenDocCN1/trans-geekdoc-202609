# F. Training

We train SchNet for each property target P by minimizing the squared loss

```
$$\ell(P, P) = ||P - P\|^2$$
```

For the training of energies and forces of molecular trajectories, we use the

```
$$\ell((E, F_1, ..., F_n), (\hat{E}, \hat{F}_n)) = \rho ||E - \hat{E}||^2 + \frac{1-\rho}{N_{atoms}} \sum ||F_i - \hat{F}_i||^2 \quad (5)$
```

where rho is a trade off between energy and force loss. All models are trained with mini-batch stochastic descent using the ADAM optimizer with mini-batches of 32. We decay the learning rate exponentially with ratio of 0.996 every 100 epochs. In each experiment, we split the data into a training set of given size N and use a validation set for early stopping. We determine the maximum number of atoms being located within a given cutoff cost of a training step scales linearly with the system size since we preprocess the indices of nearby atoms.
