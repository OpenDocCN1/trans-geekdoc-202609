# 1. Rotational invariance

It is straightforward to include rotational invariance by computing pairwise distances using of relative positions. We expand the distance in a basis of Gaussians

```
$e_k(r_i, r_j) = \exp(-\gamma(||r_i - r_j|| - \mu_{ij})^2)$
```

with cepts, centered on a uniform grid from the neighbor and the distance cutoff. This has the effect of decorrelating the filter values, which improves the conditioning of the optimization problem. The number of Gaussians and the hyper parameter determine the resolution of the filter. We set the grid spacing and scaling parameter to be 0.1 $1/	ext{\AA}^2$ for all models in this work.

# 2. Periodic boundary conditions

For atomic with periodic boundary conditions (PBCs), each atom feature vector $x_i$ is equivalent across all periodic positions, i.e., $x_i = x_{i+R}$. Due to the linearity of the convolution, we therefore apply the PBCs to the filter to accurately describe the atomic interactions while keeping the invariance to the choice of the unit. Given a filter $W^{(l)}(r_{ij}-r_{ij})$ over we obtain the convolution

```
$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot W^{(l)}(r_{ij}-r_{ij})$\n\n$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot (W^{(l)}(r_{ij}-r_{ij}))$,
```

This filter $W$ now depends on the PBCs of the system as we sum over all periods within the given cutoff

Finally, a property $P$ of a molecule or material is derived from the obtained atomic-wave representations. We use the fully connected prediction network (see in Fig. 1). Depending on whether the property is intensive or extensive, we calculate the final prediction $P$ by summing or averaging over the atomic contributions, respectively.

Since the internal atom embeddings are equivariant to rotation of atoms, the filters are independently applied to each atom and through continuous-filters convolution over all neighboring atoms, indexing equivariance is retained in the atomic-representations. Therefore, the prediction of properties as over-atom weights guarantees invariance.

When predicting atomic forces, we use a SchNet predicting the energy with respect to the atomic positions

```
$\hat{E}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn}) = \frac{\partial \hat{E}}{\partial r_i}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn})$
```

When using a rotationally invariant model, this ensures rotationally equivariant force predictions and guarantees an energy conserving field.$^{21}$
