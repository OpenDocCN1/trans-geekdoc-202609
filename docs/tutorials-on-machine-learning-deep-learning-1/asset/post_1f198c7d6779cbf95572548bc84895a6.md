## 2.2.5 Dummy variable trap

Why you should never include all of your dummy variable columns

- Multicollinearity: Intuition here that you're basically duplicating a variable. This is $D_2 = 1 - D_1$.
- The phenomenon where one or several independent variables in a linear regression predict another is called COLLINEARITY. As a result of this model cannot distinguish between the effects of $D_1$ from the effects of $D_2$. It doesn't work properly. And it is the Dummy Trap.
- If you do the math behind this you will see that the real problem is that you cannot have elements in the same time the constant $b_0$ and the dummy variables $b_4D_1, b_5D_2$.

## What is the p-value?

- Does the size of a state affect population density? The **null hypothesis** is "all states have the same population density."
- Do cats prefer fish or milk? The null hypothesis is "cats have no preference; they like them."

**P-value:** The P-value is the probability that the parameters associated to your independent variables have certain nonzero values, given that the null hypothesis is True. The most important thing to keep in mind about the P-value is that it is a statistical metric: the lower is the P-value, the more statistically significant is an independent variable, and the better the **predictor** it will be.

The smaller the p-value, the stronger the evidence that you should reject the null hypothesis. A p-value less than 0.05 (typically used as a threshold) is statistically significant. It indicates strong evidence against the null hypothesis, as there is less than a 5% probability that the **null is correct** [and the results are]

- The first step in backward elimination is pretty simple, you just select a **significance level**, or select the p-value. Usually, in most cases, a 5% significance level **is selected**. This means the P-value will be of 0.05.

P is a statistical measure that helps determine whether or not your hypotheses are correct. Usually, if the P value of a data set is lower than alpha (like, for instance, 0.05), scientists will reject the "null hypothesis".

The p-value is actually the probability of getting a sample like ours, more extreme than ours IF the null hypothesis is true. So, we assume the null hypothesis is true and then determine **how "strong" our sample really is**. If it is not strange (a large p-value) then we don't change our mind about the null.

> Important:

Pr (observation | hypothesis) ∝ Pr (hypothesis | observation)
The probability of observing a result that is strong is not equal to the probability that a hypothesis is true given some result.
Using the p-value as a "score" is committing an egregious logical error: the **transposed conditional fallacy**.
