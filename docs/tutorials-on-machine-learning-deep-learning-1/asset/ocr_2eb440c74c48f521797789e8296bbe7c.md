# 12.3. Building the RNN: output layer, compile & fit

**output-layer**: for an output we are not adding an LSTM layer, but a fully connected layer (similar to CNN). The output layer is a fully connected to the previous (4th-layer) LSTM layer.

+   - To make a connection we need to use the Dense class exactly as we did for ANN and CNN.

```
# The outputLayer
regressor_nn.add(Dense(units = 1))
```

We specified **units = 1** because we are defining a real value corresponding to the stock price, i.e. the output has only one dimension. So there be one neuron in **output-layer**. This will output our stock price, at time **T +1**

Now we're done with architecture of our super LSTM RNN.

+   - **Compiling the RNN**: Our optimizer will be 'adam' and the loss-function will be the mean_squared_error because we're some region.

+   - We use the **compile()** method, it is another method of the **Sequential** class.

```
# Compiling the Model
regressor_nn.compile(optimizer='adam', loss='mean_squared_error')
```

**optimizer**: For RNN **rmsprop** is recommended some kind of SGD optimizer that usually a good choice for **RNN**.

+   - rmsprop, with our implementation we're not using a rmsprop, here we use the **adam optimizer**.

+   - The adam optimizer is always a safe choice for SGD. It's always a **good choice** because it is very powerful and it always performs some updates of the **weights**.

**Loss**: we don't use cross-entropy. So the loss is not gonna be **binary_crossentropy** or **categorical_crossentropy**

+   - We're dealing with a regression problem because we have to predict a continuous value and the loss for this of problem is the **mean_squared_error**.

+   - So that the error can be measured by the mean of the squared differences between the predictions and the **targets**. **Targets** means real values.

+   - Mean error, sometimes called MSE.

Now our regressor is compiled with a powerful optimizer 'adam' and the right function **mean_squared_error**.

Fit/train the RNN to our training set: Notice we do not use **training_set** or **train_set**. Our training is composed of **X_train**, the data structure that is expected by the neural networks.

+   - So we need to train **X_train** and **training_set, train_set**.

We need to specify the **output=y_train**, when fitting the regressor to our training sets the output contains the ground truth that is stock at time **T +1**

+   - We're training the **RNN** on the true stock price at time **T +1**, the 60 previous stock days during the **60 previous financial days**. So we also need to include the ground truth(dependent-variable) and therefore **y_train**.

It is the final part of two, building the RNN Here to train, **X_train**, and **y_train**. The training will happen in this part and we'll have a robust **RNN** but mostly, we will have one smart RNN: Ours will be intelligent, neural network, be able to predict some, the upward trends, and downward trends of the Google stock price.

We need four inputs, which are going to be: Feature/independent **X_train**, output/dependent **y_train**, no. of **epochs** and **batch_size** for the

+   - X_train: The independent variables of the training set. Which will be the input of the neural network and will be be forward propagated to the output, which will be the **prediction** and will compare to the ground truth that is contained in **y_train**.

+   - y_train: Are you the real values for predictions, it is dependent.
- **number of epochs**: That is how many iterations you want your RNN to train. How many times will the whole data to be forward passed inside the NN and back propagated to update the weight.

+   - What is the best number?: You have to test it several times. For example:
- I tried with 25 epochs and noticed that there was no **convergence** of the loss.
