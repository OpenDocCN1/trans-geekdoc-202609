What is the bag of words model and why do we need to create it? By understanding why we need to create the bag of words model you understand even how we had to clean the text/1000 reviews cleaning The Texts but also creating a Corpus.

+   Basically the first big step is creating the bag of model

Now from here we will create our bag of words.
The bag words model really simple. We are going to take all the different words of the 1000 reviews here but without taking twice or times (duplicates or duplicated is, the unique words of 1000 reviews). We will create a table for each review which will be of columns.
Then we will put all columns in a table where the rows are not less than the 1000.

+   So basically what we'll get is a table containing 1000 rows where the rows correspond to the reviews and a list of columns where each column corresponds to each different words in the corpus of the reviews.
Each cell of this table corresponds to one specific review and one specific word of this. And in this we're going to have a number which represents the number of times the word corresponds to the appears in the review
So if a word appear in review we place a 1, and for all of the rest we place 0 in the rows. In each row(review) of the table most have 0 and a few 1s.

+   Sparse Matrix: This is actually a table, and it is called sparse matrix. In numerical analysis and scientific computing, a sparse matrix or sparse array is that which a very common name in machine learning. We are using a sparse matrix in which most of the elements are zero.

+   And that we have a lot of it is called sparsity and that's why we use sparsity. The bag of words model is basically to simply simplify the reviews, clean all the reviews to simplify the words and trying to reduce sparsity as much as possible when we work with ML.

+   Creating This matrix is actually the bags of words model. Tokenization: It is also about creating the sparse matrix through tokenization. Tokenization is the process of taking all the different words of the review and creating one column for each of these words (which we discussed).
