# 11.1.3 Grid-Search : Improve models performance

In the previous section we used K-cross-validation to evaluate our model performance. In this section we're going to learn Grid-Search which is used to improve models performance.

We'll improve our model by finding the optimal values of the hyper parameters, the parameters that we choose.

+   * This Grid-Search technique will help us to choose appropriate hyper parameters for our model and tune to the optimal value.

How do I know which model to choose for my machine learning problem? I have a learning learning problem with specific dataset, how do I know which model to choose to solve my business problem? Which model would be the best one?

+   * Step: Figure out, if it is a regression problem or a classification problem or a clustering problem.
* You just need to look at your dependent variable.
* If you don't have a dependent variable then it's a clustering problem.
* If you have a dependent variable then see if it's a continuous outcome or a categorical outcome.
* If it's a continuous outcome then your problem is a Regression problem.
* If it's a categorical outcome then your problem is a Classification problem.

+   * Step 2: Find out your problem is linear model or nonlinear model.
* When you have a large data set you cannot fit the linearity of your dataset easily. For large data-set you have to try this situation, choose a linear model like SVM or a non-linear model like kernel-SVM(if you're doing classification).
* In this situation where we have large-dataset we can get help from Grid search. Grid search will tell us if we should choose a linear model like SVM or a non-linear model like kernel-SVM.

Specifying the different parameters to use for Grid Search: Hyper parameter tuning, we need to insert Hyper-parameters from a list of dictionary. So we created this dictionary of parameters. We name this dictionary of parameters as params_dict.

+   * When we built our model only used 2 parameters: clf=SVC(kernel="rbf", random_state=0)

+   * But there are other parameters that we didn't specify, and used their default values. For example: penalty degree (in case of polynomial), gamma.

+   * We say to tune C, c gamma, 3 hyper-parameters. We created dictionaries "key-value" pair, Parameter-name as key and list of values that we want to set for tuning value of the value. These values will be tested by the grid search and we will find the best one.

```
# Grid-Search to find the "best model" and "Best hyper-parameters"---
from sklearn.model_selection import GridSearchCV
params_dict = {
  'C': [1, 10, 100, 1000], 'kernel': ['linear'],
  'C': [1, 10, 100, 1000], 'kernel': ['rbf'], 'gamma': [0.7, 0.5, 0.1, 0.01, 0.001, 0.0001]
}
```

+   * This penalty is for regularization to prevent overfitting, the default value is 1. We tune this for our model to prevent overfitting.

+   * The more you increase this penalty C the model will prevent overfitting. But be careful not to increase it too much otherwise you will get a new problem which will be Underfitting. For example 10000 will be too much for penalty.
