Since conditional independence of random variables and the properties of the joint probability distribution are closely related, one can ask if there exists a general factorization form of the distributions of MRFs. An answer to this question is to refer to the *Hammerley-Clifford Theorem* (for rigorous formulations and proofs we refer to [23:22]). The theorem states that a strictly positive distribution $p$ satisfies the Markov property w.r.t. an undirected graph $G$ if and only if $p$ factorizes over $G$. A distribution is to factorize about an undirected graph $G$ with maximal cliques $c$ if there exists a set of non-negative functions $\{\psi_c\}_{c}$, *potential functions*,

$v_x, \hat{x} \in \mathcal{V}^c; (v_x)_c = (\hat{x})_c = \psi_c(v_x) \Rightarrow \psi_c(\hat{x})$

and

$p(x) = \frac{1}{Z} \prod_{c \in \mathcal{C}} \psi_c(v_c)$

The normalization constant $Z = \sum_{c \in \mathcal{C}} \psi_c(v_c)$ is *partition function*. If $p$ is strictly positive, the same holds for the potential functions. Thus we write

$p(x) = \frac{1}{Z} \prod_{c \in \mathcal{C}} \psi_c(v_c) = \frac{1}{Z} e^{-E(x)}$

where we call $E := \sum_{c \in \mathcal{C}} \phi(v_c)$ the *energy function*. Thus, the probability distribution of every MRF can be expressed in the form given by (3), which is also called *Gibbs distribution*.

## 2.2 Unsupervised learning

Unsupervised learning means learning (interesting aspects of) an unknown distribution $q$ based on sample data. This includes finding new representations of data that foster learning, generalization, and communication. If we assume that the structure of the graphical model is known and the energy function belongs to a known family of functions parameterized by $\theta$, unsupervised learning of a distribution with an MRF means adjusting the parameters $\theta$. We write $p(\theta)$ when we emphasize the likelihood of a distribution on its parameters.

We consider training data $S = \{x_1, \dots, x_n\}$. The data samples are assumed to be independent and identically distributed (i.i.d.). That is, they are drawn from some unknown distribution $q$. A standard way of estimating the parameters of a statistical model is maximum-likelihood estimation. Applied to MRFs, this corresponds to finding the MRF parameters that maximize the probability of $S$ under the MRF distribution, i.e. training corresponds to finding the parameters $\theta$ that maximize the likelihood given the training data. The likelihood $\mathcal{L} : \Theta \rightarrow \mathbb{R}$ of an MRF given the data set $S$ maps parameters $\theta$ from a parameter space $\Theta$ to $\mathcal{L}(S) = \prod p(x_i|\boldsymbol{\theta})$. Maximizing the likelihood is the same as maximizing the log-likelihood given

$$\ln \mathcal{L}(S) = \sum_{i=1}^{\ell} \ln p(x_i|\boldsymbol{\theta}) . \quad (4)$$

For the Gibbs distribution of an MRF it is in general not possible to find the maximum likelihood parameters analytically. Thus, numerical approximation methods have to be used, for example gradient ascent which is described below.

Maximizing the likelihood corresponds to minimizing the distance between the unknown $q$ and the distribution $p$ of the MRF in terms of the Kullback-Leibler-divergence (KL-divergence), which for a finite state space $\Theta$ is given by:

$$\mathcal{KL}(q||p) = \sum_{x \in \Theta} q(x) \ln \frac{q(x)}{p(x)} = \sum_{x \in \Theta} q(x) \ln q(x) - \sum_{x \in \Theta} q(x) \ln p(x) \quad (5)$$

The KL-divergence is a (non-symmetric) measure of the difference between two distributions. It is always positive and zero if the distributions are the same. By equation (5) the KL-divergence can be expressed as the difference between the entropy of $q$ and a second term. Only the latter depends on the parameters of $p$. Approximating the expectation over $q$ in this term by the training samples from $q$ results in the log-likelihood. Therefore, maximizing the log-likelihood corresponds to minimizing the KL-divergence.

**Optimization by Gradient Ascent.** it is not possible to find parameters maximizing the likelihood analytically, the usual way to find them is gradient ascent on the log-likelihood. This corresponds to iteratively updating the parameters $\boldsymbol{\theta}^{(t)}$ to $\boldsymbol{\theta}^{(t+1)}$ based on the gradient of the log-likelihood. Let us consider the following update:

$$\boldsymbol{\theta}^{(t+1)} = \boldsymbol{\theta}^{(t)} + \eta \frac{\partial \ln \mathcal{L}(S)}{\partial\theta} = \eta \sum_{i=1}^{\ell} \frac{\partial \ln p(x_i|\boldsymbol{\theta})}{\partial\theta} - \lambda \boldsymbol{\theta}^{(t)} \quad (6)$$

If the constants $\lambda \in \mathbb{R}^+$ and $\nu \in \mathbb{R}^+$ are set, we have gradient ascent. The step $\eta \in \mathbb{R}^+$ is the learning rate. As we will see, it can be desirable for models with large values. To achieve this, we can optimize an objective function consisting of the log-likelihood minus the norm $||\theta\|^2/2$ weighted by $\lambda$. This method called weight decay penalizes weights. In a Bayesian framework, weight decay can be interpreted as a Gaussian prior on the parameters. The update rule can be further extended by a momentum term. Using momentum term helps avoid oscillations and can speed the learning process.

**Introducing Latent Variables.** Suppose we want to model an $m$-dimensional unknown probability distribution (e.g., each component of a sample). Typically, all latent variables $X=(X_{ij})$ in MRF need to be observed, and the number of variables is larger than $m$. We split $X$ into *visible* (observed) variables $V=(V_1, ..., V_n)$ corresponding to the observations and *latent* (hidden) variables $H=(H_1, ..., H_m)$ where $n=|V|$. Latent variables allow us to describe complex distributions over the visible variables by means of simple (conditional) distributions. In this case the Gibbs distribution of MRF represents the joint probability of $(V, H)$ and one is interested in the marginal distribution of $V$ which is given

$p(v) = \sum_h p(v,h) = \sum_h e^{-E(v,h)}$

where $Z = \sum_h e^{-E(v,h)}$. While the visible variables correspond to the components of an observation, the latent variables introduce dependencies between the visible variables (e.g., pixels of input image).
