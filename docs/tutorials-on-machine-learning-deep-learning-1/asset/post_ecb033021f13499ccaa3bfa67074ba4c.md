
Here we'll explain what's going on this random walk.

Basically, Gibbs sampling consists of Gibbs chain. There are several round trips from the visible nodes to the hidden nodes, from the hidden nodes to the visible nodes.

In each round trip of our input Gibbs sampling, the visible nodes are updated, and step by step, we get closer to our good predicted ratings.

At the beginning we start with our input batch of observations. That is, our input ratings in v_0, in our batch of 100 users.

Sampling Hidden Nodes: In the first step of Gibbs sampling, using Bernoulli sampling using our $p\_h\_given$ distribution from sample\_h() function.

- The first step of k-steps contrastive divergence is to sample\_h(vk) on the visible nodes, to get the first sampling of the hidden nodes.

Since we want to get this second element returned by sample\_h(vk), and then, we use the python trick '_' as we did before.

In this time, we are going to use an underscore '\_' and then the hidden nodes obtained at the k-th step of contrastive divergence.

```python
vk = rbm.sample_h(vk)
# sampling hidden nodes
```

Since we are doing the sampling of the first hidden nodes, given the values of the first visible nodes, that is our original ratings, the first input for sample\_h(vk) in this step of Gibbs sampling is not to change. We so have to take this, because the first step v_0 = vk so our output of observations, and then we will be updated.

- Get our first update of the visible nodes after the first sampling.

Sampling Visible Nodes: We'll update vk after we update it with the following function which is sample\_v(vk).

So now right vk = v_0, but in then we update vk to the first step of Gibbs sampling, i.e after getting it.

We'll get it Bernoulli sampling our $p\_v\_given$ distribution from sample\_v(vk) on the first sample of our hidden nodes.

Again we get this second element returned by sample\_v(vk), we use the python trick under underscore '\'.

```python
vk = rbm.sample_v(vk)
# sampling visible nodes
```

- Get our first update of the visible nodes after the first sampling.

That's the first of our random walk, that is the first step of Gibbs sampling.

```python
for k in range(10):
    _vk = rbm.sample_h(vk)
    # sampling hidden nodes
    _vk = rbm.sample_v(vk)
    # sampling visible nodes
```

So as the loop continues hk and vk update themselves repeatedly.

### Algorithm 1. RBM contrastive divergence
Input: RBM ($V_1, ..., V_m, H_1, ..., H_m$), training batch S
Output: gradient approximation $\Delta w_{ij}, \Delta b_j$ and $\Delta v_i$ for $i=1, ..., n, j=1, ..., m$
init $\Delta w_{ij} = \Delta b_j = \Delta v_i = 0$ for $i=1, ..., n, j=1, ..., m$
for the $v$ in $S$
    $v^{(0)} \leftarrow v$
    for $t=0, ..., k-1$
        for $i=1, ..., n$ do sample $h_i^{(t)} \sim p(h_i | v^{(t)})$
            for $j=1, ..., m$ do sample $v_j^{(t+1)} \sim p(v_j | h^{(t)})$
        for $i=1, ..., n, j=1, ..., m$ do
            $\Delta w_{ij} \leftarrow \Delta w_{ij} + p(h_i | v^{(t)}) \cdot v_j^{(t)} - p(H_i=1 | v^{(k)}) \cdot v_j^{(k)}$
            $\Delta b_j \leftarrow \Delta b_j + v_j^{(t)} - v_j^{(k)}$
            $\Delta v_i \leftarrow \Delta v_i + p(H_i=1 | v^{(0)}) - p(H_i=1 | v^{(k)})$

In the end of the loop, we'll get the 10th sample of hidden nodes and the 10th sample of visible nodes.

Getting $h_k$ and $v_k$ after the last step of the random walk, we can now approximate the gradients by 8th, 9th, and 10th steps of k-Contrastive-divergence algorithm.

What we observed is step 5 & 6 of k-Contrastive-divergence algorithm.

We want to get the last sample after the last step of the random walk, the last sample of hidden nodes and the last sample of visible nodes.

We need those last samples to update the weight and the bias to approximate the gradient.

Actually here the last sample of visible nodes:

- But we don't only use the last sample of hidden nodes, which was just to get the last sample of visible nodes.
- We got out $v_k$: we can now approximate the gradient to the weights and the bias.
- We use train() to update the weights and bias, from our RBM class.

Ignoring unwanted during weight update: Before we use this function to update the weight, we need to do something important:

- We don't want to update cells which have no rating, that is cells -1.
- We'll ignore cells that contain -1 in the training process.
- We are going to freeze these visible nodes so that it isn't possible to update them during Gibbs sampling.

How can we freeze these visible nodes containing -1? We need to take $v_k$ visible nodes, and inside the for-loop:

```python
for k in range(10):
    _hk = rbm.sample_h(vk) # sampling hidden nodes
    vk = rbm.sample_v(vk) # sampling visible nodes
    vk[<0] = v_0[<0]
```

That is, we use $v_0$ to keep $vk$ away from updating. $vk[<0]$ gets the nodes that have -1 rating, that were not originally rated. We use $v_0$ because it is not updated. Ratings are either -1 or 1.

By doing this, we make sure the training is not on ratings that were not actually rated.

So now we get out of this loop and soon enough will start the training.

### 14.5.4 Training the RBM-model - part 3: train()

$ph_k$: We want to apply the train() function to update the weight and bias. But notice that in this train() function, we need:

```python
def train(self, v0, ph0, phk):
```

i. target, $v_0$
ii. our sampled visible nodes at the last step of the random walk, $vk$.
iii. The initial probabilities, $ph_0$.
iv. k-step probabilities, $ph_k$.

Notice, we have $ph_k$: it wasn't calculated at the start. So before applying the train() function we compute $ph_k$.

We get the first element returned by sample\_h(). We apply sample\_h() on $vk$, the last sample of visible nodes (which we got from the end of the for-loop), the last visible nodes at the 10th step of the random walk, Gibbs sampling.

```python
ph_k = rbm.sample_h(vk) # probabilities after k-step
```

Now we are ready to apply the train() function.

- train(): Now let's apply the train() function. It's going to be stuff.
- Note that, the train() function doesn't return anything. It updates the weights according to steps 8, 9 and 10 of k-step-Contrastive-divergence algorithm.
- So we don't need any new variable it doesn't return anything.
- We use our object of RBM class and apply train(), using $v_0, vk$ and $ph_k$ values for our arguments.

```python
# Creating RBM model
v = len(train_tensor[0])
h = 100
batch_size = 100

m = RBM(nv, nh)

# Training the RBM
for epoch in range(1, nb_epoch + 1):
    s = 0
    for u_id in range(0, nb_users - batch_size, batch_size): # input vector
        vk = train_tensor[u_id:u_id + batch_size] # target vector
        v0 = train_tensor[u_id:u_id + batch_size]

        ph_0 = rbm.sample_h(v0) # initial probabilities
        # applying k-step contrastive divergence
        for k in range(10):
            _hk = rbm.sample_h(vk) # sampling hidden nodes
            _vk = rbm.sample_v(_hk) # sampling visible nodes
            vk[<0] = v0[<0] # preventing updates to unrated nodes

        ph_k = rbm.sample_h(vk) # probabilities after k-step
        rbm.train(v0, vk, ph_0, ph_k) # train RBM model
```

Now training is going on. The weight and the bias are going to be updated towards the direction of maximum likelihood.

And therefore all our probabilities $(v|h)$, of visible node sees the hidden nodes will be more and more relevant.

It will get the largest weights for the probabilities that are the most significant and eventually that will lead us to some predicted ratings that are going to be close to the real ratings.

### 14.5.5 Training the RBM-model - part 4: measuring error-train_loss

- Here torch.abs(vk[>=0] - v0[>=0]) finds the tensor of absolute values of the difference vk - v0.
