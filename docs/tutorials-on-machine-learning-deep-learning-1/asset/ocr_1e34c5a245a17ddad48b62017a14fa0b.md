Feature Scaling: Feature Scaling is a technique to standardize the independent features present in a fixed range. If feature scaling is not performed during the data-processing a machine learning algorithm tends to weigh features, higher and consider smaller values as lower, regardless of the unit of measurement.

What is Feature Scaling and why we have to do it: Feature Scaling is a technique that will pull all your features in the same range.

+   - If we have a look at our data we can clearly see that the values of the age feature are not in the same range as the values of the salary feature.

Why we have to apply FEATURE SCALING: Well's when training our models (not all of them) if you have some features that are taking much higher values than other features can create a bias in the correlations computations.

+   - In other words the features that have High values compared to the other ones will dominate the other features so that the other features might not be considered.
- However the other features might be having the largest impact on the dependent variable.
- You know the features that actually contribute the most to predicting the outcome.
