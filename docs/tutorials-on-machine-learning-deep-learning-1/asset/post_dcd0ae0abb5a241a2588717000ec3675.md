### 12.1.4 Vanishing gradient Problem
Vanishing gradient was first discovered by Sepp Hochreiter. And the second person is Yoshua Bengio (professor at the University of Montreal).

## The Vanishing Gradient Problem

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_378_1.png)
![](img/0aa092657a6eb1b9f2dd65bbb79055a3_378_2.png)
![](img/0aa092657a6eb1b9f2dd65bbb79055a3_378_3.png)

Vanishing gradient problem: So, as remember, following is the gradient descent algorithm. We're trying to find the global minimum of your cost function, and that's gonna be the optimal solution, optimal setup for your neural network.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_379_0.png)

Our information travels through NN to get output, and then the error is calculated and is propagated through the NN to update the weights.

It is as AIN but here all the circles represent Layers (not nodes).

- Every single node here is not just a node, it's a representation of a whole layer of nodes. There's lots neurons behind the ones that we can actually see because each one represents a layer.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_379_1.png)

In a RNN is a similar thing, when your information travels through the network it travels like this:

- It travels through time and information flows from previous time-points, keeps coming/going through the network, and remember that every node here is a whole layer of nodes.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_379_2.png)

So, at each point in time you can calculate your cost function, or your error. During the training, cost function compares your output (the red circle) to your desired output. Then you get these $\epsilon_t$ throughout the time series (for a single red circle), calculates the cost function.

How weights got updated (Gradient descent occurs): Now let's focus on one value, let's consider $\epsilon_t$. Now we want to propagate that cost function back through the network.

- To do this, every single neuron that participated in the calculation of the output associated with this cost function $\epsilon_t$ should update their weights, in order to minimize that.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_380_0.png)

But we have to note that, it's not just the neurons below (directly below that red circle): $\epsilon_t$.

- It's all the neurons that contributed (i.e. all previous time-point), all of these neurons as far back we go. Depending on how many time-steps you take. For example, you might take 50 time-steps before, then you have to update for all previous time-steps, propagate all the way back through time.

Following is the math behind RNNs, we use $W_{rec}$ and $W_{rec}$ (stands for weight recurring), and that is the weight that is used to connect hidden layers themselves in unrolled loop.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_380_1.png)

Here we can see that to propagate through the layer $X_{t-3}$ to the next layer $X_{t-2}$, we need to apply $W_{rec}$.

- In word, we are simply multiplying the output by the weight, and then get it to the next layer.
- We are multiplying by the same weight as many times as we need to go through this temporal loop. And this is where the problem arises, because when we multiply by small value it decreases quickly (e.g. $0.2 * 0.2 = 0.04$), and from the formula we can see that:

- Now remember that at the very start of the propagation process we multiply randomly to NN and now weights are assigned. Due to multiplication of such small values, our "gradient" decreases from one layer to previous layer during Back Propagation. A vanishing gradient is bad for the network. When the gradient goes back through the network, it is used to update the weights and the lower the gradient is the harder for the network to update the weights.

- The lower the gradient, updating the weights slower (the higher the gradient the faster's going to update the weights).

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_381_0.png)

- So for instance say we have 1,000 epochs. Some layers and part of our network cannot get trained properly. Having their gradients so much smaller, they're gonna be updated slower. Therefore by the end of the 1,000 epochs you might not have the final results, and then part of the network is trained and some part is not trained (based on their cost function).
- But the problem is not just that half of our network is not trained properly, also that weights on untrained layer generating wrong outputs. And those wrong outputs are being used as inputs for further layers.
- So, the training here has been all based on inputs, that inputs that are coming from untrained neurons.

In simple word that's the vanishing gradient problem for RNN.

## 12.1.5 Exploding Gradient Problem

**Exploding gradient**: if $W_{rec}$ is small, then you have a vanishing gradient problem. If $W_{rec}$ is large you have an Exploding Gradient Problem. Of course there are so many parameters in the formula, activation functions, weights etc. but in a nutshell these two things can happen.

| $W_{rec} \sim small$ | Vanishing |
| :--- | :--- |
| $W_{rec} \sim large$ | Exploding |

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_382_0.png)

## 12.1.6 Solutions for Vanishing/Exploding Gradient Problem

### The Vanishing Gradient Problem

Solutions:

- 1. Exploding Gradient
    - Truncated Backpropagation
    - Penalties
    - Gradient Clipping
- 2. Vanishing Gradient
    - Weight Initialization
    - Echo State Networks
    - Long Short-Term Memory Networks (LSTMs)

For the Exploding Gradient problem:
1. Truncated Back Propagation: For the exploding gradient you can have Truncated Back Propagation. So, you stop back propagating after a certain point, but that's probably not optimal because you're not updating all the weights.
2. Penalties: You can have Penalties. The gradient being penalized and artificially reduced.
3. Gradient Clipping: You can have Gradient Clipping. So you could have a maximum limit for the gradient. Gradient never goes over this value, and if it does, then it just stays as it propagates further down a network.

For the Vanishing Gradient problem:
1. weight Initialization: You have weight initialization, where you are smart about how you initialize your weights to minimize the potential for vanishing gradient.
2. Echo State Networks: You can have, any type of network called the echo state networks which are designed to solve the vanishing gradient.
3. Long Short-Term Memory networks, or THE LSTMs: there's a different type of network called the long-term memory networks, or the LSTMs (which are extremely popular). We will talk about it in next section.
