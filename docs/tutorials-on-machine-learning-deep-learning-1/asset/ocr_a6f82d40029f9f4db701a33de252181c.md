# What is the p-value?

+   * Does the size of a state affect population density? The **null hypothesis** is "all states have the same population density."

+   * Do cats prefer fish or milk? The null hypothesis is "cats have no preference; they like the them."

**P-value:** The P-value is the probability that the parameters associated to your independent variables have certain nonzero values, given that the null hypothesis is True. The most important thing to keep in mind about the P-value is that it is a statistical metric: the lower is the P-value, the more statistically significant is an independent variable, and the better the **predictor** it will be.

The smaller the p-value, the stronger the evidence that you should reject the null hypothesis. A p-value less than 0.05 (typically used as a threshold) is statistically significant. It indicates strong evidence against the null hypothesis, as there is less than a 5% probability that the **null is correct** [and the results are]

+   * The first step in backward elimination is pretty simple, you just select a **significance level**, or select the p-value. Usually, in most cases, a 5% significance level **is selected**. This means the P-value will be of 0.05.

P is a statistical measure that helps determine whether or not your hypotheses are correct values determine whether the **results of your experiment** are within the **normal range of values** for the events being observed. Usually, if the P value of a data set is lower than a certain alpha level (like, for instance, 0.05), scientists will reject the "null hypothesis" of their experiment.

The p-value is actually the probability of getting a sample like ours, or more extreme than ours IF the **null hypothesis is true**. So, we assume the null hypothesis is true and then determine **how "strong" our sample really is**. If it is not strange (a large p-value) then we don't change our mind about the null hypothesis. As the **p-value gets smaller**, we start wondering if the null result is true and well maybe we should change our minds (and **reject the null hypothesis**)

> Important:

Pr (observation | hypothesis) ∝ Pr (hypothesis | observation)
The probability of observing a result that is strong is not equal to the probability that a hypothesis is true given some result has been observed.
Using the p-value as a "score" is committing an egregious logical error: the **transposed conditional fallacy**.

A p-value (shaded area) is the probability of an (more extreme) result assuming that the null hypothesis is true.

+   * A little detail: A small p-value indicates that by pure luck, it would be unlikely to get a sample like the one we have if the null hypothesis is true. If this is small enough we start thinking that we aren't lucky and increase our assumption about the null being true. That's why we reject with a small p-value.

+   * A large p-value indicates that it would perfectly normal to get a sample like ours if the null hypothesis is true. So when you see, there is no reason here to change our minds like we did with a small p-value.

+   * In inferential statistics, the null (often denoted H0) is that two possibilities are the same. The null hypothesis is that the observed difference is due to chance alone. Using statistical tests, it is possible to calculate the likelihood that the null is true.
