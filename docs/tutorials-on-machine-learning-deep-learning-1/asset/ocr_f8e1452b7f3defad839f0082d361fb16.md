If we have 2 clusters then the squared distance reduces.

![](bbox=[0.228, 0.066, 0.772, 0.329])

For 3 clusters we get reduced WCSS. For 4, or 5, more centroid the distance doesn't decrease rapidly (but decreases). The WCSS tends to as K reaches to number of data points.

![](bbox=[0.308, 0.406, 0.725, 0.545])

WCSS = distance(P1, C1)^2 + distance(P1, C2)^2 + distance(P1, C3)^2

The Elbow-method is an approach that can help you to decide the number of k (clusters). But at the end of it is your decision.
