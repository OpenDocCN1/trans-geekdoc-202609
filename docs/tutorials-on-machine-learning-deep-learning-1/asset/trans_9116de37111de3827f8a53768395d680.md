
然后我尝试了 50 次，仍然没有收敛。

最后我尝试了 100 次，我观察到损失（loss）出现了收敛。

所以 100 是正确的迭代次数（epochs）数量。对于这个问题，除了我们没有那些数据，我们只有 5 年的谷歌股票价格。

batch_size：我们设置此参数是为了让 RNN 在输入神经网络的观测值/股票价格批次上进行训练。而不是在每个 epoch（每个股票价格）上通过正向传播产生误差和反向传播来更新权重，我们这样做，保留 32 个股票价格。
