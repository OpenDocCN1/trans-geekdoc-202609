For these two objects we specify the transform parameters. In this image augmentation, we apply several transformations like:

- rescale: default. If None or 0, no rescaling is applied, we multiply the data by the value provided (before any other transformation).

- rescale is always compulsory and to correct the feature scanning span of the data preprocessing phase that we know.

- Why we have to rescale by 1/255: rescale is a value by which we will multiply the data before other processing. Our original images contain RGB coefficients in the 0-255, but such values would be too high for our models to process (given a typical learning rate), so we target values between 0 and 1 instead of scaling with a.

- shear_angle: Shear Intensity (Shear angle in counter-clockwise direction as radians) sharing is a geometrical transformation that is also translation. Here the pixels are moved to a fixed direction over a proportional distance from a line that is parallel to the direction they're moving. So this is a geometrical transformation for augmenting our images.

- zoom_range: (Float) Range for zoom factor. If [lower, upper] = [1-zoom_range, zoom_range]. This is some sort of random zoom that will augment our images.

- horizontal_flip: (Boolean) Flip inputs-images horizontally.

We can have all the image transformations that are in the Keras Documentation, for now we will just use what we have in this code segment. That we will find and see if you'll get good results.

Rename train_generator and validation_generator to training_set and test_set. These are two instances of objects train_datagen and test_datagen and we use flow_from_directory method to import the train and test images by augmentation and then CNN on them. We need to specify parameters for flow_directory

- directory: to the target directory. It should contain one subdirectory per class. Any PNG, JPG or BMP images each of the subdirectories will be included in the generator.

- We replace "directory" with corresponding path. The image folder paths "dataset/training_set" and "dataset/test_set" respectively for training, test and test_set respectively.

- We don't have to specify the whole path that leads to this dataset, which is already in the working directory folder.

- target_size: Tuple of integers. (256, 256). The dimensions to all images found will be resized in size. in our case we are using with CPU, we set it to (64, 64) it should be the same as we test input_shape (dimension of expected resized images) in Convolution2D.

- batch_size: Size of the batches of data (float). batch_size is not related to of filters used in Convolution2D.

- It specifies the number of random samples of our images that will go through the CNN, with the weight will be updated.

- class_mode: one of 'categorical', 'binary', 'sparse' or None. Default: "categorical". Here we use "binary" because we are working with binary category cat/dog.

- That's the parameter indicating if your class, your dependent variable is binary or has more than two categories and therefore we have two classes, cats and dogs, the class_mode = "binary".

class_mode determines the type of label arrays are returned:

- 'categorical' will be 2D one-hot encoded labels.
- 'binary' will be 1D binary labels.
- 'sparse' will be 1D integer labels.
- If None, no labels are returned.

```python
# Part 2 - Preprocessing & fit CNN to our images
from keras.preprocessing import ImageDataGenerator
# creating two data-generator/augmentation objects for train and test data
# here we transform the parameters
train_datagen = ImageDataGenerator(
    rescale=1/255,
    shear_range=0.2,
    zoom_range=0.2,
    horizontal_flip=True
)
```

```python
test_datagen = ImageDataGenerator(rescale=1/255)
```

```python
# applying augmentation on training data : folder path needed
# target_size = Input_shape (dimension of expected resized images)
# batch_size = not related to lo. of filters
training_set = train_datagen.flow_from_directory('dataset/training_set',
    target_size=(64, 64),
    batch_size=32,
    class_mode='binary')
```

```python
# applying augmentation on test data : folder path needed
test_set = test_datagen.flow_from_directory('dataset/test_set',
    target_size=(64, 64),
    batch_size=32,
    class_mode='binary')
```

```python
cnn_classifier.fit_generator(training_set,
```
