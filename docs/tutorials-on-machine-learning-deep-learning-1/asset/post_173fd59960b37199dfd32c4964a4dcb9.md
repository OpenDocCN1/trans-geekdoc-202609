
## UPPER CONFIDENCE BOUND ALGORITHM:

**[1] Step 1:** At each round $n$, we consider two numbers for each $\hat{ad}_i$

- $N_i(n)$ = The number of times the $ad_i$ was *selected* up to round $n$.
- $R_i(n)$ = The number of rewards of the $ad_i$ up to round $n$.

**[2] Step 2:** From these two numbers we compute:

- The *average reward* of $ad_i$ up to round $n$

```
$$\bar{r}_i(n) = \frac{R_i(n)}{N_i(n)}$$
```

- The confidence interval at round $n$ is:

```
$$\bar{r}_i(n) - \Delta_i(n), \quad \bar{r}_i(n) + \Delta_i(n)$$
```

Where:
$$\Delta_i(n) = \sqrt{\frac{3 \log(n)}{2 N_i(n)}}$$

**[3] Step 3:** We select the $ad_i$ that has the maximum UCB, $\bar{r}_i(n) + \Delta_i(n)$.

## Mean, Median, and Mode: Every numerical data set has an average value that represents the weight of its value. There are many different types of average! 3 of the most popular average values: Mean, Median, and Mode. Median and Mode are average values or central tendency of a numerical data set.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_185_0.png)

- **Mean**: Mean can be calculated by adding all data points and dividing by the number of data points.
- **Median**: Median is the middle value of a data set; if there are two numbers, taking the mean of those two.
- **Mode**: Mode is the most frequent number.
