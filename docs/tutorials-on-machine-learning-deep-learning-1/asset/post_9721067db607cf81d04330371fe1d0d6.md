## 5.1.3 Apriori Algorithm

The Apriori algorithm uses frequent items to generate association rules, and it is designed to work on the databases that contain transactions. With the help of each association rule, it determines strongly or weakly two objects are connected. This algorithm uses a breadth-first search and Hash Tree to count the itemset associations efficiently. It is the iterative process for finding the frequent items from the large dataset.

This algorithm was given by R. Agrawal and Srikant in the year 1994. It is mainly used for market basket analysis and helps to find those products that can be bought together. It can also be used in the healthcare field to find drug reactions for patients.

## 5.1.4 How Does Apriori algorithm work

The apriori algorithm has three parts: to the support, the confidence and the lift.

Calculation metrics: to measure the associations of thousands of data-items, there are several metrics. These are metrics:

i. Support ii. Confidence iii. Lift

[Support] We were going to start with the support and you will see that it's very similar to the way we talked about the Naive Bayes classifiers.

frequency an item appears in the dataset is defined as the fraction of the transaction T that contains the item X if there are X datasets, then for transactions T, it can be written as:

```
support(M) = # user watchlists containing M / # user watchlists
```

| Movie Recommendation: support(I) = # transactions containing I / # transactions |

```
support(X) = Freq(X) / T
```

For example: Say from 100 people, 10 people watched Ex-Machina, then support = 10%.

[2] Confidence: Confidence indicates how often the rule has been found to be true. Or, how often the items X and Y occur together in the dataset when the occurrence of X is already given. It is the ratio of the transaction that contains X and Y to the number of records that contain X.

# $Confidence(X \rightarrow Y) = \frac{Freq(X,Y)}{Freq(X)}$

For example: Now consider we are testing a rule, *People who watched Interstellar also watched Ex-Machina*. So in the following diagram say green people who watched Interstellar is 40 among 100, and 7 of them watched Ex-Machina, then the confidence is:

# $Confidence = \frac{7}{40} = 17.5\%$

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_165_0.png)

| | |
|---|---|
| Movie Recommendation: | $confidence(M_1 \rightarrow M_2) = \frac{\# user watchlists containing $M_1$ and $M_2}{\# user watchlists containing $M_1}$ |

| | |
|---|---|
| Market Basket Optimisation: | $confidence(l_1 \rightarrow l_2) = \frac{\# transactions containing $l_1$ and $l_2}{\# transactions containing $l_1}$ |

[3] Lift: Lift is very similar to the *Naive Bayes classifiers*. Lift is basically the *ratio* of *Confidence* and *Support*. It is the *strength of any rule*, which can be defined as formula:

# $Lift = \frac{Support(X,Y)}{Support(X) \times Support(Y)}$

| | |
|---|---|
| Movie Recommendation: | $lift(M_1 \rightarrow M_2) = \frac{confidence(M_1 \rightarrow M_2)}{support(M_2)}$ |

| | |
|---|---|
| Market Basket Optimisation: | $lift(l_1 \rightarrow l_2) = \frac{confidence(l_1 \rightarrow l_2)}{support(l_2)}$ |

Example: So in below Green people who watched Interstellar and Red-circle represents the people who watched Ex-Machina.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_166_0.png)

Out of your population we know that 10% actually likes Ex-Machina. So if we take another population and then what the likelihood that if we recommend to a random person in that brand new population will like the movie is 10%. But now is the question: Can we prove that result by using prior knowledge? That's why the algorithm is called Apriori.

In that new population let's only recommend Ex-Machina to people who have already seen Interstellar. The likelihood as we've calculated out of the Green people 17.5% actually liked Ex-Machina. The Lift is the improvement in your prediction.

```
Lift = \frac{17.5\%}{10\%} = 1.75
```

Out of your new population if you first ask the question "Have you seen and liked interstellar?" If they say "yes" and then you recommend Ex-Machina the likelihood of a successful recommendation is 17.5% So the lift by definition is 1.75.

## 5.1.5 Steps in Association Rule Learning

- Step 1: Set a minimum support and confidence
- Step 2: Take all the subsets in transactions having higher support than minimum support
- Step 3: Take all the rules of these subsets having higher confidence than minimum confidence
- Step 4: Sort the rules by decreasing lift

* Apriori is quite a slow algorithm because it just goes through all of these different combinations of rules. For example it will calculate rules for Movie, Movie2, Movie3, Movie4, ... so for pair (Movie and Movie2) or triplet (Movie and Movie2 Movie3) so on.

* So there is many different rules and we pick only strong rules. The rule with highest lift is the strongest rule.
