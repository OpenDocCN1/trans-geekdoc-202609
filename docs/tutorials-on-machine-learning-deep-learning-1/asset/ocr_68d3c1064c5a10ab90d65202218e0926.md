# 10.10 Kernel-PCA in Python: Linear model & non-linear data

PCA and LDA feature techniques work on linear problems (i.e. when the data is linearly separable).

+   - Here we consider a non-linear problems where the data is not linearly separable. Here we'll apply a new feature extraction technique. This technique is called **kernel-PCA**.

+   - kernel-PCA kernel-PCA is a **kernelized** version of PCA where we **map** the data to a **higher dimension** using the **kernel trick**. From there we extract some **principal components** (PCs) and we're going to see how it manages with non-linear problems.
