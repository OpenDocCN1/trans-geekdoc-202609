
## 3.3.4 Python implementation of the SVM algorithm

```python
# Library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np
```

```python
# Data Extraction
dataset = pd.read_csv("Social_Network_Ads.csv")
X = dataset.iloc[:, 2,3].values
y = dataset.iloc[:, 4].values
```

```python
# Feature-Scaling After Data Split
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
```

```python
# Feature-Scaling
from sklearn.preprocessing import StandardScaler
```

```python
st = StandardScaler()
X_train = st.fit_transform(X_train)
X_test = st.transform(X_test)
```

```python
# Fit train to Model classifier
from sklearn.svm import SVC
clsf = SVC(kernel="linear", random_state=0)
clsf.fit(X_train, y_train)
```

```python
# Predict
y_pred = clsf.predict(X_test)
```

```python
# Make the confusion matrix using the function "confusion_matrix"
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(true=y_test,
```

```python
# Visualizing the Training sets
from matplotlib.colors import ListedColormap
X_set, y_set = X_train, y_train
X1, X2 = np.meshgrid(np.arange(start=X_set[:,0].min, stop=X_set[:,0].max+1, step=0.01), np.arange(start=y_set[:,1].min, stop=y_set[:,1].max+1, step=0.01))
```


Recall in the SVM situation we had a set of observations which belong to different classes and the algorithm will find the decision boundary between them so that any future observations could be identified which Class they fall into.

- In Non Linear Separable Case we cannot draw one single Decision Boundary or Linear Boundary so therefore the Support Vector Machine just won't work by definition.

## 3.4.2 Tricks to deal with Non Linear Separable Data

**1] Mapping to a higher dimension:** First of all we're going to explore a method called "Mapping to a higher dimension". In this case we use our dataset and add an extra dimension into our space that we're dealing with and make our data a linearly separable with "some mapping".

**2] Kernel trick:** The kernel trick allows us to make our data separable without having to deal with multiple or higher dimensions.

Lastly, we will talk about the different types of kernels that exist.
