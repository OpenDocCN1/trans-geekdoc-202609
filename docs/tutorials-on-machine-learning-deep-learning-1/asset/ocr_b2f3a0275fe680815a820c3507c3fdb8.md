Between the input space and the output space, this weight vector has NN neurons, each neuron being initialized as a vector of weights, has same size as the vector of inputs (i.a vector of 15 elements).

For each observation point the output will be the neuron that is the closest to the point. Basically, in the network, we pick the neuron that is closest to the customer, this is called the winning node.

For each customer, the winning node is the most similar neuron to the customer. We use a neighbourhood function like the Gaussian Neighbourhood function, to update the weight of the neighbors of the winning node to move closer to the point.

We do this all for the customers in the input space. It is a repeating process. And each time we repeat it, the output space decreases and loses its shape.

It reduces its dimension by little by.
And it reaches a point where the neighbourhood stops decreasing, where the output space stops decreasing and become steady.

And that's the moment where we obtained our SOM in 2d map, with all the winning nodes that were eventually identified.
