# Evaluating Regression Performance

## 2.7.1 R Squared

We talked about simple regression built through ordinary squares method where we are minimizing $\sum(Y_i - \hat{Y}_i)^2$. We were counting that sum and the line that has smallest sum will be the best fitting line or simple regression model.

Residual sum of squares: For fitted-line (model) the residual sum of squares $SS_{res}$ is:
$SS_{res} = \sum_{i=1}^n (Y_i - \hat{Y}_i)^2$

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_74_0.png)

Total sum of squares: Using the average line we get the total sum of squares:
$SS_{tot} = \sum_{i=1}^n (Y_i - Y_{avg})^2$

R-square: The following equation is the R-squared
$R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$

> R-square says "How the best fitting line (or model) is with respect to average line". Minimizing $SS_{res}$ to maximize $R^2$, $R^2 = 1$ is the best scenario (and will never happen!).

> So $R^2$ near 1 is better model and 0 is the bad model. $R^2$ can also be negative (model is worse than the average line).

## 2.7.2 Adjusted $R^2$

We talked about $R^2$ for Simple Regression while the same concepts apply for multiple linear regression. R-squared as goodness of fit parameters, the bigger it is (close to 1) the better the model.

Impact on Increase/Decrease of feature variables: $R^2$ is biased Reason: when we add new feature variable $SS_{res}$ always decreases or stays. $SS_{res}$ doesn't increase because of the model, if new variable effect in the negative way, the coefficient of the variable gets just smaller, so that the effect is negligible. By adding new feature variable, $SS_{res}$ may decrease but hence never increase by adding feature variable.

Then how to determine the impact of new feature variable? The solution is to use $R^2$.

# Adjusted $R^2$: Following is the equation for Adjusted $R^2$.

```python
adj R^2 = 1 - (1 - R^2) \frac{n-1}{p-n}
```

Where $n$ = Sample size, $p$ = number of regression/feature variable.

Penalization factor: Adjusted R-squared has a penalty for adding independent variables that don't help your model.

- As we increase variable, $p$ increase, $1-p$ decreases, $\frac{n-1}{p-n}$ increases.
- If the new variable doesn't help, then $R^2$ doesn't decrease, $(1-R^2)$ $\frac{n-1}{p-n}$ increase and adj $R^2$ decrease.
- Here actually $(1-R^2)$ and balance each other. If the new variable helps, then $(1-R^2)$ and $\frac{n-1}{p-n}$ decrease and increase.

In statistics, *regression* is the name given to any variable in a *regression model* that is used to predict a *response variable*. A *regressor* is also known as an *explanatory variable*. An *independent variable* is a *manipulated variable*. Feature, independent variable, covariate, or predictor are all of the names that are used to predict the target, outcome, variable, regressor, or regress.

## 2.7.3 Feature selection using Adjusted R-squared

Recall the Linear Regression Backward elimination, where we rejected variables by p-values. Now at final step we end with only one variable *RBD model*.

- After we end with only one variable *RBD model*, we use Adjusted R-squared to select the features. This is because $R^2$ always increases when we add a variable, but Adjusted $R^2$ penalizes for the number of variables.
