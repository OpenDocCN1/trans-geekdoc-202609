# 15.4 SAE criterion : optimizer for SAE architecture

Now we create this object with name *sae*. Since we didn't specify any arguments in-
`__init__` function of the StackedAutoEncoders, we don't have to pass any arguments here.

```
sae = StackedAutoEncoders()
```

+   * **Criterion**: We'll need this criterion to train the model.

```
criterion = nn.MSELoss()
```

+   * It's basically the *criterion* for the *loss function*, and the *loss function* going to be the mean squared error so we used
`nn.MSELoss()` class from nn module.

+   * **Optimizer**: The last thing that we need is an *optimizer*. It is much like *Keras*. The optimizer will apply Stochastic
Gradient Descent to control the different weights in order to reduce the *error* at each epoch.
* We'll use *torch* to implement our optimizer. We can use *ADAM* or *RMSProp-optimizer*. By experiment
*RMSProp* gives better result.

```
optimizer = optim.RMSprop(sae.parameters()), lr = 0.01, weight_decay=0.5
```

+   * **Arguments**: We have three things
  We have to put all the parameters of our *AutoEncoders*, that is parameters to build our *StackedAutoEncoders*
architecture.
  We don't have to rewrite all of them. The easy way is to use *sae.parameters()* that gets all the parameters from
sour sae.
  *lr*: The learning rate. It depends on epochs, a good value I found was **0.01**. Of course we can tune it to get
better result.
  *weight_decay*: Specify the decay. The decay is used to reduce the *learning rate* after every few *epochs* and
's in order to regulate the *convergence*. We can also tune it. Based on my experimenting a good value I found was
0.5.

> NoteWe apply parameters on sae, not the class StackedAutoEncoders.

```
# Creating the architecture of the Neural Network for SAE----
class StackedAutoEncoders(nn.Module):
    def __init__(self, nb):
        super(StackedAutoEncoders, self).__init__(
        self.fc1 = nn.Linear(nb_movies, 20)
        self.fc2 = nn.Linear(20, 10)
        self.fc3 = nn.Linear(10, 20)
        self.fc4 = nn.Linear(20, nb_movies)
        self.activation = nn.Sigmoid()

    def forward(self, x):
        x = self.activation(self.fc1(x))
        x = self.activation(self.fc2(x))
        x = self.activation(self.fc3(x))
        x = self.fc4(x)
        return x

sae = StackedAutoEncoders(nb)
criterion = nn.MSELoss()
optimizer = optim.RMSprop(sae.parameters()), lr = 0.01, weight_decay=0.5)
```
