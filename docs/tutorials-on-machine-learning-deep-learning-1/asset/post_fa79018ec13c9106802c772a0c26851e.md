
# 10.6 PCA in part: 3 - applying PCA

In this we cover the following sections: fitting logistic model, prediction, confusion matrix, visualization-part. Because the independent variables are not yet fixed, here is what we're going to do next:

- Import PCA
- First time applying PCA for all 13 independent variables: we examine all 13 variables and their impact (i.e. variance) on the data.
- Find the most important independent variables, i.e. Principal Component - PC.
- Then we will apply PCA second time for 2 independent variables. (after finding the no. of PCs: we just fix the number in PCA object.)

```python
# Library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Data Extract
dataset = pd.read_csv("data.csv")
X = dataset.iloc[:, :13].values
y = dataset.iloc[:, 13].values

# Data Split
from sklearn.model_selection import train_test_split
# 0.20 test_size means "2/10" of the total observation
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=0)

# Preprocessing
from sklearn.preprocessing import StandardScaler
# y need to be scaled.
st = StandardScaler()
X_train = st.fit_transform(X_train)
X_test = st.transform(X_test)

# Applying PCA
# Fit dataset to logistic regression
from sklearn.linear_model import LogisticRegression # Import class
# Instead of "regressor" we now use "classifier"
classifier = LogisticRegression(random_state=0) # create object
classifier.fit(X_train, y_train) # fit the dataset

# Predict
y_pred = classifier.predict(X_test)
# Making the confusion matrix use the function "confusion_matrix"
# Class in capital letters, functions are small letters
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_train, y_test, y_pred)
# parameters of cm: y_true: Real values, y_pred: Predicted value

# Visualizing the training set results
from matplotlib.colors import ListedColormap
X_set, y_set = X_train, y_train
X1, X2 = np.meshgrid(np.arange(X_train[:, 0].min(), X_train[:, 0].max() + 1, 0.01), np.arange(X_train[:, 1].min(), X_train[:, 1].max() + 1, 0.01))
plt.contour(X1, X2, np.array(y_train).reshape(X1.shape), alpha=0.03, cmap=ListedColormap(['red', 'green']))
plt.contour(X1, X2, np.array(y_test).reshape(X1.shape), cmap=ListedColormap(['red', 'green', 'orange']))
for i, j in enumerate(np.unique(y_set)):
    plt.scatter(X_set[j,0], X_set[:,1], c=ListedColormap(['red', 'green', 'orange'])(i), Label = j)
plt.title('Logistic Regression (training set)')
plt.legend()
plt.show()

# Visualizing the test set results
from matplotlib.colors import ListedColormap
```

Import PCA: We first import the right package and precisely the right class to use as PCA. Then we create an object of this class and we use the `fit_transform` and `transform` methods respectively on the training set and the test-set.

```python
from sklearn.decomposition import PCA
decompose_pca = PCA(n_components=None)

X_train = decompose_pca.fit_transform(X_train)
X_test = decompose_pca.transform(X_test)
```

By applying the `fit_transform` method to this `decomposition_pca` object we can see how the training set is **structured** and transformed. The object is fitted to the training-set, then we use the `transform` method to transform the test-set that is **X_test**.

That will object our **training set** and **transform** it at the same time i.e. extracting all the **PCs**.

**n_components**: int, float or None, default=None

Number of components to keep. If `n_components` is not set all components are kept. It is the number of **extracted features** you want to get to explain the most variance. We choose the number depending on how much variance you would like it to be explained.

For now we use `n_components=None`, because we want to get two **principal components** to visualize the result, but we don't know how much variance these two components explain.

We need to make sure that the first two principal components (PCs) that explain the variance don't explain the little variance.

We used None because we create a vector `explained_variance` by using a PCA attribute `explained_variance_ratio_`, to see the cumulative percentage of each of the principal components.

**explained_variance_ratio**: returns the list of all the percentage explained by each of the principal components that we have extracted.

```python
explained_variance_ratio = decompose_pca.explained_variance_ratio_
```

```python
from sklearn.decomposition import PCA
decompose_pca = PCA(n_components=None)
X_train = decompose_pca.fit_transform(X_train)
X_test = decompose_pca.transform(X_test)
explained_variance = decompose_pca.explained_variance_ratio_
```

Now we can have a look at this returned explained variance, `explained_variance` of all the principal components.

- In the **variance vector**, since we originally had 13 independent variables, we extracted 13 principal components. These are the **extracted independent variables** that explain the **most** variance.

- You can see them **ranked**, from the first ($0^{th}$) PC that explain the **most** **variance** down to the 12th and last 13th PC that explain the **least** **variance**.

First PC will explain 37% of the variance. 2nd PC will explain 19% of the variance.
So if we take two PCs they will explain 37 + 19 = 56% of the variance.

For 3D visualization, if we take the three PCs that will explain 37 + 19 + 11 = 67%

- We chose the first two PCs because we get 2D visualization of the result.
- Explaining 56% of variance is pretty good to make a classification out of.

# 10.7 PCA in Python: part 4 - Logistic & Visualize the result

We are ready to fit a logistic model to classify which segment they belong to. At the time we will predict the results and evaluate the performance using the confusion matrix.

```python
from sklearn.linear_model import LogisticRegression # Import class
# Instead of "regressor" we now use "classifier"
classifier = LogisticRegression(random_state=0) # create object
classifier.fit(X_train, y_train) # fit the dataset

# Predict
y_pred = classifier.predict(X_test)

# Making the confusion matrix use the function "confusion_matrix"
# Class in capital letters, functions are small letters
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_train, y_test, y_pred) # y_true: Real values, y_pred: Predicted value
```

## Confusion matrix:

Here we see the accuracy of our classification model with the two extracted principal components.

Since these PCs were chosen to explain the most variance they explained around 60 percent of the variance. Therefore we should get good accuracy because our two PCs are actually the directions of maximum variance in our dataset.

It's a confusion matrix with three classes, so it won't be a confusing matrix of 2x2 but since we have three classes this will be a confusion matrix of 3x3.

You can see we get excellent results because in the diagonal we will get the correct prediction.

- 14 correct predictions of the class for the customer of segment one.
- 15 correct predictions of the customer segment two.
- 6 correct predictions of the customer segment three.

So using PCA we got a very good prediction. 35 correct prediction out of 36 total observations. i.e. 35/37 = 97.2% accuracy.
