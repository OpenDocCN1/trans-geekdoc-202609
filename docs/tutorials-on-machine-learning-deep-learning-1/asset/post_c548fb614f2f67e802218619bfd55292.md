
Training model: We import apriori from apriori/package; We create object and rules, because this class takes list of lists and outputs the rules. Rules needed to be converted in list so we use list{rules}.

> apriori is a python 2 module so this is not working on python. The updated apriori.py needs to be put/copied in the working directory.

Parameters: These arguments which you will apply on your business problem, depend on the number of observations you have in your data set. Of course, your minimum support, confidence and lift are not going to be the same as if you have 1000 transactions and 10000 transactions.

```python
# Training apriori
from apriori import apriori
rules=apriori(transactions=transactions, min_support=0.003, min_confidence=0.2, min_lift=3, min_length=2)
results=list(rules)
for asocitm, item in results:
    print(f"{asocitm}")
```

In the code above, the first line is to import the apriori function. In the code, the apriori function returns the output as rules. It takes the following parameters:

- **transactions**: A list of transactions.
- **min_support**: To set the minimum support float value.
- **min_confidence**: To set the minimum confidence float value. We used 0.003 to calculate it by the total number of transactions.
- **min_lift**: To set the minimum lift value.

If a product is bought 3 times per day in a week, $3 \times 7 = 21$. And we have 7500 transactions, $min\_support = \frac{21}{7500} = 0.0028 \approx 0.003$.

All the products of our rules will have a higher support than this.

**min_confidence**: To set the minimum confidence value. Here we have taken 0.2. 0.8 means the rules have to be in 80 percent of the time. But if you get some rules containing some properties, we can change it to 0.2.

**min_lift**: To set the minimum lift value. We also try to get some rules that have lift above 3. These are actually good rules and the strength of the rule.

And remember parameters depend on your business problem:

- **min_length**: It takes the minimum number of products for association.
- **max_length**: It takes the maximum number of products. We can leave it empty.
