# 2.4 Random Forest

We will discuss Random Forest aspected to Regression Trees. We first create N trees on subset of data (picking data points randomly) and then we predict a N decision trees. Following are the steps for Random Forest:

+   * STEP 1: Pick a random K data points from the Training set. make a subset of data point.
* STEP 2: Build the Decision Tree associated to K data points. i.e create a Decision Tree on the selected subset.
* STEP 3: Choose the number of N trees to use and repeat STEPS 1 & 2.
* STEP 4: For a new data point, make each of your trees predict the value of Y for the data point in question, and assign the new data average across all the predicted Y.

In that way we are not just predicting one tree on a forest of trees. And that improves the accuracy of your prediction because it is taking the average of many predictions.

+   * Therefore if some tree is too perfect (overfitting) or too bad at prediction those extreme case are ignored i.e. impact on a forest of trees is negligible. So we get a more accurate prediction.
* This ensemble algorithms are more stable because any changes in your data set could really impact one tree but it is hard to impact a forest of trees.
