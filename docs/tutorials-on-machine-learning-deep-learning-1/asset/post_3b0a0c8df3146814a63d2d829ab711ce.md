## 9.4.1 Summary

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_291_0.png)

- Let's summarize what we've talked about.
  - **Step-1**: We started with an input image. On the input image we applied multiple different *Feature-Detectors/Filters* to create these **feature maps**. And this is our **Convolutional Layer**.
- On top of that *Convolutional Layer* we applied the ReLU to *remove linearity* or *increase non-linearity* in our images.
- **Step-2**: Then we applied a *Pooling Layer* to our *Convolutional Layer*. From every every single *Feature-Map* we created a **Pooled-Feature-Map**.
- The main purpose of the Pooling Layer is to make sure that we have *Spatial Invariants* in our images.
- So basically if an image *tilts* or *twists* or is a *different* to the ideal scenario we can still *pick out* that objects feature
- Also Pooling significantly *reduces* the size of our images.
- Moreover Pooling *helps with avoiding any kind of overfitting* of our data or overall by getting rid of a lot of that data.
- At the same time Pooling *preserves the main features* that we are after max *Pooling* is used.
- **Step-3**: Then we *flattened* all the pooled images into one *long vector* or *column* of all these values and we put that into an ANN.
- **Step-4**: We introduce a *Fully Connected Artificial Neural Network* where all of these features are processed through a NN.
- Then we have *Final Fully Connected Network* which performs the voting towards the *classes* that we are after and all of this is trained through a *forward propagation* and *back propagation* process. With lots of *iterations* and *Epochs* and in the end we have a very well defined *neural network*.
- Another thing is not only the weights in ANN part but also the **feature detectors/filters** Both are adjusted in same *Gradient Descent* process that allows us to come up with the **best feature maps**.

In the end we *fully trained* CNN which can recognize and classify them. That's how *Convolutional Neural Networks* work.

## 9.4.3 SoftMax function

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_292_0.png)

- This is the CNN that we built to Recognize Cat/Dog in a given image. Notice the output probabilities 0.05 for Cat and 0.95 for Dog.
- Now the question is: How the sum of these two values is 1 (in case of more than two class Dog Cat & Bird sum of output probabilities is always 1).
- Because as we know ANN there is nothing to say these two output-neurons are connected between each other.
- So how would you know the value of that one is holding? And how would they add to their probability-values up to 1.
- The answer is : They wouldn't be in the classic version of our ANN.

SoftMax: The only way they would know about those values if we use a special function called the SoftMax function.

Normally the Dog and the Neurons would have any kind of real values that their sum don't have to be 1. Say these values are $z_1$ and $z_1 + z_2 \neq 1$.

Then we apply the SoftMax function upon $z_1$ and $z_2$ so that the sum of their outputs is 1.

### $f_j(z) = \frac{e^{z_j}}{\sum_k e^{z_k}}$

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_293_0.png)

Here the SoftMax function or the Normalized Exponential Function is a Generalization of the Logistic Function that Squashes a k-dimensional vector of arbitrary values to a k-dimensional vector of values in the range of [0,1] if that add up to 1. i.e. for example (23, 45, 79, 45) becomes something like (0.1, 0.25, 0.4, 0.25). it normalize the vector in a way so that the sum of the elements of the vector becomes 1.

The elements of the vector in case the values returned by Cat-Neuron and Dog-neuron. SoftMax function brings these values to be in range [0,1] and make sure they add up to 1.

Why SoftMax is used in CNN: It makes sense to introduce the SoftMax function into CNN because it is strange a probability of being a dog is 95 and also probability of a cat is 65%.

Therefore it is strange a probability of being a dog is 95...
