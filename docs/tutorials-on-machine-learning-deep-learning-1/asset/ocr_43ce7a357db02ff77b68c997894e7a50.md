Import PCA: We first import the right package and precisely the right class to use as PCA. Then we create an object of this class and we use the `fit_transform` and `transform` methods respectively on the training set and the test-set.

```
from sklearn.decomposition import PCA
dcmpose_pca = PCA(n_components=None)

X_train = dcmpose_pca.fit_transform(X_train)
X_test = dcmpose_pca.transform(X_test)
```

By applying the `fit_transform` method to this `dcmpose_pca` object we can see how the training set is **structured** and transformed. The object is fitted to the training-set, then we use the `transform` method to transform the test-set that is **X_test**.

That will object our **training set** and **transform** it at the same time i.e. extracting all the **PCs**.

**n_components**: int, float or None, default=None

Number of components to keep. If `n_components` is not set all components are kept. It is the number of **extracted features** you want to get to explain the most variance. We choose the number depending on how much variance you would like it to be explained.

For now we use `n_components=None`, because we want to get two **principal components** to visualize the result, but we don't know how much variance these two components explain.

We need to make sure that the first two principal components (PCs) that explain the variance don't explain the little variance.

We used None because we create a vector `explained_variance` by using a PCA attribute `explained_variance_ratio_`, to see the cumulative percentage of each of the principal components.

**explained_variance_ratio**: returns the list of all the percentage explained by each of the principal components that we have extracted.

```
explained_variance_ratio = dcmpose_pca.explained_variance_ratio_
```

```
from sklearn.decomposition import PCA
dcmpose_pca = PCA(n_components=None)
X_train = dcmpose_pca.fit_transform(X_train)
X_test = dcmpose_pca.transform(X_test)
explind_vince = dcmpose_pca.explained_variance_ratio_
```

Now we can have a look at this returned explained variance, `explained_variance` of all the principal components.

+   In the **variance vector**, since we originally had 13 independent variables, we extracted 13 principal components. These are the **extracted independent variables** that explain the **most** variance.

+   You can see them **ranked**, from the first ($0^{th}) PC that explain the **most** **variance** down to the 12th and last 13th PC that explain the **least** **variance**.
