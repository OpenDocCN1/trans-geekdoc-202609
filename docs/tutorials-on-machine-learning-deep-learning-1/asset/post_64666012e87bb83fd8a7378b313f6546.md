
Now we're going to create an object of the class that is inherited from the nn model. This object will represent the full connection between the first input vector and the first encoded vector.

We're gonna call this full connection fct and it is associated to our object we use self.fc1.
Then we use the inherited class Linear() from the nn module. So, self.fc1 = nn.Linear().

```python
self.fc1 = nn.Linear(nb_movies, 20)
```

Parameters of nn.Linear():

- i. The first input is the number of movies in the feature vector, i.e number of movies nb_movies. The features are actually movies, because one observation (user/movie) contains the ratings of all the movies.
- ii. The second output is the number of nodes in the first hidden layer. i.e the number of elements in the first encoded vector.

- We tried several values for the feature. The value we use is based on experiments, and the value is 20.
- This is still not tuned. To get a better score we can tune it.
- 20 nodes in first hidden layer used it means that our first encoded vector is a vector of 20 elements.

If we want to make the parallel with the problem, well, what would represent this first hidden layer of 2 neurons?
autoencoder detects.

- Remember that the neurons in the auto-encoder represent some features that, through unsupervised learning, the autoencoder detects.
- These features in the first hidden layer can represent some features of movie that are like by similar people.
- For example, one of these 20 nodes could be a specific genre of movie. One of the detected feature could be the horror_genre movie.
- In that case, when a new user comes in the system, if this new user gives some good ratings to all the horror movies of the database, this will activate the horror genre neuron/node and there a big weight will be attributed to this neuron/node in the final position to predict the rating of a horror movie.

This is a very simple example and of course, the features can be much complex than would be difficult to define, but that's how it works.
With 20 neurons, we're going to detect 20.

## Second connection - ENCODING (Second layer)

Since we're making stacked autoencoders, we're gonna make another layer. We have to make a full connection.

```python
self.fc2 = nn.Linear(20, 10)
```

It is same as previous layer, we used the Linear class to give this a name 'fc2' i.e full-connection.
Again we're gonna use it to make this full connection.
To make the connection from the first hidden layer, composed of the 20 neurons and this second hidden layer, we need to specify the number of nodes of previous layer(which is 20) and since we are all encoding we choose smaller number of nodes for this layer by experiment this is 10.
In this second hidden layer with 10 neurons, it will detect even more features, based on the previous features that we detected.

## Third full connection - DECODING (3rd layer)

Since we're to add a third layer but now, we start DECODING.

```python
self.fc3 = nn.Linear(10, 20)
```

We name this hidden layer fc3, the full connection between the second hidden layer and the third hidden layer.
Since we are Decoding, the number of nodes will be higher than the previous layer. We use 10 neurons of previous layer and 20 for this layer.
Here we're just starting to reconstruct the original input vector So, let make symmetrical.

## Fourth connection - DECODING (4th layer)

This is the last part of the decoding, the last full connection we have to make. We name the full connection as fc4 here we use 20 because we have 20 nodes in the third layer.

```python
self.fc4 = nn.Linear(20, nb_movies)
```

Now this is the last layer, and the number of neurons in the output layer will be same as input layer, because we are re-reconstructing the input vector.

Hence the output vector should have the same dimension as the input vector.
Therefore, the number of neurons in the output layer is also going to be nb_movies.

**Activation**: Now we have to specify an activation function that will activate the neurons when the observation enters the network.

- For example, if someone gives good ratings for horror movies, this will activate the specific feature for the horror movie genre. And this will be done with a certain function.
- There are different activation functions, we tried the Rectifier Activation function and, the Sigmoid Activation function, and it turns out that we get better results with a Sigmoid activation between the full connections.

```python
self.activation = nn.Sigmoid()
```

So, to get the sigmoid activation, we use nn.Sigmoid(), from the module, we don't need any arguments for it.
Later we can try some combinations of the Rectifier Activation function and Sigmoid Activation, to get better results.
