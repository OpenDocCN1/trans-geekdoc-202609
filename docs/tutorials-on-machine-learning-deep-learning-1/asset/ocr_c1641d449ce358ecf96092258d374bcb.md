So the number of filters we choose here is the feature maps that we want
to create as each will be one feature map created for each filter.

row and column size of filter/feature detector: number of features is not
the only thing we need to choose, we also need to specify row and column
size of filter/feature detector/convolution kernel (convolution kernel is just another
ame for feature detector).

```
cnn_classifier.add(Convolution2D(32, 3, 3,
Here we set no. of filters = 32, row_size = 3, column_size = 3).
```

Why we choose number of filters as 32? Because,
Common Practice is 32: The CNN architectures, the common practice is to start with 32. Our
convolutional layer will be composed of 32 feature maps.

If we start with 32 detectors in the first convolutional layer and then we can add other convolutional layers
more features like 64 then 128 and 256.

We have no GPU; the reason we are working on a CPU.

border_mode (optional): Just to specify how the feature detectors handle the borders of the input image. But most of the
time we choose "same", as the default.

We don't need to input it because default is automatically applied.

input_shape: Very important argument: input_shape is the shape of your input image on which you are going to apply
our feature detectors through the convolution operation.

Since all of our images have the same size, same format and therefore need to force them in some way that we have
same format.

Therefore, by using input_shape will convert all of our images into one same format and therefore one fixed
size of the image.

Remember, we will do this conversion during the Image Pre-processing part, right after we build our CNN and just before
we fit our CNN to our images.
