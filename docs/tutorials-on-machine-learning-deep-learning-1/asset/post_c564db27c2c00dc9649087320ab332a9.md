
## 3.4.4 The Trick

Here we got the Gaussian/ Radial Basis Function (Gaussian RBF kernel) kernel.

### The Gaussian RBF Kernel

```
$K(\vec{x},\vec{l'}) = e^{-\frac{\|\vec{x}-\vec{l}'\|^2}{2\sigma^2}}$
```

- So K stands for kernel and it's the function applied to two vectors $\vec{x}, \vec{l}'$.
- There is some sort of point in our dataset and called Landmark.
- $\vec{l}'$ means there could be several landmarks.
- The double vertical lines mean the distance between $\vec{x}$ and the landmark $\vec{l}'$.
- Sigma acts like radius (variance).

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_107_0.png)

In the figure above, the tip of this observation is right in the middle, when we project it to xy plane, we get the position of the landmark. It is the point from which we're measuring the distance.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_107_1.png)

Let are two points somewhere on our plane. Green one is near the landmark, red one is far from the landmark.

- Red one quite far away from the landmark. So distance is large, hence $\frac{\|\vec{x}-\vec{l}'\|^2}{2\sigma^2}$ is also large. Which makes $K(\vec{x},\vec{l}') \to 0$.
- For the points which are closer to landmark (the green point), distance $\|\vec{x}-\vec{l}'\|$ is small, hence $\frac{\|\vec{x}-\vec{l}'\|^2}{2\sigma^2}$ is also small. Which makes $K(\vec{x},\vec{l}') \to 1$. That's the methodology on how the machine learning algorithm to find an optimal placement for these landmarks.

What's in 2D happening? We're going to use this kernel function to separate our data set to build decision boundary. Let's have a look there is our 2D dimensional space.

Let's go back to the $X_1, X_2$ plane. Now we're going to take the Landmark and put it somewhere in our Dataset.

## 2D Space

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_108_0.png)

After landmark is placed, the algorithm is set to find the optimal circumference/non-linear boundary using $\sigma$. When $\sigma$ increases the boundary spreads, when $\sigma$ decrease boundary shrinks. Kernel function is actually projected here onto our dataset.

All of the points that are within that circumference and have them like assign them a value of above zero (0,1) interval. Anything outside that circumference basically all these red points they'll get a value of 0. In 3d space, points that are within that circumference are lie on the landmark, but the points outside the circumference are very close to zero lies in the blue-colored plane.

Hence, based on this function we can separate the two classes green from the red just if we pick the right Sigma $\sigma$.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_108_1.png)

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_108_2.png)

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_109_0.png)

So basically by **finding the right sigma** you can set up the D values to all of the points that you **don't want** in your classification and values **above zero** to the point that you **do want** in your classification. And that will allow you to **separate the two classes**. Allow you to classify each from one. In essence it is a kernel trick.

- Hence, we have created a **decision boundary** actually going into a higher dimensional space without having to project back to 2D space.
- Here higher dimensional space is used but we're still doing the computations in the low dimensional space.
- Yes we have this visual representation that involves a higher dimensional space but at the same time if you look at the part we were just calculating this formula in 2D.

## 3.4.5 The Kernel Trick with Multiple landmark

Say all of a sudden you can't adjust your decision boundary and it's non-linear and moreover you find yourself being able to solve harder much more complex problems like this for example:

```
$$K(\vec{x},\vec{l}^1) + K(\vec{x},\vec{l}^2)$$
(Simplified Formula)
```

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_109_1.png)

So here is a very simplified formula:

```
$$K(\vec{x},\vec{l}^1) + K(\vec{x},\vec{l}^2)$$
```

- If you take **two kernel function** and just **add them up** (in reality you need some coefficients). The points **far from one landmark** and **near** to **another landmark** then it has non-zero value. The points which are far from **both landmark** is a 0 value. That's it.
- And the formula would be the point is assigned to the **green class**, when this **equation is greater than zero** and the point is assigned to **red class** when this **equation is equal to zero.**

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_110_0.png)

$K(\vec{x}, \vec{l}^1) + K(\vec{x}, \vec{l}^2)$
(Simplified Formula)

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_110_1.png)

$K(\vec{x}, \vec{l}^1) + K(\vec{x}, \vec{l}^2)$
(Simplified Formula)

- Green when: $K(\vec{x}, \vec{l}^1) + K(\vec{x}, \vec{l}^2) > 0$
- Red when: $K(\vec{x}, \vec{l}^1) + K(\vec{x}, \vec{l}^2) = 0$

## 3.4.6 Different types of Kernel Functions

you need to know about the kernel SVM is that the radial basis function also called the Gaussian function is not the only Kernel function that used in this method. So let's look at:

## 3.4.7 Python implementation of the kernelSVM

All code remain same as previous-Algorithm. We just need to change the "Kernel": `kernel="rbf"` instead of `kernel="linear"`

```python
# Library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Data Extraction
dataset = pd.read_csv("Social_Network_Ads.csv")
X = dataset.iloc[:, [2, 3]].values
y = dataset.iloc[:, 4].values

# Scaling after Data Split
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)

# Scaling
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
X_train = sc.fit_transform(X_train)
X_test = sc.transform(X_test)

# Fit train to Kernel-SVM classifier
from sklearn.svm import SVC
# Since data-points are non-arly separable, use "rbf" Gaussian Kernel, gives better result.
classifier = SVC(kernel="rbf", random_state=0)
classifier.fit(X_train, y_train) # fit the dataset

# Predict
y_pred = classifier.predict(X_test)

# Making the confusion matrix use the function "confusion_matrix"
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred)
# parameters of cm: true. Real values, y_pred: Predicted value

# Visualizing the Training results
from matplotlib.pyplot.colors import ListedColormap
from numpy import unique
X_set, y_set = X_train, y_train
X1, X2 = np.meshgrid(np.arange(start=X_set[:,0].min()-1, stop=X_set[:,0].max()+1, step=0.01))

plt.xlabel(alpha=0.5, cmap=ListedColormap('red', 'green'))
plt.xmin(min(y)), plt.ylim(max(y))
for i, j in enumerate(unique(y_set)):
    plt.scatter(X_set[y_set==j], y_set[y_set==j], c=ListedColormap('red', 'green')(i), label=j)
plt.title('Kernel-SVM (Training set)')
plt.xlabel('Age')
plt.ylabel('Estimated Salary')
plt.legend()

# visualizing the Test results
import matplotlib.pyplot as plt
X_test, y_test = X_test, y_test
X1, X2 = np.meshgrid(np.arange(start=X_test[:,0].min(), stop=X_test[:,0].max()+1, step=0.01), 
                      np.arange(start=X_test[:,1].min(), stop=X_test[:,1].max()+1, step=0.01))
plt.contour(X1, X2, classifier.predict(np.array([X1.ravel(), X2.ravel()]).T).reshape(X1.shape), alpha=0.5, cmap=ListedColormap('red', 'green'))
plt.xmin(min(y_test)), plt.ylim(max(y_test))
for i, j in enumerate(unique(y_set)):
    plt.scatter(X_test[y_test==j], y_test[y_test==j], c=ListedColormap('red', 'green')(i), label=j)
plt.title('Kernel-SVM (Test set)')
plt.xlabel('Age')
plt.ylabel('Estimated Salary')
plt.legend()
plt.show()
```
