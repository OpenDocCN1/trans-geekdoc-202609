# 12.3.6 Building the RNN: Structure of our RNN

Now we're going to build the RNN, the whole architecture of our LSTM.

+   - It's not gonna be an LSTM, it's a stacked LSTM with several LSTM layers and we're going to make it perfect.

+   - We're gonna make it robust by adding some dropout regularization to avoid overfitting.

+   - But keep in mind: "All models are rough, but some are useful."

# Libraries and Packages:

```
# importing keras libraries and packages
from keras.models import Sequential
from keras.layers import Dense
from keras.layers import LSTM
from keras.layers import Dropout
```

+   - Sequential will allow us to create a neural network object representing a sequence of layers (other representation is graph).
- Dense class to add the output layer.
- LSTM class, to add the LSTM layers.
- Dropout class to add some dropout regularization.

# Initialize our RNN:

```
# Initialize the RNN
regressor_rnn = Sequential()
```

We're gonna use the Sequential class from keras to initialize our regressor as a sequence of layers. [Since we're dealing with regression problem, we will use 'regressor', for classification problem we use 'classifier'].

+   - This time we're predicting a continuous value, the Google stock price, and therefore we are doing some regression.

+   - Remember, regression is about predicting the continuous value and classification is about predicting a category/class.

We also gonna build Computational Graph in following chapters. But to build some graphs, we use PyTorch, because for this, which is much more powerful tool for dynamic graphs.

Add The Different Layers: Now we add the different layers, to make it a powerful stacked LSTM. We add the first LSTM layer, of our RNN which was introduced as a sequence of layers and add some dropout to avoid Overfitting.

```
# adding first LSTM Layer & some Dropout-Regularization
regressor_rnn.add(LSTM(units=50, return_sequences=True, input_shape=(X.train.shape[1], 1)))
regressor_rnn.add(Dropout(rate=0.2))
```

Inside the add() method, we need to input the layer, the type of layer we want to add.

+   - Since we want to add an LSTM layer, we use LSTM to add first layer (and Dense) to add output layer.

# Parameters:

+   - Units: it is the number of LSTM cells or units in our LSTM layer. We use a very high number of LSTM cells, or memory units, (for simplicity it's just call them neurons).

Why more dimensions: Now already your model will have a very high dimensionality, because we are going to stack many layers. We can increase this dimensionality even by including a larger number of (neurons) in each of the LSTM layers.

+   - Since capturing the trends of a stock price is pretty complex, we need to have this high dimensionality and we also need to have a large number of neurons in each of the multiple LSTM layers.

And therefore, for number of neurons we chose for this first LSTM layer is gonna 50. The next layers, will also have 50 neurons, that we will use a model with high dimensionality and will lead to better results.

+   - return_sequences: we it is True, because we are building a stacked LSTM which has several LSTM layers. When we add another LSTM layer after another, we have to set return_sequences=True.

+   - Once you are done with your LSTM layers, we not not add another layer after that, we will set return_sequences=False, (however we don't have to do it because it's a default value of)
