
## Logarithmic Loss

If we do Classification, the Loss function can be the Logarithmic Loss:

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_255_0.png)

- Since the activation function for output layer is nothing else than the sigmoid function, the Loss-function that we're going to use our ANN and with SGD-adam optimizer is based on: the Logarithmic Loss.
- If your dependent variable has a binary outcome (like here) then Logarithmic-Loss is called 'binary_crossentropy'.
- If your dependent variable has more than two outcomes, like three categories then this logarithmic function is called 'categorical_crossentropy'.

**loss** = "binary_crossentropy"

[3]. **metrics:** it is a criterion that you choose to evaluate your model. Typically we use the 'accuracy' criterion. Basically what happens is, when the weights are updated after each observation or each batch of observations, the algorithm uses this 'accuracy' criterion to improve the models performance.

- When we fit the ANN into our training-set, the accuracy is going to increase little until reaching a peak accuracy and that will happen we choose here the "accuracy" metric.

- Since this metrics argument is to select a list of metrics. But here we use only one metric which is the accuracy metric we need to add this accuracy metric as a list. This will only contain one element which is the accuracy metric.

# Part 1 : Data Preprocessing
# Data Extract
```
dataset = pd.read_csv('Churn_Modelling.csv')
X = dataset.iloc[:, 3:-1] # which we can use
X = dataset.iloc[:, 3:13] # all columns from index 3, excluding 13
y = dataset.iloc[:, 13] # the last column
```

```
# Encode Categorical Data
from sklearn.preprocessing import LabelEncoder, OneHotEncoder
from sklearn.compose import ColumnTransformer
# Encoder "Gender" using LabelEncoder. "Gender" is in 3rd-column
# Following is applicable to numpy array, if used
label_encode = LabelEncoder()
X[:, 2] = label_encode.fit_transform(X[:, 2])
print(X)
```

```python
# For a data set we can still encode using columns "key"
# Encoder "Geography" using OneHotEncoder. "Geography" is in 2nd-column, hence 1
X["Gender"] = label_encode.fit_transform(X["Gender"])
ct = ColumnTransformer(transformers=["encoding", OneHotEncoder(), [1]], remainder='passthrough')
# remainder='passthrough' for remaining columns to be unchanged
X = ct.fit_transform(X)
X = np.array(X) # Convert this output to NumPy array
print(X)
X = X[:, 1:] # Excluding 0-index column to avoid dummy-variable type
```

```python
# Data Split
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
```

```python
# Feature-Scaling after Data Split
# Feature-Scaling
from sklearn.preprocessing import StandardScaler
# y dependent variable, not to be scaled: categorical variable, 0 and 1
st = StandardScaler()
X_train = st.fit_transform(X_train)
X_test = st.fit_transform(X_test)
```

```python
# Part 2 : Creating ANN model
# 1. importing "keras" Libraries and packages
```

```python
# tensorflow import keras
import keras # using TensorFlow backend
from keras.models import Sequential
from keras.layers import Dense
```

```python
# 2. Initialize the ANN
ann_classifier = Sequential()
```

```python
# 3. Add the "Input-Layer" and "First Hidden-Layer"
ann_classifier.add(Dense(output_dim=6, kernel_initializer='uniform', activation='relu', input_dim=11))
ann_classifier.add(Dense(units=6, kernel_initializer='uniform', activation='relu', input_dim=11))
```

```python
# 4. Add the "Second Hidden-Layer"
ann_classifier.add(Dense(units=6, kernel_initializer='uniform', activation='relu'))
```

```python
# 5. Add the "Output-Layer"
ann_classifier.add(Dense(units=1, kernel_initializer='uniform', activation='sigmoid'))
```

```python
# 6. Compile the ANN
ann_classifier.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
```

```python
# 7. Train the model: fit ANN to Training-set (batch_size and epoch)
ann_classifier.fit(X_train, y_train, batch_size=10, epochs=100)
```
