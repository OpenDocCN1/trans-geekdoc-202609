Computing the likelihood of an undirected model or its gradient for inference is in general computationally intensive, and this also holds for RBMs. Then, sampling based methods are employed to approximate the likelihood and its gradient. Sampling from an undirected graphical model is not straightforward, but for RBM Markov chain Monte Carlo (MCMC) methods are easily applicable in the form of Gibbs sampling, which will be introduced in this tutorial along with basic concepts.

After successful learning, an RBM provides a closed-form representation of the distribution underlying the (unseen) observations and to sample from the learnt distribution (e.g., to generate image texture [25,21]), in particular with marginal distributions of interest. For example, we can use visible units corresponding to a partial observation, to solve an image painting task [21].

Boltzmann machines were introduced in the 1980s [1,34]. Compared to the times when they were introduced, RBMs can now be applied to more interesting problems due to increased computational power and the development of new learning strategies [15]. Restricted Boltzmann machines have received a lot of attention recently being proposed as building blocks of multi-layer architectures called deep belief networks (DBNs [19,17]). The idea is that hidden neurons extract relevant features from the observations. These features can serve as input to another RBM. By stacking RBMs in this way, we can learn features at different levels in the hope of arriving at a high level representation.

It is an important property that simple as well as stacked RBMs can be interpreted as deterministic-forward neural networks. They are used as functions from the domain of the observations to the expectations of the latent variables in the top layer. Such a function maps the observations to features, which can, for example, serve as input to a supervised learning system. Further, the neural network corresponding to a trained RBM or DBN can be augmented by another layer, where units in the added layer represent labels. Then the model corresponds to a standard neural network used for regression which can be further trained by supervised learning algorithms [31]. It has been argued that this initialization (or unsupervised pretraining) of the feed-forward network weights based on a generative model helps to overcome problems observed when training multi-layer networks [19].
