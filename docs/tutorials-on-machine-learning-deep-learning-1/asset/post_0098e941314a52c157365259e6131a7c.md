## 2.15 FAQ

Why do we take the squared differences and simply not the absolute differences?

Because the squared differences made it easier to derive a regression line. Indeed, to find that line we need to compute the first derivative of the error function, and it is harder to compute the derivative of absolute values than squared values.

Why didn't we apply Scaling in our Simple Linear Regression model?

It's simply because y is a Linear combination of the Independent variables, the coefficients can adapt their scale to put everything on the same scale. For example if we have two independent variables x1 and x2 and y values between 0 and 1, x1 takes values between 1 and 10 and x2 takes values between 10 and 100, then b1 can be multiplied by 0.1 and b2 can be multiplied by 0.01 so b1 and b2 are all on the same scale.

What does regressor.fit(X_train, y_train) do exactly?

The fit method will use the values of X_train and y_train and then compute the coefficients b0 and b1 of the Simple Linear Regression equation (y = b0 + b1*x). That's the purpose of this fit method.

## 2.2.1 Multiple Linear Regression

There are many cases in which the *response/dependent variable* is affected by more than one *predictor/independent variable*, for such cases, the Multiple Linear Regression algorithm is used.

- Multiple Linear Regression is an extension of Simple Linear regression as it takes **more than** one *predictor variable* to predict the *response variable*.
- Multiple Linear Regression is one of the most important regression algorithms which model the linear relationship between a **dependent continuous variable** and **more than one independent variable**.
- **Example:** Prediction of CO2 emission based on engine size and number of cylinders in a car.
- **Some key points about MLR:**
  - For MLR, the *dependent or target variable Y* must be the continuous/real, but the *predictor or independent variable* may be of continuous or categorical form.
  - Each *feature variable* must *model* the *linear relationship* through a *multidimensional space of data-points*.
- MLR tries to *fit* a linear regression through multidimensional space.
