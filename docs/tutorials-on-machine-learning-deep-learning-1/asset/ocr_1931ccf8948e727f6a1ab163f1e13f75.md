For the Gibbs distribution of an MRF it in general not possible to find the maximum likelihood parameters analytically. Thus, numerical approximation methods have to be used, for example gradient ascent which is described below.

Maximizing the likelihood corresponds to minimizing the distance between the unknown $q$ and the distribution $p$ of the MRF in terms of the Kullback-Leibler-divergence (KL-divergence), which for a finite state space $\Theta$ is given by:

```
$$\mathcal{KL}(q||p) = \sum_{x \in \Theta} q(x) \ln \frac{q(x)}{p(x)} = \sum_{x \in \Theta} q(x) \ln q(x) - \sum_{x \in \Theta} q(x) \ln p(x) \quad$ (5)
```

The KL-divergence is a (non-symmetric) measure of the difference between two distributions. It is always positive and zero if the distributions are the same. By equation (5) the KL-divergence can be expressed as the difference between the entropy of $q$ and a second term. Only the latter depends on the parameters of $p$. Approximating the expectation over $q$ in this term by the training samples from $q$ results in the log-likelihood. Therefore, maximizing the log-likelihood corresponds to minimizing the KL-divergence.

# **Optimization by Gradient Ascent.** it is not possible to find parameters maximizing the likelihood analytically, the usual way to find them is gradient ascent on the log-likelihood. This corresponds to iteratively updating the parameters $\boldsymbol{	heta^{(t)} to $\boldsymbol{	heta^{(t+1)} based on the gradient of the log-likelihood. Let us consider the following update:

```
$$\boldsymbol{	heta^{(t+1)}} = \boldsymbol{	heta^{(t)}} + \eta \frac{\partial \mathcal{L}}{\partial \boldsymbol{	heta}^{(t)}} = \eta \sum_{i=1}^{N} \ln p(x_i|\boldsymbol{	heta^{(t)}}) - \lambda \boldsymbol{	heta^{(t)}} + \nu \boldsymbol{	heta^{(t-1)}} =: \boldsymbol{	heta^{(t)}} \quad$ (6)
```

If the constants $\lambda \in \mathbb{R}^+$ and $\nu \in \mathbb{R}^+$ are set, we have vanilla gradient ascent. The step $\eta \in \mathbb{R}^+$ is the learning rate. As we will see, it can be desirable to strive for models with weights having small absolute values. To achieve this, we can optimize an objective function consisting of the log-likelihood minus the norm of the parameters $||\boldsymbol{	heta}||^2/2$ weighted by $\lambda$.
