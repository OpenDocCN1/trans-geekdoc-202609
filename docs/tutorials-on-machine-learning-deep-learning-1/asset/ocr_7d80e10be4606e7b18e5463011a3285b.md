# 3.6.1 Decision Tree Regression Algorithm

The goal of the Decision Tree Regression Algorithm is to split data into similar groups. The algorithm uses something called Information Entropy, which is a mathematical process (that is super complicated).

+   The point of the algorithm is to split the data in such a way that information is added and stops splitting the data when it's unable to add any more information to the dataset.

+   In the Regression Chapter, we say the 'Decision Tree Regression' predict data of real numbers.
Classification trees help us to classify our data, the categorical variables such as male or female apple or orange or different types of colors and variants of that.
Whereas Regression trees are designed to help you predict outcomes which can be real numbers so for instance the salary of a person or the temperature that's going to be out.

+   In Classification trees, we classify the data and predict categories. Here in this part we will be looking at the approach which is almost identical to that of the Decision Tree Regression.
