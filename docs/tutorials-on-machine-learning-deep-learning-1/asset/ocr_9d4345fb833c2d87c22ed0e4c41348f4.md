p = 0.1: p is floating-point-number in range (0, 1) It is the fraction of the input you want to drop. That's the fraction of the neurons you want to drop, or disable each iteration. In newer version p is replaced with rate.

For example: If we have 10 neurons, if we choose p=0.1 it is 10% that at each iteration, one neuron will be disabled. If we equals p=0.2 two neurons will be disabled.

Which value of P(rate) should we input? The 'p' is replaced with "rate"

+   - Our advice is that when you are overfitting, try starting with p or rate values 0.1,10 and then if it doesn't solve the problem, you are still overfitting until you find a higher value of rate and increment it for example by 0.1

+   - So first try with 0.1 and if you are still overfitting, try with 0.2. If it is still overfitting with 0.3 and use regularization to reduce overfitting

+   - Too high value of rate(p) is bad, when you disable most of the neurons of a layer you'll not get overfitting but underfitting if p=0.9 nothing will be turned off.

+   - And in general we recommend to try with 0.1, then you'll get close to overfitting and that should do it.
