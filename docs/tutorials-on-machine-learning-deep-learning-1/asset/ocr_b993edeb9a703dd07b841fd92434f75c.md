The algorithms going to find optimal splits are going to maximize the number of different points in each one of leaves (leaves are split data pockets, final leaves are actually called a terminal leaves.

Decision Node and Leaf Node: In a Decision tree there are two nodes, which are the Decision Node and Leaf Node.
Decision nodes are used to make any decision and have multiple branches, whereas
Leaf nodes are the output of these decisions and do not contain any further branches. The decisions or the test are performed on basis of features of the given dataset.
