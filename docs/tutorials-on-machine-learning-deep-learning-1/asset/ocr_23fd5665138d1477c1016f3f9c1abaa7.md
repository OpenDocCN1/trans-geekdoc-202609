# 8.3.7 Back-propagation

**Forward propagation:** There's a process called Forward propagation where information is entered into the input layer and then's propagated forward to get our output-value y.

Then we compare those to the actual/value y in our **Training set.**

And then we calculate the errors then the errors are **Back Propagated** through the network in the *opposite direction* and allows us to **adjusting the weights.** of back propagation.

![](bbox=[0.095, 0.153, 0.904, 0.335])

**Back propagation adjusts all the Weights simultaneously:** Back propagation is an advanced driven by very interesting and sophisticated mathematics which allows us to *adjust the weights*. All the weights at the *same time* are adjusted simultaneously.

The huge advantage of **Back propagation** and it is one key thing to remember is that during the process of back propagation, you are able to adjust all the **weights** at the *same time*, because that's how the algorithm is structured. It is the fundamental principle of back propagation.

So you can track which part of the error in the **neural network** is responsible for.

**Adjust Each Of The Weights Independently/independently:** if we were doing this manually or if we were coming up a very different type of algorithm even if we evaluated the error and then we were trying to understand *what effect each of the weights has on* the error then we'd have *adjust each of the weights independently/independently.*
