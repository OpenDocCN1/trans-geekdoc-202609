## 14.4.8 RBM class - __init__()

- We build the architecture of our NN i.e, the architecture of the RBM.
- We'll make a class, which will define the architecture of the RBM.
- And then, we simply create an object of this class, will be the RBM.
- We will choose the number of hidden nodes, and mostly, we will build the new network just like how it works, we're gonna make this Probabilistic Graphical Model. Because, let's remember, RBM is a probabilistic model!

The class we build for RBM will contain following. These are first parameters that we need to initialize RBM using `__init__`:

- The weights.
- The bias for the probability of the visible node, given hidden node.
- The bias for the probability of the visible node, given hidden node.

We also add functions for RBM:

1) One function to `initialize` the RBM object that will be created.
2) Second function will use `sample_H` that sample the probabilities of hidden nodes given visible nodes $P(h|v)$.
3) Third function will use `sample_V`, that sample the probabilities of visible nodes given hidden nodes $P(v|h)$.
4) Fourth function will be `train`, that update contrastive divergence.

`__init__` function is define the parameters of the object that will be created. There are 3 arguments:

- `weight`: corresponds to the object that will be created.
- `nv`: the second argument is `nv`, that is the number of visible nodes.
- `nh`: the third argument is `nh`, that is the number of hidden nodes.

Inside this `__init__` function going to be all the parameters during the training of the RBM:

i. the weights
ii. the bias

Let's start with the weights, we'll call them W. Why capital W? Because all weights are to be initialized in a torch.tensor. We are all the parameters of the probabilities of the visible nodes given hidden nodes $P(v|h)$. According to the theory, they are initialized randomly in a matrix of size `nh`, number of hidden nodes, and `nv`, number of visible nodes. Since we're working with PyTorch, this matrix is going to be a torch.tensor of one type:

```
self.W = torch.randn(nh, nv)
```

Since these weights have to be initialized randomly to a normal distribution, we need to use this `randn()` of PyTorch. `torch.randn(nh, nv)` initializes a tensor of size `nh × nv`. According to a normal distribution, this has the mean of $\theta$ and a variance of 1. That initializes it for the probabilities of the visible nodes given hidden nodes.

- Initialize the bias.
- There is some bias for the probability of the hidden node given visible node $P(h|v)$,
- And some bias for the probability of the visible node given hidden node $P(v|h)$.

bias for $P(h|v)$ the probability of the hidden node given visible node: we're gonna give "a".

```
self.a = torch.randn(1, nh)
```

We're gonna use `randn` function to initialize it according to normal distribution of mean $\theta$ and variance 1. This will be a Tensor of size `1 × nh` (i.e. a vector of size of hidden nodes). Since there is some bias for each hidden node, we have `nh` hidden node, that's why we created a vector of `nh` node initialized to some random numbers that follow a normal distribution. But we need to create an additional dimension to the batch, and therefore, this vector shouldn't have I dimension (a single input vector), it has 2 dimensions:

- The first dimension corresponding to the batch and the second dimension corresponding to the bias.
- It's because that the functions we are gonna of PyTorch cannot accept a single input vector of one dimension as argument, but a two-dimensional tensor with the first dimension corresponding to the batch and the second dimension corresponding to the bias.
- So with that, we **cannot** put directly `nh`.

**torch.randn(1, nh)** creates a 2D tensor with 1 to the first dimension that is the batch. And this *nh* element corresponding to the bias.

- The bias for Probability of the visible node given the hidden node, $p\_v\_given\_h P(v|h)$ : It is as above, we give it a name 'b'.
- This time we use instead of (nh), number of the visible node, while we initializing the tensor we make it a 2D-tensor as we described above.

## 14.4.9 RBM-architecture: RBM class — sample_h()

Now we make the function will sample the hidden nodes. The second function is sampling the hidden nodes according to the probabilities. $P(h|v)$.

- From the section we see that $P(h|v)$ is nothing else than the sigmoid activation function.
- Why do we need this sample_h? Because during the training we will approximate the log likelihood gradient and we will do through Gibbs sampling.
- To apply Gibbs sampling, we need to compute $P(h|v)$, the probabilities of hidden nodes given visible nodes. Once we have this probability, we can sample the activations of the hidden nodes.

We'll call this function *sample_h* because it will return some of the different hidden nodes of RBM.

- Suppose we have 100 hidden nodes in our RBM. Well, this will sample the activations of hidden nodes, that is for each of these 100 hidden nodes, it will activate them to a certain probability that we can use in this same function. And for each hidden node, this probability is $P(h|v)$.

- That, is the probability that this hidden node equals one the values of the visible neurons, $P(1|v)$.

This *sample_h* function takes two arguments, *s* and *x* will correspond to the visible neurons, *v* in the probabilities, **ph** given **v**, i.e. $P(h|v)$.
