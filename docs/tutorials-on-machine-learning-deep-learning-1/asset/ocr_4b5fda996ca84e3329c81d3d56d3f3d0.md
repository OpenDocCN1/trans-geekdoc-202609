![](bbox=[0.135, 0.023, 0.865, 0.203])

If only one input-node is used to create all hidden-node then the reconstructed input-node would be same to input-node.

+   - Since all initial-input-nodes contributed to create each of hidden nodes, and all hidden nodes are trying to reconstruct each of input-nodes. That's why reconstructed input-nodes will not be same as Initial-input-nodes (because indirectly all initial-input-nodes are using to reconstruct an input-node).

+   - That's very important to understand, that's why this Contrastive Divergence process exists.
 The RBM repeats this: feed reconstructed node values of our inputs into the RBM and we're going to get some values for hidden nodes. Based on these hidden values, we're going to reconstruct the inputs again, and again. This whole process is called GIBBS SAMPLING.

+   - At the end, we're going to get some reconstructed input values that when we feed them into the RBM, and then we try to reconstruct them again, we will get those same values. That is the reconstructed input values converges to some values.

![](bbox=[0.115, 0.433, 0.882, 0.603])

In this final scenario, our network is modeling exactly our inputs. So basically, we can input in and we will always get the same output. This process has finally converged and our network is finally trained.
