# 12.4.1 GRU : Gated recurrent units

+   Gated recurrent units (GRUs) are a gating mechanism in RNN, introduced in 2014 by Khyyungh Cho et al. The GRU is a long short-term memory (LSTM) with a Forget gate, but with fewer parameters than LSTM, as lacks an output gate

+   GRU's performance on certain tasks of polyphonic music modeling, speech modeling and natural language processing (NLP) was found to be similar to LSTM.

+   Better for Smaller dataset: GRUs have been shown to exhibit better performance on certain smaller and less frequent datasets.
