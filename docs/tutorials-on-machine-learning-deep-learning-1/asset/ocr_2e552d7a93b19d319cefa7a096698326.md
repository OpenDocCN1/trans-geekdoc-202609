**2] Second Assumption:** [Recall Bayes' Theorem in multiple of Naive Bayes] The second assumption is less stronger than the
one. we assume that $\theta_i$ is a uniform distribution with the prior distribution $p(	heta_i)$.

**3]** Then we use the Bayes Rule to get posterior distribution which is $p(	heta|y)$. Where y gives the rewards that we got up to
 n.

So using Bayes rule that is how we get the $eta$-distribution in **step 2**

```
$p(\theta|y) = (\{number of success} + 1) / (\{number of failure} + 1)$
```

So at each **round** we take a *random draw* from this $\beta$-distribution. These *random draws* are approaching the **probability of success**, we get the maximum of these random draws is approaching the highest probability of
succ. ie. At each round, we select the Ad that has the **highest probability of success** $\theta_i$; $(n)$.

That's the idea Thompson Sampling: We were trying to

+   - Estimate these parameters $\theta_0, \theta_1, \dots, \theta_{10}$, the **probabilities of success**, of each of these **10 Ads**
- By taking these *random draws* and taking the **highest of them** we are estimating the highest probability of success and
this **highest probability of success** corresponds to **one Specific Ad** at each round.

+   - So for small amount of round, we might be wrong, but when we take these *random draws* over thousands of rounds
over all of them that corresponds to the Ad that has the **Highest Probability Of Success** (highest probability of getting
reward = 1).

**c) Step 3:** What we did. Taking the maximum of these random draws that is the maximum of these estimations of the
probability of getting reward equals 1.

Now we implement the strategy of **step 2** and **step 3** in Python. It is much easier than UCB, we just need to use
one method, `random.betavariate()`

+   - The `random.betavariate()` will calculate the $\beta$-distribution for each i-th Ad (ie each of 10 Ad). We then select the
Ad\_i that has maximum value of the calculated $\beta$-distribution.

```
for n in range(0, N):
    slct_ad = 0
    max_random_beta = 0

    for i in range(0, d):
        random_beta = random.betavariate(reward_count_of_ads[i]+1, punish_count_of_ads[i]+1)
        if random_beta > max_random_beta:
            max_random_beta = random_beta
            slct_ad = 1
```

+   - Next we simulate reward/punish and then update Reward and Punishment for Each Ad. We also append the selected Ad
