# 2.2.9 Backward Elimination

When we built it actually used all the independent variables. But among these independent variables there are some that are highly significant. If we removed this non statistically significant variables from the model we would still make some predictions.

**Need for Backward Elimination: An optimal Multiple Linear Regression model**: In the previous section, we discussed and successfully created our Multiple Linear Regression model, where we took k independent variables (R&D spend, Administration spend, Marketing spend, and state (dummy variables)) and one dependent variable (Profit).

> But that is not optimal, as we have all the independent variables and do not know which independent variable is most affecting and which is the least for prediction.

> Unnecessary features increase the complexity of the model. Hence it is to have only the most significant features and keep our simple model to get the better result.

So, in order to optimize the performance of the model, we will use the Backward Elimination method. This process is to optimize the performance of the ML model as it will include the most affecting feature and remove the least affecting feature. Let's start to opt our LR model.
