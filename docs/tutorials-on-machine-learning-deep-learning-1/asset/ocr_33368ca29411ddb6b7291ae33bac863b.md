# 3.5.2 Bayes Classifier Algorithm

+   - Bayes algorithm is a supervised learning algorithm, which is based on Bayes theorem and for solving classification problems (used to classify data with previous classes)
- It is used in text classification that includes a high-dimensional training dataset.

+   - Bayes Classifier is one of the simplest and most effective Classification algorithms which helps in building the fast machine learning models that can make quick predictions.
- It is a probabilistic classifier, which predicts in the basis of the probability of an object.
- Some popular examples of Bayes algorithm are spam filtration, Sentimental analysis, and classifying articles.

# Why is it called Bayes?

+   - The Bayes algorithm is comprised of two words Bayes and Bayes. Which can be described as:
- It is called Bayes because it assumes the occurrence of a certain feature is independent of the occurrence of other features. As if the fruit is identified on the basis of color, shape, and taste, then red, spherical, and sweet fruit is recognized as an Apple.
- Bayes is called because it depends on the principle of Bayes' Theorem.

# Advantages of Bayes Classifier:

+   - Bayes is one of the fastest and most efficient ML algorithms to predict a class of datasets.
- It can be used for Binary as well as Multi-class Classifications.
- It performs well in Multi-class predictions as compared to other Algorithms.
- It is the most popular choice for text classification problems.

# Disadvantages of Bayes Classifier:

+   - Bayes assumes that features are independent or unrelated, so it cannot learn the relationship between features.

# Applications of Bayes Classifier:

+   - It is used for Credit Scoring.
- It is used in medical data classification.
- It can be in real-time predictions because Bayes Classifier is an eager learner.
- It is used in Text classification as Spam filtering and Sentiment analysis.

# Types of Bayes Model: There are three types of Bayes Model, which are given below:

+   - Gaussian: The Gaussian model assumes that follow a normal distribution. In which if predictors take continuous variables instead of discrete, the model assumes that these values are sampled from the Gaussian distribution.

+   - Multinomial: The Multinomial Bayes classifier is used when the data is multinomial distributed. It is primarily used for document classification, which means a particular document to which category as Sports, Politics, education, etc. The classifier uses the frequency of words for the predictors.

+   - Bernoulli: The Bernoulli classifier works similar to the Multinomial classifier, but the predictor variables are the independent Boolean variables. If such a particular word is present or not in a document. This classifier is also famous for document classification tasks.
