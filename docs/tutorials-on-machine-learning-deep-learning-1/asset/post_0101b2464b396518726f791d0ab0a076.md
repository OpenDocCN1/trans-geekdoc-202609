# STEP 3: Among these K neighbors, count the number of data points in each category

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_92_2.png)

# STEP 4: Assign the new data point to the category where you counted the most neighbors

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_92_3.png)

**How to select the value of K in the K-NN Algorithm?** Below some points to remember while selecting the value of K in the K-NN algorithm.

- There is **no particular way** to determine the best value for "K", so we need to **try some values** to find the best of them. the most **preferred** value for K is 5.
- A very low value for K such as K=1 or K=2, can be **noisy** and lead to the effects of **outliers** in the model.
- Large values for K are good, but it may find some difficulties.

# **Advantages of K-NN Algorithm:**

- It is simple to implement.
- It is robust to the noisy training data
- It can be more effective if the training data is large.

# **Disadvantages of K-NN Algorithm:**

- Always needs to determine the value of K which may be complex some.
- The computation cost is high because of calculating the distance between the data points for all training samples.

NOTES:

- K-Nearest is one of the simplest Machine Learning algorithms based on **Supervised Learning** technique.

- K-NN assumes the **similarity** between the **new case/data** and available cases and put the new case into the **category** that is most similar to the **available categories**.
- K-NN algorithm stores all the available data and classifies a new data point based on the **similarity**. This means when new data appears then it can be easily classified into a **well category** by using K-NN algorithm.

- K-NN can be used for **Regression** as well as **Classification** but mostly it is used for the **Classification** problems.

**Parametric Algorithm:** K-NN is a **non-parametric algorithm**, which means it **does not make any assumption** on underlying data.

Lazy learner: it is also a lazy learner because it does not learn from the training set immediately instead stores the dataset and at the time of classification, it performs an action on the dataset.

KNN algorithm at the training phase just stores the dataset and when it gets new data, then it classifies data into a category that is much similar to the new data.

Example: Suppose, we have an image of a creature that looks similar to cat and dog, but we want to know whether it is a cat or dog. So for this identification, we can use the KNN algorithm, as it works on a similarity measure. Our KNN model will find the similar features of the new data set to the cats and dogs images based on the most similar features it will find in either or cat dog category.

```python
# Library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as

# data Extract
dataSet = pd.read_csv("Social_Network_Ads.csv")
X = dataSet.iloc[:, [2, 3]]
y = dataSet.iloc[:, 4]
```

```python
from sklearn.model_selection import train_test_split
# test_size=1/4 of the total observation
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
```

```python
# Feature-Scaling
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
```

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_94_0.png)

Fitting K-NN classifier to the training data: To this we will import KNeighborsClassifier from sklearn library. After importing the class, we will create Classifier object of the class. The Parameter of this class will be:
- n_neighbors: To define the required numbers of algorithm.
- metric='euclidean': This is the default parameter and decides the distance between the points.
- p=2: It is equivalent to the standard metric.

And then we will fit the classifier to the training data. Below is the code for:

```python
# Fitting K-NN classifier to the training set
from sklearn.neighbors import KNeighborsClassifier
cls = KNeighborsClassifier(p=2, metric='euclidean', n_neighbors=5)
cls.fit(X_train, y_train)
```

Predicting the Test Result: To predict the test result, we will get y_pred vector as we did in Logistic Regression. Below is the code for:

```python
# Predicting the test set
y_pred = cls.predict(X_test)
```
