
## 5.16 Types of Association Learning

[1] Apriori Algorithm: Algorithm uses frequent datasets to generate association rules. It is designed to work on the databases that contains transactions. This algorithm uses a Breadth-First and Hash Tree to calculate the items efficiently.

It is used for market basket analysis and helps to understand the products that can be bought. It can also be used in the healthcare field to find drug reactions for patients.

[2] Eclat Algorithm: Eclat algorithm uses for Equivalence Class Transformation. This algorithm uses a depth-first search to find frequent items in a transaction database. It performs faster execution than Apriori Algorithm.

[3] F-p Growth Algorithm: The F-p growth algorithm grows for Frequent Pattern, and it is the improved version of the Apriori Algorithm. It represents the database in the form of a tree structure that is a frequent pattern or tree. The purpose of this tree is to extract the most frequent patterns.

- Application of Association Rule Learning: it has various applications in machine learning and data mining. Below are popular applications of association rule learning:

- Market Basket Analysis: It is one of the examples and applications of association rule mining. This technique is commonly used by retailers to determine the association between items.

- Medical Diagnosis: With the help of association rules, patients can be cured easily, and it helps in identifying the probability of illness for a particular disease.

- Protein Sequence: The association rules help in determining the synthesis of Artificial Proteins. It is also used for Catalog Design and Loss-leader Analysis and many other operations.

What is Frequent Itemset? Frequent itemsets are those whose Support is greater than the Threshold Value or user-specified Minimum Support. It means if A and B are frequent items together, then individually A and B should.

Suppose there are two transactions: A = {1, 2, 3, 4, 5}, and B = {2, 3, 7}, in these two transactions, 2 and 3 are the frequent itemsets.

## Advantages of Apriori Algorithm

- This is easy to understand algorithm

- The join and prune steps of the algorithm can be easily implemented on large datasets.

## Disadvantages of Apriori Algorithm

- The algorithm runs slow when compared to other algorithms.

- The overall performance can be reduced as it scans the database for multiple times.

- The time complexity and space complexity of the Apriori is O(2^D), which is very high Here D represents the horizontal width present in the database.

**Convert-data-set to 'List of Lists'**: So, when we use apriori implementation we need to convert our data-set into 'List of Lists' format. ie. list of customer's bought item-set. It's to require TWO FOR loops re going to loop over all the transactions in the data-set. The first loop has 7500 rows. And the second loop will be to loop over all the products in each of transaction which has 20 columns.

```python
# importing data
dataset = pd.read_csv('Market_Basket_Optimisation.csv', header = None)

# creating 'List of Lists': List of product-set
# then rows of transactions and 20 columns of product
transactions = []
for i in range(len(dataset)):
    for j in range(len(dataset.iloc[0])):
        # We keep the values of the dataset as [i, j]
        # Apriori is also extracting items as strings so we need to convert the data into string
        # when we are creating the list using [j].
        item = str(dataset.values[i, j])
        if item != 'nan':
            if i not in transactions:
                transactions[i] = []
            transactions[i].append(item)
```
