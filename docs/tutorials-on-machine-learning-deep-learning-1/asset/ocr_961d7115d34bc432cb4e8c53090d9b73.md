If you know the distributions, you can just go to the fifth machine and the maximum outcome. But you don't know that in advance.

And your goal is to figure out the best distribution for, with minimum trial! So there are these two factors that are in play:

+   [1] Exploration: But you don't know which of these machines is, you're going to figure it out.

+   [2] Exploitation: But at the time you are already spending your money doing each Trial.

i.e. like the time you take to figure out "the best distribution" there's a tradeoff. The longer you take to figure it out the more you'll probably spend on the wrong ones. Therefore you have to figure it out very quickly.

We call this regret and regret is mathematically defined.

Paper: If you can read more about this in paper: Using Confidence Bounds for Exploitation-Exploration Trade-offs, Peter Auer; Institute for Theoretical Computer Science, Gauss University of Technology.

REGRET: Basically regret is when you are using a non-optimal machine

+   - So whenever you explore the non-optimal machine you have a regret. Which can be quantified as the difference between the best outcome and the non-best outcome. The longer you explore other non-optimal machines the higher REGRET.

+   - But at the same time if you don't explore for long, then a sub-optimal machine might appear as an optimal machine for you. If you don't get the best machine (real optimal).

+   - For instance: if we don't spend enough exploring we might find that the green-colored distribution is the best machine because it's quite a good (but not good as orange one).

So your goal is to find the distribution at the same time to minimize the regret.
