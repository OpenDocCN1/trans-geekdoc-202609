The Elbow technique: For a loop we include for 1 to 10 number of clusters and we calculate WCSS for each of them. After creating the list of WCSS values we plot the Elbow diagram then we select the optimal number of clusters.

```
# finding optimal number of clusters using elbow method : WCSS
from sklearn.cluster import KMeans
wcss = []
for i in range(1, 11):
    # setting cluster for cluster generator
    cluster_generator_elbow = KMeans(n_clusters=i, init='k-means', random_state=0, max_iter=300, n_init=10)
    cluster_generator_elbow.fit(data) # capturing inertia for each cluster i
    wcss.append(cluster_generator_elbow.inertia_)
    # Inertia : Sum of squared distances of samples to their closest cluster. Is actually "wcss"
plt.plot(range(1, 11), wcss, marker='o')
plt.title("The Elbow Method")
plt.xlabel("Number of Clusters")
plt.ylabel("WCSS")
plt.show()
```

We create the object:

```
KMeans(n_clusters=i, init='k-means', random_state=0, max_iter=300, n_init=10)
```

n_clusters: The number of clusters to form as well as the number of centroids to generate. For Elbow method it is a final cluster we will use a fixed number of clusters.

+   - init = 'k-means' is a Method for initialization. k-means++ selects initial clusters for k-mean clustering in a smart way to speed up convergence.

+   - n_init: Number time the k-means algorithm will be run with different centroid seeds. The final results will be the best output of n_init consecutive runs in inertia

+   - max_iter: Maximum number of iterations of the k-means algorithm for a single run.

After fitting we extract the WCSS value using:

```
cluster_generator_elbow.inertia_
```

inertia_ : Sum of squared distances of samples to their closest cluster. Is actually "wcss"
Optimal Number Of Clusters: From the Elbow diagram we notice that, if the number of clusters is more than 5 WCSS doesn't change rapidly. So is the optimal number of clusters.

From the above plot, we can see the elbow point. is at 5. So the number of clusters here will be 5.
