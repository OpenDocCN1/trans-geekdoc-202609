# ## 14.4.7 Prepare Input Data : Convert ratings to binary-rating-tensor

We have to convert these ratings for the RBM. Right now, we have **ratings** from **1** to **5** in our **training set** and **test set**.

+   - Now we have to convert ratings into binary ratings. Because **RBM-recommender system** will generate binary-ratings.
- **1 = liked, or 0 = not liked.**

> Why do we have to convert ratings?
- Because we need to have the binary format **0** or **1**, the **RBM** will take the **input vector**, from this vector, **RBM will predict** the **ratings** for the movies that were **not originally rated** by the user.
- Since these predicted ratings are computed, originally, from the *existing ratings* of the *input vector*, well, then the predicted ratings in the output must have the same *format* as the existing ratings in the **input**.
- Otherwise, this would be inconsistent for the RBM.

+   - Convert all these ratings into binary ratings. **1** or **0** for both the **training set** and the **test set**
- We'll replace all **0** in the original training set, by **-1**. Because the **zeros** in the original training set, corresponded to the movies that were **not rated** by the **users**.
- Now, once **(-1)** will mean that there was no *rating* for a specific movie, given by a specific user.

```
train_set_tensor[train_set_tensor] = -1
```

And in [brackets], we simply added the condition that we want to get these ratings. This is a torch-tensor-operation, that finds all **0**s in the elements of the **tensor** and replace them with "-1"

We're going down for the other ratings, from 1 to 5.

+   - The ratings we want to convert into **zero**, that is, not liked. The movies that were one-star or **two stars**.
- Unfortunately, the "or" doesn't work with torch objects. There is no in **torch.tensor** object that we can apply condition as:

```
test_set_tensor == 1 or (test_set_tensor == 2)
```

+   - The operator does not work like for PyTorch. Why's why we have to do this separately:

```
train_set_tensor[train_set_tensor == 1] = 0
train_set_tensor[train_set_tensor == 2] = 0
```

+   - This **tensor-operations**, finds all **1, 2**s in the **elements** of the **tensor** and replace them with "0"

+   - For the movies that we liked, we make them 1 for those movies that are rated **3** **4** or **5**.

```
train_set_tensor[train_set_tensor >= 3] = 1
```
