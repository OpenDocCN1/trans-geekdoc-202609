## 1.11 Standard Deviation

In statistics, the standard deviation is a measure of amount of variance or dispersion of a set of values. A standard deviation indicates that the values tend to be close to the mean (also called the expected value) of a set, while a high standard deviation indicates that values are spread over average.

Standard deviation may be abbreviated SD, and is most commonly represented in mathematical texts and by the lower case Greek letter sigma or σ, for population standard deviation, or Latin s, for sample deviation.

The standard deviation of a random variable, sample, statistical population, data set, or probability distribution is the square root of its variance. It is algebraically simple, though in practice less robust, than the average absolute deviation. A useful property of the standard deviation is that, unlike variance, it is expressed in the same unit as the data.

Example:
Suppose that the population of interest is eight students in a class. For a finite set of numbers, the population deviation is found by taking the square root of the average of the squared values subtracted from their average value. The marks of each student (that is, a statistical population) are the following values:

```
2, 4, 4, 5, 5, 7, 9
These data points have the mean (average) of 5
$\mu = \frac{2+4+4+5+5+7+9}{8} = 5$
First, calculate the deviations of each data point from the mean, and square the result of:
$\frac{(2-5)^2+(4-5)^2+(4-5)^2+(5-5)^2+(5-5)^2+(7-5)^2+(9-5)^2}{8} = 4$
$\frac{(-3)^2+(-1)^2+(-1)^2+0^2+0^2+2^2+4^2}{8} = 4$
$\frac{9+1+1+0+0+4+16}{8} = 4$
The variance is the mean of these values.
$\sigma^2 = \frac{9+1+1+0+0+4+16}{8} = \frac{32}{8} = 4$
And the population deviation is equal to the square root of the variance:
$\sigma = \sqrt{4}$.
```

In the case where X takes random values from a finite data set $x_1, x_2, \dots, x_n$, with each value having the same probability, the standard deviation is:

$$\sigma = \sqrt{\frac{1}{N}((x_1-\mu)^2 + (x_2-\mu)^2 + \dots + (x_N-\mu)^2)}, \text{ where } \mu = \frac{1}{N}(x_1 + \dots + x_N)}$$

or, by using summation notation:

$$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2}, \text{ where } \mu = \frac{1}{N}\sum_{i=1}^{N}x_i$$

If, instead of having equal probabilities, the values have different probabilities, $x_1$ have probability $p_1$, $x_2$ have probability $p_2$, $\dots x_n$ have probability $p_n$. In this case, the standard deviation will be:

$$\sigma = \sqrt{\int_{X}(x-\mu)^2 p(x)dx}, \text{ where } \mu = \int_{X} xp(x)dx$$
