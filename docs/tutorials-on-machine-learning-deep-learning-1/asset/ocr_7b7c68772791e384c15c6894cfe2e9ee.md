> UPPER CONFIDENCE BOUND ALGORITHM:

+   Step 1: At round n, we consider two numbers for each ad, ad_i
- N_i(n) = The number of the times the ad_i was selected up to round n.
- R_i(n) = The number of rewards of the ad_i, up to round n.

+   Step 2: From these two numbers we compute:
- The average reward of ad_i up to round n

```
r_i(n) = \frac{R_i(n)}{N_i(n)}
```

+   The confidence interval at round n is:
[\hat{r}_i(n) - \Delta_i(n), \hat{r}_i(n) + \Delta_i(n)]

```
Where:
\Delta_i(n) = \sqrt{rac{3 \log(n)}{N_i(n)}}
```

+   Step 3: We select the ad_i that has the maximum UCB, \hat{r}_i(n) + \Delta_i(n).
