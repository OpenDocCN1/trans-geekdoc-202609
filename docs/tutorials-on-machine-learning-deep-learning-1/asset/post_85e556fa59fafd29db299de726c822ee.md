## 3.7.1 Random Forest Classification

Random Forest is a version of ensemble learning (such as gradient boosting). Ensemble learning is when you take multiple algorithms or the same algorithm multiple times and you put them together to make something much more powerful than the original.

How it actually works:

- [1] STEP 1: Pick at random K data points from the Training set.
- [2] STEP 2: build the Decision Tree to associate these K data points.
- [3] STEP 3: Choose the number of Ntree of trees to build and repeat STEPS 1 & 2
- [4] STEP 4: For a new data point, make each of your Ntree predict the value of Y for the data point in question, assign the new data point the average across all of the predicted Y values.

> One of decision trees practical example is Microsoft's Xbox-Body-motion Sensor.

## 3.8.1 False Positives - False Negatives

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_133_0.png)

In our Logistic Regression Function, in terms of the predicted value for the dependent variable (y), we agree that anything below the 50% line will be projected downwards onto the horizontal line (y=0) and anything above the 50% line will be projected upwards onto the 100 percent horizontal line (y=1) and we use them to create this probabilities into actual predictions. Either Yes or No.

Now, let's pick out four values that we really know exist in our data set. And we use them to create this Logistic Regression.

> > Here the actual values of these four observation is Red colored, we then project those in our Logistic curve.
> Now according to 50% horizontal line. Line #2 and #3 observations falls in the wrong "Horizontal line". The error of the model (therefore the logistic regression made two mistakes). The 1st observation #1 and 4th observation #4 are correct predictions.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_133_1.png)

False Positive (Type I error): The first kind of error is the mistaken rejection of a null hypothesis (mistaken rejection of an actually true null hypothesis) as the result of a test procedure. This kind of error is called a type 1 error (false positive) and sometimes called an error of the first kind.

- It means that we predicted a positive outcome but it was false
- In terms of the courtroom example, a type I error corresponds to convicting an innocent defendant.
- The #3 point is predicted as "it will happen", but in reality this "actually not happened". This is kind of "Warning". Predicted as Positive but in reality they are negative. False-Positive.
