
kernel parameter also included in the dictionary as well, to find the best, a linear model or a non-linear (rbf) model. If you are dealing with large-data then it will be very useful for you to decide whether to use a linear or non-linear model.

We're not going to include degree in the dictionary because we won't test if we use polynomial kernel. We're just between linear model and non-linear model.

- gamma is a parameter for nonlinear kernels like 'rbf', 'poly' and 'sigmoid'. Since we are using 'rbf', we'll try to optimize this gamma parameter and find the best value
- The default value is auto and if 1/n features will be used. So we set the values in the range [0, 1].
- Here in this, we have 2 features so that (1/2)=0.5, 0.7 and other values if 0.5 is not the optimal.
- If you have a more features for example 100 features, or 1000 features you can try a smaller number for the gamma parameter until 0.001.

The first option: Grid Search will investigate a linear model that is a classic SVM with a linear kernel. And it will try to find the optimal value for the penalty parameter C.
The second option: Grid Search will investigate the nonlinear model 'rbf' kernel-SVM, and we will tune it, and also find the penalty parameter C.
Eventually we'll get a single combination of all these different parameters and options. And grid-search will find that combination for us.

Applying Grid-search: In this step we are going to implement grid search and we will do that after the list of parameters-dictionary that we created.
We'll create an object of GridSearchCV and we are going to fit this object on our training X_train.

- Parameters of GridSearchCV:
- estimator: This is our SVM-classifier object, so we use estimator = clsfier,
- param_grid: is the list of parameters-dictionary that we want to use using Grid-Search.
param_grid = params_dict
- scoring: The scoring matrix is used to decide the best parameters. We set scoring='accuracy'
- Grid search is going to select the best parameters on one performance matrix.
- It can be the accuracy matrix or it can be the precision matrix, it can be the recall, So it can find different metrics.
- We are going to take the most common one like did for deep learning the accuracy. So , we use scoring='accuracy'
- grid search is going to evaluate the performance of each model with its set of parameters, using K-fold-cross-validation. So we set 10 folds, cv = 10
- The most choice for CV number is 10. Most of the time you'll use 10-fold-cross-validation where you'll get 10 accuracy and 10 accuracy is actually enough to get a relevant idea of the model performance.

These 4-parameters will do the job for grid search. We can also use another parameter:

- n_jobs (optional): If you are working on a very large dataset then use, n_jobs=-1. It will help you the power from your machine.
- means using all processors. it means that you will use all the CPU on your machine and therefore you can run k-fold-cross-validation even in fast case when you are working a very large dataset.(otherwise use None)
