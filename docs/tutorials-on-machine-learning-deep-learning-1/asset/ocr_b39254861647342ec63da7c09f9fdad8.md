By adding new feature variable, $SS_{res}$ may decrease but increase. Hence is never decrease by adding feature variable.

Then how to determine the impact of new feature variable? The solution is to use $R^2$.

# Adjusted $R^2$: Following is the equation for Adjusted $R^2$.

```
$adj R^2 = 1 - (1 - R^2) \frac{n-1}{p-n}$
```

Where $n$ = Sample size, $p$ = number of regression/feature variable.

Penalization factor: Adjusted R-squared has a penalty. For adding independent variables that don't help your model.

+   - As we increase when variable, $p$ increase $1-p$ decreases $rac{n-1}{n-p}$ increases.
- If the new variable doesn't help, then $R^2$ doesn't decrease $(1-R^2)$ $rac{n-1}{n-p}$ increase and adj $R^2$ decrease.
- Here actually $(1-R^2)$ and balance each other. If the new variable helps, then $(1-R^2)$ and $rac{n-1}{n-p}$ decrease and will increase.
