The class we build for RBM, will contain following. These are first parameters that we need to initialize RBM, using `__init__`.

+   * The number of hidden nodes
* The weights.
* The weights for the probability of the visible node, given the hidden node.
* The bias for the same probability
* The bias for the probability of the visible node, given the hidden node.

We also add functions, for a self-driving car we need a lot of functions. *Functions to recognize objects on the street*, some functions to *turn right*, *to left*, to move *forward*, to move *backward*, or to *stop* when there is an obstacle on the street.

We're gonna make 3 functions.

+   1) One function to `initialize` the RBM object that will be created afterwards.
2) Second function will use `sample_H` that sample the probabilities of the hidden nodes given visible nodes. $P(h|v)$.
3) Third function will use `sample_V`, that will sample the probabilities of the visible nodes given the hidden nodes. $P(v|h)$.
4) Fourth function will be `train`, that will update the contrastive divergence.

`__init____: __init__` function is to define the parameters of the object that will be created once the class is. There are 3 arguments:

+   * `weight`: corresponds to the object that will be created afterwards. All the variables that are attached to the object will be created by putting `self` before.
* `nv`: the second argument is `nv`, that is the *number* of *visible nodes*.
* `nh`: the third argument is `nh`, the *number* of *hidden nodes*.

Then we need to initialize the `weight` and the `bias`.

Inside this `__init__` function there going going to be all the parameters that we *optimize* during the training of the *RBM*.

+   i. the *weights* and
ii. the *bias*.

Let's start with the weights, we'll call them W.
Why capital W? Because all *weights* are going to be *initialized* in a *torch.tensor*.
We are all the parameters of the *probabilities* of the visible nodes given the hidden nodes. $P(v|h)$

According to the theory, they are *initialized randomly* in a matrix of size `nh`, number of hidden nodes, and `nv`, the number of visible nodes. Since we're working with *PyTorch*, this matrix is going to be a *torch.tensor* of one single type.

```
self.W = torch.randn(nh, nv)
```

Since these weights have to be *initialized randomly* to a normal distribution, we need to use this `randn()` of *PyTorch*. This `torch.randn(nh, nv)` initializes a tensor of size `nh × nv`. According to a normal distribution, this has has the *mean* of $	heta$ and a *variance* of 1.

That initializes it for the probabilities of the visible nodes given the hidden nodes.

+   * Initialize the bias.
* There is some bias for the probability of the hidden node given the visible node $P(h|v)$, and
* some bias for the probability of the visible node given the hidden node $P(v|h)$.

bias for $P(h|v)$ the probability of the hidden node given the visible node: We're gonna give that "a".
`self.a = torch.randn(1, nh)`

We're gonna use *randn* function to initialize it according to normal distribution of *mean* $	heta$ and *variance* 1. This will be a Tensor of size `1 × nh` (i.e. a vector of size of hidden nodes).
