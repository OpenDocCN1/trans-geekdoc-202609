# 8.4.3 Creating the ann model

Now everything is ready and we can get into making the artificial neural network.

+   - Import Keras and packages: First step is to import the "keras" libraries and the required packages (some of the Keras library to build the Neural Network).

```
# importing "keras" libraries and packages
# from tensorflow import keras
import keras
import keras is using TensorFlow backend
from keras.models import Sequential
from keras.layers import Dense
```

Actually using TensorFlow is back-end. That is the keras library will use the Deep Neural Network based on TensorFlow. We can also use Theano as backend. But TF will be fast.

Also we need to import two modules:

+   - The Sequential module is required to initialize the neural network and
- The Dense module is required to build the layers of the ANN.

Initializing the ANN: initializing the ANN defining it as a Sequence of layers. There are two ways of initializing a Deep Learning model. It's either by defining the sequence of layers or by a graph.

+   - Since we'll make ANN with successive layers (as you will see in previous sections of this chapter), we'll initialize our Deep Learning model by defining it as a Sequence of layers.

We just need to create object of the Sequential class. This object is what we are going to create nothing else than the model itself i.e. the Neural Network that has a role of a Classifier (this NN-model is going to be a classifier) because our problem is a Classification problem where we have to predict a class.

```
ann_classifier = Sequential()
```
