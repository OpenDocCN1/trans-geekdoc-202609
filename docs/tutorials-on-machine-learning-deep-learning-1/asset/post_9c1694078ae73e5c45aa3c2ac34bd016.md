# 8.4.3 Creating ann model

Now everything is ready and we can get into making artificial neural network.

- Import Keras and packages: First step is to import the "keras" libraries and the required packages (some of Keras library to build the Neural Network).

```python
# importing "keras" libraries and packages
from tensorflow import keras

```

Actually using TensorFlow as backend. That is the keras library will use Deep Neural Network based on TensorFlow. We can also use Theano as backend. But TF will be fast.

Also we need to import two modules:

- The Sequential module is required to initialize the neural network
- The Dense module is required to build the layers of the ANN

Initializing the ANN: initializing it as a Sequence of layers. There are two ways of initializing a Deep Learning model. It's either by defining the sequence of layers or by a graph.

- Since we'll make ANN with successive layers (as you will see in previous sections of this chapter), we'll initialize our Deep Learning model by defining it as a Sequence of layers.

We just need to create object of the Sequential class. This object is what we are going to create nothing than the model itself i.e. the Neural Network that has a role of a Classifier (this NN-model is going to be a classifier) because our problem is a Classification problem where we have to predict a class.

```python
ann_classifier = Sequential()
```

So this classifier object is nothing else the future ANN that we're going to build.
We don't need to use any arguments because we define the layers by step afterwards.
We will start with the input Layer and the first Hidden-Layer and we'll add some hidden-layers until well add the output Layer.
So that's how we initialize our Artificial Neural Network Classifier.

INPUT LAYER and first HIDDEN LAYER: We are adding to the first layer of our ANN-model which is the input-layer and the first hidden-layer. Recall the ANN has 7 steps to follow:

# SGD

- STEP 1: Randomly initialise the weights to small numbers close 0 (but not O).
- STEP 2: Input the first observation of your dataset in the input layer, each feature in one node.
- STEP 3: Forward-Propagation from left to right, the neurons are activated in a way that the impact of each neuron's activation is limited by weights. Propagate the activations until the predicted result y.
- STEP 4: Compare the predicted result to the actual result. Measure the generated error.
- STEP 5: Back-Propagation from right to left, the error is back propagated. Update the weights according to how much they are responsible for the error. The learning rate changes by how we update the weights.
- STEP 6: Repeat Steps 1 to 5 and update the weights after each activation (Reinforcement Learning). Or:
Repeat Steps 1 to 5 but update the weights only after a batch of observations (Batch Learning).
- STEP 7: When the training session passed through the ANN, that makes an epoch. Redo more epochs.

[1]. Step-1 randomly initializes the weights of each to small numbers close to 0. Dense model is going to take care of this first step.

[2]: After our first observation in the NN and each feature as an input node. We know the number of the input layer is number of independent variables we have in our Feature-Matrix After preprocessing, we have II independent variables. In our input-layer will have II nodes.
[3]: Is forward propagation. From left to right the neurons are activated by the activation function in such a way that the higher value of the activation function is for the neuron the more that neuron is going to have in the network.

Choosing an activation function: We'll choose the Rectifier-Activation-Function for the Hidden-Layers and the Sigmoid-Activation-Function for the Output-Layer.

The best based on experiments is the rectifier-function for Hidden-layers
