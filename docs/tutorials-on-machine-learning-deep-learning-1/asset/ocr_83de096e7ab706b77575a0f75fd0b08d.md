#  14.1 Problem description

We gonna make a recommender system that will predict if a user is going to like a movie: yes or no. This predicts a binary outcome, For that it is yes or no.

We will build another recommender system that is going to predict the rating of a movie by using Auto Encoders in next chapter (predicts a rating from 1 to 5).

And this way we have the two recommender systems that are mostly used in the industry.

We gonna make the recommender system that predicts a binary outcome, yes or no with Restricted Boltzmann machines (RBM).

Dataset: For these recommended systems (RBM and AE) we're gonna start with the same data set. This is the most real world data set that you can find. It is called MovieLens.

We downloaded the dataset for 100k and 1m. We extract the files in folders: movie_lens_100k and movie_lens_1m.

There are different dataset in MovieLens. In our Project we use 100k and Billion ratings.

The dataset source is MovieLens: https://files.grouplens.org/datasets/movielens/
MovieLens 25 million: https://files.grouplens.org/datasets/movielens/ml-25m.zip
MovieLens 10 million: https://files.grouplens.org/datasets/movielens/ml-10m.zip
MovieLens 1 million: https://files.grouplens.org/datasets/movielens/ml-1m.zip
MovieLens 100k: https://files.grouplens.org/datasets/movielens/ml-100k.zip
