Among the multiple features we need to decide which ones we want to keep and ones we want to throw out (throw out columns).

+   - Two common reasons:
  - Garbage in out: If you throw lots of stuff into your model your model is going to be a garbage model.
    Unnecessary features increase the complexity of the model. Hence it is good to have only the most significant features and keep our model simple to get the better result.
  - Don't make it too complex to explain to Someone: At the end of the day you're going to explain these variables and understand not the math behind them but actually what it means certain variables predict the behavior of your dependent variable and you will have to explain that to people you're presenting to.

Stepwise Regression
Stepwise regression: Sometimes you'll hear step-wise regression. It's actually referred to as 2, 3 and 4 because they are true by step methods.

+   - More generally sometimes Bidirectional Elimination is called the Stepwise Regression because it is combination of Backward Elimination and Forward Selection.

**All-in:** All features are used. No specific feature is selected. When we use

+   - Prior knowledge: If you know prior about exact variables are going to be true predictors of your model (in case you have model before)
- You have some: Somebody gives you those variables and please build a model. Well you don't really have a choice. You just build the model (in case of framework or a company says you have to use these variables).
- Preparing for Backward Elimination: You need to use this method if you're preparing for a backward elimination.

**Backward Elimination:** Start with All Independent Variables and eliminate the rest variables one by one checking the p-values. We keep doing the procedure until we reach a point where the highest P-values are all still less than their significance level

+   - STEP 1: Select a Significance Level SL to stay(e.g. SL = 0.05). We check P-value against this SL.
- STEP 2: Fit the full model with all possible predictors/Independent variable
- STEP 3: Consider the predictor/Independent variable with the highest P-value. If P > SL, go to STEP 4,
- STEP 4: Remove the predictor
- STEP 5: Fit again without this variable. Rebuild and fit the model with the remaining variables.
- STEP 6: Your Model Is Ready
