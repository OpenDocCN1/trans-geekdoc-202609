## 12.2.5 LSTM steps

So we're ready to look into LSTM diagram step by step.

**Step 1:** Here two values enter the LSTM-block. One is input-value $X_t$ and other is the output-value $h_{t-1}$ coming from a previous LSTM-block.

They are **combined, layer-operation $\alpha$** decides whether the value should open or not (i.e. *forget-valve should be closed or somewhat closed/open*)

**Somewhat means to some degree, but not to a Large degree.**

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_391_0.png)

**Step 2:** In 2nd step we get $X_t$ and $h_{t-1}$ again after they first flow parallel, and combined in $\sigma$ or tanh operation. Basically $X_t$ and $h_{t-1}$ are **layers of neurons, $\sigma$ or tanh** which values can pass and cannot or somewhat pass.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_391_1.png)

**Step 3:** Then we've got the **memory flowing through memory pipeline**. We've got the forget valve, **joint-operation and memory valve**, closed.

- If forget valve is opened flow and we're adding in some memory if memory-valve is open.
- Or we can let this whole memory flow through, then keep memory-valve closed, keep forget valve open, the memory won't change.
- Or we can keep forget valve closed and keep memory-valve open, then we can update the memory completely.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_391_2.png)

**Step 4:** Finally we've got these two values $X_t$ and $h_{t-1}$ combined and $\sigma$ decide what part of the **memory pipeline** is going to become output of this **LSTM-module**: it is going to be full-output or partial-output.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_391_3.png)

## Example: Google Translate example for English to Czech.

Now for we consider our Google Translate example. Here we are translating English to Czech. Remember in Czech gender matters. By changing Boy into Girl in Czech we need to change gender related word. Here RNN works as follows:

- If it is Boy then Memory flows freely in the memory pipeline.
- If it is Girl (or female name 'Amanda') Sigmoid-layer-function can detect and Forget-value is closed. Old memory cannot pass through the memory pipeline. Then new memory added via Memory-value.
- In addition we have extracted gender and other data (Capitalized, singular/plural, no of letters etc).
- Output-value extract the information. For example. Gender is extracted and sends this output as the next LSTM-module, that next module can act according to this Gender (change the gender related word).

```python
def cell(self, input, hidden):
    # Cell that robustly activates inside
    gate = sigmoid(self.W_gate + input + self.U_gate + self.b_gate)
    candidate = tanh(self.W_cand + input + self.U_cand + self.b_cand)
    output = sigmoid(self.W_output + input + self.U_output + self.b_output)
    state = gate * tanh(self.W_state + input + self.U_state + self.b_state)
    res = output * candidate
    return res, state
```
