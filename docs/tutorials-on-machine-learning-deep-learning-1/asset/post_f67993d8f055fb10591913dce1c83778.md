### What is Feature Scaling and why we have to do it

Feature Scaling is a technique that will pull all your features in the same range.

- If we have a look at our data, we can clearly see that the values of the age feature are not in the same range as the values of the salary feature.
- The ages from 10 to 100 and salary from 100 to 10000. So these two features are not in the same range and feature scaling consisting of putting the values of these two features in the same range.

### Why we have to apply FEATURE SCALING

Well, when training our models (not all of them), if you have some features that are taking much higher values than other features, it can create a bias in the correlations computations.

- In other words, the features that have high values compared to the other ones will dominate the other features so that the other features might not be considered.
- However, the other features might be having the largest impact on the dependent variable.
- You know the features that actually contribute the most to predicting the outcome.
- The dependent variable and it's very important to pull all the features in the same scale.

### Not all ML needs feature scaling

You will see when we start building ML models that sometimes we have not because some ML models automatically understand that features have lower values than others. Linear regression has coefficients for each of the features and for features having high values will just compensate with a very low coefficient. So for Logistic Regression and SVR we have to apply.

### The Question - NORMALIZE OR STANDARDIZE?

Normalization vs standardization is an eternal question about machine learning.

- **Normalization** is good to use when you know that your data does not follow a Gaussian distribution. This can be useful in algorithms like K-Nearest Neighbors and Neural Networks.
- **Standardization** on the other hand is helpful in cases where the data follows a Gaussian distribution. However, unlike normalization, standardization does not have a bounding range. So if you have outliers in your data it will be affected by standardization.

However, at the end of the day, the choice of using normalization or standardization will depend on your project and the machine learning algorithm you are using. There is no fast rule to tell you to normalize or standardize your data. You can always start by fitting your data and compare the performance for the best results.

## Splitting the Dataset into the Training set and Test set

We need to make different datasets. The training sets for machine learning model to learn and the test set is to test if the ML model learned the correlations.

```python
# Splitting the Dataset: Train and Test
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(old_x, old_y, test_size=0.2, random_state=0)
print(x_train)
print(y_train)
print(x_test)
print(y_test)
```

- **What is Splitting Dataset:** We will split our dataset into two separate datasets, Training-set and Test-set.
- Training-set will use 70% or 80% of data to train our models.
- Other 30% or 20% is the Test-set, which will be used to test our models how well it will predict.

**Why Splitting Dataset:** We always keep test set to avoid the Overfitting. Overfitting is when ML model learns too much from train-set but gives bad prediction.

- **Examples of Overfitting:** Let's say we want to predict if a student will pass an exam. If the model learns the training data by heart, it won't be able to adapt to new sets and situations. This is overfitting which we will be talking about in further details the regression section and how we will learn to use REGULARIZATION techniques to prevent this.
