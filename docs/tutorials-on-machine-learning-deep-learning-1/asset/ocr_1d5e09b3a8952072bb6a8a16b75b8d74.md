# Equation of the Polynomial Regression Model:

+   - Simple Linear Regression equation:
y = $b_0 + b_1x$

+   - Multiple Linear Regression equation:
y = $b_0 + b_1x_1 + b_2x_2 + b_3x_3 + ... + b_nx$

+   - Polynomial Regression equation:
y = $b_0 + b_1x + b_2x^2 + ... + b_nx^n$

> \u2709 We can clearly say that all equations are Polynomial equations but they differ by the degree of variables. The Simple and Multiple Linear equations are also Polynomial equations with a single degree, and the Polynomial regression equation is Linear with the nth degree. (In mathematics Polynomial equations are nonlinear equations. Here in Regression it does not depend on the variables. If we add a degree to our linear equations, it will be converted into Polynomial Linear equations.)
