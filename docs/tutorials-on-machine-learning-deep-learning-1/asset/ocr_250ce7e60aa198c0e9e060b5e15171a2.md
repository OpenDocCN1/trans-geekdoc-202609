```
# library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Data Extract
dataSet = pd.read_csv("Position_Salaries.csv")
X = dataSet.iloc[:, 1:2].values
y = dataSet.iloc[:, 2].values

# Feature-Scaling
from sklearn.preprocessing import StandardScaler
sc_x = StandardScaler()
sc_y = StandardScaler()
X_scaled = sc_x.fit_transform(X)
y_scaled = sc_y.fit_transform(y.reshape(-1, 1))

# Data Split
fit dataset to Random Forest Regression
from sklearn.ensemble import RandomForestRegressor # import class
regressor = RandomForestRegressor(n_estimators=300, random_state=0) # create object
regressor.fit(X, y) # fit the dataset

# Predict
y_pred = regressor.predict([[6.5]])
print("The predictive value for 6.5 is : ", y_pred)

# plot the model
X_grid = np.arange(X.min(), X.max(), 0.01)
X_grid = X_grid.reshape(len(X_grid), 1) # reshape matrix/array
plt.scatter(X, y, color="red")
plt.plot(X_grid, regressor.predict(X_grid), color="green")
plt.title("Truth or Bluff (Random Forest Regression")
plt.xlabel("Position level")
plt.ylabel("Salary")
plt.show()
```

# 2.6.6 FAQ

+   * What is the advantage and drawback of Random Forests to compare to Decision Trees?
  * **Advantage**: Random Forests give you a better predictive power than Decision Trees.
  * **Drawback**: Decision Tree will give you more interpretability than Random Forests, because you can plot the graph of a Decision Tree to see the different splits leading to the prediction, as seen in the Intuition Layer. That's something you can cant with Random Forests.

+   * When to use Random Forest and when to use the other models?
  The best answer to this question is: them all!
  Indeed, to test the models will take you only 10 minutes to try all of the models, which is very little compared to the time dedicated to the parts of a data science project (like Data Preprocessing). So not be scared to try all the regression models and compare the results through cross validation which will be seen in Chapter 10. That's why we gave the maximum models in this course for you to use in your toolkit and increase your chance of getting better results.

+   * If you have some concerns, here are some rules to help you decide which model to use: First, you need to figure out whether your model is **linear or non linear**. You will learn how to do this in **Chapter 10 - Model Selection**.
  * If your model is **linear**, you go for **Simple Regression** if you have only one feature, and **Multiple Linear Regression** if you have several features.
  * If your model is **non linear**, you go for **Polynomial Regression**, **SVR**, **Decision Tree** or **Random Forest**.
