Updating b: we use torch.sum() to calculate the difference between the input vector of observations and the visible nodes after K keep b as a tensor of two dimensions.

We add also zero to keep the format of b as a tensor of two dimensions.

Updating bias: a contains a bias of the probabilities p_h_given_v.

+   - The probabilities that the hidden nodes = I, given the values of v0, the input vector of observations. p(Hi = 1 | v(0)) = ph0
- The probabilities the hidden nodes = I, given the values of vk, that is, the values of the visible nodes after K sampling p(Hi = 1 | v(k)) = phk
- We zero to keep the format of a as a tensor of two dimensions.

```
self.a += torch.sum(ph0 - phk)
```

# Creating the architecture of the Neural Network

```
class RBM():
    def __init__(self, nv, nh):
        self.w = torch.randn(nh, nv)
        self.b = torch.randn(1, nh)
        self.v = torch.randn(1, nv)

def sample_h(self, x):
    wx = torch.mm(x, self.w.t())
    activation = wx + self.b.expand_as(wx)
p_h_given_v = torch.sigmoid(activation)
    return p_h_given_v

def sample_v(self, y):
    wy = torch.mm(y, self.v.t())
    activation = wy + self.a.expand_as(wy)
p_v_given_h = torch.sigmoid(activation)
    return p_v_given_h

def train(self, v0, vk, ph0, phk):
    self.w += torch.mm(v0.t(), ph0) - torch.mm(vk.t(), phk)
    self.b += torch.sum(v0 - vk)
    self.a += torch.sum(ph0 - phk)
```
