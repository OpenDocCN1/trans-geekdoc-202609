DataFrame.iloc
Pure integer-location based indexing for position. .iloc[] is primarily integer position based (from 0 to length-1 of axis), can also be used with a boolean array.

Indexing just the rows:

| With a scalar integer: | df.iloc[0] |
| With a list of integers: | df.iloc[[0, 1]] |
| With a slice: | df.iloc[:3] |

Indexing axes: You can mix the index for the indices and columns. Use z to select the entire axis.

| With scalar integers: | df.iloc[0, 1] |
| With lists of integers: | df.iloc[[0, 2], [1, 3]] |
| With slice objects: | df.iloc[1:3, 0:3] |

Matrix of features and dependent variable:
Matrix of features: Matrix is for slicing.

* ":-1 is to all columns excluding last column
* ":" to select all rows

Dependent variable vector: Vector of last column as dependent variable.
