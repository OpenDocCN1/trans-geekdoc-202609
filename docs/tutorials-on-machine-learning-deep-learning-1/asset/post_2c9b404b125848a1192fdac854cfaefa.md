import numpy as np

# 10. Linear Discriminant Analysis (LDA)

Linear Discriminant Analysis (LDA) is a technique used to reduce data dimensionality by maximizing the differences between multiple known classes of objects. It finds a projection best used to maximize the ratio of between-class-variance to within-class-variance.

- LDA is a projection method onto a lower-dimensional space.
- It is used to find a linear subspace that maximizes the ratio of the between-class variance to the within-class variance.
- It is used for dimensionality reduction technique.
- it is a supervised method because it uses known labels.

## Comparison between PCA and LDA

| Feature | PCA | LDA |
| :--- | :--- | :--- |
| Type | Unsupervised | Supervised |
| Goal | Maximize variance | Maximize between-class separation |
| Usage | General feature extraction | Class classification |

### PCA:
PCA tries to find the directions of the maximum variance in the dataset. In a large feature set, there are many features that are merely duplicate of the other features or have a high correlation with the other features. Such features are basically redundant and can be ignored.

The role of PCA is to find such highly correlated or duplicate features and to come up with a new feature where there is minimum correlation between the features or in which feature set with maximum variance between the features. The variance between the features doesn't depend on the output.

### LDA:
LDA tries to reduce dimensions of the feature set while retaining the information that discriminates output classes. It finds a decision boundary around each cluster as separate from each other as the individual elements within a cluster are as close to the center as possible.

The new features are ranked on their ability to maximize the distance between clusters and minimize the distance between data points within a cluster and their centroids. These new features form the linear discriminants of the feature set.
