## 14.5.1 RBM-model

To create our first RBM object with the parameters: *no. of visible node = nv* and *no. of hidden node = nh*.

- The object will then be initialized when *__init__()* invoked, with biases *a, b* and weight *W*.
- Other functions *sample_h()*, *sample_v()* and *train()* will be used during the training, they will not take any action unless they are called.

*train_tensor[0]* is the length of the first column of *train_tensor*, which corresponds to *movies*. We have 1682 visible nodes.

- of hidden node: Here we can choose any number for *nh*. The hidden nodes correspond to some *features* that are going to be detected by the RBM model. These features will be *GENRE*, *ACTORS*, *DIRECTORS* whether the movie's got an Oscar, etc.
The number of hidden nodes corresponds to the number of features we want to detect.
nh = 100

So let's say we want to start by detecting 100 features. It's actually hard to say right now about the optimal number of features. Our code can *tune it later*.

- Batch size: We already mentioned the concept of batch when we add extra dimension during creation of batch *a & b*. This dimension here represented by 1. So 1 corresponds to the *batch*.
```python
self.a = torch.randn(1, nh)
self.b = torch.randn(1, nv)
```

- When we train our algorithm, we will update the *weights* after *batch observations* (instead of each observation). Each batch will contain some number of observations.
Also this temporary. We can adjust it to improve the model.

- Now, we can set *batch_size = 1*, in that case we're *updating the weights after each observation* going to the network. It will be very slow for large amount of data.

- For fast training we use a large batch size for example *batch_size = 100*. Since we have 943 observations the training will go very fast with batch size = 100.

Finally we create the RBM object with parameters, *nv nh*.

## 14.5.2 Training the RBM-model - part 1

To model each epoch, we use a loop. This loop will run for a specific epoch. We just need to include the different functions (that we made in RBM class) inside for this loop.

We first set the number of our epochs. Let's choose 10 epochs. Because we have only 943 observations and beside we have only binary 0 and 1, the convergence will be reached fast.

```python
# Training the RBM
nb_epoch = 10
for epoch in range(1, nb_epoch + 1):
    train_loss = 0
    s = 0.0
```

- For each epoch, all our observations will go into the network.
- We update the weights after the observation of each batch passed through the network.
- At the end we'll see our final nodes with the new ratings for the movies that were not originally rated.

Inside the loop: Note that, for any learning algorithm we use a loss function to measure the error between the predictions and the real ratings.

- Loss: In this training we will compare the predicted ratings to the ratings of the train.
- Basically we measure the difference between the predicted ratings, that is either 0 or 1, and the real ratings, or 0 or 1.
- For measuring the loss we can use different methods. In RBM we use simple difference in absolute values that measures the absolute difference between the predicted rating and the real rating.
- But the most common loss method is RMSE, the Root Mean Square Error, which is the root of the mean of the squared differences between the predicted ratings and the real ratings. We will use RMSE in next chapter to build AutoEncoders.

```python
train_loss = 0
```

We initialize it to zero, before we started this loss is equal to 0. And then the Loss will increase when we find errors between the predicted ratings and the real ratings. Counter: we will need a counter, we name it "s".

```python

```

To make a floating-number we use 0.0. Or 0., it will work.
