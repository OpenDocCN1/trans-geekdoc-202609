```
# Applying K-folds cross-validation
from sklearn.model_selection import cross_val_score
accuracies = cross_val_score(estimator=clsF, X=X_train, y=y_train, cv=10)

```

> Accuracy vector: Here is our accuracy. The first is 80% but the second is 96% and 80% followed by other accuracies.

+   - It clearly shows, the performance of your model when test-sets vary. Evaluating the model on one test set is not very reliable.
- When we say goal is to take the mean of all these 10 accuracies and that better of our average model-performance of our model.
mean_acc = accuracies.mean()

The mean of these accuracy is actually 90.33. In conclusion this 90% accuracy is the relevant value of our model performance.

+   - Standard Deviation: If we want to perform the analysis, we can also calculate the standard deviation of this accuracy's vector to tell us if there is a high variance or low variance.
std_acc = accuracies.std()

+   - We get a 6.5% standard deviation. This means the differences between the different accuracies and 90.3%.
- That's not too high variance. It means that when we evaluate our model performance, most of the test will be around 84% and 96% so eventually that we are in this low bias and low variance category.
