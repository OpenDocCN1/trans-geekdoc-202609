Split-size: What is the split? What is the proportion of the training set compared to the whole set?
Remember, the original dataset contains 100,000 ratings, and each observation corresponds to one rating. Here in
training-set we have 80,000 observations.

That means we have 80,000 ratings. And therefore, the training
set is 80% of the original dataset of 100,000 ratings.
So that we will have 80%, 20%-train-test split. That's the
optimal train-split to train a model.

The first column (not including index) corresponds to the users, the
