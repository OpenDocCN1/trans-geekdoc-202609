## Need for Backward Elimination: An optimal Linear Regression model
In the previous section, we discussed and successfully created our Linear Regression model where we took variables (R&D spend, Administration spend, Marketing spend) and one dependent variable (Profit). But that is not optimal, as we have all independent variables and do not know which variable is most affecting and which is least unnecessary features increase the complexity of the model. Hence it is to have only the significant features and keep our simple model to get the better result. So, in order to optimize the performance of the model, we will use Backward Elimination. This process is to optimize the performance of the model as it will include the most affecting feature and remove the least affecting.
