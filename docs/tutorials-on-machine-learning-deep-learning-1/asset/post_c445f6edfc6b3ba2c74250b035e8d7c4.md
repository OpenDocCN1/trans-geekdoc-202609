## The Bayes Theorem

We're going to take the Bayes Theorem and we can apply it twice.

**[1] Step 1:** First, we're going to apply it to find out what is the probability that a *person(new data-point)* walks given his features X (i.e. age & salary as features).

```
P(Walks|X) = \frac{P(X|Walks)P(Walks)}{P(X)}
```

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_118_0.png)

**[2] Step 2:** We're going to calculate the probability that somebody drives given features that we see in our **new data-point**. [Probability that a *person(new data-point)* drives given that his features X (i.e. age & salary as features)]

```
P(Drives|X) = \frac{P(X|Drives)P(Drives)}{P(X)}
```

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_118_1.png)


**[3] Step 3:** And finally we're going to compare the probability that somebody WALKS given features versus the probability that somebody DRIVES given features X. Then we'll decide which class to put that new data point in.

```
P(Walks|X) v. P(Drives|X)
```

You can see that the Naive Bayes classifier is a probabilistic type of classifier because we're first calculating the probabilities and based on probabilities we're assigning it to a class.
