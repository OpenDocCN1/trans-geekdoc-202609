
x_train will be the input of the neural network, and y_train, will contain the output.

- For each observation, that is for each financial day, X_train will contain the 60 previous stock prices, before that financial day.

We use a for loop to append data points to x_train and y_train

```python
print(f"Size of train set: {train_set_sliced.shape}")
```

```python
# creating a data structure with 60 time-steps and 1 output
data_size = train_set_sliced.shape[0]
x_train = []
y_train = []

for i in range(60, data_size):
    x_train.append(train_set_sliced[i-60:i, :1]) # append a list of 60 data points in one row and (data_size-60) rows
    y_train.append(train_set_sliced[i, 0])

# Convert x_train and y_train to NumPy
x_train, y_train = np.array(x_train), np.array(y_train)
```

## Implementing Reshape:

- It's actually simple, it just takes one line of code. We're gonna use the reshape() function. Anytime you want to add a dimension in a NumPy array you always need to use the reshape() function. because X_train contains all the inputs of the NN.
- We need to do this for X_train.

Also we need to create this new dimensionality of this new data structure, because this shape is expected by the future RNN that we're gonna build in the next.

- So that's not only for use more indicators, but also to be compatible with the input format/shape of the RNN.

reshape() is taken from NumPy library. In this reshape() function, we need to input two arguments.

- The first argument is our current-data-structure we want to reshape.
- In the second argument we need to specify this new structure. We're gonna include three elements (to add these three dimensions), because our data structure has a NumPy array of 1198 rows and 60 columns.
- After adding a dimension it will be a Stack of 1198 x 60 NumPy array.

```python
# Reshaping
X_train = np.reshape(X_train, (X_train.shape[0], X_train.shape[1], 1))
```

- X_train.shape[0] = no. of rows of X_train = 1198
- X_train.shape[1] = no. of columns of X_train = 60
- No. indicators = 1. We set it

Our 2D array is now the first-layer of a 3D tensor. numpy.reshape gives new shape to array without changing its data. First of all, it needs to know what to reshape, which is the first argument of function (in your case, you want to reshape X_train). Then it needs to know what is the shape of our matrix. This argument needs to be tuple. For 2D you can pass (W, H), for dimensions you can pass (W, H, D) and so on. However, you can also reshape a NumPy matrix by X_train.reshape(W,H,D). In this case, reshape function is method of X_train, you do not have to pass and only pass the new shape. It is also worth noting that the total number of element in matrix with the new shape, match your original matrix. For example, X_train has X_train.shape[0] × X_train.shape[1] elements. This value should be equal to W x H x D.

- First dimension is batch_size, which will correspond to the total number of observations (no. of rows of X_train).
