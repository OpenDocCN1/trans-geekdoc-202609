### Network Architecture

For the purposes of this tutorial I will be discussing two dimensional SOM. The network is created from a 2D lattice of 'nodes', each of which is fully connected to the input layer. Figure 2 shows a very small Kohonen network of 4x4 nodes connected to the input layer (shown in green) representing a two dimensional vector.

### Discover .exe

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_436_1.png)

One of the most interesting aspects of SOMs is that they learn to classify data without supervision. You may already be aware of supervised training techniques such as (typically a multilayer feedforward network) where the training data is labeled and the output is compared with the target vector. If they differ, the weights of the network are adjusted slightly to reduce the error in the output. A SOM however classifies the training data without any external supervision whatsoever. Neat huh?

Before I get on with the nifty stuff, it's best for you to forget everything you may already know about neural network if you try to think in terms of neurons, weights and backpropagation. If you do, you'll get confused quickly. So dip out all that knowledge from your head and shift it to one side before you read any further. Done? Great, let's get on with the tutorial.

> You can download the accompanying source code from here. For those of you who compile the zip file also contains an executable (I wrote a reader, Kinar has also submitted a Java version. You can grab it here).

- We're going to be creating a self-organizing map like this by running the .exe file.
- Once we run it, it will create a SOM, which has, as inputs, these eight colors: red, orange, cyan, light blue, dark green, light green, yellow and magenta.
- So, each of the rows in the data set, is R-G-B code for each of these colors. The output codes are actually normalized on scale on range [0, 1].
- The point is that we have got eight rows on our dataset (B-colors) and each one of them has three columns (R, G, B) and we are going to put them into a SOM.

Once you run it, you will see that there is number of iterations and you can press R to retrain this SOM.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_437_0.png)

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_437_3.png)

- You will notice that it organizes itself every time differently; that's because your weights are initialized at random.
- The main point is: putting a dark blue next to the light blue; and the light green next to the dark green; and most of the time magenta, red, orange-together. That's what we mean that it does preserve topology or it does find and preserve similarities in its data set. So here SOM groups similar colors together.
- Once again, check out the website, at AI Junk, and you will be able to get the codes here, you can actually get it in Java as well. And you can get some lovely examples of how all this works.
- You'll see that self-organizing maps are not hard mathematics and to code.
