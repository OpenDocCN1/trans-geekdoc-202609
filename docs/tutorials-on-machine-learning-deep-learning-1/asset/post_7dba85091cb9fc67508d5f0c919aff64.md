
## Step 3: Select the i-th Ad that has the maximum UCB_upper_conf_bound

For this we will create a vector/list which contains selected Ad for all 10,000 trials. So we'll create an empty list:
**ads_selected = []**

**ads_selected** is a vector of 10000 elements and each of these elements will be the Ad that was *selected* at each round. We are going to append this by the UCB **ads_selected**.

Now the question is how we are going to append the different versions of the Ad in this **ads_selected** vector?
So we created **max_upper_bound** and initialize it for each trial/round(i.e. it is inside 1st forloop).
But we also need to keep **track** of the index of the Ad that has the **max_upper_bound**. So that we can identify an Ad for selection. Here we will use **ad_max_ucb = i**.

```python
for n in range (a, N):
    ad_max_ucb = 0
    max_upper_bound = 0
    for i in range (n, d):
        avg_reward = numbers_of_selections[i]/numbers_of_selections[i]
        delta = math.sqrt(3*math.log(n))/(numbers_of_selections[i])
        upper_conf_bound = avg_reward + delta
        if upper_conf_bound > max_upper_bound:
            max_upper_bound = upper_conf_bound
            ad_max_ucb = i
```

At the beginning we know only the first d rounds (generally first d rounds) we don't have information about the Ads. We don't have information about their **reward**.

- Basically for first 10 Ads we select them fairly (not randomly), i.e. at round 1 Ad is selected, round 2 and so up to 10th, after 10th round/trial we are using UCB.
- To implement this, we use an **if-else** condition inside the second forloop [i]. And under else condition we use a very large **upper_conf_bound**.

## Starting Select Ads to selected_ads, tracking numbers_of_selections, numbers_of_rewards and calculating the total_reward

```python
# Reinforcement Learning : UCB, Select an by Click on Ad
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# importing dataset
dataSet = pd.read_csv("Ads_CTR_Optimisation.csv")

# UCB Implementation.
# 3 parameters are important:
# no. of bandit, d
# No. of trials, N
# initial max_upper_bound (1e400)
import math
# here is d. No. of Ads or Number of Bandits
d = 10
N = 10000 # Total number of trials

numbers_of_selections = [0]*d
numbers_of_rewards = [0]*d
selected_ads = []
total_reward = 0

for n in range(0, N):
    ad_max_ucb = 0
    max_upper_bound = 0

    for i in range(d):
        if numbers_of_selections[i] > 0:
            avg_reward = numbers_of_rewards[i]/numbers_of_selections[i]
            log_n = math.log(n+1)
            delta = math.sqrt(log_n)*(2/numbers_of_selections[i])
            upper_conf = avg_reward + delta
        else:
            upper_conf = 1e400 # i.e. 10^400

        if upper_conf > max_upper_bound:
            max_upper_bound = upper_conf
            ad_max_ucb = i

# storing selected Ad
selected_ads.append(ad_max_ucb)

# updating "numbers_of_selections" and "numbers_of_rewards" of selected Ad "ad_max_ucb"
numbers_of_selections[ad_max_ucb] += 1
reward = dataSet.values[n, ad_max_ucb] # generating reward-simulation from given Dataset
numbers_of_rewards[ad_max_ucb] += reward

total_reward += reward

# python print_UCB
```
