# 4 Restricted Boltzmann Machines

A RBM (also denoted as Harmonium) is an MRF associated with a bipartite undirected graph as shown in Fig. 1. It consists of $m$ visible units $\mathbf{V} = (v_1, ..., v_m)$ to represent observable data and $n$ hidden units $\mathbf{H} = (h_1, ..., h_n)$ to capture dependencies between observed variables. In binary RBMs, in this tutorial, the variables $(\mathbf{V}, \mathbf{H})$ take values in $\{0,1\}^{m+n}$ and the joint probability distribution over the model is given by the Gibbs distribution $p(\mathbf{v}, \mathbf{h}) \propto e^{-E(\mathbf{v, h)}}$ with the energy function

```
$E(\mathbf{v}, \mathbf{h}) = -\sum_{i=1}^m\sum_{j=1}^n w_{ij}v_ih_j - \sum_{j=1}^m b_jv_j - \sum_{i=1}^n c_ih_i. \quad (20)$
```

For all $i \in \{1,...,n\}$ and $j \in \{1,...,m\}$, $w_{ij}$ is a real valued weight associated with the edge between units $v_j$ and $h_i$, and $b_j$ and $c_i$ are real valued bias terms associated with the $j$th visible variable and the $i$th hidden variable, respectively.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_564_0.png)

Fig. 1. The undirected graph of an RBM with $n$ hidden and $m$ visible variables

The graph of an RBM has only connections between the layer of hidden and visible variables but not between two variables of the same. In terms of probability this means that the hidden variables are independent given the state of the visible variables and vice versa:

$p(\mathbf{h}|v) = \prod_{i=1}^n p(h_i|v) \text{ and } p(v|h) = \prod_{j=1}^m p(v_j|h) . \quad (21)$

The absence of connections between hidden variables makes the marginal distribution (7) of the variables easy to calculate:

```
$p(v) = \frac{1}{2}\sum_{i=1}^n p(v,h) = \frac{1}{2}\sum_{i=1}^n e^{-E(v,h)}\n= \frac{1}{2}\sum_{h_1}.....\sum_{h_n} \prod_{j=1}^n b_{j v_j} \prod_{j=1}^m (e^{c_j + \sum_{i=1}^n w_{ij}v_j})\n= \frac{1}{2}\sum_{h_1}...\sum_{h_n} \prod_{i=1}^n e^{h_i (\sum_{j=1}^m w_{ij}v_j)} \prod_{j=1}^m (e^{c_j + \sum_{i=1}^n w_{ij}v_j})^{h_j}\n= \frac{1}{2}\prod_{i=1}^n b_{i v_i} \prod_{j=1}^m (1+e^{c_j + \sum_{i=1}^n w_{ij}v_j}) \quad \quad (22)$
```

This equation shows why a (marginalized) RBM can be regarded as a *product of experts* model [15,39], in which number of "experts" for individual components of the observations are combined multiplicatively.

Any distribution $\{0,1\}^m$ can be modeled arbitrarily well by an RBM with $m$ visible and $k+1$ units, where $k$ denotes the cardinality of the support set that have a non-zero probability of being observed [24]. It has been shown recently that even less units can be sufficient depending on the patterns in the support set [30].

The RBM can be interpreted as a stochastic neural network, where nodes and edges correspond to neurons and synaptic connections, respectively. The conditional probability of a single variable being one can be interpreted as the firing rate of a (stochastic) neuron with sigmoid activation function $\sigma(x) = 1/(1+e^{-x})$, because it:

```
$p(H_i=1|v)=\sigma(\sum_{j=1}^m w_{ij}v_j+c_i) \quad (23)$
```

and

```
$p(V_j=1|h)=\sigma(\sum_{i=1}^n w_{ij}h_i+b_j) \quad (24)$
```

So we let $v_{-l}$ denote the state of all visible units except the $l$th one and let us define

```
$\alpha_l(h) := -\sum_{i=1}^n w_{il}h_i - b_l \quad (25)$
```

and

```
$\beta(v_{-l},h) = -\sum_{i=1,j\neq l}^m w_{ij}h_j \quad (26)$
```

Then $E(v,h) = \beta(v_{-l},h) + \alpha_l(h)$, where $\alpha_l(h)$ collects all terms involving $l$ and we can write:

```
$p(V_l=1|h) = \frac{p(V_l=1,v_{-l})}{p(v_{-l},h)} = \frac{e^{-E(V_l=1,v_{-l})}}{e^{-E(V_l=1,v_{-l})} + e^{-E(V_l=0,v_{-l})}}} = \frac{e^{-\beta(v_{-l},h)-\alpha_l(h)}}{e^{-\beta(v_{-l},h)-\alpha_l(h)} + e^{-\beta(v_{-l},h)}} = \frac{1}{1+e^{\alpha_l(h)}} = \sigma(-\alpha_l(h)) = \sigma(\sum_{i=1}^n w_{il}h_i + b_l) \quad (27)$
```

The independence between variables in one layer makes Gibbs sampling especially easy; instead of sampling new values for all variables, the states of all variables in one layer can be sampled jointly. Thus, Gibbs sampling can be performed in just two steps: sampling a new state $h$ for the hidden neurons from the visible layer by $p(v|h)$. This is also referred as *Gibbs sampling*.

As mentioned before, an RBM can be reinterpreted as a standard feed-forward neural network with non-linear units. This perspective RBM is viewed as a deterministic function $\{0,1\}^m\to\mathbb{R}^n$ that maps an input $v\in\{0,1\}^m$ to $y\in\mathbb{R}^n$ with $y_i = p(H_i=1|v)$. That is, an observation is mapped to the expected value of the hidden neurons given the observation.

# 4.1 The Gradient of the Log-Likelihood

The log-likelihood gradient of an MRF can be written as the sum of two expectations, see (9). For RBMs the first term of (9) (i.e. the expectation of the energy gradient under the conditional distribution of the hidden variables given a training sample $v$) can be computed efficiently because it factorizes nicely. For example w.r.t. the parameter $w_{ij}$ we get:

```
$$\sum_{h} p(h \mid v) = \frac{\partial E(v, h)}{\partial w_{ij}} = \sum_{h} p(h \mid v)h_i v_j$$
$$= \sum_{k=1}^{n} p(k \mid v)h_i v_j = \sum_{h_i} \sum_{h_{-i}} p(h_i \mid v)p(h_{-i} \mid v)v_j$$
$$= \sum_{h_i} p(h_i \mid v)h_i v_j = p(H_i=1)v_j = \sigma(\sum_{j=1}^{m} w_{ij}v_j + c_i)v_j \quad (28)$$
```

Since the second term in (9) can also be seen as $\sum_{v} p(h \mid v)\frac{\partial E(v,h)}{\partial theta}$ we can reduce its computational complexity by applying the same factorization to the inner sum, either factorizing the hidden variables or over the visible variables in an analogous way. However, the computation remains intractable for regular sized RBMs because the complexity is still exponential in the size of the smallest layer (the sum runs over either 2 or $l^2$ states).

Using the factorization trick (2) the derivative of the log-likelihood of a single training pattern w.r.t. the weight $w_{ij}$ becomes:

```
$$\frac{\partial \mathcal{L}(\theta \mid v)}{\partial w_{ij}} = \sum_{h} p(h \mid v)\frac{\partial E(v,h)}{\partial w_{ij}} + \sum_{v'} p(v' \mid v)\frac{\partial E(v,v')}{\partial w_{ij}}$$
$$= \sum_{h} p(h \mid v)h_i v_j - \sum_{v} p(v \mid v)p(h \mid v)h_i v_j$$
$$= p(H_i=1 \mid v)v_j - \sum_{v} p(v \mid 1)v_j \quad (29)$$
```

For the mean of this derivative over a training set $S = \{v_1, \dots, v_{\ell}\}$ often the following are used:

```
$$\frac{\partial \mathcal{L}(\theta \mid v)}{\partial w_{ij}} = \frac{1}{|S|} \sum_{v \in S} \left[ \sum_{h} p(h \mid v)\frac{\partial E(v,h)}{\partial w_{ij}} + \sum_{v'} p(v' \mid v)\frac{\partial E(v,v')}{\partial w_{ij}} \right]$$
$$= \frac{1}{|S|} \sum_{v \in S} \left[ p(H_i=1 \mid v)v_j - \sum_{v'} p(v' \mid v)v_j \right] \quad (30)$$
```
