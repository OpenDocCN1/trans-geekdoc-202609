**input_shape**: is exactly the shape of the input containing **X_train** that we created in the last step of the preprocessing part, corresponding to the **observations**, the **time_steps**, and the **indicators**.

But in this third argument of the LSTM class, we need to include all three dimensions, only the **time_steps** and the **indicators**.

i.e. from (X.shape[0], X.shape[1]) we need to input (**X.shape[1], 1**). The first X.shape[0] corresponds to the observations, will be automatically taken into account.

**Adding Dropout-Regularization**: We recommend to use 20% it because it's relevant. 20% of the neurons 10 out of 50 neurons of the LSTM, will be ignored during training, the forward propagation and backpropagation.

```
regressor_nn.add(Dropout(rate = 0.2))
```

We're gonna add a total of **4 LSTM layers**, so that will make a big stacked LSTM.

# 13.2.7 Building the RNN: extra LSTM layers

Now we add some **extra LSTM layers**, with dropout regularization.

+   **Adding 2nd LSTM layer**: We only need to change one, which is the **input_shape**.

```
regressor_nn.add(LSTM(units=50, return_sequences=True)
regressor_nn.add(Dropout(rate = 0.2))
```

> We had to specify **input_shape** in first layer but we don't need it for the **second layer**, because it's recognized automatically. Then in this units argument, we tell exactly that we have 50 neurons in the **previous layer**: So no need to specify any **input_shape** when you're adding your next layers, after the first one.

> 50 neurons in **hidden layer** also make **high dimensionality** to our model, but we are able to handle the **complexity** of the problem.

> Augmenting the dimensionality of our model, will augment at the same time the complexity, and therefore will **respond to better results**.

> We're keeping a 20% dropout for the regularization, since that's a relevant choice.

+   **Adding 3rd LSTM layer**: We only need to copy the 2nd LSTM layer. All are just same.

```
regressor_nn.add(LSTM(units=50, return_sequences=True)
regressor_nn.add(Dropout(rate = 0.2))
```

+   **Adding 4th LSTM layer**: We only need to copy the **2nd LSTM layer**. The parameter **return_sequences** is set to **False** because the **last LSTM layer** and next is the output layer.

```
regressor_nn.add(LSTM(units=50, return_sequences=False))
```

Because we are **not going to return any sequences**, since, the default value of the **return_sequences** parameter is False, we are removing this one.

Be careful, this is the **final layer** of our RNN, this is the fourth LSTM layer, but after that, the output comes, with the output dimension, **units** is 1 of course, because we're predicting just one **value**, of the **stock price at time T+1**

```
regressor_nn.add(LSTM(units=50))
regressor_nn.add(Dropout(rate = 0.2))
```

However we can specify the number of **neurons** in the **LSTM layers**, and we're keeping **50 neurons** to have the same goal of a high dimensionality.

Also we're **keeping the 20% dropout regularization**. We can also change that.
