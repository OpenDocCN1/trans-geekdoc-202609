Goal: To create a model that can easily determine which company has a maximum profit, and which is the most affecting factor for the profit of a company.

Since we need to fit the Profit, it is the dependent/target variable, and the other four variables are independent variables. We are the main steps of deploying the MLR model:

2. Fitting the MLR model to the training set

We analyze these 50 companies with this dataset and create a model that will tell which types of companies we should invest and our main criterion is profit.
What we are looking for: we want to understand for instance where companies perform better in New York or California if all things hold equal which companies perform better if you hold their cards.
What we want to know:
