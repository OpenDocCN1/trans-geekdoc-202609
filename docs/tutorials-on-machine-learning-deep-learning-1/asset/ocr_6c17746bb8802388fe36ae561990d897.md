Step 3: We're going to compare the probability that somebody WALKS given X versus the probability that somebody DRIVES given X.

| P(Walks | X) = P(Walks) / P(X) | P(Drives | X) = P(Drives) / P(X) |
|---|---|
| #3 Likelihood | #1 Prior Probability | #4 Posterior Probability | #1 Prior Probability |
| 3/10/30 P(Walks|X) = 0.75 | 20/20/30 P(Drives|X) = 0.25 |
| #2 Marginal Likelihood | #2 Marginal Likelihood |

# P(Walks|X) v.s. P(Drives|X)
0.75 > 0.25

Since in this case the probability of the data-point walking is greater than driving we can say that the data point is assigned to walking.

Therefore it is more likely that the person with given features X is going to be a person who walks to work than the person who drives to work.

That is how the Naive Bayes Algorithm in ML works.

+   - Why Naive? Because we assume that the features (age and Salary) are independent.

+   - We can actually drop P(). But it is good to perform full calculation. Sometimes the shortcut is used. It is ok when we are comparing but when we calculate the Posterior Probability values, we need to follow the full calculations.

| P(Walks) * P(Walks) / P(X) | P(Drives) * P(Drives) / P(X) |

+   - More than 2 classes: We need to compare all possible pair of cases.
