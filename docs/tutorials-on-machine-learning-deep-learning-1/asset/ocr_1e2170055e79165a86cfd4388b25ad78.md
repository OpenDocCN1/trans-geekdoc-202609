If you want to plot decision tree like the real tree itself then you can remove this feature scaling part from there to have interpretation of your values.

**Parameters:**

criterion: {"gini", "entropy"}, default="gini"

The function to measure the quality of a split. Supported criteria are "gini" for the Gini impurity and "entropy" for the information gain.

Most useful classifier and common decision tree is based on **Entropy**, eg: ***Maximum Entropy*** for NLP.

So that the final nodes of tree be to be as homogeneous as possible. if each split the more homogeneous is a group of users, the more the entropy is reduced from the parent node to the group child node.

So after the split if the entropy in the resulting node is choice then that this node is a fully homogeneous group of users (only users of the same class) and the information mentioned here is basically the difference between the entropies before and after.
