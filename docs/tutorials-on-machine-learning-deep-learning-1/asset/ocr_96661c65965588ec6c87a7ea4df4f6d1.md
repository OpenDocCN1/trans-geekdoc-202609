# 2.1.1 What is Simple Linear Regression

**Simple Linear Regression** is a type of Regression algorithms that models the *relationship between a dependent variable* and a *single independent variable*. The relationship shown by Simple Linear Regression model is linear or a *sloped straight line*, hence it is called Simple Linear Regression.

```
y = b_0 + b_1x + \epsilon
```

x = independent variable
y = dependent variable

b_0 = It is the **intercept** of the Regression line (can be obtained putting x=0) with y-axis. Eg: Minimum salary for Fresher.
b_1 = It is the **slope** of the regression line, which tells whether the line is increasing or decreasing.
ε = The **Error** term. (For a good model it will be negligible)

The key point in Simple Linear Regression is that the *dependent variable* must be a continuous/real value. However, the *independent variable* can be measured on continuous or categorical values.

# 2.1.2 Finding the Best fitting line

The algorithm finds a line for which

```
minimize \sum_{i=0}^n (y_i - \hat{y}_i)^2
```

Where y_i are the given points (x_i, y_i), i = 0, 1, 2, ..., n.
And \hat{y}_i = b_0 + b_1x_i, where i = 0, 1, 2, ..., n
