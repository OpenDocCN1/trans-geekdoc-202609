### 5.1.1 Association Rule Learning
Association rule learning is a type of Unsupervised Learning Technique that checks for the DEPENDENCY of one data-item on another data-item and maps accordingly so that it can be more profitable.

+   - tries to find some interesting relations or associations among the variables of dataset. It is based on different rules to discover the interesting relations between the variables.

+   It is employed in:
[1] Basket Analysis: For example, if a customer buys bread he must also buy butter, eggs, or milk, so these products are stored within a shelf or nearly nearly.
[2] Web mining
[3] Recommendation system
[4] Continuous production, etc.
