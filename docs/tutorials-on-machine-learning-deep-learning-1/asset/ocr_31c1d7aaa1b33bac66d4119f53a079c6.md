**Data-preprocess_for-Test before prediction**: This is last bit tricky. There are some important tricks that we will make sure to understand and, and some matters to absolutely avoid.

+   - Here we used our regressor, and we trained our model to predict the stock price at time T+1, based on the 60 previous stock prices, and therefore, to predict each stock price of each financial day of January, 2017, and we will need the 60 previous stocks of the 60 financial days, before the actual day.
- But the thing is, when we get each day of 2007, the 207 stock prices of the 60 previous days, we will need both the training set and the test set, because we have some of the 60 days that will be from training set, because will be from December 2006, and we will also have some stock prices of the test set because they will come from January 2007.
- We need to do some concatenation of the training set and the test set.

**How we concatenate**: if you are thinking of this by concatenating the training-set "training_set" and the test-set "real_stock_price", it will lead to a problem and we will have to re-scale the result(we) to apply the fit_transform method again. We should never do this, however to keep the actual values as you want to.

+   - The trick is here, we concatenate the original DataFrames, dataset_train and dataset_test.
- From this concatenation, we get the input of each prediction. Then we will scale it by our sc object. That's the way we are only scaling the input and not changing the actual test values.
- We have to scale the input, because our RNN model was trained on the scaled values of train data. That's why we scaled input to our predictions.
- The scaled input should be based on the same scaling normalization with our sc object.

**dataset_total** will contain all the concatenated dataset. We're gonna concat() function from our Pandas library.

+   We need to import arguments:
- The first one are the DataFrames we concatenate.
- The second argument is the axis which we want to make that concatenation. do we want to concatenate the lines/rows-wise? Or we want to concatenate the column-wise
