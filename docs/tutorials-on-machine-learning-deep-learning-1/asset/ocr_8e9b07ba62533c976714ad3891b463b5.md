$$\sigma = \sqrt{\frac{1}{N}((x_1-\mu)^2 + (x_2-\mu)^2 + \dots + (x_N-\mu)^2)}, \text{ where } \mu = \frac{1}{N}(x_1 + \dots + x_N)$$$

or, by using summation notation:

$$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2}, \text{ where } \mu = \frac{1}{N}\sum_{i=1}^{N}x_i$$

If, instead of having equal probabilities, the values have different probabilities, $x_1$ have probability $p_1$, $x_2$ have probability $p_2$, $\dots x_n$ have probability $p_n$. In this case, the standard deviation will be

$$\sigma = \sqrt{\int_{X}(x-\mu)^2 p(x)dx}, \text{ where } \mu = \int_{X} xp(x)dx$$
