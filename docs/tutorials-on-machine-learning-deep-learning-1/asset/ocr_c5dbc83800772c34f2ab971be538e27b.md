x_train will be the input of the neural network, and y_train, will contain the output.

+   - For each observation, that is for each financial day, X_train will contain the 60 previos stock prices, before that
financial day.

+   - y_train will contain the stock price the next financial day.

We use a for loop to append data points to x_train and y_train

```
print(f"Size of train set: {train_set_sliced.shape}")
print(f"No. of data points: {train_set_sliced.shape[0]}")
```

```
# creating a data structure with 60 time-steps and 1 output
data_size = train_set_sliced.shape[0]
x_train = []
y_train = []

for i in range(60, data_size):
x_train.append(train_set_sliced[i-60:i, :1]) # append a list of 60 data points in one row and (data_size-60) rows
y_train.append(train_set_sliced[i, 0])

# Convert x_train and y_train to NumPy
x_train, y_train = np.array(x_train), np.array(y_train)
```

We see the 60 stock prices in X_train, and the next stock price in y_train

+   - In y_train[i] is the 61st data point, 62nd data point and so.
- In each n-th element is the last element of X_train(n+1)-th row.
- So there are 1258-60 = 1198 times, and as time step i-stride the row's element move-stride to the left.

The first line of observation corresponds to time T = 60. At the 60th day of our training dataset.

+   - Because here we're getting the 60 stock prices before T = 60, and in 2nd row, the 60 stock prices for T = 61, hence we have 59 stock prices in common.
- Because we have this sliding window of 60, sliding with a stride of 01 at each observation, from observation to the next

That's exactly the role of the RNN. It is memorizing what's happening in the 60 previous timesteps to predict the next value at T+1.

That's practice, the data structure we need to create as the input of a RNN.
