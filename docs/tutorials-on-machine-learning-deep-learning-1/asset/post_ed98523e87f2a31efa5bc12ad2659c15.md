```python
# Library
import pandas as pd

y = dataset.iloc[:, 4].values

# Data Split
from sklearn.model_selection import train_test_split

# Feature-Scaling
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
X_train = sc.fit_transform(X_train)
X_test = sc.transform(X_test)

# linear data-points are non-separable, use "rbf" : Gaussian kernel gives better result.
kernel="rbf" instead of "linear"
clf = SVC(kernel='rbf', random_state=0)
clf.fit(X_train, y_train)

# Predict
y_pred = clf.predict(X_test)
# Making the confusion matrix use the "confusion_matrix"
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred, y_pred)
# parameters x=y_true: Real values, y_pred: Predicted value

# Applying K-fold cross-validation
from sklearn.model_selection import cross_val_score
accuracies = cross_val_score(clf, X_train, y_train, cv=10)
mean_acc = accuracies.mean()
std_acc = accuracies.std()

# Visualising the Training set
import matplotlib.pyplot as plt
```

## 1.1.3 Grid-Search : Improve models performance

In the previous section we used cross-validation to evaluate model performance. In this section we're going to learn Grid-Search which is used to improve models performance. We will improve our model by finding the optimal values of the hyperparameters that we choose.

- This Grid-Search technique will help us to choose appropriate hyperparameters for our model and tune to the optimal value.

How do I know which model to choose for my machine learning problem? With a specific dataset, how do I know which model to solve? Which model would be the best?

- Step: Figure out if it is a regression problem or classification problem or clustering problem. You just need to look at your dependent variable.
- If you don't have a dependent variable then it's a clustering problem.
- If you have a dependent variable, see if it's a continuous outcome or categorical outcome.
- If it's a continuous outcome then your problem is a Regression problem.
- If it's a categorical outcome then your problem is a Classification problem.

- Step 2: Find out if your problem is linear model or nonlinear model. When you have a large dataset you cannot fit the linearity of your dataset easily. For a large dataset, you have to try this situation: choose a linear model like SVM or a non-linear model like kernel-SVM (if you're doing classification).
- In this situation where we have a large dataset we can get help from Grid search. Grid search will tell us if we should choose a linear model like SVM or a non-linear model like kernel-SVM.

Problem description: We're going to work on the same problem as in the previous section (k-fold cross-validation). Classify the users in the social network and predict if they're going to click and buy the ad.

- We use the same dataset Social_Network_Ads.csv. Since the kernel SVM model has many parameters, like gamma, grid search will tell us exactly which values we choose for these hyperparameters.

Fitting grid: Grid search can be used after fitting your model to the training set because we are now on improving the model performance, we will use the grid search right after K-fold cross-validation section.

- Since we used K-fold cross-validation to evaluate the model performance and we are now on improving the model performance, we will use the grid search right after K-fold cross-validation section.
- We import GridSearchCV from sklearn.model_selection

```python
from sklearn.model_selection import GridSearchCV
```

Specifying the different parameters to use for Grid Search: Hyper parameter tuning, we need to insert hyperparameters from a dictionary. So we created this dictionary of parameters. We named it as params_dict.

- When we built our model only used 2 parameters: `clf=SVC(kernel="rbf", random_state=0)`
- But there are other parameters that we didn't specify and used their default values. For example: degree (in case of polynomial), gamma.
- We say to tune C, gamma (3 hyperparameters). We created dictionary "key-value" pairs, Parameter-name as key and list of values that we want to set for tuning. These values will be tested by the grid search and we will find the best one.

```python
# Grid-Search to find the "best model" and "Best hyper-parameters"
from sklearn.model_selection import GridSearchCV
params_dict = {
  'C': [1, 10, 100, 1000], 'kernel': ['linear'],
  'C': [1, 10, 100, 1000], 'kernel': ['rbf'], 'gamma': [0.7, 0.5, 0.1, 0.01, 0.001, 0.0001]
}
```

- This penalty is for regularization to prevent overfitting, the default value is 1. We tune this for our model to prevent overfitting.

- The more you increase this penalty C the model will prevent overfitting. But be careful not to increase it too much otherwise you will get a new problem which will be Underfitting. For example 10000 will be too much for penalty.
