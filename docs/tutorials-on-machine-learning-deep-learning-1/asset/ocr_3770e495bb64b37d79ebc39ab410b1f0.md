The first option: Grid Search will investigate a linear model that is a classic SVM with a linear kernel. And it will try to find the optimal value for the penalty parameter C.
The second option: Grid Search will investigate the nonlinear model 'rbf' kernel-SVM, and we will tune it, and also find the penalty parameter C.
Eventually we'll get a single combination of all these different parameters and options. And grid-search will find that combination for us.

Applying Grid-search: In this step we are going to implement grid search and we will do that after the list of parameters-dictionary that we created.
We'll create an object of GridSearchCV and we are going to fit this object on our training X_train.

```
grid_Src = GridSearchCV(estimator=clsf,
                             param_grid=params,
                             scoring='accuracy',
                             cv=10,
                             n_jobs=-1 )
grid_Src = grid_Src.fit(X_train, y_train)
best_acc = grid_Src.best_score,
best_parameters = grid_Src.best_params_
```

- param_grid: is the list of parameters-dictionary that we want to use using Grid-Search.
param_grid = params_dict
iii- scoring: The scoring matrix is used to decide the best parameters. We set scoring='accuracy'
- Grid search is going to select the best parameters on one performance matrix.
- It can be the accuracy matrix or it can be the precision matrix, it can be the recall, So it can find different metrics.
- We are going to take the most common one like did for deep learning the accuracy. So , we use scoring='accuracy'
iv- grid search is going to evaluate the performance of each model with its set of parameters, using K-fold-cross-validation. So we set 10 folds, cv = 10
- The most choice for CV number is 10. Most of the time you'll use 10-fold-cross-validation where you'll get 10 accuracy and 10 accuracy is actually enough to get a relevant idea of the model performance.
