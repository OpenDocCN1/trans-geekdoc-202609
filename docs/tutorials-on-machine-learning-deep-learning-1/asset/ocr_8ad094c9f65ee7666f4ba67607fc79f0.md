# Creating cluster with optimal "n clusters": We analyze the data for 5 clusters. We can use fit_predict() to find the values.

As we have the number of clusters, we can now train the model on the dataset.
To train the model, we will use the same lines of code as we have in the above section, but instead of using i, we will use 5, as we know there are 5 clusters that need to be formed.

```
# creating cluster with optimal "clusters". From elbow-plot we get 5 the optimal number of clusters
k_mean_cluster = KMeans(n_clusters=5, init='k-means++', random_state=0, max_iter=300, n_init=10)
y_mean_cluster = k_mean_cluster.fit_predict(X)
```

+   - The first line is the same as above for the other of KMeans class.
In the second line of code, we have created the dependent variable y_mean_cluster (we can call it y_predict also) to train the model.
By executing the above lines of code, we will get the y_mean_cluster variable. We can check under the variable explorer in the Spyder IDE. We can now compare the values of y_mean_cluster with our original dataset. Consider the image below
