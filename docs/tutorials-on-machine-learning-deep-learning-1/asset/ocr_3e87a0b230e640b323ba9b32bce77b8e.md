# iii. Step 3 - Building the Polynomial regression model:

Now we will use the Polynomial regression model, but it will be a little different from the Simple Linear model. Because here we will use PolynomialFeatures library. We are using this class to add some extra features to our dataset.
```python
# Polynomial regression
from sklearn.preprocessing import PolynomialFeatures
# Set the polynomial degree for X
poly_features = PolynomialFeatures(degree=2)
X_poly = poly_features.fit_transform(X) # Generates Polynomial Feature-Matrix
lin_regressor_2 = LinearRegression() # object for Polynomial Regression
lin_regressor_2.fit(X_poly, y)
```

+   - fit_transform() converted your matrix into Polynomial Feature Matrix.
- The parameter value (degree=2) depends on our choice. We choose it according to Polynomial features.
- After executing the code, we get another matrix X_poly, which can be seen under the following explorer:
- Next, we have another LinearRegression object, named lin_regressor_2, to fit our X_poly to the linear model.
- The 1st column is the "constant-column" Multiple-Regression (this is automatically created), 2nd column is for 1st, 3rd degree term and 4th is 2nd-degree term.

![](bbox=[0.64, 0.37, 0.845, 0.56])

> Polynomial Feature-Matrix: This poly_regressor object is going to be a transformer that will transform our matrix of feature into a new matrix of features that we get X_poly, which will be a new matrix of features containing not this independent variable X but also X2. it actually adds the polynomial terms. The degree can be set to any integer (2, 3, 4...). ... Using PolynomialFeatures(degree=2):
```python
from sklearn.preprocessing import PolynomialFeatures
poly_features = PolynomialFeatures(degree=2) # set the degree of polynomial for X
X_poly = poly_features.fit_transform(X) # Generates Polynomial Feature-Matrix
```

These three actually transformed our original matrix of features into our new matrix of features containing the original independent variable and its associated polynomial terms.

+   - Include this poly into a multiple regression model: In the following two lines we created a new linear regression object lin_regressor_2, which fitted to our new X_poly and original dependent variable y.
```python
lin_regressor_2 = LinearRegression() # object for Polynomial Regression
lin_regressor_2.fit(X_poly, y)
```
