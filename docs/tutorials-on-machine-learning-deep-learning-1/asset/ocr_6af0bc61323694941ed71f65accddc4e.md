The algorithm corresponds to standard CD without renormalizing the visible units of the Markov chain with a training sample each we want to draw a sample $v^{(k)}$ approximately persistent chains which run for $k$ Gibbs steps after each parameter update (i.e., the initial state of the current Gibbs is $v^{(k)}$ from the previous update step). The fundamental ideas underlying PCD is that one could assume the chains stay close to the stationary distribution if the learning rate is sufficiently small and the model changes only slightly between updates [41,36]. The number of persistent chains used for sampling (or the number of samples used to approximate the second term of (9)) is a hyper parameter of the algorithm. In the canonical, there exists one Markov chain per training example in a batch.

The PCD was refined in a variant called fast persistent divergence (FPCD), [37]. FPCD tries to reach faster mixing of the Gibbs chain by introducing parameters $w_{ij}, b_j, c_i$ (for $i=1,...,n$ and $j=1,...,m$) referred to as fast parameters. This new set of parameters is only used for sampling and not in the model itself. When calculating the conditional distributions for Gibbs the regular parameters are replaced by sum of the regular and fast parameters, i.e. Gibbs sampling is based on

> $\hat{p}(H_i=1|v) = \sigma(\sum_j(w_{ij}v_j+b_j)+c_i)$ and $\hat{p}(V_j=1|h) = \sigma(\sum_i(w_{ij}h_i+b_i)+c_j)$

The learning rate for the fast parameters equals the one for the regular parameters, but with an independent, large learning rate leading to faster changes as well as a large decay parameter. Decay may be used for the regular parameters, but it was suggested that regularizing the fast weights is sufficient [37].

Neither nor FPCD seems to enhance the mixing rate (or decrease the bias of the approximation) sufficiently to avoid the divergence problem as is seen in the empirical analysis in [11].
