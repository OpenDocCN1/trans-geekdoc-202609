We will sort these probabilities. But before that, we add customer_id to y_pred because it will be easy to identify the fraud.

+   It will be d2 array of 1st column holds the ids and 2nd column is probabilities of being a fraud.

Concatenate the columns:

```
y_pred               Array of float32      (690, 1)

[0.060368]]
```

Notice y_pred is a NumPy array of float, of size (690, 1). To concatenate the customer_id, it need to be a NumPy array of float.

dataset.iloc[0:1].values selects the 1st column customer_id from the dataset. 0:1 and .values is used to convert it to NumPy float.

We also chose the axis 1 Since we can now concatenate side-by-side, we set axis=1.

```
# concatenate columns to add customer_id
y_pred = np.concatenate((dataset.iloc[0:1].values, y_pred), axis=1)
```

Now sorting is bit-tricky; because NumPy will sort both columns. We don't want, we just want to sort 2nd column of y_pred i.e. the index always stays paired if we sort the probability. In NumPy it is different.

In Excel it would be easy

```
# sorting trick
y_pred = y_pred[y_pred[:, 1].argsort()] # y_pred[:1] selects the 2nd column of y_pred
```

y_pred[1] selects the 2nd column of y_pred
