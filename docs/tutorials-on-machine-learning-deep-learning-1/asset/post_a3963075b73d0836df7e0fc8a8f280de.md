```python
# implement automatic Backward Elimination. No manual iteration needed
import statsmodels.api as sm
def backward_elimination(x, y):
    numVars = len(x)
    for i in range(numVars):
        regressor_ols = sm.OLS(endog=y, exog=x).fit()
        maxPval = max(regressor_ols.pvalues).astype(float)
        if maxPval > SL:
            for j in range(numVars):
                if regressor_ols.pvalues[j].astype(float) == maxPval:
                    # deleting the column
                    x = np.delete(x, j, axis=1) # deletes j-th column "1" is used for "column". To delete "row" use "0"
                    print(regressor_ols.summary())
                    break
    return x
```

# 2.3.1 Polynomial Regression

Polynomial Regression is a regression algorithm that models the relationship between a dependent(y) and independent variable(x) as nth degree polynomial. The Polynomial Regression is given below:

```
y = b0 + b1x + b2x^2 + b3^3 + ... bnx^n
```
