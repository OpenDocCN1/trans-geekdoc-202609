What means that the coefficient for California is going to be included in the constant $b_0$ by default. When $D_1$ is equal to zero this equation will turn into an equation for California.

When $D_1$ becomes 1 you are adding $b_4$ which is the difference between New York and California coefficient.

So basically you're altering from California to New York by flipping this light switch if it's off. And the default state or the equation is working for California.

# 2.2.5 Dummy variable trap

Why you should never include all of your dummy variable columns

+   Multicollinearity: Intuition here that you're basically duplicating a variable. This is $D_2 = 1 - D_1$.

+   The phenomenon where one or several independent variables in a linear regression predict another is called MULTICOLLINEARITY. As a result of this model cannot distinguish between the effects of $D_1$ from the effects from $D_2$. It doesn't work properly. And it is the Dummy Variable Trap.

+   If you do the math behind this scenario you will see that the real problem is that you cannot have three elements in the same time the constant $b_0$ and the dummy variables $b_4D_1, b_5D_2$.
