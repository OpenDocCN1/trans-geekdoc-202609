The parameter of this activation function will not be directly the input x. We've used fc1(x) because we are encoding, and to do encoding we have applied the activation function on the first full connection fc1. Here to include information of the first full connection we did not directly.

+   - FC1 is of the Linear class it will apply the full-connection over x. And it becomes the first-full-connection.

forward() will return the output vector in the end using several encoding-decoding, and we'll compare it to the real rating.

+   - For this reason, we're going to modify x after each encoding, and hence used the variable again so that it will be modified. The encoded vector in the first hidden layer will be the modified x.

```
x = self.activation(self.fc1(x))
```

This x in self.fc1(x) is the input features of the first full connection and with this x = "self.activation(\)" will be the new first encoded vector resulting from this first encoding what happens here with the activation function in the first full connection.

Now basically we need to do the same for the other full connection and this going is to be exactly the same.

+   - Second-Encoding: We update x of the first hidden layer, then the vector in the first hidden layer, we make the second connection which will encode this vector of 20 elements into a shorter vector of 10 elements.

```
x = self.activation(self.fc2(x))
```

+   - At the same time, we apply the sigmoid activation function to activate the neurons and eventually x becomes the new encoded-vector of 10 elements for this second hidden layer.

+   - First-Decoding: We do the same for the third full connection by fc3. We are Decoding.

```
x = self.activation(self.fc3(x))
```

+   - The third full connection fc3 corresponds to the decoding from an input vector of 10 elements in the second hidden layer to a larger output vector composed of 20 elements.

+   - Final-Decoding: To get our output vector we use fc4 for 2nd (final) DECODING. It will be our reconstructed output vector, similar to input vector.

```
x = self.fc4(x)
```

+   - But we don't apply the activation function because this is the final part of decoding. We only to have our full full connection, fc4 without the activation function.

From forward() we return the reconstructed output x. Then x is our vector of predicted ratings.

```
def forward(self, x):
    x = self.activation(self.fc1(x))
    x = self.activation(self.fc2(x))
    x = self.activation(self.fc3(x))
    x = self.fc4(x)
    return x
```

[2]. the forward() does the action of establishing different full connections by applying the activation functions to activate the night neurons in the network.

+   - In forward(), we do two encoders and two decoders to get our reconstructed output vector in the output layer.
