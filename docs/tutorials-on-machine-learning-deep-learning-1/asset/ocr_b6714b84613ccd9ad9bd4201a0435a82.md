# 11.1.1 Evaluating & Improving Model Performance

+   Model parameters and Hyper parameters: In a ML model we have two types of parameters. Model parameters and Hyper parameters.

+   Model parameters: These are the parameters that the model learns and found optimal values by running the model.

+   Hyper parameters: This is type of parameters are the parameters that we choose ourselves. For example the kernel-SVM or the penalty parameter or even some regularisation parameter.

So there is still room to improve the model because we can still choose some optimal values for these parameters.

In this chapter we will do two things:

+   [1]. Evaluating our model performance: To evaluate models in an efficient way, we use K-fold-Cross-validation instead of just train-test-split. Then to tune- Hyper parameters we will use Grid Search.

+   [2]. Improving our model performance: We'll use the most powerful algorithm in ML, XGBoost.

+   Improving the model performance can be done with a technique called model selection. That consists of choosing the best parameters of your ML model.

+   Grid Search: Since the model parameter is learned by the model then we need to figure out a way to choose the optimal values for these Hyper parameters. One of the powerful techniques to tune- Grid Search.

+   K-fold-Cross-validation: We need to optimize a way to evaluate our models before we start grid search. Previously we split the dataset between the training set and a test set.

+   We trained on the training set and we tested its performance on the test set. That's a correct way of evaluating the model performance.

+   But that's not the best because we actually have a variance problem.

+   The variance problem can be explained by the fact that we have the accuracy on the test set. And if we run the model again and test on another test set, we get a very different accuracy.

+   Hence judging our model performance only on one test set is actually not a good idea. That's not the most relevant way to evaluate the model performance.

+   K-fold-Cross-validation: K-fold-Cross-validation is a technique that resolve the variance problem by splitting the training set into K-fold.
