# 11.3 ANN Hyper-Parameter tuning

+   **Model-parameter**: Are the parameters that the model learns by itself.

+   **Hyper parameters**: Are the parameters that we fix to build a model. These are the number of **epoch**, the **batch size**, the **optimizer**, or the number of **neurons** in the **layers**.

**Parameter-Tuning & Grid-Search**: It's a real deal **improving** our model's **performance** because we are going to tune our model and we gonna find the best **hyper parameters**, by best of **epoch**, the **batch size**, the **optimizer**, so we will get the best ANN that will maximize our accuracy

+   **Parameter tuning** is all finding the **best values** of these **hyper parameters** and we do this using **Grid Search** technique.

+   **Grid Search** will test several **combinations** of these **values** and eventually return the selection that leads to the best accuracy with **K-Fold-CV**.

**Implement tuning in ANN**: it's actually quite the same implementing **K-fold cross** because we use the **KerasClassifier** class to tune our ANN in a fashion so that it can be used for **sklearn.learn**.

Because we'll use **GridSearchCV** from the same **sklearn.model_selection** (used for k-fold, **cross_val_score** **function**.

+   For old version, to import it from **sklearn.grid_search**

Basically we create an **object** from **GridSearchCV** and we **gridsearch_ann** that will apply parameter tuning on our **KerasClassifier** that our traditional ANN

So we can copy all the code from **K-fold selection** except the **accuracy-vector acuracies**, and (lines are highlighted).

```
from keras.wrappers.keras import KerasClassifier # combine Keras & Scikit-Learn
from sklearn.model_selection import import GridSearchCV

# make a function that creates ANN
from keras.models import Sequential
from keras.layers import Dense

def build_ANN(classifier=None):
    model = Sequential()
    model.add(Dense(units=6, kernel_initializer='uniform', activation='relu', input_dim=11))
    model.add(Dense(units=6, kernel_initializer='uniform', activation='relu'))
    model.add(Dense(units=1, kernel_initializer='uniform', activation='sigmoid'))
    model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
    return model
```

ann_classifier_for_eval = KerasClassifier(build=build_ANN) #/compile an ANN classifier

But in our KerasClassifier we will not input the **batch_size** and **epoch** arguments because the arguments we gonna tune in **Grid-Search**.

**Creating parameter tuning**: To use Grid-search for Hyper-parameter tuning, we need to **input** those **Hyper-parameters** as **list** of dictionary. So we create this dictionary of parameters. We name this dictionary of parameters as **params_dict**

It is the procedure described in the section **11.1.3 Grid-Search** earlier in this chapter.

In this dictionary we will define combinations of **hyper-parameters** and the **Grid-Search** uses the **k-fold-CV** with those different combinations and at the end it will return the **best accuracy** with the **best selection** of these **parameters**.
