# 13.3.4 How SOM updates itself

Here we have BMUs. Now each these BMUs are going to be updated.

+   - Then each one of these BMUs is going to be assigned an area around it, and that area is going to be calculated through a radius.
- Here we can see that there are some values that don't fall under the radius, which usually doesn't happen in SOM this is just our visual example.
- Normally the radius at the start is selected as quite large so that it covers the whole self-organizing map.

Here all of the nodes that fall into these areas are updated.
