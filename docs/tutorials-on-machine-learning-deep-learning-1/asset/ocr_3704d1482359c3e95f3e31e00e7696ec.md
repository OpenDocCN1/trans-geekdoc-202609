The independence between the variables in one layer makes Gibbs sampling especially easy; instead of sampling new values for all variables whatsoever, the states of all variables in one layer can be sampled jointly. Thus, Gibbs sampling can be performed in just two steps: sampling a new state $h$ for the hidden neurons from the visible layer by $p(v|h)$. This is also referred to as *Gibbs sampling*.

As mentioned in before, an RBM can be reinterpreted as a standard feed-forward neural network with non-linear units. This perspective RBM is viewed as a deterministic function $\{0,1\}^m\to\mathbb{R}^n$ that maps an input $v\in\{0,1\}^m$ to $y\in\mathbb{R}^n$ with $y_i = p(H_i=1|v)$. That is, an observation is mapped to the expected value of the hidden neurons given the observation.
