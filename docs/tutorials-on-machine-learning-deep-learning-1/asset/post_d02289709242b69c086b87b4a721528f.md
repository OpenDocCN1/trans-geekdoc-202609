**Abstract.** Restricted Boltzmann machines (RBMs) are probabilistic graphical models that can be interpreted as stochastic neural networks. The increase in computational power and the development of faster learning algorithms have made them potentially relevant machine learning problems. They attracted much attention recently after being proposed as building blocks of multi-layer learning systems called deep belief networks. This tutorial introduces them as undirected graphical models. The basic concepts of graphical models are introduced first, basic knowledge in statistics is presented. Different learning algorithms for RBMs are discussed. Most of them are based on Markov chain Monte Carlo (MCMC) methods, an introduction to Markov chains and the required MCMC techniques is provided.

## 1 Introduction

Boltzmann machines were introduced as bidirectionally connected networks of stochastic processing units, which can be interpreted as neural network models [1,16]. A BM can be used to learn important aspects of an unknown probability distribution from samples from this distribution. In general, the learning process is difficult and time-consuming. However, the learning problem can be simplified by using restrictions on the network topology, which leads us to **restricted Boltzmann machines** (RBMs, [34]), the topic of this tutorial.

A restricted BM is a parametrized generative model representing a probability distribution. Given some observations, the training data, a BM learns adjusting the BM parameters such that the probability distribution represented by the BM fits the training data as well. Boltzmann machines consist of two types of units, visible and hidden neurons, which can be thought of as being two layers. The visible units constitute the first layer and correspond to the observation (e.g., one unit for each pixel of a digital input). The hidden units model dependencies between the components of observations (e.g., dependencies between pixels in images). They can be viewed as non-linear feature detectors [16].

Boltzmann machines can also be regarded as particular graphical models [22], more precisely undirected graphical models, also known as Markov random fields. The embedding of BMs into the framework of probabilistic graphical models provides immediate access to a wealth of theoretical results and well-developed algorithms. Therefore, our tutorial introduces RBMs from this perspective. Computing the likelihood of an undirected model or its gradient for inference is in general computationally intensive, and this also holds for RBMs. Then, sampling based methods are employed to approximate the likelihood and its gradient. Sampling from an undirected graphical model is not straightforward, but for RBM Markov chain Monte Carlo (MCMC) methods are easily applicable in the form of Gibbs sampling, which will be introduced in this tutorial along with basic concepts.

After successful learning, an RBM provides a closed-form representation of the distribution underlying the (unseen) observations and to sample from the learnt distribution (e.g., to generate image texture [25,21]), in particular with marginal distributions of interest. For example, we can use visible units corresponding to a partial observation, to solve an image painting task [21].

Boltzmann machines were introduced in the 1980s [1,34]. Compared to the times when they were introduced, RBMs can now be applied to more interesting problems due to increased computational power and the development of new learning strategies [15]. Restricted Boltzmann machines have received a lot of attention recently being proposed as building blocks of multi-layer architectures called deep belief networks (DBNs [19,17]). The idea is that hidden neurons extract relevant features from the observations. These features can serve as input to another RBM. By stacking RBMs in this way, we can learn features at different levels in the hope of arriving at a high level representation.

It is an important property that simple as well as stacked RBMs can be interpreted as deterministic-forward neural networks. They are used as functions from the domain of the observations to the expectations of the latent variables in the top layer. Such a function maps the observations to features, which can, for example, serve as input to a supervised learning system. Further, the neural network corresponding to a trained RBM or DBN can be augmented by another layer, where units in the added layer represent labels. Then the model corresponds to a standard neural network used for regression which can be further trained by supervised learning algorithms [31]. It has been argued that this initialization (or unsupervised pretraining) of the feed-forward network weights based on a generative model helps to overcome problems observed when training multi-layer networks [19].

This introduction to RBMs will complement existing tutorials, such as the highly recommended review by Bengio [2], providing more background information on Markov random fields and MCMC methods in Section 2 and Section 3, respectively. However, basic knowledge in statistics is presumed. We put an emphasis on topics that are - based on our experience - sometimes not familiar to people starting with RBMs. Restricted Boltzmann machines will be presented in Section 4. Section 5 will consider RBM training algorithms approximations of the log-likelihood gradient. This includes a discussion of contrastive divergence learning [15] as well as parallel tempering [10]. We will close by hinting at generalizations of RBMs in sections 6 and 7.

## 2 Graphical Models

Probabilistic graphical models describe probability distributions by mapping dependence and independence properties between random variables on a graph (two sets of random variables $X_1$ and $X_2$ are conditionally independent given a set of random variables $S$ if $p(X_1,X_2|X_S) = p(X_1|X_S)p(X_2|X_S)$). Visualization by graphs can help develop, understand and make probabilistic models. Furthermore, complex computations (e.g., marginalization) can be efficiently performed using the graph structure.

There exist graphical models with different kind of graph structures, for example factor graphs, Bayesian networks with directed graphs, and Markov fields, also called Markov networks or undirected graphical models. This tutorial focuses on the latter. A general introduction to graphical models [5].

### 2.1 Undirected Graphs and Markov Random Fields

First, we summarize some fundamental concepts from graph theory. An undirected graph is a tuple $G=(V,E)$, where $V$ is a finite set of nodes and $E$ is a set of undirected edges. An edge consists of a pair of nodes from $V$. If there exists an edge between two nodes $v$ and $w$, i.e. $\{v,w\} \in E$, then the neighborhood of $v$ contains $w$. The neighborhood $N_v := \{w \in V \mid \{w,v\} \in E\}$ is defined by the set of nodes connected to $v$. A clique is a subset of $V$ if no node can be added such that the resulting set is still clique. In the following we will define $C$ as the set of all maximal cliques of an undirected graph.

We associate a random variable $X_v$ to each $v \in V$, taking values in a state $A_v$. We assume $A_v = A$ for all $v \in V$.
