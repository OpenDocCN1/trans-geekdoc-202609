**Theorem 2 (Fischer and Igel [12]).** Let $p$ denote the marginal distribution of the visible units of an RBM and $q$ be the empirical distribution defined by a set of samples $v_1,\dots,v_n$. Then an upper bound on the expectation of the CD-$k$ error of the log-likelihood derivative w.r.t some RBM parameter $	heta_a$ is given

$E_{p(v^{(0)})} \left[ E_{p(v^{(k)}|v^{(0)})} \left( \frac{\partial \log q(v^{(k)})}{\partial 	heta_a} ight)^2 ight] \leq \frac{1}{2} \left\| q - p \right\|^2 \left(1 - e^{-(m+n)\Delta} \right)^k \quad (37)$
```

with

```
$\Delta = \max \left\{ \max_{i=1,\dots,n} \theta_i, \max_{j=1,\dots,m} \xi_j \right\$\$$
```

where

```
$\theta_l = \max \left\{ \sum_{i=1}^n l_{\{w_{ij}>0\}}w_{ij} + b_l, \ \sum_{j=1}^m l_{\{w_{ij}<0\}}w_{ij} + b_l \right\$$
