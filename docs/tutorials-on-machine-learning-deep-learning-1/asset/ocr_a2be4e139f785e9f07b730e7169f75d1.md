The path that contains the dataset, "./movie_len_im/movies.dat"

> The separator default is a comma, that works for csvfile, where the features are separated by commas,
But here's not the case size of the titles of the movies header is None because we cannot use the comma as a separator. If the separator is a double column, like this \'. So sep = ":"

> If you move dataset file, the you will be separated by ratings and their other features, by a double column

The third parameter is the header. Because actually the file.dat,doesn't contain headers, the default value of header is None (no column names), and therefore we need to specify this, there is no column names, and to do that header=None

Then the next parameter is to go encoding, and this is to make sure that the dataset gets imported correctly. And we will use the Python engine, engine='python'.

Last argument, is the encoding. We need to input a different encoding because some of the movie titles contain special characters that cannot be treated properly with the class encoding. UTF-8, So we're just adding the encoding argument because of some of the special characters in the movie titles. encoding='latin-1'

```
movies = pd.read_csv('./movie_len_im/movies.dat', sep=":", header=None, engine='python', encoding='latin-1")
```
