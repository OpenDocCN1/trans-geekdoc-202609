```python
# Cleaning the text
import re
import nltk
nltk.download("stopwords")
from nltk.corpus import stopwords
from nltk.stem.porter import PorterStemmer
print(f"{dataset['Review'][i]}")
corpus_review = []

for i in range(1000):
    rew = re.sub(r"[^a-zA-Z]", "", dataset["Review"][i])
    rew = rew.lower() # converting to lower case
    rew = rew.split() # converting string to "List"
    rew = [word for word in rew if word not in stopwords.words("english")]
    # Removing stopwords. Stemming: Finding the root of different versions
    ptm_stem = PorterStemmer()
    review = [ptm_stem.stem(word) for word in rew if word not in stopwords.words("english")]
    rew = " ".join(review)
    corpus_review.append(rew)
```

All stopwords removed and all words are stemmed. We will simplify these reviews even more because we will keep only the words that appear a minimum of times.

## 7.4 Clean the Data

What is the bag of words model and why do we need to create it? By understanding why we need to create bag of words you understand even how to clean the text/1000 reviews but also creating a Corpus.

Basically the first step is creating bag of model. Now from here we will create our bag of words. The bag words model really simple. We are going to take all the different words of 1000 reviews here without taking duplicates (unique words of 1000 reviews). We will create a table for each review which will be of columns. Then we will put all columns in a table where the rows are

So basically what we'll get is a table containing 1000 rows where the rows correspond to the reviews and a list of columns where each column corresponds to each different words in the corpus of the reviews. Each cell of this table corresponds to one specific review and one specific word of this. And in this we're going to have a number which represents the number of times the word appears in the review. So if a word appear in review we place a 1, and for all of the rest we place 0 in the rows. In each row(review) of the table most have 0 and a few 1s.

- Sparse Matrix: This is actually a table and it is called sparse matrix. In numerical analysis and scientific computing, a sparse matrix or sparse array is a common name in machine learning. We are using a sparse matrix in which most of the elements are zero.

- And we have a lot of it is called sparsity and that's why we use sparsity. The bag of words model is basically to simply simplify the reviews, clean all the reviews to simplify the words and trying to reduce sparsity as much as possible when we work with ML.

- Creating this matrix is actually the of of model. Tokenization: It is also about creating the sparse matrix through tokenization. Tokenization is the process of taking all the different words of the review and creating one column for each of these words (which we discussed).

- Our goal: in our goal is to predict a review is positive or negative. Our ML model needs to be trained on all these reviews, and the correlations between the hints (words) that tell us if the review is positive or negative and it's true result whether it is positive or negative.

- Now remember we will use this kind of classification in models, here we also classify a review is positive or negative according to the given data (to train the model). Now reducing the words and sparsely reducing the "independent variable" of our classification problem.

The dependent variable is a categorical binary outcome: i is a review positive or o if the reviews negative. So we are doing nothing else than classification.

So, as we managed to create this bag of words, then we simply need to copy templates and create our ML model.

At the end we will have our matrix of features or matrix of independent variables which will be the different word appearing in all reviews where we will be the columns of our matrix and we will have our dependent vector which will be the result whether the review is positive (1) or negative (0).

So that why we need to create this bag of words.
