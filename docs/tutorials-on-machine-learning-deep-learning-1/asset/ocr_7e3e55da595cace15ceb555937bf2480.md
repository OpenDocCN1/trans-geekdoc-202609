+   - To this, we use append() of Numpy library (np which we have already imported into our code), and will assign a value of 1. Here is the code for it:

```
X_pre_out = np.append(arr=X_go, values=np.ones(shape=(50, 1)).astype(int, axis=1)
```

+   - values = ": So array that we are going to import here will be a matrix of 50 1s. It will be an array of 50x1, [1, 1, ..., 1]. There is actually a trick for that. And it is
np.ones(shape=(50, 1)).astype(int)

+   - shape=1: the shape of the matrix of what we want to create as (row, column), astype(int) is needed otherwise we will get a data type error.

+   - axis=1: The last argument which here is because you can use the append() function to here add a line of values or column of these values to the matrix. We need to specify if we want to add a column or line.

+   - If we need to add a line/row then axis=0.
- If we want to add our column then axis=1.
