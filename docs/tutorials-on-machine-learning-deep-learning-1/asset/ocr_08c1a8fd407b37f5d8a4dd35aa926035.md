This actually represents the average of the error, by only considering the movies that were rated.
 need to do this because we only considered here the movies have non-zero ratings. We will compute mean, this has to be computed only on the movies we rated. That is, the movies that got non-zero ratings.
This mean_correctorvariable is just to adapt to this consideration of the movies that got non-zero ratings. We need to do this this will then be mathematically relevant to the mean of the errors.
