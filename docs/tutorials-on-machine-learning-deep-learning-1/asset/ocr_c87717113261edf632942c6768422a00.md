# 2.6.1 Ensemble Learning

+   - Ensemble Learning: Ensemble learning is when you take multiple algorithms or the same algorithm multiple times and you put them together to make something much more powerful than the original.

+   - Ensemble Methods: In statistics and machine learning, ensemble methods use multiple learning algorithms to obtain better prediction performance than obtained from any of the constituent learning algorithms.
Unlike a statistical ensemble in statistical mechanics which is usually infinite, a machine learning ensemble consists of only a concrete finite set of alternative methods, but allows for much more flexible structure to extent among others.

+   - Bootstrapping: in bootstrapping generally refers to a self-starting process that is supposed to continue or grow without external input.

# 2.6.2 Types of Ensemble Methods

Main Types of Ensemble Methods

+   - Bagging: Bagging, the short form for bootstrap aggregating, is mainly applied in classification and regression. It increases the accuracy of models through Decision Trees, which reduces variance to a large extent. The reduction of variance increases accuracy, eliminating overfitting, which is a challenge to many predictive models.

+   - Bagging is classified into two types,
  i. Bootstrapping is a sampling technique where samples are derived from the whole population (set) using the replacement method which helps make the selection procedure randomized. The base learning is based on the samples to complete the procedure.
  ii. Aggregation in bagging is done to incorporate all possible outcomes of the prediction and randomize the outcome. Without aggregation, predictions will not be accurate because all outcomes are not put into consideration. Therefore, the aggregation is based on the probability bootstrapping procedures or on the basis of all outcomes of the predictive models.

Bagging is advantageous since we learners are combined to form a strong learner that is more stable than a single learner. It eliminates any variance, reducing the overfitting of models. One limitation of bagging is that it is computationally expensive. Thus, it can lead to more bias in models when the process of bagging is ignored.

+   - Boosting: Boosting is an ensemble technique that learns from previous mistakes to make better predictions in the future. The technique combines several weak learners to form one strong learner, significantly improving the predictability of models. Boosting works by arranging weak learners in a sequence, such that weak learners learn from the next in the sequence to create better predictive models.

+   - Boosting takes many forms, GRADIENT BOOSTING, ADAPTIVE BOOSTING (ADABOST), and XGBoost (EXTREME BOOSTING),
  i. AdaBoost uses weak learners in the form of Decision Trees, which mostly use split that is popularly known as decision stumps. AdaBoost's decision stump carries similar weights.
  ii. Gradient boosting adds predictors sequentially to the ensemble where predictors correct their successors, thereafter increasing the model's accuracy. New predictors are fit to catch the effects of errors in the previous predictors. The gradient of descent helps the gradient booster identifies in learners' predictions and Counter them accordingly.
  iii. XGBoost uses method of Decision Trees with Gradient Boosting, which provided improved performance and it. It relies heavily on the computational speed and the performance of the target model. Model training should follow a sequence, thus making the implementation of gradient boosted machines slow.
