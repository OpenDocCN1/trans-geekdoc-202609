# # XGBoost Documentation

XGBoost is an optimized distributed gradient boosting library designed to be highly efficient, flexible and portable. It implements machine learning algorithms under the Gradient Boosting framework. XGBoost provides a parallel tree boosting (also known as GBDT, GBM) that may solve many data science problems in a distributed environment (Hadoop, SGE, MPI) and can solve problems billions of examples.
