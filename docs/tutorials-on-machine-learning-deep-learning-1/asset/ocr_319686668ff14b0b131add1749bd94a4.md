We need to make different datasets. The training sets on the machine learning model learn and the test set on we test if the ML model learned the correlations.

```
# Splitting the Dataset: Train and Test
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(old_x, old_y, test_size=0.2, random_state=0)
print(x_train)
print(y_train)
print(x_test)
print(y_test)
```

+   **What is Splitting Dataset:** We will split our dataset into two separate dataset, Training-set and Test-set.
- Training-set will use 70% or 80% of data to train our models.
- Other 30% or 20% is the Test-set, which will be used to test our models how well it will predict.

**Why Splitting Dataset:** We always keep test set to avoid the Overfitting. Overfitting is when ML model learns too much from train-set but bad prediction

+   **Examples of Overfitting:** Let's say we want to predict if a student will land a job interview based on their resume. Now, assume we train a model from a dataset of 10,000 examples. Our next, the test model out on the original dataset, and it predicts with 99% accuracy...!
- But now the bad news. When we run the model on a new ("unseen") dataset of resumes, we only get 50% accuracy... uh-oh!
- Our model doesn't generalize well from our training to unseen data.
- This is overfitting, and it's a common problem in machine learning and data science.

```
How to apply:
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(old_x, old_y, test_size=0.2, random_state=0)
```

**Parameters:** *arrays : sequence of indexes with shape / [shape]
Allowed inputs are list, numpy arrays, sparse-matrix or pandas dataframes.

**test_size : float or int, default=None**
If float, should be between 0.0 and 1.0 represent the proportion of the dataset to include in the test set.
If int, represents the absolute number of test samples. If None, the value is set to the complement of the train set.
If size is also None, it will be set to 0.25.

**train_size : float or int, default=None**
If float, should be between 0.0 and 1.0 represent the proportion of the dataset to include in the train split.
If int, represents the absolute number of train samples. If None, the value is automatically set to the complement of the test size.

**random_state : int, RandomState or None, default=None**
Controls the shuffling applied to the data before splitting. Pass an int for reproducible output across multiple function calls. See Glossary.

**shuffle : bool, default=True**
Whether or not to shuffle the data before splitting. If shuffle=False then it must be None.

**stratify : array-like, default=None**
If not None, it is split in a stratified fashion, using this as class labels. Read more in the User Guide.

+   **x_train, x_test, y_train, y_test** is used because train_test_split() returns four matrices. We grab them in these variables x_train, x_test, y_train, y_test. The order must be maintained.
- **test_size = 0.2** means test size is 20%. It is better of 20% or 25% or 30-33% than 40 (very rare). train_size Not needed, it automatically set to 1- **test_size**
- **random_state = 0** means no shuffling. Actually shuffling is good in order to generate same results. Use 42 generally.
