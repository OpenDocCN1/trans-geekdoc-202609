- **Input layer**: Neurons for input values: These are values that you know about a certain situation. For instance: you're modeling something, you want to predict something you always have some input to start, then that's called the **input layer**.
- **Output layer**: Then you have the output. That's of value that you want to predict EG: For a transaction in a bank, this is a fraud-transaction it so on. That's going to be **output layer**.
- **Hidden layer(s)**: Between **Input layer** and **Output layer** we're going to have a **hidden layer**. The **input layers** neurons connected to a **hidden layer** neurons that connect to output.

- **Shallow-Learning and Deep-Learning**: For a few Hidden Layers it is called Shallow-Learning. When the Hidden Layer increases it is Deep Learning.
