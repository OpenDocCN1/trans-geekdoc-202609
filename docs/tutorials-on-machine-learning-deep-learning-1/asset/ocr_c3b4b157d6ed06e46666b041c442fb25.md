```
markers = ['o', 's']
colors = ['r', 'g']
for i, x in enumerate(X):
    w = som.winner(x) # notice Lowercase 'x' used
    plot(
        w[0]+0.5,
        w[1]+0.5,
        markers[y[i]],
        markedcolor = colors[y[i]],
        markerfacecolor = 'None',
        markersize = 10,
        markerwidth = 2
    )
show()
```

+   - 'o' = circle
- 's' = square
- 'r' = red
- 'g' = green.

We are looping over all the customers and for each customer we get the winning node and dependent on whether the customer got approval or not.

+   - We actually need two variables that are be i and x (not capital).
- i is the different values of all of our customer database, that is i = 0, 1, 2, 3, . . . 69.
- x is the different vectors of customers. So x will start being equal to the vector that corresponds to the first customer, then at the next iteration x will be equal to the second vector, that corresponds to the customer and down to the last customer.

enumerate(x) return an enumerate object. The element yielded pairs a count (from start, which defaults to zero) and a value yielded by the iterable element.

+   - enumerate is useful for obtaining an indexed List: That is why we used it here that we can get (0, customer_1), (1, customer_2), (2, customer_3),... etc.

```
(0, seq[0]), (1, seq[1]), (2, seq[2]), ...
```

Inside the loop, w = som.winner(x) will get the winning node for the customer x (since each customer has a winning node).

+   - w[0] and w[1] are the coordinates for the winning-node and i is a Square of 1. So we add 0.5 to w[0] and w[1], so that our marker is in the center of the Winning-node-square.

```
w[0]+0.5, w[1]+0.5,
```

Using the dependent variable: We didn't use dependent variable to train our model, now we use it to mark our result.

+   - Using y in the loop generates either 0 or 1 according to reject/approve. We use is it to access our marker and color.
- Notice both color 'o' and color 'r' - indexed in markers and colors, so we can use the same index. And that's enable us to use y[i] as value.

```
markers[y[i]],
markedcolor = colors[y[i]],
```

To specify fill-color (no fill-color because some marker will overlay) width of the marker, and size we use the following:

```
markerfacecolor = 'None',
markersize = 10,
markerwidth = 2
```

+   - Finally we use show() to display the plot, after the loop.

Now not only we have the Mean Neuron Distances but also we get the information of whether the customers got approval or didn't get approval for each of the winning nodes.
