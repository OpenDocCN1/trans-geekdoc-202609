# 9.5.7 Adding Layers: Step 2: Pooling -layer

We are ready to move on Step 2: Pooling step is very easy, it is just of reducing the size of your feature
maps.

In Previous convolution we used a 3 x 3 px size/filter for convolution operation. We also use Stride-size of 1
the filters 1px at time, with 2px overlapping.

In pooling step we use a 2 x 2 px size table for Max-pooling (choosing maximum value of the feature
cells inside this table)/Now we use Stride-size of 2 (the maps 2px at time, with no overlapping).

| 0 | 1 | 0 | 0 |
| 0 | 1 | 1 | 0 |
| 1 | 0 | 2 | 1 |
| 1 | 4 | 2 | 1 |
| 0 | 0 | 1 | 2 |

| Max Pooling

| 1 | 1 | 0 |
| | 4 | 2 | 1 |
