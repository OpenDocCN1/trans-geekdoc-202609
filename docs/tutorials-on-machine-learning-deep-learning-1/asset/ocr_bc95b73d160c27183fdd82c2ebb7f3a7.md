**Introducing Latent Variables.** Suppose we want to model an $m$-dimensional unknown probability distribution (e.g., each component of a sample corresponds to $m$ pixels of an image). Typically, all latent variables $X = (X_{ij})$ in an MRF need to be observed, and the number of variables is larger than $m$. We split $X$ into *visible* (observed) variables $V=(V_1, ..., V_n)$ corresponding to the observations and *latent* (or hidden) variables $H=(H_1, ..., H_m)$ where $n = |V|$ variables. Latent variables allow us to describe complex distributions over the visible variables by means of simple (conditional) distributions. In this case the Gibbs distribution of MRF represents the joint probability of $(V, H)$ and one is interested in the marginal distribution of $V$ which is given

> $p(v) = \sum_h p(v,h) = \sum_h e^{-E(v,h)}$

where $Z = \sum_h e^{-E(v,h)}$. While the visible variables correspond to the components of an observation, the latent variables introduce dependencies between the visible variables (e.g., pixels of an input image).

**Log-Likelihood Gradient of MRFs with Latent Variables.** Restricted Boltzmann machines are MRFs with hidden variables and RBM learning algorithms are based on gradient ascent on the log-likelihood.
