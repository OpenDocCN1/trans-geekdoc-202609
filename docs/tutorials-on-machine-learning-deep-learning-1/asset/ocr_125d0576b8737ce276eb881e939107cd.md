Remember, the shape in the input layer of our CNN has three dimensions, of $64 \times 64$ layer, because it's a colored image `img_to_array()` will allow to create this 3D array that will have the same format as the input layer of CNN.

Using `NumPy` to add dimension: We have to add a new dimension to our test image using `expand_dims()`. Using 3-dimension, we will get an error saying we need four dimensions instead of three.

```
test_image = np.expand_dims(test_image, axis=0)
```

What this dimension corresponds to?

+   - It corresponds to the `batch`, because, in general, the functions of neural networks, like the `predict` function, cannot accept a single input by itself, like the image we have here.
- It only accepts in a `batch` format. Even if the batch contains `one` input, the `input` must be in the `batch` and this new dimension that we are creating now corresponds to the batch: whether there is `one` or `several` inputs.
- So here, we have `one` batch of `one` input, but in general, we can have `several` batches of `several` inputs, and we can apply the `predict` method on.

**axis**: `axis` is used to specify the position of the dimension that we are adding.

+   - We need to add this dimension in the `first` position, then we will specify `axis = 0` because `axis = 0` means that the `index` of this new dimension we are adding is gonna have the `first index`, that is `index zero`.

```
result = c_classifier.predict(test_image)
```

We put the result of that single prediction in a variable `result`. The new prediction, will be `1` or `0` (binary-classification).
