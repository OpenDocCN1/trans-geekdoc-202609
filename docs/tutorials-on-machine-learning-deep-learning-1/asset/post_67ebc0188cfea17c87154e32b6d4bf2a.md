## Selecting Cluster and Class:

The Dendrogram: Now we will find the optimal number of clusters using the Dendrogram for our model. Here we are going to use scipy library as it provides a function that will directly return the dendrogram for our code. Below are lines of code:

```python
# Dendrogram : Finding optimal number of clusters using "Dendrogram"
import scipy.cluster.hierarchy as sch
dendrogram = sch.dendrogram(sch.linkage(X,method="ward"))
plt.title("dendrogram")
plt.xlabel("Number of Clusters")
plt.ylabel("Euclidean distance")
plt.show()
```

In the above lines of code, we have imported the hierarchy method of scipy library. This module provides us a method dendrogram(), which uses the linkage() as a parameter. The linkage function is used to define the distance between two clusters, so here we pass the $X$ (matrix of features), and method "ward", the popular method of linkage in hierarchical clustering.

The remaining lines of code are to describe the labels for the dendrogram plot.

Output: By executing the above lines of code, we will get the following output:

**Optimal Number Of Clusters:** Using this *Dendrogram*, we will now determine the *optimal number of clusters* for our model. For this, we will find the **maximum vertical distance** that **does not cut any horizontal bar**. Consider the below diagram:

## Dendrogramma Plot

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_159_1.png)

In the diagram, we have shown the **vertical distances that are not cutting their bars**. As we can visualize, the **4th distance** is looking the **maximum**, so according to this, the number of clusters will be #5 vertical lines in this range. We can also take the 2nd number as it approximately equals the 4th distance, but we will consider the **5 clusters** because the same we calculated in the **K-means algorithm**.

In the **Dendrogram** the largest distance is considered the **Rightmost Blue Line**, but it cut by two horizontal lines at approximately **270 and 247**. Hence we take the range from **248 to 120**, because in this no horizontal lines appear. However we can take the **upper portion** of this **vertical-line**, but as mention above we need to find the number near to k-means cluster.

So, the **optimal number of clusters** will be **5**, and we will **train the model in the next step**, using the same as we did in k-means clusters.

## Training the hierarchical clustering: As we know the optimal number of clusters, we can now train our model.

```python
from sklearn.cluster import AgglomerativeClustering
hrcl_cluster_genrt = AgglomerativeClustering(n_clusters=5, affinity='euclidean', linkage='ward')
y_hrcl = hrcl_cluster_genrt.fit_predict(X)
```

In the code above, we have imported the AgglomerativeClustering class of cluster module of scikit learn library.

Then we created the object of this class as hrcl_cluster_genrt. The AgglomerativeClustering class takes the following parameters:

- *n_clusters=5*: It defines the number of clusters, and we have taken 5 because it is the optimal number of clusters.
- *affinity='euclidean'*: It is a metric to compute the linkage
- *linkage='ward'*: It defines the linkage criteria, we have used the ward linkage. This method is the popular linkage method that we have already used for creating the Dendrogram. It reduces the variance in each cluster.

In the last line, we created the dependent variable y_hrcl to fit or train the model we used fit-means clustering. It does not train only the model but also returns the clusters to which each data point belongs.
