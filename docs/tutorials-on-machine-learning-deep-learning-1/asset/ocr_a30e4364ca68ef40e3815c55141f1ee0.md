Since the second term in (9) can also be seen as $\sum_{v} p(h \mid v)\frac{\partial E(v,h)}{\	heta}$ we can reduce its computational complexity by applying the same factorization to the inner sum, either factorizing the hidden variables or over the visible variables in an analogous way. However, the computation remains intractable for regular sized RBMs because the complexity is still exponential in the size of the smallest layer (the sum runs over either 2 or l² states).

Using the factorization trick (2) the derivative of the log-likelihood of a single training pattern w.r.t. the weight $w_{ij}$ becomes

```
$$\frac{\partial \mathcal{L}(\theta \mid v)}{\partial w_{ij}} = \sum_{h} p(h \mid v)\frac{\partial E(v,h)}{\partial w_{ij}} + \sum_{v'} p(v' \mid v)\frac{\partial E(v,v')}{\partial w_{ij}}$$$
$$= \sum_{h} p(h \mid v)h_i v_j - \sum_{v} p(v \mid v)p(h \mid v)h_i v_j$$
$$= p(H_i=1 \mid v)v_j - \sum_{v} p(v \mid 1)v_j$ \quad (29)
```

For the mean of this derivative over a training set $S = \{v_1, \dots, v_{\ell}\}$ often the following are used:

```
$$\frac{\partial \mathcal{L}(\theta \mid v)}{\partial w_{ij}} = \frac{1}{|S|} \sum_{v \in S} [-E_{p(h \mid v)}\frac{\partial E(v,h)}{\partial w_{ij}} + E_{p(h, v)}\frac{\partial E(v,h)}{\partial w_{ij}}]$$$
$$= \frac{1}{|S|} \sum_{v \in S} [E_{p(h \mid v)}[v_{ij}] - E_{p(h, v)}[v_{ij}]]$$$
$$= \langle v_{ij} \rangle_{p(h,v)} - \langle v_{ij} \rangle_{q(h,v)}$$ \quad (30)
```

with $q$ denoting the empirical distribution. This gives the often stated:

```
$$\frac{\partial \mathcal{L}(\theta \mid v)}{\partial w_{ij}} \propto \langle v_{ij} \rangle_{h_{data}} - \langle v_{ij} \rangle_{model}$ \quad (31)
```
