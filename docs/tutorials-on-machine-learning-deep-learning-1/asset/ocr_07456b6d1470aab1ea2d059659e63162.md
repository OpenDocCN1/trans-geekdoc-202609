[2] Confidence: Confidence indicates how often the rule has been found to be true. Or, how often the items X and Y occur together in the dataset when the occurrence of X is already given. It is the ratio of the transaction that contains X and Y to the number of records that contain X.

# $Confidence(X \rightarrow Y) = \frac{Freq(X,Y)}{Freq(X)}$

For example: Now consider we are testing a rule, *People watched Interstellar is also watched Ex-Machina*. So in the following diagram say green people watched Interstellar is 40 among 100, and 7 of them watched Ex-Machina, then the confidence is:

# $Confidence = \frac{7}{40} = 17.5\%$

[3] Lift: Lift is very similar to the *Naive Bayes classifiers*. Lift is basically the *ratio* of *Confidence* and *Support*. It is the *strength of any rule*, which can be defined as formula:

# $Lift = \frac{Support(X,Y)}{Support(X) \times Support(Y)}$
