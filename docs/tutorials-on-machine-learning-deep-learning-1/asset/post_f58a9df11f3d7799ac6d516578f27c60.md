
# ------ Naive Bayes model
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# # Extract Data
dataset = pd.read_csv('Social_Network_Ads.csv')
X = dataset.iloc[:, [2, 3]].values
y = dataset.iloc[:, 4].values

# # Feature-Scaling After Data Split
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)

# # Feature-Scaling
from sklearn.preprocessing import StandardScaler
st = StandardScaler()
X_train = st.fit_transform(X_train)
X_test = st.transform(X_test)

# # Train set to Naive Bayes classifier: No parameter is needed
from sklearn.naive_bayes import GaussianNB
classifier = GaussianNB()
classifier.fit(X_train, y_train)

# # Predict
y_pred = classifier.predict(X_test)

# # Making the confusion matrix use the function "confusion_matrix"
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred)
# parameters of cm: y_true, y_pred: Real values, and y_pred: Predicted value

# # Visualizing the Training results
from matplotlib.colors import ListedColormap
X_set, y_set = X_train, y_train
X1, X2 = np.meshgrid(np.arange(start=X_set[:, 0].min(), stop=X_set[:, 0].max() + 1, step=0.01), np.arange(start=X_set[:, 1].min(), stop=X_set[:, 1].max() + 1, step=0.01))
plt.contour(X1, X2, classifier.predict(np.c_[X1.ravel(), X2.ravel()]), cmap=ListedColormap(['red', 'green']), alpha=0.25)
plt.xticks(X_set[:, 0])
plt.yticks(X_set[:, 1])
for i, j in enumerate(np.unique(y_set)):
    plt.scatter(X_set[y_set == j, 0], X_set[y_set == j, 1], c=j, cmap=ListedColormap(['red', 'green']), label=j)
plt.title('Naive Bayes (Training set)')
plt.xlabel('Age')
plt.ylabel('Estimated Salary')
plt.legend()
plt.show()

# # Visualizing the Test results

### 3.6.1 Decision Tree Regression Algorithm

The goal of the Decision Tree Regression Algorithm is to split data into similar groups. The algorithm uses something called Information Entropy, which is a mathematical process (that is super complicated).

- The point of the algorithm is to split the data in such a way that information is added and stops splitting the data when it's unable to add any more information to the dataset.

- In the Regression Chapter, we say the 'Decision Tree Regression' predict data of real numbers. Classification trees help us to classify our data, the categorical variables such as male or female apple or orange or different types of colors and variants of that. Whereas Regression trees are designed to help you predict outcomes which can be real numbers so for instance the salary of a person or the temperature that's going to be out.

- In Classification trees, we classify the data and predict categories. Here in this part we will be looking at the approach which is almost identical to that of the Decision Tree Regression.

- Here we see a graph with splits across different categories. The decision tree makes splits in a way that would maximize the number of points in each class and to minimize entropy. So in plain English, it groups as many of green and red dots together.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_124_0.png)

The decision tree would look like this:
- This is the method that will be used to add a new data point and classify it to the graph.
- Additionally, we don't always have to go all the way to the very end of the tree.
- Most of the time the tree will be very long and so at a reasonable point you could stop and have a probability where to classify.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_124_1.png)

- For example, let's say going through the graph at $X_1$, If the statement is True then we would have in this case 100% chance of it being red. Otherwise, instead going further down the list, we could say that there are Green than Red.

How it works: Decision Tree is a Supervised technique that can be used for both classification and Regression problems, but mostly it is preferred for solving Classification problems. The algorithm is just split the data so that the point of class will be maximum.

- It is a tree-structured classifier where internal nodes represent the features of the dataset.
- Branches represent decision rules.
- Each leaf node represents the outcome.
- Decision Node and Leaf Node: In a Decision tree there are two nodes, which are the Decision Node and Leaf Node. Decision nodes are used to make any decision whereas Leaf nodes are the output of these decisions. It starts with the root node, which expands further branches and constructs a tree-like structure. A decision tree simply asks a question (Yes/No), further split the tree into subtrees.

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_125_0.png)

NOTE: a decision tree can contain categorical well as numeric data.

### 3.6.2 Implementation of Decision Tree in Python

```python
from sklearn.tree import DecisionTreeClassifier
classifier = DecisionTreeClassifier(criterion='entropy', random_state=0)
classifier.fit(X_train, y_train)
```

No scaled feature: Decision Tree is not based on Euclidean distance, so we do not really apply feature scaling. Feature scaling is important when your algorithm is based on Euclidean distance. However we are building some trees, so we want to plot those trees in real values rather than scaled values. If you want to plot decision tree like the real tree then you can remove this feature part to have interpretation of your values.

**Parameters:**
- criterion: {"gini", "entropy"}, default="gini"

The function to measure the quality of a split. Supported criteria are "gini" for Gini impurity and "entropy" for the information gain. Most useful classifier and common decision tree is based on **Entropy**, eg: ***Maximum Entropy*** for NLP. So that the final nodes of tree be to as homogeneous as possible. if each split the more homogeneous is a group of users, the more the entropy is reduced from the parent node to the child node.

```python
# Naive Bayes model ---
# library
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Data Extraction
dataset = pd.read_csv("Social_Network_Ads.csv")
X = dataset.iloc[:,2]].values
y = dataset.iloc[:,4].values

# Feature Scaling After Data Split
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)

# Scaling
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
x_train = sc.fit_transform(x_train)
x_test = sc.transform(x_test)

# Fit set to Naive Bayes classifier: No parameter is needed
from sklearn.tree import DecisionTreeClassifier
clsfier = DecisionTreeClassifier(criterion="entropy", random_state=0)
clsfier.fit(x_train, y_train)

# Predict
y_pred = clsfier.predict(x_test)

# Making the confusion matrix to use the function "confusion_matrix"
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred)
# parameters of cm: y_true: Real values, y_pred: Predicted values

# Visualizing the Training results
from matplotlib.colors import ListedColormap
X1, X2 = np.meshgrid(np.arange(x_train[:,0].min(), x_train[:,0].max()+1, 0.1), np.arange(x_train[:,1].min(), x_train[:,1].max()+1, 0.1))
plt.contour(X1, X2, clsfier.predict(X1, X2), levels=[0], alpha=0.5, cmap=ListedColormap(['red','green'])).reshape(X1.shape)
plt.scatter(x_train[:,0], x_train[:,1], c=y_train, marker='o')plt.scatter(x_test[:,0], x_test[:,1], c=y_test, marker='x')
plt.title("Decision Tree (Training set)")
plt.xlabel("Age")
plt.ylabel("Estimated Salary")
plt.legend()
plt.show()
```
