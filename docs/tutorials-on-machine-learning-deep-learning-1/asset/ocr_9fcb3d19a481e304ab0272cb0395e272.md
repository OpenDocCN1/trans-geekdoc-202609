**Convolution Step:** Here we have an input image of a cat or a dog. We convert into a table of pixel values. Convolution step consists of applying several feature detectors on our input.

```
# step 1: Convolution - Layer
cnn_classifier.add(Convolution2D(32, 3, 3, input_shape=(64, 64, 3), activation="relu"))
```

For example: In our intuition section we select a smile face image (above).

+   Here the feature detector is the detector of the left side of a smiling mouth when we slide it all over the input image and when the detector passes over the part of the face that contains this left side of the mouth that is smiling, we get a high number in this notice (the 4 on feature map).

+   So for each detector that we apply on the input image we get a feature map.

+   The feature map contains some numbers and the highest numbers of the feature map where the feature detector could detect specific feature in the input image.

**Number of feature detectors:** We will choose the number of feature detectors, the number of feature maps in this step.

+   We get as many feature maps as feature detectors we detect some specific features in the input image. And those feature maps will be our Convolution-layer.

We are going to add an add() method on our cnn_classifier object (which we use in ANN to create a classic layer composed of several nodes, but here we use it to create a Convolution-layer).

**Parameters of Convolution-layer:** Remember when we added the classic layer in the ANN, we used the dense() function, which is used to add a fully connected (hidden-layer) in the ANN and this is not the function that we're gonna use here (we'll use later).

The function's general use is Convolution20().

+   nb_filter the number of filters. It specifies the number of feature-detectors/filters we're going to apply on our input image to get this same number of feature maps.
