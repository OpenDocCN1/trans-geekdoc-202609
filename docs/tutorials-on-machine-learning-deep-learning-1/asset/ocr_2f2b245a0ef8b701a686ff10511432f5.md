# ### 8.3.5 Stochastic Gradient Descent

Above we see that gradient descent is a very efficient method to solve our optimization problem where we're trying to minimize the cost function.
It basically takes us from 10^5 years to solving a problem within minutes hours or within a day or so. And it really helps speeds things because we can see which way is downhill and we can just go in that direction and get to the minimum faster.

![](bbox=[0.513, 0.423, 0.873, 0.545])

+   - Non-CONVEX cost-function: But the problem is, this method requires for the cost function to be convex. Which has only one global minima. What if our cost-function is not CONVEX. What if it looks something like this:

![](bbox=[0.263, 0.623, 0.703, 0.83])

This could happen:

+   If we choose a cost function which is not the square difference between Y and y
If we choose the cost function as square difference between Y and y but in a multi dimensional space it can actually turn into something that is not convex.
