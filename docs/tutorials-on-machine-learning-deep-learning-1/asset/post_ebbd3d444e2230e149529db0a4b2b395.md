
Product wx: To compute the product of the weights times the neurons, which is x. To make the product of two tensors in Pytorch, we need to use function mm().

```python
wx = torch.mm(x, self.w.t())
```

To make mathematically correct we actually need to take the transpose of weights W.

## Activation-now: Let's compute what is going to be the sigmoid activation function.

- The value for the activation function is (wx + bias).
- It is the same for every Deep learning model, the activation function is a linear function of the neurons where the coefficients are weights.
- Here we have the bias = a. So the value for activation is (wx + a). We name this variable activation.

```python
activation = wx + self.a.expand_as(wx)
```

- We need to do something. Remember that each input will not be treated individually, inside batches. The new dimension that we created using 1 randn(1, nh), and randn(1, nv), will ensure that input is still in the batch. And we create a mini batch.
- So when the batch has one input vector, one vector of bias, we want to make sure that the bias (of hidden nodes=a); we want to make sure that bias is applied to each line of the mini batch.
- To make sure, we need to use a function expand_as(bias) that will again add a new dimension for since we are using we expand_as(wx).
- In parenthesis, it is making it as in the similar format of wx before adding. That makes sure that the bias is applied to each line of the mini batch.
- It is a linear combination of the visible neurons, with coefficient W(weight) and added the bias.

Sigmoid-Activation: Now we compute the activation function which will activate the hidden nodes. Remember that this activation represents a probability. It will be the probability that the hidden node will be activated by the value of the visible node.

We give it name p_h_v. P(h|v).

For example, let's say that we have a user who likes drama-movies.

- If there is a hidden node that detected a specific feature corresponding to that drama genre of the movies, drama-movies are activated by 1 by the user.
- The probability of that specific node to this [drama feature] genre, the visible node of user who has all the nodes of the drama movie is equal to one.
- This probability: p_h_v will be very high because v=1 (user) and h corresponds to the drama movie so P(drama,genre|v) will be very high.

```python
p_h_v = torch.sigmoid(activation)
```

To use the activation function used of sigmoid() method of PyTorch and use the linear combination of neurons) "activation" to make it sigmoid.

## Returning "probability" and "sample of h": The final step is to return the probability p_h_v, or a sample of h.

- Sample of all the hidden nodes/neurons, according to this probability p_h_given_v.
- It's important to understand what we are making a Bernoulli RBM, we're just predicting a binary outcome (users like one or a movie).
- We'll return Bernoulli samples of the distribution. The probability is p_h_given_v.
- What does that mean?
- Right now p_h_given_v is a vector of nh elements. For example, suppose we have 100 hidden nodes while this p... is a vector of 100 elements. Each of these 100 elements corresponds to each of the 100 hidden nodes and each of these elements is the probability that the node is activated.

Let be the i'th element of the i'th hidden node is activated. Remember that's given the value of the visible nodes. Given the ratings that we're dealing with.

- So that is what we use in this p_h_given_vector, and the idea is to use these probabilities to sample the activation of each of 100 hidden nodes.
- That is for each 100 hidden nodes, depending on probability p_h_given_v that we have for these hidden nodes, we will activate yes or no, this hidden neuron.

And so how are we going to activate it?

Let's suppose that for a hidden neuron i, the probability corresponding to that neuron in p_h_given_v is 0.7. In case we take a random number between zero and one. If this random number is below 0.7 (70%) then we will activate the neuron. And if random number is larger than 0.7 then we will not activate the neuron.

- That's how bernoulli sampling works. And so we do that for each of the hidden nodes of our 100 nodes and in the end we get a vector of zeros and ones
- The zeros correspond to the hidden nodes that were not activated after the sampling.
- The ones to the neurons that were activated by the sampling.

How do we return sampling of the hidden neurons?

- We have a function call bernoulli(). In this function we have to input the distribution of which we are making that sampling, and i.e. p_h_given_v.
- So that will return the probabilities of the hidden nodes, given the values of the visible nodes (the ratings 0 or 1), and it will return sampling of the hidden neurons.

```python
def sample_h(self, x):
    wx = torch.mm(x, self.w.t())
    activation = wx + self.b.expand_as(wx)
    p_h_given_v = torch.sigmoid(activation)
    return p_h_given_v, torch.bernoulli(p_h_given_v)
```

That's the first function we need for Gibbs. But then we need another function, which is sample_v and basically we will do the same, but this time for the visible nodes.

## 14.4.9 RBM-architecture: RBM class - sample_v()

We implemented sample_h to function the hidden node according to the probabilities p_h_given_v.

- We are gonna do the visible node, from the values in the hidden nodes, that is whether they were activated or not.
- We will estimate the probabilities of the visible nodes, that is that each of the visible node equals one.

Our goal is to output the predicted ratings, which are not originally rated by the user, and these new ratings that we get in the end are taken from what we obtained in the hidden node, that is from the hidden node.
