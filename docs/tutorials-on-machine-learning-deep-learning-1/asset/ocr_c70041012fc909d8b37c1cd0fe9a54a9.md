Stopwords: A stop word is commonly used (such as "the", "a", "in") that a search engine has programmed to ignore, when indexing entries and retrieving them as the result of a search query.

```
import nltk
from nltk.corpus import stopwords
print(stopwords.words('english'))
```

Stemming: for example: keeping only the root of the word it. I love because we have loved, loved or loving or will love in a review, gives us hints however the word is positive or negative so we don't need word conjugated in the past or in the future and the present.

Because we keep all the different versions of a word, then in the end in our sparse matrix we will have tens of words and hence sparsity and our algorithm will have trouble to run because we will simply have many columns in the end you know that the sparse matrix will have its own column. That's why we are doing some sparsification here.

We import the PorterStemmer, then create an object it. And we apply it to our words in our list-comprehension.

```
import re
import nltk

from nltk.stem.porter import PorterStemmer
print(dataset['Review'][0])
rev_W = re.sub(r'[^a-zA-Z ]', '', dataset['Review'])
rev_w = [word.lower() for word in rev_W] # Converting to lower case
review = [wrd for wrd in rev_w if wrd not in stopwords.words()] # Converting to 'list'
# Removing stopwords. Stemming: Finding the root of different versions of a same word
prt_stem = PorterStemmer()
review = [prt_stem.stem(wrd) for wrd in rev_w if not in (stopwords.words('english'))]
rew = " ".join(review)
```
