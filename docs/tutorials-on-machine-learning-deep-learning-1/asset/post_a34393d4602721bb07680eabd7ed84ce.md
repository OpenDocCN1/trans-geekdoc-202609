nb_users = int(max(train_set[:, 0]), max(test_set[:, 0]))
nb_movies = int(max(train_set[:, 1]), max(test_set[:, 1]))

# converting the data into array with lines and movies in column.
def convert(data):
    new_data = []
    for user_id in range(1, nb_users + 1):
        # use [data',0] = user_id as over movie column [data',1]
        id_movies = data['data',1][data['data',0]==user_id] # returns a list

        # use [data',0] = user_id over over ratings column [data',2]
        id_ratings = data['data',2][data['data',0]==user_id]

        # vector of zeros
        ratings = np.zeros(nb_movies)
        ratings[id_movies - 1] = id_ratings

        new_data.append(list(ratings))
        return new_data

train_set_cvnt = convert(train_set)
tst_set_cvnt = convert(test_set)

### 14.4.7 Prepare Input Data : Convert ratings to binary-rating-tensor

We have to convert these ratings for the RBM. Right now, we have **ratings** from **1** to **5** in our **training set** and **test set**.

- Now we have to convert ratings into binary ratings. Because **RBM-recommender system** will generate binary-ratings.
- **1 = liked, or 0 = not liked.**

> Why do we have to convert ratings?
> Because we need to have the binary format **0** or **1**, the **RBM** will take the **input vector**, from this vector, **RBM will predict** the **ratings** for the movies that were **not originally rated** by the user.
- Since these predicted ratings are computed, originally, from the *existing ratings* of the *input vector*, well, then the predicted ratings in the output must have the same *format* as the existing ratings in the **input**.
- Otherwise, this would be inconsistent for the RBM.

- Convert all these ratings into binary ratings. **1** or **0** for both the **training set** and the **test set**
- We'll replace all **0** in the original training set, by **-1**. Because the **zeros** in the original training set, corresponded to the movies that were **not rated** by the **users**.
- Now, once **(-1)** will mean that there was no *rating* for a specific movie, given by a specific user.

```python
train_set_tensor[train_set_tensor] == -1
```

And in brackets, we simply added the condition that we want to get these ratings. This is a torch-tensor-operation, that finds all **0**s in the elements of the **tensor** and replace them with "-1"

We're going down for the other ratings, from 1 to 5.

- The ratings we want to convert into **zero**, that is, not liked. The movies that were one-star or **two stars**.
- Unfortunately, the "or" doesn't work with torch objects. There is no in **torch.tensor** object that we can apply as:

```python
test_set_tensor == 1 or (test_set_tensor == 2)
```

- The operator does not work like PyTorch. Why's we have to do this separately:

```python
train_set_tensor[train_set_tensor == 1] = 0
train_set_tensor[test_set_tensor == 2] = 0
```

- This **tensor-operations**, finds all **1, 2**s in the elements of the **tensor** and replace them with "0"
- For the movies that liked, we make them 1 for those movies that are rated **3**, **4** or **5**.

```python
train_set_tensor[train_set_tensor >= 3] = 1
```
![](img/0aa092657a6eb1b9f2dd65bbb79055a3_492_0.png)

In brackets, we simply added the condition that ">=3", this torch-tensor-operation, finds all 3, 4, 5 in the elements and replace with '1'. The movies rated by the users. So, three stars, four stars, five stars more. Now we use the same for test:

```python
test_set_tensor[test_set_tensor == 0] = -1
test_set_tensor[test_set_tensor == 1] = 0
test_set_tensor[test_set_tensor == 2] = 0
test_set_tensor[test_set_tensor >= 3] = 1
```

Now all the ratings from one to five will be converted into binary ratings in both training and test set. So, we get our inputs ready to go into RNN, and then RNN will return the (predictions) of the movies which were not originally rated in the input vector.

> # Converting the ratings into binary ratings: 1 (liked), 0 (not liked)
```python
train_set_tensor[test_set_tensor == 0] = -1
train_set_tensor[test_set_tensor == 1] = 0
train_set_tensor[test_set_tensor == 2] = 0
train_set_tensor[test_set_tensor >= 3] = 1
```

Some real life examples converting tensors to numpy array:

### Example: Shared storage

PyTorch tensor residing on CPU shares the same storage as numpy array `na`:

```python
import torch
a = torch.ones((1,2))
print(a)
na = a.numpy()
na[0][0]=10
print(na)
print(a)
```

Output:
```
tensor([[1., 1.]])
[[10., 1.]]
tensor([[10., 1.]])
```

### Example: Eliminate effect of shared storage, copy numpy array first

To avoid the effect of shared storage we use copy() the numpy array `na` to a new numpy array. Numpy copy() method creates the new separate storage.

```python
import torch
a = torch.ones((1,2))
print(a)
na = a.numpy()
ac = na.copy()
ac[0][0]=10
print(ac)
print(na)
print(a)
```

Output:
```
tensor([[10., 1.]])
[[1., 1.]]
tensor([[1., 1.]])
```

Now, the `ac` numpy array will be altered with the line `ac[0][0]=10`, `na` and `a` will remain as is.

### Example: CPU tensor with requires_grad=True

```python
import torch
a = torch.ones((1,2), requires_grad=True)
print(a)
na = a.detach().numpy()
na[0][0]=10
print(na)

```

Output:
```
tensor([[1., 1.]]), requires_grad=True)
[[10., 1.]]
tensor([[10., 1.]]), requires_grad=True)
```
