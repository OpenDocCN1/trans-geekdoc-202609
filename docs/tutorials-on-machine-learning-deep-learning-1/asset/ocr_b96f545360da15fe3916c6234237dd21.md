# Important to know:

+   - SOMs retain topology of the input set
- SOMs reveal correlations that are not easily identified
- SOMs classify data without supervision
- No target vector -> no backpropagation
- No lateral connections between output nodes

NOTE:
A couple of things that are important to know:

[1]. SOMs retain topology of your input set: The map slowly becomes a musk of your data. Your data might have some topology, interrelations in your data. SOM retain this.

[2]. SOMs actually reveal correlations between data that are not easily identified: Say you show features of columns in your dataset can be very challenging to find kind of correlations or similarities that might be present in your dataset.

[3]. SOMs classify data without supervision: SOM is unsupervised Deep learning technique. SOMs don't need labeled data.

It doesn't need any supervision, the SOM will extract features on its own, show features, dependencies, correlations, and similarities. It can be used in scenarios where you don't know what you're looking for but want to find any kind of correlations in your data.

[4]. SOMs don't require a target vector: There is no backpropagation in the training of a SOM (unlike ANN). SOM doesn't have a target vector. There is no error to backpropagate.

In ANN the data would go through the NI we get a weight update compared to the target vector; we'd find the error and then backpropagate through the NI to update the weights.

[5]. If there is no connections between the output-nodes: We find when you put on one node, the other close gets pulled.

When we say there's no lateral connections between the output-nodes means that there's no actual NN type of connections there no activation functions between them and so.

Sometimes you'll see images where the output-nodes are connected. There's a grid behind the nodes. They're just showing that those are output-nodes. But there is no actual formulas or equations going between output-nodes.
