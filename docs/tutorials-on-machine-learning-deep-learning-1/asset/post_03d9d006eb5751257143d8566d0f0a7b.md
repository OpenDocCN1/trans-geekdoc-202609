## 6.2.1 Thompson Sampling

We're going to be using this algorithm to solve the *Multi Armed Bandit Problem.*

- **Multi Bandit Problem**: We have several slot machines each of them has a distribution behind it. We don't know what these distributions are and we need to start playing these machines and at the same time figure out which one has the best distribution.

So we have to find that **ideal balance** or tradeoff between *exploration* and *exploitation*

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_195_0.png)

Multi arm Bandit Problem Assumptions

- [1] We have *d* arms. For example, arms *Ad*: $ad_1, ad_2, \dots, ad_d$ that we display to users each time we connect to a **web page**.
- [2] Each time a user connects to us, it makes a **round**.
- [3] At each round *n*, we choose *one* *ad* to display to the user.
- [4] At each round *n*, we give $r_n(n)$ defined as:
$$r_n(n) \in \{0, 1\} : r_n(n) = \begin{cases} 1 & \text{if the user clicked on the ad} \\ 0 & \text{if the user didn't click} \end{cases}$$
- [5] Our goal is to maximize the total reward we get over many rounds.

## Bayesian Inference

- Ad *i* gets *y* from Bernoulli distribution $p(y|\theta_i) \sim B(\theta_i)$.
- $\theta_i$ is unknown but we set its uncertainty by assuming it has a uniform distribution $p(\theta_i) \sim \mathcal{U}([0,1])$, which is the prior distribution.
- Bayes Rules: we approach $\theta_i$ by the posterior distribution

$$\frac{p(\theta_i|y)p(\theta_i)}{\int p(y|\theta_i)d\theta_i} \propto \frac{p(y|\theta_i)}{\text{likelihood function}} \times p(\theta_i)_{\text{prior distribution}}$$

- We get $p(\theta_i|y) \sim \eta(\text{number of successes} +1, \text{number of failures} +1)$
- At each round *n* we take a random draw $\theta(n)$ from this posterior distribution $p(\theta_i|y)$, for each *ad*.
- At each round *n* we select the *ad* that has the highest $\theta_i(n)$.
