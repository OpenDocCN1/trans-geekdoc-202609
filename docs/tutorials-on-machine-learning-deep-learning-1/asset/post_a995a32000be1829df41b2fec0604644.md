
# 10.9 LDA in Logistic: Model & Visualize the result

LDA is not another technique for feature extraction. We consider the wine.csv data from PCA. We are going to extract new variables that will reduce the dimensionality of our data as we did in PCA.

- PCA feature extraction technique reduced the dimensionality of our problem by extracting the variables that explain the most variants.
- LDA is quite different. Here, we are extracting some new independent variables(from the n independent variables of our dataset extracts p ≤ n new independent variables) that will separate the classes of the dependent variable.
- The fact that (DV) dependent variable is considered LDA a supervised model.
- LDA is a supervised Feature-Extraction method: Since LDA considers the classes of the dependent variable, LDA is going to extract the independent variables that separate the classes and the classes are related to the dependent variable i.e. LDA works with dependent variable to proceed feature extraction.
- That makes LDA supervised dimensionality reduction model (on the other hand, PCA was unsupervised because we didn't consider the dependent variable).

**Problem Description:** We are going to work with the same business problem "the wine chemical Customer_Segment problem" and we're going to use LDA beat the accuracy obtained by PCA that is 97%, we will see if we get a perfect accuracy of 100% (no incorrect segments).

**Data preprocessing:** This is going to be the same as in PCA because we just need a training set and a test set on which we apply features screening.

- We have our training set that is scaled so far contains the 13 independent variables.

**Import LDA:** Our model classification doesn't have to be a logistic regression, it can be SVM or a decision tree classification.

- But we need to apply LDA before fitting your classification model to the training set.

```

**Linear Discriminators:** The extracted features in PCA we called them Principal Components. In LDA extracted features are Linear Discriminators.

- n_components: We specify the number of components i is the number of Linear Discriminators.
- We don't need to build a layer of explained_variance because we're not looking for the independent variables that explain the variance or any kind of observability vector. We'll directly take n_components = 2.

There is no need for explained_variance, because we're not looking for the independent variables that explain the most variance. We are now looking for the independent variables that separate the most classes of the dependent variable(already three classes segment).

- Our goal is to visualize the training-results and the test-set results. We are already ready using 2 Linear Discriminators. For this reason we directly choose n_components = 2.

**Building the LDA model:** Also LDA is a supervised technique, we need to use independent (feature matrix) and dependent-vector both fit_method.

- Notice for training set we used fit_transform(X_train, y_train), but for test set we used only the independent (feature matrix) transform(X_test). We will predict the dependent variable by fitting the test data.

```
X_train = dcPose_lda.transform(X_train, y_train)
X_test = dcPose_lda.transform(X_test)
```

The fit transform method fits the object in the training set (X_train, y_train) are used and at the same it extracts 2 Linear Discriminants so that X_train becomes a matrix of two new features (of-13 features).

We use the transform on the test set, so that X_test becomes a matrix of features containing the 2 linear Discriminants.

We do not include y_test in transform, y_train in fit_transform is just used to build/fit the LDA object to train the LDA model.

```
# Applying LDA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
dcPose_lda = LinearDiscriminantAnalysis(components=2)
# notice: in fit_transform both are independent & dependent: X_train, y_train
X_train = dcPose_lda.transform(X_train, y_train)
X_test = dcPose_lda.transform(X_test)

NOTE that LDA is a supervised model it needs dependent variables, hence both X_train, y_train are used, because we are looking to separate the most different classes of the dependent variable.

# 10 Kernel-PCA in Python: Linear model & non-linear data

PCA and LDA techniques work on linear problems (i.e. when the data is linearly separable).

- Here we consider non-linear problems where the data is not linearly separable. Here we'll apply a new feature extraction technique. This technique is called kernel-PCA.
- kernel-PCA is a kernelized version of PCA where we map the data to a higher dimension using the kernel trick. From there we extract some principal components (PCs) and we're going to see how it manages with non-linear problems.
