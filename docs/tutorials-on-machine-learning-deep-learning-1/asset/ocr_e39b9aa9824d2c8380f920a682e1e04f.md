### 32a Feature Scaling
```python
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()

X_test = sc.transform(X_test)
```
```

We do not need to fit and transform the DUMMY VARIABLES: It depends on how much you want to keep interpretation in your models. If we scale this it will be good because everyone will be on the same scale we will be happy with that and it will be good for our predictions but will lose the interpretation of knowing which observations belongs to country etc.

+   - So as you won't break your model if you don't use the dummy variables because they will be on the same scale as the features.

We do need apply scaling to the DEPENDENT VARIABLE: In our case it is a categorical variable because it's taking only two values 0 and 1.

We do not need to do it because this is a classification problem with category dependent variable. But you will see for regression when the dependent variable will take a large range of values. We will need to apply feature scaling to the dependent variable as well.

### Feature Scaling for other models: Even sometimes models are not based on Euclidean distances we will still need to do features scaling the ALGORITHM will converge much faster. That will be the case for decision trees. Decision trees are not based on Euclidean distances but you will see that we need to do feature scaling because if we don't do it for a very long time.
```
