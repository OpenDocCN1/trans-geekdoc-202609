### 6.2.2 UCB vs Thompson Sampling

![](img/0aa092657a6eb1b9f2dd65bbb79055a3_199_2.png)

- Deterministic
- Requires update at every round
- Probabilistic
- Can accommodate delayed feedback
- Better empirical evidence

UCB is a deterministic algorithm, there's lot of different modifications to the algorithm, all belongs to a family of UCB. They are all deterministic and what that means is that it is very straightforward.

Once you pull the lever then you look at the upper confidence and get to pick a random value from the machine. But since there is on the side of the machine, we get the value that is determined. There is no randomness in the algorithm itself.

On the other hand the THOM SAMPLING ALGORITHM is a probabilistic algorithm in which there are distributions which represent our perception of the world and where we think the actual returns of those machines might lie.

Every time we are implementing or iterating in the Thompson Sampling Algorithm we actually generate random values from those distributions.

So it's going to be different because you're always sampling from your distributions which characterize your perception of the world and that is a different type of algorithm. It's a probabilistic algorithm.

UCB requires an update at every round (for each round). So once you pull the lever and you get a value back from machine that you value to incorporate it right away to proceed to the next round. You cannot proceed to the next round until you have incorporated that value.

Until you have made an adjustment to the algorithm based on that value if you don't make the adjustment then nothing changes and you're going to be stuck.

Whereas in the Thompson Sampling Algorithm can accommodate delayed feedback and it's very important. This basically means if you pull the lever and you only keep the record of results (say, pulling the lever 500 rounds), and input data to the Thompson sampling. Thompson Sampling will still work.

Why not if you run the algorithm now without updating your perception of the world you're still going to get a new set of hypothetical bandits. Because you are generating in a probabilistic manner.

And this is very important to understand this because the Thompson sampling that advantage that you don't have to update the algorithm with the result every time.

In terms of test Bandit it doesn't really matter that because if you're playing in the casino or out of sight if some hypothetical person is playing in a casino and they're pulling their lever to get the results right away. So they could update Algorithm.

But in terms of web sites and ads it's a big deal. Just you're just displaying ads on a Web site or you could use this for A/B testing the different layouts of your Web site. You could use a Thompson sampling algorithm to have balance between exploitation and exploration

This sampling allows you to do is to update your dataset or your information algorithm in a batch manner.

Thompson sampling algorithm has that better empirical evidence than to be used.

Here we can conclude that Thompson sampling algorithm would better choice.

# Thompson Sampling Algorithm

Step 1. At each round n, we consider two numbers for each ad i:

- $N_i^1(n)$ - the number of times the ad $i$ got reward 1 up to round $n$,
- $N_i^0(n)$ - the number of times the ad $i$ got reward 0 up to round $n$.

Step 2. For each ad $i$, we take a random draw from the distribution below:

```
$\theta_i(n) = \beta(N_i^1(n) + 1, N_i^0(n) + 1)$
```

Step 3. We select the ad that has the highest $\theta_i(n)$.

Step 2: For each Ad we take a random draw from distribution, which is the beta distribution.

$\theta_i(n) = \beta(N_i^1(n) + 1, N_i^0(n) + 1)$

We have two important assumptions which are related to Bayesian inference:

# Inference
- Ad gets rewards from Bernoulli distribution $p(y) \sim B(\theta_i)$.
- $\theta_i$ is unknown but we know its uncertainty by uniform distribution $p(\theta_i) \sim U([0,1])$, which is the prior distribution.
- Bayes Rules: approach $\theta_i$ by the posterior distribution $p(\theta_i|y) \propto p(y|\theta_i)p(\theta_i)$.
- The first assumption is in this line where we are showing the Ad gets rewards from Bernoulli distribution of parameter $\theta_i$. $\theta_i$ is the probability of success. And you can consider this probability of success by showing the Ad to a huge amount of users like 10000 and could be interpreted as the number of times outcomes: $\theta_i = \frac{\text{number of successes}}{\text{total number times selected the Ad}}$.

2] Second Assumption: Recall Bayes Theorem. The second assumption is stronger than one. we assume that $\theta_i$ is a uniform distribution with prior distribution $p(\theta_i)$.

3] Then we use Bayes Rule to get posterior distribution which is $p(\theta_i|y)$.

```
$p(\theta|y) = \frac{\text{number of success} + 1}{\text{number of failure} + 1}$
```

So at each round we take a random draw from this $\beta$-distribution. These random draws are approaching the probability of success, we get the maximum of these random draws. At each round, we select the Ad that has the highest probability of success $\theta_i$; $(n)$.

That's the idea Thompson Sampling:
- We were trying to estimate these parameters $\theta_0, \theta_1, \dots, \theta_{10}$, the probabilities of success of each of 10 Ads.
- By taking these random draws and taking the highest of them we are estimating the probability success and this highest probability success corresponds to specific Ad at each round.
- So for small amount of round, we might be wrong, but when we take these random draws over thousands of rounds all of them corresponds to the Ad that has the Highest Probability Of Success (highest probability of getting reward=1).

c) Step 3: What we did. Taking the maximum of these random draws is the maximum of these estimations of the probability of getting reward equals. Now we implement the strategy of step 2 and step 3 in Python. It is much easier than UCB, we just need to use one method, `random.betavariate()`

- The `random.betavariate()` will calculate the $\beta$-distribution for each i-th Ad (ie each of 10 Ad). We then select the Ad\_i$ that has maximum value of the calculated $\beta$-distribution.

```
for n in range(N):
```
