# # 11.2 K-fold cross-validation : Evaluate model performance

Let's start with this K-fold cross-validation, our first technique of model selection. We are going to use one of the model that we've built previously and apply K-fold cross-validation on.

+   We use the kernel SVM model from *Chapter - 3 : Classification*. Where we used the Social Network Ads data and kernel-SVM to prevent our customers from clicking on the ads on the social network to buy the SUV (or not).

+   We'll use the dataset *Social_Network_Ads.csv* contains the information of users obtained from the social networking sites. It is a car making company that has recently launched a new SUV. We wanted to check how many users from the dataset, want to purchase the car.

+   Since the model is already built and we already have everything. We just copy the code and K-fold cross-validation in right place (on a new section of code).

+   **Where to apply K-fold cross-validation section**: Since that consists of evaluating the model performance, the most relevant location to put it is right where we build our *kernel SVM model* that is right what we build.

+   **After y_pred and confusion-matrix**: Since getting the predictions of the test results and evaluating the confusion-matrix is actually a good way of evaluating our model. Not the best, but we apply K-fold cross-validation after y_pred and confusion-matrix.

We import the *cross_score* from *sklearn.model_selection* (the same module already used for *train_test_split*)

```python
from sklearn.model_selection import cross_val_score
```

Now we apply k-fold cross-validation on our training set. we get out of cross_val_score called *Accuracies* (this is actually a vector).

+   **Accuracies** return 10 (a vector of accuracies of the model) for each one of the 10 combinations that will be created through 10-fold-cross-validation (K=10 here).

```
accuracies = cross_val_score(estimator=clsFier, X=X_train, y=y_train, cv=10)
```

**Parameters:**

+   i. estimator: the object that is implementing 'fit' on the data. This is our SVM-classifier object, so we set estimator = clsFier.
ii. X: the data to split. it is our feature-matrix of the training sets. So we set X = X_Train.
iii. y: the target variable (the dependent variable vector) to predict in the case of supervised learning. So we set y = **y_train**.
iv. cv: The cross-validation splitting strategy. It is the number of k-fold cross-validation. Here we wanna apply 10 folds so we set cv = **10**.

+   The most common choice for this CV is actually 10. Most of the time you'll use 10-fold-cross-validation where you use 10 accuracy's and 10 accuracies is a *relevant idea of the model performance*

+   n_jobs (optional): Number of jobs to parallel. Using the estimator (classifier or regressor) and computing the score are *parallelized* over the cross-validation* splits.
-1 means 1 unless in parallel, backend. It means that you will use all the CPU on your machine and therefore you can run *k-fold-cross-validation* even for a very large dataset.

**Calculating mean of accuracies and standardared deviation**: We use mean() to return mean, std() to return standard deviation.

```
mean_acc = accuracies.mean()
std_acc = accuracies.std()
