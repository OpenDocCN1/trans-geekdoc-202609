# 14.2.1 Restricted Boltzmann Machines (RBM)

And we are going to see how Restricted Boltzmann Machines (RBM) learns, and how it is applied in practice.

+   - BM: Here we've got the standard Boltzmann machine, we've got all of these intra connections. Every single node connects to each other.

+   - In theory this is a great model and we can solve lots of different problems. But in practice it's very hard to implement. We simply cannot compute a Boltzmann machine, the reason is as you increase number of nodes, the number of connections between them grows exponentially.

![](bbox=[0.465, 0.233, 0.835, 0.353])

+   - RBM: Therefore, a different type of architecture was proposed which is called the Restricted Boltzmann Machine (RBM).

+   - Here in RBM, we've got exactly the same concept with the simple restriction that

+   - Hidden nodes cannot connect to each other
- Visible nodes cannot connect to each other.

+   - Everything else is same to the BM. We've also got undirected connections.
