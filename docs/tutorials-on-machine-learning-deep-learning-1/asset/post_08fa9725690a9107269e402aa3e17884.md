
## 12.3.6 Building the RNN: Structure of our RNN

Now we're going to build the RNN, the whole architecture of our LSTM.

- It's not gonna be an LSTM, it's a stacked LSTM with several LSTM layers and we're going to make it perfect.
- We're gonna make it robust by adding some dropout regularization to avoid overfitting.
- But keep in mind: "All models are rough, but some are useful."

## Libraries and Packages:

```python
# importing keras libraries and packages
from keras.models import Sequential
from keras.layers import Dense
from keras.layers import LSTM
from keras.layers import Dropout
```

- Sequential will allow us to create a neural network object representing a sequence of layers (other representation is graph).
- Dense class to add the output layer.
- LSTM class, to add the LSTM layers.
- Dropout class to add some dropout regularization.

## Initialize our RNN:

```python
# Initialize the RNN
regressor_rnn = Sequential()
```

We're gonna use the Sequential class from keras to initialize our regressor as a sequence of layers. [Since we're dealing with regression problem, we will use 'regressor', for classification problem we use 'classifier'].

- This time we're predicting a continuous value, the Google stock price, and therefore we are doing some regression.
- Remember, regression is about predicting the continuous value and classification is about predicting a category/class.

We also gonna build Computational Graph in following chapters. But to build some graphs, we use PyTorch, because for this, which is much more powerful tool for dynamic graphs.

Add The Different Layers: Now we add the different layers, to make it a powerful stacked LSTM. We add the first LSTM layer, of our RNN which was introduced as a sequence of layers and add some dropout to avoid Overfitting.

```python
# adding first LSTM Layer & some Dropout-Regularization
regressor_rnn.add(LSTM(units=50, return_sequences=True, input_shape=(X.train.shape[1], 1)))
regressor_rnn.add(Dropout(rate=0.2))
```

Inside the add() method, we need to input the layer, the type of layer we want to add.

- Since we want to add an LSTM layer, we use LSTM to add first layer (and Dense) to add output layer.

## Parameters:

- Units: it is the number of LSTM cells or units in our LSTM layer. We use a very high number of LSTM cells, or memory units, (for simplicity it's just call them neurons).

Why more dimensions: Now already your model will have a very high dimensionality, because we are going to stack many layers. We can increase this dimensionality even by including a larger number of (neurons) in each of the LSTM layers.

- Since capturing the trends of a stock price is pretty complex, we need to have this high dimensionality and we also need to have a large number of neurons in each of the multiple LSTM layers.

And therefore, for number of neurons we chose for this first LSTM layer is gonna 50. The next layers, will also have 50 neurons, that we will use a model with high dimensionality and will lead to better results.

- return_sequences: we it is True, because we are building a stacked LSTM which has several LSTM layers. When we add another LSTM layer after another, we have to set return_sequences=True.
- Once you are done with your LSTM layers, we not not add another layer after that, we will set return_sequences=False, (however we don't have to do it because it's a default value of)

**input_shape**: is exactly the shape of the input containing **X_train** that we created in the last step of the preprocessing part, corresponding to the **observations**, the **time_steps**, and the **indicators**.

But in this third argument of the LSTM class, we need to include all three dimensions, only the **time_steps** and the **indicators**.

i.e. from (X.shape[0], X.shape[1]) we need to input (**X.shape[1], 1**). The first X.shape[0] corresponds to the observations, will be automatically taken into account.

**Adding Dropout-Regularization**: We recommend to use 20% it because it's relevant. 20% of the neurons 10 out of 50 neurons of the LSTM, will be ignored during training, the forward propagation and backpropagation.

```python
regressor_rnn.add(Dropout(rate = 0.2))
```

We're gonna add a total of 4 LSTM layers, so that will make a big LSTM.

## 12.3.7 Building the RNN: extra LSTM layers

Now we add some LSTM layers, with dropout regularization.

- **Adding 2nd LSTM layer**: We only need to change one, which is the **input_shape**.
We had to specify **input_shape** in first layer but we don't need it for second layer, because it's recognized automatically. Then 50 neurons in hidden layer also make high dimensionality to our model, but we are able to handle the complexity of the problem.
Augment the dimensionality of our model, will augment at the same time the complexity, and therefore will respond to better results.
We're keeping 20% dropout for the regularization, since that's a relevant choice.

```python
regressor_rnn.add(LSTM(units=50, return_sequences=True)
regressor_rnn.add(Dropout(rate = 0.2))
```

- **Adding 3rd LSTM layer**: We only need to copy the 2nd LSTM layer. All are just same.

- **Adding 4th LSTM layer**: We only need to copy the 2rd LSTM layer. The parameter **return_sequences** is set to False because the last LSTM layer and next is the output layer. We are not going to return any sequences, since the default value of return_sequences is False, we are removing this one.

```python
regressor_rnn.add(LSTM(units=50, return_sequences=False))
regressor_rnn.add(Dropout(rate = 0.2))
```

However we can specify the number of neurons in the LSTM layers, and we're keeping 50 neurons to have high dimensionality.

## 12.3.8 Building the RNN: output layer, compile & fit

**output-layer**: for an output we are not adding an LSTM layer, but a fully connected layer (similar to CNN). The output layer is fully connected to the previous (4th-layer) LSTM layer.

- To make a connection we need to use the Dense class exactly as we did for ANN and CNN.

```python
# The outputLayer
regressor_rnn.add(Dense(units = 1))
```

We specified **units = 1** because we are defining a real value corresponding to the stock price, i.e. the output has only one dimension. So there be one neuron in output-layer. This will output our stock price at time T +1

Now're done with architecture of our super LSTM RNN.

- **Compiling the RNN**: Our optimizer will be 'adam' and the loss-function will be the mean_squared_error because we're some region.
- We use the compile() method, it is another method of the Sequential class.

```python
# Compiling the Model
regressor_rnn.compile(optimizer='adam', loss='mean_squared_error')
```

**optimizer**: For RNN rmsprop is recommended some kind of SGD optimizer that usually a good choice for RNN.

- rmsprop, with our implementation we're not using a rmsprop, here we use the adam optimizer.
- The adam optimizer is always a safe choice for SGD. It's always a good choice because it is very powerful and it always performs some updates of the weights.

**Loss**: we don't use cross-entropy. So the loss is not gonna be binary_crossentropy or categorical_crossentropy.

- We're dealing with a regression problem because we have to predict a continuous value and the loss for this of problem is the mean_squared_error.
- So that the error can be measured by the mean of the squared differences between the predictions and the targets. Targets means real values.
- Mean error, sometimes called MSE.

Now our regressor is compiled with a powerful optimizer 'adam' and the right function mean_squared_error.

Fit/train the RNN to our training set: Notice we do not use training_set or train_set. Our training is composed of X_train, the data structure that is expected by the neural networks.

- So we need to train X_train and training_set, train_set.

We need to specify the output=y_train, when fitting the regressor to our training sets the output contains the ground truth that is stock at time T+1

- We're training the RNN on the true stock price at time T+1, the 60 previous days during the 60 previous financial days. So we also need to include the ground truth(dependent-variable) and therefore y_train.

It is the final part of two, building the RNN here to train, X_train, and y_train. The training will happen in this part and we'll have a robust RNN but mostly, we will have one smart RNN: Ours will be intelligent, neural network, be able to predict some, the upward trends, and downward trends of the Google stock price.
