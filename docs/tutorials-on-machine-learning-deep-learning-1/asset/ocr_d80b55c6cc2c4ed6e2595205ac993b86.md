This is the last step of the Data Processing, we will add a new dimension to this structure, which will make it more powerful.

+   - Adding a dimension is related to Samsung.
-
- You do not have to do it with only one column. Open stock, but with several other indicators.
- These indicators can be some other columns of our dataset, like example the Close column, or the Volume.
- Or even some different stock prices/other-companies related to Google. For example: Apple is related to Samsung.

This step is reshaping the data that we are adding some dimensionality to the data structure that we just made.

+   - This dimension is actually the allant, the number of predictors to predict Google stock price at T+1. In this financial engineering problem, where we will try to predict the trend of Google Stock Price, the predictors are indicators.
- Right now we have one indicator, which is the Open Google Stock Price.
- Now in this new dimension that we're gonna add our data structure, we will be able to add some more indicators.

That could help predict the better answer and downward trends of the Google Stock Price (we're not gonna do it in this implementation. We will just use the open Google Stock Price).

# Implementing Reshape:

+   - It's actually simple, it just takes one line of code. We're gonna use the reshape() function. Anytime you want to add a dimension in a NumPy array you always need to use the reshape() function. because X_train contains all the inputs of the NN.
- We need to do this for X_train.

Also we need to create this new dimensionality of this new data structure, because this shape is expected by the future RNN that we're gonna build in the next.

+   - So that's not only for use more indicators, but also to be compatible with the input format/shape of the RNN.

reshape() is taken from NumPy library. In this reshape() function, we need to input two arguments.

+   - The first argument is our current-data-structure we want to reshape.
- In the second argument we need to specify this new structure. We're gonna include three elements (to add these three dimensions), because our data structure has a NumPy array of 1198 rows and 60 columns.
- After adding a dimension it will be a Stack of 1198 x 60 NumPy array.

```
# Reshaping
X_train = np.reshape(X_train, X_train.shape[0], X_train.shape[1], 1))
```

+   - X_train.shape[0] = no. of rows of X_train = 1198
- X_train.shape[1] = no. of columns of X_train = 60
- No. indicators = 1. We set it

Our 2D array is now the first-layer of a 3D tensor.

Function numpy.reshape gives new shape to array without changing its data. it is a numpy package function. First of all, it needs to know what to reshape, which is the first argument of function (in your case, you want to reshape X_train).

Then it needs to know what is the shape of our matrix. This argument needs to be a tuple. For 2D reshape you can pass (M, H), (W, H, D), for four dimensions you can pass (W, H, D, T) and so on.

However, you can also reshape a NumPy matrix by X_train.reshape(W,H,D). In this case, reshape function is a method of X_train_object, you do not have to pass it and only pass the new shape.

It is also worth noting that the total number of element in the matrix with the new shape, should match your original matrix. For example, your 2D X_train has X_train.shape[0] × X_train.shape[1] elements. This value should be equal to W x H x D.
