### Stepwise Regression
Stepwise regression: Sometimes you'll hear step-wise regression. It's actually referred to as 2, 3 and 4 because they are true by step methods.

- More generally sometimes Bidirectional Elimination is called the Stepwise Regression because it is combination of Backward Elimination and Forward Selection.

**All-in:** All features are used. No specific feature is selected. When we use

- Prior knowledge: If you know prior about exact variables are going to be true predictors of your model (in case you have model before)
- You have some: Somebody gives you those variables and please build a model. Well you don't really have a choice. You just build the model (in case of framework or a company says you have to use these variables).
- Preparing for Backward Elimination: You need to use this method if you're preparing for a backward elimination.

**Backward Elimination:** Start with All Independent Variables and eliminate the rest variables one by one checking the p-values. We keep doing the procedure until we reach a point where the highest P-values are all less than their significance level

- STEP 1: Select a Significance Level SL to stay(e.g. SL = 0.05). We check P-value against this SL.
- STEP 2: Fit the full model with all possible predictors/Independent variable
- STEP 3: Consider the predictor/Independent variable with the highest P-value. If P > SL, go to STEP 4,
- STEP 4: Remove the predictor
- STEP 5: Fit again without this variable. Rebuild and fit the model with the remaining variables.
- STEP 6: Your Model Is Ready

### [3] Forward Selection: Start with one Independent Variable and add the rest variables one by one by checking the p-values. Note that we do not keep the current model where P<SL, instead we keep the previous model.

## Building A Model

### Forward Selection

STEP 1: Select a significance level to enter the model (e.g. SL = 0.05)

STEP 2: Fit all simple regression models y - x, Select the one with the lowest P-value

STEP 3: Keep this variable and fit all possible models with one extra predictor added to the one(s) you already have

STEP 4: Consider the predictor with the lowest P-value. If P < SL, go to STEP 3, otherwise go to FIN

FIN: Keep the previous model

- STEP 1: Select a Significance SL to enter the model (e.g. SL = 0.05). We check P-value against this SL.
- STEP 2: fit all Simple Regression models ~ x, for predictors there will be n Simple Regression models, select the one with the lowest P-value.
- STEP 3: Keep this variable and fit all possible models with one extra predictor (increase independent/predictor added to the ones) you already have.
- STEP 4: Consider the predictor with the lowest P-value. If P < SL, go to STEP 3, otherwise go to FIN
- FIN: Keep the previous model

Actually what we are doing:

- We create Multiple Regression model with every independent variable. Test their P-value against SL and increase predictors one by one. And out of all those models have the lowest p-value for the independent variable
- We have selected this variable and fit all other models with one extra predictor. We've selected a Simple Linear Regression with one variable. Then construct possible Linear Regressions with two variables from other predictors.
- Now we have possible 2 linear regressions. Out of these possible Two Variable Regressions we consider the one where the new variable had the lowest p-value with P < SL (means that a a good one and it's a significant variable).
- We then moved to Step 3.

Means that now we have a Regression With Two Variables and we will add a third variable. We'll try all possible variables that we have left as our third variable and out of all those with three variables we will go to Step 4 and we'll select again of the lowest p value for that third variable. And so on.

So basically we will be growing the regression model out of all of the possible combinations one time and growing at one variable at a time.

We will only stop when the variable that we've added has a p-value that is greater than our significance level SL. That is P < SL is false. Means that variable we just added is no longer significant.

> NOTE The trick is not to keep the current model but the previous one: We reject the current model with non-significant variable and pick the previous model (which are all significant).

### Bidirectional Elimination

- STEP 1: Select a significance level to enter and stay in the model e.g.: SLENTER = 0.05, SLSTAY = 0.05

- STEP 2: Perform the next step of Forward Selection (new variables must have: P < SLENTER to enter)

- STEP 3: Perform ALL steps of Backward Elimination (old variables must have P < SLSTAY to stay)

- STEP 4: No new variables can enter and no old variables can exit

FIN: Your Model Is Ready

STEP 3: Perform ALL steps of Backward Elimination (old variables must have P < SLSTAY to Stay)
STEP 4: No new variables can enter and no old variables can exit

FIN: Your Model Is Ready
