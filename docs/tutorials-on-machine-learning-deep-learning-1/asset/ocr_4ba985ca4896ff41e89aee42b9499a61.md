Agglomerative HCA Work: The working of the AHC algorithm can be explained using the below steps:

# Agglomerative HC

+   STEP 1: Make each data point a single-point cluster $ightarrow$ forms N clusters

+   STEP 2: Take the two closest data points and make them one cluster $ightarrow$ forms N-1 clusters

+   STEP 3: Take the two closest clusters and make them one cluster $ightarrow$ forms N - 2 clusters

+   STEP 4: Repeat STEP 3 until there is only one cluster

FIN

The hierarchical clustering algorithm works that it maintains a memory of how we went through following process and that memory is stored in a DENDROGRAM.
