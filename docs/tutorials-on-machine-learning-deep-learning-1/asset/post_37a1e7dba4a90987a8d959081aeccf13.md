
The best solution is actually to use a convolutional layer. And it is very easy. We have to add 2-lines of code, after our first pooling layer. However, we can always improve your model by considering the two options that are a fully connected layer.

However, we can reach our goal of getting a test set accuracy of more than 80% (also reducing the over-fitting) by adding a second convolutional layer.

We apply the 2nd convolutional operation to this first pooling layer.

We thus build this 2nd convolution and 2nd pooling layers right after the first layers, i.e. after the first convolution and first pooling layers, and before the flattening step.

```python
# Step 1 Convolution - layer
cnn_classifier=Activation(Conv2D(32, 3, 3, input_shape=(64, 64, 3), activation="relu"))

# Step 2 Pooling - layer
cnn_classifier=Activation(MaxPooling2D(pool_size=(2, 2)))

# Improving step: Adding 2nd-Convolution and 2nd-Pooling Layers
cnn_classifier=Activation(Conv2D(32, 3, 3, activation="relu"))
cnn_classifier=Activation(MaxPooling2D(pool_size=(2, 2)))
```

Notice, we don't use input_shape parameter, because there is no input_images for this layer; we are just taking the pooled-feature-maps from the previous step, the first-pooling-layer.

So we're going to apply the convolutional and the max pooling trick, not on the images but on the pooled feature maps.

Hence we don't need input_shape. Because input_shape corresponds to our images dimensions that CNN should expect.

Therefore, when you're adding an additional convolutional layer, you just need:

- a number of feature detectors,
- the dimensions of these feature detectors
- and an activation function.

And then you apply max pooling with your pool_size parameter.

If you want to find adding additional convolutional layers, then you can increase the number of feature detectors and do it each time.

For example, you can add a third convolutional layer with 64 feature detectors. That's a common practice and leads to great results.

25 epochs is about we getting an accuracy of 85% for the test set accuracy and 82% for the test set.

That's great! We're not only reached to obtain the test set accuracy over 80% and we reduced the difference between the training accuracy and the test accuracy. But now we get a difference of 3% as opposed to this 10% that we get in the previous result (84% on training set and 75% on test set).

Getting over-accuracy: Of course, adding more convolutional layers will help us get a better accuracy. But if you increase the input_shape of the image.

Higher-size: Using higher input_shape size gives us better accuracy for our images of the train set and the test set, so we use the columns in your input layer; therefore, you will have more information on the pixels.

If you increase the size of your images, all images will be resized, so you get a lot more pixels in the rows and a lot more pixels in the columns.
