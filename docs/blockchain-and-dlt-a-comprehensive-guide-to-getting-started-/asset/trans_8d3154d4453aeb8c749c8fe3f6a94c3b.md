

# 哈希函数与分布式系统基础

鉴于分布式账本上交易的大量数据，有必要使用压缩数据结构（如默克尔树）来存储区块内的信息。这减少了在网络上运行节点所需的存储空间。

哈希函数也用于工作量证明算法中，这是网络上的节点就交易状态达成共识的机制。哈希函数接收一个输入（或对象），并生成一个固定长度的输出，称为摘要。无论输入的大小如何，输出始终保持相同的大小。此外，使用相同机制进行哈希时，相同的输入将始终产生相同的摘要。哈希函数还具有抗碰撞性，意味着两个不同输入的摘要之间没有可辨别的规律。

## 哈希算法的内部工作原理

哈希函数通常通过首先将输入数据划分为预定大小的数据块，然后利用算法计算出一个固定长度的哈希值来工作。数据块的大小可能因所采用的特定算法而异，如果块太小则可能应用填充。无论算法如何，生成的哈希值始终是固定长度的，并且该函数会迭代地应用于每个数据块。

另一方面，加密涉及对数据进行打乱以创建编码消息，只有持有相应密码的人才能对其进行解扰和解码。与哈希不同，加密是可逆的，旨在稍后由授权方解密。相比之下，哈希使用一种将任意大小的数据转换为固定长度哈希的公式，使其在计算上难以逆向。虽然加密主要用于保护传输中的数据，但哈希用于验证文件或数据的真实性，并检测其是否被篡改。

从本质上讲，加密类似于将数据放入保险箱，只有收件人知道组合密码才能打开。然而，哈希更像是一个防篡改封条，它提供保证，证明数据未被篡改或更改。

## 常见加密货币哈希函数

比特币采用的 `SHA-256` 算法属于安全哈希算法（`SHA`）家族。由美国国家安全局（`NSA`）开发，`SHA` 家族包含多种算法，如 `SHA-1`、`SHA-2`（包含 `SHA-224`、`SHA-256`、`SHA-384` 和 `SHA-512`）以及 `SHA-3`（成员包括 `SHA3-224`、`SHA3-256`、`SHA3-384` 和 `SHA3-512`）。

`SHA-256` 是一种广泛使用且高度安全的哈希算法。它被认为是 `SHA` 家族中最稳健、最可靠的加密技术之一。

其他常见的哈希算法包括消息摘要（`MD`）算法，包含 `MD2`、`MD4`、`MD5` 和 `MD6`。`MD5` 曾是一种广泛使用的算法，但因哈希碰撞已被视为不安全。Windows NT 哈希，也称为 Unicode 哈希或 `NTLM`，是 Windows 系统常用的另一种流行哈希算法。其他著名的哈希算法包括 RACE 完整性原语评估消息摘要（`RIPEMD`）、Whirlpool 和 `RSA`。

一般来说，最常用的哈希算法的哈希长度范围在 160 到 512 位之间。`SHA-256` 算法以其高安全性和可靠性著称，使其成为许多密码学应用的热门选择。

# 数字签名

数字签名是一种常用的数学过程，用于确认消息（如电子邮件、信用卡交易或数字文档）的真实性和完整性。这些数字签名会生成一个专属于个人或实体的独一无二的数字指纹，用于识别用户并保护数字消息或文档中的信息。在电子邮件的语境下，电子邮件内容本身会被整合进数字签名中。数字签名比其他类型的电子签名安全得多，并增强了在线交互的透明度，在客户、业务合作伙伴和供应商之间建立信任。

数字签名通过证明数字消息或文档自签名以来未被修改（无论是有意还是无意）来发挥作用。数字签名通过生成消息或文档的唯一哈希值，并使用发送方的私钥对其进行加密来实现这一点。生成的哈希值对于该消息或文档是唯一的，更改其中任何部分都会完全改变哈希值。

完成后，消息或数字文档被数字签名并发送给接收方。接收方随后生成该消息或数字文档的自己的哈希值，并使用发送方的公钥解密发送方的哈希值（包含在原始消息中）。接收方将自己生成的哈希值与解密后的发送方哈希值进行比较，如果两者匹配，则表明消息或数字文档未被修改，且发送方身份得到验证。

# 分布式系统基础

分布式系统是一组协同工作以实现共同目标的独立计算机的集合。这些系统可以是局域网（`LAN`）中的小型计算机网络，也可以是跨越全球的大型网络。分布式系统的基本概念是允许多台计算机协同工作，就像它们是一台计算机一样。

分布式系统的关键组件之一是分布式算法的使用。这些算法旨在以高效且容错的方式协调多台计算机的动作。分布式算法的一个例子是分布式排序算法。该算法允许多台计算机并行对大型数据集进行排序，然后以确保最终结果正确排序的方式合并结果。分布式系统中的另一个重要概念是共识协议的使用。这些协议用于确保分布式系统中的所有计算机就系统状态达成一致。例如，分布式数据库可能会使用共识协议来确保系统中的所有计算机就数据库的内容达成一致。共识协议的一个例子是 Paxos 算法，它用于确保分布式系统中的所有计算机就一系列事件的顺序达成一致。

容错性是分布式系统的另一个重要方面。这指的是系统在一个或多个组件发生故障时仍能继续正常运行的能力。容错性通过使用冗余组件以及检测和从故障中恢复的机制来实现。例如，分布式存储系统可能会使用数据的多个副本，以确保即使一个或多个存储设备发生故障，数据仍然可用。

许多人熟悉的一个分布式系统例子是万维网。万维网是一个用于共享信息和资源的庞大互联计算机网络。当你访问一个网站时，你的计算机向 Web 服务器发送请求，后者再返回所请求的信息。这一过程通过使用分布式算法和协议成为可能，它们确保信息被发送到正确的计算机并正确传输。

分布式系统的另一个例子是分布式版本控制系统（`DVCS`）。这类系统用于管理软件项目的源代码。`DVCS` 允许多个开发者同时在同一代码库上工作，并确保他们的更改被正确合并。流行的 `DVCS` 示例包括 `Git` 和 `Mercurial`。
