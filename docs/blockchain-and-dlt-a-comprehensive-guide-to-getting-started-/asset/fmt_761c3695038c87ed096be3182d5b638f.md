
# 章节概览

## [Chapter 4: Permissionless Blockchain: Ethereum](#chap04.xhtml#c04)
本章介绍 Ethereum 1.0 和 2.0，深入探讨以太坊虚拟机（EVM）固有的图灵完备性，并与 Bitcoin 进行细致比较。内容延伸至实际应用层面，如 Ether 单位、Ethereum 钱包及 Metamask 的使用。详细剖析交易细节，包括结构、Gas 机制，以及向外部拥有账户（EOA）和合约传递价值。最后正式讨论智能合约及其通过 Solidity 进行的部署。

## [Chapter 5: Permissioned Blockchain: Hyperledger Fabric](#chap05.xhtml#c05)
本章聚焦 Hyperledger Fabric，包含对该框架的深度介绍，阐述 Hyperledger Fabric 区块链不可或缺的工具与架构。进一步深入探讨 Hyperledger Fabric 的复杂组件，同时应对区块链领域内互操作性与可扩展性相关的挑战。

## [Chapter 6: Crypto Assets and Cryptocurrencies](#chap06.xhtml#c06)
本章剖析 ERC20 和 ERC721 Tokens 等概念，探讨 ERC-721 与 ERC-20 代币的差异，并阐述非同质化代币（NFT）的重要性。本章旨在指导读者驾驭复杂的数字资产，提供对首次代币发行（ICO）、证券型代币发行（STO）及多种加密货币的深入理解。

## [Chapter 7: Blockchain Applications and Case Studies](#chap07.xhtml#c07)
本章介绍区块链在 IoT、AI 和网络安全领域的变革性影响。探索区块链如何增强物联网安全、保障 AI 伦理应用及强化网络防御。真实案例研究展示了实际应用意义，使本章成为理解区块链技术与这些动态领域交汇演进的必备指南。
