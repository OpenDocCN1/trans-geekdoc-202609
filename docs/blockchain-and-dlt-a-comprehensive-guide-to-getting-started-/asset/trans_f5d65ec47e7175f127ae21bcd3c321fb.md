

# 分布式系统与区块链技术的历史演进

鲜为人知的是，早在 1960 年代初期，麻省理工学院（MIT）Robert Taylor 领导的研究团队就诞生了第一个分布式系统——兼容分时系统（CTSS）。该系统允许多用户通过远程终端并发访问单台大型主机，极大地提高了昂贵计算资源的利用率，为现代分布式系统奠定了基石。此后，该领域持续演进，以满足计算系统对可扩展性、可靠性和可用性日益增长的需求。

区块链技术作为一种数字账本系统，于 2000 年代末随比特币的发明而诞生。其基于分布式系统原理：数据与计算分散在网络的多个节点上，不存在中心控制点。可以将其想象为一份在成千上万台计算机网络中复制的电子表格，从而实现去中心化、透明的数据存储与共享。

区块链构建于点对点网络、共识算法等分布式系统技术之上。点对点网络由一组计算机组成，它们在无中央权威的情况下共享资源与信息，类似于朋友间直接分享音乐文件。共识算法用于验证和处理网络交易，确保所有节点拥有相同的账本副本，并就区块链的当前状态达成一致。

随着区块链技术的普及，其应用已超越数字货币范畴。众多企业和组织正探索将其用于供应链管理、数字身份等领域。例如，在供应链的每个环节记录上链，可实现全流程的透明化与可追溯性，便于快速定位问题。

综上所述，分布式系统与区块链技术的发展紧密交织。区块链建立在分布式系统的原理与技术之上，创造了一种去中心化、安全、透明的数据存储与共享方式——正如在旧地基上构建新建筑，新建筑虽有自有用途与设计，却依赖地基屹立不倒。

# 机械与机电设备的进步推动加密技术演进

早期 1900 年代二战中德军使用的 `Enigma` 密码机等机械、机电设备的进步，为更精细、高级的加密战术铺平了道路。随着计算机与互联网的到来，密码学与分布式系统在保障数字通信与信息安全方面变得愈发重要，应用广泛，解决了当今世界面临的诸多问题。未来随着现代化进程加速，我们可能遭遇更多挑战。

# 密码学的基本概念与术语

在深入探讨密码学相关概念与关联内容前，先熟悉几个基础概念与术语：

- **加密（Encryption）**：将明文转换为密文的过程，使未授权方无法读取。
- **解密（Decryption）**：将编码消息（密文）还原为原始形式（明文）的行为，供授权方阅读理解。
- **密码（Cipher）**：用于加密和解密的算法。
- **密钥（Key）**：与加密算法结合使用以打乱和还原信息的私有值。
- **对称密钥（Symmetric key）**：单一私有密钥，同时用于编码和解码过程。
- **非对称密钥（Asymmetric key）**：一对数学相关但不相同的密钥，一个用于加密，一个用于解密。
- **明文（Plaintext）**：原始的、未加密的数据。
- **密文（Ciphertext）**：加密后的数据。
- **哈希函数（Hash function）**：单向函数，接收输入（或消息）并返回固定大小的字符串，通常是唯一对应唯一消息的摘要。
- **数字签名（Digital signature）**：附加在电子传输文档上的数字代码，用于验证其内容和发送者身份。
- **公钥基础设施（PKI）**：建立、管理、分发、使用、存储和撤销数字证书所需的硬件、软件、人员、协议的集合。
- **证书颁发机构（CA）**：颁发数字证书并管理 PKI 的组织。
- **抗抵赖性（Non-repudiation）**：证明特定个人对特定行为或消息负责的能力。
- **认证（Authentication）**：验证个人或实体身份的过程。
- **密钥管理（Key management）**：创建、分发、存储和保护密钥的过程。

后续章节将详细探讨上述概念。

## 了解密码学

密码学是利用数学算法将明文转换为编码消息（密文）并反向转换，以实现安全通信的实践。如图 1.2 所示，`Cryptography` 一词源自两个希腊词汇的组合：`Kryptos`（隐藏）和 `Graphia`（书写）：

牛津词典将 `cryptography` 和 `cryptology` 定义为书写或破解密码的秘密方式。它是包含密码学与密码分析的科学，但 `cryptology` 一词有时宽泛地指代渲染信号安全和从中提取信息的双重领域。

密码学是利用数学算法将明文转换为编码消息（密文）并反向转换，以实现安全通信的实践。它是计算机安全的基本要素，广泛应用于网上银行、电子商务、政府与军事组织间的安全通信等场景。

密码学不仅包含加密，还包括数字签名（验证消息真实性并确保完整性）、安全密钥交换（使双方无需预共享密钥即可建立安全通信信道）等方法。在无单一中央权威管控信息流的去中心化系统中，加密显得尤为关键——它使诚实用户能安全交换信息，防止恶意个体篡改或欺骗系统。
