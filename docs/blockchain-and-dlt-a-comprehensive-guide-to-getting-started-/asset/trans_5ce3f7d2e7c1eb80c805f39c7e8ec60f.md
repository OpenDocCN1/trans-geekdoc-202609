

# 多表加密

另一方面，多表加密通过根据密钥对同一字母使用多种替换方式来增加复杂性。维吉尼亚密码是一个常见的例子，其中密钥中的每个字母对应字母表中的不同位移。这种动态替换使得密码分析者更难破译信息，与单表加密相比提供了更高的安全性。Poly 意为“多”，在此处指对每个字母有多种加密方式，为编码信息增加了额外的保护层。

在此加密中，使用关键字来确定明文中每个字母的不同位移值。

例如：

- 原文：`HELLO`
- 密钥：`KEY`
- 密文：`RIJVS`

这里，第一个字母 `H` 向后移动 10 个位置（字母表中的 `K`），第二个字母 `E` 移动 4 个位置（字母表中的 `I`），以此类推。

## 古代密码学的各种渊源

### 埃及人

古埃及人使用了一种原始形式的隐写术，即在另一条信息或媒介中隐藏信息的做法。他们会在石板背面刻写圣书体字符，然后在背面覆盖一层蜡，并在上面写上无害的信息，使人难以察觉存在隐藏信息。希腊人和罗马人也使用过隐写术，他们会剃光信使的头，在头皮上刺青信息（这一情节在好莱坞电影中有所呈现），然后等待头发长回后再派遣他上路。

### 希腊人

希腊人设计了一种稍微不同且更简单的加密方法，即将一条纸带缠绕在一根棍子上。当纸带展开时，书写内容会显得乱码无序。预期的接收者随后会使用一根匹配的棍子来破译信息。另一方面，罗马人使用凯撒移位密码技术进行加密。它涉及按固定数字（通常为三）移位字母以创建编码信息。为了解码信息，接收者随后会按相同的幅度将字母向后移动。凯撒移位密码体现了单表加密。

# 分布式系统的出现

同样，分布式系统的概念也有着悠久的历史。它可以追溯到大型计算机通过网络连接的计算机早期，那时通用的数据流总是最终汇聚到系统中的某个特定节点或少数几个节点。分布式系统的初步发展是由对可扩展性、可靠性和可用性的需求所驱动的。随着互联网范围的扩大，更多设备和资源被接入网络探索，这成为了分布式系统登场的最佳时机，并在现代计算基础设施中发挥着关键作用。在软件架构的早期，单体系统盛行。这些系统将数据访问代码、业务逻辑和用户界面代码结合在一起，使得难以分离各层（例如当 DBMS 发生变化时），或因缺乏模块化而在其他应用程序中复用组件。自起源以来，分布式计算系统的发展已取得长足进步。起初，单台计算机一次只能执行一项作业，必须有多台机器并发运行才能执行多项任务。

然而，仅凭这一点不足以建立一个完整的分布式系统，因为它需要一种不同计算机或运行在其上的软件之间相互通信的方法。这导致了基于消息的通信的诞生，即使用消息在计算机之间交换信息，以及文件和数据库共享等其他技术。多任务操作系统和个人计算机的出现标志着分布式系统新时代的到来。`Windows`、`Unix` 和 `Linux` 等操作系统的出现使得在单台机器上执行多项任务成为可能。这反过来又促进了通过消息传递，在一台或少数几台互联计算机内构建和运行完整的分布式系统。这一发展催生了面向服务的架构（SOA），其中分布式系统通过集成运行在一台或多台计算机上的一组服务来构建。服务接口使用 `WSDL`（用于 `SOAP`）或 `WADL`（用于 `REST`）进行指定，服务消费者使用这些接口进行其客户端实现。请参阅下图 1.1：

- 随着计算能力和存储成本的下降，越来越多的公司开始使用分布式系统和采用面向服务架构（SOA）的 IT 系统。然而，随着系统和服务数量的增加，将它们全部连接在一起变得困难。为了解决这个问题，创建了一种称为服务总线的新系统。它充当中间人，连接所有不同的系统。这个组件称为企业服务总线（ESB），它就像不同系统之间的翻译官，这些系统以不同的方式通信，就像说不同语言的人。该模型的主要优势是系统可以相互通信，而无需担心其他系统如何通信。

- 在 `Docker` 和 `Kubernetes` 等工具推出后，它们使得在称为主机的多个计算机系统之间移动和管理称为容器的多个软件应用程序变得容易，分布式系统领域继续专注于使这一过程更加便捷高效。这包括云原生技术的使用，该技术专为在云计算环境中良好运行而设计，并利用云的能力来处理大型复杂工作负载。此外，服务网格和无服务器计算等新技术也已开发出来，以改进这些容器化应用程序的网络和流量管理，并仅在需要时部署它们。边缘计算是涉及分布式系统的最新新兴进步之一。

## 边缘计算

分布式系统的另一个重要发展是边缘计算，它将计算能力移至数据生成源附近，以提高实时数据处理的速度和性能，特别是针对物联网（IoT）设备和应用程序。总体而言，分布式系统的目标是以高效且可管理的方式处理大型复杂工作负载，这正是推动该领域演进的动力。作为其中的一部分，当今各种著名且极具前景的技术都将分布式系统的核心原则作为根本思想，如区块链技术。
