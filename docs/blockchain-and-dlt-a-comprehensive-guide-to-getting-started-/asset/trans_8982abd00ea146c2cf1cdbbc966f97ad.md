### 共识机制

正如一群朋友必须就想看的电影达成一致一样，区块链网络需要共识机制来就交易顺序达成一致。Hyperledger Fabric V1 提供可插拔式共识，允许你选择适合你需求的机制，无论是 `PBFT` 还是 `Raft`。

Hyperledger Fabric V1 的架构就像一座结构良好的房子，每个组件都有明确的角色。它提供了一种实用且可靠的方式来构建企业级区块链网络，确保交易安全、私密且有序。因此，当你深入探索 Hyperledger Fabric V1 的世界时，请记住其简单且合乎逻辑的架构，它构成了强大区块链应用的基础。

## Hyperledger Sawtooth 简介

想象一下，踏上旅程去探索区块链宇宙中一个独特而引人入胜的角落。Hyperledger Sawtooth 以其独特的设计和创新功能向你招手，宛如一个迷人且神秘的谜题等待解开。

Hyperledger Sawtooth 是 Hyperledger 家族中的一个开源区块链平台，很像区块链树上一根杰出的枝干。它以其模块化架构、可扩展性和通用性脱颖而出，有望解决广泛的用例。

下表 5.2 展示了 Hyperledger Sawtooth 与 Hyperledger Fabric 之间的一个简要对比：

| 特性 | Hyperledger Fabric | Hyperledger Sawtooth |
| --- | --- | --- |
| 共识机制 | 模块化，支持 `PBFT`、`Kafka` 等 | 时间流逝证明 (`PoET`) 以实现公平性和能源效率 |
| 交易家族 | 不适用 | 支持通过交易家族概念进行并行处理 |
| 并行交易处理 | 区块内顺序处理 | 支持同一区块内交易的并行处理 |
| 智能合约语言兼容性 | 用于链码开发的 `Go`、`JavaScript`、`Java` | 通过一层兼容以太坊的 `solidity` |
| 身份管理 | 用于身份管理的 `MSPs` | 与外部身份管理系统集成 |
| 许可制与非许可制 | 主要为许可制网络设计 | 适用于许可制和非许可制网络 |
| 全局状态 Merkle 树 | 使用版本化键值存储作为账本状态 | 维护全局状态 Merkle 树结构 |

### 模块化与组件

Hyperledger Sawtooth 的核心在于其模块化设计，让人联想到一块精工制造的瑞士手表，每个组件都发挥着精确的作用。这些角色包括：

*   **交易家族**：这些就像手表的齿轮，负责处理特定类型的交易。想象一个齿轮处理金融交易，而另一个管理供应链操作。
*   **共识引擎**：将其想象为 Sawtooth 的心跳，决定交易如何被验证并添加到账本。它提供了灵活性，允许你选择适合你需求的共识机制。
*   **验证节点**：这些是账本的守护者，确保交易遵守交易家族定义的规则。验证节点形成一个分布式网络，增强安全性和去中心化。
*   **交易处理器**：将这些视为为我们的手表打造齿轮的熟练工匠。它们根据交易家族定义的规则执行交易，确保账本的完整性。

#### 特性与优势

Hyperledger Sawtooth 拥有一组功能，使其成为各种应用的引人注目的选择：

*   **许可制与非许可制模式**：它同时满足私有链和公有链的需求，为各种用例提供灵活性。
*   **并行交易执行**：交易可以并发处理，就像制造工厂中的不同装配线一样，提高效率。
*   **支持 WebAssembly (`Wasm`) 的智能合约**：Sawtooth 支持用 `Wasm` 编写的智能合约，使其能被广泛的开发者访问。
*   **可扩展性**：随着网络的增长，Sawtooth 能优雅地扩展，确保即使在苛刻的环境中性能也保持最优。
*   **简单而强大**：平台设计的简洁性使其易于开发者上手，同时保持了企业级应用所需的稳健性。

#### 现实应用

考虑一个寻求提高透明度和可追溯性的供应链联盟。Hyperledger Sawtooth 凭借其模块化架构和智能合约能力，可定制创建一个解决方案，无缝追踪商品从生产到分销的全过程，确保真实性和效率。
