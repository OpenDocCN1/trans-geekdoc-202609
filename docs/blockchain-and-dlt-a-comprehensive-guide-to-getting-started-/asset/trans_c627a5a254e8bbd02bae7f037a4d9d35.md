

## 4. 生成公钥

要生成公钥，需将私钥与曲线上的基点相乘。此次乘法的结果是曲线上的一个新点，即为公钥。随后，公钥会与任何需要向私钥所有者发送消息的人共享。

## 5. 加密消息

要使用 ECC 加密消息，发送方首先必须获取接收方的公钥。然后发送方生成一个称为临时密钥的随机数，用于对公钥执行计算。该计算的结果是曲线上的一个新点，即为共享密钥。随后，共享密钥被用于通过对称加密算法加密消息。

## 6. 解密消息

要解密消息，接收方使用其私钥对共享密钥执行与发送方相同的计算。这会还原出原始公钥，进而用于解密消息。

总的来说，椭圆曲线密码学提供了一种通过互联网安全传输消息的方式。通过使用一种在一个方向上难以计算、但在相反方向上易于计算的数学函数，ECC 确保只有预期的接收者才能解密使用其公钥加密的消息。

ECC 是一种公钥密码学，它利用椭圆曲线来保障数字通信安全。由于其安全性、高效性和可扩展性，近年来越来越受欢迎。ECC 的基本思想是利用数学函数生成一对密钥，一公一私。公钥可以自由共享，而私钥必须保密。使用公钥加密的消息只能用相应的私钥解密，从而确保通信的机密性。

ECC 的主要优势之一是它提供比其他公钥密码系统（如 `RSA`）更高级别的安全性。这是因为 ECC 密钥通常比 `RSA` 密钥短，却能提供同等或更好的安全性。这使得 ECC 特别适合资源受限的环境，如移动设备或嵌入式系统。为保持高性能和安全性，采用 ECC 是明智之举。网站越来越多地利用 ECC 来增强客户数据的在线安全性并优化移动端体验。随着更多站点采用 ECC 进行数据保护，对这类密码学简明指南的需求也日益增长。

用于 ECC 的椭圆曲线是有限域上的一条平面曲线，由满足方程 `y² = x³ + ax + b` 的点组成。在该椭圆曲线密码学示例中，曲线上的任意点关于 x 轴反射均不会改变曲线。此外，非垂直线将在三个或更少的位置与曲线相交。

公钥密码学是一种利用特殊数学问题的方法，这些问题在一个方向上易解，在相反方向上难解。例如，`RSA` 加密通过将素数相乘得到一个大数，这很容易做到。但仅凭这个大数很难推断出使用了哪些素数。

然而，为保持 `RSA` 的安全性，需要非常长的密钥。这使得过程变慢，且意味着密钥尺寸至关重要。ECC 是一种不同的方法，具有优势：它能以更小的密钥达到与 `RSA` 同等的安全级别。这对加密算力较弱的移动设备尤其有用。ECC 使用的数学问题比 `RSA` 的更容易求解，因此更短的密钥仍能提供强安全性。总之，与 `RSA` 相比，ECC 是一种更快、更节能的加密方法，能以更小的密钥提供高安全性。

尽管 ECC 存在一些潜在漏洞，攻击者可利用这些漏洞破坏其对私钥的安全性。两种常见的攻击类型是侧信道攻击和扭曲安全攻击。侧信道攻击包括差分功耗攻击、故障分析、简单功耗攻击和简单时序攻击。这些攻击通常导致信息泄露，但可采取简单的对策来防范。

扭曲安全攻击（如无效曲线攻击和小子群攻击）可能导致受害者的私钥暴露。不过，通过仔细的参数验证和曲线选择可缓解这些攻击。尽管存在这些漏洞，ECC 在无线安全方面的优势使其总体上成为更安全的选择。

ECC 是加密货币中数字签名最常用的实现技术之一。`Bitcoin` 和 `Ethereum` 均在签名交易时专门应用椭圆曲线数字签名算法（`ECDSA`）。然而，ECC 不仅用于加密货币。由于其密钥长度较短且效率高，它将成为大多数 Web 应用程序采用的加密标准。

椭圆曲线密码学（ECC）的部分应用如下：

- ECC 用于各种安全应用。
- Diffie-Hellman 协议便是此类应用之一，它实现了双方之间的密钥共享，双方需就曲线、域大小和数学类型达成一致。
- `ECDSA` 是一种流行的数字签名算法，用于 `Bitcoin` 和 `Ethereum` 等加密货币。它采用域逆乘法、算术乘法、逆函数和模运算来签名交易。
- ECC 不仅限于加密货币，因其高效和密钥尺寸小，还用于许多在线应用中对电子邮件、数据和软件进行单向加密。
- ECC 还用于区块链技术，如 `Ethereum 2.0`，它使用带有 `BLS` 签名的椭圆曲线密钥对，以验证特定 Eth2 验证者对特定交易的验证。

## Bitcoin 地址

`Bitcoin` 是一种数字货币，无需银行等中央机构参与即可实现安全、去中心化的交易。取而代之的是，交易记录在一个称为区块链的公共账本上，由全球节点网络维护。

`Bitcoin` 地址是一个独特的标签，用于发送和接收 `Bitcoin`。它是字母数字字符的组合，通常以数字 `1` 或 `3` 开头，代表 `Bitcoin` 网络上的特定目的地。每个 `Bitcoin` 地址都关联一个私钥，用于证明 `Bitcoin` 的所有权并签署与该地址相关的交易。

公钥密码学用于创建 `Bitcoin` 地址。这种加密方式使用一对密钥：公钥和私钥。公钥用于创建 `Bitcoin` 地址，而私钥用于证明 `Bitcoin` 所有权并签署交易。要创建 `Bitcoin` 地址，用户首先使用 `Bitcoin` 钱包生成一对公私钥。然后，使用加密算法对公钥进行哈希运算以生成 `Bitcoin` 地址。结果是一个唯一的字符串，标识用户在 `Bitcoin` 网络上的位置。

当有人想向特定地址发送 `Bitcoin` 时，他们会向网络广播一笔包含接收方地址和发送 `Bitcoin` 数量的交易。网络上的节点验证该交易，若满足特定要求，则将其添加到区块链中。

要花费与特定地址关联的 `Bitcoin`，地址所有者必须使用其私钥对交易进行签名。此操作证明了 `Bitcoin` 的所有权，并允许交易被添加到区块链。一旦网络节点确认交易，`Bitcoin` 即转移至接收方地址。
