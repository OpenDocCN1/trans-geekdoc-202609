
收到消息后，接收方可以使用其私钥对其进行解密以读取原始消息。通过遵循这些步骤，公钥密码学可以提供安全通信，同时确保只有预期的接收方才能读取消息。

## 公钥密码系统应用

公钥密码学在数字平台的安全通信方法和身份验证机制领域被认为至关重要。它有各种应用，其中一些显著的应用如下：

*   **解密/加密**：如果应用程序的目标是对消息进行编码和解码，则发送方必须使用预期接收方的公钥对消息进行编码，而接收方可以使用其自己的私钥对消息进行解码。
*   **认证**：它可以证明消息或用户是否合法。认证表示用户就是他们声称的那个人。可用性描述资源可由授权方访问，例如拒绝服务攻击，这是国家信息的敏感事项，属于针对可用性的攻击。
*   **数字签名**：当应用程序的主要目标是确认发送方的真实性时，可以使用数字签名。这涉及使用发送方的私钥对消息进行加密或签名。由于只有发送方能访问其私钥，这向所有相关方保证该消息确实由该特定个人发送。
*   **密钥生成**：每个用户生成两个密钥，包括公钥和私钥。私钥由用户保管，公钥在网络中自由可访问。
*   **验证**：签名通过相关用户的公钥进行验证。

## RSA

RSA 以其创建者 Rivest、Shamir 和 Adleman 的名字命名。它是一种非对称加密算法，便于生成公钥和私钥。RSA 实现密钥交易，其中交易涉及的每一方都被分配自己的一组公钥和私钥。随后，生成一个对称密钥，并使用公钥/私钥对安全地传输该密钥。非对称加密虽然通常比对称加密慢且可扩展性较差，但常用于安全地交换对称密钥。

RSA 使用一种基于分组密码概念的非对称加密算法，该概念在接收方一侧将明文转换为密文，反之亦然。如果使用用户 A 的公钥进行加密，则必须使用同一用户的私钥进行解密。

要实现 RSA 加密算法，需采取以下步骤：

1.  首先，选择两个素数 `X` 和 `Y`。这些素数必须足够大以确保安全性。
2.  计算两个素数的乘积，记为 `N = X*Y`。该乘积构成了加密算法的基础。
3.  接下来，选择一个公钥 `E`。它不能是 `(X-1)` 和 `(Y-1)` 的因数。
4.  选择一个私钥 `D`，使得等式 `(D * E) mod (X-1) * (Y-1) = 1` 成立。
5.  对于加密，密文 `CT` 计算为 `CT = (plaintext)^E mod N`。生成的 `CT` 随后发送给接收方。
6.  最后，对于解密，明文 `PT` 计算为 `PT = (ciphertext)^D mod N`。

这些步骤构成了 RSA 加密算法的基础，由于其在确保机密性和真实性方面的有效性，该算法广泛用于安全通信系统。

> **注意**：在 RSA 算法中，选择和生成公钥和私钥是一项关键任务。

## El Gamal 密码算法

这是一种公钥密码算法。该密码系统基于在循环群中寻找离散对数的困难性；即，即使我们知道 `ga` 和 `gk`，计算 `gak` 也极其困难。

*   首先选择两个大素数 `P` 和 `Q`，其中 `P` 为公钥，`Q` 为私钥。
*   选择第二个加密密钥为 `E1`。
*   计算第三个加密密钥 `E2`，使得 `E2 = E^Q mod P`，用于 El Gamal 密钥加密。
*   选择一个随机数 `R`。
*   计算密文为 `CT = E1^R mod P`。
*   计算第二个密文为 `CT2 = (PT * E2^R) mod P`，用于 El Gamal 密钥解密。最后，计算明文为 `PT = (CT2 * (CT^Q)^-1) mod P`。

## 椭圆曲线密码学

椭圆曲线密码学 (ECC) 是一类现代公钥加密系统，利用有限域上椭圆曲线的代数结构和椭圆曲线离散对数问题 (ECDLP) 的复杂性。ECC 提供了非对称密码系统的所有基本功能，包括加密、数字签名和密钥交换。它被视为 RSA 密码系统的天然继任者，这归功于其使用更小的密钥和签名，在提供与 RSA 相同安全级别的同时，实现了更快的密钥生成、密钥协商和签名处理速度。请参阅图 1.8，了解 ECC 的工作原理。

椭圆曲线被用于创建加密方案。它们定义在特定域上，是不连续曲线，意味着它们由有限个点组成。椭圆曲线密码学在传输和接收交易时构成了去中心化信任的基础。事实上，它被用于生成交易签名，这类似于物理签名，可以证明用户有权参与交易。在没有中央机构认证交易的去中心化系统中，广播到网络的每笔交易都必须拥有有效签名。这些签名必须能够验证交易是由特定用户发起的。这是通过非对称加密实现的，用户拥有一个或多个公钥/私钥对。签名方案包含一个问题，只有拥有公钥和私钥的用户才能计算该问题，但任何拥有公钥的其他用户都可以将其验证为真实签名。

一个例子是基于椭圆曲线的签名方案，它使用户能够证明他们拥有交易中声称的资金。这允许在无需中央机构的情况下发送和接收交易。选择椭圆曲线而非其他签名方案（如 RSA）是因为其密钥尺寸更小，有助于减少网络上存储的信息量。

## 哈希函数

哈希函数是一种数学算法，它接收可变数量的字符（称为消息），并将其转换为具有固定数量字符的字符串，称为哈希值或哈希。哈希算法是单向函数，意味着它们在一个方向上易于执行，但不可能逆向。哈希对于确保数据完整性和检测任何篡改非常有价值，因为消息的微小变化都会产生完全不同的哈希。哈希函数是现代密码学的基础工具，用于信息安全以验证交易、消息和数字签名。它们在区块链和分布式账本技术中有各种应用，包括链接区块和创建压缩数据结构。图 1.9 说明了哈希运行所涉及的顺序阶段。
