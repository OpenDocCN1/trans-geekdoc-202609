The smart garden is a lot more efficient in keeping a plant alive than the average person – as the plant is never over or under watered. The purpose is to keep the plant alive so the plant owner can do more important things.

Specifically, the smart garden sensors measure a plant’s temperature, soil moisture, amount of sunlight, and air temperature. All of this data is aggregated and analyzed by the application program decides when and how to water the plant. The smart garden kit can be purchased (ex. SwitchDoc Labs (https://shop.switch-doc.com/). The kit comes with most of what you need to build this device. The only things that need to be purchased separately are the raspberry pi, a computer monitor/keyboard, a power supply, and a plant.

Once you have assembled the smart garden according to the kit, the application has hard-coded range of the plant levels: moisture, temperature, etc. Once the moisture is too low, the sensor, which is inserted into the soil, sends the data to the raspberry pi, which sends a signal to the water pump to begin watering the plant. The pump stops once the sensor detects enough moisture.

While the smart garden is an efficient and easy way to take care of plants, it has a few flaws. First of all, it’s not a practical size. It requires many wires and tubes, which makes it difficult for the user to enjoy the benefit of. Second, an entire system can only sustain one plant. It seems like a great deal of effort for a single plant. However, this experiment is not about its practicality, it is about the system itself which clearly can be improved. The smart garden has limitless potential.
