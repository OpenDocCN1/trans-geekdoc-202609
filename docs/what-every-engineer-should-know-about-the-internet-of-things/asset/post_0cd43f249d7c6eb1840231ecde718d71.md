    - Propagate change of value notifications

By examining the current system structure, it can be seen that every time the Rule Manager and the Alarm Manager needs to query a field device, it needs to make a call that traverses multiple components along the way to the field device.

Since component boundaries typically introduces computational overhead, and the querying latency of field devices is a constraint over which we have no control, we decompose the virtual device and introduce a cache component to improve device querying performance.

This cache provides device property values to the system, saving part of the performance cost incurred when querying the actual field devices. The performance gains are seen when we reduce the number of component and machine boundaries traversed for each query. A cache is an application of maintaining multiple copies of data performance tactics. We allocate the following functional responsibilities to the cache:

- Retrieve data from field device
- Store field device configuration

# 12.5 CONCLUSION

The IoT is relatively a new technology, and building an architecture for an IoT system comes with challenges. The lack of standardization is one of the significant challenges. The hardware components related to the IoT as well as the software aspects of the IoT don't have a single platform of standardization. A standardized application programming interface (API) and software service so that future applications are employed in a uniform and level environment enables easy migration across systems. The interoperability of another concern. IoT applications offer value combining data from various IoT devices. Connectivity is also an important component of IoT architecture because it plays a crucial role in transporting data from the sensors. Furthermore, also transmits instructions to the actuators.

While there is no single and union agreement about the architecture of IoT, according to some architects, IoT architecture has three layers. While others, support the four-layer architecture. The challenge in IoT regarding security and privacy has led to a five-layer architecture proposal. Whatever the architecture might be, the challenges of an IoT architecture almost remain the same.
