# 前言

在2022年，全球物联网（IoT）支出将超过1万亿美元。到2025年，将有750亿台连接的设备。IoT 产品和信息物理系统（CPS）正被应用于几乎每一个学科。此外，智能产品正变得越来越先进，以提高我们的健康和舒适度。医疗领域的 IoT 应用不仅能提供基于实时数据的决策支持信息，还能改善需要全天候监测的疾病的治疗方案。一些能够感知、学习并适应用户偏好的产品正日益受欢迎。IoT 也在让我们的城市、政府和家庭运行得高效。

IoT 设备具有无处不在的特性；它们正被集成到每一个领域。随着这种增长，至关重要的是传达这项技术（具有感知和决策等独特的系统功能）如何支持并挑战许多领域的所有相关利益方以及所有相关资产。

本书有三个目标。第一个目标是提供一个每个工程学科都能理解并欣赏的 IoT 介绍。我们包含了重点介绍 IoT 顶级应用（智能家居、智能医疗、智能城市和智能教育）的章节，针对对设计感兴趣的工程师，提供了 IoT 要求与架构、IoT 与区块链，以及美国国家标准与技术研究院（NIST）对“物”网络的定义及其关于 IoT 信任问题的白皮书。第二个目标是为工程教育者提供见解，帮助他们培养构建 IoT 系统所需的下一代工程师。我们希望这本书能让你对 IoT 及其许多应用有新的认识，因为它们很快就会被整合到我们生活的每一个部分。
