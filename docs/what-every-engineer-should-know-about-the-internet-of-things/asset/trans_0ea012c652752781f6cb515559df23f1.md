

# IoT 信任问题

由于 IoT 背后的经济因素，这些问题变得更加复杂；构建 IoT 设备的门槛很低，这意味着市场上存在许多不同制造商的各种设备和型号，而很少有权威机构负责其中任何一个设备的安全性。虽然这些问题也延伸到了传统计算市场（如笔记本电脑和个人电脑），但市场机制已推动大多数产品向集成化的产品和功能发展，使得消费者更容易评估和理解设备及制造商提供的安全性。

尽管如此，目前尚没有中央实体来监管 IoT 设备的安全性，但随着监管参与者考虑如何解决这一复杂问题，近期已取得了一些进展。例如，《物联网网络安全改进法案》（Weaver, 2017）于 2017 年被引入，其目标是为专门安装在政府网络中的 IoT 设备制定标准。该法案包含几项重要规定，要求设备放弃固定默认密码，且设备不能有任何已知的漏洞。该法案还放宽了可能用于起诉寻求测试这些设备安全性的人员的其他法律。

多个机构的授权范围与 IoT 安全领域相交织。一个很好的例子是联邦贸易委员会（FTC）。2018 年 1 月，VTech 同意就 FTC 的指控达成和解，其指控并非违反安全法，而是美国儿童隐私法，即在未获得同意的情况下收集儿童的私人信息，并未能采取合理措施保护数据（Federal Trade Commission, 2018）。关键点在于 VTech 的产品是联网玩具——即 IoT 设备——它们收集了个人信息，由于这些设备在处理和管理数据方面存在安全风险，该公司遭到了罚款。此案例表明，如果 IoT 设备没有足够的安全性，制造商可能需要承担法律责任。

美国消费者产品安全委员会呼吁该领域的律师和专家之间进行更多合作（American Bar Association, 2017）。在美国境外，欧盟网络和信息安全局（ENISA）已发布了 IoT 的安全指南（ENISA, 2017）。随着更多对安全性的呼吁和建议出现，标准化和监管可能会随之而来，从而提高部署的 IoT 系统的安全性和。

监管提供了一种严肃手段，可以帮助增加 IoT 系统的安全性和安全性，其在汽车制造等其他行业的成功已经证明了这一点。虽然在一些机构和组织试图影响 IoT 监管的过程中注意到了一些改进，但尚未看到一个中央机构强制执行有关 IoT 系统使用和开发的规则。这样的组织可能会对 IoT 系统的安全性以及消费者的生活产生重大影响。

# 10.22.3 NIST SP 800-183 中的信任要素

NIST SP 800-183 的第 10.3 节列出了六个信任要素。此处给出这六个元素的原文，请注意 NoT 代表“物之网络”（network of 'things'）：

# 每个工程师应该了解的 IoT

[begin verbatim text]

为了完成这一模型，我们定义了六个元素，即环境、成本、地理位置、所有者、Device_ID 和快照，尽管它们不是原语，但是信任 NoT 的关键要素。这些元素在培养特定 NoT 所提供的信任程度方面起着主要作用。

1. 环境：特定 NoT 运行的环境；这尤为重要。NoT 的环境是其运行的宇宙。这包括物理和逻辑环境。NoT 的环境可能会被破坏，从而影响设备的信任度。

2. 成本：从资金和资源角度构建和运行 NoT 的成本。如果安全成本过高，可能会导致安全性降低，从而影响设备的信任度。

3. 地理位置：NoT 的地理位置是其所在的物理位置。该位置可能会改变，并可能影响设备的信任度。NoT 的地理位置应该受到保护。

4. 所有者：NoT 的所有者是拥有并控制它的个人或组织。NoT 的所有权可能会转移或遭到，从而影响设备的信任度。

5. Device_ID：Device_ID 是 NoT 的唯一标识符。如果 Device_ID 可以被伪造或欺骗，将影响设备的信任度。

6. 快照：快照是时间上的瞬间。NoT 的快照可能会被篡改，从而影响设备的信任度。

信任包括属性：所有安全性、可靠性、可用性和性能

快照可能与时钟对齐（NIST, 2015）。全局时钟对于传感器网络可能是种负担。然而，其他人则支持全局时钟（Li, 2004）。本文在撰写时不支持上述任何一种方案。
