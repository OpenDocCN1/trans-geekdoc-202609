# 物联网定义¹

## 1.1 引言

如果你让一个普通人解释“物联网”（IoT²），他们可能会回答说他们从未听过物联网，或者不知道如何解释。如果他们进行推测，他们会说物联网是“智能”的“东西”。他们很可能并不理解设备感知到了什么。事实上，“智能”一词似乎也变成了某些并不需要描述的产品的营销术语。考虑一下可以从手机操作的户外灯。除非这些灯还能感知运动等某些信号，然后向你的手机发送通知，否则它们就不是智能的的。换句话说，“智能”应该指符合某些标准（如嵌入式传感器和分析软件）的设备。具体而言，除了传感外，该设备还可以收集和分析数据，连接到有线或无线网络，然后根据数据分析执行某些操作，它可以被称为物联网设备或“智能”设备。关于物联网有许多不一致且不准确的定义；因此，本书的目标之一是为理解物联网及其应用提供清晰且准确的内容。此外，作为工程师，我们需要了解物联网的一切——特别是优势、风险，并不断提高物联网系统的安全性、隐私性、可扩展性、性能、互操作性和可用性。

## 1.2 物联网定义

维基百科将物联网定义为“物理对象的网络——即嵌入了传感器、软件和其他技术的‘东西’，其目的是与其他设备以及通过互联网进行连接和数据交换”。物联网概念源于 RFID（射频识别）社区，最初关注追踪物理对象的位置并提供其状态的能力（Greer 等人，2019）。这极地提高了供应链的可见性。

“物联网”自 1999 年以来一直存在。麻省理工学院 Auto-ID 实验室的创始人 Kevin Ashton 创造了 IoT 一术语，指代通过识别技术（例如 RFID）、定位系统（全球定位系统 (GPS)）、传感器（例如温度传感器）和执行器（例如电动机）连接的真实和虚拟信息的组合。有许多类型的传感器，如 RFID 标签、GPS 和加速度计。‘东西’可以

美国国家标准与技术研究院（NIST）特别出版物 800-183 描述了治理物联网运行、信度和生命周期的构建块（Voas，2016）。NIST 是一个联邦机构，其核心使命是支持创新。为了设计和实现物联网创新，理解物联网背后的基础科学至关重要；因此，描述了用于构建物联网系统的五个原语（传感器、聚合器、通信通道、工具和决策触发器）。这包含了本书的第 2 章。

“东西”做什么？它们捕捉数据并通信/传输数据或执行某些操作（例如执行器）。物联网实现了许多新应用，帮助扩展了大数据、业务和数据分析以及人工智能等领域。重要的是，物联网对许多人的生活质量产生了影响。

## 1.3 物联网生态系统

物联网对我们的关键基础设施系统也产生了巨大影响。当“东西”是网络系统时，它被称为信息物理系统（CPS）。关键基础设施系统属于 CPS 类别。当一个系统的资产、系统和网络至关重要，一旦受到损害就会对美国安全、经济安全以及国家健康或安全产生破坏性影响时，物联网允许这些物理设备连接、联网、交换数据并提供实时决策支持。网络基础设施和安全局（CISA）– https://www.cisa.gov/ 命名并定义了以下 16 个关键基础设施部门：

- 化学品部门：制造、储存、使用和运输潜在危险化学品的经济部门。
- 商业设施部门：吸引大量人群进行购物、商务、娱乐或住宿的各种场所。
