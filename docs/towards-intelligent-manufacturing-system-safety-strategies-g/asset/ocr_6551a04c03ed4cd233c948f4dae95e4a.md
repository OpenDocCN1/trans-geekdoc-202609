# 4.2. Preprocessing

In order to detect the information, we want to retrieve from the LOTO sheets (machine name, devices) to be locked, instructions to follow), with the dictionaries required to be used, following preparations must be made on the strings associated with each of the sheets. The following steps were done using the NK library of python:

+   * Tokenization of the character string in order to isolate each word present

+   * Removal of words that do not carry important information

+   * Removal of words that are too short (<2 characters) (which can cause problems in detecting similarities between words)

The processing of the LOTO sheets and the writing of these sheets require to extract the relevant information which will constitute our data to automatically generate the sheets. The text mixing will be relevant to perform this task (De 2019).
