# 6. CONCLUSION

This research is in the context of industry 4.0 and ESH 4.0 can contribute to improving safety in industries by providing safety procedures, usually written by humans. This paper presents the work to generate LOTO sets, namely the first identified sub-graph is the extraction of information from the names of the machines, which need to be locked and the instructions to correctly sequence them. The transformation of the LOTO sets in PDF text format results in a usable database, for modeling logic based on machine names, which is tested. The work on database may need to be performed if some errors detected in the data extraction from graphs prove to have high an impact on the methods

In the second sub-objective, the steps of the research project are the training and testing of the machine learning model combining the Apriori and Random Forest algorithms. Finally, the parameters of association and bagging algorithms will need to be tuned to produce LOTO sheets based on the line above. This work, is for the moment, based on text pdf files, a text recognition with image pdf also be done. Even, many industrialists HAVE sheets in the form of PDF images only, these sheets are an important source to improve the prediction model. As the subject deals with currency records, agents will follow the predictions which will also have to be done by being sure to use in practice this kind of assignment in writing safety practices.
