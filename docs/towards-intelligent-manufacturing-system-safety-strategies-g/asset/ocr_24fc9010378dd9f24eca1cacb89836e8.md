The study of association rules is a critical step in text mining, because it attempts to reveal meaningful values in a large data set. Association rules have been recommended for cluster analysis, but they are considered as general data in various domains. Specifically, they are suggested for the analysis of association rules. The most important and simplest is the Apriori algorithm (Agrawal and Srikant 1994). The Apriori algorithm would allow to experiment with different combinations between attribute values found in a database. The exploration of association rules is controlled by confidence thresholds. These are set to find the search area, which makes the computational process possible (Dhabi et al., 2021). Algorithms like the Apriori algorithm would allow to extract patterns of ideas and to choose sequences of operation according the type of machine. The name of the machine could be directly associated with lockout instructions. Information on medical texts has been done (Toun et al., 2021), using the Apriori algorithm. A similar work could be done on safety procedures such as LOTO sheets.
