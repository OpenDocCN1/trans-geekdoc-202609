# 6. CONCLUSION

This research is in the context of industry 4.0 and ESH 4.0 can contribute to improving safety in industries by providing safety procedures, usually written by humans. This paper presents the work to generate LOTO sets, namely the first identified sub-graph is the extraction of information from the names of the machines, which need to be locked and the instructions to correctly sequence them. The transformation of the LOTO sets in PDF text format results in a usable database, for modeling logic based on machine names, which is tested. The work on database may need to be performed if some errors detected in the data extraction from graphs prove to have high an impact on the methods
