## 4.1. PDF file conversion

To achieve objective 1 of this research, the first step is to obtain a database of LOTO sheets by retrieving the names and the identifiers. The partnering organization in this research, CONFORMIT, a Canadian company that develops, markets and implements health, safety and environmental management software such as LOTO sheets. The available LOTO sheets are PDF format as shown in Figure 3. First, we need to convert PDF file into strings. The python libraries "PDF2Text" (Kushari and Shivananda 2021) and "pdfminer" were used to convert PDF to text, in python, and format it. The "pdfminer" allowed us to keep the order of the text in the PDF files and sometimes like spaces between words could be deleted which made it very difficult to extract important words like machine names. These problems were solved with "pdfminer", which is why the choice to work with it was made. After once the files were converted in txt, we were able to import the LOTO as a sheet in a Python.

## 4.2. Preprocessing

Once the data is obtained, the objective will be to write logs sheets with only the name of the equipment as an entry. Therefore, it will be necessary to establish numerical predictions.

In order to detect the information, we want to retrieve from the LOTO sheets (machine name, devices) to be locked, instructions to follow), with the dictionaries required to be used, following preparations must be made on the strings associated with each of the sheets. The following steps were done using the NK library of python:

- Tokenization of the character string in order to isolate each word present
- Removal of words that do not carry important information
- Removal of words that are too short (<2 characters) (which can cause problems in detecting similarities between words)

The processing of the LOTO sheets and the writing of these sheets require to extract the relevant information which will constitute our data to automatically generate the sheets. The text mixing will be relevant to perform this task (De 2019).

This step is the main challenge to obtain a data frames in the association of words by similarity. Several algorithms on the NLTK library can be used for this purpose. The J-Winkler distance algorithm is another to measure similarity between two words (Yulianto and Nurhasaman 2021).

The approach a ratio between 0 and 1:1 corresponding to two identical words. The calculation of the similarity is a bit more complex and the length of the words is well reduced. The simple improvement of typing errors is also weighted reducing. Even with these二是, the Jan-Winkler distance is chosen because it offers a better recognition of shorter words.

The study of association rules is a critical step in text mining, because it attempts to reveal meaningful values in a large data set. Association rules have been recommended for cluster analysis, but they are considered as general data in various domains. Specifically, they are suggested for the analysis of association rules. The most important and simplest is the Apriori algorithm (Agrawal and Srikant 1994). The Apriori algorithm would allow to experiment with different combinations between attribute values found in a database. The exploration of association rules is controlled by confidence thresholds. These are set to find the search area, which makes the computational process possible (Dhabi et al., 2021). Algorithms like the Apriori algorithm would allow to extract patterns of ideas and to choose sequences of operation according the type of machine. The name of the machine could be directly associated with lockout instructions. Information on medical texts has been done (Toun et al., 2021), using the Apriori algorithm. A similar work could be done on safety procedures such as LOTO sheets.
