
## 网络攻击类型

### 4) 零日攻击
利用开发者和公众尚未知晓的漏洞进行的攻击。

### 5) IP 欺骗
使数据看起来像是来自可信主机的攻击。

### 6) ARP 欺骗/投毒
向交换机的 ARP 表发送多个 ARP 数据包，将黑客的 MAC 地址与尽可能多的 IP 地址关联，从而接管他人的数据。

### 7) DNS 欺骗/投毒
将用户重定向到特定网站。当受害者输入地址时，会被转向另一个站点。

### 8) 重放攻击
黑客拦截认证过程，稍后尝试再次发送相同的数据包到服务器以重新获得访问权限。

### 9) 域名劫持
将受害者引导至伪造网站，诱使其输入凭据。

### 10) 传递访问
允许黑客通过一台机器访问另一台机器。简而言之，如果两台机器通信且机器 B 信任机器 A，则使用机器 A 的黑客可以到达机器 B。

### 11) 后门
允许未经授权访问系统。如果攻击者发现后门，可以不受干扰地访问系统。后门可由恶意软件安装。

### 12) 权限提升
用户获得过高的访问级别。可能由两种情况导致：管理员错误，或利用后门/系统漏洞的攻击。

### 13) 客户端攻击
攻击者在服务器植入受感染文件并将其传播至整个网络。

### 14) 缓冲区溢出
发送超出程序处理能力的大量输入，导致程序崩溃。

### 15) XSS 跨站脚本攻击
攻击浏览器并运行脚本窃取数据。分两类：
- **持久型**：黑客在网站植入恶意代码
- **非持久型**：黑客发送包含恶意站点链接的邮件

### 16) XSRF 跨站请求伪造
操纵客户端攻击服务器。浏览器向网站发送恶意请求。

### 17) SQL 注入
未经授权访问 SQL 数据库。

### 18) 目录遍历
利用 Web 服务器弱点绕过访问限制，访问服务器上的受限文件夹。

### 19) 密码猜测
使用密码破解工具，通过尝试所有可能组合强行发现密码。

### 20) DoS 拒绝服务攻击
中断服务，使资源在一段时间内不可用。需使用大量系统（称为僵尸主机）在攻击者控制下同时运行以饱和服务器。因僵尸主机众多，追踪攻击者极难。

#### 基于洪水的攻击技术

##### A) Ping/ICMP 洪水
发送大量 Ping 直到网络饱和（Windows 下 `-t` 发送连续 Ping，`-l` 选择包大小）。需禁用 ICMP 流量防范此类攻击。

##### B) SYN 洪水与 ACK 洪水
持续发送连接请求。发送 SYN 但不发送 ACK，导致服务器保持大量打开连接。对策是设置超时关闭连接。ACK 洪水类似，仅发送 ACK 而不发起 SYN 请求。

##### C) UDP 洪水
突发发送伪造的大型 UDP 数据包饱和网络。

##### D) NULL 洪水
修改帧，发送传输协议字段设为零的数据包。

##### E) RST 洪水
突发发送不属于任何会话的 RST 或 FIN 数据包。导致防火墙饱和，因服务器尝试将数据包匹配到某个连接。

##### F) BOGUS 洪水
发送与前序数据包无关的伪造数据包，迷惑服务器并消耗其资源。

#### Smurf 攻击
攻击者在网络上广播（发送至所有连接的 IP）一系列 ICMP Echo 请求（Ping），源 IP 地址伪造为受害者 IP。结果所有主机向受害者发送响应，淹没受害者。

#### 死亡之 Ping
不基于资源耗尽，而是导致故障。利用 TCP/IP 协议栈实现漏洞，无法正确处理超出协议规定大小的数据包（现代系统不再易受此攻击）。发送超大 IP 数据包给受害者，重组时导致缓冲区溢出并阻塞系统。

### 21) MITM 中间人攻击
可用于闯入会话、监听或篡改内容。主要类型：

#### A) 嗅探
捕获两主机间的流量。

#### B) 劫持
将流量重定向至攻击者。

#### C) 注入
向连接添加恶意数据包。

#### D) 过滤
修改数据包载荷。

#### 主要攻击技术：本地、本地到远程、远程

##### 本地攻击技术

###### E) ARP 投毒
在受害者 ARP 表植入错误信息。将攻击者 MAC 地址与尽可能多的 IP 关联，使受害者发往某 IP 的数据包被发送给攻击者。

###### F) DNS 欺骗
修改并劫持主机指向伪造网站。受害者以为在访问安全网站，实则进入专门窃取登录凭据的仿冒站点。

###### G) STP 篡改
攻击者伪造并发送标识自己为根桥的数据包，将优先级字段设为零，必要时手动“降低”自身 MAC 地址（若已有零优先级交换机）。短时间内所有交换机将“迎接”新根桥并重建生成树，以攻击者为根。此时所有“非受管”流量将从交换机转发至攻击者。

###### H) 流量不同步
若攻击者能监控网段所有流量（连接至简单 HUB、交换机“监控”端口或通过 STP 篡改），可在 TCP 连接中插入伪造数据包以增加预期序列号。导致连接端点停止接受合法源流量（视为过时），转而接受攻击者拦截、可能修改并重发（更新序列号后）的流量。注意：这不属于 MITM 攻击。

##### 本地到远程 MITM 攻击

###### A) ARP 投毒
主机需向非本地 LAN 目标发送数据包时，在路由表查找网关。获取网关 IP 后，发起 ARP 请求获取其 MAC 地址。随后数据包可“上线”发送，目标 IP 为实际接收者，目的 MAC 为网关。网关再转发至目标。
