
# OpenVas 漏洞扫描完整指南

## 浏览器安全异常配置

点击“advanced”，然后点击“add exception”，最后点击“confirm security exception”，如下图所示。

![](rsrcM4.jpg)

浏览器将打开此界面，您需要指定用户名（`admin`）和密码（粘贴安装阶段保存的密码）。最后您将获得 OpenVas 图形界面的访问权限。

![](rsrcM5.jpg)

## 启动受害者虚拟机 (Metasploitable)

要执行测试，必须启动受害者虚拟机（Metasploitable）。访问时输入用户名（`msfadmin`）和密码（`msfadmin`）。

使用命令 `ifconfig` 将显示待分析机器的 IP 地址。**重要**：请在两台虚拟机中都将网络设置为“card with bridge”。

![](rsrcM6.jpg)

## 修改 OpenVas 密码

此阶段结束后，移至运行 OpenVas 的机器。首先需要修改密码。

1. 进入黑色工具栏中的“Administration”项下的“users”项。
2. 点击蓝色扳手符号，在“new password”字段中修改密码。
3. 点击“save”按钮确认保存。

![](rsrcM7.jpg)

## 执行漏洞分析

### 创建扫描任务

进入“Scans”下的“tasks”项，点击左上角的紫色魔杖符号。

![](rsrcM8.jpg)

将打开如下图所示的界面，您必须输入要分析的 IP 地址。本例中 Metasploitable 机器的 IP 地址为 `192.168.1.9`，输入后点击“start scan”并等待操作完成。如需分析多个 IP 地址，只需指定范围（例如 `192.168.1.1 - 192.168.1.20`）。

### 监控扫描进度

将打开类似下图的界面。红圈指示分析进度，蓝圈指示页面刷新检查扫描更新的秒数。

![](rsrcM9.jpg)

扫描耗时长短取决于待分析的漏洞。下图黑圈指示操作完成状态。

![](rsrcMA.jpg)

## 生成详细报告

扫描完成后，可生成包含所有发现漏洞及可能解决方案的详细报告。本测试选择了特别脆弱的目标以便分析报告。下图绿圈所示的严重程度将指示漏洞指数（范围 1-10，本例为最大值）。

进入“Scans”项下的“reports”字段（下图红圈指示）。

![](rsrcMB.jpg)

下图显示所有生成的报告列表。点击刚才执行的扫描（红圈指示）。

![](rsrcMC.jpg)

将出现包含所有已分析漏洞的界面（蓝圈指示）。在下图红圈处选择 pdf，然后点击下载按钮（绿圈指示）。

![](rsrcMD.jpg)

### 解决 PDF 生成问题

若生成的 PDF 文件大小为 0 字节，请打开终端并输入以下命令：

```
sudo apt-get install texlive-latex-base
sudo apt-get install texlive-latex-extra
sudo service openvas-scanner restart
sudo service openvas-manager restart
```

显然，您需要按上述指示重启 OpenVas 界面以使更改生效。

### 打开报告

此时选择“Save File”以下载，或选择“Open With”并选择“Other”直接打开。

![](rsrcME.jpg)

必须选择“View All Applications”。

![](rsrcMF.jpg)

最后，找到并选择“LibreOffice Writer”，先点击“Select”，再点击“Ok”。

![](rsrcMG.jpg)

几秒钟后您将看到详细报告，其中列出所有发现的漏洞及解决建议。下图显示报告的几页，您可以看到按降序排列的所有已分析漏洞索引（从最危险到最不危险）。

![](rsrcMH.jpg)

浏览报告可查看每个漏洞的详细分析和描述。

下图黑圈处为发现的漏洞结果，红圈处为可能的解决方案，绿圈处为搜索该漏洞所用的方法。

![](rsrcMJ.jpg)

## 结论

使用 OpenVas 可完全自动生成详细报告，并以简单方式分析所有已知漏洞。

在信息安全领域工作需要持续更新和每日学习。可用技术日益增多且愈发复杂，因此保护数据和信息的需求也随之增加。如今人们未意识到网络上的数据多么容易获取，仅通过浏览就能多么轻松地找到重要信息。黑客的目标从搜索系统漏洞到寻找个人漏洞不等。重要的是让每个人了解安全概念，以更清楚地认识所面临的风险。

> “不存在能保证最高安全级别的系统。”
