To begin, we can define rectangle_area simply as:

```
{ * } rectangle_area WORD
```

By definition of the multiplication operator *, the word rectangle_area must take two arguments, a number for height and a number for width. Accordingly, we can compute the area of a rectangle as:

```
5 7 rectangle_area ( → 35)
```

If we wish to embed as parameters the abstractions of h and w inside area, then we could first define a list such hw as:

```
{ 5 7} hw LIST
```

Then use the hw list as an argument for the area word:

```
hw area ( → 35)
```

This exemplifies how concrete values are substituted for labels during a function's application.

With the nesting of abstract types, with one inside another, we have in effect a hierarchy, a parent-child relationship. This permits us to exercise code re-use, reusing the code of a more general context for a distinct or concrete application. For example, in the code below, the word shape embodies the words h and w.
