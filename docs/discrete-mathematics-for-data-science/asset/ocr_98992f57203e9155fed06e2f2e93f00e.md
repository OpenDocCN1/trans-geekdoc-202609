# 13.2.4 Big-O Cases

Problems that can be solved in polynomial time are known as *tractable*. Conversely, *intractable* cannot be solved in polynomial time. (More about these concepts are discussed in the chapter *Computability`.)

DOI: https://doi.org/10.1016/j.scico.2003.12.0095. [Online]. Available: https://www.sciencedirect.com/science/article/pii/S0167642304000176. ¤

O(1): A constant, or zero degree polynomial, time. In other words, a specific number of operations is known to provide a solution. This is considered to have the fastest performance.

Consider a repetition of 10 operations:

```
for (i = 0; i < 10; i++) operation
```

Or:

```
{ operation } 10 LREPEAT
```

The upper limit is 10, which is a constant. Thus, this algorithm runs in a *constant time* efficiency of 10, which is denoted in Big-O as O(1).

O(log n): Logarithmic. A logarithmic algorithm is considered to be fast running. Typical of the efficiency of divide-and-conquer algorithms, wherein half the data is skipped in each cycle, the maximum growth function may be declared to have O(log2 n) efficiency.

The actual base of the log is a constant multiplier that is ignored in asymptotic analysis. Therefore, we can say that O(log n) = O(log2 n). Incidentally, log10(n) = log2(n) / log2(10) for all n.
