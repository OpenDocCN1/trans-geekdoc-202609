+   • Feature vector: A single observation of a set of features, also referred to as a row.
+   • Feature matrix: A set of multiple observations of feature vectors.
+   • Longitudinal data: A set of rows or records.
+   • Latitudinal data: A set of columns or dimensions.

High dimensionality can be a challenge even in situations where data sets are small and manageable. This happens when factors outnumber records, or when we generate too many additional fields as a result of data transformations and lagged time-series. Such highly dimensioanl cases are said to have as structural multicollinearity.

Data transformations increase the number of predictors (dimensions). Consider a data set consisting originally of a certain number of predictors P. If there are T data transformations performed, then we obtain new synthetic factors. Thus, the number of factors expands to:

```
P' = P \times T
```

If we additionally want to include various time lags L for each field and its transformations, then P further expands as:

```
P' = P \times T \times L
```

At some point, increasing the number of transformations and lags will possibly lead to problems, including the number of predictors exceeding exceeding the number of observations, model (classifier) overfitting, wasted resources and, as already mentioned, multicollinearity.
