+   n = the number of elements, including duplicates.
+   n1 = the count of the first element.
+   n2 = the count of the second distinct element.
+   :
+   nr = the count of the last distinct element.

Then the following formula applies:

P(n : n_1, n_2, ... n_r) = \frac{n!}{n_1! \times n_2! \times n_3! ...}

For example, consider that a received signal is decoded into the ASCII character sequence HALIFAX. The parameters of this multiset are as follows.

The length of the set: n = 7

Letter counts:

+   H: n1 = 1
+   A: n2 = 2
+   L: n3 = 1
+   I: n4 = 1
+   F: n5 = 1
+   X: n6 = 1

The number of permutations is:

\frac{7!}{1! \times 2! \times 1! \times 1! \times 1! \times 1!} = \frac{5040}{2} = 2520
