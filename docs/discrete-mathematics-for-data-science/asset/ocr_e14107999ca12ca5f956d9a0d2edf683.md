Consider the definitions of a successor function in terms of lambda calculus.

add1 = λf.λx.f(nfx) → λf.λx.fn 1x + = n 1 +

Further addition repeats the successor n + m times:

(m λx.(x add1n)) → (m add1n) → m n +

Similarly, there can be multiplication as repeated addition, and exponentiation defined by repeated multiplication. Subtraction is similar to addition, but with a predecessor function instead of a successor function. Division would then be by repeated subtraction.

Some basic addition:

1 2 (λx.(λy.(x y +))) → 2 (λy.(1 y +)) → 1 2 + = 3
