This can be stated as λx.E → λy.E[x/y].

Following alpha conversion, beta β reduction evaluates the respective parameters within a named function, replacing these sub-expressions with the resultant values.

Beta reduction of an application has the form (λx.E x) and is done by replacing all free occurrences of name x in body E with the argument x. For example, in the following application the function F replaces all occurrences of x in E.

```
(λx.E F) → E[x/F]
```

Similarly, the variable x would be replaced by the argument 5 as follows:

```
(λx.fx) 5 → f(5)
```
