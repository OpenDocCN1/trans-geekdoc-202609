# 13.2.1 Big-O: The Worst Case Scenario

The worst case scenario for an algorithm's efficiency corresponds to its upper
bound as the problem size grows. By definition, Big-O represents the worst
case scenario.

Suppose the function f(n) represents the problem size of an algorithm for
input size n. The function representing the upper bound of f is g(n). The
relationship of functions f(n) and g(n) for some input n and a positive constant
c is:

```
f(n) = O(g(n)), as n increases,
where f(n) ≤ c · g(n)
```
