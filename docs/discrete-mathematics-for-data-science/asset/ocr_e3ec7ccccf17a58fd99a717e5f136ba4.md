Conversely, if there is an element a ∈ A such that (a, a) ∉ R, then a relation R on a set A is not reflexive.

For example, if A = { 6 8 9 } and R = { (6, 6) (8, 8) (6, 8) (8, 9) }, R is not reflexive because (9, 9) ∉ R.

A relation R is irreflexive iff no elements relate to themselves. Stated differently, for all a ∈ A, (a, a) ∉ R.

If a relation is neither reflexive nor irreflexive, it is non-reflexive.

# 7.5.4 Symmetric Relations

A relation is symmetric if and only if aRb = bRa for every element of A and B. In other words, iff by R element a is related to b in the same way that b is related to a, for all pairs (a, b), then the relation R is symmetric. For a symmetric relation R, if (a, b) ∈ R, then (b, a) ∈ R.

For example, siblings are symmetric relations. Fido is Buster's brother. And logically, Buster is Fido's brother.

A relation R between two sets A and B is asymmetric iff for all pairs (a, b) where a ∈ A and b ∈ B, b is not related to a in the same way a is related to b. In other words, ∀(a, b), if (a, b) ∈ R, then (b, a) ∉ R.

For example, consider a father/son relationship: Murphy is the father of Fido. Logically, Fido is not Murphy's father.
