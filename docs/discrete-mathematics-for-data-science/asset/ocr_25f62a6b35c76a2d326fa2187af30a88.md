# B.8 WORD OVERRIDES

Abstract words can be redefined, as they are *overridable*. User-defined words are abstract words.

Primitive words are not overridable. Therefore, if a primitive word requires modification, then consider wrapping it in an abstract word. For example, suppose we want an addition operation that automatically emits the result. We can we define a word myadd that wraps the addition operator “+” followed by the *pop* operator denoted “.” and “CR” (carriage return) to display the result.

```
{ + . CR } myadd WORD
1 2 myadd
3
```

# B.9 DEEP COPY VS SHALLOW COPY

Words can control their own data and need not only reference the data of the other words comprising their definitions. That is, words may get a *deep copy* of data from their constituent words. For example:

```
: lista 2 4 6 8 ;
: listb lista ;
listb ’ SEE
2 4 6 8
```
