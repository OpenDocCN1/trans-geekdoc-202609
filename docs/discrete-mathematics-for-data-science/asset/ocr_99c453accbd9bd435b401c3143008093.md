For practice in equation minimization, we can use the Boolean theorems below to reduce the terms of a Boolean equation. A Boolean equation is an equation whose variables represent only values of true and false, or 1s and 0s respectively.

By the relation of equivalence, propositions satisfy the following Boolean laws and identities:

# Associative Identities:

p ∧ (q ∧ r) ≡ (p ∧ q) ∧ r
p ∨ (q ∨ r) ≡ (p ∨ q) ∨ r

# Commutative Identities:

p ∧ q ≡ q ∧ p
p ∨ q ≡ q ∨ p

# Complement Law:

¬p(¬p) ≡ p

# Contrapositive Law:

p → q ≡ ¬q → ¬p

# Distributive Identities:

p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
