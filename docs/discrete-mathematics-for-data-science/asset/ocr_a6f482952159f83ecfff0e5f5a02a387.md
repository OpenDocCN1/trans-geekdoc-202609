A *sum* function can be defined to repeat until all elements from *list* have been processed. That is, repeat until size of the stack as determined by the GSC function is no longer greater than 1.

```
{ + GSC 1 > sum ? } sum WORD
```

An *average* function can be defined to perform sum and division operations on the list:

```
{ list sum n / } average WORD
```

Invoking *average* generates a result:

```
average ( → 3.33)
```
