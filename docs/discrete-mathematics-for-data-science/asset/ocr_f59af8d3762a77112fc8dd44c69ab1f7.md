For another example, consider the number of possible ways that the bits of one byte can have exactly three zeros. The parameters of this 8-bit byte multiset are as follows.

The length of the set: n = 8

State counts:

+   - 0: n₁ = 3
+   - 1: n₂ = 5

The number of permutations is:

\(\frac{8!}{3! \times 5!} = \frac{40320}{6 \times 120} = 56\)

Another example: How many possible ways can bits of an 8-bit byte have more 1s than 0s?

If there are more 1s than 0s, then our bit set contains either five, six, seven, or eight 1s. Therefore, the solution is found by adding the permutations of four multi-sets.

Alternatively, we can think of this as a combination problem, where we are choosing a fixed number places (a subset of places) which will hold 1s. In terms of combinations, the computation is:

C(8, 8) + C(8, 7) + C(8, 6) + C(8, 5) = 1 + 8 + 28 + 56 = 93
