# 6.3 PROPOSITIONAL CONDITIONS

Propositional statements may be connected by logical operators. In order of precedence, these include:²

| Word | Symbol |
| :--- | :--- |
| NOT | ¬ |
| AND | ∧ |
| OR | ∨ |
| IF THEN | → |

1 In mathematics, the ≡ symbol is used to denote the equivalent cardinalities of two sets, whereas logical equivalence is often symbolized by = or ≡. In contrast, in computer programming languages, the common symbol for logical equivalence is ==, whereas the = symbol is generally used for variable assignment. ↩

2 These logic operators differ among programming languages. For example, in C we use the ` hat symbol for XOR and the | bar symbol for OR. The symbols for not or negation may be a tilde ~ in some programming languages (Standard ML) or an exclamation mark ! in others, including C/C++, D, Java, and Python. ↩

A NOT operation, symbolized by ¬, allows us to negate a proposition, giving us its complement. For example, the complement ¬1 = 0, and the complement of a symbol ¬A = a.
