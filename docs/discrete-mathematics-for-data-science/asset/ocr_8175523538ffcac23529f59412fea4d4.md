The equivalent of 3 + 4 in postfix is:

```
3 4 +
```

The result is of course 7.

Arithmetic operations are functions and functions can exist for more than arithmetic. There may exist functions for swapping and duplicating elements, perhaps called swap and dup, depending on the programming language one is using. Their effect on the number sequence 3 7 9 would be as follows:

```
3 7 9 SWAP
3 9 7 DUP
3 9 7 7
```

Notice that the operation SWAP switches only the two values preceding it and the operation DUP duplicates only the one value preceding it.

# 16.8 LIST IMPLEMENTATION OF A QUEUE

A queue is a data structure that has a First-In-First-Out (FIFO) sequence of processing. This ordering is similar to the entry-ramp for a freeway – the first car to enter the ramp is the first car to exit the ramp. The first item to enter a queue is the first to exit – FIFO for first in, first out. This contrasts with a stack, which is LIFO – last in, last out.
