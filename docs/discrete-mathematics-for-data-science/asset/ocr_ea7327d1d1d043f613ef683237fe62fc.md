9. Let x and y be positive integers and let f be a recursive function with two inputs, x and y, defined as:

```
f(x, y) = \begin{cases} 0 & \text{if } x < 1 \\ f(x - y, y) + 1 & \text{if } y \le x \end{cases}
```

+   (a) Compute \( f(21, 3) \)
+   (b) Compute \( f(3, 21) \)
+   (c) What does function \( f \) do?
