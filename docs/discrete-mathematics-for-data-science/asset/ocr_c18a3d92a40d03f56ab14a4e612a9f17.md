Formalities aside, the programming language that we wish to compose may be referred to as a *guest, target, or object language. The language used to generate (complie) a guest language may be referred to as the host or meta language. The symbols of the host may be referred to as *terminals* or *primitives*. The symbols of the guest language may be referred to as *non-terminals* or *abstractions*.

Incidentally, by composing a function of functions we effectively get what is referred to as a *higher order function*. In other words, an abstract word or function is a *higher order word*. Conversely, a primitive word or function may be called *lower order word*.5

A metalanguage and a *host language* may be one in the same. That is, if host language A is used to compile *guest* language B, then A may be referred to as a metalanguage. For example, the Python programming language is written in the C programming language. Python is the guest language and C is the host language.
