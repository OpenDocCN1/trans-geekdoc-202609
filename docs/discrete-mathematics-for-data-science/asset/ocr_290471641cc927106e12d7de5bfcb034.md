# 12.5.1 Boolean Functions

As with numbers, lambda calculus does not have any representation of *true* or *false*. These conditions must be defined. Therefore, one must define *true (t)* and *false (f)* values and related Boolean functions. This can be done as follows:

```
true=λt.λf.t
false=λt.λf.f
```

Using those functions, we can next define an *if* function that returns *true* if the argument x is true and returns *false* otherwise. In other words, *if* is an identity function. For example:

```
if = λx.λt.λf.x t f
```

Using *if* we can define additional Boolean functions in lambda calculus as follows:

```
and(x,y)=λxy.if x y f
or(x,y)=λxy.if x t y
not(x)=λx.if x f t
```
