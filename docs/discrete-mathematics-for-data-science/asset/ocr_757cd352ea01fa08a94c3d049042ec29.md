Push and pop operations provide a versatile basis upon which other words and language syntax can be built. Consider the following operations that define a word, and push that word's data values to the stack.

```
{ d e f } c WORD
a b
c
```

The data stack will now contain `a b d e f`, ordered from the bottom of the stack to the top.

Invoking the pop function one time will remove the element on top of the stack, with `a b c e` remaining. (There is more about push and pop operations in the stacks section of the Linear Structures chapter, as well as in Appendix B.)
