$R = \{ (0, 0) (1, 1) (1, -1) (-1, 1) (2, 2) (2, -2) ... \}$

Let's verify that $R$ is an equivalence relation.

Is $R$ reflexive? Yes, because for all $x \in \mathbb{Z}, |x| = |x|$, so $(x, x) \in R$.

Is $R$ symmetric? Yes, because for all $(x, y) \in R, |x| = |y|$ or $|y| = |x|$, so $(y, x) \in R$.

Is $R$ transitive? Yes, because if $(x, y)$ and $(y, z)$ are both in $R$, then $|x| = |y|$ and $|y| = |z|$, or $|x| = |y| = |z|$, so $|x| = |z|$, and so $(x, z) \in R$.

Since we have shown that the relation $R$ is reflexive, symmetric, and transitive, then by definition, $R$ is an equivalence relation.

For testing the equality of sets $A = \{ 1 \ 3 \ 5 \ 7 \}$ and $B = \{ 1 \ 3 \ 5 \ 7 \}$, we may scan each of the $N$ elements in set $A$ for a match with any of the elements $M$ in set $B$. The relation satisfying the equality of sets $A$ and $B$ would be:

$R = \{ (1, 1) (3, 3) (5, 5) (7, 7) \}$

Noting that $N = M = |R|$, we can conclude that $A = B$.
