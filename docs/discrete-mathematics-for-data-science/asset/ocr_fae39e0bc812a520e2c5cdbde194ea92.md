ARM CPU's Assembly language.7 ADD is much easier to remember than 1001000100, hence ADD is referred to as a mnemonic.

Mathematics is often done using binary operators (not to be confused with binary numbers), meaning that they take two arguments. Thus, a program's compiler will have grammars that enforce binary operations for a certain set of mathematical symbols, The enforcement of syntax rules must be a context-aware process (ie, not context-free).

When ADD is executed, the program will look for two numeric values to add together. In general, the whereabouts of the operands will be in memory, to be transferred into registers in the CPU in order to invoke addition upon them. The result may be kept in a CPU register for further operations, or it may be transferred to memory. At a higher level of abstraction, such storage may be within abstract data structures such as stacks, arrays, or linked-lists, depending on the architecture of the language.

Given that the composition of the addition function reduces, ultimately, to ADD, then ADD is considered a terminal symbol. Conversely, we may have an abstract function for addition that is not terminal. Consider the following function called addone.

```
{ 1 + } addone WORD
```

The word addone is an abstract non-terminal word, as it consists of at least one other word.
