- Singleton (unit set), { s }. A set containing just one element. For example:
  S = {s | s ∈ \mathbb{N} ∧ 0 < s < 2} = {1}, |S| = 1

- Empty or null set, ∅. Contains no elements. The cardinality is zero. For example:
  S = {s | s ∈ \mathbb{N} ∧ 0 < s < 1} = ∅ = {}

- Union, A ∪ B = {a | a ∈ A ∨ a ∈ B}. The set of elements which are in A or in B or in both A and B. For example:
  A = {1 2 3 5}, B = {1 2 4 6}, A ∪ B = {1 2 3 4 5 6}

- Intersection, A ∩ B = {a | a ∈ A ∧ a ∈ B}. The set of elements which are in both A and B. For example:
  A = {1 2 3 5}, B = {1 2 4 6}, A ∩ B = {1 2}

- Equal sets. Two sets containing the same elements and having the same cardinality. For example:
  A = {2 4 6}, B = {6 2 4}, |B| = |A|, A = B

- Equivalent sets. Two sets with same cardinality. For example:
  A = {1 3 5 7}, B = {2 4 6 8}, |B| = |A| = 4, A ≡ B

- Overlapping, A ∩ B ≠ ∅. Two intersecting sets with at least one common element. For example:
  A = {1 2 3 4}, B = {0 2 6 8}, A ∩ B = {2}

- Disjoint, A ∩ B = ∅. Two sets are disjoint if they have no elements in common. For example:
  A = {1 3 5 7}, B = {2 4 6 8}, A ∩ B = ∅

- Partitioned set. A collection of disjoint subsets p1, p2, ..., pn of S. Each subset contains at least one element of S. The union of all partitioned subsets yields the original set, S.
  p1 ∪ p2 ∪ ⋯ ∪ pn = S

- Cartesian product, A × B. The set of all possible ordered pairs (a, b) where a ∈ A, b ∈ B. For example:
  A = { 1 3 } and B = { 2 4 }, A × B = { (1, 2) (1, 4) (3, 2) (3, 4) }

- Difference, A - B = {a | a ∈ A ∧ a ∉ B}. Set of elements which are in A but not in B. For example:
  A = { 1 2 3 5 }, B = { 1 2 4 6 }, A - B = { 3 5 }, B - A = { 4 6 }

- Power set, P(S). Set of all subsets of S, including the empty set. The cardinality of P(S) is 2^n, where n is the number of elements in S. For example:
  Given S = {1 2 3 4}, n = |S| = 4
  Then, P(S) = {{}, {1}, {2}, {3}, {4}, {1 2}, {1 3}, {1 4}, {2 3}, {2 4}, {3 4}, {1 2 3}, {1 2 4}, {1 3 4}, {2 3 4}, {1 2 3 4}}
  And, |P(S)| = 2^n = 2^4 = 16

## 7.3 QUANTIFICATION

Quantifiers are symbols in propositional logic that pertain to the existence and number of elements in sets.

The quantifiers are the:

- Universal quantifier, *for all*, symbolized as ∀.
- Existential quantifier, *some exist*, or *at least one exists*, symbolized as ∃.

If a statement is true for all elements of a set, then the universal quantifier applies. This can be expressed as:

```
∀x P(x)
```

... or: “For every element x, a property P is true.”

The statement *goats are quadrupeds* has this form, given that *goats are quadrupeds* is true for all goats.

$^1$In data science topics having to do with relational databases, Cartesian Product is sometimes referred to as *cross product*. $\triangleq$

If a statement is true for only some elements of a set, then the existential quantifier applies. The expression “for every element x, some P(x) are true” can also be written as:

```
∀x ∃P(x)
```

The statement *some goats are brown* has this form, given that not all goats are brown.

Accordingly, we can also have *nested quantification*.$^2$ That is, given the domain $P(x, y)$, the statement $(\forall x)(\exists y)P(x, y)$ says: *For all x there is some y such that P(x, y) is true*.

Consider the domain of all integers. If $P(x, y)$ is the predicate $x \times y = 11$, then the statement $(\forall x)(\exists y)P(x, y)$ must be false. That is, we know for each integer x there is not an integer y such that \( x \times y = 11 \). We can only find an integer, y, for certain x values { 1 -1 11 -11 }, but not for all x values.

In programming we may have functions for testing for the existence of elements in data sets. For example, in an *epop* program we can test for the existence of a dog among animals, the statement \((\forall animals)(\exists dog)P(animals, dog)\), as follows:

```
{ cat dog pig goat } animals LIST
{ DogFound!. CR } dogfound WORD
{ dog EQ dogfound ? GSC 0 > havedog ? } havedog WORD
animals havedog ( → DogFound!)
```

In the above example code, a list named animals is invoked, pushing all four animal types on to the data stack in the order given in the animals list. Then the havedog word is invoked, which compares each animal type on the data stack to the string “dog.” If there is a match, the string DogFound! is emitted.

## 7.4 SET RELATIONS

Sets can be viewed as propositions composed of predicates. A group of predicates evaluates to true or false, and the group itself may be a predicate of a larger statement.\(^3\)

\(^2\)As with lists of lists. See the *Linear Structures* chapter.

\(^3\)This topic overlaps with *Propositional Logic* and the coverage of sets in *Unconnected Data*.

When a series of propositions exist, we have the opportunity to check for a contradiction and to validate a system of logic. In a similar way, we can construct a sequence of statements for a mathematical proof, testing it by inserting other statements where a contradiction should be formed.

Consider the two statements:

> All cats are black.
> Chewy is a gray cat.

Obviously, this is a contradiction. It cannot be true that all cats are black, because at least one non-black cat exists. Each predicate is an element of a set that is effectively symbolized by its containing proposition. Consider a set where the elements are separate statements, each of which is either true (1) or false (0).

$S = \{ 1 0 1 0 \}$

The combined statements may be evaluated as:

$S = \{ 1 \land 0 \land 1 \land 0 \} = \{ 0 \}$

In a programming context, we can evaluate such a set as follows.

```
{ 1 0 1 0 } statement WORD
{ * GSC 1 > evaluate ? } evaluate WORD
statement evaluate. ( → 0)
```

Each \(\land\) operation above is a binary operation, taking two operands. In the programming example, the multiplication operator * suffices for \(\land\), the logical *and* operator.

Applying such a binary operation to the element pairs of two or more sets allows us to affect a *binary relation* on a set.

A binary relation \( R \) on \( S \) is any subset of the ordered pairs in the Cartesian product. (All ordered pairs in the Cartesian product make up a *full relation*.)

For example, given set \( S = \{ a \ b \ c \} \), a binary relation \( R \) on \( S \) is any subset of the ordered pairs in the Cartesian product. Consider:

\( S \times S = \{ (a, a) (a, b) (a, c) (b, a) (b, b) (b, c) (c, a) (c, b) (c, c) \} \)

One relation between two sets \( A \) and \( B \) is the Cartesian product of \( A \) and \( B \). The cardinality is N × M, where N is the number of elements in set \( A \), and M is the number of elements in set \( B \). Another relation on \( S \) above could be \( R = \{ (a, b) (b, c) (a, c) \} \). \( R \) is a relation on \( S \) since these pairs exist in the full relation. It can be said that element \( a \) is related to element \( b \) by \( R \).

Note that the relation \( R \) is, itself, a set.

Conversely, there is no relation on \( S \) for \( Q = \{ (a, b) (b, c) (c, d) \} \). The pair \( (c, d) \) does not exist in the full relation.

Besides binary pairings such as \( (i, j) \), a *set relation* may consist of other ordered tuples, such as ternary \( (i, j, k) \) for three sets, and n-ary \( (i, j, k, l ...)\) for larger numbers of sets.

As with predicate logic, pair order matters in relations. For example, given that \( A = \{ a \ b \ c \} \) and \( B = \{ c \ b \ a \} \), we can say \( A = B \). However, \( (a, b) \neq (b, a) \). This is because \( a \neq b \) and \( b \neq a \).

Consider that a parent-child pair is only valid for a certain order.

\( R(parent, child) \neq R(child, parent) \)

The relationship can be described as the binary relation *begets*, in that a parent begets a child. The inverse relationship could then be the binary relation *inherits*, since the child inherits from the parent.

```
R(parent,child) ∈ begets
R(child,parent) ∈ inherits
```

The argument order infers a certain relationship.

A *binary relation* between sets *A* and *B* may be written in the form:

```
R(a, b)
```

Or:

```
aRb
```

Suppose we have three sets *A*, *B*, and *C*, and a relation *R1* between *A* and *B*, and another relation *R2* between *B* and *C*. We can then relate elements of *A* to elements of *C* by *composition* as follows:

```
a(R2 ◦ R1)c,
iff there exists some B elements that satisfy both aR1b and
bR2c.
```

The small circle symbol ◦ indicates that the output of *R1* becomes the input of *R2*. This circle symbol is used for the composition of abstract functions as well.
