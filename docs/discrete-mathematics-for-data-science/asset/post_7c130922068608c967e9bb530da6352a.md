
Given two sets $A$ and $B$, the domain $D$ of their relation $R$, denoted $DoR$, is the set of $A$'s elements that have a relation to elements in set $B$. The range of the relation is the list of distinct $b$ elements comprising each pair. The range is also called the image.

The domain can be written:

$DoR(a, b) = \{a|(a, b) \in R\}$

For unequal sets $A = \{ 1, 3, 5, 7 \}$ and $B = \{ 1, 3, 4, 6 \}$, an example of a relation $aRb$ is:

$aRb = \{(1, 3), (1, 4), (1, 6), (3, 4), (3, 6), (5, 6)\}$

The domain is:

$DoR = \{ 1, 3, 5 \}$

The range is:

$RaR = \{ 3, 4, 6 \}$

In general, the range of relation $R$ can be described as:

$RaR(a, b) = \{ b | (a, b) \in R \}$

## 7.5 TYPES OF SET RELATIONS

We will cover six special types of set relations. They are:

- Inverse
- Identity
- Reflexive
- Symmetric
- Transitive
- Equivalence

### 7.5.1 Inverse Relations

Given a relation R, the inverse relation R⁻¹, is:

```
R⁻¹ = { (b, a) | (a, b) ∈ R }
```

To find the inverse, we switch the order of each a and b. For example:

```
If R = { (1, 3), (2, 4) }, then R⁻¹ = { (3, 1), (4, 2) }
```

### 7.5.2 Identity Relations

In an identity relation, every element is related only to itself.

If A is a set, then the identity relation of A is the relation:

```
R = { (a, a) | a ∈ A }
```

For example, with A = { a, b, c }, we have relations R1 = { (a, a), (b, b), (c, c) } and R2 = { (a, a), (b, b), (c, c), (a, c) }.

R1 is an identity relation on A. However, R2 is not an identity relation on A since element a is related to c as well as a.

### 7.5.3 Reflexive Relations

A relation is reflexive if every element of a set is related to itself, though an element may be related to another element as well. Stated differently, R is reflexive iff (a, a) ∈ R for all a ∈ A.

For example, given set A = { 1, 2, 3 } and the relation R = { (1, 1), (2, 2), (3, 3), (1, 3), (2, 1) }, R is reflexive because for each a ∈ A,

(a, a) ∈ R. (Note that R is reflexive, but R is not an identity relation.)

Conversely, if there is an element a ∈ A such that (a, a) ∉ R, then a relation R on a set A is not reflexive.

For example, if A = { 6, 8, 9 } and R = { (6, 6), (8, 8), (6, 8), (8, 9) }, R is not reflexive because (9, 9) ∉ R.

A relation R is irreflexive iff no elements relate to themselves. Stated differently, for all a ∈ A, (a, a) ∉ R.

If a relation is neither reflexive nor irreflexive, it is non-reflexive.

### 7.5.4 Symmetric Relations

A relation is symmetric if and only if aRb = bRa for every element of A and B. In other words, iff by R element a is related to b in the same way that b is related to a, for all pairs (a, b), then the relation R is symmetric. For a symmetric relation R, if (a, b) ∈ R, then (b, a) ∈ R.

For example, siblings are symmetric relations. Fido is Buster's brother. And logically, Buster is Fido's brother.

A relation R between two sets A and B is asymmetric iff for all pairs (a, b) where a ∈ A and b ∈ B, b is not related to a in the same way a is related to b. In other words, ∀(a, b), if (a, b) ∈ R, then (b, a) ∉ R.

For example, consider a father/son relationship: Murphy is the father of Fido. Logically, Fido is not Murphy's father.

Finally, a relation is antisymmetric if it is not symmetric unless all elements are the same. A relation R is antisymmetric provided that, if \( (a, b) \) is in the relation, then \( (b, a) \) is not in the relation, unless \( a = b \).

For example, the relation \( \le \) on real numbers is antisymmetric because for two numbers \( a \) and \( b \), \( a \) must equal \( b \) for \( a \le b \) and \( b \le a \).

### 7.5.5 Transitive Relations

A relation \( R \) is transitive *if and only if* for all elements of sets \( A \), \( B \), and \( C \), if \( (a, b) \) and \( (b, c) \) are in \( R \), then \( (a, c) \) is also in \( R \).

Symbolically stated, \( R \) is transitive iff:

\( aRb \land bRc \rightarrow aRc, \forall a \in A, b \in B, c \in C \)

For a single set \( A = \{ a_1, a_2, a_3 \} \), a relation \( R \) is transitive iff \( a_1 \) is related to \( a_2 \) and \( a_2 \) is related to \( a_3 \) in the same way that \( a_1 \) is related to \( a_3 \).

For example, Boston is further away than Chicago. Chicago is further away than Seattle. Therefore, Boston is further away than Seattle.

A relation \( R \) is *intransitive*, or *non-transitive*, *iff* there is at least one combination of ordered pairs, \( (a, b) \) and \( (b, c) \), in \( R \) where \( (a, c) \notin R \). So, \( a \) is related to \( b \) and \( b \) is related to similarly to \( c \), but \( a \) is definitely not related to \( c \) in the same way.<sup>4</sup>

For example, consider that an airline has a direct route from Boston to Chicago, and from Chicago to Seattle, but not from Boston to Seattle.

For a relation \( R \) on a larger single set \( S \), suppose \( x \), \( y \), and \( z \) are any three elements of \( S \). \( R \) is a transitive relation *if and only if* for two pairs of the form \((x, y)\) and \((y, z)\) in \(R\), \((x, z)\) is also in the relation \(R\). For example, if \((5, 1) \in R\) and \((1, 8) \in R\), then \((5, 8)\) must be in \(R\) also.

### 7.5.6 Equality & Equivalence in Set Relations

Recall that sets are called *equivalent* if they have the same number of elements. Equivalence between two sets is strictly a matter of cardinality.<sup>5</sup> Two sets are called *equal* if all of their elements are exactly the same. While equal sets are equivalent, equivalent sets may not be equal.

An *equivalence relation* is a relation that is reflexive, symmetric, and transitive.

### Examples of equivalence relations:

```
R = { (1, 1), (2, 3), (3, 3) } (An *identity relation*.)
```

```
R = { (1, 1), (2, 3), (3, 3), (2, 3), (3, 2) }
```

Note that in each of the above relations, those pairs having equal elements are transitive. This is sometimes referred to as *vacuous transitivity*, as there are no other elements to contradict the transitive property.

For example, the pair (1, 1) is a transitive relation to itself. We can see this transitive relation in \((a, b) \in R \text{ and } (b, c) \in R\), when \(a = 1\), \(b = 1\), and \(c = 1\). Thus, by definition of transitive relation, the equal pair (1, 1) is a transitive relation.

This next relation has infinite cardinality.

```
R = \{(x, y)| x, y \in \mathbb{Z} \text{ and } |x| = |y|\}
```

<sup>4</sup> There generally appears no standard agreement that *intransitive* and *non-transitive* relations are different. Therefore, they are treated here as being the same.

<sup>5</sup> This is unlike data collections such as lists in programming languages, which require lists of equal size to have the same elements for equivalence.

Some of the elements are:

$R = \{ (0, 0), (1, 1), (1, -1), (-1, 1), (2, 2), (2, -2) ... \}$

Let's verify that $R$ is an equivalence relation.

Is $R$ reflexive? Yes, because for all $x \in \mathbb{Z}, |x| = |x|$, so $(x, x) \in R$.

Is $R$ symmetric? Yes, because for all $(x, y) \in R, |x| = |y|$ or $|y| = |x|$, so $(y, x) \in R$.

Is $R$ transitive? Yes, because if $(x, y)$ and $(y, z)$ are both in $R$, then $|x| = |y|$ and $|y| = |z|$, or $|x| = |y| = |z|$, so $|x| = |z|$, and so $(x, z) \in R$.

Since we have shown that the relation $R$ is reflexive, symmetric, and transitive, then by definition, $R$ is an equivalence relation.

For testing the equality of sets $A = \{ 1, 3, 5, 7 \}$ and $B = \{ 1, 3, 5, 7 \}$, we may scan each of the $N$ elements in set $A$ for a match with any of the elements $M$ in set $B$. The relation satisfying the equality of sets $A$ and $B$ would be:

$R = \{ (1, 1), (3, 3), (5, 5), (7, 7) \}$

Noting that $N = M = |R|$, we can conclude that $A = B$.

Conversely, given non-equal sets $A = \{ 1, 3, 5, 7 \}$ and $B = \{ 1, 3, 4, 6 \}$, a relation $R$ conditioned on the subset of equal pairs will have

a cardinality less than that of the given sets:

$R = \{ (1, 1), (3, 3) \}$
