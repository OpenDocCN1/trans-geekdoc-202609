Note how the addition operation is treated as data by its presence on the data stack. When the addition operation on the top of the stack is invoked, it adds the next two values, 5 and 3, with the result of 8 going on to the top of the stack. Before the next addition operation can be invoked, it must be moved to the top of the stack, which can be accomplished by shifting 8 to the bottom of the stack. (A program implementing such a process is available in Appendix C.11.)

The cases for recursion of the above sum operation are as follows:

+   • Base case – stop: Too few numbers exist for addition.
+   • Inductive case – continue: Enough numbers exist for addition.

There are generally two types of mathematical induction, weak and strong. For weak induction, we prove one base case and the given i of the inductive case needs only the immediate predecessor of i − 1. If we can show that P(i) is true using the assumption that P(i − 1) is true, then the inductive case is complete.

Strong induction involves proving more than one base case (the number of base cases required depends on the situation). Then we assume the statement is true for all i < n, and prove the statement must also be true for the next case (i = n). That is, assume P(i) is true for all i < n, and show P(n) is true.
