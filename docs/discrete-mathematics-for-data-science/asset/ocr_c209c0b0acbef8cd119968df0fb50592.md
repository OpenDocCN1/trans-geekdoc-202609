```
$P(exactly two heads) = \frac{|E|}{|S|} = \frac{3}{8}$
```

The _complement_ of _E_, denoted $E'$, contains all events in the sample space that are not in _E_. In our first die example, where a die is rolled once, recall $E = \{ 2 4 6 \}$. $E'$ is the event of rolling an even number, so $E' = \{ 1 3 5 \}$. Note that $E \cap E' = \emptyset$. An event and its complement have no outcomes in common; they are disjoint sets. An event and its complement cannot both occur at the same time.

Also note that $E \cup E' = $ the entire sample space. For this reason, when a procedure is performed (a coin is tossed or a die is rolled, for example), either an event or its complement must occur, which leads to the relationship:

```
$P(E) + P(E') = 1$
```

Rearranging this equation gives a way to find the probability of an event, _E_:

```
$P(E) = 1 - P(E')$
```

This relationship is especially helpful in situations where it is easier to find the probability of the complement of an event than the probability of the event itself. In addition, by using the complement, we can find the probability that event _E_ does not occur as:

```
$P(E') = 1 - P(E)$
```
