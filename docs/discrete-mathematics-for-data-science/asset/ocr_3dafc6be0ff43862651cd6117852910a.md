These argument forms will be explained through the remainder of this section.

Words may be used as arguments for other words, as needed for the purposes of branching, repetition, etc. For example, repetition can be induced by having a word refer to itself (aka *recursion*), such as:

```
{ + DUP 10 < sum ? } sum WORD
```

Words that are defined recursively should usually make the self-reference conditional (the above example is conditional on sum < 10). Otherwise, to use a recursive word unconditionally without errors, it must be predefined, such as:

```
{ } sum WORD
{ + sum DUP 10 < sum ? } sum WORD
```

Instead of recursion, the LREPEAT word can be used for repetition. LREPEAT repeats an expression inside of { } braces. The following code will repeat an operation of addition ten times:

```
{ + } 10 LREPEAT
```

Alternatively, REPEAT can be used such as:

```
+ ' 10 REPEAT
```
