# GRAPH EXERCISES

1. Compare Breadth First Search (BFS) to Depth First Search (DFS) for a graph. Explain how they work and how one or the other may be used to measure the distance of a path in a graph.

2. Write an algorithm to build a simple connected graph based on an initial list of vertices and edges.

3. Write a function to verify that a graph is regular.

4. Write an algorithm that generates two undirected graphs G1 and G2, each with vertices A to Z, and each with randomly connected vertices (no more than one connection to a pair of vertices). The connection weights should be random integers from 1 to 10.

5. For the prior generations of graphs G1 and G2, determine if G1 and G2 are equal, identical and/or isomorphic.

6. Write a function to generate an adjacency matrix from a list of vertex pairs.

7. Write a function to determine if a graph is directed or undirected.

8. Devise a function to determine if a graph is strictly a tree.

9. Consider a graph wherein all vertices have at most one neighbor. Explain how the results of a breadth-first search would compare to the results of a depth-first search.

10. Write a function called graph_density that takes as input a list of all the vertices of a graph and determines if a graph is dense or sparse.
