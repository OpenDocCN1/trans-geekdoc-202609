# B.1 EPOP'S GENERAL SYNTAX

These are the general rules for programming in epop. Individual words have their own rules, as documented below.

epop syntax is run either at the epop> prompt or in a stand-alone epop program file using the RUN word. To invoke epop from the command-line, just enter: epop. That will start epop and display its prompt as:

```
epop>
```
