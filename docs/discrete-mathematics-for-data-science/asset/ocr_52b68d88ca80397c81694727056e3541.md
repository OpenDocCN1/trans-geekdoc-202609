To duplicate a value, use DUP as a postfix operation:

```
5 DUP
```

The result is a sequence: 5 5.

To compute the average of two numbers, 3 and 5, and add 1 to the result:

```
3 5 + 2 / 1 + . CR
```

The “.” operator pops the value from the top of the stack, displaying the computed result of 5. The CR operation is a carriage return, used here to put an extra line between the result and any subsequent output, such as the terminal prompt.

# A.4 FUNCTION DEFINITIONS

We define functions as we would define words. Like the definition of a word in the English dictionary, the definition of a code word consists of other words that are elsewhere defined. Word definitions can be short or extensive. Of course, long word definitions are difficult to remember. Instead of one long complex word definition, it is preferable to have a sequence of word definitions that are short and relatively simple.
