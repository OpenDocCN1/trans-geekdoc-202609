
where $P_0$ is the probability that a symbol will be received. This can alternatively be expressed as:

$I = \log_2(1/P_0)$

<sup>4</sup>This is different than thermodynamic entropy.

By using logarithms in base 2, the system readily corresponds with binary digits and their strings thereof. However, any base can be used. For example:

$I_a = \log_a(1/P_0) / \log_a 2$

where $a$ is an arbitrary base and $I_a$ is the Shannon Information in base $a$.

Given 100% certainty that a message is received, Shannon Information is computed as:

$I = -\log_2 1 = 0$

Therefore, there are 0 bits of entropy, meaning that a message gets received with 100% certainty.

Consider a scenario of one of two possible messages being received with equal probability, such as from flipping a coin for heads or tails. Either message has a 0.5 probability of receipt. With only two possible outcomes for a message, a single bit represents the entropy. This can be verified by computing Shannon Information as:

$I = -\log_2 0.5 = \log_2(1/0.5) = \log_2 2 = 1$

## 22.3 MESSAGES OF MULTIPLE SYMBOLS

Consider a scenario where any one of ten equally probable messages may be received. Shannon Information would then be computed as:

$I = -\log_2(1/10) = 3.3$

That is 3.3 bits of Shannon Information.

Similarly, if it is known that the symbol ‘B’ occurs 8 times in 64 symbols, then the number of bits required to represent ‘B’ is:

$I = -\log_2(8/64) = 3$

The result of 3 is the exponent to which the base 2 must be raised to obtain the reciprocal of 8 / 64. That is $2^3 = 8$.

For multiple symbols comprising a message we use a weighted average entropy, denoted as:

$H = - \sum_{i=1}^{n} P_i \log_2 P_i$

The probabilities now serve as the relative weights of the symbols. $P_i$ is the probability of any one symbol and the overall Shannon Information is the sum of those probabilities. Consider the simple message AAAABBBBBB. The message has ten characters, with four As making up 40% of the total and six Bs accounting for 60%. The computation for Shannon information is thus:

$H = -(0.40 \times \log_2 0.40 + 0.6 \times \log_2 0.6) = 0.971$

## 22.4 SYMBOL PROBABILITIES

With a set of symbols in a message, the entropy calculation can be broken down as:

- Number of elements, N.
- Symbols, S, indexed from 1 to N.
- Probability of each symbol, $P_i = (|\{S_i \in S\}|)/N$
- Message entropy, $H = - \sum_{i=1}^n P_i \log_2 P_i$

Consider a list of symbols, such as the number list { 1 3 5 7 }. Since each of the four numbers is unique, the probability of randomly drawing any one of them is 1/4, or 0.25. The Shannon Information may be computed as follows:

$H = -(0.25 \times \log_2 0.25 + 0.25 \times \log_2 0.25 + 0.25 \times \log_2 0.25 + 0.25 \times \log_2 0.25) = 2$

In Information Theory we are interested in Shannon entropy given a set of symbols in any order. Unless a symbol sequence is designated as another symbol, whether data contains either a meaningful or a random sequence is not considered relevant.

In practical terms, to determine symbol probabilities quantify the symbols of a symbol dictionary relevant to its system of use, such as a spoken language. For example, the English language has these quantifications:<sup>5</sup>

## 22.5 JOINT ENTROPY

Joint entropy quantifies the uncertainty of two random variables taken together. Given that H(A) and H(B) represent the entropy for different sets of outcomes, their joint entropy is the union of these sets. If the sets are independent, then the joint entropy is the sum of their individual entropies.

Joint entropy can be expressed as:

$H(A, B) = -\sum_{i=1}^n \sum_{j=1}^m P_i(A_i, B_j) \times \log_2 P(A_i, B_j)$
$= H(A) + H(B \mid A)$

where $H(A_i, B_j) \in H(A) \cup H(B)$

## 22.6 CONDITIONAL ENTROPY

There are cases in which one variable depends on another. For example, coincident signals may actually entail some causal relationship. The discrete random variable A may be interpreted as a case while the discrete random variable B is considered an effect.

Consider that the entropy of B pertains to outcomes $a_i$, where $H(B \mid A)$ is the weighted average of $H(B \mid A = a_i)$ over all values $a_i$ that B may take.

Conditional entropy for B given a single event $a_i$ can be expressed as:

$H(B \mid a_i) = -\sum_{j=1}^m P(b_j \mid a_i) \times \log_2 P(b_j, a_i)$

Conditional entropy for B given events of A can be expressed as:

$H(B \mid A) = -\sum_{i=1}^n \sum_{j=1}^m P(a_i, b_j) \times \log_2 P(b_j \mid a_i)$
$= H(A, B) - H(B)$

where $H(A_i, B_j) \in H(A) \cap H(B)$.

To evaluate the quality of a received signal, we can compare the joint entropy of sender and receiver data to the entropy of the sender's data. In this context the equation for conditional entropy can be expressed as:

$H(R \mid S) = H(S, R) - H(R)$

Given an uncertain received signal, where R is not likely to reflect S, the sets may be independent or there may be too much noise in R.

## 22.7 MUTUAL INFORMATION

Mutual information can tell us how much uncertainty is removed from a message when there is prior knowledge of another message. The mutual information of two sets of symbols is a gauge of how much dependence exists between the sets.

Mutual information I can be expressed in terms of the prior entropy equations.

$I(A, B) = H(A) - H(A \mid B)$
$= H(B) - H(B \mid A)$
$= H(A) - H(A, B) - H(B)$
$= H(A) + H(B) - H(A, B)$

## 22.8 NOISE, ERROR DETECTION & CORRECTION

Noise amounts to entropy and uncertainty. Therefore, it is to be minimized.

Simplistic approaches to dealing with noise include sending redundant symbols and using a parity bit.

A message can be sent twice and the two instances of the received message can be compared. The information that these messages have in common provides a degree of validation. If re-transmission corroborates the symbols that were received previously, then mutual information will be equivalent to the joint entropy of the redundant sets.

Recall that for mutual information,

$I(A, B) = H(B) - H(A \mid B)$

If A = B, then by substitution it can be shown that:

$H(A \mid B) = H(A, B)$

This means that redundant symbol transmission maintains the same probability for symbols provided that all symbols have the same redundancy.

For example, instead of only transmitting the symbols HOP, transmit symbols in duplicate, such as HHOOPP. That way the receiver can determine that the receipt of HHOXPP has an error, as the probabilities of these symbols are not the same. Then some corrective measures may be taken, such as a re-transmit request.

A parity bit can be used to reduce the amount of redundant data that is used for defeating errors. The parity bit will be a single bit appended to each message indicating that the message had an odd (0) or even (1) number of bits.

For a parity bit to work when transmitting symbols of the Unicode character set, the binary representation of that character is used. For example, H in Unicode is represented by the decimal number 72, which is 01001000 in binary.

For basic one-dimensional parity, appending an even (1) parity bit makes that a 9-bit string, 010010001.

The parity of a series of symbols can be checked using the following computation:

$paritysum = \sum_{i=1}^{n} S_i \mod 2$

The result can be compared to an expected parity sum.

## 22.9 CHANNEL CAPACITY

A channel is limited by how many bits it can carry without signal loss. The maximum bandwidth may be determined by finding the highest number bits that can be transmitted without increasing the entropy of the received message.
