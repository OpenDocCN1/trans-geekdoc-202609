The formal definition of finite automata includes five parts: States, input symbols, initial state, accepting state, and a transition function.

Finite automata may be symbolized as follows (the notation varies):

+   * P: Set of input symbols.
+   * S: Set of internal states (character symbols, or 0 or 1).
+   * T: Set of yes states (subset of S; 1 for true).
+   * s₀: Initial state in S (perhaps 0).
+   * W: State transition function.

W changes the state of the system, depending on an existing state, s, and an input, p. The application of W to all inputs may be symbolized as:

```
W : S × P → S′
```

S′ represents the set of internal states after the application of the transition function. Because all yes states of DFA are enclosed in the machine, proofs of DFAs use _universal quantification_. Conversely, because only some states may be enclosed in an NFA, those proofs use _existential quantification_.
