4. Repeat from step 1 while N > 0.

Here is an example that uses the remainder method to convert 0d84 to binary.

| N/2 | Q | R |
|---|---|---|
| 84/2 | 42 | 0 |
| 42/2 | 21 | 0 |
| 21/2 | 10 | 1 |
| 10/2 | 5 | 0 |
| 5/2 | 2 | 1 |
| 2/2 | 1 | 0 |
| 1/2 | 0 | 1 |

The binary result is 0b1010100. This is an accumulation of the remainders. Starting from the top, the first remainder of 0 is placed in rightmost or least significant position, and the last remainder of 1 is placed in leftmost or most significant position.

Another example: convert 0d56 to hexadecimal using the remainder method.

| N/16 | Q | R |
|---|---|---|
| 56/16 | 3 | 8 |
| 3/16 | 0 | 3 |

The result is 0x38. Note that we end up with a remainder of 3, as 16 does not go into 3. The hexadecimal result is the accumulation of remainders starting with the rightmost, least significant digit.
