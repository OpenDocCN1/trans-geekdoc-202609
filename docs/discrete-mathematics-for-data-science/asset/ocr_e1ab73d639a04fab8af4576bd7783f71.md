# 7.1 SETS

Sets are unordered collections of elements that do not include duplicates. However, sets may also be empty and elements may actually be other sets called _subsets_. Element values can be the numbers, characters, words or the members of some class, such as number types, animals, automobiles, or some other classification.

A set may be represented such as { _a b c d_ }. Because order does not matter, the same set can be represented as { _c b d a_ }.

The character _S_ is typically used to symbolize a set. If a set _S_ had no elements, it is an _empty set_ and is given as _S_ = { } or _S_ = ∅.

If _S_ were not empty, we could have:

```
S = {s₁ s₂ ... sₙ},
```

such that each _s_ is in _S_.

Or, we could use another capital letter, such as _A_, for a set.

```
A = {a₁ a₂ ... aₙ},
```

such that each _a_ is in _A_.

If _s_ is an element of set _S_, then we write:

```
s ∈ S
```

If _t_ is not an element of set _S_, then we write:

```
t ∉ S
```
