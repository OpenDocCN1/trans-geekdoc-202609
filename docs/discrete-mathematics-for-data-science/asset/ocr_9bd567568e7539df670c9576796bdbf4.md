For example, to compute the sum of a series of numbers,
consider that an accumulator variable named _sum_ is defined as
immutable. Therefore, _sum_ cannot be used repetitiously, such
as:

```
sum = sum + input
```

Or

```
sum @input + sum !
```

7Immutability is the default state for non-reference variables in some functional
programming languages, as well as in distributed programming environments where
immutability protects variables against unintended results. ⌴

However, by using recursion we accommodate immutable
accumulator variables because assignment only occurs once,
after the enclosing function's stack was fully generated and
then executed.
