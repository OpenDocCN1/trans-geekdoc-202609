Boolean types are the simplest atomic values, as they merely evaluate to true and false. In machine terms, that is 1 for true and 0 for false. Such Boolean logic in terms of 1s and 0s forms the logical basis of computer architecture.

For example, to evaluate whether or not two numbers, 5 and 5, are the same, one might use a built-in word NEQ, for *not equivalent*. NEQ results in 1 if the statement is true and 0 if the statement is false.

```
5 5 NEQ ( → 0)
```

Conversely, one may wish to define elaborate words for evaluating equivalency in terms of *true* and *false*, such as:

```
{ 1 } t WORD ( define t as 1)
{ 0 } f WORD ( define f as 0)
{ 1 EQ t f ?? } true WORD ( define a true condition)
{ 0 EQ t f ?? } false WORD ( define a false condition)
1 true ( → 1 for true)
1 false ( → 0 for false)
```
