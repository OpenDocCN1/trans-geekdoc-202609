# ## 12.2 FUNCTION APPLICATION

Function application in lambda calculus pertains to applying a function (a lambda abstraction) to an argument. The process is one of reduction by substituting the argument for the bound variable in the function body.

In lambda calculus, function application has the form:

```
(function_expression argument_expression)
```

The application form turns an abstract function into a concrete implementation that can compute. For example:

```
2(λx.x1+) → 3
```

Reminder: we are using arithmetic operators in a postfix manner. So, x 1 + is an operation of addition (a function with two operands, x and 1). While such operations and numbers do not technically exist in lambda calculus, they are often used for internal function expressions to expedite examples. (Formally, lambda calculus uses abstractions of the successor function for numbers and operations.)
