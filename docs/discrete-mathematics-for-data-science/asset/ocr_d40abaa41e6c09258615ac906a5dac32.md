For example, if the lower bound is 0, then the base case may be denoted P(0) or P(i), where i is 0. Given a such a lower bound, if i > 0, then an inductive case exists. For the lower bound of i = 0, the inductive case then applies when i > 0.

Whether we inductively ascribe a sequence of predecessors using forward induction, or successors using reverse induction, depends on the desired order of element traversal.

Suppose that we want a recursive function to terminate when there is no data remaining to process. Using a stack data structure we can show that when the stack counter is 0, the property of the base case, then there is no recursive call.² Otherwise, by the induction hypothesis, the system incurs a recursive function call.

For example, we can trace the recursive execution of a function sum that computes the sum of numbers on the data stack. Consider the following definition of sum:

```
{ + GSC 1 > sum ? } sum WORD
```

where the addition operation is invoked if the number of values on a stack data structure is greater than 1, as determined by the evaluation of the stack counter, GSC, by the ? operator.

²The purpose of a stack is to have a collection of data storage that ensures that the first element added to the collection is the last element that can be removed (first in last out- FIL0). Stacks are covered in depth in chapter 16.6.
