# 18.3 PERMUTATIONS

A *permutation* is an arrangement of a set of n elements in a certain order. The permutation of a set's subset is called an *r-permutation*. The number *r* of subset elements will be less than or equal to the number of *superset* elements *n*, or *r ≤ n*. (A superset is a set that contains all the elements of a subset.)

Consider the inputs ABC. Below are all of the permutations of the inputs taken:

+   *all-at-a-time*: ABC, ACB, BAC, BCA, CBA, CAB

+   *two-at-a-time*: AB, AC, BA, BC, CA, CB

+   *one-at-a-time*: A, B, C (These are the same as the original inputs.)
