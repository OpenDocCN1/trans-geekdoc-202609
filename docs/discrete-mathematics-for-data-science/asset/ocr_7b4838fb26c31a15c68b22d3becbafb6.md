# ## Abstract

Being able to convert numbers from a one format to another often allows the data scientist to expedite analysis. This skill also lends insight into the tasks of distributing and storing data, as well as debugging programs.

Numbers can be represented in various ways using different bases, differing degrees of precision, or different symbols. Furthermore, numeric values can be normalized and standardized relative to a range of values. These are important considerations during the preprocessing stage of data analysis, after raw data is retrieved from a source and before statistical analysis takes place.

Changing a number's base representation should not be confused with changing its type. Base conversion does not change the value of the number, only the symbols that accord with another base.
