# 7.5.1 Inverse Relations

Given a relation R, the inverse relation R⁻¹, is:

```
R⁻¹ = { (b, a) | (a, b) ∈ R }
```

To find the inverse, we switch the order of each a and b. For example:

```
If R = { (1, 3) (2, 4) }, then R⁻¹ = { (3, 1) (4, 2) }
```

# 7.5.2 Identity Relations

In an identity relation, every element is related only to itself.

If A is a set, then the identity relation of A is the relation:

```
R = { (a, a) | a ∈ A }
```

For example, with A = { a b c }, we have relations R1 = { (a, a) (b, b) (c, c) } and R2 = { (a, a), (b, b), (c, c), (a, c) }.

R1 is an identity relation on A. However, R2 is not an identity relation on A since element a is related to c as well as a.
