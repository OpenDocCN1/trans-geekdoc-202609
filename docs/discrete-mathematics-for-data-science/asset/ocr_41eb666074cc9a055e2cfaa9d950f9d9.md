# 16.7 POSTFIX EXPRESSIONS

Operations using a stack are normally done in accordance with postfix notation. That is because operations are presented after the operands. Postfix is also referred to as *Reverse Polish Notation*, or RPN, a reverse of Polish mathematician Jan Łukasiewicz's prefix notation, otherwise known as *Polish Notation*.

Some computer languages are stack-oriented, such as Forth and Postscript, as are some hand-held calculators, such as the HP 32S-RPN Scientific. Postfix requires relatively less memory and CPU usage, as it does not entail the rules of precedence and parentheses () that are required by the more familiar infix notation, with its operator between the operands. Linear processing, from left to right (or from top to bottom) avoids the need to preprocess sections of an expression. Indeed, individual functions for the assembly language of CPUs are similarly linear, though commonly in prefixed order.

Postfix has this pattern, which conforms to a stack:

```
o_0 o_1 ... o_N f
```

where operands o_0 o_1 ...o_N are provided to the function f.

Because the stack is a First-In-First-Out (FILO) structure, the element on the top of the stack is o_N, and the bottom element on the stack is o_0, the first element that was entered.
