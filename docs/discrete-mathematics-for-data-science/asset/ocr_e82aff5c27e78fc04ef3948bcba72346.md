# 9.3 LANGUAGE SYMBOLS

The grammars comprising a metalanguage can be represented by symbols. For example, a common framework of grammars is symbolized as follows:

G = { N T S P }

Here N is the set of non-terminals, T is the set of terminals, S is an element of N and is the starting symbol for all strings, and P is the set of production rules.

Sets N and T are disjoint. That might seem incorrect considering that N derives from T. But, it is the symbol sets which matter in this context, not their derivation. To convince yourself, compile a program for a guest language that contains a word that is unique to the host language.
