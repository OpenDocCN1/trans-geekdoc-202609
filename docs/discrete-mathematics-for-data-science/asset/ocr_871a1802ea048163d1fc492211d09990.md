The next step is to process the instructions and data that was
put on the stack.

```
{ SWAP EXEC runit ? } runit WORD
GSC runit
9
8
7
...
```

Consider for example this recursive function that sums a list of
integers:

```
{ 1 3 5 7 9 } nums LIST
{ + GSC 1 > sum ? } sum WORD
nums sum ( → 25)
```

The following code uses that same sum function to generate a
mini program on the stack, emulating sum as it might appear in
memory:

```
0 nums DS2RS
{{ R > R > sum ' } GRC 2 / LREPEAT } build WORD
{ EXEC GSC 1 > runit ? } runit WORD
build runit finalsum !
```

Here is how that program appears on the stack:

| Value | index | address |
| :--- | :--- | :--- |
| sum | 8 | 82A668B00 |
| 9 | 7 | 82A668B80 |
