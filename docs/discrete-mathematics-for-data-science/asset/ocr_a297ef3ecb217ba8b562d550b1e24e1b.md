Overfitting occurs when input data is too complex for the model to distinguish from noise, which can be in part a consequence a highly dimensional data. The result of overfitting is poor outcomes for prediction and classification.

We know that when the number of predictors, \( P' \), exceeds the number of observations, \( N \), a linear regression model will exhibit dependence among its predictors. When \( P' > N \), there is no way to show that data is linearly independent. That is, we must have:

```
\( N > P \times T \times L \)
```

If this condition is not the case, then we should either increase the sample size for a greater \( N \) or reduce the dimensions for a smaller \( P' \).

If it is the case that \( P' < N \) and a regression model's predictors are linearly independent, then the regression model is considered *well-defined*. Of course, this does not guarantee that the model has predictive efficacy or value.

# 23.2 MULTICOLLINEARITY

When data sets are similar or redundant, we get a condition called *multicollinearity*. Multicollinearity occurs when data sets selected for their independence are, in fact, not independent of each other. That is, two or more dimensions of the data exhibit a dependent or linear relationship. This results when data sets are related with the same or nearly the same values, or when multiple data sets have excessive noise, much of which tends to be randomly the same.
