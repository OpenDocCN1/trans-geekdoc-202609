# EXERCISES

+   1. Define a recursive function \( S \) that increments a value by 1 from \( S_0 \) to \( S_3 \).

+   2. Give a recursive definition for the sequence \( \{ 0\ 1\ 2\ 5\ 11 \dots \} \) and show the computation of the next two numbers.

+   3. Give a recursive definition for the sequence \( \{ 3\ 5\ 9\ 17\ 33 \dots \} \) and show the computation of the next two numbers.

+   4. Give a recursive definition for the sequence \( \{ 1/2\ 1/4\ 1/8 \dots \} \) and show the computation of the next two numbers.

+   5. Give a recursive definition of the integers \( \mathbb{Z} \) and a base case of \( 0 \in \mathbb{Z} \).

+   6. In the set of real numbers \( \mathbb{R} \) and the set of integers \( \mathbb{Z} \), show now the function \( int(r - 1) \) can recursively compute the greatest integer less than the real number \( r \).

+   7. Provide a recursive algorithm to compute the following sequences:
+   
+   (a) 0 1 2 3 4 5 ...
+   (b) 0 0 1 1 2 2 ...
+   (c) 0 2 4 6 8 10 ...
+   (d) 0 1 2 4 8 16 ...

+   8. Explain the relationship between recursion and mathematical induction.
