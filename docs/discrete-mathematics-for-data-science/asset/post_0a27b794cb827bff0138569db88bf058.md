
Another example: Determine the number of *non-negative* integers that can be selected from among sets A OR B.

Set A: - 10 < a < 10
Set B: 15 < b < 30

In set A there are 10 non-negative integers less than 10 (including 0). In Set B, there are 14 non-negative integers between 15 and 30. Therefore, there are 10 + 14 or 24 non-negative integers that can be selected from among sets A OR B.

## *Product Rule:*

The product rule allows us to count the number of ways of completing a multi-step process, where A and B represent individual steps.

The product rule is stated as:

| A and B | = | A | · | B |

Similarly, given that there are n ways to select an element from one set followed by m ways to select an element from another set, then there are n × m ways to select one element from each set (for a total of two elements selected).

The product rule can be extended to selecting one element from each of more than two sets. For example, suppose that we have three sets, each containing integers. Set A has 4 elements, set B has 2 elements, and set C has 3 elements. The number of ways of selecting one element from each set is:

\( 4 \times 2 \times 3 = 24 \)

Another example: Given 5 elements in set A, 4 elements in set B, and 3 elements in set C, the possible number of element pairs (two elements from different sets) that can be selected is:

\( (5 \times 4) + (5 \times 3) + (4 \times 3) = 47 \)

## 18.2 FACTORIALS

A *factorial* is an abbreviated way of writing a special type of multiplication statement. A factorial of a whole number, n, is defined to be:

\( n! = n(n - 1)(n - 2) \ldots (1) \)

For example:

\( 5! = 5 \cdot 4 \cdot 3 \cdot 2 \cdot 1 \)

Note that \( n! = n(n - 1)! = n(n - 1)(n - 2)! \), and so on. So, \( 5! \) can be written as \( 5 \cdot 4! \) or as \( 5 \cdot 4 \cdot 3! \), for example. Note also that \( 0! \) is defined as 1.

Factorials come in handy for computing permutations and combinations, as we will soon see.

The factorial formula is implemented in *epop* code, as found in Appendix C.8.

1 Note that the ! symbol has different uses in various programming languages. In *epop* the ! symbol (having a space on both sides) is used for assigning values to variables. In C, Java, and the like, ! is a Boolean negation operator.

## 18.3 PERMUTATIONS

A *permutation* is an arrangement of a set of n elements in a certain order. The permutation of a set's subset is called an *r-permutation*. The number *r* of subset elements will be less than or equal to the number of *superset* elements *n*, or *r ≤ n*. (A superset is a set that contains all the elements of a subset.)

Consider the inputs ABC. Below are all of the permutations of the inputs taken:

- *all-at-a-time*: ABC, ACB, BAC, BCA, CBA, CAB

- *two-at-a-time*: AB, AC, BA, BC, CA, CB

- *one-at-a-time*: A, B, C (These are the same as the original inputs.)

If we had started with four inputs, ABCD, then *all-at-a-time* would include 24 permutations, including:

ACDB, DCBA, BDCA, ...

We could also generate permutations of its subsets, *three-at-a-time* and *two-at-a-time*.

The number of such set permutations, denoted as P(n, r) or nPr or P_{n,r}, is computed as:

P(n, r) = \frac{n!}{(n - r)!}

So, for ABC, the number of permutations of three letters is:

P(3, 3) = \frac{3!}{(3 - 3)!} = \frac{3 \times 2 \times 1}{1} = 6

The number of permutations of two letters is:

P(3, 2) = \frac{3!}{(3 - 2)!} = \frac{3 \times 2 \times 1}{1} = 6

The number of permutations of one letter is:

P(3, 1) = \frac{3!}{(3 - 1)!} = \frac{3 \times 2 \times 1}{2 \times 1} = 3

## 18.4 COMBINATIONS

Suppose we have a set containing 5 unique elements and we want to find the total number of possible subsets containing 2 elements. We say we are looking for the number of *combinations* of 5 elements taken 2 at time.

The symbol for a combination may be denoted either C(n,r), nCr, or C_{n,r}. Each of these symbols is read n choose r.

The nCr formula is implemented in epop code, as found in Appendix C.9.

In general, the number of subsets of size r that we can select from n elements (r ≤ n) is:

```
nCr = \frac{n!}{r!(n-r)!}
```

So, for 5C2 the computation is:

```
\frac{5!}{2!(5-2)!} = \frac{5!}{2! \cdot 3!} = \frac{5 \cdot 4 \cdot 3!}{2 \cdot 1 \cdot 3!} = \frac{5 \cdot 4}{2 \cdot 1} = 10
```

Or:

```
\frac{5 \times 4 \times 3 \times 2 \times 1}{2 \times 1 \times 3 \times 2 \times 1} = \frac{120}{12} = 10
```

If our design objective ignores element precedence or order, then we count combinations, not permutations. For example, for two distinct elements, we could simply have AB instead of AB and BA. For a set of three distinct elements, A, B, and C, we could have:

- *all-at-a-time, with order irrelevant: ABC*

- *two-at-a-time, with order irrelevant: AB, AC, BC*

To compute the number of distinct unordered subsets:

\( nCr = \frac{n!}{r! \times (n-r)!} \)

So, for all-at-a-time, the number of subsets of ABC, we have:

\( ^3C_3 = \frac{3!}{3! \times (3-3)!} = 1 \)

For two-at-a-time, the number of subsets of ABC, we have:

\( ^3C_2 = \frac{3!}{2! \times (3-2)!} = 3 \)

Starting with the larger set ABCD, and selecting three-at-a-time, the number of subsets is:

\( ^4C_3 = \frac{4!}{3! \times (4-3)!} = \frac{24}{6 \times 1} = 4 \)

The four subsets are: ABC ABD BCD CAD.

The number of combinations, C(n, r), is generally less than the number of permutations, P(n, r), because we are not counting the number of different ways we can arrange the r selected elements.

The number of combinations of n elements selected r-at-a-time is related to the number of permutations of n elements selected r-at-a-time as follows:

C(n, r) = \frac{P(n, r)}{r!}

Also,

P(n, r) = r! \times C(n, r)

For example, the number of permutations of inputs ABCD taken three-at-a-time is:

P(4, 3) = 3! \cdot C(4, 3) = \frac{3! \times 4!}{3!(4 - 3)!} = \frac{144}{6 \times 1} = 24

C(4, 3) is the number of subsets containing 3 letters and 3! is the number of distinct arrangements of each of those subsets.

## 18.5 MULTISETS

A multiset is a set containing duplicate elements. For example:

ABBC

To compute the number of permutations (arrangements) of a multiset, let:

- n = the number of elements, including duplicates.
- n1 = the count of the first element.
- n2 = the count of the second distinct element.
- :
- nr = the count of the last distinct element.

Then the following formula applies:

P(n : n_1, n_2, ... n_r) = \frac{n!}{n_1! \times n_2! \times n_3! ...}

For example, consider that a received signal is decoded into the ASCII character sequence HALIFAX. The parameters of this multiset are as follows.

The length of the set: n = 7

Letter counts:

- H: n1 = 1
- A: n2 = 2
- L: n3 = 1
- I: n4 = 1
- F: n5 = 1
- X: n6 = 1

The number of permutations is:

\frac{7!}{1! \times 2! \times 1! \times 1! \times 1! \times 1!} = \frac{5040}{2} = 2520

For another example, consider the number of possible ways that the bits of one byte can have exactly three zeros. The parameters of this 8-bit byte multiset are as follows.

The length of the set: n = 8

State counts:

- 0: n1 = 3
- 1: n2 = 5

The number of permutations is:

\(\frac{8!}{3! \times 5!} = \frac{40320}{6 \times 120} = 56\)

Another example: How many possible ways can bits of an 8-bit byte have more 1s than 0s?

If there are more 1s than 0s, then our bit set contains either five, six, seven, or eight 1s. Therefore, the solution is found by adding the permutations of four multi-sets.

Alternatively, we can think of this as a combination problem, where we are choosing a fixed number places (a subset of places) which will hold 1s. In terms of combinations, the computation is:

C(8, 8) + C(8, 7) + C(8, 6) + C(8, 5) = 1 + 8 + 28 + 56 = 93
