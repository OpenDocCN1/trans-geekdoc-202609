# 14.2.1 Element Access

Element access depends on the *connectedness* of the data collection.

With connected collections, sequential elements may be traversed until arriving at a particular index or value.

With unconnected collections, there is no structure to traverse and no permanent index. Therefore, element access requires random selection until arriving at a particular value, or until the collection is empty.

# 14.3 COLLECTION OPERATIONS

The various types of collections have both distinct and common operations.

Common collection operations with respect to single elements include counting, inserting, removing, replacing, searching, and retrieval.

Common operations that entail entire collections include copying and comparing two collections, as well as sorting connected collections.

Each of these operations have an *algorithmic efficiency*, depending on the specific implementation of the algorithm for the operation.
