As you already know, our common decimal number system sequences its digits in powers of 10. That is, each successive place value is 10 times the place value to its right. For example, the number 10,236 is represented by 6 ones, 3 tens, 2 hundreds, zero thousands, and 1 ten-thousand.

Accordingly, we can explicitly express each positional digit of a number in so called columnar notation or positional notation using the following correspondence:

| base^4 | base^3 | base^2 | base^1 | base^0 |
|---|---|---|---|---|
| digit_4 | digit_3 | digit_2 | digit_1 | digit_0 |

Note that each digit in the lower row is a symbol in the base number system. For example, for base 2 the symbols are 0 and 1. Therefore, these binary digits will be 0 or 1.

Number systems that rely on a base of a certain number of symbols are implementations of a positional number system. At each position a different magnitude of exponentiation determines a digit's value. These contrast with non-positional numbering systems such as Roman numerals and scored tallies.1

For the number 10,236 in base 10, we have this positional correspondence:

| 10^4 | 10^3 | 10^2 | 10^1 | 10^0 |
|---|---|---|---|---|
| 1 | 0 | 2 | 3 | 6 |
