To represent a complete binary tree with a list, the following indexing is common, with the root node at the top of the tree, as with level-order indexing:

+   * Parent of node at i: $(i - 1)/2$.
+   * Left child of i node: $2i + 1$.
+   * Right child of i node: $2i + 2$.

This indexing is shown for a six node binary tree in Table 17.1.
