I = -log_2(8/64) = 3

The result of 3 is the exponent to which the base 2 must be raised to obtain
the reciprocal of 8 / 64. That is 2^3 = 8.

For multiple symbols comprising a message we use a weighted average
entropy, denoted as:

H = - \sum_{i=1}^{n} P_i log_2 P_i

The probabilities now serve as the relative weights of the symbols. _P_i is the
probability of any one symbol and the overall Shannon Information is the
sum of those probabilities. Consider the simple message AAAABBBBBB. The
message has ten characters, with four As making up 40% of the total and six
Bs accounting for 60%. The computation for Shannon information is thus:

H = -(0.40 \times log_2 0.40 + 0.6 \times log_2 0.6) = 0.971

# 22.4 SYMBOL PROBABILITIES

With a set of symbols in a message, the entropy calculation can be broken
down as:

+   - Number of elements, N.
+   - Symbols, S, indexed from 1 to N.
+   - Probability of each symbol, _P_i = (|{_S_i ∈ _S}|)/N
+   - Message entropy, _H_ = - \sum_{i=1}^n _P_i log_2 _P_i

Consider a list of symbols, such as the number list { 1 3 5 7 }. Since each of
the four numbers is unique, the probability of randomly drawing any one of
them is 1/4, or 0.25. The Shannon Information may be computed as follows:

_H_ = -(0.25 \times log_2 0.25 + 0.25 \times log_2 0.25 + 0.25 \times log_2 0.25 + 0.25 \times log_2 0.25)
= 2

In Information Theory we are interested in Shannon entropy given a set of
symbols in any order. Unless a symbol sequence is designated as another
symbol, whether data contains either a meaningful or a random sequence is
not considered relevant.
