
Finally, discard the implicit leading bit of the mantissa to convert the number back into the binary32 fraction:

| sign | exponent | fraction (ignoring the implicit leading bit) |
|---|---|---|
| 0 | 10000001 | 000 0001 0000 0000 0000 0000 |

## 5.14 DIVISION WITH IEEE 754 FLOATING POINT NUMBERS

Division with IEEE 754 floating point numbers can be done by hand by dividing the fractions and then subtracting the exponents. Division is done by right shifts, denoted as >>, and subtraction.

For example, to compute C = A/B:

C = 1^signA×1×(fractionA×2^exponentA) / -1^signB×1×fractionB×2^exponentB

C = -1^signC×1×(fractionA / fractionB) × 2^exponentA-exponentB

where:

signC = signA XOR signB

and:

fractionC = fractionA / fractionB

That is a right shift of fractionA by the amount of fractionB:

(fractionB - 1) >> fractionA

The resulting exponent is:

exponentC = (exponentA - exponentB) + bias

There are some caveats, however. Consider:

- If B = 0, then set C = infinity.
- If A = 0 AND B = 0, then set C = NaN ..."Not a Number."
- If C > maximum number size, then set C = infinity.
- If C < minimum number size, then set C = 0.
- There could be overflow or underflow.

## Propositional Logic

DOI: 10.1201/9781032687759-6

### Abstract

Propositional logic is integral to the data scientist's work with automated systems of analysis, including artificial intelligence, expert systems, and application development in general. In these endeavours, it is important to convey task objectives in unambiguous logical terms, be it for architecting data flows or generating statistical reports for business decisions.

A proposition is simply a statement or expression which asserts that something is true or false. The assertion may require certain conditions be met and, because mathematical symbols may be used, propositional logic may be referred to as mathematical logic or symbolic logic.

The concepts of propositional logic are applicable to set logic when the predicates are replaced with sets. Therefore, to understand propositional logic with respect to data sets, relationships between data sets must be defined.

Applications of logic exist throughout machine architectures and program algorithms, with logical statements comprising function conditions and their *arguments* (or *parameters*).

### 6.1 PROPOSITION

A proposition is a statement that is either true or false. It cannot be both. Symbolically, true may be denoted as 1 or T and false may be denoted as 0 or F. As we will soon see, we can represent a proposition in a function form with variables, in the form of a truth table.

We can represent a proposition as a statement in a postfix functional form as:

```
15 5 10 + EQ (→ true)
10 5 4 + EQ (→ false)
```

A proposition may be a simple statement that is true or false, without depending on a predicate. Or, the proposition may be *predicated* upon some variable. A predicate is an expression or instance of a variable or symbol, that can be replaced by values. The predicates of a proposition are said to have *propositional form*.

For example, consider the statement “Goats are quadrupeds.” This statement is a proposition, as it can be evaluated as true or false. Additionally, the statement contains a predicate, “quadrupeds,” which is variable, as there many types of quadrupeds.

“The sky is sunny.” is a proposition in which “sky” is variable. In *predicate logic*, the variability of that entire statement is variable, making it also a predicate. Therefore, the statement is both a proposition and a predicate.

Symbols are often used in propositional logic to denote predicates, such as q, p, r, and s. The proposition, itself, may also be symbolized.

For example, letting 0 represent false and 1 represent true, define the following predicate variables:

```
{ 1 } a WORD
{ 1 } b WORD
{ 0 } c WORD
```

These variables can now be evaluated using logic operators, such as:

```
a b c AND AND ( → 1)
```

What that statement does is first compare the truth value of predicates a and b. The result is, itself, a truth value that is then compared with the truth value of c. In your traditional infix notation, the logic can be given as:

```
(a AND b) AND c ( → 1)
```

The logic of the postfix statement can be negated as follows:

```
a b c AND AND NOT ( → 1)
```

The result of an evaluated expression can also be assigned to a variable or function, such as the word “result,” as shown here:

```
{ a b c OR OR } result WORD
```

A proposition is entirely true or false, not both. That means that all of its predicates must have known values. For example:

...is a proposition and it is evidently true.

A statement which is not declarative is not a proposition.
Consider:

*Hello World!*
*What time is it?*

These are not propositions because they cannot be evaluated as true or false.

A single proposition outside the context of prior propositions can only be accepted as true, as there is no prior contradicting proposition. That a proposition contradicts your *a priori knowledge* does not make it false unless its logic includes a prior contradictory assertion.

For example, there may be the statement:

*The sky is dark.*

We may disagree with that statement. But, our disagreement would depend on reasoning that is outside of this isolated logic, our *a priori knowledge*.

To make this concept less counter-intuitive, replace the predicates in the statement in question with symbols, such as s for sky and d for dark, as follows:

*s is d*

Mathematically equivalent statements may be accepted as:

s ≡ d or s = d

Or, in postfix notation:

s d EQ

Here we say that s and d are equivalent.

One may have other knowledge of the words of a proposition, outside of a given context. Ignore those presumptions, as we must assume the machine only has what we give it. Substituting words with symbols helps with this process.

### 6.2 SYLLOGISMS

A syllogism is a proposition that depends on an earlier proposition. In other words, a syllogism is premised on a proposition that is assumed to be true. That leading proposition is called a premise. A syllogism may alternatively be referred to as an implication, as one proposition (the premise) implicates another.

A syllogism may be denoted as if...then or as p → q.

Here is an example syllogism:

> *If goats are quadrupeds, and Daisy is a goat, then Daisy is a quadruped.*

The premises in the above syllogism are goats are quadrupeds and Daisy is a goat. The conclusion is Daisy is a quadruped. The syllogism's predicates are:

...are quadrupeds
...is a goat
...is a quadruped

### 6.3 PROPOSITIONAL CONDITIONS

Propositional statements may be connected by logical operators. In order of precedence, these include:²

| Word | Symbol |
| :--- | :--- |
| NOT | ¬ |
| AND | ∧ |
| OR | ∨ |
| IF THEN | → |

¹ In mathematics, the ≡ symbol is used to denote the equivalent cardinalities of two sets, whereas logical equivalence is often symbolized by = or ≡. In contrast, in computer programming languages, the common symbol for logical equivalence is ==, whereas the = symbol is generally used for variable assignment. ↩

² These logic operators differ among programming languages. For example, in C we use the ` hat symbol for XOR and the | bar symbol for OR. The symbols for not or negation may be a tilde ~ in some programming languages (Standard ML) or an exclamation mark ! in others, including C/C++, D, Java, and Python. ↩

A NOT operation, symbolized by ¬, allows us to negate a proposition, giving us its complement. For example, the complement ¬1 = 0, and the complement of a symbol ¬A = a.
