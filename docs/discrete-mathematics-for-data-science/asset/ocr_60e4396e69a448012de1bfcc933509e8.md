However, if the solution is known, should the probabilistic state be 1? “Is a problem solvable merely because we have the solution?” This poses the infamous and seemingly paradoxical question of computability:

# $P = NP?$

It is sometimes practical to seek a probabilistic solution using a less complex model, incrementally reducing the number of variables (data dimensions), sample rates, and records, or by settling for less prediction accuracy. The implementation of relaxed models as such translate into shorter processing time.

Problems can be shown to be NP-complete (solvable) using *transitive polynomial time reduction*, breaking problems down into smaller solvable sub-problems. Given problem $A$ consisting of $a_1$, ..., $a_n$ sub problems, $A = P$ if for all $a$, including the worst case $a$. Thus, the solution entails a transitive relation between sub problem $a_1$ and sub problem $a_n$.

A metaphor for transitive polynomial time reduction is “the weakest link in the chain,” referring to the idea that the efficacy of a solution depends on its weakest component, which in this case would be the worst performing sub algorithm of a solution.
