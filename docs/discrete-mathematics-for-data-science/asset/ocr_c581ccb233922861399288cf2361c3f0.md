For values of $n$ from 0 to 50, we can see the expansion of $n$ for several growth rate functions.

As can been seen in Figure 13.1, an $O(n)$ algorithm expands linearly while an $O(2^n)$ expands exponentially. In contrast, an $O(1)$ algorithm is constant, showing no expansion. Note that the lines representing $O(1)$ and $O(log(n))$ look almost indistinguishable for an $n$ of 50. The graph in Figure 13.1 clearly shows that some algorithms perform faster than others.
