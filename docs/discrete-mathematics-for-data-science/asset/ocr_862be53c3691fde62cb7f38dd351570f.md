Incidentally, if the characters of HELO were given in binary, then we would need to expand the states to include the each sub pattern of bits, similar to the character states in HELO above. Because each character has seven bits, this would entail seven states per character. For example, H is 72 in Unicode decimal, or 1001000 in binary.
