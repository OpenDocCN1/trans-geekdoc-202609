# 4.1.1 The Power Method

Related to the aforementioned columnar notation is a base conversion technique called the _power method_. It selects the column having the largest number that will fit into the _most significant_ (leftmost) digit of the number that we wish to convert, and then the next one, etc. This is also referred to as _Horner's Method_ or _Horner's rule_.

We can apply Horner's Rule to convert a number of any base to decimal. The general form of computation is:

\(\sum S_n \times base^n\)

Where _S_ represents a set of the numerical symbols used in a particular base number system. _S<sub>n</sub>_ is one of those symbols.

A sequence of magnitudes will have the following polynomial pattern:

\(a_n x^n + a_{n-1} x^{n-1} + \dots + a_2 x^2 + a_1 x^1 + a_0 x^0\)

Here is an example that uses the power method to convert 0d84 to binary.

+   1. Create a sequence in magnitudes of base 2.
+   128 64 32 16 8 4 2 1
+   
+   2. Assign a 1 under the largest number ≤ 0d84.
+   128 64 32 16 8 4 2 1
+   0   1
+   
+   3. Find the difference of 84 and 64, or 20.
+   4. Repeat step 2 for 0d20.
+   5. Repeat while differences > 0.
+   6. Put a 1 under the 16, as 16 is the largest number less than 20.
