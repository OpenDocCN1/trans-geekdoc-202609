If a function can either take another function as an argument, or return a function as a result, then a function is known as a *higher order function*. Otherwise, a function is referred to as a *first order function*.

Higher order functions may be referred to as *combinators*, although there is some argument that the parameter (guest) functions must actually be *lambda expressions*, which are nameless functions consisting only of a function body. A lambda expression is a nameless function containing functions and/or data. A lambda expression may formally be referred to as a combinator if it has no external dependencies.

Lambdas provide a means to statically enclose parameters from a nameless guest function so that they persist after being returned to an outside host function.⁵ These parameters are bound in the scope of the guest function.
