# 8.9 RECURSION & PROOF BY INDUCTION

The inductive hypothesis postulates that a structure exists because, by inductive observation of the next object of a structure, the structure as a whole is observed. Through induction we can prove assertions in the form ∀x,P(x), or that some property or formula holds for all elements of a set. Because the observation can be recursively induced, proof by induction is effectively proof by recursion.

Proof by induction will have a base case and an inductive case with respect to elements of a universal set. The base case establishes that P(x) is true for at least one element x in the universal set S. The inductive case establishes that if P(x) is true for an element i, so that P(i) is true, then P(i+1) is also true. In other words, if P(x) is true for any specific element, then P(x) is true for the next element as well.

A true state for the base case can indicate that the system has met some limit, such as an index value at a designated maximum or minimum, the remaining number of elements in a set, including an empty set, or some other threshold.

When the system begins at a maximum value and ends at a minimum value, it may be referred to as reverse induction. The inductive case for reverse induction may be denoted P(i-1). Conversely, when the system begins at a minimum value and ends at a maximum value, it may be referred to as forward induction. The inductive case for forward induction may be denoted P(i+1).
