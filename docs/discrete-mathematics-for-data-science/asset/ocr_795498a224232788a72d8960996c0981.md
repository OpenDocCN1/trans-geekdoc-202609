4 elements, set B has 2 elements, and set C has 3 elements. The number of ways of selecting one element from each set is:

\( 4 \times 2 \times 3 = 24 \)

Another example: Given 5 elements in set A, 4 elements in set B, and 3 elements in set C, the possible number of element pairs (two elements from different sets) that can be selected is:

\( (5 \times 4) + (5 \times 3) + (4 \times 3) = 47 \)

# 18.2 FACTORIALS

A *factorial* is an abbreviated way of writing a special type of multiplication statement. A factorial of a whole number, n, is defined to be:

\( n! = n(n - 1)(n - 2) \ldots (1) \)

For example:

\( 5! = 5 \cdot 4 \cdot 3 \cdot 2 \cdot 1 \)

Note that \( n! = n(n - 1)! = n(n - 1)(n - 2)! \), and so on. So, \( 5! \) can be written as \( 5 \cdot 4! \) or as \( 5 \cdot 4 \cdot 3! \), for example. Note also that \( 0! \) is defined as 1.

Factorials come in handy for computing permutations and combinations, as we will soon see.
