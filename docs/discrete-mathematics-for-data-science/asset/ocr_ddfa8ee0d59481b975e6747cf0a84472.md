Claude Shannon, a pioneer of Information Theory, realized that more information does not necessarily equate to useful information. Rather, it is the amount of information of known symbols relative to noise that matters. In that respect, Information Theory seeks to minimize the amount of data required to convey a message.

In his paper, *A Mathematical Theory of Communication*, Shannon coined the term *bit* for *binary digit* as a fundamental unit of information.³ A bit can be in one of two states, symbolized 0 or 1. Having just two states, the bit accords with the base 2 numbering system.

Shannon determined the minimum number of binary digits required to store a symbol for reliable communication. Shannon termed this number *entropy*.

Entropy is based on the probability of a symbol in a message. Redundant symbols do not affect the results as long as each symbol has the same redundancy. It may be the case that the sender sends duplicate symbols to ensure their receipt.

Consider a set of symbols such as the characters of the alphabet. Suppose that message transmission is done at a rate of five symbols per second. The possible number of character combinations per second is 26⁵. Assuming each character is equally likely, the probability of drawing any one character is 1/26 .

The calculation for entropy, as shown below, includes converting 26⁵ into binary terms (Shannon's symbol set was { 0 1 }). Shannon symbolized the entropy of a message with the letter *H*.

```
26⁵ = 2ˣ
log₁₀26⁵ = log₁₀2ˣ
5 × log₁₀26 = x × log₁₀2
x = 5 × log₁₀26 / log₁₀2
x = 5 × 1.41497334797082 / 0.301029995663981
H = 23.5021985907055
```
