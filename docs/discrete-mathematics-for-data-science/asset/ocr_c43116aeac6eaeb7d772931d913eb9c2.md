curry(f(a, b, c)) → f(a)(b)(c)

In practice, currying may be implemented by replacing the multi-argument function with a series of single argument nested functions, such as:

curry(f(a, b, c)) → f2(f1(f0(a)))

The right side is the composition of three functions where:

b = f0(a)
c = f1(b)
result = f2(c)

One interest in currying is the enforcement of a data flow model of computation.10 In the data flow context, single argument functions may be connected by data pipes in some programming environments. For example:

curry(f(a, b, c)) → f0(a) | f1(b) | f2(c)
