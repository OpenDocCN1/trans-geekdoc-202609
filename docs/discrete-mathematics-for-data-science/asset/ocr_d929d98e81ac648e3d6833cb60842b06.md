# 9.5 PUSH DOWN AUTOMATON

A _push down automaton_ (PDA) is a type of finite state machine, but with memory in the form of a stack.<sup>12</sup> The stack gives memory to context-free grammars and affords the use of postfix instead of infix operations of arithmetic. A requirement such as a _subject-object-verb_ like pattern of postfix notation would be part of the grammar of a PDA. A language that combines a stack with postfix arithmetic further affords ignoring contexts of operator precedence, as would otherwise be required for infix arithmetic.<sup>13</sup> As with non-deterministic finite automata, program sequence and output varies based on input.

The components of PDA include:

+   • Input tape (stored program)
+   • Control unit (interpret program for dispatch to stack)
+   • Stack (unlimited size)

The flow between these entities is:

```
tape → control ↔ stack
```

The stack's two essential operations:

+   • push - put a symbol on the top of the stack.
+   • pop - remove the symbol on the top of the stack.

A _push_ first requires a symbol operand that will be pushed. _pop_ requires no inputs and may be followed by other operations that use the popped symbol or value.
