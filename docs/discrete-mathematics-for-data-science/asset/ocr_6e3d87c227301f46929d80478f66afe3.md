# De Morgan's Laws:

\neg(p \land q) \equiv \neg p \lor \neg q
\neg(p \lor q) \equiv \neg p \land \neg q

Suppose that we have the following expression in which upper case characters represent true statements (1s), lower case characters represent complements (0s), OR operations are treated as addition, and AND operations are treated as multiplication.

abc + Abc + AbC

This can be reduced as follows:

abc + Abc + Abc + AbC   (Idempotency identity applied to Abc.)
bc(a + A) + Ab(c + C)   (Distributive identity.)
bc(1) + Ab(1)           (Each 0+1=1.)
bc + Ab
bc + bA                 (Commutative identity.)
b(c + A)                (Distributive identity.)

# 6.6 TIPS FOR EQUATION MINIMIZATION

A compound proposition that is always true, regardless of component statements that are true, is a tautology (a statement that is always true). Each row in the proposition's column of a truth table is true (1) if it is a tautology.
