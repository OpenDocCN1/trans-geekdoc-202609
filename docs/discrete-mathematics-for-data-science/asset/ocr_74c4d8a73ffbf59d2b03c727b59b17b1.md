| | 2⁻¹ | 2⁻² | 2⁻³ | 2⁻⁴ |
|---|---|---|---|---|
| | 0.5000 | 0.2500 | 0.1250 | 0.0625 |
| 0.000 ≥ 0.0625? | | | | 0 |

Hence, 3.625 decimal is 0011.1010 in fixed point binary consisting of two distinct 4-bit registers.
