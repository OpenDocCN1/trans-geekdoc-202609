| Symbol | Classification | Example | Explanation |
| :--- | :--- | :--- | :--- |
| ℤ | Integer | ℤ = ..., -2, -1, 0, 1, 2, ... | Positive and negative whole numbers. |
| ℤ+ | Positive integer | ℤ+ = 1, 2, 3, 4, ... | The same as the set of natural numbers. |
| ℤ– | Negative integer | ℤ– = ..., -4, -3, -2, -1 | Opposite of natural numbers. |
| ℚ | Rational number | -3/2, -1/3, 2/3, 3/5 | Ratio of integer to non-zero integer. |
| ...Terminating decimal | | 10/4, 2.5 | Finite sequence of digits after decimal point. |
| ...Repeating decimal | | 2/7, 3.333... | Infinite sequence of repeating digits. |
| ℑ | Irrational number | e, π, √2 | Infinite sequence of non-repeating digits. |
| ℝ | Real number | 2, 3.45, -1/9, π, √2 | Rational and irrational numbers combined. |
| | Purely imaginary | 8i, where i = √–1 | Product of a real number and i. |
