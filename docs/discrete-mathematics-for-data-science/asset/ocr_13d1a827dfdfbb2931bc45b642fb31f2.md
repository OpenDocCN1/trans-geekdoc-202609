```
{ 1 + } guest WORD
{ || EXEC } host WORD
3 guest | host ( → 4)
```

In the above example, the integer 1 is bound to a variable in the scope of the guest function, whereas the integer 3 is not, as it is represented by a free variable.

An abstract function is the synthesis of other functions, be they also abstract or primitive functions that are not reducible to other functions, such as CPU instructions. This is graphically illustrated in Figure 9.1. The abstract function describes _what_ is to be done and its composition of primitive functions describes _how_ something is done. Directly or indirectly, program functions will rely on at least one primitive function.<sup>6</sup>

The reduction of abstract functions to their primitive components relates to the concept of an _abstract syntax tree_.

As multisets, the set of a machine's primitive symbols _P_ and a programming language _D<sub>L</sub>_ are related as:

$$D_L \subseteq (P \cup D_L)$$

This treatment of abstract functions somewhat differs from that used in _object oriented programming_, such as with the Java programming language, which defines abstract functions as a basis (the _what_) that must be modified in a way that makes it usable (the _how_).
