```
{ 5 } h WORD
{ 7 } w WORD
{ h w } shape WORD
{ * } area WORD
{ shape area } rectangle_area WORD
rectangle_area ( → 35)
```

As you may have deduced, abstraction as such can include not only abstract data, but other words in the context of what is referred to as *higher order functions*, as already mentioned.

Consider the word *average* as a user defined function to compute an average in terms of a user defined list of numbers *list*, an operation for the sum of those numbers, a count of those numbers given by *n*, and a division operation given by /.

```
{ 2 3 5 } list LIST
{ list sum n / } average WORD
```

These components are abstractions for operations internal to computing an average. Their treatment here is both as data and as functions, indicating that these words are higher order functions.

The length of *list*, *n* can be defined as:

```
{ list ' LEN } n WORD
```
