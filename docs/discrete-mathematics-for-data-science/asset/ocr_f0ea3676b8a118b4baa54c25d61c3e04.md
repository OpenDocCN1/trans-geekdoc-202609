If we want to prove that all elements of a set X have a certain property called P(x), then we are trying to prove ∀x ∈ X, P(x). Our general strategy would be as follows:

Suppose x is any element of X.
Use definitions or theorems to show that for each x, P(x) is true.
Therefore: ∀x ∈ X, P(x).

_Proof of existence_ – prove that at least one element exists in a particular set or has a particular property. We want to prove
∃x ∈ X | P(x).

We can take a _constructive_ approach by actually finding an element, or elements, with the particular property. We must, of course,
explain how we know that the elements(s) is/are of the specified type.

We can alternatively take a _non-constructive_ approach, and possibly conclude an element that makes P(x) true must exist, without
specifying any elements that make P(x) true. This strategy involves
proof by contradiction and begins as follows:

To prove: ∃x ∈ X | P(x) :
Assume ∀x ∈ X, ¬P(x).

We assume the opposite of what we are trying to prove. If by using
our assumption we can somehow arrive at a contradiction, then we
can conclude that ∃x ∈ X | P(x) by contradiction.
