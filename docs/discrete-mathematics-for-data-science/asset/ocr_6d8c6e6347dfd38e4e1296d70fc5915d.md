Consider the two statements:

> All cats are black.
> Chewy is a gray cat.

Obviously, this is a contradiction. It cannot be true that all cats are black, because at least one non-black cat exists. Each predicate is an element of a set that is effectively symbolized by its containing proposition. Consider a set where the elements are separate statements, each of which is either true (1) or false (0).

$S = \{ 1010 \}$

The combined statements may be evaluated as:

$S = \{ 1 \land 0 \land 1 \land 0 \} = \{ 0 \}$

Each \(\land\) operation above is a binary operation, taking two operands. In the programming example, the multiplication operator * suffices for \(\land\), the logical *and* operator.

Applying such a binary operation to the element pairs of two or more sets allows us to affect a *binary relation* on a set.
