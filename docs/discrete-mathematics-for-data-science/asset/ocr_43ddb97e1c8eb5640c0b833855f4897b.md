Hexadecimal is useful for viewing large numbers in a smaller space. Contrast that to binary, which entails long strings of 1s and 0s. Given that hexadecimal accommodates decimal digits 0 through 15, we use A B C D E F for the six digits 10 through 15. The decimal number 16 is 10 in hexadecimal, or 0x10.

Figure 3.3 shows a Unix tool called hexdump which displays values in hexadecimal form. By using hexadecimal, the memory representation of a binary file or program can be displayed more compactly. In this case, the hex digit pairs are program data. Each digit represents 16 bits or two bytes of data. Memory addresses are in the first column, also in hexadecimal.
