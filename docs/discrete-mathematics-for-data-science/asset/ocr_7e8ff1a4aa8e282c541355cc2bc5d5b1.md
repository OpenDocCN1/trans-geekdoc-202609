| Category | Mean | Weight |
|---|---|---|
| (E)xams | 75% | 50% |
| (Q)uizzes | 88% | 30% |
| (L)abs | 80% | 20% |

The weighted average percent score for the course grade is then computed as:

```
scores_wtd = E_mean · E_weight + Q_mean · Q_weight + L_mean · L_weight
```

```
scores_wtd = 75% · 0.5 + 88% · 0.3 + 80% · 0.2
= 37.5% + 26.4% + 16% = 79.9%
```

epop programs for computing various measures of dispersion can be found in Appendices C.16, C.17, and C.18.
