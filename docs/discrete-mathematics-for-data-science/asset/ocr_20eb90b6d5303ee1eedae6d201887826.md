for two pairs of the form \((x, y)\) and \((y, z)\) in \(R\), \((x, z)\) is also in the relation \(R\). For example, if \((5, 1) \in R\) and \((1, 8) \in R\), then \((5, 8)\) must be in \(R\) also.

# 7.5.6 Equality & Equivalence in Set Relations

Recall that sets are called *equivalent* if they have the same number of elements. Equivalence between two sets is strictly a matter of cardinality.<sup>5</sup> Two sets are called *equal* if all of their elements are exactly the same. While equal sets are equivalent, equivalent sets may not be equal.

An *equivalence relation* is a relation that is reflexive, symmetric, and transitive.

# *Examples of equivalence relations:*

```
R = { (1, 1) (2, 3) (3, 3) } (An *identity relation*.)
```

```
R = { (1, 1) (2, 3) (3, 3) (2, 3) (3, 2) }
```

Note that in each of the above relations, those pairs having equal elements are transitive. This is sometimes referred to as *vacuous transitivity*, as there are no other elements to contradict the transitive property.

For example, the pair (1, 1) is a transitive relation to itself. We can see this transitive relation in \((a, b) \in R \text{ and } (b, c) \in R\), when \(a = 1\), \(b = 1\), and \(c = 1\). Thus, by definition of transitive relation, the equal pair (1, 1) is a transitive relation.

```
R = \{(x, y)| x, y \in \mathbb{Z} \text{ and } |x| = |y|\}
```
