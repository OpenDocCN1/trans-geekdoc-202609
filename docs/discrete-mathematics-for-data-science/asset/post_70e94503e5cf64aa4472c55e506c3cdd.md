
Polish notation is a prefix style of logical notation that is generally considered to be the invention of Polish philosopher Jan Lukasiewicz, in 1924.

To duplicate a value, use DUP as a postfix operation:

```
5 DUP
```

The result is a sequence: 5 5.

To compute the average of two numbers, 3 and 5, and add 1 to the result:

```
3 5 + 2 / 1 + . CR
```

The “.” operator pops the value from the top of the stack, displaying the computed result of 5. The CR operation is a carriage return, used here to put an extra line between the result and any subsequent output, such as the terminal prompt.

## A.4 FUNCTION DEFINITIONS

We define functions as we would define words. Like the definition of a word in the English dictionary, the definition of a code word consists of other words that are elsewhere defined. Word definitions can be short or extensive. Of course, long word definitions are difficult to remember. Instead of one long complex word definition, it is preferable to have a sequence of word definitions that are short and relatively simple.

A colon ":" begins the definition in a prefix manner and a semi-colon ";" ends the definition. For example, define a word called *double* as:

```
: double DUP +;
```

Here the definition of the word double consists of:

```
DUP +
```

That is the sequence of a duplication operation followed by an addition operation. For example:

```
7 double
```

The result is 14.

## A.5 DATA

The word .S is used to display data that is readily available in a location called the *data stack*.

Data is processed on a stack, in a First In Last Out (FILO) manner. Consider the postfix expression:

```
2 45 +
```

The result of 9 is put back onto the stack. Thus, the available data is now:

```
29
```

Words may also be defined as data. That way, the word can serve as a variable that is associated with a value or as a list of many values. For example, we may define a word "five" as:

```
:five 5;
```

To define a named list of numbers:

```
: evens 2 4 6 8;
```

To express those even numbers, invoke the word evens, simply as:

```
evens
```

The result on the stack, as seen by entering .S, is 2 4 6 8.

To compute the sum of evens, we can use the REPEAT word to apply the + operation 4 times:

```
evens
4 + ' REPEAT
```

The result is 20. The tick ' mark after the addition + symbol delegates the addition operation to the REPEAT function. Otherwise, there would be just a single addition operation.

Compound words can be defined using words that were previously defined. For example:

```
: quadruple double double;
5 quadruple
```

The result is 20.

Incidentally, the above double and quadruple words can be alternatively defined using this entirely postfix approach:

```
{ DUP + } double WORD
{ double double } quadruple WORD
```

The curly braces used in such definitions represent sets of words that comprise the definitions of new words. In this case, the new words are *double* and *quadruple*.

## B.1 EPOP'S GENERAL SYNTAX

These are the general rules for programming in epop. Individual words have their own rules, as documented below.

epop syntax is run either at the epop> prompt or in a stand-alone epop program file using the RUN word. To invoke epop from the command-line, just enter: epop. That will start epop and display its prompt as:

```
epop>
```

Words and data can be entered at the prompt. Entries must be separated by at least one space, such as:

```
epop> 6 8 SWAP SQUARE . CR
epop> 36
```

If a word entry is recognized, it is interpreted accordingly. Otherwise, the entry is designated as data and pushed onto the data stack as a number or string (one or more characters strung together that may form a word).

## B.2 DATA CONTAINERS

epop's three data stacks are called: data stack, return stack and temporary stack. These stacks accommodate the following data types: strings (a sequence of characters), floating point numbers (numbers having decimal places), tables, and executable words. Integers are treated as floating point numbers by default.

If a word (function) requires data, then data must already exist on the data stack for the word to execute without error.

Apart from the data stacks, data can be stored in table objects or in SQL database tables. Both of these types of tables are designed with three columns to quickly facilitate simultaneous data transfer to and from the three data stacks. Accordingly, SQL queries having more than three columns of output are limited to three columns when the output is directed back to the three stacks.

## B.3 POSTFIX

Words that process data operate in postfix mode, such as:

```
`operand1 operand2 operation`
```

Or:

```
`data data word`
```

Data can be the output of a preceding word and a word in this series may, itself, produce data for the next word. In this way words may be used as arguments for subsequently postfixed words.

## B.4 WORDS AS ARGUMENTS

The arguments for a word can have the following form:

- Numbers, characters, strings, functions (words).
- Self-reference (recursion): A word that refers to itself.
- Tick word: A word stored as data on the data stack.
- Lambda expression: A nameless function containing functional words and/or data.
- Captured word: A word inside the { scope } or definition of another word.
- Pipe: Bypass the data stack with one word's output being the next word's input. The output could be a value or a word as well.

These argument forms will be explained through the remainder of this section.

Words may be used as arguments for other words, as needed for the purposes of branching, repetition, etc. For example, repetition can be induced by having a word refer to itself (aka *recursion*), such as:

```
{ + DUP 10 < sum ? } sum WORD
```

Words that are defined recursively should usually make the self-reference conditional (the above example is conditional on sum < 10). Otherwise, to use a recursive word unconditionally without errors, it must be predefined, such as:

```
{ } sum WORD
{ + sum DUP 10 < sum ? } sum WORD
```

Instead of recursion, the LREPEAT word can be used for repetition. LREPEAT repeats an expression inside of { } braces. The following code will repeat an operation of addition ten times:

```
{ + } 10 LREPEAT
```

Alternatively, REPEAT can be used such as:

```
+ ' 10 REPEAT
```

Instead of recursion, the REPEAT word can be used for repetition. For example, the following code will repeat an operation of addition ten times:

```
+ ' 10 REPEAT
```

The tick mark after the + sign ensures the operation of addition is not immediately invoked, but is instead delegated to a subsequent word for whatever the purpose of the subsequent word. In this case, the + operation is an argument of REPEAT, which repeats + 10 times.

For some words it is not necessary to follow the argument with a tick. Such words are referred to as inline words. For example, the inline word IFELSE takes two unticked words as arguments to branch conditionally depending on a 0 or 1 on top of the data stack (assume "if" and "else" here were already defined):

```
if else IFELSE
```

(see more about tick and inline words below).

Incidentally, prefixing a word with #, such as #w, allows only its name to be put on the data stack instead of the word's executable object. This means that only its stored definition will be put into effect if called from the data stack, as when using EXEC (any interim changes to the word's definition will be ignored).
