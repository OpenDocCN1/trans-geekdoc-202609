## 6.6 TIPS FOR EQUATION MINIMIZATION

A compound proposition that is always true, regardless of component statements that are true, is a tautology (a statement that is always true). Each row in the proposition's column of a truth table is true (1) if it is a tautology.

A compound proposition that is always false, regardless of component statements that are true, is a _contradiction_. Each row in the proposition's column of a truth table is false (0) if it is a contradiction.

A proposition that is neither a tautology nor a contradiction is a _contingency_. The rows in this proposition's column of a truth table will contain at least one false (0) and at least one true (1).

Two compound propositions P and Q are equivalent _iff_ P → Q is a tautology.

## 6.7 SELECTED PATTERNS OF INFERENCE FOR EQUATION MINIMIZATION

The following rules are helpful in minimizing equations:

### Equivalence:

If p ↔ q and p is true, then q must be true.

### Hypothetical Syllogism (Transitivity of implication. Both premise and conclusion are conditional.):

If p → q and q → r, then p → r.

### Addition (Disjunction introduction):

If p is true and p → p ∨ q is true, then p ∨ q must be true.

### Simplification (Conjunction elimination):

If p ∧ q is true, then p must be true.

### Conjunction (Conjunction introduction):

If p is true and q is true, then p ∧ q must be true.

### Resolution:

If \( p \lor q \) is true and \( \neg p \lor r \) is true, then \( q \lor r \) must be true.

### Affirmation (Known by the Latin term *modus ponens*):

If \( p \) is true and \( p \rightarrow q \) is true, then \( q \) must be true.

### Denying the Consequent (Known by the Latin term *modus tollens*):

If \( q \) is false and \( p \rightarrow q \) is true, then \( p \) must be false.

### *Modus Tollendo Ponens*, known also as *Disjunctive Syllogism* (Disjunction elimination):

If \( p \) is false and \( p \lor q \) is true, then \( q \) must be true.

### *Modus Ponendo Tollens*:

If \( p \land q \) is false and \( p \) is true, then \( q \) must be false.

## Abstract

The concepts and nomenclature of set theory underlie much of the data scientist's daily tasks in processing data sets for exploratory data analysis and database interaction.

Sets are unordered collections of elements that usually do not include duplicates. A type of set called a multiset may include duplicates. The elements of sets can exist in groups called subsets. A set with no elements is called the empty set, and the empty set is a subset of every set.

The values associated with elements can be numbers, characters, or words. Furthermore, elements may share classifications in common, such as data types, quartile rank, sample batch, etc.

When elements of a set are described using qualifiers such as SOME or NONE or ALL, we are quantifying. When predicates are quantified they are known as first-order logic. Quantification is useful in set logic.

## 7.1 SETS

Sets are unordered collections of elements that do not include duplicates. However, sets may also be empty and elements may actually be other sets called _subsets_. Element values can be the numbers, characters, words or the members of some class, such as number types, animals, automobiles, or some other classification.

A set may be represented such as { _a b c d_ }. Because order does not matter, the same set can be represented as { _c b d a_ }.

The character _S_ is typically used to symbolize a set. If a set _S_ had no elements, it is an _empty set_ and is given as _S_ = { } or _S_ = ∅.

If _S_ were not empty, we could have:

```
S = {s₁ s₂ ... sₙ},
```

such that each _s_ is in _S_.

Or, we could use another capital letter, such as _A_, for a set.

```
A = {a₁ a₂ ... aₙ},
```

such that each _a_ is in _A_.

If _s_ is an element of set _S_, then we write:

```
s ∈ S
```

If _t_ is not an element of set _S_, then we write:

```
t ∉ S
```

If \( S = \{ \ 2.2 \ 3.1 \ 4.5 \ 5.8 \} \), then we can state:

\( 3.1 \in S \land 2.5 \notin S \)

The *cardinality* (cardinal number) of a set is its element count, denoted with |{}|. For example:

\( |\{a \ b \ c \ x \ y\}| = 5 \)
\( |\{1 \ 2 \ 3 \ 4\}| = 4 \)

Cardinality may be infinite and expressed as:

\( |\{1 \ 2 \ 3 \ 4\ ...\}| = \infty \)

Two sets \( A \) and \( B \) with the same cardinality are referred to as *equivalent* sets. Set equivalence is denoted as:

\( A \equiv B \)

Or

\( (A) = (B) \)

Expressed another way:

\( IF \ |A| \ge |B| \ AND \ |A| \le |B| \ THEN \ |A| = |B| \)

If two sets \( A \) and \( B \) have different cardinalities, then the *unequal* cardinalities may be expressed as either:

\( |A| > |B| \ OR \ |A| < |B| \)

Two sets are *equal* if they contain the same elements. (Equal sets also have the same cardinality.) Equality of sets is denoted as:

\( A = B \)

## 7.2 SET TYPES

- Universal, U. All elements of a particular class. For example: The alphabet is the universal set of the characters x, a and w.

- Complement. \( A' = (U - A) \), or \( A' = \{a | a \notin A\} \). \( A' \) contains all elements in the universal set that are not in A. For example:
  
  \( U = \{ 1234 \}, A = \{ 24 \}, A' = \{ 13 \} \)

- Finite. Contains a finite number of elements. For example:
  
  \( S = \{s | s \in \mathbb{N} \land 1 < s < 100\} \)
  
  Recall from the *Numbers* chapter that \(\mathbb{N}\) = the set of all natural numbers.

- Infinite. Contains an infinite number of elements. For example:
  
  \( S = \{s | s \in \mathbb{N}\} \)

- Subset. If every element of A is an element of set B, then A is a subset of B and we write \( A \subseteq B \). For example:
  
  \( A = \{123\}, B = \{123\}, C = \{13\}, B \subseteq A, C \subseteq A \)
