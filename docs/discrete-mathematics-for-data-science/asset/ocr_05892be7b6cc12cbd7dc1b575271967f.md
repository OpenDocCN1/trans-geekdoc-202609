# 7.2 SET TYPES

+   - Universal, U. All elements of a particular class. For example: The alphabet is the universal set of the characters x, a and w.

+   - Complement. \( A' = (U - A) \), or \( A' = \{a | a \notin A\} \). \( A' \) contains all elements in the universal set that are not in A. For example:
+   
+   \( U = \{ 1234 \}, A = \{ 24 \}, A' = \{ 13 \} \)

+   - Finite. Contains a finite number of elements. For example:
+   
+   \( S = \{s | s \in \mathbb{N} \land 1 < s < 100\} \)
+   
+   Recall from the *Numbers* chapter that \(\mathbb{N}\) = the set of all natural numbers.

+   - Infinite. Contains an infinite number of elements. For example:
+   
+   \( S = \{s | s \in \mathbb{N}\} \)

+   - Subset. If every element of A is an element of set B, then A is a subset of B and we write \( A \subseteq B \). For example:
+   
+   \( A = \{123\}, B = \{123\}, C = \{13\}, B \subseteq A, C \subseteq A \)
