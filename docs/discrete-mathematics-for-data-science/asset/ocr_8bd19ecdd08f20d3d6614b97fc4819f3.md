An expression must reduce, or simplify, to a single value or function expression. Accordingly, the sub expressions must be reduced first, as these become parameters for the outer function. Otherwise we end up with a so-called *stuck expression*, an expression that is not a value and cannot be reduced. Think of it as an abstract function that has no concrete implementation.

Consider the identity function λx.x, which simply returns the argument specified. In the form of an application, such as (λx.x λx.x), the argument expression λx.x is applied to the function expression λx.x. When the application is evaluated, the bound variable x for the function expression λx.x is replaced by the latter argument expression λx.x in the body expression x giving λx.x.

A variation on the identity function is as follows, where the function λx.x both sets and gets the variable x.

```
{ x ! x @ } λx.x WORD
{ λx.x λx.x } (λx.x_ λx.x) WORD
```

The following application of the above function takes 5 as an argument and yields 5 as a result:

```
5 (λx.x_ λx.x) ( → 5)
```
