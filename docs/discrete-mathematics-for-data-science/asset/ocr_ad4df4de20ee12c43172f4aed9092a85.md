# 23.5 GENERALIZATION VERSUS OVER-FITTING

By training a model (classifier) to match exact data patterns, the model will fail when there is no exact match in the testing data. In other words, the model was overfit to the training data.

Conversely, by training a model to match variations of data patterns, the model can better “generalize” to capture patterns that did not exist in the training data.
