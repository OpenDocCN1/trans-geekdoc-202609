WORD". epop's IFELSE function, alias ??, is used to select t or f based on a preceding Boolean argument. For example:

```
{ 1 } t WORD
{ 0 } f WORD
{ t f ?? } if WORD
1 if ( -> 1)
0 if ( -> 0)
```

Next, we define the and, or, and not functions in terms of if. The "DROP" and "???" word usage here selects either t or f, depending on the binary input arguments.

```
{ f if f DROP ?? } and WORD
{ t SWAP if t DROP ?? } or WORD
{ if f t ?? } not WORD
1 1 and ( -> 1)
0 1 or ( -> 1)
1 not ( -> 0)
```

# 12.6 COMBINATORS

A combinator can be defined as a closed lambda expression. This means there are no free variables.

A particular implementation is Curry's paradoxical combinator Y, represented in lambda calculus by:

```
Y = λf.(f(x x)) λf.( λx.(f(x x)))
```
