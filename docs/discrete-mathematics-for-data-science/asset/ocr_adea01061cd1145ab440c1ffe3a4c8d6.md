# 17.2.3 Parse Tree Evaluation

One type of binary tree is a *parse tree* for modeling and evaluating binary operations of arithmetic, and also for converting between infix, prefix, and postfix notations. A parse tree may also be referred to as a *syntax tree*.²

Figure 17.8 A parse tree of (A - B) + (C x D).

Inside the parse tree we have subtrees, each representing the expression of an arithmetic operator and its two operands.
