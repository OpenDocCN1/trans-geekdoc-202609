To programmatically recognize such patterns, we can utilize the coordinate parameters of patterns in classifiers. For example, the W pattern can be represented with five (x, y) pair vertices in the Price × Time or XY plane.

Assume that dates are given for a starting date D0 and an ending date Dn. Given prices Pi normalized as a percentage of the range of a period's maximum and minimum values in a sample, each of the five point patterns would be computed as:

```
Yi = (Pi - Pmin)/(Pmax - Pmin)
Xi = Di / Dn
```

Using such points from several sample data sets, we can train a classifier to find any W patterns present in the data. The classifier's W pattern parameters can consist of the average of several similar patterns that were found. For example, with five distinct patterns, the set of the W pattern's points would be:

```
W = { (X1, Y1) (X2, Y2) (X3, Y3) (X4, Y4) (X5, Y5) }
```

where the condition for pattern W is:

```
W : IF (Y2 < Y1 AND Y3 > Y2 AND Y4 < Y3 AND Y5 > Y4)
```
