```
a 3 OBJECT
b 7 OBJECT

```

Next, link object pairs by their common edge weights. For example, suppose that there exist the following edge weights linked vertices a, b, and c:

```
a - 0.52 - b
b - 0.65 - c
```

Provided that vertex objects and their linked weight are already on the data stack, in the sequences a b 0.52 and a c 0.65, then linking these vertices can be done by invoking the LINK word for each pair, such as:

```
b.o c.o 0.65 LINK ( → b.o)
a.o b.o 0.52 LINK ( → a.o)
```

The result of those linked instructions creates a root vertex object a, which internally references vertex object b, which itself internally references vertex object c. Each nested object is a neighbor of its encompassing object.

A nested series of objects in a root vertex can be extracted to reveal the component values, such as:

```
a EXTRACT → a 3 b 7 0.52 c 5 0.65
```

Objects can be traversed and their neighbors and data extracted as needed for searches or shortest-path computations.
