\(\sum_{i=0}^{N-1} multiplier\_bit_i \times multiplicand_{10} \times 2^i\)

where _i_ represents the position of the bits in the binary multiplier, from right to left.

Thus, for an operation of 0d3 × 1, we have 1 × 3 × 2<sup>0</sup> = 0d3, or 0b11, as no shift occurred. (In 0b11, _i_<sub>0</sub> = 1 and _i_<sub>1</sub> = 1.)

For 0d3 × 0d2, we have 0 × 3 × 2<sup>0</sup> + 1 × 3 × 2<sup>1</sup> = 0d6, or 0b110, as one shift occurred and it doubled the number. (In 0b110, _i_<sub>0</sub> = 0, _i_<sub>1</sub> = 1, and _i_<sub>1</sub> = 1.)

Consider the square of the number 0b0011 (3 × 3 in decimal). The process requires three left-shifts of 0b0011.

| i | bit_i | 2^i |
|---|---|---|
| 0 | 1 × 3 × 2<sup>0</sup> = 3 | |
| 1 | 1 × 3 × 2<sup>1</sup> = 6 | |
| 2 | 0 × 3 × 2<sup>2</sup> = 0 | |
| 3 | 0 × 3 × 2<sup>3</sup> = 0 | |
| | sum = 9 | |
