For independent events \( A \) and \( B \):

```
P(B \mid A) = P(B) \text{ and } P(A \mid B) = P(A)
```

For dependent events \( A \) and \( B \):

```
P(B \mid A) \neq P(B) \text{ and } P(A \mid B) \neq P(A)
```

# Another perspective

We can utilize the symbol ? to express a position in a series of outcomes. For example, given a random set of two unknown tosses, set \( A \) would be represented as:

```
A = \{??\}
```

However, the probability of specifically getting tails on the second toss is expressed as:

```
P(\{?T\}) = 0.5, \, \text{or} \, \frac{1}{2}
```

To see why, consider the following sample space \( S \), consisting of all possible head and tail permutations of two tosses. (A bolded \(\mathbf{T}\) here in the second place denotes tails for the second toss.)

```
S = \{HH \, HT \, TT \, TH\}
```

For another example, consider the probability that a third coin toss will be tails, consisting of all possible head and tail permutations of three tosses.
