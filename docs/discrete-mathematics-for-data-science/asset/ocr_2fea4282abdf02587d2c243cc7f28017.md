+   - Retrieve: Retrieve an element from some place in a list.
+   - Map: Apply a function to each element of a list.
+   - Reduce: Apply an aggregating function to a list (such as adding all elements together).
+   - Length: Return the length (size or count) of a list.

There are other names for the above operations. For example, *reduce* is also known as *fold*, and *append* may be referred to as *push*. Additional aliases will be introduced below.
