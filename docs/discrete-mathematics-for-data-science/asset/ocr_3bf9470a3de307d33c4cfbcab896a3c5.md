The concatenation (the joining) of the separate lists into the one list $L_0$ can be done as:

```
{L0 L1} L0 LIST
{L0 L2} L0 LIST
...
{L0 LN} L0 LIST
```

Then, the new cardinality of list $L_0$ may be shown as:

```
$L_0!$LEN
```
