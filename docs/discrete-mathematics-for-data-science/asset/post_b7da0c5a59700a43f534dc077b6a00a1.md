
value (usually less than 0.05, as discussed in the Multivariate Analysis chapter) suggests rejecting the null hypothesis and concluding that the alternative hypothesis is likely true.

### 21.3 EVALUATING ESTIMATES

We can compute the error for an estimate by comparing it to an actual value. For example, suppose we generated an estimate from training data. The estimate could be some statistic of the set or it could be for a particular value in the indexed set. The estimate from the training set is then compared to an actual value, either from the testing set or from the population data. The difference of those values is the error of the estimate. Measures of such error are elaborated in the following approaches.

For a single point estimate, we can compute the Absolute Percent Error (APE):

$APE = 100 \times \left| \frac{(estimate - actual)}{(actual)} \right|$

However, to compute the error for multiple estimates, we are interested in an average of those errors. For that we can compute Mean Absolute Percent Error:

$MAPE = \frac{\sum_{i=1}^n APE_i}{n}$

Similar to the Mean Absolute Error is the *Mean Squared Error*:

```
MSE = \frac{\sum_{i=1}^n (estimate_i - actual_i)^2}{n}
```

With MSE, squaring rids us of negative errors that offset positive errors when computing an average of errors.

The square root of the MSE makes the magnitude of the error consistent with the original data. Hence, this is called the *Root Mean Squared Error*.

```
RMSE = \sqrt{MSE}
```

## Information Theory

### Abstract

Information Theory is an important foundation for data science, providing the logical validation for how information is quantified, stored, and distributed. Information theory is an application of probability to information (data).

The fundamental components of information are called symbols. In some encoding schemes, symbols may be analogous to atomic or non-divisible data such as 0 or 1 bits, numbers, or characters. In other schemes, symbols may represent abstract words, expressions, or labels for a combination of machine states.

Information may represent a finite state machine, a model, a data structure, a protocol, a language, or a transmission of any of these.

A series of symbols will convey information, a signal or message, and non-information, noise, in varying proportions. The greater the amount of information relative to noise, the greater the likelihood that the information is decipherable.

### 22.1 INFORMATION THEORY

Using Information Theory, information is not evaluated for meaning or validity. Rather, information is evaluated for the likelihood that an encoding exists amid extraneous information or random noise, if any. The task of validating an encoding, as would be useful for subsequent decoding, is more the focus of a subtopic of Information Theory called Coding Theory. Attempts to decode a message need only be made if we first determine that a message is probable.¹

Recall in the chapter on *Computability* the discussion of *finite automata*. Such systems that are deterministic produce a predetermined output state that is always the same for given inputs. Conversely, non-deterministic systems depend on possible or probable inputs, which are not known to the system in advance. In the context of Information Theory, deterministic finite automata may be considered *noiseless channels*. In that sense, probabilistic finite automata would be considered *noisy channels*.

For information to be conveyed from sender to receiver, both must utilize the same set of symbols and rules. Otherwise, communication is not possible.

The probability of receiving a message depends on the quality of the data in its initial state from a sender, as well as its state after its transfer, storage, retrieval, and any data conditioning on the side of the receiver. The conditioning aspect of a data transmission entails eliminating noise. Information Theory accounts for this probability in a measure called *Shannon entropy*, or just *entropy*, which is computed based on the symbols comprising *messages* and *noise*.²

Claude Shannon, a pioneer of Information Theory, realized that more information does not necessarily equate to useful information. Rather, it is the amount of information of known symbols relative to noise that matters. In that respect, Information Theory seeks to minimize the amount of data required to convey a message.

In his paper, *A Mathematical Theory of Communication*, Shannon coined the term *bit* for *binary digit* as a fundamental unit of information.³ A bit can be in one of two states, symbolized 0 or 1. Having just two states, the bit accords with the base 2 numbering system.

Shannon determined the minimum number of binary digits required to store a symbol for reliable communication. Shannon termed this number *entropy*.

Entropy is based on the probability of a symbol in a message. Redundant symbols do not affect the results as long as each symbol has the same redundancy. It may be the case that the sender sends duplicate symbols to ensure their receipt.

Consider a set of symbols such as the characters of the alphabet. Suppose that message transmission is done at a rate of five symbols per second. The possible number of character combinations per second is 26⁵. Assuming each character is equally likely, the probability of drawing any one character is 1/26.

The calculation for entropy, as shown below, includes converting 26⁵ into binary terms (Shannon's symbol set was { 0 1 }). Shannon symbolized the entropy of a message with the letter *H*.

```
26⁵ = 2ˣ
log₁₀26⁵ = log₁₀2ˣ
5 × log₁₀26 = x × log₁₀2
x = 5 × log₁₀26 / log₁₀2
x = 5 × 1.41497334797082 / 0.301029995663981
H = 23.5021985907055
```

As can be seen, the Shannon entropy for drawing a sequence of 5 characters from the 26 letter alphabet is approximately 23.5 bits. That would equate to about 4.7 bits for any single character selected at random.

In practice, the characters of a message are expected to have varying rates, as linguistic research has established. Additionally, noise in the transmission of a message amounts to received characters that have nothing to do with the message.

Given a certain entropy amid noise, a system's communication capacity is defined as the maximum number of bits per second that can be reliably transmitted. Shannon symbolized communication capacity with the letter *C* and showed that reliable communication requires that *H < C*. More about that below.

### 22.2 ENTROPY

The essence of Shannon's 1948 *Noiseless Coding Theorem* is that no irrelevant data be used in a message. In other words, the message and the data are ideally the same length. If not, then noise exists in the data. The amount of this noise is embodied by a statistical parameter that Shannon termed *entropy*, also known as *Shannon Entropy* or *Shannon Information*.⁴

Since Shannon established entropy as a measure of uncertainty for information, we have come to see the terms Shannon Information and Shannon Entropy generally used as synonyms. This may be confusing, as one could reasonably expect these terms to have opposite meanings, as the higher the entropy the less certain the message. However, consider that Shannon Information is inversely related to the probability of a single event, which should be interpreted as the probability that a message is received.

We can compute the entropy of a message provided we are able to distinguish its symbols and know its length. Additionally, given that the probability of each of a message's symbols is known (the message's *probability distribution*), the length of the message can be computed.
