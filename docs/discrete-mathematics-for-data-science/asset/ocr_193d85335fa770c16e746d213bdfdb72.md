Suppose f is a more complex function or operation and consider the following example of β reduction:

```
(λs.(s s) λf.(λf.f f)) → (λf.f λs.(s s)) → (λf.f λf.f) → λf.f
```

This series of lambda calculus reductions can be explained as follows:

+   1. (λs.(s s) λf.(λf.f f)) reduces to (λf.f λs.(s s)).
+   2. (λf.f λs.(s s)) reduces to (λf.f λf.f).
+   3. (λf.f λf.f) reduces to λf.f.
+   4. λf.f is the final result. This is an identity function.

Each step applies the beta reduction rule, substituting the argument into the body of the lambda function.
