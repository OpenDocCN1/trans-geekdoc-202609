Further, suppose that as the program proceeds through the symbol sequence, the state sets may be:

```
{ s_0 s_1 s_2 } S
{ s_0 s_1 } T
```

The *yes* states in T result from some evaluation that yields another state. Maybe each state is a Boolean result, such as true or false, or 1 or 0. However, there can be more than two output states.

Assume the following state implications are defined for the associated transition function inputs:

```
W(s_0, p_0) \rightarrow s_0   W(s_0, p_1) \rightarrow s_1
W(s_1, p_0) \rightarrow s_0   W(s_1, p_1) \rightarrow s_2
W(s_2, p_0) \rightarrow s_2   W(s_2, p_1) \rightarrow s_2
```

With those state implications, the corresponding state transition table is:

| W | p0 | p1 |
|---|---|---|
| s0 | s0 | s1 |
| s1 | s0 | s2 |
| s2 | s2 | s3 |
