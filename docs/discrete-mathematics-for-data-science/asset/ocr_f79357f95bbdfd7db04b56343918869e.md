Accordingly, the Shannon Information for drawing a specific character, such as ‘A’ is:

```
H = -log2(1/27) = 4.76
```

Using the weightings, the Shannon Information for drawing any three character sequence, such as ABC or XYZ is:

```
H = -log2(1/27) + -log2(1/27) + -log2(1/27)
= 3 x -log2(1/27)
= 14.26
```

In reality, the letters in a language are not used with equal frequencies. Suppose that we have the probabilities of the characters H, O, and P as PH = 0.05, PO = 0.076, and PP = 0.02. The Shannon Information for a message of these characters in any order is computed as:

```
H = -(0.05 x log2 0.05 + 0.076 x log2 0.076 + 0.02 x log2 0.02)
= 0.61
```

That is 0.61 bits of Shannon Information, or entropy.
