Real world finite state machines include traffic lights, vending machines, elevators, subway turnstiles, combination locks, and industrial logical controllers. Abstract real-word applications include classifiers for data science and lexers in programming language compilers.

Consider the operator IF as a minimalist finite state machine. Given an input state of 0 or 1 (false or true), IF will affect one operation or another. Assembling a sequence of several IF operations will effectively form a hierarchy of decisions, a decision tree. If some of those decisions involve unknown inputs and repeat a branch of the tree until a particular output is generated, then this system in non-deterministic.

Such a non-deterministic branching system is demonstrated here. This code merely executes function this, that or other based on the choice of the user.

```
{ choice @ 1 EQ this ? } a WORD
{ a choice @ 2 EQ that ? } b WORD
{ b choice @ 2 > other ? } c WORD
```

Provided that the user's input for choice was 2, executing the word c would indirectly cause the word that to be executed via word b. This code is non-deterministic because choice is not known until an instruction in the sequence is evaluated which reveals the input choice.
