# 12.4 REDUCTION & CONVERSION

To deal with problems of naming conflicts and sequence precedence, we can use techniques of name conversion and expression reduction, called alpha α conversion and beta β reduction, respectively.

When a lambda expression cannot be further reduced, as it is completely evaluated, it is said to be in normal form. When a lambda expression in which the outermost application (the head) cannot be reduced, it is said to be in head normal form.

Alpha α conversion is the renaming of a bound variable to prevent name clashes. This conversion is normally done before beta reduction.

For alpha conversion, consider the general function:

```
λ < name1 > . < body >
λx. E
```

The name x and all free occurrences of x in the expression E may be replaced by a new name, provided the new name is not the name of a free variable in λx.E.

Given λx.E, suppose that we want to replace all occurrences of x with y. Such substitution is denoted [x/y].
