This Y combinator takes a curried function and its arguments and treats it as a non-curried multi-argument function. Having more than one argument, one of those can be used to define a recursive function call. In this way, the Y combinator concept facilitates recursion in non-recursive programming languages via *indirect recursion*. For example, in *epop*, a form of indirect recursion called *mutual recursion* may be defined as follows.

```
{ i- DUP 0= FALSE isOdd ?? } isEven WORD
{ i- DUP 0= TRUE isEven ?? } isOdd WORD
4 isEven ( → 1)
6 isOdd ( → 0)
```

Recursion in lambda calculus uses the Y combinator function form Yf = f(Yf), which is a *beta reduction* of the following:

```
λf.(λs.f(ss)) (λs.f(ss))
(λs.f(ss))(λs.f(ss))
f(λs.f(ss))(λs.f(ss)) → Yf = f(Yf)
```

The Y combinator implies that recursion is possible without a named function, by simply referring to itself. This is demonstrated as follows in *epop*:

```
{ + GSC 1 > LL ? }
1 3 5 7 9 LL ( → 25)
```
