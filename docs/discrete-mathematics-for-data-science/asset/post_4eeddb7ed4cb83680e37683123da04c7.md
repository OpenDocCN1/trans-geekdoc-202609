### Abstract

When defining the functionality of an algorithm for data analysis, we are generally interested in balancing its efficiency against elegance. Facilitated by abstraction, elegant solutions are considered relatively concise, and tend to avoid or hide what might appear as a clutter of low-level redundancy.

An abstract function is the synthesis of other functions, be they also abstract or primitive in terms of the native tools of a computing environment. Primitives are analogous to axioms in propositional logic and abstractions are analogous to compound statements of propositions.

This chapter covers some axiomatic foundations, with definitions of counting, successor, predecessor, addition, and multiplication functions. Functions are built upon the concepts of relations, with abstractions of multi-argument and curried argument functions.

### 10.1 AXIOMATIC FOUNDATIONS

When building mathematical proofs, we often start with basic statements that are so obvious that we accept them as true, even if these initial statements are not provable. Axioms are the unproven statements that we accept as true to establish a foundation for a proof.

Functions have an axiomatic basis. We define functions to process a certain input in order to produce some output. The consistency of truth in the function's output relative to it inputs is a matter of evaluation.

For example, consider the following product function that we expect would generate the product of two input numbers. However, when invoking the function, it is found to actually perform subtraction.

```
{ - } product WORD
7 5 product ( → 2)
```

A product operation should not be defined in terms of a subtraction operation, as the relationship between these operations is not axiomatic. Conversely, it is axiomatic that the multiplication of two numbers is their product.

### 10.2 PEANO'S AXIOMS

Our axiomatic approach makes use of Peano's Axioms, which are the basis of a number theory known as Peano Arithmetic. Extending Peano's axioms regarding natural numbers, we can postulate (assume) the functions of addition, multiplication, etc. We can generate infinite sets based on a finite set of symbols and rules.²

Giuseppe Peano was an Italian mathematician who wanted mathematical expressions to be concise, building from an initial element by way of a *successor function*. The successor function defines a successor element as an alteration of the current element. Peano asserted that the constant zero be used for the initial element of “natural numbers.”³

¹Related chapters are *Set Quantification, Algorithmic Complexity, Proof,* and *Computability.*

²A nice take on Peano Axioms is found at this link: https://www.britannica.com/science/Peano-axioms

³Peano's is said to have originally used 1 instead of 0 as the first natural number. By his 1908 publication of *Formulario Mathematico*, Peano was using zero as a first number.

Peano's five axioms are summarized as follows:

- 1. Zero is a natural number.

- 2. Every natural number has a successor in the natural numbers.

- 3. Zero is not the successor of any natural number.

- 4. If the successor of two natural numbers is the same, then the two original numbers are the same.

- 5. If a set contains zero and the successor of every number is in the set, then the set contains the natural numbers (also known as the *principle of induction*).

Peano's axioms extend axioms about equivalence of relations among natural numbers, as follows.

*Closure of equality axiom*: Only that which is a natural number can be *equivalent* to a natural number. This can also be symbolically stated as:

```
\forall n \forall m : IF n \in N AND n \equiv m THEN m \in N
```

Equivalence is a relation having the properties of the axioms of *reflexivity*, *symmetry* and *transitivity*.

*Reflexivity axiom*: Every natural number is equivalent to itself. This can be stated as:

```
\forall n \in N : n \equiv n
```

*Symmetry axiom*: If the current number in a sequence of natural numbers is equivalent to the next, then the next is equivalent to the current. This can be stated as:

```
\forall n \forall m \in N : IF n \equiv m THEN m \equiv n
```

*Transitivity axiom*: If the current number in a sequence of natural numbers is equivalent to the next, and the next is equivalent to its next, then its next is equivalent to the current. This can be stated as:

```
\forall x \forall y \forall z \in N : IF x \equiv y AND y \equiv z THEN x \equiv z
```

*Peano axiom 1: Zero is a natural number.*

0 ∈ N

To generate more numbers, we use a successor function S, which has N as its domain.

*Peano axiom 2: Given any natural number, its successor is a natural number. That is:*

IF n ∈ N THEN S(n) ∈ N

This axiom establishes that the successor function S maps natural numbers to natural numbers, so that N is the codomain of S.⁴ However, we will need *Peano axiom 3* and *Peano axiom 4* to define the arithmetic function of addition that is required to induce the next element, such as:

S(n) = n + 1

*Peano axiom 3: Zero is not the successor of any natural number.*

∀n ∈ N : S(n) ≠ 0

How about S(−1)? The number -1 is not a natural number ( −1 is not in the domain of the successor function), so S(−1) does not exist.

*Peano axiom 4: Given that successors of two natural numbers are the same, then those two natural numbers are the same.*

\forall n \forall m \in N : IF S(n) \equiv S(m) THEN n \equiv m

This axiom requires an injective successor function S, with each natural number having a distinct successor.

*Peano axiom 5* (uses the principle of mathematical induction): If a set contains both zero and the successor of every number in the set, then the set contains all natural numbers.

A set N is inductive with a successor function S given the following two conditions:

- 1. 0 \in N
- 2. IF n \in N THEN S(n) \in N

Thus, we have an inductive set of natural numbers that ensures order and nested successors, such as:

3 = S(S(S(0)))

Therefore, by *Peano axiom 5* and *set equality*, we have:

⁴The codomain is a set that contains the range as a subset. ⊑

N = { 0, 1, 2, ... }
