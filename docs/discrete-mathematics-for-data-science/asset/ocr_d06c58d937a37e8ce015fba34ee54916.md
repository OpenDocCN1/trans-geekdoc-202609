# ## A.1 epop

In this book a Forth-like system called epop is used to assist with the expression of key concepts. epop is a Forth-inspired Functional Programming environment. An objective of epop is to be a vehicle for the study of Discrete Mathematics for Data Science.

epop characteristics (vs https://forth-standard.org):

+   - Most operations are postfix and oriented to a stack data structure.
+   - Three data stacks facilitate data manipulation: Data stack, Return stack and Temporary stack.
+   - Unrecognized code is interpreted as either numeric floating point or character string data. This is referred to as dynamic data typing.
