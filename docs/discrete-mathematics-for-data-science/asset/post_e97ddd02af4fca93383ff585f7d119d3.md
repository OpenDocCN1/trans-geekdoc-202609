
```
{ f } f
```

Such a recursive function definition implies an unconditional self-reference, meaning that f is perpetually invoked. That could lead to errors and a waste of computing resources. Therefore, there should be conditions by which the function does not refer to itself, ceasing its operations. For example:

```
{ i + DUP 8 < f ?} f WORD
0 f (→ 8)
```

The function f will repeat only if the number on the top of the stack is less than 8. Therefore, the result of invoking the function f is that it calls itself 8 times, and the final solution of this particular function also happens to be 8.

The basis of a recursion may rest with the evaluation of a condition in an if-statement. In the above function f, the operator ? is an alias for IF. When given a true condition (1 is true and 0 is false), an if-statement allows a program to evaluate a specified expression or function. The pattern is:

*condition function evaluation*

Depending on the type of evaluation of a condition, such as =, >, or <, a function can be defined to repeat while the condition is true, signified by 1.

Suppose that we have a list of numbers ls and a function f that adds two numbers, given as:

```
{ 1 3 5 7 9 } ls LIST
{ + } f WORD
```

At this stage, if we invoke ls and then f, then only the sum of the last two numbers will be computed, with the resulting value of 16 put on the top of the stack, as shown here:

```
ls f ( → 1 3 5 16)
```

Instead of processing the entire list, we can redefine f to either include a repeat operation or to behave recursively. A loop can include a repeat function, such as:

```
{ 4 + REPEAT } f WORD
```

```
ls f ( → 25)
```

Below is the recursive approach, with function f calling itself while the number of elements in the list is greater than one.

```
{ + GSC 1 > f?} f WORD
```

```
ls f ( → 25)
```

The type of recursion seen so far is direct recursion, since the function call is found within the body of a function having the same name.

Conversely, with an indirect recursion, one function calls another function, which in turn calls the original calling function. There can be several such indirect functions separating the original calling function and its ultimate recursive call.

One form of indirect recursion is called mutual recursion, which entails two recursive functions that call each other.

Types of recursive functions:

- Direct recursion: f calls f
- Mutual recursion: f calls g and g calls f
- Indirect recursion: f calls g, g calls h, and h calls f

Here is a mutual recursion example:

```
{ 1 + g} f WORD
{ 1 * f} g WORD
```

Here is an example of operations in mutual recursion that determine if a number is odd or even:

```
{ ABS i- DUP 0= FALSE isOdd ?? } isEven WORD
{ ABS i- DUP 0= TRUE isEven ?? } isOdd WORD
8 isOdd ( → 0 (false))
-5 isOdd ( → 1 (true))
```

Note that the ABS word is for absolute value, allowing these operations to properly deal with both positive or negative numbers. The ?? symbol is an if-else expression, which invokes one or the other of the preceding two functions, depending on the evaluation of the function as true or false.

## 11.2 INFINITE CYCLES

A recursive call must have a condition that allows the program to eventually exit the function's scope and end the recursive call. Otherwise, the function will be trapped indefinitely in repeated calls to itself - the infamous *infinite loop*, which may exceed the system's memory limitations (*stack overflow*) and possibly crash a program.

For example, the following word definition creates an infinite cycle, as it has no condition by which to stop calling itself.

```
{ bad!. SPACE 1 infinite ? } infinite WORD
infinite (→ bad! bad! bad! bad! bad! bad! ... )
```

Invoking this infinite word will repeatedly print bad! on your screen, indefinitely, unless the system detects the infinite loop and exits gracefully, or it crashes.² Without a terminating condition, the outcome of the self-reference is analogous to the self-reflection of an infinity mirror.³

In contrast, the following recursive word performs a limited number of operations, with its self-reference predicated on a minimum value.

```
{ good!. SPACE DROP GSC 0 > limited ? } limited WORD
1 2 3 limited ( → good! good! good!)
```

Here the function limited is bounded by the number of values remaining on the stack. GSC gets the stack count and DROP drops the topmost value from the stack, so the stack count is 0 after three function calls.

## 11.3 PEANO'S RECURSIVE LOGIC

Recall Peano's Axioms in the chapter Functions & Abstractions the assertion of the existence of an initial integer 0, from which a successor function was used to extrapolate or induce a series of numbers.⁴ Peano axioms allow us to define arithmetic recursively for any two natural numbers.

For example, referring to Peano's successor functions, mathematician Bertrand Russell defined the sum of two numbers as:

> "Suppose we wish to define the sum of two numbers. Taking any number m, we define m + 0 as m, and m + (n + 1) as the successor of m + n. In virtue of [Peano axiom 5] this gives a definition of the sum of m and n, whatever number n may be."⁵

This definition is recursive, as m + (n + 1) depends on the existing terms m + n and the successor function. Accordingly, a + b for any non-negative integer b can be defined recursively using successor function S() as:

```
Base case: a + k = a, for k = 0
General case: a + k = S(a + b), for k > 0 and k = b + 1
```

Note that the base case merely signifies that adding symbolic “0” to a number results in the original number (no actual addition occurs). For the general case, the result of addition is symbolized by the final natural number in the S(b) sequence. Again, no actual addition occurs. Like 0, the “+” symbol is merely symbolic (addition is not being defined in terms of addition).

Now the addition of any two natural numbers, a and b, can be defined as an abstraction of Peano's recursive successor function, such as:

```
S(a + b) = a + S(b)
```

Consider “1 + 1.” Having established:

```
1 = S(0) = 1 + 0
```

Therefore:

```
2 = S(1) = S(1 + 0) = 1 + S(0) = 1 + 1
```

By extension, “1 + 2” can be defined. Recall:

```
2 = S(1)
```

Therefore:

```
3 = S(2) = S(1 + 1) = 1 + S(1) = 1 + 2
```

Having defined addition, multiplication can be achieved as a process of repeated additions. Incidentally, Peano defined a semblance of the base and general cases of recursion for multiplication respectively as:⁶

```
a × 1 = a
a × (b + 1) = a × b + a
```

As with the addition symbol “+”, the multiplication symbol “×” is merely symbolic (multiplication is not being defined in terms of multiplication).

Thus, the multiplication of any two natural numbers *a* and *S(b)* can be defined recursively as:

$$a + (a \times b) = a \times S(b)$$

Consider \( a = a \times 1 \). First, having established that \( 1 = S(0) = 1 + 0 \), we therefore know that:
