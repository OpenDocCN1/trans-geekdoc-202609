```
{{ B D F } A LIST { B } B LIST { B } C LIST { E F } D LIST\ { F G } E LIST { G } F LIST } al LIST
```

Such a representation of an adjacency list maps nicely to a matrix and can be similarly presented as:

```
{ \ { B D F } A LIST \ { B } B LIST \ { B } C LIST \ { E F } D LIST \ { F G } E LIST \ { G } F LIST \ } al LIST
```

Invoking al generates instances of the sublists.

Weights for an adjacency list can be given in a separate parallel list as follows:

```
{ A:B A:D A:F B:E C:B D:E D:F E:F E:G F:G } al LIST
```

```
{ 0.52 0.60 0.11 0.40 0.65 0.41 0.55 0.75 0.63 0.21 } alweights LIST
```
