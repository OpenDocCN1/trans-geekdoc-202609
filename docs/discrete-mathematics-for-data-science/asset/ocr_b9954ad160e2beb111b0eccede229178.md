The above braced expression refers to itself via the function LL, which is used to invoke the last lambda expression. The expression is repeatedly invoked as long as the data stack contains enough data for addition (the value of GSC must be greater than one).

For more depth on the subject of lambda calculus, please refer to Greg Michaelson's book, *An Introduction To Functional Programming Through Lambda Calculus*.⁷
