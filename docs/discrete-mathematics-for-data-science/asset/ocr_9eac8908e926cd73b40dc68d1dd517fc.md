+   • All arguments are listed before the operation.
+   • No use of parenthesis (versus infix, which uses parenthesis for algebraic expressions).
+   • No assignment operator, such as the “=” symbol.
+   • No need for arithmetic operator precedence (order of operation) rules.

Because of these characteristics, postfix operations are more compact and require less computing resources than infix systems. The same benefits can be said of prefix.

The most significant programming languages that use either postfix or prefix notation are Assembly programming (prefix or postfix depending on CPU), Forth (postfix), and Lisp (prefix). C primarily uses infix.

# A.3 POSTFIX OPERATIONS

Unlike the standard infix notation, such as 3 + 4, wherein the + operator is between the operands 3 and 4, postfix notation has the operator last, such as:

```
operand1 operand2 operator
```

For example:

```
3 4 +
```

The result is 7.
