This section provides a brief overview of the data structures in this book, each of which are given in-depth coverage in the following three chapters.

An unconnected collection implies that elements are free of order such that elements appear to be placed at random. These collection types are sets and bags. A bag collection has the least restrictions of all the collection definitions, as it may contain duplicates and is not ordered.

A connected collection implies that each element has a predecessor and a successor, with the exception of the first and last elements. Connection is synonymous with linking, as in linked-lists. The linear variety of such collection types includes lists, stacks, and queues.

Of the connected types, some are branched, which means that an element may have multiple predecessors and successors, depending on a predefined topology. These collection types include graphs and trees.

# 14.2 ORDERING

Connected collections have an order. In turn, order indicates that the elements of a collection are connected.

While the sequence of the order may be assigned by an index, lexical or numeric ordering is not necessary. Where a particular ordering of a sequence is necessary, the use of pre-sorted collections may be used. These include sorted lists, priority queues, and search trees.
