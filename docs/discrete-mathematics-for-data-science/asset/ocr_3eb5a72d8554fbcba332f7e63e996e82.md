Words and the alphanumeric characters comprising a word are subsets of the language's universal set of symbols. A programming language's universal set of symbols is also referred to as the language's symbol table or dictionary.

In contrast, a word that is defined as a set of no words or characters represents an empty set, also known as an identity element. An identity word I may be defined as follows:

```
{ } I
```

Identity words serve as place holders for words or strings that may later take on characters. The common symbol for an empty word or string is ε.

The initial words in a programming language's dictionary are primitives. Words that are defined using a programming language's primitives are abstractions and are added to the dictionary. It should be emphasized that this level of abstraction pertains only inside the scope of the guest language, and not to that of the host language.9

Abstract words are defined in terms of other words, including other abstract words as well as primitive words.
