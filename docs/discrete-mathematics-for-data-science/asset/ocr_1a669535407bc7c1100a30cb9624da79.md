To see the composition of $l_1$, use the SEE operation:

```
l1 'SEE ( → a y b)
```

With mere repetition of head and tail operations we can achieve somewhat complex list processing, as would be done for computing statistics. However, to be practical, such operations should be relegated to functions that we define, if not predefined in the programming language being used.

To append an element to the back of a list:

```
{ x a y b } z PUSH ( → { x a y b z })
```

To concatenate two lists:

```
{ a b c }{ x y z } CONCAT ( → { a b c x y z })
```

To append an element to the front of a list:

```
{ z }{ x a y b } PUSH ( → { z x a y b })
```
