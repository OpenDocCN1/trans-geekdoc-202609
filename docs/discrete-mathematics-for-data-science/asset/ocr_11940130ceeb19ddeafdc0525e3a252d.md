# Description of the abstract syntax tree:

+   - Argument: The right subtree of the eval node.
+   - Function (lambda): The left subtree of the eval node.
+   - Parameter: The left child of the lambda.
+   - Function body: The right child of the lambda.

Free variables are defined outside of a function's scope, the boundaries of a function's definition. Conversely, bound variables are those which exist inside of a function's scope. Pure lambda expressions have no free variables.

In the application (y λx.x), y is a free variable and x is a bound variable. In the function: λx.(s x), s is also a free variable and x is a bound variable.

A function application may be comprised of sequences of function abstractions, much like a chain of commands. Thus, we can express an application by combining two function abstractions like this:

```
(λx.x λy.y)
```

This application has the first function abstraction as the function and the latter one as the parameter. This is similar to a nesting, or composition, of functions such as f(g(x)), where the result of the latter becomes the parameter of the first.
