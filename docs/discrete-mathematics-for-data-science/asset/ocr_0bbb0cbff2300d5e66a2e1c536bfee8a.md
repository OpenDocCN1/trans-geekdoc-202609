# 18.1 BASIC COUNTING

Basic counting measures include the techniques of the sum rule and the product rule.

# Sum Rule:

The sum rule is generally for problems having an OR condition between sets. The sum rule applies to the union of disjoint sets. The sum rule is stated as:

```
|A \cup B| = |A| + |B|
```

Suppose that one element is selected from among the elements of two sets, A and B. Then there are |A| + |B| possible selections. Note the mutually exclusive choice between the sets, a choice to select from one set or the other.

The sum rule can be extended to selecting one element from more than two sets. For example, suppose we have three disjoint sets containing integers, where set A has 4 elements, set B has 2 elements, and set C has 3 elements. The number of ways of selecting any one element from among these three sets is:

```
4 + 2 + 3 = 9
```
