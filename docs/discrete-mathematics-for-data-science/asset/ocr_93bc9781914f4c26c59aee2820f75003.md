+   • Beta $\beta$-reduction: replace parameters with named function to evaluate (reduce) to some value.

# Algorithm for beta $\beta$ reduction:

+   1. Employ alpha $\alpha$ conversion to rename as needed.
+   2. Bind the argument to the name. For example: $2 (\lambda x.x) \rightarrow \lambda x.2$
+   3. Strip function head and name. For example: $\lambda x.2 \rightarrow 2$
+   4. If the statement cannot be reduced, then we have a final parameter, in this case 2.
+   5. Repeat for the next argument and lambda (curried, one at a time).

```
$\lambda nfx.f(nfx) \rightarrow \lambda fx.f(f(\dots f(fx)\dots))$
```
