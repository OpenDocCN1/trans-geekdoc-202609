Stacks are used because they enforce a particular order of elements and so facilitate the CPU's means of memory management.

The First In Last Out (FILO) properties of the stack are often used for enforcing, in a certain sequence, the temporary memory allocation and de-allocation of functions and their constituent methods and variables, or _function scope_. A variable that is declared in a function will see its associated value _pushed_ onto the stack when the function is invoked during runtime. While a function executes, its constituent variables are _popped_ (removed) from the stack.

Think of the _Undo_ command in a word processor. When you enter words you effectively push them onto the stack. The first word entered goes to the bottom of the stack. When you select _Undo_, you effectively pop a word off the top of the stack.

Stack operations affect only those elements on top of the stack. That includes:

+   • Push: Add an element to the top of the stack.
+   • Pop: Return/remove an element from the top of the stack.
+   • Peek: See the value of the stack's top element.

Other stack operations may include:

+   • Length: Return the number of elements on the stack.
+   • Clear: Empty the stack.
