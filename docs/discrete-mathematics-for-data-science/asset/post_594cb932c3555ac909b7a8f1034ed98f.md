
## Data Dimensions

DOI: 10.1201/9781032687759-23

## Abstract

Of the data scientist's day-to-day tasks, a common chore is determining which data matters. While this is of course a conundrum when data is not available, it is a great challenge when the data available is overwhelming.

The dimensions of large data sets are its attributes which can be split into subsets. Intuitively, data dimensions can be understood as separate columns (fields) of a table, or the different data files representing different attributes of related sets of data.

Apart from algorithm complexity and computing resources, data processing programs must deal with the complexities of the data itself, not only in terms of its consistency and redundancy, but also in terms of its dimensions. A statistical overlap of data dimensions and redundancy is known as multicollinearity.

Unnecessary costs arise from processing data dimensions that do not add value to the model, such as when a model is overly fit to noise, a situation called *overfitting*. Additionally, generating estimates with irrelevant data may be costly, as when they form the erroneous basis of business decisions.

### 23.1 HIGHLY DIMENSIONAL DATA

Computing with huge amounts of redundant data, as hidden in *Big Data*, can lead to a significant waste of computing time and resources. To use computing resources efficiently, it is best to identify and minimize redundant data dimensions through appropriate pre-processing of data. Simply put, not all conceivable influences of a forecast variable need be in its predictive model. For example, if automobile sales are of interest, there are myriad attributes of cars for which we can collect data, including make, model, color, power train, etc. There are also economic conditions that may be considered, such as personal income, the unemployment rate, the stock market, etc. The collection of such data for analysis comprises the dimensions of a larger data set. Furthermore, these dimensions will expand as the data scientist applies certain transformative techniques to the original dimensions.

*Data dimension terminology:*

- Dimensions: Also referred to as features, factors, fields, predictors, manifolds, variables, columns.
- Observations: Also referred to as samples, records, and feature vectors.
- Feature vector: A single observation of a set of features, also referred to as a row.
- Feature matrix: A set of multiple observations of feature vectors.
- Longitudinal data: A set of rows or records.
- Latitudinal data: A set of columns or dimensions.

High dimensionality can be a challenge even in situations where data sets are small and manageable. This happens when factors outnumber records, or when we generate too many additional fields as a result of data transformations and lagged time-series. Such highly dimensional cases are said to have structural multicollinearity.

Data transformations increase the number of predictors (dimensions). Consider a data set consisting originally of a certain number of predictors P. If there are T data transformations performed, then we obtain new synthetic factors. Thus, the number of factors expands to:

```
P' = P \times T
```

If we additionally want to include various time lags L for each field and its transformations, then P further expands as:

```
P' = P \times T \times L
```

At some point, increasing the number of transformations and lags will possibly lead to problems, including the number of predictors exceeding the number of observations, model (classifier) overfitting, wasted resources and, as already mentioned, multicollinearity.

Overfitting occurs when input data is too complex for the model to distinguish from noise, which can be in part a consequence of highly dimensional data. The result of overfitting is poor outcomes for prediction and classification.

We know that when the number of predictors, \( P' \), exceeds the number of observations, \( N \), a linear regression model will exhibit dependence among its predictors. When \( P' > N \), there is no way to show that data is linearly independent. That is, we must have:

```
\( N > P \times T \times L \)
```

If this condition is not the case, then we should either increase the sample size for a greater \( N \) or reduce the dimensions for a smaller \( P' \).

If it is the case that \( P' < N \) and a regression model's predictors are linearly independent, then the regression model is considered *well-defined*. Of course, this does not guarantee that the model has predictive efficacy or value.

### 23.2 MULTICOLLINEARITY

When data sets are similar or redundant, we get a condition called *multicollinearity*. Multicollinearity occurs when data sets selected for their independence are, in fact, not independent of each other. That is, two or more dimensions of the data exhibit a dependent or linear relationship. This results when data sets are related with the same or nearly the same values, or when multiple data sets have excessive noise, much of which tends to be randomly the same.

When data fields are not independent from one another, then their respective relationships with the dependent variable is less clear. In such cases, unless you isolate the true important factors, you may have to keep the redundant ones just to maintain the model's predictive efficacy, minimizing the model's error. This is not necessarily a severe problem, as noted by Neter and Wasserman in their classic text, *Applied Linear Statistical Models*:

> The fact that some or all predictor variables are correlated among themselves does not, in general, inhibit our ability to obtain a good fit nor does it tend to affect inferences about mean responses or predictions of new observations, provided these inferences are made within the region of observations.¹

While keeping redundant data fields may not directly harm our conclusions, using more data than necessary wastes computing resources. Furthermore, if data is not available to ensure that the number of fields do not exceed the number of records, then statistically sound analysis is jeopardized. Such complications and related complexities in isolating key attributes in highly dimensional data is known as *the curse of dimensionality.*²

If any of the following occur, we likely have excess data dimensions:

- Removing some variables reduces regression standard errors.
- Variable pairs generally show strong correlation.
- One independent variable exhibits a high r-squared with other independent variables.
- Parameter estimates vary significantly between sample data sets.
- Forecasts significantly change after removing weakly correlated variables.
- There are high *Variance Inflation Factors*, defined below.

During the process of reducing dimensionality, our objective is to retain uncorrelated factors. Uncorrelated factors are also referred to as *orthogonal factors*.

Perhaps the simplest method to avoid dimensionality problems is to examine the category names of the predictors. Look for possible redundancy and irrelevance, and then drop those predictors that would likely duplicate the effects of other predictors, or are just not relevant to model. For example, if we are forecasting the S & P 500 index, we can probably ignore data from the S & P 100 index, as well as data on geese migration patterns.
