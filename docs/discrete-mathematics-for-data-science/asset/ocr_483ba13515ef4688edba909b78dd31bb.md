Instead of recursion, the REPEAT word can be used for repetition. For example, the following code will repeat an operation of addition ten times:

```
+ ' 10 REPEAT
```

The tick mark after the + sign ensures the operations of addition is not immediately invoked, but is instead delegated to a subsequent word for whatever the purpose of the subsequent word. In this case, the + operation is an argument of REPEAT, which repeats + 10 times.

For some words it is not necessary to follow the argument with a tick. Such words are referred to as inline words. For example, the inline word IFELSE takes two unticked words as arguments to branch conditionally depending on a 0 or 1 on top of the data stack (assume “if” and “else” here were already defined):

```
if else IFELSE
```

(see more about tick and inline words below).

Incidentally, prefixing a word with #, such as #w, allows only its name to be put on the data stack instead of the word's executable object. This means that only its stored definition will be put into effect if called from the data stack, as when using EXEC (any interim changes to the word's definition will be ignored).
