A list is a finite sequence of elements of the same data type, in a particular order. It may include duplicated elements. Lists are the basis of *sorted lists*, *stacks*, and *queues*, which are common data structures in data science. Strictly speaking, lists do not have *random access* capability, though this condition is relaxed for some practical applications.

Random access is a property that allows immediate or direct access to any element, without having to traverse (cross over) other elements in the structure. This contrasts with *sequential access* which requires traversing a hierarchical order before reaching a targeted element.

A list can simply be comprised of numbers or characters, as long as it is one type or the other.¹
