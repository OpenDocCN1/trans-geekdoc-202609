For a logical implication, we have an IF ...THEN clause in the statement. Consider the statement:

*If the dog has a bone then the dog is quiet.*

Symbolically, the dog has a bone is $p$ and the dog is quiet is $q$. The statement can be represented as:

```
p \rightarrow q
```

That implication operator, the $\rightarrow$, is an abstraction that can be decomposed into the following basic operations:

```
if p then q else true
```

(ie, if the dog has a bone then the dog is quiet else the dog barks)

In applications of logic, such as in computer architecture and programming, it is often advantageous to use an alternative logic combination for the same result. For example, the above implication is logically equivalent to:

```
\neg p \lor q
```

(ie, the dog does not have a bone or the dog is quiet.)
