The indexing scheme of a data structure pertains to the ordered numbers or keys associated with its values. For a list, indexing is a typically a linear sequence of whole numbers, such as 0, 1, 2, ... For example, for the list { cat dog goat }, it might be that cat is at index 0, dog is at index 1, and goat is at index 2. Random access to a data structure will depend on the structure's indexing scheme. If the collection is not linear, but instead branched such as with trees and graphs, then the indexing will depend on a certain computation that accounts for branches, as discussed in the Branched Structures chapter.
