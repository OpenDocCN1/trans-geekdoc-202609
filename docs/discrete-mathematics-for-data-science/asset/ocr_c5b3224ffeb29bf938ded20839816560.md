# **Problem:** Convert 0b1111010 to hexadecimal.

Break the binary string into groups of four, starting from the right:
(With the segments 111 and 1010, we must insert a zero in front
of 111 to form a group of four.)

```
0111 1010
```

Convert these 4-bit groups to hexadecimal according to the base
comparison Table 4.1 you memorized earlier.

This gives us the sequence 0x7 0xA. Therefore, 0b1111010 =
0x7A.
