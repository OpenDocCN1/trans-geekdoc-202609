Partial Functions: A partial function is a function that is only defined for a subset of the elements in its domain, its inputs. A curried function is a partial function, but a partial function is not necessarily a curried function.

If a function needs to be evaluated later because the values are currently unknown, perhaps awaiting user input, then some function arguments will remain unassigned. This is an aspect of computing known as partial application.

Partial application accommodates another computing concept known as lazy evaluation.

Similar to the data flow approach above, with f(a,b,c) → f(a) | (b,c) the full application is comprised of calling two partial functions.

Lazy evaluation delays the evaluation of an expression until it is required by a dependent expression. This contrasts with eager evaluation which evaluates an expression as soon as it is bound to a variable.
