Given two sets $A$ and $B$, the domain $D$ of their relation $R$, denoted $DoR$, is the set of $A$'s elements that have a relation to elements in set $B$. The range of the relation is the list of distinct $b$ elements comprising each pair: The range is also called the image.

The domain can be written:

$DoR(a, b) = \{a|(a, b) \in R\}$

For unequal sets $A = \{ 1 \ 3 \ 5 \ 7 \}$ and $B = \{ 1 \ 3 \ 4 \ 6 \}$, an example of a relation $aRb$ is:

$aRb = \{(1, 3) (1, 4) (1, 6) (3, 4) (3, 6) (5, 6)\}$

The domain is:

$DoR = \{ 1 \ 3 \ 5 \}$

The range is:

$RaR = \{ 3 \ 4 \ 6 \}$

In general, the range of relation $R$ can be described as:

$RaR(a, b) = \{ b | (a, b) \in R \}$
