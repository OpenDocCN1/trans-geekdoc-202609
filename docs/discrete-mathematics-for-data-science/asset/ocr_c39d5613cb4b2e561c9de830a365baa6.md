Suppose $S$ is a sample space with subset events $A$ and $B$, where $A$ and $B$ have at least one outcome in common. We say that event $A \cap B$ occurs if both events $A$ and $B$ occur.

Whether or not events $A$ and $B$ have any element(s) in common, we say that event $A \cup B$ occurs if event $A$ or event $B$ (or both) occur.

# 19.1.2 Mutually Exclusive Events

If $A$ and $B$ have no elements in common, we say events $A$ and $B$ are *mutually exclusive* (or disjoint), the condition can be denoted:

```
$A \cap B = \emptyset$
```

If $A$ and $B$ are mutually exclusive events, then:

```
$P(A \cup B) = P(A) + P(B)$
```

For example, when rolling a 6-sided die, the event of obtaining an even number and the event of obtaining a 5 are mutually exclusive; They cannot both occur on the same toss of the die.

If $A$ = the event of obtaining an even number, and $B$ = the event of obtaining a “5,” then:

```
$P(A \cup B) \quad = P(A) + P(B)$
\(\quad = 3/6 + 1/6\)
\(\quad = 4/6\)
\(\quad = 2/3\)
```
