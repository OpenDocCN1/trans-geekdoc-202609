To compute the number of distinct unordered subsets:

\( nCr = \frac{n!}{r! \times (n-r)!} \)

So, for all-at-a-time, the number of subsets of ABC, we have:

\( ^3C_3 = \frac{3!}{3! \times (3-3)!} = 1 \)

For two-at-a-time, the number of subsets of ABC, we have:

\( ^3C_2 = \frac{3!}{2! \times (3-2)!} = 3 \)

Starting with the larger set ABCD, and selecting three-at-a-time, the number of subsets is:

\( ^4C_3 = \frac{4!}{3! \times (4-3)!} = \frac{24}{6 \times 1} = 4 \)

The four subsets are: ABC ABD BCD CAD.
