such that \( x \times y = 11 \). We can only find an integer, y, for certain x values { 1 -1 11 -11 }, but not for all x values.

In programming we may have functions for testing for the existence of elements in data sets. For example, in an *epop* program we can test for the existence of a dog among animals, the statement \((\forall animals)(\exists dog)P(animals, dog)\), as follows:

```
{ cat dog pig goat } animals LIST
{ DogFound!. CR } dogfound WORD
{ dog EQ dogfound ? GSC 0 > havedog ? } havedog WORD
animals havedog ( → DogFound!)
```

In the above example code, a list named animals is invoked, pushing all four animal types on to the data stack in the order given in the animals list. Then the havedog word is invoked, which compares each animal type on the data stack to the string “dog.” If there is a match, the string DogFound! is emitted.
