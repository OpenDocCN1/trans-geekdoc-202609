The symbol for a combination may be denoted either C(n,r), nCr, or C_{n,r}. Each of these symbols is read n choose r.

The nCr formula is implemented in epop code, as found in Appendix C.9.

In general, the number of subsets of size r that we can select from n elements (r ≤ n) is:

```
nCr = \frac{n!}{r!(n-r)!}
```

So, for 5C2 the computation is:

```
\frac{5!}{2!(5-2)!} = \frac{5!}{2! \cdot 3!} = \frac{5 \cdot 4 \cdot 3!}{2 \cdot 1 \cdot 3!} = \frac{5 \cdot 4}{2 \cdot 1} = 10
```

Or:

```
\frac{5 \times 4 \times 3 \times 2 \times 1}{2 \times 1 \times 3 \times 2 \times 1} = \frac{120}{12} = 10
```

If our design objective ignores element precedence or order, then we count combinations, not permutations. For example, for two distinct elements, we could simply have AB instead of AB and BA. For a set of three distinct elements, A, B, and C, we could have:

*all-at-a-time, with order irrelevant: ABC*

*two-at-a-time, with order irrelevant: AB, AC, BC*
