The logical conjunction symbol is ∧. However, you will often see the AND operator used for logical conjunction.

The logical disjunction symbol is ∨. However, you will often see the OR operator used for logical disjunction.

Instead of relying on the order of precedence (order of operations) in the table above, parentheses may be used to indicate order. For example, the following statements are equivalent:

```
(p ∨ (q ∧ (¬r))) → s
p ∨ q ∧ ¬r → s
```

When a connective operator such as AND is used in a proposition, we have a logical conjunction. For example:

*Daisy likes bones and Daisy barks.*

This is a logical conjunction of two component propositions. Symbolically, it can be represented as:

```
p ∧ q
```

Or, in postfix notation:

```
p q AND
```

The conjunction p ∧ q is true only if both p and q are true.
