We see queues used by operating systems to prioritize processes, by digital communications to buffer packets of data, and in software for ordering financial transactions in the manufacturing supply chain or the stocks of an investment portfolio.

# Common queue functions:

+   - Enqueue: Add an element to the rear of the queue.
+   - Dequeue: Remove and return an element from the front of the queue.
+   - Front: See the first element in the queue.
+   - Back: See the last element in the queue.
+   - Length: Return the number of elements in the queue.

A _double ended queue_ (deque) can work frontwards and backwards. As such, it accommodates the addition and removal of elements from either end of the queue.

A _priority queue_ is one in which order depends on some prioritization or ranking of its elements. Two elements having the same priority are treated on a FIFO basis. Due to this ordering property, a priority queue may be based on a sorted list.

A _circular queue_ connects the last and first elements. This is achieved by having the last element in the list reference the memory address of the first object, or by using _modular indexing_ of the elements.
