If the tree is balanced, then only one branch of the tree needs to be traversed with each root comparison and, thus affording the O(log n) efficiency. Otherwise, if the tree is unbalanced, the time complexity is O(n). If the tree were perfectly balanced, with all interior nodes having two children and all leaf nodes being on the same level, then traversal is considered a relatively efficient O(log2 n) operation.
