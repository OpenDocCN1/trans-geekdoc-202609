A match of an input character to a targeted character is signified by all 1s for C's output. That is, a match can be verified by ANDing all of the output bits. The evaluation of a 7-bit character could be:

$c_{0,j} = c_{0,0} \land c_{0,1} \land c_{0,2} \land c_{0,3} \land c_{0,4} \land c_{0,5} \land c_{0,6}$

If $c_{0,j} = 1$, then we have equivalent bit sets (a match).

If $c_{0,j} = 0$, then the bits sets are not equivalent (no match).

The process repeats for each input symbol until the next symbol is not part of the required sequence, with state variables updated accordingly.
