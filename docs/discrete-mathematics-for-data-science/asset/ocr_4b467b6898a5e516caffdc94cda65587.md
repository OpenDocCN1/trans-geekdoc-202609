Once the instruction sequence of a non-deterministic finite automata (NFA) is complete and its branches determined, it may then be possible to convert the NFA into a DFA provided that any new data seen by the model does not render different decisions. Accordingly, we would record the true or yes states and then remove all other possible states from the machine. This is more feasible when using a full universal data set such as a *population* and less likely when using sample data sets.

The set of NFA vertices (states) that are set to *yes* defines a DFA.

$dfa = nfa \cap yes$

After converting the NFA to a DFA, the set of instructions that remain is said to be closed. That is, the remaining branch of instructions do not change. This concept parallels that of *closures* in the practice of *functional programming,*<sup>11</sup> which temporarily cache (store) a subset of executable functions for use by nameless functions called lambdas. Lambdas provide the means of statically enclosing the parameters of a nameless guest function that can be used for a separate host function.
