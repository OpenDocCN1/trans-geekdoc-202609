P(A, B) = P(A) \times P(B)

However, if events A and B are dependent, then the outcome of one affects the probability of the other. For example, the numerators or denominators in the respective probability calculations may differ. Consider that the first event somehow added or removed elements in the set of choices for the next event.

The joint probability when events A and B are dependent is:

P(A, B) = P(A) \times P(B | A)

For example, suppose a group of ten people includes four with a college degree. Find the probability of randomly selecting two different people who have a college degree.

Let A = the event of selecting a person with a college degree on the 1st selection.

Let B = the event of selecting a person with a college degree on the 2nd selection.

Since we don't want to select the same person twice, we have only nine people to select from for the second selection. And after event A has occurred, there are only three people remaining who have college degrees.

```
P(A \cap B) = P(A) \times P(B \mid A)
= (4/10) \times (3/9)
= 12/90
\approx 0.133
```

Note that if we are sampling from a large population, we can generally treat selections as if they are independent for the purposes of calculations.

### 19.1.5 Conditional Probability

Consider that one event can depend on another, such as the conditional probability of event A given event B. The conditional probability of event A, given event B has occurred, can be computed using:

```
P(A|B) = \frac{P(A \cap B)}{P(B)}
```

For example, when tossing a coin three times, find the probability of tossing three tails if we know the first toss results in tails.

Example solution:

- Let A = event of obtaining three tails = { TTT }
- Let B = event of the first toss resulting in tails
- = { TTT TTH THT THH }

```
P(A|B) = \frac{P(A\cap B)}{P(B)} = \frac{(1/8)}{(4/8)} = 1/4
```

The above conditional probability formula could be rewritten as:

$P(A \cap B) = P(A \mid B) \cdot P(B)$

Note that this is the formula shown previously for the joint probability that both events A and B occur.

## 19.2 STATISTICS

### 19.2.1 Measures of Central Tendency

Measures of central tendency include computations for mean, median, mode, and midrange.

Note that we use lower case n to denote a sample size and upper case N to denote population size.

Incidentally, statisticians use the word *statistic* for calculations that entail sample data and *parameter* for calculations that entail population data.

*Mean:* The arithmetic average, such as:

$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$

We use $\bar{x}$ to denote a sample mean and $\mu$ (the Greek letter for m) to denote a population mean.

*Median:* The middle data value for a sorted collection. It is given as:

$\tilde{x} = x_{\frac{n}{2}}$

For even numbered collections, the median can be any of the two middle values or their average.

Mode: The value in a series that has the highest frequency (count).

Midrange: Average of the *maximum* and *minimum* values, computed as:

```
midrange = \frac{\max(x_1, x_2, \cdots, x_n) + \min(x_1, x_2, \cdots, x_n)}{2}
```

Given a sorted list, the midrange may be computed as:

```
midrange = \frac{x_1 + x_n}{2}
```

Example: Consider the following sample of lengths (in feet):

25, 28, 19, 21, 24, 21.

The *sorted list*: 19, 21, 21, 24, 25, 28

```
mean = \frac{19+21+21+\dots+28}{6} = \frac{138}{6} = 23 ft
```

median = 22.5ft (The average of the two middle values, 21 and 24.)

mode = 21ft

```
midrange = \frac{19+28}{2} = 23.5ft
```

### 19.2.2 Measures of Variability

Measures of variability include the range of the data, the data's variance, and its standard deviation. The data may be from a sample or a population.

*Range*: The difference between the maximum and minimum values in a data set.

range = max (x₁, x₂, …, xₙ) - min (x₁, x₂, …, xₙ)

*Deviation*: The difference between a particular data value and the mean value of a data set.

deviation = xᵢ - x̄

*Sample variance*: This is the mean of the squared deviations, denoted s² and computed using n - 1 as the denominator, such as:

s² = (Σⁿᵢ₌₁(xᵢ - x̄)²) / (n - 1)

n - 1 is referred to as *degrees of freedom*, the number of values that can vary if their mean is a fixed value. Using degrees of freedom for the denominator in the computation of the sample variance is said to give us an *unbiased estimator*, with a value that better reflects the population data.

As the size of a data set increases, the significance of n - 1 in the denominator diminishes. Thus, with a large data set, as might be attributed to a population, n alone would be appropriate for computing the variance. But, since we don't often know the population size, you are advised to always use n - 1.

The square root of the sample variance gives us the *sample standard deviation*, denoted s:

```
s = \sqrt{s^2}
```

Using \( n - 1 \) for the denominator and the prior example's list of lengths (in feet) 19, 21, 21, 24, 25, 28, consider the following statistics:

```
x = 23 ft
range = 27 - 19 = 8 ft
sample variance = s^2 = \frac{(19-23)^2+(21-23)^2+\cdots+(28-23)^2}{6-1} \approx 10.8 ft^2
sample standard deviation = s = \sqrt{s^2} \approx 3.3 ft
```

A somewhat intuitive perspective of degrees of freedom ( \( n - 1 \) ) is afforded by *Set Theory*. Consider that in the *transitive relation* of three elements, \( a \leftrightarrow \mu \leftrightarrow b \), there exists two direct relations, \( a \leftrightarrow \mu \) and \( \mu \leftrightarrow b \). That is, the set \( S = \{ a \mu b \} \) has the *successor relation* \( R = \{ (a, \mu)(\mu, b) \} \), where the first relation represents the difference \( a - \mu \), the second relation represents the difference \( \mu - b \), and \( \mu \) is the mean value of the elements. The number of successor relations is clearly \( n - 1 \).

*Population variance*: This is the mean of the squared deviations, using the population size \( N \) as the denominator. It is denoted as \( \sigma^2 \), called *sigma-squared*, and computed as:

$$\sigma^2 = \frac{\sum_{i=1}^N (x_i - \mu)^2}{N}$$

*Population standard deviation*: The square root of the population variance, \(\sigma^2\), computed as:

$$\sigma = \sqrt{\sigma^2}$$

### 19.2.3 Measures of Position

Measures of position are useful when we want data that resides in a certain place, or percentile, within an ordered list, without extra computations. Common measures of position include such descriptive statistics as minimum, maximum, median, and quartile, as well various percentiles.

*Nth*: The index of a data value in a sorted list. For example, the 5th data value is the 5th smallest value, and 4 values are lower than the 5th value.

*Pth percentile*: The *pth percentile* of a list of data, ordered from smallest to largest, is the value that separates the lower *p* percent of the data values from the larger data values. (*p* is an integer from 1 to 99.)

For example, the 30th percentile is the value that separates the smaller 30% of the data values from the larger 70% of the values. A test score at the 30% percentile is higher than 30% of the lower test scores, but lower than 70% of the higher test scores.

A data set has three quartiles, and these are the values that separate a sorted data list into four equal-size subsets. The first quartile is the 25th percentile. The second quartile is the 50th percentile (equal to the median). And the third quartile is the 75th percentile.

As stated previously, range = maximum - minimum. We can use the range to scale all of the data to values within a range of 0 and 1, or in percentage terms, 0% to 100%. Such a process is called normalization and it facilitates data analysis in percentage terms, using normalized data.

The common technique of normalization, referred to as min-max scaling, computes the difference of each element and the minimum and then divides this difference by the data range, such as:

```
x_norm = (x_i - x_min) / range
```

A similar approach called mean normalization subtracts the mean in the numerator, such as:

```
x_norm = (x_i - x̄) / range
```
