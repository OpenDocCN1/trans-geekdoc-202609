Note that list ls is merely the flattened sequence of the operations and operands from the parse tree in Figure 17.9, which corresponds with the left column in Figure 17.10.

For a binary parse tree, the operator count is defined as:

opcount = n/2 − 1

Related code for the operator count of the list ls is:

```
ls
{ GSC 2 / i- } opcount WORD
```

where GSC gives us the stack count or the number of objects on the stack.

With those parameters established, we can evaluate the list sequence ls, using the functions EXEC and >> repeatedly for each operation in list s.

For example:

