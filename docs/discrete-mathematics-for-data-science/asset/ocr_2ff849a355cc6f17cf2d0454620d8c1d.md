As you may recall, a strategy of evaluation that executes all the functions of an expression without delay is referred to as eager evaluation. Problems arise with the eager evaluation of abstract functions when function components have, themselves, not yet been completely evaluated. It should be stated that the actual evaluation sequence in practice depends on the programming language being used.

As a result, each time the increment function is invoked, the original list values are used.
