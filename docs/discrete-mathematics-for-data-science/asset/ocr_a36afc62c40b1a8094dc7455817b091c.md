# 19.1 PROBABILITY

In considering a random outcome relative to a maximum number of possible outcomes, a simple coin toss gives a place to start. There are two possible outcomes, head and tails, with only one outcome per toss. With a fair coin, the probability of getting either heads or tails for a single coin toss is 1/2. As the number of tosses increases, we expect the frequency of any one outcome to approximate half of the total number of tosses.

In general, based on observation the probability of any one outcome is:

outcome probability = \frac{outcome count}{count of all possible outcomes}

Using observed coin tosses to calculate the probability of heads, on a future coin toss, the calculation is:

P(heads) = \frac{heads count}{heads count + tails count}

As the number of observed tosses increases, we expect the above result to more closely approximate 1/2 or 0.5.
