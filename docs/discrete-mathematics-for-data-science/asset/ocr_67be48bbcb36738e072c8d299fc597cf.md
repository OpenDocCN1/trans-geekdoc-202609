# 4.2 BINARY CODED DECIMAL (BCD)

Some computer systems use an encoding called *Binary Coded Decimal*, or *BCD*. Using BCD in a lookup table is an efficient approach to number conversion versus binary arithmetic.

BCD Code generally refers to *8421 code*, as this name represents the decimal digits 8 4 2 1 in 4-bit binary. The numbers 8 4 2 1 come from the exponential power sequence $2^3 2^2 2^1 2^0$. There are different schemes for BCD code, but the *8421* type seems most common.

Some BCD schemes define additional fields for values above 9, as can be seen in the fourth and fifth column of Table 4.4. In such cases, 8 bits is allocated for each BCD number.

| dec | hex | bin | BCD |
|---|---|---|---|
| 0 | 0 | 0000 | 0000 0000 |
| 1 | 1 | 0001 | 0000 0001 |
| 2 | 2 | 0010 | 0000 0010 |
| 3 | 3 | 0011 | 0000 0011 |
| 4 | 4 | 0100 | 0000 0100 |
| 5 | 5 | 0101 | 0000 0101 |
| 6 | 6 | 0110 | 0000 0110 |
| 7 | 7 | 0111 | 0000 0111 |
| 8 | 8 | 1000 | 0000 1000 |
| 9 | 9 | 1001 | 0000 1001 |
| 10 | A | 1010 | 0001 0000 |
