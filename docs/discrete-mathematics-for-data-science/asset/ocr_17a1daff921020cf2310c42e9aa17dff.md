In summary, we can state:

\( if \ X \subseteq Y \ and \ Y \subseteq X, \ then \ Y = X \)

Using these same concepts, we can also prove statements involving differences. For example:

Prove: \( A - B = A \cap B' \)

+   1. Suppose: \( x \in A - B \)
+   
+   2. \( x \in A, x \notin B \qquad\) Definition of set difference.
+   
+   3. \( x \in B' \qquad\) Definition of set complement.
+   
+   4. \( x \in A \cap B' \qquad\) Definition of intersection.
+

+   6. Suppose: \( y \in A \cap B' \)
+   
+   7. Then \( y \in A \text{ and } \) \quad Definition of intersection.

+   9. \( y \in A - B \qquad\) Definition of difference.
+   
+   10. \( A \cap B' \subseteq A - B \qquad\) Definition of subset.
+   
+   8. \( A - B = A \cap B' \qquad A - B \text{ and } A \cap B' \text{ are subsets of each other.}\)
