In set A there are 10 non-negative integers less than 10 (including 0). In Set B, there are 14 non-negative integers between 15 and 30. Therefore, there are 10 + 14 or 24 non-negative integers that can be selected from among sets A OR B.

# *Product Rule:*

The product rule allows us to count the number of ways of completing a multi-step process, where A and B represent individual steps.

The product rule is stated as:

| A and B | = | A | · | B |

Similarly, given that there are n ways to select an element from one set followed by m ways to select an element from another set, then there are n × m ways to select one element from each set (for a total of two elements selected).
