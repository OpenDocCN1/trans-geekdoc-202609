```
$z_{score} = \frac{(x_i - \bar{x})}{s}$
```

In the process of standardization, the calculation of each data value is referred to as its z-score. A z-score for a value gives the distance between the value and the mean, where the distance is measured in standard deviations.

As an example, consider as a sample of lengths (in feet) the following values: 19, 21, 21, 24, 25, 28. As we computed previously for this list, \(\bar{x} = 23\text{ ft}\) and \(s = 3.3\text{ ft}\). Additionally:

```
\(\text{z-score for } 21\text{ ft} = \frac{(21-23)}{3.3} \approx -0.61\)
```

We say 21 feet is 0.61 standard deviations less than the mean.

```
\(z - \text{score for } 28\text{ ft} = \frac{(28 - 23)}{3.3} \approx 1.521\)
```

We say 28 feet is 1.52 standard deviations higher than the mean.
