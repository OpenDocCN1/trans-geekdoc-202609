## Branched Structures

DOI: 10.1201/9781032687759-17

### Abstract

In data science, branched structures such as *trees* and *graphs* facilitate the analysis of direct and indirect relationships between data elements. Due to the branching, access to an element from another element may be direct (if the elements are adjacent) or indirect (if the element is accessible only via intermediary elements).

Trees and graphs lend to modeling real-world systems that are more complex than linear systems. In systems engineering, consider the resemblance to graphs of network topologies, or the tree-like hierarchies of operating system processes and file systems. The indexing of trees and graphs can be mapped to various linear structures to facilitate processing.

Two trees and/or graphs may be:

- Equal: The structure, data, and order are the same.
- Identical: The structure may differ while having the same data and order. Identical structures may or may not be equal.

### 17.2 TREES

A tree is a data structure with hierarchical order. Rather than linearly linking nodes, as in a linked-list with one node before and one after, a node in a tree may be at a certain level of a hierarchy with several subtrees. Accordingly, the relationship between nodes is non-linear or indirect.

Trees are useful because they help us model real-world hierarchical relationships, such as organizational structures, file-systems, document outlines, decision trees, expression trees, parse trees, etc.

The path from a tree's root node to any leaf node is unique, as seen in the file system Figure 17.6. The length of a path is the number of connecting edges.

### 17.2.1 Computations for Trees

A full binary tree is a binary tree where every node has either zero or two children, except the leaf nodes, which have no children.

The node count \(n\) of a full binary tree depends on its height, \(h\). That is:

\(n = 2^h - 1\)

Knowing \(n\) we can solve the above equation for \(h\). Here are the steps:

\(n + 1 = 2^h - 1 + 1\) (Add 1 to both sides.)
\(h = \log_2(n + 1)\) (By definition of logarithm.)

Or, using the change-of-base formula:

\(h = \log_{10}(n + 1) / \log_{10}2\)

The number of leaves on a full binary can also be computed from \(n\), such as:

\(leaves = (n + 1) / 2\)

A complete binary tree is useful in that its elements can be mapped to the simple index of an array or list, in a contiguous sequence. A complete binary tree is full at all levels with the possible exception of the bottom level, which should be filled from left to right. Such list representation of a tree may be referred to as a flattened tree.

Searching a flattened binary tree is a relatively simple linear search of the list in the index sequence 0 1 2 3 .... Given a level-order indexing of a binary tree, as shown in Figure 17.7(a), a breadth-first search is the same as linear search of a flattened tree.
