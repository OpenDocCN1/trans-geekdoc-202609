The channel between a sender and a receiver may be considered a medium or a route. The channel may carry electrical pulses representing the bit-stream of a networking protocol.

Suppose that a channel carries data at a maximum rate of 8-bits per second. The channel's bandwidth is 8 bits/s. Beyond that, transmission becomes unreliable with too many errors and too much entropy.

Shannon's Fundamental Theorem for a Noiseless Channel presents a maximum set of symbols S in a period, a data rate of symbol transmission in terms of channel capacity C divided by the entropy H. That is:

```
S=C / H
```

We can re-arrange the symbols to get C = HS and see that channel capacity depends on the product of the symbol rate and entropy.

Channel capacity may also be considered the maximum mutual information. As such, it is computed as:

```
C(A, B) = I(A, S)
```

Suppose that the sender has symbol set { 1 0 1 0 } as A to transmit. Given a data rate that is limited to half capacity, S would be { 1 0 } and it would not be clear which part of A was received.⁶

# 22.10 DATA COMPRESSION & HUFFMAN ENCODING

Data compression is an achievement of Information Theory. Compressing data allows us to represent information with fewer bits for transmission and storage. The receiver restores the original information using decompression.

Shannon entropy tells us that information may be represented by more bits than necessary, indicating opportunity for compression.
