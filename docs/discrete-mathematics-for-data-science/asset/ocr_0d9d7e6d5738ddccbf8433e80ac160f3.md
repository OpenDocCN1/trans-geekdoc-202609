(b (x λf.λc.(c f))) → (b λc.(c x)) → (b x)

The replacement shown above is a form of alpha conversion. A name clash arises when a β reduction places an expression with a free variable in the scope of a bound variable with the same name as the free variable. Alpha conversion removes the name clash.

# 12.4.1 Other Conversions

Eta η conversion: An eta specifies a different function that gives the same results, such as λx.fx. Substitution by a longer function is η-expansion and substitution by a shorter function is η-reduction.

Simplification through eta reduction: Consider an expression of the form:

λx.(x E)

This is equivalent simply to E.

The application of this expression to an arbitrary argument gives:

(arg λx.(x E)) → (arg E)
