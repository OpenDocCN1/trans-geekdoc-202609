It might seem trivial to compute this coefficient of determination ($ R^2 $) by merely squaring the R. But, simply squaring R mistakenly ignores that these two parameters deal with different data. \( R^2 \) applies to predicted \( \hat{y} \) values, whereas R applies to the actual y data.

In practice, a linear regression line may represent data poorly, having an insignificant \( R^2 \), indicating no statistical relationship. However, a higher \( R^2 \) might be found using a non-linear model.

A poor \( R^2 \) may not be entirely due to a sub-optimal regression model. Data quality and relevance is also a factor to consider. Anomalous data values, what we call *outliers*, can skew a regression model's results. It may also be that the data was imported from an incorrect or corrupt repository. Or, the data may have been sampled using insufficient randomness. (More is said about the last point in the *Resampling* chapter.)

## 20.5 MULTIPLE LINEAR REGRESSION

Consider a regression model of multiple independent variables, such as:

y = \(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_N x_N + \epsilon\)

Each beta coefficient represents the change in the \( y_i \) for a given predictor \( x_i \), holding all the other predictors constant. That is, we generate these pair-wise.

The predictor variables of a regression model may be primary data or derivations from that data, such as the products of predictor pairs, non-linear transformations, or time lags.

It is common before regressing multiple explanatory variables to first normalize or standardize each data set. This accommodates a common y-intercept and so makes interpretation easier. For example, it would only make sense to use an average \(\beta_0\) based on all the predictors if all the data were first normalized.

Unless the dependent variables are, themselves, synthetic products of one another, standardization will not affect the results of a regression, as the equations for the regression coefficients already scale the results into relative terms.

## 20.6 TESTING THE SIGNIFICANCE OF REGRESSION VARIABLES

When performing multivariable linear regression, it is best to only include those independent variables that provide a relatively significant contribution to the model.

One method for determining which independent variables to use is to test the full model, removing one predictor at a time to check the impact of each on the accuracy of the model, also called the *efficacy of the model*.\(^2\)

Another method for determining which independent variables to include involves comparing the y data to each independent variable, one at a time, to look for a significant linear relationship. For each comparison, a *hypothesis test* involving a statistic called *t-statistic* can be performed. A general overview of the hypothesis testing procedure follows:

Formally, the claim that two variables do **not** have a significant relationship is called the *null hypothesis*, and is denoted \(H_0\). In contrast to the null hypothesis is the *alternative hypothesis*, denoted as \(H_1\) or \(H_a\). The alternative hypothesis is the claim that a significant relationship **does** exist between two variables. In a hypothesis test, we decide whether or not to reject the null hypothesis based on the data, or more specifically, based on a *test-statistic* computed from the data. If the test-statistic leads us to reject the null hypothesis, then we have evidence in support of the alternative hypothesis, and we conclude there is a significant relationship.

²Model testing is covered in the Resampling chapter.

For comparing one predictor variable with the y data in a regression, the appropriate test statistic is:

$t = \frac{b_1 - 0}{se_{b_1}}$

where the numerator \(b_1 - 0\) differentiates the beta coefficient \(b_1\) with a slope of zero, and \(se_{b_1}\) is the standard error of the beta coefficient.

Recall that \(b_1\) is:

$b_1 = \frac{s_{xy}}{s_x}$

The standard error of the estimate is:

$se_{b_1} = \sqrt{\frac{\sum(Y - \hat{Y})^2}{N - 2}}$

Here, the sum of squared errors is divided by \(n - 2\) instead of \(n - 1\), as we are estimating two parameters, the slope and the intercept, requiring an additional degree of freedom. This allows the standard error of the regression to be an unbiased estimate of the standard deviation of the estimate's errors.

Associated with the value of the t-statistic is the probability of obtaining a value at least as extreme as the value of the calculated t-statistic. This probability is referred to as the p-value. Note that the computations are complex and technology is normally used to calculate both the t-statistic and the p-value.

In the context of the regression beta coefficient, we want to determine either \( H_0: \beta_1 = 0 \) or \( H_1: \beta_1 \neq 0 \).

Once a p-value is obtained, we use it to decide whether or not to reject the null hypothesis. If the p-value is small (usually less than 0.05), then we reject the null hypothesis. In this case the data supports the alternative hypothesis, which is the idea that a significant linear relationship exists. So, we include that independent predictor variable in our regression model.

3 P-values can be computed online at the following link: https://www.gigacalculator.com/calculators/p-value-significance-calculator.php

If the p-value is greater than 0.05, then we cannot reject the null hypothesis and we have not found a significant linear relationship between the predictor variable and the y data. So, we do not include that independent predictor variable in our regression model. In conclusion:

- If p-value < 0.05 then include the variable.
- If p-value > 0.05 then do not include the variable.

### 20.6.1 Analysis of Variance Table

An analysis of variance table, or ANOVA, is commonly used to display the parameters of regression models that have at least two independent variables. The fields of an ANOVA table are: degrees of freedom (DF), sum of squares (SS), mean square (MS), and F-test, as seen below.

### TABLE 20.1 An analysis of variance table (ANOVA)

| Source | DF | SS | MS | F-Test |
| :--- | :--- | :--- | :--- | :--- |
| Regression | \( k + 1 - 1 \) | \( SSR \) | \( MSR = SSR/(k + 1 - 1) \) | \( MSR / MSE \) |
| Error | \(n - k + 1\) | \(SSE\) | \(MSE = SSE / (n - k + 1)\) | |
| Total | \(n - 1\) | \(SST\) | | |

The F-test statistic for a regression model is computed as MSR/MSE, the mean of the squared residuals relative to the mean of the squared errors. This is a measure of how much of the variation in the dependent variable is explained by the model, and is used primarily when more than one independent variable is involved. If the model includes only one independent variable, then R², the coefficient of determination, is used to measure the amount of variation attributed to the model, as discussed earlier.
