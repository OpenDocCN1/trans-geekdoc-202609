problem size has a maximum growth rate of g(n)," and O(g(n)) is called the algorithm's Big-O.

To show that f(n) = O(g(n)), we show that the function f(n) is limited by the upper bound of g for all n. This relationship is proven by ignoring constant factors, such as c, and non-recurring operations.

For example, to find the Big-O for the function:

```
f(n) = n + 1
```

first note that 1 ≤ n, for all n ≥ 1. Then substitute n for 1 in f(n) = n + 1 as follows:

```
n + 1 ≤ n + n = 2n, for n ≥ 1
or: f(n) ≤ 2n, for n ≥ 1
```

If we let g(n) = n, then we have f(n) ≤ 2 × g(n), for n ≥ 1.

Thus, the Big-O for f(n) is O(n) and we can write f(n) = O(n).

As another example, to find the Big-O for f(n) = 5n + 8, note that 8 ≤ 8n, for all n ≥ 1. Substituting for 8, we can reason:

```
5n + 8 ≤ 5n + 8n = 13n for n ≥ 1
```

So, we can conclude:

```
5n + 8 ≤ 13n for n ≥ 1
```

We can rewrite the above as:

```
f(n) ≤ 13 × g(n) where g(n) = n
```

Thus, the Big-O for f(n) is O(n) and we can write f(n) = O(n).
