The inductive case in strong induction sometimes requires the use of more than just the statement P(n − 1). One might also need to use P(n − 2), P(n − 3), etc., to prove P(n) is true. Strong induction is used in more complicated situations.

The same inductive hypothesis applies to finite as well as infinite sets provided each element has an immediate predecessor.

To prove a statement P(n) is true for all n in a particular set, using mathematical induction:

+   - The base case: show that P(i) is true for one value, i, (usually the minimum) in the set.
+   - The inductive case: Assume P(k) is true for any k in the set. Use the assumption to show P(k + 1) is true.

# 8.10 INDUCTION EXAMPLES

For our first induction example, let P(n) be the statement that the sum of the first n odd natural numbers is n^2.

```
P(n) : 1 + 3 + 5 + ⋯ + (2n − 1) = n^2
```

Note that the nth positive integer can be expressed as 2n − 1.

We will use mathematical induction to prove P(n) is true for all n ∈ W.

Base case: P(n) is true for n = 1 because

```
P(1) : 1 = 1^2
```

Inductive case: Assume P(n) is true when n = k, where k is any natural number. That is, we assume the following is true:

```
P(k) : 1 + 3 + 5 + ⋯ + (2k − 1) = k^2
```
