# 2.2 ABSTRACT FUNCTIONS

An abstract function will _generalize away_ or hide the details of other functions that it embodies. Details that are common to multiple instances of the same code represent opportunity for consolidation, using a more general form that can be copied and extended. That way we can create a hierarchy: a parent object containing general attributes and child objects, which can have specialized attributes, as well as those inherited from the parent. This provides the efficiencies of code reuse and modularization.

An abstract solution exists to solve a general category of problems. A concrete solution depends on honing an abstract solution into a specific application for a specific problem. Thus, problem solving depends on isolating a problem as one of a general abstract category, and then modifying the abstract solution with additional functionality and data.
