The total possible number of combinations of these eight character bits is 2^8, meaning that any one of 256 characters may be accommodated by one byte of storage, and a string of four characters may reside at a single memory address in a system that has 32-bit addressing.

Some mysterious programming errors can be avoided by ensuring that such *character encodings* are consistent across your programming environment. Therefore, it is common today for computing systems and languages to conform to the *Unicode Character Set*, which is generally accepted.

Unicode assigns a distinct integer to each character in a language locale, such as English. Unicode's predecessor is ASCII (American Standard Code for Information Interchange), which is now a subset of Unicode.^1

Inside operating system libraries are files of data that are used to generate alpha-numeric characters in various font styles. These character fonts are also known as *glyphs*. Each character's glyph is associated with a Unicode integer. Having such a number accommodates the machine's retrieval, sorting, searching, and other processing of text.^2
