# 3.1. Dataset Collection

We initially collected a dataset from a publicly available source [16] to propose ensemble methods. Our cohort of 471 patients includes information on the patient’s history, such as age, gender, length of survival, and donor relapse type. There are 377,735 samples in the copy number somatic mutation file and 369,409 samples in the miRNA seq file, all of which were examined and approved by the Illumina HiSeq verification platform.
