因此，本研究深入探讨了用于识别系统性红斑狼疮（SLE）患者人群中免疫缺陷模式的最佳机器学习技术。它确立了机器学习系统作为一种高度准确的工具，用于识别感染及其后续导致的SLE发作风险显著升高的个体中免疫参数水平降低的情况。此外，所提出的基于随机森林（RF）的系统在更大的AUC方面超过了其他研究的性能，从而证实了其卓越的预测准确性。
