In general, the early layers of a CNN learn low-level image features that are applicable to most visual problems, but the later layers learn high-level features, which are specific to particular application domains. Therefore, fine-tuning the fully connected layers is usually good enough. However, as discussed in Ref. However, the general consensus that we can reach from the results is that transfer learning significantly improves the performance of computer-aided diagnosis problems.
