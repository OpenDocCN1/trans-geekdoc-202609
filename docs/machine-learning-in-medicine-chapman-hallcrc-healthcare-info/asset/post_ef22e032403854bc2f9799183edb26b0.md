#### 1.1 INTRODUCTION/HISTORY

When one thinks of machine learning and artificial intelligence in healthcare, the overwhelming thought is about their applicability in radiology for diagnosing pathologies through chest X-rays/computed tomography or their applicability in dermatology for diagnosing pathologies using skin images. These are logical applications, because we expect that by seeing numerous normal and pathological images, the machine/neural network can decipher the salient features that define each pathology and then use these features to predict pathology in unseen images.
