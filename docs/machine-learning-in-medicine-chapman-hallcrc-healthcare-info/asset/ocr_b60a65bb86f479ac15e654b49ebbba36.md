# 10.5.5 Results with Convolutional Neural Networks

Given the $N \times M$ input matrix where $N$ is the time-window and $M$ is the number of sensor readings, different network architectures as shown in Figure 10.2 have been tested on the Aruba dataset.

**1D Convolution**: Convolution is applied on one only dimension as seen in Figure 10.2a, where 100 filters (length of 10) are applied to the temporal dimension. Then a max-pooling layer (stride = 2) and another convolutional layer of 50 filters (length = 5) with a max-pooling layer are added. A flattened layer is added to flatten the features, and then three dense layers with hidden neurons of 512, 128 and 50 are added. Lastly, a soft-max layer is added to produce confidence values to class labels.
