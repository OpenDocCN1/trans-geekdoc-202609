
现在 `e[1]`、`e[p]` 表示第二特征向量的元素。更精确地说，特征向量是正交的，成分是不相关的，尽管在这种情况下，只要意识到两者之间的差异，使用“不相关”和“正交”这两个术语是可以互换的。我们不必止步于此！我们可以继续从数据中推导出主成分，每个主成分解释先前成分未解释的递增方差。请注意，在我们对经典 PCA 的推导中，我们是一次性将该技术应用于整个训练数据。也就是说，我们假设整个训练数据可直接获得。这种方法的替代方案被称为 *增量 PCA*（[Lippi & Ceccarelli, 2019](#ref.xhtml#re_CIT000224)），其中更新的协方差矩阵 `Σ[n + 1]` 基于“旧”的协方差矩阵 `Σ[n]`。也就是说，增量 PCA 将新观测值（`n + 1` 中的 +1）添加到协方差矩阵中，因此与传统 PCA 相比具有计算优势。其好处是不必将所有数据保存在内存中，并且该算法可以在数据集预期快速增长时或当静态数据集本身非常大、一次无法装入内存时应用 ([Lippi & Ceccarelli, 2019](#ref.xhtml#re_CIT000224))。增量 PCA 在 Python 中可通过 `sklearn` 中的 `IncrementalPCA` 获得。

### 11.2.2 PCA 作为最小二乘技术和最小化重建误差

正如大多数统计方法一样，主成分分析有不止一种解释。到目前为止，我们的解释是通过特征值分析或 SVD，但我们也可以将其解释为类似于最小二乘回归的最小二乘技术，而我们已经熟悉这种技术。与典型的普通最小二乘回归中将高维空间投影到低维空间以最小化响应中平方误差之和不同，在 PCA 中我们也寻求投影，但这次是从高维空间到低维空间，使得平方 *垂直距离* 之和最小化，其中“垂直”相当于 *正交*。

例如，图 11.1 中是从二维空间到单个 *超平面* 的投影，使得主成分的正交平方数据距离最小化。399

![图 11.1 使平方正交距离最小化并使原始变量中的方差最大化的超平面。这样的超平面称为主成分。返回文本。⏎](images/fig11.1.jpg)

*图 11.1* 使平方正交距离最小化并使原始变量中的方差最大化的超平面。这样的超平面称为主成分。返回文本。⏎

事实上，在典型的 PCA 分析中，我们寻求最小化所谓的 *重建误差*（[Murphy, 2022](#ref.xhtml#re_CIT000259)）。并非巧合，可以证明当所得成分是协方差矩阵特征值分析的特征向量时，重建误差最小化。推导的细节可在 [Bishop (2006)](#ref.xhtml#re_CIT000032) 和 [Murphy (2022)](#ref.xhtml#re_CIT000259) 中找到。平均重建误差由下式给出：

$$l\\left( W,Z \\right) = \\frac{1}{N}{\\sum\\limits\_{n = 1}^{N}\\left| \\middle| x\_{n} - Wz\_{n} \\middle| \\right|^{2}}$$

(11.4)

其中 `x[n]` 是原始数据点，`z[n]` 是基于投影得到的派生数据点，而 `W` 是一个正交矩阵。最优解（即 `l(W, Z)`，它是一个 *损失*，被最小化）是在 `Ŵ = U[L]` 时获得，其中 `U[L]` 是协方差矩阵的特征向量，因此根据定义，对于具有不同特征值的对称矩阵，正交。注意 `W z[n]` 本质上是在尝试产生与 `x[n]` 的最小偏差，并且在最理想的情况下，基于获得的特征向量（即宽松地说，成分）对数据进行重建是完美的，则 `l(W, Z) = 0`。最小化此重建误差等价于最大化变量中的方差（Murray, 2022），这正是我们最初开始的 PCA 的解释。再次，正如大多数统计方法一样，推导 PCA 技术有多种不同的方法，在这种情况下可以证明最小化重建误差在 *数学上等价* 于最大化由成分解投影的数据方差。从不同角度和视角感知统计或机器学习技术的方式可以在真正深入理解它时带来回报。

除了 PCA 可通过特征值分析或（截断）SVD 计算外，成分也可以通过期望最大化（`EM`）算法获得，并且相对于特征值分析具有优势，因此通常更快 ([Murphy, 2022](#ref.xhtml#re_CIT000259))。400

### 11.2.3 选择派生成分的数量

在良好行为矩阵的大多数条件下，我们可以获得的成分数量等于接受成分分析的观测变量的数量。也就是说，如果 `x[1]`、...、`x[p]` 包含例如 100 个变量，则在通常（也是最常见）的条件下，对这些变量计算的成分数量将等于 100。简而言之，*对观测变量进行的 PCA 本身并不会减少数据中的信息*。在 100 个变量的情况下，*选择* 少于 100 个计算成分的地方才是实际的 *数据缩减* 发生之处，否则 PCA 所做的一切只是不成比例地将大部分方差加载到前几个成分上。这意味着 PCA 只是简单地将观测变量的方差“打包”（或 *重新打包*）成连续的线性组合。但在应用意义上，它并不是真正的维度“缩减”，直到我们选择少于生成的总成分数量。这就是 PCA 作为降维技术的逻辑。PCA 首先只是一种 *变换*。

### 11.2.4 为什么重建误差不足以选择成分数量

由于 PCA 试图尽可能解释变量中的方差，在选择要保留的维度（成分）数量时，不能简单地使用 *重建误差* 或 *解释方差* 作为指导，因为保留的成分越多，解释的方差就越多，随之而来的重建误差就越小。这有点类似于在多元回归中添加更多预测变量的效果——解释的方差几乎总是会增加（除非在零相关等非常特殊的情况下），因此仅基于解释方差选择“最佳”回归模型并不是一个好策略。使用重建误差作为指导的这一局限性在我们后面考虑聚类分析并寻求衡量标准来证明要保留的聚类数量时也会再次出现。由于重建误差通常并且必然随着聚类数量的增加而减少，因此重建误差不是决定保留多少个聚类的充分衡量标准。

为了确定要保留的成分数量，应主要使用实质性判断以及统计指标，最后再加上一点常识。例如，如果前两个成分解释了 70% 的方差，但第三个成分仅额外解释了 1%，那么在 *大多数* 情况下（取决于调查的实质性性质），双成分解显然会占主导。诸如 *碎石图* 之类的图形度量可用于可视化重建误差以及解释方差，通常人们会在此类图中寻找“拐点”以指示重建误差（或解释方差）突然“下降”的位置。
