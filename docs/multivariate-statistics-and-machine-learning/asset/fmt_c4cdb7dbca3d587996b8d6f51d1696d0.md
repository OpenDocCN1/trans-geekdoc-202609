### 5.13.2 Partial Least-Squares in Python

Partial least-squares regression can be fit in Python using `PLSRegression`. The following is a simple example with easy data:

```
from sklearn.cross_decomposition import PLSRegression
X = [[0., 0., 1.], [1., 0., 0.], [2., 2., 2.], [2., 5., 4.]]
Y = [[0.1, -0.2], [0.9, 1.1], [6.2, 5.9], [11.9, 12.3]]
```

We will request a 2-component solution:

```
pls2 = PLSRegression(n_components=2)
pls2.fit(X, Y)
```

We now obtain predicted values based on the two-component solution:

