## 5.13 偏最小二乘回归

与主成分回归仅使用 `x[1]` 到 `x[p]` 构建成分不同，偏最小二乘寻求数据中同时包含预测变量和响应变量的维数或方向。也就是说，`x[1]` 到 `x[p]` 中找到的成分不仅与预测变量侧相关，也与响应 `y` 相关。偏最小二乘，或简称为“PLS”，通常被认为是对主成分回归的一种监督替代方法（[James et al., 2013](#ref.xhtml#re_CIT000168)），因为 `PLS` 在确定最佳“方向”时会纳入响应。

正如 Izenman 所描述的那样，

> PLS 搜索一组成分（称为潜向量），该成分对 `X` 和 `Y` 进行同时分解，同时约束这些成分尽可能解释 `X` 和 `Y` 之间的协方差。以这种方式，PLS 中的导出变量被构建为保留 `X[1]` 到 `X[p]` 变量中的大部分信息，并且通常通过算法而不是优化程序获得（[Izenman, 2008](#ref.xhtml#re_CIT000167)，第 133 页）。

为了阐明 PLS 实际完成的工作，再次回顾典型 PCA 中线性组合的样子：

`z[1] = e[1]x[1] + e[2]x[2] + ... + e[p]x[p]`

在 PLS 中，`z[1]` 中的系数，即 `e[1]` 等，被设置为对每个预测变量将 `y` 对 `x` 进行简单线性回归的结果系数。该系数（例如 `e[1]`）与 `y` 和 `x[j]` 之间的相关性成比例，即我们正在考虑的给定预测变量。也就是说，在计算第一个成分时，与 `y`（在单变量意义上）最密切相关的变量 `x` 会获得最大的权重。

为了得到第二个成分 `z[2]`，首先对 `z[1]` 的每个变量进行调整，通过将每个变量对 `z[1]` 回归并取“剩余”部分的残差。如果第一个成分解释了预测变量中的所有信息，残差将等于零。更有可能的是，第一个 253成分不会解释所有信息，因此残差将大于零。第二个成分 `z[2]` 使用这些残差计算得出，这些残差与第一个成分正交。迭代方法继续用于 `z` 的后续方向（即成分）。

因此该方法被称为偏最小二乘的原因很清楚。它之所以如此，是因为它利用了与之前成分值正交的残差。因此，如果 PLS 能说话，它会说：“在去除预测部分（或‘偏’）之后，让我们现在对剩余部分回归新的成分。”偏最小二乘与主成分回归一样，不是尺度不变的，因此通常建议对预测变量进行标准化。然而，正如书中其他地方所述，是否进行标准化的决定不应在不仔细考虑所研究变量的性质（尤其是尺度）的情况下做出。
