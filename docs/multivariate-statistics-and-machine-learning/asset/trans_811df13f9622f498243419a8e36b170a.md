### 8.6.2 Python 中的泊松回归
在 Python 中，我们可以使用 `sklearn` 拟合泊松模型。我们创建一些关于 `x` 和 `y` 的简单数据，并在下面拟合一个基本的泊松模型：
```
from sklearn import linear_model
clf = linear_model.PoissonRegressor()
X = [[1, 2], [2, 3], [3, 4], [4, 3]]
y = [12, 17, 22, 21]
```
从上面可以看出，`X` 有两列，而 `y` 有一列。我们现在进行拟合：
```
clf.fit(X, y)
Out[110]: PoissonRegressor()
```
模型的估计回归系数如下：
```
clf.coef_
Out[112]: array([0.12109212, 0.15836976])
```
模型的截距由以下给出：
```
clf.intercept_
Out[113]: 2.0885914156053205
```
我们现在基于 `X` 获取 `y` 的一些预测值：
```
clf.predict([[1, 1], [3, 4]])
Out[114]: array([10.67658784, 21.87505182])
```

## 8.7 广义可加模型：一种灵活的非参数替代方法
广义线性模型，具有逻辑回归和泊松回归等特例，具有“线性-like”或其他 `parametric` 形式。也就是说，我们带着先验的 `a priori` 参数思想或形式来处理数据，以将该特定形式或预先设定的结构拟合到数据上。然而，正如本书反复强调的那样，有很多时候我们不想带着 `prior hypothesized structure` 的想法来处理数据。相反，我们希望在没有关于该结构预先设定的假设想法的情况下，“发现”数据中的结构或形式。
我们已经看到，一般线性模型是广义线性模型的一个特例。然而，广义线性模型可以被视为一个更一般、更广泛的模型的一个特例，即 `generalized additive model` ([Hastie and Tibshirani, 1986](#ref.xhtml#re_CIT000144))，简称为“GAM”，在这种表述中，精确的函数形式并未 `a priori` 指定。在 GAM 中，322我们不再假设诸如 `sum_{j = 1}^{J} beta_j x_j` 的线性形式，即使在转换之后，而是将这一概念推广为 `sum_{j = 1}^{J} s_j(x_j)`，其中代替线性回归权重 `beta[j]`，`s[j]` 是未指定的函数，它们使用非参数 `scatterplot smoother`（或其他非参数形式，如核估计或样条）以及一种称为 `local scoring algorithm` 的迭代程序 ([Hastie & Tibshirani, 1986](#ref.xhtml#re_CIT000144)) 或 `iterative weighted least-squares` ([Fox, 2016](#ref.xhtml#re_CIT000106), p. 575) 来估计。读者可能还记得本书中之前的讨论，smoother 在提供对数据的紧密拟合方面很有用，而通常不会做出 `a priori` 的参数假设。
