
$$A = \\left\\lbrack \\begin{array}{l} {a\_{11}\\,\\,\\,\\,\\, a\_{12}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\, a\_{1n}} \\\\ {a\_{21}\\,\\,\\,\\,\\, a\_{22}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\, a\_{2n}} \\\\ {\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot} \\\\ {a\_{m1}\\,\\,\\,\\,\\, a\_{m2}\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\, a\_{mn}} \\\\ \\end{array} \\right\\rbrack = \\left\\lbrack \\begin{array}{l} x\_{1}^{'} \\\\ x\_{2}^{'} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ x\_{n}^{'} \\\\ \\end{array} \\right\\rbrack$$
Each column of the above matrix might represent a variable, for instance, IQ, GPA, etc., where on the right side of the equality are the corresponding variables `x[1]'` through `x[n]'` where ’ indicates transpose. Linear and matrix algebra is largely the study of different kinds of matrices and their behavior under a variety of conditions. We will see matrices “at work” throughout this book. The matrices we survey here and in this book are, relatively speaking, very small. In practice, matrices can have thousands or even millions of rows and columns. Indeed, in the age of “Big Data,” matrices can be so large that they can challenge the capacities of modern-day computing power.

### 2.37.6 Kernel (Null Space)
The kernel, or null space, of a linear transformation is the set of vectors such that `T(x) = 0`. For example, the vector `x132`
$$\\left\\lbrack \\begin{array}{l} {- 2} \\\\ {- 1} \\\\ {\\,\\,\\, 3} \\\\ \\end{array} \\right\\rbrack$$
is in the kernel or null space of $\\left\\lbrack \\begin{array}{l} {1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1} \\\\ {2\\,\\,\\,\\, - 1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1} \\\\ \\end{array} \\right\\rbrack$ as a result of $\\left\\lbrack \\begin{array}{l} {1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1} \\\\ {2\\,\\,\\,\\, - 1\\,\\,\\,\\,\\,\\,\\,\\,\\, 1} \\\\ \\end{array} \\right\\rbrack\\left\\lbrack \\begin{array}{l} {- 2} \\\\ {- 1} \\\\ {\\,\\,\\, 3} \\\\ \\end{array} \\right\\rbrack = \\left\\lbrack \\begin{array}{l} 0 \\\\ 0 \\\\ \\end{array} \\right\\rbrack$. That is, `T(x) = 0`. In words, the kernel of a linear transformation is the set of vectors that maps the transformation to zero.

### 2.37.7 Trace of a Matrix
The trace of a matrix `A`, denoted `tr(A)`, is the sum of elements along the main diagonal:
$$\\text{tr}\\left( A \\right) = {\\sum\\limits\_{i = 1}^{n}a\_{ii}}$$
(2.98)
where `a[ii]` denotes the values along the main diagonal. Traces only exist for square matrices. Among the properties of traces include the following:
$$\\begin{array}{l} {\\,\\,\\,\\,\\,\\,\\,\\,\\text{tr}\\left( A \\right) = \\text{tr}\\left( A^{T} \\right)} \\\\ {\\text{tr}\\left( A + B \\right) = \\text{tr}\\left( A \\right) + \\text{tr}\\left( B \\right)} \\\\ {\\,\\,\\,\\,\\,\\text{tr}\\left( {AB} \\right) = tr\\left( {BA} \\right)} \\\\ \\end{array}$$
The trace of a matrix multiplied by a constant `c` is also equal to that constant times the trace of the matrix, and we write,
`tr(cA) = c tr(A)`
All of these relations can be easily verified by the reader. Traces play a meaningful role in multivariate statistics. For instance, at times we are only interested in values along the main diagonal of a matrix such as when we wish to consider only variances in the covariance matrix and ignore covariances in the off-diagonal. Instead of communicating “sum all the diagonal entries of the matrix to get the total variance,” we simply say “compute the trace of the matrix.” The trace will be featured when we consider multivariate test statistics, for instance, later in the book.
The trace of a matrix in R can be obtained by `sum(diag())`. In Python, `matrix.trace()` in `numpy()` will generate the trace.

## 2.38 Linear Combinations
If there is one mathematical element or object that is common to virtually all of statistics and machine learning, it is that of a linear combination, which is defined quite simply as133
`l[i] = a[1]y[1] + a[2]y[2] + ... + a[p]y[p]`
(2.99)
The above is very generic. Usually in statistics we will see linear combinations with alternate identifiers. We use the symbol "`l[i]`" to stand for “linear combination.” We can see that a linear combination is actually a sum of products, `a[1]y[1]` through `a[p]y[p]` depending on how many variables we are summing. In the sum, `a[1]` through `a[p]` are scalars, which are usually real numbers. We can see that each variable `y[1]` through `y[p]` is being “weighted” by a given scalar. Our first impression here might be that variables receiving a greater weight have more “importance” (in some sense) than variables receiving less weight.
Where do we see linear combinations in statistics and machine learning? Everywhere! As an example, as the reader will surely already recognize, recall the simple linear regression model,
`y[i] = β[0] + β[1]x[1] + ε`
(2.100)
We can see that the above is nothing more than a linear combination, comprising of an intercept, `β[0]`, which is a constant scalar, and a variable `x[1]` that is weighted by the scalar `β[1]`, then trailing off with an error term, `ε`.
Linear combinations are utilized all over the place in ANOVA-type models as well. Consider the following linear combination between population means,
$$C\_{i} = c\_{1}\\mu\_{1} + c\_{2}\\mu\_{2} + \\cdot \\cdot \\cdot + c\_{J}\\mu\_{J} = {\\sum\\limits\_{j = 1}^{J}{c\_{j}\\mu\_{j}}}$$
(2.101)
The linear combination becomes a linear contrast when we impose the constraint that the weights, `c[1]` through `c[J]` must sum to 0, that is,
$$\\sum\\limits\_{j = 1}^{J}{c\_{j} = 0}$$
(2.102)
Another place where we see linear combinations in statistics is in principal components analysis, or “PCA” for short. In fact, a principal component is a linear combination of the sort,
`y[i] = a[1]x[1] + a[2]x[2] + ... + a[p]x[p]`
As we will see later in the book, the coefficients `a[1]` through `a[p]` will be values of the eigenvector resulting from the eigen decomposition performed to obtain the components, and the `x[1]` through `x[p]` will be variables on which the PCA is being performed.
The span of a set of vectors is the set of vectors in a vector space consisting of all linear combinations of those vectors, while the basis of a set of vectors is the number of linearly independent vectors that span the space, which means out of all vectors in the space, the basis is the minimal number of vectors that can, essentially, generate the space. There are typically lots of vectors in a vector space, but the basis vectors are those for which all those other “less important” vectors can be generated. This is why basis vectors are so important. The basis vectors are essentially the “boss” of the vector space.
Linear combinations are also featured in the committee machine of `boosting`, where one weights classifiers by scalars to generate a stronger learner from a series of weak learners. We feature a discussion of boosting later in the book.134

## 2.39 Determinants
Determinants play a central role in linear algebra and statistics. Determinants are only defined for square matrices. While determinants can be calculated for increasingly large matrices, they are most easily demonstrated for small matrices. For example, the determinant of a 2 × 2 matrix `A` can be easily computed as follows:
$$\\begin{array}{l} \\left| A \\middle| = \\left\\lbrack \\begin{array}{l} {a\_{11}\\,\\,\\,\\,\\, a\_{12}} \\\\ {a\_{21}\\,\\,\\,\\,\\, a\_{22}} \\\\ \\end{array} \\right\\rbrack \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\, = a\_{11}a\_{22} - a\_{12}a\_{21}} \\\\ \\end{array}$$
(2.103)
