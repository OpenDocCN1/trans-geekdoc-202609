
## 11.7 主曲线

其他更局部、或 *自下而上* 的方法本质上是“逐步”地通过数据云估计曲线（[Delicado, 2001](#ref.xhtml#re_CIT000081)）。这些更局部的方法通常更灵活，但方差更高，因为训练数据中的微小扰动会极大地影响曲线的位置。*局部主曲线* 是一种技术，它在一定的 *带宽* 内对曲线的片段进行建模。主曲线的概念在更高维度的工作中可以扩展为 *主曲面*。

### 11.7.1 主成分作为主曲线和主曲面的特例

我们现在可以看到，主成分如何可以被概念化为主曲线的特例，其中 “曲线” 在 `PCA` 中是线性的（[Sandilya & Kulkarni, 2002](#ref.xhtml#re_CIT000321)）。主曲线是更一般的过程。也就是说，虽然主曲线使用数据拟合曲线，主成分在某种意义上仍然使用数据来确定成分的放置，但 *曲线始终是一个超平面*。事实上，如果我们将曲线扩展到曲面，那么 `PCA` 就成为主曲线的特例，而主曲线又是主 *曲面* 的特例。这也从主曲线算法开始时拟合主成分这一事实中可以清楚地看出，直到它迭代以根据数据的排列成功拟合相应的曲线（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。

### 11.7.2 R 中的主曲线

包 `princurve`（[Hastie et al., 1989](#ref.xhtml#re_CIT000143)）可用于在 R 中拟合主曲线。我们采用包中的一个示例并绘制 resulting 曲线的图：427

```
> library(princurve)
> x <- runif(100, -1, 1)
> head(x)
[1] -0.81697944 -0.08094903 0.19879631 0.83944382 0.96564815 -0.92439484
```

上述代码生成了 100 个来自均匀分布的随机数据样本，范围为 −1 到 1。我们现在将通过加入 `x^2` 项来将数据转换为二次形式：

```
> x <- cbind(x, x^2 + rnorm(100, sd = 0.1)
+ )
```

我们现在在 `x` 上拟合主曲线并绘制结果，同时绘制表征拟合的线条和须线：

```
> fit <- principal_curve(x)
> plot(fit)
> lines(fit)
> points(fit)
> whiskers(x, fit$s)
```

输出生成了一个图（图 11.11），左侧有须线，其中须线对应于拟合曲线所依据的数据点的偏差。我们还可以将 `lowess` 平滑器拟合到数据上（右侧），从而显示实际数据点：

## 11.8 主成分分析作为编码器

*编码器* 是一个通用术语，其含义和内涵因具体上下文而有许多变化，但在最一般意义上，它是某种将数据或信息翻译或转换到另一种形式的功能，通常、最一般地，转换到具有期望属性的形式。编码器有两个部分，即 *编码* 元素和 *解码* 元素。428

*自编码器* 是一种特殊的编码器，它通过某种潜在路径进行编码，例如神经网络中的 *隐藏层*。如果自编码器具有多于一个的隐藏层，通常被称为 *深度自编码器*。*经典自编码器* 的关键特征是 *输入的数量与输出的数量相同*（[Alpaydin, 2020](#ref.xhtml#re_CIT000009)）。在新函数需要具有比输入函数更低维度的自编码器有时被称为 *欠完备自编码器*（[Goodfellow et al., 2016](#ref.xhtml#re_CIT000131)）。自编码器通常属于无监督技术家族。

在概念层面上，自编码器的一个经典例子是将手机数据编码到云端，然后将该数据解码回手机。这里的重要特征是，对于经典自编码器而言，数据的维度实际上并没有改变；它只是改变了 *形式*。如果我们将云中的数据限制为比原始手机数据具有更低的维度，这将是上述 *欠完备自编码器* 的一个例子。

更正式地，自编码器中的编码器可以表示为

`z` = `Encode`(`x`|`W`)

其中 `W` 是编码器的参数，`x` 是被编码的向量。解码器因此表示为

`x` = `Decode`(`z`|`V`)

其中 `V` 现在是解码器的参数，`z` 是被解码的向量。

自编码器可以是线性的或非线性的。例如，考虑图 11.12 中的两幅图像，一个是线性编码器，一个是非线性编码器，两者唯一的差别在于隐藏节点中函数的形式（即线性与非线性）。

## 11.9 神经网络和 PCA 作为自编码器

正如上面所述，编码器的经典案例是神经网络，其中映射不再是线性的而是非线性的。当我们回顾神经网络时，我们会看到神经网络并没有必然且本质上的非线性；从技术上讲，429 激活函数 *可以* 是线性的，如果选择为线性。然而，神经网络通常具有非线性激活函数，以努力捕捉数据中更复杂的配置。

这就是 `PCA` 发挥作用的地方。具有单个全连接隐藏层、线性激活函数和平方误差代价函数的自编码器与经典 `PCA` 紧密相关。本质上，被训练以学习恒等函数的神经网络就是自编码器的实际含义，因为我们根本不关心“改变”数据，我们只关心 *重构* 它（[Plaut, 2018](#ref.xhtml#re_CIT000290)），例如将手机数据传输到云端的例子。这听起来非常像 `PCA`！事实上，可以证明 `PCA` 中前几个成分形成的子空间几乎等于自编码器神经网络编码形成的向量，并且各自的重构误差大致相同（[Oken, 2017](#ref.xhtml#re_CIT000272)）。自编码器尽可能高效地重构数据，因此 `PCA` 可以被视为更一般自编码器思想的特例。然而请注意，`PCA` 本身并不执行降维。*我们* 通过选择解释大部分方差的前几个成分来实现降维。本质上，具有一个隐藏层单元的自编码器多层感知机（一个 *线性* 编码器）实现了 `PCA`。

`Sparse PCA` 也已被提出（Zou et al., [2004](#ref.xhtml#re_CIT000406)），它寻求通过惩罚来正则化成分模型中的系数，例如 `l1` 正则化。正如我们在下一章中将简要讨论的那样，类似的正则化惩罚也可以应用于因子分析，从而产生 *稀疏因子分析* 模型。
