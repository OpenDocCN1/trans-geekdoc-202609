
One question often asked about neural networks is whether they are parametric or nonparametric. In truth, they are a bit of both. For one, a user determining the number of nodes to have in a network is a parametric-like move. However, others regard the choice of the number of hidden neurons to include as essentially making neural networks nonparametric, especially as sample size increases. The debate as to whether neural networks are parametric or nonparametric is ongoing and is unlikely to be resolved anytime soon. This is due mostly to the wide variety of neural network possibilities and more precisely, how one operationalizes a specific given implementation of a neural network.560

We recall that the traditional statistical definition of parametric holds that assumptions are made about the underlying population from which the sample data was drawn. Some say that since neural networks typically require no parametric assumptions about distributions, means, variances, or even correlation of errors ([King, 1999](#ref.xhtml#re_CIT000186)), we can conclude that neural networks are essentially, and mostly, nonparametric models. The problem with this characterization, however, is that the user is able to freely impose conditions that do imply distributional assumptions to some extent, as well as through regularization techniques (such as weight sharing) that strongly resemble “parametric-like” actions. Hence, in the final analysis, neural networks can be nonparametric just as they can take on parametric features, depending on how the user sets up the network as well as any assumptions the user makes regarding the population to which the network is being applied.

In the end then, on the nonparametric to parametric spectrum, neural networks probably fall somewhere in between, and where exactly depends on the given neural network under consideration.

### 15.13.4 Including More Layers Leads to Increased Approximation on the Training Data

In general, adding more layers to a neural network results in increased approximation accuracy of the underlying function, at least on the training data. However, this may lead to poor generalizability on test data and hence, overfitting. Even simple neural networks do well in approximating functions. For instance, Hornik et al. ([1989](#ref.xhtml#re_CIT000158)) found that a neural network using arbitrary squashing functions could approximate virtually any function provided enough hidden units are supplied. The take-away here is that even though one can achieve accuracy by adding successive layers, the true test, as always, is on the test data, not the training data. By analogy once more, nobody cares much about how much you practiced your piano before the concert. They evaluate you based on your actual performance.

## 15.14 Neural Networks in Python

We can quite easily build a simple neural network in Python using `sklearn` for data on `X = [[0., 0.], [1., 1.]]` and response `y = [0, 1]` having two layers, where the first layer has five neurons and the second, two:

```
from sklearn.neural_network import MLPClassifier
X = [[0., 0.], [1., 1.]]
y = [0, 1]
clf = MLPClassifier(solver=‘lbfgs’, alpha=1e-5,
... hidden_layer_sizes=(5, 2), random_state=1)
>>> clf.fit(X, y)
Out[222]:
MLPClassifier(alpha=1e-05, hidden_layer_sizes=(5, 2), random_state=1,
   solver=‘lbfgs’)
```

The neural network has now been fit for classifying values on `y`.

```
clf.predict([[2., 2.], [-1., -2]])
Out[223]: array([1, 0])
```

We see that the new observations are classified into groups 1 and 0 respectively. The `alpha` parameter serves as a regularization term and helps avoid overfitting (try adjusting it and rerunning the model).561

For further details on the above example, see `scikit-learn.org` as well as [Müller and Guido (2017)](#ref.xhtml#re_CIT000258) for more examples using `MLPClassifier` as well as plotting decision boundaries. We encourage the reader to modify the layer sizes (`hidden_layer_sizes=(5, 2)`) as well in the above example to observe the corresponding impact on the ensuing class predictions.
