
## 1.9 基础率思维
假设你对一只11岁的雄性德国牧羊犬进行一次选择性超声检查。超声显示脾脏有肿块。作为狗主人，你当然担心肿块可能会破裂，但你并不知道这个肿块实际上存在了多久。这个肿块当然是脾脏上的异常，意味着这只狗不太可能出生时就带着这个肿块。它在狗的生命中的某个时间点出现了，但具体是什么时候，你并不知道。你缺乏一个超声 *基线* 来与当前数据进行比较。它是脾脏上的异常，但对一只11岁的德国牧羊犬来说，它是异常吗？可能不是。请考虑最近报道的一项关于6至13岁金毛寻回犬随机样本中脾脏肿块患病率的数据，该数据发现，惊人的52.8%的金毛寻回犬被发现患有脾脏肿块！此外，由于众所周知，脾脏肿块在老年德国牧羊犬中比年轻犬只更常见，因此老年犬（即 *条件分布*）携带脾脏肿块的比例可能接近70–80%。因此，在这只11岁犬的超声检查中发现脾脏肿块最有可能是 *预期* 的发现，而不是 *异常*。这里的要点是，很可能有许多狗携带脾脏肿块，其中许多可能是良性的，且这些肿块从未造成问题，或狗死于其他原因。的确，你在街上散步时看到的下一只11岁（或更年长）的德国牧羊犬 *很可能患有脾脏肿块*。超声检查发现肿块并不意味着它是异常的；*发现肿块并对狗进行超声检查可能才是真正的异常*。这就是我们所说的 *基础率*。
