
## 8.11 Linear Discriminant Analysis

As in traditional analysis of variance, we seek to minimize within-scatter and maximize between-scatter of the classes. The discriminant function guarantees that the separation is maximal. 334By “maximal” we mean that the function separates better on the given data than any other function we could have used in the parametric family (e.g., linear models). It accomplishes this by finding the projection that maximizes the ratio of the following, called the Rayleigh coefficient (sometimes called Rayleigh quotient):

$$\max\limits_{a} = \frac{a^{T}{Ha}}{a^{T}{Ea}}$$

(8.33)

where `H` and `E` are hypothesis and error matrices respectively, and `a` are coefficients or coordinates ([Hastie et al., 2009](#ref.xhtml#re_CIT000145), p. 116) of the estimated linear combination, or more precisely, linear discriminant function.

We can perform some algebra on (8.33) and obtain

`a`′(`H` `a`−`λ` `E` `a`) = 0

(8.34)

We seek to know the values of `a` (other than 0) that maximize values for `λ`. The solutions are found by

(`E`^(−1)`H`−`λ` `I`)`a` = 0

(8.35)

The solutions for `λ` and `a` are the corresponding eigenvalue and eigenvectors of the discriminant function(s). Large eigenvalues are associated with discriminant functions that are “important” (statistically, not necessarily substantively) and essentially doing a lot of “work” in separating classes. They are not variances in the context of LDA (in PCA, eigenvalues will be variances) and hence are best considered measures of “importance” of the given discriminant function. Smaller eigenvalues are associated with less important functions. Such measures of importance can help us in deciding how many functions to keep from our analysis. If an analytical solution for discriminant analysis is unavailable or a gradient descent solution is preferred, gradient descent can be performed where reduction of error occurs by taking partial derivatives of the error `E` with respect to coefficient weights `a`[1], `a`[2], ..., `a`[`p`],

$$\nabla_{a}E = \left[ \frac{\partial E}{\partial a_{1}},\frac{\partial E}{\partial a_{2}},...\frac{\partial E}{\partial a_{p}} \right]^{T}$$

(8.36)

where at each step, weights `a`[`i`] are updated,

$$\Delta a_{i} = - \eta\frac{\partial E}{\partial a_{i}}$$

where `η` is the learning rate, and hence new weights are computed by `a`[`i`] = `a`[`i`] + `Δ` `a`[`i`] ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)).335

## 8.12 Quadratic Discriminant Analysis

In the linear discriminant analysis above, recall that we assumed Gaussian distributions as well as equal covariance matrices among populations. More formally, we assumed that any given observation comes from a given class `k` such that

`x`[`i`] ∼ `N`(`μ`[`k`], `Σ`[`k`])

That is, we assume the covariance matrices `Σ`[`k`] are the same from population to population. What if, instead, we did not make this assumption, but allowed flexibility such that covariance matrices between populations were permitted to be unequal instead of constrained to be equal? Note our use of the word “flexibility” here, which means that instead of imposing the constraint/condition that the covariance matrices are equal, we will allow for unequal covariance matrices between populations and to incorporate these differences into our modeling. Allowing for this inequality has the effect of modeling a nonlinear or irregular (i.e., quadratic, in this case) decision boundary, and hence whereas classical LDA uses only class centroids to determine membership, QDA will use more than a single “prototype” (i.e., class centroids as well as covariance matrices). Indeed, LDA is known as a prototype classifier ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)).

When we allow for differing covariance matrices, we will then assign `x` = `x`[`i`] to the class for which the following function is the largest, where one can readily see the relevant substitutions,

$$\begin{array}{l} \left. \delta_{k}\left( x \right) = - \frac{1}{2}\left( x - \mu_{k} \right)T\Sigma_{k}^{- 1}\left( x - \mu_{k} \right) - \frac{1}{2}\log \middle| \Sigma_{k} \middle| + \log\pi_{k} \right. \\ \left. \, \,\, \,\, \,\, \,\, \,\, \,\, \,\, \,\, \,\, \,\, \,\, = - \frac{1}{2}x^{T}\Sigma_{k}^{- 1}x + x^{T}\Sigma_{k}^{- 1}\mu_{k} - \frac{1}{2}\mu_{k}^{T}\Sigma_{k}^{- 1}\mu_{k} - \frac{1}{2}\log \middle| \Sigma_{k} \middle| + \log\pi_{k} \right. \\ \end{array}$$

(8.37)

For a brief but excellent discussion of why the assumption of equal covariance matrices matters and the essential difference between linear vs. quadratic discriminant analysis, consult James et al. ([2021](#ref.xhtml#re_CIT000169)). Simplified, the argument essentially goes like this: for example, with `p` = 3 predictors, the covariance matrix looks as follows:

$$\sum{= \left[ \begin{array}{l} {\sigma^{2}\,\, \,\, \,\,{cov}\,\, \,\, \,\,{cov}} \\ {{cov}\,\, \,\, \,\, \,\, \sigma^{2}\mspace{6mu}\,\, \,\,{cov}} \\ {{cov}\,\, \,\, \,{cov}\,\, \,\, \,\, \sigma^{2}\,\, \,\,} \\ \end{array} \right]\,\,}$$

(8.38)

Notice that for `p` = 3 predictors, there are six parameters to estimate, or more generally, `p`(`p`+1)/2 parameters. That is, `p`(`p`+1)/2 = 3(3+1)/2 = 6. Even if we have `k` = 3 groups, we still have only six parameters to estimate since we are assuming `Σ`[`k`] is constant across groups. However, what if we designated a separate covariance matrix per group? This would imply that we have `p`(`p`+1)/2 parameters per group, which yields `k`*`p`(`p`+1)/2. Thus, for the `k` = 3 group problem, we will now have 3(6) = 18 parameters to estimate, which is a lot more than in the linear case. The assumption of equal covariance matrices induces linearity, which means the LDA model is less flexible since a great number of parameters are a priori fixed. That is, because of the equality condition, once we know one covariance matrix, we know them all. In the quadratic case, we are freeing this parameter to be different for each covariance matrix. Freeing and fixing parameters is a commonality in virtually all modeling. Nothing would stop us, for instance, from fixing or equating only a few parameters in the wider discriminant analysis framework, thereby building a more “customized” 336model. Presumably, such action would be based on theory or prior information. In the absence of such information, LDA or QDA are usually sufficient as “off the shelf” methods.

QDA then, is the more general model, where LDA can be conceptualized and shown to be a special case of QDA where the assumption of equal covariance matrices is imposed. The linear case is essentially a special case of the wider quadratic case in which quadratic terms are canceled due to shared covariance ([Bishop, 2006](#ref.xhtml#re_CIT000032)). Instead of `k`*`p`(`p`+1)/2 parameters to estimate in QDA, the linearity in `x` implies there to be only `k`*`p` coefficients to estimate since we only have to count a single covariance matrix in our estimation, not a number equal to however many groups we have on the response (in our earlier example, that number was 3). While QDA is more flexible, it has been found that classification rules for QDA usually require larger sample sizes than for its LDA counterpart and may also be more sensitive to parametric assumptions overall. For a discussion, see [Wald and Kronmal (1977)](#ref.xhtml#re_CIT000378). Indeed, it should be emphasized as well that maximal separation is not necessarily equivalent to maximal classification, as classification incorporates additional considerations (e.g., see [Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)).
