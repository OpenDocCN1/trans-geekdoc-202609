
我们已经非正式地讨论过基的性质。现在我们将该概念置于正式的框架下。`A basis is a set of linearly independent vectors in a vector space that spans the space`。从概念上讲，基本质上为子空间中的向量提供了一个“参考框架”。基的维数是构成该基的给定集合中线性无关向量的数量。更正式地说，基是一个`maximum linearly independent set`，如果我们再添加一个向量，该集合将不再线性无关。也就是说，如果在向量空间中存在一个包含 `n` 个向量的基，那么在该向量空间中就不可能存在包含超过 `n` 个向量的基（因为根据定义，基是 `maximum` 线性无关集）。这一最后的结果是 `Steinitz exchange lemma` 的推论（[Stillwell, 2016](#ref.xhtml#re_CIT000349)）。等价地，基是一个最小生成集，如果我们去掉一个向量，它将不再张成给定的子空间（[Hubbard & Hubbard, 2002](#ref.xhtml#re_CIT000161)）。150

### 2.54.1 正交基
回顾一下，坐标系的规范基向量生成了 `orthogonal basis`，并且由于每个向量的长度都等于 1，因此它同时也是一个 `orthonormal basis`。在许多程序中，目标是从可能尚未正交的基生成正交基。这是一个非常强大的思想，实际上解释了许多统计方法“在幕后”是如何运作的。

`Gram-Schmidt process` 是线性代数中用于寻找正交基的算法。程序的细节从应用的角度来看并不具有启发性。有关该方法的数学细节，请参阅几乎任何好的入门线性代数教材（例如，[Anton & Rorres, 2000](#ref.xhtml#re_CIT000013)）。Gram-Schmidt 过程意味着 `if you have a finite inner product space, an orthonormal basis can be constructed in that space`（[Garcia & Horn, 2017](#ref.xhtml#re_CIT000122)）。当我们回顾诸如主成分分析等方法时，这一结果将对我们大有裨益，在这些方法中，正如前面提到的，目标将是建立一组具有特殊属性的新基向量，并据此对观测数据进行投影。主成分分析本质上是将数据（线性）变换到新的基上。也就是说，它生成新的坐标以便可视化和解释原始数据。

基的非常概念或一般思想也可以变得更简单。远离矩阵和特征向量，并作为一个有帮助的不完美类比，考虑计算数字所依据的“基”。例如，表示数字 0.5 是相对于一个基（即“参考框架”），而将其表示为 ½ 是相对于另一个基（[Hubbard & Hubbard, 2002](#ref.xhtml#re_CIT000161)）。

## 2.56 微积分与优化
微积分通常被视为人类最伟大的、如果不是最伟大的智力成就之一。尽管据推测牛顿和莱布尼茨独立发现了它，但正如 151[Boyer (1959)](#ref.xhtml#re_CIT000043) 所展示的那样，在这两位数学巨人对概念（主要是 `limit` 概念）做出最后润色并发展出记号之前，类似微积分的思考早在几个世纪前就已经兴起。优化理论是统计学和机器学习的核心部分，使用微积分和其他数学来确定使函数最大化或最小化的值，也有着悠久的历史。

在我们关于基本统计学和数学回顾的这一最后部分，我们概述微积分和优化理论最重要的和最显著的元素，并预览这些元素在统计学和机器学习中的使用方式。

## 2.57 函数、近似与连续性
统计学和机器学习的大部分可以被视为 `approximating functions` 或其他数学对象的练习。但什么是近似？近似可以非常简单；例如，`π` = 22/7 是对 `π` 的近似，就像微积分中的微分和积分一样，正如我们将看到的，它们是近似过程的实现。当谈到近似时，我们才刚刚开始。很快就会意识到，统计学和机器学习中几乎所有东西，或者至少大多数东西都包含某种近似。

例如，当我们在某些数据上计算算术平均值时，这可以被视为对分布的中心趋势的近似，在某种意义上。当我们将该均值用作总体均值的估计量时，我们再次进行近似，在这种情况下是对某个参数的近似。拟合数据的最小二乘线或任何其他函数都是对真实潜在函数形式的近似。在实分析中，极限和收敛再次是近似出现的例子。例如，$\\lim\\limits\_{x\\rightarrow 5}f\\left( x \\right) = x + 3$ 表示极限为 8，但该数字只在 `in the limit` 出现。表达式 $\\lim\\limits\_{x\\rightarrow 5}f\\left( x \\right)$ 实际传达的是 `approximation` 的思想，即 `as x approaches 5, the value of the function goes to 8`。`We are converging on the value of 8 based on this limiting process.`

微积分的核心是寻找曲线的切线，其斜率称为 `derivatives`，以及通过积分找到曲线下面积的 `integrals`。回想一下，函数 `f`(`x`) 是将 `x` 输入规则或自变量后得到的结果集。对于一个规则要成为函数，对于 `x` 的每个值，`f`(`x`) 或 `y` 必须只有一个值。函数的定义域是给定函数可能的所有输入，而函数的 `codomain` 由所有理论上可产生的输出组成（即不仅仅是可能观察到的输出）。例如，对于简单的线性函数 `f`(`x`) = `x`，定义域和值域可以定义为实数集，记为 `ℝ`。

来自物理科学的函数示例包括牛顿定律等经典函数，`F` = `m` `a`，其中 `a` 是质量 `m` 在净外力 `F` 作用下的加速度，当然还有爱因斯坦的相对论，`E` = `m` `c`²，其中在光速 `c`² 恒定的情况下，能量 `E` 与物体质量 `m` 成正比。
