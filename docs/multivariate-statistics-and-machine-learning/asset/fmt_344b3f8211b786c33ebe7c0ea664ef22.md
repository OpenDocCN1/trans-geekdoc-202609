
where the function `h` is the activation function. Note that the rest of the expression, that of `x^Tβ`, is simply the generalized linear model component we surveyed earlier. Reduced to a linear model, `x^Tβ` is simply the systematic portion of a linear model with activation function set at unity, such that `h(x^Tβ)` = `1(x^Tβ)` = `x^Tβ`. In generalized linear models, this concept is referred to more generally as the link function. Hence, we see that while the generalized linear model is not as deep as neural networks typically are (as we will see later), both generalized linear models and neural networks can be said to feature the unifying notions of activation and link functions. This point is important, as the concept of activation functions is often regarded as “unique” to neural networks. However, they are much more general than they may at first appear. Indeed, prior familiarity with the generalized linear model allows one to better “see” the activation function featured in neural networks. The activation function, most generally, is simply the outer function that is being applied to the inner function, and is usually, though need not necessarily be, of nonlinear form. Both the generalized linear model and neural networks are unified by the concept of composite functions.

## 8.5 Multiple Logistic Regression

In our survey of logistic regression thus far, we have featured the one-predictor logistic model. As we did in generalizing simple linear regression to multiple, we can likewise generalize the logistic regression model to multiple logistic regression. Going from the one-predictor logistic model to the multiple logistic model is straightforward,

$$\begin{array}{l} {\log\left\lbrack \frac{p\left( x \right)}{1 - p\left( x \right)} \right\rbrack = \log\left\lbrack e^{\beta_{0} + \beta_{1}x + \cdot \cdot \cdot + \beta_{p}x_{p}} \right\rbrack} \\ {\,\, \,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\,\, = \beta_{0} + \beta_{1}x_{1} + \cdot \cdot \cdot + \beta_{p}x_{p}} \\ \end{array}$$

(8.10)

where, as before with the one-predictor model, we can write `p(x)` as follows:

$$p\left( x \right) = \frac{e^{\beta_{0} + \beta_{1}x + \cdot \cdot \cdot + \beta_{p}x_{p}}}{1 + e^{\beta_{0} + \beta_{1}x + \cdot \cdot \cdot + \beta_{p}x_{p}}}$$

(8.11)

Interpreting coefficients in a multiple logistic setting is analogous to interpreting them in a multiple regression setting, meaning that coefficients must be interpreted relative to the model in which they appear. That is, each coefficient is interpreted in the context of other coefficients. For instance, the following interpretation for `β[1]` would be incorrect:

> For a one-unit increase in `x[1]`, we expect the logit to change by `β[1]` amount.

The correct interpretation is the following:

> For a one-unit increase in `x[1]`, we expect the logit to change by `β[1]` amount, given the other predictors in the model.

As always, recall that when interpreting effects in a model, we are never, ever, interpreting them in a vacuum; they always occur or exist in the context of the other variables in the model. This is one of the key features to remember about virtually all statistical modeling as a whole, or any 316narratives for that matter, that there is always a context to the model you are interpreting, no matter how simple or complex that model may be. The trailing phrase “given the other predictors in the model” or “given the context of the model” is not optional in interpretation; it is essential for a correct interpretation of modeling results. Even in the case of a simple logistic regression with only a single predictor, the trailer “given the context of the model” is still required, even if that context is of no additional predictors. Interpreting univariate or bivariate effects in a multivariate or multivariable model without reference to context is equivalent to misinterpreting effects in the model. All models, as is true of all narratives, are context-dependent.

## 8.6 Poisson Regression

While logistic regression assumes the response is binary, Poisson regression assumes the response has a Poisson distribution, which may or may not be skewed depending on the value for `μ`. A Poisson regression is often used when the response variable is a count. The distribution of a Poisson variable is the following:
