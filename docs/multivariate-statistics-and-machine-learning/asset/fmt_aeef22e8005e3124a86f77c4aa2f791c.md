
## 5.12 Principal Components Regression

A more extensive discussion of principal components analysis (PCA) is reserved for later in the book where we discuss dimension-reduction techniques and manifold learning in more detail, devoting part of an entire chapter to the PCA technique. For now, we only survey the method briefly to learn how it serves the PCA regression technique.

Principal components analysis derives *orthogonal linear combinations* of the variables equal to the number of variables, such that successive linear combinations account for less and less variance in the observed variables. Recall that a linear combination is defined as248

`l[i] = a[1]y[1] + a[2]y[2] + ... + a[p]y[p]`

That is, a linear combination is a *weighted sum of products*, where `a[1]` through `a[p]` are the weights applied to observed variables `y[1]` through `y[p]`. For our data on `x[1]`, ..., `x[p]`, the linear combination becomes

`z[i] = a[1]x[1] + a[2]x[2] + ... + a[p]x[p]`

where now `z[i]` is the name of the linear combination and `x[1]` through `x[p]` are the observed variables. A principal component is a unique kind of linear combination such that the weights `a[1]` through `a[p]` correspond to values of allied eigenvectors extracted from an eigen analysis performed on the covariance or correlation matrix of variables `x[1]`, ..., `x[p]`. Hence, if we denote the weights `a[1]` through `a[p]` by `e[1]` through `e[p]` to represent eigenvector weights, the first principal component is defined as

`z[1] = e[1]x[1] + e[2]x[2] + ... + e[p]x[p]`

(5.31)

The first principal component accounts for the most variance in the observed variables. The second principal component accounts for the second-most variance in the observed variables but is orthogonal to the first. The goal of PCA is to capture as much variance in the first few components as possible to account for the variance in the set of observed variables. *Principal components regression* uses the first few principal components as predictors in a least-squares sense. In this way, the number of components retained in the `PCR` (*principal components regression*) can be likened to a *tuning parameter* ([Boehmke & Greenwell, 2020](#ref.xhtml#re_CIT000033)). As we will see when we survey methods such as ridge and lasso regression, tuning parameters are useful in controlling the balance between the variance and bias of a statistical learning method and are useful in selecting a “best” model from a wider set of possibilities.

Principal components regression, useful as it may at first appear, makes one important assumption that may with empirical data not always hold. By regressing `y` on the set of components, *we are implicitly assuming that the directions of most variance in* `x[1]` *through* `x[p]` *are those same directions that are associated with* `y`. While this assumption may not always hold, it is often considered a useful approximation for most data and PCA regression often gives reasonable results ([James et al., 2013](#ref.xhtml#re_CIT000168)). As more precisely stated by [Izenman (2008, p.132)](#ref.xhtml#re_CIT000167):

> The extraction of the principal components is accomplished without any reference to the output variable `Y`, we have no reason to expect `Y` to be highly correlated with any of the principal components, in particular those having the largest eigenvalues. Indeed, `Y` may actually have its highest correlation with one of the last few principal components or even the last one.

Or, as even better elucidated by [Artigue and Smith (2018, p. 9)](#ref.xhtml#re_CIT000014):

> The promise of principal components regression is that it is an efficient way of selecting a relatively small number of explanatory variables from a vast array of possibilities, based on the correlations among the explanatory variables. The problem is that the eigenvector weights on the candidate variables have nothing to do with their relationship to the variable being predicted. Mildly important variables may be given larger weights than important variables. Nuisance variables may be given larger weights than the true explanatory variables. The coefficients of the true explanatory variables may be given the wrong signs.249

Even though principal components regression provides a simple way to use less than the full spectrum of predictors for the problem, it should *not* be regarded as a feature or variable selection method because of the lack of guarantee that the directions that best explain the predictors will also be the best directions to use for predicting the response. In fact, it is entirely possible to have variables only weakly related to the response, yet as the number of these variables increases, `R-squared` of 1.0 is nonetheless approached. In general, adding useless predictors, though resulting in an increase in dimensionality, will do so at the risk of overfitting and an increase in test error.

A more in-depth discussion of the above problems can be found in [Jolliffe (1982)](#ref.xhtml#re_CIT000408). The key takeaway point is that *though PCA regression is guaranteed to derive orthogonal components that maximize variance in the set of predictors, this will not necessarily be equivalent to maximizing* `R²` *between* `y` *and those components that account for the most variance in* `x[1]` *through* `x[p]`. For this reason, PCA regression should not be considered a variable selection technique ([James et al., 2013](#ref.xhtml#re_CIT000168)) in the same spirit as techniques such as *best-subsets* or *forward regression*. PCA regression is also not scale-invariant, and hence standardization of predictors is typically (though not *always*) recommended.

### 5.12.2 PCA Regression and Singularity

As we have seen, PCA regression can be useful in situations where we wish to reduce the dimensionality of the predictors before using resulting components as predictors of a response. More to the point, PCA regression can be useful when predictors are highly correlated with one another.

There is another instance where PCA regression may be especially useful, and that is when the matrix of predictors, `X`, is *singular* and hence *ill-conditioned*. Recall that for a singular matrix `X`, it is implied that one row or column is a linear combination of one or more rows or columns. This condition always implies that the determinant of the matrix will equal zero, which implies the inverse of `X` cannot be computed. In such a case, one can substitute a *generalized inverse* when computing least-squares estimates. There are many generalized inverses, but the most common is that of the *Moore-Penrose inverse*, the use of which will yield the generalized inverse regression estimator ([Izenman, 2008](#ref.xhtml#re_CIT000167)).

The number of components to keep in PCA regression on the side of `X` can be determined by *Kaiser’s rule*, which says to keep all those components with eigenvalues greater than 1 for the correlation matrix, or by using a cross-validation technique ([Wold, 1978](#ref.xhtml#re_CIT000390)). The substantive meaning of derived components can also play a significant role in their selection contingent on whether or not the scientific nature of components matters to the scientist.
