
2. *第一个* *主成分，如前所述，是方差最大的那个*。然而，这并不必然意味着它是*最感兴趣*的成分。没有保证第一个主成分在理论上比第二个或第三个等更有趣。它仅在最大化方差的意义上是“最好”的成分。其他成分可能基于它们与其他变量的相关性或在随后的回归分析中的表现而被优先考虑，例如，或甚至在聚类分析中如何聚类（[Marden, 2015](#ref.xhtml#re_CIT000239)）。解释的方差只是用于处理成分“重要性”或“相关性”时应使用的一项标准。

3. *主成分在大多数情况下会生成与原始变量一样多的成分*。PCA 在大多数情况下必然会生成成分。然而，绝对没有要求所获得的成分是有意义或有用的。你对变量运行 PCA 并获得成分的事实并不是一个“发现”。它是一种数学上的*必然性*，早在你执行成分分析之前就已存在。是否认为这种转换在某种意义上是“有趣的”，很可能取决于你的实质性科学甚至数学哲学。也就是说，如果成分现在在实质上看起来“毫无意义”，数学转换是否仍然意味着它们无论如何都是“真实的”？这不是一个统计问题，而是*数学哲学*的问题。如果你认为数学对应于“现实”，那么无论你能否“理解”成分与否，你仍可能认为它们“存在”。这是一个非常有趣的话题，但远超出本书的范围。

4. *与 #3 相关，成分的好坏或有趣程度仅取决于所进行成分分析的输入变量*。因此，首要且主要关注的问题是将 PCA 应用于包含你希望分析的所有变量的变量集合。如果数据集不有趣或你遗漏了变量集合中的重要变量，对此类数据进行 PCA 很可能有限制，或者你的成分分析会被错误设定。410

5. *PCA 生成的特征值相等或接近相等是可能的，即使不太可能*。此外，总体特征值通常不完全等于样本生成的特征值。特征值的推断检验存在（例如，[Camargo, 2022](#ref.xhtml#re_CIT000052)），但很少使用。已开发出检验，通常需要正态性假设（[Collins & Chatfield, 1980](#ref.xhtml#re_CIT000057)；Peres-Neto et al., [2005](#ref.xhtml#re_CIT000285)）。

6. PCA 中得出的成分更依赖于相关矩阵中相关性的*比率*，而非相关性本身。正如 Collins 和 Chatfield 所指出的（[1980](#ref.xhtml#re_CIT000057), p. 67），将所有非对角相关性除以大于 1 的常数可揭示特征值发生变化但特征向量，即成分本身，并未发生变化。

7. PCA 并未评估变量的维度；它评估的是变量的*线性维度*。如果数据是非线性的，这相当于底层流形是非线性的，那么经典 PCA 将无法捕捉这种非线性。如后所述，诸如 *kernel PCA* 之类的技术在揭示非线性底层流形方面会更有效。

8. 与前一点 (#7) 相关，PCA 在最一般意义上是一种*流形学习*，其中假设流形是线性的。非线性技术可能更有效地揭示真实流形。*使用 PCA 无法揭示有意义的成分绝不应被视为变量底层不存在更深维度性的确凿证据*。这种有趣的维度性确实可能存在，但其形式可能是*非线性*的，而 PCA 在揭示这种结构方面会受限。

## 11.3 独立成分分析

在刚刚讨论的经典 PCA 中，我们要求成分是线性函数且彼此正交。我们寻求将观测变量矩阵的秩降为更小的秩，但该秩解释了原始变量中大部分方差，最好是在前几个成分中。成分彼此正交这一事实是主成分分析的一个关键特征。

在*独立成分分析*（ICA）中，我们要求成分（即*潜在变量*）相互独立且通常是非高斯的（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。也就是说，ICA 的目标是找到非高斯数据的线性表示，使得成分在统计上独立，如果不能完全独立，则*尽可能独立*。*这与仅仅要求正交性是不同的要求*。正如 [Jolliffe (2002)](#ref.xhtml#re_CIT000174) 所指出的，经典 PCA 与独立成分分析之间的联系，或许令人惊讶地，并不那么强，ICA 与因子分析的关系更密切，而不是与成分分析。

ICA 模型（[Izenman, 2008](#ref.xhtml#re_CIT000167)）可表述如下：

`X = f(S) + e`

(11.7)

其中 `X` 是随机观测“显性”变量的向量，`S` 是源的不可观测随机向量变量，其成分是独立的潜在变量，每个均值为零，而 `e` 是表示噪声的随机向量，例如在对 `X` 进行的测量中。关键点在于源的独立性意味着每个单独的源信号被假设由一个与任何其他源信号无关的过程生成（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。如果没有 `e`，该模型被称为*无噪声 ICA*。当包含 `e` 时，我们将该技术称为*有噪声 ICA*。411

在 ICA 中，投影点 `P` 是原始数据 `D` 与解混矩阵 `M^(u)` 的乘积所得，其中混合矩阵等于 `M`。因此，`P = D M^(u)`。ICA 本质上寻找使坐标（近似）独立的数据旋转。这对于来自多元正态分布的样本的所有旋转必然成立（[Venables & Ripley, 2002](#ref.xhtml#re_CIT000376), p. 313），因此 ICA 对于这种“平凡”情况不会最感兴趣。相反，ICA 对于来自非正态分布的数据最有价值和最有用，也就是*非高斯*数据。

### 11.3.1 主成分与独立成分分析

独立成分分析与 PCA 有何关系？它们之间应该存在某种关系，事实上确实存在。PCA 可以被视为 ICA 的*一种特殊情况*，其中 PCA 产生正交成分，而 ICA 生成独立成分。

Jolliffe（[2002](#ref.xhtml#re_CIT000174), p. 396）最能概括 PCA 与 ICA 之间的差异：

> PCA 的主要目标是方差的逐次最大化，而正交性和不相关性约束是附加的，其目的是确保不同的成分测量的是不同的事物。相比之下，独立成分分析（ICA）以成分的“分离”为主要目标。ICA 从这样一种观点出发：不相关性相当有限，因为它只考虑缺乏线性关系，而理想情况下成分应统计独立。这比不相关性更强的要求，*两者仅在正态（高斯）随机变量的情况下等价* \[emphasis added\]。……这与因子分析的设定更接近，而 ICA 正是对此“模型”的推广。
