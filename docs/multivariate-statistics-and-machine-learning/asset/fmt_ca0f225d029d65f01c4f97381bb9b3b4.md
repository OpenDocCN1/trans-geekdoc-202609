# 0.4 Who Should Read This Book?

This book was written for a course in multivariate statistics *and* machine learning for the scientist or practitioner. It was also written for specialists in the area who may benefit from some of the teaching and insight regarding how topics are presented and linked, the “undertones” that exist connecting the various methodologies that the reader may not have been aware of when originally studying and learning these techniques for the first time. The book is a “*big picture*” perspective on these fields. If the applied statistics course for scientists is being taught in room one and the machine learning course in room two, this book is the hallway in between.

## 0.4.1 Textbook Limbo

Having been an instructor of a multivariate course for the better part of twenty years, I have become frustrated in trying to find the ideal resource that reflects today’s mix of *multivariate*, *machine learning*, and *data science* more generally. Even within the realm of traditional multivariate texts, some books feature a discussion of factor analysis and latent variable models while others do not. Many traditional texts on multivariate analysis are quite rigorous in their development of say, *principal components analysis*, yet leave out discussion of these important factor-analytic and latent variable models of which entire books and monographs have been written in both applied statistics and psychometrics. On the other hand, modern machine learning texts are virtually obligated to discuss factor-analytical models under the more general rubric of *manifold learning*. While it is not irregular for instructors to use several different books in teaching a course, it can be difficult for introductory courses to suddenly switch gears from one text to another simply because one text omits an important and fundamental methodology. Personally, I have always found it virtually impossible to find the “right text” for my more advanced multivariate courses.

The current text, perhaps unrealistically, attempts to “cover it all” to some extent, so that upon completion of the book the student will have their *foot in the door* into this “modern empire” of statistics, machine learning, data science, etc. After studying this book, the reader should have a fair idea of *what’s going on* in multivariate statistics *and* machine learning and be able to hopefully use this book as an entry point into the literature. The book can also be used as a reference or refresher for researchers already somewhat familiar with the material.

Demonstrations using software (`R` and `Python`) are provided to get users *started* (and *started only*) in applying these techniques to their own data. Most of the software applications are relatively easy and straightforward, adapted directly from `R` packages and `Python` sources so the user can follow up with these resources to learn more about the cited examples. They are on familiar “toy” data sets and not some arcane data sets that would be difficult to follow up on for further study, demonstrations, and exploration.

By featuring examples adapted from `R` packages and online `Python` sources it hopefully encourages students and readers to more fully “explore” the source’s capabilities. In most cases, the examples we feature in the book are mere “snapshots” and incomplete demonstrations of what the package or `Python` library is capable of simply to get the proverbial “ball rolling.” In this way, it is hoped that the book serves as a “gateway” for either further class or independent learning and guides students in the direction of the skills required by today’s data scientists, which includes adapting to new packages and libraries almost *daily*. Upon encountering a novel data problem, 7the phrase “*I think `R` or `Python` has a package or library for that*,” becomes a common thought in tackling the data or research problem of the day. *Learning new things daily is what data craft is all about*.

To reiterate and emphasize, it is extremely important to realize that these demonstrations and examples are only meant to provide the reader with, once more, a *foot in the door* into these applications in getting started. The code is but a mere gateway to so much more that is *possible*. Statistical analysis and machine learning isn’t a *cookbook*, and very few if any textbook examples historically ever map on one-to-one to what is actually needed in *real research*. There are very good reasons why most `R` packages are upward of well over 100 pages, some well over 300–400! The skill of the data scientist is being able to be *creative*, *flexible*, and posessing a keen awareness of where to “dig” to follow up on the fairly trivial examples presented in this book and others. *Data can be a mess*. *Modeling it can be even messier*. In practice, each data set is unique and often requires a unique approach. Software demonstrations in this book are merely “glimpses” into the computational aspects and serve to demonstrate some of the theoretical development in the book.
