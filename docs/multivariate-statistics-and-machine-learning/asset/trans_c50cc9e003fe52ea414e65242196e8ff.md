
在迄今为止对决策树的调查中，我们只讨论了回归树。决策树不出所料，也适用于分类。分类树用于预测 *定性* 或 *分类* 响应，而不是像刚才讨论的回归树那样预测 *连续* 响应。与回归树一样，*递归二分* 用于构建树。然而，在评估树的质量时，我们不能使用 `RSS` 作为需要最小化的量，因为 `RSS` 仅适用于连续度量。

用什么来代替 `RSS` 估计误差率？分类树的替代方案是 *分类误差率*：

`E` = 1 − max[*k*](`p̂[m k]`)  
(10.2)

其中这里 `p̂[m k]` 是在树的第 *m* 个区域中（在 *训练* 数据上）被归类为 `k` 所表示的类别的观测值的比例（James et al., [2013](#ref.xhtml#re_CIT000168)）。因此，(10.2) 是给定类别中出错的观测值的比例。分类误差率并不是衡量树质量的完美指标，然而。分类误差率的一个问题是它作为生长树的度量不够敏感（[James et al., 2013](#ref.xhtml#re_CIT000168), p. 312）。也就是说，它有点太“粗糙”了。我们需要其他度量来帮助评估树的构建。这两个度量是 *基尼指数* 和 *偏差*，我们现在讨论它们。

### 10.3.1 基尼指数

*基尼指数* 是一种可用于替代或补充分类误差率的度量，并且可以在回归树上下文中取代残差平方和。它是 *节点纯度* 的度量（也常称为节点 *不纯度*），定义为

$$G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}$$  
(10.3)

它是对 `k` 个类别的总方差的度量，其中请回忆 `p̂[m k]` 是第 `m` 个区域中来自第 `k` 个类别的训练观测值的比例。作为类别间总方差的度量，该指数在 `p̂[m k]` 值越接近 0 或 1 时取值越小。也就是说，当 `p̂[m k]` 等于 0 时，`G` 减少为

$$\begin{array}{l} {G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}} \\ {\,\,\,\, = {\sum\limits_{k = 1}^{K}{0\left( 1 - 0 \right)}}} \\ {\,\,\,\, = 0} \\ \end{array}$$

在另一极端，当 `p̂[m k]` = 1 时，则375

$$\begin{array}{l} {G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}} \\ {\,\,\,\, = {\sum\limits_{k = 1}^{K}{1\left( 1 - 1 \right)}}} \\ {\,\,\,\, = 0} \\ \end{array}$$

基尼指数的较小值表明节点主要包含来自单一类别的观测值（[James et al., 2013](#ref.xhtml#re_CIT000168)）。方差在 `p̂[m k]`→0.5 时在类别间达到最大，等于 0.5(0.5) = 每个类别 0.25。任何偏离此最大值，例如 0.4(1 − 0.4) = 0.24 都会产生较小的乘积，因此对总和的方差贡献更少（[Bishop, 2006](#ref.xhtml#re_CIT000032)）。例如，对于 `p̂[m k]` = 0.1，给定的乘积为 0.1(0.9) = 0.09，这非常小，表明类别间的方差几乎为零。这再次说明为什么 `p̂[m k]`→0.5 最大化类别的方差。

基尼指数的替代方案是 *交叉熵* 或 *偏差*，定义为

$$D = - {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\log{\hat{p}}_{mk}}}$$  
(10.4)

请回忆 `p̂[m k]` 介于 0 和 1 之间，这意味着 − `p̂[m k]`log `p̂[m k]` 必须大于或等于 0（James et al., [2013](#ref.xhtml#re_CIT000168), p. 312）。当 `p̂[m k]`′*s* 接近 0 或 1 时，熵取接近 0 的值。也就是说，与基尼指数的情况一样，较小的 `D` 表明整体 *节点纯度*（[James et al., 2013](#ref.xhtml#re_CIT000168)）。熵可以解释为编码实例或观测值的类别代码所需的最小信息位数（[Alpaydin, 2020](#ref.xhtml#re_CIT000009)）。

> *基尼指数和熵彼此非常相似。两者都试图提供类别间存在多少方差的度量。它们都可以被视为节点纯度的度量。*
