
Having briefly surveyed the path analysis model, we now provide an overview of the confirmatory factor analysis model. Recall once more that the common factor analysis model of the previous chapter was an *exploratory* one, meaning that the user typically entered a number of variables into the model without presumably any hypothesis as to how many factors might be present in the data or what the nature of those factors may be. On a technical level, this translates to there being fewer constraints imposed on the model and any that were included were implicit and part of the model’s “default” parameterization. The user did not typically fix, free, or constrain any parameters at will. Of course, a user with some computational experience could alter the exploratory model and re-parametrize it, but the point we are making is that classic factor analysis is generally not amenable to such *precise* model specification. It is an “out-of-the-box” model and we simply run it on data to see what comes out.

In contrast to the exploratory model, the confirmatory factor analysis model is one in which the user typically has, *a priori*, a theory as to how many factors may result from the analysis and which observed variables should load onto which factors. That is, the researcher comes to the model with a *theory* already in mind and is ready to specify the model in great detail in terms of what parameters get estimated, which do not, and other aspects of the model. In this way, the user has much more freedom in modeling because she can essentially fix and free parameters in line with the theory she wishes to evaluate. *Confirmatory factor analysis yields all the power and freedom of modeling to the user*. Of course, one can fix and free parameters in other statistical models as 485well and hence, this idea is not unique to CFA models or the wider structural equation modeling framework that generalizes them. For example, in analysis of variance (ANOVA), not testing an interaction term is essentially fixing that parameter estimate to 0, just as not modeling a quadratic term in polynomial regression is implicitly fixing that parameter estimate to 0. Statistical modelers are *implicitly* fixing parameters every day, even if they are only running a simple `t`-test! In an SEM model, however, the fixing and freeing of parameters is a prerequisite to even running the model and allows greater specification of the user’s theory.

A simple one-factor confirmatory factor analysis model has the same model equation as we saw in the previous chapter for exploratory factor analysis:

`x = Λ f + ε`

(13.1)

where as before, `x` are observed variables, `f` are latent factors, `Λ` is a loading matrix, and `ε` is a matrix of errors. The number of factors in `f` is prespecified by the researcher. The following is a model with a two-factor structure hypothesizing factors `f[1]` and `f[2]`:

```
$\\begin{array}{l} {\\,\\,\\,\\text{x}\\,\\,\\,\\,\\,\\,\\text{=}\\,\\,\\,\\,\\Lambda\\,\\,\\,\\,\\,\\,\\,\\,\\text{f}\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\text{+}\\,\\,\\,\\,\\varepsilon} \\\\ {\\left\\lbrack \\begin{array}{l} x\_{1} \\\\ x\_{2} \\\\ x\_{3} \\\\ x\_{4} \\\\ \\end{array} \\right\\rbrack = \\left\\lbrack \\begin{array}{ll} \\lambda\_{11} & 0 \\\\ \\lambda\_{21} & 0 \\\\ 0 & \\lambda\_{32} \\\\ 0 & \\lambda\_{42} \\\\ \\end{array} \\right\\rbrack\\left\\lbrack \\begin{array}{l} f\_{1} \\\\ f\_{2} \\\\ \\end{array} \\right\\rbrack + \\left\\lbrack \\begin{array}{l} \\varepsilon\_{1} \\\\ \\varepsilon\_{2} \\\\ \\varepsilon\_{3} \\\\ \\varepsilon\_{4} \\\\ \\end{array} \\right\\rbrack} \\\\ \\end{array}$
```

which yields the following equations:

```
$$\\begin{array}{l} {x\_{1} = \\lambda\_{11}f\_{1} + 0f\_{2} + \\varepsilon\_{1}} \\\\ {x\_{2} = \\lambda\_{21}f\_{1} + 0f\_{2} + \\varepsilon\_{2}} \\\\ {x\_{3} = 0f\_{1} + \\lambda\_{32}f\_{2} + \\varepsilon\_{3}} \\\\ {x\_{4} = 0f\_{1} + \\lambda\_{42}f\_{2} + \\varepsilon\_{4}} \\\\ \\end{array}$$
```

Note that only `x[1]` and `x[2]` are hypothesized to “load” on `f[1]` as reflected by the loading matrix `Λ` constraining the loading estimates for `x[3]` and `x[4]` to 0. The key distinction in the confirmatory model in comparison to the exploratory model of the previous chapter is in precisely specifying the nature of the factor matrix, `f`, and hence attempting to “confirm” a very *specific* hypothesized factor structure through the precise specification of parameters.

## 13.6 Structural Equation Models

Having briefly surveyed path analysis and confirmatory factor analysis, we are now ready to survey the full structural equation model. The full structural equation model is given by

`η = B η + Γ ξ + ζ`

(13.2)

where `η` is a latent endogenous vector, which we note appears on both sides of the equation. Contrary to classic linear models in which a variable only appears on one side of the equation, in the SEM model, `η` are allowed to predict one another, which is why we see it both on the left side and right side of the model (in `B η`). This parameterization allows a latent variable to predict another latent variable in an SEM model. The exogenous variables are in the vector `ξ`, weighted by 486coefficients in `Γ`, and `ζ` is a vector of latent errors, also known as *disturbances* in the SEM literature. All parameter estimates for the model are contained in matrices `B` and `Γ`.

Assumptions for the model in (13.2) include `E(η) = 0`, `E(ξ) = 0`, and `E(ζ) = 0`, as well as latent errors being uncorrelated with latent exogenous variables. For further details on this classic SEM parameterization, see [Bollen (1989)](#ref.xhtml#re_CIT000037).

### 13.6.1 Covariance Modeling

Recall that in prior methods surveyed in this book, the goal was essentially to reproduce some function of the data. In regression, we sought to reproduce the response `y` by estimating predicted values, `ŷ`. In SEM and covariance models in general, the goal is also to reproduce some function of the data, but this time, it is the *observed covariance matrix* that we will attempt to reproduce by choosing which parameters to estimate and which to keep fixed. This is not that different from the factor analysis model in which the end goal, mathematically, was to regenerate the covariance or correlation matrix via specification of the model; *the “better” the model, the more precisely we should be able to reproduce the covariance or correlation matrix*.

Covariance modeling comprises an enormous class of models. [Bollen (1989)](#ref.xhtml#re_CIT000037) has shown that from the following simple equality, a whole host of models can be deduced as special cases,

`Σ = Σ(θ)`

(13.3)

where the above reads that `Σ` (the covariance matrix) is a function of model parameters contained in the vector `θ`. That is, `Σ(θ)` is the *implied model-based covariance matrix* that regenerates the observed covariance matrix, `Σ`. Choosing which parameters to *fix* and which to *free*, along with other model specification considerations, will determine how well the model fits the data. Note once more that this is exactly the same thing we do in other models from regression to ANOVA and beyond; the only difference is that such specifications in those models, at least the finer ones, are often not made as *explicit*. The equality in (13.3) is far-reaching, and special cases of it at their most fundamental level simply require decisions made by the user in conjunction with the types of variables and data they are working with in any given context. As Bollen ([1989](#ref.xhtml#re_CIT000037), p. 2) summarizes:
