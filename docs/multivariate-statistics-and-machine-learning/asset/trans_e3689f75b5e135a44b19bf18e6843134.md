
我们迄今为止考虑了一个非常简单和基础的神经网络，使得当激活函数为恒等函数时，它模仿了多元回归。我们现在考虑一个更复杂的神经网络，它更能代表实际在实践中547跨科学领域使用的神经网络。我们即将讨论的神经网络在先前调查的前馈网络的单层之上具有一层隐藏单元。增加一层或多层会产生 *多层前馈网络*，如图 [图 15.9](#c15.xhtml#f15.9) 所示。

正如我们在将神经网络与其他统计方法进行比较时稍后会强调的，神经网络的分层概念以及其深度可以被视为对网络原始输入的又一种 *基展开*（[Hastie 等，2009](#ref.xhtml#re_CIT000145)）。然而，这些参数并不是像我们在书中前面调查的基展开方法（例如，回归样条）那样被施加或先验确定的。相反，它们是通过有效地 *从数据中学习* 得出的。这些网络中 *深度* 的概念在历史上受到了 *联结主义* 思想的影响，联结主义本质上认为，虽然单个神经元单独可能无法完成太多，但多个神经元共同作用和相互作用可能表现出智能行为（[Goodfellow 等，2016](#ref.xhtml#re_CIT000131)）。

正如我们对单层网络所做的那样，我们将拆解多层网络。在 [图 15.9](#c15.xhtml#f15.9) 中的网络中，给定的隐藏单元 `h[i]` 等于输入 `x[i]` 与权重 `β[i]` 相乘的乘积之和：

$$h\_{i} = {\\sum\\limits\_{i = 1}^{p}{\\beta\_{i}x\_{i}}}$$

多层前馈网络中的隐藏层由排列在连续层中的变量组成，它们传统上被称为 *节点*、*神经元* 或 *处理单元*（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。称它们为“节点”可能是最通用的，因为神经元和“处理单元”意味着数学本身无法做到的东西548。我们可以在 [图 15.9](#c15.xhtml#f15.9) 中看到，有两个进行计算的层，即 *隐藏层* 和 *输出层*。有四个输入节点和两个输出节点，隐藏层中有三个节点。然后该网络可以指定用于回归或分类。在多元回归中，只有一个输出变量 `y[i]`，而在多元多元回归中，有许多输出变量 `y[i]`....`y[n+1]`。在二元分类中，只有一个输出变量 `y[i]`，其值为 0 或 1。

正如前面讨论的更简单的神经网络一样，激活函数被应用于给定的隐藏单元。也就是说，我们取 *给定隐藏单元的函数*，正如我们现在所知，该函数通常是从预先指定的激活函数集合或族中选择的 *非线性* 函数。在这里，例如，我们可以取上述的逻辑 sigmoid，

$$Logistic\\,\\, Sigmoid\\left( x \\right) = \\frac{1}{1 + e^{- x}}$$

或之前讨论的许多其他激活函数。简化地说，随着我们向输出移动，该输出现在是隐藏层的函数。也就是说，输出是 *输入的函数的函数*：

$$f\_{i} = {\\sum\\limits\_{i = 1}^{N}h\_{i}}\\left( \\beta\_{i}x\_{i} \\right)$$

(15.9)

其中在 (15.9) 中，`N` 是隐藏单元的数量，而 `β[i]` 是从隐藏单元到输出的权重。最后一步是输出 `f[i]` 的函数，

$${\\hat{y}}\_{i} = g\\left( f\_{i} \\right) = \\frac{1}{1 + e^{- f\_{i}}}$$

(15.10)

其中我们现在看到 `f[i]`，即内部函数，取代了 sigmoid 函数中的 `x`。随着我们在网络中从一层移动到另一层，复合函数的概念非常明显。也就是说，神经网络在达到最终输出时不断取 *函数的函数*。

## 15.7 训练神经网络

我们已经详细讨论了神经网络的架构，但尚未调查神经网络中的权重如何优化或训练。神经网络中的权重如何选择？与许多统计方法一样，它们应以 *最大化* 或 *最小化* 某个函数的方式选择。因此，权重的选择成为 *优化* 问题，就像本书中调查的大多数其他模型一样。也就是说，神经网络的“训练”包括找到优化的权重，类似于我们使用普通最小二乘或判别分析在回归中寻找最优权重。例如。“训练”统计或机器学习模型意味着通过数据运行模型，使得权重（或 *系数*）根据某些标准得到优化。在统计学的过去日子里，我们 *拟合* 模型到数据；今天我们在机器学习中 *训练* 它们。部分术语的改变仅仅是由于时代精神的转变。然而，在各种统计学习中，“学习部分”通常是在某些算法的约束下更新标量以获得最大值或最小值。也就是说，“学习”很大一部分只是 *优化*。549

### 15.7.1 反向传播与最小化误差平方和

为了优化神经网络，通常采用反向传播（有时称为 *误差反向传播*）。应强调的是，反向传播用于计算梯度，而梯度下降算法使用计算出的梯度来执行学习（[Goodfellow](#ref.xhtml#re_CIT000131)，2016）。因此，反向传播算法和梯度下降是结合使用，而不是相互替代。反向传播也被称为 *delta 规则*（[Hastie 等，2009](#ref.xhtml#re_CIT000145)；[Widrow & Hoff, 1960](#ref.xhtml#re_CIT000387)）。该算法包括两个阶段，即 *前向阶段* 和 *后向阶段*。本质上，前向阶段为模型提供了基于数据初步学习权重的机会；后向阶段使模型有机会根据模型在前向阶段的表现的 *反馈* 来“纠正”或“改进”权重估计。正是在这种意义上，神经网络 *学习*，就像人类从自己的错误中学习（例如在学习统计学时）并提高性能一样。这就是为什么 1980 年代反向传播算法的普及对神经网络如此重要。毫不夸张地说，神经网络的现代兴起主要与反向传播算法的发现以及处理日益庞大网络的计算能力有关。
