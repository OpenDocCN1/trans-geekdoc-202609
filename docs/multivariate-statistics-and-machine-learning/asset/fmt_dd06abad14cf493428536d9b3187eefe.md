*Cluster purity* is a measure of how well the algorithm classifies relative to the ground truth, if available ([Sikhakolli & Sikhakolli, 2023](#ref.xhtml#re_CIT000337)). If the algorithm performed perfectly, then out of 150 cases total, 150 should have been clustered correctly. If we let `p[j]` be the proportion representing the maximum number of points clustered correctly into the given class, and $\\frac{N\_{i}}{N}$ be the total fraction of cases eligible to be clustered for the given class from the total number of cases `N`, then cluster purity is given by

$$cluster\\, purity = {\\sum\\limits\_{i}\\frac{N\_{i}}{N}}p\_{j}$$  

(14.11)

For the iris data, if all cases were clustered correctly, the cluster purity would equal (50 + 50 + 50)/150 = 1.0 as a result of there being 50 cases per species of iris. For our actual data, the cluster purity is computed to be (50 + 48 + 36)/150 = 0.893. This is a shorthand calculation since `N[i]/N` = 50/150 for each class of species. To be more precise, the full computation is the following:

```
> purity <- (50/150)*(50/50) + (50/150)*(48/50) + (50/150)*(36/50)
> purity
[1] 0.8933333
```
