
In our model of regression in (5.1), as mentioned, we assume that our predictor is *fixed*. That is, if we were to refit the model on new data and thus replicate the experiment, we would use the same values on our predictor `x[i]`. If `x[i]` were random, we would presumably use different values since such values were presumably, at least on a theoretical level, drawn from a probability distribution. The theory we develop below assumes a fixed-effects model. For a treatment of random effects in regression, see [Fox (2016](#ref.xhtml#re_CIT000106), p. 228).

### 5.1.1 Parameter Estimates

Recall that we usually do not know values for `β[0]` and `β[1]` and hence typically require estimating them from sample data,

`ŷ = β̂[0] + β̂[1]x[i]`

(5.2)

How shall values of `β̂[0]` and `β̂[1]` be chosen? Certainly not arbitrarily or at random. As is true for most statistical models, parameter estimates are chosen in such a way that they accomplish some goal, which is usually to *minimize* or *maximize* some objective function. In the case of simple linear regression, these estimates are chosen such that they minimize the sum of squared errors around the regression line in simple linear regression and regression *surface* in multiple regression. That is, we wish to minimize the difference between observed and values predicted by the function `f̂(x[i])`:

$$
\begin{array}{l}
 {RSS = {\sum\limits_{i = 1}^{N}\left( y_{i} - \hat{f}\left( x_{i} \right) \right)^{2}}}
 \\\\
 {\,\,\,\,\,\,\,\,\,\,\,\, = {\sum\limits_{i = 1}^{N}\left( y_{i} - {\hat{\beta}}_{0} - {\sum\limits_{j = 1}^{p}{x_{ij}{\hat{\beta}}_{j}}} \right)^{2}}}
 \\\\
 \end{array}
$$

(5.3)

The general form of the above loss function is of the type (*a*−*h*)² which is a *quadratic* term, and hence the loss is a *quadratic loss*, often referred to as an *L2 loss*. Regression itself in no way requires us to minimize the L2 loss specifically. We could have instead, for instance, minimized the L1 loss, which is that of taking the absolute value of differences, |*a*−*h*|. Regression that minimizes L1 is often referred to as *robust regression* for the reason that through taking absolute deviations, it places less weight on outlying or more extreme scores (i.e., it is more “robust” to such extremes compared to L2). This is in contrast to the L2 loss, which magnifies extreme deviations through squaring them. Deviations from medians instead of means can also make regression more robust. The takeaway point for now is that there are many possible loss functions one may choose. For instance, yet another loss function is the *Huber loss* (for details, see [Murphy, 2022](#ref.xhtml#re_CIT000259)). The point is that the fact that we are minimizing the L2 loss in classic regression in no way implies that this is *the* one and only loss function that should dominate all work. However, it is undoubtedly the most 221common among loss functions and is typically used as a default. Ideally, however, whatever loss function is chosen should depend on the problem at hand.

The least-squares estimates for `β̂[0]` and `β̂[1]` are found by differentiating the residual sums of squares (RSS) with respect to both `β[0]` and `β[j]`, of which the solutions can be shown to be equal to

$$
\hat{\beta}_{0} = \overline{y} - \hat{\beta}_{1}\overline{x}
$$

(5.4)

for `β̂[0]` and

$$
\hat{\beta}_{1} = \frac{\left. {\sum\limits_{i = 1}^{n}{\left( x_{i} - \overline{x} \right)\left( y_{i} - \overline{y} \right.}} \right)}{\sum\limits_{i = 1}^{n}\left( x_{i} - \overline{x} \right)^{2}}
$$

(5.5)

for `β[1]`. It is easy to see that computing the slope requires variation in both `x` and `y`. For instance, without variation in `x`, $\sum\left( x_{i} - \overline{x} \right)^{2}$ is equal to 0 and hence `β̂[1]` is undefined.

The slope, in the case of zero intercept, can also be written as the inner product of `x` and `y` relative to the inner product of `x`, that is,

$$
\hat{\beta}_{1} = \frac{\left\langle {x,y} \right\rangle}{\left\langle {x,x} \right\rangle}
$$

(5.6)

As we will see when we survey multiple regression shortly, the variance of `β̂[1]` is equal to (`X`^(`T`)*`X`)^(−1)*`σ`² where `σ`² is estimated by

$$
\hat{\sigma}^{2} = \frac{1}{N - p - 1}{\sum\limits_{i = 1}^{N}\left( y_{i} - \hat{y}_{i} \right.}^{2}
$$

(5.7)

where `N` is the number of cases and `p` the number of predictors in the model. To compute significance tests on `β̂[0]` and `β̂[1]` we of course require standard errors, which in scalar form can be calculated from

$$
SE\left( \hat{\beta}_{0} \right)^{2} = \hat{\sigma}^{2}\left\lbrack {\frac{1}{n} + \frac{\overline{x}^{2}}{\left. {\sum\limits_{i = 1}^{n}\left( x_{i} - \overline{x} \right.} \right)^{2}}} \right\rbrack
$$

(5.8)

and222

$$
SE\left( \hat{\beta}_{1} \right)^{2} = \frac{\hat{\sigma}^{2}}{\left. {\sum\limits_{i = 1}^{n}\left( x_{i} - \overline{x} \right.} \right)^{2}}
$$

(5.9)

With standard errors computed, we can easily compute confidence intervals for both `β̂[0]` and `β̂[1]` as `β̂[0]` ± 2 ⋅ `SE`(`β̂[0]`) and `β̂[1]` ± 2 ⋅ `SE`(`β̂[1]`), respectively.

A test of the null hypothesis that the slope `β[1]` is equal to zero takes the form,

`H[0]` : `β[1]` = 0

(5.10)

against the statistical alternative hypothesis,

`H[a]` : `β[1]` ≠ 0

(5.11)

To evaluate the null, we compute a *t*\-statistic,

$$
t = \frac{\hat{\beta}_{1} - 0}{SE\left( \hat{\beta}_{1} \right)}
$$

(5.12)

evaluated on `n` − 2 degrees of freedom.

Recall that the correlation `r[yx]` between `x` and `y` is given by

$$
Cor\left( x,y \right) = r_{xy} = \frac{\sum\limits_{i = 1}^{n}{\left( x_{i} - \overline{x} \right)\left( y_{i} - \overline{y} \right)}}{\sqrt{\sum\limits_{i = 1}^{n}\left( x_{i} - \overline{x} \right)^{2}}\sqrt{\sum\limits_{i = 1}^{n}\left( y_{i} - \overline{y} \right)^{2}}} = \frac{{cov}_{xy}}{s_{x}s_{y}}
$$

The square of `r[yx]`, that is, `r[yx]`², is the proportion of variance accounted for in `y` based on knowledge of `x`. For example, for `r[yx]`² = 0.70, this means that 70% of the variance in `y` is accounted for by `x`.

Note that many of the equations and formulas just reviewed feature the use of *scalar algebra* and not matrix algebra (though we did use matrices a tiny bit). This is because in the simple linear regression case working with scalars generally suffices. As we turn shortly to multiple regression however, we will require working with matrices, where it stands that all the scalar algebra just surveyed can be just as well presented via matrices. Most books on regression will present the theory in matrices because these books aim for the widest and most *general* presentation of linear regression possible, for which using scalars (e.g., simple linear regression) is but a special case.
