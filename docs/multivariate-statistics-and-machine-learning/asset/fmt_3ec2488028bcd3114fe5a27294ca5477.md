
The reader may recall that the fundamental theorem of algebra states that *every polynomial equation of degree* `n` *with complex coefficients has exactly* `n` *roots in the complex numbers*. The proof of the theorem is generally due to [Gauss (1799)](#ref.xhtml#re_CIT000123). A number is called *algebraic* if it is the root of a nonzero polynomial with integer (or more generally, *rational*) coefficients. Numbers that are not algebraic are called *transcendental*. For some functions, solving for the roots of an equation is no easy matter. The root of an equation can be *approximated* by techniques such as *Newton’s method*. See [Tanton (2005)](#ref.xhtml#re_CIT000352) and [Hubbard and Hubbard (2002)](#ref.xhtml#re_CIT000161) for more details.

## 2.36.1.6 Points vs. Vectors
Before we leave the topic of vectors, it may be tempting from the above discussion and visualization of a vector to conclude that a vector is nothing more than a point in dimensional space. This would be a misunderstanding, however. *A vector is not equivalent to a point*. A point has no direction or magnitude, or as Euclid once said, “that which has no breadth” ([Tantom](#ref.xhtml#re_CIT000352), 2005).126

The distinction is that a point typically represents a *position* in space, whereas a vector typically represents a *displacement* or *increment*. Points are typically not added or subtracted from one another, but vectors often are. [Hubbard and Hubbard (2002](#ref.xhtml#re_CIT000161), p. 37) give the example of two points corresponding to two cities (e.g., Boston and New York) such that we would typically not “add” cities. However, if we consider the distance (i.e., vector) from Chicago to New York and the vector from New York to Boston, it makes sense to want to add those vectors.

## 2.37 Matrices
A *matrix* is a square or rectangular array of elements and can be thought of as an object in its own right, or, is sometimes best conceived as a collection of vectors. Just as for vectors, the matrices we work with all come from the field of real numbers. Hence, if `A` is a matrix, we write `A` ∈ ℝ^(m×n) and denote the matrix by

$$A = \\left\\lbrack \\begin{array}{l} {a\_{11}\\,\\,\\,\\,\\, a\_{12}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\, a\_{1n}} \\\\ {a\_{21}\\,\\,\\,\\,\\, a\_{22}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\, a\_{2n}} \\\\ {\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot} \\\\ {a\_{m1}\\,\\,\\,\\,\\, a\_{m2}\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\, a\_{mn}} \\\\ \\end{array} \\right\\rbrack$$

The *dimension* of a matrix is the number of *rows* by the number of *columns*. If there are `m` rows and `n` columns, the dimension of the matrix is `m` x `n`. A square matrix has `m` = `n`, that is, the same number of rows as columns. Note that the dimension of a matrix is not the same thing as the dimension of its *basis*, which is the dimensionality of the largest number of linearly independent rows or columns of the matrix, to be discussed later. We note that a matrix has a two-dimensional structure. If we increase this to three dimensions or greater, the object then becomes a *tensor* ([Murphy, 2022](#ref.xhtml#re_CIT000259)). The study of tensors is well beyond the scope of this book.

There are several ways of building matrices in R. A popular way is to specify the number of rows and columns via the `matrix()` function:

```
> A <- matrix(data = c(1, 2, 3, 4, 5, 6), nrow = 2, ncol = 3, byrow=TRUE)
> A
```

|  || \[,1\] || \[,2\] || \[,3\] |

| --- | --- | --- | --- |

| \[1,\] || 1 || 2 || 3 |

| --- | --- | --- | --- |

| \[2,\] || 4 || 5 || 6 |

The dimension of the matrix is revealed by the following, having 2 rows and 3 columns `(2 3)`:

```
> dim(A)
[1] 2 3
```

Creating a matrix in Python is just as easy:

127

```
A = [[1, 4, 5],
[-5, 8, 9]]
A
Out[320]: [[1, 4, 5], [-5, 8, 9]]
```

Note that in the above matrix (where each row is a *list*) constructed in Python, `[[1, 4, 5], [-5, 8, 9]]` corresponds to the matrix

$$\\left\\lbrack \\begin{array}{l} {\\,\\,\\,\\, 1\\,\\,\\,\\,\\, 4\\,\\,\\,\\,\\, 5} \\\\ {- 5\\,\\,\\,\\,\\, 8\\,\\,\\,\\,\\, 9} \\\\ \\end{array} \\right\\rbrack$$

Later, when we sample code for carrying out statistical and machine learning applications, data will often appear by row as above (i.e., `[[1, 4, 5], [-5, 8, 9]]`), but it is important to realize what is being communicated, which is illustrated by the lists or matrix above. If the data were simply a single row vector (or list, more generally), then it would have been represented without inner square brackets, as in the following:

```
[[1, 4, 5, -5, 8, 9]]
```

as we can readily verify in Python,

```
X = [[1, 4, 5, -5, 8, 9]]
X
Out[145]: [[1, 4, 5, -5, 8, 9]]
```

A more efficient approach to building vectors in Python is to use numpy:

```
import numpy as np
x = np.array([1, 4, 5, -5, 8, 9])
x
Out[125]: array([ 1, 4, 5, -5, 8, 9])
```

### 2.37.1 Identity Matrix
The *identity matrix* is a very important *square* matrix that reappears several times in statistical settings and is denoted by having only a series of “1” values along the main diagonal and zeroes everywhere else. As an example, consider the following 3 × 3 identity matrix:

$$I\_{3} = \\left\\lbrack \\begin{array}{l} {1\\,\\,\\,\\,\\,\\, 0\\,\\,\\,\\,\\,\\, 0} \\\\ {0\\,\\,\\,\\,\\,\\, 1\\,\\,\\,\\,\\,\\, 0} \\\\ {0\\,\\,\\,\\,\\,\\, 0\\,\\,\\,\\,\\,\\, 1} \\\\ \\end{array} \\right\\rbrack$$

where `I[3]` indicates a matrix having 3 rows and 3 columns. More generally, an identity matrix `I[n]` has `n` rows and `n` columns. A *zero matrix* is one for which all entries in the matrix have a value of 0.128

A basic result involving identity matrices includes `I A = A I` where `A` is a matrix of the same dimension as `I`.

Identity matrices can be easily built in R by the following via the `diag()` function:

```
> A <- diag(x = 5)
> A
```

|  || \[,1\] || \[,2\] || \[,3\] || \[,4\] || \[,5\] |

| --- | --- | --- | --- | --- | --- |

| \[1,\] || 1 || 0 || 0 || 0 || 0 |

| --- | --- | --- | --- | --- | --- |

| \[2,\] || 0 || 1 || 0 || 0 || 0 |

| \[3,\] || 0 || 0 || 1 || 0 || 0 |

| \[4,\] || 0 || 0 || 0 || 1 || 0 |

| \[5,\] || 0 || 0 || 0 || 0 || 1 |

In Python, we can create an identity matrix in the following way:


### 2.37.2 Transpose of a Matrix
The transpose of a matrix is analogous to the transpose of a vector, which we denote by

`A^(T)` or `A'`

As an example, consider the following square matrix `A` once more:

$$A = \\left\\lbrack \\begin{array}{l} {a\_{11}\\,\\,\\,\\,\\, a\_{12}} \\\\ {a\_{21}\\,\\,\\,\\,\\, a\_{22}} \\\\ \\end{array} \\right\\rbrack$$

We obtain the transpose by exchanging the first row for the first column and the second row for the second column:

$$A^{T} = \\left\\lbrack \\begin{array}{l} {a\_{11}\\,\\,\\,\\,\\, a\_{21}} \\\\ {a\_{12}\\,\\,\\,\\,\\, a\_{22}} \\\\ \\end{array} \\right\\rbrack$$

We obtain the transpose of a matrix in R via `t()`:

```
> A <- matrix(data = c(1, 2, 3, 4, 5, 6), nrow = 2, ncol = 3, byrow=TRUE)
> A
```

|  || \[,1\] || \[,2\] || \[,3\] |

| --- | --- | --- | --- |

| \[1,\] || 1 || 2 || 3 |

| --- | --- | --- | --- |

| \[2,\] || 4 || 5 || 6 |

```
> t(A)
```

|  || \[,1\] || \[,2\] |

| --- | --- | --- |

| \[1,\] || 1 || 4 |

| --- | --- | --- |

| \[2,\] || 2 || 5 |

| \[3,\] || 3 || 6 |

In Python, there are many ways of obtaining a transpose, such as the following:

```
import numpy as np
matrix = np.array([[1, 2, 3], [4, 5, 6]])
transposed_matrix = np.transpose(matrix)
print(transposed_matrix)
[[1 4]
[2 5]
[3 6]]
```
