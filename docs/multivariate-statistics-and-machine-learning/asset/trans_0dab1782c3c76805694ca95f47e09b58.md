
$$\\lim\\limits\_{x\\rightarrow a}f\\left( x \\right) = f\\left( a \\right)$$

(2.116)

其中我们再次回顾，函数的 *极限* 是函数所 *逼近* 的数，而不一定在该函数 *处* 定义。例如，在数列 0.9、0.99、0.999 中，数列的极限是 1，无论数列是否达到 1。具有极限的数列被称为 *收敛* 的。极限在 Python 中可以很容易地计算。示例请参见 [Saha (2015)](#ref.xhtml#re_CIT000319)。

尽管我们上面把连续性描绘得很基础，实际上它是一个非常深刻的概念，数学家们花了数年时间才发展并使其严谨。在现代数学中，连续性通常使用 ε-δ 定义来概念化（参见 [Denis, 2021a](#ref.xhtml#re_CIT000087) 以简要了解这些定义的工作方式）。当然，连续性首先并不是一个数学思想。它首先是一个 *概念*。人类意识中连续性的 *思想*，正如许多基本数学概念一样，很可能自人类诞生以来就已存在。想象早期文明基于一条路线的连续性来规划旅行路线，而不是选择一条会 *不连续* 且路线中存在“间隙”或“跳跃”的替代路线（也许需要跨越的河流）并不困难。数学家和哲学家使用精确的记号 *严格* 地定义这些概念这一事实，不应被理解为这些概念是“诞生”于数学的。如果说有什么的话，就像大多数事物一样，它们很可能诞生于早期的哲学“非专业”思考中。

## 2.58 导数

读者会从微积分中回忆起，要对函数 `f(x)` 求导，我们首先计算 `y` 的变化 (`δy`) 相对于 `x` 的变化 (`δx`)：

$$\\frac{\\delta y}{\\delta x} = \\frac{f\\left( x + \\delta x \\right) - f\\left( x \\right)}{\\delta x}$$

(2.117)

上述被称为 *差商*，表示函数的平均变化率。要得到 *导数*，我们按 (2.117) 计算函数相对于 `x` 的变化，但有一个非常重要的补充；我们将 `y` 的变化相对于 `x` 的变化取 *极限*，其中现在 `df` 对应于 `y` 的变化（或更一般地 *函数* 的变化），而 `dx` 对应于 `x` 的变化，现在在比值中由 `h` 表示（即 `h` = `δx`）：

$$\\frac{df}{dx} = f'\\left( x \\right) = \\lim\\limits\_{h\\rightarrow 0}\\frac{f\\left( x + h \\right) - f\\left( x \\right)}{h}$$

(2.118)

也就是说，导数 `f'(x)` 是差商的极限，当 `x` 的变化，由 `h` 表示，趋于零时。请务必注意，导数是一个 *斜率*，但它只是当 `h`→0 时极限下的斜率。换句话说，它是 *瞬时变化率*。如果没有“*当* `h`→0 时的极限”这一限定，导数就没有任何意义且未定义。微分学（以及积分学，同样如此）全部都关乎 *极限*。导数在二维中可通过 [图 2.16](#c2.xhtml#f2.16) 中的图形轻松可视化，其中我们看到曲线的切线以及近似的割线（稍后讨论）。153

![图 2.16 切线与极限概念相结合是导数的基础。导数有多种解释，其中之一是当 x 的变化趋于零时差商的极限（\\left. h\\rightarrow 0 \\right.）。导数的第二种解释是当 \\left. h\\rightarrow 0 \\right. 时割线的极限。两种解释都得到所关注特定点处曲线的切线，其中导数是该特定点处切线的斜率。返回文本。⏎](images/fig2.16.jpg)

*图 2.16* 切线与极限概念相结合是导数的基础。导数有多种解释，其中之一是当 x 的变化趋于零时差商的极限（`h`→0）。导数的第二种解释是当 `h`→0 时割线的极限。两种解释都得到所关注特定点处曲线的切线，其中导数是该特定点处切线的斜率。[返回文本。⏎](#c2.xhtml#re_f2.16)

请注意，我们可以在给定点周围画出许多斜率，它们都与 [图 2.16](#c2.xhtml#f2.16) 中的斜率略有不同。在那个特定很小的点处，*切线* 如何定义？这再次是极限概念发挥作用的地方。对于 `h` > 0，我们可以拟合许多不同的割线（即与曲线相交越来越接近最终切线的直线）。然而，当 `h`→0 时，我们 *锁定* 到切线，其斜率我们称之为 *导数*。也就是说，*导数是当* `h`→0 时割线极限所定义的斜率*。就此而言，导数不仅仅是位于给定位置 *接触* 该点的线的斜率；它是 *接触该点的极限（割）线*，尽管在非正式描述导数时，我们经常简单地说“接触该点”或“切于该点”或“该点的斜率”。

可以断定，如果一个函数在 `x` 的某个区间上每一点的导数都等于 0，则该函数在此区间上是 *常数*。也就是说，如果 `f'(x)` = 0 在每一点成立，则意味着 `f(x)` = `c` 在每一点成立，其中 `c` 为常数。如果一个函数在给定点确实存在极限，则该极限是 *唯一* 的。在更高维度中，可视化要困难得多，取而代之的是 *切于* *曲线*，我们将有 *切于曲面的平面*。词汇发生了变化，但概念相同。更高维度可能令人望而生畏，但如果对低维概念有良好的理解基础，则会不那么可怕。

[Hubbard and Hubbard (2002](#ref.xhtml#re_CIT000161), p. 126) 精妙地总结了微分学的目标，为其目的提供了深刻的见解：

> 微分学的目的在于通过用线性变换代替它们来研究非线性映射：我们用线性方程代替非线性方程，用切平面代替弯曲曲面，等等。当然，这种线性化只有在你对线性对象有相当好的理解时才有用。此外，这种替换只是或多或少合理。局部地，在切点附近，弯曲曲面可能与它的切平面非常相似，但远离时则不然。微分学最困难的部分是确定何时用线性对象代替非线性对象是合理的……非线性是一个过于宽泛的类，难以考虑。将映射分为线性和非线性，就像把人分为左撇子大提琴手和所有其他人一样。

我们还可以将导数区分为左导数和右导数。左导数不出所料，是从左侧的极限，154

$$f\_{-}^{'}\\left( x \\right) = \\lim\\limits\_{h\\rightarrow 0^{-}}\\frac{f\\left( x + h \\right) - f\\left( x \\right)}{h}$$

(2.119)

其中右导数由下式给出

$$f\_{+}^{'}\\left( x \\right) = \\lim\\limits\_{h\\rightarrow 0^{+}}\\frac{f\\left( x + h \\right) - f\\left( x \\right)}{h}$$

(2.220)

可以证明，函数在某一点的导数存在的唯一条件是左右导数都存在且彼此相等。

在 Python 中，我们可以按如下方式求函数的导数：

```
from sympy import Symbol, Derivative
t = Symbol(‘t’)
St = 5*t**2 + 2*t + 8
Derivative(St, t)
Out[68]:
Derivative(5*t**2 + 2*t + 8, t)
```

```
d = Derivative(St, t)
d.doit()
```

```
Out[70]:
10*t + 2
```
