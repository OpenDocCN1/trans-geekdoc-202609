
读者会将其识别为熟悉的 *残差平方和准则* (`RSS`)，其中 `y[i]` 为观测值，而 `ŷ[s[j]]` 为在决策面给定子区域中预测值，对应一组预测变量的组合。每次选择能使 `RSS` 减少最多的预测变量。此过程对每个预测变量和空间继续进行，直到达到停止过程的某个准则为止。停止准则可能包括对样本量限制的考虑。即，树分裂可以继续进行，直到每次分裂的 `n` 最小，足以停止算法。372

### 10.2.3 为何不使用多路分裂？

在我们构建决策树时，注意到我们在每个节点上执行的是 *二元* 分裂。但为何不执行包含两个以上可能性的分裂？虽然也可以将树节点分裂为两个以上的组，通常称为 *多路* 或 *多元* 分裂，但与更简单的二元分裂相比，其通常会产生较差的结果。此外，多路节点通常难以解释（[Aggarwal, 2015](#ref.xhtml#re_CIT000005); [Alpaydin, 2020](#ref.xhtml#re_CIT000009)）。其主要原因是多路分裂可能导致树根附近出现太多仅有少量数据点的节点，从而为后续分裂留下不足的数据。因此，与尝试多路分裂相比，通常更偏好的策略是进行多次二元分裂。

有时在拟合树之前预处理数据是有益的。这包括对数据进行标准化。尝试原始数据和标准化后的两种方案，可能有助于了解在构建树之前标准化分数所带来的任何影响。

> *最小化残差平方和是构建决策树时在每一步选择预测变量的常见准则。该算法是“贪婪”的，因为在给定分裂处最小化 `RSS` 时，它不会考虑后续分支的长期后果。*

### 10.2.4 过拟合、饱和与树剪枝

单一决策树拟合数据时很可能过拟合数据，因为它对特定数据集过于具体。这类似于将回归曲线（不限于直线）拟合得过于贴近散点图中的点。当然，其后果是过拟合的树在测试数据上的表现可能不佳，原因我们已十分熟悉。

如果树生长到没有任何节点可以再进一步分裂，则称该树为 *饱和*。也就是说，饱和树已耗尽其进行分裂的潜力。尤其是在高维空间中，很容易让树变得极大，如果我们允许其生长到饱和点，它实际上会变得难以处理。那么，如何防止过拟合呢？在决策树的早期，树构建者试图通过实施所谓的“停止规则”来限制树的生长以防止过拟合。然而，正如 [Breiman et al. (1984)](#ref.xhtml#re_CIT000045) 所示，这样的停止规则通常不被建议，而且或许反直觉的是，首选的解决方案通常是构建一棵非常大的树，然后执行所谓的 *剪枝* 以获得 *子树*（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)，p. 308）。也就是说，可以证明构建饱和树然后 *回缩* 树通常比过早停止或更一般地过早 *正则化* 树更可取。

那么如何剪枝就变得至关重要。事实上，决策树演进中的许多研究与其说是关于如何生长树，不如说是关于 *如何将其剪回*。剪枝中需要克服的一般问题是 *剪枝会产生偏差*。为什么会这样？考虑当我们剪枝一棵树时，我们现在对数据的估计是不完美的，就像回归线对散点图中的数据群进行不完美估计一样。另一种方法可能是完全放弃树剪枝，而只是通过重采样生长许多相当大的树，然后取树的平均值以降低方差。正如我们稍后将看到的，这种平均技术被称为 *bagging*，这是 *bootstrap aggregating* 的简称。毫不奇怪，“最佳”剪枝树将是 *cross-validation* 上表现最好的那棵树。然而这样做，373 将涉及考虑许多不同的树。因此，我们需要一种替代的剪枝策略来选择较小的树集进行考虑。

> *决策树很容易过拟合。实施“停止规则”以防止树长得过大通常不是理想的解决方案。首选的解决方案通常是允许树生长到饱和，然后将其剪回。*

### 10.2.5 成本复杂度或最弱链接剪枝

*cost complexity pruning* 过程，也称为 *weakest link pruning*，是为剪枝时提供所需树子集的一种方法。与考虑每棵可能的树不同，我们只考虑由非负调参参数 `α` 索引的一系列树。调参参数当然现在已不再新鲜，因为我们在岭回归和套索回归等其他程序中反复见过它们。对于调参参数 `α` 的每个取值，我们将获得一个 *subtree*，使得以下准则最小化：

$$\\left. {\\sum\\limits\_{j = 1}^{J}\\left( y\_{i} - {\\hat{y}}\_{s\_{j}} \\right)^{2}} + \\alpha \\middle| T \\right|$$  

(10.1)

给定树 `T` 的末端节点数由 `|T|` 表示。调参参数 `α` 控制子树复杂性与其对训练数据的拟合之间的权衡（[James et al., 2013](#ref.xhtml#re_CIT000168)）。我们可以看到，随着 `α` 的增加，它会导致整体误差相对较大地增加 *尤其当树上有几个末端节点时* (`|T|`)，因为 `|T|` 乘以 `α` 中较大的数会产生比不乘时更大的乘积 `α|T|`。非正式地说，这意味着如果你想要树上有许多节点，*那么这样做是有代价的*，因为我们期望 `RSS` 随着节点数增加而减少，除非我们施加惩罚。这个想法与多元回归相似，其中在没有惩罚的情况下增加更多预测变量通常会降低残差平方和。回想目标是最小化 $\\sum\\limits\_{j = 1}^{J}\\left( y\_{i} - {\\hat{y}}\_{s\_{j}} \\right)^{2}$，这意味着较小的值优于较大的值。`α` 的选择通常通过 cross-validation 或独立样本测试集进行，其中如果数据集足够大并且可以相应拆分，则独立测试集可能优于 cross-validation。还应强调的是，对于任何惩罚值，可能存在不止一个最小化子树，这使得在此情况下选择“最佳”树变得有点更具挑战性。随着 `α` 值远离零增加，决策树会被“剪枝”，因此获得 `α` 的理想值至关重要（[James et al., 2013](#ref.xhtml#re_CIT000168)，p. 309）。

> *对于 `α` 的递增取值，乘积 `α|T|` 增加，其中 `T` 是末端节点的数量。即，随着树的复杂性增加，`α|T|` 作为惩罚而起作用并增加 `RSS`。因此，如果 T 中包含的节点在降低 `RSS` 方面不“值得”，则惩罚后的 `RSS` 最终会增加而不是减少。*374
