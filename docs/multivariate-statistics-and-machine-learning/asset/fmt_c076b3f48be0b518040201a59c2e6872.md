## 3.2.4 Writing Functions in R
A function in R, as opposed to mathematics, is essentially and most generally a program for carrying out something. Functions can range from simple to very complex. As an example of writing a simple function, consider the following where we wish to compute speed as a function of distance over time, where time is equal to 2 hours and distance is 180 miles:

>speed <- function(d){

### 3.2.5.2 Logarithms and Exponentials
Recall that *logarithms* and *exponentials* are inverses of one another. An inverse function is one such that *x*\=*f* ^(\-1)(*y*) if and only if *f*(*x*) = *y*.172

A logarithm is essentially an *exponent*. The logarithm is the exponent to which the base needs to be raised in order to get the particular number we are taking the logarithm of. For example, consider the number 4. The log of 4 is
```
> log(4)
[1] 1.386294
```
The above reads that 1.38 is the exponent to which the base needs to be raised in order to get 4. But what is the base here? When we take a `log` in R without specifying the base, R automatically associates it with the *natural log*, that is, to base `e`. Recall that `e` is a constant equal to approximately 2.718, and hence when we compute the exponential of 1.386294, we obtain a number that when rounded up is equal to 4:
```
> exp(1.386294)
[1] 3.999999
```
We can easily change the base of the logarithm by the following, where we compute `log(4)` but to base 10, which ends up being equal to 0.60206:
```
> log(x = 4, base=10)
[1] 0.60206
```

### 3.2.5.4 Means
The following computes the arithmetic mean on a small data set:
```
> data <- c(1, 5, 8, 9, 10)
> mean(data)
[1] 6.6
```
The variance and standard deviation of the above data are computed as:
```
> sd(data)
[1] 3.646917
> var(data)
[1] 13.3
```
Note that both the variance and standard deviation use `n` – 1 in the denominator rather than `n` ([Davies, 2016](#ref.xhtml#re_CIT000077), p. 279). That is, R assumes we are computing these statistics to serve as *estimators* of their corresponding population counterparts. Recall that these statistics with `n` – 1 in the denominators are sometimes referred to as the *corrected* versions of the variance and standard deviation, and losing a degree of freedom makes them *unbiased estimators*.

### 3.2.5.5 Covariance and Correlation
For the following two vectors, we compute both the covariance and correlation:
```
> x <- c(0, 3, 7, 2, 8, 9)
> y <- c(3, 6, 8, 3, 8, 10)
> cov(x, y)
[1] 10.06667
> cor(x, y)
[1] 0.9576546
```
We see that the covariance is equal to 10.06 while the correlation is equal to 0.95. Of course, we could have also computed the correlation the long way as follows where we divide the covariance by the product of standard deviations:
```
> r <- cov(x, y)/(sd(x)*sd(y))
> r
[1] 0.9576546
```
