

也就是说，与岭回归权重平方和 $\\sum\\limits\_{j = 1}^{p}\\beta\_{j}^{2}$ 不同，调参现在应用于回归权重 *绝对值* 之和，$\\left. {\\sum\\limits\_{j = 1}^{p}\\left| \\beta\_{j} \\right.} \\right|$。请注意，无论是在岭回归中添加平方项还是在套索回归中添加绝对值项，其一般原理是相同的，即在最小二乘残差平方和中加入惩罚项，从而看似增加误差函数。但同样值得问的是，我们为什么要这样做。如同岭回归之前的情况，只有当这种惩罚的加入能够降低 `MSE` 在 `test`（不一定是 *train*）数据上的表现时，才“值得”。岭回归和套索回归之间的唯一区别在于惩罚的性质。在这两种情况下，随着 `lambda` *λ* 的增大，回归中的所有系数最终都会趋向于 0，因此需要一个“停止点”；否则执行岭回归或套索回归将是微不足道且毫无意义的。也就是说，虽然我们希望将某些系数收缩至或趋向于 0，但将所有系数都驱动到 0 将是 277反生产。 正如我们很快会看到的，实际上，停止点通常通过 `cross-validation` 选择。

根据 [Müller 和 Guido (2017)](#ref.xhtml#re_CIT000258)，在岭回归与套索回归之间，岭回归通常是首选。如果您拥有大量预测变量并且预计其中只有少数几个很重要，以至于其余变量可以被剔除，那么套索回归可能最有用。请记住，套索回归可用于变量选择，因为它会将某些系数一直驱动到 0。这是在应用意义上使用岭回归与套索回归之间关键区别特征。

import numpy as np

### 6.3.2 R 中的套索回归
