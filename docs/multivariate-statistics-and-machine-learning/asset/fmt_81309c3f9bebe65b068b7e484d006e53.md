### 2.60.3 Convex vs. Nonconvex Functions and Sets

Establishing minima and maxima depends on the convexity of the function. Convex functions are preferred over nonconvex functions since they have *global* minima, while nonconvex functions often have several *local* minima, which can detract from finding a global minimum. Optimization problems that feature local minima can easily get caught in locality, or more colloquially, get “stuck” in local valleys.

[Figure 2.19](#c2.xhtml#f2.19) gives a geometric interpretation of convexity. A convex function is one in which we can draw a line between line segments (as shown in the image) and the value of the function is guaranteed to be at or less than the line. For a nonconvex function, we cannot draw such a line without going through other segments of the function. Notice that for convex functions, there will be a global minimum. Another way of saying this is that for convex functions, any local minimum will also be a global minimum (Goodfellow, 2020). For nonconvex functions, there may be many local minima.

When we discuss manifold learning later in the book, generalized concepts of line segments or paths that are the shortest distances between two points and can help indicate convexity in a manifold will be called `geodesics`. Geodesics, as we will see, however, are typically not unique. A 160function defined on a manifold is convex if its `Hessian` is positive semidefinite, where the Hessian describes the local curvature of a function of many variables in terms of their second-order partial derivatives. Hence, when the Hessian is positive definite, this implies convexity of the surface we are working on, which will allow algorithms such as gradient descent to more easily perform optimization as a result of there being an assured global minimum.

## 2.61 Gradient Descent

Gradient descent is a popular algorithm used for minimizing an objective function for seeking global or local minima in many statistical and machine learning applications. It is the most common method of optimization used, for instance, in neural networks, but also many other machine learning and statistical approaches ([Ruder, 2016](#ref.xhtml#re_CIT000317)). It is an *iterative* method where the goal is to minimize some arbitrary cost function which will differ by statistical or machine learning method employed. Iterations that perform slight changes to parameter estimates are stopped once the algorithm converges to a minimum value of a cost function, after which time no further reduction in the cost function is desirable or achievable. That’s the goal: to perform slight iterative “updates” to parameter estimates until a local minimum is achieved. Though there are many varieties of gradient descent, there are generally three most popular: *batch gradient descent, stochastic gradient descent*, and *mini-batch gradient descent*.

### 2.61.1 How Does Gradient Descent Find Minima?

In finding minima of a cost or error function `E(θ[0])` subject to updates in the model’s parameters contained in the vector `θ[0]`, successive steps are taken that are proportional to the negative of the gradient of the function for the given current values of the model parameters. Note carefully what this means: we start off at some, often arbitrary parameter values, `θ[0]`, then based on the gradient (i.e., crudely “*slope,”* but is actually the vector of partial derivatives) of the function, move toward a minimum in steps. We are seeking a minimum value and move in the direction of the *negative gradient*, that is,

`θ[1] = θ[0] − η ⋅ ∇[θ]E(θ[0])`

(2.227)

where `η` is the step-size or *learning* rate and `∇[θ]E(θ[0])` is the gradient vector which contains the entire set of partial derivatives of the error or cost function `E(θ[0])`. Hence, for any value `η` ≥ 0, `E(θ[1])` ≤ `E(θ[0])`. That is, for any value of `η` greater than 0, the function at `θ[1]` (i.e., the updated parameter vector) represents a *decrease* from the original cost function evaluated at `θ[0]`. In doing so, we are in the process of *converging* to a minimum value. The set of parameters `θ[0]` is optimized according to the step-size `η`, such that the new “guess” of the parameters, `θ[0 + 1] = θ[1]` is arrived at by this method of minimization.

Visually, gradient descent can be depicted as in [Figure 2.20](#c2.xhtml#f2.20), where we see we are eventually converging on a local or global minimum toward the center and thus minimizing the cost or error function by iteratively updating parameter estimates with each iteration.161

![Figure 2.20 Concept behind gradient descent; successive iterations eventually lead to minimizing the error or cost function.Return to text.⏎](images/fig2.20.jpg)

*Figure 2.20* Concept behind gradient descent; successive iterations eventually lead to minimizing the error or cost function.[Return to text.⏎](#c2.xhtml#re_f2.20)

What we have described thus far is generally known as “vanilla” batch gradient descent ([Bishop, 2006](#ref.xhtml#re_CIT000032); Ruder, 2017). Gradient descent can be relatively slow close to the minimum value. Its asymptotic rate of convergence can also be inferior to other methods (Deisenroth et al., [2020](#ref.xhtml#re_CIT000080)). If the learning rate `η` is too fast, the true local minima could be “skipped” as the algorithm tries instead to maximize the shortest time it searches for such minima. On the opposite extreme, if the learning rate `η` is too slow, gradient descent may never converge as the algorithm tries “too hard” to find the local minima. Hence, choosing an appropriate step-size or learning rate `η` is important. There is a kind of “trade-off” in gradient descent between the accuracy of the parameter update vs. the time it takes to make such an update ([Ruder, 2016](#ref.xhtml#re_CIT000317)). One useful strategy is to have a changing learning rate that slows down as the minimum is neared, commonly known as *annealing* ([Ruder, 2016](#ref.xhtml#re_CIT000317)). Of the varieties of gradient descent, batch gradient descent is guaranteed to converge to a *global minimum* so long as the error surface is *convex*; if it is not convex, then it is guaranteed to converge to a *local* minimum.

*Stochastic gradient descent* performs a parameter update for *each* training data point, `x[i]`, not a “batch” such as in batch gradient descent,

`θ[1] = θ[0] − η ⋅ ∇[θ]E(θ; x[i])`

(2.228)
