
正如经典 PCA 的情况一样，核 PCA 的目标将是最小化重建误差。 从经典 PCA 转移到核化 PCA 时，这一目标为何没有改变应该是有道理的；两种方法本质上做的是同一件事，只是对变量和数据的变换不同。乍一看，扩大特征空间似乎会*增加*我们需要计算的维度。然而，与我们可能预期的相反，这并没有发生，多亏了再次的*核技巧*。正如我们所强调的，由于核技巧，我们实际上不必在更高维的特征空间中进行任何计算。*核的计算发生在数据的原始低维空间中*。正如 Hastie 等人所总结的（[2009，第 547 页](#ref.xhtml#re_CIT000145)）：421

> 核 PCA 扩展了 PCA 的范围，模仿了我们如果通过非线性变换扩展特征，然后在此变换后的特征空间中应用 PCA 所能得到的结果。

除此之外，更高维的空间很可能最终会是*无限维*的。这就是为什么它被称为“技巧”，因为我们可以简单地在低维中计算核，并了解更高维的一些信息，而无需在更高维中进行复杂的计算。打个比方，这有点像能够对两个数字进行加法，这是一个非常简单的操作，以了解数字以非常复杂的方式如何相关（例如，数字之间的距离是否为质数）。*核技巧允许用简单的计算来表示这些数字背后更复杂现实或“空间”*。这当然是一个不精确的类比，但在精神上或多或少地近似了这个想法。需要记住的信息是，核技巧在统计学和机器学习中是一个*大事*。

### 11.6.5 核 PCA 的矩阵

从数学上讲，核 PCA 依赖于这样一个事实：主成分可以通过计算数据矩阵 `X` 的内积从数据矩阵获得，

`K = X X^(T)`

(11.9)

然后对 `K` 的双中心化版本进行特征值分析，其中 `K̃` 现在等于

`K[c] = (I - M) K (I - M)`

(11.10)

其中 `M = 11^(T)/N` 用于对 `K` 进行中心化（[Hastie 等，2009](#ref.xhtml#re_CIT000145)，第 547 页）。也就是说，我们正在计算一个核矩阵 `K̃`，它包含数据点之间所有的成对点积。这里的双中心化确保每一行和每一列的均值等于 0。而经典 PCA 使用协方差矩阵并根据输入维度的数量进行缩放，核 PCA 则根据*数据点*的数量而不是维度进行缩放，因为特征值分析是在 `K̃` 矩阵上进行的，而不是像 PCA 中那样在协方差矩阵上进行。

正如使用核时所见，有多种核可用，例如*径向核*等。然而，核的选择至关重要，而“*你找到的东西是放入东西的函数*”这一表述在这里非常相关；一种核与另一种核相比可能会产生截然不同的发现（对此的一个例子，参见 Hastie 等，[2009](#ref.xhtml#re_CIT000145)，第 549 页）。特征值问题是什么样的？回想经典的特征值分解：

`A x = λ x`

对于核 PCA，`A` 现在是核矩阵 `K̃`，并且通过简单的代入（[Bishop, 2006](#ref.xhtml#re_CIT000032)，第 588 页）特征值问题变为，

`A x = λ x → K̃ x = λ N x`

(11.11)

或简洁地422

`K̃ x = λ̃ x`

如果 `λ̃ = λ N`（[Izenman, 2008](#ref.xhtml#re_CIT000167)，第 611 页）。请注意，我们正在对 `K̃` 矩阵进行特征值分析，而不是像传统 PCA 中那样对协方差或相关矩阵进行分析（[Bishop, 2006](#ref.xhtml#re_CIT000032)）。一旦我们获得了特征值和特征向量，我们现在就可以将数据投影到每个新维度上。

> *核 PCA 可以被概念化为“普通”PCA，但与其按特征向量的值加权输入变量，不如说数据点的核按特征向量的值加权。因此，`KPCA` 只是用观测值的核替换变量（维度），以便核技巧可以“施展其魔力”。*

### 11.6.6 经典 PCA 作为核 PCA 的特例

我们已经看到核 PCA 允许非线性。因此，可以说在施加一些约束后，经典线性 PCA 应该能够作为核 PCA 的*特例*获得并实现。事实上，从我们之前的讨论中应该很明显，经典 PCA 必须只是 `KPCA` 的特例（[Bishop, 2006](#ref.xhtml#re_CIT000032)，第 589 页），其中*核是线性核*。这是一个强大的洞见。*一般来说，许多线性方法可以被视为更一般非线性框架的特例*。非线性统计“可能性”的集合远大于较小的线性模型集合，因此线性方法只是该更广泛集合的子集，不仅在核 PCA 与 PCA 的关系中如此，而且对大多数统计方法总体而言也是如此。

### 11.6.7 核技巧不仅仅是关于成本

核技巧很有用，因为它在访问更高维特征空间时节省了计算成本。然而，应该强调的是，这并不是其效用的唯一原因。使用核方法的主要好处不仅仅是绕过计算复杂性的一种方式。重申一下，*核技巧允许我们在不知道该维度的具体细节的情况下在更高维度中工作。这就是其关键好处*。因此，尽管通常核方法通常因其在“访问”更高维度方面的计算特性而被宣传或评估，但一般应用核方法远非仅仅是减轻计算的一种方式。即使计算繁琐，而在计算大型矩阵的点积时确实可能如此，核方法仍然有用，因为它们首先允许访问那些更高维度。*一般来说，核方法允许在低维中工作时访问更高维度，通常所有这些的计算成本都比直接访问那些更高维度更合理。*
