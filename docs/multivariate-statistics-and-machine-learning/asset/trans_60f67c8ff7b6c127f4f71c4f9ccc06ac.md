
该方程的简洁性[i.e., `Σ` = `Σ`(`θ`)]仅次于其普遍性。它提供了一种统一的方式来包含社会科学中最广泛使用的许多统计技术。回归分析、联立方程系统、验证性因子分析、典型相关、面板数据分析、方差分析、协方差分析和多重线性指标模型都是`Σ` = `Σ`(`θ`)的特例。

`Σ`的值未知，因此我们通过`S`来估计`Σ`，`S`为样本协方差矩阵。我们希望`S`与`S`(`θ`)之间的距离尽可能小，即最小化，其中`S`(`θ`)是由估计的模型参数所暗示的样本协方差矩阵。差异函数是一类广泛的函数，可以从中选择一个特定的函数来最小化`S`与`S`(`θ`)之间的距离。其中一种差异函数是熟悉的普通最小二乘法，它最小化`y`的观测值与拟合值之间的距离。其他类型的模型涉及最小化或最大化其他差异函数。例如，在使用最大似然法(ML)的协方差建模中，我们希望最小化以下拟合函数`F[ML]` ([Bollen, 1989](#ref.xhtml#re_CIT000037), p. 107):487

`F[ML]` = log|`Σθ`| + tr(`S` `Σ`^(−1)(`θ`)) − log|`S`| − (`p`+`q`)

(13.4)

当`S` = `S`(`θ`)时，`F[ML]` = 0。也就是说，随着(`S`−`S`(`θ`))→0，`F[ML]`→0，并且实现了完美的模型拟合，因为样本协方差矩阵`S`与模型所暗示的`S`(`θ`)之间的差异等于0。事实证明(`n`−1)`F[ML]` ∼ `χ²`（其中`n`为样本量），可用于评估以下全局零假设，

`H[0]`: `Σ` = `Σ`(`θ`)

(13.5)

其中上述零假设`H[0]`表示总体协方差矩阵`Σ`等于由指定参数所暗示的总体协方差矩阵，即`Σ`(`θ`)。上述零假设是对备择假设`H[1]`进行评估的，

`H[1]`: `Σ` ≠ `Σ`(`θ`)

(13.6)

其表示总体协方差矩阵`Σ`不等于由模型参数`θ`所暗示的协方差矩阵。等价地，在零假设下，`Σ`−`Σ`(`θ`) = 0，因此如果模型拟合完美，则`χ²`的期望值为0。模型拟合不佳的程度即为`Σ`−`Σ`(`θ`) ≠ 0的程度。如果你仔细观察零假设，你会发现与传统零假设检验中我们希望拒绝零假设相反，在SEM中，我们实际上希望不拒绝零假设。也就是说，在SEM中，由数据支持的零假设是一个有利的结果，这与传统零假设检验的经典解释相悖。这一事实很重要，因为如果在SEM中拒绝零假设，则表明你的估计模型与协方差矩阵不一致，意味着它不能很好地再现协方差矩阵，这进一步意味着基于数据的协方差矩阵与模型所暗示的协方差矩阵之间的拟合不一致。

### 13.6.2 评估模型拟合

如同大多数监督学习模型一样，我们希望有一个衡量标准来评估模型对经验数据的拟合程度。在普通最小二乘法中，该模型拟合度量通常为`R²`、`R[adj]²`或某些其他模型选择度量，如`AIC`或`BIC`。在SEM中，我们也需要模型拟合度量来评估我们指定的模型参数在多大程度上再现`S`，即样本协方差矩阵。如同回归和其他模型一样，结构方程模型的拟合评估方式众多。SEM中的模型拟合度量通常分为两大类，即评估整体或绝对模型拟合的度量，以及评估增量拟合的度量，有时称为相对拟合度量。整体模型拟合度量在不参考竞争模型的情况下评估模型的整体，而增量或相对拟合度量则将模型相对于某个参考或竞争模型进行评估，通常是零假设或基线模型，以评估假设模型相对于基线模型的表现如何。

为什么不直接使用`χ²`作为模型拟合度量？回顾一下，(`n`−1)`F[ML]` ∼ `χ²`，并且在完美拟合的模型下，`H[0]`下`χ²`的期望等于0。因此乍一看，似乎合理地简单使用`χ²`作为模型拟合度量，使得`χ²`→0的程度即为模型拟合越来越好的程度，而`χ²` > 0的程度即为模型拟合较差的程度。也就是说，`χ²`在统计上显著的程度可能被视为模型拟合越来越差的度量。虽然这种方法乍一看似乎合理，但它存在很大问题，总体而言，单独的`χ²`在SEM中是一个较差的模型拟合度量。回顾一下，随着`n`的增加，除非限制`χ²` = 0，否则实现`χ²`的`p` < .05（或其他任意显著性水平）是必然的。只要`χ²` > 0成立，而这种情况最常见，`χ²`的统计显著性，更重要的是其缺乏显著性，不应以任何实际方式被解释为“效应”的度量，尤其是在`n`增大的情况下。

当然，这个想法并不新鲜，并且在书中前面已经讨论过；p值不是效应量。这并不意味着用户不应将`χ²`用作拟合的初步评估，只是单独的`χ²`通常不会告诉用户他们真正想知道的内容，即一个独立于样本量影响的效应度量。在以下度量中，整体度量和增量拟合指数都是效应量（或更一般地说是“拟合”）的度量，它们不受`n`大小的影响，而`χ²`在很大程度上是样本量的函数。

### 13.6.3 整体（绝对）度量

一些更常见的整体拟合度量包括均方根残差(`RMR`)、其标准化对应物标准化均方根残差(`SRMR`)以及近似均方根误差(`RMSEA`)。我们现在简要介绍每一个。
