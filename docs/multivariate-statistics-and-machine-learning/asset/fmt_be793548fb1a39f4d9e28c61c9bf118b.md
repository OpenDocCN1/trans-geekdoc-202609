## 5.2 Multiple Linear Regression
In a simple linear regression there is only a single response variable and a single predictor. In a multiple regression model, there are several predictor variables that we model simultaneously in predicting the single response. In a *multivariate multiple regression*, there are not only several predictor variables but also several responses modeled simultaneously.

The multiple linear regression model is given by

*y*[i] = *β*[0] + *β*[1]*x*[1] + *β*[2]*x*[2] +  ⋅  ⋅  ⋅  + *β*[*p*]*x*[*p*] + *ε*[*i*]  

(5.13)

where *E*(*ε*[*i*]) = 0 and thus with expectation equal to

*E*(*y*[*i*]) = *β*[0] + *β*[1]*x*[1] + *β*[2]*x*[2] +  ⋅  ⋅  ⋅  + *β*[*p*]*x*[*p*]  

or when expressed as conditional on *x*,

$$\\begin{array}{l} {y = E\\left( y \\middle| x\_{1},...,x\_{p} \\right)} \\\\ {\\,\\,\\,\\,\\, = \\beta\_{0} + {\\sum\\limits\_{j = 1}^{p}{x\_{j}\\beta\_{j}\\,}}} \\\\ \\end{array}$$
