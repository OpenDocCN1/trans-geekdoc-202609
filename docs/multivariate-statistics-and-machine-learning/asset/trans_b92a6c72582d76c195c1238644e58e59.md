

它不是满秩，因为第二列只是第一列的标量倍。也就是说，第二列恰好是第一列的两倍。矩阵的秩为 2，因为只有两列（和行）是线性无关的。秩也等于具有非零行列式的最大子矩阵 `A`（即删除某些行和列）的维数（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。在应用意义上，矩阵的秩让我们了解矩阵中信息被“重复”的程度。满秩矩阵告诉我们每一行（或列）都提供了“唯一”的信息。秩小于满秩的矩阵告诉我们，在信息方面矩阵本质上存在“重叠”。尽管这是一种非严格的理解秩的方式，但在应用层面把握概念时仍然很有帮助。

## 2.48 正交矩阵

正交矩阵是指那些与其转置相乘后得到单位矩阵的方阵。例如，`X X^T = I = X^T X` 意味着 `X` 是正交矩阵。如果 `X^2 = X`，则该矩阵被视为 *幂等*（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。对于向量，我们可以更简单地将正交性定义为内积 `x y = 0` 时。正交性也意味着垂直性，用 `x⊥y` 表示。*标准正交* 向量是正交且长度等于 1 的；因此如果 `x` 与某个向量标准正交，则有 `||x||=1`。

## 2.49 核、核技巧与对偶表示

核在机器学习中发挥着重要作用，我们在诸如 *神经网络* 和 *支持向量* *机*（SVM）等技术中可以看到它们。事实上，随着对机器学习的深入研究，“核技巧”很快就会成为常见领域。一般来说，*核函数*（与前面关于矩阵提到的核不同）用于定义数据对象之间的 *相似性*。内积核通常被用来确定输入数据的相似性，以便线性分类器可以用来解决本质上是非线性问题。在支持向量机中，核技巧最早由 Boser 等人于（[1992](#ref.xhtml#re_CIT000041)）提出。

尽管统计学很大程度上强调线性，但非线性问题遍布科学实践。例如，通过多项式变换或其他 *基函数变换* 来建模这种非线性，正如我们稍后将看到的那样，可能很复杂、耗时且在计算上不可行。然而，通过对输入数据取核，原本线性 *不可分* 的数据现在变得 *可分*，而无需在数学上真正进入那些更高维度。也就是说，核技巧允许我们在 2 维中保持不变，例如当数据仅在 3 维中可分时。本质上，*核技巧* 或 *核替代*（[Bishop, 2006](#ref.xhtml#re_CIT000032)，第 292 页）允许将无限维问题简化为有限维问题（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。

核函数 `k` 定义为

`k(x,x′) = k(x′,x) = ϕ(x)′ϕ(x′)`  

(2.110)

其中内积 `x, x′` 是两个向量之间 *相似性* 的度量，因此核函数被视为数据“相似性”的度量。也就是说，核函数本质上衡量观测值彼此的相似程度。如 (2.110) 所示，此处的核函数也是对称的，使得 `k(x,x′) = k(x′,x)`。`k(x,x′)` 的计算在原始数据空间进行，但在特征空间中等价于内积 `ϕ(x)′ϕ(x′)`。

核的唯一关键要求之一是它们必须是 *正定* 的，因为可以证明正定核在希尔伯特空间中诱导出内积（[Mohri, 2018](#ref.xhtml#re_CIT000253)）。读者可能记得，正定性确保了 `K` 的特征值（严格）为正，其中 `K` 在此情况下为 *核矩阵*。更进一步，*对于正定核，它总是会产生（或“关联”）* *一个半正定核矩阵*（[Mohri et al., 2018](#ref.xhtml#re_CIT000253)，第 .108 页）。存在多种核，例如 *多项式核*、*高斯核*、*sigmoid 核* 等。关于核的重要一点是，它们不必在原始数据空间 `x, x′` 中实际作为内积计算，就能暗示特征空间中的内积 `ϕ(x)′ϕ(x′)`。*许多其他核是可能的，它们在计算上并不直接在数据空间中计算内积*。*重要的是，核在数据空间中表达了相似程度，从而在特征空间中诱导出内积空间*。

为了更好地说明核技巧，请考虑 [图 2.14](#c2.xhtml#f2.14) 中描绘的两个类别的数据。143

![图 2.14 两个类别的数据，显然不是线性可分的。返回文本。⏎](images/fig2.14.jpg)

*图 2.14* 两个类别的数据，显然不是线性可分的。[返回文本。⏎](#c2.xhtml#re_f2.14)

当然，[图 2.14](#c2.xhtml#f2.14) 中的数据不是线性可分的；也就是说，我们需要一条弯曲的曲线来分隔这两个组。然而，通过计算数据的 *核*，*在其原始维度中*，我们本质上将这种非线性转化为特征空间中的线性可分问题。但为什么会这样工作？核技巧为什么能做到这一点？

核技巧之所以有效的原因与 *Mercer 定理*（[1909](#ref.xhtml#re_CIT000248)）相关，它本质上得出以下非常重要的结果：

> *当已知函数存在时，即使对该函数是什么的知识不完整或未知，也可以使用核来近似函数*。

也就是说，核本质上包含丰富的关于更高维度（我们目前可能还不了解）的信息。我们可以在原始配置下或通过核来处理问题这一事实被称为 *对偶表示*（[Bishop, 2006](#ref.xhtml#re_CIT000032)）。用文字来说，所谓的“核技巧”本质上传达的想法是：*你在更高维度中处理一个复杂问题，你可能甚至不知道那些维度是什么，甚至不知道可能有多少个，但如果你在现有的低维空间中计算核，你就可以在从未 ***显式*** 去过那里 的情况下了解很多关于那些更高维度的信息*。通过虚构的类比，核可能会让你留在并在此 3 维空间宇宙中计算，同时可能学习到关于另一个宇宙（例如可能在五维的宇宙）的一些东西。

如前所述，核的实用性基于我们处理的许多数据集不是线性可分这一事实。*应用核（希望）使数据线性可分，并且还允许得到一个凸解*（[Goodfellow et al., 2016](#ref.xhtml#re_CIT000131)）。凸解（我们稍后会更详细讨论）是理想的，因为它们具有 *全局* 最小值，因此算法不会陷入 *局部* 最小值。也就是说，Mercer 条件的一个重要含义是它建立了支持向量机和类似算法的优化问题的凸性（[Mohri et al., 2018](#ref.xhtml#re_CIT000253)）。因此，在优化中保证了全局最小值。
