
## 8.2 Linear Models

Note that the above model is *linear in the parameters*, meaning that `β[0]`, `β[1]`, … `β[p]` are all raised to the exponent “1.” Even if `x[1]`, for example, was raised to the second power, `x[1]²`, the model would still be regarded as a linear model so long as `β[0]`, `β[1]`, … `β[p]` remained raised to a coefficient of one; however, one could say it is no longer linear in the variables. *Linear models require only that coefficients be raised to no terms greater than one*. What basis transformations on the actual variables we perform is inconsequential as it pertains to the linearity or nonlinearity of the actual model in statistical parlance ([Bishop, 2006](#ref.xhtml#re_CIT000032)). For example, the following model would rightly be considered *nonlinear* because it is nonlinear in the coefficients, notably the `β[2]²` term:

`y[i] = β[0] + β[1]x[1] + β[2]²x[2] + ε[i]`

(8.2)

Note that the following model is also nonlinear because of `β[2]²` but not because of `x[2]²`; it is considered both nonlinear in the *parameter* and *variable*:310

`y[i] = β[0] + β[1]x[1] + β[2]²x[2]² + ε[i]`

(8.3)

### 8.2.1 Intrinsically Linear Models

A useful distinction to make when it comes to linear vs. nonlinear models is that between *intrinsic linearity* vs. *non-intrinsic linearity* (Neter et al., [1996](#ref.xhtml#re_CIT000266)). A model that is nonlinear, but that can be linearized through a transformation is often referred to as an *intrinsically linear model*. Perhaps the most classic example of this is the *exponential response*, where if we were to take the `log` of the exponential in such a model, we would obtain a linear model. That is, we can transform the response into one that is linear. It is intrinsically linear because its nonlinearity is a product only of a transformation. A *non-intrinsically linear model*, on the other hand, is one that cannot be linearized via transformation.

### 8.2.2 General vs. Generalized Linear Models

Many of the models featured thus far in this book can be considered special cases of the wider *general linear model*. Regression and analysis of variance models are indeed special cases of this wider framework. But what defines a general linear model exactly? When we refer to a specific model arising from this “general” framework, we usually mean that the distribution of the error term, `ε[i]`, has an expected *normal distribution*. The classic linear regression model, `y[i] = β[0] + β[1]x[1] + ε[i]` is one such example where `ε[i] ∼ N(0,σ[ε]²)`, meaning that the error in the model is expected to be normal, having a mean of 0 and a finite and measurable variance, `σ[ε]²`. There are many situations, however, where we would not naturally expect the error term to behave this way. One classic and popular example is when the response variable is not continuous but instead *binary*. When a response variable is binary, the expectation of the error term is, not surprisingly, not normal. Nor could we reasonably expect errors to have constant variance ([Fox, 2016](#ref.xhtml#re_CIT000106)).

The difficulty then on a theoretical level is how to deal with error distributions that have a non-normal expectation. They seem to be a different class of models altogether. However, thanks largely (but not exclusively) to the work of [Nelder and Wedderburn (1972)](#ref.xhtml#re_CIT000265), a wider framework of statistical models was proposed that could encompass even these types of models with non-normal error distributions. Recall that understanding statistics is all about looking for *hierarchies, of* classifying “special cases” of models in the context of higher forms and generalities. This is precisely what these authors accomplished in proposing a framework for modeling that encompasses not only the classic linear model (regression, ANOVA) that features normally distributed error terms, but also models that contain non-normal error terms. This new class of models they called the *generalized linear model*, and hence a vast array of models can be situated in this general framework. That is, *the generalized linear model encompasses models that contain normally and non-normally distributed error terms*.

Essentially, the logic of the generalized linear model is to take an otherwise nonlinear model and make it mimic linearity through what is called a *link function*. Through the link function, the model becomes approximately linear and we can then treat the model more akin to how we would treat a classic linear model. This is the essential logic of the generalized linear model. An important distinction to make here is that it is the *decision surface* that is linearized, not truly the model entirely or necessarily ([Bishop, 2006](#ref.xhtml#re_CIT000032)). Generalized linear models such as logistic regression engage in transformations that make them “linear-like” ([Fox, 2016](#ref.xhtml#re_CIT000106)), such that otherwise nonlinear models can be “linearized” via the transformation (e.g., taking a link function such as the `log` of the odds in the case of logistic regression).311

One very special case of the generalized linear model that has historically been very popular across virtually all scientific fields, especially medical fields, is the aforementioned *logistic regression model*, which we survey next.

## 8.3 The Logistic Regression Model

The logistic regression model is known as the *conditional Maxent model* ([Mohri et al., 2018](#ref.xhtml#re_CIT000253)) in machine learning circles, which is simply the multinomial regression model of which binary regression is a special case. The logistic function is given by the following,

$$p\\left( x \\right) = \\frac{e^{\\beta\_{0} + \\beta\_{1}x}}{1 + e^{\\beta\_{0} + \\beta\_{1}x}}$$

(8.4)

where we can work with the formulation in (8.4) and get

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} = e^{\\beta\_{0} + \\beta\_{1}x}$$

(8.5)

The left-hand side of (8.5), `p(x)/[1−p(x)]` is what is referred to as the *odds*. In words, the odds is the probability of an event occurring, `p(x)`, relative to the probability that the event does not occur, `1−p(x)`. If the probability of an event occurring is the same as the probability of it not occurring, then the odds are equal to 1.0. For example, suppose `p(x)=0.5`, then it stands that,

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)}\\frac{0.5}{1 - 0.5} = \\frac{0.5}{0.5} = 1.0$$

Suppose we were to take the `logarithm` on both sides of

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} = e^{\\beta\_{0} + \\beta\_{1}x}$$

so that,

$$\\log\\left\\lbrack \\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} \\right\\rbrack = \\log\\left\\lbrack e^{\\beta\_{0} + \\beta\_{1}x} \\right\\rbrack$$

(8.6)

Recall that taking the `log` of an exponential function `e` has the effect of bringing the exponent down and so what we have from the above is

$$\\begin{array}{l} {\\log\\left\\lbrack \\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} \\right\\rbrack = \\log\\left\\lbrack e^{\\beta\_{0} + \\beta\_{1}x} \\right\\rbrack} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = \\beta\_{0} + \\beta\_{1}x} \\\\ \\end{array}$$

(8.7)

That is, *the log of the odds is assumed to be a linear function*. The log of the odds goes by the name of the *logit*, and hence once we produce the logit, we are effectively now working with an approximate linear model similar in many respects to the classic linear model of regression. Of course, it is not *exactly* the same, since the units we are working in are no longer the natural units of the original variable, but instead are in units of the *logged odds*, or the *logit*, and hence the interpretation of parameter estimates will be in units of the logit.312
