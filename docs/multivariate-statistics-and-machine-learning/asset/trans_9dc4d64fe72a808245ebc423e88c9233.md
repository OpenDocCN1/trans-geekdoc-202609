
## 1.10
为延伸上述讨论，*统计规律性*往往使极其冒险的行为看起来没那么冒险。例如，再次考虑航空旅行。航空旅行有风险吗？危险吗？当然是！在本质上仍是实验性舱体的东西中飞行超过30,000英尺是一项冒险的事业。然而，从统计角度来看，开车去超市更危险。我们对风险的评定取决于所采用的视角。以65英里每小时行驶在高速公路上的汽车比以400英里每小时在30,000英尺高空飞行的飞机风险更小，但不是*统计上*。

统计规律性以降低我们的*风险感知*而闻名，但这仅在过去行为的意义上如此。也就是说，如果一次航空航班与之前的大多数航班相似，那么从统计上看它风险很小。然而，尽管我们将今天的航班建模为来自过去航班的分布，但我们对当前事件一无所知。*它完全是新的*。完全有可能（尽管极不可能）从现在开始的大多数航班都会坠毁；我们 simply 不知道，因为我们尚未观察到这些新实例。我们唯一确定的只有概率，我们在*假设*这些数据是从与过去事件相似的概率分布中抽取的前提下将这些概率应用于新数据。

因此，有人可能会说，30,000英尺的飞行在*绝对*意义上是有风险的，但从统计上看风险要小得多。用统计术语来说，飞行是*相对*无风险的，因为其成功的贝叶斯先验概率相当高（我们稍后会讨论贝叶斯统计）。然而，从哲学上讲，先验对实际的新物理事件一无所知。它仅在*假设*新事件是从由相似先前事件组成的分布中抽取的前提下对其概率进行建模。

### 1.10.1 贝克抑郁量表：你有多抑郁？
风险当然也普遍存在于临床障碍的诊断中。假设作为一名临床医生，你给一位新客户施测*贝克抑郁量表*（*BDI*），而该客户的得分处于轻度抑郁范围。BDI是抑郁症的知名筛查工具。好的临床医生知道不应仅使用单一诊断标准来诊断客户。然而，高BDI分数意味着什么？*它并不意味着该障碍*。它只能表明该障碍的“征兆”，并且需要应用经典的贝叶斯推理来获得抑郁的实际概率。如果客户患该障碍的先验概率较低，那么高BDI分数可能不足以表明或诊断抑郁。这是对概率进行修正的基本原则，然而事实一次又一次表明，许多诊断医学和临床障碍的人并不理解或不重视这些基础。例如，由于HIV检测结果报告不准确，患者的生命被颠覆了。这不仅仅是琐事；这是至关重要的。*未能向客户群体妥善传达统计结果等同于医疗事故。患者和客户有权被告知准确的概率估计并获得如何解读它们的指导。*

## 1.11 决策、风险分析与优化
上述关于风险和决策的讨论自然地联系到数学和统计学中正式优化的思想。在本书介绍的许多方法中，从优化的角度来看，目标是*最小化*或*最大化*某个函数，这最终本质上被转化为以尽可能少的误差最小化做出错误决策的风险。被称为*风险分析*或相关领域*决策分析*的研究领域是迷人的学科，并渗透到许多应用实践领域。最终，许多统计分析都是以做出*好决策*为最终目标进行的。然而，几乎没有决策是无风险的。尽管有人可以争辩说在理论上存在完美的决策，但它们之所以“完美”，仅在于其经过严格思考和理性构思。它们都包含后果和错误带来的成本，至少在短期内如此。

我们每天都面临决策，并且在不完美的知识下做出决策。无论我们是否正式对这些决策进行决策分析，还是直觉上试图平衡做出错误决策的风险与做出正确决策的好处，这些决策任务都渗透到我们的生活中。关于风险心理学以及人类如何管理风险的文献非常丰富，有兴趣的读者应查阅此类文献。如果这些主题引起你的兴趣的话。现在，只需简单概述这一广泛而令人兴奋的研究领域的一些特征就足够了。

### 1.11.1 做出错误决策的风险
考虑以下假设情景——你刚刚还清了价值约$400,000的房屋。虽然在法律上你在与银行签订抵押贷款时必须购买火灾房屋保险，但现在你完全拥有它后，就不再需要持有任何保险。你仔细思考是否仍应购买保险，还是把本应支付的保费存起来用于其他用途。真正解决这一决策问题的唯一方法是对竞争事件分配概率并评估*期望*或*效用*。如果保险价格为$1,000 per year，支付保费似乎是理所当然的，因为房屋因火灾损失的成本在财务上是毁灭性的，总损失为$400,000，即房屋的市场价值。然而，如果你很少离开家，火灾风险很小，那么花费在保险保费上的$1,000最好花在别处。当然，大多数房主会支付保费，因为即使很小，失去房屋的风险也太大而不应防范此类事件。然而，在 presumably 无法容忍此类风险的同时，同一个人会定期自愿开车在一段非常危险的高速公路上兜风，其丧命的风险远大于房屋因火灾损失的风险。我们要说明的要点是，风险承受能力会因具体问题而大不相同，而风险的感知，无论理性还是非理性，都可能因情境和情况而变化。
