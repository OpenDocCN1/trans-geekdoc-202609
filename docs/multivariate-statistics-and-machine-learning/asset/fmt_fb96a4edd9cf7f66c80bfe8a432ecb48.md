## 1.16 Overview of Statistical and Machine Learning Concepts

Having surveyed some fundamental philosophical assumptions and ideas underlying science, statistics, and machine learning, we now turn to surveying statistical and machine learning concepts themselves. Many of these concepts have long histories in statistics where others are more modern and apply mostly to machine learning. Topics surveyed here are selective; they are the ones the reader should be familiar with in order to understand the rest of the book.

### 1.16.1 Probably Approximately Correct

The idea of `probably approximately correct` (`PAC`) learnability arose from statistical learning theory for the purpose of identifying hypothesis classes or `sets` (usually infinite in nature) that are actually learnable and provide low generalization error ([Haussler, 1990](#ref.xhtml#re_CIT000146); [Valiant, 2013](#ref.xhtml#re_CIT000370)). Hypothesis classes are essentially subsets of virtually all functions that `could` be selected in modeling some phenomenon. For instance, suppose we select a hypothesis that minimizes empirical risk on a 48sample. How do we know such a hypothesis will also minimize population risk? If the hypothesis class is so-called `PAC learnable`, then we know it will probably also minimize population risk. That is, `PAC learnability tells us that the selected function will, essentially, likely have low generalization error`. That is, a PAC model will `probably` generalize well to new data.

A more direct and pragmatic way of understanding PAC learnability is to consider how well a hypothesis or concept class will `not` predict. That is, any hypothesis that is seriously wrong will almost certainly be “discovered” with high probability after a small number of examples or data points in a sample because it will (very soon) make an incorrect prediction. Thus, any hypothesis that is consistent with a sufficiently large set of training examples is unlikely to be seriously wrong. That is, it has been “tested” via experience, which implies it must be `probably approximately correct`. Any learning algorithm that returns hypotheses that are probably approximately correct is called a `PAC learning algorithm`, and such a designation can help provide bounds on the performance of various learning algorithms. For a precise and technical characterization of PAC learnability, see Mohri et al. ([2018](#ref.xhtml#re_CIT000253), p. 11).

### 1.16.2 No-Free-Lunch Theorem

As mentioned at the outset of this book, one element that distinguishes the machine learning paradigm from that of classical statistics is a focus more on the `algorithm` or `method` than the data. That is not to say the data are not important; they most certainly are of course, but the `performance` of the algorithm or procedure is what is studied most. Questions such as “Does logistic regression outperform discriminant analysis, and if so, under what conditions?” dominate the current machine learning zeitgeist.

Given this emphasis on the algorithm, it makes sense to ask then whether one algorithm dominates all others. That is, we ask the question:

> `Is there a best universal learner?`

The answer to this question is contained in what is known as the `No-Free-Lunch Theorem`, which essentially holds that `there is no universal learner`. There is no “best” algorithm under all conditions for all data. Unpacked, what this implies is that for any learning algorithm there is a data set for which it may be very accurate and another data set for which it is very poor. The assumptions we enter with in one substantive situation, often called the `inductive bias`, are not the same as in another domain, and hence a universal learner across all domains does not exist. When we say a learning algorithm is “good,” we are only quantifying how well its inductive bias matches the properties of the data we are currently working with ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)). However, as good as the learner may be in one setting, there is always a task in which it will fail.

As a simple example, linear regression may work wonderfully in predicting income based on education levels but fail miserably in predicting COVID-19 probabilities of death. An equivalent and more crude interpretation of the theorem is that for even the most sophisticated algorithm one can conceive, over all conceivable possible tasks it will have the same `average` performance as merely predicting that every point belongs to a particular class ([Goodfellow, 2016](#ref.xhtml#re_CIT000131)). Why will the performance of an algorithm chosen to model a specific situation likely be better? Because we will have chosen that algorithm for the specific task at hand coupled with our knowledge of the data. In other words, we are no longer averaging across all tasks. We are selecting a specific task and using an algorithm well-suited to that task.

As an analogy, modeling IQs across all possible theoretical distributions is hopeless and if we combined (or averaged) all distributions, our model of IQ would be quite poor. Fortunately, we do not employ all distributions; we usually employ a `normal distribution` because it best approximates 49the empirical shape of the distribution of IQ. The normal distribution isn’t the “best” distribution for all tasks; it is the best for particular tasks such as the modeling of IQ. That is, we “narrow down” from all distributions by making `assumptions` regarding the task we are working with. This is a powerful way to conceive of assumption-making when it comes to fitting statistical distributions – `assumptions help narrow down the search and selection of an algorithm`.

Think of this next time your chosen algorithm fits well to a given data set and be sure to not exaggerate how “good” your algorithm actually is. There is no `best` algorithm for all circumstances. Algorithms and statistical procedures must be chosen wisely for each task, which implies knowing not only something about the data but also something about the substantive area to which it is being applied. Linear regression, for instance, can never be the “best algorithm.” It can only be the best coupled with a particular data set which suits it well (e.g., one that exhibits linearity and homoscedasticity of variances).
