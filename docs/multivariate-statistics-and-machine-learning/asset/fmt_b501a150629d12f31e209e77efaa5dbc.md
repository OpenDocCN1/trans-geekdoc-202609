
where now `e[1]`, `e[p]` represent elements of the second eigenvector. More precisely, the eigenvectors are orthogonal, the components are uncorrelated, though it is fine to use the terms “uncorrelated” and “orthogonal” interchangeably in this context so long as one is aware of the difference. We need not stop there! We can continue to derive principal components from our data each accounting for a successive amount of variance unaccounted for by prior components. Note that in our development of classical PCA, we have applied the technique to the entire training data at once. That is, we have assumed the entire training data is readily available. An alternative to this approach is known as *incremental PCA* ([Lippi & Ceccarelli, 2019](#ref.xhtml#re_CIT000224)), where the updated covariance matrix `Σ[n + 1]` is based on the “old” covariance matrix, `Σ[n]`. That is, incremental PCA adds new observations (the +1 in `n + 1`) to the covariance matrix and thus has computational advantages over traditional PCA. The benefit is that not all data has to be saved in memory and the algorithm can be applied when the data set is expected to grow quickly or if the stationary data set is itself very large, too large to fit into memory at once ([Lippi & Ceccarelli, 2019](#ref.xhtml#re_CIT000224)). Incremental PCA is available in Python in `sklearn` via `IncrementalPCA`.

### 11.2.2 PCA as a Least-Squares Technique and Minimizing Reconstruction Error

As is the case with most statistical methods, there is more than a single interpretation of principal components analysis. Our interpretation thus far has been via eigen analysis or SVD, but we can also interpret it as a least-squares technique similar to that of least-squares regression, with which we are already familiar. Instead of projecting from higher-dimensional space to lower-dimensional space such that we minimize the sum of squared errors in a response as in the typical ordinary least-squares regression, in PCA we also seek a projection, but this time from higher-dimensional space to lower-dimensional space such that the sum of squared *perpendicular distances* are minimized, where “perpendicular” is equivalent to *orthogonal*.

For example, in Figure 11.1 is a projection from two-dimensional space to a single *hyperplane* such that the orthogonal squared data distances from the principal component are minimized.399

In fact, in the typical PCA analysis, we seek to minimize what is known as the *reconstruction error* ([Murphy, 2022](#ref.xhtml#re_CIT000259)). Not coincidentally, it can be shown that the reconstruction error is minimized when the resulting components are eigenvectors of an eigen analysis of the covariance matrix. Details of the derivation can be found in [Bishop (2006)](#ref.xhtml#re_CIT000032) and [Murphy (2022)](#ref.xhtml#re_CIT000259). The average reconstruction error is given by:

$$l\\left( W,Z \\right) = \\frac{1}{N}{\\sum\\limits\_{n = 1}^{N}\\left| \\middle| x\_{n} - Wz\_{n} \\middle| \\right|^{2}}$$

(11.4)

where `x[n]` are the original data points, `z[n]` are the derived data points based on the projection, and `W` is an orthogonal matrix. The optimal solution (i.e., `l(W, Z)`, which is a *loss*, is minimized) is obtained when `Ŵ = U[L]`, where `U[L]` are the eigenvectors of a covariance matrix, and hence by definition for a symmetric matrix with distinct eigenvalues, orthogonal. Note that `W z[n]` is essentially trying to produce the least amount of deviation from `x[n]` and under the most ideal of circumstances where the reconstruction of data based on the obtained eigenvectors (i.e., loosely, components) is perfect, then `l(W, Z) = 0`. Minimizing this reconstruction error is equivalent to maximizing the variance in the variables (Murray, 2022) which was the original interpretation of PCA we started out with. Again, as is the case with most statistical methods, there are a variety of different ways to derive the PCA technique, where in this case it can be shown that minimizing the reconstruction error is *mathematically equivalent* to maximizing the variance of the data projected by the components solution. Different ways of perceiving a statistical or machine learning technique from various angles and perspectives can pay dividends in truly understanding it in depth.

In addition to PCA being computed by eigen analysis or (truncated) SVD, components can also be gotten by the expectation-maximization (`EM`) algorithm and has advantages over eigen analysis such that it is often faster ([Murphy, 2022](#ref.xhtml#re_CIT000259)).400

### 11.2.3 Choosing the Number of Derived Components

Under most conditions of a well-behaved matrix, the number of components that we can obtain is equal to the number of observed variables subjected to the components analysis. That is, if `x[1]`, ..., `x[p]` consists of say, 100 variables, then under usual (and most common) conditions, the number of components computed on these variables will equal 100. In brief, *a PCA on observed variables does not, by itself, reduce the information in the data*. In the case of the 100 variables, *choosing* less than 100 computed components is where the actual *data reduction* occurs, else all the PCA has done is disproportionately load most variance hopefully onto the first few components. What this means is that PCA is simply “packaging” (or *re-packaging*) the variance of observed variables into successive linear combinations. But it is not truly dimension “reduction” in an applied sense until we select less than the total number of components generated. This is the logic of PCA as a dimension-reduction technique. PCA is first and foremost only a *transformation*.

### 11.2.4 Why Reconstruction Error Is Insufficient for Choosing Number of Components

As a result of PCA attempting to account for as much variance in the variables as possible, when choosing the number of dimensions (components) to retain, one cannot simply use the *reconstruction error* or *variance explained* as a guide, since the more components one keeps, the more variance one will explain and the smaller will be the consequent reconstruction error. This is somewhat analogous to the effect of adding more predictors in a multiple regression – variance explained will virtually always increase (except in very unusual situations of zero correlation), and hence choosing the “best” regression model based on variance explained alone is not a good strategy. This limitation of using reconstruction error as a guide will also resurface when we consider cluster analysis later in the book and seek a measure to justify the number of clusters to retain. Since reconstruction error typically and necessarily reduces as the number of clusters increases, reconstruction error is not a sufficient measure for making decisions on how many clusters to retain.

To determine the number of components to keep, one should primarily use substantive judgment in addition to statistical indicators, and in the end, a bit of common sense. For example, if the first two components explain 70% of the variance, but the third component only explains an additional 1%, then obviously the two-component solution will dominate under *most* circumstances (depending on the substantive nature of the investigation). Graphical measures such as the *scree plot* can be used to visualize both the reconstruction error as well as the variance explained, and one typically looks for a “bend” in such plots to indicate where the reconstruction error (or variance explained) suddenly “drops.”
