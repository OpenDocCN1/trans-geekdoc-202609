## 5.4 高斯-马尔可夫定理：我们为何喜欢最小二乘估计

我们为何如此喜欢最小二乘估计量？它们有何吸引力？关于它们最重要的内容可以概括为 *高斯-马尔可夫定理*，该定理断言，当误差独立分布且期望为零、方差恒定时，参数 `a^T β̂` 的最小二乘估计在所有线性无偏估计量中具有最小方差（[Fox, 2016](#ref.xhtml#re_CIT000106)，p. 212）。最小二乘估计量常被称为“BLUE”，意为 *最佳线性无偏估计量*。如前所述，`a^T β̂` 的最小二乘估计为

`a^T β̂ = a^T (X^T X)^{-1} X^T y`

(5.21)

其期望等于

$$\\begin{array}{l} {E\\left( a^{T}\\hat{\\beta} \\right) = E\\left( a^{T}\\left( XTX \\right){- 1}X^{T}y \\right)} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = a^{T}\\left( XTX \\right){- 1}X^{T}X\\beta} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = a^{T}\\beta} \\\\ \\end{array}$$

(5.22)

高斯-马尔可夫定理指出，对于任何其他期望为 `a^T β`（无偏）的线性估计量，例如 `E(w^T ŷ) = w^T y`，最小二乘估计 `a^T β̂` 的方差小于或等于 `w^T y` 的方差。有关该定理的证明，请参阅 [Fox (2016](#ref.xhtml#re_CIT000106)，p. 213）。该定理的一个推论是，最小二乘估计量在所有无偏的线性估计量中具有 *最小的均方误差*（Hastie et al., [2009](#ref.xhtml#re_CIT000145)）。

### 5.4.1 无偏估计量总是最好吗？

正如我们稍后会看到的，在回归和其他方法中对无偏估计量的限制并不总是明智的。请记住，偏差-方差权衡在估计中始终起作用。大多数时候，我们希望最小化估计中的偏差。然而，有时为了降低方差而允许估计量带有一定的偏差可能是有益的。

有偏估计量例如 *岭回归* 中的 *岭估计量* 有时可能优于无偏估计量。当最小二乘估计 *不稳定* 时（[Izenman, 2008](#ref.xhtml#re_CIT000167)），就是一个有偏估计量可能更优的情况。也就是说，如果 `(X^T X)^{-1} X^T y` 中的 `X` 的秩小于满秩，则会出现 *奇异性*，这意味着最小二乘估计将不再 *唯一*。当由于共线性或其他问题（例如相关误差）导致回归假设不成立时，必须寻求替代的估计解决方案。虽然完全共线性很少发生，但“几乎共线性”的变量根据研究背景经常出现。面对这些情况以及数据病态的情况，即估计量对数据微小变化相当敏感时，*有偏* 估计量可能是一个更好的选择（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。共线性和不稳定性往往齐头并进，因为共线性的影响可能产生过大正负估计系数，其符号在数据极其微小的变化下就会被逆转。标准误差也可能被严重夸大，从而导致非统计显著效应，而如果不存在共线性，这些效应可能就具有统计显著性。

除上述情况外，对于某些数据集，`X` 中的输入变量数量可能远大于数据中的观测数。在这种条件下，OLS 估计量仍然存在，但不是 *唯一* 的，因此在这种情况下有偏估计量可能有用。我们将在书中稍后讨论岭和 Lasso 等有偏估计量。
