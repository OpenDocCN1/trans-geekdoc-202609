### 2.36.1 Vectors

A vector is an array or listing of numbers, where the following is a column vector with elements `x[1]` through `x[n]`,

$$x = \\left\\lbrack \\begin{array}{l} x\_{1} \\\\ x\_{2} \\\\ x\_{3} \\\\ {\\,\\, \\cdot} \\\\ x\_{n} \\\\ \\end{array} \\right\\rbrack$$

Because we are working in the real numbers, we denote `x` ∈ ℝ^(`n`) and the listing of numbers `x[1]` through `x[n]` denotes the elements of the vector `x`. In this book, if not indicated specifically, it can be assumed that we are working in the field of *real numbers*, and hence where “`x` ∈ ℝ^(`n`)” is not indicated, it can be generally assumed. None of the work featured in this book features the use of complex numbers (`x` ∈ ℂ^(`n`)).

In R, we can create a simple vector by:

```
> x <- c(0, 2, 5, 8, 10)
> x
[1] 0 2 5 8 10
```

Creating the same vector in Python is just as easy:

```
import numpy as np
x = [0, 2, 5, 8, 10]
x
Out[294]: [0, 2, 5, 8, 10]
x_1 = [[0], [2], [5], [8], [10]]
x_1
Out[300]: [[0], [2], [5], [8], [10]]
```

#### 2.36.1.1 Vector Spaces and Fields

A *vector space* is generally a space where vectors can be added and lengthened or shortened by scalars, which otherwise implies multiplication and obeys a series of rules featuring these two operations. That is, vector spaces generally describe spaces where the operations of addition and multiplication occur. A *field* is an algebraic structure that satisfies a list of properties such as *commutative* and *associative* laws of addition and many more. Many algebraic structures are special cases of others when certain properties are removed. For the purposes of this book, many of the mathematical operations that underlay methodologies occur in vector spaces because they feature vector and matrix operations.

#### 2.36.1.2 Zero, Unit Vectors, and One-Hot Vectors

A vector of all zeroes is called the *zero vector*, while the unit vector has length or magnitude equal to one. Vectors that contain all zeroes except for a single value of “1” are also known as *one-hot vectors*, a term arising from electrical engineering where a circuit is either “on” or “off.” *One-hot encoding* can also mean changing status from text to a number, for instance, “`red = 0`” which is essentially similar to dummy coding variables.

#### 2.36.1.3 Transpose of a Vector

The *transpose* of a column vector is obtained by writing columns as rows, in the case of

$$x = \\left\\lbrack \\begin{array}{l} x\_{1} \\\\ x\_{2} \\\\ x\_{3} \\\\ {\\,\\, \\cdot} \\\\ x\_{n} \\\\ \\end{array} \\right\\rbrack$$

we have

`x^T` = [`x[1]`,`x[2]`,`x[3]`,⋅⋅⋅,`x[n]`]

(2.90)

where `x^T` denotes the *transpose* of `x`. Often (as we do in this book), the transpose is written as `x'`. More formally, the transpose of a *matrix* is obtained by exchanging rows for columns and columns for rows in a matrix. Some properties of transposes include (`A^T`)^T = `A`, (`A B`)^T = `B^T A^T`, (`A+B`)^T = `A^T` + `B^T`, (`c A`)^T = `c A^T`, |`A^T`|=|`A`|, among others.

Transposing vectors (and as we will see, matrices) is a useful operation in the computation of many statistics and quantities used in machine learning. For one, and as we will see, it allows for the multiplication of vectors and matrices. In R, the transpose function is `t()`. In Python, the relevant function is `numpy.transpose()`.
