
In our survey of decision trees thus far, we have discussed only those of regression trees. Decision trees, not surprisingly, are also applicable to classification. Classification trees are used to predict *qualitative* or *categorical* responses instead of *continuous* responses as was the case for the regression trees just surveyed. As for regression trees, *recursive binary splitting* is used to build the tree. However, in assessing the quality of the tree, we cannot use `RSS` as the quantity to minimize since `RSS` is applicable to continuous measures only.

What to use for estimating error rates instead of `RSS`? An alternative for classification trees is the *classification error rate*:

`E` = 1 − max[*k*](`p̂[m k]`)  
(10.2)

where here `p̂[m k]` is the proportion of observations (on the *training* data) in the *m*th region of the tree that are classified in the class denoted by `k` (James et al., [2013](#ref.xhtml#re_CIT000168)). Hence, (10.2) is the fraction of observations in error for the given class. The classification error rate is not always a perfect measure of the quality of the tree, however. A problem with the classification error rate is that it is not sensitive enough of a measure for growing a tree ([James et al., 2013](#ref.xhtml#re_CIT000168), p. 312). That is, it is a bit too “crude” of a measure. We require other measures to help in assessing the build of our tree. These two measures are the *Gini index* and the *deviance*, which we now discuss.

### 10.3.1 Gini Index

The *Gini index* is a measure that can be used in place of, or to supplement the classification error rate and can take the place of residual sums of squares in the regression tree context. It is a measure of *node purity* (also often called node *impurity*), defined by

$$G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}$$  
(10.3)

which is a measure of total variance across the `k` classes, where recall `p̂[m k]` is the proportion of training observations in the `m`th region that are from the `k`th class. As a measure of total variance across the classes, the index takes on a smaller-than-not value the closer the `p̂[m k]` values are to 0 or 1. That is, when `p̂[m k]` is equal to 0, then `G` reduces to

$$\begin{array}{l} {G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}} \\ {\,\,\,\, = {\sum\limits_{k = 1}^{K}{0\left( 1 - 0 \right)}}} \\ {\,\,\,\, = 0} \\ \end{array}$$

On the other extreme, when `p̂[m k]` = 1, then375

$$\begin{array}{l} {G = {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\left( 1 - {\hat{p}}_{mk} \right)}}} \\ {\,\,\,\, = {\sum\limits_{k = 1}^{K}{1\left( 1 - 1 \right)}}} \\ {\,\,\,\, = 0} \\ \end{array}$$

A smaller-than-not value for the Gini index indicates that a node contains predominantly observations from a single class ([James et al., 2013](#ref.xhtml#re_CIT000168)). The variance is maximized as `p̂[m k]`→0.5 across the classes, which equals 0.5(0.5) = 0.25 per class. Any deviation from this maximum, for instance, 0.4(1 − 0.4) = 0.24 produces a lesser product and hence contributes less variance to the sum ([Bishop, 2006](#ref.xhtml#re_CIT000032)). For `p̂[m k]` = 0.1, for instance, the given product is 0.1(0.9) = 0.09 which is quite small indicating hardly any variance across the classes. This again is why `p̂[m k]`→0.5 maximizes the variance of the classes.

An alternative to the Gini index is *cross-entropy* or *deviance*, defined by

$$D = - {\sum\limits_{k = 1}^{K}{{\hat{p}}_{mk}\log{\hat{p}}_{mk}}}$$  
(10.4)

Recall that `p̂[m k]` is bound between 0 and 1, which implies that − `p̂[m k]`log `p̂[m k]` must be equal to or greater than 0 (James et al., [2013](#ref.xhtml#re_CIT000168), p. 312). Entropy takes on a value close to 0 for `p̂[m k]`′*s* approaching 0 or 1. That is, as was the case for the Gini index, overall *node purity* is suggested by a small `D` ([James et al., 2013](#ref.xhtml#re_CIT000168)). Entropy can be interpreted as the minimum number of bits of information required to encode the class code of an instance or observation ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)).

> *The Gini index and entropy are very similar to one another. Both attempt to provide a measure of how much variance exists across the classes. They can both be regarded as measures of node purity.*
