
## 多元降秩回归

多元降秩回归（[Izenman, 1975](#ref.xhtml#re_CIT000166)）是多元回归模型的一个非常通用的框架，我们在这里仅为将其纳入一般回归框架的教学目的而提及。经典多元线性回归模型可以以其最一般的方式表述为

`Y` = `μ` + `C` `X` + `ε`

(5.32)

其中 `C` 是回归系数或参数的矩阵，对其存在一组线性约束。在 `C` 降秩的情况下，这些线性约束意味着 `C` = `A` `B`，其中 `A` 和 `B` 都是非唯一的满秩矩阵（[Izenman, 2008](#ref.xhtml#re_CIT000167), p. 177），因此我们可以将经典多元模型重写为

$$\\begin{array}{l} {Y = \\mu + {CX} + \\varepsilon} \\\\ {\\,\\,\\,\\,\\, = \\mu + \\left( {AB} \\right)X + \\varepsilon} \\\\ \\end{array}$$

(5.33)

其中在 (5.33) 中，我们只是用 `A` `B` 替代了 `C`。也就是说，降秩多元模型通过如 [Izenman (2008)](#ref.xhtml#re_CIT000167) 所总结的那样，放宽了对 `C` 的秩的隐含约束，从而推广了经典多元模型，这进而允许进行降维。该主题到现在为止已经很熟悉了；一个秩小于满秩的矩阵很可能在其内部隐藏着底层 260维性。通过估计 `A` 和 `B`，我们有效地“处理”了 `C` 的降秩条件。关于 `A` 和 `B` 为何非唯一的证明，参见 Izenman（[2008](#ref.xhtml#re_CIT000167), p. 177）。

若干统计模型，包括 `principal components analysis`、`exploratory factor analysis`、`canonical correlation`、`discriminant analysis`，甚至 `neural networks`，都可以被概念化为降秩多元模型的特例。更重要的是，书中前面讨论的回归 Gauss-Markov 定理推广到了多元降秩的对应形式。轮廓分析和时间序列也可以在降秩多元模型中进行概念化。

## 5.15 典型相关

典型相关是变量集合之间的双变量相关。它像 Pearson `r` 一样，是线性相关。它是线性组合之间的线性相关。也就是说，对于线性组合 `l`[1] 和 `l`[2]，它们之间的相关性由下式给出：

$$r\_{l\_{1},l\_{2}} = \\frac{{cov}\_{l\_{1},l\_{2}}}{\\sqrt{s\_{l\_{1}}^{2}s\_{l2}^{2}}}$$

(5.34)

其中 `s`[`l`[1]]² 和 `s`[`l`2]² 是各自线性组合的方差（[Denis, 2021a](#ref.xhtml#re_CIT000087)），而 `cov`[`l`[1], `l`[2]] 是线性组合 `l`[1] 和 `l`[2] 之间的协方差。非零的总体典型相关平方是以下式子的非零特征值 `λ`[`i`]（[Bilodeau and Brenner, 1999](#ref.xhtml#re_CIT000030), p. 177; [Rencher and Christensen, 2012](#ref.xhtml#re_CIT000295), p. 387）：

`Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() 

由于特征值提供了平方典型相关，因此未平方的典型相关等于特征值的平方根，即 $\\sqrt{\\lambda\_{i}}$。

平方典型相关是如何求得的？有几种方法可以获得它们，但也许最简单的方法是通过对 `Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() 进行特征值分析，其中该矩阵在特征值等式的经典形式中被分析为 `A`：

`A` `x` = `λ` `x`

回想一下，要找到 `λ`，我们令 |`A`−`λ` `I`| = 0，其中现在 `A` 不再仅仅是一个矩阵 `A`，

`A` = `Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() 

因此我们有

|`A`−`λ` `I`| = 0 → |`Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() − `λ` `I`| = 0

(5.35)

因此由于 |`A`−`λ` `I`|`x` = 0，其中 `x` 是与 `λ` 相关联的特征向量，`Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() 的相应特征向量 `a` 和 `b` 由261

(`Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() − `λ` `I`) `a` = 0

(5.36)

和

(`Σ`[`y` `y`]`^(−1)` `Σ`[`y` `x`]() `Σ`[`x` `x`]`^(−1)` `Σ`[`x` `y`]() − `λ` `I`) `b` = 0

(5.37)

求得。也就是说，第一线性组合现在为 `l`[1] = `a`′ `x`，第二为 `l`[2] = `b`′ `y`。每个维度的相应典型变量是不相关的，并且提取的每个后续典型维度与之前的维度不相关。Izenman（[2008](#ref.xhtml#re_CIT000167), p. 216）总结了典型相关：

> CVA 技术确保从原始 X 和 Y 变量中榨取每一分相关性，并以有序的方式将其沉积到成对的新变量中……它们具有特殊的相关结构。如果将相关性视为变量系统中的信息的主要决定因素，那么 CVA 就是减少原始两个变量集维度的一个主要工具。

不出所料，典型相关可以被解释为上述降秩回归的一个特例（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。典型相关的变体包括 `deep variational canonical correlation`（Wang et al., [2017](#ref.xhtml#re_CIT000380)），它将线性典型相关扩展并推广到深度神经网络参数化中的非线性模型。`Probabilistic canonical correlation` 由 [Bach and Jordan (2006)](#ref.xhtml#re_CIT000017) 讨论。`Tensor canonical correlation` 也已被提出，其中数据中的每个观测值由多维数组（张量）组成（Min et al., [2020](#ref.xhtml#re_CIT000252)）。多元降秩、PCA 和 CVA 之间的关系可以在 [Izenman (1975)](#ref.xhtml#re_CIT000166) 中找到。

### 5.15.1 R 中的典型相关

R 中的包 `CCA`（[González & Déjean, 2023](#ref.xhtml#re_CIT000130)）可用于典型相关以及正则化典型相关的一个版本。该包还允许对典型相关进行大量图形可视化。下面是一个改编自该包文档中关于 `nutrimouse` 数据的示例，其中基因数据与一组小鼠的脂质相关：

```
> library(CCA)
> data(nutrimouse)
> X = as.matrix(nutrimouse$gene[,1:3])
> Y = as.matrix(nutrimouse$lipid[, 1:3])
```
