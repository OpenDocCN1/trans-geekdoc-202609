
As the noise level increases, the performance of `ICA` algorithms deteriorates and the separation quality decreases, as manifested by cross-talk and noisy outputs. More importantly, many situations have a relatively small number of sensors but many sources, and one would like to lump the low-intensity sources together and regard them as effective noise, while the separation sources focuses on the high-intensity ones. There is no way to accomplish this using `ICA` methods … Our `IFA` [independent factor analysis] algorithm reduces to ordinary `FA` when the model sources become Gaussian, and performs principal component analysis (`PCA`) when used in the zero-noise limit … `IFA` therefore generalizes and unifies ordinary `FA`, `PCA` and `ICA` and provides a new method for modeling multi-variable data in terms of a small set of independent hidden variables … `IFA` amounts to fitting those data to a mixture model of co-adaptive Gaussians.

Hence, the classic factor analysis model, principal components, and independent principal components can all be conceived in a sense as special cases of the wider independent factor analysis model. The `IFA` model will look as it did in the classic version of the `EFA` model,

`x = μ + Λ f + ε`

(12.14)

but with the important caveat that factors will now be constrained to be *independent*, not only *uncorrelated* as in the common factor analysis model. The independent latent variables have flexible distributions modeled by mixtures of Gaussians ([Bishop, 2006](#ref.xhtml#re_CIT000032)) and hence while common exploratory factor analysis can be thought of as a low-rank version assuming a Gaussian distribution, independent factor analysis distinguishes itself from this as it features non-Gaussian distributions with Gaussian densities as essentially a “special case” ([Izenman, 2008](#ref.xhtml#re_CIT000167)).

The loading matrix `Λ` in `IFA` is regarded as the *mixing* matrix and as was true of `ICA`, is responsible for blending in of the various sources. The `EM` algorithm is typically used to maximize the log-likelihood of the observed data with respect to the parameters of the generative model that account for the data ([Attias, 1999](#ref.xhtml#re_CIT000015)). As is the case with common factor analysis, in independent factor analysis the number of latent variables and observed variables can differ ([Bishop, 2006](#ref.xhtml#re_CIT000032)).474

The independent factor analysis model has not seen much development as a unique method since its inception nor does it appear extensively in the literature. This may be due to the `ICA` model dominating applications ([Izenman, 2008](#ref.xhtml#re_CIT000167)).

## 12.8 Nonlinear Factor Analysis and Autoencoders

We have emphasized that the classic factor analysis model is linear in the parameters. One way to relax this assumption is to allow the mapping of variables to unobserved variables to be a *nonlinear model*. We remind ourselves at this point that classic `PCA` can be conceptualized as an *autoencoder*, where recall an autoencoder is a kind of *transformer* that encodes input into output but does not necessarily reduce the dimensionality of the input. Factor analysis can also be conceived as such, and hence conceptualizing nonlinear factor analysis is best done via an autoencoder, more specifically what is called a *variational encoder*, which is best thought of as a probabilistic version of a deterministic autoencoder ([Murphy, 2022](#ref.xhtml#re_CIT000259)). Factor analysis is a variational encoder due to its inclusion of an error term, `ε`. It is also a *generative model*, which implies that we can create new data (e.g., factor scores) from it, whereas the traditional classic autoencoder is deterministic ([Murphy, 2022](#ref.xhtml#re_CIT000259)).

### 12.8.1 Unpacking the Autoencoder

Recall that an autoencoder features two components, the *encoder* is `x`→`z` while the *decoder* is `z`→`x`. In the current context, observed variables `x` are encoded into one or more latent variables, while latent variables can be decoded back into observed variables. Unpacked, encoding `x` into `z` with a weighting matrix `W` corresponds to `z = W[1]^T x`, while decoding `z` corresponds to `x̂ = W[2]^T z`, where the distance `x − x̂` is minimized ([Murphy, 2022](#ref.xhtml#re_CIT000259)). In a classical `PCA`, the encoding and decoding stages will be linear maps and `W` will be constrained to be orthogonal. In a nonlinear factor analysis or a (nonlinear) neural network, the encoding and decoding will be nonlinear and depending on whether we wish factors to be uncorrelated or not we will place constraints on `W`. Eigenvectors of the covariance matrix in `W` are chosen such that the above reconstruction error is minimized.

### 12.8.2 Factor Analysis as a Neural Network

Because an autoencoder can be conceived as a special type of neural network, the nonlinear maps from `x`→`z` and `z`→`x` applied to factor analysis can also be thought of as a *neural network* in which the mapping is some nonlinear *activation function*. Hence, we see once more the generality of specific approaches such as factor analysis as special cases of a wider neural network framework. Not surprisingly, as is the case with other nonlinear methods surveyed in this book, imposing a nonlinear encoder can detect patterns and shapes in data that a classic linear factor analytic model or principal components cannot ([Japkowicz & Gluck, 2000](#ref.xhtml#re_CIT000170)). According to Japkowicz et al. ([2000](#ref.xhtml#re_CIT000170), p. 1):

While linear autoassociators emulate `PCA` and thus exhibit a flat or unimodal reconstruction error surface, autoassociators with nonlinearities in their hidden layer learn domains 475by building error reconstruction surfaces that, depending on the task, contain multiple local valleys.

Nonlinear factor analysis can also be conceived as a *deep latent Gaussian model* (Rezende et al., [2014](#ref.xhtml#re_CIT000297)). The origins of nonlinear factor analysis go back to [Bartlett (1953)](#ref.xhtml#re_CIT000021), though at the time it could not be conceived as an autoencoder or neural network, since these conceptualizations are relatively recent. For a thorough review of nonlinear factor analysis, see [Amemiya and Yalcin (2001)](#ref.xhtml#re_CIT000010).
