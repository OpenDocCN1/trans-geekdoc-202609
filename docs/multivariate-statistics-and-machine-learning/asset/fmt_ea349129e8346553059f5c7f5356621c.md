
In this chapter, we survey the technique of *exploratory factor analysis* (EFA). Factor analysis is yet another dimension-reduction technique that we could have easily included as one of the several approaches surveyed in the former chapter. As we will see later, principal components analysis can actually be conceived mathematically as a special case of the wider factor analysis model. And though factor analysis is sometimes mistakenly conflated with PCA as being equivalent, it should be emphasized at the outset that *factor analysis is not the same as PCA*. First, factor analysis models *observed* variables as a function of *latent* variables, whereas PCA models components (loosely, “latent variables”) as a function of observed variables. Second, most versions of factor analysis hypothesize a *probabilistic model* that naturally includes an error or noise term, whereas classical PCA does not. In classical PCA, there is no “noise,” whereas in classical factor analysis, observed variables are modeled as a function of factors *plus* an error term. The advantage of factor analysis being probabilistic is, for one, that we can build more complex models such as *mixture* and *nonlinear factor analysis models* ([Murray, 2022](#ref.xhtml#re_CIT000259)). Some software programs such as SPSS 461routinely provide PCA results first before delivering on factor analysis findings and can lead some researchers to believe PCA results are *equivalent* to those of factor analysis, which, as we have noted, are not.

## 12.1 Why Treat Factor Analysis in Its Own Chapter?

Since we have said that factor analysis can be conceived as just another dimension-reduction technique, why devote a separate chapter to it instead of including it in the former chapter? There are a few reasons for treating factor analysis independently in a distinct chapter. These reasons include the fact that factor analysis has a long tradition in many social sciences (e.g., psychology) as a *centerpiece methodology*, and in many courses on multivariate analysis in the social sciences is given maximal attention as a methodology in its own right. Factor analysis grew out of a research context that initiated a tremendous amount of growth and innovation in what are generally referred to as *latent variable models*. Originally founded by Charles [Spearman (1904)](#ref.xhtml#re_CIT000344) in psychometrics, the concept of a *latent variable* formed the very bedrock of many techniques that grew out of factor analysis, such as *structural equation modeling*, which we survey in the following chapter.

Hence, factor analysis has its own unique historical lineage and germination and arose to address very specific substantive research problems where defining and tapping into constructs proved quite challenging, difficult, and, at many times, contentious. For reasons such as these, to treat it only on a technical level as an alternative to PCA or yet as just another approach to dimension reduction, we believe, would be a mistake. Despite its controversy historically, it is well-deserving of its own chapter for its devoted emphasis on the *measurement problem* which has dominated the social sciences in which it first arose and is responsible for giving birth to numerous other latent variable modeling techniques.

Toward the end of the chapter we will draw links between it and other techniques to show how factor analysis relates to these other dimension reduction and manifold learning methods, especially as contextualized in modern machine learning. As we will see, in a machine learning context, factor analysis can be best conceived as yet another *autoencoder*, more specifically a *variational autoencoder* due to its inclusion of an error or “noise” variable. Before we generalize to such lengths, however, we begin with the model from the bottom up by noting conceptual parallels it has, not with principal components, but instead with the classic *regression model*.

## 12.2 Common Orthogonal Factor Model

The common orthogonal factor model is given by

`x = μ + Λf + ε`

(12.1)

where `x` is a vector of observed, or “manifest” variables that we seek to “explain” by the factor model, `μ` is an overall mean of the observed variables, `Λ` are weights or “loadings” in `Λ` applied to a vector of factors in `f` and `ε` is a vector of errors, that is, variation unexplained by the factor model. Of special note here is `f`, a vector of *unobserved* variables, not *observed* variables as in `x`. This is what is so special about the factor model, such that it attempts to account for observed variables by hypothesizing unobserved underlying variables. Note that this is not what occurs in PCA. Principal components analysis simply undergoes a rotation of axes resulting from an eigen decomposition; there is no *model equation* per se as in factor analysis. Note as well that `ε` is a vector of unobserved variables just as it was in the classic linear model. The vector `ε` is usually 462hypothesized to contain “specific” or “unique” variances, that is, variation that is unaccounted for by the latent variables in the factor model.

### 12.2.1 Factor Analysis Is a Regression Model

One of the first things to note about the factor analysis model is that it is, in actuality, a *regression model*, but not the classic regression of previous chapters. Defining it as a regression model simply means we are modeling an observed response by weighted predictors, that is, *regressing the observed responses on the weighted set of predictors*, but this is a very general idea; what is specifically being regressed on what will determine the exact *type* of regression model. Hence, concluding that factor analysis is a regression model only implies that it has a regression *characteristic* to it, no more. To appreciate the differences between the factor analysis model and that of classical least-squares regression, it behooves us to compare them side-by-side:

`x = μ + Λf + ε`   `y = xβ + ε`

We note similarities and differences between the models; both models have an observed vector as output of the function; in the factor analysis model, that vector is `x` while in the regression model that vector is `y`. Both models contain an *error* or *noise* term, `ε`. Where the models differ is in the middle terms of each equation. In regression, note that we are weighting an observed vector `x` by `β` whereas in the factor analysis model, we are weighting *unobserved* factors `f` by `Λ`. Both models are regression models, but *the factor analytic model contains unobserved factors as an explanatory variable*, whereas the regression model contains observed variables as explanatory variables. This is the key difference between the models.

> *The factor analysis model is a regression model, however unlike the classic regression model in which observed variables are regressed onto other observed variables, the factor analysis model features observed variables regressed onto unobserved factors or so-called latent variables.*

### 12.2.2 Assumptions Underlying the Factor Analysis Model

As in virtually all statistical modeling, models come with them a set of assumptions, assumptions that if not satisfied, can drastically weaken the application of the model and the conclusions that can be drawn when applying it to data. For the common factor analytic model, the assumptions are generally that `E(f) = 0`, that is, the mean of factors is equal to 0, and `E(f f') = I`, the covariance of factors is an identity matrix. Note that this is only an assumption of the *orthogonal factor model*. When we relax this assumption and allow factors to covary, such gives rise to the *oblique factor model*.
