
## 8.2 线性模型

请注意，上面的模型是*参数线性*的，这意味着 `β[0]`、`β[1]`、… `β[p]` 都被提升到指数“1”。即使例如 `x[1]` 被提升到二次方，`x[1]²`，只要 `β[0]`、`β[1]`、… `β[p]` 仍被提升到系数为一，模型仍会被视为线性模型；然而，可以说它不再在变量上是线性的。*线性模型只要求系数被提升到不大于一的项*。我们对实际变量执行的基变换在统计术语中与实际模型的线性或非线性无关 ([Bishop, 2006](#ref.xhtml#re_CIT000032))。例如，下面的模型会被正确地视为*非线性*，因为它在系数上是非线性的，尤其是 `β[2]²` 项：

`y[i] = β[0] + β[1]x[1] + β[2]²x[2] + ε[i]`

(8.2)

请注意，下面的模型也因为 `β[2]²` 而是非线性的，而不是因为 `x[2]²`；它被认为在*参数*和*变量*上都是非线性的：310

`y[i] = β[0] + β[1]x[1] + β[2]²x[2]² + ε[i]`

(8.3)

### 8.2.1 本质线性模型

在线性与非线性模型方面，一个有用的区分是在 *内在线性* 与 *非内在线性* 之间 (Neter et al., [1996](#ref.xhtml#re_CIT000266))。一个是非线性的，但可以通过变换线性化的模型通常被称为 *本质线性模型*。这方面的最经典例子就是 *指数响应*，如果我们对这种模型中的指数取 `log`，我们就会得到一个线性模型。也就是说，我们可以将响应变换为线性。它的本质是线性的，因为其非线性只是变换的产物。另一方面，*非本质线性模型* 是无法通过变换线性化的模型。

### 8.2.2 一般线性模型 vs. 广义线性模型

本书迄今为止介绍的许多模型都可以被视为更广泛的 *一般线性模型* 的特例。回归和分析 of 方差模型确实是这一更广泛框架的特例。但一般线性模型到底由什么定义呢？当我们提到源自这一“一般”框架的特定模型时，我们通常意味着误差项 `ε[i]` 的分布具有期望的 *正态分布*。经典的线性回归模型 `y[i] = β[0] + β[1]x[1] + ε[i]` 就是这样一个例子，其中 `ε[i] ∼ N(0,σ[ε]²)`，意味着模型中的误差预计为正态，具有均值为 0 和有限且可测量的方差 `σ[ε]²`。然而，在许多情况下，我们不会自然地期望误差项以这种方式表现。一个经典且流行的例子是当响应变量不是连续的而是 *二元* 时。当响应变量为二元时，误差项的期望不出所料地不是正态的。我们也不能合理地期望误差具有恒定方差 ([Fox, 2016](#ref.xhtml#re_CIT000106))。

因此在理论层面上，困难在于如何处理具有非正态期望的误差分布。它们似乎是完全不同的模型类别。然而，大多得益于（但不完全是）[Nelder and Wedderburn (1972)](#ref.xhtml#re_CIT000265) 的工作，提出了一个更广泛的统计模型框架，可以涵盖甚至这些具有非正态误差分布的模型。回想一下，理解统计学的全部在于寻找 *层次，of* 在更高形式和一般性的背景下对模型“特例”进行分类。这正是这些作者在提出建模框架时所取得的成就，该框架不仅涵盖了具有正态分布误差项的经典线性模型（回归、ANOVA），还涵盖了包含非正态误差项的模型。他们称这一新的模型类别为 *广义线性模型*，因此大量模型可以置于这一一般框架中。也就是说，*广义线性模型涵盖了包含正态和非正态分布误差项的模型*。

本质上，广义线性模型的逻辑是取一个原本非线性的模型，并通过称为 *链接函数* 的方法使其模仿线性。通过链接函数，模型变得近似线性，我们就可以像处理经典线性模型一样处理该模型。这就是广义线性模型的基本逻辑。这里需要做一个重要的区分，即被线性化的是 *决策面*，而不是真正整个模型或必然如此 ([Bishop, 2006](#ref.xhtml#re_CIT000032))。广义线性模型如逻辑回归采用使它们“线性似”的变换 ([Fox, 2016](#ref.xhtml#re_CIT000106))，使得原本非线性的模型可以通过变换“线性化”（例如，在逻辑回归的情况下取链接函数如赔率的 `log`）。311

一个在历史上非常流行于几乎所有科学领域，尤其是在医学领域的广义线性模型的非常特殊案例是上述的 *逻辑回归模型*，我们接下来对其进行概述。

## 8.3 逻辑回归模型

在机器学习圈子里，逻辑回归模型被称为 *条件 Maxent 模型* ([Mohri et al., 2018](#ref.xhtml#re_CIT000253))，它只是多项式回归模型，而二元回归是其特例。逻辑函数由以下给出，

$$p\\left( x \\right) = \\frac{e^{\\beta\_{0} + \\beta\_{1}x}}{1 + e^{\\beta\_{0} + \\beta\_{1}x}}$$

(8.4)

其中我们可以利用 (8.4) 中的公式并得到

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} = e^{\\beta\_{0} + \\beta\_{1}x}$$

(8.5)

(8.5) 的左边，`p(x)/[1−p(x)]` 被称为 *赔率*。用文字来说，赔率是事件发生的概率 `p(x)` 相对于事件不发生的概率 `1−p(x)` 的比率。如果事件发生的概率与不发生的概率相同，则赔率为 1.0。例如，假设 `p(x)=0.5`，则成立，

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)}\\frac{0.5}{1 - 0.5} = \\frac{0.5}{0.5} = 1.0$$

假设我们对

$$\\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} = e^{\\beta\_{0} + \\beta\_{1}x}$$

的两边取 `logarithm`，

$$\\log\\left\\lbrack \\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} \\right\\rbrack = \\log\\left\\lbrack e^{\\beta\_{0} + \\beta\_{1}x} \\right\\rbrack$$

(8.6)

回想一下，对指数函数 `e` 取 `log` 的效果是将指数降下来，因此从上面我们得到

$$\\begin{array}{l} {\\log\\left\\lbrack \\frac{p\\left( x \\right)}{1 - p\\left( x \\right)} \\right\\rbrack = \\log\\left\\lbrack e^{\\beta\_{0} + \\beta\_{1}x} \\right\\rbrack} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = \\beta\_{0} + \\beta\_{1}x} \\\\ \\end{array}$$

(8.7)

也就是说，*赔率的对数被假定为线性函数*。赔率的对数被称为 *logit*，因此一旦我们产生 logit，我们实际上现在就在处理一个近似线性模型，在许多方面类似于经典的回归线性模型。当然，它并不 *完全* 相同，因为我们工作的单位不再是原始变量的自然单位，而是 *对数赔率* 或 *logit* 的单位，因此参数估计的解释将以 logit 的单位进行。312
