
历史上，因子分析在数学界获得认可的速度很慢。一些数学统计学家对该方法嗤之以鼻，部分原因是其被认为存在一些技术缺陷（如载荷不唯一），但很可能也是由于它可能引发的与心理学之间的学术地盘之争，而该方法最初正是在心理学中构想的（[Chatfield 与 Collins, 1980](#ref.xhtml#re_CIT000057)）。有些多元分析书籍甚至完全拒绝介绍该技术，假装它不存在！

然而，随着机器学习的到来和迅猛崛起，以及数据科学的“革命”，因子分析在几乎 `all` 领域都重新兴起，而不仅仅是在社会科学领域——它在那里一直相当流行。今天，因子分析及其众多衍生 465and extensions 只是统计学家或计算机科学家工具箱中的又一种方法。例如，`generative topographic mapping`（Bishop 等，[1998](#ref.xhtml#re_CIT000031)），一种非线性因子分析形式，也是自组织映射的替代方案（[Kohonen, 1982](#ref.xhtml#re_CIT000196)），在机器学习中有所体现，并建立在潜变量模型的基础之上，而这一思想最初是由因子分析普及的。确实，潜变量的概念是一个强大的概念，尽管潜变量的 `idea` 并非严格归因于因子分析（[Mulaik, 1987](#ref.xhtml#re_CIT000257)），但因子分析负责将该构念操作化并为其奠定技术基础。因子分析也有助于催生心理测量学领域。例如，`item response theory`，也称为 `latent distribution theory`、`item characteristic curve`（ICC）和 `item characteristic function`（ICF），或 `latent trait analysis`（[Mair, 2018](#ref.xhtml#re_CIT000237)）都建立在基本因子模型之上。[Mahmud (2017)](#ref.xhtml#re_CIT000236) 对这些模型提供了良好的概述和总结。

因此，我们认为简单地得出因子分析存在问题且应避免的结论是一个早已过时的观点，尤其是在计算机科学和机器学习兴起的背景下，因子分析在其中找到了巨大的应用。不过时的是，除非愿意研究、理解并欣赏该方法的一些更显著的理论基础和注意事项，否则人们更容易误解和误用因子分析，并从该方法中得出远超出认识论合理范围的结论。

## 12.4 因子估计

与几乎所有统计方法一样，我们需要一种估计模型参数的方法。尽管 EFA 中存在众多估计方法，但经典估计方法包括 `principal factor`（或 `principal axis factoring`）以及 `maximum likelihood`，我们现在将对其进行（非常）简要的概述。

### 12.4.1 主因子（主轴因子分析）

为了理解主因子估计方法，首先有必要重新审视 PCA 并定义 `communality` 的含义。鉴于我们使用的是相关矩阵，在 PCA 中主对角线将包含 `unit variances`，这是因为每个变量最初都为 PCA 贡献一个“单位”方差。在 `principal factor` 方法中，也称为 `principal axis factoring`，残差矩阵被最小化，并用权重替换相关矩阵主对角线上的初始共同度，这些权重源自将给定变量对受因子分析影响的其余变量进行回归。也就是说，每个共同度权重由下式给出

$${\\hat{h}}\_{i}^{2} = R\_{i}^{2} = 1 - \\frac{1}{r^{ii}}$$

(12.4)

其中 `ĥ`[`i`]² 是变量 `i` 的估计共同度，`R`[`i`]² 是将变量 `i` 对受给定因子分析影响的所有其他变量进行回归的决定系数，而 `r`^(`i``i`) 是相关矩阵 `R` 逆矩阵的第 `i` 个对角元素（[Rencher 与 Christensen, 2012](#ref.xhtml#re_CIT000295)）。如果分析的是协方差矩阵而不是相关矩阵，则 (12.4) 变为

`ĥ`[`i`]² = `s``s`[`i``i`] `R`[`i`]²

(12.5)

其中 `s``s`[`i``i`] 是协方差矩阵 `S` 的第 `i` 个对角元素。466

### 12.4.2 最大似然

估计因子最常见的方法，或许毫不奇怪，就是最大似然法。最容易通过 `Expectation-Maximization` 算法（Choi 等，[2010](#ref.xhtml#re_CIT000062)；[Rubin 与 Thayer, 1982](#ref.xhtml#re_CIT000316)）进行 `maximum likelihood`（ML）估计。正如正交因子模型的情况一样，ML 估计量在旋转下也是不变的，因此任何旋转都会产生相同的 ML 估计值（Choi 等，[2010](#ref.xhtml#re_CIT000062)）。正如我们稍后会看到的，这对于所有因子分析模型来说并不是无条件成立的。例如，对因子模型施加 `l`[1] 罚则，从而产生稀疏的“lasso”因子分析，就不是旋转不变的（Choi 等，[2010](#ref.xhtml#re_CIT000062)）。
