
The variances of each variable are the following:

```
> var(x)
[1] 0.6165556
> var(y)
[1] 0.7165556
```

The sum of these variances is

```
> sum(var(x), var(y))
[1] 1.333111
```

When we compute the components analysis on the covariance matrix from this data, we obtain via eigen analysis eigenvalues of 1.284 and 0.0491, which when summed total 1.3331, which we note is the same total as that generated by summing the original variances of the variables. Hence, we have demonstrated through empirical data that PCA has not *changed* the variance in the variables, it has merely *reconstructed* the variance onto new dimensions instead of on the original variables. *The variance accounted for by the new components is the same variance in the original variables*. This is why again we dislike the idea of PCA “discovering” dimensions. We prefer say that PCA is simply *reorganizing* the variables onto dimensions that are mathematically assured by the decomposition. For the majority of data sets and well-behaved matrices, PCA *will* generate components. It is whether such components can be *interpreted* and whether they are meaningful that is the *real* question of interest.

### 11.2.9 Principal Components as a Rotation of Axes

We have seen that principal components analysis can be explained by eigen analysis or by reference to a least-squares argument in which squared perpendiculars are minimized instead of vertical distances. The real “mystery” of principal components analysis lies in eigen analysis. Once we accept that eigen analysis can be performed, it is a relatively simple matter to accept that we can generate components. It is the substantive understanding of these components that then matters. 404What we mean by this is that if one truly wants to understand PCA, one needs to truly understand eigen analysis.

Our understanding of PCA can also benefit from understanding some of its geometry. Geometrically, PCA is nothing more than a rotation of the original Cartesian axes. To demonstrate such a rotation, consider once more our data on PCA ([Smith, 2002](#ref.xhtml#re_CIT000340)):

We can consider them to be *factors of rotation* of the original axes ([Young, 2023](#ref.xhtml#re_CIT000401)). The eigenvectors are first and foremost *vectors*, and as such, can be easily plotted in space (Figure 11.2).

Note carefully that each eigenvector appears to account for the scatter of points. The first eigenvector, from bottom left to upper right, seems to account for *most* of the variance in the data. This is not a surprise, since the first eigenvalue is equal to 1.284 and is much larger than the second of 0.0491. The proportion of variance accounted for by the first eigenvector is `1.284/(1.284 + 0.0491)` = 0.96, or 96%. Clearly, the first eigenvector (component) is accounting for the majority of the variance in the original variables.

We can also see that the angle between the eigenvectors is one of 90 degrees. That is, the rotation of the original axes did not change the angle between them but instead kept it as orthogonal as were the original basis Cartesian axes. In linear algebra, this type of transformation is regarded as a *rigid rotation* of the axes and we have simply found an optimal new *basis* from which to project the data. Mathematically, this is all that PCA accomplishes.

### 11.2.10 Principal Components, Discriminant Functions, Canonical Variates: Linking Foundations

As mentioned at the outset of this book, if there is a common theme running throughout most of it, one of many, it is that of *dimension reduction*. Even the analysis of variance, long before we knew it in undergraduate statistics, on a deeper theoretical level could be said to be generating new dimensions on which data can be projected. It may thus appear to the reader at some point that many of the methodologies surveyed in this book and beyond are performing a similar task. Indeed, dimension reduction is common to most in one way or another, though there are of course important differences regarding how various methods go about such a task.

Recall that we had said earlier in the book that discriminant functions were underlying dimensions such that they maximized separation between groups. Successive dimensions were 406uncorrelated to one another. Both discriminant analysis and principal components analysis execute a “flavor” of dimension reduction, but they go about it in different ways. For one, in PCA, dimensions are obtained that maximize *variance*, not maximize *separation between groups*. Second, while discriminant functions are uncorrelated to one another, they are typically not orthogonal, while principal components are uncorrelated *and* orthogonal. Components have the stronger property of orthogonality ([Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)). This is also true of canonical variates in canonical correlation; *they are uncorrelated but not orthogonal*. As mentioned earlier, components can be made independent (or nearly so), but that requires independent components analysis and not classical PCA. PCA only ensures that components are uncorrelated, which is a weaker property than statistical independence ([Jolliffe, 2002](#ref.xhtml#re_CIT000174), p. 396).
