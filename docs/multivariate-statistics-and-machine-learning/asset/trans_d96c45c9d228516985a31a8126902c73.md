# 11 主成分分析、盲源分离与流形学习

DOI: [10.4324/9781003376941-14](https://doi.org/10.4324/9781003376941-14)

在本章中，我们概述了 `principal components analysis` 方法，简称“PCA”，以及其他相关技术。正如我们将看到的，主成分分析可以被解释为更一般方法的特例，这些方法通常归于 `blind source separation` 和 `manifold learning` 之名。事实上，PCA 可以被视为流形学习的特例，其中在 PCA 的情况下流形是 `linear`。更一般的流形可以呈现非线性形状，而最常见的是“流形学习”这一短语指的是 `nonlinear dimensionality reduction`。几乎所有降维技术都可以粗略地分为 `linear` 与 `nonlinear`。

PCA 的动机是取一组观测变量并生成这些变量的线性组合。从实质上讲，主成分分析经常被宣传为能够“发现”数据的潜在维度。然而，正如本章将要学习的那样，“发现”一词可能具有误导性和问题性。PCA 所能保证的，确定无疑的是，推导出使原始变量中方差最大化的变量线性组合。那些组合在任何实质意义上是否是有意义的，并不是 PCA 可以回答的问题，只能由用户参照科学理论和应用领域来回答。更重要的是，最大化观测变量中的方差可能不会产生在任何方面都 `interesting` 的维度。这是一个重要观点，因为还有许多其他竞争技术声称能够发现数据中更有趣的模式，并且它们有自己的标准，而不仅仅是最大化方差。简而言之，`maximizing variance in components does not necessarily imply those components will be of value or interesting in themselves`。从实质观点来看，它们可能在当前理论或应用下完全毫无意义。事实上，从科学观点来看，任何降维或流形学习技术的结果都应谨慎解读，因为完全有可能给定的算法“导致”有趣的几何模式或趋势，而最终这些模式或趋势并未得到数据的支持（Meila & Zhang, [2023](#ref.xhtml#re_CIT000247)）。

主成分只是寻求降低数据维度的众多技术之一。也就是说，PCA 是 `a`（即仅 `one`）种降维技术；它不等同于降维。在最一般意义上，降维可以被说成是将高维上下文中的观测数据减少到低维上下文，但确保它仍然传达相似的信息（Nanga et al., [2021](#ref.xhtml#re_CIT000263)）。也就是说，一个好的降维技术应保留原始数据的基本属性。如果低维中包含的信息具有误导性或与高维的信息相矛盾，则降维可能导致错误的解释。因此，这就是理解所使用降维技术的性质的一个重要原因，因为一种技术得出的结论可能与另一种技术得出的结论不同。`Dimension reduction is as much a function of the method as it is of the data`。一个值得问的问题是，如果一种技术的可视化与另一种不同，那么哪一个最 `correct`？对这个问题的唯一回答是，没有一个是“正确”的；它们只是完成不同的事情。395

大多数降维技术本质上是非参数的（[Murray, 2022](#ref.xhtml#re_CIT000259)），这本质上意味着它们高度关注训练数据，通常不直接尝试推广到样本外数据。这些技术包括上述的 `PCA`，但也包括 `classical multidimensional scaling`、`kernel PCA`、`Isomap`、`Laplacian Eigenmaps`（[Belkin & Niyogi, 2003](#ref.xhtml#re_CIT000026)）以及 `t-distributed Stochastic Neighbor Embedding (t-SNE)`、`non-negative matrix factorization`（`NMF`）等。PCA 的替代名称包括 `Karhunen-Loeve transform`（[Karhunen, 1947](#ref.xhtml#re_CIT000181)）、`empirical orthogonal functions`、`common principal components analysis`（[Flury](#ref.xhtml#re_CIT000105)，1998）等。不同的名称很大程度上是由于相同的方法在各个学科中被开发，或作为经典 PCA 的特例或扩展。例如，Karhunen-Loeve 变换具有在对每个类别应用 PCA 之前使用数据上的类别信息，然后取类别 PCA 的平均值的选项（[Alpaydin, 2020](#ref.xhtml#re_CIT000009)）。这类似于 `common PCA`，其中假设相似的分量会在不同的数据集中出现。因此，并非所有名称都与经典 PCA `identical`，但其核心仍然是“PCA”。再次强调统计和机器学习中的术语，人们可以很好地了解某种方法，但在某个领域却无法“识别”它，因为它被命名为不同的名称！

许多降维技术是基于一个基本定理来论证的，即 `Johnson-Lindenstrauss lemma`。它指出，对于高维空间中的若干点，这些点可以映射到维度低得多的空间，并且成对距离可能被扭曲的程度有一个上限。也就是说，该引理本质上表明可以在仍保留数据基本属性的同时进行降维。有关该引理的更多细节，请参阅 Mohri et al.（[2018](#ref.xhtml#re_CIT000253)，第 354 页）。

## 11.1 降维与术语

正如我们提到的，使降维具有挑战性的原因之一是，许多相同的技术在不同的科学领域中以略有不同的名称和不同的目的演变。例如，在心理测量学中，人们可能希望产生正交线性组合来表示受访者的态度，而在信息论中图像等更物理的应用中，同一个想法转化为图像的 `compression`。同一种技术几乎可以具有无法识别且截然相反的应用。虽然这可以说适用于几乎任何技术，而不仅仅是降维技术，但术语在维度分析中尤其“丰富”。

然而，就像简单的算术运算如加法一样，在理解加法时，重要的是不是 `what` 被加，而是更重要的是理解加法 `does` 什么。该技术必须至少在某种程度上从排除了应用的抽象观点来研究。只有在这种意义上，人们才能理解该技术实际完成什么，而不会被“左右”我们希望它在这一或那数据集上完成什么以满足我们的 `Freudian id`。
