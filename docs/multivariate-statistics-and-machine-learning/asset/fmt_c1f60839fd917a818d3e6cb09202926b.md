### 2.31.3 Correlating Linear Combinations

Just as we can covary or correlate random variables, we can also covary or correlate *linear combinations of random variables*. For example, consider the following two linear combinations,

*z* = *a*′*x* = *a*[1]*x*[1] + *a*[2]*x*[2] +  ⋅  ⋅  ⋅  + *a*[*p*]*x*[*p*]

and

*w* = *b*′*y* = *b*[1]*y*[1] + *b*[2]*y*[2] +  ⋅  ⋅  ⋅  + *b*[*p*]*y*[*p*]

The covariance between these linear combinations is given by

$$s\_{zw} = \\frac{\\sum\\limits\_{i = 1}^{n}{\\left( z\_{i} - \\overline{z} \\right)\\left( w\_{i} - \\overline{w} \\right)}}{n - 1}$$

(2.72)

and likewise, the sample correlation between `z` and `w` is114

$$r\_{zw} = \\frac{s\_{zw}}{\\sqrt{s\_{z}^{2}s\_{w}^{2}}}$$

(2.73)

Why would we want to covary or correlate linear combinations? For the same reason why we would want to correlate any two random variables. A linear combination is just a *composite* of variables. What is a single variable? It is also a composite variable, *only a very simple composite made up of only itself*. To illustrate, consider once more the linear combination for `w`:

*w* = *b*′*y* = *b*[1]*y*[1] + *b*[2]*y*[2] +  ⋅  ⋅  ⋅  + *b*[*p*]*y*[*p*]

Now, simplify `w` so that it becomes only a function of `y[1]`, that is, `w` = *b*′*y* = *b*[1]*y*[1]. If `b[1]` = 1, then `b[1]`*y*[1] = *y*[1] and hence, `w` = *y*[1]. Thus, the linear combination is simply composed of `y[1]`. That is, the motivation for correlating linear combinations is the same as that for single variables, only that linear combinations are usually more complex than single variables; they are “made up” of more “stuff” (i.e., variables) than a single random variable. However, the concept is the same. Many multivariate methods, in one way or another, correlate linear combinations, though it may not appear this way on the surface. As an example, analysis of variance and discriminant analysis do so, which are all versions of an underlying multivariate correlational methodology called *canonical correlation*. We discuss canonical correlation more thoroughly later in the book.

### 2.31.4 Covariance and Correlation Matrices

Many statistical procedures, such as principal components analysis or factor analysis, do not operate on individual variables. Rather, they operate on *matrices* of variables. That is, the object of analysis is not a variable but instead a *matrix*. As an example, principal components analysis performs (linear) dimension reduction on the covariance matrix directly. The covariance matrix for the population is given by

$$\\Sigma = \\left( \\begin{array}{l} {\\sigma\_{11}\\,\\,\\,\\,\\,\\sigma\_{12}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\,\\sigma\_{1p}} \\\\ {\\sigma\_{21}\\,\\,\\,\\,\\,\\sigma\_{22}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\,\\sigma\_{2p}} \\\\ {\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot} \\\\ {\\sigma\_{p1}\\,\\,\\,\\,\\,\\sigma\_{p2}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\,\\sigma\_{pp}} \\\\ \\end{array} \\right)$$

(2.74)

where *σ*[12], for instance, is the covariance between variables 1 and 2, and *σ*[11] is the covariance of a variable with itself, which is the variance, since

$$\\left. s\_{xy} = \\frac{\\left. {\\sum\\limits\_{i = 1}^{n}\\left( x\_{i} - \\overline{x} \\right.} \\right)\\left( y\_{i} - \\overline{y} \\right)}{n - 1}\\rightarrow\\frac{\\left. {\\sum\\limits\_{i = 1}^{n}\\left( x\_{i} - \\overline{x} \\right.} \\right)\\left( x\_{i} - \\overline{x} \\right)}{n - 1}\\rightarrow\\frac{\\sum\\limits\_{i = 1}^{n}\\left( x\_{i} - \\overline{x} \\right)^{2}}{n - 1} = s\_{x}^{2} \\right.$$

Of course, as usual in statistics, we rarely if ever have access to the population covariance matrix, and hence instead of `Σ`, we usually only have `S`, the sample covariance matrix, which, when corrected by `n`/`(n-1)`, is an unbiased estimator of `Σ`. That is, $E\\left( {\\frac{n}{n - 1}S} \\right) = \\Sigma$.

The sample correlation matrix is the standardized covariance matrix, given by115

$$R = \\left( \\begin{array}{l} {1\\,\\,\\,\\,\\,\\,\\, r\_{12}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\, r\_{1p}} \\\\ {r\_{21}\\,\\,\\,\\,\\, 1\\,\\,\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\, r\_{2p}} \\\\ {\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\, \\cdot \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, \\cdot} \\\\ {r\_{p1}\\,\\,\\, r\_{p2}\\,\\,\\,\\,\\, \\cdot \\cdot \\cdot \\,\\,\\,\\, 1} \\\\ \\end{array} \\right)$$

(2.75)

Both the covariance and correlation matrices are *symmetric* matrices, which, as we will see in our review of linear algebra, implies that for an arbitrary matrix `A`,

`A` = `A`^(`T`)

That is, the original matrix is equal to that of its transpose, or, otherwise said, if we exchange rows for columns and columns for rows, we will obtain the same matrix. Why is this fact important? It is important because there are special properties associated with symmetric matrices, including the fact that *eigenvectors are guaranteed to be pairwise orthogonal only for symmetric matrices whose eigenvectors correspond to distinct eigenvalues*, which will have significant implications for methods such as principal components. Symmetric matrices are also necessarily square matrices (i.e., same number of rows as columns), which allows for eigen decomposition to be performed on such matrices, whereas for nonsquare and asymmetrical matrices the more general SVD (*singular value decomposition*) is typically preferred.

### 2.32 *Z*-Scores and *Z*-Tests

Recall the definition of a `z`-score, or *standardized* score,

$$z = \\frac{y\_{i} - \\mu}{\\sigma}$$

A `z-`score is actually a comparison of two deviations, one in the numerator, `y[i]` − `μ`, to one in the denominator, `σ`, the standard deviation. Thus, one can interpret the `z`-score as a comparison of how large the current raw score deviation is to what is “standard” in the given distribution we are working with. A `z`-score of 0 arises only if `y[i]` − `μ` = 0, which means the raw score does not deviate at all from the mean. Should the distribution have no dispersion, then `σ` will equal 0 and the `z-`score will be *undefined*. It is also worth noting that the numerator represents a *centering* of `y[i]`. That is, whenever we subtract the mean, we are centering the given observation. Hence, the `z`-score can also be defined as the standardized centered observation. Centering plays a significant role in statistical modeling and will be revisited when we survey regression analysis and other methods in the book. Many times, we wish to center predictors by subtracting the mean so that the predictor value at zero is more meaningful. Centering often makes the intercept of a model more interpretable.

We can easily demonstrate centering and computing `z`-scores in R. Consider the following distribution of raw scores:

```
> x <- c(0, 4, 8, 9, 10)
> mean(x)
[1] 6.2
```

We now center the distribution by subtracting the mean,

```
> x.center <- x – mean(x)
> x.center
[1] -6.2 -2.2 1.8 2.8 3.8
> mean(x.center)
[1] -1.775489e-16
```

116Note that the mean of the new centered distribution is equal to 0 (within rounding error). To produce `z`-scores, we can then divide by the standard deviation, while also confirming that the mean of the new `z`-scores is equal to 0 and the standard deviation is equal to 1:

```
> z = (x-mean(x))/sd(x)
> z
[1] -1.4949527 -0.5304671 0.4340185 0.6751400 0.9162614
> mean(z)
[1] -2.218278e-17
> sd(z)
[1] 1
```
