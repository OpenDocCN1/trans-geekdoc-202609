
At the first step it \[least-angle regression\] identifies the variable most correlated with the response. Rather than fit this variable completely, `LAR` (least-angle regression) moves the coefficient of this variable continuously toward its least-squares value (causing its correlation with the evolving residual to decrease in absolute value). As soon as another variable “catches up” in terms of correlation with the residual, the process is paused. The second variable then joins the active set, and their coefficients are moved together in a way that keeps their correlations tied and decreasing. This process is continued until all the variables are in the model, and ends at the full least-squares fit.

The algorithm begins with standardizing predictors to have a mean equal to 0 and variance equal to 1 (i.e., `z`-scores). At this initial step, the residual `r[i]` is computed having no predictors in the model, that is, $r\_{i} = y\_{i} - \\overline{y}$, with all coefficients in the regression set to 0. That is, `β[1]` = `β[2]`, ..., `β[p]` = 0. Next, the predictor having the largest correlation with this residual is entered into the model; however, *not all of it*. The predictor’s weight moves *toward* its least-squares coefficient until another predictor “catches up” and has as much correlation with the current residual as the first predictor. At this point, both `β[1]` and `β[2]` move in the direction of their *joint* least-squares coefficient until another predictor “catches up” to the current residual. The algorithm proceeds in this way until all predictors are entered and hence the least-squares solution is achieved for the model. In the case where the number of predictors is greater than sample size (more specifically, `N-1`), the algorithm will reach a zero residual condition after `N-1` steps ([Hastie et al., 2009](#ref.xhtml#re_CIT000145), p. 74).

Hence, least-angle regression builds up a regression model by piecewise linear “partial” steps, adding single elements at each step by correlating the new variable with the current residual. As another variable “catches up,” the algorithm moves in a direction *equiangular* (i.e., having the 285same angle) to predictors. For this reason, least-angle regression has been called the “democratic” version of stepwise ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)). Both the lasso and forward stagewise regression models can be computed through the `least-angle regression algorithm` ([Izenman, 2008](#ref.xhtml#re_CIT000167)). The key point to emphasize is that in least-angle regression, predictors essentially “catch up” to others in the selection process, then those variables move together. In Python, the `Lars` estimator can be used to fit a least-squares regression. The `LARS` lasso can also be used which implements the `LARS` estimator while driving some coefficients to 0, as is characteristic of the lasso.
