
We can more concisely state the above model more generally as a function `f(x)`,

$$f\\left( x \\right) = \\beta\_{0} + {\\sum\\limits\_{j = 1}^{p}{x\_{j}\\beta\_{j}}}$$  

(5.14)

where “`f(x)`” represents the function `f` given the input of `x`. The summation $\\sum\\limits\_{j = 1}^{p}{x\_{j}\\beta\_{j}}$ allows for as many predictors that we wish to include into the regression model.

As was true for the simple linear regression model, parameter values `β[0]`, `β[1]`, `β[2]`, ..., `β[p]` are not known and must be estimated from the sample data; hence the estimated multiple regression model is given by

`ŷ[i] = β̂[0] + β̂[1]x[1] + β̂[2]x[2] + ... + β̂[p]x[p]`  

(5.15)

Parameter values are chosen via ordinary least-squares, which is an optimization problem to minimize the sum of squared errors. The least-squares solution is the following, where `X` is a matrix of predictors and `y` a vector of responses:

`β̂ = (X^T X)^(-1) X^T y`  

(5.16)

Though the matrix representation for multiple regression looks more complex than for simple regression, it is not difficult to appreciate the solution. Recall that taking inverses is conceptually equivalent to division in ordinary scalar algebra, and hence if we were to `naïvely` though mathematically incorrectly rewrite (5.16) in the most “familiar” way, we could express it as

$$\\begin{array}{l} {\\hat{\\beta} = \\left( XTX \\right){- 1}X^{T}y} \\\\ {\\,\\,\\,\\,\\, = \\frac{X^{T}y}{\\left( X^{T}X \\right)}} \\\\ \\end{array}$$  

We now easily see that the numerator contains in a general way a product of `X` and `y` whereas the denominator contains only a product of `X`. Hence, in words, the solution for `β̂` is answering the question of the extent to which `X` and `y` “go together” relative to only `X`. If `X` and `y` are highly `linearly` related emphasis on `linear` here, then `X^T y` will be much larger than `X^T X` and hence the coefficient for `β̂` will be larger than not. On the opposite extreme, if `X` and `y` are not very much linearly related, then `X^T y < X^T X` and `X^T y` will be only a `fraction` of the total “cross-variation” present in `X^T X` in the hypothetical division of quantities. Note that this matrix representation then is nothing more than a generalization of the single variable case in which228

$$\\hat{\\beta} = \\frac{Cov\_{xy}}{S\_{x}^{2}}$$  

where in this simpler case `Cov_xy` is analogous, in concept at least, to `X^T y` and `S_x^2` to `X^T X`.

The term

`X† = (X^T X)^(-1) X^T`,  

(5.17)

that is, with `y` dropped, is the left `pseudo-inverse` of the nonsquare matrix `X` ([Murphy, 2022](#ref.xhtml#re_CIT000259), p. 367). Hence, in cases where the inverse does not exist, a pseudo-inverse may be an option. This is especially useful for nonsquare matrices since ordinary inverses exist only for square matrices. Pseudo-inverses are best computed using the singular value decomposition, or “`SVD`” ([Murphy, 2022](#ref.xhtml#re_CIT000259)).

### 5.2.1 Minimizing Squared vs. Absolute Deviations

Recall that instead of squared deviations from predicted values, one could also take least absolute deviations of the kind

`|y[i] - ŷ[i]|`  

(5.18)

But what is the relationship between minimizing `(y[i] - ŷ[i])^2` vs. minimizing `|y[i] - ŷ[i]|`? Minimizing `|y[i] - ŷ[i]|` instead of `(y[i] - ŷ[i])^2` places less emphasis on extreme scores. That is, when we square `y[i] - ŷ[i]`, differences are magnified due to the squaring. If we instead minimize `|y[i] - ŷ[i]|`, large deviations are not so emphasized.

Minimizing `|y[i] - ŷ[i]|` is featured in `least-absolute-value regression`, or “`LAV`” regression for short. Historically, however, `(y[i] - ŷ[i])^2` is usually first choice in a regression context as squares are usually more tractable mathematically than are absolute value deviations ([Fox, 2016](#ref.xhtml#re_CIT000106)).

### 5.2.2 Hypothesis-Testing in Multiple Regression

The null hypothesis under test in the multiple regression model is the following:

`H[0] : β[1] = β[2] = ... = β[p] = 0`  

(5.19)

against the statistical alternative hypothesis that at least one of the coefficients, `β[j]`, is not equal to 0. To evaluate, as we did in analysis of variance (ANOVA), we compute an `F-ratio`, but not identical to that in ANOVA,

$$F = \\frac{\\left( TSS - RSS \\right)/p}{RSS/\\left( n - p - 1 \\right)}$$  

(5.20)

which is evaluated on `p` and `n - p` degrees of freedom, where `p` is the number of predictors and `n` is the number of data points. `TSS` and `RSS` are the total and residual sums of squares, respectively. If the probability of `F` under the null hypothesis of `ρ² = 0` is small, we reject the null hypothesis of no effect and conclude `ρ² ≠ 0` in the population from which the data were drawn.229
