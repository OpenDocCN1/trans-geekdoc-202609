
As usual, we rarely if ever know the values for `μ[1]`, `μ[2]`, and `μ[3]`. Instead, we must estimate from them on data by computing corresponding sample means, ${\\overline{y}}\_{1},{\\overline{y}}\_{2},{\\overline{y}}\_{3}$:

$$\\begin{array}{l} {{\\hat{C}}\_{i} = c\_{1}{\\overline{y}}\_{1} + c\_{2}{\\overline{y}}\_{2} + c\_{3}{\\overline{y}}\_{3}} \\\\ {\\,\\,\\,\\,\\,\\,\\, = \\left( 2 \\right){\\overline{y}}\_{1} + \\left( - 1 \\right){\\overline{y}}\_{2} + \\left( - 1 \\right){\\overline{y}}\_{3}} \\\\ \\end{array}$$

which is now an `estimated linear contrast`, which can be stated more generally as

$$\\begin{array}{l} {{\\hat{C}}\_{i} = c\_{1}{\\overline{y}}\_{1} + c\_{2}{\\overline{y}}\_{2} + \\cdot \\cdot \\cdot + c\_{J}{\\overline{y}}\_{J}} \\\\ {\\,\\,\\,\\,\\,\\,\\, = {\\sum\\limits\_{j = 1}^{J}{c\_{j}{\\overline{y}}\_{j}}}} \\\\ \\end{array}$$

(4.8)

with the variance of the contrast equal to

$$\\sigma\_{{\\hat{C}}\_{i}}^{2} = MS\\, error{\\sum\\limits\_{j}\\frac{c\_{j}^{2}}{n\_{j}}}$$

(4.9)

and estimated standard error equal to the square root of the variance,193

$$\\sigma\_{{\\hat{C}}\_{i}} = \\sqrt{\\sigma\_{{}\_{{\\hat{C}}\_{i}}}^{2}}$$

(4.10)

With the estimated standard error in place, we can now evaluate a null hypothesis that `C[i]` = 0:

`H[0]` : `C[i]` = 0

(4.11)

against an alternative hypothesis that the true contrast value is unequal to 0:

`H[1]` : `C[i]` ≠ 0

(4.12)

The null for the contrast is typically evaluated as a `t` statistic on `N`−`J` degrees of freedom from the overall ANOVA,

$$t = \\frac{{\\hat{C}}\_{i} - C\_{i}}{\\sigma\_{{\\hat{C}}\_{i}}}$$

(4.13)

The extent to which the difference `Ĉ[i]` − `C[i]` is large relative to the estimated standard error, `σ[Ĉ[i]]` is the extent to which there is eventually grounds to reject the null and infer the statistical alternative. That is, we have evidence, at least for the given experiment, that the particular mean difference hypothesized by the researcher exists in the population from which the data were drawn.

`Post-hoc tests` attempt to control for the inflation of the type I error rate across comparisons or contrasts. For a review of `post-hoc` tests, see [Ott and Longnecker (2016)](#ref.xhtml#re_CIT000277). One popular test is the Tukey HSD (“Honestly Significant Difference”). We perform it following an ANOVA on some fictitious data:194

### 4.1.5 ANOVA in Python

Our demonstrations of ANOVA that follow are very simple and we proceed quite briskly, as we assume the reader already has some experience in fitting ANOVA models and evaluating assumptions. See [Denis (2021b)](#ref.xhtml#re_CIT000088) for more Python software examples.

There are numerous ways to conduct a simple one-way analysis of variance in Python. In the following, we use the `SciPy` library to evaluate the null hypothesis that mean temperature is the same across populations 1–4:

```
from scipy.stats import f_oneway
temperature1 = [89, 89, 88, 78, 79]
temperature2 = [93, 92, 94, 89, 88]
temperature3 = [89, 88, 89, 93, 90]
temperature4 = [81, 78, 81, 92, 82]
```

Notice there are four groups. The first group has data values 89, 89, 88, 78, and 79. The second group has data values 93, 92, 94, 89, 88, and so on for the other two groups. We conduct the ANOVA using `f_oneway()`:195

```
f_oneway(temperature1, temperature2, temperature3, temperature4)
Out[553]: F_onewayResult(statistic=4.625000000000002, pvalue=0.016336459839780215)
```

We see the reported `F`-stat is 4.625 with an associated `p`-value of 0.0163, which exceeds `p` < 0.05, and hence we would typically reject the null hypothesis of equal population means assuming assumptions are satisfied for the analysis. That is, somewhere among the means is at least one statistically significant mean difference.
