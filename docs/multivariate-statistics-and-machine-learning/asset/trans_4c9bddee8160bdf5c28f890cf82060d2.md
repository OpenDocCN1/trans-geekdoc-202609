
# 测试误差估计与交叉验证

`test error` 是使用统计学习方法预测新观测响应时产生的平均误差——即在训练该方法时未使用到的测量值。这一定义及其更广泛的概念在评估模型时至关重要。如前所述，`training error typically underestimates the test error rate`。然而，估计测试误差并没有看起来那么容易。理想情况下，我们会有专门的测试集观测值（比如原始数据集的20–30%），我们可以直接将统计模型应用于其上以观察其表现。然而，通常我们没有这样的数据集可供使用，因此开发了许多56techniques来帮助仅使用可用训练数据来估计测试误差（例如，赤池信息准则（AIC））。

目前假设我们有足够的数据，可以将其中的一部分留作经验交叉验证之用。已经开发出不同的交叉验证新样本的方法。`validation set approach` 指定一个子集或 `holdout` 观测值用于测试（例如，20–30%）。`Leave-one-out cross-validation` 采用类似的理念，但只留出一个观测值进行预测，因此可以被视为验证方法的特例，其中 `n` = 1。测试观测值是 (`x` [1], `y` [1])，并且未用于拟合，因此 (`y`[1]−`ŷ`[1])² 提供了测试误差的近似无偏估计。它是无偏的，但高度可变，因为它只是一个观测值。所谓“高度可变”意味着如果我们使用不同的观测值，可能会得到相当不同的结果。因此，我们对所有观测值重复此过程，从而留一交叉验证对测试均方误差（MSE）的估计是所有 `n` 个测试误差估计的平均值：

$$CV\_{(n)} = \\frac{1}{n}{\\sum\\limits\_{i = 1}^{n}{MSE\_{i}}}$$

(1.8)

其中 `MSE` `[i]` 用于定量响应（对于离散或分类响应，通常使用其他误差度量）。留一交叉验证的偏差小于验证集方法。也就是说，它不太可能像验证方法通常会的那样高估测试误差。此外，与验证方法不同，该方法中没有随机性。由于我们使用了全部 `n`，随机抽样或划分为任意验证集的想法不存在。另一种方法是 `k-fold cross-validation`，它是验证集方法和留一方法之间的一种折中。K 折交叉验证产生的“折”数量大于留一情况下的 `n` = 1。请记住，当我们检查真实数据时，我们不知道真正的测试 MSE，因此我们无法 `fully` 确定交叉验证估计的准确性。在进行交叉验证时，有时我们想知道最小值的确切值，而有时我们只想知道哪种方法给出最低的最小值。

我们在全书中应用其选择方法时将重新讨论交叉验证。然而，我们需要提出一个重要的警告：交叉验证模型的过程可能导致通过 `grid searches` 以及其他探索性可视化工具模拟各种参数的相对复杂的练习，以寻求并得出就最小化误差而言的“最佳”模型或调优参数，但这些工具也应结合你所在领域的事物性问题一起解释。这样，“微调”模型通常并不像遵循这样或那样的计算交叉验证“常规”那样简单明了，而应在更广泛的科学背景下考虑。

此外，通过网格搜索尝试调优参数的 `ranges` 并改变其他设置，通常被推荐，而不是过分依赖一两个参数。例如，在诸如 `ridge` 和 `lasso` 回归等方法中，良好的交叉验证通常涉及使用不同输入参数范围的网格搜索，以确定使误差最小化的最佳值，而不仅仅是“在训练数据上进行调优”的一个或两个值。我们在本书中对交叉验证的选择性“snipet”讨论通常为了保持处理简洁和空间可管理而大大简化了这一过程。然而，这绝不意味着交叉验证的过程和得出最终模型因此就已完成。在实际数据分析中，`it may be just the beginning`。读者假设因为我们对交叉验证的讨论简短或经常省略，所以它对57given方法因此不必要或不重要，这将是一个错误。它最常见且肯定 `is`；然而，通过计算演示进行广泛的交叉验证会让我们远远超出我们在入门教材中想要达到的范围，该教材寻求在 `theory`、`method` 和 `practice` 之间取得理想平衡。在许多情况下，我们提供了必要的软件包参考，可以在其中寻求广泛的交叉验证指导。如本书前面所述，本书中的大多数软件示例仅旨在作为对计算方面的“入门”一瞥，在大多数情况下仅旨在选择性地 `demonstrate` 该技术；这些简单的演示并非旨在详尽无遗或以任何方式构成完整的“菜谱”或进行任何分析的必要彻底或详尽的步骤。

## 1.24 蒙特卡洛方法

蒙特卡洛方法以计算机辅助的重复迭代抽样为特征。请注意，我们不需要 `need` 计算机来进行此类抽样，但可以说，如果没有计算机的便利，几乎不可能进行广泛的抽样，因为计算机可以轻松、非常快速地自动化这一过程。只要一种方法以计算机进行某种重复抽样，则根据定义，它就是一种 `Monte Carlo method`。当然，计算机的演进和先进的计算速度使得重抽样的想法相对容易实现。然而，需要注意的是，尽管蒙特卡洛方法被宣传为执行 `random sampling`，但计算机的重抽样永远不可能 `truly` 随机。也就是说，一旦我们有一个算法选择下一个“随机”数，真正的随机性思想就永远丢失了。

该技术的常见用途之一是估计统计量的抽样分布，要么是因为抽样分布无法解析推导，要么只是因为我们想将蒙特卡洛方法与其解析对应物进行比较。当我们使用此类方法估计一个量及其抽样分布时，它通常被称为 `bootstrapping`。我们将在下一章介绍自助法。自助法是更一般的蒙特卡洛方法的特例，因为它具有重抽样。然而，请注意，自助法并不 `equivalent` 于蒙特卡洛方法。

蒙特卡洛方法还经常用于通过随机算法解决复杂的优化问题，因此经常用于统计和机器学习。此类方法也可以很容易地用于估计相对于竞争替代方案的统计功效。关于此的一个很好的例子，请参阅 [Rizzo (2019)](#ref.xhtml#re_CIT000303)。

## 1.25 缺失数据

缺失数据绝不应被忽略，因为 `missingness` 通常是有原因的。个人在调查中未回答某个特定问题的事实并不是缺失数据；相反，它是 `extremely informative data`，可能预示着最重要的回答。也许个人不愿承认自己曾偷过东西？因此，问题“你是否曾偷过东西？”的回答就是不回答！那就是变得 `most interest` 的数据。`Never ignore missing data`。`Instead, get curious as to why it is missing`。
