
### 5.10.1 经典中介

*图5.3* 经典中介模型，其中“`M`”是`X`与`Y`之间关系的中介。[返回正文。⏎](#c5.xhtml#re_f5.3)

“经典”或传统中介的条件通常包括以下内容（[MacKinnon et al., 2007](#ref.xhtml#re_CIT000232)）：

1. `X`应与`Y`存在关系。
2. `X`应与`M`存在关系。
3. 当`X`和`M`同时作为`Y`的预测因子时，`M`应与`Y`相关。
4. `X`与`Y`的关系在加入`M`后应*减弱*（就绝对值而言）， presumably 是因为`M`“吸收”了原本会从`X`传递到`Y`的相关性（仅在某种*统计*意义上）。243

更复杂的组合中介模型示例如[图5.4](#c5.xhtml#f5.4)所示，其中我们现在有三个中介变量`z[1]`、`z[2]`和`z[3]`，且`ε[1]`、`ε[2]`和`ε[3]`为误差。

虽然最初包含多个中介变量似乎是个好主意，但它伴随着许多注意事项。这些模型的有效性仅限于对其施加的假设。确实，正如Pearl再次指出的（[2012](#ref.xhtml#re_CIT000283)，第2–3页），我们对其进行转述：

> 这两种方法的有效性当然取决于*假设*\[加粗强调\]误差项…不相关，否则，部分结构参数会产生有偏的结果。在随机试验中，误差可以与随机化装置等同，我们可以确信误差与其他误差不相关，因此回归估计将是无偏的…然而，随机化并不能消除`e2`和`e3`的误差。

中介模型的复杂程度没有上限。例如，[图5.5](#c5.xhtml#f5.5)展示了一个具有混杂因素的中介模型，该混杂因素预测处理、中介变量和结果。除混杂因素外，该模型是经典的三变量中介模型。

### 5.10.2 统计调节

正如我们讨论中介和调节时开头所提到的，调节分析无非就是分析交互作用。也就是说，严格来说，“调节”只是统计*交互作用*的花哨说法。当你进行方差分析并建模交互作用时，你就是在进行调节分析。然而，在心理学等领域，关于调节分析的“炒作”实在太多，它经常被宣传为能够完成远超其能力的任务。再次重申，在调节分析的*统计*程序中，除非你所使用的变量和理论暗示了某种“物理”过程，否则没有任何东西必然在*物理*或*实质*意义上“调节”其他东西。*统计调节本身绝不会以任何方式提供该过程*。事实上，在许多情况下，统计调节可能相当令人失望。

作为调节的一个基本例子，请考虑[图5.6](#c5.xhtml#f5.6)中的图。

![图5.6 两组调节的说明；斜率非平行。返回正文。⏎](images/fig5.6.jpg)

*图5.6* 两组调节的说明；斜率非平行。[返回正文。⏎](#c5.xhtml#re_f5.6)

由于斜率不同（*非平行*），我们产生了调节效应。当然，在*样本*中，几乎*总是*会存在调节效应。你真的认为斜率在样本中可能*完全*平行吗？真正的问题是是否可以将此类效应推断到总体上，这正是我们最终感兴趣的推断问题。我们将在本章后面使用软件介绍一个调节的例子。

### 5.10.3 调节的中介

正如检验任何其他交互效应一样，人们可能有兴趣了解整个中介模型是否在调节变量的不同取值下成立。更具体地说，我们可能有兴趣了解*间接效应*（即，所谓“通过”中介变量的效果）是否取决于调节变量的取值。这被称为*调节的中介*，更一般地称为*条件过程模型*（[Hayes, 2018](#ref.xhtml#re_CIT000147)），或再次，寻找*条件间接效应*。也就是说，间接（或“中介”）效应取决于某个其他第三变量，如[图5.7](#c5.xhtml#f5.7)所示。245

![图5.7 以w为条件的三变量中介模型。返回正文。⏎](images/fig5.7.jpg)

*图5.7* 以`w`为条件的三变量中介模型。[返回正文。⏎](#c5.xhtml#re_f5.7)

我们在[图5.7](#c5.xhtml#f5.7)中看到经典的三变量中介模型，然而它取决于`w`变量，如`x*w`交互作用所示。请注意，由于*边际性原理*（[Fox, 2016](#ref.xhtml#re_CIT000106)），`w`和交互项`x*w`都被包含在内，该原理认为不应包含交互项而不同时包含构成该交互项的各个项，在本例中仅为`w`变量。

*中介的调节*模型是指自变量与调节变量之间的交互作用在统计上“影响”中介变量，而中介变量进而在统计上“影响”结果变量。根据Hayes（[2018](#ref.xhtml#re_CIT000147)，第465页），“中介的调节既不有趣也不有意义”，在大多数条件下在数学上等同于调节的中介。因此，Hayes建议将中介的调节问题重新表述为*调节的中介假设*。
