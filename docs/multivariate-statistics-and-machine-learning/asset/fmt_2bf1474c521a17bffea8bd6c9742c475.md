
## 11.16 t-SNE

*t*\-SNE, or *t-Distributed Stochastic Neighbor* *Embedding*, is related to the technique of SNE; like SNE, *t*\-SNE essentially converts high-dimensional Euclidean distances between data points into conditional probabilities. These probabilities then represent similarities between data points in higher dimensions. The “*t*” in *t*\-SNE stands for the *t*\-distribution, whereas traditional SNE, as we saw, uses the Gaussian (i.e., *z*) distribution. That is, SNE is, essentially, “*z*\-SNE” where `q[j|i]` is now defined,

$$q\_{j|i} = \\frac{\\left( 1 + \\middle| \\middle| y\_{i} - y\_{j} \\middle| \\middle| {}\_{2} \\right)^{- 1}}{\\sum\\limits\_{k \\neq l}\\left( 1 + \\middle| \\middle| y\_{k} - y\_{l} \\middle| \\middle| {}\_{2} \\right)^{- 1}}$$

(11.30)

The idea behind *t*\-SNE is, as was the case for SNE, to convert high-dimensional Euclidean distances into conditional probabilities that represent similarities. The technique provides a way to 454visualize high-dimensional data by essentially giving each data point a “location” in a two or three-dimensional map ([van der Maaten & Hinton, 2008](#ref.xhtml#re_CIT000372)). Given that the aim of dimensionality reduction is to preserve as much as possible the structure of high-dimensional data into a lower-dimensional map, *t*\-SNE does this remarkably well, presumably better than SNE and is easier to optimize than SNE ([van der Maaten & Hinton, 2008](#ref.xhtml#re_CIT000372)). The problem with SNE is that it is hampered by a cost function that is difficult to optimize and also by a problem referred to generally as the *crowding problem*.

The crowding problem is the idea that data points in higher dimensions may look far from each other, but when we reduce the dimensionality, say from two-dimensional to one-dimensional, we essentially do not have enough “room” to accommodate all neighbors to those points and they get “squashed” toward the center of the plot. Essentially, it’s another interpretation of the curse of dimensionality problem. This is one of the biggest problems with SNE. *t*\-SNE allows more “wiggle room” to place points through, in part, using a heavy-tailed distribution (*t*) instead of the Gaussian. For details on the crowding problem, see [van der Maaten and Hinton (2008)](#ref.xhtml#re_CIT000372). The crowding problem is not unique to *t*\-SNE however and occurs in other manifold procedures such as Sammon mapping. *t*\-SNE aims to improve on these limitations.

Even the most common methods of reducing dimensionality, such as Sammon mapping, Isomap, and others, while they perform relatively well on artificial data sets, they are not that great at visualization ([van der Maaten & Hinton, 2008](#ref.xhtml#re_CIT000372)). The main problem is that these techniques are not capable of maintaining both the local and global character of the data simultaneously. The benefit of *t*\-SNE is that it is able to assess much of the local structure of the high-dimensional data while also somewhat uncovering global structure such as the presence of clusters ([van der Maaten & Hinton, 2008](#ref.xhtml#re_CIT000372)).

### 11.16.1 Performance of *t*\-SNE to Other Techniques

[Maaten and Hinton (2008)](#ref.xhtml#re_CIT000372) compared the performance of *t*\-SNE to many other nonparametric visualization techniques such as Sammon mapping and Isomap, as well as locally linear embedding and found visualization via *t*\-SNE to generally be superior in almost all cases. However, as always, there is no “free lunch” and no single manifold technique is guaranteed to universally work better than others ([Izenman, 2008](#ref.xhtml#re_CIT000167)). Much depends on the data to which the given technique is being applied. A “multi-view” version of *t*\-SNE and Isomap has also been proposed (Rodosthenous et al., [2024](#ref.xhtml#re_CIT000305)), where multi-view data comprises of multiple kinds of data generated by the same sample. Multi-view versions of SNE, Isomap, as well as LLE were found to produce better visualizations when compared to single-view versions of the same techniques. See [Rodosthenous et al. (2024)](#ref.xhtml#re_CIT000305) for details.

### 11.16.3 *t*\-SNE in R

The package `Rtsne` ([Krijthe, 2015](#ref.xhtml#re_CIT000206)) performs *t*\-SNE. We adapt an example from the package’s documentation once more using the iris data. We first remove potential duplicates from the data:

```
> iris_unique <- unique(iris)
```

We next create a matrix made up of features sepal length through to petal width:

```
> iris_matrix <- as.matrix(iris_unique[,1:4])
> set.seed(42)
```

We now perform the *t*\-SNE:

```
> library(Rtsne)
> tsne_out <- Rtsne(iris_matrix,pca=FALSE,perplexity=30,theta=0.0)
```

As was the case for SNE, the `perplexity` controls how many nearest neighbors are taken into account when constructing the embedding in the lower-dimensional space ([Krijthe, 2015](#ref.xhtml#re_CIT000206)). `Theta` is a numeric measure of speed/accuracy trade-off, such that an increase in theta amounts to less accuracy. The default for *exact* *t-*SNE is 0.0. See the package for further details.

```
> plot(tsne_out$Y,col=iris_unique$Species, asp=1)
```
