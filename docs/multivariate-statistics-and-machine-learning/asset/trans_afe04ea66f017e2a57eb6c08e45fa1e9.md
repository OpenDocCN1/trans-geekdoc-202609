
在第一步，\[least-angle regression\] 识别出与响应最相关的变量。与完全拟合该变量不同，`LAR`（最小角回归）将该变量的系数连续地朝其最小二乘值移动（导致其与不断变化的残差的相关性绝对值减小）。一旦另一个变量在与残差的相关性方面“赶上”，过程就会暂停。然后第二个变量加入活动集，并且它们的系数以保持相关性相等且递减的方式一起移动。该过程一直持续到所有变量都进入模型为止，并以完整的最小二乘拟合结束。

该算法首先将预测变量标准化，使其均值等于 0，方差等于 1（即 `z` 分数）。在此初始步骤中，残差 `r[i]` 在模型中没有预测变量的情况下计算，即 $r\_{i} = y\_{i} - \\overline{y}$，回归中的所有系数均设为 0。也就是说，`β[1]` = `β[2]`， ..., `β[p]` = 0。接下来，具有与该残差最大相关性的预测变量进入模型；然而，*并非全部*。预测变量的权重向其最小二乘系数移动，直到另一个预测变量“赶上”并与当前残差的相关性与第一个预测变量一样大。此时，`β[1]` 和 `β[2]` 均朝向它们的 *联合* 最小二乘系数方向移动，直到另一个预测变量“赶上”当前残差。该算法以这种方式继续进行，直到所有预测变量都被纳入，从而为模型实现最小二乘解。在预测变量数量大于样本量的情况下（更具体地说，`N-1`），算法将在 `N-1` 步后达到零残差条件（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)，第 74 页）。

因此，最小角回归通过分段线性“部分”步骤建立回归模型，在每一步通过将新变量与当前残差相关联来添加单个元素。当另一个变量“赶上”时，算法朝预测变量移动的方向为 *等角*（即具有相同的角度）。因此，最小角回归被称为逐步回归的“民主”版本（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。套索和前向分段回归模型都可以通过 `least-angle regression algorithm` 计算（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。需要强调的关键点是，在最小角回归中，预测变量本质上在选择过程中“赶上”其他变量，然后这些变量一起移动。在 Python 中，可以使用 `Lars` 估计器拟合最小二乘回归。也可以使用 `LARS` 套索，它实现 `LARS` 估计器，同时将一些系数驱动为 0，这是套索的特征。
