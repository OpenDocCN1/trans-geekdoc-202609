
![图 15.6 ReLU 激活函数。对于等于或小于 0 的值，函数恒为 0，而对于大于 0 的值，函数的斜率等于 1。返回文本。⏎](images/fig15.6.jpg)

*图 15.6* The `ReLU` 激活函数。对于等于或小于 0 的值，函数恒为 0，而对于大于 0 的值，函数的斜率等于 1。[返回文本。⏎](#c15.xhtml#re_f15.6)

我们可以看到 `ReLU` “剪掉”小于 0 的值，但以稳定的“斜坡”方式激活大于 0 的值。`ReLU` 函数的一个优点是该函数及其导数可以非常容易地实现，且计算成本相对较低（[Lederer, 2021](#ref.xhtml#re_CIT000213)）。

尽管具有所有优点，`ReLU` 仍存在一个弱点。问题在于如果初始化权重很大且为负值，则可能导致在训练过程的大部分时间内许多 `ReLU` 节点处于 *inactive* 状态，这可能使算法难以或无法学习日益复杂的模型。也就是说，对于小于 0 的值，没有信息进入网络，因为根据函数对负值的定义，它们默认被设为等于 0。这在文献中被称为 `dead ReLU` 问题。它是 *vanishing gradient problem* 的一种形式（Dubey et al., [2022](#ref.xhtml#re_CIT000092); [Lederer, 2021](#ref.xhtml#re_CIT000213)）。解决该问题的可能方法包括选择较低的学习率或用 `leakyReLU` 替换 `ReLU`，我们现在讨论这一点。545

### 15.5.3.2 LeakyReLU

`leakyReLU` 由下式给出（其中权重 `a` = 0.01 被采用）

$$L{Re}LU\\left( x \\right) = \\left\\{ \\begin{array}{l} {x,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, x \\geq 0} \\\\ {0.01\\left( x \\right),\\,\\,\\,\\,\\, x < 0} \\\\ \\end{array} \\right.$$  

(15.7)

`ReLU` 与 `leakyReLU` 的比较见 [图 15.7](#c15.xhtml#f15.7)。

![图 15.7 ReLU（左）与 leakyReLU（右）。leakyReLU 在小于零的值上向下倾斜，而不是像 ReLU 那样在零处保持恒定。返回文本。⏎](images/fig15.7.jpg)

*图 15.7* `ReLU`（左）与 `leakyReLU`（右）。`leakyReLU` 在小于零的值上向下倾斜，而不是像 `ReLU` 那样在零处保持恒定。[返回文本。⏎](#c15.xhtml#re_f15.7)

我们看到，与 `ReLU` 的情况不同，函数对于所有小于 0 的值不再等于 0，`leaky ReLU` 将简单地等于某个非常小的负数而不是常数零。这转化为小于 0 的值的小负斜率。因此，`leakyReLU` 的范围是 (−∞,∞) 而不是 `ReLU` 的 \[0,∞)。这允许对小于 0 的值进行更新并避免 vanishing gradient problem（[Alpaydin, 2020](#ref.xhtml#re_CIT000009)）。正如 Dubey et al.（[2022](#ref.xhtml#re_CIT000092)）所指出的，`leakyReLU` 的一个问题在于确定负输入的正确斜率，因为不同的斜率可能适用于或最相关于不同类型的问题。`parametric ReLU`（`PReLU`）试图通过将负输入视为训练参数来纠正这一点，然而这可能导致过拟合。有关细节请参阅 Dubey et al.（[2022](#ref.xhtml#re_CIT000092)）。

另一种试图改进 `ReLU` 的激活函数是 `elu`，或 *exponential linear unit*，它是一个光滑函数，因此相对于 `ReLU` 具有优势：

$$elu\\left( x \\right) = \\left\\{ \\begin{array}{l} {x,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, x \\geq 0} \\\\ {\\alpha\\left( e^{x} - 1 \\right),\\,\\,\\,\\,\\, x < 0} \\\\ \\end{array} \\right.$$  

(15.8)

在 `elu` 中，`α` 是 `α(e^(x)-1)` 中的可训练超参数。虽然 `elu` 显示出积极的结果，但其理论依据不足（[Basirat & Roth, 2019](#ref.xhtml#re_CIT000022)）。`elu` 的一个变体是 `selu`，其中“*s*”代表“*scaled*”，并将正输入的斜率限制为大于一（Dubey et al., [2022](#ref.xhtml#re_CIT000092); [Lederer, 2021](#ref.xhtml#re_CIT000213)）。

我们可以通过查看它们的代数函数来继续详细说明大量激活函数，但也许最方便的是简单地以图形方式查看最常见的激活函数，因为它们的图形立即比解释其代数对应物更能说明其形式。在 [图 15.8](#c15.xhtml#f15.8) 中有一些更受欢迎的激活函数，其中包括并扩展了我们迄今为止调查的一些函数。546

## 15.5.4 Which Activation Function to Use?

正如我们在回顾激活函数之初所讨论的，根据 [Lederer (2021)](#ref.xhtml#re_CIT000213)，在实践中 `softsign` 和 `ReLU`（或 `leakyReLU`）应该是首选的激活函数。根据 [Basirat](#ref.xhtml#re_CIT000022) 和 Roth（2019），大多数深度学习方法主要由于其简单性和可靠性而使用 `ReLU`。[Izenman (2008)](#ref.xhtml#re_CIT000167) 指出，具有 `tanh` 函数的算法通常比具有 logistic 的算法收敛更快，然而 `tanh` 本身已被发现计算效率低下（Dubey et al., [2022](#ref.xhtml#re_CIT000092)）。如前所述，`sigmoid` 和 `tanh`，最初在神经网络早期由大脑生物神经元放电所激发（Dubey et al., [2022](#ref.xhtml#re_CIT000092)），遭受 *vanishing gradient problem*（[Basirat](#ref.xhtml#re_CIT000022) & Roth, 2019）的原因是它们是压缩函数。回想一下，这是因为梯度变得非常接近 0，导致训练期间参数几乎没有更新。对于 `ReLU`，由于正输入的导数等于一，梯度不会消失。

机器学习和数学领域存在一个完整的文献和专业领域，专门用于评估现有激活函数以及提出新的激活函数。最近的工作还引入了 *learning/adaptive activation functions* 的概念，正如名称所示，它们包含可学习参数以利用数据的更多复杂性。这些包括诸如 `Adaptive Piecewise Linear`（`APL`）、`swish`、`e-swish` 等激活函数。请参阅 [Dubey et al. (2022)](#ref.xhtml#re_CIT000092) 以获得对各种非自适应和自适应激活函数的优缺点进行彻底且出色的综述，并且他们还给出了在各种条件下应使用哪些激活函数的一系列建议。虽然 `ReLU` 通常是默认选择，但这些作者还建议对大多数问题尝试 `swish`、`mish,` 和 `PAU`（`Padé activation unit`）。当然，对于任何给定问题尝试各种激活函数绝对没有问题。只要 resulting network 理想情况下接受交叉验证，就没有任何理论上的“type I error rate”会限制用户尝试几种激活函数。
