
其中 `θ̂[g]` 是 `θ[g]` 的最大似然估计，`v[g]` 是具有 `g` 个分量的模型相关的估计参数数量（[Baudry 等, 2010](#ref.xhtml#re_CIT000024)），而 `n` 是样本量。注意，在这种情况下，更大的 `BIC` 值优于更小的值，因为目标是最大化方程的第一部分，即 log `p(x|g,θ̂[g])`。惩罚或校正因子在第二项 $\\frac{v\_{g}}{2}\\log\\left( n \\right)$ 中，其中包含了为给定 `g` 个分量获得给定最大值所需参数的数量 `v[g]`。在 `v[g]` 所需参数越多时，$\\frac{v\_{g}}{2}\\log\\left( n \\right)$ 会越来越大，因此我们从 log `p(x|g,θ̂[g])` 中减去一个越来越大的数。因此，与 `BIC` 一样，通常更倾向于更简约的模型。此处通常不鼓励使用截断标准，而什么构成“良好”的聚类解将取决于研究领域和用户判断。还要注意，在聚类分析中，混合模型的 `BIC` 及其相关模型选择统计量存在不同版本。我们在此呈现的内容是 528仅一种可能性。在解释之前，始终核实给定作者或软件如何定义所使用的特定模型选择统计量是良好的实践。

包 `mclust`（Scrucca et al., [2023](#ref.xhtml#re_CIT000331)）可在 `R` 中执行混合建模。

## 14.13 聚类验证

在回顾了包括 `k-means`、层次、基于密度和混合模型在内的最基本聚类分析算法和方法后，我们以对聚类验证问题及选择聚类数标准的简要讨论和回顾来结束本章。

一般而言，对聚类解可以进行两种类型的验证：1）内部验证标准，和 2）外部验证标准。其中最受青睐的当然是外部验证，因为对聚类解进行外部验证使我们重新与经验世界联系起来，类似于在测试数据上对模型进行交叉验证，有助于我们了解模型或算法在尚未见过的数据上的表现。然而，当外部验证标准不可用或难以获得时，内部验证方法也可能有用。

内部验证方法包括到质心的平方距离之和，其如名称所示，是个案与其对应质心之间变异性的度量。更好的聚类解通常比较差的解具有更小的平方和距离。该度量可用于 `k-means`，但不能用于诸如 `DBSCAN` 之类的基于密度聚类。还可以计算类内距离（距离内部）与类间距离（距离之间）的比率（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)，第 196 页），其中较小的值表明解更好。内部有效性的其他度量包括轮廓系数以及概率度量。详情请参见 Aggarwal（[2015](#ref.xhtml#re_CIT000005)，第 196–197 页）。Tibshirani、Walther 和 Hastie（[2001](#ref.xhtml#re_CIT000359)）还提出了上述“间隙”统计量，在某些情况下也可能有用。间隙本质上将给定聚类解（例如 `k-means` 中的 `k` 聚类解）的总类内变异与在零分布下预期值进行比较。因此，越来越大的间隙表明聚类解更精细。

对于混合模型，如我们所见，可以计算对数似然统计量以及 `BIC` 以帮助确定混合模型的分量数。应注意，混合模型是少数通常允许进行显著性检验的聚类方法之一，因为它们是概率性的。还提出了一种称为聚类图（clustergram）的工具（详情请参见 [Fleischmann, 2023](#ref.xhtml#re_CIT000104)）。

外部聚类验证方法在实际聚类（有时称为真实值）的知识在进行聚类分析之前已知时最有用（例如聚类鸢尾花数据的情况）。使用外部验证方法而非内部方法的优点在于它们不会受到执行聚类的特定算法的偏差影响（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)）。为了外部验证聚类解，可以生成诸如混淆矩阵之类的简单工具，正如读者从判别分析中回忆的那样，以了解聚类解如何“模仿”现实或真实值。虽然较小混淆矩阵的简单可视化可能已足够，但对于特别大的混淆矩阵，可以计算聚类纯度度量，正如我们之前对鸢尾花数据聚类时所做的那样。正如所料，虽然这些和其他度量很有用，但对聚类数的最终决定通常取决于实质性解释，并且应高度受聚类解在研究或科学背景下表现出的实用性影响。529

## 14.14 聚类分析及其延伸

在本章中，我们回顾了聚类分析和数据分割最常见和基础的技术。这些包括诸如 `k-means` 和其他 `k` 代表、层次和凝聚方法、诸如 `DBSCAN` 之类的基于密度方法以及混合模型等技术。读者应注意，本章在聚类分析文献方面仅触及了皮毛。新的聚类技术在统计和机器学习文献中不断被开发。然而，与本书中回顾的其他方法一样，如果读者对本章回顾的技术基础扎实，他们将处于合理的位置，能够将该知识推广到未来遇到的新技术。

接下来该去哪里？所回顾方法的扩展几乎是无限的。本章中的 `k-means` 聚类方法可以扩展到核 `k-means` 算法。`DENCLUE` 算法基于核密度估计（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)）。集成方法也可以用于选择聚类解，因为不同方法可能提供冲突的解，但将它们结合起来可能描绘出更清晰的图景。`K-means` 用于与数据压缩相关的矢量量化，常用于图像分析（详情请参见 [Bishop, 2006](#ref.xhtml#re_CIT000032)，第 428 页）。

聚类分析也可以应用于分类数据，但难度更大；`k-modes` 聚类是分类分析的一种选择。一种被发现对分类数据有用的层次算法是 `ROCK`，代表分类属性的稳健聚类算法。详情请参见 [Aggarwal (2015)](#ref.xhtml#re_CIT000005)。半监督聚类分析方法也可用。

聚类分析的其他选项包括谱聚类，其特征是对相似矩阵进行特征值分析（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)），以及双聚类，其涉及对数据矩阵的行或列进行聚类。详情请参见 Murray (2022, 第 731 页)。
