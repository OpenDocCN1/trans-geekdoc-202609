
More to the point, projection pursuit is the search in a potentially nonlinear structure of high-dimensional data lower-dimensional linear projections ([Posse, 1995](#ref.xhtml#re_CIT000291)). It is considered nonparametric since nonparametric estimators (*smoothers*) are used in the estimation process. Many excellent examples of projection pursuit can be found in [Posse (1995)](#ref.xhtml#re_CIT000291). Projection pursuit is primarily a visualization technique with limited output as is traditional with methods such as principal components analysis ([Laa & Cook, 2020](#ref.xhtml#re_CIT000210)).

Projection pursuit itself was first coined by [Friedman and Tukey (1974)](#ref.xhtml#re_CIT000112) in what is an exceptionally well-written paper “A Projection Pursuit Algorithm for Exploratory Data Analysis,” but as mentioned had its origins somewhat earlier with [Kruskal (1969)](#ref.xhtml#re_CIT000204). Friedman and Tukey introduced the method as an algorithm that seeks to find one- and two-dimensional linear projections of multivariate data that are relatively highly revealing:
> Mapping of multivariate data onto low-dimensional manifolds for visual inspection is a commonly used technique in data analysis. The discovery of mappings that reveal the salient features of the multidimensional point swarm is often far from trivial. Even when every adequate description of the data requires more variables than can be conveniently perceived (at one 556time) by humans, it is quite often still useful to map the data into a lower, humanly perceivable, dimensionality where the human gift for pattern recognition can be applied.
>
> ([Friedman & Tukey, 1974](#ref.xhtml#re_CIT000112), p. 1)

Interestingly, Friedman and Tukey chose not to treat nonlinear dimension reduction techniques stating that they are more difficult to interpret but also for their computational complexity, a problem that has since been overcome by the modern uprise in computing power. Projection pursuit uses a *projection index* as a quantity that needs to be optimized in the search for interesting projections. Hence, we see immediately that *principal components analysis can be regarded as a special case of projection pursuit where the index is that of maximizing variance of orthogonal linear combinations*.

Components analysis, as we have seen, is by far not the only way to project data. For instance, returning to a simpler example, one could project data via ordinary least-squares. Most of the indexes used in projection pursuit are built around detecting departures from known distributions, such as multivariate normality, or projections that are best able to distinguish between groups ([Laa & Cook, 2020](#ref.xhtml#re_CIT000210)). As [Jolliffe (2002)](#ref.xhtml#re_CIT000174) notes, most projection pursuit techniques begin by assuming that multivariate normality is the *least* interesting basis for a projection, and hence many indices in the projection essentially measure deviations from this “uneventful” status. Numerically, the actual index is a scalar computed in the *d*\-dimensional space and is maximized over all possible *d-*dimensional projections of a data set. A number of indexes are discussed in [Laa and Cook (2020)](#ref.xhtml#re_CIT000210). For a concise summary of projection pursuit, see Jolliffe ([2002](#ref.xhtml#re_CIT000174), pp. 219–221).

### 15.12.1 Projection Pursuit Regression and Relation to Neural Networks

The model for *projection pursuit regression*, which can be considered a special case of the wider more general projection pursuit framework, can be stated as follows:
$$y\_{i} = \\beta\_{0} + {\\sum\\limits\_{j = 1}^{r}{f\_{j}\\left( \\beta\_{j}^{T}x\_{i} \\right) + \\varepsilon\_{i}}}$$
(15.17)
where the model looks pretty much the same as we would expect from a typical linear regression model,
$$y\_{i} = \\beta\_{0} + {\\sum\\limits\_{j = 1}^{r}{\\left( \\beta\_{j}^{T}x\_{i} \\right) + \\varepsilon\_{i}}}$$

However, note the key difference, the inclusion of *f*[*j*] in the projection pursuit of (15.17). For convenience, we will drop the error term *ε*[*i*] for now and simply focus on the systematic portion of the model. In projection pursuit, we can have numerous functions *m* through *M* and hence we account for these via summation,
$$\\left. y\_{i} = {\\sum\\limits\_{j = 1}^{M}{f\_{j}\\left( \\beta\_{j}^{T} \\right.}}x\_{i} \\right)$$
and seek to minimize the following error function557
$${\\sum\\limits\_{i}^{N}\\left\\lbrack \\left. y\_{i} - {\\sum\\limits\_{m = 1}^{M}{f\_{j}\\left( \\beta\_{j}^{T} \\right.}}x\_{i} \\right) \\right\\rbrack}^{2}$$
(15.18)

We can think of *β*[*j*]^(*T*) in projection pursuit as containing *directions* instead of merely scalars as we might typically think of such in ordinary regression ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)) though it definitely does not hurt to think of these weights as directions in classical regression as well. In projection pursuit, *f*[*j*](*β*[*j*]^(*T*)*x*[*i*]) is called a *ridge function*, with its direction determined by values in *β*[*j*]^(*T*). We note that essentially the only difference between this and the classic linear model is the inclusion of *f*[*j*], where these are a *collection* of unknown smoothing functions (i.e., “unknown” until they are “learned” from the data). That is, in *f*[*j*](*β*[*j*]^(*T*)*x*[*i*]) we are taking a function *f*[*j*] of another function *β*[*j*]^(*T*)*x*[*i*] and hence once more, we are taking a *composite function* just as we do in a neural network. The number of these smoothing functions we will take is a *flexible hyperparameter*. When that number is one the model is sometimes referred to as a *single index model* ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)). Cross-validation can be used to determine an optimal number of smoothing functions. Its value can also be determined based on how much each successive term improves the model in terms of visualization.

We can see that the projection pursuit model is entirely general. Indeed, as noted by [Hastie et al. (2009](#ref.xhtml#re_CIT000145), p. 390), “the operation of forming nonlinear functions of linear combinations generates a surprisingly large class of models.” The link to neural networks is rather obvious then, such that in neural networks we are taking, as we saw, *(typically) nonlinear functions of linear (or nonlinear) combinations*. In projection pursuit, we could do the same if we chose a linear function instead of smoothing functions. That is, with a bit of generality, projection pursuit can be conceptualized as a layered neural network where *f*[*j*] essentially becomes the *activation function*. Once we make *f*[*j*] a classic *activation function* such as the *sigmoid function* instead of smoothing functions, projection pursuit essentially becomes analogous to a simple neural network.

One key difference between projection pursuit and neural networks, however, is that the *activation function* in the former can be different for each hidden unit and is typically estimated *nonparametrically*, where in neural networks such are usually prespecified parametric functions. However, this does not make neural networks entirely parametric, since they are especially useful when we have no theoretical preconceptions about the data. That is, neural networks “learn” from the data, which is a very “nonparametric” idea. And while it is technically possible to assign a *unique* activation function to each hidden unit in a neural network, it is not the norm.
