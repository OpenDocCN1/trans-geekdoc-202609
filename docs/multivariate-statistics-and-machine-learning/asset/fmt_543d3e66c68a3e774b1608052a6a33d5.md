
## Overview
If dimension reduction is so vast a subject, why begin with `PCA`? We begin with `PCA` simply because it is generally considered the most common and oldest method of the family of dimension-reduction methods, having its origins with Karl Pearson in 1901. It is also the easiest (though deceptively simple) to understand and hence forms a good grounding for understanding other more advanced techniques as extensions or derivatives of essential `PCA`. Since the time of Pearson, several other dimension-reduction methods have been developed, `PCA` now considered only a *special case* of a wider family of blind source separation techniques ([Izenman, 2008](#ref.xhtml#re_CIT000167)). Many of the more modern techniques feature latent variables which are analogous to hidden variables in neural networks ([Izenman, 2008](#ref.xhtml#re_CIT000167)) and are also featured extensively in exploratory and confirmatory factor-analytic models as well as structural equation models. In its most general interpretation, 396blind source separation involves separating out signals from noise, such that the signals extracted possess certain mathematically desirable properties, such as orthogonality in the case of classical `PCA` and many versions of exploratory factor analysis, or independence in the case of independent components analysis or independent factor analysis.

Principal components analysis can also be considered purely from an essential linear algebra point of view, equivalent to `best subspace approximation` using the singular value decomposition, or “`SVD`” for short (more precisely, `reduced SVD`). Singular value decomposition itself dates back to [Beltrami (1873)](#ref.xhtml#re_CIT000027) and is a method for obtaining eigenvalues and eigenvectors from a matrix, mathematical objects that are at the very crux of `PCA`. `SVD` is able to decompose via factorization of a rectangular matrix `X` such that

```
X = V D W^(T)
```

(11.1)

where `X` in a statistical application is a data matrix of observations on a number of variables, `V` and `W` contain orthonormal columns (i.e., orthogonal and of length equal to one), and `D` is a diagonal matrix ([Jolliffe, 2002](#ref.xhtml#re_CIT000174), p. 44). From the `SVD`, singular values and singular vectors can be obtained of even rectangular matrices, and hence `SVD` can be considered a pathway to generating principal components.

We can also conceptualize `PCA` as a `rotation`, such that `PCA` transforms or rotates empirical data by deriving new axes from which the data are projected onto these new axes. These new axes are the `eigenvectors` of the rotation. The `best basis theorem` states the best orthonormal basis is given by the leading eigenvectors of the transformation.

Whether one uses eigen analysis or `SVD` to compute principal components will result in the same components, though `SVD` is often preferred due to computational benefits (Murray, 2022). For extremely large dimensional problems, a `randomized SVD algorithm` (Murray, 2022) can be used to handle increasingly large dimensional data. In Python, for instance, `sklearn` features a randomized solver. `PCA` is also associated with the `Eckart-Young` and `Schmidt-Mirsky` theorems in mathematics as these both account for the mathematics that underlie the dimension-reduction technique.

> *In modern statistics and machine learning, there are a whole host of dimension-reduction techniques. What unites them all is the attempt to “uncover” a lower-dimensional manifold from higher-dimensional data. That data could be attributes on a scale or an image that needs to be “decoded” by color, or even sound signals from a musical symphony.*

## 11.2 Deriving Classic Principal Components Analysis
As mentioned, classical `PCA` has its roots with Pearson in 1901. The term “principal component” was coined by Hotelling in 1933. Classical `PCA` is motivated as follows. Suppose we have a set of observed variables `x[1]` through `x[p]`. From these observed variables, we wish to produce linear combinations of these variables that have desirable statistical properties. Recall more generally the nature of a linear combination from our earlier review of linear algebra:397

```
l[i] = a[1] y[1] + a[2] y[2] + ... + a[p] y[p]
```

where a linear combination `l[i]` is a `weighted sum of products` and where `a[1]` through `a[p]` are the weights applied to observed variables `y[1]` through `y[p]`. For our data on `x[1]`,...,`x[p]`, the linear combination becomes

```
z[i] = a[1] x[1] + a[2] x[2] + ... + a[p] x[p]
```

where now `z[i]` is the name of the linear combination and `x[1]` through `x[p]` are the observed variables. A principal component is a unique kind of linear combination such that the weights `a[1]` through `a[p]` correspond to values of allied eigenvectors extracted from an eigen analysis performed on the covariance or correlation matrix of variables `x[1]`,...,`x[p]`. Hence, if we denote the weights `a[1]` through `a[p]` by `e[1]` through `e[p]` to denote eigenvector weights, the first principal component is defined as

```
z[1] = e[1] x[1] + e[2] x[2] + ... + e[p] x[p]
```

(11.2)

The first principal component possesses an important property; `it is the linear combination that accounts for the most variance in the observed variables`. What this means is that the variance of the resulting `z[i]` will have `maximum variance` compared to any other linear combination that we could have derived from the data. If you think about this for a moment, you might agree that it is a favorable quality to have for a linear combination. It suggests that instead of needing `x[1]`,...,`x[p]` variables, perhaps we could account for a great deal of the variance in those observed variables by considering only the first principal component. That is, the first component makes up a large proportion of those observed variables.

However, the first principal component will likely not account for `all` of the variance in the variables. To account for more, we will have to consider the second and successive principal components.

More formally, if the total variance `E|x-μ|²` is defined by

```
E|x-μ|_2 = sum_{i=1}^{p} var x_i = sum_{i=1}^{p} sigma_{ii}^2 = tr Sigma
```

(11.3)

where `tr Sigma` is the sum of variances `sigma[ii]^2` along the main diagonal, `PCA` essentially constructs orthogonal variables (i.e., linear combinations) the variance of which, in totality, equal `tr Sigma`.

> *The first principal component is that which accounts for maximal amount of the variance in the original variables as possible. Ensuing components will account for increasingly less variance.*398

### 11.2.1 The Second Principal Component
The second principal component is that linear combination that accounts for maximal variance in the variables, as was true for the first component, but with an additional important property, that it accounts for variance `not captured by the first` `principal component`. How can we express this idea mathematically? Recall that in linear algebra, linear combinations that account for different sources of `information` (in a sense) more generally in the original variables are called `orthogonal`. Hence, the second principal component is that linear combination accounting for maximal variance in the observed variables but `orthogonal` to the first component:

```
z[2] = e[1] x[1] + e[2] x[2] + ... + e[p] x[p]
```
