# 14 Cluster Analysis and Data Segmentation

DOI: [10.4324/9781003376941-17](https://doi.org/10.4324/9781003376941-17)

Cluster analysis, also known as *data segmentation*, is a general name for a variety of methods and analyses designed to discover, *in some sense*, groups of cases that, again, *in some sense*, “go together.” Perhaps the most significant challenge to cluster analysis is in defining what exactly *is* a cluster. Indeed, unpacking the phrase “in some sense” is very much the goal of this chapter. As noted by [Izenman (2008)](#ref.xhtml#re_CIT000167), determining the exact nature of a cluster “is a difficult question to answer mainly because there is no universally accepted definition of exactly what constitutes a cluster. As a result, the various clustering methods usually do not produce identical or even similar solutions” (p. 408). Hence, as we will see, there is no universal single cluster solution when it comes to cluster analysis. Rather, there are a variety of algorithms that will potentially generate disparate results depending on the algorithm used in performing the clustering and the data on which that algorithm is interacting.

A good clustering algorithm, in general, should intuitively be one for which pairwise distances between cases are smaller for cases *within* the same cluster than for cases *between* clusters. More formally, cluster analysis attempts to discover multiple convex regions (i.e., convex meaning *circular* or *sphere-like*) of the variable space that essentially contain modes of the probability distribution of that variable space ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)). One can also seek to “cluster the clusters” such that the clusters that are most alike are classified into a larger “super cluster.” At first glance, the establishment of clusters may seem to resemble very much techniques such as PCA. However, in PCA the number of generated dimensions could never be more than the number of original dimensions (i.e., variables) subjected to the PCA. And while in cluster analysis one cannot typically generate more clusters than there are cases, the dimensionality of the new “clustered” space can actually be more numerous than in the original variables ([Alpaydin, 2020](#ref.xhtml#re_CIT000009), p. 178).
