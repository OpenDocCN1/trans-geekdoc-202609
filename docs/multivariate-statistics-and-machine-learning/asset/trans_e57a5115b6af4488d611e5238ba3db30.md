
## 5.12 主成分回归

对主成分分析（PCA）的更深入讨论留待本书后面章节，在那里我们将更详细地讨论降维技术和流形学习，并专门用一整章来讨论 PCA 技术。目前，我们仅简要介绍该方法，以了解它如何服务于 PCA 回归技术。

主成分分析推导出变量数相等的 *正交线性组合*，使得连续的线性组合所解释的观测变量方差越来越少。回想一下，线性组合定义为248

`l[i] = a[1]y[1] + a[2]y[2] + ... + a[p]y[p]`

也就是说，线性组合是 *加权乘积之和*，其中 `a[1]` 到 `a[p]` 是应用于观测变量 `y[1]` 到 `y[p]` 的权重。对于我们关于 `x[1]`、...、`x[p]` 的数据，线性组合变为

`z[i] = a[1]x[1] + a[2]x[2] + ... + a[p]x[p]`

其中现在 `z[i]` 是线性组合的名称，而 `x[1]` 到 `x[p]` 是观测变量。主成分是一种独特的线性组合，其权重 `a[1]` 到 `a[p]` 对应于从对变量 `x[1]`、...、`x[p]` 的协方差或相关矩阵进行的特征值分析中提取的相关特征向量的值。因此，如果我们用 `e[1]` 到 `e[p]` 表示权重 `a[1]` 到 `a[p]` 以表示特征向量权重，则第一个主成分定义为

`z[1] = e[1]x[1] + e[2]x[2] + ... + e[p]x[p]`

(5.31)

第一个主成分解释了观测变量中最多的方差。第二个主成分解释了观测变量中第二多的方差，但与第一个正交。PCA 的目标是尽可能在前几个成分中捕获尽可能多的方差，以解释观测变量集合的方差。*主成分回归* 以最小二乘意义上使用前几个主成分作为预测变量。这样，保留在 `PCR`（*主成分回归*）中的成分数量可以类比为 *调优参数*（[Boehmke & Greenwell, 2020](#ref.xhtml#re_CIT000033)）。正如我们在介绍岭回归和套索回归等方法时将看到的那样，调优参数对于控制统计学习方法中方差与偏差之间的平衡非常有用，并且有助于从更广泛的可能性中选择“最佳”模型。

主成分回归乍看之下似乎很有用，但它做出了一个重要的假设，该假设在经验数据中可能并不总是成立。通过对一组成分回归 `y`，*我们隐含地假设方差最大的方向在* `x[1]` *到* `x[p]` *是与* `y` *相关联的那些相同方向*。虽然这一假设可能并不总是成立，但它通常被认为是对大多数数据有用的近似，并且 PCA 回归通常能给出合理的结果（[James et al., 2013](#ref.xhtml#re_CIT000168)）。正如 [Izenman (2008, p.132)](#ref.xhtml#re_CIT000167) 更精确地所述：

> 主成分的提取是在没有任何参考输出变量 `Y` 的情况下完成的，我们没有理由期望 `Y` 与任何主成分高度相关，特别是那些具有最大特征值的成分。事实上，`Y` 可能与其最后几个主成分甚至最后一个主成分的相关性最高。

或者，正如 [Artigue and Smith (2018, p. 9)](#ref.xhtml#re_CIT000014) 更清晰地阐述的那样：

> 主成分回归的承诺在于，它是一种基于解释变量之间相关性，从大量可能性中选择相对较少数量的解释变量的有效方法。问题在于候选变量上的特征向量权重与其与被预测变量的关系无关。轻微重要的变量可能被赋予比重要变量更大的权重。干扰变量可能被赋予比真实解释变量更大的权重。真实解释变量的系数可能被赋予错误的符号。249

尽管主成分回归提供了一种简单的方法来使用少于问题的全部预测变量谱，但由于无法保证最能解释预测变量的方向也将是最适合用于预测响应的方向，因此它不应被视为特征或变量选择方法。事实上，完全可能存在与响应仅弱相关的变量，但随着这些变量数量的增加，`R-squared` 仍会接近 1.0。一般来说，添加无用预测变量虽然会导致维度增加，但会冒过拟合和测试误差增加的风险。

上述问题的更深入讨论可在 [Jolliffe (1982)](#ref.xhtml#re_CIT000408) 中找到。关键要点是 *尽管 PCA 回归保证推导出在预测变量集合中最大化方差的正交成分，但这不一定等同于最大化* `R²` *在* `y` *与那些解释* `x[1]` *到* `x[p]` *中最大方差的成分之间*。因此，PCA 回归不应被视为变量选择技术（[James et al., 2013](#ref.xhtml#re_CIT000168)），其精神与诸如 *最优子集* 或 *前向回归* 等技术相同。PCA 回归也不是尺度不变的，因此通常（尽管不是 *总是*）建议对预测变量进行标准化。

### 5.12.2 PCA 回归与奇异性

正如我们所见，PCA 回归在希望在将所得成分用作响应预测变量之前降低预测变量维度时可能很有用。更具体地说，当预测变量彼此高度相关时，PCA 回归可能很有用。

还有另一种情况，PCA 回归可能特别有用，那就是当预测变量矩阵 `X` 为 *奇异* 且因此 *病态* 时。回想一下，对于奇异矩阵 `X`，意味着一行或一列是另一行或多行列的线性组合。这一条件始终意味着矩阵的行列式将等于零，这意味着 `X` 的逆无法计算。在这种情况下，在计算最小二乘估计时可以代入 *广义逆*。广义逆有很多种，但最常见的是 *Moore-Penrose 逆*，使用它将得到广义逆回归估计量（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。

`X` 侧 PCA 回归中应保留的成分数量可由 *Kaiser 准则* 确定，该准则指出对于相关矩阵应保留所有特征值大于 1 的成分，或通过使用交叉验证技术确定（[Wold, 1978](#ref.xhtml#re_CIT000390)）。派生成分的实质意义在选择时也可能发挥重要作用，这取决于成分的科学性质是否对科学家重要。
