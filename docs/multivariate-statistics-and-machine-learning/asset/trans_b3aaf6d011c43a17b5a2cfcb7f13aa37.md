
各变量的方差如下：

```
> var(x)
[1] 0.6165556
> var(y)
[1] 0.7165556
```

这些方差之和为

```
> sum(var(x), var(y))
[1] 1.333111
```

当我们对该数据来自的协方差矩阵进行成分分析时，通过特征值分析得到特征值为 1.284 和 0.0491，其总和为 1.3331，我们注意到这与将变量的原始方差相加所产生的总和相同。因此，我们通过实证数据证明，PCA 并未 *改变* 变量中的方差，它只是将方差 *重构* 到新的维度上，而不是原始变量上。*新成分所解释的方差与原始变量中的方差相同*。这就是为什么我们再次不喜欢 PCA “发现” 维度的想法。我们更愿意说 PCA 只是将变量 *重新组织* 到由分解在数学上保证的维度上。对于大多数数据集和行为良好的矩阵，PCA *会* 生成成分。能否对这些成分进行 *解释* 以及它们是否具有意义才是真正感兴趣的 *实际* 问题。

### 11.2.9 主成分作为轴的旋转

我们已经看到，主成分分析可以通过特征值分析来解释，或通过最小二乘论证来解释，其中最小化的是平方垂直距离而不是垂直距离。主成分分析的真正“奥秘”在于特征值分析。一旦我们接受特征值分析可以进行，接受我们可以生成成分就是相对简单的事情。此时重要的是对这些成分的实质性理解。404我们所说的意思是，如果一个人真正想理解 PCA，就需要真正理解特征值分析。

我们对 PCA 的理解也可以从理解其几何特性中受益。从几何上讲，PCA 不过是对原始笛卡尔轴的旋转。为了演示这种旋转，再次考虑我们关于 PCA 的数据（[Smith, 2002](#ref.xhtml#re_CIT000340)）：

### 11.2.10 主成分、判别函数、典型变量：基础的联系

正如本书开头所述，如果有一条贯穿其中的共同主题，其中之一就是 *降维*。即使是方差分析，在本科统计学中很久以前就知道了，从更深的理论层面来说，也可以说是在生成数据可以投影到的新维度。因此，读者在某个时候可能会觉得本书及以后所介绍的许多方法都在执行类似的任务。的确，降维在某种程度上是大多数方法的共同点，尽管关于各种方法如何执行此类任务，当然存在重要的差异。

回顾一下，我们在本书前面说过，判别函数是潜在的维度，使得它们最大化组间分离。连续的维度 406彼此不相关。判别分析和主成分分析都执行了降维的“一种形式”，但它们的做法不同。首先，在 PCA 中，获得的维度最大化 *方差*，而不是最大化 *组间分离*。其次，虽然判别函数彼此不相关，但它们通常不是正交的，而主成分既不相关 *又* 正交。成分具有更强的正交性属性（[Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)）。这在典型相关中的典型变量中也是如此；*它们是不相关的但不是正交的*。如前所述，成分可以被设为独立（或接近独立），但这需要独立成分分析而不是经典 PCA。PCA 只保证成分不相关，这比统计独立性是一个更弱的属性（[Jolliffe, 2002](#ref.xhtml#re_CIT000174)，p. 396）。
