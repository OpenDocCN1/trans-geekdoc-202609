
## 11.13 Locally Linear Embedding
A weight is also set to 0 if the neighboring point is the actual point we are building a neighborhood around, hence, this necessitates the idea of considering only points that are truly “neighbors” instead of the actual focal point ([Roweis & Saul, 2000](#ref.xhtml#re_CIT000315)). The corresponding weights in `Ŵ` are then used in reconstructing values of `Y`, which correspond to the lower-dimensional representation.

How many dimensions should `Y` consist of? The lower dimension projected points are obtained by minimizing a similar function as we did for the original higher-dimensional scores `x[i]`, only that now, the minimization is relative to `y[i]` instead of `x[i]`,

$$z = {\\sum\\limits\_{i}\\left| \\middle| y\_{i} - {\\sum\\limits\_{j}\\left. W\_{ij}y\_{j} \\middle| \\right|^{2}} \\right.}$$

(11.21)

such that ${\\sum\\limits\_{i = 1}^{n}{y\_{i}y\_{i}^{T}}} = I$ and also that $\\sum\\limits\_{i = 1}^{n}{y\_{i} = 0}$. The first condition guarantees that points will be uncorrelated, whereas the second condition centers the output on the origin. Together, both conditions impose a unit covariance matrix for `z` which now contains the new coordinates as a function of the weights in `W`. That is, `E(z)` = 0 and `Cov(z)` = `I` ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)). The function for `z` is then minimized via an eigen analysis on

`E` = (`I`−`W`)ᵀ(`I`−`W`)

(11.22)

thus obtaining `d` eigenvalue-eigenvector pairs that correspond to the new embedded dimensionality of the original data ([Belkin & Niyogi, 2003](#ref.xhtml#re_CIT000026)), keeping the eigenvectors that correspond to the lowest (nonzero) eigenvalues. Such will yield a set of orthogonal coordinates ([Roweis & Saul, 2000](#ref.xhtml#re_CIT000315)) corresponding to the `d`\-dimensions chosen for the eigen analysis, where `d` is a free parameter set by the user. In essence then, *LLE first establishes points as a function of some arbitrarily chosen definition of nearest neighbors, then reconstructs new points in lower dimensions, given the constraint that such “new” points are reconstructed subject to the aforementioned concept and definition of neighborhoods*. *In this sense, the reconstruction implements the concept of “linear patches” in reconstructing points in lower dimensions*.

An advantage of `LLE` is that it is unlikely to get “stuck” in local minima as the optimization is convex. A disadvantage is that it does not learn a new mapping such that we can predict new values for `z` for new inputs ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)). Note that `LLE` also makes no attempt to measure geodesic distances. This will prove to be a significant difference when we compare it to procedures that do, such as `Isomap`.

## 11.14 Isomap
Recall that classical multidimensional scaling (MDS) attempts to output coordinates (i.e., the *principal coordinates*) that seek to preserve pairwise distances. If the true manifold is complex, then classical MDS using Euclidean distances may not recover it. What `Isomap` (*isometric feature mapping*) does is use the *geodesic distance* (not Euclidean distance as is usually used in classical MDS), which, recall, is essentially “the shortest curve length which respects the geometry of the data” ([Ihler, 2003](#ref.xhtml#re_CIT000163)). *Isomap seeks to preserve this geodesic distance when reducing the dimensionality*. That is, if two points are distant in higher dimensions, we would like to preserve that distance in lower dimensions, and vice versa. The distance `x[i]` − `x[j]` is sought to be preserved when transformed to a geodesic distance. According to its innovators, “ours \[Isomap\] efficiently computes a globally optimal solution, and, for an important class of data manifolds, is guaranteed to converge asymptotically to the true structure” (Tenenbaum et al., [2000](#ref.xhtml#re_CIT000354), p. 2319). The convergence is justified by a theorem that holds that as `n`→∞ distances on a manifold (so-called *graph distances*), increasingly provide better and better approximation to true geodesic distances (Tenenbaum et al., [2000](#ref.xhtml#re_CIT000354)). This result is assured because the approximation can be achieved by much shorter Euclidean distance “hops.”

Since by definition a manifold is a structure that is locally Euclidean, meaning once more that at any area on the structure it is flat (again, think of the earth as an example), it stands that the `k`\-nearest neighbors in the original high-dimensional space should, ideally, also be the `k`\-nearest neighbors on the manifold. Hence, the first step in `Isomap` is determining which points are neighbors based on the familiar notion of distance, `d[i]` = `x[i]` − `x[j]`. What constitutes a “neighbor” can be determined by a flexible radius `ε` parameter. Not surprisingly, for points that are very close, Euclidean distances approximate geodesic distances quite well, however this is not the case for points that are increasingly further apart. Selection of a suitable neighborhood size is a crucial input to conducting `Isomap`.

Next, geodesic distances are estimated between all pairs of points `i`, `j`. The more dense the sampling of points, the better estimates one will obtain. *Dijkstra’s algorithm* ([Dijkstra, 1959](#ref.xhtml#re_CIT000089)) or competing algorithm can be used to estimate the shortest paths, which are approximated by the sum of local distances. Lastly, classical MDS is then computed on the geodesic distances. Essentially then, *Isomap performs a multidimensional scaling (eigen analysis) on the high-dimensional data, but instead of using Euclidean distances as classical MDS, it performs the MDS on geodesic distances*. Using geodesic distances carries the benefit of capturing nonlinear and complex dimensions that could otherwise not be “tapped” using Euclidean distances.
