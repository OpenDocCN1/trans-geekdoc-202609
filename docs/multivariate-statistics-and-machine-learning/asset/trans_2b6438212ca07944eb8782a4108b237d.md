
*图 6.2*  `OLS` 的同心 `RSS` 椭圆。岭估计是 `OLS` 估计的收缩版本，随着调参参数的函数而将系数向 0 移动（左）。对于一个恒定的同心椭圆，`β[1]` 和 `β[2]` 的岭估计如图中所示，其中两个系数 `β[1]` 和 `β[2]` 都已被收缩向，但未收缩到，0。也就是说，椭圆“接触”圆的地方（它是圆或“圆盘”，而不是其他形状，这是岭约束区域的结果）位于圆上不等于 0 的点上。相比之下，套索解（右）产生了一个具有尖锐边缘的菱形约束区域的形状，因此 `β[1]` 和 `β[2]` 的套索解更可能使某个系数等于 0。[返回正文。⏎](#c6.xhtml#re_f6.2)

[图 6.2](#c6.xhtml#f6.2) 中的同心椭圆代表每个椭圆的系数 `β[1]` 和 `β[2]` 的残差平方和的可能且恒定值。也就是说，无论 `RSS` 在给定特定椭圆上的位置如何，它都是 *相同* 的值。离估计系数更远的椭圆具有更大的 `RSS`。图中 `OLS` 估计（以及相应的 `RSS`）是在回归中对于 `β[1]` 和 `β[2]` 值组合产生的 `RSS`。注意相应的岭估计在哪里；它位于 `β[1]` 和 `β[2]` 值都已“收缩”且因此小于 `OLS` 估计（位于中心椭圆）的位置，尽管通常不会完全驱动到 0，因为从几何上讲岭具有 *圆形约束*。也就是说，圆形约束区域有效地是岭系数的搜索空间。该搜索最有可能在 [图 6.2](#c6.xhtml#f6.2) （左）所示的圆形区域的边缘终止。另一方面，套索具有 *菱形* 搜索空间而不是（作为 L1 惩罚的结果）具有尖锐边缘，这说明系数不仅会被驱动得更小，而且可能被“收缩”到 0。也就是说，搜索空间这次在菱形内部，这意味着 `RSS` 将与菱形的硬边缘相交，而不是像岭中那样与圆形区域的光滑部分相交。因此，套索系数“落在”0 上，例如 `β[1]`，作为首先接触套索约束区域的点，即套索搜索空间。有关以这种方式解释岭（和套索）回归的更深入讨论，请参阅 James et al. ([2013](#ref.xhtml#re_CIT000168))，以更深入地解释岭与套索回归的几何形状。

我们现在对解进行交叉验证。Python 中的 `RepeatedKFold` 交叉验证器在每次重复中以不同的随机化执行 `k` 折 `n` 次。我们将请求十次拆分（即“折”）并重复三次：

```
import numpy as np
from sklearn.model_selection import RepeatedKFold
cv = RepeatedKFold(n_splits=10, n_repeats=3, random_state=1)
grid = dict()
grid[‘alpha’] = np.arange(0, 1, 0.01)
```

上面从 0 到 1 以 0.01 为增量的值是正则化参数 `alpha` 的值。我们现在将运行一个 *网格搜索*，扫描参数值，找到使平均绝对误差最小的一个：273

```
search = GridSearchCV(clf, grid, scoring=‘neg_mean_absolute_error’, cv=cv, n_jobs=-1)
results = search.fit(X, y)
print(‘MAE: %.3f’ % results.best_score_)
MAE: -0.620
print(‘Config: %s’ % results.best_params_)
Config: {‘alpha’: 0.13}
```

上面，我们看到 *负平均绝对误差*（即 `MAE`）等于 −0.620，基于最优参数，等于 `alpha` 为 0.13。

Python 还提供 *贝叶斯岭回归*，其中正则化参数会系统地更新。要实现贝叶斯岭回归，请参阅 Python 中的 `BayesianRidge()` 函数。此外，对于本文介绍的示例，因为我们从标准正态分布抽取了随机数据（即抽取的数据处于相同的 *尺度*），我们没有将结果数据 *标准化* 以使其均值等于 0 且标准差等于 1。然而，这并不意味着标准化在这里不值得做。这在变量自然出现在 *不同尺度* 的情况下尤其如此，在这种情况下，人们不希望一个变量的“重要性”仅仅因为其测量的尺度而超过另一个变量。另一方面，这种以 *进行测量的原始尺度* 为依据的“贝叶斯先验”可能正是根据研究设置和背景所期望的，在这种情况下，是否标准化的决定会更困难（[Izenman, 2008](#ref.xhtml#re_CIT000167)）。无论如何，在进行大多数正则化方法时，同时比较有无标准化的结果都是一个好主意。如果必须在两者之间选择一个选项，在大多数情况下标准化可能是一个好主意（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)，第 63 页），但在没有充分谨慎考虑的情况下不应这样做。
