
人们常问的一个问题是神经网络是有参数的还是非参数的。事实上，它们兼具两者特性。一方面，用户确定网络中节点的数量是一种类似参数化的做法。然而，其他人认为选择要包含的隐藏神经元数量本质上使神经网络成为非参数的，尤其是在样本量增加时。关于神经网络是有参数还是非参数的争论仍在继续，且短期内不太可能解决。这主要是由于神经网络可能性非常广泛，更具体地说，是如何操作化特定给定的神经网络实现。560

我们回顾一下，参数化的传统统计定义认为，对样本数据所抽取的总体做出了假设。有人说，由于神经网络通常不需要关于分布、均值、方差，甚至误差相关性的参数假设（[King, 1999](#ref.xhtml#re_CIT000186)），我们可以得出结论，神经网络本质上且主要是非参数模型。然而，这种表述的问题在于，用户能够自由地施加条件，这些条件在某种程度上确实意味着分布假设，以及通过正则化技术（如权重共享）来实现，这些技术与“parametric-like”操作非常相似。因此，在最终分析中，神经网络可以是非参数的，也可以具有参数特征，这取决于用户如何设置网络以及用户对网络所应用的总体所做的任何假设。

最终，在非参数到参数的光谱上，神经网络可能介于两者之间，具体位置取决于所考虑的给定神经网络。

### 15.13.4 增加更多层会导致训练数据上的近似度提高

一般来说，给神经网络添加更多层会提高对底层函数的近似精度，至少在训练数据上如此。然而，这可能导致在测试数据上的泛化能力较差，从而出现过拟合。即使是简单的神经网络在近似函数方面也表现良好。例如，Hornik 等人（[1989](#ref.xhtml#re_CIT000158)）发现，使用任意压缩函数的神经网络只要提供足够的隐藏单元就可以近似几乎任何函数。这里的要点是，即使可以通过添加连续层来达到准确性，真正的考验，如同以往一样，在测试数据上，而非训练数据上。再举个类比，没人太在意你在音乐会前练习了多少钢琴。他们根据你的实际表现来评价你。

## 15.14 Python 中的神经网络

我们可以相当容易地使用 `sklearn` 在 Python 中构建一个简单的神经网络，用于数据 `X = [[0., 0.], [1., 1.]]` 和响应 `y = [0, 1]`，具有两层，其中第一层有五个神经元，第二层有两个：

```
from sklearn.neural_network import MLPClassifier
X = [[0., 0.], [1., 1.]]
y = [0, 1]
clf = MLPClassifier(solver=‘lbfgs’, alpha=1e-5,
... hidden_layer_sizes=(5, 2), random_state=1)
>>> clf.fit(X, y)
Out[222]:
MLPClassifier(alpha=1e-05, hidden_layer_sizes=(5, 2), random_state=1,
   solver=‘lbfgs’)
```

神经网络现在已拟合用于对 `y` 的值进行分类。

```
clf.predict([[2., 2.], [-1., -2]])
Out[223]: array([1, 0])
```

我们看到新观测值分别被分类为组 1 和 0。`alpha` 参数用作正则化项，有助于避免过拟合（尝试调整它并重新运行模型）。561

有关上述示例的更多详细信息，请参阅 `scikit-learn.org` 以及 [Müller and Guido (2017)](#ref.xhtml#re_CIT000258)，以获取使用 `MLPClassifier` 的更多示例以及绘制决策边界。我们鼓励读者也在上述示例中修改层大小（`hidden_layer_sizes=(5, 2)`），以观察其对后续类别预测的相应影响。
