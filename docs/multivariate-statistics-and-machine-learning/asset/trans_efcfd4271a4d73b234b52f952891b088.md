
在原假设下，总体协方差矩阵相等。对于这些数据，我们拒绝原假设（`p` = 2.2e-16）并推断备择假设，即至少有两个协方差矩阵不同。当协方差矩阵不同时，研究者有必要查看这些矩阵并考虑它们可能不同的实质性原因。*切勿在不仔细考虑该统计结果在科学上（而不仅仅是统计上）可能对数据意味着什么的情况下得出统计结果*。有关该检验的更多理论，请参阅 [约翰逊和威彻恩 (2007)](#ref.xhtml#re_CIT000173)。

## 4.7 线性判别分析（作为 MANOVA 的“逆”）

线性判别分析模型（我们在 `MANOVA` 示例中刚刚简要看到的）具有二元或多分类的分类响应变量，其中寻求预测变量的线性组合以最大化响应上的组间差异。判别分析有时在数据挖掘文献中被称为 *过滤模型* 和 *特征选择方法*（[阿格瓦尔, 2015](#ref.xhtml#re_CIT000005)）。乍一看，这可能对读者来说难以把握或“看到”整体情况，但 `LDA` 模型实际上可以被视为一个“枢纽”模型，即许多其他模型可以被视为 `LDA` 模型结构的 *扩展* 或 *缩小* 版本的模型。

首先，它可以以几种不同的方式实现，包括成为 `MANOVA` 模型的“相反”。这是我们在这里最感兴趣的解释，以补充我们对 `MANOVA` 的讨论，并理解 R 中由 `MANOVA` 后续分析或粗略地“*事后*”分析提供的上述输出（尽管它严格来说不是 *事后* *检验*，因为我们没有试图控制任何误差率，我们在这里使用“*事后*”一词纯粹是 *描述性地*）。`MANOVA` 和 `LDA` 通常被视为彼此的 *对立面*，并且多次，判别分析会作为 `MANOVA` 的后续分析进行，以帮助了解负责如此有效地分离组的底层函数（称为 *判别函数*）。
