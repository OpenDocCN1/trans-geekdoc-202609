### 8.6.2 Poisson Regression in Python
In Python, we can use `sklearn` to fit a Poisson model. We create some easy data on `x` and `y`, and fit a basic Poisson model in what follows:
```
from sklearn import linear_model
clf = linear_model.PoissonRegressor()
X = [[1, 2], [2, 3], [3, 4], [4, 3]]
y = [12, 17, 22, 21]
```
Note from the above that there are two columns of `X` and a single column of `y`. We now proceed with the fit:
```
clf.fit(X, y)
Out[110]: PoissonRegressor()
```
The estimated regression coefficients for the model are the following:
```
clf.coef_
Out[112]: array([0.12109212, 0.15836976])
```
The intercept of the model is given by:
```
clf.intercept_
Out[113]: 2.0885914156053205
```
We now obtain some predicted values for `y` based on `X`:
```
clf.predict([[1, 1], [3, 4]])
Out[114]: array([10.67658784, 21.87505182])
```
Poisson regression can also be performed using `statsmodels()` by specifying a Poisson link.

## 8.7 Generalized Additive Models: A Flexible Nonparametric Alternative
The generalized linear model, with special cases such as logistic and Poisson regression, features "linear-like" or other `parametric` forms. That is, we approach the data with an `a priori` parametric idea or form in mind to fit to the data that particular form or preconceived structure. As emphasized throughout this book, however, there are many times where we do not want to approach the data with a `prior hypothesized structure` in mind. Instead, we would like to "discover" structure or form in the data without preconceived hypothesized ideas about that structure.
We have seen that the general linear model is a special case of the generalized linear model. However, the generalized linear model can be conceived as a special case of an even more general and wider model, that of the `generalized additive model` ([Hastie and Tibshirani, 1986](#ref.xhtml#re_CIT000144)), or "GAM" for short, where in this formulation, a precise functional form is not specified `a priori`. In GAM, 322we no longer assume linear forms such as `sum_{j = 1}^{J} beta_j x_j`, even after transformation, but instead generalize this notion to `sum_{j = 1}^{J} s_j(x_j)`, where instead of linear regression weights `beta[j]`, `s[j]` are unspecified functions that are estimated using a nonparametric `scatterplot smoother` (or some other nonparametric form, such as a kernel estimate or spline) and an iterative procedure known as the `local scoring algorithm` ([Hastie & Tibshirani, 1986](#ref.xhtml#re_CIT000144)) or `iterative weighted least-squares` ([Fox, 2016](#ref.xhtml#re_CIT000106), p. 575). The reader may recall from our earlier discussion in the book that smoothers are useful in providing a close fit to the data without generally making parametric assumptions `a priori`.
