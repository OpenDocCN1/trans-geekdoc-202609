
We have already discussed informally the nature of a basis. We now put the concept on a formal footing. `A basis is a set of linearly independent vectors in a vector space that spans the space`. Conceptually, a basis essentially provides a “frame of reference” for vectors in a subspace. The dimension of a basis is the number of linearly independent vectors in the given set making up the basis. More formally, a basis is a `maximum linearly independent set` such that if we added one more vector, the set would cease to be linearly independent. That is, if there exists a basis with `n` vectors in a vector space, then there cannot be a basis with more than `n` vectors in that vector space (since by definition, a basis is the `maximum` linearly independent set). This last result is a consequence of the `Steinitz exchange lemma` ([Stillwell, 2016](#ref.xhtml#re_CIT000349)). Equivalently, a basis is a minimal spanning set such that if we dropped a vector, it would no longer span the given subspace ([Hubbard & Hubbard, 2002](#ref.xhtml#re_CIT000161)).150

### 2.54.1 Orthogonal Basis
Recall that the canonical basis vectors of the coordinate system generate an `orthogonal basis`, and that since each of the vector’s lengths is equal to 1, it is simultaneously an `orthonormal basis`. In many procedures, the goal is to generate an orthogonal basis from one that may not already be orthogonal. This is a very powerful idea that actually accounts for how many statistical methods operate “under the hood” so to speak.

The `Gram-Schmidt process` is an algorithm used in linear algebra for finding an orthogonal basis. The details of the procedure are not enlightening from an applied point of view. For mathematical details on the approach, see virtually any good introductory linear algebra text (e.g., [Anton & Rorres, 2000](#ref.xhtml#re_CIT000013)). The Gram-Schmidt process implies that `if you have a finite inner product space, an orthonormal basis can be constructed in that space` ([Garcia & Horn, 2017](#ref.xhtml#re_CIT000122)). Such a result will serve us well when we survey methods such as principal components analysis, where, as already mentioned, the goal will be to establish a new set of basis vectors with special properties and from which to project the observed data. Principal components analysis is essentially a (linear) transformation of the data onto a new basis. That is, it generates new coordinates from which to visualize and interpret the original data.

The very concept or general idea of a basis can also be made much simpler. Moving away from matrices and eigenvectors, and as a helpful imperfect analogy, consider the “basis” on which numbers are computed. For example, expressing the number 0.5 is relative to one basis (i.e., “frame of reference”), while expressing it as ½ is relative to another ([Hubbard & Hubbard, 2002](#ref.xhtml#re_CIT000161)).

## 2.57 Functions, Approximation, and Continuity
Much of statistics and machine learning can be regarded as an exercise in `approximating functions` or other mathematical objects. But what is an approximation? An approximation can be extremely simple; for instance, `π` = 22/7 is an approximation to `π` just as differentiating and integrating in calculus, as we will see, are implementations of an approximation process. When speaking of approximations, however, we are only getting started. It doesn’t take long to realize that virtually everything, or at least most things in statistics and machine learning feature approximations of some kind.

For example, when we compute an arithmetic mean on some data, such can be regarded as an approximation to the central tendency, in some sense, of the distribution. When we use that mean as an estimator of the population mean, we are again approximating, in this case, some parameter. The least-squares line or any other function fit to data is an approximation of the true underlying functional form. In real analysis, limits and convergence are once more examples of where approximation surfaces. For example, $\\lim\\limits\_{x\\rightarrow 5}f\\left( x \\right) = x + 3$ denotes a limit of 8, but that number only occurs `in the limit`. What the expression $\\lim\\limits\_{x\\rightarrow 5}f\\left( x \\right)$ is actually communicating is the idea of an `approximation`, that `as x approaches 5, the value of the function goes to 8`. `We are converging on the value of 8 based on this limiting process.`

Calculus is all about finding tangents to curves, the slope of which are called `derivatives`, and `integrals`, which are areas under curves found by integration. Recall that a function, `f`(`x`) is the set obtained by inputting `x` into the rule or argument. For a rule to be a function, for every value of `x` there must be only one value for `f`(`x`), or `y`. The domain of a function is all inputs that are possible for the given function, while the `codomain` of the function consists of all theoretically produceable outputs (i.e., not only those potentially observed). For example, for the simple linear function `f`(`x`) = `x`, the domain and codomain can be defined as the set of real numbers, denoted `ℝ`.

Examples of functions from the physical sciences include such classic functions as Newton’s law, `F` = `m` `a`, where `a` is the acceleration of a mass `m` subjected to a net external force `F`, and of course Einstein’s theory of relativity, `E` = `m` `c`², where under a constant speed of light `c`², energy `E` is proportional to the mass `m` of the object.
