
Bounded activation functions (e.g., 0 to 1 or −1 to 1) are also often referred to as `squashing functions` ([Sarle, 1994](#ref.xhtml#re_CIT000322)). For instance, as we will see, the `sigmoid` function has this property of “squashing” values into a bounded interval ([Lederer, 2021](#ref.xhtml#re_CIT000213)). Again, this is not meant to imply any physical action, but only to communicate that the activation function has the effect of outputting values within a bounded interval. Activation functions need also not be consistent across each output and different activation functions can be used for each.

### 15.5.2 Types of Activation Functions

As we have seen, we are unlikely to simply use `identity` functions and will prefer to use more complex functions, most of which will be `nonlinear` in order to capture complex nonlinear aspects of the data or processes we are seeking to model. The most popular activation functions in use in neural networks are, generally, the `logistic`, `tanh`, and `ReLu` ([Lederer, 2021](#ref.xhtml#re_CIT000213)), however novel functions have recently been proposed, including `softplus`, `elu`, `selu`, and `swish`. We survey some of these activation functions shortly. [Lederer (2021)](#ref.xhtml#re_CIT000213) provides an exceptional review of these functions and many more. According to [Lederer (2021)](#ref.xhtml#re_CIT000213), `softsign` and `ReLu` should be the preferred activation functions in practice. The `softsign` function has been found to have computational advantages over `tanh` due to its simplicity ([Lederer, 2021](#ref.xhtml#re_CIT000213)).

There are some important things to consider in choosing an activation function, however. Indeed, the choice of an activation function can have rather dramatic effects on the performance of a neural network, and hence how to choose a “good” activation function has been ongoing research in the neural network community for years with entire literatures devoted to the subject. As noted by [Lederer (2021)](#ref.xhtml#re_CIT000213), “the literature contains an entire zoo of different activation functions, and arguments for and against specific activation functions are often based on heuristics and anecdotal 542evidence” (p. 2). Also, predicting which activation function will work best for a given situation can be very difficult to impossible ([Goodfellow, 2016](#ref.xhtml#re_CIT000131)).

### 15.5.3 Saturating vs. Non-Saturating Activation Functions

Ideally, activation functions should be `differentiable` at most points and generally also increasing. Beyond that, we have the choice to select from a wide range of activation functions, some more preferable than others depending on the context. One very important distinguishing feature of activation functions is whether they are `saturating` or `non-saturating`. Non-saturating activation functions are generally preferred over saturating ones. The requirements for activation functions are not absolute, however, which is to say these requirements are flexible to some extent and not always preferable in all contexts.

A `saturating` activation function implies that for large inputs, the function asymptotes at a constant value, such as 0 or 1. This is a characteristic of the `logistic sigmoid` activation function (Dubey et al., [2022](#ref.xhtml#re_CIT000092); [Murphy, 2022](#ref.xhtml#re_CIT000259)),

$$Logistic\\,\\, Sigmoid\\left( x \\right) = \\frac{1}{1 + e^{- x}}$$

(15.4)

which saturates (or “asymptotes”) at values of 0 and 1 (Dubey et al., [2022](#ref.xhtml#re_CIT000092)). That is,

$$\\lim\\limits\_{x\\rightarrow - \\infty}\\left( \\frac{1}{1 + e^{- x}} \\right) = 0$$

and

$$\\lim\\limits\_{x\\rightarrow + \\infty}\\left( \\frac{1}{1 + e^{- x}} \\right) = 1$$

These functions essentially “squeeze” or “squash” the input to be within upper and lower bounds. Unfortunately, as we will soon discuss, saturating activation functions will generate a `vanishing gradient problem`, where the gradient of the objective function becomes very close to 0, and hence updating weights becomes virtually impossible. The `tanh` function,

$$\\tanh\\left( x \\right) = \\frac{e^{x} - e^{- x}}{e^{x} + e^{- x}}$$

(15.5)

also quite popular, also squashes the inputs, but this time between −1 and 1 (Dubey et al., [2022](#ref.xhtml#re_CIT000092)).

Hence, one of the keys to training very deep neural networks is to select activation functions that are `non-saturating` ([Murphy, 2022](#ref.xhtml#re_CIT000259)). A non-saturating activation function is one that does not asymptote at a constant value and hence typically goes to infinity. That is,

$$\\lim\\limits\_{x\\rightarrow\\infty}f\\left( x \\right) = \\infty$$

The `rectified linear unit` (or “ReLU” for short) is one such non-saturating activation function,543

$${Re}LU\\left( x \\right) = \\max\\left( 0,x \\right) = \\left\\{ \\begin{array}{l} {x,\\,\\,\\,\\,\\, if\\,\\,\\,\\,\\, x \\geq 0} \\\\ {0,\\,\\,\\,\\,\\, otherwise} \\\\ \\end{array} \\right.$$

(15.6)

It is non-saturating because the range of the function is from 0 to positive infinity, that is, \[0,∞) as we can see from [Figure 15.5](#c15.xhtml#f15.5) featuring a few competing activation functions.

![Figure 15.5 Some activation functions commonly used in neural networks. The tanh and sigmoid functions are saturating while the ReLu is a non-saturating activation function.Return to text.⏎](images/fig15.5.jpg)

`Figure 15.5` Some activation functions commonly used in neural networks. The `tanh` and `sigmoid` functions are `saturating` while the `ReLu` is a `non-saturating` activation function.[Return to text.⏎](#c15.xhtml#re_f15.5)

We see from [Figure 15.5](#c15.xhtml#f15.5) that the `sigmoid function` is saturating, squeezing input values to be within \[0, 1\]. The `tanh` function is saturating for similar reasons, this time squeezing inputs to be within \[−1, 1\]. The `arctan`, another activation function, is also saturating. It is easy to see that the `ReLU` function is non-saturating, being constant at 0 for values equal to or less than 0 and increasing linearly for values greater than 0 and hence still allowing for updates to occur even for large values of `x` ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)). However, for negative inputs, the `vanishing gradient problem` still rears its ugly head (Dubey et al., [2022](#ref.xhtml#re_CIT000092)).

> `A saturating activation function essentially “squeezes” the input values to be within specified bounds (e.g., 0, 1). A non-saturating activation function does not “bind” the input in this way and instead allows the function to typically go to infinity. When it comes to choosing an activation function for a neural network, non-saturating ones are often preferred over saturating ones.`

Incidentally, all of these functions can be easily plotted in software. For instance, a `sigmoid` activation function in Python (plot not shown) can be generated quite simply as:


#### 15.5.3.1 The Problem with ReLU

The `ReLU` function, also commonly known as the `positive-part function` or `ramp function` due to its shape, is one of the most common activation functions used in neural networks. The positive part of the function is merely the `identity` function, linear with slope equal to 1. It is this `near linearity` of `ReLU` that in part, makes `ReLU` attractive in the sense that it can allow for easy optimization using gradient-based methods as is the case with most linear models ([Goodfellow et al., 2016](#ref.xhtml#re_CIT000131)). The negative part of the function is constant at a value of 0. A look at the `ReLU` function more closely reveals these characteristics ([Figure 15.6](#c15.xhtml#f15.6)).
