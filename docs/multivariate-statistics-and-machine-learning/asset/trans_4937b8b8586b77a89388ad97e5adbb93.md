# 8 广义线性与加性模型 Logistic 及相关模型

DOI: [10.4324/9781003376941-11](https://doi.org/10.4324/9781003376941-11)

到目前为止，在我们对建模的讨论中，我们一直假设响应变量或多或少是 *连续* 的，或至少是“伪连续”的，因为在理想的数学意义上，没有经验变量是真正连续的。连续性本身是一个 *抽象*，一个哲学概念，它在数学上使用诸如实分析中的ε-δ定义等事物来表达。更务实地说，我们假设响应表现出相当广泛的“密集”值范围，目标是基于一个或多个预测变量预测响应沿此连续体的值。虽然其中许多模型是线性的，但我们也调查了一些非线性模型。然而，在所有这些模型中，响应变量一直被假设为连续，并在我们的分析中作为连续变量处理。在建模中存在许多响应变量不是连续而是 *分类* 的实例。此类响应包含互斥的类别，而不是数值可能性的连续体。具有此属性的一些响应是自然发生的（例如，通过与失败），而其他响应可以由用户操作化为特定类别（例如，将测试上的数值分数分类为通过与失败的二元结果）。

统计模型如何处理二元或分类响应？得益于 *广义线性模型* 的理论（[McCullagh & Nelder, 1989](#ref.xhtml#re_CIT000243)），二元和多项响应可以置于我们能找到经典线性模型的同一总体框架中。广义线性模型包含这些模型的全家，并是本章的主题。

在调查广义线性模型之前，我们应该从一开始就问一个重要问题：*“分箱”响应是一个好主意吗*？这样做的优点和缺点是什么？我们从对将响应操作化为二元或多项结果的优点和缺点进行简要调查开始本章。

## 8.1 如何操作化响应

如前所述，一些响应变量本质上是分类的。例如，一条鲑鱼要么“向上游”要么“下游”，不能同时两者（尽管正如我们都看到的那样，它们有时似乎只是无方向地在水中徘徊）。当响应具有这种质量时，将变量“保持原样”并将其视为二元是一个简单的决定，因为保持 *原样* 使其保持在其自然 *测量* 状态。在其他情况下，研究人员可能会选择将变量分箱为互斥类别。在机器学习文献中，在将其“分箱”之前变量的伪连续性有时被称为 *预分类器*（Kroese et al., [2020](#ref.xhtml#re_CIT000202)），因为在将其值强制为类别之前它相对连续。309

### 8.1.1 分箱的利弊

是否分箱变量是一个重要决定。事实上，单个变量的不同操作化会导致由此产生的统计模型“发现”不同的效应。作为一个简单的例子，班级测试上的 *成绩* 操作化为 *通过* 与 *失败* 可能是最终成绩的预测因子，但操作化为数值分数可能会改变预测能力。变量是相同的，但我们对其的操作化现在不同了。更重要的是，在方差分析（ANOVA）中对变量的操作化方式选择会影响由此产生的均方，最终影响对零假设的拒绝。关于在 ANOVA 中操作化效应的影响存在大量文献（例如，参见 [Prentice & Miller, 1992](#ref.xhtml#re_CIT000292)）。

### 8.1.2 检测新类别

虽然我们讨论了分箱的利弊，但也值得提到在机器学习中，还有一些技术实际上允许算法根据算法对数据的检查来检测新类别或类别。这种在机器学习圈中被称为 *新颖性检测*，因此不是将案例分类为 `C[t]` 类中的一个，而是派生出新的类别标签 `C[t + 1]`，不是由研究人员的判断或如何分箱的决定，而是由实际算法发现新类别。这种过程有时被称为 *开放集识别* 的一般概念（[Murray, 2022](#ref.xhtml#re_CIT000259)）。在本書中，我们不调查检测新类别的方法。我们假设研究人员正在积极决定如何操作化其变量。

## 8.2 广义线性模型

广义线性模型（GLM）背后的动机是涵盖具有经典普通最小二乘（OLS）回归中连续响应的模型，但也纳入具有二元或分类响应的模型。GLM 是所有这些模型的“父”模型，本质上对二元或多项响应进行转换，使其成为线性和连续的。在开发 GLM 时，最好首先回忆我们在回归讨论中介绍的经典线性模型：
