
> *PCA 在大多数情况下会生成与变量数量一样多的成分。实际的“数据降维”是通过选择前几个成分来实现的，以尽可能解释变量中的大部分方差，或者等价地说，最小化重建误差。选择要保留或维持的成分数量在很大程度上取决于研究或科学背景，并且通常基于用户判断。*

### 11.2.5 成分上的约束

回顾一下，我们提到特征向量权重 `e[1]` 到 `e[p]` 被应用于观测变量以生成成分。在推导这些成分时，我们将对这些特征向量权重施加约束，使得 *它们的平方和等于1*。也就是说，我们将平方和的特征向量权重设为一，

$${\\sum\\limits\_{i = 1}^{n}e\_{i}^{2}} = 1$$

(11.5)

当我们在每个成分上施加此类条件时，该成分被称为 *已标准化*。并没有绝对要求和必须为1；从理论上讲，它可以是任何其他正的常数值。将其设为1意味着成分的长度等于1。但为什么要施加这样的约束呢？此约束的目的是，如果我们不对载荷施加至少 *某种* 约束，那么从理论上讲，我们就可以让成分的方差无界地增加。通过施加此约束，或方差的其他正常数，我们可以确保成分的方差不会仅仅是特征向量权重越来越大的反映。

正如我们在本书中看到的那样，上述这类约束在统计或机器学习方法中并不罕见。在更一般的数学建模中，某些量被固定或约束为特定值的情况很常见，以便在这些约束下可以更自由地估计其他可变量。最终，这类约束 *简化了问题*。

### 11.2.6 中心化观测变量

观测变量在进行成分分析之前也经常（尽管并非 *必然*）被中心化，使得每个变量的均值等于0。这里的 *中心化* 我们 simply 指减去每个观测原始变量的均值。例如，如果观测变量为 `x[i]`，均值为 $\\overline{x}$，则中心化变量意味着为每个观测生成 $x\_{i} - \\overline{x}$。读者会认识到这里的中心化是计算 `z-scores` 的前奏，其中中心化偏差随后除以标准差 `s`。作为中心化的一个简单示例，考虑 R 中原始均值等于 6.2 的以下数据向量：

```
> v <- c(0, 4, 8, 9, 10)
> mean(v)
[1] 6.2
```

要中心化此数据，我们只需从每个观测值中减去均值：

```
> v.center <- v - mean(v)
> v.center
[1] -6.2 -2.2 1.8 2.8 3.8
```

我们随后可以很容易地确认，在舍入误差范围内，中心化数据的均值等于0：

```
> mean(v.center)
[1] -1.775489e-16
```

### 11.2.7 成分的正交性

如前所述，成分分析的一个吸引人的特征是，派生的成分保证是正交的（即特征向量）并且彼此不相关。回顾正交性意味着什么，它意味着派生的成分处于 *直角*，或 *垂直* 于彼此（90度）。从实质观点来看，正交性确保每个成分解释变量中 *不同* 的方差比例，并且没有重叠。必须强调，正交性与 *统计独立性* 不同。*统计独立性在某种意义上是比正交性更强的属性，主成分只有在数据为多元正态时才同时正交且独立*。要在超出多元正态性假设的情况下使成分同时正交且独立，必须超越传统的 PCA，而改进行 *独立成分分析*，将在后面讨论。然而，假设所有成分均不为零，正交性将意味着 *线性独立*（与 *统计* 独立相对）。

> *经典主成分分析确保成分的正交性，但不能保证其统计独立性。统计独立性是此情况下更强的属性，保留给独立成分分析技术。*

### 11.2.8 每个成分解释的方差比例：协方差 vs. 相关矩阵

在按解释方差递减的顺序计算成分后，现在值得问一个自然问题：每个成分实际解释了多少方差？请记住，成分分析不会 *改变* 原始变量中的方差量。它只是沿着新的维度（称为 *成分*，它们实际上是变换的 *特征向量*）重构该方差。因此，*成分总体的总方差应等于原始变量的总方差*。也就是说，当我们将所有成分解释的方差相加时，该和应等于原始变量的总方差。在协方差矩阵中，该方差之和将等于所有观测变量的方差之和。在 *相关矩阵* 中，该和将等于 *变量* 的总数，因为在相关矩阵中，每个变量贡献的方差等于1。分析协方差或相关矩阵可能会导致截然不同的结果。主成分分析对所分析矩阵的类型不是不变的。这一事实乍一看似乎违背直觉，因为人们可能假设或期望协方差和相关矩阵会产生相似的结果，或者至少一个结果是另一个的平凡变换。然而事实并非如此。在相关矩阵上执行的 PCA 通常会产生与在协方差矩阵上执行的 PCA 不同的 *特征值* 和特征向量。

鉴于此区别，问题就变成：分析哪个矩阵？一些人认为协方差矩阵更符合 PCA 的精神（例如参见 [Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)），其他人则建议 PCA 几乎总是应在 *标准化* 协方差矩阵上执行，当然也称为 *相关矩阵*（[Bilodeau & Brenner, 1999](#ref.xhtml#re_CIT000030); Murray, 2022）。当然，同时尝试两种解决方案并进行比较并无害处。然而，重要的是要认识到，在一个矩阵上与另一个矩阵上执行 PCA 通常不会产生相同的结果。主成分分析还要求变量对之间至少存在 *某种* 协方差（或相关性）。如果没有这种协方差，即所有协方差或相关性都等于0，只有主对角线上的方差保留，则 PCA 将用处不大。最多，PCA 只会生成成分，这些成分是原始变量的反映，但按方差递减的顺序排列（[Chatfield & Collins, 1980](#ref.xhtml#re_CIT000057)）。现在，我们假设我们正在使用协方差矩阵。鉴于特征值是每个成分的方差，则应满足以下关系：

∑`s²` = ∑`λ[i]`

(11.6)

也就是说，原始变量的方差之和应等于成分分析的特征值之和。我们可以很容易地在经验数据上证明这一点。考虑 `x`、`y` 的一些数据：

```
> x <- c(2.5, 0.5, 2.2, 1.9, 3.1, 2.3, 2.0, 1.0, 1.5, 1.1)
> y <- c(2.4, 0.7, 2.9, 2.2, 3.0, 2.7, 1.6, 1.1, 1.6, 0.9)
```
