## 11.11 Self-Organizing Maps

Multidimensional scaling can be slow because it must incorporate all distances between variables into its final computation ([Venables & Ripley, 2002](#ref.xhtml#re_CIT000376)). An alternative to MDS, for large-scale problems especially, is the *self-organizing map* ([Kohonen, 1990](#ref.xhtml#re_CIT000197), [1995](#ref.xhtml#re_CIT000198)), which instead of using the entire matrix of distances, focuses on a rectangular or hexagonal two-dimensional lattice of 440representative points. SOM can also be considered from the vantage point of cluster analysis, it being a special “constrained” case of `k`-means clustering where data are “encouraged” to lie in a one or two-manifold feature space ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)). While most of the work on SOMs occurred in the 1990s and beyond, the initial principle for SOM first appeared in the early 1980s ([Kohonen, 1990](#ref.xhtml#re_CIT000197)).

There are several versions of algorithms for SOM. A simple version of the SOM algorithm operates similar to `k`-means clustering, in that given an observation from the data, `x[i]`, the closest data point `m[j]` is selected. Then, a neighbor of `m[j]`, called the neighbor `m[k]`, is moved toward `x[i]` via the following update rule ([Hastie et al., 2009](#ref.xhtml#re_CIT000145), p. 528; [Kohonen, 1990](#ref.xhtml#re_CIT000197), p. 1467),

`m[k]←m[k]+α(x[i]−m[k])`

(11.18)

where `α` is the learning rate and where 0 < `α` < 1. The updating is run for each input vector and the process should be run at least 500 times the number of nodes ([Izenman, 2008](#ref.xhtml#re_CIT000167)). The updating function can be more complex than a simple weight ([Kohonen, 1990](#ref.xhtml#re_CIT000197)). For example, instead of simply a weight `α`, one can specify a *function* of the weight,

`m[k]←m[k]+αh[k](x[i]−m[k])`

(11.19)

where `h[k]` now can be a function such as a kernel (e.g., a Gaussian kernel).

The algorithm is detailed in Yin ([2008](#ref.xhtml#re_CIT000398), p. 725). Self-organizing maps can also be generally considered in the family of neural network algorithms ([Oliveira & Levkowitz, 2003](#ref.xhtml#re_CIT000275)) and can be integrated with other visualization techniques. The very idea of naming the method *self-organizing* arose from biology and sets of neurons essentially competing with one another, which is why often self-organizing maps are discussed under the machine learning topic of *competitive learning*. We quote Kohonen ([1990](#ref.xhtml#re_CIT000197), p. 1464):

> It \[self-organizing map\] is a sheet-like artificial neural network, the cells of which become specifically tuned to various input signal patterns or classes of patterns through an unsupervised learning process.
