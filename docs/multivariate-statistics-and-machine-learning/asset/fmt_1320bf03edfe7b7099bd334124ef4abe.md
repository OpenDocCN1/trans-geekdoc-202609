
For lack of a better terminology, and to differentiate among repeated-measures approaches, we will refer to the repeated measures that typically assumes a *sphericity structure* for the covariance matrix to be that of *classic repeated measures*. The assumption of sphericity is essentially that of equal variances among differences between all possible pairs of within-subject conditions. An even more stringent assumption is that of *compound symmetry* that assumes all variances and covariances in the matrix of within-subject variables are equal. Both of these assumptions give rise to what we are calling the “classic” repeated-measures model to distinguish it from more sophisticated models such as random-effects, mixed-effects, and structural equation longitudinal models and growth curves. *Latent growth models* are a sub-type of the more general *structural equation model* in which the latent variables are typically such things as intercepts and slopes that “give rise” to time points.

Just as we did for classic ANOVA, we assume the reader has had at least some exposure to basic repeated measures under the assumption of a spherical covariance matrix. Hence, we move quickly and simply provide the expected mean squares for the classic model. There is a lot of theory and explanation that goes along with these expected mean squares and for readers unfamiliar, [Hays (1994)](#ref.xhtml#re_CIT000149) and [Denis (2021a)](#ref.xhtml#re_CIT000087) are good sources that explain how these expected mean squares arise, including how `MS residual` is a function of the intraclass coefficient `ρ` below.

The expected mean squares for the classic additive “sphericity” repeated-measures model are thus:210

*E*(MS subjects) = *σ*[*e*]² + *K**σ*[*s**u**b**j**e**c**t**s*]²  

(4.17)

$$E\\left( \\text{MS}\\,\\text{treatment} \\right) = \\sigma\_{e}^{2} + \\frac{J{\\sum\\limits\_{j}\\alpha\_{j}^{2}}}{K - 1}$$  

(4.18)

*E*(MS residual) = *σ*[*e*]² = *σ*[*T*]²(1−*ρ*)  

(4.19)

where `J` is the number of rows for subjects, `K` is the number of columns for treatment, `ρ` is the intraclass coefficient, and `σ[T]²` and `σ[e]²` are the total and error variances, respectively.

There are numerous ways of fitting repeated-measures models in R. The function `aov()` in R has easy capabilities for fitting such models (see [Denis, 2021a](#ref.xhtml#re_CIT000087) for details). Many packages are also devoted to fitting repeated-measures or longitudinal models, for example the `mmrm` package ([Sabanes et al., 2024](#ref.xhtml#re_CIT000318)). Repeated-measures models can also be fit in a variety of ways in Python. Probably the easiest way is via `statsmodels` using `AnovaRM`. The following is sample code (output not shown) for a basic one-way repeated measures where the dependent variable is y, the subject variable is person, and the repeated measure is time:

```
from statsmodels.stats.anova import AnovaRM
print(AnovaRM(data=df, depvar=‘y’, subject=‘person’, within=[‘time’]).fit())
```

## 4.6 Multivariate Analysis of Variance (MANOVA)

Univariate ANOVA allows for more than a single independent variable or factor but only allows for a single response or dependent variable. The name *univariate* derives from this fact, that of a single response. When there exists more than a single response variable, we enter into *multivariate* territory. Multivariate analysis of variance, or “MANOVA” for short, is defined by having more than a single continuous response variable.

The multivariate hypothesis about mean vectors can be stated as follows,

$$H\_{0}:\\left( \\begin{array}{l} \\mu\_{11} \\\\ \\mu\_{21} \\\\ \\mu\_{31} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ \\mu\_{j1} \\\\ \\end{array} \\right) = \\left( \\begin{array}{l} \\mu\_{12} \\\\ \\mu\_{22} \\\\ \\mu\_{32} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ \\mu\_{j2} \\\\ \\end{array} \\right) = \\left( \\begin{array}{l} \\mu\_{13} \\\\ \\mu\_{23} \\\\ \\mu\_{33} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ \\mu\_{j3} \\\\ \\end{array} \\right)... = \\left( \\begin{array}{l} \\mu\_{1p} \\\\ \\mu\_{2p} \\\\ \\mu\_{3p} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ {\\,\\, \\cdot} \\\\ \\mu\_{jp} \\\\ \\end{array} \\right)$$  

(4.20)

### 4.6.1 Suitability of MANOVA

When is it appropriate to perform a MANOVA over an ANOVA? The answer cannot simply be “when there is more than a single continuous response,” despite misleading cookbook approaches to data analysis sometimes advising on such a poor strategy. Indeed, analyzing sex differences on response variables IQ and amount of gasoline consumed in one’s vehicle in the past week would make little sense for the reason that the response “variate,” that is, the combination of variables on the response side, makes little if any substantive “sense.” Can it be analyzed? Yes, but on an applied level, is not a hypothesis we would likely be interested in. The key to MANOVA is not to analyze multiple responses simultaneously; it is to analyze multiple responses that in some sense “go together” to produce a *variate*. Simultaneous analysis of reading speed and grade point average would be a variate of more interest in an applied setting. Or, another example might be skull measurements as a function of prehistoric epoch ([Anderson, 2003](#ref.xhtml#re_CIT000011)). The takeaway point is that when one combines multiple responses into a single model, one should have a *reason* for doing so over and above simply producing a multivariate model.

With that substantive rationale and caveat in place, there are *statistical* benefits to conducting a MANOVA over multiple ANOVAs, which include control over an inflating type I error rate. For instance, three different univariate ANOVAs conducted separately carries an increasingly large type I error rate (e.g., 0.05 per test, `p` = 0.05). The probability of making *no type I errors* (`r` = 0) across `n` = 3 tests each set at 0.05 is a binomial random variable,

$$\\begin{array}{l} {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, p\\left( r \\right) = \\left( \\begin{array}{l} n \\\\ r \\\\ \\end{array} \\right)p^{r}\\left( 1 - p \\right){n - r}} \\\\ {p\\left( 0,3,0.05 \\right) = \\left( \\begin{array}{l} 3 \\\\ 0 \\\\ \\end{array} \\right)\\left( 0.05 \\right)0\\left( 0.95 \\right)3 = 0.86} \\\\ \\end{array}$$  

(4.22)

and hence the probability of at least one type I error is equal to 1 − 0.86 = 0.14. More formally, the probability of *at least one type I error* across `k`-tests can be approximated by

`p(type I error ≥1)` = 1 − (1−`α[PC]`) ^ (`k`)  

(4.23)
