
But what function shall the neural network optimize when doing the learning? While a number of functions can be minimized, one convenient and familiar function for continuous responses is that of minimizing error sums of squares with respect to the network’s connection weights,

$$E^{2} = {\\sum\\limits\_{i = 1}^{N}\\left( y\_{i} - {\\hat{y}}\_{i} \\right)^{2}}$$  

(15.11)

The extent to which `E²` is minimized can also be used as a performance metric for the neural network. The backpropagation algorithm itself is an *iterative gradient-based algorithm*, using randomly chosen initial values for the weights and employing primarily the chain rule from calculus in conducting its optimization. Essentially, backpropagation features repeated application of the chain rule to compute and update weights in the network by differentiating relative to an error function (e.g., error sums of squares),

$$\\frac{\\partial E}{\\partial w\_{ij}} = \\frac{\\partial E}{\\partial s\_{i}}\\frac{\\partial s\_{i}}{\\partial net\_{i}}\\frac{\\partial net\_{i}}{\\partial w\_{ij}}$$  

(15.12)

where `E` is the error function, `w[i j]` are the weights from neurons `j` to `i,` that is, the elements we wish to *optimize*, `s[i]` is the output, and `net[i]` is the weighted sum of the inputs for a given neuron `i` ([Riedmiller & Braun, 1993](#ref.xhtml#re_CIT000299), p. 586). The gradient $\\frac{\\partial E}{\\partial w\_{ij}}$ is then updated via

$$w\_{ij}\\left( t + 1 \\right) = w\_{ij}\\left( t \\right) - \\varepsilon\\frac{\\partial E}{\\partial w\_{ij}}\\left( t \\right)$$  

(15.13)

where `t` is the iteration and `ε` is the learning rate. That is, `w[i j](t+1)` denotes the weight `w[i j]` at iteration `t` + 1, where `w[i j](t)` is the current weight at iteration `t`, from which we subtract550

$$\\varepsilon\\frac{\\partial E}{\\partial w\_{ij}}\\left( t \\right)$$  

which denotes the learning rate `ε` multiplied by the gradient $\\frac{\\partial E}{\\partial w\_{ij}}$ at time (iteration) `t`. We see there are two steps, one is computing the gradient, the other is updating the weights `w[i j]` at (`t`+1). If the learning rate is set too small, it may take a longer time to train the neural network than if the learning rate is set at a larger value; if set too large, such may result in less than optimal solutions. [Aggarwal (2015)](#ref.xhtml#re_CIT000005) suggests beginning with a relatively large weight then gradually reducing the weight as more optimal values are settled upon.

Another option is to use a *momentum* adaptation,

$$\\Delta w\_{ij}\\left( t \\right) = - \\varepsilon\\frac{\\partial E}{\\partial w\_{ij}}\\left( t \\right) + \\mu\\Delta w\_{ij}\\left( t - 1 \\right)$$  

(15.14)

where `μ` is a momentum parameter ([Riedmiller & Braun, 1993](#ref.xhtml#re_CIT000299), p. 586) which serves as a direct scaling factor for the previous step (i.e., `w[i j](t-1)`). The effort to adapt weights took a big step with the work of Riedmiller and Braun ([1993](#ref.xhtml#re_CIT000299)) who proposed *resilient propagation*, commonly known today as simply *resilient backpropagation*, which provides an improved adaptation process. Details of the algorithm are given in [Riedmiller and Braun (1993)](#ref.xhtml#re_CIT000299) and [Riedmiller (1994)](#ref.xhtml#re_CIT000300). Resilient backpropagation is what is used in the `R` package `neuralnet` that we will feature later in the chapter as a demonstration of neural networks using software. For much deeper details on how optimization works in the multilayer network, see [Izenman (2008)](#ref.xhtml#re_CIT000167) or Warner and Misra ([1996](#ref.xhtml#re_CIT000381), pp. 288–289), who provide an excellent account and overview.

As noted, backpropagation helped neural networks “rise to fame” in the 1980s. The development of the backpropagation algorithm is primarily responsible for the relatively recent resurgence of interest in neural networks ([Warner & Misra, 1996](#ref.xhtml#re_CIT000381)). The training of neural networks is a major challenge that requires both ingenuity and much experimentation. The algorithms for training neural networks with great depth are collectively referred to as *deep learning methods*.

Despite its success, there is no proof that the backpropagation algorithm always converges. Further, it can be a slow learner, its estimates may be unstable, and there may exist many local minima as the function being optimized is a nonconvex function of the model parameters ([Bishop, 2006](#ref.xhtml#re_CIT000032)). Further, because backpropagation utilizes the chain rule, derivatives are multiplied which can cause problems of the gradient either vanishing or exploding ([Alpaydin, 2020](#ref.xhtml#re_CIT000009)). Overfitting can also be a problem in backpropagation and attempts for it to converge can be addressed by early stopping as well as through other approaches we will soon discuss.

## 15.8 How Many Hidden Nodes and Layers to Include?

How many nodes and layers should a network have? This is an empirical question, and surprisingly continues to be an open question in the literature on neural networks. In general, *the closer the approximation desired, the larger the number of hidden nodes required*. In this sense, deep neural networks are usually preferred over shallow ones and empirical and theoretical evidence supports this. Yet at the same time, Ockham’s razor should be kept in mind, keeping the model as simple as possible while maintaining its ability to generalize well. Cross-validation can be used, as well as trial-and-error in determining the number of hidden nodes and layers. As we will see shortly when we discuss the universal approximation theorem, it can be shown that a multilayer perceptron with only a single hidden layer is a *universal approximator*. Such implies that a multilayer perceptron can model any suitably smooth function to any desired level of accuracy assuming a sufficient number of hidden units ([Murphy, 2022](#ref.xhtml#re_CIT000259)).551

It should be emphasized as well that a feedforward neural network with linear activation functions and `n` layers is equivalent to a linear neural network without hidden layers. Hence, the idea of “adding layers” in this case does not increase the approximation “power” of a linear neural network at all, unlike for nonlinear neural networks. In this sense then, the nonlinearity of neural networks is essential when it comes to better approximating functions based on increasing hidden layers. This is one reason why neural networks are almost always described as nonlinear. However, formally, they need not necessarily be so. If the number of hidden units in a single-layer neural network is chosen to be smaller than the number of inputs and all activation functions are linear, then information is essentially lost in the dimension reduction, in which case the neural network would essentially mimic a principal components analysis ([Bishop, 2006](#ref.xhtml#re_CIT000032)).

## 15.9 Overfitting in Neural Networks

Overfitting is a problem with neural networks perhaps more so than in any other technique. This is largely due to their complexity. It is very easy to design a quite complex network that will provide a reasonably good fit to one’s training data. However, as emphasized throughout this book, what is a good fit on the *training* data does not necessarily imply an equally good fit on *test* data. We have just discussed that the complexity of neural networks should be minimized, *all else equal*, as to avoid an unnecessarily complex network when a simpler one will garner the same or similar fit. Beyond that general principle, the question then is how to prevent overfitting? We survey some of the more common methods, though many more approaches can be found in the literature.
