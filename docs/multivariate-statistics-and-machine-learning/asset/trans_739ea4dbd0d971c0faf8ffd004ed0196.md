
决策树和神经网络是相对不稳定的方法，而线性回归和判别分析等方法则更加稳定，具有较低的方差和更高的偏差可能性。即使使用这些技术，*委员会机器* 仍可用于组合学习器以产生更稳定的估计器。稳定性体现在学习器对新测试数据的泛化能力上，因此，委员会机器或有时被称为 *ensemble* *methods* 的方法，也可以被解释为一种正则化形式（[Goodfellow 等, 2016](#ref.xhtml#re_CIT000131)）。例如，[Perrone 和 Cooper (1993)](#ref.xhtml#re_CIT000287) 提出生成神经网络委员会，而不是选择泛化性能最好的单一神经网络。确实，可以证明由网络委员会产生的误差小于或等于这些网络平均值产生的误差。再次，这本身就相当引人注目——*一支平庸的队伍表现优于单个更强的选手；一群较弱的狼表现优于一只强壮的狼。*

因此，也许有些矛盾且出人意料，算法的不稳定性在某种意义上实际上可能是可取的，或者至少无害的，从而成为一种可以用来利用和提高该学习算法准确性的重要工具。正如我们将看到的，*bagging* 和 *boosting* 实际上利用了这种相对弱点，即不稳定性，以创建更准确的学习方法。较弱的学习器可以组合起来生成更强的学习器。通过扰动学习集，这些方法生成一组不同的基础预测器或分类器“ensemble”，然后将其组合成单一的组合预测器或分类器。这种组合有多成功？其成功程度部分取决于各个基础预测器的不稳定性程度。Bagging 已被证明在组合倾向于过拟合数据且相对不稳定的学习器时是有益的（Kroese 等, [2020](#ref.xhtml#re_CIT000202)）。370

在另一端，如前所述，如果一种方法在不同的数据集甚至同一数据集的子集上产生相似的结果，则称其具有低方差。也就是说，如果你稍微扰动数据，它通常仍然会导致相似的结果。请回顾至今主导本书的偏差-方差权衡，我们在此重申：

> *好的学习器具有低偏差和低方差；然而，随着其中一个的降低，另一个很可能增加；因此存在权衡。*

在更详细地考虑委员会机器之前，我们需要概述 *决策树* 这一重要主题。我们从决策树开始有两个原因：1) 决策树本身很重要，并且构成了一种相当简单的方式来理解预测变量的统计影响；2) 我们对 bagging 和 boosting 的讨论将围绕决策树展开。正如我们将看到的，平均多个决策树是构建委员会机器的典型例子，尽管平均和组合其他程序也有类似效果。

## 10.2 决策树

基于决策树的统计学习方法因其简洁性、直观表示以及在一定程度上预测准确性而获得了巨大流行，尽管与许多其他学习方法相比，它们通常名列第二。在所有统计学习方法中，决策树作为基于树的算法家族的成员，被认为也许是所谓“现成”数据挖掘程序中最有用的。在回归的背景下，回归树首次由 [Morgan 和 Sonquist (1963)](#ref.xhtml#re_CIT000254) 引入，使用名为 *Automatic Interaction Detection*（AID）的计算机程序。有关决策树的历史，请参阅 Ripley（[1996](#ref.xhtml#re_CIT000301)，第 7.4 节）。正如我们稍后将讨论的，boosting 和自助聚合（*bagging*）可以提高决策树和其他学习方法的效率。

决策树中的 *根节点* 是树的唯一起点，而树的结束处被称为 *终端节点*。沿着树向下，分支被创建以表示给定变量的分割。当然，并非所有节点都是终端节点。非终端节点分裂为两个子节点，从而创建二元分割。如果变量是二元的，则定义分割的性质 371 的分割很简单（例如，0 与 1）。如果变量是连续的，则将其离散化并二值化，例如在中位数处分割。只有一个分割且仅有两个终端节点的树称为 *stump*。所有终端节点的集合称为 *数据的划分*。

决策树有很多好处。首先，它们可以处理非常大的数据集。它们还可以处理混合的预测变量，即 *定量* 和 *定性* 的。它们既可用于回归（其中目标或响应变量是 *连续* 的），也可用于分类问题（其中目标或预测变量是 *分类* 的）。它们能相当容易地处理缺失数据，并且通常树相对容易解释，尤其是树较小时。决策树的缺点包括较大的树可能难以解释，且决策树的预测性能通常不如竞争方法。此外，深树（即未剪枝的树，也称为 *饱和树*）通常过度依赖用于构建它们的训练数据。训练数据的微小变化可能导致结果树发生巨大变化。由于决策树通常表现出高方差，因此诸如 *bagging*、*boosting* 和 *random forests* 之类的委员会机器变得流行起来，并在专门应用于决策树时尤其有用。

### 10.2.1 树应如何生长？

我们在上面演示了一个简单的决策树，但我们如何生长这样的树？我们如何创建相关的节点和分支？在每个节点，树分割算法需要决定哪个变量在提供分割方面是“最佳”的。也就是说，在每个节点，算法需要选择一个变量，该变量相对于响应变量提供区分。我们必须考虑给定节点处所有变量的每一种可能分割，然后枚举所有可能的分割，评估每一个，并决定在某种意义上哪一个是理想的（[Izenman, 2008](#ref.xhtml#re_CIT000167)，第 285 页）。如果考虑分割的变量是有序的或连续的，则给定节点处的可能分割数比其不同观测值的数量少一个。如果变量是名义的或分类的，则该节点上该变量的可能分割集合是所有子集的集合。

### 10.2.2 树构建的优化准则

正如几乎所有统计方法一样，在为树创建相关分支时，我们应要求一个优化条件。由于我们无法考虑预测变量空间的 *每一种* 划分（这样会花费太长时间且可能性太多），我们需要采用整体方法来做到这一点。一种经常采用的方法是 *自上而下* 的 *贪婪方法*，称为 *递归二元分割* 或更一般地称为 *递归划分*（[Izenman, 2008](#ref.xhtml#re_CIT000167)），其寻求最小化以下准则：

$$\\sum\\limits\_{j = 1}^{J}\\left( y\_{i} - {\\hat{y}}\_{s\_{j}} \\right)^{2}$$
