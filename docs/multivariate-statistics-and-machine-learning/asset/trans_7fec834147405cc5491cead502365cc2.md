
几乎所有统计技术在某种程度上都是对距离度量的组织和重新组织。即使皮尔逊相关系数也可以被视为点之间距离的度量（我们挑战读者思考这一点）。

距离最常见的度量是 *欧几里得距离*，由下式给出

$$d\\left( O,P \\right) = \\sqrt{x\_{1}^{2} + x\_{2}^{2} + \\cdot \\cdot \\cdot + x\_{p}^{2}}$$

(2.111)

其中 *d* 是原点 *O* 与 *P* 之间的距离，其中 *x*[1]² 到 *x*[*p*]² 是观测值的坐标。欧几里得距离的一个优点是它们具有 *旋转不变性*，这意味着两点之间的直线距离不会随坐标轴系统的方向而改变（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)）。

虽然欧几里得距离是我们通常考虑距离时所想到的，但距离的定义还有很多，包括 *闵可夫斯基*、*城市街区（曼哈顿）* 等等。距离度量在聚类分析技术中尤其有用，该技术试图根据案例之间的相似性或距离从案例到案例生成 *组*（在某种意义上）。在本方法和其它方法中，我们将在全书中介绍多种距离度量。Python 中的简单距离可以使用 `numpy.linalg.norm(a−b)` 计算。

## 2.52 投影与基
读者最熟悉的投影无疑是线性回归，其中我们取向量 *y*，生成线性函数，并投影到 *x* 的张成空间上，从而得到一条新的直线，称为 *回归线*，包含预测值 *ŷ*。回归线对点群的拟合本质上是由于将 *y* 投影到 *x* 所“占据”的空间上。残差是 *y*[*i*] − *ŷ*。

当我们谈论 *正交投影* 时，这意味着对于子空间 *S*，*y*[*i*] − *ŷ* 与 *S* 正交。也就是说，残差与预测变量所“占据”的空间 *S* 垂直（正交）（通常称为 *列空间*）。换句话说，回归的参数估计（进而生成 *ŷ*）被选为使残差向量 *y*[*i*] − *ŷ* 与模型中预测变量所“生成”的空间正交（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。

正交性结合毕达哥拉斯定理进一步意味着我们可以按如下方式分解这些对象的平方范数，148

||*y*[*i*]|| ²\= ||*ŷ*||[2]+||*y*[*i*]−*ŷ*||²

(2.112)

或者更一般地，对于任意观测向量和拟合向量，其中 *v̂* 是向量的更一般拟合值，而上面的 *ŷ* 只是特例：

||*v*|| ²\= ||*v̂*||[2]+||*v*−*v̂*||²

(2.113)

上述恒等式很重要，因为它们本质上描述了回归和方差分析中发生的情况；也就是说，总平方和可以分解为处理引起的部分和误差引起的部分（[Marden, 2015](#ref.xhtml#re_CIT000239)，p. 89）。“处理变异”由 ||*v̂*||² 表示，而误差由 ||*v*−*v̂*||² 给出。

在 *主成分分析* 中，目标是获得一个子空间，我们也将观测数据投影到该子空间上。投影后的数据是 *主成分得分*，而数据被投影的新的坐标是新的 *基向量*。原始基，或有时称为 *规范基*，是相互垂直的原始坐标。例如，在 ℝ³ 中，标准基向量如下：

$$e\_{1} = \\left\\lbrack \\begin{array}{l} 1 \\\\ 0 \\\\ 0 \\\\ \\end{array} \\right\\rbrack,e\_{2} = \\left\\lbrack \\begin{array}{l} 0 \\\\ 1 \\\\ 0 \\\\ \\end{array} \\right\\rbrack,e\_{3} = \\left\\lbrack \\begin{array}{l} 0 \\\\ 0 \\\\ 1 \\\\ \\end{array} \\right\\rbrack$$

标准基或任何其它基的轴不必相互垂直（[Hubbard & Hubbard, 2002](#ref.xhtml#re_CIT000161)）。也就是说，从本体论的角度来看，并没有 *绝对* 要求上述向量 *e*[1]、*e*[2]、*e*[3] 必须相互垂直，*本体论*。历史上，对于大多数问题，选择基相互垂直很大程度上是出于 *方便*。笛卡尔在 17 世纪发明笛卡尔坐标系，使得代数可以用几何方式表达，其中每个轴都彼此垂直或正交。皮埃尔·德·费马（1607–1665）也发现了相同的坐标系，尽管他的著作在他死后才出版，因此笛卡尔通常与我们今天所知的传统坐标系相关联。数学家约翰·沃利斯（1616–1703）是第一个设想负坐标可能性的人之一（[Tanton, 2005](#ref.xhtml#re_CIT000352)）。如果不从基向量的成对正交性开始，问题会变得极其复杂，因此与数学中的许多其它事物一样，在许多情况下从规范向量的正交性假设或约束开始是方便的。它是许多问题的方便而自然的起点，事实上，也是整个数学的很大一部分的起点。

在主成分情况下，新的基向量是 *特征向量*，并具有进行投影的有利性质。因此，在技术层面上，PCA 通常被视为一种 *基变换* 方法论，我们通过它来投影新的得分。它通常也被视为一种 *降维技术*，但这种降维是通过基变换实现的。

## 2.53 线性的含义
术语 *线性* 也许是统计和机器学习中最常用的词。但线性究竟意味着什么？线性变换 *T*，如前所述，是从 ℝ^(*n*) 到 ℝ^(*m*) 的映射，使得对于标量 *a* 和向量 *x* 和 *y*，以下条件成立：149

*T*(*x*+*y*) = *T*(*x*) + *T*(*y*)

(2.114)

和

*T*(*a**x*) = *a**T*(*x*)

(2.115)

也就是说，线性变换被认为保持向量加法和标量乘法。从几何角度来看，线性变换是 *仿射变换* 的一个例子。仿射变换及其相关几何也保持诸如点间距离之比等性质。例如，将摄氏度转换为华氏度是仿射变换的一个例子，因为例如 10 摄氏度和 20 摄氏度之间的相对变化在转换为华氏度时得以保持：

^∘*C* = ((^∘*F*)−32)(5/9)

如果绘制相应的图，就会看到摄氏度和华氏度之间的关系确实是线性的，且距离之比得以保持。

R 和 Python 中的线性变换非常简单执行。例如，在 Python 中，假设我们想确定 32.0 华氏度对应的上述摄氏温度：

```
F = 32.0
(F-32)*(5/9)
Out[16]: 0.0
```

或者，对于温度 F = 0，我们有

```
F = 0
(F-32)*(5/9)
Out[18]: -17.77777777777778
```
