
In the previous chapter, we surveyed the method of linear discriminant analysis as a popular method for classifying a linear combination of input features into two or more mutually exclusive classes or groups. The *linear discriminant function* is only one of many methods that generates a hyperplane with the goal of classification. “Hyperplane” here, in two dimensions, is synonymous with *linear*.
In the current chapter, we study another classifier, but capable of more generality than the classic discriminant function. The *support vector machine* allows one to not only classify linear boundaries but also *nonlinear* ones by essentially constructing a linear boundary in a transformed version of the feature space ([Hastie et al., 2009](#ref.xhtml#re_CIT000145)). Modern support vector machines were developed by Cortes and Vapnik in the 1990s and are quite sophisticated in the way they go about discriminating. They are a special case of what are generally known as *kernel machines*. Kernel machines, as the name suggests, make heavy use of the *kernel operator*, usually in the form of what is known as the *kernel trick* in statistics and machine learning.
Entire books and numerous papers are written on support vector machines and kernel methods more generally. In this chapter, we highlight their main features and emphasize what differentiates them from more classical techniques. The full support vector machine is a generalization of what is called the *maximum margin classifier*, and hence before studying the SVM (*support vector machine*), we need to discuss the nature of a maximal margin classifier and briefly survey its properties. This will open the door to SVM, which will allow for the classification of nonlinear boundaries.

## 9.1 Maximal Margin Classifier
We begin with the definition of a hyperplane. A *hyperplane* is a flat affine subspace of dimension `p −` 1, given by the following:
`f(x) = x^(T)β + β[0] = 0`
(9.1)
which in the general case allows for as many dimensions as we wish. We typically set the length of `β` to unity, so that `||β||=1`. For instance, if we let `β = 1` and `β[0] = 0`, we will obtain the line in [Figure 9.1](#c9.xhtml#f9.1) that passes through the origin.351
![Figure 9.1 Line that passes through the origin having \\beta = 1 and \\beta\_{0} = 0.Return to text.⏎](images/fig9.1.jpg)
*Figure 9.1* Line that passes through the origin having *β* = 1 and *β*[0] = 0.[Return to text.⏎](#c9.xhtml#re_f9.1)
In the case where we have two dimensions, (9.1) becomes
`f(x) = β[0] + β[1]x[1] + β[2]x[2] = 0`
(9.2)
Any `x = (x[1],x[2])^(T)` for which `f(x)` is true is a point on the hyperplane. In `p` dimensions, we can extend `f(x)` to be
`f(x) = β[0] + β[1]x[1] + β[2]x[2] + ... + β[p]x[p] = 0`
(9.3)
Again, consider that we can specify any `x = (x[1],x[2],...x[p])^(T)` for which
`β[0] + β[1]x[1] + β[2]x[2] + ... + β[p]x[p] = 0`
(9.4)
holds. All of these points, for `x[1]`, `x[2]`, ...`x[p]` fall on the hyperplane, which is why the sum is equal to 0. Any points for `x[1]`, `x[2]`, ...`x[p]` not falling on the hyperplane will fall on either side of it.

### 9.1.1 When Sum Does Not Equal Zero
Consider the case now where `β[0] + β[1]x[1] + β[2]x[2],...,β[p]x[p] ≠ 0`. What are some possibilities? The sum could be *larger* than 0, or *smaller*, as we note below for the multidimensional case:352
`β[0] + β[1]x[1] + β[2]x[2] + ... + β[p]x[p] > 0`
`β[0] + β[1]x[1] + β[2]x[2] + ... + β[p]x[p] < 0`
The fact that a point can fall on either side of the hyperplane implies we have two classes, which we can enumerate as {−1,1}. We can now define a separating hyperplane for any given observation, `x[i]`, with the following specific membership categories, now including `y[i] = 1` for one class and `y[i] = -1` for the other,
$$\\begin{array}{l} {\\beta\_{0} + \\beta\_{1}x\_{i}{}\_{1} + \\beta\_{2}x\_{i}{}\_{2} + \\cdot \\cdot \\cdot + \\beta\_{p}x\_{i}{}\_{p} > 0,y\_{i} = 1} \\\\ {\\beta\_{0} + \\beta\_{1}x\_{i}{}\_{1} + \\beta\_{2}x\_{i}{}\_{2} + \\cdot \\cdot \\cdot + \\beta\_{p}x\_{i}{}\_{p} < 0,y\_{i} = - 1} \\\\ \\end{array}$$
The above naturally implies the following property for the hyperplane,
`y[i](β[0]+β[1]x[i][1]+β[2]x[i][2]+...+β[p]x[i][p]) > 0`
(9.5)
Hence, what we have established is a basic rule by which to classify new observations, `x[i]`. Further, the *size* of the deviation greater than or less than 0 can be used to assess the magnitude of the discrepancy away from the hyperplane. For example, though the result
$$\\begin{array}{l} {\\beta\_{0} + \\beta\_{1}x\_{i}{}\_{1} + \\beta\_{2}x\_{i}{}\_{2} + \\cdot \\cdot \\cdot + \\beta\_{p}x\_{i}{}\_{p} > 0,y\_{i} = 1} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 10 > \\, 0,y\_{i} = 1} \\\\ \\end{array}$$
yields the same classification as
$$\\begin{array}{l} {\\beta\_{0} + \\beta\_{1}x\_{i}{}\_{1} + \\beta\_{2}x\_{i}{}\_{2} + \\cdot \\cdot \\cdot + \\beta\_{p}x\_{i}{}\_{p} > 0,y\_{i} = 1} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 2 > \\, 0,y\_{i} = 1} \\\\ \\end{array}$$
the *magnitudes* of the size of discrepancy, of course, differ greatly. We have more *confidence*, in a sense, in the first classification than in the second due to the magnitude of the deviation (i.e., 10 vs. 2).

#### 9.1.1.1 So, What’s the Problem?
At first glance, the above seems to be a simple matter of how to classify with observations, `x[i]`, based on the establishment of a hyperplane. The problem, however, is that estimating the hyperplane poses a challenge since if our data can be well-separated by a hyperplane, then there is an infinite number of such hyperplanes, as shown in [Figure 9.2](#c9.xhtml#f9.2).353
![Figure 9.2 Data that are linearly separable by an infinite number of hyperplanes.Return to text.⏎](images/fig9.2.jpg)
*Figure 9.2* Data that are linearly separable by an infinite number of hyperplanes.[Return to text.⏎](#c9.xhtml#re_f9.2)
Notice that all the drawn hyperplanes successfully separate the binary categories. The problem of the *maximal margin classifier* boils down to the following question:
*Which of the infinite hyperplanes should we choose?*
Does this problem sound familiar? Of course it does! A similar problem posed itself when we considered earlier “classical” procedures in this book, such as *linear regression*, *discriminant analysis*, and even *principal components analysis*. What an opportune time to present a unifying theme! In all of these methods, the goal was to utilize a hyperplane based on some optimization criteria, such as minimizing or maximizing some function. Recall that in regression analysis, ordinary-least-squares required us to minimize the sum of squared errors. In discriminant analysis, the job was to maximize group differences. In principal components, the goal (as we will see later) is to maximize perpendicular distances. Now we come to yet another situation where we need to define the optimization criteria for a new approach. The question thus becomes:
*What is the best way to choose a hyperplane such that it maximizes classification?*
