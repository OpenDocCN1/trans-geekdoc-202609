## 6.4 弹性网络

缩减参数的第三种选择是 *elastic net*，其惩罚等于

$$\\left. {\\sum\\limits\_{j = 1}^{p}\\left( \\alpha \\middle| \\beta\_{j} \\middle| + \\left( 1 - \\alpha \\right) \\right.}\\beta\_{j}^{2} \\right)$$  

(6.10)

Elastic net 被认为是在 ridge 和 lasso 之间的一种折中，是一种上述估计量的“混合”（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。可以证明 elastic net 实际上采用了 ridge 和 lasso 惩罚函数的线性组合（详见 [Izenman, 2008](#ref.xhtml#re_CIT000167)，第 153 页）。

请注意，elastic net 包含两个系数，`β`[*j*]² 和 |`β`[*j*]|。要理解 `α` 在此上下文中的调参作用，请注意它同时应用于 `β`[*j*]² 和 |`β`[*j*]|，即分别在 ridge 和 lasso 中使用的损失（即二次和绝对函数损失）。因此，我们可以看到 `α` 的作用是对 `β`[*j*]² 和 |`β`[*j*]| 进行差异化加权。这就是为什么 elastic net 被解释为 ridge 和 lasso 之间的“折中”，这种折中取决于所选 `α` 值对 ridge 和 lasso 的 L2 和 L1 损失分别进行差异化加权。

## 6.5 哪种正则化惩罚更好？

为了总结我们对这些正则化方法的讨论，需要注意的是，ridge、lasso 和 elastic net 都不会普遍占优彼此。*没有免费的午餐！* 当少数系数接近 0 而其余系数相当可观时，lasso 可能表现更好，而当所有系数大致相等，或至少对研究者同等重要时，ridge 通常表现最佳。然而，没有保证。建议在一定程度上使用 *交叉验证* 来确定哪种方法对给定数据集更好，其中调参通过不同值的 *网格搜索* 选择，并使用交叉验证来观察哪种方法给出最低的 *测试误差*。重申一下，我们希望最小化 *测试误差*，而不一定是 *训练误差*。这就是为什么交叉验证对于选择最佳调参如此重要。请参阅 [Frank and Friedman (1993)](#ref.xhtml#re_CIT000108)，以比较普通最小二乘法不仅与 ridge 回归，还与主成分回归和偏最小二乘法。

## 6.6 最小角回归

正如我们在调查变量选择技术时所看到的，前向回归一次选择候选池中一个能改善模型拟合的变量。*最小角回归* 可以被视为与前向回归相关的技术，因为它仍然基于前向策略进行选择，但不一定选择 *整个* 变量。相反，进入选择的是变量中 *应得* 用于预测的那部分，而不是传统逐步程序中的全部。Hastie et al.（[2009](#ref.xhtml#re_CIT000145)，第 73–74 页）最简洁地描述了该算法：
