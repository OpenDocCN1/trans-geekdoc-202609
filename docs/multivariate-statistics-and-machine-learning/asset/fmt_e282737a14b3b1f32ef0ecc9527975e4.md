### 3.3.2 Elements of Python

As was the case for R, Python operates on *objects*, where an object can be of two types: *scalar* vs. *non-scalar*. Scalar objects are indivisible and can be thought of as the “atoms” of the language ([Guttag, 2013](#ref.xhtml#re_CIT000137)). Scalar objects include `int` for integers, `float` for real numbers, `bool`, which are Boolean “true” vs. “false” values, and `None`, which has only a single value. As a simple example ([Guttag, 2013](#ref.xhtml#re_CIT000137), p. 9), 4 + 2 is an expression and denotes the object 6 of type `int`, whereas the expression 3.0 + 7.0 denotes the object 10.0 of type `float`.

We can ask Python to confirm the type of object via `type()`:

```
type (3)

Out[196]: float
```

A *variable* in Python simply denotes a name; it does not have the same meaning as in mathematics. For example, the following is a variable:

```
> pi = 3.14159
```

That is, we have identified 3.14159 with “`pi`.” Of course, `pi` is in actuality a *constant*, but the point is that in the above we have simply identified 3.14159 with a variable name (`pi`).

### 3.3.4 Python Functions for Data Analysis

The `scikit-learn` library is the “go-to” package for machine learning in Python. It is open-source and in constant development. It also has a devoted user guide on the Python website and can be installed via `Anaconda`. Python also offers many preprocessing functions, which are functions applied to data before actually engaging in analysis. Oftentimes in statistical and machine learning applications we need to transform data in some way before implementing the algorithm or method. In statistical parlance, this is usually and simply referred to as *transforming* data while in machine learning jargon it is often called *preprocessing* data. There are multiple options for preprocessing data in Python.

One useful and popular function is that of the `MinMaxScaler()` function. This function transforms features by scaling each feature to a given range (e.g., between zero and one). Another popular class of functions is that of the `pipeline()` function. The `pipeline()` function reduces the code necessary for carrying something out and chains together multiple steps in the machine learning workflow so that instead of fitting multiple functions you can simply fit the `pipeline()` function. It is also a way to organize all of your code into one function, especially if you regularly run the same coding steps on different data sets. `StandardScaler` in `scikit-learn` transforms data to *z-*scores having a mean of 0 and standard deviation of 1. Other scaling options include `RobustScaler()` which removes the median and scales the data according to the interquartile range as a default. `Normalizer()` scales each variable or vector to have Euclidean length equal to one. There are of course other scaling options and we refer the reader to Python documentation or other resources to explore them.
