
算法本质上连接的是彼此之间距离在 `ε`（或“`eps`”）范围内的核心点，`ε` 是一个灵活的参数，用户可以自由调整。`ε` 选择过大，结果将得到一个密度等于案例数量的簇。另一方面，若 `ε` 设置过小，则几乎所有点都将各自成为一个簇。边界点随后被分配给 `connectivity` 最高的簇，这意味着单靠自身不足以成为核心点（由于未满足 `MinPts` 准则），因此会被归类到距离核心点最近的簇。由此得到的结果组即为簇，而剩余的点为噪声点。该算法的精确步骤详见 Schubert 等人（[2017](#ref.xhtml#re_CIT000329)，第 3 页）。

`DBSCAN` 算法实际上可以被视为单链接方法的更稳健的推广，其中与 `k-means` 中仅检测球形簇不同，它可以找到任意形状的簇（[Aggarwal, 2015](#ref.xhtml#re_CIT000005)）。`DBSCAN` 还可以被视为 *单链接凝聚聚类* 的一种修改，通过对边界点和噪声点给予特殊考虑，而其他方法则不对它们进行特殊处理。也就是说，在经典 523单链接聚类中，例如，边界点和噪声点在这种算法中没有意义，因此只是计算链接时周围的更多点。正如 [Aggarwal (2015)](#ref.xhtml#re_CIT000005) 所指出的，`DBSCAN` 相对于单链接的优势在于，考虑到边界点和噪声点，异常值的敏感性降低，同时算法能够检测任意形状的簇，而不仅仅是 `k-means` 方法中那样的球形簇。回顾一下，我们从一开始就说过，聚类算法的主要困难之一是它们经常对簇的形状做出先验假设（例如 `k-means` 中的球形）。`DBSCAN` 有用之处在于它不受限于检测球形或其他预定义形状。`DBSCAN` 在用于较小数据集时也被发现具有更好的聚类分类效果。

## 14.12 通过混合模型进行聚类

我们迄今为止调查的聚类算法，即 `k-means`（和 `k-representatives`）、层次聚类以及诸如 `DBSCAN` 之类的基于密度的方法，并未对数据的采样位置做出任何假设。也就是说，它们没有对数据做出任何 *参数假设* 或对簇的性质做出 *先验假设*（除假设 `k-means` 中的簇必须为球形或 `DBSCAN` 中簇位于密集区域外），也没有涉及任何概率内容。它们只是简单地依赖经验数据来说明是否存在簇，并通过硬规则的算法过程将案例分配到簇中。
