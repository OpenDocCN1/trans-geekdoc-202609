### 2.60.3 凸函数与非凸函数及集合

确定最小值和最大值取决于函数的凸性。凸函数优于非凸函数，因为它们具有 *全局* 最小值，而非凸函数通常有多个 *局部* 最小值，这会妨碍找到全局最小值。具有局部最小值的优化问题很容易陷入局部性，或者更通俗地说，在局部“山谷”中“卡住”。

[图 2.19](#c2.xhtml#f2.19) 给出了凸性的几何解释。凸函数是指我们可以在线段之间画一条线（如图像所示），并且函数的值保证等于或小于该线。对于非凸函数，我们无法在不经过函数的其他线段的情况下画出这样的线。请注意，对于凸函数，将存在全局最小值。另一种说法是，对于凸函数，任何局部最小值也将是全局最小值（Goodfellow, 2020）。对于非凸函数，可能存在许多局部最小值。

当我们在书中后面讨论流形学习时，线段或路径的广义概念——它们是两点之间的最短距离并且可以帮助指示流形中的凸性——将被称作 `geodesics`。不过，正如我们将看到的，测地线通常不是唯一的。160 定义在流形上的函数如果其 `Hessian` 为半正定则为凸，其中 Hessian 描述了多变量函数在二阶偏导数方面的局部曲率。因此，当 Hessian 为正定时，这意味着我们正在处理的曲面是凸的，这将使诸如梯度下降之类的算法更容易执行优化，因为存在确定的全局最小值。

## 2.61 梯度下降

梯度下降是一种常用的算法，用于在许多统计和机器学习应用中最小化目标函数以寻找全局或局部最小值。它是最常用的优化方法，例如在神经网络中，但也适用于许多其他机器学习和统计方法（[Ruder, 2016](#ref.xhtml#re_CIT000317)）。它是一种 *迭代* 方法，其目标是最小化某个任意成本函数，该函数会因所采用的统计或机器学习方法而不同。对参数估计进行轻微更改的迭代会在算法收敛到成本函数的最小值时停止，此后不再期望或能够进一步降低成本函数。这就是目标：对参数估计进行轻微的迭代“更新”，直到达到局部最小值。虽然梯度下降有许多变体，但通常有三种最流行的方法：*批量梯度下降、随机梯度下降* 和 *小批量梯度下降*。

### 2.61.1 梯度下降如何找到最小值？

在寻找成本或误差函数 `E(θ[0])` 的最小值时，该函数受包含在向量 `θ[0]` 中的模型参数的更新约束，会采取与给定当前模型参数值的函数梯度的负值成比例的连续步骤。请仔细注意这意味着什么：我们从某些通常任意的参数值 `θ[0]` 开始，然后基于函数的梯度（即粗略地“*斜率*”，但实际上是偏导数向量），逐步向最小值移动。我们正在寻找最小值并沿 *负梯度* 方向移动，即

`θ[1] = θ[0] − η ⋅ ∇[θ]E(θ[0])`

(2.227)

其中 `η` 是步长或 *学习* 率，而 `∇[θ]E(θ[0])` 是梯度向量，包含误差或成本函数 `E(θ[0])` 的全部偏导数集合。因此，对于任意值 `η` ≥ 0，`E(θ[1])` ≤ `E(θ[0])`。也就是说，对于任何大于 0 的 `η` 值，`θ[1]` 处的函数（即更新后的参数向量）代表相对于在 `θ[0]` 处计算的原始成本函数的 *下降*。这样做时，我们正在 *收敛* 到最小值。参数集合 `θ[0]` 根据步长 `η` 进行优化，使得参数的新的“猜测” `θ[0 + 1] = θ[1]` 通过这种最小化方法得到。

从视觉上看，梯度下降可以如 [图 2.20](#c2.xhtml#f2.20) 所示，其中我们看到最终会收敛到中心处的局部或全局最小值，从而通过每次迭代迭代更新参数估计来最小化成本或误差函数。161

![图 2.20 梯度下降背后的概念；连续的迭代最终导致最小化误差或成本函数。返回正文.⏎](images/fig2.20.jpg)

*图 2.20* 梯度下降背后的概念；连续的迭代最终导致最小化误差或成本函数。[返回正文.⏎](#c2.xhtml#re_f2.20)

我们迄今为止描述的内容通常被称为“原版”批量梯度下降（[Bishop, 2006](#ref.xhtml#re_CIT000032)；Ruder, 2017）。梯度下降在接近最小值时可能相对较慢。其渐近收敛速率也可能不如其他方法（Deisenroth et al., [2020](#ref.xhtml#re_CIT000080)）。如果学习率 `η` 太快，真正的局部最小值可能会被“跳过”，因为算法试图最大化搜索此类最小值所需的最短时间。相反，如果学习率 `η` 太慢，梯度下降可能永远不会收敛，因为算法试图“太努力”地找到局部最小值。因此，选择合适的步长或学习率 `η` 很重要。梯度下降中存在一种“权衡”，即参数更新的准确性与进行此类更新所需的时间之间的权衡（[Ruder, 2016](#ref.xhtml#re_CIT000317)）。一种有用的策略是具有随接近最小值而减慢的动态学习率，通常称为 *退火*（[Ruder, 2016](#ref.xhtml#re_CIT000317)）。在梯度下降的各种方法中，批量梯度下降只要误差曲面是 *凸* 的，就保证收敛到 *全局最小值*；如果不是凸的，则保证收敛到 *局部* 最小值。

*随机梯度下降* 对 *每个* 训练数据点 `x[i]` 执行参数更新，而不是像批量梯度下降中的“批量”，

`θ[1] = θ[0] − η ⋅ ∇[θ]E(θ; x[i])`

(2.228)
