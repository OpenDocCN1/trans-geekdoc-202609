
R is based on the S language that was developed in the 1970s by Bell Laboratories. R was released under a GNU public license in the 1990s, and since then has been developed extensively through its 167many libraries and packages. Not only is R relatively easy to use (but has a relatively steep learning curve), it is the *packages* and *libraries* that makes it so useful. Literally, the best statistics and computing minds on the planet are daily adding and revising packages for R that can be downloaded and implemented by the user. These packages can conduct very specific functions on data, and in many cases, functions that preprogrammed packages (such as SPSS) are incapable of performing. In this way then, R is “live” on the internet and is being constantly updated. While at first this benefit may not seem that important, as you increasingly work with data, you will likely come to appreciate it. Many, maybe even most analyses and problems that you come across will call for solutions that deviate from clean “textbook” scripts or problems and in no time you will be searching for a package that may be uniquely suited for the data you have to analyze. This is the norm even if you already have extensive training in statistics or computing. *Each data problem and data set is different and may require a unique solution*. As a consultant in statistics, I have found that problems can get complicated very quickly and that routine text and code usually have to be edited and adapted in some way or another to best address the specific problem at hand, so much so that each problem worked on might eventually seem like an *exception* to the safe and predictable textbook-type problems students are used to. Those who teach “cookbook” statistics may not be aware that many problems need relatively customized answers, for which the cookbook approach does no service to students in understanding and appreciating the nature and complexities of statistical modeling.

### 3.2.1 Installing R

The latest version of R can be installed by going to the R Project website: [www.r-project.org](http://www.r-project.org). When you open R, you will arrive at the following screen:

![](images/inline3.1.jpg)

The prompt can be adjusted and named whatever you like. For instance, we can name it “R” via the `options` command, or virtually anything else we would like, such as “Hello”:

```
> options(prompt=“R> “)
R>
R> options(prompt=“Hello> “)
Hello>
```

168Many times when programming, we wish to include comments to help keep track of what we are doing. Comments can be indicated by “#”. For example, consider the following, where we square the number 5 and include a comment to describe what we are doing:

```
> 5^2 # here, we are raising 5 to the second power
[1] 25
```

Note that the appended comment is not reproduced; only the computation is. One can obtain help on a topic in R by coding `help()`. For instance, suppose we wanted help on computing means:

```
> help(mean)
```

The above will bring up an online page (not shown) with R functions available on the arithmetic mean. One can also simply code `?mean` to get help as well. Coding `??mean` will bring up more options as well. One can also get an example of an object via the `example()` function. For instance, suppose we wanted an example of computing the arithmetic mean:

```
> example(mean)
mean> x <- c(0:10, 50)
mean> xm <- mean(x)
mean> c(xm, mean(x, trim = 0.10))
[1] 8.75 5.50
```

Quitting R can be done by `q()`.

#### 3.2.2.1 Building a Data Frame

Most data sets we deal with in this book are already part of R or are contained in a specific package and hence easily loaded into R. However, we can easily also build a data frame directly in R using the `data.frame()` function. In the following, we build a data frame on three individuals, recording their `age` and `sex`:

```
> mydata <- data.frame(subject=c(“Bob”, “John”, “Louis”),
+ age=c(20, 25, 30),
+ sex=factor(c(“M”, “M”, “M”)))
> mydata
```

|  || subject || age || sex |

| --- | --- | --- | --- |

| 1 || Bob || 20 || M |

| --- | --- | --- | --- |

| 2 || John || 25 || M |

| 3 || Louis || 30 || M |

### 3.2.3 Installing Packages in R

As mentioned, packages are one of the highlights of R software as they allow one to implement specific functions prepared by experts in the area and are continuously being improved daily. Packages in R can be installed via the `install.packages()` function. For example, in the following, we install the package `car`:

```
> install.packages(“car”)
> library(car)
```
