
我们可以在更一般的情况下更简洁地将上述模型表述为一个函数 `f(x)`，

$$f\\left( x \\right) = \\beta\_{0} + {\\sum\\limits\_{j = 1}^{p}{x\_{j}\\beta\_{j}}}$$  

(5.14)

其中“`f(x)`”表示给定输入 `x` 的函数 `f`。求和 $\\sum\\limits\_{j = 1}^{p}{x\_{j}\\beta\_{j}}$ 允许我们将任意数量的预测变量纳入回归模型。

正如简单线性回归模型的情况一样，参数值 `β[0]`、`β[1]`、`β[2]`、...、`β[p]` 未知，必须从样本数据中估计；因此估计的多元回归模型为

`ŷ[i] = β̂[0] + β̂[1]x[1] + β̂[2]x[2] + ... + β̂[p]x[p]`  

(5.15)

参数值通过普通最小二乘法选择，这是一个最小化残差平方和的优化问题。最小二乘解如下，其中 `X` 是预测变量矩阵，`y` 是响应向量：

`β̂ = (X^T X)^(-1) X^T y`  

(5.16)

尽管多元回归的矩阵表示看起来比简单回归更复杂，但理解该解并不困难。回想一下，求逆在概念上等价于普通标量代数中的除法，因此如果我们要 `naïvely` 尽管在数学上不正确地以最“熟悉”的方式重新写出 (5.16)，可以将其表示为

$$\\begin{array}{l} {\\hat{\\beta} = \\left( XTX \\right){- 1}X^{T}y} \\\\ {\\,\\,\\,\\,\\, = \\frac{X^{T}y}{\\left( X^{T}X \\right)}} \\\\ \\end{array}$$  

我们现在很容易看出，分子以一般方式包含 `X` 与 `y` 的乘积，而分母仅包含 `X` 的乘积。因此，用文字来说，`β̂` 的解回答了 `X` 与 `y` 相对于仅 `X` 的“共同变化”程度的问题。如果 `X` 与 `y` 高度 `linearly` 相关 这里强调 `linear`，那么 `X^T y` 将远大于 `X^T X`，因此 `β̂` 的系数会更大。相反，在极端情况下，如果 `X` 与 `y` 线性相关性不大，则 `X^T y < X^T X`，并且 `X^T y` 仅为 `X^T X` 中存在的总“交叉变异”的一部分，在数量的假设除法中。注意，这个矩阵表示不过是对单变量情况的推广，即228

$$\\hat{\\beta} = \\frac{Cov\_{xy}}{S\_{x}^{2}}$$  

其中在这种更简单的情况下，`Cov_xy` 在概念上至少类似于 `X^T y`，而 `S_x^2` 类似于 `X^T X`。

项

`X† = (X^T X)^(-1) X^T`,  

(5.17)

即去掉 `y` 后，是非方矩阵 `X` 的左 `pseudo-inverse`（[Murphy, 2022](#ref.xhtml#re_CIT000259)，p. 367）。因此，在逆不存在的情况下，伪逆可能是一个选择。这对于非方矩阵尤其有用，因为普通逆仅存在于方矩阵中。伪逆最好使用奇异值分解，或“`SVD`”（[Murphy, 2022](#ref.xhtml#re_CIT000259)）计算。

### 5.2.1 最小化平方偏差与绝对偏差

回想一下，除了预测值的平方偏差外，还可以采用如下的最小绝对偏差

`|y[i] - ŷ[i]|`  

(5.18)

那么最小化 `(y[i] - ŷ[i])^2` 与最小化 `|y[i] - ŷ[i]|` 之间有什么关系？与最小化 `(y[i] - ŷ[i])^2` 相比，最小化 `|y[i] - ŷ[i]|` 对极端值的影响较小。也就是说，当我们对 `y[i] - ŷ[i]` 进行平方时，差异会因平方而放大。如果我们改为最小化 `|y[i] - ŷ[i]|`，则不会过度强调大偏差。

最小化 `|y[i] - ŷ[i]|` 出现在 `least-absolute-value regression` 中，简称为“`LAV`”回归。然而，历史上，在回归背景下，`(y[i] - ŷ[i])^2` 通常是首选，因为平方在数学上通常比绝对值偏差更易处理（[Fox, 2016](#ref.xhtml#re_CIT000106)）。

### 5.2.2 多元回归中的假设检验

多元回归模型中检验的原假设如下：

`H[0] : β[1] = β[2] = ... = β[p] = 0`  

(5.19)

与统计备择假设相对，后者认为至少有一个系数 `β[j]` 不等于 0。为了评估，正如我们在方差分析（ANOVA）中所做的那样，我们计算一个 `F-ratio`，但与 ANOVA 中的不完全相同，

$$F = \\frac{\\left( TSS - RSS \\right)/p}{RSS/\\left( n - p - 1 \\right)}$$  

(5.20)

该值在 `p` 和 `n - p` 自由度上进行评估，其中 `p` 是预测变量的数量，`n` 是数据点的数量。`TSS` 和 `RSS` 分别是总平方和与残差平方和。如果在 `ρ² = 0` 的原假设下 `F` 的概率很小，我们拒绝无效应的原假设，并得出从数据中抽取的总体中 `ρ² ≠ 0`。229
