
A second feature that distinguishes `PCA` from linear discriminant analysis (`LDA`) (and canonical analysis) is that obtaining components does not involve the computation of an inverse matrix. In discriminant analysis, we were required to obtain eigenvalues and eigenvectors from `E^(-1)H` and hence `E^(-1)` had to exist. In `PCA`, no such inverse is computed. Of what consequence is this fact? Recall that inverses exist only for matrices that are *nonsingular*. A singular matrix has determinant equal to 0, which also implies or equates to linear dependence among select rows or columns. However, if the computation of an inverse is not required, then this implies that `PCA` can be performed on a covariance matrix that is singular. Under this condition some eigenvalues will equal 0 ([Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)). In such a case, these components are to be ignored, as they explain zero variance. A second case in which singularity can arise is when the number of observations is less than the number of variables. `PCA` can still be performed on such data, whereas `LDA` or canonical analysis on such data would, analytically, be problematic.

### 11.2.13 Cautionary Concerns and Caveats Regarding Principal Components

Principal components analysis can seem like a relatively simple procedure, but it has a lot of hidden complexities associated with it that often bypass the novice. In statistics, `PCA` is probably the simplest procedure that has the most complexity associated with it and things that can “trip you up” if you’re not careful. *Its simplicity is deceiving*. Understanding `PCA` is actually quite challenging, which might explain why there are entire books devoted to the subject. The graduate student learning `PCA` for the first time, concluding it is an “easy” procedure simply lacks the experience to appreciate its “latent” (pun intended!) complexity. We list a few of the more common caveats below. These are things you should be well aware of before using or interpreting the technique. Some we have already mentioned elsewhere in the chapter, and we emphasize here again only to reiterate their importance:

1. 1\. *Principal components are not scale-dependent*. That is, whether the `PCA` is performed on the covariance or correlation matrix usually results in different findings. Variables with greater variance will have greater influence on the `PCA` solution than variables with lesser variance. The typical way to get around this issue is to scale variables so that they all have the same variance, which amounts to analyzing the correlation matrix instead of the covariance matrix. While this may seem like a good solution to be adopted in all circumstances, if variables are not originally conceived to be of equal importance (almost in the sense of a Bayesian prior), then the covariance matrix should be analyzed over the correlation matrix ([Chatfield & Collins, 1980](#ref.xhtml#re_CIT000057), p. 71) as the analysis of covariance matrices is more in the spirit of `PCA` ([Rencher & Christensen, 2012](#ref.xhtml#re_CIT000295)).
