# 14 聚类分析和数据分割

DOI: [10.4324/9781003376941-17](https://doi.org/10.4324/9781003376941-17)

聚类分析，也称为 *数据分割*，是各种方法和分析的统称，这些方法和分析旨在发现，*在某种意义上*，一组案例，这些案例再次，*在某种意义上*，“相互关联”。也许聚类分析最具挑战性的问题在于定义究竟什么是 *聚类*。事实上，剖析短语“在某种意义上”正是本章的目标。正如 [Izenman (2008)](#ref.xhtml#re_CIT000167) 所指出的，确定聚类的确切本质“是一个难以回答的问题，主要是因为没有 universally accepted definition of exactly what constitutes a cluster. As a result, the various clustering methods usually do not produce identical or even similar solutions”（第 408 页）。因此，正如我们将看到的那样，聚类分析并没有通用的单一聚类解。相反，有各种算法可能会根据用于执行聚类的算法以及该算法所作用的数据产生不同的结果。

一个好的聚类算法，一般来说，直观上应该是这样一种算法：案例 *在* 同一聚类 *内* 的成对距离小于案例 *在* 聚类 *之间* 的距离。更正式地说，聚类分析试图发现变量空间的多个凸区域（即，凸意味着 *圆形* 或 *球形*），这些区域本质上包含该变量空间的概率分布的模式（[Hastie et al., 2009](#ref.xhtml#re_CIT000145)）。也可以寻求“聚类的聚类”，使得最相似的聚类被归类到更大的“超聚类”中。乍一看，聚类的建立似乎与 PCA 等技术非常相似。然而，在 PCA 中，所生成的维数永远不可能超过所受 PCA 作用的原始维数（即变量）。而且，虽然在聚类分析中通常不能生成比案例数更多的聚类，但新的“聚类”空间的维度实际上可能比原始变量更多（[Alpaydin, 2020](#ref.xhtml#re_CIT000009)，第 178 页）。
