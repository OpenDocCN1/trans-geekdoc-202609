
Note that the first element of the vector, 3, is plotted along the `x`\-axis, the second element (2) is plotted along the `y`\-axis, and the third element, 1, is plotted along the `z`\-axis. As a result of the vector being defined as a specific location in space defined by its coordinates, in a physical context a vector is often said to have *magnitude* and *direction*.

It is also worth noting that the plotting of the vector in [Figure 2.10](#c2.xhtml#f2.10) generates a new geometrical object, in this case a *cuboid*. Many objects in linear algebra have geometrical counterparts. We will return to this point later in our survey of determinants.

### 2.36.1.4 Vector Addition and Length
Only vectors of the same dimension can be added or subtracted. We add vectors element by element,

$$x + y = \\left\\lbrack \\begin{array}{l} x\_{1} \\\\ x\_{2} \\\\ {\\,\\, \\cdot} \\\\ x\_{n} \\\\ \\end{array} \\right\\rbrack + \\left\\lbrack \\begin{array}{l} y\_{1} \\\\ y\_{2} \\\\ {\\,\\, \\cdot} \\\\ y\_{n} \\\\ \\end{array} \\right\\rbrack = \\left\\lbrack \\begin{array}{l} {x\_{1} + y\_{1}} \\\\ {x\_{2} + y\_{2}} \\\\ {\\,\\,\\,\\,\\,\\,\\, \\cdot} \\\\ {x\_{n} + y\_{n}} \\\\ \\end{array} \\right\\rbrack$$

(2.91)

The analogous operation holds for the subtraction of vectors as well. The *length* of a vector is the square root of the sum of squared terms (or “components”),

$$L\_{x} = \\sqrt{x\_{1}^{2} + x\_{2}^{2} + \\cdot \\cdot \\cdot + x\_{n}^{2}}$$

(2.92)

For reasons that will become clearer later, in many settings we often desire the length of a vector to be unity, which means the sum of squared elements is equal to 1, that is,123

$$L\_{x} = \\sqrt{x\_{1}^{2} + x\_{2}^{2} + \\cdot \\cdot \\cdot + x\_{n}^{2}} = 1$$

(2.93)

The length of a vector is also referred to as the *Euclidean norm*, also known as the `l`[2] norm of that vector more generally defined as

$$\\begin{array}{l} \\left| \\middle| x \\middle| \\middle| {}\_{2} = \\sqrt{x\_{1}^{2} + x\_{2}^{2} + \\cdot \\cdot \\cdot + x\_{n}^{2}} \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = \\sqrt{\\sum\\limits\_{i = 1}^{n}x\_{i}^{2}}} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = \\sqrt{x^{T}x}} \\\\ \\end{array}$$

(2.94)

where `x^(T)x` is the dot product (to be reviewed shortly). The `l`[1] norm, on the other hand, instead of summing squares, sums *absolute values*,

$$\\left| \\middle| x \\middle| \\middle| {}\_{1} = {\\sum\\limits\_{i = 1}^{n}\\left| x\_{i} \\right|} \\right.$$

(2.95)

As we will see later, *eigenvectors* will typically have length set (or *constrained*) to unity in methods such as *principal components analysis*. This is done mostly for convenience so that the variance accounted for by the component cannot grow simply as a function of its length. Setting lengths of vectors equal to unity is common practice in many other statistical methods as well. The important point for now is that what matters most in many of these procedures is not the actual length of the vector, but the *relative distance between the values*. “Normalizing” a vector to unit length does not disrupt these distances. That is, the *ratios* between values remain the same.

We can lengthen or shorten vectors by multiplication by a scalar or constant `c`, as in the following where each element of the vector `x`[1], `x`[2], `x`[3], ..., `x`[*n*] is being multiplied by the constant `c`:

$$cx = \\left\\lbrack \\begin{array}{l} {cx\_{1}} \\\\ {cx\_{2}} \\\\ {cx\_{3}} \\\\ {\\,\\, \\cdot} \\\\ {cx\_{n}} \\\\ \\end{array} \\right\\rbrack$$

In [Figure 2.11](#c2.xhtml#f2.11) is an example of multiplying a vector by a constant of 2, which has the effect of lengthening (or “stretching”) the vector. In the same picture we multiply a vector by ½ (from the origin), forcing it into the opposite direction.

### 2.36.1.5 Eigen Analysis and Decomposition
The idea of multiplication by a constant may seem trivial in this abstract context but is very significant in multivariate settings because many transformations by a matrix can be equated to the lengthening of a vector. For instance, in *eigen analysis*, as we will see later, the product of a matrix with a vector is equated to simply a lengthening of that vector by multiplication by a constant,125

*A**x* = *λ**x*

(2.96)

where `A` is some matrix, often a covariance or correlation matrix, post-multiplied by `x`, a vector. The equality states that this product `A x` is equal to the pre-multiplication of `x` by a constant, `λ`. The constant `λ` is referred to as an *eigenvalue* of the transformation and `x` an associated *eigenvector*. As we will see, eigenvectors are unique only up to multiplication by a constant. Many seemingly complicated multivariate methods have eigen analysis at their core and feature this very simple idea of multiplying a vector by a constant, the constant in this case being the eigenvalue of the transformation.

To solve for `λ` and `x` we can start by rewriting *A**x* = *λ**x* as

(*A*−*λ**I*)*x* = 0

When we set the determinant equal to 0, that is, |*A*−*λ**I*|=0, we can then find values of `λ` to then solve for `x`.

As an example, consider the following matrix and the computation of the characteristic polynomial on matrix `A` to obtain eigenvalues:

$$\\left\\lbrack \\begin{array}{l} {3\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\, 1} \\\\ {1\\,\\,\\,\\,\\, 3\\,\\,\\,\\,\\, 2} \\\\ {1\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\, 3} \\\\ \\end{array} \\right\\rbrack$$

We calculate |*A*−*λ**I*|:

$\\left| A - \\lambda I \\middle| = \\left\\lbrack \\begin{array}{l} {3\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\, 1} \\\\ {1\\,\\,\\,\\,\\, 3\\,\\,\\,\\,\\, 2} \\\\ {1\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\, 3} \\\\ \\end{array} \\right\\rbrack - \\left\\lbrack \\begin{array}{l} {\\lambda\\,\\,\\,\\,\\, 0\\,\\,\\,\\,\\, 0} \\\\ {0\\,\\,\\,\\,\\,\\lambda\\,\\,\\,\\,\\, 0} \\\\ {0\\,\\,\\,\\,\\, 0\\,\\,\\,\\,\\,\\lambda\\,\\,} \\\\ \\end{array} \\right\\rbrack = \\left\\lbrack \\begin{array}{l} {3 - \\lambda\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 1} \\\\ {\\,\\,\\, 1\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 3 - \\lambda\\,\\,\\,\\,\\,\\,\\,\\,\\, 2} \\\\ {\\,\\,\\, 1\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 2\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, 3 - \\lambda\\,\\,} \\\\ \\end{array} \\right\\rbrack \\right.$ =  − (*λ*−6)(*λ*−2)(*λ*−1)

or in unfactored form, simply  − *λ*³ + 9*λ*² − 20*λ* + 12. The corresponding eigenvalues are 6, 2, and 1 because they are the values for which |*A*−*λ**I*|=0 is true. The corresponding eigenvectors, as the reader may verify, are `v`[1] = (1,1,1), `v`[2] = (−3,1,1) and `v`[3] = (2,−3,2).
