
一种替代这些聚类方法的方法是假设数据来自 `mixture`（通常是）高斯分布或其他参数分布（例如离散数据的泊松分布等）的混合。这些分布的类型和数量通常由用户根据该领域的先验实质性经验以及关于混合成分的先验知识或假设来选择，尽管在大多数特定知识未知的情况下，高斯分布通常是默认选择。然而，成分的数量可以被视为超参数 526用户必须指定 ([Alpaydin, 2020](#ref.xhtml#re_CIT000009))。如果聚类数量是已知的 `a priori`，因此聚类数量的“ground truth”存在，指定成分数量就很简单。然而，正如通常一样，聚类分析是在聚类数量 `a priori` 未知的情况下进行的，在这种情况下，用户可能 `expect` 看到的先验知识在指定成分数量时可能很有用。

`mixture model`，正如名称所示，并且我们在其他上下文中已经看到过，是一种概率密度分布的混合，对于聚类分析，其一般形式为，

$$f\\left( x;\\theta \\right) = {\\sum\\limits\_{g = 1}^{G}{\\pi\_{g}f\_{g}\\left( x;\\theta\_{g} \\right)}}$$  
(14.12)

其中有 `g` = 1 到 `G` 个聚类，`π`[`g`] 是观测来自第 `g` 个聚类的概率（`π`[`g`] 代表 `mixing proportions`），`f`[`g`](`x`;`θ`[`g`]) 是第 `g` 个聚类中的概率密度函数，而 `θ`[`g`] 是一个需要估计的参数向量。假设 `f`[`g`](`x`;`θ`[`g`]) 的通常形式是多元正态性，这意味着 `θ`[`g`] 因此将由均值向量和协方差矩阵组成 ([Jolliffe, 2002](#ref.xhtml#re_CIT000174))。

拟合混合模型后，后验概率 `p`(*y*/*θ*) 得到。最流行的混合模型，如前所述，是 `Gaussian mixture model`（Murray, 2022），其密度为 `N`(*y*|`μ`[`g`],`Σ`[`g`])，其中 `N`(*y*|`μ`[`g`],`Σ`[`g`]) 表示具有均值向量 `μ`[`g`] 和协方差矩阵 `Σ`[`g`] 的多元正态分布。这里更稳健的版本将使用 `t`-distribution 而不是正态分布 ([McLachlan & Chang, 2004](#ref.xhtml#re_CIT000245))。

`mixture model` 中的统计目标是通过最大化数据的 `likelihood function` 来估计模型参数，以在已知模型参数的情况下生成关于数据的聚类成员后验概率。然而，在高斯混合中最大化似然时可能会出现问题，即潜在 `singularities` 的问题。如果混合模型的一个成分的均值等于单个数据点的均值，则会出现奇点。正如 [Bishop (2006)](#ref.xhtml#re_CIT000032) 所指出的，在这种条件下，单个数据点对似然函数贡献一项，

$$N\\left( x\_{i} \\middle| x\_{i},\\sigma\_{j}^{2}I \\right) = \\frac{1}{\\left( 2\\pi \\right)^{1/2}}\\frac{1}{\\sigma\_{j}}$$  
(14.13)

其中 `σ`[`j`]² 是第 `j` 个成分的方差，`x`[`i`] 是一个给定的数据点，由于奇点的缘故，它等于给定成分的均值，即 `μ`[`j`]。当 `σ`[`j`] 越来越接近 0 时问题就会出现，在极限情况下，

$$\\lim\\limits\_{\\sigma\_{j}\\rightarrow 0}\\left( {\\frac{1}{\\left( 2\\pi \\right)^{1/2}}\\frac{1}{\\sigma\_{j}}} \\right) = \\infty$$  

因此对数似然会由于 1/`σ`[`j`] = 1/0 而趋向无穷大。在这种情况下发生时，均值的随机值可以被“reset”，以帮助避免以这种方式使点在似然上“collapsing”。有关此问题的更详细描述，请参阅 [Bishop (2006)](#ref.xhtml#re_CIT000032)。

如前所述，用户可以从不同的模型分布和参数选择中进行选择，这会产生对每个成分概率分布的 `flexibility`。混合建模方法的优点是 resulting clusters 将倾向于 527 具有相对紧密且不同的聚类中心所产生的高度峰值，因此混合模型在许多情况下可以很好地解释聚类数据。

混合模型是概率型聚类算法大家族的一部分，其特点是 `soft clustering` 的思想，其中一个案例被分配到一个聚类不是 `deterministically` 而是 `probabilistically`。这些模型通常被称为 `generative models`，因为它们假设观测值是从一个或多个概率分布中 `generated` 的。读者可能会在这个想法中认识到“Bayesian”的基调。更技术地说，生成模型背后的基本思想是可以通过从边缘分布中抽取值来生成合成数据 ([Bishop, 2006](#ref.xhtml#re_CIT000032))。

估计这些基于概率的模型的一种流行方法是使用众所周知的 EM 算法的最大似然法 ML。回想一下，EM 算法是一种通常用于处理 `incomplete data` 的通用优化程序，但已被证明对于拟合聚类分析中的混合模型特别有价值，其迭代由 `E-step` 和 `M-step` 组成。`E`-`step`（`expectation`）和 `M-step`（`maximization`）被迭代执行直至收敛以确定最佳参数，最终估计后验概率并获得概率模型，其中用 `soft assignments` 替代了案例到聚类的 `hard assignments`。事实证明，EM 算法的特殊情况等价于 `k`-means 算法的软版本，其中代表性距离用于定义软 EM 分配概率 ([Aggarwal, 2015](#ref.xhtml#re_CIT000005))。

### 14.12.1 聚类解的模型选择

乍一看，在聚类分析混合模型环境中，模型选择可能通过简单地最大化边际似然，或更具体地说，其对数，并为 `g`[1,]`g`[2], ...`G` 解决方案选择对数似然最大的聚类解来进行。然而，关于此的正式检验很难获得 ([McLachlan & Chang, 2004](#ref.xhtml#re_CIT000245))。`H`[0] : `g` = `g`[0] 与 `H`[1] : `g` > `g`[0] 的正式检验（其中 `g`[0] 分别是在零假设和备择假设下的聚类数）可通过自助法进行，其中从针对特定 `H`[0] 的 `g` = `g`[0] 个成分的给定拟合混合模型中抽取自助样本，并计算 `H`[0] 和 `H`[1] : `g` > `g`[0] 两者的  − 2log `λ` 值。然后可以获得 `p`-value 以了解在统计意义上增加另一个成分是否值得。

我们寻求的似然也可以通过以下 BIC 统计量来近似，

$$BIC\\left( g \\right) = \\log p\\left( x \\middle| g,{\\hat{\\theta}}\_{g} \\right) - \\frac{v\_{g}}{2}\\log\\left( n \\right)$$  
(14.14)
