换句话说，`logloss` 试图衡量模型是否倾向于为正类分配较高的预测概率，例如 0.90，还是显示出较差的识别正类能力并分配较低的预测概率，例如 0.55？

`logloss` 可以取大于 0 的任意值。值为 0 表示模型已正确分配了 0% 或 100% 的概率。**[表 8.6](#16_Chapter08.xhtml#tab8.6)** 按 `logloss` 递增顺序显示了排序后的表格。
