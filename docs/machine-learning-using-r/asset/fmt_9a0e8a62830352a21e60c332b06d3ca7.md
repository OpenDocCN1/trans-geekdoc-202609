
## Chapter 2 - Data Preprocessing
This chapter introduces `data.table` package, which provides an efficient implementation of reading huge volume of data to create a `data.frame` as well as syntax for faster querying on the data through binary search. The chapter also introduces basic operations, such as selecting, filtering, grouping, joining, creating new variables, etc., using the syntax of `data.table` package itself rather than relying on base packages or `dplyr` package. Though we use the simple dataset, that is, Indian Premier League (IPL) 2011 data to showcase the use of `data.table` package, we compare the efficiency of read operation of `data.table` package with the read operation performed using traditional base package on a dataset with 30 million records.

## Chapter 3 - Data Visualization
This chapter presents the grammar of graphics, the building block for visualization, which is fundamental to understand the `ggplot2` package. The chapter uses the Indian Premier League (IPL) 2011 data to describe the theory behind various statistical charts, such as histogram, distribution plot, scatter plot, box-plot hexagon plot, etc., and how to derive insights from these plots. The chapter briefly introduces a powerful option provided by `ggplot2` package to visualize multiple plots with multiple dimensions in a grid view.

## Chapter 4 - Probability and Distributions
This chapter provides an overview of probability distributions, such as binomial distribution, normal distribution, exponential distribution, Poisson distribution, and their applications to real-world problems. The chapter uses the stock price data of two companies to deep dive into normal distribution and apply the concepts of normal distribution to gain insights from the stock data. Central limit theorem - the building block for many statistical analysis - is also demonstrated using the publicly available stock price data of a company. We also discuss hypotheses tests, such as `t-test`, paired `t-test` and, ANOVA in this chapter.

## Chapter 5 - Supervised Learning Algorithm: Linear Regression
In the field of Data Science, regression is one of the important and popular techniques to analyze a wide variety of problems. In this chapter, we discuss the basic concept behind regression and building regression models. We have used the Indian Premier League (IPL) 2011 data to estimate the sold price of the players. The data is a mix of categorical and numeric features. We will learn how to incorporate categorical (qualitative) variables in a regression model. We will understand the usefulness of splitting the data into train set and test set before building the model. We will build stepwise regression using strategies, such as forward selection and backward elimination. While doing so, we will understand Akaike Information Criteria (`AIC`) for applying the above strategies as well as understand the techniques used for model validation and gauging model usefulness. We will learn about statistical significance using `t-test` and `F-test`, regression model diagnostics and perform tasks such as residual analysis, identification of outliers, and influential observations. We will use `caret` package to build the linear regression and multiple linear regression models.

## Chapter 6 - Classification Problems
In this chapter we discuss various classification problems and basic concepts behind the binary logistic regression to solve classification problems. We use attrition data from a company and develop binary logistic regression, stepwise logistic regression with forward selection and backward elimination strategy. The chapter also showcases the use of logistic regression for target marketing. We also discuss the concept behind decision tree, cross-validation, and apply it on attrition dataset. We compare the logistic regression and decision tree models and discuss the multi-model approach to reduce features yet maintain model accuracy. We also show the importance of feature engineering and devise several new features from the raw data. The chapter provides in-depth understanding of evaluating the models using metrics derived from confusion matrix, such as Sensitivity, Specificity, `F-score`, precision, kappa, McNear test, recall, area under ROC curve (`AUC`), and finding optimal cut-off for model deployment.

## Chapter 7 - Advanced Machine Learning
In this chapter we will understand cost function, regularization, and usage of optimization techniques like gradient descent (`GD`) in ML algorithms. This chapter introduces the bias-variance concept and its trade-off, with an application on a simple yet real dataset. We will learn the concept behind `LASSO`, `Ridge` and `ElasticNet` and apply them on estimating the sold price of players in Indian Premier League (IPL) 2011, with cross-validation strategy. Using attrition data from an industry, we also show the application of these algorithms to solve a classification problem. The chapter uses `caret` package which has standardized framework for model development. We also show the usefulness of `glmnet` package to fine-tune the hyper-parameters of the algorithms discussed in this chapter. We will compare the results of `glmnet` with that of `caret` on the same dataset and understand the nuances of building a Lasso, Ridge, and ElasticNet model.

## Chapter 8 - Ensemble Methods
This chapter deep dives into the theory and application of advanced models, such as Random Forest, Gradient boosting machine (`GBM`), and Xtreme boosting in solving Net Promoter Score (`NPS`) problem. It also provides insights into the usage of ensemble techniques such as `GBM` and Xtreme boosting to solve for regression problems. We will understand the use of state-of-the-art `h2o` package for model building and hyper-parameter search using grid search techniques. Given that the search space for hyper-parameters of `GBM` and Xtreme boosting may get complex, we will understand the sequence of steps to follow to fine-tune these models.

## Chapter 9 - Text Analytics
Social media data is a messy data to deal with, particularly so if we use Twitter to express our views. The chapter provides details of setting and authenticating account to scrape twitter data. We then deep dive into the COVID pandemic data and use text preprocessing steps, such as regular expressions (`regex`), stop word removal, stemming, and lemmatization for text clean up, Create Bag of Words (`BoW`) using basic word embeddings like count, `TF`, and `TF-IDF` vectorization. We discuss how to visualize unigrams and bigrams to draw insights and extract user sentiments using three predefined lexicons. Next, we explain how to create document term matrix (`DTM`) and prepare a dataset with a mix of numeric and categorical feature for further modelling needs. We also discuss the use of topic model to extract themes of discussion in COVID data. Along with `ggplot2` and `dplyr`, the chapter mostly uses tidy text package for analysis in this chapter.
