### 9.7.6 改进 BoW – 使用 n-grams

迄今为止的分析单独使用了每个标记或词。但某些词的含义可能取决于其前后的词，例如 ‘not happy’。它应被视为一个特征，而不是两个不同的特征。`n`-gram 是 `n` 个词的连续序列。当两个连续词被视为一个特征时，称为二元词组；三个连续词称为三元词组，以此类推（Pradhan and Kumar, 2019）。我们将使用 `unnest_token()` 创建二元词组。请注意，在创建二元词组时，我们未使用词干提取和词形还原的概念。**[表 9.25](#17_Chapter09.xhtml#tab9.25)** 显示了下面代码的输出。
