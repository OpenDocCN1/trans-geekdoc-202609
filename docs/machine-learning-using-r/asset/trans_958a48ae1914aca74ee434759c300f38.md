## 1. Global environment
全局环境显示在进行任何数据分析项目时加载或创建到内存中的对象。这些对象可以称为全局变量，并在全局环境中列为 ‘Data‘、‘Functions‘ 或 ‘Values‘。

• Data 指的是在从任何文件格式读取数据文件时创建的对象。这些对象被创建为 `data.frame`、`data.table`、`tibble` 等。

• Functions 指的是作为用户定义函数创建的对象。

• Values 指的是原始以及复杂数据类型（如 `int`、`float`、`list`、`matrices` 等）的对象。

在使用 RStudio 编写和执行 R 脚本之前，必须安装 R 软件。

[图 1.7](#09_Chapter01.xhtml#fig1.7) 描述了全局环境，显示了 ‘Data’ 和 ‘Values’ 的快照。当我们将值赋给变量 ‘age‘ (`age = 20`) 或从系统读取逗号分隔值（csv）文件 (`read_csv = read.csv(<file-name>)`) 时，变量 `age`（列为 values）和 `read_csv`（列为 data）会在全局环境中创建。

R 中的环境也有更深层的含义。例如，`functions` 会创建自己的求值环境，函数调用期间创建的对象存储在局部环境中，而不是全局环境中。全局环境中的对象在整个 R 会话中都可用，而局部环境中的对象仅在函数创建的局部环境中可用。

### Content viewer
内容查看器有五个基本子标签页：

#### 1. Files
列出当前工作目录中的所有文件。默认情况下，当前工作目录是主目录。

#### 2. Plots
进行数据分析时生成的所有图表都可以在 plots 标签页中查看。

#### 3. Packages
R 中的包可以通过 packages 标签页安装。[图 1.8](#09_Chapter01.xhtml#fig1.8) 显示了通过在 ‘package’ 标签页中点击 install 按钮来安装包的一种方法。我们可以将包视为元数据或字典，或是一组预定义函数，其中包含调用函数时应执行步骤的信息。

例如，当我们输入 `read.csv` 时，R 解释器必须有某种方式理解该函数用于读取 csv 文件。包含此定义的包是 ‘`utils`‘。‘`utils`‘ 包有一组此类函数，可识别在编辑器中编写函数时应执行的逻辑操作。在 [图 1.8](#09_Chapter01.xhtml#fig1.8) 中，我们看到 package 标签页列出了机器上安装的所有包。当前会话中加载的包在相应框中会有复选标记。控制台中的 `installed.packages()` 命令也会返回 R 中安装的所有包。

![](images/page13-01.png)

#### 4. Help
任何函数或命令的帮助都可以通过 help 标签页查看。例如，要获取 `read.csv` 的帮助，请在控制台输入 `? read.csv`。结果将出现在 help 标签页中，如 [图 1.9](#09_Chapter01.xhtml#fig1.9) 所示。

#### 5. Viewer
RStudio 包含一个 Viewer 面板，可用于探索本地网页内容。例如，使用 `GoogleVis`、`htmlwidgets` 和 `rCharts` 等包生成的网页图形和图表，甚至使用 `Shiny`、`Rook` 或 `OpenCPU` 等包创建的本地 Web 应用程序。

### 1.9 | Anaconda
Anaconda 是另一个集成开发环境，可让数据科学家访问 Python 和 R 中最流行的数据科学发行版。实际上，Anaconda 是一个发行版管理系统和一个包含 1,000 多个开源包的集合。Anaconda 发行版使用 `conda` 来管理包、依赖项和环境。

根据 Conda 的官方网站，[⁷](#09_Chapter01.xhtml#ch1-r-fn7) “它是一个开源的包管理与环境管理系统，可在 Windows、macOS 和 Linux 上运行。`Conda` 可快速安装、运行和更新包及其依赖项。`Conda` 可轻松在本地计算机上创建、保存、加载和切换环境。它最初为 Python 程序创建，但可打包和分发任何语言的软件”。Anaconda IDE 主要用于使用 Python 进行数据科学，提供了使用 R 执行数据分析所需的所有支持。`Conda` 是包管理器，而 Anaconda 是一组约一百个包的集合，包括 `Conda`、`Numpy`、`Scipy`、`Ipython notebook` 等。
