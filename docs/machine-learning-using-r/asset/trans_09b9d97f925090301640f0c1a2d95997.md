### 3.5.2 条形图

条形图是定性变量（或分类变量）的频数图。当变量为定性时，不能使用直方图（在 [第 3.5.3 节](#11_Chapter03.xhtml#sec3.5.3) 中讨论）。条形图可用于评估数据集中出现频率最高和最低的类别（Kumar, 2017; Roshan, 2020）。绘制条形图时，我们可以：

**1.** 使用 `geom_bar()`，它使条形的高度与每个类别或组中的案例数量成比例（如果提供了 `weight` 美学属性，则对其求和）。

**2.** 使用 `geom_col`，如果我们希望条形的高度代表实际值。数据框应作为 `data` 参数传入。**[图 3.6](#11_Chapter03.xhtml#fig3.6)** 显示了为每个年龄类别的球员计数创建的条形图。

`geom_bar()` 默认使用 `stat_count()`，因此会统计每个水平（`x`）位置的记录数。`geom_col()` 使用 `stat_identity()`，它绘制来自数据中的实际值。
