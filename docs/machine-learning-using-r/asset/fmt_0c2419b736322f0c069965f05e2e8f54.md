To generate a scatter plot, the steps listed below must be followed:

### 1. Create a new dataset

Create a new dataset that reflects the mapping of `AVE_BL` to horizontal axis, `SR_BL` to vertical axis, and third dimension `TEAM` can be assigned a shape (such as a point). Horizontal axis, vertical axis, and shape (point) are known as the aesthetics of a graph, that is, things which we see on a graph. Many aesthetics can be generated from the above data. We can draw a line chart, in which case the shape will be a line and not a point. We can also generate a bar chart from the above data (aesthetic will be bar). Thus, point, line, or bar can be termed as geometrical objects.

![](images/page58-03.png)

### 2. Convert the numbers

Convert the numbers, that is, `AVE_BL` and `SR_BL` into physical units which can be displayed by the computer. We can do so by linear scaling and by using the cartesian co-ordinate system. These transformations need to be performed for every aesthetic -horizontal axis, vertical axis, and shape. In this case, it applies to `TEAM` as well (map `CSK` to green, map `DD` to red, etc.). These transformations are known as scaling.

### 3. Render the above data

Render the above data to create a graphical object that can be displayed on the screen. This step combines data (represented by geometrical objects), the scales and the co-ordinate system and plot annotations (title, background, axis name, etc).

Based on the type of chart one wishes to generate from transformations/scaling done in step 2, many variations of the plot can be achieved. In the example of scatter plot, it is just an identity transformation where we plot the point as it appears in the data. However, one can bin or aggregate data before plotting, and they can be thought of as statistical transformations (histogram plot, box plot, contour plot, density plot, jitter plot, etc.).

Mapping from variables to aesthetic and geometrical objects, scaling and transformations, and rendering forms one layer of the plot. A plot can have multiple layers. The layer component is the physical representation of data, and is visible on the screen. A layer with a combination of stat and geom defines many familiar graphics and plots such as the scatterplot, histogram, contour plot, bar plot, etc.

`ggplot2` helps to implement the grammar of graphics as described below.

The `ggplot` package is based on grammar of graphics and follows the concept of layering of charts. The function `ggplot()` creates an empty plot section, which intuitively can be thought of as canvas ready to paint.

### 1. `ggplot()`

It creates a coordinate system (empty graph) to which different layers are added.

### 2. `geom_objects`

A `geom` is the geometrical object that a plot uses to represent data. `geom_point()` adds a layer of points which creates a scatter plot.

`ggplot2` comes with many `geom` objects that each adds a different type of layer to a plot.

### 3.5.1 Scatter Plot

Scatter plot is a plot of two variables represented as cloud of points showing a joint distribution of two numerical variables, in which each point denotes an observation from the dataset. Scatter plot assists data scientists in understanding if there is any association relationship between two variables. The relationship could be linear or non-linear. Scatter plot is also useful for assessing the strength of the relationship and to find if there are any outliers in the data. Scatter plots are used during regression model building to decide whether to include a variable in a regression model.

In [Figure 3.1](#11_Chapter03.xhtml#fig3.1), the `ggplot()` created a plot object, to which a layer was then added. In the layer, we specified the data and the mapping. We also specified that the geometrical object is point (which shows various records as a scatter plot).

However, while using the `ggplot`, many defaults are set in `ggplot()`:

#### 1. Geom defaults

When we specify the `geom`, there is no need to specify the `stats` since the geometrical objects have default transformation already set, and vice versa. The `ggplot` defines many geometrical functions. Say, for `geom="point"`, `ggplot` has `geom_point()`, for `geom="bar"`, `ggplot` has `geom_bar()`, etc.

#### 2. Aesthetic mapping

The data and aesthetic mapping can be provided in the `ggplot()` itself. However, not all aesthetic will be applicable to all geometrical functions. While adding multiple layers of `geom` functions, one needs to be careful about the aesthetic applicable to that layer. If the aesthetic is passed within the `geom` functions, it overrides the aesthetic passed in `ggplot()`.

#### 3. Default scales

Default scales will be added according to the type of variables and the aesthetic mapping. It means `scale_x_continuous()` and `scale_y_continuous()` are used by default in the above plot. We can mention scale in case it is needed to change the default. Say, the scaling is logarithmic (`scale_x_log10()` and `scale_y_log10()`), etc.

#### 4. Coordinate system

Cartesian co-ordinate system is used by default.
