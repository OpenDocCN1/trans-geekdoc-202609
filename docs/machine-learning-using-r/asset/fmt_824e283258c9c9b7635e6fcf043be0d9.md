### 9.7.6 Improve BoW – Using n-grams

The analysis so far used each token or word individually. But the meaning of some of the words might be dependent on the words that precede or succeed them, such as, ‘not happy’. It should be considered as one feature and not two different features. `n`-gram is a contiguous sequence of `n` words. When two consecutive words are treated as one feature, it is called a bigram; three consecutive words is called a trigram and so on (Pradhan and Kumar, 2019). We will use `unnest_token()` to create a bigram.
