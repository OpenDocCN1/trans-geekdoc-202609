## 7.7 | 机器学习 – 使用 Caret 进行回归

直接使用 `glmnet` 包构建回归模型并通过 `caret` 调用 `glmnet` 会导致最佳模型返回的最终 `lambda` 值出现一些差异。这可能是由于 `caret` `glmnet` 方法与 `glmnet` 包之间的内部交互所致。然而，如果通过 `caret` 包正确地进行模型调优，结果可能不会有太大差异。在业务关键项目中，建议使用 `glmnet` 包而不是 `caret` 包来微调和构建回归模型。如果业务要求使用 `caret` 包，则建议使用 [第 7.6.3 节](#15_Chapter07.xhtml#sec7.6.3) 中所示的步骤生成 `lambda` 序列，并使用 `caret` 包（`glmnet` 方法）对这些 `lambda` 值进行网格搜索。
