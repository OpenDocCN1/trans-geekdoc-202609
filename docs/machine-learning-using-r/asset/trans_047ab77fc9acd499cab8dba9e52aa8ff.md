
# R 简介

根据全面的 `R` 档案网络 (`CRAN`)，[¹](#09_Chapter01.xhtml#ch1-r-fn1) `R` 是 `S` 编程语言的实现，结合了受 `Scheme` 启发的词法作用域语义 (`S` 语言)。 `S` 由 John Chambers 于 1976 年在贝尔实验室创建。 Ross Ihaka 和 Robert Gentleman 在新西兰奥克兰大学创建了 `R`。该项目构想于 1992 年，1995 年发布了初始版本，2000 年发布了稳定测试版 (Anon 2021)。 `R` 的名称部分基于前两位 `R` 作者的名字 (Robert Gentleman 和 Ross Ihaka)。

![](images/page4-01.png)

`R` 是一种编程语言和开源软件平台，专为统计计算和图形设计。它由 `R` 基金会支持，该基金会是由 `R` 核心开发团队成立的非营利组织。 `R` 语言在统计学家和机器学习专家中被广泛使用，用于开发基于机器学习算法的模型。作为一种解释型语言，`R` 允许使用函数进行模块化编程，并通过抽象细节为用户提供灵活性，如同典型的编程语言。[²](#09_Chapter01.xhtml#ch1-r-fn2)

`R` 拥有超过 12,000 个软件包，适用于几乎任何类型的统计或机器学习分析。强大的用户社区不断更新并创建新的库。

![](images/page5-01.png)

也有可用于构建深度学习模型的软件包。一些用于统计和机器学习的实用软件包在 **[表 1.1](#09_Chapter01.xhtml#tab1.1)** 中提及。

[表 1.1](#09_Chapter01.xhtml#tab1.1) 中的列表并非详尽无遗，读者可能会发现其他软件包对数据分析和构建机器学习模型有用。

### 1.5 | R 的流行度指数

The Importance of Being Earnest (`TIOBE`) 编程指数是衡量编程语言接受度的重要指标。 `TIOBE` 指数由荷兰埃因霍温的 `TIOBE` 公司创建和维护。根据 `TIOBE` (Anon, 2021)，“该指数是根据包含语言名称的查询的搜索引擎结果数量计算得出的（**[表 1.2](#09_Chapter01.xhtml#tab1.2)**）”。语言的流行度应结合 `TIOBE` 的免责声明来理解：

![](images/page6-01.png)

**1.** 根据 `TIOBE` 网站，`TIOBE` 指数“并非关于最佳编程语言或编写了最多代码行的语言”。

**2.** 根据 `TIOBE` 网站，“该指数涵盖了 Google、Google 博客、MSN、Yahoo!、Baidu、Wikipedia 和 YouTube 的搜索，并每月更新一次”（Anon, 2021）。

**3.** 该网站声称，搜索结果的网页数量可能反映了全球熟练工程师、学生、提供的课程数量以及该技能的就业市场。

从 [表 1.2](#09_Chapter01.xhtml#tab1.2) 可以看出，`Python` 是首选语言，排名第四，而 `R` 占据第 18 位。最新排名可在 `TIOBE` 网站上找到。[³](#09_Chapter01.xhtml#ch1-r-fn3) 截至 2020 年 8 月的最新 `TIOBE` 指数排名将 `R` 排在第八位。[⁴](#09_Chapter01.xhtml#ch1-r-fn4)

排名差异也由于 `Python` 是一种通用编程语言，可用于其他软件开发任务，而 `R` 更适合作为统计计算和机器学习的语言 (Pradhan and Kumar, 2019)。

在热门网站上对 `SAS`、`Python` 和 `R` 等各种语言的职位数量进行搜索，[⁵](#09_Chapter01.xhtml#ch1-r-fn5) 显示了 **[图 1.3](#09_Chapter01.xhtml#fig1.3)** 中的趋势。很明显，`R` 仍然是机器学习的第二佳语言，自 2016 年以来需求不断增长。

### 1.6 | R 安装 - 入门

在本节中，我们讨论 `R` 的安装以及如何开始使用 `R`。 `R` 是一个开源（免费）的统计分析和图形软件环境，可在 `UNIX`、`Windows` 和 `MacOS` 等操作系统和平台上使用。 `R` 提供了执行多种统计和机器学习模型的软件包。

综合 `R` 档案网络 (`CRAN`) 是一个存储库，托管 `R` 软件以及可能需要的数千个软件包，用于执行统计计算和图形。 `R` 主页的快照显示在 **[图 1.4](#09_Chapter01.xhtml#fig1.4)** 中。

![](images/page7-02.png)

要下载 `R`，请执行以下步骤：

**1.** 前往 [`https://cloud.r-project.org`](https://cloud.r-project.org)

**2.** 根据您机器的操作系统选择下载链接。

**3.** 点击下载的文件并按照步骤在您的机器上下载兼容版本。

直接在 `R` 软件上工作可能不是一个方便的选择，因此交互式开发环境 (`IDEs`) 为数据科学家提供了一个集成框架，以便更轻松地编写和调试代码。 `IDEs` 通常是语言无关的，这意味着同一个 `IDE` 可能让数据科学家能够使用 `IDE` 支持的任何语言编写代码。

### 1.7 | RStudio

`RStudio` 就是这样一个 `IDE`，它使 `R` 编程语言更易于使用。 `RStudio` 由控制台、用于直接代码执行的语法高亮编辑器以及图形、调试和工作区管理工具组成。当前版本的 `RStudio` (`Version 1.2.1335`) 使用户能够在同一个代码编辑器中编写 `R` 代码或 `Python` 代码或执行命令行脚本。

`RStudio` 提供两种选项：

**1.** **RStudio 桌面版：** 这是开源版，提供本地访问 `RStudio` 的系统。它具有语法高亮、代码补全和智能缩进。一些实用功能包括（*来源*: rstudio.com）：

• 能够直接从源编辑器执行 `R` 代码

• 易于使用的函数定义

• 使用项目管理多个工作目录的便利性

• 集成 `R` 帮助和文档

• 交互式且用户友好的调试器，可轻松诊断和修复错误

• 强大的软件包开发工具。这是独立用户进行统计计算的首选版本。

**2.** **RStudio 服务器版：** 它具有桌面版的所有功能。它是商业许可版本，适用于因内部政策无法使用开源许可版本的组织。它提供优先电子邮件支持，并在工作时间内八小时响应。

要下载 `RStudio`，请执行以下步骤：

**1.** 前往 [`https://www.rstudio.com/products/RStudio`](https://www.rstudio.com/products/RStudio)/。`RStudio` 主页的快照显示在 **[图 1.5](#09_Chapter01.xhtml#fig1.5)** 中。

**2.** 点击链接下载 `RStudio` 桌面版。

**3.** 在后续页面中，点击链接下载与您机器操作系统兼容的免费桌面版。

**4.** 点击下载的文件并按照步骤在您的机器上安装兼容版本。

请注意 `RStudio` 与 `R` 软件之间的版本兼容性。下载 `RStudio` 的第 3 步将说明在尝试下载 `RStudio` 之前需要预先安装哪个版本的 `R`。[⁶](#09_Chapter01.xhtml#ch1-r-fn6)

有关 `RStudio` 的更多信息可在 [`http://docs.rstudio.com/ide/server-pro`](http://docs.rstudio.com/ide/server-pro)/ 找到。
