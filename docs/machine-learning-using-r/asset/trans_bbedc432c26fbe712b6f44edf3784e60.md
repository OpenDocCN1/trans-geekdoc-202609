### 5.10.7 转换响应变量

转换是通过推导新的因变量和/或自变量来识别回归模型正确函数形式的过程（Kumar, 2017）。例如，因变量 `Y` 在模型中可以用 `ln(Y)`、`1/Y` 等替换；同样，自变量 `X` 可以用 `ln(X)`、`1/X` 等替换。MLR 中的转换用于解决以下问题：

**1.** 拟合不佳（`R-squared` 值低）。

**2.** 残差分析中出现模式，表明因变量与自变量之间存在潜在的非线性关系。

**3.** 残差不服从正态分布。

**4.** 残差不是同方差的。
