
## Step 2: Preprocess the Data
Before the model is built, it is essential to ensure the quality of the data on such issues as reliability, completeness, usefulness, accuracy, missing data, and outliers. Data imputation techniques may be used to deal with missing data. Descriptive statistics and visualization (such as box plot and scatter plot) may be used to identify the existence of outliers and variability in the dataset. Many new variables (such as ratio or product of variables) can be derived (aka feature engineering) and used in model building. Categorical data has to be preprocessed using dummy variables (part of feature engineering) before it can be used in the regression model. Note that, in R, some of the algorithms (such as regression using `lm()` function from `stats` package) implicitly carry out dummy variable coding.

## Step 3: Dividing Data into Training and Validation Datasets
In this stage, the data is divided into two subsets (sometimes more than two): training dataset and validation or test dataset. The proportion of training dataset is usually between 70% and 80% of the data; the remaining is treated as validation data. Subsets may be created using random/stratified sampling procedure. This is an important step to measure performance of the model outside the data used for model building. It is also essential to check any overfitting of the model. In many cases, multiple training and multiple test data can be used (called k-fold cross-validation).

## Step 4: Perform Descriptive Analytics or Data Exploration
It is always a good practice to perform descriptive analytics before moving to predictive analytics model building. Descriptive statistics will help us understand the variability in the features and visualization of the data through, say, a box plot which can be used to identify if there are outliers in the data. Another visualization technique, the scatter plot, may also reveal if there is any obvious relationship between the two variables under consideration. Scatter plot is useful to describe the functional relationship between the dependent or outcome variable and features.

## Step 5: Build the Model
Build the model using the training dataset to estimate the regression parameters. The method of Ordinary Least Squares (`OLS`) is used to estimate the regression parameters. `OLS` is explained later in the chapter.

## Step 6: Perform Model Diagnostics
Regression is often misused since many times necessary diagnostics tests are not performed before applying the model. Before it can be applied, it is necessary that the model is validated for all model assumptions including the definition of the functional form between outcome variable and feature. If model assumptions are violated, remedial measures must be employed.

## Step 7: Validate the Model and Measure Model Accuracy
A major concern in analytics is overfitting, that is, the model may perform very well in the training dataset but badly in validation dataset. It is important to ensure that the model performance is as consistent in the validation dataset as it was in the training dataset. In fact, the model may be cross-validated using multiple training and test datasets.

## Step 8: Decide on Model Deployment
The final step in the regression model is to develop a deployment strategy in the form of actionable items and business rules that can be used by the organization.
