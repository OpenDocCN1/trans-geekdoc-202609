## 5.5 模型诊断

在模型用于实际应用之前，验证回归模型以确保其有效性和拟合优度非常重要。以下度量用于验证简单线性回归模型（Kumar, 2017）：

**1.** 决定系数（R 平方）。

**2.** 假设检验以检查回归系数的统计显著性。

**3.** 方差分析用于整体模型有效性（更适用于多元线性回归）。

**4.** 残差分析以验证回归模型假设，如正态性和同方差性。

**5.** 异常值分析。
