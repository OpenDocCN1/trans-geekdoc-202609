## 9.7.8 计数向量 vs. 带词干提取和词形还原的计数向量 vs. TF-IDF 向量

计数向量、带词干提取和词形还原的计数向量以及TF-IDF向量是创建BoW模型中词嵌入的三种不同方法。这三种衡量词语重要性的方法最终有助于为文档创建词向量。文档中词语的排名会根据所选的度量而变化。让我们深入研究用户‘PIBImphal的推文。对于PIBImphal，`twitter_word_count`、`twitter word stem count`和`twitter word tf count`中的词数为551。对于PIBImphal，让我们比较[表9.30](#17_Chapter09.xhtml#tab9.30)和[9.31](#17_Chapter09.xhtml#tab9.31)：

**1.** 未进行词干提取和词形还原的[表9.30](#17_Chapter09.xhtml#tab9.30)显示‘church’和‘urges’是按`n`排序的前六条记录中的两个词。

**2.** 进行词干提取和词形还原的[表9.31](#17_Chapter09.xhtml#tab9.31)显示‘appeal’和‘minist’是按`n`排序的前六条记录中的两个词。

![](images/page391-01.png)![](images/page391-02.png)![](images/page391-03.png)![](images/page392-01.png)

词干提取和词形还原过程将词语

**1.** ‘appeals’和‘appealed’还原为其词根形式‘appeal’，从而增加了‘appeal’的计数。

**2.** ‘minister’和‘ministers’还原为其词根形式‘minist’，因此计数为八。

这导致[表9.30](#17_Chapter09.xhtml#tab9.30)中的最后两条记录被剔除，并清楚地表明了词语排序可能因词干提取和词形还原而发生变化。

使用TF-IDF有助于提取在同一主题上发推的用户集合中特定用户（`screenName`）的特征词。为了验证该说法，让我们比较[表9.30](#17_Chapter09.xhtml#tab9.30)和[9.32](#17_Chapter09.xhtml#tab9.32)：

**1.** 未进行词干提取和词形还原的[表9.30](#17_Chapter09.xhtml#tab9.30)显示‘follow’和‘peopl’是按`n`排序的前七条记录中的两个词。

**2.** 进行词干提取和词形还原并加上TF-IDF的[表9.32](#17_Chapter09.xhtml#tab9.32)显示‘church’和‘pastor’是按`n`排序的前七条记录中的两个词。

基于TF-IDF，我们可以在[表9.32](#17_Chapter09.xhtml#tab9.32)中看到‘church’和‘pastor’等词，这在PIBImphal的推文中更相关，而‘follow’和‘people’等词可能已被语料库中的许多用户使用。在[表9.30](#17_Chapter09.xhtml#tab9.30)中，计数为13的‘follow’未能进入[表9.32](#17_Chapter09.xhtml#tab9.32)中的前七条记录。与此同时，仅有六次计数的‘pastor’在[表9.32](#17_Chapter09.xhtml#tab9.32)中排名高于minist（表格按TF-IDF升序排序）。
