
`sample_rate_per_class`: This parameter is optional and is a substitute for `sample_rate` (either one can be used). For each tree in the ensemble model, this parameter can be used to control the proportion of rows, which needs to be sampled without replacement for each class. The parameter expects a list to be passed with the value between 0 and 1 (relative fraction of rows). The range for this option is 0.0 to 1.0. Note that this method is sample without replacement (*Source:* docs.h20.ai).
While using `sample_rate_per_class` parameter, `balance_classes` and `class_sampling_factors` may be ignored. In the NPS prediction case, `sample_rate_per_class` seems to give a better result than using any combination of `balance_classes` and `class_sampling_factors` parameter.

### 8.7.4 | Control Growth
Following are the parameters that can lead to controlling the growth of the tree (*Source:* docs.h2o.ai):
1. `min_split_improvement` – This parameter can be used to reduce overfitting by restricting the growth of the tree. The value of this parameter signifies the minimum change in the in squared error to split a node into two. The default value is set to `10^(-5)`. The optimal values for this parameter can be in the range of `10^(-10)` to `10^(-3)`.
2. `max_depth` – This is another parameter used to reduce overfitting. It is used to control the depth to which a tree can grow. A higher value for this parameter will lead to a more complex tree. If the value is set to zero mean no limit to grow the tree (highly complex tree). The default is set to `5`.
3. `min_rows` – This parameter specifies the minimum number of observations to be present in the leaf node. The default is set to `1` which may lead to overfitting issues.
4. `learn_rate` – This parameter takes a value between 0 and 1 and is used to specify the learning rate.
5. `learn_rate_annealing` – This parameter works in conjunction with `learn_rate` and is used to reduce the `learn_rate` by a fixed factor after every tree. If there are `N` trees in the model, then GBM will start with `learn_rate` and will end at `learn_rate * learn_rate_annealing ^ N`.
