## 3.5.8 Lay Out Panels in a Grid
We can create panel of plots using `facet_grid()` from `ggplot`. Facet in general means ‘a particular aspect or feature of something’. When we say we want to create a plot with faceting variable as `AGE` and `PLAYING_ROLE`, it means we want to visualize the plot with `AGE` and `PLAYING_ROLE` as two more dimensions of the data.

`facet_grid()`, forms a matrix of panels defined by row and column faceting variables (Anon, 2021). It is most useful when there are two discrete variables in the data and all combinations of the variables also exist.
