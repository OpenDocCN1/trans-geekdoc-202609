
2. Total the individual values of the `curves` to compute the value of the `density` at each point of the given `dataset`. This will result in an overall density curve.

3. Normalize the resulting curve, so that the area under it is equal to 1.

4. The resulting curve is kernel PDF or density and is depicted by density plot.

To draw the density plot, we can use `geom_density` which computes and draws kernel density estimate. `geom_density()` internally uses `stat_density()` in which some of the parameters playing an important role in estimating the PDF are set by default to:

1. `kernel="gaussian"`. Type `?density` on the console to get the list of all the kernel which can be passed.

2. `bandwidth="nrd0"`

3. `adjust = 1`. The multiplicative factor by which bandwidth can be adjusted.

4. `n=512`. The number of equally spaced points at which the density is to be estimated, the value of `n` should be a power of two, one can use `?density` for additional details.

### 3.5.5 Box Plot

Box plot (aka Box and Whisker plot) is a graphical representation of numerical data that can be used to understand the variability of the data and the existence of outliers. In this section, we will discuss codes used to generate Box plot. Let us consider the variable `SOLD_PRICE` of the players. The steps which can be used to generate the box plot and identify outliers in data are as follows:

1. Arrange data in ascending order. The number of observations in `SOLD_PRICE`, arranged in chronological order (ascending) is

![](images/page79-03.png)![](images/page80-01.png)

The count of number of observations in the sorted data is 130.

![](images/page80-02.png)

2. Calculate the median of the data. This is called as (quartile 2). If the number of observations in the data is `n`, then median is calculated using the following logic in which the data is arranged in ascending order:

• If `n` is odd, then the middle value is observation at `(n+1)/2` position in the sorted data.

• If `n` is even, the middle value is the average of middle two numbers i.e. observation at `floor((n+1)/2)` position and `ceiling((n+1)/2)` position.

Since the data has 130 observations (even) in `SOLD_PRICE`, it falls under the second rule. The middle value is the average of values at index position 65 `floor((obs + 1)/2)` and index position 66 `ceiling((obs + 1)/2)`.

![](images/page80-03.png)

3. Calculate the median of the first half of the data. This is `Q1` (quartile 1). In the `ipl_sorted_dt` the number of observations in the first half is 64. Since this is an even number of observations, the second rule of step 2 applies.

![](images/page80-04.png)![](images/page81-01.png)

4. Calculate the median of the second half of the data. This is `Q3` (quartile 3). In the `ipl_sorted_dt` the number of observations in second half is 64. Since this is an even number of observations, the second rule of step 2 applies.

![](images/page81-02.png)

5. The box joins `Q1` to `Q3` (contains middle 50% of data). The other statistics calculated are as follows:

1. Inter-quartile range (`IQR`) is the distance (difference) between the 3^(rd) quartile and 1^(st) quartile. The length of the box is equivalent to `IQR`. `IQR` is calculated as `IQR = Q3 - Q1`.

2. Lower interval fence which is `LIF = Q1 - 1.5*IQR`

3. Upper interval fence which is `UIF = Q3 + 1.5*IQR`

![](images/page81-03.png)

6. In the `ipl_sorted_dt`, the smallest observation greater than or equal to `LIF` is 20,000 (lower whisker) and the largest observation less than or equal to `UIF` is 135,000 (upper whisker). The whisker spreads from lower whisker to `Q1` and `Q3` to upper whisker. All observations outside the lower and upper whiskers are called outliers.

![](images/page82-01.png)

In `ipl_sorted_dt`, there are no outliers on the lower whisker side as there is no point outside the lower whisker. However, there are four unique values which are greater than the upper whisker. They are 1,500,000; 1,550,000; 1,600,000; 1,800,000.

Interpretation of box plot:

1. If the plot has wide box and long whiskers, then the data has a lot of variation.

2. If box is small and the whiskers are short, then the data has less variation and cluster together.

3. If box is small and the whiskers are long, then maybe the data has less variation, but may have some ‘outliers’.

The box plot on `ipl_dt` can be created by using `geom_boxplot`. **[Figure 3.25](#11_Chapter03.xhtml#fig3.25)** shows the box plot for `SOLD_PRICE`. The outliers above the upper whisker are marked with black points.

![](images/page82-02.png)

The box plot can be split by another categorical feature. **[Figure 3.26](#11_Chapter03.xhtml#fig3.26)** shows a box plot by `PLAYING_ROLE`.
