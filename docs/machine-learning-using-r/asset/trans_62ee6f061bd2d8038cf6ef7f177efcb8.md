
# 集成方法

集成方法是一种学习算法，它接收一组估计器或分类器（模型），并使用诸如多数投票等策略对新的数据点进行分类。多数投票可以基于简单地统计每个分类器的投票，也可以基于分类器的准确率进行加权。集成方法也用于回归问题，其中新数据的预测是来自一组回归模型的所有预测的简单平均值或加权平均值，如 **[图 8.1](#16_Chapter08.xhtml#fig8.1)** 所示。

在 **[图 8.1](#16_Chapter08.xhtml#fig8.1)** 中，`K` 和 `N` 是原始集合中特征数和记录数，而 `k` 和 `n` 是采样集合中特征数和记录数。需要注意的是，构建多个分类器（模型）需要多个数据集（使用不同的特征和记录）。但在实践中，总有一个训练集可用。我们可能必须采用某些策略，为学习算法提供训练集的不同子集（视图）。

1. 策略如自助采样（训练数据的有放回随机样本）可用于创建训练集的多个子集。自助法与‘随机子空间方法’结合也用于特征子集的随机选择。这种自助法与随机子空间方法相结合的思想是随机森林算法的起源，并使其有别于早期的袋装算法（这些算法是未应用随机子空间方法的剪枝决策树分类器）。

2. 另一种可采用的策略是通过为训练数据的观测值分配权重，并向学习算法提供权重更高的观测值。一般来说，Boosting 算法在学习过程中依赖于这一策略。

![](images/page286-01.png)

创建训练数据的不同子集视图类似于为学习算法创建不同的经验，使其可以从中学习有用的模式。创建训练数据不同子集的这一概念与 [第 7 章](#15_Chapter07.xhtml) 中给出的机器学习的正式定义相联系。在本章中，我们将主要研究随机森林、自适应提升和极端提升。然而，我们还将对可使用 `R` 实现的其他袋装和提升算法提供一些见解。

## 8.2 | 随机森林

随机森林（通常称为 Bagging）是使用不同采样策略开发若干棵树（因此得名‘森林’）的流行集成方法之一（Breiman, 1996, 2001）。[¹](#16_Chapter08.xhtml#ch8-r-fn1) 最常用的采样策略之一是 **Bootstrap 聚合**（或 **Bagging）。** Bagging 是有放回的随机采样。利用数据和特征的样本，随机森林开发多个分类模型（通常是树）。在连续结果变量（回归问题）的情况下，各种基础学习器的预测结果会被平均。在离散结果变量（分类问题）的情况下，新观测值通过多数投票进行分类。在他的开创性工作中，Breiman (1994, 2001) 认为随机森林（`RF`）在真实和模拟数据集上的回归和分类问题中都实现了显著的准确率提升。数学上，`RF` 是学习器 {`L`[`k`](`X`, `T`[`k`])} 的集合，`k` = 1, 2,…, `N`}。`X` 是输入集合，`T`[`k`] 是独立同分布的样本，学习器（或分类器）`L`[`k`](`X`, `T`[`k`]) 在其上开发。

随机森林是按照以下步骤开发的（Kumar, 2017）：

1. 假设训练数据有 `N` 个观测值。需要生成若干个大小为 `M`（`M` ≤ `N`）的有放回样本（Bootstrap 聚合或 Bagging）。设基于训练数据集采样得到的样本数为 `K`，即树的数量为 `K`。

2. 如果数据有 `n` 个预测变量，则采样 `m` 个预测变量（`m` < `n`）。此步骤用于使树相互独立。

3. 使用步骤 2 中的预测变量样本为步骤 1 中生成的每个样本开发树。如果结果变量是离散的，则开发分类树；如果结果变量是连续的，则开发回归树。

4. 对步骤 1 中生成的所有样本重复步骤 3。

5. 在分类情况下使用多数投票预测结果变量值，在连续结果变量情况下使用预测值的平均值。

### 8.2.1 袋外数据

使用 Bootstrap 聚合程序的一个优点是它提供了称为 `Out-of-Bag (OOB)` 数据的验证数据。在一个基础模型中，至少有 (`N`-`M`) 条记录不会参与模型构建；不属于基础模型的部分记录称为袋外数据。考虑一个有 20 条记录的数据集，标记为 1, 2 起，直至 20。设从这 20 条记录中生成大小为 10 的自助样本。一些可能的样本显示在 **[表 8.1](#16_Chapter08.xhtml#tab8.1)** 中。

在 **[表 8.1](#16_Chapter08.xhtml#tab8.1)** 中，样本 1 由记录 {7, 8, 9, 6, 2, 3, 3, 4, 17, 19} 组成，即记录 {1, 5, 10, 11, 12, 13, 14, 15, 16, 18, 20} 不属于样本 1；这些记录对样本 1 来说是袋外的。记录 16 在任何样本中都不存在，因此可以用作使用 **[表 8.1](#16_Chapter08.xhtml#tab8.1)** 中列出的样本生成的全部五个基础模型的测试数据。所有不属于某棵树训练数据的情况都可作为验证数据使用，这类情况称为 Out-Of-Bag 数据。随机森林模型使用 `Out-of-Bag (OOB)` 数据作为验证数据进行验证，因此不需要单独的验证数据。大约 33% 的数据不参与构建 `RF` 中的基础模型。然而，许多数据科学家仍然创建单独的验证数据。

### 8.2.2 使用随机森林预测净推荐值（NPS）

我们将通过净推荐值（`NPS`）预测的例子讨论随机森林方法。`NPS` 可用作衡量客户忠诚度的领先指标，基于一个问题 – 您有多大可能向朋友或同事推荐我们的公司或产品/服务？

客户在 0 到 10（11 点）量表上对回答进行评分。高度满意的客户很可能给出 9 或 10 分，被称为推荐者；被动客户给出 7 或 8 分，而那些给出 6 分及以下的则为贬损者。

![](images/page287-02.png)

将推荐者的百分比减去贬损者的百分比得出一个单一数字 – 公司的 `NPS`。贬损者很可能在朋友和同事中传播对组织的负面情绪。

#### 示例 – 随机森林模型开发

All India Electronics（`AIE`）是电子小工具的领先制造商，业务面向 B2B 领域。它为其向客户销售的设备提供预防性以及纠正性维护服务。客户满意度是业务增长的关键，`AIE` 的管理层希望改善其目前的 `NPS` 评分，该评分目前为 49%。
