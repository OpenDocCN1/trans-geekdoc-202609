# TABLE 3.2
# Various Time-Domain Features and Their Formula

| Time-Domain Features | Formula |
| :--- | :--- |
| Mean ($\mu$) | $\mu = \frac{1}{N} \sum_{i=1}^{N} x_i$ |
| Variance (Var) | $\text{Var} = \frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^2$ |
| Standard Deviation ($\sigma$) | $\sigma = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^2}$ |
| Root Mean Square (RMS) | $\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}$ |
| Peak-to-Peak Amplitude (P-to-P) | P-to-P = $max(x_i) - min(x_i)$ |
| Skewness ($S$) | $S = \frac{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^3}{\sigma^3}$ |
| Kurtosis ($K$) | $K = \frac{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^4}{\sigma^4}$ |
| Crest factor (CF) | $\text{CF} = \frac{max(x_i)}{\text{RMS}}$ |
| Energy ($E$) | $E = \sum_{i=1}^{N} x_i^2$ |

# TABLE 3.3
# Various Frequency-Domain Features and Their Formula

| Frequency-Domain Features | Formula |
| :--- | :--- |
| Discrete Fourier Transform/DFT ($X(f_k)$) | $X(f_k) = \sum_{n=0}^{N-1} x(n) e^{-j2\pi kn/N}$ |
| Power Spectral Density (PSD) | $\text{PSD}(f_k) = \frac{|X(f_k)|^2}{N}$ |
| Peak Frequency | Peak Frequency = $f_k$ where max $|X(f_k)|$ |
| Spectral Bandwidth | Spectral Bandwidth = $\sqrt{\frac{\sum_{k=0}^{N-1} (f_k - C)^2 |X(f_k)|}{\sum_{k=0}^{N-1} |X(f_k)|}}$ |
| Spectral Entropy | Spectral Entropy = $- \sum_{k=0}^{N-1} P(f_k) \log_2 P(f_k)$ |
