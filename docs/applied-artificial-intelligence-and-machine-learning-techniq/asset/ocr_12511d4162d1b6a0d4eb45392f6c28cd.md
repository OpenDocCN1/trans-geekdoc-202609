# 10.2.2.12 Model Response

As discussed in Section 10.2.2, the input prompt is decoded by the model and a response is generated. The response is based on probability distribution, contextual background and sampling strategy.

# 10.2.2.13 User Follow-Up

There are two possible states for the users. Either the user is satisfied with the response or the user is unsatisfied. If the user is satisfied, then the conversation might end or else a new conversation can be started by giving a different input. If the user is unsatisfied with the response, then by giving follow-up prompts the conversation might proceed.
