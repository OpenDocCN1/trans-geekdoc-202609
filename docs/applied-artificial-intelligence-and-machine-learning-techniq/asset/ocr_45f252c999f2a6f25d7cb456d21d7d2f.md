```
x[n] = \frac{BE - DH}{1 + E + H}
```

Now considering that H = (n - 1)E, and E = f(x[n]) = \frac{x[n]}{1 + x[n]}, we can write

```
x[n] = \frac{(B - (n - 1)D)f(x[n])}{1 + nf(x[n])}
```

Using Equation 9.4, we can write

```
(1 + n)x[n] = (B - (n - 1)D + n)f(x[n])
```

Using Equation 9.3 allows us to calculate steady-state activation as

```
x[n] = \frac{(B - 1 - (n - 1)D)}{1 + n}
```

# 9.2.2 STABILITY ANALYSIS: NON-DIVERGENCE

In order for stable steady-state activity, we must also have a non-divergence condition added to our stability analysis. If x_i and x_j are activities of i - th and j - th node respectively, then the non-divergence condition becomes \frac{d(\Delta x)}{dt} and needs to have a negative slope, where \Delta x = x_i - x_j.

Following Equation 9.2 we have (using Equation 9.4)

```
\frac{d(\Delta x)}{dt} = -\Delta x - \Delta x \sum_k^N f(x_k) + (B + D)(f(x_i) - f(x_j))
= -\Delta x - (B + D)\Delta x(\frac{f(x_i)}{x_i}\frac{f(x_j)}{x_j}) - \Delta x \sum_k^N f(x_k)
```

This can simplified using Equation 9.4. Moreover, we take advantage of the fact that near steady-state f(x_i) \rightarrow f(x[n]). Thus we have

```
\frac{d(\Delta x)}{dt} = \Delta x | 1 - nf(x[n]) - (B + D)(\frac{f(x[n])}{x[n]})^2 |
```

With a substitution a = B + D - nD, and considering that non-divergence requires that the coefficient of \Delta x to be less than 0, we can write using Equations 9.7 and 9.8 (as

```
1 + nf(x[n]) = a \frac{f(x[n])}{x[n]} \text{ and } \frac{f(x[n])}{x[n]} = \frac{1 + n}{a + n}
```
