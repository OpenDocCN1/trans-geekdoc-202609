# Creating the Main Movie Listing Page

We start by creating an `index.php` page that lists all the movie titles in the `movieListing` table of the `Movie` database.

# Laying Out the Main Page

To make our page look clean, I use the Bootstrap[^2] CSS framework and use a striped table. Figure 15.13 shows what we want our main movie listing to look like.
