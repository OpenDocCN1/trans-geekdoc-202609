# Sorting

After populating an array, you may need to work with it in sorted order. asort()[10] will reorder an array with the values in sorted order and preserve the key-value pairs. Listing 6.7 is an example where that resorts U.S. state capitals in alphabetic order.

Listing 6.7.

```
$us_state_capitals = [
    "California" => "Sacramento",
    "Florida" => "Tallahassee",
    "Wisconsin" => "Madison"
];

asort($us_state_capitals);

echo "<pre>";
print_r($us_state_capitals);
echo "</pre>";
```

Results in:

```
Array
(
    [Wisconsin] => Madison
    [California] => Sacramento
    [Florida] => Tallahassee
)
```

> *PHP provides many built-in functions for sorting arrays. For example, if you need to reverse sort an array, use arsort()[11]. For a complete list, see “Sorting Arrays”[12].*
