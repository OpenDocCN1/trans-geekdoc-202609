# Create a Test Database User and Database

By default, we cannot access MySQL databases using the root account. This default is a robust security constraint. For us to use Adminer—or PHP for that matter—to access our databases, we need to use the MySQL command-line interface (CLI) tool as root to create a database user account and grant access to that user to a database.
