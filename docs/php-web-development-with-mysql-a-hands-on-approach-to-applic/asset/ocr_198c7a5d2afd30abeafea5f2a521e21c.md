# 7. Truth, Comparisons, Conditions, and Compound Conditions

# Exercises

Create a script `comparisons.php` for the following:

+   1. Use $x = random_int(1,10) to pick a number between 1 and 10. Output the value of $x. Then indicate if it is between 3 and 7 inclusive.
+   2. Use $x = random_int(1,10) to pick a number between 1 and 10. Output the value of $x. Indicate if it's less than 3, between 3 and 7 inclusive, or greater than 7.
+   3. Redo the previous exercise using compound conditional statements.
