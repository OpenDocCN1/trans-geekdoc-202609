# Deleting Database Entries with PDO

Finally, let’s look at what a delete() method should look like. See Listing 26.31.

Listing 26.31.

```
1. public function delete($id)
2. {
3.     $db = new PDO(self::DSN, self::DB_USER, self::DB_PASSWORD);
4. 
5.     // Delete a record
6.     $sql = "DELETE FROM student WHERE id=:id";
7. 
8.     $db->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
9. 
10. try
11. {
12.     $query = $db->prepare($sql);
13.     $query->bindParam(":id", $id, PDO::PARAM_INT);
14.     $query->execute();
15.     $rows_affected = $query->rowCount();
16. }
17. catch(Exception $ex)
18. {
19.     echo $ex->getMessage() . "<br/>";
20. }
21. 
22. return $rows_affected; // Returns the number of rows affected by the DELETE
23. }
```

Since we need to pass in the id as a parameter to delete(), we need to parameterize it as indicated on lines 6 and 13. As we did in the update() method, we will return the number of rows affected by the DELETE.
