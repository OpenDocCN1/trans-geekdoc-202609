# continue

Use the continue command in a loop if you want to skip the rest of the current iteration and continue to the next. See Listing 9.4 for an example that skips every third iteration of a loop.

Listing 9.4.

```
<?php
$random_words = ['one', 'two', 'three', 'anxious', 'ecstatic'];

for ($i = 1; $i <= 9; i++)
{
    if ($i % 3)
    {
        continue;
    }

    echo "$i<br/>";
}
```

This loop produces the following output:

```
1
2
4
5
7
8
```
