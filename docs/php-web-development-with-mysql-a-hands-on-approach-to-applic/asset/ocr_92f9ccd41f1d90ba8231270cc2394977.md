As long as there is an access modifier (private, protected, or public) preceding the variable in the constructor's parameter list, PHP will create the properties under the hood, and assign the values passed into the parameter list. You can still directly access the properties in the class using the this keyword.

Details are buried in the PHP manual section on constructors[9]. For in-depth information, you can refer to the Request for Comments (RFC) for constructor property promotion[10] that was approved for PHP 8 on the PHP manual Wiki if you'd like to know more.
