## 练习

- 1. 创建一个“添加电影”页面，其中包含一个表单，允许用户在数据库中插入电影。
  - 1. 确保用户提交标题、评分、导演、播放时长和类型。
  - 2. 在电影列表页面上放置一个“添加电影”按钮。
- 2. 向表单中至少添加一种新的电影类型。确保数据保存到数据库中。在详情页面上显示所选的值（如果已选择）。
- 3. 向表单中添加电影发行年份的字段。允许从 1900 年到未来十年内的年份。确保数据保存到数据库中。在详情页面上显示发行年份。
