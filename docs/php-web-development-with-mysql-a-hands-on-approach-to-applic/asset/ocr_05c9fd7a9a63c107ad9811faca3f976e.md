# Create a PHP Application to Insert Data

What is cool about PHP is that it lets you easily insert data into your MySQL database. PHP provides several ways for accomplishing this. One way is using mysqli function calls, and another is PHP Data Objects (PDO). PDO is a more object-oriented way of interacting with your database. For this example, we’ll use the mysqli[5] functions.

Let’s take our self-referencing postfullname.php script from chapter 11 and modify it to insert the first and last name into the fullName table of our FullName database. Listing 12.1 shows our initial form.
