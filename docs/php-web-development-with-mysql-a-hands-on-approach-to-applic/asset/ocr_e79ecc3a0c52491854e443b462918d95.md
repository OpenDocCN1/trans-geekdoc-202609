# 23. ADDING USER LOGINS

Notice, I call the session_start()[6] function since we will be creating session variables for a user after a successful login. Also notice I added a definition for the page title that is included from the script called pagetitles.php:

```
<!DOCTYPE html>
<?php
session_start();
require_once('pagetitles.php');
$page_title = MR_LOGIN_PAGE;
?>
```

Add the definition for the Login page to pagetitles.php:

```
<?php
// Page Titles
define('MR_SIGNUP_PAGE', 'Movie Reservations - Sign Up');
define('MR_LOGIN_PAGE', 'Movie Reservations - Login');
```
