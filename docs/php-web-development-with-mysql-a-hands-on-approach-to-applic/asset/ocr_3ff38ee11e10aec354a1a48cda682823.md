Again, let’s look at this on its own:

```
<?php if (isset($_SESSION['user_access_privileges'])
    && $_SESSION['user_access_privileges'] == 'admin'): ?>
<a class="nav-item nav-link<?= $page_title == MR_ADD_MOVIE_PAGE ? ' active' : '' ?>"
   href="addmovie.php">Add a Movie</a>
<?php endif; ?>
```

As in a previous example, we have two conditions here. The first (outer condition) checks to see if the user has admin privileges.

> > *Incidentally, this condition also checks to see if the user is logged in, as $_SESSION['user_access_privileges'] is only set when the user logs in.*
