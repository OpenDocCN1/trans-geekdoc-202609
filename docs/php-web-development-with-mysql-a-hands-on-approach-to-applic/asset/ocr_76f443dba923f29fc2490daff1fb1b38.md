Now we need to add a nav link item to the addmovie.php page and have addmovie.php include navmenu.php. We only want to display a link to the “Add a Movie” page when logged in as a user with admin privileges. We want our nav menu to look like Figure 24.9 when we are on the home page and have admin privileges. And when we are on the “Add a Movie” page, we want our menu to look like Figure 24.10.
