# pow()

The pow() function returns the first argument raised to the power of the second argument:

```
echo pow(10, 3) . '<br/>'; // 1000
echo pow(10, -1) . '<br/>'; // 0.1
```

This outputs:

```
1000
0.1
```

# round()

The round() function returns the rounded value of a given argument by a default or given precision in number of digits after the decimal point. If a precision is not specified, the default precision is 0:

```
echo round(4.4) . '<br/>'; // 4
echo round(4.5) . '<br/>'; // 5
```

Outputs:

```
4
5
```

See the online docs for more information on the Math Functions[4].
