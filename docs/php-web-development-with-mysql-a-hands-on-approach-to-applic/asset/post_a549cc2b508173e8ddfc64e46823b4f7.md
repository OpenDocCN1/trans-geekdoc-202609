### Creating an Array with Checkboxes for Genre

A movie can fit into multiple genres. Since we want to include various selections for “Genre,” we need to use checkboxes (Figure 16.4). It also cuts down on duplication of HTML markup if we create an array containing our genres.

![](img/83a2e1d9463a10cf8d6f7fe54ee4b1c7_181_0.png)

Listing 16.3 shows what the PHP code and HTML markup look like for “Genre”.

### Listing 16.3.

```
<?php
$genres = [
    'Action', 'Adventure', 'Comedy', 'Documentary', 'Drama',
    'Fantasy', 'Horror', 'Romance', 'Science Fiction'
];
?>
// ...
<?php
foreach ($genres as $genre)
{
?>
<div class="form-check form-check-inline col-sm-3">
    <input class="form-check-input" type="checkbox"
        id="movie_genre_checkbox_action"
        name="movie_genre_checkbox[]"

        for="movie_genre_checkbox_action"><?= $genre ?></label>
</div>
<?php
}
?>
```

The previous code and markup create a checkbox input for each item in our genres array. Every genre checked by the user gets added to the movie_genre_checkbox array (note the [] added to the name attribute). Be aware that if the user does not select any genre, the movie_genre_checkbox name attribute will not exist in the $_POST[] superglobal array.
