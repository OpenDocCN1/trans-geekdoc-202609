# Displaying Movie Image on Details Page

Since we are using Bootstrap's Flexbox grid implementation, it is best to encapsulate the image and table in separate columns and put them both in a single row, all just below the movie title located in the <h1> element:

# Listing 19.22.

```
<h1><?= $row['title'] ?></h1>
<div class="row">
  <div class="col-2">
    <img src="<?= $movie_image_file ?>" class="img-thumbnail"
         style="max-height: 200px;" alt="Movie image">
  </div>
  <div class="col">
    <table class="table table-striped">
      ...
    </table>
  </div>
</div>
```

Again, notice we set the style attribute to a maximum height of 200 pixels.
