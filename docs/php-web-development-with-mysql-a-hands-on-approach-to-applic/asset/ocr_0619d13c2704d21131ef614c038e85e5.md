# *Use a Databases*

Let’s verify we imported the Northwind database correctly. To work with a database, we need to issue an SQL command indicating we want to use it. At the mysql> prompt type:

```
```sql
USE northwind;
```
```

# *Show Tables*

We can show all the tables in the northwind database by issuing the following SQL command:

```
```sql
SHOW TABLES;
```
```

You should see output like Figure 12.10.

![](bbox=[0.694, 0.256, 0.902, 0.556])

# *Describe a Table*

Let’s say we are interested in finding out more information about the structure of the products table. We can describe all the fields (or columns) in a table by issuing the following SQL command:

```
```sql
DESCRIBE products;
```
```

Figure 12.11 shows the output.

DESCRIBEing a table shows the Field names in order, their data types, and other important information regarding the table.
