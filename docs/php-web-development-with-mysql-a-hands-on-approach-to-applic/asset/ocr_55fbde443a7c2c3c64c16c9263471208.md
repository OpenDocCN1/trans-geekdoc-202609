# Installing and Testing Apache

In the terminal window, install Apache using the apt installation package manager by running the following command as superuser:

```
sudo apt install apache2
```

You will need to type Y or press Enter to accept the changes (Figure 2.10).

To ensure Apache is running, run the following command in the terminal window as superuser. You should see output as shown in Figure 2.11.

```
sudo systemctl status apache2
```

Type the q key to exit the systemctl status command.
