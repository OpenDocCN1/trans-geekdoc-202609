# 15. DISPLAYING A LIST OF ITEM DETAILS

Add the following listing data for *Deadpool*:

+   - *title*: Deadpool
+   - *rating*: R
+   - *director*: Tim Miller
+   - *running_time_in_minutes*: 108
+   - *genre*: Action, Adventure, Comedy

Select **Save and insert next** for the first two movie listings. Doing so saves the data and refreshes the data entry form. Press **Save** for the last one (Figure 15.11).

After selecting *Save*, the *Select: movieListing* page is displayed (Figure 15.12), showing all the movie listings you entered.
