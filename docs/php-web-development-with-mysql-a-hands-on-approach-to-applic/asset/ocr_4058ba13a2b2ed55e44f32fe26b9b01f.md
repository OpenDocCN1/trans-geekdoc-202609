Let’s take a look at a portion of the vulnerable code:

```
$search_term = isset($_POST['search']) ? $_POST['search'] : '';
?>
<h2>Stuff you might be interested in as a result of searching for
<span class="text-danger"><?= $search_term ?></span>...</h2>
```

We’re not sanitizing the input from our search field of HTML entities like <, >, ", and other special symbols. As a result, we allow HTML markup and JavaScript code to execute.
