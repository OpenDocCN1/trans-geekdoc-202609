# 6. ARRAYS

# array_values()

In order to get all of the values for an array, you can use the array_values()[8] function as follows in Listing 6.4.

Listing 6.4.

```
```php
$us_state_capitals = [
    "California" => "Sacramento",
    "Florida" => "Tallahassee",
    "Wisconsin" => "Madison"
];
echo "<pre>";
print_r(array_values($us_state_capitals));
echo "</pre>";
```
```

Results in:

```
Array
(
    [0] => Sacramento
    [1] => Tallahassee
    [2] => Madison
)
```

# array_splice()

array_splice()[9] is a useful function that we can use to remove a range of elements from an array and replace that range with another range of elements or not at all. Listing 6.5 is an example that removes items from an array.

Listing 6.5.

```
```php
$us_states = [
    "California",
    "Arizona",
    "Florida",
    "Wisconsin"
];
array_splice($us_states, 1, 2); // Removes 'Arizona' and 'Florida'
echo "<pre>";
print_r($us_states);
echo "</pre>";
```
```
