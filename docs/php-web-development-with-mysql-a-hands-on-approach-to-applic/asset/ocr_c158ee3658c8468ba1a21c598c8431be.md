When you start it up, you will see a blank document. Here are some preferences I like to set up for the gedit editor. In the hamburger menu for the Text Editor window, select the Preferences menu item as in Figure 2.37.

In the Preferences dialog under the View tab, select Display line numbers and Highlight matching brackets as shown in Figure 2.38.

Under the Editor tab, change the Tab width to 4, select Insert spaces instead of tabs, and Enable automatic indentation. See Figure 2.39.
