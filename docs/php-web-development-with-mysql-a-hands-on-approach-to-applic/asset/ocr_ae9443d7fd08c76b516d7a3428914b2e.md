```
    while($row = mysqli_fetch_assoc($result)):

```

Then we close the <table>:

```
    </tbody>
    </table>
```

If we do not have any movies to list, add an else: condition, indicate there are no movies, then close the conditional. Messages like this prevent users from wondering if the application doesn't have any databases or encountered an error or bug.

```
<?php
    else:
?>
    <h3>No Movies Found :-(</h3>
<?php
    endif;
?>
```
