As mentioned earlier, the two common reasons for the error are: the image is too big, or the image is the wrong file type. So this gives us three error conditions we can test:

1. The file is the right image type but too big.

2. The file is the wrong image type but less than ML_MAX_FILE_SIZE.

3. The file is the wrong image type AND too big.

Implementing these tests is left as an exercise for you. You'll want to write one error message for each of these cases.
