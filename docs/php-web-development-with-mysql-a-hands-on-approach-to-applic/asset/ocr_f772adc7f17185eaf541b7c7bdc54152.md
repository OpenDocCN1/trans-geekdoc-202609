# 23. ADDING USER LOGINS

# Complete Code Listing

Listing 23.30 is the complete listing for the authorizeaccess.php page:

# Listing 23.30.

```
```php
<?php
session_start();

// Not logged in, redirect to unauthorizedaccess.php script
if (!isset($_SESSION['user_id']) || !isset($_SESSION['user_access_privileges']))
{
    header("Location: unauthorizedaccess.php");
    exit();
}

// IF NOT admininistrative access redirect to unauthorizedaccess.php script
if ($_SESSION['user_access_privileges'] != 'admin')
{
    header("Location: unauthorizedaccess.php");
    exit();
}
```
