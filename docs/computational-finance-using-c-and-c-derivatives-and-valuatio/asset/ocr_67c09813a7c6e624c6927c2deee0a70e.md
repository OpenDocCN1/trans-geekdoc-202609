# General Payment Timing

For the general case, when the coupon payment date does not correspond to the end of its associated forward rate, we use the result from equation (7.2.43) that

```
$dW^k = \left(\frac{\mu_k}{\sigma_k}ight)dt + dW^i, i \neq k. \quad (7.2.33)$
```

(7.2.33) states that Brownian motion $W^i$ under measure $DF(t, t_i)$ can be transformed into Brownian motion $W^k$ under measure $DF(t, t_k)$ by the addition of a drift term, which more detail can be found in Section 7.2.3. If we assume constant drift $\mu_k, W^k_{t_0} = 0$, we obtain

```
$W^k_{t_k} = (t_k - t_0)\frac{\mu_k}{\sigma_k} + W^i_t. \quad (7.2.34)$
```

and in equation (7.2.30)

```
$\sigma_k W^k_t = (t - t_0)\mu_k + \sigma_k W^i_t.$
```

A $\mu_k$ can be achieved by freezing the forward rates that make up $\mu_k$, for example, $F(t, t_{k-1}, t_k) 	o F(t, t_0, t_k)$, see Section 7.2.3 for more details concerning $\mu_k$.

This means that $F(t, t_{k-1}, t_k)$ follows the process

```
$d(t, t_{k-1}, t_k) = F(t, t_{k-1}, t_k)\mu_k dt + F(t, t_{k-1}, t_k)\sigma_k dW^i.$
```

The above equation is GBM with drift and can be modified by solving equation (7.2.30) to

```
$F(t, t_{k-1}, t_k) = F(t, t_0, t_k)\exp\left((t-t_0)\mu_k - \frac{(t-t_0)\sigma_k^2}{2} + \sigma_k W^i_t\right). \quad (7.2.35)$
```

As before, the $t_0$ value of the coupon payment at time $t_i$ is

```
$V_0 = DF(t, t_i)E^{Q^t}\left[frac{F(t_{k-1}, t_{k-1}, t_k)}{DF(t_i, t_k)}ight]\tau P,$
```

which since $DF(t_i, t_i)=1$ equals

```
$V_0 = DF(t, t_i)E^{Q^t}\left[F(t_{k-1}, t_{k-1}, t_k)\right]\tau P.$
```

Now from equation (7.2.35), we have

```
$E^{Q^t}[F(t, t_{k-1}, t_k)]\n=E^{Q^t}F(t, t_0, t_k)\exp\left((t-t_0)\mu_k - \frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W^i_{t_{k-1}}\right)\n=F(t_0, t_{k-1}, t_k)\exp\left((t-t_0)\mu_k\right)E^{Q^t}\left[exp\frac{(t_{k-1}-t_0)\sigma_k^2}{2} + \sigma_k W^i_{t_{k-1}}\right]\n=F(t_0, t_{k-1}, t_k)\exp\left((t-t_0)\mu_k\right), \quad (7.2.37)$
```

where, as before, we have used the expectation given in Appendix D.2.
