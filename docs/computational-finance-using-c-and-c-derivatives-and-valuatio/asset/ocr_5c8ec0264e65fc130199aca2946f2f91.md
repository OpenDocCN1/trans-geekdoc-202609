# FX Call

The time t value (in domestic currency) of an FX call to buy one unit of foreign currency can be found from equation (4.4.55) and substitutions given in (7.3.8). We have

```
$C_d(t) = X_d^f \exp(-r^f(T-t))N(d_1) - K \exp(-r^d(T-t))N(d_2).$
```

```
$d_1 = \frac{1}{\sigma\sqrt{T-t}} \left( \log\frac{X_d^f(t)}{K} + (r^d - r^f)(T-t) + \frac{1}{2}(\sigma)^2(T-t) \right),$
```

```
$d_2 = d_1 - \sigma\sqrt{T-t}.$
```

where K is the strike, the rate that has been agreed for pay one unit of foreign currency in units of domestic currency, and σ is the implied foreign/domestic currency exchange rate FX option volatility, which may depend on effects such as time to maturity, volatility smile, etc.

In practice, the following, modified version of equation (7.3.9) is usually used

```
$C_d(t) = P^f \{X_d^f \exp(-r^f(T-t))N(d_1) - K \exp(-r^d(T-t))N(d_2)\}$,
```

where Pf is the number of units of foreign currency and all the other symbols have their previous meanings.

The value C_b(t) of the call in base currency can be found by using C_b(t) = X_b^f(t). From equation (7.3.12), we

```
$C_b(t) = P^f \{X_d^f(t)N(d_1)DF(t,T) - K X_d^f(t)N(d_2)DF(t,T)\},
```

where we have used the fact that X_d^f(t)X_b^f(t) = X_b^f(t), DF(t,T) = exp(-r^f(T-t)), and DF(t,T) = exp(-r^d(T-t)). We can also re-express the values for d1 in given equation (7.3.10)

```
$d_1 = \frac{1}{\sigma\sqrt{T-t}} \left( \log\frac{X_d^f(t)}{KX_b^f(t)} + \log\frac{DF(t,T)}{FD(t,T)} + \frac{1}{2}\sigma^2(T-t) \right),
```

where we have used that

```
$log DF(t,T) = -r^f(T-t), \quad log FD(t,T) = -r^d(T-t).
```
