# D THE GENERAL ERROR DISTRIBUTION

This section proves various relations for the generalized error distribution. The density function for generalized error distribution is

```
$f(\epsilon_i) = \mathcal{K}\exp(-\frac{1}{2}(\frac{\epsilon_i}{\lambda})^a), \quad \text{where} \mathcal{K} = \frac{a}{\lambda 2^{(1+1)/a}}\Gamma(1/a)} \quad (D.4.1)$
```

# D.4.1 Value of $\lambda$ for Variance $h_i$

Calculation of the scale factor $\lambda$ required for a generalized error distribution with mean 0 and variance $h_i$. The variance of the distribution, $E(\epsilon_i^2)$, is given by

```
$E(\epsilon_i^2) = \mathcal{K}\int_{-\infty}^{\infty} \epsilon_i^2\exp(-\frac{1}{2}(\frac{\epsilon_i}{\lambda})^a)d\epsilon_i = 2\mathcal{K}\int_{0}^{\infty}\exp(-\frac{1}{2}(\frac{\epsilon_i}{\lambda})^a)d\epsilon_i.$
```
