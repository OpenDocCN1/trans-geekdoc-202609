# B.1 THE DOWN AND OUT CALL

We will now derive the formula for the value, $c_{do}$ of a European down and out option with dividend yield $q$ when the strike, $E$, satisfies $E > B$,

```
$c_{do} = \frac{\exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \{S\exp(X) - E\ f(X > B)dX.\quad (B.1.1)
```

Substituting for $f(X > B)$, we have $c_{do} = I_A + I_B$, where

```
$I_A = \frac{\exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \{S\exp(X) - E\ \exp\left(-\frac{X - (r - q - \sigma^2/2)\tau}{\sigma^2\tau}\right)dX$
```

and

```
$I_B = \frac{\exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} \{S\exp(X) - E\ \exp\left(-\frac{X - (r - q - \sigma^2/2)\tau}{\sigma^2\tau}\right)\n\times \exp\left(-\frac{2\log(B/S)(X - \log(B/S))}{\sigma^2\tau}\right)dX.
```

Now comparing $I_A$ with equation (4.4.54), we can identify $I_A$ as $c$, the price of a European call. That is,

```
$I_A = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2),\quad (B.1.2)
```

where

```
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)\tau}{\sigma \sqrt{\tau}},
```

```
$d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)\tau}{\sigma \sqrt{\tau}}
```

We now consider the term $I_B$, and let $I_B = I_C + I_D$,

```
$I_C = -\frac{\exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{X=\log(E/S)}^{\infty} S\exp(X)\exp\left(-\frac{X - (r - q - \sigma^2/2)\tau}{\sigma^2\tau}\right)\n\times \exp\left(-\frac{2\log(B/S)(X - \log(B/S))}{\sigma^2\tau}\right)dX$
```
