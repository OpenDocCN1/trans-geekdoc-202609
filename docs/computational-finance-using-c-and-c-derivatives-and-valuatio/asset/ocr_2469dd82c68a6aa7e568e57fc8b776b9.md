```
$\mu_k = \frac{\tau\rho_{k,k-1}\sigma_k F_{k+1}}{1+\tau F_k} - \frac{\tau\rho_{k+1,k}\sigma_{k+2}F_{k+2}}{1+\tau F_{k+2}}, \quad (7.2.72)$
```

```
$dF_k =-\sigma_k F_k \sum_{j=k-1}^i \frac{\rho_{k,j}\tau_j F_j}{1+\tau F_j}dt + \sigma_k F_k dW^i, \quad (7.2.73)$
```

where all symbols have the same meanings as before, but now $i$ can take any integer value greater than k.

# 7.2.4 Interest Rate Quanto

This section considers derivatives whose value depends on the foreign interest rate yield curve but have a payoff in domestic currency. We use the same notation as in Section 7.3, which deals with exchange derivatives.

For example, a standard rate cap has a payoff in domestic currency and also depends on the currency forward rates. The value at $t_0$ of a cap which pays at $t_k$ and from $t_{k-1}$ to time $t_k$ is

```
$Caplet(t_0) = P D F(t_0, t_k) E^{Q^k} [\max (F_k^D - K)], \quad (7.2.74)$
```

where $P$ is the principal, $K$ is the strike, $\tau=t_{k-1}-t_k$, $F_k$ is the domestic forward rate $F(t_0, t_{k-1}, t_k)$. Equation (7.2.74) can be evaluated using the Black Scholes formula as:

```
$Caplet(t_0) = P D F(t_0, t_k) \{N_1(d_1) - K N_1(d_2)\}, \quad (7.2.75)$
```

where $\sigma_k$ is the volatility of $F_k$, and

```
$d_1 = \frac{\log(\left(\frac{F(t_0, t_{k-1}, t_k)}{K}\right)) + \frac{\sigma_d^2\tau}{2}}{\sigma_d\sqrt{\tau}},
```

```
$d_2 = \frac{\log(\left(\frac{F(t_0, t_{k-1}, t_k)}{K}\right)) - \frac{\sigma_d^2\tau}{2}}{\sigma_d\sqrt{\tau}}, \quad (7.2.76)$
```
