# Unconditional Variance and Covariance

Let

$Y_{w,t} = \exp(-\alpha t) \Psi_t, \text{ where } \psi_t = \left(\frac{\sigma^2 \exp(2\alpha t)}{2\alpha}\right). (2.9.18)$

and

$Y_{w,s} = \exp(-\alpha s) \Psi_s, \text{ where } \psi_s = \left(\frac{\sigma^2 \exp(2\alpha s)}{2\alpha}\right). (2.9.19)$

The covariance is

$Cov[Y_{w,s}, Y_{w,t}] = E[Y_{w,t} Y_{w,s}] - E[Y_{w,t}] E[Y_{w,s}] \n E[Y_{w,t} Y_{w,s}]. (2.9.20)$

since $E[Y_{w,t}] = E[Y_{w,t}] = 0$.

Shortening the notation of $Y_{w,t}$ to $Y_t$, we obtain

$Cov[Y_s, Y_t] = E[\exp(-\alpha t) \Psi_t \Psi_s] \n = \exp(-\alpha(t + s)) E{\{\Psi_t \Psi_s\}\].

From equation (2.1.2),

$E[W_s, W_t] = s \wedge t. (2.9.21)$

Therefore, if $s \le t$,

$E[\Psi_t \Psi_s] = \Psi_s. (2.9.22)$

and

$Cov[Y_s, Y_t] = \frac{\exp(-\alpha(t + s)) \sigma^2 \exp(2\alpha s)}{2\alpha} = \frac{\sigma^2}{2\alpha}\exp(-\alpha(t - s)). (2.9.23)$

The unconditional variance (obtained by setting $s = t$) is

$Var[Y_t] = \frac{\sigma^2}{2\alpha}. (2.9.24)$
