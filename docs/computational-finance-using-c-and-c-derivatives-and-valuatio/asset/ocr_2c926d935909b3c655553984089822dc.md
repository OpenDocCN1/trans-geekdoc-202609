# 16 CHAPTER | 2 Introduction to Stochastic Processes

We obtain the following expression for the quotient rule:

```
$d\left(\frac{X_1}{X_2}\right) = \left(\frac{X_1}{X_2}\right)\frac{dX_1}{X_1} - \frac{dX_2}{X_2} + E\left[\left(\frac{dX_1}{X_2}\right)\left(\frac{dX_2}{X_2}\right)\right] - E\left[\left(\frac{dX_1}{X_1}\right)\left(\frac{dX_2}{X_2}\right)\right]\right]. (2.6.4)$
```

(i) Brownian motion

Here, we have

```
$dX_1 = \mu_1 dt + \sigma_1 dW_1 \quad\text{and} \quad dX_2 = \mu_2 dt + \sigma_2 dW_2$,
```

or equivalently

```
$$\frac{dX_1}{X_1} = \mu_1 dt + \sigma_1 dW_1 \quad\text{and} \quad \frac{dX_2}{X_2} = \mu_2 dt + \sigma_2 dW_2$.
```

Therefore,

```
$E\left[\left(\frac{dX_1}{X_2}\right)\left(\frac{dX_2}{X_2}\right)\right] = E\left[(\mu_2 dt + \sigma_2 dW_2)(\mu_2 dt + \sigma_2 dW_2)\right]\n= E\left[\mu_2^2 dt^2\right] + E\left[\sigma_2^2 (dW_2)^2\right] + 2E[\mu_2\sigma_2 dt dW_2]
= \mu_2^2 dt^2 + \sigma_2^2 dt + 2\mu_2\sigma_2 dt[dW_2]$,
```

which results in

```
$E\left[\left(\frac{dX_1}{X_2}\right)\left(\frac{dX_2}{X_2}\right)\right] = \sigma_2^2 dt. (2.6.5)$
```

where we have ignored all terms in $dt$ with order higher than 1 and used the fact that $E[dW_2] = 0$.

In a similar manner,

```
$E\left[\left(\frac{dX_1}{X_1}\right)\left(\frac{dX_2}{X_2}\right)\right] = E\left[(\mu_1 dt + \sigma_1 dW_1)(\mu_2 dt + \sigma_2 dW_2)\right]\n= E[\mu_1\mu_2 dt^2] + E[\mu_1\sigma_2 dt dW_2] + E[\sigma_1\mu_2 dt dW_1]
+ E[\sigma_1\sigma_2 dW_1 dW_2]
= \mu_1\mu_2 dt^2 + \mu_1\sigma_2 dt[dW_2] + \sigma_1\mu_2 dt[dW_1]
+ \sigma_1\sigma_2 dt$,
```

which gives

```
$E\left[\left(\frac{dX_1}{X_1}\right)\left(\frac{dX_2}{X_2}\right)\right] = \sigma_1\sigma_2 dt\rho_{12}. (2.6.6)$
```

where we have proceeded as before but also used the fact that $E[dW_1 dW_2] = \rho_{12}dt$.

Substituting this equation (2.6.4), we have

```
$d\left(\frac{X_1}{X_2}\right) = \left(\frac{X_1}{X_2}\right)\frac{dX_1}{X_1} - \frac{dX_2}{X_2} + \sigma_2^2 dt - \sigma_1\sigma_2\rho_{12}dt\n= \left(\frac{X_1}{X_2}\right)[\mu_1 dt + \sigma_1 dW_1 - \mu_2 dt - \sigma_2 dW_2]\n= \left(\frac{X_1}{X_2}\right)[\mu_1 dt + \sigma_1 dW_1 - \mu_2 dt - \sigma_2 dW_2 + \sigma_1\sigma_2\rho_{12}dt]$.
```
