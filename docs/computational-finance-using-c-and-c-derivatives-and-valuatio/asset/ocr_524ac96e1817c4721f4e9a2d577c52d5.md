# D.2 THE LOGNORMAL DISTRIBUTION

If the variable $x$ follows a lognormal distribution, then the probability density function $f(x)$ is given by

```
$$\frac{1}{x\sqrt{2\pi}} \exp\left(\frac{(\log(x) - \mu)^2}{2\sigma^2}\right)$,\quad (D.2.1)$
```

where $x > 0$. Here, we define the lognormal distribution for $x$ as $x \sim \mathcal{A}(\mu, \sigma^2)$. Setting $y = \log(x)$, it can be seen that $y \sim N(\mu, \sigma^2)$. Thus, if $x$ is a lognormal distribution $\mathcal{A}(\mu, \sigma^2)$, then $\log(x)$ is a normal distribution with mean $\mu$ and variance $\sigma^2$. Conversely, if $y \sim N(\mu, \sigma^2)$, then the distribution for $x = e^y$ is $x \sim \mathcal{A}(\mu, \sigma^2)$.
