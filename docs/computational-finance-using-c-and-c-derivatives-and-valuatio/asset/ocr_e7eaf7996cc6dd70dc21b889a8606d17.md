Now since the probability $P(m_t^x \le b, 	ilde{X}_t \ge x)$ decreases as $x$ increases, we have

```
$P(m_t^x \le b, 	ilde{X}_t \ge x) - P(m_t^x \le b, 	ilde{X}_t \ge x+\Delta x) = -\frac{\partial P}{\partial x}\Delta x$ (H.9.2)
```

and

```
$P(m_t^x \le b, 	ilde{X}_t \ge x) - P(m_t^x \le b, 	ilde{X}_t \ge x+\Delta x) \sim p(m_t^x \le b, 	ilde{X}_t = x)\Delta x,$ (H.9.3)
```

where $p(m_t^x \le b, 	ilde{X}_t = x)$ is the probability density function of $P(m_t^x \le b, 	ilde{X}_t \ge x)$ and $\Delta x 	o 0$.
Combining equations (H.9.2) and (H.9.3), we obtain

