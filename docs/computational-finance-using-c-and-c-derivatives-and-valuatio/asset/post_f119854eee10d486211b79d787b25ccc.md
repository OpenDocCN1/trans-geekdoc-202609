## Unconditional Mean

The unconditional mean is

$E[Y_{w,t}] = E\left[\exp(-\alpha t) W\left(\frac{\sigma^2 \exp(2\alpha t)}{2\alpha}\right)\right], \text{ where } \alpha > 0 \text{ and } t \to \infty. (2.9.16)$

So,

$E[Y_{w,t}] = 0. (2.9.17)$

## Unconditional Variance and Covariance

Let

$Y_{w,t} = \exp(-\alpha t) \Psi_t, \text{ where } \psi_t = \left(\frac{\sigma^2 \exp(2\alpha t)}{2\alpha}\right). (2.9.18)$

and

$Y_{w,s} = \exp(-\alpha s) \Psi_s, \text{ where } \psi_s = \left(\frac{\sigma^2 \exp(2\alpha s)}{2\alpha}\right). (2.9.19)$

The covariance is

$Cov[Y_{w,s}, Y_{w,t}] = E[Y_{w,t} Y_{w,s}] - E[Y_{w,t}] E[Y_{w,s}] = E[Y_{w,t} Y_{w,s}]. (2.9.20)$

since $E[Y_{w,t}] = E[Y_{w,t}] = 0$.

Shortening the notation of $Y_{w,t}$ to $Y_t$, we obtain

$Cov[Y_s, Y_t] = E[\exp(-\alpha t) \Psi_t \Psi_s] = \exp(-\alpha(t + s)) E\{\Psi_t \Psi_s\}$.

From equation (2.1.2),

$E[W_s, W_t] = s \wedge t. (2.9.21)$

Therefore, if $s \le t$,

$E[\Psi_t \Psi_s] = \Psi_s. (2.9.22)$

and

$Cov[Y_s, Y_t] = \frac{\exp(-\alpha(t + s)) \sigma^2 \exp(2\alpha s)}{2\alpha} = \frac{\sigma^2}{2\alpha}\exp(-\alpha(t - s)). (2.9.23)$

The unconditional variance (obtained by setting $s = t$) is

$Var[Y_t] = \frac{\sigma^2}{2\alpha}. (2.9.24)$

## 2.10 ORNSTEIN UHLENBEC PROCESS

The Ornstein Uhlenbeck process is often used to model interest rates because of its mean reverting property. It is defined by the equation

$dX_t = -\alpha X_t dt + \sigma dW_t. (2.10.1)$

$\E\left[ \{X_t - X_{t_0} \exp(-\alpha t)\}^2 \right].$

However from equation (2.10.5),

$X_t - X_{t_0} \exp(-\alpha t) = \sigma \exp(-\alpha t) \int_{s=0}^{s=t} \exp(\alpha s) ds$

So substituting above expression into equation (2.10.8),

$Var[X_t] = E \left[\{\exp(-\alpha t) \sigma \int_{s=0}^{s=t} \exp(\alpha s) dW_s\}^2\right] (2.10.9)$

$Var[X_t] = \sigma^2 \exp(-2\alpha t) E \left\{\int_{s=0}^{s=t} \exp(\alpha s) dW_s\}^2\right] (2.10.10)$

Using Ito's isometry (see Section 2.12.2),

$E \left\{\{\int_{s=0}^{s=t} \exp(\alpha s) dW_s\}^2\right] = E \left[\int_{s=0}^{s=t}\{\exp(\alpha s)\}^2 ds\right]$

Then Fubini's theorem (see Section 2.12.1),

$E \left[\int_{s=0}^{s=t}\{\exp(\alpha s)\}^2 ds\right] = \int_{s=0}^{s=t} \exp(2\alpha s) ds = \left\{\frac{\exp(2\alpha s)}{2\alpha}\right]_{s=0}^{s=t} = \frac{\exp(2\alpha t)-1}{2\alpha}$

Substituting the above result into equation (2.10.10),

$Var[X_t] = \sigma^2 \left\{\frac{\exp(2\alpha t)-1}{2\alpha}\right\} (2.10.11)$

which yields the following expression for the variance:

$Var[X_t] = \sigma^2 \left\{\frac{\exp(-2\alpha t)}{2\alpha}\right\} (2.10.11)$

The expressions for the mean and variance derived in equations (2.10.7) and (2.10.11) allow us to write the distribution of $X_t$ as

$X_t \sim N(X_{t_0} \exp(-\alpha t), \sigma^2 \left\{\frac{\exp(-2\alpha t)}{2\alpha}\right\}) (2.10.12)$

which if $X_{t_0} = 0$ reduces to

$X_t \sim N(0, \sigma^2 \left\{\frac{\exp(-2\alpha t)}{2\alpha}\right\}) (2.10.13)$

## The Ornstein Uhlenbeck Bridge Section 2.11

The transition density from $X_0$ to $X_t$ is

$P(X_t|X_0) = \sqrt{\frac{K}{2\pi(1-y^2)}} \exp\left\{ \frac{K(X_t - X_0) \exp(-\alpha(t-t_0))}{1-y^2}\right\} (2.10.14)$

where $K = 2\alpha/\sigma^2$ and $y = \exp(-\alpha(t-t_0))$. Ornstein Uhlenbeck stochastic paths can be simulated using

$X_{t+dt} = X_t \exp(-\alpha dt) + \sigma \sqrt{\frac{1-\exp(-2\alpha dt)}{2\alpha}} dZ. (2.10.15)$

From equation (2.10.14), we can write

$E[X_{t+dt}|X_t] = X_t \exp(-\alpha dt)$
$Var[X_{t+dt}|X_t] = \sigma^2 \left\{\frac{1-\exp(-2\alpha dt)}{2\alpha}\right\}$.

We will now show that in the limit $dt \to 0$ equation (2.10.15) reduces to GBM. We can take a first order expansion of the exponentials in (2.10.15) to obtain

$X_{t+dt} = X_t (1-\alpha dt) + \sigma \sqrt{\frac{1-2\alpha dt}{2\alpha}} dZ = X_t - \alpha X_t dt + \sigma dZ,$

which is GBM with drift $-\alpha$ and volatility $\sigma$.

$dX_t = -\alpha X_t dt + \sigma dW_t.$
