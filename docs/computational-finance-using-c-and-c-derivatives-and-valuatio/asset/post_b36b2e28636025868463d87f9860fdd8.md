## 7.2.4 Interest Rate Quanto

This section considers derivatives whose value depends on the foreign interest rate yield curve but have a payoff in domestic currency. We use the same notation as in Section 7.3, which deals with exchange derivatives.

For example, a standard rate cap has a payoff in domestic currency and also depends on the currency forward rates. The value at $t_0$ of a cap which pays at $t_k$ and from $t_{k-1}$ to time $t_k$ is

```
$Caplet(t_0) = P D F(t_0, t_k) E^{Q^k} [\max (F_k^D - K)], \quad (7.2.74)$
```

where $P$ is the principal, $K$ is the strike, $\tau=t_k-t_{k-1}$, $F_k$ is the domestic forward rate $F(t_0, t_{k-1}, t_k)$. Equation (7.2.74) can be evaluated using the Black Scholes formula as:

```
$Caplet(t_0) = P D F(t_0, t_k) \{N_1(d_1) - K N_1(d_2)\}, \quad (7.2.75)$
```

where $\sigma_k$ is the volatility of $F_k$, and

```
$d_1 = \frac{\log(\left(\frac{F(t_0, t_{k-1}, t_k)}{K}\right)) + \frac{\sigma_d^2\tau}{2}}{\sigma_d\sqrt{\tau}},
```

```
$d_2 = \frac{\log(\left(\frac{F(t_0, t_{k-1}, t_k)}{K}\right)) - \frac{\sigma_d^2\tau}{2}}{\sigma_d\sqrt{\tau}}, \quad (7.2.76)$
```

In Section 7.2.3, we showed that the process $[F^d(t,t_{k-1},t_k)/DF^d(t,t_k)]$ is a martingale, that is, zero drift when $DF^d(t,t_k)$ is used as numeraire,

```
$dF^d(t,t_{k-1},t_k) = \sigma_d F^d(t,t_{k-1},t_k)dW^d.
```

### Quanto Caplet

In a quanto caplet instead of the domestic forward rate $F^d(t,t_{k-1},t_k)$, we use the foreign forward rate $F^f(t,t_{k-1},t_k)$. Under probability measure $\mathbb{F}$ associated with a foreign zero coupon bond $DF^f(t,t_k)$, the foreign forward rate is a martingale and is described by the following equation:

```
$dF^f(t,t_{k-1},t_k) = \sigma_f F^f(t,t_{k-1},t_k)dW^f. \ (7.2.77)$
```

However, when we use $DF^d(t,t_k)$ as a numeraire, the process $\mathbb{F}\{F^f(t,t_{k-1},t_k)/DF^d(t,t_k)\}$ has a drift and we price the quanto caplet

```
$dF^f(t,t_{k-1},t_k) = dF^f(t,t_{k-1},t_k)\alpha dt + \sigma_f F^f(t,t_{k-1},t_k)dW^F. \ (7.2.78)$
```

Our aim is to find the value of $\alpha$ and then price the quanto caplet

```
$Caplet(t_0) = P DF^d(t_0,t_k)\mathbb{F}\{\exp(\alpha(t_{k-1}-t_0))N_1(d_1) - KN_1(d_2)\}. \ (7.2.79)$
```

Where $P$ is the principal, $K$ is the strike, $\tau=t_k-t_{k-1}$, $F^f(t_0,t_{k-1},t_k)$ is the foreign currency rate, $\sigma_f$ is the volatility of $F^f(t_0,t_{k-1},t_k)$ and

```
$d_1 = \frac{\log\left(\frac{F^f(t_0,t_{k-1},t_k)}{K}\right) + (\alpha + \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```

```
$d_2 = \frac{\log\left(\frac{F^f(t_0,t_{k-1},t_k)}{K}\right) + (\alpha - \frac{\sigma_f^2}{2})(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```

We will now derive the value of $\alpha$.

First we define two $X_1(t)$ and $X_2(t)$ such that

```
$X_1(t) = \frac{DF^f(t,t_{k-1}) - DF^f(t,t_k)}{DF^d(t,t_k)}X_d^f(t). \ (7.2.80)$
```

and

```
$X_2(t) = X_f^f(t)\frac{DF^f(t,t_k)}{DF^d(t,t_k)} = X_f^f(t). \ (7.2.81)$
```

where $X_f^f(t,t_k)$ is the forward exchange rate, see Section 7.3. Therefore,

```
$\frac{X_1(t)}{X_2(t)} = \frac{DF^f(t,t_{k-1}) - DF^f(t,t_k)}{DF^f(t,t_k)} = F^f(t,t_{k-1},t_k). \ (7.2.82)$
```

$dX_1 = \sigma_1 X_1 dW_1^Q$

and

$dX_2 = \sigma_2 X_2 dW_2^Q$

Equation (7.2.84) can also be expressed as

$$\frac{d(DF_d^f(t,t_k))}{DF_d^f(t,t_k)} = \sigma_x dW_x^Q$$

Using Itô we obtain

$$\left(\frac{X_1}{X_2}\right) = \left(\frac{X_1}{X_2}\right)\left\{\sigma_1 dW_1^Q - \sigma_2 dW_2^Q\right\} + \left(\frac{X_1}{X_2}\right)\left[E\left(\left(\sigma_2 dW_2^Q\right)^2\right] - E\left[\left(\sigma_1 dW_1^Q\right) \left(\sigma_2 dW_2^Q\right)\right]$$

and the following processes for log $(X_1)$ and log $(X_2)$:

$$d(\log(X_1)) = -\frac{\sigma_1^2}{2}dt + \sigma_1 dW_1^Q$$

$$d(\log(X_2)) = -\frac{\sigma_2^2}{2}dt + \sigma_2 dW_2^Q$$

Using (7.2.85) we can write equation (7.2.87) as

$$d\left(\log\left(DF_d^f(t,t_k)\right)\right) = -\frac{\sigma_x^2}{2}dt + \sigma_x dW_x^Q$$

Now

$$\mathbb{E}[d(\log(X_2)) \{d(\log(X_2)) - d(\log(X_1))\}] = \mathbb{E}[d(\log(X_2))^2] - \mathbb{E}[d(\log(X_1)) d(\log(X_2)] = \mathbb{E}[(\sigma_2 dW_2^Q)^2] - \mathbb{E}[(\sigma_1 dW_1^Q)(\sigma_2 dW_2^Q)]$$

where we have ignored terms in $dt$ order greater than 1. In addition,

$$\mathbb{E}[d(\log(X_2)) \{d(\log(X_1))\} = \mathbb{E}[d(\log(X_2)) d\log\left(\frac{X_1}{X_2}\right)] = \mathbb{E}[d(\log(X_2)) d\log(F^f(t,t_{k-1},t_k))]$$

where $\sigma_x$ is the volatility of foreign exchange rate $X_d^f(t,t_k)$, $\sigma_f$ is the volatility of foreign forward rate $F^f(t,t_{k-1},t_k)$, and $\rho_{x,f}$ is correlation between $dW_x^Q$ and $dW_f^Q$.

Therefore, equation (7.2.86) can be written as

## Quanto Floorlet

The formula to value a quanto floorlet can be obtained in similar manner to that used for the quanto caplet.

The value at $t_0$ of a standard floorlet that pays at time $t_k$ and extends from time $t_{k-1}$ to $t_k$ is

```
$Floorlet(t_0) = P\tau DF^f(t_0,t_k)E^{Q^k} \left[max (K - F^f, 0)\right],$ (7.2.90)
```

where $P$ is the principal, $K$ is the strike, $\tau=t_k-t_{k-1}$, $F_k$ is the domestic forward rate $F(t_0,t_{k-1},t_k)$. Equation (7.2.90) can be evaluated using the Black Schedules formula as follows:

```
$Floorlet(t_0) = P\tau DF^f(t_0,t_k)\left\{-F^f(t_0,t_{k-1},t_k)N_1(-d_1) + KN_1(-d_2)\right\},$ (7.2.91)
```

where the symbols have the same meaning as for the corresponding quanto caplet,

```
$d_1 = \frac{\log\left(\frac{DF^f(t_0,t_{k-1},t_k)}{K}\right) + \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}} \ d_2 = \frac{\log\left(\frac{DF^f(t_0,t_{k-1},t_k)}{K}\right) - \frac{\sigma_d^2}{2}(t_{k-1}-t_0)}{\sigma_d\sqrt{t_{k-1}-t_0}}$$ \ (7.2.92)
```

In a quanto floorlet instead of using the domestic forward rate $F^d(t_0,t_{k-1},t_k)$,

```
$QFloorlet(t_0) = P\tau DF^d(t_0,t_k) \times \left\{-F^f(t_0,t_{k-1},t_k)\exp(\alpha(t_{k-1}-t_0))N_1(-d_1) + KN_1(-d_2)\right\},$ \ (7.2.93)
```
