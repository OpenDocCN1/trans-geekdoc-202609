We will now consider the cases of early and late coupon payments.

# Early Coupon Payment

Let consider the case when $i = k - 1$. From equation (7.2.50),

$$\mu_k = \frac{\sigma_k^2 F(t, t_{k-1}, t_k)}{(1 + \tau F(t, t_{k-1}, t_k))}$

First, we freeze the rates in $\mu_k$ we use the following:

$$\mu_k = \frac{\sigma_k^2 F(t_0, t_{k-1}, t_k)}{(1 + \tau F(t_0, t_{k-1}, t_k))}$

Substituting for $\mu_k$ is equation (7.2.39), we obtain

$V_{t_0} = DF(t_0, t_k) t_R P \frac{\sigma_k^2 \tau_k F^2(t_0, t_{k-1}, t_k)}{(1 + \tau F(t_0, t_{k-1}, t_k))}$

see Brigo and Mercurio (2001), p 387, Hull (2003).

# Late Coupon Payment

We consider the case when $i = k + 1$. From equation (7.2.66),

$$\mu_k = \frac{\tau P_{k,k+1} \sigma_k \sigma_{k+1} F(t, t_k, t_{k+1})}{(1 + \tau F(t, t_k, t_{k+1}))}$

Freezing the rates, we obtain

$$\mu_k = \frac{\tau P_{k,k+1} \sigma_k \sigma_{k+1} F(t_0, t_k, t_{k+1})}{(1 + \tau F(t_0, t_k, t_{k+1}))}$
