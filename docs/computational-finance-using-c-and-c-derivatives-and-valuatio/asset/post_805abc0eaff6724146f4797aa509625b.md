We will now consider a more general technique for pricing both American puts and calls.

### 5.2.2 The Macmillan, Barone-Adesi, and Whaley Method

Here, we consider a method of pricing American options which relies on an approximation that reduces a transformed Black–Scholes equation into a second order differential equation by Barone-Adesi and Whaley (1987), and Macmillan (1986). It provides an alternative way of evaluating American options that could be used instead of computationally intensive as finite-difference methods. Although the method prices American options, it is really based on the value of an American option relative to European counterpart. Since an American option gives more choice, its value is always at risk of its counterpart. This early exercise premium $\nu(S,\tau) \geq 0$ is now defined more precisely for American puts and calls. If current time $t$ the asset price is $S$, then the early exercise premium for an call which expires at $T$ and has maturity $\tau=T-t$, is

$\nu(S,\tau) = C(S,\tau) - c(S,\tau) \geq 0 \quad (5.2.8)$

$C(S,\tau)$ denotes the value of the American call and $c(S,\tau)$ denotes the value of the European call. The early exercise premium of an American put, $\nu_p(S,\tau)$, is similarly defined as

$\nu_p(S,\tau) = P(S,\tau) - p(S,\tau) \geq 0 \quad (5.2.9)$

where $P(S,\tau)$ is the value of the American put, and $p(S,\tau)$ is the value of the European put. The key insight provided by the Macmillan, Barone-Adesi, and Whaley method is that since both American and European options satisfy the Black–Scholes partial differential equation the early exercise premium, $\nu(S,\tau)$, see Section 4.4. Which we can write

$\frac{\partial\nu}{\partial t} + (r-q)\frac{\partial\nu}{\partial S} + \frac{1}{2}\sigma^2S^2\frac{\partial^2\nu}{\partial S^2} = v \quad (5.2.10)$

as usual $S$ is the asset price, $r$ the continuously compounded interest rate, $q$ the dividend, and $t$ increases from the current time to the expiry time $T$.

We will now introduce the function $h(\tau) = 1 - \exp(-q\tau)$ and use the factorization $\nu(S,\tau) = h(\tau)g(S,\tau)$. From standard calculus, we obtain

$\frac{\partial\nu}{\partial t} = g\frac{\partial h}{\partial t} + h\frac{\partial g}{\partial t} = rg(h-1) + h(h-1)\frac{\partial g}{\partial h}$

$\frac{\partial\nu}{\partial S} = h\frac{\partial g}{\partial S}$ and $\frac{\partial^2\nu}{\partial S^2} = h\frac{\partial^2 g}{\partial S^2}$.

Substituting these results into equation (5.2.10) yields the following transformed Black–Scholes equation:

$S^2\sigma^2h\frac{\partial^2g}{\partial h^2} + (r-q)Sh\frac{\partial g}{\partial h} + rg(h-1) + rh(h-1)\frac{\partial g}{\partial h} = rgh \quad (5.2.11)$

which can be further substituted into

$S^2\sigma^2\frac{\partial^2g}{\partial S^2} + \frac{2(r-q)}{\sigma^2}\frac{\partial g}{\partial S} - \frac{2rg}{h^2} - \frac{2r(1-h)}{\sigma^2}\frac{\partial g}{\partial h} = rgh \quad (5.2.12)$

or

$S^2\frac{\partial^2g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h}(h-1)\frac{\partial g}{\partial h} = 0 \quad (5.2.13)$

where $\alpha = \frac{2r}{\sigma^2}$ and $\beta = \frac{2(r-q)}{\sigma}$.

We consider the last term of equation (5.2.13) and note that when $q\tau$ is large, $-h(\tau) \sim 0$. Also when $\tau \to 0$, the option is close to maturity, and the value $\nu(S,E,\tau) \sim 0$ and $\frac{\partial}{\partial h} \sim 0$. It can be seen that the last term is generally quite small, and the Macmillan, Barone-Adesi, and Whaley approximation assumes it can be ignored.

$S^2\frac{\partial^2g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h} = 0 \quad (5.2.14)$

which is a second order differential equation with two linearly independent solutions of the form $aS^\gamma$. They can be found by substituting $g(S)$ into (5.2.14) as

$\frac{\partial\nu}{\partial S} = h\frac{\partial g}{\partial S}$ and $\frac{\partial^2\nu}{\partial S^2} = h\frac{\partial^2 g}{\partial S^2}$.

$S^2\frac{\partial^2g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h} = 0$

$\frac{\partial\nu}{\partial t} = g\frac{\partial h}{\partial t} + h\frac{\partial g}{\partial t} = rg(h-1) + h(h-1)\frac{\partial g}{\partial h}$

$S^2\sigma^2h\frac{\partial^2g}{\partial h^2} + (r-q)Sh\frac{\partial g}{\partial h} + rg(h-1) + rh(h-1)\frac{\partial g}{\partial h} = rgh \quad (5.2.11)$

$S^2\sigma^2\frac{\partial^2g}{\partial S^2} + \frac{2(r-q)}{\sigma^2}\frac{\partial g}{\partial S} - \frac{2rg}{h^2} - \frac{2r(1-h)}{\sigma^2}\frac{\partial g}{\partial h} = rgh \quad (5.2.12)$

$S^2\frac{\partial^2g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h}(h-1)\frac{\partial g}{\partial h} = 0 \quad (5.2.13)$

$S^2\frac{\partial^2g}{\partial S^2} + \beta S\frac{\partial g}{\partial S} - \frac{\alpha}{h} = 0 \quad (5.2.14)$
