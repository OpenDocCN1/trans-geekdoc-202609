
# The 2008 Financial Crisis Section | 9.8

The day after the downgrade, AIG made a last ditch effort to raise additional financing. The management met with representatives of Goldman, Sachs & Co., J.P. Morgan, and the Federal Reserve Bank of New York (NY Fed) to discuss putting together a $75 billion secured lending facility syndicated among various financial institutions. However, no private sector lending was forthcoming and the US government decided to step in.

In September 16, 2008 it was announced that NY Fed would bail out AIG with a $85 billion credit facility.

In March 2009 the New York Times published an article based on a confidential 21-page document prepared for regulators by AIG entitled “A.I.G.: Is the Risk Systemic?” It noted that AIG’s insurance subsidiaries had issued 375 million policies in the US with a face value of $19 trillion.

Nobody knew for certain the scope of the damage that would result from an AIG bankruptcy. Its size and interconnectedness, and the fact that financial markets were already under serious distress, created the fear that AIG’s failure would lead to the collapse of the entire financial system. The federal government was unwilling to take this risk and, therefore, bailed out AIG with a rescue package of over $182.5 billion.

## Appendix A

## The Greeks for Vanilla European Options

### A.1 INTRODUCTION

In this section, we will present some useful results which will be used later on to derive expressions for the Greeks.

A fundamental result of calculus is that

```
$$\frac{\partial}{\partial x} \int f(x)dx = f(x).$ (A.1.1)$$
```

Also the indefinite integral, $\int f(x)dx$, can be expressed as a definite integral with variable upper bound as:

```
$$\int f(x)dx = \int_{a}^{x} f(x)dx + c.
```

so

```
$$\frac{\partial}{\partial x} \int_{y=a}^{y=x} f(y)dy = f(x).$ (A.1.2)$$
```

We can now use this result to obtain the derivative of the cumulative distribution function

```
$N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=x} exp(-y^2/2)dy.$
```

which gives

```
$$\frac{\partial N_1(x)}{\partial x} = n(x),$ (A.1.3)$$
```

where

```
$n(x) = \frac{1}{\sqrt{2\pi}} exp(-x^2/2).$
```

We now derive various results for the parameters $d_1$ and $d_2$ which appear in the Black-Scholes equation

```
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)(T - t)}{\sigma \sqrt{T - t}}$ (A.1.4)$
```

and

```
$d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)(T - t)}{\sigma \sqrt{T - t}} = d_1 - \sigma \sqrt{T - t}}.$ (A.1.5)$
```

We have

```
$$\frac{\partial d_2}{\partial S} = \frac{\partial d_1}{\partial S}-\frac{1}{S\sqrt{T-t}}, \quad (A.1.6)$$
```

```
$$\frac{\partial d_2}{\partial \sigma} = \frac{\partial d_1}{\partial \sigma}-\sqrt{T-t}, \quad (A.1.7)$$
```

```
$$\frac{\partial d_1}{\partial r} = \frac{\partial d_2}{\partial r}-\frac{\sqrt{T-t}}{\sigma}, \quad (A.1.8)$$
```

```
$$\frac{\partial d_2}{\partial t} = \frac{\partial d_1}{\partial t}-\frac{\sigma}{2(T-t)}, \quad (A.1.9)$$
```

Also

```
$n(d_2) = \frac{1}{\sqrt{2\pi}}exp(-d_2^2/2)
= \frac{1}{\sqrt{2\pi}}exp(-d_1^2/2)\exp\{d_1\sqrt{T-t}-\sigma^2(T-t)/2\}
= n(d_1)\exp\{log(S/E)+(r-q+\sigma^2/2)(T-t)-\sigma^2(T-t)/2\}$
```

so

```
$n(d_2) = \frac{S}{E}n(d_1)\exp(r(T-t))exp(-q(T-t)).\quad (A.1.10)$
```

We note that

```
$$\frac{\partial N(d_1)}{\partial S} = \frac{\partial N(d_1)}{\partial d_1}\frac{\partial d_1}{\partial S} = n(d_1)\frac{1}{S\sqrt{T-t}}$$
```

This technique will be used for computing the Greeks.

### A.2 GAMMA

Gamma is defined as the second derivative of the option value with respect to the underlying stock price. This means (see Appendix A.3) it is the rate of change of delta with the underlying stock price. For a European call, the value of gamma is

```
$$\Gamma_c = \frac{\partial^2\Delta_c}{\partial S^2}=\frac{\partial\Delta_c}{\partial S}\frac{\partial}{\partial S}\{N_1(d_1)\exp(-q(T-t))\}$$
```

the value of $\Delta_c$ is given in Appendix A.3. So

```
$$\Gamma_c = exp(-q(T-t))\frac{n(d_1)}{\partial S}\frac{\partial d_1}{\partial S}.\quad (A.2.1)$$
```

Therefore, the value of gamma for a European call can be calculated similarly

```
$$\Gamma_p = \frac{\partial^2p}{\partial S^2}=\frac{\partial\Delta_p}{\partial S}\frac{\partial}{\partial S}\{(N_1(d_1)-1)exp(-q(T-t))\}$$
```

where we have used the value of $\Delta_p$, derived in Appendix A.3. Therefore,

```
$\Gamma_p = \exp(-q(T-t))\frac{n(d_1)}{\partial S}\frac{\partial d_1}{\partial S}$
```

```
$\Gamma_p = \Gamma_c = \frac{n(d_1)}{S\sqrt{T-t}} \exp(-q(T-t)).\quad (A.2.2)$
```

So value of gamma for both a put and a call is the same.

### A.3 DELTA

Delta is defined as the rate of change of option value with the underlying price. For a European call, we have

```
$\Delta_c = \frac{\partial c}{\partial S} = \frac{\partial}{\partial S}\{S\exp(-q(T-t))N_1(d_1) - E\exp(-r(T-t))N_1(d_2)\}$
```

so

```
$\Delta_c = \exp(-q(T-t)) \left(N_1(d_1) + Sn(d_1)\frac{\partial d_1}{\partial S}\right) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial S}.\quad (A.3.1)$
```

Substituting for $n(d_2)$ and $\partial d_2/\partial S$, we obtain

```
$\Delta_c = \exp(-q(T-t))N_1(d_1).\quad (A.3.2)$
```

In similar manner, we have for a European put

```
$\Delta_p = \frac{\partial p}{\partial S} = \frac{\partial}{\partial S}\{E\exp(-r(T-t))(1-N_1(d_2)) - S\exp(-q(T-t))(1-N_1(d_1))\}$
```

so

```
$\Delta_p = -E\exp(-r(T-t))n(d_2) - \exp(-q(T-t))\left\{1-N_1(d_1) + Sn(d_1)\frac{\partial d_1}{\partial S}\right\quad (A.3.3)$
```

Substituting for $n(d_2)$ and $\partial d_2/\partial S$, we obtain

```
$\Delta_p = \exp(-q(T-t))N_1(d_1) - 1.\quad (A.3.4)$
```

### A.4 THETA

Theta is defined as the rate of change of option value with time. For a European call, we have

```
$\Theta_c = \frac{\partial c}{\partial t} = \frac{\partial}{\partial t}\{S\exp(-q(T-t))N_1(d_1) - E\exp(-r(T-t))N_1(d_2)\}$
```

```
= q\exp(-q(T-t))SN_1(d_1) + \exp(-q(T-t))Sn(d_1)\frac{\partial d_1}{\partial t} - E\exp(-r(T-t))N_1(d_2) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial t};$
```

stituting for $n(d_2)$ and $\partial d_2/\partial t$, we obtain

```
$\Theta_c = q\exp(-q(T-t))SN_1(d_1) - rE\exp(-r(T-t))N_1(d_2) - \frac{Sn(d_1)\sigma\exp(-q(T-t))}{2\sqrt{T-t}}$
```

Therefore, the value of theta is

```
$\Theta_c = \exp(-q(T-t))\left\{q - SN_1(d_1)\frac{Sn(d_1)\sigma}{2\sqrt{T-t}}\right{\ - rE \exp(-r(T-t))N_1(d_2).$ (A.4.1)
```

For a put, we can similarly show how

```
$\Theta_p = \frac{\partial p}{\partial t} = \frac{\partial}{\partial t} \left\{E\exp(-r(T-t))(1-N_1(d_2)) - S\exp(-q(T-t))(1-N_1(d_1))\right\},$
```

```
$\Theta_p = r\exp(-r(T-t))(1-N_1(d_2)) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial t} - S\exp(-q(T-t))(1-N_1(d_1)) + S\exp(-q(T-t))n_1(d_1)\frac{\partial d_1}{\partial t};$
```

stituting for $n(d_2)$ and $\partial d_2/\partial t$, we obtain

```
$\Theta_p = r\exp(-r(T-t))N_1(-d_2) - S\exp(-q(T-t))N_1(-d_2) - E\exp(-r(T-t))\exp(r(T-t))\exp(-q(T-t))n(d_2)\left{\frac{S}{E}\frac{\partial d_1}{\partial t} + \frac{\sigma}{2(T-t)}\right{\} + S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial t}.$
```

so we have

$\Theta_p = \exp(-q(T-t))\left\{qSN_1(-d_1) + \frac{Sn(d_1)\sigma}{2\sqrt{T-t}}\right{\ + rE \exp(-r(T-t))N_1(-d_2).$ (A.4.2)
