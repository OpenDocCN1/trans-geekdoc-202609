# American Call Options

We use the fact that both the value and the early exercise premium $(v_c(S, E, \tau) = hg_c(S, E, \tau))$ of an American call tend to zero as the asset price $S \rightarrow 0$. This means that $q_c(S, E, \tau) \rightarrow 0$.

However, since $\gamma1 < 0$, the only way this can be achieved in equation(5.2.19) is if $a_1 = 0$. So $g_c(S, E, \tau) = a_2 S^{\gamma2}$, and the value of an American call is

```
$C(S, E, \tau) = c(S, E, \tau) + ha_2 S^{\gamma2}$.
```

An expression for $a_2$ can be found by considering the critical asset price (on the early exercise boundary), $S^*$, above which the American option will be exercised. For $S < S^*$, the value of the American call is governed by equation (5.2.19), and when $S > S^*$, we have $C(S, E, \tau) = S - E$.

Now, since the value of the American option is continuous, at the critical asset value $S^*$ the following equation applies

```
$S^* - E = c(S^*, \tau) + ha_2 S^{\gamma2}$.
```

Furthermore, since the gradient of the American option is also continuous, at $S^*$ we

```
$\frac{\partial (S^* - E)}{\partial S^*} = \frac{\partial}{\partial S^*}\{c(S^*, E, \tau) + ha_2 S^{\gamma2}\}$
```

which gives

```
$1 = \exp(-q\tau)N_1(d_1(S^*)) + \gamma_2 ha_2 S^{\gamma2-1}$,
```

where we used the value of the hedge parameter $\Delta_c$ for a European call (see section on the Greeks)

```
$\Delta_c = \frac{\partial c(S^*, E, \tau)}{\partial S^*} = \exp(-q\tau)N_1(d_1(S^*))$.
```

Equation (5.2.22) can therefore be written as

```
$ha_2 S^{\gamma2} = \frac{S^*}{\gamma_2}\{1 - \exp(-q\tau)N_1(d_1(S^*))\}$.
```
