
## C.3 THE VARIANCE AND COVARIANCE OF RANDOM VARIABLES

### C.3.1 Variance

### One Variable

Let X be a variate from a given distribution, and Z be the following linear function of this variate:

```
Z = a + bX,
```

where a and b are constants. Then

```
E[Z] = E[a] + E[bX] = a + bE[X]
```

and

```
Var[Z] = E[(Z - E[Z])^2]
= E[(a + bX - a - bE[X])^2]
= E[(bX - bE[X])^2]
= b^2 E[(X - E[X])^2]
= b^2 E(X - E[X])^2).
```

Therefore, the mean is a + bE[X], and the variance is b^2Var[X].

### Two Variables

Let Z = a + b1X1 + b2X2, where a, b1, and b2 are constants.
Then the mean is E[Z] = E[a] + E[b1X1] + E[b2X2] = a + b1E[X1] + b2E[X2].
The variance Var[Z] is computed as follows:

```
Var[Z] = E[(a + b1X1 + b2X2 - a - b1E[X1] - b2E[X2])^2]
= E[(b1(X1 - E[X1]) + b2(X2 - E[X2]))^2]
= b1^2 E[(X1 - E[X1])^2] + b2^2 E[(X2 - E[X2])^2]
+ 2b1b2 E[[X1 - E[X1]] E[X2 - E[X2]]]
= b1^2Var[X1] + b2^2Var[X2] + 2b1b2Cov[X1,X2],
```

where Cov[X1, X2] is the covariance between X1 and X2. If X1 and X2 are IID random variables, then Cov[X1, X2] = 0, and we thus have

```
Var[Z] = b1^2Var[X1] + b2^2Var[X2].
```

### Three Variables

Let Z = a + b1X1 + b2X2 + b3X3, where a, b1, b2, and b3 are constants.

Then mean E[Z] = E[a] + E[b_1X_1] + E[b_2X_2] + E[b_3X_3] = a + b_1E[X_1] + b_2E[X_2] + b_3E[X_3].

The Var[Z] is computed as:

```
Var[Z] = E[{a + b_1X_1 + b_2X_2 + b_3X_3 - a - b_1E[X_1] - b_2E[X_2] - b_3E[X_3]]^2}
= E[{b_1(X_1 - E[X_1]) + b_2(X_2 - E[X_2]) + b_3(X_3 - E[X_3])}^2]
= b_1^2E[(X_1 - E[X_1])^2] + b_2^2E[(X_2 - E[X_2])^2] + b_3^2E[(X_3 - E[X_3])^2]
+ 2b_1b_2E[(X_1 - E[X_1])(X_2 - E[X_2])]
+ 2b_1b_3E[(X_1 - E[X_1])(X_3 - E[X_3])]
+ 2b_2b_3E[(X_2 - E[X_2])(X_3 - E[X_3])]
= b_1^2Var[X_1] + b_2^2Var[X_2] + b_3^2Var[X_3] + 2b_1b_2Cov[X_2,X_1] + 2b_1b_3Cov[X_1,X_3] + 2b_2b_3Cov[X_2,X_3].
```

If X_1, X_2, and X_3 are IID, all the covariance terms are zero and the variance is

```
Var[Z] = b_1^2Var[X_1] + b_2^2Var[X_2] + b_3^2Var[X_3].
```

### Variance of n Variables

We now derive an expression for the sum of n IID random variables.

Let Z = a + \sum_{i=1}^n b_iX_i, where a and b_i, i = 1 . . . n are constants.

Then we have E[Z] = E[a] + E[\sum_{i=1}^n b_iX_i] = a + \sum_{i=1}^n b_iE[X_i] and

```
Var[Z] = E[{\sum_{i=1}^n b_iX_i - a - \sum_{i=1}^n b_iE[X_i]]^2}
= \sum_{i=1}^n b_i^2E[(X_i - E[X_i])^2] + 2\sum_{1 \le i < j \le n} b_ib_jE[(X_i - E[X_i])(X_j - E[X_j])]
= \sum_{i=1}^n b_i^2Var[X_i] + 2\sum_{1 \le i < j \le n} b_ib_jCov[X_i,X_j].
```

As before all the X variables are IID, the covariance terms are zero and we have

```
Var[Z] = \sum_{i=1}^n b_i^2Var[X_i].
```

If all the b_i terms have variance $\sigma^2$, we obtain

```
Var[Z] = \sum_{i=1}^n b_i^2\sigma^2.
```

### C.3.2 Covariance

### Two Variables

Let Z_1 = a + bX and Z_2 = c + dY, where a, b, c, and d are constants. We have

```
Cov[Z_1, Z_2] = Cov[a+bX, c+dY]
= E[(a+bX)(c+dY)]-E[a+bX]E[c+dY]
= E[ac+adY+bcX+bdXY]-(a+bE[X])(c+dE[Y])
= bdCov[X,Y].
```

By symmetry, it can be seen that Cov[X,Y] = Cov[Y,X].

### Three Variables

Let Z_1 = a + b1X_1 + b2X_2 and Z_2 = c + dY, where a, b1, b2, c, and d are constants. We have

```
Cov[Z_1, Z_2] = Cov[a+b1X_1+b2X_2, c+dY]
= E[(a+b1X_1+b2X_2)(c+dY)]-E[a+b1X_1+b2X_2]E[c+dY]
= b1Cov[X_1,Y] + b2Cov[X_2,Y].
```

### Four Variables

Let Z_1 = a + b1X_1 + b2X_2 + b3X_3 and Z_2 = c + dY, where a, b1, b2, b3, c, and
d are constants. We have

```
Cov[Z_1,Z_2] = Cov[a+b1X_1+b2X_2+b3X_3,c+dY]
= E[(a+b1X_1+b2X_2+b3X_3)(c+dY)]
- E[a+b1X_1+b2X_2+b3X_3]E[c+dY]
= b1Cov[X_1,Y] + b2Cov[X_2,Y] + b3Cov[X_3,Y].
```

### Covariance of n Variables

In a similar manner to outlined above,

```
Cov[a + \sum_{i=1}^n b_iX_i,c+dY] = \sum_{i=1}^n b_iCov[X_i,Y].
```

### C.3.3 Covariance Matrix

Let X denote the n element vector containing the random X_i,i = 1,\dots,n. The mean and variance of the $i$-th varie are $E[X_i]$ and $E[(X_i - E[X_i])^2]$ respectively. The covariance $Cov[X]_{ij}$ between the $i$-th and $j$-th variables are $E[(X_i - E[X_i])(X_j - E[X_j])]$. The elements of $n \times n$ covariance matrix $Cov[X]$ are

```
Cov[(X_i - E[X_i])(X_j - E[X_j])], \quad i=1,\dots,n,j=1,\dots,n.
```

We will now show that $Cov[X+A] = Cov[X]$ where $A$ is an n element vector containing the constants $A_i,i=1,\dots,n$. Since $E[X_i + A_i] = E[X_i] + A_i$, we obtain

```
Var[(X+A_i)] = Var[X_i+A_i]
E = E[(X_i+A_i-E[X_i+A_i])^2] = E[(X_i-E[X_i])^2]
```

and

```
Cov[X+A]_{ij} = E[(X_i+A_i-E[X_i+A_i])(X_j+A_j-E[X_j+A_j])]
E = E[(X_i-E[X_i])(X_j-E[X_j])]
Cov[X]_{ij}.
```

## C.4 CONDITIONAL MEAN AND COVARIANCE OF NORMAL DISTRIBUTIONS

Let $X=[X_1/X_2]$ be distributed as $N_p(\mu, \Sigma)$ with $\mu=[\mu_1/\mu_2]$, and $\Sigma=[\Sigma_{11}\Sigma_{12}/\Sigma_{21}\Sigma_{22}]$, and $|\Sigma_{22}|>0$.

We will prove the conditional distribution of $X_1$, given that $X_2=x_2$, is normal and has
Mean $\mu_1=\mu_1+\Sigma_{12}^{-1}(x_2-\mu_2)$, and covariance $=\Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$.
Let the inverse of $\Sigma$ be $\Sigma^{-1}$, where

```
\Sigma^{-1} = \begin{pmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{pmatrix}^{-1} = \frac{1}{|\Sigma|} \begin{pmatrix} \Sigma_{22} & -\Sigma_{12} \\ -\Sigma_{21} & \Sigma_{11} \end{pmatrix}.
```
