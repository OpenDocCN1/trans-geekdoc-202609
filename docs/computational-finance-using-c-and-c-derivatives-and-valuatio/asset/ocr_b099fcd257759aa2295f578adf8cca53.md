# H.1 SOME CONCERNS CONCERNING BROWNIAN MOTION

Here, we will prove some facts concerning Brownian motion.
If the Brownian motion has zero drift, then

```
$dX_t = \sigma \sqrt{dt} dZ_t, \quad dZ_t \sim N(0,1),$
```

```
$P(m_t^X \leq b, X_t \geq x) = N_1 \left( \frac{2b-x}{\sigma \sqrt{dt}} \right)$
```

and where $m_t^X$ denotes the minimum value of $X_t$ over the interval $[0,t]$, $b \leq 0$, and $x \geq 0$.
When the Brownian motion has nonzero drift then

```
$dX_t = vt + \sigma \sqrt{dt} dZ_t, \quad dZ_t \sim N(0,1)$
```

and the following equations are satisfied by $m_t^X$ and $	ilde{X}_t$,

```
$P(\tilde{X}_t \leq K) = N_1 \left( \frac{K-vt}{\sigma \sqrt{dt}} \right)$
```

```
$P(\tilde{X}_t \geq K) = N_1 \left( \frac{vt-K}{\sigma \sqrt{dt}} \right)$
```

```
$P(m_t^X \leq b, \tilde{X}_t \geq x) = \exp \left( \frac{2vb}{\sigma^2} \right) N_1 \left( \frac{2b-x+vt}{\sigma \sqrt{dt}} \right)$
```

```
$P(m_t^X \geq b, \tilde{X}_t \geq x) = N_1 \left( \frac{2vb}{\sigma \sqrt{dt}} \right) - \exp \left( \frac{2vb}{\sigma^2} \right) N_1 \left( \frac{2b-x+vt}{\sigma \sqrt{dt}} \right)$
```

```
$P(m_t^X \leq b) = N_1 \left( \frac{b-vt}{\sigma \sqrt{dt}} \right) - \exp \left( \frac{2vb}{\sigma^2} \right) N_1 \left( \frac{b+vt}{\sigma \sqrt{dt}} \right)$
```

```
$P(m_t^X \geq b) = N_1 \left( \frac{vt-b}{\sigma \sqrt{dt}} \right) - \exp \left( \frac{2vb}{\sigma^2} \right) N_1 \left( \frac{b+vt}{\sigma \sqrt{dt}} \right)$
```

where $K$ is a constant, $	ilde{X} \geq 0, b \leq 0$, and $P(condition)$ denotes the probability associated with the appropriate condition, i.e., $	ilde{X}_t \geq K, m_t^X \geq b, \tilde{X}_t \geq x$, e.c.
The conditional probability density function associated associated with $P(m_t^X \leq b, \tilde{X}_t \geq x)$ is

```
$P(m_{t_1,t_2}^X \leq b, \tilde{X}_{t_2} | \tilde{X}_{t_1}) = \frac{1}{\sigma \sqrt{2\pi\Delta t}} \exp \left( \frac{2v(b-\	ilde{X}_{t_1})}{\sigma^2} \right)$
```
