## 5.3.4 The Binomial Lattice with BBS and BBSR

Here, we discuss the binomial-Scholes (BBS) method and also the binomial-Scholes method with Richardson extrapolation (BBSR), Broadie and Depele (1996). As the control variant method discussed in the previous section, both of these techniques can be used in conjunction with a standard binomial lattice to improve the computed results. We will discuss the BBS method.

## The BBS Method

The BBS method is identical to the standard binomial lattice except that in the last step (that is just before maturity) the Black-Scholes formula is used to calculate the option values at maturity. For an n-time binomial lattice, this involves evaluating the Black-Scholes formula at each node in the penultimate time step. In Code excerpt 5.13, we define the function `bs_lattice` which incorporates the BBS method into a standard binomial lattice. The reader will have noticed `bs_lattice` is rather lax concerning the amount of storage that is required; the modification to use an array of size Sn is

```c
void bs_lattice(double value, double greeks[], double S0, double X, double sigma, double T, double r, int put, long *flag) {
    // Input parameters:
    S0 // the current price of the underlying asset
    X // strike price
    sigma // volatility
    T // time to maturity
    r // interest rate
    q // dividend yield
    put // if call option otherwise put option
    M // number of time steps
    value // value of option, greeks[] // statistics as follows:
    greeks[0] is gamma,
    greeks[1] is delta,
    greeks[2] is theta,
    an error index.

    // allocate the arrays s[(M+1)], and v[M+1]
    dt = T/(double)M;
    u = exp(sigma*sqrt(dt));
    d = 1/u;
    p = (exp(r*dt)-d)/(u-d);
    if (p < 0 || (p > 1.0)) return; // Invalid probability
    discount = exp(-r*dt);
    n = p*discount;
    j = 0;
    s[0] = S0;
    /* The "price" of j, at a given instant, the asset price */
    for (int i=1; i<=M; i++) { /* Calculate values at (M-i)th step */
        for (int j=i; j>=1; j--) {
            s[j] = u*s[j-1];
        }
        s[0] = d*s[0];
    }

    for (int i=0; i<=n; i++) { /* Use Black-Scholes for the final step */
        black_scholes(NULL, s[i], X, sigma, r, put, &flag[i]);
    }

    for (int i=M-1; i>=0; i--) { /* work backwards through the lattice */
        for (int j=0; j<=i; j++) {
            if (v[j] == 0 && v[j+1] == 0) {
                hold = 0;
            } else {
                if (put) {
                    v[j] = MAX(hold, s[j]-X);
                } else {
                    v[j] = MAX(hold, s[j]);
                }
            }
            hold = v[j];
        }
    }
}
```

## The BBSR Method

The BBSR method applies two-point Richardson extrapolation to the computed BBS values, for more information Richardson extrapolation see Marchuk and Shaidurov (1983). In this method, the price estimates from two BBS lattices, with differing number of steps, are combined to form an improved estimate:

$C_{BBSR}(S,E,au,2n) = \frac{4}{3}C_{BBS}(S,E,au,2n) - \frac{1}{3}C_{BS}(S,E,au,n). \quad (5.3.26)$
