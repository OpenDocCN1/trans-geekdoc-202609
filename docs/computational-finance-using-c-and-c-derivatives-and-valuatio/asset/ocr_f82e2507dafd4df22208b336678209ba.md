# E.3 THE CUMULATIVE NORMAL DISTRIBUTION FUNCTION

In this section, we show that the cumulative normal distribution function, $N_1(x)$, is related to the complementary error function, erfc(x), by the following equation:

```
$N_1(x) = \frac{1}{2}\text{erfc}(-x/\sqrt{2}). \quad (E.3.1)$
```

If we let the error function be represented by erf(x), then we have

```
$$\text{erf}(x) = \frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp(-t^2)dt.$
```

Now we have the following:

erfc(x) = 1 - \text{erf}(x)$, erfc(-x) = -\text{erf}(x)$, erfc($\infty$) = 1, and erfc(-$x$) = 2 - \text{erf}(x).

We will consider the integral

```
$I(x) = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{0}\exp(-t^2)dt + \frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp(-t^2)dt.$
```

Since

```
$$\frac{2}{\sqrt{\pi}}\int_{-\infty}^{0}\exp(-t^2)dt = 1.$
```

We therefore have

```
$I(x) = 1 + \text{erf}(x) = 1 + \{1 - \text{erfc}(x)\} = 2 - \text{erfc}(x).$.
```

Substituting for erf(x), we obtain

```
$N_1(x) = 2 - \{2 - \text{erfc}(-x)\} = \text{erfc}(-x).$.
```

So we have

```
$$\text{erfc}(-x) = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt. \quad (E.3.2)$
```

The cumulative normal distribution is defined as

```
$N_1(x) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt.$
```

Let $u = t\sqrt{2}$, we have $du = \sqrt{2}dt$, and for the upper limit, we have $x = t\sqrt{2}$ or $t = x/\sqrt{2}$.

This integral becomes

```
$N_1(x) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{x/\sqrt{2}}\exp(-t^2)dt. \quad (E.3.3)$
```

So from equation (E.3.2), we have

```
$N_1(x) = \frac{1}{2}\text{erfc}(-x/\sqrt{2}). \text{QED}$
```

We also note that

```
$N_1(-x) = 1 - N_1(x).$.
```
