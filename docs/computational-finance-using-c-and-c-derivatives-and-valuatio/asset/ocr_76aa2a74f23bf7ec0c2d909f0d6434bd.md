# Generate the Lattice Asset Prices

Next we generate the asset prices for the $pth stochastic lattice. Since the lattice is non-recombining at the $ith$ time step, there are $b^i$ nodes/asset prices. This contrasts with the binomial lattice of Chapter 5 where the asset prices at a given time step are arranged in ascending order, that is $S_i^j$ increases with increasing $j$. We denote the $j$th value at the $i$th time step by $S_i^j$. For example, in Fig. 5.9, where $b=3$ and $d=3$, we have for the first time step

$S_i^1=115, S_i^2=60, S_i^3=114$

and for the second time step

$S_i^2=116, S_i^3=90, S_i^4=149,...,S_i^7=102, S_i^8=88, S_i^9=80$.

The $k$th asset price at the $ith$th time step, $S_i^k$ then generates the following asset prices at the $(i+1)$ time step

```
$S_i^{\frac{(k-1)b+j}{i+1}} = dS_i^k, \quad j=1,...,b, k=1,...,b^i$
```

where $dS_i^k$ is, as before, random variate from a given distribution. When $S_i$ follows GBM, we have

```
$S_i^{\frac{(k-1)b+j}{i+1}} = \exp\left(\left(r-\sigma_i^2/2\right)\Delta t + \sigma_i dX_i\right), \quad j=1,...,b, k=1,...,b^i$.
```
