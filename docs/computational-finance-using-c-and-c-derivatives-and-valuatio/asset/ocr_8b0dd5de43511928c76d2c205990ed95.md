# 328 APPENDIX | D Statistical Distribution Functions

The expectation of the $t$ moment (where $t$ is a positive integer) of $x$ is thus

```
$E[x^t] = \frac{1}{\sigma \sqrt{2\pi}} \int_{-\infty}^{\infty} x^{t-1} \exp\left(\frac{(\log(x) - \mu)^2}{2\sigma^2}ight)dx.$
```

Using $y = \log(x)$, we have

```
$frac{dy}{dx} = \frac{\log(x)}{dx} = \frac{1}{x}, dx = xdy$ and $x^t = (e^y)^t = e^{ty}$.
```

Thus,

```
$E[x^t] = E[e^{ty}] = M_y(t) = \frac{1}{\sigma \sqrt{2\pi}} \int_{y=-\infty}^{\infty} e^{ty} \exp\left(\frac{(y-\mu)^2}{2\sigma^2}ight)dy$.
```

where $M_y(t)$ is the moment generating function of a normal distribution with mean $\mu$ and variance $\sigma^2$.

From Appendix D.1,

```
$E[x^t] = M_y(t) = \exp\left(\mu + \frac{\sigma^2 t^2}{2}ight)$.
```

Therefore, if $x \sim \Lambda(\mu, \sigma^2)$, then for $t=1$,

```
$E[x] = \exp\left(\mu + \frac{\sigma^2}{2}ight). (D.2.2)
```

for $t=2$, and the variance is obtained using

```
$E[x^2] = \exp(2\mu + 2\sigma^2), (D.2.3)
```

```
$Var[x] = \exp(2\mu + \sigma^2) (\exp(\sigma^2) - 1)$.
```

So

```
$Var[x] = \exp(2\mu + \sigma^2) (\exp(\sigma^2) - 1)$
```

or

```
$Var[x] = (E[x])^2 (\exp(\sigma^2) - 1). (D.2.4)
```

Note: If $x_1 = \exp(\mu + \sigma Z)$, where $Z \sim N(0,1)$, then $x_1 \sim \Lambda(\mu, \sigma^2)$. So $E[x_1]$ and $Var[x_1]$ are given by equations (D.2.2) and (D.2.4).
