## E.1 STANDARD INTEGRALS

```
$$\int_{0}^{\infty} exp(-ay^2) dy = \frac{1}{2} \sqrt{\frac{\pi}{a}}, \quad (i)$$
$\int_{0}^{\infty} y \exp(-ay^2) dy = \frac{1}{2}, \quad (ii)$$
$\int_{0}^{\infty} y^2 \exp(-ay^2) dy = \frac{1}{4a} \sqrt{\frac{\pi}{a}}, \quad (iii)$$
$\int_{0}^{\infty} y^3 \exp(-ay^2) dy = \frac{3}{8a^2} \sqrt{\frac{\pi}{a}}, \quad (iv)$$
$\int_{0}^{\infty} y^{2n} \exp(-ay^2) dy = \frac{1 \times 3 \times 5 \dots (2n-1)}{2^{2n+1}a^n} \sqrt{\frac{\pi}{a}}, \quad (v)$$
$\int_{0}^{\pi} \epsilon^n \exp(-b\epsilon^p) = \frac{\Gamma(k)}{p b^k}, \quad n > -p, b > 0, \text{ and } k = \frac{n+1}{p} \quad (vi)$$
$\int_{0}^{\infty} \frac{\epsilon^a d\epsilon}{(m + \epsilon^b)^c} = \frac{1}{b} \frac{\Gamma((\frac{a+1}{b}))}{\Gamma(c-(a+1)/b)} \quad (vii)$
```

where $a > -1, b > 0, \text{ and } c > (a+1)/b$.

## E.3 THE CUMULATIVE NORMAL DISTRIBUTION FUNCTION

In this section, we show that the cumulative normal distribution function, $N_1(x)$, is related to the complementary error function, erfc(x), by the following equation:

```
$N_1(x) = \frac{1}{2}\text{erfc}(-x/\sqrt{2}). \quad (E.3.1)$
```

If we let the error function be represented by erf(x), then we have

```
$$\text{erf}(x) = \frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp(-t^2)dt.$
```

Now we have the following:

erfc(x) = $1 - \text{erf}(x)$, erfc(-x) = $-\text{erf}(x)$, erfc($\infty$) = 1, and erfc(-$x$) = 2 - \text{erf}(x).

We will consider the integral

```
$I(x) = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{0}\exp(-t^2)dt + \frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp(-t^2)dt.$
```

Since

```
$$\frac{2}{\sqrt{\pi}}\int_{-\infty}^{0}\exp(-t^2)dt = 1.$
```

We therefore have

```
$I(x) = 1 + \text{erf}(x) = 1 + \{1 - \text{erfc}(x)\} = 2 - \text{erfc}(x).$.
```

Substituting for erf(x), we obtain

```
$N_1(x) = 2 - \{2 - \text{erfc}(-x)\} = \text{erfc}(-x).$.
```

So we have

```
$$\text{erfc}(-x) = \frac{2}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt. \quad (E.3.2)$
```

The cumulative normal distribution is defined as

```
$N_1(x) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{x}\exp(-t^2)dt.$
```

Let $u = t\sqrt{2}$, we have $du = \sqrt{2}dt$, and for the upper limit, we have $x = t\sqrt{2}$ or $t = x/\sqrt{2}$.

This integral becomes

```
$N_1(x) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{x/\sqrt{2}}\exp(-t^2)dt. \quad (E.3.3)$
```

So from equation (E.3.2), we have

```
$N_1(x) = \frac{1}{2}\text{erfc}(-x/\sqrt{2}). \text{QED}$
```

We also note that

```
$N_1(-x) = 1 - N_1(x).$.
```

## E.4 ARITHMETIC AND GEOMETRIC PROGRESSIONS

### Arithmetic progression

The sum of the first n terms of an arithmetic progression is

```
$s_n = \frac{n}{2}\{2a_1 + (n-1)d\}, \quad (E.4.1)$
```

where $a_1$ is the first term, and $d$ is the common difference, that is, the terms in the sequence are $a_1, a_1+d, a_1+2d, a_1+3d,\dots$

### Geometric progression

The sum of the first n terms of an arithmetic progression is

```
$s_n = \frac{a_1(1-r^n)}{1-r}, \quad (E.4.2)$
```

where $a_1$ is the first term, and $r$ is the common ratio, that is, the terms in the sequence are $a_1, a_1r, a_1r^2, a_1r^3,\dots$

## Black-Scholes Finite-Difference Schemes

### F.1 THE GENERAL CASE

In this section, we consider the stability of finite-difference schemes described in Chapter 5. It is assumed that the grid contains $n_s$ points, and we will denote the time dependent values at the $i$th and $(i+1)$th instants by the $n_{s-2}$ vectors $X^i$ and $X^{i+1}$. We can therefore write

```
$X^i = T_1 X^{i+1}, \quad (F.1)$
```

where $T_1$ and $T_2$ are $n_{s-2} \times n_{s-2}$ tridiagonal matrices, and $x^i_k = 1, \dots, n_{s-2}$ will be used to denote the elements of the vector $X^i$.

```
$X^i = T_1^{-1} X^{i+1}. \quad (F.2)$
```

However, equation (F.2) is only stable if the eigenvalues of the $n_{s-2} \times n_{s-2}$ matrix $T_1^{-1}T_2$ all have modulus less than one, see Smith (1985).

### F.2 THE LOG TRANSFORMATION AND A UNIFORM GRID

We will prove that the implicit-difference method, $\theta_m = 0$, when used on the log transformed Black-Scholes equation with a uniform grid is unconditionally stable, which means that stability does not depend on the values of $\sigma, \Delta t, \Delta Z$.

From Chapter 5, the finite-difference scheme is described by the following tridiagonal system:

$$\begin{pmatrix} B & C & 0 & 0 & \dots & 0 \\ A & B & C & 0 & \dots & 0 \\ 0 & A & B & C & \dots & 0 \\ \vdots & \vdots & \ddots & \ddots & \ddots & \vdots \\ 0 & 0 & \dots & A & B & C \\ 0 & 0 & \dots & 0 & A & B \end{pmatrix} \begin{pmatrix} x^{i+1}_1 \\ x^{i+1}_2 \\ x^{i+1}_3 \\ \dots \\ x^{i+1}_{s-2-1} \\ x^{i+1}_{s-2} \end{pmatrix} = \begin{pmatrix} x^i_1 \\ x^i_2 \\ x^i_3 \\ \dots \\ x^i_{s-2-1} \\ x^i_{s-2} \end{pmatrix}$$

where

```
$A = \frac{(1-\theta_m)\Delta t}{2\Delta Z^2} \{b\Delta Z - \sigma^2\}, \quad (F.2.1)$
$B = 1 + (1-\theta_m)\Delta t + \frac{\sigma^2}{\Delta Z^2}, \quad (F.2.2)$
$C = -\frac{(1-\theta_m)\Delta t}{2\Delta Z^2} \{b\Delta Z + \sigma^2\}, \quad (F.2.3)$
$\tilde{A} = -\frac{\theta_m\Delta t}{2\Delta Z^2} \{b\Delta Z - \sigma^2\}, \quad (F.2.4)$
$\tilde{B} = 1-\theta_m\Delta t + \frac{\sigma^2}{\Delta Z^2}, \quad (F.2.5)$
$\tilde{C} = \frac{\theta_m\Delta t}{2\Delta Z^2} \{b\Delta Z + \sigma^2\}, \quad (F.2.6)$
```

As in Chapter 5, $b=r-q=(\sigma^2/2)$, and $r>0$. Substituting $\theta_m=0$ into equations (F.2.1)-(F.2.6), we have $\tilde{A}=\tilde{C}=0, \tilde{B}=1$,

```
$A=\frac{\Delta t}{2\Delta Z^2}\{b\Delta Z - \sigma^2\}, \quad B=1+\frac{\sigma^2}{\Delta Z^2}, \quad C=-\frac{\Delta t}{2\Delta Z^2}\{b\Delta Z + \sigma^2\}$
```

The finite-difference scheme is represented by this equation

```
$X^i = T_1^{-1}X^{i+1}, \quad (F.2.7)$
```

where $T_2=1$ in equation (F.1.1). As mentioned in Appendix F.1, equation (F.2.7) is stable if the moduli of all the eigenvalues of $T_1^{-1}$ are less than one. We now show that this is in the case. If the eigenvalues of $T_1$ are $\lambda_k, k=1,...,n_{s-2}$, then the eigenvalues of $T_1^{-1}$ are $\lambda_k^{-1}, k=1,...,n_{s-2}$. This means that the system is stable if all the eigenvalues of $T_1$ have a modulus greater than one. This result can be proved by considering the eigenvalue with the smallest modulus, $\lambda_{min}$. If $|\lambda_{min}| > 1$, then the result is proved.

# The Log Transformation and a Uniform Grid

Now the eigenvalues of $T_1$, see Smith (1985), are given by

```
$$\lambda_k = 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right) + 2\sqrt{AC} \cos\left(\frac{k\pi}{n_{s-2}+1}\right), \quad k=1,\dots,n_{s-2}, \quad(F.2.8)$
```

where the term

```
$$\2\sqrt{AC} = \sqrt{\frac{\sigma^4 - b^2\Delta Z^2}{\Delta Z^4}}. \quad (F.2.9)$
```

It can be seen that if $b^2\Delta Z^2 > \sigma^4$, then the eigenvalues are complex, and if $\sigma^4 \geq b^2\Delta Z^2$, then the eigenvalues are real. We will consider each of these cases in turn.

# Complex eigenvalues: $b^2\Delta Z^2 > \sigma^4$

We will represent the $k$th complex eigenvalue as

```
$$\lambda_k = R + iY$.
```

where the real part

```
$$\R = 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right)$
```

and the imaginary part

```
$$\Y = 2\sqrt{AC} \cos\left(\frac{k\pi}{n_{s-2}+1}\right)$.
```

Since

```
$|\lambda_k| > |R| + |Y| \quad \text{and} \quad |R| > 1$,
```

we conclude that

```
$|\lambda_{min}| > 1$.
```

# Real eigenvalues: $\sigma^4 \geq b^2\Delta Z^2$

In this case, the $k$th eigenvalue is real, and from equation (F.2.8), we have

```
$$\lambda_k > 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right) - 2\sqrt{AC}.$$
```

Since $b^2\Delta Z^2 > 0$ from equation (F.2.9), we have

```
$$\2\sqrt{AC} < \sqrt{\frac{\sigma^4\Delta t^2}{\Delta Z^4}}$$
```

or

```
$$\2\sqrt{AC} < \sqrt{\frac{\sigma^2\Delta t}{\Delta Z^2}}$$
```
