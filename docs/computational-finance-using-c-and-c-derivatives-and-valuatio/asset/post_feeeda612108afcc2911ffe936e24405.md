The expectation of the $t$ moment (where $t$ is a positive integer) of $x$ is thus

```
$E[x^t] = \frac{1}{\sigma \sqrt{2\pi}} \int_{-\infty}^{\infty} x^{t-1} \exp\left(\frac{(\log(x) - \mu)^2}{2\sigma^2}\right)dx.$
```

Using $y = \log(x)$, we have

```
$\frac{dy}{dx} = \frac{1}{x} = \frac{1}{x}, dx = xdy$ and $x^t = (e^y)^t = e^{ty}.$
```

Thus,

```
$E[x^t] = E[e^{ty}] = M_y(t) = \frac{1}{\sigma \sqrt{2\pi}} \int_{y=-\infty}^{\infty} e^{ty} \exp\left(\frac{(y-\mu)^2}{2\sigma^2}\right)dy$.
```

where $M_y(t)$ is the moment generating function of a normal distribution with mean $\mu$ and variance $\sigma^2$.

From Appendix D.1,

```
$E[x^t] = M_y(t) = \exp\left(\mu + \frac{\sigma^2 t^2}{2}\right)$.
```

Therefore, if $x \sim \Lambda(\mu, \sigma^2)$, then for $t=1$,

```
$E[x] = \exp\left(\mu + \frac{\sigma^2}{2}\right). (D.2.2)
```

for $t=2$, and the variance is obtained using

```
$E[x^2] = \exp(2\mu + 2\sigma^2), (D.2.3)
```

```
$Var[x] = \exp(2\mu + \sigma^2) (\exp(\sigma^2) - 1)$.
```

So

```
$Var[x] = \exp(2\mu + \sigma^2) (\exp(\sigma^2) - 1)$
```

or

```
$Var[x] = (E[x])^2 (\exp(\sigma^2) - 1). (D.2.4)
```

Note: If $x_1 = \exp(\mu + \sigma Z)$, where $Z \sim N(0,1)$, then $x_1 \sim \Lambda(\mu, \sigma^2)$. So $E[x_1]$ and $Var[x_1]$ are given by equations (D.2.2) and (D.2.4).

## GENERAL ERROR DISTRIBUTION

This section proves various relations for generalized error distribution. The density function for generalized error distribution is

```
$f(\epsilon_i) = \mathcal{K}\exp\left(-\frac{\epsilon_i^2}{2\lambda}\right), \quad \text{where} \mathcal{K} = \frac{1}{\sqrt{2\pi\lambda}} (D.4.1)
```

## D.4.1 Value of $\lambda$ for Variance $h_i$

Calculation of the scale factor $\lambda$ required for a error distribution with mean 0 and variance $h_i$. The variance of the distribution, $E(\epsilon_i^2)$, is given by

```
$E(\epsilon_i^2) = \mathcal{K}\int_{-\infty}^{\infty} \epsilon_i^2\exp\left(-\frac{\epsilon_i^2}{2\lambda}\right)d\epsilon_i = 2\mathcal{K}\int_{0}^{\infty}\epsilon_i^2\exp\left(-\frac{\epsilon_i^2}{2\lambda}\right)d\epsilon_i.$
```

Using the standard integrals in Appendix E.1 with $n=2, p=a,$ and $b=1/2$ gives

```
$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\frac{3}{2}\right) \left\{\frac{1}{2\lambda}\right\}^
```

which after some simplification gives

```
$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\frac{3}{2}\right) \lambda$
```

Substituting for $\mathcal{K}$ and simplifying gives

```
$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\frac{3}{2}\right) \lambda$
```

The required value of $\lambda$ is therefore

## D.4.2 The Kurtosis

```
$E[\epsilon_i^4] = \int_{-\infty}^{\infty} \epsilon_i^4 \exp\left(-\frac{\epsilon_i^2}{2\lambda}\right)d\epsilon_i = 2\mathcal{K}\int_{0}^{\infty} \epsilon_i^4 \exp\left(-\frac{\epsilon_i^2}{2\lambda}\right)d\epsilon_i.$
```

However from standard tables

```
$E[\epsilon_i^4] = \frac{1}{(2\lambda)^a} \exp(-b\epsilon_i^a) = \frac{\Gamma(k)}{p^k}$
```

where $p=a, b=\frac{1}{2}(\lambda)^a$ and $k=\frac{5}{a}$ which gives

```
$E[\epsilon_i^4] = \frac{2\mathcal{K} 2^{5/a} \lambda^5}{a} \Gamma\left(\frac{5}{a}\right) = 2^{2/a} \lambda^2 h_i \Gamma\left(\frac{3}{a}\right)$
```

From Appendix E.1, we have

```
$E[\epsilon_i^2] = h_i \frac{2\mathcal{K} 2^{3/a} \lambda^3}{a} \Gamma\left(\frac{3}{a}\right) \text{ and } \lambda^2 = h_i \frac{2^{-2/a} \Gamma(1/a)}{\Gamma(3/a)}$
```

Therefore,

```
$E[\epsilon_i^4] = h_i^2 \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}$
```

which gives the kurtosis as

```
$\kappa = \frac{E[\epsilon_i^4]}{(E[\epsilon_i^2])^2} = \frac{h_i^2 \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}}{\left(h_i \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}\right)}$
```
