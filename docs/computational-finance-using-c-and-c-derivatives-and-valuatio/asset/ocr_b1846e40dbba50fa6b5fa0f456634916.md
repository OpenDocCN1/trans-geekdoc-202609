# 64 CHAPTER 4 European Options

Since the stochastic variables $S_{i,t} = 1, \dots, n$ follow $n$-dimensional GBM, the change in the $i$th asset price, $\Delta S_i$, over the time interval $\Delta t$ is given

```
$\Delta S_i = \mu_i S_i \Delta t + \sigma_i S_i \Delta W_i, \quad i = 1, \dots, n, \quad (4.4.20)$
```

where $\Delta W_i = dZ_i \sqrt{\Delta t}$,

```
$E[dZ_i^2] = 1, i = 1, \dots, n,$
```

and $E[dZ_i dZ_j] = \rho_{i,j}, \quad i = 1, \dots, n, \quad j = 1, \dots, n, \quad i \neq j.$

Substituting equation (4.4.17) and (4.4.20) into equation (4.4.19), we obtain

```
$\Delta \Pi = - \left{\frac{\partial f}{\partial t} + \sum_{i=1}^n \mu_i S_i \frac{\partial f}{\partial S_i} + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j}\right\} \Delta t$ \\n - \sum_{i=1}^n \sigma_i S_i \Delta W_i \frac{\partial f}{\partial S_i} + \frac{1}{2} \sum_{i=1}^n ({\mu_i S_i \Delta t + \sigma_i S_i \Delta W_i})\,$
```

```
$\. \Delta \Pi = - \sum_{i=1}^n \mu_i S_i \Delta t \frac{\partial f}{\partial S_i} - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j} \\n - \sum_{i=1}^n \sigma_i S_i \Delta W_i \frac{\partial f}{\partial S_i} + \sum_{i=1}^n \mu_i S_i \frac{\partial f}{\partial S_i} + \sum_{i=1}^n \sigma_i S_i \Delta W_i \frac{\partial f}{\partial S_i}., \quad (4.4.21)$
```

Cancelling the terms, we get

```
$\Delta \Pi = -\Delta t \left{\frac{\partial f}{\partial t} + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j}}\right{}, \quad (4.4.22)$
```

If this portfolio is to grow at the riskless interest rate, $r$, we have

```
$r \Pi \Delta t = \Delta \Pi.$
```

From equation (4.4.22), we have that

```
$r \Pi \Delta t = -\Delta t \left{\frac{\partial f}{\partial t} + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j}}, \quad (4.4.23)$
```

Substituting for II and we get

```
$r \Delta t = \left{f - \sum_{i=1}^n S_i \frac{\partial f}{\partial S_i}}\right} = -\Delta t \left{\frac{\partial f}{\partial t} + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j}}\right). \quad (4.4.24)$
```

Rearranging equation (4.4.24) gives

```
$\frac{\partial f}{\partial t} + \sum_{i=1}^n S_i \frac{\partial f}{\partial S_i} + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \sigma_i \sigma_j \rho_{i,j} S_i S_j \frac{\partial^2 f}{\partial S_i \partial S_j}} = rf,$
```

which is the $n$-dimensional Black–Scholes partial differential equation.
