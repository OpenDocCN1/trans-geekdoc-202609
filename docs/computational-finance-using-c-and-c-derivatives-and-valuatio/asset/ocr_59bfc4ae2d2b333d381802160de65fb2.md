# C.1 THE LAW OF LARGE NUMBERS

Let $x_1, x_2, \dots$ be a sequence of independent, identically distributed random variables (IID), each with expected value $\mu$ and variance $\sigma^2$. Define the sequence of averages

```
$y_n = \frac{\sum_{i=1}^n x_i}{n} = \frac{x_1 + x_2 + \dots + x_n}{n}, \quad n=1, 2, \dots$
```

Then the law of large numbers states that $y_n$ converges to $\mu$ as $n \to \infty$, that is, $Var[y_n] \to 0$.

The mean of $y_n$ is

```
$E[y_n] = \frac{1}{n}(E[x_1] + E[x_2] + \dots + E[x_n]) = \frac{1}{n}n\mu = \mu$.
```

For the variance of $y_n$, we have

```
$Var[y_n] = Var[\frac{\sum_{i=1}^n x_i}{n^2}] = \frac{1}{n^2}Var[\sum_{i=1}^n x_i] = \frac{1}{n^2}\sum_{i=1}^n Var[x_i] = \frac{1}{n^2}n\sigma^2 = \frac{\sigma^2}{n},\n$
```

where we have used the fact that the variance of the sum of independent random variables is the sum of their variances, see Appendix C.2. We have therefore that as $n \to \infty, Var[y_n] \to 0$.

# C.2 THE CENTRAL LIMIT THEOREM

Let $x_1, x_2, \dots$ be a sequence of $IID$ random variables, each with expected value $\mu$ and variance $\sigma^2$. If we define $u_i = x_i - \mu$, then

```
$E[u_i] = E[u] = 0. \quad Var[u_i] = E[u_i^2] = \sigma^2$.
```

Let

```
$s_n = \frac{\sum_{i=1}^n u_i}{n} + n\mu$.
```

So

```
$s_n = \frac{\sum_{i=1}^n x_i}{n}$.
```
