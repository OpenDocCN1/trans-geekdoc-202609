# The BBSR method

The BBSR method applies two-point Richardson extrapolation to the computed BBS values, for more information Richardson extrapolation see Marchuk and Shaidurov (1983). In this method, the option price estimates from two BBS lattices, with differing number of time steps, are combined to form an improved estimate.

Here, we are using the following BBSR method to compute the value of an American option:

$C_{BBSR}(S,E,	au,2n) = \frac{4}{3}C_{BBS}(S,E,	au,2n) - \frac{1}{3}C_{BBS}(S,E,	au,n), \quad (5.3.25)$
