
So

$$\lambda_{min} > 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right) - \frac{\sigma^2 \Delta t}{\Delta Z^2}$$

Therefore, we have

$|\lambda_{min}| > 1 + r\Delta t$

and since $r > 0$, we have

$|\lambda_{min}| > 1$.

## Appendix G

### The Brownian Bridge: Alternative Derivation

Here, we provide an alternative derivation of the Brownian bridge equation given in Chapter 2.

Let a Brownian process have values $W_{t_0}$ at time $t_0$ and $W_{t_1}$ at time $t_1$. We want to find the conditional distribution of $W_t$ given $W_{t_0}$, where $t_0 < t < t_1$. This distribution will be denoted by $P(W_t|\{W_{t_0}\})$, where $W_t$ is conditional on the end values $W_{t_0}$ and $W_{t_1}$. We have

$$P(W_t|W_{t_0}) = \frac{1}{\sqrt{2\pi(t-t_0)}} \exp\left(\frac{(W_t-W_{t_0})^2}{2(t-t_0)}\right)$$

The joint distribution of $W_{t_0}$ and $W_{t_1}$ given $W_{t_0}$ is

$$P(\{W_{t_0},W_{t_1}\}|W_{t_0}) = P(W_{t_0}|W_{t_0})P(W_{t_1}|W_{t_0}) = \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \exp\left(\left(\frac{(W_t-W_{t_0})^2}{2(t-t_0)} - \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t)}\right)\right) = \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \exp\left(\left(-\frac{1}{2}\left(\frac{(W_t-W_{t_0})^2}{2(t-t_0)} + \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t)}\right)\right)\right)$$

Similarly,

$$P(W_{t_1}|W_{t_0}) = \frac{1}{\sqrt{2\pi(t_1-t_0)}} \exp\left(\frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t_0)}\right)$$

Now we have

$$P(W_t|{W_{t_0},W_{t_1}\}) = \frac{P(W_{t_0},W_{t_1}|W_{t_0})}{P(W_{t_0}|W_{t_0})} = \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \times \exp\left\left(-\frac{1}{2}\left(\frac{(W_t-W_{t_0})^2}{2(t-t_0)} + \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t)}\right)\right\right.$$

For ease of reference we write this equation as

$$P(W_t|{W_{t_0},W_{t_1}}) = \frac{1}{\sqrt{2\pi(t_1-t_0)(t_1-t)}} \exp\left\{A\right\}$$

## APPENDIX G The Brownian Bridge: Alternative Derivation

We consider the terms in the exponent A,

$$A = -\frac{1}{2} \left( \frac{(X_1-X_0)^2(t_1-t)(t-t_0)}{(t-t_0)(t_1-t)(t_1-t_0)} + \frac{(X_1-X_0)^2(t-t_0)}{(t-t_0)(t_1-t)(t_1-t_0)} \right) - \frac{(X_1-X_0)^2(t-t_0)(t_1-t)}{(t-t_0)(t_1-t)(t_1-t_0)}$$

where $V = \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2}$

So

$$A = -\frac{1}{2V} \left( \frac{(t_1-t)}{(t_1-t_0)} \frac{(t-t_0)}{(t_1-t_0)} \right) + W_{t_1}^2 \frac{(t_1-t)}{(t_1-t_0)^2} + W_{t_0}^2 \frac{(t-t_0)}{(t_1-t_0)^2} - 2W_{t_1}W_{t_0} \frac{(t_1-t)(t-t_0)}{(t_1-t_0)^2}$$

where $V = \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2} \quad \mu = W_{t_0} \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1} \frac{(t-t_0)}{(t_1-t_0)}$

Therefore we have

$$B = -\frac{1}{2V} \left( W_{t_0}^2 \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1}^2 \frac{(t-t_0)}{(t_1-t_0)} \right)^2 - 2W_{t_1} \left( W_{t_0} \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1} \frac{(t-t_0)}{(t_1-t_0)} \right)$$

Expanding and gathering terms, we obtain

$$B = -\frac{1}{2V} \left( W_{t_0}^2 \frac{(t_1-t)^2}{(t_1-t_0)^2} + W_{t_1}^2 \frac{(t-t_0)^2}{(t_1-t_0)^2} + 2W_{t_1}W_{t_0} \frac{(t_1-t)(t-t_0)}{(t_1-t_0)^2} \right) - 2W_{t_1}W_{t_0} \frac{(t_1-t)(t-t_0)}{(t_1-t_0)^2}$$

## The Brownian Bridge: Alternative Derivation

Comparing coefficients of A and B, we have the following:

Coefficients for $W_t^2$:

$A : \frac{1}{2V} \left( \frac{(t_1 - t)}{(t_1 - t_0)} + \frac{(t - t_0)}{(t_1 - t_0)} \right) = -\frac{1}{2V} \left( \frac{t_1 - t + t - t_0}{t_1 - t_0} \right) = -\frac{1}{2V}$,

$B : \frac{1}{2V^2}$,

Coefficients for $W_{t_1}^2$:

$A : \frac{1}{2V} \left( \frac{(t_1 - t)}{(t_1 - t_0)} - \frac{(t - t_0)(t_1 - t)}{(t_1 - t_0)^2} \right) = \frac{1}{2V} \left( \frac{(t_1 - t)(t_1 - t_0) - (t - t_0)(t_1 - t)}{(t_1 - t_0)^2} \right)$,

Coefficients for $W_{t_0}^2$:

$A : \frac{1}{2V} \left( \frac{(t - t_0)(t_1 - t_1) - (t - t_0)(t_1 - t)}{(t_1 - t_0)^2} \right) = \frac{1}{2V} \left( \frac{(t - t_0)(t_1 - t_0 - t_1 + t)}{(t_1 - t_0)^2} \right)$,

### H.1 SOME CONCERNING BROWNI MOTION

Here, we will prove some facts concerning Brownian motion.

If the Brownian motion has zero drift,

$$dX_t = \sigma \sqrt{dt} dZ_t, \quad dZ_t \sim N(0,1)$$

$$P(m_t^X \leq b, X_t \geq x) = N_1 \left(\frac{2b-x}{\sigma\sqrt{dt}}\right)$$

where $m_t^X$ denotes the minimum value of $X_t$ over the interval $[0,t]$, $b \leq 0$, and $x \geq 0$.

When the Brownian motion has nonzero drift then

$$dX_t = vt + \sigma \sqrt{dt} dZ_t, \quad dZ_t \sim N(0,1)$$

and the following equations are satisfied by $m_t^X$ and $\tilde{X}_t$,

$$P(\tilde{X}_t \leq K) = N_1 \left(\frac{K-vt}{\sigma\sqrt{dt}}\right)$$

$$P(\tilde{X}_t \geq K) = N_1 \left(\frac{vt-K}{\sigma\sqrt{dt}}\right)$$

$$P(m_t^X \leq b, \tilde{X}_t \geq x) = \exp\left(\frac{2vb}{\sigma^2}\right) N_1 \left(\frac{2b-x+vt}{\sigma\sqrt{dt}}\right)$$

$$P(m_t^X \geq b, \tilde{X}_t \geq x) = N_1 \left(\frac{2vb}{\sigma\sqrt{dt}}\right) - \exp\left(\frac{2vb}{\sigma^2}\right) N_1 \left(\frac{2b-x+vt}{\sigma\sqrt{dt}}\right)$$

$$P(m_t^X \leq b) = N_1 \left(\frac{b-vt}{\sigma\sqrt{dt}}\right) - \exp\left(\frac{2vb}{\sigma^2}\right) N_1 \left(\frac{b+vt}{\sigma\sqrt{dt}}\right)$$

$$P(m_t^X \geq b) = N_1 \left(\frac{vt-b}{\sigma\sqrt{dt}}\right) - \exp\left(\frac{2vb}{\sigma^2}\right) N_1 \left(\frac{b+vt}{\sigma\sqrt{dt}}\right)$$

where $K$ is a constant, $\tilde{X} \geq 0, b \leq 0$, and $P(condition)$ denotes the probability associated with the appropriate condition, i.e., $\tilde{X}_t \geq K, m_t^X \geq b, \tilde{X}_t \geq x$, e.c.

The conditional probability density function associated with $P(m_t^X \leq b, \tilde{X}_t \geq x)$ is

$$P(m_t^X \leq b, \tilde{X}_t \geq x) = \frac{1}{\sqrt{2\pi V}} \exp\left(\frac{(X_t - \mu)^2}{2V}\right)$$
