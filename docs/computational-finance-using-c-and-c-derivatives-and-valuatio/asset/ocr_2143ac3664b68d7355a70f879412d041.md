# Quanto Caplet

In a quanto caplet instead of the domestic forward rate $F^d(t,t_{k-1},t_k)$, we use the foreign forward rate $F^f(t,t_{k-1},t_k)$. Under the probability measure $\mathbb{F}$ associated with a foreign zero coupon bond $DF^f(t,t_k)$, the foreign forward rate is a martingale and is described by the following equation:

```
$d(F^f(t,t_{k-1},t_k)) = \sigma_f F^f(t,t_{k-1},t_k)dW^F_f$. (7.2.77)
```

However, when we use $DF^d(t,t_k)$ as a numeraire, the process $[\mathbb{F}\{F^f(t,t_{k-1},t_k)/DF^d(t,t_k)\}]$ has a drift and we price the quanto caplet

```
$d(F^f(t,t_{k-1},t_k)) = d(F^f(t,t_{k-1},t_k))\alpha dt + \sigma_f F^f(t,t_{k-1},T_k)dW^F_f$. (7.2.78)
```

Our aim is to find the value of $\alpha$ and then price the quanto caplet $QCaplet(t_0) = P	au DF^d(t_0,t_k)\mathbb{F}\{\exp(\alpha(t_{k-1}-t_0))N_1(d_1) - KN_1(d_2)\}$. (7.2.79)

Where $P$ is the principal, $K$ is the strike, $	au = t_{k-1}-t_0$, $F^f(t_0,t_{k-1},t_k)$ is the foreign currency rate, $\sigma_f$ is the volatility of $F^f(t_0,t_{k-1},t_k)$ and

```
$d_1 = \frac{\log\left(\frac{F^f(t_0,t_{k-1},t_k)}{K}ight) + \left(\alpha + \frac{\sigma_f^2}{2}ight)(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```

```
$d_2 = \frac{\log\left(\frac{F^f(t_0,t_{k-1},t_k)}{K}ight) + \left(\alpha - \frac{\sigma_f^2}{2}ight)(t_{k-1}-t_0)}{\sigma_f\sqrt{t_{k-1}-t_0}}$
```

We will now derive the value of $\alpha$.

First we define two $X_1(t)$ and $X_2(t)$ such that

```
$X_1(t) = \frac{DF^f(t,t_{k-1}) - DF^f(t,t_k)}{DF^d(t,t_k)}X_d^f(t)$ (7.2.80)
```

and

```
$X_2(t) = 	au X_f^f(t)\frac{DF^f(t,t_k)}{DF^d(t,t_k)} = 	au X_f^f(t).$ (7.2.81)
```

where $X_f^f(t,t_k)$ is the forward foreign exchange rate, see Section 7.3. Therefore,

```
$\frac{X_1(t)}{X_2(t)} = \frac{DF^f(t,t_{k-1}) - DF^f(t,t_k)}{	au DF^f(t,t_k)} = F^f(t,t_{k-1},t_k).$ (7.2.82)
```
