# 3.3.3 Student's $t$-Distribution

If $S_t(\mu,v)$ represents the Student's $t$-distribution with mean $\mu$ and number of degrees of freedom $v$, then $X \sim S_t(0,v)$ can be generated as follows:

```
$X \sim \frac{Z}{\sqrt{Y/v}} \qquad (3.3.15)
```

where $Z \sim N(0,1)$ and $Y \sim \chi_v^2$. The variance of $X$ is

```
$E[X^2] = \frac{\nu}{\nu-2}$.
```

Variates $X'$ from Student's $t$-distribution having $v$ degrees of freedom with mean $\mu$ and variance $s$ can be generated by modifying equation (3.3.15) as follows:

```
$X' \sim \mu + \frac{s^{1/2}}{\sqrt{v/(v-2)}}\sqrt{Y/v} \qquad (3.3.16)
```

The probability density function, $f(x)$, for $X'$

```
$f(x) = \frac{\Gamma((v+1)/2)}{\Gamma(v/2)^{-1/2}\pi^{1/2}\Gamma(v/2)} \left[ 1 + \frac{(x-\mu)^2}{s(v-2)} \right]^{-(v+1)/2} \qquad (3.3.17)
```

where $v > 2$.

# 3.4 GENERATION OF MULTIVARIATE DISTRIBUTIONS: CORRELATED VARIATES

In this section, we will show how to generate variates from a multivariate distribution with a known mean and a given covariance or correlation matrix. The methods described for covariance matrices are also applicable to correlation matrices, in which case the generated variates are normalized to have unit variance.

# 3.4.1 Estimation of Correlation and Covariance

Here, we show how to obtain a valid correlation matrix $C_R$ or covariance matrix $C$ from historic market data.

Let $\hat{X}$ be an $n \times p$ data matrix, with entries in the $i$-th row containing the $i$-th observation, and the $j$-th column containing the values of the $j$-th variable.
