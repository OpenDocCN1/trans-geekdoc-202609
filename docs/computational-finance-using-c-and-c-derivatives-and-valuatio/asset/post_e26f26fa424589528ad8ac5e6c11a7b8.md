If we let $\mathcal{G} = (x_1 - \mu_1)^T\Sigma^{11}(x_1 - \mu_1) + 2(x_1 - \mu_1)^T\Sigma^{12}(x_2 - \mu_2)$, then we obtain

$$\mathcal{G} = (x_1 - \mu_1)^T\Sigma^{11}(x_1 - \mu_1) + (x_1 - \mu_1)^T\Sigma^{12}(x_2 - \mu_2)$$
$+ (x_2 - \mu_2)^T\Sigma^{21}(x_1 - \mu_1),$$
$$\mathcal{G} = \{x_1 - \mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2 - \mu_2)\}\{x_1 - \mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2 - \mu_2)\}$$
$- (x_2 - \mu_2)^T\Sigma^{21}(\Sigma^{12})^{-1}(x_2 - \mu_2). \quad (C.4.11)$$

where for instance we have used the fact that that scalar quantity

$$\{(x_1 - \mu_1)^T\Sigma^{12}(x_2 - \mu_2)\} = (x_2 - \mu_2)^T\Sigma^{21}(x_1 - \mu_1).$$

Since the last term in equation (C.4.11) only involves constants (as far as $f(x_1|x_2)$ is considered), it follows that

$$f(x_1|x_2) = \exp\left[-\frac{1}{2}\{x_1 - \mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2 - \mu_2)\}\right]$$
$$\times \Sigma^{11}\{x_1 - \mu_1 + (\Sigma^{11})^{-1}\Sigma^{12}(x_2 - \mu_2)\},$$

which is the distribution of a multivariate normal distribution that has a mean of $\mu_1 - (\Sigma^{11})^{-1}\Sigma^{12}(x_2 - \mu_2)$, which from equation (C.4.7) can be expressed as $\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$. The covariance matrix is $(\Sigma^{11})^{-1}$, which from equation (C.4.9) can be written as $\Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$.

## C.5 MOMENT GENERATING FUNCTIONS

If $x$ is a random variable with probability distribution $f_x(x)$, then the moment generating function $M_x(t)$ is defined by

$$M_x(t) = E[e^{tx}] = \int_{-\infty}^{\infty} e^{tx} f_x(x)dx.$$

We can expand the following expression as:

$$E[e^{tx}] = E[1 + tx + \frac{1}{2}(tx)^2 + ...].$$

$$M_x(t) = 1 + tE[x] + \frac{1}{2}t^2E[x^2] + .. \quad (C.5.1)$$

Now

$$\frac{d^k(M_x(t))}{dt^k} = \frac{d^k}{dt^k}\{E[e^{tx}]\} = E[\frac{d^k}{dt^k}e^{tx}] = E[x^k e^{tx}].$$

For $t = 0$, we have

$$\frac{d^k(M_x(t))}{dt^k}|_{t=0} = \frac{d^k(M_x(0))}{dt^k} = E[x^ke^0] = E[x^k]. \quad (C.5.2)$$

## APPENDIX | C Standard Statistical Results

### Moment generating function of a linear function of a random variable x

If the random variable $y$ is defined as $y = ax+b$, then the moment generating function of $y$, $M_y(t)$ is defined as follows:

$$M_y(t) = M_{ax+b}(t) = E[e^{ty}] = E[e^{t(ax+b)}] = e^{bt}E[e^{tx}].$$

Therefore,

$$M_y(t) = e^{bt}M_x(at). \quad (C.5.3)$$

### Moment generating function of a linear combination of random variables

Let $z = x + y$ where $x$ and $y$ are independent random variables then

$$M_z(t) = E[e^{tz}] = E[e^{t(x+y)}] = E[e^{tx}e^{ty}].$$

Since $x$ and $y$ are independent,

$$E[e^{tx}e^{ty}] = E[e^{tx}]E[e^{ty}] = M_x(t)M_y(t).$$

More generally, if $s_n = \sum_{i=1}^n x_i$ where $x_i, i = 1, \dots, n$ are independent, then

$$M_{s_n}(t) = \prod_{i=1}^n M_{x_i}(t). \quad (C.5.4)$$

If $x_i, i = 1, \dots, n$ are IID, then we have

$$M_{s_n}(t) = E\left[\exp(t\sum_{i=1}^n x_i)\right] = (E[e^{tx}])^n. \quad (C.5.5)$$

## Appendix D Statistical Distribution Functions

### D.1 THE NORMAL (GAUSSIAN) DISTRIBUTION

Here, we describe some properties of the normal distribution. If $x$ comes from a normal distribution, then the associated moment generating function $M_x(t)$ is given by

$$M_x(t) = E[e^{tx}] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx.$$

Now completing the square we have

$-\frac{1}{2\sigma^2}(x-\mu)^2 = -\frac{1}{2\sigma^2}(x^2 - 2\mu x + \mu^2) = -\frac{1}{2\sigma^2}(x-\mu t)^2 - \frac{\mu^2}{2\sigma^2}$ (Wait, standard derivation follows):

$$M_x(t) = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx.$$

Now letting $y=x-\mu$, $dx=dy$, and

$$E[e^{tx}] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{y^2}{2\sigma^2} + ty\right)dy.$$

where we have used (see Appendix E.1) the fact that

$$\int_{-\infty}^{\infty} \exp(-ay^2) dy = \sqrt{\frac{\pi}{a}}$$

Thus, the moment generating function $M_x(t)$ for a normal distribution with mean $\mu$ and variance $\sigma^2$ is

$$M_x(t) = \exp(\mu t + \frac{\sigma^2 t^2}{2}).$$

### Some Elementary Results Involving the Mean and Variance of Normal Distribution

From first principles, we have the following:

The mean:

$$E[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} x \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx.$$

Let $x = x - \mu$ we have $dx = dy$ and $y = y + \mu$; therefore,

$$E[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} (y + \mu) \exp\left(-\frac{y^2}{2\sigma^2}\right)dy.$$

$$E[x] = \mu \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{y^2}{2\sigma^2}\right)dy + \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y \exp\left(-\frac{y^2}{2\sigma^2}\right)dy.$$

Since

$$\int_{-\infty}^{\infty} y \exp\left(-\frac{y^2}{2\sigma^2}\right)dy = 0,$$$$

we have using the integral result (1) in Appendix E.1 with $a=1/2\sigma^2$,

$$E[x] = \mu \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{y^2}{2\sigma^2}\right)dy = \mu.$$

The variance:

$$Var[x] = E[x^2] - (E[x])^2 = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} x^2 \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx - \mu^2.$$

Let $x = x-\mu$ we have $dx=dy$ and

$$Var[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} (y+\mu)^2 \exp\left(-\frac{y^2}{2\sigma^2}\right)dy - \mu^2.$$

$$Var[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} (y^2 + 2\mu y + \mu^2) \exp\left(-\frac{y^2}{2\sigma^2}\right)dy - \mu^2.$$

$$Var[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y^2 \exp\left(-\frac{y^2}{2\sigma^2}\right)dy + 0 + \mu^2 - \mu^2 = \sigma^2.$$

### D.2 THE LOGNORMAL DISTRIBUTION

If the variable $x$ follows a lognormal distribution, then the probability density function $f(x)$ is given by

$$\frac{1}{x\sqrt{2\pi}} \exp\left(\frac{(\log(x) - \mu)^2}{2\sigma^2}\right), \quad (D.2.1)$$

where $x > 0$. Here, we describe some properties of the lognormal distribution. If $x \sim \mathcal{A}(\mu, \sigma^2)$, then $\log(x) \sim N(\mu, \sigma^2)$. The mean and variance of $x$ can be found using the moment generating function of the normal distribution.
