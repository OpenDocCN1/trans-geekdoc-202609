We will now consider the case in which the basis swap has been traded at time $t$ and shall assume that $C_1 = C_2 = 0$ and $t = t_{k_1} = t_{k_2}$. In addition, we will specify that principal exchange occurs at the start (time $t$) and end (time $t_n$) of the swap.

The cash flows associated with principal exchange at the start of the swap are in the opposite direction for the remainder of the swap, Hull (2003).

```
$FLT_1(t) = P_1 - P_1 DF(t,t_n) + \{-P_1 + P_1 DF(t,t_n)\}$
```

and

```
$FLT_2(t) = P_2 - P_2 DF(t,t_n) + \{-P_2 + P_2 DF(t,t_n)\}$
```

where the principal exchange terms are in the curly brackets and discount factors $DF(t,T)$ derived from the main currency curve rather than $DF_1(t,T)$ or $DF_2(t,T)$.

It can be seen from (7.2.21) that principal exchange at the start of the swap causes leg 2 to contribute the positive amount $P_2$ to the value of the swap, while leg 1 contributes the negative amount $P_2$ to the value of the swap. In contrast, principal exchange at the end of the swap results in leg 2 contributing the negative $-P_2 DF(t,t)$ to the swap value while leg 1 contributes the positive amount $P_1 DF(t,t)$. If $P_1 = P_2 = P$, principal exchange does not affect the value of the swap. It can also be seen from (7.2.24) if leg 1 used the main GBP currency curve of the 1-month LIBOR curve $DF_1(t,t_n) = DF(t,t)$, which would result in $FLT_1(t) = 0$. $DF_2(t,t_n) = DF(t,t)$ would mean $FLT_2(t) = 0$.

If the validation time $t$ is after the swap has started, then equation (7.2.21) and (7.2.25) need to be used to price the value of the swap, but equations be modified as follows:

```
$FLT_1(t) = P_1 DF(t,t_{k_1}) + \{-P_1 DF(t,t_{k_n})\}$
```

and

```
$FLT_2(t) = P_2 DF(t,t_{k_2}) - P_2 DF(t,t_n) + \{P_2 DF(t,t_n)\}$
```

# Coupon Payment on Time

In this section, we will justify the approach we have adopted in obtaining the present value of future cash flows generated from vanilla swaps.

From equation (4.2.1), we know that the value at time $t_k$ of a coupon payment at time $t_k$ is

```
$V_0 = DF(t_0, t_k) E^{Q^k} \frac{F(t_{k-1}, t_{k-1}, t_k)}{DF(t_k, t_k)} rP$
```

where the symbols have their usual meaning, and we have chosen the numeraire to be the zero coupon bond which matures at time $t_k$. Since $DF(t_k,t_k) = 1$, we can write

```
$V_0 = DF(t_0, t_k) E^{Q^k} [F(t_{k-1}, t_{k-1}, t_k)] rP$
```
