If $S_T \geq E$
Portfolio A is worth,

$\max(S_T - E, 0) + \exp(r\tau)E\exp(-r\tau) = S_T - E + E = S_T .$

Portfolio B is worth,

$\max(S_T - E, 0) + S_T\exp(-q\tau)\exp(q\tau) = 0 + S_T = S_T,$

where $S\exp(-q\tau)\exp(q\tau)$ is the combined value of the shares and dividends
at option maturity.

If $S_T < E$
Portfolio A is worth,

$\max(S_T - E, 0) + \exp(r\tau)E\exp(-r\tau) = 0 + E = E.$

Portfolio B is worth,

$\max(S_T - E, 0) + S_T\exp(-q\tau)\exp(q\tau) = E - S_T + S_T = E.$

We have therefore shown that under all conditions the value of portfolio A
is is the same as that of portfolio B.

# 4.4.1 The Option Pricing Partial Differential Equation

In this section, we will derive the (Black–Scholes) partial differential equation
that is obeyed by options on a single asset.

Previously, in Sections 2.3 and 2.5, we derive Ito's lemma, which provides
an expression for the change in value of the function $\phi(X,t)$, where $X$ is
stochastic variable. When the stochastic variable, $X$, follows GBM, the
in value of $\phi$ was to be shown by (2.3,6). Here, we will
assume that the function $\phi(S,t)$ is the value of a financial option and that the
price of the underlying asset, $S$, follows GBM.

If we denote the value of the financial derivative by $f$, then its change, $df$,
of the time interval $dt$ is given

```
$df =(\mu S\frac{\partial f}{\partial S} + \frac{\partial f}{\partial t} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2})dt + \sigma S\frac{\partial f}{\partial S}dW \sim N(0,dt).
```

The discretized version of this equation is

```
$\Delta f =(\mu S\frac{\partial f}{\partial S} + \frac{\partial f}{\partial t} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2})\Delta t + \sigma S\frac{\partial f}{\partial S}\Delta W \sim N(0,\Delta t),$ (4.4.1)
```

where the time interval is $\Delta t$ and the change in derivative value is $\Delta f$.
If we assume the asset price, $S$, follows GBM, we also have

```
$\Delta S = \mu S\Delta t + \sigma S\Delta W \sim N(0,\Delta t),$ (4.4.2)
```
