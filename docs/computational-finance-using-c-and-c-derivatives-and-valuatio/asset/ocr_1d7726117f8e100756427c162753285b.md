# CHAPTER | 3 Generation of Random Variates

+   Manual adjustment of a correlation matrix may have occurred to reflect expected market conditions. This especially occurs when the market crashes and certain stock prices become highly correlated.
There may be rounding error in computing $C_r = X^T X$.

Under these circumstances, the best that can be done is to try and repair the correlation matrix $C_r$ into a valid correlation matrix $\hat{C}_r$.
We proceed as follows.
When $C_r$ is not positive definite (the Cholesky decomposition fails), then we use the eigen decomposition

```
$C_r = V\Sigma V^T,$
```

where

```
$$\Sigma = \begin{pmatrix} \lambda_1 & & \ & \lambda_2 & \ & & \ddots & \ & & \lambda_p \end{pmatrix};$$
```

then we form the matrix

```
$C_r^* = V K K^T V^T = V K(V K)^T,$
```

where the matrix $K$ is formed by taking the square root of the maximum of each eigenvalue and a very small number $\epsilon$ (say $\sim10^{-16}$). Thus,

```
$$K = \begin{pmatrix} \max(\lambda_1, \epsilon) & & \ \ & \max(\lambda_2, \epsilon) & \ \ & & \ddots & \ \ & & \max(\lambda_p, \epsilon) \end{pmatrix};$$
```

The matrix $C^+$ is not acceptable as a correlation matrix because, although real, symmetric, and positive definite, its diagonal elements are not unity. It is possible to remedy this by pre- and post-multiplying $C^+$ by the diagonal matrix $F$.

```
$$\hat{C}_r^+ = FC_r^+ F = FC\hat{C}_r^+ F^T,$$
```

where $\hat{C}$ is the new repaired correlation matrix, i.e., it is positive definite, symmetric and unit diagonal elements. To achieve this, the diagonal elements of $F$ must be given by

```
$F_{ii} = \frac{1}{\sqrt{C_{ii}}}.$
```
