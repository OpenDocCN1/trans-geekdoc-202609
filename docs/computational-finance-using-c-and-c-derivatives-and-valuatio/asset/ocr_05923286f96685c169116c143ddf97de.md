# A.5 RHO

Rho is the rate of change of the option value with interest rate.

For a call, we have

$\rho_c = \frac{\partial c}{\partial r} = \frac{\partial}{\partial r} \left\{S\exp(-q(T-t))N_1(d_1) - E\exp(-r(T-t))N_1(d_2)\right\}$\
$- S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial r} + E\exp(-r(T-t))N_1(d_2) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial r};

substituting for $n(d_2)$ and $\partial d_2/\partial t$, we obtain

$\rho_c = E\exp(-r(T-t))N_1(d_2).$ (A.5.1)
