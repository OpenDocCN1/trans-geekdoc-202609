Using the standard integrals in Appendix E.1 with $n = 2, p = a,$ and $b = (1/2) (1/lambda)^a$ gives

```
$h_i = \frac{2\mathcal{K}}{a} \Gamma\left(\frac{3}{2}\right) \left\{\frac{1}{2\lambda}\right)^{\lambda^{-3/a}}$
```

which after some simplification gives

```
$h_i = \frac{2\mathcal{K} 2^{3/a} \lambda^3}{a} \Gamma\left(\frac{3}{a}\right)$
```

Substituting for $\mathcal{K}$ and simplifying then gives

```
$h_i = \lambda^2 2^{2/a} \frac{\Gamma(3/a)}{\Gamma(1/a)}$
```

The required value of $\lambda$ is therefore

```
$\lambda = \left\{ h_i 2^{-2/a} \frac{\Gamma(1/a)}{\Gamma(3/a)} \right\}^{1/2}$
```

# D.4.2 The Kurtosis

```
$E[\epsilon_i^4] = \int_{-\infty}^{\infty} \epsilon_i^4 \exp\left(-\left\frac{|\epsilon_i|}{2\lambda}\right)^a\right) d\epsilon_i \n 2\mathcal{K} \int_{-\infty}^{\infty} \epsilon_i^4 \exp\left(-\left\frac{|\epsilon_i|}{2\lambda}\right)^a\right) d\epsilon_i$
```

However from standard mathematical tables

```
$E[\epsilon_i^4] = \frac{1}{2}(\lambda)^a \exp(-b\epsilon_i^a) = \frac{\Gamma(k)}{p b^k}$
```

where $p=a, b=\frac{1}{2}(\lambda)^a$ and $k=\frac{5}{a}$ which gives

```
$E[\epsilon_i^4] = \frac{2\mathcal{K} 2^{5/a} \lambda^5}{a} \Gamma\left(\frac{5}{a}\right) \n 2^{2/a} \lambda^2 h_i \Gamma\left(\frac{3}{a}\right)$
```

From Appendix E.1, we have

```
$E[\epsilon_i^2] = h_i \frac{2\mathcal{K} 2^{3/a} \lambda^3}{a} \Gamma\left(\frac{3}{a}\right) \text{ and } \lambda^2 = h_i \frac{2^{-2/a} \Gamma(1/a)}{\Gamma(3/a)}$
```

Therefore,

```
$E[\epsilon_i^4] = h_i^2 \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}$
```

which gives the kurtosis as

```
$\kappa = \frac{E[\epsilon_i^4]}{(E[\epsilon_i^2])^2} = \frac{h_i^2 \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}}{\left(h_i \frac{\Gamma(5/a) \Gamma(1/a)}{\Gamma(3/a) \Gamma(3/a)}ight)}$
```
