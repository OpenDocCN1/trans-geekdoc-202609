# Compute the Lattice Option Prices

The method used to compute the option values is *similar* to that used by the binomial tree. The main difference is that there are now b branches per node instead of two. The option values are computed by starting at the lattice terminal nodes and iterating backwards. Here, we denote the option value at the kth time step as $f_i^k$.

The option values at the terminal nodes, $t_{d-1}$, are computed in the usual manner. For a put, we have

```
$f_{d-1}^k = \text{MAX}(E - S_{d-1}^k, 0), \quad k=1, \dots, b^{d-1}$
```

where $E$ is the exercise price. The option values at the $(i-1)$ time step are computed from those at the ith time step as follows:

```
$f_{i-1}^k = \text{MAX}(g_{i-1}^k, h_{i-1}^k)$
```

where

```
$h_{i-1}^k = \frac{\exp(-r\Delta t)}{b} \sum_{j=1}^{(k-1)b+j}$
```

and

```
$g_{i-1}^k = \text{MAX}(E - S_{i-1}^k, 0)$
```

The option value for the p stochastic lattice is therefore

```
$f_H^\theta = f_0^1 = \frac{\exp(-r\Delta t)}{b} \sum_{j=1}^b f_1^j$
```
