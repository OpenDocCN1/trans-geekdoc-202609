# The Text Files

The application is driven by a portfolio configuration file and also a number of portfolio definition files, each of which is plain text and can easily be edited by the user. The portfolio configuration file specifies the names of the portfolio files which are to be valued, and each portfolio definition file provides the details of the trades contained in a given portfolio. In addition, there is a market data file (also in text format) which provides the market data required to value the trades.

A portfolio configuration file and two portfolio definition files are included in the portfolio definition files, in Exhibit 8.1. It can be seen that it is useful to document the deals contained in the portfolio. It is also possible to ignore a single trade by using a/ at the beginning of a line. Complete sections of portfolio definition file can also be ignored by using the C style syntax /*.*/

The syntax of each deal entry in the portfolio definition file is as follows:

```
Trade=DealClass.Reference=DescriptionText.DealClassParam1=Value, ...DealClassParamN=Value
```

Each deal line begins with an assignment to the Trade attribute using the syntax Trade=DealClass, where <DealClass> is the name of the C# class used to represent the given deal, equityOption for an Equity Option. The other deal attributes are properties of DealClass and Deal valuation proceeds by first constructing an empty object of type Deal. The application converts the string representation of the attribute values to the values expected by the DealClass and assignment to the deal object occurs. Once the deal object has been populated with the required market data, the deal'Price() method is run. This retrieves the required market data, computes the deal value, and returns this to this application for output to the portfolio results file.
