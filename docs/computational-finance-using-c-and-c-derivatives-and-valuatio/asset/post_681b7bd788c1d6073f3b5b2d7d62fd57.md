# Computing the Greeks: Δ, Γ, and Θ

We will now describe how to calculate the option hedge statistics (Greeks) by $f_k$ and $S_t$ respectively. So, for instance, $S_T$ represents the asset price at $T$ and $f_T$ is the corresponding option value at node $T$. Table 5.4 supplies details of the lattice node values in the vicinity of the root node R. The computation of each Greek is now considered.

### Delta
The definition of $\Delta f$ is the rate of change of the option value with asset price; all other parameters remaining fixed. Thus,

$$\Delta = \frac{\Delta f}{\Delta S}$$

$\Delta f$ is the change value corresponding to the change in the asset price $S$. Ideally, we would like to evaluate this partial derivative at the root node $R$ ($m1=0$); however, we cannot because we need at least two lattice nodes to compute a value. The best we can do is to evaluate the derivative at the first time step (m1=1) as follows:

```cpp
$\Delta = \frac{f_S - f_T}{S_S - S_T} = \frac{v[4] - v[3]}{s[M+1] - s[M-1]}$
```

### Gamma
The definition of $\Gamma$ is the rate of change of $\Delta$ with asset price; all other parameters remaining fixed. Thus,

```cpp
$\Gamma = \frac{\partial^2 f}{\partial S^2} \frac{\partial \Delta}{\partial S}$
```

In order to evaluate $\Gamma$, we require at least two values of $\Delta$. The nearest this can be achieved to the root node $R$ is at time step 2, where we have

```cpp
$\Gamma = \frac{\Delta_{UV} - \Delta_{VW}}{S^*_{UV} - S^*_{VW}}$
```

with the midpoints and the values of $\Delta$ at the midpoints $S^*_{UV}$ and $S^*_{VW}$ denoted by $\Delta^*_{UV}$ and $\Delta^*_{VW}$ respectively. Since

```cpp
$S^*_{UV} = \frac{1}{2}\{S_U + S_V\}$
```

```cpp
$\Delta^*_{UV} = \frac{f_U - f_V}{S_U - S_V}, \Delta^*_{VW} = \frac{f_V - f_W}{S_V - S_W}$
```

and we have

```cpp
$S^*_{UV} - S^*_{VW} = \frac{1}{2}\{S_U - S_W\}$,
```

```cpp
$\Delta^*_{UV} = \frac{v[2] - v[1]}{s[M+2] - s[M]}, \Delta^*_{VW} = \frac{v[1] - v[0]}{s[M] - s[M-2]}$
```

The value of $\Gamma$ can therefore be approximated as

```cpp
$\Gamma = \frac{2\{\Delta^*_{UV} - \Delta^*_{VW}\}}{s[M+2] - s[M-2]}$
```

### Theta
The definition of $\Theta$ is the rate of change of option value with time; all other parameters remaining fixed. Thus,

```cpp
$\Theta = \frac{\partial f}{\partial t} = \frac{\Delta f}{\Delta t}$
```

The nearest to the root node $R$, this can be computed over the time interval from time step 0 to time step 2. We then obtain the following approximation:

$$\Theta = \frac{f_V - f_R}{2\Delta t} = \frac{v[1]-v[5]}{2\Delta t}$$

# Vega
The definition of $\mathcal{V}$ is the rate of change of the option value with volatility,

$$\mathcal{V} = \frac{\partial f}{\partial \sigma}.$$

In a standard binomial lattice, $\mathcal{V}$ cannot be computed directly. A simple approach is to use two binomial lattices as follows:

$$\mathcal{V} = \frac{f_{\sigma+\Delta\sigma} - f_{\sigma}}{\Delta\sigma},$$

where $f_{\sigma+\Delta\sigma}$ is the option value computed using a binomial lattice with volatility $\sigma + \Delta\sigma$, and $f_{\sigma}$ is the option value computed using another binomial lattice with volatility $\sigma$, all other parameters constant.

### 5.3.3 Binomial Lattice with a Control Variate
The control variate technique can be used to enhance the accuracy that a standard binomial lattice gives for the value of an American option. It involves using the same lattice to value both an American option and the European option. The Black-Scholes formula is then used to compute the accurate value of the European option. If we assume that the error in pricing the European option is the same as for the option, we can achieve an improved estimate for the value of the American option. When applied to the valuation of an American put option, this can be expressed as follows:

European pricing error, $\Delta_E = p^{BS}(S,E) - p^L(S,E)$,
American pricing error, $\Delta_A = p^*(S,E) - p^L(S,E)$,
where $S$ is the current value of the asset, $E$ is the strike price, and $t$ is the maturity of the option. $p^{BS}(S,E)$ is the Black-Scholes value of the European option, $p^*(S,E)$ is the accurate (unknown) value estimate of the American put option, and $p^L(S,E)$ is the binomial estimate of the American option.

Setting $\Delta_E = \Delta_A$, we then have

$$p^{BS}(S,E) - p^L(S,E) = p^*(S,E) - p^L(S,E)$$
$$p^*(S,E) = p^{BS}(S,E) - p^l(S,E) + p^L(S,E)$$

We use $p^*(S,E)$ as the improved, control variate estimate for the value of American put option. Exactly the same approach can be used to obtain an improved estimate for the value of an American call.

Code excerpt 5.12 shows the use of the control variate technique in provide improved estimates for both the value and the hedge statistics of an American option.

/* Set the arrays in the standard lattice */
