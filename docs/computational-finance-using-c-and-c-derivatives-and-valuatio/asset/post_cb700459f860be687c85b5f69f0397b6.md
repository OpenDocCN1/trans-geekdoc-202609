## 2.2 BROWNIAN MODEL OF ASSET PRICE MOVMENTS

In the previous section, we showed Brownian motion can be used to describe the motion of small particles suspended in a liquid. The first attempt at using Brownian motion to describe financial asset price movements was provided by Bachelier (1900). This however had limited success because the *significance* of a given change in asset price depends on the original asset price. For example, a £1 increase in the value of a share originally £1.10 is *more significant* than a £1 increase in the value of a share originally £100. It is for this reason that asset price movements are generally described in terms of *relative* or percentage changes. For example, if the £1.10 increases by £11 and the £100 increases, both of these price changes have the same significance and correspond to a 10% increase in value. The idea of relative price changes in the value of a share can be formalized by defining a quantity called the *return*, $R_t$, of a share at time $t$. The return $R_t$ is defined as follows:

```
$$R_t = \frac{S_{t+dt}-S_t}{S_t} = \frac{dS_t}{S_t}, \quad (2.2.1)$$
```

where $S_{t+dt}$ is the value of the share at time $t+dt$, $S_t$ is the value of the share at time $t$, and $dS_t$ is the change in value of the share over the time interval $dt$. The percentage return $R^*$, over the time interval $dt$ is simply defined as $R^* = 100 \times R_t$.

We are now in position to construct a simple Brownian model of asset price movements, however further information on Brownian motion within finance can be found in Shreve et al. (1997).
The asset return at time $t$ is now given by

```
$$R_t = \frac{dS_t}{S_t} = \mu dt + \sigma dW_t, \quad dW_t \sim N(0,dt), \quad (2.2.2)$$
```

or equivalently $$dS_t = S_t \mu dt + S_t \sigma dW_t. \quad (2.2.3).$$

The process given in equation (2.2.2) and equation (2.2.3) is termed geometric Brownian motion, which we will abbreviate as GBM. This is because the relative (rather than absolute) process follows Brownian motion.

## 2.3 ITO'S FORMULA (OR LEMMA)

In this section, we will derive Ito's formula, a more rigorous treatment than we found in Karatas and Shreve (2000).

Let us consider the stochastic process $X$,

```
$dX = a dt + b dW = ad + b\sqrt{dt} dZ, \quad dZ \sim N(0,dt), \quad dW \sim N(0,dt). \quad (2.3.1)$
```

**where** $a$ and $b$ are constants. We want to find the process followed by a function of the stochastic variable $X$, that is, $\phi(X,t)$. This can be done by applying a Taylor expansion, to order second, in the variables $X$ and $t$ as follows:

```
$\phi^* = \phi + \frac{\partial \phi}{\partial t}dt + \frac{\partial \phi}{\partial X}dX + \frac{1}{2}\frac{\partial^2 \phi}{\partial X^2}dX^2 + \frac{1}{2}\frac{\partial^2 \phi}{\partial t^2}dt^2 + \frac{\partial^2 \phi}{\partial X\partial t}dXdt, \quad (2.3.2)$
```

$\phi^*$ is used to denote the value $\phi(X+dX)$

```
$dX^2 = (adt + b\sqrt{dt} dZ)(adt + b\sqrt{dt} dZ) = a^2dt^2 + 2ab dt^{3/2} dZ + b^2 dt^2$,
```

then

```
$dXdt = a^2dt + b dt^{3/2} dZ$.
```

So as $dt \to 0$, and ignoring all terms in $dt$ of order greater than 1, we have

```
$dX^2 \sim b^2 dt, \quad dt^2 \sim 0, \quad \text{and} dXdt \sim 0$.
```

Therefore, equation (2.3.2) can be rewritten as

```
$d\phi = \frac{\partial \phi}{\partial t}dt + \frac{\partial \phi}{\partial X}dX + \frac{1}{2}\frac{\partial^2 \phi}{\partial X^2} E[dX^2]. \quad (2.3.3)$
```

where $d\phi = \phi^* - \phi$, and we have replaced $dX^2$ by its expected value $E[dX^2]$. Now

```
$E[dX^2] = b^2 dt$,
```

we have used the fact that $dZ \sim N(0,dt)$, the variance of $dZ$, $E[dZ^2]$, is by definition 1. Using these values in equation (2.3.3) and substituting for $dX$ from equation (2.3.1), we obtain

```
$d\phi = \frac{\partial \phi}{\partial t}dt + \frac{\partial \phi}{\partial X}(adt + bdW) + \frac{b^2}{2}\frac{\partial^2 \phi}{\partial X^2}dt. \quad (2.3.4)$
```

This gives Ito's formula

```
$d\phi = (\frac{\partial \phi}{\partial t} + a\frac{\partial \phi}{\partial X} + \frac{b^2}{2}\frac{\partial^2 \phi}{\partial X^2})dt + b\frac{\partial \phi}{\partial X}dW. \quad (2.3.5)$
```

In particular, if we consider the geometric Brownian process

```
$dS = \mu S dt + \sigma S dW$
```

where $\mu$ and $\sigma$ are constants substituting $X = S, a = \mu S,$ and $b = \sigma S$ into equation (2.3.5) yields

```
$df = \frac{\partial \phi}{\partial t}dt + \mu S \frac{\partial \phi}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 \phi}{\partial S^2} dt + \sigma S \frac{\partial \phi}{\partial S}dW. \quad (2.3.6)$
```

(2.3.6) describes the change of a function $\phi(S,t)$ over the time interval $dt$, when the stochastic variable $S$ follows GBM. The result has very important applications in the pricing of derivatives. Here, the function $\phi(S,t)$ is taken as the price of a financial derivative, that depends on the value of an underlying asset $S$, which is assumed to follow GBM. In Chapter 4, we will use equation (2.3.6) to derive the (Black-Scholes) partial differential equation is satisfied by the price of a financial derivative $\phi = \log(S)$. We also use equation (2.3.3) to derive

```
$\frac{\partial \phi}{\partial S_t} = \frac{\partial \log(S)}{\partial S_t} - \frac{\sigma^2}{S_t^2}$.
$\frac{\partial \phi}{\partial t} = 0.
```

So,

```
$d(\log(S)) = vdt + \sigma dW_t, \quad \text{where } v = \mu - \frac{\sigma^2}{2}. \quad (2.3.7)$
```

Integrating (2.3.7) yields

```
\int_{t=0}^T d(\log(S_t)) = \int_{t=0}^T vdt + \int_{t=0}^T \sigma dW_t,
```

so

```
\log(S_T) - \log(S_0) = vT + \sigma W_T. \quad (2.3.8)
```

where we used $t_0 = 0$ and $W_0 = 0$.

We obtain

```
\log(\frac{S_T}{S_0}) \sim N(vT, \sigma^2T). \quad (2.3.9)
```

and so

```
\log(\frac{S_T}{S_0}) = vT + \sigma W_T. \quad (2.3.10)
```

The solution to the GBM in equation (2.2.3) is

```
$$S_T = S_0 \exp(vT + \sigma W_T), \quad \nu = \mu - \frac{\sigma^2}{2}. \quad (2.3.11)$$
```

The asset value at time $t + dt$ can therefore be generated from its value at time

```
$$S_{t+dt} = S_t \exp(vdt + \sigma dW_t)$$
```

We have shown that if the asset price follows GBM, the logarithm of the asset price follows standard Brownian motion. Another way of stating this is, over the time $dt$, the change in the logarithm of the asset price is a Gaussian distribution with mean $[\mu - (\sigma^2/2)]$ and variance $\sigma^2dt$.
These results can be generalized to include time varying drift and volatility. Instead of equation (2.2.3) we have

```
$dS_t = S_t dt + \sigma_t dW_t$
```

which results in

```
$d(\log(S_t)) = v_t dt + \sigma_t dW_t$
```

so

```
$$\int_{t_0}^T d(\log(S_t)) = \int_{t_0}^T v_t dt + \int_{t_0}^T \sigma_t dW_t.$$
```

which results in the following solution for $S_T$:

```
$S_T = S_{t_0} \exp(\int_{t_0}^T v_t dt + \int_{t_0}^T \sigma_t dW_t).$
```

## 2.4 GIRSANOV'S THEOREM

This theorem states that for any stochastic process $k(t)$ such that $\int_0^t k(s)^2 ds < \infty$ then the Radon Nikodym derivative $dQ/d\mathbb{P} = \rho(t)$ is given by

```
$$\rho(t) = \exp(\int_0^t k(s)dW_s - \frac{1}{2} \int_0^t k(s)^2ds),$$
```

where $W_t^P$ is also Brownian motion (possibly with drift) under probability measure $\mathbb{P}$, we have Baxter and Rennie (1996). Under probability measure $\mathbb{Q}$, we have

```
$W_t^Q = W_{t_0}^P - \int_0^t k(s)ds,$
```

We can also write

```
$dW^P = dW^Q + k(t)dt.
```

Girsanov's theorem provides a mechanism for changing the drift of a Brownian motion.
