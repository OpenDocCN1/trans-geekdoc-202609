
## Vanilla Options and the Black-Scholes Model Section | 4.4

The univariate cumulative standard normal distribution, $\Phi(x)$, can be evaluated in Excel using its built-in function NORMDIST. The definition of this function is as follows:

```
NORMDIST(x,mean,standard_dev,cumulative)
```

This function returns the normal cumulative distribution for the specified mean and standard deviation.
Parameters:

- x: the value for which you want the distribution.
- mean: the arithmetic mean of the distribution.
- standard_dev: the standard deviation of the distribution.
- cumulative: a logical value that determines the form of the function. If cumulative is TRUE, NORMDIST returns the cumulative distribution; if FALSE, it returns the probability density function.

If mean = $\Phi$ and standard_dev = 1, NORMDIST returns the standard normal distribution. 
This function can be used to create a Visual Basic function to calculate European option values within Excel, see Code 4.5.

```visual basic
Function bs_opt(S As Double)
  ByVal X As Double, sigma As Double, T As Double,
  ByVal r As Double, ByRef put As Double
  ' Visual Basic function to calculate the value of
  ' either a European Put or European Call option.
  ' Author: George Levy
  Dim temp As Double
  Dim d1 As Double
  Dim d2 As Double
  Dim Sqrt As Double
  Dim value As Double
  temp = Log(S / X)
  d1 = (temp + (r + (sigma * sigma / 2)) * T) / Sqrt(T)
  Sqrt = Sqrt(T)
  d2 = d1 - sigma * Sqrt
  If (put = 0) Then ' a call option
    value = S * Exp(-r * T) * Worksheet.NormDist(d1, 0, 1, True) - \
            Worksheet.NormDist(d2, 0, 1, True) * X * Exp(-r * T)
  Else ' a put option
    value = X * Exp(-r * T) * Worksheet.NormDist(-d2, 0, 1, True) - \
            Worksheet.NormDist(-d1, 0, 1, True) * S * Exp(-r * T)
  End If
  bs_opt = value
End Function
```

## 4.5 BARRIER OPTIONS

### 4.5.1 Introduction

Barrier options are derivatives which the payoff depends on whether the asset price reaches a given barrier level, B. Knockout options become worthless (cease to exist) if the asset price reaches the barrier, whereas knockin options come into existence when the asset price hits the barrier. We will consider the following single asset European barrier options:

- **Down and call**: A knockout vanilla call option, value $c_{do}$, which ceases to exist when the asset price reaches or goes below the barrier level.
- **Up and call**: A knockout vanilla call option, value $c_{uo}$, which ceases to exist when the asset price reaches or goes above the barrier level.
- **Down and in**: A knockin vanilla call option, value $c_{di}$, which comes into existence when the asset price reaches or goes below the barrier level.
- **Up and in**: A knockin vanilla call option, value $c_{ui}$, which comes into existence when the asset price reaches or goes above the barrier level.

The following expressions may be true:

```
$c = c_{uo} + c_{ui}, \quad (4.5.1)$
$c = c_{do} + c_{di}. \quad (4.5.2)$
```

where $c$ is the value of the vanilla call option. We need thus derive expressions for both the knockout options and then use the above equations to calculate the value of the corresponding knockin options. The notation that we will use is as follows: The symbol $t$ represents the current time, and $T$ is the time to maturity, the duration of the option. The symbol $s$, with $t \le s \le T$, is any intermediate time during which the option is alive.

### 4.5.2 Analytic Pricing of Down and Out Options

If we consider Brownian motion (with zero drift) $X_s \sim N(0, \sigma^2(s-t))$, $t \le s \le T$ which starts at $X_t = 0$, and after time $T$ ends at the point $X_T = X$, the probability density function for this motion to exceed the value $X = b$ (where $b > 0$) during $T$ is given by:

```
$f(X_s^{max}) = \frac{2}{\sigma\sqrt{2\pi(T-t)}} \exp\left(-\frac{b^2}{2\sigma^2(T-t)}\right) \quad (4.5.3)$
```

where for convenience we have used $\Omega = 1/\sigma\sqrt{T-t}$ and $X_s^{max} = \max(X_s)$. Since $X_s$ is Brownian motion without drift and volatility $\sigma$, then $-X_s$ is identical Brownian motion. By substituting $X \to -X$ and $b \to -b$ in our equation, we have:

```
$f(X_s^{min}) = \frac{2}{\sigma\sqrt{2\pi(T-t)}} \exp\left(-\frac{b^2}{2\sigma^2(T-t)}\right) \quad (4.5.4)$
```

we have used $X_s^{min} = \min(X_s, t \le s \le T)$. Equation (4.5.4) is the probability density of $-X_s$ staying above the value $b$, where $b < 0$. These results can be generalized to include drift (e.g., Musiela and Rutkowski (1998)), so that $X_s \sim N((r-q)(s-t), \sigma^2(s-t))$. We have the following:

```
$f(X_s^{min}) = \Omega = \frac{2}{\sigma\sqrt{2\pi(T-t)}} \exp\left(-\frac{(b-(r-q)(T-t))^2}{2\sigma^2(T-t)}\right) \quad (4.5.5)$
```

```
$f(X_s^{min}) = \Omega = \frac{2}{\sigma\sqrt{2\pi(T-t)}} \exp\left(-\frac{(b-(r-q)(T-t))^2}{2\sigma^2(T-t)}\right) \quad (4.5.6)$
```

where $r$ is the risk free rate and $q$ is the continuous dividend yield. A European down and out option with maturity $T$ and a barrier at $X=B$ will cease to exist (become worthless) if at any time $X_s \leq B$. The probability density that the barrier option will continue to exist at time $T$ if the price $X$ is

```
$f(X > B) = \sqrt{\frac{2}{\pi}} \int_{B}^{X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2}\right) \exp\left(-\frac{(X-(r-q)T)^2}{2\sigma^2}\right) db \quad (4.5.7)$
```

or

```
$f(X > B) = \sqrt{\frac{2}{\pi}} \exp\left(-\frac{(X-(r-q)T)^2}{2\sigma^2}\right) \int_{B}^{X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2}\right) db \quad (4.5.8)$
```

where we have integrated over all possible values of $b$ (i.e., $B < b < X$) that keep the option alive. Recalling that

```
$\int_{\log(B/S)}^{X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2}\right) db = \exp\left(\frac{(X-2b)}{\sigma^2}\right) \exp\left(\frac{2(X-b)}{\sigma\sqrt{T}}\right)$
```

and that

```
$\frac{\partial}{\partial b} \exp\left(\frac{2(X-b)}{\sigma^2}\right) = \frac{2(X-2b)}{\sigma^2} \exp\left(\frac{2(X-b)}{\sigma^2}\right),
```

we have

```
$\int_{\log(B/S)}^{X} \exp\left(\frac{2(X-b)}{\sigma^2}\right) db = \left[\exp\left(\frac{2(X-b)}{\sigma^2}\right)\right]_{b=\log(B/S)}^{b=X} \quad = \left\{1 - \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2}\right)\right\}$,
```

So we have

```
$f(X > B) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(X-(r-q-\sigma^2/2)T)^2}{2\sigma^2}\right) \times \left\{1 - \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2}\right)\right\}$,
```
