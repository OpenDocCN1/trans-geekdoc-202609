# A.1 INTRODUCTION

In this section, we will present some useful results which will be used later on to derive expressions for the Greeks.

A fundamental result of calculus is that

```
$$\frac{\partial}{\partial x} \int f(x)dx = f(x).$ (A.1.1)$
```

Also the indefinite integral, $\int f(x)dx$, can be expressed as a definite integral with variable upper bound as:

```
$$\int f(x)dx = \int_{a}^{x} f(x)dx + c.$
```

so

```
$$\frac{\partial}{\partial x} \int_{y=a}^{y=x} f(y)dy = f(x).$ (A.1.2)$
```

We can now use this result to obtain the derivative of the cumulative distribution function

```
$N_1(x) = \frac{1}{\sqrt{2\pi}} \int_{y=-\infty}^{y=x} exp(-y^2/2)dy.$
```

which gives

```
$$\frac{\partial N_1(x)}{\partial x} = n(x),$ (A.1.3)$
```

where

```
$n(x) = \frac{1}{\sqrt{2\pi}} exp(-x^2/2).$
```

We now derive various results for the parameters $d_1$ and $d_2$ which appear in the Black-Scholes equation

```
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)(T - t)}{\sigma \sqrt{T - t}}$ (A.1.4)$
```

and

```
$d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)(T - t)}{\sigma \sqrt{T - t}} = d_1 - \sigma \sqrt{T - t}}.$ (A.1.5)$
```
