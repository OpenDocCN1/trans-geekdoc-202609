the volatility is computed as the standard deviation of the $n$ continuously compounded returns, $u_i, i = 1, \dots, n$, where

$S_i = S_{i-1} \exp(u_i)$

$u_i = \log \left(\frac{S_i}{S_{i-1}}\right)$.

We already know (see equation (2.1.10)) that the expected standard deviation of the asset returns over the time interval is $\sigma \sqrt{dt}$. This means that we obtain the following expression for $\hat{\sigma}$, the estimated volatility:

$$\hat{\sigma} \sqrt{dt} = \sqrt{\frac{1}{n} \sum_{i=1}^n (u_i - \hat{u})^2} \quad (4.4.68)$$

$$\hat{\sigma} = \sqrt{\frac{1}{(n-1) d\tau} \sum_{i=1}^n (u_i - \hat{u})^2} \quad (4.4.69)$$

It is accepted practice to express all time in years, and so the volatility is the *annualized* standard deviation of the returns. There is also the issue of account for non-trading days such as weekend and holidays. For example, let us say that the history of assets prices $S_i, i=0,\dots,n$ was obtained by recording the price on each *trading* day. One approach is to use $d\tau = 1/N_{td}$, where $N_{td}$ is the number of trading days in a year. If we take $N_{td} = 250$, then equation (4.4.69) becomes

$$\hat{\sigma} = \sqrt{\frac{250}{(n-1)} \sum_{i=1}^n (u_i - \hat{u})^2} \quad (4.4.70)$$

The estimated error in $\hat{\sigma}$ is, for example, Hull (2003), given by

$$\hat{\sigma}_{std} = \sqrt{\frac{1}{2(n-1)}} \quad (4.4.71)$$

## Implied Volatility

The implied volatility of a European option is the volatility, when substituted into the Black-Scholes equation yields the market value quoted for the same option. The implied volatility will depend on both the time to expiry of the option and the ratio of the current asset price to the strike - this is known as the volatility smile. These values are usually stored in a multidimensional implied volatility surface, and the volatility for pricing a given option obtained via multidimensional interpolation.

The routine provided in Code 4.3 uses Newton's method to calculate the implied volatility for a European option from its market price. We will now illustrate this technique for a European call option with market value opt_value. The implied volatility, $\sigma$, is then that value which satisfies

$c(S,E,T,\sigma) - opt\_value = 0,$

where $c(S,E,T,\sigma)$ represents the value of the European call and the other symbols have their usual meaning.

From Newton's method, we have

$$\sigma_{i+1} = \sigma_i - \frac{F(\sigma_i)}{F'(\sigma_i)}$$

where

$F'(\sigma_i) = \frac{\partial F}{\partial\sigma}\frac{\partial c(S,E,T,\sigma)}{\partial\sigma} = V_c$.

Therefore, the iterative procedure

$$\sigma_{i+1} = \sigma_i - \frac{c(S,E,T,\sigma)}{\mathcal{V}_c}$$

where $\sigma_0$ is the initial estimate, and $\sigma_{i+1}$ is the improved estimate of the implied volatility based on the $i$-th estimate $\sigma_i$. Termination of this iteration occurs when $ABS(\sigma_{i+1}-\sigma_i) < tol$, for a specified tolerance, tol.

It can be seen as $\sigma \to 0, d_1 \to \infty, d_2 \to \infty$, and from equation(4.4.67), we have $\mathcal{V}_c \to 0$. Under these circumstances, Newton's method fails.
