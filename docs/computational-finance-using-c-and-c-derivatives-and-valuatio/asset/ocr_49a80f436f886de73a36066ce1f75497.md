# 342 APPENDIX | G The Brownian Bridge: Alternative Derivation

We consider the terms in the exponent A,

```
$A = -\frac{1}{2} \left( \frac{(X_1-X_0)^2(t_1-t)(t-t_0)}{(t-t_0)(t_1-t)(t_1-t_0)} + \frac{(X_1-X_0)^2(t-t_0)}{(t-t_0)(t_1-t)(t_1-t_0)} \right) - \frac{(X_1-X_0)^2(t-t_0)(t_1-t)}{(t-t_0)(t_1-t)(t_1-t_0)}$
```

Dividing top and bottom of the expression A by $(t_1-t_0)^2$, then we obtain

```
$A = -\frac{1}{2V} \left( (W_{t_1}^2 + W_{t_0}^2 - 2W_{t_1}W_{t_0}) \frac{(t_1-t_0)}{(t_1-t_0)^2} + (W_{t_1}^2 + W_{t_0}^2 - 2W_{t_1}W_{t_0}) \frac{(t-t_0)}{(t_1-t_0)^2} \right) - (W_{t_1}^2 + W_{t_0}^2 - 2W_{t_1}W_{t_0}) \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2}$
```

where

```
$V = \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2}$
```

So

```
$A = -\frac{1}{2V} \left( \frac{(t_1-t)}{(t_1-t_0)} \frac{(t-t_0)}{(t_1-t_0)} \right) + W_{t_1}^2 \frac{(t_1-t)}{(t_1-t_0)} \frac{(t-t_0)}{(t_1-t_0)^2} + W_{t_0}^2 \frac{(t-t_0)}{(t_1-t_0)} \frac{(t_1-t)}{(t_1-t_0)^2} - 2W_{t_1}W_{t_0} \frac{(t_1-t)}{(t_1-t_0)} - 2W_{t_1}W_{t_0} \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2} \right)$
```

We show that A can be expressed as quadratic form

```
$B = -\frac{1}{2V}(W_{t_1}-\mu)^2 = -\frac{1}{2V}(W_t^2+\mu^2-2\mu)$
```

where

```
$V = \frac{(t-t_0)(t_1-t)}{(t_1-t_0)^2} \quad \quad \ \mu = W_{t_0} \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1} \frac{(t-t_0)}{(t_1-t_0)}$
```

Therefore we have

```
$B = -\frac{1}{2V} \left( W_{t_0}^2 \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1}^2 \frac{(t-t_0)}{(t_1-t_0)} \right)^2 - 2W_{t_1} \left( W_{t_0} \frac{(t_1-t)}{(t_1-t_0)} + W_{t_1} \frac{(t-t_0)}{(t_1-t_0)} \right)$
```

Expanding and gathering terms, we obtain

```
$B = -\frac{1}{2V} \left( W_{t_0}^2 \frac{(t_1-t)^2}{(t_1-t_0)^2} + W_{t_1}^2 \frac{(t-t_0)^2}{(t_1-t_0)^2} + 2W_{t_1}W_{t_0} \frac{(t_1-t)(t-t_0)}{(t_1-t_0)^2} \right) - 2W_{t_1}W_{t_0} \frac{(t_1-t)(t-t_0)}{(t_1-t_0)^2}$
```
