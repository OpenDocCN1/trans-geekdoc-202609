## 5.4 GRID METHODS FOR VANILLA OPTIONS

### 5.4.1 Introduction

In Section 5.3, we discussed the use of binomial lattice methods for valuing both European and American options. The lattice methods we have described have the advantage that they are fairly easy to implement and can value simple options, such as vanilla puts and calls, *reasonably* accurately. The use of up- and down-jump probabilities at the lattice nodes is also an appealing feature, they are directly related to the stochastic process which is being modelled. However, lattice techniques have the following drawbacks:

- They require small time steps to ensure numerical stability.
- There is little control over where the lattice nodes are located. This can lead to poor accuracy when valuing certain types of options, for example, those with barriers at particular asset prices.

### 5.4.2 Uniform Grids

The Black-Scholes equation for the value of an option, $f$, is given by:

$$\frac{\partial f}{\partial t} + (r-q)S\frac{\partial f}{\partial S} + \frac{1}{2}\sigma^2S^2\frac{\partial^2 f}{\partial S^2} = rf. (5.4.1)$$

We want to estimate the duration of the option, from the current time $t$ to the maturity at time $T$. To do this we use a grid in which the asset price $S$ takes $n_s$ uniformly spaced values $S_j = j\Delta S, j = 0, \dots, n_s-1$, where $\Delta S$ is the spacing between points. If $S_{\max}$ is the maximum asset value we want to represent, then the grid spacing $\Delta S^*$, can be simply calculated as

$$\Delta S^* = \frac{S_{\max}}{n_s-1}. (5.4.2)$$

However, since we would like to solve the option values and Greeks at the current asset price $S_0$, we would also like a grid line to coincide with the current asset price. This leads to the use of interpolation when the asset value does not correspond to a grid line. The method by which we achieve this is outlined below. Here, the user supplies the function `opt_gfd` with values for $S_{\max}$ and $n_s-1$ which is computed using equation (5.4.2). We then find $n_1$, that is below (or equal) to the value $\frac{S_0}{\Delta S^*}$ and use this to obtain a new grid spacing $\Delta S^*$ where we have ensured that $S_{n_1} = S_0$. The user also supplies the function `opt_gfd` with the number of intervals for the grid. Here $n_t$ time intervals, the grid has $n_t+1$ uniformly spaced instances $t_i = i\Delta t, i=0,\dots,n_t$, and the time step is

$$\Delta t = \frac{T}{n_t}. (5.4.3)$$

As with binomial lattice methods, we will solve the equation backwards in time from maturity (at $t+\tau$) to the present (the time $t$). So as we solve the equation, the time index will start at $i=n_t$ (time $t+\tau$) and decrease to $i=0$ (current time $t$).

Here, we discuss the grid method of solving the Black-Scholes equation in terms of the following:

- The Finite-difference approximation.
- The boundary conditions.
- Computation of the option values at a given time instant.
- Backwards iteration and early exercise.

Each of these aspects will be considered in turn.

### The Finite-Difference Approximation

The option value corresponding to the grid node at $t_i = i\Delta t$ and $S_j = j\Delta S$ will be denoted by $f_{i,j}$. We will approximate the partial derivative of $f_{i,j}$ with respect to time as

$$\frac{\partial f}{\partial t} = \frac{f_{i+1,j}-f_{i,j}}{\Delta t}. (5.4.4)$$

For the other terms in equation (5.4.1), we will use the weighted $\Theta_m$ method. This technique involves selecting an appropriate choice for $\Theta_m$ in the range $0 \leq \Theta_m \leq 1$ so that the contribution from node $(i,j)$ is a weighted sum over the values at nodes $(i,j)$ and $(i+1,j)$. For instance, the time $rf_{i,j}$ in equation (5.4.1) is approximated as

$$rf_{i,j} = r \{\Theta_m f_{i+1,j} + (1 - \Theta_m) f_{i,j}\}$$

and the term $\frac{\partial f}{\partial S}_{i,j}$ in equation (5.4.1) is approximated as

$$\frac{\partial f}{\partial S}_{i,j} = \{\Theta_m \frac{\partial f}{\partial S}_{i+1,j} + (1 - \Theta_m) \frac{\partial f}{\partial S}_{i,j}\}$$

Using this method, we obtain, at node (i, j), the following discretized version of equation (5.4.1):

$$\frac{f_{i+1,j} - f_{i,j}}{\Delta t} + (r - q)S_j \{\Theta_m^* f_{i+1,j} + \Theta_m^* f_{i,j}\}$$
$$\frac{1}{2}\sigma^2S_j^2 \{\Theta_m^* f_{i+1,j} + \Theta_m^* f_{i,j}\} = r \{\Theta_m f_{i+1,j} + \Theta_m^* f_{i,j}\} (5.4.7)$$

where for compactness we have written $\Theta_m^* = 1 - \Theta_m$ and denote the partial derivatives with respect to S at node (i, j) as $f'_{i,j} = \frac{\partial f}{\partial S}_{i,j}$ and $f''_{i,j} = \frac{\partial^2 f}{\partial S^2}_{i,j}$.

The complete finite-difference approximation to the Black-Scholes equation can be found by substituting the approximations for the first and second derivatives, given in equation (5.4.10) and equation (5.4.11), into equation (5.4.7). We obtain

$$r\Delta t \Theta_m f_{i+1,j} + \Theta_m^* f_{i,j} = f_{i,j+1} - f_{i,j} - \frac{(r-q)S_j\Delta t}{2} + \frac{\sigma^2 S_j^2 \Delta t^2}{2}, (5.4.12)$$
