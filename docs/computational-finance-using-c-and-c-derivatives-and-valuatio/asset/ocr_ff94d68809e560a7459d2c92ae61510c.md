# 8.2 STORING AND RETRIEVING THE MARKET DATA

As mentioned before, the market data required to price derivatives is stored in market dictionaries. The MarketDataDictionaries class, shown in Code excerpt contains a set of C# dictionary member items which hold all the market data required by the deal classes. Below, we give the declaration of the CurrencyTable, EquityTable, and CorrelationDictionary,

```
public static Dictionary Currency, CurrencyTable = new Dictionary<string, Currency>();
public static Dictionary Equity, EquityTable = new Dictionary<string, Equity>();
public static Dictionary Correlation, CorrelationTable = new Dictionary<string, Correlation>();
```

Each dictionary entry is made of a <unique-key, value-object> pair, where unique-key is a unique string, and value-object is a class containing the corresponding market data. We now consider each of the above dictionaries and the information they hold in more detail.
