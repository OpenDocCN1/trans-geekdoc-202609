```
$c(S^*, E, \tau_1) = S^* + D_1 - E,$$
```

where $c(S^*, E, \tau_1)$ is the Black-Scholes value of a European call option with strike price $S^*$ and maturity $\tau_1 = T - t_1$, on an asset with current value $S^*$ at time $t_1$. If just before the ex-dividend date $S_{t_1} > S^*$, the American option will be exercised and realize a payoff of $S_{t_1} + D_1 - E$. On the other hand, if $S_{t_1} \le S^*$, the option is worth worthless and will be held until maturity at T.

We can rewrite (5.2.2) so that $S^*$ is the root of the following equation:

```
$K(S^*) = c(S^*, E, \tau_1) - S^* - D_1 + E,$$
```

Where $K(S^*)$ denotes the function of solving equation the single variable $S^*$. A well-known technique for solving equation (5.2.3) is Newton's method, in which this case takes the

```
$S^*_{i+1} = S^*_i - \frac{K(S^*_i)}{K'(S^*_i)},$$
```

where $S^*_i$ is the $i$th approximation to $S^*$ and $S^*_{i+1}$ is the improved $(i+1)$th approximation.

If we now consider the terms in equation (5.2.4), we have from equation (5.2.2) and equation (5.2.3) that

```
$K(S^*_i) = c(S^*_i, E, \tau_1) - S^*_i - D_1 + E$
```

and

```
$K'(S^*_i) = \frac{\partial K(S^*_i)}{\partial S^*_i} = \frac{\partial c(S^*_i, E, \tau_1)}{\partial S^*_i} - 1.$
```

Also from equation (A.1.4) in Appendix A.3

```
$\frac{\partial c(S^*_i, E, \tau_1)}{\partial S^*_i} = N_1(d_1(S^*_i)),$$
```

we note here that the continuous dividend yield, $q=0$. So

```
$K'(S^*_i) = \frac{\partial K(S^*_i)}{\partial S^*_i} = N_1(d_1(S^*_i)) - 1, \text{ where } d_1 = \frac{\log(S^*/E) + (r + \sigma^2/2)\tau_1}{\sigma\sqrt{T-t_1}}.$
```

Substituting these results into equation (5.2.4) gives
