# Relation to the Brownian Bridge

We will now prove that in the limit $(t_1-t_0) \to 0$ the Brownian bridge result is obtained.

For the conditional mean, we have

```
$$\mu = X_{t_0} \exp(-\alpha(t-t_0)) \left\{ \frac{1-\exp(-2\alpha(t_1-t_0))}{(1-\gamma^2)} \right\$
$+ X_{t_1} \exp(-\alpha(t_1-t_0)) \left\{ \frac{1-\exp(-2\alpha(t-t_0))}{(1-\gamma^2)} \right\right}$
```

where

```
$$\gamma = \exp(-\alpha(t_1-t_0)),$$
```

which is

```
$$\mu = X_{t_0} \left\{ \frac{\exp(-\alpha(t-t_0))\exp(-2\alpha(t_1-t_0))}{(1-\exp(-2\alpha(t_1-t_0))-\exp(-2\alpha(t-t_0)))} \right\$
$+ X_{t_1} \left\{ \frac{\exp(-\alpha(t_1-t_0))\exp(-2\alpha(t-t_0))-\alpha(t_1-t_0))}{(1-\exp(-2\alpha(t_1-t_0)))} \right\}\right\}$
```

For small $(t_1-t_0)$, both $(t_1-t_0)$ and $t$ are small, so

```
$$\mu \to X_{t_0} \left\{ \frac{1-\exp(-2\alpha(t_1-t_0))-\alpha(t_1-t_0)}{1-\exp(-2\alpha(t_1-t_0))} \right\$
$+ X_{t_1} \left\{ \frac{1-\exp(-2\alpha(t-t_0))-\alpha(t_1-t_0)}{1-\exp(-2\alpha(t_1-t_0))} \right\}\right\}$
```

which yields the Brownian bridge result for the conditional mean

```
$$\mu \to X_{t_0} \frac{(t_1-t_0)}{(t_1-t_0)} + X_{t_1} \frac{(t-t_0)}{(t_1-t_0)}$$$
```

For the conditional variance,

```
$$\V_t = \frac{(1-\exp(-2\alpha(t-t_0)))(1-\exp(-2\alpha(t_1-t_0)))}{2\alpha(1-\exp(-2\alpha(t_1-t_0)))}$$$
```

For small $(t_1-t_0)$, both $(t_1-t_0)$ and $t$ are small, so we see

```
$$\V \to \frac{(1-\exp(-2\alpha(t-t_0)))(1-\exp(-2\alpha(t_1-t_0)))}{2\alpha(1-\exp(-2\alpha(t_1-t_0)))}$$$
```
