## 5.5 PRICING AMERICAN OPTIONS USING A STOCHASTIC LATTICE

In this section, we consider the use of Monte Carlo simulation and stochastic lattices to price American options. Information on the use of Monte Carlo simulation to value single asset and multi-asset European options is provided in Chapters 4 and 6. The main difficulty in using simulation to value American options is the need to incorporate optimal early exercise policies. The standard algorithms for valuing European contracts are forward in time. That is each price path, which contributes to the value of the option, is generated by stepping from current time, $t$, to option maturity, $t+\tau$, where $\tau$ is the duration of the option. For instance if there are $n$ equidistant time steps of size $\Delta t$ and one underlying asset, then we use the asset values $S_{t,i}=0,\dots,n$, where $S_i$ corresponds to the asset value at the $i$th time instant, $t_i$, and $t_0=0$. Here $S_{i+1}$ is generated from the previous asset value $S_i$ as follows:

$\frac{S_{i+1}}{S_i} = dS_i$, for $i=0,\dots,n-1$.

where $dS_i$ is a random variable taken from a given distribution. When $S_t$ follows GBM, we have from equation (2.3.11) that

$S_{i+1}/S_i = \exp\{(r-\sigma_i^2/2) \Delta t + \sigma_i dX_i\}, \quad i=0,\dots,n-1,\quad (5.5.2)$

where $dX_i \sim N(0, \Delta t)$ and the usual definitions are used for $\sigma_i$ and $r$.

For exotic options (such as time dependent barrier options), the value of a particular price path will depend on the asset values $S_{i,i}=0,\dots,n$. This is not true of European vanilla options whose value depends only on $S_n$, the underlying asset price at maturity. The Monte Carlo approximation to the value of an exotic option is this

$f = \frac{\sum_{j=1}^{nsim} p_j(n_j)}{nsim}$

where $nsim$ is the number of simulations used, $n_j$ is the number of time steps associated with the $j$th price path, and $p_j(n_j)$ is the value of the $j$th price path. In the case of European vanilla options, we can use $n_j=1,\dots,nsim$; the accuracy improves obviously with increasing $nsim$.

The valuation of American style options, including the possibility of early exercise, is more complicated. In Chapter 5, we described the use of binomial trees to price American options where the underlying asset is GBM. Dynamic programming was used and the option prices were computed by working backwards in time. The application of Monte Carlo methods for pricing American options is described in Tilley (1993), Broadie and Glasserman (1995), and also by Boyle et al. (1997). Here, we use the stochastic lattice approach described in Broadie and Glasserman (1997), where both a high estimator and a low estimator of the American option value are calculated. Since both of these estimators converge (with increasing number of simulations and lattice nodes) to the true option value, we will only consider how to compute the high estimator $\hat{\theta}_H$. We summarize the approach as follows:

- Set the parameters.
- Generate the lattice asset prices.
- Compute the lattice option prices.
- Compute the Monte Carlo estimate.

First we set the parameters, that is $nsim$ is the number of simulations, $b$ is the number of branches per lattice node, and $d$ is the number of time instants in the lattice. Note definition of $d$ is different from that used in the original paper by Broadie and Glasserman (1997), where $d$ is defined as the number of steps in the lattice.

Next we generate the asset prices for the stochastic lattice. Since the lattice is non-combining at the $i$th time step, there are $b^i$ nodes/asset prices. This contrasts with the binomial lattice of Chapter 5 where the asset prices at a given time step are arranged in ascending order, that is $S_i^j$ increases with $j$. We denote the $j$th value at the $i$th time step by $S_i^j$. For example, in Fig. 5.9, where $b=3$ and $d=3$, we have for the first time step $S_i^1=15, S_i^2=60, S_i^3=14$ and for the second time step $S_i^2=16, S_i^3=90, S_i^4=49, \dots, S_i^5=50, S_i^6=48, S_i^7=102, S_i^8=88, S_i^9=80$.

The $k$th asset price at the $i$th time step, $S_i^k$, then generates the following asset prices at the $(i+1)$ time step

$S_i^{\frac{(k-1)b+j}{i+1}} = dS_i^k, \quad j=1,\dots,b, k=1,\dots,b^i$

where $dS_i^k$ is, as before, a random variate from a given distribution. When $S_i$ follows GBM, we have

$S_i^{\frac{(k-1)b+j}{i+1}} = \exp\left(\left(r-\sigma_i^2/2\right)\Delta t + \sigma_i dX_i\right), \quad j=1,\dots,b, k=1,\dots,b^i$.

The method used to compute the option values is *similar* to that used by the binomial tree. The main difference is that there are now $b$ branches per node instead of two. The option values are computed by starting at the lattice terminal nodes and iterating backwards. Here, we denote the option value at the $k$th time step as $f_i^k$.

The option values at the terminal nodes, $t_{d-1}$, are computed in the usual manner. For a put, we have

$f_{d-1}^k = \text{MAX}(E - S_{d-1}^k, 0), \quad k=1, \dots, b^{d-1}$

where $E$ is the exercise price. The option values at the $(i-1)$ time step are computed from those at the $i$ time step as follows:

$f_{i-1}^k = \text{MAX}(g_{i-1}^k, h_{i-1}^k)$

where

$h_{i-1}^k = \frac{\exp(-r\Delta t)}{b} \sum_{j=1}^{(k-1)b+j} \dots$

and

$g_{i-1}^k = \text{MAX}(E - S_{i-1}^k, 0)$

The option value for the $p$ stochastic lattice is therefore

$f_H^\theta = f_0^1 = \frac{\exp(-r\Delta t)}{b} \sum_{j=1}^b f_1^j$
