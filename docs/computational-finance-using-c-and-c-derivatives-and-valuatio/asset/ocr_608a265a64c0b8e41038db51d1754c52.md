# 4.4.5 Pricing Options with Microsoft Excel

In this section, we show how the Visual Basic within Excel can be used to create powerful pricing applications based on the Black-Scholes formula. We will explain how Excel's Visual Basic can be used to create an application that prices a simple European put and call options at the press of a button.

In Section 4.4.3, we use the Black–Scholes formula:

> $c(S,E,T) = SN_1(d_1) - e^{-rT} EN_1(d_2)$
np(S,E,T) = -SN_1(-d_1) + e^{-rT} EN_1(-d_2)$

where
$$d_2 = \frac{\log(S/E) + (r - \sigma^2/2)T}{\sigma\sqrt{T}} = d_1 - \sigma\sqrt{T},,$$

where $S$ is the current value of the asset and $\sigma$ is the volatility of the asset, and $N_1(x) = (1/\sqrt{2\pi}) \int_{-\infty}^x e^{-x^2/2} dx$.
