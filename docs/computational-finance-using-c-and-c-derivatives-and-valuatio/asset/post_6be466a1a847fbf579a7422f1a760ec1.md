The value, $c_{do}$ of a European down out call option with strike $E$, satisfying $E > B$, is given by

```
$c_{do} = \frac{\exp(-r\tau)}{\sqrt{2\pi\tau}} \int_{\log(E/S)}^{\infty} \{\exp(X) - E\} f(X > B)dX. \quad (4.5.9)
```

This integral is evaluated in Appendix B.1, and the value of the down and out call option $c_{do}$ is

```
$c_{do} = c - c_{di}. \quad (4.5.10)
```

where

```
$c = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2),$
$c_{di} = S\exp(-q\tau)N_1(d_4) \left(\frac{B}{S}\exp(-\frac{qr}{\sigma^2})\right) - E\exp(-r\tau)N_1(d_3) \left(\frac{B}{S}\exp(-\frac{2(r-q)}{\sigma^2})\right),$
$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)\tau}{\sigma\tau}, \quad d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)\tau}{\sigma\tau},$
$d_3 = \frac{\log(B^2/SE) + (r - q - \sigma^2/2)\tau}{\sigma\tau}, \quad d_4 = \frac{\log(B^2/ES) + (r - q + \sigma^2/2)\tau}{\sigma\tau}$
```

## 4.5.3 Analytic Pricing of Up and Out Options

Here we will obtain an expression for an up out European call option with continuous dividend yield $q$, in a similar manner to used in Section 4.5.2 for the down and out European call option. A European up and out barrier option with maturity $\tau$ and barrier at $X = B$ will cease to exist (become worthless) if at any time $X \ge B$, for all $t \le s \le T$. The probability density function that the barrier option will continue to exist at time $t$ if the end point is $X$ is this

$f(X < B) = \frac{1}{\sqrt{2\pi}} \int_{X}^{B} S \exp(b) \Omega \exp\left(\frac{2b(X-b)}{\sigma^2}\right) \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2}\right) db,$

or

$f(X < B) = \frac{1}{\sqrt{2\pi}} \int_{X}^{B} S \exp(b) \Omega \exp\left(\frac{2b(X-b)}{\sigma^2}\right) \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2}\right) db,$

where as in Section 4.5.2 we used $\Omega = (B-X)/\sigma^2$ and integrated over all possible values of $b$ (i.e., $B > b > X$), that keep the option active. Recalling that

$\int_{X}^{B} \exp\left(\frac{2b(X-b)}{\sigma^2}\right) db - \int_{X}^{B} \log(B/S)} \exp\left(\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2}\right) db,$

and noting

$\frac{\partial}{\partial b} \exp\left(\frac{2b(X-b)}{\sigma^2}\right) = \frac{2(X-b)}{\sigma^2} \exp\left(\frac{2b(X-b)}{\sigma^2}\right),$

we have

$\int_{X}^{\log(B/S)} \frac{2(X-b)}{\sigma^2} \exp\left(\frac{2b(X-b)}{\sigma^2}\right) db = \left[-\exp\left(\frac{2b(X-b)}{\sigma^2}\right)\right]_{X}^{\log(B/S)} = \left[1-\exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2}\right)\right].$

Therefore,

$f(X < B) = \frac{1}{\sqrt{2\pi}} \int_{X}^{B} \exp\left(-\frac{X-(r-q-\sigma^2/2)\tau}{2\sigma^2}\right) \left[1-\exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2}\right]\right] db,$ (4.5.14)

We will now derive the formula for an up out call when $E < B$. In fact if $E > B$, then the option is worthless since at the current time $t$ the call's payoff, $\max(S_t-E, 0)=0$, and if $S_t > E$ then the option will be knocked out,

$c_{uo} = \frac{1}{\sqrt{2\pi}} \int_{\infty} S\exp(X)-E f(X<B)dX.$ (4.5.15)
