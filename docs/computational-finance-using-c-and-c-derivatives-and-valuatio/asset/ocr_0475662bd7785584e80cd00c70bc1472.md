The incorporation of nonconstant asset price requires more work. This is because the finite-difference approximations to the first and second derivatives $f'_{i,j}$ and $f''i,j}$, in equation (5.4.10) and equation (5.4.11), are based on a Taylor expansion about the point $f_{i,j}$.

We will now derive expressions for these derivatives.\ If we let $\Delta X_j^- = S_j - S_{j-1}$ and $\Delta X_j^+ = S_{j+1} - S_j$ and then using a Taylor expansion about $f_{i+1,j}$, we have

```
$f_{i+1,j+1} = f_{i+1,j} + f'_{i+1,j}\Delta X_j^+ + \frac{1}{2}f''_{i+1,j}(\Delta X_j^+)^2$
```

and also

```
$f_{i+1,j-1} = f_{i+1,j} - f'_{i+1,j}\Delta X_j^- + \frac{1}{2}f''_{i+1,j}(\Delta X_j^-)^2$.
```

Multiplying equation (5.4.32) by $\Delta X_j^-$ and adding it to $\Delta X_j^+$ times equation (5.4.33) give

```
$\Delta X_j^- f_{i+1,j-1} + \Delta X_j^+ f_{i+1,j+1} = \Delta X_j^- f_{i+1,j} + \frac{1}{2}f''_{i+1,j}\{(\Delta X_j^+)^2\Delta X_j^- + (\Delta X_j^-)^2\Delta X_j^+\}$.
```

Therefore,

```
$f''_{i+1,j} = \frac{2{\Delta X_j^- f_{i+1,j-1} + \Delta X_j^+ f_{i+1,j+1} - f_{i+1,j}(\Delta X_j^- + \Delta X_j^+)}}{\{(\Delta X_j^+)^2\Delta X_j^- + (\Delta X_j^-)^2\Delta X_j^}}$
```

So

```
$f''_{i+1,j} = \frac{2{\Delta X_j^- f_{i+1,j-1} + \Delta X_j^+ f_{i+1,j+1} - f_{i+1,j}(\Delta X_j^- + \Delta X_j^+)}}{\{(\Delta X_j^+)^2\Delta X_j^- + (\Delta X_j^-)^2\Delta X_j^}}$
```

To calculate $f'_{i+1,j}\Delta X_j^-,$, we rearrange equation (5.4.33) to obtain

```
$-f'_{i+1,j}\Delta X_j^- = f_{i+1,j-1} - f_{i+1,j} - \frac{1}{2}f''_{i+1,j}(\Delta X_j^-)^2$
```

and

```
$f'_{i+1,j} = \frac{f_{i+1,j} - f_{i+1,j-1}}{\Delta X_j^-} + \frac{1}{2}f''_{i+1,j}\Delta X_j^-.$.
```

If we now substitute for $f'_{i+1,j}$, from equation (5.4.34) into equation (5.4.35), we have

```
$f'_{i+1,j} = \frac{f_{i+1,j} - f_{i+1,j-1}}{\Delta X_j^-}\frac{\Delta X_j^- f_{i+1,j-1} - (\Delta X_j^- + \Delta X_j^+)f_{i+1,j} + \Delta X_j^+ f_{i+1,j+1}}{\{(\Delta X_j^+)^2\Delta X_j^- + (\Delta X_j^-)^2\Delta X_j^}}$
```
