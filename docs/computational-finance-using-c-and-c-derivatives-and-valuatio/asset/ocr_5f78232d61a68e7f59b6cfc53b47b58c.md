We will assume that the $n$ element random vector $dZ$ is drawn from a multivariate normal distribution with zero mean and covariance matrix $\hat{C}$. That we can write

```
$dZ \sim N(0, \hat{C}).$
```

Since $\hat{C}_{ii} = Var[dZ_i] = 1, i = 1, \dots, n$, the diagonal elements of $\hat{C}$ are all unity and the matrix $\hat{C}$ is in fact *correlation matrix* with off-diagonal elements given by

```
$\hat{C}_{ij} = E[dZ_i dZ_j] = \rho_{i,j}, i = 1, \dots, n, j = 1, \dots, n, i \neq j$,
```

Similarly, the $n$ element random vector $dW$ is drawn from a multivariate normal distribution with zero mean and covariance matrix $C$. We can write this

```
$dW \sim N(0, C).$
```

The diagonal elements of $C$ are $C_{ii} = Var[dW_i] = dt, i = 1, \dots, n$ and off-diagonal elements are

```
$C_{ij} = E[dW_i dW_j] = \rho_{i,j} dt, i = 1, \dots, n, j = 1, \dots, n, i \neq j$.
```
