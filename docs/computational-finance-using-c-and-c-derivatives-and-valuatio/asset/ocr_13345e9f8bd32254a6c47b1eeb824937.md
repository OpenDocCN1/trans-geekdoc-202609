$\mathbb{Q}$ is the probability measure under which the relative price $(S_t^B/S_t^A)$ is a martingale.

The process follows $(S_t^B/S_t^A)$ can be found by substituting $X_1 = S_t^B$ and $X_2 = S_t^A$ into equation (2.6,7). Which yields

```
$d\frac{S_t^B}{S_t^A} = \frac{S_t^B}{S_t^A} \left(\\mu_B - \mu_A + \sigma_A^2 - \sigma_A\sigma_B\rho_{AB}\right)dt + \frac{S_t^B}{S_t^A} \left(\sigma_B dW_t^B - \sigma_A dW_t^A\right)$.$
```

$\hat{X} = \sigma_B dW_t^B - \sigma_A dW_t^A$. $E[\hat{X}] = \sigma_B E[dW_t^B] - \sigma_A E[dW_t^A] = 0$ and $Var[\hat{X}] = \sigma_B^2 dt + \sigma_A^2 dt - 2\sigma_B\sigma_A\rho_{AB}dt$ where we use (see Appendix C.3)

$Var[a dW_1 + b dW_2] = a^2 Var[dW_1] + b^2 Var[dW_2] + 2ab Cov[dW_1, dW_2]$, $Var[dW_t^B] = Var[dW_t^A] = dt$ and $Cov[dW_t^B, dW_t^A] = \rho_{AB}dt$,

which means $\hat{X} \sim N(0, (\sigma_B^2 + \sigma_A^2 - 2\sigma_B\sigma_A\rho_{AB})dt)$ and the variate $(\sigma_B^2 + \sigma_A^2 - 2\sigma_B\sigma_A\rho_{AB})$ is from the distribution as $\hat{X}$.

Therefore, we can write

```
$d\frac{S_t^B}{S_t^A} = \frac{S_t^B}{S_t^A} \bar{\mu}dt + \frac{S_t^B}{S_t^A} \bar{\sigma}dW_t^P, \quad (6.5.2)$
```

where

```
$$\bar{\sigma} = \sqrt{\sigma_B^2 + \sigma_A^2 - 2\sigma_B\sigma_A}$
```

and

```
$$\bar{\mu} = \mu_B - \mu_A + \sigma_A^2 - \sigma_B\sigma_A\rho_{AB}$.$
```

Following Section 4.4.3 we choose the probability measure $\mathbb{Q}$ so that the drift term in equation (6.5.2) is zero.

```
$dW_P = dW_Q - \left(\frac{\bar{\mu}}{\bar{\sigma}}\right)dt$.
```

Substituting this into equation (6.5.2) gives

```
$d\frac{S_t^B}{S_t^A} = \frac{S_t^B}{S_t^A} \bar{\sigma}dW_Q. \quad (6.5.3)$
```

It can be seen that (6.5.3) is identical to equation (4.4.31) but with the mapping

```
$S \to \frac{S_t^B}{S_t^A}, \quad \sigma \to \bar{\sigma}, \quad r \to 0. \quad (6.5.4)$
```
