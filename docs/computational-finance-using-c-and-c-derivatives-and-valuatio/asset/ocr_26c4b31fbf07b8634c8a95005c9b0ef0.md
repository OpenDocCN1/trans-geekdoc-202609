# The Brownian Bridge:
Alternative Derivation

Here, we provide an alternative derivation of the Brownian bridge equation given in Chapter 2.

Let a Brownian process have values $W_{t_0}$ at time $t_0$ and $W_{t_1}$ at time $t_1$. We want to find the conditional distribution of $W_t$ given $W_{t_0}$, where $t_0 < t < t_1$. This distribution will be denoted by $P(W_t|\{W_{t_0}\})$, where $W_t$ is conditional on the end values $W_{t_0}$ and $W_{t_1}$. We have

```
$P(W_t|W_{t_0}) = \frac{1}{\sqrt{2\pi(t-t_0)}} \exp\left\\frac{(W_t-W_{t_0})^2}{2(t-t_0)}\right)$
```

The joint distribution of $W_{t_0}$ and $W_{t_1}$ given $W_{t_0}$ is

```
$P(\{W_{t_0},W_{t_1}\}|W_{t_0}) = P(W_{t_0}|W_{t_0})P(W_{t_1}|W_{t_0})$\n= \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \exp\left\left\\left{\frac{(W_t-W_{t_0})^2}{2(t-t_0)} - \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t)}\right\right\right)\n= \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}} \exp\leftleft\left{-\frac{1}{2}\left\\frac{(W_t-W_{t_0})^2}{2(t-t_0)} + \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t)}\right\right\right\right.$
```

Similarly,

```
$P(W_{t_1}|W_{t_0}) = \frac{1}{\sqrt{2\pi(t_1-t_0)}} \exp\left\\frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t_0)}\right)$
```

Now we have

```
$P(W_t|{W_{t_0},W_{t_1}\}) = \frac{P(W_{t_0},W_{t_1}|W_{t_0})}{P(W_{t_0}|W_{t_0})\n= \frac{1}{\sqrt{2\pi(t-t_0)(t_1-t)}}\n\times \exp\leftleft\left{-\frac{1}{2}\left\\frac{(W_t-W_{t_0})^2}{2(t-t_0)} + \frac{(W_{t_1}-W_{t_0})^2}{2(t_1-t_0)}ight\right\right\right.$
```
