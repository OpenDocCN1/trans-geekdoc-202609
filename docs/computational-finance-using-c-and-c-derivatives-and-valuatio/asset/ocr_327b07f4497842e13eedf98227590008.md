# Computation of the Options Value at a Given Instant Time

Having found the option boundary values, we are now in a position to solve equation (5.4.14) at instant time $t_i = i\Delta t$.
First we note that $f_{i,0} = fBL$, and $f_{i,n_{s-1}} = fBU$, equation (5.4.14) only needs to be solved for values of the asset index $j$ in the range $j=1$ to $j=n_{s-2}$. We now deal with the following situations:

+   * Case 1: $j=1$, the asset grid line just above the lower boundary.
* Case 2: $j=n_{s-2}$, the asset grid line just below the upper boundary.
* Case 3: all other grid lines not included in Case 1 or Case 2

and consider the fact that (5.4.14) takes under each condition.
Case 1: $j=1$
Substituting $j=1$ into equation (5.4.14), we obtain

```
$a_1f_{1,0} + b_1f_{1,1} + c_1f_{1,2} = \tilde{a}_1f_{1,0} + \tilde{b}_1f_{1,1} + \tilde{c}_1f_{1,2}$.
```

Now, since $f_{i,0} = fBL$, this becomes

```
$b_{1,1} + c_{1,2}f_{1,2} = (\tilde{a}_1 - a_1)fBL + b_1f_{1,1} + \tilde{c}_1f_{1,2}$,
```

or equivalently

```
$b_{1,1} + c_{1,2}f_{1,2} = R_{1,1},$ (5.4.22)
```

where

```
$R_{1,1} = (\tilde{a}_1 - a_1)fBL + \tilde{b}_1f_{1,1} + \tilde{c}_1f_{1,2}$. (5.4.23)
```

Case 2: $j=n_{s-2}$.nSubstituting $j=n_{s-2}$ into equation (5.4.14), we obtain

```
$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} + cn_{n_{s-2}}f_{i,n_{s-1}}
= \tilde{a}_{n_{s-2}}f_{i+1,n_{s-3}} + \tilde{b}_{n_{s-2}}f_{i+1,n_{s-2}} + \tilde{c}_{n_{s-2}}f_{i+1,n_{s-1}}$.
```

Since $f_{i,n_{s-1}} = fBU$, this gives

```
$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} = \tilde{a}_{n_{s-2}}f_{i+1,n_{s-3}} + (\tilde{c}_{n_{s-2}} - c_{n_{s-2}})fBU$,
```

or equivalently

```
$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} = R_{i+1,n_{s-2}}$, (5.4.24)
```
