```

```

Then Fubini's theorem (see Section 2.12.1),

```
$E \left{\int_{s=0}^{s=t}\{\exp(\alpha s)\}^2 ds\right] = E \left{\int_{s=0}^{s=t}\{\exp(\alpha s)\}^2 ds\right}\n= \int_{s=0}^{s=t} \exp(2alpha s) ds\n= \left{\\exp(2alpha s)}{2alpha}\right]_{s=0}^{s=t}\n= \frac{\exp(2alpha t)-1}{2alpha}$
```

```

```

```
$Var[X_t] = \sigma^2 \left{\{\exp(-2alpha t)}{2alpha}\right\} (2.10.11)$
```
