# 7.4.3 Total Swap

A total return swap (TRS) is a synthetic replication of the return of a reference asset (bond) $B$.
A total return swap (TRS) is a synthetic replication of the return of a reference asset (bond) $B$. The receiver of the TRS receives the coupon payments of the reference asset during the life of the swap for making periodic coupon payments at the risk-free rate plus an agreed margin. In the event of default, the receiver makes a default payment to the payer equal to the agreed price of the reference asset less the price at default, and the transaction terminates. If there is no default, the difference between the initial asset (bond) price $B_0$ and the price at maturity $B(t_m)$ is settled by the payer and the receiver, with the receiver paying (receiving) if the (bond) is worth less (more) at maturity. The maturity of the reference asset (bond) may be longer than the maturity $t_m$.

To the receiver of the reference asset coupons, a TRS has value $TRS$, which is given by

$TRS = $ total bond return – total floating coupon payments of the swap
total bond return = total bond fixed coupons over the duration of the TRS + increase in the bond value at maturity of the TRS – default payment, if the bond defaults over the duration of the TRS.
The value of $TRS_t$ at time $t$

$TRS_{(t)} =$

```
$= \hat{C} \sum_{t_j=t_1}^{t_m} DF(t,t_j) \quad \text{fixed reference bond payments}$
$+ P \left\{ \frac{B(t_m) - B_0}{B_0} \right\} DF(t,t_m) \quad \text{increase in value of reference bond}$
$- \sum_{t_j=t_1}^{t_m} C_j DF(t,t_j) \quad \text{floating payments of swap at LIBOR + margin}$
$- P (1 - R) \sum_{t_j=t_1}^{t_m} DF(t,t_j) \{S(t,t_{j-1}) - S(t,t_j)\} \quad \text{bond default payments,}$
```

and the reference bond satisfies

```
$B(t_r) = 1$
$B(t_m) = \overline{DF(t_m,R)}t + \hat{C} \sum_{t_j=t_m}^{t_r} DF(t_m,t_j)|t$
$+ R \sum_{t_j=t_m}^{t_r} DF(t_m,t_j)|t \S(m,t_{j-1}) - S(m,t_j)\}$.
```
