### 2.7 ITO PRODUCT IN DIMENSIONS

Using (2.5.7) we will derive an expression for the product of $n$ stochastic processes. In this case, $\phi = \prod_{i=1}^n X_i$, and the partial derivatives are follows:

$\frac{\partial \phi}{\partial X_i} = \phi \frac{1}{X_i}, \quad \text{for } i=1,...,n,$

$\frac{\partial^2 \phi}{\partial X_i^2} = 0, \quad \text{for } i=1,...,n,$

$\frac{\partial^2 \phi}{\partial X_i \partial X_j} = \phi \left(\frac{1}{X_i}\right)\left(\frac{1}{X_j}\right), \quad \text{for } i \neq j, i=1,...,n,j=1,...,n,$

$\frac{\partial \phi}{\partial t} = 0.$

So substituting into (2.5.7), we have

$d\phi = \phi \sum_{i=1}^n \left(\frac{dX_i}{X_i}\right)^2 + \phi E \left[\sum_{i=1}^n \sum_{j=1(i\neq j)}^n \left(\frac{dX_i}{X_i}\right)\left(\frac{dX_j}{X_j}\right)\right]$. (2.7.1)

which in full is

$d\left(\prod_{i=1}^{n} X_{i}\right)=\left(\prod_{i=1}^{n} X_{i}\right)\left(\sum_{i=1}^{n} \frac{dX_{i}}{X_{i}}\right)+\left(\prod_{i=1}^{n} X_{i}\right)E\left(\sum_{i=1}^{n} \sum_{j=1,(i\neq j)}^{n} \frac{dX_{i}}{X_{i}} \frac{dX_{j}}{X_{j}}\right)$. (2.7.2)

## 2.8 THE BROWNIAN BRIDGE

Let a Brownian process have values $W_{t0}$ at time $t0$ and $W_{t1}$ at time $t1$. We want to find the conditional distribution of $W_{t}$, where $t0 < t < t1$. This distribution will be denoted by $P(W|W_{t0}, W_{t1})$ to indicate that $W$ is conditional on the end values $W_{t0}$ and $W_{t1}$. We now write $W_{t}$ and $W_{t1}$ as

$W_{t} = W_{t0} + \sqrt{(t-t0)}X_{t}, \quad X_{t} \sim N(0,1), (2.8.1)$

$W_{t1} = W_{t0} + \sqrt{(t1-t)}Y_{t}, \quad Y_{t} \sim N(0,1), (2.8.2)$

where $X_{t}$ and $Y_{t}$ are independent variables. Combining equation (2.8.1) and equation (2.8.2), we can be re-expressed as

$W_{t1} - W_{t0} = \sqrt{(t-t0)}X_{t} + \sqrt{(t1-t)}Y_{t}.$

Using the Brownian motion property, $Z_{t} \sim N(0,1)$,

$Z_{t} = \frac{W_{t1} - W_{t0}}{\sqrt{t1-t0}}$. (2.8.3)

Now the probability distribution of $W_t$ conditional on $W_{t0}, W_{t1}$ is, $P(W_t|W_{t0}, W_{t1})$. By Bayes law,

$P(W_t|W_{t0}, W_{t1}) = \frac{P(W_{t1}|W_t)P(W_t|W_{t0})}{P(W_{t1})}$.

Since $X_{t}$, $Y_{t}$, and $Z_{t}$ are Gaussian, we can write

$P(W_t|W_{t0}, W_{t1}) = \frac{1}{\sqrt{2\pi}}\exp\left(-\frac{\left(W_t - \frac{t-t0}{t1-t0}(W_{t1}-W_{t0})\right)^2}{2\frac{t-t0}{t1-t0}}\right)$.

First let us compute $Y_{t}^{2}$,

$Y_{t}^{2} = \left(\frac{W_{t1} - W_{t0} - \sqrt{(t-t0)}X_{t}}{\sqrt{(t1-t)}}\right)^{2} = \frac{(W_{t1}-W_{t0})^2 + (t-t0)X_t^2 - 2\sqrt{(t-t0)}(W_{t1}-W_{t0})X_t}{t1-t}$.

Next we compute $X_t^2 + Y_t^2 - Z_t^2$ as follows:

$X_t^2 + Y_t^2 - Z_t^2 = \frac{(W_{t1}-W_{t0})^2 + (t-t0)X_t^2 - 2\sqrt{(t-t0)}(W_{t1}-W_{t0})X_t}{t1-t} - \frac{(W_{t1}-W_{t0})^2}{t1-t0}$ (Wait, the logic follows simplification).

Dividing top and bottom of equation (2.8.7) by $t1-t0$, we obtain

$X_t^2 + Y_t^2 - Z_t^2 = \frac{\frac{(W_{t1}-W_{t0})^2}{t1-t0} + \frac{t-t0}{t1-t0}X_t^2 - 2\frac{\sqrt{(t-t0)}}{t1-t0}(W_{t1}-W_{t0})X_t}{1}$ (OCR error in source).

which gives

$X_t^2 + Y_t^2 - Z_t^2 = \frac{\left(X_t - \frac{t-t0}{t1-t0}(W_{t1}-W_{t0})\right)^2}{\frac{t-t0}{t1-t0}}$

where we have used

$\left(X_t - \frac{t-t0}{t1-t0}(W_{t1}-W_{t0})\right)^2 = X_t^2 + \frac{(t-t0)^2}{(t1-t0)^2}(W_{t1}-W_{t0})^2 - 2\frac{t-t0}{t1-t0}(W_{t1}-W_{t0})X_t$.

Substituting equation (2.8.8) into (2.8.5) yields

$P(W_t|W_{t0}, W_{t1}) = \frac{1}{\sqrt{2\pi}}\exp\left(-\frac{\left(W_t - \frac{t-t0}{t1-t0}(W_{t1}-W_{t0})\right)^2}{2\frac{t-t0}{t1-t0}}\right)$.

Therefore, $P(W_t|W_{t0}, W_{t1})$ is a Gaussian distribution with

$E[W_t|W_{t0}, W_{t1}] = W_{t0} + \frac{t-t0}{t1-t0}(W_{t1}-W_{t0})$ and $Var[W_t|W_{t0}, W_{t1}] = \frac{t-t0}{t1-t0}t$.

We can substitute $\tilde{X}_t$ for $X_t$ in equation (2.8.1) to obtain

$W_t = W_{t0} + \sqrt{t-t0} \left(E[X_t] + \sqrt{Var[X_t]}\right)$.

which gives

$W_t = W_{t0} + \sqrt{t-t0} \left\{E[X_t] + \sqrt{Var[X_t]}\right\}$.

The variate $\bar{X}_t = E[X_t] + \sqrt{Var[X_t]}$ has the same distribution as $P(W_t|W_{t0}, W_{t1})$.

## 2.9 TIME TRANSFORMED BROWNI MOTION

Let us consider the Brownian motion

$dW_t = \sigma \sqrt{dt} dZ_t$, (2.9.1)

and the scaled and transformed Brownian motion

$Y_t = a_t W_{f_t}$, (2.9.2)

where the scale factor, $a_t$, is a real function and $f_t$, is a increasing function satisfying $f_t \geq 0$, see Cox and Miller (1965).

Using Ito's lemma,

$dY_t = \frac{\partial Y_t}{\partial t}dt + \frac{\partial Y_t}{\partial W_t}dW_t$, (2.9.3)

where we have used the fact that $\frac{\partial^2 Y_t}{\partial W_t^2} = 0$.

From equation (2.9.3),

$dW_{f_t} = \left(\frac{\partial a_t}{\partial t}\right)W_{f_t} + a_t df_t$, (2.9.4)

Now

$dW_{f_t} = \sqrt{dt} dZ_t = \sqrt{\frac{\partial f_t}{\partial t}} dt dZ_t$, (2.9.5)

so we can write

$dY_t = a_t' W_{f_t} + a_t \sqrt{f_t'} dt dZ_t$, (2.9.6)

where

$a_t' = \frac{\partial a_t}{\partial t} \text{ and } f_t' = \frac{\partial f_t}{\partial t}$.

### 2.9.1 Scaled Brownian Motion

We will prove that $\hat{W}_t$ defined by

$\hat{W}_t = \frac{1}{c}W_{c^2t}, \quad c > 0$

is Brownian motion.
Let us consider the process

$\hat{Y}_t = W_{c^2t}.$

From equation (2.9.2), we have $a_t = 1, f_t = c^2t, a'_t = 0$, and $f'_t = c^2$.
Substituting these values into equation (2.9.6) yields

$dY_t = \sqrt{c^2}dt \ dZ_t,$

which gives

$dY_t = c\sqrt{c}dt dZ_t = cW_t.$

Therefore, $\hat{W}_t = \frac{dY_t}{c}$ is Brownian motion.
