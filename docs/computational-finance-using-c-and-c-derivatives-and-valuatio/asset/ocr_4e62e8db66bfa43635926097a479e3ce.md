Iterate Backwards through the Lattice

The probability of moving from node $(i,j)$ at time $i\Delta t$ to node $(i+1,j+1)$ at time $(i+1)\Delta t$ is $p$, and the probability of moving from node $(i,j)$ at time $i\Delta t$ to the node $(i+1,j)$ at time (i+1)\Delta t$ is $1-p$. If we assume there is no early exercise, then

```
$f_{i,j}^E = \exp(-r\Delta t)pf_{i+1,j}^E + (1-p)f_{i+1,j}^E, \quad j \leq n-1, \quad 0 \leq j \leq i. \quad (5.3.22)$
```

When early exercise, for an American option, is taken into account, we have

```
$f_{i,j}^A = \max\{E - S_{i,j}, f_{i,j}^E\}, \quad (5.3.23)$
```

or for an American option,

```
$f_{i,j}^A = \max\{S_{i,j} - E, f_{i,j}^E\}, \quad j \leq i \leq N-1, \quad 0 \leq j \leq i. \quad (5.3.24)$
```

where $f_{i,j}^E$ is given by (5.3.22).

The following Code excerpt 5.8 works backward through the lattice and uses the array $v$ to store option values.

```
for (m = m1; m >= 2; --m) {
  P1 = m-1;
  P2 = m-2;
  for (n = 0; n <= m; ++n) {
    if (v(n) == zero && v(n+1) == zero) {
      hold = zero;
    } else {
      hold = p*d[v(n)+1] + (1-p)*d[v(n+1];
      if (is_american) {
        if (hold) {
          v(n) = MAX(hold, X[P1]);
        } else {
          v(n) = MAX(hold, S[P1]);
        }
      }
    }
  }
  P1 = P2;
}
```

**Code excerpt 5.8** Computer code that iteratively backward through the lattice computing the option values at each time step. The array v contains the option values from the previous time step, and they are overwritten with option values computed for the current time step. The iteration stops at the second step, since we do not want to overwrite values required for calculating Greeks in the neighbourhood of the root node.

At each time step, the newly calculated option values overwrite those computed by the previous time step. This process is continued until the second time step (m=2) is reached. A different technique is then used, which does not overwrite the values and allows the Greeks to be computed in the vicinity of the root lattice node R. If the Greeks are not required, continue working backward through the lattice until the root node R (m1=0) is reached, and the current value of the option is then given by v[0] (or multidimensional equivalent).
