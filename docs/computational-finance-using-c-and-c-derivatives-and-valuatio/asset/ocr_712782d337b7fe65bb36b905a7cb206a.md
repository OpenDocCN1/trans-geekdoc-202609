Next we compute $X_t^2 + Y_t^2 - Z_t^2$ as follows:

```
$X_t^2 + Y_t^2 - Z_t^2 = \frac{(t_1-t_0)X_t^2 + (t-t_0)Z_t^2 - 2\sqrt{(t_1-t_0)}\sqrt{(t-t_0)}X_t Z_t}{(t_1-t_0)}$
```

Dividing top and bottom of equation (2.8.7) by $t_1-t_0$, we obtain

```
$X_t^2 + Y_t^2 - Z_t^2 = \frac{\frac{(t_1-t_0)}{t_1-t_0}Z_t^2 - 2\sqrt{\frac{(t_1-t_0)}{t_1-t_0}}\sqrt{\frac{(t-t_0)}{t_1-t_0}}X_t Z_t}{\frac{t_1-t_0}{t_1-t_0}}$
= \frac{\frac{(t-t_0)}{t_1-t_0}Z_t^2 - 2\sqrt{\frac{(t-t_0)}{t_1-t_0}}\sqrt{\frac{(t_1-t_0)}{t_1-t_0}}X_t Z_t}{\frac{t_1-t_0}{t_1-t_0}}$
```

which gives

```
$X_t^2 + Y_t^2 - Z_t^2 = \frac{\left(X_t - \sqrt{\frac{(t-t_0)}{t_1-t_0}}}Z_t\right)^2}{\frac{t_1-t_0}{t_1-t_0}}$
```

where we have used

```
$\left(X_t - \sqrt{\frac{(t-t_0)}{t_1-t_0}}}Z_t\right)^2 = X_t^2 + \frac{(t-t_0)}{t_1-t_0}Z_t^2 - 2\sqrt{\frac{(t-t_0)}{t_1-t_0}}\sqrt{\frac{t_1-t_0}{t_1-t_0}}X_t Z_t.$
```

Substituting equation (2.8.8) into (2.8.5) yields

```
$P(X_t|Z_t) = \frac{1}{\sqrt{2\pi}}exp\left(-\frac{\left(X_t - \sqrt{\frac{(t-t_0)}{t_1-t_0}}}Z_t\right)^2}{2\frac{t_1-t}{t_1-t_0}}\right)$
```

Therefore, $P(X_t|Z_t)$ is a Gaussian distribution with

```
$E[X_t|Z_t] = \sqrt{\frac{t-t_0}{t_1-t_0}}Z_t$ and $Var[X_t|Z_t] = \sqrt{\frac{t_1-t}{t_1-t_0}}$
```

```

which gives

```
$E[X_t] = \sqrt{\frac{t-t_0}{t_1-t_0}}(W_t-W_{t_0}).$
