# 2.12.1 Fubini's Theorem

Fubini's theorem states that (for well-behaved functions) the value of a multidimensional integral is independent of the order in which the integral is evaluated. For example, the two-dimensional integral of the function $f(X,Y)$ can be evaluated as

```
$$\int_{X=a}^b \int_{Y=c}^d f(X,Y)dXdY = \int_{X=a}^b \int_{Y=c}^d f(X,Y)dX = \int_{Y=c}^d \int_{X=a}^b f(X,Y)dY.$$
```

We will mainly use this result in the form

```
$$\left[\int_{s=0}^t f(W,s)ds\right] = \int_{s=0}^t E[f(W,s)]ds. \quad (2.12.1)$$$
```

Since

```
$E[f(W,s)] = \int_{-\infty}^{\infty} P(W,s)f(W,s)dW$
```

where $P(W,s)$ is the probability density function of $f(W,s)$. We can then use equation (2.12.1) in full

```
$$\int_{-\infty}^{\infty} \int_{s=0}^t P(W,s)dsdW = \int_{s=0}^t \int_{W=-\infty}^{\infty} P(W,s)dsdW.$$
```
