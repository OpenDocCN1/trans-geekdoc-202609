
## Appendix I

## Feynman–Kac Formula

### 1.1 SOME RESULTS

The Feynman–Kac formula provides a link between stochastic processes and partial differential equations, which we will now illustrate.

In the risk-neutral measure, the equation followed by the asset price is

```
$$dS = rSdt + \sigma dW \quad (I.1.1)
```

and that of the money account

```
$$dB = Brdt. \quad (I.1.2)$$
```

If $(S,t)$ is the value of a derivative, then using Ito’s lemma we have

```
$$df = \left[ \frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2} \right]dt + \frac{\partial f}{\partial S}\sigma dW. \quad (I.1.3)$$
```

Since $f$ is a tradable, we know that the process $(f/B)$ must be a martingale in the risk-neutral measure and therefore have zero drift.

We will evaluate $d(f/B)$ using the quotient rule (see equation (2.6.4))

```
$$d\left(\frac{X_1}{X_2}\right) = \left(\frac{dX_1}{X_2} - \frac{X_1 dX_2}{X_2^2}\right) + E\left[\frac{dX_1}{X_1}\frac{dX_2}{X_2}\right] - E\left[\frac{dX_2}{X_2}\frac{dX_1}{X_1}\right] \quad (I.1.4)$$
```

and rewrite equation (I.1.2) and (I.1.3) as

```
$$dX_1 = \mu_1 dt + \sigma_1 dW,$$ \
dX_2 = \mu_2 dt$$
```

where

```
$$d\left(\frac{X_1}{X_2}\right) = d\left(\frac{f}{B}\right), \quad \tilde{\mu}_1 = \left[\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2}\right],,$$ \
\tilde{\sigma}_1 = \sigma\frac{\partial f}{\partial S}, \tilde{\sigma}_2 = r, X_1 = f, X_2 = B, \tilde{\mu}_2 = r.$$
```

Evaluating equation (I.1.4), we obtain

```
$$E\left[\left(\frac{dX_1}{X_2}\right)\left(\frac{dX_2}{X_2}\right)\right] = E\left[\tilde{\mu}_2^2 dt^2\right] \to 0,$$
```

```
$$E\left[\left(\frac{dX_1}{X_1}\right)\left(\frac{dX_2}{X_2}\right)\right] = E\left[\left(\frac{\tilde{\mu}_1 dt + \sigma_1 dW}{X_1}\right)\left(\frac{\tilde{\mu}_2 dt}{X_2}\right)\right] \to 0,$
```

and therefore,

```
d\left(\frac{X_1}{X_2}\right) = \left(\frac{X_1}{X_2}\right)\left(\frac{\mu_1 dt + \sigma_1 dW}{X_1} - \frac{\mu_2 dt}{X_2}\right)\n= \left(\frac{\mu_1}{X_2} - \frac{\mu_2}{X_1}\right)dt + \left(\frac{\sigma_1}{X_2}\right)dW\n= \frac{1}{X_2}\{\mu_1 - X_1\mu_2\}dt + \left(\frac{\sigma_1}{X_2}\right)dW. \quad (I.1.5)
```

Since $(X_1/X_2)$ is a martingale, the drift term in equation (I.1.5) is zero so

```
\mu_1 - X_1\mu_2 = 0. \quad (I.1.6)
```

Therefore, substituting for $\mu_1, X_1$ and $\mu_2$ in equation (I.1.6), we obtain

```
\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2} - rf = 0 \quad (I.1.7)
```

or

```
\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2} = rf, \quad (I.1.8)
```

which is the Black–Scholes partial differential equation, which we derived in Chapter 4.

In general, if an asset follows the process

```
dS = \mu dt + \sigma dW. \quad (I.1.9)
```

then the price of a derivative $f(S,t)$ obeys the partial differential equation

```
\frac{\partial f}{\partial t} + \hat{\mu}\frac{\partial f}{\partial S} + \frac{\hat{\mu}^2}{2}\frac{\partial^2 f}{\partial S^2} = rf \quad (I.10)
```

or

```
\dots \text{ (similar form)} \dots \quad (I.11)
```

## Glossary

The notation used is as follows:

- **GBM**: Geometric Brownian motion.
- **BM**: Brownian motion.
- $W_t$: Brownian motion at time $t$ - the term may be non-zero.
- $\rho$: The correlation coefficient.
- $\sigma$: The volatility. Since assets follow GBM it is computed as the standard deviation of the returns.
- $r$: The free interest rate.
- $q$: The continuously dividend yield.
- $S_t$: The asset price at time $t$.
- $I_{nn}$: The $n \times n$ unit matrix.
- $\Lambda(\mu,\sigma^2)$: A lognormal distribution with parameters $\mu$ and $\sigma^2$. If $y = \log(x)$ and $y \sim N(\mu,\sigma^2)$ then the distribution for $x = e^y$ is $\Lambda(\mu,\sigma^2)$. We have $E[x] = \exp(\mu + \frac{\sigma^2}{2})$ and $Var[x] = \exp(2\mu + \sigma^2)(\exp(\sigma^2) - 1)$.
- $DF(t,T)$: The discount factor between times $t$ and $T$, where $T \geq t$. The price of a defaultable coupon bond that matures at $T$ is the expected value of $DF(t,T)$. In this book we assume that interest rates are deterministic and thus $DF(t,T)$ is the value of a coupon bond maturing at $T$.
- $\overline{DF}(t,T)$: The discount factor (including the possibility of default) between times $t$ and $T$, where $T \ge t$: $\overline{DF}(t,T) = S(t,T)DF(t,T)$. The price of a defaultable zero coupon bond which matures at $T$ is the expected value of $DF(t,T)$. In this book we assume that interest rates are deterministic and $\overline{DF}(t,T)$ is the value of a defaultable zero bond bond maturing at $T$.
- $F(t,T_1,T_2)$: The forward rate at time $t$ between times $T_1$ and $T_2$ where $T_2 \ge T_1$ and $T_1 \ge t$.
- $L(T_1,T_2)$ is the simply compounded spot rate between times $T_1$ and $T_2$,
- $\log(x)$: The natural logarithm of $x$.
- $N(a,b)$: Normal distribution, with mean $a$ and variance $b$.
- $dW_t$: A Brownian motion, this is simulated as normal vari (sampled at time $t$) from the distribution $N(0,dt)$, where $dt$ a specified time interval e.g. $dx = \mu dt + dW_t$.
- $dZ_t$: A Normal (sampled at time $t$) from the distribution $N(0,1)$. Note: the variate $\psi = \sqrt{dt}Z_t$ has the same distribution as $dW_t$.
- IID: Independently and Identically Distributed.
- $\mathcal{U}(a,b)$: The uniform distribution, with lower limit $a$ and upper limit $b$.
- $|x|$: The absolute value of the variable $x$.
- $PDF$: The probability density function of a given distribution.
- $x \wedge y$: The minimum of $x$ and $y$, that is $min(x,y)$.
- $S(t,T)$: The survival probability between time $t$ and $T$, $T > t$.
- $\|A-B\|$: The distance between two matrices with the same dimensions. If $A$ and $B$ both have $n$ rows and $m$ columns then this is

```
\sqrt{\sum_{i=1}^{n} \sum_{j=1}^{m} {A_{i,j} - B_{i,j}}^2}
```

where $A_{i,j}$, and $B_{i,j}$, refer to the element in the $i$th row and $j$th column.
