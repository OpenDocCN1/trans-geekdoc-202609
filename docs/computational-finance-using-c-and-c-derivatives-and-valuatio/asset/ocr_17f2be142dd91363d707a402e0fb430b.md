# H.4 PROOF OF EQUATION (H.1.5)

We know that $P(\tilde{X}_t \ge K) = 1 - P(\tilde{X}_t \le K)$.\nSubstituting from equation (H.1.4) gives

$P(\tilde{X}_t \ge K) = 1 - N_1\left(\frac{K-vt}{\sigma\sqrt{t}}\right)$

Since $1 - N_1(x) = N_1(-x)$, we obtain

$P(\tilde{X}_t \ge K) = N_1\left(\frac{vt-K}{\sigma\sqrt{t}}\right)$
