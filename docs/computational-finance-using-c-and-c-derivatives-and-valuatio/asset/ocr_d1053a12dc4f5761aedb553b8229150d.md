```
d\left(\frac{X_1}{X_2}\right) = \left(\frac{X_1}{X_2}\right)\left(\frac{\mu_1 dt + \sigma_1 dW}{X_1} - \frac{\mu_2 dt}{X_2}\right)\n= \left(\frac{\mu_1}{X_2} - \frac{\mu_2}{X_1}\right)dt + \left(\frac{\sigma_1}{X_2}\right)dW\n= \frac{1}{X_2}\{\mu_1 - X_1\mu_2\}dt + \left(\frac{\sigma_1}{X_2}\right)dW. \quad (I.1.5)
```

Since $(X_1/X_2)$ is a martingale, the drift term in equation (I.1.5) is zero so

```
\mu_1 - X_1\mu_2 = 0. \quad (I.1.6)
```

Therefore, substituting for $\mu_1, X_1$ and $\mu_2$ in equation (I.1.6), we obtain

```
\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2} - rf = 0 \quad (I.1.7)
```

or

```
\frac{\partial f}{\partial t} + rS\frac{\partial f}{\partial S} + \frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial S^2} = rf, \quad (I.1.8)
```

which is the Black–Scholes partial differential equation, which we derived in Chapter 4.

In general, if an asset follows the process

```
dS = \mu dt + \sigma dW. \quad (I.1..9)
```

then the price of a derivative $f(S,t)$ obeys the partial differential equation

```
\frac{\partial f}{\partial t} + \hat{\mu}\frac{\partial f}{\partial S} + \frac{\hat{\mu}^2}{2}\frac{\partial^2 f}{\partial S^2} = rf \quad (I.1.10)
```

or

```
\frac{\partial f}{\partial t} + \tilde{\mu}\frac{\partial f}{\partial S} + \frac{\tilde{\mu}^2}{2}\frac{\partial^2 f}{\partial S^2} f = rf. \quad (I.1.11)
```
