# H.2 PROOF OF EQUATION (H.1.2)

From equation (H.1.2),

```
$X_t = \sigma\sqrt{t}Z_t, \quad Z_t \sim N(0,1),$
```

where $X_0 = 0$. We define the probability of events that $m_t^X \le b$ and $X_t \ge b$ occurring. For $m_t^X$ to occur, there must be a $	au$ such that $X\tau \le b$, for $0 < \tau \le t$. At time $	au$ instead of continuing with the original Brownian motion, $X_t$ we will consider the reflected motion $X_t^R$ defined by

```
$X_s^R = X_s, \quad s < \tau$\nnX_s^R = 2b - X_s, \quad s \ge \tau$.
```

Therefore, before time $	au$, the motion $X_s$ is identical to $X_s^R$. For $s \ge \tau$, the coordinates of $X_s^R$ are obtained by reflection of $X_s$ about the level $b$. The event $X_t \ge x$ is equivalent to the event $X_t^R \le 2b-x$ (remember $b \le 0$ and $x \ge 0$). However, the event $X_t^R \le 2b-x$ only occurs if $m_t^X \le b$ also occurs,

```
$P(X_t^R \le 2b-x) = P(m_t^X \le b, X_t \le x)$.
```

At time $	au$, we have

```
$X_{t+	au}^R = 2b - X_	au, \quad (H.2.1)$
```

and after time $	au$,

```
$X_{	au+y}^R = 2b - X_{	au+y}, \quad y > 0. \quad (H.2.2)$
```

Thus, subtracting equation (H.2.1) from equation (H.2.2) gives

```
$X_{	au+y}^R - X_	au^R = X_	au - X_{	au+y},\nX_{	au+y}^R - X_	au^R = -(X_{	au+y} - X_	au). \quad (H.2.3)$
```

However, we know that

```
$(X_{	au+y} - X_	au^R) \sim N(0, \sigma^2 \gamma). \quad (H.2.4)$
```

So

```
$(X_{	au+y} - X_	au^R) \sim -N(0, \sigma^2 \gamma),
```

which means that

```
$(X_{	au+y}^R - X_	au^R) \sim N(0, \sigma^2 \gamma). \quad (H.2.5)$
```

Since the left-hand sides of equation (H.2.4) and equation (H.2.5) have the same distribution, and $	au$ satisfies the three Brownian properties in Section 2.1, we write

```
$P(X_t^R \le 2b-x) = P(X_t \le 2b-x)\n= N_1 \left(\frac{2b-x}{\sigma\sqrt{t}}\right).
```
