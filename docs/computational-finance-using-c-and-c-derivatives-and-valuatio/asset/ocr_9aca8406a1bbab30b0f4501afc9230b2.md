# Put Options on the Maximum of Two Assets

It will now be shown that the price of a European put on the maximum of two assets, $p_{max}(S_1, S_2, E, 	au)$ is

```
$p_{max}(S_1, S_2, E, 	au) = E \exp(-r\tau) - c_{max}(S_1, S_2, \tau) + c_{max}(S_1, S_2, E, \tau), \quad (6.5.9)$
```

where, as before, the meaning of the symbols has been previously defined.
This result can be proved by considering the following two investments:

# Portfolio A:

Purchase one option on the maximum of $S_1$ and $S_2$ with exercise price $E$.

# Portfolio B:

Purchase one discount bond which pays $E$ at maturity. (Write is to sell) one option on the maximum of $S_1$ and $S_2$ with an exercise price of zero. Purchase one option on the maximum of $S_1$ and $S_2$ with exercise price $E$.

As we now consider the values of these portfolios at option maturity,

If max($S_1, S_2$) $\ge E$

Portfolio A: Pays zero
Portfolio B: Pays $-max(S_1, S_2) + max(S_1, S_2) - E = 0$.

If max($S_1, S_2$) < $E$

Portfolio A: Pays $E - S_1$
Portfolio B: Pays $E - S_1 + 0 = E - S_1$.

If max($S_1, S_2$) = $S_2$

Portfolio A: Pays $E - S_2$
Portfolio B: Pays $E - S_2 + 0 = E - S_2$.

It follows that, under all possible circumstances, Portfolio A has the same value as Portfolio B, and this means that equation (6.5.9) is true.
