Comparing coefficients of $A$ and $B$, we have the following:

Coefficients for $W_t^2$:

$A : \frac{1}{2V} \left( \frac{(t_1 - t)}{(t_1 - t_0)} + \frac{(t - t_0)}{(t_1 - t_0)} ight) = -\frac{1}{2V} \left( \frac{t_1 - t + t - t_0}{t_1 - t_0} ight) = \frac{1}{2V}$,

$B : \frac{1}{2V^2}$,

Coefficients for $W_{t_1}^2$:

$A : \frac{1}{2V} \left( \frac{(t_1 - t)}{(t_1 - t_0)} - \frac{(t - t_0)(t_1 - t)}{(t_1 - t_0)^2} ight) = \frac{1}{2V} \left( \frac{(t_1 - t)(t_1 - t_0) - (t - t_0)(t_1 - t)}{(t_1 - t_0)^2} ight)$,

$A : \frac{1}{2V} \left( \frac{(t_1 - t)(t - t_0)}{(t_1 - t_0)^2} ight) = -\frac{1}{2V} \left( \frac{(t_1 - t)^2}{(t_1 - t_0)^2} ight)$,

$B : \frac{1}{2V} \left( \frac{(t_1 - t)^2}{(t_1 - t_0)^2} ight)$,

Coefficients for $W_t^2$:

$A : \frac{1}{2V} \left( \frac{(t - t_0)(t_1 - t_1) - (t - t_0)(t_1 - t)}{(t_1 - t_0)^2} ight) = \frac{1}{2V} \left( \frac{(t - t_0)(t_1 - t_0 - t_1 + t)}{(t_1 - t_0)^2} ight)$,

$A : \frac{1}{2V} \left( \frac{(t_1 - t)^2}{(t_1 - t_0)^2} ight)$,

$B : \frac{1}{2V} \left( \frac{(t_1 - t_0)^2}{(t_1 - t_0)^2} ight)$,

The remaining coefficients in $A$ and $B$ for $W_{t_0}W_{t_1}, W_{t_1}W_t, W_{t_0}W_t$ are identical.

We have shown that

$P(W_{t_1}|{W_{t_0}, W_{t_1}\}) = \frac{1}{\sqrt{2\pi}} \left( \frac{(t_1 - t_0)}{(t - t_0)(t_1 - t)} ight) \exp \left\{ -\left( \frac{(W_{t_1} - \mu)^2}{2V} ight) ight\}$

= \frac{1}{\sqrt{2\pi V}} \exp \left\{ \frac{(W_{t_1} - \mu)^2}{2V} ight \}$,

Thus, the conditional distribution of $W_t$ is a Gaussian with mean

$\mu = W_{t_0} \frac{(t_1 - t)}{(t_1 - t_0)} + W_{t_1} \frac{(t - t_0)}{(t_1 - t_0)}$

and variance

$V = \frac{(t - t_0)(t_1 - t)}{(t_1 - t_0)}$,

and we can obtain a variate $\hat{W}_t$ from this distribution using

$\hat{W}_t = W_{t_0} \frac{(t_1 - t)}{(t_1 - t_0)} + W_{t_1} \frac{(t - t_0)}{(t_1 - t_0)} + \frac{(t - t_0)(t_1 - t)}{(t_1 - t_0)} Z, 	ext{ where } Z \sim N(0,1)$.
