Before we solve equation (5.4.14) we will briefly consider its characteristics for different values of the weight parameter $\Theta_m$. When $\Theta_m = 1$, the values of the coefficients in equation (5.4.14) are $a_j = c_j$ and $b_j = 1$. This means that equation (5.4.14) reduces to

```
$f_{i,j} = a_j f_{i+1,j-1} + b_j f_{i+1,j} + c_j f_{i+1,j+1}$.
```

This is termed the *explicit method*, and it can be seen that the unknown value $f_{i,j}$ at the node $(i,j)$ is just a weighted sum of the (known) option values $f_{i+1,j-1}, f_{i+1,j}$, and $f_{i+1,j+1}$. This is the simplest situation to deal with and actually corresponds to a trinomial lattice; however it has numerical properties and requires a very small step size to obtain accurate results, see Smith (1985).

When $\Theta_m 
eq 1$, the unknown value $f_{i,j}$ depends not only on the known option values $f_{i+1,j-1}, f_{i+1,j}$, and $f_{i+1,j+1}$ (as in the explicit method above) but on the neighbouring unknown values $f_{i,j-1}$ and $f_{i,j+1}$. It is now necessary to solve a set of simultaneous equations to compute the value $f_{i,j}$. This is therefore called an *implicit method*, see see Smith (1985).

The implicit method $\Theta_m = 0$ is also the fully implicit method, since the now value $f_{i,j}$ only depends on the neighbouring values $f_{i,j-1}, f_{i,j+1}$, and previous value $f_{i,j}$. This can be shown by substituting $\Theta_m = 0$ in equation (5.4.16) to (5.4.21). We then have $	ilde{a}_j = 	ilde{c}_j$ and $	ilde{b}_j = 1$, which means that equation (5.4.14) reduces to

```
$a_j f_{i,j-1} + b_j f_{i,j} + c_j f_{i,j+1} = f_{i+1,j}$.
```
