For exotic options (such as time dependent barrier options), the value of a particular price path will depend on the asset values $S_{i,i}=0,\dots,n$. This is not true of European vanilla options whose value depends only on $S_n$, the underlying asset price at maturity. The Monte Carlo approximation to the value of an exotic option is this

```
$f = \frac{\sum_{j=1}^{nsim} p_j(n_j)}{nsim}$
```

where $nsim$ is the number of simulations used, $n_j$ is the number of time steps associated with the $j$th price path, and $p_j(n_j)$ is the value of the $j$th price path. In the case of European vanilla options, we can use $n_j=1,\dots,nsim$; the accuracy improves obviously with increasing $nsim$.

The valuation of American style options, including the possibility of early exercise, is more complicated. In Chapter 5, we described the use of binomial trees to price American options where the underlying asset process is GBM. Dynamic programming was used and the option prices were computed by working backwards in time through the lattice. The application of Monte Carlo methods for pricing American options is described in Tilley (1993), Barrquud and Martineau (1995), and also by Boyle et al. (1997). Here, we will use the stochastic lattice approach described in Broaddie and Glasserman (1997), where both a high estimator and a low estimator of the American option value are calculated. Since both of these biased estimators converge (with increasing number of simulations and lattice nodes) to the true option value, we will only consider how to compute the high estimator, $\hat{	heta}_H$. We summarize the approach as follows:

+   * Set the parameters.
* Generate the lattice asset prices.
* Compute the lattice option prices.
* Compute the Monte Carlo estimate.

We will now consider each of these steps in more detail.

# Set the Parameters

First we set the simulation parameters, that is, $nsim$ is the number of lattice simulations, $b$ is the number of branches per lattice node, and $d$ is the number of time instants in the lattice.
