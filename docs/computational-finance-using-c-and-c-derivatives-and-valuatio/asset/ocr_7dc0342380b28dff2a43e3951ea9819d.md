If we now form a linear combination of call and put, then $\Psi = a_1c + a_2p$, where both $a_1$ and $a_2$ are constants, $\Psi$ obeys the Black–Scholes equation

```
$$\frac{\partial \Psi}{\partial t} + S\frac{\partial \Psi}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 \Psi}{\partial S^2} = r\Psi.$ (4.4.12)$
```

We will prove that $\Psi$ satisfies equation (4.4.12). First we rewrite equation (4.4.12) as

```
$$\frac{\partial(a_1c+a_2p)}{\partial t} + S\frac{\partial(a_1c+a_2p)}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2(a_1c+a_2p)}{\partial S^2} = r(a_1c+a_2p)$ (4.4.13)$
```

and use the following results from elementary calculus:

```
$$\frac{\partial(a_1c+a_2p)}{\partial t} = a_1\frac{\partial c}{\partial t} + a_2\frac{\partial p}{\partial t},$\n$\frac{\partial(a_1c+a_2p)}{\partial S} = a_1\frac{\partial c}{\partial S} + a_2\frac{\partial p}{\partial S}.$
```

and

If we denote the left-hand side of equation (4.4.12) by LHS, then we have

```
$LHS = a_1[\frac{\partial c}{\partial t} + S\frac{\partial c}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 c}{\partial S^2}] + a_2[\frac{\partial p}{\partial t} + S\frac{\partial p}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 p}{\partial S^2}]. (4.4.14)$
```

We use equation (4.4.10) and equation (4.4.11) to substitute for the values in the curly brackets in equation (4.4.14), and we obtain

```
$LHS = a_1rc + a_2rp.$ (4.4.15)$
```

which is the right-hand side of equation (4.4.12); so we proved the result. It should be noted that this result is also true for American options, since they also obey the Black-Scholes equation.
