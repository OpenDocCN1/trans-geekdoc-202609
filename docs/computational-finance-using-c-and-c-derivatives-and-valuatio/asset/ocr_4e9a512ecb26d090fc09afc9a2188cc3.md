Now the eigenvalues of $T_1$, see Smith (1985), are given by

```
$$\lambda_k = 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right) + 2\sqrt{AC} \cos\left(\frac{k\pi}{n_{s-2}+1}\right), \quad k=1,\dots,n_{s-2}, \quad(F.2.8)$
```

where the term

```
$$\2\sqrt{AC} = \sqrt{\frac{\sigma^4 - b^2\Delta Z^2}{\Delta Z^4}}. \quad (F.2.9)$
```

It can be seen that if $b^2\Delta Z^2 > \sigma^4$, then the eigenvalues are complex, and if $\sigma^4 \geq b^2\Delta Z^2$, then the eigenvalues are real. We will consider each of these cases in turn.

# Complex eigenvalues: $b^2\Delta Z^2 > \sigma^4$

We will represent the $k$th complex eigenvalue as

```
$$\lambda_k = R + iY$.
```

where the real part

```
$$\R = 1 + \Delta t \left(r + \frac{\sigma^2}{\Delta Z^2}\right)$
```

and the imaginary part

```
$$\Y = 2\sqrt{AC} \cos\left(\frac{k\pi}{n_{s-2}+1}\right)$.
```

Since

```
$|\lambda_k| > |R| + |Y| \quad \text{and} \quad |R| > 1$,
```

we conclude that

```
$|\lambda_{min}| > 1$.
```

# Real eigenvalues: $\sigma^4 \geq b^2\Delta Z^2$
