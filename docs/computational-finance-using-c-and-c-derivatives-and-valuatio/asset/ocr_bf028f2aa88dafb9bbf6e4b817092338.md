**FIGURE 5.10** The option for the $b=3$ and $d=3$ lattice in Fig. 5.9 corresponding to an American put with strike $E=100$ and interest rate $r=0$. The option values at the lattice nodes are computed backwards from the payoffs at maturity, $t_2$ to the current time $t_0$; the value of the option is 11.9.

Since $r=0$, we have $\exp(-r\Delta r)=1$ which gives

$h_1^1 = \frac{1}{3}(f_2^2 + f_2^2 + f_3^2) = \frac{1}{3}(16 + 0 + 49) = 21.7$,

h_1^2 = \frac{1}{3}(f_2^2 + f_2^2 + f_3^2) = \frac{1}{3}(0 + 0 + 0) = 0$,

h_1^3 = \frac{1}{3}(f_2^2 + f_2^2 + f_3^2) = \frac{1}{3}(2 + 0 + 0) = 0.66$.

The option values are then computed as follows:

$f_1^1 = \max(h_1^1, g_1^1) = \max(21.7, 15) = 21.7$,

f_1^2 = \max(h_1^2, g_1^2) = \max(0, 0) = 0$,

f_1^3 = \max(h_1^3, g_1^3) = \max(0.66, 14.0) = 14.0$.

Step 0
Here,

$g_0^1 = \max(101 - 100.0) = 1$, and

h_0^0 = \frac{1}{3}(f_1^1 + f_1^2 + f_1^3) = \frac{1}{3}(21.7 + 0 + 0.66) = 11.9$.

The final value of the option is for this particular lattice is therefore

f_0^1 = \max(h_0^0, g_0^1) = \max(11.9, 1.9) = 11.9$.
