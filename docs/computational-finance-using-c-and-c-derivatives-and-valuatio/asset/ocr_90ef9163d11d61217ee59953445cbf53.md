We will quote the Roll, Geske, and Whaley (1981) formula for the value of an American call which pays a single dividend $D_1$ at time $t_1$, it is

```
$C(S, E, \tau) = S_D \N_1(b_1) + N_2(a_1, -b_1, \sqrt{(t_1 - \tau)/\tau}) + D_1 \exp(-r(t_1 - \tau)) N_1(b_2) \- E \exp(-r\tau) N_2(a_2, -b_2, \sqrt{(t_1 - \tau)/\tau}) \ \quad \text{ (5.2.6)}$
```

where $S_D$ is given by equation (5.2.1), $E$ is the exercise price, $t$ is the option expiry date, $	au$ is the option maturity, $N(a)$ is the univariate cumulative density function with upper integral limit $a$, and $N_2(a, b, \rho)$ is the bivariate cumulative density function with upper integral limits $a$ and $b$ and correlation coefficient $\rho$. The other symbols used in equation (5.2.6) are defined as

```
$a_1 = \frac{\log(S/E) + \sigma^2/2\tau}{\sigma\sqrt{\tau}}, \quad a_2 = a_1 - \sigma\sqrt{\tau}, \\nb_2 = \frac{\log(S/S^*) + \sigma^2/2(t_1 - t)}{\sigma\sqrt{(t_1 - t)}}, \quad b_2 = b_1 - \sigma\sqrt{(t_1 - t)},
```

and $S$ is the current (time) asset price, $S^*$ is given by equation (5.2.5), $r$ is the riskless interest rate, $\sigma$ is the asset's volatility, $\tau = T - t$, and $	au_1 = T - t_1$.

To compute the value of an American call which pays $n$ dividends $D_i, i = 1, \dots, n$ at times $t_i = 1, \dots, n$, we can use the fact that optimal exercise normally only occurs over the final ex-dividend date $t_n$, see, for example, Hull (2003). Under these circumstances, equation (5.2.6) can still be shown to be the value of the American call but now $t_1$ should be set to $t_n$, $D_1$ should be set to $D_n$, and $S_D$ is given by

```
$S_D = S - \sum_{i=1}^{n} D_i \exp(-r(t_i - t)). \quad \text{ (5.2.7)}$
```
