However, if we introduce the change of variable $Z = \log S$, we obtain the following equation:

## Derivation of Equation (5.4.48)

We will now derive an expression for the logarithmic Black-Scholes equation and show that it agrees with equation (5.4.48).

Since $Z=\log S$, we have $\partial Z/\partial S=1/S$.

```
$$\frac{\partial f}{\partial S}=\frac{\partial Z}{\partial S}\frac{\partial f}{\partial Z}=\frac{1}{S}\frac{\partial f}{\partial Z}$$
```

and

```
$$\frac{\partial^2 f}{\partial S^2}=\frac{\partial}{\partial S}(\frac{\partial f}{\partial S})=\frac{1}{S}\frac{\partial}{\partial S}(\frac{1}{S}\frac{\partial f}{\partial Z})=\frac{1}{S}(-\frac{1}{S^2}\frac{\partial f}{\partial Z}+\frac{1}{S}\frac{\partial^2 f}{\partial S\partial Z}) =\frac{1}{S}\frac{\partial f}{\partial Z}\frac{1}{S}\frac{\partial^2 f}{\partial Z\partial S}+\frac{1}{S^2}\frac{\partial^2 f}{\partial Z^2}$$
```

```
$$\frac{\partial^2 f}{\partial S^2}=-\frac{1}{S^2}\frac{\partial f}{\partial Z}+\frac{1}{S^2}\frac{\partial^2 f}{\partial Z^2}$$
```

So equation (5.4.47) becomes

```
$$\frac{\partial f}{\partial t}-S\frac{\partial f}{\partial Z}+\frac{\sigma^2 S^2}{2}\frac{\partial^2 f}{\partial Z^2}=rf.$$
```

thus, setting $b=r-q-(\sigma^2/2)$, we obtain

```
$$\frac{\partial f}{\partial t}+b\frac{\partial f}{\partial Z}+\frac{\sigma^2}{2}\frac{\partial^2 f}{\partial Z^2}}=rf.$ $QED$
```

We will now consider the finite-difference discretization of equation (5.4.48).

## The Finite-Difference Method

Application of the finite-difference method to the log transformed Black-Scholes equation is very similar to that already outlined in Sections 5.4.2 and 5.4.3.

Using of the $\Theta_m$ method on equation (5.4.48) results in

```
$$\frac{f_{i+1,j}-f_{i,j}}{\Delta t}+b[\Theta_{m,i+1,j}+\Theta_{m,i,j}^*]+\frac{\sigma^2}{2}[\Theta_{m,i+1,j}^*+\Theta_{m,i,j}^*]=r[\Theta_{m,i+1,j}+\Theta_{m,i,j}^*]$$
```

where $\Theta_m^*=1-\Theta_m$. Applying a numerical discretization at node (i,j), we obtain

```
$$f_{i+1,j}-f_{i,j}\frac{\Delta t}{\Delta Z}+b\frac{\sigma^2 \Delta T^2}{2\Delta Z}=r\Delta t[\Theta_{m,i+1,j}+\Theta_{m,i,j}^*].$ (5.4.49)
```
