Taking expectations of the above equation yields
$$E\left[\int_{s=a}^{b} f(s) dW_sight] = E\left[\sum_{i=0}^{n-1} f(t_i) \{W_{t_{i+1}}-W_{t_i}\}ight] = \sum_{i=0}^{n-1} f(t_i) E[W_{t_{i+1}}-W_{t_i}] = 0,$$

where we have used $E[W_{t_{i+1}}-W_{t_i}] = 0$, which is Brownian motion property (iii) in Section 2.1.
