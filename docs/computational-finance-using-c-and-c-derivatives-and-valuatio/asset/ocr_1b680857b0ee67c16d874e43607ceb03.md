(5.4.1) is approximated as

$r f_{i,j} = r \{\Theta_m f_{i+1,j} + (1 - \Theta_m) f_{i,j}\}$

and the term $\frac{\partial f}{\partial S}_{i,j}$ in equation (5.4.1) is approximated as

$$\frac{\partial f}{\partial S}_{i,j} = \{\Theta_m \frac{\partial f}{\partial S}_{i+1,j} + (1 - \Theta_m) \frac{\partial f}{\partial S}_{i,j}\}$\}$

Using this method, we obtain, at node (i, j), the following discretized version of equation (5.4.1):

$$\frac{f_{i+1,j} - f_{i,j}}{\Delta t} + (r - q)S_j \{\Theta_m^* f_{i+1,j} + \Theta_m^* f_{i,j}\}$ $

$$\frac{1}{2}\sigma^2S_j^2 \{\Theta_m^* f_{i+1,j} + \Theta_m^* f_{i,j}\} = r \{\Theta_m f_{i+1,j} + \Theta_m^* f_{i,j}\}$ (5.4.7)

where for compactness we have written $\Theta_m^* = 1 - \Theta_m$ and denote the partial derivatives with respect to S at node (i, j) as $f'_{i,j} = \frac{\partial f}{\partial S}_{i,j}$ and $f''_{i,j} = \frac{\partial^2 f}{\partial S^2}_{i,j}$.

Finite-difference approximations for these derivatives can be obtained by considering a Taylor expansion about the point $f_{ij}$. We obtain as follows:

$f_{i,j+1} = f_{i,j} + f'_{i,j}\Delta S + \frac{1}{2}f''_{i,j}(\Delta S)^2$, (5.4.8)

$f_{i,j-1} = f_{i,j} - f'_{i,j}\Delta S - \frac{1}{2}f''_{i,j}(\Delta S)^2$. (5.4.9)

Subtracting equation (5.4.9) from equation (5.4.8), we obtain

$f_{i,j+1} - f_{i,j-1} = 2f'_{i,j}\Delta S$

and so

$f'_{i,j} = \frac{f_{i,j+1} - f_{i,j-1}}{2\Delta S}$. (5.4.10)

Adding equation (5.4.9) and equation (5.4.8), we obtain

$f_{i,j+1} + f_{i,j-1} = 2f_{i,j} + f''_{i,j}\Delta S^2$,

which gives

$f''_{i,j} = \frac{f_{i,j+1} - 2f_{i,j} + f_{i,j-1}}{\Delta S^2}$

The complete finite-difference approximation to the Black-Scholes equation can be found by substituting the approximations for the first and second partial derivatives, given in equation (5.4.10) and equation (5.4.11), into equation (5.4.7). We obtain

$r\Delta t \Theta_m f_{i+1,j} + \Theta_m^* f_{i,j} = f_{i,j+1} - f_{i,j} - \frac{(r-q)S_j\Delta t}{2} + \frac{\sigma^2 S_j^2 \Delta t^2}{2}$, (5.4.12)
