where $c(S^*, E, \tau_1)$ is the Black-Scholes value of a European call option with strike price $S^*$ and maturity $\tau_1 = T - t_1$, on an asset with current value $S^*$ at time $t_1$. If just before the ex-dividend date $S_{t_1} > S^*$, the American option will be exercised and realize a payoff of $S_{t_1} + D_1 - E$. On the other hand, if $S_{t_1} \le S^*$, the option is worth worthless and will be held until maturity at $T$.

We can rewrite (5.2.2) so that $S^*$ is the root of the following equation:

```
$K(S^*) = c(S^*, E, \tau_1) - S^* - D_1 + E,$$
```

Where $K(S^*)$ denotes the function of solving equation the single variable $S^*$. A well-known technique for solving equation (5.2.3) is Newton's method, in which this case takes the

```
$S^*_{i+1} = S^*_i - \frac{K(S^*_i)}{K'(S^*_i)},$$
```

where $S^*_i$ is the $i$th approximation to $S^*$ and $S^*_{i+1}$ is the improved $(i+1)$th approximation.

If we now consider the terms in equation (5.2.4), we have from equation (5.2.2) and equation (5.2.3) that

```
$K(S^*_i) = c(S^*_i, E, \tau_1) - S^*_i - D_1 + E$
```

and

```
$K'(S^*_i) = \frac{\partial K(S^*_i)}{\partial S^*_i} = \frac{\partial c(S^*_i, E, \tau_1)}{\partial S^*_i} - 1.
```

Also from equation (A.1.4) in Appendix A.3

```
$\frac{\partial c(S^*_i, E, \tau_1)}{\partial S^*_i} = N_1(d_1(S^*_i)),$
```

we note here that the continuous dividend yield, $q=0$. So

```
$K'(S^*_i) = \frac{\partial K(S^*_i)}{\partial S^*_i} = N_1(d_1(S^*_i)) - 1, \text{ where } d_1 = \frac{\log(S^*/E) + (r + \sigma^2/2)\tau_1}{\sigma\sqrt{T-t_1}}.$
```

Substituting these results into equation (5.2.4) gives

```
$S^*_{i+1} = S^*_i - \frac{c(S^*_i, E, \tau_1) - (S^*_i + D_1 - E)}{N_1(d_1(S^*_i)) - 1},$$
```

Rearrangement, this that yields

```
$S_{t+1}^* = S_t^* N_1(d_1(S_t^*)) - c(S_t^*, E, \tau) + D_1 - E N_1(d_1(S_t^*) - 1) \quad \text{for } i = 0, \dots, \text{max\_iter}, \text{ (5.2.5)}$
```

where a convenient initial approximation is to choose $S_0^* = E$, and $\text{max\_iter}$ is the maximum number of iterations that are to be used.

We will quote the Roll, Geske, and Whaley (1981) formula for the value of an American call which pays a single dividend $D_1$ at time $t_1$, it is

```
$C(S, E, \tau) = S_D N_1(b_1) + N_2(a_1, -b_1, \sqrt{(t_1 - \tau)/\tau}) + D_1 \exp(-r(t_1 - \tau)) N_1(b_2) - E \exp(-r\tau) N_2(a_2, -b_2, \sqrt{(t_1 - \tau)/\tau}) \quad \text{ (5.2.6)}$$
```

where $S_D$ is given by equation (5.2.1), $E$ is the exercise price, $t$ is the option expiry date, $\tau$ is the option maturity, $N(a)$ is the univariate cumulative density function with upper integral limit $a$, and $N_2(a, b, \rho)$ is the bivariate cumulative density function with upper integral limits $a$ and $b$ and correlation coefficient $\rho$. The other symbols used in equation (5.2.6) are defined as

```
$a_1 = \frac{\log(S/E) + \sigma^2/2\tau}{\sigma\sqrt{\tau}}, \quad a_2 = a_1 - \sigma\sqrt{\tau}, \\
b_2 = \frac{\log(S/S^*) + \sigma^2/2(t_1 - t)}{\sigma\sqrt{(t_1 - t)}}, \quad b_2 = b_1 - \sigma\sqrt{(t_1 - t)},
```

and $S$ is the current (time) asset price, $S^*$ is given by equation (5.2.5), $r$ is the riskless interest rate, $\sigma$ is the asset's volatility, $\tau = T - t$, and $\tau_1 = T - t_1$.

To compute the value of an American call which pays $n$ dividends $D_i, i = 1, \dots, n$ at times $t_i = 1, \dots, n$, we can use the fact that optimal exercise normally only occurs over the final ex-dividend date $t_n$, see, for example, Hull (2003). Under these circumstances, equation (5.2.6) can still be shown to be the value of the American call but now $t_1$ should be set to $t_n$, $D_1$ should be set to $D_n$, and $S_D$ is given by

```
$S_D = S - \sum_{i=1}^{n} D_i \exp(-r(t_i - t)). \quad \text{ (5.2.7)}$
```
