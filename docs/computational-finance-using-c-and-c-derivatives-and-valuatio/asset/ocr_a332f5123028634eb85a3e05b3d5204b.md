# C.5 MOMENT GENERATING FUNCTIONS

If $x$ is a random variable with probability distribution $f_x(x)$, then the moment generating function $M_x(t)$ is defined by

```
$$$M_x(t) = E[e^{tx}] = \int_{-\infty}^{\infty} e^{tx} f_x(x)dx.$$$
```

We can expand the following expression as:

```
$$$E[e^{tx}] = E[1 + tx + \frac{1}{2}(tx)^2 + ...].$$
```

```
$$$M_x(t) = 1 + tE[x] + \frac{1}{2}t^2E[x^2] + .. \quad (C.5.1)$$$
```

Now

```
$$$\frac{d^k(M_x(t))}{dt^k} = \frac{d^k}{dt^k}\{E[e^{tx}]\} = E[\frac{d^k}{dt^k}e^{tx}] = E[x^k e^{tx}].$$
```

For $t = 0$, we have

```
$$$\frac{d^k(M_x(t))}{dt^k}|_{t=0} = \frac{d^k(M_x(0))}{dt^k} = E[x^ke^0] = E[x^k]. \quad (C.5.2)$$$
```
