# H.8 PROOF OF EQUATION (H.1.9)

We start with

$$P(m_t^x \ge b) = 1 - P(m_t^x \le b)$.$

Substituting from (H.1.8),

$$P(m_t^x \ge b) = 1 - N_1\left(\frac{b-vt}{\sigma\sqrt{t}}\right) + \exp\left(\frac{2vb}{\sigma^2}\right) N_1\left(\frac{b+vt}{\sigma\sqrt{t}}\right) \quad (H.8.1)$

But $1 - N_1(x) = N_1(-x)$, equation (H.8.1) can be expressed as

$$P(m_t^x \ge b) = N_1\left(\frac{vt-b}{\sigma\sqrt{t}}\right) + \exp\left(\frac{2vb}{\sigma^2}\right) N_1\left(\frac{b+vt}{\sigma\sqrt{t}}\right)$
