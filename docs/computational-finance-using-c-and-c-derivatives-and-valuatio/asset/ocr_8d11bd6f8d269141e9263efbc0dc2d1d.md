Then mean E[Z] = E[a] + E[b_1X_1] + E[b_2X_2] + E[b_3X_3] = a + b_1E[X_1] + b_2E[X_2] + b_3E[X_3].

The Var[Z] is computed as:

```
Var[Z] = E[{a + b_1X_1 + b_2X_2 + b_3X_3 - a - b_1E[X_1] - b_2E[X_2] - b_3E[X_3]]^2}
= E[{b_1(X_1 - E[X_1]) + b_2(X_2 - E[X_2]) + b_3(X_3 - E[X_3])}^2]
= b_1^2E[(X_1 - E[X_1])^2] + b_2^2E[(X_2 - E[X_2])^2] + b_3^2E[(X_3 - E[X_3])^2]
+ 2b_1b_2E[(X_1 - E[X_1])(X_2 - E[X_2])]
+ 2b_1b_3E[(X_1 - E[X_1])(X_3 - E[X_3])]
+ 2b_2b_3E[(X_2 - E[X_2])(X_3 - E[X_3])]
= b_1^2Var[X_1] + b_2^2Var[X_2] + b_3^2Var[X_3] + 2b_1b_2Cov[X_2,X_1] + 2b_1b_3Cov[X_1,X_3] + 2b_2b_3Cov[X_2,X_3].
```

If X_1, X_2, and X_3 are IID, all the covariance terms are zero and the variance is

```
Var[Z] = b_1^2Var[X_1] + b_2^2Var[X_2] + b_3^2Var[X_3].
```

# Variance of n Variables

We now derive an expression for the sum of n IID random variables.

Let Z = a + \sum_{i=1}^n b_iX_i, where a and b_i, i = 1 . . . n are constants.

Then we have E[Z] = E[a] + E[\sum_{i=1}^n b_iX_i] = a + \sum_{i=1}^n b_iE[X_i] and

```
Var[Z] = E{{\sum_{i=1}^n b_iX_i - a - \sum_{i=1}^n b_iE[X_i]}^2}
= E{{\sum_{i=1}^n b_iX_i - \sum_{i=1}^n b_iE[X_i]}^2}
= E{{\sum_{i=1}^n b_i(X_i - E[X_i])}^2}
= \sum_{i=1}^n b_i^2E[(X_i - E[X_i])^2] + \sum_{i=1}^n \sum_{j=1(j\neq i)}^n b_i b_jE[(X_i - E[X_i])(X_j - E[X_j])}
= \sum_{i=1}^n b_i^2Var[X_i] + \sum_{i=1}^n \sum_{j=1(j\neq i)}^n b_i b_jCov[X_i,X_j].
```
