# The Boundary Conditions

In order to solve (5.4.14) at time instant $j\Delta t$, we need to obtain the option values at the upper asset boundary, the lower asset boundary, and the initial values that are specified at option maturity.
nHere, we calculate the boundary values using the time independent payoff, $p_j$, at the $j$th asset index within the grid. If $E$ is the strike price, then vanilla call options have payoffs

```
$p_j = max(j\Delta S - E), \quad j = 0, \dots, n_{s-1}$
```

and vanilla put options have payoffs

```
$p_j = max(E - j\Delta S), \quad j = 0, \dots, n_{s-1}$
```

**Upper asset boundary values**
At the upper boundary, $j = n_s - 1$ and $(n_s - 1)\Delta S = S_{max}$, where we note that for the grid to be useful, we require $S_{max} > E$.
Here, we observe that $S_{max} > E$ so for call options

```
$p_{n_{s-1}} = S_{max} - E,$
```

and for put options

```
$p_{n_{s-1}} = 0.$
```

The option value at the upper boundary, denoted by $f_{BU}$, is set to $p_{n_{s-1}}$, and we have $f_{i,n_{s-1}}=f_{BU}, i = 0, \dots, n_t$.
**Lower asset boundary values**
At the lower boundary, $j = 0$ and the value of $j\Delta S$ is zero.
So for call options

```
$p_0 = 0,$
```

and for put options
The option value at the lower boundary, denoted by $f_{BL}$, is set to $p_0$, and we have $f_{i,0}=f_{BL}, i = 0, \dots, n_t$.
**Boundary values at option maturity**

```
$p_0 = E.$
```

At option maturity ($i = n_t$), the initial option (boundary) values are the previously mentioned factors. If $E$ is the strike price, then for vanilla call options,

```
$f_{n_t,j} = max(j\Delta S - E), \quad j = 0, \dots, n_{s-1}$.
```
