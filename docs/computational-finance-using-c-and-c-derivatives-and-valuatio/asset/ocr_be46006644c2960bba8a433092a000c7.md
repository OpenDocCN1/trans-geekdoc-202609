$f(b \leq X_s^{min}, X) = -\Omega \sqrt{\frac{2}{\pi}} \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) \exp\left(-\frac{(X-(r-q-\sigma^2/2)	au)^2}{2\sigma^2	au}ight) \quad \quad (4.5.6)$
```

where $r$ is the risk free rate and $q$ is the continuous dividend yield. A European down and out option with maturity $	au$ and a barrier at $X=B$ will cease to exist (become worthless) if at any time $X_s \leq B$, for $t \leq s \leq T$. The probability density function that the barrier option will continue to exist at time $T$ if the price $X$ is

```
$f(X > B) = -\sqrt{\frac{2}{\pi}} \int_{B=S\exp(b)}^{b=X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) \exp\left(-\frac{(X-(r-q-\sigma^2/2)	au)^2}{2\sigma^2	au}ight) db \ \quad \quad (4.5.7)$
```

or

```
$f(X > B) = -\sqrt{\frac{2}{\pi}} \exp\left(-\frac{(X-(r-q-\sigma^2/2)	au)^2}{2\sigma^2	au}ight) \int_{b=\log(B/S)}^{b=X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) db \ \quad \quad (4.5.8)$
```

where we have integrated over all possible values of $b$ (i.e., $B < b < X$) that keep the option alive. Recalling that we

```
$\int_{b=\log(B/S)}^{b=X} \Omega \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) db = \exp\left(\frac{(X-2b)}{\sigma^2	au}ight) \exp\left(\frac{2(X-b)}{\sigma^3\sqrt{	au}}ight)$
```

and that

```
$\frac{\partial}{\partial b} \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) = \frac{2(X-2b)}{\sigma^2	au} \exp\left(\frac{2(X-b)}{\sigma^2	au}ight)$,
```

we have

```
$\int_{b=\log(B/S)}^{b=X} \exp\left(\frac{2(X-b)}{\sigma^2	au}ight) db = \left[\exp\left(\frac{2(X-b)}{\sigma^2	au}ight)ight]_{b=\log(B/S)}^{b=X} \ \quad = \left\{1 - \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2	au}ight)ight\}$,
```

So we have

```
$f(X > B) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(X-(r-q-\sigma^2/2)	au)^2}{2\sigma^2	au}ight) \ \times \left\{1 - \exp\left(\frac{2\log(B/S)(X-\log(B/S))}{\sigma^2	au}ight)ight\}$,
