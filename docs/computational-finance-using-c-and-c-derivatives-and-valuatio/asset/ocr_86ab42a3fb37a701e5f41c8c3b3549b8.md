Let us now consider a portfolio consisting of -1 derivative and $\partial f/\partial S$ units of the underlying stock. In other words, we have gone short (that is) sold a derivative on an asset and have $\partial f/\partial S$ stocks of the (same) underlying asset. The value of the portfolio, $\Pi$, is therefore

```
$$\Pi = -f + \frac{\partial f}{\partial S}S,$$ (4.4.3)
```

and the change, $\Delta\Pi$, in the value of the portfolio over time $\Delta t$ is

```
$$\Delta\Pi = -\Delta f + \frac{\partial f}{\partial S}\Delta S,$ (4.4.4)
```

Substituting equation(4.4.1) and equation(4.4.2) into equation(4.4.4), we obtain

```
$$\Delta\Pi = -(\mu S\frac{\partial f}{\partial t}\Delta t + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\Delta t - \sigma S\Delta W)\frac{\partial f}{\partial S} + (\mu S + \sigma S\Delta t)\frac{\partial f}{\partial S},\$
.: \Delta\Pi = -\mu S\frac{\partial f}{\partial S}\Delta t - \frac{\partial f}{\partial t}\Delta t - \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}\Delta t - \sigma S\Delta W\frac{\partial f}{\partial S} + \mu S\Delta t\frac{\partial f}{\partial S} + \sigma S\Delta t\frac{\partial f}{\partial S};$ (4.4.5)
```

Cancelling the terms, we obtain

```
$$\Delta\Pi = -\Delta t(\frac{\partial f}{\partial t} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}),$ (4.4.6)
```

If this portfolio is to grow at the riskless interest rate, $r$, we have

```
$$\r\Pi\Delta t = \Delta\Pi.$
```

We so have that

```
$$\r\Pi\Delta t = -\Delta t(\frac{\partial f}{\partial t} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}),$ (4.4.7)
```

Substituting for $\Pi$ and we obtain

```
$$\r\Delta t = (f - S\frac{\partial f}{\partial S}) = -\Delta t(\frac{\partial f}{\partial t} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2}),$ (4.4.8)
```

On rearranging, we have

```
$$\frac{\partial f}{\partial t} + S\frac{\partial f}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 f}{\partial S^2} = rf,$$ (4.4.9)
```

which is the Black–Scholes partial differential equation.
