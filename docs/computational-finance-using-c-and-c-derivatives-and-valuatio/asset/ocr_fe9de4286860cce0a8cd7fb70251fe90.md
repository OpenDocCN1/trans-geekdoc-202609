where it can be seen that L and U are bipolar. Once the decomposition of A has been found, it is possible to solve for x in equation (5.49.29) using a two-stage method (for example, Golub and Van Loan (1989)). Here, forward elimination is used to solve $L_Y = \mathcal{R}$, and back-substitution is applied to $Ux = y$. We can then write the procedure as

```
Ax = (LU)x = L(Ux) = Ly = \mathcal{R}.
```
