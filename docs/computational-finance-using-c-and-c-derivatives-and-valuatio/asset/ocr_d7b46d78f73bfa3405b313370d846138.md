# C.3.3 Covariance Matrix

Let X denote the n element vector containing the random $X_i,i = 1.\dots,n$. The mean and variance of the $ith$ varie are $E[X_i]$ and $E[(X_i - E[X_i])^2]$ respectively. The covariance $Cov[X]_{ij}$ between the $ith$ and $jth$ variables are $E[(X_i - E[X_i])(X_j - E[X_j])]$. The elements of $n$ by $n$ covariance matrix $Cov[X]$ are

```
$Cov[(X_i - E[X_i])(X_j - E[X_j])], \quad i=1,\dots,n,j=1,\dots,n.\\n(C.3.1)
```

We will now show that $Cov[X+A] = Cov[X]$ where $A$ is an n element vector containing the constants $A_i,i=1,\dots,n$. Since $E[X_i + A_i] = E[X_i] + A_i$, we obtain

```
$Var[(X+A_i)] = Var[X_i+A_i]$\n$E = E[(X_i+A_i-E[X_i+A_i])^2] = E[(X_i-E[X_i])^2]$
```

and

```
$Cov[X+A]_{ij} = E[(X_i+A_i-E[X_i+A_i])(X_j+A_j-E[X_j+A_j])$\n$E = E[(X_i-E[X_i])(X_j-E[X_j])$\n$Cov[X]_{ij}.\\\n(C.3.2)
```
