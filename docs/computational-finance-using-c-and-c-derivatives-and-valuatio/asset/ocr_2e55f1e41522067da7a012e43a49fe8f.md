# 5.2.2 The Macmillan, Barone-Adesi, and Whaley Method

Here, we consider a method of pricing American options which relies on an approximation that reduces a transformed Black–Scholes equation into a second order differential equation, by Barone–Adesi and Whaley (1987), and MacMillan (1986). It provides an alternative way of evaluating American options that could be used instead of computationally intensive techniques as finite-difference methods. Although the method prices American options, it is really based on the value of an American option relative to the European option value (which can readily be computed using the Black–Scholes pricing formula).

Since an American option gives more choice, its value is always at risk of its European counterpart. This early exercise premium $\nu(S,E,\tau)\geq 0$ is now defined more precisely for American puts and calls. If current time $t$ the asset price is $S$, then the early exercise premium for an American call which expires at $T$ and has maturity $\tau=T-t$, is

```
$\nu(S,E,\tau)=C(S,E,\tau)-c(S,E,\tau)\geq 0\quad (5.2.8)
```

$C(S,E,\tau)$ denotes the value of the American call and $c(S,E,\tau)$ denotes the value of the European call. The early exercise premium of an American put, $\nu_p(S,E,\tau)$, is similarly defined as

```
$\nu_p(S,E,\tau)=P(S,E,\tau)-p(S,E,\tau)\geq 0\quad (5.2.9)
```

where $P(S,E,\tau)$ is the value of the American put, and $p(S,E,\tau)$ is the value of the European put. The key insight provided by the Macmillan, Barone–Adesi, and Whaley method is that since both the American and European options satisfy the Black–Scholes partial differential equation does the early exercise premium, $\nu(S,E,\tau)$, see Section 4.4.1. Which we can write

```
$\frac{\partial\nu}{\partial t} + (r-q)S\frac{\partial\nu}{\partial S} + \frac{1}{2}\sigma^2S^2\frac{\partial^2\nu}{\partial S^2}=rv\quad (5.2.10)
```

as usual $S$ is the asset price, $r$ the continuously compounded interest rate, $q$ the volatility dividend, and $t$ increases from the current time to the expiry time $T$.

We will now introduce the function $h(\tau)=1-\exp(-	au)$ and use the factorization $\nu(S,E,\tau)=h(\tau)g(S,E,\tau)$. From the standard calculus, we obtain

```
$\frac{\partial\nu}{\partial t}=g\frac{\partial h}{\partial t}+h\frac{\partial g}{\partial t}=rg(h-1)+h\frac{\partial g}{\partial t}=rg(h-1)+hr(h-1)\frac{\partial g}{\partial h}$
```

```
$\frac{\partial\nu}{\partial S}=h\frac{\partial g}{\partial S}\text{ and }\frac{\partial^2\nu}{\partial S^2}=h\frac{\partial^2 g}{\partial S^2}$.
```
