When a uniform grid is used, $\Delta Z_j^* = \Delta Z = \Delta Z$, and therefore,

```
$D = (\Delta Z_j^*)^2 \Delta Z + (\Delta Z_j^*)^2 \Delta Z^2 = 2(\Delta Z)^3,$
```

```
$$\frac{(\Delta Z_j^*)^2}{D} = \frac{(\Delta Z)^2}{D} = \frac{1}{2(\Delta Z)^3}$
```

```
$$\frac{\Delta Z_j^*}{D} = \frac{\Delta Z}{D} = \frac{1}{2\Delta Z^2} \text{ and } \frac{(\Delta Z_j^*)^2 - (\Delta Z)^2}{D} = 0.$
```

In these circumstances,
