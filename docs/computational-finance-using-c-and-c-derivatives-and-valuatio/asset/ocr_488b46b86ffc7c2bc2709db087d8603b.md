# 2.8 THE BROWNIAN BRIDGE

Let a Brownian process have values $W_{t0}$ at time $t0$ and $W_{t1}$ at time $t1$. We want to find the conditional distribution of $W_{t}$, where $t0 < t < t1$. This distribution will be denoted by $P(W|{W_{t0}, W_{t1}})$ to indicate that $W$ is conditional on the end values $W_{t0}$ and $W_{t1}$. We now write $W_{t}$ and $W_{t1}$ as

$W_{t} = W_{t0} + \sqrt{(t-t0)}X_{t}, \quad X_{t} \sim N(0,1), (2.8.1)$

$W_{t1} = W_{t0} + \sqrt{(t1-t)}Y_{t}, \quad Y_{t} \sim N(0,1), (2.8.2)$

where $X_{t}$ and $Y_{t}$ are independent normal variables. Combining equation (2.8.1) and equation (2.8.2), we have

which can be re-expressed as

$W_{t1} - W_{t0} = \sqrt{(t-t0)}X_{t} + \sqrt{(t1-t)}Y_{t}$.

Using the Brownian motion property (iii) in Section 2.1,

$W_{t1} - W_{t0} = \sqrt{(t1-t0)}Z_{t}, \quad Z_{t} \sim N(0,1)$.

So

$\sqrt{(t1-t0)}Z_{t} = \sqrt{(t-t0)}X_{t} + \sqrt{(t1-t)}Y_{t}$

and

$Y(X_{t},Z_{t}) = \frac{\sqrt{(t1-t0)}Z_{t} - \sqrt{(t-t0)}X_{t}}{\sqrt{(t1-t)}} (2.8.3)$

Now $P(W_{t}|{W_{t0},W_{t1}} ) = P(X_{t}|Z_{t})$, the probability distribution of $X_{t}$ conditional on $Z_{t}$. By Bayes law,

$P(X_{t}|Z_{t}) = \frac{P(X_{t})P(X_{t},Z_{t})}{P(Z_{t})} = \frac{1}{\sqrt{2\pi}} \exp\left{-\frac{(X_{t}^{2}+Y_{t}^{2}-Z_{t}^{2})}{2}\right). (2.8.4)$

Since $X_{t}$, $Y_{t}$, and $Z_{t}$, are Gaussian, we can write

$P(X_{t}|Z_{t}) = \frac{1}{\sqrt{2\pi}} \exp\left{-\frac{(X_{t}^{2}+Y_{t}^{2}-Z_{t}^{2})}{2}\right). (2.8.5)$
