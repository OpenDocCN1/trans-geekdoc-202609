So in the risk-neutral measure Q, the dynamics of $dS$ are

```
$dS_t = S_t r dt + S_t \sigma dW_t. \quad (4.4.31)
```

Comparing equation (4.4.31) with the original equation in (4.4.26), we see that changing from the real world to the risk-neutral measure simply substituting $dW^Q$ for $dW^P$ and $r$ for $\mu$.

We can now solve equation (4.4.31) by using the result given in equation (2.3.11). We have

```
$S_T = S \exp(r(T-t_0) + \sigma W^Q_{T-t_0}),$
```

where $S$ is the asset price at current time $t_0$, and $r = -\sigma^2/2$. From Appendix D.2, we have

```
$S(t_0, T) = E[S_T] = S \exp(r(T-t_0)). \quad (4.4.32)
```

Using equation (2.3.9), the distribution of the asset price at time $T$ is

```
$\log(\frac{S_T}{S}) \sim N(r(T-t_0), \sigma^2(T-t_0)). \quad (4.4.33)
```

We want to obtain the price of a vanilla European option with strike price $E$ which matures at future time $T=T-t_0$. The approach we will adopt is to first derive an expression for the value of a European call option and then use the put/call relationships of Section 2.2 to obtain the value of the corresponding European put option.

Referring to (4.2.1), we have

```
$V_t = B_{t_0} E^Q[\frac{H_T}{B_T}] = \frac{B_{t_0}}{B_T} E^Q[H_T]. \quad (4.4.34)
```

Substituting $B_{t_0}=1, B_T=\exp(r(T-t_0)) = \exp(r\tau)$, and $H_T=\max(S_T-E, 0)$, we obtain

```
$V_t = \frac{1}{\exp(r\tau)} E^Q[\max(S_T-E, 0)], \quad (4.4.35)
```

and so denoting the value of the call by $c(S,E,\tau)$

```
$c(S,E,\tau) = \exp(-r\tau) E^Q[\max(S_T-E, 0)]. \quad (4.4.36)
```

It can be seen from (4.4.36) that the value of the European call option is the expected value of the option's payoff at maturity, discounted to current time $t$ by the risk interest rate $r$.

This means that the value of the call can be written as

```
$c(S,E,\tau) = \exp(-r\tau) \int_{S_T=E}^{\infty} f(S_T)(S_T-E)dS_T, \quad (4.4.37)
```

where $(S_T)$ is the probability density function of $S_T$.
