# Relation to the Brownian Bridge

We will now prove that in the limit $(t_1-t_0) \to 0$ the Brownian bridge result is obtained.

For the conditional mean, we have

$$\mu = X_{t_0} \exp(-\alpha(t-t_0)) \left\{ \frac{1-\exp(-2\alpha(t_1-t_0))}{(1-\gamma^2)} \right\} + X_{t_1} \exp(-\alpha(t_1-t_0)) \left\{ \frac{1-\exp(-2\alpha(t-t_0))}{(1-\gamma^2)} \right\}$$

where

$$\gamma = \exp(-\alpha(t_1-t_0)),$$

which is

$$\mu = X_{t_0} \left\{ \frac{\exp(-\alpha(t-t_0))\exp(-2\alpha(t_1-t_0))}{(1-\exp(-2\alpha(t_1-t_0))-\exp(-2\alpha(t-t_0)))} \right\} + X_{t_1} \left\{ \frac{\exp(-\alpha(t_1-t_0))\exp(-2\alpha(t-t_0))-\alpha(t_1-t_0))}{(1-\exp(-2\alpha(t_1-t_0)))} \right\}$$

For small $(t_1-t_0)$, both $(t_1-t_0)$ and $t$ are small, so

$$\mu \to X_{t_0} \left\{ \frac{1-\exp(-2\alpha(t_1-t_0))-\alpha(t_1-t_0)}{1-\exp(-2\alpha(t_1-t_0))} \right\} + X_{t_1} \left\{ \frac{1-\exp(-2\alpha(t-t_0))-\alpha(t_1-t_0)}{1-\exp(-2\alpha(t_1-t_0))} \right\}$$

which yields the Brownian bridge result for the conditional mean

$$\mu \to X_{t_0} \frac{(t_1-t_0)}{(t_1-t_0)} + X_{t_1} \frac{(t-t_0)}{(t_1-t_0)}$$

For the conditional variance,

$$V_t = \frac{(1-\exp(-2\alpha(t-t_0)))(1-\exp(-2\alpha(t_1-t_0)))}{2\alpha(1-\exp(-2\alpha(t_1-t_0)))}$$

For small $(t_1-t_0)$, both $(t_1-t_0)$ and $t$ are small, so we see

$$V \to \frac{(1-\exp(-2\alpha(t-t_0)))(1-\exp(-2\alpha(t_1-t_0)))}{2\alpha(1-\exp(-2\alpha(t_1-t_0)))}$$

which yields the Brownian bridge result for the conditional variance

$$V_t \rightarrow \frac{(t-t_0)(t_1-t)}{(t_1-t_0)}$$

# 2.12 OTHER USEFUL RESULTS

## 2.12.1 Fubini's Theorem

Fubini's theorem states that (for well-behaved functions) the value of a multidimensional integral is independent of the order in which the integral is evaluated. For example, the two-dimensional integral of the function $f(X,Y)$ can be evaluated as

$$\int_a^b \int_c^d f(X,Y)dYdX = \int_a^b \int_c^d f(X,Y)dX = \int_c^d \int_a^b f(X,Y)dY.$$

We will mainly use this result in the form

$$\left[\int_0^t f(W,s)ds\right] = \int_0^t E[f(W,s)]ds.$$

Since $P(W,s)$ is the probability density function of $f(W,s)$, we can then use equation (2.12.1) in full

$$\int_{-\infty}^{\infty} \int_0^t P(W,s)ds = \int_0^t \int_{-\infty}^{\infty} P(W,s)dW.$$

## 2.12.2 Ito's Isometry

The expected value of the integral of the well-behaved function $f(W_t,t)$ satisfies

$$\left[\int_a^b f(W_s,s)dW_s\right]^2 = \left[\int_a^b \{f(W_s,s)\}^2 ds\right]. \quad (2.12.2)$$

where $t_a = t_0 < t_1 < \dots < t_b, t_{i+1}-t_i = (t_b-t_a)/n$, and $t_i = t_a + id, i = 0,\dots,n-1$. The integral on the left-hand side (LHS) of equation (2.12.2) is

$$\left(\int_a^b f(W_s,s)dW_s\right)^2 = \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j) (W_{t_{i+1}}-W_{t_i})(W_{t_{j+1}}-W_{t_j})$$

(2.12.3)

Taking expectations of equation (2.12.3), we obtain

$$E\left[\int_a^b f(W_s,s)dW_s\right)^2] = E\left[\sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_i) f(W_{t_j}, t_j) (W_{t_{i+1}}-W_{t_i})(W_{t_{j+1}}-W_{t_j})\right]$$

(2.12.4)

which means

$$E\left[\int_a^b f(W_s,s)dW_s\right)^2] = \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} f(W_{t_i}, t_j) E\left[(W_{t_{i+1}}-W_{t_i})(W_{t_{j+1}}-W_{t_j})\right]$$

(2.12.5)

Here from the Brownian motion property (iii) in Section 2.1, we have

$$E\left[(W_{t_{i+1}}-W_{t_i})(W_{t_{j+1}}-W_{t_j})\right] = 0 \quad \text{when } i \neq j \text{ and when } i = j.$$

Therefore, equation (2.12.5) can be rewritten as

$$E\left[\int_a^b f(W_s,s)dW_s\right)^2] = \sum_{i=0}^{n-1} \{f(W_{t_i}, t_i)\}^2 dt.$$

which means

$$E\left[\int_a^b f(W_s,s)dW_s\right)^2] = E\left[\int_a^b \{f(W_s,s)\}^2 ds\right]$$

## 2.12.3 Expectation of a Stochastic Integral

If $f(t)$ is a deterministic function of time, then

$$E\left[\int_a^b f(s)dW_s\right] = 0. \quad (2.12.6)$$

Proof. We first express the integral (2.12.6) by the following summation:

$$\int_a^b f(s)dW_s = \sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}}-W_{t_i}), \quad \text{where } a = t_0 < t_1 < \dots < t_n = b.$$

Taking expectations of the above equation yields

$$E\left[\int_a^b f(s)dW_s\right] = E\left[\sum_{i=0}^{n-1} f(t_i)(W_{t_{i+1}}-W_{t_i})\right] = \sum_{i=0}^{n-1} f(t_i) E[W_{t_{i+1}}-W_{t_i}] = 0,$$

where we have used $E[W_{t_{i+1}}-W_{t_i}] = 0$, which is Brownian motion property (iii) in Section 2.1.

# 2.13 EXERCISES

In this section, we provide various problems which test the readers understanding of stochastic calculus.

- **Problem 1 (Problem 4.5, Øksendal (2003)).** Let $W_t^k, t \geq 0$, where $W_0=0$.
    - (a) Using Ito's formula for $k=2,3,\dots$, that $W_t^k = \frac{1}{2}\int_0^t k W_s^{k-1} ds$.
    - (b) Deduce that $E[W_t^k] = 0$.
    - (c) What is $E[W_t^4]$?

- **Problem 2 (Problem 5.4 (ii), Øksendal (2003)).** Solve the stochastic equation $dX_t = X_t + dW_t$.

- **Problem 3 (Problem 5.4 (iii), Øksendal (2003)).** Solve the stochastic equation $dX_t = -X_t + dW_t$.

- **Problem 4 (Problem 4.2, Øksendal (2003)).** Use Ito's formula to prove that $\int_0^t W_s^2 dW_s = \frac{1}{3}W_t^3 - \int_0^t W_s ds$, where $W_0=0$.

- **Problem 5 (Problem 5.6, Øksendal (2003)).** Solve $dY_t = r dt + \alpha Y_t dW_t$, where $r$ and $\alpha$ are real constants. Use the integrating factor $F_t = \exp[-\alpha W_t + (\alpha^2/2)t]$.

- **Problem 6 (Problem 5.7, Øksendal (2003)).** The mean reverting Ornstein-Uhlenbeck process is the solution $X_t$ of the stochastic equation $dX_t = (m - X_t)dt + \sigma dW_t$, where $m$ and $\sigma$ are constants.
    - (a) Solve this equation.
    - (b) Find $E[X_t]$ and $Var[X_t] = E[X_t - E[X_t]]^2$.

- **Problem 7.** Consider the equation $dS_t = \mu_t S_t dt + \sigma_t S_t dW_t$, where the value $S_t$ at time $t=0$ is denoted by $S_0$.
    - (a) Show that this means $E[\log(S_t)] = \log(S_0) + \int_0^t (\mu_s - \frac{\sigma_s^2}{2}) ds$.
    - (b) Show that the variance is $Var[\log(S_t)] = \int_0^t \sigma_s^2 ds$.

- **Problem 8.** Prove that $\phi = \exp(tW_t)$, then $d\phi = \phi(W_t + \frac{t^2}{2})dt + t\phi dW_t$.

- **Problem 9 (Problem 4.4, Øksendal (2003)).** Define $Z_t = \exp(\int_0^t \theta_s dW_s - \frac{1}{2}\int_0^t \theta_s^2 ds)$.
    - (a) Use Ito's formula to prove $dZ_t = Z_t \theta_t dW_t$.

- **Problem 10.** Let $S_t = S_0 \exp(\mu t + \sigma W_t)$, where $\mu$ and $\sigma$ are constants.
    - (a) Show by Ito's lemma that $dS_t = (\mu + \frac{\sigma^2}{2})S_t dt + \sigma S_t dW_t$.
    - (b) Show that $E[S_t] - E[S_0] = (\mu + \frac{\sigma^2}{2})\int_0^t E[S_s] ds$.
    - (c) Show that $E[S_t] = S_0 \exp(\mu t + \frac{\sigma^2}{2}t)$.

- **Problem 11 (Problem 4.3, Øksendal (2003)).** Let $X_t, Y_t$ be stochastic processes. Prove that $d(X_t, Y_t) = X_t dY_t + Y_t dX_t + E[dX_t dY_t]$. Deduce the following general integration by parts formula:
$$\int_0^t X_s dY_s = X_t Y_t - X_{t_0} Y_{t_0} - \int_0^t Y_s dX_s - \int_0^t E[dX_s dY_s].$$$$
