where

```
$$\mathcal{K} = \frac{\Gamma((v+1)/2)(v-2)^{-\frac{1}{2}}h_i^{-\frac{1}{2}}}{\pi\Gamma(v/2)}$
```

we have

```
$E[\epsilon_i^2] = 2\mathcal{K} \int_{0}^{\infty} \frac{\epsilon_i^2 de_i}{(1+\epsilon_i^2/h_i(v-2))^{(v+1)/2}} = 2\mathcal{K}h_i(v-2)^{\frac{(v+1)}{2}} \int_{0}^{\infty} \frac{\epsilon_i^2 de_i}{(h_i(v-2)+\epsilon_i^2)^{(v+1)/2}}$
```

Using the standard integrals in Appendix E.1 with $a=2, b=2, c=(v+1)/2$, and $m=(v-2)h_i$ gives

```
$$\frac{m}{h_i}\frac{a+1-bc}{b} = \frac{(h_i(v-2))^{\frac{2-v}{2}}}{2}, \Gamma\left(\frac{a+1}{b}\right) = \Gamma(3/2),\n\Gamma\left(c-\frac{a+1}{b}\right) = \Gamma\left(\frac{v}{2}\right), \Gamma(c)=\Gamma\left(\frac{v+1}{2}\right)$
```

This gives

```
$E[\epsilon_i^2] = 2\mathcal{K}(h_i(v-2))^{\frac{2-v}{2}} \frac{\{(h_i(v-2))^{\frac{2-v}{2}}\sqrt{\pi}\Gamma((v-2))\}}{4\Gamma((v+1)/2)}$
```

Substituting for $\mathcal{K}$ and simplifying, we obtain

```
$E[\epsilon_i^2] = \frac{h_i(v-2)\Gamma((v-1)/2)}{\Gamma(v/2)}$
```

But

So

```
$$\Gamma\left(\frac{v-2}{2}\right)\Gamma\left(\frac{v-1}{2}\right) = \Gamma\left(\frac{v-1}{2}+1\right) = \Gamma\left(\frac{v}{2}\right)$
```

```
$E[\epsilon_i^2] = \frac{h_i(v-2)\Gamma(v/2)}{2(v-2)\Gamma(v/2)} = h_i.$
```

Similarly, we have

```
$E[\epsilon_i^2] = 2\mathcal{K} \int_{0}^{\infty} \frac{\epsilon_i^2 de_i}{(1+\epsilon_i^2/h_i(v-2))^{(v+1)/2}} = 2\mathcal{K}h_i(v-2)^{\frac{(v+1)}{2}} \int_{0}^{\infty} \frac{\epsilon_i^2 de_i}{(h_i(v-2)+\epsilon_i^2)^{(v+1)/2}}$
```

Using the standard integrals in Appendix E.1 with $a=4, b=2, c=(v+1)/2$, and $m=(v-2)h_i$ gives

```
$$\frac{m}{h_i}\frac{a+1-bc}{b} = \frac{(h_i(v-2))^{\frac{2-v}{2}}}{2}, \Gamma\left(\frac{a+1}{b}\right) = \Gamma(5/2),\n\Gamma\left(c-\frac{a+1}{b}\right) = \Gamma\left(\frac{v-4}{2}\right), \Gamma(c)=\Gamma\left(\frac{v+1}{2}\right)$
```
