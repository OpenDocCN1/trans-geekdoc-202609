Finally, we should mention that the control variant technique does not just apply to American vanilla options. The method is quite general and can be used to obtain improved estimates for any integral (or exotic option) so long as an accurate (closed form) solution of a similar method is known. One common use of the control variant method is to improve the Monte Carlo estimates.
