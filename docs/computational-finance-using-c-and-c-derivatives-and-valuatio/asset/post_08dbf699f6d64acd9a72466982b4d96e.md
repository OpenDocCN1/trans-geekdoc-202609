The attractive feature of the BEGKR binomial lattice model is that it can be easily generalized to describe a model consisting of $k$ assets. Here, we will merely quote the results in Kamrad and Ricken (1991). As it is assumed that the asset process follows a multivariate lognormal distribution. Let $\mu_i = r - \sigma_i^2/2$, and $\sigma_i$ be the instantaneous mean and variance respectively $(i=1, 2, \dots, k)$ and let $\rho_{ij}$ be the correlation between assets $i$ and $j$. The binomial model now requires $2^k$ possible jumps in the time interval $\Delta t$. Let $m$ denote the state of the process at $\Delta t$ with $p_m$ representing the probability of state $m$ ($m=1, \dots, 2^k$). The probabilities of these jumps are given by

$$p_m = \left\{1 + \Delta t \sum_{i=1}^k \frac{\mu_i}{\sigma_i} + \sum_{i=1}^k \sum_{j=i+1}^k (x_{ij}^* \rho_{ij})\right\}, m=1, 2, \dots, 2^k, k \ge 2,$$

where $x_{im}=1$ if asset $i$ has an up-jump in state $m$, and $x_{im}=-1$ if asset $i$ has a down-jump in state $m$. In addition, $x_{ij}^*=1$ if asset $i$ and asset $j$ jump in the same direction in state $m$, and $x_{ij}^*=-1$ if asset $i$ and asset $j$ jump in the opposite direction in state $m$.

## 6.5 TWO-ASSET OPTIONS

In this section, we consider options based on the underlying prices of two assets, $S_1$ and $S_2$. We give analytic formulae to price European exchange options and those based on the maximum or minimum of two assets. In addition, we show how to construct binomial latices for the valuation of two-asset American style options.

### 6.5.1 European Exchange Options

A European exchange option gives the holder the right to exchange one asset for another at maturity

$$dS_A^A = S_A^A \mu_A dt + S_A^A \sigma_A dW_A^A,$$
$$dS_B^B = S_B^B \mu_B dt + S_B^B \sigma_B dW_B^B.$$

where $S_A^A$ denotes the value of asset $A$ at time $t$ and $S_B^B$ denotes the value of asset $B$ at time $t$ - the other symbols have their obvious meanings.
We will now find the value, at time $t_0$, of an option which gives the holder the right to exchange asset $A$ for asset $B$ at maturity $T$. The payoff of maturity is $H_T = \max(S_B^B - S_A^A, 0)$.
If we use the value of asset $A$ as the numeraire, then from equation (4.2.1), the value of the exchange option at time $t_0$ is

$$V(t_0) = S_A^A E^Q \left[ \frac{\max(S_B^B - S_A^A, 0)}{S_T^A} \right]$$

which can be written as

$$V(t_0) = S_A^A E^Q \left[ \max\left(\frac{S_B^B}{S_T^A}-1\right) \right], \quad (6.5.1)$$

$\mathbb{Q}$ is the probability measure under which the relative price $(S_B^B/S_A^A)$ is a martingale.
The process $(S_B^B/S_A^A)$ can be found by substituting $X_1 = S_t^B$ and $X_2 = S_t^A$ into equation (2.6). Which yields

$$d\frac{S_B^B}{S_A^A} = \frac{S_B^B}{S_A^A} \left(\mu_B - \mu_A + \sigma_A^2 - \sigma_B\rho_{AB}\right)dt + \frac{S_B^B}{S_A^A} \left(\sigma_B dW_t^B - \sigma_A dW_t^A\right).$$

$\hat{X} = \sigma_B dW_t^B - \sigma_A dW_t^A$. $E[\hat{X}] = \sigma_B E[dW_t^B] - \sigma_A E[dW_t^A] = 0$ and $Var[\hat{X}] = \sigma_B^2 dt + \sigma_A^2 dt - 2\sigma_B\rho_{AB}dt$ where we use (see C.3)

$$Var[adW_1 + bdW_2] = a^2 Var[dW_1] + b^2 Var[dW_2] + 2ab Cov[dW_1, dW_2],$$
$Var[dW_t^B] = Var[dW_t^A] = dt$ and $Cov[dW_t^B, dW_t^A] = \rho_{AB}dt$, which means $\hat{X} \sim N(0, (\sigma_B^2 + \sigma_A^2 - 2\sigma_B\rho_{AB})dt)$ from the distribution as $\hat{X}$.
Therefore, we can write

$$d\frac{S_B^B}{S_A^A} = \frac{S_B^B}{S_A^A} \bar{\mu}dt + \frac{S_B^B}{S_A^A} \bar{\sigma}dW_t, \quad (6.5.2)$$

where

$$\bar{\sigma} = \sqrt{\sigma_B^2 + \sigma_A^2 - 2\sigma_B\rho_{AB}}$$

and

$$\bar{\mu} = \mu_B - \mu_A + \sigma_A^2 - \sigma_B\rho_{AB}.$$

Following Section 4.4.3 we choose the probability measure $\mathbb{Q}$ so that the drift term in equation (6.5.2) is zero.

$$dW_P = dW_Q - \left(\frac{\bar{\mu}}{\bar{\sigma}}\right)dt.$$

Substituting this into equation (6.5.2) gives

$$d\frac{S_B^B}{S_A^A} = \frac{S_B^B}{S_A^A} \bar{\sigma}dW_Q. \quad (6.5.3)$$

It can be seen that (6.5.3) is identical to equation (4.4.31) with the mapping

$$S \to \frac{S_B^B}{S_A^A}, \quad \sigma \to \bar{\sigma}, \quad r \to 0. \quad (6.5.4)$$

Now combining equations (4.4.35) and equation (4.4.47), we have

$$\exp(-rt)E^Q[\max(S_T, 0)] = SN_1(d_1) - E\exp(-rt)N_1(d_2),$$

where $d_1$ and $d_2$ have been defined in Chapter 4.

Therefore,

$$E^Q[\max(S_T - 1, 0)] = \exp(r\tau)SN_1(d_1) - N_1(d_2).$$

Using the mapping defined in equation (6.5.4), we have

$$E^Q\left[\max\left(\frac{S_B^B}{S_T^A}-1, 0\right)\right] = \left[\frac{S_T^B}{S_T^A}N_1(d_1) - N_1(d_2)\right]$$

and so from equation (6.5.1).

$$V(t_0) = S_{t_0}^B N_1(d_1) - S_{t_0}^A N_1(d_2),$$

which means that the value of the exchange option at time $t_0$ is

$$V(t_0) = S_{t_0}^B N_1(d_1) - S_{t_0}^A N_1(d_2),$$

where

$$d_1 = \frac{\log\left(\frac{S_{t_0}^B}{S_{t_0}^A}\right) + \frac{1}{2}(T-t_0)\sigma^2}{\sigma\sqrt{T-t_0}}$$
$$d_2 = \frac{\log\left(\frac{S_{t_0}^B}{S_{t_0}^A}\right) - \frac{1}{2}(T-t_0)\sigma^2}{\sigma\sqrt{T-t_0}}$$
