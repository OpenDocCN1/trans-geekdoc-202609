
# Vanilla Options and the Black–Scholes Model Section | 4.4

The Black–Scholes formula for the value of a European call including continuous dividends is this

```
$c(S,E,\tau) = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2),$
```

and the corresponding formula for a put can be shown (using put call parity) to

```
$p(S,E,\tau) = -S\exp(-q\tau)N_1(-d_1) + E\exp(-r\tau)N_1(-d_2),$
```

or equivalently, $N_1(-x) = 1 - N_1(x)$, we have

```
$p(S,E,\tau) = E\exp(-r\tau)\{1 - N_1(d_2)\} - S\exp(-q\tau)\{1 - N_1(d_1)\},$
```

where

```
$d_1 = \frac{\log(S/E) + (r-q+\sigma^2/2)\tau}{\sigma\sqrt{\tau}}, \quad d_2 = \frac{\log(S/E) + (r-q-\sigma^2/2)\tau}{\sigma\sqrt{\tau}}$
```

Thus, European put/call options with continuous dividends can be priced using equations (4.4.47) and (4.4.50) with $S$ replaced by $S\exp(-q\tau)$.

These formulae can be re-expressed in terms of the current forward price with maturity $T$, $S(t,T)$:

```
$c_t = E\exp(-r(T-t))S(t,T)N_1(d_2) - EN_1(d_2),$
```

```
$p_t = E\exp(-r(T-t))\{-S(t,T)N_1(-d_1) - EN_1(-d_2)\},$
```

where we have used the notation $p_t$ and $c_t$ to denote the current $(t)$ value of put and call options, and the current forward price with maturity $T$ is

```
$S(t,T) = S\exp((r-q)(T-t)), \quad t \le T$
```

and

```
$d_1 = \frac{\log(S(t,T)/E) + (\sigma^2/2)(T-t)}{\sigma\sqrt{\tau}}, \quad d_2 = \frac{\log(S(t,T)/E) - (\sigma^2/2)(T-t)}{\sigma\sqrt{\tau}}$
```

# The Inclusion of Discrete Dividends

Here, consider $n$ discrete dividends $D_i,i=1,\dots,n$, at times $t_i=1,\dots,n$ during the life of the option. In these circumstances, the Black–Scholes formula is used to price European options, but the current asset value is reduced by the present value of the cash dividends.

This means that instead of $S$ we use the quantity $S_D$ which is computed as

```
$S_D = S - \sum_{i=1}^{n} D_i\exp(-rt_i),$
```

where $r$ is the (in this case constant) interest rate. The formulae for European puts and calls are

```
$c(S,E,\tau) = S_DN_1(d_1) - E\exp(-r\tau)N_1(d_2),$
```

```
$p(S,E,\tau) = E\exp(-r\tau)\{1 - N_1(d_2)\} - S_D\{1 - N_1(d_1)\},$
```

where

$d_1 = \frac{\log(S_D/E) + (r + \sigma^2/2)\tau}{\sigma\sqrt{\tau}} \text{ and } d_2 = \frac{\log(S_D/E) + (r - \sigma^2/2)\tau}{\sigma\sqrt{\tau}} = d_1 - \sigma\sqrt{\tau}. (4.4.62)$

# The Greeks

Now that we have derived formulae for price European vanilla puts and calls, and it is possible to work out their partial derivatives (hedge statistics). We will now merely quote expressions for the Greeks (hedge statistics) for European options. Here, the subscript $c$ refers to a European call, and the subscript $p$ refers to a European put. Complete derivatives of these results can be found in Appendix A.

# Gamma:

$$\Gamma_c = \frac{\partial^2 c}{\partial S^2} = \Gamma_p = \frac{\partial^2 p}{\partial S^2} = \exp(-q\tau)\frac{n(d_1)}{\sigma\sqrt{\tau}} (4.4.63)$$

# Delta:

$$\Delta_c = \frac{\partial c}{\partial S} = \exp(-q\tau)N_1(d_1), \Delta_p = \frac{\partial p}{\partial S} = \exp(-q\tau)\{N_1(d_2) - 1\}. (4.4.64)$$

# Theta:

$$\Theta_c = \frac{\partial c}{\partial t} = q\exp(-q\tau)N_1(d_1) - rE\exp(-r\tau)N_1(d_2) - \frac{Sn_1(d_2)\exp(-q\tau)}{2\sqrt{\tau}}$$
$$\Theta_p = \frac{\partial p}{\partial t} = -q\exp(-q\tau)N_1(d_1) + rE\exp(-r\tau)N_1(d_2) - \frac{Sn_1(d_2)\exp(-q\tau)}{2\sqrt{\tau}} (4.4.65)$$

# Rho,

$$\rho_c = \frac{\partial c}{\partial r} = EN_1(d_2), \rho_p = \frac{\partial p}{\partial r} = -EN_1(d_2). (4.4.66)$$

# Vega:

$$\nu_c = \frac{\partial c}{\partial \sigma} = \nu_p = \frac{\partial p}{\partial \sigma} = S\exp(-q\tau)n(d_1)\sqrt{\tau}, (4.4.67)$$

where $n(x) = (1/\sqrt{2\pi})\exp(-x^2/2)$. The Black-Scholes option value and Greeks given in equations (4.4.63) to (4.4.67).
