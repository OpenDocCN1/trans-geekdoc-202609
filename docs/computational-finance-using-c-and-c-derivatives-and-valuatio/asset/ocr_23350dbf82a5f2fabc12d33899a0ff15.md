Lattice level 7: Time t + 6Δt

$S_G = Su^6, \quad S_H = Su^4, \quad S_I = Su^2, \quad S_J = S,
$S_K = Sd^2, \quad S_L = Sd^4, \quad S_M = Sd^6.$

In general, at $t + i\Delta t$, there are $i+1$ stock prices; these are
$S_{i,j} = Su^{i-j}d^j, \quad j = 0, 1, \dots, i.$

We note, that $u = 1/d$, an movement followed by a down movement
gives the same stock price as a down movement followed by an up movement,
 instance $Su^2d = Su$. This means the tree recombines, and the number of
nodes to represent all the different asset prices is significantly reduced.
