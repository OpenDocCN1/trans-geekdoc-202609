# Equity Quanto Forward

(The time $t$) value of a domestic equity forward contract with maturity $T$

```
$F(t)=DF^d(t,T)\{S^d(t,T)-K^d\},$
```

where $K^d$ is the strike in domestic currency and $S^d(t,T)$ is the domestic forward price.

To value an equity quanto contract, we need to know the forward price of the foreign equity $S^F$.

It can be seen from equations (4.4.31),(4.4.32) and (7.5.20) can for this forward price is

```
$S^F(t,T)=S^F(t)\exp((rf-\\sigma_s\sigma_x\rho_{xs})(T-t)).\n\n(7.5.21)$
```

where $S^F(t)$ is the current price of the foreign equity and $T$ is the maturity of the forward.

In equity quanto forward, the payoff is in foreign currency but it is converted to domestic currency at a predetermined exchange rate (which denote here by X). The value quanto forward is

```
$qPF(t)=DF^d(t,T)\{S^d(t,T)-K^f\}X,$
```

where $X$ is the specified exchange rate, $K^f$ is the strike in units of foreign currency, and $S^F(t,T)$ is the forward foreign equity price.
