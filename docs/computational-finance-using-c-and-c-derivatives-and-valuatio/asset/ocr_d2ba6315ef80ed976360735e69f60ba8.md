Replacing $k$ with $k-1$ in equation (7.2.52) gives

```
$dW^{k-1} = \frac{\sigma_{k-1}F_{k-1}}{1+F_{k-1}}dt + dW^{k-2}, \quad (7.2.54)$
```

and using (7.2.54) to substitute for $dW^{k-1}$ in equation (7.2.52), we obtain

```
$dW^k = \frac{\sigma_k F_k}{1+F_k}dt + \frac{\sigma_{k-1}F_{k-1}}{1+F_{k-1}}dt + dW^{k-2}, \quad (7.2.55)$
```

Replacing $dW^k$ in equation (7.2.40) with that given in equation (7.2.55),

```
$dF_k = F_k\sigma_k(\frac{\sigma_k F_k}{1+F_k}dt + \frac{\sigma_{k-1}F_{k-1}}{1+F_{k-1}}dt), \quad (7.2.56)$
```

so the drift is

```
$\mu_k = \frac{\sigma_k^2 F_k}{(1+F_k)} + \frac{\sigma_k\sigma_{k-1}F_{k-1}}{1+F_{k-1}}, \quad (7.2.57)$
```

The general expression can be derived in a similar manner:

```
$dF_k = F_k\sigma_k \sum_{j=i+1}^k \frac{P_j\sigma_j F_j}{1+F_j}dt + \sigma_k F_k dW^i, \quad (7.2.58)$
```

where all the symbols have the same means as before, but $i$ can take any integer value less than $k$.

Case $i > k$

We now consider the case when the maturity of the numeraire $DF_i$ is after the expiry of the forward rate $F_k$.

Case $i = k+1$

Here, $DF_{k+1}$ is the numeraire and $F_k$ is the forward rate which starts at time $t_{k-1}$ and ends at time $t_k$.

Since $DF_{k-1}$ is a tradable, its relative price, $\phi = DF_{k-1}/DF_{k+1}$, is a martingale under $\mathbb{Q}^{k+1}$ and thus has zero drift.

Now

```
$\phi = \frac{DF_{k-1}}{DF_{k+1}} = (1+	au F_k)(1+	au F_{k+1}), \quad (7.2.59)$
```

where the processes for $F_k$ and $F_{k+1}$ are

```
$dF_k = F_k(1+\sigma_k)\sigma_k dW^{k+1}, \quad (7.2.60)$
```

```
$dF_k = F_k\mu_k dt + F_k\sigma_k dW^{k+1}, \quad (7.2.61)$
```

and the drift, $\mu_k$, is to be determined.
Using Ito, we have

```
$\phi = \frac{\partial \phi}{\partial F_k}dF_k + \frac{\partial \phi}{\partial F_{k+1}}dF_{k+1} + \frac{1}{2} \sum_{i=k}^{k+1} \sum_{j=k}^{k+1} \frac{\partial^2 \phi}{\partial F_i\partial F_j}E[dF_i, dF_j], \quad (7.2.62)$
```
