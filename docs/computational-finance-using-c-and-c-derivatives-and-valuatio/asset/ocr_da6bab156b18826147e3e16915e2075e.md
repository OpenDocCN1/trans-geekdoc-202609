Since $dZ_i \sim N(0,1)$, by the law of large numbers (see Appendix C.1), we have that the expected value of position $X_T$

```
$E[X_T] = \sigma \sqrt{dt} E \left[ \sum_{i=1}^n dZ_i \right] = 0.$
```

The variance of the position $X_T$ is

```
$Var[X_T] = Var \left[ \sigma \sqrt{dt} \sum_{i=1}^n dZ_i \right] = \sigma^2 dt Var \left[ \sum_{i=1}^n dZ_i \right]. \quad (2.1.8)
```

Since all $dZ_i$ are $IID N(0,1)$, we have $Var[dZ_i] = 1$ and $Var[\sum_{i=1}^n X_i] = \sum_{i=1}^n Var[X_i]$, see Appendix C.3.1. Thus,

```
$Var[X_T] = \sigma^2 dt Var[dZ_i] = \sigma^2 dt \sum_{i=1}^n 1, \quad (2.1.9)
```

which gives

```
$Var[X_T] = \sigma^2 n dt = T \sigma^2. \quad (2.1.10)
```

So, at $T$, the position of the pollen grain, $X_T$ is distributed as $X_T \sim N(0, \sigma^2)$.

If the water container is not level then the pollen grains will exhibit drift in a particular direction. We can modify equation (2.1.5) to take into this account as follows:

```
$dX_T = \mu dt + \sigma \sqrt{dt} dZ_i, \quad dZ_i \sim N(0,1),$
```

or equivalently

```
$dX_t = \mu dt + \sigma dW_t, \quad dW_t \sim N(0,dt), \quad (2.1.12)
```

where we have included the constant drift $\mu$. Proceeding in a similar manner to that the case of zero drift Brownian motion, we have

```
$X_T = \sum_{i=1}^n (\mu dt + \sigma \sqrt{dt} dZ_i) = \mu dt + \sigma \sqrt{dt} \sum_{i=1}^n dZ_i = \mu T + \sigma \sqrt{dt} \sum_{i=1}^n dZ_i,$
```

which gives

```
$E[X_T] = E \left[ \mu T + \sigma \sqrt{dt} \sum_{i=1}^n dZ_i \right],$
```

```
$E[X_T] = \mu T + \sigma \sqrt{dt} E \left[ \sum_{i=1}^n dZ_i \right] = \mu T.$
```

The variance of the position $X_T$ is

```
$Var[X_T] = Var \left[ \mu T + \sigma \sqrt{dt} \sum_{i=1}^n dZ_i \right] = Var \left[ \sigma \sqrt{dt} \sum_{i=1}^n dZ_i \right].
```
