# 4.5.3 Analytic Pricing of Up and Out Options

Here we will obtain an expression for an up out European call option with continuous dividend yield q, in a similar manner to used in Section 4.5.2 for the down and out European call option. A European up and out barrier option with maturity τ and barrier at X = B will cease to exist (become worthless) if at any time X ≥ B, for all t ≤ s ≤ T. The probability density function that the barrier option will continue to exist at time if the end point is X is this

> $f(X < B) = \sqrt{\frac{2}{\pi}} \int_{b=X}^{B} S \exp(b) \Omega \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right) \exp\left(\frac{\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right) db \(4.5.11)

or

> $f(X < B) = \sqrt{\frac{2}{\pi}} \exp\left(\frac{\\{X-(r-q-\sigma^2/2)\tau\}^2}{2\sigma^2\tau}\right) b^{log(B/S)} \int_{b=X}^{B} \Omega \exp\left(\frac{2b(X-b)}{\sigma^2\tau}\right) db \(4.5.12)

where as in Section 4.5.2 we used $\Omega = (B-X)/\sigma^3\tau^{3/2}$ and integrated over all possible values of $b$ (i.e., $B > b > X$), that can keep the option active. Recalling that
