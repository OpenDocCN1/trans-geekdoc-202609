# Optimally repaired correlation matrix

Here, we provide details of how to obtain an optimally repaired correlation matrix using hyperspherical coordinates, see Rebonato and Jäck (1999) – for a different approach see Higham (2002) or Qi and Sun (2006).
The coordinates of the $i$th point on an $n$-dimensional hypersphere with radius $r$ can be shown to

```
$x_{i,1} = r \cos(\theta_{i,1}),$\n$x_{i,2} = r \sin(\theta_{i,1})cos(\theta_{i,2}),$\n$x_{i,3} = r \sin(\theta_{i,1})sin(\theta_{i,2})cos(\theta_{i,3}),$\n$x_{i,4} = r \sin(\theta_{i,1})sin(\theta_{i,2})sin(\theta_{i,3})cos(\theta_{i,4}),$\n$\n$\dots$\n$x_{i,n-1} = r \sin(\theta_{i,1}).sin(\theta_{i,n-2}). \quad \dots \sin(\theta_{i,n-3})sin(\theta_{i,n-2})cos(\theta_{i,n-1}),$\n$x_{i,n} = r \sin(\theta_{i,1})sin(\theta_{i,2}). \quad \dots \sin(\theta_{i,n-2})sin(\theta_{i,n-1}).$
```

where $	heta_{i,k}$ are hyperspherical coordinates and have the following constraints: $0 \le \theta_{i,k} \le \pi, k = 1, \dots, n-2$, and $0 \le \theta_{i,n-1} \le 2\pi$.
By construction, the radius of the sphere satisfies

```
$r^2 = \sum_{k=1}^{n} (x_{i,k})^2.$
```

This can be seen as follows:

```
$(B^T B)_{i,i} = r^2 { \cos^2(\theta_{i,1}) + \sin^2(\theta_{i,1}) (\cos^2(\theta_{i,2}) + \sin^2(\theta_{i,2})) + \cos^2(\theta_{i,3}) + \sin^2(\theta_{i,3})) \n \times ( \cos^4(\theta_{i,1}) + + \sin^2(\theta_{i,n-2})\cos^2(\theta_{i,n-1}) + \sin^2(\theta_{i,n-1}) \dots ) } \n = r^2$,
```

where we have used
$\cos^2(\theta_{i,k}) + \sin^2(\theta_{i,k}) = 1, k = 1, \dots, n-1.$
