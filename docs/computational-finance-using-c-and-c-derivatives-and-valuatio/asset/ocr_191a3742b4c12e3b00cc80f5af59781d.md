# Quanto Swapet

A quanto (also known as diff or differential swap) is an agreement in which one party makes floating rate payments based on the foreign forward rate while the other makes fixed or floating payments based on the domestic interest rates.

Here, we consider quanto swaps in which the receiving floating coupons (in domestic currency) are computed using foreign forward rates.
The value of a standard swap (which all the currencies are domestic) can be found by using (7.2.90) and (7.2.74) to write

```
$Caplet(t_0) - Floorlet(t_0) = P\tau D^f(t_0, t_k)E^{Q^k} [max(F^f_k - K, 0) - max(K - F^f_k, 0)]\n= P\tau D^f(t_0, t_k)E^{Q^k} [F^f_k - K]\n= P\tau D^f(t_0, t_k)E^{Q^k} \{F^f(t_0, t_{k-1}, t_k) - K\}.$ (7.24)
```

From equation (7.2.94), we can see that Caplet(t_0) - Floorlet(t_0) is the value of a swap in which the owner pays the fixed rate $K$ and receives the floating rate $E^d(t_0, t_{k-1}, t_k)$.

The value of the floating leg payment can be found by setting $K=0$ in equation (7.2.94) and $P\tau D^f(t_0, t_k)F^d(t_0, t_{k-1}, t_k).
The value of the floating leg payments in a quanto swap can be found in a similar manner,

```
$Caplet(t_0) - Floorlet(t_0) = P\tau D^f(t_0, t_k)E^{Q^k} [max(F^f_k - K, 0) - max(K - F^f_k, 0)].$.
```
