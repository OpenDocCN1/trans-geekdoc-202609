# 7.3.1 FX Forward

A foreign exchange (FX) forward is a contract to exchange an agreed amount of foreign currency at a future time T. If $P^f$ is the amount (number of units) of foreign currency, and $P^d$ is the amount (number of units) of domestic currency, then the value (in currency) of the FX contract at time T is

```
$FX_d(T) = P^f X_d^f(T) - P^d$.
```

The value of the contract at time T is

```
$FX_d(t) = \left\ P^f X_d^f(t,T) - P^d \right\ DF^d(t,T),$
```

where $t < T$. Substituting for $X_d^f(t,T)$ from equation (7.3.1) we then gives

```
$FX_d(t) = \left\ P^f X_d^f(t,T) \frac{DF^f(t,T)}{DF^d(t,T)} - P^d \right\ DF^d(t,T),$
```

which can be re-expressed as

```
$FX_d(t) = P^f X_d^f(t,T) DF^f(t,T) - P^d DF^d(t,T). \quad (7.3.2)$
```

The value of this FX Forward contract in base currency is

```
$FX_b(t) = \left\ P^f X_b^f(t,T) DF^f(t,T) - P^d DF^d(t,T) \right\ X_b^d,$
```

that is,

```
$FX_b(t) = P^f X_b^f(t,T) DF^f(t,T) - P^d DF^d(t,T) X_b^d(t), \quad (7.3.3)$
```

where we have used that $X_d^f(t) = X_d^d(t)$.

An alternative way of expressing equation (7.3.3) is as

```
$FX_b(t) = \left\ P^f X_b^f(t,T) DF^f(t,T) - K DF^d(t,T) X_b^d(t) \right\, \quad (7.3.4)$
```

where $K = P^d/P^f$. In the next section, we will see that $K$, the agreed rate to be paid for one unit of foreign currency in units of domestic currency, corresponds to the $strike$ of an FX call option.
