For each value of $j$, equation (5.4.14) gives us a relationship between three option values $f_{i+1,j-1}, f_{i+1,j}, and f_{i+1,j+1}$ at time index $i+1$ and three option values $f_{i,j-1}, f_{i,j}$, and $f_{i,j+1}$ at time index $i$.

This situation is shown in Fig. 5.5 where we have labelled the grid nodes that contribute to option value $f_{5,5}$ at node E. These are the option values:
- node A: $f_{6,6}$
- node B: $f_{6,5}$
- node C: $f_{6,4}$
- node D: $f_{5,3}$
- node E: $f_{5,5}$
- node F: $f_{5,4}$

Before we solve equation (5.4.14) we will briefly consider its characteristics for different values of the weight parameter $\Theta_m$. When $\Theta_m = 1$, the values of the coefficients in equation (5.4.14) are $a_j = c_j$ and $b_j = 1$. This means that equation (5.4.14) reduces to

$f_{i,j} = a_j f_{i+1,j-1} + b_j f_{i+1,j} + c_j f_{i+1,j+1}$.

This is termed the *explicit method*, and it can be seen that the unknown value $f_{i,j}$ at node $(i,j)$ is just a weighted sum of the (known) option values $f_{i+1,j-1}, f_{i+1,j}$, and $f_{i+1,j+1}$. This is the simplest situation to deal with and actually corresponds to trinomial lattice; however it has numerical properties and requires a very small step size to obtain accurate results, see Smith (1985).

When $\Theta_m < 1$, the unknown value $f_{i,j}$ depends not only on the known option values $f_{i+1,j-1}, f_{i+1,j}$, and $f_{i+1,j+1}$ (as in the explicit method above) but on the neighbouring unknown values $f_{i,j-1}$ and $f_{i,j+1}$. It is now necessary to solve a set of simultaneous equations to compute the value $f_{i,j}$. This is therefore called an *implicit method*, see Smith (1985).

The implicit method $\Theta_m = 0$ is also the fully implicit method, since the value $f_{i,j}$ only depends on the neighbouring values $f_{i,j-1}, f_{i,j+1}$, and previous value $f_{i,j}$. This can be shown by substituting $\Theta_m = 0$ in equation (5.4.16) to (5.4.21). We then have $\tilde{a}_j = \tilde{c}_j$ and $\tilde{b}_j = 1$, which means that equation (5.4.14) reduces to

$a_j f_{i,j-1} + b_j f_{i,j} + c_j f_{i,j+1} = f_{i+1,j}$.

The implicit method $\Theta_m = 0.5$ is also the Crank-Nicolson method, first method by John Crank and Phyllis Nicholson in 1946 (see Crank and Nicolson (1947)), computes $f_{i,j}$ by giving equal weight to the contributions from time step $i+1$ and time step $i$. Substituting $\Theta_m = 0.5$ in equation (5.4.16) to obtain the Crank-Nicolson coefficients:

$a_j - \tilde{a}_j = \frac{\Delta t}{4} \{(r-q)j - \sigma^2 j\}$,
$\tilde{b}_j = 1 + \frac{\Delta t}{2} \{r + \sigma^2 j\}$,
$\tilde{c}_j = 1 - \frac{\Delta t}{4} \{ r + \sigma^2 j\}$,
$c_j = -\tilde{c}_j = -\frac{\Delta t}{4} \{(r-q)j + \sigma^2 j^2 \}$

## The Boundary Conditions

In order to solve (5.4.14) at time instant $j\Delta t$, we need to obtain the option values at the upper asset boundary, the lower asset boundary, and the initial values that are specified at option maturity. Here, we calculate the boundary values using the time independent payoff $p_j$, at the $j$th asset index within the grid. If $E$ is the strike price, then vanilla call options have payoffs

$p_j = \max(j\Delta S - E), \quad j = 0, \dots, n_s-1$

and vanilla put options have payoffs

$p_j = \max(E - j\Delta S), \quad j = 0, \dots, n_s-1$

**Upper asset boundary**
At the upper boundary, $j = n_s - 1$ and $(n_s - 1)\Delta S = S_{max}$, where we note for the grid to be useful, we require $S_{max} > E$. Here, we observe that $S_{max} > E$ so for call options

$p_{n_s-1} = S_{max} - E$,

and for put options $p_{n_s-1} = 0$.

The option value at the upper boundary, denoted by $f_{BU}$, is set to $p_{n_s-1}$, and we have $f_{i,n_s-1}=f_{BU}, i = 0, \dots, n_t$.

**Lower asset boundary**
At the lower boundary, $j = 0$ and the value of $j\Delta S$ is zero. So for call options $p_0 = 0$, and for put options the option value at the lower boundary, denoted by $f_{BL}$, is set to $p_0$, and we have $f_{i,0}=f_{BL}, i = 0, \dots, n_t$.

**Boundary values at option maturity**
At option maturity ($i = n_t$), the initial option (boundary) values are the previously mentioned. If $E$ is the strike price, then for vanilla call options $f_{n_t,j} = \max(j\Delta S - E), \quad j = 0, \dots, n_s-1$, and for vanilla put options, $f_{n_t,j} = \max(E - j\Delta S, 0), \quad j = 0, \dots, n_s-1$.

This is illustrated in Fig. 5.5 for a vanilla put option with current asset value $S_0 = 20$, $E = 25$, and maturity $\tau=2$. The grid spacing $\Delta S = 5$, and the time index $\Delta t = 0.2$. At option maturity, corresponding to time index $i = 10$, the value of the put option is zero for all asset indices $j \geq 5$.

## Computation of the Options Value at a Given Time

Having found the option boundary values, we are now in position to solve equation (5.4.14) at instant time $t_i = i\Delta t$. First we note that $f_{i,0} = f_{BL}$, and $f_{i,n_s-1} = f_{BU}$, equation (5.4.14) only needs be solved for values of the asset index $j$ in the range $j=1$ to $j=n_s-2$. We now deal with the following situations:
- Case 1: $j=1$, the asset grid line just above the lower boundary.
- Case 2: $j=n_s-2$, the asset grid line just below the upper boundary.
- Case 3: all other grid lines not included in Case 1 or Case 2

and consider the fact that (5.4.14) takes under each condition.

Case 1: $j=1$
Substituting $j=1$ into equation (5.4.14), we obtain

$a_1f_{1,0} + b_1f_{1,1} + c_1f_{1,2} = \tilde{a}_1f_{1,0} + \tilde{b}_1f_{1,1} + \tilde{c}_1f_{1,2}$.

Now, since $f_{i,0} = f_{BL}$, this becomes

$b_{1,1} + c_{1,2}f_{1,2} = (\tilde{a}_1 - a_1)fBL + b_1f_{1,1} + \tilde{c}_1f_{1,2}$,

or equivalently

$b_{1,1} + c_{1,2}f_{1,2} = R_{1,1},quad (5.4.22)$

where

$R_{1,1} = (\tilde{a}_1 - a_1)fBL + \tilde{b}_1f_{1,1} + \tilde{c}_1f_{1,2}. (5.4.23)$

Case 2: $j=n_s-2$.
Substituting $j=n_s-2$ into equation (5.4.14), we obtain

$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} + cn_{n_{s-2}}f_{i,n_{s-1}} = \tilde{a}_{n_{s-2}}f_{i+1,n_{s-3}} + \tilde{b}_{n_{s-2}}f_{i+1,n_{s-2}} + \tilde{c}_{n_{s-2}}f_{i+1,n_{s-1}}$.

Since $f_{i,n_s-1} = fBU$, this gives

$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} = \tilde{a}_{n_{s-2}}f_{i+1,n_{s-3}} + (\tilde{c}_{n_{s-2}} - c_{n_{s-2}})fBU$,

or equivalently

$an_{n_{s-2}}f_{i,n_{s-3}} + bn_{n_{s-2}}f_{i,n_{s-2}} = R_{i+1,n_{s-2}},quad (5.4.24)$
