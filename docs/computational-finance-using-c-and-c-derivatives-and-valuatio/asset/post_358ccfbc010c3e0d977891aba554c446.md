## Equity Deal Classes Section | 8.3

Below, we provide some example results for options on four and ten assets. The assets were Drinks-4U, Beverage-Ltd, H20-Ltd, and Fine-Wines-Ltd. The trade attributes are able to expire of one year, all volatilities are 0.2, and the number of units is 100. Other information required to price the option, such as the correlations between the equities and the risk-free interest rate, is from the market data dictionaries.

The syntax for the deal GenericEquityBasketOptionDeal with the portfolio definition is

Trade-GenericEquityBasketOptionDeal:Payoff=MaxPut,Strike=100.0,Volatilities={0.2,0.2,0.2},Equities={Drinks-4U,Beverage-Ltd,H20-Ltd,Fine-Wines-Ltd},NumberOfUnits=100,TimeTo_To_Expiry=1.0,NumberScenarios=169

The crucial difference is that entry GenericEquityBasketDeal:MaxPut, whereas GenericEquityOptionDeal is derived from the abstract class GenericEquityBasketDeal. The .NET assembly containing the GenericEquityBasketDeal is stored in memory and its Price() method is called to validate the option.

```csharp
using System;
namespace Computational_lib{
    public class GenericEquityBasketOptionDeal_MaxPut : GenericEquityBasketDeal{
        public override string Name()
        {
            string string_temp = "";
            string_temp = "Generic Option: Put on the maximum of " + n + " assets";
            return string_temp;
        }

        public override double Payoff(double[] ST)
        {
            double max_val = 0;
            double pay_val = 0;
            double zero = 0;

            for (int j = 0; j < n; j++) {
                if (ST[j] > max_val) { max_val = ST[j]; }
            }
            pay_val = Math.Max(Strike_, max_val, zero);
        }
    }
}
```

In the code above, the ST_, Strike_, and n are data members of the base class GenericEquityBasketDeal.
