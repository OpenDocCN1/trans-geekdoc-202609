The value, $c_{do}$ of a European down out call option with strike $E$, satisfying
E > B$, is given by

```
$c_{do} = \frac{\exp(-r\tau)}{\sqrt{2\pi\tau}} \int_{\log(E/S)}^{\infty} {exp(X) - E} f(X > B)dX. \quad (4.5.9)
```

This integral is evaluated in Appendix B.1, and the value of the down and out call option $c_{do}$ is

```
$c_{do} = c - c_{di}. \quad (4.5.10)
```

where

```
$c = S\exp(-q\tau)N_1(d_1) - E\exp(-r\tau)N_1(d_2),\n$c_{di} = S\exp(-q\tau)N_1(d_4) \left(\frac{B}{S}\exp(-\frac{qr}{\sigma^2})\right) - E\exp(-r\tau)N_1(d_3) \left(\frac{B}{S}\exp(-\frac{2(r-q)}{\sigma^2})\right)\n$d_1 = \frac{\log(S/E) + (r - q + \sigma^2/2)\tau}{\sigma\tau}}, \quad d_2 = \frac{\log(S/E) + (r - q - \sigma^2/2)\tau}{\sigma\tau},\n$d_3 = \frac{\log(B^2/SE) + (r - q - \sigma^2/2)\tau}{\sigma\tau}, \quad d_4 = \frac{\log(B^2/ES) + (r - q + \sigma^2/2)\tau}{\sigma\tau}$
```
