> $Puu - Pud + Pdd + Pdu = \frac{\mu_2}{\sigma_2}$,$

$Puu + Pud + Pdd + Pdu = 1$,

$Puu - Pud + Pdd - Pdu = \rho$.

These lead to the following jump probabilities:

> $Puu = \frac{1}{4} \left\{1 + \sqrt{\Delta t} \left( \frac{\mu_1}{\sigma_1} + \frac{\mu_2}{\sigma_2} \right) + \rho \right\right$,

$Pud = \frac{1}{4} \left\{1 + \sqrt{\Delta t} \left( \frac{\mu_1}{\sigma_1} - \frac{\mu_2}{\sigma_2} \right) - \rho \right\right$,

$Pdd = \frac{1}{4} \left\{1 - \sqrt{\Delta t} \left( \frac{\mu_1}{\sigma_1} - \frac{\mu_2}{\sigma_2} \right) + \rho \right\right$,

$Pdu = \frac{1}{4} \left\{1 + \sqrt{\Delta t} \left( \frac{\mu_1}{\sigma_1} + \frac{\mu_2}{\sigma_2} \right) - \rho \right\right$.
