We introduce the normalized value $z_n$, as follows:

```
$$$z_n = \frac{s_n - n\mu}{\sigma \sqrt{n}} = \frac{1}{\sqrt{n}} \sum_{i=1}^{n} u_i.$$
```

The central limit theorem states that as $n$ tends to infinity the probability distribution of $z_n$ tends to a normal distribution with zero mean and unit variance, mathematically $z_n 	o N(0,1)$ as $n 	o \infty$.

Proof. From Appendix C.5 equation (C.5.3),

```
$$$M_{z_n} = E[\exp(tz_n)] = E \left[ \exp \left\{ \frac{t}{\sqrt{n}} \sum_{i=1}^{n} u_i ight\} ight].$$
```

and using (C.5.5)

```
$$$M_{z_n} = M_u \left( \frac{t}{\sqrt{n}} ight)^n.$$$$
```

Equation (C.5.1) then yields

```
$$$M_u \left( \frac{t}{\sqrt{n}} ight) \approx 1 + \frac{t}{\sqrt{n}} E[u] + \frac{1}{2} \left( \frac{t}{\sqrt{n}} ight)^2 E[u^2] + ..$$$$
```

As $n \to \infty/t(\sqrt{n}) \to 0$,

```
$$$M_u \left( \frac{t}{\sqrt{n}} ight) \to 1 + \frac{t}{\sqrt{n}} E[u] + \frac{1}{2} \left( \frac{t}{\sqrt{n}} ight)^2 E[u^2] = 1 + \frac{t^2}{2n}.$$$$
```

Thus,

```
$$$M_u \left( \frac{t}{\sqrt{n}} ight)^n = \left( 1 + \frac{t^2}{2n} \right)^n \to 1 + \frac{t^2}{2n} \text{ as } n \to \infty,$$$$
```

where we have used the fact that $t << 1$ Grimmett and Welsh (1986).
We have therefore shown that as $n \to \infty$

```
$$$M_{z_n}(t) \to e^{\frac{t^2}{2}}.$$$
```

Thus from Appendix D.1, the moment generating function $M_z(t)$ for a standard normal distribution ($\mu = 0, \sigma^2 = 1$) is

```
$$$M_z(t) = e^{\frac{t^2}{2}}, \text{ where } z \sim N(0,1).$$$$
```

Thus, we have proved that $z_n \to N(0,1)$ as $n \to \infty$.
