It has already been noted that the volatility used by the application to price options is supplied as a deal attribute, rather than being stored as market data. The reason for this is simplicity. In Chapter 4, we mentioned that a volatility surface is required to retrieve the implied volatility used to price options. Storing the implied volatility would require a set of volatility surfaces in the market data file and multidimensional interpolation to retrieve the volatility applicable to a given option. It was decided to choose the volatility as a trade attribute and update its value.
