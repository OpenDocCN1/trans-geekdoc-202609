# Four Variables

Let Z1 = a+b1X1+b2X2+b3X3 and Z2 = c+dY, where a, b1, b2, b3, c, and
d are constants.

We have

```
Cov[Z1,Z2] = Cov[a+b1X1+b2X2+b3X3,c+dY]
= E[(a+b1X1+b2X2+b3X3)(c+dY)]
- E[(a+b1X1+b2X2+b3X3)]E[c+dY]
= E[(a+b1X1+b2X2)(c+dY)] + b3X3(c+dY)
- {E[(a+b1X1+b2X2)] + E[b3X3]E[c+dY]}
= E[(a+b1X1+b2X2)(c+dY)] - E[b2X2]E[c+dY]
- E[(a+b1X1+b2X2)]E[c+dY] - E[b3X3]E[c+dY]
= E[(a+b1X1+b2X2)(c+dY)] - E[a+b1X1+b2X2]
- {E[(b3X3)(c+dY)] - E[b3X3]E[c+dY]}
= Cov[a+b1X1+b2X2,c+dY] + Cov[b3X3,c+dY].
```

.. Cov[Z1,Z2] = b1Cov[X1,Y] + b2Cov[X2,Y] + b3Cov[X3,Y].

# Covariance of n Variables

In a similar manner to outlined above,

```
Cov[a + ∑_{i=1}^n bXi,c+dY] = ∑_{i=1}^n diCov[Xi,Y].
```

For the most general case, let Z1 = a + ∑_{i=1}^M bXi and Z2 = c + ∑_{j=1}^M bjYj.

So

```
Cov[Z1,Z2] = Cov[a + ∑_{i=1}^M bXi,c + ∑_{j=1}^M djYj] = Cov[a + ∑_{i=1}^n bXi,c + ∑_{j=1}^n djYj].
```

So

```
Cov[a + ∑_{i=1}^n bXi,c + ∑_{j=1}^M djYj] = ∑_{i=1}^n diCov[Xi, ∑_{j=1}^M djYj].
```
