It should be mentioned that this result applies for both American and European options and it does not matter whether we have bought or sold options.

In Chapter 5, we will use the fact that the difference between the value of a European option and the equivalent American option obeys the Black–Scholes equation. We can show this immediately by considering the following portfolios that are long in an American option (i.e., have sold) in a European option

```

```

Where $P$ and $C$ are the values of American put and call options. $\Psi^P$ and $\Psi^C$ both obey the Black–Scholes equations and are the differences in value of American/European put and American/European call options.

## 4.4.2 The Multi-asset Option Pricing Partial Differential Equation

In this section we will derive the multi-asset (Black–Scholes) partial differential equation that is obtained by options on n assets. Proceeding in Section 4.4.1 we will use the n-dimensional version of Ito’s lemma to find the process followed by the value of a multi-asset financial derivative. We will denote the value of this derivative by $f(S,t)$, where $S$ is an n-element stochastic vector containing the prices of the underlying assets. $S_i,i=1,...,n$. If we assume $S$ follows n-dimensional GBM, the change in the value of the derivative, $df$, is (2.5.8) given by

```
$df = \frac{\partial f}{\partial t} + \sum_{i=1}^n \mu_i \frac{\partial f}{\partial S_i} + \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_{ij}S_iS_j\rho_{ij}\frac{\partial^2 f}{\partial S_i\partial S_j}dt + \sum_{i=1}^n \frac{\partial f}{\partial S_i}S_idW_i.\(4.4.16)
```

The discretized version of this equation is

```
$$\Delta f = \frac{\partial f}{\partial t} + \sum_{i=1}^n \mu_i \frac{\partial f}{\partial S_i} + \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_{ij}S_iS_j\rho_{ij}\frac{\partial^2 f}{\partial S_i\partial S_j}\Delta t + \sum_{i=1}^n \frac{\partial f}{\partial S_i}S_id\Delta W_i.\(4.4.17)
```

where the time interval is now $\Delta t$ and the change in derivative value is $\Delta f$.

Let us consider a portfolio consisting of $n$ derivatives of the $i$th underlying stock. In other words, we have short (that is sold) a derivative that depends on the price $S_i,i=1,...,n$, of $n$ underlying assets and have $\partial f/\partial S_i$ units of the $i$th asset. ```

```

and the change, $\Delta\Pi$, in the value of the portfolio over the time interval $\Delta t$ is

```
$$\Delta\Pi = -\Delta f + \sum_{i=1}^n \frac{\partial f}{\partial S_i}\Delta S_i.\(4.4.19)

## 4.4.3 The Black–Scholes Formula

The Black–Scholes model consists of two assets, the riskless money account and equity can be cast as the following two-dimensional equation:

```
$dS_t = \mu S_t dt + \sigma S_t dW^P,
$dB_t = r B_t dt, \(4.4.26)
```

where $W^P$ is Brownian motion (without drift) under measure $\mathbb{P}$, so $dW^P \sim N(0,dt)$. Current time is denoted by $t_0$, and the option maturity by $T$. The money account has value $B_{t_0}=1$ at time $t_0$ and $B_T = \exp(r(T-t_0))$ at time $T$. We will now consider the process by the relative value $\phi(S_t, B_t) = S_t/B_t$. Using the quotient rule described in Section 2.6 and substituting $X_1 = S_t$ and $X_2 = B_t$ in equation (2.6), we have

```
$d\left(\frac{S_t}{B_t}\right) = \left(\frac{S_t}{B_t}\right)(\mu - r)dt + \left(\frac{S_t}{B_t}\right)\sigma dW^P.
```

So finally we can write

```
$dS_t^* = S_t^*(\mu - r)dt + S_t^*\sigma dW^P, \(4.4.27)
```

where $S_t^* = S_t/B_t$. Referring to Girsanov's theorem in Section 2.4, we can choose a probability measure $\mathbb{Q}$ such that

```
$dW^P = dW^Q - \left(\frac{\mu - r}{\sigma}\right)dt, \(4.4.28)
```

In equation (2.4), we have $k(t) = -\left(\frac{\mu - r}{\sigma}\right)$ and

```
\frac{dQ}{d\mathbb{P}} = \exp\left\{-\left(\frac{\mu - r}{\sigma}\right)W^P - \frac{1}{2}\left(\frac{\mu - r}{\sigma}\right)^2\right\}, \(4.4.29)
```

see Musiela and Rutkowski (1998). Substituting for $dW^P$ in equation (4.4.27) yields

```
$dS_t^* = S_t^*(\mu - r)dt - S_t^*\left(\frac{\mu - r}{\sigma}\right)dt + S_t^*\sigma dW^Q,
```

which simplifies to

```
$dS_t^* = S_t^*\sigma dW^Q. \(4.4.30)
```

Equation (4.4.30) means that the process for $S_t^*$ is a martingale under probability measure $\mathbb{Q}$. Replacing $dW^P$ with the value in equation (4.4.28) yields

```
$dS_t = \mu S_t dt + \sigma S_t dW^P,
$= \mu S_t dt + S_t\left\{dW^Q - \left(\frac{\mu - r}{\sigma}\right)dt\right\}$,
$= \left\{S_t dt - S_t\left(\frac{\mu - r}{\sigma}\right)\right\}dt + S_t\sigma dW^Q.
```

So in the risk-neutral measure $Q$, the dynamics of $dS$ are

```
$dS_t = S_t r dt + S_t \sigma dW_t. \(4.4.31)
```

Comparing equation (4.4.31) with the original equation in (4.4.26), we see that changing from the real world to the risk-neutral measure simply substituting $dW^Q$ for $dW^P$ and $r$ for $\mu$.

We can now solve equation (4.4.31) by using the result given in equation (2.3.11). We have

```
$S_T = S \exp(r(T-t_0) + \sigma W^Q_{T-t_0}),
```

where $S$ is the asset price at current time $t_0$, and $r = -\sigma^2/2$. From Appendix D.2, we have

```
$S(t_0, T) = E[S_T] = S \exp(r(T-t_0)). \(4.4.32)
```

Using equation (2.3.9), the distribution of the asset price at time $T$ is

```
\log\left(\frac{S_T}{S}\right) \sim N(r(T-t_0), \sigma^2(T-t_0)). \(4.4.33)
```

We want to obtain the price of a vanilla European option with strike price $E$ which matures at future time $T=T-t_0$. The approach we will adopt is to first derive an expression for the value of a European call option and then use the put/call relationships of Section 2.2 to obtain the value of the corresponding European put option.
