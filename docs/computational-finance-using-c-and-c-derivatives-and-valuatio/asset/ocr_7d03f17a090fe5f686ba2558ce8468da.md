B. The probability that the option has not been knocked out between times $t_1$ and $t_2$ is therefore

```
$P(m^Z > b|Z_{t_1}, Z_{t_2}) = 1 - \exp\left\{ -\frac{2(\log(B) - \log(S_{t_1}))(\log(B) - \log(S_{t_2}))}{\sigma^2 \Delta t} \right\.\\n(4.5.20)
```

This means that for the (complete) $ith$ scenario path, of $n$ time steps, the probability that $m^Z > b$ is

```
$BB_C^i = \prod_{j=0}^{n-1} \left\{ 1 - \exp\left\{ -\frac{2(\log(B) - \log(S_{t_j}^i))(\log(B) - \log(S_{t_{j+1}}^i))}{\sigma^2 \Delta t} \right\ \right\}$
```

where $S_t^i$ is the $ith$ scenario asset price at time $t_i$.\nnThe basic Monte Carlo $ith$ scenario option value $DO_i$ can therefore be adjusted as

```
$DO_i^i = DO_i BB^c$.
```

and the New Monte estimate $DO^*$ is

```
$DO^* = \frac{\sum_{i=1}^{Scenarios} DO_i^*}{Scenarios}$
```
