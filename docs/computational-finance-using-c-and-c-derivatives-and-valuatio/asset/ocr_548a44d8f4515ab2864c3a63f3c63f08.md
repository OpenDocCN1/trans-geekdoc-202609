Discount factors and forward rates are accessed from an ICur object. The discount factor is obtained as follows:

```
ICur DF = MarketDataDictionaries.
CurrencyTable[Currency].YieldCurve;
```

declares the ICur object DF. The discount factor, between  and Time_To_Expiry... is computed with the

```
double discount_fac = DF(0, Time_To_Expiry);
```

where DF[0, Time_To_Expiry] calls the ICur accessor (declared as public double this[double t0, double t1] with t0 = 0 and t = Time_To_Expiry. It can be seen from Code excerpt 8.3 that linear interpolation is performed by the accessor.

The forward rate is accessed in a similar manner:

```

CurrencyTable[Currency].YieldCurve;

declares the ICur object FWD. Then the forward rate F(0,t1,t2) is returned with the statement

```

where FWD[0, t1, t2] calls the ICur accessor (declared as public double this[double t1, double t2]) with t = 0.0.5, and t2 = 1.5. It can be seen from Code excerpt 8.3 that the accessor computes the forward rate
