# Vega Section | A.6 305

For a European put, we have

```
$$\rho_p = \frac{\partial p}{\partial r}=\frac{\partial}{\partial}\{E\exp(-r(T-t))(1-N_1(d_2)) - S\exp(-q(T-t))(1-N_1(d_2))\}\n= -E(T-t)(1-N_1(d_2)) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial r}\n+S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial r}\n= -E(T-t)N_1(-d_2) - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial r}}\n+S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial r}$.$
```

substituting for $n(d_2)$ and $\partial d_2/\partial r$, we obtain

```
$$\rho_p = -E(T-t)N_1(-d_2).\quad (A.5.2)$
```

# A.6 VEGA

Vega is the rate of change of option value with volatility. For a call, we have

```
$$\mathcal{V}_c = \frac{\partial c}{\partial \sigma}\quad (A.6.1)\n= \frac{S\exp(-q(T-t))N_1(d_1) - E\exp(-r(T-t))N_1(d_2)}{\partial \sigma}}\n= S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial \sigma}} - E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial \sigma}.$
```

substituting for $n(d_2)$ and $\partial d_1/\partial \sigma$, we obtain

```
$$\mathcal{V}_c = S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial \sigma}} - S n(d_1)\exp(-q(T-t))\frac{\partial d_1}{\partial \sigma}} - \sqrt{T-t}.\$
```

Therefore,

```
$$\mathcal{V}_p = S\exp(-q(T-t))n(d_1)\sqrt{T-t}.\quad (A.6.2)$
```

For a European put, we have

```
$$\mathcal{V}_p = \frac{\partial c}{\partial \sigma}\quad (A.6.3)\n= \frac{\partial}{\partial \sigma}\{E\exp(-r(T-t))(1-N_1(d_2)) - S\exp(-q(T-t))(1-N_1(d_1))}\}\n= -E\exp(-r(T-t))n(d_2)\frac{\partial d_2}{\partial \sigma}} + S\exp(-q(T-t))n(d_1)\frac{\partial d_1}{\partial \sigma}};$
```

substituting for $n(d_2)$ and $\partial d_2/\partial \sigma$, we obtain

```
$$\mathcal{V}_p = S\exp(-q(T-t))n(d_1)\sqrt{T-t},\quad (A.6.4)$
```

which is the same as for a call.
