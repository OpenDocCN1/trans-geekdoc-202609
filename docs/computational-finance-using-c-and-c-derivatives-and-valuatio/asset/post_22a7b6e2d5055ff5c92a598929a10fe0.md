### Compute the Monte Carlo Estimate

The Monte Carlo estimate, $\theta_H$, is computed as the average of $\theta_{H,p} = 1,\dots,nsim$, where $nsim$ is the number of simulations,

```
$$\theta_H = \frac{\sum_{i=1}^{nsim} \theta_{H,i}}{nsim}$$
```

Below, in Code 5.21, we provide a computer program that prices single american asset put and calls using a stochastic lattice. The method used by the program is the depth first procedure outlined in Broadie and Glasserman (1997), which has the advantage that the memory requirements are of order $b \times d$; as $b$ is the number of branches per node and $d$ is the number of times interact.

Here, it is assumed the underlying asset follows GBM and the function normal(M, S) to generate a normal distribution with mean $M$ and standard deviation $S$. We can then check the accuracy of the simulation obtained by a closed solution follows a lognormal distribution, in which case we use formula from Geske and Johnson (1984).

However, the real power of this method is when the underlying asset follows a non-Gaussian and time varying. The only realistic modification to the code is to replace the normal with that of another probability distribution and supply the time varying parameters to it.
