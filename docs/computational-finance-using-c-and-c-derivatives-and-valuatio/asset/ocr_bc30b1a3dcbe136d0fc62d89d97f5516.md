# B.2 THE UP AND OUT CALL

We will derive the formula for a European up and out call option with yield $q$ when the strike, satisfies $B > E$.

```
$c_{uo} = \frac{\exp(-r\tau)}{\sigma\sqrt{\tau}}\frac{\log(B/S)}{\log(E/S)}\{S\exp(X) - E\f(X < B)dX.$ (B.2.1)
```

Substituting for $f(X < B)$, we have $c_{uo} = I_A + I_B$,

```
$I_A = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}}\frac{\log(B/S)}{\log(E/S)}\{S\exp(X) - E\}\exp\left(-\frac{X - (r - q - \sigma^2/2)\tau}{2\sigma^2\tau}\right)dX$
```

and

```
$I_B = \frac{\exp(-r\tau)}{\sigma\sqrt{2\pi}}\frac{\log(B/S)}{\log(E/S)}\{S\exp(X) - E\}\exp\left(-\frac{X - (r - q - \sigma^2/2)\tau}{2\sigma^2\tau}\right)\n\exp\left(\frac{\log(B/S)(X - \log(B/S))}{\sigma^2\tau}\right)dX.$
```
