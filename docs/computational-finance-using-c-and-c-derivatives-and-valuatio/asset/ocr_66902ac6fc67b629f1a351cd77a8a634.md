# The Up and Out Call Section | B.2 311

Let $I_A = I_1 + I_2$, where

```
$I_1 = \frac{S \exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{\log(B/S)}^{\log(E/S)} \exp(X) \exp\left(-\\{{X-(r-q-\sigma^2/2)\tau\}^2\right) dX$
```

and

```
$I_2 = \frac{-E \exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{-\log(E/S)}^{\log(B/S)} \exp\left(-\{\{X-(r-q-\sigma^2/2)\tau\}^2\right) dX$
```

From our previous derivation of the Black–Scholes formula in Chapter 4, we have

```
$I_1 = \frac{S \exp(-q\tau)}{\sigma \sqrt{2\pi}} \int_{k_1}^{k_2} \exp\left(-\frac{u^2}{2}\right) du = S \exp(-q\tau) \N_1(k_2) - N_1(k_1)\}$,
```

where

```
$k_1 = \frac{\log(E/S)-(r-q+\sigma^2/2)\tau}{\sigma \sqrt{\tau}}$
```

and

```
$k_2 = \frac{\log(B/S)-(r-q+\sigma^2/2)\tau}{\sigma \sqrt{\tau}}$
```

```
$I_2 = \frac{-E \exp(-r\tau)}{\sigma \sqrt{2\pi}} \int_{k_3}^{k_4} \exp\left(-\frac{u^2}{2}\right) du = -E \exp(-r\tau) \{N_1(k_4) - N_1(k_3)\}$,
```

where

```
$k_3 = \frac{\log(E/S)-(r-q-\sigma^2/2)\tau}{\sigma \sqrt{\tau}}$
```

and

```
$k_4 = \frac{\log(B/S)-(r-q-\sigma^2/2)\tau}{\sigma \sqrt{\tau}}$
```

Therefore,

```
$I_A = S \exp(-q\tau) \N_1(k_2) - N_1(k_1) - E \exp(-r\tau) \{N_1(k_4) - N_1(k_3)\}$,
```

Since $N_1(-x) = 1 - N_1(x)$, we have

```
$N_1(k_2) - N_1(k_1) = N_1(-k_1) - N_1(-k_2)$
```

so

```
$I_A = S \exp(-q\tau) \N_1(d_1) - N_1(d_2) - E \exp(-r\tau) \{N_1(d_3) - N_1(d_4)\}$,
```

```
= S \exp(-q\tau) \N_1(d_1) - E \exp(-r\tau) \N_1(d_2) + E \exp(-r\tau) \N_1(d_4)$,
```

which gives

```
$I_A = c - S \exp(-q\tau) \N_1(d_2) + E \exp(-r\tau) \N_1(d_4). \quad (B.2.2)
```
