
required (i.e., daily, hourly...), but will always maintain a set of deatiled market values that can be used consistently across all devaluations.

It should be noted that the main advantage of type E1 deal entries is not just that the portfolio definition is smaller, but also ensures that market values are used to price all the trades in the portfolio. When type E2 deal entries are used, it is necessary to ensure that all the extra attributes are updated as new market data becomes available. This may be a time-consuming process, and if a partial update occurs it could rise to invalid devaluations caused by inconsistent attribute values such as FXEquityCurrency and DividendYield.
