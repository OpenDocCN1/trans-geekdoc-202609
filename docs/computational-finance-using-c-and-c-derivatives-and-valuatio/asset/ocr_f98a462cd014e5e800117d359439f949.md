# Compute the Option Payoff at the Terminal Nodes

The current value of an option is evaluated by starting at option maturity, the end of the tree, and working backwards. The option values for the terminal nodes of tree are given by the payoff (at maturity) of the option; this is independent of whether the option is an American or European. For a lattice with $n$ time steps, there are $n+1$ terminal nodes, with option values, $f_{n,j} = 0, \dots, n$.

To compute the values of vanilla American and European options, $E$ we will start with the following terminal node values: for put options,

> $f_{n,j} = \max(Su^j d^{n-j} - E, 0), \quad j = 0, \dots, n$

and for call options,

> $f_{n,j} = \max(E - Su^j d^{n-j}, 0), \quad j = 0, \dots, n$
