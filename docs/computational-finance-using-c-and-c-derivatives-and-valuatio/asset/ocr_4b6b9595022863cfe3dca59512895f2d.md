It can be shown

```
$\Sigma_{i,j} = \log\left(1 + \frac{S_{i,j}}{\tilde{m}_i\tilde{m}_j}\right) \quad (3.4.7)$
```

and

```
$\mu_i = \log(\tilde{m}_i) - \frac{\Sigma_{i,i}}{2}, \quad i=1, \dots, p, \quad j=1, \dots, p. \quad (3.4.8)$
```

For the case of independent variables, we then have

```
$\mu_i = \log(\tilde{m}_i) - \frac{\sigma_i^2}{2}, \quad i=1, \dots, p$
```

and

```
$\Sigma_{i,i} = \sigma_i^2 = \log\left(1 + \frac{S_{i,i}}{\tilde{m}_i^2}\right), \quad i=1, \dots, p \text{ and for } i \neq j, \Sigma_{i,j}=0$,
```

which are just (3.3.13) and equation (3.3.14) given in Section 3.3.2.
