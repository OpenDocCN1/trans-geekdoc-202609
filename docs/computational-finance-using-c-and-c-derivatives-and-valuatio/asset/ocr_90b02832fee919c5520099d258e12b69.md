# CHAPTER 2 Introduction to Stochastic Processes

We have shown that if the asset price follows GBM, the logarithm of the asset price follows standard Brownian motion. Another way of stating this is, over the time $dt$, the change in the logarithm of the asset price is a Gaussian distribution with mean $[\mu - (\sigma^2/2)]$ and variance $\sigma^2dt$.
These results can be generalized to include time varying drift and volatility. Instead of equation (2.2.3) we have

```
$dS_t = S_{t_0}dt + \sigma_t dW_t$
```

which results in

```
$d(\log(S_t)) = v_t dt + \sigma_t dW_t$
```

so

```
$$\int_{t_0}^T d(\log(S_t)) = \int_{t_0}^T v_t dt + \int_{t_0}^T \sigma_t dW_t$.$
```

which results in the following solution for $S_T$:

```
$S_T = S_{t_0} \exp(\int_{t_0}^T v_t dt + \int_{t_0}^T \sigma_t dW_t), \text{ where } v_t = \mu_t - \frac{\sigma_t^2}{2}$.
```

The results presented in equation (2.3.11) and equation (2.3.14) are very important and will be referred to in later sections of the book.

# 2.4 GIRSANOV'S THEOREM

This theorem states that for any stochastic process $k(t)$ such that $\int_0^t k(s)^2 ds < \infty$ then the Radon Nikodym derivative $dQ/d\mathbb{P} = \rho(t)$ is given by

```
$$\rho(t) = \exp(\int_0^t k(s)dW_s - \frac{1}{2} \int_0^t k(s)^2ds),$$
```

where $W_t^P$ is also Brownian motion (possibly with drift) under probability measure $\mathbb{P}$, we have Baxter and Rennie (1996). Under probability measure $\mathbb{Q}$, we have

```
$W_t^Q = W_{t_0}^P - \int_0^t k(s)ds$,
```

where $W_t^Q$ is also Brownian motion (possibly with drift).
We can also write

```
$dW^P = dW^Q + k(t)dt$.
```

Girsanov's theorem provides a mechanism for changing the drift of a Brownian motion.
