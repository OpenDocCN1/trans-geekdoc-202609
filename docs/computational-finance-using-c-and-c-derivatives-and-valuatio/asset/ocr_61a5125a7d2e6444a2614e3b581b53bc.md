# 188 CHAPTER | 6 Multi-asset Options

is_max - if is_max is 1 then the option is a call on the maximum of two assets, otherwise the option is a call on the minimum of two assets.

Output parameters:

```
opt_value      - the value of the option;
flag           - an error indicator.
```
