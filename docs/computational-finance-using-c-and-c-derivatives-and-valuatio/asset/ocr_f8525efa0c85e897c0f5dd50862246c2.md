# 2.6.1 Ito Product Rule

Here, $\phi = \phi(X_1X_2)$ and the partial derivatives are as follows:

```
$$\frac{\partial \phi}{\partial X_1} = X_2, \quad \frac{\partial \phi}{\partial X_2} = X_1\frac{\partial^2 \phi}{\partial X_1^2} = \frac{\partial^2 \phi}{\partial X_2\partial X_2} = 0, \quad \frac{\partial^2 \phi}{\partial X_1\partial X_2} = \frac{\partial^2 \phi}{\partial X_2\partial X_1} = 1$.
```

Therefore, using (2.6.1),

```
$d\phi = X_2dX_1 + X_1dX_2 + \frac{2E[dX_1dX_2]}{2}$
```

and the product rule is

```
$d(X_1X_2) = X_2dX_1 + X_1dX_2 + E[dX_1dX_2]. (2.6.2)
```

# Brownian Motion with One Source of Randomness

For the special case where $X_1$ is Brownian motion and $X_2$ has no random term, we have

```
$dX_1 = X_1\mu_1dt + X_1\sigma_1dW_1 \quad dX_2 = X_2\mu_2dt$.
```

Now

```
$E[dX_1dX_2] = E[X_1\mu_1dt + X_1\sigma_1dW_1] X_2\mu_2dt$\n= X_1X_2\mu_1\mu_2dt^2 + X_1X_2\sigma_1\mu_2dtE[dW_1]$\n= 0$.
```

where we have ignored terms in $dt$ with order higher than 1 and used $E[dW_1]$.

Therefore, equation (2.6.2) becomes

```
$d(X_1X_2) = X_2dX_1 + X_1dX_2$\n$d(X_1X_2) = X_2(X_1\mu_1dt + X_1\sigma_1dW_1) + X_1X_2\mu_2dt$.
```

So, we finally obtain

```
$d(X_1X_2) = (X_1X_2)\{\mu_1 + \mu_2\}dt + (X_1X_2)\sigma_1dW_1. (2.6.3)
```

# 2.6.2 Ito Quotient Rule

Here, $\phi = \phi(X_1/X_2)$ and the partial derivatives are as follows:

```
$$\frac{\partial \phi}{\partial X_1} = \frac{1}{X_2}, \quad \frac{\partial \phi}{\partial X_2} = -\frac{X_1}{X_2^2}\frac{\partial^2 \phi}{\partial X_1^2} = 0, \quad \frac{\partial^2 \phi}{\partial X_2^2} = \frac{2X_1}{X_2^3}, \quad \frac{\partial^2 \phi}{\partial X_1\partial X_2} = \frac{1}{X_2^2}, \quad \frac{\partial^2 \phi}{\partial X_2\partial X_1} = -\frac{1}{X_2^2}$.
```

Therefore, using equation (2.6.1),

```
$d\phi = \frac{dX_1}{X_2} - X_1\frac{dX_2}{X_2^2} + \frac{1}{2}E\left{\{\frac{2X_1}{X_2^3}dX_2 - 2\frac{dX_1dX_2}{X_2^2}\}$\right]$.
```
