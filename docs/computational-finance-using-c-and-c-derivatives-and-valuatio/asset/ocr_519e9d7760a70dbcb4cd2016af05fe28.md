# ## 4.5.4 Monte Carlo Pricing of Down and Out Options

In this section, we show how Monte Carlo simulation can be used to price down and out options. We will describe both a basic Monte Carlo approach and also a Brownian bridge method which gives more accurate results, see Chapter.

The asset price, $S$, will be assumed to be GBM, the logarithm of the asset price $Z$ follows the Brownian process

```
$$\Delta Z = v\Delta t + \sigma\Delta W_t,$$ (4.5.18)
```

where $v$ is the drift and $\sigma$ is the volatility.

If the barrier level is $B$, then the option will be knocked out when $S \le B$, or equivalently $\log(S) \le \log(B)$. This will be expressed as $Z \le b$, where $b = \log(B)$.

The basic approach to simulating the down and out option is to decide how many TimeSteps are to be in each scenario. The size of each step is $time\step TimeToExpiry/TimeSteps$. For each scenario, the path of $Z_t$ is advanced in time from $t$ to $t+\Delta t$ using $dt = time\step$ and a value for $\Delta W_t$ from a Gaussian random number. Construction is stopped if the option expiry time is reached or if the option is knocked out, i.e., $Z \le b$. If the option is knocked out before expiry, the payoff for that scenario is zero. We will denote the option value obtained from the $i$th scenario as $DO_i$. The option value is the average value of $DO_i$ over all scenarios – see Code excerpt 4.8.

One problem with this approach to simulation is that it does not take into account the possibility that $Z_t \le b, t < t+\Delta t$, even though $Z_{t+\Delta t} > b$. In such circumstances, the option should be treated as knocked out, since $Z hit (or crossed) the barrier $b$ at time $\tau$, but then increased to the value $Z_{t+\Delta t}$ at time $t+\Delta t$.
