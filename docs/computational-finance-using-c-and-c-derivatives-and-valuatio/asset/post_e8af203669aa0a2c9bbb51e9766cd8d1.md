## H.4 PROOF OF EQUATION (H.1.5)

We know that $P(\tilde{X}_t \ge K) = 1 - P(\tilde{X}_t \le K)$.

## APPENDIX Brownian Motion: More Results

It can be seen from Section 2.4 that the transformation between measures $\mathbb{P}$ and $\mathbb{Q}$ can be accomplished using $k=v/\sigma$, and the associated Radon–Nikodym derivative is

$$\frac{dQ}{d\mathbb{P}} = \exp\left(kW_t^P - \frac{1}{2}k^2t\right)$$
$$= \exp\left(\frac{v}{\sigma}W_t^P - \frac{1}{2}\frac{v^2t}{\sigma^2}\right)$$
$$= \exp\left(\frac{v}{\sigma^2}X_t - \frac{1}{2}\frac{v^2t}{\sigma^2}\right), \quad (H.5.5)$$

where we have used fact that under probability measure $\mathbb{P}$, we can write $W_t^P = X_t/\sigma$.
Now

$P(m_t^X \leq b, \bar{X}_t \geq x) = E^{\mathbb{P}}\left[\{m_t^X \leq b\}\}\{\bar{X}_t \geq x\}\right], \quad (H.5.6)$

where $[condition]$ is an indicator function that takes unit value when condition is satisfied and zero otherwise – for example, $[m_t^X \leq b]$ is one when $m_t^X \leq b$ and zero when $m_t^X > b$.
However, for example Baxter and Rennie (1996), we have

$E^{\mathbb{Q}}\left[\{m_t^X \leq b\}\}\{\bar{X}_t \geq x\}\right] = E^{\mathbb{P}}\left[\{m_t^X \leq b\}\}\{X_t \geq x\}\right]\frac{dQ}{d\mathbb{P}}$

So substituting for $\frac{dQ}{d\mathbb{P}}$ from equation (H.5.5) gives

$E^{\mathbb{Q}}\left[\{m_t^X \leq b\}\}\{\bar{X}_t \geq x\}\right] = E^{\mathbb{P}}\left[\{m_t^X \leq b\}\{X_t \geq x\}\exp\left(\frac{vX_t}{\sigma^2} - \frac{v^2t}{\sigma^2}\right)\right], \quad (H.5.8)$

Expressed in terms of the reflected Brownian motion, $X_t^R = 2b - X_t$, can be written

$P(m_t^X \leq b, \bar{X}_t \geq x) = E^{\mathbb{P}}\left[\{2b-X_t^R \geq x\}\{\exp\left(\frac{v(2b-X_t^R)}{\sigma^2} - \frac{v^2t}{\sigma^2}\right)\right]$
$$= \exp\left(\frac{vb^2}{\sigma^2}\right)E^{\mathbb{P}}\left[\{2b-X_t^R \geq x\}\{\exp\left(\frac{vX_t^R}{\sigma^2} - \frac{v^2t}{\sigma^2}\right)\right], \quad (H.5.9)$

Since equation (H.5.9) becomes

$\{2b-X_t^R > x\} = \{2b+X_t^R < x\} = \{X_t^R < 2b-x\}$.
$P(m_t^X \leq b, \bar{X}_t \geq x) = E^{\mathbb{P}}\left[\exp\left(\frac{vb^2}{\sigma^2}\right)\left\{X_t^R < 2b-x\}\right], \quad (H.5.10)$
where, by notation, we denote $X_t^R$ by $X_t$ on the right-hand side of equation (H.5.10).
