# Equity Swap

A special case of an equity TRS is an equity swap. Here, one party (say A) pays the total returns on one equity and receives one (from party B) the returns on another equity, with the interest on the net difference of the last reset notion of the two equity assets. An equity swap, ESWP, can be constructed from a long position in one equity TRS and a short position in another, with the same payment dates and currency. If the individual equity TRS deals are denoted by $ETRS^p_1$ and $ETRS^p_2$, then the value of the equity swap at time $t$ is

```
$ESWP(t) = ETRS^p_1(t) - ETRS^p_2(t). \quad (7.5.9)$
```

