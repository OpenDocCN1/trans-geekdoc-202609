# Some Elementary Results Involving the Mean and Variance of Normal Distribution

From first principles, we have the following:

The mean:

```
$E[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{x=-\infty}^{\infty} x \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx$.
```

Let $x = x - \mu$ we have $dx = dy$ and $y = y + \mu$; therefore,

```
$E[x] = \frac{1}{\sigma\sqrt{2\pi}} \int_{y=-\infty}^{\infty} (y + \mu) \exp\left(-\frac{y^2}{2\sigma^2}\right)dy$.
```

```
$E[x] = \mu \frac{1}{\sigma\sqrt{2\pi}} \int_{y=-\infty}^{-\mu} \exp\left(-\frac{y^2}{2\sigma^2}\right)dy + \frac{1}{\sigma\sqrt{2\pi}} \int_{y=\mu}^{\infty} y \exp\left(-\frac{y^2}{2\sigma^2}\right)dy$.
```

Since

```
$$\int_{-\infty}^{\infty} y \exp\left(-\frac{y^2}{2\sigma^2}\right)dy = 0$,
```

we have using the integral result (1) in Appendix E.1 with $a=1/2\sigma^2$,

```
$E[x] = \mu \frac{1}{\sigma\sqrt{2\pi}} \int_{y=-\infty}^{\infty} \exp\left(-\frac{y^2}{2\sigma^2}\right)dy = \mu$.
```

The variance:

```
$E[x^2] = \frac{1}{\sigma\sqrt{2\pi}} \int_{x=-\infty}^{\infty} x^2 \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)dx$.
```

Let $y = x - \mu$ we have $dx = dy$ and $x^2 = y^2 + 2\mu y + \mu^2$; therefore,

```
$E[x^2] = \frac{1}{\sigma\sqrt{2\pi}} \int_{y=-\infty}^{\infty} (y^2 + 2\mu y + \mu^2) \exp\left(-\frac{y^2}{2\sigma^2}\right)dy$.
```

```
$E[x^2] = \mu^2 \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} \exp\left(-\frac{y^2}{2\sigma^2}\right)dy + \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{\infty} y^2 \exp\left(-\frac{y^2}{2\sigma^2}\right)dy$.
```
