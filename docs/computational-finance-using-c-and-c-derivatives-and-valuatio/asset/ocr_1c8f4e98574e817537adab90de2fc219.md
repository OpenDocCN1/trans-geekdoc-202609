# 4.4.2 The Multi-asset Option Pricing Partial Differential Equation

In this section we will derive the multi-asset (Black–Scholes) partial differential equation that is obtained by options on n assets. Proceeding in Section 4.4.1 we will use the n-dimensional version of Ito’s lemma to find the process followed by the value of a multi-asset financial derivative. We will denote the value of this derivative by $f(S,t)$, where $S$ is an n-element stochastic vector containing the prices of the underlying assets. $S_i,i=1,...,n$. If we assume $S$ follows n-dimensional GBM, the change in the value of the derivative, $df$, is (2.5.8) given by

```
$df = \frac{\partial f}{\partial t} + \sum_{i=1}^n \mu_i \frac{\partial f}{\partial S_i} + \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_{ij}S_iS_j\rho_{ij}\frac{\partial^2 f}{\partial S_i\partial S_j}dt + \sum_{i=1}^n \frac{\partial f}{\partial S_i}S_idW_i.\n(4.4.16)
```

The discretized version of this equation is

```
$$\Delta f = \frac{\partial f}{\partial t} + \sum_{i=1}^n \mu_i \frac{\partial f}{\partial S_i} + \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \sigma_{ij}S_iS_j\rho_{ij}\frac{\partial^2 f}{\partial S_i\partial S_j}\Delta t + \sum_{i=1}^n \frac{\partial f}{\partial S_i}S_id\Delta W_i.\n(4.4.17)
```

where the time interval is now $\Delta t$ and the change in derivative value is $\Delta f$.\nLet us consider a portfolio consisting of $n$ derivatives of the $i$th underlying stock. In other words, we have short (that is sold) a derivative that depends on the price. $S_i,i=1,...,n$, of $n$ underlying assets and have $\partial f/\partial S_i$ units of the ith asset. The value of the portfolio, $\Pi$, is therefore

```
$$\Pi = -f + \sum_{i=1}^n \frac{\partial f}{\partial S_i}S_i,\n(4.4.18)
```

and the change, $\Delta\Pi$, in the value of the portfolio over the time interval $\Delta t$ is

```
$$\Delta\Pi = -Delta f + \sum_{i=1}^n \frac{\partial f}{\partial S_i}\Delta S_i.\n(4.4.19)
```
