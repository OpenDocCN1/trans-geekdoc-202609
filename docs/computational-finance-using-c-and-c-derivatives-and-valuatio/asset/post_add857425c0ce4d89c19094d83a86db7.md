
## CHAPTER 5 Single Asset American Options

The iterative algorithm for the American put is therefore

```
$S_{i}^{**} = \frac{E - RHS(S_{i}^{**}, E, \tau)}{1 + b_i} + b_i S_{i}^{**} \quad (5.2.37)
```

where we can use $S_{0}^{**} = E$ for the initial estimate of the critical asset value (see the computer code except below).

## The Expression for $b_i$

Here, we derive an expression for the term $b_i$ which is used in equation (5.2.37). Since

```
$b_i = \frac{\partial}{\partial S_{i}^{**}} p(S_{i}^{**}, E, \tau) - \frac{S_{i}^{**}}{\gamma_1} (1 - \exp(-q\tau)) + N_1(d_1(S_{i}^{**})) \exp(-q\tau))$
```

we have

```
$b_i = \frac{\partial p(S_{i}^{**}, E, \tau)}{\partial S_{i}^{**}} - \frac{1}{\gamma_1} \{1 - \exp(-q\tau)\} - \frac{1}{\gamma_1} \exp(-q\tau) N_1(d_1(S_{i}^{**})) \\ \frac{\exp(-q\tau) N_1(d_1(S_{i}^{**}))}{\partial d_1(S_{i}^{**})}{\gamma_1} \frac{\partial d_1(S_{i}^{**})}{\partial S_{i}^{**}}$
```

We now quote the following results which are derived in Appendix A:

- Appendix A, equation (A.1.3): $\frac{N(d_1(S_{i}^{**}))}{\partial d_1(S_{i}^{**})} = n(d_1(S_{i}^{**}))$
- Appendix A, equation (A.1.6): $\frac{1}{\partial S_{i}^{**}} = \frac{1}{S_{i}^{**}} \sigma \sqrt{\tau}$
- Appendix A, equation (A.3.4): $\Delta_p = \frac{\partial p(S_{i}^{**}, E, \tau)}{\partial S_{i}^{**}} = \exp(-q\tau) \{N_1(d_1(S_{i}^{**})) - 1\}$

Substituting these results into the above expression, we obtain

```
$b_i = \exp(-q\tau) \{N_1(d_1(S_{i}^{**})) - 1\} - \frac{1}{\gamma_1} \{\exp(-q\tau) + N_1(d_1(S_{i}^{**})) \exp(-q\tau)\} \\ \frac{\exp(-q\tau) N_1(d_1(S_{i}^{**}))}{\partial d_1(S_{i}^{**})}{\gamma_1} \frac{\partial d_1(S_{i}^{**})}{\partial S_{i}^{**}}$
```

```
$=\exp(-q\tau) \{N_1(d_1(S_{i}^{**})) - 1\} - \frac{1}{\gamma_1} \{\exp(-q\tau) + N_1(d_1(S_{i}^{**})) \exp(-q\tau)\}
```

```
$-\frac{S_{i}^{**} \exp(-q\tau) n(d_1(S_{i}^{**}))}{\gamma_1 \sigma \sqrt{\tau}},
```

which can be rearranged to yield

```
$b_i = \exp(-q\tau) \{N_1(d_1(S_{i}^{**})) - 1\} \frac{1}{\gamma_1} + \frac{1}{\gamma_1} \{\exp(-q\tau) - 1 - \frac{\exp(-q\tau) n(d_1(S_{i}^{**}))}{\sigma \sqrt{\tau}}\} \exp(-q\tau)\}quad (5.2.38)$
```

    sigma           - volatility
    t               - time to maturity
    r               - interest rate
    q               - continuous dividend yield
    put             - if put is 0 call option, otherwise a put option
    Output parameters:
    opt_value       - value of the option
    critical_value  - critical value
    error           - an indicator
}

    double di1, alpha, h2, temp1;

    pi = PI;
    beta = 2.0 * (r - q) / (sigma * sigma);
    alpha = 2.0 * r / (sigma * sigma);
    temp = 1.0 * exp(-t);
    sol = 0.0;
    iter = 0;
    tol = 1e-6;
    if (put) { // American call
        gamma_2 = sqrt(temp + (4.0/alpha));
        gamma_2 = 2.0 / gamma_2;
    } else { // American put
        while (iter < 5) { // iteratively
            di = log(S/x) + (r - q-sigma/2.0)*t / (sigma*sqrt(t));
            di1 = di + sigma*sqrt(t);
            pdf = (1.0*exp(-di1*di1/2.0))/sqrt(2*PI);
            temp = (temp*temp)*(1.0 - (1/gamma_2));
            temp = (1.0 - (exp/pdf(sigma*sqrt(temp))))/gamma_1;

            rhs = s_star*exp(-q*t)-exp(-r*t)*cum_norm(di1)*s_star/gamma_1;
            s_star = x*exp(-r*t)*rhs;
            err = fabs(s_star-x) - rhs;
            if (err < tol) break;
            iter++;
        }
        A_2 = (s_star/gamma_2)*exp(-temp)*cum_norm(di1);
        if (s_0 > s_star) { // American call
            temp = 1.0;
            black_scholes(&err, s_0,sigma, T,r,q,put);
            opt_value = s_0 + pow(temp,gamma_2);
        } else { // American put
            gamma_1 = sqrt(temp + (4.0/alpha));
            gamma_1 = 2.0 / gamma_1;
            iter = 0;
            while (iter < 5) { // calculate S, iteratively
                di = log(S/x) + (r - q-sigma/2.0)*t / (sigma*sqrt(t));
                di1 = di + sigma*sqrt(t);
                pdf = (1.0*exp(-di1*di1/2.0))/sqrt(2*PI);
                temp = (temp*temp)*(1.0 - (1/gamma_1));
                temp = (1.0 - (exp/pdf(sigma*sqrt(temp))))/gamma_1;
                h2 = temp;
            }
            // calculate the Black-Scholes value of a put
            black_scholes(&err, s_star,sigma, T,r,q,put);
            rhs = s_star*(1.0-exp(-q*t))-exp(-temp)*cum_norm(di1)*s_star/gamma_1;
            s_star = x*exp(-r*t)*rhs/x;
            err = fabs(s_star-x) - rhs;
            if (err < tol) break;
            iter++;
        }
        opt_value = -s_star;
}
