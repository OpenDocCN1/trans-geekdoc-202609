## 8.4 FX CLASSES

Here, we provide code for valuing derivatives. The FX option routines are very similar to the equity option routines we have already considered. The FX routine calls the Black-Scholes routine with the dividend yield set to the foreign currency risk-free interest rate, and the supplied volatility is that of the foreign/domestic exchange rate. In the market data file, the currency FX spot rates are with respect to the base currency.

### 8.4.2 FX Option

The code for the single FX option (see Code excerpt 13) is very similar to that for the equity option. For example, European equity options are priced using `PricingUtils.black_scholes(ref vol)` while European FX options use `PricingUtils.black_scholes(ref vol, Zero, Strike, f_d, Time_Expiry, DomesticFreeRate, put, flag)`. It can be seen that when pricing FX options, the foreign-free rate is used instead of the dividend yield, and the supplied volatility is that of the foreign/domestic exchange rate. Another difference is that the equity option value returned by the call to black_scholes is in domestic currency units and is then converted to base units; in the case of FX options, the value is already in base currency units and requires no conversion.
