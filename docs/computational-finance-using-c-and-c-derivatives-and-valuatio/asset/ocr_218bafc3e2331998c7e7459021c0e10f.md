# Floating Leg

Let the floating leg have coupon payments at times $t_m, m = 1, \dots, N_f$, where $	au_f = t_m - t_{m-1}$. If the next coupon is at time $t_j$, then the value of the floating leg is

```
$V_f(t) = L(t_{j-1}){R(t_{j-1}) + \Phi\} + \tau_f DF(t,t_j)\\n + \sum_{m=j+1}^{N_f} \frac{S(t)}{DF(t,t_{m-1})} \{F(t,t_{m-1},t_m) + \tau_f DF(t,t_m)\}, \quad (7.5.2)
```

where $\Phi$ is the *margin* added to the forward rate used to compute coupons, $F(t,t_{m-1},t_m)$ is the time $t$ forward rate between times $t_{m-1}$ and $t_m$, and $R(t_{j-1})$ is the reset rate that is used between $t_{j-1}$ and $t_j$ to compute the coupon payment at time $t_j$.

# Payer Equity TRS

The owner of a payer TRS swaps the equity leg coupons, and thus at time $t$ the swap has value

```
$ERS_{Sp}(t) = V_f(t) - V_e(t). \quad (7.5.3)
```

The receiver of a equity TRS receives the equity leg coupons, and the value of the swap is

```
$ERS_{Tc}(t) = -V_f(t) + V_e(t). \quad (7.5.4)
```

We will now compute an expression for the value of a payer equity swap. Since

```
$F(t,t_{m-1},t_m) = \frac{1}{(t_m - t_{m-1})} \left( \frac{DF(t,t_{m-1})}{DF(t,t_m)} - 1 \right),
```

we have

```
$\tau_f F(t,t_{m-1},t_m) = \left( \frac{DF(t,t_{m-1})}{DF(t,t_m)} - 1 \right), \quad (7.5.5)
```

Substituting equation (7.5.5) into equation (7.5.2) and using equation (7.5.3), we obtain

```
$ERS_{Sp}(t) = \sum_{m=j+1}^{N_f} \frac{S(t)DF(t,t_m)}{DF(t,t_{m-1})} - 1\}\\n + \sum_{m=j+1}^{N_f} \frac{S(t)}{DF(t,t_{m-1})} \Phi \tau_f DF(t,t_m)\\n + L(t_{j-1})(R(t_{j-1}) + \Phi) \tau_f DF(t,t_j)\\n - \sum_{k=i+1}^{N_k} \left\ 1 - \frac{DF(t,t_k)}{DF(t,t_{k-1})} \right\ - \left\ \frac{S(t)}{DF(t,t_i)} \right\} DF(t,t_i). \quad (7.5.6)
```
