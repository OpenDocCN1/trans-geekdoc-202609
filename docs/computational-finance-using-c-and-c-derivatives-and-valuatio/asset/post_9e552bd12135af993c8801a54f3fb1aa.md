Other Financial Derivatives

We will start by writing $(X_d^B/B_d)$ as $(S_f^B/B_f)(X_d^B/B_d)$. Using the Ito product rule, we have

```
$d\left(\frac{S_f^B}{B_f}\frac{X_d^B}{B_d}\right)=\left(E\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)+\sigma_x\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right)+E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]\quad(7.5.15)$
```

Substituting for $(X_d^B/B_d)$ from equation (7.5.14) into equation (7.5.15) gives

```
$d\left(\frac{S_f^B}{B_f}\frac{X_d^B}{B_d}\right)=\left(\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)+\sigma_x\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right)dW_x^Q+E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]\quad(7.5.16)$
```

Using the Ito quotient rule (see Section 2.6.2) with one source of randomness, equation (7.5.13) and equation (7.5.10) yield

```
$d\left(\frac{S_f^B}{B_f}\right)=\alpha dt+d\left(\frac{S_f^B}{B_f}\right)\sigma_x dW_x^Q.\quad(7.5.17)$
```

We now consider the term $E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]$ in equation (7.5.16)

```
$E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]=\left\left(\frac{S_f^B}{B_f}\right)\left(\alpha dt+d\left(\frac{S_f^B}{B_f}\right)\sigma_x dW_x^Q\right)\sigma_x\left(\frac{X_d^B}{B_d}\right)+\left\left(\frac{X_d^B}{B_d}\right)\left(\alpha dt+d\left(\frac{X_d^B}{B_d}\right)\sigma_x dW_x^Q\right)\sigma_x\left(\frac{S_f^B}{B_f}\right)-\left\left(\frac{X_d^B}{B_d}\right)d\left(\frac{X_d^B}{B_d}\right)\right)\sigma_x\sigma_x\left(\frac{S_f^B}{B_f}\right)\left(\frac{X_d^B}{B_d}\right)\right]$
```

Since $[dW_x^Q]=0$ and $E[dW_x^Q dW_x^Q]=\rho_{xs}dt$, we have

```
$E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]=\left\left(\frac{S_f^B}{B_f}\right)\left(\frac{X_d^B}{B_d}\right)\right)\sigma_x\sigma_x\rho_{xs}dt.\quad(7.5.18)$
```

Using the values of $(S_f^B/B_f)$ and $E\left[d\left(\frac{S_f^B}{B_f}\right)d\left(\frac{X_d^B}{B_d}\right)\right]$ from equations (7.5.17) and (7.5.18) in equation (7.5.16) results in

```
$d\left(\frac{S_f^B}{B_f}\frac{X_d^B}{B_d}\right)=\left\left(\frac{S_f^B}{B_f}\right)\left\left(\frac{X_d^B}{B_d}\right)\right)\alpha dt+\left\left(\frac{S_f^B}{B_f}\right)\left\left(\frac{X_d^B}{B_d}\right)\right)\sigma_x\sigma_x dW_x^Q+\sigma_x\left(\frac{X_d^B}{B_d}\right)\left(\frac{S_f^B}{B_f}\right)\sigma_x\sigma_x\rho_{xs}dt.$
```

## Equity Derivatives Section

Re-arranging we obtain

```
$d\left(\frac{S_f^B}{B^d}\right)=\left(\frac{S_f^B}{B^d}\right)\{\alpha+\sigma_s\sigma_x\rho_{xs}\}dt+\left(\frac{S_f^B}{B^d}\right)(\sigma_s dW_s+\sigma_x dW_x).\quad(7.5.19)$
```

$(\frac{S_f^B}{B^d})$ is a martingale under measure $Q$ so the drift term in equation (7.5.19) can be zero. This means that

```
$\alpha=-\sigma_s\sigma_x\rho_{xs},$
```

where $\sigma_s$ is volatility of foreign equity, $\sigma_x$ is volatility of foreign exchange rate, and $\rho_{xs}$ is correlation between $dW_s$ and $dW_x$. Equation (7.5.13) can then be written as

```
$dS^F=\{rf-\sigma_s\sigma_x\rho_{xs}\}S^F dt+\sigma_s S^F dW_s.\quad(7.5.20)$
```

## Equity Quanto Forward

(The time $t$) value of domestic equity forward contract with maturity $T$

```
$F(t)=DF^d(t,T)\{S^d(t,T)-K^d\},
```

where $K^d$ is strike in domestic currency and $S^d(t,T)$ is domestic forward. To value an equity quanto contract, we need to know the forward price of foreign equity $S^F$. It can be seen from equations (4.4.31), (4.4.32) and (7.5.20) that this forward price is

```
$S^F(t,T)=S^F(t)\exp((rf-\sigma_s\sigma_x\rho_{xs})(T-t)).\quad(7.5.21)$
```

where $S^F(t)$ is current price of foreign equity and $T$ is maturity of the forward. In equity quanto forward, the payoff is in foreign currency but it is converted to domestic currency at a predetermined exchange rate (denoted here by $X$). The value quanto forward is

```
$PF(t)=DF^d(t,T)\{S^d(t,T)-K^f\}X,$
```

where $X$ is the specified exchange rate, $K^f$ is strike in units of foreign currency, and $S^F(t,T)$ is forward equity price.

## Equity Quanto Option

In Chapter 4, equations (4.4.58) and (4.4.59) expressed the value of vanilla European put and call options as

```
$Call(t)=\exp(-rd(T-t))\{S^d(t,T)N_1(d_1)-EN_1(d_2)\},$
```

```
$Put(t)=\exp(-rd(T-t))\{-S^d(t,T)N_1(-d_1)+EN_1(-d_2)\},$
```

where we use superscripts to denote the domestic currency, and the current equity forward price with maturity $T$ is

```
$S^d(t,T) = S^d \exp(r^d(T-t)), \quad t \le T.$
```

The value of any equity option can be obtained by substituting $f^d$ for $S^d$ in the above equation. We obtain

```
$QCall(t) = \exp(-r^d(T-t)) \{S^d(t,T)N_1(d_1) - E^f N_1(d_2)\},$
```

```
$QPut(t) = \exp(-r^d(T-t)) \{-S^f(t,T)N_1(-d_1) + E^f N_1(d_2)\}, X.$
```

```
$d_1 = \frac{\log(S^f(t,T)/E^f) + \sigma^2/2T}{\sigma_s \sqrt{T-t}}, \quad d_2 = \frac{\log(S^f(t,T)/E^f) - \sigma^2/2T}{\sigma_s \sqrt{T-t}}$
```

where $E^f$ is the strike in foreign currency units, $S^f(t,T)$ is the foreign equity forward price (obtained from equation (7.5.21)), and $X$ is the specified exchange rate (number units of domestic currency per foreign currency).
