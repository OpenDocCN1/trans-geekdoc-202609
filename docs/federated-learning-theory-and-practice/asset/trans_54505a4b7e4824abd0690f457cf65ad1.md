```
ν(D_m) = √(det(D_m^⊤ D_m)),
```

其中`det(·)`表示矩阵的行列式。文献[\[23\]](#Chp015_281-296_B9780443190377000247.xhtml#br0115)中还提出了RV，即公式[(15.7)](#Chp015_281-296_B9780443190377000247.xhtml#deq7)中体积的一种鲁棒变体，以解决估值中的数据复制问题。总体而言，RV为VP驱动的数据估值技术提供了一种可行的替代方案，将估值与验证解耦，并规避了选择合适验证集相关的挑战。该方法计算效率高，因为它是免训练的（即不需要训练）。然而，其缺点是理论性能保证仅适用于回归任务。

#### 15.4.1.3 相似性驱动

不同于性能驱动方法，相似性驱动方法通过将数据集与一个具有代表性且可信的参考进行对比来确定价值。简单来说，与聚合数据或参考目标分布更相似的数据集会被赋予更高的价值。

**MMD。** Tay等人[\[17\]](#Chp015_281-296_B9780443190377000247.xhtml#br0085)提议使用`D[𝒜] ∪ G[𝒜]`作为参考集，其中`G[𝒜]`代表使用`D[𝒜]`训练的生成模型（如变分自编码器、生成对抗网络等）生成的合成数据集。利用MMD高效度量两个采样数据集之间的分布相似性。具体而言，我们表示为

```
ν(D[m]) = −MMD[u]²(D[m], D[𝒜] ∪ G[𝒜]),
```

其中`MMD[u]`是无偏MMD估计。该工作还讨论了MMD的核选择及通过合成数据奖励激励CML的扩展，这将在后续关于联邦学习激励的章节中进一步讨论。

**DAVINZ。** 相关地，我们在公式[(15.6)](#Chp015_281-296_B9780443190377000247.xhtml#deq6)中早前介绍的DAVINZ框架，在域外项中包含相似性驱动度量的要素。考虑域偏移在CML和FL中尤为重要，因为客户端通常拥有异构的本地数据分布，这些分布可能与测试时的目标分布不完全相同。

#### 15.4.1.4 信息驱动

信息论通过与模型相关的不确定性，为量化模型的“有用性”提供了一种替代方案。该度量独立于验证数据集，从而避免了为数据估值选择合适验证数据集及其相关偏差的需求。

**信息增益。** Sim等人[\[15\]](#Chp015_281-296_B9780443190377000247.xhtml#br0075)提议通过在`D[m]`上训练后，训练模型参数`w[m]`不确定性减少的量度来衡量数据集`D[m]`的质量。遵循信息论概念，随机变量的熵反映了与该变量结果相关的“信息”量或“不确定性”量。因此，利用先验熵`H(w[m])`和后验熵`H(w[m] | D[m])`分别表示训练前后与`w[m]`相关的不确定性，基于信息增益（IG）的数据价值可表示为

```
ν(D[m]) = H(w[m]) − H(w[m] | D[m])。
```

解释而言，更有价值的数据集会导致模型训练过程中更大的不确定性减少。有趣的是，IG与性能驱动方法相关，因为它可以被视为一种具有未知验证集的预测性能代理[\[9\]](#Chp015_281-296_B9780443190377000247.xhtml#br0045)，[\[10\]](#Chp015_281-296_B9780443190377000247.xhtml#br0050)。然而，该估值方法要求对`w[m]`（和`D[m]`）进行贝叶斯处理，且对于某些模型（如多层贝叶斯神经网络），IG的计算可能代价高昂。

### 15.4.2 估值函数

估值函数作用于在包含数据集`D[𝒞] ⊆ D[𝒜]`的多个联盟`𝒞`上由效用函数计算出的效用值。虽然我们通常考虑`𝒞`中客户端的联盟，但请注意，在相同公式下，每个单个数据样本的价值也是定义明确的。在本节中，我们将讨论适用于任意效用函数`ν`的估值函数。

#### 15.4.2.1 留一法（LOO）

留一法贡献测试源于鲁棒统计学，Cook[\[3\]](#Chp015_281-296_B9780443190377000247.xhtml#br0015)曾用它来研究线性回归中单个数据点的影响。直观上，它计算在完整数据上拟合的模型与删除第`m`个点或客户端后的数据上拟合的模型之间的距离。在数据估值的背景下，我们采用

```
ϕ[m]^(LOO) = ν(D[𝒜]) − ν(D[𝒜 ∖ {m}]),
```

其中`ν`是任意效用函数（示例见第[15.4.1](#Chp015_281-296_B9780443190377000247.xhtml#s0030)节）。LOO仅考虑数据对大联盟（不含其自身）的边际效用改进。

#### 15.4.2.2 Shapley值（SV）

几个博弈论解概念已被证明在数据估值中很有用，包括Shapley值（SV）[\[7\]](#Chp015_281-296_B9780443190377000247.xhtml#br0035)、Banzhaf值[\[19\]](#Chp015_281-296_B9780443190377000247.xhtml#br0095)和最小核[\[24\]](#Chp015_281-296_B9780443190377000247.xhtml#br0120)。我们在此重点关注SV，因为它是满足`效率`、`对称性`、`线性性`和`虚拟玩家`性质[\[5\]](#Chp015_281-296_B9780443190377000247.xhtml#br0025)的唯一解。

客户端`m`的SV定义为`m`对所有联盟`𝒞 ⊆ 𝒜 ∖ {m}`的平均边际贡献，
