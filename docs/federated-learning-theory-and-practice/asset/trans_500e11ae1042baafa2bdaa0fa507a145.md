### 重新设计 B

`BN[infer]`，攻击者基于 `(μ, σ²)` 推断 `(mean(x*), var(x*))`。一个更合理的攻击者会尝试在更新 `x`（他对私有批次的猜测）的同时推断 `(mean(x*), var(x*))`，并使用 `(mean(x), var(x))` 来归一化该批次。在这种情况下，`(μ, σ²)` 可作为 BatchNorm 统计量的先验来正则化恢复过程，正如文献 [[45]](#Chp006_105-122_B9780443190377000144.xhtml#br0225) 所建议的：

```
argmin_x 1 - ⟨∇_θ L_θ(x,y), ∇_θ L_θ(x*,y*)⟩ / (‖∇_θ L_θ(x,y)‖ ‖∇_θ L_θ(x*,y*)‖) + α_TV R_TV(x) + α_BN R_BN(x),
```
(6.3)

其中 `R_BN(x) = Σ_l ‖mean(x[l]) − μ[l]‖_2 + Σ_l ‖var(x[l]) − σ[l]²‖_2`。

如图所示，对于一批低分辨率图像，`BN[infer]` 的重建结果比 `BN[proxy]` 好得多，但与 `BN[exact]` 相比，仍无法恢复私有批次的一些细节。对于单张高分辨率图像，结果更差：攻击者使用 `BN[infer]` 无法返回可识别的重建结果。这表明，无法访问私有批次的 BatchNorm 统计量已削弱了最先进的梯度反演攻击。

## 放宽条件 2：不知道私有标签

Zhao 等人 [[49]](#Chp006_105-122_B9780443190377000144.xhtml#br0245) 指出，*单张* 私有图像的标签信息可以从紧邻输出层的那一层的梯度中解析计算得出。Yin 等人 [[45]](#Chp006_105-122_B9780443190377000144.xhtml#br0225) 进一步扩展了该方法，以支持对一批图像的标签进行恢复。然而，如果私有批次中的多张图像属于同一标签，这两种方法都无法判断有多少张图像属于该标签，更不用说哪一部分图像属于该标签了。[图 6.2](#Chp006_105-122_B9780443190377000144.xhtml#f0015)a 表明，对于 CIFAR-10，在各种批次大小下，批次中许多训练样本可能具有相同的标签，且标签分布不均匀——因此，推断标签变得更难，攻击也会减弱。在 [图 6.2](#Chp006_105-122_B9780443190377000144.xhtml#f0015)b 中，我们通过对比已知私有标签和未知私有标签情况下的恢复效果，评估了攻击者在该设定下的最坏情况。

## 6.4 针对梯度反演攻击的防御

已经提出了几种防御思路来缓解梯度反演的风险。本章考虑三种防御方法。

### 6.4.1 加密梯度

基于密码学的方法对梯度进行加密以防止梯度反演。Bonawitz 等人 [[7]](#Chp006_105-122_B9780443190377000144.xhtml#br0035) 基于秘密共享 [[41]](#Chp006_105-122_B9780443190377000144.xhtml#br0205) 提出了一种联邦学习的安全聚合协议，通过计算梯度向量的和来实现。Phong 等人 [[38]](#Chp006_105-122_B9780443190377000144.xhtml#br0190) 提出在发送前使用同态加密来加密梯度。这些方法需要特殊的设置，且实施成本可能很高。

此外，使用安全聚合协议时，诚实但好奇的服务器仍可对求和后的梯度向量发起梯度反演攻击。同样，诚实但好奇的客户端也可对服务器返回的模型发起梯度反演攻击，以重建其他客户端的私有数据，即使使用了同态加密。

作为替代方案，已提出另外两类防御机制来缓解针对*明文*梯度攻击的风险。

### 6.4.2 扰动梯度

#### 梯度剪枝

在提出首个实用的梯度反演攻击时，Zhu 等人 [[51]](#Chp006_105-122_B9780443190377000144.xhtml#br0255) 也建议了一种防御方法，即将幅度较小的梯度设为零（即梯度剪枝）。基于他们的攻击，他们证明剪枝超过 70% 的梯度会使恢复的图像在视觉上不再可识别。然而，建议的剪枝比例是基于较弱的攻击确定的，可能无法在最先进的攻击下保持安全。

#### 给梯度添加噪声

受 DPSGD [[1]](#Chp006_105-122_B9780443190377000144.xhtml#br0005) 启发，DPSGD 通过给梯度添加噪声来实现差分隐私 [[15](#Chp006_105-122_B9780443190377000144.xhtml#br0075),[16]](#Chp006_105-122_B9780443190377000144.xhtml#br0080)，近期工作 [[43](#Chp006_105-122_B9780443190377000144.xhtml#br0215),[51]](#Chp006_105-122_B9780443190377000144.xhtml#br0255) 也建议通过向梯度添加高斯或拉普拉斯噪声来进行防御。他们表明，成功的防御需要添加高水平的噪声，导致在 CIFAR-10 任务上准确率下降超过 30%。近期的实证研究 [[36](#Chp006_105-122_B9780443190377000144.xhtml#br0180),[42]](#Chp006_105-122_B9780443190377000144.xhtml#br0210) 建议使用更好的预训练技术和更大的批次大小（例如 4096）来实现更好的 DPSGD 训练精度。

由于大多数用于自然图像分类任务的 DPSGD 实现 [[1](#Chp006_105-122_B9780443190377000144.xhtml#br0005),[36](#Chp006_105-122_B9780443190377000144.xhtml#br0180),[42]](#Chp006_105-122_B9780443190377000144.xhtml#br0210) 都采用预训练和微调流程，因此很难与其他可以在从头训练模型时直接应用的防御方法进行公平比较。因此，我们将与 DPSGD 的比较留待未来工作。
