
# 裁剪噪声与偏差

裁剪引入了裁剪噪声，其定义为裁剪后的梯度 `[a[h]]_C` 与原始梯度 `a[h]` 之间的差值。这会影响收敛速度并导致裁剪偏差。如果收敛的是向 [(2.1)](#Chp002_29-55_B9780443190377000090_split_000.xhtml#deq1) 的（局部）最小值 `w*`，那么 DP-SGD 将不会越来越接近 `w*`，而是会收敛到 `w*` 周围某个半径范围内的某个模型，该半径由裁剪偏差和因添加高斯噪声以实现预期 DP 保证而产生的偏差组成，并且该半径至少与最后使用的步长成正比。我们注意到，裁剪噪声可能不会从一轮到下一轮减小：尽管 `E[ξ][∇[w]f(w*; ξ)]` 趋于零（因为我们收敛到局部最小值），但梯度的期望范数 `c(w*) = E[ξ][∥∇[w]f(w*; ξ)∥]` 通常不会收敛到零。因此，裁剪常数 `C` 必须适当设置（不能太小）。例如，通过使用另一个先前相关学习任务的 `C`，或者在执行 DP-SGD 时使用公共数据集来估计 `c(w*)`。

## 2.2.2 小批量 SGD

DP-SGD 受限于小批量 SGD 方法，即在第 `e` 个轮次的第 `b` 个本地轮次开始前，从大小为 `|d| = N` 的本地数据集 `d` 中选取一个随机小批量 `S[b]`，其样本大小为 `|S[b]| = m`。在 [算法 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 的描述中，采样是在轮次 `e` 开始前通过采样过程 `Sample[m]` 为所有轮次一次性完成的。DP-SGD 实现了*子采样*，即从 `d` 中均匀随机选择一个大小为 `m` 的子集 `S[b] ⊆ d`。

内层循环计算 `m` 个梯度 `a[h] = ∇[w]f(w; ξ[h])`。由于一个轮次内有 `N/m` 个轮次，因此每个轮次的总梯度复杂度确实为 `N = |d|`。我们注意到，每个梯度的计算都基于 `w`，即通过中断服务程序从服务器接收到的最后一个全局模型。在原始 DP-SGD 中，客户端在轮次开始时等待，直到接收到包含所有客户端所有前序轮次聚合更新的全局模型。[算法 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 中的表述允许异步行为，包括来自服务器的消息丢失（或重新排序），这可能导致客户端错过接收全局模型版本。更重要的是，服务器可能决定以低于客户端计算和通信其加噪轮次更新的速率来广播全局模型。这允许具有不同计算速度/资源的客户端参与。此外，计算轮次更新的速率不受服务器向客户端广播消息吞吐量的限制（当然，它仍受限于客户端通过聚合节点到服务器的网络吞吐量）。这意味着参数 `m` 可以从整个范围 `{1, …, N}` 中选择，包括非常小的 `m`（导致每个轮次有许多轮次更新）或较大的 `m`（导致每个轮次只有少数几轮更新）。我们稍后将讨论 `m` 对收敛、准确性和 DP 保证的影响。

我们注意到，过多的异步行为会损害小批量 SGD 方法的收敛性，并可能导致最终全局模型的准确性变差。因此，在开始一轮之前，客户端可以检查最近接收到的全局模型与本地保留的模型偏离的程度。如果偏离太远，或者上一次接收全局模型已经是很多轮次之前的事了，那么客户端将希望等待，直到接收到新的全局模型并触发中断服务程序。这实现了针对收敛性和准确性所需的同步行为。

## 2.2.3 高斯噪声

裁剪后的梯度 `[a[h]]_C` 在轮次更新 `U` 中被求和。在每个本地轮次结束时，通过向 `U` 的每个向量条目添加高斯噪声

```
𝒩(0, (2Cσ)²)
```

来对轮次更新 `U` 进行混淆。将生成的加噪轮次更新 `Ū` 除以小批量大小 `m` 后传输给服务器。

对于相邻数据集 `d` 和 `d'`，我们有：以基于 `d` 的 `U` 和基于 `d'` 的 `U'` 之间的欧几里得距离衡量的*敏感度*（另见第 [2.2.1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#s0020) 节）至多为 `2C`。试图区分观测到的更新来自 `d` 还是 `d'` 的对手，需要弄清楚该观测是来自

```
U + 𝒩(0, (2Cσ)²I)  还是  U' + 𝒩(0, (2Cσ)²I)。
```

由于 `∥U − U'∥ ≤ 2C`，这在对手最有利的情况下等价于 `𝒩(0, (2Cσ)²)` 与 `𝒩(2C, (2Cσ)²)` 的假设检验。除以 `2C` 后，这等价于假设检验

```
𝒩(0, σ²)  对比  𝒩(1, σ²)。  (2.3)
```

我们看到，轮次更新的任何差分隐私保证均由 `σ` 表征。

上述论证不依赖于函数 `f` 的性质。事实上，我们可以自由决定如何计算 [算法 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 第 14 行中的 `a[h]`。只要每次计算 `a[h]` 都从 `w` 开始，这些计算本身就可以依赖多个样本。例如，`a[h]` 可以计算来自本地 SGD 方法（联邦学习中使用）的更新，可以按小批量 SGD 风格计算，或按某种其他基于动量的方法计算。
