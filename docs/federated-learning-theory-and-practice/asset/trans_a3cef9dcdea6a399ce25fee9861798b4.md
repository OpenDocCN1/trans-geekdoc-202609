
如[图 6.3](#Chp006_105-122_B9780443190377000144.xhtml#f0020)所示，当批量大小为 32 时，将 Intra-InstaHide（`k`=4）与梯度剪枝（`p`=0.9）相结合，会使重构结果几乎无法辨认。与使用 `p`=0.999 的梯度剪枝相比，组合防御产生了更高的 LPIPS 分数，但引入的精度损失更小（与无防御流水线相比约为 7%）。

### 6.5.4 端到端恢复单张图像的时间估计

[表 6.3](#Chp006_105-122_B9780443190377000144.xhtml#t0020) 显示了在采用 GradPrune 或 InstaHide 防御的联邦学习设置中，端到端恢复单张图像的时间估计。我们未对 MixUp 进行估计，因为已有证明表明它是一种较弱的防御（参见第 [6.5.2](#Chp006_105-122_B9780443190377000144.xhtml#s0090) 节）。

**表 6.3** 使用最先进的梯度反演攻击 [[18]](#Chp006_105-122_B9780443190377000144.xhtml#br0090) 从客户端数据集恢复*单张图像*的时间估计（NVIDIA GeForce RTX 2080 Ti GPU 小时）。我们假设客户端数据的图像分辨率为 32×32×3。

| 客户端数据集大小 (*N*) | 无防御 | GradPrune | InstaHide |
| :--- | :---: | :---: | :---: |
| 5000 | 0.25 | 0.25 | 934.48 |
| 50,000 | 46,579.01 (≈ 5.5 GPU 年) | | |
| 500,000 | 4,215,524.32 (≈ 493.4 GPU 年) | | |

我们的时间估计考虑了三个相当小的数据集大小。我们估计中的最大规模仅占 ImageNet 规模数据集的一小部分。我们考虑这样一个客户端：其持有包含 *N* 张私有图像的数据集并参与联邦学习，该学习过程使用批量大小 `b`=128 训练 ResNet-18 模型。假设客户端数据的分辨率为 32×32×3。如果攻击者使用单张 NVIDIA GeForce RTX 2080 Ti GPU 作为计算资源，并运行包含 10,000 次优化迭代的梯度反演，则 `t`，即攻击单个批次的运行时间，约为 0.25 GPU 小时（批量大小 `b` 对攻击运行时间影响甚微，但较大的 `b` 会降低攻击效果）。

**无防御与梯度剪枝。** 在无防御流水线（或仅应用梯度剪枝作为防御的流水线）中恢复单张图像，只需攻击者反演单个训练步骤的梯度，耗时 `t`。

**InstaHide。** 当应用 InstaHide 时，当前的攻击 [[8]](#Chp006_105-122_B9780443190377000144.xhtml#br0040) 表明，恢复单张图像将涉及先恢复整个数据集。正如第 [6.4](#Chp006_105-122_B9780443190377000144.xhtml#s0060) 节所讨论的，Carlini 等人的攻击包含两个步骤：

1.  从 `T` 个 epoch 的梯度中恢复 InstaHide 图像——这将耗时 (`N`×`T`/`b`)×`t` GPU 小时。
2.  在 InstaHide 图像上运行解码攻击 [[8]](#Chp006_105-122_B9780443190377000144.xhtml#br0040) 以恢复私有数据集，这涉及：
    1.  **2a** 训练一个神经网络以检测恢复的 InstaHide 图像中的相似性。假设训练该网络至少需要 `n` 张恢复的 InstaHide 图像，则通过运行梯度反演收集这些图像将耗时 (`n`/`b`)×`t` GPU 小时。根据 [[8]](#Chp006_105-122_B9780443190377000144.xhtml#br0040)，训练需要 10 GPU 小时，因此训练相似性网络总共需要 (`n`/`b`)×`t` + 10 GPU 小时。
    2.  **2b** 运行组合算法以恢复原始图像。已证明该步骤的运行时间至少与 `m`（InstaHide 编码的数量）的平方成正比 [[9]](#Chp006_105-122_B9780443190377000144.xhtml#br0045)。当 `m`=5×10³ 时，此步骤耗时 1/6 GPU 小时。因此，对于 `m`=`N`×`T`，运行时间至少为 $1/6 \\times {(\\frac{NT}{5 \\times 10^{3}})}^{2}$ GPU 小时。

总共而言，在这种现实场景下对 InstaHide 的攻击将耗时 $(NT/b) \\times t + (n/b) \\times t + 10 + 1/6 \\times {(\\frac{NT}{5 \\times 10^{3}})}^{2}$ GPU 小时。我们采用 `T`=50（[[8]](#Chp006_105-122_B9780443190377000144.xhtml#br0040) 中使用的值）、`n`=10,000，并在[表 6.3](#Chp006_105-122_B9780443190377000144.xhtml#t0020)中给出估计值。如表所示，当 InstaHide 应用于小型数据集（`N`=5,000）时，单张图像的端到端恢复时间比无防御流水线或 GradPrune 流水线长 3,000 倍以上；当 InstaHide 应用于较大数据集（`N`=500,000）时，端到端恢复的计算成本巨大。

## 6.6 结论

本章首先指出，一些近期的梯度反演攻击对已知 BatchNorm 统计量和私有标签做出了强假设。放宽此类假设会显著削弱这些攻击。

随后，我们报告了一组针对梯度反演攻击的提议防御措施的性能，并估计了在不同数据集规模下端到端恢复单张图像的计算成本。我们的评估表明，不与公共数据集混合的 InstaHide 结合梯度剪枝，可以抵御最先进的攻击，并且在中等规模的客户端数据集（例如 500,000 张图像）中恢复单张图像的估计时间是巨大的。

基于我们对 [[18]](#Chp006_105-122_B9780443190377000144.xhtml#br0090) 的攻击及多种针对*明文*梯度的防御措施的评估，我们有以下几点观察。

首先，*在深度网络中使用 BatchNorm 层但在联邦学习期间不共享私有批次的 BatchNorm 统计量会削弱攻击*。我们在第 [6.3](#Chp006_105-122_B9780443190377000144.xhtml#s0020) 节中已证明，向攻击者暴露 BatchNorm 统计量会显著提高梯度反演的质量。因此，联邦学习的一种更安全配置是使用 BatchNorm 层，但在训练中不共享 BatchNorm 统计量，这已被证明在 [[3]](#Chp006_105-122_B9780443190377000144.xhtml#br0015)、[[33]](#Chp006_105-122_B9780443190377000144.xhtml#br0165) 中是可行的。

其次，*使用大批量大小会削弱攻击；小于 32 的批量大小是不安全的*。我们已证明，较大的批量大小通过增加猜测私有标签的难度（第 [6.3](#Chp006_105-122_B9780443190377000144.xhtml#s0020) 节）以及即使在拥有正确私有标签的情况下恢复私有图像的难度（第 [6.5](#Chp006_105-122_B9780443190377000144.xhtml#s0080) 节）来阻碍攻击。我们的实验表明，即使应用了一些弱防御，小于 32 的批量大小也无法抵御最强的梯度反演攻击。
