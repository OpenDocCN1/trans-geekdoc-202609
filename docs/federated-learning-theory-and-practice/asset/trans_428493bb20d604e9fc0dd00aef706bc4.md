
我们注意到，批量归一化与 DP-SGD 的差分隐私分析不兼容，后者对每个梯度进行单独裁剪（因为这会在 `U` 中的裁剪梯度之间引入依赖关系，且灵敏度 `2*C` 的上界不再成立）。另一方面，层归一化以及组归一化和实例归一化是兼容的（因为这些仅涉及单个梯度计算）。我们注意到，如果 `a[h]` 本身是通过局部小批量 SGD 方法计算的，那么所用小批量的批量归一化可以集成在其计算中。

作为最后的说明，我们的讨论假设我们已经知道如何通过提取特征来表示数据样本。我们可以使用主成分分析（PCA）进行降维，即学习一组我们想要用来表示数据样本的特征。PCA 可以实现差分隐私 [[6]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0030)，因为由此产生的特征提取方法（特征变换）相对于用于计算变换的数据样本具有 DP 保证。DP-SGD 可以被视为 PCA 后的后处理，用于表示 DP-SGD 为其提供 DP 保证的本地训练数据样本。在实践中，我们通常已经知道如何为我们的学习任务表示数据，并且已经知道使用哪个函数 `f(w; ξ)`，即使用哪种神经网络拓扑和损失函数（得益于迁移学习的成功，我们可以从其他学习任务中采用数据表示和 `f`）。

## 2.3 差分隐私

为了防止机器学习中的推理攻击导致数据泄露 [[36]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0180)，例如深度梯度泄露攻击 [[21](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0105), [59](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0295), [60]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0300) 或成员推理攻击 [[43](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0215), [49](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0245), [50]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0250)，已经提出了一系列保护隐私的方法。联邦学习的隐私保护解决方案包括本地差分隐私（LDP）解决方案 [[1](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005), 2, [12](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0060), [26](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0130), [42](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0210), 5[2]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0010) 和中心差分隐私（CDP）解决方案 [[23](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0115), [39](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0195), [42](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0210), [47](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0235), [58]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0290)。在 LDP 中，为实现差分隐私而添加的噪声在每个客户端本地计算，并在发送到服务器之前添加到更新中——在本章中，我们仅考虑 LDP。在 CDP 中，*可信服务器*（也称为可信第三方）将接收到的客户端更新聚合为全局模型；为了实现差分隐私，服务器在向客户端传达全局模型之前向其添加噪声。

差分隐私 [[[13](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0065)–[15](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0075), [17](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0085)]]，参见 [[16]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0080) 以获取一本优秀的教材，为数据库上的算法定义了隐私保证，在我们的案例中，指客户端在其训练数据集上的一系列小批量梯度计算。该保证量化了客户端的输出（发送给服务器的更新集合）可在多大程度上用于区分两个相邻的训练数据集 `d` 和 `d'`（即其中一个集合比另一个集合多一个元素）。

### 2.3.1 差分隐私度量的特性

在 DP-SGD 中，客户端希望尽可能保护其本地训练数据集的隐私。每个加噪的轮次更新 `\overline{U}` 都会泄露隐私。让我们将轮次机制 `M[b]` 定义为输出第 `b` 轮 `\overline{U}` 的轮次计算。`M[b]` 的输入是数据集 `d` 连同更新后的本地模型 `w`。我们有以下递归关系：

```
\overline{U}_b \leftarrow \mathcal{M}_b(w_b; d),
```

其中 `w[b]` 是接收到的全局模型更新的函数，而这些全局模型更新又依赖于其他客户端的轮次更新与自身先前传输的轮次更新 `\overline{U}_1, ..., \overline{U}_{b - 1}` 的组合。为了表达这种依赖关系，我们使用以下符号：

```
w_b \leftarrow \mathsf{W}(\overline{U}_1, ..., \overline{U}_{b - 1}),
```

其中 `W` 接收服务器的全局模型（本质上反映了中断服务例程）。我们将整体机制 `M` 定义为所有轮次机制 `M[b]` 的（自适应）组合，即：

```
{\overline{U}_b} \leftarrow \mathcal{M}(d) \text{~with~} \overline{U}_b \leftarrow \mathcal{M}_b(\mathtt{W}(\overline{U}_1, ..., \overline{U}_{b - 1}); d).
```

在定义 DP 度量时，我们希望能够*组合*不同轮次机制 `M[b]` 的 DP 保证：如果我们能证明对于*所有* aux（可由 `W(...)` 输出），`M[b](aux; ⋅)` 具有特定的 DP 保证，记为 `DP[b]`，那么所有轮次机制 `M[b]` 的组合 `M` 应具有组合后的 DP 保证：

```
DP[1] ⊗ DP[2] ⊗ … ⊗ DP[(N/m) ⋅ E]
```

其中 ⊗ 为 DP 度量上的某种组合张量。

一旦证明了机制 `M` 的 DP 保证，我们不希望它因 `M` 的输出经过*后处理*而减弱。特别是，中心服务器使用 `M` 的输出来跟踪并计算当前学习任务的最终全局模型。该最终模型应仍具有相同（或更强）的差分隐私态势。让我们用过程 `P` 表示后处理。如果 `M` 具有 DP 保证 DP，那么我们希望 `P ∘ M` 也具有 DP 保证 DP（这称为后处理引理），
