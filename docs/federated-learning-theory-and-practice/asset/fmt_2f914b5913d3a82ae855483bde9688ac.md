
![Image](OEBPS/images/B9780443190377000089/si382.png)

For simplicity, we choose all parameters to be constant. Let us define $D\_{t}: = F(w^{t}) - F^{\\star} + \\frac{\\eta(1 - L\\eta)}{2}{\\| v^{t - 1}\\|}^{2} + \\frac{(c - \\eta)}{2}\\sigma\_{t - 1}^{2}$![Image](OEBPS/images/B9780443190377000089/si383.png), and impose the following conditions:

2*L*²*η*²*c*(1 − *β*)² ≤ *η*(1 − *L**η*) and *c*(1 − *β*)² ≤ *c* − *η*.

![Image](OEBPS/images/B9780443190377000089/si384.png)(1.30)

Then, the last estimate leads to

$\\mathbb{E}\\lbrack D\_{t + 1}|\\mathcal{F}\_{t}\\rbrack + \\underset{\\Delta\_{t}}{\\underset{︸}{\\frac{\\eta}{2}{\\|\\nabla F(w^{t})\\|}^{2}}} \\leqslant D\_{t} + \\underset{E\_{t}}{\\underset{︸}{c\\beta^{2}{\\widehat{\\sigma}}^{2}}},$

![Image](OEBPS/images/B9780443190377000089/si385.png)

which is exactly [(1.26)](#Chp001_3-28_B9780443190377000089_split_002.xhtml#deq41) with *ω*[*t*] = 1![Image](OEBPS/images/B9780443190377000089/si202.png).

Assume that we choose $\\eta \\in (0,\\frac{1}{L})$![Image](OEBPS/images/B9780443190377000089/si386.png) and *c* > 0![Image](OEBPS/images/B9780443190377000089/si58_u1.png) such that 2*L*²*η*²(*c* − *η*) = *η*(1 − *L**η*)![Image](OEBPS/images/B9780443190377000089/si387.png), leading to $c: = \\frac{1 - L\\eta}{2L^{2}\\eta} + \\eta = \\frac{1 - L\\eta + 2L^{2}\\eta^{2}}{2L^{2}\\eta}$![Image](OEBPS/images/B9780443190377000089/si388.png). Moreover, ${(1 - \\beta)}^{2} \\leqslant 1 - \\frac{2L^{2}\\eta^{2}}{1 - L\\eta + 2L^{2}\\eta^{2}}$![Image](OEBPS/images/B9780443190377000089/si389.png). Then, both conditions of [(1.30)](#Chp001_3-28_B9780443190377000089_split_002.xhtml#deq57) hold with equality. In this case, we obtain $\\mathbb{E}\\lbrack D\_{t + 1}|\\mathcal{F}\_{t}\\rbrack + \\frac{\\eta}{2}{\\|\\nabla F(w^{t})\\|}^{2} \\leqslant D\_{t} + \\frac{(1 - L\\eta + 2L^{2}\\eta^{2})\\beta^{2}}{2L^{2}\\eta}{\\widehat{\\sigma}}^{2}$![Image](OEBPS/images/B9780443190377000089/si390.png). This inequality implies

$\\frac{1}{T + 1}\\sum\\limits\_{t = 0}^{T}\\mathbb{E}\\lbrack{\\|\\nabla F(w^{t})\\|}^{2}\\rbrack \\leqslant \\frac{2}{\\eta(T + 1)}D\_{0} + \\frac{(1 - L\\eta + 2L^{2}\\eta^{2})\\beta^{2}}{L^{2}\\eta^{2}}{\\widehat{\\sigma}}^{2} \\leqslant \\frac{2\\lbrack F(w^{0}) - F^{\\star}\\rbrack}{\\eta(T + 1)} + \\frac{{\\| v^{0}\\|}^{2}}{(T + 1)} + \\frac{\\sigma\_{- 1}^{2}}{2L^{2}\\eta^{2}(T + 1)} + \\frac{\\beta^{2}{\\widehat{\\sigma}}^{2}}{L^{2}\\eta^{2}}.$

![Image](OEBPS/images/B9780443190377000089/si391.png)

Finally, we choose $\\eta: = \\frac{1}{L{(T + 1)}^{1/3}} \\leqslant \\frac{1}{L}$![Image](OEBPS/images/B9780443190377000089/si392.png), $\\sigma\_{- 1}: = \\frac{1}{{(T + 1)}^{1/3}}$![Image](OEBPS/images/B9780443190377000089/si393.png), and $\\beta: = \\mathcal{O}\\left( \\frac{1}{{(T + 1)}^{2/3}} \\right)$![Image](OEBPS/images/B9780443190377000089/si394.png) such that ${(1 - \\beta)}^{2} \\leqslant 1 - \\frac{2L^{2}\\eta^{2}}{1 - L\\eta + 2L^{2}\\eta^{2}}$![Image](OEBPS/images/B9780443190377000089/si389.png) (such a *β* always exists). Moreover, the last estimate shows that

$\\frac{1}{T + 1}\\sum\\limits\_{t = 0}^{T}\\mathbb{E}\\lbrack{\\|\\nabla F(w^{t})\\|}^{2}\\rbrack = \\mathcal{O}\\left( \\frac{1}{{(T + 1)}^{2/3}} \\right),$

![Image](OEBPS/images/B9780443190377000089/si395.png)

as proven in [\[66\]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0330).

We have illustrated our approach by using the recursive estimate [(1.26)](#Chp001_3-28_B9780443190377000089_split_002.xhtml#deq41) to analyze the convergence of three SGD schemes, including variance-reduced methods. We believe that this approach can be used to analyze other variants including SVRG and SARAH.

## 1.4 Concluding remarks

We have reviewed several main components that constitute the gradient descent method and its variants, including deterministic and stochastic ones, ranging from convex to nonconvex problems. We have provided a simple and unified convergence analysis framework relying on an elementary recursive estimate under the most basic structure assumptions commonly used in the literature. While this approach can be applied to analyze several methods, we have only illustrated it on a few well-known schemes. Note that we have not proposed any new algorithms, but rather unified the convergence analysis using a simple recursive estimate. However, we believe that such an approach can be extended beyond what we have done in this chapter. The following research topics are interesting to us. First, can one still apply our analysis to accelerated variance-reduced stochastic gradient-type methods? Perhaps, this can possibly be done by using the idea from a recent work [\[15\]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0075). Second, how can we extend our framework to study other optimization methods in distributed systems and federated learning? We emphasize that many algorithms in these fields can be viewed as a randomized \[block-\]coordinate methods. Therefore, extensions to coordinate and shuffling methods are promising and remain open. Third, is it possible to extend and adapt our analysis to asynchronous gradient-based algorithms? We believe that such an extension is possible as long as the delay is bounded. However, one needs to modify the recursive expression to capture with the delayed updates, leading to an extra error term in the recursive inequality. Finally, our approach can be used to analyze convergence of algorithms for minimax and variational inequality problems, which have recently gained tremendous popularity [\[19](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0095),[65\]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0325).
