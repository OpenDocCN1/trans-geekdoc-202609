
考虑[(13.10)](#Chp013_237-255_B9780443190377000223.xhtml#deq8)中定义的最优性差距，其中`${\\widehat{\\mathbf{\\theta}}}^{\\ast}$`由FLoRA选择，每个客户端`m` ∈ `[n]`收集`T`个(HP, loss)对`{(**θ**[*t*]^((*m*)),ℒ[*t*]^((*m*))),*t*∈`[T]`}`，在每个客户端的本地HPO期间。对于目标数据分布`$\\mathcal{D} = \\sum\_{m = 1}^{n}w\_{m}\\mathcal{D}\_{m}(\\mathbf{x},c)$`，其中`{𝒟[*m*](**x**,*c*),*m*∈`[n]`}`是每个客户端的本地数据分布，且`*w*[*m*] ∈ [0, 1]`，`∀*m* ∈ `[n]`，我们有

```
$\\widetilde{\\ell}({\\widehat{\\mathbf{\\theta}}}^{\\star},\\mathcal{D}) - \\widetilde{\\ell}(\\mathbf{\\theta}^{\\star},\\mathcal{D})\\ \\leq 2\\max\\limits\_{\\mathbf{\\theta} \\in \\mathbf{\\Theta}}\\sum\\limits\_{m \\in \\lbrack n\\rbrack}\\alpha\_{m}(\\mathbf{\\theta})\\left\\{ \\widetilde{\\beta}\\sum\\limits\_{j \\neq m \\in \\lbrack n\\rbrack}w\_{j}\\mathcal{W}\_{1}(j,m) + \\left( {\\widetilde{L}}\_{m} + {\\widehat{L}}\_{m} \\right)\\Delta\_{m}(\\mathbf{\\theta}) + \\delta\_{m} \\right\\},$
```

(13.9)

其中：
(i) `𝒲[1](*j*, *m*)`是第`j`个客户端分布`𝒟[*j*](**x**, *c*)`和第`m`个客户端分布`𝒟[*m*](**x**, *c*)`之间的1-Wasserstein距离；
(ii) `*Δ*[*m*](**θ**) :  = min[*t* ∈ `[T]`]*d*(**θ**, **θ**[*t*]^((*m*)))`是`***θ***`到客户端`m`尝试的最近HP的距离，对于距离度量`*d* : **Θ** × **Θ** → ℝ[+]`；
(iii) `*δ*[*m*]`是本地损失曲面`*f*^((*m*))`的每样本最大训练误差，即`*δ*[*m*] :  = max[*t* ∈ `[T]`]|ℒ[*t*]^((*m*)) − *f*^((*m*))(**θ**[*t*]^((*m*)))|`；
(iv) `*β̃*`和`*L̃*[*m*]`分别是`$\\widetilde{\\ell}$`关于`***θ***`和`𝒟`的Lipschitz常数；
(v) `*L̂*[*m*]`是本地损失曲面`*f*^((*m*))`关于`***θ****`的Lipshitz常数；
(vi) `*α*[*m*](**θ**)`是聚合损失曲面中的每个客户端权重。

特别地，当所有客户端具有IID本地数据分布时，[(13.11)](#Chp013_237-255_B9780443190377000223.xhtml#deq9)简化为

```
$\\widetilde{\\ell}({\\widehat{\\mathbf{\\theta}}}^{\\star},\\mathcal{D}) - \\widetilde{\\ell}(\\mathbf{\\theta}^{\\star},\\mathcal{D}) \\leq 2\\max\\limits\_{\\mathbf{\\theta} \\in \\mathbf{\\Theta}}\\sum\\limits\_{m = 1}^{n}\\alpha\_{m}(\\mathbf{\\theta})\\left\\{ \\left( {\\widetilde{L}}\_{m} + {\\widehat{L}}\_{m} \\right)\\Delta\_{m}(\\mathbf{\\theta}) + \\delta\_{m} \\right\\}. $
```

请注意，上述次优性在损失估计的温和Lipschitz平滑性假设下成立，即损失估计`$\\widetilde{\\ell}$`和统一损失曲面`$\\widehat{\\ell}$`是Lipschitz连续的（参见[\[42\]](#Chp013_237-255_B9780443190377000223.xhtml#br0210)），无论损失函数的凸性和客户端（可能异构的）本地数据分布如何。此外，如果我们定义全局损失曲面`$\\widehat{\\ell}:\\mathbf{\\Theta}\\rightarrow\\mathbb{R}$`为

```
$\\widehat{\\ell}(\\mathbf{\\theta}) = \\sum\\limits\_{m = 1}^{n}\\alpha\_{m}(\\mathbf{\\theta}) \\cdot f^{(m)}(\\mathbf{\\theta}),\\quad\\alpha\_{m}(\\mathbf{\\theta}) \\in \\lbrack 0,1\\rbrack,\\quad\\sum\\limits\_{m = 1}^{n}\\alpha\_{m}(\\mathbf{\\theta}) = 1,$
```

(13.10)

则：

1.  i) 如果`$\\alpha\_{m}(\\mathbf{\\theta}) = \\frac{1}{n}$`，`∀*m* ∈ `[n]`，`**θ** ∈ **Θ`，则`$\\widehat{\\ell}$`简化为APLM损失曲面。
2.  ii) 如果`*α*[*m*](**θ**) = 𝕀(*f*^((*m*))(**θ**)=max[*m*^′ ∈ `[n]`]*f*^((*m*^′))(**θ**))`，则`$\\widehat{\\ell}$`简化为MPLM损失曲面（假设所有`*f*^((*m*))(**θ**)`值唯一）。
3.  iii) 如果`*α*[*m*](**θ**) = 𝕀(*f*^((*m*))(**θ**)=min[*m*^′ ∈ `[n]`]*f*^((*m*^′))(**θ**))`，则`$\\widehat{\\ell}$`简化为SGM损失曲面（假设所有`*f*^((*m*))(**θ**)`值唯一且所有`**θ**[*t*]^((*m*))`唯一，`∀*m* ∈ `[n]`，`*t* ∈ `[T]`）。

我们现在对[定理13.1](#Chp013_237-255_B9780443190377000223.xhtml#enun0020)进行一些详细观察。首先，我们界限中的第一项表征了客户端本地数据分布差异带来的误差，即FL系统中非IID程度的大小。特别是，我们可以看到它在IID设置下消失。其次，最后两项衡量本地损失曲面`*f*^((*m*))`的质量，如果选择了良好的损失曲面，则可以减小。第三，`*Δ*[*m*](**θ**) :  = min[*t* ∈ `[T]`]*d*(**θ**, **θ**[*t*]^((*m*)))`表明最优性差距仅取决于最接近最优HP设置的HP试验`**θ**[*t*]^((*m*))`。最后，如果我们假设每个客户端的训练数据集`*D*[*m*]`大小为`|*D*[*m*]|`，按`*D*[*m*] ∼ 𝒟[*m*](**x**, *c*)`采样，我们可以视`$w\_{m} = \\frac{|D\_{m}|}{\\sum\_{m^{\\prime} \\in \\lbrack n\\rbrack}|D\_{m}^{\\prime}|}$`，即以概率`*w*[*m*]`所需数据分布`𝒟`从`𝒟[*m*](**x**, *c*)`采样。
