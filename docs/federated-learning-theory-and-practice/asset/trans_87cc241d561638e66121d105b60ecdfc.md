
其中 `α` 为步长，`g[m](w − α∇g[m](w))` 是与客户端 `m` 相关的元函数。为了求解 [(7.5)](#Chp007_125-141_B9780443190377000107.xhtml#deq6)，需要计算二阶梯度，这在计算方面代价高昂。作者提供了两种方法，包括 `FO-MAML` [[14]](#Chp007_125-141_B9780443190377000107.xhtml#br0070) 和 `HF-MAML` [[12]](#Chp007_125-141_B9780443190377000107.xhtml#br0060) 来近似海森矩阵，从而降低计算成本。

基于寻找一个全局模型作为个性化模型的良好初始化点这一相似思路，[[9]](#Chp007_125-141_B9780443190377000107.xhtml#br0045) 提出了新的问题公式化：

![Image](OEBPS/images/B9780443190377000107/fx007.jpg)(7.6)

其中

```
g_m(w) = min_{θ_m ∈ ℝ^d} { ℓ_m(θ_m) + λ/2 ||θ_m - w||^2 }
```

![Image](OEBPS/images/B9780443190377000107/si36_u3.png)(7.7)

是著名的 Moreau 包络，它引入了 `L2` 范数正则化以控制个性化与泛化性能之间的平衡。模型 `θ[m]` 表示客户端 `m` 的个性化模型，`λ` 是一个正则化参数，控制全局模型 `w` 对个性化模型的约束强度。较大的 `λ` 可使拥有不可靠数据的客户端从丰富的数据聚合中受益，而较小的 `λ` 则有助于拥有充足有用数据的客户端优先考虑个性化。注意 `λ ∈ (0, ∞)`，以避免 `λ = 0`（即无联邦学习）或 `λ = ∞`（即无个性化联邦学习）等极端情况。总体思路是允许客户端朝不同方向追求各自的模型，但不能偏离“参考点” `w` 太远，每个客户端都为此参考点做出贡献。虽然 `w` 通过在外层利用多个客户端的数据聚合来寻找，但 `θ[m]` 是针对客户端 `m` 的数据分布进行优化，并在内层保持与 `w` 的有界距离。与问题 [(7.5)](#Chp007_125-141_B9780443190377000107.xhtml#deq6) 相比，问题 [(7.6)](#Chp007_125-141_B9780443190377000107.xhtml#deq7) 中 `w` 作为“元模型”具有相似的含义，但 `pFedMe` 不是将 `w` 用作初始化，而是通过求解一个双层问题，并行追求个性化模型和全局模型，这具有几个优势。首先，虽然 `Per-FedAvg` 为其个性化模型优化了单步梯度更新，但 `pFedMe` 与内层优化器无关，这意味着 [(7.7)](#Chp007_125-141_B9780443190377000107.xhtml#deq8) 可以使用任何支持多步更新的迭代方法求解。其次，通过重写 `Per-FedAvg` 的个性化模型更新为

```
θ_m(w) = w - α∇g_m(w) = arg min_{θ_m ∈ ℝ^d} { ⟨∇g_m(w), θ_m - w⟩ + 1/(2α) ||θ_m - w||^2 }
```

![Image](OEBPS/images/B9780443190377000107/si40_u3.png)

我们可以看到，除了相似的正则化项外，`Per-FedAvg` 仅优化 `g[m]` 的一阶近似，而 `pFedMe` 直接在 [(7.7)](#Chp007_125-141_B9780443190377000107.xhtml#deq8) 中最小化 `g[m]`。第三，`Per-FedAvg`（或通常基于 MAML 的几种方法）需要计算或估计海森矩阵，而 `pFedMe` 仅需使用一阶方法进行梯度计算。

### 7.3.3 多任务学习

多任务方法的主要目标是利用任务间的共性和差异，使多个相关任务能够同时学习。在联邦学习设置中，`MOCHA` [[35]](#Chp007_125-141_B9780443190377000107.xhtml#br0175) 和 `FedU` [[9]](#Chp007_125-141_B9780443190377000107.xhtml#br0045) 将每个客户端视为单个任务，然后基于客户端数据捕获客户端间的关系，并学习多个个性化模型，而不是单一全局模型，以处理非独立同分布数据。`FMTL` 的通用公式化如下：

### 7.3.4 权重共享

权重共享（WS）旨在通过将局部私有层与全局联邦学习模型参数解耦来实现个性化联邦学习。客户端在本地训练自己的私有层，不与联邦学习服务器共享。这使得能够学习特定任务的表示以增强个性化。在深度神经网络的 WS 中，通常使用两种配置。第一种是使用全局表示并个性化最后几层，由 `FedPer` [[2]](#Chp007_125-141_B9780443190377000107.xhtml#br0010) 和 `FedRep` [[6]](#Chp007_125-141_B9780443190377000107.xhtml#br0030) 提出。在此设置中，客户端保留个性化层进行本地训练，并与其他客户端共享全局表示。第二种设计见 [[26]](#Chp007_125-141_B9780443190377000107.xhtml#br0130)，它为每个客户端考虑个性化特征表示，而所有客户端共享公共的最后一层。
