

### 1.2.3 最优性方法

如果 `g` 可微，则我们可以直接使用其最优性条件 `∇g(z) + γ^(-1)(z - w) = 0`，并将其作为关于 `z` 的非线性方程求解。示例包括 `-log det(X)` 和 `∑_{i=1}^n log(1 + exp(y_i X_i^⊤ w))`。

请注意，第二种和第三种技术仅用于凸函数，而第一种可用于非凸函数。能够高效计算 `prox_γg(·)` 的凸函数 `g` 数量庞大；更多示例和计算技巧请参见，例如，[1]、[51]。

### 1.2.4 动量

解释动量作用的一种方法是使用源自牛顿第二定律的动力学系统形式 `ẅ(τ) + ψ(τ)ẇ(τ) + ∇F(w(τ)) = 0`，其中 `ψ(τ)ẇ(τ)` 代表摩擦力或阻尼因子。如果我们使用 `ẅ(τ) ≈ (w^{t+1} - 2w^t + w^{t-1})/h_t^2` 和 `ẇ(τ) ≈ (w^t - w^{t-1})/h_t` 离散化该微分方程，则得到 `(w[t+1] - 2w[t] + w[t-1])/h[t]² + ψ[t](w[t] - w[t-1])/h[t] + ∇F(w[t]) = 0`，从而得出 `w^(t+1) := w^(t) - h[t]²∇F(w^(t)) + (1 - h[t]ψ[t])(w^(t) - w^(t-1))`，参见，例如，[61]。因此，当 `P = I`（单位算子）时，我们可以按如下方式指定 (1.2) 的动量变体：

```
w^(t+1) := w^(t) + η[t]d^(t) + β[t](w^(t) - w^(t-1))
```
(1.5)

其中 `β[t] > 0` 是动量步长。搜索方向 `d^(t)` 可以在 `w^(t)` 处评估，从而得到所谓的重球法 [54]。或者，如果 `d^(t)` 在中间点处评估，例如 `z^(t) := w^(t) + β[t](w^(t) - w^(t-1))`，则在凸情况下得到 Nesterov 加速方案 [44]。该方案可写为两步形式：

```
z^(t) := w^(t) + β[t](w^(t) - w^(t-1)) and w^(k+1) := z^(t) + η[t]d(z^(t))
```
(1.6)

其中 `d(z^(t))` 表示在 `z^(t)` 而非 `w^(t)` 处评估的方向 `d^(t)`。请注意，动量项在 (1.2) 的基础上并未显著增加计算成本。然而，它们可以在凸情况下加速算法 [44, 46]（另见第 1.2.8 节），并可能在某些非凸设置中加速，参见，例如，[35, 63]。

### 1.2.5 对偶平均变体

方案 (1.2) 可视为前向更新，但在凸优化中，对偶平均方案也与 (1.2) 密切相关。与 (1.2) 不同，对偶平均方案按如下方式工作。从 `w⁰ ∈ ℝ^(p)` 开始，对于 `t ≥ 0`，我们更新

```
w^{t+1} := argmin_w { ∑_{j=0}^t γ_j ⟨g^j, w⟩ + 1/(2η_t) ||w - w^0||^2 }
```
(1.7)

其中 `g^(j)` 为给定的对偶方向（例如，`g^(j) := ∇F(w^(j))`），`γ[j]` 为 `g^(j)` 的权重，`η[t]` 为给定的对偶步长。在一般设置中，我们可以用广义 Bregman 距离 `D(w, w⁰)` 替换 `1/2 ||w - w^0||^2`。如果范数为欧几里得范数，则有 `w^{t+1} := w^0 - η_t ∑_{j=0}^t γ_j g^j`。如果 `η[t] = η > 0` 固定且我们选择 `g^(j) := ∇F(w^(j))`，则有 `w^{t+1} = w^0 - η∑_{j=0}^t γ_j g^j = w^0 - η∑_{j=0}^{t-1} γ_j g^j - ηγ_t g^t = w^t - ηγ_t g^t`，这正是 (1.2) 所涵盖的情况。因此，对于欧几里得范数 `1/2 ||w - w^0||^2`，对偶平均方案 (1.7) 与梯度下降方案 `w^(t+1) = w^(t) - ηγ[t]g^(t)` 完全相同。然而，在非欧几里得范数或 Bregman 距离下，这些方法彼此不同。

### 1.2.6 结构假设

设计基于梯度的算法时，一项主要的理论任务是确立其收敛性。从计算角度来看，估计收敛速率以及复杂度也至关重要。然而，为了确立这些，我们要求 `F` 满足一组假设。以下结构常用于优化建模和算法中：

*   **Lipschitz 连续性。** 如果 (1.1) 中的函数 `F` 满足
    ```
    |F(w) - F(w')| ≤ M ||w - w'||, ∀w, w' ∈ ℝ^(p).
    ```
    (1.8)
    则称其为 `M`-Lipschitz 连续。
