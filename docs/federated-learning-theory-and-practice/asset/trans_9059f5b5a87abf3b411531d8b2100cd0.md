
对于相邻的 `d` 和 `d'`；[算法 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 中一轮更新所对应的机制具有*灵敏度* `c = 2C`。将观测值 `o` 投影到连接 `u(d)` 和 `u(d')` 的直线上，并通过除以 `c` 进行归一化后，我们可以得到：在对抗者的最佳情况下（即 `‖u(d) − u(d')‖ = c`），区分 `o` 对应于 `d` 还是 `d'` 等价于区分接收到的输出来自 `𝒩(0, σ²)` 还是 `𝒩(1, σ²)`；等价地，来自 `𝒩(0, 1)` 或 `𝒩(1/σ, 1)`。这就是高斯权衡函数 `G[σ^(−1)]` 发挥作用的方式。

### 2.4.2 子采样

除了实现高斯噪声，DP-SGD 还使用子采样：对于包含 `N` 个样本的数据集 `d`，`Sample[m](d)` 从 `d` 中均匀随机选择大小为 `m` 的子集。我们定义凸组合

`f[p](α) = p f(α) + (1 − p)(1 − α)`

及其对应的 `p`-采样算子

`C[p](f) = min {f[p], f[p]^(−1)}^(**)`

其中函数 `h` 的共轭 `h^(*)` 定义为

```
h^*(y) = sup_x { yx - h(x) }
```

而权衡函数 `h` 的逆 `h^(−1)` 定义为

`h^(−1)(α) = inf {t ∈ [0, 1] | h(t) ≤ α}` (2.8)

它本身也是一个权衡函数（例如，我们注意到 `G[μ] = G[μ]^(−1)`，并称 `G[μ]` 为对称的）。文献 [[11]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055) 中的定理 4.2 表明，如果作用于大小为 `N` 的数据集上的机制 `M` 是 `f`-DP 的，那么子采样机制 `M ∘ Sample[m]` 就是 `C[m/N](f)`-DP 的。

算子 `C[p]` 背后的直觉如下。首先，`Sample[m](d)` 以概率 `p` 采样到 `d` 和 `d'` 之间的区分元素。在这种情况下，计算 `M ∘ Sample[m](d)` 和 `M ∘ Sample[m](d')` 是不同的，假设检验可以通过权衡函数 `f(α)` 进行。以概率 `1 − p`，无法进行假设检验，此时权衡函数为 `1 − α`。这导出了凸组合 `f[p]`。

其次，我们注意到如果 `h = T(M(d), M(d'))`，则 `h^(−1) = T(M(d'), M(d))`。因此，如果 `M` 是 `f`-DP 的（这对所有相邻数据集对都成立，特别是对 `(d, d')` 和 `(d', d)` 这两对），那么 `h ≥ f` 和 `h^(−1) ≥ f` 同时成立，我们得到一个对称的上界 `min {h, h^(−1)} ≥ f`。由于 `f` 是权衡函数，`f` 是凸的，我们可以计算一个更紧的上界：`f` 至多等于 `≤ min {h, h^(−1)}` 的最大凸函数，这等于双共轭 `min {h, h^(−1)}^(**)。由此我们得到了算子 `C[p]` 的定义。

### 2.4.3 组合

对于权衡函数 `f = T(P, Q)` 和 `h = T(P', Q')`，张量积 `f ⊗ h` 由下式明确定义：

`f ⊗ h = T(P × P', Q × Q')`。

令 `y[i] ← M[i](aux, d)` 且 `aux = (y[1], …, y[i−1])`。文献 [[11]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055) 中的定理 3.2 表明，如果对于所有 `aux`，`M[i](aux, ·)` 都是 `f[i]`-DP 的，那么按顺序从 `i = 1` 到 `i = T` 应用 `M[i]` 的组合机制 `M` 是 `(f[1] ⊗ … ⊗ f[T])`-DP 的。张量积满足交换律。

作为一个特例，文献 [[11]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055) 中的推论 3.3 指出，多个高斯算子 `G[μ[i]]` 的组合结果为 `G[μ]`，其中

```
μ = √(∑_i μ_i^2).
```

### 2.4.4 DP-SGD 的紧致分析

我们现在能够给出原始 DP-SGD 的差分隐私保证，因为它是子采样高斯 DP 机制的组合。文献 [[11]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055) 中的定理 5.1 表明，文献 [[1]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005) 中引入的 DP-SGD 是

`C[m/N](G[σ^(−1)])^(⊗ T)`-DP，

其中 `T = (N/m) ⋅ E` 是局部轮数的总数。由于上述引用的文献 [[11]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055) 中的每个定理和结果都是精确的，我们得到了一个紧致分析。这在文献 [[61]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0305) 中引出了一个（紧致的）差分隐私核算器。
