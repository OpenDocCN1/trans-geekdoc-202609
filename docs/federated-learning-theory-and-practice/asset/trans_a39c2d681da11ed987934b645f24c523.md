# 第17章：量子联邦机器学习导论

Samuel Yen-Chi Chen; Shinjae Yoo  
布鲁克海文国家实验室，纽约州阿普顿，美国

## 摘要

`量子计算`和`机器学习`的最新进展引起了人们对结合这两项迷人技术的极大关注。`量子机器学习`（QML）领域包含开发在量子计算机上运行的机器学习算法。经典机器学习关注的问题，如隐私保护特性和分布式训练，在量子世界中依然重要。例如，如何在确保数据安全并保持模型性能（如分类准确率）与非分布式训练相当的前提下，跨多台量子计算机分发训练？本章将介绍现代QML架构，即变分量子算法及其变体，并回顾联邦或分布式QML的最新提案。最后，将讨论QML的弱点与优势，并提供未来展望。

### 关键词

联邦学习；量子机器学习；量子神经网络；隐私保护机器学习

## 17.1 导论

量子计算（QC）有望以二次或指数级的速度优势，解决经典计算机难以处理的某些计算任务，例如非结构化数据库搜索[\[36\]](#Chp017_311-328_B9780443190377000272.xhtml#br0180)或大数分解[\[74\]](#Chp017_311-328_B9780443190377000272.xhtml#br0370)[\[37](#Chp017_311-328_B9780443190377000272.xhtml#br0185),[61\]](#Chp017_311-328_B9780443190377000272.xhtml#br0305)。此外，某些量子算法已显示出在组合优化[\[31\]](#Chp017_311-328_B9780443190377000272.xhtml#br0155)等问题上相对于经典算法的优势。最近，包括Google[\[4\]](#Chp017_311-328_B9780443190377000272.xhtml#br0020)、IBM[\[23\]](#Chp017_311-328_B9780443190377000272.xhtml#br0115)和IonQ[\[26\]](#Chp017_311-328_B9780443190377000272.xhtml#br0130)在内的大型科技公司和初创企业对量子硬件的开发，为这些先进算法的部署和更多潜在应用的探索带来了曙光。

与此同时，经典机器学习的发展在几乎所有方面都取得了巨大成功，包括计算机视觉[\[39](#Chp017_311-328_B9780443190377000272.xhtml#br0195),[45](#Chp017_311-328_B9780443190377000272.xhtml#br0225),[48](#Chp017_311-328_B9780443190377000272.xhtml#br0240),[76](#Chp017_311-328_B9780443190377000272.xhtml#br0380),[83\]](#Chp017_311-328_B9780443190377000272.xhtml#br0415)、自然语言处理[\[21](#Chp017_311-328_B9780443190377000272.xhtml#br0105),[82\]](#Chp017_311-328_B9780443190377000272.xhtml#br0410)、语音识别[\[34](#Chp017_311-328_B9780443190377000272.xhtml#br0170),[35](#Chp017_311-328_B9780443190377000272.xhtml#br0175),[66](#Chp017_311-328_B9780443190377000272.xhtml#br0330),[67\]](#Chp017_311-328_B9780443190377000272.xhtml#br0335)、医学诊断[\[25\]](#Chp017_311-328_B9780443190377000272.xhtml#br0125)、推荐系统[\[91\]](#Chp017_311-328_B9780443190377000272.xhtml#br0455)以及复杂序列决策（例如玩电子游戏[\[58\]](#Chp017_311-328_B9780443190377000272.xhtml#br0290)或围棋等棋类游戏[\[75\]](#Chp017_311-328_B9780443190377000272.xhtml#br0375)）。

鉴于经典机器学习取得的实质性进展和量子计算的最新发展，将两者结合，即`量子机器学习`（QML），是顺理成章的。自变分量子算法（VQA）[\[9](#Chp017_311-328_B9780443190377000272.xhtml#br0045),[11\]](#Chp017_311-328_B9780443190377000272.xhtml#br0055)和量子电路学习[\[57\]](#Chp017_311-328_B9780443190377000272.xhtml#br0285)问世以来，QML领域已显著增长。这些框架为构建可训练或可优化的参数化量子电路[\[7\]](#Chp017_311-328_B9780443190377000272.xhtml#br0035)架构提供了可能性，从而使QML成为可能。
