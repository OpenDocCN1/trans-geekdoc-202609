
在上一节中，我们讨论了用于确保客户端级差分隐私（DP）的各种裁剪策略，并观察到模型差异裁剪应成为联邦学习（FL）应用的首选策略。我们引入了 DP-FedAvg（[算法 4](#Chp003_57-74_B9780443190377000119.xhtml#f0025)），该算法利用模型差异裁剪并在裁剪后添加扰动以确保 DP。在本节中，我们将对[算法 4](#Chp003_57-74_B9780443190377000119.xhtml#f0025)进行彻底的理论和实证研究，旨在理解与该算法相关的隐私和收敛保证。

### 3.4.1 主要结果

带有 DP 的 FL 算法的主要理论结果包含两部分：一是收敛保证，说明训练模型的性能如何；二是隐私保证，描述算法在训练过程中保护隐私的能力。在大多数情况下，隐私保护以牺牲模型性能为代价，因此我们需要在模型性能和隐私保证之间进行权衡。

为了继续，让我们首先陈述假设：

**假设 3.1**

问题的目标满足

`g(w) ≥ g^⋆ > −∞, for some constant g^⋆, ∀ w.`

![Image](OEBPS/images/B9780443190377000119/si77_u4.png)(3.5)

**假设 3.2**

**Lipschitz 梯度**

客户端函数的梯度满足

`∥∇g[m](w) − ∇g[m](w′)∥ ≤ L∥w − w′∥, ∀ m, w, w′,`

![Image](OEBPS/images/B9780443190377000119/si78_u6.png)

其中 `L` 是梯度的 Lipschitz 常数。

**假设 3.3**

**有界方差**

客户端函数的随机梯度是无偏的，即 `𝔼[g̃[m]] = ∇g[m](w)`![Image](OEBPS/images/B9780443190377000119/si79_u6.png)，且其方差满足

`𝔼∥g̃[m] − ∇g[m](w)∥² ≤ σ[ℓ]², ∀ m, w,`

![Image](OEBPS/images/B9780443190377000119/si80_u5.png)

对于某个常数 `σ[ℓ]²`![Image](OEBPS/images/B9780443190377000119/si81_u4.png)。

除了这些标准假设外，在 DP-FedAvg 的分析中还需要以下额外假设。

**假设 3.4**

**有界梯度异质性（BGD）**

局部问题与全局问题之间的梯度间方差由某个常数 `σ[g]²`![Image](OEBPS/images/B9780443190377000119/si82_u5.png) 界定，即

`∥∇g(w) − ∇g[m](w)∥² ≤ σ[g]², ∀ m, w.`

![Image](OEBPS/images/B9780443190377000119/si83_u6.png)

**假设 3.5**

**有界梯度**

每个客户端函数的梯度由某个常数 `G` 上界定，即

`∥∇g[m](w)∥² ≤ G, ∀ m, w.`

![Image](OEBPS/images/B9780443190377000119/si84_u5.png)

BGD 假设已被用于许多 FL 证明中（参见 [\[13](#Chp003_57-74_B9780443190377000119.xhtml#br0065),[40\]](#Chp003_57-74_B9780443190377000119.xhtml#br0200)），以表征客户端数据分布的非独立同分布（non-i.i.d.）性质。有界梯度是替代 BGD 假设的更严格假设，已用于早期的 FL 算法工作（参见 [\[16\]](#Chp003_57-74_B9780443190377000119.xhtml#br0080)）和 DP 算法的分析中（参见 [\[23](#Chp003_57-74_B9780443190377000119.xhtml#br0115),[32](#Chp003_57-74_B9780443190377000119.xhtml#br0160),[33\]](#Chp003_57-74_B9780443190377000119.xhtml#br0165)）。有了上述假设，我们准备好展示 DP-FedAvg（[算法 4](#Chp003_57-74_B9780443190377000119.xhtml#f0025)）的理论结果。

#### 3.4.1.1 收敛定理

**定理 3.6**

**DP-FedAvg 的收敛性，[\[39, Theorem 3.1\]](#Chp003_57-74_B9780443190377000119.xhtml#br0195)**

*在* [假设 3.1](#Chp003_57-74_B9780443190377000119.xhtml#enun0050)–[假设 3.5](#Chp003_57-74_B9780443190377000119.xhtml#enun0070) *下，令* `η_g η_ℓ ≤ min{n_t / (96 τ_m²), n_t / (6 τ_m · L(n_t − 1))}`![Image](OEBPS/images/B9780443190377000119/si85_u6.png) *和* `η_ℓ ≤ 1 / (√60 τ_m · L)`![Image](OEBPS/images/B9780443190377000119/si86_u4.png) *，对于* [算法 4](#Chp003_57-74_B9780443190377000119.xhtml#f0025) *，我们有*

```
(1/τ) ∑_{t=0}^{τ-1} 𝔼[ᾱ^t ∥∇g(w^t)∥²] ≤ FedAvg Term
+ (caused by clipping) G² (4/τ) ∑_{t=0}^{τ-1} 𝔼[ (1/n) ∑_{m=1}^n (|α_m^t − α̃_m^t| + |α̃_m^t − ᾱ^t|) ]
+ (caused by clipping) η_g · η_ℓ · L · τ_m G² (6/τ) ∑_{t=0}^{τ-1} 𝔼[ (1/n_t) ∑_{m=1}^n (|α_m^t − α̃_m^t|² + |α̃_m^t − ᾱ^t|²) ]
+ (caused by privacy noise) (2 η_g · L · d · σ²) / (η_ℓ · τ_m · n_t)
```

![Image](OEBPS/images/B9780443190377000119/si87_u5.png)

*其中* `α_m^t := C / max(C, ∥Δw_m^t∥)`![Image](OEBPS/images/B9780443190377000119/si88_u5.png)*、* `α̃_m^t := C / max(C, ∥𝔼[Δw_m^t]∥)`![Image](OEBPS/images/B9780443190377000119/si89_u5.png)*、* `ᾱ^t := (1/n) ∑_{m=1}^m α̃_m^t`![Image](OEBPS/images/B9780443190377000119/si90_u3.png)*；`d` 是 `w` 的维度，* `γ_1(τ) = (1/τ) ∑_{t=0}^{τ-1} 𝔼[ᾱ^t] ≤ 1`![Image](OEBPS/images/B9780443190377000119/si91_u3.png)*、* `γ_2(τ) = (1/τ) ∑_{t=0}^{τ-1} 𝔼[(ᾱ^t)²] ≤ 1`![Image](OEBPS/images/B9780443190377000119/si92_u3.png)*，且*

```
FedAvg Term := 4(g(w^0) − g^⋆) / (η_g · η_ℓ · τ · τ_m)
+ (25/2) η_ℓ² · L · τ_m (σ_ℓ² + 6 τ_m · σ_g²) γ_1(τ)
+ 6 η_g · η_ℓ · L · σ_ℓ² / n_t γ_2(τ).
```

![Image](OEBPS/images/B9780443190377000119/si93_u4.png)

在[定理 3.6](#Chp003_57-74_B9780443190377000119.xhtml#enun0075)的界中，`FedAvg Term` 继承自具有双边学习率的标准 FedAvg，当设置 `η_g = √(n_t · τ_m)`![Image](OEBPS/images/B9780443190377000119/si95_u3.png) 和 `η_ℓ = 1 / (√τ τ_m · L)`![Image](OEBPS/images/B9780443190377000119/si96_u4.png) 时，可产生 `O(1/√(n_t · τ · τ_m) + 1/τ)`![Image](OEBPS/images/B9780443190377000119/si94_u4.png) 的收敛率。当裁剪操作和 DP 噪声不出现时，它恢复了 FedAvg 的标准收敛界（参见 [\[38, Theorem 1\]](#Chp003_57-74_B9780443190377000119.xhtml#br0190)）。除了 `FedAvg Term` 之外，还有两个由隐私噪声 `z[m]^(t)`![Image](OEBPS/images/B9780443190377000119/si74_u6.png) 和裁剪操作分别引起的额外项。由隐私噪声引起的误差项是隐私保护的代价，可以在 DP-SGD 算法的分析中找到（参见 [\[11](#Chp003_57-74_B9780443190377000119.xhtml#br0055),[32](#Chp003_57-74_B9780443190377000119.xhtml#br0160),[35\]](#Chp003_57-74_B9780443190377000119.xhtml#br0175)）。
