
上述定义的协作公平性未考虑各客户端内部的资源成本（例如数据收集成本或计算资源成本）。然而，成本也可以成为客户端决定是否参与的重要衡量标准，特别是当客户端是基于净利润（即奖励减去成本）做决策的组织时。如果客户端获得的奖励低于提供相应资源的成本，它将因净利润为负而后悔参与协作，并不会在下一次参与。因此，最小化客户端的总体遗憾是可取的。将客户端的资源成本记为 `s[m]` (`m ∈ N`)，客户端的遗憾记为 `k[m] = max((s[m] − r[m]), 0)` (`m ∈ N`)，由此引出以下公平性概念，这是文献 [32] 的简化版本：

### 定义 8.6：最小化遗憾的协作公平性

如果联邦学习（FL）系统满足 `{(r_m^*)}_{m ∈ N} = arg min_{(r_m)}_{m ∈ N} ∑_{m=1}^n (k_m)^2 − α ∑_{m=1}^n r_m c_m` 且 `∑_{m=1}^n r_m ≤ b`，其中 `b` 是总奖励预算，`α` 是可调参数，则该系统实现了最小化遗憾的协作公平性。

在**定义 8.6** 的优化问题目标中，项 `∑_{m=1}^n (k_m)^2` 是客户端遗憾的平方和。因此，最小化该项将减少总体遗憾。二次表达式 `k[m]²` 自然地避少数客户端具有极高遗憾而其他客户端遗憾为零的情况。如果高贡献 `c[m]` 的客户端获得的奖励 `r[m]` 很高，项 `∑_{m=1}^n r_m c_m` 将会很大。因此，最小化遗憾的协作公平性试图将总预算 `b` 分配为奖励，以在最小化总体遗憾的同时，确保贡献较大的客户端获得更高的奖励。可调参数 `α > 0` 平衡这两个目标的重要性。

### 8.2.3 算法公平性

非正式地说，如果机器学习（ML）中的模型不歧视特定群体（即具有特定敏感属性值的数据），则称该模型实现了算法公平性（具体为群体公平性）。换而言之，训练好的模型在不同群体间应具有相似的性能，即群体间的性能差异较低 [16]。联邦学习中的算法公平性与机器学习中的密切相关，因此引入了全局算法公平性的概念作为机器学习中该概念的延伸。另一个概念——多客户端算法公平性——则是专门针对联邦学习场景提出的。

在不失一般性的前提下，考虑二分类情况，标签 `y ∈ {0, 1}`，并假设存在一个全局敏感属性（例如性别）`s ∈ {0, 1}`。将训练好的联邦模型表示为由学习参数 `w` 参数化的预测函数 `f(w, ·)`，并将输入 `x` 的预测标签表示为 `ŷ[w] = f(w, x)`。记 `D[m]^(ij) = {(x, y, s) : (x, y, s) ∈ D[m], ŷ[w] = i, s = j}` 和 `D[m]^(·j) = {(x, y, s) : (x, y, s) ∈ D[m], ŷ[w] ∈ {0, 1}, s = j}`。存在多种使用不同度量来量化所有群体间模型性能差异的定义（例如人口统计学平等 [3]、机会均等 [6] 和相等几率 [6]）。我们聚焦于人口统计学平等来描述以下定义，这些定义可轻松扩展到其他差异度量。基于该度量的算法公平性定义如下：

### 定义 8.7：全局算法公平性 [2, 4]

在联邦学习（FL）系统中，如果模型 `f(w, ·)` 满足

```
ΔDP_g(w) = | (∑_{m=1}^n |D_m^(11)|) / (∑_{m=1}^n |D_m^(·1)|) − (∑_{m=1}^n |D_m^(10)|) / (∑_{m=1}^n |D_m^(·0)|) | ≤ ϵ。
```

则该模型实现了 `ϵ` 全局算法公平性。

此处，`∑_{m=1}^n |D_m^(11)| / ∑_{m=1}^n |D_m^(·1)|` 是敏感属性 `s = 1` 的群体被预测为正类的概率，`∑_{m=1}^n |D_m^(10)| / ∑_{m=1}^n |D_m^(·0)|` 是敏感属性 `s = 0` 的群体被预测为正类的概率。因此，`ΔDP_g(w)` 是聚合数据集 `{D[m]}_{m ∈ N}` 上，两个群体使用模型 `w` 被预测为正类的概率之差的绝对值。如果两个群体被预测为正类的概率之差小于 `ϵ`，则模型实现了全局算法公平性。尽管全局算法公平性概念直观，但强制执行它有时效用有限，特别是在客户端存在异构本地数据分布的情况下。此时，联邦模型可能在特定客户端上实现了算法公平性，但在其他客户端上却未实现。
