
假设 *F* 在 (*θ*[0], **θ**) 中是 *μ*-强凸的。那么在假设 [11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0010)–[11.3](#Chp011_199-217_B978044319037700020X.xhtml#enun0020) 和 [11.5](#Chp011_199-217_B978044319037700020X.xhtml#enun0045) 下，如果 $\eta_{0}^{k} = \eta_{m}^{k} = \frac{2}{\nu(k + K_{0})}$ 其中 $K_{0} = \frac{4(1 + \max_{m}\sqrt{c_{m}})L}{\nu}$ 且 *ν* 是依赖于 *μ*、 *L*、 ${\overline{p}}_{m}$、 *ρ* 的正常数，则可得

𝔼*F*(*θ*[0]^(*K*), **θ**^(*K*)) − *F*^(\*) = 𝒪(1/*K*)。

## 11.4 用于平滑性的扰动局部嵌入

在本节中，我们介绍一种由每个客户端应用的局部扰动技术，用于平滑原本非平滑的局部嵌入映射，以便可应用第 [11.3](#Chp011_199-217_B978044319037700020X.xhtml#s0045) 节中的收敛分析。

### 11.4.1 局部扰动

回顾 *h*[*m*] 表示客户端 *m* 的局部嵌入函数，其参数为 *θ*[*m*]，将局部数据 *x*[*n*, *m*] 的信息嵌入到其输出 *h*[*n*, *m*] := *h*[*m*](*θ*[*m*]; *x*[*n*, *m*]) 中。当 *h*[*m*] 为线性嵌入时，它简单地表示为 *h*[*m*](*θ*[*m*]; *x*[*n*, *m*]) = *x*[*n*, *m*]^⊤*θ*[*m*]。为了进一步考虑神经网络等非线性嵌入，我们将 *h*[*n*, *m*] 表示为以下形式：

*u*[0] = *x*[*n*, *m*],

(11.17a)

*u*[*l*] = *σ*[*l*](*w*[*l*]*u*[*l* − 1] + *b*[*l*]), *l* = 1, …, *L*,

(11.17b)

*h*[*n*, *m*] = *u*[*L*],

(11.17c)

其中 *σ*[*l*] 为线性或非线性函数，而 *w*[*l*], *b*[*l*] 对应 *h*[*m*] 的参数 *θ*[*m*]，例如 *θ*[*m*] := [*w*[1], …, *w*[*L*], *b*[1], …, *b*[*L*]]^⊤。此处我们假设 *σ*[*l*] 是 *L*[*σ*[*l*]]⁰-Lipschitz 连续的。特别地，当 *h*[*m*] 为线性时，复合嵌入 (11.17) 对应于 *L* = 1, *σ*[1](*z*) = *z*。

我们通过在每一层 *l* 添加一个输出为 *Z*[*l*] 的随机神经元来扰动局部嵌入函数 *h*[*m*](参见 (11.17b))：

*u*[*l*] = *σ*[*l*](*w*[*l*]*u*[*l* − 1] + *b*[*l*] + *Z*[*l*]), *l* = 1, …, *L*,

(11.18)

其中 *Z*[1], …, *Z*[*L*] 为独立随机变量。通过适当选择 *Z*[*l*] 的分布，*l* = 1, …, *L*，我们将在下文证明 *h*[*m*] 是平滑的并能实现差分隐私。虽然这不排除其他选项，但我们对扰动分布的选择是：

*Z*[*L*] ∼ 𝒩(0, *c*²),

(11.19a)

$Z_{l} \sim \mathcal{U}[ - \sqrt{3}c_{l},\sqrt{3}c_{l}],\ l = 1,\ldots,L - 1,$

(11.19b)

其中 𝒩(0, *c*²) 表示均值为零、方差为 *c*² 的高斯分布，$\mathcal{U}[ - \sqrt{3}c_{l},\sqrt{3}c_{l}]$ 表示在 $[ - \sqrt{3}c_{l},\sqrt{3}c_{l}]$ 上的均匀分布。

### 11.4.2 强制平滑性

我们现在将扰动局部嵌入技术与第 [11.3](#Chp011_199-217_B978044319037700020X.xhtml#s0045) 节中的收敛理论联系起来。

第 [11.3](#Chp011_199-217_B978044319037700020X.xhtml#s0045) 节中的收敛结果在 [假设 11.2](#Chp011_199-217_B978044319037700020X.xhtml#enun0015) 下成立，该假设要求整体损失函数的平滑性。受随机平滑技术 [[12](#Chp011_199-217_B978044319037700020X.xhtml#br0060), [26]](#Chp011_199-217_B978044319037700020X.xhtml#br0130) 启发，我们通过对随机神经元求期望来平滑目标函数。直观上，这遵循这样一个事实：通过与适当的分布卷积，可以增加函数的平滑性。通过添加随机神经元 *Z*[*l*]，*σ*[*l*] 的地形将在关于 *Z*[*l*] 的期望下被平滑。并通过数学归纳法，我们可以证明局部嵌入向量 *h*[*m*] 的平滑性。那么只要损失函数 *ℓ* 关于局部嵌入向量 *h*[*m*] 是平滑的，全局目标 *F* 通过对所有随机神经元求期望就是平滑的。

我们在以下定理中正式确立这一结果。

**定理 11.5**

*对于每个嵌入函数* *h*[*m*]，*若激活函数满足* *σ*[*l*] = *σ*, ∀*l*，*且随机神经元的方差遵循* (11.19)，*并假设* ∥*w*[*l*]∥ *有界，则令* **Z** = [*Z*[1]^⊤, …, *Z*[*L*]^⊤]^⊤，*扰动损失满足* [假设 11.2](#Chp011_199-217_B978044319037700020X.xhtml#enun0015)，*由下式给出*

*F*[*c*](*θ*[0], **θ**) = 𝔼[**Z**][*F*(*θ*[0], **θ**; **Z**)].

(11.20)
