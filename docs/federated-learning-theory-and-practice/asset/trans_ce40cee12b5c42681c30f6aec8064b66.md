

# 17.2 量子联邦学习

联邦学习 [\[56\]](#Chp017_311-328_B9780443190377000272.xhtml#br0280) 是一个新兴的研究领域，其出现源于人们对使用大规模数据集和基于云的深度学习 [\[72\]](#Chp017_311-328_B9780443190377000272.xhtml#br0360) 产生了更多担忧。联邦学习的高层思想包含一个 `central node`（中心节点）和若干个 `client nodes`（客户端节点），如 [图 17.1](#Chp017_311-328_B9780443190377000272.xhtml#f0010) 所示。`central node`（中心节点）的任务是从客户端节点（可能是手机或物联网设备等）收集训练好的本地模型，然后执行 `aggregation`（聚合）过程以生成 `global model`（全局模型）。生成的全局模型随后会共享给所有客户端节点。客户端节点将使用其自身的 `local`（本地）数据进一步训练接收到的模型。通常情况下，每个客户端节点拥有的数据量仅占整个数据集的一小部分。

The central node's mission is to collect trained model parameters from the client nodes and perform a specific aggregation process to generate the new global model, which is shared with all of the client nodes. The client nodes usually initial their own model parameters randomly and train the model with their own private data. [图 17.1](#Chp017_311-328_B9780443190377000272.xhtml#cf0140) 量子联邦学习。在量子联邦学习中，存在一个 `central node`（中心节点）和若干个 `client nodes`（客户端节点）。中心节点的任务是从客户端节点收集训练好的模型参数，并执行特定的 `aggregation`（聚合）过程以生成新的 `global model`（全局模型），该模型将共享给所有客户端节点。客户端节点通常随机初始化其自身的模型参数，并使用其私有数据训练模型。在客户端节点从中心节点接收到聚合后的全局模型后，它们将利用自己的数据集进一步训练模型，并将模型上传至中心节点。本图基于文献 [\[19\]](#Chp017_311-328_B9780443190377000272.xhtml#br0095) 的工作绘制。

了解了经典联邦学习之后，将这一思想推广到量子领域是值得考虑的。设想位于不同客户端站点的一组量子计算机。这些设备可能具有不同的计算能力。然而，对于这个提议的场景，假设它们共享相同的规格，例如量子比特数量。存在一个商定的共同任务需要完成，这可能类似于医学图像分类或金融数据建模。这些任务很可能严重依赖专有数据。每个客户端都拥有不应共享的特定敏感或私有数据，但由于数据量相对较小，单个客户端均无法成功训练此类模型。在不共享数据的情况下协同训练量子机器学习模型，正是联邦量子机器学习能够提供帮助的地方。此处的需求是共享训练好的量子模型。因为量子模型实际上是带有一些参数的参数化量子电路，我们需要共享的就是那些电路参数，它们只是可以利用现有通信基础设施轻松传输的“经典”数值。

在近期，可用的量子计算机可能拥有有限数量的量子比特，这意味着大维度的输入数据可能无法直接编码进量子态。因此，有必要采用一种方法来压缩我们想要处理的数据。一种可能的方法是使用经典神经网络执行 `dimensional reduction`（降维）。例如，在图像分类任务中，我们可以采用强大的预训练卷积神经网络（CNN） [\[76\]](#Chp017_311-328_B9780443190377000272.xhtml#br0380) 从感兴趣的数据中提取有价值的特征 [\[64\]](#Chp017_311-328_B9780443190377000272.xhtml#br0320)。这种方法可以被视为一种从经典到量子的 `transfer learning`（迁移学习），最早由文献 [\[53\]](#Chp017_311-328_B9780443190377000272.xhtml#br0265) 引入该领域。[图 17.2](#Chp017_311-328_B9780443190377000272.xhtml#f0015) 展示了此类混合量子-经典迁移学习的通用架构。

![Figure 17.2 Hybrid Quantum-Classical Transfer Learning. This diagram shows the generic structure of hybrid quantum-classical transfer learning first introduced in [53]. This setting features a dataset consisting of classical data entries with large dimensions that cannot be processed by a near-term quantum computer directly. Such entries need to be compressed or dimensionality reduced first before they can be loaded into a quantum circuit. There are various ways to achieve this goal. For example, using a classical neural network to compress the data or more traditional ways such as down-sampling or principal component analysis (PCA). A more efficient way is to use large pre-trained models, such as pre-trained CNNs, to extract important features. For example, in [19], the authors use pre-trained VGG16 [76] to compress the large dimensional images into 4 dimensional vectors, which are suitable for quantum simulation.](OEBPS/images/B9780443190377000272/gr002_u10.jpg)

[图 17.2](#Chp017_311-328_B9780443190377000272.xhtml#cf0160) 混合量子-经典迁移学习。该图展示了混合量子-经典迁移学习的通用结构，最早由文献 [\[53\]](#Chp017_311-328_B9780443190377000272.xhtml#br0265) 引入。此设置包含一个由大维度经典数据条目组成的数据集，这些条目无法被近期量子计算机直接处理。此类条目在加载进量子电路前，首先需要进行压缩或降维。实现这一目标的方法有很多。例如，使用经典神经网络压缩数据，或采用更传统的方式，如下采样或主成分分析（PCA）。一种更高效的方法是使用大型预训练模型（如预训练 CNN）来提取重要特征。例如，在文献 [\[19\]](#Chp017_311-328_B9780443190377000272.xhtml#br0095) 中，作者使用预训练的 VGG16 [\[76\]](#Chp017_311-328_B9780443190377000272.xhtml#br0380) 将大维度图像压缩为 4 维向量，使其适合量子模拟。
