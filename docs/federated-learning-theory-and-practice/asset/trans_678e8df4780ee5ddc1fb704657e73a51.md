

此外，任何酉量子参数化门都可以重写为 `V[l](θ[l]) = exp(iθ[l]H[l])`，其中 `H[l]` 指代门 `V[L]` 的厄米生成元。对 Fubini–Study 度量张量的近似表明，对于变分量子电路中的每个参数化层 `l`，Fubini–Study 度量张量 `g[l, i, j]^+` 的 `n[l] × n[l]` 分块对角子矩阵由以下公式计算：

```
g[l, i, j]^+ = ⟨ψ[l]|H[l](i)H[l](j)|ψ[l]⟩ − ⟨ψ[l]|H[l](i)|ψ[l]⟩⟨ψ[l]|H[l](j)|ψ[l]⟩,
```
(18.8)

其中

```
|ψ[l]⟩ = V[l](θ[l])W[l] ··· V[1](θ[1])W[1]|ψ[0]⟩.
```
(18.9)

注意，公式 (18.9) 中的 `|ψ[l]⟩` 表示在应用参数化层 `l` 之前的量子态。图 18.4 示出了 VQC 的简化版本，其中 `W[1]` 和 `W[2]` 与非参数化门相关，而 `V[1](θ[0], θ[1])` 和 `V[2](θ[2], θ[3])` 分别对应于具有可调参数的参数化门。由于存在两层，每层拥有两个自由参数，因此分块对角近似由两个 `2 × 2` 矩阵 `g[1]^+` 和 `g[2]^+` 组成，它们可以分别表示为

```
g_1^+ = [[⟨z_0^2⟩ − ⟨z_0⟩^2, ⟨z_0 z_1⟩ − ⟨z_0⟩⟨z_1⟩],
         [⟨z_0 z_1⟩ − ⟨z_0⟩⟨z_1⟩, ⟨z_1^2⟩ − ⟨z_1⟩^2]]
```
(18.10)

和

```
g_2^+ = [[⟨y_1^2⟩ − ⟨y_1⟩^2, ⟨y_1 x_2⟩ − ⟨y_1⟩⟨x_2⟩],
         [⟨y_1 x_2⟩ − ⟨y_1⟩⟨x_2⟩, ⟨x_2^2⟩ − ⟨x_2⟩^2]].
```
(18.11)

**图 18.4** 基于 Fubini–Study 度量张量的 VQC 近似方法演示：(a) 基于 Fubini–Study 度量张量的 VQC 分块对角近似；(b) 对 `|ψ[0]〉` 进行 `z[0]`、`z[1]` 的测量；(c) 对 `|ψ[1]〉` 进行 `y[1]`、`x[2]` 的测量。

`g[1]^+` 和 `g[2]^+` 的元素组成 `g^+(θ)`，如下所示：

```
g^+(θ) = [[g_1^+, 0],
          [0, g_2^+]].
```
(18.12)

## 18.5 联邦量子自然梯度下降

**算法 1** 迭代近似。

可以通过以 FL 方式建立 VQC 模型来构建 QFL 系统，给定由子集 `S[1], S[2], …, S[K]` 组成的数据集 `S`，QFL 的目标可以表述为

```
min_θ Σ_{k=1}^K w_k g_k^+(θ) L(θ; S_k),
```
(18.13)

其中 `w[k]` 指代分配给第 `k` 个梯度参与者的系数，每个 `w[k]` 可以估计为

```
w_k = |S_k| / |S| = |S_k| / Σ_{k=1}^K |S_k|.
```
(18.14)

QNGD 算法被应用于每个 VQC，所有 VQC 的上传梯度被聚合以更新全局 VQC 的模型参数。FQNGD 可以在数学上总结为

```
θ̄_{t+1} = θ̄_t − η Σ_{k=1}^K (|S_k| / |S|) g_k^+(θ_t^(k)) ∇L(θ_t^(k); S_k),
```
(18.15)

其中 `θ̄_t` 和 `θ_t^(k)` 分别对应于全局 VQC 的模型参数和第 `k` 个 VQC 模型在第 `t` 个周期的参数，`N[k]` 表示存储在参与者 `k` 中的训练数据量，`K` 个参与者的数据之和等价于 `N`。

与用于 QFL 的 SGD 对应算法相比，FQNGD 算法为梯度提供了自适应学习率，因此根据 VQC 模型状态，收敛速度可以得到加速。
