
此外，为了解决客户端可能不愿在收到奖励前分享其贡献的问题，服务器可以要求每个客户端改为声明 `ϕ(C[m])` 的值，例如在拍卖期间 [[2]](#Chp016_299-309_B9780443190377000260.xhtml#br0010)，或根据早期轮次的贡献来估算第 `t` 轮的 `ϕ(C[m])` [[3]](#Chp016_299-309_B9780443190377000260.xhtml#br0015)。然而，无法访问客户端 `m` 的贡献 `C[m]` 限制了 `ϕ(C[m])` 的选择。例如，如果无法计算包含多个客户端的联盟的模型效用 `ν`（如验证准确率），我们就不能使用 `Shapley value`（沙普利值）来定义 `ϕ(C[m])`。

**真实性 (T)** 激励与 **激励相容性 (IC)** 相关。当一个机制（如用于决定奖励价值的拍卖）使得所有客户端真实申报其成本 `χ[m](C[m], γ[m])`（或成本类型 `γ[m]`）和贡献价值 `ϕ(C[m])` 是最优的（个体利润最大化）时，该机制即为 IC。此外，为了激励客户端提交真实且高质量的信息而非虚假和对抗性的信息，服务器可以根据客户端在早期轮次中的声誉和价值为其分配并考虑声誉 [[10]](#Chp016_299-309_B9780443190377000260.xhtml#br0050)，或利用客户端预测 [[8]](#Chp016_299-309_B9780443190377000260.xhtml#br0040) 或模型更新 [[9]](#Chp016_299-309_B9780443190377000260.xhtml#br0045) 中的相关性来定义 `ϕ(C[m])`。

## 16.5 客户端选择

在本节中，我们将讨论如何从所有 `n` 个客户端中选择一部分客户端 `𝒮`，以解决理性、群体福利和真实性激励问题。当服务器预算 `B(·)` 有限，且因 **可行性 (F)** 约束而无法承担所有客户端的总成本 `∑[m]χ[m](·)` 时，客户端选择显得尤为重要。

对于 **个体理性 (IR)**，任何利润为负的客户端（即 `r[o] < χ[o](·)`）应被排除，不参与协作。对于任何未被选中的客户端 `o`，其成本和奖励（因此利润）均为零，即 `r[o] = χ[o](·) = 0`。

为了最大化 **群体福利 (GW)**，全局服务器应选择那些能以较低的总成本 `∑[m∈𝒮]χ[m](·)` 提高全局模型效用 `ν(w^𝒮)` 的客户端。如果忽略成本，全局服务器可以根据每个客户端 `m` 的贡献价值 `ϕ(C[m])` 对其进行排序，该价值使用上一章联邦学习数据估值中的效用函数定义。还有更具体的策略来增加群体福利。例如，文献 [[15]](#Chp016_299-309_B9780443190377000260.xhtml#br0075) 利用深度强化学习智能地选择每轮 FL 中参与的客户端，以抵消非 IID 数据引入的偏差，并在更少的通信轮数下提高全局模型的效用。

为了同时鼓励 **真实性 (T) / 激励相容性**，文献 [[10]](#Chp016_299-309_B9780443190377000260.xhtml#br0050) 的作者提出，全局服务器根据过去的验证集性能为每个客户端分配 `reputation score`（声誉分数），并在每轮中选择声誉最高的客户端。

## 16.6 奖励分配

本节进一步讨论如何利用贡献价值 `(ϕ(C[m]))[m∈𝒮]` 来设定奖励值 `(r[m])[m∈𝒮]`，以保持公平性并最大化群体福利。此外，我们还将讨论值 `r[m]` 如何对应货币奖励或非货币奖励。这两种设置下的激励条件可能略有不同。

对于货币奖励，每个被选中的客户端 `m` 从全局服务器的预算 `B(·)` 中获得货币支付 `r[m]`，并可选择获得相同的全局模型 `w^𝒮`。负的 `r[m]` 意味着客户端 `m` 应向全局服务器付款。使用货币奖励进行激励实现起来很方便：在决定向每个客户端的支付金额后，很容易落实并向每个客户端支付确切金额。然而，全局服务器和客户端必须就贡献价值 `ϕ(C[m])` 或效用函数 `ν` 的单位变化所对应的货币价值达成一致。全局服务器的利润是模型的货币价值减去总货币支付，即 `ν(w^𝒮) − ∑[m∈𝒮]r[m]`。对于每个被选中的客户端 `m`，其利润是收到的支付减去成本，即 `r[m] − χ[m](C[m], γ[m])`。货币奖励必须同时满足的激励条件为：

**可行性 (F)。** 奖励方案必须确保 **预算平衡**：总货币奖励不得超过预算，即 `∑[m∈𝒮]r[m] ≤ B(·)`。

**个体理性 (IR)。** 每个客户端 `m` 获得的奖励 `r[m]` 至少应等于其成本 `χ[m](·)`，即 `r[m] ≥ χ[m](·)`。

**群体福利 (GW)。** 要最大化的服务器和客户端的总福利/利润为 `ν(w^𝒮) − ∑[m∈𝒮]χ[m](C[m], γ[m])`。

此外，为了最大化仅客户端的福利并激励其参与，服务器应充分利用预算，即 `B(·) = ∑[m∈𝒮]r[m]`（**效率**）。
