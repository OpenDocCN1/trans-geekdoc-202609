
Since the method introduced by [\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070), named `DP-FTS-DE`, is the state-of-the-art algorithm for FBO, we will introduce the details of the `DP-FTS-DE` algorithm in the next section (Section [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035)), and then discuss its theoretical guarantees and empirical performances in Section [14.2.5](#Chp014_257-279_B9780443190377000235.xhtml#s0040).

### 14.2.4 Algorithms for FBO

For ease of understanding, in this section, we will firstly introduce the `DP-FTS` algorithm without the `DE` technique, and then describe how `DP-FTS` can be modified to incorporate `DE` to derive the `DP-FTS-DE` algorithm.

**The DP-FTS algorithm.** [Fig. 14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(a) illustrates the `DP-FTS` algorithm. Every iteration *t* of `DP-FTS` consists of the following steps:

![Figure 14.1 (a) DP-FTS algorithm without distributed exploration; (b)–(c) replacing steps (3) and (5) in (a) with that in (b) and (c) to derive the DP-FTS-DE algorithm (P = 2 sub-regions).](OEBPS/images/B9780443190377000235/gr001_u12.jpg)

Figure 14.1 (a) DP-FTS algorithm without distributed exploration; (b)–(c) replacing steps (3) and (5) in (a) with that in (b) and (c) to derive the DP-FTS-DE algorithm (*P* = 2 sub-regions).

**Steps** ![Image](OEBPS/images/B9780443190377000235/fx002_u2.jpg)**and** ![Image](OEBPS/images/B9780443190377000235/fx003_u1.jpg)**by the agents.** Every agent `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) samples a vector `ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png) following equation [(14.2)](#Chp014_257-279_B9780443190377000235.xhtml#deq2) using its own current history of *t* input–output pairs (step ![Image](OEBPS/images/B9780443190377000235/fx004_u1.jpg)), and then sends `ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png) to the central server – step ![Image](OEBPS/images/B9780443190377000235/fx005_u1.jpg).

**Steps** ![Image](OEBPS/images/B9780443190377000235/fx006_u1.jpg)**and** ![Image](OEBPS/images/B9780443190377000235/fx007_u1.jpg)**by the central server.** Next, the central server processes the *N* received vectors `{ω[n, t]}[n=1,…,N]`![Image](OEBPS/images/B9780443190377000235/si60.png) using a sub-sampled Gaussian mechanism – step ![Image](OEBPS/images/B9780443190377000235/fx008_u1.jpg)– which consists of four steps:

1.  **A.**  Selecting a random subset of agents `𝒮[t] ⊂ {1, …, N}`![Image](OEBPS/images/B9780443190377000235/si61.png) by choosing each agent with probability *q*,
2.  **B.**  Clipping the vector `ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png) of every selected agent such that its *L*[2]![Image](OEBPS/images/B9780443190377000235/si62.png) norm is upper-bounded by *S*, ![Image](OEBPS/images/B9780443190377000235/fx009_u1.jpg),
3.  **C.**  Calculating a weighted average of the clipped vectors with `{φ[n]}[n=1,…,N]`![Image](OEBPS/images/B9780443190377000235/si63_u1.png), `ω_t = (q)⁻¹ Σ_{n ∈ 𝒮_t} φ_n ω̂_{n,t}`![Image](OEBPS/images/B9780443190377000235/si64.png), and
4.  **D.**  Adding noise `ϵ ∼ 𝒩(0, (z S φ_max / q)²)`![Image](OEBPS/images/B9780443190377000235/si65.png) to `ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png) where `φ_max = max[n=1,…,N] φ[n]`![Image](OEBPS/images/B9780443190377000235/si67_u1.png) and *z* is a parameter controlling the privacy-utility trade-off. The final vector `ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png) is then broadcast to all agents – step ![Image](OEBPS/images/B9780443190377000235/fx010_u1.jpg).

**Step** ![Image](OEBPS/images/B9780443190377000235/fx011_u1.jpg)**by the agents.** After an agent `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) receives the vector `ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png) from the central server, it can choose its next query `x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png) (step ![Image](OEBPS/images/B9780443190377000235/fx012_u1.jpg)). Choose `δ ∈ (0, 1)`![Image](OEBPS/images/B9780443190377000235/si69_u1.png) and define `β_t := B + σ√(2(γ_{t-1} + 1 + log(4/δ))`![Image](OEBPS/images/B9780443190377000235/si70_u1.png), in which *B* is an upper bound on the RKHS norm of the objective functions `f^(n)`![Image](OEBPS/images/B9780443190377000235/si71_u1.png)'s (Section [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025)), *σ* is the noise standard deviation (Section [14.2.1](#Chp014_257-279_B9780443190377000235.xhtml#s0020)), and `γ[t-1]`![Image](OEBPS/images/B9780443190377000235/si72_u1.png) is the maximum information gain about `f^(n)`![Image](OEBPS/images/B9780443190377000235/si71_u1.png) from any set of `t-1`![Image](OEBPS/images/B9780443190377000235/si73_u1.png) queries [\[70\]](#Chp014_257-279_B9780443190377000235.xhtml#br0350).

Then, with probability of `p[t + 1] ∈ (0, 1]`![Image](OEBPS/images/B9780443190377000235/si74_u1.png), `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) chooses `x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png) using standard TS by sampling a function `f[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si75_u1.png) from its posterior of `𝒢𝒫(μ[t]^(n)(·), β[t + 1]² σ[t]^(n)(·, ·)²)`![Image](OEBPS/images/B9780443190377000235/si76_u1.png) [(14.1)](#Chp014_257-279_B9780443190377000235.xhtml#deq1) and then choosing `x[t + 1]^(n) = arg max[x ∈ 𝒳] f[t + 1]^(n)(x)`![Image](OEBPS/images/B9780443190377000235/si77.png). Otherwise, with probability of `1 - p[t + 1]`![Image](OEBPS/images/B9780443190377000235/si78.png), `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) chooses `x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png) using `ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png) received from the server, `x[t + 1]^(n) = arg max[x ∈ 𝒳] ϕ(x)^⊤ ω[t]`![Image](OEBPS/images/B9780443190377000235/si79_u1.png). The sequence `(p[t])[t ∈ ℤ⁺]`![Image](OEBPS/images/B9780443190377000235/si80.png) is chosen as a monotonically increasing sequence such that `p[t] ∈ (0, 1]`, `∀t`![Image](OEBPS/images/B9780443190377000235/si81.png) and `p[t] → 1`![Image](OEBPS/images/B9780443190377000235/si82.png) as `t → ∞`![Image](OEBPS/images/B9780443190377000235/si83_u1.png). This ensures that, when `1 - p[t]`![Image](OEBPS/images/B9780443190377000235/si84.png) is large, an agent can leverage the information from the other agents (via `ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)) to improve its convergence by accelerating its exploration.

After choosing `x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png) and observing `y[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si85.png), the agent `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) adds `(x[t + 1]^(n), y[t + 1]^(n))`![Image](OEBPS/images/B9780443190377000235/si86.png) to its history of observations and then samples a new vector `ω[n, t + 1]`![Image](OEBPS/images/B9780443190377000235/si87.png) – step ![Image](OEBPS/images/B9780443190377000235/fx004_u1.jpg). Next, `𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png) sends `ω[n, t + 1]`![Image](OEBPS/images/B9780443190377000235/si87.png) to the central server – step ![Image](OEBPS/images/B9780443190377000235/fx005_u1.jpg)– and the algorithm is repeated.

**The DP-FTS-DE algorithm.** The `DP-FTS-DE` algorithm is obtained by incorporating the technique of `DE` into `DP-FTS` described above.
