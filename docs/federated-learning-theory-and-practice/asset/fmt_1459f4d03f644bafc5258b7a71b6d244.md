
where `k_t(x) := (k(x, x_τ))_{τ=1,…,t}^⊤` is a `t`-dimensional column vector, `y_t := (y_τ)_{τ=1,…,t}^⊤` is also a `t`-dimensional column vector, `K_t := (k(x_τ, x_τ'))_{τ,τ'=1,…,t}` is a `t × t`-dimensional matrix and `λ > 0` is a regularization parameter [10]. In iteration `t + 1`, the GP posterior (14.1) is used to calculate an *acquisition function*, which is then maximized to select the next query `x_{t+1}`. For example, the classic *Thompson sampling* (TS) [10] algorithm first samples a function `f_{t+1}` using the GP posterior (14.1) and then uses it as the acquisition function to chooses `x_{t+1} = arg max_{x ∈ X} f_{t+1}(x)`. BO algorithms are usually analyzed in terms of *regrets* [70]. A hallmark for well-performing BO algorithms is to be asymptotically *no-regret*, which requires the *cumulative regret* `R_T := ∑_{t=1}^T (f(x^*) - f(x_t))` to grow sub-linearly so that the simple regret `S_T := min_{t=1,…,T} (f(x^*) - f(x_t)) ≤ R_T / T` goes to 0 asymptotically.

To reduce the computational cost of GP posterior inference (14.1), *random Fourier features* (RFFs) [59] is commonly adopted to approximate the kernel function `k` using `M`-dimensional random features `ϕ`: `k(x, x') ≈ ϕ(x)^⊤ ϕ(x')`. RFFs offers a high-probability guarantee on the approximation quality, i.e., we have that `sup_{x, x' ∈ X} |k(x, x') - ϕ(x)^⊤ ϕ(x')| ≤ ε`, in which `ε = O(M^{-1/2})` [59]. Of note, RFFs makes it particularly convenient to approximately sample a function from the GP posterior (14.1). Specifically, define `Φ_t := (ϕ(x_τ))_{τ ∈ [t]}^⊤` (i.e., a `t × M`-dimensional matrix), `Σ_t := Φ_t^⊤ Φ_t + λ I`, and `ν_t := Σ_t^{-1} Φ_t^⊤ y_t`. To sample a function `f̃` from the GP posterior with the approximate kernel `k̃(x, x') ≈ ϕ(x)^⊤ ϕ(x')`, we only need to sample an `M`-dimensional vector

```
ω ∼ N(ν_t, λ Σ_t^{-1})
```

### 14.2.2 Background on federated Bayesian optimization

Here we present the problem setting of *federated BO* (FBO), which follows the works of [14] and [15]. FBO involves a central server and `N` agents/clients `A_1, …, A_N`. Every agent `A_n` attempts to maximize its own objective function `f^{(n)} : X → R`, i.e., to find `x_*^{(n)} ∈ arg max_{x ∈ X} f^{(n)}(x)`, by querying `x_t^{(n)}` and observing `y_t^{(n)}`, `∀ t = 1, …, T`. As a representative motivating example, `N` mobile phone users (agents) who use DNNs for next-word prediction in a smart keyboard application may wish to collaboratively tune the hyperparameters of their DNNs. In this application, agent (mobile phone user) `A_n` sequentially queries the hyperparameter configurations `x_t^{(n)} ∈ X`, `∀ t = 1, …, T` in order to maximize its validation accuracy denoted by the function `f^{(n)} : X → R`. As another example, a hospital can use BO to select the patients to perform a medical test to assess the possibility of readmission [81], and multiple hospitals may wish to collaborate to achieve better patient selection strategies. In this case, the input query `x_t^{(n)} ∈ X` selected by hospital `A_n` in iteration `t` corresponds to the features representing the selected patient, and the corresponding value of the objective function `f^{(n)}(x_t^{(n)})` represents the test score for the selected patient `x_t^{(n)}`.
