
正如之前所讨论的，联邦学习（FL）算法的目标是在确保通信和计算效率以及数据隐私的前提下，求解问题[(3.1)](#Chp003_57-74_B9780443190377000119.xhtml#deq1)。近年来，FL 研究呈指数级增长，许多算法针对不同问题类别实现了最先进的性能[[13](#Chp003_57-74_B9780443190377000119.xhtml#br0065),[14](#Chp003_57-74_B9780443190377000119.xhtml#br0070),[19](#Chp003_57-74_B9780443190377000119.xhtml#br0095),[40]](#Chp003_57-74_B9780443190377000119.xhtml#br0200)。然而，最流行的 FL 算法仍然是标准的 FedAvg，如[算法 1](#Chp003_57-74_B9780443190377000119.xhtml#f0010)所述。更具体地说，在每个通信轮次 `t` 中，会采样一部分客户端 `C[t]`。然后，采样的客户端利用上一轮聚合的参数，采用 SGD 作为本地优化器来更新其本地模型。经过 `τ[m]` 次本地更新后，采样的客户端向服务器共享总更新差值 `Δw[m]^(t)`。服务器随后聚合收集到的模型差值以更新全局模型。请注意，[算法 1](#Chp003_57-74_B9780443190377000119.xhtml#f0010) 中呈现的 FedAvg 采用了*双边*学习率，即*同时*由本地代理和服务器使用经过良好校准的学习率来分别更新本地和全局模型[[37]](#Chp003_57-74_B9780443190377000119.xhtml#br0185)。这涵盖了 FedAvg 的原始版本作为一种特殊情况，即服务器的学习率设置为 `η[g] = 1`[[21]](#Chp003_57-74_B9780443190377000119.xhtml#br0105)。

### 3.2.2 差分隐私

差分隐私（DP）是利用相邻数据集的概念定义的，该概念可以以特定应用的方式进行表征。大多数机器学习从业者使用 DP 的 `(ε, δ)` 定义[[5]](#Chp003_57-74_B9780443190377000119.xhtml#br0025)，这是[[6]](#Chp003_57-74_B9780443190377000119.xhtml#br0030)中给出的 DP 原始定义的一个轻微变体。`(ε, δ)`-DP 定义如下。

**定义 3.1**

如果对于任意两个相邻数据集 `D` 和 `D'` 以及算法 `A` 的任意输出子集 `S`，都有

`P(A(D) ∈ S) ≤ e^(ε) ⋅ P(A(D') ∈ S) + δ`，

则称随机算法 `A` 对某些 `ε > 0` 和 `δ > 0` 满足 `(ε, δ)`-DP。

![Image](OEBPS/images/B9780443190377000119/si18_u8.png)(3.2)

上述定义表明，为了使算法达到 `(ε, δ)`-DP，该算法在两个相邻数据集上的输出应具有相似的分布。这意味着任何拥有 `A(D)` 和 `A(D')` 访问权限的对手都将无法区分这两个数据集，从而确保了这两个数据集的隐私。如前所述，相邻数据集可以以特定应用的方式定义。这在 FL 中引出了样本级和客户端级的 DP 概念，我们将在下文中定义。

**定义 3.2**

样本级差分隐私（DP）

考虑数据集 `D = ⋃_{m=1}^n D_m`，其中 `m` 是问题[(3.1)](#Chp003_57-74_B9780443190377000119.xhtml#deq1)中定义的单个代理。如果[(3.2)](#Chp003_57-74_B9780443190377000119.xhtml#deq2)成立，其中相邻数据集 `D` 和 `D'` 在代理 `m ∈ [n]` 处最多相差单个样本 `(x[m], c[m])`，则称算法实现了 `(ε, δ)` 样本级 DP。

样本级 DP 旨在用于单个数据样本可能泄露敏感信息的场景。例如，医学诊断中的训练数据可能包含患者的私人信息，需要受到保护。在 FL 中，样本级 DP 常用于*跨孤岛*设置，其中单个代理通常是组织（例如医学诊断示例中的医院），且代理数量较少。

另一方面，也存在需要保护单个代理身份的情况。例如，在典型的*跨设备* FL 设置中，大量移动设备参与联合训练会话，客户端可能不愿透露其身份。一个例子是 Google Keyboard 应用[[9]](#Chp003_57-74_B9780443190377000119.xhtml#br0045)，其中每个代理是一个应用用户，为了保护用户的个人信息，保护用户身份是必要的。对于此类情况，需要一种称为*客户端级 DP*的更强 DP 概念。

**定义 3.3**

客户端级差分隐私（DP）

考虑数据集 `D = {D[m]}_{m=1}^n`，其中 `m ∈ [n]` 是问题[(3.1)](#Chp003_57-74_B9780443190377000119.xhtml#deq1)中定义的单个代理。如果[(3.2)](#Chp003_57-74_B9780443190377000119.xhtml#deq2)成立，其中相邻数据集 `D` 和 `D'` 在代理 `m ∈ [n]` 处最多相差一个完整数据集 `D[m]`，则称算法实现了 `(ε, δ)` 客户端级 DP。

请注意，与样本级 DP 相比，客户端级 DP 是一种相对更强的 DP 概念，因为它掩盖的是完整数据集的身份，而不仅仅是单个样本。DP 有一些有用的特性，使其特别适合 FL 应用：

1.  **后处理**，即如果一种机制满足 DP，则对手无法通过进一步处理提取关于数据库的任何额外信息。形式上，它指出
