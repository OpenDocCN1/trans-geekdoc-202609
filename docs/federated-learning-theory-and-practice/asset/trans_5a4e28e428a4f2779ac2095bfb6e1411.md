
具体而言，DE 将整个域 `𝒳` 划分为 `P ≥ 1` 个不相交的子区域 `𝒳[1], …, 𝒳[P]`，而 DE 的引入要求对 DP-FTS 进行三项主要修改。首先，在初始化阶段，每个智能体仅探索局部子区域 `𝒳[i]`，而非整个域 `𝒳`。

接下来，中央服务器不再生成并广播单个向量 `ω[t]`，而是生成并广播 `P` 个向量 `{ω[t]^(i)}[i=1,…,P]`，每个向量对应不同的子区域 `𝒳[i]`，并使用不同的一组权重 `{φ[n]^(i)}[n=1,…,N]`。有趣的是，中央服务器为生成 `P` 个向量而执行的不同隐私保护变换，可以被解释为单个子采样高斯机制生成单个联合向量 `ω[t]^(joint) ≜ (ω[t]^(i))[i ∈ [P]]`（[图 14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(b)）。

然后，如果智能体 `𝒜[n]` 使用从中央服务器接收到的向量 `ω[t]^(joint) = (ω[t]^(i))[i ∈ [P]]` 来选择下一个查询 `x[t+1]^(n)`（概率为 `1 − p[t+1]`），它将通过最大化所有子区域的重构函数来选择 `x[t+1]^(n)`，如[图 14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(c)所示。关于 DP-FTS-DE 算法的更完整描述，请参阅文献 `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` 的工作。

### 14.2.5 FBO 的理论与实证结果

文献 `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` 的工作为 DP-FTS-DE 的隐私性和效用性均提供了理论保证。隐私保证由下述命题给出：

**命题 14.1**

*存在常数 `c[1]` 和 `c[2]`，使得对于固定的 q 和 T 以及任意 `ϵ < c[1]q²T`、`δ > 0`，若 `z ≥ c₂q√(T log(1/δ))/ϵ`，则 DP-FTS-DE 满足 `(ϵ, δ)`-DP。*

以下定理给出了 DP-FTS-DE 效用/性能的保证，以 `R[T]¹` 的上界形式表示（第 [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025) 节），其中所有符号均已在第 [14.2.1](#Chp014_257-279_B9780443190377000235.xhtml#s0020)、[14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025) 和 [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035) 节中定义：

**定理 14.1**

**非正式表述**

*以高概率，*

```
R_T^1 = \widetilde{\mathcal{O}}\left( \left( B + 1/p_1 \right)\gamma_T\sqrt{T}\ + \ \sum_{t = 1}^{T}\psi_t\ + \ B\sum_{t = 1}^{T}\vartheta_t \right),
```

*其中 `\psi_t := \widetilde{\mathcal{O}}((1 - p_t)P\varphi_{\max}q^{-1}(\Delta_t + zS\sqrt{M}))`，且 `\Delta_t := \sum_{n = 1}^{N}\widetilde{\mathcal{O}}(\varepsilon Bt^2 + B + \sqrt{M} + d_n + \sqrt{\gamma_t})`。`\vartheta_t := (1 - p_t)\sum_{i = 1}^{P}\sum_{n \in \mathcal{C}_t}\varphi_n^{(i)}`，`\mathcal{C}_t := \{ n \in [N] \mid ||\mathbf{\omega}_{n,t}||_2 > S/\sqrt{P} \}`。*

从[定理 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015)获得的第一个有趣见解是，即使所有其他智能体都是异构的（即所有其他智能体具有与 `𝒜[1]` 显著不同的目标函数），智能体 `𝒜[1]` 在渐近意义上也是*无懊悔*的。这确保了 DP-FTS-DE 对智能体异构性的鲁棒性，而这是 FBO 中的一项重大挑战（第 [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025) 节）。

此外，结合[命题 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010) 来解读[定理 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015)，还揭示了关于**隐私-效用权衡**的一些有趣理论见解。首先，较大的 `z`（即添加的高斯噪声方差较大，第 [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035) 节）能改善隐私保证（[命题 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010)），但会导致效用变差，因为它会导致更差的懊悔上界（通过 `\psi_t`）。其次，较大的 `q`（即每次迭代中选中的智能体更多，第 [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035) 节）能改善效用，因为它收紧了懊悔上界（通过降低 `\psi_t` 的值），但这是以牺牲隐私保证为代价的（[命题 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010)）。裁剪阈值 `S` 的值通过两种相互冲突的效应影响懊悔上界（从而影响效用）：较小的 `S`（1）降低 `\psi_t` 的值（从而降低懊悔界），但也可能扩大集合 `C[t]` 的基数，从而增加 `\vartheta_t` 的值，进而增加懊悔界（[定理 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015)）。关于 DP-FTS-DE 理论保证及相关见解的更详细讨论，请参阅文献 `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` 的第 4 节。
