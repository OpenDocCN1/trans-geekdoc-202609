
当 *α* → ∞ 时，RDP[*α*] 收敛于标准的 (*ε*, 0)-DP。*ε* 和 *δ* 都应为正数或等于零。考虑到 *δ* → 0 仅带来微小的放宽，较小的 *ε* 值意味着更强的 (*ε*, 0)-差分隐私保证。换句话说，来自相邻输入 *d* 和 *d*′ 的概率在 [(20.1)](#Chp020_353-368_B9780443190377000302.xhtml#deq1) 中几乎相等，这使得数据身份更难推断。此外，基于语音数据的后处理特征学习（例如梅尔频谱 [[6](#Chp020_353-368_B9780443190377000302.xhtml#br0030), [16]](#Chp020_353-368_B9780443190377000302.xhtml#br0080)）也可以是差分隐私的，这已由 [[1](#Chp020_353-368_B9780443190377000302.xhtml#br0005), [18]](#Chp020_353-368_B9780443190377000302.xhtml#br0090) 中给出的定理证明。我们旨在进一步研究本提案中加性 DP 噪声与基于神经网络模型鲁棒性之间的性能权衡，这仍然是一个开放性问题，即如何设计高性能的 DP 保护语音模型并理解其极限。作为一种流行的基于深度神经网络的 DP 保护基线，我们回顾了差分隐私随机梯度下降（DPSGD） [[65]](#Chp020_353-368_B9780443190377000302.xhtml#br0325)。DPSGD 基于随机梯度下降（SGD） [[30]](#Chp020_353-368_B9780443190377000302.xhtml#br0150)，后者是一种用于求解凸优化问题的迭代优化方法。SGD 从起始点 *w*[0] 开始，在第 *t* 步按如下方式更新迭代值：

*w*[*t* + 1] = *w*[*t*] − *η*[*t*](*λw*[*t*] + ∇ℓ(*w*[*t*], *x*[*t*], *y*[*t*])),

(20.3)

其中 *η*[*t*] 表示学习率，(子)梯度 ∇ℓ(*w*[*t*], *x*[*t*], *y*[*t*]) 基于单个输入 *x*[*t*] 和标签 *y*[*t*] 计算得出。为了引入 DP 噪声，DPSGD 更新定义为：

*w*[*t* + 1] = *w*[*t*] − *η*[*t*](*λw*[*t*] + ∇ℓ(*w*[*t*], *x*[*t*], *y*[*t*]) + *Z*[*t*]),

(20.4)

其中每个 *Z*[*t*] 是一个在 *R*^(*d*) 中的随机噪声向量，独立地从密度 *ρ*(*z*) ∝ *e*^(−(*α*/2)∥*z*∥) 中抽取。DPSGD 最近 [[15]](#Chp020_353-368_B9780443190377000302.xhtml#br0075) 被引入大规模优化机学习主干网络，以取代 SGD 来在 DP 度量下训练模型。然而，直接的数据库级 DP 扰动和 DPSGD 都会在很大程度上降低模型性能。当 ASR 和语音助手生产仍然是性能驱动的任务时，我们将介绍一些近期的联邦训练方法来提升 ASR 性能。

## 20.1.5 用于联邦 ASR 的师生学习

如何减少隐私预算并部署性能驱动的 ASR 系统是一个极具挑战性的课题。为了降低标准数据无关界限上的隐私成本，Papernot 等人 [[46]](#Chp020_353-368_B9780443190377000302.xhtml#br0230) 通过深度神经网络的**集成学习**，提供了一个通用的数据相关上界的理论分析，这需要更少的预测损失成本来达到目标 DP 隐私预算 (*ε*)。我们可以在 *ε*-DP 下扩展随机隐私保护算法 ℳ（在 [(20.1)](#Chp020_353-368_B9780443190377000302.xhtml#deq1) 中引入），其中 *ε* 等于 2*γ*^()

$$
\alpha\left( l;d,d^{\prime} \right) \leqslant \log\left( (1 - \tau)\left( \frac{1 - \tau}{1 - e^{2\gamma}\tau} \right)^{l} + \tau e^{(2\gamma l)} \right).
$$

(20.5)

界限 [(20.5)](#Chp020_353-368_B9780443190377000302.xhtml#deq5) 建立在基于 *ε*-DP 的聚合方法的组合定理 [[19]](#Chp020_353-368_B9780443190377000302.xhtml#br0095) 基础之上。更多细节请参阅 [[46]](#Chp020_353-368_B9780443190377000302.xhtml#br0230) 中的定理 1 和定理 3。

我们现在描述基于教师集成的私有聚合（PATE） [[46](#Chp020_353-368_B9780443190377000302.xhtml#br0230), [47]](#Chp020_353-368_B9780443190377000302.xhtml#br0235) 声学建模，以在联邦设置中实现 *ε*-DP。首先，通过将训练数据集划分为 *I* 个不相交的子集 𝒟[1], …, 𝒟[*I*] 来构建教师模型集成。接下来，利用这些子集独立训练 *I* 个教师模型 𝒯[1], …, 𝒯[*I*]。它们被用来生成声学模型得分 [[8]](#Chp020_353-368_B9780443190377000302.xhtml#br0040)，通过加权平均来自 ASR 模型的上下文相关状态后验概率，作为一种有效的师生学习方式来聚合教师的帧级预测。对于每一帧音频 *x*，最终聚合的教师模型生成一个关于上下文相关状态 *s* 的后验概率向量 𝒯[*ens*](*s*|*x*)，计算如下：

$$
\mathcal{T}_{ens}(s|x) = \sum\limits_{i = 1}^{I}w_{i}\mathcal{T}_{i}(s|x),
$$

(20.6)

其中 𝒯[*i*](*s*|*x*) 是第 *i* 个模型的后验概率，*w*[*i*] 是其加权系数。在输出对齐之前（例如，考虑对齐前的特殊静音字符），来自各个教师模型的对应状态具有相同的维度 *J*。

为了在 PATE 方法下确保 *ε*-DP，向各个教师的预测 (𝒯[*i*]) 中引入了随机扰动。我们修订 [(20.6)](#Chp020_353-368_B9780443190377000302.xhtml#deq6) 以获得来自带噪教师的最终集成：

$$
\mathcal{T}_{PATE}(x,\lambda) = \sum\limits_{i = 1}^{I}w_{i}\left( \mathcal{T}_{i}(x) + Y_{j}(\lambda) \right),
$$

(20.7)

其中 *Y*[1], …, *Y*[*m*] 是位置为 0、尺度为 *λ*^(−1) 的独立同分布拉普拉斯或高斯随机变量，其中 *λ* 是指影响 (*ϵ*, *δ*)-DP 保证的隐私参数，并且在适用于模型聚合的组合定理下已证明了其界限 [[46](#Chp020_353-368_B9780443190377000302.xhtml#br0230), [47]](#Chp020_353-368_B9780443190377000302.xhtml#br0235)。
