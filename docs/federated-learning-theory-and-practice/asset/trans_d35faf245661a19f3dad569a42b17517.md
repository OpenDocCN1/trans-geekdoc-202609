
例如，在[\[19\]](#Chp017_311-328_B9780443190377000272.xhtml#br0095)中，作者使用*变分编码*方案将经典值（如像素值或压缩表示）编码进量子态。该编码方案的基本思想是将输入值或其变换作为量子旋转门的旋转角度。如[图 17.7](#Chp017_311-328_B9780443190377000272.xhtml#f0040)所示，编码部分由单量子比特旋转门`R[y]`和`R[z]`组成，并使用`arctan(x[i])`和`arctan(x[i]²)`作为相应的变换。

### 17.3.2 量子梯度

混合量子-经典模型可遵循训练经典深度神经网络常用的反向传播方法，以端到端的方式进行训练。采用`Parameter-shift`（参数平移）方法计算量子函数的梯度。文献[\[8\]](#Chp017_311-328_B9780443190377000272.xhtml#br0040)、[\[69\]](#Chp017_311-328_B9780443190377000272.xhtml#br0345)所述方法可用于推导量子电路的解析梯度。参数平移规则背后的思想是：给定计算特定可观测量子函数期望值的知识，量子梯度可在不使用有限差分法的情况下计算得出。例如，给定关于如何计算可观测量`P̂`在量子函数上的期望值的知识，

`f(x;θ[i]) = ⟨0|U[0]^†(x)U[i]^†(θ[i])P̂U[i](θ[i])U[0](x)|0⟩ = ⟨x|U[i]^†(θ[i])P̂U[i](θ[i])|x⟩`

(17.4)

其中`x`为输入值（如像素值或其他加载进量子电路的经典输入）；`U[0](x)`为将`x`变换或编码为量子态的态制备例程；`i`为待求梯度的电路参数索引；`U[i](θ[i])`表示由泡利算符`X`、`Y`、`Z`生成的单量子比特旋转。文献[\[57\]](#Chp017_311-328_B9780443190377000272.xhtml#br0285)表明，该量子函数`f`关于参数`θ[i]`的梯度为

```
∇_θ_i f(x;θ_i) = 1/2 [ f(x;θ_i + π/2) - f(x;θ_i - π/2) ]
```

(17.5)

获得量子函数的梯度后，下一步是更新实际参数。最简单的方法是执行经典梯度下降更新，可写为

`θ ← θ − η∇[θ]L(x; θ)`
