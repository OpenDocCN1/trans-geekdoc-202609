

## 解的存在性

我们首先假设 $F^\star := \inf_w F(w)$ 有一个下界，即 $F^\star > -\infty$，以保证 [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) 的良定性。许多机器学习应用自动满足此条件，因为底层损失函数通常是非负的。一个显而易见的例子是最小二乘问题。

我们接下来的问题是：*是否*存在 [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) *的最优解？* 为了讨论这一方面，我们使用非线性分析中的强制性概念 [\[18\]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0090)。我们称 $F$ 为强制函数，如果 $\lim_{\|w\| \to \infty} F(w) = +\infty$。一个常见的强制函数是 $F(w) := \mathcal{L}(w) + \frac{\lambda}{2}\| w\|^2$，其中 $\mathcal{L}$ 是 $M$-Lipschitz 连续的（但不一定是凸的）且 $\lambda > 0$。如果 $F$ 是连续且强制的，那么根据著名的魏尔斯特拉斯定理，[(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) 存在全局最优解 $w^\star$。在这种情况下，我们用 $F^\star := F(w^\star)$ 表示其最优值。如果 $F$ 是非凸且可微的，那么我们用 $w^\star$ 表示其驻点，即 $\nabla F(w^\star) = 0$。如果 $F$ 不可微，则需要驻点的推广 [\[40\]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0200)。为保持简单，我们假设本章中 $F$ 始终是连续可微的。

如果 $F$ 是强凸的，那么它是连续且强制的，并且 [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) 有一个唯一的全局最优解。对于凸问题，我们的目标是按某种意义找到 $w^\star$ 的近似全局解 $\hat{w}^\star$（见第 [1.2.7](#Chp001_3-28_B9780443190377000089_split_001.xhtml#s0065) 节）。对于非凸问题，我们只期望计算一个近似驻点 $\hat{w}^\star$，它可以是局部极小值点的候选者。然而，我们在本章中不尝试检查它是否为近似局部极小值点。

## 1.2 GD 型方法的基本组成部分

梯度下降（GD）法是一种旨在寻找 [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) 近似解的迭代方法。这可以追溯到 19 世纪柯西的工作，并在数值分析中（包括优化）被深入研究了几十年。在过去二十年里，由于在信号和图像处理、现代统计学以及机器学习中的应用，一阶方法，特别是梯度型算法，出现了巨大的增长。在本章中，我们不试图回顾 GD 型方法的文献，而仅侧重于总结其基本组成部分。

形式上，梯度下降算法从给定的初始点 $w^0 \in \mathbb{R}^{(p)}$ 开始，在每次迭代 $t \ge 0$ 时，它进行更新

$$w^{(t+1)} := \mathcal{P}(w^{(t)} + \eta_t d^{(t)}), \tag{1.2}$$

其中 $w^{(t)}$ 是当前迭代点，$\eta_t > 0$ 称为步长或学习率，$d^{(t)}$ 称为搜索方向，$\mathcal{P}$ 是用于处理约束或正则化项的算子；如果不需要此项，可以设置 $\mathcal{P} = \mathbb{I}$，即单位算子。该方法仅利用 $F$ 的一阶信息（例如函数值、近端算子或[次]梯度）生成一系列迭代向量 $\{w^{(t)}\}$。在此，我们添加了一个算子 $\mathcal{P}$，它也可用于处理约束、正则化项、惩罚项或 Bregman 距离（例如原始空间与对偶空间之间的映射）。让我们讨论方案 [(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) 的每个组成部分。

### 1.2.1 搜索方向

[(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) 中最重要的组成部分是搜索方向 $d^{(t)}$，它决定了算法的类型，如一阶、二阶、拟牛顿型或随机方法。让我们考虑以下可能性：

*   **下降方向。** 假设 $F$ 连续可微，如果 $\langle \nabla F(w^{(t)}), d^{(t)} \rangle < 0$，则搜索方向 $d^{(t)}$ 在迭代点 $w^{(t)}$ 处被称为下降方向。我们甚至可以施加一个更强的条件，称为严格下降方向，即 $\langle \nabla F(w^{(t)}), d^{(t)} \rangle \le -c \|\nabla F(w^{(t)})\|^2$，其中 $c > 0$。“下降”这个名称源于这样一个事实：如果我们从 $w^{(t)}$ 沿着方向 $d^{(t)}$ 以适当的步长 $\eta_t$ 移动，则会得到下降，即 $F(w^{(t+1)}) < F(w^{(t)})$。如果 $\mathcal{P} = \mathbb{I}$（单位算子），则 [(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) 简化为 $w^{(t+1)} := w^{(t)} + \eta_t d^{(t)}$。由 $F$ 的泰勒展开，我们有

$$F(w^{(t+1)}) = F(w^{(t)}) + \eta_t \langle \nabla F(w^{(t)}), d^{(t)} \rangle + o(\eta_t^2 \|d^{(t)}\|^2) < F(w^{(t)}).$$
