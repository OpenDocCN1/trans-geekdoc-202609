

### 随机递归梯度估计器

$$v^{(t)} := v^{(t-1)} + \left[\nabla \mathbf{F}(w^{(t)}, \mathcal{S}_t) - \nabla \mathbf{F}(w^{(t-1)}, \mathcal{S}_t)\right] \tag{1.24}$$

这被称为**随机递归梯度估计器**。不幸的是，该估计是有偏的，即 $\mathbb{E}_{\mathcal{S}_t}[v^{(t)}] \neq \nabla F(w^{(t)})$。然而，可以证明：

$$\mathbb{E}_{\mathcal{S}_t}[v^{(t)}] = \nabla F(w^{(t)}) + e_t \quad \text{and} \quad \mathbb{E}_{\mathcal{S}_t}[\|v^{(t)} - \nabla F(w^{(t)})\|^2] \leq \sigma_t^2,$$

其中 $e_t := v^{(t-1)} - \nabla F(w^{(t-1)})$ 是误差项，且若 $\mathbf{F}$ 为 $L$-平均光滑，则有 $\sigma_t^2 \leqslant \sigma_{t-1}^2 + \frac{L^2}{b_t}\| w^t - w^{t-1} \|^2$（参见 [52]）。

另一个有趣的估计器是文献 [66] 中提出的混合方差缩减估计器，其形式为：

$$v^{(t)} := (1 - \beta_t)\left[v^{(t-1)} + \left(\nabla \mathbf{F}(w^{(t)}, \mathcal{S}_t) - \nabla \mathbf{F}(w^{(t-1)}, \mathcal{S}_t)\right)\right] + \beta_t u^{(t)}, \tag{1.25}$$

其中 $\beta_t \in [0, 1]$，且 $u^{(t)}$ 是 $\nabla F(w^{(t)})$ 的无偏估计器，方差为 $\hat{\sigma}_t^2$，即 $\mathbb{E}[\|u^{(t)} - \nabla F(w^{(t)})\|^2 | \mathcal{F}_t] \leq \hat{\sigma}_t^2$。同样，如文献 [66] 所证，这是 $\nabla F(w^{(t)})$ 的有偏估计器。若 $\mathbf{F}$ 为 $L$-平均光滑，则 $v^{(t)}$ 满足 $\mathbb{E}[\|v^{(t)} - \nabla F(w^{(t)})\|^2] \leq \sigma_t^2$，其中

$$\sigma_t^2 \leqslant (1 - \beta_t)^2 \sigma_{t-1}^2 + \frac{2(1 - \beta_t)^2 L^2}{b_t}\| w^t - w^{t-1} \|^2 + 2\beta_t^2 \hat{\sigma}_t^2.$$

$u^{(t)}$ 的一个简单选择是 $u^{(t)} := \nabla \mathbf{F}(w^{(t)}, \mathcal{S}_t)$。此时，$\hat{\sigma}_t^2 = \frac{\sigma^2}{b_t}$。

### 1.3.3 统一收敛分析

#### (a) 通用方法

让我们确定 [算法 1](#Chp001_3-28_B9780443190377000089_split_002.xhtml#f0010) 收敛分析中的关键步骤。最重要的步骤之一是建立关于内层迭代 $t$ 的递归估计，形式如 [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) 所示，但在条件期望下：

$$\mathbb{E}[D_{t+1} | \mathcal{F}_t] + \Delta_t \leq \omega_t \cdot D_t + E_t, \tag{1.26}$$

其中相关量的定义类似于 [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14)。若对 [(1.26)] 两边取全期望，并假设 $\omega_t = \frac{\xi_t}{\xi_{t+1}}$（其中 $\xi_t > 0$）且 $\mathbb{E}[E_t] \leq \theta_t^2 M^2$（其中 $M \geq 0, \theta_t > 0$），则有：

$$\xi_{t+1}\mathbb{E}[D_{t+1}] + \xi_{t+1}\mathbb{E}[\Delta_t] \leq \xi_t \cdot \mathbb{E}[D_t] + \xi_{t+1}\theta_t^2 M^2.$$

通过数学归纳法，可得：

$$\xi_{T+1}\mathbb{E}[D_{T+1}] + \sum_{t=0}^{T} \xi_{t+1}\mathbb{E}[\Delta_t] \leq \xi_0 \mathbb{E}[D_0] + M^2 \sum_{t=0}^{T} \xi_{t+1}\theta_t^2. \tag{1.27}$$

令 $S_T := \sum_{t=0}^{T} \gamma_t$，给定权重 $\gamma_t > 0$（通常依赖于 $\xi_t$ 和/或 $\theta_t$）。将 [(1.27)] 两边同除以 $S_T$，得到：

$$\frac{1}{S_T}\sum_{t=0}^{T} \xi_{t+1}\mathbb{E}[\Delta_t] \leq \frac{\xi_0 \mathbb{E}[D_0]}{S_T} + \frac{M^2}{S_T}\sum_{t=0}^{T} \xi_{t+1}\theta_t^2. \tag{1.28}$$

估计式 [(1.27)] 和 [(1.28)] 均可用于估计基础算法的收敛速率。下面我们应用此方法证明 [算法 1](#Chp001_3-28_B9780443190377000089_split_002.xhtml#f0010) 某些变体的收敛性。

#### (b) 非光滑凸问题的 SGD

分析 SGD 方案 [(1.21)](#Chp001_3-28_B9780443190377000089_split_002.xhtml#deq33) 的收敛性。利用更新式 [(1.21)]，有：

$$\|w^{(t+1)} - w^\star\|^2 = \|w^{(t)} - w^\star\|^2 - 2\eta_t \langle v^{(t)}, w^{(t)} - w^\star \rangle + \eta_t^2 \|v^{(t)}\|^2.$$

对该估计取条件期望 $\mathbb{E}[\cdot | \mathcal{F}_t]$，并注意到 $\mathbb{E}[v^{(t)} | \mathcal{F}_t] = \nabla F(w^{(t)})$，可得：

$$\eta_t \langle \nabla F(w^t), w^t - w^\star \rangle = \frac{1}{2}\|w^t - w^\star\|^2 - \frac{1}{2}\mathbb{E}[\|w^{t+1} - w^\star\|^2 | \mathcal{F}_t] + \frac{\eta_t^2}{2}\mathbb{E}[\|v^t\|^2 | \mathcal{F}_t].$$

若 $F$ 为凸函数，则 $F(w^{(t)}) - F(w^\star) \leq \langle \nabla F(w^{(t)}), w^{(t)} - w^\star \rangle$。此外，亦有 $\mathbb{E}[\|v^{(t)}\|^2 | \mathcal{F}_t] \leq M^2$。结合上述两式及最后一个不等式，得：

$$\underbrace{\frac{1}{2}\mathbb{E}[\|w^{t+1} - w^\star\|^2 | \mathcal{F}_t]}_{\mathbb{E}[D_{t+1} | \mathcal{F}_t]} + \underbrace{\eta_t [F(w^t) - F(w^\star)]}_{\Delta_t} \leq \underbrace{\frac{1}{2}\|w^t - w^\star\|^2}_{D_t} + \underbrace{\frac{\eta_t^2}{2}M^2}_{E_t}.$$
