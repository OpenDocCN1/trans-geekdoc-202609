
其中 `w[t]` 表示第 `t` 次迭代后的模型；`w[t]` 用于计算 `f(w[t]; ξ)` 的梯度，其中 `ξ` 是从数据集 `{ξ[i]}_{i=1}^m` 中随机选择的一个数据样本，该数据集包含所有本地数据集的并集。

这种方法允许每个客户端对属于该客户端本地训练数据集的数据样本 `ξ` 执行本地 SGD 递归。SGD 递归 [(2.2)](#Chp002_29-55_B9780443190377000090_split_000.xhtml#deq2) 产生的更新被发送到一个中心服务器，该服务器聚合所有接收到的更新并维护一个全局模型。服务器定期广播其最新的全局模型，以便客户端能在其本地 SGD 计算中使用。这使得每个客户端能够利用从其他客户端的本地数据集中学到的知识。这有助于提高最终全局模型的准确性。

每个客户端对一批本地数据执行 SGD 递归。这些递归共同代表一轮本地训练，在本地轮结束时，一个本地模型更新（以该轮计算出的梯度聚合形式）被传输到服务器。服务器反过来将接收到的本地更新添加到其全局模型中——一旦服务器从（绝大多数）所有客户端接收到新更新，全局模型就会被广播给每个客户端。在考虑隐私时，我们关心的是这些本地更新在多大程度上泄露了所用本地数据集的信息。每个客户端都希望其本地数据集相对于观察轮次通信的外部世界（外部世界包括所有其他客户端）尽可能保持私密。

与其减少轮次通信量以减少敏感信息泄露，差分隐私 [[13](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0065)–[15](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0075),[17](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0085)] 提供了一种方案，即通过噪声对每次客户端到服务器的通信进行混淆。如果添加的噪声幅度不太大，则仍可获得良好的全局模型准确性，代价是收敛所需的总体 SGD 迭代次数增加。另一方面，只有当添加的噪声幅度足够大时，才能提供良好的差分隐私保证。这导致了期望的差分隐私与期望的效用/准确性之间的摩擦。

第 [2.2](#Chp002_29-55_B9780443190377000090_split_000.xhtml#s0015) 节开始讨论 DP-SGD [[1](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005)]，它实现了差分隐私小批量 SGD。第 [2.3](#Chp002_29-55_B9780443190377000090_split_000.xhtml#s0055) 节解释了基于各种（基于散度的）度量和属性的差分隐私。第 [2.4](#Chp002_29-55_B9780443190377000090_split_001.xhtml#s0075) 节继续详述最先进的基于假设检验的差分隐私，称为 `f`-DP [[11](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0055)]，并将其应用于 DP-SGD。我们在第 [2.5](#Chp002_29-55_B9780443190377000090_split_001.xhtml#s0115) 节以开放问题作为结语。

## 2.2 差分隐私 SGD (DP-SGD)

我们在一个包含多个客户端和一个中心聚合服务器的分布式设置中，分析 [[1](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005)] 中基于高斯的差分隐私方法，称为 DP-SGD。DP-SGD 的一个稍微泛化的描述如 [算法 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 所示。DP-SGD 的主要目标是隐藏传输的轮次更新集合 `\overline{U}` 是对应于数据集 `d` 还是相邻数据集 `d'`；如果集合 `d` 和 `d'` 仅在一个元素上不同，则称它们为邻居。为了实现这一目标，DP-SGD 引入了噪声，正如我们将看到的，噪声有两种形式：*裁剪噪声* 和 *高斯噪声*。

### 2.2.1 裁剪

DP-SGD 不直接使用梯度 `a[h] = ∇f(w, ξ[h])` 本身，而是使用其裁剪版本 `[∇f(w, ξ[h])]_C`，其中

```
[x]_C = x / max {1, ||x|| / C}.
```

我们称之为*个体裁剪*方法，因为每个计算出的梯度都被单独裁剪。裁剪是必要的，因为通常我们不能假设梯度有一个界 `C`（例如，有界梯度假设与强凸性相冲突 [[44](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0220)]），然而更新 `U` 中添加的梯度需要被某个常数 `C` 所限制，以便 [[1](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005)] 的 DP 分析能够成立。原因在于裁剪引入了一个界，限制了如果 `d` 和 `d'` 之间的区分样本被用于计算，`U = ∑_{h=1}^m [a_h]_C` 会受到多大影响。裁剪强制了不使用区分样本的更新 `U` 与计算相同梯度但其中一个梯度计算使用区分样本的更新 `U'` 之间的距离很小。这意味着如果分别向 `U` 和 `U'` 添加高斯噪声，则 `U` 和 `U'` 之间的距离越小，就越难判断实际观察到的带噪更新源自 `d` 还是 `d'`。这从而提供了差分隐私保证。

假设 `a[h]` 影响另一个梯度计算，例如 `a[h+1]`。那么，如果区分样本被用于 `a[h]` 的计算，这不仅影响 `a[h]`，还影响 `a[h+1]`。即使 `a[h]` 和 `a[h+1]` 都会被裁剪，这也会增加 `U` 和 `U'` 之间的距离，从而削弱差分隐私。因此，`U` 中不同的梯度计算 `a[h]` 应该相互独立。特别是，我们不希望实现经典 SGD，其中 `a[h]` 的计算会更新本地模型 `w`，而该模型又被用于下一个梯度计算 `a[h+1]`。这就是实现小批量 SGD 的原因，其中每个梯度 `a[h]` 都是针对同一个 `w` 计算的。
