
![Image](OEBPS/images/B9780443190377000247/si6_u15.png)(15.3)

其中，数据多样性的确切度量需要更深入的研究。例如，相对数据多样性通常与分布的相似性度量相关。如果我们假设目标参考分布具有足够的多样性（即可能覆盖整个总体），则分布更接近参考分布的数据集更加多样，因此也更有价值。更多细节将在本章后续部分进行研究。

**通信开销。** 该属性与数据量相关，且是联邦学习（FL）特有的。客户端 `m` 参与的通信轮数 `τ[m]`![Image](OEBPS/images/B9780443190377000247/si7_u15.png) 可以作为贡献指标。参与度越高，可能意味着数据量越大，且在联邦学习的各个阶段贡献越多。因此，`D[m]`![Image](OEBPS/images/B9780443190377000247/si5_u15.png) 的相对值也可以表示为

```
ν(D_m) = τ_m / Σ_{i=1}^n τ_i  and  φ_m^RE = ν(D_m) / Σ_{i=1}^n ν(D_i).
```

![Image](OEBPS/images/B9780443190377000247/si8_u12.png)(15.4)

总体而言，本节介绍的三个估值指标乍看之下可能很简单，但它们可以作为更复杂的数据估值方法设计中的重要指导原则。在本章剩余部分，我们将频繁回顾这些原则。

## 15.4 相关工作：传统数据估值

数据估值反映了每个客户端对最终全局模型性能的贡献程度。我们首先介绍在没有联邦客户端的标准监督学习设置下的数据估值方法。在此设置下，多个客户端贡献其数据集 `D[m]`![Image](OEBPS/images/B9780443190377000247/si5_u15.png) 以共同学习一个预测模型 `f`。我们将联盟定义为客户端的一个子集 `𝒞 ⊆ 𝒜 ≜ {1, …, n}`![Image](OEBPS/images/B9780443190377000247/si9_u14.png)。我们用 `D[𝒜] = {D[m]}_{m=1}^n`![Image](OEBPS/images/B9780443190377000247/si10_u15.png) 表示来自所有 `n` 个客户端的聚合数据集，其中 `D[m]`![Image](OEBPS/images/B9780443190377000247/si5_u15.png) 是客户端 `m` 的本地训练数据集。我们复用该符号，令 `D[𝒞] = {D[m]}_{m∈𝒞}`![Image](OEBPS/images/B9780443190377000247/si11_u15.png)。

按照此惯例，数据估值需要一个效用函数 `ν : 𝒫(D[𝒜]) → ℝ`![Image](OEBPS/images/B9780443190377000247/si12_u15.png) 和一个估值函数 `ϕ(D[m], D[𝒜], ν)`![Image](OEBPS/images/B9780443190377000247/si13_u17.png)，其中 `𝒫(D[𝒜])`![Image](OEBPS/images/B9780443190377000247/si14_u17.png) 表示 `D[𝒜]`![Image](OEBPS/images/B9780443190377000247/si15_u17.png) 的幂集。效用函数和估值函数的不同设计会产生具有不同属性的数据估值。效用函数 `ν` 旨在产生一个数据效用，该效用将被估值函数 `ϕ` 用于根据联邦学习中其他客户端数据的存在情况输出最终价值。在深入细节之前，为了提供一个概览，我们将本章后续将讨论的方法在[表 15.1](#Chp015_281-296_B9780443190377000247.xhtml#t0010)中进行分类。

### 15.4.1 效用函数

效用函数 `ν` 为参与客户端形成的任意联盟 `𝒞`![Image](OEBPS/images/B9780443190377000247/si16_u17.png) 分配一个实值效用。直观上，效用衡量联盟的“实用性”，用于估值函数（见第 [15.4.2](#Chp015_281-296_B9780443190377000247.xhtml#s0055) 节）评估数据。下面我们介绍几个具有代表性的效用函数。

#### 15.4.1.1 性能驱动

性能驱动的效用函数奖励实现高模型性能的数据联盟。

**验证性能（VP）。** VP 是模型实用性最直接的替代指标，被数据夏普利值 [[7]](#Chp015_281-296_B9780443190377000247.xhtml#br0035) 采用。通常在预定义的、感兴趣的验证集 `D[val]`![Image](OEBPS/images/B9780443190377000247/si17_u17.png) 上测量（或由服务器和客户端共同商定），我们定义

`ν(D[m]) = −ℓ(w[m]; D[val])`，

![Image](OEBPS/images/B9780443190377000247/si18_u16.png)(15.5)

其中 `w[m]`![Image](OEBPS/images/B9780443190377000247/si19_u16.png) 是在 `D[m]`![Image](OEBPS/images/B9780443190377000247/si5_u15.png) 上训练的模型，`ℓ` 表示损失函数。有时，验证准确率被用作公式 [(15.5)](#Chp015_281-296_B9780443190377000247.xhtml#deq5) 中取反验证损失的替代方案。该效用函数与第 [15.3](#Chp015_281-296_B9780443190377000247.xhtml#s0020) 节介绍的性能驱动 `数据量` 相关。正如所讨论的，较大的数据集通常会导致性能更好的模型，这意味着更低的验证损失和更高的价值。然而，对联盟进行的每一次 VP 评估都需要计算成本高昂的模型训练，对于深度神经网络模型来说，这可能慢得难以接受。这限制了受实际约束可考虑的模型复杂度。

**初始化时的数据估值（DAVINZ）。** 受到在复杂深度神经网络（DNN）应用中对数据进行估值且完全避免模型训练的启发，Wu 等人 [[21]](#Chp015_281-296_B9780443190377000247.xhtml#br0105) 从理论上推导出一个领域感知的泛化界，以在无需模型训练的情况下估计 DNN 的泛化性能。具体而言，效用函数同时考虑了由神经网络初始化时的神经切线核（NTK）矩阵 `Θ[0]`![Image](OEBPS/images/B9780443190377000247/si20_u16.png) 表征的域内 DNN 泛化误差，以及由训练-验证领域分歧 `d_ℋ(D[m], D[val])`![Image](OEBPS/images/B9780443190377000247/si21_u16.png) 引起的泛化误差。我们有

```
ν(D_m) = -κ√(ŷ Θ_0^{-1} ŷ / |D_m|) - d_ℋ(D_m, D_val),
```

![Image](OEBPS/images/B9780443190377000247/si22_u16.png)(15.6)

其中 `ŷ`![Image](OEBPS/images/B9780443190377000247/si23_u16.png) 中的每个元素被定义为初始化网络上的残差 `ŷ = y − f(x, w^(0))`![Image](OEBPS/images/B9780443190377000247/si24_u16.png)，`ℋ`![Image](OEBPS/images/B9780443190377000247/si25_u16.png) 是用于评估领域分歧的合适函数空间，`κ` 被视为一个平衡超参数。直观上，第一个域内项可以解释为 `D[m]`![Image](OEBPS/images/B9780443190377000247/si5_u15.png) 的复杂度度量，而第二项则处理领域偏移。作者在实践中采用最大均值差异（MMD）作为领域差异度量。总体而言，DAVINZ 通过准确的估计解决了效用评估的计算效率问题。实际局限性在于超参数 `κ` 的确定，该参数用于平衡域内和域外误差的权重。

#### 15.4.1.2 多样性驱动

多样性驱动的效用函数将联盟中数据的多样性或丰富度作为效用的替代指标进行考察。
