
我们假设对手知道区分样本在 `d ∖ d'` 和 `d' ∖ d` 中，但在机制 `M` 执行之前（先验地），可能只知道（除了 `d ∩ d'` 的 99% 特征描述外）`d` 和 `d'` 交集中样本数量的估计值，即对手知道 `|d ∩ d'| + noise`，其中噪声足够大，能产生关于所用数据集大小（`d` 或 `d'`）的“足够强”的 DP 保证。由于 `M` 不直接揭示所用数据集的大小，我们假设（如先前文献所述）`N = |d| ≠ N' = |d'|` 的影响最多只贡献极少量的隐私泄露，小到足以在我们的 DP 分析中忽略，即我们在 DP 分析中可以假设 `N = N'`。

这意味着 DP-SGD 的紧致 `f`-DP 分析成立，即使我们使用的邻近数据集定义声明 `|d ∖ d'| = 1` 或 `|d' ∖ d| = 1`；原始的 `f`-DP 分析考虑的是 `|d ∖ d'| = |d' ∖ d| = 1` 的情况，这需要 [Algorithm 1](#Chp002_29-55_B9780443190377000090_split_000.xhtml#f0010) 中 `2Cσ` 这个因子。如果我们假设不知道确切的数据集大小（如上所述）并假设概率采样（见第 [2.4.5](#Chp002_29-55_B9780443190377000090_split_001.xhtml#s0100) 节），那么我们可能只使用 `Cσ`，节省因子 2（这有助于收敛到更高的精度）。

在 `N = N'` 的设定下，先前工作中的 DP 分析考虑了一个对手 `A_dv`，它可以模仿机制 `M ∘ Sample[m]`，因为它可以在很大程度上重放 `Sample[m]` 如何采样所用数据集（`d` 或 `d'`）：我们说某一轮有 `k` 个区分数据样本，如果 `Sample[m]` 采样的索引子集恰好包含来自 `(d ∖ d') ∪ (d' ∖ d)` 的 `k` 个区分数据样本的索引。对手知道 `Sample[m]` 如何操作，并可以推导出在定义计算更新的 epoch 序列中的一系列轮次内，每轮区分数据样本数量的联合概率分布 `P`。

对手 `A_dv` 不知道从 `P` 中抽取的确切实例，但在 DP 证明中，被赋予了为每一轮实现权衡函数 `f_k(α)` 的能力，该函数对应于 `M ∘ Sample[m](d)` 和 `M ∘ Sample[m](d')` 之间的假设检验，如果 `Sample[m]` 在该轮中选择了 `k` 个区分样本。在刻画 `f_k(α)` 的 DP 分析中，对手 `A_dv` 被赋予了关于 `d` 或 `d'` 中索引到值的映射的知识。这里（如前所述），`d ∩ d'` 中索引到值的映射对于 `d` 中的索引到值的映射和 `d'` 中的索引到值的映射是相同的。此外，对手可以重放 `Sample[m]` 如何从中采样 `m` 个索引的子集。

在 DP 分析中，对手 `A_dv` 在分析单轮时被赋予了关于区分样本数量 `k` 的知识。也就是说，它被给予了 `P` 在单轮上的投影实例。我们注意到，在期望下，对手 `A_dv` 观察到的邻近数据集单轮灵敏度（见第 [2.4.1](#Chp002_29-55_B9780443190377000090_split_001.xhtml#s0080) 节）等于 `(1 − p) ⋅ 0 + p ⋅ 2C = (m/N) ⋅ 2C`，这产生了一个“期望的”权衡函数 `G[1/(σN/m)]`。`c²(N/m)²` 轮的组合给出 `G[c/σ]`。这使我们相信 `C[m/N](G[σ^(−1)])^(⊗ T)` 收敛到 `G[c ⋅ h(σ)]`，其中 `T = c²(N/m)² → ∞`（或等价地，`√T ⋅ m/N = c`，其中 `T → ∞` 且 `N → ∞`），`h(σ)` 是仅依赖于 `σ` 的某个函数（见下文）。这一直觉得到了文献 [11] 中 Corollary 5.4 的确认，也间接得到了文献 [53] 的确认，后者表明 DP-SGD 对于 `σ = √(2(ϵ + ln(1/δ))/ϵ)` 是 `(ϵ, δ)`-DP，适用于广泛的参数设置 `N`、`m`、`T`，其中 `T` 至多 `≈ ϵ(N/m)²/2`，并且这与文献 [11] 中的 Corollary 5.4 相匹配，即 `T` 的上限最多只能大一个常数因子 ≈4（否则将违反该推论）。
