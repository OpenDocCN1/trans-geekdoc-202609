

公式 [(8.3)](#Chp008_143-160_B9780443190377000168.xhtml#deq6) 中的目标可视为一个双人博弈，其中玩家 *A* 想要找到 *λ* 以使加权损失最大化，而玩家 *B* 想要找到参数 **w** 以使加权损失最小化。由于 *g*(**w**, *λ*) 关于 *λ* 是线性的，最优 *λ* 将位于 {*λ* : ∃*m* ∈ *N* : *λ*[*m*] = 1, ∀*m*′ ∈ *N* ∖ {*m*} : *λ*[*m*′] = 0} 中。因此，公式 [(8.3)](#Chp008_143-160_B9780443190377000168.xhtml#deq6) 的解 **w**^* 也是 min[**w** ∈ 𝒲] max[*m* ∈ {1, …, *n*}] *g*[*m*](**w**) 的解。因此，求解公式 [(8.3)](#Chp008_143-160_B9780443190377000168.xhtml#deq6) 将得到一个根据定义实现善意公平的模型。为了求解公式 [(8.3)](#Chp008_143-160_B9780443190377000168.xhtml#deq6) 中的优化问题，可以使用 ∇[*λ*]*g*(**w**, *λ*) 和 ∇[**w**]*g*(**w**, *λ*) 的梯度估计器。相应地将梯度估计器记为 *δ*[*λ*]*g*(**w**, *λ*) 和 *δ*[**w**]*g*(**w**, *λ*)。用 [*n*] 表示 {1, …, *n*} 上的均匀分布。在 AFL 中，*δ*[*λ*]*g*(**w**, *λ*) 的计算如下：采样 *m* ∼ [*n*]，然后采样 *i* ∼ [*|D*[*m*]|]。接着设置 [*δ*[*λ*]*g*(**w**, *λ*)][*m*] = *n*ℓ(**w**; *x*[*m*, *i*], *y*[*m*, *i*]) 以及 [*δ*[*λ*]*g*(**w**, *λ*)][*k*] = 0, ∀*k* ∈ *N* ∖ {*m*}，其中 ℓ(**w**; *x*[*m*, *i*], *y*[*m*, *i*]) 是模型 **w** 在客户端 *m* 的第 *i* 个数据点上的损失函数。类似地，计算 *δ*[**w**]*g*(**w**, *λ*) 时，首先按均匀分布采样 *i*[*m*] ∼ [*|D*[*m*]|], ∀*m* ∈ *N*，然后 $\delta_{\mathbf{w}}g(\mathbf{w},\lambda) = \sum_{m = 1}^{n}\lambda_{m}\nabla_{\mathbf{w}}\ell(\mathbf{w};x_{m,i_{m}},y_{m,i_{m}})$。求解 AFL 目标的算法 STOCHASTIC-AFL 的伪代码见 [算法 1](#Chp008_143-160_B9780443190377000168.xhtml#f0010)。[算法 1](#Chp008_143-160_B9780443190377000168.xhtml#f0010) 中的 $\text{PROJECT}(\widetilde{\mathbf{w}},\mathcal{W})$ 是投影函数，用于寻找 $\mathbf{w}_{p} = {\arg\min}_{w \in \mathcal{W}} {\|\mathbf{w} - \widetilde{\mathbf{w}}\|}^{2}$，可在近线性时间内高效求解 [\[26\]](#Chp008_143-160_B9780443190377000168.xhtml#br0130)。其收敛保证已在 [\[17\]](#Chp008_143-160_B9780443190377000168.xhtml#br0085) 中确立。

**算法 1 STOCHASTIC-AFL.**

为了实现性能均衡公平，提出了 q-FFL [\[12\]](#Chp008_143-160_B9780443190377000168.xhtml#br0060)。直观上，如果某个局部目标具有更高的权重，全局目标就会优先最小化该局部目标。因此，q-FFL 提议为损失值较高的局部目标分配更高的权重，从而使损失在客户端间均衡分布。由于难以 *a priori* 完成，重加权过程在训练期间动态进行。q-FFL 的目标是

$$\min_{\mathbf{w}}f_{q}(\mathbf{w}) = \sum_{m = 1}^{n}\frac{p_{m}}{q + 1}g_{m}^{q + 1}(\mathbf{w}),$$

![Image](OEBPS/images/B9780443190377000168/si99.png)(8.4)

其中 $p_{m} = |D_{m}|/\sum_{m = 1}^{n}|D_{m}|$，*q* 为可调参数。借用 *α*-公平 [\[10\]](#Chp008_143-160_B9780443190377000168.xhtml#br0050) 的思想，q-FFL 可通过调整 *q* 以满足客户端性能不同层级的均等性。较大的 *q* 意味着目标强调表现较差客户端的损失，从而在所有客户端间强制实现更好的性能均等性。相反，较小的 *q* 使目标更接近 FedAvg 的目标（后者不考虑均等性），特别地，*q* = 0 即恢复 FedAvg 目标。求解 q-FFL 目标的算法 q-FedSGD 的伪代码见 [算法 2](#Chp008_143-160_B9780443190377000168.xhtml#f0015)。为使算法收敛，梯度更新的步长根据不同的 *q* 值进行选择。q-FedSGD 提议使用 *h*[*k*](*t*) 来控制步长，从而无需针对不同的 *q* 手动调整步长即可保证收敛。

![算法 2 q-FedSGD.](OEBPS/images/B9780443190377000168/gr002_u4.jpg)

**算法 2 q-FedSGD.**

STOCHASTIC-AFL 和 q-FedSGD 均通过修改训练目标来实现其各自针对的公平性概念。此外，在特定假设下，这两种算法均被证明能够收敛 [\[12\], [17\]](#Chp008_143-160_B9780443190377000168.xhtml#br0060)。由于公式 [(8.4)](#Chp008_143-160_B9780443190377000168.xhtml#deq7) 中存在可调参数 *q*，q-FedSGD 比 STOCHASTIC-AFL 提供了更灵活的控制，以权衡公平性与效用。令人惊讶的是，尽管 q-FedSGD 并未显式致力于获得在表现最差客户端上的更好性能，但它在多个数据集上实现的善意均衡公平优于 STOCHASTIC-AFL [\[12\]](#Chp008_143-160_B9780443190377000168.xhtml#br0060)，同时也实现了更好的性能均衡公平。从 [表 8.3](#Chp008_143-160_B9780443190377000168.xhtml#t0020) 可知，STOCHASTIC-AFL 在通信和运行时间方面均比 q-FedSGD 代价更高。两者的通信开销均高于 FedAvg。
