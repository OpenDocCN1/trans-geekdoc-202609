

### (a) 收敛速率

收敛速率刻画了最优性度量（例如，目标残差 `F(ŵ^(t)) − F^⋆`、到解的距离平方 `∥ŵ^(t) − w^⋆∥²` 或梯度范数平方 `∥∇F(ŵ^(t))∥²`）相对于迭代次数 `t` 的进展，其中 `ŵ^(t)` 是近似解。例如，在光滑凸问题的梯度法中，我们有 `F(w^(t + 1)) - F^⋆ ≤ (L∥w^0 - w^⋆∥²) / (2(t + 1))`，表明目标残差 `F(w^(t)) − F^⋆` 至少以 `1/t` 的速度下降，记作 `F(w^(t)) − F^⋆ = 𝒪(1/t)`。我们也可以写成 `F(w^(t + 1)) - F^⋆ = 𝒪(R₀²L / (t + 1))`（其中 `R₀ := ∥w⁰ − w^⋆∥`），以展示速率对 `L` 和 `R₀` 的依赖关系。

请注意，我们通常试图建立一个上界速率，但也可以证明在某些假设下，对于某些类算法，该上界与下界速率匹配（在常数因子范围内），见例如 [45]。对于梯度型方法，仅在凸性和 `L`-光滑性假设下，最优收敛速率为 `𝒪(1/t²)`，这由 Nesterov 的最优方法保证。对于非凸问题，梯度型方法在 `L`-光滑性假设下，仅能在 `∥∇F(ŵ^(t))∥²` 上达到 `𝒪(1/t)` 的速率。在强凸性、误差界、二次增长或 PL 条件等额外假设下，可以达到线性收敛速率。然而，本章不再进一步讨论这些变体。

### (b) 复杂度

复杂度的概念源于理论计算机科学，但在计算数学中广泛应用，特别是在优化领域。复杂度的形式化定义可见于例如 [43, 45]。我们区分梯度型方法的两种复杂度：迭代复杂度（或解析复杂度）和计算复杂度（有时称为算术复杂度或工作量复杂度）[45]。在梯度型方法中，总体计算复杂度通常由预言机复杂度主导，后者刻画了寻找近似解所需的函数和/或梯度评估总数。我们注意到，我们这里对 `oracle`（预言机）概念的使用有所扩展，其正式定义可见于例如 [45]。在数学上，算法 `T` 次迭代的预言机复杂度（在我们的语境下）定义如下：

```
预言机复杂度 := ∑_{t=0}^{T} 第 t 次迭代的单次迭代复杂度。
```
(1.19)

**单次迭代复杂度**刻画了每次迭代的工作量（例如梯度评估的次数）。在每次迭代中，我们通常计算最占主导地位的计算步骤，如梯度评估、函数评估、近端操作、投影、矩阵-向量乘法或 Hessian-向量乘法。如果单次迭代复杂度是固定的，则

```
预言机复杂度 = 迭代次数 × 单次迭代复杂度。
```

例如，对于光滑凸问题的标准梯度下降法，单次迭代复杂度为 `𝒪(1)`，即需要一次梯度评估，从而得到预言机复杂度 `𝒪(1/ϵ)`，以获得满足 `F(w^(t)) − F^⋆ ≤ ϵ` 的 `w^(t)`。确实，从收敛界 `F(w^t) - F^⋆ ≤ (L∥w^0 - w^⋆∥²) / (2t)` 可知，`F(w^(t)) − F^⋆ ≤ ϵ` 由 `(L∥w^0 - w^⋆∥²) / (2t) ≤ ϵ` 蕴含，从而得到 `t ≥ ⌈(L∥w^0 - w^⋆∥²) / (2ϵ)⌉`。因此，我们最多需要 `t_max := ⌈(L∥w^0 - w^⋆∥²) / (2ϵ)⌉ = 𝒪(1/ϵ)` 次迭代，进而需要 `𝒪(1/ϵ)` 次梯度评估。

### 1.2.10 初始点、热启动与重启

对于凸算法，其可以从任意初始点 `w⁰` 出发收敛到全局最小化点 `w^⋆`，`w⁰` 的选择将影响迭代次数，因为对于任意解 `w^⋆`，项 `∥w⁰ − w^⋆∥²` 出现在收敛保证的界中，例如 `F(w^T) - F^⋆ ≤ 𝒪(L∥w^0 - w^⋆∥² / T^ν)`（其中 `ν = 1` 或 `ν = 2`）。显然，如果 `w⁰` 接近 `w^⋆`，则迭代次数 `T` 很小。

对于非凸算法，初始化起着关键作用，因为不同的初始点 `w⁰` 可能使算法收敛到不同的近似驻点 `w^⋆`，且它们的质量各异。驻点是局部最小化点的候选者，但其中一些可能给出极大化点或鞍点。即使我们确实得到了一个局部最小化点，它可能仍是一个糟糕的局部最小化点，即远离任意全局最小化点，或者在机器学习中给出较差的预测误差。

热启动策略使用上一次运行或上一次迭代的输出，来初始化当前阶段或迭代的算法。其基于这样的思想：上一次运行已经给出了期望解的一个良好近似。从这一点初始化可能有望快速收敛到目标最优解。热启动广泛应用于顺序迭代（如顺序二次规划）或在线学习方法中。
