
这些攻击旨在通过阻止训练过程（更具体地说，是服务器端的聚合算法）收敛到一个 `good` 极小值，从而使模型无法使用。原则上，拜占庭客户端可以发送一个与其本应发送的更新任意偏离的更新。然而，为了避免在服务器端被检测到，对抗性更新会根据对系统的（`full` 或 `partial`）了解进行适当修改——包括聚合规则、对其他客户端更新的估计等 [\[5](#Chp004_75-90_B9780443190377000120.xhtml#br0025),[6\]](#Chp004_75-90_B9780443190377000120.xhtml#br0030)。为了应对拜占庭攻击的威胁，提出了许多具有不同属性和适用性的防御措施（参见第 [4.4.1.1](#Chp004_75-90_B9780443190377000120.xhtml#s0085) 节）。在一场新兴的军备竞赛中，提出了经过修改的拜占庭攻击 [\[3](#Chp004_75-90_B9780443190377000120.xhtml#br0015),[23](#Chp004_75-90_B9780443190377000120.xhtml#br0115),[43\]](#Chp004_75-90_B9780443190377000120.xhtml#br0215) 以绕过拜占庭鲁棒聚合规则，至少在实际设置中如此。其中一种攻击是局部模型投毒 [\[15\]](#Chp004_75-90_B9780443190377000120.xhtml#br0075)。在这种攻击中，被攻陷的客户端在 FL 的每次迭代中发送精心设计的更新。这些更新经过优化，旨在将全局模型参数推向与无攻击情况下全局模型参数变化方向相反的方向。已证明这种攻击对拜占庭鲁棒聚合机制具有极高的成功率。

### 4.3.1.2 后门攻击

这些攻击旨在通过注入 `triggers` 来操纵一部分训练样本，使得在投毒数据集上训练的机器学习模型会对嵌入相同触发器的测试样本做出错误预测 [\[2](#Chp004_75-90_B9780443190377000120.xhtml#br0010),[42\]](#Chp004_75-90_B9780443190377000120.xhtml#br0210)。与拜占庭攻击不同，后门攻击并非旨在降低模型的整体性能或导致测试样本上的无差别错误。相反，后门攻击的目标是在模型中植入一个 `stealthy` 或不可检测的后门，使其对嵌入攻击者选定触发器的任何输入数据预测目标标签 `τ`。此外，后门攻击显式地优化其目标，以允许训练收敛并在大多数测试样本上保持高模型性能（就所选指标如准确率而言）（即同时拟合后门任务和主任务）。根据全局触发器注入模型的方式，我们可以进一步将提出的攻击分为 `centralized` 和 `distributed` 后门攻击。在集中式设置中，所有恶意客户端在其更新中嵌入相同的触发器，即共享全局触发器。在去中心化设置中，全局触发器被分解为局部模式，这些较小的触发器模式随后被分享给恶意客户端。

**集中式基于样本的触发器。** 最早的基于集中式模型投毒的后门攻击之一是在 [\[4\]](#Chp004_75-90_B9780443190377000120.xhtml#br0020) 中提出的。他们分析了单个恶意客户端发起成功后门攻击的可行性，以及在概率选择下 `M` 个共享相同辅助数据集的串通恶意客户端（即 `m = 1, …, M` 时 `𝒟[aux, m] = 𝒟[aux]`）发起攻击的可行性。在这种攻击中，辅助数据集中的每个数据样本都是一个带有目标标签 `τ[i]` 的触发器。换句话说，对于给定的分类器 `f`，对抗目标是最大化 `𝒟[aux]` 中每个样本的目标误分类（或等价地，最小化损失），如下所示：

```
L_attack(𝒟_m ∪ 𝒟_aux, w̃^(t)) = max_{w̃^(t)} ∑_{i=1}^r 1[f(x_i; w̃^(t)) = τ_i],
```
(4.4)

其中 `1[·]` 是指示函数，当条件满足时输出 1，否则输出 0。注意，在公式 [(4.4)](#Chp004_75-90_B9780443190377000120.xhtml#deq4) 中，`w̃^(t) = w^(t-1) + α_m δ_m^(t)` 被用作时间步 `t` 全局模型的估计。这是因为恶意代理在实践中预计对其他（良性）客户端共享的更新可见性有限或不可见。

作者还定义了第二个准确率目标，以确保恶意更新在测试数据集（记为 `𝒟[test]`）上的性能接近全局模型的性能（该全局模型使用除恶意客户端外所有客户端的数据进行更新）。形式上，

```
∑_{(x_j, y_j) ∈ 𝒟_test} 1[f(x_j; w_{S_t \ m}^(t)) = y_j] - 1[f(x_j; w̃^(t)) = y_j] < γ_t,
```
(4.5)

其中 `γ_t` 是服务器可能用来拒绝更新的阈值。`γ_t` 的较小值意味着恶意更新应与良性更新非常相似，因此具有高度隐蔽性。

采用 `alternating minimization strategy` 来同时优化公式 [(4.4)](#Chp004_75-90_B9780443190377000120.xhtml#deq4) 和 [(4.5)](#Chp004_75-90_B9780443190377000120.xhtml#deq5)。在一定步数内，使用 `𝒟[aux]` 中的样本优化公式 [(4.4)](#Chp004_75-90_B9780443190377000120.xhtml#deq4) 中的恶意目标以生成一个更新。然后使用该更新在 `𝒟[m]` 上优化准确率目标。这两个步骤交替重复，直到成功生成一个隐蔽且恶意的更新。

**集中式基于语义的触发器。** 这种攻击是在 [\[2\]](#Chp004_75-90_B9780443190377000120.xhtml#br0010) 中构想并针对共享相同辅助数据集 `𝒟[aux]` 的 `M` 个串通恶意客户端进行评估的。触发器是基于数据的语义属性定义的。例如，一个被植入语义后门的图像分类模型会将所有 `purple cars`（紫色汽车）误分类为 `birds`（鸟类）。在这种情况下，`𝒟[aux]` 将包含标签为 `purple car` 的图像，并且整个类别的目标标签将被设置为 `bird`。恶意客户端可以自由选择数据样本中自然发生的特征，或没有其参与就无法出现的特征（例如，只有恶意客户端拥有的特殊帽子或眼镜的图像）。

恶意客户端执行 `model replacement` 以植入后门。其思路是用模型 `w̃` 替换全局模型，其中

```
w̃ = w^(t-1) + (η/n) ∑_{k ∈ S_t} δ_k^(t),
```
(4.6)
