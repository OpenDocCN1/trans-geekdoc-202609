
后续工作 [[6](#Chp005_91-104_B9780443190377000132.xhtml#br0030),[14](#Chp005_91-104_B9780443190377000132.xhtml#br0070),[26]](#Chp005_91-104_B9780443190377000132.xhtml#br0130) 在 *Sybils* 设置下研究标签翻转，即一组串通的代理共同发起攻击。例如，Cao 等人 [[6]](#Chp005_91-104_B9780443190377000132.xhtml#br0030) 通过实证研究了串通代理/投毒训练样本的数量与攻击有效性（不使用增强）之间的关系，并表明数量越多会导致攻击越有效。Tolpegin 等人 [[26]](#Chp005_91-104_B9780443190377000132.xhtml#br0130) 也研究了最多包含 50% 串通代理的类似设置，并发现攻击对被翻转标签的那部分类别有更大的负面影响，但对剩余类别几乎没有影响，这作为一种为避免检测而进行的目标攻击，是期望的现象。他们还表明，在训练过程后期注入的毒样本比早期注入的更有效。

#### 5.2.1.2 后门

后门攻击 [[17]](#Chp005_91-104_B9780443190377000132.xhtml#br0085) 旨在操纵一部分训练数据及其标签，使得在被篡改数据集上训练的机器学习模型，对于任何带有攻击者选定模式（例如语义模式或人工触发器模式）的输入数据，都会预测目标标签 $\overline{c}$。与保持数据实例不变的标签翻转攻击相比，后门攻击可以向数据中引入人工模式。

在联邦学习（FL）中，后门攻击最近已被研究 [[2](#Chp005_91-104_B9780443190377000132.xhtml#br0010),[3](#Chp005_91-104_B9780443190377000132.xhtml#br0015),[27](#Chp005_91-104_B9780443190377000132.xhtml#br0135),[31]](#Chp005_91-104_B9780443190377000132.xhtml#br0155)，其意图是操纵局部模型并同时拟合主任务和后门任务，使得被投毒的局部模型以及最终的全局模型在未篡改的数据样本上表现正常（即攻击者的模型不会“脱颖而出”），同时在后门数据样本上达到很高的攻击成功率。我们将 FL 中的后门攻击分为两类：基于触发器的后门和语义后门。

##### 5.2.1.2.1 基于触发器的后门

FL 中的后门攻击 [[2](#Chp005_91-104_B9780443190377000132.xhtml#br0010),[3]](#Chp005_91-104_B9780443190377000132.xhtml#br0015) 考虑的是像素模式后门，这要求攻击者在 *训练时和测试时* 以特殊方式修改数字图像的像素或文本的词汇，以使 FL 模型对修改后的图像/文本进行错误分类。形式上，对抗代理 *m* 通过最小化以下目标来训练其局部模型：

```
\min_{w_{m}}\left( \sum_{j \in D_{m}^{poi}}\ell_{m}(\mathbf{w}_{\mathbf{m}};\mathtt{Trans}(\mathbf{x}_{\mathbf{m}}^{\mathbf{j}};\mathbf{\phi}),\overline{c}) + \sum_{j \in D_{m}^{cln}}\ell_{m}(\mathbf{w}_{\mathbf{m}};\mathbf{x}_{\mathbf{m}}^{\mathbf{j}},c_{m}^{j}) \right).
```

(5.4)

函数 `Trans` 使用一组参数 *ϕ* 将任意类别的干净数据转换为带有攻击者选定触发器模式的后门数据。例如，对于图像数据，*ϕ* 可分解为触发器位置 `TL`、触发器大小 `TS` 和触发器间隙 `TG`（*ϕ* = {*TS*, *TG*, *TL*}）。例如，[图 5.1](#Chp005_91-104_B9780443190377000132.xhtml#f0010)(a) 中的攻击者用四种颜色高亮显示的选定模式嵌入训练数据，这些模式共同构成一个完整的模式作为后门触发器。攻击者可以设计自己的触发器模式并选择最优的投毒数据比率 *r*，以获得更好的模型参数 *w*[*m*]^((*t* + 1)')，利用该参数，*w*^((*t* + 1)) 既能为后门数据 `Trans`(**x**[**m**]^(**j**); **ϕ**) 分配最高概率给目标标签 $\overline{c}$，也能为良性数据 **x**[**m**]^(*j*') 分配最高概率给真实标签 *c*[*m*]^(*j*')。类似于增强过程 [[4]](#Chp005_91-104_B9780443190377000132.xhtml#br0020)，Bagdasaryan 等人 [[2]](#Chp005_91-104_B9780443190377000132.xhtml#br0010) 将恶意更新按因子 *γ* 放大，以确保后门在服务器聚合的平均过程中存活下来，并使全局模型被投毒的局部模型替换。这种缩放方法也称为“模型替换”。

The aggregator at round t + 1 combines information from local parties (benign and adversarial) in the previous round t, and updates the shared model w(t+1). When implementing backdoor attacks, the backdoor attacker uses a global trigger while distributed backdoor attacker uses a local trigger which is part of the global trigger.](OEBPS/images/B9780443190377000132/gr001_u3.jpg)

**图 5.1** (a) 后门攻击和 (b) 分布式后门攻击在 FL 上的概览。第 *t* + 1 轮的聚合器结合上一轮 *t* 中来自本地参与方（良性和对抗性）的信息，并更新共享模型 *w*^((*t*+1))。实施后门攻击时，后门攻击者使用全局触发器，而分布式后门攻击者使用局部触发器，后者是全局触发器的一部分。

然而，此类标准后门攻击 [[2](#Chp005_91-104_B9780443190377000132.xhtml#br0010),[3]](#Chp005_91-104_B9780443190377000132.xhtml#br0015) 并未充分利用 FL 的分布式学习方法论，因为它们会在所有对抗代理中嵌入 *相同的* 全局触发器模式。利用 FL 从本地参与方聚合分散信息以训练共享模型的能力，Xie 等人 [[31]](#Chp005_91-104_B9780443190377000132.xhtml#br0155) 提出了针对 FL 的 *分布式* 后门攻击（DBA）。给定与标准后门攻击相同的触发器模式，DBA 将其分解为局部模式，并分别嵌入不同的对抗代理中。在 DBA 中，所有攻击者仅使用完整触发器（即全局触发器）的部分来投毒其局部模型，而最终的对抗目标与标准攻击相同——使用完整触发器攻击 FL 全局模型。例如，在 [图 5.1](#Chp005_91-104_B9780443190377000132.xhtml#f0010)(b) 中，带有橙色标记的攻击者 *仅* 使用位于橙色区域的触发器模式来投毒其部分训练数据。类似的攻击方法适用于绿色、黄色和蓝色标记。每个 DBA 攻击者的触发器被定义为 *局部触发器*，组合后的完整触发器被定义为 *全局触发器*。为了公平比较，标准后门攻击和 DBA 中保持相似总量的修改像素。
