
which shows an $\mathcal{O}(1/t)$-last-iterate convergence rate on $w^{(t)}$. It also implies that $\sum_{t = 0}^{T}t\|\nabla F(w^{t})\|^{2} \leqslant L^{2}\| w^{0} - w^{\star}\|^{2}$ (by using $\sum_{t = 0}^{T}\Delta_{t} \leqslant D_{0}$) and $\|w^{(t)} - w^{\star}\| \le \|w^{0} - w^{\star}\|$ (by using $D[t] \le D[0]$) for all $t \ge 0$.

**(e) Accelerated gradient method for smooth and convex problems.** Our last illustration follows Nesterov's accelerated gradient scheme:

```
z^{t} := w^{t} + \beta_{t}(w^{t} - w^{t - 1}) \quad \text{and} \quad w^{t + 1} := z^{t} - \frac{1}{L}\nabla F(z^{t}),
```
(1.17)

where $\beta_{t} = \frac{\theta_{t - 1} - 1}{\theta_{t}}$ for $\theta[t] \ge 1$ such that $\theta[t](\theta[t] - 1) \le \theta[t - 1]^{2}$ with $\theta[0] := 1$. This is an accelerated variant of [(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) with the momentum $\beta[t](w^{(t)} - w^{(t - 1)})$. It is well-known [[44]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0220) that, after a few elementary transformations, [(1.17)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq24) can be written as

```
z^{t} := (1 - \frac{1}{\theta_{t}})w^{t} + \frac{1}{\theta_{t}}u^{t}, \quad w^{t + 1} := z^{t} - \frac{1}{L}\nabla F(z^{t}), \quad \text{and} \quad u^{t + 1} = u^{t} - \frac{\theta_{t}}{L}\nabla F(z^{t}).
```

Let $v^{t} := (1 - \frac{1}{\theta_{t}})w^{t} + \frac{1}{\theta_{t}}w^{\star}$. Then, $z^{t} - v^{t} = \frac{1}{\theta_{t}}(u^{t} - w^{\star})$. Moreover, by convexity of $F$, we have $F(z^{t}) \leqslant F(v^{t}) + \langle\nabla F(z^{t}),z^{t} - v^{t}\rangle \leqslant (1 - \frac{1}{\theta_{t}})F(w^{t}) + \frac{1}{\theta_{t}}F(w^{\star}) + \frac{1}{\theta_{t}}\langle\nabla F(z^{t}),u^{t} - w^{\star}\rangle$. Hence, multiplying both sides by $\theta[t]^{2}$, we obtain

```
\begin{array}{lcl} {\theta_{t}^{2}[ F(z^{t}) - F(w^{\star})]\ } & {\leqslant \ } & {\theta_{t}(\theta_{t} - 1)[ F(w^{t}) - F(w^{\star})] + \theta_{t}\langle\nabla F(z^{t}),u^{t} - w^{\star}\rangle.} \\ \end{array}
```

Similar to the proof of [(1.14)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq15) and [(1.16)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq18), respectively, we have

```
\left\{ \begin{array}{l} {\frac{L}{2}\| u^{t + 1} - w^{\star}\|^{2} + \theta_{t}\langle\nabla F(z^{t}),u^{t} - w^{\star}\rangle = \frac{L}{2}\| u^{t} - w^{\star}\|^{2} + \frac{\theta_{t}^{2}}{2L}\|\nabla F(z^{t})\|^{2},} \\ {\theta_{t}^{2}[ F(w^{t + 1}) - F(w^{\star})] + \frac{\theta_{t}^{2}}{2L}\|\nabla F(z^{t})\|^{2} \leqslant \theta_{t}^{2}[ F(z^{t}) - F(w^{\star})].} \\ \end{array} \right.
```

Summing up the last three inequalities, we obtain

```
\underset{D_{t + 1}}{\underset{\text{︸}}{\theta_{t}^{2}[ F(w^{t + 1}) - F(w^{\star})] + \frac{L}{2}\| u^{t + 1} - w^{\star}\|^{2}}} + \underset{\Delta_{t}}{\underset{\text{︸}}{(\theta_{t - 1}^{2} - \theta_{t}(\theta_{t} - 1))[ F(w^{t}) - F(w^{\star})]}} \quad \leqslant \underset{D_{t}}{\underset{\text{︸}}{\theta_{t - 1}^{2}[ F(w^{t}) - F(w^{\star})] + \frac{L}{2}\| u^{t} - w^{\star}\|^{2}}},
```
(1.18)

which is exactly [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) with $E[t] = 0$ and $\omega[t] = 1$, provided that $\theta[t - 1]^{2} - \theta[t](\theta[t] - 1) \ge 0$ (note that $\theta[0] = 1$ and $\theta_{- 1} = \frac{1}{2}$ satisfy this condition). The recursive estimate [(1.18)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq28) implies that $D[t] \le D[0]$, leading to

```
F(w^{t}) - F(w^{\star}) \leqslant \frac{D_{0}}{\theta_{t - 1}^{2}} = \frac{L}{2\theta_{t - 1}^{2}}\| w^{0} - w^{\star}\|^{2}.
```

In particular, if we choose $\theta_{t - 1} := \frac{t + 1}{2}$, then $\theta_{t - 1}^{2} = \frac{(t + 1)^{2}}{4} \geqslant \theta_{t}(\theta_{t} - 1) = \frac{t(t + 1)}{4}$, then we get the last-iterate convergence guarantee $F(w^{t}) - F(w^{\star}) \leqslant \frac{2L\| w^{0} - w^{\star}\|^{2}}{(t + 1)^{2}}$.

We have illustrated how to employ the unified recursive expression [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) to analyze four different deterministic gradient-type algorithms. It provides a simple approach with a few lines to derive convergence rate analysis compared to classical techniques in the literature. We believe that this approach can be extended to analyze other methods that have not been listed here.

### 1.2.9 Convergence rates and complexity analysis

Classical optimization literature often characterizes asymptotic convergence or linear convergence rates of the underlying algorithm, while sublinear rates or oracle complexity are largely elusive, see, e.g., [[3]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0015), [[21]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0105), [[22]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0110), [[31]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0155), [[38]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0190), [[53]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0265). Sublinear convergence rates have been widely studied in convex optimization methods, see, e.g., [[45]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0225), while oracle complexity analysis was formally studied in [[43]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0215). Recently, these topics have gained in popularity due to applications to large-scale problems in modern signal and image processing, machine learning, and statistical learning [[9]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0045), [[28]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0140), [[67]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0335). Let us discuss these concepts in detail here.
