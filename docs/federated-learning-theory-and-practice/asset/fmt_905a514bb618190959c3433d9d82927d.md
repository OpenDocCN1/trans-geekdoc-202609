
Moreover, the PQC is equipped with the CNOT gates for quantum entanglement and learnable quantum gates, i.e., `R[X](α[i])`, `R[Y](β[i])`, and `R[Z](γ[i])`, where the qubit angles `α[i]`, `β[i]`, and `γ[i]` are tuned in the training process. The PQC framework in the green dash square (dark gray in print version) is repeatedly copied to set up a deep model, and the number of the PQC frameworks is called the depth of the VQC. The operation of the measurement outputs the classical expected observations `|z[1]⟩, |z[2]⟩, …, |z[U]⟩` from the quantum output states. The expected outcomes are used to calculate the loss value and the gradient descents [[30]](#Chp018_329-341_B9780443190377000284.xhtml#br0150), which are used to update the VQC model parameters by applying the back-propagation algorithm [[35]](#Chp018_329-341_B9780443190377000284.xhtml#br0175) based on the stochastic gradient descent (SGD) optimizer.

## 18.3 Quantum natural gradient descent

As shown in Eq. [(18.2)](#Chp018_329-341_B9780443190377000284.xhtml#deq2), at step `t`, the standard gradient descent minimizes a loss function `ℒ(θ)` with respect to the parameters `θ` in a Euclidean space,

```
θ[t + 1] = θ[t] − η∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si22_u17.png)(18.2)

where `η` is the learning rate.

The standard gradient descent algorithm conducts each optimization step in a Euclidean geometry on the parameter space. However, since the form of parameterization is not unique, different compositions of parameterizations are likely to distort the distance geometry within the optimization landscape. A better alternative method is to perform the gradient descent in the distribution space, namely natural gradient descent [[1]](#Chp018_329-341_B9780443190377000284.xhtml#br0005), which is dimension-free and invariant for different parameterization forms. Each optimization step of the natural gradient descent chooses the optimum step size for the update of parameter `θ[t]`, regardless of the choice of parameterization. Mathematically, the standard gradient descent is modified as

```
θ[t + 1] = θ[t] − ηF^(−1)∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si24_u17.png)(18.3)

where `F` denotes the Fisher information matrix, which acts as a metric tensor that transforms the steepest gradient descent in the Euclidean parameter space to the steepest descent in the distribution space.

Since the standard Euclidean geometry is sub-optimal for optimizing quantum variational algorithms, a quantum analog has the following form:

```
θ[t + 1] = θ[t] − ηg^+(θ[t])∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si25_u17.png)(18.4)

where `g^+(θ[t])` refers to the pseudo-inverse and is associated with the specific architecture of the quantum circuit. The coefficient `g^+(θ[t])` can be calculated using the Fubini–Study metric tensor, which it then reduces to the Fisher information matrix in the classical limit [[21]](#Chp018_329-341_B9780443190377000284.xhtml#br0105).

The Fubini–Study metric is the natural metric for the geometrization of quantum mechanics, and much of the peculiar behavior of quantum mechanics including quantum entanglement can be attributed to the peculiarities of the Fubini–Study metric.

In this chapter, the Fubini–Study metric tensor is typically defined in quantum mechanics' notations of mixed states. To explicitly equate this notation to the homogeneous coordinates, let

```
|ψ⟩ = ∑_{k = 0}^{K} Z_k |e_k⟩ = [Z_0:Z_1:…:Z_K],
```

![Image](OEBPS/images/B9780443190377000284/si27_u17.png)(18.5)

where `{|e_k⟩}` is a set of orthonormal basis vectors for Hilbert space, and the `Z_k` are complex numbers; `Z_α = [Z_0 : Z_1 : … : Z_K]` is the standard notation for a point in the projective space of homogeneous coordinates. Then, given two points `|ψ⟩ = Z_α` and `|ϕ⟩ = W_α` in the space, the distance between `|ψ⟩` and `|ϕ⟩` is

```
γ = arccos√(⟨ψ|ϕ⟩⟨ϕ|ψ⟩ / ⟨ψ|ψ⟩⟨ϕ|ϕ⟩).
```

![Image](OEBPS/images/B9780443190377000284/si35_u16.png)(18.6)
