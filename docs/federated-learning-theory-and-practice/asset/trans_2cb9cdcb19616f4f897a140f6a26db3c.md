
针对梯度反演攻击，已提出多种防御措施。这些措施包括扰动梯度[[43]](#Chp006_105-122_B9780443190377000144.xhtml#br0215)、[[51]](#Chp006_105-122_B9780443190377000144.xhtml#br0255)以及使用客户端可即时应用的训练数据变换[[23]](#Chp006_105-122_B9780443190377000144.xhtml#br0115)、[[46]](#Chp006_105-122_B9780443190377000144.xhtml#br0230)。针对梯度，更传统的加密思想包括安全聚合[[7]](#Chp006_105-122_B9780443190377000144.xhtml#br0035)或同态加密[[38]](#Chp006_105-122_B9780443190377000144.xhtml#br0190)，也可被使用，且推测能完全阻止任何窃听攻击。由于它们特殊的设置和开销，本文不予研究。

首先，我们关注当前梯度反演攻击[[18]](#Chp006_105-122_B9780443190377000144.xhtml#br0090)隐含的两个强假设。我们表明，通过消除这些假设，攻击性能显著下降，且仅能针对低分辨率图像生效。相关发现将在第6.3节探讨，并已暗示联邦学习中一些更安全的配置（第6.6节）。

其次，我们总结各类防御措施（第6.4节），并系统性评估（第6.5节）部分防御措施抵御最先进梯度反演攻击的性能，展示其数据效用与隐私泄露的权衡。我们估算在各评估防御下端到端恢复单张图像的计算成本。我们还通过实验证明组合防御的可行性和有效性。我们的发现总结为进一步提升联邦学习抵御梯度反演攻击安全性的策略（第6.6节）。最后，我们讨论梯度反演攻击的新兴主题和未来方向（第6.7节）。

## 6.2 梯度反演攻击

先前研究已证明，对于图像分类任务，从梯度恢复输入（即梯度反演）是可行的，方法是将其表述为一个优化问题：给定一个参数为`θ`的神经网络，以及使用私有数据批次`(x^(*), y^(*)) ∈ ℝ^(b×d) × ℝ^b`（其中`b`、`d`分别为批次大小和图像尺寸）计算出的梯度`∇[θ]ℒ[θ](x^(*), y^(*))`，攻击者试图恢复`x ∈ ℝ^(b×d)`，即`x^(*)`的一个近似值，公式如下：

```
\arg\min\limits_{x}\mathcal{L}_{grad}(x;\theta,\nabla_{\theta}\mathcal{L}_{\theta}(x^{*},y^{*})) + \alpha\mathcal{R}_{aux}(x).
```

(6.1)

优化目标包含两部分：项`ℒ[grad](x; θ, ∇[θ]ℒ[θ](x^(*), y^(*)))`强制恢复批次`x`的梯度与提供的梯度`ℒ[θ](x^(*), y^(*))`匹配，而项`ℛ[aux](x)`则通过使用已知图像先验来正则化损失，进一步改善重建效果。值得注意的是，随着私有批次`x`维度的增加，攻击难度加大，即当`x`是大训练批次，或`x`由高维输入（如高分辨率图像）组成时。此外，模型架构和规模进一步影响重建质量。

Phong等人[[37]](#Chp006_105-122_B9780443190377000144.xhtml#br0185)通过证明单层神经网络即可实现此类重建，为该任务提供了理论见解。Zhu等人[[51]](#Chp006_105-122_B9780443190377000144.xhtml#br0255)首次展示了对于最大批次大小为8的情况，使用`ℓ[2]`-距离作为`ℒ[grad](⋅, ⋅)`且不包含正则化项`ℛ[aux](x)`，精确的像素级重建是切实可行的。该方法在具有Sigmoid激活函数的简单神经网络上，对低分辨率CIFAR数据集[[29]](#Chp006_105-122_B9780443190377000144.xhtml#br0145)有效，但无法扩展到高分辨率图像，或具有ReLU激活函数的更大模型。后续工作[[49]](#Chp006_105-122_B9780443190377000144.xhtml#br0245)提出了一种简单方法，可从梯度中部分提取真实标签，通过在梯度反演期间放宽重建标签`y^(*)`的需求，进一步增强了攻击（详见第6.3.2节）。更新的方法通过调整`ℒ[grad]`的选择并添加正则化项`ℛ[aux](x)`来改进恢复效果。Geiping等人[[18]](#Chp006_105-122_B9780443190377000144.xhtml#br0090)大幅改进了攻击，通过为`ℒ[grad]`选择余弦距离，为`ℛ[aux](x)`选择全变分，实现了从最大批次大小为100的梯度中恢复低分辨率图像（下一节将详细描述）。此外，该方法还能从ImageNet[[11]](#Chp006_105-122_B9780443190377000144.xhtml#br0055)中重建单张高分辨率图像。Wei等人[[43]](#Chp006_105-122_B9780443190377000144.xhtml#br0215)分析了训练中不同配置如何影响Geiping等人的攻击。

一项更新的工作[[45]](#Chp006_105-122_B9780443190377000144.xhtml#br0225)通过基于批量归一化[[25]](#Chp006_105-122_B9780443190377000144.xhtml#br0125)统计量添加额外正则化项，并引入一个强制多次攻击试验间一致性的正则化项，进一步改进了针对高分辨率图像的攻击。

另一正交研究方向[[50]](#Chp006_105-122_B9780443190377000144.xhtml#br0250)提议将梯度反演攻击表述为闭式递归过程，而非优化问题。然而，该方法仅能在训练批次大小为1时恢复低分辨率图像。
