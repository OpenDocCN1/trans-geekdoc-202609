
第二个标准是使用 `F` 的梯度范数，例如 `∥∇F(ŵ)∥` 或其平方范数。注意 `∇F(w⋆) = 0` 仅提供驻点，在非凸设置中，这些是局部极小值点的候选者。因此，对于给定容差 `ϵ > 0`，满足 `∥∇F(ŵ)∥ ≤ ϵ` 的任何向量 `ŵ` 仅提供 [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) 的一个近似驻点 `ŵ`。为保证近似局部解，我们可以添加二阶条件，例如对于某个 `ϵ̂ > 0`，有 `λ_min(∇²F(ŵ)) ≥ −ϵ̂`，其中 `λ_min(∇²F(ŵ))` 是 `∇²F(ŵ)` 的最小特征值。在非凸情况下，`ŵ` 的构造通常依赖于从 `{w⁰, …, w^(T)}` 中选取的最佳迭代点，其意义在于 `∥∇F(ŵ)∥ = min_{0 ≤ t ≤ T} ∥∇F(w^(t))∥`。对于非光滑优化，其中 `F := f + g`，我们可以使用梯度映射 `G_β(ŵ) := β^(−1)(ŵ − prox_βg(ŵ − β∇f(ŵ)))` 的范数 `∥G_β(ŵ)∥`，其中 `β > 0`。对于随机优化，需要使用期望 `𝔼[∥∇F(ŵ)∥²]`、`𝔼[F(ŵ) − F⋆]`，或高概率 `ℙ[∥∇F(ŵ)∥ ≤ ϵ] ≥ 1 − δ` 或 `ℙ[F(ŵ) − F⋆ ≤ ϵ] ≥ 1 − δ` 来刻画最优性条件，其中 `δ ∈ (0, 1)` 很小。

### 1.2.8 统一收敛分析

**(a) 一般方法。** 形式如 [(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) 的一阶方法的大多数收敛分析依赖于以下递归不等式，该不等式通常由两个或三个连续迭代生成：

`D[t + 1] + Δ[t] ≤ ω[t] ⋅ D[t] + E[t],`

其中 `D[t]`、`Δ[t]` 和 `E[t]` 是非负量，且 `ω[t] ∈ (0, 1]` 是收缩因子。这些量通常依赖于两个连续迭代 `w^(t)` 和 `w^(t + 1)`，但有时也依赖于 `w^(t − 1)`。误差项 `E[t]` 通常满足 `∑_{t=0}^{∞} E_t < +∞`。此外，对于次线性速率，我们通常有 `ω[t] = 1` 或 `ω[t] → 1`；对于线性速率，则有固定的 `ω[t] = ω ∈ (0, 1)`。量 `D[t]` 可被称为势函数或 Lyapunov 函数。不存在构造 `D[t]` 的通用通用方法，但对于梯度型方法，它通常是 `∥w^(t) − w⋆∥²`、`∥w^(t) − w^(t − 1)∥²`、`F(w^(t)) − F⋆`、`∥∇F(w^(t))∥²`（在欧几里得或加权范数中），或这些项的组合。显然，如果 `E[t] = 0`，则 `{D[t]}` 是非增的，显示了 `D[t]` 的下降性质。然而，如果 `E[t] > 0`，则不再具有 `D[t]` 的下降性质，这通常发生在 SGD 或次梯度方法中。存在两种情况：

*   **情况 1。** 如果 `D[t]` 包含最优性度量，例如 `S[t][F(w^(t)) − F⋆]`，则我们可以证明对于最后一个迭代 `w^(t)`，有 `F(w^t) - F⋆ ≤ C / S_t`，其中 `C` 是依赖于 `w⁰` 并可能依赖于 `w⋆` 或 `F⋆` 的常数。

*   **情况 2。** 如果 `Δ[t]` 包含最优性度量，例如 `γ[t]∥∇F(w^(t))∥²`，则我们可以证明对于某个常数 `C` 和 `S_T := ∑_{t=0}^{T} γ_t`，有 `(1 / S_T) ∑_{t=0}^{T} γ_t ∥∇F(w^t)∥² ≤ C / S_T`。

递归估计 [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) 可用于证明不同梯度型方法的收敛性，包括标准和加速算法。让我们举例说明如何为一些常见方案获得 [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14)。
