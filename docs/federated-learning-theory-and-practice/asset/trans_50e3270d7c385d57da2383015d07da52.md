## 20.1.4 差分隐私与联邦语音助手

在理解了联邦语音模型设计的基础后，我们将把重点转移到保护隐私的联邦语音建模上，该建模可结合新的数据法规要求，通过可靠的联邦系统提供可度量的隐私损失。更具体地说，我们关注差分隐私[[1](#Chp020_353-368_B9780443190377000302.xhtml#br0005),[18]](#Chp020_353-368_B9780443190377000302.xhtml#br0090)（DP）保护的联邦学习框架，其中带有 DP 的联邦学习旨在提供定量的隐私度量。由于 DP 在保护数据隐私（如用户身份）和模型参数（如权重和梯度信息）方面的优势，它满足了 GDPR 指南中规定的部分要求。DP 算法[[1](#Chp020_353-368_B9780443190377000302.xhtml#br0005),[20]](#Chp020_353-368_B9780443190377000302.xhtml#br0100)旨在提供定量保证，并进一步防止身份（如口音）推断。我们在下文中定义差分隐私的数学形式，并探讨其对语音处理的潜在影响，其中差分隐私机制[[18]](#Chp020_353-368_B9780443190377000302.xhtml#br0090)已被公认为部署具有目标隐私保证算法的既定标准。

我们将介绍一些关于从局部差分隐私的定义出发，扩展和发展 Rényi 散度[[42](#Chp020_353-368_B9780443190377000302.xhtml#br0210),[62]](#Chp020_353-368_B9780443190377000302.xhtml#br0310)度量至语音处理领域的最新进展，并为结合集成学习框架进行 DP 保护的语音处理的一些优势提供理论依据。

我们首先详细阐述用于监督语音识别的 `ε`-DP，其中 `ε` 表示由部署在训练语音数据集上的随机噪声机制形成的隐私预算。较小的 `ε` 表示在具有 `ℓ[p]`-范数有界（`p` ≥ 1）距离[[64]](#Chp020_353-368_B9780443190377000302.xhtml#br0320）的空间中存在较大的噪声失真。我们在下文中定义差分隐私的数学形式，并探讨其对语音处理的潜在影响，其中差分隐私机制[[18]](#Chp020_353-368_B9780443190377000302.xhtml#br0090)已被公认为部署具有目标隐私保证算法的既定标准。

### 定义 20.1

定义域为 `𝒟`、值域为 `ℛ` 的随机算法 `ℳ` 是（`ε`，`δ`）-差分隐私的，如果对于任意两个相邻输入（如语音数据）`d`，`d'` ∈ `𝒟` 以及任意输出预测子集（如标签）`S` ⊆ `ℛ`，以下成立：

`Pr[ℳ(d) ∈ S] ≤ e^(ε)Pr [ℳ(d')∈S] + δ`。

(20.1)

上述定义产生了一种隐私概念，可解释为通过乘法因子 `e^(ε)` 和加法量 `δ` 来衡量特定结果的概率差异。带有后处理[[1]](#Chp020_353-368_B9780443190377000302.xhtml#br0005)（如批次训练）的 `DP` 机制处于一般 Rényi 散度[[42]](#Chp020_353-368_B9780443190377000302.xhtml#br0210)度量下，阶为 `α` ∈ (1, ∞)，称为 `RDP[α]`，对于所有相邻数据集 `d`，`d'`：

```
RDP_α(M(d)||M(d')) = 1/(α - 1) log S_θ ~ M(d')[(p_M(d)(θ)/p_M(d')(θ))^α] ≤ ε.
```

(20.2).
