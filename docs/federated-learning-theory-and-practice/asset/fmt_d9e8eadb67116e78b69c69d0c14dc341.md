
### 10.4.2 Algorithm design for BiG-FL

Solving Eq. [(10.17)](#Chp010_181-197_B9780443190377000181.xhtml#deq21) exactly to get the optimal solution is not practical. Instead, following the FL algorithms, we apply SGD for several steps and obtain an approximate solution of the LL problem. To be more specific, the LL optimization variable is updated by

```
\mathbf{\theta}_{i}^{k + 1} = \mathbf{\theta}_{i}^{k} - \frac{\beta^{t}}{m}\sum\limits_{j = 1}^{m}\nabla_{\mathbf{\theta}_{i}}G_{i}(\mathbf{\varphi}^{t},\mathbf{\theta}_{i}^{k},\mathbf{\theta}_{- i}^{k};\xi_{j}),\quad\forall i \in \lbrack n\rbrack,
```

![Image](OEBPS/images/B9780443190377000181/si97_u6.png)(10.19)

where `k` denotes the index of the inner loop by initializing `\mathbf{\theta}_{i}^{0} = \mathbf{\theta}_{i}^{(t)}`, `\beta^{(t)}` is the LL step size, and `\nabla G_{i}(\mathbf{\varphi}^{(t)},\mathbf{\theta}_{i}^{(k)},\mathbf{\theta}_{- i}^{(k)};\xi_{j})` represents the gradient of the `i`th BiG-FL LL empirical loss function evaluated at the point `(\mathbf{\varphi}^{(t)},\mathbf{\theta}_{i}^{(k)},\mathbf{\theta}_{- i}^{(k)})` with the `j`th data sample (i.e., `\xi_{j} \triangleq (X_{j}, Y_{j}) \sim \mathcal{D}_{j}`). After consecutive `\tau` steps of the inner loop update, we set `\mathbf{\theta}_{i}^{(t + 1)} = \mathbf{\theta}_{i}^{(\tau)}`.

Similarly, the LL variable is updated by SGD with computing the hyper-gradient [[5]](#Chp010_181-197_B9780443190377000181.xhtml#br0025) as follows:

```
\mathbf{\varphi}^{t + 1} = \mathbf{\varphi}^{t} - \frac{\alpha^{t}}{m}\sum\limits_{j = 1}^{m}\left( \nabla_{\mathbf{\varphi}}F_{j}^{t} - \nabla_{\mathbf{\varphi}\mathbf{\theta}}^{2}\mathbf{G}_{j}^{t}\left( \nabla_{\mathbf{\theta}\mathbf{\theta}}^{2}\mathbf{G}_{j}^{t} \right)^{- 1}\nabla_{\mathbf{\theta}}F_{j}^{t} \right),
```

![Image](OEBPS/images/B9780443190377000181/si104_u7.png)(10.20)

where `\alpha^{(t)}` denotes the UL step size, `\nabla_{\varphi}F_{j}^{(t)}` (the abbreviation of `\nabla_{\mathbf{\varphi}}F(\mathbf{\varphi}^{(t)},\{\mathbf{\theta}_{i}^{(t)}\};\xi_{j})`) is the gradient of the UL empirical loss function evaluated at point `(\mathbf{\varphi}^{(t)},\{\mathbf{\theta}_{i}^{(t)}\})` with the `j`th tail node of the negative sample for head node `i` (i.e., `j \sim \mathcal{P}_{i}`), `\nabla_{\mathbf{\varphi}\mathbf{\theta}}^{2}\mathbf{G}_{j}^{(t)}` and `(\nabla_{\mathbf{\theta}\mathbf{\theta}}^{2}\mathbf{G}_{j}^{(t)})^{-1}` respectively stand for the stochastic approximation of the Jacobian matrix of the LL loss function with respect to both `\varphi` and `\{\mathbf{\theta}_{i}\}` and the inverse of Hessian matrix of the LL loss function. Here, we assume that the LL loss functions are strongly convex (e.g., if `\kappa` is sufficiently large), implying that `\nabla_{\mathbf{\theta}\mathbf{\theta}}^{2}\mathbf{G}_{j}^{(t)}` is invertible. The complete implementation of BiG-FL is shown in [Algorithm 4](#Chp010_181-197_B9780443190377000181.xhtml#f0030), where `\theta` is the concatenation of `\{\mathbf{\theta}_{i}, \forall i\}`.
