

#### 4.4.1.1 训练期间的防御

1.  **梯度裁剪与噪声添加**。其中 `C` 是预先确定的裁剪阈值，用于防止某些客户端利用提升（第 [4.3.1.2](#Chp004_75-90_B9780443190377000120.xhtml#s0065) 节）产生过大的影响。裁剪后，根据 `𝒩(0, σ²I)` 添加噪声。Xie 等人 [[44]](#Chp004_75-90_B9780443190377000120.xhtml#br0220) 表明，训练期间的裁剪和噪声添加，连同测试时的参数平滑，能为针对参数扰动幅度受限的攻击者提供经认证的鲁棒性。

2.  **鲁棒学习率** [[32]](#Chp004_75-90_B9780443190377000120.xhtml#br0160)。该防御背后的直觉是：恶意客户端的更新很可能会使模型朝着与良性代理不同的方向移动。因此，该防御按如下方式调整更新中每个坐标 `i` 的学习率：

```
η_θ,i = { η  if |∑_{k ∈ S_t} sign(δ_k[i])| ≥ θ,
        { -η otherwise,
```

其中，*学习阈值 θ* 是服务器端的一个超参数。这确保了在足够数量的客户端达成一致的维度上，按常规进行更新。否则，将最大化关于这些参数的损失，从而可能使模型远离对抗方向。

3.  **更新稀疏化** [[33]](#Chp004_75-90_B9780443190377000120.xhtml#br0165)。同样，基于恶意客户端提供的更新指向与良性客户端不同的方向以植入后门这一直觉，服务器在裁剪后仅更新聚合更新中幅度最大的前 `l` 个元素。他们证明了这给攻击者带来了一个具有挑战性的约束：增加关键坐标的幅度对于被选入前 `l` 个是必要的，但裁剪确保了来自单个客户端的单个坐标的幅度无法压倒其他客户端。

#### 4.4.1.2 *事后* 防御

到目前为止，我们讨论的防御旨在防止恶意行为在联邦模型训练期间被植入。在后门攻击的特定情况下，也有大量工作致力于*检测已训练模型中的后门* [[16](#Chp004_75-90_B9780443190377000120.xhtml#br0080), [21](#Chp004_75-90_B9780443190377000120.xhtml#br0105), [25](#Chp004_75-90_B9780443190377000120.xhtml#br0125), [40](#Chp004_75-90_B9780443190377000120.xhtml#br0200), [45](#Chp004_75-90_B9780443190377000120.xhtml#br0225)]。然而，由于其中大部分工作并非针对 FL 场景，我们建议感兴趣的读者参考一些关于后门防御的优秀综述文章 [[11](#Chp004_75-90_B9780443190377000120.xhtml#br0055), [35](#Chp004_75-90_B9780443190377000120.xhtml#br0175)]。

**寻找后门的瓶颈。** 近期工作 [[17]](#Chp004_75-90_B9780443190377000120.xhtml#br0085) 指出，存在一些学习设置，在这些设置中可以将“不可检测”的后门植入模型。他们表明，没有任何高效算法能够区分包含后门的模型和不包含后门的模型。事实上，通过从 3-SAT 归约，已证明在模型中检测后门是 NP-hard 问题 [[41]](#Chp004_75-90_B9780443190377000120.xhtml#br0205)。这一结果对上述后门检测防御的影响是未来工作一个引人入胜的研究方向。

### 4.4.2 防御推理时攻击

正如第 [4.3.2](#Chp004_75-90_B9780443190377000120.xhtml#s0070) 节所述，使用 FL 训练的模型在推理时容易受到精心设计的对抗样本攻击。针对对抗样本的防御存在大量研究，特别是针对中心化训练的模型 [[12](#Chp004_75-90_B9780443190377000120.xhtml#br0060), [28](#Chp004_75-90_B9780443190377000120.xhtml#br0140), [34](#Chp004_75-90_B9780443190377000120.xhtml#br0170)]，而开发联邦推理时防御的工作主要集中在将这些技术应用于 FL。

在各种提出的防御中，对抗训练（AT）被表述为鞍点问题的优化 [[28]](#Chp004_75-90_B9780443190377000120.xhtml#br0140)，已成为中心化训练鲁棒模型的首选方法。然而，当天真地应用于 FL 时，AT 结合代理端的非独立同分布（non-iid）本地数据会导致显著的*模型漂移*。

Zizzo 等人 [[49]](#Chp004_75-90_B9780443190377000120.xhtml#br0245) 还研究了拜占庭鲁棒聚合策略与 AT 的兼容性。兼容性将确保模型同时对训练时的拜占庭攻击和推理时的对抗攻击具有鲁棒性。他们的实验表明，Trimmed Mean 和 Krum 的对抗准确率均显著下降，只有 Bulyan 提供了任何有意义的对抗性能。因此，开发能够联合优化训练时和推理时鲁棒性的联邦训练技术是一个开放问题。将针对对抗样本的经认证防御 [[12](#Chp004_75-90_B9780443190377000120.xhtml#br0060), [34](#Chp004_75-90_B9780443190377000120.xhtml#br0170)] 应用于 FL 的早期工作见于 [[9]](#Chp004_75-90_B9780443190377000120.xhtml#br0045)。

## 4.5 要点与未来工作

由于可能有不受信任的客户端参与模型训练，FL 固有地容易受到攻击。后门攻击的必然性也已在 [[41]](#Chp004_75-90_B9780443190377000120.xhtml#br0205) 中得到严格确立，文中指出：“如果模型容易受到输入扰动形式的推理时攻击（即对抗样本）影响，那么它将容易受到训练时的后门攻击。此外，如果存在对抗样本，则模型扰动后门的范数上界为一个（实例相关的）常数乘以对抗样本的扰动范数。” 反之，可以证明对后门攻击的鲁棒性意味着对对抗样本的韧性，而这本身就是一个开放问题 [[41]](#Chp004_75-90_B9780443190377000120.xhtml#br0205)。
