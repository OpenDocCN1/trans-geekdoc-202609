
此外，PQC 配备了用于量子纠缠的 CNOT 门和可学习量子门，即 `R[X](α[i])`、`R[Y](β[i])` 和 `R[Z](γ[i])`，其中量子比特角度 `α[i]`、`β[i]` 和 `γ[i]` 在训练过程中进行调整。绿色虚线方框中的 PQC 框架（印刷版为深灰色）被重复复制以构建深度模型，PQC 框架的数量称为 VQC 的深度。测量操作从量子输出态中输出经典期望观测值 `|z[1]⟩, |z[2]⟩, …, |z[U]⟩`。期望结果用于计算损失值和梯度下降 [[30]](#Chp018_329-341_B9780443190377000284.xhtml#br0150)，这些值用于基于随机梯度下降（SGD）优化器应用反向传播算法 [[35]](#Chp018_329-341_B9780443190377000284.xhtml#br0175) 来更新 VQC 模型参数。

## 18.3 量子自然梯度下降

如公式 [(18.2)](#Chp018_329-341_B9780443190377000284.xhtml#deq2) 所示，在第 `t` 步，标准梯度下降在欧几里得空间中关于参数 `θ` 最小化损失函数 `ℒ(θ)`，

```
θ[t + 1] = θ[t] − η∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si22_u17.png)(18.2)

其中 `η` 为学习率。

标准梯度下降算法在参数空间的欧几里得几何中执行每一步优化。然而，由于参数化的形式并不唯一，不同的参数化组合可能会扭曲优化景观内的距离几何。一种更好的替代方法是在分布空间中执行梯度下降，即自然梯度下降 [[1]](#Chp018_329-341_B9780443190377000284.xhtml#br0005)，它与维度无关，且对不同的参数化形式保持不变。自然梯度下降的每一步优化都为参数 `θ[t]` 的更新选择最优步长，而与参数化的选择无关。数学上，标准梯度下降被修改为

```
θ[t + 1] = θ[t] − ηF^(−1)∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si24_u17.png)(18.3)

其中 `F` 表示费舍信息矩阵，它充当度量张量，将欧几里得参数空间中的最速梯度下降转换为分布空间中的最速下降。

由于标准欧几里得几何对于优化量子变分算法并非最优，其量子类比具有以下形式：

```
θ[t + 1] = θ[t] − ηg^+(θ[t])∇ℒ(θ[t]),
```

![Image](OEBPS/images/B9780443190377000284/si25_u17.png)(18.4)

其中 `g^+(θ[t])` 指代伪逆，并与量子电路的特定架构相关。系数 `g^+(θ[t])` 可通过富比尼-施图迪度量张量计算，在经典极限下它归约为费舍信息矩阵 [[21]](#Chp018_329-341_B9780443190377000284.xhtml#br0105)。

富比尼-施图迪度量是量子力学几何化的自然度量，量子力学的许多奇特行为（包括量子纠缠）均可归因于富比尼-施图迪度量的特殊性。

在本章中，富比尼-施图迪度量张量通常以量子力学混合态的符号定义。为将该符号显式等同于齐次坐标，设

```
|ψ⟩ = ∑_{k = 0}^{K} Z_k |e_k⟩ = [Z_0:Z_1:…:Z_K],
```

![Image](OEBPS/images/B9780443190377000284/si27_u17.png)(18.5)

其中 `{|e_k⟩}` 是希尔伯特空间的一组标准正交基矢，`Z_k` 为复数；`Z_α = [Z_0 : Z_1 : … : Z_K]` 是投影空间中齐次坐标点的标准符号。然后，给定空间中的两个点 `|ψ⟩ = Z_α` 和 `|ϕ⟩ = W_α`，`|ψ⟩` 和 `|ϕ⟩` 之间的距离为

```
γ = arccos√(⟨ψ|ϕ⟩⟨ϕ|ψ⟩ / ⟨ψ|ψ⟩⟨ϕ|ϕ⟩).
```

![Image](OEBPS/images/B9780443190377000284/si35_u16.png)(18.6)

## 18.4 面向 VQC 的量子自然梯度下降

在将 QFNGD 用于量子联邦学习系统之前，我们专注于 QNGD 在单个 VQC 中的应用。为简化起见，我们利用富比尼-施图迪度量张量的分块对角近似，将 QNGD 组合到 NISQ 量子硬件上的 VQC 训练中。

我们设定初始量子态 `|ψ[0]⟩` 和具有 `L` 层的 PQC。对于 `l ∈ [L]`，我们分别用 `W[l]` 和 `V[l](θ[l])` 表示与非参数化量子门和参数化量子门相关的酉矩阵。（参见 [图 18.3](#Chp018_329-341_B9780443190377000284.xhtml#f0020)。）
