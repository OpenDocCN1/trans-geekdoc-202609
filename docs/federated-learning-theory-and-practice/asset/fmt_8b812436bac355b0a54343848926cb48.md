
Specifically, DE divides the entire domain `𝒳` into `P ≥ 1` disjoint sub-regions `𝒳[1], …, 𝒳[P]`, and the incorporation of DE requires three major modifications to DP-FTS. Firstly, during the initialization stage, every agent only explores a local sub-region `𝒳[i]` instead of the entire domain `𝒳`.

Next, instead of a single vector `ω[t]`, the central server produces and broadcasts `P` vectors `{ω[t]^(i)}[i=1,…,P]`, each corresponding to a different sub-region `𝒳[i]` and using a different set of weights `{φ[n]^(i)}[n=1,…,N]`. Interestingly, the different privacy-preserving transformations performed by the central server to produce `P` vectors can be interpreted as a single sub-sampled Gaussian mechanism producing a single joint vector `ω[t]^(joint) ≜ (ω[t]^(i))[i ∈ [P]]` ([Fig. 14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(b)).

Then, if agent `𝒜[n]` uses the vector `ω[t]^(joint) = (ω[t]^(i))[i ∈ [P]]` received from the central server to choose the next query `x[t+1]^(n)` (with probability `1 − p[t+1]`), it chooses `x[t+1]^(n)` by maximizing the reconstructed functions for all sub-regions, as illustrated in [Fig. 14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(c). Refer to the work of `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` for a more complete description of the DP-FTS-DE algorithm.

### 14.2.5 Theoretical and empirical results for FBO

The work of `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` has provided theoretical guarantees on both the privacy and utility of DP-FTS-DE. The privacy guarantee is given by the proposition below:

**Proposition 14.1**

*There exist constants `c[1]` and `c[2]` such that for fixed q and T and any `ϵ < c[1]q²T`, `δ > 0`, DP-FTS-DE is `(ϵ, δ)`-DP if `z ≥ c₂q√(T log(1/δ))/ϵ`.*

The following theorem gives a guarantee on the utility/performance of DP-FTS-DE in terms an upper bound on `R[T]¹` (Section [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025)), in which all notations have been defined in Sections [14.2.1](#Chp014_257-279_B9780443190377000235.xhtml#s0020), [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025) and [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035):

**Theorem 14.1**

**Informal**

*With high probability,*

```
R_T^1 = \widetilde{\mathcal{O}}\left( \left( B + 1/p_1 \right)\gamma_T\sqrt{T}\ + \ \sum_{t = 1}^{T}\psi_t\ + \ B\sum_{t = 1}^{T}\vartheta_t \right),
```

*where `\psi_t := \widetilde{\mathcal{O}}((1 - p_t)P\varphi_{\max}q^{-1}(\Delta_t + zS\sqrt{M}))`, and `\Delta_t := \sum_{n = 1}^{N}\widetilde{\mathcal{O}}(\varepsilon Bt^2 + B + \sqrt{M} + d_n + \sqrt{\gamma_t})`. `\vartheta_t := (1 - p_t)\sum_{i = 1}^{P}\sum_{n \in \mathcal{C}_t}\varphi_n^{(i)}`, `\mathcal{C}_t := \{ n \in [N] \mid ||\mathbf{\omega}_{n,t}||_2 > S/\sqrt{P} \}`.*

The first interesting insight from [Theorem 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015) is that agent `𝒜[1]` is asymptotically *no-regret* even if all other agents are heterogeneous, i.e., all other agents have significantly different objective functions from `𝒜[1]`. This ensures that DP-FTS-DE is robust against the heterogeneity of agents, which is a significant challenge in FBO (Section [14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025)).

Moreover, [Theorem 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015), when interpreted together with [Proposition 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010), also reveals some interesting theoretical insights regarding the **privacy–utility trade-off**. Firstly, a larger `z` (i.e., larger variance for the added Gaussian noise, Section [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035)) improves the privacy guarantee ([Proposition 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010)), yet results in a worse utility since it leads to a worse regret upper bound (through `\psi_t`). Secondly, a larger `q` (i.e., more selected agents in each iteration, Section [14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035)) improves the utility since it tightens the regret upper bound (by reducing the value of `\psi_t`) at the expense of a worse privacy guarantee ([Proposition 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0010)). The value of the clipping threshold `S` affects the regret upper bound (hence the utility) through two conflicting effects: a smaller `S` (1) reduces the value of `\psi_t` (hence, the regret bound) but is also likely to enlarge the cardinality of the set `C[t]` which increases the value of `\vartheta_t` and hence, the regret bound ([Theorem 14.1](#Chp014_257-279_B9780443190377000235.xhtml#enun0015)). Refer to Section 4 of `[[14]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)` for a more detailed discussion on the theoretical guarantees of DP-FTS-DE, as well as the associated insights.
