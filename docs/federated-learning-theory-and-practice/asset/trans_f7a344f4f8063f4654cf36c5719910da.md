# 第2章：关于带差分隐私的模型训练理论的考量

Marten van Dijk^([a](#Chp002_29-55_B9780443190377000090_split_000.xhtml#aff0010),[b](#Chp002_29-55_B9780443190377000090_split_000.xhtml#aff0015))；Phuong Ha Nguyen^([c](#Chp002_29-55_B9780443190377000090_split_000.xhtml#aff0020))

## 摘要

在联邦学习中，协作学习由一组客户端进行，每个客户端都希望保持对其本地训练数据使用方式的控制，特别是每个客户端的本地训练数据如何保持私密。差分隐私是限制隐私泄露的一种方法。我们提供了其框架和可证明属性的总体概述，采用了基于假设的较新定义，称为高斯DP或`f`-DP，并讨论了差分隐私随机梯度下降（DP-SGD）。我们停留在元层面，尝试提供直观的解释和见解。

### 关键词

随机梯度下降 (SGD)；DP-SGD；差分隐私 (DP)；高斯DP

## 2.1 简介

隐私泄露是大数据时代的一个主要问题。基于大数据解决学习任务本质上意味着，只有通过协作努力才能获得足够的数据，以训练出具有足够纯净准确性（效用）的全局模型。联邦学习是一个框架，其中学习任务由一组松散联合的参与设备/客户端解决，这些设备/客户端由中央服务器协调 [[3]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0015)，[[7]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0035)，[[8]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0040)，[[10]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0050)，[[27]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0135)，[[28]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0140)，[[31]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0155)，[[33]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0165)–[[35]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0175)，[[37]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0185)，[[38]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0190)，[[40]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0200)，[[55]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0275)，[[57]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0285)。客户端使用自己的本地数据参与学习任务，通过训练全局模型，希望对其本地专有数据获得隐私保证。为此，引入了DP-SGD [[1]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0005)，因为它将分布式随机梯度下降 (SGD) [[54]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0270) 与差分隐私 (DP) [[13]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0065)–[[15]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0075)，[[17]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0085) 相结合。

使用包含 `m` 个样本的训练集 `{ξ[i]}_{i=1}^m` 训练许多机器学习 (ML) 模型的优化问题可以表述为如下的有限和最小化问题：

```
\min_{w \in \mathbb{R}^{d}}\left\{ F(w) = \frac{1}{m}\sum_{i = 1}^{m}f(w;\xi_{i}) \right\}.
```

(2.1)

目标是针对模型参数 `w` 最小化损失函数。该问题称为经验风险最小化，它涵盖了来自机器学习领域的广泛凸和非凸问题，包括但不限于逻辑回归、多核学习、条件随机场和神经网络。

我们希望在分布式环境中求解 (2.1)，其中许多客户端拥有自己的本地数据集，有限和最小化问题针对所有本地数据集的集合。一种广泛接受的方法是反复使用SGD [[44]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0220)，[[45]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0225)，[[48]](#Chp002_29-55_B9780443190377000090_split_001.xhtml#br0240) 递归公式：

```
w[t + 1] = w[t] - η[t]∇f(w[t]; ξ),
```

(2.2)
