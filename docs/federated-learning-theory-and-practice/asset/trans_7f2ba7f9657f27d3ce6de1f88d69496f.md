
文献[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)和[\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)提出了FBO算法。文献[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)引入了首个FBO算法，名为`federated Thompson sampling`（FTS，联邦汤普森采样），该算法解决了FBO中的若干重要挑战。具体而言，FTS算法免除了传输BO观测值的要求，仅需交换少量参数，且尽管存在智能体异质性，理论上仍保证无懊悔[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)。文献[\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)的最新工作将文献[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)的FTS算法进行了扩展，纳入了严格的隐私保障，并通过分布式探索方法进一步提升了其实际性能。关于FRL，文献[\[26\]](#Chp014_257-279_B9780443190377000235.xhtml#br0130)的最新工作引入了首个具有理论收敛保证的FRL框架。具体而言，该工作基于经典的策略梯度算法，仅要求智能体交换其策略梯度而非原始轨迹，并通过利用方差缩减优化技术实现了低样本复杂度。此外，文献[\[26\]](#Chp014_257-279_B9780443190377000235.xhtml#br0130)还实现了对拜占庭智能体（即由随机故障或对抗性攻击引起）的理论鲁棒性保证，这是FL中另一个重要的考量因素。这些关于FBO[\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)、[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)和FRL[\[26\]](#Chp014_257-279_B9780443190377000235.xhtml#br0130)的最新工作已被证明在理论上扎实且在实践中有效，我们将分别在第[14.2](#Chp014_257-279_B9780443190377000235.xhtml#s0015)节和第[14.3](#Chp014_257-279_B9780443190377000235.xhtml#s0045)节中详细讨论它们。除了FBO和FRL，另一条研究路线将`multi-armed bandits`（多臂老虎机）[\[40\]](#Chp014_257-279_B9780443190377000235.xhtml#br0200)（另一个经典的序贯决策问题）扩展到了联邦设定，从而引入了联邦老虎机[\[16\]](#Chp014_257-279_B9780443190377000235.xhtml#br0080)、[\[22\]](#Chp014_257-279_B9780443190377000235.xhtml#br0110)、[\[66\]](#Chp014_257-279_B9780443190377000235.xhtml#br0330)。这些关于联邦老虎机的最新工作主要关注理论视角，我们将在第[14.4.3](#Chp014_257-279_B9780443190377000235.xhtml#s0090)节中讨论它们。

### 14.2.1 贝叶斯优化背景

`Bayesian optimization`（BO，贝叶斯优化）旨在利用序贯查询来最大化目标函数`f : X → R`，即寻找`x* ∈ arg max[x ∈ X] f(x)`，其中`X ⊂ R^d`是`d`维域的一个离散子集。

GP `GP(μ(·), k(·, ·))`由其均值函数`μ`和核函数`k`表征。我们假设在不失一般性的情况下`μ(x) = 0`且`k(x, x') ≤ 1, ∀x, x' ∈ X`，且主要关注此处广泛使用的`squared exponential`（SE，平方指数）核[\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)、[\[15\]](#Chp014_257-279_B9780443190377000235.xhtml#br0075)。在BO的第`t + 1`次迭代中，给定前`t`个观测到的输入-输出对，GP后验由`GP(μ_t(·), σ_t²(·, ·))`给出，其中

```
μ_t(x) := k_t(x)^⊤(K_t + λI)^(−1)y_t,
σ_t²(x, x') := k(x, x') − k_t(x)^⊤(K_t + λI)^(−1)k_t(x')
```
