# 第9章：元联邦学习

## 摘要

由于其分布式方法论及隐私保护特性，联邦学习（FL）易受训练时对抗攻击。本研究聚焦于后门攻击，此类攻击中攻击者旨在导致嵌入对抗触发器的输入发生目标误分类，同时在主要学习任务上保持可接受的性能。联邦学习中针对后门攻击的现有防御需要直接访问每个客户端的更新，而在部署了`安全聚合`的最新FL设置中，这并不可行。本研究旨在回答以下问题：“*在安全聚合到位的情况下，是否可能防御后门攻击？*”，这是先前工作未曾解决的问题。为此，我们提出了`元联邦学习`（Meta-FL），一种新型联邦学习变体，它不仅兼容安全聚合协议，还便于防御后门攻击。我们在两个分类数据集SVHN[\[20\]](#Chp009_161-179_B978044319037700017X.xhtml#br0100)和GTSRB[\[25\]](#Chp009_161-179_B978044319037700017X.xhtml#br0125)上对Meta-FL进行了系统评估。结果表明，Meta-FL不仅比经典FL实现了更好的效用，还增强了现有防御在对抗攻击方面的鲁棒性性能。
