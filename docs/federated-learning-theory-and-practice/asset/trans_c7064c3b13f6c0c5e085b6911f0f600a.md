
由于文献[\[14\]](#Chp014_257-279_B9780443190377000235.xhtml#br0070)提出的方法（名为`DP-FTS-DE`）是FBO的最先进算法，我们将在下一节（第[14.2.4](#Chp014_257-279_B9780443190377000235.xhtml#s0035)节）介绍`DP-FTS-DE`算法的细节，然后在第[14.2.5](#Chp014_257-279_B9780443190377000235.xhtml#s0040)节讨论其理论保证和实证性能。

### 14.2.4 FBO的算法

为了便于理解，在本节中，我们将首先介绍不包含`DE`技术的`DP-FTS`算法，然后描述如何修改`DP-FTS`以融入`DE`从而推导出`DP-FTS-DE`算法。

**DP-FTS算法。** [图14.1](#Chp014_257-279_B9780443190377000235.xhtml#f0010)(a)展示了`DP-FTS`算法。`DP-FTS`的每次迭代*t*包含以下步骤：

![Figure 14.1 (a) DP-FTS algorithm without distributed exploration; (b)–(c) replacing steps (3) and (5) in (a) with that in (b) and (c) to derive the DP-FTS-DE algorithm (P = 2 sub-regions).](OEBPS/images/B9780443190377000235/gr001_u12.jpg)

图14.1 (a) 不带分布式探索的DP-FTS算法；(b)–(c) 用(b)和(c)中的步骤替换(a)中的步骤(3)和(5)以推导出DP-FTS-DE算法（*P* = 2个子区域）。

**智能体执行的步骤** ![Image](OEBPS/images/B9780443190377000235/fx002_u2.jpg)**和** ![Image](OEBPS/images/B9780443190377000235/fx003_u1.jpg)**。** 每个智能体`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)利用其自身当前的*t*个输入-输出对历史记录，遵循公式[(14.2)](#Chp014_257-279_B9780443190377000235.xhtml#deq2)采样一个向量`ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png)（步骤![Image](OEBPS/images/B9780443190377000235/fx004_u1.jpg)），然后将`ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png)发送给中央服务器——步骤![Image](OEBPS/images/B9780443190377000235/fx005_u1.jpg)。

**中央服务器执行的步骤** ![Image](OEBPS/images/B9780443190377000235/fx006_u1.jpg)**和** ![Image](OEBPS/images/B9780443190377000235/fx007_u1.jpg)**。** 接下来，中央服务器使用子采样高斯机制处理接收到的*N*个向量`{ω[n, t]}[n=1,…,N]`![Image](OEBPS/images/B9780443190377000235/si60.png)——步骤![Image](OEBPS/images/B9780443190377000235/fx008_u1.jpg)——该机制包含四个步骤：

1.  **A.**  以概率*q*选择每个智能体，从而选取智能体的随机子集`𝒮[t] ⊂ {1, …, N}`![Image](OEBPS/images/B9780443190377000235/si61.png)；
2.  **B.**  裁剪每个被选中智能体的向量`ω[n, t]`![Image](OEBPS/images/B9780443190377000235/si59_u13.png)，使其*L*[2]![Image](OEBPS/images/B9780443190377000235/si62.png)范数的上界为*S*，![Image](OEBPS/images/B9780443190377000235/fx009_u1.jpg)；
3.  **C.**  利用`{φ[n]}[n=1,…,N]`![Image](OEBPS/images/B9780443190377000235/si63_u1.png]计算裁剪向量的加权平均值，`ω_t = (q)⁻¹ Σ_{n ∈ 𝒮_t} φ_n ω̂_{n,t}`![Image](OEBPS/images/B9780443190377000235/si64.png)；以及
4.  **D.**  向`ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)添加噪声`ϵ ∼ 𝒩(0, (z S φ_max / q)²)`![Image](OEBPS/images/B9780443190377000235/si65.png)，其中`φ_max = max[n=1,…,N] φ[n]`![Image](OEBPS/images/B9780443190377000235/si67_u1.png)，*z*是控制隐私-效用权衡的参数。最终向量`ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)随后广播给所有智能体——步骤![Image](OEBPS/images/B9780443190377000235/fx010_u1.jpg)。

**智能体执行的步骤** ![Image](OEBPS/images/B9780443190377000235/fx011_u1.jpg)**。** 智能体`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)从中央服务器接收向量`ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)后，可以选择其下一个查询`x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png)（步骤![Image](OEBPS/images/B9780443190377000235/fx012_u1.jpg)）。选择`δ ∈ (0, 1)`![Image](OEBPS/images/B9780443190377000235/si69_u1.png)并定义`β_t := B + σ√(2(γ_{t-1} + 1 + log(4/δ))`![Image](OEBPS/images/B9780443190377000235/si70_u1.png)，其中*B*是目标函数`f^(n)`![Image](OEBPS/images/B9780443190377000235/si71_u1.png)的RKHS范数上界（第[14.2.2](#Chp014_257-279_B9780443190377000235.xhtml#s0025)节），*σ*是噪声标准差（第[14.2.1](#Chp014_257-279_B9780443190377000235.xhtml#s0020)节），`γ[t-1]`![Image](OEBPS/images/B9780443190377000235/si72_u1.png)是关于`f^(n)`![Image](OEBPS/images/B9780443190377000235/si71_u1.png)从任意`t-1`![Image](OEBPS/images/B9780443190377000235/si73_u1.png)个查询集合中获得的最大信息增益[\[70\]](#Chp014_257-279_B9780443190377000235.xhtml#br0350)。

然后，以`p[t + 1] ∈ (0, 1]`![Image](OEBPS/images/B9780443190377000235/si74_u1.png)的概率，`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)通过从其后验分布`𝒢𝒫(μ[t]^(n)(·), β[t + 1]² σ[t]^(n)(·, ·)²)`![Image](OEBPS/images/B9780443190377000235/si76_u1.png) [(14.1)](#Chp014_257-279_B9780443190377000235.xhtml#deq1)中采样函数`f[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si75_u1.png)，再选择`x[t + 1]^(n) = arg max[x ∈ 𝒳] f[t + 1]^(n)(x)`![Image](OEBPS/images/B9780443190377000235/si77.png)，利用标准TS选择`x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png)。否则，以`1 - p[t + 1]`![Image](OEBPS/images/B9780443190377000235/si78.png)的概率，`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)利用从服务器接收到的`ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)选择`x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png)，即`x[t + 1]^(n) = arg max[x ∈ 𝒳] ϕ(x)^⊤ ω[t]`![Image](OEBPS/images/B9780443190377000235/si79_u1.png)。序列`(p[t])[t ∈ ℤ⁺]`![Image](OEBPS/images/B9780443190377000235/si80.png)被选为单调递增序列，使得`p[t] ∈ (0, 1]`，`∀t`![Image](OEBPS/images/B9780443190377000235/si81.png)且当`t → ∞`![Image](OEBPS/images/B9780443190377000235/si83_u1.png)时`p[t] → 1`![Image](OEBPS/images/B9780443190377000235/si82.png)。这确保了当`1 - p[t]`![Image](OEBPS/images/B9780443190377000235/si84.png)较大时，智能体可以利用来自其他智能体的信息（通过`ω[t]`![Image](OEBPS/images/B9780443190377000235/si66.png)）来通过加速探索来改善其收敛性。

在选择`x[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si68.png)并观测到`y[t + 1]^(n)`![Image](OEBPS/images/B9780443190377000235/si85.png)后，智能体`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)将`(x[t + 1]^(n), y[t + 1]^(n))`![Image](OEBPS/images/B9780443190377000235/si86.png)添加到其观测历史中，然后采样一个新向量`ω[n, t + 1]`![Image](OEBPS/images/B9780443190377000235/si87.png)——步骤![Image](OEBPS/images/B9780443190377000235/fx004_u1.jpg)。接着，`𝒜[n]`![Image](OEBPS/images/B9780443190377000235/si43_u12.png)将`ω[n, t + 1]`![Image](OEBPS/images/B9780443190377000235/si87.png)发送给中央服务器——步骤![Image](OEBPS/images/B9780443190377000235/fx005_u1.jpg)——算法重复执行。

**DP-FTS-DE算法。** `DP-FTS-DE`算法是通过将`DE`技术融入上述`DP-FTS`而获得的。
