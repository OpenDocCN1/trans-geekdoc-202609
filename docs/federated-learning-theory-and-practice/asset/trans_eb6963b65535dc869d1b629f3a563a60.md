
一个满足这些假设的简单场景是所有客户端的激活遵循独立的泊松过程。也就是说，如果客户端 *m* 两次连续激活之间的时间差遵循参数为 *λ*[*m*] 的指数分布，那么客户端 *m* 的激活就是一个泊松过程，其概率为 $q\_{m} = \\lambda\_{m}^{- 1}/\\sum\_{j = 1}^{M}\\lambda\_{j}^{- 1}$。我们首先展示有界 *τ*[*n*[*k*], *m*]^(*k*) 的收敛结果。

### 11.3.1 有界延迟下的收敛性

我们仅针对本小节做出以下假设。

**假设 11.4** 均匀有界延迟

*对于每个客户端 m 和每个样本 n，第 k 次迭代时的延迟* *τ*[*n*, *m*]^(*k*) *由常数 D 界定，即* *τ*[*n*, *m*]^(*k*) ≤ *D*。*

为了处理延迟信息，我们利用以下 Lyapunov 函数来分析 VAFL：

```
V^{k} = F( \theta\_{0}^{k},\mathbf{\theta}^{k} ) + \sum\limits\_{d = 1}^{D}\gamma\_{d}\left\| \mathbf{\theta}^{k - d + 1} - \mathbf{\theta}^{k - d} \right\|^{2},
```

(11.10)

其中 {*γ*[*d*]} 是一组稍后确定的常数。

**引理 11.1**

*在* 假设 [11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0010)–[11.4](#Chp011_199-217_B978044319037700020X.xhtml#enun0025) *下，若* $\eta\_{0}^{k} \leqslant \frac{1}{4L}$、*$\eta\_{m}^{k} \leqslant \frac{1}{4(L + 2\gamma\_{1})}$*，则有（令* $\gamma\_{D + 1} = 0$*）*

```
\mathbb{E}V^{k + 1} - \mathbb{E}V^{k} \leqslant - \left( \frac{\eta\_{0}^{k}}{2} - L{(\eta\_{0}^{k})}^{2} \right)\mathbb{E}\left\lbrack \left\| \nabla\_{\theta\_{0}}F\left( \theta\_{0}^{k},\mathbf{\theta}^{k} \right) \right\|^{2} \right\rbrack - \sum\limits\_{m = 1}^{M}q\_{m}\left( \frac{\eta\_{m}^{k}}{2} - L{(\eta\_{m}^{k})}^{2} - 2\gamma\_{1}{(\eta\_{m}^{k})}^{2} \right)\mathbb{E}\left\lbrack \left\| \nabla\_{\theta\_{m}}F\left( \theta\_{0}^{k},\mathbf{\theta}^{k} \right) \right\|^{2} \right\rbrack + \sum\limits\_{d = 1}^{D}\left( Dc^{k} + D\gamma\_{1}\max\limits\_{m}2\left( \eta\_{m}^{k} \right)^{2}L\_{m}^{2} + \gamma\_{d + 1} - \gamma\_{d} \right)\mathbb{E}\left\lbrack \left\| \mathbf{\theta}^{k + 1 - d} - \mathbf{\theta}^{k - d} \right\|^{2} \right\rbrack + L\left( \eta\_{0}^{k} \right)^{2}\sigma\_{0}^{2} + \sum\limits\_{m = 1}^{M}q\_{m}\left( L + 2\gamma\_{1} \right)\left( \eta\_{m}^{k} \right)^{2}\sigma\_{m}^{2}.
```

(11.11)

如果 {*γ*[*d*]} 按照补充材料中的规定妥善选择，则式 [(11.11)](#Chp011_199-217_B978044319037700020X.xhtml#deq15) 右侧的前三项为负。通过精心选择 {*η*[0]^(*k*), *η*[*m*]^(*k*)}，我们可以保证 [算法 1](#Chp011_199-217_B978044319037700020X.xhtml#f0010) 的收敛性。我们首先展示非凸情况下的收敛性。

**定理 11.1**

*在* [引理 11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0030) *的假设下，若* $\eta\_{0}^{k} = \eta\_{m}^{k} = \min\{\frac{1}{4(1 + D)L},\frac{c\_{\eta}}{\sqrt{K}}\}$ *且* *c*[*η*] > 0*，则有*

```
\frac{1}{K}\sum\limits\_{k = 0}^{K - 1}\mathbb{E}\left\lbrack {\|\nabla F\left( \theta\_{0}^{k},\mathbf{\theta}^{k} \right)\|}^{2} \right\rbrack = \mathcal{O}\left( 1/\sqrt{K} \right).
```

(11.12)

在额外的强凸假设下，收敛速率得到改进。

**定理 11.2**

*假设 F 是 μ-强凸的。在* [引理 11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0030) *的相同假设下，若* $\eta^{k} = \frac{4}{\mu\min\limits\_{m}\sqrt{q\_{m}}(k + K\_{0})}$ *且* $K\_{0} = \frac{4(4(D + 1)L + \mu\min\limits\_{m}\sqrt{q\_{m}}D)}{\mu\min\limits\_{m}\sqrt{q\_{m}}}$*，则有*

```
\mathbb{E}F(\theta\_{0}^{K},\mathbf{\theta}^{K}) - F^{\ast} = \mathcal{O}(1/K).
```

(11.13)

值得注意的是，在有界延迟假设下，即使不协调客户端的梯度样本和局部模型更新，我们的算法在非凸和强凸情况下均能达到与分块 SGD 相同阶的收敛速率 [\[42\]](#Chp011_199-217_B978044319037700020X.xhtml#br0210)。此外，定理 [11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0035) 和 [11.2](#Chp011_199-217_B978044319037700020X.xhtml#enun0040) 中的收敛速率通过最大延迟 *D* 依赖于工作节点数 *M*，通常 *D* = 𝒪(*M*)。具体而言，定理 [11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0035) 中的步长条件依赖于 *D*，而定理 [11.2](#Chp011_199-217_B978044319037700020X.xhtml#enun0040) 中的步长条件通过 *K*[0] 依赖于 *D*。因此，随着 *D* 的增加，步长需要减小，否则误差将随 *D* 的增加而增加。

### 11.3.2 随机无界延迟下的收敛性

接下来我们展示 *τ*[*n*[*k*], *m*]^(*k*) 无界但具有随机性情况下的收敛结果。我们仅针对本小节做出以下假设。

**假设 11.5** 随机无界延迟

*对于每个客户端 m，延迟* *τ*[*n*[*k*], *m*]^(*k*) *是一个具有无界支撑集的随机变量。存在* ${\overline{p}}\_{m},\rho > 0$ *使得*

```
\mathbb{P}\left( \tau\_{n\_{k},m}^{k} = d \right) \leqslant {\overline{p}}\_{m}\rho^{d}.
```

(11.14)

在 [假设 11.5](#Chp011_199-217_B978044319037700020X.xhtml#enun0045) 下，我们获得了与有界延迟情况相同阶的收敛速率。

**定理 11.3**

*在* 假设 [11.1](#Chp011_199-217_B978044319037700020X.xhtml#enun0010)–[11.3](#Chp011_199-217_B978044319037700020X.xhtml#enun0020) 和 [11.5](#Chp011_199-217_B978044319037700020X.xhtml#enun0045) *下，若* $\eta\_{0}^{k} = \eta\_{m}^{k} = \min\left\{ \frac{1}{4(1 + \min\_{m}\sqrt{c\_{m}})L},\frac{c\_{\eta}}{\sqrt{K}} \right\}$*，则有*

```
\frac{1}{K}\sum\limits\_{k = 0}^{K - 1}\mathbb{E}\left\lbrack \left\| \nabla F\left( \theta\_{0}^{k},\mathbf{\theta}^{k} \right) \right\|^{2} \right\rbrack = \mathcal{O}\left( 1/\sqrt{K} \right).
```

(11.15)
