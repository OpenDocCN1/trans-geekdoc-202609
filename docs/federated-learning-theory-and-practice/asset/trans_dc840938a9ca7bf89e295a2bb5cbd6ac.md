
其中 `w` 为共享全局参数，`θ = (θ[1], …, θ[n])` 为个性化模型，`g_m(w, θ_m) = (1/|D_m|) ∑_{i=1}^{|D_m|} ℓ_m((w, θ_m); (x_m^(i), c_m^(i)))` 为第 *m* 个客户端的局部损失函数，且 `0 ≤ d[w]`，`d[θ] ≤ d`。通过精心构造局部损失 `g_m(w, θ_m)` [[17]](#Chp007_125-141_B9780443190377000107.xhtml#br0085)，公式 [(7.2)](#Chp007_125-141_B9780443190377000107.xhtml#deq3) 涵盖了大多数现有的凸和非凸 pFL 方法，以及当 `d[θ] = 0` 和 `d[w] = d` 时的传统 FL 目标 [(7.1)](#Chp007_125-141_B9780443190377000107.xhtml#deq1)。因此，训练不同的 pFL 模型等价于求解问题 [(7.2)](#Chp007_125-141_B9780443190377000107.xhtml#deq3) 的特定实例，并能将广泛的新型 pFL 公式作为特例获得。在线性回归、逻辑回归或 SVM 的情况下，通用 pFL 问题 [(7.2)](#Chp007_125-141_B9780443190377000107.xhtml#deq3) 是一个凸问题。在深度神经网络（DNN）、卷积神经网络（CNN）或循环神经网络（RNN）的背景下会出现更复杂的情况，此时使用的是非线性映射而非线性映射 `x^(T)w`。DNN、CNN 或 RNN 通过一组层，利用 tanh、ReLu、Softmax 等非线性激活函数，以特征向量 `x` 的非凸函数进行预测。此时，方程 [(7.2)](#Chp007_125-141_B9780443190377000107.xhtml#deq3) 为非凸。

### 7.3.1 模型混合

模型混合背景下的通用思路是为每个客户端学习一个个性化模型，该模型为最优局部模型与最优全局模型的最优混合。采用混合技术的常见工作有 APFL [[7]](#Chp007_125-141_B9780443190377000107.xhtml#br0035)、L2GD [[16]](#Chp007_125-141_B9780443190377000107.xhtml#br0080) 和模型插值 [[27]](#Chp007_125-141_B9780443190377000107.xhtml#br0135)。在 APFL 算法中，每个客户端 *m* 的混合参数 `α[m]` 在 pFL 训练过程中自适应学习，以控制全局模型与局部模型之间的混合权重。APFL 的公式如下：
