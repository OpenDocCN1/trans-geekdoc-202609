
$$
\underset{D_{t + 1}}{\underset{\text{︸}}{\frac{1}{2}{\| w^{t + 1} - w\|}^{2}}} + \underset{\Delta_{t}}{\underset{\text{︸}}{\eta_{t}[ F(w^{t}) - F(w)]}} \leqslant \underset{D_{t}}{\underset{\text{︸}}{\frac{1}{2}{\| w^{t} - w\|}^{2}}} + \underset{E_{t}}{\underset{\text{︸}}{\frac{\eta_{t}^{2}}{2}{\|\nabla F(w^{t})\|}^{2}}}.
$$

![Image](OEBPS/images/B9780443190377000089/si222.png) (1.15)

This inequality is exactly in the form [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) with `ω[t] = 1`![Image](OEBPS/images/B9780443190377000089/si202.png). To guarantee convergence, we need to take `w = w^⋆`![Image](OEBPS/images/B9780443190377000089/si161_u2.png) as a solution of [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1) and assume that `∥∇F(w^(t))∥ ≤ M`![Image](OEBPS/images/B9780443190377000089/si223.png). Then, [(1.15)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq16) implies that `Δ[t] ≤ D[t] − D[t + 1] + E[t]`![Image](OEBPS/images/B9780443190377000089/si224.png). By induction, we have $\sum_{t = 0}^{T}\Delta_{t} \leqslant D_{0} - D_{T + 1} + \sum_{t = 0}^{T}E_{t} \leqslant D_{0} + \sum_{t = 0}^{T}E_{t}$![Image](OEBPS/images/B9780443190377000089/si225.png). Therefore, we obtain

$$
F(\widehat{w}) - F(w^{\star}) \leqslant \frac{1}{S_{T}}\sum\limits_{t = 0}^{T}\eta_{t}[ F(w^{t}) - F(w^{\star})] \leqslant \frac{1}{2S_{T}}{\| w^{0} - w^{\star}\|}^{2} + \frac{M^{2}}{2S_{T}}\sum\limits_{t = 0}^{T}\eta_{t}^{2},
$$

![Image](OEBPS/images/B9780443190377000089/si226.png)

where $S_{T}: = \sum_{t = 0}^{T}\eta_{t}$![Image](OEBPS/images/B9780443190377000089/si227.png) and $\widehat{w}: = \frac{1}{S_{T}}\sum_{t = 0}^{T}\eta_{t}w^{t}$![Image](OEBPS/images/B9780443190377000089/si228.png) as computed by [(1.12)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq13). To obtain a convergence rate bound, we require $\sum_{t = 0}^{\infty}\eta_{t}^{2} < + \infty$![Image](OEBPS/images/B9780443190377000089/si229.png) and $S_{T}\rightarrow S_{\infty} = \sum_{t = 0}^{\infty}\eta_{t} = \infty$![Image](OEBPS/images/B9780443190377000089/si230.png). These are exactly the conditions to guarantee the convergence of [sub]gradient methods, see, e.g., [[8]](#Chp001_3-28_B9780443190377000089_split_002.xhtml#br0040).

### (c) Gradient descent method for nonconvex problems

If we assume that `F` is only `L`-smooth and not necessarily convex, then using [(1.10)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq11) with `w := w^(t)`![Image](OEBPS/images/B9780443190377000089/si231.png) and `w' := w^(t + 1) = w^(t) − η[t]∇F(w^(t))`![Image](OEBPS/images/B9780443190377000089/si232.png), we have

$$
F(w^{t + 1}) \leqslant F(w^{t}) + \langle\nabla F(w^{t}),w^{t + 1} - w^{t}\rangle + \frac{L}{2}{\| w^{t + 1} - w^{t}\|}^{2} = F(w^{t}) - \eta_{t}\left( 1 - \frac{L\eta_{t}}{2} \right){\|\nabla F(w^{t})\|}^{2}.
$$

![Image](OEBPS/images/B9780443190377000089/si233.png) (1.16)

By adding `− F^⋆`![Image](OEBPS/images/B9780443190377000089/si234.png), where `F^⋆ := inf[w]F(w) > − ∞`![Image](OEBPS/images/B9780443190377000089/si235.png) (our assumption), to both sides and rearranging the result, inequality [(1.16)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq18) leads to

$$
\begin{array}{lcl}
{\underset{D_{t + 1}}{\underset{\text{︸}}{F(w^{t + 1}) - F^{\star}}} + \underset{\Delta_{t}}{\underset{\text{︸}}{\eta_{t}\left( 1 - \frac{L\eta_{t}}{2} \right){\|\nabla F(w^{t})\|}^{2}}}} & {\leqslant} & {\underset{D_{t}}{\underset{\text{︸}}{F(w^{t}) - F^{\star}}}.}
\end{array}
$$

![Image](OEBPS/images/B9780443190377000089/si236.png)

This is exactly in the form [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) with `ω[t] = 1`![Image](OEBPS/images/B9780443190377000089/si202.png) and `E[t] = 0`![Image](OEBPS/images/B9780443190377000089/si209.png). Without any further assumption, we have `Δ[t] ≤ D[t] − D[t + 1]`![Image](OEBPS/images/B9780443190377000089/si237.png) and, by induction, get $\sum_{t = 0}^{T}\Delta_{t} \leqslant D_{0} - D_{T + 1} \leqslant D_{0}$![Image](OEBPS/images/B9780443190377000089/si238.png), leading to

$$
\min\limits_{0 \leqslant t \leqslant T}{\|\nabla F(w^{t})\|}^{2} \leqslant \frac{1}{S_{T}}\sum\limits_{t = 0}^{T}\gamma_{t}{\|\nabla F(w^{t})\|}^{2} \leqslant \frac{F(w^{0}) - F^{\star}}{S_{T}},
$$

![Image](OEBPS/images/B9780443190377000089/si239_u1.png)

where $\gamma_{t} = \eta_{t}(1 - \frac{L\eta_{t}}{2})$![Image](OEBPS/images/B9780443190377000089/si240_u1.png) and $S_{T} = \sum_{t = 0}^{T}\gamma_{t}$![Image](OEBPS/images/B9780443190377000089/si241_u1.png), provided that $0 < \eta_{t} < \frac{2}{L}$![Image](OEBPS/images/B9780443190377000089/si242_u1.png). This result allows us to certify the best-iterate convergence rate of the algorithm to a stationary point of [(1.1)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq1).

### (d) Gradient descent method for smooth and convex problems

Assume that `F` is convex and `L`-smooth. Let us choose $\eta_{t}: = \frac{1}{L}$![Image](OEBPS/images/B9780443190377000089/si243_u1.png) in [(1.2)](#Chp001_3-28_B9780443190377000089_split_000.xhtml#deq2) to get $w^{t + 1}: = w^{t} - \frac{1}{L}\nabla F(w^{t})$![Image](OEBPS/images/B9780443190377000089/si244_u1.png). Then, from [(1.14)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq15) and [(1.16)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq18), and the convexity of `F`, we have

$$
\left\{ \begin{array}{l}
{\frac{L}{2}{\| w^{t + 1} - w^{\star}\|}^{2} + \langle\nabla F(w^{t}),w^{t} - w^{\star}\rangle = \frac{L}{2}{\| w^{t} - w^{\star}\|}^{2} + \frac{1}{2L}{\|\nabla F(w^{t})\|}^{2},} \\
{(t + 1)[ F(w^{t + 1}) - F(w^{\star})] + \frac{(t + 1)}{2L}{\|\nabla F(w^{t})\|}^{2} \leqslant (t + 1)[ F(w^{t}) - F(w^{\star})],} \\
{F(w^{t}) - F(w^{\star}) \leqslant \langle\nabla F(w^{t}),w^{t} - w^{\star}\rangle.}
\end{array} \right.
$$

![Image](OEBPS/images/B9780443190377000089/si245_u1.png)

By summing up these three inequalities and canceling terms, we obtain

$$
\frac{L}{2}{\| w^{t + 1} - w^{\star}\|}^{2} + (t + 1)[ F(w^{t + 1}) - F(w^{\star})] + \frac{t}{2L}{\|\nabla F(w^{t})\|}^{2}\quad \leqslant \frac{L}{2}{\| w^{t} - w^{\star}\|}^{2} + t[ F(w^{t}) - F(w^{\star})].
$$

![Image](OEBPS/images/B9780443190377000089/si246_u1.png)

This is exactly [(1.13)](#Chp001_3-28_B9780443190377000089_split_001.xhtml#deq14) with $D_{t}: = \frac{L}{2}{\| w^{t} - w^{\star}\|}^{2} + t[ F(w^{t}) - F(w^{\star})]$![Image](OEBPS/images/B9780443190377000089/si247_u1.png), $\Delta_{t}: = \frac{t}{2L}{\|\nabla F(w^{t})\|}^{2}$![Image](OEBPS/images/B9780443190377000089/si248_u1.png), `E[t] = 0`![Image](OEBPS/images/B9780443190377000089/si209.png), and `ω[t] = 1`![Image](OEBPS/images/B9780443190377000089/si202.png). This recursive estimate implies `D[t + 1] ≤ D[0]`![Image](OEBPS/images/B9780443190377000089/si249_u1.png), and therefore, using the definition of `D[t + 1]`![Image](OEBPS/images/B9780443190377000089/si250_u1.png) and dropping $\frac{L}{2}{\| w^{t + 1} - w^{\star}\|}^{2}$![Image](OEBPS/images/B9780443190377000089/si251_u1.png), we get

$$
F(w^{t + 1}) - F(w^{\star}) \leqslant \frac{D_{0}}{t + 1} = \frac{L{\| w^{0} - w^{\star}\|}^{2}}{2(t + 1)},
$$

![Image](OEBPS/images/B9780443190377000089/si252_u1.png)
