
其中 `φ` 是 UL 决策变量，`{θ[i], ∀i}` 表示 LL 模型参数，`f(⋅, ⋅)` 和 `G[i](⋅, ⋅)` 分别代表 UL 和 LL 损失函数，而 `{θ[i]^(*)(φ), ∀i ∈ [n]}` 代表 LL 优化变量的最优解。该模型可涵盖广泛的分层联邦学习问题，例如联邦声学语音识别 [[3]](#Chp010_181-197_B9780443190377000181.xhtml#br0015)、个性化元学习 [[4]](#Chp010_181-197_B9780443190377000181.xhtml#br0020)、强化学习中的多智能体 Actor-Critic 方案 [[15]](#Chp010_181-197_B9780443190377000181.xhtml#br0075) 等。

请注意，结构化图知识与所有本地模型相关，因此 LL 优化变量将会耦合。一个例子是公式 [(10.10)](#Chp010_181-197_B9780443190377000181.xhtml#deq12) 所示的多中心联邦学习情况，其中参与 LL 问题的第 `k` 个中心是基于所有 `θ[i]` 计算得出的。因此，[[25]](#Chp010_181-197_B9780443190377000181.xhtml#br0125) 提出了一种更广义的双层优化增强 GAFL，简称 BiG-FL，通过将 LL 优化问题表述为一个竞争博弈，如下所示：

```
(ℙ3)  min_φ  ℓ(φ) = f( φ, {θ_i^*(φ)} )
```
![Image](OEBPS/images/B9780443190377000181/si67_u12.png)(10.12a)

```
such that  θ_i^*(φ) = argmin_θ_i 𝔼_ξ∈D_i G_i( φ, θ_i, θ_{-i}^*(φ); ξ ), ∀i ∈ [n],
```
![Image](OEBPS/images/B9780443190377000181/si68_u8.png)(10.12b)

其中 `θ[−i]^*(φ)` 表示 `{θ[−i]^*(φ) | θ[j]^*(φ), j ≠ i, ∀j ∈ N[i]}`。从该模型可以看出，UL 优化问题旨在最小化全局可共享参数 `φ`，而 LL 问题用于整合 UL 知识并适应本地数据分布。下文我们将提供一种将 BiG-FL 应用于嵌入 GNN 的联邦学习系统的方法。

### 10.4.1 BiG-FL 的应用

受用于链路预测的图嵌入学习 [[7]](#Chp010_181-197_B9780443190377000181.xhtml#br0035) 启发，BiG-FL 可将 FL 客户端/设备的连通性（即全局图结构中的边信息）作为 UL 优化过程中的指导，并将该拓扑信息映射为加权邻近客户端模型的相似度。

令 `θ^*(φ) ∈ ℝ^(n×d)` 表示所有 LL 最优解的拼接。通过 GNN 中的线性消息传递构建嵌入矩阵 `H` 可得：

```
H = L θ^*(φ) φ,
```
![Image](OEBPS/images/B9780443190377000181/si72_u8.png)(10.13)

其中 `L ∈ ℝ^(n×n)` 是拉普拉斯矩阵（例如 `L ≜ D̃^(-1/2) Ã D̃^(-1/2)`，其中 `Ã = A + I` 且 `D̃_ii = Σ_j Ã_ij`，这些常用于图卷积网络 (GCN) [[8]](#Chp010_181-197_B9780443190377000181.xhtml#br0040)），`θ^*(φ)` 从本地模型中学习得到，而 `φ ∈ ℝ^(d×d)` 表示作为 GNN 中权重的 UL 参数，形状为 `d×d`。

**UL 损失函数**。利用这种基于图的表示，我们可以使用余弦嵌入损失来表述 UL 目标函数，如下所示：

```
f(φ, θ^*(φ)) ≜ (1/n) Σ_{i=1}^n Σ_{j∈N_i} (1 - cos(H_i, H_j)) + (1/n) Σ_{i=1}^n 𝔼_{j∼P_i} max(0, cos(H_i, H_j)) + (λ/2) ||φ - I||^2,
```
![Image](OEBPS/images/B9780443190377000181/si80_u7.png)(10.14)

其中 `i` 和 `j` 是节点的索引（即 FL 客户端/设备），

```
cos(H_i, H_j) ≜ (H_i^T H_j) / (||H_i|| ||H_j||),
```
![Image](OEBPS/images/B9780443190377000181/si81_u6.png)(10.15)

且 `P[i]` 表示客户端 `i` 处的负采样分布 [[7]](#Chp010_181-197_B9780443190377000181.xhtml#br0035)。

公式 [(10.14)](#Chp010_181-197_B9780443190377000181.xhtml#deq18) 中 BiG-Fed 的 UL 目标函数利用余弦嵌入损失来计算所有链接客户端的客户端对嵌入相似度以及负样本的客户端对嵌入非相似度。由于嵌入源自本地模型权重，公式 [(10.14)](#Chp010_181-197_B9780443190377000181.xhtml#deq18) 将本地学习任务与服务器端的图链路预测任务相耦合。

值得注意的是，链路预测模型学习的是本地模型之间的相对关系。此外，我们期望优化后的 UL 模型能保持整体权重分布的质心，因此我们用单位矩阵 `I` 初始化 `φ`，并在 UL 损失函数中添加了一个以单位矩阵 `I` 为基准的正则项。

**LL 损失函数**。BiG-FL 在每个设备上的本地 LL 学习任务是寻找以下问题的纳什均衡：

```
θ_i^*(φ) = argmin_θ_i g_i( φ, θ_i, θ_{-i}^*(φ) ), ∀i ∈ [n],
```
![Image](OEBPS/images/B9780443190377000181/si83_u8.png)(10.16)

其中 `g_i(φ, θ_i, θ_{-i}^*(φ)) ≜ 𝔼[ξ∼D_i] G_i(φ, θ_i, θ_{-i}^*(φ); ξ)`。在这种情况下，UL 权重 `φ` 被引入 LL 学习任务，以惩罚邻近权重聚合与本地权重之间的距离，因为我们假设邻近客户端共享相似的潜在空间。因此，对于每个客户端，损失函数 `g_i(⋅)` 同时包含监督学习误差和本地模型参数与从 UL 图知识学习到的质心之间的距离：
