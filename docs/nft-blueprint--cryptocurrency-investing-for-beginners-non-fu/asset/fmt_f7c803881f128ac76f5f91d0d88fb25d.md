
# MetaMask Wallet: Features, Setup, and Security

With MetaMask it is easily possible to store tokens, send them, and also exchange them with each other. Through swaps, MetaMask users receive the cheapest prices available on the market at the time of trading – with a relatively low transaction fee of up to `0.875%` of the trading volume. At the same time, MetaMask prides itself on offering the most secure and at the same time simplest service, so that users can easily use other blockchain-based decentralized applications (dApps) – even without previous knowledge.

Therefore, the provider describes itself as a "crypto wallet and gateway to blockchain apps": Here, users are provided with a large selection of innovative and decentralized apps. In concrete terms, this means that MetaMask is more than just a commercially available wallet. The functionality of MetaMask can therefore be roughly divided into three areas:

* Ethereum wallet for storing, sending, receiving and swapping tokens
* A means to access innovative dApps
* An app that delivers more security and anonymity

## How to Set up MetaMask Wallet?

If you already feel like using the MetaMask Wallet, you can log in within just a few minutes. In the following, we specify in three steps how to quickly and easily download and set up the wallet for all operating systems. While in the next sections we will focus more on the browser version, we will go into more detail below on the differences between the operating systems.

### Step 1: The MetaMask Download

In the first step, it makes sense to go to the [website of the provider](https://metamask.io/). Here are all possibilities to choose from how MetaMask can be used. In addition, it is of course also possible to download the apps or add-ons directly from external stores such as Google Play. For add-ons, however, it should be made absolutely sure that you really download the original versions in the respective store. For example, if you are looking for the MetaMask Firefox add-on in the browser, you can simply click on "Add-ons" in the menu bar and enter the name of the provider in the search bar. If you then decide to add MetaMask, the add-on will be downloaded.

### Step 2: MetaMask Login

After successful download, it is sufficient to accept the privacy policy and create a so-called Secret Backup Phrase. This backup phrase should be written down and stored in a safe place. This ensures that your own currencies can be restored in the event of a loss of the device or other mishaps. Therefore, this step should be done with thoroughness and really ensure that no errors occur in the order.

### Step 3: Integrate wallets and buy Ethereum

Once the phrases have been confirmed in the next step, most of the process is already complete. With the establishment of the wallet, it is now possible to purchase Ethereum or other ERC-20 coins. Of course, it is also possible to easily import an existing Ethereum wallet into the MetaMask Wallet with just a few clicks. To do this, it is sufficient to simply click "Import Wallet" and import the wallet in the following window. With the browser version of MetaMask, it is even possible to connect a hardware wallet (Ledger or Trezor). To do this, it is sufficient to click on "Connect Hardware Wallet" and then follow the instructions.

## MetaMask Features

### Compatibility

MetaMask Wallet is available across platforms for a number of browsers and operating systems. Desktop users are spoilt for choice here between browser add-ons for MetaMask Firefox, Google Chrome, Edge and Brave, while mobile users can download the MetaMask Wallet for iOS and Android. Of course, it is also possible to connect the user account with several apps and browsers, so that the account can be accessed comfortably from home or on the go and users always have a full overview.

### Mobile & Desktop Installation

As mentioned earlier, there are a variety of ways in which the MetaMask Wallet can be used. Users can choose either between a variety of browser add-ons or for the mobile versions. The installation is very easy with all versions and differs only slightly from each other. In the following, we will therefore go into more detail about the respective differences in the setup.

#### Desktop installation with MetaMask Firefox, Google Chrome, Edge and Brave

For the desktop, MetaMask is not available as a separate program, but as a browser add-on for MetaMask Chrome, MetaMask Firefox, Edge and Brave. To set up, users can simply go to the MetaMask website and then to the download area. Here you can decide between the different versions and will be redirected to the respective stores, where the add-on can be downloaded with just one click. Alternatively, it is possible to search for the add-on directly in the browser store. Here it should be made absolutely clear that it is the original wallet - therefore, the way via the provider side is the safest.

#### Mobile installation with iOS and Android

MetaMask Android and iOS have been available for some time, which means that smartphone users can now also enjoy the MetaMask wallet. To download the app, users can also go to the download area of the website. Alternatively, users can also search for the wallet here in Google Play or the Apple Store. The wallet can then be synchronized with the browser add-ons.

## MetaMask Wallet Types

### Desktop/Online Wallet

MetaMask is only available as an online wallet. There are several options here that users can choose between. The original variant consists of the browser add-ons, which are now already available for Google Chrome, Firefox, Edge and Brave. The versions may differ from each other in their functionality depending on the system. For example, the use of a hardware wallet, which we will discuss in more detail below, is only possible with the browser add-ons, but not with the mobile apps.

### Where to download MetaMask wallet?

The MetaMask Wallet can be easily downloaded from the provider's website. On the website, wallets for all browser versions and operating systems are available to users. Alternatively, it is of course also possible to download the versions directly from external stores. Our Firefox account experiences: If you search for the respective add-on in Firefox, you can click on "Add-ons" in the menu bar and enter "MetaMask" in the search bar. Users can then add the MetaMask Wallet.

## MetaMask Wallet Fees

Before we go into more detail about the fees, it is necessary to distinguish between the network and wallet fees of MetaMask in advance. The Ethereum network charges fees for the transactions that are paid in so-called "gas" units: the fees are paid in "gas", while gas is paid by ETH. It should also be noted that the exporters of the transactions must pay the fees, regardless of whether the transactions are carried out successfully or not.

The MetaMask Wallet allows users to choose gas prices from a predetermined selection. The following applies: The cheaper the prices are, the longer the respective transaction takes. Alternatively, it is even possible to set a custom transaction fee as well as a limit manually. However, for beginners who are not yet familiar with pricing, it is recommended to choose the predetermined fees. Users can then click on "Save" to start the transaction. MetaMask transaction fee is `0.3% – 0.875%` of the trading volume and is already indicated in the quotes.

## Safety

MetaMask has set up high security standards that make it one of the best hot wallets. The provider ConsenSys assures, for example, that the seed phrase, the passwords and the private keys are encrypted and stored only on the end device. Furthermore, other security features, such as fingerprints or facial recognition, have been introduced, which make unauthorized access much more difficult.
