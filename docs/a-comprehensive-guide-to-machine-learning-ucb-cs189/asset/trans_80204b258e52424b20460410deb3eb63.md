

## 第 4 章 梯度下降、牛顿法

注意，我们使用的线性化函数 $\hat{F}$ 在 $\theta$ 处的雅可比矩阵恰好是 $J(\theta^{(k)})$。这是因为当线性映射为 $J(\theta^{(k)})$ 时，$\hat{F}$ 是仿射，因此最佳线性近似就是它。

为了简洁起见，令 $J = J(\theta^{(k)})$，我们有

```
$J^T Y = J^T F(\theta^{(k)}) + J^T \Delta Y$$
$$J^T(Y - F(\theta^{(k)})) = J^T \Delta Y$$
$$\Delta\theta = (J^T J)^{-1}(Y - F(\theta^{(k)}))$$
$$(J^T J)^{-1}\Delta Y$$
```

其中 $\Delta Y := Y - F(\theta^{(k)})$。通过将此解与最小二乘法（OLS）比较，我们看到实际上是在求解：

```
$\Delta\theta = \arg \min_{\theta} ||J\theta - \Delta Y||^2$
```

由于在 $\theta^{(k)}$ 处 $\hat{F} \approx J\Delta\theta$，这意味着我们选择了权重的变化来修正函数值的当前误差，但这是基于 $F$ 的线性化计算的。考虑到 $\Delta\theta = \theta - \theta^{(k)}$，我们可以通过以下更新改进当前的猜测值 $\theta^{(k)}$：

```
$\theta^{(k+1)} = \theta^{(k)} + \Delta\theta$
$\theta^{(k+1)} = \theta^{(k)} + (J^T J)^{-1}J^T \Delta Y$
```

以下是整个流程的步骤：

- 使用某些猜测值初始化 $\theta^{(0)}$
- 重复直到收敛：
  (a) 计算关于当前迭代值的雅可比矩阵，$J = J(\theta^{(k)})$
  (b) 计算 $\Delta Y = Y - F(\theta^{(k)})$
  (c) 更新：$\theta^{(k+1)} = \theta^{(k)} + (J^T J)^{-1}\Delta Y$

注意，找到的解通常取决于初始值 $\theta^{(0)}$。一些选择包括测试目标值的变化：

```
$|\frac{\theta^{(k+1)} - \theta^{(k)}}{\theta^{(k)}}| \le$ threshold
```

或者迭代值本身的变化：

```
$max |\frac{\Delta\theta_j}{\theta^{(k)}}| \le$ threshold
```

## 4.2 梯度下降

梯度下降是一种寻找可微函数局部极小值的迭代算法。为了类比，想象你在你在浓雾弥绕的山坡下行走，浓雾阻止了你看到周围土地的高度，只能判断哪个方向最陡峭。

![](img/99defe26aebed215976e83d281581f33_68_0.png)

记得 $f$ 在 $x$ 处的梯度表示为 $\nabla f(x)$，它指向最陡上升的方向。相反，负梯度指向最陡下降的方向。因此，如果我们沿着负梯度方向迈出一小步，就会减少函数的值。

执行的更新为：

```
$$\mathbf{x}_{i+1} = \mathbf{x}_i - \alpha_i \nabla f(\mathbf{x}_i)$$
```

其中 $\alpha_i > 0$ 是步长。我们可以选择 $\alpha_i$ 为固定常数，但在许多情况下，它会在训练过程中衰减到零。

### 5.1 神经网络

神经网络是一种复合函数近似器。与我们过的其他近似器（例如多项式）不同，它们在参数上是非线性的。

（旁白）在信息处理中，有几种视角：

- 过程视角——用命令式编程语言来思考
- 函数视角——数学方程
- 电路/图视角——信息流过系统时的处理方式

我们将从电路/图视角来考虑神经网络。
考虑以下电路：

![](img/99defe26aebed215976e83d281581f33_70.png)

这些电路代表矩阵乘法，边上的权重是矩阵。假设信息流从左到右，左侧电路是 $3 \times 4$ 矩阵乘法，右侧电路是 $2 \times 4$ 矩阵乘法后跟 $3 \times 2$ 矩阵乘法。

这些电路表达能力相等吗？显然不是，因为左侧的秩最多为 2，而右侧可能为 3。然而，左侧有更多的处理层，它看起来应该更有表达能力。缺失的关键是非线性部分。

在这些线性计算后插入一个非线性函数，称为激活函数。我们希望这个激活函数使电路成为通用近似器。一个关键观察是，分段常数函数是通用近似器：

![](img/99defe26aebed215976e83d281581f33_0.png)

我们使用的非线性函数是阶跃函数：

$u(x) = \begin{cases} x & x \geq 0 \\ 0 & x < 0 \end{cases}$

![](img/99defe26aebed215976e83d281581f33.png)

我们可以通过这种简单阶跃函数的平移和缩放版本来构建复杂的函数。观察到：

- 如果 $a, b \in \mathbb{R}$，函数 $x \mapsto u(a+bz)$ 是阶跃函数的平移（且取决于 $b$ 的符号，可能经过翻转）：这本质上意味着对于任何连续函数，我们都可以选择权重使得电路的输出任意接近给定函数的输出。

5.1 神经网络

![](img/99defe26aebed215976e83d281581f33_0.png)

- 如果 $a, b \in \mathbb{R}$，函数 $x \mapsto u(a+bz)$ 是阶跃函数的平移（且取决于 $b$ 的符号，可能经过翻转）：

![](img/99defe26aebed215976e83d281581f33_1.png)

网格的输出为：

$h(x) = \sum_{i=1}^d c_i u(a_i + b_i x)$

其中 $d$ 是隐藏单元的数量，$a_i, b_i, c_i$ 是参数，$u$ 是激活函数。

## 权重选择

通过适当选择 $a_i, b_i, c_i$，该函数可以近似任何连续函数。但问题仍然是：给定某个目标函数，我们如何选择这些？

尝试一种熟悉的技术：最小二乘。假设我们有训练数据 $\{(x_k, y_k)\}_{k=1}^n$。我们的目标是求解优化问题：

```$$\min_{a,b,c} \sum_{k=1}^n (y_k - h(x_k))^2$$
```

梯度下降需要损失关于优化变量的导数。我们计算链式法则：

```
$$\frac{\partial f}{\partial c_i} = \sum_{k=1}^n -2(y_k - h(x_k))\frac{\partial h}{\partial c_i}(x_k)$$
```

我们看到，如果这一特定步骤是“关闭”的，如 $u(a_i+b_ix)=0$，则：

```
$$\frac{\partial e_i}=0$$
```

因此该示例不会进行更新。更重要的是，考虑对 $a_i$ 的导数：

```
$$\frac{\partial f}{\partial a_i} = \sum_{k=1}^n -2(y_k - h(x_k))\frac{\partial h}{\partial a_i}(x_k)$$
```

类似地：

```
$$\frac{\partial f}{\partial b_i}=0$$
```

跳跃处的导数未定义，但在实践中我们永远不会遇到那个不连续点。更大的问题是，梯度下降对优化 $a_i$ 和 $b_i$ 权重毫无作用。尽管阶跃函数对于选择神经网络的近似能力有用，但在实践中很少用，因为无法通过传统的基于梯度的方法进行训练。

下一个简单的通用近似器是分段线性函数类。正如分段常数函数可以通过阶跃函数作为非线性来实现，分段线性函数可以通过修正线性单元（ReLU）函数的组合来实现：

$$u(x) = \max(0, x)$$

现在我们可以计算梯度了：

```
$$\frac{\partial f}{\partial c_i} = \sum_{k=1}^n -2(y_k - h(x_k))\max(0, a_i+b_ix_k)$$
```
