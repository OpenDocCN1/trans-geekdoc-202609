
## 6.3 QDA CLASSIFICATION

```
$= arg \max_{\mu_k, \sigma_k^2} \sum_{i=1}^{n_k} \frac{(x_i - \mu_k)^2}{2\sigma_k^2} - \ln(\sigma_k) - \ln(2\pi)$$
$$= arg \min_{\mu_k, \sigma_k^2} \frac{(x_i - \mu_k)^2}{2\sigma_k^2} + \ln(\sigma_k)
```

Note the above objective is not convex, so we cannot simply take derivatives and set them to 0! Instead, we decompose the minimization over $\sigma_k^2$ and $\mu_k$ into a nested optimization problem:

```
$$\min_{\mu_k, \sigma_k^2} \sum_{i=1}^{n_k} \frac{(x_i - \mu_k)^2}{2\sigma_k^2} + \ln(\sigma_k) = \min_{\sigma_k^2} \sum_{i=1}^{n_k} \frac{(x_i - \mu_k)^2}{2\sigma_k^2} + \ln(\sigma_k)
```

The optimization problem has been decomposed into an inner problem for $\mu_k$ given a fixed $\sigma_k^2$, and an outer problem for $\sigma_k$ given the optimal value $\hat{\mu}_k$. Let's first solve the inner problem. Given a fixed $\sigma_k^2$, the objective is convex in $\mu_k$, so we can take a partial derivative w.r.t $\mu_k$ and set it to 0:

```
$$\frac{\partial}{\partial\mu_k} \sum_{i=1}^{n_k} \frac{(x_i - \mu_k)^2}{2\sigma_k^2} + \ln(\sigma_k) = \sum_{i=1}^{n_k} \frac{-(x_i - \mu_k)}{\sigma_k^2} = 0 \Rightarrow \hat{\mu}_k = \frac{1}{n_k} \sum x_i$$
```

Having solved the inner problem, we have

```
$$\min_{\sigma_k^2} \sum_{i=1}^{n_k} \frac{(x_i - \hat{\mu}_k)^2}{2\sigma_k^2} + \ln(\sigma_k) = \min_{\sigma_k^2} \sum_{i=1}^{n_k} \frac{(x_i - \hat{\mu}_k)^2}{2\sigma_k^2} + \ln(\sigma_k)$$
```

Note that this objective is not convex in $\sigma_k$, so we must not find the critical point of the objective matches the objective. Assuming that $\sigma_k \geq 0$, the critical points are:

- $\sigma_k = 0$: assuming that all the points $x_i$ are equal to $\hat{\mu}_k$, there are two terms that are at odds with each other: a $1/\sigma_k^2$ term that blows off to $\infty$, and a $\ln(\sigma_k)$ term that blows off to $-\infty$ as $\sigma_k \rightarrow 0$. Note that the $1/\sigma_k^2$ term blows off at a faster rate, so we could
- $\sigma_k = \infty$: this case does not lead to the solution, because it gives a maximum, not a minimum.
- Points at which the derivative w.r.t $\sigma$ is 0

```
$$\lim_{\sigma_k \rightarrow 0} \sum_{i=1}^{n_k} \frac{(x_i - \hat{\mu}_k)^2}{2\sigma_k^2} + \ln(\sigma_k) = \infty$$

$$ \frac{\partial}{\partial\sigma_k} \sum_{i=1}^{n_k} \frac{(x_i - \hat{\mu}_k)^2}{2\sigma_k^2} + \ln(\sigma_k) = \sum_{i=1}^{n_k} \frac{-(x_i - \hat{\mu}_k)^2}{\sigma_k^3} + \frac{1}{\sigma_k} = 0 \Rightarrow \sigma_k^2 = \frac{1}{n_k} \sum_{i=1}^{n_k} (x_i - \hat{\mu}_k)^2$$
```

We conclude that the optimal points is:

$$\sigma_k^2 = \frac{1}{n_k} \sum_{i=1}^{n_k} (x_i - \hat{\mu}_k)^2$$

## QDA Formulation

Assuming that we know the covariances for all the classes, we can use Bayes Rule to directly solve the optimization problem:

```
$k^* = \arg \max P(k) f_k(\mathbf{x})$$
$$= \arg \max \ln P(k) + \ln f_k(\mathbf{x})$$
$$= \arg \max \ln P(k) - \frac{1}{2}(\mathbf{x} - \mu_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \mu_k) - \frac{1}{2} \ln(|\boldsymbol{\Sigma}_k|) = Q_k(\mathbf{x})$$
```

For future reference, let’s use $Q_k(\mathbf{x}) = \ln P(k) - \frac{1}{2}(\mathbf{x} - \mu_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \mu_k) - \frac{1}{2} \ln(|\boldsymbol{\Sigma}_k|)$ to simplify our notation.

## 6.4 LDA

While QDA is a reasonable approach to classification, we might be interested in simplifying our model to reduce the number of parameters we have. One way to do this is using **Linear Discriminant Analysis (LDA)**. Just as in QDA, LDA assumes that class probability distributions are normally distributed with different $\mu_k$, but LDA differs from QDA in that it requires all distributions to share the same covariance matrix $\boldsymbol{\Sigma}$. This is a simplification that, in the context of Bias-Variance tradeoff, increases the bias of our method but decreases the variance.

The training and classification procedures for LDA are almost identical to that of QDA. However, the empirical covariance is computed with:

$$\boldsymbol{\Sigma} = \frac{1}{n} \sum_{i=1}^n (\mathbf{x}_i - \mu)(\mathbf{x}_i - \mu)^T$$

To understand this formula as a weighted average of within-class covariances, here assume we have sorted our training data by class and we can index $\mathbf{x}_i$ by class $k$:

$$\boldsymbol{\Sigma}_k = \frac{1}{n} \sum_{i=1}^{n_k} (\mathbf{x}_i - \mu_k)(\mathbf{x}_i - \mu_k)^T$$ $

## 6.5 LDA vs. QDA: Differences and Decision Boundaries

Up to this point, we have used quadratic terms in QDA and linear in LDA. These terms signify the shape of the decision boundary in x-space. Given any two classes, the decision boundary represents the points in x-space where the two classes are equally likely. Let's study binary (2-class) examples for simplicity. Assume that the two classes are A and B. An arbitrary point $x$ can be classified according to three cases:

$$k^* = \begin{cases} A & P(class=A|x) > P(class=B|x) \\ B & P(class=A|x) < P(class=B|x) \\ \text{Either A or B} & P(class=A|x) = P(class=B|x) \end{cases}$$

The decision boundary is the set of all points in x-space that are classified according to the third case. Let's look at the form of the decision boundary under different scenarios.

The simplest case is when the two classes are equally likely in prior, and their conditional probability distributions are isotropic with identical covariances. Isotropic Gaussian distributions have covariances of the form $\Sigma = \sigma^2I$, which means that their contours are circles. In this case, $f_A(x)$ and $f_B(x)$ have identical covariances of the form $\Sigma_A = \Sigma_B = \sigma^2I$.

![](img/99defe26abed215976e83d28151f33_86_0.png)

Figure 6.1: Contour plot of two isotropic, identically distributed Gaussians in $\mathbb{R}^2$. The circles are the level sets of the Gaussians.

Geometrically, we can see that the task of classifying a 2-D point into one of the two classes amounts to figuring out which of the classes it's closer to. Using our notation of $Q_k(\mathbf{x})$ from before, this can be expressed mathematically as:

$$Q_A(\mathbf{x}) = Q_B(\mathbf{x})$$

$$\ln\left(\frac{1}{2}\right)-\frac{1}{2}(\mathbf{x}-\mu_A)^T\sigma^2(\mathbf{x}-\mu_A)-\frac{1}{2}\ln\left(|\sigma^2|\right)=\ln\left(\frac{1}{2}\right)-\frac{1}{2}(\mathbf{x}-\mu_B)^T\sigma^2(\mathbf{x}-\mu_B)-\frac{1}{2}\ln\left(|\sigma^2|\right)$$
$$(\mathbf{x}-\mu_A)^T(\mathbf{x}-\mu_A)=(\mathbf{x}-\mu_B)^T(\mathbf{x}-\mu_B)$$

The decision boundary for $x$ for which $|\mathbf{x}-\mu_A||_2=|\mathbf{x}-\mu_B||_2$, is simply the set of points that are equidistant from $\mu_A$ and $\mu_B$. This decision boundary is linear because the set of points that are equidistant from $\mu_A$ and $\mu_B$ are simply the perpendicular bisector of the segment connecting $\mu_A$ and $\mu_B$.
