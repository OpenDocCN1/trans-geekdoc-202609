# Multi-Class Extension

We can also adapt this to the case where we have multiple classes. Suppose there are $K$ classes, labeled $1, 2,...,K$. One possible way to extend the approach from binary classification is to compute $w_iw(x_i)$ and round it to the nearest number from 1 to $K$. However, this approach gives an "ordering" to the classes, even if the classes themselves have no natural ordering. This is clearly a problem. For example, in fruit classification, suppose 1 is used to represent "peach", 2 is used to represent "banana", and 3 is used to represent "apple". In our numerical representation, it would appear that peaches are less than bananas, which are less than apples. As a result, if we have an image that looks like some between an apple and a peach, we might simply end classifying it as a banana.

The typical way to get around this issue is as follows: if the $i$-th observation has class $k$, instead of the representation $y_i = k$, we can use the representation $y_i = e_k$, the $k$-th canonical vector. Now there is no relative ordering in the representations of the classes. This method is called **one-hot encoding**.

When we have multiple classes, $y_i$ is a $K$-dimensional one-hot vector, so for LS-SVM, we instead have a $K \times (d+1)$ weights to optimize over:

```
$$\arg \min_{\mathbf{w}} \sum_{i=1}^n ||y_i - \mathbf{Wx}_i||^2 + \lambda|\mathbf{w}||^2$
```

To classify a data point, compute $\mathbf{Wx}$ and see which component $j$ is the largest - we then predict $x_i$ to be in class $j$.

# 6.8 Logistic Regression

**Logistic regression** is a discriminative classification technique that has a direct probabilistic interpretation. Suppose that we have the binary classification problem where classes are represented by 0 and 1. Note that instead of using $-1/+$ labels (as in LS-SVM), in logistic regression logistic regression makes more sense this way because it directly outputs a probability, which belongs in the range of values between 0 and 1.

In logistic regression, we would like to model our estimate of the probability that a data point is in 1. We can start with the linear function $\mathbf{w}^T\mathbf{x}$ and convert it to a number between 0 and 1 by applying a sigmoid transformation $s(\mathbf{x}) = \frac{1}{1+e^{-\mathbf{x}^T\mathbf{x}}}$. Thus to classify $\mathbf{x}_i$ after learning the weights $\mathbf{w}$, we would estimate the probability

```
$P(y_i=1|\mathbf{x}_i) = s(\mathbf{w}^T\mathbf{x}_i)$
```

and classify $\mathbf{x}_i$ as

+   $\hat{y}_i = \begin{cases} 1 & \text{if } s(\mathbf{w}^T\mathbf{x}_i) \geq 0.5 \ 0 & \text{otherwise} \end{cases}$
