$-\sum_{i=1}^{n} y_i

```

Note that $
abla_z s(z) = s(z)(1-s(z))$, and by the chain rule we have

```
$
abla_w p_i = 
abla_w s(w^T x_i) = s(w^T x_i)(1-s(w^T x_i))x_i = p_i(1-p_i)x_i$
```

Plugging in this gradient value, we have

```
$
abla_w L(w) = -\sum_{i=1}^{n} \left(\frac{y_i}{p_i} - \frac{1 - y_i}{1 - p_i}ight) 
abla_w p_i$$
$$=-\sum_{i=1}^{n} p_i(1-p_i)x_i$$
$$=-\sum_{i=1}^{n} (y_i(1-p_i) - (1-y_i)p_i)x_i$$
$$=-\sum_{i=1}^{n} (y_i - p_i)x_i$
```

We conclude that the gradient of the loss function with respect to the parameters is

```
$
abla_w L(w) = -\sum_{i=1}^{n} (y_i - p_i)x_i = -X^T(y-p)$
```

where $y, p \in \mathbb{R}^n$. The gradient descent updates us

```
$w = w - \epsilon 
abla_w L(w)$
```

It does not matter what values we choose for $w$, because the loss function $L(w)$ is convex and does not have local minima. Let's prove this, by first finding the Hessian of the loss function. The $k$,th entry of the Hessian is the partial derivative of the gradient with respect to $w_k$ and $w_l$.

```
$H_{kl} = \frac{\partial^2 L(w)}{\partial w_k \partial w_l}$$
$$=\frac{\partial}{\partial w_k} \sum_{i=1}^{n} (y_i - p_i)x_{il}$$n$$=-\sum_{i=1}^{n} \frac{\partial p_i}{\partial w_k}x_{il}$$n$$=-\sum_{i=1}^{n} p_i(1-p_i)x_{ik}x_{il}$
