# 4.1. NONLINEAR SQUARES

$J(\theta) = \nabla_	heta F$, the Jacobian of F

Observe that when $f$ is linear in $	heta$ ($f_i(	heta)=	heta^T x_i$), the gradient $\nabla_	heta f_{LS}$ will only have $	heta$ in place because the term $\nabla_	heta f(x_i;	heta)$ will only depend on $x_i$:

```
$\nabla_	heta f_{LS} = 2\sum_i (y_i - \theta^T x_i)\nabla_	heta(\theta^T x_i) = 2\sum_i (y_i - \theta^T x_i)x_i$
```

and it is easy to derive a closed-form solution for $	heta$ in terms of the $y_i$ and $x_i$:

```
$2X^T(Y-X\theta)=0\n2X^TY-2X^TX\theta=0\nX'Y=X'TX\theta\n\theta=(X'X)^{-1}X'Y$
```

It's just OLS!

If, however, $f$ were not linear in $\theta$, the gradient $\nabla_	heta f(x_i;theta)$ would contain more $\theta$ terms (differentiation wouldn't be enough to make them go), and it would not be possible to write out a closed-form solution for $\theta$.

**Remark:** Without more assumptions on $f$, the NLS is not convex in general. This means that the first-order optimality condition is a *necessary* but not *sufficient* condition for a local minimum. That is, it is possible that the derivative is zero for some value of $\theta$, but that value is not a local minimum. It could be a saddle point, or worse, a local maximal! Even if it is, it may not be the global minimum.

# The Gauss-Newton algorithm

Since there is no closed-form solution to the nonlinear squares optimization problem, we resort to an iterative algorithm, the **Gauss-Newton algorithm**, to tackle it. At each iteration, the method linearly approximates the function $F$ about the current iterate and solves a least-squares problem involving the linearization in order to compute the next iterate.

Let's say we have a "guess" for $\theta$ at iteration $k$, we denote $\theta^{(k)}$. We can approximate $F(\theta)$ to first order using a Taylor expansion about $\theta^{(k)}$:

```
$F(\theta^{(k)}+\Delta\theta)=F(\theta^{(k)})+\nabla_	heta F(\theta^{(k)})\Delta\theta\nF(\theta^{(k)})+J(\theta^{(k)})\Delta\theta$
```

where $\Delta\theta:=\theta-\	heta^{(k)}$.

Since $F$ is linear in $\Delta\theta$ (the Jacobian and $F$ are constants: functions evaluated at $\theta^{(k)}$), we can use the closed-form solution for $\Delta\theta$ from the optimality condition to *update* our current guess $\theta^{(k)}$. Applying the first-order optimality condition earlier to the objective F yields the following equation:

```
$0=J(\theta^{(k)})^T(Y-\theta(\theta^{(k)}))-J(\theta^{(k)})^TJ(\theta^{(k)})\Delta\theta$
```

1 For some reason this algorithm was called gradient descent, but it is not really gradient descent. Like gradient descent, it is an iterative, first-order optimization algorithm. Another method for solving nonlinear least squares, the *Levenberg-Marquardt algorithm*, is a sort of interpolation between Gauss-Newton and gradient descent.
