To simplify the argument, assume that $P$ is a Bernoulli distribution. If $P \sim \text{Bernoulli}(1)$ or $P \sim \text{Bernoulli}(0)$, there is no surprise at all because we always expect the same value every time we sample from the distribution. This is justified mathematically by the fact that entropy is minimized: $H(P)=0$. However, when $P \sim \text{Bernoulli}(0.5)$, there is a lot of uncertainty/surprise and in fact, entropy is maximized.

# 6.9 Multiclass Logistic Regression

Recall that in logistic regression, we are tuning a weight vector $w \in \mathbb{R}^{d+1}$, which leads to a posterior distribution $Q_i \sim \text{Bernoulli}(p_i)$ over the binary classes 0 and 1:

```
$P(Q_i=1) = p_i = s(w^T x_i) = \frac{1}{1+e^{-w^T x_i}}\n$$P(Q_i=0) = 1-s(w^T x_i) = \frac{e^{-w^T x_i}}{1+e^{-w^T x_i}}$
```

Let's generalize this concept to **Multiclass Logistic Regression**, where there are $K$ classes. Unlike our discussion, it is important to note that there is no inherent ordering to the classes, and predicting a class in the continuous range from 1 to $K$ would be a poor choice. Here we, recall our fruit classification example. Suppose 1 is used to represent pear, and 2 is used to represent banana, and in our numerical representation, it would appear that less than bananas, which are less than apples. As a result, if we have an image that looks like something between an apple and a pear, we may simply end classifying it as a banana.

The solution is to use a **one-hot vector encoding** to represent all of labels. If the i-th observation has class $k$, instead of using the representation $y_i=k$, we can use the representation $y_i=e_k$. In our fruit example, if the i-th image is classified as "banana", its label representation would be

```
$y_i = [0 \ 1]^T$
```

Now there is no ordering in the representations of the classes. We must modify our weight representation according to the one-hot encoder. Now, there are a set of $d+1$ weights associated with every class, which amounts to a matrix $W \in \mathbb{R}^{K \times (d+1)}$. For each input $x_i \in \mathbb{R}^{d+1}$, each class is given a "score",

```
$z_k = w_k^T x_i$
```

Where $w_k$ is the k-th row of the $W$ matrix. Now there are $K$ scores for each input $x_i:

```
$[w_1^T x_i \quad w_2^T x_i \quad \dots \quad w_K^T x_i]$
```

The higher the score for a class, the more likely logistic regression will pick that class. Now that we have a system, we transform all of these scores into a posterior probability distribution $Q$. For binary regression, we used the logistic function, which takes the value $w_k^T x_i$ and squashes it to a value between 0 and 1. The generalization to the logistic function for the multiclass case is the **softmax function**. The softmax function takes as input all $K$ scores (formally known as **logits**) and an index $j$, and outputs the probability that the corresponding softmax takes value $j:

```
$softmax(j, \{z_1, z_2, \dots, z_K\}) = \frac{e^{z_j}}{\sum_{k=1}^K e^{z_k}}$
```
