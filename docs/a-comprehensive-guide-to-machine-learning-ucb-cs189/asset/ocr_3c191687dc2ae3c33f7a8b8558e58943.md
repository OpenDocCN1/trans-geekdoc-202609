each $i = 1, \dots, n$. This set of equations can be written in matrix form as

$\begin{bmatrix} y_1 \ \ y_n \ y \end{bmatrix} \approx egin{bmatrix} \mathbf{x}_1 \ \ \mathbf{x}_n \ \mathbf{x} \end{bmatrix} egin{bmatrix} w_1 \ \ w_d \ w \end{bmatrix}$

In words, the matrix $\mathbf{X} \in \mathbb{R}^{n 	imes d}$ has the input datapoint $\mathbf{x}_i$ as its $i$-th row. This matrix is sometimes called the **design matrix**. Usually $n \ge d$, meaning that there are more datapoints than measurements.

There will be in general no exact solution to the equation $\mathbf{y} = \mathbf{Xx}$ (even if the data were perfect, consider how many equations and variables there are), but we can find an approximate solution by minimizing the sum (or equivalently, the mean) of the squared errors:

```
$L(\mathbf{w}) = \sum_{i=1}^n(\mathbf{x}_i^	op\mathbf{w} - y_i)^2 = ||\mathbf{Xx} - \mathbf{y}||_2^2$
```

Now that we have formulated an optimization problem, we want to go about solving it. We will see that the particular structure of OLS allows us to compute a closed-form expression for a globally optimal solution, which we denote $\mathbf{w}_{OLS}$.

# Approach 1: Vector calculus

Calculus is the primary mathematical workhorse for studying the optimization of differentiable functions. Recalling the following important result: if $L: \mathbb{R}^d \to \mathbb{R}$ is continuously differentiable, then any local optimum $\mathbf{w}^*$ satisfies $\nabla(\mathbf{w}^*) = \mathbf{0}$. ```
$||\mathbf{Xx} - \mathbf{y}||_2^2\n=(\mathbf{Xx} - \mathbf{y})^	op(\mathbf{Xx} - \mathbf{y})\n=(\mathbf{Xx} - \mathbf{y})^	op\mathbf{Xx} - \mathbf{y}^	op\mathbf{Xx} + \mathbf{y}^	op\mathbf{y}\n=\mathbf{w}^	op\mathbf{X}^	op\mathbf{Xx}-2\mathbf{w}^	op\mathbf{X}^	op\mathbf{y} + \mathbf{y}^	op\mathbf{y}$
