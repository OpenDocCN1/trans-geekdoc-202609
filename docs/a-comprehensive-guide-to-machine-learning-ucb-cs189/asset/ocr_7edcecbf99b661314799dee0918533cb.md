Note that the **L0-norm** of $w$ is simply the number of non-zero elements in $w$. This optimization problem minimizes the residual error between our prediction $Xw$ and $y$ ensuring that the solution $w$ is sparse. Solving this optimization problem is NP-hard, so we still intend to find a computationally feasible alternative method that can approximate the optimal solution. **Matching pursuit** is a greedy algorithm that achieves this goal.

# Matching Pursuit Algorithm

Recall that in ordinary least squares, we minimize the residual error $\|Xw - y\|_2^2$ by projecting $y$ onto the subspace spanned by the columns of $X$, obtaining a linear combination $w^*$ of the with columns. Matching pursuit starts with a completely sparse solution ($w=0$) and iteratively “build up” $w$ until the sparsity constraint $\|w\|_0 \le k$ can no longer be met. The algorithm is as follows:

```
Algorithm 2: Matching Pursuit
initialize $r = y$
initialize the weights $w = 0$
**while** $\|w\| < k$
  find the index $i$ for which the residual is minimized: $i = \arg \max_j \frac{\langle r, x_j angle}{\|x_j\|}$
  update the $i$-th entry of the weight vector to $w_i = \langle r, x_j angle / \|x_j\|^2$
  update the new residual value: $r = y - Aw$
  **end while**
```

At each step of the algorithm, we pick the coordinate $i$ such that $x_i$ (the $i$-th column of $X$ corresponding to feature $i$, *not* datap $i$) minimizes the residual $r$. This equates to finding the index $i$ for which the length of the projection onto $x_i$ is maximized:

> $i = \arg \max_j \frac{\langle r, x_j \rangle}{\|x_j\|}$

Let's see why this is true. When we project the residual $r$ on the vector $x_j$, the resulting projection has length $\langle r, x_j angle / \|x_j\|$. The length follows from pythagoras theorem:

> $|r_{old}\|^2 = \|r_{new}\|^2 + \left(\frac{\langle r, x_j \rangle}{\|x_j\|}ight)^2 \implies i = \arg \max_j \frac{\langle r, x_j \rangle}{\|x_j\|}$

We move $w_i$ to the optimum projection value and repeat greedily at each iteration. While matching pursuit is not guaranteed to find the optimal $w^*$, in practice it works well for most applications. Setting the number of iterations is typically determined through cross-validation.
