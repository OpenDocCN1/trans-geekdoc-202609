LDA is an indirect approach to classification - it estimates parameters for $P(X|Y)$ and use Bayes' rule to compute a decision boundary, which leads to the discrepancy between the number of parameters required to specify the model and the number of parameters required to perform classification. This leads us to the concept of discriminative models, where we bypass learning a generative model altogether and directly learn a decision boundary for the purpose of classification. The process of constructing a discriminative model is composed of two key design choices:

+   1) Representation: how we represent the output of the model (for example, the output of a model could be any real-valued number that we threshold to perform classification, or the output could represent a probability)

+   2) Loss function: how we train and penalize errors

# 6.7 Least Squares Support Vector Machine

# Model and Training

As first example of a discriminative model, we discuss the Least Squares Support Vector Machine (LS-VM). Consider the binary classification problem where the classes are represented by $-1$ and $+1$. One way to classify a data point $x$ is to estimate parameters $w$, compute $w^T\mathbf{x}$, and classify $x$ by sign($w^T\mathbf{x}$). Geometrically, the decision boundary here is a hyperplane, $w^T\mathbf{x}=0$.

We need to figure out how to optimize the parameter $w$. One simple procedure we try is to fit a least squares objective:

```
$$\arg min_{w} \sum_{i=1}^{n} ||y_i - w^T\mathbf{x}_i||^2 + \lambda|\mathbf{w}||^2$
```

Where $\mathbf{x}_i, w \in \mathbb{R}^{d+1}$. Note that we have not forgotten the bias term! Even though we are dealing with $d$ dimensional data, $\mathbf{x}_i$ and $w$ are $d+1$ dimensional: we add an extra "feature" of 1 to $\mathbf{x}$, and a corresponding bias term of $k$ in $w$. In practice, we do not want to penalize the bias term in the regularization term, because we should be able to work with any affine transformation of the data and end up with the same decision boundary. Therefore, rather than taking the norm of $w$, we often take the norm of $w'$, which is every term of $w$ excluding the bias term. For simplicity of notation, this would be equivalent to minimizing the number of misclassified training points. Unfortunately, optimizing this is NP-hard (computationally intractable). However, we can solve a relaxed version of this problem:

```
$$\arg min_{w} \sum_{i=1}^{n} ||y_i - w^T\mathbf{x}_i||^2 + \lambda|\mathbf{w}||^2$
```

This method is the 2-class least squares support vector machine (LS-VM). Note that in this relaxed version, we care about the magnitude of $w^T\mathbf{x}_i$ and not just the sign.
