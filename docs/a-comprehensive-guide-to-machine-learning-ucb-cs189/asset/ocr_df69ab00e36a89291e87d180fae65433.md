# Finding multiple principal components

We have seen how to derive the first principal component, which maximizes the variance of the projected data. But usually we will need more than one direction, since one direction is unlikely to capture the data well. The best idea here is to subtract the contributions of the previously computed principal components, and then apply the same rule as before to what remains. $u_{(1)},\dots,u_{(k-1)}$ denote the principal components already computed, this subtracting off is accomplished by

```
$$\hat{X} = X - \sum_{j=1}^{k-1} X_j u_{(j)}^	op = X(I - \sum_{j=1}^{k-1} u_{(j)}u_{(j)}^	op)$
```

This expression should be expressed as applying the same transformation to each row of the data$^2$:

```
$$\hat{x}_i = (I - \sum_{j=1}^{k-1} u_{(j)}u_{(j)}^	op)x_i = x_i - \sum_{j=1}^{k-1} u_{(j)}u_{(j)}^	op x_i$
```

The vector $\hat{x}_i$ should be recognized as the orthogonal projection of $x_i$ onto the subspace spanned by $u_{(j)}$. Here $\hat{x}_i$ is what's left when you start with $x_i$ and remove all the components that belong to the subspaces spanned by $u_{(j)}$^3$

We want to find the direction of largest variance subject to the constraint that it must be orthogonal to all the previously computed directions. We have a constrained problem of the form

```
$u_{(k)} = \arg\max_{\forall j < k, u'^	op u_{(j)}=0} \frac{u'^	op X u'}{u'^	op u'}$
```

But we don't want to compute $\hat{X}$. Fortunately, we have not to! Consider that if $u$ is orthogonal to $u_{(1)},\dots,u_{(k-1)}$ (as we constrain it), then

```
$$\hat{X}u = (X - \sum_{j=1}^{k-1} X_j u_{(j)}^	op)u = Xu - \sum_{j=1}^{k-1} X_j u_{(j)}^	op u = Xu$
```

Thus we can write the optimization problem above as

```
$u_{(k)} = \arg\max_{\forall j < k, u'^	op u_{(j)}=0} \frac{u'^	op X u'}{u'^	op u}$
```

eliminating the need to compute $\hat{X}$. Unsurprisingly, the solution to this problem is given by $u_{(k)}=v_k$, that is, a unit eigenvector corresponding to the $k$th largest eigenvalue of $X^	op X$.\nRather than iteratively computing each $u_{(j)}$, we can view the problem of finding the first $k$ principal components as a joint optimization over all $k$ directions simultaneously. This amounts to maximizing the variance projected onto a $k$-dimensional subspace

```
$$\U = \arg\max_{U^	op U=I} \sum_{j=1}^k u_{(j)}^	op X^	op X u_{(j)} = \arg\max tr(U^	op X^	op U)$
```
