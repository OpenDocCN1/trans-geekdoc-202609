## Other derivations of PCA

We have given the most common derivation of PCA above, but it turns out that there are other equivalent ways to arrive at the same formulation. These give us helpful additional perspectives on what PCA is doing.

## Gaussian assumption

Let us assume that the data are generated by a multivariate Gaussian distribution:

```
$x_i \overset{iid}{\sim} \mathcal{N}(\mu, \Sigma)$
```

Then the maximum likelihood estimate of the covariance matrix $\Sigma$ is

```
$\hat{\Sigma} = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})(x_i - \bar{x})^T = \frac{1}{n} X^T X$
```

where $\bar{x}$ is the sample average and the matrix $X$ is assumed to be zero-mean as before. The eigenvectors of $\hat{\Sigma}$ and $X^T X$ are the same since they are scalar multiples of each other. The contours of the Gaussian density form are ellipsoids (see Figure 1). The direction of largest variance (i.e. the first principal component) is the eigenvector corresponding to the smallest eigenvalue of $\Sigma^{-1}$, which is the largest eigenvalue of $\Sigma$. We do not know $\Sigma$ in general, so we use $\hat{\Sigma}$ in its place. Thus the principal component is an eigenvector corresponding to the largest eigenvalue of $\Sigma$. As mentioned earlier, this matrix has the same eigenvalues and eigenvectors as $X^T X$, so we arrive at the same solution.

## Minimizing reconstruction error

Ordinary least squares minimizes the vertical distance between the fitted line and the data points:

```
$||y - Xu||^2$
```

We show that PCA can be interpreted as minimizing the perpendicular distance between the principal component subspace and the data points, in this sense it is doing the same thing as total least squares.

The orthogonal projection of a vector $x$ onto the subspace spanned by a unit vector $u$ equals $u$ scaled by the scalar projection of $x$ onto $u$:

```
$P_u x = (uu^T)x = (u^T x)u$
```

Suppose we want to minimize the total reconstruction error:

```
$\epsilon_{PCA\_Err}(u) = \sum_{i=1}^n ||x_i - P_u x_i||^2\n= \sum_{i=1}^n (||x_i||^2 - ||P_u x_i||^2)\n= \sum_{i=1}^n ||x_i||^2 - \sum_{i=1}^n ||(x_i^T)u||^2 \quad (*)$
```

## 3.3. CANONICAL CORRELATION ANALYSIS

```
$= \sum_{i=1}^{n} ||x_i||^2 - \sum_{i=1}^{n} (x_i^T u)^2 = \epsilon_{PCA,Var(u)}$
```

where (*) holds by the Pythagorean theorem

```
$||x - P_u x||^2 + ||P_u x||^2 = ||x||^2$
```

since $x - P_u x \perp P_u x$. Then the first term $\sum_i ||x_i||$ is constant with respect to $u$, we have
$\arg min_u \epsilon_{PCA,Var(u)} = \arg min \text{ constant} - \epsilon_{PCA,Var(u)}$

Hence minimizing reconstruction error is equivalent to maximizing projected variance.

## 3.3 Canonical Correlation Analysis

The Pearson Correlation $\rho(X,Y)$ is a way to measure how linearly related (in other words, how a linear model captures the relationship between random variables $X$ and $Y$.

```
$$\rho(X,Y) = \frac{Cov(X,Y)}{\sqrt{Var(X)Var(Y)}}$$
```

Here are some important facts about:

- It is always commutative: $\rho(X,Y) = \rho(Y,X)$
- It is always between -1 and 1: $-1 \leq \rho(X,Y) \leq 1$
- It is completely invariant to affine transformations: for any $a,b,c,d \in \mathbb{R}$,
$\rho(aX+b, cY+d) = \frac{Cov(aX+b, cY+d)}{\sqrt{Var(aX+b)Var(cY+d)}}$
$= \frac{Cov(aX,cY)}{\sqrt{Var(aX)Var(cY)}}$
$= \frac{a \cdot c \cdot Cov(X,Y)}{\sqrt{a^2 Var(X) \cdot c^2 Var(Y)}}$
$= \frac{Cov(X,Y)}{\sqrt{Var(X)Var(Y)}}$
$= \rho(X,Y)$

The correlation is defined in terms of random variables rather than observed data. Assume that $\mathbf{x,y} \in \mathbb{R}^n$ are vectors containing $n$ independent observations of $X$ and $Y$. Recall the law of large numbers, which states that for i.i.d. $X$ with mean $\mu$,

```
$$\sum_{i=1}^n X_i \xrightarrow{a.s.} n\mu \text{ as } n \to \infty$$
```

We can use this to justify a sample-based approximation to the mean:

```
$Cov(X,Y) = \mathbb{E}[(X-\mathbb{E}[X])(Y-\mathbb{E}[Y])] \approx \frac{1}{n} \sum_{i=1}^n (x_i-\bar{x})(y_i-\bar{y})$
```

where the bar indicates the sample average, $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$. Then as a special case we have

```
$Var(X) = \text{Cov}(X, X) = E[(X - E[X])^2] \approx \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$
```

```
$Var(Y) = \text{Cov}(Y, Y) = E[(Y - E[Y])^2] \approx \frac{1}{n}\sum_{i=1}^{n}(y_i - \bar{y})^2$
```

Plugging these estimates into the definition for correlation and canceling the factor of 1/n leads to the sample Correlation Coefficient $\hat{\rho}$:

```
$$\hat{\rho}(x, y) = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{n}(y_i - \bar{y})^2}} \text{where } \hat{x} = x - \bar{x}, \hat{y} = y - \bar{y}$$
```

Here are 2-scatter plots and their corresponding correlation coefficients: ![](img/9926aed15976e8d2815f33.png)

You should notice that:

- The magnitude of $\hat{\rho}$ increases as $X$ and $Y$ become more linearly correlated.
- The sign of $\hat{\rho}$ tells whether $X$ and $Y$ have a positive or negative relationship.
- The correlation coefficient is undefined if either $X$ or $Y$ has 0 variance (horizontal line).

## Correlation and Gaussian

## Canonical Correlation

**Canonical Correlation Analysis (CCA)** is a method of modeling the relationship between two sets by maximizing the correlation coefficient. Formally, given zero-mean random vectors $X_{rv} \in \mathbb{R}^p$ and $Y_{rv} \in \mathbb{R}^q$, we want to find projections $u \in \mathbb{R}^p$ and $v \in \mathbb{R}^q$ that maximizes the correlation between $X_{rv}^T u$ and $Y_{rv}^T v$:

```
$$\rho(X_{rv}^T u, Y_{rv}^T v) = \max_{u,v} \frac{Cov(X_{rv}^T u, Y_{rv}^T v)}{\sqrt{Var(X_{rv}^T u) Var(Y_{rv}^T v)}}$$
```

Observe that

```
$$\Cov(X_{rv}^T u, Y_{rv}^T v) = \mathbb{E}[(X_{rv}^T u - \mathbb{E}[X_{rv}^T u])(Y_{rv}^T v - \mathbb{E}[Y_{rv}^T v])]\n= u^T(X_{rv} - \mathbb{E}[X_{rv}])(Y_{rv} - \mathbb{E}[Y_{rv}])^T v\n= u^T Cov(X_{rv}, Y_{rv}) v$$
```

which also implies ($Var(Z) = Cov(Z, Z)$ for any random variable $Z$) that

```
$Var(X_{rv}^T u) = u^T Cov(X_{rv}, X_{rv}) u$
$Var(Y_{rv}^T v) = v^T Cov(Y_{rv}, Y_{rv}) v$
```

so the correlation writes

```
$$\rho(X_{rv}^T u, Y_{rv}^T v) = \frac{u^T Cov(X_{rv}, Y_{rv}) v}{\sqrt{u^T Cov(X_{rv}, X_{rv}) u \cdot v^T Cov(Y_{rv}, Y_{rv}) v}}$$
```

Unfortunately, we do not have access to the true distributions of $X_{rv}$ and $Y_{rv}$, so we cannot compute these covariance matrices. We estimate them from data. Assume that we are given zero-mean data $X \in \mathbb{R}^{nx}$ and $Y \in \mathbb{R}^{nq}$, where the rows of the matrix $X$ are i.i.d. samples $x_i \in \mathbb{R}^p$ from the random variable $X_{rv}$, and correspondingly for $Y_{rv}$.

```
$$\Cov(X_{rv}, Y_{rv}) = \mathbb{E}[(X_{rv} - \mathbb{E}[X_{rv}])(Y_{rv} - \mathbb{E}[Y_{rv}])^T] \approx \frac{1}{n} \sum_{i=1}^n x_i y_i^T = \frac{1}{n} X^T Y$$
```

where again the sample-based approximation is justified by the law of large numbers. Similarly,

```
$$\Cov(X_{rv}, X_{rv}) = \mathbb{E}[X_{rv}X_{rv}^T] \approx \frac{1}{n} \sum_{i=1}^n x_i x_i^T = \frac{1}{n} X^T X$$
$$\Cov(Y_{rv}, Y_{rv}) = \mathbb{E}[Y_{rv}Y_{rv}^T] \approx \frac{1}{n} \sum_{i=1}^n y_i y_i^T = \frac{1}{n} Y^T Y$$
```
