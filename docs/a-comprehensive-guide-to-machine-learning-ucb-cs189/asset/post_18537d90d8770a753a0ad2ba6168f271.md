
## 7.1. DUALITY

This solution comes at a cost - in an effort to remove the equality constraints, we had to add dual variables, for each inequality constraint. With this in mind, let's try to do the same for the inequality constraints. Adding dual $\lambda_i$ to represent each inequality constraint, we now have

```
$\min_{x} \mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m} \lambda_i f_i(x) + \sum_{j=1}^{n} \nu_j h_j(x)$
\text{s.t.} \quad \lambda_i \ge 0 \quad i=1, \dots, m \quad (7.4)$
```

For convenience, we can place the constraints involving $\lambda$ into the optimization variable.

```
$\max_{x} \mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m} \lambda_i f_i(x) + \sum_{j=1}^{n} \nu_j h_j(x)$
```

This optimization problem is otherwise known as the **primal** (not to be confused with the dual variables), and its optimal value is indeed equivalent to that of the original constrained optimization problem.

```
$p^* = \max_{\lambda\ge0, \nu} \mathcal{L}(x, \lambda, \nu)$
```

We can verify that this is indeed the case:

- For any $x$ that violates the inequality constraints (meaning $\exists i \in [1, m]$ $f_i(x) > 0$), the inner maximization problem over $\lambda$ can choose $\lambda$ as $\infty$ to cause the inner maximization blow off to $\infty$, therefore ignored by the outer minimization over $x$
- For any $x$ that violates the equality constraints (meaning $\exists j$ s.t. $h_j(x) \neq 0$), the inner maximization problem over $\nu$ can choose $\nu$ as $\infty$ if $h_j(x) > 0$ (or if $h_j(x) < 0$) to cause the inner maximization blow off to $\infty$, therefore ignored by the outer minimization over $x$
- For any $x$ that does not violate any of the equality constraints, in the inner maximization problem over $\nu$, the expression $\sum_{j=1}^{n} \nu_j h_j(x)$ can be at maximum at 0, because $\lambda_i$ is constrained to be non-negative, and $f_i(x)$ is non-positive. Therefore, at best, the maximization problem sets $\lambda_i f_i(x) = 0$, and

```
$\max_{\lambda} \mathcal{L}(x, \lambda, \nu) = f_0(x)$
```

In full form, the objective $\mathcal{L}(x, \lambda, \nu)$ is called the **Lagrangian**, and it takes into account the unconstrained set of primal variables $x \in \mathbb{R}^d$, the constrained set of dual variables $\lambda \in \mathbb{R}^m$ corresponding to the inequality constraints, and the unconstrained set of dual variables $\nu \in \mathbb{R}^m$ corresponding to the equality constraints. Note that our dual variables $\lambda_i$ are in fact constrained, so ultimately we were not able to turn the original optimization problem into an unconstrained one, but ours are much simpler than before.

The **dual** of this optimization problem is still over the same optimization objective, except we now swap the maximization of the dual variables and the minimization of the primal variables.

```
$d^* = \max_{\lambda\ge0, x} \mathcal{L}(x, \lambda, \nu) = \max_{\lambda\ge0, \nu} g(\lambda, \nu)$
```

The dual is effectively a maximization problem (over the dual variables):

```
$max_{\lambda\ge0} g(\lambda, \nu)$
```

## CHAPTER 7. DUALITY, NEAREST NEIGHBORS, SPARSITY

where

$g(\lambda, u) = \min_x \mathcal{L}(x, \lambda, u)$

The dual is very useful to work with, because now the inner optimization problem over $x$ is an unconstrained problem!

### Strong Duality and KKT Conditions

It is *always* true that the solution to the primal problem is at least as large as the solution to the dual problem:

$p^* \geq d^*$ (7.5)

This condition is known as **weak duality**.

Proof. We know that

$\forall x, \lambda \geq 0, u \quad \max_{\lambda \geq 0} \mathcal{L}(x, \lambda, \tilde{u}) \geq \mathcal{L}(x, \lambda, u) \geq \min_{\tilde{x}} \mathcal{L}(\tilde{x}, \lambda, u)$

More compactly,

$\forall x, \lambda \geq 0, u \quad \max_{\lambda \geq 0} \mathcal{L}(x, \lambda, \tilde{u}) \geq \min_{\tilde{x}} \mathcal{L}(\tilde{x}, \lambda, u)$

Since this is true for all $x, \lambda \geq 0, u$ is true when we set

$x = \arg \min_{\tilde{x}} \max_{\lambda \geq 0} \mathcal{L}(\tilde{x}, \lambda, \tilde{u})$

and

$\lambda, u = \arg \max_{\tilde{x}} \max_{\lambda \geq 0} \mathcal{L}(\tilde{x}, \lambda, \tilde{u})$

We therefore know that

$p^* = \min_{\tilde{x} \geq 0} \mathcal{L}(\tilde{x}, \lambda, \tilde{u}) \geq \max_{\lambda \geq 0} \mathcal{L}(x, \lambda, u) = d^*$

The difference $p^* - d^*$ is known as the duality gap. In the case of **strong duality**, the duality gap is 0. That is, we can swap the order of the minimization and maximization and up with the optimal value:

$p^* = d^*$ (7.6)

There are several theoretical details proving the existence of strong duality, such as **Slater's theorem**, which states that if the primal problem is convex, and there exists an $x$ that *strictly* meet the inequality constraints and meet the equality constraints, then strong duality holds. Given the **Karush-Kuhn-Tucker (KKT) conditions** can help us find the solutions to the dual variables of the optimization problem. The KKT conditions are composed of:

- 1. Primal feasibility (inequalities) $f_i(x) \leq 0, \forall i \in [1, m]$
- 2. Primal feasibility (equations) $h_j(x) = 0, \forall j \in [1, n]$

### 3. Dual feasibility

$\lambda_i \ge 0, \forall i \in [1, m]$

### 4. Complementary Slackness

$\lambda_i f_i(x) = 0, \forall i \in [1, m]$

### 5. Stationarity

$\nabla_x f_0(x) + \sum_{i=1}^m \lambda_i \nabla_x f_i(x) + \sum_{j=1}^n \nu_j \nabla_x h_j(x) = 0$

The KKT conditions relate to strong duality:

**Theorem.** If $x, \lambda, \nu$ satisfy the KKT conditions, then $p^* = d^*$.

Proof. From the stationarity, primal feasibility, dual feasibility, and the complementary slackness $\lambda_i f_i(x) = 0$, we have:

$f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^n \nu_j h_j(x) = f_0(x) + 0 + 0 = f_0(x)$

Since $x$ is the optimal value for the primal and $\lambda, \nu$ are optimal for the dual, $p^* = d^*$.
