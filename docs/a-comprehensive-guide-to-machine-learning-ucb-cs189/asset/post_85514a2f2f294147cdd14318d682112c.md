### Cross-validation

Setting aside a validation set works well, but comes at a cost, since we cannot use the validation data for training. Since having more data generally improves the quality of the trained model, we may prefer not to let that data go to waste, especially if we have little data to begin with and/or collecting more data is expensive. Cross-validation is an alternative to having a dedicated validation set.

$k$-fold cross-validation works as follows:

1. Shuffle the data and partition it into $k$ equally-sized (or as equal as possible) blocks.
2. For $i = 1, \dots, k$,
    * Train the model on all the data except block $i$.
    * Evaluate the model (i.e. compute the validation error) using block $i$.

| 1 | 2 | 3 | 4 | 5 | 6 | ... | $k$ |
|---|---|---|---|---|---|---|---|
| validate | train | | | | | | |
| train validate | | train | | | | | |
| | train validate | | train | | | | |
| | | | | | | | |

3. Average the $k$ validation errors; this is our final estimate of the true error.

Note that this process (except for the shuffling and partitioning) must be repeated for every hyperparameter configuration we wish to test. This is the principle drawback of $k$-fold cross-validation as compared to using a held-out validation set - there is roughly $k$ times as much computation required. This is not a big deal for the relatively small linear models we've seen so far, but it can be prohibitively expensive when the model takes a long time to train, as is the case in the Big Data regime or when using neural networks.

## Kernel Ridge Regression

In ridge regression, we give a vector $\mathbf{y} \in \mathbb{R}^n$ and a matrix $\mathbf{X} \in \mathbb{R}^{n \times l}$, where $n$ is the number of training points and $l$ is the dimension of the raw data points. In most settings we don't want to work with the raw feature space, so we augment features to the data points and replace $\mathbf{X}$ with $\mathbf{\Phi} \in \mathbb{R}^{n \times d}$, where $\phi_i = \phi(\mathbf{x}_i) \in \mathbb{R}^d$. Then we solve a well-defined optimization problem that involves $\mathbf{\Phi}$ and $y$, where the parameters $\mathbf{w} \in \mathbb{R}^d$.

The problem that arises here if we use polynomial features of degree $p$ in the raw $l$ dimensional space is that there are $d = \binom{l+p}{p}$ terms we need to optimize, which can be very large (much larger than the number of training points $n$). Wouldn't it be better instead of solving an optimization problem over $d$ variables solve an equivalent problem over (potentially smaller) $n$ variables and achieve a computational runtime independent of the number of augmented features? It turns out, a concept of kernels called the kernel trick will allow us to achieve this goal. Consider the solution to ridge regression:

$\mathbf{w} = (\mathbf{\Phi}^T\mathbf{\Phi} + \lambda\mathbf{I})^{-1}\mathbf{\Phi}^T\mathbf{y}$

This operation involves calculating $\mathbf{\Phi}^T\mathbf{\Phi}$, which is a $d \times d$ matrix and takes $O(d^2)$ time to compute. The matrix inversion takes an additional $O(d^3)$ time to compute. What we really like is to have an $n \times n$ matrix that takes $O(n^3)$ to invert: if we flip the order of $\mathbf{\Phi}$ and $\mathbf{\Phi}$, we end up with an $n \times n$ matrix $\mathbf{\Phi}^T\mathbf{\Phi}$. In fact $\mathbf{\Phi}^T\mathbf{\Phi}$ has an intuitive meaning: it is the matrix of inner products between all datapoints, which measures the 'similarity' of the datapoints and captures their representation. Now let's see if we could somehow express the solution to ridge regression using the matrix $\mathbf{\Phi}^T$.

For simplicity of notation, let's revert back to using $\mathbf{X}$ instead of $\mathbf{\Phi}$ (pretend we are only working with raw features, our analysis of kernel regression still holds). Rearranging the terms of the original regression solution we have:

$\mathbf{w} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}$
$(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\mathbf{w} = \mathbf{X}^T\mathbf{y}$
$\mathbf{X}^T\mathbf{X} + \lambda\mathbf{w} = \mathbf{X}^T\mathbf{y}$
$\mathbf{w} = \frac{1}{\lambda}(\mathbf{X}^T\mathbf{y} - \mathbf{X}^T\mathbf{X})$

which says that whatever $\mathbf{w}$ is, it is some linear combination of the training points $\mathbf{x}_i$ (because anything of the form $\mathbf{X}^T\mathbf{v}$ is a linear combination of the columns of $\mathbf{X}^T$, which are the training points). To find $\mathbf{w}$ it suffices to find $\mathbf{v}$, where $\mathbf{w} = \mathbf{X}^T\mathbf{v}$. Recall that the relationship we have to satisfy is $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{w} = \mathbf{X}^T\mathbf{y}$. Let's assume that we have $\mathbf{v}$, and substitute $\mathbf{v}$ in $\mathbf{w}$ for all the $\mathbf{w}$:

$\mathbf{X}^T(\mathbf{X}\mathbf{v}) + \lambda(\mathbf{X}^T\mathbf{v}) = \mathbf{X}^T\mathbf{y}$

$\mathbf{X}^T\mathbf{v} + \mathbf{X}^T(\lambda v) = \mathbf{X}^T\mathbf{y}$
$\mathbf{X}^T(\mathbf{X}\mathbf{v} + \lambda v) = \mathbf{X}^T\mathbf{y}$

We can't isolate $v$ and have a closed-form solution for it, but we *can* make the observation if we found an $v$ such that we had

$\mathbf{X}^T\mathbf{v} + \lambda v = u$

would *imply* that this $v$ also satisfies the above equation. Note that we did not *cancel* the $\mathbf{X}^T$s on both sides of the equation. We saw that having $v$ satisfy one equation implied that it satisfied the other as well. So, indeed, we can isolate $v$ in this new equation:

$\mathbf{X}^T(\mathbf{X} + \lambda I)\mathbf{v} = u \implies \mathbf{v}^* = (\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}u$

and have that the $V$ which satisfies this equation will be $\mathbf{X}^T\mathbf{v}$ equals $u$. We conclude that the optimal $\mathbf{w}$ is

$\mathbf{w}^* = \mathbf{X}^T\mathbf{v}^* = \mathbf{X}^T(\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}u$

Recall that we previously derived ridge regression and ended up with

$\mathbf{w}^* = (\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}\mathbf{X}^T\mathbf{y}$

In fact, these are two equivalent expressions! The question that arises is which expression should you pick? Which is more *efficient* to calculate? We will answer this question after we introduce kernels.

### Linear Algebra Derivation

The previous derivation involved using some intuitive manipulations to achieve the desired result. Let's formalize our derivation using more principled arguments from linear algebra and optimization (FTLA): Before we do, we must first introduce the **Fundamental Theorem of Linear Algebra** That a matrix (linear map) $X$ maps $\mathbb{R}^d$ to $\mathbb{R}^n$. $\mathcal{N}(\mathbf{X})$ is the nullspace of $\mathbf{X}$, and $\mathcal{R}(\mathbf{X})$ is the range of $\mathbf{X}$. Then the following properties hold:

1. $\mathcal{N}(\mathbf{X}) \perp \mathcal{R}(\mathbf{X}^T) = \mathbb{R}^d$ and $\mathcal{N}(\mathbf{X}^T) \perp \mathcal{R}(\mathbf{X}) = \mathbb{R}^n$
2. $\mathcal{R}(\mathbf{X}) \oplus \mathcal{N}(\mathbf{X}^T) = \mathbb{R}^n$
3. $\mathbb{R}^d = \mathcal{R}(\mathbf{X}^T) \oplus \mathcal{N}(\mathbf{X})$

The symbol $\perp$ indicates that taking a direct sum of $\mathcal{N}(\mathbf{X})$ and $\mathcal{R}(\mathbf{X}^T)$, means that for $u \in \mathbb{R}^d$ there exist unique elements $u_1 \in \mathcal{N}(\mathbf{X})$ and $u_2 \in \mathcal{R}(\mathbf{X}^T)$ such that $u = u_1 + u_2$. Furthermore, $\mathcal{N}(\mathbf{X})$ and $\mathcal{R}(\mathbf{X}^T)$ are orthogonal subspaces.

Here is where FTLA comes in the context of ridge regression. We can express any $\mathbf{w} \in \mathbb{R}^d$ as a unique combination $\mathbf{w} = \mathbf{w}_1 + \mathbf{w}_2$, where $\mathbf{w}_1 \in \mathcal{R}(\mathbf{X}^T)$ and $\mathbf{w}_2 \in \mathcal{N}(\mathbf{X})$. We can express this as $\mathbf{w} = \mathbf{X}^T\mathbf{v} + \mathbf{r}$, where $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathcal{N}(\mathbf{X})$. Instead, of optimizing over $\mathbf{w} \in \mathbb{R}^d$, we can optimize over $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathbb{R}^l$, which equates to optimizing over $n+l$ variables. However, as we see, the optimization over will be trivial since we just have to optimize an $n$ dimensional problem

We know that $\mathbf{w}^* = \mathbf{X}^T\mathbf{v}^* + \mathbf{r}$, where $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathcal{N}(\mathbf{X})$.
