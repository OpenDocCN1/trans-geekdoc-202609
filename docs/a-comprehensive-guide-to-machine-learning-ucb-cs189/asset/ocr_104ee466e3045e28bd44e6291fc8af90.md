where $U \in \mathbb{R}^{n \times n}$, $\Sigma \in \mathbb{R}^{n \times d}$, $V \in \mathbb{R}^{d \times d}$. In the context of OLS, we must have that $\mathbf{X}^	op\mathbf{X}$ is invertible, or equivalently, $\text{rank}(\mathbf{X}^	op\mathbf{X}) = \text{rank}(\mathbf{X}^	op) = \text{rank}(\mathbf{X}) = d$. Assuming that $\mathbf{X}$ and $\mathbf{X}^	op$ are full column rank $d$, we can express the SVD of $\mathbf{X}$ as

X = \begin{bmatrix}\Sigma_d \ 0\end{bmatrix}V^	op$

where $\Sigma_d \in \mathbb{R}^{d \times d}$ is a diagonal matrix with strictly positive entries. Now let's try to expand the $(\mathbf{X}^	op\mathbf{X})^{-1}$ term in terms of SVD of:

```
$(\mathbf{X}^	op\mathbf{X})^{-1} = (V \begin{bmatrix}\Sigma_d & 0\end{bmatrix} U^	op U \begin{bmatrix}\Sigma_d^	op \ 0\end{bmatrix} V^	op)^{-1}$
$= (V\Sigma_d^2 V^	op)^{-1}$\n$= (V^	op)^{-1}(\Sigma_d^2)^{-1}V^{-1} = V\Sigma_d^{-2}V^	op$
```

This means that $(\mathbf{X}^	op\mathbf{X})^{-1}$ will have singular values that are the squared of the singular values of **X**, potentially leading to extremely large singular values when the singular value of **X** is close to 0. Such excessively large singular values can be problematic for numerical stability purposes. In addition, high values to the optimal **w** solution would prevent OLS from becoming too large and generalizing to unseen data.

There is a very simple solution to these issues: penalize the entries of **w** from becoming too large. We can do this by adding a penalty term constraining the norm of **w**. For a fixed, small scale $\lambda > 0$, we have:

```
$\min_{\mathbf{w}} ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2 + \lambda|\mathbf{w}||_2^2$
```

Note that the $\lambda$ in our objective function is a hyperparameter that measures the sensitivity to the values in **w**. Just like the degree in polynomial features, $\lambda$ is a value that we must choose arbitrarily through validation. Let's expand the terms of the objective function:

```
$f(\mathbf{w}) = ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2 + \lambda|\mathbf{w}||_2^2$\n$= \mathbf{w}^	op\mathbf{X}^	op\mathbf{w} - 2\mathbf{w}^	op\mathbf{X}^	op\mathbf{y} + \mathbf{y}^	op\mathbf{y} + \lambda\mathbf{w}^	op\mathbf{w}$
```

Finally take the gradient of the objective and find the value of **w** that achieves for the gradient:

```
$\nabla_w f(\mathbf{w}) = \mathbf{0}$
$2\mathbf{X}^	op\mathbf{w} - 2\mathbf{X}^	op\mathbf{y} + 2\lambda\mathbf{w} = \mathbf{0}$
$(\mathbf{X}^	op\mathbf{X} + \lambda\mathbf{I})\mathbf{w} = \mathbf{X}^	op\mathbf{y}$
$\mathbf{w}_{RIDGE} = (\mathbf{X}^	op\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^	op$
```

This value is guaranteed to achieve the (unique) global minimum, because the objective function is strongly convex, so it suffices to compute the Hessian of $f$, which in this case is

```
$\nabla^2 f(\mathbf{w}) = \mathbf{X}^	op\mathbf{X} + \lambda\mathbf{I}$
```
