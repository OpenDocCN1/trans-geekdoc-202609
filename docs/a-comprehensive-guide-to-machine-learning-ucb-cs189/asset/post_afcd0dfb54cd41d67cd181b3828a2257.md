## Derivation of AdaBoost

Suppose we have computed classifiers $G_1, ..., G_{m-1}$ along with their corresponding weights $\alpha_k$ and we want to compute the next classifier $G_m$ along with its weight $\alpha_m$. The output of our model so far is $F_{m-1}(x) := \sum_{i=1}^{m-1} \alpha_i G_i(x)$, and we want to minimize the:

```
\arg \min_{\alpha_m, G_m} L(y, F_{m-1}(x) + \alpha_m G_m(x))
```

for some loss function $L$. Loss functions which we have previously used mean squared error for linear regression, cross-entropy loss for logistic regression, and hinge loss for SVM. For AdaBoost, we use the exponential loss:

$L(y, h(x)) = e^{-yh(x)}$

This loss function is illustrated in Figure 8.1. We have exponential decay as we increase the input - if $yh(x)$ is large and positive (so $h(x)$ has the correct sign and magnitude), or if $yh(x)$ is a large negative value, our loss is increasing exponentially, and we are heavily penalized for making an incorrect prediction.

![](img/99defe26aebed215976e83d281581f33_135_0.png)

Figure 8.1: The exponential loss provides increasing penalty for confident incorrect predictions. This figure is from Cornell CS4780.

We can write the AdaBoost optimization problem with exponential loss as follows:

```
\alpha, G_m = \arg \min_{\alpha, G} \sum_{i=1}^n e^{-y_i(F_{m-1}(x_i) + \alpha G(x_i))}
```

## 8.3. BOOSTING

```
$arg \min_{\alpha, G} \sum_{i=1}^{n} e^{-y_i F_{m-i}(x_i)} e^{-y_i, \alpha G(x_i)}$
```

The term $w_i^{(m)} := e^{-y_i F_{m-i}(x_i)}$ is a constant with respect to our optimization variables. We can split this out sum into the components which correctly classify points and incorrectly classified points:

```
$$\alpha_{m, G_m} = \arg \min_{\alpha, y=G(x)} e^{-\alpha} \sum_{y \neq G(x)} w_i^{(m)} e^{\alpha} \quad (*)$$
$\alpha = \arg \min_{\alpha, G} \sum_{y \neq G(x)} w_i^{(m)} e^{-\alpha} \sum_{i=1}^{n} w_i^{(m)}$
```

For a fixed value of $\alpha$, the second term does not depend on $G$. We can then see that the best choice of $G_m(x)$ is the classifier that minimizes the error weights $w_i^{(m)}$.

```
$e_m = \frac{\sum_{y \neq G_m(x)} w_i^{(m)}}{\sum w_i^{(m)}}$
```

Once we have obtained $G_m$, we can solve for $\alpha_m$ by dividing ($*$) by the constant $\sum_{i=1}^{n} w_i^{(m)}$, we obtain

```
$$\alpha_m = \arg \min_{\alpha} (1-e_m) e^{-\alpha} + e_m e^{\alpha}$$
```

which has the solution (left as exercise)

```
$$\alpha_m = \frac{1}{2} \ln \left(\frac{1-e_m}{e_m}\right)$$
```

as claimed earlier. From the optimal $\alpha_m$, we can derive the weights:

```
$w_i^{(m+1)} = \exp(-y_i F_m(x_i))$
$= \exp(-y_i [F_{m-1}(x_i) + \alpha_m G_m(x_i)])$
$= w_i^{(m)} \exp(-y_i G_m(x_i) \alpha_m)$
$= w_i^{(m)} \exp(-y_i G_m(x_i) \frac{1}{2} \ln(\frac{1-e_m}{e_m}))$
$= w_i^{(m)} \left(\frac{1-e_m}{e_m}\right)^{-\frac{1}{2} y_i G_m(x_i)}$
```

We see that the multiplicative factor is $\frac{e_m}{1-e_m}$ when $y_i = G_m(x_i)$ and $\frac{1-e_m}{e_m}$ otherwise. This completes the development of the algorithm.

As a final note about the intuition, we view these updates as pushing towards a solution in some direction until we can no longer improve performance. More precisely, whenever we compute $\alpha_m$ (and thus $w_i^{(m+1)}$), for the incorrectly classified entries, we have

```
$$\sum_{y_i \neq G_m(x_i)} w_i^{(m+1)} = \sum_{y_i \neq G_m(x_i)} w_i^{(m)} \sqrt{\frac{1-e_m}{e_m}}$$
```

Dividing the right-hand side by $\sum_{i=1}^n w_i^{(m)}$, we obtain $e_m \sqrt{\frac{1-e_m}{e_m}} = \sqrt{e_m(1-e_m)}$. Similarly, the correctly classified entries, we have

```
$$\frac{\sum_{i=1}^n w_i^{(m+1)}}{\sum_{i=1}^n w_i^{(m)}} = (1-e_m) \sqrt{\frac{e_m}{1-e_m}} = \sqrt{e_m(1-e_m)}$$
```

These two quantities are the same once we have adjusted $\alpha$, so the misclassified and correctly classified sets both get equal weight. This observation has an interesting practical implication. Even after the training error goes to zero, the AdaBoost test error may continue to decrease. This may be counter-intuitive, as one would expect the classifier to be overfitting to the training data. One interpretation for this phenomenon is that even though the boosted classifier has achieved perfect training error, it is still refining its fit in a max-margin fashion, which increases its generalization capabilities.

### 9.1 Convolutional Neural Nets

A convolutional neural net is just like a regular neural net, except more complicated (convolved). But in some ways, a convolutional neural net can actually be a simpler model than a fully-connected neural net.

We'll be talking about convolutional neural networks (ConvNets) mostly in the framework of image classification. First, let's recall what one layer of a regular neural net looks like:

![](img/99defe26aebed215976e83d281581f33_138_0.png)

Remember each layer consists of units which represent a single number. The values on the units of some layer are determined by the values of the units behind them and the weights on the edges between the layers. More specifically, the vector of numbers representing layer 2, say $y$, can be represented by linear combinations $W$ of the vector representing layer 1. If we were dealing with images, each unit of the input layer might be the intensity of a single pixel of the image.

The fully-connected architecture of units has a lot of weights to learn. For just a $32 \times 32$ image, there would be 1024 input units and at least as many weights between the first two layers. Now, let's look at how a ConvNet deals with images uses its weights differently.

## Convolutional layer

A convolutional layer is determined by convolving a kernel about the previous layer. The kernel is just a fancy name for an array of weights, and convolving means that we slide the array of weights across the pixels of the previous layer and compute the sum of the elementwise products (kind of like a 2D dot-product). Here is a picture that illustrates this:

![](img/99defe26aebed215976e83d281581f33_139_1.png)

In the above picture, we extracted 6 activation values through some nonlinearity as well. In a fully-connected net, we would have 6 × 12 = 72 weights. However, in this convolutional layer, we used 4 weights because we made weight sharing among the input. This strategy decreases the complexity of our model

How do kernels detect things, anyways? The short answer is: they will produce large values in the areas of the image most similar to them. Consider a simple kernel [1 - 1]. This kernel will produce large values for which the left pixel is bright and the right pixel is dark. Conversely, it will produce small values for which the left pixel is dark and the right pixel is bright.

![](img/99defe26aebed215976e83d281581f33_140_0.png)

Figure 9.1: Left: a sample image. Right: the output of convolving the [1 - 1] kernel about the image.

Notice how the output image has high values (white) in the areas where the original image turned from bright to dark (like the right hand side of the figure), and it has low values (black) in the areas where the original image turned from dark to bright (like the left hand side of the figure). This kernel can be thought of as a simple edge detector! Another example, consider the kernel:

```
0.6 0.2 0
0.2 0 0.2
0 0.2 0.6
```

If this convolved about an image, it would detect edges at a 45-degree angle.
