We can also use kernels to compute distances in a different feature space. For example, if $k$ is a kernel with associated feature map $\Phi$ and we want to compute the Euclidean distance from $\Phi(x)$ to $\Phi(z)$, then we have

```
$$\|\Phi(x) - \Phi(z)\|^2 = \Phi(x)^T\Phi(x) - 2\Phi(x)^T\Phi(z) + \Phi(z)^T\Phi(z)\n= k(x,x) - 2k(x,z) + k(z,z)$$
```

Thus if we define $D(x,z) = \sqrt{k(x,x) - 2k(x,z) + k(z,z)}$, then we can perform Euclidean nearest neighbors in $\Phi$-space without explicitly representing $\Phi$ by the kernelized distance function $D$.

## 7.4 Sparsity and LASSO

### Sparsity for SVMs
Recall the objective function of the soft-margin SVM problem:

```
$$\min_{w} \frac{1}{2}\|w\|^2 + C\sum_{i=1}^n \xi_i^2$$
```

Note that if a point $x$ has a nonzero slack $\xi > 0$, by definition it must lie outside the margin. Due to the heavy penalty factor $C$ for penalizing the margin there are relatively few such points, and thus the slack $\xi$ is **sparse**—most of its entries are zero. We are interested in explaining why this phenomenon occurs in this specific optimization problem, and identifying the key properties that determine sparse solutions for arbitrary optimization problems.

To reason about the SVM case, let's see how changing some arbitrary slack variable $\xi_i$ affects the loss. A decrease in $\xi_i$ results in a "reward" of $C_i$ and is captured by the partial derivative $\frac{\partial}{\partial\xi_i}$. Note that no matter what the current value of $\xi_i$ is, the reward for decreasing $\xi_i$ is constant. Of course, $\xi_i$ may change the boundary and the cost attributed to the size of the margin. The overall reward for decreasing $\xi_i$ is either to worth the effort (greater than cost incurred from $w$) or not worth the effort (less than cost incurred from $w$). Intuitively, $\xi_i$ will continue to decrease until it hits a lower-bound "equilibrium"—which is just 0.

Now consider the following formulation (constrained for brevity):

```
$$\min_{w} \frac{1}{2}\|w\|^2 + C\sum_{i=1}^n \xi_i^2$$
```

The reward for decreasing $\xi_i$ is no longer constant—at any point, a decrease in $\xi_i$ results in a "reward" of $2C\xi_i$. As $\xi_i$ approaches 0, the rewards get smaller and smaller, infinitesimally affecting the values of $\|w\|^2$. On the other hand, decreasing $\xi_i$ causes a finite increase in the cost incurred by the $\|w\|^2$—the same increase as in the previous example. Intuitively, we can reason that there will be a threshold value $\xi^*$ such that decreasing $\xi_i$ further will no longer outweigh the cost incurred by the size of the margin, and that $\xi_i$ will halt their descent before they hit zero.

There are many advantages for optimization problems with sparse solutions. One advantage of sparse solutions is that they speed up testing time. In the context of primal problems, if the weight vector $w$ is sparse, then as we compute $w$ in training, we can discard features/dimensions with 0 weight, as they will contribute nothing to the evaluation of the hypothesized regression values of test points. A similar reasoning applies to dual with weight vector $v$, allowing us to discard the training points corresponding to dual weight 0, ultimately allowing for faster evaluation of our hypothesis function on test points.

## LASSO

The motivations for sparsity in SVMs, let's modify the ridge regression objective to achieve sparsity as well. The least absolute shrinkage and selection operator (LASSO) developed in 1996 by Robert Tibshirani, is one method that achieves this desired effect. LASSO is identical to the ridge regression objective, except that the L2-norm (squared) penalizing $w$ is now changed to an L1-norm (with no squaring term):

```
\min_{w} \|Xw - y\|^2 + \lambda||w\|_1
```

The **L1-norm** of $w$ is a sum of absolute values of its entries:

```
$\|z\|_1 = \sum_{i=1}^d |w_i|$
```

Compare this to the **L2-norm** squared of $w$, the sum of squared values of its entries:

```
$\|z\|_2 = \sum_{i=1}^d w_i^2$
```

Just as in ridge regression, there is a statistical justification for the L1-norm. Whereas ridge regression assumes a Gaussian prior over the weights $w$, LASSO assumes a **Laplace prior (otherwise known as a double exponential distribution)**- over the weights $w$.

### 7.5 Coordinate Descent

Note that the LASSO objective function is convex but not differentiable, due to the "pointiness" of L1-norm. This is a problem for gradient descent techniques—in particular LASSO zeros out features and sets these weights to 0. **Coordinate descent** is an alternative optimization algorithm that can solve convex but non-differentiable problems. While SGD focuses on iteratively optimizing the value of the objective $L(w)$ for each *sample* in the training set, coordinate descent iteratively optimizes the value of the objective for each *feature*.

**Algorithm 1** Coordinate Descent
while $w$ has not converged:
  pick a feature index $i$
  update $w_i$ to $\arg\min_{w_i} L(w)$

Coordinate descent is guaranteed to find the global minimum if $L$ is **jointly convex**. No such guarantees can be made if $L$ is **only elementwise convex**, since it may have local minima. To understand why, let's start by understanding elementwise convexity. Suppose that we are minimizing $f(x,y)$, a function of two variables $x$ and $y$. For simplicity, assume $f$ is twice differentiable, we can take its Hessian. $f(x,y)$ is elementwise convex in $x$ if its Hessian is psd:

$$\frac{\partial^2}{\partial x^2}f(x,y) \geq 0$$

Same for elementwise convexity in $y$. $f(x,y)$ is jointly convex in $x$ and $y$ if its Hessian $\nabla^2 f(x,y)$ is psd. Note that being elementwise convex in $x$ and $y$ does not imply joint convexity in $x$ and $y$ (consider $f(x,y) = x^2+y^2-4xy$ as an example). However, being jointly convex in $x$ and $y$ does imply elementwise convexity in both $x$ and $y$.

Now, if $f(x,y)$ was jointly convex, then we could find the gradient $x$ and $y$ individually, set them to 0, and be guaranteed the global minimum. Can we do this for elementwise convex? Not always. Even though it is true that $\min_{x,y}f(x,y) = \min_x \min_y f(x,y)$, we can't always get sets to zero if $f(x,y)$ is not jointly convex. The reason for this is that the inner optimization problem over $y$, the outer optimization problem over $x$ may not be convex. In the case where convexity is not reached, there is no clean strategy to find global minimum and we must analyze all of the critical points to find the minimum.

In the case of LASSO, the objective function is jointly convex, so we can use coordinate descent. There are a few details to handle, namely the choice of feature to update and how $w_i$ is updated. One simple way is to update $w_i \leftarrow \argmin_i L(w)$. For LASSO, it turns out there is a closed-form solution (that we are only minimizing with respect to one feature instead of all the features).

The LASSO objective is $\|Xw-y\|_2^2+\lambda\|w|_1$. It will be convenient to separate the terms that depend on $w_i$, from others. Denoting $x_j$ as the $j$-th column of $X$, we have:

```
$L(w) = \|Xw-y\|_2^2+\lambda\|w\|_1$
= \sum_{j=1}^d \|w_jx-y_j\|^2 + \lambda|w_i| + \lambda\sum_{j\neq i} |w_j|$
= \|w_ix+C^{(1)}\|_2^2 + \lambda|w_i| + C^{(2)}$
```

where $C^{(1)} = \sum_{j\neq i} w_ix_j - y$ and $C^{(2)} = \lambda\sum_{j\neq i} |w_j|$.
