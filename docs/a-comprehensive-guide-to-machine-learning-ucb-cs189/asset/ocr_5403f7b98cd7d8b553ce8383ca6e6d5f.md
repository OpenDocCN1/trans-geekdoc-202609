In both cases where we drop the conditioning on $\mathbf{Y}$, we are using fact $\mathbf{U}'$ is independent of $\mathbf{V}'$ (and independent of $\mathbf{Y} = \mathbf{DV}'$). Therefore

```
$$\mathbf{W} \mid \mathbf{y} \sim \mathcal{N}(\mathbf{BD}^{-	op}\mathbf{y}, \mathbf{AA}^	op)$
```

Recall that a Gaussian distribution is completely specified by its mean and covariance matrix. We see that the covariance matrix of the joint distribution

```
$$\mathbf{E} \left[ \begin{matrix} \mathbf{W} \ \mathbf{Y} \end{matrix} \left[ \begin{matrix} \mathbf{W}^	op \ \mathbf{Y}^	op \end{matrix} \right] \right] = \left[ \begin{matrix} \mathbf{A} & \mathbf{B} \ 0 & \mathbf{D} \end{matrix} \right]^	op \left[ \begin{matrix} \mathbf{A}^	op & 0 \ \mathbf{B}^	op & \mathbf{D}^	op \end{matrix} \right]$$
= \left[ \begin{matrix} \mathbf{AA}^	op + \mathbf{BB}^	op \ \mathbf{DB}^	op & \mathbf{DD}^	op \end{matrix} \right]$
= \left[ \begin{matrix} \Sigma_{\mathbf{W}} & \Sigma_{\mathbf{W,Y}} \ \Sigma_{\mathbf{Y,W}} & \Sigma_{\mathbf{Y}} \end{matrix} \right]$
```

Matching the corresponding terms, we can express the conditional mean and variance of $\mathbf{W} \mid \mathbf{y}$ in terms of these (cross-)covariance matrices:

```
$$\mathbf{BD}^{-	op}}\mathbf{y} = \mathbf{B}\mathbf{D}^	op\mathbf{D}^{-1}\mathbf{y} = (\mathbf{BD}^	op)(\mathbf{D}^{-	op})^{-\1}\mathbf{y} = \Sigma_{\mathbf{W,Y}}\Sigma_{\mathbf{Y}}^{-1}\mathbf{y}$$
$\$\Sigma_{\mathbf{W}} = \mathbf{AA}^	op + \mathbf{BB}^	op$$$
$\$\Sigma_{\mathbf{Y}} = \mathbf{AA}^	op + \mathbf{BB}^	op - \mathbf{B}\mathbf{D}^{-	op}\mathbf{D}^{-1}\mathbf{D}^	op\mathbf{B}^	op$$$
$\$\Sigma_{\mathbf{W,Y}} = \mathbf{AA}^	op + \mathbf{BB}^	op - (\mathbf{BD}^	op)(\mathbf{DD}^	op)^{-\1}\mathbf{DB}^	op$$$
= \Sigma_{\mathbf{W}} - \Sigma_{\mathbf{W,Y}}\Sigma_{\mathbf{Y}}^{-1}\Sigma_{\mathbf{YW}}$
```

We can then apply the same logic to the original estimator:

```
$$\mathbf{E} \left[ \begin{matrix} \mathbf{Y} \ \mathbf{W} \end{matrix} \left[ \begin{matrix} \mathbf{Y}^	op \ \mathbf{W}^	op \end{matrix} \right] \right] = \left[ \begin{matrix} \mathbf{R}_{\mathbf{Z}}\mathbf{R}_{\mathbf{Z}}^	op + \mathbf{XR}_{\mathbf{W}}\mathbf{R}_{\mathbf{W}}\mathbf{X}^	op & \mathbf{XR}_{\mathbf{W}}\mathbf{R}_{\mathbf{W}}^	op \ \mathbf{RR}_{\mathbf{W}}\mathbf{X}^	op & \mathbf{R}_{\mathbf{W}}\mathbf{R}_{\mathbf{W}}^	op \end{matrix} \right]$$
= \left[ \begin{matrix} \Sigma_{\mathbf{Y}} & \Sigma_{\mathbf{Y,W}} \ \Sigma_{\mathbf{W,Y}} & \Sigma_{\mathbf{W}} \end{matrix} \right]$$
```

Therefore after defining $\Sigma_{\mathbf{Z}} = \mathbf{R}_{\mathbf{Z}}\mathbf{R}_{\mathbf{Z}}$, we can read out

```
$$\Sigma_{\mathbf{W}} = \mathbf{R}_{\mathbf{W}}\mathbf{R}_{\mathbf{W}}^	op$$$
$\$\Sigma_{\mathbf{Y}} = \Sigma_{\mathbf{Z}} + \mathbf{X}\Sigma_{\mathbf{W}}\mathbf{X}^	op$$$
$\$\Sigma_{\mathbf{W,Y}} = \mathbf{X}\Sigma_{\mathbf{W}}$$
$\$\Sigma_{\mathbf{W,Y}} = \Sigma_{\mathbf{W}}\mathbf{X}^	op$$
```

Plugging this into our estimator yields

```
$$\mathbf{w} = \mathbf{E}[\mathbf{W} \mid \mathbf{y}] = \mathbf{y}$$
n= \Sigma_{\mathbf{W,Y}}\Sigma_{\mathbf{Y}}^{-1}\mathbf{y}$
```
