different from the matrix **R** that relates **U** to **Z**). As shown in the diagram below, we have some off-centered circular region **R'** and we would like to approximate the probability that **U** takes a value in this region. We can do so by taking a Riemann sum of the density function $f_U(.)$ over smaller and smaller squares that make up the region **R'**:

![](bbox=[0.237, 0.185, 0.762, 0.355])

Mathematically, we have that

```
$P(U \subseteq R') = \int_{R'} f_U(u_1, u_2) du_1 du_2 \approx \sum \sum f_U(u_1, u_2) \Delta u_1 \Delta u_2$
```

Now, let's apply the linear transformation **Z = RU**, mapping the region **R'** in **U** space, to the region $T(R')$ in **Z** space.

![](bbox=[0.226, 0.535, 0.773, 0.715])

The graph on the right is now **Z** space, the 2D space with axes $Z_1$ and $Z_2$. Assuming that the matrix **R** is invertible, there is a one-to-one correspondence between points in **U** space to points in **Z** space. We can as note in the diagram above, each unit square in **U** space maps to a parallelogram in **Z** space (in higher dimensions, we would use the terms **hypercube** and **parallelepiped). Recall the relationship between each unit hypercube and the parallelepiped maps to:

```
$Area(parallelepiped) = |det(R)| \cdot Area(hypercube)$
```

In this 2D example, if we denote the area of each unit square as $\Delta u_1 \Delta u_2$, and the area of each unit parallelepiped as $\Delta A$, we say that

```
$\Delta A = |det(R)| \cdot \Delta u_1 \Delta u_2$
```
