
## 7.2 THE DUAL OF SVMs

Let's apply our knowledge of duality to find the dual of the soft-margin SVM optimization problem.

```
$$\min f(w,t,\xi)\min_{w,t,\xi} \frac{1}{2}||w||^2 + C \sum_{i=1}^{n} \xi_i$$
$(1-\xi_i) - y_i(w^T x_i - t) \leq 0 \quad \text{and} \quad -\xi_i \leq 0_{g(w,t,\xi)\leq0}$$
```

Let's identify the primal and dual variables for the SVM problem. We will have

- Primal variables $w, t$, and $\xi_i$
- Dual variables $\alpha_i$ corresponding to each constraint of the form $y_i(w^T x_i - t) \geq 1 - \xi_i$
- Dual variables $\beta_i$ corresponding to each constraint of the form $\xi_i \geq 0$

For the purposes of notation, note that we are using $\alpha$ and $\beta$ in place of $\lambda$, and there are no dual variables corresponding to $\nu$ because there are no equality constraints. The lagrangian for the SVM problem is

```
$$\mathcal{L}(w,t,\xi,\alpha,\beta) = \frac{1}{2}||w||^2 + \sum_{i=1}^{n} \xi_i + \sum_{i=1}^{n} \alpha_i(1-\xi_i) - y_i(w^T x_i - t) + \sum_{i=1}^{n} \beta_i(-\xi_i) \quad (7.7)$$
```

```
$$\frac{1}{2}||w||^2 - \sum_{i=1}^{n} \alpha_i(w^T x_i - t) + \sum_{i=1}^{n} \alpha_i + \sum_{i=1}^{n} (C - \alpha_i - \beta_i)\xi_i$$
```

Thus, the dual is:

```
$$\max_{\alpha,\beta\geq 0} = \min_{w,t,\xi} \frac{1}{2}||w||^2 - \sum_{i=1}^{n} \alpha_i(w^T x_i - t) + \sum_{i=1}^{n} \alpha_i + \sum_{i=1}^{n} (C - \alpha_i - \beta_i)\xi_i \quad (7.8)$$
```

Let's use the KKT conditions to find the optimal dual variables. Verify that the primal is convex. We know that from the stationarity conditions, evaluated at the optimal values $w^*, t^*, \xi^*$,

```
$$\frac{\partial \mathcal{L}}{\partial w} = \frac{\partial \mathcal{L}}{\partial t} = 0$$
```

- $\frac{\partial \mathcal{L}}{\partial w} = w - \sum_{i=1}^{n} \alpha_i x_i = 0 \Rightarrow w^* = \sum_{i=1}^{n} \alpha_i x_i$. This tells us that $w^*$ is going to be the weighted combination of the positive-class $x_i^*$ and negative-class $x_i^*$.
- $\frac{\partial \mathcal{L}}{\partial t} = \sum_{i=1}^{n} \alpha_i = 0$. This tells us that the weights $\alpha_i^*$ will be equally distributed among positive- and negative training points.
- $\frac{\partial \mathcal{L}}{\partial \xi_i} = C - \alpha_i - \beta_i = 0 \Rightarrow 0 \leq \alpha_i^* \leq C$. This tells us that the weights $\alpha_i^*$ are restricted to being less than the hyperparameter $C$.

Verify that the other KKT also hold, establishing strong duality. Using these observations, we can eliminate some terms of the dual problem.

```
\mathcal{L}(w, t, \xi, \alpha^*, \beta^*) = \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i - t) + \sum_{i=1}^n \alpha_i^* + \sum_{i=1}^n (C - \alpha_i^* - \beta_i^*) \xi_i\n= \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i) + \sum_{i=1, s=0}^n \alpha_i^* y_i + \sum_{i=1, s=0}^n (C - \alpha_i^* - \beta_i^*) \xi_i\n= \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i) + \sum_{i=1}^n \alpha_i^*
```

We can rewrite the optimal primal variables $w^*, t^*, \xi^*$ in terms of the dual variables $\alpha_i^*$:

```
$g(\alpha^*, \beta^*) = \min_{w,t,\xi,\alpha^*} \mathcal{L}(w,t,\xi,\alpha^*,\beta^*)\n= \mathcal{L}(w^*,t^*,\xi^*,\alpha^*,\beta^*)\n= \frac{1}{2}\sum_{i=1}^n \alpha_i^* y_i x_i^2 - \sum_{i=1}^n\sum_{j=1}^n \alpha_i^* y_i \alpha_j^* y_j (x_j^T x_i) + \sum_{i=1}^n \alpha_i^*\n= \frac{1}{2}\sum_{i=1}^n \alpha_i^* y_i x_i^2 - \sum_{i=1}^n\sum_{j=1}^n \alpha_i^* y_i \alpha_j^* y_j (x_j^T x_i) + \sum_{i=1}^n \alpha_i^*\n= \alpha^{*T} 1 - \frac{1}{2}\alpha^{*T} Q$
```

where $Q_{ij} = y_i(x_i^T x_j)$ and $Q = \text{diag}(y)$. Now we can write the final form of the dual, which is only in terms of $\alpha$ and $x$ and $y$ (Note that we have eliminated $\beta$):

```
\max_{\alpha} \alpha^{T} 1 - \frac{1}{2}\alpha^{T} Q\alpha\text{s.t.} \sum_{i=1}^n \alpha_i = 0\n0\le \alpha_i \le C \quad i = 1, \dots, n
```

## Geometric intuition

We've seen that the optimal value of the dual problem in terms of $\alpha$ is equivalent to the optimal value of the primal problem in terms of $w, t$, and $\xi$. But what do these dual values $\alpha$ mean? That's a good question! We know that the following KKT conditions are enforced:

- Stationarity: $C - \alpha_i^* - \beta_i^* = 0$
- Complementary slackness: $\alpha_i^* \cdot ((1 - \xi_i^*) - y_i(w^{*T} x_i - t^*)) = 0$

Here are some noteworthy relationships between $\alpha_i$ and the properties of SVMs:

- Case 1: $\alpha_i^* = 0$. In this case, $\beta_i^* = C$, which is nonzero, and therefore $\xi_i^* = 0$. That is, if for point $i$ we have $\alpha_i^* = 0$ by the dual problem, then there is no slack given to this point. Looking at the complementary slackness condition, which makes sense if $\alpha_i^* = 0$, then $y_i(w^{*T}x_i - t^*) - (1-\xi_i^*)$ may be any value, and if we're minimizing the sum of our $\xi_i$, then we have $\xi_i^* = 0$. So, point $i$ lies **on** or **outside the margin**.
- Case 2: $\alpha_i^*$ is nonzero. If this is the case, then we know $\beta_i^* = C - \alpha_i^* \geq 0$.
- Case 2.1: $\alpha_i^* = C$. If this is the case, then we know $\beta_i^* = 0$, and therefore $\xi_i^*$ may be exactly zero or nonzero. So, point $i$ lies **on** or **inside the margin**.
- Case 2.2: $0 < \alpha_i^* < C$. In this case, $\beta_i^*$ is nonzero and $\xi_i^* = 0$. But this is different from Case 1 because with $\alpha_i^*$ nonzero, we can divide by $\alpha_i^*$ in the complementary slackness condition and arrive at the fact that $1 - y_i(w^{*T}x_i - t^*) = 0 \Rightarrow y_i(w^{*T}x_i - t^*) = 1$, which means $x_i$ lies exactly on the margin determined by $w^*$ and $t^*$. So, point $i$ lies **on the margin**.

Finally, let's reconstruct the optimal values $w^*, t^*, \xi_i^*$ from the optimal dual $\alpha^*$:

```
$w^* = \sum_{i=1}^n \alpha_i^* y_i x_i$\
$t^* = \text{mean}(w^{*T}x_i) \quad \forall : 0 < \alpha_i^* < C$\
$\xi_i^* = \begin{cases} 1 - y_i(w^{*T}x_i - t^*) & \text{if} \alpha_i^* = C \\ 0 & \text{otherwise} \end{cases}$ (7.10)
```

## 7.3 Nearest Neighbor Classification

In classification, it is reasonable to conjecture that data points that are sufficiently close to one another should be of the same class. For example, in fruit classification, perturbing a few pixels in an image should still result in something that looks like a banana. The k-nearest neighbors (k-NN) classifier is based on this observation. Assuming that is no preprocessing of the training data, the training time for k-NN is effectively O(1). To train this classifier, we simply store our training data for future reference. For this reason, k-NN is sometimes referred to as “lazy learning”. The major work of k-NN is done at test time: to predict on a test data we compute the k closest training points to z, where “closeness” can be quantified in some distance function such as Euclidean distance - these are k nearest neighbors to z. We then find the most common y among these k neighbors and classify z as y (that is, we perform a majority vote). For binary classification, k is usually chosen to be odd so we can break ties cleanly. Note that k-NN can also be applied to regression tasks — in that case k-NN would return the average label of the k nearest points.
