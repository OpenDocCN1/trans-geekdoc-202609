Coordinate descent is guaranteed to find the global minimum if $L$ is **jointly convex**. No such guarantees can be made if $L$ is **only elementwise convex**, since it may have local minima. To understand why, let's start by understanding elementwise vs convexity. Suppose that we are minimizing $f(x,y)$, a function of two variables $x$ and $y$. For simplicity, assume $f$ is twice differentiable, we can take its Hessian. $f(x,y)$ is elementwise convex in $x$ if its Hessian is psd when $y$ is:

$$\frac{\partial^2}{\partial x^2}f(x,y) \geq 0$

Same for elementwise convexity in $y$.
$f(x,y)$ is jointly convex in $x$ and $y$ if its Hessian $\nabla^2 f(x,y)$ is psd. Note that being elementwise convex in $x$ and $y$ does not imply joint convexity in $x$ and $y$ (consider $f(x,y) = x^2+y^2-4xy$ as an example). However, being joint convexity in $x$ and $y$ does imply elementwise convexity in both $x$ and $y$.

Now, if $f(x,y)$ was jointly convex, then we could find the gradient $x$ and $y$ individually, set them to 0, and be guaranteed the global minimum. Can we do this for elementwise convex? Not always. Even though it is true that $\min_{x,y}f(x,y) = \min_x \min_y f(x,y)$, we can't always get sets to zero if $f(x,y)$ is not jointly convex. The reason for this is that the inner optimization problem over $y$, the outer optimization problem over $x$ may not be convex. In the case where convexity is not reached, there is no clean strategy to find global minimum and we must analyze all of the critical points to find the minimum.

In the case of LASSO, the objective function is jointly convex, so we can use coordinate descent. There are a few details to handle, in namely the choice of feature to update and how $w_i$ is updated. One simple way is to update $w_i \leftarrow \argmin_i L(w)$. For LASSO, it turns out there is a closed-form solution (that we are only minimizing with respect to one feature instead of all the features).
