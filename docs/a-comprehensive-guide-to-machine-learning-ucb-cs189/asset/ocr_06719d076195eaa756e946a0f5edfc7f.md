# 7.2. THE DUAL OF SVMS

Here are some noteworthy relationships between $\alpha_i$ and the properties of the SVMs:

+   - Case 1: $\alpha_i^* = 0$. In this case, $eta_i^* = C$, which is nonzero, and therefore $\xi_i^* = 0$. That is, if for point $i$ we have $\alpha_i^* = 0$ by the dual problem, then there is no slack given to this point. Looking at the other complementary slackness condition, which makes sense because if $\alpha_i^* = 0$, then $y_i(w^{*T}x_i - t^*) - (1-\xi_i^*)$ may be any value, and if we're minimizing the sum of our $\xi_i$, then we have $\xi_i^* = 0$. So, point $i$ lies **on** or **outside the margin**.
- Case 2: $\alpha_i^*$ is nonzero. If this is the case, then we know $eta_i^* = C - \alpha_i^* \geq 0$
- Case 2.1: $\alpha_i^* = C$. If this is the case, then we know $eta_i^* = 0$, and therefore $\xi_i^*$ may be exactly zero or nonzero. So, point $i$ lies **on** or **inside the margin**.
- Case 2.2: $0 < \alpha_i^* < C$. In this case, $eta_i^*$ is nonzero and $\xi_i^* = 0$. But this is different from Case 1 because with $\alpha_i^*$ nonzero, we can divide by $\alpha_i^*$ in the complementary slackness condition and arrive at the fact that $1 - y_i(w^{*T}x_i - t^*) = 0 \implies y_i(w^{*T}x_i - t^*) = 1$, which means $x_i$ lies exactly on the margin determined by $w^*$ and $t^*$. So, point $i$ lies **on the margin**.

```
$$\alpha_i = 0 \implies y_i f(x_i) \geq 1$: on or outside the margin$\n$0 < \alpha_i < C \implies y_i f(x_i) = 1$: on the margin$\n$\alpha_i = C \implies y_i f(x_i) \leq 1$: on or inside the margin$\n$\alpha_i = 0 \implies y_i f(x_i) > 1$: outside the margin$\n$\alpha_i = C \implies y_i f(x_i) < 1$: inside the margin$
```

Finally, let's reconstruct the optimal values $w^*, t^*, \xi_i^*$ from the optimal dual $\alpha^*$:

```
$w^* = \sum_{i=1}^n \alpha_i^* y_i x_i$\nt^* = \text{mean}(w^{*T}x_i) \quad \forall : 0 < \alpha_i^* < C$\n\xi_i^* = \begin{cases} 1 - y_i(w^{*T}x_i - t^*) & \text{if} \alpha_i^* = C, \ 0 & \text{otherwise} \end{cases}$ \ (7.10)
```
