and show that this is positive definite (PD):

$$\nabla w \neq 0, \mathbf{w}^T(\mathbf{X}^T + \lambda\mathbf{I})\mathbf{w} = (\mathbf{Xw})^T\mathbf{Xw} = ||\mathbf{Xw}||_2^2 + \lambda||w||_2^2 > 0$

Since the Hessian is positive definite, we can equivalently say that the eigenvalues of the Hessian are strictly positive and that the objective function is strongly convex. A useful property of strongly convex functions is that they have a unique optimum point, so the solution ridge is unique. We cannot make such guarantees, about ordinary least squares, because the corresponding Hessian could have eigenvalues that are 0. As we explore in OLS when the Hessian has a 0 eigenvalue, in this context, the term $\mathbf{X}^T$ is not invertible, but this does *not* imply that no solution exists! In OLS, there always exists a solution, and when the Hessian is PD that solution is unique; when the Hessian is PSD infinitely many solutions. There always exist a solution to the equation $\mathbf{X}^T\mathbf{X}w=\mathbf{X}^T\mathbf{y}$, because the range of $\mathbf{X}^T\mathbf{X}$ and the range of $\mathbf{X}$ are equivalent; since $\mathbf{y}$ lies in the range of $\mathbf{X}^T$, it must equivalently lie in the range of $\mathbf{X}^T$ and therefore there always exists a $\mathbf{w}$ that satisfies the equation $\mathbf{X}^T\mathbf{X}w=\mathbf{X}^T\mathbf{y}$.

The technique we discussed is known as ridge regression, (otherwise known as Tikhonov regularization in the statistics community). Note that the expression $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}$ is invertible, regardless of rank of $\mathbf{X}$. Let first

```
$$(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1} = \left(V \begin{bmatrix} \Sigma_r & 0 \ 0 & 0 \end{bmatrix} \mathbf{U}^T\mathbf{U} \begin{bmatrix} \Sigma_r & 0 \ 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$
$$= \left(V \begin{bmatrix} \Sigma_r & 0 \ 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$
$$= \left(V \begin{bmatrix} \Sigma_r^2 & 0 \ 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$
$$= \left(V \begin{bmatrix} \Sigma_r^2 + \lambda\mathbf{I} & 0 \ 0 & 0 \end{bmatrix} V^T\right)^{-1}$
$$= (V^T)^{-1} \begin{bmatrix} \Sigma_r^2 + \lambda\mathbf{I} & 0 \ 0 & \lambda\mathbf{I} \end{bmatrix}^{-1} V\n$$= V \begin{bmatrix} (\Sigma_r^2 + \lambda\mathbf{I})^{-1} & 0 \ 0 & \lambda^{-1} \end{bmatrix} V^T$
```

With our slight tweak, the matrix $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}$ has full rank and thus invertible. The singular values are guaranteed to be at most $\frac{1}{\sqrt{\lambda}}$ and $\sqrt{\lambda}$, solving numerical instability issues. Furthermore, we have partially solved the overfitting issue. By penalizing the norm of $\mathbf{x}$, we encourage the weights corresponding to relevant features that capture the main structure of the true model, and penalized the weights corresponding to complex features that only serve to fine tune the model and fit noise in the data.
