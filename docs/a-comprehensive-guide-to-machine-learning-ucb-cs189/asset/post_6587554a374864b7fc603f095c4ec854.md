
## 1.2 ORDINARY SQUARES

If $X$ is full rank, then $\mathbf{X}^T\mathbf{X}$ is invertible, so we can solve for a unique solution

$$\mathbf{w}_{\text{OLS}}^*=(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$

Note: Although we write $(\mathbf{X}^T\mathbf{X})^{-1}$, in practice we would not actually compute the inverse; it is numerically stable to solve the linear system of equations above (e.g. with Gaussian elimination).

In this derivation we used the condition $\nabla L(\mathbf{w}^*)=0$, which is a necessary but not sufficient for optimality. We found a critical point, but in general such a point could be a local minimum, a local maximum, or a saddle point. Fortunately, in this case the objective function is convex, which implies that any critical point is a global minimum. To show that $L$ is convex, it suffices to compute the Hessian of $L$, in which this case is

$$\nabla^2 L(\mathbf{w})=2\mathbf{X}^T\mathbf{X}$$

and show that this is positive semi-definite:

$$\mathbf{v}^T(2\mathbf{X}^T\mathbf{X})\mathbf{v}=2\mathbf{X}^T\mathbf{X}\mathbf{v}=2\|\mathbf{X}\mathbf{v}\|_2^2 \ge 0$$

## Approach 2: Orthogonal projection

There is also a linear way to arrive at the same solution: orthogonal projections.

Recall that if $V$ is an inner product space and $S$ is a subspace of $V$, then any $\mathbf{v} \in V$ can be decomposed uniquely in the form

$$\mathbf{v}=\mathbf{v}_S+\mathbf{v}_\perp$$

where $\mathbf{v}_S \in S$ and $\mathbf{v}_\perp \in S^\perp$. $S^\perp$ is the orthogonal complement of $S$, i.e. the set of vectors that are perpendicular to every vector in $S$.

The orthogonal projection onto $S$, denoted $P_S$, is the linear operator that maps $\mathbf{v}$ to $\mathbf{v}_S$ in the decomposition above. An important property of the orthogonal projection is

$$\|\mathbf{v}-P_S\mathbf{v}\| \le \|\mathbf{v}-\mathbf{s}\|$$

for all $\mathbf{s} \in S$, with equality if and only if $\mathbf{s}=P_S\mathbf{s}$. That is,

$$P_S\mathbf{v}=\arg \min_{\mathbf{s}\in S} \|\mathbf{v}-\mathbf{s}\|$$

Proof. By the Pythagorean theorem,

$$\|\mathbf{v}-\mathbf{s}\|^2=\|\sum_{\mathbf{s}'\in S} (\mathbf{v}-P_S\mathbf{v})+P_S\mathbf{s}\|^2=\|\mathbf{v}-P_S\mathbf{v}\|^2+\|P_S\mathbf{s}\|^2 \ge \|\mathbf{v}-P_S\mathbf{v}\|^2$$

equality holding if and only if $\|P_S\mathbf{v}-\mathbf{s}\|^2=0$, $\mathbf{s}=P_S\mathbf{v}$. Taking square roots on both sides gives $\|\mathbf{v}-\mathbf{s}\| \ge \|\mathbf{v}-P_S\mathbf{v|$ as claimed (since norms are nonnegative). $\square$

In the OLS case,

$$\mathbf{w}^*_{OLS} = \arg \min_{\mathbf{w}} ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2$$

But observe that the set of vectors that can be written $\mathbf{X}\mathbf{w}$ for some $\mathbf{w} \in \mathbb{R}^d$ is precisely the range of $\mathbf{X}$, which we know to be a subspace of $\mathbb{R}^n$, so

$$\min_{\mathbf{z} \in \text{range}(\mathbf{X})} ||\mathbf{z} - \mathbf{y}||_2^2 = \min_{\mathbf{w}} ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2$$

By pattern matching with the earlier optimality statement about $P_{\mathbf{X}}$, we observe that $P_{range(\mathbf{X})}(\mathbf{y}) = \mathbf{X}\mathbf{w}^*_{OLS}$, where $\mathbf{w}^*_{OLS}$ is any optimum for the right-hand side. The projected point $\mathbf{X}\mathbf{w}^*_{OLS}$ is always unique, but if $\mathbf{X}$ is full rank (assuming $n \geq d$), then the optimum $\mathbf{w}^*_{OLS}$ is also unique (expected). This is because $\mathbf{X}$ being full rank means that the columns of $\mathbf{X}$ are linearly independent, in which case there is a one-to-one correspondence between $\mathbf{w}$ and $\mathbf{X}\mathbf{w}$.

To solve for $\mathbf{w}^*_{OLS}$, we need the following fact$^1$:

$$\text{null}(\mathbf{X}^T) = \text{range}(\mathbf{X})\perp$$

Since we are projecting onto range($\mathbf{X}$), the orthogonality condition for optimality is that $\mathbf{y} - P_{\mathbf{X}}\mathbf{y} \perp \text{range}(\mathbf{X})$, i.e. $\mathbf{y} - \mathbf{X}\mathbf{w}^*_{OLS} \in \text{null}(\mathbf{X}^T)$. This leads to the equation

$$\mathbf{y}^T(\mathbf{y} - \mathbf{X}\mathbf{w}^*_{OLS}) = 0$$

which is equivalent to

$$\mathbf{X}^T\mathbf{X}\mathbf{w}^*_{OLS} = \mathbf{X}^T\mathbf{y}$$

as before.

## 1.3 RIDGE REGRESSION

Why are singular values bad? Let us illustrate via the singular value decomposition (SVD) of $\mathbf{X}$:

$$\mathbf{X} = U\Sigma V^T$$

where $U \in \mathbb{R}^{n \times n}$, $\Sigma \in \mathbb{R}^{n \times d}$, $V \in \mathbb{R}^{n \times d}$. In the context of OLS, we must have that $\mathbf{X}^T\mathbf{X}$ is invertible, or equivalently, $\text{rank}(\mathbf{X}^T\mathbf{X}) = \text{rank}(\mathbf{X}) = d$. Assuming that $\mathbf{X}$ and $\mathbf{X}^T$ are full rank $d$, we can express the SVD of $\mathbf{X}$ as

$$\mathbf{X} = U \begin{bmatrix} \Sigma_d & 0 \end{bmatrix} V^T$$

where $\Sigma_d \in \mathbb{R}^{d \times d}$ is a diagonal matrix with strictly positive entries. Now let's try to expand the $(\mathbf{X}^T\mathbf{X})^{-1}$ term in terms of SVD:

$$(\mathbf{X}^T\mathbf{X})^{-1} = (V \Sigma_d^T U^T U \begin{bmatrix} \Sigma_d \\ 0 \end{bmatrix} V^T)^{-1} = (V \Sigma_d^2 V^T)^{-1} = V (\Sigma_d^2)^{-1} V^T = V \Sigma_d^{-2} V^T$$

This means that $(\mathbf{X}^T\mathbf{X})^{-1}$ will have singular values that are the squared of the singular values of $\mathbf{X}$, potentially leading to extremely large values when the singular value of $\mathbf{X}$ is close to 0. Such excessively large values can be problematic for numerical stability. In addition, high values to the optimal $\mathbf{w}$ solution would prevent OLS from generalizing to unseen data.

There is a very simple solution to these issues: penalize the entries of $\mathbf{w}$ from becoming too large. We can do this by adding a penalty term constraining the norm of $\mathbf{w}$. For a fixed, small scale $\lambda > 0$, we have:

$$\min_{\mathbf{w}} ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2 + \lambda|mathbf{w}||_2^2$$

Note that the $\lambda$ in our objective function is a hyperparameter that measures the sensitivity to the values in $\mathbf{w}$. Like the degree in polynomial features, $\lambda$ is a value that we must choose through validation. Let's expand the terms of the objective function

$$f(\mathbf{w}) = ||\mathbf{X}\mathbf{w} - \mathbf{y}||_2^2 + \lambda||\mathbf{w}||_2^2 = \mathbf{w}^T\mathbf{X}^T\mathbf{X}\mathbf{w} - 2\mathbf{y}^T\mathbf{X}\mathbf{w} + \mathbf{y}^T\mathbf{y} + \lambda\mathbf{w}^T\mathbf{w}$$

Finally take the gradient of the objective and find the value of $\mathbf{w}$ that achieves the gradient $\nabla f(\mathbf{w})=2\mathbf{X}^T\mathbf{X}\mathbf{w} - 2\mathbf{X}^T\mathbf{y} + 2\lambda\mathbf{w} = 0$$

$$(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\mathbf{w} = \mathbf{X}^T\mathbf{y}$$

This value is guaranteed to achieve the (unique) global minimum because the objective function is strongly convex, so it suffices to compute the Hessian of $f$, which in this case is

$$\nabla^2 f(\mathbf{w}) = 2(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})$$

and show that this is positive definite (PD):

$$\mathbf{w}^T(2\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\mathbf{w} = 2\mathbf{w}^T\mathbf{X}^T\mathbf{X}\mathbf{w} + 2\lambda\|\mathbf{w}\|^2 > 0$$

Since the Hessian is positive definite, we can equivalently say that the eigenvalues of the Hessian are strictly positive and that the objective function is strongly convex. A useful property of strongly convex functions is that they have a unique optimum, so the solution is unique. We cannot make such guarantees about ordinary squares because the corresponding Hessian could have eigenvalues that are 0. As we explore in OLS when the Hessian has a 0 eigenvalue, in this context the term $\mathbf{X}^T$ is not invertible, but this does *not* imply that no solution exists! In OLS, there always exists a solution, and when the Hessian is PSD there are infinitely many solutions. There always exist a solution to the equation $\mathbf{X}^T\mathbf{X}\mathbf{w}=\mathbf{X}^T\mathbf{y}$ because the range of $\mathbf{X}^T\mathbf{X}$ and the range of $\mathbf{X}$ are equivalent; since $\mathbf{y}$ lies in the range of $\mathbf{X}^T$, it must equivalently lie in the range of $\mathbf{X}^T$ and therefore there exists a $\mathbf{w}$ that satisfies the equation $\mathbf{X}^T\mathbf{X}\mathbf{w}=\mathbf{X}^T\mathbf{y}$.

The technique we discussed is known as ridge regression (otherwise known as Tikhonov regularization in the statistics community). Note that the expression $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}$ is invertible, regardless of rank of $\mathbf{X}$. Let first

$$(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1} = \left(V \begin{bmatrix} \Sigma_r^2 & 0 & 0 & 0 \end{bmatrix} \mathbf{U}^T\}{U{ \} \Sigma} \Sigma r & 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$$
$$= \left(V \begin{bmatrix} \Sigma_r & 0 \\ 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$$
$$= \left(V \begin{bmatrix} \Sigma_r^2 & 0 \\ 0 & 0 \end{bmatrix} V^T + \lambda\mathbf{I}\right)^{-1}$$
$$= \left(V \begin{bmatrix} \Sigma_r^2 + \lambda\mathbf{I} & 0 \\ 0 & 0 \end{bmatrix} V^T\right)^{-1}$$
$$= (V^T)^{-1} \begin{bmatrix} \Sigma_r^2 + \lambda\mathbf{I} & 0 \\ 0 & \lambda\mathbf{I} \end{bmatrix}^{-1} V$$
$$= V \begin{bmatrix} (\Sigma_r^2 + \lambda\mathbf{I})^{-1} & 0 \\ 0 & \lambda^{-1} \end{bmatrix} V^T$$

With our slight tweak, the matrix $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}$ has full rank and thus invertible. The singular values are guaranteed to be at most $\frac{1}{\sqrt{\lambda}}$ and $\sqrt{\lambda}$, solving numerical instability issues. Furthermore, we have partially solved the overfitting issue. By penalizing the norm of $\mathbf{x}$, we encourage the weights corresponding to relevant features that capture the main structure of the true model, and penalized the weights corresponding to complex features that only serve to fine tune the model and fit noise in the data.
