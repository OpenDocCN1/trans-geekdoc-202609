
## CHAPTER 5. NEURAL NETWORKS

By the linearity of differentiation, we see that

```
$$\nabla L(w) = \frac{1}{n} \sum_{i=1}^n \nabla_w \ell(x_i, w, y_i)$$
```

So computing the gradient takes time linear in $n$. In the “big data” regime, $n$ is very large, this cost may be unacceptable.

For this reason, we have reason to try to approximate the gradient of the loss function of a neural network by taking a representative random sample of the inputs to calculate the gradient. Since gradient descent is an iterative process, we might consider forfeiting the exactness of the update of each iteration for better speed of computation. If we take the gradient over a random sample of these training samples at each step, we will get a noisy or unbiased estimate of the true gradient. The noise in each step is often an acceptable tradeoff in exchange for the opportunity to take more steps.

In the regular descent update, we have the policy:

```
$w^{(k+1)} \leftarrow w^{(k)} - \alpha_k \nabla_w L(w^{(k)})$
```

In stochastic gradient descent, we have the update rule:

```
$w^{(k+1)} \leftarrow w^{(k)} - \alpha_k G_k$
```

where $G_k$ is a random variable which satisfies $\mathbb{E}[G_k] = \nabla L(w^{(k)})$. Typically $G_k$ is constructed by sampling $m < n$ training points uniformly at random (the index is $I_k \subset \{1, \dots, n\}$) and computing the gradient on these points:

```
$G_k = \frac{1}{m} \sum_{i \in I_k} \nabla_w \ell(x_i, y_i)$
```

We denote the optimal by $w^*$. Our goal is to show the:

```
$$\lim_{k \to \infty} \mathbb{E}[\|w^{(k)} - w^*\|^2] = 0$$
```

We make the following assumptions in the analysis:

- 1. The loss function $f$ is $\ell$-strongly convex; that is, there exists an $\ell > 0$ such that $(\nabla f(x) - \nabla f(y))^T(x - y) \geq \ell \|x - y\|^2$ for all $x, y$. 
- 2. The expected square norm of the stochastic gradient is bounded by $\mathbb{E}[\|G_k\|^2] \leq M^2 < \infty$.

We begin by expanding the desired term:

```
$$\mathbb{E}[\|w^{(k+1)} - w^*\|^2] = \mathbb{E}[(w^{(k+1)} - w^*)^T(w^{(k+1)} - w^*)] = \mathbb{E}[((w^{(k)} - w^* - \alpha_k G_k)^T(w^{(k)} - w^* - \alpha_k G_k)] = \mathbb{E}[\|w^{(k)} - w^*\|^2 - 2\alpha_k \mathbb{E}[(w^{(k)} - w^*)^T G_k] + \alpha_k^2 \mathbb{E}[\|G_k\|^2]]$$
```

For brevity, define

```
$d_k = \mathbb{E}[\|w^{(k)} - w^*\|^2]$
```

Our assumption on the expected square norm of $G_k$ implies

```
$d_{k+1} \leq d_k - 2\alpha_k \mathbb{E}[(w^{(k)} - w^*)^T G_k] + \alpha_k^2 M^2$
```

To evaluate the expectation, we condition on the past (i.e. all random decisions that contributed to $w^{(k)}$, including choices of points to evaluate the gradient at). By the law of iterated expectation, we have

$$E[(w^{(k)} - w^*)G_k] = E_{\text{past}}[E[(w^{(k)} - w^*)G_k \mid \text{past}]]$$

The next expectation is taken over the choice of training points used to compute the stochastic gradient. But given the past (which includes $w^{(k)}$), we already know $u^{(k)}$, so

$$E[(w^{(k)} - w^*)G_k \mid \text{past}] = (w^{(k)} - w^*)E[G_k \mid \text{past}]$$

The current $G_k$ depends on our choice of evaluation point, which is presumed independent of the past and thus $E[G_k \mid \text{past}] = E[G_k \mid w^{(k)}]$, where the second equality holds because $G_k$ is an unbiased estimator for the true gradient at $w^{(k)}$. Putting this together, we have

$$E[(w^{(k)} - w^*)G_k] = E_{\text{past}}[(w^{(k)} - w^*) \nabla f(w^{(k)})]$$

First order conditions for optimality imply that $\nabla f(w^*) = 0$. By the assumption of $\ell$-strong convexity, we have

$$(w^{(k)} - w^*)T \nabla f(w^{(k)}) = \langle w^{(k)} - w^*, \nabla f(w^{(k)}) - \nabla f(w^*) \rangle \geq \ell \|w^{(k)} - w^*\|_2^2$$

Taking expectations

$$E[(w^{(k)} - w^*) \nabla f(w^{(k)})] \geq \ell \|w^{(k)} - w^*\|_2^2 = \ell d_k$$

Putting this into account for $d_{k+1}$, we get

$$d_{k+1} \le d_k - 2\alpha_k d_k + \alpha_k^2 M^2 = (1 - 2\alpha_k)d_k + \alpha_k^2 M^2$$
