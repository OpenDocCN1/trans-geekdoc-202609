# 3.3. CANONICAL CORRELATION ANALYSIS

```
= \max_{u_w, v_w} \frac{u_w^	op X_w^	op Y_w v_w}{\sqrt{u_w^	op X_w^	op X_w u_w \cdot v_w^	op Y_w^	op Y_w v_w}}}\n\rho(X_w, Y_w)
```

We have used the fact that $X_w^	op X_w$ and $Y_w^	op Y_w$ are identity matrices by construction.

+   Second, let's choose matrices $D_x, D_y$ to **decorrelate** $X_w$ and $Y_w$. This will let us simplify the covariance matrix $(X_w D_x)^	op (Y_w D_y)$ into a **diagonal** matrix. To do this, we'll use the SVD:

```
$X_w^	op X_w = USV^	op$
```

The choice of $U$ for $D_x$ and $V$ for $D_y$ largely yours,

```
$(X_w U)^	op (Y_w V) = U^	op X_w^	op Y_w V = U^	op (SV^	op)V = S$
```

Let's denote the decorated $X_d = D_x^{-1}X_w$ and $Y_d = D_y Y_w$. Then by the change of variables $u_d = D_x^{-1}u_w$ and $v_d = D_y^{-1}v_w$,

```
\max_{u_w, v_w} \rho(X_w u_w, Y_w v_w) = \max \frac{(X_w u_w)^	op (Y_w v_w)}{\sqrt{u_w^	op X_w^	op X_w u_w \cdot v_w^	op Y_w^	op Y_w v_w}}\n= \max_{u_w, v_w} \frac{(D_x D_x^{-1} u_w)^	op (D_y D_y^{-1} v_w)}{\sqrt{(D_x u_d)^	op D_x u_d \cdot (D_y v_d)^	op D_y v_d}}\n= \max_{u_d, v_d} \frac{u_d^	op X_d^	op Y_d v_d}{\sqrt{u_d^	op X_d^	op X_d u_d \cdot v_d^	op Y_d^	op Y_d v_d}}\n= \max_{u_d, v_d} \frac{u_d^	op S v_d}{\sqrt{u_d^	op u_d \cdot v_d^	op v_d}}\n\rho(X_d, Y_d)\n= \max_{u_d, v_d} \frac{u_d^	op S v_d}{\sqrt{u_d^	op u_d \cdot v_d^	op v_d}}
```

With loss of generality, suppose $u_d$ and $v_d$ are unit vectors so that the denominator becomes 1, and we can ignore it:

```
\max_{u_d, v_d} u_d^	op S v_d = \max_{\|u_d\|=1, \|v_d\|=1} u_d^	op S v_d = \max_{\|u_d\|=1} \|Su_d\|
```

The diagonal of $S$ implies $0$ for $i \neq j$, so our simplified objective expands as

```
$u_d^	op S v_d = \sum_{i,j} S_{ij}(u_d)_i(v_d)_j = \sum_{i} S_{ii}(u_d)_i(v_d)_i$
```
