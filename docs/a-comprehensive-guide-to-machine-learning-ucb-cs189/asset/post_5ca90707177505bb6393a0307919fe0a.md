## 7.3. NEAREST NEIGHBOR CLASSIFICATION

![](img/99defe26aebed215976e83d281581f33_120_0.png)

Figure 7.2: Voronoi diagram for $k=1$ vs. $k=15$. Figure from Introduction to Statistical Learning.

Choosing $k=1$, we achieve an optimal training error of 0 because each training point will classify as itself, achieving 100% accuracy on itself. However, $k=1$ overfits to the training data, and there is a terrible choice in the context of the bias-variance tradeoff. Increasing $k$ leads to an increase in training error, but a decrease in testing error and achieves better generalization. At one point, if $k$ becomes too large, the algorithm will underfit the training data, and suffer from huge bias. In general, in order to select $k$ we use cross-validation.

### Bias-Variance Analysis

Let's justify this reasoning formally for k-NN applied to regression tasks. Suppose we are given a training dataset $\mathcal{D}=\{(x_i, y_i)\}_{i=1}^n$, where the labels $y_i$ are real valued scalars. We model our hypothesis $h(z)$ as

```
$h(z) = \frac{1}{k} \sum_{i=1}^n N(x_i, z, k)$
```

where the function $N$ is defined as

```
$N(x_i, z, k) = \begin{cases} y_i & \text{if } x_i \text{ is one of the } k \text{ closest points to } z \\ 0 & \text{o.w.} \end{cases}$
```

Suppose also we assume our labels $y_i = f(x_i) + \epsilon$, where $\epsilon$ is the noise from $\mathcal{N}(0, \sigma^2)$ and $f$ is the true function. Let $x_1 \dots x_k$ be the $k$ closest points. Let's derive the bias of our model for the given dataset $D$.

```
$E[[h(z)] - f(z)]^2 = E\left[\left(\sum_{i=1}^k N(x_i, z, k) - f(z)\right)^2\right] = E\left[\left(\sum_{i=1}^k y_i - f(z)\right)^2\right]$
```

```
$E\left[(\sum_{i=1}^k E[y_i] - f(z)\right)^2\right] = E\left[\left(\sum_{i=1}^k E[f(x_i) + \epsilon] - f(z)\right)^2\right]$
```

```
$E\left[(\sum_{i=1}^k f(x_i) - f(z))^2\right]$
```

When $k \to \infty$, then $\sum_{i=1}^k f(x_i)$ goes to the average level for $x$. When $k=1$, the bias is simply $f(x_1) - f(z)$. Assuming $x_1$ is close enough to $f(z)$, the bias would likely be small when $k=1$ since it's likely to share a similar mean. Meanwhile, when $k \to \infty$, the bias doesn't depend on the training points at all which will restrict it to be higher.

Now, let's derive the variance of $h(z)$

```
$Var[h(z)] = Var\left[\frac{1}{k} \sum_{i=1}^k y_i\right] = \frac{1}{k^2} \sum_{i=1}^k Var[f(x_i) + \epsilon]$
```

```
$$\frac{1}{k^2} \sum_{i=1}^k Var[\epsilon]$$
```

```
$$\frac{1}{k^2} \sum_{i=1}^k \sigma^2 = \frac{1}{k^2} k\sigma^2 = \frac{\sigma^2}{k}$$
```

The variance goes to 0 when $k \to \infty$, and is maximized at $k=1$.

### Properties

**Computational complexity:** We require $O(n)$ space to store a training set of size $n$. There is no runtime cost during training if we use specialized data structures to store the data. However, predictions take $O(n)$ time, which is costly. There has been research into approximate nearest neighbors (ANN) procedures that quickly find an approximation for the nearest neighbor - some common ANN methods are *Locality-Sensitive Hashing* and algorithms that perform dimensionality reduction via randomized (Johnson-Lindenstrauss) distance-preserving projections.^2$

$^2$ ANN methods are beyond the scope of this course, but are useful in real applications.

**Flexibility:** When $k>1$, k-NN can be modified to output predicted probabilities $P(Y|X)$ by defining $P(Y|X)$ as the proportion of nearest neighbors to $X$ in the training set that has class $Y$. k-NN can also be adapted for regression — instead of taking the majority vote, take the average of the $y$ values for the nearest neighbors. k-NN can learn complicated, non-linear decision boundaries.

**Non-parametric:** k-NN is a non-parametric method, which means that the number of parameters in the model grows with $n$, the number of training points. This is opposed to parametric methods, for which the number of parameters is independent of $n$. Some examples of parametric methods include linear regression, LDA, and neural networks.

**Behavior in high dimensions:** k-NN does not behave well in high dimensions. As the dimension increases, data points drift far apart, so the nearest neighbor to a point will be very far away.

**Theoretical properties:** k-NN has impressive theoretical guarantees for such simple method. Cover and Hart, 1967 prove that as the number of training samples $n$ approaches infinity, the expected prediction error for $l$-NN is bounded by $2e^*$, where $e^*$ is the Bayes (optimal) error. Fix and Hodges, 1951 prove that as $n$ and $k$ approach infinity.

### Curse of Dimensionality

To understand why k-NN does not perform well, we first need to understand the properties of high dimensions. Here is a classical example: Consider the ratio of the outer ball to the inner ball. In high dimensions, random Gaussian will lie within![](img/99defe26aebed215976e83d281581f33_120_1.png)

As $d \to \infty$, the volume of the outer ball is proportional to the inner ball. This phenomenon is known as the concentration of measure. Without resorting to more complicated inequalities, we can show a simple result:

**Theorem:** If $X_i \sim N(0, \sigma^2), i=1,\dots,d$ are independent and $R^2=\sum_{i=1}^d X_i^2$, then for every $\epsilon > 0$, the following holds:

```
$$\lim_{d \to \infty} P(|R^2 - E(R^2)| \geq d^{1/2+\epsilon}) = 0$$
```

*Proof.* From the formula for the variance of a chi-squared distribution, we see that $Var(R^2)=d\sigma^4$. Applying a Chebyshev bound yields

```
$P(|R^2 - E(R^2)| \geq d^{1/2+\epsilon}) \leq \frac{2d\sigma^4}{d+1} \xrightarrow{d \to \infty} 0$
```

Thus a random Gaussian will lie within a thin annular region away from the origin in high probability, though the mode of the Gaussian bell curve is at the origin.

### Improving k-NN

There are two ways to improve k-NN and overcome the shortcomings we have discussed:

- 1. Obtain more training data.
- 2. Reduce the dimensionality of the features and/or pick better features. Consider other choices of distance function.

One example of reducing the dimensionality in image space is to lower the resolution of the image while this is throwing some of the original pixel features away, we may still be able to get the same or better performance with a nearest neighbors method.

We can also modify the distance function. For example, we have a family of **Minkowski distances** that are induced by the $L^p$ norms:

```
$D_p(x,z) = \left( \sum_{i=1}^d |x_i - z_i|^p \right)^{1/p}$
```

Without preprocessing the data, I-NN with the $L^3$ distance outperforms I-NN with $L^2$ on MNIST.
