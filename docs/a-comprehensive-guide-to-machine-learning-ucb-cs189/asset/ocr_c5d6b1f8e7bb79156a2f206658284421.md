# 6.8. LOGISTIC REGRESSION

In the context of classification, if the class label $y_i$ is interpreted as the probability of class 1, then logistic regression provides an estimate $p_i$ of the probability that the data is in class 1. The true class can be viewed as a sampled value from the “true” distribution $P_i \sim 	ext{Bernoulli}(y_i)$. $P_i$ is not a particularly interesting distribution because all values sampled from it will yield $P(y=y_i)=1$. Logistic regression yields a distribution $Q_i \sim 	ext{Bernoulli}(p_i)$, which the posterior probability estimates the true distribution $P_i$. Be careful not to mix up the random variable $P_i$ and the quantity $p_i$. In the context of this problem $p_i$ is associated with the estimated distribution $Q_i$, not the true distribution $P_i$.

The KL divergence from $Q_i$ to $P_i$ provides a measure of how closely logistic regression can match the true value. To minimize this KL divergence, ideally we would like to choose our weights so that $D_{KL}(P_i||Q_i)=0$. This is impossible for two reasons. First, if we want $D_{KL}(P_i||Q_i)=0$, we need $p_i=y_i$, which is impossible because $p_i$ is the output of a logistic function that can never reach 0 or 1. Second, even if we tuning the weights so that $D_{KL}(P_i||Q_i)=0$, that's only optimizing one of the data points - we need to tune the weights so that we can collectively minimize the totality of all the $KL$ divergences contributed by all data points.

Our goal is to tune the weights $w$ (which indirectly affect the $p_i$ values and therefore the estimated distribution $Q_i$), in order to minimize the total sum of KL divergences contributed by all data points:

```
$w_{LR} = \arg\min_w \sum_{i=1}^n D_{KL}(P_i||Q_i)\n= \arg\min_w \sum_{i=1}^n y_i \ln\frac{y_i}{p_i} + (1-y_i) \ln\frac{1-y_i}{1-p_i}\n= \arg\min_w \sum_{i=1}^n y_i(y_i - \ln p_i) + (1-y_i)(\ln(1-y_i) - \ln(1-p_i))\n= \arg\min_w \sum_{i=1}^n (-y_i \ln p_i - (1-y_i) \ln(1-p_i)) + (y_i \ln y_i + (1-y_i) \ln(1-y_i))\n= \arg\min_w \sum_{i=1}^n y_i \ln p_i + (1-y_i) \ln(1-p_i)$
```

Note that the $y_i \ln y_i + (1-y_i) \ln(1-y_i)$ component of the KL divergence is a constant, independent of our changes to $p_i$. We are effectively minimizing the sum of the **cross entropies** $H(P_i, Q_i)$. We conclude our discussion of KL divergence by noting the relation between KL divergence and entropy:

$D_{KL}(P_i||Q_i) = H(P_i, Q_i) - H(P_i)$

Where $D_{KL}(P_i||Q_i)$ is the KL divergence from $Q_i$ to $P_i$, $H(P_i, Q_i)$ is the cross entropy between $P_i$ and $Q_i$, and $H(P_i)$ is the **entropy** of $P_i$. Intuitively, we can think of entropy as the expected amount of “surprise” of a distribution. Mathematically, we have

```
$H(P) = \sum_x -P(x) \ln P(x) = \sum_x P(x) \ln\frac{1}{P(x)} = \mathbb{E}_P[\ln\frac{1}{P(x)}]$
```
