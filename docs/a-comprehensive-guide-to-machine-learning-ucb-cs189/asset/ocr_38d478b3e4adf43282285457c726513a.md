$\mathbf{X}^T(\mathbf{X}\mathbf{v} + \lambda v) = \mathbf{X}^T\mathbf{y}$

We can't isolate $v$ and have a closed-form solution for it, but we *can* make the observation if we found an $v$ such that we had

$\mathbf{X}^T\mathbf{v} + \lambda v = 
u$

would *imply* that this $v$ also satisfies the above equation. Note that we did not *cancel* the $\mathbf{X}^T$s on both sides of the equation. We saw that having $v$ satisfy one equation implied that it satisfied the other as well. So, indeed, we can isolate $v$ in this new equation:

$\mathbf{X}^T(\mathbf{X} + \lambda I)\mathbf{v} = 
u \implies \mathbf{v}^* = (\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}
u$

and have that the $V$ which satisfies this equation will be that $\mathbf{X}^T\mathbf{v}$ equals $
u$. We conclude that the optimal $\mathbf{w}$ is

$\mathbf{w}^* = \mathbf{X}^T\mathbf{v}^* = \mathbf{X}^T(\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}
u$

Recall that we previously derived ridge regression and ended up with
\n$\mathbf{w}^* = (\mathbf{X}^T\mathbf{X} + \lambda I)^{-1}\mathbf{X}^T\mathbf{y}$

In fact, these are two equivalent expressions! The question that arises is which expression should you pick? Which is more *efficient* to calculate? We will answer this question after we introduce kernels.

# Linear Algebra Derivation

The previous derivation involved using some intuitive manipulations to achieve the desired result. Let's formalize our derivation using more principled arguments from linear algebra and optimization (FTLA): Before we do, we must first introduce the **Fundamental Theorem of Linear Algebra** That that a matrix (linear map) $X$ maps $\mathbb{R}^d$ to $\mathbb{R}^n$. $\mathcal{N}(\mathbf{X})$ is the nullspace of $\mathbf{X}$, and $\mathcal{R}(\mathbf{X})$ is the range of $\mathbf{X}$. Then the following properties hold:

+   1. $\mathcal{N}(\mathbf{X}) \perp \mathcal{R}(\mathbf{X}^T) = \mathbb{R}^d$ and $\mathcal{N}(\mathbf{X}^T) \perp \mathcal{R}(\mathbf{X}) = \mathbb{R}^n$ by symmetry

+   2. $\mathcal{N}(\mathbf{X}^T) = \mathcal{R}(\mathbf{X})$ and $\mathcal{N}(\mathbf{X}) = \mathcal{R}(\mathbf{X}^T)$ by symmetry

+   3. $\mathcal{R}(\mathbf{X}) = \mathcal{R}(\mathbf{X}^T)$ and $\mathcal{R}(\mathbf{X}^T) = \mathcal{R}(\mathbf{X})$ by symmetry.

The symbol $\perp$ indicates that taking a *direct sum* of $\mathcal{N}(\mathbf{X})$ and $\mathcal{R}(\mathbf{X}^T)$, which means that $u \in \mathbb{R}^d$ there exist unique elements $u_1 \in \mathcal{N}(\mathbf{X})$ and $u_2 \in \mathcal{R}(\mathbf{X}^T)$ such that $u = u_1 + u_2$. Furthermore, $\mathcal{N}(\mathbf{X})$ and $\mathcal{R}(\mathbf{X}^T)$ are orthogonal subspaces.

Here is where FTLA comes in in the context of ridge regression. We can express any $\mathbf{w} \in \mathbb{R}^d$ as a unique combination $\mathbf{w} = \mathbf{w}_1 + \mathbf{w}_2$, where $\mathbf{w}_1 \in \mathcal{R}(\mathbf{X}^T)$ and $\mathbf{w}_2 \in \mathcal{N}(\mathbf{X})$. We can express this as $\mathbf{w} = \mathbf{X}^T\mathbf{v} + \mathbf{r}$, where $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathcal{N}(\mathbf{X})$. Instead, of optimizing over $\mathbf{w} \in \mathbb{R}^d$, we can optimize over $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathbb{R}^l$, which equates to optimizing over $n+l$ variables. However, as we see, the optimization over will be trivial since we just have to optimize an $n$ dimensional problem

We know that $\mathbf{w}^* = \mathbf{X}^T\mathbf{v}^* + \mathbf{r}$, where $\mathbf{v} \in \mathbb{R}^n$ and $\mathbf{r} \in \mathcal{N}(\mathbf{X})$. Let's solve ridge regression by optimizing over the variables $\mathbf{v}$ and $\mathbf{r}$ in stead of:

```
$\mathbf{v}^*, \mathbf{r}^* = \arg\min_{\mathbf{v} \in \mathbb{R}^n, \mathbf{r} \in \mathcal{N}(\mathbf{X})} ||\mathbf{X}^T\mathbf{w} - \mathbf{y}||_2^2 + \lambda ||\mathbf{w}||_2^2$
```
