# CHAPTER 4. GRADIENT DESCENT, NEWTON'S METHOD

Note that we have used the Jacobian of the linearized function $\hat{F}$, evaluated at $	heta$, is precisely $J(	heta^{(k)})$. This is because $\hat{F}$ is affine when the linear map is $J(	heta^{(k)})$, so the best linear approximation is just that.

Writing $J = J(	heta^{(k)})$ for brevity, we have

```
$J^T Y = J^T F(	heta^{(k)}) + J^T \Delta Y$$
$$J^T(Y - F(	heta^{(k)})) = J^T \Delta Y$$
$$\Delta	heta = (J^T J)^{-1}(Y - F(	heta^{(k)}))$$
$$(J^T J)^{-1}\Delta Y$
```

where $\Delta Y := Y - F(	heta^{(k)})$. By comparing this solution to OLS, we see that it is effectively solving

```
$\Delta\theta = \arg \min_{\theta} ||\J\theta - \Delta Y||^2$
```

Since $\hat{F} \approx J\Delta	heta$ over $	heta^{(k)}$, this is saying that we choose a change to the weights that corrects the current error in the function values, but it is this calculation on the linearization of $F$. Recalling that $\Delta	heta = 	heta - 	heta^{(k)}$, we can improve our current guess $	heta^{(k)}$ with the update

```
$\theta^{(k+1)} = \theta^{(k)} + \Delta\theta$$
$\theta^{(k+1)} = \theta^{(k)} + (J^T J)^{-1}J^T \Delta Y$
```

Here's the entire process laid out in steps:

+   Initialize $	heta^{(0)}$ with some guess
Repeat until convergence:
  (a) Compute Jacobian with respect to the current iterate, $J = J(	heta^{(k)})$
  (b) Compute $\Delta Y = Y - F(	heta^{(k)})$
  (c) Update: $	heta^{(k+1)} = 	heta^{(k)} + (J^T J)^{-1}\Delta Y$

Note that the solution found will depend on the initial value $	heta^{(0)}$ in general. Some choices include testing changes in the objective value:

```
$|\frac{\theta^{(k+1)} - \theta^{(k)}}{\theta^{(k)}}| \lele$ threshold
```

or in the iterates themselves:

```
$max |\frac{\Delta\theta_j}{\theta^{(k)}}| \le$ threshold
```
