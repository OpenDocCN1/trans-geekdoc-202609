## 2.4. MULTIVARIATE GAUSSIANS

Now let's take a Riemann sum to find the probability that Z takes a value in T(R’):

```
$P(\mathbf{Z} \subseteq T(\mathbf{R}')) = \int_{T(\mathbf{R}')} f_{\mathbf{Z}}(z_1, z_2) \ dz_1 dz_2$
$$\approx \sum_{T(\mathbf{R}')} f_{\mathbf{Z}}(\mathbf{Ru}) \ \Delta A$$
$$\sum \sum_{\mathbf{R}'} f_{\mathbf{Z}}(\mathbf{Ru}) |det(\mathbf{R}')| \Delta u_1 \Delta u_2$$
```

The change of variables in the last step: we sum over the squares in U space, instead of parallelograms in R space.

So far, we have shown that (for any dimension n)

```
$P(\mathbf{U} \subseteq \mathbf{R}') = \int_{\dots} \int_{\mathbf{R}'} f_{\mathbf{U}}(\mathbf{u}) du_1 du_2 \dots du_n$
$P(\mathbf{Z} \subseteq T(\mathbf{R}')) = \int_{\dots} \int_{\mathbf{R}'} f_{\mathbf{Z}}(\mathbf{Ru}) |det(\mathbf{R})| du_1 du_2 \dots du_n$
```

Notice that these two probabilities are equivalent! The probability that U values in R’ must equal the probability that the transformed random vector Z takes a value in the transformed region T(R’).

Therefore, we can say

```
$P(\mathbf{U} \subseteq \mathbf{R}') = \int_{\dots} \int_{\mathbf{R}'} f_{\mathbf{U}}(\mathbf{u}) du_1 du_2 \dots du_n$
$$= \int_{\dots} \int_{\mathbf{R}'} f_{\mathbf{Z}}(\mathbf{Ru}) |det(\mathbf{R})| du_1 du_2 \dots du_n$
$$= P(\mathbf{Z} \subseteq T(\mathbf{R}'))$
```

We conclude that

```
$f_{\mathbf{U}}(\mathbf{u}) = f_{\mathbf{Z}}(\mathbf{Ru}) |det(\mathbf{R})|$
```

An identical argument allows us to state that

```
$f_{\mathbf{Z}}(\mathbf{z}) = f_{\mathbf{U}}(\mathbf{R}^{-1}\mathbf{z}) |det(\mathbf{R}^{-1})| = \frac{1}{|det(\mathbf{R})|} f_{\mathbf{U}}(\mathbf{R}^{-1}\mathbf{z})_i$
```

Since densities for all $U_i$ are i.i.d, and $U = \mathbf{R}^{-1}\mathbf{Z}$, we can write the joint density function of Z as

```
$f_{\mathbf{Z}}(\mathbf{z}) = \frac{1}{|det(\mathbf{R})|} \prod_{i=1}^n f_{\mathbf{U}}(\mathbf{R}^{-1}\mathbf{z})_i$
= \frac{1}{|det(\mathbf{R})|} (\sqrt{2\pi})^n$
= \frac{1}{|det(\mathbf{R})|} (\sqrt{2\pi})^n e^{-\frac{1}{2}\mathbf{z}^T\mathbf{R}^T\mathbf{R}^{-1}\mathbf{z}}$
```

Note that $(\mathbf{RR}^T)^{-1}$ is the covariance matrix for **Z**:

$Cov[Z] = E[ZZ^T] = RE[UU^T]R^T = \mathbf{RR}^T$

Thus the density function of **Z** can be written as

$f_Z(\mathbf{z}) = \frac{1}{|\det(\mathbf{R})|(\sqrt{2\pi})^n} e^{-\frac{1}{2}\mathbf{z}^T\Sigma_Z}$

Furthermore, we know that

$|det(\Sigma_Z)| = |det(R^T)| = |det(R) \cdot det(R^T)| = |det(R)|^2$

and therefore

## 2.5 MLE with Dependent Noise

Up to this point, we have been able to easily view regression problems from an optimization perspective. In the context of dependent noise however, it is much easier to view the problem from a probabilistic perspective. Note as before that:

$\mathbf{y} = \mathbf{Xw} + \mathbf{Z}$

Where **Z** is now a jointly Gaussian vector. $\mathbf{Z} \sim \mathcal{N}(\mathbf{0}, \Sigma_Z)$, and $\mathbf{y} \sim \mathcal{N}(\mathbf{Xw}, \Sigma_Z)$.

$\mathbf{w}^* = \arg \max_{\mathbf{w} \in \mathbb{R}^n} \frac{1}{\sqrt{\det(\Sigma_Z)}}(\sqrt{2\pi})^n} e^{-\frac{1}{2}(\mathbf{y}-\mathbf{Xw})^T\Sigma_Z^{-1}(\mathbf{y}-\mathbf{Xw})} \quad (2.1)$

$\arg \min_{\mathbf{w} \in \mathbb{R}^n} (\mathbf{y}-\mathbf{Xw})^T\Sigma_Z^{-1}(\mathbf{y}-\mathbf{Xw}) \quad (2.2)$

Note that $\Sigma_Z$ is symmetric, which means it has a good eigen structure, we can interpret it geometrically. $\Sigma_Z$ can be written as

$\Sigma_Z = \mathbf{Q} \begin{pmatrix} \sigma_1^2 & 0 & \dots & 0 \\ 0 & \sigma_2^2 & \dots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \sigma_n^2 \end{pmatrix} \mathbf{Q}^T$

where **Q** is orthonormal. This means a multivariate Gaussian can be thought of having its level sets by the ellipsoid axis given by **Q** and amount of stretch given by $\sigma$.

Let

$\mathbf{R}_Z = \sqrt{\Sigma_Z} = \mathbf{Q} \begin{pmatrix} \sigma_1 & 0 & \dots & 0 \\ 0 & \sigma_2 & \dots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \sigma_n \end{pmatrix}$

## 2.6 MAP WITH COLORED NOISE

As before, we can scale the data to morph the problem into an MLE problem, very similar to the independent noise problem, the MLE of the dependent noise problem is $\mathbf{w}^* = (\mathbf{X}^T\Sigma_Z^{-1}\mathbf{X})^{-1}\mathbf{X}^T\Sigma_Z^{-1}\mathbf{y}$.

In the ordinary squares (OLS) statistical model, we assume that the output is a linear function of the input plus noise:

$\mathbf{Y} = \mathbf{XW} + \mathbf{Z}$

where $\mathbf{Y}$ and $\mathbf{Z}$ are $n$-dimensional random vectors, and $\mathbf{X}$ is a $n \times d$ matrix.

We have seen that ridge regression can be derived by assuming a prior on **W** in which $W_i$ are i.i.d Gaussian, $\mathbf{W} \sim \mathcal{N}(0, I)$. But more generally, we can allow **W** to be any multivariate Gaussian: $\mathbf{W} \sim \mathcal{N}(\mu_W, \Sigma_W)$.

Recall that we can rewrite a multivariate Gaussian as an affine transformation of a standard Gaussian:

$\mathbf{W} = \Sigma_W^{1/2}\mathbf{v} + \mu_W \quad \mathbf{v} \sim \mathcal{N}(0, I)$

This change of variable is sometimes called the **reparameterization trick**. Plugging in this parameterization into our statistical model gives:

$\mathbf{Y} = \mathbf{X}(\Sigma_W^{1/2}\mathbf{v} + \mu_W) + \mathbf{Z}$

But this can be re-written

$\mathbf{Y} - \mathbf{X}\mu_W = \mathbf{X}\Sigma_W^{1/2}\mathbf{v}$

which we see has the form of the statistical problem that underlies OLS, and therefore

$\hat{\mathbf{v}} = (\Sigma_W^{1/2}\mathbf{X}^T\Sigma_W^{1/2})^{-1}\Sigma_W^{1/2}\mathbf{X}^T(\mathbf{Y}-\mathbf{X}\mu_W)$

However V is not what we want - we need to connect back to the actual weights **W** in order to make predictions. Since **W** is completely determined by **V** (assuming fixed mean and covariance),

$\hat{\mathbf{w}} = \Sigma_W^{1/2}\hat{\mathbf{v}} + \mu_W$
$= \mu_W + \Sigma_W^{1/2}(\Sigma_W^{1/2}\mathbf{X}^T\Sigma_W^{1/2}+\mathbf{I})^{-1}\Sigma_W^{1/2}\mathbf{X}^T(\mathbf{Y}-\mathbf{X}\mu_W)$
$= \mu_W + (\mathbf{X}^T+\Sigma_W^{-1/2}\mathbf{X}^T\Sigma_W^{-1/2})^{-1}\mathbf{X}^T(\mathbf{Y}-\mathbf{X}\mu_W)$
