
## 6.5 LDA VS. QDA: DIFFERENCES AND DECISION BOUNDARIES

![](img/99defe26aebed215976e83d281581f33_88_0.png)

Figure 6.2: Two anisotropic, identically distributed Gaussians in $\mathbb{R}^2$. The ellipses are the level sets of the Gaussians.

When the two classes are anisotropic distributions can be reduced to the isotropic case simply by performing a change of coordinates that transforms the ellipses back into circles. Thus, the decision boundary is still linear.

### Identical Distributions with Priors

Now, let's find the decision boundary when the two classes still have identical covariances but are not necessarily equal in prior

```
$Q_A(\mathbf{x}) = Q_B(\mathbf{x})$
$\ln(P(A)) - \frac{1}{2}(\mathbf{x}-\mu_A)^T\Sigma_A^{-1}(\mathbf{x}-\mu_A) - \frac{1}{2}\ln(|\Sigma_A|) = \ln(P(B)) - \frac{1}{2}(\mathbf{x}-\mu_B)^T\Sigma_B^{-1}(\mathbf{x}-\mu_B)$
$- \frac{1}{2}\ln(|\Sigma_B|)$
$\ln(P(A)) - \frac{1}{2}(\mathbf{x}-\mu_A)^T\Sigma_A^{-1}(\mathbf{x}-\mu_A) = \ln(P(B)) - \frac{1}{2}(\mathbf{x}-\mu_B)^T\Sigma_B^{-1}(\mathbf{x}-\mu_B)$
$2\ln(P(A)) - 2\mathbf{x}^T\Sigma_A^{-1}\mu_A - \mu_A^T\Sigma_A^{-1}\mu_A = 2\ln(P(B)) - 2\mathbf{x}^T\Sigma_B^{-1}\mu_B - \mu_B^T\Sigma_B^{-1}\mu_B$
$2\ln(P(A)) + 2\mathbf{x}^T\Sigma_A^{-1}(\mu_B-\mu_A) - \mu_A^T\Sigma_A^{-1}\mu_A + \mu_B^T\Sigma_B^{-1}\mu_B = 2\mathbf{x}^T\Sigma_B^{-1}(\mu_B$
```

Simplifying, we have that

```
$\mathbf{x}^T(\Sigma_A^{-1}-\Sigma_B^{-1})(\mu_A-\mu_B) + (\ln(\frac{P(A)}{P(B)}) - \frac{\mu_A^T\Sigma_A^{-1}\mu_A - \mu_B^T\Sigma_B^{-1}\mu_B}{2}) = 0$
```

The decision boundary is the level set of a linear function $f(\mathbf{x}) = \mathbf{w}^T\mathbf{x}+k$. Notice the pattern: the decision boundary is always the level set of a linear function (which itself is linear) as long as the two class conditional probability distributions share the same covariance matrices. This is the reason for why LDA has a linear decision boundary.

### Nonidentical Distributions

This is clearly *not* the case in LDA. We have that:

```
$$\ln(P(A)) - \frac{1}{2}(\mathbf{x}-\mu_A)^T\Sigma_A^{-1}(\mathbf{x}-\mu_A) = \ln(P(B)) - \frac{1}{2}(\mathbf{x}-\mu_B)^T\Sigma_B^{-1}(\mathbf{x}-\mu_B)$$$
```

Here, unlike the case when $\Sigma_A = \Sigma_B$, we *cannot* cancel the quadratic terms in $\mathbf{x}$ from both sides of the equation, and thus our decision boundary is now represented by the level set of an arbitrary quadratic function.

It should now make sense why QDA is short for **quadratic** discriminant analysis and LDA is short for **linear** discriminant analysis!

### Generalizing to Multiple Classes

The quadratic nature of the decision boundary in QDA and the linear nature of the decision boundary in LDA will still apply to the general case when there are more than two classes. The following excellent figures from Professor Shewchuk's *notes* illustrate this point:

## 6.6 Discriminative Models

In our discussion of LDA and QDA, we focused on **generative models**, where we explicitly model the probability of the data $P(X, Y)$ and choose the class $c^*$ that maximizes the probability: $c^* = \arg\max_c P(Y=c|X)$. For example, in QDA we model $P(X|Y=c)$ as a Gaussian with an estimated mean $\mu_c$ and covariance matrix $\Sigma_c$. If we choose a prior $P(Y)$, then our predicted class for a new test point $x$ is:

```
$c^* = \arg\max_c P(Y=c|X=x) = \arg\max_c P(X=x|c)P(Y=c)$
```

The generative approach is flexible and we can actually use our model to generate samples. However, LDA and QDA can be inefficient because they require estimation of a large number of parameters (covariance matrices, which have $\frac{d(d+1)}{2}$ parameters). For 2-class LDA, the decision boundary is of form

```
$$\mathbf{w}^T\mathbf{x} + k = 0$$
```

LDA is an indirect approach to classification - it estimates parameters for $P(X|Y)$ and uses Bayes' rule to compute a decision boundary, which leads to the discrepancy between the number of parameters required to specify the model and the number of parameters required to perform classification. This leads us to the concept of discriminative models, where we bypass learning a generative model and directly learn a decision boundary. The process of constructing a discriminative model is composed of two key choices:

- Representation: how we represent the output of the model (for example, the output of model could be any real-valued number to threshold to perform classification, or represent a probability)
- Loss function: how we train and penalize errors

## 6.7 Least Squares Support Machine

### Model and Training

As first example of a discriminative model, we discuss the Least Squares Support Machine (LS-VM). Consider the binary classification problem where the classes are represented by $-1$ and $+1$. One way to classify a data point $x$ is to estimate parameters $w$, compute $w^T\mathbf{x}$, and classify $x$ by $\text{sign}(w^T\mathbf{x})$. Geometrically, the decision boundary here is a hyperplane $w^T\mathbf{x}=0$.

We need to figure out how to optimize the parameter $w$. One simple procedure we try is to fit a least squares objective:

```
$$\arg min_{w} \sum_{i=1}^{n} ||y_i - w^T\mathbf{x}_i||^2 + \lambda||w||^2$$
```

Where $x_i, w \in \mathbb{R}^{d+1}$. Note that we have not forgotten the bias term! Even though we are dealing with $d$ dimensional data, $x_i$ and $w$ are $d+1$ dimensional: we add an extra "feature" of 1 to $\mathbf{x}$, and a corresponding bias term of $k$ in $w$. In practice, we do not want to penalize the bias term in the regularization term because we should be able to work with any affine transformation of the data and end up with the same decision boundary. Therefore, rather than taking the norm of $w$, we often take the norm of $w'$, which is every term of $w$ excluding the bias term. For simplicity of notation, this would be equivalent to minimizing the number of misclassified training points. Unfortunately, optimizing this is NP-hard (computationally intractable). However, we can solve a relaxed version of this problem:

```
$$\arg min_{w} \sum_{i=1}^{n} ||y_i - w^T\mathbf{x}_i||^2 + \lambda||w||^2$$
```

This method is the 2-class least squares support machine (LS-VM). Note that in this relaxed version, we care about the magnitude of $w^T\mathbf{x}_i$ and not just the sign.

One drawback of LS-SVM is that the hyperplane decision boundary it computes does not necessarily make sense for the sake of classification. For example, consider the following set of data points, color-coded according to the class:

### Feature Extension

Working with linear classifiers in the raw feature space may be extremely limiting, so we may consider adding features that allow us to come up with nonlinear classifiers (note that we are still working with linear classifiers in the augmented feature space). For example, adding quadratic features allows us to find a linear decision boundary in the augmented quadratic space that corresponds to a nonlinear "circle" decision boundary projected down into the raw feature space.

![](img/99defe26aebed215976e83d281581f33_92_0.png)

Figure 6.6: Augmenting Features, image courtesy of [Prof. Shewchuk](https://github.com/sshewchuk)

In order to implement this idea, we re-express our objective as

```
$$\arg min_{w} \sum_{i=1}^{n} |y_i - \mathbf{w}^T\phi(\mathbf{x}_i)||^2 + \lambda||w||^2$$
```

Note that $\phi$ is a function that takes as input the data in raw feature space, and outputs the data in augmented feature space.

### Neural Network Extension

Instead of using the linear function $\mathbf{w}^T\mathbf{x}$ or augmenting features to the data, we can directly use a non-linear function of choice in the original feature space, such as a neural network. One can imagine a whole of discriminative binary classifiers that minimize

```
$$\arg min_{w} \sum_{i=1}^{n} |y_i - g_w(\mathbf{x}_i)||^2 + \lambda||w||^2$$
```

where $g_w(\mathbf{x}_i)$ can be any function that is easy to optimize. Then we can classify using rule

```
$y_i = \begin{cases} 1 & g_w(\mathbf{x}_i) > 0 \ -1 & g_w(\mathbf{x}_i) \le 0 \end{cases}$$
```

Where $\theta$ is some threshold. In LS-SVM, $g_w(\mathbf{x}_i) = \mathbf{x}_i^T\mathbf{w}$ and $\theta = 0$. Using a neural network with non-linearities as $g_w$ can produce complex, non-linear decision boundaries.
