Verify that the other KKT also hold, establishing strong duality. Using these observations, we can eliminate some terms of the dual problem.

```
\mathcal{L}(w, t, \xi, \alpha^*, \beta^*) = \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i - t) + \sum_{i=1}^n \alpha_i^* + \sum_{i=1}^n (C - \alpha_i^* - \beta_i^*) \xi_i\n= \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i) + \sum_{i=1, s=0}^n \alpha_i^* y_i + \sum_{i=1, s=0}^n (C - \alpha_i^* - \beta_i^*) \xi_i\n= \frac{1}{2}|w|^2 - \sum_{i=1}^n \alpha_i^* y_i(w^T x_i) + \sum_{i=1}^n \alpha_i^*
```

We can rewrite the optimal primal variables $w^*, t^*, \xi^*$ in terms of the dual variables $\alpha_i^*$:

```
$g(\alpha^*, \beta^*) = \min_{w,t,\xi,\alpha^*} \mathcal{L}(w,t,\xi,\alpha^*,\beta^*)\n= \mathcal{L}(w^*,t^*,\xi^*,\alpha^*,\beta^*)\n= \frac{1}{2}\sum_{i=1}^n \alpha_i^* y_ix_i^2 - \sum_{i=1}^n\sum_{j=1}^n \alpha_i^* y_i((\alpha_j^* y_j x_j)^T x_i) + \sum_{i=1}^n \alpha_i^*\n= \frac{1}{2}\sum_{i=1}^n \alpha_i^* y_ix_i^2 - \sum_{i=1}^n\sum_{j=1}^n \alpha_i^* y_ix_i^T(\alpha_j^* y_jx_j)) + \sum_{i=1}^n \alpha_i^*\n= \alpha^{*T} 1 - \frac{1}{2}\alpha^{*T} Q\alpha^*$
```

where $Q_{ij} = y_i(x_i^T x_j)y_j$ and $(Q = (	ext{diag } y)XX^T(	ext{diag } y))$.\nNow, we can write the final form of the dual, which is only in terms of $\alpha$ and $x$ and $y$ (Note that we have eliminated references to $\beta$):

```
\max_{\alpha} \alpha^T 1 - \frac{1}{2}\alpha^T Q\alpha\ns.t. \sum_{i=1}^n \alpha_i y_i = 0\n0 \le \alpha_i \le C \quad i = 1, \dots, n
```

# Geometric intuition

We've seen that the optimal value of the dual problem in terms of $\alpha$ is equivalent to the optimal value of the primal problem in terms of $w, t$, and $\xi$. But what do these dual values $\alpha$ even mean? That's a good question!

We know that the following KKT conditions are enforced:

+   - Stationarity
$C - \alpha_i^* - \beta_i^* = 0$

+   - Complementary slackness
$\alpha_i^* \cdot ((1 - \xi_i^*) - y_i(w^{*T} x_i - t^*)) = 0$
