# 1.7 KERNEL TRICK

Each entry $\Phi_{ij}^*$ is a dot product between $\phi(\mathbf{x}_i)$ and $\phi(\mathbf{x}_j)$ and can be interpreted as a similarity measure:

```
$$\Phi_{ij} = \langle\phi(\mathbf{x}_i), \phi(\mathbf{x}_j)\rangle = k(\mathbf{x}_i, \mathbf{x}_j)$
```

where $k(\., .)$ is the **kernel** function. The kernel function takes raw-feature inputs and outputs their inner product in the augmented feature space. We define the matrix of $k(\mathbf{x}_i, \mathbf{x}_j)$ terms as the **Gram matrix** and denote it as K:

```
$$\mathbf{K} = \mathbf{\Phi}^T\mathbf{\Phi} = \begin{pmatrix} k(\mathbf{x}_1, \mathbf{x}_1) & k(\mathbf{x}_1, \mathbf{x}_2) & \dots \ k(\mathbf{x}_2, \mathbf{x}_1) & k(\mathbf{x}_2, \mathbf{x}_2) & \dots \ \vdots & \vdots & \vdots \ k(\mathbf{x}_n, \mathbf{x}_1) & k(\mathbf{x}_n, \mathbf{x}_2) & \dots \end{pmatrix}$
```

Formally, $k(\mathbf{x}_1, \mathbf{x}_2)$ is defined to be a valid kernel if there exists a feature map $\phi(\cdot)$ such that $\forall\mathbf{x}_2$,

```
$k(\mathbf{x}_1, \mathbf{x}_2) = \langle\phi(\mathbf{x}_1), \phi(\mathbf{x}_2)\rangle$
```

Equivalently, we can also say that for all sets $D=\{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_n\}$, the Gram matrix $K(D)$ is PSD.

Computing the Gram matrix $k(\mathbf{x}_i, \mathbf{x}_j)$ can be done in a straightforward fashion if we apply the feature map to $\mathbf{x}$ and $\mathbf{x}$, and then take their dot product in the augmented feature space — this takes $O(d)$ time, where $d$ is the dimensionality of the problem in the augmented feature space. However, if we use the **kernel trick**, we can perform this operation in $O(l + \log p)$ time, where $l$ is the dimensionality of the problem in the raw feature space and $p$ is the degree of the polynomials in the augmented feature space.

# 1.7 Kernel Trick

Suppose that we compute $k(\mathbf{x}, \mathbf{z})$ using a $p$-degree polynomial feature map that maps $l$ dimensional inputs to $d=O(p^l)$ dimensional outputs. Let's take $p=2$ and $l=2$ as an example. We have

```
$k(\mathbf{x}, \mathbf{z}) = \langle\phi(\mathbf{x}), \phi(\mathbf{z})\rangle$
```

```
$= \begin{pmatrix} x_1^2 & \sqrt{2}x_1x_2 & \sqrt{2}x_1 \ \sqrt{2}x_1x_2 & x_2^2 & \sqrt{2}x_2 \ \sqrt{2}x_1 & \sqrt{2}x_2 & 1 \end{pmatrix} \begin{pmatrix} z_1^2 & \sqrt{2}z_1z_2 & \sqrt{2}z_1 \ \sqrt{2}z_1z_2 & z_2^2 & \sqrt{2}z_2 \ \sqrt{2}z_1 & \sqrt{2}z_2 & 1 \end{pmatrix}^T$
$= x_1^2z_1^2 + 2x_1x_2z_1z_2 + 2x_1z_1 + 2x_2z_2 + x_2^2z_2^2 + 1$
$= (x_1z_1 + x_2z_2 + 1)^text{...})^2 + 2(x_1z_1 + x_2z_2) + 1$
$= (\mathbf{x}^T\mathbf{z})^2 + 2\mathbf{x}^T\mathbf{z} + 1$
$= (\mathbf{x}^T\mathbf{z} + 1)^2$
```

We can compute $k(\mathbf{x}, \mathbf{z})$ either by

+   1. Raising the inputs to the augmented feature space and take their inner product of the raw-feature inputs
2. Computing ($\mathbf{x}^T\mathbf{z} + 1)^2$, which involves an inner product of the raw-feature inputs

Clearly, the latter option is much cheaper to calculate, taking $O(l + \log p)$ time, instead of $O(p^l)$ time. In fact, this generalizes for any arbitrary $l$ and $p$, and for $p$-degree polynomial features, we have that

```
$k(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z} + 1)^p$
```
