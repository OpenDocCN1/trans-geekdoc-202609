The kernel trick makes computations significantly cheaper to perform, making kernelization much more appealing! The takeaway here is no matter what the degree $p$ is, the computational complexity is the same — it is only dependent on the dimensionality of the raw feature space!

# Computational Analysis

Back to the original question — in ridge regression, should we compute

```
$\mathbf{w}^* = \Phi^T(\Phi\Phi^T + \lambda I)^{-1}\mathbf{y}$
```

or

```
$\mathbf{w}^* = (\Phi\Phi^T + \lambda I)^{-1}\Phi^T\mathbf{y}$
```

Let's compare their computational complexities. Suppose are given an arbitrary test point $z \in \mathbb{R}^d$, and you would like to compute its predicted value $\hat{\mathbf{y}}$. Let's see how these values are calculated in each case:

+   1. Kernelized

```
$\hat{\mathbf{y}} = \langle\phi(z), \mathbf{w}^*\rangle = \phi(z)^T(\Phi\Phi^T + \lambda I)^{-1}\mathbf{y} = [k(x_1, z) \quad \dots \quad k(x_n, z)]^T(\mathbf{K} + \lambda I)^{-1}\mathbf{y}$
```

Computing the $\mathbf{K}$ term takes $O(n^2(l + \log p))$, and inverting the matrix takes $O(n^3)$. These two computations dominate, for a total computation time of $O(n^3 + n^2(l + \log p))$.

+   2. Non-kernelized

```
$\hat{\mathbf{y}} = \langle\phi(z), \mathbf{w}^*\rangle = \phi(z)^T(\Phi\Phi^T + \lambda I)^{-1}\Phi^T\mathbf{y}$
```

Computing the $\Phi\Phi^T$ term takes $O(nd^2)$, and inverting the matrix takes $O(d^3)$. These two computations dominate, for a total computation time of $O(d^3 + d^2n)$.

Here is the takeaway: if $d \ll n$, the non-kernelized method is preferable. Otherwise if $n \ll d$, the kernelized method is preferable.
