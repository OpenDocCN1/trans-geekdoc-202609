# 3. Dual feasibility

$\lambda_i \ge 0, \forall i \in [1, m]$

# 4. Complementary Slackness

$\lambda_i f_i(x) = 0, \forall i \in [1, m]$

# 5. Stationarity

$
abla_x f_0(x) + \sum_{i=1}^m \lambda_i \nabla_x f_i(x) + \sum_{j=1}^n \nu_j \nabla_x h_j(x) = 0$

Let's see how the KKT conditions relate to strong duality.

**Theorem 1.** If $x^*$ and $\lambda^*, \nu^*$ are the primal and dual solutions respectively, with zero duality gap (i.e. strong duality), then $x^*, \lambda^*, \nu^*$ also satisfy the KKT conditions.

Proof. KKT conditions 1, 2, 3 are trivially true, because the primal solution $x^*$ must satisfy the primal constraints, and the dual solution $
u^*$ must satisfy the dual constraints. Now, let's prove conditions 4 and 5. We know that since strong duality holds, we can say that

```
$p^* = f_0(x^*) = d^*\n= \min \mathcal{L}(x, \lambda^*, \nu^*)\n\le \mathcal{L}(x^*, \lambda^*, \nu^*)\n= f_0(x^*) + \sum_{i=1}^m \lambda_i^* f_i(x^*) + \sum_{j=1}^n \nu_j^* h_j(x^*)\n= f_0(x^*) + \sum_{i=1}^m \lambda_i^* f_i(x^*)\n\le f_0(x^*)$
```

In the fourth step, we can cancel the terms involving $h_j(x^*)$ because we know that the primal solution must satisfy $h_j(x^*) = 0$. In the fifth step, we know that $\lambda_i^* f_i(x^*) \le 0$, because $\lambda_i^* \ge 0$ in order to satisfy the dual constraints and to order the primal constraints. Since we established that $f_0(x^*) = \min \mathcal{L}(x, \lambda^*, \nu^*) \le \mathcal{L}(x^*, \lambda^*, \nu^*) = f_0(x^*)$, we know that all of the inequalities hold with equality and therefore $\mathcal{L}(x^*, \lambda^*, \nu^*) = \min_x \mathcal{L}(x, \lambda^*, \nu^*)$. This implies KKT condition 5 (stationarity),

$
abla_x f_0(x^*) + \sum_{i=1}^m \lambda_i^* \nabla_x f_i(x^*) + \sum_{j=1}^n \nu_j^* \nabla_x h_j(x^*) = 0$

Finally, not that due to the equality $f_0(x^*)+\sum_{i=1}^m \lambda_i^* f_i(x^*) = 0$, we know that $\sum_{i=1}^m \lambda_i^* f_i(x^*) = 0$. This combined with the fact that $\lambda_i^* f_i(x^*) \le 0$, establishes KKT condition 4 (complementary slackness):

$\lambda_i^* f_i(x^*) = 0, \forall i \in [1, m]$

The theorem above establishes that in the presence of strong duality, if the solutions are optimal, then they satisfy the KKT conditions. Let's prove a statement that is almost (but not quite) the converse, which will be much more helpful for solving optimization problems.
