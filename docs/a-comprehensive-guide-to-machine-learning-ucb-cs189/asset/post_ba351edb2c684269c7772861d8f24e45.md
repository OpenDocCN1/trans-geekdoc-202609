## Probabilistic Models in Machine Learning

### 2.1 MLE and MAP

So far, we've explored two approaches of the least squares framework, Ordinary Least Squares and Ridge Regression:

```
$w_{OLS}^* = \arg \min_{\mathbf{w}} ||\mathbf{y} - \mathbf{X}\mathbf{w}||_2^2 = \arg \min_{\mathbf{w}} \sum_{i=1}^n (y_i - \mathbf{x}_i^T\mathbf{w})^2$
```

```
$w_{RIDGE}^* = \arg \min_{\mathbf{w}} ||\mathbf{y} - \mathbf{X}\mathbf{w}||_2^2 + \lambda|\mathbf{w}||_2^2 = \arg \min_{\mathbf{w}} \sum_{i=1}^n (y_i - \mathbf{x}_i^T\mathbf{w})^2 + \lambda \sum_{j=1}^d w_j^2$
```

One question that you may have been asking yourself is why we are using the squared error to measure the effectiveness of our model, and why we use the $l^2$ norm for the model weights (and not other norm). We will justify all of these design choices by exploring the statistical interpretations of supervised learning methods and in particular, regression methods. In more concrete terms, we will use a variety of concepts from probability, such as Gaussians, MLE and MAP, to validate what we have done so far through a different lens.

## Optimization in Model Space

Let's look at a simple regression model:

```
$f(x) = slope \cdot x + intercept$
```

Our goal is to find the optimal slope and intercept values that we believe describe the data. Each arbitrary (slope, intercept) pair pairs a line in data space. However, it can be viewed as a single point in model space. Learning the optimal model amounts to fitting a line to the data points in the data space; it's equivalent to locating the optimal parameter point in the model space:

The data that we observe are random samples with different distributions, coverages, and densities. There are many different distributions that we will encounter, such as Uniform, Gaussian, and Laplacian. Noise distributions in particular are often assumed to be Gaussian, partly because most of the noise is captured within 1 or 2 standard deviations of the mean. Let's state their properties for convenience.

### 2.1 MLE AND MAP

random variable: $X \sim p(x)$

probability distribution: $p(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

mean: $E[X] = \int_{-\infty}^{\infty} xp(x)dx = \mu$

variance: $V[X] = E[(X-\mu)^2] = \int_{-\infty}^{\infty} (x-\mu)^2p(x)dx = \sigma^2$

parameters: $X \sim \mathcal{N}(\mu, \sigma^2)$

log-likelihood: $\log P(X) = \sum \frac{(x-\mu)^2}{2\sigma^2} - \sqrt{2\pi}\sigma$.

linear combinations: $E[aX+bY] = a\mu_x + b\mu_y$

if $X, Y$ are independent: $V[aX+bY] = a^2\sigma_x^2 + b^2\sigma_y^2$
$aX+bY \sim \mathcal{N}(a\mu_x+b\mu_y, a^2\sigma_x^2+b^2\sigma_y^2)$

### MLE and MAP for Model Selection

In the context of regression, (and all of supervised learning for that), we assume a **true underlying model** that maps inputs to outputs. Our goal as machine learning experts is to find a **hypothesis model** that represents the true underlying model, by using the data we are given.

Let's define more concretely our definition of the data and the model. Our data takes consists of $n$ $(x_i, y_i)$ pairs, just as we have seen before:

$$\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n$$

The true underlying model $f$ is a function that maps the inputs $x_i$ to the true outputs $f(x_i)$. Each **observation** $y_i$ is simply a noisy version of $f(x_i)$:

$y_i = f(x_i) + N_i$

Now $f(x_i)$ is a constant, while $N_i$ is a random variable. We always assume that $N_i$ has zero mean, otherwise there would be systematic bias in our observations. The $N_i$ could be Gaussian, Uniform, Laplacian, etc. Here, let us assume that they are **independent and identically distributed (i.i.d)** and Gaussian: $N_i \sim \mathcal{N}(0, \sigma^2)$. We can verify that $y_i|x_i \sim \mathcal{N}(f(x_i), \sigma^2)$.

Now that we have introduced the data, and we wish to find a hypothesis model $h_\theta$ that best describes the data, possibly taking into account prior beliefs that we have about the true model. We can represent this as a probability problem, where the goal is to find the optimal model that maximizes our probability.

### Maximum Likelihood Estimation

In Maximum Likelihood Estimation (MLE), the goal is to find the model that maximizes the probability of the data. If we parametri the set of hypothesis models with $\theta$, we can represent the problem as:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} P(data = \mathcal{D} | \text{true model} = \theta)
```

More concretely:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} P(y_1, \dots, y_n | \mathbf{x}_1, \dots, \mathbf{x}_n, \theta)
```

Note that we actually conditioned on the $\mathbf{x}_i$'s, because we treat them as fixed values. The only randomness in our data comes from the $y_i$'s (since they are noisy versions of the true values $f(\mathbf{x}_i)$). We can simplify this expression by viewing the problem as a graphical model. Note that $y_i$ only depends on its parent in the graphical model, it does not depend on the other $y_j$, since all $y_j$ have independent noise terms. We can then simplify the objective:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} \prod_{i=1}^n P(y_i | \mathbf{x}_i, \theta) = \sum_{i=1}^n \log P(y_i | \mathbf{x}_i, \theta)
```

Now let's focus on each individual term $P(y_i | \mathbf{x}_i, \theta)$. We know that $y_i | \mathbf{x}_i, \theta \sim N(h(\mathbf{x}_i), \sigma^2)$, which is cumbersome to work with because Gaussians have exponential terms. Instead we will use logs, which makes the exponential terms:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} \sum_{i=1}^n \log P(y_i | \mathbf{x}_i, \theta) (2.1)
```

Note with logs we are still working with the same problem because logarithms are monotonic functions. In other words we have:

$P(A) < P(B) \iff \log P(A) < \log P(B)$

Continuing with logs:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} \sum_{i=1}^n \log P(y_i | \mathbf{x}_i, \theta) (2.1)
```

```
$= \arg \max_{\theta} \sum_{i=1}^n \left( -\frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2} - \log \sqrt{2\pi} \right) (2.2)
```

```
$= \arg \min_{\theta} \sum_{i=1}^n \left( \frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2} + \log \sqrt{2\pi} \right) (2.3)
```

```
$= \arg \min_{\theta} \sum_{i=1}^n (y_i - h(\mathbf{x}_i))^2 (2.4)
```

Note that in step (3) we turned the problem from a maximization to a minimization problem by negating the objective. In step (4) we eliminated the second term and the denominator in the first term, because they do not depend on the variables we are trying to optimize.

Now let's look at the case of regression. In that case our hypothesis has the form $h(\mathbf{x}_i) = \mathbf{x}_i^T \theta$, where $\theta \in \mathbb{R}^d$, where $d$ is the number of dimensions of our featurized datapoints. For this specific setting, the problem becomes:

```
$$\theta_{\text{MLE}} = \arg \min_{\theta \in \mathbb{R}^d} \sum_{i=1}^n (y_i - \mathbf{x}_i^T \theta)^2
```

This is just the Ordinary Least Squares (OLS) problem! We just proved that OLS and MLE for regression lead to the same answer! We conclude that MLE is a probabilistic justification for using squared error (the basis of OLS) is a good metric for evaluating a regression model.

### Maximum a Posteriori

In Maximum a Posteriori (MAP) Estimation, the goal is to find the model for which the data maximizes the probability of the model:

```
$$\theta_{MAP} = \arg\max P(\text{true model} = h_\theta | \text{data} = \mathcal{D}) (2.1)
```

```
$= \arg\max_{\theta} P(\text{data} = \mathcal{D} | \text{true model} = h_\theta) P(\text{true model} = h_\theta) (2.2)
```

```
$= \arg\max_{\theta} \log P(\text{data} = \mathcal{D} | \text{true model} = h_\theta) P(\text{true model} = h_\theta) (2.3)
```

```
$= \arg\max_{\theta} \log P(\text{data} = \mathcal{D} | \text{true model} = h_\theta) + \log P(\text{true model} = h_\theta) (2.4)
```

```
$= \arg\min_{\theta} -\log P(\text{data} = \mathcal{D} | \text{true model} = h_\theta) - \log P(\text{true model} = h_\theta) (2.5)
```

Here, we used **Bayes' Rule** to express the objective. In we represent $P(\text{data} = \mathcal{D})$ as a constant value because it does not depend on the variables we are optimizing. Notice that MAP is just like MLE, except we add a term $P(h_\theta)$ to our objective. The term is *prior* over our true model.

More concretely, we have (just as we with MLE):

```
$$\theta_{MAP}^* = \arg\min_{\theta} -\sum_{i=1}^n \log P(y_i|x_i, h_{\theta}) - \log P(h_{\theta})$
```

Again, just in MLE, notice the constraints on the $x_i$ in the whole process we treat them as constants. Also, let us assume before that the noise terms are i.i.d and Gaussian: $N \sim \mathcal{N}(0, \sigma^2)$. For the prior $P(h_\theta)$, we assume that it follows a shifted and scaled version of the standard Gaussian distribution: $h_\theta \sim \mathcal{N}(\theta_0, \sigma_h^2)$. Using this specific information, we have:

```
$$\theta_{MAP} = \arg\min_{\theta} \sum_{i=1}^n \frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2} + \frac{|||\theta - \theta_0||^2}{2\sigma_h^2} (2.1)
```

```
$= \arg\min_{\theta} \sum_{i=1}^n \frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2} + \frac{\sigma^2}{2\sigma_h^2} \frac{|||\theta - \theta_0||^2}{\sigma^2} (2.2)
```

Let's look at the case for linear regression to illustrate the effect of the term $h_{\theta}(x)$. If $\theta_0 = 0$ In this, we refer to the linear hypothesis function $h_{\theta}(x) = \theta^T x$.

```
$$\theta_{MAP} = \arg\min_{\theta \in \mathbb{R}^d} \sum_{i=1}^n \frac{(y_i - x_i^T\theta)^2}{2\sigma^2} + \frac{\sigma^2}{2\sigma_h^2} \sum_{j=1}^d \theta_j^2$
```

This is the Ridge Regression problem! We just proved that Ridge Regression and MAP for regression lead to the same answer! We can simply set $\lambda = \frac{\sigma^2}{\sigma_h^2}$.
