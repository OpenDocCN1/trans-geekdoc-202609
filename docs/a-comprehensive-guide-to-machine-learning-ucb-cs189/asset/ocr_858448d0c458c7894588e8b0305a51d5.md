# 6.8. LOGISTIC REGRESSION

![](bbox=[0.328, 0.096, 0.672, 0.273])

Figure 6.7: Logistic function. For our purposes, the horizontal axis is the output of the linear function $\mathbf{w}^T\mathbf{x}_i$, and the vertical axis is the output of the logistic function, which can be interpreted as a probability between 0 and 1.

The classifier equivalently classifies $\mathbf{x}_i$ as

```
$\hat{y}_i = egin{cases} 1 & \text{if } \mathbf{w}^T\mathbf{x}_i \ge 0 \ 0 & \text{otherwise} \end{cases}$
```

In order to train our model, we need a loss function to optimize. One possibility is least squares:

```
$\arg\min_{\mathbf{w}} \sum_{i=1}^{n} |y_i - s(\mathbf{w}^T\mathbf{x}_i)\|^2 + \lambda|\mathbf{w}||^2$
```

However, this might not be the best choice. Ordinary least squares regression has theoretical justifications as being the maximum likelihood objective under Gaussian noise. Least squares for this classification problem does not have a similar justification.

Instead, the loss function we use for logistic regression is called the log-loss, or **cross entropy**:

```
$\L(\mathbf{w}) = \sum_{i=1}^{n} y_i \ln(\\frac{1}{s(\mathbf{w}^T\mathbf{x}_i)}) + (1 - y_i) \ln(\\frac{1}{1 - s(\mathbf{w}^T\mathbf{x}_i)})$ $
```

If we define $p_i = s(\mathbf{w}^T\mathbf{x}_i)$, then we use the properties of logs we can write this as

```
$\L(\mathbf{w}) = \sum_{i=1}^{n} y_i \ln p_i + (1 - y_i) \ln(1 - p_i)$ $
```

For each $x_i$, $p_i$ represents our predicted probability that its corresponding class is 1. Because $y_i \in \{0, 1\\}$, the loss corresponding to the $i$-th data point is

```
$\L_i = \begin{cases} -ln p_i & \text{when } y_i = 1 \ -ln(1 - p_i) & \text{when } y_i = 0 \end{cases}$
```

Intuitively, if $p_i = y_i$, then we incur 0 loss. However, the logistic function can never actually output a value of exactly 0 or 1, and we will therefore incur some loss. If the actual label is $y_i = 1$, as we lower $p_i$ towards 0, the loss for this data point approaches infinity. The loss function can be derived from a maximum likelihood perspective or an information-theoretic perspective.
