Figure 9.6: AlexNet architecture. Reference: “ImageNet Classification with Deep Convolutional Neural Networks,” NIPS 2012.

+   - Several layers of convolution, max pooling, some normalization. Three fully connected layers at the end of the network (these comprise the majority of the weights in the network).
- Around 60 million weights, half of which are in the first fully connected layer following the last convolution.
- Trained over two GPU’s- the top and bottom divisions in Figure 9.6 were due to the need to separate training onto two GPUs. There was limited communication between the GPU’s, as illustrated by the arrows that go between the top and bottom.
- Dropout in it first FC layers - prevents overfitting
- Heavy data augmentation. One form is image translation and reflection: an elephant facing left is the same as an elephant facing right. The second form is altering the intensity of RGB color channels: different cameras can have different lighting on the same objects, so it is necessary to account for this.

# VGGNet (Simonyan and Zisserman, 2014)

Reference paper: “Very Deep Convolutional Networks for Large-Scale Recognition,” ICLR 2015.¹ Key characteristics:

+   - Only $3 	imes 3$ convolutional filters. Blocks of conv-conv-conv pools are stacked together, followed by fully connected layers at the end (the number of convolutional layers between pooling layers can vary). Note that a stack of $3 	imes 3 	imes 3$ filters has the same effective receptive field as $7 	imes 7 	imes 7$ filter. To see this, imagine sliding a $3 	imes 3 	imes 3$ filter over a image - the result is a $5 	imes 5 	imes 5$ image. Do this more and the result is a $1 	imes 1 	imes 1$ cell - sliding then $7 	imes 7 	imes 7$ filter over the original image would also result in. The computational cost of $3 	imes 3$ filters is lower - a stack of 3 such filters C requires $3^2C$ weights (not including bias weights), while one $7 	imes 7 	imes 7$ filter would introduce a higher cost of $7^2C$ weights. Deeper, more narrow networks can introduce more non-linearities than shallower, wider networks due to the repeated composition of activation functions.

> ¹VGG stands for the “Visual Geometry Group” at Oxford where this was developed.
