# 2.6 MAP with Colored Noise

In the ordinary squares (OLS) statistical model, we assume that the output $Y$ is a linear function of the input, plus Gaussian noise. We take this step further in **maximum a posteriori** (MAP) estimation, where we assume that the weights are a random variable. The new statistical model is

```
**\mathbf{Y} = \mathbf{W} + \mathbf{Z}**
```

where **Y** and **Z** are $n$-dimensional random vectors, and **W** is a $d$-dimensional random variable, and **X** is a fixed $n 	imes d$ matrix. Note that random vectors are not notationally distinguished from matrices here, so keep in mind what each symbol represents.

We have seen that ridge regression can be derived by assuming a prior distribution on **W** in which $W_i$ are i.i.d. (univariate) Gaussian, or equivalently,

```
**\mathbf{W} \sim \mathcal{N}(0, I)****
```

But more generally, we can allow **W** to be any multivariate Gaussian:

```
**\mathbf{W} \sim \mathcal{N}(\mathbf{\mu}_W, \mathbf{\Sigma}_W)****
```

Recall that we can rewrite a multivariate Gaussian as an affine transformation of a standard Gaussian variable:

```
**\mathbf{W} = \mathbf{\Sigma}_W^{1/2}\mathbf{v} + \mathbf{\mu}_W \quad \quad \mathbf{v} \sim \mathcal{N}(0, I)****
```

This change of variable is sometimes called the **reparameterization trick**. Plugging in this parameterization into our previous statistical model gives

```
**\mathbf{Y} = \mathbf{X}(\mathbf{\Sigma}_W^{1/2}\mathbf{v} + \mathbf{\mu}_W) + \mathbf{Z}****
```

But this can be re-written

```
**\mathbf{Y} - \mathbf{X}\mathbf{\mu}_W = \mathbf{X}\mathbf{\Sigma}_W^{1/2}\mathbf{v}****
```

which we see has the form of the statistical problem that underlies OLS, and therefore

```
**\hat{\mathbf{v}} = $(\mathbf{\Sigma}_W^{1/2}\mathbf{X}^	op\mathbf{\Sigma}_W^{1/2})^{-1}\mathbf{\Sigma}_W^{1/2}\mathbf{X}^	op(\mathbf{Y}-\mathbf{X}\mathbf{\mu}_W)****
```

However V is not what we want - we need to connect back to the actual weights **W** in order to make predictions. Since **W** is completely determined by **V** (assuming fixed mean and covariance),

```
**\hat{\mathbf{w}} = \mathbf{\Sigma}_W^{1/2}\hat{\mathbf{v}} + \mathbf{\mu}_W**
= \mathbf{\mu}_W + \mathbf{\Sigma}_W^{1/2}(\mathbf{\Sigma}_W^{1/2}\mathbf{X}^	op\mathbf{\Sigma}_W^{1/2}+\mathbf{I})^{-1}\mathbf{\Sigma}_W^{1/2}\mathbf{X}^	op(\mathbf{Y}-\mathbf{X}\mathbf{\mu}_W)\n= \mathbf{\mu}_W + (\mathbf{X}^	op+\mathbf{\Sigma}_W^{-T/2}\mathbf{X}^	op\mathbf{\Sigma}_W^{-1/2})^{-1}\mathbf{X}^	op(\mathbf{Y}-\mathbf{X}\mathbf{\mu}_W)****
```
