# QDA Optimization Formulation

Assuming that we know the covariances for all the classes, we can use Bayes’ Rule to directly solve the optimization problem

```
$k^* = \arg_k P(k) \ f_k(\mathbf{x})$$
$$= \arg_k \max(\sqrt{2\pi})^d P(k) \ f_k(\mathbf{x})$$
$$= \arg_k \ln P(k) + \ln((\sqrt{2\pi})^d f_k(\mathbf{x}))$$
$$= \arg_k \ln P(k) - \frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) - \frac{1}{2} \ln(|\boldsymbol{\Sigma}_k|) = Q_k(\mathbf{x})$
```

For future reference, let’s use $Q_k(\mathbf{x}) = \ln((\sqrt{2\pi})^d P(k) f_k(\mathbf{x}))$ to simplify our notation.

# 6.4 LDA Classification

While QDA is a reasonable approach to classification, we might be interested in simplifying our model to reduce the number of parameters we have to learn. One way to do this is using **Linear Discriminant Analysis (LDA)** classification. Just as in QDA, LDA assumes that the class conditional probability distributions are normally distributed with different $oldsymbol{\mu}_k$, but LDA is different from QDA in that it requires all of the distributions to share the same covariance matrix $\boldsymbol{\Sigma}$. This is a simplification, in the context of the Bias-Variance tradeoff, increases the bias of our method may help decrease the variance.

# Estimating $f_k(\cdot)$

The training and classification procedures for LDA are almost identical that of QDA. To compute the within-class means, we must wait until the empirical mean. However, the empirical covariance is now computed with

```
$\boldsymbol{\Sigma} = \frac{1}{n} \sum_{i=1}^n(\mathbf{x}_i - \boldsymbol{\mu}_t)(\mathbf{x}_i - \boldsymbol{\mu}_t)^T$
```

One to understand this formula is as a **weighted average of the within-class covariances**. Here, assume we have sorted our training data by class and we can index within the $\mathbf{x}_i$ by specifying a class $k$ and the index within that class $j$:

```
$\boldsymbol{\Sigma}_k = \frac{1}{n_k} \sum_{i=1}^{n_k}(\mathbf{x}_{j,k} - \boldsymbol{\mu}_k)(\mathbf{x}_{j,k} - \boldsymbol{\mu}_k)^T$$
$$= \frac{1}{n} \sum_{k=1}^K n_k \boldsymbol{\Sigma}_k$$
```
