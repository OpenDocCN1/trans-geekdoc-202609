# 2.2 Bias-Variance Tradeoff

Recall from our previous discussion for a fixed input x, the corresponding measurement Y is a noisy measurement of the true underlying response f(x):

```
Y = f(\mathbf{x}) + N
```

Where N is a zero-mean random variable, and is typically represented as a Gaussian distribution. Our goal in regression is to recover the underlying model f(.) as closely as possible. We previously mentioned MLE and MAP as techniques that try to find of reasonable approximation to f(.) by solving a probabilistic objective. In this section we would like to form a theoretical metric that can exactly measure the effectiveness of a hypothesis function h. Keep in mind that this is a metric that cannot be measured in real life, but it can be approximated via empirical experiments—more than later.

Before we introduce the metric, let's make a few subtle points about the data and hypothesis. As you may recall from our previous discussion on MLE and MAP, in this context, we treated the x_i in our dataset D that consists of n (x_i, y_i) pairs. In this case we treated the x_i as random variables.

D is a random variable, because it consists of random variables X_i and Y_i. (Note that these quantities are random variables, and they are all represented by uppercase letters.) Our hypothesis model h(.) is also a random variable—h(x, D) depends on some arbitrary input x, as well as the random D that we used to train h. Since D is random, we will have a slightly different hypothesis model h(., D) every time we use a new dataset.

```
D = {X_1, Y_1; X_2, Y_2; ...; X_n, Y_n}
```

# Metric

Our objective is to, for a fixed value of x, evaluate how well the hypothesis can encapsulate the noisy observation corresponding to x. Note that we have denoted x as a lowercase letter because we are treating it as a fixed constant, while Y and D as as uppercase letters because we are treating them as random variables. Y and D have no relation to the set of X_i and Y_i in D. In this case, we can think of D as the training data, and (x, Y) as the test data—the point x is not necessarily in the training set D! Mathematically, we define our metric as the squared error between the hypothesis and the observation Y = f(\mathbf{x}) + N:

```
ε(x; D) = E((h(x; D) - Y)^2)
```

The expectation here is over two random variables, D and Y:

```
E_Y[(h(x; D) - Y)^2] = E_D[E_Y[(h(x; D) - Y)^2]]
```

Note that the error is w.r.t. the observation Y and not the true underlying model f(x), because we do not know the true model and only have access to the noisy observations from the true.

# Bias-Variance Decomposition

The error metric is difficult to interpret and work with, so let's try to decompose it into parts that are easier to understand. Before start, let's find the expectation and variance of Y:

```
E[Y] = E[f(\mathbf{x}) + N] = f(\mathbf{x}) + E[N] = f(\mathbf{x})
```
