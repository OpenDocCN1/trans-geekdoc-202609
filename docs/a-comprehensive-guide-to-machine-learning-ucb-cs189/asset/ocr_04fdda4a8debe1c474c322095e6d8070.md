More concretely:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} P(y_1, \dots, y_n | \mathbf{x}_1, \dots, \mathbf{x}_n, \theta)$
```

Note that we actually conditioned on the $\mathbf{x}_i$'s, because we treat them as *fixed* values of data. The only randomness in our data comes from the $y_i$'s (since they are noisy versions of the true values $f(\mathbf{x}_i)$).

We can simplify this expression by viewing the problem as a graphical model. Note that $y_i$ only depends on its parent in the graphical model, it does not depend on the other $y_j$'s, since all $y_j$''s have independent noise terms. We can then simplify the objective:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} P(y_1, \dots, y_n | \mathbf{x}_1, \dots, \mathbf{x}_n, \theta) = \prod_{i=1}^n P(y_i | \mathbf{x}_i, \theta)$
```

Now let's focus on each individual term $P(y_i | \mathbf{x}_i, \theta)$. We know that $y_i | \mathbf{x}_i, \theta \sim N(h(\mathbf{x}_i), \sigma^2)$, which is cumbersome to work with because Gaussians have exponential terms. Instead we will use logs, which makes the exponential terms:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} \log[P(y_1, \dots, y_n | \mathbf{x}_1, \dots, \mathbf{x}_n, \theta)] = \sum_{i=1}^n \log[P(y_i | \mathbf{x}_i, \theta)]$
```

Note that with logs we are still working with the same problem, because logarithms are monotonic functions. In other words we have that:

```
$P(A) < P(B) \iff \log P(A) < \log P(B)$
```

Continuing with logs:

```
$$\theta_{\text{MLE}} = \arg \max_{\theta} \sum_{i=1}^n \log[P(y_i | \mathbf{x}_i, \theta)] \quad (2.1)$
```

```
$= \arg \max_{\theta} (- \sum_{i=1}^n \frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2} - n \log \sqrt{2\pi}\sigma) \quad (2.2)$
```

```
$= \arg \min_{\theta} (sum_{i=1}^n \frac{(y_i - h(\mathbf{x}_i))^2}{2\sigma^2}) + n \log \sqrt{2\pi}\sigma \quad (2.3)$
```

```
$= \arg \min_{\theta} \sum_{i=1}^n (y_i - h(\mathbf{x}_i))^2 \quad (2.4)$
```

Note that in step (3) we turned the problem from a maximization to a minimization problem by negating the objective. In step (4) we eliminated the second term and the denominator in the first term, because they do not depend on the variables we are trying to optimize over.

Now let's look at the case of regression. In that case our hypothesis has the form $h(\mathbf{x}_i) = \mathbf{x}_i^T \theta$, where $\theta \in \mathbb{R}^d$, where d is the number of dimensions of our featurized datapoints. For this specific setting, the problem becomes:

```
$$\theta_{\text{MLE}} = \arg \min_{\theta \in \mathbb{R}^d} \sum_{i=1}^n (y_i - \mathbf{x}_i^T \theta)^2$
```
