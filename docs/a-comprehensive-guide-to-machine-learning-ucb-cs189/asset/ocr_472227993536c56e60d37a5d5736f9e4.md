# 7.2 THE DUAL OF SVMs

Let's apply our knowledge of duality to find the dual of the soft-margin SVM optimization problem.

```
$$\min f(w,t,\xi)\n\min_{w,t,\xi} \frac{1}{2}||w||^2 + C \sum_{i=1}^{n} \xi_i\n$$(1-\xi_i) - y_i(w^T x_i - t) \leq 0 \quad \text{and} \quad -\xi_i \leq 0\n_{g(w,t,\xi)\leq0}$$
```

Let's identify the primal and dual variables for the SVM problem. We will have

+   - Primal variables $w, t$, and $\xi_i$
- Dual variables $\alpha_i$ corresponding to each constraint of the form $y_i(w^T x_i - t) \geq 1 - \xi_i$
- Dual variables $eta_i$ corresponding to each constraint of the form $\xi_i \geq 0$

For the purposes of notation, note that we are using $\alpha$ and $eta$ in place of $\lambda$, and there are no dual variables corresponding to $
u$ because there are no equality constraints. The lagrangian for the SVM problem is

```
$$\mathcal{L}(w,t,\xi,\alpha,\beta) = \frac{1}{2}||w||^2 + \sum_{i=1}^{n} \xi_i + \sum_{i=1}^{n} \alpha_i(1-\xi_i) - y_i(w^T x_i - t) + \sum_{i=1}^{n} \beta_i(-\xi_i) \quad (7.7)$$
```

```
$$\frac{1}{2}||w||^2 - \sum_{i=1}^{n} \alpha_i(w^T x_i - t) + \sum_{i=1}^{n} \alpha_i + \sum_{i=1}^{n} (C - \alpha_i - \beta_i)\xi_i$$
```

Thus, the dual is:

```
$$\max_{\alpha,\beta\geq 0} = \min_{w,t,\xi} \frac{1}{2}||w||^2 - \sum_{i=1}^{n} \alpha_i(w^T x_i - t) + \sum_{i=1}^{n} \alpha_i + \sum_{i=1}^{n} (C - \alpha_i - \beta_i)\xi_i \quad (7.8)$$
```

Let's use the KKT conditions to find the optimal dual variables. Verify that the primal is convex. We know that from the stationarity conditions, evaluated at the optimal values $w^*, t^*, \xi^*$,

```
$$\frac{\partial \mathcal{L}}{\partial w} = \frac{\partial \mathcal{L}}{\partial t} = 0$$
```

+   - $\frac{\partial \mathcal{L}}{\partial w} = w - \sum_{i=1}^{n} \alpha_i x_i = 0 \Rightarrow w^* = \sum_{i=1}^{n} \alpha_i x_i$. This tells us that $w^*$ is going to be the weighted combination of the positive-class $x_i^*$ and negative-class $x_i^*$.
- $\frac{\partial \mathcal{L}}{\partial t} = \sum_{i=1}^{n} \alpha_i = 0$. This tells us that the weights $\alpha_i^*$ will be equally distributed among positive- and negative training points.
- $\frac{\partial \mathcal{L}}{\partial \xi_i} = C - \alpha_i - \beta_i = 0 \Rightarrow 0 \leq \alpha_i^* \leq C$. This tells us that the weights $\alpha_i^*$ are restricted to being less than the hyperparameter $C$.
