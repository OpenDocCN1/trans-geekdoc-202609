```
$\frac{\partial L}{\partial w_i} = \lambda + \sum_{j=1}^n 2x_{j,i}(w^*_{j,i} + C_{j,i}^{(1)}) = 0 \implies w^*_i = \frac{-\lambda - \sum_{j=1}^n 2x_{j,i}C_{j,i}^{(1)}}{\sum_{j=1}^n 2x_{j,i}^2}$
```

Denoting $a = -\sum_{j=1}^n 2x_{j,i}C_{j,i}^{(1)}$ and $b = \sum_{j=1}^n 2x_{j,i}^2$, we have

```
$w_i = \frac{-\lambda + a}{b}$
```

But this only if the right hand side, $\frac{-\lambda+a}{b}$, is actually positive. If it is negative or 0, then there is no optimum in $(0, \infty)$.

When $w^*_i < 0$, some calculations will lead to

```
$w^*_i = \frac{\lambda + a}{b}$
```

Again, this only holds if $\frac{\lambda+a}{b}$ is actually negative. If it is positive or 0, then there is no optimum in $(-\infty, 0)$.

If neither the condition $\frac{-\lambda+a}{b} > 0$ or $\frac{\lambda+a}{b} < 0$ holds, then there is no optimum in $(-\infty, 0)$ or $(0, \infty)$. But the LASSO objective is convex in $w_i$ and has an optimum, in this case $w^*_i = 0$.

For this happen, $\frac{-\lambda+a}{b} \leq 0$ and $\frac{\lambda+a}{b} \geq 0$. Rearranging, this can be shown to $|a| \leq k$.

To summarize:

| | |
|---||
| $w^*_i = 0$ | $|a| \leq k$ |
| | $\frac{-\lambda+a}{b} > 0$ |
| | $\frac{\lambda+a}{b} < 0$ |

where

```
$a = -\sum_{j=1}^n 2x_{j,i}C_{j,i}^{(1)}, b = \sum_{j=1}^n 2x_{j,i}^2$
```

The term $\frac{a}{b}$ is the least squares solution (without regularization), so we can see that the regularization term tries to pull the least towards 0. This is not a gradient-descent update — we have a closed-form solution for the optimum $w_i$, given all the other weights are fixed constants. We can also see explicitly the LASSO objective induces sparsity — $a$ is some function of the data and the other weights, when $|a| \leq k$, we set $w_i = 0$ in this iteration of coordinate descent. By increasing $\lambda$, we increase the threshold for $|a|$ to be set to 0, and our solution becomes sparse.
