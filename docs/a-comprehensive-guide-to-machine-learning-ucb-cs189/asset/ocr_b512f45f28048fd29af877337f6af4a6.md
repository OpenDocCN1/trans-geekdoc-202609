# ### 9.1 Convolutional Neural Nets

A convolutional neural net is just like a regular neural net, except more complicated (convolved). But in some ways, a convolutional neural net can actually be a simpler model than a fully-connected neural net.

We'll be talking about convolutional neural networks (ConvNets) mostly in the framework of image classification. First, let's recall what one layer of a regular neural net looks like:

![](bbox=[0.336, 0.506, 0.663, 0.715])

Remember each layer consists of units which represent a single number. The values on the units of some layer are determined by the values of the units behind them and the weights on the edges between the layers. More specifically, the vector of numbers representing layer 2, say $y$, can be represented by linear combinations $W$ of the vector representing layer 1. If we were dealing with images, each unit of the input layer might be the intensity of a single pixel of the image.

The fully-connected architecture of units has a lot of weights to learn. For just a $32 \times 32$ image, there would be 1024 input units and at least as many weights between the first two layers. Now, let's look at how a ConvNet deals with images uses its weights differently.
