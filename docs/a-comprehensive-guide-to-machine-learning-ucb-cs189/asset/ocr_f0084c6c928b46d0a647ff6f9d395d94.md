Let's insert a nonlinear function, called an activation function, after these linear computations. We would like to choose this activation function to make the circuit a universal function approximator.
nA key observation is that piecewise-constant functions are universal function approximators:

![](bbox=[0.335, 0.212, 0.663, 0.401])

The nonlinearity we use, then, is the step function:

$u(x) = \begin{cases} x & x \geq 0 \ 0 & x < 0 \end{cases}$

![](bbox=[0.343, 0.545, 0.656, 0.683])

We can build very complicated functions from this simple step function by combining translated and scaled versions of it. Observe that

+   - If $a, b \in \mathbb{R}$, the function $x \mapsto u(a+bz)$ is a translated (and, depending on the sign of $b$, possibly flipped) version of the step function:
