
## Multi-Class Extension

We can also adapt this to the case where we have multiple classes. Suppose there are $K$ classes, labeled $1, 2, ..., K$. One possible way to extend the approach from binary classification is to compute $w_iw(x_i)$ and round it to the nearest number from 1 to $K$. However, this approach gives an "ordering" to the classes, even if the classes themselves have no natural ordering. This is clearly a problem. For example, in fruit classification, suppose 1 is used to represent "peach", 2 is used to represent "banana", and 3 is used to represent "apple". In our numerical representation, it would appear that peaches are less than bananas, which are less than apples. As a result, if we have an image that looks like some thing between an apple and a peach, we might simply end classifying it as a banana.

The typical way to get around this issue is as follows: if the $i$-th observation has class $k$, instead of the representation $y_i = k$, we can use the representation $y_i = e_k$, the $k$-th canonical vector. Now there is no relative ordering in the representations of the classes. This method is called **one-hot encoding**.

When we have multiple classes, $y_i$ is a $K$-dimensional one-hot vector, so for LS-SVM, we instead have a $K \times (d+1)$ weights to optimize over:

```
$$\arg \min_{\mathbf{w}} \sum_{i=1}^n ||y_i - \mathbf{Wx}_i||^2 + \lambda|\mathbf{w}||^2$$
```

To classify a data point, compute $\mathbf{Wx}$ and see which component $j$ is the largest - we then predict $x_i$ to be in class $j$.

## 6.8 Logistic Regression

**Logistic regression** is a discriminative classification technique that has a direct probabilistic interpretation. Suppose that we have the binary classification problem where classes are represented by 0 and 1. Note that instead of using $-1/+$ labels (as in LS-SVM), in logistic regression logistic regression makes more sense this way because it directly outputs a probability, which belongs in the range of values between 0 and 1.

In logistic regression, we would like to model our estimate of the probability that a data point is in 1. We can start with the linear function $\mathbf{w}^T\mathbf{x}$ and convert it to a number between 0 and 1 by applying a sigmoid transformation $s(\mathbf{x}) = \frac{1}{1+e^{-\mathbf{x}^T\mathbf{x}}}$. Thus to classify $\mathbf{x}_i$ after learning the weights $\mathbf{w}$, we would estimate the probability

```
$P(y_i=1|\mathbf{x}_i) = s(\mathbf{w}^T\mathbf{x}_i)$
```

and classify $\mathbf{x}_i$ as:

- $\hat{y}_i = \begin{cases} 1 & \text{if } s(\mathbf{w}^T\mathbf{x}_i) \geq 0.5 \\ 0 & \text{otherwise} \end{cases}$

![](img/99defe26aebed215976e83d281581f33_94_0.png)

Figure 6.7: Logistic function. For our purposes, the horizontal axis is the output of the linear function $\mathbf{w}^T\mathbf{x}_i$, and the vertical axis is the output of the logistic function, which can be interpreted as a probability between 0 and 1.

The classifier equivalently classifies $\mathbf{x}_i$ as:

```
$\hat{y}_i = \begin{cases} 1 & \text{if } \mathbf{w}^T\mathbf{x}_i \ge 0 \\ 0 & \text{otherwise} \end{cases}$
```

In order to train our model, we need a loss function to optimize. One possibility is least squares:

```
$\arg\min_{\mathbf{w}} \sum_{i=1}^{n} |y_i - s(\mathbf{w}^T\mathbf{x}_i)\|^2 + \lambda|\mathbf{w}||^2$
```

However, this might not be the best choice. Ordinary least squares regression has theoretical justifications as being the maximum likelihood objective under Gaussian noise. Least squares for this classification problem does not have a similar justification.

Instead, the loss function we use for logistic regression is called the log-loss, or **cross entropy**:

```
$\L(\mathbf{w}) = \sum_{i=1}^{n} y_i \ln(\frac{1}{s(\mathbf{w}^T\mathbf{x}_i)}) + (1 - y_i) \ln(\frac{1}{1 - s(\mathbf{w}^T\mathbf{x}_i)})$
```

If we define $p_i = s(\mathbf{w}^T\mathbf{x}_i)$, then we use the properties of logs we can write this as:

```
$\L(\mathbf{w}) = \sum_{i=1}^{n} y_i \ln p_i + (1 - y_i) \ln(1 - p_i)$
```

For each $x_i$, $p_i$ represents our predicted probability that its corresponding class is 1. Because $y_i \in \{0, 1\}$, the loss corresponding to the $i$-th data point is:

```
$\L_i = \begin{cases} -\ln p_i & \text{when } y_i = 1 \\ -ln(1 - p_i) & \text{when } y_i = 0 \end{cases}$
```

Intuitively, if $p_i = y_i$, then we incur 0 loss. However, the logistic function can never actually output a value of exactly 0 or 1, and we will therefore incur some loss. If the actual label is $y_i = 1$, as we lower $p_i$ towards 0, the loss for this data point approaches infinity. The loss function can be derived from a maximum likelihood perspective or an information-theoretic perspective.

## Logistic Loss: Maximum Likelihood Approach

Logistic regression can be derived from a maximum likelihood model. Suppose we $\mathcal{D} = \{x_i, y_i\}_{i=1}^n$, and each observation is sampled from a distribution $Y_i \sim \text{Bernoulli}(p_i)$, where $p_i$ is a function of $x_i$. We can view $P(Y_i=1) = P(Y=1|x_i)$ as the posterior probability that $x_i$ is classified as 1, and $P(Y_i=0)$ as the posterior probability that $x_i$ is classified as 0. The observation $y_i$ is simply sampled from this posterior probability distribution $Y_i$. Thus our observation $y_i$, which we can view as a "sample," has probability:

```
$P(Y_i = y_i) = \begin{cases} p_i & \text{if } y_i=1 \\ 1-p_i & \text{if } y_i=0 \end{cases}$
```

One way to write the likelihood of a sample if $p_i$ is:

```
$P(Y_i = y_i) = p_i^{y_i}(1-p_i)^{(1-y_i)}$
```

which holds no matter what $y_i$ is.

We need a model for the dependency of $p_i$ on $x_i$, which is a transformation of $x_i$, that results in a number from 0 to 1. One way to achieve this is by using the sigmoid function

```
$p_i = \frac{1}{1+e^{-\mathbf{w}^T\mathbf{x}_i}}$
```

Now we estimate the weights $\mathbf{w}$ via maximum likelihood. We have:

```
$\ell(w) = \sum_{i=1}^n \ln P(Y_i = y_i) = \sum_{i=1}^n [y_i \ln p_i + (1-y_i) \ln(1-p_i)]$
```

Our goal is to minimize the negative log-likelihood, which is:

```
$L(w) = \sum_{i=1}^n [-y_i \ln p_i - (1-y_i) \ln(1-p_i)]$
```

Adding a regularization term $\lambda\|\mathbf{w}\|^2$, we get:

```
$L(w) = \sum_{i=1}^n [-y_i \ln p_i - (1-y_i) \ln(1-p_i)] + \lambda\|\mathbf{w}\|^2$
```

## Logistic Loss: Information-Theoretic Perspective

The loss function can be derived from an information-theoretic perspective. To motivate this, we introduce the Kullback-Leibler (KL) divergence between two distributions $P$ and $Q$:

```
$D_{KL}(P||Q) = \sum_x P(x) \ln \frac{P(x)}{Q(x)}$
```

The KL divergence measures how much one probability distribution $Q$ differs from a second, reference probability distribution $P$. In our case, we want to minimize the divergence between the true distribution $P_i$ and our predicted distribution $Q_i$. For a single data point, the divergence is:

```
$D_{KL}(P_i||Q_i) = y_i \ln \frac{y_i}{p_i} + (1-y_i) \ln \frac{1-y_i}{1-p_i}$
```

Summing over all data points and ignoring constants leads to the same cross-entropy loss used in logistic regression:

```
$L(w) = \sum_{i=1}^n [-y_i \ln p_i - (1-y_i) \ln(1-p_i)]$
```
