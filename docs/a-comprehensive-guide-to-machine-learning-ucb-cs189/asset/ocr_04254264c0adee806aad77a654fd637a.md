Plugging these estimates for the tr covariance matrices, we arrive at the problem

```
$$\max_{u,v} \frac{u^{\top} (\frac{1}{n}X^{\top}Y) u}{\sqrt{u^{\top} (\frac{1}{n}X^{\top}X) \cdot v^{\top} (\frac{1}{n}Y^{\top}Y) v}}} = \max_{u,v} \frac{u^{\top} X^{\top}Y v}{\sqrt{u^{\top} X^{\top}X \cdot v^{\top} Y^{\top}Y}}} = \rho(Xu, Yv)$
```

Let's try to manage the maximization problem into a form that we can reason with more easily. Our strategy is to choose matrices to transform $X$ and $Y$ such that the maximization problem is equivalent but easier to understand.

+   1. First, let's choose matrices $W_x, W_y$ to whiten $X$ and $Y$. This will make the (co)variance matrices $(W_x^{	op})(WX_x)$ and $(W_y^{	op})(YW_y)$ identity matrices and simplify our expression. To do this, note that $X^{	op}X$ is positive definite (hence symmetric), so we can employ the eigendecomposition

```
$X^{\top}X = U_x S_x U_x^{	op}$
```

Since all the diagonal entries are positive, we can define the "square root" of this matrix by taking the square root of every diagonal entry:

```
$S_x^{1/2} = \text{diag}(\sqrt{\lambda_1(X^{\top}X)}, \dots, \sqrt{\lambda_d(X^{\top}X)})$
```

Then, $W_x = U_x S_x^{-1/2}U_x^{	op}$, we have

```
$$(W_x^{	op})(WX_x) = W_x^{	op}X^{	op}WX_x\n= U_x S_x^{-1/2}U_x^{	op}X^{	op}WX_xU_x S_x^{-1/2}U_x^{	op}\n= U_x S_x^{-1/2}S_x S_x^{-1/2}U_x^{	op}\n= U_x U_x^{	op}\n= I$$
```

which shows that $W_x$ is a whitening matrix for $X$. The same process can be repeated to produce a whitening matrix $W_y = U_y S_y^{-1/2}U_y^{	op}$ for $Y$.

Let's denote the whitened $u_w = W_x^{-1}u, v_w = W_y^{-1}v$ and $X_w = WX_x, Y_w = WY_y$. Then by the change of variables

```
$$\max_{u,v} \rho(Xu, Yv) = \max_{u,v} \frac{(Xu)^{	op}(Yv)}{\sqrt{(Xu)^{	op}(Xu) \cdot (Yv)^{	op}(Yv)}}\n= \max_{u,v} \frac{(X_w^{	op}X_w)W_x^{-1}u^{	op}Y_w^{	op}W_y^{-1}v}{\sqrt{(X_w^{	op}X_w)W_x^{-1}u^{	op}W_x^{-1}u \cdot (Y_w^{	op}Y_w)W_y^{-1}v^{	op}W_y^{-1}v}}}\n= \max_{u_w,v_w} \frac{(X_w^{	op}X_w)u_w^{	op}v_w}{\sqrt{(X_w^{	op}X_w)u_w^{	op}u_w \cdot (Y_w^{	op}Y_w)v_w^{	op}v_w}}}\n= \max_{u_w,v_w} \frac{u_w^{	op}X_w^{	op}X_w u_w}{\sqrt{u_w^{	op}X_w^{	op}X_w u_w \cdot v_w^{	op}Y_w^{	op}Y_w v_w}}$
```
