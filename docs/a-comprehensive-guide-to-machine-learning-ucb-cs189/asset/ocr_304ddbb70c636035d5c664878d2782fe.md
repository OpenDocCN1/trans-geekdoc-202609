where the bar indicates the sample average, $ar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$. Then as a special case we have

```
$Var(X) = 	ext{Cov}(X, X) = E[(X - E[X])^2] \approx \frac{1}{n}\sum_{i=1}^{n}(x_i - ar{x})^2$
```

```
$Var(Y) = 	ext{Cov}(Y, Y) = E[(Y - E[Y])^2] \approx \frac{1}{n}\sum_{i=1}^{n}(y_i - ar{y})^2$
```

Plugging these estimates into the definition for correlation and canceling the factor of 1/n leads to the sample Pearson Correlation Coefficient $\hat{ho}$:

```
$$\hat{ho}(x, y) = \frac{\sum_{i=1}^{n}(x_i - ar{x})(y_i - ar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - ar{x})^2 \cdot \sum_{i=1}^{n}(y_i - ar{y})^2}} \ \text{where } \hat{x} = x - ar{x}, \hat{y} = y - ar{y}$
```

Here are 2-scatter plots and their corresponding correlation coefficients:

![](bbox=[0.3, 0.403, 0.699, 0.532])

You should notice that:

+   * The magnitude of $\hat{ho}$ increases as $X$ and $Y$ become more linearly correlated.
* The sign of $\hat{ho}$ tells whether $X$ and $Y$ have a positive or negative relationship.
* The correlation coefficient is undefined if either $X$ or $Y$ has 0 variance (horizontal line).

# Correlation and Gaussians

Here's a neat fact: if $X$ and $Y$ are jointly Gaussian, i.e.

```
$$\begin{bmatrix} X \ Y \end{bmatrix} \sim \mathcal{N}(0, \Sigma)$
```

then we can define a distribution on normalized $X$ and $Y$ and have their relationship entirely captured by $ho(X, Y)$. First write

```
$$\rho(X, Y) = \frac{\sigma_{xy}}{\sigma_x \sigma_y}$
```

Then

```
$$\Sigma = \begin{bmatrix} \sigma_x^2 & \sigma_{xy} \ \sigma_{xy} & \sigma_y^2 \end{bmatrix} = \begin{bmatrix} \sigma_x^2 & \rho \sigma_x \sigma_y \ \rho \sigma_x \sigma_y & \sigma_y^2 \end{bmatrix}$
```
