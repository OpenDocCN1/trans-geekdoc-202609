allowing us to discard the training points corresponding to dual weight 0, ultimately allowing for faster evaluation of our hypothesis function on test points.

# LASSO

The motivations for sparsity in SVMs, let's modify the ridge regression objective to achieve sparsity as well. The least absolute shrinkage and selection operator (LASSO) developed in 1996 by Robert Tibshirani, is one method that achieves this desired effect. LASSO is identical to the ridge regression objective, except that the L2-norm (squared) penalizing $w$ is now changed to an L1-norm (with no squaring term):

```
\min_{w} ||Xw - y\|^2 + \lambda||w||_1
```

The **L1-norm** of $w$ is a sum of absolute values of its entries:

```
$|z||_1 = \sum_{i=1}^d |w_i|$
```

Compare this to the **L2-norm** squared of $w$, the sum of squared values of its entries:

```
$|z||_2 = \sum_{i=1}^d w_i^2$
```

Just as in ridge regression, there is a statistical justification for the L1-norm. Whereas ridge regression assumes a Gaussian prior over the weights $w$, LASSO assumes a **Laplace prior (otherwise known as a double exponential distribution)**- over the weights $w$.
