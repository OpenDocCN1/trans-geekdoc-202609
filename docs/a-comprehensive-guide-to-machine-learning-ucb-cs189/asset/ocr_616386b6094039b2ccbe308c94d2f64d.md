# Maximum a Posteriori

In Maximum a Posteriori (MAP) Estimation, the goal is to find the model, for which the data maximizes the probability of the model:

```
$$\theta_{MAP} = \arg\max P(\text{true model} = h_{\theta} |\text{data} = \mathcal{D})$ (2.1)$
```

```
$$\arg\max_{\theta} P(data = \mathcal{D} |\text{true model} = h_{\theta})P(\text{true model} = h_{\theta})$ (2.2)$
```

```
$$\arg\max_{\theta} P(data = \mathcal{D} |\text{true model} = h_{\theta})P(\text{true model} = h_{\theta})$ (2.3)$
```

```
$$\arg\max_{\theta} \log P(data = \mathcal{D} |\text{true model} = h_{\theta}) + \log P(\text{true model} = h_{\theta})$ (2.4)$
```

```
$$\arg\min_{\theta} -\log P(data = \mathcal{D} |\text{true model} = h_{\theta}) - \log P(\text{true model} = h_{\theta})$ (2.5)$
```

Here, we used **Bayes' Rule** to express the objective. In we represent $P(data = \mathcal{D})$ as a constant value because it does not depend on the variables we are optimizing. Notice that MAP is just like MLE, except we add a term $P(h_{\theta})$ to our objective. The term is *prior* over our true model.

More concretely, we have (just as we with MLE):

```
$$\theta_{MAP}^* = \arg\min_{\theta} -\sum_{i=1}^n \log P(y_i|\x_i, h_{\theta}) - \log P(h_{\theta})$ $
```

Again, just in MLE, notice the constraints on the $x_i$ in the whole process we treat them as constants. Also, let us assume before that the noise terms are i.i.d and Gaussian: $N \sim \mathcal{N}(0, \sigma^2)$. For the prior $P(h_{\theta})$, we assume that it follows a shifted and scaled version of the standard Multivariate Gaussian distribution: $h_{\theta} \sim \mathcal{N}(\theta_0, \sigma_h^2 I)$. Using this specific information, we have:

```
$$\theta_{MAP} = \arg\min_{\theta} \sum_{i=1}^n \frac{(y_i - h_{\theta}(x_i))^2}{2\sigma^2} + \frac{|||\theta - \theta_0||^2}{2\sigma_h^2}$ (2.1)$
```

```
$$\arg\min_{\theta} \sum_{i=1}^n \frac{(y_i - h_{\theta}(x_i))^2}{2\sigma^2} + \frac{\sigma^2}{2\sigma_h^2} \frac{|||\theta - \theta_0||^2}{\sigma^2}$ (2.2)$
```

Let's look at the case for linear regression to illustrate the effect of the term $h_{\theta}(x)$. If $\theta_0 = 0$ In this, we refer to the linear hypothesis function $h_{\theta}(x) = \theta^T x$.

```
$$\theta_{MAP} = \arg\min_{\theta \in \mathbb{R}^d} \sum_{i=1}^n \frac{(y_i - x_i^T\theta)^2}{2\sigma^2} + \frac{\sigma^2}{2\sigma_h^2} \sum_{j=1}^d \theta_j^2$
```

This is the Ridge Regression problem! We just proved that Ridge Regression and MAP for regression lead to the same answer! We can simply set $\lambda = \frac{\sigma^2}{\sigma_h^2}$. We conclude that MAP is a probabilistic justification for adding the penalized ridge term to Ridge Regression.
