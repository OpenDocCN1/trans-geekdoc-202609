# Formulating PCA

Let $X \in \mathbb{R}^{n \times d}$ be our matrix, where each row is a $d$-dimensional data point. We will assume that the data points have mean of zero; otherwise we subtract the mean to make them zero-mean:

```
$X - \frac{1}{n}\mathbf{1}_n\mathbf{1}_n^T X, \quad \mathbf{1}_n = \begin{bmatrix} 1 \\ \vdots \\ 1 \end{bmatrix}$
```

The motivation for this is that we want to find directions of high variance within the data, and variance is defined relative to the mean of the data. If we did not zero-center the data, the directions found would be heavily influenced by where the data lie relative to the origin, rather than where they lie relative to the other data, which is more useful. For example, translating all the data by some fixed vector could completely change the principal components if we did not center.

Recall that any random variable $Z$,

```
$Var(Z) = \mathbb{E}[(Z - \mathbb{E}[Z])^2]$
```

if $\mathbb{E}[Z] = 0$ then $Var(Z) = \mathbb{E}[Z]^2$.

Hence once $X$ is zero-mean, the variance of the projections is given by

```
$\epsilon_{PCA,var}(u) = \sum_{i=1}^n (x_i^T u)^2 = \|Xu\|^2$
```

where $u$ is constrained to have unit norm. To maximize the variance, the objective becomes

```
$\max_{\|u\|=1} \epsilon_{PCA,var}(u) = \max_{\|u\|=1} \|Xu\|^2 = \max_{u\neq 0} \frac{\|Xu\|^2}{\|u\|^2} = \max_{u\neq 0} \frac{u^T X^T Xu}{u^T u}$
```

The ratio which is known as a *Rayleigh quotient*. We will see that Rayleigh quotients are heavily related to eigenvalues, so anytime you use one, its eigensense would single.

# Rayleigh Quotients

Suppose $M \in \mathbb{R}^{d \times d}$ is a real, symmetric ($M = M^T$) matrix. The Rayleigh quotient of $M$ is defined as

```
$R(u; M) = \frac{u^T Mu}{u^T u}$
```

The eigenvalues of $M$ by $\lambda_1 \geq \lambda_2 \geq \dots \geq \lambda_d$, with corresponding eigenvectors $v_1, \dots, v_d$. That is, $M_j = \lambda_j v_j$ for $j = 1, \dots, d$. If we stack the $v_j$ as columns of a matrix $V$:

```
$V = [v_1 \quad \dots \quad v_d]$
```

then the eigenvector equations can be simultaneously written as

$MV = V\Lambda$

where

$$\Lambda = diag(\lambda_1, \dots, \lambda_d) = V^T$$

Then $V$ is an orthogonal matrix, it is invertible with $V^{-1} = V^T$, so

$V^T MV = \Lambda$

Let $u$ be a unit length vector. Since $\{v_j\}$ form a basis, we can write

$$u = \sum_{j=1}^d \alpha_j v_j = V\alpha$$

Then $V$ is an orthogonal matrix. $|u| = 1$ is as well. Now

$$R(u;M) = \frac{u^T Mu}{u^T u} = \alpha^T MV\alpha = \alpha^T \Lambda\alpha = \sum_{j=1}^d \lambda_j \alpha_j^2$$

Since we have the constraint $\alpha_1^2 + \dots + \alpha_d^2=1$, the largest expression is a weighted average of the eigenvalues and hence bounded by the smallest and largest of these:

$$\lambda_d \le R(u;M) \le \lambda_1$$

The lower bound is achieved by putting $\alpha_1=\pm1, \alpha_{j\neq 1}=0$. The maximizing value can then be recovered by

$$\sum_{j=1}^d \alpha_j v_j = \pm v_1$$

That is, it is an eigenvector corresponding to the largest eigenvalue: Hence

$$\lambda_d = R(v_d;M) \le R(v_1;M) \le \lambda_1$$

Finally note that the Rayleigh quotient is scale invariant, i.e. $R(\gamma u;M) = R(u;M)$ for any $\gamma \neq 0$, the inequality holds for all scaling of the vectors, not unit-length vectors.

# Calculating the first principal component

Armed with our knowledge of Rayleigh quotients, the solution to the PCA problem is immediate:

$$\max_{\|u\|=1} PCA.var(u) = \max_{u\neq 0} \frac{u^T X u}{u^T u} = \lambda_1(X^T X)$$

where the maximizer $u^*$ is a unit eigenvector corresponding to this eigenvalue. Writing $X=U\Sigma V^T$,

$$X^T X = V\Sigma^T U^T U\Sigma V^T = V\Sigma^2 V^T$$

The expression on the right is an eigendecomposition of $X^T X$, so

$$\lambda_1(X^T X) = \sigma_1^2$$

with corresponding eigenvector $v_1$, which is the first principal component.

# Finding multiple components

We have seen how to derive the first principal component which maximizes the variance. But usually we will need more than one direction since one direction is unlikely to capture the data well. The best idea here is to subtract the contributions of the previously computed principal components and then apply the same rule to what remains. $u_{(1)},\dots,u_{(k-1)}$ denote the principal components already computed, this subtracting is accomplished by

$$\hat{X} = X - \sum_{j=1}^{k-1} X u_j u_j^T = X(I - \sum_{j=1}^{k-1} u_j u_j^T)$$

This expression should be expressed as applying the same transformation to each row of the data:

$$\hat{x}_i = (I - \sum_{j=1}^{k-1} u_j u_j^T)x_i = x_i - \sum_{j=1}^{k-1} u_j u_j^T x_i$$

The vector $\hat{x}_i$ should be recognized as the orthogonal projection of $x_i$ onto the subspace spanned by $u_{(j)}$. Here $\hat{x}_i$ is what's left when you start with $x_i$ and remove all the components that belong to subspaces spanned by $u_{(j)}$. We want to find the direction of largest variance subject to the constraint that it must be orthogonal to all the previously computed directions. We have a constrained problem of form

$$u_k = \arg\max_{\forall j < k, u^T u_{(j)}=0} \frac{u^T X^T u}{u^T u}$$

But we don't want to compute $\hat{X}$! Consider that if $u$ is orthogonal to $u_{(1)},\dots,u_{(k-1)}$ (as we constrain it), then

$$\hat{X}u = (X - \sum_{j=1}^{k-1} X u_j u_j^T)u = Xu - \sum_{j=1}^{k-1} X u_j u_j^T u = Xu$$

Thus we can write the optimization problem above as

$$u_k = \arg\max_{\forall j < k, u^T u_{(j)}=0} \frac{u^T X^T u}{u^T u}$$

eliminating the need to compute $\hat{X}$. Unsurprisingly, the solution to this problem is given by $v_k$, that is a unit eigenvector corresponding to the $k$th largest eigenvalue of $X^T X$. Rather than iteratively computing each $u_j$, we can view the problem of finding the first $k$ principal components as a joint optimization over all $k$ directions simultaneously. This amounts to maximizing the variance projected onto a $k$-dimensional subspace

$$U = \arg\max_{U^TU=I} \sum_{j=1}^k u_j^T X^T u_j = \arg\max \text{tr}(U^T X^T U)$$

- To see this, take the projection of both sides and use the symmetry of $I - \sum_j u_j u_j^T$.
- This is exactly the same idea as the Gram-Schmidt method.

For matrices $U$ with orthogonal columns we can define

```
$R(U; M) = R([u_1, \dots, u_k]; M) = \sum_{j=1}^k R(u_j; M)$
```

As before, the bounds for this expression are given in terms of the smallest and largest eigenvalues, and we know that them are:

```
$\lambda_1 + \lambda_2 + \dots + \lambda_k = R([v_1, \dots, v_k]; M)$
```

Hence, projection onto the subspace spanned by the first $k$ leading eigenvectors maximizes the variance of the projected data. We can find $k$ principal components by computing the SVD, $X = U\Sigma V^T$, and then taking the first $k$ columns of the matrix $V$.

# Projecting onto the PCA coordinate system

Once we have the principal components, we can use them as a new coordinate system. To do this we must project the data onto this coordinate system, which can be done in the same way as above (taking inner products). Each data point $x_i \in \mathbb{R}^d$ becomes a new vector $\tilde{x}_i \in \mathbb{R}^k$, where $k$ is the number of principal components. The components of the projection write

```
$\tilde{x}_ij = x_i^T u_j$
```

We can compute all these vectors at once efficiently using a matrix-matrix multiplication

```
$\tilde{X} = U^T X
```

where $U \in \mathbb{R}^{d\times k}$ is a matrix whose columns are the principal components.
