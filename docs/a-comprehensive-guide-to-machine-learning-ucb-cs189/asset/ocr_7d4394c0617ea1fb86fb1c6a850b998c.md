# 2.1 MLE AND MAP

random variable: $X \sim p(x)$

probability distribution: $p(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

mean: $E[X] = \int_{-\infty}^{\infty} xp(x)dx = \mu$

variance: $V[X] = E[(X-\mu)^2] = \int_{-\infty}^{\infty} (x-\mu)^2p(x)dx = \sigma^2$

parameters: $X \sim \mathcal{N}(\mu, \sigma^2)$

log-likelihood: $\log P(X) = \sum \frac{(x-\mu)^2}{2\sigma^2} - \sqrt{2\pi}\sigma$.

linear combinations: $E[aX+bY] = a\mu_x + b\mu_y$

if $X, Y$ are independent: $V[aX+bY] = a^2\sigma_x^2 + b^2\sigma_y^2$
$aX+bY \sim \mathcal{N}(a\mu_x+b\mu_y, a^2\sigma_x^2+b^2\sigma_y^2)$

# MLE and MAP for Model Selection

In the context of regression, (and all of supervised learning for that), we assume a **true underlying model** that maps inputs to outputs. Our goal as machine learning experts is to find a **hypothesis model** that represents the true underlying model, by using the data we are given.

Let's define more concretely our definition of the data and the model. Our data takes consists of $n$ $(x_i, y_i)$ pairs, just as we have seen before:

$$\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n$

The true underlying model $f$ is a function that maps the inputs $x_i$ to the true outputs $f(x_i)$. Each **observation** $y_i$ is simply a noisy version of $f(x_i)$:

$y_i = f(x_i) + N_i$

Now $f(x_i)$ is a constant, while $N_i$ is a random variable. We always assume that $N_i$ has zero mean, otherwise there would be systematic bias in our observations. The $N_i$ could be Gaussian, Uniform, Laplacian, etc. Here, let us assume that they are **independent and identically distributed (i.i.d)** and Gaussian: $N_i \sim \mathcal{N}(0, \sigma^2)$. We can verify that $y_i|x_i \sim \mathcal{N}(f(x_i), \sigma^2)$.

Now that we have introduced the data, and we wish to find a hypothesis model $h\theta$ that best describes the data, possibly taking into account prior beliefs that we have about the true model. We can represent this as a probability problem, where the goal is to find the optimal model that maximizes our probability.
