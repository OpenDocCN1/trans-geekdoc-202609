

# AI偏见与监控风险

## 预测性系统中的偏见

所有这些偏见都凸显了使用数据预测未来结果的风险。在AI领域，这一问题尤为突出。以执法为例，特别是在美国，警方已开始使用预测性系统来评估某人再犯罪的可能性、是否应获准保释，或犯罪高发期何时可能出现。麻烦在于，此类系统不可避免地将那些历史上一直是警方重点关注对象的个人和社区作为目标。

> “如果你使用有问题的数据，你就会得到有问题的执法结果，”专门研究刑事司法领域AI及其歧视性影响的研究员Renée Cummings解释道。

在美国，黑人被捕的可能性是白人的两倍多。他们更有可能无故被警方拦截，黑人男性被警方杀害的可能性是白人男性的2.5倍。

> “这始于偏见之处，”Cummings说。“AI真正放大了系统中固有的偏见和歧视。”

### 案例研究：COMPAS软件

2016年，ProPublica的一项调查揭示了名为`COMPAS`的预测性软件如何对黑人存在偏见。

即使从预测性警务AI系统中剔除种族数据（这是平等法的常见要求），问题依然存在。AI Now论文作者Rashida Richardson（现为罗格斯法学院访问学者）指出，有多种形式的数据可作为种族的代理指标。地理位置便是其中之一。如果你居住的区域因种族构成而已受到高强度警务巡逻，那么档案中必然会有更多警方报告，从而导致AI极大概率判定你的区域为高犯罪区。其他可能导致扭曲的数据画像还包括年龄和社会关系。荷兰使用的一种预测性警务工具，将单亲家庭数量、领取社会救济人数、非西方移民数量等人口统计数据，作为判断特定区域犯罪发生可能性的因素。

目前几乎没有证据表明预测性或AI风险评估工具真正有效。证明算法决策工具优于人类预测的研究寥寥无几，且由于警方通常对其AI技术的使用讳莫如深，其数据鲜少经过独立分析和验证。不过，洛杉矶警方对一款名为`PredPol`、在美国多地使用的系统进行审查后表示，很难得出关于该系统在减少车辆或其他犯罪方面有效性的结论。

2020年6月，超过1400名数学家签署公开信，声明不相信该领域应与警方在这些系统上合作。

## 偏见的跨领域扩散

AI偏见不仅存在于警务领域。住房、就业和金融事务均深受偏见问题困扰。医疗保健正成为遭遇此类问题的最新领域。例如在美国，加州大学伯克利分校的研究人员发现，保险公司和医院用于管理每年约2亿人护理的算法，给自我认同为黑人的人群打出的风险分，低于病情同等严重的白人。

随着AI日益复杂，研究人员担心算法建立的关联将变得更加晦涩。某些类型数据的代理指标将更难识别，机器可能会建立人类无法联想在一起、或因信息处理规模过大而无法察觉的关联。这种情况的早期迹象已现端倪。

### 案例研究：Facebook定向广告歧视

2019年3月，美国住房和城市发展部（`HUD`）指控`Facebook`其住房定向广告运作方式涉嫌歧视。

> “算法对人群分组，未必基于性取向或肤色，”牛津互联网研究所AI法律与伦理副教授兼高级研究员Sandra Watcher表示。她称算法根据相似行为对人群分组。“这些相似性可能是他们都穿绿鞋，或都在周二吃印度菜，或都玩电子游戏。”问题在于，此类相关性可能导致完全错误的推断——例如算法可能断定穿绿鞋的人有或没有按时还贷的倾向。在任何人类看来，这种结论都荒谬至极；但在AI眼中，这可能显得完全合乎逻辑。

> “即使银行能解释决策使用了哪些数据和变量（如银行记录、收入、邮政编码），决策取决于从这些来源得出的推断；例如，申请人不是可靠的借款人，”Wachter写道。

## 监控技术的缺陷

如果AI在处理数据时已显问题，那么在处理涉及人类的图像——特别是通过面部识别技术——时，也暴露出严重缺陷。

### 面部识别原理

这些系统的工作原理在理论上相当简单。假设连接AI系统的监控摄像头检测到一张面部，系统会测量面部特征间的距离（如额头到下巴的距离），并创建生物特征图谱。该图谱用于生成面部指纹（实际上是一串数字），随后与数据库中的其他面部指纹比对以寻找潜在匹配。底层算法已在数据集上通过人脸匹配训练。

世界各地警方使用此类AI检测其系统中已登记的罪犯或潜在罪犯。实时部署中若出现匹配，一线警员会收到警报并追踪嫌疑人。一些运行实时面部识别系统的摄像头有明确标识，但许多更复杂的模型外观与普通闭路电视摄像头无异。一款2020年推出的特别先进的摄像头系列，使用六种AI算法，提供高达1200万像素分辨率，并将面部识别与人群计数、车牌识别相结合。它能监控周界和队列，甚至能检测人们是否佩戴安全帽。

### 实战与实验室的差距

以上至少是理论情况。实践中，实验室测试的高准确率往往难以在现实世界复现。光线不足会干扰面部识别，低质量视频素材亦是如此。阳光尤为棘手。英国警方早期试用实时面部识别系统时，判定2470张面部与警方数据库匹配，实际仅8%属实，其余所谓匹配均为误报。

### 准确性与种族偏见

准确性是个问题。因许多系统主要基于白人图像训练，它们在识别黑人和棕色人种面部时准确度较低，因此发生了错误识别。2020年1月，来自密歇根州的41岁黑人男子Robert Williams，因算法触发错误逮捕，在羁押中度过了30小时。
