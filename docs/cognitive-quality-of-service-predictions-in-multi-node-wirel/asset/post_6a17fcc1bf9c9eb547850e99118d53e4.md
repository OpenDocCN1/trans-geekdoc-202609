## 5. Conclusions

Modern communication systems are envisioned to be adaptive. The advent of software-defined networking and network function virtualization makes it possible to implement adaptive designs. Such adaptive design can be realized using dynamic fine-tuning of configurable communication parameters with the help of machine learning. In this paper, we demonstrated the potential of using machine learning for predicting quality of service metrics in wireless sensor networks and the internet of things based on parameters like traffic rate, packet size, transmission power, maximum transmissions, number of nodes, and distance. The accurate predictions of the quality of service metrics can help design a data-driven adaptive communication system for the internet of things. Data was collected through extensive experiments and was statistically analyzed to identify the relationship among the communication parameters and quality of service metrics like packet delivery ratio, throughput, energy consumption (both CPU and radio).

The correlations encouraged adopting intelligent techniques like machine learning. The prediction results are sufficiently accurate and provide a basis for the products and solutions development based on adaptive design. In future, we intend to develop a working prototype of an adaptive system that integrates the communication network with the cloud and predictions are made using live performance data.
