# 2.1. Experiment topology

The topology of the experiment is shown in Fig. 2. The experimental setup is configured on w.iLab testbed [22], located in Gent University, Belgium. The sending nodes are indicated using indicated squares (black, green, and purple), and receivers (sinks) are indicated using red circles. The purple nodes participate in experiments only when the number of nodes is set to 24. The green nodes participate when the number of nodes is 16, or 24. Black nodes participate in all experiments when the number of nodes is set to 8, 16, or 24. The average node to node distance is a little over 2 m, whereas the receiver/sink is placed in the center of the network. The numbers of sending nodes are varied between 8 (black), 16 (black+green), and 24 (black+green+purple). The Fig. 2 is taken from the actual dashboard of the testbed and a cross is placed to indicate dysfunctional nodes due to maintenance or any other problem. Node 0–32 was not available during the time this experiment was conducted.

The minimum runtime of the experiment is based on the number of combinations of parameter values. The detail of the communication parameters and their values are provided in Table 1. Based on this description in Table 1, we present the detail of combinations as follows:

```
Total combinations = TP x NN x MT x PS x IAT
= 6 x 3 x 3 x 3 x 4
~ 650 (1)
```

This meant that the experiment ran against these almost 650 combinations of the parameter configurations. We ran the experiment against each parameter configuration for 600 s (10 min) and repeated aiming to reach a consistent behavior. Therefore, the minimum time required for running the experiment and overheads due to schedule, technical difficulties, erroneous runs, is as follows:

```
Total time for experiments = Number of parameter configurations
x Time + Overhead(1/4th of actual time)
= 650 x 10 min + 1625 min
~ 6500 min + 1625 min
= 8125 min ~ 135 h = 06 days
(2)
```
