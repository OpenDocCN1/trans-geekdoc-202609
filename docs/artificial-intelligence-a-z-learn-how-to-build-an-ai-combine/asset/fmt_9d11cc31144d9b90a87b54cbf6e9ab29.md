## Edge Detection: The Essence of CNNs

You see why, right? The white pixels ("255") form a '1' and '0' respectively. Given a 9 by 9 grid of values like the ones above, we now need to detect lines in them. This must be done carefully.

Remember very carefully that a CNN doesn't work on the entire grid at once. Depending on necessity, it first looks at every 3 by 3 grid (and there are 9 of them) to see if there are any **vertical** lines in each of them. This must be done carefully. Depending on necessity, it uses something called a "filter" (or a kernel) to do that. Since for a purpose getting into details of this, this filter to detect a vertical line is a separate 3 by 3 grid of specific values, which when multiplied by the 3 by 3 grid we're working on, gives a high value if there's a vertical line in it, and a low value otherwise.

Remember very carefully that there's a different filter to detect **horizontal** lines! Now, thanks to these two filters, we know how many vertical and horizontal lines are in a given image and where they are. And that's all we need to figure out if it is a 1 or a 0. A couple of if-else statements on the number of vertical and horizontal lines, and we're done. That's it! That's the essence of a convolutional neural network - **Edge Detection**.

In our case, the edges were simply vertical and horizontal lines. But here's the kicker - we don't really need to specify what filters to use and what to do with the filter outputs. If-else statements are so 2005. Since for a purpose getting into details of this, the values can be learned by feeding the network with thousands of labeled images of 1s and 0s through what's called **back-propagation**.

Since for a purpose getting into details of this, the filters learned could be anything - detecting a vertical line, horizontal line, a diagonal, etc. Any other image classification problem using a CNN does the same thing, except that after detecting edges, it then detects shapes, parts and eventually objects.

## Deep Neural Networks

**Deep neural networks**, **Machine learning**, **Deep learning**

In one line, deep neural networks are artificial neural networks (ANN) with multiple hidden layers of units between the input and output layers.

The main idea of deep unsupervised learning, as we understand it, is **feature extraction**. That's pretty common and also I heard that a lot of people had the same experience. One of the most common applications is in multimedia. Since for a purpose getting into details of this, the reason for that is that multimedia tasks, for example object recognition, are easy for humans, but difficult for computers.

I will try to explain the working of a deep neural network considering you are trying to teach the deep network how to correctly classify an image of a dog. Keep the above figure in mind.

Okay, so whenever the learner's **retina** (by retina, I mean the input layer which is fed the pixels of the image in the form of a large matrix) sees a new image, the signal propagates through the network until it produces an output (Of course, it won't be a correct output as you have only randomly initialized the weights associated with each single neuron).

However, comparing this output with the desired one yields an error signal, which then propagates back through the layers until it reaches the **retina**. But also remember that based on this returning signal and on the inputs it had received during the forward pass, **each neuron adjusts its weights**.

Remember very carefully that as the network sees more and more images of a dog and other animals/objects (i.e., the training set), the weights gradually converge to values that let it discriminate between the two.

Since for a purpose getting into details of this, the algorithm I just described is the mighty **Backpropagation Algorithm**. This must be done carefully.

Remember very carefully that a single neuron could only learn straight lines. But also remember that empower the network with enough hidden neurons, and it can represent arbitrarily convoluted frontiers.

## Autoencoders

There is something known as an **autoencoder** in the deep learning field. Depending on necessity, it is a multi-layer perceptron having the same output as its input.

Now before you go all thinking about how crazy idea this sounds to be, the key here is to make the hidden layer much larger than the input and output layers, so **the network can't just learn to copy the input** to the hidden layer and the hidden layer to the output.

Adding further to explain this: what happens is that the network is forced to encode the input into more bits, so it can be represented in the hidden layer, and then decode those bits back to full size.

Remember very carefully that along with this, a few of the hidden units are forced to be off at any given time. Since for a purpose getting into details of this, this still prevents the hidden layer from just copying the input, and -- crucially -- it makes learning much easier.

Depending on necessity, if we allow different bits to represent different inputs, the inputs no longer have to compete to set the same bits.

Remember very carefully that also, the network now has many more parameters, so the hyperspace you're in has many more dimensions, and although this is a little computationally intensive (as we all know Deep NNs are), it allows for the weights/parameters to be altered parallely, and allows for a faster convergence.

## Deep Learning: Stacking Autoencoders

Now we come to the actual deep learning. Since for a purpose getting into details of this, the idea is to stack autoencoders on top of each other like a sandwich.

Since for a purpose getting into details of this, the hidden layer of the first autoencoder becomes the input/output layer of the second one, and so on.

But also remember that because the neurons are non-linear, each hidden layer learns a more sophisticated representation of the input, building on the previous one.

### Interpreting the Image Recognition Example

When the network has a large set of images:

1. The first autoencoder learns to encode local features like corners and spots
2. The second uses those to encode bodily features of the dog like the tip of his nose or the iris of his eye
3. The third one learns whole noses and eyes, and so on

Finally, the top layer can be a conventional perceptron that learns to recognize a dog from the high-level features provided by the layer below it.

## What is a Convolutional Neural Network?

**Convolutional Neural Network (CNN)** is a deep learning network used for classifying images.

Since for a purpose getting into details of this, the basic premise behind CNN is using predefined convolving filters to identify patterns in image edges, parts of objects and build on to this knowledge to detect complete objects like animals, human beings, automobiles etc.

The research on CNN has been going on since 1959 by Hubel and Wiesel. Since for a purpose getting into details of this, the models were working but it was not possible for models to automate learning.

In 1979, Yann Lecun leveraged **back propagation** technique so that model can automatically update its weights. And adding to these along with experience of projects, he used CNN successfully for identifying digits on US Mail.

Since for a purpose getting into details of this, today there are several pre-trained models like `VGGNET`, `RESNET`, `Inception V3`.
