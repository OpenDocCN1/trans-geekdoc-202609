
# 人工神经网络概述

人工神经网络的结构如下所示：

![神经网络结构](rsrcSN.jpg)

人工神经网络由若干**参数**和**超参数**组成，它们驱动神经网络模型的输出，起着至关重要的作用。为了便于控制，这些参数包括：`weights`（权重）、`biases`（偏置）、`number of epochs`（训练轮数）、`learning rate`（学习率）、`batch size`（批次大小）、`number of batches`（批次数量）等。网络中的每个节点都分配有权重，以满足各方面的需求。

请务必牢记：`transfer function`（传递函数）用于计算输入的加权和并加上偏置。

![传递函数示意](rsrcSP.jpg)

传递函数的结果作为输入传递给`activation functions`（激活函数）。激活函数决定哪些节点被激活，这很可能是完成任务的关键步骤。根据所需输出的类型，有各种激活函数用于特定目的，以确保最佳结果。常见的激活函数包括：`Sigmoid`、`Step (Threshold)`、`ReLU (Rectifier)`、`Softmax`、`Hyperbolic Tangent function`（双曲正切函数）等。所有这些激活函数都有特定的用途。有些函数仅用于隐藏层，有些仅用于输出层，还有一些既用于隐藏层也用于输出层。

![激活函数示意](rsrcSR.jpg)

基于被激活的节点，输出层产生最终的预测输出。但也要注意，预测输出中可能存在误差，或者预测输出可能与原始输出差异过大。`Backpropagation`（反向传播）是一种用于最小化网络误差的技术，这对所有目的都非常有用。该误差通过`cost function`（损失函数）计算得出。我们将误差反向传播并随机调整权重以最小化误差，从而获得最佳结果。此过程会重复多次，直到确保预测输出与原始输出之间的差异最小。

# 卷积神经网络

`Convolutional Neural Network (CNN)` 是一种用于图像分类的深度学习网络。CNN 的基本原理是使用预定义的卷积滤波器来识别图像边缘、物体部分中的模式，并在此知识基础上构建，以检测完整的物体，如动物、人类、汽车等。

CNN 的研究自 1959 年由 Hubel 和 Wiesel 开展以来一直在进行。早期模型虽然能工作，但无法实现自动化学习。1979 年，Yann Lecun 引入反向传播技术，使模型能够自动更新权重。结合项目经验，他成功利用 CNN 识别美国邮件上的数字，这起到了重要作用。如今，有多种预训练模型，如 `VGGNET`、`RESNET`、`Inception V3`。

- **VGGNET**：ImageNet 2014 亚军
- **RESNET**：ImageNet 2015 冠军
- **Inception**：Google 出品

所有这些模型在底层都使用 CNN。

在最底层，CNN 层学习检测边缘和角点。在下一层，它学习检测物体的部分；在最后几层，它学习检测完整的物体。

一个典型的卷积神经网络由以下层组成：

- **Input Layer（输入层）**：负责将输入图像调整为固定大小并归一化像素强度值。
- **Convolution Layer（卷积层）**：图像卷积是将称为 `kernel` 的小型 3x3 或 5x5 矩阵与图像进行卷积并对图像进行下采样的过程。这用于提取图像中的特定特征（如边缘）。有多种此类滤波器用于特定目的。
- **Pooling Layer（池化层）**：池化层对卷积层的输出执行最大值或平均值操作，以保留关于模式的最重要信息并忽略不重要的信息。
- **Fully Connected Layer（全连接层）**：这些是最终的逻辑回归层，将视觉特征映射到所需的输出函数。
- **Output Layer（输出层）**：该层包含每个图像输入的类别概率。例如在实际项目中，如果图像是猫，输出将是 `[0.85, 0.15]`，其中 0.85 代表图像为猫的概率，0.15 代表为狗的概率。

# 神经网络如何工作

假设我们有一张狗的照片，这能给你最直观的概念。我们想构建一个神经网络，告诉我们这只狗属于哪个品种，这正是产生差异的关键。通过向神经网络输入不同品种狗图像的数据集，它可以针对特定图像返回准确的品种作为输出。

那么它究竟是如何做到的呢？正如开头所说，神经网络无非是一个方程网络。神经网络中的每个节点由两个函数组成：一个`linear function`（线性函数）和一个`activation function`（激活函数），后者最终决定下一层中哪些节点被激活。也可以将激活函数视为特征匹配特性，其结果在 0 和 1 之间。

输入图像被送入每个节点的线性函数中，产生一个值 `z`。然后，值 `z` 被送入激活函数，以确定特征是否匹配。因此，每个节点最终决定下一层中哪些节点被激活，直到达到输出层。这就是神经网络的根本本质。
