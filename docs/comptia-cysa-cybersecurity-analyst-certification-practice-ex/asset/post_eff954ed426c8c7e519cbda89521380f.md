+   4. Which of the following vulnerability scanners is the open source and free of the commercially licensed scanner Nessus?

+   A. Nikto
+   B. OpenVAS
+   C. Nexpose
+   D. Qualys
+   E. Microsoft Baseline Security Analyzer

+   B is correct. OpenVAS is open source and free to use. Originally forked from the Nessus project, OpenVAS is similarly structured and capable.

+   A, C, D, and E are incorrect. All of the vulnerability scanners collect and analyze the data, but their scope and pricing differ. Nikto is also a vulnerability scanner, unlike Nessus, Nikto is a command-line utility and specific to web servers. As such, Nikto works very quickly but is not intuitive as GUI-based tools. Nexpose, like Nessus and Nikto, is also a vulnerability scanner. While Nessus is more useful for managing vulnerabilities, it can integrate directly with Metasploit, making Nexpose something of an exploitative tool as well. Qualys commercially licenses its vulnerability scanner QualysGuard. Lastly, the Microsoft Baseline Security Analyzer is free, but only capable of scanning Windows endpoints and servers.

+   5. A recent incident has led to law enforcement (LE) taking several employees' mobile devices. LE requires data extraction from these devices, while ensuring no changes to the data can be made during extraction. Given the scope of effort, and how it's done on company-managed devices, LE asks for your suggestion on the proper forensic tool for the job. What forensic tool would you recommend?

+   A. EnCase
+   B. FTK Imager
+   C. Sysinternals
+   D. Cellebrite
+   E. Helix

+   D is correct. Cellebrite's flagship product, the Universal Forensic Extraction Device (UFED), is a handheld device for facilitating data extraction while also employing write blocking.

A, B, C, and E are incorrect. EnCase is by far the most popular forensic product used by law enforcement. However, its mobile device capabilities are not close to those of UFED. The tool FTK Imager is another well-known forensic tool for law enforcement for data preview and volume imaging, but is not useful for mobile devices. As a side note, FTK has a utility—Mobile Phone Examiner (MPE+)—that applies here, but MPE+ wasn't given as an answer. The Windows utilities originally created by Sysinternals (now owned by Microsoft) are powerful tools for security analysts, but their capabilities offer nothing to mobile devices. Helix is the only forensic tool that provides value to mobile devices. However, to date, Helix's mobile utilities are still not as robust as those offered by Cellebrite.

+   6. As a safety measure, the finance manager has been archiving the company's folder every evening and asks for any way to ensure that the files have not changed since they were archived. What tools can you use? (Choose all that apply.)

+   A. md5sum
+   B. tcpdump
+   C. shasum
+   D. Vega
+   E. ZAP

+   A and C are correct. To verify the files remain, the finance manager should archive the files again and then compare hashes made from the two archives. Only if the archives are exactly alike will the hash values be exactly alike. The two utilities that create dethese hash values are md5sum and shasum.

B, D, and E are incorrect. The utility tcpdump is a command-based packet capture and analysis tool. For use on different platforms, arguably on Linux/Unix systems, tcpdump is ideal for capturing packets off the network, not for comparing files. Instead, Vega is an interception proxy that sits between the user and the resources. Vega, written in Java, offers automated scanning vulnerability discovery. ZAP is an interception proxy like Vega. However, ZAP is considerably more popular because of its easier learning curve and intuitive interface.

D is correct. Hydra is a fuzzing tool, meaning its purpose is to send unexpected input to an application with the intent of breaking or crashing it. ModSecurity is a monitoring toolkit that benefits from the OWASP Core Rule Set (CRS), a set of detection rules tailored for web application attacks. Kiwi Syslog, like ModSecurity, is also a monitoring tool. However, Kiwi functions just short of an actual SIEM and instead contends on regulatory compliance issues. Cain & Abel is a password cracking tool and although it performs brute-force attempts, it would not be able to operate with the developer’s new input.

+   Your CEO recently read an article titled “Security Information and Event Management—How You Know Everything.” The CEO has been interested in alerts you receive from the company’s vast array of systems, but he is now willing to invest in real-time analysis of those alerts. Which tool would you suggest the CEO invest?

+   A. ArcSight
+   B. Bro
+   C. Cacti
+   D. tcpdump

+   A is correct. ArcSight is a powerful trio of platforms intended for medium to large companies. Its correlation and analytics engines are mature and well-respected in the field of SIEM solutions. The CEO would be proud and pleased with ArcSight integrated into the current fold of alert management systems.

+   B, C, and D are incorrect. The IDS Bro is a monitoring and detection tool. Given a strong, flexible scripting language, Bro is nearly an intrusion prevention system, able to respond to certain alerts. But can hardly be considered a comprehensive SIEM. Cacti, also a monitoring tool, is a free front end to a network logging and graphic tool based on MRTG. Unlike Bro, Cacti just monitors and makes nice graphs—again, far from functioning as SIEM. The packet capture and analysis tool tcpdump excels at capturing packets, but not at responding to or reporting findings in a particularly useful way.
