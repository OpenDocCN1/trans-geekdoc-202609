15. A contractor has borrowed an older company laptop and has been using it with no issues for months. Recently the contractor came in, asking for a new laptop because his is ‘acting weird.’ When asked for specifics, the contractor mentioned his application sometimes freezes, the browser goes to different websites, and other strange things start happening. What might be the best course of action?

A. Ensure the OS and applications patched.

B. Increase the size of the hard drive; add more memory.

C. Create the contractor new account.

D. Back up your data and perform a fresh, updated system install.

- **D** is correct. Given the older system was poorly managed and behind patch management, the system might have been compromised. Best approach is to wipe it and start with a new, updated install if the system has resources.
- **A, B, and C** are incorrect. A is incorrect because although the OS and applications are not up to date on patching, it might be too late for course of action. B is incorrect because increasing the hard drive and memory is a good idea once the system has a fresh install. C is incorrect because creating a new account will not solve system performance problems.

16. A security team alerts you that a new domain account has been created, but there is no documented request. No legitimate way the account could be created without your assistance shows a user session active now on local host. What is your first step?

A. Fire the analyst.

B. Log off the session.

C. Isolate the host.

D. Reset the account.

- **D** is correct. Your first step is to reset the account's password, quickly followed by logging off the session.
- **A, B, and C** are incorrect. A is incorrect because there is no evidence to suggest the analyst is behind this. B is incorrect because this is your second step. If you log off the session, the unauthorized user would immediately log back. C is incorrect because isolating the host would stop the user.

17. An important file that lists accounts is tightly controlled, including a process for making changes. Although no documented changes made, an analyst has determined its hash value changed sometime between today and yesterday. What would cause a different hash?

A. New account added

B. Unauthorized changes made

C. Different generator used

D. Capacity increased

- **B** is correct. Whether the change in the file was due to a new account being added or the account being changed, unauthorized creates a different hash value when calculated.
- **A, C, and D** are incorrect. A is incorrect regardless of how the file was different. C is incorrect because the tool used to generate the hash value should not matter provided the same hashing algorithm (for example, MD5) is used. D is incorrect because changing the capacity would not change the file.

# Frameworks, Policies, and Procedures

This chapter includes questions on the following topics:

- Common information security frameworks
- Common policies and procedures
- Considerations in choosing controls
- How to verify and validate compliance

Before a security analyst can complain they are too busy, the analyst needs to understand why they are busy. Before the first configuration change is made and before any tool is used, the organization needs to know what it wants to enforce and monitor. Before the environment can be secured, there needs to be documented steps on how to carry that out. These answers and much more are provided by the organization’s policies and procedures. The policies state the “why,” while the procedures specify the “how.”

When an organization is tackling the question of how best to marry security and business in the environment, frameworks can provide an overarching approach. Other frameworks can be used that focus on service management or security for government systems, for example. A variety of frameworks is available, as you will find in this chapter as we delve into policies and procedures.
