+   A is correct. The Remote Authentication Dial-In User Service (RADIUS) uses UDP, not TCP. Additionally, RADIUS allows the use of a “shared secret” across the network. For both these reasons, using an unreliable or untrusted network is highly discouraged if the company is wanting to use RADIUS.

+   B, C, and D are incorrect. B is incorrect because Terminal Access Controller Access System Plus (TACAS+) uses TCP, so it is a viable solution for the low-bandwidth network. However, because TACAS+ does not use encryption, it is vulnerable to reply attacks. authenticating across the Internet is not recommended. C is incorrect because Lightweight Directory Access Protocol (LDAP) is an option over the dedicated line. D is incorrect because XTACACS is a later, extended version of TACACS and also uses encryption, so the untrusted network is not a big risk.
