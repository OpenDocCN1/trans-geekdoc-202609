# Identity and Access Management

This chapter includes questions on the following topics:
* Various parameters for context-based authentication
* Security issues and best practices for using common authentication protocols
* Security issues with various components of the network environment
* Commonly used exploits against authentication and access systems

Authentication and authorization are the gatekeepers between users and the resources they need. The one key component that is necessary is the identity; whether it's a user, an application, a service, or a system, the identity commands a level of trust that the subject is who or what it claims to be. In this chapter, we cover methods for protecting identity, issues involved with sharing identity, and some common methods to exploit identity.
