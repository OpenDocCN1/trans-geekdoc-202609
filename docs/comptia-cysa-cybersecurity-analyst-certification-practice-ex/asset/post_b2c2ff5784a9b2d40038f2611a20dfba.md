12. Which of the following is not a Event Event category in Windows desktop?

D is correct. Storage is not an actual Event category. A, B, and E are incorrect. All of these—Application, System, and Audit—are valid Event categories.

15. A cybersecurity analyst scans the network for servers with TCP port 636. What other port--port can the analyst expect to find open on each of those servers?
- A. 22
- B. 111
- C. 53
- D. 389
- E. 5000

D is correct. Port 636 is open for LDAP over SSL (LDAPS). Any server that has port 636 listening very likely has LDAPS listening on port 389.
A, B, C, and E are incorrect. A is incorrect because port 22 is typically for SSH. B is incorrect because port 111 is for MRPC (Microsoft Remote Procedure Call). C is incorrect because port 53 is for DNS. Lastly, E is incorrect because port 5000 could be for several services, but nothing specifically associated with port 636.

16. What tool presents a graphical user interface for nmap?
- A. Nessus
- B. Zenmap
- C. TShark
- D. Qualys

B is correct. Zenmap is the GUI version of nmap.
A, C, and D are incorrect. A is incorrect because Ness is a vulnerability scanner, not a port scanner. C is incorrect because TShark is the CLI version of Wireshark. Lastly, D is incorrect because Qualys is a GUI vulnerability scanner.

17. An analyst is viewing the logs of a Cisco ASA firewall. What should the analyst type at the command line to verify what logging is enabled?
- A. # show running-config logging
- B. # log full show
- C. # show all
- D. # show run

A is correct. The command show running-config logging is the proper one to start with, on a ASA firewall.

18. After running tcpdump, an analyst reviews the output, which includes the following line:
```
16:35:39.83754 > badguy.org.12889 > target.net.80: FP(DF)
```
What does the “FP” represent?
- A. Final Packet
- B. First Packet
- C. Fin Push
- D. Forward Packet

C is correct. The “F” stands for Fin, and the “P” for Push. A, B, and D are incorrect. The “P” in FP does not stand for “Packet.”

19. The director of technology has decided that the company requires an IDS. As the senior security analyst, you recommend Snort. The director requests that you flag any SSH request coming from a competitor’s network. Examine the following rules and select the one that alerts if traffic originates from the network 12.34.56.x/24 and is destined for the company’s web server (IP address 210.67.79.89).
- A. alert tcp 210.67.78.89 -> 12.34.56.0/24 80
- B. alert tcp 12.34.56.0 24 -> 210.67.79.89 21
- C. alert tcp 210.67.78.80 -> 12.34.56.0/24 any
- D. alert tcp 12.34.56.0 24 -> 210.67.79.89 22

D is correct. The Snort rule correctly alerts if an SSH request (over 22/TCP) comes from the network 12.34.56.0/24 to the company web server at 210.67.79.89.
A, B, and C are incorrect. A is incorrect because the source and destination addresses reversed and is monitoring port 80 (HTTP), when the question stated SSH traffic. B is incorrect because the Snort rule is monitoring for port 21 (FTP). C is incorrect because the Snort rule has "any" instead of a specific port.
