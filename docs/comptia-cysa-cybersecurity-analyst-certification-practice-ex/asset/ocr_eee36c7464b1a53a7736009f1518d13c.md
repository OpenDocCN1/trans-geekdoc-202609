+   22. What is the term used to describe when an attacker is able to leap from a virtual machine to the host machine?

A. Lateral move
B. Virtual interruption
C. Escape
D. Sandbox jump
C is correct. Leaving the VM and accessing the host system is called an escape.
A, B, and D are incorrect. None of these is the correct term to describe moving from the VM to the host.
