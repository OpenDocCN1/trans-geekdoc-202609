+   6. An internal cybersecurity analyst is asked to send a report via e-mail. The analyst plans to send the report from within the company’s network. In order to ensure the confidentiality of the report, which is a likely step for the analyst to take?

+   A. Create a hash of the report file and send the in a second e-mail.

+   B. Use the e-server, but wipe it with a cloth or something.

+   C. Using a cryptography tool to further protect the report.

+   D. None of the above. E-mailing across an internal infrastructure is perfectly safe.

+   C is correct. Given that e-mail is open and insecure, encrypting the report first can help ensure the report’s confidentiality.

+   A, B, and D are incorrect. A is incorrect because creating a hash doesn’t preclude from intercepting the report. Having a copy elsewhere doesn't change the file’s hash value, so comparing the received copy doesn't matter. B is incorrect because wiping the server afterward (whether with a cloth or something else) doesn’t make sending the report by e-mail any more secure. D is incorrect because unencrypted e-mail is not safe from spying eyes, regardless of where it happens.
