* A, B, D, and E are incorrect. Nessus is a vulnerability scanner with tens of thousands of plug-ins available for searching vulnerabilities. While Nessus would likely be able to identify the vulnerabilities that allowed the malware to get installed, it isn't the ideal tool for identifying systems already infected. The monitoring tool Multi Router Traffic Graph (MRTG) is for graphing network utilization, but it is not able to identify individual workstation behavior. The command-line utility netstat would report on network connections and listening sockets, but wouldn't identify all the systems with port 5297 as quickly as nmap can.
