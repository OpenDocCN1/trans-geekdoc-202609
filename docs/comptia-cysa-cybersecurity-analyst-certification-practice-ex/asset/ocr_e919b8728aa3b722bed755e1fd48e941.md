16. Which of the following is not included when capturing packet headers but is provided with full packet capture?

17. Which of the following statements is not true when it comes to syslog?

+   A. Syslog supports a broad range of devices and events.

+   B. Messages can be aggregated into a single, nonhierarchical file.

+   C. Devices can be polled for messages, echoing back to a syslog server.

+   D. The syslog protocol and messaging core native in most firewalls and network devices as well as *nix systems.

+   C is correct. Syslog does not "poll" devices for event messages. Syslog messages are sent to a syslog server, with no prompting.

+   A, B, and D are incorrect. A is incorrect because a wide variety of devices and types of messages are supported by syslog. B is incorrect because syslog messages are collected and shown as a flat file. D is incorrect because such network devices and *nix systems support syslog.
