# 外汇交易 - 使用神经网络获取巨额利润

今天，我们看到神经网络在金融市场中的使用日益增加，以帮助更准确地预测价格，其复杂性和研究令人难以置信。本文将探讨神经网络在金融交易中的使用及其盈利潜力。

## 人脑与计算机

人脑是已知最复杂的对象，如果不是最复杂的。它不仅仅是其卓越的处理速度和存储空间使其非凡，更重要的是其学习和适应的能力。

## 神经网络定义

计算机科学家试图编写软件，让计算机模仿大脑的学习能力（计算机已经具有卓越的存储和处理速度），而神经网络旨在帮助计算机学习和适应。

神经网络本质上是一个由程序和数据结构组成的系统，它近似于人脑的操作。神经网络由大量并行运行的处理器组成，每个处理器都有自己的知识领域并可访问自己的数据库。

神经网络是通过提供大量数据和一组规则来“训练”的。计算机程序可以告诉网络如何响应外部事件并根据其可访问的知识启动反应。

因此在外汇交易中，神经网络可以根据输入的数据学习如何交易。

## 它们有效吗？

目前的答案是人脑现在是并且永远会是更优越的，因为它可以独立思考。计算机永远无法达到人脑的学习能力，因为它只能按照编程的规则工作。

计算机程序可以进行交易，但你需要神经网络吗。

今天有一些不使用神经网络的计算机程序，其规则可以赚钱，而神经网络完全没有任何优势。

人们认为技术可以解决一切问题，但市场是一个简单系统可以并且确实表现最好的领域之一。

## 投资事实

事实是50年前95%的外汇交易者亏损，而今天同样的比例仍然适用。

尽管我们在市场研究、计算机和信息传递速度方面取得了所有进步。如果你想在外汇交易中获胜，请记住这一点：

交易是一种概率游戏，将科学应用于预测注定会失败。

永远不会有神经网络能够像人脑那样学习和适应，因为它必须由人类编程，而变量是无穷无尽的。

## 保持简单以获得成功

如果有人试图向你推销基于神经网络的程序或服务，请要求查看他们的实时业绩记录，看看你是否能得到——很可能你得不到。

人们总是希望科学能提供帮助，但在市场中忘记神经网络并顺势而为。

无论是用你的大脑还是使用一个简单的、只有几条规则的货币交易系统——这就是你所需要的，不要寻找更多。

# 将新神经元整合到神经网络中

过去，神经研究领域一直坚信人们在年老时无法生长出新的神经元。但1998年的一项惊人发现改变了一切。现在人们普遍认为，人们在衰老时仍可以生长新的神经元。现在研究的重点主要放在这些新神经元如何优雅地整合到现有的神经网络中而不引起任何潜在问题。研究在胚胎啮齿动物和猴子身上进行表明，神经递质GABA，通常抑制神经元放电，可能反而会刺激新神经元放电。

为这一结论感到惊讶，约翰霍普金斯大学的一个团队专注于海马体的一部分，齿状回。他们将一种使分裂神经元发出绿色荧光的逆转录病毒注入小鼠。之后他们可以测量这些细胞对不同神经递质的反应性。

最初，神经元对扩散到细胞间空间的GABA敏感。一周后，新细胞与已建立的神经元相连，后者以脉冲方式传递GABA。再过一周，细胞形成了接收谷氨酸的连接，这是成年神经元中主要的兴奋性神经递质。结果表明，尽管胚胎和成体之间存在差异，“新形成的神经元必须遵循这一序列”，法国地中海神经生物学研究所所长、与约翰霍普金斯工作无关的Yehezkel Ben-Ari说道。

显然，年轻细胞内部氯离子过量负责了GABA对其的兴奋。科学家们改造的GABA缺乏神经元显示出连接发育延迟两周并最终死亡。约翰霍普金斯神经科学家Hongjun Song说，该团队希望测试在正确的时间和剂量下将GABA应用于干细胞是否可以帮助修复中枢神经系统损伤。
