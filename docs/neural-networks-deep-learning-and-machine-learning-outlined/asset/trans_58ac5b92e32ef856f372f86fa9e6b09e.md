

# 离散余弦变换

像任何傅里叶相关的变换一样，离散余弦变换（DCT）将函数或信号表示为不同频率和振幅的正弦波之和。像离散傅里叶变换（DFT）一样，DCT 对有限数量的离散数据点上的函数进行操作。DCT 与 DFT 的明显区别在于，前者仅使用余弦函数，而后者使用余弦和正弦（以复指数形式）。然而，这种可见的差异仅仅是更深层次区别的结果：DCT 意味着与 DFT 或其他相关变换不同的边界条件。

傅里叶相关的变换在有限域上对函数进行操作，例如 DFT 或 DCT 或傅里叶级数，可以被视为隐式地定义了该函数在域外部的扩展。也就是说，一旦你将函数 f(x) 写成正弦波之和，你就可以在任何 x 处评估该和，即使对于原始 f(x) 未指定的 x。DFT 与傅里叶级数一样，意味着原始函数的周期性扩展。DCT 与余弦变换一样，意味着原始函数的偶扩展。

离散余弦变换（DCT）将有限多个数据点的序列表示为不同频率振荡的余弦函数之和。DCT 在科学和工程的众多应用中很重要，从音频和图像的有损压缩（其中可以丢弃小的<|message|> 高频分量），到用于偏微分方程数值解的光谱方法。在这些应用中使用余弦而不是正弦函数至关重要：对于压缩，事实证明余弦函数更有效（如下所述，需要更少的函数来逼近典型的信号），而对于微分方程，余弦表达了特定的边界条件选择。

特别是，DCT 是一种与离散傅里叶变换（DFT）相似的傅里叶相关变换，但仅使用实数。DCT 等价于大约两倍长度的 DFT，对具有偶对称性的实数据进行操作（因为实偶函数的傅里叶变换是实偶的），其中在某些变体中输入和输出数据被半个采样偏移。有八种标准 DCT 变体，其中四种常见。

最常见的离散余弦变换变体是 II 型 DCT，通常简称为“ DCT”；其逆变换 III 型 DCT 相应地通常简称为“逆 DCT”或“IDCT”。两个相关的变换是离散正弦变换（DST），它等价于实奇函数的 DFT，以及基于重叠数据的修改离散余弦变换（MDCT）。

DCT，特别是 DCT-II，常用于信号和图像处理，尤其是在有损数据压缩中，因为它具有很强的“能量压缩”特性。大多数信号信息往往集中在 DCT 的少数低频分量中。

## 神经网络

在这项工作中，使用了一种神经网络结构，即学习向量量化神经网络。下面简要概述了该网络。

### 学习向量量化

学习向量量化（LVQ）是基于 Linde 等人、Gray 和 Kohonen 的工作的向量量化的监督版本，类似于自组织映射（SOM）。它可以应用于模式识别、多类分类和数据压缩任务，例如语音识别、图像处理或客户分类。作为监督方法，LVQ 对每种输入模式的形式使用已知的目标输出分类。

LVQ 算法不像向量量化或概率神经网络那样近似类样本的密度函数，而是直接基于原型、最邻近规则和赢者通吃范式定义类边界。主要思想是用“码本向量”（CV）覆盖样本的输入空间，每个向量代表一个用类标记的区域。CV 可以被视为一个原型的类成员，位于输入空间中类或决策区域的中心。一个类可以用任意数量的 CV 表示，但一个 CV 只代表一个类。

就神经网络而言，LVQ 是一个具有一个隐藏层神经元的前馈网络，与输入层完全连接。CV 可以被视为一个隐藏神经元（“Kohonen 神经元”）或与所有输入神经元和相应的 Kohonen 神经元之间的权重之间的权重向量。

学习意味着根据适应规则修改权重，从而改变输入空间中 CV 的位置。由于类边界是作为相邻类 CV 之间中平面段的分段线性构建的，因此类边界在学习过程中会得到调整。由 CV 集合引起的镶嵌是最佳的，如果单元格内的所有数据确实属于同一类。学习后的分类基于样本与 CV 的邻近性：分类器将相同的类标签分配给落入同一镶嵌中的所有样本——单元格的标签

## 人工神经网络在心脏护理中的应用

人工神经网络（ANN）是源自人工智能的模型，通常互换地称为神经网络。它是一种处理互连数据（人工神经元）的数学或计算模型，以在数据中寻找模式。在此过程中，输入数据通过联结主义方法传递到输出数据。系统通过流经其中的大量数据进行适应和学习。结果是一个专家决策或甚至预测系统，准确率接近 100%。小 wonder，临床医生一直在使用 AI 和专家系统为患者提供更好、更及时的医疗保健。

医学人工智能（AIM）很好地总结了一些应用领域。它们是：

*   生成警报和提醒
*   诊断辅助
*   疗法评判和规划
*   信息检索代理
*   图像识别和解释

在一项 1990 年代末的研究中，研究人员冒险纳入了 1,120 条心脏病发作患者的 ECG 记录，以及 10,452 条正常患者的记录。神经网络被发现能够使用这些输入数据，建立关系和模式。这种学习阶段被系统内部化，并开始以比大多数在职临床医生/心脏病专家高出 10% 的准确率识别具有异常 ECG 的患者。

但这里需要注意的一点是，像 ANN 这样的技术不能取代在诊断心脏病发作之前会查看更多因素和细节的医生。它只能作为一种手段来补充和加快诊断过程。

说到确定心脏病发作的其他因素，一项有趣的研究工作已在 InderScience 集团的科学期刊《国际知识工程与软数据范式杂志》（IJKESDP）上发表，名为“使用在线分析处理方法开发急性冠状综合征风险评估的计算算法”（第 1 卷，第 1 期，第 85-99 页，2009 年）。四位希腊研究人员冒险开发了一种计算算法，该算法源自更现代的技术，即在线分析处理（OLAP）。他们使用这种方法为“心脏病发作计算器”奠定了基础。OLAP 的优势在于它提供了数据的多维视图，允许在原本会保持不可战胜的非常大的数据集中辨别模式。
