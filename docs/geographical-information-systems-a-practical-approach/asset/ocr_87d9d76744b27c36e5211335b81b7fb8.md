# # Remote Sensing Data Analysis

Remote sensing data are one of the major sources of spatial data. How to effectively analyse remote sensing data to derive useful information is of critical importance for geographical analysis and monitoring using GIS. This chapter provides an introduction to remote sensing data and presents the basics of digital image processing. It introduces commonly used operations of digital image processing in remote sensing of environment, including image preprocessing, transformation and classification.
