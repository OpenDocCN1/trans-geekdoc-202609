### 6.7.3.1.1 Similarity in Value

Using Euclidean distance as the similarity measure, a clustering algorithm is used to form clusters wherein individual time series have maximum similarity with other individual time series within the group (intra-cluster similarity), and minimum similarity in value with individual time series in other groups (inter-cluster similarity). k-means and k-medoids are two typical techniques for clustering time series data according to similarity in value.

Time series are similar if they have about equal values of a particular variable across time. For example, a time series with values (2, 1, 2, 1, 2) is more similar to (2, 2, 2, 2, 2) than it is to a time series with values (20, 10, 20, 10, 20) because the values are more similar. A simple, widely used measure of the similarity in value between time series is the Euclidean distance between the values in the time series (not to be confused with the distance in geographical space between the locations of the time series). This measure is calculated by taking the square root of the sum of squared differences in values across time. Suppose a bin time series is represented by $T_1$: $(t_{11}, t_{12}, \cdots, t_{1n})$, and another is $T_2$: $(t_{21}, t_{22}, \cdots, t_{2n})$, where $t_{ki}$ is the value of a given variable at the time step $i$ in the bin time series $k$. The Euclidean distance between $T_1$ and $T_2$ is

$D(T_1, T_2) = \sqrt{\sum_{i=1}^n [t_{1i} - t_{2i}]^2} \quad (6.47)$

The fundamental principle of the two techniques is based on the method of moving centres, aiming to minimise the total Euclidean distance between all time series in a cluster from the cluster centre. In **k-means clustering**, the centre of a cluster is its centroid, which corresponds to the average or arithmetic mean of data values across time of all the locations assigned to the cluster. Suppose a cluster comprises $m$ time series, $T_1$: $(t_{11}, t_{12}, \cdots, t_{1n})$, $T_2$: $(t_{21}, t_{22}, \cdots, t_{2n})$, $\cdots$, $T_m$: $(t_{m1}, t_{m2}, \cdots, t_{mn})$. Its centroid is a time series calculated as follows:

$C = \left( \frac{\sum_{i=1}^m t_{i1}}{m}, \frac{\sum_{i=1}^m t_{i2}}{m}, \cdots, \frac{\sum_{i=1}^m t_{in}}{m} \right) \quad (6.48)$

A smaller $D(T_1, T_2)$ indicates higher similarity, and vice versa. For instance, the distance between two time series of (2, 1, 2, 1, 2) and (2, 2, 2, 2, 2) is

$\sqrt{(2-2)^2 + (1-2)^2 + (2-2)^2 + (1-2)^2 + (2-2)^2} = 1.414$

For example, if a cluster consists of the time series (80, 56, 77, 65), (75, 53, 74, 62), (60, 50, 59, 55) and (68, 54, 66, 61), its centroid would be:

$\left( \frac{80 + 75 + 60 + 68}{4}, \frac{56 + 53 + 50 + 54}{4}, \frac{77 + 74 + 59 + 66}{4}, \frac{65 + 62 + 55 + 61}{4} \right)$

That is (70.75, 53.25, 69, 60.75). Basically, k-means partitions n time series into k (pre-defined) clusters in which each location belongs to the cluster with the nearest cluster centroid. The k-means algorithm works through an iterative process, in which it moves each time series to the cluster whose centroid is closest, recalculates the cluster centroid and repeats the assignment procedure until no time series is reassigned (Lloyd 1982). Specifically, the process works as follows:

- 1. Find k initial cluster centroids by selecting k random locations (bin time series).
- 2. Assign each location to the most similar cluster. The most similar cluster is the cluster with the closest centroid, according to Euclidean distance.
- 3. Recalculate the k cluster centroids by averaging all the assigned locations for each cluster.
- 4. Repeat steps 2 and 3 until cluster centroids no longer move.

The number k of clusters must be specified a priori. k-means clustering is also highly affected by outlier data. An outlier is a time series very different from the rest of the time series. All the outlier time series show up in a different cluster and will attract other clusters to merge with it. Outlier data increase the mean of a cluster.

k-medoids clustering is conceptually similar to k-means. It is an improved version of k-means clustering mainly designed to deal with outlier data sensitivity. Instead of using centroids as cluster centres, k-medoid takes a medoid as a cluster centre. A medoid is a time series in the cluster from which is the sum of distances to other time series is minimal (that is, to minimise total dissimilarity). Medoids are always one of the observations in the data, while that is not necessarily the case for centroids. There are three types of algorithms for k-medoids clustering: PAM (partitioning around medoids), CLARA (clustering large applications) and CLARANS (clustering large applications based upon randomised search).

The PAM algorithm clusters a time series dataset based on the search for k medoids of the dataset by randomly exchanging all the non-medoid time series into medoid points iteratively until convergence (Kaufman and Rousseeuw 1987). A general description of the algorithm is given here:

- 1. Select k random locations from the data as the initial medoids and assign them to k number of clusters.
- 2. For each of the remaining locations, calculate its Euclidean distance to each medoid and assign it to the cluster with the nearest medoid.
- 3. Calculate the total cost (the sum of all the distances from all the locations to the medoids).
- 4. Select a random location as the new medoid, and swap it with the previous medoid. Repeat steps 2 and 3.
- 5. If the total cost of the new medoid is less than that of the previous medoid, make the new medoid permanent and repeat step 4.
- 6. If the total cost of the new medoid is greater than the cost of the previous medoid, undo the swap and repeat step 4.
- 7. The repetitions continue until no change is encountered with new medoids to classify locations.

The PAM algorithm is known to be computationally intensive for a large k and a large number of time series or observations (more than several thousands) (Ng and Han 1994). CLARA is an extension to PAM to support k-medoids clustering for large datasets in order to reduce computing time. Instead of finding medoids for the entire dataset, this algorithm selects samples from the dataset, applies PAM on each sample and outputs the best clustering out of these samples (Kaufman and Rousseeuw 1990). This is more effective than PAM for a large dataset. However, the algorithm may give wrong clustering results if one or more sampled medoids are away from the actual best medoids. CLARANS deals with the concerns of both PAM and CLARA and maintains a balance between the computational cost and the influence of data sampling on clusters’ formation. In CLARANS, the process of finding k medoids from a dataset is viewed abstractly as searching through a certain graph (Ng and Han 2002). In the graph consisting of a set of connected nodes, a node is represented by a set of k locations (bin time series) as selected medoids. Two nodes are neighbours if their sets differ by only one location. In each iteration, CLARANS considers a sample of randomly chosen neighbour nodes instead of samples from the dataset and examines the neighbours of every node. It moves to the neighbour node if the neighbour is a better choice for medoids. Otherwise, a local optimum is discovered. The entire process is repeated multiple times to find the best local optimum choice of medoids. These medoids are then used for clustering.

### 6.7.3.1.2 Similarity in Shape

Time series are considered similar if they tend to stay in proportion to each other and increase and decrease in value at the same time. For example, cities can be clustered based on their population growth rates. Although their actual population sizes are quite different, cities will be grouped into clusters if they follow similar patterns of population growth.
