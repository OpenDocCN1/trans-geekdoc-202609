WMS, WFS and WCS services operate using different forms of HTTP requests. A map server is accessed by a client application that sends requests including specific operations supported by these protocols in the form of HTTP URL strings. The URL sets the parameters to be returned, such as what portion of the Earth is to be mapped, and the dimensions of the output GeoTIFF image. A spatial database or file server stores spatial data, which can be accessed and utilised by the map server to draw maps or dynamically generate HTML, XML or GML (Geography Markup Language) (OGC 2007) files that can be used by a client to display maps. The client can be a web browser, a mobile app or a desktop GIS.

# 4.6.2 Elements of an Online Map

Online maps are characterised by interactivity, taking advantage of the interactive, interconnected, real-time and dynamic nature of the web environment. Therefore, in addition to the cartographic elements of traditional maps described in Section 4.1.1, online maps often include navigation tools (such as zoom, pan, place finders and bookmarks) and interactive elements. Generally, the map body of online maps is composed of base maps (or base layers) and thematical layers. The most common base maps for online mapping are vector road maps and remotely sensed imagery. For example, the base map shown in Figure 4.38 is the world imagery from the ArcGIS World Imagery service (https://

services.arcgis.com/ArcGIS/rest/services/World_Imagery/MapServer). Although a base map may consist of many layers (such as roads, lakes, buildings and so on), these are often fused together into a rasterised set of tiled map images or map tiles and treated as a single layer in an online map. The concept of map tiles is similar to that of subsampled layers in a raster pyramid discussed in Section 2.4.3. That is, a base map is broken up at each zoom level into a set of map tiles, which are arranged in an ordered grid. When a base map scrolls to a new location, or to a new zoom level, the mapping application determines which tiles are needed and translates that into a set of tiles to retrieve and display. These map tiles may consist of thousands or millions of predrawn images that are saved on the server and transferred to browsers as users pan around the map. In recent years, some applications use the base map sent by the server as chunks of vector coordinates, sometimes known as vector tiles. Many online maps contain a base map gallery that allows users to switch between maps like imagery and topography. For example, the online maps in Figure 4.38 have a base map gallery of nine base layers for users to choose.

Thematic layers are the focus of online maps. They are constructed using data layers from the server(s) and may contain features added directly to the map from a client by local users. Many online maps organise the thematic layers into groups, which may be brought in as one or more separate web services. Users can toggle on and off these layers in a browser.
