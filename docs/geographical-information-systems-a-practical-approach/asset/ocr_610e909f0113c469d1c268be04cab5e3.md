# 8.4.1.3 Profiles

A terrain profile is a 2D diagram that depicts the landscape in vertical cross section.

It shows changes in elevation, slope and curvature of the terrain surface along a specific line called a profile line or transect, such as a hiking trail or a road. The profile line can be a straight line or a polyline. The x-axis of the diagram represents horizontal distance from the starting point of the profile line, and the y-axis represents the elevation. With a GIS, when a profile line is drawn on a DEM or TIN, a terrain profile will be plotted with a certain vertical exaggeration factor. Figure 8.11 shows an example.
