## 6.7.3.3 Emerging Hotspot Analysis

Emerging hotspot analysis evaluates how hot and cold spots detected by using the Getis–Ord Gi* statistic (discussed in Section 6.5.2) are changing over time. It treats the series of Gi* statistics at each location

```
S = \sum_{k=1}^{n-1} \sum_{j=k+1}^{n} sign(x_j - x_k) \quad (6.53)
```

```
where:

sign(x_j - x_k) = \begin{cases} 1 & \text{if } x_j > x_k \\ 0 & \text{if } x_j = x_k \\ -1 & \text{if } x_j < x_k \end{cases}
```

S is the number of positive differences minus the number of negative differences. If S > 0, observations obtained later in time tend to be larger than observations made earlier. If S < 0, observations made later in time tend to be smaller than observations made earlier. The variance of S is given by:

```
var(S) = \frac{1}{18} \left[ n(n-1)(2n+5) - \sum_{p=1}^{g} t_p(t_p-1)(2t_p+5) \right] (6.54)
```

where g is the number of tied groups and t_p is the number of observations in the pth group. A tied group is a set of observations having the same value. For example, in the time series (23, 24, 29, 6, 29, 24, 24, 29, 23), we have g = 3 tied groups, for which t_1 = 24 and t_2 = 3 for the tied value 23, t_2 = 3 for the tied value 24 and t_3 = 3 for the tied value 29. In cases where the number of observations n > 10, the Mann–Kendall trend test statistic is calculated as follows:

```
Z_{mk} = \begin{cases} \frac{S-1}{\sqrt{var(S)}} & \text{if } S > 0 \\ 0 & \text{if } S = 0 \\ \frac{S+1}{\sqrt{var(S)}} & \text{if } S < 0 \end{cases} (6.55)
```

Z_mk has a standard normal distribution. A positive (negative) value of Z_mk indicates that the data tend to increase (decrease) with time. At a significance level \alpha, if |Z_{mk}| < Z_{1-\alpha/2}, H_0 cannot be rejected, where the notation Z_{1-\alpha} denotes the 100 \times (1-\alpha)^{th} percentile of the standard normal distribution; if Z_{mk} \ge Z_{1-\alpha} there exists a statistically significant upward monotonic trend in the time series; if Z_{mk} \le -Z_{1-\alpha}, there exists a statistically significant downward monotonic trend in the time series. At the 5 per cent significance level, the null hypothesis of no trend is rejected if |Z_{mk}| > 1.96.

Emerging hotspot analysis combines the Gi* and Mann–Kendall test statistics to evaluate whether there are any trends in hot or cold spots over time. It takes a space-time cube as an input and performs a hotspot analysis using the Gi* for each time-step. After hotspot analysis is complete, each bin in the input space-time cube receives an associated z-score, p-value and hotspot bin classification. The hot and cold spot trends are then evaluated using the Mann–Kendall trend test. With the result statistic Z_{mk} score and associated p-value for each location with data, and with the hotspot z-score and p-value for each bin, each location in the study area is categorised as follows:

- 1. No pattern detected.
- 2. New hot/cold spot, which is a statistically significant hot/cold spot for the final time-step but has never been a statistically significant hot/cold spot before.
- 3. Consecutive hot/cold spot, which has a single uninterrupted run of at least two statistically significant hot/cold spot bins in the final time-step intervals but has never been a statistically significant hot/cold spot prior to the final hot/cold spot run and has less than 90 per cent of all bins that are statistically significant hot/cold spots.
- 4. Intensifying hot/cold spot, which has been a statistically significant hot/cold spot for 90 per cent of the time-step intervals with the increasing intensity of clustering over time, including the final time-step.
- 5. Persistent hot/cold spot, which has been a statistically significant hot/cold spot for 90 per cent of the time-step intervals, with no discernible trend in the intensity of clustering over time.
- 6. Diminishing hot/cold spot, which has been a statistically significant hot/cold spot for 90 per cent of the time-step intervals, with the decreasing intensity of clustering over time, including the final time-step.
- 7. Sporadic hot/cold spot, which is a statistically significant hot/cold spot for the final time-step interval with a history of also being an on-again and off-again hot/cold spot. Less than 90 per cent of the time-step intervals have been statistically significant hot/cold spots, and none of the time-step intervals have been statistically significant cold/hot spots.
- 8. Oscillating hot/cold spot, which is a statistically significant hot/cold spot for the final time-step interval that has a history of also being a statistically significant cold/hot spot during a prior time-step. Less than 90 per cent of the time-step intervals have been statistically significant hot/cold spots.
- 9. Historical hot/cold spot, which is not hot/cold in the most recent time period, but at least 90 per cent of the time-step intervals has been statistically significant hot/cold spots.
