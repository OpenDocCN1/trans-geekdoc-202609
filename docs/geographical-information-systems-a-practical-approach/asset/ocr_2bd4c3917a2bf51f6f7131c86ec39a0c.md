The WFS standard specifies discovery, query, locking and transaction operations as well as operations to manage stored, parameterised query expressions for creating, modifying and exchanging feature data on the internet (OGC 2010). These operations allow geographical features or their attribute values to be retrieved from the underlying database based upon the spatial constraints and query criteria defined by a client. WFS services deliver map data in the standard XML (Extensible Markup Language) format. Data from some WFS services can also be downloaded as CSV (comma-separated values), Shapefile, KML and JSON (JavaScript Object Notation) files. A WFS service is mainly a feature access service,

but it can also be a feature-type service, a coordinate conversion/transformation service and geographical format conversion service. The WCS is a specification for serving raster and LiDAR datasets, referred to as coverages, over the web (OGC 2018). A coverage in WCS can be a multidimensional dataset representing spatially and temporally variable phenomena. This may include regular and irregular grids, point clouds and satellite imagery. Unlike WMS, a WCS service returns a coverage with its original properties intact, which can be interpreted, processed and extrapolated rather than just being simply viewed. It also allows the end user to directly download raster data in GeoTIFF or other image formats.
