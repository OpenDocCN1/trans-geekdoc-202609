The object-oriented data model stores spatial data (including geometry, topology and attributes) as objects. An object encapsulates both state and behaviour and can store all the relationships it has with other objects. Each object is defined as a separate component or building block, which can be used with other objects to form complex objects. These features allows users to create their own object-oriented models that extend a base model according to their own view and classification of the geographical features they study.
