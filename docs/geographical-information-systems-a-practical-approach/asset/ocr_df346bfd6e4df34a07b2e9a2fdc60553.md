In addition to feature classes, raster datasets and attribute tables, a geodatabase can also store network datasets, geometric networks, topologies, terrains, parcel fabrics (connected parcel features or parcel networks) and many others and use SQL to create, modify and query tables and their data elements (Allen 2019). Moreover, a geodatabase allows users to build spatial datasets with topological structures and add behaviour to them with no programming required. SQL has been extended to incorporate spatial types and functions (Shekhar and Chawla 2003). Therefore, the contents of relational tables containing feature geometries, when stored as an SQL spatial type, can be accessed through SQL.
