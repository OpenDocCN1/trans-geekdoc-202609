```
where:

sign(x_j - x_k) = \begin{cases} 1 & \text{if } x_j > x_k \\ 0 & \text{if } x_j = x_k \\ -1 & \text{if } x_j < x_k \end{cases}
```

S is the number of positive differences minus the number of negative differences. If S > 0, observations obtained later in time tend to be larger than observations made earlier. If S < 0, observations made later in time tend to be smaller than observations made earlier. The variance of S is given by:

```
var(S) = \frac{1}{18} \left[ n(n-1)(2n+5) - \sum_{p=1}^{g} t_p(t_p-1)(2t_p+5) \right] (6.54)
```

where g is the number of tied groups and t_p is the number of observations in the pth group. A tied group is a set of observations having the same value. For example, in the time series (23, 24, 29, 6, 29, 24, 24, 29, 23), we have g = 3 tied groups, for which t_1 = 24 and t_2 = 3 for the tied value 23, t_2 = 3 for the tied value 24 and t_3 = 3 for the tied value 29. In cases where the number of observations n > 10, the Mann–Kendall trend test statistic is calculated as follows:

```
Z_{mk} = \begin{cases} \frac{S-1}{\sqrt{var(S)}} & \text{if } S > 0 \\ 0 & \text{if } S = 0 \\ \frac{S+1}{\sqrt{var(S)}} & \text{if } S < 0 \end{cases} (6.55)
```

Z_mk has a standard normal distribution. A positive (negative) value of Z_mk indicates

that the data tend to increase (decrease) with time. At a significance level \alpha, if |Z_{mk}| < Z_{1-\alpha/2}, H_0 cannot be rejected, where the notation Z_{1-\alpha} denotes the 100 \times (1-\alpha)^{th} percentile of the standard normal distribution; if Z_{mk} \ge Z_{1-\alpha} there exists a statistically significant upward monotonic trend in the time series; if Z_{mk} \le -Z_{1-\alpha}, there exists a statistically significant downward monotonic trend in the time series. At the 5 per cent significance level, the null hypothesis of no trend is rejected if |Z_{mk}| > 1.96.

Emerging hotspot analysis combines the Gi* and Mann–Kendall test statistics to evaluate whether there are any trends in hot or cold spots over time. It takes a space-time cube as an input and performs a hotspot analysis using the Gi* for each time-step. After hotspot analysis is complete, each bin in the input space-time cube receives an associated z-score, p-value and hotspot bin classification.
