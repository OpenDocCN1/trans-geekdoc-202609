By substituting $I^c$ and $I^v$, respectively, with $I_i^c$ and $I_i^v$ in equation (6.20), the z score can be obtained for significance testing of the calculated $I_i$.

A positive $I_i$ value suggests the presence of positive local spatial autocorrelation, indicating that feature $i$ has neighbouring features with similarly high or low attribute values; thus, feature $i$ is part of a cluster. A negative $I_i$ value indicates that a feature has neighbouring features with dissimilar values (that is, negative local spatial autocorrelation), and the feature is an outlier (for example, a location with high values surrounded by neighbours with low values). In either case, the $p$-value associated with $I_i$ must be smaller than the pre-specified

significance level for the cluster or outlier to be considered statistically significant.
