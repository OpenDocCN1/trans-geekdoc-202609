ArcGIS Online is a cloud GIS offering SaaS services. It can be used to develop applications for web mapping and spatial data management and allows users to analyse and share spatial data. ArcGIS Online maps and services can be accessed on any device with an internet connection, including desktop, mobile and web applications. Users can author their maps with ArcGIS Desktop software or simply create maps by uploading their data using a web browser.

ArcGIS Platform is a cloud GIS providing PaaS services. It provides a wide range of spatial data (including base maps), mapping libraries and location services (such as routing and directions, geocoding and place finding and spatial analysis) for developers to build mapping and analysis applications or add mapping and location services to their products, solutions or business systems.

While ArcGIS Online provides a cloud GIS computing environment for mapping and analysis without the need for users to install, set up and maintain the GIS software, ArcGIS Enterprise is a server GIS that is installed on a single-server machine or scaled across many machines an organisation controls and manages, whether in the cloud, on premises or a mixture of them. It gives the organisation complete control over its deployment and allows centralised management and web-based delivery of GIS services for distributed mapping, spatial data management, spatial analysis and modelling.

### 1.5.2.2 TerrSet

TerrSet (formerly IDRISI) is an integrated desktop GIS and remote sensing software system developed by Clark Labs at Clark University which runs on the Windows platform (https://clarklabs.org/). Since 1987, it has been widely used in over 180 countries worldwide for environmental management, sustainable resource management and equitable resource allocation. It contains a comprehensive set of GIS analysis tools, including those for surface analysis, statistical analysis, decision analysis, change and time series analysis, a digital image processing toolkit and a variety of environmental modelling tools, including the Earth Trends Modeler for modelling time series of environmental trends, the Land Change Modeler for land change analysis and prediction, the Climate Change Adaptation Modeler for modelling future climate and its impacts, the Ecosystem Services Modeler for assessing the value of natural resources, the Habitat and Biodiversity Modeler for habitat assessment and biodiversity modelling and the GeOSIRIS for assessing deforestation, carbon emissions, agricultural revenue and carbon payments.

### 1.5.2.3 MapInfo Pro

MapInfo Pro is a Windows-based desktop GIS software system produced by Precisely (formerly Pitney Bowes Software and MapInfo Corporation) (www.precisely.com/). It was first released in 1986 as the Mapping Display and Analysis System (MIDAS), replaced by MapInfo for Windows in 1990 and renamed to MapInfo Pro in 1995. MapInfo Pro is well distributed and has been widely used in demographic analysis, business and service planning. The MapBasic and Python programming languages can be used to create additional tools, new functionality and custom applications for use with MapInfo Pro. It also allows users to access custom features and add-on functionality via the MapInfo Marketplace, a collaborative space where users can download and share plugins for the software.

### 1.5.2.4 GeoMedia

The GeoMedia product suite from Hexagon Geospatial consists of GeoMedia Essentials, GeoMedia Advantage, GeoMedia Professional and a set of add-on modules (www.hexagongeospatial.com/). It is a Windows-based desktop GIS software package. GeoMedia Essentials allows users to perform spatial query, conduct basic spatial analysis based on vector data and produce maps. GeoMedia Advantage adds raster data processing and analysis functions to the functionality of Essentials. GeoMedia Professional provides all the functionality of GeoMedia and adds spatial data capturing and editing functions as well as quality assurance and validation tools. GeoMedia has a number of add-on modules, such as GeoMedia 3D for 3D visualisation and analysis, GeoMedia Image for image processing, GeoMedia Mapping Manager for enhanced cartographic capabilities and GIS mapping automation and GeoMedia Transportation Manager for analysis and management of transportation infrastructure.

### 1.5.2.5 Maptitude

Maptitude is a desktop mapping software package developed by Caliper Corporation (www.caliper.com/). It runs under the Windows operating system. The package has many common features of desktop GIS software and also provides MapWizard for thematic mapping and the GIS Developer's Kit (GISDK) to enable developers to extend its functionality and develop new applications.

### 1.5.2.6 Azure Maps

Microsoft's Azure Maps is a cloud GIS offering PaaS services (https://azure.microsoft.com/en-au/services/azure-maps/). The Azure Maps services allow users to add maps, time zone, traffic and weather information as well as elevation data to various mobile and/or web applications, and to provide their applications with routing and place searching capabilities using the Azure Maps geospatial APIs. Its data service can be used to upload and store customers' own spatial data for use with spatial operations or image composition, and its spatial service can quickly analyse location information to help inform users of ongoing events happening in time and space, enabling near real-time analysis and predictive modelling of events.

### 1.5.2.7 Google Earth Engine

Google Earth Engine (GEE) is a cloud GIS which provides a cloud computing platform for global-scale spatial data and analysis (https://earthengine.google.com/). It combines a multi-petabyte catalogue of satellite imagery and other spatial datasets (including environmental and socio-economic variables, weather and climate forecasts, land use/land cover and topographic datasets) which are co-located with a high-performance, inherently parallel computation service and being updated and expanded on a daily basis (Gorelick et al. 2017). GEE allows users to visualise, process, manipulate and produce spatial data in an easy and fast way. It also incorporates a wide range of spatial data manipulation and analysis tools for users to detect changes, map trends and assess differences on the Earth's surface. In addition, users can upload their own spatial datasets to this cloud GIS platform and develop algorithms using JavaScript and Python programming languages.

### 1.5.3 Open-Source GIS Software

Over the last two decades, an increasing number of free and open-source GIS software packages have been made available. These software packages have their source code freely available for modification and redistribution by the general public. They do not charge license fees, and they use open standards that facilitate integration with other systems and are easily customisable. They are often developed and maintained by a community of shared interest. However, they do not offer professional support and lack release coordination. In spite of these disadvantages, open-source GIS provides unique opportunities to serve the low-cost high-control niches that are difficult, if not impossible, to cater for through commercial, proprietary avenues.
