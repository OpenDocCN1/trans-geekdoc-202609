The focal function ‘majority’ determines the cell value that occurs most often in the neighbourhood. Section 7.3 will provide a full discussion on spatial filters in digital image processing.

In addition to focal statistics, slope, aspect and surface curvature functions (see Section 8.4) are usually grouped into the focal functions, as their calculations are based on neighbourhood cell values. Practical 5.12 provides some examples of the use of focal functions in ArcGIS Pro and QGIS.

**Zonal functions** compute a new value for every cell in the output raster as a function of the existing values of the cells belonging to the same zone. A zone is a group of cells of the same value. It could make up a single region, or several disconnected regions that have the same value. Zonal functions calculate summary statistics of all the cell values in each zone and write the statistics into each cell of the zone in the output raster. The summary statistics include all those listed in Table 5.5. Zones are usually identified from another layer separate from the raster whose cell values are to be summarised statistically.
