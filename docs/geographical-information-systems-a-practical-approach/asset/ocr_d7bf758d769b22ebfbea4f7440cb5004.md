include feature classes, raster datasets and attribute tables. A feature class is stored as a table, in which each row represents a feature – a spatial object with a geometric shape. A feature class table has one distinguished field of type Geometry, referred to as the Shape field. This field stores the geometry for each feature in the table. The type of shape of a feature is defined by the feature class, which could be Point, Multipoints (features that are composed of more than one point), Polyline or Polygon. Figure 2.32 shows a polygon feature class table for a land cover layer. The Shape field in the table holds the polygon geometry for each feature. The value Polygon indicates that the field contains the coordinates and the geometry that defines one polygon feature in each row.

A raster dataset refers to an image (such as an orthoimage) or raster (such as a DEM) organised into one or more bands. Each band consists of a matrix of pixels or cells. A raster has a single band. An image may have one or more bands. In a geodatabase, a raster dataset is typically divided

into small tiles, referred to as blocks. The typical size of a block is about 128 rows by 128 columns or 256 rows by 256 columns. These blocks are stored in a table for each image or raster, which is called a block table. Each row in the block table represents a block. Figure 2.33 shows an example of a block table. The field Block Data in the table stores the block's tile of the raster. It has a BLOB data type. The block structure of a raster dataset allows only the blocks for an extent to be retrieved when they are needed, instead of the entire raster layer or image. In addition, it facilitates the building of an image or raster pyramid. A raster pyramid is a collection of the same raster or image with different resolutions. It is made by repeatedly subsampling the original raster or image dataset usually by a factor of 2 (reducing the resolution to half), as illustrated in Figure 2.34. A pyramid may contain many subsampled layers. It enables the rapid display of image or raster data by retrieving only the data at a specified resolution that is required for the display.
