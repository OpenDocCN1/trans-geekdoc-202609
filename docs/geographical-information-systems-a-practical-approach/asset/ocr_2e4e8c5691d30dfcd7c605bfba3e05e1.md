Through the appropriate positioning of online map elements on a web page, we can control the relationship between them to better guide the user experience. Since the user is the only person who clicks the mouse and interacts with the maps, simplicity is the best way to go when considering the user experience and the usability. In other words, the website layout of online maps should be made not only visually appealing but also intuitive, consistent and easy to use.

Layout design depends on the map’s purpose. For map or mapping services or information provision and data query through maps, the map body should occupy a large proportion of a web page, as shown in Figure 4.38. Some online maps cover the entire web page, such as Google Maps and Bing Maps. Navigational and interactive tools are often placed to or on the top left- or right-side of the map body. The placement of all the elements on the page needs to be visually balanced, whether through symmetry or balanced asymmetrical arrangements. Some online mapping websites use toggle-able menus to hide interactive elements and other tools in order to maximise the map display area. In most of these cases, only the map body and menu toggles are visible on the page. A menu toggle displays an option that the user can open (turn on) or close (turn off) a menu. Each time the user clicks the toggle, the status of the option switches. A good example is Earth Weather, which is an animated online map showing real-time global weather conditions, including current wind, weather, ocean and pollution conditions. As shown in Figure 4.39, the online map contains only one visible interactive element – a menu toggle labelled as

'Earth', to show or hide a menu of interactive tools for adding data layers or changing display parameters – placed at the bottom-left corner of the page. Clicking on a location in the map reveals information about the weather conditions at that location from the displayed data layers. The map can be zoomed by turning the mouse wheel and panned by dragging the mouse. The layout is neat and simple but serves the purpose well.

Online maps at a website should have a consistent layout so that they are easy to use and understand for all users. Consistency in layout design is about including common online map elements, keeping these elements in the same position on each map and having them look and behave the same way. A consistent layout should also have a clear, visual hierarchy to the elements on each map so that an online map is not only functional but also attractive from an aesthetic point of view.

In addition, the layout design should be mobile-friendly. More people are using their phones or other devices to access online maps. It is important to consider designing the website with a responsive layout where it can adjust to different screens.
