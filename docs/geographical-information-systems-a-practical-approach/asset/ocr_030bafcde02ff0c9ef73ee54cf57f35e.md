It also allows users to preview a spatial dataset on a map. ArcScene is used to create 3D maps, and ArcGlobe allows users to display spatial data in 3D on a globe surface. ArcMap and ArcGIS Pro are the main components. ArcMap is used to view, edit, create, manipulate and analyse spatial data. Its ArcToolbox contains an extensive set of spatial data manipulation and analysis tools, along with much of the functionality in ARC/INFO. ArcMap was superseded by ArcGIS Pro in 2015 but will continue to be supported until March 1, 2026. ArcGIS Pro includes most of the functionality available in ArcMap and incorporates catalogue functions, 3D visualisation and advanced AI-based analytical tools. It can be used to visualise 2D and 3D data simultaneously, manage multiple maps and share data across ArcGIS Online and ArcGIS Enterprise. As it is taking the place of ArcMap as the desktop software of choice, ArcGIS Pro is adopted for illustrations in this book and for practicals on the book's support material. Practical 1.1 provides a guided tour through ArcGIS Pro.

ArcGIS Online is a cloud GIS offering SaaS services. It can be used to develop

applications for web mapping and spatial data management and allows users to analyse and share spatial data. ArcGIS Online maps and services can be accessed on any device with an internet connection, including desktop, mobile and web applications. Users can author their maps with ArcGIS Desktop software or simply create maps by uploading their data using a web browser. ArcGIS Platform is a cloud GIS providing PaaS services. It provides a wide range of spatial data (including base maps), mapping libraries and location services (such as routing and directions, geocoding and place finding and spatial analysis) for developers to build mapping and analysis applications or add mapping and location services to their products, solutions or business systems.

While ArcGIS Online provides a cloud GIS computing environment for mapping and analysis without the need for users to install, set up and maintain the GIS software, ArcGIS Enterprise is a server GIS that is installed on a single-server machine or scaled across many machines an organisation controls and manages, whether in the cloud, on premises or a mixture of them.
