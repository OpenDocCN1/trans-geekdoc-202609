# Enterprise Geodatabases

Enterprise geodatabases are large, multi-user spatial databases. They are based on the geodatabase object-relational data model, stored and managed using an RDBMS, such as Oracle, Microsoft SQL Server, PostgreSQL, SAP HANA or IBM DB2. They can be used to manage extremely large spatial datasets, primarily used for data-centric spatial database applications in departmental and enterprise settings. They take advantage of the underlying RDBMS architecture to provide high performance, provide a multi-user access and editing environment with access control and support spatial data management for scalability, reliability, security, backup and data integrity. In addition to supporting many users with concurrent access to the same data, enterprise geodatabases can be integrated with an organisation’s existing IT systems.
