With the vector approach, true 3D geometric structures can be represented by multipatch features, which are made of planar 3D rings and triangles stitched together to model 3D objects like trees and buildings with overhanging features (Kennedy 2009). **Multipatches** represent the outer surface or isosurfaces of 3D features. They store texture, colour, transparency and geometric information representing different parts of the features. They are particularly useful for representing urban features to create 3D urban models to provide contexts

for studying environmental and economic development issues in cities. Figure 4.32 shows such an example, in which the annual mean PM2.5 distribution is mapped in a 3D virtual model of Clayton Campus, Monash University. The buildings in the 3D view are all multipatch features. GIS allows multipatch features to be created from 3D point and line symbols and extruded polygons, but it does not provide tools to create complex photorealistic 3D multipatch features. Other software packages such as SketchUp and AutoCAD are often used to create multipatch features to be imported into a GIS system.
