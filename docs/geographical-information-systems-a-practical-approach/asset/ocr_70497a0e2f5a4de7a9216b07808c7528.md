# 6.7.3.1.1 Similarity in Value

Using Euclidean distance as the similarity measure, a clustering algorithm is used to form clusters wherein individual time series have maximum similarity with other individual time series within the group (intra-cluster similarity), and minimum similarity in value with individual time series in other groups (inter-cluster similarity). k-means and k-medoids are two typical techniques for clustering time series data according to similarity in value.

Time series are similar if they have about equal values of a particular variable across time. For example, a time series with values (2, 1, 2, 1, 2) is more similar to (2, 2, 2, 2, 2) than it is to a time series with values (20, 10, 20, 10, 20) because the values are more similar. A simple, widely used measure of the similarity in value between time series is the Euclidean distance between the values in the time series (not to be confused with the distance in geographical space between the locations of the time series). This measure is calculated by taking the square root of the sum of squared differences in values across time.
