# Block Table

| Band | RRD | Row | Col | Block Data |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 3 | 1 | 1 | |
| 1 | 3 | 1 | 2 | |
| 1 | 3 | 1 | 3 | |
| 1 | 3 | 1 | 4 | |
| 1 | 3 | 1 | 5 | |
| 1 | 3 | 2 | 1 | |
| ... | ... | ... | ... | ... |

Band – Band number
RRD – Reduced resolution dataset (RRD) factor that determines the position of the block within the raster pyramid
Row – Block's row number
Col – Block's column number
Block data – a BLOB field storing the block's tile of the raster
