array_shift — prepends one or more elements to the beginning of an array

“array_shift() prepends passed elements to the front of the array. Note that the list of elements is prepended as a whole, so that the prepended elements stay in the same order. All numerical array keys will be modified to start counting from zero while literal keys won’t be touched. ”

Syntax:

```
int array_shift ( array &$array, mixed $value1 [, mixed $$... ] )
```

Example:

```
$first_array = array('Pete',‘Smith’,‘123 Main Street’,‘Atlanta’,‘CA’, 30001);
```

```
print(array_shift($first_array, “770-777-7777”, “adm@no.co”));
```

```
print_r($first_array);
```
