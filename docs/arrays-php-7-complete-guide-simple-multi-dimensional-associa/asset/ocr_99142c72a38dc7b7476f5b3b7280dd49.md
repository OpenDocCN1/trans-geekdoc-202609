Syntax:

```
array_diff ( array $array1 , array $array2 [, array $... ] )
```

Example:

```
$first_array = array("a", "b", "c", "d", "e");
$second_array = array("a", "d", "f", "g", "h");
$difference = array_diff($first_array,
$second_array);

print_r($difference);
```

Output:

```
Array (
[1] => b
[2] => c
[4] => e
)
```

In this example, the arrays are compared. If a difference is found, the key and value from the first array ($_first_array) is returned.

array_diff_assoc — computes the difference of arrays with additional index check, compares data by a callback function

"array_diff_assoc() returns an array containing all the values from array1 that are not present in any of the other arguments. Note that the keys are used in the comparison unlike array_diff() and array_udiff(). The comparison of arrays' data is performed by using an user-supplied callback."

Syntax:

```
array_udiff_assoc ( array $array1 , array $array2 [, array $... ], callable
```
