The function as is used with associative arrays to sort values. It sorts values in alphabetical order. In this example zip code is listed last because it is numeric. The remaining values are in alphabetical order. The keys (subscripts) are maintained.

# ksort — sorts an array by key in reverse order

> "Sorts an array by key in reverse order, maintaining key to data correlations. This is useful mainly for associative arrays."

# Syntax:

```
bool krsort ( array &$array, int $sort_flags = SORT_REGULAR )
```

# Example:

```
$first_array = array('first_name' => 'Pete', 'last_name' => 'Smith', 'address' => '123 Main Street', 'city' => 'Atlanta', 'state' => 'CA', 'zip_code' => 30001);
```

```
krsort($first_array);
print_r($first_array);
```

# Output:

```
Array (
[zip_code] => 30001
[state] => CA
[last_name] => Smith
[first_name] => Pete
[city] => Atlanta
```
