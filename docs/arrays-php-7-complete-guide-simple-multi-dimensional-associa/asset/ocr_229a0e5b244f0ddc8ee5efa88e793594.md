ksort — sorts an array by key

“Sorts an array by key, maintaining key to data correlations. This is useful mainly for associative arrays.”

Syntax:

```
bool ksort ( array &$array, int $sort_flags = SORT_REGULAR )
```

Example:

```
$first_array = array('first_name' => 'Pete', 'last_name' => 'Smith', 'address' => '123 Main Street', 'city' => 'Atlanta', 'state' => 'CA', 'zip_code' => 30001);
```

```
ksort($first_array);
print_r($first_array);
```

Output:

```
Array (
[address] => 123 Main Street
[city] => Atlanta
[first_name] => Pete
[last_name] => Smith
[state] => CA
[zip_code] => 30001
)
```

ksort sorts array kesy in alphabetical order. In this example, address is now first in the array.
