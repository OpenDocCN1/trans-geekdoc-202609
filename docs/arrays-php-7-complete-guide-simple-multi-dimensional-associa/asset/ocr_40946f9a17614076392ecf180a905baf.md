Only two minor changes (besides the array itself), are needed from the original example from chapter 2. The data type of the second subscript is changed to string and the string subscript (first_name) is passed to the method. As we have seen before this will replace Pete with Peter. Again, if the position does not exist, it will insert the value into the position.
