By using associate arrays we don’t have to worry about the order in which values are saved. In the example, the two arrays are saved in reverse order. However, we access the values by the alphabetical subscript names, not position. print $customer_record[0]['first_name'] will display the value in that location (default) no matter where it actually located in the array.
