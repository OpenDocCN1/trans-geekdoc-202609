An array is nothing more than a container of multiple properties. array is given a name (such as $customer_records) using the same syntax as a property. This one is used for storing and reviewing every value in the array. Since the same name is used to access every value in the array, there needs to be a way determine where a value is stored or retrieved. This is done by using a subscript. In most languages a subscript is a numerical value. However, as we will see later, PHP arrays also allow alphabetical subscripts.

Note: PHP actually has only one type of arrays. This allows numerical or alphabetic. The term “Associative Arrays” is used to describe PHP arrays with alphabetic. However, all PHP arrays are stored in memory in the same format. We will discuss associative arrays a little later.

We can replace the individual properties (such as $first_name) with the array name plus ($customer_records[0]).

Example 1–4 – process_customer_record.php

```
<?php
// accepts information from example1.html
// This is NOT a complete program. Validate methods shown need to be created
clean any // input
$customer_record[0] = validate_first_name($_POST['first_name']);
$customer_record[1] = validate_last_name($_POST['last_name']);
$customer_record[2] = validate_address($_POST['address']);
$customer_record[3] = validate_city($_POST['city']);
$customer_record[4] = validate_state($_POST['state']);
$customer_record[5] = validate_zip_code($_POST['zip_code']);
print "Your name is $customer_record[0] $customer_record[1].
nYou live at $customer_record[2], $customer_record[3],
$customer_record[4], $customer_record[5]"";
?>
```

In Example 1-4, the individual records are replaced with locations within the array $customer_record to store the values retrieved. In most programming languages, arrays subscripts must be numbered beginning with zero. Unlike many other languages, PHP allows us to dynamically create our array locations when needed (as shown in Example 1-4).
