ukort sorts an array in ascending order by keys (subscripts) based on the comparison provided by a user supplied function. The function must determine what is equal, is greater than, and what is less than. The keys (subscripts) from the original array are maintained.

The user can modify the comparison shown (such as using === instead of ==) to determine what is ‘equal’. The user supplied function must return a value < 0, 0, and > 0, as shown in the example function.

```
uksort($first_array, "strcmp");
print_r($first_array);
```

A PHP comparison function can be used instead of a user defined function. These could include strcmp, strcasecmp, strnatcasecmp, substrcmp, or other PHP comparison functions that return < 0, 0, or > 0 as a result.
