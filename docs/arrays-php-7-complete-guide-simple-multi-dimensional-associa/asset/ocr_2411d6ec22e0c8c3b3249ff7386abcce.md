```
$count = sizeof($first_array);

for($I=0; $I < $count; $I++)
{
    print $first_array[$I] . "<br />";
}
```

30001

sizeof will return the size of the array. Arrays are numbered starting at zero. The last position would be one less than the value returned. Thus, the for loop used continues until $I is no longer less than the value in $count. Notice the example determines the size before the loop, instead of inside the for loop. This provides only one execution of the sizeof function instead of calling it seven times in the above example. See count for another example.
