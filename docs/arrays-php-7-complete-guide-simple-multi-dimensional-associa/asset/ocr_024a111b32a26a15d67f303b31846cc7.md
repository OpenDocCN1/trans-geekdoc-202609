range provides a quick way to generate sequential values for an array.

# Example:

```
print_r(range('A', 'F'));
```

# Output:

```
Array (
[0] => A
[1] => B
[2] => C
[3] => D
[4] => E
[5] => F
)
```

You are not limited to just numerical values.

# Example:

```
print_r(range('F', 'A'));
```

# Output:

```
Array (
[0] => F
[1] => E
[2] => D
[3] => C
[4] => B
[5] => A
)
```
