当这种情况发生时，程序的执行流也将跳转到最后。这会将执行流传回外层循环的顶部，获取下一行（如果有）。循环内部的 `print` 语句显示每行中的值。上面使用的格式不允许我们检索下标数字（0, 1）或列下标（0, 1, 2, 3, 4, 5）。要要访问这些信息，我们必须将 $row 属性拆分为两个部分。目前 $row 是将要访问的实际数组（行）。要访问下标，我们必须使用以下格式同时请求行下标和行中的值：
