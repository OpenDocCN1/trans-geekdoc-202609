array_udiff_uassoc — computes the difference of arrays with additional index check, compares data and indexes by a callback function

“Returns an array containing all the values from array1 that are not present in any of the other arguments.”

# Syntax:

array_udiff_uassoc ( array $array1 , array $array2 [, array $... ], callable $value_compare_func , callable $key_compare_func )
