foreach loops can also be used to populate an array with values. It is common
pract to provide initial values in an array, especially if the array will be used
in calculations. In chapter 1, we talked about the possibility that an array, in
some program languages, could contain a NULL value. If an attempt is made
to do a calculation on a position in an array that contains a NULL value, an
Error will be thrown. This can be avoided by providing initial values.

```
foreach($customer_record as $row => $row_array)
{
  foreach($row_array as $column => $column_value)
  {
    $customer_record[$row][$column] = "default";
  }
}
```
