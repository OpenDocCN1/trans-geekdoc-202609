To add an alphabetical subscript to this example we use the syntax discovered in foreach loops. key => value is used to define each position in the array. The key is the subscript name ('first_name'). The value is the information placed in the location ('Pete').

```
'first_name' => 'Pete'
'last_name' => 'Smith'
'address' => '123 Main Street'
'city' => 'Atlanta'
'state' => 'GA'
'zip_code' => 30001
```

We can then retrieve a value using its subscript name.

```
print $customer_record[0]['last_name'];
Smith
```
