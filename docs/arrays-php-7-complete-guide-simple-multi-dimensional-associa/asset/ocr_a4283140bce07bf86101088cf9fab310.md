The PHP function file_put_contents will dump the contents of a property into a file. It will overwrite whatever is already in the file. It will also create the file if it does not exist.

However, remember it is assumed JSON data is stored in the file. To convert the array into JSON format the PHP method json_encode is called. This converted JSON data is then stored in the file customer_data.json.
