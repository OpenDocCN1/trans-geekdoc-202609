```php
$first_array = array('a' => 1, 'b' => 2, 'c' => 3);

array_u_sort($first_array, function($a, $b) {
    return $a <=> $b;
});

print_r($first_array);
```

Output:

Array
(
[a] => 1
[b] => 2
[c] => 3
)

array_u_keysort — sorts an array by its keys using a user comparison function

“array_u_keysort() sorts an array by its keys using a user-defined callback function to compare keys.”

Syntax:

```
bool array_u_keysort ( array &$array, callable $callback, int $flags = SORT_REGULAR, int $order = SORT_ASC )
```

Example:

```php
$first_array = array('c' => 3, 'a' => 1, 'b' => 2);

array_u_keysort($first_array, function($a, $b) {

print_r($first_array);
```

Array

[c] => 3
)

array_walk_recursive — applies a function to each element of an array

“array_walk_recursive() applies a callback function to each element of an array, including nested arrays.”

Syntax:

```
void array_walk_recursive ( array &$array, callable $callback, mixed $userdata = null )
```

Example:

```php
$first_array = array('first_name' => 'Pete', 'info' => array('city' => 'Atlanta'));

array_walk_recursive($first_array, function($value, $key) {
    $value = strtoupper($value);
});

print_r($first_array);
```

Output:

Array
(
[first_name] => PETE
[info] => Array
    (
        [city] => ATLANTA
    )
)
