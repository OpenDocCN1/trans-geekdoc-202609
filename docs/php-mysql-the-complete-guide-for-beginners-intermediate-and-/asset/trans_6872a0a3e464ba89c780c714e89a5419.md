## 第 77.1 节：使用 PHP-ML 进行分类

机器学习中的分类问题是识别新观测值属于哪组类别的问题。分类属于监督式机器学习范畴。

![](Image01479.jpg)任何实现分类的算法都称为分类器。

PHP-ML 支持的分类器有：

![](Image01480.jpg)
- SVC（支持向量分类）
- k-近邻算法
- 朴素贝叶斯

所有分类器的 `train` 和 `predict` 方法相同。唯一的区别在于所用的底层算法。
