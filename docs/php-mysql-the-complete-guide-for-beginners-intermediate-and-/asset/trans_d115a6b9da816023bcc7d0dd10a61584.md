## 第 48.3 节：数据存储与访问

![](Image01117.jpg)本主题专门讨论 UTF-8 以及将其与数据库一起使用时的注意事项。如果你想了解更多关于在 PHP 中使用数据库的信息，请查看该主题。

在 MySQL 数据库中存储数据：

![](Image01118.jpg)在数据库的所有表和文本列上指定 `utf8mb4` 字符集。这使得 MySQL 以 UTF-8 原生编码物理存储和检索值。

| utf8mb4_ |
| --- |

![](Image01119.jpg)如果指定了 `*` 排序规则（不带任何显式字符集），MySQL 将隐式使用 `utf8mb4` 编码。

旧版本的 MySQL (< 5.5.3) 不支持 `utf8mb4`，因此你将被迫使用 `utf8`，它仅支持 Unicode 字符的一个子集。

在 MySQL 数据库中访问数据：

![](Image01120.jpg)在你的应用程序代码中（例如 PHP），无论你使用哪种数据库访问方法，都需要将连接字符集设置为 `utf8mb4`。这样，当 MySQL 将数据传递给你的应用程序时（反之亦然），不会从其原生 UTF-8 进行转换。

![](Image01121.jpg)某些驱动程序提供自己的机制来配置连接字符集，这既更新了其自身的内部状态，又通知 MySQL 连接上将使用的编码。这通常是首选方法。

例如（关于 `utf8mb4` / `utf8` 的相同考虑如上所述）：

| [set_charset](http://www.php.net/manual/en/mysqli.set-charset.php) |
| --- |

```
$handle = new PDO('mysql:charset=utf8mb4');
```

