# Gaussian Mixture Models (GMMs)

- Mixture coefficient:
$p(k) = \pi_k, \text{with } 0 \le \pi_k \le 1, \sum_{k} \pi_k = 1$

- Mixture component:
$p(x|k) = \mathcal{N}(x|\mu_k, \Sigma_k)$

- Mixture distribution:
$p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x|\mu_k, \Sigma_k)$

- Always integrates to 1
- Parameters of the mixture
$$\theta = \{\pi_1, \mu_1, \Sigma_1, \dots, \pi_K, \mu_K, \Sigma_K\}$$

# Which divergence to use?

- In the simplest case, we just use forward KL
$$KL(p^*||q) = \int p^*(x) \log \frac{p^*(x)}{q(x)} dx$$
- But as a function of argument z of sigmoid, only one of them is convex!

# Maximum likelihood of a mixture

- (Marginal-)Log-Likelihood $\mathcal{L}(\theta) = \sum_{i=1}^{N} \log p_{\theta}(\boldsymbol{x}_i)$

- For learning generative models $q(x)$ from data we need to minimize a divergence
$q^* = \text{argmin}_q D(q, p^*)$

- The KL-divergence is one of the most commonly used loss functions
- It exists in two variants with different properties:
  - Forward: Mode averaging
  - Reverse: Mode seeking

The known Maximum Likelihood solution is a special case $D(q, p^*) = \text{KL}(p^*||q)$ (forward KL). The choice of divergence and distribution q also governs complexity.

# Estimating Gaussian Mixture Models

So why is optimizing $\mathcal{L} = \sum_{i=1}^{N} \log p_{\theta}(\boldsymbol{x}_i)$ so hard?

- Because we do not know which mixture component created which data point
- If we would have data from the joint distribution $p(\boldsymbol{x}_i, k_i|\theta)$, then it would be easy

In this case, we can simply perform a maximum likelihood estimate:

- Coefficients: $\pi_k = \frac{\sum_i q_{ik}}{N}$
- Means: $\mu_k = \frac{\sum_i q_{ik}\boldsymbol{x}_i}{\sum_i q_{ik}}$
- Covariances: $\boldsymbol{\Sigma}_k = \frac{\sum_i q_{ik}(\boldsymbol{x}_i - \mu_k)(\boldsymbol{x}_i - \mu_k)^T}{\sum_i q_{ik}}$

where $q_{ik} = \mathbb{I}(k, k_i)$ is 1 if the ith sample belongs to the kth component and 0 otherwise

# Expectation-Maximization: Chicken and Egg...

Yet, we do not know which component belongs to which sample

- Can we estimate that? Given a current mixture model, yes!
- Compute cluster probabilities aka responsibilities for each sample (Bayes rule)

$$q_{ik} = p(k_i = k|x_i) = \frac{p(x_i|k)p(k)}{\sum_{j=1}^K \pi_j \mathcal{N}(x_i|\mu_j, \mathbf{\Sigma}_j)}$$

- Responsibilities $q_{ik}$ are now continuous between 0 and 1
- But we need to know the Gaussian components

# EM for Gaussian Mixture Models

# Expectation-Maximization algorithm

- E-step: Compute responsibilities $q_{ik}$
- M-step: Update parameters $\pi_k, \mu_k, \boldsymbol{\Sigma}_k$ using $q_{ik}$
- Repeat- until convergence
