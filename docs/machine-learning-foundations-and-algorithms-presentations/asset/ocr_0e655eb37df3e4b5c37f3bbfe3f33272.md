# Maximum a-posteriori solution

“Poor men’s” Bayesian Learning:

+   1. Find the parameter vector $\theta_{MAP}$ that maximizes the posterior
$$\theta_{MAP} = \arg \max_{	heta} p(	heta|\mathcal{D}) = \arg \max_{	heta} p(\mathcal{D}|	heta)p(	heta)$$
- Uncertainty in $\theta$ is ignored
- Optimization is done in log-domain
$$\theta_{MAP} = \arg \max_{	heta} \log p(\mathcal{D}|\theta) + \log p(\theta)$$$
2. Use $\theta_{MAP}$ for prediction $p(x^*|\mathcal{D}) \approx p(x^*|\theta_{MAP})$
- We still use point estimate - no model uncertainty

**Recap (Lecture 1):** The MAP solution is the same as the standard ML solution with L2 regularization (e.g. Ridge regression)
