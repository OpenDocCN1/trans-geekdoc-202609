# Algorithm: EM for GMMs

+   * **Initialize**: Mixture Components + Mixture coefficients
  - E.g. Use k-means for the component means and some initial covariance

+   * **Repeat** until convergence:
  - **Expectation-step**: Compute responsibilities
  $$q_{ik} = \frac{\pi_k \mathcal{N}(oldsymbol{x}_i|oldsymbol{\mu}_k, oldsymbol{\Sigma}_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(oldsymbol{x}_i|oldsymbol{\mu}_j, oldsymbol{\Sigma}_j)}$$
  - **Maximization-step**: Update coefficients, components means and component variance
  $$\pi_k = \frac{\sum_i q_{ik} oldsymbol{x}_i}{\sum_i q_{ik}} \quad oldsymbol{\Sigma}_k = \frac{\sum_i q_{ik}(oldsymbol{x}_i - oldsymbol{\mu}_k)(oldsymbol{x}_i - oldsymbol{\mu}_k)^T}{\sum_i q_{ik}}$$
