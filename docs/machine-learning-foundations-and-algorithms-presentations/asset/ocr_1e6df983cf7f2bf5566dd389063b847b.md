# ## Variational Inference

$$\arg \min_q KL(q(x)||p^*(x)) = \int q(x) \log \frac{q(x)}{p^*(x)} dx$$

+   - Bayes by Backprob (rather slow)
- Natural gradients
- Diagonal gaussian used in most cases, but low-rank approximations exists
