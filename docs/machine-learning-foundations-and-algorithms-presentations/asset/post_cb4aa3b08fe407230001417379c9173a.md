
## Expectation-Maximization: Chicken and Egg...

Yet, we do not know which component belongs to which sample

- Can we estimate that? Given a current mixture model, yes!

- Maximization Step:
  - Compute (weighted) maximum likelihood estimate

  $$\pi_k = \frac{\sum_i q_{ik}}{N} \quad \mu_k = \frac{\sum_i q_{ik}\mathbf{x}_i}{\sum_i q_{ik}} \quad \mathbf{\Sigma}_k = \frac{\sum_i q_{ik}(\mathbf{x}_i - \mu_k)(\mathbf{x}_i - \mu_k)^T}{\sum_i q_{ik}}$$
- But we need to know the responsibilities

## Algorithm: EM for GMMs

- **Initialize**: Mixture Components + Mixture coefficients
  - E.g. Use k-means for the component means and some initial covariance

- **Repeat** until convergence:
  - **Expectation-step**: Compute responsibilities
  $$q_{ik} = \frac{\pi_k \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}$$
  - **Maximization-step**: Update coefficients, components means and component variance
  $$\pi_k = \frac{\sum_i q_{ik} \boldsymbol{x}_i}{\sum_i q_{ik}} \quad \boldsymbol{\Sigma}_k = \frac{\sum_i q_{ik}(\boldsymbol{x}_i - \boldsymbol{\mu}_k)(\boldsymbol{x}_i - \boldsymbol{\mu}_k)^T}{\sum_i q_{ik}}$$

## Practical considerations...

How **many mixture components** do we need?

- More components will typically lead to a better likelihood
- But are more components necessarily better? Not always, because of overfitting!
- It's again a model-selection problem (cross-validate on a validation-set)
- Bayesian methods can be used to integrate out number of components (tricky to get them to work)

How do we initialize:

- EM can give very poor results with wrong initialization
- Most common approach:
  - Use k-means (simple clustering algorithm) to initialize the centers
  - Use a fixed value for the covariance

## A generalized view on EM

## Mixture Models are Latent Variable Models

Mixture models are an instance of latent variable models

- Examples: mixture models, missing data, latent factors,
- Observed variables: **x**, Latent variables: **z** (e.g., index k of mixture component)

Parametric model: $p_{\theta}(\boldsymbol{x}, z) = p(\boldsymbol{x}|z)p(z)$, for GMM: $p_{\theta}(\boldsymbol{x}, k) = p(\boldsymbol{x}|k)p(k)$

Marginal distribution: $p_{\theta}(\boldsymbol{x}) = \sum_{z} p(\boldsymbol{x}, z), \quad p_{\theta}(\boldsymbol{x}) = \int_{z} p_{\theta}(\boldsymbol{x}, z)dz$
discrete latent variable
continuous latent variable

(Marginal) Log-Likelihood:
$L(\theta) = \sum_{i=1}^{N} \log \left(\sum_{z} p_{\theta}(\boldsymbol{x}_i, z)\right)$

... which is **hard to optimize** for all latent variable models (due to log of a sum)

## Expectation-Maximization (EM)

Expectation-Maximization (EM) is a general algorithm for estimating latent variable models

- Most common application: Gaussian Mixture models
- ... many other (deep) models as well
- Its extension is called Variational Bayes, which is underlying variational auto-encoder and other variational inference techniques
- Very hot research topic... pays off to look into the math of it

EM can be derived in 2 ways:

- Jensen's inequality (not covered, see GKI)
- Decomposition in lower-bound and KL-term (harder to understand, but more insightful)

## Expectation-Maximization (EM)

EM uses a lower bound of the marginal log-likelihood for the optimization

- For simplicity, lets consider only a single data-point first

$$\log p(\boldsymbol{x}|\boldsymbol{\theta}) = \sum_{z} q(z) \log \frac{p(\boldsymbol{x}, z|\boldsymbol{\theta})}{q(z)} + \sum_{z} q(z) \log \frac{q(z)}{p(z|\boldsymbol{x})}$$
$$\text{marginal log-like} \text{ Lower Bound } \mathcal{L}(q,\boldsymbol{\theta}) \text{ KL Divergence: KL}(q(z)||p(z|\boldsymbol{x}))$$

Where $q(z)$ is called the variational / auxiliary distribution

- This decomposition holds for any $q(z)$
- By introducing $q(z)$, the optimization will become much simpler

Why is that the same?

- We can use Bayes rule for $p(z|\boldsymbol{x}) = \frac{p(\boldsymbol{x}, z|\boldsymbol{\theta})}{p(\boldsymbol{x}|\boldsymbol{\theta})}$ and all terms except $p(\boldsymbol{x}|\boldsymbol{\theta})$ cancel

## Recap: Kullback-Leibler Divergences

The KL-divergence is an important similarity measure for distributions

```
$KL(q(x)||p(x)) = \sum_{x} q(x) \log \frac{q(x)}{p(x)}$
```

- Its always non-negative
- If its zero, both distributions are the same:
- It is non-symmetric (hence, its not a distance metric):

$KL(q||p) \geq 0$
$KL(q||p) = 0 \iff q = p$
$KL(q||p) \neq q$

- Can be used to find different approximations
- Used a lot in Variational Inference, Information theory

## EM-Decomposition

Derivation:

$\log p(\boldsymbol{x}) = \sum_{z} q(z) \log p(\boldsymbol{x})$

1. Introduce variational distribution $q(z)$
$\log p(\boldsymbol{x}) = \sum_{z} q(z) \log \frac{p(\boldsymbol{x}, z)}{p(z|\boldsymbol{x})}$

2. Use Bayesian theorem $p(\boldsymbol{x}) = \frac{p(\boldsymbol{x}, z)}{p(z|\boldsymbol{x})}$
$\log p(\boldsymbol{x}) = \sum_{z} q(z) \log \frac{p(\boldsymbol{x}, z)}{p(z|\boldsymbol{x})}$

3. Add and subtract $\log q(z)$
$\log p(\boldsymbol{x}) = \sum_{z} q(z) \log \frac{p(\boldsymbol{x}, z)}{q(z)} + \sum_{z} q(z) \log q(z)$

4. Write as sums
$\mathcal{L}(q,\theta) = \sum_{z} q(z) \log p(\boldsymbol{x}, z) - \sum_{z} q(z) \log q(z)$

## EM Decomposition

Marginal Likelihood decomposes in 2 terms:
$\mathcal{L}(q,\theta) = \sum_{z} q(z) \log p(\boldsymbol{x}, z) - \sum_{z} q(z) \log q(z)$

- Why is it a lower bound?
- Since $KL(q||p) \geq 0$ it follows that $\mathcal{L}(q,\theta) \leq \log p(\boldsymbol{x})$

## Expectation-Maximization Steps

EM iteratively applies 2 steps:

- (E)x-step: $q(z) = \arg\min_q KL(q(z)|p(x))$
- Find $q(z)$ that minimizes KL
- Can be done in closed form for discrete $z$ (e.g. mixtures):
q(z) = p(z|x,\theta_{old}) = \frac{p(x,z|\theta_{old})}{\sum_z p(x,z|\theta_{old})}$

- Observations:
- The marginal log-likelihood $log p(x|\theta)$ is unaffected by the E-step
- As KL is minimized, lower bound has to go up
- After the E-step $KL(q(z)|p(x)) = 0$ and therefore, the lower bound is tight, i.e.:
$\log p(x|\theta) = \mathcal{L}(q,\theta)$

## Expectation-Maximization Steps

EM iteratively applies 2 steps:

$\mathcal{L}(q,\theta) = \sum_{z} q(z) \log p(\boldsymbol{x}, z|\theta) - \sum_{z} q(z) \log q(z)$

- (M)maximization-step:
  * $\theta = \arg \max \mathcal{L}(q,\theta) = \arg \max \sum_{z} q(z) \log p(\boldsymbol{x}, z|\theta) + \text{const}$
  * Maximize lower bound with respect to $\theta$
  * This is the **weighted maximum likelihood** objective
    * Each possible value of the missing data is weighted by $q(z) = p(z|\boldsymbol{x}, \theta_{\text{old}})$
