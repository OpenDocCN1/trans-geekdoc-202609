# Wrap-Up

What we have learned today:

+   - In VI we approximate an intractable target distribution with a tractable one using optimization
- VI is formulated as reverse KL minimization problem
- Reverse KL can generate high quality generative models (no mode averaging)
- Most common approximations are Gaussian meanfield approximations (for high-D parameters) or Gaussian Mixture Models (for low-D parameters)
- We have looked at different methods to compute the gradient of the reverse KL
- Black-box VI, Bayes by Backprob, Natural Gradients
