# Gaussian propagation

Given marginal $p(x) = \mathcal{N}(x|oldsymbol{\mu}_x, oldsymbol{\Sigma}_x)$ and conditional $p(y|x) = \mathcal{N}(y|oldsymbol{F}x, \sigma_y^2oldsymbol{I})$ we want to obtain the marginal for y

+   - The marginal distribution $p(y) = \int p(x)p(y|x)dx$ is Gaussian with
  - Mean: $oldsymbol{\mu}_y = oldsymbol{F}oldsymbol{\mu}_x$
  - Variance: $oldsymbol{\Sigma}_y = \sigma_y^2oldsymbol{I} + oldsymbol{F}oldsymbol{\Sigma}_xoldsymbol{F}^T$
  - Derivation:
    - Use Eq (1) to obtain joint distribution
    - Marginal $p(y)$ can be directly read from the joint
  - Variance in $y$ increases due to uncertainty in $x$

+   **In a Gaussian linear model, all the marginals stay Gaussian!**
- And we can compute the marginals in closed form!
