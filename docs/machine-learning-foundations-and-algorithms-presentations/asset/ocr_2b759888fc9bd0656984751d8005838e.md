# Logistic sigmoid function

Sigmoid function:

```
$\sigma(a) = \frac{1}{1 + \exp(-a)}$
```

+   - Output is bounded between 0 and 1
- Smooth

![](bbox=[0.513, 0.155, 0.936, 0.663])

For linear classification:

+   - Squash the output of the linear function
- Minimize the loss

```
$L(\boldsymbol{w}) = \sum_{i} (\sigma(f(\boldsymbol{x}_i)) - c_i)^2 = \sum_{i} (\sigma(\boldsymbol{w}^T \boldsymbol{x} + b) - c_i)^2$
```
