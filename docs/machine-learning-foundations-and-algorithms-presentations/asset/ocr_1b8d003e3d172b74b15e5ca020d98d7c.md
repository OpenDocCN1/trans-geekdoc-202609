# Kernel ridge regression

The “kernelized” solution is given by:

$w^* = \Phi^T \underbrace{(\Phi\Phi^T + \lambda\mathbf{I})^{-1}}_{N\times N \text{ matrix inversion}} y = \Phi^T \underbrace{(\mathbf{K} + \lambda\mathbf{I})^{-1}y}{\alpha} = \Phi^T \alpha$

+   - Instead of inverting a d x d matrix, we can now invert an N x N matrix
- Is beneficial for d >> N (e.g., d is infinite)
- Still, $w^* \in \mathbb{R}^d$ is potentially infinite dimensional and can not be represented

Yet, we can evaluate the function f that is specified by $w^*$:

$f(x) = \phi(x)^T w^* = \phi(x)^T\Phi^T \alpha = k(x)^T\alpha = \sum_{i} \alpha_i k(x_i, x)$

+   - The function is evaluated by a weighted sum of kernel activations evaluated at the training data
