# Predictive distribution

Predictive GP distribution:

+   - Mean:
  $\mu(x^*) = k_{x^*}^T(K+\sigma_y^2 I)^{-1}y$
- Variance:
  $\sigma^2(x^*) = k^* + \sigma_y^2 - k_{x^*}^T(K+\sigma_y^2 I)^{-1}k_{x^*}$

Observations:

+   - mean corresponds to the Kernel Ridge Regression solution
- Yet, we also get an input dependent variance estimate
- Epistemic uncertainty: Variance is reduced if kernel activations are high
