
## Basics: Gaussian Bayes rules

Bayes rule for Gaussian distribution:

- Marginal: $p(x) = \mathcal{N}(x|\mu_x, \Sigma_x)$
- Conditional: $p(y|x) = \mathcal{N}(y|Fx, \sigma_y^2I)$

### Gaussian Bayes Rule 1: The posterior $p(x|y)$ is Gaussian with

- Mean: $\mu_{x|y} = \mu_x + \Sigma_x F^T(\sigma_y^2I + F\Sigma_x F^T)^{-1}(y - F\mu_x)$
  Correction Term
- Covariance: $\Sigma_{x|y} = \Sigma_x - \Sigma_x F^T(\sigma_y^2I + F\Sigma_x F^T)^{-1}F\Sigma_x$
  Variance/Uncertainty is reduced by new information

Same Equations as in Kalman Filtering

- Derivation: Use Eq (1) to form joint $p(x,y)$ from marginal $p(x)$ and conditional $p(y|x)$. Use Eq (2) to form posterior $p(x|y)$ from joint $p(x,y)$

## Basics: Gaussian Bayes rules

Bayes rule for Gaussian distribution:

- Marginal: $p(\boldsymbol{x}) = \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_{\boldsymbol{x}}, \boldsymbol{\Sigma}_{\boldsymbol{x}})$
- Conditional: $p(\mathbf{y}|\boldsymbol{x}) = \mathcal{N}(\mathbf{y}|F\boldsymbol{x}, \sigma_y^2 I)$

- Gaussian Bayes Rule 2: The posterior $p(\boldsymbol{x}|\mathbf{y})$ is Gaussian with
  - Mean: $\mu_{\boldsymbol{x}|\mathbf{y}} = \boldsymbol{\mu}_{\boldsymbol{x}} + (\sigma_y^2 \mathbf{I} + \boldsymbol{\Sigma}_{\boldsymbol{x}}F^T F)^{-1} \boldsymbol{\Sigma}_{\boldsymbol{x}}F^T(\mathbf{y}-F\boldsymbol{\mu}_{\boldsymbol{x}})$
  - Covariance: $\boldsymbol{\Sigma}_{\boldsymbol{x}|\mathbf{y}} = (\boldsymbol{\Sigma}_{\boldsymbol{x}}^{-1} + \sigma_y^{-2} F^T F)^{-1} \sigma_y^2(\sigma_y^2 \mathbf{I} + \boldsymbol{\Sigma}_{\boldsymbol{x}}F^T F)^{-1} \boldsymbol{\Sigma}_{\boldsymbol{x}}$

- Derivation: Use following identities for Bayes rule 1 from the matrix cookbook...
  - Use identity $\mathbf{A}(\mathbf{I} + \mathbf{BA})^{-1} = (\mathbf{I} + \mathbf{AB})^{-1}\mathbf{A}$ for the mean (Searl identity)
  - Use identity $(\mathbf{A} + \mathbf{BC}^T)^{-1} = \mathbf{A}^{-1} - \mathbf{A}^{-1}\mathbf{C}(\mathbf{B}^{-1} + \mathbf{C}^T\mathbf{A}^{-1}\mathbf{C})^{-1}\mathbf{C}^T\mathbf{A}^{-1}$ for the covariance (Woodbury identity)

## Basics: Gaussian Bayes rule

- Gaussian Bayes Rule 1: used for derivation with kernels
  - Mean: $\mu_{\boldsymbol{x}|y} = \boldsymbol{\mu}_{\boldsymbol{x}} + \boldsymbol{\Sigma}_{\boldsymbol{x}}F^T(\sigma_y^2 I + F\boldsymbol{\Sigma}_{\boldsymbol{x}}F^T)^{-1}(\boldsymbol{y} - F\boldsymbol{\mu}_{\boldsymbol{x}})$
  - Covariance: $\Sigma_{\boldsymbol{x}|y} = \boldsymbol{\Sigma}_{\boldsymbol{x}} - \boldsymbol{\Sigma}_{\boldsymbol{x}}F^T(\sigma_y^2 I + F\boldsymbol{\Sigma}_{\boldsymbol{x}}F^T)^{-1}F\boldsymbol{\Sigma}_{\boldsymbol{x}}$

- Gaussian Bayes Rule 2: used for derivation with features
  - Mean: $\mu_{\boldsymbol{x}|y} = \boldsymbol{\mu}_{\boldsymbol{x}} + (\sigma_y^2\boldsymbol{\Sigma}_{\boldsymbol{x}}^{-1} + F^T F)^{-1}F^T(\boldsymbol{y} - F\boldsymbol{\mu}_{\boldsymbol{x}})$
  - Covariance: $\Sigma_{\boldsymbol{x}|y} = \sigma_y^2(\sigma_y^2\boldsymbol{\Sigma}_{\boldsymbol{x}}^{-1} + F^T F)$

Do not remember exact equations... remember their properties

- Both rules are mathematically equivalent...
- However, numerically it can be huge difference
- Bayes rule 1: Invert a matrix with dimension $dim(y) \times dim(y)$
- Bayes rule 2: Invert a matrix with dimension $dim(x) \times dim(y)$

> Use Rule 1 if $dim(y) < dim(x)$

## Basics: Gaussian propagation

Given marginal $p(x) = \mathcal{N}(x|\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$ and conditional $p(y|x) = \mathcal{N}(Fx, \sigma_y^2 I)$ we want to obtain the marginal for y:

- The marginal distribution $p(y) = \int p(x)p(y|x)dx$ is Gaussian with
  - Mean: $\boldsymbol{\mu}_y = F\boldsymbol{\mu}_x$
  - Variance: $\boldsymbol{\Sigma}_y = \sigma_y^2 I + F\boldsymbol{\Sigma}_x F^T$
  - Derivation:
    - Use Eq (1) to obtain joint distribution
    - Marginal $p(y)$ can be directly read from the joint
    - Variance in $y$ increases due to uncertainty in $x$

Ok... we are ready to derive Bayesian Regression!

## Bayesian Linear Regression: Computing the Posterior

- Likelihood (conditional): $p(y|\mathbf{X}, \mathbf{w}) = \mathcal{N}(\mathbf{y}|\Phi\mathbf{w}, \sigma^2\mathbf{I})$
- Prior (marginal): $p(\mathbf{w}) = \mathcal{N}(\mathbf{0}, \lambda^{-1}\mathbf{I})$
- Dimensions: $\mathbf{w} \in \mathbb{R}^d$ and $y \in \mathbb{R}^{N}$, typically $d \ll N$

As the dimensionality of the marginal variable (parameter vector) is smaller than dimensionality of cond. variable (number of datapoints), we have to use Gaussian rule 2!

$$\mu_{\mathbf{w}|\mathbf{X},\mathbf{y}} = \boldsymbol{\mu}_{\mathbf{w}} + (\sigma_y^2\boldsymbol{\Sigma}_{\mathbf{w}}^{-1} + F^T F)^{-1}F^T (\mathbf{y} - \boldsymbol{\mu}_{\mathbf{w}})$$
$$\boldsymbol{\Sigma}_{\mathbf{w}|\mathbf{X},\mathbf{y}} = \sigma_y^2(\sigma_y^2\boldsymbol{\Sigma}_{\mathbf{w}}^{-1} + F^T F)^{-1}$$

with $\boldsymbol{\mu}_{\mathbf{w}} = \mathbf{0}, \boldsymbol{\Sigma}_{\mathbf{w}} = \lambda^{-1}\mathbf{I}, \mathbf{F} = \Phi$ and $\sigma_{y}^2 = \sigma_y^2$

## Computing the Posterior

**Posterior** $p(w|X, y) = \mathcal{N}(w|\mu_{w,y}, \Sigma_{w,y})$ :

- Posterior mean: $\mu_{w,y} = (\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}\Phi^T y$
- Posterior covariance: $\Sigma_{w,y} = \sigma_y^2(\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}$

**Observations:**

- The posterior mean is equivalent to the MAP estimate
- ... results from the linearity of the likelihood (not the case for non-linear models)
- Mean and mode are the same for Gaussians

**So whats the advantage?**

- We also get an uncertainty estimate for the parameter vector!

## Example: Samples from the posterior

- Each $\boldsymbol{w}_i$ represents a function $f_i(\boldsymbol{x}) = w_i^T \phi(\boldsymbol{x})$

## Predictive Distribution

The predictive distribution is given by:

$$p(y^*|x^*,X,y) = \int p(y^*|w,x^*)p(w|X,y)dw$$

- Using Gaussian propagation, we can evaluate the predictive distribution. It is Gaussian with
  - Mean: $\mu(x^*) = \phi(x^*)^T(\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}\Phi^T y$
  - Variance: $\sigma_y^2(x^*) = \sigma_y^2(1 + \phi(x^*)^T(\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}\phi(x^*))$

Nothing new for the mean (same as Ridge Regression / MAP solution)

However:

- The variance is now input dependent!
- Also captures epistemic uncertainty!

## Take-away messages

* Bayesian learning consists of 2 steps:
  - Compute posterior over parameters / models
  - Average over all parameters / models weighted by posterior
* Both steps are **in general intractable**
  - Can only be done for linear feature / kernelized regression models in closed form
  - For all other cases, we need to **rely on approximations**
* However, theoretically one of the most powerful learning methods
  - Robust against overfitting (averages over unspecified behaviour between datapoints)
  - Does not require test set
  - Quantifies model uncertainty
  - **Hot research topic**: Bayesian Neural Network
