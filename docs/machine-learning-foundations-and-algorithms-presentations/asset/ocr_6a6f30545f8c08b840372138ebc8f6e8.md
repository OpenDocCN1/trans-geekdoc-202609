# Which divergence to use?

+   - In the most simple case, we just use the forward KL
  $$KL(p^*(x)|\|q(x)) = \int_{x} p^*(x) \log \frac{p^*(x)}{q(x)} dx \approx -\frac{1}{N} \sum_{x_i \sim p^*(x)} \log q(x_i) + 	ext{const}$$
- i.e. maximum likelihood
