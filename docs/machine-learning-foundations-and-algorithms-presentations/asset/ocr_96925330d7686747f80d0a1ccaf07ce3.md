# # Bayesian Linear Regression

**2 Steps:**

+   1. Compute posterior

```
```
np(w|X,y) = \frac{p(y|X,w)p(w)}{p(y|X)} = \frac{p(y|X,w)p(w)}{\int p(y|X,w)p(w)dw}
```
```

+   2. Compute predictive distribution: Integrate posterior out

```
```
np(y*|x*,X,y) = \int p(y*|w,x*)p(w|X,y)dw
