# Basics: Completing the square for Gaussian posterior

**Posterior:** $p(\mu|\mathbf{X}) \propto p(\mathbf{X}|\mu)p(\mu) \propto \exp \left\{ -\frac{\sum_i(x_i-\mu)^2}{2\sigma^2} - \frac{(\mu-\mu_0)^2}{2\sigma_0^2} ight\}$$
$= \exp \left\{ -\frac{1}{2} \left( \frac{N}{\sigma^2} + \frac{1}{\sigma_0^2} ight)_a \mu^2 + \left( \frac{\sum_i x_i}{\sigma^2} + \frac{\mu_0}{\sigma_0^2} ight)_b \mu + 	ext{const} ight\}$

**Completing the square:** $p(\mu|\mathbf{X}) = \mathcal{N}(\mu|\mu_N, \sigma_N^2)$

+   - Mean: $\mu_N = a^{-1}b = \frac{\sigma_0^2}{N\sigma_0^2+\sigma^2} \sum_i x_i + \frac{\sigma^2}{N\sigma_0^2+\sigma^2}\mu_0$
$= \frac{N\sigma_0^2}{N\sigma_0^2+\sigma^2}\mu_{ML} + \frac{\sigma^2}{N\sigma_0^2+\sigma^2}\mu_0$

+   - Variance: $\sigma_N^2 = a^{-1} = \frac{\sigma^2\sigma_0^2}{N\sigma_0^2+\sigma^2}$
