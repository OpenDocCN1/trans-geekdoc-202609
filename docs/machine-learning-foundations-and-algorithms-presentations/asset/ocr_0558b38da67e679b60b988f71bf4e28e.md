# # Variational Bayes Convergence Properties

+   - VB improves the lower bound
  $\mathcal{L}(q_{new}, 	heta_{new}) \geq \mathcal{L}(q_{old}, 	heta_{old})$

+   - M-step: Lower bound is maximized
- E-step: KL is decreased (but not set to 0), lower bound has to go up

![](bbox=[0.683, 0.085, 0.929, 0.435])

+   - VB does not always improve the marginal likelihood (difference to EM) !!

+   - M-step: Lower bound increases but KL can also decrease (its not 0)
- Lower bound is not tight!
- E-step: Marginal likelihood is unaffected
