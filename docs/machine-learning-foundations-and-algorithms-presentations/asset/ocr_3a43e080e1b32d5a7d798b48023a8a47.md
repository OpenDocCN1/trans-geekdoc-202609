# # Recap: Gaussian Bayes rule

+   - Gaussian Bayes Rule 1
  - Mean: $\mu_{w|x,y} = \lambda^{-1}oldsymbol{\Phi}^T(\sigma_y^2\mathbf{I} + \lambda^{-1}oldsymbol{\Phi}oldsymbol{\Phi}^T)^{-1}y$
  - Covariance: $oldsymbol{\Sigma}_{w|x,y} = \lambda^{-1}\mathbf{I} - \lambda^{-2}oldsymbol{\Phi}^T(\sigma_y^2\mathbf{I} + \lambda^{-1}oldsymbol{\Phi}oldsymbol{\Phi}^T)^{-1}oldsymbol{\Phi}$
- Gaussian Bayes Rule 2
  - Mean: $\mu_{w|x,y} = (oldsymbol{\Phi}^Toldsymbol{\Phi} + \sigma_y^2\lambda\mathbf{I})^{-1}oldsymbol{\Phi}^Ty$
  - Covariance: $oldsymbol{\Sigma}_{w|x,y} = \sigma_y^2(oldsymbol{\Phi}^Toldsymbol{\Phi} + \sigma_y^2\lambda\mathbf{I})^{-1}$

**Observations: Both rules are mathematically equivalent**

+   - However, numerically it can be a huge difference
- Bayes rule 1: Invert a matrix with dimension $dim(\mathbf{y}) 	imes dim(\mathbf{y})$
- Bayes rule 2: Invert a matrix with dimension $dim(\mathbf{w}) 	imes dim(\mathbf{w})$

> Use Rule 1 if $dim(\mathbf{y}) < dim(\mathbf{x})$, otherwise Rule 2
