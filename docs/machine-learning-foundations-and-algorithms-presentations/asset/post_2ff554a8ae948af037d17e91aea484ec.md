
# Regularization

- Regularization:
- We have seen huge errors on the test set for too complex models
- **Problem**: Weights can get very large to fit the data exactly
- **Solution**: Limit the model (i.e. weights) such that it can not fit the training data perfectly any more

## Simple form of regularization: forcing the weights **w** to be small

- Small weights will lead to a smoother function
- Introduce “regularization term” in cost-function

```
$L = E_D(\mathbf{w}) + \lambda E_W(\mathbf{w})$
$Loss = Data term + Regularization term$
```

- where $\lambda$ is the regularization factor
- Needs to be tuned manually in most cases

## Regularized Least Squares

With the sum-of-squares error function and a quadratic regularizer, we get

```
$$L_{\text{ridge}} = (y - \Phi w)^T(y - \Phi w) + \lambda w^T w
$E_D(w) \quad E_W(w)$$
```

- This particular choice of regularizer is known as **weight decay** because in sequential learning algorithms, it encourages weight values to decay towards zero, unless supported by the data.
- In statistics, it is called **ridge regression**.

Derivations can be done similarly as before. The solution is given by

```
$$w^*_{text{ridge}} =(\Phi^T \Phi + \lambda I)^{-1}\Phi^T y$$
```

- $I$ is the Identity matrix
- The matrix $(\Phi^T \Phi + \lambda I)$ is now full rank and can be more easily inverted

# Notation

- A random variable $X$ represents uncertain states or outcomes of the world
- We will write $p(x)$ to refer to the probability that X takes the value x
- The sample space is the space of all possible outcomes
  - Might be discrete, continuous or mixed

- $p(x)$ is the probability mass (density) function
  - Assigns a number to each point of the sample space
  - Non-negative, sums (integrates) to 1
  - Intuitively: How often does x occur? How much do we believe in x?

# Distributions

- Joint distribution
  - $p(x, y)$
  - Probability that X=x and Y=y

- Conditional distribution
  - $p(x|y)$
  - Probability that X=x given Y=y

# Bayes Rule

**Bayes rule** is one of most important equations in probability theory and in machine learning

```
$p(x|y) = \frac{p(y|x)p(x)}{p(y)} = \frac{p(y|x)p(x)}{\sum_{x'} p(y|x')}$
```

![](img/f01928df50903c99ce023dd3c527a33d_110_0.png)

- Way of “reversing” the conditional probabilities
- Often conditional is tricky but the other is simple
- One of most important equations for ML!

# Maximum Likelihood Estimation (MLE)

- Given: the training data $D = \{(x_i, y_i)\}_{i=1}^N$ identically distributed (iid) from the data distribution $p_{data}$
- Let $p_{\theta}(x, y)$ be a family of distributions parametrized by $\theta \in \Theta$
- We want to find $\theta$ such that $p$ fits the data well

Fitness of $\theta$ for one data point:
$L(\theta; x_i, y_i) = p_\theta(x_i, y_i)$

Fitness of $\theta$ for whole dataset (iid):
$L(\theta; D) = \prod_{i} p_\theta(x_i, y_i)$

# Maximum Likelihood Estimation (MLE)

Log-likelihood is easier to optimize:

```
$L(\theta; D) = \sum_{i} \log p_{\theta}(x_i, y_i)$
```

- Log is monotonous -> same optimum
- Sums are “nicer” to optimize than products
- Log cancels exponential form (most distributions are in exponential family)

The MLE solution is given by:

```
\theta_{ML} = \text{argmax}_{\theta} L(\theta; D)
```

# Example: Gaussian

Gaussian density function:

$L(\theta; D) = -N \log \sqrt{2\pi\sigma^2} - \sum_{i} \frac{(x_i - \mu)^2}{2\sigma^2}$

# MLE: conditional log-likelihood

- Given the training data $D = \{(x_i, y_i)\}_{i=1}^N$ iid from the data distribution $p_{data}$
- Let $p_{\theta}(y|x)$ be a family of distributions parametrized by $\theta \in \Theta$
- We only care about distribution of $y$, not of $x$
- **Typical case in supervised learning**

**Log-likelihood:**

```
$L(\theta; D) = \sum_{i} p_{\theta}(y_i|x_i)$
```

# Example: Linear Gaussian model

$p(y|x) = \mathcal{N}(y|w^T x, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left\{\frac{(y-w^T x)^2}{2\sigma^2}\right\}$

$\log p(y|x) = -\log(\sqrt{2\pi\sigma^2}) - \frac{(y-w^T x)^2}{2\sigma^2}$

We consider the following conditional Gaussian model:

$p_{\theta}(y|x) = \mathcal{N}(y|w^T x, \sigma^2), \quad \theta = \{\mathbf{w}\}$

**Log-likelihood:**

$L(\theta; D) = -N\log\sqrt{2\pi\sigma^2} - \sum_{i} \frac{(y_i - w^T x_i)^2}{2\sigma^2}$

- For obtaining $\mathbf{w}$, only the squared errors matter, i.e.
$L(\theta; D) = const_1 - const_2\sum_{i}(y_i - w^T x_i)^2$

- Hence, the **MLE solution is equivalent to the least squares solution**!

- **But:** we can also obtain the variance $\sigma^2$ by MLE!

# A probabilistic formulation of regularization

**We can formalize regularization as a prior on the parameters:**

- Prior can specify that we want to have small parameter vectors, i.e., $p(\theta) = \mathcal{N}(0, \lambda^{-1}\mathcal{I})$

- Find the parameter vector $\theta_{MAP}$ that maximizes the likelihood times prior
$\theta_{MAP} = \arg\max_{\theta} p(\mathcal{D}|\theta)p(\theta) \ \dots$ or in log domain
$\theta_{MAP} = \arg\max_{\theta} \log p(\mathcal{D}|\theta) + \log p(\theta)$

- This is called maximum posteriori estimate (MAP) as it maximizes the posterior $p(\theta|\mathcal{D})$ (more on in the probabilistic ML chapter)

$p(\theta|\mathcal{D}) = \frac{p(\mathcal{D}|\theta)p(\theta)}{p(\mathcal{D})} \propto p(\mathcal{D}|\theta)p(\theta)$
