# # Rules of Probability

+   - Sum rule (marginalization / integrating out):

```
$p(x) = \sum_{y} p(x, y)$
$p(x_1) = \sum_{x_2} \sum_{x_3} \cdots \sum_{x_D} p(x_1, \dots, x_D)$
```

+   - Note: For continuous distributions, the sums will be replaced by integrals
