
# Linear Discriminators

A linear discriminator is given in the form:

$f(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + b$

In 2D, the discriminator is a line

- $\mathbf{w}$ is the normal to the line
- $b$ is the bias

In 3D, it's a **plane**

In N-D, it's a **hyper-plane**

![](img/f01928df50903c99ce023dd3c527a33d_141_0.png)

## Linear Classification: 0-1 loss (1st attempt)

**Prediction:** $y = \text{step}(f(x)) = \text{step}(w^T x + b)$

- Predict class 1 for $f(x) > 0$
- else predict class 0

**Optimization:** Find $w$ such that

```
$L_0(w) = \sum_{i} \mathbb{I}(\text{step}(w^T x + b) \neq c_i)$
```

- where $\mathbb{I}$ returns 1 if the argument is true
- ... counts the number of misclassifications

× Very **difficult to optimize**!!! (NP-hard)

## Linear Classification: regression loss (2nd attempt)

We can use same loss as in regression
$L_{reg}(\mathbf{w}) = \sum_{i} (f(\mathbf{x}_i) - c_i)^2$

- Minimize the squared error: Easy!
- However: we ignored the fact that $c_i$ is restricted to $\{0,1\}$

Not robust to outliers

![](img/f01928df50903c99ce023dd3c527a33d_143_0.png)

## Compare the two

![](img/f01928df50903c99ce023dd3c527a33d_144_0.png)

- The output of a linear function is unbounded!
- However, useful output values are only 0 or 1

## Logistic sigmoid function

Sigmoid function:

```
$\sigma(a) = \frac{1}{1 + \exp(-a)}$
```

- Output is bounded between 0 and 1
- Smooth

![](img/f01928df50903c99ce023dd3c527a33d_145_0.png)

For linear classification:

- Squash the output of the linear function
- Minimize the loss

```
$L(\boldsymbol{w}) = \sum_{i} (\sigma(f(\boldsymbol{x}_i)) - c_i)^2 = \sum_{i} (\sigma(\boldsymbol{w}^T \boldsymbol{x} + b) - c_i)^2$
```

## Better: Probabilistic view, MLE

- Given the training data $D = \{(x_i, y_i)\}_{i=1...N}$ iid. from the data distribution $p_{data}$
- Let $p_{\theta}(y|x)$ be a family of distributions parametrized by $\theta \in \Theta$
- We only care about distribution of $y$, not of $x$
- Typical case in supervised learning

**Log-likelihood:**

```
$loglik(\theta; D) = \sum_{i} \log p_{\theta}(y_i|x_i)$
```

## Distribution for binary classification

Bernoulli Distribution:

- Binary random variable $X \in \{0, 1\}$
- One parameter $p(X = 1) = \mu$
- Probability distribution $p(x) = \mu^x(1-\mu)^{1-x}$
  Depending on x, selects either mu or 1-mu as probability

- Think of it as tossing a coin

![](img/f01928df50903c99ce023dd3c527a33d_148_0.png)

## Conditional Bernoulli as sigmoid

Define conditional probability distribution of the class label

$p(c = 1|\boldsymbol{x}) = \sigma(\boldsymbol{w}^T \boldsymbol{x} + b), \quad p(c = 0|\boldsymbol{x}) = 1 - \sigma(\boldsymbol{w}^T \boldsymbol{x} + b)$

- This is now a **conditional Bernoulli** distribution. i.e. the **outcome of the event c depends on $\boldsymbol{x}$**
- We can use the same “exponential trick” to select the correct probability depending on the value of c, i.e.

$p(c|\boldsymbol{x}) = p(c = 1|\boldsymbol{x})^c p(c = 0|\boldsymbol{x})^{1-c} = \sigma(\boldsymbol{w}^T \boldsymbol{x} + b)^c (1 - \sigma(\boldsymbol{w}^T \boldsymbol{x} + b))^{1-c}$

## Log-Likelihood

We can now directly optimize the conditional log-likelihood

$$\text{loglik}(\tilde{w}, D) = \sum_{i} \log p(c_i|\boldsymbol{x}_i) = \sum_{i} \log p(c=1|\boldsymbol{x}_i)^{c_i} p(c=0|\boldsymbol{x}_i)^{1-c_i}$$
$= \sum_{i} c_i \log p(c=1|\boldsymbol{x}_i) + (1-c_i) \log p(c=0|\boldsymbol{x}_i)$$
$= \sum_{i} c_i \log \sigma(\tilde{w}^T \tilde{x}_i) + (1-c_i) \log (1-\sigma(\tilde{w}^T \tilde{x}_i))$$

- Negative likelihood is also referred to as cross-entropy

## Logistic “Regression”

Optimizing the log-likelihood of a sigmoid is called logistic regression

$\text{argmax}_{\tilde{w}} \text{loglik}(\tilde{w}, D) = \text{argmax}_{\tilde{w}} \sum_{i} c_i \log \sigma(\tilde{w}^T \tilde{x}_i) + (1-c_i) \log (1-\sigma(\tilde{w}^T \tilde{x}_i))$

- ... even though we solve a classification problem
- One can show that the function is still convex (only one maximum)
- However, there is no closed form solution as in linear regression
- It is also called the cross-entropy loss (coming from information theory)

How can we find the maximum? **Gradient Descent!**

## Generalized models

As in regression, we can fit a **linear discriminator** in a **non-linear feature** space

- Similar to generalized linear models

$\text{argmax}_w \text{loglik}(\boldsymbol{w}, D) = \text{argmax}_w \sum_{i} c_i \log \sigma(\boldsymbol{w}^T \phi(\boldsymbol{x}_i)) + (1-c_i) \log (1-\sigma(\boldsymbol{w}^T \phi(\boldsymbol{x}_i)))$

- Problems that are not linear separable in input space can be linear separable in feature space

## Regularization

Similar as in linear regression, we can again add a regularization penalty
$L(\tilde{w}, D) = \text{loglik}(\tilde{w}, D) - \lambda \text{penalty}(\tilde{w})$

Most common: L2 regularization loss
$\text{penalty}(\tilde{w}) = ||\tilde{w}||^2$

- L is still convex for most penalty terms

## Optimization

For most ML algorithms, we want to find the best model to fit the data.
Two examples we already know:

- Least squares solution:
$\argmin_w SSE(w, D) + \lambda \text{penalty}(w)$
- Maximum likelihood solution:
$\argmax_w \text{loglik}(w, D) - \lambda \text{penalty}(w)$

> Note that:
$\argmin_x f(x) = \argmax_x f(x)$
Hence, the role of the penalty is the same

... plus regularization penalty

## Optimization

General form of optimization for ML: loss + penalty

$$\arg min_{\text{parameters } \theta} \sum_{i=1}^{N} l(\boldsymbol{x}_i, \theta) + \lambda \text{penalty}(\theta)$$

- Summed sample-loss plus regularization penalty

How to do that? **Optimization**

## When can we do that?

![](img/f01928df50903c99ce023dd3c527a33d_160_0.png)

- The global minimum/maximum can only be found for convex functions!
- For non-convex functions we are limited to finding a local minimum / maximum

## Convex functions

A convex function $f : \mathbb{R}^d \to \mathbb{R}$ satisfies for any $\boldsymbol{x}_0, \boldsymbol{x}_1 \in \mathbb{R}^d$

$f((1-\alpha)\boldsymbol{x}_0 + \alpha\boldsymbol{x}_1) \le (1-\alpha)f(\boldsymbol{x}_0) + \alpha f(\boldsymbol{x}_1), \quad \alpha \in [0, 1]$

- Line joining $(\boldsymbol{x}_0, f(\boldsymbol{x}_0))$ and $(\boldsymbol{x}_1, f(\boldsymbol{x}_1))$ is always above the function value
- There is only one minimum!

![](img/f01928df50903c99ce023dd3c527a33d_161_0.png)

## Gradient Descent

- Is good for finding **global minima** if function is **convex**
- Is good for finding **local minima** if function is **non-convex**
- Has many applications in ML:
  - Logistic Regression
  - Linear Regression (for large input dimensions)
  - Deep Neural Networks
  - Mixture Models
- ...
