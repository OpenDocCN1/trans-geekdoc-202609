
# Hinge Loss

$$\text{argmin}_{w} ||w||^2_{\text{regularization}} + C \sum_{i=1}^{N} \max(0, 1 - y_i f(\boldsymbol{x}_i))_{\text{loss function}}$$

**Points are in 3 categories:**

- $y_i f(\boldsymbol{x}_i) > 1$ : Point outside margin, no contribution to loss
- $y_i f(\boldsymbol{x}_i) = 1$ : Point is on the margin, no contribution to loss as in hard margin
- $y_i f(\boldsymbol{x}_i) \le 1$ : Point violates the margin, contributes to loss

![](img/f01928df50903c99ce023dd3c527a33d_201_0.png)

# Loss function is convex

![](img/f01928df50903c99ce023dd3c527a33d_202_0.png)

- There is only one minimum
- We can find it with gradient descent
- However:
  - Hinge loss is **not differentiable!**
  - How can we optimize this?

# Basics: Sub-gradients

**Remember:** For any convex function $f : \mathbb{R}^d \to \mathbb{R}$

```
$f(z) \geq f(x) + \nabla f(x)^T(z - x)$
```

- I.e. linear approximation underestimates function

![](img/f01928df50903c99ce023dd3c527a33d_204_0.png)

**A subgradient** of a convex function $f$ at point $\mathbf{x}$ is any $\mathbf{g}$ such that

```
$f(z) \geq f(x) + g^T(z - x)$
```

- Always exists (also if $f$ is not differentiable)
- If $f$ is differentiable at $\mathbf{x}$, then $\mathbf{g} = \nabla f(\mathbf{x})$

# Examples

Consider $f(x) = |x|$

- For $x \neq 0$, unique sub-gradient of $g = \text{sign}(x)$
- For $x = 0$, sub-gradient is any element of $[-1, 1]$

![](img/f01928df50903c99ce023dd3c527a33d_205_0.png)

# Examples

Let $f_1, f_2 : \mathbb{R}^n \to \mathbb{R}$ be convex, differentiable, and consider $f(x) = \max\{f_1(x), f_2(x)\}$

- For $f_1(x) > f_2(x)$, unique subgradient $g = \nabla f_1(x)$
- For $f_2(x) > f_1(x)$, unique subgradient $g = \nabla f_2(x)$
- For $f_1(x) = f_2(x)$, subgradient $g$ is any point on the segment between $\nabla f_1(x)$ and $\nabla f_2(x)$

![](img/f01928df50903c99ce023dd3c527a33d_206_0.png)

# Sub-Gradient Method

Like gradient descent, but replacing gradients with sub-gradients

**Sub-gradient Descent:**

- Given convex $f$, not necessarily differentiable
- Initialize $x_0$
- Repeat: $x_{t+1} = x_t + \eta g$, where $g$ is any sub-gradient of $f$ at $x_t$

# Sub-gradients for hinge loss

$\mathcal{L}(\mathbf{x}_i, y_i, \mathbf{w}) = \max(0, 1 - y_{i}f(\mathbf{x}_i)) \quad f(\mathbf{x}_i) = \mathbf{w}^T \mathbf{x}_i + b$

![](img/f01928df50903c99ce023dd3c527a33d_208_0.png)

# Sub-gradient descent for SVMs

$\arg\min_{\mathbf{w}} C \sum_{i=1}^{N} \max(0, 1 - y_i f(\boldsymbol{x}_i)) + ||\mathbf{w}||^2_{\text{regularization}}$

At each iteration, pick random sample $(\mathbf{x}_i, y_i)$

- If $y_i f(\boldsymbol{x}_i) < 1$: $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta(2\mathbf{w}_t - C\mathbf{x}_i)$
- Otherwise: $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta 2\mathbf{w}_t$

# Comparison to logistic function

- SVM-hinge loss

$$\text{argmin}_w \frac{\|w\|^2}{\text{regularization}} + \sum_{i=1}^N \max(0, 1 - y_i f(\boldsymbol{x}_i)), \text{ with } \lambda = \frac{1}{C}$$

- (Regularized) logistic regression loss (see lecture2)

$$\text{argmax}_w -\lambda\|w\|^2 + \sum_{i=1}^N c_i \log(\sigma(\boldsymbol{x}_i)) + (1-c_i) \log(1-\sigma(\boldsymbol{x}_i)), \text{ with } c_i \in \{0,1\}$$
$$\dots$$
$$\text{argmin}_w \frac{\|w\|^2}{\text{regularization}} + \sum_{i=1}^N \log(1+\exp(-y_i f(\boldsymbol{x}_i))), \text{ with } y_i \in \{-1, 1\}$$

Both loss functions have similar interpretations

- Keep weights small + $y_i f(\boldsymbol{x}_i)$ should be large
- Saturates if $y_i f(\boldsymbol{x}_i)$ gets too large

# Comparison to logistic loss function

# SVM (hinge) loss:

$\max(0, 1 - y_i f(x_i))$

- Outputs -1 or 1 (class labels)
- Estimates maximum margin solution
- Loss contribution is 0 for correct classification

![](img/f01928df50903c99ce023dd3c527a33d_212_0.png)

# Logistic loss:

$\log (1 + \exp(-y_i f(x_i)))$

- Outputs probabilities
- Contribution never 0
- Often results in slightly less accurate classification
- Diverges faster than hinge loss
- More sensitive to outliers

# The “thing” about features

Good feature representations are typically hard to find...

- Polynomial features:
  - Number of features increases with O(d^k), where d is dimensionality of data and k is degree of polynom
  - Can get very high feature value for large k

- Radial basis function features:
  - Uniformly distribute Gaussian functions over the input space
  - Number of basis functions scales exponentially with d
  - Many basis functions located at irrelevant positions with no data

$$\phi(\boldsymbol{x})=[\phi_{\mu_1}(\boldsymbol{x}), \dots, \phi_{\mu_M}(\boldsymbol{x})]^T, \quad \phi_{\mu_i}(\boldsymbol{x})=\exp\left(-\frac{\|\boldsymbol{x}-\mu_i\|^2}{2\sigma^2}\right)$$
$\mu_i \dots i^{th}$ center location (fixed) $\sigma^2 \dots$ bandwidth

# Kernel - Motivation

Can we find a more powerful representation for linear models?

- Yes! Kernels!
- They are more generic, scale better and adapt to the data set
- They still preserve simple linear computations
