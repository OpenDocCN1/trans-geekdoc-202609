# EM-Decomposition

Derivation:

$\log p(\boldsymbol{x}) = \sum_{z} q(z) \log p(\boldsymbol{x})$

+   1. Introduce variational distribution $q(z)$

= \sum_{z} q(z)(\log p(\boldsymbol{x}, z) - \log p(z|\boldsymbol{x}))$

+   2. Use Bayesian theorem $p(\boldsymbol{x}) = \frac{p(\boldsymbol{x}, z)}{p(z|\boldsymbol{x})}$

= \sum_{z} q(z)(\log p(\boldsymbol{x}, z) - \log q(z))$

+   3. Add and subtract $\log q(z)$

+ \log q(z) - \log p(z|\boldsymbol{x})$

= \sum_{z} q(z) \log \frac{p(\boldsymbol{x}, z)}{q(z)} + \sum_{z} q(z) \log \frac{q(z)}{p(z|\boldsymbol{x})}$

+   4. Write as 2 sums

Lower Bound $\mathcal{L}(q)$
KL Divergence: $KL(q(z)||p(z|\boldsymbol{x}))$
