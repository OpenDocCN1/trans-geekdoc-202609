# Regression

# Regression:

+   - Learn continuous function

$y = f(x) + \epsilon$

# Linear Regression:

+   - “just” fit a line

$y = f(x) + \epsilon = w_0 + w_1x + \epsilon$

We assume that the outputs are affected by (typically) Gaussian noise:

$\epsilon \sim \mathcal{N}(0, 1)$
