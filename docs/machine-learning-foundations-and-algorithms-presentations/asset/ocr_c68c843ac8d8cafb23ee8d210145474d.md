# Motivation – Support Vector Machines

Maximum margin classifiers have been the most successful classifiers until 10 years ago

+   - Often called support vector machine (SVM)
- Maximum Margin Solution is very robust against overfitting
- Easy to compute
- Can deal with small datasets
- Same loss function is still occasally used for deep neural networks

Nowadays they are used much less, but...

+   - Understanding Maximum Margin Classification also helps in understanding the main problems for classification in terms of overfitting
- SVMs are the basis for the hinge loss, which is still used quite a lot for DNNs as well
- Its important to understand the different properties of cross-entropy and hinge loss
