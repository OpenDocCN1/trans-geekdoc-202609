# # Recap: Matrix Calculus

# ## Derivatives of a scalar function w.r.t a vector...

+   - Yields the gradient vector: $
abla_{\mathbf{x}}f = \frac{\partial f(x)}{\partial \mathbf{x}} = \left[ \frac{\partial f(x)}{\partial x_1}, \dots, \frac{\partial f(x)}{\partial x_d} ight]^T$

+   - Example: Quadratic form $
abla_{\mathbf{x}}x^T\mathbf{x} = 2\mathbf{x}$ $
abla_{\mathbf{x}}x^T\mathbf{A}x = 2\mathbf{Ax}$

# ## Derivatives of a vector-valued function w.r.t a vector...

+   - Yields a matrix (the Jacobian) $
abla_{\mathbf{x}}f = \frac{\partial f(\mathbf{x})}{\partial \mathbf{x}} = \left[ egin{array}{ccc} \frac{\partial f_1(x)}{\partial x_1} & \dots & \frac{\partial f_k(x)}{\partial x_1} \ \vdots & \ddots & \vdots \ \frac{\partial f_1(x)}{\partial x_d} & \dots & \frac{\partial f_k(x)}{\partial x_d} \end{array} ight]$

+   - Example: Linear form $
abla_{\mathbf{x}}\mathbf{Ax} = \mathbf{A}^T$
