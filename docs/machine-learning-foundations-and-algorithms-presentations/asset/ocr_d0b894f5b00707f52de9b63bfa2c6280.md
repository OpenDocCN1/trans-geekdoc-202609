# # Case 2: Variational Bayes

Instead of using an individual auxiliary distribution $q_i(\mathbf{z})$per data-point $oldsymbol{x}_i $, we can use an “amortized” distribution $q_{\varphi}(\mathbf{z}|boldsymbol{x}_i)$ that is given by a DNN

```
$$\mathcal{L}(q,p) = \frac{1}{N} \sum_{i} q_{\varphi}(\mathbf{z}|\boldsymbol{x}_i) \log p_{\varphi}(\boldsymbol{x}_i|\mathbf{z})dz - KL(q_{\varphi}(\mathbf{z}|\boldsymbol{x}_i)||p_{\varphi}(\mathbf{z}))$$
```

This is the standard objective used for variational auto-encoders (VAE)

+   - Encoder $q_{\varphi}(\mathbf{z}|\boldsymbol{x})$, Decoder $p_{\varphi}(\boldsymbol{x}|\mathbf{z})$, Latent Prior $p_{\varphi}(\mathbf{z})$
- The lower bound is directly optimized with respect to $\boldsymbol{\phi}$ and $\boldsymbol{\varphi}$

Lower bound $\mathcal{L}(q,p)$ is often called the Evidence Lower Bound (ELBO) as it is the lower bound to $\log p(\boldsymbol{x})$ which is often called the (log) evidence
