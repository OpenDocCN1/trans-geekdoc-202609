# Definition

Given the dataset $\mathcal{D} = \{(oldsymbol{x}_i, c_i)\}_{i=1...N}$, where $oldsymbol{x}_i \in \mathbb{R}^d$ are the input samples and $c \in \{1 \dots K\}$ are the class labels, we want to learn a classifier $f(oldsymbol{x})$ that predicts the class label for unseen samples.

+   * $K=2$: Binary classification
* $K>2$: Multi-class classification

In difference to regression, the **output is now discrete**!
