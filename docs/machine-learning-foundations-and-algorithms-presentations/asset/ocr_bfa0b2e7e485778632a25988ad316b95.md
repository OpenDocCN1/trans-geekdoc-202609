# Example: Multi-layer Perceptron (vector form)

# Backward pass:

$\overline{\mathcal{L}} = 1$

$\overline{\mathbf{y}} = \overline{\mathcal{L}}(\mathbf{y} - \mathbf{t})$

# Forward pass:

$\overline{\mathbf{W}^{(2)}} = \overline{\mathbf{h}}^T$

$\mathbf{z} = \mathbf{W}^{(1)}}\mathbf{x} + \mathbf{b}^{(1)}$

$\mathbf{h} = \sigma(\mathbf{z})$

outer product

$\mathbf{y} = \mathbf{W}^{(2)}}\mathbf{h} + \mathbf{b}^{(2)}$

$\overline{\mathbf{b}^{(2)}} = \overline{\mathbf{y}}$

$\mathcal{L} = \frac{1}{2}(\mathbf{y} - \mathbf{t})^T(\mathbf{y} - \mathbf{t})$

$\overline{\mathbf{h}} = \overline{\mathbf{W}^{(2)}}\overline{\mathbf{y}}^T$

element-wise product

$\overline{\mathbf{z}} = \overline{\mathbf{h}} \circ \sigma'(\overline{\mathbf{y}})$

$\overline{\mathbf{W^{(1}}}} = \overline{\mathbf{zx}}^T$

outer product

$\overline{\mathbf{b^{(1)}}} = \overline{\mathbf{z}}$
