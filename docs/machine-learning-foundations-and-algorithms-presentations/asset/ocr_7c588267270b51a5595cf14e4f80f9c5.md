# Example: Linear Gaussian model

$p(y|x) = \mathcal{N}(y|w^T\tilde{x}, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}exp\left{\frac{(y-w^T\tilde{x})^2}{2\sigma^2}\right\}$

$$\log p(y|x) = -\log(\sqrt{2\pi\sigma^2}) - \frac{(y-w^T\tilde{x})^2}{2\sigma^2}$

We consider the following conditional Gaussian model:

$p_{\theta}(y|x) = \mathcal{N}(y|w^T\tilde{x}, \sigma^2), \quad \theta = \{\mathbf{w}\}$

# **Log-likelihood:**

$$\log liklik(\theta; D) = -N\log\sqrt{2\pi\sigma^2} - \sum_{i} \frac{(y_i - w^T\tilde{x}_i)^2}{2\sigma^2}$

+   - For obtaining $\mathbf{w}$, only the squared errors matter, i.e.
  $\log liklik(\theta; D) = const_1 - const_2\sum_{i}(y_i - w^T\tilde{x}_i)^2$

+   - Hence, the **MLE solution is equivalent to the least squares solution**!

+   - **But:** we can also obtain the variance $\sigma^2$ by MLE!
