# Selecting covariance hyperparameters

**a) Optimize the marginal likelihood under the Gaussian process:**

$\gamma^* = \text{argmax}_\gamma \log p(\mathbf{r}_{1:t}|\boldsymbol{	heta}_{1:t}, \gamma, \sigma)$,$\log p(\mathbf{r}_{1:t}|\boldsymbol{	heta}_{1:t}, \gamma, \sigma) = -\frac{1}{2}\mathbf{r}_{1:t}^T(\mathbf{K}_{\gamma} + \sigma\mathbf{I})^{-1}\mathbf{r}_{1:t} - \frac{1}{2}\log|\mathbf{K}_{\gamma} + \sigma\mathbf{I}| - \frac{t}{2}\log 2\pi$

+   - Can be done via gradient descent
- Uses a single point estimate for hyper-parameters

**b) Bayesian treatment in acquisition function**

+   - Integrate hyperparameters out
- $acq_t(\boldsymbol{	heta}) = \int acq_t(\boldsymbol{	heta}, \gamma, \sigma)p(\gamma, \sigma|\mathbf{r}_{1:t}, \boldsymbol{	heta}_{1:t})d\gamma,\sigma$
- Can be approximated using Monte-Carlo Markov Chain (MCMC) Sampling
- Tends to work better, but computationally much more expensive
