# Recap: Bayesian Learning

- 1. Compute posterior: $p(\theta|D) = \frac{p(D|\theta)p(\theta)}{p(D)}$

- 2. Integrate out posterior: $p(x^*|D) = \int p(x^*|\theta)p(\theta|D) d\theta$

# Properties:

- For very large datasets, the posterior will be a point estimate $\lim_{n\to\infty} p(\theta|\mathcal{D}_n) = \delta(\theta - \theta^*)$
  - i.e. Bayesian Learning will be equivalent to maximum likelihood

- However, large advantage for smaller datasets!
  1. We know where our model is uncertain
  2. More robust estimate due to averaging, less overfitting
  3. For DNNs all datasets are small due to the large number of parameters

Approximate posterior: $q(W|\mu) = \prod_{i} q(w_i|\mu_i)$ $p$ is a fixed hyper-parameter!

$q(w_i|\mu_i) = p \delta(0) + (1 - p) \delta(\mu_i)$

Approximate KL-divergence: $KL(q(W|\mu)||p(W)) \approx \alpha|\mu||_2^2$ (see paper for the proof)
