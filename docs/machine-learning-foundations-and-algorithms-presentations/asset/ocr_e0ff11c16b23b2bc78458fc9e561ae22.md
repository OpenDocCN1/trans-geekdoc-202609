# True risk vs. empirical risk

**True risk:** performance on a random test point (x,y)

+   - **Classification:** probability of misclassification $p(y \neq f(x))$

+   - **Regression:** expected squared error $\mathbb{E}_{x,y}[(f(x) - y)^2]$

**Unknown!**

**Empirical risk:** performance on the training set

+   - **Classification:** proportion of misclassified samples $\frac{1}{n} \sum_{i} \mathbb{I}(f(x_i) \neq y_i)$

+   - **Regression:** average squared error $\frac{1}{n} \sum_{i} (f(x_i) - y_i)^2$
