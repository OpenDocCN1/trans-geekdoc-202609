# Linear regression models in matrix form

+   - Equation for the i-th sample

$$\hat{y}_i = w_0 + \sum_{j=1}^{D} w_j x_{i,j} = 	ilde{oldsymbol{x}}_i^T oldsymbol{w}, \quad 	ext{with } 	ilde{oldsymbol{x}}_i = egin{bmatrix} 1 \ x_i \end{bmatrix} 	ext{and } oldsymbol{w} = egin{bmatrix} w_0 \ \vdots \ w_D \end{bmatrix}$$

+   - Equation for full data set

$$\hat{oldsymbol{y}} = egin{bmatrix} \hat{y}_1 \ \vdots \ \hat{y}_n \end{bmatrix} = egin{bmatrix} 	ilde{oldsymbol{x}}_1^T \ \vdots \ 	ilde{oldsymbol{x}}_n^T \end{bmatrix} = oldsymbol{X}oldsymbol{w}$$

+   - $\hat{oldsymbol{y}}$ is a vector containing the output for each sample

+   $$\boldsymbol{X} = egin{bmatrix} 1 & 	ilde{oldsymbol{x}}_1^T \ \vdots & \vdots \ 1 & 	ilde{oldsymbol{x}}_n^T \end{bmatrix} \quad \text{is the data-matrix containing a vector of ones as the first column as bias}$$
