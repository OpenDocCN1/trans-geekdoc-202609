# # GNNs with Edge Embeddings

![](bbox=[0.078, 0.203, 0.584, 0.673])

# ## Pros:

+   - Support edge features
- More expressive than GCN
- Very general

# ## Cons:

+   - Need to store intermediate edge-based activations
- Limited to small graphs

Formally: $v ightarrow e : \mathbf{h}_{(i,j)}^l = f_e^l([\mathbf{h}_i^l, \mathbf{h}_j^l, \mathbf{x}_{(i,j)}])$

e ightarrow v : \mathbf{h}_j^{l+1} = f_v^l([\sum_{i \in \mathcal{N}_j} \mathbf{h}_{(i,j)}^l, \mathbf{x}_j])$
