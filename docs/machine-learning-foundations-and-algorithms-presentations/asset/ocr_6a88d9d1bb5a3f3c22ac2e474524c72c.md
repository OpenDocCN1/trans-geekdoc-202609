# # So far ... “Non-Bayesian” Learning

+   We mainly considered algorithms that optimize a single model using a given loss
- The algorithms do not know what they really know... and what is uncertain

+   However, ...
- As the data is noisy, the estimated optimal parameter vector $	heta^*$ is also uncertain
  - I.e. parameters are just random variables
  - We so far not really know how wrong / uncertain our estimate $	heta^*$
- We have also seen that multiple models (ensembles) usually work better!
- Prediction might be arbitrary wrong far away from the data
  - And we do not even know when this is the case
