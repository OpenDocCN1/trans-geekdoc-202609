
## EM Convergence Properties

![](img/f01928df50903c99ce023dd3c527a33d_660_0.png)

- **EM improves the lower bound**
  $\mathcal{L}(q_{new}, \theta_{new}) \geq \mathcal{L}(q_{old}, \theta_{old})$
  M-step: Lower bound is maximized
  E-step: KL is set to 0, lower bound has to go up

- **EM improves the marginal likelihood**
  $\log p(x|\theta_{new}) \geq \log p(x|\theta_{old})$
  M-step: Lower bound increases and KL increases (can't get smaller than 0)
  Lower bound is always tight after E-step!
  E-step: Marginal likelihood is unaffected

![](img/f01928df50903c99ce023dd3c527a33d_660_1.png)

## Variational Bayes Convergence Properties

- VB improves the lower bound
  $\mathcal{L}(q_{new}, \theta_{new}) \geq \mathcal{L}(q_{old}, \theta_{old})$

- M-step: Lower bound is maximized
- E-step: KL is decreased (but not set to 0), lower bound has to go up

![](img/f01928df50903c99ce023dd3c527a33d_661_0.png)

- VB does not always improve the marginal likelihood (difference to EM) !!

- M-step: Lower bound increases but KL can also decrease (its not 0)
- Lower bound is not tight!
- E-step: Marginal likelihood is unaffected

![](img/f01928df50903c99ce023dd3c527a33d_661_1.png)

## Objective for the variational distribution

What does q learn?

```
KL(q(z)||p(z|x)) = \int q(z) \log \frac{q(z)}{p(z|x)} dz = \int q(z) \log \frac{q(z)p(x)}{p(z|x)} dz = -\mathcal{L}(q,p) + \text{const}
```

$\Rightarrow \argmax_q \mathcal{L}(q,p)$

- By maximizing the variational lower bound $\mathcal{L}(q,p)$ wr $q$, the variational distribution will approximate the posterior $q(z) \approx p(z|x)$
- This minimization is also called Variational Inference
- Target is moving as posterior changes with decoder

## Full-Dataset Lower Bound

$\mathcal{L}(\{q_i\}, p) = \frac{1}{N} \sum_{i} \int q_i(z) \log p(x_i|z) - KL(q_i(z)||p(z))$

- Introduced individual variational distribution $q_i(z)$ for each data point
- **More sampling:**
  - Instead of sampling from the uninformed prior $p(z)$ ...
  - we can now sample from the variational distributions $q_i(z) \approx p(z|x_i)$
  - Each $q_i(z)$ will produce high-quality samples $p(x|z)$ once optimized!
- **Integral is outside the log:**
  - one sample from $q_i(z)$ needed to obtain unbiased estimate of the lower bound, i.e. suitable for stochastic gradient descent while the marginal log is not

## Case 1: Expectation Maximization

$\log p(x) = \int q(z) \log \frac{p(x|z)}{q(z)} dz + \int q(z) \log \frac{q(z)}{p(x|z)} dz$
marginal-like Lower Bound $\mathcal{L}(q)$ KL Divergence: $KL(q(z)||p(x|z))$

Expectation-Maximization uses the same decomposition, but two separate steps:

- Maximization Step:
  - Keep $q(z)$ fixed, maximize Lower bound $\mathcal{L}(q, p)$ wr model distribution $p_{\varphi}(x|z)$ and $p_{\varphi}(z)$
- Expectation Step:
  - Keep model $p_{\varphi}(x|z)$ and $p_{\varphi}(z)$ fixed, minimize KL wr $q$
  $q^* = \arg \min KL(q(z)||p(x|z)) \rightarrow q^*(z) = p(z|x)$

> **Note**
- In EM the KL can be set to zero (i.e we can compute posterior $p_{\varphi}(x|z)$)
- Only works in special cases e.g. discrete $z$, GMMs
- In this case the lower bound is tight
- increasing lower bound always increases marginal-like

## Case 2: Variational Bayes

Instead of using an individual auxiliary distribution $q_i(z)$ per data-point $x_i$, we can use an “amortized” distribution $q_{\varphi}(z|x_i)$ that is given by a DNN:

```
\mathcal{L}(q,p) = \frac{1}{N} \sum_{i} q_{\varphi}(z|x_i) \log p_{\varphi}(x_i|z) - KL(q_{\varphi}(z|x_i)||p_{\varphi}(z))
```

This is the standard objective used for variational auto-encoders (VAE)

- Encoder $q_{\varphi}(z|x)$, Decoder $p_{\varphi}(x|z)$, Latent Prior $p_{\varphi}(z)$
- The lower bound is directly optimized with respect to $\phi$ and $\varphi$

Lower bound $\mathcal{L}(q,p)$ is often called the Evidence Lower Bound (ELBO) as it is the lower bound to $\log p(x)$ which is often called the (log) evidence

## Optimization over the variational distribution

$\mathcal{L}(q, p) = \frac{1}{N} \sum_{i} \int q_i(z) \log p(x_i|z) - KL(q_i(z)||p(z))$

**But: How can we optimize over $q_{\varphi}(x_i)$?**

- Here, samples are not fixed but generated!
- Reparameterization trick!!

## Reparameterization Trick

We want to optimize distribution $p_{\theta}(x)$ using the following:

$\theta^* = \argmin_{\theta} \mathbb{E}_{p_{\theta}}[f(x)] = \int p_{\theta}(x)f(x)dx$

... and we are given. How can we exploit this?

We can reparameterize the expectation:

- Introduce random variable $\xi \sim q$ where $q$ is a parameter-free distribution (e.g. $\xi \sim \mathcal{N}(0, I)$)
- If we can find a mapping $x = h_{\theta}(\xi)$ such that $x$ is distributed as $x \sim p_{\theta}(x)$ then:

$\int p_{\theta}(x)f(x)dx = \int q(\xi)f(h_{\theta}(\xi))d\xi$

> We moved the parameters from distribution $p_{\theta}(x)$ into a function $h_{\theta}(\xi)$

## Reparameterization Trick

Example: Lets $p_{\theta}(x) = \mathcal{N}(\mu, \Sigma)$ and $q(\xi) = \mathcal{N}(0, I)$. If we set
$h_{\theta}(\xi) = \mu + A^T\xi$, with $\theta = \{\mu, \Sigma\}$ and $A^T A = \Sigma$
Then $x' = h_{\theta}(\xi)$ is distributed with $p(x') = \mathcal{N}(\mu, A^TIA) = \mathcal{N}(\mu, \Sigma)$

**Reparameterization Trick:**

$\int p_{\theta}(x)f(x)d\mathbf{x} = \int q(\xi)f(h_{\theta}(\xi))d\xi$

**Reparameterized Gradient:**

$\nabla_{\theta}\mathbb{E}_{p_{\theta}}[f(x)] = \nabla_{\theta} \int q(\xi)f(h_{\theta}(\xi))d\xi = \int q(\xi)\frac{\partial h_{\theta}}{\partial \theta}(\xi)\frac{\partial f}{\partial x}(h_{\theta}(\xi))d\xi$

- We can now use the gradient $\frac{\partial f}{\partial x}$ to compute $\nabla_{\theta}\mathbb{E}_{p_{\theta}}[f(x)]!$
