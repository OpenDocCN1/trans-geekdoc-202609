# Matrix Calculus - Denominator-layout notation

Derivatives of a scalar function w.r.t a vector...

+   - Yields the gradient vector: $\nabla_{\mathbf{x}}f = egin{bmatrix} \frac{\partial f(x)}{\partial x_1} \ \vdots \ \frac{\partial f(x)}{\partial x_d} \end{bmatrix}$
- Example: Quadratic form $\nabla_{\mathbf{x}}\mathbf{x}^T \mathbf{x} = 2\mathbf{x}$

Derivatives of a vector-valued function w.r.t a scalar...

+   - Yields a matrix (the Jacobian) $\nabla_{\mathbf{x}}\mathbf{f} = egin{bmatrix} \frac{\partial f_1(\mathbf{x})}{\partial x} & \dots & \frac{\partial f_k(\mathbf{x})}{\partial x} \end{bmatrix}$
- Example: Linear form $\nabla_{\mathbf{x}}\mathbf{xa} = \mathbf{a}^T$
