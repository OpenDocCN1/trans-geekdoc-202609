# # Case 1: Expectation Maximization

$$\log p(\boldsymbol{x}) = \int q(z) \log \frac{p(oldsymbol{x}|z)p(z)}{q(z)} dz + \int q(z) \log \frac{q(z)}{p(oldsymbol{x}|z)} dz$$
$$\$\text{marginal log-like} \quad \text{Lower Bound } \mathcal{L}(q) \quad \text{KL Divergence: } KL(q(z)||p(\boldsymbol{x}|z))$$

**Expectation-Maximization** uses the same decomposition, but two separate optimization steps

+   - Maximization Step:
  - Keep $q(z)$ fixed, maximize Lower bound $\mathcal{L}(q, p)$ w.r.t. model distribution $p_{\varphi}(oldsymbol{x}|z)$ and $p_{\varphi}(z)$

+   - Expectation Step:
  - Keep model $p_{\varphi}(oldsymbol{x}|z)$ and $p_{\varphi}(z)$ fixed, minimize KL w.r.t $q$
  $$\q^* = \arg \min KL(q(z)||p(\boldsymbol{x}|z))$$
  $$\rightarrow q^*(oldsymbol{z}) = p(z|\boldsymbol{x})$$$

> > **Sidenote**
- In EM the KL can be set to zero (i.e. we can compute posterior $p_{\varphi}(oldsymbol{x}|z)$)
- Only works in special cases
  - e.g. discrete $z$, GMMs
- In this case the lower bound is tight
- increasing lower bound always increases marginal log-like
