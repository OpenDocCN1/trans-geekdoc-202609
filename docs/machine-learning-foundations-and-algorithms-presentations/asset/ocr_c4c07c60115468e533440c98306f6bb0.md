# Wrap-up

What we learned today:

+   - Standard DNNs are overconfident, i.e. poorly calibrated
- Bayesian Deep Learning can considerably improve upon standard deep learning
  - Improved accuracy
  - Improved calibration
- Most standard methods approximate a single mode
  ... but can be “ensembled” easily
- Ensemble methods typically perform better

Algorithms:

+   - Dropout can be formulated as Bayesian Learning algorithm using VI
- SWAG is a promising VI alternative to approximate Gaussian posteriors
