# Example: XOR

XOR in terms of elemental operations:

+   - XOR(a,b) = (a OR b) AND NOT (a AND b)

Design a network that implements XOR:

+   - Hard threshold for activation function, x1 and x2 are binary
- h1 computes x1 OR x2
- h2 computes x1 AND x2
- y computes h1 AND NOT h2
