# # Overfitting with DNNs

What theory (and traditional ML practice) says:

+   - If the model capacity is too small:
  - we underfit
- If the model capacity is too large:
  - we overfit
  - Training error will be close to 0
- **Occams Razor**: We should always prefer a simple neural network if it has similar performance
