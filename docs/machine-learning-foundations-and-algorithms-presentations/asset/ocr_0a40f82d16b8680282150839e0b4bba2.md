# Relaxed constraints with slack

# Primal optimization problem:

$\arg\min_{\mathbf{w}} \quad ||\mathbf{w}\|^2 + C \sum_{i=1}^N \xi_i$,$
$\text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$

# Dual optimization problem:

$\max_{\lambda} \sum_{i} \lambda_i - \frac{1}{2} \sum_{i} \sum_{j} \lambda_i y_i y_j k(\mathbf{x}_i, \mathbf{x}_j)$$
$\text{s.t.} \quad C \geq \lambda_i \geq 0, \forall i \in [1 \dots N], \quad \sum_{i} \lambda_i y_i = 0$

# This is a quadratic program
