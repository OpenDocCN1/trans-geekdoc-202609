# # What is a kernel?

# ## Representation by point-wise comparisons

![](bbox=[0.161, 0.318, 0.837, 0.638])

+   - Define a "comparison function" $k: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$
- Represent a set of points $\mathcal{S} = {\mathbf{x}_1, \dots, \mathbf{x}_n\}$ by the $n \times n$ matrix $[\mathbf{K}]_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)$
