# MCD as variational inference

Variational Inference for Bayesian Learning

Prior: $p(W) = \prod_{i,j} p(w_{ij}), \ p(w_{ij}) = \mathcal{N}(0, 1)$

Approximate posterior: $q(W|\mu) = \prod_{i} q(w_i|\mu_i)$ $p$ is a fixed hyper-parameter!

$q(w_i|\mu_i) = p \delta(0) + (1 - p) \delta(\mu_i)$

Approximate KL-divergence: $KL(q(W|\mu)||p(W)) \approx \alpha|\mu||_2^2$ (see paper for the proof)
