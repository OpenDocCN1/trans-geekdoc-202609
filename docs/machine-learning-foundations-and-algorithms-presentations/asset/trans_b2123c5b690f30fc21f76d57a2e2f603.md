## 为什么这么多算法？

- 不同的用场景
  - 回归、分类、密度估计等...
- 不同的属性
  - 图像、文本、图谱、时间序列
- 权衡
- 数据的复杂度
- 可解释性
- 对过拟合的敏感性
- 生成式 AI
- 多尺度方法
- 领先方法
- 小样本区域

## 7. 多尺度变形物体模拟

导师：Tai Hoang 和 Philipp Dahlinger

### 动机：

- 变形物体的模拟成本很高
- 使用图神经网络学习动力学！
- 当前方法：消息传递神经网络
- 随着分辨率增加，感受野会变小
解决方案：使用 U-Net 结构的多尺度模拟

任务：

- 熟悉数据驱动的变形物体模拟
- 理解多尺度 MGN 的领先方法
- 实现生成分层图数据集的算法
- 实现 U-Net 结构
- 从和复杂度评估新方法
