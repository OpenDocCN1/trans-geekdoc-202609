# Conclusion / Wrap-Up

For learning generative models $q(x)$ from data we need to minimize a divergence measure
$q^* = \text{argmin}_q D(q, p^*)$

+   - The KL-divergence is one of the most commonly used loss functions
- It exists in two variants with different properties:
  - Forward: Mode averaging
  - Reverse: Mode seeking

The well known Maximum Likelihood solution is a special case with
$D(q, p^*) = \text{KL}(p^*||q)$, (forward KL)

The choice of divergence and distribution q also governs the complexity of the optimization
