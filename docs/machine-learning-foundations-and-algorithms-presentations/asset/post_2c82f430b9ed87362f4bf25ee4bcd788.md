## Choosing the covariance

- Space of functions covered by the GP depend on $k(\theta, \theta')$
- Squared exponential (Gaussian) kernel

```
$k_{SE}(\theta, \theta') = \exp \left( -\frac{\sum_{i=1}^{n}(\theta_i - \theta'_i)^2}{2\rho_i^2} \right)$
```

- Isotropic if $\rho_i = \rho$ for every dimension $i$, otherwise anisotropic
- Functions defined by Gaussian kernel are often too smooth.

## Matern covariance

- Explicit parameter $\nu$ to control smoothness
- Matérn kernel:
$$k_{\nu}(\mathbf{x}, \mathbf{x}') = \frac{2^{1-\nu}}{\Gamma(\nu)} \left(\sqrt{2\nu}r^2(\mathbf{x}, \mathbf{x}')\right)^{\nu} K_{\nu} \left(\sqrt{2\nu}r^2(\mathbf{x}, \mathbf{x}')\right)$$
$$k_{5/2}(\mathbf{x}, \mathbf{x}') = \left(1 + \sqrt{5}r^2(\mathbf{x}, \mathbf{x}') + \frac{5}{3}r^2(\mathbf{x}, \mathbf{x}')\right) \exp \left(-\sqrt{5}r^2(\mathbf{x}, \mathbf{x}')\right)$$
$$\text{with} \ r^2(\mathbf{x}, \mathbf{x}') = \sum_{i=1}^{n}(x_i - x'_i)^2/\rho_i^2$$
- $\Gamma$: Gamma function
- $K_{\nu}$: Bessel function of the second kind

When $\nu \to \infty$, Matérn kernel converges to Gaussian kernel.

## Covariance hyperparameters

- The GP has its own hyper-parameters $\gamma$ to tune (Kernel parameters $\rho$, noise variance $\sigma$)
- Influence the posterior and hence also the acquisition function

![](img/f01928df50903c99ce023dd3c527a33d_982_0.png)
![](img/f01928df50903c99ce023dd3c527a33d_982_1.png)

## Selecting covariance hyperparameters

**a) Optimize the marginal likelihood under the Gaussian process:**

$\gamma^* = \text{argmax}_\gamma \log p(\mathbf{r}_{1:t}|\boldsymbol{\theta}_{1:t}, \gamma, \sigma)$, $\log p(\mathbf{r}_{1:t}|\boldsymbol{\theta}_{1:t}, \gamma, \sigma) = -\frac{1}{2}\mathbf{r}_{1:t}^T(\mathbf{K}_{\gamma} + \sigma\mathbf{I})^{-1}\mathbf{r}_{1:t} - \frac{1}{2}\log|\mathbf{K}_{\gamma} + \sigma\mathbf{I}| - \frac{t}{2}\log 2\pi$

- Can be done via gradient descent
- Uses a single point estimate for hyper-parameters.

**b) Bayesian treatment in acquisition function**

- Integrate hyperparameters out
- $acq_t(\boldsymbol{\theta}) = \int acq_t(\boldsymbol{\theta}, \gamma, \sigma)p(\gamma, \sigma|\mathbf{r}_{1:t}, \boldsymbol{\theta}_{1:t})d\gamma,\sigma$
- Can be approximated using Monte-Carlo Markov Chain (MCMC) Sampling
- Tends to work better, but computationally much more expensive.

## Example: Bayesian Optimization in AlphaGo

- During the development of AlphaGo, its many hyperparameters were tuned with Bayesian optimization multiple times.
- This automatic tuning process resulted in substantial improvements in playing strength. For example, prior to the match with Lee Sed, they tuned the latest AlphaGo agent and this improved its win-rate from 50% to 66.5% in self-play games. This tuned version was deployed in the final match.

## Multi-Fidelity Optimization

- Use cheap approximations of the blackbox, performance which correlates with the blackbox, e.g.:
  - Subsets of the data
  - Fewer epochs of iterative training (e.g., SGD)
  - Fewer trials in deep learning
  - Downsampled images in object recognition
- Also applicable in different domains, e.g., fluid simulations:
  - Less particles
  - Shorter simulations

## Multi-Fidelity Optimization

Make use of cheap low-fidelity evaluations
- E.g.: subsets of the data (here: SVM on MNIST)
![](img/f01928df50903c99ce023dd3c527a33d_989_0.png)
- Many cheap evaluations on small subsets
- Few expensive evaluations on the full data
- Up to 100x speedups [Klein et al, AISTATS 2017]

- **Envelope:**
  - Shows distance to final evaluation error (shaded areas)
  - Can only differentiate between 2 configurations if shaded areas do not overlap anymore
  - In general, the size of shaded area is unknown
- **Hyperband:**
  - Run Successive Halving multiple times with different initial budget.

## BOHB: Bayesian Optimization & Hyperband

Advantages of Hyperband
- Strong anytime performance
- General-purpose

  - High-dimensional spaces with conditionality, categorical dimensions, etc
- Easy to implement
- Scalable
- Easily parallelizable

## Advantage of Bayesian optimization: strong final performance

Combining the best of both worlds in BOHB
- Bayesian optimization
  - for choosing the configuration to evaluate (using a TPE variant)
- Hyperband
  - for deciding how to allocate budgets

## Wrap-Up

**Bayesian Optimization:**

- Bayesian treatment for learning the fitness function
- Includes model uncertainty (e.g. GPs)
- Acquisition function used to guide exploration
  - Generate samples with high model uncertainty
  - ... and potentially high reward
- Bayesian treatment of hyper-parameters help.

**Beyond Blackbox:**

- Use multiple fidelities / budgets
- Combination of hyperband and BO can speed up HPO up to a factor of 50
