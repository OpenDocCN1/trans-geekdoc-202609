# # Why so many algorithms?

+   - Different use cases
  - regression, classification, density estimation, etc...
- Different properties of the data:
  - Vectors, images, text, graphs, time-series, low-D vs high-D...
- Different trade-offs
  - Complexity vs. number of needed data points
  - Computation speed (training and testing)
  - Interpretability
  - Sensitivity to overfitting
- Nowadays everyone is talking about Deep Learning and Generative AI...
  - In most cases we would also choose a deep learning method, but...
  - We also want to understand the mathematical principles behind these methods and not purely apply them
  - In same cases, simple methods still work very well (e.g. small data regimes)
