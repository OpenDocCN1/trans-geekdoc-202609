# # The f-divergence

**Interesting fact:** Most divergences are special cases of the f-divergence

```
$D_f(p(\boldsymbol{x})||q(\boldsymbol{x})) = \int f\left(\frac{p(\boldsymbol{x})}{q(\boldsymbol{x})}\right) q(\boldsymbol{x})dx$
```

+   - with different choices for the function f
- This is also true for the forward and reverse KL!
