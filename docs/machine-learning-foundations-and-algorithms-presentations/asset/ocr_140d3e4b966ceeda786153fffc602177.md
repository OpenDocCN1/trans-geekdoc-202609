# Stochastic Weight Averaging - Gaussian (SWAG)

Use these moments to construct a low-rank Gaussian approximation.

```
$$\mu_{	heta} = \frac{1}{T} \sum \theta_t \quad \Sigma_{\theta} = 0.5 \left( \frac{1}{T-1} \sum (\theta_t - \mu_{	heta})(\theta_t - \mu_{	heta})^T + \frac{1}{T-1} \sum \text{diag}(\theta_t - \mu_{\theta})^2 \right)$
```

+   - Low rank as less samples T than dimensions
- Form predictive distribution using $q(\theta) = \mathcal{N}(\mu_{\theta}, \Sigma_{\theta})$ as posterior approximation
- Needs to be done “online” for the homework as we typically can not store so many parameter vectors
