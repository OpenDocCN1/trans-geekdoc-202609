# Basics: Gaussian Bayes rules

Bayes rule for Gaussian distribution:

+   - Marginal: $p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|oldsymbol{\mu}_{\mathbf{x}}, \Sigma_{\mathbf{x}})$ 
- Conditional: $p(\mathbf{y}|\mathbf{x}) = \mathcal{N}(\mathbf{y}|\mathbf{F}\mathbf{x}, \sigma_y^2I)$

+   - Gaussian Bayes Rule 1: $p(\mathbf{x}|\mathbf{y})$ is Gaussian with 
- Mean: $\mu_{\mathbf{x}|\mathbf{y}} = oldsymbol{\mu}_{\mathbf{x}} + \Sigma_{\mathbf{x}}\mathbf{F}^T(\sigma_y^2I + \mathbf{F}\Sigma_{\mathbf{x}}\mathbf{F}^T)^{-1}(\mathbf{y}-oldsymbol{\mu}_{\mathbf{y}})$ Correction Term 
- Covariance: $\Sigma_{\mathbf{x}|\mathbf{y}} = \Sigma_{\mathbf{x}} - \Sigma_{\mathbf{x}}\mathbf{F}^T(\sigma_y^2I + \mathbf{F}\Sigma_{\mathbf{x}}\mathbf{F}^T)^{-1}\mathbf{F}\Sigma_{\mathbf{x}}$ 
- Variance/Uncertainty is reduced by new information

Same Equations as in Kalman Filtering

Derivation: Use Eq (1) from Gaussian Identities to form joint $p(\mathbf{x}, \mathbf{y})$ from marginal $p(\mathbf{x})$ and conditional $p(\mathbf{y}|\mathbf{x})$ . Use Eq (2) to form posterior $p(\mathbf{x}|\mathbf{y})$ from joint $p(\mathbf{x}, \mathbf{y})$
