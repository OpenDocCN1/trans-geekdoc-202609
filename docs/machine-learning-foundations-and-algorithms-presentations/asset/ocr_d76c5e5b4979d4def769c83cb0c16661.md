# Kernel trick

**Recap:** Ridge Regression

+   - Squared error function + L2 regularization
- Linear feature space
- Not directly applicable in infinite dimensional feature spaces

Objective:

$L_{ridge} = (\mathbf{y} - \Phi \mathbf{w})^T(\mathbf{y} - \Phi \mathbf{w}) + \lambda \mathbf{w}^T \mathbf{w}$
\text{sum of squared errors} \quad L_2 \text{ regularization}$

Solution:

$\mathbf{w}^*_{ridge} = (\mathbf{\Phi}^T \mathbf{\Phi} + \lambda \mathbf{I})^{-1} \mathbf{\Phi}^T \mathbf{y}$
d \times d \text{ matrix inversion} \quad 	ext{Matrix inversion infeasible in infinite dimensions}$
