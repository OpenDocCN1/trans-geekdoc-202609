# Positive definite kernels

A positive definite kernel function $k$ is a function $k : \mathcal{X} 	imes \mathcal{X} ightarrow \mathbb{R}$ that is:

(i) Symmetric: $\forall \boldsymbol{x}, \boldsymbol{x}' : k(\boldsymbol{x}, \boldsymbol{x}') = k(\boldsymbol{x}', \boldsymbol{x})$

(ii) Similarity matrix is always positive semi-definite (psd)

$$\boldsymbol{a}^T K \boldsymbol{a} = \sum_{i=1}^{n} \sum_{j=1}^{n} a_i a_j k(\boldsymbol{x}_i, \boldsymbol{x}_j) \geq 0, \quad \forall \boldsymbol{a}, \forall S = {\boldsymbol{x}_1, \dots, \boldsymbol{x}_n\}$

+   - Condition for psd matrices: all eigenvalues >==

Kernel methods are algorithms that take such matrices as input.
