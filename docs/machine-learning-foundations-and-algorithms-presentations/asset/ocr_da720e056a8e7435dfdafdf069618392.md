# Data log-likelihood: $\text{loglik}(\mathcal{D}, \boldsymbol{w}_{1:K}) = \sum_{i=1}^N \log p(c_i|\boldsymbol{x}_i) = \sum_{i=1}^N \sum_{k=1}^K \boldsymbol{h}_{c_{i,k}} \log p(k|\boldsymbol{x}_i)$
$loss_i...$ loss of the ith sample

$= \sum_{i=1}^N \sum_{k=1}^K \boldsymbol{h}_{c_{i,k}} \left[ \boldsymbol{w}_k^T \phi(\boldsymbol{x}_i) - \log \left( \sum_{j=1}^K \exp(\boldsymbol{w}_j^T \phi(\boldsymbol{x}_i)) \right) \right]$

$= \sum_{i=1}^N \sum_{k=1}^K \boldsymbol{h}_{c_{i,k}} \boldsymbol{w}_k^T \phi(\boldsymbol{x}_i) - \log \left( \sum_{j=1}^K \exp(\boldsymbol{w}_j^T \phi(\boldsymbol{x}_i)) \right) \sum_{k=1}^K \boldsymbol{h}_{c_{i,k}}
$independent from k$
