# Gradient Flow in Vanilla RNNs

Vanilla RNN unit:

```
$h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t)$
$= \tanh\left(W \left[\begin{smallmatrix} h_{t-1} \\ x_t \end{smallmatrix}\right]\right)$
```

![](img/f01928df50903c99ce023dd3c527a33d_471_0.png)

Backpropagation from $h_t$ to $h_{t-1}$ multiplies by $W$ (actually $W_{hh}^T$)

- Gradient flow backwards in time

```
$\frac{\partial h_t}{\partial h_{t-1}} = \text{diag}\left(\tanh'\left(W \left[\begin{smallmatrix} h_{t-1} \\ x_t \end{smallmatrix}\right)\right)\right)W_{hh}^T$
```

![](img/f01928df50903c99ce023dd3c527a33d_471_1.png)

# Gradient Flow in Vanilla RNNs

![](img/f01928df50903c99ce023dd3c527a33d_472_0.png)

Computing gradient of $h$ involves many factors of $W$ (and repeated tanh)

- Largest singular value > 1: **Exploding gradients**
  - **Gradient Clipping**: Scale gradients if the norm is too big
- Largest singular value < 1: **Vanishing gradients**
  - We need a **different RNN architecture!**

# Long-term short-term memory (LSTM)

Contribution of old memory state and current input is gated

- **f**: Forget gate,
  - whether to erase cell
- **i**: Input gate,
  - whether to write to cell
- **g**: Gate gate (?)
  - How much to write to cell
- **o**: Output gate
  - How much to reveal cell

![](img/f01928df50903c99ce023dd3c527a33d_473_0.png)

**Next memory state:**
$c_t = f_t \circ c_{t-1} + i_t \circ g_t, \quad h_t = o_t \circ \tanh(c_t)$

# LSTM: Gradient Flow

![](img/f01928df50903c99ce023dd3c527a33d_474_0.png)

- No non-linear activation function from $c_{t-1}$ to $c_t$
- Backpropagation from $c_t$ to $c_{t-1}$ only elementwise multiplication by $f$, no multiply by $W$

# Sequence to Sequence Models

- Delayed sequence to sequence
![](img/f01928df50903c99ce023dd3c527a33d_480_0.png)

- Sequence goes in, sequence comes out
- No notion of “synchrony” between input and output
- May not even maintain order of symbols
  - E.g. “I ate an apple” -> “Ich habe einen apfel gegessen”
- Or even seem related to the input
  - E.g. “My screen is blank” -> “Please check if your computer is plugged in.”

# Bottleneck of Recurrent Models

**Simple solution:** Compute the average of all encoder hidden states

- Input this average to every stage of the decoder
- The initial decoder hidden state is now separate from the encoder
- And may be a learnable parameter

# Adding context - Using all input states

![](img/f01928df50903c99ce023dd3c527a33d_488_0.png)

**Problem: The average applies the same weight to every input**

- It supplies the same average to every output word
- In practice, different outputs may be related to different inputs
  - E.g. "Ich" is most related to "I", and "habe" and "gegessen" are both most related to "ate"
