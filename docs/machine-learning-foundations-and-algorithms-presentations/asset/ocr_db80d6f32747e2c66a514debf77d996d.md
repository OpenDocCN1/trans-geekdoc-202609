# Bayes by Backprop - Reparameterization Trick

We want to optimize distribution $p_{	heta}(x)$ using the following expected objective

$$\theta^* = \text{argmin}_\theta \mathbb{E}_{p_{	heta}}[f(x)] = \int p_{	heta}(x)f(x)dx$

... and we are given $\frac{df}{dx}(x)$. How can we exploit this information?

We can reparametrize the expectation:

+   - Introduce random variable $\xi \sim v(\xi)$ where q is a simple, parameter-free distribution (e.g.,, $v(\xi) \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$

+   - If we can find a mapping $x = h_{	heta}(\xi)$ such that $x$ is distributed as $x \sim p_{	heta}(x)$ then:

$$\int p_{	heta}(x)f(x)dx = \int v(\xi)f(h_{	heta}(\xi))d\xi$

> We moved the parameters from distribution $p_{	heta}(x)$ into a function $h_{	heta}(\xi)$
