# # Sub-gradient descent for SVMs

$$\arg\min_{\mathbf{w}} C \sum_{i=1}^{N} \max(0, 1 - y_i f(\mathbf{x}_i)) + ||\mathbf{w}||^2$\n\text{loss function} \text{regularization}$

At each iteration, pick random training sample $(\mathbf{x}_i, y_i)$

+   - If $y_i f(\mathbf{x}_i) < 1$: $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta(2\mathbf{w}_t - C_i\mathbf{x}_i)$
- Otherwise: $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta 2\mathbf{w}_t$
