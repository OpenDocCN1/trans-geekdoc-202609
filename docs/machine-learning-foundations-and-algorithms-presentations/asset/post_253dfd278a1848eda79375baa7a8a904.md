
## Attending different input states

![](img/f01928df50903c99ce023dd3c527a33d_490_0.png)

- **Solution**: Use a different weighted average for each output word
- The weighted average provided for the kth output word is:

$$c_0 = \sum_{i=1}^{N} w_i(0)h_i$$

Gerhard Neumann | Machine Learning | KIT | SS 2024

## Requirements on attention weights

* The weights $w_i(t)$ must be positive and sum to 1
-- I.e. be a distribution
- Ideally, must be high for the most relevant inputs for the ith output and low elsewhere

![](img/f01928df50903c99ce023dd3c527a33d_491_0.png)

* Solution: A two step weight computation

- First compute raw weights: $e_i(t) = g(h_i, s_{t-1})$
- Then softmax them: $w_i(t) = \frac{\exp(e_i(t))}{\sum_j \exp(e_j(t))}$

### Typical options for g()
(variables in red must be learned)

```
$g(h_i, s_{t-1}) = h_i^T s_{t-1}$
$g(h_i, s_{t-1}) = h_i^T W s_{t-1}$
$g(h_i, s_{t-1}) = MLP([h_i, s_{t-1}])$
```

## Converting an input: inference

- Compute the attention weights $w_i(0)$ for the first output using $s_{-1}$
- Will be a distribution over the input words
- Compute "context" $C_0$
- Weighted sum of input hidden states
- Input $c_0$ and $<sos>$ to the decoder at time 0
-- $<sos>$ because we are starting a new sequence
-- In practice we will enter the *embedding* of $<sos>$

![](img/f01928df50903c99ce023dd3c527a33d_493_0.png)

```
$g(h_i, s_{-1}) = h_i^T W_g s_{-1}$
$e_i(0) = g(h_i, s_{-1})$
w_i(0) = \frac{\exp(e_i(0))}{\sum_j exp(e_j(0))}$
```

## Converting an input: inference

![](img/f01928df50903c99ce023dd3c527a33d_495_0.png)

- Compute the attention weights $w_i(1)$ over all inputs for the *second* output using $s_0$
- Compute raw weights, followed by softmax
- Compute "context" $c_1$
  - Weighted sum of input hidden representations
- Input $c_1$ and first output word to the decoder
  - In practice we enter the *embedding* of the word

```
$g(h_i, s_0) = h_i^T W s_0$
$e_i(1) = g(h_i, s_0)$
w_i(1) = \frac{\exp(e_i(1))}{\sum_j \exp(e_j(1))}, c_1 = \frac{1}{N} \sum_i^N w_i(1)h_i$
```

## Attention-based decoding

![](img/f01928df50903c99ce023dd3c527a33d_497_0.png)

$e_i(t) = g(h_i, s_{t-1})$
$w_i(t) = \frac{\exp(e_i(t))}{\sum_j \exp(e_j(t))}$

$c_t = \frac{1}{N} \sum_{i=1}^N w_i(t)h_i$

## Modification: Query value

![](img/f01928df50903c99ce023dd3c527a33d_498_0.png)

- Encoder outputs an "key" and "value" at each input time
- Key is used to evaluate the importance of the input at that time, for a given output
- Decoder outputs an "query" at each output time
- Query is used to evaluate which inputs to pay attention
- The weight is a function of key and query
- The actual context is a weighted sum of value

## What does the attention learn?

![](img/f01928df50903c99ce023dd3c527a33d_499_0.png)

$g(h_i, s_0) = h_i^T w s_0$
$e_i(1) = g(h_i, s_0)$
$w_i(1) = \frac{\exp(e_i(1))}{\sum_j \exp(e_j(1))}$

- The key component of this model is the attention weight
- It captures the relative importance of each position in the input to the current output

## Training the network

![](img/f01928df50903c99ce023dd3c527a33d_501_0.png)

- Given training input (source sequence, target sequence)
- **Forward pass:** Pass the actual input sequence through the encoder
- At each time the output is a probability distribution over words

## Training the network

Back propagation also updates parameters of the “attention” function()

![](img/f01928df50903c99ce023dd3c527a33d_502_0.png)

- **Backward pass:** Compute a divergence (softmax loss) between target output and output distributions
- Backpropagate derivatives through the network

## Training Paradigms

- Decoder takes in ground truth for inference
- This approach performs maximum-likelihood estimation of the model
- The forward pass of training takes in both inputs and ground-truth output labels for generation
- This forward pass is not like regular inference
- Model output not used in autoregressive manner

## Why not auto-regression for training?

![](img/f01928df50903c99ce023dd3c527a33d_504_0.png)

The output could be anything

- And in the early stages of training, will be random
- Cannot really compute a loss
- Needs much longer to converge...

## Extension: Multi-Head Attention

![](img/f01928df50903c99ce023dd3c527a33d_505_0.png)

- Have multiple query/key/value sets
- Each attention "head" uses one of these sets
- The combined contexts from all heads are passed to the decoder
- Each "attender" focuses on a different aspect of the input that's important for the decode

## Recap: Recurrent Models as Attention Models

![](img/f01928df50903c99ce023dd3c527a33d_508_0.png)

- Encoder recurrently produces hidden representations of input word sequence
- Decoder recurrently generates output word sequence

- For each output word the decoder uses a weighted average of the hidden input representations as input “context”, along with the recurrent hidden state and the previous output word
