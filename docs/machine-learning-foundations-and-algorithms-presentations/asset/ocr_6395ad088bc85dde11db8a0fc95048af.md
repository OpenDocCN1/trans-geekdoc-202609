# Expectation-Maximization Steps

EM iteratively applies 2 steps:

$\mathcal{L}(q, \boldsymbol{	heta}) = \sum_{z} q(z) \log p(\boldsymbol{x}, z|\boldsymbol{	heta}) - \sum_{z} q(z) \log q(z)$

+   * (M)maximization-step:
  * $\boldsymbol{	heta} = \arg \max \mathcal{L}(q, \boldsymbol{	heta}) = \arg \max \sum_{z} q(z) \log p(\boldsymbol{x}, z|\boldsymbol{	heta}) + \text{const}$
  * Maximize lower bound with respect to $\boldsymbol{	heta}$
  * This is the **weighted maximum likelihood** objective
    * Each possible value of the missing data is weighted by $q(z) = p(z|\boldsymbol{x}, \boldsymbol{	heta}_{\text{old}})$
