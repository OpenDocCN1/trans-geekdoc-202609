# Basics: Gaussian propagation

Given marginal $p(x) = \mathcal{N}(x|oldsymbol{\mu}_x, oldsymbol{\Sigma}_x)$ and conditional $p(y|x) = \mathcal{N}(y|Fx, \sigma_y^2 I)$ we want to obtain the marginal for y

+   - The marginal distribution $p(y) = \int p(x)p(y|x)dx$ is Gaussian with
  - Mean: $oldsymbol{\mu}_y = Foldsymbol{\mu}_x$
  - Variance: $oldsymbol{\Sigma}_y = \sigma_y^2 I + Foldsymbol{\Sigma}_x F^T$
- Derivation:
  - Use Eq (1) to obtain joint distribution
  - Marginal $p(y)$ can be directly read from the joint
- Variance in $\mathbf{y}$ increases due to uncertainty in $\mathbf{x}$
