# Example: Linear kernel

The linear kernel is the simplest kernel for vectors

+   - Its defined by the scalar product:
$k(\mathbf{x}, \mathbf{x}') = \langle\mathbf{x}, \mathbf{x}'angle$, where $\langle\cdot, \cdotangle$ denotes the inner product
- It is always positive definite:
$\sum_{i=1}^n \sum_{j=1}^n a_i a_j \langle\mathbf{x}_i, \mathbf{x}_jangle = |\sum a_i \mathbf{x}_i\|^2 \geq 0$
