# Graph Neural Networks (GNNs) with Attention

![](bbox=[0.071, 0.258, 0.593, 0.703])

Pros:

+   - No need to store intermediate edge-based activation vectors (when using simple dot-product attention)
- Slower than GCNs but faster GNNs with edge embeddings

Cons:

+   - Most likely less expressive than GNNs with edge embedding
- Can be more difficult to optimize
