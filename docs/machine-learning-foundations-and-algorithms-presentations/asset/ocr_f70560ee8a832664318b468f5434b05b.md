# # Variational Inference for Bayesian Learning

Minimize KL to posterior distribution:

$KL(q(\theta)||p(\theta|\mathcal{D})) = \int_{	heta} q(\theta) \log \frac{q(\theta)}{p(\theta|\mathcal{D})} d\theta$\n= \int_{	heta} q(\theta) \log \frac{q(\theta)}{p(\mathcal{D}|\theta)p(\theta)} d\mathbf{x} + Z$\n= - \int_{	heta} q(\theta) \log p(\mathcal{D}|\theta) d\theta + KL(q(\theta)||p(\theta)))$

Rewrite into a maximization problem:

$\argmin_q KL(q(\theta)||p(\theta|\mathcal{D})) = \argmax_q q(\theta) \log p(\mathcal{D}|\theta) d\theta - KL(q(\theta)||p(\theta))$
