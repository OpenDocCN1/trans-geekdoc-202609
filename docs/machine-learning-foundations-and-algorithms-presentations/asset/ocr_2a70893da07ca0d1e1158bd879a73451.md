# A few kernel identities

Let $\Phi_X = \begin{bmatrix} \phi(x_1)^T \ \vdots \ \phi(x_N)^T \end{bmatrix} \in \mathbb{R}^{N \times d}$ then the following identities hold:

+   **Kernel matrix:** $K = \Phi_X \Phi_X^T$

+   - Check: $[K]_{ij} = \phi(x_i)^T \phi(x_j) = k(x_i, x_j)$

+   **Kernel vector:** $k(x^*) = \begin{bmatrix} k(x_1, x^*) \ \vdots \ k(x_N, x^*) \end{bmatrix} = \begin{bmatrix} \phi(x_1)^T \phi(x^*) \ \vdots \ \phi(x_N)^T \phi(x^*) \end{bmatrix} = \Phi_X \phi(x^*)$
