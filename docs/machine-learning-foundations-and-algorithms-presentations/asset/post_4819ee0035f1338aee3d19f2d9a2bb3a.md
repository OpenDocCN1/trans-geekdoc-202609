
## Variational Inference for Bayesian Learning

Minimize KL to posterior distribution:

$KL(q(\theta)||p(\theta|\mathcal{D})) = \int_{\theta} q(\theta) \log \frac{q(\theta)}{p(\theta|\mathcal{D})} d\theta$
$= \int_{\theta} q(\theta) \log \frac{q(\theta)}{p(\mathcal{D}|\theta)p(\theta)} d\mathbf{x} + Z$
$= - \int_{\theta} q(\theta) \log p(\mathcal{D}|\theta) d\theta + KL(q(\theta)||p(\theta))$

Rewrite into a maximization problem:

$\arg\min_q KL(q(\theta)||p(\theta|\mathcal{D})) = \arg\max_q \int q(\theta) \log p(\mathcal{D}|\theta) d\theta - KL(q(\theta)||p(\theta))$

- We need to find distribution $q$ with samples that have high likelihood...
- ... and qq should be close to prior
- The evidence $p(\mathcal{D})$ is not needed!

## Recap: Variational Inference for VAEs

VAEs **optimize the lower bound** instead of the log-likelihood

$\mathcal{L}(q, p) = \int q(z) \log \left(p(\boldsymbol{x}|z) \frac{p(z)}{q(z)}\right) dz = \int q(z) \log p(\boldsymbol{x}|z)dz - KL(q(z)||p(z))$

- Why is it a lower bound? Since $KL(q||p) \geq 0$ it follows that $\mathcal{L}(q, p) \leq \log p(\boldsymbol{x})$
- Its is also called **Evidence lower bound (ELBO)**, as the marginal likelihood is often called evidence

**Joint optimization of the lower bound** $\mathcal{L}(q, p)$ w.r.t $p$ and $q$ using stochastic gradient descent

$q^*, p^* = \arg \max_{q,p} \mathcal{L}(q, p)$

In practice, $q_\varphi(z), p_\varphi(\boldsymbol{x}|z)$ and $p_\varphi(z)$ will be parametrized distributions and we optimize over $\phi$ and $\varphi$

## Recap: Variational Inference for VAEs

**What does q learn?**

$$$$KL(q(z)||p(z|\underline{x})) = \int q(z) \log \frac{q(z)}{p(z|\underline{x})}dz = \int q(z) \log \frac{p(\underline{x})q(z)}{p(\underline{x}|z)p(z)}dz = \int q(z) \log \frac{q(z)}{p(\underline{x}|z)p(z)}dz + const$$
$= -\mathcal{L}(q,p) + const$$$$

$$\Rightarrow \arg\min_q KL(q(z)||p(z|\underline{x})) = \arg\max_q \mathcal{L}(q,p)$$

- By maximizing the variational lower bound $\mathcal{L}(q,p)$ w.r.t $q(z)$, the variational distribution will approximate the posterior, i.e. $q(z) \approx p(z|\underline{x})$
- I.e. for obtaining $q$, we minimize the l-projection (see lecture 10) to the posterior
  - This minimization is also called Variational Inference
  - Target is moving as our posterior changes with the decoder $p(\underline{x}|z)$

## Bayes by Backprop - Reparameterization Trick

We want to optimize distribution $p_{\theta}(x)$ using the following expected objective

$$\theta^* = \text{argmin}_\theta \mathbb{E}_{p_{\theta}}[f(x)] = \int p_{\theta}(x)f(x)dx$$

... and we are given $\frac{df}{dx}(x)$. How can we exploit this information?

We can reparametrize the expectation:

- Introduce random variable $\xi \sim v(\xi)$ where $q$ is a simple, parameter-free distribution (e.g., v(\xi) \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$)
- If we can find a mapping $x = h_{\theta}(\xi)$ such that $x$ is distributed as $x \sim p_{\theta}(x)$ then:

$$\int p_{\theta}(x)f(x)dx = \int v(\xi)f(h_{\theta}(\xi))d\xi$$

> We moved the parameters from distribution $p_{\theta}(x)$ into a function $h_{\theta}(\xi)$

## Basics: Reparameterization Trick

**Example:** Lets assume $p_{\theta}(x) = \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ and $v(\xi) = \mathcal{N}(\mathbf{0}, I)$. If we set $h_{\theta}(\xi) = \mu + \mathbf{A}^T\xi$, with $\theta = \{\boldsymbol{\mu}, \boldsymbol{\Sigma}\}$ and $\mathbf{A}^T\mathbf{A} = \boldsymbol{\Sigma}$ then $x' = h_{\theta}(\xi)$ is distributed with $p(x') = \mathcal{N}(\boldsymbol{\mu}, \mathbf{A}^T\mathbf{A})$

**Reparameterization Trick:**

$$\int p_{\theta}(x)f(x)dx = \int v(\xi)f(h_{\theta}(\xi))d\xi$$

**Reparameterized Gradient:**

$$\nabla_{\theta}\mathbb{E}_{p_{\theta}}[f(x)] = \nabla_{\theta} \int v(\xi)f(h_{\theta}(\xi))d\xi = \int v(\xi)\frac{\partial h_{\theta}}{\partial \theta}(\xi)\frac{\partial f}{\partial x}(x=h_{\theta}(\xi))d\xi$$

- We can now use the gradient $\frac{\partial f}{\partial x}$ to compute $\nabla_{\theta}\mathbb{E}_{p_{\theta}}[f(x)]$

## Back to Variational Inference

**Objective:** $L(\theta) = \text{KL}(q_{\theta}(x)||p^*(x)) = \int_{x} q_{\theta}(x) \left(\log q_{\theta}(x) - \log p^*(x)\right) d\mathbf{x}$

**Reparameterization:** Mean-field gaussian distribution $q_{\mu,\sigma}(x) = \mathcal{N}(\mu, \text{diag}(\sigma^2))$

- Mapping is defined as $h_{\theta}(\xi) = \mu + \sigma \circ \xi, \dots$ element-wise product
$\nabla_{\theta} L(\theta) = \nabla_{\theta} v(\xi) \left(\log q_{\theta}(h_{\theta}(\xi)) - \log p^*(h_{\theta}(\xi))\right) d\xi$

- Gradient w.r.t $\theta$ can now be easily obtained via the chain rule (backpropagation)
- In combination with VI, reparametization is called Bayes by Backprop

## Variational Inference with GMMs

### Gaussian Mixture Models:

$q(x) = \sum q(o)q(x|o), \text{ with } q(x|o) = \mathcal{N}(x|\mu_o, \Sigma_o)$

- Where $o$ is now the latent variable
- Very flexible, can represent multi-modality
- Also desirable in RL -> learn multiple solutions!
- Might need a lot of components

### Problem: Optimizing the I-projection

$$\arg \min_q \text{KL}(q(x)||p^*(x)) = \int_x q(x) \log \frac{q(x)}{p^*(x)} dx$$ for GMMs is hard (no natural gradient solution exists)

- How to do this exactly will not be covered

## Wrap-Up

What we have learned today:

+   - In VI we approximate an intractable target distribution with a tractable one using optimization
- VI is formulated as reverse KL minimization problem
- Reverse KL can generate high quality generative models (no mode averaging)
- Most common approximations are Gaussian meanfield approximations (for high-D parameters) or Gaussian Mixture Models (for low-D parameters)
- We have looked at different methods to compute the gradient of the reverse KL
- Black-box VI, Bayes by Backprob, Natural Gradients
