# What is learning?

+ “Learning denotes changes in a system that ... enable a system to do the same task ... more efficiently the next time.” - Herbert Simon (Nobel Prize in Economics)

+ “Learning is constructing or modifying representations of what is being experienced.” - Ryszard Michalski (ML pioneer)

+ “Learning is making useful changes in our minds.” - Marvin Minsky (MIT)

# What is Machine Learning?

Algorithms that can **improve their performance** using **training data**

- Typically we have a large number of **parameters**
- Learned from data

**Useful if:**

+ No expert knowledge available: industrial/manufacturing control, mass spectrometer analysis, drug design, anatomic discovery
- **Black-box expert knowledge:** face/handwriting/speech recognition, driving a car, flying a plane
- **Fast changing phenomena:** credit scoring, financial modeling, diagnosis, fraud detection
- **Customization/personalization:** personalized news reader, movie/book recommendation
