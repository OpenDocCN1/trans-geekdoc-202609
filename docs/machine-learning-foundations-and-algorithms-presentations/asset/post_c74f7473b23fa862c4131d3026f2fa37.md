
# Recipe for learning

Given: dataset $\mathcal{D} := \{x_1, x_2, x_3, \dots, x_n\} \sim q(\mathbf{x})$

- learn the density $q(\mathbf{x})$
- choose a simple source density $p(\mathbf{z})$
- use maximum likelihood

```
$$\prod_{i=1}^n q(\mathbf{x}_i) = \prod_{i=1}^n p(\mathbf{z}_i) |det(\nabla_{\mathbf{z}} \mathbf{T}(\mathbf{z}_i))^{-1}|$$
$$\hat{\mathbf{T}} := \arg \max_{\mathbf{T}} \prod_{i=1}^n p(\mathbf{z}_i) |det(\nabla_{\mathbf{z}} \mathbf{T}(\mathbf{z}_i))^{-1}|$$
$$\hat{\mathbf{T}} := \arg \max_{\mathbf{T}} \sum_{i=1}^n \log p(\mathbf{z}_i) - \log |det(\nabla_{\mathbf{z}} \mathbf{T}(\mathbf{z}_i))|$$
```

But....

what are $\mathbf{z}_i$?

$$\mathbf{z}_i = \mathbf{T}^{-1}(\mathbf{x}_i)$$

so we need the inverse computation of determinant and Jacobian must be cheap.

# Normalizing Flows - Compositions

- Bijections allow for composing several functions together!
- This follows that we can now define:
$z \sim p(z)$, $x = f_T \circ f_{T-1} \circ \dots \circ f_1(z)$
![](img/f01928df50903c99ce023ddc527a33d_796.png)

$$\log p_x(x) = \log p_z(z_0) + \sum_{t=1}^{T} \log|det f_t(z_{t-1})| \quad z_T = x, z_0$$

Inverse: $z = g_1 \circ g_2 \circ \dots \circ g_T(x)$

# Normalizing Flows - Characteristics

For a good (efficient) flow, we must have functions (steps) that are:

1. Expressive
2. Invertible
3. Offer cheap Jacobian

Computing a determinant is a cubic operation, but some special cases of matrices can make it very cheap. Which cases?

- For a diagonal matrix, the determinant is simply the product of its elements. Same applies for triangular matrix!

# Normalizing Flows - Construction

We can directly construct an invertible map from $x$ to $z$:

- Split $x$ into $x_1$ and $x_2$
- Copy $x_1$ to $z_1$
- Feed $x_1$ into DNN to predict $\alpha$ and $\beta$ (scalar or vector)
- Define $z_2$ by affine transform:
```
$z_2 = \alpha x_2 + \beta$
```
- Q: Is this map invertible?
- Q: Can we compute the Jacobian efficiently?

# Conclusion

Normalizing Flows allow for explicit computation of the density

- As opposed to VAEs, GANs or Diffusion
- Transform simple distribution into data distribution with deterministic mapping
- Needs to be:
  - Invertible
  - Cheap to compute determinant of Jacobians

Diffusion methods are more popular as they typically produce higher quality samples

- Flow architectures are limited (invertible, compute Jacobian)...
- Hard to learn (need to back prop through all composition layers

But: Flows have seen a lot of attention recently!
