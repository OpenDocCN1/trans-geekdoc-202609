# # True denoising distribution

+   - "True denoising distribution" $q(x_{t-1}|x_t, x_0)$ already knows the target
- Generative distribution $p(x_{t-1}|x_t)$ needs to learn to denoise without target

![](bbox=[0.237, 0.335, 0.673, 0.615])

$q(x_{t-1}|x_t, x_0)$ is **tractable** and can be calculated **exactly** without any approximation:

$q(x_{t-1}|x_t, x_0) = \mathcal{N}(x_{t-1}; ar{\mu}_t, ar{\Sigma}_t)$

$\bar{\mu}_t = \frac{\sqrt{\alpha_t}(1-ar{\alpha}_{t-1})}x_t + \sqrt{ar{\alpha}_{t-1}(1-\alpha_t)}x_0}{1-ar{\alpha}_t}, \quad \Sigma_t = \frac{(1-\alpha_t)(1-ar{\alpha}_{t-1})}{1-ar{\alpha}_t}$

> $q(x_{t-1}|x_t, x_0) = q(x_t|x_{t-1}, x_0)q(x_{t-1}|x_0)$
