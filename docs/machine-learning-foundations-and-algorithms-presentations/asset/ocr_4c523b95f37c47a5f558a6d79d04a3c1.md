# Data preprocessing

NNs work best with zero-mean unit variance data

$$\tilde{\mathbf{x}}_i = (\mathbf{x}_i - \mu) \oslash \sigma$$

+   - Where $\mu$ is the mean, $\sigma$ is the standard deviation and $\oslash$ the element-wise division operator
- Why? network initialization strategies are optimized for zero-mean unit variance!
