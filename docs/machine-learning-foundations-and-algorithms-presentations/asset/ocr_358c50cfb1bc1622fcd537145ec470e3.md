# EM Decomposition

Marginal Likelihood decomposes in 2 terms: $\log p(x|	heta) = \mathcal{L}(q, 	heta) + KL(q(z)|p(z|x))$

+   - Lower bound $\mathcal{L}(q, 	heta) = \sum_{z} q(z) \log p(x, z|	heta) - \sum_{z} q(z) \log q(z)
  - Contains $\log p(x, z|	heta)$ instead of $\log p(x|	heta) = \log \sum_{z} p(x, z|	heta)$
  - ... which is much easier to optimize (convex for most distributions)
  - Each $\log p(x, z|	heta)$ is weighted by $q(z)$

+   - Why is it a lower bound?
  - Since $KL(q||p) \geq 0$ it follows that $\mathcal{L}(q, 	heta) \leq \log p(x|	heta)$
