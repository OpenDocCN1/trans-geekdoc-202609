# # Backpropagation

Full backpropagation algorithm:

+   - Let $v_1, \dots, v_N$ be a topological ordering of the computation graph (i.e. parents come before children).

+   - $v_N$ denotes the variable we’re trying to compute derivatives of (e.g. loss).

![](bbox=[0.683, 0.246, 0.917, 0.506])

> forward pass
For $i = 1, \dots, N$
Compute $v_i$ as a function of $Pa(v_i)$

> backward pass
$\overline{v_N} = 1$
For $i = N - 1, \dots, 1$
$\overline{v_i} = \sum_{j \in Ch(v_i)} \overline{v_j} \frac{\partial v_j}{\partial v_i}$
