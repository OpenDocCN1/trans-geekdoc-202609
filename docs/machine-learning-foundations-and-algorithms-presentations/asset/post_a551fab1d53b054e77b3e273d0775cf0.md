# Hyper-parameter Tuning

Training NNs can involve setting many hyper-parameters

- The most common hyper-parameters include:
    - Number of layers, and number of neurons per layer
    - Initial learning rate
    - Learning rate decay schedule (e.g., decay constant)
    - Optimizer type
- Other hyper-parameters may include:
    - Regularization parameters ($L_2$ penalty, dropout rate)
    - Batch size
    - Activation functions
    - Loss function

Hyper-parameter tuning can be very time/compute-consuming for larger NNs

# Hyper-parameter Tuning

- Grid search
    - Check all values in a range with a step value
    - Only works for 2-3 dimensions

- Random search
    - Randomly sample values for the parameter
    - Often preferred to grid search

- Bayesian hyper-parameter optimization
    - Is an active area of research (see RL lecture)

- Many tools exists for doing this
    - We always need to evaluate the test loss
    - Tool easy to integrate in python and cloud computing: Weights and Biases (WandB) Sweeps
