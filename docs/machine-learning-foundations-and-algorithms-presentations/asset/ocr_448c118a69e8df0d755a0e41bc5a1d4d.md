# Generative Process

Our model can be interpreted in terms of a generative process

+   1. Sample latent variable
$z \sim \mathcal{N}(0, I)$

+   2. Linearly project to high-D space
$y = Wz + \mu$

+   3. Sample noise
$\epsilon \sim \mathcal{N}(0, \sigma^2 I)$

+   4. Add noise to obtain x
$x = y + \epsilon$
