# Predictive distribution

Still, we can use the posterior to evaluate the predictive distribution (using the Kernel trick)

```
$p(y^*|\mathbf{x}^*,\mathbf{X},\mathbf{y}) = \int p(y^*|\mathbf{w},\mathbf{x}^*)p(\mathbf{w}|\mathbf{X},\mathbf{y})dw\n= \int \mathcal{N}(y^*|\boldsymbol{\phi}_*^T\mathbf{w}, \sigma_y^2)\mathcal{N}(\mathbf{w}|\boldsymbol{\mu}_{w|\mathbf{x},\mathbf{y}}, \boldsymbol{\Sigma}_{w|x,y})dw$
```

The predictive distribution is again Gaussian with

+   - Mean: $\mu(\mathbf{x}^*) = \lambda^{-1}\boldsymbol{\phi}(\mathbf{x}^*)^T\boldsymbol{\phi}^T(\sigma_y^2\mathbf{I}+\mathbf{K})^{-1}\mathbf{y}\n= \mathbf{k}_{x^*}^T(\sigma_y^2\mathbf{I}+\mathbf{K})^{-1}\mathbf{y}$

+   - Variance: $\sigma(\mathbf{x}^*) = \sigma_y^2+\lambda^{-1}\boldsymbol{\phi}(\mathbf{x}^*)^T\boldsymbol{\phi}(\mathbf{x}^*)-\lambda^{-2}\boldsymbol{\phi}(\mathbf{x}^*)^T\boldsymbol{\phi}^T(\sigma_y^2\mathbf{I}+\mathbf{K})^{-1}\boldsymbol{\phi}\boldsymbol{\phi}(\mathbf{x}^*)\n= \sigma_y^2+k_{x^*}-\mathbf{k}_{x^*}^T(\sigma_y^2\mathbf{I}+\mathbf{K})^{-1}\mathbf{k}_{kx}\n... which is the same result as obtained with Gaussian conditioning (Slide 7)
