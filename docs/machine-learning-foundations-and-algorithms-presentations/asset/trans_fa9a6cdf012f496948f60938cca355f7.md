# 不同的学习类型

- 1. 监督学习：训练数据包含目标值
- 2. 无监督学习：训练数据不包含目标值
- 3. 强化学习：没有目标值，但对输出有评估（奖励）

  let left = 0;

# 机器学习的概念视角

- 数以千计的学习算法
- 每年都有数百种新算法
- 我们将关注基础算法并讨论连接它们的原理

每个机器学习算法都由三部分组成：

- 表示
- 评估
- 优化

# 表示

我们模型的底层表示是什么？

- * 特征
* 核函数
* 神经网络
    * 前馈神经网络
    * CNN
    * Transformer
    * GNN
* 模型集成
* 实例
* 混合模型
* 隐变量模型
* 等等

# 评估

我们正在优化什么？

- * 准确率
* 精确率和召回率
* 平方误差
* 似然性
* 后验概率
* 成本 / 效用
* 边界
* 熵
* KL 散度
* 等

# 优化

我们如何优化？

- 最小二乘解
- 梯度下降
- 带有适应学习率的梯度下降
- 二阶方法
- 约束优化
- 随机搜索
