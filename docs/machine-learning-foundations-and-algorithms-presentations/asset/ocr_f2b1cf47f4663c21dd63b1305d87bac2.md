# # Examples

Let $f_1, f_2 : \mathbb{R}^n 	o \mathbb{R}$ be convex, differentiable, and consider $f(x) = \max\{f_1(x), f_2(x)\}$

+   - For $f_1(x) > f_2(x)$, unique subgradient $g = 
abla f_1(x)$n- For $f_2(x) > f_1(x)$, unique subgradient $g = 
abla f_2(x)$n- For $f_1(x) = f_2(x)$, subgradient $g$ is any point on the segment between $
abla f_1(x)$ and $
abla f_2(x)$
