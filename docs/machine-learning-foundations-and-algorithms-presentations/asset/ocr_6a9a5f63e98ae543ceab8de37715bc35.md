# # Conditional Bernoulli as sigmoid

Define conditional probability distribution of the class label

$p(c = 1|oldsymbol{x}) = \sigma(oldsymbol{w}^T oldsymbol{x} + b), \quad p(c = 0|oldsymbol{x}) = 1 - \sigma(oldsymbol{w}^T oldsymbol{x} + b)$

+   - This is now a **conditional Bernoulli** distribution. i.e. the **outcome of the event c depends on \boldsymbol{x}**
- We can use the same “exponential trick” to select the correct probability depending on the value of c, i.e.

$p(c|oldsymbol{x}) = p(c = 1|oldsymbol{x})^c p(c = 0|oldsymbol{x})^{1-c} = \sigma(oldsymbol{w}^T oldsymbol{x} + b)^c (1 - \sigma(oldsymbol{w}^T oldsymbol{x} + b))^{1-c}$
