# Variance reduction for Ensembles

In general: Var $\left[rac{1}{M} \sum_{i=1}^{M} X_i\right] = \frac{1}{M^2}Var\left[\sum_{i=1}^{M} X_i\right] = \frac{1}{M}Var\left[X\right],, \quad$ if $X$ i.i.d.$

+   - i.e. the variance of a mean estimator linearly decreases with the number of samples
- ... if i.i.d assumption holds...

In practice: Var $\left[rac{1}{M} \sum_{i=1}^{M} \text{Model}_i\right] > \frac{1}{M}Var[\Model\],, \quad$ as models are still correlated

+   - But variance reduction is still significant
- Ensembles reduce the **variance** of the base learner but has almost no effect on the **bias**
  - i.e. less overfitting: The more models the better (but also costly)
- It's most effective if we use **strong** base learners that have very little bias but high variance, e.g., neural nets
