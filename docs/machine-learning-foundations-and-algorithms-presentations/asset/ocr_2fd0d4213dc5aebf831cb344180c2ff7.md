# Computing the Posterior

Using the Gaussian Bayes Rule 1 results in the following posterior:

$$\mu_{w|x,y} = \lambda^{-1}\boldsymbol{\Phi}^T(\sigma_y^2\boldsymbol{I} + \lambda^{-1}\boldsymbol{\Phi}\boldsymbol{\Phi}^T)^{-1}_{\mathbf{K}}\mathbf{y}$

$$\boldsymbol{\Sigma}_{w|x,y} = \lambda^{-1}\boldsymbol{I}-\lambda^{-2}\boldsymbol{\Phi}^T(\sigma_y^2\boldsymbol{I} + \mathbf{K})^{-1}_{N\times N \text{ matrix}}\boldsymbol{\Phi}$

+   - We used the Kernel trick to evaluate the inverse matrix
  - The prior precision $\lambda$ has been subsumed in the kernel
- Both quantities are still potentially infinite dimensional and can not be evaluated!
