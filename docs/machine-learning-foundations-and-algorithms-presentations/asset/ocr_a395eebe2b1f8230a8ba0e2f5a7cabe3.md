# ## Motivation:

+   - Simulation of deformable objects is costly
- Learn dynamics with Graph Neural Networks!
- Current approach: Message Passing Neural Network
- Receptive field becomes smaller with increasing the resolution
 Solution: Multi-Scale simulation using a U-Net structure

# ## Task:

+   - Get familiar with data-driven deformable object simulation
- Understand the state-art methods for Multi-Scale MGNs
- Implement algorithm for generating the hierarchical graph dataset
- Implement the U-Net structure
-Evaluate the new method with respect to quality and complexity
