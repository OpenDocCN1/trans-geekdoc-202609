# # Constraint Optimization in SVMs

![](bbox=[0.266, 0.125, 0.733, 0.413])

In constraint optimization, we have to optimize the **dual function:**

$\lambda^* = \text{argmax}_{\lambda} g(\lambda) = \text{argmax}_{\lambda} \sum_{i} \lambda_i - \frac{1}{2} \sum_{i,j} \lambda_i \lambda_j y_i y_j \phi(x_i)^T \phi(x_j), \text{s.t. } \lambda_i > 0$

+   - Where $\lambda_i$ are Lagrangian multipliers
- The weight vector can then be obtained by
  $\boldsymbol{w}^* = \sum_{i} \lambda_i y_i \phi(\boldsymbol{x}_i)$

**We can directly use the kernel trick here**

$g(\lambda) = \sum_{i} \lambda_i - \frac{1}{2} \sum_{i,j} \lambda_i \lambda_j y_i y_j k(x_i, x_j)$

+   - Scalar products of the feature vectors can be written as kernels, $i.k(x_i, x_j) = \phi(x_i)^T \phi(x_j)$
