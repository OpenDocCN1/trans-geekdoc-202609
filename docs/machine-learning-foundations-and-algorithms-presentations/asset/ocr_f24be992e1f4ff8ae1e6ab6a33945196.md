# # Reverse Denoising Process

Formal definition of forward and reverse processes in T steps:

![](bbox=[0.068, 0.253, 0.943, 0.603])

$$p(\mathbf{x}_T) = \mathcal{N}(\mathbf{x}_T; \mathbf{0}, \mathbf{I})$$

$$p\theta(\mathbf{x}_{t-1}|\mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \mu_{	heta}(\mathbf{x}_t, t), \sigma_{	heta}^2\mathbf{I})$$

$$p\theta(\mathbf{x}_{0:T}) = p(\mathbf{x}_T) \prod_{t=1}^T p\theta(\\mathbf{x}_{t-1}|\mathbf{x}_t)$$$
