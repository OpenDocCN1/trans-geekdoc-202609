# Training Paradigms

+   - Decoder takes in ground truth labels for inference

+   - This approach performs maximum-likelihood estimation of the model
  - The forward pass of training takes in both inputs and ground-truth output labels for generation
  - This forward pass is not like regular inference
  - Model output not used in autoregressive manner
