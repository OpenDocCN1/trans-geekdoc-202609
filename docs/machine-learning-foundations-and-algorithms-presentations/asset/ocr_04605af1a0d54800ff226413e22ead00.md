# Computing the Posterior

**Posterior** $p(w|X, y) = \mathcal{N}(w|\mu_{w|x,y}, \Sigma_{w|x,y}) :

+   - Posterior mean: $\mu_{w|x,y} = (\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}\Phi^T y$

+   - Posterior covariance: $\Sigma_{w|x,y} = \sigma_y^2(\Phi^T\Phi + \sigma_y^2\lambda I)^{-1}$

# **Observations:**

+   - The posterior mean is equivalent to the MAP estimate

+   - ... results from the linearity of the likelihood (not the case for non-linear models)

+   - Mean and mode are the same for Gaussians

# **So whats the advantage?**

+   - We also get an uncertainty estimate for the parameter vector!
