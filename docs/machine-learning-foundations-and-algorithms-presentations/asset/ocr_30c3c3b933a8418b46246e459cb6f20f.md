# Conclusion Optimizers

Is ADAM always the winner?

+   * ADAM is used in a lot of applications
  - Training complex models, large scale datasets, non-stationary objectives (e.g. Reinforcement learning, variational inference)
* However, for certain applications SGD is still preferred
  - Typically find models that generalize better
  - Fine-tuning and transfer learning
* Many other optimizers have been suggested including variants of ADAM.
  - There is no clear winner across all applications / architectures
