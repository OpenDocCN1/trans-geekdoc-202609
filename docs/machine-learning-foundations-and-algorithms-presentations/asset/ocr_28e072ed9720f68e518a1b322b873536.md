# Template for BO using Acquisition Functions

For each round $t$ :

+   1. Select an action $	heta_t \in \mathcal{X}$ that maximizes an acquisition function $	ext{acq}_t(\theta)$

+   2. Observe reward

$r_t = g(\theta_t) + \epsilon_t, \quad \epsilon_t \dots \text{observation noise}$

**After T rounds:** recommend solution $\theta_T^*$
