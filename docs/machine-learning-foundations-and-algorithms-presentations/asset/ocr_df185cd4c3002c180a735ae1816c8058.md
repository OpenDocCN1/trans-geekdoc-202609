# Motivation

Generative Models:

+   - We want to learn a model that can sample from the unknown data distribution $p(x)$ or a conditional distribution $p(x|y)
  - i.e. the model can generate different answers given the same input

+   - For some of these models, we will directly learn the densities $p(x)$ or $p(x|y)$
  - E.g. Language models (transformers), Gaussian mixtures

+   - For some of these models we just learn how to sample:
  - Diffusion, VAEs, GANs...
  - (density is hard to evaluate in this case)

In this lecture, we will learn the basics, but more specialized lectures cover this topic deeper
