# Linear Classifiers

A linear classifier is given in the form:

$f(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + b$

In 2D, the classifier is a line

+   - $w$ is the normal to the line
- $b$ is the bias shifting the boundary
