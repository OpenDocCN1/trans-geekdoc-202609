# Objective for the variational distribution

What does q learn?

```
$KL(q(z)||p(z|\underline{x})) = \int q(z) \log \frac{q(z)}{p(z|\underline{x})} dz = \int q(z) \log \frac{p(\underline{x})q(z)}{p(z|\underline{x})p(\underline{x})} dz = \int q(z) \log \frac{q(z)}{p(z|\underline{x})} dz + \text{const}$\n$= -\mathcal{L}(q,p) + \text{const}$
```

$\Rightarrow \argmin_q KL(q(z)||p(z|\underline{x})) = \argmax_q \mathcal{L}(q,p)$

+   - By maximizing the variational lower bound $\mathcal{L}(q,p)$ w.r.t $q(z)$, the variational distribution will approximate the posterior, i.e., $q(z) \approx p(z|\underline{x})$

-  
  - This minimization is also called Variational Inference
  - Target is moving as our posterior changes with the decoder $p(\underline{x}|z)$
