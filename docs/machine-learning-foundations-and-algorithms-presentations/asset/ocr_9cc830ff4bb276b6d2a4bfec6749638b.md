# Binary Dropout

Many models (ensemble) in one model:

+   - Linear Layer: $x_2 = Wx_1$

+   - With dropout:
$x_2 = W(x_1 \circ m)$
$m \sim \text{Bernoulli}(p), \quad p \dots \text{Dropout rate}$
