# # Gaussian Processes

A Gaussian Process (GP) $f(\boldsymbol{x}) \sim \mathcal{GP}(m(\boldsymbol{x}), k(\boldsymbol{x}, \boldsymbol{x}'))$ is a mean function covariance function

is a probability distribution over functions $f(\boldsymbol{x})$, such that any finite set of function values $t_i = f(\boldsymbol{x}_i)$ evaluated at inputs $oldsymbol{x}_1, \dots, \boldsymbol{x}_n$ is jointly Gaussian distributed

+   - Mean function evaluates our prior belief about the function
  $\mathbb{E}[f(\boldsymbol{x})] = m(\boldsymbol{x})$$
  - For simplicity, we will use $m(\boldsymbol{x}) = 0$

+   - Covariance function evaluates how similar/correlated two function evaluations at inputs $oldsymbol{x}, \boldsymbol{x}'$ are
  $\mathbb{E}[f(\boldsymbol{x})f(\boldsymbol{x}')] = k(\boldsymbol{x}, \boldsymbol{x}')$$
  - Covariance function needs to be a positive definite function (similar to a kernel function)
