# # Adaptive Momentum (Adam)

Combine momentum term with gradient normalization:

```
$g_k = \nabla_\theta \mathcal{L}(\theta_k)\nv_{k+1,i} = \gamma_1 v_{k,i} + (1 - \gamma_1)g_{k,i}^2 \quad \text{gradient norm}\nm_{k+1} = \gamma_2 m_k + (1 - \gamma_2)g_k \quad \text{momentum}\n\theta_{k+1,i} = \theta_{k,i} - \frac{\eta c_2(k)}{\sqrt{c_1(k)}v_{k+1,i} + \epsilon}} m_{k+1,i}\n\text{norm-based scaling}$
```

+   - Initialization $m_0 = 0, v_0 = 0$ leads to underestimation fixed by $c_i(k) = \frac{1}{1 - \gamma_i^k}$
- Choose $\gamma_1 = 0.9, \gamma_2 = 0.999$ and $\epsilon = 10^{-8}$. Not too sensitive to parameter changes
- Note: Violates convergence guarantees...

> [Kingma et al., 2015, Adam: A Method for Stochastic Optimization]
