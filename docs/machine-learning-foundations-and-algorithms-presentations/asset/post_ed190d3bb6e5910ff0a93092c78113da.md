
## Kernel Matrix (aka Gram Matrix)

Properties:

- **K** is always an $n \times n$ matrix, whatever the nature of data: the same algorithm will work for any type of data (vectors, strings, ...)
- Total modularity between the choice of function k and the choice of the algorithm.
- Poor scalability with respect to the dataset size ($n^2$) to compute and store **K**...
- We will restrict ourselves to a particular class of pairwise comparison functions.

## Positive definite kernels

A positive definite kernel function $k$ is a function $k : \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ that is:

(i) Symmetric: $\forall \boldsymbol{x}, \boldsymbol{x}' : k(\boldsymbol{x}, \boldsymbol{x}') = k(\boldsymbol{x}', \boldsymbol{x})$

(ii) Similarity matrix is always positive semi-definite (psd)

$$\boldsymbol{a}^T K \boldsymbol{a} = \sum_{i=1}^{n} \sum_{j=1}^{n} a_i a_j k(\boldsymbol{x}_i, \boldsymbol{x}_j) \geq 0, \quad \forall \boldsymbol{a}, \forall S = \{\boldsymbol{x}_1, \dots, \boldsymbol{x}_n\}$$

- Condition for psd matrices: all eigenvalues > 0
Kernel methods are algorithms that take such matrices as input.

## Example: Linear kernel

The linear kernel is the simplest kernel for vectors

- Its defined by the scalar product: $k(\mathbf{x}, \mathbf{x}') = \langle\mathbf{x}, \mathbf{x}'\rangle$, where $\langle\cdot, \cdot\rangle$ denotes the inner product.
- It is always positive definite: $\sum_{i=1}^n \sum_{j=1}^n a_i a_j \langle\mathbf{x}_i, \mathbf{x}_j\rangle = \|\sum a_i \mathbf{x}_i\|^2 \geq 0$

## Kernels in Feature Spaces

![](img/f01928df50903c9ce023dd3c27a33d224_0.png)

Let $\phi : \mathcal{X} \to \mathbb{R}^d$ be an arbitrary feature function, then $k(\mathbf{x}, \mathbf{x}') = \langle\phi(\mathbf{x}), \phi(\mathbf{x}')\rangle$ defines a positive definite kernel.

Proof: $\sum_{i=1}^n \sum_{j=1}^n a_i a_j \langle\phi(\mathbf{x}_i), \phi(\mathbf{x}_j)\rangle = \|\sum_{i=1}^n a_i \phi(\mathbf{x}_i)\|^2 \geq 0$

## Kernels as inner products

**Theorem (Aronsajn 1950):** $k$ is a positive semi-definite kernel on set $\mathcal{X}$ if and only if there exists a feature space $\mathcal{H}$ and a feature mapping $\phi : \mathcal{X} \to \mathcal{H}$ such that for any $x, x' \in \mathcal{X}$ :

$k(x, x') = \langle\phi(x), \phi(x')\rangle$

- **Every psd kernel** comes with an associated **feature space**!

## Example: polynomial kernel

For $\boldsymbol{x} = [x_1, x_2]^T$, let $\phi(\boldsymbol{x}) = [x_1^2, \sqrt{2}x_1x_2, x_2^2]$

The kernel is defined by:

$k(\boldsymbol{x}, \boldsymbol{x}') = x_1^2x'^2 + 2x_1x_2x_1'x_2' + x_2^2x'^2 = (x_1x_1' + x_2x_2')^2 = \langle\boldsymbol{x}, \boldsymbol{x}'\rangle^2$

Kernel for polynomials of degree $d$:

$k(\boldsymbol{x}, \boldsymbol{x}') = \langle\boldsymbol{x}, \boldsymbol{x}'\rangle^d$

## Example: Gaussian Kernel

The Gaussian kernel is defined by:

$k(\boldsymbol{x}, \mathbf{y}) = \exp\left( -\frac{||\boldsymbol{x} - \mathbf{y}||^2}{2\sigma^2} \right)$

- where $\sigma$ is the bandwidth parameter

![](img/f01928df50903c9ce023dd3c27a33d228_0.png)

Often also called:

- Radial basis function kernel (RBF)
- Squared exponential kernel

It is the **most used kernel** for kernel methods

## Is the Gaussian kernel a valid p.d. kernel?

Yes! It can be shown that the kernel is a valid product of two infinite dimensional feature vectors

- Consider the following feature function: $\phi_{\mu}(x) = 1/Z \exp \left(\frac{\|x-\mu\|^2}{\sigma^2}\right), \mu \in \mathbb{R}^d$
- I.e. we have an infinite amount of features (for every center $\mu$)
- $Z$ is a normalization constant (which we will ignore)

![](img/f01928df50903c9ce023dd3c27a33d229_0.png)

The Gaussian kernel can be computed as (not shown):

$k(x, y) = \exp \left(\frac{\|x-y\|^2}{2\sigma^2}\right) = \langle\phi_{\mu}(x), \phi_{\mu}(y)\rangle = \int \phi_{\mu}(x)\phi_{\mu}(y)d\mu$

- Inner product becomes an integral due to infinite amount of dimensions
- We never have to represent these vectors if we can directly compute their inner products

## Kernel Trick

### So why do we do this?

- Kernels can be used for most feature based algorithms that can be rewritten such that they contain inner products of feature vectors
  - This is true for almost all feature based algorithms (Linear regression, Support Vector Machines, ...)
  - This is called the Kernel Trick
- Kernels can be used to map the data $x$ in an infinite dimensional feature space (i.e., a function space)
  - The feature vector never has to be represented explicitly
  - As long as we can evaluate the inner product of two feature vectors
- Hence, we obtain a more powerful representation than standard linear feature models

## A few kernel identities

Let $\Phi_X = \begin{bmatrix} \phi(x_1)^T \\ \vdots \\ \phi(x_N)^T \end{bmatrix} \in \mathbb{R}^{N \times d}$ then the following identities hold:

- **Kernel matrix:** $K = \Phi_X \Phi_X^T$
- Check: $[K]_{ij} = \phi(x_i)^T \phi(x_j)$
- **Kernel vector:** $k = \begin{bmatrix} k(x, x_1) \\ \vdots \\ k(x, x_N) \end{bmatrix} = \phi(x)^T \Phi_X$
- **Kernel vector:** $k = \Phi_X \phi(x)^T$
- **Kernel matrix:** $K = \begin{bmatrix} k(x_1, x_1) & \dots & k(x_1, x_N) \\ \vdots & \ddots & \vdots \\ k(x_N, x_1) & \dots & k(x_N, x_N) \end{bmatrix}$

## Kernel trick

### Kernel Regression

- Regularized objective: $\min_{w} \sum_{i=1}^n (y_i - f(x_i))^2 + \lambda ||w||^2$
- $f(x) = \langle w, \phi(x) \rangle$
- Solution: $w = \sum_{i=1}^n \alpha_i \phi(x_i)$
- $f(x) = \sum_{i=1}^n \alpha_i k(x_i, x)$
- The dual problem: $(K + \lambda I)\alpha = y$

## The tale of two Pseudo Inverse

- Two side: $A^{-1}A = I, AA^{-1} = I$
- Standard matrix inverse... often not exist
- Left-Pseudo Inverse (see linear regression): $A_{left}^{\dagger} = (A^T A)^{-1}A^T$
- Right-Pseudo Inverse: $A_{right}^{\dagger} = A^T(AA^T)^{-1}$
- For regularized version, both are mathematically (but not numerically) equivalent: $(A^T A + \lambda I)^{-1}A^T = A^T(AA^T + \lambda I)^{-1}$
- Difference: Size of the matrix that needs to be inverted

## Kernel ridge regression

- Regularized objective: $\min_{w} \sum_{i=1}^n (y_i - f(x_i))^2 + \lambda ||w||^2$
- $f(x) = \langle w, \phi(x) \rangle$
- Solution: $w = \sum_{i=1}^n \alpha_i \phi(x_i)$
- $f(x) = \sum_{i=1}^n \alpha_i k(x_i, x)$
- The dual problem: $(K + \lambda I)\alpha = y$
