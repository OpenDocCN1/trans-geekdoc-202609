
## When do update W?

**Mini-Batches:** Take subset of samples $I_t \subset \{1, \dots, n\}, |I_t| = b, b \ll n$ to approximate real gradient:

$$\theta_{t+1} = \theta_t - \frac{\eta}{b} \sum_{i \in I_t} \nabla l(x_i; \theta_t)$$

- Intermediate version of stochastic and batch gradient descent
- Less noisy estimates than stochastic gradient descent
- More efficient than batch gradient descent
- Preferable for GPU implementations
- When we refer to SGD typically mean gradient descent with mini-batches

## Momentum term

**Insight:** Compute running average for gradient (or other quantities)

- $m_0 = 0, m_{k+1} = \gamma m_k + (1 - \gamma)g_k$, where $g_k$ is the gradient.
- Geometric Average (constant $\gamma$)

**Applied to the gradient update:**

$$\theta_{k+1} = \theta_k - \eta m_{k+1}$$

**Intuitively:** You can think of it as a “velocity term” for the update. The gradient is in this view acceleration.

## Gradient Normalization (RMSProp)

- In plateaus, take large steps as they do not have much risk. In steep areas take smaller steps
- Normalize gradient by running average of gradient norm

```
$$g_k = \nabla_\theta \mathcal{L}(\theta_k)$$
$$v_{k+1,i} = \gamma v_{k,i} + (1 - \gamma)g_{k,i}^2$$
$$\theta_{k+1,i} = \theta_{k,i} - \frac{\eta}{\sqrt{v_{k+1,i} + \epsilon}}g_{k,i}$$
```

- $v_{k,i}$ computes running average of the squared gradients (root mean square, RMS)
- with a small $\epsilon$ to prevent division by zero
- This algorithm is called ADDELTA or RMSProp

> [Zeiler, 2012, ADDELTA - An Adaptive Learning Rate Method]

## Adaptive Momentum (Adam)

Combine momentum term with gradient normalization:

```
$$g_k = \nabla_\theta \mathcal{L}(\theta_k)$$
$$v_{k+1,i} = \gamma_1 v_{k,i} + (1 - \gamma_1)g_{k,i}^2 \quad \text{gradient norm}$$
$$m_{k+1} = \gamma_2 m_k + (1 - \gamma_2)g_k \quad \text{momentum}$$
$$\theta_{k+1,i} = \theta_{k,i} - \frac{\eta c_2(k)}{\sqrt{c_1(k)}v_{k+1,i} + \epsilon}} m_{k+1,i} \quad \text{norm-based scaling}$$
```

- Initialization $m_0 = 0, v_0 = 0$ leads to underestimation fixed by $c_i(k) = \frac{1}{1 - \gamma_i^k}$
- Choose $\gamma_1 = 0.9, \gamma_2 = 0.999$ and $\epsilon = 10^{-8}$. Not too sensitive to parameter changes
- Note: Violates convergence guarantees...

> [Kingma et al., 2015, Adam: A Method for Stochastic Optimization]

## First vs. second order

### First order:
- Use gradient to form linear approximation
- Step along shallow dimension, jitter along steep direction

### Second order:
- Use gradient and Hessian to form quadratic approximation
- Step to minimum

## 2nd order methods

**Insight:** Taylor expansion:

$$\mathcal{L}(\theta) \approx \mathcal{L}(\theta_0) + \nabla \mathcal{L}(\theta_0)^T(\theta - \theta_0) + \frac{1}{2}(\theta - \theta_0)^T \nabla^2 \mathcal{L}(\theta_0)(\theta - \theta_0)$$

Solving for $\theta$:

$$\theta^* = \theta_0 - H^{-1}g$$

- No iterations required
- Hessian has $O(N^2)$ parameters
- Inverse is $O(N^3)$

- Quasi-Newton (BFGS most popular): Does not store the full Hessian.
- Works very well in full batch mode
- Does not transfer very well to stochastic setting. Adapting L-BFGS to large-scale is an active area of research.

- L-BFGS (Limited memory BFGS): Does not store the full Hessian.
- Works very well in full batch mode
- Does not transfer very well to stochastic setting. Adapting L-BFGS to large-scale is an active area of research.
