# # The Encoder-Decoder Model

+   * Probabilistic Encoder:
  * $p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(oldsymbol{\mu}_{z|\mathbf{x}}, oldsymbol{\Sigma}_{z|\mathbf{x}})$n  * Maps from high-dimensional output to low-dimensional input
  * Learned in E-Step

+   * Probabilistic Decoder:
  * $p(\mathbf{x}|\mathbf{z}) = \mathcal{N}(oldsymbol{W}\mathbf{x} + oldsymbol{\mu}, \sigma^2\mathbf{I})$n  * Maps from low-dimensional latent space to high dimensional output
  * Learned in M-Step
