# Batch Normalization

- Normalization of inputs for hidden layers
- Helps with exploding/vanishing gradient problems
- Can increase training stability and convergence rate
- Can be understood as additional normalization layers (with additional parameters)

# Batch Normalization

![](img/f01928df50903c99ce023dd3c527a33d_336_0.png)

- Suppose, we have net input $z_1^{(2)}$ associated with an activation in the 2nd hidden layer

- Now, consider all examples in a minibatch such that the net input of a given training example at layer 2 is written as:

$z_1^{(2)}[i], \quad i \in \{1, \dots, n\}$

- In the next slides, let's omit the layer index, as it may be distracting...

$y_1 y_2 y_3 \rightarrow \mathcal{L}(y, o)$

# BatchNorm Step 1: Normalize Net Inputs

$$\mu_j = \frac{1}{n} \sum_{i} z_j^{[i]}$$
$$\sigma_j^2 = \frac{1}{n} \sum_{i} (z_j^{[i]} - \mu_j)^2$$
$$z'_j^{[i]} = \frac{z_j^{[i]} - \mu_j}{\sigma_j}$$
For numerical stability: $$z'_j^{[i]} = \frac{z_j^{[i]} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}}$$
Zero-centered, unit variance...

# BatchNorm Step 2: Pre-Activation Scaling

$$z'_j^{[i]} = \frac{z_j^{[i]} - \mu_j}{\sigma_j}$$
$$a'_j^{[i]} = \gamma_j \cdot z'_j^{[i]} + \beta_j$$
Controls the spread
Controls the mean

# Backpropagation for Parameters

$$z_j'^{(2)} = \frac{z_j^{(2)}[i] - \mu_j}{\sigma_j} \quad a_j'^{(2)} = \gamma_j \cdot z_j'^{(2)} + \beta_j$$

![](img/f01928df50903c99ce023dd3c527a33d_340_0.png)

$$\frac{\partial l}{\partial \beta_j} = \sum_{i=1}^n \frac{\partial l}{\partial a_j'^{(2)}[i]} \cdot \frac{\partial a_j'^{(2)}[i]}{\partial \beta_j} = \sum_{i=1}^n \frac{\partial l}{\partial a_j'^{(2)}[i]}$$

$$\frac{\partial l}{\partial \gamma_j} = \sum_{i=1}^n \frac{\partial l}{\partial a_j'^{(2)}[i]} \cdot \frac{\partial a_j'^{(2)}[i]}{\partial \gamma_j} = \sum_{i=1}^n \frac{\partial l}{\partial a_j'^{(2)}[i]} \cdot z_j'^{(2)}[i]$$

# Backprop Beyond the BatchNorm Layer

![](img/f01928df50903c99ce023dd3c527a33d_341_0.png)

Since the minibatch mean and variance act as parameters, we can/have to apply the multivariable chain rule:

$$\frac{\partial l}{\partial z_j^{(2)}[i]} = \frac{\partial l}{\partial z_j'^{(2)}[i]} \frac{\partial z_j'^{(2)}[i]}{\partial z_j^{(2)}} + \frac{\partial l}{\partial \mu_j} \frac{\partial \mu_j}{\partial z_j^{(2)}[i]} + \frac{\partial l}{\partial \sigma_j^2} \frac{\partial \sigma_j^2}{\partial z_j^{(2)}[i]} = \frac{\partial l}{\partial z_j'^{(2)}[i]} \cdot \frac{1}{\sigma_j} + \frac{\partial l}{\partial \mu_j} \cdot \frac{1}{n} + \frac{\partial l}{\partial \sigma_j^2} \cdot \frac{(z_j^{(2)}-\mu_j)}{n}$$

$$\mu_j = \frac{1}{n} \sum z_j^{[i]}$$
$$\sigma_j^2 = \frac{1}{n} \sum (z_j^{[i]}-\mu_j)^2$$
$$z_j'^{[i]} = \frac{z_j^{[i]}-\mu_j}{\sigma_j}$$

# BatchNorm During Prediction ("Inference")

- Use exponentially weighted average (moving average) of mean and variance
```
running_mean = momentum * running_mean
+ (1 - momentum) * sample_mean
```
- (where momentum is typically ~0.1; and same for variance)
- Alternatively, can also use global training set mean and variance

# Other normalization schemes

- **Layer Norm:**
  - Normalization over all neurons in a layer
  - Similar to BatchNorm, scales and shifts the normalized values using learnable parameters $\gamma$ (scale) and $\beta$ (shift)
- **Instance Norm...**
- **Group Norm...**

Which one to use depends on the architecture:

- **Batch Norm:** Most wildly used, Feedforward NNs and CNNs
- **Layer Norm:** Mostly used for sequence models and transformers

# Neural Nets summary

Neural Nets are extremely powerful and complex non-linear representations

- Can be seen as feature extraction for regression and classification
- Yet, need a lot of samples
- Can easily overfit (Criticism: they often learn the data by heart)

The last 5-10 years they have “taken over” ML

- Deep Neural Networks (depth > 2) set the gold standard in many fields
- Computer Vision, Natural Language Processing, Robotics and Reinforcement Learning, Time-Series Prediction, etc...
- **Why now?** More data, more computation... but same algorithms as 40 years ago

Yet, we do not fully understand them:

- Training them needs experience and a lot of computation
