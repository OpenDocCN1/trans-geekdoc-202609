# Understanding the true risk

**Regression example:** $y = f(\boldsymbol{x}) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$

**Expected Loss:**

$R(\hat{f}_{D_n}) = \mathbb{E}_{D_n} [\mathbb{E}_{x,y} [(\hat{f}_{D_n}(\boldsymbol{x}) - y)^2]]$
= \mathbb{E}_{D_n} [\mathbb{E}_{x} [(\hat{f}_{D_n}(\boldsymbol{x}) - \hat{f}_*(\boldsymbol{x}))^2]] + \mathbb{E}_{x} [(\hat{f}_*(\boldsymbol{x}) - f(\boldsymbol{x}))^2] + \sigma^2$
\quad \text{Variance} \quad \text{Bias}^2$

+   - $\hat{f}_*(\boldsymbol{x}) = \mathbb{E}_{D_n}[\hat{f}_{D_n}(\boldsymbol{x})]$ is the average estimate, averaged over all data de sets of size n
- ... which can approximately be seen as training with infinite data
- ... can be seen as “best achievable fit” with the given function class
