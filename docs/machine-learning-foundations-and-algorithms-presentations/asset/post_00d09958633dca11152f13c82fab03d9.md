
# Predictive distribution

Predictive GP distribution:

- Mean:
  $\mu(x^*) = k_{x^*}^T(K+\sigma_y^2 I)^{-1}y$
- Variance:
  $\sigma^2(x^*) = k^* + \sigma_y^2 - k_{x^*}^T(K+\sigma_y^2 I)^{-1}k_{x^*}$

Observations:

- mean corresponds to the Kernel Ridge Regression solution
- Yet, we also get an input dependent variance estimate
- Epistemic uncertainty: Variance is reduced if kernel activations are high

# Weight space view – GPs as Bayesian Learning Models

So why are GPs an instance of Bayesian Learning?

- We can also derive GPs from the Bayesian Linear Regression view
- Kernelized version of Bayesian Linear Regression (with infinite dimensional feature spaces)

So back to Bayesian linear regression....

- Likelihood (conditional): $p(y|X,w)=\mathcal{N}(y|\Phi w,\sigma_{y}^{2}I)$
- Prior (marginal): $p(w)=\mathcal{N}(w|\mathbf{0},\lambda^{-1}I)$
- Dimensions: $w\in\mathbb{R}^{d}$ and $Y\in\mathbb{R}^{N \times1}$, high/infinite dimensional features $d \gg N$

As the dimensionality of the marginal variable (parameter vector) is now larger than dimensionality of cond. Variable (number of samples), we have to use Gaussian Bayes rule 1

# Recap: Gaussian Bayes rule

- Gaussian Bayes Rule 1
  - Mean: $\mu_{w|x,y} = \lambda^{-1}\Phi^T(\sigma_y^2\mathbf{I} + \lambda^{-1}\Phi\Phi^T)^{-1}y$
  - Covariance: $\Sigma_{w|x,y} = \lambda^{-1}\mathbf{I} - \lambda^{-2}\Phi^T(\sigma_y^2\mathbf{I} + \lambda^{-1}\Phi\Phi^T)^{-1}\Phi$
- Gaussian Bayes Rule 2
  - Mean: $\mu_{w|x,y} = (\Phi^T\Phi + \sigma_y^2\lambda\mathbf{I})^{-1}\Phi^Ty$
  - Covariance: $\Sigma_{w|x,y} = \sigma_y^2(\Phi^T\Phi + \sigma_y^2\lambda\mathbf{I})^{-1}$

**Observations: Both rules are mathematically equivalent**

- However, numerically it can be a huge difference
- Bayes rule 1: Invert a matrix with dimension $dim(\mathbf{y}) \times dim(\mathbf{y})$
- Bayes rule 2: Invert a matrix with dimension $dim(\mathbf{w}) \times dim(\mathbf{w})$

> Use Rule 1 if $dim(\mathbf{y}) < dim(\mathbf{x})$, otherwise Rule 2

# Recap: A few kernel identities

**A kernel is an inner product of a feature space:** $k(\boldsymbol{x}, \boldsymbol{x}') = \langle\phi(\boldsymbol{x}), \phi(\boldsymbol{x}')\rangle = \phi(\boldsymbol{x})^T \phi(\boldsymbol{x}')$

Let $\Phi = \begin{bmatrix} \phi(\boldsymbol{x}_1)^T \ \vdots \phi(\boldsymbol{x}_N)^T \end{bmatrix} \in \mathbb{R}^{N \times d}$ then the following identities hold:

- Kernel matrix: $K = \Phi\Phi^T$
  - Check: $[K]_{ij} = \phi(\boldsymbol{x}_i)^T \phi(\boldsymbol{x}_j) = k(\boldsymbol{x}_i, \boldsymbol{x}_j)$
- Kernel vector: $\mathbf{k}_{\boldsymbol{x}^*} = \begin{bmatrix} k(\boldsymbol{x}_1, \boldsymbol{x}^*) \ \vdots \ k(\boldsymbol{x}_N, \boldsymbol{x}^*) \end{bmatrix} = \begin{bmatrix} \phi(\boldsymbol{x}_1)^T \phi(\boldsymbol{x}^*) \ \vdots \ \phi(\boldsymbol{x}_N)^T \phi(\boldsymbol{x}^*) \end{bmatrix} = \Phi_X \phi(\boldsymbol{x}^*)$

# “Bayesian” kernel identities

A kernel is an inner product of a feature space: $k(x, x') = \lambda^{-1}\langle\phi(x), \phi(x')\rangle = \lambda^{-1}\phi(x)^T\phi(x')$

Let $\Phi_X = \begin{bmatrix} \phi(x_1)^T \ \vdots \phi(x_N)^T \end{bmatrix} \in \mathbb{R}^{N \times d}$ then the following identities hold:

In Bayesian case, we will subsum the prior precision $\lambda$ into the kernel

- **Kernel matrix:** $K = \lambda^{-1}\Phi_X\Phi_X^T$
  - Check: $[K]_{ij} = \lambda^{-1}\phi(x_i)^T\phi(x_j) = k(x_i, x_j)$
- **Kernel vector:** $\mathbf{k}_{x^*} = \begin{bmatrix} k(x_1, x^*) \ \vdots \ k(x_N, x^*) \end{bmatrix} = \lambda^{-1}\begin{bmatrix} \phi(x_1)^T\phi(x^*) \ \vdots \ \phi(x_N)^T\phi(x^*) \end{bmatrix} = \lambda^{-1}\Phi_X\phi(x^*)$

# Computing the Posterior

Using Gaussian Rule 1 results in the following posterior:

$\mu_{w|x,y} = \lambda^{-1}\Phi^T(\sigma_y^2\mathbf{I} + \lambda^{-1}\Phi\Phi^T)^{-1}y$

$\Sigma_{w|x,y} = \lambda^{-1}\mathbf{I}-\lambda^{-2}\Phi^T(\sigma_y^2\mathbf{I} + \lambda^{-1}\Phi\Phi^T)^{-1}\Phi$

- We used the Kernel trick to evaluate inverse matrix
- The prior precision $\lambda$ has been subsumed in the kernel
- Both quantities are still infinite dimensional and not evaluated!

# Predictive distribution

Still, we can use the posterior to evaluate the predictive distribution (using the Kernel trick)

```
$p(y^*|\mathbf{x}^*,\mathbf{X},y) = \int p(y^*|\mathbf{w},\mathbf{x}^*)p(\mathbf{w}|\mathbf{X},y)dw = \int \mathcal{N}(y^*|\phi_*^T\mathbf{w}, \sigma_y^2)\mathcal{N}(\mathbf{w}|\mu_{w|x}, \Sigma_{w|x})dw$
```

The predictive distribution is again Gaussian with:

- Mean: $\mu(\mathbf{x}^*) = \lambda^{-1}\phi(\mathbf{x}^*)^T\Phi^T(\sigma_y^2\mathbf{I}+K)^{-1}y = \mathbf{k}_{x^*}^T(\sigma_y^2\mathbf{I}+K)^{-1}y$
- Variance: $\sigma(\mathbf{x}^*) = \sigma_y^2+\lambda^{-1}\phi(\mathbf{x}^*)^T\Phi^T(\sigma_y^2\mathbf{I}+K)^{-1}\phi(\mathbf{x}^*) = \sigma_y^2+k_{x^*}^T(\sigma_y^2\mathbf{I}+K)^{-1}\mathbf{k}_{x}$... which is the same result as obtained with Gaussian conditioning (Slide 7)

# Wrap-up: derivations

Function View:

- A Gaussian process is a distribution over functions, where every set of N function evaluations is jointly distributed
- Predictions can hence be performed by conditioning

Weight Space View:

- A Gaussian process is a Bayesian Kernel approach
- Underlying feature space is potentially infinite dimensional
- Weight vector (which is not representable) is integrated out using the Kernel trick

Kernel matrix corresponds to covariance matrix of the GP

While GP for Regression is computationally expensive $O(N^3)$, it is one of the most principled approaches to statistical learning for regression

# Kernels and Hyperparameters

- The parameters of the kernel (e.g. length-scale of Gaussian kernel) are called “hyper-parameters” $\beta$.
- The prior precision of the weights as well as the observation noise are for simplicity also subsumed in the kernel hyper-parameters

![](img/f01928df50903c99ce023dd3c527a33d_880_0.png)

**The most common kernel is the Gaussian / RBF / squared-exponential Kernel**

$k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \lambda^{-1} \exp \left(-\frac{\|\boldsymbol{x}_i - \boldsymbol{x}_j\|}{2l^2}\right) + \delta_{ij}\sigma_y^2$

![](img/f01928df50903c99ce023dd3c527a33d_880_1.png)

- $\lambda...$ prior precision of the weight vector
- $\sigma_y^2...$ noise variance
- (only applied if $i = j$, in this notation $K + \sigma_y^2 I$ is replaced by $\mathbf{C}$)
- $l...$ length scale

# Kernels and Hyperparameters

Squared-exponential Kernel can be extended with a length-scale per dimension

```
$k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \lambda^{-1} \exp \left(-\sum_{k=1}^{d} \frac{(x_{i,k} - x_{j,k})^2}{2l_k^2}\right) + \delta_{ij}\sigma_y^2$
```

- $\lambda...$ prior precision of the weight vector
- $\sigma_y^2...$ noise variance
- (only applied if $i = j$, in this notation $K + \sigma_y^2 I$ is replaced by $\mathbf{C}$)
- $l...$ length scale

Also called Automatic Relevance Determination (ARD) kernel:

- Optimizing the length-scale determines the relevance of each dimension
- Large length-scale -> dimension is less important
