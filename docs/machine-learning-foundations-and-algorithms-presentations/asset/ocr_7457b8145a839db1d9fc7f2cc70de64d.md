# Variational Inference

We want to approximate an intractable target distribution

$p^*(oldsymbol{x}) = \frac{	ilde{p}^*(\boldsymbol{x})}{Z}, \quad \text{with } Z = \int \tilde{p}^*(\boldsymbol{x})d\boldsymbol{x}

with a tractable distribution $q(\boldsymbol{x})$ (e.g. a Gaussian)

# What does intractable mean?

+   - We can not evaluate the normalization constant Z
- Its hard to sample from $p^*(oldsymbol{x})$
  - Can be done using Monte-Carlo Markov Chain (MCMC) sampling, but very inefficient
- As well as do inference (evaluate expectations, find $\boldsymbol{x}$ with maximum density, ...)
