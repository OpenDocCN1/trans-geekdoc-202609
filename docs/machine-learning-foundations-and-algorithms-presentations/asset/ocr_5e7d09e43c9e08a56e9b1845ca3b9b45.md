# # Change of variables

![](bbox=[0.163, 0.169, 0.381, 0.574])

# ## univariate

**Z** : source random variable and density $p(z)$

**X** : target random variable and density $q(x)$

$T : Z ightarrow X$

$q(x) = p(z) \left| \frac{\partial T(z)}{\partial z} ight|^{-1}$

$p(z)dz = q(x)dx$

# ## multivariate

**T** : $\mathbb{R}^d ightarrow \mathbb{R}^d$

$q(x) = p(z) \left| \frac{dz}{dx} ight|$

$q(x) = p(z) \left| \det\left(
abla_z T(z)ight) ight|^{-1}$
