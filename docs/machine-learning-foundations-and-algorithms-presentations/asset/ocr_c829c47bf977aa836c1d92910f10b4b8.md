# # Gaussian Mixture Models (GMMs)

```
$p(\boldsymbol{x}) = \sum_{k=1}^{K} \pi_k \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$
```

# ## Properties:

+   - Can model highly multi-modal data distributions
- Universal approximators: Can model any distribution given enough components
- Density can be easily evaluated
  - This is not the case for most other generative models!
