## Basics: Chain rule gradients of composite functions

**Objective functions for training neural nets:**

- per sample loss + regularization penalty (see lecture 2)
  $$\mathcal{L}(\theta, \mathcal{D}) = \sum_{i=1}^{N} l(\boldsymbol{x}_i, \theta) + \lambda \text{penalty}(\theta)$$

- We need to compute the following partial derivatives:
  - Layer weight matrices: $\frac{\partial\mathcal{L}}{\partial\boldsymbol{W}^{(l)}}$
  - Layer bias vectors: $\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}^{(l)}}$

- Can be done by a recursive use of the chain rule!

## Multivariable chain rule

Suppose we have a function $f(x,y)$ and functions $x(t)$ and $y(t)$ (All the variables here are scalar-valued.)

$\frac{d}{dt}f(x(t), y(t)) = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$

![](img/f01928df50903c99ce023dd3c527a33d_292_0.png)

### Example:

$f(x,y) = y + \exp(xy)$
$x(t) = \cos t$
$y(t) = t^2$

### Plug in Chain Rule:

$\frac{d}{dt}f(x(t), y(t)) = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = (y \exp(xy))(-\sin t) + (1 + x \exp(xy))(2t)$

## Backpropagation

Full backpropagation algorithm:

- Let $v_1, \dots, v_N$ be a topological ordering of the computation graph (i.e. parents come before children)
- $v_N$ is the variable we’re trying to compute derivatives of (e.g. loss).

![](img/f01928df50903c99ce023dd3c527a33d_294_0.png)

```
$$\begin{aligned} \text{forward pass} & \quad i = 1, \dots, N & \ \text{Compute } v_i \text{ as function of } Pa(v_i) \\ \text{backward pass} & \quad i = N-1, \dots, 1 & \ \overline{v_i} = \sum_{j \in Ch(v_i)} \overline{v_j} \frac{\partial v_j}{\partial v_i} \end{aligned}$$
```
