# MULTI-HEAD SELF ATTENTION BLOCK

```
$q_i^a = W_q^a h_i$
k_i^a = W_k^a h_i$
v_i^a = W_v^a h_i$
```

```
$w_{ij}^a = \text{attn}(q_i^a, k_{0:N}^a)$
```

```
$o_i^a = \sum_j w_{ij}^a v_j^a$
```

```
$o_i = [o_i^1; o_i^2; o_i^3; ...; o_i^H]$
```

```
$y_i = \text{MLP}(o_i)$
```
