# BatchNorm Step 1: Normalize Net Inputs

$$$\mu_j = \frac{1}{n} \sum_{i} z_j^{[i]}$$
$$\sigma_j^2 = \frac{1}{n} \sum_{i} (z_j^{[i]} - \mu_j)^2$$
$$z'_j^{[i]} = \frac{z_j^{[i]} - \mu_j}{\sigma_j}$$

For numerical stability: $$z'_j^{[i]} = \frac{z_j^{[i]} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}}$$
