# Recap: Matrix Calculus

Derivatives of a scalar function w.r.t a vector...

By default, we use column vector representation

+   - Yields the gradient vector: $
abla_{\mathbf{x}}f = \frac{\partial f(x)}{\partial \mathbf{x}} = \left[ \frac{\partial f(x)}{\partial \mathbf{x}_1}, \dots, \frac{\partial f(x)}{\partial \mathbf{x}_d} \right]^T$
- Example: Quadratic form $
abla_{\mathbf{x}}x^T\mathbf{x} = 2\mathbf{x}$

Derivatives of a vector-valued function w.r.t a vector...

+   - Yields a matrix (the Jacobian) $
abla_{\mathbf{x}}f = \frac{\partial f(x)}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial f_1(x)}{\partial \mathbf{x}_1} & \dots & \frac{\partial f_k(x)}{\partial \mathbf{x}_1} \ & \vdots & \vdots \ \frac{\partial f_1(x)}{\partial \mathbf{x}_d} & \dots & \frac{\partial f_k(x)}{\partial \mathbf{x}_d} \end{bmatrix}$
- Example: Linear form $
abla_{\mathbf{x}}\mathbf{A}\mathbf{x} = \mathbf{A}^T$
