# # Expected Improvement

+   - Also considers magnitude of improvement
- Improvement at location x using function $g$:n  $I_t(g, 	heta) = \max(g(	heta) - g_{t-1}^*, 0)$

As g is unknown, we can estimate the **expected improvement**:

$EI_t(	heta) = \mathbb{E}_{g \sim GP(\mathcal{D})}[I_t(	heta)|\mathcal{D}]$, where $\mathcal{D} = [	heta_1, g_1, \dots, 	heta_{t-1}, g_{t-1}]$

+   - Can again be estimated for GPs, works better then probability of improvement (PI)
- Has a hyper-parameter $\xi$ that can scale exploration
- $\xi$ is always added to $g_{t-1}^*$ to pretend we have found a higher maximum
  - Enforces exploration
