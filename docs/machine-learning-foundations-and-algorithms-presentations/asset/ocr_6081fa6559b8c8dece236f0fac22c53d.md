Since the minibatch mean and variance act as parameters, we can/have to apply the multivariable chain rule

```
$$\frac{\partial l}{\partial z_j^{(2)}[i]}} = \frac{\partial l}{\partial z'_j^{(2)}[i]}} \frac{\partial z'_j^{(2)}[i]}{\partial z_j} + \frac{\partial l}{\partial \mu_j} \frac{\partial \mu_j}{\partial z_j^{(2)}[i]} + \frac{\partial l}{\partial \sigma_j} \frac{\partial \sigma_j^2}{\partial z_j^{(2)}[i]} = \frac{\partial l}{\partial z'_j^{(2)}[i]}} \cdot \frac{1}{\sigma_j} + \frac{\partial l}{\partial \mu_j} \cdot \frac{1}{n} + \frac{\partial l}{\partial \sigma_j^2} \cdot \frac{1(z_j^{(2)}-\mu_j)}{n}$
```

```
$$\mu_j = \frac{1}{n} \sum z_j^{[i]}$
```

```
$$\sigma_j^2 = \frac{1}{n} \sum (z_j^{[i]}-\mu_j)^2$
```

```
$z_j'^{[i]} = \frac{z_j^{[i]}-\mu_j}{\sigma_j}$
```
