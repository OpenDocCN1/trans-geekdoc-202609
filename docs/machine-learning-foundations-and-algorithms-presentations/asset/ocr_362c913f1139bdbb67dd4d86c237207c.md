# # Gradient for Logistic Regression

$\frac{\partial \text{loss}_i}{\partial \mathbf{w}} = \frac{\partial}{\partial \mathbf{w}}(c_i \log \sigma(\mathbf{w}^T \phi(\mathbf{x}_i)) + (1 - c_i) \log (1 - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i))))$$
= c_i \frac{1}{\sigma(\mathbf{w}^T \phi(\mathbf{x}_i))}\sigma(\mathbf{w}^T \phi(\mathbf{x}_i))(1 - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i)))\phi(\mathbf{x}_i)$$
$+ (1 - c_i) \frac{1}{1 - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i))}(--)\sigma(\mathbf{w}^T \phi(\mathbf{x}_i))(1 - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i)))\phi(\mathbf{x}_i)$$\n= c_i(1 - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i)))\phi(\mathbf{x}_i) - (1 - c_i)\sigma(\mathbf{w}^T \phi(\mathbf{x}_i))\phi(\mathbf{x}_i)$$\n= (c_i - \sigma(\mathbf{w}^T \phi(\mathbf{x}_i)))\phi(\mathbf{x}_i)$
