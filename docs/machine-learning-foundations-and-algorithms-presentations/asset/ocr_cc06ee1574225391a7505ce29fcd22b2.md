# 2nd order methods

2nd order Taylor approximation:

```
$$\mathcal{L}(\theta) \approx \mathcal{L}(\theta_0) + (\theta - \theta_0)^T \mathbf{g} + (\theta - \theta_0)^T \mathbf{H}(\theta - \theta_0)$
```

+   - With $g = \nabla_{\theta}\mathcal{L}(\theta)$ is the gradient and $H = \nabla_{\theta}^2\mathcal{L}(\theta)$ is the Hessian matrix

Solving for $\theta$ yields a Newton update:

```
$$\theta^* = \theta_0 - H^{-1}\mathbf{g}$
```

Properties:

+   - No hyperparameters
- No learning rate
- Less iterations required

+   - Hessian has O($N^2$) parameters
- Inverse is O($N^3$)
- N is huge (several millions!)
