# # Matrix Calculus

We need to know some rules from **Matrix Calculus** (see wikipedia)

| | scalar | vector | matrix |
| --- | --- | --- | --- |
| **Linear:** | $\frac{\partial ax}{\partial x} = a$ | $
abla_x Ax = \mathbf{A}^T$ | $
abla_x a^T Xb = ab^T$ |
| **Quadratic:** | $\frac{\partial x^2}{\partial x} = 2x$ | $
abla_x x^T x = 2x$<br>$
abla_x x^T Ax = (\mathbf{A}^T + \mathbf{A})x = 2\mathbf{Ax}$ if $\mathbf{A}$ is symmetric | |

**Reference:** https://en.wikipedia.org/wiki/Matrix_calculus
