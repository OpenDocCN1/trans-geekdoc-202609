# Radial Basis Function (RBF) Features

Popular generic feature representation:

$\phi(x) = [\phi_{\mu_1}(x), \dots, \phi_{\mu_M}(x)]^T, \quad \phi_{\mu_i}(x) = \exp \left( -\frac{\{\|x - \mu_i\\|^2}{2\sigma^2} \right)$

$\mu_i \dots i^{th}$ center location (fixed) \quad \sigma^2 \dots$ bandwidth

+   - M Gaussian activation functions with only local influence
  - Bandwidth typically adapted to distance between two neighboring centers
- Typically used as grid for the center locations over input space
- Hard to scale for high-D input (we need exponentially many centers)
