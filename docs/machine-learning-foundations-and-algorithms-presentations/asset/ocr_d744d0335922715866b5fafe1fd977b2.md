# Gaussian propagation for diffusion

For diffusion, lets first consider skipping one step:

```
$q(x_t|x_{t-2}) = \int_{dx_{t-1}} q(x_t|x_{t-1})q(x_{t-1}|x_{t-2})dx_{t-1} = \mathcal{N}(x_t|mu_{t|t-2}, \Sigma_{t|t-2})$
```

with $q(x_t|x_{t-1}) = \mathcal{N}(x_t|\sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)\mathbf{I})$, with $\alpha_t = 1-\beta_t$

Apply propagation:

```
$F = \sqrt{\alpha_t}, \sigma_y^2 = 1-\alpha_t, \mu_x = \sqrt{\alpha_{t-1}}x_{t-2}, \Sigma_x = (1-\alpha_{t-1})\mathbf{I}\n\mu_{t|t-2} = \sqrt{\alpha_t\alpha_{t-1}}x_{t-2},\n\Sigma_{t|t-2} = ((1-\alpha_t) + \alpha_t(1-\alpha_{t-1}))\mathbf{I} = (1-\alpha_t\alpha_{t-1})\mathbf{I}$
```

+   - Single step propagation $q(x_t|x_{t-2}) = \mathcal{N}(x_t|\sqrt{\alpha_t\alpha_{t-1}}x_{t-2}, (1-\alpha_t\alpha_{t-1})\mathbf{I})$
