# Motivation

Generative Models:

- We want to learn a model that can sample from the unknown data distribution $p(x)$ or a conditional distribution $p(x|y)$— i.e. the model can generate different answers given the same input

- For some of these models, we will directly learn the densities $p(x)$ or $p(x|y)$
- e.g. Language models (transformers), Gaussian mixtures

- For some of these models we just learn to sample:
- Diffusion, VAEs, GANs...
- (density is hard to evaluate in this case)

In this lecture, we will learn the basics, but more specialized lectures cover this topic deeper

# Divergence Measures

We can minimize a divergence measure between both distributions

```
$q^* = \text{argmin}_q \ D(q, p^*)$
```

- Between data distribution $p^*(x)$ and model $q^*(x)$
- A divergence can be seen as similarity measure between distributions

Many divergences exist:

| Kullback–Leibler divergence: | $D_{KL}(p, q) = \int \frac{p(x)}{q(x)} dx$ |
| squared Hellinger distance: | $H^2(p, q) = 2 \int (\sqrt{p(x)} - \sqrt{q(x)})^2 dx$ |
| Jensen-Shannon divergence: | $D_{JS}(p, q) = \frac{1}{2} \int p(x) (\ln(p(x)) + \ln(q(x))) - (p(x) + q(x)) \ln(\frac{p(x) + q(x)}{2}) dx$ |
| $\alpha$-divergence: | $D^{(\alpha)}(p, q) = \frac{4}{1-\alpha^2} \int (1 - p(x)/q(x))^{\frac{1+\alpha}{2}} dx$ |
| chi-squared divergence: | $D_{\chi2}(p, q) = \int \frac{(p(x) - q(x))^2}{p(x)} dx$ |
| $(\alpha,\beta)$-product divergence: | $D_{\alpha,\beta}(p, q) = \frac{2}{(1-\alpha)(1-\beta)} \int (1 - \frac{q(x)}{p(x)})^{\frac{1-\alpha}{2}} (1 - \frac{p(x)}{q(x)})^{\frac{1-\beta}{2}} p(x) dx$ |

# Most common divergences

- **Reverse KL-divergence**: Variational Inference
KL(q(x)\|p^*(x)) = \int_{x} q(x) \log \frac{q(x)}{p^*(x)}dx

- **Zero forcing**: If $p^*(x)$ is small, $q(x)$ needs to be small

- **Forward KL-divergence**: Maximum Likelihood (implicitly)
KL(p^*(x)\|q(x)) = \int_{x} p^*(x) \log \frac{p^*(x)}{q(x)}dx

- **Probability forcing**: If $p^*(x)$ is high, $q(x)$ needs to be high

- **Jensen-Shannon Divergence**: Generative Adversarial Networks (GANs)
JS(p^*(x)\|q(x)) = \frac{1}{2}(KL(p^*(x)\|m(x)) + KL(q(x)\|m(x))), with $m(x) = \frac{p^*(x) + q(x)}{2}

# Properties of the KL-divergence

Kullback-Leibler divergence:

$KL(p(\mathbf{x})||q(\mathbf{x})) = \int p(\mathbf{x}) \log \frac{p(\mathbf{x})}{q(\mathbf{x})} d\mathbf{x}$$

- Always positive: $KL(p||q) \ge 0$
- 0 iff both distributions are equal: $KL(p||q) = 0 \Leftrightarrow p = q$
- Non-symmetric: $KL(p||q) \neq KL(q||p)$

**Other names:** Relative Entropy, Information Gain...

**Also used a lot in:** Reinforcement Learning, Information theory
