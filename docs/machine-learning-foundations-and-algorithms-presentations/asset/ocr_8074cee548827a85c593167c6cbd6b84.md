# **Backward pass:**

$\overline{\mathcal{L}_{	ext{reg}}} = 1$

$\overline{\mathcal{R}} = \overline{\mathcal{L}_{	ext{reg}}} \frac{d\mathcal{L}_{	ext{reg}}}{d\mathcal{R}}
$\overline{\mathcal{R}} = \overline{\mathcal{L}_{	ext{reg}}} \lambda$

$ar{z} = ar{y} \frac{dy}{dz}$
$ar{z} = ar{y}\sigma'(z)$

$ar{w} = ar{z} \frac{\partial z}{\partial w} + \overline{\mathcal{R}} \frac{d\mathcal{R}}{dw}$
$ar{w} = ar{z}x + \overline{\mathcal{R}}w$
