# Hold-out method

+   - We would like to pick the model M with the smallest generalization error
- Can judge the generalization error by independent data set (not used for training)

**Hold-out procedure:** n datapoints available $D = \{(oldsymbol{x}_i, y_i)\}_{i=1}^n$

+   1. Split into 2 datasets:
   **Training Data**
$D_T = \{(oldsymbol{x}_i, y_i)\}_{i=1}^m
   **Validation Data**
$D_V = \{(oldsymbol{x}_i, y_i)\}_{i=m+1}^n$
2. Train on training data to obtain $\hat{f}_{D_T}(oldsymbol{x})$ for each model class M
3. Evaluate resulting estimators on validation data, e.g: $MSE(D_V, \hat{f}_{D_T}) = \frac{1}{n-m} \sum_{i=m+1}^n (\hat{f}_{D_T}(oldsymbol{x}_i) - y_i)^2$
4. Pick model with best validation loss
