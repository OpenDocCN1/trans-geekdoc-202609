# # Backpropagation

Full backpropagation algorithm:

+   - Let $v_1, \dots, v_N$ be a topological ordering of the computation graph (i.e. parents come before children.)
- $v_N$ denotes the variable we’re trying to compute derivatives of (e.g. loss).

![](bbox=[0.688, 0.239, 0.915, 0.513])

```
$$\begin{aligned} \text{forward pass} & \quad i = 1, \dots, N \ & \text{Compute } v_i \text{ as a function of } Pa(v_i) \ \ \text{backward pass} & \quad \overline{v_N} = 1 \ & \ i = N-1, \dots, 1 \ & \overline{v_i} = \sum_{j \in Ch(v_i)} \overline{v_j} \frac{\partial v_j}{\partial v_i}} \end{aligned}$
```
