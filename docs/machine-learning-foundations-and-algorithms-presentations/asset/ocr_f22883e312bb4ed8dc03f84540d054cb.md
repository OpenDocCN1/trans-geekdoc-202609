# # Activation functions

Computes $f(x) = \max(0.1x, x)$

![](bbox=[0.127, 0.323, 0.351, 0.626])

+   - Does not saturate
- Computationally efficient
- Converges much faster than sigmoid/tanh in practice! (e.g. 6x)
- will not “die”

# # Leaky ReLU
