## Back to optimization over the variational distribution

- Lower bound: $\mathcal{L}(q, p) = \frac{1}{N} \sum_{i} \int q_\phi(\boldsymbol{z}|\boldsymbol{x}_i) \log p_\varphi(\boldsymbol{x}_i|\boldsymbol{z}) d\boldsymbol{z} - \text{KL}(q_\phi(\boldsymbol{z}|\boldsymbol{x}_i) || p_\varphi(\boldsymbol{z}))$
- Distribution: $q_\phi(\boldsymbol{z}|\boldsymbol{x}) = \mathcal{N}(\boldsymbol{z}|\mu_\phi(\boldsymbol{x}), \sigma_\phi^2(\boldsymbol{x})\boldsymbol{I})$
- Reparameterization function: $\boldsymbol{h}_\phi(\boldsymbol{\xi}, \boldsymbol{x}) = \mu_\phi(\boldsymbol{x}) + \sigma_\phi(\boldsymbol{x}) \circ \boldsymbol{\xi}$
- Reparametrized lower bound:
$\mathcal{L}(q, p) = \frac{1}{N} \sum_{i} \int p(\boldsymbol{\xi}) \left( \underbrace{\log p_\varphi(\boldsymbol{x}_i|\boldsymbol{h}(\boldsymbol{\xi}, \boldsymbol{x}_i))}_{\text{reconstruction}} - \underbrace{\log q_\phi(\boldsymbol{h}(\boldsymbol{\xi}, \boldsymbol{x}_i)|\boldsymbol{x}_i)}_{\text{KL-term}} \right)$

## Stochastic gradient descent...

- Reparameterized lower bound from before:

$$\mathcal{L}(q, p) = \frac{1}{N} \sum_{i} \int p(\xi) \left( \underbrace{\log p_{\varphi}(\boldsymbol{x}_i|\boldsymbol{h}(\xi, \boldsymbol{x}_i))}_{\text{reconstruction}} + \underbrace{\log p_{\varphi}(\boldsymbol{h}(\xi, \boldsymbol{x}_i)) - \log q_{\phi}(\boldsymbol{h}(\xi, \boldsymbol{x}_i)|\boldsymbol{x}_i)}_{\text{KL-term}} \right) $$

- Approximate integral by K samples

$$\mathcal{L}(q, p) \approx \frac{1}{N} \sum_{i} \sum_{\xi_{ik} \sim p(\xi)} \left( \underbrace{\log p_{\varphi}(\boldsymbol{x}_i|\boldsymbol{h}(\xi_{ik}, \boldsymbol{x}_i))}_{\text{reconstruction}} + \log p_{\varphi}(\boldsymbol{h}(\xi_{ik}, \boldsymbol{x}_i)) - \log q_{\phi}(\boldsymbol{h}(\xi_{ik}, \boldsymbol{x}_i)|\boldsymbol{x}_i) \right) \text{KL-term}$$

- Standard case is to use only 1 sample (K =1) of $\xi_i$ for each data sample x

$$\mathcal{L}(q, p) \approx \frac{1}{N} \sum_{i} \left( \underbrace{\log p_{\varphi}(\boldsymbol{x}_i|\boldsymbol{h}(\xi_i, \boldsymbol{x}_i))}_{\text{reconstruction}} + \log p_{\varphi}(\boldsymbol{h}(\xi_i, \boldsymbol{x}_i)) - \log q_{\phi}(\boldsymbol{h}(\xi_i, \boldsymbol{x}_i)|\boldsymbol{x}_i) \right) \text{KL-term} $$

## ELBO (from previous slide):

$\mathcal{L}(q, p) \approx \frac{1}{N} \sum_{i} \left( \log p_{\varphi}(\boldsymbol{x}_i|\boldsymbol{h}(\boldsymbol{\xi}_i, \boldsymbol{x}_i)) + \log p_{\varphi}(\boldsymbol{h}(\boldsymbol{\xi}_i, \boldsymbol{x}_i)) \right) - \log q_{\phi}(\boldsymbol{h}(\boldsymbol{\xi}_i, \boldsymbol{x}_i)|\boldsymbol{x}_i)$

- For t=1: T
- Estimate $\frac{d\mathcal{L}(q,p)}{d\phi}$ and $\frac{d\mathcal{L}(q,p)}{d\varphi}$
- Update $\phi, \varphi$

- Update all of the parameters at the same time instead of using separate E, M steps
- This is standard back propagation. Just use ELBO as loss, and run your favorite SGD variant

## Class conditional VAEs

So far, we haven’t used the labels y. A class-conditional VAE provides the labels to both the encoder and the decoder.

Since the latent code z no longer has to model the image category, it can focus on modeling the stylistic features.

If we're lucky, this lets us disentangle style and content. (Note: disentanglement is still a dark art.)

- See Kingma et al., “Semi-supervised learning with deep generative models."

## The maximum likelihood

- It decomposes the marginal likelihood in a lower bound and a term
- The integral has moved outside the log
- More direct sampling in latent space by sampling from approximate posterior $q_i(z)$ instead of prior $p(z)$
- No guarantee that we also improve marginal likelihood (except in the special case of EM)
* Expectation Maximization is a special case where posterior can be computed analytically
* Most prominent application of VB is the Variational Auto-Encoder

## Recap:

- **Reverse KL-divergence**: Variational Inference

$$KL(q(x)||p^*(x)) = \int_{x} q(x) \log \frac{q(x)}{p^*(x)}dx$$
- **Zero forcing**: If $p^*(x)$ is small, $q(x)$ needs to be small

- **Forward KL-divergence**: Maximum Likelihood (implicitly)

$$KL(p^*(x)||q(x)) = \int_{x} p^*(x) \log \frac{p^*(x)}{q(x)}dx$$
- **Probability forcing**: If $p^*(x)$ is high, $q(x)$ needs to be high
