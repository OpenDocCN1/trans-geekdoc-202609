# # Chain rule with tensors

Tensor vector product:

```
$\mathcal{T}_{ijd}\mathbf{u} = \sum_{d} \mathcal{T}_{[d,\cdot]}u_d = \sum_{d} \mathbf{X}_d u_d = \begin{bmatrix} x_1u_1 & x_2u_1 & \dots & x_nu_1 \ \vdots & \vdots & & \vdots \ x_1u_d & x_2u_d & \dots & x_nu_d \end{bmatrix} = \mathbf{ux}^T$
```

Which is the *outer product*!

![](bbox=[0.299, 0.458, 0.501, 0.743])

Hence:

```
$\nabla_{\mathbf{W}}f = \frac{\partial f(z)}{\partial \mathbf{W}} = \frac{\partial}{\partial \mathbf{W}}(\mathbf{Wx} + b) = \frac{\partial f(z)}{\partial \mathbf{z}} = \frac{\partial f(z)}{\partial \mathbf{z}}\mathbf{x}^T$
```
