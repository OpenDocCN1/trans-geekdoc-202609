# Chain rule with tensors

For weight matrices: $\frac{\partial Wx+b}{\partial W} = \mathcal{T}_{ijd}\text{ with } \mathcal{T}_{[\cdot]d} = \frac{\partial z_d}{\partial W} = \begin{pmatrix} 0^T \ \vdots \ x^T \ \vdots \ 0^T \end{pmatrix}$ Matrix with zeros, d-th row contains $x^T$

Tensor vector product:

$\mathcal{T}_{ijd}u = \sum_d \mathcal{T}_{[\cdot]d}u_d = \sum_d \mathbf{X}_du_d = \begin{bmatrix} x_1u_1 & x_2u_1 & \dots & x_nu_1 \ \vdots & & & \vdots \ x_1u_d & x_2u_d & \dots & x_nu_d \end{bmatrix} = \mathbf{u}\mathbf{x}^T$

+   - Which is the outer product!

Hence: $\nabla_W f = \frac{\partial f(z)}{\partial W} = \frac{\partial}{\partial W}(\mathbf{Wx}+b)\frac{\partial f(z)}{\partial \mathbf{z}} = \frac{\partial f(z)}{\partial \mathbf{z}}\mathbf{x}^T$
