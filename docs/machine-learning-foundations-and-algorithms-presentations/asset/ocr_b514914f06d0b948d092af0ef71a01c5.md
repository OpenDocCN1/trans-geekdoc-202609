# # Estimating Gaussian Mixture Models

So why is optimizing $\mathcal{L} = \sum_{i=1}^{N} \log p_{	heta}(oldsymbol{x}_i)$ so hard?

+   - Because we do not know which mixture component k created which data-point
- If we would have data from the joint distribution $p(oldsymbol{x}_i, k_i|	heta)$, then it would be easy ...

In this case, we can simply perform a maximum likelihood estimate:

+   - Coefficients: $\pi_k = \frac{\sum_i q_{ik}}{N}$
- Means: $\mu_k = \frac{\sum_i q_{ik}oldsymbol{x}_i}{\sum_i q_{ik}}$
- Covariances: $oldsymbol{\Sigma}_k = \frac{\sum_i q_{ik}(oldsymbol{x}_i - \mu_k)(oldsymbol{x}_i - \mu_k)^T}{\sum_i q_{ik}}$

where $q_{ik} = \mathbb{I}(k, k_i)$ is 1 if the ith sample belongs to the kth component and 0 otherwise
