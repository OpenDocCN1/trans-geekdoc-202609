# Function view

I.e. a Gaussian process over N function evaluations $t = [t_1, \dots, t_N]^T$ is completely specified by the 2nd order statistics, i.e., mean and covariance, i.e.

```
$p(t|\mathbf{X}) = \mathcal{N}(t|\mathbf{0}, \mathbf{K}) \quad \text{with} \quad \mathbf{K} = \begin{bmatrix} k(\mathbf{x}_1, \mathbf{x}_1) & \dots & k(\mathbf{x}_1, \mathbf{x}_N) \ & \vdots & \ \ k(\mathbf{x}_N, \mathbf{x}_1) & \dots & k(\mathbf{x}_N, \mathbf{x}_N) \end{bmatrix}$
```

In reality, we can only measure noisy function values, i.e. $y_i = f(\mathbf{x}_i) + \epsilon, \epsilon \sim \mathcal{N}(0, \sigma_y^2)$. We get the following Gaussian distribution over $\mathbf{y}$

```
$p(\mathbf{y}|\mathbf{X}) = \int p(\mathbf{y}|t)p(t|\mathbf{X})dt\n= \int \mathcal{N}(\mathbf{y}|t, \sigma_y^2\mathbf{I})\mathcal{N}(t|\mathbf{0}, \mathbf{K})dt \dots$ Gaussian propagation\n= \mathcal{N}(\mathbf{y}|\mathbf{0}, \mathbf{K} + \sigma_y^2\mathbf{I})$
```
