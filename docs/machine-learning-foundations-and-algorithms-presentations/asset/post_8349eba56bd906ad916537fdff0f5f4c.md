# Model Selection

Choose complexity of the model class

- Too complex: Overfitting
  - Fit noise in the data
  - Unspecified behavior between data points
  - Not enough data

- Too simple: Underfitting
  - We can not represent the underlying function

# Bias-Variance Decomposition

Regression example: $y = f(x) + \epsilon, \quad \epsilon \sim N(0, \sigma^2)$

**Expected Loss = Variance + Bias$^2$ + Noise**

**Bias:**

- Due to restriction of your model class
- Also called “structure error”

**Variance:**

- Due to randomness of the data set

**Noise:**

- Nothing we can do about it...

![](img/f01928df50903c99ce023dd3c527a33d_388_0.png)

# Understanding the true risk

Regression example: $y = f(\boldsymbol{x}) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$

Expected Loss:

```
$R(\hat{f}_{D_n}) = \mathbb{E}_{x,y} \left[(\hat{f}_{D_n}(\boldsymbol{x}) - y)^2\right]$
```

- $\hat{f}_{D_n}$ is the estimate of $f$ we obtain using data $D_n$

- The expectation is done w.r.t all training-sets $D_n$ of size $n$. What does that mean?

- Assume there is a process that can generate data sets with n data-points, e.g.:

- E.g. sample $\boldsymbol{x}$ uniformly in range $[-1,1]$
- Sample $y_i$ as $y_i = f(\boldsymbol{x}_i) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$
- Repeat n times

- The expectation averages the error over all training-sets $D_n$

Expected error for training with a specific dataset Expectation is done w.r.t all possible inputs and outputs

# Understanding the true risk

**Regression example:** $y = f(\boldsymbol{x}) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$

**Expected Loss:**

$R(\hat{f}_{D_n}) = \mathbb{E}_{D_n} [\mathbb{E}_{x,y} [(\hat{f}_{D_n}(\boldsymbol{x}) - y)^2]]$
$= \mathbb{E}_{D_n} [\mathbb{E}_{x} [(\hat{f}_{D_n}(\boldsymbol{x}) - \hat{f}^*(\boldsymbol{x}))^2] + \mathbb{E}_{x} [(\hat{f}^*(\boldsymbol{x}) - f(\boldsymbol{x}))^2] + \sigma^2]$
$= \text{Variance} + \text{Bias}^2$

- $\hat{f}^*(\boldsymbol{x}) = \mathbb{E}_{D_n}[\hat{f}_{D_n}(\boldsymbol{x})]$ is the average estimate, averaged over all sets of size n
- ... which can approximately be seen as training with infinite data
- ... can be seen as “best achievable” with the given class

![](img/f01928df50903c99ce023dd3c527a33d_390_0.png)

# Bias-Variance Decomposition

Observations:

- We can not get better than the noise

Bias: $\mathbb{E}_x [(\hat{f}^*(\boldsymbol{x}) - f(\boldsymbol{x}))^2]$
- Difference of true function to the “best” estimate
- The best you can do with your class
- Also called “structure error”

Variance: $\mathbb{E}_{D_n} [\mathbb{E}_{x} (\hat{f}_{D_n}(\boldsymbol{x}) - \hat{f}^*(\boldsymbol{x}))^2]$
- Difference of the estimates to the “best” estimate
- Due to limited size of the data set
- Depends on number of data points
- Also called “estimation error”

![](img/f01928df50903c99ce023dd3c527a33d_391_0.png)

# Bias-Variance Trade-off

Each point represents a fitted model with a different dataset

- Low variance, high bias: Underfitting
- High variance, low bias: Overfitting
- High variance, high bias: something is terribly wrong
- Low variance, low bias: too good to true

# Overfitting with DNNs

What theory (and traditional ML practice) says:

- If the model capacity is too small:
  - we underfit
- If the model capacity is too large:
  - we overfit
  - Training error will be close to 0
- **Occams' Razor**: We should always prefer a simple neural network if it has similar performance

# The double descent effect for DNNs

The “magic” of DNNs:

- Initial U-shaped curve aligns with classical understanding
- But: beyond a certain point (interpolation threshold) the test risk starts to decrease again.

This effect is called “double descent”

![](img/f01928df50903c99ce023dd3c527a33d_395_0.png)

# The double descent effect for DNNs

![](img/f01928df50903c99ce023dd3c527a33d_396_0.png)

- Classical regime:
  - Follows what we know (bias-variance trade-off)
- **Interpolation threshold:**
  - network size is about right to achieve 0 training loss.
  - Only very narrow parameter-space to achieve that
  - Rule of thumb: Num params ≈ num samples
  - Depends on: Number of samples, regularization, used optimizer, etc...
- **“Modern” interpolating regime:**
  - Many models can achieve 0 training loss. We “somehow” end up with a good generalization model
  - Might be the bias induced by stochastic gradient descent (we do not find the exact local optimum and it is noisy)

# Hold-out method

- We would like to pick the model M with the smallest generalization error
- Can judge the generalization error by independent data set (not used for training)

**Hold-out procedure:** n datapoints available $D = \{(boldsymbol{x}_i, y_i)\}_{i=1}^n$

1. Split into 2 datasets:
   **Training Data**
   $D_T = \{(boldsymbol{x}_i, y_i)\}_{i=1}^m$
   **Validation Data**
   $D_V = \{(boldsymbol{x}_i, y_i)\}_{i=m+1}^n$
2. Train on training data to obtain $\hat{f}_{D_T}(\boldsymbol{x})$ for each model class M
3. Evaluate resulting estimators on validation data, e.g: $MSE(D_V, \hat{f}_{D_T}) = \frac{1}{n-m} \sum_{i=m+1}^n (\hat{f}_{D_T}(\boldsymbol{x}_i) - y_i)^2$
4. Pick model with best validation loss
