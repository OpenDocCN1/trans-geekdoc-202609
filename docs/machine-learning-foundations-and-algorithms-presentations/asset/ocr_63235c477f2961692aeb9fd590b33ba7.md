+   - Latent variable models

+   - Marginal log likelihood very hard to compute and optimize!
  $\log p_{	heta}(oldsymbol{x}) = \log \int p_{	heta}(oldsymbol{x}|oldsymbol{z})p(oldsymbol{z})dz$

+   - Optimize Lower Bound (ELBO) instead
  $\log p_{	heta}(oldsymbol{x}) \geq \int q_{\phi}(oldsymbol{z}|oldsymbol{x}) \log \frac{p_{	heta}(oldsymbol{x}|oldsymbol{z})p(oldsymbol{z})}{q_{\phi}(oldsymbol{z}|oldsymbol{x})}dz$
  $= \int q_{\phi}(oldsymbol{z}|oldsymbol{x}) \log p_{	heta}(oldsymbol{x}|oldsymbol{z}) - KL(q_{\phi}(oldsymbol{z}|oldsymbol{x})||p(oldsymbol{z})) = \mathcal{L}(p, q)$

+   - Bound is tight with the right $q(oldsymbol{z}|oldsymbol{x})$
