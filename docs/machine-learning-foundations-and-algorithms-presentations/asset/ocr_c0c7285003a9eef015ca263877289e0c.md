# # Maximum likelihood for different distributions

![](bbox=[0.20833000000000002, 0.12667, 0.79167, 0.43917])

| Desired output: $d$ | Desired output: $[0,0, ..., 1, ..., 0]$ |
|---|---|
| L2 | $Div = \frac{1}{2}(y-d)^2$ | $Div = \frac{1}{2}\sum(y_i - d_i)^2$ |
| KL | $Div = -d \log(y) - (1-d) \log(1-y)$ | $Div = \sum d_i \log(d_i) - \sum d_i \log(y_i)$ |

+   - L2 is popular for networks that perform numeric prediction/regression
- KL is popular for networks that perform classification
