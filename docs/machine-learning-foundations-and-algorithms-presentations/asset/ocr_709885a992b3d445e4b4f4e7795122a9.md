# Calibration for Deep Learning

A network is well calibrated if predictions with a certain confidence probability are accurate with the same propability, i.e.,

$p(\hat{y} = y|conf(x) = p) = p, \forall p \in [0,1]$

Confidence plots:

$ECE = \mathbb{E}_{p\sim\mathcal{U}([0,1]),x\in\mathcal{D}} [|p(\hat{y} = y|conf(x) = p) - p|]$
