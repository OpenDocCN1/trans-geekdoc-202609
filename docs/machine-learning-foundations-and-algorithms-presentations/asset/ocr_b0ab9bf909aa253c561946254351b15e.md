# Recap: Matrix Calculus

Derivatives of a vector-valued function w.r.t a vector...

+   - Yields a matrix (the Jacobian) $$
 \nabla_x f = \begin{bmatrix} \frac{\partial f_1(x)}{\partial x_1} & \dots & \frac{\partial f_k(x)}{\partial x_1} \ \vdots & \ddots & \vdots \ \frac{\partial f_1(x)}{\partial x_d} & \dots & \frac{\partial f_k(x)}{\partial x_d} \end{bmatrix}$$

+   - Activation func is applied element wise, thus the resulting Jacobian is only a diagonal matrix
