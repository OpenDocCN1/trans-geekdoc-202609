# # Motivation

+   - For continuous spaces, we have so far just got to know a Gaussian distribution to model the data

$p(\boldsymbol{x}) = \mathcal{N}(oldsymbol{\mu}, \boldsymbol{\Sigma})$

+   - Yet, most real data distributions **are not:**
  - Unimodal
  - Symmetric

![](bbox=[0.506, 0.305, 0.977, 0.619])

+   - Hence, more generative models have to be used

+   - The Gaussian Mixture Model (GMM) is the first model we will look at
  - We can evaluate the density easily
  - We can sample easily
