
# Gaussian propagation

Given marginal $p(x) = \mathcal{N}(x|\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$ and conditional $p(y|x) = \mathcal{N}(y|\boldsymbol{F}x, \sigma_y^2\mathbf{I})$ we want to obtain the marginal for $y$

- The marginal distribution $p(y) = \int p(x)p(y|x)dx$ is Gaussian with
  - Mean: $\boldsymbol{\mu}_y = \boldsymbol{F}\boldsymbol{\mu}_x$
  - Variance: $\boldsymbol{\Sigma}_y = \sigma_y^2\mathbf{I} + \boldsymbol{F}\boldsymbol{\Sigma}_x\boldsymbol{F}^T$
  - Derivation:
    - Use Eq (1) to obtain joint distribution
    - Marginal $p(y)$ can be directly read from the joint
  - Variance in $y$ increases due to uncertainty in $x$

- **In a Gaussian linear model, all the marginals stay Gaussian!**
- And we can compute the marginals in closed form!

# Gaussian propagation for diffusion

For diffusion, lets first consider skipping one step:

```
$q(x_t|x_{t-2}) = \int_{dx_{t-1}} q(x_t|x_{t-1})q(x_{t-1}|x_{t-2})dx_{t-1} = \mathcal{N}(x_t|\mu_{t|t-2}, \Sigma_{t|t-2})$
```

with $q(x_t|x_{t-1}) = \mathcal{N}(x_t|\sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)\mathbf{I})$, with $\alpha_t = 1-\beta_t$

Apply propagation:

```
$F = \sqrt{\alpha_t}, \sigma_y^2 = 1-\alpha_t, \mu_x = \sqrt{\alpha_{t-1}}x_{t-2}, \Sigma_x = (1-\alpha_{t-1})\mathbf{I}$
\mu_{t|t-2} = \sqrt{\alpha_t\alpha_{t-1}}x_{t-2},
\Sigma_{t|t-2} = ((1-\alpha_t) + \alpha_t(1-\alpha_{t-1}))\mathbf{I} = (1-\alpha_t\alpha_{t-1})\mathbf{I}$
```

- Single step propagation $q(x_t|x_{t-2}) = \mathcal{N}(x_t|\sqrt{\alpha_t\alpha_{t-1}}x_{t-2}, (1-\alpha_t\alpha_{t-1})\mathbf{I})$

# Diffusion Kernel

Single step propagation: $q(x_t|x_{t-2}) = \mathcal{N}(x_t|\sqrt{\alpha_t\alpha_{t-1}}x_{t-2}, (1-\alpha_t\alpha_{t-1})I)$

Full-sequence propagation: $q(x_t|x_0) = \mathcal{N}(x_t|\sqrt{\bar{\alpha}_t}x_0, (1-\bar{\alpha}_t)\mathbf{I}), \text{with } \bar{\alpha}_t = \prod_{k=1}^t \alpha_k$

- This takes us from time-step 0 (the data) to time-step t in one step!
- We could do this because inference model $q(x_t|x_{t-1})$ is very simple!

# Generative Learning by Denoising

Recall, that the diffusion parameters are designed such that $q(\mathbf{x}_T) \approx \mathcal{N}(\mathbf{x}_T; \mathbf{I})$

Generation:

- Sample $\mathbf{x}_T \sim \mathcal{N}(\mathbf{x}_T; \mathbf{0}, \mathbf{I})$
- Iteratively sample $\mathbf{x}_{t-1} \sim q(\mathbf{x}_{t-1}|\mathbf{x}_t)$

True Denoising Dist.![](img/f01928df50903c99ce023dd3c527a33d_711_0.png)

In general $q(\mathbf{x}_{t-1}|\mathbf{x}_t) \propto q(\mathbf{x}_{t-1})q(\mathbf{x}_t|\mathbf{x}_{t-1})$ is intractable.

Can we approximate $q(\mathbf{x}_{t-1}|\mathbf{x}_t)$? Yes, we can use a Gaussian distribution if $\beta_t$ is small in each forward step.

# Reverse Denoising

Formal definition of forward and reverse processes in T steps:

![](img/f01928df50903c99ce023dd3c527a33d_712_0.png)

$$p(\mathbf{x}_T) = \mathcal{N}(\mathbf{x}_T; \mathbf{0}, \mathbf{I})$$

$$p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \mu_\theta(\mathbf{x}_t), \sigma_\theta^2\mathbf{I})$$

$$p_\theta(\mathbf{x}_{0:T}) = p(\mathbf{x}_T) \prod_{t=1}^T p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t)$$

Trainable network similar to the generative model in VAEs.

# Diffusion ELBO

We can again find a variational lower bound (ELBO)

```
$\log p_\theta(x_0) = \log \int p_\theta(x_{0:T})dx_{1:T}$
geq \int q(x_{1:T}|x_0) \log \frac{p_\theta(x_{0:T})}{q(x_{1:T}|x_0)} dx_{1:T}$
$= \int q(x_{1:T}|x_0) \log \frac{p(x_T) \prod_{t=1}^{T-1} p_\theta(x_t|x_{t+1})}{\prod_{t=1}^{T} q(x_t|x_{t-1})} dx_{1:T}$
```

```
$\mathbb{E}_{q(x_1|x_0)}[\log p_\theta(x_0|x_1)] - D_{KL}(q(x_T|x_0)|p(x_T)) - \sum_{t=2}^{T} \mathbb{E}_{q(x_t|x_0)}[D_{KL}(q(x_{t-1}|x_t, x_0)|p_\theta(x_{t-1}|x_t))]$
```

# Diffusion ELBO

```
$= \mathbb{E}_{q(x_1|x_0)}[\log p_\theta(x_0|x_1)] - D_{KL}(q(x_T|x_0) |p(x_T)) - \sum_{t=2} q(x_t|x_0)[D_{KL}(q(x_{t-1}|x_t, x_0) ||p_\theta(x_{t-1}|x_t)])$
```

Reconstruction, Prior matching, Denoising

- **Reconstruction**: Reconstruction from least noisy version (**hyperparameter choice can make this arbitrarily small**)
- **Prior matching**: Moving the posterior closer to the true prior on the final noisy step (**0 for diffusion models**)
- **Denoising**: Divergence between approximate denoising ($p_\theta$) and true denoising ($q$) steps

Loss can focus on the denoising term. Decomposing for each timestep, we can have the $t^{th}$ loss term:

```
$L_t = D_{KL}(q(x_{t-1}|x_t, x_0) ||p_\theta(x_{t-1}|x_t)) + C$
```

# True denoising distribution

- "True denoising distribution" $q(x_{t-1}|x_t, x_0)$ already knows the target
- Generative distribution $p(x_{t-1}|x_t)$ needs learn to denoise without target

![](img/f01928df50903c99ce023dd3c527a33d_715_0.png)

$q(x_{t-1}|x_t, x_0)$ is **tractable** and can be calculated **exactly** without any approximation:

$q(x_{t-1}|x_t, x_0) = \mathcal{N}(x_{t-1}; \bar{\mu}_t, \bar{\Sigma}_t)$

$\bar{\mu}_t = \frac{\sqrt{\alpha_t}(1-\bar{\alpha}_t)}x_t + \sqrt{\bar{\alpha}_{t-1}}(1-\alpha_t)}x_0}{1-\bar{\alpha}_t}, \quad \bar{\Sigma}_t = \frac{(1-\alpha_t)(1-\bar{\alpha}_t)}{1-\bar{\alpha}_t}$

$q(x_{t-1}|x_t, x_0) = q(x_{t-1}|x_t, x_0)$

# Basics: Bayes rules

Bayes rule for Gaussian:

- Marginal: $p(x) = \mathcal{N}(x|\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$
- Conditional: $p(y|x) = \mathcal{N}(y|\boldsymbol{F}x, \sigma_y^2\mathbf{I})$

- Bayes rule 1: $p(x|y)$ is Gaussian
  - Mean: $\boldsymbol{\mu}_{x|y} = \boldsymbol{\mu}_x + \boldsymbol{\Sigma}_x\boldsymbol{F}^T\frac{\sigma_y^2\mathbf{I} + \boldsymbol{F}\boldsymbol{\Sigma}_x\boldsymbol{F}^T}{\text{Gain}}(\boldsymbol{y}-\boldsymbol{\mu}_x)$
  - Covariance: $\boldsymbol{\Sigma}_{x|y} = \boldsymbol{\Sigma}_x - \boldsymbol{\Sigma}_x\boldsymbol{F}^T\frac{\sigma_y^2\mathbf{I} + \boldsymbol{F}\boldsymbol{\Sigma}_x\boldsymbol{F}^T}{\text{Gain}}\boldsymbol{F}\boldsymbol{\Sigma}_x$
- Variance is reduced by new information

Same as in Filtering

Derivation: Use Eq (1) from Gaussian to form $p(\boldsymbol{x}, \boldsymbol{y})$ from $p(\boldsymbol{x})$ and $p(y|x)$

# Bayes rule for obtaining denoising distribution

Bayes rule for denoising:

$q(x_{t-1}|x_t, x_0) = \frac{q(x_t|x_{t-1})q(x_{t-1}|x_0)}{q(x_t|x_0)}$
