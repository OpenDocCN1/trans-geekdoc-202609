# The f-divergence

| Divergence | Corresponding $f(t)$ | Discrete Form |
| --- | --- | --- |
| $\chi^\alpha$-divergence, $\alpha \ge 1$ | $\frac{1}{2}|t-1|^\alpha$ | $\frac{1}{2}\sum_i |\frac{p_i-q_i}{q_i}|^\alpha$ |
| Total variation distance $(\alpha = 1)$ | $\frac{1}{2}|t-1|$ | $\frac{1}{2}\sum_i |p_i-q_i|$ |
| $\alpha$-divergence | $egin{cases} \frac{t^\alpha-at-(1-\alpha)}{\alpha(\alpha-1)} & 	ext{if } \alpha 
eq 0, \alpha 
eq 1 \ t \ln t + t-1, & 	ext{if } \alpha = 1 \ -\ln t + t-1, & 	ext{if } \alpha = 0 \end{cases}$ | $\sum_i p_i \ln \frac{p_i}{q_i}$ |
| KL-divergence $(\alpha = 1)$ | $t \ln t$ | |
| reverse KL-divergence $(\alpha = 0)$ | $-\ln t$ | $\sum_i q_i \ln \frac{q_i}{p_i}$ |
| Jensen-Shannon divergence | $\frac{1}{2}(t \ln t + (t+1)\ln(\frac{t+1}{2}))$ | $\frac{1}{2}\sum_i (p_i \ln \frac{p_i}{(p_i+q_i)/2} + q_i \ln \frac{q_i}{(p_i+q_i)/2})$ |
| Jeffrey's divergence (KL + reverse KL) | $(t-1)\ln(t)$ | $\sum_i (p_i-q_i) \ln \frac{p_i}{q_i}$ |

+   * **Note:** The exact equations here do not really matter for us, but its good to know that the f-divergence exists
* General approaches exists to minimize the f-divergence for, they are typically less effective than approaches tailored for a specific divergence [1]
