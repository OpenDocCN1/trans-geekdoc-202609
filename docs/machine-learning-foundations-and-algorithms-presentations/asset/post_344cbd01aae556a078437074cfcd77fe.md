## Recap: Matrix Calculus

Derivatives of a vector-valued function w.r.t a vector...

- Yields a matrix (the Jacobian)
$$\nabla_x f = \begin{bmatrix} \frac{\partial f_1(x)}{\partial x_1} & \dots & \frac{\partial f_k(x)}{\partial x_1} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_1(x)}{\partial x_d} & \dots & \frac{\partial f_k(x)}{\partial x_d} \end{bmatrix}$$

- Activation func is applied element wise, thus the resulting Jacobian is only a diagonal matrix

## PyTorch: Autograd Example

Modern deep learning toolbox defined all the forward and backward passes for common operators (e.g. add, multiply, copy, transpose etc.) and functions (e.g. exp, log, cross-entropy) in the backend.

Here is an example of a linear layer:

$z = W^{(1)}x + b^{(1)}, \text{gradient w.r.t. } z: \bar{z}$

```python
import torch
from torch.autograd import Function

class MyCustomFCLayer(Function):
    @staticmethod
    def forward(ctx, x, W, b=None):
        ctx.save_for_backward(x, W, b)
        z = x.mm(W.t()) # Matrix multiplication
        if b is not None:
            z += b # Direct addition of the vector
        return z

    @staticmethod
    def backward(ctx, grad_z):
        x, W, b = ctx.saved_tensors
        grad_W = grad_b = None

        if ctx.needs_input_grad[0]:
            grad_x = grad_z.mm(W)
        if ctx.needs_input_grad[1]:
            grad_W = grad_z.t().mm(x)
        if b is not None and ctx.needs_input_grad[2]:
            grad_b = grad_z
```
