# # Reparameterization Trick

Example: Lets $p_	heta(x) = \mathcal{N}(oldsymbol{\mu}, oldsymbol{\Sigma})$ and $q(\xi) = \mathcal{N}(\mathbf{0}, \mathbf{I})$. If we set
$h_	heta(\xi) = oldsymbol{\mu} + \mathbf{A}^T\xi$, with $	heta = \{oldsymbol{\mu}, oldsymbol{\Sigma}\}$ and $\mathbf{A}^T\mathbf{A} = oldsymbol{\Sigma}$
Then $x' = h_	heta(\xi)$ is distributed with $p(x') = \mathcal{N}(oldsymbol{\mu}, \mathbf{A}^T\mathbf{IA}) = \mathcal{N}(oldsymbol{\mu}, oldsymbol{\Sigma})$

**Reparameterization Trick:**

$\int p_	heta(x)f(x)d\mathbf{x} = \int q(\xi)f(h_	heta(\xi))doldsymbol{\xi}$

**Reparameterized Gradient:**

$
abla_	heta\mathbb{E}_{p_	heta}[f(x)] = 
abla_	heta \int q(\xi)f(h_	heta(\xi))doldsymbol{\xi} = \int q(\xi)\frac{\partial h_	heta}{\partial	heta}(oldsymbol{\xi})\frac{\partial f}{\partial\mathbf{x}}(h_	heta(\xi))doldsymbol{\xi}$

+   - We can now use the gradient $\frac{\partial f}{\partial\mathbf{x}}$ to compute $
abla_	heta\mathbb{E}_{p_	heta}[f(x)]!$
