# # Regularization penalty

Which penalty functions can we use?

+   - $L_2$ penalty: $	ext{penalty}(	heta) = ||	heta||_2 = \sum_{d} 	heta_d^2$
- Easy to optimize (strongly convex)
- Redundant parameters will be close to 0, but never 0
- Also called **weight decay** for gradient based methods...
- Heavily used with DNNs

![](bbox=[0.677, 0.018, 0.903, 0.513])

+   - $L_1$ penalty: $	ext{penalty}(	heta) = ||	heta||_1 = \sum_{d} |	heta_d|$
- Induces **sparse** solutions
- Called “Lasso” regularization
- Much harder to optimize (not in this lecture), rarely used
