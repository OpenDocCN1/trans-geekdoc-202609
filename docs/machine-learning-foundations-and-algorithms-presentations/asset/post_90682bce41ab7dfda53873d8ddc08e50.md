# Comparison

- Ridge Regression

$f(\mathbf{x}) = \phi(\mathbf{x})^T \mathbf{w}^* = \phi(\mathbf{x})^T (\Phi^T \Phi + \lambda \mathbf{I})^{-1} \Phi^T \mathbf{y} = \sum_{i=1}^d w_i \phi_i(\mathbf{x})$
$d \times d$ matrix inversion

- Use if $d < N$

- Kernel Ridge Regression

$f(\mathbf{x}) = \phi(\mathbf{x})^T \mathbf{w}^* = \phi(\mathbf{x})^T \Phi (\Phi \Phi^T + \lambda \mathbf{I})^{-1} \mathbf{y} = \sum_{i=1}^N \alpha_i k(\mathbf{x}, \mathbf{x}_i)$
$N \times N$ matrix inversion

- Use if $N < d$

# Summary: Kernel ridge regression

The solution for kernel ridge regression is given by
$f^*(x) = k(x)^T(K + \lambda I)^{-1}y$

- No evaluations of the feature vectors needed
- Only pair-wise scalar products (evaluated by the kernel)
- Need to invert a $N \times N$ matrix (can be costly)

Note:

- We have to store all samples in kernel-based methods (they also belong to the instance-based non-parametric methods)
- Computationally expensive (matrix inverse is $O(n^{2.376})$) !
- Hyper-parameters of the method are given by the kernel-parameters
  - Can be optimized on validation-set
- Very flexible function representation, only few hyper-parameters

# Constraint Optimization in SVMs

![](img/f01928df50903c99ce023dd3c527a33d_245_0.png)

In constraint optimization, we have to optimize the **dual function:**

$\lambda^* = \text{argmax}_{\lambda} g(\lambda) = \text{argmax}_{\lambda} \sum_{i} \lambda_i - \frac{1}{2} \sum_{i,j} \lambda_i \lambda_j y_i y_j \phi(x_i)^T \phi(x_j), \text{s.t. } \lambda_i > 0$

- Where $\lambda_i$ are Lagrangian multipliers
- The weight vector can then be obtained by
  $\boldsymbol{w}^* = \sum_{i} \lambda_i y_i \phi(\boldsymbol{x}_i)$

**We can directly use the kernel trick here**

$g(\lambda) = \sum_{i} \lambda_i - \frac{1}{2} \sum_{i,j} \lambda_i \lambda_j y_i y_j k(x_i, x_j)$

- Scalar products of the feature vectors can be written as kernels, $k(x_i, x_j) = \phi(x_i)^T \phi(x_j)$

# Relaxed constraints with slack

# Primal optimization problem:

$\arg\min_{\mathbf{w}} ||\mathbf{w}\|^2 + C \sum_{i=1}^N \xi_i$,
$\text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \ge 1-\xi_i, \quad \xi_i \ge 0$

# Dual optimization problem:

$\max_{\lambda} \sum_{i} \lambda_i - \frac{1}{2} \sum_{i} \sum_{j} \lambda_i y_j k(\mathbf{x}_i, \mathbf{x}_j)$
$\text{s.t.} \quad C \ge \lambda_i \ge 0, \forall i \in [1 \dots N], \sum_{i} \lambda_i y_i = 0$

# This is a quadratic program

- Quadratic objective, linear constraints
- Efficient solution exists

# Overfitting

Huge feature space with kernels: should we worry about overfitting?

- SVM objective seeks a solution with large margin
- Theory says that large margin leads to generalization
- But everything overfits sometimes

Can control overfitting by:

- Setting C (low C -> smaller Complexity)
- Choosing a better Kernel
- Varying parameters of the Kernel (width of Gaussian, etc.)

# Takeaway messages

## What we learned today?

- Kernels estimate the similarity between samples
- They represent an inner product in a feature space
  - Allows to use potentially infinite dimensional
  - That's ok due to the kernel trick and regularization
- Many standard ML algorithms can be “kernelized"
  - i.e. rewritten in terms of inner products
  - **Regression**: Kernel Ridge regression, Gaussian Processes (to be covered), Support Vector Regression (not discovered)
  - **Classification**: SVMs, Kernel Logistic Regression (not covered)

- Very flexible representation that adapts to the complexity of the data
- Works well with small data sets

- Hard to scale to more complex (high-D) problems or large datasets
