# # Generalized logistic models

As in regression, we can fit a **linear discriminator** in a **non-linear feature** space

+   - Similar to generalized linear regression models

$\text{argmax}_w \text{loglik}(\boldsymbol{w}, D) = \text{argmax}_w \sum_{i} c_i \log \sigma(\oldsymbol{w}^T \boldsymbol{\phi}(\boldsymbol{x}_i)) + (1 - c_i) \log (1 - \sigma(\boldsymbol{w}^T \boldsymbol{\phi}(\boldsymbol{x}_i)))$

+   - Problems that are not linear separable in input space can be linear separable in feature space
