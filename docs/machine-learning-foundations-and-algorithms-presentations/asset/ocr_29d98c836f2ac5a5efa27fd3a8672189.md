+   - Classical regime:
  - Follows what we know (bias-variance trade-off)
- **Interpolation threshold:**
  - network size is about right to achieve 0 training loss.
  - Only very narrow parameter-space to achieve that
  - Rule of thumb: Num params ≈ num samples
  - Depends on: Number of samples, regularization, used optimizer, etc...
- **“Modern” interpolating regime:**
  - Many models can achieve 0 training loss. We “somehow” end up with a good generalization model
  - Might be the bias induced by stochastic gradient descent (we do not find the exact local optimum and its noisy)
