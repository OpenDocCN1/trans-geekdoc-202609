# # How can we do that?

We can minimize a divergence measure between both distributions

$q^* = \text{argmin}_q \ D(q, p^*)$

Commonly used divergence:

+   * **Reverse KL-divergence:** $KL(q(x)|\p^*(x)) = \int_{\boldsymbol{x}} q(x) \log \frac{q(\boldsymbol{x})}{p^*(oldsymbol{x})} dx$
  * **Zero forcing:** If $p^*oldsymbol{x})$ is small, $q(\boldsymbol{x})$ needs to be small

+   * **Comparison: Forward KL** $KL(p^*(oldsymbol{x})|\q(x)) = \int_{\boldsymbol{x}} p^*(oldsymbol{x}) \log \frac{p^*(oldsymbol{x})}{q(x)} dx$
  * **Probability forcing:** If $p^*(oldsymbol{x})$ is high, $q(\boldsymbol{x})$ needs to be high
