# Recap: Bayesian Learning

+   1. Compute posterior: $p(	heta|D) = \frac{p(D|	heta)p(	heta)}{p(D)}$

+   2. Integrate out posterior: $p(x^*|D) = \int p(x^*|	heta)p(	heta|D) d	heta$

# Properties:

+   - For very large datasets, the posterior will be a point estimate $\lim_{n\to\infty} p(	heta|\mathcal{D}_n) = \delta(\theta - 	heta^*)$
  - i.e., Bayesian Learning will be equivalent to maximum likelihood

+   - However, large advantage for smaller datasets!
  1. We know where our model is uncertain
  2. More robust estimate due to averaging, less overfitting
  3. For DNNs all datasets are small due to the large number of parameters
