## 1. Rescaling Data

当你处理具有不同量级的数据时，需要将属性重新缩放到相同的量级。属性被重新缩放到 0 到 1 的范围内，这被称为归一化（normalization）。为了实现这一点，使用了 scikit-learn 中的 `MinMaxScaler` 类。例如：![](rsrc11C.jpg)![](rsrc11D.jpg)重新缩放后，你将得到 0 到 1 之间的值。通过重新缩放数据，可以确认神经网络、优化算法以及具有距离度量（如 k-最近邻）的算法的适用性。

## 3. Binarizing Data

如果使用二进制阈值，可以更改数据，使高于阈值的值变为 1，而等于或低于阈值的值变为 0。对于此任务，你使用 `Binarized` 类。![](rsrc11G.jpg)![](rsrc11H.jpg)如你所见，Python 代码将 0 及以下的所有值标记为 0，其余值标记为 1。

## 4. Mean Removal

这是从每个属性中移除均值以将其中心化到零的过程。

## 5. One Hot Encoding

当你处理少量且分散的数值时，在进行 One Hot Encoding 之前可能需要先存储它们。对于 k 个不同的值，你可以将特征更改为一个 k 维向量，其中只有一个值为 1，其余值为 0。![](rsrc11J.jpg)
