Hybrid approaches (HAs) are considered innovative solution and essential mechanism that can tackle task deployed with heterogeneous sources. Today, large-scale datasets (LSDB) are experiencing voluminous from every possible domain like information communication (ICT), electronic health records (EHRs), cloud computing, social media, chain management, with local area network (LAN), wide-area network (WAN), wireless, sensors, mobile and cloud technologies, etc. Big data is defined as voluminous and complex unstructured, semi-structured that traditional software applications are inadequate to deal with. However, one of the main challenges in big data is the inherent difficulty to coherently manage incompatible and inconsistent data from heterogeneous sources (DHS). Traditional approaches integrate well comparatively for small data but fail when they are applied to unstructured, semi-structured and massive datasets. The efficient logical cognition of existing approaches preserve the interoperability. The HAs with logical functions including sufficient sensitivity can easily handle data integration (DI) process and with effective algorithm address quality (DQ), inconsistency, etc.
