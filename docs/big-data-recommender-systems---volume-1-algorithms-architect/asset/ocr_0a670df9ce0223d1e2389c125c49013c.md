# Model-specific attributes

Researches [12], [29] and [35] show that generic attributes are not enough to detect attack profiles, particularly when profiles are small with small number of filter items. We know attacks with their properties as target item $i_t$, selected items $I_s$ and filter items $I_f$. Model-specific attributes are able to detect particular attack method properties.

A proposed method detects the profile partitions that are the most similar to target. This method splits each profile $u$ into three sets. Items that are target in $P_{u,T}$ set, items that can be filter items in $P_{u,F}$ set and untrated items in $P_{u,\emptyset}$ set. In method, first the profile should be separated into the two parts: a target item, and other rated items. An Average attack changes each filter rating to make them close to the rating average. So, an Average attack generates a very similar profile to the average ratings for each item but not for the target item.
