```
$P(V, h) = \frac{\exp(-E(V,h))}{\sum_{V',h'} \exp(-E(V',h'))}} \quad (6.22)$
```

with the energy term $E(V,h)$ given as

```
$E(V,h) = -\sum_{i=1}^m \sum_{j=1}^F \sum_{k=1}^K w_{ij}^k h_j v_i^k - \sum_{i=1}^m \log Z_i - \sum_{j=1}^F \sum_{k=1}^K v_i^k b_j^k - \sum_{j=1}^F h_j b_j \quad (6.23)$
```

Where $w_{ij}^k$ is the weight between the rating $k$ of item $i$ and the hidden unit $j$, and $b_j^k$ is the corresponding bias. $Z_i = \sum_{k=1}^K \exp(b_j^k + h_j w_{ij}^k)$ is the normalization factor that ensures $\sum_{k=1}^K p(v_i^k|h) = 1$. With the joint distribution, we can derive the conditional distributions as

```
$p(v_i^1|h) = \frac{\exp(b_i^1 + \sum_{j=1}^F h_j w_{ij}^1)}{\sum_{k=1}^K \exp(b_i^k + \sum_{j=1}^F h_j w_{ij}^k)} \quad p(h|V) = \sigma(b_j + \sum_{i=1}^m \sum_{k=1}^K w_{ij}^k v_i^k) \quad (6.24)$
```

The goal of RBM-CF is to learn the weights and bias by maximizing the likelihood $\sum_n p(V^{(n)})$, where $V^{(n)}$ are the ratings of user $n$. After the model is trained, $p(v_i^k|h)$ can be used for rating prediction. RBM-CF [30] proposed UI-RBM-CF, which combines the user-based and item-based RBM-CF in a unified framework. We can easily design an item-based RBM-CF if we clamp an item's ratings on the visible layer. # 6.3.2 Autoencoder for recommender systems

AE is another widely used DL model for recommendation. AE is a neural network trained to learn latent representation by reconstructing its input. In fact, one hidden layer AE without nonlinear activation function is similar to PCA, which is one of the reason AE can be used for recommendation. AutoRec [10] applies AE for rating prediction. AutoRec takes user personal vectors $r^{(u)}$ or item partial vectors $r^{(i)}$ as input and reconstruct them at output layer. Based on the input, it has two variants, i.e., Item-based AutoRec (I-AutoRec) and User-based AutoRec. Figure 6.6(c) gives an illustration of I-AutoRec.
