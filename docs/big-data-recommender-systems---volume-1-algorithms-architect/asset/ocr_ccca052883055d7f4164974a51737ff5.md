+   **Music recommendation and label propagation on song graph**nMusic recommendation will construct the graph immediately after obtaining the music similarity [29], then it will be possible to treat it as a label propagation from labeled data (i.e., items with ratings) to unlabeled data.

**Definition 7.1. (Song graph):** A graph is an undirected weighted graph $G=(V,E)$, where

+   - $V$ is the node set ($L$ is the song set, which means that each song is represented as a node on the graph $G$);
- $E$ is the edge set. Associated with each edge $e_{pq} \in E$ is the similarity $w_{pq}$, which is nonnegative and satisfies $w_{pq}=w_{qp}$.

The label propagation [22] is a diffusive process of the labeled information [30,31]. The Green's function of the Laplace operator is used by music recommendation to recommend music [32].
