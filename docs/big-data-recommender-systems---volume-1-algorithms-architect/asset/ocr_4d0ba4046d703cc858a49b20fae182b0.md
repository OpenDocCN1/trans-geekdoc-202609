# 6.3 Deep learning for recommender systems

DL has demonstrated a great capability in learning useful representations of data in domains such as computer vision, natural language processing and speech recognition. The impressive feature-learning ability of DL has attracted the attention of researchers in recommender system community. Recently, DL models as AutoRec[10], N [11] and visual-content recommendation [29] have shown significant improvement over traditional recommender systems. In this section, we will briefly introduce recommender systems based on DL algorithms, which includes restricted Boltzmann machine, AE, multilayer perceptron and long short-term memory (LSTM).

# 6.3.1 Restricted Boltzmann machine-based collaborative filtering

RBM-CF [9] is probably the first recommendation model built atop DL. An illustration of RBM-CF is shown in Figure 6.6(a). It is composed of two layers, input layer $V$ and hidden layer $h$. The input/visible layer $V \in {0,1\}^{K\times m}$ encodes the ratings of a user to items, where $m$ is the total number of items and $K$ is the rating range, i.e., the rating is from 1 to $K$.
