Intra-profile attributes
Int-profile attributes use profile' statistics unlike a single profile attribute. If an
attack occurs in a system, there would be many attacks that attack the
same item. To understand this, we use Target Focus Model (TMF) attribute. TMF attribute
the partition weight which is assigned to profile on items that are shared to other attack\partitions. So, TMF tries to find suspicious profiles which are probability the
fake items. To show TMF in formal form, we use $q_{i,m}$ to show the overall times
that item $i$ contains target $P_{u,t}$ which is used to partition $m$. TMF is calculated by
relation (11.13):

```
$TargetFocus(u,i,m) = \frac{q_{j,m}}{\sum_j q_{j,m}} \quad$ (11.13)
```
