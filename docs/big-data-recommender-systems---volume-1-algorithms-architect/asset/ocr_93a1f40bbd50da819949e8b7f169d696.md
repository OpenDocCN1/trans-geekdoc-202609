# 3.1 Introduction

A recommender or a recommendation system classifies the subclass of information filtering system, which predicts the rating or preference of a user that he/she would give an item. Indeed, recommendation systems are critical in today's big data world, and many recommendation algorithms are available [6,7]. System has gained popularity in recent years and used in many areas, such as movies, news and social tags. Recommender systems usually produce a list of recommendations in two ways; collaborative [8,9] and content-based filtering [7,10]. CF is based on a model of prior user behavior, which can be constructed from sole user's behavior or from the behavior of other users who have similar behaviors, while content-based filtering constructs a recommendation on user's behavior such as by using historical browsing information. Apart from these, a hybrid approach can be used by combining two. The main advantage of the collaborative approach is that it does not rely on machine-analyzable content and can recommend complex systems, such as movies. The collaborative approach assumes that users who agree in the past will agree in future as well, i.e., the users who like the similar kind of products/items in the past will like in future. One of the examples of CF is item-to-item CF used by Amazon.com. Other examples include social websites such as Facebook, Myspace and LinkedIn. CF usually has three problems with such cold, scalability and sparsity. Content-based filtering is based on the description of an item and user's preferences. Content-based system uses keywords to describe the item and building user profiles to identify types of items that user may like. To abstract the features of the item, an item presentation algorithm is applied, as vector space representation. These systems are a good alternative for search engines in contrast, as they allow users to discover items, which may not be found with search algorithms. Such systems use search engines indexing.
