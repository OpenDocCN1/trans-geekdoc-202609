We will introduce a set of features to detect some attacks that use supervised learning algorithms. We use features that are introduced in [17–19] to know the effect of these features in detecting attacks. In this approach, we will produce data by combining original profiles with attacked profiles (profiles that are under the attack discussed above). All profiles are tagged as attacked user profile or as an original user profile. By using this training data set and features, a binary classifier can be generated and there is no need to use any classified profiles to detect an attack. These features are divided into two types: generic and model-specific. Generic features use statistics to understand the attributes that make attackers’ profile different from original user profiles. Model-specific features try to understand the attributes of each attack model [20]. You can see the summary of attack model in Table 11.1.
