# Table 9.3 Notations of model parameters

| Variable | Interpretation |
| --- | --- |
| $K$ | The number of latent topics |
| $z_{u,i}$ | The topic assigned to spatial item $v_{u,i}$ |
| $	heta^0$ | The background topic vector |
| $	heta^{native}$ | The topic vector representing the intrinsic interests of user $u$ |
| $	heta_{l,t}$ | The topic of $l$ on time $t$, representing the native preferences at $l$ on time $t$ |
| $	heta^{tourist}$ | The topic of $l$ on time $t$, representing the tourist preferences at $l$ on time $t$ |
| $\phi^l$ | The word vector of the background |
| $\psi^0$ | The spatial item vector of the background |
| $\phi^{topic}$ | Content word vector of topic $z$ |
| $\psi^{topic}$ | Spatial item vector of topic $z$ |

out-of-town. Technically, we introduce two parameters: native preferences $	heta^{native}$ and tourist preferences $	heta^{tourist}$. Given a location $l$, the native preferences $	heta^{native}$ represent the preferences of people living at $l$. In contrast, the tourist preferences $	heta^{tourist}$ represent the preferences of people traveling to location $l$. Note that, distinguishing native preferences from tourist preferences is one of the fundamental differences between our models ST-SAGE and the LCA-LDA [16] which also exploits local activity records at the target location.
