# 11.4.1 Association rule mining

Generally, association rule mining is used to analyze the market basket. The goal is to know customers' manner and find products that may buy together. The relations between items are discovered by association rules using patterns of transactions. In [21], association rules are used to personalize web pages. We use association rule mining for collaborative filtering. We use the Apri algorithm by assuming each user profile as a transaction. Also, in [22] association rules are used to create groups that contain similar items.
