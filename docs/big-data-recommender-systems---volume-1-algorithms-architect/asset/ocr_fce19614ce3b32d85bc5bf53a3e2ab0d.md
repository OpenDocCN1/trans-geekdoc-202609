# 8.10 Conclusion and future work

In the current research, waste-segregation-management system is thoroughly studied and developed an automated proof of concept model by leveraging the application of deep learning techniques. Specifically, segregation of plastic and nonplastic problem is considered. Deep learning techniques provide facility to pass raw image samples such as the model and obtain an optimal feature representation. This representation helps segment the plastic and nonplastic images. The hardware setup model demonstrates the segregation of plastic and nonplastic waste implemented using CNN. The performance of the CNN model is evaluated on various data sets. It performed well in almost all the data sets. The prototype designed has given a better idea of how a waste-segregating machine can be designed. This system can be used for commercial purpose by any manufacturing company. This model, when used for commercial purpose, can be more advantageous, as it can reduce humans infected by wastes and reducing the efforts of them.

Due to computational time and other requirements, we were unable to try experiments with the more complex architecture. Thus, even more images can be used to train and even more epochs be done to increase the accuracy, thus reducing the error of prediction. The machine can be designed in even more user friendly manner so that this product can be commercialized in future. Additionally, CNN methodology can be integrated with other machine learning techniques such as SVM so that it can achieve a greater efficiency [17]. Additionally, the recent trend in artificial intelligence is switching towards CapsNet because it has the capability to use 3D imaging and can achieve good performance with less data set. Thus, the CapsNet outperforms CNN in image-classification tasks [27].
