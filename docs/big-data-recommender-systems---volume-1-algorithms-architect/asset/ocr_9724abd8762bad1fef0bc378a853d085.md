# 9.3.3 Model inference

The goal of model inference is to learn parameters that maximize the marginal likelihood of the observed random variables w, v, t and s, and the marginalization is performed with respect to the latent variable z. However, the latent variable z is difficult to maximize directly. Therefore, the Gibbs algorithm [34], a mixture of EM and a Monte Carlo sampler, is adopted to maximize the data likelihood in (9.7), represents the set of all the parameters. There are two steps in each iteration of the Gibbs algorithm: In the E-step, we sample latent topic assignments for the activity records using the Gibbs sampling and fixing all other parameters. In the M-step, we optimize the model parameters and fixing topic assignments using the gradient descent algorithm. The two steps are iterated until

```
$$\alpha_{u,s,j,z} = \frac{\exp(\theta_z^0 + u_{j,z}^{user}) + (1-s) \times s \times x_{j,z}^{native})}{\sum_{z'} \exp(\theta_{z'}^0 + u_{j,z'}^{user}) + (1-s) \times s \times x_{j,z'}^{native}})$$\n\n$\beta_{z,w} = \frac{\exp(\\phi_z^0 + \phi_{z,w}^{topic})}{\sum_{w'} \exp(\\phi_{z'}^0 + \phi_{z',w'}^{topic})} \qquad$ (9.6)
```

```
$P(z, \mathbf{w}, \mathbf{v} | \odot, \mathbf{s}, \mathbf{u}, \mathbf{l}, \mathbf{t}) = P(z | \mathbf{u}^{native}, \mathbf{t}^{topic}) \times P(\mathbf{v} | z, \mathbf{u}^{user}, \mathbf{t}^{topic})$$\n\n$\prod_{u=1}^{|D_u|} \prod_{i=1}^{|D_i|} \alpha_{u,s,j,z} u_{s,j,j,j,u,z} \times \prod_{u=1}^{|D_u|} \prod_{n=1}^{|W_{u,n}|} \beta_{z,w_{u,n}} w_{u,n,z} \times \prod_{u=1}^{|D_u|} \prod_{z} \gamma_{z_{u,ij}}$$\n\quad (9.7)
```

More specifically, we draw latent topic $z$ for all activity records in the E-step. When sampling $z_{u,i}$ as expressed in (9.8), we assume all other variables are fixed, $z_{-u,i}$ represents the topic assignments for all user activities except the $ith$ activity for user $u$.

```
$P(z_{u,i} | z_{-u,i}, \mathbf{w}, \mathbf{v}, \mathbf{s}, \mathbf{u}, \mathbf{l}, \mathbf{t}, \odot) = \alpha_{u,s,j,j,u,z} \times \prod_{n=1}^{|W_{u,n}|} \beta_{z,w_{u,n}} w_{u,n,z} \times \gamma_{z_{u,ij}}$ \qquad$ (9.8)
```

In the M-step, we optimize the parameters $\odot$ to maximize the log likelihood of the objective function with all topic assignments fixed.
