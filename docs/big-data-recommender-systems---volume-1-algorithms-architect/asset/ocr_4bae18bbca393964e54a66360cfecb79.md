+   3. Functional dependencies corresponding relation variables: Detecting inconsistencies in distributed data is recognised as one of the most important issues for DQ [25]. There a given data D and a set Σ of dependencies as DQ rules, to identify tuples in D that violate some rules in Σ. When D is generalised database, there have been effective Structured Query Language (SQL) based techniques for finding violations. It is, however, far more challenging when data in D are distributed, in which inconsistency detection often necessarily exchanging data from one site to another. A central issue for DQ inconsistency detection, to identify errors in the data. More specifically, given a data D and a set Σ of dependencies serving as DQ rules, the detection problem is to find all the violations of Σ in D, i.e. all the tuples in D that violate some rules in Σ. For a DQ tool to be effective in practice, it is a must to support automated and efficient inconsistency identification approaches.
