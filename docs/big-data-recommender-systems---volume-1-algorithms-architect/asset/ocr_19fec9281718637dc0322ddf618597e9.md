# 14.6.5 Proposed architecture for URL analysis

+   1. Recurrent layers
nThe high-level architecture of the proposed architecture for URL analysis is shown in Figure 14.8. We have used various recurrent layers. For better performance, we have to tune the hyper-parameters. Based on the result of hyperparameter tuning, 256 number of blocks/units is set. The LSTM cell uses hyperbolic tangent as input. The output activation value in the range [~1, 1]. The gates in the LSTM use sigmoid which has values in the range [0, 1].

+   2. Convolution layers
CNN architectures capture the spatial dependencies. So in order to capture the spatial correlational between characters, the CNN architecture includes convolutional layers followed by max-pooling layers. The architecture of CNN we propose a convolutional 1D layer containing 256 filters with filter length 4. The output of the convolution layer is passed to the max-pooling layer. The max-pooling layer contains a pool length of 4. The max-pooling 1D output is flattened to a vector and passed to a fully connected layer. Now, in order to learn the sequential information passed from the max-pooling layer, we introduce the LSTM layer containing 50 memory blocks.
