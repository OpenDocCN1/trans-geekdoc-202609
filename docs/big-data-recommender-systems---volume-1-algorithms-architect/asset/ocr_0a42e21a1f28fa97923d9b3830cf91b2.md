# 6.2.4 Collaborative topic models

Although topic models as PLSA and LDA can be formulated as hybrid recommendation models, this technique has not been widely acknowledged as the best way to integrate content with CF. In fact, the most popular way of creating a hybrid recommendation is to infuse the generative framework of topic model PMF. The very first model that leveraged this technique is CTR [4]. Figure 6.5 shows the graphical structure of CTR where the bottom part is the PMF and the top part is the LDA topic model. Similar to PMF, CTR assumes that the observed rating $r_{ij}$ is generated from the latent attributes of users and items, but unlike PMF, CTR assumes that a user $i$ selects (or rates) an item $j$ mostly based on its contents $	heta_i$, and the user might diverge from this decision by an offset distribution $\epsilon_{ij}$, which is drawn from the PMF part (i.e., CF part) of the CTR model. In this way, the model seamlessly integrates both the content information of items and the rating information of users to create a hybrid recommendation framework.
