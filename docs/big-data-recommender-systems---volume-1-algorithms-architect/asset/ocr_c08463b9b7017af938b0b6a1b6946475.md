+   **Recommendation mechanism**
The Recommendation mechanism merges the four basic angles to order the candidate texts. Every basic angle is a correspondence of a rank of texts. For a compound joined by k basic angles and the k basic angels to k rank, a content has k rank array (RA) that comprise k parts relating to the k areas of the content in the k positions, where $RA = (r_1, r_2, ..., r_k)$ one RA can be changed into one value ($Integratedrank, Ir$) by multiplying a coefficient vector $CV = (c_1, c_2, ..., c_k)$ where $c_1 + c_2 + ... + c_k = 1$ and $c_1, c_2, ..., c_k$ are within $[0, 1]$.

```
$Ir = \overrightarrow{CV} \times \overrightarrow{RA} = \sum_{i=1}^{k} c_i * r_i \quad (7.1)$
```

Then we are able to read rank text based on the integrated ranks. Note that the integrated rank itself might not be as an integer. The default value of $CV$ is $(1/k, 1/k, ..., 1/k)$.
