# 13.5.2 Experimental results

We will now discuss the performance of the proposed methodology with respect to matching accuracy and time performance. To assess matching accuracy, we consider precision and recall defined as the information retrieval community. Precision is defined as the proportion of the number of relevant records retrieved, Recall refers to the total number of relevant records retrieved divided by the total number of existing relevant records. With respect to time performance, we include a comparison with the sequential counterpart of our algorithm implemented as outlined above.
