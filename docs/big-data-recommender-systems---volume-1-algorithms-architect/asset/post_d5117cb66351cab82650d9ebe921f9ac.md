Innocent client does not know about the way that the application which will download is protected or pernicious. The thought is to manufacture a central server that will accumulate the clients' information and carry out the dynamic investigation of an Android application to locate the risky examples and will group it as malicious or benign. This assignment will require huge processing power. Here, the importance of big data comes into picture.

Already existed and suggested frameworks have been tremendously helpful, and huge information is the main impetus behind recommendation frameworks. Our planned mechanism additionally plans to gather a lot of client information; for example, it adds up to a number of downloads, clients' audits, consents required by an application, and designer data to give relevant and powerful proposals. There is a need of dynamic malware investigation system which uses the innovations of graphical user interface (GUI)-based testing, big data examination, and machine learning how to identify malignant Android applications.
