# 7.1.1 Content-based recommendations

Content-based recommendation, the recommended items are based on the previously preferred items by the users [1]. In creating recommended applications, content is the foundation for recommender applications. These recommendations are totally based on item descriptions rather than the similarity of other users. Machine-learning algorithms are being used to induce a model of user preferences based on feature factors. There are various accessible contents, such as articles, photos, video, blogs, wikis, classification terms, polls and lists [3].
