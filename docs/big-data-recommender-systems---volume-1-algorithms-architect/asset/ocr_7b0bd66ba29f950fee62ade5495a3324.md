A user activity indicates that the user $u$ visits the spatial item $v$, located at $l_v$ and described as $W_v$, at time $t$, in the role of $s$. If $s=0$, the user is recognized as a local and the activity occurs in $u$'s hometown. If $s=1$, the user plays the role of tourist when visiting v.

**Definition 9.5. (User profile)** For each user $u$, we create a user profile $D_u$, which is a set of user activities associated with $u$.

Given a dataset $D$ using the union of a collection of user profiles, we aim to provide spatial item recommendation for both hometown and out-of-town users. We formulate our problem as follows, following our previous work [28,29].

**Problem 9.1. (Spatial item recommendation)** Given a user activity dataset, a target user $u$ with his/her current location $l$ and the querying time $t$ (i.e., the query is $q=(u, l, t)$), our goal is to recommend-$k$ spatial items that the target user $u$ would be most interested in. Given a distance $d$, the problem becomes an **out-of-town recommendation** if the distance between $u$'s current location and his/her home location $|l-l_h|)$ is greater than $d$. Otherwise, the problem is a hometown recommendation.

We set $d=100$ km in following related studies [7,30–32]. A distance around 100 km is the typical radius of human “reach” as it usually takes 1–2 h to drive such a distance.

# 9.3.2 Model description

In this chapter, we propose an ST-STAGE to model users visiting activities in LBSNs. The graphical representation of ST-STAGE is demonstrated in Figure 9.1. The notations of our model are summarized in Table 9.3. The shaded circles in Figure 9.1 model the observed random variables. More specifically, users’ activity profiles. Following existing models [16,20], the topic index of each user activity is modeled with a latent random variable, denoted as $z$.

**User interest modeling.** Intuitively, a user chooses a spatial item at a given location and a specific time by matching his/her personal interests with the content of that item. Inspired by the early work of user interest modeling [16,20,33], ST-STAGE also adopts latent topics to characterize users’ interests. We infer an individual user’s interest vector over a set of topics according to his/visited spatial items and their associated contents, denoted as $	heta^{user}$. As the content of spatial items can be the medium through which user preferences from their hometown can be transferred to out-of-town regions, our proposed model is able to alleviate the locality problem for out-of-town recommendation. Moreover, beyond $	heta^{user}$, we also introduce a background vector over topics $	heta^b$. This background vector is able to capture common topics among users to make the user interests encoded in $	heta^{user}$ more descriptive.
