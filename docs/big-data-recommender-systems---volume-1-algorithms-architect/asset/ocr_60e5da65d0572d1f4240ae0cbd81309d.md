# 11.4.5 Probabilistic latent semantic analysis

Probabilistic latent semantic analysis (PLSA) models [26] are probabilistic methods for hidden semantic associations. In [27–29], PLSA is used to personalize web pages. We combine this method to collaborative filtering [25].

For $n$ users, $U = \{u_1, u_2, ..., u_n\}$, and $m$ items, $I = \{i_1, i_2, ..., i_m\}$ and PLSA amplifies the unbiased variable $Z$ with the observed rating data, where $Z = \{z_1, z_2, ..., z_i\}$. We define the relation for: a target user $u$ and a target item $i$:

# 11.4.6.1 User-based collaborative filtering

The standard collaborative filtering algorithm uses the similarity between users [24]. User-based collaborative filtering algorithm chooses the $k$ most similar users to the target user. Extensively kNN is used and it is very accurate. By using the Pearson's correlation coefficient, we can calculate the similarity between the target user $u$ and a neighbor $v$, in relation to (11.5):

```
$sim_{u,v} = \frac{\sum_{i \in I}(r_{u,i} - \bar{r}_u) \cdot (r_{v,i} - \bar{r}_v)}{\sqrt{\sum_{i \in I}(r_{u,i} - \bar{r}_u)^2 \cdot \sum_{i \in I}(r_{v,i} - \bar{r}_v)^2}}} \quad (11.5)$
```
