Essentially, CDAE follows the same generative principle as the CTR that was discussed in Algorithm 2. One key difference is that, instead of LDA, the CDAE uses a DAE to embed the content information of items in a latent space (i.e., lines 11–12). One can observe that the content of the latent vector $v_i$ is drawn from $g_{l/2}$, which is the middle layer of SDAE. The objective of CDAE is defined as follows:

```
$$\arg \min_{W_{bi}} \|X_0 - X_iW_{bi}\|_F^2 + \lambda \sum_j \frac{\lambda_w}{j} \|W_{ij}\|^2$
```

where $\lambda$ is the regularization parameter and $\|cdot\|_F$ is the Frobenius norm. Similar to CTR, the posterior $P(U,V,g|i)$ is derived using a MAP estimate. The likelihood of CDAE is defined as follows:

```
$$\mathcal{L}(U,V,W,t_i) = -\frac{\lambda_u}{2} \sum_i \|u_i\|^2 - \frac{\lambda_w}{2} \sum_j (\|W_{ij}\|^2 + \|b_j\|^2) \n -\frac{\lambda_v}{2} \sum_j \|v_j - g_{l/2,j}^*\|^2 - \frac{\lambda_s}{2} \sum_{lj} \|g_{lj}^* - X_{0j}^*\|^2 \n -\frac{\lambda_{\sigma}}{2} \sum_{l} \sum_j \|\sigma(g_{l-1,j}W_i + b_l) - g_{lj}^*\|^2 \n -\sum_{ij} C_{ij}^2(R_{ij} - u_i^T v_j)^2 \n \quad (6.33)$
```

To obtain parameters $u_i$ and $v_j$, coordinate ascent is used. Given $U$ and $V$, the weights $W_i$ and biases $b_j$ can be learned using back propagation. This process is repeated iteratively until a local optimum for $\mathcal{L}$ is reached.

# 6.4.2 Collaborative variational autoencoder

Although CDAE is a powerful DL model that delivers excellent performance, it is not without its faults. The denoising component of the model works by corrupting the input data, which is extremely data specific and requires specialized corruption schemes that are designed for the type of data. In other words, a corruption scheme that is used for image data cannot be applied over text data and vice versa. This in turn degrades the quality of the learned representations.
