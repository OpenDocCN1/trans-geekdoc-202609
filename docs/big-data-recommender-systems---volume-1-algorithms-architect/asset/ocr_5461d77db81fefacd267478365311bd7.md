# 7.1.4 Demographic recommendations

Demographical data such as age, gender, social class, education, location can be used and achieved both explicitly and implicitly based on the demographic data which a user profile can be made of. A demographic profile can recommend identical items. As an example, teenagers obviously rather different products than the olds; rich class of society may differ type and items quality and definitely are willing to pay more on mentioned features. So the demographic recommendation takes into account personal characteristic of users and makes recommendations. Demographic approach does not apply user-item ratings before rating any item; new users are also to take advantage of receiving recommendations. The technique is domain independent to an independence of item’s knowledge and its features. To gather the demographic data, this approach faces the privacy issues which can be grouped in disadvantages of the technique. For highly personalized recommendations, demographic classification is a little too basic [10].

# 7.1.5 Hybrid recommendations

Very simple recommendation techniques are used by current RSs, such as content-based, collaborative, demographic, utility-based and knowledge-based. Using these techniques alone will lead to both advantages and disadvantages. The fact is a total inspiration to more research in hybrid RS which has merged techniques to enhance performances. Numerous hybrids have been investigated, i.e., the hybridization techniques that have been named as weighted, switching, feature combination, feature augmentation, meta-level, cascading and mixed. They are described as follows [11]:

+   - Weighted: Applying collaborative and content-based system individually and afterward until their predictions.
- Switching: System applies a specific switching criterion to swap between two recommendation systems that are working on the similar object.
- Feature combination: Features related to dissimilar recommendation system’s data sources are gathered into a single recommendation algorithm.
- Feature augmentation: We can sometimes utilize output of a system as an input feature of another; for instance, we can use a produced model to form features by another model.
- Meta-level: Here a feature can be used as input of another, like model learned by one recommendation.
- Cascading: In this category, one recommendation system improves the outcome presented by another.
- Mixed: Integrating two or more techniques simultaneously; for instance, content based and CF.
