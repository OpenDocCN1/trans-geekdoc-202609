### 8.6.1 TensorFlow

It is an open-source software library which is used computing complex mathematical operations especially numerical methods. Hence, this is also used as a machine-learning tool especially for CNN and deep learning. TensorFlow uses dataflow graphs for computing. Dataflow graphs are made of nodes and edges. All the data are stored in the edges which are multidimensional arrays. The nodes are used to build computational graphs. Three types of nodes, named, constant, variable and placeholder can used to build a dataflow graph:

**Constant:** Constants are nodes which hold a value which cannot be changed throughout the operation.

**Placeholder:** In order to place a value with another value once an operation is done with former value, a placeholder is needed.

**Variable:** To make a model trainable, the value of the weights would be changed every cycle. Hence, a variable node is needed to do a training operation.
