
## Efficient and socio-recommendation approaches

A RF is called a Gibbs RF if it satisfies $\mathbb{P}(X = x) = (1/Z)e^{-U(x)/T}$, where $Z := \sum_{x \in \mathcal{X}} e^{-U(x)/T}$ is the partition function and $T$ is called the temperature of the system. $U(x)$ is called the potential function and represents an "energy" metric of configuration $x$. However, a useful class of potential functions is one in which $U(x)$ is decomposed into a sum of cliques (maximally connected subgraph), $U(x) = \sum_{c \in \mathcal{C}} \Phi_c(x)$, where $\mathcal{C}$ is the set of cliques of nodes formed in the topology. Each clique potential depends only on the states of the cliques formed by the sites of the MRF. The clique-based representation of $U(x)$ is very useful in various applications of MRFs, e.g., in the modeling of malware propagation in computer/communication networks through direct neighbor interactions [25], process assembling considerably the spreading of rumors and marketing trends in an SN.

### 4.3.2.1 Pairwise recommendation MRFs

One of the approaches employing the concept of MRF for recommendations is the one presented in [21], where belief propagation (BP) approach is employed for computing the marginal probability distributions of a pairwise-MRF (PMRF) modeling the similarity associations between various items. Assuming $M$ users and $N$ items, the objective is to predict the numerical value (typically in the discrete range of 1-5) of the collection of variables $S_{ij} = \{r_{ij} : i \in L_j\}$, where $r_{ij}$ is the recommendation score of user $j$ for item $i$, $i$ is the set of items and $L_j$ denotes the set of rated items by user $z$. The employed PMRF consists of a hidden (item rated to be predicted) and an observed layer of sites (Figure 4.4). Similarity sites correspond to known local evidence, e.g., average rating from other users, using similarity relations for the user for whose rating is estimated: $y_i = \hat{y}_i + (\sum_{j \in \mathcal{K}_i} S_{zi}(r_{zi} - \hat{y}_j))/\sum_{j \in \mathcal{K}_i} S_{zi}$, where $\hat{y}_i$ denotes a set of $K_i$ users most similar to $z$ among users who rated item $i$, Figure 4.4. Similarity can be computed with any of the similarity mentioned before. Two items are connected if their similarity is above a predefined threshold, or if at least one is among the $K$ most similar items of the other, or both. $K$ is a fixed parameter. A local evidence function $\phi(r_{zi})$ represents how one item is rated according to the local evidence $y_i$, and a compatibility function between two connected items $i_a, i_b$ is defined as $\psi_{rab}(r_{za}, r_{zb}) = (1/Z_{ab})\exp(-(r_{za}-r_{zb})^2/\sigma_{ab}^2)$, where $\sigma_{ab}$ is adjusted by item similarity, penalizing the incompatible rating from connected items if they deviate from each other. The authors employ a probabilistic message passing (in the form of BP) algorithm over the defined PMRF and the observed beliefs (expectations of the marginal probability distributions) corresponding to the desired ratings are exact if the PMF has no loops, otherwise they constitute approximations of the desired ratings (Figure 4.4). The approach was evaluated in [21] on the 100K MovieLens dataset using the mean absolute error and root mean square error metrics, demonstrating comparative performance with the state of the art at the time and linear complexity per user ever. Further, it can update the recommendations for each user instantaneously, using the most recent rating, without needing to solve the marginal distributions for all users. The results indicate that such approaches can scale well in bigdata environments and efficient implementations.

### 4.3.2.2 Preference networks

The work in [22] suggests preference networks (PNs), a probabilistic model for combining content-based with CF into a hybrid recommendation approach. The goal of PNs is again to estimating the user to item ratings of the utility (preference) matrix for only a limited set of items for each user (top-N ranking), as a user is typically interested in a moderate number of items.

In PNs, each vertex of the undirected directed graph $G(V, E)$ corresponds to a rating $r_{ui}$ of user $u$ for item $i$ and each edge captures a relation between two ratings, either of item-item or user-item. Specifically, there is an edge between two ratings by the same user, and an edge between two ratings on the same item (Figure 4.5). The resulting network is typically very connected. The PN is a conditional MRF that defines a distribution over the graph, $P(X|\mathbf{o}) = (1/Z(\mathbf{o}))\Psi(X, \mathbf{o}) = \prod_{u \in V} \psi_{u}(X, \mathbf{o}) = \prod_{(i,j) \in E} \psi_{ij}(r_{ui}, r_{uj}, \mathbf{o})$

## Efficient and socio-aware approaches

In the following, we briefly outline parameter selection and preference prediction. To optimize the PNs, due to the density of the obtained network, standard log-likelihood methods are not applicable, due to complexity issues. The authors resort to simple pseudo-likelihood method, where the log-likelihood is replaced by regularized sum of local likelihoods. Maximizing this function allows efficient estimation of parameters by stochastic gradient ascent, and 2-3 passes of all data is sufficient. Once the model has been estimated, ratings in addition to the known, can be added.

It may appear non-obvious that a prediction may depend on unknown ratings (other predictions to be made), but this is the advantage of the Markov networks. For instance, consider the recommendation of a relatively new item to a set of promising users. $\hat{r}_{ui} = \arg\max_{r} P(r|N(u, i))$. Based on the evaluations provided in [22], PNs have competitive performance against both the well-known item-based and user-based CF methods in the rating prediction task, and against the user-based method in the top-N recommendation task at the time of the study.

### 4.3 Ordinal random fields

An interesting observation for RSs, in general, is that users are not good at making consistent quantitative judgment, namely, they are not consistent with the same numerical rating for the same item at different times, ordinal preferences, i.e., relations over items, such as item-best, second best, among a set of items, are considered to be more consistent than liked users. Ordinal matrix factorization (OMF) [26] has been suggested as an effective method in the past.

The work in [23] develops a unified model, denoted as ordinal RFs (ORF) combining elements OMF and previous MRF-based techniques. ORF model can employ any OMF representation and focuses on the local structure of the system, namely, on the second order interactions between similar users or items, also using neighborhood-based collaborative filtering. At the same time, it can capture the global structure as well, i.e., the weaker interactions among all users and items.
