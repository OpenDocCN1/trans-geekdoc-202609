## 14.5 Intrusion detection (ID) using multidimensional zoom (M-ZOOM) framework

The fundamental goal of an M-ZOOM framework is, given a higher order tensor than how we can detect the blocks present in the tensor. This problem formulation demands the data to be arranged in the form of a tensor. Each feature represents each dimension of the tensor. The following example helps to understand the idea behind M-ZOOM framework.

The data tabled in Table 14.11 refers to the grade of a student. The fundamental question here is how do we convert this into a tensor? Let us depict Table 14.11 as R = Grade (student, subject, marks, count). Each tuple (st, s, m, c) represents the student “st” has obtained “c” times marks in subject “s”. Here when comparing student Z1, Z2 as marks Z3 as Y. Z1, Z2 represent dimension attributes and Y represent measure. When comparing with original data, Z1, Z2, Z3 are the features from the original data and Y represents the count of times that (P, Marks, 30) have occurred seven times, then the Y value for that corresponding particular tuple has occurred seven times, then the Y value is 7. The next step is to define mass C = R, P2 = Computer science, Maths, The Mass of C given by MC is 7 + 5 = 12. Similarly $M_{C(P)} = Mass(C(R)) = 5$ and $M_{C(C'(P))} = 7$. Figure 14.6 represents the representation of data.

The aim of M-ZOOM framework is to find the “k” dense distinct subsets from R. The detailed algorithm and terminology definitions are provided in [23]. We make use of the methodology provided in [23] for the analysis.

### 14.5.1 Density measures

This work uses three density measures. Out of the two-density measures are an extension of classical density measures and are commonly used in sub-graphs [51,52].

**Definition 14.1.** (Arithmetic average mass [51]). The arithmetic average mass of a block B of a relation R is defined as $\rho_{ori}(B,R) = M_B/(S_B/N)$.

**Definition 14.2.** (Geometric average mass [32]). The geometric average mass of block B of a relation R is defined as $\rho_{geo}(B, R) = M_B/V_B^{(1/N)}$.

The density measure (Definition 14.3) is the negative log likelihood of MB. The fundamental assumption used is the value on each cell (in the tensor representation) of R follows a Poisson distribution. This has been found in fraud detection [53].

**Definition 14.3.** (Suspiciousness [53]). The suspiciousness of a block B of a relation R is defined as $\rho_{susp}(B, R) = M_B \log(M_B/M_R) + M_R V_B/V_R - M_R \log(V_B/V_R)$.

The notations are $M_B$ Mass of B, $M_R$ Mass of R, $V_B$ Volume of B, $V_R$ Volume of R, $N$ the number of dimension attributes in a relation, $S_B$ is the size of 'block B' and $\rho(B)$ is the density of block in R.
