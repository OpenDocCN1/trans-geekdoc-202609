In this example, there are four topics (i.e. distribution $\theta$) over color-coded codes and four movies, which are depicted as colors of the $\phi$ matrix. The following steps delineate the generative process of LDA.

- A user has interests over multiple topics with different proportions which follows a Dirichlet distribution $\theta$ with hyperparameter $\alpha$.
- From the topical interests $\theta$, he then picks a single topic $z$ (denoted by the color codes) using a multinomial distribution. In this example, the user picks the movie topic horror that is denoted by the orange coin.
- To watch a movie $v$, he consults a topic-movie matrix $\phi$, which indicates probability of $v$ belonging to a topic $z$ and picks a single movie that matches his topical interests using a multinomial distribution. In Figure 6.4, the user picks *Rings* which corresponds to the genre horror.

However, in reality we do not observe the specific topic $z$, which implies that both the user-topic proportion $\theta$ and the movie-topic proportion $\phi$ are not observed. The observed variables are the sets of $U = \{u_i\}_{i=1}^n$ and their item selections $N_u = \{v_{uj}\}_{j=1}^m$. Therefore, the central inference problem of LDA is to estimate $\theta$ and $\phi$ from the observed variables $v$ and $u$. The formal representation of LDA’s graphical model is shown in 6.4(b).

**Parameter inference:** The posterior of LDA is defined as follows:

```
$P(\theta, z|v, \alpha) = \frac{P(\theta, z|v, \alpha)}{P(v|\alpha)}$
```

By examining the graphical structure of the model, the likelihood for a single user $u$ can be expanded as follows:

```
$P(\theta, z, v|\alpha, \beta) = P(v|\beta, z)P(z|\theta)P(\theta|\alpha)$
```

The above expression is similar to the likelihood except for the marginalization integral $\theta$ and the summation over the topic space $[z]_i$. However, this normalizing factor is intractable to compute. This is because, in the graphical model of LDA 6.4(b) there is a coupling between $\theta$ and $\beta$. When taking the log of (6.11) it is not possible to separate parameters $\theta$ and $\beta$. To overcome this problem, LDA tries to approximate the parameters using Gibbs sampling or variational inference (VI). The former approximates the parameters by drawing MCMC samples from the posterior, while the latter achieves this objective by optimizing the evidence lower bound (ELBO) of the likelihood function. Here, we restrict our explanation to the VI technique. Readers interested in Gibbs sampling-based inference are refer to the tutorial on parameter estimation for text analysis [25].

The VI solves the problem of coupling by assuming that the distribution $\theta$ and $\beta$ depends only on their respective variational parameters $\gamma$ and $\phi$ [26, 27]. Under this assumption, the ELBO can be stated as follows:

```
$ln P(v|\alpha, \beta) = \mathcal{L}(\alpha, \beta) + KL(q(\theta, z|v)|P(\theta, z|v, \alpha, \beta))$ $ (6.12)
```

The objective of VI is to learn $\mathcal{L}(\alpha, \beta)$ as close as possible to $ln P(v|\alpha)$. In other words, the goal is to learn the parameters $\gamma$ and $\phi$ which minimizes the KL divergence between the variational distribution $q(\theta, z:|)$ and the true posterior. One of achieving this is to use iterative fixed-point method, which yields the following updates:

```
$\phi_{uk} \propto \beta_{kv} \exp[\log(\theta_k)|\gamma_k]$ (6.13)
```

```
$$\gamma_k = \alpha_k + \sum_{i=1}^U \phi_{ik}$ (6.14)
```

where the expectation is defined as follows:

**Algorithm 2**: Generative process of CTR

```
1 **for each user** $i \in I$ **do**
2   draw user latent $\theta_i \sim \text{Dirichlet}(\alpha)$
3 **end**
4 **for each item** $j \in J$ **do**
5   draw topic proportions $\theta_j \sim \text{Dirichlet}(\alpha)$
6   draw item latent offset $\epsilon_j \sim \mathcal{N}(0, \lambda_v^2)$
7   Set item latent vector $v_j = \theta_j + \epsilon_j$
8   **for each word** $n \in N$ **do**
9     draw topic assignment $z_{jn} \sim \text{Mult}(\theta_j)$
10    draw word $\phi_{jn} \sim \text{Mult}(\beta_{jn})$
11 **end**
12 **end**
13 **for each user-item pair** $(i, j)$ **do**
14   draw rating $r_{ij} \sim \mathcal{N}(u_i^T v_j, c_{ij}^{-1})$
15 **end**
```

**Parameter inference:** There are four latent parameters in this model, namely, $\theta$, $\phi, U$ and $V$. The authors adopt a MAP estimate to infer these parameters by maximizing the following likelihood:

> $\mathcal{L} = -\frac{\lambda_u}{2} \sum_{i=1}^N u_i^T u_i - \frac{\lambda_v}{2} \sum_{j=1}^J (v_j - \theta_j)^T(v_j - \theta_j) + \sum_{j=1}^J \sum_{n=1}^N \phi_{jn} (\log \theta_{jk} \beta_{k,jn} - \log \phi_{jn}) - \sum_{i,j=1}^N \frac{c_{ij}}{2}(r_{ij} - u_i^T v_j)^2 \quad (6.18)$

Coordinate ascent is used to learn parameters by iteratively optimizing the CF variables $U$ and $V$, and the item-topic properties $\theta$. The learning of $U$ and $V$ remains as that of PMF (Section 6.2.1). Given $U$ and $V$, the likelihood function for the topics is derived by applying Jensen's inequality as follows:

> $\mathcal{L} \geq \frac{\lambda_u}{2}(v_j - \theta_j)^T(v_j - \theta_j) + \sum_{n=1}^N \sum_{k=1}^K \phi_{jn} (\log \theta_{jk} \beta_{k,jn} - \log \phi_{jn}) \quad = \mathcal{L}(\theta_j, \phi_j) \quad (6.19)$

where $\phi_{jn}$ is the variational distribution $q(z_{jn}=k)$. $\mathcal{L}(\theta_j, \phi_j)$ gives the tight lower bound of $\mathcal{L}(\theta_j)$, and projection gradient [28] is used to obtain parameter $\theta$.
