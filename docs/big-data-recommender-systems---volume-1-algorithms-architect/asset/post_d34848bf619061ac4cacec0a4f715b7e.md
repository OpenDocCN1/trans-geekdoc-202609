## 11.3.3 Ratings strategy

The ratings strategy we adopt is tailored to the particular automated collaborative filtering (ACF) algorithm that we use. We use a user-based algorithm which is described in [12]. This algorithm is used to calculate predictions by taking into account the differences between ratings for different users and using a deviation from mean. $p_{aj}$ is the prediction and is calculated for a user “a” on an item “j” which is the neighbors’ ratings average as follows:

```
$p_{aj} = \bar{r}_a + \frac{\sum_{i=1}^{n} w(a,i)(r_{ij} - \bar{r}_a)}{\sum_{i=1}^{n} w(a,i)} \quad (11.1)$
```

where the average rating for user a is shown as $\bar{r}_a$ and $r_{ij}$ is the rating which is attached by neighbor i to j. The similarity $w(a,i)$ between the user a and neighbor i is typically computed using Pearson correlation [12].

Therefore, for successful product push and nuke attacks, it is essential to be sure that the magnitude of deviation is maximized or minimized. The portion of any neighbor is a function of:

- 1. item rating for a desirable prediction,
- 2. neighbor’s rating tool and
- 3. neighbor user similarity.

Therefore, selecting ratings carefully is required. First, attack profiles need to have a high degree of similarity with genuine users to influence predictions. Since Pearson correlation results in values between −1 and 1, it is important that all attack profiles correlate either positively or negatively with genuine users. Otherwise, the contributions of multiple attack profiles may be cancelled or attacked items may be inadvertently pushed instead of being nuked, or vice versa [11].

## 11.3.4 Dimensions of attacks

An attacker requires some knowledge to profile injection attacks by considering the attack size and attack intention. From an attacker's point of view, the best attack is an attack that has the biggest influence with the least amount on the system. We use a relatively informal distinction between two types of attack based on knowledge:

- 1. High knowledge attacks: These attacks need the detailed knowledge in the database of recommender systems. For an instance, the attacker needs to know about rating tools or the standard deviation for each item.
- 2. Low knowledge attacks: These attacks need some public information about sources. The goal of an attack is one of the dimensions of attacks. Two generals of attacks are push and nuke. The effect of profile injection attack may make a fake product more likely, which is called push, or make an original product less likely, which is called nuke to be recommended. The attacker may have another goal to degrade system functionality. We focus on economic motivation for an attacker, who wants to promote or degrade a product rating.

In several ways, we can measure the size of an attack. We enumerate the number of fake profiles and the number of ratings that are generated in each profile. We assume an attacker can automate the profile injection process. As online registration human intervention, the number of profiles is very important and site owner may impose a cost due to create new profiles. When profiles consist of ratings, another risk will be added. Real users' ratings are just a small part of large recommendation space. A person with a profile cannot rate to every item, so, recognizing fake profiles with many ratings are very easy [13].

### 11.3.5.2 Push attacks

Push attack has two main models [9]: random and average. These attacks fake ratings to filler items.

### Random and average attack models

These attacks are discussed in [9]. In this formal model, we consider I_s to be empty, the set of I_f is chosen randomly and we need some information about the distribution of ratings. The σ function calculates the overall average of ratings. Average model works like random attack, I_s is calculated for each filler item. So, for more information we need about distribution of ratings in the system. Average attack is more effective than random attack, but it infeasible to know the rating distribution details of the system.

### Bandwagon attack

Bandwagon attack is like random attack model. Bandwagon model needs a little knowledge about the system that determines the favorite item in specific domains such as blockbuster movies and top-selling records. Obtaining this information does not need detailed information about the system. A set that is named I_s consists of these favorite items. In profile attacks, high ratings are given to these items. Item-based algorithms are vulnerable to Segment attack. Item-based algorithms create clusters of similar items. The main aim of Segment attack is to increase the target item and the segment items in I_s similarity. To enhance the similarity between the target item and these items, low ratings are given to filler items.
