- Real-time matrix factorization model update based on stochastic gradient descent (SGD)
First, a real-time MF [37] based on CF algorithm, which is an online update strategy will be developed. MF measure user preferences which are modeled merely by a small number of latent factors and these factors then attempts to explain the observed user-item ratings by these factors which have been inferred from the rating patterns. MF aims to uncover the latent factors which are each user $u$ is associated with a vector $x_u \in \mathbb{R}^f$. For a given item $i$, the elements of $y_i$ measure the extent to which the item belongs to those factors. Similarly, for a given user $u$, the elements of $x_u$ measure the extent of interest the user has in items that are high on the corresponding factors. The “u$’s rating of item $i$ is $r_{ui}$, which indicates the preference by user $u$ of item $i$. Higher $r_{ui}$ values mean stronger preference, and the goal of MF is to predict the unknown ratings. The prediction is done by taking an inner product, $\hat{r}_{ui} = x_u^T y_i$. The major challenge MF is dealing with “i” to compute the mapping of each user and item to factors $x_u, y_i \in \mathbb{R}^f$. To learn the vectors $(x_u$ and $y_i)$, the training is performed by minimizing the regularized squared error on the set of known ratings:

$$\min_{x_u, y_i \in D} (r_{ui} - x_u^T y_i)^2 + \lambda (||x_u||^2 + ||y_i||^2) \quad (7.10)$$

where $D$ is the set of user-item pairs for which $r_{ui}$ is known, i.e., the training set, and $\lambda$ is a parameter used to control the extent of regularization. The regularization term $\lambda (||x_u||^2 + ||y_i||^2)$ is used to avoid overfitting, and the value of $\lambda$ is data-dependent and usually determined by experiments. By taking the biases into account, the prediction of rating $r_{ui}$ could be extended as:

$$\hat{r}_{ui} = \mu + b_u + b_i + x_u^T y_i \quad (7.11)$$

where $\mu$ stands for the average rating, $b_u$ and $b_i$ indicate the observed deviations of user $u$ and item $i$, respectively, from the average.

$$\min_{x_u, y_i \in D} (r_{ui} - \mu - b_u - b_i - x_u^T y_i)^2 + \lambda (||x_u||^2 + 2b_u + b_i^2) \quad (7.12)$$

The most successful method to solve MF optimization problem is SGD [38], identifying a training dataset that contains tuples in the form (user,item,rating). SGD performs passes through the dataset until the moment of stopping criteria is met, which is generally a union bound or a maximum number of iterations. At most, SGD hits every known rating in the training set. For each rating, SGD updates the parameters by correcting them in the inverse direction of the gradient of error. $\eta \le 1$ is the factor by which the extent of correcting is determined and it is known as step size of the learning rate. Based on (7.11), the associated prediction error of rating $r_{ui}$ can be computed as:

$$e_{ui} = r_{ui} - \mu - b_u - b_i - x_u^T y_i \quad (7.13)$$

The operating operations are as follows:

- $b_u \to b_u + \eta(e_{ui} - \lambda b_u) \quad (7.14)$
- $b_i \to b_i + \eta(e_{ui} - \lambda b_i) \quad (7.15)$
- $x_u \to x_u + \eta(e_{ui}x_u - \lambda x_u) \quad (7.16)$
- $y_i \to y_i + \eta(e_{ui}y_i - \lambda y_i) \quad (7.17)$

The confident levels of various implicit feedback data instances are considered by the online strategy. The learning rate of the training process is adjustable to each data instance.
