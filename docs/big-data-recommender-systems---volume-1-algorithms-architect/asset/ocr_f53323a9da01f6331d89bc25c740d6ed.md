# 11.4.6.2 Item-based collaborative filtering

Item-based collaborative filtering compares items using users' ratings patterns. We can combine this approach with the nearest-neighbor approach. KNN algorithm covers the $k$ most similar items users rated them. We measure the similarity by using relation (11.6), which is introduced in [29].

```
$Sim_{i,j} = \frac{\sum_{u \in U} (r_{u,i} - ar{r}_u) * (r_{u,j} - \bar{r}_u)}{\sqrt{\sum_{u \in U} (r_{u,i} - \bar{r}_u)^2 * \sum_{u \in U} (r_{u,j} - \bar{r}_u)^2}}}$ $(11.6)
```

Here $r_{u,i}$ is ratings which user $u$ give for item $i$. As mentioned before, $ar{r}_u$ is ratings average of user $u$. By calculating the similarity between items finished (by using relation (11.6)), we can choose the $k$ most similar items to the target item and put them in a set. We can also predict it using the formula in relation (11.7):

```
$p_{u,i} = \frac{\sum_{j} r_{u,j} * sim_{i,j}}{\sum_{j} sim_{i,j}}$ $(11.7)
```

The set of $k$ similar items is named $J$. $r_{u,j}$ is a prediction value for a user $u$ on item $j$, and and $j$ items similarity is calculated by $sim_{i,j}$, which is defined in relation (11.6).
