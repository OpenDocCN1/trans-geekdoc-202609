Specifically, for each user activity record $(u, v, l_v, W_v, s, t)$ in $D_{test}$: (1) we compute the score for spatial item $v$ and all other spatial items which are within the circle of radius $d$ centered at $l_i$ and unvisited by $u$: (2) we form a ranked list by ordering all of these spatial items according to their ranking scores. Let $r$ denote the position of the spatial item $v$ within this list. The best result corresponds to the case where $v$ precedes all the unvisited items (that is, $r = 1$) and (3) we form a top-k recommendation list by picking the $k$ ranked spatial items from the list. If $r \leq k$, we have a hit (i.e., the ground truth item $v$ is recommended to the user). Otherwise, we have a miss.

The computation of Accuracy@k proceeds as follows. We define hit@k for a single test case as either value 1, if the item $v$ appears in the top-k results, or the value 0, if otherwise. The overall Accuracy@k is defined by averaging all test cases:

```
$Accuracy@k = \frac{\#hit@k}{|D_{test}|}$
```
