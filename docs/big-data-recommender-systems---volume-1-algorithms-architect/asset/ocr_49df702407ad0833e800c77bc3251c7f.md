# 8.1 Introduction

Due to advancement of technology, the world today is producing uncountable products for the use of men. When it becomes unusable, we keep them with us and look for ways to dispose of them. The choices we have to dispose either in land or in water bodies. Either of these affects the environment and its living beings. To a great extent, we can reduce harm caused by the disposal of waste in land or water by recycling them through some process [1–3]. To recycle, the waste material has been collected and segregated as per its nature and then recycled. Many of the disposed wastes can be recycled and give shape to new products out of it. Metal items can be easily recycled and reused for printing purposes. As said earlier, in order to recycle the disposed wastes, we have to collect and segment the materials. Commonly, this is done manually by people engaged for. This method is causing harm to the life of the people. It is, therefore, highly important that we implement automation for the collection and segregation of waste.

There are many techniques that are used for automatic waste segregation. Some methods use image-processing techniques to classify the waste. Size, color, texture, etc., of waste is used to segment, and such systems are implemented using microcontrollers [1]. There are also waste segregators which are based on sensors. Different types of sensors such as capacitive sensors to detect plastic, glass, wood; inductive proximity sensors to detect metals, gas detection and optical sensors for detecting food items, etc., are used to segment waste [3,4]. Segregation of waste is also done using radio frequency identification (RFID). In this type of segregation, the RFID is attached to each type of material during manufacturing, so that classification becomes easier [5].

Currently, supervised learning techniques in machine learning are used for classification [6]. In supervised learning, the data is labeled and the algorithm predicts the output from input data. The supervised learning algorithm learns to inherit structure from input data. Traditional supervised learning techniques rely on feature engineering, feature representation and feature-selection techniques. This requires extensive domain knowledge. Recently, deep learning have performed well in comparison to the traditional machine learning in various standing intelligence tasks which are related to CV, natural language processing, speech processing, etc. They have the capability to learn optimal features by taking raw input samples. They pass the input data across many hidden layers and to learn the abstract feature representation. CNN is a type of deep learning algorithms. It has proved as a best classifier [7]. This has also performed well on test [8–13] and time series data [14–16]. In this work, we employ CNN for waste segregation. The main objectives of this system are as follows:

+   * To develop scalable framework that can handle huge data set.
* Framework employs deployed and parallel algorithms with various optimization techniques that are capable of analyzing the plastic and nonplastic data.
* To implement a hardware setup to demonstrate the segregation of plastic and nonplastic trash.
