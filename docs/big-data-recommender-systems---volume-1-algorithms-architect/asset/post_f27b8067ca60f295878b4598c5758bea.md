ST-SAGE1 is the first simplified version of the ST-SAGE model, and it does not consider the temporal information. This means that $o^{native}$ and $o^{tourist}$ in this version are $|R| \times |T|$ vectors. For each user activity, the topic index $z$ is sampled according to the equation used in (9.3). This simplified version is equal to the Geo-Sage model proposed in [28].

```
$P(z_{u,j}|S_{u,j},u_{u,j},o^{0}_{u,j},o^{native}_{u,j},o^{tourist}_{u,j}) = P(z_{u,j}|u_{u,j}) + (1-S_{u,j}) \times o^{native}_{u,j} + S_{u,j} \times o^{tourist}_{u,j}$
```

ST-SAGE2 is the second simplified version, and it models the temporal information without omitting the proposed spatial pyramid. More specifically, the topic index $z$ is sampled according to the following equation:

```
$P(z_{u,j}|S_{u,j},u_{u,j},o^{0}_{u,j},o^{native}_{u,j},o^{tourist}_{u,j}) = P(z_{u,j}|u_{u,j}) + (1-S_{u,j}) \times o^{native}_{u,j} + S_{u,j} \times o^{tourist}_{u,j}$
```

ST-SAGE3 is the third simplified version of ST-SAGE which does not exploit the geographical correlation in the spatial pyramid. Thus, the model cannot deal with the informed temporal native preference and temporal tourist preference for location $l$ at time $t$ are not reliable when there are few or even no activity records in the corresponding region.

## 9.5.1 Evaluation methods

We aim to evaluate the effectiveness and efficiency of the proposed ST-SAGE. For the efficiency part, both the model training and the online recommendation efficiency are to be evaluated.

Recommendation effectiveness. Since our ST-SAGE model is designed for hometown recommendation and out-of-town recommendation, we evaluate the recommendation effectiveness of our model under each of the scenarios. Given a user profile containing a collection of user activities, we divide these activities into a training set and a test set. For the hometown recommendation scenario, we randomly select 30% of the activity records occurring at the hometown as the test set, and use the remaining activity records as the training set. Similarly, for the scenario of out-of-town recommendation, we randomly select 30% of the activity records generated by the user he/she travels out of town as the test set and use the remaining records as the training set. To decide whether an activity record occurs in his/her hometown elsewhere, we measure the location distance between the user's hometown and the spatial item (e.g., $|l_u - l_i|$). If the distance is greater than 100 km, we assume the activity occurs when the user is out-of-town. The threshold $d = 100$ km is selected because a distance of around 100 km is the radius of “human reach,” which takes 1–2 h to drive.

According to the above dividing strategies, we split the user activity dataset D into the training set $D_{train}$ and the test set $D_{test}$. To evaluate the recommendation

methods, we adopt the evaluation methodology and measurement Accuracy@k, which is applied in [16,20,43–45]. Specifically, for each user activity record $(u, v, l_v, W_v, s, t)$ in $D_{test}$: (1) we compute the score for spatial item $v$ and all other spatial items which are within the circle of radius $d$ centered at $l_i$ and unvisited by $u$: (2) we form a ranked list by ordering all of these spatial items according to their ranking scores. Let $r$ denote the position of the spatial item $v$ within this list. The best result corresponds to the case where $v$ precedes all the unvisited items (that is, $r = 1$) and (3) we form a top-k recommendation list by picking the $k$ ranked spatial items from the list. If $r \leq k$, we have a hit (i.e., the ground truth item $v$ is recommended to the user). Otherwise, we have a miss.

The computation of Accuracy@k proceeds as follows. We define hit@k for a single test case as either value 1, if the item $v$ appears in the top-k results, or the value 0 otherwise. The overall Accuracy@k is defined by averaging all test cases:

```
$Accuracy@k = \frac{\#hit@k}{|D_{test}|}$
```

## 9.5.2 Impact of different factors

To validate the respective benefits acquired by exploiting the temporal information and the spatial smoothing based on the spatial pyramid, we compare ST-SAGE-S1, ST-SAGE-S2 and ST-SAGE-S3. The results of this comparison are shown in Figures 9.7 and 9.8. From this, we observe that ST-SAGE consistently outperforms the three variant versions for both out-of-town recommendation and hometown recommendation, which demonstrates the benefits of exploiting the temporal information and the spatial smoothing. By comparing ST-SAGE-S1 and ST-SAGE-S2, we also observe that ST-SAGE-S1 performs better in out-of-town recommendation while ST-SAGE-S2 performs better in hometown recommendation. This is because the personal activity data is extremely sparse in out-of-town recommendation, and this sparsity leads to inaccuracy in the personal temporal preferences in ST-SAGE-S2.
