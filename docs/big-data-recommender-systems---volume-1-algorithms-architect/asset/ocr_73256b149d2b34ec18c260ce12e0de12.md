+   1. CORLP method: Rather than modeling a previously unrelated relationship between users and items, the CORLP method models relational qualities through complex number. Comparing to the state-of-the-art methods, CORLP method has accomplished considerable performance. Directed graph $G=(V, E, w)$ is a representation of input data, where the set of nodes $V$ and items $I$, is a set of links for diverse associations, and w contains all of the links weight. Subsequently, set $w_{like}=i, w_{dilate}=-i, w_{similar}=1, w_{dissimilar}=-1$, where $i$ is an imaginary number with negative square. Therefore, they are able to change graph $G=(V,E,W)$ to $G'=(V',E',W')$ which is an unweighted and undirected network. The adjacency matrix $A$ of the user-item graph (UI) includes the following characteristics:

```
$A(x,y) = \begin{cases} i, & \text{if x likes similar y} \ -i, & \text{if x dislikes y} \ i, & \text{if x likes y or y dislikes x} \ -i, & \text{if x dislikes y or y likes x} \ 0, & \text{if (x,y) \notin E} \end{cases} \quad (7.2)
```

where $A(x,y)$ is the value in row $x$ and column $y$ of matrix $A$. Matrix $A$ can be signed as $A_{UU} A_{II}$ where $A_{UU},A_{II}$ are the similarity matrix of users and items; $A_{UI},A_{IU}$ are the preference matrices of users, and the graph $G'$ is a bipartite graph and the adjacency matrix $A$ can be simplified to

```
$\begin{bmatrix} 0 & A_{UI} \ -A_{IU} & 0 \end{bmatrix}$
```

and they can further convert $A$ to $B$, where $B$ is a real matrix. Based on path counting in weighted and undirected networks, the path counting for paths of length $k$ can be derived similarly. $A^k$

```
$A^k = \begin{cases} \begin{bmatrix} (BB^T)^n & 0 \ 0 & (B^TB)^n \end{bmatrix}, & k=2n \ \begin{bmatrix} 0 & (BB^T)^n B \ -(B^TB)^n B^T & 0 \end{bmatrix}, & k=2n+1 \end{cases} \quad (7.3)
```
