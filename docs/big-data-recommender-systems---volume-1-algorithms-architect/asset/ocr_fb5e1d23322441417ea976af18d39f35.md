However, this normalizing factor is intractable to compute. This is because, in the graphical model of LDA 6.4(b) there is a coupling between $	heta$ and $\beta$. When taking the log of (6.11) it is not possible to separate parameters $\theta$ and $\beta$. To overcome this problem, LDA tries to approximate the parameters using Gibbs sampling or variational inference (VI). The former approximates the parameters by drawing MCMC samples from the posterior, while the latter achieves this objective by optimizing the evidence lower bound (ELBO) of the likelihood function. Here, we restrict our explanation to the VI technique. Readers interested in Gibbs sampling-based inference are refer to the tutorial on parameter estimation for text analysis [25].

The VI solves the problem of coupling by assuming that the distribution $\theta$ and $\beta$ depends only on their respective variational parameters $\gamma$ and $\phi$ [26, 27]. Under this assumption, the ELBO can be stated as follows:

```
$ln P(v|\alpha, \beta) = \mathcal{L}(\alpha, \beta) + KL(q(\theta, z|v)|P(\theta, z|v, \alpha, \beta))$ $ (6.12)
```

The objective of VI is to learn $\mathcal{L}(\alpha, \beta)$ as close as possible to $ln P(v|\alpha)$. In other words, the goal is to learn the parameters $\gamma$ and $\phi$ which minimizes the KL divergence between the variational distribution $q(\theta, z:|)$ and the true posterior. One of achieving this is to use iterative fixed-point method, which yields the following updates:

```
$\phi_{uk} \propto \beta_{kv} \exp[\log(\theta_k)|\gamma_k]$ (6.13)
```
