# **Algorithm 2**: Generative process of CTR

```
1 **for each user** $i \in I$ **do**
2   draw user latent vector $u_i \sim \mathcal{N}(0, \lambda_u^2 I_K)$
3 **end**
4 **for each item** $j \in J$ **do**
5   draw topic proportions $	heta_j \sim 	ext{Dirichlet}(\alpha)$
6   draw item latent offset $\epsilon_j \sim \mathcal{N}(0, \lambda_v^2 I_K)$
7   Set the item latent vector $v_j = \epsilon_j + 	heta_j$
8   **for each word** $n \in N$ **do**
9     draw topic assignment $z_{jn} \sim 	ext{Mult}(	heta)$
10    draw word $v_{jn} \sim 	ext{Mult}(eta_{jn})$
11 **end**
12 **end**
13 **for each user-item pair** $(i, j)$ **do**
14   draw the rating $r_{ij} \sim \mathcal{N}(u_i^T v_j, c_{ij}^{-1})$
15 **end**
```

**Parameter inference**: There are four latent parameters in this model, namely, $	heta$, $\phi$, $U$ and $V$. The authors adopt a MAP estimate to infer these parameters by maximizing the following likelihood.

> $\mathcal{L} = -\frac{\lambda_u}{2} \sum_{i=1}^N u_i^T u_i - \frac{\lambda_v}{2} \sum_{j=1}^J (v_j - 	heta_j)^T (v_j - 	heta_j) + \sum_{j=1}^J \sum_{n=1}^N \log (\sum_{k=1}^K 	heta_{jk} eta_{k,jn}) - \sum_{i,j=1}^N \frac{c_{ij}}{2}(r_{ij} - u_i^T v_j)^2 \quad (6.18)$

Coordinate ascent is used to learn parameters by iteratively optimizing the CF variables $U$ and $V$, and the item-topic properties $	heta$. The learning of $U$ and $V$ remains as that of PMF (Section 6.2.1). Given $U$ and $V$, the likelihood function for the topics is derived by applying Jensen's inequality as follows:

> $\mathcal{L} \geq \frac{\lambda_u}{2}(v_j - 	heta_j)^T(v_j - 	heta_j) + \sum_{n=1}^N \sum_{k=1}^K \phi_{jn} (\log 	heta_{jk} eta_{k,jn} - \log \phi_{jn}) \\quad = \mathcal{L}(	heta_j, \phi_j) \\quad (6.19)$

where $\phi_{jn}$ is the variational distribution $q(z_{jn}=k)$. $\mathcal{L}(	heta_j, \phi_j)$ gives the tight lower bound of $\mathcal{L}(	heta_j)$, and projection gradient [28] is used to obtain parameter $	heta$. After estimating the user latent attribute $U$ and item latent attribute $V$, parameters $\phi, eta$ can be obtained using the M-update method of LDA that was explained in Section 6.2.3.
