Today, the large-scale datasets (LSDB) are experiencing the massive voluminous datasets from every possible domain like information communication (ICT), electronic health records (EHRs), cloud computing, social media, chain management, with the continuous applications of local area network (LAN), wide-area network (WAN), wireless, sensors, mobile and cloud technologies transmission, etc. Big data is defined as voluminous and complex unstructured, semi-structured and structured dataset that traditional data software applications are inadequate to deal with. However, one of the main challenges in big data is the inherent difficulty to coherently manage incompatible and inconsistent data structures from diverse heterogeneous sources (DHS) [1]. Traditional approaches integrate well comparatively for small data domain but fail when they are being applied to unstructured, semi-structured and massive datasets. The efficient logical cognition and existing approaches preserve the traditional approaches for the interoperability. The HAs with their logical functions including sufficient sensitivity can easily handle data integration (DI) process and with the efficient algorithmic logic address the quality (DQ), data accuracy, inconsistency, etc. Most of the existing approaches such as peer-to-peer warehouses, middleware, data grid, data mining, semantic and ontology establish connections between heterogeneous sources. Although these approaches offer advantages in some aspects, they do not provide a coherent mechanism to solve every problem. In addition, none of them pay strong attention to data inconsistency which has been a long-standing challenge in database environments [2–4]. This implies that big data can show inconsistency because different organisations have several standards and different major systems, which have emerged as critical issues and practical challenges The challenges become even more important when implementing any big data including an exponential increase of data, particular infrastructure need, need for a skilled workforce, need interoperable data standards, privacy and security, and the need to include people, processes and policies to ensure their adoption.
