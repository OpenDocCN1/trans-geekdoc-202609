We implement a parallel ST-SAGE inference algorithm on the distributed GraphLab framework [39] and parallel gradient descent learning framework PSSG [35]. PSSG is scalable because it not only uses the quasi-Newton strategy with line search to robust to common functions but also adopts the multicore processing strategy. Specifically, in the E step, we implement the Gibbs sampling algorithm in the GraphLab framework [39]; in the M step, PSSG [35] is adopted as the parallel gradient descent-learning framework in ST-SAGE.

GraphLab framework is proposed to support asynchronous, dynamic, graph-parallel computation while ensuring statistical correctness, which is required by Gibbs Sampling to ensure each and achieving a high degree of parallel performance in the shared-memory setting. GraphLab has demonstrated superior performance over popular parallel systems, e.g., MapReduce and Spark, for many machine-learning algorithms [40].

This framework implements the gather – scatter (GAS) model which abstracts the program into three phases. In the gather phase, each vertex aggregates data from the scope of the vertex. The scope of a vertex includes the data stored in vertex as well as the data stored in all adjacent vertices and edges. The gather result is used to update the data stored in the vertex phase. Lastly, each vertex triggers its neighboring vertices or modifies adjacent edge data. GraphLab framework stores the graph state as an undirected graph called the data graph. In this graph, users can associate arbitrary data with each vertex and edge. In ST-SAGE, we store the state as a graph in Figure 9.4. Specifically, we construct an undirected graph that connects each user with each spatial item.
