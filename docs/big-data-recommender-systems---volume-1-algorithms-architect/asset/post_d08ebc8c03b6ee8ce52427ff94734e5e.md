## 6.3 Deep learning for recommender systems

DL has demonstrated a great capability in learning useful representations of data in domains such as computer vision, natural language processing and speech recognition. The impressive feature-learning ability of DL has attracted the attention of researchers in recommender system community. Recently, DL models as AutoRec[10], N [11] and visual-content recommendation [29] have shown significant improvement over traditional recommender systems. In this section, we will briefly introduce recommender systems based on DL algorithms, which includes restricted Boltzmann machine, AE, multilayer perceptron and long short-term memory (LSTM).

### 6.3.1 Restricted Boltzmann machine-based collaborative filtering

RBM-CF [9] is probably the first recommendation model built atop DL. An illustration of RBM-CF is shown in Figure 6.6(a). It is composed of two layers, input layer $V$ and hidden layer $h$. The input/visible layer $V \in \{0,1\}^{K\times m}$ encodes the ratings of a user to items, where $m$ is the total number of items and $K$ is the rating range, i.e., the rating is from 1 to $K$. Each rating is converted to one-hot-coding. For example, the first column of $V$ as shown in Figure 6.6(a) is $[0, 0, 0, 1]$, denoting that the rating the user give to the first item is 4. The hidden layer $h \in \{0,1\}^{F\times1}$ is corresponding latent features of a user we want to learn, where $F$ is number of latent dimensions. The joint distribution of $V$ and $h$ is defined as

```
$P(V, h) = \frac{\exp(-E(V,h))}{\sum_{V',h'} \exp(-E(V',h'))} \quad (6.22)$
```

with the energy term $E(V,h)$ given as

```
$E(V,h) = -\sum_{i=1}^m \sum_{j=1}^F \sum_{k=1}^K w_{ij}^k h_j v_i^k - \sum_{i=1}^m \log Z_i - \sum_{j=1}^F \sum_{k=1}^K v_i^k b_j^k - \sum_{j=1}^F h_j b_j \quad (6.23)$
```

Where $w_{ij}^k$ is the weight between the rating $k$ of item $i$ and the hidden unit $j$, and $b_j^k$ is the corresponding bias. $Z_i = \sum_{k=1}^K \exp(b_j^k + h_j w_{ij}^k)$ is the normalization factor that ensures $\sum_{k=1}^K p(v_i^k|h) = 1$. With the joint distribution, we can derive the conditional distributions as

```
$p(v_i^1|h) = \frac{\exp(b_i^1 + \sum_{j=1}^F h_j w_{ij}^1)}{\sum_{k=1}^K \exp(b_i^k + \sum_{j=1}^F h_j w_{ij}^k}) \quad p(h|V) = \sigma(b_j + \sum_{i=1}^m \sum_{k=1}^K w_{ij}^k v_i^k) \quad (6.24)$
```

The goal of RBM-CF is to learn the weights and bias by maximizing the likelihood $\sum_n p(V^{(n)})$, where $V^{(n)}$ are the ratings of user $n$. After the model is trained, $p(v_i^k|h)$ can be used for rating prediction. RBM-CF [30] proposed UI-RBM-CF, which combines the user-based and item-based RBM-CF in a unified framework. We can easily design an item-based RBM-CF if we clamp an item's ratings on the visible layer. Georgiev et al. proposed An illustration of UI-RBM-CF is shown in Figure 6.6(b), where $h^u$ is the latent feature for users and $W^u$ and $W^i$ are the latent weights for modeling users and items, respectively.

### 6.3.2 Autoencoder for recommender systems

AE is another widely used DL model for recommendation. AE is a neural network trained to learn latent representation by reconstructing its input. In fact, one hidden layer AE without nonlinear activation function is similar to PCA, which is one of the reason AE can be used for recommendation. AutoRec [10] applies AE for rating prediction. AutoRec takes user personal vectors $r^{(u)}$ or item partial vectors $r^{(i)}$ as input and reconstruct them at output layer. Based on the input, it has two variants, i.e., Item-based AutoRec (I-AutoRec) and User-based AutoRec. Figure 6.6(c) gives an illustration of I-AutoRec. Given the input $r^{(i)}$, AutoRec encodes it to latent representation

### 6.3.3 Multilayer perceptron based recommender systems

Recently, NCF [11] based on multilayer perceptron is proposed, which also shows promising results. Unlike collaborative-based methods, such as RBM-CF and I-AutoRec, NCF uses MLP, which is shown in Figure 6.7(a). It takes a (user, item) pair as input. The architecture of NCF consists of several fully connected layers to capture the non-linear interactions between users and items. The loss function for NCF is defined as

```
$$\mathcal{L} = \sum_{(u,i) \in \Theta} (r_{ui} - \hat{r}_{ui})^2$$
```

where $\Theta$ is the set of positive data and $\Theta^{-}$ is a subset of missing ratings. For implicit ratings, the cross-loss is

```
$$\mathcal{L} = - \sum_{(u,i) \in \Theta} r_{ui} \log \hat{r}_{ui} + (1 - r_{ui}) \log (1 - \hat{r}_{ui})$$
```

### 6.3.4 RNN/LSTM for recommendation

As LSTM is of great modeling sequence data and user rating history is also sequential, LSTM is of great potential for temporal/dynamic recommendation systems. One representative of RRN is proposed in [12], which exploits LSTMs to model the seasonal evolution of items and changes of preferences over time for prediction. As shown in Figure 6.7(b), RRN uses two LSTMs as the building block to model dynamic user state and item representation. Respectively, the input to the LSTM is modeled as a sequence of ratings of the user. Specifically, the sequence $y_1,y_2,...,y_t$ is defined as

```
$y_t = Embedded(xt_t, n_{newbie}, \tau_t)$
```

where $W_{embed}$ is the transformation to be learned project source information into embedding space. $x_i \in \mathbb{R}^m$ denotes the rating for a given user at time $t$. $x_{ij}=k$ if the user rated item $j$ with the score $k$ at time step $t$ and $x_{ij}=0$ otherwise. $\tau_t$ is the wall clock at time step $t$ and $n_{newbie}=1$ indicates that the user is new. With such inputs, the users latent representation at time $t$

```
$u_t = LSTM(u_{t-1}, y_t)$
```
