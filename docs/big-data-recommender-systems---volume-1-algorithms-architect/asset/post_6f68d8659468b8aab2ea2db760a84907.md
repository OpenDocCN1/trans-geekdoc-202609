## 8.9 Experiments and observation

Generally, any machine learning model contains two modules, training and testing. The images used for training is required to train the neural network, whereas the images for testing is used to predict the accuracy of the system. Data of waste materials required for our setup is collected; they are trained and tested using CNN. The images of plastic waste and nonplastic waste are collected real-time using mobile camera as from real-time internet training. The detailed statistics of various data sets is reported in Table 8.4. Data set 1 and 2 is collected from Internet sources. Data set 3 is collected from real-time camera. Data set 4 is a combination of data sets 1, 2 and 3. The experiment is done in four different ways:

- The network is trained with images from the internet and tested using the images from the internet (data set 1).
- The network is trained with images from the internet and tested using the images from the internet (data set 2).
- The network is trained with images captured from real time and tested using the images captured real time (data set 3).
- The network is trained with images captured real time, input and tested using the images captured real time.
- The network is trained with images captured in real time and tested using the images from internet and captured real time.

## 8.10 Conclusion and future work

In the current research, waste-segregation management system is thoroughly studied and developed an automated proof of concept model by leveraging the application of deep learning techniques. Specifically, segregation of plastic and nonparametric problem is considered. Deep learning techniques provide facility to pass raw image samples such as the model and obtain an optimal feature representation. This representation helps segment plastic and nonparametric images. The hardware setup model demonstrates the segregation of plastic and nonparametric waste using CNN. The performance of the CNN model is evaluated on various data sets. It performed well in almost all data sets. The prototype designed has given a better idea of how a waste-segregating machine can be designed. This system can be used for commercial purpose by any manufacturing company. This model, when used for commercial purpose, can be more advantageous, as it can reduce humans infected by wastes and reducing the efforts of them.

Due to computational time and other requirements, we were unable to try experiments with more complex architecture. Thus, even more images can be used to train and even more epochs be done to increase the accuracy, thus reducing the error of prediction. The machine can be designed in even more user-friendly manner so that this product can be commercialized in future. Additionally, CNN methodology can be integrated with other machine learning techniques such as SVM so that it can achieve a greater efficiency [17]. Additionally, the recent trend in artificial intelligence is switching towards CapsNet because it has the capability to use 3D imaging and can achieve good performance with less data set. Thus, CapsNet outperforms CNN in image-classification tasks [27].
