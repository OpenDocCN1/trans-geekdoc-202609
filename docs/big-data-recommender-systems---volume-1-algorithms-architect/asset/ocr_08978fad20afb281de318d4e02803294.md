**Figure 6.4 Generative framework of recommendation using LDA model:
(a) shows a toy example of the movie-selection process of a user and
(b) represents the formal graphical structure of the model

recommendation system, which illustrates the decision-making process of a user $u$ to watch a movie $v$. In this example, there are four topics (i.e., distribution $	heta$) over color-coded codes and four movies, which are depicted as colors of the $\phi$ matrix. The following steps delineate the generative process of LDA.

+   * A user has interests over multiple topics with different proportions which follows a Dirichlet distribution $	heta$ with hyperparameter $\alpha$.
* From the topical interests $	heta$, he then picks a single topic $z$ (denoted by the color codes) using a multinomial distribution. In this example, the user picks the movie topic horror that is denoted by the orange coin.
* To watch a movie $v$, he consults a topic-movie matrix $\phi$, which indicates probability of $v$ belonging to a topic $z$ and picks a single movie that matches his topical interests using a multinomial distribution. In Figure 6.4, the user picks *Rings* which corresponds to the genre horror.

However, in reality we do not observe the specific topic $z$, which implies that both the user-topic proportion $	heta$ and the movie-topic proportion $\phi$ are not observed. The observed variables are the sets of $U = \{u_i\}_{i=1}^n$ and their item selections $N_u = \{v_{uj}\}_{j=1}^m$. Therefore, the central inference problem of LDA is to estimate $	heta$ and $\phi$ from the observed variables $v$ and $u$. The formal representation of LDA’s graphical model is shown in 6.4(b).

**Parameter inference:** The posterior of LDA is defined as follows:

```
$P(\theta, z|v, \alpha) = \frac{P(\theta, z|v, \alpha)}{P(v|\alpha)}$
```

By examining the graphical structure of the model, the likelihood for a single user $u$ can be expanded as follows:

```
$P(\theta, z, v|\alpha, \beta) = P(v|\beta, z)P(z|\theta)P(\theta|\alpha)$
```
