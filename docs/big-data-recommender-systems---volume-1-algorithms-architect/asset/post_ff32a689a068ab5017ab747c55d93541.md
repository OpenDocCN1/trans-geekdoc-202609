This decision permits us to cast the problem as logistic regression, which is carried out for scalability reasons. In fact items $i$ and $j$ have distance $d(X_i, X_j) = c$, then they have probability 0.5 of being related; the probability increases above 0.5 for $d(X_i, X_j) < c$ and decreases as $d(X_i, X_j) > c$. Bear in mind that do not state $c$ in advance but choose $c$ to maximize prediction accuracy.

Now a set of potential distance functions will be described.

**Weighted nearest neighbor:** Taking that into consideration, those different feature dimensions are almost certainly more important than the different relationships; our concern is to acquire a method by which we can discover feature dimensions relevant to distinct relationships. They aim to learn which feature dimensions are relevant for a particular relationship. So they fit a distance function of the

```
$d_W(X_i, X_j) = ||W \circ (X_i - X_j)||^2,$
```

where $\circ$ is the Hadamard product.

**Mahalanobis transform:** Equation (7.29) is restricted in modeling the visual similarity between objects, although with varying emphasis per feature dimension. Modeling subtle notions is a bit tricky, which pairs of pants and regardless having different aspects, fit in the same style. To do so, they are supposed to learn how different feature dimensions relate to each other; or to precise how they find out how the features of a pair of pants will be transformed in order to help spot a well-matched pair of objects. To identify such transformations, they relate image features via a Mahalanobis distance, which basically generalizes (7.29), so as at the level of pairs of features, weights will be described. In particular they fit

```
$d_M(X_i, X_j) = (X_i - X_j)M(X_i - X_j)^T$
```

A complete ranked matrix M contains excessive parameters and it makes it hard to fit amenably into the size of the dataset. For instance, if we want to use features with dimension F = 22, to learn a transform in (7.30), around 8 million parameters are required to be fitted in; not only is this nearly overfitting, it is also not practical for any current solver. To deal with these, by considering the fact that M parameters a Mahalanobis distance, we can estimate M ≈ YYᵀ where Y is a matrix of dimension ≈ K. Consequently, we define

```
$d_Y(X_i, X_j) = (X_i - X_j)YY^T(X_i - X_j)^T \|_2^2$ (7.31)
```

Remember that almost every distance (and its derivatives) define the distance in O(FK), which is noteworthy for the scalability of the method. Similar ideas emerge in [51] [17], which take the problem of machine learning into accounting by low-rank implant, even if it uses a different objective than the one they have considered.

- 1. Style space: In addition to being computationally useful, the low-rank transform in (7.31) has a convenient interpretation. Specifically, if they consider the K-dimensional transform $s_i = X_iYYᵀ$, then the distance can be rewritten as

```
$d_Y(X_i, X_j) = \|S_i - S_j\|_2^2$ (7.32)
```

In other words, (7.31) defers a low-dimensional embedding of the features $x_i$ and $x_j$. This low-dimensional representation is referred to as style-space embedded products. Despite hope that related objects fall close to each other. The notion of style is automatically learned by training the model on pairs of objects regard as being related. Personalizing styles to individual users:

A model has been developed to learn a universal notion; according to that, we learn products together or match. Rooted in the notion of style-related products should have similar style. This notion is adaptable and could be personalized for each user in order to discover which style they regard classy or important. To do so, they need to learn personalized distance functions $d_Y(X_i, X_j)$ which appear the distance between item $i$ and $j$ according to the user $u$. They pick the distance

```
$d_Y(X_i, X_j) = (X_i - X_j)D^{(ij)}YY^T(X_i - X_j)^T$ (7.33)
```

Where $D^{(ij)}$ is a diagonal semidefinite matrix. In this way, the entry $D^{(ij)}$ indicates the extent to which the user $u$ “cares about” the style. In practice, $D^{(ij)} = X_u$.
