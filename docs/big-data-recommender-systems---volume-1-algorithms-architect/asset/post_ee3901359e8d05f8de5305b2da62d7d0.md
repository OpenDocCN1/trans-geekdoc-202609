**CNN:** It is a form of neural network commonly used for image classification. Unlike the other traditional network which has densely connected layers, CNN shares weights between receptive fields. This reduces the number of parameters and CNN employs convolution mechanism with filters. CNN is a network that learns the filters to use, i.e., the features to extract, in order. The network takes input data, transforms it by calculating a weighted sum over the input and applies a nonlinear filter for this transformed input to find an intermediate state. These three steps constitute a layer. The commonly used nonlinear activation function is rectified linear unit (ReLU).

CNN constitute combination of the following layers:

**Convolution layer:** This layer contains filters, and each filter produced an image containing a particular feature. So the output of a convolution layer will be a stack of images called Tensor.

**Maxpool layer:** This layer is used to reduce the size of the input by merging the neighboring elements by taking the maximum value. Hence a two-dimensional window is chosen, and it is convolved over each image steps. After each step, it gets values which within the window; from these values, the maximum value is chosen and over all convolution steps, a matrix of all these chosen values is formed which is of low dimension. This will help to reduce the number of parameters and hence the amount of computation.

**Fully connected layer:** In this layer, we have many units. Each unit is connected to every other unit. As the density increases, the accuracy also increases. In this work, the sigmoid activation function as loss function. The entry is defined mathematically as follows:

$loss(pd, ed) = -\frac{1}{N}\sum_{i=1}^{N} [ed_i \log pd_i + (1 - ed_i) \log (1 - pd_i)]$

where $pd$ is a vector of probability for all samples and $ed$ is a vector of expected class.
