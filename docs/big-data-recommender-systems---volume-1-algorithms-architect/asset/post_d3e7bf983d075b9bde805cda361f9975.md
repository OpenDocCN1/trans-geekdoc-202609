## Love and Hate attack

Deploying Love and Hate attack is simple and there is no need for additional knowledge. Love and Hate attack contains profile attacks. In this attack $r_{min}$ (the minimum rating) is given to $i_t$ (the target item) and $r_{max}$ (the maximum rating) is set for other ratings in the filler item. By changing $r_{min}$ to $r_{max}$ and vice versa in push attack, we can define the variables form of Love and Hate attack.

So, the target item is affiliated to dislike items. The system may produce low ratings for these items tend to be very popular. Low-rated items, on the other hand, have to spend higher ratings, making it much harder to select items to be included in the attack, enough to make a significant impact. ### 11.4.1 Association rule mining

Generally, association rule mining is used to analyze market basket. The goal is to know customers' manner and find products that may buy together. The relations between items are discovered by association rules using patterns of transactions. In [21], association rules are used to personalize web pages. We use association rule mining for collaborative filtering. We use the Apri algorithm by assuming each user profile as transaction. Also, in [22] association rules are used to create groups that contain similar items. If an item is not repeated sufficiently, will not be in any set that contains frequent items. This means that this item will never recommended. Increasing the threshold leads to recommend more items, but these recommended items may not have adequate evidence of the pattern. We must consider ratings of profile using association rule mining on datasets. To calculate the zero-mean profile of each user, first we subtract the average rating of each user from user’s ratings. We divide items into two sets: Like and Dislike. If the calculated value of the item is >0, this item will be put in Like set and if the calculated value of the item is <=0, effective can be gained by doubling the total number of features. To do this, attacker must be able to infer the items that can be recommended [23].

### 11.4.2 Base algorithms

To find users’ profiles that are target user, we can use user-based collaborative filtering algorithms. By using the ratings assigned to items of neighbor group, we can predict rating values for missing items. In these approaches, a ranked list is generated and recommender system recommends top predictions [23].

### 11.4.3 k-Nearest neighbor

The kNN algorithm is very precise, so it is extensively used [24]. To calculate the similarity between items, Pearson’s correlation coefficient is used in this algorithm. The k most similar users are chosen as neighbors who have rated the target item. It means that the target user can have different ratings for each item. It is usual to filter neighbors whose similarity is under threshold. By using this approach, negative correlations are prevented.
