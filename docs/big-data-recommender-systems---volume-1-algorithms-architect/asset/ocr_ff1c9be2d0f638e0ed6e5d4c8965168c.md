# ### 6.3.3 Multilayer perceptron based recommender systems

Recently, NCF [11] based on multilayer perceptron is proposed, which also shows promising results. Unlike the reconstruction-based methods, such as RBM-CF and I-AutoRec, NCF uses MF with MLP, which tries to capture the nonlinear way interaction between users and items. The architecture of the NCF is shown in Figure 6.7(a). It takes in a (user, item) pair as input to a multilayer perceptron. The user and item are represented using one-hot coding, which are first projected to the later representation in the embedding layer. The projection is simply the multiplication of sparse user/item representation with the embedding matrix, i.e.,UT_u^{user}$ and $VT_i^{item}$. The embedding matrix then goes to Layer 1 of NCF layers and the Output Layer gives the rating score

```
$$\hat{r}_{ui} = f(UT_u^{user} \cdot VT_i^{item} | U, \theta)$
```

where $f(\cdot)$ is the multilayer perceptron and $	heta$ are the parameters of the network. For explicit regression, the loss function is defined as the weighted square error

```
$$\mathcal{L} = \sum_{(u,i) \in \Theta \times \Theta^{-}} W_{ui} \cdot (r_{ui} - \hat{r}_{ui})^2$
```

where $\Theta$ is the set of positive training data and $\Theta^{-}$ is a subset of missing ratings. For implicit ratings, the cross-loss is defined as

```
$$\mathcal{L} = - \sum_{(u,i) \in \Theta \times \Theta^{-}} r_{ui} \log r_{ui} + (1 - r_{ui}) \log (1 - \hat{r}_{ui})$
```

One to note is that traditional MF is a special case of NCF by removing the NCF layers. In others, without the NCF layers, (6.26) reduces to $\hat{r}_{ui}=(UT_u^{user}, VT_i^{item})$.

# ### 6.3.4 RNN/LSTM for recommendation

As LSTM is of great modeling sequence data and user rating history is also sequential, LSTM is of great potential for temporal/dynamic recommender systems. One representative of RRN is proposed in [12], which exploits LSTMs to model the seasonal evolution of items and changes of preferences over time for prediction. As shown in Figure 6.7(b), RRN uses two LSTMs as the building block to model dynamic user state and item representation. Respectively, the input to the LSTM is modeled as a sequence of ratings of the user. Specifically, the sequence $y_1,y_2,...,y_t$ is defined as

```
$y_t = Embedded(xt_t, n_{newbie}, \tau_t)$
```

where $W_{embed}$ is the transformation to be learned project source information into embedding space. $x_i \in \mathbb{R}^m$ denotes the rating for a given user at time $t$. $x_{ij}=k$ if the user rated item $j$ with the score $k$ at time step $t$ and $x_{ij}=0$ otherwise. $\tau_t$ is the wall clock at time step $t$ and $n_{newbie}=1$ indicates that the user is new. With such inputs, the users latent representation at time $t$

```
$u_t = LSTM(u_{t-1}, y_t)$
```
