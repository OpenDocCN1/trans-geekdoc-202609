# 14.5 Intrusion detection (ID) using multidimensional zoom
(M-ZOOM) framework

The fundamental goal of an M-ZOOM framework is, given a higher order tensor than how we can detect the blocks present in the tensor. This problem formulation demands the data to be arranged in the form of a tensor. Each feature represents each dimension of the tensor. The following example helps to understand the idea behind M-ZOOM framework.

The data tabled in Table 14.11 refers to the grade of a student. The fundamental question here is how do we convert this into a tensor? Let us depict Table 14.11 as R = Grade (student, subject, marks, count). Each tuple (st, s, m, c) represents the student “st” has obtained “c” times marks in subject “s”. Here when comparing student Z1, Z2 as marks Z3 as Y. Z1, Z2 represent dimension attributes and Y represent measure. When comparing with original data, Z1, Z2, Z3 are the features from the original data and Y represents the count of times that (P, Marks, 30) have occurred seven times, then the Y value for that corresponding particular tuple has occurred seven times, then the Y value is 7. The next step is to define mass C = R, P2 = Computer science, Maths, The Mass of C given by MC is 7 + 5 = 12. Similarly $M_{C(P)} = Mass(C(R)) = 5$ and $M_{C(C'(P))} = 7$.
