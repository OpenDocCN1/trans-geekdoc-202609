In the MRF model considered, a vertex represents a preference $r_{ui}$ of user u on item i and each edge captures a relation between two preferences by the same user, similarly to the previously presented MRF-based models. This standard MRF model captures the local structure between item-item correlations. The ORF model captures item-item correlations with the point-wise ordinal distribution: $P(r_{ui}) = \Psi_u(r_{ui})Q(r_{ui}, i)$, where $\Psi_u(\cdot)$ is the potential function capturing the interaction among items $r$, and $r_u$ is the set of preferences from user u. The potential function can be decomposed into pairwise potentials: $\Psi_u(r_{ui}) = \exp(\sum_{r_{ij}\in r_u} w_{ij}f_{ij}(r_{ij}))$, where $f_{ij}(\cdot)$ is the correlation feature between items $i,j$ and $w_{ij}$ is a weight that controls the influence of each correlation relation to ordinal distribution. The feature function captures the item-item correlation in the form $f(r_{ij}) = g(r_{ij} - ar{r}_j)$, where $g(x) = 1/(1+e^{-x})$ and $ar{r}_i, ar{r}_j$ are the average ratings of $i$ and $j$, respectively. This function ensures that correlated items receive similar ratings by the same user after the grouping of each item. User-user correlations can be determined analogously and the bias with identity features for item-users can be addressed. The decomposition of the potential function in pairwise potentials allows proper scaling in bigdata environments and distributed operation.

The work in [23] provides more details on parameter estimation of the model based on a pseudo-likelihood approach, maximizing the regularized log likelihoods. Following the estimation of model parameters, rating prediction is straightforward, by identifying the rating with the greatest mass in local likelihood $r_{ui} = \argmax_{r_{ui}} P(r_{ui})$. The local likelihood in this case serves as a confidence measure. For predictions of scalar values, the expectation $r_{ui} = \sum_{r_{ui}} r_{ui}P(r_{ui})$ can be easily used. The authors in [23] compare the performance of the ORF approach with $K$-nearest neighbors and OMF approaches, verifying the effectiveness of their approach.
