Researchers have introduced various ML-based solutions to IDS. IDS for the enhancement of improvement in detecting attacks is largely studied in recent days. This section delves into the details of used-based solutions to IDS till disclose the issues of the KDD-Cup-99 data set.

Most research studies considered IDS—a classification task that finds a rating plane for the behaviors of normal and attacks in network data. A large number of methods introduced following the first paper about IDS. In that, ML and data-mining techniques emerged as prominent methods are largely used toward IDS. However, their performance is less in comparison to other areas as IDS is an evolving problem with new types of attacks. Due to this, IDS has been a vivid area of research for the past 50 years.

The openly available data set for creating an ML model for ID is very little. A few data sets exist, each suffers from its own issues. A commonly observed issue is that the data set have failed to represent the real-time network traffic characteristics. KDD-Cup-99 is the most commonly used IDS data set for benchmarking the performance of ML models. KDD-Cup-99 data set was used as part of the ID challenge conducted by third International Knowledge Discovery and Data-Mining Tools Competition. The aim of the challenge was to classify the connection records as either benign or attack. Totally, 24 entries were participated and submitted their results. The most of the performed entries used decision tree and its criteria. After the challenge, the KDD-Cup-99 data set was most commonly used data set for evaluation of various models. Most of the research studies used 10% data set for ID in the case of feature reduction. Other few studies have used their own custom-built data sets. These custom-built in the data set were constructed using the random selection of connection records from 10% train and test connection records.
