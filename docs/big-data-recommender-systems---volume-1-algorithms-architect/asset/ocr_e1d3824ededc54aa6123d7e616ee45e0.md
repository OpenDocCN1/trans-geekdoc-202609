According to the limited-memory BFGS [36] updates for the quasi-Newton method, the gradients of model parameters $\theta^y$, $	heta^{user}$, $	heta^{native}$ are provided as

```
$$\frac{\partial L}{\partial \theta^z} = d(z) - \sum_{u=1}^{u} \alpha_{u,s_j}d_{uj,j}d_{uj,z}, \quad \frac{\partial L}{\partial \theta^{user}}_u = d(u,z) - \sum_{i=1}^{i} \alpha_{u,s_j}d_{uj,j}d_{uj,z}$ \qquad (9.9)
```

```
$$\frac{\partial L}{\partial \theta^{native}_{l,z}} = (1-s) \times (d(l,t,z) - \sum_{j=1}^{j} \alpha_{u,s_j}d_{sj,J,z}), \qquad (9.10)
```

```
$$\frac{\partial L}{\partial \theta^{tourist}_{l,z}} = s \times (d(l,t,z) - \sum_{j=1}^{j} \alpha_{u,s_j}d_{sj,J,z})$ \qquad (9.11)
```

where $d(z)$ represents the number of user activities assigned to the topic $z$, $d(u,z)$ denotes how many activities are assigned to topic $z$ in $u$'s activity profile $D_u$, the number of visiting activities assigned to topic $z$ at location $l$ and time $t$, $d(l,t,z)$ represents the set of activities occurring at location $l$ and time $t$, and $u_{uj}$ denotes the user who generates the $j^{th}$ activity. Similarly, the gradients of model parameters $\phi^0_{topic}$, $\psi^0$ and $\phi^{topic}_{topic}$ are computed as follows:

```
$$\frac{\partial L}{\partial \phi^0_w} = d(w) - \sum_{k=1}^{K} d(z)\beta_{z,w}, \quad \frac{\partial L}{\partial \psi^0_{z,w}} = d(z,w) - d(z)\beta_{z,w}$ \qquad (9.12)
```

```
$$\frac{\partial L}{\partial \psi^0_v} = d(v) - \sum_{k=1}^{K} d(z)\gamma_{z,v}, \quad \frac{\partial L}{\partial \phi^0_{z,v}} = d(z,v) - d(z)\gamma_{z,v}$ \qquad (9.13)
```

where $d(w)$ is the total number of activities where the word $w$ appears, and $d(z,w)$ is the number of user activities associated with the topic $z$, and $d(z,v)$ represents the number of user activities in which which the topic $z$ is assigned to item $v$.

**Time complexity.** There are two steps in each iteration of the Gibbs EM algorithm: Gibbs sampling and gradient descent learning. We assume that the algorithm needs $I$ iterations to reach convergence. For each iteration, the time complexity is analyzed as follows. In the E-step, it needs to go through all check-in records, and for each check-in, requires $O(K)$ operations to compute the probability distribution for sampling topic $z$. Thus, the time complexity in this step is $O(K \times D)$ where $D = \sum_{u}|D_u|$ is the total number of check-ins in the dataset. In the M-step, we use the gradient descent learning to update the model parameters $\bigcirc = [\theta^0_{user},\theta^0_{native},\theta^0_{tourist},\phi^0_{topic},\phi^0_{topic},\phi^{topic}_{topic}]$ based on the topic assignments sampled in the E-step. We estimate that the gradient descent algorithm needs $J$ iterations to converge, and in each iteration, the time complexity to compute the model parameters $\bigcirc$ is $O(K \times D)$.
