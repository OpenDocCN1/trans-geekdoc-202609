```
log P(X, R) = E_q[log P(Z, U, V, R, X) - q(U, V, Z)] (6.35)
```

Here, the variational distribution $q$ is over three latent variables, $U, V,$ and $Z$. The RHS of the ELBO (i.e., the likelihood term) can be expanded as

```
\mathcal{L}(U, V, \theta, \phi) = E_{q(Z)}[log P(X|Z) - \mathscr{D}(q(Z|X) || P(Z))] + E_{q(Z)}[log P(V|Z) + log P(R|U) + log Pr(U)] (6.36)
```

where $\phi$ and $	heta$ are the set of weights for the encoder and decoder networks, respectively. The first term of the above equation is simply the ELBO of VAE, while the second term is likelihood of PMF. One can observe that the ELBO of VAE has two parts, the first is simply the sum squared error between the predicted and actual inputs, and the second term is $\mathscr{D}$ the KL divergence between two multivariate normal distributions which is given as

```
\mathscr{D}(q(Z|X)||Pr(Z)) = -\frac{1}{2}(tr (\Sigma_{\phi}(x)) + (\mu_{\phi}(x))^T (\mu_{\phi}(x)) - log det(\Sigma_{\phi}(x))) (6.37)
```

In the likelihood function $\mathcal{L}(U, V, \theta, \phi)$, it is straightforward to take the gradient w.r.t. to $	heta$; however, the gradient w.r.t. to $\phi$ cannot be estimated since the sampling operation is not a deterministic function. This in turns makes back-propagation unfeasible. A reparameterization trick is adopted to obtain samples of $z$ from an isotropic normal distribution where $z = \mu_{\phi}(x) + \epsilon \Sigma_{\phi}(x)$, $\epsilon \sim N(0, I)$ and $x$ is the attribute vector of a single item [34]. Substituting the corresponding distributions in 6.36, the following MAP estimate is obtained:

```
\mathscr{L}^{MAP}(U, V, \theta, \phi) = \mathscr{L}(VAE) - \sum_{ij} \frac{C_{ij}}{2}(R_{ij} - U_i^T V_j)^2 - \frac{\lambda_U}{2} \sum_{i} ||U_i||^2 - \frac{\lambda_V}{2} \sum_{j} E_{q(Z|Z)} ||V_j||^2 (6.38)
```
