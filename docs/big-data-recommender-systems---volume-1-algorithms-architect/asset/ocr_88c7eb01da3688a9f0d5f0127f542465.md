# 11.3.5.1 Profile injection attacks

In this section, we introduce the basic concepts of profile injection attacks and dimensions. Profile injection attacks have two main aspects: profile injection attack models and profile injection attack dimensions. [8,13–15] for additional details.

Profile injection attack models create profile attacks and are based on the information about recommender systems, its database and its links. In Figure 11.3, we can see the general structure of these profiles. This structure consists of four items: a target item $i_t$, similar items with special features that are chosen by the attacker $I_s$, filler items that are selected $l_f$ and items that have no ratings $I_o$. We define attack models, e.g. target item, selected items, filler items and how ratings are assigned to items to define the model of an attack. $\gamma$ function determines the target item. $\sigma$ function defines how ratings are assigned and $\delta$ function defines filter items.
