# Table 1. Nearpod questions.

Complete the Dialogue:
1. A: 一大早怎么会堵车呢? (How could there be a traffic jam so early in the morning)
   B: _______. (事故) (Accident)
2. A: _______, 把。 (Preposition)
   B: 好的,我马上送过去。 (Okay, I'll send it over right away)
3. A: _______ (以前) (A long time ago)
   B: 真的假的? 看不出来嘛。 (Is that true or not? I can't tell.)
4. A: 这道题怎么会填错呢? (How could this question be answered incorrectly?)
   B: _______。 (马虎) (careless)
5. A: 你这周末都去哪里玩了? (Where did you go this weekend?)
   B: _______。 (都) (all)
Making Sentences: 以前, 被, 什么... 也..., 每隔, 送给 (a long time ago, auxiliary, whatever... also, every period, give)

Errors were found in grammar, word order and syntax, and sentence meaning. Meanwhile, in writing words, errors occurred in using correct words. For example, mistakes in writing the word 吗 become 吗, and 评 became 秤. Students were unable to write the Chinese characters, for example, the letters “蔬菜”, which were written as “shuca i” (Figure 4).
