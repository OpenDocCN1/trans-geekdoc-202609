$r = \sqrt{x^2 + y^2}$
$\lambda(r) = \ln\left[r + \sqrt{r^2 - 1}\right]$
$\therefore \operatorname{arcosh}(x + y) = \lambda(r) = \ln\left[(x + y) + \sqrt{(x + y)^2 - 1}\right]$

The function $\lambda(r)$ sets the boundary conditions, effectively constricting the solution space of the transcendental equation within the constraints of the Poincaré disk model. $\square$

# 3.2. Mader to Euclidean Transformation, Distance Function $d_e$

The Mader model is integrated by transformation function $\Psi$ that bridges the distance along the diameter (denoted by $r$) with the Euclidean distance $d_e$.

$r = \Psi(d_e) = \frac{d_e}{d_e + \sqrt{d_e^2 + 1}}$  (5)

**Proof.** Given the Poincaré metric:
$ds = \frac{2\,dx}{1 - x^2}$

To find the hyperbolic distance $r$ from 0 to $d_e$, we integrate:
$r = \int_0^{d_e} \frac{2\,dx}{1 - x^2}$

Using trigonometric substitution:
Let $x = \tanh(u)$ imply $dx = \operatorname{sech}^2(u)\,du$.
When $x = 0$, $u = 0$ and $x = d_e$, $u = \operatorname{artanh}(d_e)$.
Thus,
$r = \int_0^{\operatorname{artanh}(d_e)} 2\operatorname{sech}^2(u)\,du$
$r = 2u\big|_0^{\operatorname{artanh}(d_e)} = 2\operatorname{artanh}(d_e)$

Using the identity for the inverse hyperbolic tangent,
$\operatorname{arctanh}(x) = \frac12 \log\left(\frac{1 + x}{1 - x}\right)$
$r = \log\left(\frac{1 + d_e}{1 - d_e}\right)$
$e^r = \frac{1 + d_e}{1 - d_e}$
$d_e = \frac{1 - e^r}{e^r + 1}$

Multiplying both the numerator and denominator by $e^{-\frac{r}{2}}$:
$d_e = \frac{e^{-\frac{r}{2}} - e^{\frac{r}{2}}}{e^{-\frac{r}{2}} + e^{\frac{r}{2}}}$
