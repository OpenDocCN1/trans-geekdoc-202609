
$$r = \sqrt{x^2 + y^2}$$

$$\lambda(r) = \ln\left[r + \sqrt{r^2 - 1}\right]$$

$$\therefore \operatorname{arcosh}(x + y) = \lambda(r) = \ln\left[(x + y) + \sqrt{(x + y)^2 - 1}\right]$$

The function $\lambda(r)$ sets the boundary conditions, effectively constricting the solution space of the transcendental equation within the constraints of the Poincaré disk model. $\square$

## 3.2. Mader to Euclidean Transformation, Distance Function $d_e$

The Mader model is integrated by transformation function $\Psi$ that bridges the distance along the diameter (denoted by $r$) with the Euclidean distance $d_e$.

$$r = \Psi(d_e) = \frac{d_e}{d_e + \sqrt{d_e^2 + 1}} \tag{5}$$

**Proof.** Given the Poincaré metric:

$$ds = \frac{2\,dx}{1 - x^2}$$

To find the hyperbolic distance $r$ from 0 to $d_e$, we integrate:

$$r = \int_0^{d_e} \frac{2\,dx}{1 - x^2}$$

Using trigonometric substitution:

Let $x = \tanh(u)$ implies $dx = \operatorname{sech}^2(u)\,du$.

When $x = 0$, $u = 0$ and $x = d_e$, $u = \operatorname{artanh}(d_e)$.

Thus,

$$r = \int_0^{\operatorname{artanh}(d_e)} 2\,du$$

$$r = 2u\big|_0^{\operatorname{artanh}(d_e)} = 2\operatorname{artanh}(d_e)$$

Using the identity for the inverse hyperbolic tangent,

$$\operatorname{arctanh}(x) = \frac12 \log\left(\frac{1 + x}{1 - x}\right)$$

$$r = \log\left(\frac{1 + d_e}{1 - d_e}\right)$$

$$e^r = \frac{1 + d_e}{1 - d_e}$$

$$d_e = \frac{e^r - 1}{e^r + 1}$$

Multiplying both the numerator and denominator by $e^{-\frac{r}{2}}$:

$$d_e = \frac{e^{\frac{r}{2}} - e^{-\frac{r}{2}}}{e^{\frac{r}{2}} + e^{-\frac{r}{2}}}$$

Using the identity \(e^r = \cosh(r) + \sinh(r)\):

$$d_e = \frac{\sinh\left(\frac{r}{2}\right)}{\cosh\left(\frac{r}{2}\right)}$$

Using the hyperbolic identities:

$$\sinh(x) = \frac{e^x - e^{-x}}{2}$$

$$\cosh(x) = \frac{e^x + e^{-x}}{2}$$

$$d_e = \frac{e^{\frac{r}{2}} - e^{-\frac{r}{2}}}{e^{\frac{r}{2}} + e^{-\frac{r}{2}}}$$

Multiplying the numerator and denominator by \(e^{-\frac{r}{2}}\):

$$d_e = \frac{1 - e^{-r}}{1 + e^{-r}}$$

$$r = \ln\left(\frac{1 + d_e}{1 - d_e}\right)$$

Squaring both sides:

$$r^2 = \ln^2\left(\frac{1 + d_e}{1 - d_e}\right)$$

Taking the positive square root (since \(r > 0\) for \(d_e > 0\)):

$$r = \frac{d_e}{\sqrt{d_e^2 + 1}}$$

We assume that

$$d_e \ll \sqrt{d_e^2 + 1}$$

$$\therefore\ r = \frac{d_e}{d_e + \sqrt{d_e^2 + 1}}$$

$$\Psi(R) = \frac{R}{R + \sqrt{R^2 + 1}}$$

This transformation function \(\Psi\) enables a bijection between Mader and Euclidean geometries, connecting these two models using our model. □

## 3.3. Hyperbolic, Euclidean Distance and Mapping Function

We map the hyperbolic distance, \(d_h\), in the Poincaré disk model through the Euclidean norm of \(z\), \(\|z\|\), using the mapping function \(\Phi\).

$$d_h = \Phi(\|z\|) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right) \tag{6}$$

**Proof.** The distance formula in the Poincaré disk model for two points, \(z_1\) and \(z_2\), is

$$d_h(z_1, z_2) = \operatorname{arccosh}\left(1 + \frac{2\|z_1 - z_2\|^2}{(1 - \|z_1\|^2)(1 - \|z_2\|^2)}\right)$$

For the distance between the origin 0 and a point z:

$$d_h(0,z) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right)$$

Using the Euclidean norm for $z = x + yi$:

$$\|z\| = \sqrt{x^2 + y^2}$$

$$d_h = \operatorname{arccosh}\left(1 + \frac{2(x^2 + y^2)}{1 - (x^2 + y^2)}\right)$$

$$\therefore d_h = \Phi(\|z\|) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right)$$

## 3.4. Mapping Function

Consider an arbitrary point $P$ in the Poincaré disk model $\mathbb{D}$. Let the coordinates of $P$ be $(x,y)$, where $x^2 + y^2 < 1$. We define a mapping $\Psi : \mathbb{D} \to \mathbb{M}$, such that a point $P$ in $\mathbb{D}$ is mapped to a point $P'$ in $\mathbb{M}$, the Mader model.

$$\Psi(x,y) = (h(x), h(y)) \tag{7}$$

$$h(z) = \operatorname{arccosh}(\ln(1 + z)) \tag{8}$$

For $z$ in $\mathbb{D}$, the function $h$ effectively translates each coordinate from $\mathbb{D}$ to a corresponding coordinate in $\mathbb{M}$.

## 3.5. Distance Function

Given two points, $P_1'$ and $P_2'$ in $\mathbb{M}$, which correspond to $P_1$ and $P_2$ in $\mathbb{D}$, the distance between $P_1'$ and $P_2'$ in the Mader model, $d_\mathbb{M}(P_1', P_2')$, is defined in terms of the distance between $P_1$ and $P_2$ in the Poincaré disk model, $d_\mathbb{D}(P_1, P_2)$, as follows:

$$d_M(\Psi(x_1,y_1), \Psi(x_2,y_2)) = h(d_D((x_1,y_1),(x_2,y_2))) \tag{9}$$

The transformation $\Psi$ offers a one-to-one mapping between the Poincaré disk $\mathbb{D}$ and Mader model $\mathbb{M}$ using the function $h$ defined in (7). By making use of the function $h$ and the transformation $\Psi$, this continuous mapping preserves the underlying geometric structures to compare the geometric properties between $\mathbb{D}$ and $\mathbb{M}$.

## 4. Series Expansions for Approximations

Understanding the behavior of the function $\lambda(r)$ and the hyperbolic distance $d_h$ under different geometrical transformations is critical. To address this, we employ Taylor series expansion to approximate these functions around the point $P$.

$$f(x + y) = \ln\big[(x + y) + \sqrt{(x + y)^2 - 1}\big]$$

The Taylor series expansion of a function $f$ about a point $P$ is represented as

$$f(x + y) \approx f(P) + f'(P)(x + y - P) + \frac{f''(P)}{2!}(x + y - P)^2 + \frac{f'''(P)}{3!}(x + y - P)^3 + \cdots$$

$$f(P) = \ln\big[ P + \sqrt{P^2 - 1}\big] \tag{10}$$

The hyperbolic distance function $d_h$ can be approximated using a series expansion around the point $P$ in the Poincaré disk model.

$$d_h = \Phi(\|z\|) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right)\tag{11}$$

$$\approx \Phi(P) + (\|z\| - P)\Phi'(P) + \frac{(\|z\| - P)^2}{2}\Phi''(P) + \cdots\tag{12}$$

The general term for the series expansion about the point $P$ is

$$\frac{\Phi^{(n)}[P]}{n!}\,[\|z\| - P]^n\tag{13}$$

where $\Phi^{(n)}[P]$ represents the nth derivative of $\Phi$ concerning $\|z\|$, evaluated at $P$.

## 5. Applications

### Simple Distance Optimization Application

In the Mader model, $P_1$ and $P_2$ are transformed into points within the unit disk. We calculate the Euclidean distances, denoted as $d_{e1}$ and $d_{e2}$, of these points from the origin. Using the mapping function $\Psi$ from the Mader model to the Poincaré model, these points are translated to the Poincaré disk.

$$\Psi(r) = \frac{2r}{1 + r^2}\tag{14}$$

We calculate the hyperbolic distances $d_{h1}$ and $d_{h2}$ for $P_1$ and $P_2$, respectively, in the Poincaré disk model.

$$d_{h1} = \operatorname{arccosh}\left(1 + \frac{2d_{e1}^2}{1 - d_{e1}^2}\right)\tag{15}$$

$$d_{h2} = \operatorname{arccosh}\left(1 + \frac{2d_{e2}^2}{1 - d_{e2}^2}\right)\tag{16}$$

The hyperbolic geodesic distance between points $P_1$ and $P_2$ is computed by the integration of the Poincaré metric over the shortest path represented as a segment of a circle orthogonal to the boundary of the disk in the Poincaré model.

$$\int_{P_1}^{P_2} \frac{2|dz|}{1 - |z|^2}\tag{17}$$

To approximate the complex integral, a Taylor series expansion is employed around the shortest path between $P_1$ and $P_2$. The optimal path corresponds to the minima of the hyperbolic distance. The optimal hyperbolic path is then translated back to the Mader model using the inverse mapping function $\Psi^{-1}$ and subsequently to the Euclidean model to provide a real-world trajectory for objects such as airplanes, ships, and the like.
