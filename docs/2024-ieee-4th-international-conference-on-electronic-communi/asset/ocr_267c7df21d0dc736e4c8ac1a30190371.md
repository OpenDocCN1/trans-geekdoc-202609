The hyperbolic distance function $d_h$ can be approximated using a series expansion around the point $P$ in the Poincaré disk model.

$$d_h = \Phi(\|z\|) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right)\tag{11}$$

$$\approx \Phi(P) + (\|z\| - P)\Phi'(P) + \frac{(\|z\| - P)^2}{2}\Phi''(P) + \cdots\tag{12}$$

The general term for the series expansion about the point $P$ is

$$\frac{\Phi^{(n)}[P]}{n!}\,[\|z\| - P]^n\tag{13}$$

where $\Phi^{(n)}[P]$ represents the nth derivative of $\Phi$ concerning $\|z\|$, evaluated at $P$.

# 5. Applications

*Simple Distance Optimization Application*

In the Mader model, $P_1$ and $P_2$ are transformed into points within the unit disk. We calculate the Euclidean distances, denoted as $d_{e1}$ and $d_{e2}$, of these points from the origin. Using the mapping function $\Psi$ from the Mader model to the Poincaré model, these points are translated to the Poincaré disk.

$$\Psi(r) = \frac{2r}{1 + r^2}\tag{14}$$

We calculate the hyperbolic distances $d_{h1}$ and $d_{h2}$ for $P_1$ and $P_2$, respectively, in the Poincaré disk model.

$$d_{h1} = \operatorname{arccosh}\left(1 + \frac{2d_{e1}}{1 - d_{e1}^2}\right)\tag{15}$$

$$d_{h2} = \operatorname{arccosh}\left(1 + \frac{2d_{e2}}{1 - d_{e2}^2}\right)\tag{16}$$

The hyperbolic geodesic distance between points $P_1$ and $P_2$ is computed by the integration of the Poincaré metric over the shortest path represented as a segment of a circle orthogonal to the boundary of the disk in the Poincaré model.

$$\int_{P_1}^{P_2} \frac{2|dz|}{1 - |z|^2}\tag{17}$$

To approximate the complex integral, a Taylor series expansion is employed around the shortest path between $P_1$ and $P_2$. The optimal path corresponds to the minima of the hyperbolic distance. The optimal hyperbolic path is then translated back to the Mader model using the inverse mapping function $\Psi^{-1}$ and subsequently to the Euclidean model to provide a real-world trajectory for objects such as airplanes, ships, and the like.
