Using the identity \(e^r = \cosh(r) + \sinh(r)\):

\[d_e = \frac{\sinh\left(\frac{r}{2}\right)}{\cosh\left(\frac{r}{2}\right)}\]

Using the hyperbolic identities:

\[\sinh(x) = \frac{e^x - e^{-x}}{2}\]

\[\cosh(x) = \frac{e^x + e^{-x}}{2}\]

\[d_e = \frac{e^{\frac{r}{2}} - e^{-\frac{r}{2}}}{e^{\frac{r}{2}} + e^{-\frac{r}{2}}}\]

Multiplying the numerator and denominator by \(e^{-\frac{r}{2}}\):

\[d_e = \frac{1 - e^{-r}}{1 + e^{-r}}\]

\[r = \ln\left(\frac{d_e + 1}{d_e}\right)\]

Squaring both sides:

\[r^2 = \ln^2\left(\frac{d_e + 1}{d_e}\right)\]

Taking the positive square root (since \(r > 0\) for \(d_e > 0\)):

\[r = \frac{d_e}{\sqrt{d_e^2 + 1}}\]

We assume that

\[d_e \ll \sqrt{d_e^2 + 1}\]

\[\therefore\ r = \frac{d_e}{d_e + \sqrt{d_e^2 + 1}}\]

\[\Psi(R) = \frac{R}{R + \sqrt{R^2 + 1}}\]

This transformation function \(\Psi\) enables a bijection between Mader and Euclidean geometries, connecting these two models using our model. □

# 3.3. Hyperbolic, Euclidean Distance and Mapping Function

We map the hyperbolic distance, \(d_h\), in the Poincaré disk model through the Euclidean norm of \(z\), \(\|z\|\), using the mapping function \(\Phi\).

\[d_h = \Phi(\|z\|) = \operatorname{arccosh}\left(1 + \frac{2\|z\|^2}{1 - \|z\|^2}\right) \tag{6}\]
