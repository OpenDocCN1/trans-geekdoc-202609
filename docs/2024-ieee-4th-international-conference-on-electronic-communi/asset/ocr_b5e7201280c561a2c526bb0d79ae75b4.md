# *3.4. Island Volume Parameter Selection Method*

As shown in Figure 2, the approach involves examining the volumes (sum of performance) occupied by different islands located at sea level and selecting the parameter point with the best performance from the largest island as the parameter choice. Regarding benchmark performance, we arranged the performance of all parameter combinations within the in-sample dataset from smallest to largest for each period. Subsequently, benchmark performance was determined by percentile ranks (PR). As previously mentioned, PR values in this method were set at 90, 95, and 99.
