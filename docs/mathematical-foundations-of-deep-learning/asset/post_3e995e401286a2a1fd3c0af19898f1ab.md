## 8.1 Key Concepts

Recurrent Neural Networks (RNNs) are a class of neural architectures specifically designed for processing sequential data, leveraging their recursive structure to model temporal dependencies. At the core of an RNN lies the concept of a hidden state \(\mathbf{h}_t \in \mathbb{R}^m\), which evolves over time as a function of the current input \(\mathbf{x}_t \in \mathbb{R}^n\) and the previous hidden state \(\mathbf{h}_{t-1}\). This evolution is governed by the recurrence relation:

\(\mathbf{h}_t = f_h(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{b}_h) \quad \text{(443)}\)

where \(\mathbf{W}_{xh} \in \mathbb{R}^{m \times n}\) is the input-to-hidden weight matrix, \(\mathbf{W}_{hh} \in \mathbb{R}^{m \times m}\) is the hidden-to-hidden weight matrix, \(\mathbf{b}_h \in \mathbb{R}^m\) is the bias vector, and \(f_h\) is a non-linear activation function, typically

\(\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} \quad \text{(444)}\)

or the rectified linear unit \(\text{ReLU}(x) = \max(0, x)\). The recursive nature of this update equation ensures that \(\mathbf{h}_t\) inherently encodes information about the sequence \(\{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_t\}\), allowing the network to maintain a dynamic representation of past inputs. The output \(\mathbf{y}_t \in \mathbb{R}^o\) at time \(t\) is computed as:

\(\mathbf{y}_t = f_y(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y) \quad \text{(445)}\)

where \(\mathbf{W}_{hy} \in \mathbb{R}^{o \times m}\) is the hidden-to-output weight matrix, \(\mathbf{b}_y \in \mathbb{R}^o\) is the output bias, and \(f_y\) is an activation function such as the softmax function:

\(f_y(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{j=1}^o e^{z_j}} \quad \text{(446)}\)

for classification tasks. Expanding the recurrence relation iteratively, the hidden state at time \(t\) can be expressed as:

\(\mathbf{h}_t = f_h(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}f_h(\mathbf{W}_{xh}\mathbf{x}_{t-1} + \mathbf{W}_{hh}f_h(\dots f_h(\mathbf{W}_{xh}\mathbf{x}_1 + \mathbf{W}_{hh}\mathbf{h}_0 + \mathbf{b}_h) + \mathbf{b}_h) + \mathbf{b}_h) + \mathbf{b}_h) \quad \text{(447)}\)

This expansion illustrates the depth of temporal dependency captured by the network and highlights the computational challenges of maintaining long-term memory. Specifically, the gradient of the loss function \(L\), given by:

\(L = \sum_{t=1}^T \ell(\mathbf{y}_t, \mathbf{y}_t^{\text{true}}) \quad \text{(448)}\)

with \(\ell(\mathbf{y}_t, \mathbf{y}_t^{\text{true}})\) representing a task-specific loss such as cross-entropy:

\(\ell(\mathbf{y}_t, \mathbf{y}_t^{\text{true}}) = -\sum_{i=1}^o \mathbf{y}_t^{\text{true}}(i) \log \mathbf{y}_t(i) \quad \text{(449)}\)

is computed through backpropagation through time (BPTT). The gradient of L with respect to \(\mathbf{W}_{hh}\), for instance, is given by:

\(\frac{\partial L}{\partial \mathbf{W}_{hh}} = \sum_{t=1}^T \sum_{k=1}^t \frac{\partial \ell_t}{\partial \mathbf{h}_t} \prod_{j=k+1}^t \frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}} \frac{\partial \mathbf{h}_k}{\partial \mathbf{W}_{hh}},\)

where \(\prod_{j=k+1}^t \frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}}\) represents the chain of derivatives from time step k to t. Unlike feedforward neural networks, where each input is processed independently, RNNs maintain a hidden state \(\mathbf{h}_t\) that acts as a dynamic memory, evolving recursively as the input sequence progresses. Formally, given an input sequence \(\{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_T\}\), where \(\mathbf{x}_t \in \mathbb{R}^n\) represents the input vector at time t, the hidden state \(\mathbf{h}_t \in \mathbb{R}^m\) is updated via the recurrence relation:

\(\mathbf{h}_t = f_h(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{b}_h),\)

where \(\mathbf{W}_{xh} \in \mathbb{R}^{m \times n}\), \(\mathbf{W}_{hh} \in \mathbb{R}^{m \times m}\), and \(\mathbf{b}_h \in \mathbb{R}^m\) are learnable parameters, and \(f_h\) is a nonlinear activation function such as tanh or ReLU. The recursive structure inherently allows the hidden state \(\mathbf{h}_t\) to encode the entire history of the sequence up to time t. The output \(\mathbf{y}_t \in \mathbb{R}^o\) at each time step is computed as:

\(\mathbf{y}_t = f_y(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y),\)

where \(\mathbf{W}_{hy} \in \mathbb{R}^{o \times m}\) and \(\mathbf{b}_y \in \mathbb{R}^o\) are additional learnable parameters, and \(f_y\) is an optional output activation function, such as the softmax function for classification. To elucidate the recursive dynamics, we can expand \(\mathbf{h}_t\) explicitly in terms of the initial hidden state \(\mathbf{h}_0\) and all previous inputs \(\{\mathbf{x}_1, \dots, \mathbf{x}_t\}\):

\(\mathbf{h}_t = f_h(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}f_h(\mathbf{W}_{xh}\mathbf{x}_{t-1} + \mathbf{W}_{hh}f_h(\dots f_h(\mathbf{W}_{xh}\mathbf{x}_1 + \mathbf{W}_{hh}\mathbf{h}_0 + \mathbf{b}_h) + \mathbf{b}_h) + \mathbf{b}_h) + \mathbf{b}_h).\)

This nested structure highlights the temporal dependencies and the potential challenges in training, such as the vanishing and exploding gradient problems. During training, the loss function L, which aggregates the discrepancies between the predicted outputs \(\mathbf{y}_t\) and the ground truth \(\mathbf{y}_t^{\text{true}}\), is typically defined as:

\(L = \sum_{t=1}^T \ell(\mathbf{y}_t, \mathbf{y}_t^{\text{true}}),\)

where \(\ell\) is a task-specific loss function, such as the mean squared error (MSE)

\(\ell(\mathbf{y}, \mathbf{y}^{\text{true}}) = \frac{1}{2} \| \mathbf{y} - \mathbf{y}^{\text{true}} \|^2\)

for regression or the cross-entropy loss for classification. To optimize L, gradient-based methods are employed, requiring the computation of derivatives of L with respect to all parameters, such as \(\mathbf{W}_{xh}\), \(\mathbf{W}_{hh}\), and \(\mathbf{b}_h\). Using backpropagation through time (BPTT), the gradient of L with respect to \(\mathbf{W}_{hh}\) is expressed as:

\(\frac{\partial L}{\partial \mathbf{W}_{hh}} = \sum_{t=1}^T \sum_{k=1}^t \frac{\partial \ell_t}{\partial \mathbf{h}_t} \prod_{j=k+1}^t \frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}} \frac{\partial \mathbf{h}_k}{\partial \mathbf{W}_{hh}}.\)

Here,

\(\prod_{j=k+1}^t \frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}}\)

is the product of Jacobian matrices that encode the influence of \(\mathbf{h}_k\) on \(\mathbf{h}_t\). The Jacobian \(\frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}}\) itself is given by:

\(\frac{\partial \mathbf{h}_j}{\partial \mathbf{h}_{j-1}} = \mathbf{W}_{hh} \odot f'_h(\mathbf{a}_j),\)

where

\(\mathbf{a}_j = \mathbf{W}_{xh}\mathbf{x}_j + \mathbf{W}_{hh}\mathbf{h}_{j-1} + \mathbf{b}_h,\) (459)

and \(f'_h(\mathbf{a}_j)\) denotes the elementwise derivative of the activation function. The repeated multiplication of these Jacobians can lead to exponential growth or decay of the gradients, depending on the spectral radius \(\rho(\mathbf{W}_{hh})\). Specifically, if \(\rho(\mathbf{W}_{hh}) > 1\), gradients explode, whereas if \(\rho(\mathbf{W}_{hh}) < 1\), gradients vanish, severely hampering the training process for long sequences. To address these issues, modifications such as Long Short-Term Memory (LSTM) networks and Gated Recurrent Units (GRUs) introduce gating mechanisms that explicitly regulate the flow of information. In LSTMs, the cell state \(\mathbf{c}_t\), governed by additive dynamics, prevents vanishing gradients. The cell state is updated as:

\(\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tanh(\mathbf{W}_c \mathbf{x}_t + \mathbf{U}_c \mathbf{h}_{t-1} + \mathbf{b}_c),\) (460)

where \(\mathbf{f}_t\) is the forget gate, \(\mathbf{i}_t\) is the input gate, and \(\mathbf{U}_c, \mathbf{W}_c,\) and \(\mathbf{b}_c\) are learnable parameters.
