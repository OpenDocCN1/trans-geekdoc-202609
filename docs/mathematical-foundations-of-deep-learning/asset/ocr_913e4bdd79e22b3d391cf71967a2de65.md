# (OLS) solution:

```
\hat{\theta}_{\text{OLS}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}
```

This formulation, however, can lead to overfitting when \( p \) is large or when \( \mathbf{X}^T\mathbf{X} \) is nearly singular. In such cases, **regularization** is used to modify the loss function, adding a penalty term \( \mathcal{R}(\theta) \) to the objective function that discourages large values for the parameters \( \theta_i \). The **regularized loss function** is given by:

```
\mathcal{L}_{\text{regularized}}(\theta) = \mathcal{L}(\theta) + \lambda \mathcal{R}(\theta)
```

where \( \lambda \) is a **regularization parameter** that controls the strength of the penalty. The term \( \mathcal{R}(\theta) \) penalizes the complexity of the model by imposing constraints on the magnitude of the coefficients. Let us explore two widely used forms of regularization: **L1 regularization** (Lasso) and **L2 regularization** (Ridge). L1 regularization involves adding the \( \ell_1 \)-norm of the parameter vector \( \theta \) as the penalty term:

```
\mathcal{R}_{L1}(\theta) = \sum_{i=1}^p |\theta_i|
```

The corresponding **L1 regularized loss function** is:

```
\mathcal{L}_{L1}(\theta) = \frac{1}{n} \|\mathbf{X}\theta - \mathbf{y}\|^2 + \lambda \sum_{i=1}^p |\theta_i|
```

This formulation promotes sparsity in the parameter vector \( \theta \), causing many coefficients to become exactly zero, effectively performing **feature selection**. In high-dimensional settings where many features are irrelevant, L1 regularization helps reduce the model complexity by forcing irrelevant features to be excluded from the model. The effect of the L1 penalty can be understood geometrically by noting that the constraint region defined by the \( \ell_1 \)-norm is a **diamond-shaped** region in \( p \)-dimensional space. When solving this optimization problem, the coefficients often lie on the boundary of this diamond, leading to a sparse solution with many coefficients being exactly zero. Mathematically, the **soft-thresholding** solution that arises from solving the L1 regularized optimization problem is given by:

```
\hat{\theta}_i = \text{sign}(\theta_i) \max(0, |\theta_i| - \lambda)
```

This soft-thresholding property drives coefficients to zero when their magnitude is less than \( \lambda \), resulting in a sparse solution. L2 regularization, on the other hand, uses the \( \ell_2 \)-norm of the parameter vector \( \theta \) as the penalty term:

```
\mathcal{R}_{L2}(\theta) = \sum_{i=1}^p \theta_i^2
```

The corresponding **L2 regularized loss function** is:

```
\mathcal{L}_{L2}(\theta) = \frac{1}{n} \|\mathbf{X}\theta - \mathbf{y}\|^2 + \lambda \sum_{i=1}^p \theta_i^2
```

This penalty term does not force any coefficients to be exactly zero but rather **shrinks** the coefficients towards zero, effectively reducing their magnitudes. The L2 regularization helps stabilize the solution when there is multicollinearity in the features by reducing the impact of highly correlated features. The optimization problem with L2 regularization leads to a **ridge regression** solution, which is given by the following expression:

```
\hat{\theta}_{\text{ridge}} = (\mathbf{X}^T\mathbf{X} + \lambda \mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}
```
