If you continue to interact with this contract from the founder account, you can use the `mintNFT` button to create a new NFTFD token. (Note that creating a new token does require gas.) Here’s how that’s done:

1.  **Click the downward arrow to the right of the `mintNFT` button, as shown in** [Figure 11-10](#c11.xhtml#c11-fig-0010)**.** ![FIGURE 11-10: Expanding function parameters housed in our NFTFD contract.](images/9781119843313-fg1110.png)

    [FIGURE 11-10:](#c11.xhtml#rc11-fig-0010) Expanding function parameters housed in our `NFTFD` contract.

2.  **Fill in the function parameters as follows, as shown in** [Figure 11-11](#c11.xhtml#c11-fig-0011)**:** 

    1.  `to: 0x885b0F6065B2cD6655eDcc2F7A12062b1ca79d97`

        This address links to another test account we created via MetaMask. You can use whatever account address you want here. To prevent confusion, however, we strongly recommend that you avoid co-mingling digital assets across different networks within the same account (as we discuss in [Chapter 7](#c07.xhtml)).

    2.  `tokenID: 17760704`

    3.  `tokenURI: https://en.wikipedia.org/wiki/Independence_Day_(United_States)`

3.  **Click the Transact button, and then click the Confirm button on the MetaMask pop-up notification.**

![FIGURE 11-11: Your mintNFT function parameters.](images/9781119843313-fg1111.png)

[FIGURE 11-11:](#c11.xhtml#rc11-fig-0011) Your `mintNFT` function parameters.

Excellent! You've now created and gifted a new NFTFD token.

This information changes if you type **1** or **5** instead of **17760704**, because those tokens belong to the founder account. You can also track your new NFTFD token holdings via your MetaMask wallet. Make sure you're on the right account and Ropsten Test Network within your MetaMask wallet. We start with the Testnet account (`0x43371B75585785D62e3a50533aa15ee8D350273F`) that we use to deploy the `NFTFD` contract, and proceed on MetaMask as follows:

1.  **Click the Assets tab (toward the bottom of the account screen) and then click the Add Token button, as shown in** [Figure 11-14](#c11.xhtml#c11-fig-0014)**.** ![FIGURE 11-14: Adding a new token type on your MetaMask wallet.](images/9781119843313-fg1114.png)

    [FIGURE 11-14:](#c11.xhtml#rc11-fig-0014) Adding a new token type on your MetaMask wallet.

2.  **On the Add Tokens page that appears (see** [Figure 11-15](#c11.xhtml#c11-fig-0015)**), type the appropriate Token contract address.**

    In our case, it's `0xd4139A846b5561c31df03FbbCE3583f1A7d8A814`.

    The Token Symbol field automatically displays NFTFD after the contract address has been entered.

3.  **Enter** 0 **for Token Decimal and then click the Next button.**

    The next page shows the token being added (NFTFD) and the token balance for this particular account.

    ![Remember](images/remember.png)Unlike fungible tokens, each NFT is unique and cannot be further divided (see [Chapter 1](#c01.xhtml)). Thus, the “Token Decimal” field is set to “0” for NFTs.

4.  **Click the Add Tokens button, as shown in** [Figure 11-16](#c11.xhtml#c11-fig-0016)**.**

    Now whenever you toggle to see the assets in your account, you see the five NFTFD in addition to the test ETH, as shown in [Figure 11-17](#c11.xhtml#c11-fig-0017).
