# 简介

欢迎阅读《NFTs For Dummies》（NFT 入门指南）！如果您对 NFT 感兴趣——包括它们的起源、用例和底层技术——那么这本书非常适合您。

在本书中，您可以找到探索 NFT 世界的有用信息和建议。您还可以找到实用的分步指南，教您如何设置热钱包来存储 NFT、如何浏览 NFT 市场，甚至如何编写您自己的 NFT 代码。
