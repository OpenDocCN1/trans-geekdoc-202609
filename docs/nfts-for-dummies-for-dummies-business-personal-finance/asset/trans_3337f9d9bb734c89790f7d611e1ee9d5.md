
就其本质而言，非同质化商品更难以系统地记录和追踪。首先，它们需要存储更多信息来标示其独特差异。虽然我们无法将世界数字化，但在许多场景中，我们将极大受益于一种可靠、透明且自动化的系统，该系统旨在对对我们重要的非同质化事物进行分组、组织和数字化追踪。NFT 由此登场！

![Remember](images/remember.png) **非同质化代币（NFT）** 是一种受保护并存储在公共区块链上的唯一数字标识符。一个代币不能与另一个代币互换，也不能进一步分割。

NFT 实际代表的内容取决于开发者的意图。正如加密货币——或**同质化代币**——可以代表全球交换媒介（比特币）、用于为智能合约提供燃料的实用代币（以太币），或与基金份额挂钩的金融证券（BCAP）一样，NFT 在其当前和潜在用途上也各不相同。

尽管直到最近，大众对 NFT 的兴趣微乎其微甚至不存在，但开发社区多年来一直**同质化代币**活动频繁。继比特币（2009 年）、莱特币（2011 年）和狗狗币（2013 年）成功推出后，大量项目随之涌现，每个项目都衍生出自己的**同质化代币**。在这股加密浪潮中，开发者开始设想一个数字收藏品的世界——即比尼宝贝和棒球卡的加密版本。这些项目需要一种不同类型的代币标准，以确保每个加密宝贝或加密卡片的唯一性和不可分割性。

最终，随着**CryptoKitties** 的巨大成功，这是一种于 2017 年首次亮相的**以太坊**上的**非同质化代币**，**ERC-721 非同质化代币标准**随即出现，为开发社区提供了蓝图。（在[第 2 章](#c02.xhtml)中阅读更多关于**CryptoKitties** 的内容。）从那时起，NFT 项目呈爆发式增长，仅在**以太坊**上就部署了超过 15,000 个 NFT。（参见[图 1-4](#c01.xhtml#c01-fig-0004)。）

## 探索 NFT 的用例

NFT 领域仍处于起步阶段，但开发社区已经涌现出大量关于如何善用它们的想法。最自然的用例——目前主导市场的用例——是追踪数字收藏品。由此延伸，游戏道具和数字媒体也是自然的应用方向。然而，尽管 NFT 最近呈爆发式增长，目前的实现范围仍相当有限，主要集中在收藏品的变现上。该行业也受到“快速致富”心态的阻碍，这种心态困扰着整个加密领域，并吸引了许多不择手段的投机者。

尽管如此，我们仍看到 NFT 有一系列有趣的潜在用例。其中一些可能真正颠覆我们验证、追踪和分配独特及晦涩物品所有权的方式，或致力于有效实现内容创作和分发的民主化。想象一下，省去了验证稀有收藏品所有权历史的昂贵侦查工作。又或者想象一个世界，昂贵的 eBay 拍卖包含**以太坊区块链**上的所有权证明。目前关注点多集中在投机上，但这些令人兴奋的可能性带来的潜在价值，远远超过了宣称最新 NFT 百万富翁和 NFT 骗子的头条新闻。

加密货币世界也遭遇了类似广泛的反应，从深度怀疑到热情接受不一而足。但随着政府和主要金融机构开始接受**比特币**和**以太币**，底层技术的前景成为讨论的焦点。虽然 NFT 受益于其加密先行者（它们本身仍相当年轻）的铺垫，但我们需要更多时间来观察 NFT 生态系统将如何演变，以及它将催生出什么。

## 了解 NFT 的工作原理

人们经常将 NFT 本身与 NFT 所代表的内容混淆。*NFT* 是一份经过加密保护的数字记录，用于验证你对某件数字艺术品的所有权或访问权——这有点像你的车辆登记证书验证你对车辆的所有权。没有登记证书，你并不真正拥有你占有的汽车；没有相应的 NFT，你也不真正拥有你 JPEG 图片收藏中的**CryptoKitty**。

例如，考虑名为**Mutant Ape Yacht Club (MAYC)** 的加密收藏品。这一系列奇特的变异猿（它们可能属于游艇俱乐部，也可能不属于？）是 NFT 收藏家中的最新狂欢，现在是最活跃的 **ERC-721 代币**。（参见[图 1-5](#c01.xhtml#c01-fig-0005)。）但拥有特定的 **MAYC** 究竟意味着什么？

![FIGURE 1-5: MAYCs listed for public sale on OpenSea.](images/9781119843313-fg0105.png)

[图 1-5：](#c01.xhtml#rc01-fig-0005) 在 OpenSea 上公开出售的 MAYC。

当在 **OpenSea**（你可以在[第 4 章](#c04.xhtml)和[第 12 章](#c12.xhtml)中发现的 NFT 市场之一）上浏览待售的 **MAYC** 时，你会注意到市场平台上展示了挑衅性的图形和特征。（参考[图 1-5](#c01.xhtml#c01-fig-0005)。）你看到的是每个 **MAYC** 的视觉呈现——但 NFT 本身是受保护在**以太坊区块链**上的唯一数字代码。

例如，考虑 [图 1-5](#c01.xhtml#c01-fig-0005) 左上角的 **MAYC #7632**。购买此 NFT 意味着你现在是 **TokenID 7632** 的合法记录所有者，该代币存储在**以太坊区块链**上合约账户 `0x60e4d786628fea6478f785a6d7e704777c86a7c6` 中。所有权的所有转让都将被记录在区块链上，以便始终可知 **MAYC #7632** 的来源及其当前的合法所有者，如[图 1-6](#c01.xhtml#c01-fig-0006) 所示。

![FIGURE 1-6: MAYC #7632.](images/9781119843313-fg0106.png)

[图 1-6：](#c01.xhtml#rc01-fig-0006) MAYC #7632。

截至撰写本文时，共有 14,688 个 **MAYC** 分布在 7,709 个持有者手中。你可以在 [`https://etherscan.io/token/0x60e4d786628fea6478f785a6d7e704777c86a7c6`](https://etherscan.io/token/0x60e4d786628fea6478f785a6d7e704777c86a7c6) 查看每个独特 **MAYC** 的个别详情和所有权。

![Remember](images/remember.png) 你购买的数字艺术品很容易复制。（按键盘上的 PrintScreen 键几乎不需要任何培训。）然而，因为 NFT 受保护在公共区块链上，非法转让、复制或以其他方式攻击它要困难得多。NFT 的美妙之处在于其底层技术——**智能合约**与验证者分布式网络的连接点——它允许你可靠且自动地验证谁真正拥有这 14,688 个变异猿 NFT 中的每一个。

因此，我们的变异猿是一个更大去中心化生态系统的一部分，记录以公开且无需信任的方式保存，这意味着我们不需要受信任的中心化方（如**美国银行**）来为我们维护一个可靠安全的系统来追踪我们的变异猿。以其独特的方式，这些变异猿进一步提高了人们对蓬勃发展的**去中心化金融（DeFi）**和**去中心化自治组织（DAO）**格局的认知。（要阅读更多关于 **DAO** 的内容，请查看[第 4 章](#c04.xhtml)和[第 6 章](#c06.xhtml)。）

大多数 NFT 作为 **ERC-721 代币** 在**以太坊**上铸造。因此，如[图 1-6](#c01.xhtml#c01-fig-0006) 所示，每个代币的来源都被记录在公共**以太坊区块链**上。每笔后续交易都由分布式矿工网络验证并执行——这与保护**比特币区块链**的系统非常相似。
