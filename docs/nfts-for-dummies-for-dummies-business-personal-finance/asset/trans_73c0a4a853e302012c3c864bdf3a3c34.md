

# 合约部署与交互验证

我们合约的地址是 `0xd4139A846b5561c31df03FbbCE3583f1A7d8A814`。稍后，我们将讨论如何使用该地址继续追踪您的合约并与之交互。

![图 11-8：复制您新部署合约的地址。](images/9781119843313-fg1108.png)

[图 11-8：](#c11.xhtml#rc11-fig-0008) 复制您新部署合约的地址。

![警告](images/warning.png) 执行等待时间通常少于一分钟，但执行时间可能会有很大差异。请耐心等待！如果网络在十分钟以上仍无响应，请稍作休息后重试。

与之前一样，当您在本章早些时候将 `NFTFD` 合约部署到本地 Ganache 区块链上时，请注意您刚刚在 Ropsten 上部署的 `NFTFD` 合约下显示着相同的公共函数和数据列表。

例如，如果您点击 Founder（创始人）按钮，您将看到部署代币合约的账户地址。您也可以将此地址粘贴到 `balanceOf` 输入框中，该框将显示该账户中有五个代币，如[图 11-9](#c11.xhtml#c11-fig-0009)所示。（回想一下，我们的代码在初始化时生成了五个代币。）这些数据调用不需要 Gas。

![图 11-9：与部署在 Ropsten 上的 NFTFD 进行交互。](images/9781119843313-fg1109.png)

[图 11-9：](#c11.xhtml#rc11-fig-0009) 与部署在 Ropsten 上的 `NFTFD` 进行交互。

如果您继续从创始人账户与该合约交互，可以使用 `mintNFT` 按钮创建一个新的 NFTFD 代币。（请注意，创建新代币确实需要 Gas。）具体操作如下：

1.  **点击 `mintNFT` 按钮右侧的向下箭头，如** [图 11-10](#c11.xhtml#c11-fig-0010) **所示。** ![图 11-10：展开我们 NFTFD 合约中存放的函数参数。](images/9781119843313-fg1110.png)

    [图 11-10：](#c11.xhtml#rc11-fig-0010) 展开我们 `NFTFD` 合约中存放的函数参数。

2.  **按如下方式填写函数参数，如** [图 11-11](#c11.xhtml#c11-fig-0011) **所示：**

    1.  `to: 0x885b0F6065B2cD6655eDcc2F7A12062b1ca79d97`

        该地址链接到我们通过 MetaMask 创建的另一个测试账户。您可以在此处使用任何您想要的账户地址。不过，为防止混淆，我们强烈建议您避免在同一账户中混合不同网络的数字资产（正如我们在[第 7 章](#c07.xhtml)中讨论的那样）。

    2.  `tokenID: 17760704`

    3.  `tokenURI: https://en.wikipedia.org/wiki/Independence_Day_(United_States)`

3.  **点击 Transact（交易）按钮，然后在 MetaMask 弹出的通知中点击 Confirm（确认）按钮。**

![图 11-11：您的 mintNFT 函数参数。](images/9781119843313-fg1111.png)

[图 11-11：](#c11.xhtml#rc11-fig-0011) 您的 `mintNFT` 函数参数。

太棒了！您现在已经创建并赠送了一个新的 NFTFD 代币。

您可以通过在 `ownerOf` 和 `tokenURI` 按钮旁边的输入框中输入 **17760704**（即前面示例步骤 2 中输入的 `tokenID`）来验证该代币的所有者和 URI，如[图 11-12](#c11.xhtml#c11-fig-0012)所示。如果您输入 **1** 或 **5** 而不是 **17760704**，这些信息会发生变化，因为那些代币属于创始人账户。尝试检查不存在的代币编号的所有者会在 Remix 控制台中产生一条错误消息，如[图 11-13](#c11.xhtml#c11-fig-0013)所示。

您还可以通过 MetaMask 钱包追踪您新的 NFTFD 代币持仓。请确保您在 MetaMask 钱包中处于正确的账户和 Ropsten 测试网络。我们从用于部署 `NFTFD` 合约的测试网账户 (`0x43371B75585785D62e3a50533aa15ee8D350273F`) 开始，在 MetaMask 上按如下步骤操作：

1.  **点击 Assets（资产）选项卡（位于账户屏幕底部附近），然后点击 Add Token（添加代币）按钮，如** [图 11-14](#c11.xhtml#c11-fig-0014) **所示。** ![图 11-14：在您的 MetaMask 钱包上添加新代币类型。](images/9781119843313-fg1114.png)

    [图 11-14：](#c11.xhtml#rc11-fig-0014) 在您的 MetaMask 钱包上添加新代币类型。

2.  **在出现的 Add Tokens（添加代币）页面上（见** [图 11-15](#c11.xhtml#c11-fig-0015) **），输入适当的 Token contract address（代币合约地址）。**

    在我们的例子中，它是 `0xd4139A846b5561c31df03FbbCE3583f1A7d8A814`。

    输入合约地址后，Token Symbol（代币符号）字段会自动显示 NFTFD。

3.  **在 Token Decimal（代币精度）处输入** 0 **，然后点击 Next（下一步）按钮。**

    下一页将显示正在添加的代币 (NFTFD) 以及该特定账户的代币余额。

    ![记住](images/remember.png)与同质化代币不同，每个 NFT 都是独一无二且不可再分割的（见[第 1 章](#c01.xhtml)）。因此，NFT 的“Token Decimal”字段设置为“0”。

4.  **点击 Add Tokens（添加代币）按钮，如** [图 11-16](#c11.xhtml#c11-fig-0016) **所示。**

    现在，每当您切换查看账户中的资产时，除了测试 ETH 之外，您还将看到五个 NFTFD，如[图 11-17](#c11.xhtml#c11-fig-0017)所示。

[图 11-15：](#c11.xhtml#rc11-fig-0015) 在您的 MetaMask 钱包上为新代币类型指定自定义详细信息。

![图 11-16：在您的 MetaMask 钱包上确定新代币类型及其账户余额。](images/9781119843313-fg1116.png)

[图 11-16：](#c11.xhtml#rc11-fig-0016) 在您的 MetaMask 钱包上确定新代币类型及其账户余额。

![记住](images/remember.png)正如我们在[第 7 章](#c07.xhtml)中关于“消失”余额的讨论所述，我们测试网账户中的 NFTFD 余额仅在我们连接到 Ropsten 测试网络时才会出现，因为这个 NFTFD 代币合约 (`0xd4139A846b5561c31df03FbbCE3583f1A7d8A814`) 是部署在 Ropsten 上的，不存在于其他网络上。

例如，当您在连接到以太坊主网的情况下查看我们的测试网账户时，测试 ETH 余额和 NFTFD 余额会完全消失，如[图 11-18](#c11.xhtml#c11-fig-0018)所示。

为了完整起见，我们重新执行前面的步骤，将 NFTFD 代币余额添加到我们的第二个测试账户 `0x885b0F6065B2cD6655eDcc2F7A12062b1ca79d97`，该账户获得了我们在合约初始化后铸造的特殊 `17760704` 代币。正如预期的那样，MetaMask 显示该账户的 NFTFD 余额为 1，如[图 11-19](#c11.xhtml#c11-fig-0019)所示。
