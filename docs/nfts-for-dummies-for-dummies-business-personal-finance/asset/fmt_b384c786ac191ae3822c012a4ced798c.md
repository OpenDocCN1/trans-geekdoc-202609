
# 设置本地区块链测试环境

1.  访问 [`www.trufflesuite.com/ganache`](http://www.trufflesuite.com/ganache) 并点击 **Download** 按钮（如[图 8-2](#c08.xhtml#c08-fig-0002)所示），下载 Ganache 桌面应用程序。

    ![[图 8-2：下载 Ganache 桌面应用程序。](images/9781119843313-fg0802.png)]

    [图 8-2：](#c08.xhtml#rc08-fig-0002) 下载 Ganache 桌面应用程序。

2.  下载完成后，双击安装包并按照提示安装 Ganache（如[图 8-3](#c08.xhtml#c08-fig-0003)所示）。

    ![[图 8-3：Ganache 安装程序。](images/9781119843313-fg0803.png)]

    [图 8-3：](#c08.xhtml#rc08-fig-0003) Ganache 安装程序。

3.  安装完成后，启动 Ganache，然后在起始页面点击 **Quickstart Ethereum** 选项（如[图 8-4](#c08.xhtml#c08-fig-0004)所示）。

    Ganache 会启动一个本地区块链，其中包含模拟以太坊外部拥有账户的测试账户（如[图 8-5](#c08.xhtml#c08-fig-0005)所示）。

    Ganache 的默认设置是启动十个测试账户，每个账户拥有 100 个测试 ETH 余额，仅可在当前工作区中使用。

    ![[图 8-4：Ganache 起始屏幕。](images/9781119843313-fg0804.png)]

    [图 8-4：](#c08.xhtml#rc08-fig-0004) Ganache 起始屏幕。

    ![[图 8-5：Ganache 账户屏幕。](images/9781119843313-fg0805.png)]

    [图 8-5：](#c08.xhtml#rc08-fig-0005) Ganache 账户屏幕。

4.  点击 **Blocks** 标签页（位于屏幕顶部菜单栏 **Accounts** 标签页右侧），查看当前工作区的完整区块链账本。

    初始化时，你只有一个区块：区块 0（**创世**区块），如[图 8-6](#c08.xhtml#c08-fig-0006)所示。

    ![[图 8-6：初始化时的 Ganache 创世区块。](images/9781119843313-fg0806.png)]

    [图 8-6：](#c08.xhtml#rc08-fig-0006) 初始化时的 Ganache 创世区块。

5.  点击 Ganache 应用程序窗口右上角的 **Save** 按钮保存工作区（参考[图 8-6](#c08.xhtml#c08-fig-0006)）。

    Ganache 会自动（随机）为你的工作区命名。在本例中，Ganache 将我们的工作区命名为 `Handsomely-Vessel`（如[图 8-7](#c08.xhtml#c08-fig-0007)所示）。

    ![[图 8-7：在 Ganache 上保存工作区。](images/9781119843313-fg0807.png)]

    [图 8-7：](#c08.xhtml#rc08-fig-0007) 在 Ganache 上保存工作区。

6.  关闭并重新打开 Ganache，在起始页面查看已保存的工作区（如[图 8-8](#c08.xhtml#c08-fig-0008)所示），以便轻松继续之前的工作。

恭喜！你已准备好在私有开发环境中开始工作！

![提示](images/tip.png) 如果要更改工作区名称，请点击工作区名称右侧的 **Settings**（齿轮）图标（参考[图 8-7](#c08.xhtml#c08-fig-0007)）。将出现一个新屏幕，你可以在其中编辑工作区名称（如[图 8-9](#c08.xhtml#c08-fig-0009)所示）。

我们将保留 Ganache 为我们随机生成的这个宏伟工作区名称：`Handsomely-Vessel`！

![[图 8-8：重新初始化后的 Ganache 起始页面。](images/9781119843313-fg0808.png)]

[图 8-8：](#c08.xhtml#rc08-fig-0008) 重新初始化后的 Ganache 起始页面。

![[图 8-9：在 Ganache 上编辑工作区。](images/9781119843313-fg0809.png)]

## 将自定义（Ganache）网络连接到 MetaMask 钱包

启动本地区块链后，你可以将这个自定义“网络”及其关联账户添加到 MetaMask 钱包。请按以下步骤操作：

1.  打开 Ganache 并加载前一节创建的工作区。

2.  找到你的 RPC URL，默认为 [`http://127.0.0.1:7545`](http://127.0.0.1:7545)（如[图 8-10](#c08.xhtml#c08-fig-0010)所示）。

    ![[图 8-10：从 Ganache 界面定位 RPC URL。](images/9781119843313-fg0810.png)]

    [图 8-10：](#c08.xhtml#rc08-fig-0010) 从 Ganache 界面定位 RPC URL。

3.  登录你的 MetaMask 钱包。

4.  要在 MetaMask 中切换网络，请从下拉菜单中选择 **Custom RPC** 选项（如[图 8-11](#c08.xhtml#c08-fig-0011)所示）。

    ![[图 8-11：MetaMask 钱包中的网络下拉菜单。](images/9781119843313-fg0811.png)]

    [图 8-11：](#c08.xhtml#rc08-fig-0011) MetaMask 钱包中的网络下拉菜单。

5.  在出现的新页面中（如[图 8-12](#c08.xhtml#c08-fig-0012)所示），填写网络名称、新 RPC URL 和链 ID，如下所示：

    *   **Network name:** `HANDSOMELY-VESSEL`

        ![提示](images/tip.png) 你可以选择任何网络名称。为保持一致性并避免混淆，建议使用 Ganache 工作区中所选网络的名称。

    *   **New RPC URL:** [`http://127.0.0.1:7545`](http://127.0.0.1:7545) —— 默认 RPC URL

    *   **Chain ID:** `1337` —— 默认链 ID

6.  点击 **Save** 按钮。

干得好！你已成功将新网络添加到 MetaMask 网络选项中（如[图 8-13](#c08.xhtml#c08-fig-0013)所示）。

![[图 8-12：向 MetaMask 钱包添加新网络。](images/9781119843313-fg0812.png)]

[图 8-12：](#c08.xhtml#rc08-fig-0012) 向 MetaMask 钱包添加新网络。

![[图 8-13：HANDSOMELY-VESSEL 现已出现在 MetaMask 网络选项中。](images/9781119843313-fg0813.png)]

[图 8-13：](#c08.xhtml#rc08-fig-0013) HANDSOMELY-VESSEL 现已出现在 MetaMask 网络选项中。

## 将本地（Ganache）账户添加到 MetaMask 钱包

安装 Ganache 并在 MetaMask 中添加相应的自定义网络后，你需要将 Ganache 工作区中的一些账户导入 MetaMask。

要导入本地账户，你需要它们的私钥。请按以下步骤获取密钥：

1.  打开 Ganache 并加载本章前面“[设置本地区块链测试环境](#c08.xhtml#c08-sec-0006)”一节中创建的工作区。

2.  在 **Accounts** 页面，选择一个账户，然后点击最右侧的 **Key** 图标（如[图 8-14](#c08.xhtml#c08-fig-0014)所示）。

    接下来的弹出屏幕将提供该账户的私钥（如[图 8-15](#c08.xhtml#c08-fig-0015)所示）。

![[图 8-14：在 Ganache 工作区中访问账户私钥。](images/9781119843313-fg0814.png)]

[图 8-14：](#c08.xhtml#rc08-fig-0014) 在 Ganache 工作区中访问账户私钥。

![[图 8-15：Ganache 中的示例账户地址和私钥。](images/9781119843313-fg0815.png)]

[图 8-15：](#c08.xhtml#rc08-fig-0015) Ganache 中的示例账户地址和私钥。

有了私钥，按以下步骤将这些账户导入 MetaMask 钱包：

1.  登录 MetaMask 钱包并切换到 `Handsomely-Vessel` 网络。

    ![记住](images/remember.png) 我们的自定义网络名称为 `Handsomely-Vessel`，这可能与你在前面“[设置本地区块链测试环境](#c08.xhtml#c08-sec-0006)”一节中创建的自定义网络名称不同。

2.  点击 MetaMask 应用右上角的彩色圆圈，从下拉菜单中选择 **Import Account** 选项（如[图 8-16](#c08.xhtml#c08-fig-0016)所示）。

    ![[图 8-16：MetaMask 中的导入账户选项。](images/9781119843313-fg0816.png)]

    [图 8-16：](#c08.xhtml#rc08-fig-0016) MetaMask 中的导入账户选项。
