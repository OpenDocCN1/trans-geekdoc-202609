
# 探索 NFT 的重要用例

如果你恰好是按章节顺序阅读本书，那么到现在为止，你应该已经对 NFT 是什么有了一定了解（定义见[第 1 章](#c01.xhtml)），甚至可能已经购买了一个（操作方法见[第 2 章](#c02.xhtml)）。但在 `CryptoKitties` 的可爱形象与 6900 万美元 NFT 的光鲜亮丽之间，NFT 的实际本质很容易被遗忘。`非同质化代币（NFT）` 仅仅是一段经过加密保护的数字代码，用于验证非同质化（即独一无二）物品的所有权。

本章涵盖 NFT 的未来潜力以及 NFT 对财产权可能意味着什么。然而，在深入这些主题之前，我们先带你深入了解那枚在佳士得拍卖行以 69,346,250 美元成交的臭名昭著的 NFT，透过现象看本质，剖析这枚天价 NFT 的实际内部运作机制。如果这枚 Beeple NFT 不是艺术品本身，那它究竟是什么？

## 剖析一枚 6900 万美元 NFT 的解剖结构

艺术家 Beeple 以每天创作一幅新的数字艺术品、持续 5000 天的承诺，开启了其 `EVERYDAYS` 系列。那幅著名的作品 `EVERYDAYS — THE FIRST 5000 DAYS` 标志着这段艺术旅程的终点，旅程始于 2007 年 5 月，终于 2021 年 2 月 16 日对应 NFT 的铸造。最终的 `EVERYDAYS` 作品本身如[图 3-1](#c03.xhtml#c03-fig-0001)所示，但 Beeple 到底在出售什么？

![FIGURE 3-1: Beeple's famed digital artwork, EVERYDAYS — THE FIRST 5000 DAYS.](images/9781119843313-fg0301.png)

[图 3-1：](#c03.xhtml#rc03-fig-0001) Beeple 的著名数字艺术品，`EVERYDAYS — THE FIRST 5000 DAYS`。

由于数字图像是像素值的矩阵，Beeple 将其约 300 兆字节的创作浓缩为图形机器级表示的数字浓缩形式（称为 `哈希码`）。然后，该哈希码连同附加元数据再次进行哈希处理，并作为 Beeple NFT 元数据的一部分存储，同时存储的还有 tokenURI `ipfs://ipfs/QmPAg1mjxcEQPPtqsLoEcauVedaeMH81WXDPvPx3VC5zUz`，它提供了一条路线图，可在 IPFS 点对点网络上找到 Beeple 的 `EVERYDAYS — THE FIRST 5000 DAYS` 数字艺术品。就这样，Beeple 的数字艺术被传播开来，`token ID 49013`（在智能合约地址：`0x2a46f2ffd99e19a89476e2f62270e0a35bbf0756` 中）诞生了！（有关 IPFS 网络的更多信息，请参阅附近的侧边栏“[深入暗网](#c03.xhtml#c03-fea-0001)”。）

这些细节出现在 Beeple 铸造其 6900 万美元 NFT 的交易事件日志中，如[图 3-2](#c03.xhtml#c03-fig-0002)所示。该 NFT 的相应识别详情在佳士得拍卖网站上，如[图 3-3](#c03.xhtml#c03-fig-0003)所示。（如果你好奇，可在此查看完整交易详情：[`https://etherscan.io/tx/0x84760768c527794ede901f97973385bfc1bf2e297f7ed16f523f75412ae772b3`](https://etherscan.io/tx/0x84760768c527794ede901f97973385bfc1bf2e297f7ed16f523f75412ae772b3)。）

最终，拍卖赢家实际上购买了什么？在该特定案例中，该 NFT 并不赋予数字艺术品的独家合法访问权（该数字艺术品本身已作为公共产品自由分发）；也不代表其使用产生的版税收入索赔权。我们拥有的是一段令人难以置信的金融科技（FinTech）历史 —— 我们拥有一条去中介化且安全的所有权记录，永久铭刻在以太坊区块链上，现在我们可以可靠地追溯这一独特数字物品的历史，以验证当前是谁拥有它，以及过去是谁拥有过它。

通过让大众认知这项充满希望的技术，Beeple 和他的最高出价者为 NFT 的未来奠定了基础。你可以在[第 13 章](#c13.xhtml)中阅读更多关于 `THE FIRST 5000 DAYS` 的内容，以及其他九个以惊人价格售出的 NFT（包括 Beeple 的另外两幅作品）。

## 重新定义财产权（NFT 不仅仅关乎数字艺术和猫咪！）

追踪 `CryptoKitties`（或 Beeple 的 NFT）的所有权和血统，仅仅是 NFT 所能实现的冰山一角。运行良好的市场需要定义清晰且可强制执行的财产权。人们往往理所当然地依赖扮演这一重要角色的可信中介 —— 例如，他们依赖县书记官维护房产所有权记录，信任车管所（DMV）维护车辆所有权记录。如今，NFT 提供了一种去中介化的方式来永久记录交易并验证所有权。

NFT 的意义不仅在于其在区块链上加密安全的地位， Beeple NFT 便是一例。在现代，转移所有权意味着转移使用特定资产的合法权利，无论是汽车、房屋还是数字图像。（“拾得者拥有”并非针对汽车盗窃指控的合法抗辩理由。）这一框架与 NFT 完美契合，NFT 可被创建用于合法地代表所有权证书、契据或许可证。

总体而言，NFT 有潜力在无需可信第三方验证交易完整性的前提下，可靠地追踪点对点的所有权记录转移。其即时追踪和验证每件独特物品所有权的能力，使其特别适合颠覆那些独特物品溯源验证机制失效或不足的市场。

## NFT 与数字财产

追踪数字财产是 NFT 的自然切入点。从数字收藏品到游戏道具和数字媒体，NFT 有潜力真正实现创作者经济的民主化。

### 音乐、电影和书籍

直到最近，消费者必须拥有音乐才能随点随听。从唱片到磁带，从 CD 到 mp3，拥有物理或数字媒体被视为理所当然的现状。

尽管数字音乐很方便，但购买和出售实体媒体让人感到踏实 —— 艺术家知道同一时间只能播放一个实例，一旦转手，消费者就不再拥有访问权。因此，首售原则得以确立，规定购买者无需作品版权持有者许可即可转售实体副本。

现在，拥有音乐似乎已成往事 —— 流媒体服务远超音乐的购买和下载。考虑到数字副本质量不退化，美国版权局一直不愿将首售原则应用于数字传输，这种情况顺理成章。任何人都可以轻松出售购买的数字音乐，同时在个人设备上保留副本。

如果数字媒体的真实所有权和访问权得到确立且易于验证，数字领域的销售和转让应与物理领域无异。因此，NFT 可在数字时代带回“拥有媒体”（以及首售原则！）的概念，不仅适用于音乐，还适用于电影和书籍。
