Let's look in detail at the syntax for creating the pipelines. It is in the form
Pipeline(steps), where the input argument steps is a list of transforms and models
to chained, in the order in which they need to be called. Each step is described by
at tuple (name, model), where name is a string used by the user and model is a sklearn
object. The pipeline can be fitted to the data as we have shown above:

```
pipeline.fit(X_train, y_train)
```

To access the original objects in a Pipeline, we use attribute named_steps. For
example, the linear regression object is accessed as:

```
pipeline.named_steps["lin_reg"]
```

and coefficient of the linear regression w₀, ..., w_k can be accessed as


# Cross-validation

If we use a test set, the performance may vary every time we create a different
split. A more robust way is to perform cross-validation, we split the data into
k groups (folds). Each fold will be used to measure performance exactly once, while
t remaining data are used to fit the model. Average performance over the k folds
be much more robust. If there are no hyperparameters to tune, cross-validation can be
used directly to measure the performance of the model. In scikit-learn cross-validation
is called using

```
from sklearn.model_selection import cross_val_score
scores = cross_val_score(estimator, X, y, cv=5)
```

where estimator is the model we want to fit to the feature X and target values/-
bels (for supervised models only). The optional argument cv defines the number of
folds. The model returns an array with scores for each fold.
