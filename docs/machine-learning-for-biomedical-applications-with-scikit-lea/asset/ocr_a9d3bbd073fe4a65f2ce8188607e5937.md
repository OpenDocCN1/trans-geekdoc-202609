# Dataset class

Previously, we have stored our numpy arrays, which we loaded into memory. We also passed the whole dataset to the stochastic gradient descent optimizer training at each iteration. However, this is not possible in many practical situation, where the dataset is stored as individual images on the disk, and it does not fit to CPU and GPU memory because it is too large. PyTorch offers a class `Dataset` that provides an interface to facilitate training using a custom dataset:

```
from torch.utils.data import Dataset
```

The `Dataset` provides three mandatory member functions that have to be implemented:

returns the length of the dataset
For our neonatal MRI dataset, we have these requirements: First, we need to split it into training, validation and test set. To do that, we simply assign the first 320 (81%) subjects for training, the next 32 (8%) for validation and the remaining 44 (11%) for testing. We will aim at batches of 16 for training and validation so we make sure that the numbers in these two sets are divisible by 16 (though this is not necessarily required).

+   - `__init__` takes input parameters and initializes member variables
- `__len__` returns the length of the dataset
- `__getitem__` returns one sample from the dataset for a given index `idx`
