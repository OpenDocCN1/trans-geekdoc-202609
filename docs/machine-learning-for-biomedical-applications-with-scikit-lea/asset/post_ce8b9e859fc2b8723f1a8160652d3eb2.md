
## 1.6.4 List comprehensions

One other example of how we can write in shorthand list comprehensions. These collapse all the lines of code from a for loop (with just one statement, and a single output expression) into a single line appended at each end with a square bracket

```python
a=[]
for i in range(5):
    if i%2==0:
        a.append('num'.format(i))
```

Thus, for the previous list, which prints out numbers in the range 0 to 4 if they are exactly divisible by 2 (and concatenates to 'num' string), using a list comprehension, the code may be written in a single line

```python
b=['num'.format(i) for i in range(5) if i%2==0]
```

Note that if statement is not a necessary component, so you can have list comprehensions with just for.

## 1.7. Functions

Functions allow compact structuring of sections of code that are intended to be used more than once in a program (or indeed multiple programs). A function in Python is defined by a `def` statement. In pseudocode, the general syntax looks like this:

```python
def function(arg1,arg2,arg3):
    body of code to be repeated
    return someval,someval
```

which takes input arguments `arg1`, `arg2`, and `arg3`, performs operation(s), and outputs variables `someval` and `some2`. As with control flows, the function definition is `followed by a colon`, and all code within the function is `indented` relative to the `def` statement. For simple functions the function can be returned in one line, e.g,

```python
def sum(x,y):
    return x+y
```

It is also possible to supply optional input arguments with default values, e.g., `z` in this example:

```python
def sum2(x,y,z=0):
    return x+y+z
```

whereby, it is possible to call the function either with, or without, z:

```python
a=5; b=10; c=20

sum_of_a_and_b=sum2(a,b)
sum_of_a_b_and_c=sum2(a,b,c)
```

Alternatively, it is possible to specify which exact optional arguments are required through the use of keywords (referencing the specific argument name in the function call):

```python
def sum3(x, y, z1=0, z2=0):
    return x - y + z1 - z2
```

```python
# apply function

a=5; b=10; c=20; d=30

a_minus_b=sum3(12,4)
a_minus_b_minus_d=sum3(42,15,z2=10)
a_minus_b_plusc_minus_d=sum3(42,15,z1=20, z2=10)
```

## 1.7.1 Docstrings

When writing code that includes functions, it is good practice to document the purpose of the function using a 'doc' string after the function definition, indicated by triple quotes.

```python
def arbitrary_sum(*x):
    """
    This function adds and an arbitrary number of input arguments

    input args:
        *x: a list or tuple containing numbers to be summed

    returns:
        mysum: result of adding all input arguments
    """
```

```python
mysum=0
for val in x:
    mysum+=val
    return mysum
```

## 1.7.2 Passing by object

In C++ you may have heard the terms 'pass by value' or 'pass by reference' with respect to how arguments are passed to functions. This references how variables are either copied to a new place in memory when they are passed to a function (pass by value) or whether their memory address is passed and shared with the function argument (pass by reference). In the former case, when the argument is changed within the function, the original variable remains unchanged. In the latter case, changing the value of the input argument will also change the value of the original variable.

In Python arguments are strictly 'passed by object', which means what happens to the variable within a function will depend on whether it is immutable or mutable. For immutable types (ints, floats, tuples, strings) the objects are immutable, hence they cannot be changed at any point whether they are in a function, or in the main body of code. Hence, in effect they will always be passed 'by value'. On the other hand if objects are mutable (lists, dictionaries) then the original values (in the main code body) can be changed if the variable is changed in place, for example:

```python
def passing_by_object2(names):
    # changed in place using the += operator:
    names
```
