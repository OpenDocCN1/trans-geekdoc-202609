These performance results were calculated for a binary classifier to detect heart failure (Sect. 4.1.3). For multi-label problems, as three-class heart-failure detection (Sect. 4.1.4), we can efficiently print recalls for all classes by

```
recalls = recall_score(y_train,y_pred_train, average = None)
print('recalls: ',np.around(recalls,2))
>>> recalls: [0.98 0.088 0.5]
```

We can quickly observe that the good accuracy of 29%, which we just calculated, does not reflect poorly sensitivity 0.5 for the detection of the severe heart failure, which means that we correctly identify only 50% of the severe cases.
