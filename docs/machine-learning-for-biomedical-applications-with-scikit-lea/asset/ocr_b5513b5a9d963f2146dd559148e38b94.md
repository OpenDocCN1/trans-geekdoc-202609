In all cases the function may take 0 or more input arguments, and may return 0 or more output arguments. For functions where it is not possible to prescribe an exact number of input arguments, arbitrary numbers may be defined using an asterisk:

```
def arbitrary_sum(*x):
    mysum=0
    for val in x:
        mysum+=val
    return mysum
```

mylist=[1,2,3,4,5]

```
sumlist1=arbitrary_sum(*mylist)
@ returns same result as
sumlist2=arbitrary_sum(1,2,3,4,5)
```

# 1.7.1 Docstrings

When writing code that includes functions, it is good practice to document the purpose of the function using a 'doc' string after the function definition, indicated by triple quotes.

```
def arbitrary_sum(*x):
    """
    This function adds and arbitrary number of input arguments

    input args:
        *x: a list or tuple containing numbers to be summed

    returns:
        mysum: result of adding all input arguments
    ""
```

```
mysum=0
for val in x:
    mysum+=val
    return mysum
```
