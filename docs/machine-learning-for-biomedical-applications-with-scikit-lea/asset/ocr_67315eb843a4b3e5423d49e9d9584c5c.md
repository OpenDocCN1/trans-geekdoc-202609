my_array=np.array([1,2,3,4,5,6])

And, it's also possible to define arrays that evenly sample within a range using np.arange([start], stop, [step]), e.g., np.arange(50,85) samples points in the range [50-80), in steps of 5. This function is commonly used in combination with loops. Note that, when sampling all integers from zero, only the end point of the range needs defined, e.g., np.arange(5) returns [0,1,2,3,4]. When, alternatively, seeking a number of values within a range, use np.linspace(start,end,num). Here, num determines the number of samples and the size of the spacing.

# Random number generation

NumPy also has a submodule np.random,¹ which creates arrays that follow specific random distributions, including uniformly distributed samples in the range [0,1).

```
rand1=np.random.random(3,3)
```

floats sampled from the standard normal distribution

```
rand2=np.random.randn(3,3)
```

and random integers in some range, e.g., [5,20):

```
rand3=np.random.randint(5,20,(3,3)
```

Note that in each the returned array has size 3 x3; however, the functions differ whether the shape is passed as a tuple or each dimension is passed as a separate argument.

# Loading from files

Often, data will come preformed and stored in text files. It is possible to directly load matrices and arrays from text files using theloadtxt function:

```
new_mat=np.loadtxt('matrix.txt',delimiter=',')
```
