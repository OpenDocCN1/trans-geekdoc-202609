The receptive field $f$ can vary (typically, odd numbers, e.g., $3 	imes 3, 5 	imes 5, 7 	imes 7$); however, the number of input channels must be equal to the output channels from the previous layer. The input layers might have 3 channels for a RGB image or 1 channel for a grey-scale image.

In the example CNN shown in Fig. 11.3, the first convolutional layer filters with dimension $1 	imes f$ since the image has one channel (we have not specified the receptive field $f$). It will learn 8 filters, corresponding to the number of output feature maps, together with 8 parameters. The second convolutional layer has 8 input channels and 16 output channels, so it will learn 16 filters of size $8 	imes f$ and 16 parameters.

This design results in a significant reduction of parameters compared to the fully connected layer. For example, using a receptive field 5 and excluding the bias parameters for simplicity, the first convolutional layer in Fig. 11.3 learns 8 filters of size $1 	imes 5 	imes 5$, resulting in $8 	imes 1 	imes 5 	imes 5 = 200$ parameters. Fully connected layers, however, would learn $1 	imes 64 	imes 8 	imes 64 	imes 64$ parameters (approximately 1.4 million) to connect all the pixels in the input and output feature maps.

# Convolutional layers in PyTorch

In PyTorch a 2D convolutional layer is implemented as

```
import torch
conv = torch.nn.Conv2d(in_channels = 1,
                              out_channels = 8,
                              kernel_size = 5)
```

We set the parameters to implement the first layer of Fig. 11.3, with one input channel, 8 output channels and a kernel size of $5 	imes 5$. This can be written in a shorter form as

```
conv = torch.nn.Conv2d(1,8,5)
```

We can now print the convolution layer that we defined as

```
print(conv)
>>> Conv2d(1, 8, kernel_size=(5, 5), stride=(1, 1))
```

We see that there is 1 input channel, 8 output channels and the kernel is $5 	imes 5$. Stride $1	imes1$ means that convolution will be applied to every pixel in the image, without skipping any. By default, the convolution filters also have a bias term and do not use any padding.
