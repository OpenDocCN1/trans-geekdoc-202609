Intuitively, we could think that larger number of features results in better prediction, but is this really the case? Let us revisit our dataset with brain structures calculated from 164 MRI scans (Fig. 3.1). The first dataset has a single feature, the second dataset six, and the third dataset eighty six features. Table 3.1 gives RMSE_train and RMSE_CV (in weeks) for these three datasets.

Table 3.1 Root-mean-squared error obtained by fitting regression model to the whole training dataset (RMSE_train) and using cross-validation (RMSE_CV).

| Number of features (weeks) | 1 | 6 | 86 |
|---|---|---||}{
| RMSE_train (weeks) | 1.56 | 1.12 | 0.68 |
| RMSE_CV (weeks) | 1.6 | 1.27 | 2.08 |

We can see that RMSE on the training dataset (RMSE_train) decreases with more features. However, this is not the case for RMSE_CV that has been calculated through cross-validation. The model fitted to six volumes with a single feature, the whole-brain volume. We judge this from the small error (RMSE_train) but large cross-validated error (RMSE_CV), which shows that the model does not generalize to unseen data. In fact, the model with 86 features has clearly overfitted to the noise in the data. We the more features we have, the more flexibility the model has because the number of parameters of the model (weights w) grows with the number of features. Multivariate linear regression with a large number of features is therefore prone to overfitting.

How do we decide many features D are optimal for our model? That depends on the number of samples N for training. The most error-prone part of the normal equation (Eq. 3.6) is inversion of the matrix XTX. The size of this matrix D+1 xD+1 is related to the number of features. Its rank also depends on the number of samples N is at most min(N, D+1) because the size of the matrix X is Nx+1. Therefore, if we have no more samples than features, N < D+1, the matrix XTX is not invertible, and there are many solutions that fit the training data exactly. In that case the scikit-learn object LinearRegression will select the solution with the smallest [w]. If the number of samples N is similar to the number of features D and N ≥ D+1, overfitting to noise is very likely. If N is much larger than D+1, the model is well conditioned, and the predictions generalize well.
