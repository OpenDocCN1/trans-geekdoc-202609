We can see that features selected by different models are very different from each other.
The features correlated with age at scan are frontal and GM on both sides of the brain, but only one of these has been selected by the other two models, perhaps because it made the other highly correlated features redundant. Generally, we see that GM volumes are most predictive of age at scan, though the model based selector also chosen CSF and RFE selector have chosen deep brain structures and caudate. Choosing complementary features turns out to be a good strategy; while selection of 4 features most correlated with age resulted in linear regression with CV RMSE 1.39, model based selection and RFE achieved better CV RMSE of 1.19 and 1.21 respectively (see Table 8.1).
