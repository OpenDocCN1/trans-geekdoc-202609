weights are passed to the weak learner for iteration, directing it to minimize the relative cost to that probability distribution—in other words, it will learn a weighted cost that will pay more attention to classifying higher weighted examples. After that, an error ($e$) is calculated over all the examples as a weighted sum, where $|f(x_i, 	heta) - y_i|$ will be 0, if the predicted $f(x_i, 	heta)$ has the same class as the true label ($y_i$), and will be 1. Therefore, there is zero contribution to the error of correctly classified examples, and the contribution from incorrectly classified examples is larger for examples that have been upweighted in previous rounds. Note that the error is never allowed to drop below 0.5 or 50% accuracy because this would mean it performs worse than random chance. If this occurs, the tree or stump is reset and a different learner is fit.

In the next step, the error is turned into a $eta_i$ value, bounded between 0 and 1, with smaller $eta_i$ corresponding to smaller error. This is used to re-weight examples for the next round of boosting. Counter to the example in Fig. 7.8, the actual effect is that since $|f(x_i, 	heta) - y_i|$ is 1 for incorrect predictions, which makes the exponent grow and reduces the $eta_i$ term to 1. This indirectly upweights misclassified examples, during probability estimation in the next round probability is estimated by normalizing over the sum of weights. The lower the overall error, the smaller the $eta_i$ and hence the more correctly classified examples for that are downweighted. Finally, at the end, the prediction for each example, is aggregated from the predictions across all base learners as a weighted majority vote.

Regression (Algorithm 7.3) [12] starts similarly but diverges at the point where the error is calculated. Typically a range of choices are offered for estimation of the loss including absolute error, mean squared error or exponential. An average loss is then estimated across training samples, and used to estimate the $eta_i$ parameter. Similarly to classification, the smaller the loss, the more the weight is reduced for the correctly predicted examples. The final prediction is calculated as a weighted median across all models in the ensemble.
