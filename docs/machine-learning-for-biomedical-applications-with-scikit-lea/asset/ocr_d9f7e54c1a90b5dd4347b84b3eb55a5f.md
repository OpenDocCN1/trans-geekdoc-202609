# 5.6. Manifold learning

In some circumstances, linear embeddings are insufficient to model the underlying distribution of the data. Take the toy example of Fig. 5.14. Here, a uniform distribution of points, originally generated in 2D (Fig. 5.14a), is subsequently rolled up into a 3D structure (Fig. 5.14b). We can see from points the black dashed arrow (Fig. 5.14b) that Euclidean distances shortcut between points that were originally distant on the plane. For instance, PCA and ICA embeddings will always fail to recover the data of nonlinearly distributed points: A 2D PCA embedding of the swiss roll dataset will severely collapse all points onto a plane that projects the points through the directions of variance through the data (Fig. 5.14c). What we need is to recover the geodesic distances (Fig. 5.14b (red dashed arrow)) that follows the curve of the manifold. Scikit-learn offers several approaches for this [2,3,11,39,46,47,51], each with slightly different techniques for approximating the underlying geodesic distances.^21 In this chapter, we will focus on Laplacian eigenmaps [2], which is known as spectral-embedding, which is one of the most intuitive to understand.
