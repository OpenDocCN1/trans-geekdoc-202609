# **Eigenvectors**

Going forward, we will see that, for PCA we always want *unit* eigenvectors. To normalize we first need to use the Pythagorean theorem for the magnitude of a vector. Specifically, the magnitude of $
u_1$ as shown in Fig. 5.5 is determined from $a = \sqrt{b^2 + c^2}$. For the previous example, where $
u_1 = \left(egin{matrix}1\0\end{matrix}ight)$ and $
u_2 = \left(egin{matrix}1\-1\end{matrix}ight)$, the magnitude in both cases is $\sqrt{2}$.^3$ Thus, the normalized eigenvector is

$
u_1 = \frac{1}{\sqrt{2}} \left(egin{matrix}1\1\end{matrix}ight),$  (5.31)

Following the same procedure$^4$ for eigenvalue $\lambda_2 = 1$ returns

$
u_2 = \frac{1}{\sqrt{2}} \left(egin{matrix}1\-1\end{matrix}ight).$  (5.32)
