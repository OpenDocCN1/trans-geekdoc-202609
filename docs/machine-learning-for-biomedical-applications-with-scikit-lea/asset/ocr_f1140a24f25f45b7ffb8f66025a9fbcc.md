```
from sklearn.datasets import make_moons
X, l = make_moons(n_samples=100, noise=0.05)
```

Next, we create the spectral clustering object. We set the number of dimensions of the nonlinear embedding using parameter n_components and the number of clusters (one each moon), using parameter n_clusters. To create the affinity matrix using kNN graph, we use parameter affinity='nearest_neighbors', and choose the number of nearest neighbors using n_neighbors:

```
from sklearn.cluster import SpectralClustering
model=SpectralClustering(n_components=3, n_clusters=2,
affinity='nearest_neighbors',
n_neighbors=5)
```

Finally, we fit the model, predict the labels, and show the clustered data:

```
y = model.fit_predict(X)
plt.plot(X[:,0][y==0], X[:,1][y==0],"r*"
plt.plot(X[:,0][y==1], X[:,1][y==1],"bo")
```

In scikit-learn we can also choose other types of affinity matrices to construct a Laplacian eigenmap. Symmetric k-NN graph is only one way to construct spectral embedding. The affinity matrix can be constructed from any measure of similarity between the pairs of samples. For example, Euclidean distances d between pairs of samples can be converted to similarities a using a Gaussian kernel

> a = e^{d^2}

This is implemented in scikit-learn

```
model=SpectralClustering(affinity='rbf', gamma=0.0001)
```

Finally, it is also possible to precompute the affinity matrix A and input it during fitting instead of the feature matrix X:

```
model=SpectralClustering(affinity='precomputed')
y = model.fit_predict(A)
```
