Given $x_i \in \mathbf{X}$ and $y_i \in \{0, 1\}$

Assign all $n$ examples equal weight $u_i^1 = 1/n$

```python
for $t$ in $E$ do
  $p \leftarrow w^t / \sum^n w^t$
  $f_t(\mathbf{X}, \theta) = \text{train\_stump}(\mathbf{X}, \mathbf{y})$
  $D \leftarrow |f_t(x_i, \theta) - y_i|$
  $L \leftarrow \sum^n p_i L_i$
  $\bar{L} = \sum p_i$
  $\beta_t \leftarrow 1/\bar{L}$
  $w_i^{t+1} \leftarrow w_i^t \beta_t^{1-L_i}$
end
```

- for each tree $t$ in the ensemble
- convert weights into probabilities
- calculate loss with $D$ as normalizing factor
- average loss
- update weights

Similarly to bagging, it is possible to pass any choice of base estimator, where the default is a decision tree with max_depth=1—in other methods, an axis-aligned decision stump. As before, the size of the ensemble is controlled by n_estimators.

## 7.2.11 GridSearchCV for ensembles

One point to be aware of, when optimizing model methods in scikit-learn, is the various ways in which parameters of their base models are passed to GridSearchCV. Normally, the grid search function to be optimized accepts parameter ranges in the form of a dictionary, where the argument is supplied as a dictionary key (i.e., see for the n_estimators parameter next). For base learners you additionally need to specify these arguments pre-fixed with the base_estimator__ keyword; this is shown subsequently for the min_samples_leaf parameter of a DecisionTreeClassifier, optimized as part of the bagging ensemble

## 7.2.2 Feature importance

Another aspect of tree-based ensembles is that they balance performance with interpretability very well. Since decision stumps make predictions by thresholding features, it becomes very easy to trace which features are most discriminative for a prediction simply by observing how each was used when training the ensemble. Such importance rankings are especially meaningful for biomedical problems, where it is vital that automated decisions are supported by clinically interpretable justifications. Knowledge of the most discriminative features for a problem can generate potential biomarkers of disease progression, or support the construction of mechanistic models of biological processes or the progression of disease. Importance rankings can also be used for feature selection in other models (see Chap. 8 for more details).

Scikit-learn calculates the importance of decision trees by calculating the degree to which each feature decreases the node impurity that is accumulated throughout the entire tree. Importance for ensembles therefore reflects the mean importance across all trees and can be retrieved from each model using the feature_importances_attribute of random-forest and boosting methods.

## 7.2.13 Heterogeneous ensembles

In contrast to homogeneous ensembles, heterogeneous ensembles stack predictions made from various classes of machine learning model. In principle, this allows for the leveraging of complementary advantages across various types of models, for example, combining linear and nonlinear models.

The basic framework of a stacking algorithm is shown in Fig. 7.10. Here, training X and labels y are passed to 3 different models—could be anything, e.g., a random forest, support vector machine or a logistic regression. Each model outputs a prediction: $\hat{y}^1$, $\hat{y}^2$, $\hat{y}^3$; these predictions form the data that is input to the second level (meta) learning model, which combines them to output a single final prediction $\hat{y}$. The meta model might be something as simple as majority voting but could equally be any other learning model (e.g., a second forest, SVM or logistic regression).
