### 5.3.1 Eigenvalues and eigenvectors

An eigenvector of a given linear transform is defined as a direction that remain unchanged (with the exception of a scale factor) following application of a linear transform. For example, observe the shearing operation shown in Fig. 5.4, the red vector (initially in the y direction) changes direction under the operation of the transform, whereas the yellow arrow (in the direction of the x axis) does not. In this case, the yellow vector is an *eigenvector*, and the degree to which an eigenvector $\mathbf{v}$ is scaled by a transform is represented by its *eigenvalue* ($\lambda$). We can represent this relationship in matrix form as

```
$$Av = \lambda v,$$
```

which presents a way to estimate the eigenvectors and values of $A$ by rearranging the equation, bringing everything to one side and extracting the common factor of $v^T$

```
$$Av - \lambda v = 0$$
```

$^1$ I represents the identity matrix.

$(\mathbf{A} - \lambda\mathbf{I})\mathbf{v} = 0.$

We enforce that $\mathbf{v}$ must be nonzero. This means that $(\mathbf{A} - \lambda\mathbf{I})$ must be singular, with the determinant equal to zero

$|\mathbf{A} - \lambda\mathbf{I}| = 0.$

This expression is known as the *characteristic equation*.

## Matrix determinant

A determinant is a scalar value, derived as a function of a matrix, that is nonzero only if the matrix is invertible and represents an isomorphic transformation (one-to-one) such that all points in the original domain are mapped to exactly one location in the second domain. For a $2 \times 2$ matrix $\mathbf{B} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$, the matrix determinant may be estimated as:

$det\mathbf{B} = |\mathbf{B}| = ad - bc.$

## Example: eigenvector calculation

To estimate the eigenvectors and eigenvalues of the horizontal scaling operation $\mathbf{A} = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}$, first substitute for $\mathbf{A}$ in the characteristic equation and calculate the determinant

$|\mathbf{A} - \lambda\mathbf{I}| = |\begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix} - \lambda \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}|,$

$= |\begin{pmatrix} 3-\lambda & 0 \\ 0 & 1-\lambda \end{pmatrix}| = 0,$

$= (3-\lambda)(1-\lambda) = 0.$

This tells us that the solutions (roots) are $(3-\lambda) = 0$ and $(1-\lambda) = 0$; thus, the eigenvectors of $\mathbf{A}$ are $\lambda_1 = 3$ and $\lambda_2 = 1$. Now, estimate the eigenvectors by substituting into Eq. (5.8) for $\lambda$, starting with $\lambda = 3$

$$\begin{pmatrix} 3-3 & 0 \\ 0 & 1-3 \end{pmatrix} \begin{pmatrix} \nu_1 \\ \nu_2 \end{pmatrix} = 0.$$

Multiplied out this gives

- $\rightarrow 0\nu_1 + 0\nu_2 = 0$
- $\rightarrow 0\nu_1 - 2\nu_2 = 0,$

which implies $v_2$ must be zero (since $2 \times v_2$ cannot equal 0, unless $v_2 = 0$). Thus, the eigenvector corresponding to $\lambda_1=3$ (defined up to an arbitrary scale factor $k$) is

```
$v = \begin{pmatrix} k \\ 0 \end{pmatrix} \quad (5.17)$
```

This represents a scale along the x-axis. Similarly, the eigenvector corresponding to eigenvalue $\lambda_1=1$ is estimated from

```
$$\begin{pmatrix} 3-1 & 0 \\ 0 & 1-1 \end{pmatrix} \begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = 0 \quad (5.18)$$
\rightarrow 2v_1 + 0v_2 = 0 \quad (5.19)$$
\rightarrow 0v_1 - 0v_2 = 0, \quad (5.20)$$
```

where Eq. (5.20) implies $v_1$ must be zero (from $2v_1=0$). Thus, the eigenvector corresponding to $\lambda_2=1$ represents a scale along y

```
$v = \begin{pmatrix} 0 \\ k \end{pmatrix} \quad (5.21)$
```

Since the eigenvalue = 1, this equates to a unit scale, resulting in the overall effect of stretch along x.

## Eigenvectors of symmetric matrices

If instead we have a matrix with an off-diagonal term, such as $\mathbf{A}_2 = \left(\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\right)$, the characteristic equation is expanded as

```
$$\begin{pmatrix} 2-\lambda & 1 \\ 1 & 2-\lambda \end{pmatrix} = (2-\lambda)(2-\lambda)-1=0 \quad (5.22)$$
\lambda^2-4\lambda+4-1=0 \quad (5.23)$$
\lambda^2-4\lambda+3=0 \quad (5.24)$$
$(3-\lambda)(1-\lambda)=0. \quad (5.25)$
```

Thus, once more, the eigenvalues are $\lambda_1=3$ and $\lambda_2=1$. For $\lambda_1=3$ the eigenvector can be calculated from

```
$$\begin{pmatrix} 2-3 & 1 \\ 1 & 2-3 \end{pmatrix} \begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = 0 \quad (5.26)$$
\rightarrow -v_1+v_2=0 \rightarrow v_1=v_2 \quad (5.27)$$
```

## Matrix diagonalization

We can see from Fig. 5.6 that this represents the same transformation as before (a stretch of 3 along one axis and 1 along the other) this time along the $\mathbf{v}_1 = \left(\begin{matrix}1&0\end{matrix}\right)$ and $\mathbf{v}_2 = \left(\begin{matrix}0&1\end{matrix}\right)$ axes. Thus, eigenvectors $\mathbf{v}_1, \mathbf{v}_2$ represent the same transform in a rotated coordinate basis. More specifically, it can be shown that the eigenvectors of any symmetric matrix $\mathbf{A}_2$ form an orthogonal basis from which the matrix may be diagonalized

> $$\mathbf{A}_2\mathbf{V} = \mathbf{\Lambda}\mathbf{V}$$
> (5.33)
> $\rightarrow \mathbf{V}^{-1}\mathbf{A}_2\mathbf{V} = \mathbf{V}^{-1}\mathbf{\Lambda}\mathbf{V}$$
> (5.34)
> $= \mathbf{\Lambda}$$
> (5.35)
> $= \mathbf{A}$$
> (5.36)

Here, Eq. (5.33) is a matrix equivalent of Eq. (5.6), the columns of $\mathbf{V}$ represent all eigenvectors of $\mathbf{A}_2$, and $\mathbf{\Lambda}$ is a diagonal matrix of all eigenvalues. For the example of this case, $\mathbf{A}_2 = \left(\begin{matrix}\frac{3}{2} & \frac{1}{2} \\ \frac{1}{2} & \frac{3}{2}\end{matrix}\right)$, $\mathbf{\Lambda} = \left(\begin{matrix}3 & 0 \\ 0 & 1\end{matrix}\right)$.
