# 3.2.4 Training penalized regression models in scikit-learn

In this section we will demonstrate how to tune hyperparameter λ for ridge regression. We first need to define a dictionary of values that we would like to try. We select 100 values for alpha on logarithmic scale between $10^{-3}$ and $10^{3}$:

```
params = {"alpha": np.linspace(-3,3,100)}
```

Next we search for optimal alpha using GridSearchCVCV, as already shown in Sect. 2.3:5:

```
from sklearn.linear_model import Ridge
from sklearn.model_selection import GridSearchCVCV

model = Ridge()
gcs = GridSearchCV(model, params, scoring="neg_mean_squared_error")

gcs.fit(X, y)
```

The optimal estimator_alpha can be found

```
gs.best_estimator_alpha
>>> 46
```

Because we use scoring="neg_mean_squared_error", cross-validated RMSE can also be extracted directly using

```
np.sqrt(-gs.best_score_)
>>> 1.17
```

The coefficients of the best model can be plotted as

```
plt.plot(gs.best_estimator_.coef_, '*')
```
