# 5.5.3 A mathematical definition

The assumption of ICA is that the available data (X_M) represents a mixture of source signals (S), with mixing coefficients **M**

X_M = MS. (5.57)

Thus, each sample from X_M is a linear combination of the n original source signals

X_M(t) = ∑ M S_i(t). (5.58)

The objective through ICA optimization is to learn the unmixing matrix W whose coefficients unmix the data X and recover the sources S

S = M⁻¹X = WX. (5.59)

This is achieved by assuming the source signals are independent and non-Gaussian.

# Why must signals be non-Gaussian?

Let's say our sources come from two mean-centered Gaussian signals with unit variance: S ~ N(0,1), i.e., S will have a circular distribution centered on the origin¹⁴
