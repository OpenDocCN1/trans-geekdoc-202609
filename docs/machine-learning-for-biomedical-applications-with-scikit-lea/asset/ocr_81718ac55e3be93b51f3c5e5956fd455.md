# 6.2. Gaussian mixture model

We now introduce another approach using the Gaussian Mixture Model (GMM). It models clusters as Gaussian distributions, and it is suitable for elongated clusters and has potentially nonlinear cluster boundaries. See 6.2, left is an intensity histogram of a T1-weighted MRI image. The peaks correspond to the mean intensities of WM, GM, and CSE. Note that nonbrain tissues have been removed and padded with zeros.

The key assumption of the Gaussian mixture model is that the feature values for each cluster are drawn from a Gaussian distribution. This is shown in 6.2. T1-weighted MRI intensities x for brain-tissue class k follow the Gaussian

```
$p(x|y=k) = G(x, \mu_k, \sigma_k^2) = \frac{1}{\sqrt{2\pi}\sigma_k} e^{-\frac{(x-\mu_k)^2}{2\sigma_k^2}}$
```
