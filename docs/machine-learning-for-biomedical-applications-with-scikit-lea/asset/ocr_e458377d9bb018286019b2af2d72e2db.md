# Create the model

Next, we choose the linear regression model:

```
from sklearn.linear_model import LinearRegression
model = LinearRegression()
```

Our model will be univariate because we have only one feature per sample, though scikit-learn implementation is suitable for any number of features. A univariate regression model is given by

> ŷ = w₀ + w₁x,

where x is the feature, y is the predicted target value, and w = (w₀, w₁) is is the parameter vector we want to fit the linear regression model.
