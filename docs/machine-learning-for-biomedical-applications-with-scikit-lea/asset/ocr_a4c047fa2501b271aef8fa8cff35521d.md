# 1.6. For statements

For loops iterate over a given sequence, for example, as given by a list:

```
mylist=[10,20,30,40,50]
```

```
for item in mylist:
    print(item)
```

For numeric ranges, Python provides function range(start,end,increment):

```
for item in range(0,10,2):
    print(item)
```

the previous loop would iterate over all values from 0, in steps of 2, up to but
including 10. It is also possible to have multiple for loops nested within each other,
for example

```

fruits = ["car", "dog", "bike"]

# for every item in the 'adj' list
```
