# 1.4. Control flow

Like many coding languages, Python offers a range of various types of statements which direct the flow of code, allowing loops, breaks, and conditional statements. In this book we consider `if`, `for`, and `while` statements, but they may also come across statements (which specify exception handlers and/or cleanup code) or with statements (which allow execution of initialization and finalization code, prior to running a code block). In Python, the flow of code is almost entirely controlled through code indentation (see Fig. 1.3). These signify that blocks of code belong to flow statements. To break out of a loop, however, all that is needed is to revert the code block inline with the previous block of code.
