# 1.2. Variable types and operators

In Python, with all programming, data typing is an important concept. Variables of different types have different properties, and each has its own set of functions, which do different things. In this section we will cover simple data types (numbers, strings and Booleans), as well as more complex data structures (lists, tuples and dictionaries). At the same time we work at a range of arithmetic (+, -, *,) and Boolean (and, or, not) operators.

# 1.2.1 Simple variable types

Numeric
The first group of variables is numeric data types. Python supports three types of numbers: integers (or whole numbers), floats (decimal numbers) and complex numbers. An example of assigning a variable integer value is:

```
myint = 5
```

Examples of float declarations are:

```
myfloat1=12.1
# casting an integer type as float
myfloat2=float(myint)
```

To verify what type a variable has, you can use the function type (e.g., type(myint)). Complex numbers will not be used in this course.

# Strings

Character strings are defined either with a single quote or a double quotes:

```
string1="a string"
string2='another string'
string2="Emma's string"
```

where, if you need a apostrophe inside, you must use double quotes on the outside.
