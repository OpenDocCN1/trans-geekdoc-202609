## 10.2.2 Training a multilayer perceptron in PyTorch

We will now show how to fit the perceptron model that we constructed in Sect. 10.1.4 to separate co-centric circles, as shown in Fig. 10.2, middle. First, we generate the dataset in scikit-learn:

```python
from sklearn.datasets import make_circles
X,y = make_circles(n_samples=500,factor=0.5,noise=0.08)
```

Next, we prepare the training data by converting them to PyTorch tensors of type float and reshaping it to 2D:

```python
import torch
X = torch.from_numpy(X).float()
y = torch.from_numpy(y).reshape(-1,1).float()
```

To perform training, we create a function train. First, we define the binary cross-entropy loss and stochastic gradient-descent optimizer. Note that if we use momentum, which allows us to increase the learning rate and train the network in as little as 100 epochs. The remainder of the training follows the same steps as previously shown for a single-layer perceptron. Finally, we call the function train to fit the network to the dataset X,y:

```python
def train(net, X, y):
    loss_function = nn.BCELoss()
    optimizer = torch.optim.SGD(net.parameters(),
        lr=2,
        momentum=0.75)

    epochs = 100
    for i in range(epochs):
        optimizer.zero_grad()
        prediction = net(X)
        loss = loss_function(prediction, y)
```

```python
loss.backward()
optimizer.step()
return net
```

## 10.2.3 Backpropagation

In this section we provide an in-depth mathematical explanation of the backpropagation algorithm. In Sects. 9.1.2 and 9.3.1, we have shown how the single-layer neural network can be trained in two steps—first predicting the outputs using the current estimate of the weights in the forward pass (Eq. (9.5)) and then updating the weights of the network (Eq. (9.6)) based on the errors between the predicted and desired outputs (Eq. (9.7) and (9.8)) in the backward pass. While expanding the forward pass to multiple layers is straightforward (Eq. (10.1) and (10.2)), the backward pass is slightly more complicated because the loss $L$ is directly calculated only from the errors in outputs $a_k^{(M)}$ of the final layer $M$. In order to calculate the gradients of the weights in all layers, we will backpropagate the output errors from the final layer $M$ to the lower layers.

### Backpropagation works

To calculate how the weights need to be updated to decrease the loss $L_i$ for a training sample $i$, we will keep track of the quantities $\delta_{ik}^{(l)}$ defined as the gradient of the $L_i$ with respect to the total input $z_{ik}^{(l)} = \sum_{j=1}^{D_{l-1}} w_{ji}^{(l)}\delta_{jk}^{(l-1)}$ of the neuron in layer $l$

(Eq. (10.1)):

```math
$$\delta_{ik}^{(l)} = -\frac{\partial L_i}{\partial z_{ik}^{(l)}}$$
```

The derivatives with respect to the weights $u_{jk}^{(l)}$ can be easily calculated using $\delta_{ik}^{(l)}$ using the chain rule:

```math
$$\frac{\partial L_i}{\partial u_{jk}^{(l)}} = \frac{\partial L_i}{\partial z_{ik}^{(l)}} \cdot \frac{\partial z_{ik}^{(l)}}{\partial u_{jk}^{(l)}} = \delta_{ik}^{(l)} \cdot d_{ij}^{(l-1)}$$
```

Once we have the weight gradients, we can update the weights using gradient descent (Eq. (10.7)) or another numerical technique, such as momentum. We will start the backpropagation by evaluating $\delta_{ik}^{(M)}$ for the last layer M:

```math
$$\delta_{ik}^{(M)} = \frac{\partial L^{(M)}}{\partial z_{ik}^{(M)}} \cdot \frac{\partial f_M}{\partial a_{ik}^{(M)}}$$
```

The value of $\delta_{ik}^{(M)}$ will depend on the choice of the loss function $L$ and the activation function $f_l$. For example, in the regression with sum of squared-errors loss and the identity activation, we might observe errors in the *predicted outputs* $\hat{y}_{ik} = a_{ik}^{(M)}$ compared to the expected outputs $y_i$:

```math
$$\delta_{ik}^{(M)} = a_{ik}^{(M)} - \gamma_i$$
```

Interestingly, the same result is obtained for the binary cross-entropy loss and the sigmoid activation. For more details on how to calculate these derivatives, refer to Sect. 9.1.2.

We will now show how we can backpropagate the output errors $\delta_{ik}^{(M)}$ into the other layers. We will use the chain rule to express $\delta_{jk}^{(l)}$ as follows:

```math
$$\delta_{jk}^{(l)} = \sum_{k} \frac{\partial L_i}{\partial z_{ik}^{(l+1)}} \cdot \frac{\partial z_{ik}^{(l+1)}}{\partial z_{jk}^{(l)}} = \sum_{k} \delta_{ik}^{(l+1)} \cdot f'_{l+1}(z_{jk}^{(l+1)})$$
```

where $f'_{jk}^{(l+1)} = \frac{\partial f_{l+1}}{\partial z_{jk}^{(l+1)}}$. We can therefore calculate the output errors $\delta_{jk}^{(l)}$ propagated to layer $l$ by summing up the output errors $\delta_{ik}^{(l+1)}$ weighted by the weights and the derivative of the activation for the layer $l+1$.

### **The training algorithm**

Training of the neural network can be summarized as follows:
each iteration $n$ and for each sample $i$:

1. Forward pass: Using current estimated weights $w_{jk}^{(L,n)}$, predict the activations $a_{jk}^{(L,n)}$ for sample $i$, starting from the first layer

```math
$$a_{ik}^{(L,n)} = f_l^{(L)} \left( \sum_{j=0}^{D_l} w_{jk}^{(L,n)} x_{ij} \right) \quad (10.3)$$
```

and iteratively moving through the layers $l = 2, \dots, M$

```math
$$a_{ik}^{(L,n)} = f_l^{(L)} \left( \sum_{j=0}^{D_l} w_{jk}^{(L,n)} a_{ij}^{(L-1,n)} \right) \quad (10.4)$$
```

2. Output errors: Calculate the output errors $\delta_{ik}^{(M,n)}$

$\delta_{ik}^{(M,n)} = a_{ik}^{(M)} - y_{ik}$ for standard regression and binary classification.

3. Backward pass: Moving backwards from layer $M$ towards layer 1,

- calculate the propagated errors $\delta_{ij}^{(l,n)}$

```math
$$\delta_{ij}^{(l,n)} = \sum_{k=1}^{D_{l+1}} \delta_{ik}^{(l+1,n)} f_{l+1}'(a_{ik}^{(l+1,n)}) \quad l = M-1, \dots, 1; \quad (10.5)$$
```

- calculate the derivatives with respect to the weights $w_{jk}^{(l,n)}$

```math
$$\frac{\partial L_i}{\partial w_{jk}^{(l,n)}} = \delta_{ik}^{(l,n)} \cdot a_{ij}^{(l-1,n)} \quad l = M, \dots, 1; \quad (10.6)$$
```

4. Update network weights using the gradient-descent equation (Eq. (3.8)) (or similar):

```math
$$w_{jk}^{(l,n+1)} = w_{jk}^{(l,n)} - \eta \frac{\partial L_i}{\partial w_{jk}^{(l,n)}} \quad (10.7)$$
```

The weights of the network $w_{jk}^{(l,n)}$ are initialized to small random values to ensure that neurons in each layer learn different information.
