return data

Let's describe in detail what each member set_type with values 'train', 'val' or 'test':

+   - __init__ takes an input parameter set_type with values 'train', 'val' or 'test', and depending on which set we want to create, it will assign a start index self.start_idx and the number of samples self.len for this particular set;
- __len__ returns length of the data set saved in self.len;
- __get_item__ loads the image and the segmentation for the subject idx from the disk, processes them and converts them to a required format. The images are normalized to the range [0, 1], and the cortex label is extracted from the segmentation image.
