## 1.1.4 Writing your first Python program

The simplicity of Python is never better demonstrated than through the well-known 'Hello World' example. Specifically, to print 'Hello World' in Python you need the function:

```python
print("Hello World")
```

This can be entered into a console and run directly, or saved in a hello.py file for running from an editor or command line. By contrast, performing the same action in C++, requires several more lines of code, and importing standard libraries:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!";
    return 0;
}
```

More fundamentally, C++ code will not run until it has been compiled.

### Conditional (if) statements

In its simplest (pseudocode) code, an if statement in python looks like this:

```python
if condition:
    statement
    statement
```

The conditional statement must evaluate to a boolean (True/False) but otherwise there are few constraints, examples include:

```python
if weight>=25:
    print("This person is overweight")

if name=="John":
    print("This person's name is John")
```

All forms of conditional statement (described in 2.2. Introduction to Type) may be used, using and and/or statements e.g.


## 1.2 Variable types and operators

In Python, with programming data typing is an important concept. Variables of different types have different properties, and each has its own set of functions. In this section we will cover simple data types (numbers, strings and Booleans), as well as more complex structures (lists, tuples and dictionaries). At the same time we work at arithmetic (+, *) and Boolean (and, or) operators.

### 1.2.1 Simple variable types

The first group of variables is numeric data types. Python supports three types: integers (whole numbers), floats (decimal numbers) and complex numbers. An example of assigning a variable value is:

```python
myint = 5
```

Examples of float declarations are:

```python
float1=12.1
float2=float(myint)
```

To verify what a variable has, you can use the type function (e.g., type(myint)). Complex numbers will not be used in this course.

### Strings

Character strings are defined either with a single quote or double quotes:

```python
string1="a string"
string2='another string'
string2="Emma's string"
```

where, if you need an apostrophe inside you must use double quotes on the outside.

### Format strings

In some cases we will use printed statements with formatted output using the .format method for strings. Using this formulation, it is possible to cast different data types using the string while also truncating floats, for example

```python
print('var1: {}, var2: {}'.format('dog','cat'))
```

will return

```
var1: cat, var2: dog
Pi 3.4159
```

with general syntax `[argument]:[width][precision]` such that the example

```python
print('Pi is {:.8f}'.format(3.14159, 2))
```

returns

```
Pi is 3.14,
```

to two decimal places preceded by five spaces; since the format placeholder {:.8f} selects the argument relative to its position in the format string, i.e. 3.14159 is not 225; 8 is the formatted width (where the width is longer than the whitespace added in front); 2 is the number of decimal places; and f is the (float) type. Examples of other common types include d (signed integer) and s (string) type.

### Booleans

Booleans represent binary True or False statements. They may be returned from the bool(...) function or from Boolean operators (below). For the purpose of control flow (i.e. if statements), the following objects would be considered as False:

- integer or float zero (0 or 0.0)
- None
- empty lists, tuples, arrays etc. (e.g., (), [])

Every other output would be considered True.

## 1.2.2 Grouping structures

In addition to simple data types, Python provides a range of different structures for storing variables. The key types (ignoring arrays and matrices, for the time being) are lists, tuples and dictionaries. The most important differences to be aware of when reviewing these types of structures is whether they store objects in order, and whether they are mutable.

### Mutable and immutable objects

The definition of a mutable object is one that may be changed after creation. All built-in simple Python variables (int, float, strings, Booleans) are immutable and therefore fixed. This means that when a different value is assigned to a previously created variable, e.g.,

```python
my_var=5
my_var=7
```

the location in memory of these two instances of my_var will change, indicating that an entirely new variable has been created. This can be verified by running id(my_var) after each line of code.

For group structures, the impact of this property is more noticeable since an attempt to assign a new variable to any location in an immutable group structure, e.g.,

```python
my_tuple=(1,2,3)
# attempt to change the first item
my_tuple[0]=4
```

will cause Python to throw an error. The same thing happens if you try to assign a new character to an existing string.
