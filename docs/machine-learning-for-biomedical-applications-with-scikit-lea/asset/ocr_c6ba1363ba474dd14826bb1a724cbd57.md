# 1.4.2 Debugging

Exploring indentation errors provides a useful framework with to highlight Python exception handling and error messaging since, if the previous code example had contained errors been upon, accidentally deleting the indentation in the middle of the loop, the Python interpreter would have thrown an IndexError error (Fig. 1.4) highlighting the offending line, and the location within that line using the ^ symbol. In general, Python error messages should be fairly self-explanatory. However, sometimes you will come upon ones that you do not understand.
