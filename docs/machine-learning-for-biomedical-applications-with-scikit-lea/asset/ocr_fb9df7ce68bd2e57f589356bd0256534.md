E\Sigma^{-1}. Specifically, rewriting

```
$C_X = E\Sigma E^{-1} \rightarrow \Sigma = E^{-1}C_X E$
```

We want to learn the prewhitening P that transforms $X_C$ (as $Y = PX$) into a distribution where the data covariance matrix is diagonal and eigenvalues are 1 ($Cov(Y) = I$).

Prior to whitening, we know that $\Sigma$ multiplied by its inverse the identity ($\Sigma\Sigma^{-1} = I$), then we can define:

```
$$\Sigma^{-1}\Sigma = \Sigma^{-1}E^{-1}C_X E \rightarrow I = \Sigma^{-1}E^{-1}C_X E$.
```

Rewriting $\Sigma^{-1}$ as $\Sigma^{-1/2}\Sigma^{-1/2}^{16}$

```
$I = \Sigma^{-1/2}E^{-1}C_X\Sigma^{-1/2}$.
```

We need the covariance (rewritten in terms of $P$ and $X$) to be the identity:

```
$Cov(Y) = \frac{1}{n+1}PXX^TP^T = \mathbb{I}$,
```

and, both Eqs. (5.64) and (5.65) are equal to the identity, we can equate them:

```
$$\frac{1}{n+1}PXX^TP^T = \Sigma^{-1/2}E^{-1}C_X\Sigma^{-1/2}$.
```

Replacing $\frac{1}{n+1}XXT$ with $C_X$,

```
$PCP^T = \Sigma^{-1/2}E^{-1}C_X\Sigma^{-1}$
```

We can see from the symmetry on the left and right sides$^{17}$ this means that $P = \Sigma^{-1/2}E^T$ is premultiplied by $E$ in order to rotate data back to its original orientation. Thus, we define:

```
$P = E\Sigma^{-1/2}E^T$.
```

Thus, essentially whitening performs the transformations summarized in Fig. 5.11. First multiplication by $E$ rotates the data distribution into alignment with principal axes (decorrelating interactions between features (see Fig. 5.11b), the variance is squeezed along the dimensions where it is larger than one, and stretched along dimensions where it is less than one (see Fig. 5.11c). Then, data is rotated back to its original orientation.
