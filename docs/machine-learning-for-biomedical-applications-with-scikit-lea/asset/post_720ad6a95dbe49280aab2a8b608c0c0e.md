## 4.1. Classification basics

In this section we will introduce binary and multi-label classification techniques. We will look at perceptron and logistic regression models and discuss performance measures for binary and multi-label classifiers.

### 4.1.1 Binary linear classification

**Binary classifiers** predict two labels, usually 0 and 1, based on a $D$-dimensional feature vector $x = (x_1, \dots, x_D)^T$. The prediction is based on a **decision function**, which is the multivariate linear function

```
$h(\mathbf{x}) = w_0 + x_1w_1 + \dots + x_Dw_D$.
```

The decision boundary is defined by the decision function being equal to zero $h(\mathbf{x})=0$. The binary labels $\hat{y}$ are based on the sign of the decision function: If the value of the decision function is positive or zero, the predicted label is 1. If the value of the decision function is negative, the predicted label is 0.

```
$$\hat{y} = \begin{cases} 1 & \text{if } h(\mathbf{x}) \geq 0 \\ 0 & \text{if } h(\mathbf{x}) < 0 \end{cases}$$
```

We have already introduced an example of binary linear classification in Sect. 2.1.1. In this example we predicted whether the patient is healthy or has heart failure (mild or serious) from two features (EF and GLS), see Fig. 2.2. In Fig. 4.1 we visualize the decision function $h(\mathbf{x})$ for this example as a 2D plane embedded in 3D space. The decision boundary $h(\mathbf{x})=0$ is a 1D line, defined by the intersection.

### 4.1.2 Perceptron

The objective of binary classification is to find a decision function so that the resulting labels match the training labels as closely as possible. The perceptron achieves this by penalizing misclassified samples proportionally to the absolute value of the decision function:

```
$$\hat{\mathbf{w}} = \arg\max_{\mathbf{w}} \sum |h(\mathbf{x})|$$
```

![Figure 4.2](img/d2194c20ff50f47845dec7a9cb107.png)

### 4.1.3 Logistic regression

The sigmoid function converts the decision boundary into a probability. The perceptron algorithm is:

1. Pick a random training sample $\mathbf{x}$;
2. If $y_i=1$ and $h(\mathbf{x}) < 0$, update the decision function: $\mathbf{w} = \eta\mathbf{x}_i$;
3. If $y_i=0$ and $h(\mathbf{x}) \geq 0$, update the decision function: $\mathbf{w} = \mathbf{w} - \eta\mathbf{x}_i$.

The algorithm iterates until convergence. Parameter $\eta$ is the learning rate. Unlike for a perceptron, the convergence of the logistic regression is guaranteed.

Logistic regression uses the sigmoid function:

$$\sigma(h) = \frac{1}{1 + e^{-h}}$$

This is illustrated in Fig. 4.3. Logistic regression finds parameters $w$ of the decision function by minimizing the **cross-entropy** over the training labels $y_i$ and probabilities $p_i = \sigma(h(\mathbf{x}))$ for class 1:

![Figure 4.3](img/d2194c20ff50f47845dec7a9cb108.png)

To understand why the cross-entropy loss works, consider a simple sample with a training label $y_i$. If $y_i=1$, the penalty introduced by cross-entropy loss for this sample is $-\ln(p_i)$. This penalty is zero for $p_i=1$ and tends to infinity as $p_i$ approaches zero. By minimizing this penalty, we will ensure that the predicted probability of label 1 for this sample is high, as prescribed by the training label. On the other hand, if the training label is 0, the penalty $-\ln(1-p_i)$ will be zero if $p_i$ of class 1 is also zero and tends to infinity if it is close to 1.

In scikit-learn logistic regression is formulated and fitted as follows:

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X_train, y_train)
```
