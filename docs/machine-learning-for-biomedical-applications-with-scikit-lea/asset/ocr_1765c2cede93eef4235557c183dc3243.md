**L = D - A**, where **D** is the diagonal $degree$ matrix with number of nearest neighbours

The graph Laplacian has one eigenvalue for each connected component of the
graph. For this reason the smallest eigenvalue is always zero because there is at least
one connected component and the first eigenvector is excluded from the
embedding. In our example, we have two connected components in the graph.
The graph Laplacian therefore has two eigenvalues, but one of them is excluded.
The first embedded dimension therefore has zero eigenvalue and contains two discrete
values that identify the two moon-shaped clusters—see Fig. 6.4, right.

In Sect. 5.7 we have used the unnormalized graph Laplacian $L = D - A$. This is
suitable when degrees of the nodes of the graph (e.g., the number of edges in each
weighted graphs) are similar between the nodes. This is obviously the case
of kNN graph because each node has a degree of approximately k. When degrees of
todes vary, it is better to normalize the graph Laplacian, for example, by multiplying
it by the inverse of the matrix D**

**L = D^{-1}(D - A).**

# 6.3.2 Spectral clustering in scikit-learn

In scikit-learn the spectral clustering algorithm is implemented in the object
SpectralClustering. This object implements manifold embedding using a Laplacian
eigenmap with normalized Laplacian, followed by k-means clustering.
