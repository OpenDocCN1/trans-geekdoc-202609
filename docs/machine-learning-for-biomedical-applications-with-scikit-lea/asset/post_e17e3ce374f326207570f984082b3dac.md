
## 5.4.5 Implementing PCA in Python

Whether you implement PCA using the covariance method or SVD, implementation always starts in the same way: You must demean the data matrix. Following this, eigenvectors and eigenvalues are estimated using either SVD or the covariance method. Assuming the data matrix X has shape $(n_{examples}, n_{features})$ and we are interested in the covariance between features not examples, PCA may run from the following steps:

- 1. Mean center the data matrix $X_C = X - \bar{X}$ using numpy.mean. Make sure to specify which axis you want to average over (in this case you are looking for a mean value for each feature)
- 2. Estimate the principal components through either:
   - The covariance method:
     - Estimate the data covariance matrix using Eq. (5.38), implemented using numpy.matmul(...).
     - Estimate the eigenvector and eigenvalues of the covariance matrix using $\Lambda$, numpy.linalg.eig(...).
     - This will return unsorted eigenvalues ($\Lambda$) and eigenvectors (U).
     - Sort eigenvalues and eigenvectors into descending order using numpy.argsort.^{10}$
   - The SVD method:
     - Estimate the singular values and values using $U, \Lambda$, numpy.linalg.svd(...).
     - This will return left singular vectors (U), right singular vectors ($V^H^{11}$) and singular values ($\Lambda$)
     - calculate eigenvalues from singular values by implementing Eq. (5.55).

## 5.4.6 PCA for dimensionality reduction

For datasets that have more features than examples, the action of projecting all points onto their PCA components ($Y = X_C U$) reduces dimensionality automatically since the total number of nonzero components is at most equal to the smallest dimension of the data matrix (matrix rank $r \le min(n, n)$). Often, the rank of the data covariance matrix may be less as a result of correlation between features. For example, predicting neonatal brain age from the volume of various regions, where we have strong correlation in their trends of growth (Figs. 5.7a and 5.8a). A cumulative distribution of the PCA eigenvalues derived from the full set (Fig. 5.8b) shows that most almost all of the data variance can be described by just three eigenvalues. Thus, we could project $X_C$ onto three eigenvectors and still capture the most meaningful variation in the data. Although there is no strict guide, a good rule of thumb is to choose the set of PCA eigenvectors that represent significant proportion (e.g., 90%) of the total data variance.

> $^{10}$ numpy.argsort will return the indices that sort an array in ascending order. This can be used to permute the eigenvalue and eigenvector matrices.

> $^{11}$ Here, VH corresponds to $V^T$; columns of U and rows of VH are the singular vectors.

## 5.4.7 Implementing PCA in scikit-learn

As with all models, PCA object is straightforwardly implemented using a few calls to scikit-learn. The PCA object is derived from `sklearn.decomposition` and takes an optional argument `n_components`, which determines the number of components that are returned from the model. For example, fitting PCA to a randomly generated matrix of shape (10,2)

```python
from sklearn.decomposition import PCA
import numpy as np
```

```python
# creating a random matrix of shape (10,2)
random_data=np.random.uniform(0,10,(10,2))
```

```python
# instantiate model
model=PCA(n_components=2)
# fit the model
# note PCA is unsupervised (only Features for fitting!)
model.fit(random_data)
```

```python
# or simultaneously fit the model
# and use it to transform the data
projected_data=model.fit_transform(random_data)
```

Key attributes that can be returned from the PCA model include:
model.explained_variance_ratio_, which returns explained variance (lambdas) as a proportion of total variance; model.singular_values_, which returns the singular values; and model.components_, which returns the PCA components.

## 5.5 Statistical independence

To fully understand what it means to extract ‘independent’ signals, we must first revise probability. Consider the table shown in Fig 5.9. This simulates the outcome of a survey of 100 people. Here, participants were asked whether they were suffering from any of the illnesses: Cancer (C), Heart disease (H), Diabetes (D), Mental health (M), or none of the above (N). The responses were grouped by age bracket (<20 years, 20–40 years, 40–60 years, 60–80 years, >80 years). The sum of all values in the table adds up to 100.

Let's say that we are interested in the marginal probability of selecting a participant from a specific age bracket. This can be written in general terms as $P(age_c) = \frac{r_c}{n}$, i.e., the marginal probability of any age in the row $r_c$ as a fraction of all participants. For the probability of selecting a participant under 20, we therefore have $P(c < 20) = \frac{2+1+3+5}{100} = \frac{11}{100}$ (Fig. 5.9b (orange row)). If we are interested in the marginal probability that an individual suffers from heart disease, we instead need the column total (Fig 5.9c); $P(H) = \frac{1+3+4+8}{100} = \frac{16}{100}$.

Joint probabilities summarize the chance of two events co-occurring. For example, if we want the joint probability that an individual aged 60-80 with mental health illness, we need the total from the cell at intersection of these two events: $q$ (shown in Fig 5.9d). The joint probability is then the value divided by the total number of samples: $P(60 -80, M) = \frac{4}{100}$.

Finally, conditional probability measures the probability of one event given another. For example, to calculate the probability of an individual suffering from mental illness given they are 20–40, it is first necessary to take the subset of examples corresponding to participants of age 20–40 (Fig. 5.9e highlighted in orange) and then estimate the proportion of examples that have mental health illness relative to the row: $r_c$. Hence $P(M|20-40) = \frac{6}{30} = 1/5$. If our interest was to include the conditional probability of status, we would express the conditioning as the cell total relative to the column total, e.g., $P(20-40|M) = \frac{6}{20}$.

Independent variables for which one gives us no information of the value of the other. In the case of mental health and age groups, we can see that the marginal probabilities of selecting an individual with mental health illness irrespective of age group are $P(M<20) = P(M|20-40) = P(M|40-60) = P(M|60-80) = P(M>80) = 1/5$. Further, the marginal probability of selecting an individual with mental health illness irrespective of age (Fig. 5.9f (blue column)) is $P(M) = \frac{20}{100} = 1/5$.
