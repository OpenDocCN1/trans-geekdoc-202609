```
from skimage.feature import graycomatrix
glcm = graycomatrix(image, [3], [0], 64)
```

Note that the variable image should be of type 'uint8' or 'int8' so that it contains a small number of discretized levels. The second input argument is the distance between neighboring pixels, in this case 3, and the third argument is the direction, in this case x-direction (0 rad) will therefore produce a matrix similar to Fig. 8.2, left. Final argument is the number of discretized intensity levels, in this case 64, which means levels 0, ..., 63.

The statistical measures of GLCM can be calculated using command

```
from skimage.feature import graycoprops
c = graycoprops(glcm, 'contrast')
```

In this case we calculated the contrast measure, but all the other measures listed be obtained in a similar way.
