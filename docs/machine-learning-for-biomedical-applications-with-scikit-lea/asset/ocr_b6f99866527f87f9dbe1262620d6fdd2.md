# Test error

Now we are ready to calculate the error on the test set. As we already prepared the dataset and the evaluation function, this is very simple:

```
rmse_test = RMSE(net,X_test,y_test)

>> Test RMSE: 0.74
```

The error 0.74 weeks (5 days) on the test set is lower than the validation error (6 days), which is a good sign. We can conclude that, in spite of overfitting, the network still generalizes to the unseen data and can predict the age of the baby with an error of less than one week.
