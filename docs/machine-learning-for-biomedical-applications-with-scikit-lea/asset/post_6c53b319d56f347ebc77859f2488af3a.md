## 11.4. CNN segmentation for medical images

Segmentation is a very important task for processing of medical images. It enables extraction of quantitative measures, such as volumes of brain structures or indices of cardiac function, including ejection fraction and global longitudinal strain, which we have used in the previous chapters. Training convolutional neural networks for medical image segmentation, however, comprises unique challenges. Medical images are 3D, with hundreds of thousands or even millions of voxels. On the other hand, training data is very difficult to obtain because manual segmentation of these large 3D images are time-consuming. Therefore, the segmentation networks often need to be trained with a small number of segmented images, with data sets including hundreds or even tens of samples.

In spite of these challenges, CNN segmentation has been extremely successful in medical imaging, due to specific approaches to deal with smaller datasets. These include:

- using smaller networks with fewer layers and weights;
- data augmentation, where the dataset is labeled by random spatial and intensity transformations [35,38];
- employing encoder-decoder architectures, that reduce network overfitting [38].

In this final section of the book, we will implement a CNN to segment cortex in neonatal MRI. But extension to multi-label segmentation is straightforward. The solution is based on encoder-decoder network called U-Net [38], called after its U-shape architecture (Fig. 11.9), or mTNet, consistently outperforms other architectures for medical image segmentation [23].

![](img/d219b4c20ff50f4b97845dec7a9acecb_273_0.png)

**Figure 11.9** U-Net architecture.

The convolutional neural network consists of an encoder and a decoder. The encoder reduces the spatial resolution while increasing feature depth, and the decoder restores the spatial resolution to the original size.

### Encoder

The first convolutional block of the encoder (blue arrow) extracts 8 low-level feature maps from the input and uses ReLU function to produce activation maps.

```python
import torch.nn as nn
conv1_down = nn.Conv2d(1,8,3,padding=1)
ReLU = nn.ReLU()
```

```python
enc1 = ReLU(conv1_down(im))
enc1.shape
>>> torch.Size([1, 8, 256, 256])
```

The encoder activations in the following blocks are obtained by downsampling using averaging pooling, followed by a convolution to increase the number of features (red arrows). The second level activation maps enc2, obtained using the following, 16 channels and reduced spatial resolution 128 × 128:

```python
down = nn.AvgPool2d(kernel_size=2)
conv2_down = nn.Conv2d(8,16,3,padding=1)
enc2=down(enc1)
enc2=ReLU(conv2_down(enc2))
enc2.shape
>>> torch.Size([1, 16, 128, 128])
```

Obtaining the third-level encoder activation maps enc3 is analogous to the second level, resulting in 32 channels and resolution 64 × 64:

```python
conv3_down = nn.Conv2d(16,32,3,padding=1)
enc3=down(enc2)
enc3=ReLU(conv3_down(enc3))
enc3.shape
>>> torch.Size([1, 32, 64, 64])
```

For the fourth-level encoder activation maps, we opt not to increase the number of channels to keep the network small, enc4 with 32 channels with spatial resolutions 32 × 32:

```python
conv4 = nn.Conv2d(32,32,3,padding=1)
enc4=down(enc3)
enc4=ReLU(conv4(enc4))
enc4.shape
>>> torch.Size([1, 32, 32, 32])
```

### Decoder

```python
up = nn.UpsamplingBilinear2d(scale_factor=2)
conv3_up = nn.Conv2d(32+32,16,3,padding=1)
```
