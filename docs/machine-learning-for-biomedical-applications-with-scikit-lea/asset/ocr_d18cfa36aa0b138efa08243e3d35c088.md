# Training

The training of the network is performed through a predefined number of iterations called epochs. During each epoch, we update the network using gradient descent. The following code shows how training is implemented. For our simple case of linear regression, we perform the training in a loop with 10 epochs:

```
epochs = 10
for n in range(epochs):
    # 1. Clear gradients
    optimizer.zero_grad()
    # 2. Forward pass: predict outputs
    prediction = net(X)n    # 3. Compute loss
    loss = loss_function(prediction, y)
    # 4. Backward pass: calculate gradients
    loss.backward()
    # 5. Update network parameters
    optimizer.step()
```

In step 1, the gradients are set to zero. In step 2, the forward pass predicts the outputs $\hat{y}^{(n)}$ (Eq. (9.5)). In step 3, the MSE loss between the true and predicted targets is calculated using Eq. (9.3). In step 4, the backward pass calculates the gradients of the MSE loss (Eq. (9.7)). Finally, in step 5, the network parameters $\theta_{ij}$ are updated using Eq. (9.6).
