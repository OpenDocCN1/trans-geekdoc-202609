# 3.3.2 Kernel trick

# Dual representation

An alternative way to turn a linear model into a nonlinear one is to use the **kernel trick**. First, we will change the parameters of our model **w** to a **dual representation** a defined as

```
w = \Phi^T a.
```

Let us now find out what this representation means. First of all, the weight vector **w** has dimension $D$, which is the number of features. The feature matrix $\Phi$ is $D 	imes N$, and therefore dimension of the dual representation a is $N$, with one parameter $a_i$ per **sample**. Let's now have a look at the new regression model

```
\hat{y} = \phi(\mathbf{x})^T\mathbf{w} = \phi(\mathbf{x})^T\Phi^T a = \sum_{i=1}^{N} \phi(\mathbf{x})^T\phi(\mathbf{x}_i)a_i.
```

The regression model then becomes a linear combination of **kernels** $\kappa$

```
\kappa(\mathbf{x}, \mathbf{x}_i) = \phi(\mathbf{x})^T\phi(\mathbf{x}_i)
```

that define the **similarity** between two feature vectors. In this case we calculate a similarity between a training sample $\mathbf{x}_i$ and a new sample $\mathbf{x}$ for which we would like to evaluate the model. The most common choice for the kernel $\kappa$ is the **Gaussian kernel**:

```
\kappa(\mathbf{x}, \mathbf{x}_i) = \exp(\left(\frac{|\mathbf{x}-\mathbf{x}_i|_2^2}{2\sigma}\right).
```

where $|\mathbf{x}-\mathbf{x}_i|_2 = \sqrt{\sum_{j=1}^{D}(x_j-x_{ij})^2}$ is the Euclidean distance between two feature vectors. The Gaussian is shown in Fig. 3.9. Note that pairs of features with larger distances have smaller similarity $\kappa$, while identical feature vectors have the largest similarity.
