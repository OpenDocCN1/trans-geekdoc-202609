# Prepare the data

The following code loads the breast-cancer dataset and extracts the feature matrix X of 30-dimensional feature vectors:

```
from sklearn import datasets
bc = datasets.load_breast_cancer()
X = bc.data
```

```
print('We have {} features.'.format(X.shape[1]))
>>> We have 30 features.
```

# Create the model

We will now the model for PCA with two principal components:

```
from sklearn.decomposition import PCA
model = PCA(n_components=2)
```

# Fit the model

After we fit the model to the training data, we are able to access the two principal component vectors as follows:

```
model.fit(X)
pcp1 = model.components_[0]
pcp2 = model.components_[1]
```
