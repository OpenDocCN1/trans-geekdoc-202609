# # Machine Learning for Biomedical Applications with Scikit-Learn and PyTorch

Machine Learning for Biomedical Applications is an easy to understand, interactive learning resource that applies machine and deep learning methods to biomedical engineering.

+   Key Features:
- Gives a basic understanding of the most fundamental concepts within machine learning and their role in biomedical data analysis.
- Shows how to apply a range of commonly used machine learning and deep learning techniques to biomedical problems.
- Develops practical computational skills needed to implement machine learning and deep learning models for biomedical data sets.
- Shows how to design machine learning experiments that address specific problems related to biomedical data

Machine Learning for Biomedical Applications with Scikit-Learn and PyTorch presents the machine learning techniques most used in a biomedical setting. It provides a practical and interactive way of learning, through short descriptions followed by solving simple examples using biomedical data. Interactive Python notebooks are provided with each chapter to complement the text and aid understanding.

This book provides self-contained material that will take a beginner from learning the basic Python commands, through classical Machine Learning in Scikit-learn, to the state-of-art Deep Learning in PyTorch. The first two chapters provide a practical Python and Scikit-learn tutorial. Chapters three to eight focus on in-depth description of popular machine learning techniques, such as Support Vector Machines and Random Forests. The last three chapters introduce the Deep Learning concepts and provide a PyTorch tutorial.

This accessible and interactive introduction to machine learning and data analysis skills is suitable for undergraduates and postgraduates in biomedical engineering, computer science, biomedical science, and clinicians.

About the Authors:

Dr Maria is is Lecturer in Medical Imaging at the School of Biomedical Engineering & Imaging Science at King's College London. Her research focuses on machine learning and image analysis of fetal and non-local MRI, with applications to brain development, preterm birth, congenital anomalies, and neurodevelopmental disorders. Her research group developed techniques for modelling of brain development using multi-modal MRI and deep learning embedding motion correction and localisation in fetal MRI (github.com).

Dr Emma C Robinson is Lecturer in Medical Imaging at the School of Biomedical Engineering & Imaging Science at King's College London. Her research focuses on the development of computational methods for brain image analysis, in particular applications of machine learning to build sensitive tools. She led the development and evaluation of the Multimodal Surface Matching (MSM) software for cortical surface registration. This is critical to developing the Human Connectome Project "of the Human Cortex" (Glasser et al., Nature 2010) and a central tenant in the HCP program for neuroimaging analysis (Glasser et al., Nature Science 2016).

Dr Deprez and Dr Robinson designed the popular Machine Learning modules for undergraduate students of Biomedical Engineering and postgraduate students of Healthcare Technologies at King's College London, on which this book is based. They also lead a research lab METRICS (metrics-lab.github.com)
