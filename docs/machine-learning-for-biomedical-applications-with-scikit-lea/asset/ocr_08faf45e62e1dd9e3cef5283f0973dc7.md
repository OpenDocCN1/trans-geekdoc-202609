We can observe that the accuracy on the test set is the same as the cross-validated accuracy on the training set, so the model generalized well on the unseen data. By analysis of the recalls, we can see that the ability of the classifier to identify mild heart failure (label 0) is better than for severe heart failure (label 1). This is not unexpected, as the class 1 is underrepresented, because only 20% of patients in the dataset have been diagnosed with severe heart failure.
