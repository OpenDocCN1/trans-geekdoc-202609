
## 7.1.2 Stacking stumps into trees

**7.4** presents a simple cartoon of a nonlinearly separable multiclass classification problem. Here, we have five classes: pink asterisks, yellow questions, red plus signs, blue crosses and dark green open circles. The objective is to separate these based on two features: $x_1$ and $x_2$. A decision tree may achieve this by stacking axis-aligned decision stumps after another. In this example, the root node splits on $x_1$ (orange dotted line). This broadly separates the blue crosses and dark green open circles, from red plus signs, pink asterisks and yellow question marks. In the second level (green dotted line), the second stump splits on $x_2$, splitting pink asterisks from yellow crosses. The final level (black dotted line), a second threshold on $x_1$ splits the red plus signs from the partitions. At this stage, each leaf in the tree is assigned a label, by the majority class of all training examples that reach that leaf. In this way, leaf nodes determine the prediction for each new example that reach that leaf at test time.

## 7.1.3 Decision tree learning rules

So, decision trees partition the feature space into distinct sections and assign each section a different prediction. But, how does the model decide which feature, and threshold, to make at each stage?

Like machine learning models, decision tree splits are parameterized via optimizing a cost function, where the appropriate choice of cost varies for classification and regression. Typical regression losses include those that we have seen before, specifically mean square error (MSE) and mean absolute error (MAE), where since trees a constant $y$ for each branch, this branches to the value that is, on average, closest to the ground truth values of the data points within that range.

Decision tree classifiers focus more on nodes of purity than accuracy scores or counts of false positives/negatives. Specific examples include:
- information gain, which represents the decrease in entropy obtained after a dataset is split on an attribute
- gini impurity, which reflects how the classes are following the split

Let's look at these in more detail, starting with a definition of entropy.

Entropy is an estimate of the amount of disorder in a system. It is calculated for decision tree classifiers, by considering the distribution of labels over all classes, at the node $j$:

$$H(S_j) = -\sum_{y\in Y} p(y_k) \log_2 p(y_k). \quad (7.1)$$

Here, $Y$ are the class labels (e.g., (0, 1) for a binary problem), and $p(y_k)$ is the proportion of examples that have class $k$, for the node under consideration $(j)$.

Calculating entropy for decision tree nodes acts as a proxy for how separated data examples are for split. For example, Fig. 7.6 demonstrates three class partitions, for a two-class classification problem. In the left case, the group contains 5 examples of each class, with $p(y_1)=p(y_2)=5/10=0.5$; this returns maximum entropy $H=(-0.5\log_2 0.5+0.5\log_2 0.5)=1$. The second group contains 2 circles and 7 signs, with proportions $p(y_1)=2/9$ and $p(y_2)=7/9$, with entropy $H=(-2/9\log_2 2/9+7/9\log_2 7/9)=0.764$. The third group only has signs, making its entropy zero. 

Information gain for a classification tree node is a measure of the change in entropy when data is split from the parent node into two children. It is estimated as the relative difference between the entropy of the parent and the children:

$$I(S_j) = H(S_j) - \sum_{i \in L,R} \frac{|S_i|}{|S_j|} H(S_i). \quad (7.2)$$

Here, $|S_j|$ represents the number of samples in the parent node, and $|S_i|$ represents the number of samples in each child node. Gini impurity is a simpler approach, it measures the probability of a randomly chosen element being incorrectly labeled if it was randomly labeled according to the distribution of labels in the set.

## 7.7 Example

Let's work through the simple example shown in Fig. 7.7. Here, a parent node with 14 circles and 9 plus signs (23 instances in total) is split into two nodes, with the first containing 10 circles and 2 plus signs, and the second containing 4 circles and 7 signs.

Before calculating information gain, we need to calculate the entropy of the parent and children using (7.1). This returns the entropy for the parent as

$$H(S_j) = -\left(\frac{14}{23}\log_2\frac{14}{23} + \frac{9}{23}\log_2\frac{9}{23}\right) = 0.966, \quad (7.5)$$

for child 1 as

$$H(S'_j) = -\left(\frac{10}{12}\log_2\frac{10}{12} + \frac{2}{12}\log_2\frac{2}{12}\right) = 0.650, \quad (7.6)$$

and child 2 as

$$H(S''_j) = -\left(\frac{4}{11}\log_2\frac{4}{11} + \frac{7}{11}\log_2\frac{7}{11}\right) = 0.946, \quad (7.7)$$

Applying (7.2), and inserting these values, returns an information gain of

$$I_{IG}(S_j) = 0.966 - \left(\frac{12}{23} \times 0.650 + \frac{11}{23} \times 0.946\right) = 0.174. \quad (7.8)$$

Here, $|S_j| = 23, |S'_j| = 12$ and $|S''_j| = 11$. Doing the same for Gini impurity instead implements

$$I_{gini}(S_j) = \frac{12}{23} \times Gini_1 + \frac{11}{23} \times Gini_2, \quad (7.9)$$
