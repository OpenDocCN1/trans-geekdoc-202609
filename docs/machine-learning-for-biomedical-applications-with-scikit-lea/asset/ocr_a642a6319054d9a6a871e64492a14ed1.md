the ensemble and aggregated using either majority voting (for classification) or averaging
(for regression).

def bootstrap_sample(dataset):
    """Sample from the dataset with
    replacement:
        input:
            dataset: shape (N,M)
        output:
            samples: shape (N,M)

# 7.2.5 Random forests

While bagging seeks to optimize uncorrelated models solely by training on different
bootstrapped samples from the data, random forests [5] further randomization
by presenting each node of the tree with a random subset of the total available features.
In this way, each decision stump is trained—without seeking the optimal feature
for that—forcing each tree to find several different solutions to each classification
problem, increasing randomization, and further reducing correlantions in the predictions across all trees. The overall effect is to reduce model
variance and the chance of overfitting. (see Sect. 7.2,8),
random forests always build ensembles of trees.
