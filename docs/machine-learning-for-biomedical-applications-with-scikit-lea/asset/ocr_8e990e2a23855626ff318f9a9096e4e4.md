We will also rename the negative label from 0 to -1. As before, we predict the label as 1 if the decision function is positive or zero, and -1 if it is negative:

```
$$\hat{y} = \begin{cases} 1 & \text{if } h(\mathbf{x}) \geq 0 \ -1 & \text{if } h(\mathbf{x}) < 0. \end{cases} \quad (4.4)$
```

The aim of the **hard-margin objective** is to keep the samples on or outside the margins on the correct side of the decision boundary, while keeping the margins as large as possible at the same time. This can be written as

```
$$\minimize \frac{1}{2}\mathbf{w}^\top\mathbf{w} \text{ subject to } y(\mathbf{x}) \geq 1 \text{ for } i=1,...,NN.$$
```

The objective **$\mathbf{w}^\top$** measures the squared magnitude of the slope of the decision function. Smaller slopes mean larger margins. Note the similarity to the ridge penalty. The quantity $y(\mathbf{x})$ is larger than 1 for a positive sample if $h(\mathbf{x}) \geq 1$, which ensures that the sample is on or outside the margin and correctly classified. For negative sample we have $h(\mathbf{x}) \leq -1$, which again means that it should be on or outside the margin and correctly classified.

The hard-margin objective can only be applied to separable problems and is very sensitive to outliers. Practical implementations therefore use the soft-margin objective that addresses these problems instead.
