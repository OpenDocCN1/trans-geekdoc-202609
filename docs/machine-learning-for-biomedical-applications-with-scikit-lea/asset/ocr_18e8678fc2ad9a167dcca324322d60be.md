![](bbox=[0.136, 0.093, 0.814, 0.245])

**Figure 5.11** Whitening works to transform data into a distribution with diagonalized, variance-normalized covariance (a) original data; b) data is rotated into alignment with the principal axes; c) variance in each axis is then normalized to one.

This transform can be used to generate a new orthogonal mixing matrix \hat{A}

```
Y = E\Sigma^{-1/2}E^T X
= ES\^{-1/2}E^T AS
```

where, orthogonality may be seen through the fact that \hat{A} is the whitened form of **A**. Whitening reduces the number of parameters that are to be estimated during ICA optimization, since all orthogonal matrices are symmetric, it is sufficient to estimate only the values of the upper or lower diagonal of the matrix. In some cases, it can also be useful to implement PCA based dimensionality reduction—throwing away all eigenvectors of $C_X$ with small eigenvalues—to reduce the impact of noise [21].

# ### 5.5.5 Implementing ICA in scikit-learn

Scikit-learn implements the FastICA [21], in a similar way to PCA (Sec. 5.4.7), namely,

```
from `sklearn.decomposition` import FastICA
```

```
# instantiate the model
model=FastICA(n_components=2, whitening='unit-variance')
# fit the model to data X and transform data
model.fit_transform(X)
```

Here, **n_components** and **whiten** are tunable parameters. The model is set to whitening by default. The class has attributes including `model.components_`, which returns the original source signals, and `model.whitening_`, which returns the whitening transform.¹18
