**Figure 11.2** Filtering using convolution. The filter is applied to all locations in the image, and the output intensity is calculated by weighted averaging the weights from the filter. The red square in the input image shows the position of the filter over location (3,5). The resulting value in the same location in the image is shown by a red square. Calculation of the output value is given.

mathematically written as

```
$$(w * x)_{ij} = \sum_{k=-s}^{s} \sum_{l=-s}^{s} w_{kl}x_{i+k,j+l}, \quad (11.1)$
```

where $s$ means the size of the kernel is $2s+1 \times 2s+1$. From this equation, we can see that for each location $(i,j)$ we overlap the kernel $\mathbf w$ over the image $\mathbf x$ and perform weighted averaging of the pixel intensities using the weights in the kernel. This process is illustrated in Fig. 11.2.
