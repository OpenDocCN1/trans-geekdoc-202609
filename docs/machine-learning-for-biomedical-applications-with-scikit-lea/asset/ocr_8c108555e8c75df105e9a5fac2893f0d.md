# Extending to higher dimensions

We can extend this process to higher dimensions by constraining the next choice of eigenvector to be orthogonal to $v_1^5$ This time, we need two Lagrange multipliers, $\lambda_2$ and $\phi$, where $\phi$ constrains the magnitude of the second eigenvector and 1 ensures that $v_2$ is orthogonal to $v_1^T v_2 = 0$,

```
$\mathcal{L}(v_2, \lambda_2, \phi) = v_2^T C v_2 + \lambda_2(1 - v_1^T v_2) - \phi v_2^T v_1$.\  (5.45)
```

Now, when taking the derivative with respect to $v_2$, and multiplying through by $v_1:

| $C v_2$ | $-\lambda_2$ | $-\phi v_1$ | $= 0$ | (5.46) |
| $v_1^T v_2$ | $-\lambda_2 v_1^T v_2$ | $-\phi v_1^T v_1$ | $= 0$ | (5.47) |
| $0$ | $-0$ | $-\phi v_1^T v_1$ | $= 0$ | (5.48) |

The first two must be zero, since by the orthogonality constraint $v_2^T v_1 = 0$, and since $v_1^T v_1 = 1$, Eq. (5.48) tells us that $\phi$ must be 0. This means all terms in $\phi$ must disappear, leaving us again with an eigenvector equation, this time for $v_2:

```
$C v_2 = \lambda_2 v_2$ (5.49)
```

# 5.4.3 Estimating PCA from the eigenvectors of the covariance matrix

Extrapolating across all dimensions, the matrix equation for eigendecomposition of $C$ can be written as $^6$:

```
$C V = \Lambda V$.  (5.50)
```

Here, $\Lambda$ is a diagonal matrix of eigenvalues

$\Lambda = \begin{pmatrix} \lambda_1 & 0 & \dots & 0 \ 0 & \lambda_2 & \dots & \vdots \ \vdots & \vdots & \ddots & \vdots \ 0 & 0 & \dots & \lambda_m \end{pmatrix}$ (5.51)

where eigenvalues represent the proportion of variance described by each corresponding eigenvector (or *principal component*). It is common practice to organize principal components in descending order of magnitude, such that $\lambda_1$ corresponds to the largest eigenvalue, $\lambda_2$ the second largest eigenvalue, all the way down to $\lambda_m$ (the smallest eigenvalue). When sorting eigenvalues, it is also important to preserve the columns of $V$ to preserve the correct relationship between eigenvalues and eigenvectors.

> $5$ Since covariance matrix is symmetric and thus eigenbasis is orthogonal.

> $6$ Where the specific order of matrix multiplication here is important.
