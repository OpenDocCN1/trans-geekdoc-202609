# Math operators

The basic math operators are: addition (+), subtraction (-), multiplication (*) and division (/). The modulus operator returns the integer remainder following division, for example: for a=9 and b=5, a%b=4. Using twice (**) results in the power operator, e.g., a**=5904. And the // operator means while division: //=1.

Note that operators also work on strings, lists, and dictionaries, for example, given two strings: string1='hello' and string2='5', adding (string3=string1+string2) returns 'hello5', multiplying (string4=string1*3) returns 'hellohellohello'. The same operations may be applied to lists such as:

```
list1=[1,2,3,4]
list2=[5,6,7,8]
list3=list1+list2
#or
list1+=list2
```

Using +=, -=, *= operators is simplifying operations that reduce the amount code needed, for a+=b. For mutable objects such as lists, this can be used to append additional items to an existing list. Whereas, for immutable numeric and string variables, the output will be a new variable in memory.

# Boolean operators

In contrast to math operators, Boolean operations always return either True or False. They are often used to define if and while control-flow statements (covered in Sect. 1.4). Examples include:

+   - exactly equals to: ==
- not equal to: :=
- inverse/opposite: not
- object identity: is or not
- comparisons: greater than >, less than <, greater than or equal to >=, less or equal to <=
- containment: not or in

Some examples of the use of Booleans on numeric types include:

```
a=10
print(a==10)
print(a<12)
print(a>20)
```

Using before a Boolean expression inverts:

```
a=10
b=12
print(not a==b)
```
