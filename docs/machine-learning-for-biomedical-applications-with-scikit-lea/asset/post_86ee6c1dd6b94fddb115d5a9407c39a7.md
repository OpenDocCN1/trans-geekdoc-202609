
We can minimize the log-likelihood by setting the derivatives with respect to the Gaussian mixture models to zero, and this way we will arrive at a two-step iterative algorithm. In the first step we calculate the posterior probabilities $p_k = p(k|x_i, \phi)$, which are in fact probabilistic segmentations for individual tissues (Fig. 6.3):

```
$p_k = \frac{\pi_k G(x, \mu_k, \sigma_k^2)}{\sum_{i=1}^N \pi_i G(x, \mu_i, \sigma_i^2)}$
```

In the second step we update GMM parameters $\phi$

```
$$\mu_k = \frac{\sum_{i=1}^N \pi_i x_i}{\sum_{i=1}^N \pi_i}, \quad \sigma_k^2 = \frac{\sum_{i=1}^N \pi_i (x_i - \mu_k)^2}{\sum_{i=1}^N \pi_i}, \quad c_k = \frac{\sum_{i=1}^N \pi_i}{N}$$
```

The algorithm iterates between these two steps until the change in the log-likelihood (En. (6.6)) is below a specified threshold.

## 6.3. Spectral clustering

Spectral clustering [49] allows us to correctly separate nonlinear clusters, such as the moon dataset from scikit-learn library. In Fig. 6.4, left, we can see that the GMM fails to separate the moons. To solve this problem, we can perform nonlinear manifold embedding and perform clustering in the embedded space.

### 6.3.1 Spectral clustering algorithm

Spectral clustering algorithm consists of two steps:
- 1. Perform nonlinear manifold embedding using eigenmap.
- 2. Perform clustering in the embedded space using k-means. This is described in Sect. 5.7.
