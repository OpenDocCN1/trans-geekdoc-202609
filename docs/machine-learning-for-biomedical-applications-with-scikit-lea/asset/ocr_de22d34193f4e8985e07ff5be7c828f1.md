# 3.3. Nonlinear regression

Linear regression models are not always appropriate since there might be nonlinear relationships between features and target values in the data. We have already illustrated this with the example of polynomial regression in Sect. 2.3 and 2.6. In Fig. 3.8 we plot the true GA of preterm babies GA predicted from the volumes of six brain structures. Note, we cannot easily plot the data and the model due to the high dimensionality of the features. In the case of ridge regression (Fig. 3.8, left), we can see that for younger babies the model does not fit well, which indicates the nonlinearity of the features.

In the following sections we will describe multivariate regression obtained using nonlinear feature transformation (Sect. 3.3.1) and the kernel trick for ridge regression (Sect. 3.3.2).

# 3.3.1 Nonlinear feature transformation

In Sect. 2.3 we have seen that polynomial regression can be viewed as a **nonlinear feature transformation** followed by multivariate linear regression. We will now generalize this approach to other nonlinear transformations and multivariate problems.

Nonlinear feature transformation $\phi$ is a nonlinear function of the original feature vector $x$. The dimension of the transformed feature vector $\phi(\mathbf{x})$ is often increased compared to $x$. For example, the univariate polynomial feature transformation of second-degree $\phi(\mathbf{x}) = (1, \mathbf{x}, \mathbf{x}^2)^T$ increases the dimension of the feature vector from one to three. For a two-dimensional feature vector $\mathbf{x} = (x_1, x_2)^T$, the polynomial feature transformation of second degree

```
$\phi(x_1, x_2) = (1, \sqrt{2x_1}, \sqrt{2x_2}, x_1^2, \sqrt{2x_1x_2}, x_2^2)^T$
```
