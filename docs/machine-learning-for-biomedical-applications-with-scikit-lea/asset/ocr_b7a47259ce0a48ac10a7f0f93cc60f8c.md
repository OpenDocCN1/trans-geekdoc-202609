# Binary classification in PyTorch

Similarly, for this we will also create an artificial neuron classifier that implements logistic-regression, but just like the linear regression, but
in addition to that we need a sigmoid activation function, which is available at torch.nn module as:
torch.nn.Sigmoid()

The activation function is added to the __init__ and forward functions:

```
class ANClassifier(nn.Module):
    def __init__(self):
        super(ANClassifier, self).__init__()
        self.layer = nn.Linear(2, 1)
        self.sigmoid = nn.Sigmoid()

def forward(self, x):
        x = self.layer(x)
        x = self.sigmoid(x)
        return x
```
