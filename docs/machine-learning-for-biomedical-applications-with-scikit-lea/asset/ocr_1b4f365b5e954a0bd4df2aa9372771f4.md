```
from sklearn.mixture import GaussianMixture

model=GaussianMixture(n_components=3)
model.fit(X)
m = model.means_
s = model.covariances_
w = model.weights_
```

We can then plot the weighted cluster likelihoods $ckp(y|k)$, depicted in Fig. 6.2, middle, as follows:

```
from scipy.stats import norm
x = np.linspace(X.min(),X.max(),100)
for i in range(3):
 l = w[i]*norm.pdf(x, m[i], np.sqrt(s[i]))
plt.plot(x,l.flatten())
```

The overall likelihood $p(X)$, displayed in Fig. 6.2 right, is our fitted Gaussian mixture model (Eq. (6.5)), and it can be evaluated using function `score_samples`

```
l = np.exp(model.score_samples(x.reshape(-1,1))
plt.plot(x,l)
```

Finally, we will show how to plot the probabilistic assignments $p_{ik}$, shown in Fig. 6.3, from the model using the function `predict_proba`:

```
p = model.predict_proba(X)
for k in range(3):
 pk = p[:,k]
post2D = np.zeros_like(T1)
post2D[ind]=pk
plt.subplot(1,3,k+1)
plt.imshow(post2D)
```
