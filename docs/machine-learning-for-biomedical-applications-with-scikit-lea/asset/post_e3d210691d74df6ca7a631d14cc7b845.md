## 5.4.1 Estimation of the data covariance matrix

The covariance matrix is a symmetric matrix whose entries represent the variance between elements of a data set, where elements we may interchangeably refer to the features of the data set or the examples themselves. For example, if we assume that our data set $\mathbf{X} \in \mathbb{R}^{100 \times 4}$ has 100 examples with 4 features, we can estimate the covariance between examples as

```
$$\mathbf{C} = \frac{1}{N-1}\mathbf{X}_C\mathbf{X}_C^T. \quad (5.37)$$
```

in this case Case $\mathbf{C}$ will have shape $100 \times 100$, or we estimate the covariance between features as

```
$$\mathbf{C} = \frac{1}{N-1}\mathbf{X}_C^T\mathbf{X}_C. \quad (5.38)$$
```

with shape $4 \times 4$. Importantly, in each instance we assume the data has first mean centered: $\mathbf{X}_C = \mathbf{X} - \mathbf{X}$, by subtracting either the mean per example (for Eq. (5.37)) or the mean per feature (for Eq. (5.38)). For dimensionality reduction, we are always interested in the latter, i.e., covariance between features. In this case, our covariance matrix looks like

```
$C = \begin{pmatrix} COV_{11} & COV_{12} & COV_{13} & COV_{14} \\ COV_{21} & COV_{22} & COV_{23} & COV_{24} \\ COV_{31} & COV_{32} & COV_{33} & COV_{34} \\ COV_{41} & COV_{42} & COV_{43} & COV_{44} \end{pmatrix} \quad (5.39)$
```

with variance of each individual feature ($COV_{11}, COV_{33}, COV_{44}, COV_{55}$) on the diagonal and covariances between different features ($COV_{12}, COV_{13}, COV_{14}, COV_{21}, ...$) stored on the off diagonal. In this representation, the variance estimates the spread of values along a single feature dimension, whereas covariance is a measure of shared information between features. The covariance matrix is symmetric, which means its eigenvectors form a new orthogonal basis set that better represents the variance features.

## 5.4.2 Deriving PCA

We know from trigonometry that the projection of data point $\mathbf{x}_n$ onto $\mathbf{v}_1$ may be estimated as $|\mathbf{x}_n|cos\theta$ and that scalar (dot) product of these two vectors is

```
$\mathbf{x}_n\mathbf{v}_1 = |\mathbf{x}_n|\mathbf{v}_1|cos\theta. \quad (5.40)$
```

Thus, by rearranging Eq. (5.40), we see that the dot product is equivalent to the scalar projection, provided that $|\mathbf{v}_1| = 1$,

```
$|\mathbf{x}_n|cos\theta = \frac{\mathbf{x}_n\mathbf{v}_1}{\|\mathbf{v}_1|}. \quad (5.41)$
```

Putting this altogether, for PCA we are seeking the direction $\mathbf{v}_1$ for which the variance across all projected data points is maximized. Assuming, that we first normalize our eigenvectors ($\mathbf{v}_1 = \mathbf{v}_1/|\mathbf{v}_1|$), we can represent the variance of projected points onto $\mathbf{v}_1$ as

```
$\frac{1}{N-1}(\mathbf{XC}\mathbf{v}_1)^T(\mathbf{XC}\mathbf{v}_1) = \mathbf{v}_1^T\mathbf{C}\mathbf{v}_1. \quad (5.42)$
```

To find the direction that maximizes the projected variance, we must take the derivative of the variance $\mathbf{v}_1$ w.r.t. $\mathbf{v}_1$. At the same time, we enforce a plausible solution by constraining the estimated eigenvectors to have unit magnitude. This constraint is implemented through the method of Lagrange multipliers:

```
$\mathcal{L}(\mathbf{v}_1, \lambda_1) = \mathbf{v}_1^T\mathbf{C}\mathbf{v}_1 + \lambda_1(1-\mathbf{v}_1^T\mathbf{v}_1). \quad (5.43)$
```

Optimizing for $\mathbf{v}_1,\mathcal{L}(\mathbf{v}_1, \lambda_1)=0$, then this reduces to

```
$\mathbf{C}\mathbf{v}_1 = \lambda_1\mathbf{v}_1. \quad (5.44)$
```

meaning that $\mathbf{v}_1$ must be an eigenvector of $\mathbf{C}$, where eigenvalue $\lambda_1 = \mathbf{v}_1^T\mathbf{C}\mathbf{v}_1$ equates to the magnitude of the variance along that direction.

## Extending to higher dimensions

We can extend this process to higher dimensions by constraining the next choice of eigenvector to be orthogonal to $v_1$. This time, we need two Lagrange multipliers, $\lambda_2$ and $\phi$, where $\phi$ constrains the magnitude of the second eigenvector and ensures that $v_2$ is orthogonal to $v_1^T v_2 = 0$,

```
$\mathcal{L}(v_2, \lambda_2, \phi) = v_2^T C v_2 + \lambda_2(1 - v_2^T v_2) - \phi v_1^T v_2. \quad (45)$
```

Now, when taking the derivative with respect to $v_2$, and multiplying through $v_1$:

| Term 1 | Term 2 | Term 3 | Result |
| :--- | :--- | :--- | :--- |
| $C v_2$ | $-\lambda_2$ | $-\phi v_1$ | $= 0$ (46) |
| $v_1^T v_2$ | $-\lambda_2 v_1^T v_2$ | $-\phi v_1^T v_1$ | $= 0$ (47) |
| $0$ | $-0$ | $-\phi v_1^T v_1$ | $= 0$ (48) |

The first two must be zero, since the orthogonality constraint $v_2^T v_1 = 0$, and since $v_1^T v_1 = 1$, Eq. (48) tells us that $\phi$ must be 0. This means all terms in $\phi$ disappear, leaving us again with an eigenvector equation, this time for $v_2$:

```
$C v_2 = \lambda_2 v_2 \quad (49)$
```

## 5.4.3 Estimating PCA from the eigenvectors of the covariance matrix

Extolating across all dimensions, the matrix equation for eigendecomposition of $C$ can be written as:

```
$CV = \Lambda V \quad (50)$
```

Here, $\Lambda$ is a diagonal matrix of eigenvalues

$\Lambda = \begin{pmatrix} \lambda_1 & 0 & \dots & 0 \\ 0 & \lambda_2 & \dots & \vdots \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \lambda_m \end{pmatrix} \quad (51)$

where eigenvalues represent the proportion of variance described by each eigenvector (or *principal component*). It is common practice to organize principal components in descending order of magnitude, such that $\lambda_1$ corresponds to the largest eigenvalue, $\lambda_2$ the second largest, all the way down to $\lambda_m$ (the eigenvalue). When sorting eigenvalues, it is also important to preserve the columns of $V$ to preserve the correct relationship between eigenvalues and eigenvectors.

## 5.4.4 Estimating PCA using singular value decomposition

Often the covariance matrix will not be of full rank (several eigenvalues will be zero). This is particularly likely to be the case when the matrix is estimated from nonsquare data matrices with high numbers of features. In these cases, computation becomes unstable, and it is better practice to implement PCA using singular value decomposition (SVD). SVD generalizes eigendecomposition to matrices of any shape. For example, for $X \in \mathbb{R}^{n \times m}$,

```
X = U\Sigma V^T \quad (52)$
```

SVD factorizes $X$ into $U \in \mathbb{R}^{n \times m}, V \in \mathbb{R}^{m \times m}$ and $\Sigma \in \mathbb{R}^{n \times m}$. Here, $U$ and $V$ are the left and right singular vectors, with component vector having unit magnitude and being orthogonal to one another; $\Sigma$ represents a rectangular diagonal matrix of singular values $(r_i)$. The maximum number of nonzero singular values is determined by the matrix rank $r \leq \min(n, m)$.

The relationship between PCA and SVD can be seen if we substitute $X$. Eq. (52) into our expression for the eigenvectors and values of our covariances:

```
$X_C X_C^T = U\Sigma V^T (U\Sigma V^T)^T U = U\Sigma V^T V\Sigma^T U^T = U\Sigma^2 U^T \quad (53)$
```

Thus, $U$ reflect the eigenvectors of data covariance matrix $X_C X_C^T$. $V$ represents the eigenvectors of $X_C^T X_C$.

```
$X_C^T X_C V = (U\Sigma V^T)^T U\Sigma V^T V = V\Sigma^2 V^T \quad (54)$
```

In both cases, covariance matrices share $r$ nonzero eigenvalues ($\Sigma \in \mathbb{R}^{r \times r}$), and these are related to the SVD singular values as

```
$\lambda_i = \frac{\sigma_i^2}{n-1} \quad (55)$
```
