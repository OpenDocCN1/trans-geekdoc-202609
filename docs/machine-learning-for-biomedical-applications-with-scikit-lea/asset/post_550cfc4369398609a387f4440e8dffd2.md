## 2.2.2 Classification in scikit-learn

We will now revisit the classification example of detecting heart failure using measures calculated from cardiac MRI or US images from Sect. 2.1.1, and visualized in Fig. 2.2. We will demonstrate how the prediction model can be fitted using the perceptron classifier. This section demonstrates the API of a classifier object in sklearn.

# Prepare the data

We will first import the data from a CSV file and check the column names:

```python
df = pd.read_csv('heart_failure_data.csv')
df.keys()
>>> Index(['EF', 'GLS', 'HF'], dtype='object')
```

Now, we are ready to create a feature matrix of 2-dimensional feature vectors with EF and GLS measures. We will also standardize both features to have a zero mean and unit variance across all the training samples. This is implemented in sklearn object StandardScaler. Scaling of the features is important for convergence of the perceptron classifier:

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
data = df.to_numpy()
X = scaler.fit_transform(data[::2])
```

The label vector will be HF which indicates diagnosis of heart failure.

```python
y = data[::2]
```

# Create the model

The following code creates the perceptron classifier:

```python
from sklearn.linear_model import Perceptron
model = Perceptron()
```

The perceptron model will find the decision function, which for our 2-dimensional features x = (x1, x2) takes the following linear form:

```
h(x) = w0 + w1x1 + w2x2
```

The predicted label is decided on the sign of the decision function

```python
\hat{y} = \begin{cases} 1 & \text{if } h(\mathbf{x}) \geq 0 \\ 0 & \text{if } h(\mathbf{x}) < 0 \end{cases}
```

The decision boundary is therefore defined by the decision function being:

```
w0 + w1x1 + w2x2 = 0.
```

# Fit the model

Just as linear regression, fitting the perceptron model means finding the weight vector w = (u0, u1, u2) that separates the two classes. This is achieved by minimizing the perceptron criterion

```
F(\mathbf{w}) = \sum_{i \in \mathcal{M}} |h(\mathbf{x}_i)|
```

where $\mathcal{M}$ is the set of all the misclassified samples. Note that for correctly classified samples there is no penalty and for misclassified samples the penalty is equal to the absolute value of the decision function for that sample. The criterion will be zero if all samples are correctly classified, and we will try to minimize misclassifications. The perceptron model is fitted by

```python
model.fit(X, y)
```

and the coefficients of the decision function can be accessed

```python
w0=model.intercept_[0]
w1=model.coef_[0][0]
w2=model.coef_[0][1]
```

Note that the perceptron intercept_ is a 1D array and coef_ is a 2D array. This is to support more than two classes, which require multiple decision boundaries. The decision boundary is therefore defined by the decision function being:

```
w0 + w1x1 + w2x2 = 0.
```

## 2.2.4 Dimensionality reduction in scikit-learn

We will look at principal component analysis (PCA) as an example of a dimensionality-reduction method. PCA seeks to find a predefined number of orthogonal directions, along which the data has the greatest variance. It orders these components according to the variance size and creates an orthonormal coordinate transformation to project the original feature vectors to the reduced dimensional subspace that preserves the most variance in the data. It is therefore considered a transformation, and PCA is a transformer object in sklearn.
