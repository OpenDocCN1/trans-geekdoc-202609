# 3.3.3 Exercises

+   1. The feature transformation to create linear regression is $\phi(x) = (1, x)^T$. Calculate the linear kernel using Eq. (3.20).

+   2. The feature transformation to create polynomial regression of second degree is $\phi(x) = (1, x^2)^T$. Calculate the second-order polynomial kernel using Eq. (3.20).

+   3. Given three training samples with feature matrix $\mathbf{X} = (-1, 0, 1)$ and target vector $\mathbf{y} = (2, 3, 2)^T$, Gaussian kernel with $\sigma = 1$ and $\lambda = 0$, calculate the dual representation a (Eq. (3.24)) to fit the ridge regression model. Evaluate the model for the new sample $x=0.5$ using Eq. (3.25).

+   4. Fit the scikit-learn ridge model and kernel ridge regression model with Gaussian kernel in scikit-learn to predict GAs from the volume of the cortex, the first feature given in the file 'GA-brain-volumes-6-features.csv'^5 Experiment with parameters $degree$, $gamma$, and $alpha$ to observe the effect.

+   5. Given three training samples with the feature matrix $\mathbf{X} = (-1, 0, 1)^T$ and target vector $\mathbf{y} = (2, 3, 2)^T$, Gaussian kernel with $\sigma = 1$, and $\lambda = 0$, implement the following in NumPy:
* Generate vector $\mathbf{x}$ of 100 samples in the interval $[-1.25, 1.25];
* Calculate and plot the kernels $(\mathbf{x}, \mathbf{x})$ (Eq. (3.21)) for these samples;
* Calculate dual representation a using Eq. (3.24);
* Calculate and plot the kernel ridge regression model using Eq. (3.25).

+   6. Fit the kernel ridge regression model in scikit-learn to predict GAs from six structure volumes available in 'GA-brain-volumes-6-features.csv'. Optimize the hyperparameters $\lambda$ and $y$ using `GridSearchCV`. Compare the cross-validated RMSE for kernel ridge and linear regressions.
