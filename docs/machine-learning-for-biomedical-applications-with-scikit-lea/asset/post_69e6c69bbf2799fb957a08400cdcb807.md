# Dimensionality reduction

Modern biomedical data sets are enormous. Consider, for a minute, just one single MRI brain scan, defined on a typical volumetric image grid. This has a resolution of 255 × 255 × 180. If we were to consider each data point as a separate feature, we would have over 11 million features per image. Similarly, genetic samples record millions of single nucleotide polymorphisms (SNPs) per image, and biometric devices (such as smart watches) record physiological measurements continuously. Add to this the fact that biomedical samples are challenging to acquire, and this means that the numbers of features often outstrip the numbers of examples. This is a problem because, with increasing dimensions, the same amount of data fills the space and more sparsely, making it easier to fit a separating hyperplane by chance, and in this way, overfit to noise in the training data. In this chapter, we look at techniques for addressing this through linear or nonlinear projection of the data.

## 5.1. The curse of dimensionality

To understand the risks associated with having more features than examples, consider the toy example shown in Fig. 5.1. This simulates the effect of classifying a fixed number of data points as the dimensionality of feature space grows. In this example, we have two classes, shown by red and green markers. Each point is randomly sampled from a normal distribution centered at 0.5, with equal variance for each group. Therefore, the groups should be non-separable. Fig. 5.1, however, shows a case where the classes are separable by chance.

In the top row, we can see that, in one dimension, both groups completely overlap, and classification accuracy is close to random chance (as would be expected). As the feature dimensions grow, the points spread out more, and the classification rates rise. As three dimensions, the classifier reports 75% accuracy. Clearly, the classifier is overfitting to the noise in the data, and this is getting worse as the dimensionality of the feature space increases.

## 5.3. Linear transforms

Before we consider nonlinear manifolds, let us start by considering linear embeddings constructed from linear transforms. Mathematically, a linear transform is a function that satisfies the properties of additivity and scalar multiplication, while preserving the origin

- additivity: $T(\mathbf{x}_1 + \mathbf{x}_2) = T(\mathbf{x}_1) + T(\mathbf{x}_2)$ (5.1)
- scalar multiplicity: $T(\alpha\mathbf{x}) = \alpha T(\mathbf{x})$ (5.2)

In simple terms, this means that linear transforms preserve the linear properties of the vector space. In other words, they map data points from one Euclidean domain to Euclidean subspace. Practically, the action of any matrix on a vector is a linear transform. For example, the action of $\mathbf{A} = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}$ represents a scale along the x-axis by a factor of 3 (see Fig. 5.3), as follows:

$$\begin{pmatrix} x' \ y' \end{pmatrix} = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} (5.3)$$

$$= \begin{pmatrix} 3x + 0y \\ 0x + 1y \end{pmatrix} (5.4)$$

$$= \begin{pmatrix} 3x \\ 1y \end{pmatrix} (5.5)$$
