## 6.1. K-means clustering

Clustering is an unsupervised machine-learning task, where training labels are not given. We therefore need to split the samples into groups according to some predefined criterion. One of the simplest ideas is that within-cluster variance $\sigma_W^2$ can be expressed as a sum of cluster variances $\sigma_k^2$ weighted by the size $n_k$ of the cluster $k$:

```
$$\sigma_W^2 = \sum_{k=1}^{N} \frac{n_k}{N} \sigma_k^2. \quad (6.1)$$
```

where $n_k$ is the number of samples in the cluster $k$, $K$ is the number of clusters and $N$ is the number of all samples.

### 6.1.1 K-means algorithm

So, can we minimize the within-cluster variance $\sigma_W^2$? First, let's write down the expression for variance of the cluster $k$:

```
$$\sigma_k^2 = \frac{1}{n_k} \sum_{i \in S_k} |x_i - \mu_k|^2$$
```

Note that $x$ is a multidimensional feature vector for sample $i$, $\mu_k$ is the multidimensional mean for the cluster $k$, and $|\cdot|$ denotes the Euclidean distance. If we expand the expression for $\sigma_k^2$ (Eq. (6.1)) it directly gives the variance of each cluster, we will see that within-cluster variance is actually an average squared distance of each sample to its cluster center:

```
$$\sigma_W^2 = \frac{1}{N} \sum_{i=1}^N |x_i - \mu_{y_i}|^2$$
```

where $y_i$ is the label assigned to the sample $i$. This intuitively gives an iterative algorithm to minimize the within-cluster variance. We will iterate between assigning the cluster with the closest feature mean each sample:

```
$y_i = \arg \min_k |x_i - \mu_k| \quad (6.2)$
```

and recalculating the means of the clusters:

```
$$\mu_k = \frac{1}{n_k} \sum_{i \in S_k} x_i \quad (6.3)$$
```

We start the process with random initialization of the cluster means $\mu_k$. Fig. 6.1 shows how this procedure finds the clusters of voxels by WM, GM, and CSF in T1- and T2-weighted MRI.

### 6.1.2 K-means in sklearn

We have already shown in Sect. 2.2.3 how to fit the scikit-learn kmeans model to one-dimensional segmentation problem. Here, we will expand it to 2D feature space. First, we will load the T1- and T2-weighted MRI slices:

```python
import matplotlib.pyplot as plt
T1 = plt.imread('T1.png')
T2 = plt.imread('T2.png')
```

Assuming that the brain tissues have been extracted and the nonbrain tissues padded by zeros, we identify all nonzero values:

```python
ind = T1>0
```

Next, we select all nonzero values and stack them into a N × 2 feature matrix:

```python
import numpy as np
X = np.stack([T1[ind],T2[ind]]).T
print(X.shape)
>>> (3180, 2)
```

The dataset can now be plotted as in Fig. 6.1 left:

```python
plt.plot(X[:,0],X[:,1],'bo')
```

We then fit the three-cluster kmeans model to the feature matrix X and predict the labels $y$:

```python
from sklearn.cluster import KMeans
model=KMeans(n_clusters=3)
model.fit(X)
y = model.predict(X)
```

The clustering result, similar to the one shown in Fig. 6.1, right, can be plotted as:

```python
plt.plot(X[y=0],X[y=0],'bo')
plt.plot(X[y=1],X[y=1],'g')
plt.plot(X[y=2],X[y=2],'rd')
```

### 6.13 K-means in NumPy

To further understand K-means algorithm, we will now show how to implement it in NumPy. First, we define the distance function that calculates distances of the samples from the cluster centers:

```python
def dist(k):
    return np.sum((X-mu[k])**2,axis=1)
```

Next, we randomly initialize the cluster means and iterate between calculating the labels $y$ (Eq. (6.2)) and the cluster means $\mu$ (Eq. (6.3)):

```python
mu = np.random.rand(3,2)
for i in range(10):
    y=np.argmin([dist(0),dist(1),dist(2)])
    mu[0]=np.mean(X[y==0,:]],axis=0)
    mu[1]=np.mean(X[y==1,:]],axis=0)
    mu[2]=np.mean(X[y==2,:]],axis=0)
```

Here, we used 10 iterations for simplicity, but we can instead stop the algorithm when the cluster means do not change any. We can then plot the means of the cluster clusters as:

```python
plt.plot(mu[:0],mu[:1],'y*')
```

## 6.2. Gaussian mixture model

We now introduce another approach using the Gaussian mixture (GMM). The key assumption of the Gaussian mixture is that the feature intensities follow a Gaussian distribution. Note that the Gaussian mixture is suitable for nonlinear feature boundaries. The T1-weighted MRI cells. The probability of an intensity value $x$ given class $k$ is:

```
$p(x|k) = \frac{1}{\sqrt{2\pi}\sigma_k} e^{-\frac{(x-\mu_k)^2}{2\sigma_k^2}}$
```

The overall image is drawn from a mixture of Gaussian distributions:

```
$p(x) = \sum_{k=1}^{K} \varrho_k G(x, \mu_k, \sigma_k^2) \quad (6.5)$
```

The coefficients $\varrho_k$ represent the proportion of samples assigned to class $k$ and they sum to one $\sum_{k=1}^{K}\varrho_k=1$. The cluster dependent conditional probability $p(x|k)$ and the overall image probability $p(x)$ of observing an intensity value $x$ are referred to as likelihoods.

### 6.2.1 GMM algorithm

The purpose of the GMM clustering algorithm is to fit the Gaussian Mixture Model (Eq. (6.5)) to the histogram of observed image intensities (Fig. 6.2, right). In others, we want to maximize the likelihood $p(X|\phi)$ of observing a particular set of image intensities $X = \{x_1, \dots, x_N\}$, given the parameters of GMM $\phi = \{\mu_k, \sigma_k, \varrho_k\}_{k=1}^{K}$.

If we assume the voxel intensities $x_i$ are independent of each other, we can multiply the individual likelihoods $p(x_i|\phi) = \prod_{i=1}^{N}p(x_i|\phi)$, which will change to the sum if we take a logarithm of this. By using (6.5), we get a sum of log-likelihoods of the individual voxels:

```
$$\phi = \arg \max \sum_{i=1}^{N} \log p(x_i|\phi) = \arg \max \sum_{i=1}^{N} \sum_{k=1}^{K} \varrho_k G(x_i, \mu_k, \sigma_k^2). \quad (6.6)$$
```
