
# 2020年第二届国际计算、通信、控制与网络进展会议 (ICACCCN) (印度大格诺伊达 2020.12.18-2020.12.19)

## 摘要

每个学生都梦想在离开大学前拿到工作录取。招聘指标帮助学生了解自身状况以及应该做什么以确保良好的选择。招聘预测器是一种可以预测处于招聘过程的学生概率或表现的设备。此类程序的使用有助于未来年的学术准备。随着数据挖掘和机器学习的兴起，各种模型被广泛应用；本文针对工程专业大四毕业生介绍了关于不同统计选择模型的文献综述，以便机构的招聘部门可以为当前学生建立招聘账户。

沿着这些思路，关注不同的招聘预测框架非常重要。本文概述了各种招聘框架及其对学生的应用。

**关键词**——数据挖掘，逻辑回归，决策树，随机森林。

## II. 文献综述

### A. 使用逻辑回归进行预测

根据统计数据，每年有 600万学生从计算机系毕业。对有技能和合格学生的需求日益增长。校内和校外招聘的人数巨大，但具备技能且合格的学生人数非常少。大学和工业界需要关注带给学生的真实知识的实际应用。招聘是学生生活中充分做好准备的最佳机会，而招聘预测器则帮助判断学生是否获得招聘。该系统还可以帮助识别学生需要参加招聘的领域。该系统使用学生的学术成绩、编码技能等详细信息。该系统使用往年的招聘统计数据和招聘失利等方面。

在模糊逻辑的帮助下，这种方法本质上是预测并将学生数据分解到定义的类别中，这对于公司分析海量学生数据集具有巨大的优势。

```
Logit(p) = \beta 0 + \beta X1 + \beta X2 + \beta X3
```

其中成功的概率为“p”。

本文中的方法 [3] 使用数据挖掘方法进行了详细阐述。创建“模糊逻辑和神经邻居”模型的方程是比该逻辑推理框架更合适的替代方案。“K 最近邻算法 (KNN)”是分类任务的典型近似，并根据分离步骤创建新案例。对效率和准确性的提高已通过可视化进行检查，并且在演示考试之前对每个模型进行了处理。

logit 过程被称为机会（注：此处原文为 opportunity，可能为误用或指 logit 转换过程）：

```
Logit(p) = \log(p/p-1)
```

- **整体拟合**：无效模型的可能性 - 2，当自主因素对结果影响很小时，LO 是导致产生估计的类别。
- **回归参数**：每个因素都与 `\beta` 系数相关。该系数衡量了逻辑系统中用于增加因子或独立变量的输入。添加的逻辑模型参数越多，产生的曲线越平滑。尺度范围在 0 到 1 之间。
- **最终处理**：最后，数据进入来自学生在线测试的逻辑模型。

使用算法来收集数据和制造所需的特征。通过 KNN 分析获得的一致性分别为 97.33% 和模糊逻辑下的 92.67%，依此类推，这比先前的分析更简单，如果使用 KNN 来预测招聘结果，将更加方便。

### B. 使用模糊方法进行预测

模糊推理是一种提供直接理解现实和伪值的哲学，这些属性的取值遵循与模糊逻辑相同的准则，这些建议可能表示为完整性和虚假状态。

与结果（1 或 0）或布尔逻辑相比，模糊思维的原则是处理真理寻求的方法。模糊逻辑是估计比例值逻辑在入学数组上的扩展，它将特征映射到模糊集合或选择模糊集合，这被称为模糊逻辑。

本文 [2] 的核心目标是使用模糊推理对学生数据进行排序选择，并估计申请人是否符合招聘条件。对于单一本科学年，其类别留了招聘和未招聘的间隔期。这些学生将在测量准备培训中获得更好的经验或良好的成绩 (GPA)，回校学生将参加额外的课程以提高他们的成绩。这种技术在任何时候都难以预见这两种情况。
