## 3.1 引言
物联网（IoT）在互联网和移动通信之后，带来了网络行业迄今为止最大的浪潮 \[[1](#Ch03.xhtml#ref3_1)\]。物联网指的是一个互联的设置 \[[2](#Ch03.xhtml#ref3_2)\]，它允许通过互联网远程访问对象（事物）。这些事物通常配备某种传感器，可能包括移动设备、洗衣机、街头摄像头、可穿戴设备、医疗设备等。随着此类连接设备的数量以惊人速度增长，几年后它将变得几乎无界。这种大量的事物将导致不可预见的数据生成量。除其他外，最重要但显而易见的关注点是如何处理如此庞大且不断增加的数据？处理这种海量数据绝对具有挑战性，尤其是考虑到物联网的异构和动态特性。为了最有利有效地利用物联网系统，需要一个高效的数据处理系统，能够解决物联网数据捕获、处理和消费执行中出现的不同问题。企业组织认识到将业务转变为物联网导向的巨大机会。了解不同架构的细微差别将有助于组织审慎实施物联网。

由于物联网设备通常以有限的计算和存储容量为特征，需要一些外部数据处理手段。物联网开发者和实施者必须做出的一项关键决策是：在哪里处理庞大的物联网数据。是要在物联网设备内部处理，还是在远程集中式数据中心处理，或是在中间的某个地方。组织应使用自己的基础设施在本地处理，还是应调用第三方服务等等。

每个网络系统都容易受到安全和隐私威胁。物联网也不例外。物联网在巨大规模上的广泛使用使风险更加严重。物联网数据的安全至关重要，因为由于数据的脆弱性，它可能为用户和系统打开漏洞。

本章其余部分组织如下。在 [第 3.2 节](#Ch03.xhtml#sec3_2) 中，列出了物联网的一些典型属性。在 [第 3.3 节](#Ch03.xhtml#sec3_3) 中，我们将提到物联网数据处理中需要处理的问题。[第 3.4 节](#Ch03.xhtml#sec3_4) 解决了本章的核心主题，即可用于处理物联网数据的所有可能架构，考虑不同因素。每个原型的安全和隐私问题在 [第 3.5 节](#Ch03.xhtml#sec3_5) 中被识别。对物联网安全和隐私问题的一般讨论在 [第 3.6 节](#Ch03.xhtml#sec3_6) 中陈述，而在 [第 3.7 节](#Ch03.xhtml#sec3_7) 中，我们提出了关于物联网安全和隐私上过度强调的担忧是否真的如此令人担忧的理性观点。最后，[第 3.8 节](#Ch03.xhtml#sec3_8) 总结了本章。
