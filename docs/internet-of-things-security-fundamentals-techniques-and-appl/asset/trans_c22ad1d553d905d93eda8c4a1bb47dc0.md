
1. 系统即使参数公开也能抵御关联规则挖掘。
2. 该模型生成巨大的频繁集合，很难确定会话的未来参数。
3. 密钥构造策略可能有助于使用便捷的方法为 `AVK` 建议未来密钥/参数。

### 6.4.3 参数化 AVK 模型生成的频繁模式
传统的 `Apriori` 算法应用于具有可变数量参数的响应数据。为了分析响应，`Apriori` 算法应用于响应数据，使用制表符分隔的文本文件格式作为输入文件。同一文件还存储最终结果。该算法可用于两种方式：首先，通过用户定义的支持阈值修剪候选参数集来找到频繁参数集。之后用于规则生成，最小支持度和置信度在范围（1–100%）内变化。关于可变支持，频繁参数数量的变化、生成关联规则所消耗的时间（以秒为单位）以及相应的文件大小已如 [表 6.10](#Ch06.xhtml#table6_10) 所示被捕获。
