
随着物联网（IoT）的蓬勃发展，网络犯罪不仅局限于获取信用卡详细信息及其相关数据库信息，还会渗透到现实生活物品和人体中。物联网已使轮上行驶的计算机（自动驾驶汽车）和飞行计算设备（智能航空设备和飞机）以及扫描仪（MRI）和胰岛素泵成为可能。然而，与独立/连接的固定式计算机相比，很难估计和分析这些仪器的安全性。网络罪犯和黑客有相当大的机会可以从远程位置控制无人驾驶汽车甚至心脏起搏器。通过主动警惕，可以改善此类安全问题。除了物联网的信息安全视角外，基于云的安全问题也是日益增长的担忧。考虑云视角的理由是物联网数据存储在云中并在云中处理，云提供了敏捷性、存储容量、性能和高可用性的好处。提供此服务的第三方需要探索这种海量存储信息的安全存储。保护数据上云并非易事。许多组织保护存储在传统本地数据中心的数据，但对于基于云的物联网信息存储库，由于对云的依赖，存在不同的挑战。

责任水平和需要保护的信息程度是一个巨大的挑战，同时在存储和检索可用替代方案时还存在以下问题：

1.  *资源利用不足：* 当组织仅将非关键数据迁移到云端时，云的潜力被低估，并限制了业务增长。

2.  *将现有解决方案应用于云：* 通过在云基础设施中智能应用加密过程，可以确保数据安全。组织将其当前数据中心安全解决方案应用于云。存储在云上的数据由多个组织共享，并由组织的管理员或员工管理。然而，云基础设施的共享可能会出现多个问题，例如：数据治理、监管和合规问题。这些解决方案侧重于参数安全和访问控制。它们并不能保护数据本身。在云的多租户环境下，数据保护需要对参数和访问控制有根本不同的概念。云数据保护被认为是计划迁移到云的组织面临的最大障碍之一。使用高效的加密技术是保护云中数据的唯一选择，因为您的数据存储在由多台机器共享的机器上。它显著降低了与许多数据治理和监管合规问题相关的风险。

3.  *预防和风险缓解*：组织必须采取必要措施防止信息丢失，并必须做好加强其安全性的准备，以抵御恶意窃取组织机密信息的企图。

4.  *了解正在共享的内容以及谁负责* 云端的信息安全：组织必须对云服务提供商的设施有充分的了解和视野。

除了上述四个保障信息安全的要点外，*用户端服务加密*也是另一种选择。用户端加密是在源头（用户端）对数据进行编码，然后将其发送到云存储提供商的方法。用户的加密密钥对云服务提供商不可用，使得云存储提供商难以或无法在云中解密数据。该方案允许维护零知识系统，其主机无法访问数据，并确保高水平隐私和异常稳健的数据安全策略。它消除了机密数据被包括服务提供商在内的第三方查看，客户端加密确保存储在云中的数据和文件只能在交换的客户端查看。这可以防止数据丢失和私人或个人文件的未经授权披露，为个人和企业用户提供更大的安心感。因此，可以实现信息的保密性、完整性和真实性，以保护物联网数据。最近，许多组织正在提供此功能（信息的保密性、完整性和真实性）。截至2016年初，没有任何大型巨头提供客户端加密。

将安全留给客户端或用户端的最大挑战是密钥的误用、选择不当以及密钥或密码的选择。糟糕密钥的典型示例通常是像“1234abcd”或出生日期或“qwerty”或用户选择的类似随机密码，这会危及系统的安全。这基本上导致从公共社交领域可获得的信息中选择密钥，或容易猜测。

## 6.2 The Classical Model of Automatic Variable Key (AVK)

“Perfect Secrecy” is the requirement of a cryptosystem, where after a cryptogram is attacked by an intruder, the posterior probability of this cryptogram is the same as the prior probability of the same messages before the interception [[1](#Ch06.xhtml#ref6_1), [2](#Ch06.xhtml#ref6_2)]。“完美保密”是密码系统的要求，其中在密文被入侵者攻击后，该密文的后验概率与拦截前相同消息的先验概率相同 [[1](#Ch06.xhtml#ref6_1), [2](#Ch06.xhtml#ref6_2)]。它表明完美保密是可以实现的，但条件是如果消息数量是有限的，则应有相同数量的可能密钥，或者如果消息被认为以给定速率不断生成，则密钥必须以相同或更高的速率生成 [2–[5](#Ch06.xhtml#ref6_5)]。

Secured transport of information over the network is a pertaining research challenge in today’s context.在当今的背景下，网络上的信息安全传输是一个相关研究挑战。The problem continues to aggregate with an increasing volume of network traffic, which is evident from several research studies [[12](#Ch06.xhtml#ref6_12), [14](#Ch06.xhtml#ref6_14), [15](#Ch06.xhtml#ref6_15)]。随着网络流量的增加，该问题持续累积，这从多项研究中可见一斑 [[12](#Ch06.xhtml#ref6_12), [14](#Ch06.xhtml#ref6_14), [15](#Ch06.xhtml#ref6_15)]。Security basically refers to the protection of the data against intentional modification, loss or damage, and fabrication of data and/or deliberate disclosure of data to unauthorized persons or miscreants。安全基本上是指保护数据免受故意修改、丢失或损坏以及数据伪造和/或故意向未经授权的人员或恶意者披露数据。In the classical paper on Information Security, Shannon, the father of Information theory has already established that perfect security can be achieved only when the key is made to vary from session to session and/or data to data [[6](#Ch06.xhtml#ref6_6), [7](#Ch06.xhtml#ref6_7)]。在信息安全经典论文中，信息论之父香农已确立，只有当密钥在会话之间和/或数据之间发生变化时，才能实现完美安全 [[6](#Ch06.xhtml#ref6_6), [7](#Ch06.xhtml#ref6_7)]。

## 6.3 Mechanism of Variation in Key of Automatic Variable Key (AVK) Framework

Realization of the time variable key is difficult to achieve, as a key must be communicated between the sender and the receiver [1, [3](#Ch06.xhtml#ref6_3)] from time-to-time。时间可变密钥的实现难以实现，因为密钥必须在发送方和接收方之间不时通信 [1, [3](#Ch06.xhtml#ref6_3)]。The automatic variable key (AVK) for a session between Alice and Bob is to be sent initially as `K[0]`, and they exchange data `D[0]`。Alice 和 Bob 之间会话的自动可变密钥（AVK）最初发送为 `K[0]`，他们交换数据 `D[0]`。The key is now variable, and after every transmission, it changes dynamically such that: with initial key `K[0]` initial secret key, the future keys can be constructed by `K[i] = K[i−1] ⊕ D[i−1]`, ∀`[i−1] > 0`, where `D[i−1]` and `K[i−1]` are data and key of (`i–1`)th session。密钥现在是可变的，并且在每次传输后都会动态变化，使得：以初始密钥 `K[0]` 为初始密钥，未来密钥可以通过 `K[i] = K[i−1] ⊕ D[i−1]` 构造，∀`[i−1] > 0`，其中 `D[i−1]` 和 `K[i−1]` 是第 (`i–1`) 次会话的数据和密钥。
