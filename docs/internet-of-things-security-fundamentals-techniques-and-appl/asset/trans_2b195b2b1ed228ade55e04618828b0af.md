### 4.4.3 传输层
传输层在远程主机上的两个进程之间提供点对点和端到端连接。传输层从上层（即应用层）获取数据，然后将其划分为较小大小的段，对每个字节进行编号，并交给下层（网络层）进行传输。该层执行以下功能：
- 它将应用层提供的信息数据分解为称为段的较小单元。它对段中的每个字节进行编号并维护其核算。
- 它确保数据按发送的相同顺序接收。
- 它在不属于同一子网的主机之间提供端到端的数据传输。
- 所有通过网络通信的服务器进程都提供传输服务访问点（TSAPs），也称为端口号。

传输层在物联网方面有两个最重要的协议。*TCP（传输控制协议）*是面向连接的协议。TCP使两个设备能够建立连接并交换数据流。TCP保证数据的交付，并保证数据包按发送的相同顺序交付。它有助于避免网络拥塞和拥塞崩溃。它在通过IP网络通信的主机上运行的应用程序之间提供可靠、有序且经过错误检查的数据流传输。*UDP（用户数据报协议）*是无连接协议。它用于对时间敏感的应用程序。它是一种面向事务且无状态的协议，不保证数据包交付。它提供快速的数据传输和恒定数据流，但不提供可靠性。

该层也容易受到与物联网相关的以下攻击：
- *会话劫持*也称为TCP会话劫持。它是通过秘密获取用户的会话ID并假装为授权用户来访问数据，从而控制用户会话的一种方式。
- *TCP Land攻击*是攻击者向通常具有开放TCP端口的主机服务器发送SYN数据包的攻击。
- *UDP泛洪攻击*是攻击者用无数请求淹没服务器机器的攻击；这使得机器认为假装为授权用户的攻击者确实急需服务，服务器机器开始向攻击者提供服务；结果，真正需要服务的用户往往被忽视。
- *TCP和UDP端口扫描*是一种技术，攻击者对主机机器的各种工具进行端口扫描以找到机器上的开放端口，并在识别出端口后用于攻击服务器。

### 4.4.4 应用层
应用层是实际通信发起并体现的顶层。该层不为其他层服务，但借助传输层及其以下所有层来通信或将其数据传输到远程主机。该层为网络上的数据传输准备设备之间的通信并启动数据传输。它从网络接收数据并为使用做好准备。应用层由适用于物联网设备的各种协议组成。该层的协议有 *HTTP* (*超文本传输协议*)，它是一种无状态协议，遵循请求-响应模型并使用URI（通用资源标识符）。*受限应用协议 (CoAP)*是一种为物联网中的受限设备和受限网络使用而设计的传输协议。该协议专为智能能源和建筑自动化等M2M应用而设计。它在UDP而不是TCP上运行，并遵循请求-响应模型。*WebSocket*是另一种计算机通信协议，它通过单个TCP连接提供全双工通信通道。它基于TCP，允许消息流在客户端和服务器之间来回发送。

*消息队列遥测传输* (MQTT)是一种轻量级消息协议，在资源受限环境中非常有用。该协议简单地在网络上分发遥测信息。它使用发布/订阅通信模式，最广泛用于M2M通信。它在物联网中发挥着重要作用。*XMPP* (*可扩展消息和存在协议*)是一种基于可扩展标记语言（XML）的协议。该协议主要用于即时消息（IM）和在线存在检测应用。它有时也称为jabber协议。它用于实时通信和XML数据的流传输。它最广泛用于游戏、多方聊天和语音/视频通话等应用。它是一种去中心化协议，对物联网设备非常有用。*高级消息队列协议 (AMQP)*是一种开放标准的消息导向协议。它支持点对点和发布者订阅者模型，并用于在网络上路由和排队数据。

物联网中的应用层也容易受到以下几种攻击：
- *恶意代码注入：*攻击者从未知位置向系统注入恶意代码并试图窃取或操纵授权用户的数据。
- *拒绝服务攻击：*攻击者假装为登录系统的已认证用户并中断网络的工作。
- *钓鱼攻击：*攻击者获取系统的凭证并访问系统并损坏数据。
- *嗅探攻击：*攻击者使用嗅探应用程序攻击系统的网络并读取未加密的数据包。
