
### 现场处理
现场处理在采用标准设备且黑客无法真正深入系统渗透的情况下，被认为是最安全的。

### 内存计算
内存服务器通常是组织的内部资产（否则将削弱内存计算的优势）。因此，它可被视为物联网数据处理的相对安全选项。但通常情况下，如果处理后的输出发送到中央存储库，则可能面临安全威胁。

## 3.6 关于物联网安全和隐私问题的一般讨论
物联网吸引了各行各业人士的广泛关注。大家纷纷急于试水并成为抢占先机的先行者，却缺乏充分的规划和考量。但忽视其给网络世界带来的额外安全威胁将是危险的。在消费类 IT 领域，物联网在智能电网、智能交通系统、智慧医疗、智能水务和废物管理以及智能公共安全和监控等方面具有巨大潜力。上述所有组件都是许多政府正在计划推出的智慧城市不可或缺的一部分。因此，由于这些智能设备固有的通信能力，设备与控制单元之间数据交换的安全性和隐私性考虑变得至关重要。随着医疗行业很可能成为物联网设备的最大受益者之一，保护患者敏感数据对于物联网的更广泛采用至关重要。

大多数物联网设备易于访问，这使其容易受到攻击。诸如数据篡改、停用和标签分离等安全攻击，加上通常的网络威胁如欺骗、窃听、拒绝服务等，会使物联网系统的状况变得极具挑战性。关键的脆弱区域包括——不安全的 Web 界面、认证/授权不足、不安全的网络服务以及缺乏传输加密。物联网使用户暴露于身份盗窃和安全漏洞。物联网设备相比其他典型目标设备（如计算机、平板电脑和智能手机）更容易被黑，主要是因为物联网设备能力有限，无法自行运行保护性应用程序（如复杂的加密和解密技术以及防病毒软件）。黑客只需最少的资源即可击垮任何物联网系统，例如通过发起 DDoS（分布式拒绝服务）攻击。物联网僵尸网络正成为实施此类攻击的常用武器，并随着物联网的普及而愈发猖獗。

现有的安全技术在一定程度上可能有用，但不足够。例如，由于物联网设备将通过电信网络或其他开放网络相互通信并与控制器通信，当前的网络认证机制（如 IMEI [[23](#Ch03.xhtml#ref3_23)] 和 ESN [[24](#Ch03.xhtml#ref3_24)]）可能不够充分。需要采用新颖的方法和技术（如区块链 [[25](#Ch03.xhtml#ref3_25)]）来确保物联网数据的隐私和安全。由于设备的异构性，我们必须为新的攻击做好准备并规划创新防御措施。政府和组织应部署风险评估框架（如 NIST [[26](#Ch03.xhtml#ref3_26)] 和 COSO [[27](#Ch03.xhtml#ref3_27)]）并选择有效的政策框架来保护其敏感数据。各国根据其威胁感知程度，监管指南的实施处于不同阶段。监管机构在落实物联网框架方面发挥着关键作用，包括数据传输和存储的指南。政府必须介入以监管和控制物联网安全。政府不仅应制定安全标准，还应为进入市场的物联网设备制定标准，并制定所有利益相关者必须遵守的严格政策和规则 [[28](#Ch03.xhtml#ref3_28)]。尽管由于跨大洲义务等原因，这对于像互联网这样的全球联网系统而言难以实施，但区块链等技术可以发挥重要作用，这得益于其完全去中心化、点对点、自主、开放和安全等特性 [[29](#Ch03.xhtml#ref3_29)]。

## 3.7 关于物联网安全和隐私问题的另类展望
随着越来越多的人接触物联网，我们也越来越多地听到其安全漏洞的危险。普遍的假设是，物联网的广泛和普遍采用缺乏安全标准、措施和实践，为黑客提供了盛宴。他们可以引爆家里的冰箱，在我们驾驶时接管我们的汽车，通过控制智能电网使整个城市陷入黑暗，夺取我们士兵的武器等等 [[30](#Ch03.xhtml#ref3_30)]。简而言之，他们可以摧毁任何已连接的东西。但我们是否反应过度了？自从发明互联网和万维网以来，我们就一直处于连接状态。我们真的面临过那种网络毁灭吗？那为什么我们现在会失去信心呢？并非所有物联网系统都那么危险，其中一些在该方面需要最少的关注。安全风险应基于物联网应用进行评估。例如，假设有人远程操控我家用电连接，通过连接和断开我家线路到电网，而在另一种情况下，他通过在电网中制造不可修复的故障使整个城市停电一周。当然，这两种情况都令人恐惧，但第二种情况更令人担忧。再考虑另一种情况，如果有人在我驾驶时接管我的汽车，比起有人入侵汽车音响系统并在汽车停在车库时整夜播放音乐，显然更令人担忧。关键在于要理解每个物联网用例都有不同的安全顾虑，而不是对整个物联网感到恐慌，应根据风险程度按案例采取适当的预防措施。

当我们更担心那个可以掌控物联网并让我们灭亡的虚构恶鬼时，我们可能忽视了与隐私相关的更大威胁。物联网已渗透到我们生活的每个领域，包括卧室。它记录我们的饮食和睡眠习惯，它记录我们的健康状况和病史，它记录我们的购买行为，它记录我们旅行的地点，它记录我们的数字足迹等等！简而言之，它监视着我们日常生活的方方面面。如果不法分子能够获取这些数据，我们将令人不安地暴露在他们面前。利用先进的分析工具，他们可以挖掘出我们自己可能都不知晓的每一个细节。而要做到这一点，并不总是需要违法。因为数据无处不在，猎人只需在正确的地方下手即可。因此，与其担心那个可以入侵我们物联网设备安全的想象中的恶魔，我们更应关注那些觊觎我们个人数据的现有恶魔 [30]。
