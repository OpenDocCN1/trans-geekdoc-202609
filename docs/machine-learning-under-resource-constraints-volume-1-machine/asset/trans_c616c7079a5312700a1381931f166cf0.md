
标准 R 解释器 (`StdPeak`) 的峰值内存使用量减少增益 (`GainP`) 从 gbm 的 −0.9 % 到 lssvm 的 53.8 % 不等。然而，[表 7.3](#9783110785937_078254.xhtml#b_9783110785944-007_tab_003) 中 `GainP` 和 `GainA` 列的负值表明，页面共享优化并未为三个基准测试带来内存节省。在此，两个基准测试（gbm、GU/08a-2）的峰值内存消耗和一个基准测试（naiveBayes）的平均内存消耗略有增加。这是由于内部处理内存页面所需的额外数据结构导致的。

对于 gbm，平均内存使用量减少了 7.9% (`GainA`)。对于 naiveBayes，情况相反：优化节省了 12.1% 的峰值内存使用量，而其平均内存使用量 (−0.6%) 略有增加。由于去重恢复的页面数量（见 `ZPG` 列）较低（78），假定峰值内存使用量的节省是由优化的分配和复制策略主动避免页面重复所导致的。对于 GU/08a-2，优化未能为峰值内存使用量节省内存，且未为平均内存使用量节省有意义的数量 (`GainA`)。GU/08a-2 无法从优化中获益的原因是，尽管它使用了包含 240 万个元素的大向量，但它分配了一个立即用随机数填充的向量。因此，它无法从优化分配中获益，且如 `ZPG` 列所示（13），内容检查只能恢复少量零页。GU/08a-2 不使用任何对象复制。因此，优化复制没有节省内存的潜力。

尽管页面共享优化导致上述三个基准测试的峰值或平均内存使用量略有增加，但其他所有十二个基准测试均从优化中受益，在峰值和平均内存使用量上均实现了节省。我们计算了所有 15 个基准测试的几何平均值，从而避免了异常值对几何平均值的影响。结果显示峰值内存使用量减少了 13.6%，平均内存使用量减少了 18.0%。其中，可节省的最高内存量出现在 lssvm 基准测试中，峰值使用量节省 53.8%，以及 randomForest 中，平均内存使用量节省 37.9%。这两个基准测试均通过内容检查恢复了大量零页。因此，对于这些基准测试，内存占用的减少不仅由分配和复制优化触发，还由动态细化触发，后者对零页进行去重。

### glmnet

如前所述，glmnet 基准测试利用了针对稀疏矩阵的现有内存优化。将其纳入评估是为了确定页面共享优化在存在应用专用知识的专门优化时，是否能提供额外的内存节省。在[图 7.7](#9783110785937_078254.xhtml#b_9783110785944-007_fig_007)左上角展示了该基准测试的内存随时间变化行为。虽然平均内存使用量仅有微小改善（见绿色虚线），但节省了 6.2% 的峰值内存消耗（见顶部直线）。内存消耗曲线显示，在所有局部内存峰值处，优化版 R 解释器均节省了少量内存，而执行其余部分的内存消耗基本不受影响。这导致平均内存消耗仅略微减少。尽管如此，即使存在针对稀疏矩阵的特定优化，页面共享优化仍可提供额外的内存节省。正如 [表 7.3](#9783110785937_078254.xhtml#b_9783110785944-007_tab_003) `ZPG` 列所示，节省是由大量通过去重恢复的页面触发的（46 877）。

### gbm

不过，并非所有基准测试都能从内容检查中受益。例如，[表 7.3](#9783110785937_078254.xhtml#b_9783110785944-007_tab_003) 显示 gbm 仅恢复了 464 个零页。该基准测试更多地受益于分配和复制方面的优化。相应的内存随时间变化行为如[图 7.7](#9783110785937_078254.xhtml#b_9783110785944-007_fig_007)右上角所示。此处，优化并未减少内存消耗的峰值，但在峰值之间的谷值处内存使用量显著减少，使平均内存消耗减少了 7.9%。
