
如果建立在对算法分析的基础上，将机器学习过程的能量最小化，则可以给出统计保证。指数族是一种涵盖许多学习任务的学习模型，例如概率密度的估计（主题模型即使用此方法），或最大似然状态的预测（朴素贝叶斯或条件随机场即使用此方法）。对学习模型的仔细分析可能使得在非常受限甚至超低能耗设备上运行极其复杂的机器学习任务成为可能。本书在[第 9.1 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001)中提供了这样一种方法，该节描述了`整数马尔可夫随机场 (IntMRF)`及其理论基础。请注意，受限于整数的是底层模型类；这不仅仅是将状态空间限制为整数。在这里，状态空间可以是一个随机离散空间，无需任何额外约束。运行时间缩短和节能归因于更廉价的操作。新颖的位长传播算法（`BL-Prop`）允许仅使用整数进行计算，即实数不是事后量化的，而是所有学习处理仅使用整数。除了先前的工作（[567](#backmatter-001.xhtml#b_9783110785944-010_ref_567)）外，[第 9.1 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001)还引入了用于凸目标函数的新型数值优化方法`IntGD`。它基于一种针对非光滑和非凸惩罚项的加速近端算法。对于通过`BL-Prop`计算的整数梯度，`IntGD`保证提供一个纯整数学习过程，其中最终参数向量以及所有中间结果均为整数。整数马尔可夫随机场的表达能力几乎与实值马尔可夫随机场相当，但可以在不提供浮点运算的超低功耗设备上执行（[570](#backmatter-001.xhtml#b_9783110785944-010_ref_570)）。

正如我们所见，减少机器学习能耗有多种途径：为更节能的处理器（`FPGA`）开发算法、定制机器学习算法、优化其执行以缩短运行时间，甚至开发旨在节能的新型学习算法。

## 1.3 机器学习的内存需求

### 1.3.1 深度学习

深度学习因其众多超参数、张量对齐、特定的卷积算法和算子调度，对`GPU`内存构成了挑战。在对 4960 次失败的深度学习运行进行详细分析中，Yanjie Gao 及其同事发现其中 8.8% 是由`GPU`内存耗尽导致的（[242](#backmatter-001.xhtml#b_9783110785944-010_ref_242)）。随后，他们开发了一种深度学习模型`GPU`内存需求的估算方法。在本书中，`图神经网络 (GNN)`的内存需求是[第 4.2 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_002)和[第 4.3 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_003)所呈现工作的一部分。由于相邻节点的相互依赖性，常规的小批量训练在`GNN`中变得困难。图的指数级增长已在文献（[455](#backmatter-001.xhtml#b_9783110785944-010_ref_455)）中得到证实，该文献提出了边采样。[第 4.3 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_003)提出了适用于多种`GNN`架构的更通用解决方案。新颖的`GNN AutoScale`消息传递框架成功使`GNN`甚至适用于流式设置，因为对于单个周期和层，每条边仅被处理一次。

深度学习的量化导致权重和激活值变为二进制值，从而大幅降低内存消耗（[325](#backmatter-001.xhtml#b_9783110785944-010_ref_325)）。`二值神经网络 (BNN)`提供了更轻量级的处理。将机器学习与计算机体系结构工作相结合，催生了用于天体粒子物理超大流式数据快速推理的`FPGA`上的`BNN`（[112](#backmatter-001.xhtml#b_9783110785944-010_ref_112)）。朝着算法与硬件紧密互动更进一步的步骤是考虑现代内存技术。我们再次看到，在近似或非易失性内存（它们降低能耗但增加位错误率）的情况下，能耗与内存架构之间存在密切关系。对于`BNN`，权重或网络激活值中的位翻转会降低模型精度。隐藏层能容忍多少位错误？为`支持向量机 (SVM)`开发的最大间隔优化思想（[680](#backmatter-001.xhtml#b_9783110785944-010_ref_680)），启发了一种位错误容忍度指标的构想，该指标可被整合进`BNN`训练中（[113](#backmatter-001.xhtml#b_9783110785944-010_ref_113)）。机器学习预判硬件错误，从而为节能计算架构生成鲁棒的学习模型。[第 7.2 节](#9783110785937_078254.xhtml#b_9783110785944-007_s_002)更详细地解释了在`BNN`训练中降低位错误率的这种方法。

### 1.3.2 摘要与聚类

为了从分布式传感器流中学习，数据摘要或聚合是必要的。草图或采样已针对数据流聚类进行了理论研究 [70, 103]。`核心集`和草图对数据进行摘要，使其可被任何学习算法分析，并且与在完整数据集上训练相比，它们能提供大致相同的结果（[516](#backmatter-001.xhtml#b_9783110785944-010_ref_516)）。[第 3.2 节](#9783110785937_007154.xhtml#b_9783110785944-003_s_002)分析了用于分布式和流式数据的`核心集`和草图。该分析涵盖了贝叶斯和广义线性回归的方法。证明了原始高维数据空间的一个稀疏子空间是样本高效的。数据缩减不仅节省内存，还节省运行时间和能量需求。

固定内存大小的摘要通常使用亚模函数开发。对于视频摘要，可以在隐私约束下优化亚模集合函数（[495](#backmatter-001.xhtml#b_9783110785944-010_ref_495)）。在[第 3.1 节](#9783110785937_007154.xhtml#b_9783110785944-003_s_001)中，固定大小内存的筛流采样得到了增强，用于“即时”采样最有信息量的观测值。除了节省资源外，新颖的`ThreeSieves`算法还为人机交互式数据探索提供摘要。

无监督学习以多种不同方式对数据进行分区。本书在[第 5.1 节](#9783110785937_041148.xhtml#b_9783110785944-005_s_001)中介绍了图数据的聚类，在[第 5.2 节](#9783110785937_041148.xhtml#b_9783110785944-005_s_002)中介绍了曲线的聚类。`BETULA`算法在[第 5.3 节](#9783110785937_041148.xhtml#b_9783110785944-005_s_003)中显著增强了层次凝聚聚类的可扩展性。

一些问题作为学习算法的构建模块出现。`矩阵分解`就是其中之一。[第 5.4 节](#9783110785937_041148.xhtml#b_9783110785944-005_s_004)介绍了一种对噪声鲁棒的二值和布尔`矩阵分解`方法。它使用`近端梯度下降优化`并允许重叠聚类。

另一个是`最大有向割 (max dicut)`问题：将有向图划分为两个子集，使得两个子集之间边权重之和最大化。[第 4.4 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_004)研究了该问题的并行算法，这些算法可扩展至超大图。
