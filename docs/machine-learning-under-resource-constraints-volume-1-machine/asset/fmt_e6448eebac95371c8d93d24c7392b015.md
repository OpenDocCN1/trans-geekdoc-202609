
在欧几里得空间`ℝ^d`中，存在一系列针对`k`-聚类问题的`(1+ε)`-近似算法。许多算法基于核心集的概念；即核心集是一个比输入小的（加权）集合，它关于任意`k`个中心的选择（强核心集），或仅关于最优`k`个中心的选择（弱核心集），对输入的聚类成本进行`(1+ε)`-近似。关于`k`-聚类核心集方法的综述，请参阅Munteanu和Schwiegelshohn的工作[[516]](#backmatter-001.xhtml#b_9783110785944-010_ref_516)。

我们现在讨论一般度量空间中`k`-聚类问题的最新进展。对于`k`-中心问题，存在一个简单的贪心2-近似算法，由Gonzalez提出[[264]](#backmatter-001.xhtml#b_9783110785944-010_ref_264)（Hochbaum和Shmoys也独立给出[[317]](#backmatter-001.xhtml#b_9783110785944-010_ref_317)），该算法也是最优的。直观上，该算法从输入中随机选取第一个中心，然后`k-1`次选取使到已选中心距离最大化的输入点。

对于一般度量空间中的`k`-中位数，通常研究的是离散版本。注意，由于三角不等式，离散情况的每个`α`-近似都是无限制情况的`2α`-近似。Chen[[130]](#backmatter-001.xhtml#b_9783110785944-010_ref_130)给出了一个运行时间为`O(nk) + k⁷ε^(−5) log⁵ n`的`(10 + ε)`-近似算法。Chen[[130]](#backmatter-001.xhtml#b_9783110785944-010_ref_130)的近似因子在两篇论文中得到了进一步改进，但运行时间不再是`n`的线性函数。Li和Svensson[[433]](#backmatter-001.xhtml#b_9783110785944-010_ref_433)给出了一个`(1 + √3 + ε) ≈ (2.732 + ε)`-近似，时间为`O(n^((1/ε)²))`。Byrka等人[[116]](#backmatter-001.xhtml#b_9783110785944-010_ref_116)将Li和Svensson[[433]](#backmatter-001.xhtml#b_9783110785944-010_ref_433)的结果改进为`(2.675 + ε)`-近似算法，运行时间为`O(n^((1/ε) log(1/ε)))`。

一条重要的研究路线建立在Kumar、Sabharwal和Sen[[405]](#backmatter-001.xhtml#b_9783110785944-010_ref_405)针对`k`-中位数问题的`(1 + ε)`-近似算法之上，其运行时间为`O(n^d ⋅ 2^((k/ε)^O(1)))`，基于随机采样。他们的结果最初是为欧几里得`k`-中位数问题开发的。Kumar等人[[405]](#backmatter-001.xhtml#b_9783110785944-010_ref_405)表明，一个小的均匀样本（包含常数个输入点，与`n`无关：`O((1/ε)^O(1))`）足以构建一个大小为`O(2^((1/ε)^O(1)))`的候选集，该集合包含1-中位数问题的`(1 + ε)`-近似（然后递归构建`k`-中位数问题的`(1 + ε)`-近似）。Indyk和Thorup[[333, 659]](#backmatter-001.xhtml#b_9783110785944-010_ref_333)表明，要在`n`个点上将离散度量1-中位数近似到`(1 + ε)`因子内，大小为`O((1/ε²) ⋅ log n)`的均匀样本就足够了。Ackermann、Blömer和Sohler[[2]](#backmatter-001.xhtml#b_9783110785944-010_ref_002)展示了如何将该论证适应于具有有限倍增维数的度量空间[[31]](#fn31)。

Ackermann、Blömer和Sohler[[2]](#backmatter-001.xhtml#b_9783110785944-010_ref_002)表明，如果可以通过采取常数大小的随机样本并在样本上精确求解1-中位数问题来找到1-中位数问题的`(1 + ε)`-近似，则可以在一般度量空间中高效地找到`k`-中位数问题的`(1 + ε)`-近似。此结果不仅适用于具有有限倍增维数的度量空间（如`ℓ₂^d`），也适用于那些不一定是度量但其非相似性度量满足采样性质的空间。然而，由于无界倍增维数，上述结果不直接适用于具有`d_F`或`d_dF`度量的空间[[185]](#backmatter-001.xhtml#b_9783110785944-010_ref_185)。

在处理度量空间`(Δ^d, d_F)`或`(Δ^d, d_dF)`中的`k`-聚类问题之前，我们需要解决过拟合问题：即使我们仅在Fréchet距离下为`Δ[m]^d`中的`n`条曲线输入寻找单个簇代表（中心），最优解的复杂度也可能为`O(mn)`，正如Ahn等人[[12]](#backmatter-001.xhtml#b_9783110785944-010_ref_012)所指出的。考虑到资源限制，这通常是不可取的，且对于现实问题建模往往是不必要的。因此，我们按照Driemel等人[[185]](#backmatter-001.xhtml#b_9783110785944-010_ref_185)的引入，通过将聚类中心曲线的复杂度限制为常数`ℓ ∈ ℕ`来调整经典问题。

形式上，给定一组`n`条曲线`𝒲 = {τ₁, …, τₙ} ⊆ Δ[m]^d`和参数`k, ℓ ∈ ℕ, ℓ ≥ 2`（我们假设它们为常数），我们定义`(k, ℓ)`-聚类问题是从`Δ[ℓ]^d`中找到一组`k`条曲线`𝒞 = {ς₁, ..., ςₖ}`，使以下成本函数之一最小化：

```
cost_∞(𝒲, 𝒞) = max_{1 ≤ i ≤ n} min_{1 ≤ j ≤ k} d_F(τ_i, ς_j)  (5.6)
```

```
cost_1(𝒲, 𝒞) = ∑_{i=1}^n min_{1 ≤ j ≤ k} d_F(τ_i, ς_j)  (5.7)
```

我们分别将该聚类问题称为`(k, ℓ)`-中心（公式5.6）和`(k, ℓ)`-中位数（公式5.7）。

`(k, ℓ)`-聚类问题是**NP**-难的。当`k`是输入的一部分时，Driemel等人[[185]](#backmatter-001.xhtml#b_9783110785944-010_ref_185)通过从`ℝ^d`中的经典对应问题归约，证明了`(k, ℓ)`-中心和`(k, ℓ)`-中位数问题的难度结果。在这种情况下，`(k, ℓ)`-中心问题**NP**-难以在因子2以内近似。
