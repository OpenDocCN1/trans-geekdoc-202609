
在计算添加新候选中心点 `y[c]` 的损失变化时，我们用每个现有中心点的移除损失初始化数组 `Δℓ`，这是来自 FastPAM [[617]](#backmatter-001.xhtml#b_9783110785944-010_ref_617) 的一种优化。为了避免对所有中心点 `k` 进行内层循环，我们还结合了来自 FasterPAM [[616]](#backmatter-001.xhtml#b_9783110785944-010_ref_616) 的一个思路，即在变量 `Δℓ⁺` 中累积适用于所有中心点的损失变化。`Δℓ⁺` 的一个有趣性质是，它代表了添加新中心点的损失变化，我们也利用这一点来动态增加聚类数量。我们受益于该方法中的稀疏性，因为不必考虑那些不是候选点 `y[c]` 邻居的对象：移除现有中心点的损失变化已经计入，且由于它们无法从 `y[c]` 到达，添加替代中心点时不存在损失变化。因此，我们的循环只需遍历邻居即可。对于每个邻居 `x[o]`，我们区分四种情况：(1) 该点当前尚未被覆盖，因此我们在行 12 获得 `π(o)` 但产生 `d(x[o], y[c])`；(2) 新中心点比所有现有中心点都近，因此我们在行 14 获得 `d[n₁](o) − d(x[o], y[c])`。对于移除最近中心点的情况，我们已经包含了 `d[n₁](o)`，因此必须将其抵消（要么用 `−π(o)` 要么用 `d[n₂](o)`）。如果新中心点只是第二近的，且 (3) 之前不存在第二近的，则只需在行 20 更新移除最近中心点的损失。如果 (4) 存在之前的第二近中心点，但它比新中心点远，我们还需要在行 22 通过产生的差值来调整移除最近中心点的损失，该差值源于分配给新中心点而非之前的第二近中心点。类似的情况区分——除了处理未定义的第二近情况——在 FasterPAM [[616]](#backmatter-001.xhtml#b_9783110785944-010_ref_616) 中已可找到。

我们观察到行 5 和行 9 的两个循环都遍历所有边，因此该过程的复杂度为 `O((e + N · k) · i)`，其中 `e` 是边的数量，`i` 是迭代次数。在街道网络示例中，我们可以论证当将方法扩展到更大网络时（因为我们会保持最大距离不变，但增加区域），`e ∈ O(N)`。因此，这种稀疏 `k`-中心点版本在此应用中呈线性扩展。如果我们拥有一个稠密连接图，则 `e ∈ O(N²)`，运行时间与标准 FasterPAM 相匹配。

### 5.1.6 实验

在实验中，我们预期相比 FasterPAM 能看到加速效果。我们还想检查在考虑约束条件下 `k` 的动态变化如何工作。我们必须评估稀疏 `k`-中心点在满足约束条件下寻找最小可能 `k` 的能力如何。因此，我们分析了三种初始化方法：DynBUILD、Random 和 Sparse++。最后，我们通过将模拟结果与 OSM 中的原始变电站位置进行比较，执行定性评估。

#### 算法 2 DynBUILD：动态非对称 BUILD 初始化

```
1 ℓ, M ← (∞,∞), ∅
/* 选择第一个中心点： */
2 // 计算每个 y[j] 的损失 foreach y[j] do
3  // 一切均未分配
4  // 检查邻居（稀疏）
5 
6 if ℓ[j] < ℓ then ℓ, M ← ℓ[j], {y[j]} // 当前最优
/* 选择剩余中心点： */
7 for i = 1 ... k − 1 do
8  Δℓ^(*), y^(*) ← (0, 0), ∅ // 存储最佳解
9 foreach y[j] ∉ M do
10  Δℓ[j] ← (0, 0) // 损失变化累加器
11 foreach x[o] ∈ N(y[j]) do // 检查邻居（稀疏）
12  δπ ← −π(o) if d[n₁](o) = ∞ else 0
13  δd ← d(x[o], y[j]) − d[n₁](o)
14 if δπ < 0 or δd < 0 then Δℓ[j] ← Δℓ[j] + (δπ, δd)
15 if Δℓ[j] < Δℓ^(*) then Δℓ^(*), y^(*) ← Δℓ[j], y[j] // 当前最优
16 ℓ, M ← ℓ + Δℓ^(*), M ∪ {y^(*)} // 使用最佳新中心点
17 if i = k − 1 and ℓ[π] > 0 then k ← k + 1 // 增加 k
18 return ℓ, {m₁, ..., mₖ}
```

#### 算法 3 DynSWAP：面向非对称稀疏数据的动态 SWAP

```
1 y[last] ← invalid
2 foreach x[o] do compute n₁(o), d[n₁](o), d[n₂](o)
3  Δℓ^(−m₁), …, Δℓ^(−mₖ) ← compute loss change removing m[i]
4 while still changing do
5 foreach y[c] ∉ {m₁, ..., mₖ} do
6  break outer loop if y[c] = y[last] // 未发现改进
7  Δℓ ← (Δℓ^(−m₁), …, Δℓ^(−mₖ)) // 移除损失
8  Δℓ⁺ ← 0 // 累加器 (FasterPAM)
9 foreach x[o] ∈ N(y[c]) do // 检查邻居（稀疏）
10  d[oc] ← d(x[o], y[c]) // 到候选点的距离
11 if d[n₁](o) = ∞ then // x[o] 尚未被覆盖
12  Δℓ⁺ ← Δℓ⁺ + (−π(o), d[oc])
13 else if d[oc] < d[n₁](o) then // 新的最近
14  Δℓ⁺ ← Δℓ⁺ + (0, d[oc] − d[n₁](o))
15 if d[n₂](o) = ∞ then // 无第二近
16  Δℓ[n₁(o)] ← Δℓ[n₁(o)] + (−π(o), d[n₁](o))
17 else
18  Δℓ[n₁(o)] ← Δℓ[n₁(o)] + (0, d[n₁](o) − d[n₂](o))
19 else if d[n₂](o) = ∞ then // 无第二近
20  Δℓ[n₁(o)] ← Δℓ[n₁(o)] + (−π(o), d[oc])
21 else if d[oc] < d[n₂](o) then // 新的第二近
22  Δℓ[n₁(o)] ← Δℓ[n₁(o)] + (0, d[oc] − d[n₂](o))
23 i ← arg min({Δℓ[i]}) // 当前最佳中心点
24 Δℓ[i] ← Δℓ[i] + Δℓ⁺ // 加上累加器
25 if ΔTD[i] < (0, 0) then // 急切交换 (FasterPAM)
26  swap roles of medoid m^(*) and non-medoid y[c]
27  ℓ ← ℓ + Δℓ[i]
28  update n₁(o), d[n₁](o), d[n₂](o), Δℓ^(−m₁), …, Δℓ^(−mₖ)
29  y[last] ← y[c] // 新的停止位置
// 每次交换后，尝试减小 k：
30 if min(Δℓ[π]^(−m₁), …, Δℓ[π]^(−mₖ)) = 0 then // Dyn↓
31  r ← arg min({Δℓ^(−m[i])})
32  remove medoid m[r]
33  update n₁(o), d[n₁](o), d[n₂](o), Δℓ^(−m₁), …, Δℓ^(−mₖ)
34 else if Δℓ[π]⁺ < 0 then // Dyn↑
35  add new medoid y[c] as it fixes at least one constraint
36  update n₁(o), d[n₁](o), d[n₂](o), Δℓ^(−m₁), …, Δℓ^(−mₖ)
37  y[last] ← y[c] // 新的停止位置
38 return ℓ, M
```
