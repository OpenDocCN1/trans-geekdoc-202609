### 4.1.8 时空随机场的正则化训练

在我们的模型中，`l`[2] 正则项在时间上对参数动态施加了“平滑性”，提供了一种可控的方式来避免过拟合噪声观测。平滑度由 `λ`[2] 控制，而压缩比由 `λ`[1] 控制。`λ`[2] 的正值有助于我们的方法，因为曲率估计变得更加适定。

#### 4.1.8.1 训练模型的稀疏性及其训练准确率

[图 4.4](#9783110785937_013188.xhtml#b_9783110785944-004_fig_004) 展示了 `STRF`（我们的方法）和 `MRF`（经典参数化）在一系列 `λ`[1] 值下的负对数似然和 `NNZ` 比率方面的表现。参数 `λ`[2] 固定为 `10^(-1)`（我们在 `[0, 1]` 范围内尝试的各种 `λ`[2] 值的特征几乎相同）。对于 `MRF`，我们用 [4.1.4 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_001_s_004) 中讨论的 `l`[1] 和 `l`[2] 正则项增广了目标函数，然后应用了固定步长（`η` = `10^(-2)`）的次梯度下降法。我们的结果表明：（i）无论 (`λ`[1], `λ`[2]) 如何选择，次梯度法都无法为 `MRF` 正确执行正则化；（ii）随着 `λ`[1] 的增加，负对数似然降低，这是预期内的，因为最强的 `l`[1] 正则化会迫使所有边缘分布变为均匀分布；（iii）我们的方法 `STRF` 根据给定的正则化强度识别稀疏模型，同时保持与 `MRF` 相似的似然值。更准确地说，关注 `STRF` 的曲线，似然值持续改善直到 `λ`[1] 达到 0.47。超过此值后，模型被过度压缩，失去了预测能力。总体而言，对于交通数据，(`λ`[1], `λ`[2]) = (0.4655, 1.0) 且 `NNZ` 比率为 0.101573 被确定为一个好的选择；对于温度数据，(`λ`[1], `λ`[2]) = (0.0255, 1.0) 且 `NNZ` 比率为 0.248136 被确定为一个好的选择，因为两者都能得到具有合理似然值的稀疏模型。我们在后续实验中使用这些值。

由于边参数的数量是参数空间维度 `d` 的主要因素，因此希望 `STRF` 能充分压缩边参数。分别考虑顶点和边参数的 `NNZ` 比率，结果表明 `STRF` 具有这一特性：使用上述良好的参数值，顶点的 `NNZ` 比率约为 0.95，而边的约为 0.09。

由第 4.1.8.1 节所述正则化参数获得的模型的测试集准确率见 [图 4.5](#9783110785937_013188.xhtml#b_9783110785944-004_fig_005)。这里比较了我们的方法 `STRF`、经典 `MRF`、具有若干 `k` 值的 `k`NN 算法以及随机猜测法。`STRF` 产生的模型的预测质量与 `MRF` 几乎相同，尽管 `STRF` 模型的规模小得多（对于交通和温度数据，分别仅为 `MRF` 模型规模的 10.2% 和 24.8%）。`k`NN 算法有时表现优于 `STRF` 和 `MRF`，但请记住 `k`NN 无法捕捉概率关系，且需要访问完整的训练数据，而 `STRF` 和 `MRF` 则不需要。

### 4.1.10 结论

在本贡献中，我们提出了一种改进的图模型，旨在高效地对时空数据进行概率建模。它基于参数化和正则化的结合，使得估计参数稀疏且估计边缘概率平滑，同时不损失预测准确性。我们在真实数据集上研究了模型的稀疏性、平滑性、预测准确性和可扩展性。实验表明，通常原始模型规模的 10% 左右足以达到几乎相同的预测准确性。此外，该方法适合并行化，并能随着 CPU 数量的增加良好扩展。
