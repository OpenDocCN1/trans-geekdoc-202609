

## 6.3.4.1 与深度学习方法的比较

如[表 6.6](#9783110785937_066530.xhtml#b_9783110785944-006_tab_006)所示，算法 4 中描述的、极易并行化的“一对其余”框架的 DiSMEC 实例化可以成为一个有竞争力的基线。与通常采用 Transformer 编码器[\[174\]](#backmatter-001.xhtml#b_9783110785944-010_ref_174)的最先进深度学习方法相比，其性能并无显著劣势。与需要仔细调整超参数的深度学习模型不同，DiSMEC 所依赖的线性二分类从理论角度来看更易于解释且理解透彻。对于稀疏的 tf-idf 数据表示，线性 XMC 分类器的表现也与基于树的方法[\[371, 584\]](#backmatter-001.xhtml#b_9783110785944-010_ref_371)以及涉及稠密低维标签嵌入的方法[\[51, 279\]](#backmatter-001.xhtml#b_9783110785944-010_ref_051)不相上下。

### 6.3.5 总结与展望

在本节中，我们介绍了用于极端多标签分类的线性分类算法。线性模型使得训练能在不同标签间完美并行化，尽管在实践中，当单个节点内的核心数过多时，扩展性会趋于平稳。这是因为尽管训练本身不需要线程间的任何通信或同步，但机器内的不同核心仍会竞争内存访问等资源。通过在每个 NUMA 域中放置一份特征矩阵的副本，可以确保每个 CPU 都能从其访问速度最快的内存部分读取数据，并且内存接口的负载分散在不同的 NUMA 域中。此外，通过重新排序稀疏特征矩阵中的列，可以提高数据局部性，从而改善缓存效率。结合这些技术的实现可在 `https://doi.org/10.5281/zenodo.6699587` 找到。关于机器学习与内存层级交互的进一步讨论，请参见[第 7 章](#9783110785937_078254.xhtml#b_9783110785944-007)。

通过从良好的初始化开始权重，可以大幅减少为 XMC 典型的高度不平衡数据训练线性分类器所需的工作量。寻找此类权重向量的一种方法是将数据集缩减为仅两个训练实例，即原始数据集中正负训练点的质心，这可以高效计算。通过用分离该汇总数据的权重向量初始化完整训练过程，可以利用共轭梯度优化器因铰链损失的隐式难例挖掘而带来的加速。该过程可视为[第 3.2 节](#9783110785937_007154.xhtml#b_9783110785944-003_s_002)中介绍的“草图求解”原则的一种变体。主要区别在于，此处基于草图的解被用于初始化完整训练，因此不会在精度上做出妥协。

本书的阐述侧重于 XMC 问题的计算与实现挑战。然而，标签空间的规模也导致了有趣的统计后果，例如长尾标签分布及尾部标签相应的数据稀缺，以及带有缺失标签的不完整训练数据。关于这些问题的讨论，请参阅 Babbar 和 Schölkopf[\[29\]](#backmatter-001.xhtml#b_9783110785944-010_ref_029)、Jain、Prabhu 和 Varma[\[336\]](#backmatter-001.xhtml#b_9783110785944-010_ref_336) 以及 Qaraei、Schultheis、Gupta 和 Babbar[\[587\]](#backmatter-001.xhtml#b_9783110785944-010_ref_587) 的著作。
