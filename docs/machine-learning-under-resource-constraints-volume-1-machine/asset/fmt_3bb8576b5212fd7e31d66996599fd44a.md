
## 4.1.6.3 Analysis

We define the $l_1$ and $l_2$ regularizers for the slope matrix $\mathbf{\Delta}$ as follows,

(4.7) $\parallel \mathbf{\Delta} \parallel_{1}: = \sum\limits_{j = 1}^{d}\left\| \mathbf{\Delta}_{j.} \right\|_{1},\quad \parallel \mathbf{\Delta} \parallel_{F}^{2}: = \sum\limits_{j = 1}^{d}\left\| \mathbf{\Delta}_{j.} \right\|_{2}^{2}.\qquad (4.7)$

The two regularizers induce sparsity and smoothness respectively, as we have discussed in [Section 4.1.4](#9783110785937_013188.xhtml#b_9783110785944-004_s_001_s_004). The difference is that due to the reparametrization, now differences between parameters $\boldsymbol{\theta}(t - 1)$ and $\boldsymbol{\theta}(t)$ are penalized, not the actual values they contain, which are unlikely to be zero.

The proposed reparametrizations can result in large improvements regarding a model's memory consumption. Clearly, the amount of reduction depends on the specific dataset. It is hence even more astonishing that the reparametrization itself can be applied without any harm—it can represent any natural parameter. Let us consider a proper definition of our former intuition. For the sake of generality, let $C$ be any clique (e.g., an edge) of the underlying graph.

**Definition 4** (Piecewise Linear Reparametrization [[567]](#backmatter-001.xhtml#b_9783110785944-010_ref_567)). *Let $G$ be a spatio-temporal graph of length $T$, and let $\mathbf{D}(h) \in [0; 1]^{h \times h}$ be a lower unitriangular*[^(12)](#fn12)

(4.8) $\theta[C = x'] = \eta[\mathbf{D}(h)](\mathbf{\Delta}[C = x']) = \mathbf{D}(h)\mathbf{\Delta}[C = x'] \qquad (4.8)$

*where $h = T - (\max\{t' \mid v(t') \in C\} - \min\{t' \mid v(t') \in C\})$ is called a spatio-temporal random field.*

Based on that definition, we can derive some useful properties.

**Lemma 5** (Universality of the Reparametrization). *The spatio-temporal reparametrization is universal. That is, the piecewise linear reparametrization is a bijection.*

**Proof** Indeed, any $\mathbf{\Delta} \in \mathbb{R}^d$ can be mapped to some $\boldsymbol{\theta} \in \mathbb{R}^d$ by multiplication with $\mathbf{D}$ according to Definition 4. To see that the converse also holds, note that for each $t \in [T]$, $\det \mathbf{D}(h) = \prod_{i = 1}^{T}\mathbf{D}(h)_{i,i} = 1,$ due to unitriangularity. Each $\mathbf{D}(h)$ is thus invertible and so is the block diagonal matrix $\mathbf{D}^\circ$. So for any given natural parameter $\boldsymbol{\theta}[C = y]$, we can find the corresponding reparametrization via $\mathbf{\Delta}[C = y] = \mathbf{D}^{-1}\boldsymbol{\theta}[C = y]$. That is, $\eta[\mathbf{D}]$ is bijective and hence universal. ◼

Since $\eta[\mathbf{D}]$ is universal, any natural parameter can be represented via some $\mathbf{\Delta}$. Moreover, $\eta[\mathbf{D}]$ is a linear function of $\mathbf{\Delta}$. The convexity of a function is preserved by composing it with a linear function. Hence, the reparametrized negative average log-likelihood $\ell(\eta[\mathbf{D}](\mathbf{\Delta});\mathcal{D}) = A(\eta[\mathbf{D}](\mathbf{\Delta})) - \langle \eta[\mathbf{D}](\mathbf{\Delta}), \tilde{\boldsymbol{\mu}} \rangle$ is a convex function of $\mathbf{\Delta}$.

Up to now, we have not saved any memory since $\mathbf{\Delta}$ and $\boldsymbol{\theta}$ have the same dimension. By imposing $l_1$- and $l_2$-regularization on the reparametrized objective, we arrive at the problem

(4.9) $\min\limits_{\mathbf{\Delta} \in \mathcal{R}^{d}}\underbrace{A\left( {\eta_{D}(\mathbf{\Delta})} \right) - \left\langle {\eta_{D}(\mathbf{\Delta}),\widetilde{\boldsymbol{\mu}}} \right\rangle + \frac{\lambda_{2}}{2} \parallel \mathbf{\Delta} \parallel_{F}^{2} + \lambda_{1} \parallel \mathbf{\Delta} \parallel_{1}}_{\mathcal{l}^{\text{ST}}(\mathbf{\Delta};\mathcal{D})}.\qquad (4.9)$

The following theorem shows that the intuition that we used to design our reparametrization has indeed the desired effect—it allows us to convert redundancy into sparsity by detecting negligible changes in consecutive natural parameters. Moreover, a polynomial number of samples suffices to achieve a small estimation error with high probability.

**Theorem 6** (STRF Consistency). *Consider a random variable $\mathbf{X}$ with exponential family density, parameter $\boldsymbol{\theta}^* \in \mathbb{R}^d$ whose reparametrization has minimal norm among all equivalent parameters, and a generalized sequence structure of length $T$. We are given a dataset $\mathcal{D}$ with $N = |\mathcal{D}|$ samples from $\mathbf{X}$. Suppose $\|\nabla^2 A(\boldsymbol{\theta}^*)^{-1}\|_\infty \le \kappa$ and $\|\mathbf{\Delta}\|_\infty \le \gamma$, and set $\lambda_1 = 4T\sqrt{\log(d)/N} \text{ and } \lambda_2 = \gamma^{-1}\lambda_1$. If $N \ge 324\kappa^4 d^{12} \log(d)/(T - d^2)^2$, then, for an arbitrary decay matrix $\mathbf{D}$:*

*   *the distance between the true parameter $\boldsymbol{\theta}^*$ and the estimate $\eta[\mathbf{D}](\hat{\mathbf{\Delta}})$ is bounded, i.e.,*
    $\|\eta[\mathbf{D}](\hat{\mathbf{\Delta}}) - \boldsymbol{\theta}^*\|_\infty \le 3\kappa d^2 \lambda_1$,
*   *any sparsity in the estimate implies some redundancy in the true parameter, i.e.,* $\hat{\mathbf{\Delta}}[C = x'](t) = 0 \Rightarrow$
    $$
    \begin{matrix}
    \left| {\theta_{C = x'}^*(t - 1) - \theta_{C = x'}^*(t)} \right| \\
    \leq \frac{3d^2 \kappa \lambda_1}{T} + (t - 1)\left( {\max\limits_{i = 1}^{t - 1}\left| {\hat{\Delta}_{C = x'}(i)} \right| + \frac{3d^2 \kappa \lambda_1}{T}} \right),
    \end{matrix}
    $$
    *for any clique $C$ and time-point $t$. Both statements hold with probability at least $1 - (2/d)$.*

A proof for this statement can be found in [[567]](#backmatter-001.xhtml#b_9783110785944-010_ref_567).
