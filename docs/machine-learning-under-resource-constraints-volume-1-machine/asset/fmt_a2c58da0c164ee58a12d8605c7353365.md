### 4.3.4 Scalable and Expressive Graph Neural Networks

While the full-gradient in GNNs is straightforward to compute since we have access to *all* hidden node representations of *all* layers, this is not feasible in large-scale graphs due to memory limitations and slow convergence [\[455\]](#backmatter-001.xhtml#b_9783110785944-010_ref_455). Therefore, given a loss function *ϕ*, it is desirable to approximate its full-batch gradient stochastically

(4.29) $\nabla\mathcal{L} = \frac{1}{\left| \mathcal{V} \right|}\sum\limits_{v \in \mathcal{V}}\nabla\phi\left( {h_{v}^{(L)},y_{v}} \right) \approx \frac{1}{\left| \mathcal{B} \right|}\sum\limits_{v \in \mathcal{B} \subseteq \mathcal{V}}\nabla\phi\left( {h_{v}^{(L)},y_{v}} \right),\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\left( 4.29 \right)$

which considers only a mini-batch $\mathcal{B} \subseteq \mathcal{V}$ of nodes for loss computation. However, this stochastic gradient is still expensive to compute due to the exponentially increasing dependencies of node representations over layers, a phenomenon known as *neighbor explosion* [\[292\]](#backmatter-001.xhtml#b_9783110785944-010_ref_292). Specifically, the representation of a given node depends recursively on all its neighbor’s representations, and the number of dependencies grows exponentially with respect to the number of layers.

Recent works try to alleviate this problem by proposing various different sampling techniques [\[455\]](#backmatter-001.xhtml#b_9783110785944-010_ref_455), which can be broadly categorized as node-wise, layer-wise, and subgraph sampling strategies. In general, these techniques can all be viewed as different variants of dropping edges [\[600\]](#backmatter-001.xhtml#b_9783110785944-010_ref_600). *Node-wise sampling* [\[126, 292\]](#backmatter-001.xhtml#b_9783110785944-010_ref_126) recursively samples a fixed number *k* of 1-hop neighbors, leading to an overall bounded *L*-hop neighborhood of $\mathcal{O}(k^L)$ for each node. In contrast to tracking down inter-layer connections, *layer-wise sampling* techniques independently sample nodes for each layer, leading to a constant sampled size in each layer [\[126, 323, 747\]](#backmatter-001.xhtml#b_9783110785944-010_ref_126). Here, variance is further reduced via importance sampling or adaptive sampling techniques. In *subgraph sampling* [\[137, 731, 732\]](#backmatter-001.xhtml#b_9783110785944-010_ref_137), a full GNN is run on an entire subgraph $\mathcal{G}[\mathcal{B}]$ induced by a sampled batch of nodes $\mathcal{B} \subseteq \mathcal{V}$. Notably, most of these sampling approaches eliminate the neighbor explosion problem, but there are challenges to preserving the edges that present a meaningful topological structure.

Another line of work is based on the idea of decoupling propagations from predictions [\[234, 378, 710, 726\]](#backmatter-001.xhtml#b_9783110785944-010_ref_234). Here, input node features are first enhanced by performing several rounds of propagation via, say, the normalized Laplacian matrix or the personalized matrix, before they are inputted into an `Multilayer Perceptron (MLP)` to perform the final prediction. While this scheme enjoys fast training and inference time, it cannot be applied to any GNN, especially because the propagation is non-trainable. Recently, Huang, He, Singh, Lim, and Benson [\[321\]](#backmatter-001.xhtml#b_9783110785944-010_ref_321) proposed a simple post-processing step to correct and smooth the predictions of a simple graph-agnostic model via label propagation. While this step is orthogonal to recent GNN advancements, it can only be applied in transductive learning scenarios.

It is well known that the most powerful GNNs adhere to the same representational power as the WL test [\[701\]](#backmatter-001.xhtml#b_9783110785944-010_ref_701) in distinguishing non-isomorphic structures [\[509, 714\]](#backmatter-001.xhtml#b_9783110785944-010_ref_509), i.e., $h[v]^{(L)} \neq h[w]^{(L)}$ in case $C[V]^{(L)} \neq C[W]^{(L)}$, where $c[v]^{(L)}$ denotes a node’s coloring after *L* rounds of color refinement. However, in order to leverage such expressiveness, a GNN needs to be able to reason about structural differences across neighborhoods directly *during* training. It has been shown that GNNs that scale by sub-sampling edges are not capable of doing so [\[224\]](#backmatter-001.xhtml#b_9783110785944-010_ref_224):

**Proposition 10.** *Let* $f[\theta]^{(L)}:\mathcal{V}\to\mathbb{R}^{(d)}$ *be a L-layered GNN as expressive as the WL test in distinguishing the L-hop neighborhood around each node v ∈* $\mathcal{V}$. *Then there exists a graph* $\mathbf{A} \in \{0, 1\}^{|V|\times|V|}$ *for which* $f[\theta]^{(L)}$ *operating on a sampled variant* $\tilde{\mathbf{A}}$, $\tilde{a}[v,w] = \left\{ \begin{matrix} {\frac{\left| \mathcal{N}(v) \right|}{\left| \tilde{\mathcal{N}}(v) \right|},\quad\text{if~}w \in \tilde{\mathcal{N}}(v)} \\ {0,\quad\quad\quad\quad\quad\quad\quad\text{otherwise~}} \\ \end{matrix} \right.,$ *produces a non-equivalent coloring, i.e.,* $\tilde{h}[v]^{(L)} \neq \tilde{h}[w]^{(L)}$ *while* $c[V]^{(L)}= C[W]^{(L)}$ *for nodes v*, $w \in \mathcal{V}$*.*

Therefore, a special interest lies in the question if there exist scalable GNN variants that are as expressive as their full-batch counterpart.

#### 4.3.4.1 Scaling Graph Neural Networks via Historical Embeddings
