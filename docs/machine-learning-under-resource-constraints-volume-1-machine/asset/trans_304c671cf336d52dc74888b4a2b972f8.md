
关于数据缩减技术（如核心集和草图）的研究，无论从理论还是应用视角来看，都是一个不断发展的领域。对于线性回归等相对简单但重要的基础问题，其局限性和可能性现已被充分理解。但将研究扩展到更复杂、计算需求更高的方法（如贝叶斯统计和神经网络）在许多情况下仍然是开放且极具挑战性的。

我们预计贝叶斯统计领域将取得重大进展。这些方法的优势在于其坚实的理论统计基础、模型的可解释性以及内置的不确定性量化能力。然而，通常贝叶斯方法需要消耗巨量资源。我们的基础研究已展示出使这些方法具备可扩展性和资源高效性的初步途径，并为未来研究留下了巨大的潜力。

# 4 结构化数据

在本章中，我们将展示在资源感知环境下学习结构化数据模型的方法与技术。在实践中，数据模型通常可以构建为图，其中不同的数据点表示为节点，数据点之间的关系由边捕获。图出现在许多应用中，因为它们非常适合将物理世界的对象表示为部件的组合。例如，分子可以用图来描述，其中原子由节点表示，化学键由边表示。另一个例子是数学公式，其组合结构可由图在语义上进行良好建模（参见[第 4.5 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_005)）。此外，图中节点间的交互甚至可以随时间构建结构，从而形成时空概率图（参见[第 4.1 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_001)）。

一旦确定了特定类型的图模型，就可以训练模型来执行机器学习任务，如图分类；或者当我们将图解释为转移系统时，预测从一种状态变化到另一种状态的概率。本章使用的学习方法主要可分为*判别式*图神经网络（GNN）和*生成式*随机场。GNN 采用的学习方法源自卷积神经网络（CNN），通过消息传递函数聚合每个节点邻域的信息（参见[第 4.2 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_002)、[4.3 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_003)、[4.5 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_005)）。随机场是一种概率模型，它捕获多个随机变量之间的依赖关系，并经过训练以回答在事件 *B* 已发生的条件下事件 *A* 的概率查询（参见[第 4.1 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_001)）。GNN 和随机场是不同的方法，但两者都可用于表达同类问题。例如，要推断每个事件的条件概率，我们可以采用分层方法使用多个 GNN [[376]](#backmatter-001.xhtml#b_9783110785944-010_ref_376)。然而，它们处理计算资源的方式截然不同。

以下是本章概览。[第 4.1 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_001)提出了一种利用随机场训练时空网络的新模型，称为*时空随机场*。该模型通过理论基础扎实的通用重参数化，在不损失精度的情况下降低了内存消耗。[第 4.2 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_002)重点从理论运行时间和算法可扩展性角度解释了*Weisfeiler-Leman 算法*。随后，综述了 Weisfeiler-Leman 算法与使用图核和 GNN 的学习方法之间的联系。[第 4.3 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_003)引入了 GNN 中可微消息传递的统一框架，并提出了提高其可扩展性的技术。[第 4.4 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_004)提出了一个在有向图中计算高质量割的框架，该框架在共享内存中扩展性良好，可用于半监督学习和数据压缩。[第 4.5 节](#9783110785937_013188.xhtml#b_9783110785944-004_s_005)介绍了一种搜索科学论文的新技术，该技术使用数学公式而非词语。一个 GNN 在从 arXiv 提取的海量数据集上训练，结果表明该模型在实践中扩展性良好。

## 4.1 时空随机场

*Nico Piatkowski*

*Katharina Morik*

**摘要：** 参数共享是各种最先进机器学习方法中的关键技术。其核心思想简单而有效。给定一个高度过参数化的模型，其输入数据服从某种重复结构，则将多个参数子集绑定在一起。一方面，这减少了参数数量，简化了相应的估计问题。另一方面，信息从数据空间的一个部分传递到另一个部分，从而使模型能够学习训练数据中从未显式出现的模式。在资源受限的数据分析背景下，主要关注点在于由较低的参数空间维度和推测较低的样本复杂度所带来的内存需求减少。在本贡献中，参数共享的基础概念被迁移到了时空领域。更确切地说，针对有限长度的非平稳时间序列，提出了一种无向概率图模型（即马尔可夫随机场，MRF）的重参数化方法。MRF 等价于深度潜变量模型 [[568]](#backmatter-001.xhtml#b_9783110785944-010_ref_568)，但具有更易于解释的结构。此类时空模型的数据自然产生于分布式传感器网络。然而，相应的机器学习模型过大，无法直接在传感器层面处理。重参数化的概率模型表现出非常稀疏的参数空间，这有助于直接从压缩模型进行概率推断。本节研究了底层重参数化的不同变体，并在基准数据上通过数值实验对它们进行了比较。此外，我们提出了如何将学习过程直接嵌入到传感器网络中：在分布式设置中应用近端优化。结果表明，参数优化纯粹是局部的，传感器节点间的通信仅用于梯度计算。包括交通模型和传感器网络模型在内的不同实际应用，印证了压缩时空随机场（STRF）的实用相关性。
