
最初尝试使计算更稳健地抵抗溢出，依赖于这样一个事实：消息 `m[v]`[→`u`](`x`) 可以任意缩放，只要对所有 `x` 使用相同的缩放，生成的边缘概率就不会改变。尽管如此，消息不能像浮点运算那样简单地除以它们的和，因为整数除法会将所有消息钉死在 0。许多尝试通过位移操作来缩放整数消息，仅在相对较小的图结构上有效，但所有这些方法都遭受了信息丢失的问题，每当为了防止溢出必须移出太多位时，就会发生这种情况。

图 9.1 具有 50 个节点且每个节点 2 个状态的 50 棵随机树的边缘概率估计。边缘概率由位长度近似 ( ^`p`) 和标准 BP (`p`) 在相同的参数向量 `θ` 上计算得出。

作为该问题的解决方案，定义了新的消息。我们不计算原始的和积消息，而是提议计算整数消息位长度的近似值。近似位长度 `β[vu]` (`y`) 和相应的消息 `m̂`^[`vu`](`y`) 由下式给出：

```
(9.11) β[v u](y) := max[x] θ[v u = x y] + θ[v = x] + θ[u = y] + ∑[w ∈ N[v] ∖ {u}] β[w v](x) (9.12)
(9.13) m̂[v u](y) := 2^(β[v u](y)) (9.13)
(9.14) = max[x] ψ[v u](x, y) ∏[w ∈ N[v] ∖ {u}] m̂[w u](x) (9.14)
```

`m` 和 `m̂` 如何相互关联是一个自然的问题。由位长度近似产生的消息 `m̂` 类似于最大积消息 [[404]](#backmatter-001.xhtml#b_9783110785944-010_ref_404)。它们的量级通过以下引理与原始消息 `m` 相关联。

**引理 1。** *设* (`v`, `u`) *为 G* = (`V`, `E`) *的一条边，h[v]* := `|`𝒳`[v]|` 为 v 状态空间的大小，且 n[v]* := `|`𝒩`[v]|` 为其邻居的数量。若 h[v]* ≥ 2 *∧ ∀y ∈* 𝒳`[u]` *: ∃x ∈* 𝒳`[v]` *: θ*[`vu`][`=xy`] + `θ`[`v`][`=x`] + `θ`[`u`][`=y`] > 0*，则*

```
m̂[v u](x) < m[v u](x) ≤ m̂[v u]^(h[v])(x).
```

该陈述可通过顶点度数的数学归纳法证明。注意，这意味着 `M[v](y) = ∏[w ∈ n[v]] m[w v](x) ≤ ∏[w ∈ n[v]] m̂[w v]^(h[v])(x) = M̂[v]^(h[v])(y)`。当涉及到边缘概率的逐点估计时，会发现由于近似消息，某些边缘概率根本无法出现。[图 9.1](#9783110785937_093138.xhtml#b_9783110785944-009_fig_001) 显示了分别由 `m` 和 `m̂` 生成的随机参数的边缘概率。人们清楚地看到概率空间是如何被近似消息离散化的。也可以看到，用 `m̂` 计算的近似边缘概率存在误差，因为如果误差为零，所有点都将位于对角线上。

前面的引理有助于推导真实推理结果与由消息更新方程 9.14 产生的结果之间距离的估计。

**定理 1。** *设* `β[v]`^⋆ := `max[y] max[u] β[u v](y)` *为 v 处的最大传入位长度，并假设引理 1 的前提条件成立，则*

```
D(p[v]∥p̂[v]) ∈ 𝒪(n[v] h[v] β[v]^⋆),
```

*其中 D* (`p[v]‖` ^`p[v]`) *表示由消息更新 m[vu]* (`y`)* 计算的边缘概率质量函数 p[v] 与由 m̂*^[`vu`](`y`)* 计算的* *p̂[v] 之间的 Kullback-Leibler (KL) 散度。*

该结果可通过将 BP 边缘概率（方程 9.9）代入 KL 散度的定义并两次应用引理 1 来推导。KL 仍然是无界的，因为 `β[v]`^⋆ 没有界。尽管如此，它表明 `p[v]` 和 `p̂[v]` 的 KL 散度取决于状态空间大小 `|`𝒳`[v]|` 和邻域大小 `|`𝒩`[v]|`。这种关系也可以在 [第 9.1.4 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001_s_004) 的数值实验中观察到。关于消息误差如何普遍影响信念传播结果的综合讨论见 [[332]](#backmatter-001.xhtml#b_9783110785944-010_ref_332)。

### 9.1.3.1 参数估计

在下文中，推导了一种基于 MLE 闭式解的整数参数估计方法。回顾 $\mathbb{E}_{\mathcal{D}}[\phi(\mathbf{x})] = \frac{1}{|\mathcal{D}|}{\sum_{\mathbf{x} \in \mathcal{D}}\phi}(\mathbf{x})$ 并设 `f` := ∑[`x` ∈ 𝒟]`ϕ`(`x`) 和 bl (`a`) = ⌊log[2]`a`⌋ + 1 为 `a` 的位长度。利用此，可以找到最优参数的整数上界。

```
(9.15) log[2]𝔼[𝒟][ϕ[v = x](x)] = log[2]f[v = x] − log[2]|𝒟| (9.15)
(9.16) ≤ bl f[V = x] − bl|𝒟| =: θ̃[v = x] (9.16)
(9.17) log[2]𝔼[𝒟][ϕ[v u = x y](x)] ≤ bl f[v u = x y] (9.17)
(9.18) − bl f[v = x] − bl f[v u = x y] + bl |𝒟| =: θ̃[v u = x y] (9.18)
```

不幸的是，这些估计中的大多数是负数，由于整数限制这是不允许的。设 `s` := `max[1 ≤ i ≤ d]` − `θ̃`[`i`] 为幅度最大的 `θ̃` 的负分量。现在，考虑权重

```
θ̃[v = x]^+ := s + θ̃[v = x], θ̃[v u = x y]^+ := s + θ̃[v u = x y]
```

带有 `s` := (`s`, `s`, `. . .` , `s`)[⊤] ∈ **ℝ**[`d`]。显然，用 bl 替换 log[2] 会在 `θ̃` 中引入误差 `θ̃`。以下引理表明，移位 `s` 不会引入新的误差。

**引理 2。** *设 **s*** := (`s`, `s`, `. . .` , `s`)[⊤] ∈ **ℝ**[`d`] 且 ϕ 为过完备充分统计量，则 ℓ*(`θ` + `s`) = `ℓ`(`θ`)*."

**证明**：由于 `ϕ` 是过完备的，因此有 ⟨`s`, `ϕ`(`x`)⟩ = const，`∀x`，因而：

```
ℓ(θ) − ℓ(θ + s)
= 1/D ∑[x ∈ 𝒟] log (∑[y ∈ x] exp ⟨θ + s, ϕ(y)⟩) / (exp ⟨s, ϕ(x)⟩ ∑[y' ∈ X] exp ⟨θ, ϕ(y')⟩) = 0. (9.19)
```

[第 9.1.2 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001_s_002) 中定义的 `ϕ` 实际上是过完备的。这现在可用于限制移位整数参数 `θ̃`^+ 的训练误差。
