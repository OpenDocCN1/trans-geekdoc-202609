实验上，他们展示了其 `k-WL` 的一个变体在许多标准基准数据集上达到了新的最先进水平，同时比 `k-WL` 快几个数量级。

#### 4.2.4.5 基于 Weisfeiler-Leman 算法的其他核

在下文中，我们综述了其他建立在 Weisfeiler-Leman 范式之上的图核。

**Weisfeiler-Leman 核框架** 修改和增强图核的一种通用技术是修改其标签，以便编码额外信息。这可以通过计算 `1-WL` 的前 `h ≥ 0` 个颜色 `C[0]¹, …, C[h]¹` 来实现 [[627]](#backmatter-001.xhtml#b_9783110785944-010_ref_627)。然后，给定一个用作基础核的任意图核，相应的 Weisfeiler-Leman 核是将基础核应用于具有标签 `C[i]¹`（其中 `i` 在 `{0, ..., h}` 中）的图对的求和。*Weisfeiler-Leman 子树核*（见 [第 4.2.4.1 节](#9783110785937_013188.xhtml#b_9783110785944-004)）是通过计算公共顶点标签的基础核获得的。另一种常用的实例是通过使用最短路径核 [[65]](#backmatter-001.xhtml#b_9783110785944-010_ref_065) 获得的。

**哈希图核框架** 在化学信息学或生物信息学中，图的边和顶点通常带有实值信息注释，例如物理测量值 [[508]](#backmatter-001.xhtml#b_9783110785944-010_ref_508)。能够考虑这些属性的先前图核相对较慢，并采用核技巧 [65, 222, 394]。因此，这些方法无法扩展到大型图和数据集。此外，由于离散本质，Weisfeiler-Leman 子树核等核无法充分处理此类连续信息。为了克服这一问题，引入了哈希图核框架 [[507]](#backmatter-001.xhtml#b_9783110785944-010_ref_507)。其思路是使用随机哈希函数迭代地将连续属性转化为离散标签。这允许应用快速、显式的图特征映射（例如 Weisfeiler-Leman 子树核），而这些映射仅限于离散注释。在每次迭代中，算法采样新的哈希函数并计算特征映射。最后，将所有迭代的特征映射组合成一个特征映射。为了获得 `ℝ^d` 中属性之间有意义的相似度，要求两个独立选择的随机哈希函数 `h[1], h[2] : ℝ^d → ℕ` 的碰撞概率 `Pr[h[1](x) = h[2](y)]` 等于 `ℝ^d` 上的一个合适的核。配备这样一个哈希函数，为几个能够处理连续信息的最先进核推导出了近似结果 [[507]](#backmatter-001.xhtml#b_9783110785944-010_ref_507)。特别地，我们推导出了一个 Weisfeiler-Leman 子树核的变体，它可以处理连续属性。广泛的实验研究表明，哈希核框架的实例在达到最先进分类准确率的同时，比专门设计用于处理连续信息的核快几个数量级。

**图核中的邻域聚合** 邻域聚合的思想被广泛使用，且定义上往往存在细微差别。为求完备，我们提及几个遵循这一通用思想的图核。*邻域哈希核* [[314]](#backmatter-001.xhtml#b_9783110785944-010_ref_314) 在精神上类似于 Weisfeiler-Leman 子树核，但用位向量表示简单标签，并使用逻辑运算和哈希来编码直接邻域以提高效率。[[528]](#backmatter-001.xhtml#b_9783110785944-010_ref_528) 中提出的传播核提供了一个通用框架，基于标签和属性的信息传播方案来定义图核。传播（例如基于随机游走）在两个输入图上单独执行，并通过比较每次传播步骤后的标签分布来获得核。在连续（多维）属性的情况下，使用单个哈希函数来获得离散标签。[[537]](#backmatter-001.xhtml#b_9783110785944-010_ref_537) 中提出了一个用于核的通用消息传递框架，其中在邻域聚合步骤中引入了最优赋值的概念（见第 4.2.4.2 节）。*持久 Weisfeiler-Leman 核* [[597]](#backmatter-001.xhtml#b_9783110785944-010_ref_597) 将 `1-WL` 与持久同调相结合，以提取环等拓扑特征。将 `1-WL` 与图同态联系起来的最新理论结果 [[167]](#backmatter-001.xhtml#b_9783110785944-010_ref_167) 被用来定义具有与 `1-WL` 相同表达能力但不同特征空间的图核 [[533]](#backmatter-001.xhtml#b_9783110785944-010_ref_533)。

### 4.2.5 图神经网络及其与 Weisfeiler-Leman 算法的联系

GNNs 作为图核在图分类和其他图机器学习任务（如节点分类或回归）中的替代方案而出现。标准 GNNs 可以被视为 `1-WL` 的神经网络版本，其中颜色被连续特征向量取代，并使用神经网络聚合节点邻域 [252, 292, 375]。实际上，GNN 框架可以被视为实现了一种基于图的连续形式的“消息传递”，其中局部邻域信息被聚合并传递给邻居 [[252]](#backmatter-001.xhtml#b_9783110785944-010_ref_252)。通过部署可训练的神经网络来聚合局部节点邻域中的信息，GNNs 可以与分类或回归算法的参数一起以端到端的方式进行训练，与经典 `1-WL` 的核对应物相比，这可能允许更大的适应性和更好的泛化能力。

GNN 模型由一堆神经网络层组成，其中每一层聚合每个节点周围的局部邻域信息（即邻居的特征），然后将聚合后的信息传递给下一层。有关架构示意图，请参见 [图 4.8](#9783110785937_013188.xhtml#b_9783110785944-004_fig_008)。
