

# 广义线性模型与逻辑回归

## 广义线性模型 (GLMs)

广义线性模型 (GLMs) 将经典线性回归扩展到了更灵活的生成分布类，参见 [479](#backmatter-001.xhtml#b_9783110785944-010_ref_479)。通常假设因变量的实现值基于独立观测，源自指数族分布的某个成员。此类分布的著名例子包括正态分布、二项分布、泊松分布和伽马分布。因变量目标 `Y` 的期望通过链接函数 `h` 与线性预测器 `Xβ` 相连：

```
h(𝔼(Y)) = Xβ
```

其中 `X` 是自变量特征变量，`β` 是未知参数向量。

关于用于近似回归问题的采样方法有大量研究，包括 `ℓ2`-回归 [188, 189] 和 `ℓ1`-回归 [141, 142, 637]。这些被推广到所有 `p ∈ [1,∞)` 的 `ℓp`-回归 [161, 709]。较新的工作研究了用于 `M`-估计量 [143, 144, 146] 和广义线性模型 [327](#backmatter-001.xhtml#b_9783110785944-010_ref_327) 的采样方法。我们在核心集和逻辑回归 [515, 517] 以及 `p`-广义 Probit 回归 [513](#backmatter-001.xhtml#b_9783110785944-010_ref_513) 的草图方面继续了这条研究路线。

## 逻辑回归

逻辑回归是广义线性模型的一个重要实例 [479](#backmatter-001.xhtml#b_9783110785944-010_ref_479)。逻辑回归的目标是基于观测数据估计隐式定义伯努利分布的参数 `β`。一个典型任务是评估变量在预测患者患某种疾病概率方面的影响和交互作用，依据为其个人、生理和诊断数据。该学习任务基于一组固定的患者数据 `X ∈ ℝ^n^(×d)` 和相应的标签 `Y ∈ {−1, +1}[n]`，指示患者是否健康。将标签折叠进数据中，我们为所有 `1 ≤ i ≤ n` 定义行向量 `Z[i] = Y[i]X[i]`。

我们在 [517](#backmatter-001.xhtml#b_9783110785944-010_ref_517) 中的第一个结果表明，在最坏情况下，对于任何数据缩减技术，都不可能以亚线性方式（相对于输入规模）压缩数据。为了绕过这一限制，我们引入了一个新参数，可用于限制压缩数据集 `Z` 进行逻辑回归的复杂度。该参数定义为

```
μ(Z) = sup_{β ∈ ℝ^d \ {0}} ||(Zβ)^+||_1 / ||(Zβ)^-||_1
```

其中 `(Zβ)^+`、`(Zβ)^-` 分别仅包含 `Zβ` 的正项和负项。如果数据集满足 `μ(Z) ≤ μ`，我们称其为 `μ`-复杂。如果数据对于一个较小的、不一定是常数的 `μ` 是 `μ`-复杂的，则基于 [219, 416] 的敏感度框架，存在一种重要性采样和重加权方案，能以高概率生成大小为 `O(ε^(-2) μ √n d^(3/2) log^O(1)(μnd))` 的 `ε`-核心集。一种更复杂的递归采样方案可生成大小为 `O(ε^(-4) μ³ d³ log^O(1)(μnd))` 的 `ε`-核心集，如果数据表现良好且输入规模特别大，这将更有利。这些是逻辑回归首个可证明的亚线性核心集构造。

参数 `μ(Z)` 具有直观的统计学解释，正如 [517](#backmatter-001.xhtml#b_9783110785944-010_ref_517) 详述的那样，可能具有独立的研究价值。在实践中，`μ(Z)` 很小的情况并不罕见，因为否则逻辑回归会表现出方法论上的弱点。

我们在 [517](#backmatter-001.xhtml#b_9783110785944-010_ref_517) 中基于真实世界基准数据的实验评估表明，存在一种基于草图 QR 分解的高效实现，其准确性优于均匀随机采样和最先进的启发式方法（如 [327](#backmatter-001.xhtml#b_9783110785944-010_ref_327) 所述），同时在运行时间方面具有竞争力。

同时，通过将重要性采样分布中的杠杆分数替换为 `ℓ1`-Lewis 权重 [462](#backmatter-001.xhtml#b_9783110785944-010_ref_462)，核心集大小已减少至 `Õ(ε^(-2) μ² d)`。这也略微提高了实验准确性，尽管以增加运行时间为代价。

然而，已知核心集构造的一个局限性是它们需要对数据进行两次遍历：一次用于近似重要性采样分布，另一次用于子采样和收集数据。递归改进到对数多项式大小，或计算 Lewis 权重，甚至需要 `O(log log n)` 次遍历。由于假设 `μ(Z)` 很小，Merge & Reduce 框架在此无济于事。有人可能会辩称，随机顺序流对每个数据批次都满足此条件，但在最坏情况下，即使 `μ(Z) = 1`，对于某个批次 `Z[i]` 也会有 `μ(Z[i]) → ∞`。

## 逻辑回归草图

为了针对温和的 `μ`-复杂数据创建具有所有计算灵活性的单遍历交错流算法，我们开发了首个逻辑回归线性草图。我们的主要结果 [515](#backmatter-001.xhtml#b_9783110785944-010_ref_515) 是一个堆叠稀疏随机矩阵的分布

```
Π = [ S_0
      S_1
      ⋮
      S_O(log n)
      T ]
```

此处，在每一层 `i`，`S[i]` 首先对输入点进行 `2^(-i)` 比例的子采样，然后将它们哈希到少量的桶中，通过求和处理同一桶中的碰撞。该构造由一个小的均匀采样矩阵 `T` 补充。生成的草图将 `d` 维中的 `n` 个输入点减少到仅 `O(poly(μd log n)) × d`。我们证明 `ΠZ` 可以在交错流上以输入稀疏度时间计算，即每个非零输入元素花费 `O(1)` 时间。此外，以高概率（取决于 `Π` 的随机构造），对于 `β̃ ∈ argmin_β f(ΠZβ)`，有

```
f(Zβ̃) ≤ O(1) min_β f(Zβ)
```

其中 `f` 表示逻辑损失函数 [515](#backmatter-001.xhtml#b_9783110785944-010_ref_515)。该方法背后的直觉是：坐标根据*权重类别*分组，即具有相似损失的类别，可在分析中分别处理。成员数量少的权重类别将在元素数量多的草图层级上得到良好近似，因为大致需要对所有成员进行子采样以获得良好估计。成员数量多的权重类别将在子采样样本较少的层级上得到良好近似。因为如果太多成员在子采样中幸存，在均匀哈希下也会有太多碰撞，这要么导致它们相加时产生大的高估，要么由于不对称性相互抵消导致大的低估。处理逻辑损失的不对称性是另一个需要控制的问题。如果元素的符号被混淆，误差无法被界定，因为对于无约束逻辑回归的损失函数 `ℓ(·)`，比率 `ℓ(x)/ℓ(-x)` 是无界的。最后，可能有太多接近零的微小贡献。与范数不同，逻辑回归给它们分配非零常数损失。因此它们的贡献可能变得显著。这由大小为 `Õ(μd)` 的小均匀样本 `T` 来处理。
