
获得的列簇（本例中即词簇的特征簇）如[图 5.19](#9783110785937_041148.xhtml#b_9783110785944-005_fig_019)–[5.20](#9783110785937_041148.xhtml#b_9783110785944-005_fig_020)所示。此处仅展示正交松弛法 OO 的模糊簇指示器；NN 的结果非常相似[[312]](#backmatter-001.xhtml#b_9783110785944-010_ref_312)。模糊簇 *s* 的词云中词 *i* 的大小对应于分配的权重 `X[is]` ≥ 0。反过来，BROCCOLI 的二值词指示器可视化为：词云中词的大小与该词被分配到的簇数量的倒数成正比。即，仅属于各自簇的词比分配到多个簇的词更大。观察簇的可视化，我们看到词 `max` 在许多簇中显著出现。词 `max` 获得了相对非常高的词频。平均词频为 1.59，99% 的词的词频小于或等于 8。词 `max` 出现在 149 篇帖子中，词频在 \[1, 800\] 区间内。因此，词 `max` 在少数帖子中达到异常高的词频，从而扮演了特殊角色。不同聚类方法对词 `max` 这种异常高词频的处理方式不同。OO 几乎在所有簇中都给该词很高的权重，而 BROCCOLI 则忽略了该词的高频。这展示了基于二值簇指示矩阵的双聚类更模块化的方法及其对异常值的鲁棒性。

所有聚类方法均可检测到针对特定主题的有意义簇。比较各方法涉及的主题，可见 BROCCOLI 提供了数据集的独特视角，例如识别出了方法 OO 未包含的 `religion` 簇。因此，尽管 BROCCOLI 的优化利用了松弛目标，其结果相对于松弛对应物仍提供了另一种数据视角。

### 5.4.10 应用、影响与未来工作

本工作回顾了具有矩阵分解目标的聚类优化方法。我们对流行聚类目标的比较表明，大多数方法旨在寻找划分簇，遵循排他性约束：每个点恰好分配到一个簇。Lloyd 算法的合理改进保证了在划分约束特别是二值约束下，目标函数收敛到局部最优。这相较于松弛二值约束或启发式的其他实用替代方案具有不可否认的优势。松弛方法的主要缺点在于离散化步骤，其中针对松弛目标解可能提供的理论保证通常会丢失。然而，在某些应用中，支持按 Lloyd 交替最小化的排他性约束是不可行的。在文本或基因组数据聚类等方面，重叠和非穷尽聚类更有可能代表“真实”模型。在这种情况下，相应目标高效优化的理论基础尚不完善。

我们提出了一个基于近端交替最小化的重叠聚类通用优化框架。特别地，我们提出了两种优化双聚类目标的方法，此时排他性假设最常失效。方法 `PAL-TILING` 旨在优化布尔矩阵分解，用于推导二值数据的重叠和非穷尽簇。方法 `BROCCOLI` 旨在基于三因子分解对实值数据进行双聚类。

我们的实验分析在两个实例上凸显了所提优化方法的威力：基于 MDL 的 BMF 方法 `Primp`（此处记为 `PAL-TILING`）[[310]](#backmatter-001.xhtml#b_9783110785944-010_ref_310) 和 `BROCCOLI` 框架的 NMF 初始化[[312]](#backmatter-001.xhtml#b_9783110785944-010_ref_312)。合成数据实验特别表明了我们所提优化方法对噪声、重叠程度和异常值数量的鲁棒性（参见[图 5.16](#9783110785937_041148.xhtml#b_9783110785944-005_fig_016)和 5.17）。对发现簇的定性检查表明了发现簇的意义性（参见[图 5.20](#9783110785937_041148.xhtml#b_9783110785944-005_fig_020)和[5.18](#9783110785937_041148.xhtml#b_9783110785944-005_fig_018)）。

这使得 `PAL-TILING` 和 `BROCCOLI` 成为一种理论基础扎实、实践表现良好且灵活的方法，有潜力激发对非排他聚类优化特别是离散结构学习的进一步研究。

**未来工作** 所提优化方法灵活，有潜力确立一种基于矩阵分解的聚类结构优化标准方法，且不要求排他性假设。注意，许多流行聚类方法基于（或可视为）矩阵分解：`k-means`、谱聚类及深度聚类变体。此外，矩阵分解中应对特定数据特征的技术可轻松迁移至 `PAL-TILING` 和 `BROCCOLI` 采用的优化方案。

此外，非凸优化是持续研究领域。存在 `PALM` 优化方案的随机[[163, 187]]、加速[[427]](#backmatter-001.xhtml#b_9783110785944-010_ref_427)和惯性[[581]](#backmatter-001.xhtml#b_9783110785944-010_ref_581)变体。即，所提优化框架的威力随底层优化方案的研究而增长。针对二值约束特别是聚类的非凸优化方案分析，将是进一步研究课题。

# 6 硬件感知执行
