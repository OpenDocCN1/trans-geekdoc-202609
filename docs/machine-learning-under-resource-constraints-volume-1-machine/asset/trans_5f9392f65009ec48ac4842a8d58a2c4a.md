
研究表明，如果要持续跟踪信道占用情况以使传输延迟尽可能低，无线电信道上活跃的去中心化信道接入会导致所有等待用户的功耗增加。相反，在中心组织的蜂窝无线网络中，`User Equipment (UE)`（用户设备）的能耗主要由上行传输决定，尤其是在需要高传输功率时。然而，接收所占的比例主要取决于传输时长。事实上，通过`Carrier Aggregation (CA)`（载波聚合）增加额外的接收路径，不仅能提高数据速率，还能降低`UE`的能耗。

由于发射功率的知识对于估算功耗至关重要，但大多数`UE`不向应用层提供此信息，因此也提出了一种基于`Machine Learning (ML)`（机器学习）的方法，利用可用参数（如接收信号的强度和质量）来估算发射功率。

## 9.2.1 简介

未来的智能仓库将不再把库存物品视为静态资源，而是将容器转变为`Cyber Physical Systems (CPSs)`（网络物理系统），使其主动、自主地参与物流流程的优化。因此，必须解决大规模`Internet of Things (IoT)`（物联网）固有的新挑战，例如共享通信介质中的信道接入问题。

此类仓库场景的一个示例如[图 9.5](#9783110785937_093138.xhtml#b_9783110785944-009)所示。各种自主运输系统用于将货物运入或运出仓库。单个货物存放在智能容器中，它们可以随时通过无线电提供关于其当前内容及所含货物的信息。对于此目的所用的嵌入式系统而言，能量供应是一个特殊的挑战。由于场地面积大，市电和电池供电均被排除，因此平台必须通过*能量采集*（例如利用光伏）获取运行和通信所需的能量，并必须对其进行极高效的管理。

为了提取特定库存，分布式`Access Points (APs)`（接入点）向仓库发送库存查询。内容匹配的容器会回答这些查询，并指明所含数量。随后，运输系统将请求的数量运送到拣选点以供进一步使用。

由于此类请求可能导致大量回复（取决于货物和库存的分布），必须协调信道接入以避免传输过程中的碰撞。分布式信道接入方法很快会达到其容量极限，并因碰撞、重复传输和长时间等待空闲信道而增加网络用户的能耗。在这方面，`CRC 876`开发并汇聚了用于记录、分析和优化能耗的创新方法[206, 209]，将在以下小节中进行讨论。

这与具有中心组织信道接入的移动通信网络形成对比，后者将在本节后面讨论。如果我们接受仅在一个频段上运行一种特定技术的限制，则可以换取更高的频谱效率。中心功率控制或小区间干扰协调等技术即使在高用户密度下也能实现资源高效的传输。`CRC 876`的大量研究表明，当前移动无线终端（`UE`）的能耗主要由数据传输决定，尤其是在高传输功率下。专门开发的`CoPoMo`支持各种权衡，例如针对不同频率范围、建筑密度和移动性配置文件，在传输时间、能耗和频谱资源需求之间进行权衡。[第 9.2.4 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_002_s_004)介绍了`CoPoMo`的基本概念，并展示了两项研究：一项涉及传输带宽与能耗之间的权衡，另一项则提出了一种基于`ML`的、利用可用质量指标进行`UE`侧发射功率估算的方法。

## 9.2.2 分布式信道接入下的功耗

在非授权频段中，通常使用分布式信道接入方法以实现不同技术的公平共存。这些频段包括 2.4 GHz 的`Industrial Scientific Medical (ISM)`（工业、科学、医疗）频段和 868 MHz 的`SRD`频段。后者用于`PhyNode`的通信。分布式信道接入基于`Listen Before Talk (LBT)`（监听后发送）原则，该原则以类似形式作为`Carrier Sense Multiple Access Collision Avoidance (CSMA/CA)`（载波监听多路访问/冲突避免）用于`WLAN`和`ZigBee`网络。对于`SRD`频段，信道接入由`European Telecommunications Standards Institute (ETSI)`（欧洲电信标准协会）规定，其示意图如[图 9.6](#9783110785937_093138.xhtml#b_9783110785944-009_fig_006)所示。有传输意图的站点会保留传输，直到传输信道空闲。当信道变为空闲时，系统会额外等待一个退避时间 `t[L]` = `t[F]` + `t[PS]`，其中 `t[F]` = 5 ms。`t[PS]`在每次启动时从 0 ms 到 5 ms 的区间内随机选择。如果经过 `t[L]` 后信道仍然空闲，则执行传输。否则，系统会再次等待空闲信道，包括一个新选择的退避时间 `t[L]`。为了在信道利用率低时加速，如果信道在初始传输请求和 `t[F]` 到期之间持续空闲，站点可以将首次传输尝试的 `t[PS]` 设置为 0 ms。

[图 9.7](#9783110785937_093138.xhtml#b_9783110785944-009_fig_007)展示了无线电频谱中三个站点的信道占用情况。记录开始时，信道被干扰源持续占用。三个站点已有传输意图，暂时保留传输。关闭干扰源后，三个站点根据接入方案和随机退避间隔依次传输。

然而，短 s 会导致信道利用率低，并因相对较长的等待时间而降低频谱效率。此外，信道接入方法要求在传输意图到达和实际执行传输之间持续监控无线电信道。这种监控的持续时间随信道利用率的增加而增加。由于接收电路在此期间必须处于激活状态，所有竞争站点的功耗显著增加。
