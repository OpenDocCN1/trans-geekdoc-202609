
我们观察到 `μ` 和 `ζ(A[a])` 之间存在一个匹配，该匹配实现了 `d[dF](ζ(A[a]), μ) ≤ 1`。由于 `ζ(A[a])` 仅由顶点 `v[1]` 和 `v[−3]` 组成，且在 `ℝ` 中不存在到这两个顶点距离均至多为 1 的点，因此 `μ` 中的每个顶点只能匹配到 `ζ(A[a])` 中的一个顶点。由于在 `ζ(A[a])` 中任意两个 `v[−3]` 顶点之间都有一个 `v[1]` 顶点，`μ` 中的一个顶点最多只能匹配到 `ζ(A[a])` 中的一个 `v[−3]`。对于 `ζ(A[a])` 中的 `v[1]` 顶点也同理。因此 `μ` 中的每个顶点恰好匹配到 `ζ(A[a])` 中的一个顶点。类似地，`μ` 中的每个顶点也恰好匹配到 `ζ(B[b])` 中的一个顶点。

我们可以将 `μ` 的顶点划分为 `2a + 1` 个子集 `M[i]^(a)`，`i ∈ {1,…,2a+1}`，其中同一子集 `M[i]^(a)` 内的所有顶点都映射到 `ζ(A[a])` 中的第 `i` 个顶点（在实现 `d[dF](ζ(A[a]), μ)` 的匹配中）。类似地，我们可以将 `μ` 的顶点划分为 `2b + 1` 个子集 `M[j]^(b)`，`j ∈ {1,…,2b+1}`（使用实现 `d[dF](ζ(B[b]), μ)` 的匹配）。

我们将这些划分合二为一。我们将代表 `v[−3] ∈ ζ(A[a])` 的子集 `M[i]^(a)` 称为 **A-子集**，将代表 `v[3] ∈ ζ(B[b])` 的子集 `M[j]^(b)` 称为 **B-子集**。

我们注意到，`μ` 中不存在同时属于某个 A-子集和某个 B-子集的顶点，否则该顶点将同时到 `v[3]` 和 `v[−3]` 的距离至多为 1。我们将 A-子集和 B-子集纳入新的划分中（并称之为字母子集）。根据构造，共有 `a + b = t` 个字母子集。`μ` 中剩余的顶点——位于沿 `μ` 的第一个字母子集之前、最后一个字母子集之后，或两个字母子集之间——形成两两不相交的缓冲子集，从而与字母子集一起定义了 `μ` 顶点的一个划分。最多可以有 `t + 1` 个缓冲子集，因此构造的 `μ` 顶点划分中最多有 `2t + 1` 个子集。[图 5.9](#9783110785937_041148.xhtml#b_9783110785944-005_fig_009) 展示了这样一个划分的示例。

序列 `S[*]` 可以利用 `μ` 的构造划分来生成，方法是将 A-子集替换为字母 `A`，将 B-子集替换为字母 `B`。缓冲子集直接省略。序列 `S[*]` 的长度为 `t`。我们需要证明 `S[*]` 是 `𝒮` 中所有序列的超序列。

设 `S[i] ∈ 𝒮` 中的某个序列为 `η(S[i]) ∈ 𝒢` 其代表曲线。由于 `μ` 是 `𝒢 ∪ {ζ(A[i]), ζ(B[j])}` 在距离 1 处的中间曲线，存在 `η(S[i])` 和 `μ` 的一个匹配，实现 `d[dF](η(S[i]), μ) ≤ 1`。在这个匹配中，某个 A-子集（`μ` 顶点划分中的）中的一个顶点不能匹配到两个不同字母工具（在 `η(S[i])` 中）中的顶点，因为分隔两个字母工具的缓冲工具包含顶点 `v[1]`，该顶点无法以距离至多 1 的方式匹配到 A-子集中的顶点。类似地，某个 B-子集中的一个顶点也不能匹配到两个不同字母工具中的顶点。

`η(S[i])` 中的每个字母 `A` 工具都包含顶点 `v[−3]`，它必须匹配到 `μ` 的某个 A-子集中的顶点（否则根据构造，它将到 `v[1]` 的距离至多为 1）。类似地，`η(S[i])` 中的每个字母 `B` 工具都包含顶点 `v[3]`，它必须匹配到某个 B-子集中的顶点。因此 `η(S[i])` 中的每个字母工具都与 `μ` 中的一个字母子集一一对应，且 `η(S[i])` 中字母工具的序列对应于 `μ` 中字母子集的序列。因此 `S[i]` 是 `S[*]` 的子序列，正如所声称的。 ![](graphic/b_9783110785944-005_ingr_070.png)

引理 19 和引理 20 展示了一个从 SCS 问题（已知为 **NP-hard**）到（每种变体的）MIDDLE CURVE 问题的有效归约。给定 SCS 实例 `(𝒮, t)`，对于一对 `(a, b) ∈ ℐ[t]`，MIDDLE CURVE 实例 `(𝒢 ∪ {ζ(A[a]), ζ(B[b])}, 1)` 可以在输入规模的线性时间内构造。由于对于给定长度为 `t` 的超序列，可能的配对 `(a, b) ∈ ℐ[t]` 的数量在 `t` 中是线性的，因此不同的 MIDDLE CURVE 实例数量也是 `t` 的线性函数。因此该归约可以在 SCS 实例输入规模的多项式时间内计算。因此，对于离散 Fréchet 距离，以下定理成立。

**定理 21。** *对于离散和连续 Fréchet 距离，MIDDLE CURVE 问题的每种变体均为* **NP-hard**。

与 Buchin 等人 [[95]](#backmatter-001.xhtml#b_9783110785944-010_ref_095) 的证明类似，针对离散 Fréchet 距离所示的归约可以改编以证明定理 21 对连续 Fréchet 距离同样成立。引理 22 和引理 23 分别取代了引理 19 和引理 20。其余证明原文照搬。

**引理 22。** *若* `(𝒮, t)` *为返回 TRUE 的* (*SCS 实例* )*，则存在一对* `(a, b) ∈ ℐ[t]` *使得* `(𝒢 ∪ {ζ(A[a]), ζ(B[b])}, 1)` *为连续 Fréchet 距离下返回 TRUE 的 RESTRICTED MIDDLE CURVE 实例。*

*证明。* 给定返回 TRUE 的 SCS 实例 `(𝒮, t)`，引理 19 蕴含存在一对 `(a, b) ∈ ℐ[t]`，使得对于其证明中构造的受限中间曲线 `μ = μ(S[*])`，有 `d[dF](τ, μ) ≤ 1` 对所有 `τ ∈ 𝒢 ∪ {ζ(A[a]), ζ(B[b])}` 成立。由于离散 Fréchet 距离是连续 Fréchet 距离的上界，我们有 `d[F](τ, μ) ≤ d[dF](τ, μ) ≤ 1` 对所有 `τ ∈ 𝒢∪{ζ(A[a]), ζ(B[b])}` 成立。这意味着 `μ` 也是连续 Fréchet 距离下的受限中间曲线。 ![](graphic/b_9783110785944-005_ingr_071.png)

**引理 23。** *若存在一对* `(a, b) ∈ ℐ[t]` *使得* `(𝒢∪{ζ(A[a]), ζ(B[b])}, 1)` *为连续 Fréchet 距离下返回 TRUE 的 UNORDERED MIDDLE CURVE 实例，则* `(𝒮, t)` *为返回 TRUE 的 SCS 实例。*

*证明。* 给定一对 `(a, b) ∈ ℐ[t]`，设 `μ` 为集合 `𝒢 ∪ {ζ(A[a]), ζ(B[b])}` 在距离 1 处的无序中间曲线。我们将引理 20 的证明改编为连续情况。由于 `d[F](ζ(A[a]), μ) ≤ 1`，曲线 `μ` 上必须存在一个点 `q[a]`，它到 `ζ(A[a])` 中的顶点 `v[−3]` 的距离至多为 1，针对每个这样的顶点均成立。因此 `q[a] ∈ [−2, −3]`。但由于 `d[F](ζ(B[b]), μ) ≤ 1`，`ζ(B[b])` 上必须存在一个点到 `q[a]` 的距离至多为 1，因此这样的点位于 `[−2, −1]` 中。由于 `ζ(B[b])` 上的所有点都位于 `[−1, 3]` 中，这蕴含该点必须恰好位于 −1 处，因此 `q[a] = v[−2]`。我们称该点为 `μ` 的一个 A-子集。曲线 `μ` 可能在 `v[−2]` 处包含若干连续顶点，在这种情况下，由这些顶点定义的整条子曲线即为 `μ` 的一个 A-子集。类似地，我们得出结论：对于每个 `v[3] ∈ ζ(B[b])`，存在一个点 `v[2] ∈ μ`，并称其为 `μ` 的一个 B-子集。

同引理 20 一样，我们将曲线 `μ` 划分为 `2a + 1` 条（或 `2b + 1` 条）子曲线（子集）`M[i]^(a)`，`i ∈ {1,…,2a+1}`（或 `M[j]^(b)`，`j ∈ {1,…,2b+1}`）。若对它们编号，偶数索引的子曲线为 `μ` 的 A-子集（相应地为 B-子集），而 `μ` 的其余部分定义了奇数索引的子曲线。同样，我们将这两个 `μ` 的划分合二为一，因为 `μ` 上的任何点不能同时属于 A-子集和 B-子集。序列 `S[*]` 通过将 `μ` 中的每个字母子集替换为相应字母来构造。
