#### 7.2.3.2 用于比特错误容忍度优化的边界最大化

比特翻转正则化通过在前向传播期间模拟比特错误，提高了网络的错误容忍度。这给训练引入了两个目标：给定一组带标签的输入数据，训练一个BNN以实现高准确率和高比特错误容忍度。因此，另一种方法是将高准确率和高比特错误容忍度直接结合到单一损失函数中，以便在训练期间联合优化这两个目标。为此，我们现在引入一种基于边界的神经元级比特错误容忍度度量指标，并将其扩展以构建输出层的比特错误容忍度度量指标。

在下文中，我们使用描述卷积层神经元属性的符号，但我们的分析也适用于全连接层中的神经元。设 `n` 为人工神经网络（ANN）中某个神经元的索引，`x ∈ 𝒳` 为ANN的输入。卷积层中神经元的输出是一个高度为 `U`、宽度为 `V` 的特征图。设 `h[x][n,u,v] ∈ ℤ` 为神经元 `n` 在位置 `(u, v) ∈ {0, ..., U} × {0, ..., V}` 处的**预激活值**，即在应用激活函数**之前**的值。对于BNN，神经元的预激活值由取值为 ±1 的输入和权重的加权和计算得出。因此，一个权重中的单个比特翻转会使预激活值变化 2。

**定理 25。** *设 `n ∈ {0, ..., N}` 为某个神经元的索引。此外，设 `q` 为神经元 `n` 权重中诱导的比特翻转数量。诱导这些比特翻转后，神经元 `n` 在位置 `(u, v)` 处的预激活值落在区间 `[h[x][n,u,v] − 2q, h[x][n,u,v] + 2q]` 内。*

证明见文献[\[113\]](#backmatter-001.xhtml#b_9783110785944-010_ref_113)。

文献[\[114\]](#backmatter-001.xhtml#b_9783110785944-010_ref_114)已对隐藏层神经元的错误容忍度进行了详细分析，但据报道，利用定理 25 在神经元层面优化比特错误容忍度并不成功。我们假设，神经元输出的比特翻转只有在其影响传达到输出层并导致预测类别改变时，才会影响BNN的预测。因此，我们现在将重点转移到将边界概念应用于输出层，即索引在 `N[O]` 中的神经元。

输出层中的每个神经元仅有一个输出值 `h[x][n,1,1]`，它是预测向量 `ŷ` 中的一个条目。这些神经元的输出值不应用激活函数。`ŷ` 中值的数量与最后一层神经元的数量相同。`ŷ` 中最大值条目的索引决定了类别预测，我们假设平局任意打破。

如果比特错误修改了输出层中的输出值，导致另一个神经元提供最高的输出值，则类别预测会发生改变。设 `h[x][n′,1,1]` 和 `h[x,n′′,1,1]`（其中 `n′, n′′ ∈ N[O]`）分别为输出层神经元的最高输出值和第二高输出值。以下推论表明，边界

(7.10) `m := h[x,n′,1,1] − h[x,n′′,1,1]` (7.10)

可作为输出层的比特错误容忍度度量指标。

**推论 26。** *若 `m > 0`，则BNN的输出层可容忍 `max(0, ⌊m/2⌋ - 1)` 次比特翻转。*

证明见文献[\[113\]](#backmatter-001.xhtml#b_9783110785944-010_ref_113)。

我们现在致力于基于推论 26 和支持向量机（SVM）中已知的合页损失来构建损失函数。用于最大边界分类的合页损失 [\[602\]](#backmatter-001.xhtml#b_9783110785944-010_ref_602) 定义为

(7.11) `ℓ(y, f) = max(0, 1 − y ⋅ f)` (7.11)

其中真实标签 `y = ±1`，预测值 `f ∈ ℝ`。当预测值与预测类别符号相同且幅度接近 1 时，该损失变小。对于大于 1 的预测值，损失变为 0。损失中的“1”迫使分类器最大化两个类别预测之间的边界。

对于最后一层的BER容忍度，如公式 7.10 所引入的边界 `m` 需要足够大，以便输出层能容忍的最大比特翻转数较高。边界可通过从输出向量 `ŷ` 的最高条目 `ŷ[c′]` 中减去第二高条目 `ŷ[c′′]` 直接计算得出，即 `m = ŷ[c′] − ŷ[c′′]`。然而，在不考虑 `ŷ` 的其他条目 `ŷ[c]` 的情况下针对 `m` 进行优化，可能无法充分发挥 `ŷ[c′]` 与其他类别输出 `ŷ[c]` 之间边界的潜力。`ŷ[c′]` 与其他类别 `c` 的 `ŷ[c]` 之间的边界 `m[C] = ŷ[c′] − ŷ[C]` 越大，计算 `ŷ[c]` 的神经元在不改变预测的情况下能容忍的比特错误就越多。简言之，对于比特错误容忍的输出层，`ŷ[c′]` 需要尽可能大，而其他 `ŷ[c]` 需要尽可能小。

然而，在用于多类问题的BNN情况下，公式 7.11 中的合页损失版本无法直接使用。为了将合页损失扩展到多类，我们定义 `y[enc]` 为一个元素在 `{−1, 1}` 中的独热向量，在真实标签索引处为 `+1`，其余为 `−1`。`y[enc]` 与 `ŷ` 具有相同数量的元素。然后计算逐元素乘积 `y[enc] · ŷ`。在此乘积中，若预测正确，正确类别的正预测保持为正，而本应尽可能为负的负预测变为正。若预测错误，即正确类别为高负值、错误类别为高正值，则值变为负。为了在错误情况下施加高惩罚、在正确情况下施加小惩罚，我们从参数 `b` 中减去乘积 `y[enc] · ŷ`，得到 `(b − y[enc] · ŷ)`。由于我们不要求预测值高于 `b`，我们使用 max 函数将负值设为零，并将其称为修正合页损失（MHL）：

```
ℓ[MHL](ŷ, y[enc]) = max{0, (b − y[enc] ⋅ ŷ)}.
```
