

# 网络物理系统与机器学习中的能量约束

能量是一种几乎无处不在的基本资源约束。前面的许多章节间接讨论了网络物理系统和机器学习的能量需求。从更宏观的角度审视网络物理系统，我们会发现，解决特定问题所需的总能量为（假设 `P` 恒定）

```
W = P * t
```

其中 `P` 是运行硬件的功率，`t` 是该硬件执行给定软件所需的时间。因此，能量消耗通常由以下因素决定：

1.  所用硬件（即 `P`）
2.  在硬件上运行的算法（这会影响 `P` 和 `t`）
3.  硬件执行实现算法的时间（即 `t`）

在实践中，这些量之间往往存在权衡。处理能力强的硬件可以非常快地执行软件，但通常也需要更多的能量。同样，性能较弱的硬件执行软件流水线可能需要更长时间，但由于所需功率较小，总体能量消耗反而更低。最后，某些实现可能会利用特定的硬件特性（例如 GPU），从而影响执行所需的能量和时间。随着机器学习（ML）持续融入网络物理系统，必须探索两个研究方向。

首先，为了在小型设备上应用和训练机器学习模型，必须降低 ML 算法本身的能量消耗。这需要一种全面的方法，将 ML 流水线的所有步骤都纳入考量，从其理论模型一直到其在特定硬件平台上的具体实现。

其次，必须探索将 ML 模型应用于降低网络物理系统*其他*部分的能量消耗。这需要一种跨领域的方法，将领域专业知识与针对特定问题的 ML 相结合。

本章将对这两种方法进行示范性讨论。[第 9.1 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001) 讨论了如何用纯整数运算重述概率无向模型，从而不再需要浮点协处理器。它介绍了位长传播（BL-Prop），并将其与一种用于带整数约束的数值优化的新型 IntGD 算法相结合。该算法使得马尔可夫随机场能够在小型设备上仅使用整数运算进行训练和推理。

[第 9.2 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_002) 讨论了如何将 ML 模型集成到网络物理系统的无线通信中。更具体地说，讨论了针对不同通信技术（包括 LTE、LTE-A 和 NB-IoT）的功耗建模方法。进一步探讨并结合实际场景讨论了在用户设备（UE）中集成 ML 模型，以在外部影响（如信号强度或信号质量）下估算上行传输功率。

## 9.1 整数指数族

*Nico Piatkowski*

**摘要：** 本文研究如何将底层计算架构的知识直接融入学习问题中。更准确地说，我们考虑了超低功耗（ULP）微控制器单元（MCU）的算术限制。此类系统不包含算术协处理器，这意味着大多数算术运算必须通过整数逻辑来模拟。然而，这给严重依赖浮点运算的任何机器学习方法带来了巨大的性能损失。为缓解这一问题，我们展示了如何用纯整数运算重述模型本身，从而不再需要浮点协处理器。我们以概率无向模型（即马尔可夫随机场）为例说明这一过程。文中讨论了学习和推理的所有步骤。文中提出了一种近似但纯整数的概率推理过程，称为位长传播（BL-Prop）。BL-Prop 基于信念传播，但不是传播完整的消息，而是沿着模型的条件独立性结构仅传播消息的位长。我们分析了该算法，并指出了对近似质量影响最大的因素。

此外，我们推导了 IntGD——一种用于带整数约束的凸目标函数的数值优化方法。该方法基于一种针对非光滑和非凸惩罚项的加速近端算法。对于通过 BL-Prop 计算的整数梯度，IntGD 能够保证提供一个整数学习过程，其中最终参数向量以及所有中间结果均为整数。基准数据上的数值实验表明，整数模型使我们能够在低端硬件上实现具有竞争力的预测质量，同时相比其双精度对应物保持了巨大的加速比——从而彻底消除了因缺少浮点单元而产生的性能损失。

### 9.1.1 引言

流式传感器数据的大数据分析在多方面挑战着算法的资源效率。在资源受限的计算环境中运行数据挖掘方法，在执行时间和能量消耗方面产生了挑战。幸运的是，减少 CPU 忙碌周期数的优化也能节省能量消耗。查看处理单元的规格时会发现，整数运算在指令延迟方面通常更廉价，即它需要更少的时钟周期才能使算术指令的结果就绪。[表 9.1](#9783110785937_093138.xhtml#b_9783110785944-009_tab_001) 显示了以时钟周期衡量的 Intel CPU、ARM CPU 和 Nvidia GPU 的算术指令延迟。请注意，超越函数由多条指令组成，因此所需周期数可能比 [表 9.1](#9783110785937_093138.xhtml#b_9783110785944-009_tab_001) 中报告的要多得多。这促使我们在设计新的资源感知学习算法时，减少代码执行的周期数。

如今，大数据产生于社交媒体、工业以及基本上所有的科学研究领域。由于无处不在的信息感知移动设备越来越多地收集数据，数据集规模不断增长。基于多个观测输入联合预测各种未知量，是计算生物学、计算机视觉和自然语言处理等各领域实际问题中无处不在的子任务。概率图模型非常适合此类任务，但它们受困于概率推理的高复杂性。过去十年中，基于信念传播（BP）[404, 560] 的许多近似概率推理方法被提出，例如计数 BP [[369]](#backmatter-001.xhtml#b_9783110785944-010_ref_369)、提升 BP [[10]](#backmatter-001.xhtml#b_9783110785944-010_ref_010)、随机 BP [[539]](#backmatter-001.xhtml#b_9783110785944-010_ref_539)、树加权 BP [[691]](#backmatter-001.xhtml#b_9783110785944-010_ref_691)、树块坐标下降 [[642]](#backmatter-001.xhtml#b_9783110785944-010_ref_642) 和粒子 BP [[331]](#backmatter-001.xhtml#b_9783110785944-010_ref_331)。求积法 [572, 573] 取得了有希望的结果，但不适合嵌入式或资源受限环境。相比之下，这里的基础模型类被限制在整数范围内，这在保持良好性能的同时，减少了运行时间并节省了能量。渐近来看，新方法与原始 BP 具有相同的复杂度，但使用了更廉价的操作。
