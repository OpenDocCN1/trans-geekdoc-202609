
# 无电池传感系统

当周围环境提供足够能量时，无电池传感系统会执行高效的数据采样。然而，即使换能器足够大，能够在正确的电压和电流范围内直接为应用电路供电，也无法保证其能在最大功率点进行采集 [\[631\]](#backmatter-001.xhtml#b_9783110785944-010_ref_631)。如果应用电路调整其工作点以从换能器提取最大功率，这极有可能不是应用电路的最佳工作点。应用电路的最高能效运行仅取决于应用本身及其使用的外设，而与环境条件无关。为了最大化采集能量并最小化应用的能量成本，系统架构需要为采集电路和应用电路设置独立的电压域。这样，功率调理电路即可与换能器解耦，实现用于最大功率传输的阻抗匹配，而不影响应用电路。应用电路也可根据应用需求动态调整自身的工作电压。这些架构要求将结合能量管理单元（EMU）解决方案进行详细讨论，该方案最早见于文献 [\[259\]](#backmatter-001.xhtml#b_9783110785944-010_ref_259)。多年来，该架构已在实验中被证明在广泛的工作条件下既节能又稳健。

基于 EMU 的传感系统利用电压和电流解耦来高效执行基于任务的应用。因此，一个仅在 `1 V` 下提供 `10 μW` 的环境，仍可为在 `3 V` 下运行、任务消耗高达 `100s of mW` 的应用电路供电。因此，即使在不利的环境条件下，无电池应用也能可靠执行。我们将展示两个基于 EMU 架构的无电池应用场景。一个详述了可使用蓝牙低功耗（BLE）无线电异步传输数据的静态定位环境传感器。另一个则专注于运行在无电池系统上的可穿戴传感应用，用于基于加速度计的手势检测。我们将展示该嵌入式学习应用的完整流程，从数据采集到模型训练及系统性能优化。

本文其余部分结构如下：室内光伏数据集见 [第 2.3.2 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_002)，能量管理单元（EMU）架构见 [第 2.3.5 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_005)，首个用于环境监测的无电池传感系统见 [第 2.3.8 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_008)，第二个用于手势检测的无电池系统见 [第 2.3.9 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_009)，两个系统的分析见 [第 2.3.14 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_014)，结论见 [第 2.3.17 节](#9783110785937_002446.xhtml#b_9783110785944-002_s_003_s_017)。

## 2.3.2 室内光伏的能量可用性

大型数据集可辅助面向户外场景的能量采集物联网系统的设计与评估过程。由于室内环境的采集特性差异显著，这些数据集不适用于设计和评估面向室内应用的采集式系统。在室内环境中，可采集能量严重受限，从而给基于采集的系统施加了严格的能量约束。此外，即使部署在相邻位置的系统，其采集特性也可能发生剧烈变化。为了解室内能量情况并适当设计基于采集的物联网系统，需要来自各种室内位置的长期室内采集数据。此类数据还能对室内能量采集系统进行广泛评估。我们将讨论一个室内采集数据集的收集过程，该数据集包含太阳能电池板采集功率的测量值、能量存储中缓存的能量，以及描述系统环境条件的传感器数据。

## 2.3.3 测量设置与部署

室内采集数据集首次见于文献 [\[632\]](#backmatter-001.xhtml#b_9783110785944-010_ref_632)，是利用 [图 2.13](#9783110785937_002446.xhtml#b_9783110785944-002_fig_013) 所示的定制监测平台收集的。该平台包含一个太阳能电池板（`AM-5412`，`50 mm x 33mm`），用于测量其输出。`bq25505` 采集芯片包含一个带有最大功率点跟踪（MPPT）的升压转换器，确保太阳能电池板高效运行，并将采集到的能量存储在虚拟电池电路中。由于测量平台不包含消耗采集能量的应用，能量存储元件会溢出，与之相关的测量值将不符合能量采集物联网系统的典型行为。取而代之的是，虚拟电池电路模拟系统的能量存储持续在 `4.2 V` 的典型电压下运行。它维持采集管理组件的一致工作点，并提供与基于采集的系统行为一致的采集测量值。为了记录环境条件，平台包含两个 `TSL45315` 光照传感器和一个 `BME280` 湿度传感器。光照传感器位于太阳能电池板的两侧，提供太阳能电池板在采集能量时所暴露的照度条件。湿度传感器测量环境相对湿度、气压和温度。

定制平台设计为与 Rocketlogger 平台 [\[631\]](#backmatter-001.xhtml#b_9783110785944-010_ref_631) 配合使用。Rocketlogger 是一种体积小巧的测量设备，可为广泛电流范围无缝提供高精度测量。这些特性使 Rocketlogger 能够用于长期部署，记录室内环境中高度多变的条件。因此，Rocketlogger 可测量太阳能电池板采集并流入采集芯片的能量、`bq25505` 组件的输出以及环境传感器数据。传感器、能量提取及虚拟电池所需的电路均由 Rocketlogger 供电，确保采集系统不受影响。作为独立观察者，Rocketlogger 对被测系统影响极小，并提供将环境条件与电功率信号关联所需的数据。

由定制监测平台和 Rocketlogger 组成的五个测量平台（如 [图 2.13](#9783110785937_002446.xhtml#b_9783110785944-002_fig_013) 所示）部署在瑞士苏黎世联邦理工学院 (ETH Zurich) 一栋办公楼的一层楼内。[图 2.14](#9783110785937_002446.xhtml#b_9783110785944-002_fig_014) 描绘了测量平台的位置。因施工原因，一个平台被移动，图中显示了其初始位置和后续位置。部署覆盖了多样化的环境。因此，平台在一天中的不同时段暴露于不同混合的人工光与自然光、直射与间接阳光下。此外，平台在房间内的朝向各异，房间的占用模式从定期且长期占用的办公室到仅偶尔占用不等。所有部署位置详见 [表 2.4](#9783110785937_002446.xhtml#b_9783110785944-002_tab_004)。
