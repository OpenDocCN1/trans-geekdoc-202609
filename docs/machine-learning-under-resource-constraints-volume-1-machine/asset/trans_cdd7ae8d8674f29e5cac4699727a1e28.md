

# 7.1 高效内存占用减少

**Helena Kotthaus**

**Peter Marwedel**

**摘要：** 本节讨论了用 GNU R 编程语言编写的机器学习算法在高效内存占用减少方面的优化方法。所提出的优化策略针对 R 解释器与操作系统之间的内存管理层，通过确保仅为确实需要的内存页分配内存，从而减少大型数据结构的内存开销。所提出的方法利用运行时环境的附加信息（例如内存块的短期使用模式）来指导优化。评估基于统计机器学习算法。当内存消耗达到操作系统开始换出内存的程度时，优化策略能将计算速度提升数个数量级。

## 7.1.1 动机

为了在资源受限设备上执行机器学习算法，高效利用可用资源非常重要。这些资源包括处理器（含运行时间）、内存、通信带宽和能量。本书包含旨在实现资源效率的示例优化算法。特别是[第 6 章](#9783110785937_066530.xhtml#b_9783110785944-006)至[第 9 章](#9783110785937_093138.xhtml#b_9783110785944-009)展示了此类示例优化。本节演示了内存作为资源的优化潜力。理想情况下，内存具有无限容量，但其大小可能对某些技术的适用性产生相关影响。这对于资源受限的嵌入式系统尤其如此。本节重点关注用 R 语言编写的机器学习算法对内存的高效利用。R 语言被用于许多机器学习应用，因此在此予以考虑。如文献 [387, 503] 所示，R 环境存在若干缺点，导致程序执行缓慢且内存效率低下。在 R 程序中，大多数数据结构是向量。当向量大小超过特定阈值时，R 解释器会分配一个大向量。对于每个大向量，都会分配一个专用内存块，可能跨越多个页面。这些页面即使未被使用，也会占用内存。当计算所需内存量超过应用程序可用的物理内存时，频繁的页面换入换出（需要 I/O）会大幅降低执行速度，这种现象也称为“颠簸”。由颠簸导致的性能损失可能使复杂计算完全变得不可行。

本贡献基于 Kotthaus 等人 [383, 385, 386] 的工作。[第 7.1.2 节](#9783110785937_078254.xhtml#b_9783110785944-007_s_001_s_002)综述了相关工作并解释了 R 内存管理的基础知识。[第 7.1.3 节](#9783110785937_078254.xhtml#b_9783110785944-007_s_001_s_003)讨论了用于 R 机器学习算法高效内存利用的页面共享策略。最后，[第 7.1.4 节](#9783110785937_078254.xhtml#b_9783110785944-007_s_001_s_004)展示了评估结果并以总结结束。

## 7.1.2 相关工作与基础：内存占用减少与 R 环境

**相关工作 - 内存占用减少** [第 7.1.3 节](#9783110785937_078254.xhtml#b_9783110785944-007_s_001_s_003)中提出的内存优化工作在 R 解释器环境与操作系统之间的一个层面上。这使得仅需对 R 解释器进行少量修改且无需更改应用程序，即可优化任意 R 应用程序，尤其是内存饥渴型机器学习应用程序。因此，下文将讨论用于减少内存利用的相关系统级方法。

总体而言，关于更高效利用主存的相关工作可分为两类：内存压缩方法（常受嵌入式系统资源约束影响）和内存去重（主要用于虚拟化）。

内存压缩试图通过压缩内存内容而非将页面换出到辅助存储来减少系统的换入换出活动。压缩方法共享一个缺点：大量处理器时间被花费在压缩和解压缩内存内容上。

相比之下，内存通过去将具有相同内容的虚拟页面映射到单个物理页面来减少内存开销。这在虚拟化环境中通常是有益的，因为大量只读内存（如共享库）被多个虚拟机使用 [[626]](#backmatter-001.xhtml#b_9783110785944-010_ref_626)。然而，去重可能引入显著的计算开销，因为必须定期扫描页面内容以识别具有相同内容的页面。一种常用的去重实现是 Linux 中的 `Kernel Samepage Merging` (KSM) [[22]](#backmatter-001.xhtml#b_9783110785944-010_ref_022)，它一直是多项改进的主题。文献 [[133]](#backmatter-001.xhtml#b_9783110785944-010_ref_133) 通过引入基于访问特征的分类方案对 KSM 进行了优化，仅比较同一类别内的页面以减少页面扫描的开销。Deng 等人 [[169]](#backmatter-001.xhtml#b_9783110785944-010_ref_169) 提出了基于内存追踪的不同去重和压缩方法的评估，结果表明去重产生的效果优于内存压缩。
