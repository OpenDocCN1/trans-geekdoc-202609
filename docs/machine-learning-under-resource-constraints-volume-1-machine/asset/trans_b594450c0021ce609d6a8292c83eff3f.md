

## CoNLL-2000 数据

该数据集是为 2000 年计算自然语言学习会议的共享任务而提出的。训练数据和测试数据由三列组成，列之间以空格分隔。每个词单独占一行，每个句子后有一个空行。第一列包含当前词，第二列包含其词性标注（由 Brill 标注器得出），第三列包含其块标注（源自《华尔街日报》语料库）。块标注包含块类型的名称——例如名词短语词为 `I-NP`，动词短语词为 `I-VP`。大多数块类型有两种块标注：`B-CHUNK` 表示块的第一个词，`I-CHUNK` 表示块中的其他每个词。总共有 22 个块标签，对应于顶点状态，即 `|𝒳| = 22`。对于逐块 F1 分数的计算，仅当属于同一块的所有连续标签均正确时，该块才被视为正确。数据集包含 8,936 个训练实例和 2,012 个测试实例。对于每个词，周围的词和词性标注被用作特征。由于相邻顶点状态之间固有的依赖关系，如果整数近似保留了顶点之间的依赖结构，则该数据集特别适合用于评估。

### 9.1.4.1 `|𝒳|` 和 `|𝒩[v]|` 对质量和运行时间的影响

在 [第 9.1.3 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001_s_003) 中，关于用位长 `BP` 计算的边缘概率误差的估计表明，顶点状态空间的大小 `|𝒳[v]|` 和度 `|𝒩[v]|` 对训练误差有影响。[图 9.2](#9783110785937_093138.xhtml#b_9783110785944-009_fig_002) 展示了在合成数据上，随着顶点数量增加，不同 `|𝒳[v]|` 和 `|𝒩[v]|` 值下的训练误差（归一化负对数似然）、测试误差（MAP 准确率）以及运行时间（秒）。每条曲线是在 `K = 8` 的情况下，对 100 棵具有随机参数的随机树取平均得到的。变化 `|𝒳[v]|` 的结果是在最大度为 8 的情况下生成的，而变化 `|𝒩[v]|` 的结果是在 `|𝒳[v]| = 4` 的情况下生成的。

就训练误差而言，左上图显示了在相同状态数下，整数估计与浮点估计之间存在明显的偏移。就变化度而言（左中图），整数模型的训练误差对不同的邻域大小有响应，而浮点模型的似然对度不变。对于测试准确率对 `|𝒳|` 和 `|𝒩[v]|` 的依赖关系（右上图、中上图），呈现出类似的图景。浮点 MAP 估计不随状态数和邻居数的增加而改变，而整数 MRF 显示出明显的响应。整数 MRF 的准确率实际上随着度的增加而提高。总体而言，模型的质量似乎与图中顶点的数量无关。

在 MAP 准确率和负对数似然方面，浮点模型优于近似整数模型。然而，[图 9.2](#9783110785937_093138.xhtml#b_9783110785944-009_fig_002) 底部的两个图显示，整数模型在时钟周期方面的资源消耗大幅减少。时间测量包括参数估计、似然计算和执行 MAP 预测。由于两种算法（`RealMRF` 和 `IntMRF`）在这些过程中的渐近复杂度完全相同，结果所显示的运行时间大幅减少必定归因于时钟周期的减少。

### 9.1.4.2 `K` 对质量的贡献

将整数参数缩放使得生成的参数向量 $\overline{\theta}$ 落在集合 `{0, 1, ..., K}` 中可能比较方便。我们通过整数模型在训练质量和测试误差方面的响应来说明这种缩放的效果，如 [图 9.3](#9783110785937_093138.xhtml#b_9783110785944-009_fig_003) 顶部的两个图所示。训练误差似乎是 `K` 的平滑函数，而 MAP 准确率对 `K` 的选择敏感。这是我们预期的，因为较大的 `K` 基本上意味着可以表示更多的边缘概率。还可以看到，一旦 `K` 足够大（即 [图 9.3](#9783110785937_093138.xhtml#b_9783110785944-009_fig_003) 顶部右图中的 `K = 8`），进一步增加 `K` 对训练误差和测试准确率均无显著影响。这两个结果均在最大度为 8 的图上生成，但正如前一个实验已知的那样，不同度对模型质量的影响可以忽略不计。[图 9.3](#9783110785937_093138.xhtml#b_9783110785944-009_fig_003) 左下图显示了内在参数空间的宽度，即重缩放前最小和最大整数参数之和。结果表明，参数空间的宽度是天然有界的，因为对于各种 `n` 和 `𝒳` 配置，`s + m` 似乎收敛于同一值。单独绘制 `s` 和 `m` 显示，`s + m` 的动态主要受最小参数 `s` 影响，即参数空间的宽度必须增加以表示更小的概率。

### 9.1.4.3 `K` 对梯度范数的影响

正如 [第 9.1.3 节](#9783110785937_093138.xhtml#b_9783110785944-009_s_001_s_003) 对训练误差的分析所指出的，最大似然估计与直接整数参数估计结果之间的距离基本上由整数参数 `¯θ` 的梯度范数界定。由于梯度的分量不能超过 1，参数向量维度 `d` 是梯度范数的一个平凡上界。在最右侧的图中可以做出一个非常有力的观察，该图显示了随着顶点数量增加和不同 `K` 值下的相对梯度范数。这一结果表明，存在一个与顶点数量无关的相对梯度范数上界，且该上界随 `K` 的增加而减小。
