
我们根据[表 7.6](#9783110785937_078254.xhtml#b_9783110785944-007_tab_006)所示配置，在数据集 `FashionMNIST` 和 `CIFAR10`（见[表 7.5](#9783110785937_078254.xhtml#b_9783110785944-007_tab_005)）上评估全连接二值化神经网络（`FCBNNs`）和卷积二值化神经网络（`CBNNs`）。在所有实验中，我们对 `FashionMNIST` 运行 `Adam` 优化器 100 个周期，对 `CIFAR10` 运行 250 个周期。我们使用 128 的批量大小和 10[−3] 的初始学习率。为稳定训练，我们每 25 个周期将学习率按指数衰减 50%。下文中，我们将基于边界的方法（`MHL`）与翻转正则化（`FR`）进行比较。`FR` 默认使用交叉熵损失（`CEL`）。我们首先比较无 `FR` 的 `MHL` 与 `FR`。第二步，我们比较无 `FR` 的 `MHL` 与 `MHL` 结合 `FR` 的情况。

#### 7.2.4.1 仅 MHL 对比 FR

[图 7.10](#9783110785937_078254.xhtml#b_9783110785944-007_fig_010) 展示了不同 BNN 在准确率随 BER 变化（[图 7.10](#9783110785937_078254.xhtml#b_9783110785944-007_fig_010)(a) 和 (b) 中为 0% 至 15%，图(c) 中为 0% 至 5%）方面的实验结果。针对每个数据集，我们使用 `MHL`（无任何 `FR`）和 `FR`（在不同 BER 下进行位翻转注入）分别训练了五个 BNN。此外，对于所有使用 `MHL` 训练的 BNN，我们对参数 `b` 进行了参数搜索，测试 2 的幂次方，上限为输出层神经元最大计算值的两倍（输出层神经元的最大输出值为输出层前一层的神经元数量）。在这些 `b` 的配置中，选择了最优者。我们观察到，使用无 `FR` 的 `MHL` 训练的 BNN 在 BER 下的准确率优于使用 `FR` 训练的 BNN，即在图(a)和(b)中高达 10%，在图(c)中高达 5%。当训练期间的 BER 较高时，使用 `FR` 训练的 BNN 在较低 BER 下会遭受显著的准确率下降，例如低 BER 下的 `CEL` 20% 和/或 `CEL` 30%。然而，使用 `MHL` 训练的 BNN 不存在这种准确率下降。尽管在 [图 7.10(b)](#9783110785937_078254.xhtml#b_9783110785944-007_fig_010) 中，使用 `FR` 20% 和位翻转注入训练的 BNN 在错误率高于 10% 时对 Fashion `CBNN` 具有更好的准确率，但 BNN 的准确率会大幅下降，这可能是不可接受的。下文我们将展示进一步的研究。

#### 7.2.4.2 MHL 结合 FR

我们评估在不同 BER 下使用 `MHL` 和 `FR` 训练的 BNN。此外，使用 `MHL` 无 `FR` 训练的 BNN（即 [图 7.11](#9783110785937_078254.xhtml#b_9783110785944-007_fig_011) 中在 0% BER 下使用 `MHL` 生成的那些 BNN）作为本小节的基线。对于所有配置，我们采用了与上一节相同的 `b` 参数搜索。[图 7.11](#9783110785937_078254.xhtml#b_9783110785944-007_fig_011) 展示了不同 BNN 在准确率随 BER 变化（[图 7.11(a) 和 (b)](#9783110785937_078254.xhtml#b_9783110785944-007_fig_011) 中为 0% 至 30%，(c) 中为 0% 至 6%）方面的实验结果。在所有实验中，我们观察到，使用 `MHL` 和 `FR` 训练的 BNN 在 BER 下的准确率显著高于仅由 `MHL` 训练的基线。例如，对于 [图 7.11](#9783110785937_078254.xhtml#b_9783110785944-007_fig_011) 中的 Fashion，准确率显著下降的 BER 从 5%（基线，绿色曲线）分别延伸至 20% 和 15%，且在 0% BER 下的准确率仅有微小折损。如果在低误码率下牺牲更多准确率，准确率陡降的 BER 甚至可以进一步后移。对于 [图 7.11](#9783110785937_078254.xhtml#b_9783110785944-007_fig_011) 中的 `CIFAR10`，该临界点也可提高。然而，与前几种情况相比，需要牺牲更多的准确率。如果 `b` 高于所示数值，较低 BER 下的准确率会受损，类似于使用高 BER 的 `CEL`。如果 `b` 较低，则与 `CEL` 0% BER 相比无显著变化。我们仅展示最优 `b` 的结果。

### 7.2.5 结论

深度学习以极度贪婪的内存需求著称，因此必须开发新的内存子系统，以将人工神经网络（ANN）的应用推向小型设备。同样，新的 ANN 架构有助于降低内存消耗，并提供更节省资源的深度网络执行方式。铁电场效应晶体管（`FeFET`）等非易失性存储器是新型内存子系统的有前景技术。`FeFET` 实现了更快、更节能的读/写操作，但会在执行过程中引入位错误。虽然标准软件解决方案可以监测和纠正位错误，但它们通过引入额外的处理开销，抵消了非易失性存储器的优势。相比之下，设计上对随机位错误具有鲁棒性的神经网络，能够保留非易失性存储器的优势，从而带来潜在的更快、更节能的解决方案。`BNNs` 是一类新颖的小型、资源高效的神经网络，非常适合此类场景。在 `BNNs` 中，每个权重由 `{0, 1}` 组成，因此它们所需内存比其浮点对应物少 32 倍，同时对随机位翻转更具鲁棒性。在本文中，我们深入讨论了 `BNNs` 中的位错误，并由此推导出一种新颖的最大边界优化方法。我们的方法在大多数错误率下提供更好的准确率，同时防止 `BNN` 过拟合到特定错误率。因此，我们的方法允许在具有未知和变化错误率的各种不同设备上部署 `BNNs`。
