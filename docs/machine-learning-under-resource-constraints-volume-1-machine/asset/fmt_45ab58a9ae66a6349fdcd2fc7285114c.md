
# 能量采集与无电池传感系统

## 概述

信息已成为现代经济中最重要的因素之一，在医疗、基础设施和供应链等众多领域发挥着关键作用。每当需要来自物理域的信息时，都必须采用传感系统以可扩展且经济的方式收集相关数据。为长期部署设计这些系统是一项艰巨的挑战，因为传统的电池供电设备在尺寸、成本、可靠性和维护方面存在限制。大型储能元件可提供稳定的电源，即使系统的功率需求高度可变，也可能实现长系统寿命。然而，当前趋势指向部署数十亿个相互连接的嵌入式系统，它们从周围环境感知数据并将被集成到物联网中。在许多物联网用例中，希望这些传感设备在物理和心理上都“消失”，且几乎不需要维护，这促使了移动无线传感器节点的使用。能量采集被广泛认为将在为这类资源受限设备提供足够能量方面发挥日益重要的作用。然而，尽管成本已下降，但鲜有物联网产品采用基于能量采集的解决案。这部分归因于能量生产的功率密度和时效性与消费者需求之间的不匹配。

## 无电池传感系统

最近出现了一类新的无电池传感系统，为向预期的大量物联网设备提供足够的运行功率提供了可持续的长期解决方案。这些机会式能量系统仅在环境提供足够运行能量时才工作；否则，它们消耗零能量。本文重点关注无电池传感应用的高效执行设计挑战，特别是由光供电的应用。此处展示的工作完美补充了第3卷第3.6节中讨论的室内光伏详细数学模型。

## 设计优化准则

从室内环境施加的能量约束研究出发，介绍了无电池平台的主要优化准则。基于这一形式化方法，展示了可穿戴和静态放置传感器的不同应用场景。详细讨论了这些应用及其硬件考量，以及在无电池系统中可靠高效地执行它们所需的软件优化。

## 环境能量动态分析

如果系统运行取决于从周围环境提取的能量，理解环境条件的动态就变得至关重要。在最坏情况下，环境条件是非确定性且高度可变的。因此，依赖能量采集的系统为了稳健运行，需要容忍[[261]](#backmatter-001.xhtml#b_9783110785944-010_ref_261)或适应[[11]](#backmatter-001.xhtml#b_9783110785944-010_ref_011)可变的采集条件。来自时空可变环境的数据以及可通过采集提取的能量，对于此类系统的尺寸设计、校准和测试极具价值。世界各地气象站提供的室外太阳能采集辐照数据非常丰富，通常可追溯数十年。相比之下，室内太阳能采集数据仅稀疏可用，但对于针对楼宇自动化和辅助生活等部署环境的许多物联网应用而言，其重要性日益凸显。

## 室内能量采集数据集

我们讨论了一个广泛的室内能量采集数据集，该数据集首次在[[632]](#backmatter-001.xhtml#b_9783110785944-010_ref_632)中提出，解决了长期室内太阳能采集轨迹缺乏的问题。虽然其他工作已在室内环境中进行照度测量[[267]](#backmatter-001.xhtml#b_9783110785944-010_ref_267)，但这项工作联合监测了从太阳能电池板提取的能量、存储在电池中的能量以及环境条件。使用真实采集系统实现的功率测量与丰富的环境传感器数据相结合，为分析和评估提供了多样化的机会，包括功率估算、能量采集源建模和采集系统效率分析等。该数据集的一个关键洞察是定量理解室内光伏采集器在两年多时间内的能量变异性。同一室内太阳能电池在一天内可产生0到潜在数百焦耳之间的能量，具体取决于地理位置、建筑设计和许多其他变量。

## 机会式能量操作范式

遵循无电池传感范式时，这种潜在的大能量流应在能量被采集时立即消耗。这种机会式能量操作的主要原因在于：替代方案（为未来使用存储能量）需要昂贵的可充电储能装置。例如，一个500 mA h的锂离子聚合物电池即使大批量采购也可能花费数美元，而一个47 *μ*F陶瓷表面贴装电容器仅需0.1美元。最小化能量供给将使物联网在经济上更可行、环境上更友好，并可能更节能。当电池供电设备让应用电路保持通电多年时，相当一部分存储能量将耗费在*睡眠*模式上。即使这是高度优化的低功耗模式，市面上大多数微控制器在最佳情况下也只能将功耗降至几*μ*W，假设所有其他外设均可关闭。因此，这些几*μ*W在多年累积下可能变成数千焦耳，这些能量并未用于实际应用，而仅用于维持系统通电。维持系统开启对许多传感应用至关重要，但并非全部。能量驱动的传感器将通过运行应用尽快消耗采集到的能量。在没有能量的夜间，无电池传感器将无法支持节能的*睡眠*模式，而是完全关闭，消耗零瓦特，直到环境再次能供应能量。因此，无电池系统仅花费极少量能量维持*睡眠*状态；大部分能量将实际用于执行应用。
