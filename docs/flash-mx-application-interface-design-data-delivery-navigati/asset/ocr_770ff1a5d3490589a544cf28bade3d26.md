We need to know what each of our buttons does, so it's time to add some labels to them. Create a new layer and call it text. On this layer create a static text box and type '4789;'. This is not very informative text yet, but select it and change it from our default 'Arial' font to 'Webdings' and we have instant universally recognized video control symbols.

![](bbox=[0.07, 0.41, 0.46, 0.47])

Create a new static text box and cut and paste the 'rewind' symbol to it, repeat this with 'fast forward', and 'rewind to start'. We can leave play and pause in the same text box. This one may need to have the character spacing tweaked slightly to get the spacing right.

![](bbox=[0.14, 0.6, 0.39, 0.73])

These labels can now be placed on our buttons. Create some more for slow motion, advance one frame and reverse one frame.

![](bbox=[0.06, 0.82, 0.46, 0.9])

We could have created seven duplicates of our button within the library, and added text directly to each button, but I know that I'm fickle and often change elements as I progress through a project, so it's better to leave my options open. If for example, we decide to use green text rather than black for our labels we have them all in one place, on one layer making it easy to select them all and transform them.

Before we leave these buttons we need to give each instance its own name so that we can differentiate between them when we come to add functionality to them.

Our buttons are named – from left to right – homeBut, rewindBut, playBut, ffwdBut, backFrameBut, slomoBut and forwardFrameBut.

Retuning to our main stage, rename our only layer video and create a new layer called controls. Drag an instance of the controller movie clip to the main stage.
