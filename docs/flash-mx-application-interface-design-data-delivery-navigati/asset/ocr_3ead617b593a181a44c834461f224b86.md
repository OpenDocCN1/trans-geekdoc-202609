At the top of the screen is a status bar with several pieces of information, and interface items:

![](bbox=[0.485, 0.148, 0.895, 0.412])

These are, from left to right:

+   - Navigate Up button – takes us up one level.
+   - Current location – where we are in the site.
+   - Number of items – tells us how many items (files/folders) are in this window.
+   - File size – tells us how big the currently selected item is, in bytes.
+   - File type – a filter for which type of files we’re allowing Flash to show us.

This is, in effect, a complete file system-esque navigation interface, which can be intuitively understood by anyone with a basic understanding of computers. Of course, you can never quite account for every potential user out there, but in terms of my target audience, I’m confident that it is self-explanatory and simple.
