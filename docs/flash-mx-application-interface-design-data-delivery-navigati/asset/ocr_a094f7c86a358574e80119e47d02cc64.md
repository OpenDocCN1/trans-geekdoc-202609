We are now ready to start adding some functionality to our buttons. Add another new layer to our main timeline. Rename this one Actions. All the code for our Flash Movie is going to be housed on frame one of this layer, as is best practice in Flash MX. We could attach functions directly to our buttons but keeping all our code in one place makes it easier to see what's going on, and troubleshoot should the need arise.

We can now test our movie and check that our play/pause button successfully starts our video, pauses it and sets it playing again each time it is pressed.

The most important button is our play/pause one, so let's get that one working.

The forward and backward single frame button functions are nice and simple so we'll get them out of the way next. Add this ActionScript below the first code:

Making sure that frame1 on the Actions layer is selected, bring up the Actions window.

Enter this ActionScript:

```
controls.playBut.onRelease = function() {
  if (playing == false) {
    video.play();
    playing = true;
  } else {
    video.stop();
    playing = false;
  }
};
```

```
controls.backFrameBut.onRelease = function() {
  video.prevFrame();
  playing = false;
};

controls.forwardFrameBut.onRelease = function() {
  video.nextFrame();
  playing = false;
};
```

This code allows our button to function as both a play and pause button. All our buttons will be within the controller movie clip known as controls, so all our button scripts will begin with a similar structure:

These two bits of code simply tell the video clip to go to either the previous frame, or the next frame. Each function also includes the line we first saw in our play/pause button (playing = false). This is important to ensure that we have parity in the state that our buttons leave the video. Without it, the play button would need to be clicked twice before it would function as expected, as nothing would have told it that the video had in fact stopped playing.

Next we'll attach a function to our rewind to start button. The ActionScript is similar in structure to our back and forward frame buttons:

When the button is released Flash checks to see whether video is already playing or not and then acts accordingly. We set a variable playing to show true when the video clip is playing and false when stopped. This variable is set immediately after the video is told to play or stop and therefore sets up the script for next time the button is pressed. It is important to bear this in mind when we come to add functions to our other buttons.

```
controls.homeBut.onRelease = function() {
  video.gotoAndStop(1);

};
```

This time though, rather than just going back a single frame, we are telling the video clip to return right to the beginning at frame 1.
