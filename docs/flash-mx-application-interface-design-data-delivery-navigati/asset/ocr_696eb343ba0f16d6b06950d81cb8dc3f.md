We then draw our second curved line by using a little math to offset the control point by an arbitrary amount (you could probably tweak this line to achieve different results) and draw the line from the end point (the red movie clip) back to the start point (the green movie clip). After this, we end the fill.

The last line of code outputs a string into a selectable text field on screen by concatenating the x and y positions of the green, red, and yellow movie clips, along with the other information we typed into the input fields. Just be sure to hit the button marked Generate Array whenever you make any changes.

Once we have our leaf in the shape that we’d like to see it when it’s at full growth, all we have to do is copy the contents of the text field and paste it into the leafMap array in the appropriate place. You’ve then got the coordinates for every leaf that you want to make, without having to sit down and try work out in your head how and where each leaf will be and what it will look like.

The values in the array that are outputted to screen in our mini-application are those of the leaf as you’d see it when the plant is fully grown (when the variable plantSize is equal to 50). For our leaf to start out smaller and grow to the finished size as we see it in the mini-application, you should do the following:

+   - If the leaf curls out to the left, you must manually add 50 to the value of `_root.endMov.x`. For example if `_root.endMov.x` is 200 in the full-grown leaf, you must change the value of it to 250 in the `leafMap` array for that leaf.

+   - If the leaf curls out to the right, you must manually remove 50 from the value of `_root.endMov.x`. For example if `_root.endMov.x` is 350 in the full-grown leaf, you must change the value of it to 300 in the `leafMap` array for that leaf.
