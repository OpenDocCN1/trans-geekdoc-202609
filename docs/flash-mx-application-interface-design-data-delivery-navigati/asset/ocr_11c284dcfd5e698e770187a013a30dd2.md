This line is redrawn every frame, and we get a nice smooth line from the start point to wherever we move the mouse.

When we release the mouse, we run through a similar set of actions, but we draw to the drawPad instead of to the tempLayer. First of all, we clear the tempLayer to delete the temporary line that we'd been using:

```
drawPad.onRelease = drawPad.onReleaseOutside=function () {
tempLayer.clear();
}
```

We then set the lineStyle of the drawPad, and draw a line from the original start point to the last mouse position points. We also set the _root.onEnterFrame handler to be undefined, as we've finished with it until next time we click the mouse.

```
drawPad.lineStyle(_root.mainButBrushSize.bSize, _root.col, _root.mainButBrushAlpha.bAlpha);
drawPad.moveTo(_root.startX, _root.startY);
drawPad.lineTo(_root.xM, _root.yM);
_root.onEnterFrame = undefined;
});
};
```
