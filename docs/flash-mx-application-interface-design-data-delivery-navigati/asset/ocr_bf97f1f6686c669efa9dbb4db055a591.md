This code simply allows the controller to be dragged around while the drag button is pressed until the button is released:

```
controls.drag.onPress = function() {
    startDrag(controls);
};
controls.drag.onRelease = function() {
    stopDrag();
};
```

This next code allows us to drag the video around. There is no need for a button as it is the only function the video clip needs to have.

```
video.onPress = function() {
    startDrag(video);
};
video.onRelease = function() {
    stopDrag();
};
```
