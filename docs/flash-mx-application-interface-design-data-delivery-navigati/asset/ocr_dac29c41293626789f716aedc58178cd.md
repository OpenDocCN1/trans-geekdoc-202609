This folder happens to be filled with JPG images, which, when double-clicked, open up a little JPG viewer within the window:

![](bbox=[0.109, 0.174, 0.513, 0.432])

This is complete with zoom in / zoom out and download buttons.

Alternatively, we can navigate to a location containing MP3 files:

![](bbox=[0.122, 0.572, 0.504, 0.699])

If we double-click on an MP3 file, an MP3 player opens:

![](bbox=[0.199, 0.766, 0.431, 0.892])

And then of course, if we find any text files, (with the extension .txt), then Flash opens up the text file in a text reader window:

![](bbox=[0.549, 0.174, 0.959, 0.429])

Any other file types, and by default, Flash will open them up in a blank browser window, via the getURL action.

Navigation is, of course, accomplished with the use of folder icons, like so:

![](bbox=[0.549, 0.565, 0.959, 0.696])

Double-click on a folder, and we navigate into it, and its contents populate the window.
