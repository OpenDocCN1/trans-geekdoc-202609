

# 来自 Transformers 的双向编码器表示 (BERT)

**来自 Transformers 的双向编码器表示** (**BERT**) [[6]](#c11.xhtml#c11_ref6) 是另一种使用 Transformer 层堆栈的上下文语言模型。Transformer 架构首次在 [第 11 章，序列建模](#c11.xhtml) 的*语言翻译*中引入。那里我们有 Transformer 编码器和解码器。BERT 模型仅使用 Transformer 的编码器部分。下图展示了具有两个 Transformer 编码器层的 BERT 架构。输入 Token 的数量与输出 Token 的数量相同 (N)。我们将这些称为 `transformed features`。请参考下图：

![BERT architecture with 2 transformer encoder layers](images/Figure-12.9.jpg)

**图 11.9：** *具有 2 个 Transformer 编码器层的 BERT 架构*

输入是大小为 H 的 Token 嵌入序列。输出是大小为 H 的向量序列。输出序列的长度与输入序列相同。这些向量是输入向量的上下文嵌入。对于 BERT，通常使用固定的序列长度。然而，输入可以是可变长度的，因此必须对输入进行填充以使其长度相同。

由于 Transformer 架构不是循环的，并且一次性看到整个序列，我们必须有一种方法来保留文本中的顺序信息。此外，文本中存在自然片段，如句子和段落。保留这些输入信息对于更好地建模文本非常重要。这是通过位置编码和片段编码来完成的。

## 位置编码

由于我们的词嵌入是向量，为了编码单词的位置，我们不能直接使用整数。使用整数 `i` 的向量表示来编码位置。我们知道任何整数最简单的向量表示是二进制（6 位）表示，如下表所示，针对整数 0-7。我们看到最低有效位 (LSB) 在连续位之间交替。下一位每两个数字变化一次，再下一位每四个数字变化一次，依此类推。二进制交替信号的连续对应物是正弦函数 `sin(ωt)`。此外，我们可以通过改变参数 `ω` 来控制它们交替的频率。因此，使用正弦函数，我们可以为序列定义位置编码 `PE(pos, 2i)`，定义如下：

![Positional encoding formula](images/2721.jpg)

下图显示了长度为 50 的序列的 128 维位置编码。我们可以看到向量的第一个分量（最左边的垂直列）在高正值和负值之间交替，非常类似于二进制表示中的 LSB，随着我们向右移动，变化的频率降低。请参考下图：

![BERT positional encoding](images/Figure-12.10.jpg)

**图 11.10：** *BERT 位置编码 来源：[https://kazemnejad.com/blog/transformer_architecture_positional_encoding/](https://kazemnejad.com/blog/transformer_architecture_positional_encoding/)*

Transformer 架构配备了残差连接，这使得序列信息能够传递到 Transformer 的顶层。这种位置编码可用于编码 Token 级别的位置和句子片段位置，如下图所示：

对于训练此架构和创建这些嵌入，不需要任何标记的训练数据。以无监督方式训练 BERT Transformer，这称为*预训练*。

## BERT 预训练任务的输入表示

由于 BERT 接受固定大小的输入，首先通过零填充使每个句子长度相等，并使用以下步骤标记句子的分隔和结束。

1.  每个输入序列的第一个 Token 是特殊的分类 Token – `[CLS]`。此 Token 用于分类任务，作为整个序列表示的聚合。在非分类任务中会被忽略。
2.  对于单文本句子任务，此 `[CLS]` Token 后跟 WordPiece Token 和分隔 Token – `[SEP]`。
3.  对于句子对任务，两个句子的 WordPiece Token 由另一个 `[SEP]` Token 分隔。此输入序列也以 `[SEP]` Token 结尾。

## WordPiece 分词

分词从根本上说是将文本分解为 Token 的过程。**词表外单词** (**OOV**) 或词汇表中不包含的单词，被视为“*未知*”。解决此问题的一种更好且现代的方法是将文本分词为子词单元，在大多数分割中可以保留语言学意义。因此，即使一个单词对模型未知，单个子词 Token 可能保留足够的信息供模型推断含义。WordPiece 就是一种此类算法。给定文本，WordPiece 首先将文本预分词为单词（通过在标点符号和空白处分割），然后将每个单词分词为子词单元，称为 wordpieces。例如，让我们以下图所示的句子为例：

![WordPiece tokenization example](images/Figure-12.12.jpg)

**图 11.12：** *WordPiece 来源 ([https://ai.googleblog.com/2021/12/a-fast-wordpiece-tokenization-system.html](https://ai.googleblog.com/2021/12/a-fast-wordpiece-tokenization-system.html))。*

预训练的 BERT 模型通常在海量数据集上执行。预训练后，BERT 模型可以作为文本的特征提取器，并可用于解决其他 NLP 任务，如文本分类、文本摘要等。对于这些任务，我们通常拥有较小的数据集。可以在 BERT 顶部添加几个特定任务的层，如下图所示，并使用特定任务的数据进行训练。此过程称为*微调*。根据数据集的大小，我们可以选择将 BERT 特征提取器用作固定函数（不可训练）或训练所有层。

[图 11.13](#c11.xhtml#fig11_13) 展示了通过结合 BERT 和一个额外的输出层来执行的各种微调任务。

*   ([图 11.13](#c11.xhtml#fig11_13) 左上) 句子对分类，给定两个句子，任务是找出它们之间的相似度分数，或将它们分类为改写，即它们用不同的词表达相同的含义。Quora 问题对和 **Microsoft Research Paraphrase Corpus** (**MRPC**) 分别是这两项任务的两个流行基准数据集。
*   ([图 11.13](#c11.xhtml#fig11_13) 右上) 第二个任务是句子分类，其中计算出的句子嵌入 `[CLS]` 用作句子分类的特征。
*   ([图 11.13](#c11.xhtml#fig11_13) 左下) 第三个任务是问答或抽取式摘要，给定一个问题句子和一个包含答案的段落，任务是从段落中选出能回答问题的最佳句子边界。
