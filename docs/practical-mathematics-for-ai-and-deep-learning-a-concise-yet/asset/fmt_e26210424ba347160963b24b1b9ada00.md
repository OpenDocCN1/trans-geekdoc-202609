
# How is a r.v. different from a simple variable?

For a simple variable, we cannot say how likely it is that the variable takes a given value or how likely its value is to fall in each range because there is no probability associated with the variables. For an r.v., there is an associated probability measure that tells how likely it is that the variable takes a certain value or a certain range of values. This extra information about the variable distinguishes an r.v. from a simple variable, and it is represented as another function called the **Probability Mass Function (P.M.F)** for a discrete random variable and **Probability Density Function (P.D.F)** for a continuous random variable.

Let the random experiment be tossing a coin three times. Let `X` denote the count of heads from three-coin tosses. Clearly, `X` can take values from this set `{0,1,2,3}`. # Bernoulli and categorical distribution

The most basic of all discrete random variables is the *Bernoulli*. `X` is said to have a Bernoulli distribution if `X = 1` occurs with probability `p` and `X = 0` occurs with probability `1 - p`. Here, `p` is generally called the probability of success. This is like a biased coin toss experiment where head occurs with chance `p` and tail with chance `1 - p`.

![](images/994.jpg)

## Generalized Bernoulli distribution (Categorical)

In a Bernoulli experiment, we have only two possible outcomes. We can generalize this to K possible outcomes. For example, we are given an urn of four different colored balls: red, blue, green, and orange. Let `X=0,3` represent the four colors, respectively. We have to find the probability of drawing a given colored ball, where each ball is drawn at random with replacement. Such an r.v. is called a categorical random variable. In general, a categorical variable `X` can take one of K possible values `{1,2,…,K}` with probability ![](images/995.jpg), where ![](images/996.jpg) = 1.
