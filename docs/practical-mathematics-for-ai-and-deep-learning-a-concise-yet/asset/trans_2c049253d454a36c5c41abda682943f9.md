
考虑一个包含 `n` 个数据样本的集合，该集合被划分为 `m` 个模糊簇，其中 `c_j` 是第 `j` 个簇的质心。样本 `x_i` 属于簇 `c_j` 的隶属度用 `u_{ij} \in [0, 1]` 表示，其中 `\sum_{j=1}^m u_{ij} = 1`。该值也称为*隶属度值*。`d` 是一个控制簇模糊程度的超参数（值越大，模糊程度越高）。*隶属度值* 定义如下：

```
u_{ij} = \frac{1}{\sum_{k=1}^m \left( \frac{\|x_i - c_j\|}{\|x_i - c_k\|} \right)^{\frac{2}{d-1}}}
```

第 `j` 个簇 `c_j` 的模糊质心定义如下：

```
c_j = \frac{\sum_{i=1}^n u_{ij}^d x_i}{\sum_{i=1}^n u_{ij}^d}
```

FCM 的目标是最小化以下函数：

```
J = \sum_{i=1}^n \sum_{j=1}^m u_{ij}^d \|x_i - c_j\|^2
```

K-means 算法优化的是上述相同的目标函数，但隶属度值 `u_{ij}` 将只能是 0 或 1。模糊程度由 `d \in [1, \infty)` 的值控制。当 `d \to 1` 时，`u_{ij}` 变为 0 或 1，FCM 退化为 k-means 算法。

我们已经讨论了不同类别的聚类算法。没有明确定义的指南说明哪种算法最适合特定领域。我们必须在我们的问题上尝试不同的距离度量和聚类算法，以满足需求。

# 结论

在本章中，我们讨论了专门用于无标签数据的距离度量和聚类算法。我们还讨论了各种流行的聚类算法类别及每类中的具体算法。存在不同的现实场景，在这些场景中只有无标签数据或极少量的有标签数据可用。在这些场景中，我们必须使用聚类算法。

# 降维

在应用 AI 算法之前，每个对象都通过向量在数学上表示。用随机向量表示对象绝对是个坏主意，因为它无法捕捉数据之间的关系（如果关系存在的话）。大多数时候，数据之间确实存在关系，这些关系将成为 AI 算法学习所需任务的关键信息。学习前的一项关键任务是用数值表示对象，以捕捉它们的关系。
