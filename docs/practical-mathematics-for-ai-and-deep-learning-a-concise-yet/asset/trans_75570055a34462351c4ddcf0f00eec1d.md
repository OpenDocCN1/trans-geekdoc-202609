
在显著性水平 `α` 下，统计量 `Z` 的临界值对于双尾检验定义为 `Z_{α/2}`。此处，`P(Z > Z_{α/2}) = α/2`，意味着 `P(Z < -Z_{α/2}) = α/2`。这在 [图 5.2](#c05.xhtml#fig5_2) 的阴影区域中有所描绘。因此，我们有 `P(Z > Z_{α/2}) = α/2`。由对称性可知，`P(Z < -Z_{α/2}) = α/2`。对于单尾备择假设的检验，将只有一个阴影区域，位于左侧或右侧，取决于检验类型，如 [图 5.2](#c05.xhtml#fig5_2) 所示；该阴影区域称为*临界区或拒绝域*：

### 6. 结论

将计算得到的 `Z` 值与给定显著性水平 `α` 下的显著性值 `Z_{α/2}` 进行比较。如果 `Z` 值落在定义的临界区内，则以置信度 `1 - α` *拒绝*原假设。选择 `α = 0.01`，我们可以断定原假设（即此处的专家委员会的主张）是错误的，并可以 99% 的置信度将其拒绝。

现在，让我们看几个假设检验的例子，在这些例子中我们将遵循上述步骤来验证统计假设。

**示例**：检验一枚骰子是否均匀或无偏（即所有六个面值出现的可能性相等）。一枚骰子被投掷 9000 次，出现 5 或 6 的次数为 3600 次。这枚骰子是否无偏？

对于一枚无偏骰子，每个面的概率为 `1/6`。我们可以将出现 5 或 6 的事件视为成功，并用 `S` 表示。我们有 `P(S) = 1/3`。出现除 5 或 6 以外的任何值均视为失败。因此，我们得到一个二项分布变量，试验次数 `n = 9000`，成功概率 `p = 1/3`，观察到的成功次数为 3600。此处，原假设为 `H_0: p = 1/3`，即 `p = 0.333...`，备择假设为 `H_1: p ≠ 1/3`。设随机变量 `X` 表示成功的计数。对于二项分布，均值为 `np`，方差为 `npq`：

因此，对于大 `n`，`μ = 3000` 且 `σ² = 2000`

所以，`Z = (3600 - 3000) / √2000 ≈ 13.42`

由于 `Z > Z_{0.005} ≈ 2.576`，选择显著性水平 `α = 0.01`，根据正态分布的经验法则可知此点。因此，`Z` 落在临界区或拒绝域内。所以，我们可以以 99% 的置信度拒绝原假设。因此，该骰子不是一枚均匀骰子。

# 统计推断

让我们考虑一个具有概率密度 `f(x; θ)` 的随机变量 `X`。此处，`θ` 表示分布的参数集合，或更正式地说，`θ` 表示参数向量。例如，在正态分布的情况下，`θ = (μ, σ²)`。所有参数可能取值的集合称为*参数空间*。因此，参数空间定义了一族概率分布：

`{ f(x; θ) : θ ∈ Θ }`

现在，让我们考虑一个来自总体的大小为 `n` 的随机样本 `X_1, X_2, ..., X_n`，其概率密度函数为 `f(x; θ)`。我们能否将参数向量 `θ` 作为样本值的函数进行估计？也就是说，我们能否定义一个统计量 `t` 来近似总体参数？设向量 `X = (X_1, X_2, ..., X_n)`，那么我们想要寻找样本统计量：

`θ̂ = t(X)`

使得 `θ̂` 的分布集中在总体参数 `θ` 的真实值附近。此处，`t(·)` 描绘了统计量 `θ̂` 的估计量函数。在这种情况下，统计量 `θ̂` 称为总体参数 `θ` 的*估计量*。

## 估计量的性质

现在让我们讨论什么样的统计量性质使其成为一个好的估计量：

*   **无偏性**：如果 `E(θ̂) = θ`，则估计量 `θ̂` 称为总体参数 `θ` 的*无偏*估计量。假设对于一个具有概率分布 `f(x)` 的未知总体，我们已知期望：`E(X) = μ` 和 `Var(X) = σ²`。样本点 `X_i` 可以视为一组 `n` 个**独立同分布**（**i.i.d.**）随机变量 `X_1, X_2, ..., X_n`，它们取值 `x_1, x_2, ..., x_n`，且每个 `X_i` 均具有均值 `μ` 和方差 `Var(X_i) = σ²`。对于统计量样本均值 `X̄`，我们有 `E(X̄) = μ`。

    因此，样本均值是总体均值的*无偏*估计。样本方差的期望如下：

    `E(S²) = (n-1)/n σ²`

    证明参考见*延伸阅读部分 [3]*。因此，*样本方差不是总体方差的无偏估计*。

*   **一致性**：对于任意估计量 `θ̂_n`，我们可以定义一个变量序列：`θ̂_1, θ̂_2, ..., θ̂_n`。此处，`θ̂_n` 取决于所取样本值的数量 `n`。如果这一数值序列 `θ̂_n` 依概率收敛于真实参数值，则称估计量 `θ̂` 为参数值 `θ` 的*一致*估计量。我们将其表示为 `θ̂_n → θ`，其中算子 `→` 表示依概率收敛，即对于任意任意小的 `ε`：

    `lim_{n→∞} P(|θ̂_n - θ| > ε) = 0`

    显然，样本均值是总体均值的*一致*估计量。

*   **有效性**：对于一个总体参数，可能存在多个无偏且一致的估计量。因此，需要进一步的准则来选择最佳估计量。方差较小的那个称为*有效*估计量，因为它的取值倾向于更紧密地集中在参数的正确值周围，因此我们的估计将更接近实际值。对于正态分布，由于钟形曲线的对称性，样本中位数也是总体均值 `μ` 的无偏估计。那么，应该选择哪一个作为更好的估计量？这里我们可以比较两个估计量的方差或标准误的平方。现在，`Var(X̄) = σ²/n`，且可以证明对于样本中位数 `Md`，`Var(Md) ≈ πσ²/(2n)`。因此，样本均值是 `μ` 的更有效估计量。

*   **充分性**：如果一个估计量包含样本中关于被估计总体参数的所有信息，则称其为充分估计量。估计量的这一性质超出了本书进一步讨论的范围。

## 最小方差无偏估计量

如果统计量 `T` 是总体参数 `θ` 的无偏估计量，且 `T` 在所有无偏估计量类中具有最小方差，则称 `T` 为 `θ` 的最小方差无偏估计量。形式上：

*   `E(T) = θ`
*   `Var(T) ≤ Var(T')` 对所有无偏估计量 `T'` 成立

MVU 是唯一的。要检验一个无偏估计量是否为 MVU，可使用**克拉默-拉奥不等式**。该不等式为参数无偏估计量的方差提供了一个下界。量 `E(θ̂) - θ` 通常称为估计量的*偏差*。对于无偏估计量，偏差为零。
