
*   **句子分割**：将文本拆分为句子的过程也称为句子分段。这主要是一种基于规则的方法；例如，句子必须以大写字母开头，并以特定的标点符号结尾。

*   **词元化**：这是将句子拆分为其组成词语的过程。在此过程中，标点字符会被拆分并分离为独立的词元。这些也是基于规则的，我们可以指定使用正则表达式拆分词元的规则，也可以使用标准的语法规则进行拆分。

*   **文本清洗**：文本中常见的词汇，如常用动词、连词，例如 `{ a, an, and, but, how, in, is, are, on, or, the, what, will }` 称为 `stopwords`（停用词），会从词元列表中移除。转小写、移除特殊字符、空白字符也是常见的预处理步骤。

*   **词形还原**：移除词的词缀以获取词的基本形式。这种基本形式必须是一个语义正确的单词。通常使用类 WordNet 的数据库来对单词进行词形还原。例如，以下所有单词 `{connection, connections, connective, connected, connecting}` 都源自词根 ‘connect’，而 ‘connect’ 是它们的词元。

*   **词干提取**：词干提取类似于词形还原，不同之处在于输出不必是一个有意义的单词。这是一种基于规则的方法。Porter 词干提取器是一种流行的基于规则的词干提取算法。

*   **子词词元化**：将单词进一步分割成不必具有任何意义的小块，称为子词词元化。这是为了解决 `Out Of Vocabulary` (`OOV`，词表外) 词汇而需要的。假设我们从语料库中提取了所有单词，我们称之为该语料库的 `vocabulary`（词汇表/词表）。我们仅基于这些单词构建文本特征，文本模型也以这些特征作为输入。现在，给定用于训练模型推理的新文本，如果该文本包含不在我们词表中的新单词，我们称之为 OOV 词。如果我们有子词词元，则可以将新单词拆分为子词元，这些子词元属于我们的词表。许多最先进的 NLP 模型都使用这种词元化技术。我们详细讨论了一种子词词元化方法。

*   **词性标注**：词性标签也可以作为文本的特征使用。

在各种编程语言中都有多种文本预处理库。在 Python 中，我们有 `nltk`、`genism`、`scikit-learn`。建议读者参阅“进一步阅读”部分中的 `[1]`、`[2]` 以获取详细示例。NLTK 文档 `[3]` 也提供了大量入门示例。

# 文本模型

*“所有模型都是错的，但有些是有用的！”* ——这是统计学中的一句名言，通常归功于统计学家乔治·博克斯。这在 NLP 领域同样适用。存在各种文本模型，每种模型适合解决文本中的特定问题。没有任何单一模型能够代表文本结构的所有方面。例如，如果我们想通过查看某些关键词来判断一封邮件是否为垃圾邮件，垃圾邮件中通常出现的关键词和关键短语可能很有用。因此，对于这个问题，将文本建模为词袋就足够了。我们可能不需要考虑书面文本中的结构细节。然而，如果我们想分析关于一部电影或新发布产品的评论是正面还是负面，我们可能需要利用文本中更深层的语义和句法关系。

文本模型可以在所有层级构建：文档级、句子级、段落级和单词级。如果我们想比较或分类一组文档，我们会倾向于使用文档级文本模型。对于构建聊天机器人，我们需要构建句子或短语级模型，能够跟踪对话上下文并提供期望的回复句子。

# 词袋模型

从给定的文本文档出发，我们应用前面讨论的标准预处理技术，每个文档被表示为一个无序的单词列表，即文档中出现的已处理单词。这种表示形式不捕捉文本的任何句法或语义属性。这是最简单的文本模型。将无序单词列表转换为数值表示有多种方法，具体讨论如下。

# 向量空间模型

给定从文档中提取的 BoW，我们可以为文档创建一个特征向量，其中每个特征是一个单词，特征的值应反映该单词在文档中的出现情况和重要性。整个文档被表示为一个特征向量，每个特征向量对应向量空间中的一个点。该向量空间的维度为 `V`，其中 `V` 是词汇表的大小。这里，词汇表是基于整个语料库构建的。

# 基于计数或布尔值

给定一个文档语料库，我们可以将每个文档表示为一个向量。假设整个语料库中有 V 个唯一单词。那么，每个文档将被表示为一个 V 维向量。我们称 V 为语料库的 `vocabulary`（词汇表/词表）大小。词汇表中的每个单词代表向量中的一个特征。如果词汇表中的某个单词 w 未出现在特定文档中，则对应的特征值为零；否则，特征值为该单词在特定文档中出现的次数，即词频。*表 11.1* 展示了一个包含两个文档及其对应词频向量的语料库示例。语料库中共有七个唯一单词。

# 词频-逆文档频率

基于计数或布尔值的模型赋予语料库中所有单词同等的重要性。可能存在一组单词在语料库中更频繁，且几乎出现在每个文档中。这些单词可能无法为语料库中的文档提供任何重要特征。相反，仅在极少数文档中出现的稀有单词可能提供一些区分性特征。文档频率是指包含某个单词的文档数量。**逆文档频率** 记为 **IDF**，其计算方法是将语料库中文档总数除以每个词项的文档频率，然后对结果应用对数缩放。我们可以给每个词项的文档频率加 1，以防止仅出现在一个文档中的词项以及语料库中不存在的词项导致 idf = 0，这也能防止计算 `idf` 时出现除零错误。`term frequency`（词频）是词项在文档中的计数，因此我们用 `idf` 加权词频，从而得到每个词项的 tf-idf，公式如下：
