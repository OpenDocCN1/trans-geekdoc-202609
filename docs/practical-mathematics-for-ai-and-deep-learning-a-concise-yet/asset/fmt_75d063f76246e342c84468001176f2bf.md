![](images/2373.jpg)

以下代码实现了 μ=0 和 σ=1 时的此函数：

```
1. def laplacian_of_gaussian_2d(x, y):
2.     # Exponent part of gaussain function mean=0, sd=1
3.     power_part = (np.power(x, 2.) + np.power(y, 2.)) / 2.
4.     exp_part = np.exp(-power_part)
5.     prod_part = (-1./np.pi) * (1. - power_part)
6.     return prod_part * exp_part
```

# [Sobel 核：一阶导数](#toc.xhtml#s302a)

迄今讨论的拉普拉斯核是二阶导数，用于测量斜率的变化。而 Sobel 核是一阶导数，用于测量斜率，并像 LoG 一样结合了高斯平滑。

Sobel 核由两个核组成，分别计算水平轴和垂直轴方向导数的近似值。可以使用 OpenCV 库获取各种尺寸的 Sobel 滤波器。*代码 9.8* 展示了获取 Sobel 滤波器的步骤。`getDerivKernels()` 输出两个大小为 `dim×1` 的向量，这两个向量需要相乘以获得可分离向量：

```
1. def get_sobel_kernel(dim=3):
2.     sobelx_sep = cv.getDerivKernels(1, 0, dim, normalize=True)
3.     sobelx = np.outer(sobelx_sep[0], sobelx_sep[1])
4.     sobely_sep = cv.getDerivKernels(0, 1, dim, normalize=True)
5.     sobely = np.outer(sobely_sep[0], sobely_sep[1])
6.     return sobelx, sobely
```

**代码 9.8：** 使用 OpenCV 库获取 Sobel 滤波器

# [非线性滤波器](#toc.xhtml#s303a)

*中值滤波器* 是一种用于去除噪声的非线性滤波器（对“椒盐噪声”有效：这是一种由尖锐突发干扰引起的噪声形式，表现为稀疏分布在图像上的黑白像素）。大小为 `n×n` 的 *中值滤波器* 在应用于某像素时，将其替换为该像素及其邻域像素的中值（`n×n` 个像素的中值），卷积核中心与待处理像素对齐。滤波器在整个图像上滑动。为了覆盖边界像素，通常使用 *边界复制* 填充，即用最近像素值填充边界。

*平均滤波器* 在应用于某像素时，将其替换为该像素及其邻域像素的平均值（`n×n` 个像素的平均值），卷积核中心与待处理像素对齐。与所有其他滤波器一样，该滤波器通过在每个可能的像素上滑动来应用于图像。
