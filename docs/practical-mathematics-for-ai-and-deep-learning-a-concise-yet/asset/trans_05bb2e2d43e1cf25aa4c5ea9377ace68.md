

# 指数分布

指数分布是另一种常用的连续分布。它常用于表示事件之间经过的时间。

服从指数分布的连续随机变量 X 的密度函数记为 `X ~ Exp(λ)`，λ > 0，定义如下：

```
f(x) = λe^(-λx) for x ≥ 0
```

**示例**：机票通常提前预订，一般来说，我们提前预订机票的天数取决于诸如行程是否有计划、是否为假期、价格是否会飙升等因素。观察发现，旅客提前购买机票的天数服从指数分布，平均为 15 天。

# 随机变量的数学期望

随机变量 X 的概率分布告诉我们 X 取特定值或落在特定区间的可能性。在实践中，更易于解释的信息是随机变量取值的平均值。例如，一家公司可能对其即将推出的新产品的平均利润感兴趣；儿科医生可能对 5 岁儿童的平均身高和平均体重感兴趣。随机变量的平均值也称为随机变量的**数学期望**，记为 `E[X]`。

离散随机变量的期望值是所有可能值的加权平均，由下式给出：

```
E[X] = Σ x * P(X = x)
```

对于连续随机变量，我们必须用积分代替求和，得到定义：

```
E[X] = ∫ x * f(x) dx
```

**示例**：设 X 表示一个人在高层建筑中等待电梯的时间（分钟）。这里，X 是一个连续随机变量，具有以下分布：

```
f(x) = x * e^(-x) for x ≥ 0
```

X 的期望值由下式给出：

```
E[X] = ∫ x * f(x) dx = 1
```

因此，该建筑中等待电梯的期望时间为 1 分钟。读者可以绘制该密度函数，观察到在这种情况下最大密度也在 `x = 1` 处。

我们可以计算前面讨论的已知概率分布的随机变量的期望。这在下表中展示：

| **分布(X)** | **均值或 E[X]** | **方差 E[(X – E[X])²]** |
| --- | --- | --- |
| `X ~ Bernoulli(p)` | `p` | `p(1 – p)` |
| `X ~ Binomial(n;p)` | `np` | `np(1 – p)` |
| `X ~ Poisson(λ)` | `λ` | `λ` |
| `X ~ N(μ, σ²)` | `μ` | `σ²` |
| `X ~ Exponential(λ)` | `1/λ` | `1/λ²` |
| `X ~ Uniform(a,b)` | `1/2(a + b)` | `1/12(b – a)²` |

**表 4.3：** *几种常用分布的均值和方差*

我们也可以定义随机变量函数 `g(X)` 的期望值，如下所示：

```
E[g(X)] = Σ g(x) * P(X = x)  (离散)
E[g(X)] = ∫ g(x) * f(x) dx   (连续)
```

对于 `g(X) = (X - μ)^r`，`g(X)` 的期望称为 X 关于均值的 r 阶矩。特别地，如果 `r = 2`，则 `g(X)` 的期望称为随机变量的**方差**，常记为 `σ²`。

```
Var(X) = E[(X - μ)²] = E[X²] - (E[X])²
```

以下是期望的几个性质：

*   **期望是线性算子。** 因此，随机变量线性组合的期望由下式给出：
    *   `E[X + Y] = E[X] + E[Y]`
    *   `E[aX] = aE[X]` 对任意常数 a 成立。
*   **相互独立随机变量乘积的期望**如下：
    *   `E[XY] = E[X]E[Y]`
    *   `E[g(X)h(Y)] = E[g(X)]E[h(Y)]`
*   **柯西-施瓦茨不等式**：若 X 和 Y 是两个随机变量，则 `(E[XY])² ≤ E[X²]E[Y²]`，等号成立当且仅当 `Y = aX + b`，其中 `a, b` 为实数。
*   **詹森不等式**：设 g 为随机变量 X 的凸函数，则 `E[g(X)] ≥ g(E[X])`。

# 联合概率分布

到目前为止，我们讨论了单个随机变量的概率分布。在现实生活中，我们经常遇到多个相关的随机变量。以下是几个例子：

1.  在生态学中，一种物种可能是另一种的猎物，因此捕食者的数量将与猎物的数量相关。如果我们将猎物和捕食者的数量建模为两个随机变量 `X₁` 和 `X₂`，它们之间必然存在某种依赖关系，并且这些随机变量取某对值的概率也存在关联。因此，对变量 `(X₁, X₂)` 的联合概率进行建模是合理的。
2.  假设我们正在研究某个社区的不同家庭。我们可以将家庭收入、家庭成员数量、家庭最高学历等统计数据表示为不同的随机变量 `X₁`、`X₂` 和 `X₃`。这些变量极有可能相互依赖，我们需要联合研究它们的分布。

设 X、Y 为两个离散随机变量，X 取 n 个不同值 `x₁, x₂, ..., xₙ`，Y 取 m 个不同值 `y₁, y₂, ..., yₘ`。X 和 Y 的联合概率质量定义为 `P(X = xᵢ, Y = yⱼ)`。例如，设 X 表示工厂包装车间生产的塑料盖的长度，Y 表示宽度（单位：毫米）。如果将 X、Y 四舍五入到最近的整数，它们取一组离散值。设 `X ∈ {200,201,202,203}` 和 `Y ∈ {300,301}`。请参考下表：

**表 4.4：** *联合分布示例*

| 长度 X | 宽度 Y = 300 | 宽度 Y = 301 | P(X) |
| :--- | :---: | :---: | :---: |
| 200 | 0.10 | 0.17 | 0.27 |
| 201 | 0.15 | 0.20 | 0.35 |
| 202 | 0.07 | 0.26 | 0.33 |
| 203 | 0.05 | 0.03 | 0.08 |
| **P(Y)** | **0.37** | **0.63** | **1.00** |

表中所有概率之和为 1.0。给定 X 和 Y 的联合概率分布，可以很容易地从联合分布导出 X 或 Y 的单独概率分布。

`P(X = 202) = P(X = 202, Y = 300) + P(X = 202, Y = 301) = 0.33` = 前一个联合概率矩阵中 `X = 202` 所在的第 3 列的列和。

`P(Y = 301) = P(Y = 301, X = 200) + P(Y = 301, X = 201) + P(Y = 301, X = 202) + P(Y = 301, X = 203) = 0.17 + 0.20 + 0.26 = 0.63` = 上述联合概率矩阵中 `Y = 301` 所在的第 2 行的行和。

概率分布 `P(X)` 出现在列和中，概率分布 `P(Y)` 出现在行和中，如**表 4.4**所示。因为它们出现在表格的边缘，所以被称为联合分布的*边缘概率分布*。

两个变量 X 和 Y 的联合概率密度函数记为 `f(x, y)`，称为*二元概率密度函数*。

```
f(x, y) ≥ 0 对所有 x, y 成立
∫∫ f(x, y) dx dy = 1
P((X, Y) ∈ A) = ∫∫_A f(x, y) dx dy
```

边缘密度由下式给出：

```
f_X(x) = ∫ f(x, y) dy
f_Y(y) = ∫ f(x, y) dx
```

联合概率和边缘概率的这些定义可以推广到 **n** 维，称为*多元概率密度函数*。要沿任意维度找到边缘分布，必须在剩余的 **n – 1** 个维度上求和（或积分）。例如，三维分布 `f(x, y, z)` 沿 x 轴的边缘分布为：

```
f_X(x) = ∫∫ f(x, y, z) dy dz
```

对于连续随机变量，我们也可以通过将求和替换为积分来定义联合分布和相应的边缘分布。二维积分表示二维区域上的积分，给出该区域的面积。对于连续分布，我们有：

```
f(x, y) ≥ 0
∫∫ f(x, y) dx dy = 1
```

X、Y 落入区域 **R** 的概率由下式给出：

```
P((X, Y) ∈ R) = ∫∫_R f(x, y) dx dy
```

边缘概率密度由下式给出：

```
f_X(x) = ∫ f(x, y) dy
```
和
```
f_Y(y) = ∫ f(x, y) dx
```

**注意：给定 X = x 时 Y 的条件密度函数可定义为：**

```
f_{Y|X}(y|x) = f(x, y) / f_X(x)  当 f_X(x) > 0 时
```

**对于相互独立的随机变量 X、Y，联合分布 `f_{XY}(x,y)` 可表示为边缘分布的乘积：**

```
f_{XY}(x, y) = f_X(x) f_Y(y)
```
