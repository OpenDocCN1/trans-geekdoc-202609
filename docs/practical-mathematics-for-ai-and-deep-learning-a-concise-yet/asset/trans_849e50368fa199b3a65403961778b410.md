
M 步更新公式以调整参数矩阵，使其最佳拟合观测数据和期望的隐藏状态。然后这两个步骤反复迭代，直到参数收敛，或者模型达到特定的准确度要求。

HMM 中的潜在变量可以具有某种有意义的解释。因此，对于给定的观测序列，找到最可能的隐藏状态序列通常很有用。我们之前讨论的一个例子就是句子的词性标注。此外，在语音识别中，我们可以为给定的一系列声学观测找到最可能的音素序列。我们可以使用 `Viterbi` 算法（一种基于动态规划的算法）找到最可能的隐藏状态序列。关于 Viterbi 算法的详细解释，请参阅延伸阅读 `[3], [4]`。

HMM 在各种序列建模问题中都有应用。随着深度学习的进步及其在超大数据集上训练模型的能力，循环神经网络开始在许多 HMM 曾用于的任务上表现得更好。

# 循环神经网络

神经网络也可用于学习序列。在前馈神经网络中，不同时间输入的两个不同输入被假定为相互独立，这意味着第一个输入或第一个输入的输出——两者都不影响第二个输出。因此，我们不能直接使用前馈网络来建模序列。**循环神经网络（RNN）** 将序列预测问题建模为：给定时间步 `t-1` 的序列，预测时间步 `t` 的序列。RNN 将过去时间步的信息存储在状态 `h_t` 中，然后将其与当前时间步的信息一起用于预测下一个时间步。此外，状态在每个时间步都会更新。

让我们通过一个简单的例子来理解这一点。给定一个数字序列，我们想要计算 EWMA（单侧）并输出 EWMA 的某个函数。让我们以 EWMA 的 `EWMA/2` 作为期望输出。以下代码实现了这一点：

```
1. import pandas as pd
2. import numpy as np
3.
4. seq = np.random.random(10)
5. print(pd.DataFrame(seq).ewm(alpha=0.1,adjust=False).mean()/2)
6.
7. #Also, we can implement it as
8. S = seq[0]
9. alpha = 0.1
10. for i in range(len(seq)):
11.      S = alpha*seq[i]+(1-alpha)*S
12.      output = S/2
13.      print(output, S)
```

**代码 10.2：**

在这里，变量 `S` 可以被视为一个保存已处理序列信息的状态变量。另一方面，`alpha` 是状态的一个参数，大致决定了在状态中存储多少先前信息。状态被初始化为等于序列的第一个元素。状态变量在每个时间步都会被使用，连同新的序列输入来计算 EWMA/2。

RNN 的结构类似于这个例子。我们可以用张量 `h_t`（隐藏状态）替换状态变量 `S`。`h_t` 作为输入（也是张量 `x_t`）和前一个隐藏状态 `h_{t-1}` 的函数来计算。参数 `alpha` 可以用权重矩阵 `W_h` 替换。网络预测的输出是状态 `h_t` 的函数。这里，`b_h` 和 `b_y` 是偏置项，分别描述了平均隐藏状态向量和平均输出向量。在 `t=0` 时，我们可以用零张量初始化隐藏状态。形式上，这可以写成如下形式：

```
h_t = f_h(W_h * h_{t-1} + U_h * x_t + b_h)
y_t = f_y(W_y * h_t + b_y)
```

这里，`f_h` 和 `f_y` 分别是隐藏状态和输出的激活函数。这些是 RNN 层方程，也称为 `RNN cell`。RNN 层由对序列的每个元素应用 RNN cell 组成。Cell 应该接受输入和前一个状态向量，并输出下一个状态和下一个序列元素。与前馈神经网络层不同，RNN cell 有一个反馈回路连接，因为 `h_{t-1}` 也是该层的输入，即上一时间步的层输出。我们可以用两种形式直观地表示这一点：一种带有反馈回路（图 10.7 左），另一种是展开的回路（图 10.7 右）：

# 训练 RNN

我们必须为序列定义损失函数来训练 RNN。所有时间步的损失函数 `L` 定义为基于每个 T 个时间步损失的总和：

```
L = sum_{t=1}^T E(y_t, y_t_hat)
```

这里，`y_t_hat` 是时间 `t` 的预测值，`y_t` 是序列在时间 `t` 的实际值。`E` 是误差函数。每个时间步的误差函数 `E` 根据我们要解决的问题类型来定义。对于预测序列的下一个元素，我们可以计算时间 `t` 预测序列与实际序列的 MSE。

理论上，RNN 应该能够从非常长的序列中学习，但在实践中，它们只能回溯几步。这一限制的原因在于基于链式法则的梯度更新。为了更新对应状态张量 `h_t` 的权重 `W_h`，我们必须计算误差梯度：

```
dL/dW_h = sum_{t=1}^T (dL/dy_t * dy_t/dh_t * dh_t/dW_h)
```

但 `h_t` 依赖于所有之前时间步的隐藏状态。我们可以将其写为：

```
dh_t/dW_h = sum_{k=1}^t (dh_t/dh_k * dh_k/dW_h)
```

`dh_t/dh_k` 是雅可比矩阵的乘积：

```
dh_t/dh_k = prod_{i=k+1}^t (dh_i/dh_{i-1})
```

因此范数为：

```
||dh_t/dh_k|| <= prod_{i=k+1}^t ||dh_i/dh_{i-1}||
```

随着序列长度增加，如果 `||dh_i/dh_{i-1}|| < 1`，则乘积会变得非常小，我们称之为 RNN 训练中的梯度消失问题。另一方面，如果 `||dh_i/dh_{i-1}|| > 1`，这些乘积会变得非常大，导致梯度爆炸问题。

为了解决这些问题，使用 **长短期记忆（LSTM）** 和 **门控循环单元（GRU）** 对 RNN 架构进行了一些修改。这些通常被称为门控单元。

> **注意：** 用于训练 RNN 的反向传播算法需要通过首先计算每个时间步的前向步骤来展开输入。这称为时间反向传播（BPTT）。由于这种时间依赖性，BPTT 无法并行化。因此，提出了另一种称为教师强制的算法，在训练期间，模型在时间 `t + 1` 接收真实输出 `y_t` 作为输入。教师强制不是将模型自己的输出反馈给自身，而是由目标值指定正确的输出是什么，这可以很容易地并行化。我们可以并行计算每个时间步的前向步骤，从而并行计算损失。

# 长短期记忆（LSTM）

LSTM 由三个或四个门组成，包括输入门、输出门和遗忘门，它们决定是否将信息写入记忆或隐藏状态。这些门也是基于小型神经网络的函数，公式如下，并在训练阶段学习。以下方程定义了 LSTM 单元中信息如何流动以及状态如何更新：

*   遗忘门：`f_t = sigma(W_f * [h_{t-1}, x_t] + b_f)`
*   输入门：`i_t = sigma(W_i * [h_{t-1}, x_t] + b_i)`
*   输出门：`o_t = sigma(W_o * [h_{t-1}, x_t] + b_o)`
*   细胞输入激活向量：`g_t = tanh(W_g * [h_{t-1}, x_t] + b_g)`
*   细胞状态输出：`c_t = f_t * c_{t-1} + i_t * g_t`
*   隐藏状态向量：`h_t = o_t * tanh(c_t)`
