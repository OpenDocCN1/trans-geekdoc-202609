# 聚类算法

选择用于我们任务的聚类算法存在许多因素。因素包括数据类型、数据集大小、数据样本维度、基于更大/更新数据的算法扩展性、算法的时间复杂度和资源需求、问题领域、数据样本间的相似性/非相似性比较。基于这些因素，我们可以选择聚类算法。存在许多类型的聚类算法，每种都适合特定的场景。接下来，我们将讨论几个重要的聚类算法类别。

# 基于划分的聚类

在这种聚类方法中，每个簇由一个*中心*或*质心*向量表示，该向量不必是数据集向量。此*中心*或*质心*向量代表相应的簇。存在多种计算此表示向量的方法。算法可能保持不变，但选择代表簇的向量的方法可能不同，从而导致不同的簇和解释。`k-means` 和 `k-medoids` 是基于划分聚类中最流行的聚类算法。

# K-means

**K-means [3]** 聚类算法将数据集样本划分为 `k` (给定) 个簇，使得**簇内平方和 (WCSS)** (即方差) 最小化。簇的质心或中心向量通过计算属于该簇的所有样本的均值得出，因此得名 `k-means`。

3. 通过计算分配给各自簇的所有样本的均值，计算 `k` 个簇的质心 `images/2151.jpg`。
4. 如果任何簇的质心发生变化，则转到步骤 2，否则停止。

算法将输出 `k` 个簇，其中每个数据样本被分配到一个簇。`k` 的值是算法的输入。我们如何知道正确的 `k` 值？不存在找到 `k` 值的正确方法。我们必须尝试不同的 `k` 值并根据我们的目标推断每个输出。肘部法则有助于找到正确的簇数，但可能并非在所有情况下都有效。

## 肘部法则

绘制一条轴为 `k` 值、另一条轴为误差的图。在某些情况下，我们可以注意到误差随 `k` 值的增加而逐渐减小，然后突然之间，误差减小的速率减缓。该节点处的 `k` 值，称为肘部，可以被考虑。这种确定 `k` 值的方法在少数情况下可能产生正确结果，没有数学基础支持该方法在所有情况下都有效。

## 挑战

由于以下挑战，K-means 算法并未被广泛使用：

* 该算法假设所有簇大小相似。
* 无效的 `k` 值可能会导致一些无效的簇。
* 它假设簇是球形的。鸢尾花数据集的簇不是球形的，该算法无法在此数据集上找到正确的簇。
* 算法输出受异常值或噪声的影响，因为质心向量的选择受异常值影响。

我们可以改变计算簇质心的方法。代替均值，我们可以使用类中点或中位数。使用中位数计算簇质心的算法称为 `k-medians`，使用类中点的算法称为 `k-medoids`。这些算法的其他步骤与 `k-means` 相比将保持相似。

# K-medoids

簇的类中点定义为簇中与簇内所有数据样本平均非相似度最小的数据样本。**K-medoids [4]** 选择实际数据点作为质心，与 `k-means` 的质心相比，这有助于更好地解释簇质心。由于 `k-medoids` 最小化成对非相似度之和，而不是平方欧氏距离之和（`k-means` 的情况），它比 `k-means` 对噪声和异常值更鲁棒。`K-medoids` 可用于任意非相似度度量，而 `k-means` 最适合欧氏距离。这里同样，k-medoids 问题精确求解是 NP-hard 的。一些流行的近似算法是**围绕类中点划分 (PAM) [5]**、**大规模应用聚类 (CLARA)** 和**基于随机搜索的大规模应用聚类 (CLARANS) [6]**。

PAM 算法遵循以下步骤：

1. 随机初始化 `k` 个数据样本作为质心。
2. 将所有非质心数据样本分配给最近的质心。
3. 对于每个质心 `m` 和每个非质心 `x`：
    1. 通过临时交换 `m` 和 `x` 计算代价
    2. 记录代价最小的组合
4. 交换代价最小的 `m` 和 `x`。
5. 如果任何簇的质心发生变化，则转到步骤 3，否则停止。
