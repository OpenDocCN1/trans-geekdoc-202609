# [特征值与特征向量](#toc.xhtml#s84a)

在向量空间中，可能存在某些特殊的非零向量。对应于线性变换函数 `T(⋅)` 的方阵变换矩阵 `A` 作用于这些特殊非零向量 `e` 时，会使向量按实标量因子 λ 缩放，即 `T(e) = Ae = λe`。这些向量称为*特征向量*，特征向量缩放所对应的缩放因子 λ 称为方阵 `A` 的*特征值*。

方程 `Ae = λe` 可表述为 (`A` – λ`I`) `e` = `o`，其中 `e` 为非零向量。这将有助于你求得特征值和特征向量。当且仅当矩阵 `B` = (`A` – λ`I`) 有相关的列/行，或零空间有非零向量时，非零特征向量 `e` 才存在。换句话说，当矩阵 `B` 不可逆时，`e` 存在非零解。

任何不可逆矩阵 `B` 的行列式均为零，即 `|A – λI| = 0`。该方程称为*特征方程*，是变量 λ 的多项式函数，该多项式的次数为 `n`（矩阵 `A` 的阶数）。该多项式函数称为 `A` 的*特征多项式*。`n` 次特征多项式可分解为 `n` 个线性项的乘积：`|A – λI| = (λ[1] – λ)(λ[2] – λ)…(λ[n] – λ)`，其中 `λ[i]` 为多项式的根，称为矩阵 `A` 的特征值。矩阵的特征值不总是唯一的；可能有重复。实矩阵的特征值也可以是复数。

一旦计算出特征值，即可使用 (`A` – λ`I`) `e` = `o` 求得对应的特征向量。对应于一个特征值的特征向量数量是无限的，可以用向量的标量乘法简洁地表示（见下文示例）。

此外，每个方阵 `A` 都满足其自身的特征多项式。这被称为*凯莱-汉密尔顿定理*。因此，如果我们在上述特征方程中用 `A` 代替 `λ`，会得到一个等于零矩阵的矩阵方程。

对应于不同特征值的特征向量是否总是线性无关？

考虑不同的特征值 `λ[1]` ≠ `λ[2]` 及矩阵 `A` 对应的特征向量 `e`[1]、`e`[2]。若 `e`[1] = `ke`[2]，则 `Ae`[1] = `Ake`[2] ⇒ `λ[1] e`[1] = `λ[2] ke`[2] ⇒ `λ[1]` = `λ[2]`，这导致矛盾。因此，对应于不同特征值的特征向量总是线性无关的。

# [特征性质](#toc.xhtml#s85a)

让我们讨论几个重要的特征性质：

*   对应于不同特征值的特征向量线性无关。
*   矩阵的迹等于其所有特征值之和。
*   矩阵的行列式等于其所有特征值之积。
*   `A^k` 的特征值（其中 `k` 为正整数）为 `λ[i]^k`，其中 `λ[i]` 为 `A` 的特征值。
*   若 `A` 可逆，则 `A^(-1)` 的特征值为 1⁄`λ[i]`，其中 `λ[i]` 为 `A` 的特征值。
