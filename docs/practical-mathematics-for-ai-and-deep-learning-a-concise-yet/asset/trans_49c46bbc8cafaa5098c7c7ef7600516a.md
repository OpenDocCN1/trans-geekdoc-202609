# 向量微积分

**向量微积分** 是向量场和标量场的研究。标量场是一种映射，它向向量空间中的每个点分配一个标量或实数。向量场向向量空间中的每个点分配一个新向量。向量微积分包括标量场和向量场的导数计算以及标量场上的积分。这些是定义优化理论和概率论中参数估计的基本工具，而这些是 ML/AI 的基础支柱。向量微积分理论是单变量函数微积分向多变量函数（标量场和向量场）的推广。

我们将首先介绍实分析的基础知识，即易于可视化的实值函数。我们将详细阐述可微性概念，因为它们是后面讨论的所有函数优化理论的基础。然后，我们将看到这些概念如何推广到多变量函数：标量场和向量场。

# 实函数分析

实分析是处理实数 ![](images/r.jpg) 以及实值函数和序列性质的数学领域。在本节中，我们将涵盖实分析的几个主题，特别是与 ML/AI 相关的实函数。我们将从实线定义开始。

*有理数* 是可以用任意两个整数的比精确表示的数 ![](images/569C3eqig1.jpg)。存在无法用这种形式表示的数，例如，不存在平方为 2 的有理数，即 √2 是*无理数*。所有有理数和无理数的集合称为*实数*集，记为 ![](images/r.jpg)。从几何上看，点的集合 ![](images/r.jpg) 可以用一条无始无终的线来表示。存在比你能想到的最小数还小的实数。也存在比我们能想到的最大数还大的实数。集合 ![](images/r.jpg) 是稠密的，即无论你能想到的两个实数 *a* 和 *b* 有多接近，都存在另一个实数 *c* 使得 *a* < *c* < *b*。整数集合不是稠密的，因为两个连续整数之间不存在整数。
