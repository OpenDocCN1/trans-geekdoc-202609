到目前为止，我们的讨论围绕着从解析和几何上求解三元线性方程。随着变量和方程数量的增加，使用上述任何方法求解都变得困难。此外，除非我们有一种能推广到超大量变量和方程的线性方程的方法，否则很难实现这些操作的自动化。人们需要一种线性方程的简洁表示来处理大量的方程和变量，这由*矩阵*提供。

## 引入矩阵

*矩阵* 是一个数字的矩形阵列，为其定义了加法和乘法等运算。矩阵中条目的水平线和垂直线分别称为行和列。矩阵的大小由其包含的*行*数和*列*数定义。一个具有 *m 行* 和 *n 列* 的矩阵称为 *m × n 矩阵*，或 *m-by-n 矩阵*，而 *m* 和 *n* 称为其维度。每个条目通过行号和列号索引为 *a*[xy]，其中 *x* 代表行号，*y* 代表列号。

![](images/13.jpg)

行数和列数相同的矩阵；*m = n* 称为*方阵*，表示为 *A*[m]。条目仅为实数的矩阵称为*实矩阵*。本书中的大多数矩阵运算将集中在实矩阵上。

## 增广矩阵

在用矩阵形式表示方程时，每个方程占据矩阵的一行。方程中变量的系数表示在行的左侧，随后是一条垂直线，然后方程的右侧（RHS），即一个实数，在垂直线后指定。类似地，表示所有方程，矩阵的每一行代表一个方程。这种表示线性方程组的矩阵形式称为*增广矩阵*。包含方程 *e*[1]：`1b + 1p + 1m = 1500`，*e*[2]：`3b + 4p + 2m = 4400` 和 *e*[3]：`5b + 3p + 5m = 6500` 的示例的增广矩阵表示为：
