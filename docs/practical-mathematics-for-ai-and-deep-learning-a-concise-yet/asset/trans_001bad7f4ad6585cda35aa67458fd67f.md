
# 确保判别器中的 Lipschitz 约束

深度神经网络对其输入非常敏感。例如，精心挑选的输入图像的微小扰动可能会误导神经网络，并显著降低其分类准确性。评估神经网络对微小扰动鲁棒性的一个指标是 Lipschitz 常数 *K*，它给出了输入扰动与输出变化之间关系的上界。在 WGAN 中，使用以下两种方法来确保 Lipschitz 条件：

1.  **权重裁剪**：在每次梯度更新后，将权限钳制在一个固定的区间内，例如 `[-0.01, 0.01]`。这可以确保 Lipschitz 条件。然而，训练需要更多的迭代次数和时间。这是因为权重裁剪显著限制了网络的容量。这可以按如下方式实现：

```
1. for p in D.trainable_variables:
2.     p.assign(tf.clip_by_value(p, -0.01, +0.01))
```

2.  **梯度惩罚**：确保梯度的范数至多为 1。这可以通过向 WGAN 目标函数添加一个误差项来实现，该误差项强制梯度范数接近于 1：`||∇D(x̂)||₂ ≈ 1`，其中 `x̂` 是真实样本和生成样本之间的某个点：`x̂ = εx + (1-ε)x̃`，其中 `ε ~ U[0,1]` 和 `x̃ ~ p_g`，两者独立随机选取。这在以下代码的第 4 行中展示。或者，我们可以向真实数据点添加少量噪声并创建扰动输入 `x̃ = x + ε`，其中 `ε ~ N(0, σ²)`，然后按前述方式实现梯度惩罚：`||∇D(x̃)||₂ ≈ 1`。

```
1. D = discriminator()
2. def gradient_penalty(real_output, fake_output):
3.     epsilon = tf.random.uniform([real_output.shape[0], 1, 1, 1], 0.0, 1.0)
4.     x_hat = epsilon * real_output + (1 - epsilon) * fake_output
5.     with tf.GradientTape() as tape:
6.         tape.watch(x_hat)
7.         d_hat = D(x_hat)
8.     gradients = tape.gradient(d_hat, x_hat)
9.     gradnorm_sqr_reg = tf.reduce_mean((tf.norm(gradients) - 1.0) ** 2)
10.    return gradnorm_sqr_reg
```

GP 损失项被添加到判别器损失中，以在判别器中强制执行 Lipschitz 条件。

# 条件 GAN (cGAN)

我们可以通过将辅助信息 *y* 作为额外输入同时送入判别器和生成器，来实现生成器/判别器的条件控制。这里，*y* 通常以某些分类数据的形式出现；因此，一个自然的选择是使用嵌入层对 *y* 进行编码，然后将编码后的标签送入判别器和生成器。例如，考虑文本生成图像，其中 *y* 是文本。我们可以使用嵌入层对文本表示进行编码。然而，如果类别数量很少，我们可以避免使用嵌入层。

现在，判别器 *D* 将判断的不再仅仅是 *X*，而是来自联合分布 (*X*, *Y*) 的一个点 (*x*, *y*)。此外，相应的生成器 *G* 对条件联合概率分布 `p(x|y)` 进行建模，其中 *z* 是给定的噪声向量。给定噪声向量 *z*，我们应该有 `G(z) = (X, Y)`。生成器一个更有趣且实用的表述是：我们将辅助信息 *y* 作为指导输入生成器 *G*，指明生成什么，然后生成器以噪声向量 *z* 作为输入，输出在辅助信息条件下的数据点 *X*。例如，在人脸生成中，如果 *Y* 代表一个布尔变量性别，那么设置 *y*=0 生成器将生成一张女性人脸图像。这里，生成器对 `p(x|y)` 进行建模。请参考下图：

形式上，我们可以按如下方式定义条件判别器和条件生成器：

我们有一个生成器函数 `G(z, y)`，它接收噪声数据 *z* 和标签嵌入 *y* 并输出一个数据点 *x*。此外，我们有一个判别器函数，它接收一个数据点 *x* 和一个噪声嵌入 *y* 并输出一个概率分数，表示该对 (*x*, *y*) 是否来自真实分布 `p(X,Y)`。这里，我们的数据分布可以表示为联合概率分布 `p(X,Y)`。生成器旨在对条件分布 `p(x|y)` 进行建模，其中辅助数据 *y* 服从分布 `p(y)`。因此，要从联合分布 (*x*, *y*) 中产生一个点，我们可以先从 `p(y)` 中采样 *y*，然后使用生成器模型从 `p(x|y)` 生成 *x*，即我们有 `x ~ p(x|y)`。生成器模型也以噪声 *z* 为条件，因此生成器实际上估计的是 `p(x|y,z)`。然而，由于 *Y* 和 *Z* 相互独立，`p(y,z) = p(y)p(z)`。所以，我们有：

`p(x,y) = p(x|y)p(y)`

因此，我们可以按如下方式修改我们的极大极小损失函数：

`min_G max_D V(D,G) = E_{x,y~p_data}[log D(x,y)] + E_{z~p(z), y~p(y)}[log(1 - D(G(z,y), y))]`

在训练时，我们需要从生成器采样图像来评估两个玩家 *G* 和 *D*。这需要像普通 GAN 一样从噪声分布采样，同时也需要从辅助数据分布 `p(y)` 中采样。

如果我们直接从训练样本中抽取 *y* 的样本，生成器可能会达到一个虚假的最优解，即在给定条件输入的情况下精确复现训练数据。这样我们就得不到任何新的数据点，生成器就变成了训练数据的数据库，从给定数据集中复现每一个训练样本。为了避免这种情况，我们可以使用任何经典的密度估计技术（如 Parzen 窗估计）训练一个数据分布模型，利用从训练数据中抽取的条件值 `y_i` 来从中抽取 *y*。以下是针对 CelebA 数据集的条件判别器实现。CelebA 为每张人脸图像附带了 40 个二值属性列表。这些属性包括性别。我们可以将其提取为类别标签，从而得到一个二分类标签作为辅助信息。以下是条件 GAN 的判别器代码：

```
1. def discriminator():
2.     img = layers.Input(shape=[64,64,3])
3.     label = layers.Input(shape=[2,]) #for two classes
4.     y = layers.Dense(64*64)(label)
```
