# 自然语言

*自然*语言是人类经过漫长岁月发展和演变出来、用于相互交流的语言。自然语言具有层级结构。语言学是一门理解语言中这些结构的科学分支。口语可以分解为一小组声音或声学模式，称为 `phones`。例如，英语单词 ‘cup’ 可以分解为音素 `/k/`、`/uh/`、`/p/`。语音原子单位的这种表示称为 `phonemes`。在自然语言的书面形式中，原子单位是 `characters`（字符）或字母。`Grapheme`（字素）是代表单个音素的一个字母或一组字母。音素进而构成 `morphemes`（语素），即最小的有意义词段。`Words`（单词）由一个或多个 `morphemes` 组成。单词组合形成表达完整思想的群体，称为 `phrases`（短语），如名词短语、动词短语、形容词短语和介词短语，它们是 `sentences`（句子）的结构成分，句子表达完整的思想。在更高层级上，我们有各种类型的篇章结构，如段落和章节。自然语言中的结构大致可分为两类：(1) 句法结构和 (2) 语义结构，我们将在后续章节中详细讨论。研究这些语言学结构的目的是将其应用于从文本数据中提取特征。在本章中，我们将讨论英语的句法和语义，但这些概念大多也可以推广到其他语言。

# 语言的句法结构

我们统称为语言 `grammar`（语法）的某些规则，充当了单词如何组合成短语、短语如何组合成分句、分句如何组合成句子的指导准则。

# 词性

任何语言的单词数量都是巨大的。要定义任何语法，我们首先需要将单词归类为一小组类别，然后针对类别定义规则，而非针对单个单词。我们可以根据英语单词的句法功能将其归类为九大基本类型。它们被称为**词性**：名词、代词、形容词、限定词、动词、副词、介词、连词和感叹词。

# 短语

短语是构成句子/分句中有意义片段的一个或多个单词。主要有五种类型的短语：名词短语、动词短语、形容词短语、介词短语和副词短语。在每种短语中，都会在核心词类型周围添加少量单词。NP：单个名词或围绕单个名词构建的一组单词。例如：‘The President of India’ 是一个 NP。VP：单个动词或围绕单个动词构建的一组单词。例如，I *will be going* to France next week.

# 分句

分句是一组具有某种关系的单词，通常包含一个主语（名词）和一个谓语（动词及其宾语）。主语不一定总出现在分句中。主要有两类分句：主句和从句。主句也称为独立分句，因为它本身可以构成一个句子。从句或依赖分句则依赖主句来表达其含义。

# 句子

句子是由一个或多个单词组成的语法单位，用于表达独立的陈述、疑问、请求、命令、感叹等，且通常包含主语和谓语。句子通常以大写字母开头，并根据其类型以适当的标点符号结尾。请参阅下图：

# 文档与文本语料库

以书面、印刷或数字化文本文件形式存在的句子集合称为文本 `document`（文档）。文档的集合称为文本 `corpus`（语料库）。它通常由书面文本主体组成，常以数字化形式存储。随着时间的推移，针对各种 NLP 任务构建了许多大型文本语料库。

# 语言的语义结构

研究语言意义的学科称为语义学。含义相近的单词可以在数据库中链接在一起，这对于理解语言意义非常有用。在英语等语言中，两个意义相同的单词可能因时态、数等不同而拼写不同。在法语等语言中，指代不同性别的形容词也会使用不同的拼写。语言中最小的有意义且句法正确的单位称为 `lemma`（词元/引导词）或 `lexeme`（词汇项）。

单词的含义可能因其在句子中的位置和上下文而改变。存在拼写或发音相同但含义不同的单词，称为 `homonyms`（同音异义词/同形异义词）。例如，在 ‘a cricket bat’（板球球拍）和 ‘a bat which is seen at night’（夜间可见的蝙蝠）这两个短语中，单词 ‘bat’ 含义不同。这类词之间的关系称为 `homonymy`（同音异义/同形异义现象）。`Capitonyms`（大小写异义词）是拼写相同但首字母大写时含义不同的单词。例如，五月 和短语 ‘may be’（可能）。`Synonyms`（同义词）是拼写不同但含义相同的单词。`Polysemes`（多义词）类似于同音异义。如果一个词可用于表达不同含义，则它是多义的。这两个概念的区别非常微妙。如果你听到（或读到）两个发音（或书写）相同但含义不完全相同的词，我们必须判断它到底是两个不同的词（同音异义词），还是一个词在两种不同方式下的使用（多义词）。多义词的例子是 “Good man” 与 “Good artist”。前者中 “good” 描述道德品质，后者描述技能水平。

# WordNet

WordNet 是一个词汇数据库，包含如前所述的单词间语义关系，涵盖 200 多种语言，将同义词归类为同义词集，并附带简短定义和用法示例。其主要用途在于自动文本分析和人工智能应用。
