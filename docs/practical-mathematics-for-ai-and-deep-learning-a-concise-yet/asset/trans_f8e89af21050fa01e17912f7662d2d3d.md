
由于海森矩阵 `H` 是实对称矩阵，二次型 `Q(x) = x^T H x` 当且仅当其所有特征值均为正时为正定，当所有特征值均为负时为负定。

假设 `H` 的所有特征值均为正且 `λ_min > 0`。我们选择 `x ≠ 0`，则 `Q(x) = x^T H x > 0`。显然，`λ_i > 0` 是 `H` 的特征值。二次型如下：

`Q(x) = Σ λ_i y_i^2`

现在，`lim_{x→a} f(x) = L`，根据极限的定义，对于任意给定的正数 `ε`，存在一个 `δ` 使得 `|f(x) - L| < ε`。将该不等式两边同时乘以 `||x - a||^2`，得到 `|f(x) - L| ||x - a||^2 < ε ||x - a||^2`。选取任意数 `M = ε`，则有 `|f(x) - L| ||x - a||^2 < M ||x - a||^2`。

`f(x) - f(a) = ∇f(a)^T (x - a) + o(||x - a||)`

因此，`a` 是相对极小值点。类似地，我们可以证明定理中关于极大值和鞍点的陈述。

**示例**：寻找并分类曲面 `z = x^2 - y^2` 的驻点

我们有 `∂z/∂x = 2x` 和 `∂z/∂y = -2y`。在驻点处，两个偏导数均应为零。显然，原点 `(0, 0)` 是一个驻点。

现在，`∂²z/∂x² = 2` 且 `∂²z/∂y² = -2`。这与 `∂²z/∂x∂y = 0` 矛盾。因此 (0, 0) 是唯一的驻点。

`H = [[2, 0], [0, -2]]`

现在，让我们讨论一种可用于最小化任意可微函数的迭代算法。

# 下降法

在实践中，我们会遇到多元函数，但不知道函数在其定义域的何处取得最优值。事实上，我们可能永远无法找到精确的最小值 `x*`。我们的目标是尽可能接近最小值 `x*`。因此，我们必须从某个任意点 `x_0` 开始，然后沿着函数值下降的方向迈出小步 `α_k`：

`x_{k+1} = x_k + α_k d_k`

此处，`α_k` 是搜索方向 `d_k` 上的**步长**。我们的目标是选择 `d_k` 和 `α_k` 使得 `f(x_{k+1}) < f(x_k)`。这些点序列 `x_k` （应收敛于最小值 `x*`）。

利用一阶泰勒级数展开，设 `f(x)` 和 `x` 为一个非常接近 `a` 的点，即 `x = a + v`。令 `v = x - a`：

`f(x) ≈ f(a) + ∇f(a)^T v`，其中 `v = x - a`

此处，`∇f(a)^T v` 表示变化向量 `v` 方向上的方向导数。如果该项为负，我们就可以降低 `x` 处 `f` 的值。因此，`v` 必须与负梯度 `-∇f(a)` 成锐角。我们称这样的方向为*下降方向*。最理想的情况是向量 `v` 和 `-∇f(a)` 之间的夹角为零，即向量平行，也就是说，如果对于某个 `α > 0` 有 `v = -α ∇f(a)`。这称为*最速下降方向*。某点处负梯度的方向即为最速下降方向。

因此，我们可以按如下方式定义一个用于最小化函数的迭代算法：

*   给定一个起始点 `x_0`
*   重复：
    *   `d_k = -∇f(x_k)`
    *   选择步长 `α_k`
    *   更新 `x_{k+1} = x_k + α_k d_k`

前述迭代算法的停止准则通常基于梯度的范数。由于我们是迭代地寻找驻点，当点 `x_k` 处的梯度接近 0 时，算法即可收敛，即 `||∇f(x_k)|| < ε`，其中 `ε` 很小。`ε` 是一个预定义的固定数字，表示可接受的误差水平。该算法称为*梯度下降算法*。现在，我们还需要一种选择步长的方法。步长不应过短或过长。以下示例展示了步长的影响。

**示例**：以实值函数 `f(x) = x^2` 为例。作为实数线上的函数，我们只有两个可能的方向 `±1`；我们可以选择下降方向为 `d = -sign(x)`。注意，该下降方向也平行于负梯度方向，因为 `∇f(x) = 2x`。我们将使用两种不同的步长：(1) `α_k = 2 + 3/2^{k+1}`，这是一个较大的步长；(2) `α_k = 1/2^{k+1}`，这是一个单调递减的较小步长。现在，从初始点 `x_0 = 2` 开始，遵循前述更新公式 `x_{k+1} = x_k + α_k d_k`，我们发现对于 (1)，函数值最终在 -1 和 1 之间振荡；而对于步长 (2)，函数值的减小变得非常小，几乎在 1 处收敛。以下代码展示了这一点的实现：

```python
def step(k, type=1):
    if type == 1:
        return 2 + 3 / np.math.pow(2, k + 1)
    elif type == 2:
        return 1 / np.math.pow(2, k + 1)
    else:
        return 1

def update(x, k, type=1):
    return x + np.sign(-x) * step(k, type)

x = 2
for k in range(20):
    x = update(x, k, type=1)
    print(k, x, x**2)
    k = k + 1
```

寻找合适步长的一种方法是*精确线搜索*，即沿直线 `x_{k+1} = x_k + α d_k` 最小化函数，也就是：

`min_{α > 0} f(x_k + α d_k)`

这是一种有效的方法，但不具成本效益。因此，通常使用不精确线搜索方法，我们寻找一个能使 `f` 充分减小的步长。其中一种方法称为*回溯线搜索*。这取决于两个参数 `α, β ∈ (0, 1)`。给定一个下降方向 `d_k`，我们从单位步长开始，然后按因子 `β` 减小步长，直到满足某个停止准则。一阶泰勒公式可以给我们一个停止准则。根据一阶泰勒近似，`f(x_k + α d_k) ≈ f(x_k) + α ∇f(x_k)^T d_k`。

`f(x_k + α d_k) ≤ f(x_k) + c α ∇f(x_k)^T d_k`

因此，在后续步骤中，我们按常数因子 `β` 减小步长（这限制了步长过小），并且我们看到 `f` 至少减小了由一阶泰勒公式预测的减小量的固定分数 `c`。这也限制了步长过大。该条件称为**Armijo 条件**。

梯度下降中还有一些其他启发式方法用于步长选择。

**固定步长**：选择一个固定值 `α`。

**可变步长**：每次迭代中选择 3 或 4 个步长值，选择能使函数值下降最多的那个。

*   **黄金分割搜索**：使用两个值之间的范围并将其分成若干区间。

*   **示例**：（**Rosenbrock 函数**）：`f(x, y) = (1 - x)^2 + 100(y - x^2)^2`。该函数在点 `(1, 1)` 处有一个全局最小值，此时 `f(1, 1) = 0`。全局最小值位于一个细长的、抛物线形状的平坦山谷内部，如 `a = 10` 时的*图 3.19* 所示。该函数的梯度由下式给出：

`∇f(x, y) = [-2(1 - x) - 400x(y - x^2), 200(y - x^2)]^T`

*   可从任意起始点收敛到局部最小值
*   收敛有时可能非常缓慢
