该系数代表直线的斜率，即预测变量值每变化一个单位，目标变量 `y` 变化的因子。

> **注意：** 这种作为斜率的解释也可以推广到多个预测变量。对于多个预测变量，我们可以将权重视为一个因子，即在保持所有其他预测变量不变的情况下，目标变量随预测变量每变化一个单位而变化的因子。这种对系数的解释有助于我们理解哪些预测变量影响目标变量以及如何影响。然而，这种关系不应被视为因果关系，因为它指示的是相关性，而相关性不意味着因果性。

这些系数是随机估计值；它们有可能不准确并可能误导我们。为了防范此类风险，我们可以采用假设检验（或系数显著性检验）。我们检验假设，查看系数 `β = 0` 是否成立。形式上，我们用原假设和备择假设来表示如下：

`H₀: β = 0`

对立的备择假设为

`H₁: β ≠ 0` 或 `H₁: β > 0` 或 `H₁: β < 0`

由于 `β̂` 服从正态分布，若 `H₀` 为真，则 `β̂` 服从均值为 0 的正态分布，因此，`t = (β̂ - 0) / se(β̂)` 服从自由度为 `n - 2` 的 t 分布，该自由度与 `β̂` 的样本方差 `se(β̂)²` 相关，即之前计算的 `se(β̂)`。

遵循假设检验的标准步骤，我们首先选择显著性水平 `α`，并执行双尾 t 检验以检验原假设对立 `H₁`。双尾备择假设下 Student t 分布的临界值在分布的每一尾放置概率 `α/2`。落入拒绝域的概率称为 *p值*。*较小的 p值 `p < α` 表明，我们无法拒绝原假设，因此系数 `β = 0` 不显著。* 我们也可以计算系数的置信区间。这更具信息量，因为它们反映了估计的精度。针对备择假设 `H₁: β ≠ 0` 进行检验，`β₀` 和 `β₁` 的 95% 置信区间分别由以下公式给出：`β₀ ± t_{α/2, n-2} * se(β₀)` 和 `β₁ ± t_{α/2, n-2} * se(β₁)`。

我们可以使用 Python statsmodels 库来计算这些置信区间并检验每个系数的显著性，如下面的代码所示。这里我们使用了花瓣宽度与花瓣长度的关系，如 *[图 5.9](#c05.xhtml#fig5_9) (左)* 所示。

```
1. import statsmodels.formula.api as smf
2. model = smf.ols(formula="petal_length ~ petal_width", data=df)
3. results = model.fit()
4. print(results.summary())
```

在 *[图 5.10](#c05.xhtml#fig5_10)* 的结果中，我们看到了称为 `R²` 和 F 统计量的评分。这些有助于我们评估模型拟合的整体优度。让我们看看它们的含义。可以很容易地证明（参见 *延伸阅读 [6]*）：

`SST = SSR + SSE`

总**平方和**（**SST**）= **回归平方和**（**SSR**）+ **误差平方和**（**SSE**）。在该证明中，我们使用了线性回归的误差正态性假设，即误差项的均值 `E[ε] = 0`。这里，SST 是目标变量的总方差，与模型无关。其中一部分方差由模型解释（SSR），另一部分未被模型解释，即平方误差（SSE）。将等式两边同时除以 *SST*，得 `1 = SSR/SST + SSE/SST`。我们定义 `R² = SSR/SST` 为 *决定系数*，它表示模型解释的总方差比例。显然，`0 ≤ R² ≤ 1`。`R²` 值越大表示模型拟合越好。

> **注意：** 该等式 `SST = SSR + SSE` 对于多个预测变量也完全成立。但随着我们向模型中添加更多预测变量，我们会看到 `R²` 值单调增加。这并不总是意味着增加预测变量就能获得更好的拟合，因为并非每个预测变量都会影响目标变量。因此，随着预测变量数量的增加，我们使用调整后的 `R²`。

调整后的 `R²` 告诉你仅由真正影响**因变量**的**自变量**所解释的*变异百分比*。

系数的显著性也可以用于线性模型的其他变体，如逻辑回归。

> **提示：** 对于逻辑回归模型，此 `R²` 统计量没有意义，因为它基于解释方差的比率。McFadden 伪 R 平方定义为 `R²_pseudo = 1 - (ln L / ln L_null)`。此处，`L` 表示最大化似然值，`L_null` 表示仅含截距的模型。直观上，我们可以这样理解这一度量。如果模型没有预测能力，模型的似然值不会比零模型的似然值大多少。因此，两个对数似然值的比率将接近 1，且 `R²_pseudo` 将接近零。

# [要点回顾](#toc.xhtml#s213a)

*   统计量 `T` 是来自总体的样本的函数，通常用于根据样本值估计总体参数 `θ`。我们可以将预测模型视为一种统计量和真实总体行为的估计器。训练数据可以视为用于估计真实总体行为的样本。
*   **偏差-方差分解**：统计量 `T` 估计参数 `θ` 的**均方误差**（**MSE**）可以分解为：`MSE(T) = Var(T) + [Bias(T)]²`
*   **偏差-方差权衡**：高偏差模型表明我们的模型过于简化且欠拟合，因此这些模型的预测具有高方差。同样，低偏差意味着过拟合，且该模型的预测将具有低方差。
*   如果某统计量存在 MVU，则 MLE 过程将给出该估计量。
*   MLE 估计量具有相合性和有效性，但不一定无偏。
*   MLE 估计量容易过拟合，这可以通过带有 MAP 的贝叶斯估计或正则化技术来缓解。
*   此处讨论的线性模型不应仅被视为直线或平面。请记住，线性是指线性系数，通过使用非线性基函数（如多项式或径向基函数），我们可以表示非常复杂的多变量非线性函数（*固定基函数模型*）。
