

# 正交化

**正交化** 是寻找一组张成子空间的正交向量的过程。考虑一个线性无关向量集 `{v[1], v[2], …, v[k]}`，它张成 `R^n` 中内积空间的一个子空间，其中 `k ≤ n`。正交化是获得正交向量集 `{w[1], w[2], …, w[k]}` 的过程，该向量集张成的子空间与 `{v[1], v[2], …, v[k]}` 相同。对导出的正交集进一步处理可获得标准正交向量集 `{u[1], u[2], …, u[k]}`，其中所有向量的长度/范数均为 1，且张成的子空间与 `{v[1], v[2], …, v[k]}` 相同。为给定子空间获取标准正交集的过程称为 **标准正交化**。**Gram-Schmidt（格拉姆-施密特）** 过程是标准正交化技术之一，它通过内积空间中的投影导出标准正交向量。

# 标准正交化的应用

用正交向量来表示一个向量具有优势：沿任一正交向量对向量的改变不会影响其他正交向量。从系统角度来看，可以将这些正交向量视为旋钮，调节这些旋钮相当于改变系统的独立因素。

以电视机为例，它有控制亮度、对比度、长度和帧宽度的旋钮。调节这些旋钮只会改变帧的一个属性，而不影响其他属性。如果存在一个旋钮，能同时以微小百分比改变亮度、对比度、长度和宽度，你会习惯用这个旋钮来达到理想的帧质量吗？毫无疑问不会。

同样的概念可应用于机器学习算法的调优过程。算法的可调参数必须表现出正交性；否则，分析单个参数的行为将变得困难。

标准正交化是将矩阵表示为包含标准正交矩阵的矩阵乘积的重要步骤，这将在本章后续章节中讨论。接下来，让我们讨论将向量从一个子空间变换到另一个子空间。

# 线性变换

**线性变换**，也称为 **线性映射**，是将向量从线性向量子空间 `V ⊆ R^n` 映射到线性向量子空间 `W ⊆ R^m`，两者均在同一标量域 `R` 上，记作 `T : V → W`。此外，它必须保持向量加法和标量乘法运算。正式地说，若 `∀ u, v ∈ V` 和 `标量 s ∈ R` 满足以下两个条件，则映射 `T : V → W` 是线性的：

*   `T(u + v) = T(u) + T(v)` 保持加法运算
*   `T(su) = sT(u)` 保持标量乘法

换句话说，无论线性映射是在加法和标量乘法运算之前还是之后应用，结果都一样。

**示例**：一元函数的导数算子 `d/dx` 和积分算子 `∫ dx` 是线性变换，因为两者都保持加法和标量乘法：
