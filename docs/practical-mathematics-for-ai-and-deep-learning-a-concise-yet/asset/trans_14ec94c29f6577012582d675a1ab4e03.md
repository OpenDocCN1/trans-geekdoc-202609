
增广矩阵的第一列代表变量 `b` 的系数，因此矩阵的第一行给出了 `bowling alley` (`b`) 的值为 ₹400。同样，从第二行和第三行可知，`play station` (`p`) 的值为 ₹500，`movie ticket` (`m`) 的值为 ₹600。这一在矩阵上使用行运算获得行阶梯形，并进一步将其化简为简化行阶梯形的过程称为 **Gauss-Jordan Elimination method**（高斯-约当消元法）。

## Pseudocode forward substitution

考虑矩阵 `A[mxn]`，其第 `i` 行第 `j` 列的元素通过 `A[i, j]` 访问。以下代码提供了前向代入的伪代码。此阶段将产生一个上三角矩阵。

```
1. for row_idx = 1 to m do
2.   pivot_row = select_pivot_from_ref(row_idx)
3.   swap_rows(pivot_row, row_idx)
4.   normalize_row(row_idx)
5.   for tr_row = row_idx + 1 to m do
6.     for tr_col = row_idx to n do
7.       A[tr_row, tr_col] = A[tr_row, tr_col] - A[row_idx, tr_col] * A[tr_row, row_idx]
8.     end for
9.   end for
10. end for
```

## Pseudocode back substitution

对上三角矩阵应用回代以获得对角矩阵。以下代码提供了回代的步骤：

```
1. for row_idx = m to 1 do
2.   normalize_row(row_idx)
3.   for tr_row = row_idx - 1 to 1 do
4.     for tr_col = row_idx to n do
5.       A[tr_row, tr_col] = A[tr_row, tr_col] - A[row_idx, tr_col] * A[tr_row, row_idx]
6.     end for
7.   end for
8. end for
```

我们现在有了一个算法，可以使用一系列矩阵运算来求解包含大量变量的任何线性方程组。类似于实数上的加、减、乘、求逆运算，可以在整个矩阵上定义运算，因为矩阵可以被视为抽象的数值对象。

矩阵使我们能够求解含有 `n` 个未知数的线性方程组。无法在 `n` 维空间中直观展示这些方程组的解空间。三个未知变量的问题分析相对简单，因为它将我们限制在三维空间中。我们需要将三维空间的概念推广到 `n` 维空间，其中 `n` 为正整数。要在三维空间中表示一个点，需要三个值，分别表示在各维度轴上的坐标。类似地，要在 `n` 维空间 `R^n` 中表示一个点 `p`，需要一个有序 `n` 元组 `(x[1], x[2], …, x[n])`，其中 `x[i] ∈ R`，每个 `x[i]` 对应某一维度上的值。所有这些有序 `n` 元组的集合构成 **Euclidean n-space**（欧几里得 n 空间）。该集合的每个元素都由称为 **vectors**（向量）的有序 `n` 元组表示。

## Euclidean space

欧几里得空间由希腊数学家欧几里得引入，用于抽象我们周围的物理空间。`n` 维欧几里得空间中的线性方程表示一个超平面——即将三维中的平面推广到 `n` 维。这些方程的解是 `n` 维空间中的点或向量。本节将介绍 `n` 维欧几里得空间中 `n` 维向量的长度、距离、旋转、平移、角度等概念。

## Vectors and basic properties

**Vector**（向量）一词源自拉丁语，意为“载体”。向量最初在几何中引入，用于同时表示大小和方向。定义了这些向量相互作用的规则，这些规则大多源于对宇宙的理解。

## Representing vector

向量连接两个点，它表示空间中的大小和方向，记作顶部有箭头的小字母（如 `v⃗`）或加粗的小字母（如 `υ`）。空间中的向量表示为从起点指向终点的有向线段。如果起点是 **0**（原点），则该向量称为 **positional vector**（位置向量）。`R^n` 中的任意点 `P(x[1], x[2], …, x[n])` 都由一个终止于 `P` 的位置向量表示。
