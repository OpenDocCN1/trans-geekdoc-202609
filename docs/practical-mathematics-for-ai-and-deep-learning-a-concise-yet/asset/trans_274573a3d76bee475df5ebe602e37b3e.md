## 利用主成分进行降维

我们可以使用所有四个特征向量对原始数据进行线性变换。然而，变换后的向量仍将处于四维空间。相反，我们可以选择捕获原始数据前两个最大变化的前两个特征向量。由前两个特征向量组成的变换矩阵，也称为*主成分*，如下所示：

![](images/2245.jpg)

我们可以对原始数据应用变换，以获得二维的变换数据，如 *代码 8.4* 所示（接续 *代码 8.3*）：

```
1. # 选择两个主成分
2. eigen_vect0 = eigen_vect[:, 0]
3. eigen_vect1 = eigen_vect[:, 1]
4. trans_mat = np.array([eigen_vect0, eigen_vect1]).T
5. # 变换数据点
6. x_reduced = np.matmul(x, trans_mat)
```

## 方差保留

我们可以通过选择数据协方差矩阵的少数主成分，并使用选定的标准正交基对原始数据进行线性变换，来降低数据的维度。关于选择多少个主成分的问题肯定会出现在你的脑海中。每个主成分都保留了原始数据的一定方差。如果使用所有成分，则保留原始数据的所有方差。我们可以计算方差保留的百分比。基于这个方差保留百分比，我们可以决定主成分的数量。

协方差矩阵的迹或对角线元素之和等于其特征值之和。单个特征向量的保留百分比可以通过以下公式计算：

要计算多个特征向量的保留百分比，必须加上其对应的特征值，如下所示：

![](images/2247.jpg)

在鸢尾花数据集上，第一主成分将保留 92.5% 的总方差。前两个主成分将保留 97.7% 的总方差。加上第三主成分将达到 99.5%。对于鸢尾花数据集，我们可以放心地将维度从四维降至三维，同时保留原始数据 99.5% 的方差。

## 何时使用 PCA

AI 算法假设特征是相互独立的。如果我们希望使特征独立，那么 PCA 将是正确的选择。通过 PCA，如果少数主成分能够保留我们所需的方差，我们还能降低数据的维度，当然这取决于数据本身。

在原始数据中，每个维度代表一个特征。这些特征传达了关于所考虑样本的含义。然而，当通过 PCA 降维后，降维后数据的维度/特征可能无法用于理解样本。如果你想保留每个维度的含义，请勿使用 PCA 进行降维。

## 自编码器

*自编码器* 是一种非线性无监督降维技术，它利用神经网络学习原始数据的紧凑表示。简单的自编码器模型如 *[图 8.4](#c08.xhtml#fig8_4)* 所示。输入层和输出层的维度始终相同。自编码器模型的目标是在数据通过隐藏层（维度在隐藏层中被降低）时，生成与相应输入向量完全相同的输出向量。在 *[图 8.4](#c08.xhtml#fig8_4)* 中，输入和输出维度为四，它们之间共有三个隐藏层。*编码层* 也称为 *瓶颈层*，是整个网络中维度最低的层。在本例中，我们将编码层的维度设为二。编码器模型在训练过程中将学习输入数据的紧凑表示，使其能够从编码数据中重建原始数据。编码器模型中通过编码层将输入数据表示为紧凑表示的部分称为 *编码器*。编码器模型中从编码数据创建原始输入数据的部分称为 *解码器*。请参考下图：

![](images/Image45351.jpg)

## 鸢尾花自编码器

让我们为鸢尾花数据集构建一个编码层为两维的自编码器。由于鸢尾花数据集包含四个特征，输入层和输出层的维度均为四。为保持简单，让我们只设置一个隐藏层，即编码层。*代码 8.5* 提供了创建 TensorFlow 自编码器模型的步骤：

```
1. from sklearn import datasets
2. from sklearn.model_selection import train_test_split
3. import tensorflow as tf
4. from tensorflow.keras import layers, losses
5. from tensorflow.keras.models import Model
6. from tensorflow.keras.initializers import RandomUniform
7.
8. class Autoencoder(Model):
9.     def __init__(self):
10.         super(Autoencoder, self).__init__()
11.         self.encoder = tf.keras.Sequential([
12.             layers.Dense(
13.                 units=2, activation='relu',
14.                 kernel_initializer=RandomUniform(minval=0., maxval=1.,
15.                     seed=10)),
16.         ])
17.         self.decoder = tf.keras.Sequential([
18.             layers.Dense(
19.                 units=4, activation='relu',
20.                 kernel_initializer=RandomUniform(minval=0., maxval=1.,
21.                     seed=10)),
22.         ])
23.     def call(self, x):
24.         encoded = self.encoder(x)
25.         decoded = self.decoder(encoded)
26.         return decoded
```
