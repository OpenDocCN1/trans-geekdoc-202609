# 高斯分布或正态分布

连续随机变量可以取无限多个值。然而，大多数自然发生的连续随机变量，如人的身高、血压、学生的考试分数、机器生产的物体的精确尺寸，在绘制频率分布图时，观察到都呈钟形分布，即如果我们绘制这些随机变量取值的样本，会得到 *[图 4.14](#c04.xhtml#fig4_14)* 中所示的“钟形”直方图：

![](images/figure-4.14.jpg)

**图 4.14：** *高斯分布*

如果我们取大量任意随机变量之和的分布，正态分布也会自然产生。设 X 在区间 [0, 1] 内服从均匀分布，且 Y = X[1] + X[2] + … + X[n]。然后，随着 n 的增加，*[图 4.15](#c04.xhtml#fig4_15)* 显示求和 Y 所取值的分布变得更接近钟形曲线。高斯分布的这一性质正式表述为*中心极限定理*。请参考下图：

![](images/figure-4.15.jpg)

**图 4.15：** ***(左)*** *均匀密度函数* ***(右)*** *均匀累积分布函数*

现在，让我们看看上图中钟形曲线的概率解释。*[图 4.14](#c04.xhtml#fig4_14)* 中的这条钟形曲线在 x = 75 处达到峰值。当我们向两个方向远离这个中心点时，找到随机变量某值的机会就会减小。因此，概率与 x 到中心点的距离成反比。事实上，当我们远离中心点时，观察到随机变量 X 的某值 x 的机会会*呈指数级*下降。让我们用 μ 表示中心点。任意值 x 到中心点 μ 的标准化距离为 ![](images/1037.jpg)，其中 σ > 0 是数据围绕中心点 μ 的离散程度或离散度的度量。

使用 Python 的 `scipy.stats` 库，我们可以计算许多连续分布函数的累积分布函数，如下面的代码片段所示：

```
1. from scipy.stats import norm
2. print("P(Z<0.36) = ", norm.cdf(0.36))
3. print("P(1.5<Z<3.2) = ", norm.cdf(3.2)-norm.cdf(1.5))
```
