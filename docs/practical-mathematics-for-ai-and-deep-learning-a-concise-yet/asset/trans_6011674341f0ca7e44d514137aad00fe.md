

# 联合分布变量的期望

我们可以将 $n$ 个联合分布的随机变量表示为一个随机向量。该随机变量 $X$ 是向量值的，并取欧几里得空间中的值。该随机向量的多元密度用 $f_X(x)$ 或简写为 $f(x)$ 表示，其中 $x$ 是欧几里得空间中的一个向量。

我们在前几节中已经定义了单个变量的数学期望。对于两个联合分布的随机变量 $X$ 和 $Y$，我们可以按如下方式定义函数 $g(X, Y)$ 的期望：

$$E[g(X, Y)] = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} g(x, y) f_{X,Y}(x, y) \, dx \, dy, \text{ 若 } X,Y \text{ 为连续型}$$

以及

$$E[g(X, Y)] = \sum_x \sum_y g(x, y) P(X=x, Y=y)$$

联合中心矩（$X$ 的 $r$ 阶中心矩和 $Y$ 的 $s$ 阶中心矩）记为 $\mu_{rs}$，定义如下：

$$\mu_{rs} = E[(X - \mu_X)^r (Y - \mu_Y)^s]$$

1.  若 $r=1, s=1$，我们称之为协方差，记为 $\text{COV}(X, Y)$。因此：
    $$\text{COV}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)]$$

2.  若 $r=2, s=0$，联合中心矩退化为 $X$ 的方差，即 $\mu_{20} = \text{Var}(X)$

3.  若 $r=0, s=2$，联合中心矩退化为 $Y$ 的方差，即 $\mu_{02} = \text{Var}(Y)$

$\text{COV}(X,Y)$ 可以等价地写为 $\text{COV}(X,Y) = E[XY] - E[X]E[Y]$。其证明很简单。
$\text{COV}(X,Y) = E[(XY - XE[Y] - YE[X] + E[X]E[Y])] = E[XY] - E(X)E[Y] - E[Y]E[X] + E[X]E[Y] = E[XY] - E[X]E[Y]$。

**示例**：让我们考虑两个具有联合密度函数的随机变量 $X$ 和 $Y$：

$$f_{X,Y}(x,y) = \frac{1}{2\pi\sqrt{1-\rho^2}} \exp\left(-\frac{1}{2(1-\rho^2)}\left[x^2 - 2\rho xy + y^2\right]\right)$$

该密度绘制在[图 4.18](#c04.xhtml#fig4_18)中，其中每条线代表平行于直线 $y = x$ 的等密度轮廓线。较浅的阴影代表高密度区域。随着远离原点，密度沿平行于直线 $y = -x$ 的方向降低。（然而，线条之间的空白区域并**不**代表高密度区域。那里的密度也沿着线条方向变化。）请参考下图：

![图 4.18](images/figure-4.18.jpg)

现在让我们计算边缘概率密度函数：

$$f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x,y) \, dy = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$$
$$f_Y(y) = \int_{-\infty}^{\infty} f_{X,Y}(x,y) \, dx = \frac{1}{\sqrt{2\pi}} e^{-y^2/2}$$

我们也可以计算条件分布 $f_{Y|X}(y|x)$ 和 $f_{X|Y}(x|y)$：

$$f_{Y|X}(y|x) = \frac{f_{X,Y}(x,y)}{f_X(x)}$$

已知边缘分布，我们也可以计算各个变量的期望：

$$E[X] = \int_{-\infty}^{\infty} x f_X(x) \, dx = 0$$

同理，$E[Y] = 0$。现在，我们可以按如下方式计算这两个变量的方差：

$$\text{Var}(X) = E[X^2] - (E[X])^2 = 1$$

要计算这两个变量的协方差，我们需要 $E[XY]$：

$$E[XY] = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} xy f_{X,Y}(x,y) \, dx \, dy = \rho$$

因此，我们现在可以使用以下公式计算协方差：

$$\text{Cov}(X,Y) = E[XY] - E[X]E[Y] = \rho$$

**定理**：两个独立随机变量是不相关的。$X, Y$ 独立意味着 $f_{X,Y}(x,y) = f_X(x)f_Y(y)$。然而，逆命题不成立，即两个不相关的变量不一定独立。

示例：$X \in \{-4, -3, -1, 1, 3, 4\}$，$Y = X^2$。此处 $P(X=x) = 1/6$。

然而，$E[XY] = \frac{1}{6} \times [-4 \times 16 - 3 \times 9 - 1 \times 1 + 1 \times 1 + 3 \times 9 + 4 \times 16] = 0$ 且 $E[X] = 0$。

因此，$\text{COV}(X,Y) = 0$，进而 $\rho_{XY} = 0$，但 $X$、$Y$ 不独立，因为 $Y = X^2$。

# 随机变量的变换

设 $X$ 为随机变量，$g(.)$ 为函数；则 $Y = g(X)$ 也是一个随机变量。此处，$X$ 和 $Y$ 均为随机向量，因此 $g$ 必须是向量场。我们可以将 $g$ 表示为 $g = (g_1, g_2, ..., g_d)$，使得：

$$Y_i = g_i(X_1, X_2, ..., X_d) \quad \text{对于 } i = 1, ..., d$$

其中，所有 $i$ 的 $g_i$ 均为连续可微函数。

若 $f_X(x)$ 表示 $X$ 的联合密度函数，则 $Y$ 的联合分布函数由 $f_Y(y) = f_X(g^{-1}(y)) |J|$ 给出。此处，$J$ 表示随机变量的雅可比矩阵，$|J|$ 代表雅可比行列式，因此是一个多项式。

$$J = \begin{bmatrix} \frac{\partial g_1}{\partial x_1} & \cdots & \frac{\partial g_1}{\partial x_d} \\ \vdots & \ddots & \vdots \\ \frac{\partial g_d}{\partial x_1} & \cdots & \frac{\partial g_d}{\partial x_d} \end{bmatrix}$$

若 $X$ 和 $Y$ 为实值随机变量，则雅可比矩阵简化为简单导数；我们写为：

$$f_Y(y) = f_X(g^{-1}(y)) \left| \frac{d}{dy} g^{-1}(y) \right|$$

**示例**：设 $Y = X^2$，其中 $X$ 为服从 $N(0,1)$ 分布的随机变量。我们有：

$$f_X(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}, \quad x = \pm \sqrt{y}$$

因此，随机变量 $Y$ 的密度函数由 $f_Y(y) = \frac{1}{\sqrt{2\pi y}} e^{-y/2}, \quad y > 0$ 给出。

**示例**：设 $Z = X + Y$ 和 $W = X - Y$，即 $X = \frac{Z+W}{2}, Y = \frac{Z-W}{2}$；我们有 $|J| = \frac{1}{2}$。$Z$ 的分布为 $f_Z(z) = \int f_{X,Y}(\frac{z+w}{2}, \frac{z-w}{2}) \frac{1}{2} dw$

# 多元分布

现在，让我们看看几个重要的多元分布，它们将在后续章节中用于定义许多机器学习模型。我们还将看看这些多元分布的一些边缘分布。

## 多项分布

考虑一个包含 **n** 次独立类别试验的序列，其类别概率向量为 $p = (p_1, ..., p_K)$，其中 $\sum_{k=1}^K p_k = 1$，这些是每次试验的常数。例如，在球和盒子实验中，一个盒子里装有 $K$ 种不同颜色的许多球。抽取的球的颜色服从类别分布，而有放回地进行 $n$ 次此类试验的序列将服从多项分布。在 $n$ 次试验中，若 $X_k$ 代表获得第 $k$ 类的计数，则必须有 $\sum_{k=1}^K X_k = n$。这些不同的类别可以通过 $\frac{n!}{X_1! \cdots X_K!}$ 种方式获得，获得这种类别分布的概率为 $\frac{n!}{X_1! \cdots X_K!} p_1^{X_1} \cdots p_K^{X_K}$。设 $X$ 服从多项分布 $M(n, p)$。此处，$X$ 是一个向量：$X = (X_1, ..., X_K)$，我们记作 $X \sim M(n, p)$。

$$P(X_1=x_1, ..., X_K=x_K) = \frac{n!}{x_1! \cdots x_K!} p_1^{x_1} \cdots p_K^{x_K}, \text{ 其中 } \sum x_k = n$$

文本数据可以建模为词汇上的多项分布。假设文本是词的集合，给定一组文本文档，我们可以定义整个文档集合中出现的 $K$ 个不同词汇的词汇表。根据每个词在每个文档中出现的次数，我们可以将每个文档表示为一个类别变量。

## 多元高斯分布

对于向量 $x \in \mathbb{R}^d$，多元高斯分布采取以下形式：

$$p(x) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2} (x - \mu)^T \Sigma^{-1} (x - \mu)\right)$$

其中 $\mu$ 是 $d$ 维均值向量，$\Sigma$ 是 $d \times d$ 协方差矩阵，$|\Sigma|$ 是 $\Sigma$ 的行列式。这用符号 $X \sim N(\mu, \Sigma)$ 表示。

我们将在本书的多个主题中遇到这种形式的高斯分布。因此，我们必须详细理解它。首先，我们将从该密度函数的几何解释入手，这将让我们了解高斯分布向量在 $\mathbb{R}^d$ 中是如何相对放置的。此外，我们将证明 $p(x)$ 确实代表一个密度，即：

$$\int_{\mathbb{R}^d} p(x) \, dx = 1$$

将 $dx_1 \cdots dx_d$ 表示为向量 $dx$，我们得到了归一化方程的简洁表示，即 $\int p(x) \, dx = 1$

指数项中的幂 $(x - \mu)^T \Sigma^{-1} (x - \mu)$ 是一个二次型，因为 $\Sigma$ 作为协方差矩阵可以被视为对称的；因此其逆矩阵也是对称的。此处，$\Delta$ 称为从 $\mu$ 到 $x$ 的*马氏距离*，当 $\Sigma$ 为单位矩阵时，它退化为欧几里得距离。
