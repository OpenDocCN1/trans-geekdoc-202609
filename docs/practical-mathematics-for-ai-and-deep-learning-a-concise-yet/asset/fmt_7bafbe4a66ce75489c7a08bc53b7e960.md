
将矩阵表示为矩阵乘积的过程称为**矩阵分解**或**矩阵因子分解**。存在许多矩阵分解方法，每种方法适用于特定类别的问题。矩阵分解的主要优势在于将矩阵表示为一种有助于解决问题的形式。

如果矩阵的逆存在，计算其逆可能计算量很大。但当矩阵表示为矩阵乘积时，可以用相对较少的计算资源完成。假设矩阵`A`可以表示为任意三个矩阵`P`、`Q`、`R`的乘积，且它们的逆计算很简单。因此，将矩阵分解为合适的矩阵可以减少计算量：

## LU 分解

**LU 分解**是将方阵表示为下三角矩阵和上三角矩阵乘积的过程，即`A = LU`：

![](images/221.jpg)

从乘积`a[11] = l[11] * u[11]`可知，`l[11]`和`u[11]`有许多可能的取值。为了获得分解的一致性，将下三角矩阵的对角线元素赋值为 1。在下面的例子中，`l[xx] = 1`。固定`l[xx]`的值后，我们可以求出其他值：

利用得到的值，`u[12] = 3`，`l[21] = 3`，解`l[21] * u[12] + l[22] * u[22] = 1`得`u[22] = -8`。

类似地，可以得到`L`和`U`矩阵所有条目的值。

![](images/223.jpg)![](images/224.jpg)

当`a[11] = 0`时会发生什么？

当`a[11] = 0`时，`a[11] = l[11] * u[11] ⇒ l[11] = 1, u[11] = 0`，但如果`rank(A) = n`，这种情况是不可能的，因为赋值`u[11] = 0`会导致`rank(U) < n`，进而导致`rank(A) < n`。如果打乱矩阵`A`的行，就可以避免这种情况。矩阵`A`的行打乱或排列可以通过排列矩阵`P`来执行，如*Matrices*一节所述。矩阵`A`的排列行将分解为`PA = LU`。每个方阵都可以分解为这种形式：

![](images/225.jpg)

通过在`L`和`U`矩阵之间引入对角矩阵`D`（非对角线元素为 0），可以将`U`矩阵的所有对角线条目赋值为 1。

## 高斯-约当消元法的副产品

## 奇异值分解

**奇异值分解**是特征分解向矩形矩阵的推广。方阵`S`的特征值`λ`和对应的特征向量`e`满足`S e = λ e`。由于`S[n×n]`是方阵，相乘向量和结果向量都属于`R^n`，且它们相同（都在同一维子空间中）。考虑矩形矩阵`A[m×n]`，当它与向量`v ∈ R^n`相乘时，结果是向量`u ∈ R^m`。由于相乘向量和结果向量属于不同维度的子空间，需要使用`A`（映射`R^n → R^m`）和`A^T`（映射`R^m → R^n`）双向映射。
