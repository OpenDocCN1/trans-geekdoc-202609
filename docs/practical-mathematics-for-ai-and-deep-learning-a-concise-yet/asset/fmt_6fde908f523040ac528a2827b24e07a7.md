
Since the Hessian `H` is a real symmetric matrix, the quadratic form `Q(x) = x^T H x` is positive definite if and only if all its eigenvalues are positive and negative definite if all eigenvalues are negative.

Suppose all eigenvalues of `H` are positive and `λ_min > 0`. We choose `x ≠ 0`, then `Q(x) = x^T H x > 0`. Clearly, `λ_i > 0` are the eigenvalues of `H`. The quadratic form is as follows:

`Q(x) = Σ λ_i y_i^2`

Now, `lim_{x→a} f(x) = L`, using the definition of limit for any chosen positive `ε` there exists a `δ` such that `|f(x) - L| < ε`. Multiplying both sides of this inequality by `||x - a||^2`, we get `|f(x) - L| ||x - a||^2 < ε ||x - a||^2`. Choosing the arbitrary number `M = ε`, we have `|f(x) - L| ||x - a||^2 < M ||x - a||^2`.

`f(x) - f(a) = ∇f(a)^T (x - a) + o(||x - a||)`

Hence, `a` is a relative minimum. Similarly, we can prove the statements of the theorem for maximum and saddle point.

**Example**: Locate and classify the stationary points for the surface `z = x^2 - y^2`

We have `∂z/∂x = 2x` and `∂z/∂y = -2y`. At a stationary point, both the partial derivatives should vanish. Clearly, origin `(0, 0)` is a stationary point.

Now, `∂²z/∂x² = 2` and `∂²z/∂y² = -2`. This contradicts `∂²z/∂x∂y = 0`. Thus (0, 0) is the only stationary point.

`H = [[2, 0], [0, -2]]`

# Descent Methods

In practice, the functions of several variables are encountered, we will have no idea where in the domain of the function it will attain its optimum value. In fact, we may never be able to find the exact minimum `x*`. Our target is to reach as close as possible to the minimum, `x*`. So, we must start at some arbitrary point `x_0` and then take small steps `α_k` in the direction in which the function value decreases:

`x_{k+1} = x_k + α_k d_k`

Here, `α_k` is the **step size** in the direction of the search direction `d_k`. Our target is to choose `d_k` and `α_k` such that `f(x_{k+1}) < f(x_k)`. These sequence of points `x_k` (should converge to the minimum `x*`).

Using first order Taylor series expansion, let `f(x)` and `x` be a point very close to `a`, that is, `x = a + v`. Let `v = x - a`:

`f(x) ≈ f(a) + ∇f(a)^T v`, where `v = x - a`

Here, `∇f(a)^T v` represents the directional derivative in the direction of the change vector `v`. If this term is negative, we can reduce the value of `f` at `x`. So, `v` must make an acute angle with the negative gradient `-∇f(a)`. We call such a direction as *descent direction*. The best case is when the angle between the vectors `v` and `-∇f(a)` is zero or the vectors are parallel, that is, if `v = -α ∇f(a)` for some `α > 0`. This is called the *direction of steepest descent*. The direction of the negative gradient at a point is the direction of steepest descent.

Hence, we can define an iterative algorithm for minimizing a function as follows:

*   Given a starting point `x_0`
*   Repeat:
    *   `d_k = -∇f(x_k)`
    *   Choose a step size `α_k`
    *   Update `x_{k+1} = x_k + α_k d_k`

Stopping criteria for the preceding iterative algorithm is generally based on norm of the gradient. As we are finding a stationary point iteratively, the algorithm can converge when the gradient at the point `x_k` is close to 0, that is, `||∇f(x_k)|| < ε` where `ε` is small. `ε` is a pre-defined fixed number indicating acceptable level of error. This algorithm is called *gradient descent algorithm*. Now, we also need a way of choosing the step size. The step size should not be too short or too long. The following example shows the effect of step size.

**Example**: Let’s take a real valued function `f(x) = x^2`. Being a function on real line, we have only two possible directions `±1`; we can choose the descent direction as `d = -sign(x)`. Note that this descent direction is also parallel to the negative gradient direction, as `∇f(x) = 2x`. We will use two different step sizes (1) `α_k = 2 + 3/2^{k+1}` which is a big step size, and (2) `α_k = 1/2^{k+1}` which is a monotonically decreasing small step size. Now, starting with initial point `x_0 = 2` and following the preceding update equation `x_{k+1} = x_k + α_k d_k`, we see that with (1), the function value eventually oscillates between -1 and 1 and with step size (2), the decrease in function value becomes very small and almost converges at 1. The following code shows an implementation of this:

```python
def step(k, type=1):
    if type == 1:
        return 2 + 3 / np.math.pow(2, k + 1)
    elif type == 2:
        return 1 / np.math.pow(2, k + 1)
    else:
        return 1

def update(x, k, type=1):
    return x + np.sign(-x) * step(k, type)

x = 2
for k in range(20):
    x = update(x, k, type=1)
    print(k, x, x**2)
    k = k + 1
```

One approach to find appropriate step size is *exact line search*, where the function is minimized along the line `x_{k+1} = x_k + α d_k`, that is:

`min_{α > 0} f(x_k + α d_k)`

This is a valid method but is not cost effective. So, inexact line search methods are used where we are looking for a step size that reduces `f` enough. One such method is called *backtracking line search*. This depends on two parameters `α, β ∈ (0, 1)`. Given a descent direction `d_k`, we start with unit step size and then reduce the step size by a factor of `β` until some stopping criteria is reached. The first order Taylor’s formula can give us a stopping criterion. By first order Taylor's approximation, `f(x_k + α d_k) ≈ f(x_k) + α ∇f(x_k)^T d_k`.

`f(x_k + α d_k) ≤ f(x_k) + c α ∇f(x_k)^T d_k`

So, in the successive step, we reduce the step size by a constant factor `β` (this restricts the step size from being too small), and we see that `f` is reduced by at least a fixed fraction `c` of the reduction promised by first order Taylor’s formula. This also restricts the step size from being too long. This condition is called **Armijo condition**.

There are other heuristics that are also used for step size selection in gradient descent.

**Constant step size**: Choose one fixed value `α`.

**Variable step size**: 3 or 4 values of step are chosen in each iteration, and whichever gives the best reduction of function value is chosen.

*   **Golden search**: A range between two values is used and divided into sections.

*   **Example**: (**Rosenbrock function**): `f(x, y) = (1 - x)^2 + 100(y - x^2)^2`. This function has a global minimum at the point `(1, 1)` where `f(1, 1) = 0`. The global minimum is located inside a long, narrow, parabolic shaped flat valley, as shown in *Figure 3.19* for `a = 10`. The gradient of the function is given by:

`∇f(x, y) = [-2(1 - x) - 400x(y - x^2), 200(y - x^2)]^T`
