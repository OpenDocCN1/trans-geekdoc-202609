
给定一种源语言（例如法语）的文本序列，任务是将其转换为一种目标语言（例如英语）。自然语言固有的歧义性和灵活性导致源文本到另一种语言不存在单一的最佳翻译。这使得语言翻译问题极具挑战性。经典的语言翻译模型要么基于规则，要么基于统计。基于规则的模型由语言学家开发，此类规则的集合非常庞大。统计方法是数据驱动的，利用源语言和目标语言的句对集合，将源语言的短语或子句转换为目标语言。这被称为**统计机器翻译**（**SMT**）。当神经网络模型应用于此任务时，其表现优于上述两种方法。

我们可以从**[http://www.manythings.org/anki/](http://www.manythings.org/anki/)**下载法英数据集，其中包含双语句对。

文本可以视为单词序列。假设某种语言的词汇表中有 N 个单词；我们可以用 1 到 N 的数字来表示它们。因此，源句子是一个整数索引序列。我们必须将这些整数转换为独热编码向量。通常 N 会非常大，转换为独热编码会导致高维稀疏向量。为避免此问题，单词通过查找矩阵转换为稠密向量表示，该矩阵包含维度为 ![](images/2635.jpg) 的 N 个稠密向量。此查找矩阵称为*嵌入矩阵*，其维度称为*嵌入维度*。我们将在下一章 NLP 中更详细地讨论嵌入矩阵。
