

# 随机变量与简单变量有何不同？

对于简单变量，我们无法说明该变量取某个给定值的可能性有多大，也无法说明其值落在各个范围内的可能性有多大，因为变量没有与之关联的概率。对于随机变量（r.v.），存在一个关联的概率测度，它告诉我们变量取某个特定值或某个特定范围值的可能性有多大。关于变量的这一额外信息将随机变量与简单变量区分开来，它表示为另一个函数，称为离散随机变量的**概率质量函数（P.M.F）**和连续随机变量的**概率密度函数（P.D.F）**。

设随机实验为连续抛掷三次硬币。设 `X` 表示三次抛硬币中正面朝上的次数。显然，`X` 可以从集合 `{0,1,2,3}` 中取值。从所有可能的八种结果中，我们可以计算每个结果的概率，如 *[图 4.11](#c04.xhtml#fig4_11)* 所示。例如，有三种结果的 `X=1` 个正面，即 `{HTT, THT, TTH}`，因此，![](images/987.jpg)。对于所有 `X` = 0, …, 3，我们可以计算概率，并得到由 ![](images/988.jpg) 表示的离散概率密度函数。

**注意：** ![](images/989.jpg) 和 ![](images/990.jpg)

对于随机变量的任何函数要成为概率密度函数，它必须满足这两个性质。密度函数 `f(x)` 类似于沿一条线分布的单位质量粉末。因此，将所有质量相加应等于 1。此外，这条线上不能有负质量；我们最多只能有单位质量，最少为零质量。

# 伯努利分布与类别分布

所有离散随机变量中最基础的是*伯努利分布*。如果 `X = 1` 发生的概率为 `p`，`X = 0` 发生的概率为 `1 - p`，则称 `X` 服从伯努利分布。这里，`p` 通常称为成功概率。这类似于一个不均匀的抛硬币实验，正面出现的概率为 `p`，反面出现的概率为 `1 - p`。

## 广义伯努利分布（类别分布）

在伯努利实验中，我们只有两种可能的结果。我们可以将其推广到 K 种可能的结果。例如，我们有一个装有四种不同颜色球（红、蓝、绿、橙）的罐子。设 `X=0,3` 分别代表这四种颜色。我们需要求抽到给定颜色球的概率，其中每个球都是有放回地随机抽取。这样的随机变量称为类别随机变量。一般来说，类别变量 `X` 可以按概率 ![](images/995.jpg) 取 K 个可能值 `{1,2,…,K}` 中的一个，其中 ![](images/996.jpg) = 1。类别分布的一个样本可以表示为维度为 K 的独热编码向量。在罐子的例子中，蓝球可以表示为 `(0,1,0,0)`，绿球可以表示为 `(0,0,1,0)`。设 `x` 表示来自类别分布的独热编码样本。则向量 `x` 的质量函数定义为：

***注意：** 对于连续概率密度 `f(x) ≠ P(X = x)`，`f(x)` 表示点 `X = x` 附近概率质量的密度。连续随机变量 `X` 取任何精确值 `x` 的概率为零。然而，对于离散分布，`f(x) = P(X = x)`。此外，对于连续分布，`f(x)` 在某些 `x` 值处可以大于 1。然而，对于离散分布，`f(x) ≤ 1` 恒成立，因为它代表一个概率。*
