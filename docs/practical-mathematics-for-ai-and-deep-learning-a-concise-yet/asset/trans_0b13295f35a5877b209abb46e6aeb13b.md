# 方向

**向量的方向**是指它与空间坐标轴所成的角度。在二维空间中，向量将与 `x` 轴和 `y` 轴都形成夹角。一般来说，在 `n` 维空间中，向量将与空间的每个 `n` 个坐标轴形成夹角。考虑**图 2.6** 中从 `(2, 1)` 连接到 `(5, 5)` 的向量 `v = (3, 4)`。分别过向量的起点和终点作平行于 `x` 轴和 `y` 轴的直线，构成以该向量为斜边的直角三角形，如**图 2.6** 所示。要找到向量 `v` 与 `x` 轴之间的夹角 `θ`，可使用三角函数公式 `tan(θ)`。在这个直角三角形中，平行于 `x` 轴的边长是向量的 `x` 轴分量，同理 `y` 轴也是如此。根据**图 2.6**，`θ = arctan(4/3) = 53.13°`。同理，对于向量 `u`，其与 `x` 轴的夹角 `θ = 53.13°`。

> **提示：** 在欧几里得空间中，获得向量间夹角的通用方法是通过点积。点积将在下一节中解释。

在**图 2.6** 中，由于向量 `v` 和 `u` 具有相同的模和方向，它们相等，即 `u ≡ v`。

> **注意：** 如果两个向量具有相同的模和方向，则称它们相等。这引出了一个重要概念：向量的起点并不重要，重要的是它们的模和方向。

# 数乘

**数乘**是指通过与实数 `k`（称为标量）相乘来改变向量的模或长度，而不改变其方向。向量与非零标量 `k` 相乘时，其模将按 `k` 的因子变化。与正标量相乘保持方向不变，与负标量相乘则将向量方向翻转 180°。将向量 `v = (a_1, a_2, …a_n)` 与标量 `k` 相乘将得到 `w = kv = k(a_1, a_2, …a_n) = (k * a_1, k * a_2, … k * a_n)`。在**图 2.7（左）**中，将向量 `u = (3, 3)` 与标量值 `2` 和 `-1` 相乘。得到的向量将分别为 `w = 2u = 2 * (3, 3) = (2 * 3, 2 * 3) = (6, 6)` 和 `v = (-1)u = -1 * (3, 3) = (-1 * 3, -1 * 3) = (-3, -3)`。请参阅下图：

# 向量的加法/减法

两个向量的**加法**（减法）是通过将它们对应的分量相加（相减）来执行的。两个向量 `u = (a_1, a_2, …a_n)` 和 `v = (b_1, b_2, …b_n)` 相加将得到：

`u + v = (a_1, a_2, …a_n) + (b_1, b_2, …b_n) = (a_1 + b_1, a_2 + b_2, …a_n + b_n)`

同理，减法为：

`u – v = (a_1, a_2, …a_n) + (b_1, b_2, …b_n) = (a_1 – b_1, a_2 – b_2, …a_n – b_n)`

在**图 2.7（右）**中，向量 `u = (10,0)` 和 `v = (2,8)`。这两个向量的加法通过将对应分量相加执行，结果为 `u + v = (10 + 2, 0 + 8) = (12,8)`。向量的减法也是通过将向量的对应分量相减执行，结果为 `u – v = (10 – 2, 0 – 8) = (8, –8)`。

如果两个向量的点积为 0，则称它们**正交**。换句话说，如果它们之间的夹角为 `θ = 90°`，则向量正交。当 `θ` 为 90° 时，`cos(θ) = 0`，这验证了点积为 0。由于 `x` 轴和 `y` 轴之间夹角为 90°，`x` 轴上的任意向量都与 `y` 轴上的任意向量正交。如果向量彼此正交且其模为 1，则称它们为**标准正交**。换句话说，如果 `u ⋅ v = 0` 且 `‖u‖ = ‖v‖ = 1`，则向量 `u` 和 `v` 称为标准正交。
