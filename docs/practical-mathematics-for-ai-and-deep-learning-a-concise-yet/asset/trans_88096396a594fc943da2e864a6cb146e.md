

# 一阶方程称为线性方程

将线性方程重写为 `9*C* – 5*F* + 160 = 0` 的形式，可得到通式 `ax + by + c = 0`。这被称为线性方程的通式，因为我们可以轻松地将其扩展到两个以上变量，即 `a[1]x[1] + a[2]x[2] + … + a[n]x[n] + a[0] = 0`。常数 `a[i]` 称为系数，`a[0]` 称为方程的截距。三个变量的线性方程（`a[i] ≠ 0; 1 ≤ i ≤ 3`）在几何上表示三维空间中的超平面或平面。超平面的概念可以推广到 `n` 维。

当多个线性方程在 `n` 维空间中表示时，分析这些方程所代表的超平面的公共点或交点是很有趣的。这些公共点同时位于所有超平面上，被称为**线性方程组**的*解*。

现在，让我们将一个简单的问题建模为线性方程组并求解。

假设一群朋友计划去商场。他们打算在看电影、保龄球和游戏机上花费时间。由于对从哪里开始玩意见不一，他们分成了三组。在商场玩了一会儿后，他们聚在一起讨论。

第一组 `G1` 提到他们在 1 个*保龄球道*、1 台*游戏机*和 1 张*电影票*上花费了 ₹1500。第二组 `G2` 在 3 个*保龄球道*、4 台*游戏机*和 2 张*电影票*上花费了 ₹4400。第三组 `G3` 在 5 个*保龄球道*、3 台*游戏机*和 5 张*电影票*上花费了 ₹6500。根据这些信息，能否推导出保龄球道、游戏机和电影票的价格？可以用方程形式表示上述数据如下：

`G1: 1 保龄球道 + 1 游戏机 + 1 电影票 = ₹1500`

`G2: 3 保龄球道 + 4 游戏机 + 2 电影票 = ₹4400`

`G3: 5 保龄球道 + 3 游戏机 + 5 电影票 = ₹6500`

用 `b` 替换*保龄球道*，`p` 替换*游戏机*，`m` 替换*电影票*来表示线性方程组，得到 3 个线性方程：

`e[1]: 1*b + 1*p + 1*m = 1500`

`e[2]: 3*b + 4*p + 2*m = 4400`

`e[3]: 5*b + 3*p + 5*m = 6500`

让我们在 3D 中可视化这些方程的几何表示，x 轴代表*保龄球道*，y 轴代表*游戏机*，z 轴代表*电影票*。每个方程在 3D 空间中都是一个平面。考虑用于在 3D 空间表示的方程 `1*b + 1*p + 1*m = 1500`。变量 `b` 和 `p` 可以取正的自由值（保龄球、游戏机和电影票的成本应为正），但 `m` 的值将通过方程 `e[1]` 赋值为 `m = 1500 – b – p`。这些表示方程的值将在 3D 中张成一个平面，如 *[图 2.2](#c02.xhtml#fig2_2) (左)* 所示：

![](images/2.jpg)

同样，表示方程 `e[2]` 的平面在 3D 中绘制。在这种情况下，表示 `e[1]` 和 `e[2]` 的平面在 3D 中沿一条线相交，该线可用方程 `b + 2*p = 1400` 和 `m = p + 100` 表示，如 *[图 2.2](#c02.xhtml#fig2_2) (右)* 所示。可以通过将 `b` 设为自由变量来绘制相交线，其他因变量赋值为 `p = (100 – b)/2` 和 `m = p + 100`。这意味着位于相交线上的所有点也将位于这两个平面上。

同样，表示方程 `e[3]` 的平面可以在 3D 中绘制，如 *[图 2.3](#c02.xhtml#fig2_3)* 所示。这三个平面恰好在唯一点 `p(400,500,600)` 相交。这意味着交点 `p` 位于表示三个方程中每一个的所有三个平面上。这组方程的解是 `(400,500,600)`，这意味着*保龄球道* (`b`) 的价格是 ₹400，*游戏机* (`p`) 是 ₹500，*电影票* (`m`) 是 ₹600。该方程组的解是通过几何方法获得的。

在本例中，表示平面的每个方程都在唯一点相交。这是*唯一解*的情况。情况并不总是如此。如果平面沿单条线或超平面相交，则位于相交线或超平面上的所有点都是表示这些平面的方程的解。这提供了*无限多解*或*无穷解*的情况。还可能出现平面在任何点都不相交的情况，即*无解*或*不一致系统*。没有解的线性方程组称为*不一致系统*。后续讨论将围绕这些解的类别及获取这些解的解析方法展开。请参阅下图：

# 解析求解方程组

由于难以直观地可视化解，几何方法求解方程并非首选。考虑四个或更多变量的线性方程；无法可视化这些方程形成的超平面。让我们讨论一种寻找方程组解的通用方法。解析上，可以对这些方程执行一系列有效运算以获得相同的解。这些运算包括乘法和加法。

## 乘法

将同一个非零实数乘到方程的左侧 (LHS) 和右侧 (RHS) 不会改变方程的等式关系。例如，方程 `e[1]` 乘以非零实数 3，运算表示为 `3*e[1] → e[1]`，表示方程两边同时乘以 `e[1]`，所得方程称为 `e[1]`：

```
方程 e[1]: 1b + 1p + 1m = 1500
乘法: 3*e[1] → e[1]
结果方程 e[1]: 3b + 3p + 3m = 4500
```

## 加法

将同一个实数加到方程的左侧 (LHS) 和右侧 (RHS) 不会改变方程的等式关系。也可以将等式方程相加，因为 LHS 和 RHS 相等。例如，将 `e[2]` 加到 `e[1]`，所得方程赋给 `e[1]`，运算表示为 `e[1] + e[2] → e[1]`：

```
方程 e[1]: 1b + 1p + 1m = 1500, e[2]: 3b + 4p + 2m = 4400
加法: e[1] + e[2] → e[1]
结果方程 e[1]: 4b + 5p + 3m = 5900
```
