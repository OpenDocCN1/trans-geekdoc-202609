
一旦确定了特征，我们必须定义一组规则来对花朵进行分类。在这里，我们的输出或 `target` 变量是花朵的类别。这也被称为 `independent variable`（自变量），而特征则被称为 `dependent variables`（因变量）。[图 1.5](#c01.xhtml#fig1_5) 展示了一个仅使用前两个特征的规则示例。萼片长度和花瓣长度的取值范围不同。我们可以应用一些数据变换，使数据集中的所有特征值都映射到一个通用的尺度上，而不会扭曲数值范围的差异。这被称为 `data normalization`（数据归一化）。特征值被归一化或缩放，使其围绕零点为中心；这就是为什么我们在坐标轴上看到负值和零值的原因。原始数据集全为正值，因为所有四个花朵特征都是长度或宽度。请参考下图：

![](images/Image38499.jpg)

**图 1.5：** *仅使用前两个特征识别鸢尾花种类*

通过观察仅两个特征即可将花朵分类到相应类别的简单规则如下：

*   如果归一化后的萼片长度 < 0 且归一化后的萼片宽度 > 0，则为山鸢尾。
*   如果萼片长度和宽度落在左下三角区域内，则极有可能是变色鸢尾。该三角区域可由三条直线方程定义。
*   否则，为维吉尼亚鸢尾。

这一组规则或表示这些规则的数学函数，有助于识别花朵类型，被称为 `model`（模型）。

手动推导规则或数学函数是一项耗时的任务。机器学习算法试图通过学习规则、决策边界或数学函数来自动化这一过程，该函数以花朵的数字表示作为输入，输出花朵可能的类别。

特征的选择是否会影响所学习模型的分类准确性？是的，分类准确性取决于所选的花朵特征。我们在前面的例子中看到，由于我们只选择了两个特征，无法正确区分变色鸢尾和维吉尼亚鸢尾这两个类别。在下一节中，我们将讨论设计基于 ML 模型的分步流程。

## ML 模型是如何创建的？

构建 ML 模型是一个迭代过程。它始于理解业务问题，然后收集与问题领域相关的数据。接着，对这些数据进行处理、清洗并准备建模。这在[图 1.6](#c01.xhtml#fig1_6)中有所描述：

![](images/Image38506.jpg)

**图 1.6：** *构建 ML 模型*

以下是构建 ML 模型的各个步骤：

1.  **数据收集**：收集与问题相关的观测值或数据的过程称为**数据收集**。在鸢尾花亚型分类中，我们必须测量采集样本中每朵花的花瓣和萼片的长度和宽度。这些花朵特征和样本花朵的数量是否足以解决问题？答案是，我们最初无法判断这些特征或收集到的样本数量是否足够。擅长花卉识别的人类领域专家可以提供关于所选特征是否充分的有用信息。我们需要采集多少花朵样本？这最初也不明确。在模型构建和初步分析后，我们可以重新审视这个问题。一个经验法则是，如果每个样本有更多特征，我们必须收集更多数据样本。

2.  **数据准备**：在此步骤中，分析观测值以检查是否存在缺失值、数据收集中的任何错误（如异常观测值），如果有，则必须从数据集中更正或移除它们。

3.  **特征提取/选择**：进一步分析清洗后数据的特征，以查找明显的相互关联。可能某些特征高度相关，使用这些相关特征中的任何一个就足以解决问题。可能存在对问题完全不重要的特征。这些统计检验将在[第 5 章，统计推断与应用](#c05.xhtml)中详细讨论。在此步骤之后，会选择少数特征。有时，我们可能需要从收集的特征中推导出新特征。例如，我们可能使用对数函数转换特征值，并将对数值作为特征。此步骤也称为 `feature engineering`（特征工程）。

4.  **训练模型**：选择一个接受选定特征并输出期望结果的数学函数：**模型选择**。通常，这些数学函数是 `parametric`（参数化的），即它们的函数形式是固定的，但改变参数会改变函数。在[图 1.5](#c01.xhtml#fig1_5)所示的鸢尾花分类中，参数函数是二维空间中的一条直线，其通式为：`ax + by + c = 0`，其中 `a`、`b`、`c` 为参数。事实上，我们有 3 条这样的直线；因此，需要 9 个参数来定义模型函数。对于这组参数的固定值，我们得到一个决策边界或规则，称之为模型。寻找这些参数值以使结果接近期望值（或真实标签）的过程称为 `model training`（模型训练）。

5.  **模型评估**：设计各种指标来评估上一步创建的模型质量。这些指标因不同类型的 ML 算法而异。这些将在后续关于 ML 模型类型的章节中讨论。

6.  如果发现模型质量不可接受，则会尝试各种改进模型的方法。这可能涉及选择不同的函数形式，例如使用二次函数 `ax² + bx + cxy + d = 0` 作为模型，并再次估计其参数。如果我们仍未能找到一个好的模型，可能必须回到数据准备阶段设计更多特征，甚至可能必须进一步回溯以收集更多相关数据和特征来解决问题。这些在[图 1.6](#c01.xhtml#fig1_6)中显示为向后的虚线。

针对不同类型的问题，存在各种类型的 ML 算法。所有这些算法都是通过从数据中学习迭代构建的。关于问题领域的数据或观测值是 ML 算法的起点，然后这些算法通过从数据中获取反馈进行迭代改进。我们将首先简要讨论不同类型的数据，然后讨论不同类型的 ML 算法。

## 数据类型

数据是解决 AI 中任何问题的起点。数据大致可分为两类：结构化和非结构化。结构化数据是表格数据，我们拥有某些预定义的特征或属性，即表中的列已定义。表中的行包含这些属性的值。非结构化数据是指未按照预定义的数据模型或模式排列的信息，因此无法以表格形式存储。在[图 1.7](#c01.xhtml#fig1_7)中，这两大类进一步细分为不同的子类别并附带示例：

## 从数据中学习

为了让算法从数据中学习，需要有关于算法所学规则或逻辑的反馈。基于反馈，算法将学习数据的更好表示以实现期望的输出。针对不同程度的反馈，需要不同的算法。接下来，我们将讨论这些算法的各种类型。
