# [从 CTC 网络推理](#toc.xhtml#s359a)

从 CTC 网络推理可以通过两种不同的方式完成：*贪心搜索* 和 *束搜索*。给定长度为 `T` 的输入序列，CTC 网络将输出长度为 `T` 的概率分布序列。贪心解码在每个时间步选择概率最大的输出标记。

束搜索不是在从概率中解码输出序列时贪心地选择最可能的下一步，而是扩展所有可能的下一步，并保留 `k` 个最可能的，控制通过概率序列的束数或并行搜索数。 *[Figure 10.21](#c10.xhtml#fig10_21)* 展示了一个束宽为 `k` 且输出字母表为 `{a, b, ϵ}` 的束搜索示例。请参考下图：

![](images/Image47388.jpg)

**Figure 10.21:** *束搜索图解 [source: [https://github.com/distillpub/post--ctc/issues/4](https://github.com/distillpub/post--ctc/issues/4)]*

CTC 的局限性如下：

*   CTC 假设给定帧的模型输出与前几帧无关。CTC 层不是循环的。
*   输出序列不能长于输入序列——对于文本转语音或文本转手写等任务，输出可能长于输入。
