
Roland Fisher 在 1938 年发表的论文中发布了一个数据集，包含三种鸢尾花各 50 个样本。每个花样本测量了四个特征（单位：厘米）：萼片长度、萼片宽度、花瓣长度、花瓣宽度。我们使用 TensorFlow 框架将花卉数据表示为向量；setosa、virginica 和 versicolor 分别代表标签 0、1 和 2。因为每朵花由四个特征表示，所以代表花的向量属于 ![](images/r.jpg)⁴。以下代码提供了加载鸢尾花数据的步骤。随后将数据集中的少量样本复制到 TensorFlow 数组中以供进一步分析。

```
1. import tensorflow as tf
2. import tensorflow_datasets as tfds
3. import numpy as np
4. iris_ds = tfds.load('iris', split='train')  # load Iris dataset
5. SAMPLE_SIZE = 6   # consider few samples from the dataset
6. iris_ex = iris_ds.take(SAMPLE_SIZE)   # consider first few samples from the dataset
7. # Tensor array to store dataset samples
8. tf_arr = tf.TensorArray(tf.float32, size=0, dynamic_size=True, clear_after_read=False)
9. index = 0
10. for sample in iris_ex:
11.      feat = sample["features"]
12.      label = sample["label"]
13.      tf_arr = tf_arr.write(index, feat)  # Add sample to array
14.      index = index + 1
15.      vec_norm = tf.norm(feat)  # Calculate norm of the vector
16.      tf.print("label=", label, ' vector v', index, '=', feat, " Euclidean Norm=", vec_norm, sep="")
```

1. for ref_index in range(0, SAMPLE_SIZE):

鸢尾花数据集还包含与 150 个观测值相关联的类别标签或花名。如果给定一个属于这三个花类别中任意一种的新花的测量向量或观测值，我们能否判断该新花的正确类型？仅使用由范数诱导的距离度量，我们就可以为鸢尾花数据集构建一个简单的分类器。基于向量间距离原理工作的算法之一是 K 近邻算法。它利用整个数据集来推断新观测值可能的类别。

# K 近邻算法

**K 近邻算法** 基于向量间距离的原理工作。主要使用欧几里得距离来计算距离。在该算法中，计算新观测向量与数据集中每个向量的距离。新观测向量的类别由其在已知类别的给定数据集中的最近邻决定。邻居被定义为根据所选距离度量，在给定数据集中距离最近的 K 个向量。最近邻的数量 K 是算法的一个参数，通过经验确定。[图 2.14](#c02.xhtml#fig2_14) 展示了基于 K 值对新样本进行分类的情况。当 K=3 时，新样本会被分类为 `Class B`；但当 K=7 时，新样本会被分类为 `Class A`。请参考下图：

![](images/Image39564.jpg)

9.      test_knn_labels = np.zeros((0), dtype=np.int)
10.      outer_index = 0
11.      # Calculate Euclidean distance between a test vector & all training vectors
12.      # Select k-nearest neighbors based on the distance
13.      for test_feat_samp in iris_test_feat:
14.           eu_dis = np.zeros((0), dtype=np.float)
15.           inner_index = 0

17.                euclidean_distance = np.linalg.norm(train_feat_samp - test_feat_samp)
18.                eu_dis = np.insert(eu_dis, inner_index, euclidean_distance, axis=0)

20.           sorted_index = np.argsort(eu_dis)  # Sort based on euclidean distance

22.           nearest_k_labels = iris_train_label[sorted_index[0:k_val]]
