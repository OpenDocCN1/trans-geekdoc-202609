```
1. from sklearn.preprocessing import PolynomialFeatures
2. from sklearn.linear_model import LinearRegression
3. import matplotlib.pylab as plt
4.
5. def sin(n):
6.     x = np.linspace(0, 1, n)
7.     noise = np.random.normal(loc=0, scale=0.3, size=n)
8.     y = np.array([np.math.sin(2*np.pi*a) for a in x.tolist()]) + noise
9.     return x, y
10.
11. X, y = sin(100)
12. polynomial_features= PolynomialFeatures(degree=3)
13. features = polynomial_features.fit_transform(np.expand_dims(X, axis=1))
14. model= LinearRegression().fit(features, y)
15. line=model.predict(features)
16. plt.scatter(X, y)
17. plt.plot(X, line, color='black')
```

# 过拟合和欠拟合

我们必须检查机器学习模型对新数据的泛化能力如何，以及它是否能够学习训练数据中的固有模式。较差的泛化性能称为*过拟合*。当模型不仅学习了模式，还学习了训练数据中的噪声时，就会发生这种情况。由于模型做出的某些假设而无法学习训练数据中的模式，称为*欠拟合*。这些是导致机器学习算法性能不佳的原因。

1 次多项式的模型拟合较差，3 次多项式的模型拟合良好，而高阶多项式的模型则是过拟合。
