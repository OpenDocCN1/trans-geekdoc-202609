
假设数据有 m 个特征，即 `x = (x1, x2, ..., xm)`，并且给定 x 来自类别 `Ck` 时，这些特征相互独立。形式上：

`P(x|Ck) = P(x1|Ck) * P(x2|Ck) * ... * P(xm|Ck)`

将其代入贝叶斯方程，我们得到：

`P(Ck|x) = P(Ck) * P(x|Ck) / P(x) = P(Ck) * ∏ P(xi|Ck) / P(x)`

因此，新数据 **x** 属于类别 k 的概率由下式给出：

`P(Ck|x) ∝ P(Ck) * ∏ P(xi|Ck)`

这就是朴素贝叶斯分类器。

这里，*先验* 概率 `P(Ck)` 的估计很简单，如前所述。我们也可以假设所有类别同等可能，即 `P(Ck) = 1/K`。对于 `P(xi|Ck)` 的估计，我们必须弄清每个属性 `xi` 的分布。如果 `xi` 是离散的，我们可以假设多项式分布或类别分布。如果 `xi` 是连续的，我们可以假设高斯分布。

对于连续属性，可以为每个类别 `Ck` 估计属性 `xi` 的均值和方差。我们分别称它们为 `μik` 和 `σ²ik`。因此，我们现在有：

`P(xi|Ck) = (1 / √(2πσ²ik)) * exp(-(xi - μik)² / (2σ²ik))`

**注意：我们也可以通过适当地对特征值进行分箱来离散化连续属性。对于离散属性，假设我们取 `P(xi|Ck)` 为类别分布。假设离散属性 `xi` 总共有 T 个类别，`Nikt` 表示类别 t 在来自类别 k 的样本中出现的次数，令 `Nik` 表示来自类别 k 的样本总数。因此，我们有：**

`P(xi = t|Ck) = Nikt / Nik`

**现在，可能会发生在某个类别 `Ck` 中，`xi` 的所有 T 个类别都不存在的情况。这可能是因为我们采集的样本有限。因此，假设属性 `xi` 的类别 t 不能出现在类别 k 中是不恰当的。令 `T` 为属性 `xi` 的类别总数。那么，我们可以重写为：**

`P(xi = t|Ck) = (Nikt + α) / (Nik + αT)`

**这里，`α` 是一个平滑参数，它通过赋予 `α` 某个非零值来处理来自任何类别的样本中缺失的类别。**

# 回归

在回归问题中，输入向量 `x` 必须被分配给一个实数 y 或一个实向量 **y**。我们得到一个由 n 对样本 `{(xi, yi)}` 组成的数据集，称为训练数据。利用这些数据，我们需要找到一个函数 `f` 来映射 `x → y`。这里，y 是连续的。让我们先通过一个简单的例子来理解，其中输入向量只有一个属性且目标 y 是实数。令 `x` 代表父亲的身高，`y` 代表他成年儿子的身高。我们有一个大小为 N = 30 的数据集，由对 `(xi, yi)` 组成，并将其绘制在 *[图 5.3](#c05.xhtml#fig5_3) (左)* 中：

![](images/Image43156.jpg)

**图 5.3：** *简单回归* ***(左)*** *成年儿子身高 vs 父亲身高* ***(右)*** *曲线拟合数据*

从图中我们可以看到，儿子的身高可以建模为父亲身高的确定性函数 `f` 加上一些随机噪声，即：

`y = f(x) + ε`

在 *[图 5.3](#c05.xhtml#fig5_3)(右)* 中，我们可以看到，在父亲身高 `x` 英寸时，`f(x)` 低估了儿子的身高，我们可以加上一些正量来得到相应的成年儿子身高 y。对于某些 `x` 值，`f(x)` 可能会高估儿子的身高，我们可能需要减去一些变量量 `ε`。因此，噪声 epsilon 可以是正也可以是负。此外，假设随机噪声沿曲线 `f(x)` 对称分布或居中。因此，随机噪声分布的一个自然选择是均值为零、方差为 `σ²` 的高斯分布，即 `ε ~ N(0, σ²)`。因此，y 是一个由 `f(x)` 平移的随机正态变量。因此，我们可以写出 y：

`y ~ N(f(x), σ²)`

下一步是理解如何求解 `f(x)`。我们可以假设 `f` 是输入的参数化函数，例如 `f(x)` 是一个二次多项式，`f(x) = w0 + w1*x + w2*x²`，其中 `w0, w1, w2` 是参数。我们可以将参数表示为向量 `w = (w0, w1, w2)`，并将 `f` 表示为 `f(x; w)`。因此，我们现在有 `y ~ N(f(x; w), σ²)`。

因此，我们将回归表述为概率模型参数估计。

这里，参数向量 **w** 是未知的，我们可以使用 MLE 技术来估计它，我们将在线性模型部分更详细地讨论。我们将看到，MLE 估计技术归结为最小化平方和误差函数。将回归表述为概率模型的这种方法可以推广到向量输入 **x** 和目标向量 y。

# 线性和曲线回归

给定训练数据集 `{(xi, yi)}`，目标是找到一个*线性*函数 `f` 使得 `f(xi) ≈ yi`，对所有 `i` 成立，即 `f(xi)` 近似 `yi`。这个 `f` 将被称为线性回归模型。因此，`f` 采取形式 `f(x) = w0 + w1*x1 + ... + wm*xm`，其中 `w0` 称为*偏置*。所有这些 `wi` 共同表示为向量 `w = (w0, w1, ..., wm)`。

现在，训练数据集是从大总体中抽取的大小为 N 的样本。一个好的模型是能够很好地泛化到大部分总体，而不仅仅针对这个训练样本。我们将对总体做一些假设：

*   **线性**：`x` 与 y 的均值之间的关系是线性的。如下图所示，y 值散布在一条均值线周围。“回归”意味着向后退，向平均值靠拢。函数 `f` 对目标 y 的平均值建模。
*   **同方差性**：如 *[图 5.4](#c05.xhtml#fig5_4)* 所示，目标 y 值围绕均值线的散布是恒定的，而不是 x 的函数，即*残差或误差* `|f(x) – y|` 的方差对于任何 `x` 值都相同。
*   **误差正态性**：对于任何固定的 **x** 值，目标 y 服从正态分布，即残差服从正态分布。
*   **误差无自相关**：残差（误差）项之间不应存在相关性。自相关的存在可能会大幅降低模型的准确性。
*   **无多重共线性**：数据向量 `x` 的分量，即自变量，不应相关。如 *[图 5.4](#c05.xhtml#fig5_4)* 所示，回归模型可以视为分布 `y ~ N(f(x), σ²)` 或等价地 `ε ~ N(0, σ²)`。请参阅下图：

![](images/linear-regression.jpg)

**图 5.4：** *正态性假设和直线周围的恒定方差*

让我们看看该模型是否满足前面提到的假设。基于假设 1，`E[y|x]` 可以视为 **x** 的线性函数，即 `E[y|x] = w0 + w1*x1 + ... + wm*xm`。这里，`σ²` 是一个未知常数，表示假设 2 中的恒定散布。残差或误差项 `ε = y - f(x)`，满足假设 3。假设 5 期望向量的所有分量不相关。我们可以通过一些特征工程来确保这一点，即使用前面讨论的固定基函数来转换数据，从而得到 `φ(x) = (φ0(x), φ1(x), ..., φM(x))`，其中 `f(x) = w0*φ0(x) + w1*φ1(x) + ... + wM*φM(x)`。
