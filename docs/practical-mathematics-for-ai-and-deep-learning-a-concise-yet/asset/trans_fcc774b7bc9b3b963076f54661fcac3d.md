
现在，让我们获取高斯函数的离散近似，它可以作为卷积操作中的核用于图像处理。为简化问题，让我们考虑零均值 `μ=0` 和标准差 `σ=1`。有了这些值，函数变为如下形式：

`G(x, y) = (1 / (2πσ²)) * exp(-(x² + y²) / (2σ²))`

编写代码时，仅考虑函数的变量部分 `exp(-(x² + y²) / 2)`。以下代码展示了实现。它从二维空间接受 `(x, y)` 坐标值，并输出高斯函数变量部分的值：以下代码展示了二维高斯函数的实现。

```
1. import numpy as np
2. def gaussian_fn_2d(x, y):
3.     # 高斯函数的指数部分 均值=0, 标准差=1
4.     exp_part = np.exp(-(np.power(x, 2.) + np.power(y, 2.)) / 2.)
5.     return exp_part
```

**代码 9.4：** 二维高斯函数

如前所述，考虑 `3σ` 矩阵已足够。我们需要奇数阶矩阵，因此对于 `σ=1`，应考虑 7×7 矩阵。用于离散化的函数参数值应在距离原点 3σ 范围内。我们可以考虑 *[图 9.9](#c09.xhtml#fig9_9)(a)* 所示的 `(x, y)` 值，用于核矩阵。这些坐标值用于核矩阵，如以下代码所示：

```
1. # 距离原点 3 sigma
2. X_START = Y_START = -3
3. X_STOP = Y_STOP = 3
4. def get_gaussian_kernel():
5.     kernel_shape = (X_STOP - X_START + 1, Y_STOP - Y_START + 1)
6.     gaussian_sample = np.zeros(shape=kernel_shape, dtype=float)
7.     ker_x = ker_y = 0
8.     for y_idx in range(Y_START, Y_STOP + 1):
9.         for x_idx in range(X_START, X_STOP + 1):
10.            gaussian_sample[ker_x][ker_y] = gaussian_fn_2d(x_idx, y_idx)
11.            ker_y = ker_y + 1  # 更新索引
12.        ker_x = ker_x + 1  # 更新索引
13.        ker_y = 0
14.    return gaussian_sample
15. # 获取高斯核并归一化
16. gaussain_ker = get_gaussian_kernel()
17. div_part = 2. * np.pi
18. norm_gauss_kernel = (1. / div_part) * gaussain_ker
```

**代码 9.5：** 获取距离原点等距离的少数坐标的高斯函数值

使用该代码获得的核矩阵记录在 *[图 9.9](#c09.xhtml#fig9_9)(b)* 中。注意它未经过归一化。请参考下图：

**图 9.9：** **(a)** *创建二维核所考虑的 (x,y) 坐标* **(b)** *μ=0, σ=1 下未归一化的高斯核*

前述高斯核的归一化可通过两种方式执行。一种方法是将核的所有值除以高斯函数的常数部分，即 `1 / (2πσ²)`（情况：**μ=0, σ=1**）。由于核尺寸有限，核的所有值之和可能不等于 `1 / (2πσ²)`（**μ=0, σ=1**）。我们可以采用另一种方法，即将核的所有值除以核所有元素的总和。第二种方法更好。

## 基于图像导数的核

让我们首先了解导数在恒定强度、阶跃和斜坡强度不连续性/斜坡的开始与结束处的行为。 *[图 10.13](#c10.xhtml#fig10_13)* 绘制了像素强度图，描绘了强度斜坡和阶跃。

在图像中，沿一个维度，像素 `x` 的邻域像素为 `x + 1` 和 `x - 1`。利用此信息，一维函数的一阶导数基本定义如下：

`f'(x) = f(x + 1) - f(x)`

一阶导数的性质如下：

*   在恒定强度区域为零
*   在强度斜坡/阶跃的开始和结束处非零
*   沿强度斜坡非零

类似地，二阶导数的定义如下：

`f''(x) = f(x + 1) + f(x - 1) - 2f(x)`

二阶导数的性质如下：

*   在恒定强度区域为零
*   在强度斜坡/阶跃的开始和结束处非零
*   沿强度斜坡为零

*[图 9.13](#c09.xhtml#fig9_13)* 显示了强度值的一阶和二阶导数。我们可以验证这些导数的性质。导数提供了关于恒定强度、斜坡上升/下降和阶跃强度的信息。数字图像中的边缘表现得像斜坡强度。识别这些斜坡将有助于我们寻找边缘，从而辅助图像锐化。接下来，我们将使用二阶导数进行图像锐化。请参考下图：

## 拉普拉斯核——二阶导数

最简单的各向同性（在所有方向均等适用）导数算子是*拉普拉斯算子*，对于二元函数定义如下：

`∇²f = ∂²f/∂x² + ∂²f/∂y²`

由于任何阶导数都是线性的，拉普拉斯算子是线性算子。我们需要将该算子以离散格式表示用于二维图像，如下所示：

`∇²f(x, y) = f(x+1, y) + f(x-1, y) + f(x, y+1) + f(x, y-1) - 4f(x, y)`

离散化的拉普拉斯算子可写为：

```
0  1  0
1 -4  1
0  1  0
```
