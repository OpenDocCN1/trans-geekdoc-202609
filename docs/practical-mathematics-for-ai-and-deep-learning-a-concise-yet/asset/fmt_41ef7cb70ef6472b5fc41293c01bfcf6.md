# 单位矩阵

*单位矩阵*表示为 `I[n]`，是一个 `n x n` 矩阵，其对角线元素等于 1，所有其他元素为零。任意方阵 `S[n]` 乘以同维度的单位矩阵 `I[n]` 结果仍为矩阵 `S[n]`；因此，`I[n]` 称为单位矩阵。`I[n]` 是矩阵乘法的单位元。

![](images/109.jpg)

# 对称矩阵

*对称矩阵*是等于其转置的方阵，即 `A = A^T`。换句话说，若 `a[xy] = a[yx]`（其中 `1 ≤ x, y ≤ m`），则矩阵 `A[m]` 为对称矩阵。所有单位矩阵均为对称矩阵。*图 2.9* 中所示的向量间距离即为对称矩阵。

![](images/110.jpg)

对称矩阵 `A`、`B` 的性质：

*   `A + B` 和 `A - B` 结果为对称矩阵
*   `A^n` 对 `n ∈ Z` 为对称矩阵
*   `A^(-1)` 为对称矩阵

# 反对称矩阵

*反对称矩阵*是等于其转置负值的方阵，即 `A = -A^T`。换句话说，若 `a[xy] = -a[yx]`（其中 `1 ≤ x, y ≤ m`），则方阵 `A[m]` 为反对称矩阵。根据定义，反对称矩阵的所有对角线元素均为零。所有单位矩阵均非反对称矩阵，因为其对角线元素非零。以下是几个示例：

![](images/111.jpg)

反对称矩阵 `A[m]`、`B[m]` 的性质：

*   `kA[m]` 为对称矩阵，其中 `k ∈ R`
*   `A + B` 为反对称矩阵
*   `A + I` 总是可逆的

# 可逆矩阵

*可逆矩阵* / *非奇异矩阵* / *非退化矩阵* `A[n]` 是一个方阵，且存在矩阵 `B[n]` 使得：

`AB = BA = I[n]`

其中 `I[n]` 为单位矩阵，乘法为普通矩阵乘法。在这种情况下，矩阵 `B` 由 `A` 唯一确定，表示为 `A^(-1)`。不可逆的方阵称为*奇异矩阵*或*退化矩阵*。

问题：矩阵的逆在什么条件下存在？

*可逆矩阵定理*指出，实方阵 `A[n]` 可逆*当且仅当*满足以下任一条件：

*   `A[n]` 与单位矩阵 `I[n]` 行等价
*   `A[n]` 与单位矩阵 `I[n]` 列等价
*   `A[n]` 有 `n` 个主元位置（矩阵中的主元位置是指对应于矩阵简化行阶梯形中主元 1 的位置）
*   `rank(A[n]) = n`，即 `A[n]` 的秩为满秩
*   方程 `Ax = 0` 只有平凡解 `x = 0`（零向量）
*   方程 `Ax = b` 对任意 `b ∈ R^n` 恰好有一个解
*   `A` 的列向量线性无关
*   列空间 `C(A) = R^n`
*   `A` 的列向量构成 `R^n` 的一组基
*   存在 `B[n]` 使得 `AB = BA = I[n]`
*   矩阵的转置 `A^T` 可逆
