

# 零空间

当 `b` 为零向量时，解的表现如何？

所有使得 `Ax = o` 的 `x ∈ R^n` 的可能值，其中 `o` 是 `R^m` 中的零向量，构成了矩阵 `A` 的*零空间*，记作 `N(A)`。零空间在通常的加法和数乘定义下是一个向量空间（验证过程留给读者作为练习）。让我们将 `Ax` 表示为点积形式，其中 `r[i]` 表示矩阵 `A` 的第 `i` 行。`x` 与所有行 `r[k]` 的点积结果应为 0。这表明 `x` 应正交于 `A` 的所有行。

![](images/142.jpg)

这意味着零空间 `N(A)`（`R^n` 的子空间）正交于 `A` 的行空间（`R^n` 的子空间）。如果想要在 `R^n` 中寻找解，则搜索应限制在 `Ax = o` 的子空间内，该子空间正交于 `A` 的行空间，记作 ![](images/143.jpg)。

类似地，可以将矩阵 `A` 的*左零空间*分析为 `x^T A = o^T`，其中 `o` 是 `R^n` 中的零向量且 `x ∈ R^m`。这等价于表示为 `A^T x = o`。*左零空间*是所有使得 `A^T x = o` 成立的 `x ∈ R^m` 的可能解，记作 `N(A^T)`。`N(A^T)` 是 `R^m` 的子空间，将正交于 `C(A)` 即 `A` 的列空间。

# 子空间间的正交性

对于任意给定的实矩阵 `A[mxn]`，存在四个基本子空间，其性质概括如下：

*   列空间 `C(A) ⊆ R^m`
*   行空间 `C(A^T) ⊆ R^n`
*   零空间 `N(A) ⊆ R^n`
*   左零空间 `N(A^T) ⊆ R^m`
*   `A` 的列空间正交于左零空间 `N(A^T) ⊥ C(A)`
*   `A` 的行空间正交于零空间 `N(A^T) ⊥ N(A)`

其中 `j` 为列号，`a[i,j]` 是 `A` 的第 `i` 行第 `j` 列的元素，`M[i,j]` 称为*余子式*，是去掉 `A` 的第 `i` 行和第 `j` 列后得到的子矩阵的行列式。项 `C[ij] = (–1)^(i+j) M[ij]` 称为矩阵 `A` 中 `a[i,j]` 的*代数余子式*。此操作递归应用，直到 `M` 的维度减少到 1x1。

递归地，可以求得任意 `nxn` 矩阵的行列式。任意 `nxn` 方阵的行列式和实标量值 `k ∈ R` 具有以下性质：

*   单位矩阵的行列式为 1，`det(I[n]) = 1`
*   交换两行（两列）时，行列式的值保持不变，但符号（+/-）改变
*   若将一行（列）的标量倍数加到另一行（列）上，行列式不变
*   若某行或某列乘以 `k`，行列式乘以 `k`
*   `det(kA) = k^n det(A)`
*   `det(A) = 0` 当且仅当 `A` 不可逆，或有相关行（列），或其 `rank(A) < n`。换句话说，`det(A) ≠ 0` 当且仅当 `A` 可逆
*   若矩阵是三角矩阵，则其行列式等于对角线元素的乘积
*   `det(AB) = det(A) * det(B)`
*   `det(A^T) = det(A)`
