# 序列分类

序列分类是一种预测建模问题，给定一个观测序列，任务是为该序列预测一个类别。序列分类有广泛的应用，如基因组分析、信息检索、健康信息学、金融、异常检测、手势识别和动作识别。

序列可能带有类别标签。例如，心电图数据的时间序列可能来自健康人或患病者。DNA 序列可能属于基因编码区或非编码区。一段文本可以被视为单词序列。电影评论是单词序列，可以是正面或负面的。这些都是二分类序列分类问题的例子。

序列分类的典型架构是使用 RNN 将变长序列输入编码为一个固定大小的向量。这充当序列的特征向量，通过一系列全连接层，后接 softmax 层进行分类。[图 10.14](#c10.xhtml#fig10_14) 描述了这一点：

![](images/Image47325.jpg)

**图 10.14：** 典型序列分类架构

RNN 仅按前向方向处理序列。对于某些序列（如文本），可能需要看到当前单词后面的单词以获取更多上下文。在语音识别中，如果我们查看未来的音素而不仅仅是已经发出的音素，音素的分类效果会更好。这符合人类理解语言的方式。很多时候，我们只有在听到下一个单词甚至句子结束后，才能理解说话者说出的单词。下一节讨论的**双向 RNN** 可以从两个方向处理序列以提取更好的序列特征。

# 双向 RNN

**双向 RNN (BRNN)** 从两个方向处理序列。通常，使用两个独立的 RNN：一个用于前向方向，一个用于反向方向。这会产生来自每个 RNN 的隐藏状态，通常将它们连接起来形成单个隐藏状态。前向和反向 RNN 之间不交互；它们可以像标准 RNN 一样进行训练。这在[图 10.15](#c10.xhtml#fig10_15) 中展示：

![](images/Image47333.jpg)

**图 10.15：** 双向 RNN

可以堆叠多层 BRNN 以用于更复杂的序列分类任务。BRNN 用于许多其他序列建模任务，如语音识别、手写识别和序列异常检测。

# 序列到序列

**序列到序列建模** 是关于训练模型将一个领域的序列转换为另一个领域的序列。以下是 Seq2Seq 建模的几个例子：

*   手写识别
*   语言翻译：英语句子翻译成法语
*   语音识别：音频转文本记录
*   视频字幕生成
*   问答：聊天机器人
*   文本转语音
*   文本转手写墨迹坐标

在所有这些例子中，输入序列和输出序列具有不同的长度。虽然 RNN 模型是强大的序列学习模型，但在许多实际问题中，如手写体（草书）识别、语音识别和手势识别，输入是*未分段*的。例如，在草书手写识别中，存在**塞尔悖论**：草书单词如果不分段就无法识别，如果不识别就无法分段。这意味着基于字符分段的大多数 OCR 系统无法直接用于草书手写识别。[图 10.16](#c10.xhtml#fig10_16) 解释了手写识别中未分段的输入：

![](images/Image47344.jpg)

**图 10.16：** 序列到序列中的对齐问题

因此，主要问题是*输入到输出的对齐*，即手写图像的哪一部分对应一个字符，或者语音信号的哪一段对应一个字符。如果有一种方法对输入进行分段，基于简单 RNN 的架构就足以构建模型，但这里并非如此。这一领域的首次突破由 Alex Graves 于 2006 年 [7] 完成，他引入了**连接主义时序分类**，这是一种*无需对齐*的技术，解决了这个问题。直到 2015 年，Google 才引入了一种新颖的神经网络架构 [8] 来应对这一挑战。

# 连接主义时序分类

**连接主义时序分类 (CTC)** 的思想是消除对显式对齐的需求，即将问题重新定义为一个*输入和输出序列长度相同*的无对齐问题。输入首先被分割成大小相等的片段，以便从原始音频/图像获得序列输入。对于每个片段，我们必须有一个目标标签。例如，考虑[图 10.17](#c10.xhtml#fig10_17) 中所示的手写示例：
