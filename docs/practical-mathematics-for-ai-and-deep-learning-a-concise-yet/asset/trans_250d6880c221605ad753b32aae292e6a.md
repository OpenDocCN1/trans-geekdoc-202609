

第一部分 ![](images/2817.jpg) 是一个期望 ![](images/2818.jpg)。这可以通过从 `p(x|z)` 中采样并取平均来近似。假设 `p(x|z)` 是多元高斯分布。![](images/2819.jpg) 作为一个神经网络，是完全确定性的，因此，我们可以将 `p(x|z)` 写为 `p(x|![](images/2820.jpg))`。`p(x|![](images/2820.jpg))` 由于是高斯分布，将包含一个指数项 ![](images/2822.jpg)，因此，`log(p(x|z))` 将包含平方误差项 ![](images/2823.jpg)。所以，第一部分在概念上表示重构误差，正如我们在自编码器中所见。我们也可以将其实现为逐像素的交叉熵损失，就像我们对普通自编码器所做的那样，如下面的代码所示：

```
1. '''以下代码仅在提供来自 AE 的有效数据和重构张量时运行'''
2. '''作为平方和'''
3. reconstruction_loss = tf.reduce_mean(
4.     tf.square(tf.norm(data - reconstruction))
5. )
6. '''作为逐像素二元交叉熵损失'''
7. reconstruction_loss = tf.reduce_mean(
8.     tf.reduce_sum(
9.         tf.keras.losses.binary_crossentropy(data, reconstruction),
10.         axis=(1, 2)
11.     )
12. )
```

用于生成潜在分布 `q(z|x)` 的网络的第一部分称为编码器，第二部分从 `z` 的采样中生成数据点，称为解码器。我们拥有类似自编码器的编码器-解码器架构，因为编码器的输入和解码器的输出都预期是相同的 `X`，即 ![](images/2824.jpg)。

对于训练，[*图 12.8*](#c12.xhtml#fig12_8) 中所示的网络首先计算前向传播以创建重构输入 ![](images/2825.jpg)，然后计算重构损失。重构损失的导数被反向传播。

*   **前向传播**：输入 `X`，生成 ![](images/1041.jpg)，![](images/2827.jpg)。然后，从 ![](images/2828.jpg) 中采样向量 `z` 并将其前向传递以生成 ![](images/2825.jpg)。
*   **反向传播**：计算重构误差 ![](images/2830.jpg) + kl-损失（如下面的代码所示）并反向传播误差导数。

为了在前向传播中实现采样，我们必须使用一个称为“重参数化”的技巧。因此，我们可以使用任何标准深度学习框架来实现这一点。除了大小为 `n` 的一批数据 `X`，我们还将随机采样 `n` 个噪声向量 ![](images/2831.jpg) ~ `N(0,1)`。在前向传播期间，我们将计算 `z` 为 ![](images/2832.jpg)，其中 ![](images/2833.jpg) 表示逐元素乘法。因此，编码器块接收一批 `X` 和一批噪声向量 `z` 作为输入，并输出三元组 (`z_mean`, `z_log_var`, `z`)，如下面的代码所示。对于重参数化，我们需要 ![](images/1046.jpg)，但我们有 ![](images/2835.jpg)。所以，我们必须将 `z_log_var` 转换为 `tf.exp(0.5 * z_log_var)`。

```
1. def vae_encoder(latent_dim):
2.     epsilon = layers.Input(shape=latent_dim)
3.     img = layers.Input(shape=(28, 28, 1)) # For MNIST
4. 
5.     x = layers.Conv2D(filters=32, kernel_size=3,
6.                       strides=2, padding='same')(img)
7.     x = layers.LeakyReLU(0.2)(x)
8.     x = layers.Conv2D(filters=64, kernel_size=3,
9.                       strides=2, padding='same')(x)
10.     x = layers.LeakyReLU(0.2)(x)
11.     x = layers.Flatten()(x)
12.     x = layers.Dense(16, activation="relu")(x)
13.     z_mean = layers.Dense(latent_dim, name="z_mean")(x)
14.     z_log_var = layers.Dense(latent_dim, name="z_log_var")(x)
15.     z = z_mean + tf.exp(0.5 * z_log_var) * epsilon
16.     return Model(inputs=[img, epsilon], outputs=[z_mean, z_log_var, z])
```

变分解码器可以使用反卷积算子实现，如下面的代码所示。解码器接收由编码器创建的样本 `z ~ q(z|x)` 并重现 `X`。如果我们对图像数据使用 `[0, 1]` 范围内的归一化像素输入值，则可以在解码器的最后一层应用 `sigmoid` 激活函数，以获得重构图像的归一化像素值；请参考下面代码中的 *第 12 行*：

```
1. def vae_decoder(latent_dim):
2.     z = layers.Input(shape=(latent_dim,))
3.     x = layers.Dense(7 * 7 * 64, activation="relu")(z)
4.     x = layers.Reshape((7, 7, 64))(x)
5.     x = layers.Conv2DTranspose(filters=64, kernel_size=3,
6.                                strides=2, padding="same")(x)
7.     x = layers.LeakyReLU(0.2)(x)
8.     x = layers.Conv2DTranspose(filters=32, kernel_size=3,
9.                                strides=2, padding="same")(x)
10.     x = layers.LeakyReLU(0.2)(x)
11.     decoder_outputs = layers.Conv2DTranspose(1, 3,
12.                                activation="sigmoid", padding="same")(x)
13.     return Model(z, decoder_outputs)
```

VAE 的解码器部分可以用作生成模型。我们可以从先验分布 `p(z)`（即单位高斯分布）中选择任意 `z`，然后解码 `z` 以生成样本图像。请注意，我们不再需要限制 `z`，因为这仅用于训练解码器。取潜在维度 = 2 并从左下角 [-1, -1]、右上角 [1, 1] 的正方形单位网格中采样 `z`，我们可以在二维网格中可视化生成的数字，如 [*图 12.9*](#c12.xhtml#fig12_9) 所示。网格中数字的位置代表用于生成该数字的样本 `z` 的位置。

## 生成对抗网络

**生成对抗网络**（**GANs**）是另一类生成模型，由 Ian Goodfellow 于 2014 年 6 月设计。与普通 VAE 相比，GANs 用于图像生成时可以产生更高质量的图像。GANs 不尝试进行任何显式的密度估计，并且通过条件 GANs，我们可以强制生成器输出所需类别的数据。GAN 架构由两个组件组成：一个生成器和一个判别器。生成器 `G` 接收来自已知分布的随机向量 `z`，将其转换为数据点 `X`。判别器 `D` 是一个二分类器，输出数据点 `X` 来自真实数据集的概率。如果我们呈现一个使用生成器 `G` 合成的假 `X`，那么 `D` 应该输出一个非常低的分数。`G` 和 `D` 都是随机初始化权重的神经网络。这两个网络不断地相互更新，变得比对方更聪明。在实践中，它们是一次训练一个的。保持 `G` 的权重固定，更新 `D` 的权重若干步。然后反过来，保持 `D` 的权重固定，更新 `G` 若干步。
