# 零特征值的存在性

在什么条件下，方阵会有零特征值？

特征向量 `e` 的定义指出，它是一个非零向量，当变换 `A` 应用于它时，按标量因子 `λ` 发生变化。对应的标量因子称为其特征值。根据定义：

![](images/205.jpg)

因为 `e` 是非零向量，`N(A)` 应包含非零向量，这仅当 `rank(A[n]) < n` 时可能 ⇒ 矩阵至少有一个相关的列/行。如果零子空间的维数大于零，即 `dimension(N(A)) > 0`，特征值 `λ = 0` 将会重复。此外，零特征值重复的次数将等于 `dimension(N(A))`。

# 对称矩阵的特征属性

对称矩阵因其特征值和特征向量的以下性质而显得重要：

*   实对称矩阵的特征值总是实数。
*   对称矩阵 `A[n]` 恰好存在 `n` 个特征值（不必互不相同）。
*   存在 `n` 个特征向量，分别对应每个特征值，且它们两两正交。

注意，对于实向量 `x`，`Q(x)` 是一个标量或实数。如果实数 `Q(x) = x^T A x` 对每个非零实列向量 `x` 均为正，则称实对称矩阵 `A` 为 *正定*。正定矩阵用符号 `A ≽ 0` 表示。

设 `v` 为正定矩阵 `A` 任一特征向量（它总是非零）对应于特征值 `λ` 的特征向量。则有 `Av = λv`。因此，`Q(v) = v^T (λv) = λv^T v = λ‖v‖² > 0`。此处，`‖v‖` 表示欧几里得范数，且 `‖v‖² > 0` 恒成立。所以，`λ > 0`，即正定矩阵的特征值均为正。

如果 `A ≽ 0`，则集合 `ε = {x : Q(x) < 1}` 称为 `R^n` 中的 *椭球体*。*椭球体* 是椭圆在 `n` 维空间的推广。二维椭圆有两条轴：一条称为 *长轴*，另一条称为 *短轴*，如 *[图 2.20](#c02.xhtml#fig2_20)* 所示：

![](images/Image39720.jpg)

**图 2.20：** *椭球体*

![](images/212.jpg)

如果我们将对应于特征值的特征向量 `q[1], q[2], …, q[n]` 按特征值递减顺序排列为 `λ[1] ≥ λ[2] ≥ … ≥ λ[n]`，则 `x^T A x` 的值在 `q[1]` 方向上较大。因此，椭球体在 `q[1]` 方向上细长。这是长轴的方向。在 `q[n]` 方向上，`x^T A x` 的值较小，所以椭球体在 `q[n]` 方向上扁胖。我们将在 [*第 4 章 基础统计与概率论*](#c04.xhtml) 引入多元高斯分布时再次遇到这些椭球体。
