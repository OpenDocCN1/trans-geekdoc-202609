# 函数的导数

函数在某一点的导数表示该函数在该点的变化率。求导数的过程称为*求导*。

**定义**：函数 `f` 在 `x_0` 处的*右导数*（其中 `x_0` 是函数定义域内的一点）定义为函数在点 `x_0` 右侧邻域内的变化率。*变化率*是函数值的变化量与 `x` 值在轴上向 `x_0` 右侧发生微小变化（设为 `x_0 + h`，其中 `h` (>0) 很小）的比值。变化率由下式给出：

```
(f(x_0 + h) - f(x_0)) / h
```

该比值代表割线的斜率，如 *[图 3.4](#c03.xhtml#fig3_4)* 所示：

![](images/Figure-3.4.jpg)

**图 3.4：** *导数与切线*

随着 `h` 变得非常小，这条割线趋于成为 `x_0` 处的切线。函数图像在点 `(x_0, f(x_0))` 处的这条切线的斜率即为函数 `f` 在 `x_0` 处的右导数，正式写作：

```
f'_+(x_0) = lim_{h->0+} (f(x_0 + h) - f(x_0)) / h
```

我们称此为 `x_0 + h`，因为 `x_0 + h` 在 `x_0` 的右侧。类似地，我们可以定义左导数 `f'_-(x_0)` 为：

```
f'_-(x_0) = lim_{h->0+} (f(x_0) - f(x_0 - h)) / h
```

对于轴上 `x_0` 左侧的任意点 `x_0 - h`。

当且仅当函数 `f` 在 `x_0` 处同时具有右导数和左导数，且这两个导数相等时，*函数 f 在 `x_0` 处可导*。这意味着函数图像在 `x_0` 邻域内是光滑的，即如果你取 `x_0` 邻域内函数的一段极小线段，可以用一条小线段来近似它。这就是可导函数也被称为光滑函数的原因。现在，如果函数可导，我们可以将导数重写为对称差商形式：

```
f'(x_0) = lim_{h->0} (f(x_0 + h) - f(x_0 - h)) / (2h)
```

**示例**：（幂函数）幂函数 `f(x) = x^n` 的导数可使用通用导数公式计算：

```
f'(x) = lim_{h->0} ((x+h)^n - x^n) / h
```
```
= n x^{n-1}
```

利用导数的定义，我们可以计算大多数常见数学函数（如三角函数、对数函数、指数函数）的导数。然而，在实践中，我们会遇到许多由这些函数的和、积及复合构成的函数，如 `f(x) = log(2 + sin(x))`。为了计算此类复杂函数的导数，我们使用以下求导法则：

1.  导数是线性算子：

    ```
    (a f(x) + b g(x))' = a f'(x) + b g'(x)
    ```

2.  导数的乘积法则：

    ```
    (f(x) g(x))' = f'(x) g(x) + f(x) g'(x)
    ```

3.  导数的链式法则（用于函数复合）：

    ```
    (f(g(x)))' = f'(g(x)) g'(x)
    ```

**示例**：Sigmoid 函数定义为：

```
\sigma(x) = 1 / (1 + e^{-x})
```

设 `u = 1 + e^{-x}` 且 `y = 1/u`。因此，`\sigma(x) = y`。应用链式法则：

```
d\sigma/dx = dy/du * du/dx = (-1/u^2) * (-e^{-x}) = e^{-x} / (1 + e^{-x})^2
```

因此，`\sigma'(x) = \sigma(x) (1 - \sigma(x))`

**示例**：*tanh* 函数定义为：

```
\tanh(x) = (e^x - e^{-x}) / (e^x + e^{-x})
```

应用导数的乘积法则和链式法则，tanh 的导数可求得如下：

```
\tanh'(x) = 1 - \tanh^2(x)
```
```
= \text{sech}^2(x)
```

这些导数是针对 `f` 定义域内的任意一点计算的，我们可以在 *[图 3.5](#c03.xhtml#fig3_5)* 中直观地看到它们的图像：

![](images/Figure-3.5.jpg)

**图 3.5：** *作为函数的导数*

接下来，我们陈述几个关于可导函数的有用定理。

**定理**：可导函数是连续的，但反之不成立。

**示例**：设 `f(x) = |x|`。在 `x=0` 处，此外，`f` 在 `x=0` 处连续

```
f'_+(0) = 1 and f'_-(0) = -1
```

因为 `f'_+(0) != f'_-(0)`，所以 `f` 在 `x=0` 处不可导。可导性意味着光滑性。在 `x=0` 处，`|x|` 的图像有一个尖角。方向改变了 90 度。因此，从几何上看，我们可以看到 `|x|` 在 0 处的不可导性，所以函数的连续性并不总能保证可导性。

**中值定理（拉格朗日）**：设 `f` 在 `[a, b]` 上连续，且在 `(a, b)` 内每一点可导。则至少存在一点 `c \in (a, b)` 使得：

```
f'(c) = (f(b) - f(a)) / (b - a)
```

**罗尔定理：** 设 `f` 在 `[a, b]` 上连续，且在 `(a, b)` 内每一点可导。若 `f(a) = f(b)`，则至少存在一点 `c \in (a, b)` 使得 `f'(c) = 0`。

*[图 3.6](#c03.xhtml#fig3_6)* 形象地描绘了这两个定理：

![](images/Figure-3.6.jpg)

**图 3.6：** ***导数定理：（左）*** *从 f(a) 到 f(b) 的割线斜率由 `(f(b) - f(a)) / (b - a)` 给出，`c` 处的切线与此割线平行。* ***（右）*** *因为 f(a)=f(b)，函数必须在某处折返，在该点导数为 0。*

# 高阶导数

函数 `f` 的导数本身也是一个函数。我们用 `f'(x)` 表示它。设 `f(x) = x^3`。则 `f'(x) = 3x^2`。因此，我们可以计算导函数的导数：

```
f''(x) = 6x
```

这称为*二阶导数*。因此，对于该函数，我们有 `f'''(x) = 6`。导函数可求导任意次数以获得 *n^(th)* 阶导数。这用以下符号表示：

```
f^{(n)}(x)
```

请参考下图：

![](images/Figure-3.7.jpg)

**图 3.7：** *高阶导数*

高阶导数有许多应用，如函数逼近和寻找有界函数的最大值或最小值。我们将简要介绍利用高阶导数的泰勒级数展开。

# 泰勒级数展开

如果实值函数满足以下条件：

*   函数应可求导任意次数
*   函数应在给定点 `a` 处有定义

则，

```
f(x) = f(a) + f'(a)(x-a) + f''(a)(x-a)^2/2! + f'''(a)(x-a)^3/3! + ...
```

这称为函数 `f` 在点 `a` 处的*泰勒级数展开*。这是一个无限级数，即该级数的项数无限，用求和符号更正式地表示如下：

```
f(x) = \sum_{n=0}^{\infty} f^{(n)}(a) (x-a)^n / n!
```

现在，如果我们取 `x` 足够接近点 `a`，则多项式 `(x-a)^n` 对于 `n > 2` 的高次项变得可以忽略不计并可被忽略。

一般来说，对于任意点 `x`，我们可以用有限项来近似 `f(x)`。假设 `f` 在 `a` 的邻域内可导 `n` 次；我们可以只考虑含 `n` 项的泰勒多项式。此近似会有一个误差，与 `x` 到 `a` 的距离成正比，由 `R_n(x) = f^{(n+1)}(c) (x-a)^{n+1} / (n+1)!` 给出，其中 `c` 是 `a` 和 `x` 之间的某一点。这称为*拉格朗日余项*。带拉格朗日余项的二阶泰勒多项式由下式给出：

```
f(x) = f(a) + f'(a)(x-a) + f''(c)(x-a)^2 / 2
```

**示例**：`f(x) = e^x` 且设 `a = 0`。对于 0 邻域内的 `x`：

```
e^x = 1 + x + x^2/2! + x^3/3! + ...
```

或 `e^x \approx 1 + x + x^2/2`
