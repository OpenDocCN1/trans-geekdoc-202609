# 爱因斯坦记号

对高维张量执行张量运算变得非常繁琐且难以编码。爱因斯坦记号由阿尔伯特·爱因斯坦于 1916 年在物理学中引入，用于公式中一组带索引项的求和的紧凑表示。前面讨论的所有张量运算都可以用爱因斯坦求和来表示。此外，使用爱因斯坦记号，许多常见的多维线性代数数组运算可以用简单的方式表示。使用爱因斯坦求和编写的代码具有高度可读性和紧凑性。

爱因斯坦求和接受两部分参数：方程字符串和执行运算的张量。矩阵转置运算的方程字符串示例为 `![](images/534.jpg)`。这里，每个小字母表示张量的一个维度。箭头左侧的所有指标都是输入张量的指标，右侧的指标是输出张量的指标。对于多个输入张量，我们可以用逗号分隔指标。例如，矩阵乘法由方程字符串 `![](images/535.jpg)` 表示。箭头右侧缺失的指标是执行求和的轴，即左矩阵的第 j 行元素与右矩阵的第 k 列对应元素相乘并求和。前面讨论的点积和外积可以使用爱因斯坦求和轻松计算。
