# 随机实验

实验是指产生结果的活动。可能有不同数量的可能结果。例如，掷骰子是一个有六种可能结果的实验。如果一个实验有不止一种可能结果，并且无法预先预测结果（即在实验进行之前），则称为**随机实验**。我们只有在掷骰子之后才知道骰子的结果！

# 事件即集合

*事件*可以看作是*随机实验*的一个结果。对于事件“玩家在游戏中获胜”，实验是“玩家玩一局游戏”。该实验有两种可能结果：玩家赢/输。我们可以将其表示为包含两个事件的集合：{‘玩家赢’，‘玩家输’}。这是与该实验相关的所有可能事件的集合，称为*样本空间*。单元事件或基本事件 {‘玩家赢’} 和 {‘玩家输’} 不能同时发生，称为*互斥事件*。事件的概率用 `P` 表示。

## 基本概率恒等式

若 `A` 和 `B` 为两个事件，则：

*   `P(not A) = P(A') = 1 – P(A)`
*   `P(A ∩ B)' = P(A' ∪ B')`，概率的德摩根定律
*   `P(A ∪ B)' = P(A' ∩ B')`，概率的德摩根定律
*   `P(A ∪ B) = P(A) + P(B) – P(A ∩ B)`
*   `P(A and not B) = P(A ∩ B') = P(A) – P(A ∩ B)`
*   `P(exactly one of A,B) = P((A and Not B)or (B and not A)) = P((A ∩ B’)U (A’ ∩ B)) = P(A) + P(B) – 2P(A ∩ B)`

# 条件独立性

再次以一对骰子为例，设 `A` 表示事件“*第一个骰子显示 1*”，`B` 表示事件“*第二个骰子显示 2*”；则 `A` 和 `B` 显然是独立的：

![](images/960.jpg)

现在，设 `C` 为事件“两个结果之和为 `S`”。那么，在给定 `C` 的条件下，`A` 和 `B` 不再独立。因此，我们称 `A` 和 `B` 为条件依赖：

![](images/961.jpg)

给定其中一个结果并固定两个结果之和 = `S`，我们只能有一种可能的结果：`A|C` = {(1, S-1)} 和 `B|C` = {(S-2, 2)}。因此：

![](images/962.jpg)

所以，`P(A|C)P(B|C) ≠ P(A ∩ B|C)`。

如果满足以下条件，则称两个事件 `A` 和 `B` 在给定事件 `C` 的条件下*条件独立*：

`P(A ∩ B|C) = P(A|C)P(B|C)`

***注意：事件的独立性不意味着条件独立性，正如此处示例所示。同样，条件独立性也不意味着事件的独立性。***
