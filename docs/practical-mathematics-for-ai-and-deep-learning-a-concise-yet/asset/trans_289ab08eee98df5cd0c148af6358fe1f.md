

**四分位距**（**IQR**）由 `Q3 - Q1` 给出。这是比极差更好的度量，因为它使用了 50% 的数据并排除了异常值。该度量通过 John Tukey 提出的一个简单经验法则来剔除数据中的离群值。*Tukey 法则*指出，离群值是指距离四分位数超过 1.5 倍四分位距的值，即低于 `Q1 - 1.5 * IQR` 或高于 `Q3 + 1.5 * IQR` 的值被视为离群值。花萼宽度箱线图在 *[图 4.3](#c04.xhtml#fig4_3)* 中以圆圈形式显示了这些离群值。

*   标准差的 C.D：![](images/906.jpg)，且 ![](images/907.jpg) 称为**变异系数**（**C.V**）

为了比较两个序列的变异性，需计算 C.V，C.V 值较大的序列被认为变异性更大。从鸢尾花数据集四个属性的分布图中可以明显看出，*花萼长度*和*花瓣宽度*的均值差异很大。然而，这两个序列的标准差分别为 0.83 和 0.76，这表明*花萼长度*的变异性大于*花瓣宽度*。这与直方图相矛盾。*花萼长度*似乎变异性小得多。让我们使用 pandas 计算所有序列的 C.V，如下面的代码所示：

# [偏度和峰度](#toc.xhtml#s150a)

数据分布缺乏对称性称为**偏度**。这是通过给定数据分布与对称分布的偏离程度来度量的。当 `mean != mode != median` 时，分布被称为非对称分布。偏度通过差值 `mean - median` 或 `mean - mode` 来度量。

峰度让我们了解数据频率曲线有多尖锐或平坦。它由矩的比率 ![](images/909.jpg) 来度量。该量可以解释如下：

*   `β[2] = 3` 表示正常频率曲线，既不太尖也不太平
*   `β[2] > 3` 表示在均值周围尖锐峰值
*   `β[2] < 3` 表示关于均值平坦且无峰值

*[图 4.5](#c04.xhtml#fig4_5)* 展示了偏度和峰度如何定义分布的形状。如果 `mean > median > mode`，数据分布为***正偏态***。同样，如 *[图 4.5](#c04.xhtml#fig4_5)* 所示，我们可以定义负偏态：

![](images/figure-4.04.jpg)

**图 4.5：** *数据分布的偏度和峰度*

到目前为止讨论的度量可以让我们深入了解观测值的单个属性或特征。这统称为*单变量数据分析*。在实践中，不同变量之间的关系也能提供有趣的见解。例如，在家庭支出研究和商品价格或需求研究中，这两者极有可能一起增加或减少，即它们协变。与实验相关的各种测量的成对分析称为*双变量分析*。在下一节中，我们将讨论如何可视化这些关系以及如何度量它们。

# [相关性](#toc.xhtml#s151a)

如果一个变量的变化影响其他变量的变化，则这些变量**相关**。如果一个变量的增加（或减少）导致另一个变量增加（或减少），则相关称为正相关或直接相关。另一方面，如果一个变量的增加导致另一个变量减少，反之亦然，则相关称为负相关。可以通过绘制两个变量沿 x 轴和 y 轴的散点图来直观检测相关性。例如，我们可以将*花瓣宽度*放在 y 轴，将其他属性（如花萼长度和宽度）放在 x 轴，绘制散点图，如 *[图 4.6](#c04.xhtml#fig4_6)* 所示。
