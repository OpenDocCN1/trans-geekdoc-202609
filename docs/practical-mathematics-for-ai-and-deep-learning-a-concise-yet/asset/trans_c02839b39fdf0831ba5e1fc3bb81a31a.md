***注意：如果我们有一个可微函数 f，在点 x = a 处计算函数 f’(a) 的一阶导数，我们可以用一条直线 y = f(a) + f'(a) 来近似靠近 "a" 处的函数。这种近似在非常接近该点的地方是有效且非常接近的。***

***例如，如果我们取函数 |x|。在任何非零点，该函数都代表一条直线。然而，在 0 处，由于它不可微，无论我们取零点周围多么小的区间，都无法用一条直线来近似该函数。***

到目前为止，我们已经介绍了研究单个实变量函数的几个基本概念。在机器学习中，我们主要会遇到多变量函数。这些实分析概念可以推广到多变量函数。事实上，这种用直线在局部近似可微函数的方法将有助于定义多变量函数的导数。在接下来的章节中，我们将研究多变量函数。

# [标量场与向量场](#toc.xhtml#s108a)

在上一章中，我们研究了从一个线性向量空间 `V` 到另一个向量空间 `W` 的线性变换 ![](images/385.jpg)。设这两个向量空间均为有限维。设定义域空间 `V` 的维度为 `dim(V) = n`，值域空间 `W` 的维度为 `dim(W) = m`。我们根据 `n` 和 `m` 称 `T` 为实值函数、标量场或向量场。这里，`T` 不必是线性函数。

![](images/386.jpg)

*标量场* 表示将 `n` 维空间中的一个点映射到一个实数的函数。例如，如果在大气中的每一点 ![](images/387.jpg) 我们分配一个实数 `f(a)` 来表示 `a` 处的温度，那么函数 `f` 就是一个标量场。当我们从点 ‘`a`’ 移动到空间中的附近点时，标量场会发生变化。在机器学习中，标量场出现在我们训练模型的过程中。模型可以表示为参数空间上的一个标量场。它将每个可能的参数向量映射为相对于给定数据点的总误差值（一个实数）。

# [标量场对向量的导数](#toc.xhtml#s110a)

我们已经看到，一个场的变化方式通常取决于我们远离 `a` 的方向。以温度标量场为例。从 `a` 出发，朝向热源移动时温度升高，远离热源时温度降低。标量场的变化率或导数仅在固定方向上定义。从同一点 `a` 出发但朝不同方向移动，可能会有不同的变化率。
