# 序列生成模型

生成式 LSTM 并非真正的新架构；它更多的是关于模型如何被使用以及对模型从数据中学到什么的解释的视角转变。在这里，我们将简要讨论一个用于手写生成的生成模型。建议您阅读论文“*使用循环神经网络生成序列*” *[13]* 以了解更多内容，如手写生成和文本生成。我们将在这里更详细地讨论手写生成。该模型在 IAMOnline DB *[14]* 上训练，该数据库包含从各位作者那里收集的笔画手写数据，这些作者被要求用手写笔在智能白板上书写。笔画坐标以 XML 格式捕获，如 *[图 10.11](#c10.xhtml#fig10_11)* 所示。这里，XML 中的“stroke”节点表示不抬笔绘制的连续曲线。每个笔画数据的 x、y 笔坐标在所示时间戳处采样。真实文本作为标签附加到笔画坐标数据上。请参考下图：

# 混合密度网络

**混合密度网络 (MDN)** 是一类通过将传统神经网络与混合密度模型相结合而获得的神经网络模型。神经网络的输出被用来参数化一个混合分布。如果使用 RNN 作为神经网络，那么输出分布不仅取决于当前输入，还取决于之前输入序列的历史。 *[图 10.12](#c10.xhtml#fig10_12)* 展示了具有三个混合成分的二元高斯分布的 MDN 层架构。MDN 层中有 6 × 3 = 18 个节点。这里，混合权重输出节点通过 `softmax` 函数进行归一化，以确保它们形成一个有效的类别分布。各种参数成分的其他节点通过合适的函数传递，以保持其值在有意义的范围内。方差应始终为正，因此 ![](images/2549.jpg) 可以通过 `exponential` 激活函数。协方差可以是正或负，但我们不希望它取非常大的值，因此使用 `tanh` 激活函数将其值限制在 \[-1, 1\] 范围内。请参考下图：
