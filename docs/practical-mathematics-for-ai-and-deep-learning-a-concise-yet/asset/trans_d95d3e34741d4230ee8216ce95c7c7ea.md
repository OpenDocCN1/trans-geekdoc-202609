
# 基于划分的聚类算法主要形成硬聚类

基于划分的聚类算法主要形成硬聚类。这类算法的主要局限性在于选择 `k` 的值。接下来，让我们讨论基于密度的聚类，它不需要将 `k` 值作为输入，且离群点无需被分配到任何聚类中。

# 基于密度的聚类

基于密度的聚类算法将高密度区域中的数据样本分配到同一个聚类中。聚类的数量由聚类密度和阈值决定。密度较低的聚类可被视为离群点。这些算法输出的聚类通常是硬聚类。该类别中的流行算法有 `Density-Based Spatial Clustering of Applications with Noise (DBSCAN)` [7]、`Ordering Points To Identify Cluster Structure (OPTICS)` [8]、`Density-based Clustering (DENCLUE)` [9]。

每个聚类将至少包含一个核心点，以及至少 `min_pts – 1` 个从核心点*直接可达*的点。可达性不是对称的，因为只有核心点可以到达非核心点。

让我们定义一种对称关系。如果两点 *p* 和 *q* 从某个公共点（设为 *o*）均是*可达*的，则称它们是*密度连接*的。[图 7.6](#c07.xhtml#fig7_6) 描绘了密度连接的点。根据定义，公共点 *o* 必须是核心点，因为可达性仅针对核心点定义。利用这种对称关系，我们可以定义 DBSCAN 算法形成的聚类。这些聚类满足两个性质：

*   聚类内的所有点相互密度连接。
*   如果一个点从聚类的任意一点是密度可达的，则它必须属于该聚类。请参考下图：

现在让我们编写伪代码：

对于数据集 *D* 中的每个未处理点 *p*：

如果 *p* 是核心点（如 [图 7.5](#c07.xhtml#fig7_5) 所示），则：

*C* = {*q* | *q* 与 *p* 密度连接，给定 ε 和 `min_pts`，其中 *q* ∈ *D*}

将属于 的所有点标记为已处理。

输出聚类 。

否则，将点 *p* 标记为离群点并标记为已处理。

## 选择参数

参数 ε>0 为实数，`min_pts` 为正整数，*distance* 度量是 DBSCAN 的输入。这些参数的选择会影响 DBSCAN 的最终结果。几种选择这些值的方法讨论如下：

*   参数 `min_pts` 影响一个聚类中的点数。值越高，分配到同一聚类的点越多。保持较大的值会导致噪声或离群点被添加到聚类中。较低的值会导致更多的聚类和离群点。
*   ε 的值可以通过绘制每个点到其 `min_pts` 个最近邻的平均距离来选择。这些点的平均 `min_pts` 按升序绘制，ε 的值将是图中出现急剧增长的“拐点”。更多信息请参阅 *References* 部分的 [20]。较低的值会导致大量聚类和大量离群点，而较高的值会导致较少的聚类。
*   *distance* 函数的选择与 ε 值紧密相关。其选择应基于我们要解决的领域问题。

## 优势

DBSCAN 具有以下几个优势：

*   聚类的数量基于输入参数形成。无需像 *k*-means 那样向算法输入聚类数量。
*   它可以发现不同形状的聚类。即使一个聚类被另一个聚类包围，该算法也能工作。
*   它对离群点具有鲁棒性，且对处理点的顺序大多不敏感。

## 局限性

DBSCAN 应用面临的几个挑战如下：

*   如果存在密度差异很大的聚类，性能会下降。
*   性能取决于所使用的距离度量。最常用的度量是欧氏距离。在高维空间中基于欧氏距离选择 ε 值具有挑战性。

# 基于分布的聚类

**基于分布的聚类**基于这样一个假设：如果原始数据映射到多个分布，则属于同一聚类的样本应来自同一个分布。该类别下流行的算法之一是 `Gaussian Mixture Model (GMM)` [10]。

# 高斯混合模型
