
# Recursive Solutions to Large Eigenproblems

A commonly used approach for computing the transitions amplitudes is to approximate the propagator in the Krylov subspace, in a similar spirit to the time-dependent wave packet Krylov. For example, the Lanczos-based QMR has been used for $U(H) = (\hat{E}-H)^{-1}$ when calculating S-matrix elements from an initial channel $\chi_{mn}^{93-97}$. The transitions to all final channels $\chi_m$ can be computed from the “cross-correlation functions,” namely their overlaps with the recurring vectors. Since the initial vector is given by $\chi_{mn}$, only a column of the S-matrix can be obtained from a single Lanczos recursion.

The entire amplitude matrix can be calculated in a straightforward fashion if the complete set of eigenvectors $(E_n, b_n)$ of the total Hamiltonian (H) is known:

```
$C_{mm'} = \sum_n \chi_{mn}^T U(E_n)\chi_{mn'} = \sum_n R_{mmn'} U(E_n) \quad [41]$
```

where $\chi_{mn} = \chi_m^T b_n$ are overlaps between $\chi_m$ and the eigenvectors $b_n$. The quantity $R_{mmn'} = \chi_{mn}^T\chi_{mn'}^{36}$ is referred to as the residue. Recall, that the calculation of eigenvectors with the Lanczos algorithm is typically much more demanding in both CPU and core memory, so one should avoid such calculations as much as possible.

A closer look at Eq. [41] reveals that, in addition to the eigenvalues, only overlaps between the presated states and the eigenvectors of H are needed. Both are scalar quantities. It is thus desirable to develop methods that are capable of efficient and accurate computing of both the eigenvalues and the overlaps but without explicit recourse to eigenvectors.

Such a method was first proposed by Wyatt and co-workers.$43-47,56$ In their so-called residue residue generation method (RRGM), both eigenvalues and overlaps are obtained using the Lanczos algorithm, without explicit calculation and storage of eigenvectors. In particular, the residue in Eq. [41] can be expressed as a linear combination of two residues:

```
$R_{mmn'} = [R_{\pm,n} - R_{\pm,n'}]/2 \quad [42]$
```

where

```
$\chi_{\pm} = (\chi_m \pm \chi_{m'})/\sqrt{2} \quad [43]$
```

```
$R_{\pm,n} = [\chi_{\pm}^T b_n]^2 \quad [44]$
```

The two vectors in Eq. [43] are used to initiate two Lanczos recursions that yield not converged eigenvalues but also the residues $R_{\pm,n}$. In particular, Wyatt and Scott have shown that these residues are the squared first elements of the Lanczos eigenvectors in a K-step recursion:$46$

```
$R_{\pm,n}^{(K)} = |\sum_i |\xi_{li}^{(K)}|^2 \quad [45]$
```

# Single Lanczos Propagation Method

Although improvements to the original RRGM were later proposed,$47,99$ multiple recursions are still needed to generate the full transition amplitude matrix. Clearly, one would like to minimize the length of the recursion because they usually represent the most time-consuming part of the calculation. One method has recently been suggested by Chen and Guo.$38,100$ The premise of this so-called *single Lanczos propagation* (SLP) method is that projections of all prespecified states onto the eigenvectors can be obtained from a single Lanczos recursion starting with an arbitrary initial state. As result, SLP would be more efficient in calculating the entire transition amplitude matrix. We note that a closely related idea implemented with the Chebyshev recursion was proposed by Modelshantam,$101$.

To illustrate the principles of SLP, we note that a Lanczos recursion initiated by an arbitrary vector $\mathbf{q}_1$, can, in exact arithmetic, yield not only the eigenvalues of $\mathbf{H}$, but also overlaps of prespecified vectors with eigenvectors, as follows:

```
$$c_{m,n}^{(K)} = \sum_k z_{kn}^{(K)} \lambda_{mk} \mathbf{q}_k^T = \sum_k z_{kn}^{(K)} c_{m,k}^{(K)} \quad [46]$
```

where $c_{m,k} = \mathbf{z}_m^T \mathbf{q}_k$ can be loosely regarded as correlation functions. This expression can be considered as a spectral method in which the spectrum $(c_{m,n}^{(K)})$ is obtained from the "correlation function" $(c_{m,k})$ by a transformation $(Z)$, which is reminiscent of the Chebyshev spectral method that will be described below. Unlike the Chebyshev spectral method, however, there is no restriction on the initial state. In fact, in the special case we have

```
$$c_{m,n}^{(K)} = \sum_k z_{kn}^{(K)} \lambda_{mk} \mathbf{q}_k^T = \sum_k z_{kn}^{(K)} c_{m,k}^{(K)} \quad [46]$
```

Despite the simplicity of the above scheme, however, a straightforward implementation in finite-precision arithmetic may cause severe problems. The only circumstance that permits the direct application of Eq. [46] is when there is only a single copy, whose normalization is always maintained in finite-precision arithmetic. When converted copies appear, the normalization of the approximate eigenvectors may not hold because of loss of orthogonality. Tests have shown that the norm of the approximate eigenvectors fluctuates over multiple copies.$^{38}$

Despite these problems, it was realized that one can still compute the overlaps accurately by using the formula:$^{38}$

```
$$\zeta_{m,n}^{(K)} = \sum_{i} |c_{i}^{(K)}|^2/N_n^{(K)} \quad [48]$
```

where the sum runs over all converted copies $\{E_i^{(K)}\}$ of the true eigenvalue $E_n$. This is possible because of a remarkable observation by Chen and Guo on the Lanczos algorithm in finite-precision arithmetic;$38}$ i.e., the sum of the norms of all converted copies equals the following numbers:

```
$$\sum_{i} |b_i^{(K)}|^2 \approx N_n^{(K)} \quad [49]$
```

For real-symmetric systems, the above relation holds up to machine precision despite the fact that individual copies are not normalized.$^{38}$ It also works reasonably well for complex-symmetric Hamiltonians.$^{102}$ Unfortunately, there has not yet been a formal proof of this striking observation.
