Spin-dependent operators are now introduced. The external potential can be an operator $\hat{V}_{ext}$ acting on the two-component spinors. The exchange-correlation potential is defined as in Eq. [27], although $E_{xc}$ is now a functional $E_{xc} = E_{xc}[ho_{\alphaeta}]$ of the spin-density matrix. The exchange-correlation potential is this

```
$V_{xc}^{\alphaeta}(\vec{r}) = \frac{\delta E_{xc}[\rho_{\alpha\beta}]}{\delta \rho_{\alpha\beta}(\vec{r})} \quad [40]$
```

This potential is often written in terms of a fictitious exchange-correlation magnetic field $B_{xc}$

```
$V_{xc}^{\alphaeta}(\vec{r}) = \frac{\delta E_{xc}}{\delta n(\vec{r})}I - B_{xc}(\vec{r}) \cdot \sigma \quad [41]$
```

```
$B_{xc}(\vec{r}) = - \frac{\delta E_{xc}}{\delta m(\vec{r})} \quad [42]$
```

The Kohn-Sham Hamiltonian is

```
$$\hat{H}_{KS}[\rho_{\alpha\beta}] = \hat{T} + \hat{V}_{ext} + \hat{V}_H[n]I + \hat{V}_{xc}[\rho_{\alpha\beta}] \quad [43]$
```

and the corresponding Kohn-Sham equations become

```
$$\hat{H}_{KS}[\rho_{\alpha\beta}]|\Psi_j = \varepsilon_j|\Psi_j \quad [44]$
```

that is,

```
$$\sum_{\beta} \left( -\frac{\nabla^2}{2}\delta_{\alpha\beta} + V_{KS}^{\alpha\beta}(\vec{r}) \right) \Psi_{\beta}(\vec{r}) = \varepsilon_i \Psi_{xc}(\vec{r}) \quad [45]$
```

when the Kohn-Sham effective potential is

```
$V_{KS}^{\alpha\beta}(\vec{r}) = V_{ext}^{\alpha\beta}(\vec{r}) + \delta_{\alpha\beta} \frac{n(\vec{r}')}{|\vec{r}-\\vec{r}'|} d^3r' + V_{xc}^{\alpha\beta}(\vec{r}) \quad [46]$
```

In most cases of interest, the spin density $n(\vec{r})$ is collinear; the direction of the magnetization density $m(\vec{r})$ is the same over the space occupied by the system; it is customary to identify this as the z-direction.
