Our perturbative scheme starts with assigning with the following Hamiltonian:

```
$H' = H + \lambda\Omega \quad [53]$
```

where $\lambda$ is a sufficiently small parameter. The Lanczos recursion under the effective Hamiltonian yields a set of eigenvalues $(E_n'(\lambda))$. The expectation value of $\Omega$ can be computed using the Hellmann-Feynman theorem:

```
$\Omega = \langle E_n|\Omega|E_n\rangle \cong \frac{E_n'(\lambda) - E_n}{\lambda} \quad [54]$
```

where $E_n = E_n'(\lambda \rightarrow 0)$ are obtained from another Lanczos recursion under the original Hamiltonian. Numerical tests indicate that the accuracy is reasonable.

## Chebyshev Operator and Cosine Propagator

The generation of Krylov subspaces by the Lanczos recursion in the previous section is just one of strategies for recursive diagonalization of a large, real-symmetric matrix. Indeed, Krylov subspaces can be generated using three-term recursion relations of classic orthogonal polynomials. The Chebyshev polynomials, for example, use the following recursion formula$^{122}$

```
$T_k = 2xt_{k-1} - T_{k-2} \quad \text{for} \quad k \geq 2 \quad [55]$
```

with $T_1 = x$ and $T_0 = 1$. The variable $x$ is defined on the real axis in $[-1,1]$ and the polynomials diverge exponentially outside this range. Starting with a normalized initial vector $q_0$, one can generate the Chebyshev vectors recursively:

```
$q_k = \mathbf{Hq}_k = 2H\mathbf{q}_{k-1} - \mathbf{q}_{k-2} \quad \text{for} \quad k \geq 2 \quad [56]$
```

with $\mathbf{q}=\mathbf{H}_0$. Here, the Hamiltonian matrix has to be scaled so that all of its eigenvalues lie in $[-1,1]$. This is achieved readily by setting: $H_{\text{scaled}} = (H - H^{\pm}^*)/H^*$ with $H^{\pm} = (H_{\max} \pm H_{\min})/2$. In the ensuing discussions, the Hamiltonian is assumed to have been scaled. The extrema of the spectrum $(H_{\min}$ and $H_{\max})$ can be estimated.

The usefulness of Chebyshev polynomials being both efficient and accurate was realized first by Ezer and Kosloff,$79$ and later by others. A well-known property of Chebyshev polynomials is that they can be mapped to the cosine function:

```
$T_k(x) = \cos(k \arccos x)$
```

This allows for the use of the Fast Fourier Transform (FFT) to accelerate the recursion.
