We can analyze this time regime as we did for the bead-spring model by fitting it with an extended von Schweidler

$S(q,t) = f_q^\infty - b_q t^b + b_q(2)t^{2b} \pm \dots$$

The von Schweidler law describes how the plateau in both the coherent and the incoherent scattering functions. All correlators for PB can be fitted with a von Schweidler exponent $b = 0.3$ (see Figure 22). Like the findings by Van Zon and de Leeuw$^{148}$ and by Lyulin and Michels,$^{149}$ the decay is much more stretched for the chemically realistic PB model than for the KWW fit bead-spring model. Typical values for the stretching exponent $b$ for the $\alpha$ relaxation (which should approach $b \to \infty$) are around 0.5, which agrees well with experimental values. Using the $eta$ fit parameters, we determine the critical temperature in a manner that is similar to what we did for the bead-spring model. The value obtained this way is $T_c = 214 \pm 2 K,$^{176}$ which agrees perfectly with experiment.$^{177}$ It so far not been possible to obtain a value for the von Schweidler exponent experimentally, which we can therefore predict by these chemically realistic simulations of PB.
