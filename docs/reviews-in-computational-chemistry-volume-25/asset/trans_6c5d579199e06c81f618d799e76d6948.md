# 通用密度泛函理论

密度泛函理论 (DFT)$^{22}$ 中的基本变量是电子密度 $n(\vec{r})$。在 DFT 的通常实现中，密度是根据非相互作用电子辅助系统的占据单粒子波函数 $\psi_i(\vec{r})$ 计算的：

$n(\vec{r}) = \sum_i \theta(\varepsilon_F - E_i)|\psi_i(\vec{r})|^2$ [22]$$

而轨道 $\psi_i(\vec{r})$ 通过求解 Kohn–Sham 方程$^{23}$ ：

$(-\frac{\nabla^2}{2} + V_{KS}(\vec{r}))\psi_i(\vec{r}) = \varepsilon_i\psi_i(\vec{r})$ [23]$$

方程以原子单位表示。方程 [22] 中的符号 $\theta$ 是阶跃函数，它确保所有能量 $\varepsilon_i$ 低于费米能级 $\varepsilon_F$ 的轨道都被占据。

且所有能量高于 $\varepsilon_F$ 的轨道都是空的。费米能级通过归一化条件确定：

$$\int n(\vec{r})d^3r = N \quad [24]$$

其中 $N$ 是电子数。出现在方程 [23] 中的有效 Kohn–Sham 电势 $V_{ks}(\vec{r})$ 是几个不同不同贡献之和：

$$\V_{ks}(\vec{r}) = V_{ext}(\vec{r}) + V_{H}(\vec{r}) + V_{sc}(\vec{r}) \quad [25]$$$

外部电势 $V_{ext}(\vec{r})$ 包含了原子核或离子贡献以及可能的外场贡献。哈特能级 $V_H(\vec{r})$ 是电子的经典静电势：

$$\V_{H}(\vec{r}) = - \int \frac{n(\vec{r'})}{|\vec{r}-\vec{r}'|}d^3\vec{r'} \quad [26]$$$$

而 $V_{sc}(\vec{r})$ 是交换相关势。电子之间的交换源于全等费米子粒子多电子波函数的反对称性：两个电子不能同时占据同一个单粒子态（由轨道和自旋量子数表征）。这种效应的结果是在电子周围形成一个称为“费米空穴”的洞，它排斥了相同自旋取向的其它电子（在通常的符号中，$z$ 分量表示为 $\uparrow$ 或 $\downarrow$）的存在。此外，电子的瞬时位置之间存在库仑相关，因为它们是相互排斥的带电粒子。由于这种排斥，无论自旋取向如何，两个电子不能靠得太近。费米相关和库仑相关的结合效应可以描述为建立在每个电子周围的交换相关穴。在实践中，$V_{sc}(\vec{r})$ 使用其在 DFT 中的定义，作为交换相关能量泛函 $E_{sc}[n]$ 的泛函导数计算：

$$\V_{sc}(\vec{r}) = \frac{\delta E_{sc}[n]}{\delta n(\vec{r})} \quad [27]$$$

**局部密度近似 (LDA)**$^{24}$ 常用于计算 $E_{sc}[n]$ 和 $V_{sc}(\vec{r})$。LDA 以恒定密度电子气体的交换相关能作为输入。在均匀系统中，每个粒子的交换能是精确已知的，其表达式为：

$$\e_x(n_0) = - \frac{3}{4}(\frac{3}{\pi})^{1/3}n_0^{1/3} \quad [28]$$$

# 自旋密度泛函理论 205

$n_0$ 是系统的恒定密度。密度为 $n(\vec{r})$ 的不均匀系统的交换能，通过假设方程 [28] 有效得到近似；即：

$E_x[n] = -\frac{3}{4}\left(\frac{3}{\pi}\right)^{1/3}\int n(\vec{r})^{4/3}d^3r \quad [29]$$$

对方程 [29] 进行泛函求数（见方程 [27]）导致：

$V_x^{LDA}(\vec{r}) = -\left(\frac{3}{\pi}\right)^{1/3}n(\vec{r})^{1/3} \quad [30]$$$

均匀电子气每个粒子的相关能 $e_c(n_0)$ 的表达式不存在，但仍然存在良好的近似。$^{24}$ 此外，已经通过数值方法获得了不同密度的近精确相关能$^{25}$，并且结果被参数化为有用的函数 $e_c(n)^{26}$。相应的 LDA 相关势：

$V^{LDA}(\vec{r}) = \left.\frac{d[ne_c(n)]}{dn}\right]_{n=n(\vec{r})} \quad [31]$$$

总而言，在 LDA 中，空间中某点的 $V^{LDA}(\vec{r})$ 被假设等于具有“恒定”密度 $n=n(\vec{r})$ 的均匀电子气中的交换相关势，该值恰好等于该点的局部密度 $n(\vec{r})$。LDA 在实践中的效果比预期好，这种成功源于交换能 $E_{sc}[n]$ 几个形式性质的满足以及细微的抵消。通过**广义梯度近似 (GGAs)** 获得了显著改进：

$$E_{xc}^{GGA}[n] = \int E_{xc}^{GGA}(n(\vec{r}),\nabla n(\vec{r}))d^3r \quad [32]$$$

这在交换相关能量泛函中包含了 $\nabla n(\vec{r})$，甚至是电子密度的更高阶梯度$^{27-29}$。

项。Von Barth 和 Hedin 为自旋极化情况制定了 DFT。在这种情况下，基本变量是 $2 \times 2$ 自旋密度矩阵 $\rho_{\alpha\beta}(\vec{r})$，定义为：

$$\rho_{\alpha\beta}(\vec{r}) = \sum_i \theta(\varepsilon_F - \varepsilon_i) \Psi_{i^*\alpha}(\vec{r})\Psi_{i\beta}(\vec{r}) \quad [33]$$$

其中符号 $\chi$ 包含了位置 $\vec{r}$ 和自旋 $\alpha = +1/2$ 或 $-1/2$。2 \times 2$ 矩阵 $\rho_{\alpha\beta}(\vec{r})$ 是厄米的，并定义于点 $\vec{r}$。该矩阵的自旋密度为：

$$n(\vec{r}) = \text{Tr}\rho_{\alpha\beta}(\vec{r}) = n_+(\vec{r}) + n_-(\vec{r}) \quad [34]$$$

$n_-(\vec{r}) = \rho_{++} = \rho_{--}$ }$ 是对角线项。为了量化磁效应，可以定义磁化密度 $\vec{m}(\vec{r})$，使得：

$$\rho_{\alpha\beta}(\vec{r}) = \frac{1}{2}n(\vec{r})I + \frac{1}{2}\vec{m}(\vec{r}) \cdot \sigma \quad [35]$$$

其中 $I$ 是 $2 \times 2$ 单位矩阵，$\sigma = (\sigma_x, \sigma_y, \sigma_z)$，$\sigma_x, \sigma_y$ 和 $\sigma_z$ 定义了 $2 \times 2$ 泡利自旋。$n(\vec{r})$ 和 $\vec{m}(\vec{r})$ 形成了 $\rho_{\alpha\beta}(\vec{r})$ 的另一种表示。单粒子表示现在基于双分量自旋（在空间轨道加上自旋时，自旋的两个分量 $+$ 和 $-$ 对应于自旋沿量子化轴的投影，向上 $\uparrow$ 和向下 $\downarrow$）：

$$\Psi(\vec{r}) = \begin{bmatrix} \Psi_+(\vec{r}) \\ \Psi_-(\vec{r}) \end{bmatrix} \quad [36]$$$

自旋极化 DFT 的目的是用辅助非相互作用单粒子自旋 $\{\Psi_1, \dots, \Psi_N\}$ 来描述系统（分子、簇...）。该非相互作用系统的基态密度矩阵：

$$\rho_{\alpha\beta}(\vec{r}) = \sum_i \theta(\varepsilon_F - \varepsilon_i) \Psi_{i^*\alpha}(\vec{r})\Psi_{i\beta}(\vec{r}) \quad [37]$$$

应该与相互作用系统的相等。用单粒子自旋轨道表示为：

$$n(\vec{r}) = \sum_i \theta(\varepsilon_F - \varepsilon_i) \Psi_i^*(\vec{r})\Psi_i(\vec{r}) \quad [38]$$$

$$\vec{m}(\vec{r}) = \sum_i \theta(\varepsilon_F - \varepsilon_i) \Psi_i^*(\vec{r})\sigma\Psi_i(\vec{r}) \quad [39]$$$
