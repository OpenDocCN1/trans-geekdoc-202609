尽管到为止，我们的关注一直是用于检测和量化由凝聚相中粒子排列所反映的结构序的平均值，但结构的另一个互补方面也被认为对于确定材料性质至关重要：自由体积。我们现在将讨论如何计算自由体积，并提供其与玻璃形成材料热力学和动力学性质之间关系的示例。

# 自由体积

多年来引入了描述自由体积的不同方法。然而，从定性的角度上来说，所有方法都部分表征了材料组成粒子可用的局部空间（即它们表征了粒子在其填充结构中的“呼吸空间”）。正如人们可能想象的，流体的等温压缩通常会让组成粒子靠得更近，从而减少自由体积，对于大多数系统而言，熵和粒子迁移率都会降低（某些条件下的液态水是一个例外$^{62}$）。因此，人们自然地好奇，深入理解自由体积是否能揭示凝聚相材料热力学和动力学性质的新微观见解。

将单粒子动力学与自由体积联系起来的最简单概念是：假设粒子需要足够的自由体积 $v_i$ 才能从邻近粒子形成的瞬态笼中“逃逸”，从而贡献自扩散。在这种观点下，微观密度波动在促进粒子迁移率方面起着核心作用。Cohen 和 Turnbull$^{63}$ 基于这一想法引入了一个定性模型。该模型始于平移自扩散系数 $D$ 与寻找自由体积在 $v_i$ 和 $v_i + dv_i$ 之间的粒子的概率密度 $p(v_i)$ 之间的关系：

```
D = \int_{v_i}^{\infty} dv_ip(v_i)D(v_i) \quad [7]
```

# 自由体积 137

在这里，$D(v_f)$ 代表具有自由体积 $v_f$ 的粒子对自扩散的贡献。在过去的五十年里，人们已经探索了针对 $p(v_f)$ 和 $D(v_f)$ 的各种近似方法，以及具有相同模型精神的其他理论方法（例如，文献 64–68，文献 69 提供了一份最新的综述）。尽管付出了这些努力，但基本的观点并没有改变。一个全面且在微观上合理的基于自由体积的动力学理论尚未出现，这在很大程度上是因为缺乏用于测量和表征自由体积的实验/计算工具。然而，近期计算统计几何学$^{70,71}$ 的进展现在使得从实验（例如粒子悬浮液的共聚焦显微镜$^{72,73}$）或计算机模拟（$71,74–76$）获得的粒子构型中高效计算自由体积变得可行，这为仔细检查基于自由体积视角的动力学基本思想打开了大门。

我们专门关注一种常用的粒子自由体积 $v_f$ 的几何定义。该定义是指可访问空间的“笼”（见图 6），如果邻近粒子固定在它们的构型中$^{77}$，粒子中心从其当前状态可以访问的区域。这种几何定义假设粒子之间的短程相互作用足以为粒子分配有效的（取决于压力和温度的$^{78}$）“硬球”半径，这一假设也是液态热力学扰动$^{46}$ 的基础。界定粒子自由体积的表面积 $s_f$称为其自由表面积。注意，在使用上述几何定义时，每个粒子都可以明确地与一个自由体积和一个自由表面积相关。

# 138 自由体积、结构序

图 6 显示了被排除球包围的粒子示意集合。每个粒子的排除球表示其他粒子被排除在外的空间体积。所示，在凝聚相中，排除球（通常）会重叠，因为平均粒子间间距相对较小（粒子直径数量级）。此类构型中的空腔被定义为位于排除球外的连通空间。空腔的并集通常被称为可用体积。空腔与自由体积密切相关。特别是，为了计算粒子的自由体积，人们实际上是从构型的一个快照中“移除”目标粒子。新形成的空腔的体积和表面积代表了该粒子的自由体积和表面积。我们在下面概述了计算体积和自由体积的基本步骤。关于执行这些计算的高效算法的更多细节可以在其他地方找到。79 识别空腔并计算其体积
