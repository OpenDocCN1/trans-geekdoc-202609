How can dynamic electron correlation be included? In a single configuration, the obvious choices are preferably CC methods, or if the system is too large, second order perturbation theory (MP2), which is already accurate. A practical multiconfigurational CC theory does not exist. A method that has been used with great success since the 1980s is Multi-Reference CI (MRCI), where the most of the CFs of the CAS wave function are used as reference configurations in a CI expansion that includes all CFs that can be generated by single and double replacements of the orbitals in the reference functions.¹⁴ The method is still used with some success because of recent technological developments.¹¹⁵ It becomes time consuming for systems with many electrons, however also has the disadvantage of lacking size-extensivity, even if this latter problem can be corrected approximately.

Another way to treat dynamic correlation effects is to use perturbation theory. Such an approach has the virtue of being size-extensive and ought to be computationally more efficient than the MRCI approach. Moller-Pleset second-order perturbation theory (MP2) has been used for a long time to treat electron correlation for ground states, where the reference function is a single determinant. of closed-shell molecules. Could such an approach also work for a multiconfigurational reference function like CASSCF?
