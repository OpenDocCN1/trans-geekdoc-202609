If the number of samples in the database is comparable with, or less, the number of connection weights, the network may learn specific examples from the dataset and few general rules. However, if the dataset is sufficiently large and diverse, the network will learn the general rules that underlie the database, thus, in effect, deducting the laws buried in the database.

This observation leads to the intriguing possibility of automatic rule discovery. Suppose that we launch a neural network into a large and complicated dataset where the relationship between the data and the desired output is inadequately understood. Once fully trained, the networks should encode relationships that allow it to describe these links. Such relationships are in effect equivalent to scientific laws, so this process is rule-discovery by machine. Software capable of doing this is not far off the horizon; indeed, some rule-discovery networks are already operating. There is, however, a problem: it is difficult to extract laws from a standardised feedforward neural network, because the laws are encoded in a complicated way to determine connection weights. Our network training to assess an infrared spectrum to determine whether it indicates a carbonyl-containing group is present without having assessed the database, report that

Instead, the network's understanding of this rule is deduced in the set of connection weights from which the extraction of a human language rule may not be simple. Nevertheless, rule-discovery neural networks, or their derivatives, have great potential and will play an increasingly important role in scientific progress.¹³³

# What Can We Do with Neural Networks?

ANNs have the advantage that no assumptions need to be made about the data before analysis starts. In analyzing spectra, for example, the underlying shape of the spectral distribution or line shape is of no connection to a neural network, unlike the requirements of more traditional methods. They are also tolerant of noise and outliers. In contrast to expert systems, they can accommodate aberrant points without too much difficulty. However, as noted above, it is difficult to extract from the network weights an algebraic function that relates input to output, so most neural networks function as black boxes; in addition, training is lengthy, although the operation of a trained network is rapid.
