It is easy to show that the eigenspectrum of **H** is simply a cosine Fourier transform of the Chebyshev autocorrelation function:

```
$$\Sigma(E) \equiv \mathbf{q}_0^T \delta(\mathbf{EI} - \mathbf{H}) \mathbf{q}_0 = \frac{1}{\pi \sin \theta} \sum_{k=0}^{\infty} (2 - \delta_k) \cos k\theta C_k$$  [65]
```

The efficient FFT scheme can be used to extract the eigenspectrum from the correlation function. We note in passing that the eigenspectrum can also be obtained using cross-correlation functions: $C'_k = \mathbf{p}^T \mathbf{q}_k$, where the vector **p** can be chosen arbitrarily.

Once the eigenvalues are determined accurately, the corresponding (unnormalized) eigenvectors can be assembled from a recursive relation:

```
$$b_n = \delta(\mathbf{EI}_n - \mathbf{H}) \mathbf{q}_0 = \frac{1}{\pi \sin \theta_n} \sum_{k=0}^{n} (2 - \delta_k) \cos k\theta_n \mathbf{q}_k$$  [66]
```

where $\theta_n = E_n$. The cosine form of the Chebyshev propagator also affords symmetry in the effective time domain, which allows for doubling of autocorrelation function. In particular, $2K$ values of autocorrelation function can be obtained from a K-step procedure$^{147}$

```
$$C_{2k} = \mathbf{q}_0^T \mathbf{q}_{2k} = 2\mathbf{q}_0^T \mathbf{q}_k - \mathbf{q}_0^T \mathbf{q}_0$$  [67]\n$$C_{2k+1} = \mathbf{q}_0^T \mathbf{q}_{2k+1} = 2\mathbf{q}_1^T \mathbf{q}_k - \mathbf{q}_1^T \mathbf{q}_1$$  [68]
```

based on the trigonometry relation:

```
$$2\cos(k_1) \cos(k_2) = \cos[(k_1 + k_2)] + \cos[(k_1 - k_2)]$$  [69]
```

It is advantageous to use the doubling property of the autocorrelation function to reduce computational costs.

Apart from the delta discussed here, one can define other filters using the same Chebyshev operators. In fact, any analytic function of the Hamiltonian can be expressed in an expansion terms of the Chebyshev operator$^{126,127,149}$ For instance, the Green filter can be expressed as follows:

```
$$G(E) = $(\mathbf{EI} - \mathbf{H})^{-1} = \frac{-i}{\sqrt{1 - E^2}} \sum_{k=0}^{\infty} (2 - \delta_k) e^{-ik \arccos E_k} T_k(\mathbf{H})$$  [70]
```
