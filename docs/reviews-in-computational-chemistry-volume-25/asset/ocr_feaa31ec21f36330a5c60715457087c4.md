# The Complete Active Space SCF Method

The CASSCF method was developed almost 30 years ago. It was inspired by the development of the Graphical Unitary Group approach (GUGA) to the full CI problem by Shavitt,8 making it possible to solve large CI problems with full control of spin and space symmetry. The GUGA approach is in itself not very helpful because it can only be used with small basis sets and few electrons. It was known, however, that the important configurations (those with coefficients apparently different from zero) in a full CI expansion used only a limited set of molecular orbitals. The following idea, especially the concept of a fully optimized reaction space (FORS) introduced by Ruedenberg and Sundberg in 1976:The molecular orbital space is divided into three subspaces: inactive, active, and external orbitals. The inactive orbitals are assumed to be doubly occupied in all configuration functions (CFs) used to build the wave function. The inactive orbitals thus constitute a Hartree-Fock “sea” in which the active orbitals move. The remaining electrons occupy a set of predetermined active orbitals. The external orbitals are assumed to be unoccupied in all configurations. Once the assignment of electrons to active orbitals is done, the wave function is fully defined within the set of active orbitals. The space and spin symmetry are included in the multiconfigurational wave function. This concept of CAS was introduced by B. O. The choice of the correct active space for a specific application is not trivial, and many times one to make several “experiments.” It is difficult to derive any general rules because every chemical system poses its own problems. The rule of thumb is that all orbitals intervening in the chemical process must be included.
