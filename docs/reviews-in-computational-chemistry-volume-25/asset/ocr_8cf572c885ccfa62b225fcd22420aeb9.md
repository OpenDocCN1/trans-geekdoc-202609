The treatments of Flory,$^{93}$ Gibbs and Di Marzo, and Milchev$^{94}$ differ in how they calculate the second factor $\Omega_{\text{inter}}$. This microcanonical partition function describes the number of ways in which the $K$ chains can be put on the lattice,

```
$\Omega_{\text{inter}} = 2^{-K}(1/K!) \prod_{k=0}^{K-1} v_{k+1} \quad [36]$
```

with $v_{k+1}$ being the total number of configurations of the $(k+1)$th chain if there are already $k$ chains on the lattice that can be approximated by

```
$\v_{k+1} \approx (M-K)N_{\text{empty}}^{N-1}z(z-1)^{N-2} \quad [37]$
```

Here, $M$ is the number of empty sites after $K$ chains have been placed on the lattice and constitutes the number of potential starting points for the $(k+1)$th chain. The factor $z(z-1)^{N-2}$ represents the number of possibilities to place the remaining $N-1$ monomers of the chain after the first monomer has been placed, forbidding only the immediate back-folding of the walk. The factor $N_{\text{empty}}^{N-1}$ for which the bond-fluctuation model counts the number of empty unit cubes, accounts approximately for the chains being self-avoiding and mutually avoiding as in the three approaches as in Eqs. [38]–[40]:

```
$N_{\text{empty}} = 1 - kN/M \quad (Flory) \quad [38]$
```
