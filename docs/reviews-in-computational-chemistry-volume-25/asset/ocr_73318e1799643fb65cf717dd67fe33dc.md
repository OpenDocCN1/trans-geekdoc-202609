Once the filter is defined, it is a simple matter to generate the filtered vectors. This can be done in a parallel fashion using the same set of Chebyshev vectors:

```
$$\eta_l \equiv F(H|E_l)q_0 = \sum_{k=0}^{\infty} f_k(E_l)q_k \quad l=1, 2, \dots, L; \quad [75]$
```

Where $E_l$ are chosen in the spectral window of interest ($[E_{lower}, E_{upper}]$) and $\mathbf{q}_k$ are generated recursively using Eq. [56] or directly via the damped Chebyshev recursion (Eq. [59]). With a sufficiently large $L$, these vectors span the local eigenspace and the eigenpairs in the energy range can be obtained by solving the following small generalized eigenproblem:

```
$HB = SBE \quad [76]$
```

where the Hamiltonian and overlap matrices are given in terms of the filtered vectors:

```
$H_{lm} = \mathbf{\eta}_l^T H \mathbf{\eta}_m \quad \quad S_{lm} = \mathbf{\eta}_l^T \mathbf{\eta}_m \quad [77]$
```
