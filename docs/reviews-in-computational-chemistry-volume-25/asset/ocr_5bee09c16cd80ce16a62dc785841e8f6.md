For Krylov subspace methods, symmetry adaptation can also lower the computational costs, although the savings may not be as dramatic as in direct diagonalization. To this end, the breakdown of the spectrum into symmetric species reduces the spectral density, rendering faster convergence. An example of such near-degeneracy is the local vibrational modes coupled by the Darling–Dennison resonance.¹¹⁸ It is pathologically difficult to converge using a recursive approach. The unique operation in recursive methods, namely matrix-vector multiplication, demands different strategies in symmetry adaptation. We shall discuss of these strategies below, with the assumption that a coordinate system has been chosen such that symmetry operations in the group to which the molecular system belongs can be realized.

The simplest approach to symmetry adaptation is to recur symmetry-adapted vectors.¹²,¹⁴⁵,¹⁸⁹ This approach is not optimal because multiple recursions must be executed. The numerical efficiency can be improved by propagating only a single vector and constructing multiple symmetry-adapted vectors/or correlation functions at each step. This approach is possible because symmetry operators and the Hamiltonian commute. Using the Chebyshev propagator as an example, a symmetry-adapted Chebyshev vector for the mth representation of the symmetry group to which the molecular system belongs can be obtained by applying the appropriate projection operator (P⁽ᵐ)) onto the original Chebyshev vector.¹⁹²

```
$q^{(m)}=T_k(H)q_0^{(m)}=T_k(H)P^{(m)}q_0^{(m)}=P^{(m)}T_k(H)q_0^{(m)}=P^{(m)}q_k$ [91]
```

where the projection operator, being linear combination of symmetry operators, commutes with the Hamiltonian and thus with the Chebyshev propagator. Similarly, autocorrelation functions belonging to different symmetries can be obtained from a single propagation:

```
$C_k^{(m)}=[q_0^{(m)}]ᵀT_k^{(m)}=[q_0^{(m)}]ᵀ[q_k]T^{(m)}$ [92]
```

where the idempotency of the projection operator $P^{(m)}$ ($P^{(m)(m)}=p^{(m)}$) is used. These symmetry-adapted autocorrelation functions can be used directly in a spectral method, or they can be used to construct symmetry-adapted eigenfunctions in FD. Numerical tests have shown that these strategies are both accurate and efficient.¹¹⁹³,¹⁹⁴

Unfortunately, the symmetry adaptation scheme described above for the Chebyshev recursion cannot be applied directly to the Lanczos recursion.
