For short times, one has a power decay

```
$g_{\pm}(t/t_{\sigma}) = \frac{t^{-a}}{t_{\sigma}} \pm A_1\frac{t^{a}}{t_{\sigma}} + \dots$
```

where $A_1$ is some amplitude. For large $t/t_0$, $g_{+}(t/t_{\sigma}) \to \infty)=1/sqrt{1-\lambda}$, consistent with Eq. [49], the correlator approaches structural decay. The liquid phase solution, on the other hand, exhibits another power law, the so-called von Schweidler law,

```
$g-(\frac{t}{t_{\sigma}}) = -B\frac{t^{b}}{t_{\sigma}}, \quad(\frac{t}{t_{\sigma}} \gg 1)$
```

where $B$ is another amplitude, and the von Schweidler exponent $b$ is related to $\lambda$ as

```
$\Gamma(1+b)]^2/\Gamma(1+2b) = \lambda$
```
