这些修正背后的思想是承认：并不是所有空晶格点都可以作为新聚合物的起点；只有那些位于 $k$ 条链已占据体积之外的点才能被使用。遗憾的是，方程 [37] 或 $N_{empty}$ 的表达式都无法在数学严格性上通过证明。对于 Flory$^{93}$ 以及 Gibbs 和 Di Marzo$^{91}$ 近似，低温下的熵为负值（在 $N \to \infty$ 和 $\rho \to 1$ 的极限下）：

$s(T \to 0) = -1 \quad (Flory) [41]$

$s(T \to 0) = (\frac{9}{2} - 1) \ln (1 - \frac{2}{z}) < 0 \quad (Gibbs-Di Marzo) [42]$

为了在计算机模拟中测试这些理论方法，需要分步骤进行。第一步，通过测量每个单体的能量 $e(\rho, T)$ 以及通过过量化学电位的热力学积分计算每个单体的自由能，确定溶液中每个单体的熵：

$s(\rho, T) = \frac{e(\rho, T)}{T} - \ln \ln N - \ln \frac{Z_p(N, T)}{N} - \frac{1}{N} \int_0^{\rho} \mu_{ex}(\rho', T) d\rho' [43]$

其中 $Z_p(N, T)$ 是长度为 $N$ 的单链的配函数。过量化学电位可以通过以下方式测量：

$$\mu_{ex}(\rho, T) = -T \ln p_{ins}(\rho, T) [44]$$

通过在密度为 $\rho^{97,98}$ 的溶液中评估长度为 $N$ 的链的插入概率来实现。第二步，测量处于激发态的键的比例 $f$、有效配位数 $z$（熔体中给定单体周围、在由最大键长给定的距离范围内的单体数量）以及空穴数 $H$（键波动模型中，可以放入另一个单体的空晶格点所占空晶格点总数的比例）。

Flory 和 Gibbs–DiMarzio 理论得出了几乎相同的预测，两者都导致在 $T=0.18$ 附近出现 Kauzmann 悖论（负过量熵），该温度接近该模型确定的 Vogel–Fischer 温度 $T_0\sim0.13$。然而，这两种理论都严重低估了构型熵的值，而构型熵始终为正。原因是当将 $1/T=0$ 时的行为与模拟数据比较时，对分子间配函数存在低估，而该值与模拟数据高度吻合且在整个温度范围内保持正值。所有理论都很好地再现了模拟曲线的形状，这解释了为什么 Gibbs–Di Marzio 理论在预测仅取决于比熵导数的聚合物熔体玻璃转变实验结果方面如此成功。然而，从模拟中得出，过量熵消失的 Kauzmann 悖论是一个外推事实，而基于这一发现的理论描述基于不恰的近似。因此，这些研究并未揭示任何关于聚合物熔体玻璃转变底层的相变的证据。

在实验和模拟中都能观察到的比熵急剧减少（即熔体中链可用构型空间的减少），被 Adam 和 Gibbs [81] 联系到系统动力学的变慢。在 Adam-Gibbs 理论中，链的质自扩散系数与熵联系如下：

```
D(T) = D(\infty)\exp\left\{\frac{A}{TS(T)}\right\} \quad [45]$
```

利用模拟中确定的比熵，可以通过将该表达式拟合到模拟中观察到的 D 的温度依赖性来测试这种理论方法。结论认为，Adam-Gibbs 理论无法从包含熵温度依赖性的热力学信息预测动力学的温度依赖性。在后续章节中，我们将重点分析过冷液体的动力学，并根据玻璃转变模式耦合理论讨论我们的发现，这是一种根据液态结构性质预测动力学的液态理论。

# 过冷聚合物熔体的动力学

因此，原则上，聚合物应该是过冷液体（准）平衡理论的良好候选者。描述过冷液体变慢的液态理论是模式耦合理论$^{99-101}$。它是一种从冻结出发预测玻璃转变的微观方法。该理论假设密度波动是玻璃形成体系的主导变量。尽管该理论最初是针对单原子流体制定的，但被认为具有更广泛的适用性，并已应用于聚合物玻璃转变的实验。从作为动力学基础演化方程的 Liouville 方程开始，模式耦合使用常用的投影算子技术来消除快速变量，从而得到密度波动的相关函数的方程，即中间散射函数：

```
$$\frac{\partial^2}{\partial t^2}S(q,t) + \Omega_q^2S(q,t) + 2\zeta_q\frac{\partial}{\partial t}S(q,t) + \int_{0}^{t} m_q(t-t')\frac{\partial}{\partial t'}S(q,t')dt' = 0 [46]$
```

在这个振荡方程中

```
$m_q(t) = \sum_{i=1}^{\infty} \sum_{k_1,...,k_i} V^{(i)}(q,k_1,...,k_i)S(k_1,t)...S(k_i,t) [47]$
```

这种模式函数的系数是理想化模式耦合理论的基本控制参数。可以看到 [46] 和 [47] 允许对相关函数 $S(q,t)$ 建立一组自洽方程。

模式耦合理论的基本定性预测是，降低温度或增加熔体密度时，可以观察到微观动力学与结构弛豫之间的尺度分离，导致所有弛豫函数的两步衰减。想象分子在一段时间内被困在由其邻居形成的笼中，处于短时间动力学和粒子离开笼子的大尺度结构弛豫之间。长时间行为是结构（或 $\alpha$）弛豫，以及振动动力学之间的平台期，理论将这种 $\alpha$-弛豫称为 $\beta$-弛豫。对于良好的中间平台期，模式耦合预测了如下类型的解：

```
$S(q,t) = f_q^2 + h_qG(t,\sigma) [48]$
```

在时间窗口 $t_0 \ll t \ll t_0'$ 中，其中 $f_q^2$ 是遍历性参数，$h_q$ 是与波矢量相关的振幅，$G$ 是与其无关的时间缩放函数，$t_0$ 是微观尺度。奇异性参数 $\sigma \propto 1-\frac{1}{f}$ 测量了距离代表“理想”玻璃转变的奇异点的距离。对于 $\sigma \geq 0$，有：

```
$$\lim_{t\to\infty}S(q,t) = f_q^2 + h_q\sqrt{/(1-\lambda)} + O(\sigma) [49]$$
```
