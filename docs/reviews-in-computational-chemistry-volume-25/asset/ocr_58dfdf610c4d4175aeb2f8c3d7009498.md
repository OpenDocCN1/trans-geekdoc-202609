# Recursive Solutions to Large Eigenproblems

Because of round-off errors, symmetry contamination is often present even when the initial vector is properly symmetzed. To circumvent this problem, an effective scheme to reinforce the symmetry at every Lanczos recursion step has been proposed independently by Chen and Guo$^{100}$ and by Wang Carrington$^{195}$. Specifically, the Lanczos recursion is executed with symmetry-adapted vectors, and the matrix-vector multiplication is performed at every Lanczos step with the unsymmetrized vector. In other words, the symmetrized vectors are combined just after the operation Hq$_k$, and the resultant vector is symmetzed using the projection operators:

```
[Hq_k^{(m)} = H\left(\sum q_k^{(m)}\right) = p^{(m)} H\left(\sum q_k^{(m)}\right)] [93]
```

Such a strategy gives, from a single Lanczos recursion, to multiple T matrices that can be subsequently diagonalized for eigenvalues in different irreducible representations. The symmetrized vectors need not be stored in full length but can be squeezed into the space of a single vector. As a result, the memory requirement of this symmetry-adapted Lanczos algorithm remains unchanged. The CPU requirement also remains the same because the projection can be readily performed with few arithmetic operations. Applications to various problems have demonstrated the power of this symmetry-adaptation method.$^{103,196-205}$

Even when the system has no symmetry, one can still take advantage of the inherent symmetry in some operators in the Hamiltonian. An example is the reflection symmetry in the kinetic energy $\partial^2/\partial x^2$, which can be used to reduce the DVR matrix into a block-diagonal form. When the computation of its action onto the recurring vector is rate limiting, the efficiency will double if the symmetrized representation is used, even when the potential has no symmetry. In practical implementations, the recurring vector is first symmetrized before applying the symmetrized DVR matrix. This is followed by recombination of the result vectors to give the non-symmetric vector. This extended symmetry-adapted discrete variable representation (ESADVR) can be generalized to any reference Hamiltonian that has high symmetry. The computational savings, which are proportional to the number of symmetry species in the group, can be significant for large systems. For details of the discussion, the reader is referred to Ref. 206.
