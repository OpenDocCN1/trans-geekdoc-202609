# 结构有序图

将结构有序与材料属性联系起来的一个有用概念是有序图$^{30,31}$，它将系统的可能状态投影到其结构有序指标的平面上。有序图提供了结构有序沿平衡路径及非平衡路径演变的宽泛表征。图 2 展示了单原子硬球系统的有序图$^{30,31}$。两种相关的有序形式——键取向有序和和平移有序——作为图表的两个坐标轴。键取向有序表示为 $Q = Q_6/Q_6^{fc}$（见等式 [5]）；即，这是 $Q_6$ 的原始值通过其在完美 fcc 晶体的值归一化后的结果。平移有序 $\tau$ 由等式 [1] 给出，衡量流体中平均粒子间距与完美 fcc 晶体间距的相似性。以这种方式定义，硬球系统中的两种结构有序指标的值均介于零（理想随机性）和单位（完美晶体）之间。

通过观察有序图，可以很容易量化材料平衡态和玻璃态所展现的有序类型和程度。一个重要点是，硬球系统的玻璃态占据的有序空间区域与平衡流体不同，尽管两者在名义上都是“无序的”。$^{30}$ 硬球系统捕捉了许多原子和分子流体的基本有序模式，这一发现反驳了玻璃结构应被简单视为“类液体”的传统观念。同样注意，压缩速率的影响会强烈增强非平衡硬球玻璃态的结构有序（即结构有序（或缺乏结构有序）对于硬球玻璃态是一个程度问题）。“随机性”在于，具有略高填充分数 $\phi$ 的玻璃态可以以微小增加为代价被创造。后者的观察结果最近导致了对所谓的“随机密堆积态”概念价值的重新评估$^{31}$。

基于上述结果，一个自然的问题是：简单的吸引力会改变有序图吗？作为回答这一问题的第一步，Debenedetti 和 Torquato 检查了一组通过平移力 Lennard-Jones 势相互作用的相同粒子的各种有序指标对温度和密度的依赖性$^{32}$ 他们对涉及该系统平衡气态、液态和晶态的键取向和平移有序路径的检查带来了有趣的发现。

# 计算自由体积，结构有序

压缩速率的影响会强烈增强非平衡硬球玻璃态的结构有序（即结构有序（或缺乏结构有序））是一个程度问题。然而，由 Errington 和 Debenedetti 定义的有序指标 $q$

```
$q=1-\frac{3}{8}\sum_{j=1}^{3}\sum_{k=j+1}\left(\cos \psi_{jk}\right)^{2} [6]$
```

提供了量化四面体有序的有效方法。其中 $\psi_{jk}$ 是连接分子与其两个邻居的键所形成的角。这与 Chao 和 Hardwick 引入的参数相似之处在于，$q$ 的平均值介于 0（无相关系统）和 1（完美四面体）之间。注意该指标提供了对所有粒子进行平均后的局部全局有序测量。所谓的四面体参数$^{51}$ 是另一个可用于检测四面体有序的指标。

尽管上述键取向指标已被证明识别晶体$^{45}$ 非常有用，但对于检测面心立方、体心立方、简单立方和六方堆积点格等系统的有序是不够的。四面体液体（如水或硅）中方向性引力和短程斥力之间的竞争产生了非平凡的物理和结构性质。例如恒压冷却时的膨胀$^{51,52}$ 以及在足够低的温度下等温压缩时的迁移率增加$^{53-56}$
