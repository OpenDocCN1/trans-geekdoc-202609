An alternative to Lees-Edwards boundary conditions is the formalism put forth by Parrello and Rahman for the simulation of solids under constant stress.⁵²,⁵³ They described the positions of particles by reduced, dimensionless coordinates $r_n$, where the $r_n$ can take the value $0 \le r_n < 1$ in the central image. Periodic images of a given particle are generated by adding or subtracting images from the individual components of r.

The real coordinates of $R$ are obtained by multiplying $r$ with the matrix $b$ that contains the vector spanning the simulation cell. In the current two-dimensional (2-D) example, this could read as follows:

```
$R_{\alpha} = \sum_{\beta} b_{\alpha\beta}r_{\beta} \quad [28]$
```

```
$b = \begin{bmatrix} L_x & 0 \ 0 & L_y \end{bmatrix} \begin{bmatrix} \hat{e} & t \ \end{bmatrix} \quad [29]$
```

In this approach, the potential energy $V$ is a function of the reduced coordinates and the $b$-matrix. For the kinetic energy, one would only be interested in the motion of the particle relative to the distorted geometry so that suitable Lagrange function $L_0$ for the system would read as follows:

```
$L_0 = \sum_{\alpha} \frac{1}{2}m_{\alpha}(\sum_{\beta} b_{\alpha\beta}\dot{r}_{eta})^2 - V(b, \dot{r}) \quad [30]$
```

in which the $b$ matrix may be time dependent. Through this Lagrangian, it is straightforward to derive the Newtonian equations for the reduced coordinates, which can then be solved to any number of integration schemes. One advantage of the scheme outlined in Eqs. [28] to [30] is that it is relatively easy to allow for fluctuations of the size of the central cell. This scheme is described further below.
