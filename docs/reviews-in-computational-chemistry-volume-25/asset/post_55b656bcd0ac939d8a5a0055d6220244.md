## The Complete Active Space SCF Method

The CASSCF method was developed almost 30 years ago. It was inspired by the development of the Graphical Unitary Group approach (GUGA) to the full CI problem by Shavitt,8, making it possible to solve large CI problems with full control of spin and space symmetry. The GUGA approach is in itself not very helpful because it can only be used with small basis sets and few electrons. It was known, however, that the important configurations (those with coefficients apparently different from zero) in a full CI expansion used only a limited set of molecular orbitals. The following idea, especially the concept of a fully optimized reaction space (FORS) introduced by Ruedenberg and Sundberg in 1976: 

The molecular orbital space is divided into three subspaces: inactive, active, and external orbitals. The inactive orbitals are assumed to be doubly occupied in all configuration functions (CFs) used to build the wave function. The inactive orbitals thus constitute a Hartree-Fock “sea” in which the active orbitals move. The remaining electrons occupy a set of predetermined active orbitals. The external orbitals are assumed to be unoccupied in all configurations. Once the assignment of electrons to active orbitals is done, the wave function is fully defined within the set of active orbitals. The space and spin symmetry are included in the multiconfigurational wave function. This concept of CAS was introduced by B. O. Roos in the 1980s;10,11 A scheme of how the orbitals can be subdivided is presented in Figure 1.

The choice of the correct active space for a specific application is not trivial, and many times one has to make several “experiments.” It is difficult to derive any general rules because every chemical system poses its own problems. The rule of thumb is that all orbitals intervening in the chemical process must be included. For example, in a chemical reaction where a bond is formed/broken, all orbitals involved in the bond formation/breaking must be included in the active space.

![](img/fa9d34afc1bcb785fd3792baa6c5c679_283_0.png) If, on the other hand several electronic states are considered, the molecular orbitals to which electronic excitation have to be included in the active space. There is also a tight connection with the choice of atomic orbital (AO) basis, which must be extensive enough to be able to describe the molecular orbitals (MOs) properly. Moreover, the size of the active space is limited in most software packages for the case where the number of orbitals and electrons are equal. This is the most severe limitation of the CASSCF method and makes it difficult or even impossible to perform a specific study. In this chapter, we shall exemplify how active orbitals are chosen for compounds that pose difficulties in this respect because of the large number of valence orbitals that may contribute to actinide bonds (5f, 6d, 7s, and possibly 7p).

An extension to the CASSCF method exists that has not been used much but may become possible future: The restricted active space (RAS) method where the active space is divided into three regions: RAS1, RAS2, and RAS3. In RAS1 are doubly occupied, but a limited number of holes are allowed. Arbitrary occupation numbers are allowed in RAS2. A limited number of electrons is allowed to occupy RAS3. Many different types of RAS wave functions can be constructed. RAS1 fully occupied and RAS3 empty, where a wave function that includes all single, double, triple and quadruple (SDTQ)-CI wave function of a closed shell reference function is obtained.

The interesting feature of the RAS wave function is that it can work with larger active spaces than CAS without exploding the CI expansion. It thus has the potential to perform multiconfigurational calculations that cannot be performed with the CASSCF method. The problem with the RAS wave function is how to add the effects of dynamic correlation. For CASSCF, second-order perturbation theory (CASPT2, see below) can be used to accomplish this, but this is not yet possible for RAS wave functions. Recent developments in our research group and in the group of Roos indicate, however, that this may become possible in the near future through the development of the RASPT2 method, extending the applicability of multiconfigurational methods to classes of problems that cannot be treated today. This is currently in progress.

## Multiconfigurational Second-Order Perturbation Theory, CASPT2

If the active space has been adequately chosen, the CASSCF wave function will include the most important CFs in the full CI wave function. In this way we include all near-degenerate configurations which describe static correlation effects, for example, in a bond breaking process. The CASSCF function will then be qualitatively correct for the entire chemical process, which could be an energy surface for a chemical reaction, a photochemical process, and the energies that emerge however, not very accurate. We need to include the part of the CF space that describes the remaining (dynamic) correlation effects. This requirement is as necessary in the multiconfigurational approach as it were from the HF single determinant approximation.

How can dynamic correlation be included? In a single configuration, the obvious choices are preferably CC methods, or if the system is too large, second-order perturbation theory (MP2), which is already accurate. A practical multiconfigurational CC theory does not exist. A method that has been used with great success since the 1980s is Multi-Reference CI (MRCI), where the most CFs of the CAS wave function are used as reference configurations in a CI expansion that includes all CFs that can be generated by single and double replacements of the orbitals in the reference functions.¹⁴ The method is still used with some success because of recent technological developments.¹¹⁵ It becomes time consuming for systems with many electrons, however also has the disadvantage of lacking size-extensivity, even if this latter problem can be corrected approximately.

Another way to treat dynamic correlation effects is to use perturbation theory. Such an approach has the virtue of being size-extensive and ought to be computationally more efficient than the MRCI approach. Moller-Pleset second-order perturbation theory (MP2) has been used for a long time to treat electron correlation for ground states, where the reference function is a single determinant of closed-shell molecules. Could such an approach also work for a multiconfigurational reference function like CASSCF? This approach was suggested after the introduction of the CASSCF method.¹⁶ but difficulties delayed a full implementation until the late 1980s,⁷¹⁸ Today is the most widely used method to compute dynamic correlation effects for multiconfigurational (CASSCF) wave functions. The principle is simple: One first computes the second-order energy with a zeroth-order approximation. That said we point out that there are some problems to be solved that do not occur in single determinant MP2. One needs to define a zeroth-order Hamiltonian with the CASSCF function as an eigenfunction. One should preferably be a one-electron Hamiltonian to avoid a too complicated formalism. One then needs to define an interacting space of configurations. These configurations are given as

```
E_{pq}rs|CASSCF
```

[1] is internally contracted configuration space, doubly excited with respect to the CAS reference function [0] = |CASSCF>; one or two of the four p,q,r,s must be outside the active space. The functions of Eq. [1] are linear combinations of CFs and span the entire configuration space that interacts with the reference function.
