## 翻译中的机器学习

《翻译中的机器学习》介绍了与翻译流程最相关的机器学习（ML）理论和技术，从人类视角切入该话题，强调 ML 及其驱动的技术是为人类服务的工具。

本书探讨了人类学习与机器学习的共同点，以及利用这一新维度的翻译本质，帮助语言学家、译者和本地化人员更好地在 ML 驱动的翻译环境中找到自身的附加价值。第 1 部分探讨了人类与机器以各自独特的方式处理翻译问题，涉及词嵌入、更大意义单元的分块以及基于更广泛语境的翻译预测。第 2 部分介绍了关键任务，包括机器翻译、翻译质量评估与质量估算，以及翻译中的其他自然语言处理（NLP）任务。第 3 部分着重探讨了数据在人类学习与机器学习过程中的作用。它提出，译者的独特价值在于在翻译流程的不同 ML 任务中创建、管理和利用语言数据的能力。本书概述了在机器学习时代需要纳入传统翻译教育的新知识与新技能。书末讨论了以人为中心的翻译机器学习，强调有必要通过与 ML 用户、开发人员和程序员的沟通，为译者赋予 ML 知识，并提供持续学习的机会。

这本通俗易懂的指南旨在为本地化工作流中 ML 技术的当前和未来用户提供服务，包括修读翻译与本地化、语言技术及相关领域课程的学生。它支持翻译从业者的职业发展，使他们能够充分利用 ML 技术，并设计自己以人为中心的 ML 驱动翻译工作流和 NLP 任务。

**彭鹏** 是加拿大公共事务及政府服务部翻译局的自由职业会议传译员，渥太华大学翻译与传译学院兼职教授，以及本地化学院 Think NLP 和机器翻译大师班的课程设计者与讲师。她出版过两本中文著作，包括 *哈利·波特及其中文译本*。

**大卫·B·索eyer** 是美国国务院外事学院语言测试主任，美国马里兰大学高级讲师。他是 *口译教育基础：课程与评估* 的作者，以及 *口译与翻译教育不断发展的课程：利益相关者视角与声音* 的合编著（以上两书均由 John Benjamins 出版）。
