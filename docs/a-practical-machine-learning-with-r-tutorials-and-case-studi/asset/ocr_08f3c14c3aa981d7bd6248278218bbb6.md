This section introduces some of the principle ideas Neural Networks. We start in Section 9.4.1 with a graphical representation of a simplified Neural Network that predicts the Price of a diamond based on two predictor variables (Carat and Clarity). In Section 9.4.2, we will show how the graphical representation of a Neural Network can be transformed into the prediction equation of the Neural Network. In Section 9.4.3 we use a numerical example to show how the Neural Network can predict the price of a given diamond based on its carat and clarity when the $eta$ values are determined.
