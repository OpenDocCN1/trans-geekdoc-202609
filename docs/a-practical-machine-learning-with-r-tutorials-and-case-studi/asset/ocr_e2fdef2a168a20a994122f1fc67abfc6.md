# Character Data Type

In the first set of exercises, you will work with character *Data Types*.

# Exercise 1:

The simplest way to use character *Data Types* is to print them, like in the following exercises:

```
print("This is printed text")
```

**Your turn:** Why don't you change the text and print again?

# Exercise 2:

You can assign characters to an *R object*, which then becomes an *R character-object*, and you can print it afterword:

```
Sentence="This is text stored in an R object."
print(Sentence)
```
