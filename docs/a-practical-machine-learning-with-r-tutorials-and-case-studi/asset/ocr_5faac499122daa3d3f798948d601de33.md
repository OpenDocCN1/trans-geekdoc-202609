The decision boundaries in Figure 4.3 create three sub-spaces:

+   1. An area for wines with Acidity > 8 mainly containing red wines. Therefore, any wine falling into this area would be predicted as red.
2. An area for wines with Acidity < 8 and Sulfur < 75 mainly containing red wines. Therefore, any wine falling into this area would be predicted as red. The unknown wine symbolized by the blue point would also be classified as red.
3. An area with Acidity < 8 and Sulfur > 75 mainly containing white wines. Therefore, any wine falling into this area would be classified as white.

The resulting confusion matrix is displayed below:

```
##
## Prediction red white
## red 1016 145
## white 103 974
```

You can see that the accuracy (based on the training data) has improved:

> $Accuracy = \frac{1016 + 974}{1016 + 145 + 103 + 974} = 0.89$

Generating a non-linear decision boundary like in Figure 4.4 is the underlying idea behind Neural Network models (see Chapter 9 for details).
