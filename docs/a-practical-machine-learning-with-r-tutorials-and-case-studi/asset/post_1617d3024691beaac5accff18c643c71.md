## Vector-Objects

You learned that a sequence of numerical, character, or logical objects is a vector object.

For the following exercises, we created four related vector objects: VecFirstNames, VecAges for their age, VecIsFemale to identify if sex is female (or not), and VecNumKids for the number of children they have. To assign values to the vector objects, we use the c(combine) command:

```r
VecFirstNames=c("Carsten", "Jose", "Jane")
VecAges=c(45,54,23)
VecIsFemale=c(FALSE,FALSE,TRUE)
VecNumKids=c(1,2,1)
```

The four vector objects are related because we used the same order for their values. The first value belongs to Carsten, the second value belongs to Jose, and the third to Jane. Therefore, we can deduce Jose is 54 years old, his sex is male (Female), and he has two kids.

It is a little cumbersome that we always have to track the order of elements to interpret the vector values correctly. Fortune, this gets much easier when we use data frames in the following exercise section.

For now, we just assume the order in each of the three vectors is the same and see what we can do with the vector-objects.

## Data Frame Objects

In the previous exercise section, you analyzed the content of different vectors under the assumption that their elements were in the same order. Required remembering the order of elements in a vector when performing analysis, which is cumbersome and can be avoided with data frames.

You can think of a data frame as a table with variables in the columns, variables in the first row, and related observations in all rows — just like an Excel table.

The variables in the columns of a data frame are very similar to vector objects — that they are part of the data frame. In fact, we will show in the exercises that the columns of a data frame can be populated with vector objects and columns of a data frame can be extracted as vector objects.

After a data frame object is defined, you can use commands from the tidyverse package to process the data. Throughout this book, we will almost exclusively work with data frames and use the tidyverse for data engineering.
