# 9.5 Build a Simplified Neural Network Model

Now it is time to see a *Neural Network* in action. This section uses the $R$ net package (Venables and Ripley (2002)) to show a real-world application for *Neural Networks*. In what follows, we will emphasize the outstanding approximation properties of *Neural Networks* but also show how susceptible packages are overfitting.

We use the next package in this section, also more advanced packages such as *PyTorch* which has recently implemented in *R*. You will use PyTorch in the interactive Section 9.7.

The reason to use next here is to stay compatible with Section 9.4. That is, the net package supports Sigmoid activation functions. In contrast, PyTorch only supports more advanced activation functions as Rectified Linear Activation (ReLU) functions (more about ReLU in Section 9.7).

As we start with loading the data and generating training and testing data:

```
library(tidymels); library(janitor)
set.seed(777)
DataDiamonds<- diamonds |>
  clean_names("upper_camel") |>
  select(Price, Carat, Clarity) |>
  mutate(Clarity=as.numeric(Clarity)) |>
  sample_n(500)

Split085 <- initial_split(DataDiamonds, prop=0.85)
DataTrain<-training(Split085)
DataTest<-testing(Split085)
```

As you can see, we use only 500 observations from the diamond dataset and assign 25 observations (prop=0.05; 0.05*500=25) to the training dataset. A training dataset with 25 observations is extremely small for a *Neural Network* application, but it is well suited to demonstrate the overfitting problem later on.
