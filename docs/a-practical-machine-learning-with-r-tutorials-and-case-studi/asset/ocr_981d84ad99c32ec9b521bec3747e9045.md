# 5.4 Univariate Mockup: Study Time and Grades

At this point, we are not yet ready to calculate $eta_{opt}$ according to Equation (5.7) because the formula also requires calculating the sum of the product of the observations for $y_i$ and $x_i$ ($\sum_{i=1}^N y_ix_i$) as well as the sum of the squares of the $x_i$ values ($\sum_{i=1}^N x_i^2$). However, we can use the mutate() command to add these variables to the frame DataMockup and call the new result frame DataMockup:

```
DataTable<-DataMockup |>
mmutate(GradeStudyTime=Grade$StudyTime)
mmutate(StudySquared=StudyTime^2)
```

Table 5.2 shows the resulting data frame DataTable.

Next, we calculate the sums of $\sum_{i=1}^N y_ix_i$ and $\sum_{i=1}^N x_i^2$ (see the code below). When we plug in these sums together with the previously calculated sums $\sum_{i=1}^N x_i$ and $\sum_{i=1}^N y_i$ and the value for $N = 5$ into Equation (5.7)

```
N=5
SumOffsetY=sum(DataTable$Grade)
OfFX=sum(DataTable$StudyTime)
SumOfXY=sum(DataTable$GradeStudyTime)
SumOfSq=sum(DataTable$StudyTimeSquared)

Betaopt=(N*SumOfXY-SumOffsetY*SumOfFX)/(N*SumOfSq-SumOfFX^2)
```

> *Based on the training dataset the optimal value for Beta = \*
Betaopt*

## on the training dataset the optimal value for Beta = 3.963
Afterward, we can plug in the value of $eta_{opt}$, into Equation (5.8) together $\sum_{i=1}^N y_i$ and $\sum_{i=1}^N x_i$ to calculate $eta_{2opt}$.

```
Beta2opt=(SumOffsetY-Betaopt*SumOfFX)/N
cat("Based on the training dataset the optimal value for Beta2 =", Beta2opt)
```

## on the training dataset the optimal value for Beta2 = 64.188
