# 10 Tree-Based Models — Bootstrapping Explained

We start with downloading the data, selecting the outcome, the predictor
variables, and we will use later to weigh our observations.

```
library(rio); library(tidymodels); library(xgboost)
DataVax<-import(\https://ai.lang-analytics.com/DataVax.rds") |
select(PercVacFull, PercCep,
  Percasian, PercBlack, PercHish,
  PercYoung25, PercOld65,
  PercFoodSt, Population) |
mutate(Population=Frequency_weights(Population))
```

Since we tune some of the hyper-parameters of the XGBoost algorithm,
again we use the 10-Step Tuning Template from Section 6.6:

# Step 1 - Generate Training and Testing Data: The training and test-
ing data as follows:

```
set.seed(2021)
Split85<-initial_split(DataVax, prop=0.85, strata=PercVacFull,
breaks=3)
```

```
DataTrain<-training(Split85)
DataTest<-testing(Split85)
```

# Step 2 - Create a Recipe: The recipe below determines the outcome vari-
able(PercVacFull) and chooses all other variables as predictor vari-
ables, which excludes Population because this variable was set to fre-\quency_weights() when the data were loaded and the variables were selected:

```
RecipeVax<-recipe(PercVacFull),, data=DataTrain
```

# Step 3 - Create a Model Design: The model design uses the
tree() command to choose a Gradient Boosting machine learning mo-\del. The algorithm XGBoost is in the set_engine() command with
the argument xgboost. Since we predict a continuous variable (the vaccina-
rate), set_mode() is set to regression

```
ModelDesignBoostTrees<-boost_tree(trees=tune(), tree_depth=tune()) |
set_engine("xgboost") |
set_mode("regression")
```

For the boost_tree() command, we set two hyper-parameters for tuning.
The hyper-parameter determines the number of Decision Trees, and the
hyperparameter tree_depth specifies how many levels of each Decision
Trees has.
