Due to the complexity and the demanding computational resources, Deep Neural Networks are beyond the scope of this. Instead, we will explain the basic concepts of Deep Learning using a simpler Neural Network type called Multi-Layer Perceptron (MLP).

MLP Neural Networks were among the first Neural Networks to be developed. The principles of MLP Neural Networks can also be applied to more complex and sophisticated Neural Networks. After reading this chapter you will have a good idea about the basic functionality of Deep Neural Networks.

MLP Neural Networks consist of one or more layers, each layer contains at least one neuron. The layers in MLP Neural Networks are fully connected, meaning that each neuron in one layer can pass information to each neuron in the following layer. Figure 9.1 in Section 9.4.1 shows a basic example of a fully connected MLP Network with an input layer (2 neurons), a hidden layer (2 neurons), and an output layer (1 neuron).

Neural Networks are used for classification and regression tasks. Here, we will focus on regression tasks. Throughout this chapter, we will use the diamonds dataset to predict diamond prices based on a diamond's properties. We will introduce the diamonds dataset in detail in Section 9.3.
