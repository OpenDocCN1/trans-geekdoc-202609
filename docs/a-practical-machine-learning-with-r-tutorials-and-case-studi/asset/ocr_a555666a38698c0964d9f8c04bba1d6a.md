# Takeaways from the MSE

MSE for the univariate OLS regression with $N$ observations can be calculated as:

> $MSE = \frac{1}{N} \sum_{i=1}^{N}(\beta_1 x_i - y_i)^2$ with $x_i$ and $y_i$ known from the training dataset.

+   1. When the training data are given, only the choice of the $eta$ parameters determines the MSE. Since both — the values for $x_i$ and $y_i$ — are part of the training dataset, the MSE depends only on the chosen values for the $eta$ parameters.
2. Since different $eta_1$ and $eta_2$ generate different MSEs, the goal is to find a pair of $eta$ that leads to the smallest MSE.

In the following Section 5.4.2, you will learn how to calculate the optimal values $eta_{1,opt}$ and $eta_{2,opt}$ for the mockup example using OLS. Afterward, in Section 5.4.3, we will introduce two algorithms that a computer can use for a systematic trial-and-error approach to find the optimal values $eta_{1,opt}$ and $eta_{2,opt}$.
