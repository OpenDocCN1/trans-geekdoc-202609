## 11.5 Visualizing the Impact of Changing Predictor Variables

In this section, we will use Ceteris Paribus Plots and Partial Dependence Plots to visualize how a change in a single predictor variable impacts the predictions for the outcome variable.

We analyze changes of the variable Tenure, but the methodology is also valid for changes of other predictor variables.

### 11.5.1 Ceteris Paribus Plots

Ceteris Paribus Plot visualizes how the values for a predictor variable impacts the prediction for a single observation of interest (local interpretation). The observation of interest here is for Helga:

```r
## A tibble: 1 x 5
## Wage Edu Tenure Female .pred
## <dbl> DALEX: <dbl> <dbl> <dbl>
## 1 8.9 17 18 1 9.24
```

In the previous section, we predicted a wage of $89.24 for Helga. But would Helga's predicted wage change if her Tenure was greater or smaller and all other predictor values would remain the same?

To find the answer, we need to leave Tenure=17 and Female=1 as they are. Then, we use the Random Forest workflow WfModelWageRF to generate wage predictions for various values of Tenure. The graphical representation of the result leads to the Ceteris Paribus Plot in Figure 11.1.

In the Ceteris Paribus Plot, the Tenure values are plotted against the related wage predictions from the Random Forest model. The plot in Figure 11.1 was generated with the following R code:

```r
library(DALEX)
ExplainerRF=DALEX::explain(extract_fit(WfModelWageRF), data=DataTrain, y=DataWage)
PPlot=predict_profile(explainer=ExplainerRF, observation=ObsHelga, variables="Tenure")
plot(PPlot, variables="Tenure")
```

> In general, only one variable to change and leaving other variables constant is called ceteris paribus (Latin for: everything else the same). Thus, the name of the plot.

![f240d449191f5add983daf6c380e43.png]

**FIGURE 11.1 Ceteris Paribus Plot for Tenure**

Most interpretation algorithms work in two steps. First, an explainer object (here ExplainerRF) is created, which is a container that stores the training data, the model design, and some other information that does not perform any interpretation tasks. In the second step, the interpretation is performed with another command based on the explainer object. Note, when we create the explainer object with the command `explain()`, the command is prefixed with DALEX::. This ensures that both the tidyverse package and the package that we use later contain a command `predict_profile()`.

The Ceteris Paribus plot is created with the command `predict_profile()`. Arguments are the explainer (`explainer=ExplainerRF`), the observation used for the plot (`observation=ObsHelga`), and the variable that is analyzed (`variables="Tenure"`). In the Ceteris Paribus plot in Figure 11.1, Helga's Tenure/Wage combination is marked with a blue dot. You can see that Helga's wage would mostly stay the same if she had more or less tenure. However, if Helga had much less tenure (Tenure < 8), her predicted wage would be much smaller. All this makes sense for somebody with high tenure and education.

### 11.5.2 Partial Dependence Plot

Ceteris Paribus plot interprets the prediction for a specific observation (local interpretation). What if we want to get a global interpretation of the whole model? The following section provides a tool for this purpose.

The idea behind Partial Dependence Plots is first to create Ceteris Paribus plot for every or at least many observations from the training dataset and create an ensemble of these individual plots. You can see the individual Ceteris Paribus plots in Figure 11.2 as light grey lines. Each line represents a Ceteris Paribus plot for one of the training observations. The ensemble of grey lines in Figure 11.2 is called Individual Conditional Expectation (ICE) plot.

![f240d449191f5add983daf6c380e4fe3.png]

**FIGURE 11.2 ICE Plot Combined with Partial Dependence Plot**

If we calculate for each Tenure value the average from the related values of the light grey lines (the ICE plots), we get the bold blue line, which is called a Partial Dependence Plot (PDP).

```r
library(DALEX)
ICEPDP=model_profile(explainer=ExplainerRF, variables="Tenure", N=NULL)
plot(ICEPDP) + ggtitle("ICE & PDP for Tenure")
```

The model_profile() generates the plot based on the explainer defined above (explainer=ExplainerRF), and selects the predictor variable to be analyzed (variables=Tenure). The argument NULL determines that all training observations are used for the ICE plot. Alternatively, N random observations from the training dataset can be used.

The PDP plot (bold blue line) in Figure 11.2 shows how Tenure determines the predicted wage for the Random Forest model. In the first 17 years, higher values increase the predicted wage with a sharp increase in years 16 and 17. Afterward, a longer tenure does not lead to a significant increase in predicted wage. This is what one expects. Companies value tenure up to a certain degree. Afterward, an increasing tenure neither helps nor hurts.

## 11.6 Variable Importance for Tree-Based Models

In the previous section, we used Ceteris Paribus plots and Partial Dependence Plots to analyze the quantitative impact of predictor variable changes. In contrast, Variable Importance Plots (VIP) focus on the relevance of a predictor variable rather than its quantitative impact on the outcome. As the name suggests, VIP focus on predictor variable importance.

VIPs can help decide if a specific predictor variable is important enough to be kept in a model or if it should be dropped.
