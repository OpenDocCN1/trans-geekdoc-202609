To fit a workflow model with the training data, we must add the recipe
and use the built-in Optimizer and the training
data (DataTrain) to find optimal parameters for the bs:

```
WFModelNN=workflow() %>nadd_model(ModelDesignNN) |nadd_recipe(RecipeDiamonds) |nfit(DataTrain)
```

Since the workflowModelNN is now a fitted workflow, we can use it for pre-
dicting models.

We start with generating predictions for the training dataset and evaluating
how well the predictions approximate the true values in the training dataset.
Again, we use the augment() command to create the predictions. These predic-
t are augmented to the training dataset by creating an extra column
pred. The resulting dataframe is saved as DataTrainWithPred.

The metrics() command then compares for each observation the prediction
(.pred) with the true value for the diamond (Price) and calculates the
root of the mean squared error MSE, r^2 and the mean absolute error (mae)
for the training:

```
DataTrainWithPredNN=augment(WFModelNN, new_data=DataTrain)
metrics(DataTrainWithPredNN, truth=Price, estimate=$pred)
```


As you can see, the Neural Network approximates the training data extremely
well. For example, r^2 = 0.996.
