**Step 4:** Two effective inputs — one for each hidden neuron — are now plugged into non-linear functions (called *activation functions*) inside hidden neuron $H1$ and $H2$. The results are called the *activities* ($A_{H1}^\sigma$ and $A_{H2}^\sigma$) of the neurons $H1$ and $H2$. We will talk more about activation functions in a minute.

## 9.4 The Idea Behind Neural Network Models

**Step 4:** Two effective inputs — one for each hidden neuron — are now plugged into non-linear functions (called *activation functions*) inside hidden neuron $H1$ and $H2$. The results are called the *activities* ($A_{H1}^\sigma$ and $A_{H2}^\sigma$) of the neurons $H1$ and $H2$. We will talk more about activation functions in a minute.

**Step 5:** The activities of the hidden neurons $A_{H1}^\sigma$ and $A_{H2}^\sigma$ are transmitted to the output neuron (O1), but before they arrive, their values are weighted by $\beta_1$ and $\beta_2$, respectively.

**Step 6:** Three values arrive at the $\oplus$ sign in front of the output neuron (O1): the two weighted *activities* from the hidden neurons ($\beta_1 A_{H1}^\sigma$ and $\beta_2 A_{H2}^\sigma$) and the value from the bias neuron $B2$, which equals $\beta_7$. These three values are aggregated (added up) to a single value, which is the value of the output neuron O1, and the predicted price for the related diamond.

In complex contexts, the output neuron O1 may also contain an activation function, but here what goes into the output neuron comes without any transformation ($O1 = f^\sigma(O1)$).

The above, in connection with Figure 9.1, provide a basic idea about how a Neural Network processes variables to generate a prediction for an outcome variable. If the Neural Network contains more input and hidden neurons, or more layers, the process is more complex, but the underlying idea is the same.

However, two questions have not been answered so far:

**Question 1:** We assumed that for the initial values of $\beta_j$: How are they determined?

**Answer:** The answer to this question is simple for the initial values of $\beta_j$ (usually $-1 < \beta_j < 1$). This makes it possible to generate initial predictions for all observations in the training dataset. The resulting initial predictions are not very good. We need improvement by updating the $\beta$ parameters in an iterative process. This updating process — called training the Network — is a little more complex. We will discuss the underlying basics in Section 9.4.4 after we cover a numerical example for a prediction in Section 9.4.3.

**Question 2:** How are the *activation functions* inside the hidden neurons $H1$ and $H2$ transforming the *effective input values* ($I_{j,1}^\sigma$ and $I_{j,2}^\sigma$) into the activities of the hidden neurons ($A_{H1}^\sigma$, and $A_{H2}^\sigma$)?

**Answer:** This is a bit more tricky: Various activation functions can be used inside a hidden neuron to transform the *effective inputs* $I_{j,i}^\sigma$ into an activity $A_j^\sigma$ ($j$ stands for the hidden neuron number and $i$ for the observation number). Here, we use the Logistic function — the same function we used for Logistic Regression in Chapter 8. We plug the effective inputs $I_{1,i}^{eff}$ and $I_{2,i}^{eff}$ into the Logistic function and calculate the activities $A_{1,i}^{cl}$ and $A_{2,i}^{cl}$ for the hidden neurons $H1$ and $H2$:

$$A_{1,i}^{cl} = \frac{1}{1+e^{-I_{1,i}^{eff}}} \quad (9.1)$$
$$A_{2,i}^{cl} = \frac{1}{1+e^{-I_{2,i}^{eff}}} \quad (9.2)$$

### 9.4.2 Transforming the Graphic Approach Into a Prediction Equation

Figure 9.1 and Step 3 above show the structure of a *Neural Network*, but for using a computer to make predictions, the graph needs to be transformed into a prediction equation, which is the goal of this section.

Figure 9.1 and 3 show how the *effective inputs* for the two hidden neurons are calculated from the weighted predictor variables and the bias neurons. From an observation, this can be expressed in the two equations determining $I_{1,i}^{eff}$ and $I_{2,i}^{eff}$:

$$I_{1,i}^{eff} = \beta_1 + \beta_2 Carat + \beta_3 Clarity, \quad (9.3)$$
$$I_{2,i}^{eff} = \beta_4 + \beta_5 Carat + \beta_6 Clarity, \quad (9.4)$$

We can substitute $I_{1,i}^{eff}$ and $I_{2,i}^{eff}$ into Equations (9.3) and (9.4) into the activation functions (9.1), and (9.2) and we get the *activities* for the hidden neurons:

$$A_{1,i}^{cl} = \frac{1}{1+e^{-(\beta_1+\beta_2 Carat+\beta_3 Clarity)}} \quad (9.5)$$
$$A_{2,i}^{cl} = \frac{1}{1+e^{-(\beta_4+\beta_5 Carat+\beta_6 Clarity)}} \quad (9.6)$$
