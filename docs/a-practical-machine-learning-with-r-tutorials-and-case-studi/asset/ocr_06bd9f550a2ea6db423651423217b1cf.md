# Fitted Model vs. Unfitted Model

An unfitted model is a prediction equation like Equation (5.4) in Section 5.4.1 or a model that has not been fitted to the training data (i.e., if we omit fit(xatrain) in the workflow code). An unfitted model contains the rule of how predictions are built. Still, because the numerical values for the parameters ($\$\beta$) are not determined — an unfitted model cannot be used to predict.

When we determine the optimal values for the parameters ($\beta$) by minimizing the MSE, we calibrate (it$\hat{M}$) to the training data. The model becomes a fitted model.

A fitted model can be used directly for predictions because the numerical values for its parameters ($\beta$) have been determined.

We use the tidy() command to extract the parameters and other useful information. In general, the tidy() command extracts important information from various types of $R$ objects and returns a data frame that can be saved for further processing. We output the data frame to the Console:

```
tidy(WFModelMock)

## Able: 2 x 5
## term std.error statistic p.value
## <chr> dbl dbl dbl
## #1 (Intercept) 64.2 6.06 10.6 0.00180
## #2 StudyTime 3.96 1.14 3.48 0.0399
```

As you can see in the column estimate, the value for the parameter related to StudyTime ($\beta_{2,opt}$) and the one related to the intercept of the prediction function ($\beta_{1,opt}$$, $\$\beta_{2,opt}$) are the same as ones we calculate manually. Using a real-world dataset, we will interpret the other columns from the tidy() output layer in Section 5.5.
