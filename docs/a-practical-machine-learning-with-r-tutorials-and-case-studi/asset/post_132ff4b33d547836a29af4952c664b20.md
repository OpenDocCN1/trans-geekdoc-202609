### 5.4.3.2 Finding Optimal Parameters Using an Optimizer

The Grid Search algorithm tries all possible pairwise $\beta$ combinations. However, as we saw, it can be very slow. This raises the question if it is really necessary to calculate the $MSE$ for all pairs or if there is a more systematic approach.

Different types of $Optimizers$ fill this void. In general, the process for an $Optimizer$ to find an $MSE$-minimum can be described in four steps:

- The Optimizer uses a guess for the parameters to start the Optimizer process.
- For example, we use $\beta_1 = 4$ and $\beta_2 = 61$ as a first guess.
- The Optimizer uses the error function to calculate the target $MSE$-value for the chosen parameters.
- We will use the function to calculate the $MSE$ based on the training data and the $\beta_1$ and $\beta_2$ parameters.
- The Optimizer changes the parameters so that the new result in a lower target value (a lower $MSE$).
- Repeat Steps 2 and 3 until the target value ($MSE$) approximately reaches a minimum.

The process described above leads to a local minimum. A local minimum guarantees that no $\beta$-combination with a lower $MSE$ exists in the close vicinity of the minimum (similar $\beta$). However, it is possible that the minimum found is not unique and other local minima exist. Some or all of these local minima have a smaller $MSE$.

In practices, the problem of a local minimum is negligible. In some cases (including linear regression), we already know that only one minimum exists. In other cases, the predictive quality is already good, and it is not very relevant if we can improve it.

Most importantly, a high approximation of the training data might lead to overfitting — approximating the training data poorly (more in Chapter 6). Therefore, finding the lowest minimum (global minimum) for the $MSE$ for the training data might not be in our best interest. The old saying “Perfect is the enemy of the good”, applies.

The good message is that $Optimizers$ are already integrated into almost all machine learning algorithms. They are executed automatically and can be treated as a black box.
