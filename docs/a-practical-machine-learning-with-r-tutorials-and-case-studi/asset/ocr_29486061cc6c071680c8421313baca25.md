# 10.3.1 The Idea Behind a Decision Tree

The best way to introduce the idea behind Decision Trees is to see the algo-rith in action. We will use the Titanic dataset¹ to generate a Decision Tree and discuss the resulting graph.

In the code block, we download the data, rename the variables into UpperCamel form, and select(Survived, Sex, Class (renamed from Pclass), Age, and Fare (renamed from FareInPounds) for the analysis. We use mutate() to convert data type (Survived = TRUE for a passenger that survived and Survived = FALSE otherwise). Since we perform a classification task, the outcome survived also has been converted into a factor variable:

```
library(rio);library(titanicmodels);library(janitor)
DataTitanic=import("https://ai.lang-analytics.com/data/Titanic.csv") |
  clean_names("upper_camel") |
  select(Survived, Sex,Pclass, Age,
  Fare=FareInPounds) |
  mutate(Survived=as.logical(Survived)) |
  mutate(Survived=as.factor(Survived))
```

Afterward, as usual, we create a training and a testing dataset:

