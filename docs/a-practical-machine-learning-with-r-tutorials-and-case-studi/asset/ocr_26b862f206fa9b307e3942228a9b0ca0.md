# # Training and Testing Data

When working with data to build machine learning models and evaluate their predictive quality, we split the observations into two different datasets.

**Training data** are used to optimize a machine learning model, which includes finding promise for the parameters and *hyper-parameters* that provide the best for a well-performing model.

**Testing data** constitute a holdout dataset exclusively to assess the predictive quality of a machine learning model.

*Never use testing data for any kind of optimization!*

Why we must follow the above rule strictly will be covered in detail in Chapter 6. Which proportion should be used for training and which proportion should be withheld for assessment is difficult. As a rule of thumb, around 60%-85% of the observations should be used for training and the remaining observations for testing. In any case, we have to ensure that the training dataset contains sufficient observations to optimize the parameters.

*R* code to randomly assign observations to either the *training or testing* dataset can be tedious. With the *R tidymodels* package, randomly splitting the dataset into *training* and *testing* data is straightforward.

In the *R* code below, we load the *tidymodels* package and use `initial_split()` to define the splitting criteria to assign observations to either the training or the testing dataset. The command `initial_split()` performs the training(Split7030) and testing(SplitSplit7030) in the following two lines, we extract the training and testing data and assign them to the data frames *DataTrain* and *DataTest*:

```
library(tidymodels)
set.seed(876)
DataTrain<-training(Split7030, prop=0.7, strata=WineColor)
DataTest<-testing(Split7030)
```

The `set.seed()` command in the code initializes *R*'s random number generator. This is recommended because we want to avoid a setup where we must deal with different training and testing data every time we execute the code. Consequently, we initialize the random number generator using an integer number.
