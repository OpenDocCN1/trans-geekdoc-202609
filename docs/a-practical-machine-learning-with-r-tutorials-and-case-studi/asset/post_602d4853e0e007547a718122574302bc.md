## 10.5.1 The Idea Behind Gradient Boosting

As mentioned above, Gradient Boosting builds Decision Trees based on prediction errors. No such prediction errors are at the starting point of building the Gradient Boosting ensemble; an initial prediction is needed. Gradient Boosting starts with the mean of the outcome as prediction for all observations. Afterward, it uses the errors from previous predictions to build new trees to enrich the ensemble.

To explain the process in detail, let us see step-by-step how Gradient Boosting works. To keep it simple, limit the ensemble only to three Decision Trees. In reality Gradient Boosting works with many Decision Trees.²²

Let us assume we want to create an ensemble with Decision Trees $D_1^{Tree}, D_2^{Tree}$, and $D_3^{Tree}$. The goal is to produce an outcome variable $Y_i$.

As mentioned, the initial prediction is only based on the mean of the outcome from the following dataset:

```
$$\hat{Y}_i = \bar{Y} = \frac{1}{N} \sum_{i=1}^{N} Y_i\quad (10.2)$$
```

Note that Equation (10.2) implies that the predictions for all observations are the same because the mean of the outcome is a single number. This is reasonable, but Equation (10.2) represents a very weak learner, and thus we expect large prediction errors $(u_{0,i})$. We can calculate these errors for all training observations because we know the true outcome for each training observation:

```
$u_{0,i} = Y_i - \bar{Y}\quad (10.3)
```

Note that the index 0 in $u_{0,i}$ indicates that the errors for the $i$ observations are related to the starting prediction in the *ensemble*. Equation (10.3) can also be written as Equation (10.4), which states that at the initial stage, the known outcomes from the training dataset $Y$, consist of the predicted outcome $(\hat{Y})$ and the related errors:

```
$Y_i = \overline{Y} + u_{0,i}\quad(10.4)$
```

Because we used a *weak learner*, the errors $u_{0,i}$ most likely contain systematic impacts on the outcome. To integrate these systematic impacts, we can create a *Decision Tree* ($D^{Tree}(Obs_i)$) that uses the known errors (see Equation (10.3)) as values for the certain variable and variables from the training dataset as predictor variables ($Obs_i$). Predicting errors seems to be a little odd, but please bear with us. It will make perfect sense very soon.

Below is the prediction equation for the initial errors based on the first *Decision Tree*:

```
$u_{0,i} = D_i^{Tree}(Obs_i)\quad(10.5)$
```

Since the *Decision Tree* in Equation (10.5) does not predict the initial errors $(u_{0,i})$ perfectly, it will also create its own prediction errors $(u_{1,i})$. Consequently, the true errors consist of the predictions from the first *Decision Tree* and the errors related to these predictions:

```
$u_{0,i} = D_i^{Tree}(Obs_i) + u_{1,i}\quad(10.6)$
```

Substituting Equation (10.6) into Equation (10.4) gives:

```
$Y_i = \overline{Y} + D_i^{Tree}(Obs_i) + u_{1,i}\n\hat{Y}_i\quad(10.7)$
```

Now, you can see why predicting errors makes sense. Equation (10.7) shows that the predictions $\hat{Y}_i$ is not only based on the mean of the outcome $(\overline{Y})$ but also on the first *Decision Tree*'s prediction $(D^{Tree}(Obs_i))$.

*Gradient Boosting* is a slight modification from the prediction in Equation (10.7). Gradient Boosting predicts the outcome at the stage of the first *Decision Tree* as:

```
$Y_i = \overline{Y} + \gamma D_i^{Tree}(Obs_i) + u_{1,i} \text{ with: } 0 < \gamma < 1\n\hat{Y}_i\quad(10.8)$
```

Equation (10.8) is identical to Equation (10.7), except that the influence of the *Decision Tree* is weakened by multiplying with the learning rate $\gamma$. The learning rate $\gamma$ is a tunable *hyper-parameter*. It is usually set to values considerably smaller than one. For example, the *Gradient Boosting* algorithm *XGBoost* in *tidymodels* uses $\gamma=0.3$ as the default learning rate.

Since in Equation (10.8) $\gamma$ weakens the influence of the first Tree, it is reasonable to assume that the related errors $(u_{1,i})$ still contain some impacts on the outcome variable $Y$. Therefore, we create a second Decision Tree ($D^{Tree}(Obs_i)$) based on the predictor variables in the training dataset and the known errors from the first Decision Tree. These errors are known because we can calculate them as the difference between the known outcome values from the training dataset and the predictions from Equation (10.8):

```
$Y_{1,i} = \overline{Y} + \gamma D_i^{Tree}(Obs_i)\quad \text{with: } 0 < \gamma < 1$
```

After creating the second Decision Tree $(D^{Tree}(Obs_i))$ to predict the errors from the first Tree $(u_{1,i})$, the prediction equation for the outcome $Y$ improves to:

```
$Y_i = \overline{Y} + \gamma D_i^{Tree}(Obs_i) + \gamma^2 D_i^{Tree}(Obs_i) + u_{2,i}\quad \text{with: } 0 < \gamma < 1$
```

The errors from the prediction by the second Decision Tree $(u_{2,i})$ may still contain some information, and since their values are known, we can use a third Decision Tree to integrate the systematic impacts from these errors, which leads to:

```
$\widehat{Y}_{i} = \overline{Y} + \gamma D_i^{Tree}(Obs_i) + \gamma^2 D_i^{Tree}(Obs_i) + \gamma^3 D_i^{Tree}(Obs_i) + u_{3,i}\quad(10.9)\quad \gamma < 1$
```

We stop here because we decided to use only three Decision Trees. In real-world applications, the number of Decision Trees to be added is a tunable *hyper-parameter* for *Gradient Boosting* models. Equation (10.9) can be used to predict the outcome $Y_i$ for any observation $i$ as long as the values for predictor variables $(Obs_i)$ are known. For example, we could use the observations from a testing dataset to assess how well a *Gradient Boosting* model performs. Equation (10.9) also allows us to explain why weakening the influence of Decision Trees through the learning rate $\gamma$ makes sense. Assume we would have a prediction as Equation (10.9) without a learning rate $\gamma$ but with more Decision Trees. The errors of each Decision Tree would be artificially weakened by the following Decision Tree, and this correction would not be. Such an unregulated correction could lead to a severe overfitting problem because the prediction equation could possibly approximate the training data almost perfectly.
