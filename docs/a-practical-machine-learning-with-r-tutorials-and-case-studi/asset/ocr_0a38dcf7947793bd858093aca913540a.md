Step 8 - Extract the Best Hyper-Parameter(s): All assessment results for the specified metrics are stored in the tuning object TuneResults. Choose the metric accuracy by substituting <METRIC>. ```


As you will see in the printout after executing the R code, the best value for the hyper-parameter neighbors based on accuracy is 1. It is saved in the data frame BestHyperParam.
