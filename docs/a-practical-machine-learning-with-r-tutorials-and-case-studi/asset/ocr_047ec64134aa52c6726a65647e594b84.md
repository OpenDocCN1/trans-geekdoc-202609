In the examples below, we demonstrate a few applications of filter(). For this, we use the data frame TitanicNarrow that we created using the select() command:

# Analyzing only male passengers:

If we want to analyze the male passengers and then save the results in a new frame, TitanicMen, we can use:

```
TitanicMen=filter(TitanicNarrow, Sex=="male")nhead(TitanicMen)
```

In the code block above, when we filtered for male passengers, we used Sex=="male" as a condition. This condition could be translated to: "the variable-name sc.x is required to be "male".

Please note the following two techniques:

+   1. we == instead of = This is required in R and in most other programming languages because == indicates a condition rather than an assignment. Forgetting the second "="-sign in the condition is a common mistake. Fortunately, R gives a distinct error when this happens.

+   2. The word "male" must be written in quotes because the condition requires the variable Sc.x equals the char-value "male" and not the object male.

# Analyzing only passengers with low fares:

To filter the data frame for passengers with a fare below £7 and then save the results in the new data frame, TitanicLowFare, you can use the following R code:

```
TitanicLowFare=filter(TitanicNarrow, FareInPounds<7)
head(TitanicLowFare)
```
