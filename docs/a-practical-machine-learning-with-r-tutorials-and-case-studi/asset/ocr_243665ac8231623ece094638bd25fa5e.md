# 7.4 The Idea Behind Regularization

The goal of $regularization$ — to generate smaller or zero $eta$ parameters — leads to the following question:

How we influence the Optimizer to produce smaller model-parameters than the ones that minimize the Mean Squared Error?

The answer is that we must give the $Optimizer$ a different goal. Such a goal is formalized in the target function:

```
$T^{target} = \frac{1}{20}\sum_{i=1}^{20} (Price_i - Price_i^*)^2 + \lambda Penalty \quad (7.3)$
```

with:
$Price_i = \beta_1 Sqft_i + \beta_2 Sqft_i^2 + \beta_3 Sqft_i^3 + \beta_4 Sqft_i^4 + \beta_5 Sqft_i^5 + \beta_6$

You can see now that the target function consists of the $MSE$ and a $penalty$ term ($Penalty$). Hence, we call it a $target$ function rather than an $error$ function. The goal for the $Optimizer$ is twofold:

+   - Minimizing the $MSE$.
- Minimizing a penalty value which is high when the $model$-parameters (the $eta s$) are large and low otherwise.

The $MSE$ and $P^{penalty}$ will still only depend on the values for the $eta s$. Therefore, the $Optimizer$ can minimize the target function (7.3) as with systematic $trial-and-error$.

The $hyper-parameter \lambda$ $(0 \le \lambda < +infty)$ determines the strength of the $P^{penalty}$ relative to the $MSE$.

Two major approaches exist to quantify the $penalty$:

**Lasso:** The $penalty$ is calculated as the sum of all (absolute) $\beta$ values, except the one for the intercept $(\beta_0)$:

```
$P^{penalty}_{Lasso} = \sum_{j=1}^{5} |\beta_j| \quad (7.4)$
```

While reducing a large or a small $\beta$ by the same amount has the impact on the $penalty$.

**Ridge:** The $penalty$ is calculated as the sum of all squared $\beta$ values, except the one for the intercept $(\beta_0)$:

```
$P^{penalty}_{Ridge} = \sum_{j=1}^{5} \beta_j^2 \quad (7.5)$
```
