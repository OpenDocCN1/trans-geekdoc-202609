**Step 6 - Creating Resamples for Cross-Validation:** The values you have created for k (hyper-parameter neighbors) will be evaluated later using five folds (resamples). Each fold contains the complete training data, but different sections are used for training and assessment in each fold.

Please create five folds by substituting <NUMBER OF FOLDS> accordingly.
The folds will be saved in the R object FoldsForTuning:

```
set.seed(123)
FoldsForTuning<-vfold_cv(DataTrain, v=<NUMBER OF FOLDS>,
```
