## 拟合模型 vs 未拟合模型

未拟合模型是一个预测方程，例如第 5.4.1 节中的方程 (5.4)，或者是尚未对训练数据拟合的模型（即如果在工作流代码中省略了 `fit(xatrain)`）。未拟合模型包含了构建预测的规则。尽管如此，由于参数 ($\beta$) 的数值尚未确定——*未拟合模型无法用于预测*。

当我们通过最小化 MSE 来确定参数 ($\beta$) 的最优值时，我们就是对训练数据进行了校准 ($\hat{M}$)。模型变成了拟合模型。

拟合模型可以直接用于预测，因为其参数 ($\beta$) 的数值已经确定了。

## 5.4.3 通过试错法寻找最优参数

接下来的章节将使用试错法来寻找最优的 $\beta$。由于我们已经在上一节中计算了 $\beta_{1,opt}$ 和 $\beta_{2,opt}$，我们可以将这些结果作为基准，看看试错法的性能如何。

## 5 线性回归 — 核心机器学习概念

```
$$MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$
$$\longleftarrow \text{预测 } i$$
$$MSE = \frac{1}{N} \sum_{i=1}^{N} (\beta_1 x_i + \beta_2 - y_i)^2 \quad (5.9)$$
```

方程 (5.9) 提供了计算 *MSE* 的公式。对于训练数据集（所有 $y$ 和 $x_i$ 均已知），我们可以选择任意一对 $\beta_1$ 和 $\beta_2$，并使用方程 (5.9) 计算相关的*均方误差*（详情见第 5.4 节）。然而，我们不会随意选择 $\beta_1$ 和 $\beta_2$ 的值，而是使用更系统的方法。

在第 5.4.3.1 节中，我们使用网格搜索（Grid Search）：首先，我们分别生成包含各种值的向量 $\beta_1$ 和 $\beta_2$。然后，我们将使用 R 生成 $\beta_1$ 和 $\beta_2$ 值的所有可能组合。对于 $\beta_1$ 和 $\beta_2$ 的每一个结果，我们将计算 $MSE$，并最终选择 $MSE$ 最低的一对。

在第 5.4.3.2 节中，我们将使用优化器（Optimizer）来寻找 $\beta_1$ 和 $\beta_2$ 的最优值。*优化器*是一个可以最小化或最大化目标函数的迭代算法。在我们的情况下，$MSE$ 函数 (5.9) 就是目标函数。
