
## 9.6 NNet vs. PyTorch (brulee)

- **epochs**: Determines the maximum number of epochs used by the Optimizer for training. Internally PyTorch generates a validation dataset and if the prediction error does not improve for five consecutive epochs, it stops the training even if the maximum number of epochs set by epochs has not been reached.

- **hidden_neurons**: This hyper-parameter determines the number of hidden neurons, and at the same time, the number of hidden layers. When working with only one hidden layer like here, you can assign a number to hidden_neurons, which determines the number of neurons for the only hidden layer (e.g., hidden_neurons=50 for the only hidden layer).

Suppose you like to work with more than one layer. In that case, you must assign a vector to hidden_neurons where each element determines the number of hidden neurons for consecutive hidden layers (e.g., hidden_neurons=(25, 30, 28) for a Neural Network with three layers where the first layer contains 25 neurons, the second layer of 30 neurons, and the third of 20 neurons.

- **dropout**: PyTorch allows randomly switching off a predefined percentage of hidden neurons for each iteration of the Optimizer process. The value assigned to dropout determines the proportion of hidden neurons randomly switched off at each iteration. For example, dropout=0.25 indicates that the Optimizer randomly switches 25% of the hidden layer's neurons at each iteration of the training process.

- **penalty**: Determines the weight of the penalty term compared to the MSE in the target function when regularization is used (see Chapter 7 for details). By default Ridge regularization is used with penalty=0.001.

### 9.6.2 ReLU Activation Functions

Unlike the next package, PyTorch supports ReLU activation functions. In this section, we will discuss ReLU activation functions and focus on:

1. 1. Introducing the ReLU activation function.
2. Demonstrating that Neural Networks with ReLU activation functions have the same outstanding approximation properties as a Neural Networks with Sigmoid activation functions.
3. Discussing the problem of the Vanishing Gradient in context of classic Sigmoid vs. ReLU activation functions. A Vanishing Gradient can lead to a situation where the Optimizer cannot change the parameters anymore, although they are still far from optimal.

Let us start with a ReLU activation function determines the activity of a hidden neuron:

$Act_{j,s} = max(0, f_{j,s}) \quad (9.10)$

with $j :=$ hidden number and $i :=$ observation number

Equation (9.10) shows that the algebraic form of a $ReLU$ activation function is limited if the *effective input* is greater than 0, the $ReLU$ function returns the *effective input* as $Act_{j,s} = f_{j,s}^+$. If the effective input is smaller than 0, the $ReLU$ function returns 0 ($Act_{j,s} = 0$). You can also see this in Figure 9.7 below. For all positive *effective inputs*, we get the *Linear-Parent-Function* graph ($y=x$-graph). For all negative values we get a straight line with $y=0$.

Figure 9.7 shows, that the graph of the ReLU activation function is limited to depicting only half of a step. In contrast, the graph of a *Sigmoid activation function depicts a full step. Therefore the question arises if *Neural Networks* with $ReLU$ activation functions have the same outstanding approximation properties as *Neural Networks with Sigmoid* activation functions$^{13}$

![](img/f240d449191f5add983daf6c380e4fe3_268_0.png)

**FIGURE 9.7** The ReLU Activation Function

The answer is that $ReLU$ activation functions have the same outstanding approximation properties. This is because we can combine two $ReLU$ functions into a complete step, and then they have the same approximation properties as classical *Sigmoid* (full-step) functions.

> $^{13}$See Section 9.5 for the approximation properties of *Neural Networks with Sigmoid* activation functions.

## 9.6 NNet with PyTorch (brulee)

We can show this with an example using a Neural Network with one predictor (x), one hidden layer, and multiple hidden neurons.

Let us look at the first hidden neuron. Before its activity is transmitted to the output neuron it is weighted with $\beta_3$. Therefore we consider ($\beta_3 Act_{t,i}$) rather than its activity ($Act_{t,i}$):

$$\beta_3 Act_{t,i} = \beta_3 max (0, \Gamma_{t,i}) \qquad (9.11)$$

Since we have only one predictor variable $x$, substituting the effective input $\Gamma_{t,i}=\beta_1+\beta_2x$ into Equation (9.11) leads to:

$$\beta_3 Act_t = \beta_3 (0, \beta_1 + \beta_2 x) \qquad (9.12)$$

with:
$\beta_3$: parameter for hidden neuron B1
$\beta_2$: parameter for the only predictor variable $x$

Equation (9.12) can be plotted and for $\beta_1=0$, $\beta_2=1$, and $\beta_3=1$, the plot shows the ReLU from Figure 9.7.

By changing $\beta_1$, $\beta_2$, and $\beta_3$, the graph of the augmented ReLU function in Figure 9.7 can be transformed:

- horizontally shifted (changing $\beta_1$)
- the slope can be changed (changing $\beta_3$)
- the graph can be turned upside down (changing $\beta_3$ to a negative value)
- the graph can be mirrored horizontally (changing the sign of $\beta_2$)

Using the transformations above on two different ReLU functions (two hidden neurons) they can jointly form a step function similar to a Sigmoid function, except that the step on the two ReLU function has two kinks and the slope between the two kinks is constant.

In Section 9.9, we provide a link to an internet app and a blog post where you can transform and combine ReLU functions to form a complete step function.

**Summary:** If we can combine two hidden neurons with ReLU activation functions into a step function, we can expect the approximation properties from a Neural Network with ReLU activation functions that are defined in Section 9.5 for Neural Networks with Sigmoid functions.

The constant slope of a ReLU activation function is a major advantage over a Sigmoid function. Let us compare the slope of the Logistic activation function in Figure 9.3 with the slope of the ReLU activation function in Figure 9.7. The ReLU activation function has a constant slope of one for all positive effective inputs. In contrast, the slope of the Logistic activation function is always smaller than one, and it becomes very small when the effective input gets greater in absolute terms (when approaching the red and blue lines in Figure 9.3).

While the small slope of Logistic activation functions is not a problem for Neural Networks with one layer, it is a problem for Neural Networks with many layers.

When the Optimizer adjusts individual $\beta$ values in a multi-layer Neural Network and calculates by how much each change from iteration to iteration, the weighted slopes of the activation functions in different layers are multiplied.$^{14}$ If these weighted slopes are smaller than one, each multiplication brings the change of the related $\beta$ smaller. With enough layers, the calculated change get close to zero. Consequently, the $\beta$ parameters will not change anymore, and the optimization process gets stuck. This problem is called the Vanishing Gradient.$^{15}$

Since ReLU activation functions have a constant slope of one for positive effective inputs, the Vanishing Gradient is mostly mitigated using ReLU activation functions.
