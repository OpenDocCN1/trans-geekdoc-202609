## Fitted Model vs. Unfitted Model

An unfitted model is a prediction equation like Equation (5.4) in Section 5.4.1 or a model that has not been fitted to the training data (i.e., if we omit fit(xatrain) in the workflow code). An unfitted model contains the rule of how predictions are built. Still, because the numerical values for the parameters ($\beta$) are not determined — an unfitted model cannot be used to predict.

When we determine the optimal values for the parameters ($\beta$) by minimizing the MSE, we calibrate ($\hat{M}$) to the training data. The model becomes a fitted model.

A fitted model can be used directly for predictions because the numerical values for its parameters ($\beta$) have been determined.

## 5.4.3 Trial-and-error to find Optimal Parameters

The following sections will use trial-and-error approaches to find the optimal $\beta$s. Since we calculated $\beta_{1,opt}$, and $\beta_{2,opt}$, already in the previous section, we can use the results as a benchmark to see how well the trial-and-error approaches are performing.

## 5 Linear Regression — Key Machine Learning Concepts

```
$$MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$
$$\longleftarrow \text{Prediction } i$$
$$MSE = \frac{1}{N} \sum_{i=1}^{N} (\beta_1 x_i + \beta_2 - y_i)^2 \quad (5.9)$$
```

Equation (5.9) provides the formula to calculate the *MSE*. For a training dataset (all $y$ and $x_i$ are known), we can choose any pair $\beta_1$ and $\beta_2$, and use Equation (5.9) to calculate the related *mean squared error* (see Section 5.4 for details). However rather than arbitrarily choosing values for $\beta_1$ and $\beta_2$, we will use more systematic approaches.

In Section 5.4.3.1, we use Grid Search: First, we generate two vectors $\beta_1$ and $\beta_2$ containing various values, respectively. Then we will use R to generate all possible combinations for $\beta_1$ and $\beta_2$ values. For each of the results of $\beta_1$ and $\beta_2$, we will calculate the $MSE$ and finally choose the pair with the lowest $MSE$.

In Section 5.4.3.2, we will use an Optimizer to find optimal values for $\beta_1$ and $\beta_2$. An *Optimizer* is an iterative algorithm that can minimize or maximize a target function. In our case the $MSE$ function (5.9) is the target function.

### 5.4.3.1 Finding Optimal Parameters Using Grid Search

This section uses the *Grid Search* algorithm to find the pair of $\beta_{1,opt}$ and $\beta_{2,opt}$ that minimizes the $MSE$. Let us begin by deciding a range for $\beta_1$ and $\beta_2$ and how many values we would like to test. At the beginning of this section, we used $\beta_1 = 4$ and $\beta_2 = 6$, and the predictions were not bad. So, why not use a range around $3-5$ for $\beta_1$ and a range of $50-70$ for $\beta_2$? For each $\beta_1$ and $\beta_2$, we will generate about 21 values in the chosen range. In the code below, we generate a sequence of values for $\beta_1$ ranging from 3 to 5 with an increment of 0.1. For $\beta_2$, we choose values ranging from 50 to 70 with an increment of 1. These values are assigned to the $R$ vector objects `vecBeta1Values` and `vecBeta2Values`, respectively.

```r
vecBeta1Values=seq(3, 5, 0.1)
vecBeta2Values=seq(50, 70, 1)
```

For each pair of $\beta_1$ and $\beta_2$ (each row in GridBetaPairs), we must calculate the MSE for the pair with the smallest MSE. This method is comprehensive but not computationally efficient; Grid Search is sometimes called a Brute Force approach.

Calculating the MSE for $\beta_1$ and $\beta_2$ is accomplished in the following code block with the apply() command. It applies a function (in this case, MSE()) to each of the rows of the data frame GridBetaPairs using the $\beta_1$ and $\beta_2$ pairs in each row together with the data frame DataMockup to calculate the related MSEs.³ These MSE values are then stored in the R vector object VcMSE and appended to the data frame GridBetaPairs as a new column using mutate().

```r
FctMSE=import("https://ai.lang-analytics.com/FctMSE.rds")
VcMSE=apply(GridBetaPairs, FUN=FctMSE, data=DataMockup, MARGIN=1)
```

```r
GridBetaPairs=mutate(GridBetaPairs, MSE=VcMSE)
```
