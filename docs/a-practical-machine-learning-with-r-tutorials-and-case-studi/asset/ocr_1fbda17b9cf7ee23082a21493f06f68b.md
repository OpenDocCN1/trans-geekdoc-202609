We will not use the apply() command in the following chapters. Therefore, it is sufficient to understand that apply() calculates the MSE for each of the rows of GridBetaPairs.

The last step is to find the β-pair with the smallest MSE. This is a little tricky: We first find the smallest MSE (using min(MSE)) and then use this smallest MSE to filter the data frame (MSE=min(MSE)). The result is the row with smallest MSE, which we save as BestModel and print forward.

```
BestModel=filter(GridBetaPairs, MSE=min(MSE))

print(BestModel[1])
```

```
## Betal Beta2 MSE
## 1 4 64 20.8
```

As you can see in the printout, we get β1 = 4 and β2 = 64 with an MSE = 20.8. This deviates slightly from the calculated values from Section 5.4.2 where we obtained opt.1=3.96 and opt.2=64.18. This deviation should not come as a surprise. For the β1 range, we used an increment of 0.1, and for the β2 range, an increment of 1, leaving us with a coarse grid that already had 441 rows for which the MSEs needed to be calculated.
