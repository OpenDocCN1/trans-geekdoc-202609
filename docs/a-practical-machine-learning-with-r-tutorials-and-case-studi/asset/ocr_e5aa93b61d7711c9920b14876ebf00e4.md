# 4.5.2 k-Nearest Neighbors for k>1

So far, we have considered only $k=1$, but this can be problematic in some cases. Take a look at Figure 4.6: We used a different wine to predict (blue point) that has a slightly higher acid content (*Acid = 7.3 instead of 6.8*). Therefore, compared to Figure 4.5 the blue point is now located higher and nearer to a point (observation) representing a wine (see $N_1$ in Figure 4.6). Consequently, the prediction of *k-Nearest Neighbors* ($k=1$) would be *white*. However, in Figure 4.6, red wine observations surround the wine that we try to predict, and the closest white wine seems to be an exception.

Intuitively, we would predict the unknown wine as being *red*.
