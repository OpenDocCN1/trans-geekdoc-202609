For example, the sixth row in the table in Figure 11.6 represents the blue path through the flow chart. The marginal contribution of *Educ = 17* is 3.46. The predictor value for *Educ* was added at the end of the blue path leading to *Coalition: ETF*. The contribution without *Educ = 17 (Coalition: TF)*, contained only the predictor *Educ* and others.

*Coalition: TF* without Education leads to a predicted wage of 5.78. The *Coalition: TF* that includes Education leads to a predicted wage of 9.24. Therefore, including *Educ = 17* in the wage prediction increased the predicted wage for the blue path (9.24–5.78) — which is the marginal contribution of *Educ = 17*

The marginal contribution of *Tenure* for the scenario in the sixth row in the table can be calculated in a similar way. *Tenure* was added second along the blue path, and the difference between the wage prediction from *Coalition: TF* (containing *Tenure = 18*) and *Coalition: F* (without *Tenure*) is 1.14 (5.78–4.64).

The third value in the row of the table represents the marginal contribution of *Female = 1*. The predictor value *Female = 1* was considered first for the step-wise wage prediction along the blue path. The marginal contribution of *Female = 1* is the difference between *Coalition: F* and *Coalition: none* (4.64–5.94 = -1.3).

Marginal contributions for other paths through the flow chart in Figure 11.6 can be calculated in a similar way. You find them in the table to the right of the flow chart.

To summarize, the marginal contribution of *Educ = 17*, *Tenure = 18*, and *Female = 1* for the scenario, the step-wise prediction was performed in the order *F*, *TF*, and *ETF*,:

```
$3.46 + 1.14 + (-1.30) = 3.3$
MargContE + MargContT + MargContF + MargContAll
```

You can see that the marginal contributions add up to 3.3, which is the same for all orderings (all rows). This represents the cumulative contribution from all three predictor variables to the predicted wage. We can show this by calculating the difference between *Coalition: ETF*, where all predictor variables are considered, and *Coalition: none*, where no predictor variable is considered:
