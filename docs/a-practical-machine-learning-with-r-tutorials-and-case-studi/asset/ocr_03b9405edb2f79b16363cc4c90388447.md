To calculate metrics for the testing data, we use the metric_set() command and require accuracy, sensitivity, and specificity. The resulting R command is used in the R objects MetricsSetMinist.

Then, in the second line of code, we execute the MetricsSetMinist() command with the same arguments that we used to create the fusion metrics.

```
MetricsSetMinist=metric_set(accuracy, sensitivity, specificity)
MetricsSetMinist(DataTestWithPred, truth=Label, estimate=$.pred_class)
```
