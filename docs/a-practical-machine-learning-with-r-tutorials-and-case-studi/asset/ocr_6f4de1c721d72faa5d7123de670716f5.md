Now that you have two different data frames that either contain male or
female passengers' observations, you are ready to calculate the related survival
rates.

In the code block below, you will calculate the female survival rate.
Later, for the male survival rate, we will show you a shorter alternative.

The female survival rate (Fem_{SurRate}) is defined as:

> Fem_{SurRate} = \frac{Fem_{Sur}}{Fem_{Total}}

Therefore, to calculate the female survival rate (Fem_{Sur}) and the total number of
female passengers Fem_{Total}. The latter is the number of observations in the
the data frame DataWomen and can be calculated with nrow(DataWomen).

To find the number of surviving women (Fem_{Sur}), we can use the fact that
a surviving passenger was coded with TRUE with an internal value of 1 and
not-surviving passenger with FALSE with an internal value of 0. Therefore,
when we extract the variable Survived as a vector object from the data frame
DataWomen (sum(DataWomen$Survived)), we calculate the sum from this vector, we get the number of female
survivors.
