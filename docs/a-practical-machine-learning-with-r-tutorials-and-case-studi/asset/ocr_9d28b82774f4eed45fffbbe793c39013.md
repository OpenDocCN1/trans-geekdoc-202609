The command to create permutation-based Variable Importance is the same as the one for impurity-based Variable Importance (see Section 11.6.1), except it requires us to set the metric for the error via the metric= argument:

```
library(vip)
vip(extract_fit_engine(WModelWageRF), metric="rmse")
```

Options for the error metric include metric="rmse" (root mean squared error), metric="mae" (mean absolute error), and metric="rsq" (r²). It is recommended to use the metric that was used for the underlying machine learning model.
