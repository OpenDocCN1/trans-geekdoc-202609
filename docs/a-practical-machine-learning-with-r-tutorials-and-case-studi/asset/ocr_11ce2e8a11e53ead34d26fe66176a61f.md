# FIGURE 7.2 Parameter Estimates for Different Ridge Penalty Estimates

Figure 7.2 shows the $\beta$ estimates of the related predictor variables for penalty multipliers ranging from $\lambda = 19$ to $\lambda = 190, 385, 312^4$.

In the Lasso model, when $\lambda$ increases, the calibrated $\beta$ values have a tendency to move toward zero. In contrast to the Lasso model (see Figure 7.1), individual predictor variables are not eliminated ($eta$ values are not set to zero). Yet, you can see in Figure 7.2 that the paths for the $\beta$ values converge to a common value. Afterward, when further increasing $\lambda$, this common value decreases further, until all $\beta$ values reach zero—none of the $\beta$s reach zero individually in the Lasso case. Consequently, of many of the predictor variables are eliminated individually.

This phenomenon can be explained by the Ridge penalty term. When $\lambda$ is large, the penalty term has a high weight compared to the MSE. Consequently, the Optimizer focuses mainly on the penalty term. Since larger (in absolute) $\beta$ values impact the penalty-over-proportionally, the Optimizer has an incentive to favor smaller values first. This leads to a situation where $\beta$ values converge to similar values (Figure 7) at large $\lambda$ values.

> $^4$The *lasso_reg()* command from the glm package does not only calibrate the $\beta$ parameters based on the $\lambda$ chosen (penalty=100000), it also calibrates 100 other $\lambda$ values. The results for Figure 7.2 were extracted with the command *extract_fit_engine(WMFasso)*. We do not use these results for tuning because we use the more advanced tidymodels approach later in Section 7.5.
