# 11 Interpreting Machine Learning Results

Given that the three economists have slightly different talents (Angela specializes in financial economics, Bruce specializes in health economics, and Carsten specializes in machine learning), we cannot equally divide the profit of 107 among the three economists. We have to find out the individual contribution of each economist. The marginal contribution is calculated as the difference between a coalition and a coalition where the same individual did not contribute. There is a problem: the contribution varies for each economist depending on which stage they joined the project.

![](img/f240d449191f5add983daf6c380e4fe3_332_0.png)

FIGURE 11.5 The Shapley Graph

For example, we follow the red path in the flow chart as Figure 11.5, we can see that Angela joins first, then Bruce; and Carsten. When Angela joins, the profit increases from Coalition: none by 66 to Coalition: A, where Angela is the only contributor (from 7,000 to 7,066). When Bruce joins, the profit increases by 19, and finally, with Carsten joins, the profit increases by 22. Therefore, Angela's marginal contribution is 66, Bruce's is 19, and Carsten's is 22. Should Angela get 66 of the total contribution of 107? This is more than half and does not sound reasonable.

Why this not reasonable becomes more clear when we look at the blue path in the flow chart Figure 11.5. Following that path, we see that Angela joins last and contributes only 26.

The different results make sense: In the initial coalition, the company did not have an economist, so when Angela joins, she contributes all of the economics expertise. However, following the blue path, Angela joins last. Before she joined, the company had already hired two economists, contributing their economics knowledge and their specialties. When Angela joins, the profit goes up because she adds financial economics expertise, but economics, in general, was well covered by Bruce and Carsten.

The order in which coalition members join could not influence their overall contribution. Therefore, we could look at every possible scenario where Angela can join, calculate her marginal contribution for each scenario, and then calculate the average as an estimate of Angela's overall contribution.

This is exactly the idea behind SHAP values, and you can see how it works in the table displayed in Figure 11.5. Since we have three economists, there are precisely six (3! = 1 · 2 · 3) scenarios for the order in which they can join the project, and these six scenarios are displayed in the rows of the table. When Angela joins first (Scenarios ABC and ACB), her contribution is 66. When she joins second (Scenarios BAC and CAB), her contribution is 21 and 20. When she joins last (Scenarios BCA and CBA) her contribution is 26. The average for all scenarios is 37, which is Angela's estimated overall contribution — SHAP value.

We can follow a similar procedure for Bruce and Carsten, and we get SHAPLEY values of 36 and 34, respectively. They are displayed in the last row of the table in Figure 11.5 and add up to the overall contribution of the three economists of 107.

SHAPLEY values always ensure that their sum adds up to the total contribution (107 in our case).

## 11.7 SHAP Contribution of Predictor Variables

Now that you understand how SHAP values are calculated, it is a small step to understand SHAP values.

The underlying idea of the SHAP values approach is to apply the SHAPLEY logic to the SHAP approach.¹¹⁰. This is reflected in the definition of SHAP values:

**SHAP values quantify the contributions of all predictor variables' values to the prediction for a specific observation.**

Since the SHAP values approach is based on an individual observation, the SHAP algorithm is considered **local**.

Since SHAP can be applied to any machine learning model that can generate predictions, the algorithm is considered **model-agnostic**.

> ¹⁰ O'Sullivan (2022a) compares the SHAPLEY and the SHAP approaches provides mathematical foundation for both approaches. He also discusses how SHAP values can be computationally approximated.

## 11.7.2 From SHAPLEY to SHAP Values

To explain the transition from the SHAPLEY to the SHAP approach, let us work with the same wage prediction example as the previous sections. Again, our goal is to explain the wage prediction of the Random Forest model from Section 11.4. In detail, we want to estimate the contributions of the predictor variable Educ := 17, Tenure := 18, and Female := 1 to the predicted value (.pred) for the observation Helga:

```
print(ObsHelga)

## 1 8.9 17 18 9.24
```

When we discussed SHAPLEY in Section 11.7.1, we considered six scenarios where three employees joined in a different order. Similarly here, the values for the predictor variables (E := Educ := 17, T := Tenure := 18, and F := Female := 1) are step-wise, in different order to predict Helga's wage (see Figure 11.6).

Because three predictor variables can be ordered in different ways, there are six paths through the flow chart in Figure 11.6. Each path represents a possible ordering of the predictor variables. The marginal contribution of each variable along a path is the change in the predicted wage when that variable is added. The table to the right of the flow chart shows these marginal contributions:

| Scenario | Educ | Tenure | Female | .pred |
| :--- | :--- | :--- | :--- | :--- |
| ABC | 66 | 19 | 22 | 9.24 |
| ACB | 66 | 22 | 19 | 9.24 |
| BAC | 21 | 66 | 20 | 9.24 |
| CAB | 20 | 66 | 21 | 9.24 |
| BCA | 26 | 21 | 20 | 9.24 |
| CBA | 26 | 20 | 21 | 9.24 |

## 11.7.3 Deriving SHAP Values for Observation Helga

The entries in the table show the marginal contributions of the predictor variables for each scenario. For example, the blue path shows the difference of 1.14 between *Coalition: TF* and *Coalition: F*. The marginal contribution of *Educ = 17* along the blue path is 3.46, which is the difference between *Coalition: ETF* and *Coalition: TF* (9.24–5.78).

To find the SHAP value for each variable, we calculate the average marginal contribution across all scenarios:

- For Educ: (66 + 66 + 21 + 20 + 26 + 26) / 6 = 37
- For Tenure: (19 + 22 + 66 + 66 + 21 + 20) / 6 = 36
- For Female: (22 + 19 + 20 + 21 + 26 + 26) / 6 = 34

The sum of these SHAP values is 37 + 36 + 34 = 107, which is the total difference between the predicted wage (9.24) and the base prediction (5.94).
