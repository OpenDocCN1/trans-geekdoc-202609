# 4.7.2 Loading and Splitting the Data

In the code block below, we start with loading the needed R packages, rio, and tidymodels.

Note that tidymodels is a meta-package comprising various packages, including most packages, Therefore, it is usually not necessary to load the tidymverse package separately.

After loading the packages, we use the same wine dataset as in Section 4.5 and select only the predictors TotalSulfurDioxide (renamed to Sulfur) and Acidity to predict the outcome WineColor (see import()) and select()).

Many learning models that perform classification (including k-Nearest Neighbors) require the outcome to be an R factor variable (see Section 3.5.1 for details about R factor variables). In the dataset, WineColor is a character variable. Therefore, we have to mutate to transform WineColor to a factor variable using the factor():

```
library(rio); library(janitor); library(tidymodels)
DataWine<-import("https://ai-analytics.com/data/WineData.rds") |
 clean_names("upper_camel") |
 select(WineColor,TotalSulfurDioxide, Acidity) |
 mutate(WineColoras_factor, factor(WineColor))
```
