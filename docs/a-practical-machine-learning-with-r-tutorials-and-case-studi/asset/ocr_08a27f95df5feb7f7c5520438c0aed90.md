Following the flow chart in Figure 3.4, it is not difficult to generate the R code for our task:

```
library(tidyverse);library(rio)
DataTantic=import("https://ai.lang-analytics.com/data/Titanic.csv")

DataFinalResult=select(Survived, Sex, Age, FareInPounds) |
  filter(Sex=="female") |
  mutate(FareIn2023Dollars=108.5*FareInPounds,
  FareInPounds=NULL)
```

Instead of writing the pipe in one line, we added a line break after each |> and indented that the select(), filter(), and mutate() commands are lined up. This is not required but makes the code very easy to read. Note, R does not allow the piping operator at the beginning of a line!

The readability of the code is the reason that we use piping whenever possible for the remainder of the book. The code block below shows how much more difficult it is to read without piping. Note that we do not override data frames in the code below this can cause errors when extending a code line or reusing a data frame.

```
library(tidyverse);library(rio)
DataTantic=import("https://ai.lang-analytics.com/data/Titanic.csv")
```
