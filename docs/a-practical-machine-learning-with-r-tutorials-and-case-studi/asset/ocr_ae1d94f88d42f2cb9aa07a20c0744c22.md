# 11.7 SHAP Contribution of Predictor Variables

In the R code, we use the command explain_tidymodels from the DALExtra package, which allows us to create the explainer object directly from the tidymodels workflow wfModelVax. The command explain_tidymodels() requires the training data assigned to the argument data= excluding the prediction variables. This is why we first select() to create a data frame containing only the explainer object. The outcome variable PercVacFull (a county's rate of fully vaccinated adults) is provided through the y argument, and verbose=FALSE suppresses message.

Now, everything is ready to calculate the SHAP values for one of the observations with the predict_parts() command. In the interactive part of this section below, you can create and interpret SHAP values for almost any US county, but for now we keep it and choose Los Angeles County, CA.

In the DataV frame, Los Angeles has a CountyID=133, which means that the Los Angeles observation is in the 133rd row of the dataset.

The plot in Figure 11.7, the bars indicate the SHAP values for the respective predictor variables, with the label at the vertical axis indicating the value of the respective predictor variable in Los Angeles County. The bar plots overlapping each bar indicate the distribution of the SHAP values for the 25 randomly scenarios (ordering of predictor variables). You find the R code that generates Figure 11.7 below:

```
set.seed(2021)
CountyID=133
SHAPobject<-predict_parts(
explainer=ExplainerRandForest,
new_observation=DataVax[CountyID],
type="shap", B=25)
```

```
plot(SHAPobject)
```

We use the argument new_observations=DataVax[CountyID]) to create SHAP values for the observation Los Angeles. Also, the explainer object that we created is assigned to the argument explainer= and the argument B=25
