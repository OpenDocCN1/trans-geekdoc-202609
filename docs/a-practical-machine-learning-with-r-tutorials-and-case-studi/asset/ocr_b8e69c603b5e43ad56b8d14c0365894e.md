# 9.5 Build a Simplified Neural Network Model

Changing the $eta$ values that impact the *effective input* $z_{ij}$ of a specific *Sigmoid* activation function and changing the $eta$ value that weighs the resulting activity $(eta A_{ij}^k)$, can move a (*Sigmoid function*) horizontally, increase or decrease the step size, change the steepness, and also convert from up to a downward step.

Since a *Neural Network* consists of hidden neurons, many *Sigmoid* (steps) functions can be combined into a staircase-like structure with smaller and bigger steps as upwards and downward steps — depending on the $eta$ parameter values. This staircase-like structure — if it has enough steps — can approximate a function in any given range to any degree.

The mathematical formula behind which staircase-like structure is the *Neural Network* prediction function. It combines the *Sigmoid* (steps) to approximate whatever continuous function needs to be approximated (in a given range) with various up- and downward steps.

Consequently, with this procedure, a *Neural Network* can approximate a function to any degree of smoothness in a given range by increasing the number of hidden neurons.

Figure 9.6 shows an example of the arguments outlined above. The goal is to approximate a sine function (the orange dots in the upper diagram in Figure 9.6) in an input range between 0 and 9 with a *Neural Network*. The sine function to be approximated is:

```
$y_i = \sin(x_i + 5) + 1$
```

We use a *Neural Network* with one input $(x_i)$, three hidden neurons with *Logistic* activation functions, and one output $	ilde{y}_i$.

When all $eta$ values are appropriately chosen$^{11}$ the three $eta$ weighted activation functions of the three hidden neurons form three steps (the lower two diagrams in Figure 9.6). When these steps are combined (added) together with the bias for the output neurons $(eta_0 = 2)$ they form the *Neural Network* prediction function (the blue line in the upper diagram of Figure 9.6). As you can see, we get a good approximation of the sine function. The *Neural Network* prediction function forms a staircase-like structure with one step up, one step down, and line in the upper diagrams of Figure 9.6). If we want to increase the smoothness of the approximation, we could work with six hidden neurons (six steps). With appropriate values for the $eta$ parameters, we could form a staircase-like structure with two (smaller) steps up, two (smaller) steps down, and two (smaller) steps up.

> $^{11}$The underlying $eta$ values are not the result of an *Optimizer* process. They have been chosen manually by *trial-and-error* to generate a good approximation.
