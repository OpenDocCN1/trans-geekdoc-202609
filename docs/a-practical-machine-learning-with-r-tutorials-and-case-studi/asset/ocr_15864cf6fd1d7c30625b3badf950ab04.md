# 5.3 The Basic Idea Behind Linear Regression

The basic idea linear regression is to use a linear function with one (uni-
atevari) or more (multivariate) predictor variables $x_i$ to predict a continuous
outcome variable $y$.

Equations (5.1) and (5.2) are examples of predicting the outcome $y_i$ with
two predictor variables, respectively. Because regression Equations (5.1)
and (5.2) generate predictions for the true outcome variable $y_i$, the variables
one on the left of the equations are marked with a hat (see $\hat{y}_i$) to indicate that the
left-hand-sides of Equations (5.1) and (5.2) are the results of:

```
$y_i = \beta_1 x_i + \beta_2$
$\hat{y}_i = \beta_1 x_i + \beta_2 x_i + \beta_3$
```

We know the numerical values for the predictor variables $x_{i,j}$ for any given
observation in the training and testing dataset. Consequently, we can plug in
the numerical values for the predictors $x_{i,j}$ into Equations (5.1) or (5.2)
calculate a prediction for the outcome ($\hat{y}_i$).

However, this only works if and only if we know the values for the parameters
(the $eta$s). Finding optimal values for the parameters result in
the best prediction quality is the central objective for linear regression. It is
similar important for most machine learning algorithms.

> ¹Strictly speaking, the $eta$s are also estimates and should be written as $\hat{eta}_j$. For simplicity,
what follows, we omit the hats on model-parameters.
