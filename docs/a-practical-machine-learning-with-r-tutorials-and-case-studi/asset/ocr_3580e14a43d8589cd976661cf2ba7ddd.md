# 8 Logistic Regression — Handling Imbalanced Data

How we the code block below. We use step_downsample(Churn, over_ratio=2) and step_smote(Churn, over_ratio=0.75):

```
set.seed(789)
RecipeChurn=recipe(Churn-, data=DataTrain) |>
    step_dummy(Gender) |>
    step_downsample(Churn, over_ratio=2) |>
    step_smote(Churn, over_ratio=0.75)
```

```
DataTrainBal=RecipeChurn |>
    prep() |>
    juice() |>
count(Churn, Churn)
```

How did we get the frame DataTrainBal? First, step_downsample(Churn, over_ratio=2) randomly deletes observations from the majority class of the training data frame (DataTrain), until the number of observations in the majority class is reduced to double the size of the minority class (1,308 observations for Churn = Yes and 2,616 observations for Churn = No); initially, step_smote(Churn, over_ratio=0.75) creates new observations for the minority class unit until the number of observations in the minority class reaches 75% (1,962 observations for Churn = Yes and 2,616 observations for Churn = No).

Using this somehow balanced dataset, we got (based on the testing data), the following confusion matrix:

## Truth Yes No

The confusion matrix above implies a specificity of 78% but still only a sensitivity of 62%. This is an improvement compared to the analysis with the imbalanced dataset, but maybe you can improve the results further.
