Now that we know that Neural Networks with enough neurons can approximate any dataset to a very high degree, the crucial question is, how well our fitted Neural Network can predict the testing data — the Neural Network has never seen before.

In the code block below, we use the augment() and the metrics() commands as when evaluating training data performance, except that we evaluate the testing data (DataTest):

```
DataTestWithPredNN=augment(ModelNN, new_data=DataTest)
metrics(DataTestWithPredNN,truth=Price,estimate=.pred)
```

The prediction result is not good. For instance, for the testing data, the mae, our model on average/underestimates a diamond's price, is $1,273. This is a typical case of overfitting; the training data approximation is (mae = 110.94), the prediction quality based on the testing data is poor.

Neural Networks with a large number of parameters are prone to overfitting, especially when the training dataset is relatively small.
