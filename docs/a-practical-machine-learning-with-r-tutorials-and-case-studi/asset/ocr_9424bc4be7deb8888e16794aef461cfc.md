Next, we reset the value for $eta_1$ and use the same procedure for $eta_2$ to find out if $eta_2$ should be increased or decreased.

We do the same for all $eta$ parameters, and consequently, we will know for each $eta$ parameter if it should be increased or decreased.

The amount of increase or decrease for each of the $eta$ parameters is proportional to the change of the $MSE$ they triggered when changed. In addition, to ensure that the changes are not too large, we multiply these changes with a learning rate — a constant smaller than one, for example, $0.001^8$.

This procedure results in a new set of $eta$ with a slightly smaller $MSE$. This new set of $eta$ becomes the benchmark and the procedure above is repeated.

After each iteration (also epoch), the $MSE$ slightly improves. We continue until the $MSE$ is lowered to the desired level or until a preset number of epochs is reached.
