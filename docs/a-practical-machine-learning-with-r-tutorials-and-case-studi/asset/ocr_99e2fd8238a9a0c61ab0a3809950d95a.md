# 10.4 Random Forest

the set_engine() command. The Random Forest implementation in tidy-models allows us to execute R code parallel on multiple computer cores to speed up computation time. Random Forest is well suited for parallel computing because the various Decision Trees can be developed independently from each other in order and afterward combined into a Random Forest. We set the argument num.threads (the number of processes that run in parallel) to be the number of computer cores of the executing computer (num.threads=detectCores()). This worked well on a computer with 16 logical cores.

In the code block below, we create the workflow and add the recipe, model design, and we add the variable add_weights(Population) to weigh the observations with their respective population.

```
set.seed(2021)
WModelVax <- workflow() |>
  add_recipe(RecipeVax) |>
  add_model(ModelDesignRand) |>
  add_weights(Population) |>
  fit(DataTrain)
```

Weighting counties by their population is needed because the U.S. counties have very different population sizes. Using unweighted observations would imply assigning the same weight to counties with a few hundred residents as counties with millions of residents, which would not be reasonable.
