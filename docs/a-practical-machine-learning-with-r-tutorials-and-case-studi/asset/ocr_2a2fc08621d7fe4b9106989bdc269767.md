At this point, you can already see that smaller prediction errors (i.e., absolute smaller values for $\hat{y}_i - y_i$) lead to a smaller $MSE$. Therefore, our error function is well suited as a metric to measure a model's predictive quality and can be used to find optimal $eta$ parameters for the model later on.

Equation (5.5) allows us to calculate the $MSE$ for any set of parameters $(eta_1, eta_2)$ because based on the training data, all values for the predictor variable $(x_i)$ and the output variable $(y_i)$ are known — only $eta_1$ and $eta_2$ to be determined.

This can be shown for the mockup dataset, if we resolve the summation sign ($\sum$) in Equation (5.5) and also substitute $y_i$ and $x_i$ with the training data observations from Table 5.1 (remember, $i$ is the index for the observation), we get (5.6):

```
$MSE = \frac{(\beta_1x_1 - y_1)^2 + (\beta_1x_2 - y_2)^2 + \dots + (\beta_1x_5 - y_5)^2}{5}$
$MSE = \frac{1}{5} \left[ \begin{array}{c|c} Prediction 1 & Prediction 2 \ (\beta_1 \cdot 7 + \beta_2 - 65)^2 + (\beta_1 \cdot 3 + \beta_2 - 82)^2 \ Error 1 & Error 2 \ Prediction 3 & Prediction 4 \ (\beta_1 \cdot 7 + \beta_2 - 93)^2 + (\beta_1 \cdot 8 + \beta_2 - 93)^2 \ Error 3 & Error 4 \ Prediction 5 & Error 6 \ (\beta_1 \cdot 4 + \beta_2 - 83)^2 \ \end{array} \right] (5.6)$
```

Equation (5.6) shows that **when the training data are given, the MSE is only based on the choice of the parameters** — $eta_s$.

Consequently, if you substitute the arbitrary chosen values, $eta_1 = 4$ and $eta_2 = 61$, into Equation (5.6), you can take a calculator and find that $MSE = 29.8$. This is quite cumbersome, but it might be a good exercise to fully understand the importance of Equation (5.6).

Although calculating the $MSE$ is cumbersome for a human, writing a function in $R$ to calculate the $MSE$ based on a set of $eta$-values and a training dataset is relatively easy.
