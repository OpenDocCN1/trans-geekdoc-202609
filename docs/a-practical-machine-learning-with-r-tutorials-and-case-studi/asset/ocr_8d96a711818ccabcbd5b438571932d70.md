# 7. The Idea Behind Regularization

# 7.4.3 Elastic-Net — Combining Lasso and Ridge

In the previous two sections, we introduced Lasso and Ridge. Lasso tends to reduce $eta$ parameter values to zero. Consequently, it eliminates predictors from the model and makes overfitting less likely. It is the model of choice if you want to reduce the number of predictors to those with the strongest explanatory power. In contrast, Ridge lowers the $eta$ parameter variables to avoid overfitting without eliminating variables. If you like to keep all predictor variables in the model, Ridge is the model of choice to avoid overfitting.

Often, we are ambivalent about keeping all predictor variables or not. The goal is to maximize predictive performance and minimize overfitting. Therefore, it is often difficult to determine which algorithm is superior. So why not combine Lasso and Ridge?

This is exactly how the Elastic-Net approach does. It uses both — the penalty for Lasso and the one for Ridge — adds their weighted average to the MSE in the target function:

```
$T_{Elastic}^{2} = \frac{1}{MSE} \sum_{i=1}^{20} (Price_{i} - Price_{i})^{2} + \lambda (\alpha \frac{penalty_{Lasso}}{MSE} + (1-\alpha) \frac{penalty_{Ridge}}{MSE})$  (7.8)
```

```
$T_{Elastic}^{2} = \frac{1}{MSE} \sum_{i=1}^{20} (Price_{i} - Price_{i})^{2} + \lambda (\alpha \sum_{j=1}^{5} |\beta_{j}| \frac{penalty_{Lasso}}{MSE} + (1-\alpha) \sum_{j=1}^{5} \beta_{j}^{2} \frac{penalty_{Ridge}}{MSE})$  (7.9)
```

with: $Price_{i} = \beta_{1}Sqft_{i} + \beta_{2}Sqft_{i} + \beta_{3}Sqft_{i} + \beta_{4}Sqft_{i} + \beta_{5}Sqft_{i} + \beta_{6}$

In Equation (7.5) you can see that the penalty for $penalty_{Lasso}$ and $penalty_{Ridge}$ is calculated as a weighted average. The hyper-parameter $\alpha$ ($0 \le \alpha \le 1$) determines the share of the Lasso penalty. For example, if $\alpha=0.5$ the share of the Lasso penalty is 50% and the share of the Ridge penalty $(1-\alpha)=0.5$ is also 50%. If $\alpha=0.3$ the share of the Lasso penalty is 30%, and the share of the Ridge penalty $(1-\alpha)=0.7$ is 70%.

The hyper-parameter $\alpha$ corresponds to the argument mixture in the linear\_reg() function. Worked with it already in Section 7.4.1 when you set mixture=1 assigning a share of 100% to the Lasso penalty and a share of 0% $((1-\alpha)=0)$ to the Ridge penalty — basically running a pure Lasso model.

In Section 7.4.2 you can run a pure Ridge by setting mixture=$\phi$ ($\alpha=0$) and thus implying the share of the Ridge penalty is 100% $((1-\alpha)=1)$.
