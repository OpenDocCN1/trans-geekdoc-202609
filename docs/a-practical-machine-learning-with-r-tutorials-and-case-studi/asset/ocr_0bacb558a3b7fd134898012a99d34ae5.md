# 11.5 Visualizing the Impact of Changing Predictor Variables

In this section, we will use Ceteris Paribus Plots and Partial Dependence Plots to visualize how a change in a single predictor variable impacts the predictions for the outcome variable.

We analyze changes of the variable Tenure, but the methodology is also valid for changes of other predictor variables.

# 11.5.1 Ceteris Paribus Plots

Ceteris Paribus Plot visualizes how the values for a predictor variable impacts the prediction for a single observation of interest (local interpretation). The observation of interest here is for Helga:

```
## A trible: 1 x 5
## Wage Edu Tenure Female .pred
## <dbl> DALEX: <dbl <ft> <dbl
## 1 8.9 17 18 1 9.24
```

In the previous section, we predicted a wage of $89.24 for Helga. But would Helga's predicted wage change if her Tenure was greater or smaller and all other predictor values would remain the same?

To find the answer, we need to leave Tenure=17 and Female=1 as they are. Then, we use the Random Forest workflow WfModelRF to generate wage predictions for various values of Tenure. The graphical representation of the result leads to the Ceteris Paribus Plot in Figure 11.1.

In the Ceteris Paribus Plot, the Tenure values are plotted against the related wage predictions from the Random Forest model. The plot in Figure 11.1 was generated with the following R code:

```
library(DALEX)
ExplainerRF=DALEX:explain(extract_fit_engine(WfModelWageRF),
data=DataTrain, y=DataTrainWage)
PPlot=predict_profile(explainer=ExplainerRF,
_observation=ObsHelga,
variables="Tenure")
plot(PPlot, variables="Tenure")
```

> In general, only one variable to change and leaving all other variables constant is called ceteris paribus (Latin for: everything else the same). Thus, the name of the plot.
