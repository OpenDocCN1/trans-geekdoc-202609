Step 1 - Generating Training and Testing Data: As before, you use
the dataset and split the data into training (DataTrain) and testing
(DataTest). Use the same value in the set.seed() command,
(the random) split will be identical to the one we used before with the k = 4
Nearest Neighbor model. The code has been executed already.

```
library(tidymodels); library(rio); library(janitor)
WineData<-import(\https://ai.lang-analytics.com/data/WineData.rds")
clean_names("upper")
rename(Sulfur=TotalSulfurDioxide) |
mutate(Color=as.factor(WineColor))

set.seed(076)
Split70=initial_split(WineData, prop=0.7, strata=WineColor)
DataTrain=training(Split70)
DataTest=testing(Split70)
```
