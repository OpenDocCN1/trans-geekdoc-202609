The linear regression model is represented by the following equation:

$Price = \beta_0 + \beta_1Grade + \beta_2Waterfront + \beta_3Waterfront_yes + \beta_4$ (5.10)

OLS assumes all predictor variables have additive and independent impact on the outcome variable. The related $\beta_s$ scale strength of these impacts.

Using OLS to find the optimal numerical OLS values for the variables, we have to solve one problem: The $Waterfront$ variable in the data frame `dataTrain` is not normal. It contains the values 'yes' and 'no'. To tackle this problem, we can transform $Waterfront$ into a `dummy` variable using `step_dummy()` in the recipe. The command `step_dummy()` assigns a value of 1 when the $Waterfront$ variable is 'yes' and a value of 0 when it is 'no'. There is no definite rule about which value 1 or 0 is assigned to 'yes' or 'no', but it is common practice to assign 1 to 'yes' and 0 to 'no'.

The recipe in the code block below determines the variables used for analysis and converts $Waterfront$ into a dummy variable. First, $Price$ is defined as the outcome variable, and all other variables ($Sqft, Grade,$ and $Waterfront$) are defined as predictor variables using the ..notation. Then `step_dummy(Waterfront)` converts the categorical variable $Waterfront$ into the dummy variable $Waterfront\_yes$.

```
library(tidymodels)
recipe(Price--, data=dataTrain) %>%nstep_dummy(Waterfront)
```

Note that step_dummy() changes the variable name (the column name in the data frame) to indicate which category is set to '1'. Since 'yes' is assigned to 1, the command `step_dummy()` renames $Waterfront$ to $Waterfront\_yes$. Consequently, if $Waterfront\_yes = 1$, a house is located at the waterfront.
