> R Script and Data Sources for MNIST Data Analysis
he material provided below allows you to experiment with recognizing handwritten notes from the MNIST dataset using k-Nearest Neighbors.
You to import random subsets of the MNIST dataset as well as the complete MNIST dataset:
- 500 sample observations (R data):
https://ai.lang-analytics.com/data/MN500.rds
- 1000 sample observations (R frame):
https://ai.lang-analytics.com/data/MN1000.rds
- 10000 sample observations (R frame):
https://ai.lang-analytics.com/data/MN10000.rds
- Complete MNISTdataset (R object):
https://ai.lang-analytics.com/data/MN.rds

Example:
library(rio)
DataMNIST<-import("https://ai.lang-analytics.com/data/MN500.rds")
