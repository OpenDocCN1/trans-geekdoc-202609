- All R commands have more than one argument, each of which has a unique name. This is also true for the commands mean() and median(). However, you can see that only one argument was provided in the two examples above. This is possible because R uses default values if the user does not provide values for all arguments.

- As mentioned earlier, we can nest commands. In the examples above, you can see the commands mean() and median() are nested into the command cat(). R allows for nesting commands to any depth. But nesting commands can make the code very difficult to read.

Let us look at the median() command in detail. When we type ? median() in the Console of RStudio, a help file is displayed in the Help-tab of RStudio. Besides other help topics, we get information about the command's arguments, their order, and default values:

```r
median(x, na.rm = FALSE, ...)
```

In this case, the median() command has two arguments: One argument x without a default, which means the user must assign the data to x, and second argument named na.rm. The latter determines if missing values are removed automatically before calculating the median. The default na.rm=FALSE means that missing values are not automatically removed. However, the user can set na.rm=TRUE, for example:

```r
median(x=VecAge, na.rm=TRUE)
```

Alternatively, the user can omit the argument names as long as the values of the arguments are in the correct order:

```r
median(VecAge, TRUE)
```

As a rule of thumb: In most R commands, the data argument is the first argument. This rule of thumb will help us later when we connect multiple commands (piping; Section 3.9.4).

# 3.9.1 Select Data

With the select() command, you can select variables (columns) from a data frame. This is useful if you do not need all variables.

The first argument of select() command is the name of the data frame you are working with. The other arguments (separated by commas) are the variables you like to select.

In the example, we load the tidyverse and import the Titanic dataset, and use select() to create a data frame called TitanicNarrow.

```r
library(tidyverse)
library(rio)
Titanic=import("https://ai.lang-analytics.com/data/Titanic.csv")
TitanicNarrow=select(Titanic, Survived, PasClass=PClass, Sex, Age, FareInounds)
```

As you can see, we were successful. The data frame TitanicNarrow contains only the selected columns.

We also renamed a variable. Since the variable PClass did not comply with our naming standards, we used PasClass=PClass to first select PClass and rename it to PasClass.

You can override an existing dataframe with the select() command, as shown in the example below:

```r
library(tidyverse)
library(rio)
Titanic=import("https://ai.lang-analytics.com/data/Titanic.csv")
Titanic=select(Titanic, Survived, PasClass=PClass, Sex, Age, FareInpounds)
```

In most cases, overwriting a data frame is not desired. You can see the problem here: if, for whatever reason, the select() command gets executed a second time, we would get an error message because we try to select and rename PClass, but PClass does not exist anymore in Titanic. It was renamed before, when we executed the select() command first time.

# 3.9.2 Filter Data
