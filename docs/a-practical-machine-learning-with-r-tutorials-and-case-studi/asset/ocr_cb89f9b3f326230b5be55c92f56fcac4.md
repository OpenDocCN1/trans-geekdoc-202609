# 7.4.1 Lasso Regularization

When you substitute the definition for the Lasso penalty from equation (7.4) into the target function (7.3) you get your target for the Lasso approach:

```
$T^{target}_{Lasso} = \frac{1}{20}\sum_{i=1}^{20}(Price_i - Price_i)^2 + \lambda\sum_{j=1}^{5}|\beta_j| \quad MSE_{OLS}\quad (7.6)
```

with:
$P^{penalty}_{Lasso} = \beta_1Sqft_1^2 + \beta_2Sqft_2^2 + \beta_3Sqft_3^2 + \beta_4Sqft_4^2 + \beta_5Sqft_5^2$,

You can see that the target $(T_{Lasso})$ only depends on the $eta$ values which causes the values of the houses ($Price_i$) and their square footage ($Sqft_i$) are known from the training data. Consequently, the Optimizer can use a systematic trial-and-error process to find the $\beta$ values that minimize the target function (7.6).

During the process, the Optimizer considers both the MSE and $P^{penalty}_{Lasso}$ simultaneously. Therefore for all $\lambda > 0$ the optimal $eta$ parameters will be smaller than in the case of an unregularized optimization $(\lambda = 0)$.

Below you will find the code to create a Lasso model design and a fitted workflow model. For the recipe that created the various powers of Sqft and normalized the resulting predictors, we use the recipe from Section 7.3:

```
library(glmet)

ModelDesignLasso<-linear_reg(penalty=500, mixture=1) |>
set_engine("glnet") |>
set_mode("regression")
```

```
WFModelLasso<-workflow() |>
```
