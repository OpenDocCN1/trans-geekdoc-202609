# FctMSE() - An R Function to Calculate the Mean Squared Error

A blog post by Carsten Lange describes how to program an R function. It uses the R function FctMSE() which was used in the book Practical Machine Learning with R as an example. FctMSE() calculates the MSE for a dataset based on the provided parameter values for slope and intercept of a univariate prediction function.
