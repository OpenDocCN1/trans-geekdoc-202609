Since all observations fall in one of the four cells in the confusion matrix, the sum of the four cells equals the number of observations. In addition, the sum of the cells on the main diagonal of the confusion matrix reflects the correctly predicted observations. This allows us to calculate our first performance metrics (accuracy) from the confusion matrix:

```
Accuracy = \frac{510 + 1039}{510 + 80 + 609 + 1039} = 0.69
```
