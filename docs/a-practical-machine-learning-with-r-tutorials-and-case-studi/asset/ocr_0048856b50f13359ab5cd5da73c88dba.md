FIGURE 6.2 Model Performance on Testing and Training Data (the non-linearity of the Polynomial Model)

The flexibility of the magenta line allows to approximate the training data very well, but the strong focus on the training data fails to represent the general trend of the remaining data (testing data). This is exactly the problem of overfitting.

In contrast, the blue linear line cannot bend (the linear one-predictor model can only produce a straight line). This prevents the model from overfitting (over-approximating the training data).
