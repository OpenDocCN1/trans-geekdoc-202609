In the examples below, we demonstrate a few applications of filter(). For this, we use the data frame TitanicNarrow that we created using the select() command:

### Analyzing only male passengers:

If we want to analyze the male passengers and then save the results in a new frame, TitanicMen, we can use:

```
TitanicMen=filter(TitanicNarrow, Sex=="male")
head(TitanicMen)
```

In the code block above, when we filtered for male passengers, we used Sex=="male" as a condition. This condition could be translated to: "the variable-name Sex.x is required to be "male"".

Please note the following two techniques:

- 1. we use == instead of = This is required in R and in most other programming languages because == indicates a condition rather than an assignment. Forgetting the second "-" sign in the condition is a common mistake. Fortunately, R gives a distinct error when this happens.
- 2. The word "male" must be written in quotes because the condition requires the variable Sex.x equals the char-value "male" and not the object male.

### Analyzing only passengers with low fares:

To filter the data frame for passengers with a fare below £7 and then save the results in the new data frame, TitanicLowFare, you can use the following R code:

```
TitanicLowFare=filter(TitanicNarrow, FareInPounds<7)
head(TitanicLowFare)
```

### 3.9.3 Mutate (Calculate) New Variables in a Data Frame

The mutate() command provides something very similar to what we often do in Excel: We have an Excel table with data and want to add an extra column based on one or more columns.

**Based on a data frame, mutate() calculates a new variable (column) based on existing variables (columns).** A command like *calculate* rather than mutate would likely show what the command actually does, but the name is — *mutate()*.

Here is an example: The FareInPounds in the Titanic dataset reflects prices of 1912 in pounds. How many are these prices in 2023 U.S. dollars? To get an approximate value, we have to multiply the British pound prices from 1912 by 108.5.

Here are the detailed steps:

- We need to create a new data frame DataTitanicNewFare that contains a variable (column) FareIn2023Dollars based on the data frame DataTitanicNarrow.
- The new variable (column) FareIn2023Dollars is defined as: 108.5 * FareInPounds.
- It would also be nice to delete the column FareInPounds afterward, as it is no longer useful.
- We can accomplish all with the mutate() command:
- The first argument of the mutate() command is (again) the data it operates on (DataTitanicNarrow).
- The following arguments determine how to calculate new variables and update existing variables.
- Subsequent definitions are separated by commas.

The related R code and the output:

The exchange rate for 1912 was about 108.5.

```
DataTitanicFare=mutate(DataTitanicNarrow, FareIn2023Dollars=108.5*FareInPounds, FareInPounds=NULL)
head(DataTitanicFare)
```

### 3.9.4 Linking Commands Together with Piping

Piping is a procedure that links one or more commands. The pipe operator pushes the output of one command as input to the next. We will demonstrate how piping works with an example: Assume that on the data frame, we would like to create a data frame DataFinalResult that contains:

- the variables Survived, Sex, Age, and FareInPounds
- only female passengers
- the fare should be expressed in 2023 dollars.

As you learned, for the first condition, you would use the select() command to select the required variables, ensuring your result contains only female passengers, you would use filter() to filter your observations, and finally, to ensure the fare is expressed in 2023 dollars, you would use mutate().
