Since all three performance measures ranked a Polynomial Model of degree 6 as the best model, it does not matter what performance we choose to extract the data for the best model. For example, to extract the best-performing hyper-parameter to minimize rmse, we can use:

```
BestHyperPar=select_best(TuneResultsHouses, "rmse")
print(BestHyperPar)
```

```

```

The printout of BestHyperPar shows that the best-performing hyper-parameter value is saved in the data column degree as the first and only entry.

We will use this data frame to create a model (the best one) with the best hyper-parameter (degree=6).

To do this, we add the best-parameter to the tune workflow with finalize_workflow(). This command updates the tune() placeholder with the optimal hyper-parameter value that is stored in BestHyperPar. Afterward, we call the fit() pipe to train the workflow model:

```
BestWFModelHouses=TuneWFModelHouses |
finalize_workflow(BestHyperPar) |
fit(DataTrain)
print(BestWFModelHouses)
```
