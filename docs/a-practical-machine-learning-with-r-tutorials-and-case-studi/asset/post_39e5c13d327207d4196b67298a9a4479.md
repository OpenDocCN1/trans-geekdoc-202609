### 11.7 SHAP Contribution of Predictor Variables

In the R code, we use the command `explain_tidymodels` from the explainer package which allows us to create the explainer object directly from the `wfModelVax` workflow. The command `explain_tidymodels()` requires the training data assigned to the `data` argument. This is why we first `select()` to create a data frame containing only the prediction variables. The outcome variable `PercVacFull` (a county's rate of fully vaccinated adults) is provided through the `outcome` argument, and `verbose=FALSE` suppresses the message.

Now, everything is ready to calculate SHAP values for one observation with the `predict_parts()` command. In the interactive part below, you can create and interpret SHAP values for almost any county, but for now we keep and choose Los Angeles County. In the data frame, Los Angeles has `CountyID=133`, which means the Los Angeles observation is the 133rd row of the dataset.

The plot in Figure 11.7 shows the bars indicate the SHAP values for the respective predictor variables, with the label on the vertical axis indicating the value of the predictor variable in Los Angeles. The overlapping bars indicate the distribution of the SHAP values for 25 scenarios (random orderings of predictor variables). You find the R code that generates Figure 11.7 below:

```r
set.seed(2021)
CountyID=133
SHAPobject<-predict_parts(
  explainer=ExplainerRandForest,
  new_observation=DataVx[CountyID],
  type="shap", B=25)

plot(SHAPobject)
```

We use the argument `new_observation=DataVx[CountyID]` to create SHAP values for the Los Angeles observation. Also, the explainer object that we created is assigned to the argument `explainer=` and the argument `B=25`.
