```
DataMockup=
import("https://ai.lang-analytics.com/data/DataStudyTimeMockup.rds")

VecBeta=(4, 61)
DataTable<-DataMockup |>
mutate(PredGrade=VecBeta[1]*StudyTime+VecBeta[2]) |>

cat("MSE for VecBeta[1]=4 and VecBeta[2]=61 is:", MSE)
```

# The MSE for VecBeta[1]=4 and VecBeta[2]=61 is: 29.8

We can also calculate the $MSE$ algebraically:

```
$$MSE = \frac{1}{N} \sum_{i=1}^{N}(\hat{y}_i - y_i)^2$$
\implies MSE = \frac{1}{N} \sum_{i=1}^{N} (\frac{\beta_1 x_i + \beta_2 - y_i}{Error i})^2 \quad (5.5)
```

## 5 Linear Regression — Key Machine Learning Concepts

At this point, you can already see that smaller prediction errors (i.e., absolute smaller values for $\hat{y}_i - y_i$) lead to a smaller $MSE$. Therefore, our error function is well suited as a metric to measure a model's predictive quality and can be used to find optimal $\beta$ parameters for the model later on.

Equation (5.5) allows us to calculate the $MSE$ for any set of parameters $(\beta_1, \beta_2)$ because based on the training data, all values for the predictor variable $(x_i)$ and the output variable $(y_i)$ are known — only $\beta_1$ and $\beta_2$ to be determined.

This can be shown for the mockup dataset, if we resolve the summation sign ($\sum$) in Equation (5.5) and also substitute $y_i$ and $x_i$ with the training data observations from Table 5.1 (remember, $i$ is the index for the observation), we get (5.6):

```
$$MSE = \frac{(\beta_1x_1 - y_1)^2 + (\beta_1x_2 - y_2)^2 + \dots + (\beta_1x_5 - y_5)^2}{5}$$
$$MSE = \frac{1}{5} \left[ \begin{array}{c|c} Prediction 1 & Prediction 2 \\ (\beta_1 \cdot 7 + \beta_2 - 65)^2 + (\beta_1 \cdot 3 + \beta_2 - 82)^2 \\ Error 1 & Error 2 \\ Prediction 3 & Prediction 4 \\ (\beta_1 \cdot 7 + \beta_2 - 93)^2 + (\beta_1 \cdot 8 + \beta_2 - 93)^2 \\ Error 3 & Error 4 \\ Prediction 5 & Error 6 \\ (\beta_1 \cdot 4 + \beta_2 - 83)^2 \\ \end{array} \right] (5.6)$$
```

Equation (5.6) shows that **when the training data are given, the MSE is only based on the choice of the parameters** — $\beta_s$.

Consequently, if you substitute the arbitrary chosen values, $\beta_1 = 4$ and $\beta_2 = 61$, into Equation (5.6), you can take a calculator and find that $MSE = 29.8$. This is quite cumbersome, but it might be a good exercise to fully understand the importance of Equation (5.6).

Although calculating the $MSE$ is cumbersome for a human, writing a function in $R$ to calculate the $MSE$ based on a set of $\beta$-values and a training dataset is relatively easy. Since such a function will be needed in the following sections, we created an $R$ function `FctMSE()` to calculate the $MSE$. This function can be imported in your $R$ code using the `import()` command (see the code block below).

For those who are interested in the underlying code and how how to program a function in $R$, a link to a blog post is provided in the Digital Resource Section 5.7.

## Takeaways from the MSE

MSE for the univariate OLS regression with $N$ observations can be calculated as:

> $MSE = \frac{1}{N} \sum_{i=1}^{N}(\beta_1 x_i - y_i)^2$ with $x_i$ and $y_i$ known from the training dataset.

- 1. When the training data are given, only the choice of the $\beta$ parameters determines the MSE. Since both — the values for $x_i$ and $y_i$ — are part of the training dataset, the MSE depends only on the chosen values for the $\beta$ parameters.
- 2. Since different $\beta_1$ and $\beta_2$ generate different MSEs, the goal is to find a pair of $\beta$ that leads to the smallest MSE.

In the following Section 5.4.2, you will learn how to calculate the optimal values $\beta_{1,opt}$ and $\beta_{2,opt}$ for the mockup example using OLS. Afterward, in Section 5.4.3, we will introduce two algorithms that a computer can use for a systematic trial-and-error approach to find the values $\beta_{1,opt}$ and $\beta_{2,opt}$.

## 5.4.2 Calculate Optimal Values Based on OLS

Below are the formulas for the optimal $\beta$s for a univariate regression based on a training dataset with $N$ observations. Before, we abbrevi the outcome variable *Grade* with $y$ and the only predictor *StudyTime* with $x^2$:

```
$$\beta_{1,opt} = \frac{N\sum_{i=1}^{N} y_i x_i - \sum_{i=1}^{N} y_i}{N\sum_{i=1}^{N} x_i^2 - (\sum_{i=1}^{N} x_i)^2} \quad (5.7)$$
```

```
$$\beta_{2,opt} = \frac{\sum_{i=1}^{N} y_i - \beta_1\sum_{i=1}^{N} x_i}{N} \quad (5.8)$$
```

You can see the values for $\beta_{opt,1}$ and $\beta_{opt,2}$ are only based on data from training dataset. The two equations might look scary to readers unfamiliar with summation notation. However, it is actually not difficult to calculate the values for $\beta_{opt,1}$ and $\beta_{opt,2}$ if we use $R$. Again, use the mockup dataset (see Columns 2 and 3 of Table 5.2) to demonstrate how $\beta_{opt,1}$ and $\beta_{opt,2}$ can be calculated with $R$ based on Equations (5.7) and (5.8).

We start with summation $\sum_{i=1}^{N} x_i$. The term means we sum up all $x$, considering that $i$ takes values from 1 and ending with $N$ (being 5 in our case). Because $i$ is the row number in Table 5.1, $\sum_{i=1}^{N} x_i$ stands for the $x$ column in Table 5.1. The same applies to $\sum_{i=1}^{N} y_i$.

With this knowledge, we can easily use $R$ to calculate $\sum_{i=1}^{N} x_i$ and $\sum_{i=1}^{N} y_i$.

```
SumOfX=sum(DataMock$StudyTime)
SumOfY=sum(DataMock$Grade)
```

At this point, we are not yet ready to calculate $\beta_{opt}$ according to Equation (5.7) because the formula also requires calculating the sum of the product of the observations for $y_i$ and $x_i$ ($\sum_{i=1}^N y_ix_i$) as well as the sum of the squares of the $x_i$ values ($\sum_{i=1}^N x_i^2$). However, we can use the mutate() command to add these variables to the frame DataMockup and call the new result frame DataTable:

```
DataTable<-DataMockup |>
mutate(GradeStudyTime=Grade$StudyTime)
mutate(StudySquared=StudyTime^2)
```

Table 5.2 shows the resulting data frame DataTable.

Next, we calculate the sums of $\sum_{i=1}^N y_ix_i$ and $\sum_{i=1}^N x_i^2$ (see the code below). When we plug in these sums together with the previously calculated sums $\sum_{i=1}^N x_i$ and $\sum_{i=1}^N y_i$ and the value for $N = 5$ into Equation (5.7)

```
N=5
SumOffsetY=sum(DataTable$Grade)
OfFX=sum(DataTable$StudyTime)
SumOfXY=sum(DataTable$GradeStudyTime)
SumOfSq=sum(DataTable$StudySquared)

Betaopt=(N*SumOfXY-SumOffsetY*OfFX)/(N*SumOfSq-OfFX^2)
```

> *Based on the training dataset the optimal value for Beta = Betaopt*

### on the training dataset the optimal value for Beta = 3.963

Afterward, we can plug in the value of $\beta_{opt}$, into Equation (5.8) together $\sum_{i=1}^N y_i$ and $\sum_{i=1}^N x_i$ to calculate $\beta_{2opt}$.

```
Beta2opt=(SumOffsetY-Betaopt*OfFX)/N
cat("Based on the training dataset the optimal value for Beta2 =", Beta2opt)
```
