Tree, it is reasonable to assume that the related errors ($u_i$) still contain some systematic impacts on the outcome variable $Y$. Therefore, we create a second Decision Tree ($D_i^{DecTree}(Obs_i)$) based on the predictor variables in the training dataset and the known errors from the first $Decision Tree$. These errors are known because we can calculate them as the difference between the known outcome values from the training dataset and the predictions from Equation (10.8):

$Y_{1,i} = \overline{Y} + \gamma D_i^{DecTree}(Obs_i) \quad \text{with: } 0 < \gamma < 1$$

After creating the second $Decision Tree (D_i^{DecTree}(Obs_i))$ to predict the errors from the first $Decision Tree$ ($u_{1,i}$), the prediction equation for the outcome $Y$ improves to:

$Y_{i} = \overline{Y} + \gamma D_i^{DecTree}(Obs_i) + \gamma^2 D_i^{DecTree}(Obs_i) + u_{2,i} \quad \text{with: } 0 < \gamma < 1$$

The errors from the prediction by the second Decision Tree ($u_{2,i}$) may still contain some systematic information, and since their values are known, we can use a third $Decision Tree$ to integrate the systematic impacts from these errors, which leads to:

$\widehat{Y}_{i} = \overline{Y} + \gamma D_i^{DecTree}(Obs_i) + \gamma^2 D_i^{DecTree}(Obs_i) + \gamma^3 D_i^{DecTree}(Obs_i) + u_{3,i}$$

$0 < \gamma < 1$$

$\widehat{Y}_{i} = \overline{Y} + \gamma D_i^{DecTree}(Obs_i) + \gamma^2 D_i^{DecTree}(Obs_i) + \gamma^3 D_i^{DecTree}(Obs_i) \quad (10.9)$$

$0 < \gamma < 1$$

We stop here because we decided to use only three Decision Trees. More trees would be added. In real-world applications, many fact the number of $Decision Trees$ to be added is a tunable $hyper-parameter$ for $Gradient Boosting$ models.

Equation (10.9) can be used to predict the outcome $Y_i$ for any observation $i$ as long as the values for the predictor variables $(Obs_i)$ are known. For example, we could use the observations from a testing dataset to assess how well a $Gradient Boosting$ model performs.
