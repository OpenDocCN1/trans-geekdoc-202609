2. As already explained in Section 9.6, you will use the more advanced PyTorch Neural Network from the butlee package instead of the Neural Network from the next package.
3. You will tune the Neural Network's hyper-parameters (hidden_units and dropout) using Cross-Validation.

Keep in mind that you have install the butlee package before you can execute the code. After the butlee package is installed, the PyTorch software must also be installed. We use the 10-Step Template introduced in Section 6.6. Steps 1 – 4 are already prepared for you.

### Step 1 - Generating Training and Testing Data:

```
library(tidymodels); library(janitor); library(butlee)
set.seed(888)
Diamonds=sample_n(diamonds, 500) |
clean_names(upper_camel) |
select(Price, Carat, Cut, Color, Clarity) |
mutate(Cut=as.integer(Cut), Color=as.integer(Color),
Clarity=as.integer(Clarity))
```

```
set.seed(888)
Split70=initial_split(Diamonds, prop=0.7, strata=Price, breaks=5)
```

### 9.7 Using PyTorch to Predict Diamond Prices

```
DataTrain=training(Split70)
DataTest=testing(Split70)
```

In the code block above, we load the data and choose randomly 500 observations. Then we select the outcome variable (*Price*) and the predictor variables Carat, Clarity, Cut, and Color transforming the factor-levels of the last three variables to numerical values. Finally, we split the data into training and testing data.

### Step 2 - Create a Recipe:

We use the same recipe() command as in Section 9.5:

```
RecipeDiamonds=recipe(Price-, data=DataTrain) |>
step_normalize(all_predictors())
```

After, we use step_normalize() for Z-score Normalization¹⁶ of all predictors.

### Step 3 - Create a Model:

In the code below, we create a model. Like in Section 9.5, we use mlp() to create a model.

```
ModelDesignNN=mlp(hidden_units=tune(), dropout=tune()) |>
set_mode("regression")
```

The hyper-parameters hidden_units and dropout are prepared for tuning. When you use the provided R script from 9.9 to run the code rather than in a browser, you can increase the (e.g., epochs=100).

### Step 4 - Add the Recipe and the Model Design to a Workflow:

Below, we add the recipe and the model design to a workflow, which will be tuned in Step 7:

```
TuneWFModelNN=workflow() >
add_model(ModelDesignNN) >
add_recipe(RecipeDiamonds)
```

Steps 5 — 10 in the code block are the steps you will execute (and potentially modify). It is recommended to execute the code unchanged in a first attempt. Then, you can start modifying the code and see what happens. To use different values for the hyper-parameters, modify the Hyper-Parameter Grid in Step 5.

### Step 5 - Create a Hyper-Parameter Grid:

To out different hyper-parameter values, change the values that are assigned to the respective hyper-parameters below

```
ParGridNN=expand.grid(hidden_units=c(10, 20, 50), dropout=c(0, 0.25))
```

### Step 6 - Create Resamples for Cross-Validation:

You can v= to consider a different number of folds (e.g. v=10). Note, computing time will change proportionally.
set.seed(888)
oldsForTurningNN=fold_cv(DataTrain, v=7, strata=Price)

### Step 7 - Tune the Workflow and Train All Models:

(this step requires patience; run time 5-30 minutes)
set.seed(888)
TuneResultsNN=tune_grid(TuneWFModelNN, resamples=FoldsForTurningNN,
grid=ParGridNN, metrics=metric_set(rmse, rsq, mae))

### Step 8 - Extract the Best Hyper-Parameter(s)

BestHyperNN=select_best(TuneResultsNN, "rmse")
print("Best Hyper-Parameters:")
print(BestHyperNN)
