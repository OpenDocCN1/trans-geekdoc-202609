# 9 Deep Learning — Neural Networks Explained

By default, the R script utilizes the complete dataset. Computing time is only limited by your patience, you can try out more values for the pre-set hyper-parameters (hidden_neurons= and dropout=), and you can add different hyper-parameters such as penalty=tune() to try out various degrees of regularization.

Let us use the Neural Network that you will run in a browser. We will estimate the price of diamonds with a Neural Network under real-world conditions:

+   1. You will use all C variables Carat, Clarity, and Color as predictor variables. We will use Carat and Clarity explicitly in Section 9.5. Here, the variables Cut and Color are added to the analysis. Cut describes the quality of the diamond and is rated from (lowest) to 6 (highest); Color rates the color of a diamond from (highest) to 7 (lowest); the opposite direction of the rating scale.
2. As already explained in Section 9.6, you will use the more advanced PyTorch Neural Network from the butlee package instead of the Neural Network from the next package.
3. You will tune the Neural Network's hyper-parameters (hidden_units and dropout) using Cross-Validation.

Keep in mind that you have install the butlee package before you can execute the code. After the butlee package is installed, the PyTorch software must also be installed. For the first time (i.e., with library(butlee)) a popup window appears to download and install the required software. After confirming with “Yes", the PyTorch software will be installed.
