# Calculate Euclidean Distance for Three or More Variables

Assume our observations have two predictor variables $x$ and $y$, like in the example we showed. We can then apply the logic from Equation (4.1) and calculate the (Euclidean) distance between a point we like to predict and any point $i$ as follows:

```
$EucDist2 = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$
```

$EucDist2$, is the distance between the two observations in two-dimensional space.

How does the formula change when considering a third predictor variable $z$? We just add the new variable under the square root in as we did for the other variables:

```
$EucDist3 = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2 + (z_i - z_j)^2}$
```

Interestingly, considering three variables, $EucDist3$, represents the length of the shortest straight-line distance between two points in three-dimensional space.

If we have more variables, a straightforward geometric interpretation is not possible. However, we just add the difference of each new variable between the prediction point and a point $p$ under the square root. For example, in Section 4.10, we will consider 784 variables resulting in a pretty long formula under the square root, but this is no problem for a computer.

The formula below shows how the Euclidean Distance is calculated when $N$ predictor variables $(v_1, v_2, ..., v_N)$ are considered:

```
$EucDist_N = \sqrt{\sum_{j=1}^{N}(v_{ij} - v_{pj})^2}$
```

> To avoid writing very long formulas, a programmer who creates a k-Nearest Neighbors algorithm would likely use matrix algebra.

Now you know how to calculate the Euclidean Distance between any two observations for any number of predictor variables, we can demonstrate how the $k$-Nearest Neighbors model predicts and how its performance can be measured using the testing dataset:

+   Step 1: Take the first observation from the testing dataset and calculate the distance from this record to all observations in the training dataset.
Step 2: Find the observation that has the smallest distance to the testing observation.
Step 3: The predicted class (e.g., red or white) for the observation from the testing dataset is the same as the class from its nearest neighbor.
