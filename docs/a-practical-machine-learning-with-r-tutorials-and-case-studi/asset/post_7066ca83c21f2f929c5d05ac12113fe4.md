## What criterion determines if a splitting variable/value combination is good?

The Decision Tree algorithm from the r package uses Gini Impurity as a criterion for classification problems. Other measures that can be set Information Gain and Chi-Square.5 Here we focus on Gini Impurity.6

The Titanic passengers were different in many ways. Some of their differences (e.g., their Sex) were crucial for survival, while others were less important. When we split a parent node (for instance, the root node) into two child nodes, we want the two nodes to be as different as possible regarding survival proportions. Ideally, we would like to get one child node with a survival proportion of 100% and the other with 0%. In that case containing one group of survivors and another group of non-survivors, Gini Impurity would be somewhat at the lowest level for both child nodes.

Let us follow this unrealistic path by assuming that all men on the Titanic died and all women survived. A decision rule of Sex=male would create two pure nodes containing only non-survivors and the other containing only survivors. GiniImpurity should be 0 for both pure child nodes.

Gini Impurity for an individual node is defined by the product of the proportions for the observation between two different classes (P_{Surv} and P_{NonSurv}), multiplied by two. In one case:7

```
$G^{Imp} = 2P_{Surv}P_{NonSurv}. (10.1)
```

We used type=$0 instead of $sex=0$. Obviously, this decision rule would make little sense, since blue type will not influence the survival chance on the Titanic. The proportions of survivors in both child nodes would be approximately the same as in the parent node (root node): $P_{Surv}=0.39$ and $P_{NonSurv}=0.61$ (see Figure 10.1).

Equation (10.1) shows that the resulting Gini Impurities would be the for the parent node and the two child nodes:

```
$G_{parent}^{Imp} = G_{leftChild}^{Imp} = G_{rightChild}^{Imp} = 2 \cdot 0.61 - 0.61 = 0.48$
```

The value of Gini Impurity is not so crucial. Where is crucial that the decision rule is able to lower the Gini Impurity from the parent node to the child nodes. Gini impurity 0.48 in the parent node and the (weighted) average from the two child nodes is 0.48. The decision rule is useless!

Finally, let us review the extreme examples and take a look at the decision rule $sex=male$ lower Gini Impurity? We already know from the last example that the root node has a Gini Impurity of $G_{root}^{Imp}=0.48$. According to Equation (10.1), the Gini Impurity for the left child node is (see Figure 10.1):

```
$G_{male}^{Imp} = 2 \cdot 0.2 - 0.8 = 0.32$
```

The Gini Impurity for the right child node is:

```
$G_{female}^{Imp} = 0.73 \cdot 0.27 - 0.29 \cdot 0.37 = 0.35$
```

The Gini Impurity for a decision rule is the average of the two child nodes weighted by the proportion of the observations that ended up in the two child nodes:

```
$G_{male/female}^{Imp} = 0.64 \cdot 0.32 + 0.36 \cdot 0.39 = 0.35$
```

Consequently, the decision rule $sex=male$ decreased the Gini Impurity by 0.13 from $G_{root}^{Imp}=0.48$ to $0.35$.

We know that the Optimizer calculated the Gini Impurity decrease for all possible splitting variable/value combinations. Therefore, a Gini Impurity decrease of 0.13 must have been the largest. Otherwise, $sex=male$ would not have been chosen as the decision rule.

## 10.3.2 The Instability of Decision Trees

You saw already one drawback of Decision Trees in the previous section — not all rules make sense.

This section will show another drawback of Decision Trees. They react very sensitively to small changes. For example, in the code block below, the Titanic dataset is split into testing and training data:

```
set.seed(888)
Split7525=initial_split(Titanic, strata=Survived)
DataTrain=training(Split7525)
DataTest=testing(Split7525)
```
