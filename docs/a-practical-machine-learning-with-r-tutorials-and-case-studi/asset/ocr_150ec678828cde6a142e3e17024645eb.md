Let us look at the median() command in detail. When we type ? median()
in the Console of RStudio, a help file is displayed in the Help-tab of
RStudio. Besides other help topics, we get informa-
out the command's arguments, their order, and default values:

```
median(x, na.rm = FALSE, ...)
```

In this case, the median() command has two arguments: One argued
x without a default, which means the user must assign the data to x, and
second argument named na.rm. The latter determines if missing values are
removed automatically before calculating the median. The default na, rm=FALSE
means that missing values are not automatically removed. However, the user
set can na.rm=TRUE, for example:

```
median(x=VecAge, na.rm=TRUE)
```

Alternatively, the user can omit the argument names as long as the values of
t arguments are in the correct order:

```
median(VecAge, TRUE)
```
