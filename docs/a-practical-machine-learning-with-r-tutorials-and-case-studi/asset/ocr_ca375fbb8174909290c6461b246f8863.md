R uses almost scientific notation except for substituting the "10 to the power of ..." with the lowercase letter e. This notation is not very pretty, and it is certainly not mathematically correct, but almost statistical programs use this pseudo-scientific notation.¹12

What did you learn? When you see R output for very big or small numbers, you know now how to interpret the number following the letter e. This number tells you how many digits to shift the decimal point to the right (when the number is positive) or to the left (when the number is negative).
