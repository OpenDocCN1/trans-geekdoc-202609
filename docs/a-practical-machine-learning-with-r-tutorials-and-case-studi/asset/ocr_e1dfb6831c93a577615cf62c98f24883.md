# 11 Interpreting Machine Learning Results

Using three predictor variables led to eight coalitions to consider. One was highly based on the *Random Forest* model we wanted to explain (Coalition: ETF), and for another one, we used the mean of the outcome variable from the training dataset as the predicted weight for which we had to design and train six new *Random Forest* models. Creating new *Random Forest* models is not a significant computational problem. However, the number of coalitions (NCitions) grows exponentially with the number of predictor variables (NPredVar):

```
NCoalitions = 2^NPredVar
```

For three predictor variables, we need eight coalitions (2³ = 8), but for 20 predictor variables, we need to design and fit more than 1 *Random Forest* models (²⁰ = 1,048,576). The computational cost of this is excessively high.

Fortunately, many effective algorithms exist to estimate SHAP values to explain predictions of machine learning models. For example, KernelSHAP, a kernel based SHAP value, was developed by Lundberg and Lee (2017). Later, Lundberg et al. (2019) developed *TreeSHAP*, a very effective model-specific algorithm limited to *tree-based* models. Both algorithms are beyond the scope of this book, but an introduction and a comparison of both models can be found online (2029).

In the following section, we use the DALEX and the DALEXR packages to estimate SHAP values to interpret the results from the vaccination project that we used in the interactive Section 10.4.2. Below, we present the basic ideas of the DALEX algorithm.

DALEX, like our simplified approach, used the mean of the outcome variable for the first coalition (Coalition: name) and the final to predict the outcome for the last coalition (Coalition: ETF). For all other coalitions, DALEX also uses the final machine learning model, which avoids designing and fitting new machine learning models for every coalition.

However, using a model designed to use all predictor variables for a coalition that consists less than all raises the question of which values to use for the variable(s) covered by this coalition. For example, if we want to predict *College*: TF from Figure 11.6, we would use the *Tenure* = 18 and *Female* = 1 values from observation Helga, but what do we use for *Edu*?

The DALEX solution is to substitute *Tenure* and *Female* values in the training dataset observations with Helga's values *Tenure* = 18 and *Female* = 1, but leave all values for *Edu* untouched. Then, based on the new dataset, the *Random Forest* model creates predictions for all observations. This way, the values from observation Helga (*Tenure* = 18 and *Female* = 1) are utilized to predict, and the distribution of the missing variable (*Edu*) is preserved.
