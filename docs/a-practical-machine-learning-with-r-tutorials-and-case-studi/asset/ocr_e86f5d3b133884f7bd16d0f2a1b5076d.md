# 5 Linear Regression — Key Machine Learning Concepts

The linear predictionTime equation for predicting the outcome $Grade$ with the predictor $StudyTime$ is:

```
$Grade_c = \beta_1 StudyTime_c + \beta_2 \quad\ (5.4)$
```

Given a numerical pair of parameters $(\beta_1, \beta_2)$, it is possible to predict a $Grade$ for any value of the predictor variable $StudyTime$. We can arbitrarily choose $\beta_1=4, \beta_2=61$, and store the $\beta$'s$ in the $R$ vector object $VecBeta$.

```
VecBeta=c(4, 61)
DataTable=DataMockup(Grade=VecBeta[1]*StudyTime+VecBeta[2])
```

Let us verify the grade for the first observation in Table 5.1:

```
$PredGrade_1 = 4 \times 2 + 61 = 69$
```

The predicted grade for a student who studies for 2 hours is predicted to 69 points. Similarly, you can predict the grades for all other observations in the training dataset (see Column 4 of Table 5.1). Try to verify at least one observer's $PredGrade!$

Figure 5.1 shows the $StudyTime/Grade$ data from Table 5.1 plotted as blue points. The red line reflects the prediction equation for the arbitrarily chosen $\beta_1=4$ and $\beta_2=61$. Consequently, all predicted $StudyTime/PredGrade$ combinations (black dots) are on the red line.

To measure the prediction error for each of the five observations (see Column 5 in Table 5.1), we have to calculate the difference between the prediction and the true value of the outcome:

```
$Error = PredGrade - Grade$
```

These errors are visualized in Figure 5.1 as the vertical difference between the blue points (true grades) and the black points (predicted grades).
