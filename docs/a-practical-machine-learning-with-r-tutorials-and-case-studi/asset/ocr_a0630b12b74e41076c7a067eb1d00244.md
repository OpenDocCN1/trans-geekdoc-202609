# 5 Linear Regression — Key Machine Learning Concepts

```
$MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$
$$\longleftarrow \text{Prediction } i$$
$$MSE = \frac{1}{N} \sum_{i=1}^{N} (eta_1 x_i + \beta_2 - y_i)^2 \quad (5.9)$
```

Equation (5.9) provides the formula to calculate the *MSE*. For a training dataset (all $y$ and $x_i$ are known), we can choose any pair $eta_1$ and $eta_2$, and use Equation (5.9) to calculate the related *mean squared error* (see Section 5.4 for details). However rather than arbitrarily choosing values for $eta_1$ and $eta_2$, we will use more systematic approaches.

In Section 5.4.3.1, we use Grid Search: First, we generate two vectors $eta_1$ and $eta_2$ containing various values, respectively. Then we will use R to generate all possible combinations for $eta_1$ and $eta_2$ values. For each of the results of $eta_1$ and $eta_2$, we will calculate the $MSE$ and finally choose the pair with the lowest $MSE$.

In Section 5.4.3.2, we will use an Optimizer to find optimal values for $eta_1$ and $eta_2$. An *Optimizer* is an iterative computer algorithm that can minimize or maximize a target function. In our case the $MSE$ function (5.9) is the target function.

# 5.4.3.1 Finding Optimal Parameters Using Grid Search

This section uses the *Grid Search* algorithm to find the pair of $eta_{1,opt}$ and $eta_{2,opt}$ that minimizes the $MSE$.

Let us begin by deciding a range for $eta_1$ and $eta_2$ and on how many values we would like to test for. At the beginning of this section, we used $eta_1 = 4$ and $eta_2 = 61$, and the predictions were not too bad. So, why not use a range around $3 - 5$ for $eta_1$ and a range of $50 - 70$ for $eta_2$? For each, $eta_1$ and $eta_2$, we will generate about 20 values in the chosen range.

In the code block below, we generate a sequence of values for $eta_1$ ranging from 3 to 5 with an increment of 0.1. For $eta_2$, we choose values ranging from 50 to 70 with an increment of 1 in 21 values for each, $eta_1$ and $eta_2$. These values are assigned to the $R$ vector objects `vecBeta1Values` and `vecBeta2Values`, respectively.

```
vecBeta1Values=seq(3, 5, 0.1)
vecBeta2Values=seq(50, 70, 1)
```
