
## 9.4 神经网络模型背后的原理

**步骤 4：** 现在，两个有效输入（每个隐藏神经元一个）被接入隐藏神经元 $H1$ 和 $H2$ 内部的非线性函数（称为*激活函数*）。这些结果被称为神经元 $H1$ 和 $H2$ 的*活性*（$A_{H1}^\sigma$ 和 $A_{H2}^\sigma$）。我们稍后会详细讨论激活函数。

**步骤 5：** 隐藏神经元的活性 $A_{H1}^\sigma$ 和 $A_{H2}^\sigma$ 被传输到输出神经元 (O1)，但在到达之前，它们的值分别被 $\beta_1$ 和 $\beta_2$ 加权。

**步骤 6：** 三个值到达输出神经元 (O1) 前的 $\oplus$ 符号处：来自隐藏神经元的两个加权*活性*($\beta_1 A_{H1}^\sigma$ 和 $\beta_2 A_{H2}^\sigma$) 以及来自偏置神经元 $B2$ 的值（其等于 $\beta_7$）。这三个值被聚合（相加）为一个单一值，即输出神经元 O1 的值，以及相关钻石的预测价格。

在复杂场景下，输出神经元 O1 可能也包含一个激活函数，但此处进入输出神经元是不经过任何转换的 ($O1 = f^\sigma(O1)$)。

上述内容结合图 9.1，提供了关于神经网络如何处理变量以生成结果变量预测的基本思想。如果神经网络包含更多的输入和隐藏神经元，或更多的层，该过程会更加复杂，但基本原理是相同的。

然而，到为止还有两个问题尚未解答：

**问题 1：** 我们假设 $\beta_j$ 的初始值为：它们是如何确定的？

**回答：** 对于 $\beta_j$ 的初始值，这个问题的答案很简单（通常 $-1 < \beta_j < 1$）。这使得为训练数据集中的所有观测生成初始预测成为可能。生成的初始预测并不理想。我们需要通过在迭代过程中更新 $\beta$ 参数来改进。这个更新过程——被称为训练网络——要复杂一些。我们在第 9.4.3 节涵盖预测的数值示例后，将在第 9.4.4 节讨论其基础原理。

**问题 2：** 隐藏神经元 $H1$ 和 $H2$ 内部的*激活函数*是如何将*有效输入值* ($I_{j,1}^\sigma$ 和 $I_{j,2}^\sigma$) 转换为隐藏神经元的活性的（$A_{H1}^\sigma$ 和 $A_{H2}^\sigma$）？

**回答：** 这稍微复杂一点：隐藏神经元内部可以使用各种激活函数将*有效输入* $I_{j,i}^\sigma$ 转换为活性 $A_j^\sigma$（$j$ 代表隐藏神经元的编号，$i$ 代表观测编号）。在这里，我们使用 Logistic 函数——我们在第 8 节用于逻辑回归时使用的相同函数。我们将有效输入 $I_{1,i}^{eff}$ 和 $I_{2,i}^{eff}$ 代入 Logistic 函数，并计算隐藏神经元 $H1$ 和 $H2$ 的活性 $A_{1,i}^{cl}$ 和 $A_{2,i}^{cl}$：

$$A_{1,i}^{cl} = \frac{1}{1+e^{-I_{1,i}^{eff}}} \quad (9.1)$$
$$A_{2,i}^{cl} = \frac{1}{1+e^{-I_{2,i}^{eff}}} \quad (9.2)$$

### 9.4.2 将图形方法转换为预测方程

图 9.1 和上述步骤 3 显示了*神经网络*的结构，但为了使用计算机进行预测，需要将图转换为预测方程，这正是本节的目标。

图 9.1 和图 3 显示了两个隐藏神经元的*有效输入*是如何通过加权预测变量和偏置神经元计算得的。从一个观测值来看，这可以通过确定 $I_{1,i}^{eff}$ 和 $I_{2,i}^{eff}$ 的两个方程表示：

$$I_{1,i}^{eff} = \beta_1 + \beta_2 Carat + \beta_3 Clarity, \quad (9.3)$$
$$I_{2,i}^{eff} = \beta_4 + \beta_5 Carat + \beta_6 Clarity, \quad (9.4)$$

我们可以将 $I_{1,i}^{eff}$ 和 $I_{2,i}^{eff}$ 代入方程 (9.3) 和 (9.4)，然后进入激活函数 (9.1) 和 (9.2)，得到隐藏神经元的*活性*：

$$A_{1,i}^{cl} = \frac{1}{1+e^{-(\beta_1+\beta_2 Carat+\beta_3 Clarity)}} \quad (9.5)$$
$$A_{2,i}^{cl} = \frac{1}{1+e^{-(\beta_4+\beta_5 Carat+\beta_6 Clarity)}} \quad (9.6)$$

注意，两个隐藏神经元的*有效输入* ($I_{1,i}^{eff}$ 和 $I_{2,i}^{eff}$) 被高亮显示，以使方程更易读。
