# 7.1. Global minimum of the loss is a good approximation to the PDE solution

We demonstrate that the results of the previous sections can be used to prove *a priori error estimates* for physics-informed learning, provided that one can find a global minimum of the physics-informed loss function (2.69).

We revisit the error decomposition (3.7) proposed in Section 3. There it was shown that if one can answer Question 2 in the affirmative, then, for any θ*, θ̂ ∈ Θ,

$$\mathcal{E}(θ^*) ≤ C\mathcal{E}_G(θ^*)^α$$

$$≤ C\left(\mathcal{E}_G(\hat{θ}) + 2\sup_{θ∈Θ} |\mathcal{E}_T(θ,\mathcal{S}) - \mathcal{E}_G(θ)| + \mathcal{E}_T(θ^*,\mathcal{S}) - \mathcal{E}_T(\hat{θ},\mathcal{S})\right)^α. \tag{7.1}$$

For any ε > 0, we can now let θ̂ be the parameter corresponding to the model from Question 1, and hence we find that \mathcal{E}_G(\hat{θ}) < ε if the model class is expressive enough. Next we can use the results of Section 6 to deduce a lower limit on the size of the training set \mathcal{S} (in terms of ε) such that also sup_{θ∈Θ} |\mathcal{E}_T(θ,\mathcal{S}) - \mathcal{E}_G(θ)| < ε. Finally, if we assume that θ* = θ*(\mathcal{S}) is the global minimizer of the loss function θ ↦ \mathcal{J}(θ,\mathcal{S}) = \mathcal{E}_T(θ,\mathcal{S}) (2.69), then it must hold that \mathcal{E}_T(θ*,\mathcal{S}) ≤ \mathcal{E}_T(\hat{θ},\mathcal{S}) and hence \mathcal{E}_T(θ*,\mathcal{S}) - \mathcal{E}_T(\hat{θ},\mathcal{S}) ≤ 0. As a result, we can infer from (7.1) that

$$\mathcal{E}^* ≤ C(3ε)^α. \tag{7.2}$$

Alternatively, we note that many of the *a posteriori* error bounds in Section 6 are of the form

$$\mathcal{E}(θ^*) ≤ C(\mathcal{E}_T(θ^*,\mathcal{S}) + ε)^α \tag{7.3}$$

if the training set is large enough (depending on ε). As before,

$$\mathcal{E}_T(θ^*,\mathcal{S}) ≤ \mathcal{E}_T(\hat{θ},\mathcal{S}) ≤ \mathcal{E}_G(\hat{θ}) + \sup_{θ∈Θ} |\mathcal{E}_T(θ,\mathcal{S}) - \mathcal{E}_G(θ)| ≤ 2ε, \tag{7.4}$$

such that in total we again find that \mathcal{E}^* ≤ C(3ε)^α, in agreement with (7.2).

We first demonstrate this argument for the Navier–Stokes equations, and then show a similar result for the Poisson equation in which the curse of dimensionality is overcome.
