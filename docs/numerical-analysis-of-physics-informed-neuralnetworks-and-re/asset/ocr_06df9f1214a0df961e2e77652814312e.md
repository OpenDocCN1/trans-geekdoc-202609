# Example 6.8 (scalar conservation laws).

We again consider weak PINNs for the scalar conservation laws. Recall from the stability result (Theorem 5.8) that the generalization error is given by

$$\mathcal{E}(\theta,\varphi,c) = -\int_0^1\int_0^T\big(|u_{\theta^*(\mathcal{S})}(x,t)-c|\partial_t\varphi(x,t)+Q[u_{\theta^*(\mathcal{S})}(x,t);c]\partial_x\varphi(x,t)\big)\,dx\,dt + \int_0^1|u_\theta(x,0)-u(x,0)|\,dx + \int_0^T|u_\theta(0,t)-u_\theta(1,t)|\,dt.\tag{6.12}$$

To this end, we consider the simplest case of random (Monte Carlo) quadrature and generate a set of collocation points,

$$\mathcal{S}=\{(x_i,t_i)\}_{i=1}^N\subset D\times[0,T],$$

where all $(x_i,t_i)$ are i.i.d. drawn from the uniform distribution on $D\times[0,T]$. For a fixed $\theta\in\Theta$, $\varphi\in\Phi_\epsilon$, $c\in\mathcal{C}$ and for this data set $\mathcal{S}$, we can then define the training error

$$\mathcal{E}_T(\theta,\mathcal{S},\varphi,c)= -\frac{T}{N}\sum_{i=1}^N\big(|u_\theta(x_i,t_i)-c|\partial_t\varphi(x_i,t_i)+Q[u_\theta(x_i,t_i);c]\partial_x\varphi(x_i,t_i)\big) + \frac{T}{N}\sum_{i=1}^N|u_\theta(x_i,0)-u(x_i,0)| + \frac{T}{N}\sum_{i=1}^N|u_\theta(0,t_i)-u_\theta(1,t_i)|.\tag{6.13}$$

During training, we then aim to obtain neural network parameters $\theta^*_{\mathcal{S}}$, a test function $\varphi^*_{\mathcal{S}}$ and a scalar $c^*_{\mathcal{S}}$ such that

$$\mathcal{E}_T(\theta^*_{\mathcal{S}},\mathcal{S},\varphi^*_{\mathcal{S}},c^*_{\mathcal{S}})\approx\min_{\theta\in\Theta}\max_{\varphi\in\Phi_\epsilon}\max_{c\in\mathcal{C}}\mathcal{E}_T(\theta,\mathcal{S},\varphi,c)\tag{6.14}$$

for some $\epsilon>0$. We call the resulting neural network $u^*:=u_{\theta^*_{\mathcal{S}}}$ a weak PINN (wPINN). If the network has width $W$, depth $L$ and its weights are bounded by $R$, and the parameter $\epsilon>0$ is as in Theorem 5.10, then we obtain the following theorem (De Ryck et al. 2024c, Theorem 3.9 and Corollary 3.10).

# Theorem 6.9.

Let $\mathcal{C}$ be the essential range of $u$ and let $N,L,W\in\mathbb{N}$, $R\ge\max\{1,T,|\mathcal{C}|\}$ with $L\ge2$ and $N\ge3$. Moreover, let $u_\theta:D\times[0,T]\to\mathbb{R}$, $\theta\in\Theta$, be tanh neural networks with at most $L-1$ hidden layers, width at most $W$ and weights and biases bounded by $R$. Assume that $\mathcal{E}_G$ and $\mathcal{E}_T$ are bounded by $B\ge1$. It holds with a probability of at least $1-\delta$ that

$$\mathcal{E}_G(\theta^*_{\mathcal{S}},\varphi^*_{\mathcal{S}},c^*_{\mathcal{S}})\le\mathcal{E}_T(\theta^*_{\mathcal{S}},\mathcal{S},\varphi^*_{\mathcal{S}},c^*_{\mathcal{S}})+\frac{3BLW}{\sqrt{N}}\sqrt{\ln\left(\frac{C\ln(1/\epsilon)WRN}{\epsilon^3\delta B}\right)}.\tag{6.15}$$
