Passive data sources can include computer-based data, for example geographical IP location, computer security health certificates, keyboard typing and clickstream patterns, or WAP data. Data over networks may be secured through the use of antivirus software, firewall, encryption, secure protocols, etc. However, hackers can always devise innovative ways of breaking into network systems. An intrusion detection and prevention system is placed inside the network to detect possible network intrusions and, where possible, prevent cyber attacks.
