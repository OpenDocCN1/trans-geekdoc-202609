# ## 1.3 WHITE-BOX ADVERSARIAL ATTACKS

We start with a reasonably comprehensive definition of adversarial attacks based on $\ell$-norm.

**Definition 1 (Adversarial Attack):** Let $x$ be a legitimate input data that is correctly classified as class $y$ by an ML classifier $f$. A target class $t$ such that an adversarial attack is a mapping such that the adversarial example is misclassified as class $t$ by $f$, whereas the difference between $x'$ and $x$ is trivial; i.e., for some small value $\epsilon$.

+   - $\ell_2$-norm:

measures the Euclidean distance between $x'$ and $x$.

+   - $\ell_\infty$-norm or the Chebyshev Distance:

measures the maximum absolute change to any of the coordinates of $x$.
