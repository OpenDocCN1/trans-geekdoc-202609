# 6.2.3 Policy-based Methods

In policy-based RL, we explicitly build a policy representation by mapping and keep it in memory during the learning process. In contrast, we do not store any explicit policy in value-based methods, only a value function. The policy here is implicitly derived from the value function to pick an action with the best value.
