# 10.2.3 Security of DRL

DRL has different security challenges compared with those of ML. The major difference is that DRL’s goal is to find the optimization policy from a sequence of problems, whereas most ML algorithms are trained to solve single-step prediction or cluster problems. And the training dataset for ML is a fixed distribution. On the other hand, intelligent agent in DRL is trained with a deterministic or stochastic policy.

RL problems have four parts where s stands for state, a stands for action, r stands for reward, and p stands for the transient probability that an agent is in state s, takes action a, and switches to the next state .
