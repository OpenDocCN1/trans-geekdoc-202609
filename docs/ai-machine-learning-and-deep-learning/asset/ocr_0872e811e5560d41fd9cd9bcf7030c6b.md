+   2. *Reduction in the spatial dimension:* In [5], the example of median smoothing was given, which is equivalent to pooling in convolutional neural networks. It takes the median of the n×n filter and replaces the value of the original region. Because the values of the pixels in the neighboring regions are similarly correlated, smoothing the whole map does not affect the final result but removes the noise added to it.

Although image preprocessing is effective in scenarios where the attacker is unaware of the defense method, it is almost ineffective in scenarios where the attacker is aware of the defense method. However, preprocessing is still an attractive class of defense methods because it can work with other defense methods to produce stronger defenses and can mitigate the harm of adversarial samples without knowing the target model.
