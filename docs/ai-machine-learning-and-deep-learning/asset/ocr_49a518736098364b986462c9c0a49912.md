# ### 16.3.1 Attack Model

The interest flooding attack (IFA) is a typical variation of the denial of service (DoS) attack in the NDN architecture. The adversary in IFA could generate interest requests to overuse the PIT in the NDN network within a limited short period. Therefore, IFA can block the NDN router from receiving other interest requests from all legitimate users or drop the current unsatisfied legitimate interest request in PIT due to time-out.
