# 6.4  ATTACKS ON DRL SYSTEMS

# 6.4.1  Attacks on Environment

Attack agents can add perturbations directly to the environment (see **Figure 6.6**). Chen et al. provide a common dominant adversarial example generation (CDG) method to create adversarial examples based on the environment of DRL [21]. The attack agent aims at A3C pathfinding. In typical situations, a victim agent is trained to find a path to the destination. The attack agent adds a thing into the environment and puts this thing in a place so that the victim agent takes more time or is unable to reach the final goal.
