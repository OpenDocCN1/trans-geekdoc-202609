# 1.3.7   Shadow Attack

In this subsection, we introduce a class of adversarial attacks, called “semantic” adversarial attacks, on image datasets that usually generate adversarial examples through a larger perturbation on an image in terms of -norm but that are still semantically similar to its original image. A typical example of the attack is simply a small color shift, rotation, shearing, scaling, or translation of a natural image to fool a state-of-the-art image classifier [4, 29]. The attack is successful due to differences in the way the ML model recognizes an image and the human visual recognition system. A semantic adversarial example can be formally defined next.
