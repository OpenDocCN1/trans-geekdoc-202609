# ### 5.1 INTRODUCTION

Deep reinforcement learning (DRL) systems combine the techniques of reinforcement learning (reward maximization) with the artificial neural networks of deep learning (DL) [1]. This combination allows a well trained model to operate on much more complex data sets than a typical reinforcement learning system. For example, input data from a camera or sensor stream is high dimensional and would be difficult for a traditional RL system to solve. However, a DRL system can represent the policies for these higher-dimensional choices with its neural network, enabling it to perform much better than RL or deep learning systems alone.
