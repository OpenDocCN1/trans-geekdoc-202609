# 14.3.4.1 Big Data

The first component in the big data analytics framework for cyber security is the availability of big data about cyber security. Traditional sources of big data are systems logs and vulnerability scans [4]. However, sources of big data about cyber security have extended to include computer-based data, mobile-based data, physical data of users, human resources data, credentials, one-time passwords, digital certificates, biometrics, and social media data [21]. Some authors identify the sources of big data about cyber security as business mail, access control systems, CRM systems and human resources systems, a number of pullers in linked data networks, intranet/internet and IIoT/IoT, collectors and aggregators in social media networks, and external news tapes [52]. Big data about cyber security should be imported from multiple sources to ensure effectiveness in detection and prediction of possible threats [5].
