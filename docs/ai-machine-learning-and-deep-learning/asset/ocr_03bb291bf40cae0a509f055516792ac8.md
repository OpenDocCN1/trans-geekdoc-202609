We need to deal with several security issues. Looking back to sections 6.3–6.4 on adversarial ML attacks, we see an attack trying to exploit numerous adversarial examples with several input requests. Therefore, we should limit probing numbers from the exact IP location in various attack scenarios within a fixed time. In this case, it certainly costs the attack agent more probing time to discover adversarial examples. Second, in the man in the middle attack, the attack agent can manipulate any intercepted data and resend it to the victim agent at the destination system. To defend against this attack, we need to ensure that the data source and the communication channel we observe are fully trusted.
