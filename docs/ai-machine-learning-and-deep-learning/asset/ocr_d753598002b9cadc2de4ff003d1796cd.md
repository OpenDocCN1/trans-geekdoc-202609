Furthermore, AutoAttack can run entirely without predefined user inputs across benchmark datasets, models, and norms. Therefore, it can provide a reliable, quick, and parameter-free evaluation tool when a researcher develops adversarial defenses [24]. We will introduce fast adaptive boundary attacks in section 1.3.5 and square attacks in section 1.4.4.
