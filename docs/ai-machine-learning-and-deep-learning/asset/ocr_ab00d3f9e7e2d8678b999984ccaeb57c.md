# Definition 3: The share c of instances satisfying the rule that lead to the same prediction can be described by

The minimum of this share is called the confidence threshold c_t [27] and will be set to c_t = 0.95.

The higher the confidence threshold, the higher the probability that another set of words will satisfy this rule and lead to the same prediction. This means that the respective anchor candidate is more stable in guaranteeing a specific prediction the higher the threshold.

These functionalities of the anchor explanations were implemented with the help of the alibi packages for python. Just like the output of LIME, this algorithm outputs the anchor, i.e., the set of words that characterize the classification of this email. It also provides the emails with the word replacements that led to the classification. The implementation was done with the default settings of this algorithm, except that the anchor candidate was replaced by UNK with a certain probability.
