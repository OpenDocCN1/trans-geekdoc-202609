# 14.4.2 Support Vector Machine

A support vector machine is a classification of the artificial intelligence and machine learning algorithm with a set containing points of two types in an X-dimensional place. A support vector machine generates a (X − 1) dimensional hyperplane for separating these points into two or more groups using either linear kernel or nonlinear kernel functions [17].
