# 14.4.5 Random Forest Classifier

The random forest classifier is an ensemble algorithm used for both classification and regression problems. It creates a set of decision trees from a randomly selected subset of the training set [17]. It then makes a decision by aggregating the votes from individual decision trees to decide the final class of an instance in the classification problem [103]. The tree with the higher error rates is given a low weight in comparison to the other trees, increasing the impact of trees with low error rates.
