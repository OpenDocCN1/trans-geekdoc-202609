A total of 591 novel oxide perovskite and halide perovskite compounds are found using the ML model. The final list of compounds comprises 247 oxide perovskite, 19 fluoride perovskite, 132 chloride perovskite, and 190 bromide perovskite. For battery application, the charge capacity [60] is estimated using the formula given by

```
$Q = nF/(3600 * Mw)mAhg^{-1}$
```

where $F$ is the *Faraday constant*, $n$ is the number of charge carriers and $Mw$ is the molecular weight of perovskite materials to be used in electrodes. Consider the following chemical equation:

```
$LiTaO_3 \longrightarrow Li^+ + TaO_3 + 1e^-$
```

The value of n will be (1Li+ ) 1 and molecular weight of LiTaO3 is 235.89

gmol$^{-1}$. Hence using the above equation, the charge capacity will be 113.62 mAhg$^{-1}$.

We prepared a separate data frame to estimate the charge capacity of final compounds. The highest charge capacity is found in a fluoride perovskite in all halide perovskite.
