using decision trees. The RFC method combines the votes from different decision trees from a randomly selected subset of the training dataset. The final prediction of the model is decided by a class with maximum votes [49].

The hyper-parameters in the random forest classifier (RFC) are (a) *number of decision trees* and (b) *tree depth* at each splitting node. The Scikit-learn package [45] is used to implement the random forest classifier. The entire dataset is split into a training and test set of 80 and 20, respectively for both stability and formability classifications. It means the model is trained using 80 % of the randomly chosen dataset and tested using the remaining 20 % of the dataset. The robustness of these models have also been tested by verifying the test results. Before applying the RFC as an ML model, we normalize all the features to ensure zero mean and set standard deviation equal to unity. The number of estimators or trees (n-estimators) for formability and stability classification models is 29. The maximum tree depth (max-depth) is 22 for formability classification and 19 for stability classification. Both of the RFC models are studied using 34 features comprised of 30 atom-specific features and 4 geometric features.

These hyper-parameters for both classifications are tuned using 5-fold cross-validation (CV) to enhance the reliability of the models. In the 5-fold CV, the input dataset is divided into 5 different subsets of the same size. Further, four sets are used for training the said model and the remaining one is to test the results. The final performance of the ML model is extracted by averaging the test results. In this work, the accuracy of the formability classification model is 0.946, whereas the accuracy of the stability classification model is 0.84. After successfully training and testing the model, both the models are applied simultaneously on the dataset of new compounds containing oxides and halides to predict new formable and stable perovskite.

The Zunger’s pseudopotential radius is the sum of radii of s-orbitals and p-orbitals [24]. A summary of the formability classification model in the form of a confusion matrix (CM) is shown in Figure 4a as explained in [50]. The number of true values and false values predictions are summarized in the matrix form. The diagonal elements of the matrix (CM11 and CM22) are true negative (TN) and true positive (TP), whereas off-diagonal elements (CM12 and CM21) are false negative (FN) and false positive (FP). Furthermore, the precision and accuracy of the model can be estimated using the values of elements in the CM. A model’s prediction capability of predicting the positive class or formable class can be analyzed by precision. It can be estimated by the ratio of TP to the sum of TP and FP (i.e. Precision = TP/(TP + FP)). The accuracy of a model helps analyze the predicting capability with correct classifications. It can be estimated as \(Accuracy = (TP + TN)/(TP + FN + FP + FN)\). The values of precision and accuracy are 0.9380 and 0.9465, respectively in the formability classification model. Talapatra et al. [24] applied the RFC on 1505 single and double oxide perovskite for formability classification and it was found that the precision and accuracy values were 0.9344 and 0.9401, respectively. The classifier has an AUC of 0.869 which is reasonably good.
