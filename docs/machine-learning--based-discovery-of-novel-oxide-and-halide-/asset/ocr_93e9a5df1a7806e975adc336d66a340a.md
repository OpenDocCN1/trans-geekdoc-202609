# 3.3. Gaussian process classification

To validate the classifier model discussed in the previous section, an alternative approach is used to test the reliability of the computational approach and results. In this section, a well-accepted and popular Gaussian Process Classifier (GPC) has been employed for the classification of formability and stability.

GPC employs Gaussian Processes (GPs) [51,52] to construct a probabilistic classification model. The basic concept is to model the latent function (f(x) ~ $\mathcal{KP}(0, k(x, x'))$)[52] values with GP and then apply a link function [52] to map these latent values into class probabilities [53]. The GP can be defined as
f(x) ~ $\mathcal{KP}(m(x), k(x, x')),$ (7)

where m(x) is the mean function which is generally assumed to be 0 and k(x, x’) is the covariance function (or kernel function that defines the relationship between two different points in the input space.) for any finite subset x = {x1, x2, ..., xn} $\in$ X. GPC estimates the feature importance indirectly by examining the learned parameters of the kernel function. In the Gaussian Process model, the kernel function captures the relationship among the data points in the feature space. The features that contribute more to these relationships are considered. To make a fair verification of the RFC model, the RFC and GPC are evaluated on the same set of data. The train-test split remains the same (i.e. 80 and 20) in both classifier models for which the same random state (i.e. 46) is used. Further, RFE technique is also used to remove the features of the lowest weights in the GPC model to ensure consistent and potentially more stable feature selection. These hyperparameters for both classifications are tuned using 5-fold cross-validation (CV) to enhance the reliability of the models. In the 5-fold CV, the input dataset is divided into 5 different subsets of the same size. Further, four sets are used for training the said model and the remaining one is to test the results. The final performance of the ML model is extracted by averaging the test results. In this work, the accuracy of the formability classification model is 0.946, whereas the accuracy of the stability classification model is 0.84. After successfully training and testing the model, both the models are applied simultaneously on the dataset of new compounds containing oxides and halides to predict new formable and stable perovskite.

Figure 4b shows feature importance obtained for formability classification of oxide and halide perovskite as a result of GPC followed by RFE. The t and $\mu$ are the most important features in the GPC formability model also. Further, the other topmost features belong to atom ‘A’ and ‘B’ symmetric features which are very much similar to the RFC formability model with slight changes in the order of feature importance. In Figure 4b, the confusion matrix is also shown and the accuracy of GPC formability model is found as 0.938 which is very close to the accuracy of the formability model using RFC i.e. 0.946. Figure 4d shows feature importance’ obtained for stability classification using GPC. In stability classification t again is the most important feature in the list. The other top features are also consistence with the stability model using RFC with

a slight change in the order of the feature importance. The confusion matrix is also shown in Figure 4d and the accuracy of the stability model using GPC is found as 0.838 which is very close to the accuracy of the stability model using RFC.

The local explanations of the training dataset for formability and stability features are extracted as well and global explanations of feature importance are also extracted for both. # 4.2. Permutation feature importance using random forests classifier

For any classification model, it is very important to measure the predictive values of features. It provides insight into the relationship between the features and the target. Permutation Feature Importance (PFI) along with Tree Feature Importance (TFI) is used within the RFC model as a model examination technique to extract the importance of each feature used in the database. In the PFI method, the values of a feature are shuffled randomly which breaks the relation between the target and features. This leads to a drop in the accuracy and it is measured by the current model. Therefore the model could also suffer as there may be correlated features. To handle multicollinearity, the hierarchical clustering is performed on the features using Spearman correlation Eq. (6) [56]. The Spearman correlation can be defined with Pearson's correlation coefficient between the ranked features.

Further hierarchical clustering of the features is implemented using Ward's minimum variance [37]. The clusters having minimum variance within the cluster are paired after merging. The change in the variance between the centers of clusters is measured as Euclidean distance. After the clustering of all the features, the plot of Euclidean distance with respect to the features in the form of a distance matrix is known as dendrogram [57]. To optimize the accuracy for a given feature, a threshold distance is chosen while iterating the cluster distances. In this process, highly correlated features from the dataset are filtered out. For a better understanding of the effect of PFI on formability, the partial dependencies are also plotted. Open-source SciPy tools [58] are used to implement these methods in the present work.
