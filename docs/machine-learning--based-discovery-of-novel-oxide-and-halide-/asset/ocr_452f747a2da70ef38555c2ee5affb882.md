# 2.2. Features selection

The preparation of formability and stability databases of oxide, fluoride, and halide perovskites are composed of geometric features and atom-specific features. The features in the database are composed of features of atoms associated with perovskites e.g. atom A, B and X in single perovskite and atoms A, A', B, B' and X in double perovskite. Pilania et al. [43,44] proposed for double perovskite that a given property P can be estimated using the symmetric compound feature (\(P_A+ = (P_A + P_{A'})/2\)) and anti-symmetric compound feature (\(P_A - = (P_A - P_{A'})/2\)), where \(P_A\) and \(P_{A'}\) is the properties of atom A and A', respectively.
