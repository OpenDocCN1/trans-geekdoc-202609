### 2.1. Formability and stability databases

Formability training dataset contains 1962 experimentally known oxides, fluoride, and halide perovskites of the form ABO3, AA'BB'O6 and AA'BB'X6, respectively. The halide X is composed of Cl and Br in this dataset and it is composed of 1453 perovskites and 509 non-perovskites. The dataset is prepared based on literature like Zhang et al. [34], Balacharan et al. [38], Vasala et al. [39], Talapatra et al. [24], Li et al. [40], Li et al. [41] and an existing database like Inorganic Crystal Structure Database (ICSD). The stability training database is composed of all possible compositions i.e. ABO3, AA'BB'O6, AA'B2O6 and ABX3, AA'BB'X6, AA'B2X6, A2BB'X6 compounds. The total number of oxides, fluoride, and halides is 4075 compounds. Of these, 2053 compounds are thermodynamically stable and 2022 compounds are thermodynamically unstable. Figure 2 presents the distribution of single and double perovskites that comprise oxide perovskite, fluoride perovskite, chloride perovskite, and bromide perovskite. Figures 2a and 2b show the distributions of various types of compounds within the formability database and stability database of perovskite materials, respectively. In formability and stability distribution, the domination of oxide perovskite can be seen in this literature. The dataset is prepared from Materials Project Application Programming Interface (Materials API) by setting Energy above hull (\(\Delta E_h\)) 50 meV/atom for each compound. Wu et al. [42] found that approximately 80 % of compounds in ICSD had Energy above hull values less than 36 meV/atom. So for better analysis, the \(\Delta E_h\) value equal to 50 meV/atom is opted in the present work.

### 2.2. Features selection

The preparation of formability and stability databases of oxide, fluoride, and halide perovskites are composed of geometric features and atom-specific features. The features in the database are composed of features of atoms associated with perovskites e.g. atom A, B and X in single perovskite and atoms A, A', B, B' and X in double perovskite. Pilania et al. [43,44] proposed for double perovskite that a given property P can be estimated using the symmetric compound feature (\(P_A+ = (P_A + P_{A'})/2\)) and anti-symmetric compound feature (\(P_A - = (P_A - P_{A'})/2\)), where \(P_A\) and \(P_{A'}\) is the properties of atom A and A', respectively. A large number of geometric and chemical features are used to train both models. ## 3. ML classification: technical details

### 3.1. Using random forest classifier

In machine learning, classification is a process of categorizing a dataset based on a given input dataset. It requires a training dataset of multiple inputs and outputs for learning. In this work, the prediction of stability and formability of new compounds is performed using the RFC model. Random forest (also known as random decision forest) is a supervised ML technique used for regression analysis and classification by using decision trees. The RFC method combines the votes from different decision trees from a randomly selected subset of the training dataset. The final prediction of the model is decided by a class with maximum votes [49].

![](img/0947dcc86f17166636a5ebab0393245e_3_0.png)

Fig. 3. The eight very basic features defining Perovskites (a) Geometric features and (b) Chemical features.

The hyper-parameters in the random forest classifier (RFC) are (a) *number of decision trees* and (b) *tree depth* at each splitting node. The Scikit-learn package [45] is used to implement the random forest classifier. The entire dataset is split into a training and test set of 80 and 20, respectively for both stability and formability classifications. It means the model is trained using 80 % of the randomly chosen dataset and tested using the remaining 20 % of the dataset. The robustness of these models have also been tested by verifying the test results. Before applying the RFC as an ML model, we normalize all the features to ensure zero mean and set standard deviation equal to unity. The number of estimators or trees (n-estimators) for formability and stability classification models is 29. The maximum tree depth (max-depth) is 22 for formability classification and 19 for stability classification. Both of the RFC models are studied using 34 features comprised of 30 atom-specific features and 4 geometric features.

These hyper-parameters for both classifications are tuned using 5-fold cross-validation (CV) to enhance the reliability of the models. In the 5-fold CV, the input dataset is divided into 5 different subsets of the same size. Further, four sets are used for training the said model and the remaining one is to test the results. The final performance of the ML model is extracted by averaging the test results. In this work, the accuracy of the formability classification model is 0.946, whereas the accuracy of the stability classification model is 0.84. After successfully training and testing the model, both the models are applied simultaneously on the dataset of new compounds containing oxides and halides to predict new formable and stable perovskite.

### 3.2. Formability and stability classification of perovskite

Figure 4a shows feature importance obtained for formability classification of oxide and halide perovskite as a result of RFC followed by RFE. The tolerance factor (t) and octahedral factor (\(\mu\)) are the most important features in the list. The atom ‘A’ symmetric key features are \(EA_A, IE_A, Z^A_r, LUMO_A, IX_A\) and atom ‘B’ symmetric key features are \(Z^B_r, IX_B, LUMO_B, HOMO_B, IE_B, EA_B\) that define the compounds to be formable or not formable as perovskite. The Zunger’s pseudopotential radius is the sum of radii of s-orbitals and p-orbitals [24]. A summary of the formability classification model in the form of a confusion matrix (CM) is shown in Figure 4a as explained in [50]. The number of true values and false values predictions are summarized in the matrix form. The diagonal elements of the matrix (CM11 and CM22) are true negative (TN) and true positive (TP), whereas off-diagonal elements (CM12 and CM21) are false negative (FN) and false positive (FP). Furthermore, the precision and accuracy of the model can be estimated using the values of elements in the CM. A model’s prediction capability of predicting the positive class or formable class can be analyzed by precision. It can be estimated by the ratio of TP to the sum of TP and FP (i.e. Precision = TP/(TP + FP)). The accuracy of a model helps analyze the predicting capability with correct classifications. It can be estimated as \(Accuracy = (TP + TN)/(TP + FN + FP + FN)\). The values of precision and accuracy are 0.9380 and 0.9465, respectively in the formability classification model. Talapatra et al. [24] applied the RFC on 1505 single and double oxide perovskite for formability classification and it was found that the precision and accuracy values were 0.9344 and 0.9401, respectively. The classifier has an AUC of 0.869 which is reasonably good.
