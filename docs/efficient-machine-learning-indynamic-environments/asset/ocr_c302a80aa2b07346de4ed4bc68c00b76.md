# ## A.2 Proofs of Main Theorems

Here, we provide a proof of Theorem 2.1, which is restated below:

**Theorem.** Suppose the class $\mathcal{F}$ satisfies that for all $f \in \mathcal{F}$, $\|f - g\|_\infty \le G_\infty$. Let $F = \{f_t\}$ be the ensemble after $T$ rounds of Algorithm 1, with the final output $F_t = \frac{1}{T} \sum_{t=1}^T f_t$. If $f_t$ satisfies Equation (2.7) for all $t \le T$ then for $T \ge \ln 2N$ and

\[
\eta = \frac{1}{G_\infty} \sqrt{\frac{\ln 2N}{T}}
\]

we have for all j

\[
\|F_{t,j} - g_j\|_\infty \le G_\infty \sqrt{\frac{\ln 2N}{T}} - \frac{1}{T} \sum_{t=1}^T \gamma_t(j)
\]

where $F_{t,j}$ and $g_j$ are the $j^{th}$ coordinates of the functions $F_t$ and $g$ respectively.

_Proof._ For simplicity, assume that $f_t$ and $g$ are scalar valued functions, since the proof goes through coordinate-wise. At each time, define the edge of the weak learning algorithm to be

\[
\gamma_t = \sum_i K_t^+(i)(f_t(x_i) - g(x_i)) + \sum_i K_t^-(i)(g(x_i) - f_t(x_i))
\]

Let $Z_t$ denote the normalizing constant at time $t$, that is,

\[
Z_t = \sum_i K_t^+(i) \exp \left( -\eta (f_t(x_i) - g(x_i)) \right) + K_t^-(i) \exp \left( \eta (f_t(x_i) - g(x_i)) \right)
\]

From the update rule,

\[
\begin{aligned}
K_{T+1}^+(i) &= \frac{K_T^+(i)e^{\eta(f_T(x_i)-g(x_i))}}{Z_T} \\
&= \frac{K_1^+(i)\exp \left( -\eta \sum_{t=1}^T (f_t(x_i)-g(x_i))_j \right)}{\prod_{t=1}^T Z_t} \\
&= \frac{K_1^+(i)\exp \left( -\eta T (F_T(x_i)-g(x_i)) \right)}{\prod_{t=1}^T Z_t}
\end{aligned}
\]
