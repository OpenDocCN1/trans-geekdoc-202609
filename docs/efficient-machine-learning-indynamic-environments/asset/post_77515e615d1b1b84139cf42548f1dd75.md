**Figure C.5:** Change in solution quality (y-axis) vs time taken (x-axis, 99th percentile values shown) to find a solution to large-scale resource-allocation problems in three domains using three approaches – (1) _LP/ILP\*_ solves the (integer) linear program formulation using commercial LP/ILP solvers [154, 202], (2) _POP_ partitions the resource and request sets [137], then solves the partitioned problems using the same commercial LP/ILP solvers in parallel, and (3) COPTER formulates allocation problems as _slowly evolving_ linear programs (see Section 4.3) and reuses computational effort from solving prior problems to speedup solver runtimes.
