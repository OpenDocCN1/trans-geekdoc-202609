# Chapter 2

# Constructing Elastic ML Models

Many real-world ML inference applications face resource budgets that fluctuate unpredictably from call to call. This chapter studies ML inference under such arbitrary environments and introduces elastic models—models that can trade inference cost for accuracy at runtime. We develop B-DISTIL, an algorithm that constructs an elastic model from a pretrained teacher by progressive ensemble distillation, and we demonstrate its benefits across vision, speech, and sensor tasks. This chapter builds on the techniques developed by Dennis, Shetty, Sevekari, Koishida, and Smith [166].

# 2.1 Elastic Models

A conventional training pipeline produces a rigid network: given a fixed input dimension, the model always incurs the same inference cost. On ImageNet, the smallest ResNet available to us consumes only 0.15 GFLOPs but answers fewer than 12% of queries correctly (Figure 2.1). A large network delivers 83.4% top-1 accuracy yet demands 30.4 GFLOPs. Static selection therefore forces a painful choice between budget compliance and predictive quality.

Elastic models aim to escape that trade-off. We define an elastic model as a predictor f(x, κ), where x is the input and κ is the configurable elasticity value that determines where on the accuracy-cost Pareto frontier this model lies. Given a fixed input x and a resource budget τ, one can now aim to find the elasticity parameter κ corresponding to the best-effort prediction attainable under cost τ.

Note that the inference cost can be defined in various ways, for example— inference latency, floating-point operations (FLOPs), or total energy consumed. By being able to dynamically trade inference costs, elastic models offer a way to break free from static tuning.
