and similarly

\(K_{T+1}^-(i) = \frac{K_1^-(i) \exp(\eta T (F_T(x_i) - g(x_i))}{\prod_{t=1}^T Z_t}\)

First, bound \(\ln(Z_t)\):

\(\begin{aligned} \ln(Z_t) &= \ln \left( \sum_i K_t^+(i) \exp(-\eta(f_t(x_i) - g(x_i))) + \sum_i K_t^-(i) \exp(\eta(f_t(x_i) - g(x_i))) \right) \\ \le \ln \Bigg( \sum_i K_t^+(i) \Big( 1 - \eta(f_t(x_i) - g(x_i)) + \eta^2(f_t(x_i) - g(x_i))^2 \Big) \\ &+ \sum_i K_t^-(i) \Big( 1 + \eta(f_t(x_i) - g(x_i)) + \eta^2(f_t(x_i) - g(x_i))^2 \Big) \Bigg) \\ \le \ln \Bigg( 1 - \eta \sum_i K_t^+(i)(f_t(x_i) - g(x_i)) + \eta \sum_i K_t^-(i)(f_t(x_i) - g(x_i)) + \eta^2 G_\infty^2 \Bigg) \\ \le -\eta \gamma_t + \eta^2 G_\infty^2 \end{aligned}\)

where the second step follows from the identity \(\exp(x) \le 1 + x + x^2\) for \(x \le 1\), provided that \(\eta \le \frac{1}{G_\infty}\). This gives a bound on regression error after \(T\) rounds:

\(\begin{aligned} -\eta T (F_T(x_i) - g(x_i)) &= \ln(K_{T+1}^+(i)) - \ln(K_1^+(i)) + \sum_{t=1}^T \ln(Z_t) \\ \le \ln \left( \frac{K_{T+1}^+(i)}{K_1^+(i)} \right) + \sum_{t=1}^T -\eta \gamma_t + \eta^2 G_\infty^2 \\ = \ln \left( \frac{K_{T+1}^+(i)}{K_1^+(i)} \right) + \eta^2 T G_\infty^2 - \eta \sum_{t=1}^T \gamma_t \\ \le \ln 2N + \eta^2 T G_\infty^2 - \eta \sum_{t=1}^T \gamma_t , \end{aligned}\)

where the last bound follows since \(K_1^+ = \frac{1}{2N}\) and \(K_{T+1}^+ \le 1\). Similarly, observe the bound

\(\eta T (F_T(x_i) - g(x_i)) \le \ln 2N + \eta^2 T G_\infty^2 - \eta \sum_{t=1}^T \gamma_t\)

Combining the two equations,

\(\sup_i |F_T(x_i) - g(x_i)| = \|F_T - g\|_\infty \le \frac{\ln 2N}{\eta T} + \eta G_\infty^2 - \frac{1}{T} \sum_{t=1}^T \gamma_t .\)
