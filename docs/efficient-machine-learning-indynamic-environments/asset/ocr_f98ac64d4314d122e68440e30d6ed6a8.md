Let us choose \(\eta = \frac{1}{G_\infty}\sqrt{\frac{\ln 2N}{T}}\) to minimize this expression and obtain the following bound on regression error:

\(\|F_t - g\|_\infty \le -\frac{1}{T} \sum_{t=1}^T \gamma_t + G_\infty\sqrt{\frac{\ln 2N}{T}}.\)

which is exactly Equation (2.8). Note that the value of \(\eta\) only satisfies the condition \(\eta \le \frac{1}{G_\infty}\) when \(T \ge \ln 2N\), which is the time horizon after which the bound holds. \(\square\)

Now, we provide a proof of Theorem 2.2 which follows from the VC dimension bound and Theorem 2.1. Before we begin, we set up some notation. Given a function \(f\), distribution \(\mathcal{D}\) over space \(\mathcal{X} \times \mathcal{Y}\) where \(\mathcal{X}\) is the input space and \(\mathcal{Y}\) is the label space, and data \(D\) consisting of \(N\) iid samples \((x, y) \sim \mathcal{D}\), we define

\(\widehat{\text{err}}(f) = \Pr_{(x,y)\sim D} [\text{sign}(F_T(x) \neq y)] \quad \text{err}(f) = \Pr_{(x,y)\sim \mathcal{D}} [\text{sign}(F_T(x) \neq y)]\)

# Theorem (Excess Risk). Suppose data \(D\) contains of \(N\) iid samples from distribution \(\mathcal{D}\). Suppose that the function \(g\) has large margin on data \(D\), that is

\(\Pr_{x\sim D} [|g(x)| < \epsilon] < \mu\)

Further, suppose that the class \(\mathcal{C}_T\) has VC dimension \(d\), then for

\(T \ge \frac{4G_\infty^2 \ln 2N}{\epsilon^2},\)

with probability \(1 - \delta\) over the draws of data \(D\), the generalization error of the ensemble \(F_T\) obtained after \(T\) round of Algorithm 1 is bounded by

\(\text{err}(F_T) \le \widehat{\text{err}}(g) + O \left( \sqrt{\frac{d \ln(N/d) + \ln(1/\delta)}{N}} \right) + \mu\)

Proof. Recall the following probability bound Schapire and Freund [36, theorem 2.5] which follows Sauer's Lemma:

\(\text{Pr} [\exists f \in \mathcal{C}_T : \text{err}(f) \ge \widehat{\text{err}}(f) + \epsilon] \le 8 \left( \frac{me}{d} \right)^d e^{-m\epsilon^2/32}\)

which holds whenever \(|D| = N \ge d\). It follows that with probability \(1 - \delta\) over the samples, we have for all \(f \in \mathcal{C}_T\)

\(\text{err}(f) \le \widehat{\text{err}}(f) + O \left( \sqrt{\frac{d \ln(N/d) + \ln(1/\delta)}{N}} \right)\) (A.5)
