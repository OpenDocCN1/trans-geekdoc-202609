# Chapter 5

# Gradual-Evolution Beyond Machine Learning

Building on the continual-optimization perspective introduced in Chapter 4, this chapter explores benign evolution in non-ML resource-allocation tasks. We examine two large-scale, highly practical problems—(i) shard load balancing and (ii) wide-area-network (WAN) traffic engineering—and show how the same structure of gradual evolution is exploited by COPTER outside the ML domain. The material draws on work by Jayaram Subramanya, Dennis, Smith, and Ganger [203].

# 5.1 Shard Load-Balancing

The shard load-balancing problem frequently arises in the operation of elastic database systems [29, 41, 43] where replicas of data shards are shuffled around a fixed pool of servers to ensure a consistent load across the server fleet.
