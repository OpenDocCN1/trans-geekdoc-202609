## 5.4 结论

本章展示了 COPTER 如何将机器学习工作流之外的优化扩展到另外两项大规模任务：分片负载均衡和广域网流量工程。与第 4 章一起，这些结果凸显了第二部分的核心观点：许多资源分配问题最好被视为缓慢演进的实例序列，因此天然适合持续优化。

在三个领域——GPU 集群调度、分片负载均衡和广域网流量工程中——COPTER 提供的分配速度比最先进的、与轮次无关的求解器快 10–100×，且解决方案质量几乎无损失。
