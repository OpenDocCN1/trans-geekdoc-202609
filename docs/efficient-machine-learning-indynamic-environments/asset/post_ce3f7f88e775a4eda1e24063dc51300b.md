
## Algorithm 1 B-DISTIL: Main algorithm

```
Require: Target teacher model g, total number of rounds T, data {(x_i, y_i)}_{i=1}^N, learning rate eta, model classes ordered on inference cost {F_m}_{m=1}^M
1: K_t^+(i, j), K_t^-(i, j) <- 1/(2N), 1/(2N) forall(i, j)
2: F, r, t <- empty, 1, 1
3: while r < R and t < T do
4:   f_t = FIND-WL(K_t^+, K_t^-, F_r)
5:   if f_t is NONE then
6:     r <- r + 1
7:     continue
8:   With l := f_t - g, update K_t^+, K_t^-. forall(i, j)
     K_{t+1}^+(i, j) <- K_t^+(i, j) exp(-eta * l(x_i)_j)   (2.4)
     K_{t+1}^-(i, j) <- K_t^-(i, j) exp(eta * l(x_i)_j)    (2.5)
9:   Normalize K_t^+, K_t^-.
10: F, t <- F U {f_t}, t + 1
11: Return 1/|F| sum_{i=1}^{|F|} f_i
```

Our procedure iteratively searches for weak learners (weak gradients) that satisfy Equation (2.3) with respect to the target g within the class F_m. Whenever we find such a learner we add it to our ensemble. As the procedure continues, the loss of the ensemble converges in-sample to the minimax value in Equation (2.1) (Theorem 2.1) and it enjoys a bounded excess risk (Theorem 2.2). Although Equation (2.3) is a seemingly easier notion than the full optimization, in many problems of interest even this is challenging. In fact, in the multi-label setting we discuss here, one of the main algorithmic challenges is to construct an algorithm that can reliably find low-cost weak gradients/learners (see Section 2.2.3).

## 2.2.2 B-DISTIL Algorithm

Concretely, at each round t B-DISTIL maintains matrices K_t^+ in R^{N x L} and K_t^- in R^{N x L} of values for N data points and L labels, such that for all (i, j) in [N] x [L], 0 <= K_t^+(i, j), K_t^-(i, j) <= 1. Moreover, sum_i K_t^+(i, j) + K_t^-(i, j) = 1. The elements K_t^+(i, j) and K_t^-(i, j) serve as weights on the residuals f_{t-1}(x) - g(x) and g(x) - f_{t-1}(x), respectively, up-weighting large deviations from the teacher model. Our specific notion of weak learners used in this setting is formalized in Definition 2.1, which is a natural extension of the standard weak learning assumption in the boosting literature.

Definition 2.1 (Weak learning condition). Given a dataset {(x_i, y_i)}_{i=1}^N, a target function $g : \mathcal{X} \to \mathbb{R}^L$ and probability matrices $K_t^+, K_t^-$, a function $f_t : \mathcal{X} \to \mathbb{R}^L$ is said to satisfy the weak learning condition with respect to $g, \forall j$, if the following sum is strictly positive:

\(\sum_i K_t^+(i,j)(f_t(x_i) - g(x_i))_j + K_t^-(i,j)(g(x_i) - f_t(x_i))_j.\)

At each round $t$, with the current probability matrices $K_t^-, K_t^+$, B-DISTIL performs two steps: first, it invokes a subroutine FIND-WL (discussed below) that attempts to find a classifier $f_t \in \mathcal{F}_r$ satisfying the weak learning condition (Definition 2.1). If such a predictor is found, we add it to the ensemble and the algorithm proceeds to the second step, updating the probability matrices $K_t^-, K_t^+$ based on errors made by $f_t$. This is similar in spirit to boosting algorithms such as AdaBoost [36] for binary classification. If no such predictor can be found, we invoke the Algorithm 2 subroutine with the next model class, $\mathcal{F}_{r+1}$. This procedure is repeated until a weak learner is found or we have no further classes to search in.

```
Algorithm 2 FIND-WL
Require: Probability matrices $K^+, K^-$, model class $\mathcal{F}$ parameterized by $\theta \in \Theta$, hyperparameters for SGD
1: Obtain $\{\mathcal{F}_r\}_{r=1}^R$ by expanding $\mathcal{F}$ (see below).
2: **for** $\mathcal{F}' \in \{\mathcal{F}_r\}_{r=1}^R$ **do**
3:   Initialize parameter $f_{\theta_0} \in \mathcal{F}'$.
4:   **for** $i \in \{1, \dots, \text{max-search}\}$ **do**
5:     Randomly initialize $f_{\theta_i}$.
6:     Run SGD to solve Equation (2.6).
7:     **if** $f_{\theta_i}$ is a weak learner **then**
8:       **Return** $f_{\theta_i}$
9:   **Return** NONE
```

## 2.2.3 Finding Weak Learners

The main difficulty in provably approximating the teacher model in this setting is finding a *single*, resource-efficient, tiny learner, that at each round $t$, simultaneously satisfies the weak learning condition for all labels $j$. Existing boosting methods for classification treat multi-class settings ($L > 1$) as $L$ instances of the binary classification problem (one-vs-all) [36]. They typically choose $L$ different weak learners for each instance, which is unsuitable for resource-efficient on-device inference. The difficulty is further increased by the capacity gap between the student and teacher models considered here for distillation. Thus, along with controlling the temperature for distillation, we employ two additional strategies:

- we use a regularizer as part of the objective FIND-WL solves to promote weak learning and,
- we let current weak-learning candidates reuse a limited number of stored activation outputs of previously evaluated models to increase their expressivity.

### Log-barrier regularizer.

To find a weak learner, the FIND-WL method minimizes the sum of two loss terms using stochastic gradient descent. The first is standard binary/multi-class cross-entropy distillation loss [50], with temperature smoothing. The second term corresponds to the weak learning condition, and is defined as:

```
-\frac{1}{\beta} \sum_{i,j} I_{ij}^+ \log \left( 1 + \frac{l(x_i)_j}{2B} \right) + (1 - I_{ij}^+) \log \left( 1 - \frac{l(x_i)_j}{2B} \right)
```

Here $I_{ij}^+ := I[K_t^+(i,j) > K_t^-(i,j)]$, $B$ is an upper bound on the magnitude of the logits, and $l(x_i) := f(x_i) - g(x_i)$. To see the intuition behind Equation (2.6), assume the following holds: $\forall(i,j)$

```
$(K_t^+(i,j) - K_t^-(i,j))(f(x_i) - g(x_i))_j > 0.$
```

Summing over all $x_i$, we can see that this is sufficient for $f$ to be a weak learner with respect to $g$. Equation (2.6) is a soft log-barrier version of the weak learning condition that penalizes those $(i,j)$ for which Equation (2.7) does not hold. The relative importance of the regularization objective can be tuned through $\beta$, encouraging $f_t$ to be a weak learner potentially at the expense of classification performance.

### Intermediate layer connections and profiling.

As discussed in Section 2, distillation onto a linear combination of low-capacity student models often offers no better performance than that of any single model in the ensemble trained independently. For boosting, empirically, once the first weak learner has been found in some class $\mathcal{F}_m$ of low-capacity deep networks, it is often impossible to find a weak learner for the reweighted objective from the same class $\mathcal{F}_m$. To work around this we let the class of weak learners at round $t$ also include functions that depend on the output of intermediate layers of previous weak learners [118].

As a concrete example, consider a deep fully connected network with $U$ layers, parameterized as $f = W \phi_{1:U}$. Here $\phi_{1:u}$ can be thought of as a feature transform on $x$ using the first $u$ layers into $\mathbb{R}^{d_u}$ and $W \in R^{d_U \times L}$ is a linear transform. With two-layer fully connected base model class $\mathcal{F}_0 := \{W^{(0)} \phi_{1:2}^{(0)} \mid W^{(0)} \in \mathbb{R}^{L \times d_2}\}$ (dropping subscript $m$ for simplicity), we define:

```
$\mathcal{F}_r = \{W^{(r)} \phi_{1:2}^{(r)}(\text{id} + \phi_{1:2}^{(r-1)})\} \quad \text{and,} \quad \mathcal{F}'_r = \{W^{(r)} \phi_2^{(r)}(\text{id} + \phi_1^{(r)} + \phi_1^{(r-1)})\},$
```

with $\text{id}(x) := x$. Observe how $\{\mathcal{F}_r\}$ and $\{\mathcal{F}'_r\}$ define a variant of residual connection-based networks [65] and the classes of functions $\{\mathcal{F}_r\}$ (and $\{\mathcal{F}'_r\}$) increase in capacity with r. Moreover, when evaluating sequentially the inference cost of a model from $\mathcal{F}_r$ is roughly equal to that of $\mathcal{F}$. Each subsequent evaluation *reuses* stored activations from previous evaluations. For this reason the parameter count of each $\mathcal{F}_r$ matches that of the base class. By picking the base class as dense networks at various scales and connections as dense connections this algorithm recovers MSDNets studied in [65]. Similarly, by picking the base class as root nodes and binary connections, the algorithm recovers an HNE from [141].

We refer to the process of constructing $\{\mathcal{F}_r\}$ given a choice of base class $\mathcal{F}_0$, the parameter $R$, and the connection type as *expanding* $\mathcal{F}_0$. Note that while intermediate connections help with capacity, they often reduce parallelizability as models become mutually dependent. As a practical consequence, dependencies on later-layer activations are preferred; we therefore use the profiler of Rasley et al. [114] to measure inference cost during training rounds and rank models (see Appendix A.3).

## 2.3 Theoretical Analysis

In this section we provide theoretical analysis and justification for our method. First, we show that the ensemble output produced by Algorithm 1 converges to $g$ at $\mathcal{O}(1/\sqrt{T})$ rate, provided that the procedure FIND-WL succeeds at each time $t$.

Theorem 2.1. *Suppose the class* $\mathcal{F}$ *satisfies, for all* $f \in \mathcal{F}, \|f - g\|_\infty \le G_\infty$. *Let* $F = \{f_t\}_{t=1}^T$ *be the ensemble after T rounds of Algorithm 1, with the final output* $F_t = \frac{1}{T} \sum_{t=1}^T f_t$. *If* $f_t$ *satisfies Equation (2.7) for all* $t \le T$ *then for* $T \ge \ln 2N$ *and*

$$\eta = \frac{1}{G_\infty} \sqrt{\frac{\ln 2N}{T}}$$

we have for all $j$

$$\|F_{t,j} - g_j\|_\infty \le G_\infty \sqrt{\frac{\ln 2N}{T}} - \frac{1}{T} \sum_{t=1}^T \gamma_t(j)$$ (2.8)

where $F_{t,j}$ and $g_j$ are the $j^{th}$ coordinates of the functions $F_t$ and $g$ respectively.

The main idea behind the proof is to bound the rate of convergence of the algorithm towards the minimax solution. This proceeds by maintaining a potential function and keeping track of its progress through the algorithm. The bounds and techniques used here are also general, in the sense that for various objectives and loss functions, appropriately designed weak learners give similar rates of convergence to the minimax solution. Furthermore, a stronger version that shows exponential rates can be shown by additionally assuming a constant edge for the weak learner (Equation (2.9)) in the proof that follows.
