At runtime, choose the model whose cost best fits the current budget. In this simple case, the elasticity parameter \(\kappa\) can be thought of as the index of the models in a sorting on cost. Assuming \(\mathcal{F} = \{f_1, \dots, f_K\}\) are the Pareto-optimal set of models, sorted in order of increasing cost, we have

```
f_{naive}(x, \kappa) = f_\kappa(x), \quad f_\kappa \in \mathcal{F}
```

Although simple, this approach has practical downsides in terms of maintenance overhead of managing models, selection latency when switching between models, and, crucially, it assumes the budget is known a priori. In practice the budget is revealed only when it has already been exhausted, rendering an upfront choice of \(\kappa\) impossible.

We pursue a more principled alternative. Starting from a single teacher model \(g(x)\), we decompose its capacity into a sequence of \(K\) weak learners \(\{f_1, \dots, f_K\}\). As we progressively evaluate the first \(\kappa = k < K\) learners, we obtain a prediction whose cost scales with \(k\). Assuming the accuracy at every \(\kappa\) remains competitive with the best-effort predictor, we have an anytime model whose accuracy improves as more budget becomes available. When inference is interrupted, we simply return the most recent prediction.
