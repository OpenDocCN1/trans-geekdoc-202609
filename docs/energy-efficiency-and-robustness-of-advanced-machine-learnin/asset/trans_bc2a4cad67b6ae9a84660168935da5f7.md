
一个突触被认为是 spiking neural network (SNN) 中最简单的计算单元。当从前交联神经元发出的尖峰到达后交联神经元的输入时，与突触权重相关的注入到神经元体内的尖峰电流会整合到膜电位中，从而有助于提高其膜电位。文献中已提出多种神经元模型，本节提供了在 SNN 中最常用的模型的概述。

The `McCulloch-Pitts neuron` \[[169](#refbib.xhtml#refbib169)\] 是神经网络的前身模型。它简单地计算输入尖峰的总和，并在总和高于其阈值时输出布尔值 1（发火），否则输出 0。其主要缺点是无法学习。为克服这一问题，提出了 `perceptron` 模型 \[[230](#refbib.xhtml#refbib230)\]，它引入了可学习的权重，这些权重会与 McCulloch-Pitts 突触的布尔输出相乘。 perceptron 网络代表了神经网络的第一代，而第二代则使用同样结构的 perceptron 模型但采用更复杂的激活函数。对于第三代，即 SNN，可以采用不同的神经元模型，权衡生物学可信性与实现成本：

*   The `Hodgkin-Huxley model` \[[90](#refbib.xhtml#refbib90)\] 是最具生物学可信性但也最复杂的神经元模型。它涉及多个微分方程，使得使用该模型开发大规模 SNN 变得不切实际且效率低下。

*   The `Izhikevich model` \[[95](#refbib.xhtml#refbib95)\] 能够再现多种尖峰模式以及生物皮层神经元的尖峰形状，同时计算需求低于 Hodgkin-Huxley 突触。其功能由方程 (2.3) 到 (2.5) 描述，其中 *v* 为膜电位，*I* 为输入电流，*u* 为膜恢复变量，*a, b, c, d* 为设置尖峰形状的常数。

    $$\\begin{array}{l} {\\frac{dv}{dt} = 0.04v^{2}(t) + 5v(t) + 140 - u(t) + I(t)} \\\\ \\end{array}$$  

    (2.3)

    $$\\begin{array}{l} {\\frac{du}{dt} = a(bv(t) - u(t))} \\\\ \\end{array}$$

    (2.5)

*   The `Integrate-and-Fire (IF) model` \[[61](#refbib.xhtml#refbib61)\] 从计算角度来看是最简单的模型。因此，它在 SNN 社区中被广泛使用。该模型基于电阻-电容 (RC) 电路，类似于低通滤波器。方程 (2.6) 描述了后交联神经元膜电位随时间变化的方式，从中可以推导出时间常数 *τ*[*m*] = *R**C*，如方程 (2.7) 所示。

    (2.6)

    当膜电位在射击时间 *t*[*f*] 时达到一定阈值 *V*[*t**h**]，后交联神经元会产生尖峰 *δ*(*t − *t*[*f*])，随后膜电位被重置为 *v*[*r**e**s**t*（通常假设为 0），这显然低于 *V*[*t**h**]。

*   The `Leaky-Integrate-and-Fire (LIF)` \[[278](#refbib.xhtml#refbib278)\] 是 IF 模型的改进版本，引入了禁制期的概念。禁制期是指射击后的一段时间，在此期间膜电位即使接收到输入尖峰也不能增加。 LIF 突触的膜电位随时间变化由方程 (2.8) 描述。

    (2.8)

    一个突触电流 *i*[*j*](*t*) 在接收到尖峰时产生，随后由其对应的突触权重 *w*[*j*] 调制并与偏置电流 *i*[0](*t*) 相加。与 Hodgkin-Huxley 模型相比，LIF 突触的计算复杂度更低，但生物学可信性也相应降低。LIF 模型假设每个射击的动作电位形状均为相同，这一假设限制了其再现生物射击模式和形状的能力。然而，这种低复杂度使得可以构建大规模 SNN 并在神经形态硬件上实现。

### 2.3.2 Spike Coding Techniques

SNN 的输入信息通过射击列车进行表示和传播到输出。不同的编码方法用于将信息编码为射击 \[[210](#refbib.xhtml#refbib210)\]，如 [Figure 2.10](#chapter2.xhtml#fig2_10) 所示：

*   `Rate Coding`: 强度对应于发射尖峰的概率，即在观察期间计数多个尖峰时的平均发射率。它因其简便性而被广泛使用，但相比其他编码技术，由于发射率较高，可能更耗费能量。

*   `Inter-Spike-Interval (ISI) Coding`: 强度以相邻尖峰之间的精确延迟作为时域编码。

*   `Time-to-First-Spike (TTFS) Coding`: 强度 *I* 以射击与刺激之间的时间差 *Δ**t*** 编码，即 *Δ**t** = 1/*I* 或线性关系 *Δ**t** = 1 − *I*。该编码假设神经元对每个刺激只产生一个尖峰，后续尖峰被忽略 \[[199](#refbib.xhtml#refbib199)\]。其主要优势是处理速度快，因为信息在第一个尖峰传出后即可处理。

### 2.3.3 SNN Learning Techniques

根据学习拓扑的不同，可采用多种 SNN 训练方法。对于无监督学习，可能的方法基于 Hebbian 学习 \[[235](#refbib.xhtml#refbib235)\]，Spike-Driven Synaptic Plasticity (SDSP) \[[56](#refbib.xhtml#refbib56)\]，以及 Spike-Time-Dependent Plasticity (STDP) \[[255](#refbib.xhtml#refbib255)\]。STDP 是社区中最常用的方法，它根据前后交联神经元尖峰在空间和时间域的相关程度来增强或减弱突触权重。

基于梯度的监督 DNN 学习方法无法直接应用于 SNN，因为尖峰损失函数不可微分 \[[232](#refbib.xhtml#refbib232)\]。克服这一挑战的可能方案是 (1) 在 DNN 域先训练权重后进行 DNN-to-SNN 转换，或 (2) 使用 surrogate gradient 近似损失函数对 spiking 导数进行估计。
