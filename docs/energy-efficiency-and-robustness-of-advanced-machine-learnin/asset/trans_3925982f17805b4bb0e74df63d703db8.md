
$$\begin{array}{l} {\\frac{\\partial L}{\\partial\\mathbf{W}^{n}} = \\sum\\limits\_{t = 1}^{T}\\frac{\\partial L}{\\partial\\mathbf{u}^{t,n}} \\cdot \\frac{\\partial\\mathbf{u}^{t,n}}{\\partial x^{t,n}} \\cdot \\frac{\\partial x^{t,n}}{\\partial W^{n}} = \\sum\\limits\_{t = 1}^{T}\\frac{\\partial L}{\\partial\\mathbf{u}^{t,n}} \\cdot \\mathbf{o}^{t,n - 1}} \\\\ \\end{array}$$  

(6.14)

它们用于执行 `Gradient Descendent Optimization Algorithm`。使用 `STBP` 学习规则的实现，光滑函数的导数替代尖峰非线性的导数，遵循 `Surrogate Gradient` \[[185](#refbib.xhtml#refbib185)\] 策略。

#### 6.4.2.4 Loss Function

在数据预处理步骤之后，DET 数据集中的车道类和背景类也会出现失衡。因此，我们采用 *Weighted Binary Cross-Entropy* (WCE) 损失函数 \[[88](#refbib.xhtml#refbib88)\]，它是更常见的 *Binary Cross-Entropy* (BCE) 损失函数的变体。如方程 (6.15) 所示，\(\hat{y}\) 是预测该像素是否为车道的概率，\(y\) 表示类别值，可为正（\(y = 1\)）或负（\(y = 0\)）。

$$\\begin{array}{l} {L\_{WCE}(y,\\hat{y}) = - (\\beta \\cdot y \\cdot \\log(\\hat{y}) + (1 - y) \\cdot \\log(1 - \\hat{y}))} \\\\ \\end{array}$$  

(6.15)

WCE 函数因为对正类（即车道存在）的系数 \(\beta\) 加权，从而缓解了标签失衡问题。

然而，`STBP` 学习规则 \[[283](#refbib.xhtml#refbib283)\] 通常与 *Mean Squared Error* (MSE) 损失函数（方程 6.16）一起使用，而 MSE 在分割任务中并不常见。

$$\\begin{array}{l} {L\_{MSE} = \\frac{\\sum\\limits\_{i = 1}^{n}(y\_{i} - {\\hat{y}}\_{i})^{2}}{n}} \\\\ \\end{array}$$  

(6.16)

因此，针对车道检测任务，我们提出一种结合 MSE 与 WCE 优势的新损失函数。该联合加权损失函数可表示为方程 (6.17)。

$$\\begin{array}{l} {L\_{MSE\\ \\&\\ WCE} = (1 - p) \\cdot L\_{MSE} + p \\cdot L\_{WCE},} \\\\ \\end{array}$$  

(6.17)

其中 \(p\) 表示 WCE 贡献的参数，\((1 - p)\) 表示 MSE 贡献，满足 \(0 \geq p \geq 1\)。

#### 6.4.3.2 Input and Output

为保持与 DET 数据集在 6.4.2 节所作选择的一致，我们对每张原始灰度图像只生成一个脉冲列车。因此，网络仅使用一个输入通道。

输出尺寸必须与修改后的 DET 数据集的标签图像尺寸保持一致。因此，最后一层应有 400 个神经元，对应每个像素，其放电率代表该像素被判定为车道的概率。

#### 6.4.3.3 Network Architectures

文献中许多基于神经网络的语义分割算法可用于一般语义分割任务，主要分为两类：

*   *End-to-End*：这些算法仅使用 NN，无需任何前置或后处理步骤即可解决车道检测问题。通常网络被分为两个部分，即 **downsampling**（降采样）和 **upsampling**（上采样）阶段 \[[181](#refbib.xhtml#refbib181)\]。

*   *More than one step*：NN 仅代表完整检测算法的一部分，适用于其他更复杂的传统算法 \[[143](#refbib.xhtml#refbib143)\]，当这些独立 NN 表现不佳时 \[[106](#refbib.xhtml#refbib106)\]。

为降低系统的延迟和功耗，我们选择实现 *End-to-End* 算法。为 Loihi 实现，我们使用 NxTF 库 \[[233](#refbib.xhtml#refbib233)\] 来构建网络，该库仅支持基础层，如 Conv、FC 和平均池化。

我们受以往工作的启发，设计了一种脉冲卷积网络（spiking CNN），参考 \[[106](#refbib.xhtml#refbib106)\] 与 \[[140](#refbib.xhtml#refbib140)\]。第一篇工作 \[[106](#refbib.xhtml#refbib106)\] 在网络末端部署了一个小的全连接（FC）网络作为 **upsampling** 部分；第二篇工作 \[[140](#refbib.xhtml#refbib140)\] 强调在 **downsampling** 结构中卷积层（Conv）的重要性。

因此，我们首先设计了名为 **CNN LaneSNN**（见 [Table 6.21](#chapter6.xhtml#tbl6_21)）的网络，包含五个卷积层，将输入图像尺寸 80 × 20 通过 16 个通道缩小至 20 × 5 像素。随后，图像进入上采样区域，由 400 个输出神经元与随后的卷积层相连，并采用 **dropout** 层。
