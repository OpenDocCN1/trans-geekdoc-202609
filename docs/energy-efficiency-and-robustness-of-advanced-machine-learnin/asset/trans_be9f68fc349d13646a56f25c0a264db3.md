
### 7.3.4 Robustness Exploration Methodology

我们的研究探讨了在不同对抗噪声预算下SNN的鲁棒性，针对不同 `V[t]` 和 `T` 参数组合。[Figure 7.18](#chapter7.xhtml#fig7_18) 给出了我们方法论的不同组成部分的概览。它由以下两个主要步骤组成。**(1)** 探索的第一步旨在排除结构参数中不利于 SNN 高效学习的组合。事实上，没有兴趣研究基线性能较低的 SNN 的鲁棒性。**(2)** 在第二步，对于所有能够使 SNN 训练高效收敛的 `V[t]` 和 `T` 设置，我们进行鲁棒性探索。

![Figure 7.18: Methodology steps for exploring the SNN robustness, varying the threshold voltage V_{th}, the time window T, and the adversarial perturbation ε.](images/fig7_18.jpg)

[Figure 7.18:](#chapter7.xhtml#b7fig7_18) Methodology steps for exploring the SNN robustness, varying the threshold voltage `V[t]`, the time window `T`, and the adversarial perturbation `ε`.

[Algorithm 25](#chapter7.xhtml#comp07_3) 详细描述了我们的鲁棒性探索方法论。第 1 行和第 2 行浏览 `n` 个阈值电压和 `m` 个时间窗口进行探索。一旦训练启动（第 3 行），我们便对给定的 `V[t]` 和 `T` 组合进行 SNN 可学性研究。如第 4 行所示，可学性通过设定一个最低基线准确率阈值来定量验证，该阈值以下我们认为 SNN 学习效率低下。该数值取决于 SNN 架构、学习方法、数据集和应用。在我们的案例研究中，我们使用准确率阈值为 70%，因为这是当前最先进的 SNN 通常能够达到的数值 \[[209](#refbib.xhtml#refbib209)\]。

安全分析从第 5 行开始。它会使用不同的噪声预算生成对抗示例以欺骗 SNN。噪声预算模拟了攻击生成中允许的侵略程度；噪声预算越高，攻击越具有侵略性。首先，我们初始化成功攻击生成的计数器（第 6 行）。然后，我们遍历数据集 𝒟（第 7 行），使用 PGD 生成对抗攻击，如第 8 行所示。随后，算法验证生成的示例是否能够欺骗 SNN（第 9-10 行），即攻击是否迫使输出变为错误标签，并相应地增加对抗成功计数器。随后，我们对每个 `ε` 值评估鲁棒性，即对手未能生成能够欺骗受害者 SNN 的对抗示例的比例（第 11 行）。因此，通过跟踪准确率随 `ε` 的变化趋势，我们可以比较每个模型对抗攻击的鲁棒性。

### 7.3.5 Evaluation of the SNNs' Robustness

#### 7.3.5.1 Experimental Setup

我们的实验使用 Norse \[[209](#refbib.xhtml#refbib209)\]，这是一个扩展 PyTorch \[[204](#refbib.xhtml#refbib204)\] 的库，提供生物启发神经元组件的原语，从而使我们能够在 spiking 域中训练和运行 SNN。对抗攻击使用 Foolbox v3.1.1 \[[224](#refbib.xhtml#refbib224)\]。SNN 架构是基于 LIF 积分和差分（LIF）神经元模型的 Lenet-5，并在 MNIST 数据集上进行训练 \[[118](#refbib.xhtml#refbib118)\]。实验在 Nvidia GeForce RTX 2080 Ti GPU 上进行。

#### 7.3.5.2 Learnability Study

在研究结构参数变化时的鲁棒性之前，我们需要定义探索空间。阈值电压和时间窗口参数的默认值为 `V[t]` 和 `T` = (1, 64)。因此，我们关注在围绕这些设置的邻近区域内的 SNN 可学性进行概览。[Figure 7.19](#chapter7.xhtml#fig7_19) 展示了不同 `V[t]` 和 `T` 组合的准确率热图。水平轴和纵轴分别表示 `V[t]` 和 `T`，不同颜色表示 SNN 的准确率。注意，最高准确率的组合倾向于位于左上角，即低 `V[t]` 和高 `T`。然而，热图并非单调递增。例如，存在准确率低于 16% 的组合，却被准确率高于 89% 的组合包围。

#### 7.3.5.3 Security Study

本节研究在白盒场景下，通过增加对抗噪声幅度来评估 SNN 的鲁棒性。我们首先在所有先前的 `V[t]` 和 `T` 组合下进行整体探索。[Figure 7.20](#chapter7.xhtml#fig7_20) 展示了在 PGD 攻击下，噪声幅度为 1 和 1.5 时 SNN 精度的下降情况。

![Figure 7.20: Heat maps showing the SNN accuracy for the MNIST dataset using different combinations of (V_{i},T_{j}). (a) Security analysis for ε = 1. (b) Security analysis for ε = 1.5.](images/fig7_20.jpg)

[Figure 7.20:](#chapter7.xhtml#b7fig7_20) Heat maps showing the SNN accuracy for the MNIST dataset using different combinations of `V[i]` and `T[j]`. **(a)** Security analysis for `ε` = 1. **(b)** Security analysis for `ε` = 1.5.

我们从 [Figure 7.20](#chapter7.xhtml#fig7_20) 中提取的第一个令人着迷的洞察是：高基线可学性（即在没有对抗攻击的情况下的表现）并不能保证鲁棒性。此外，我们注意到结构参数的不同会导致 SNN 在面对对抗攻击时表现出不同的演变趋势。具体来说，两个初始精度相近的 SNN 可能在攻击下表现截然不同。例如，组合 `V[t]` 和 `T` = (0.5, 80) 与 `V[t]` 和 `T` = (0.75, 72) 都以 97% 的准确率开始。然而，在 `ε` = 1 攻击预算下，第一个组合的准确率下降至 27%，而第二个组合仅下降 6%。

[Figure 7.20b](#chapter7.xhtml#fig7_20) 展示了在大对抗扰动（`ε` = 1.5）下的更为突出的行为，超过一半的热图区域的 SNN 准确率低于 20%。值得注意的是，`V[t]` 和 `T` = (0.75, 48) 的 SNN 在 `ε` = 1.5 时准确率降至 2%，而在 `ε` = 1 时相对较高（86%）。另一方面，`V[t]` 和 `T` = (1, 80) 的 SNN 对 PGD 攻击表现相对稳健，其准确率从 `ε` = 0 和 `ε` = 1 时的 72% 仅下降到 `ε` = 1.5 时的 66%。
