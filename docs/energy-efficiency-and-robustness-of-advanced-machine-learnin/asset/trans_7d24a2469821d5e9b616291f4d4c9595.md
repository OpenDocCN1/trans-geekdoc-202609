
-   [应用驱动的存储层次结构，由片上 SPM 和片上 DRAM 组成，可在不牺牲 Google CapsNet 模型的吞吐量的前提下，节省高达 73% 的能量。请注意，吞吐量通过在交错方式与当前操作同时预取下一操作的数据来保持不变。因此，片上内存的延迟可以被隐藏。]

-   片上内存的利用率取决于 CapsNet 推理的操作，因此对未使用的区域启用电源门可以进一步降低其能耗。

-   将 SPM 分割为独立的组件（数据、权重和累加器），有助于存储数值并高效地将其馈送到加速器。

### 3.4.4 DESCNet: Scratchpad Memory Design

#### 3.4.4.1 DESCNet Memory Architecture

我们的 `DESCNet` 架构如 [Figure 3.32](#chapter3.xhtml#chapter3.xhtml#fig3_32) 所示。它通过专用总线与 CapsNet 加速器相连，并通过专用总线与片上内存相连。SPM 被分为 `B` 个 bank，每个 bank 包含 `SC` 个大小相等的 sector。不同 bank 之间的所有 sector 通过实现为睡眠晶体管的电源门电路（用于高效的按 sector 级电源管理控制）相互连接，这在一定程度上会增加面积开销。我们的设计为每个 bank 配备 `SC` 个 sector，所有 sector 共享同一睡眠信号。我们仅考虑 `ON` 与 `OFF` 两种模式，因为它们在我们的设计中表现出优势，并且不需要保留状态。我们的应用驱动内存电源管理单元（PMU）决定睡眠晶体管的合适控制信号（即 `ON` ↔ `OFF`）。在当前操作执行完成后，SPM 中的值会被丢弃，因为我们在设计中采用深度睡眠 `OFF` 状态，该状态不可保留。从睡眠模式切换到另一种模式会产生一定的唤醒能量和延迟开销，需要通过泄漏能量节约（取决于睡眠时长和处于睡眠模式的 sector 数量）来摊薄。请注意，我们的记忆模型可以推广至支持不同尺寸和并行度的记忆组织，包括多端口记忆。 *为此，我们研究了以下三种设计选项。*

1.  (a)**[Figure 3.33a](#chapter3.xhtml#chapter3.xhtml#fig3_33)—Shared Multi-Port Memory (SMP):** a shared on-chip memory with 3 ports for accessing the weights, input data and accumulator's storage in parallel.

2.  (b)**[Figure 3.33b](#chapter3.xhtml#chapter3.xhtml#fig3_33)—Separated Memory (SEP):** weights, input data, and the accumulator's partial sums are stored in separate on-chip memories.

3.  (c)**[Figure 3.33c](#chapter3.xhtml#chapter3.xhtml#fig3_33)—Hybrid Memory (HY):** a combination of the above two design options, i.e., an `SMP` coupled with a `SEP` memory.
