
$$\begin{array}{l} {\\frac{\\partial L}{\\partial\\mathbf{W}^{n}} = \\sum\\limits\_{t = 1}^{T}\\frac{\\partial L}{\\partial\\mathbf{u}^{t,n}} \\cdot \\frac{\\partial\\mathbf{u}^{t,n}}{\\partial x^{t,n}} \\cdot \\frac{\\partial x^{t,n}}{\\partial W^{n}} = \\sum\\limits\_{t = 1}^{T}\\frac{\\partial L}{\\partial\\mathbf{u}^{t,n}} \\cdot \\mathbf{o}^{t,n - 1}} \\\\ \\end{array}$$  

(6.14)

They are used to perform the `Gradient Descendent Optimization Algorithm`. Using the implementation of the `STBP` learning rule, the derivative of a smooth function replaces the derivative of the spiking nonlinearity, following the `Surrogate Gradient` \[[185](#refbib.xhtml#refbib185)\] strategy.

#### 6.4.2.4 Loss Function

The lane and background classes in the DET dataset are also imbalanced after the dataset pre-processing step. Therefore, we employ the *Weighted Binary Cross-Entropy* (WCE) loss function \[[88](#refbib.xhtml#refbib88)\] that is a variant of the more common *Binary Cross-Entropy* (BCE) loss function. It is described in Equation (6.15), where *ŷ* is the predicted probability of having a lane in a determined pixel, and *y* represents the class value, which can be positive (*y* = 1) or negative (*y* = 0).

$$\\begin{array}{l} {L\_{WCE}(y,\\hat{y}) = - (\\beta \\cdot y \\cdot \\log(\\hat{y}) + (1 - y) \\cdot \\log(1 - \\hat{y}))} \\\\ \\end{array}$$  

(6.15)

The WCE function introduces a slight improvement for the unbalanced labels because the positive class (i.e., the presence of the lane) is weighted by the coefficient *β* that balances the positive and negative prediction.

However, the STBP learning rule \[[283](#refbib.xhtml#refbib283)\] is always studied with the implementation of the *Mean Squared Error* (MSE) loss function (Equation (6.16)), which is not widely used for segmentation problems \[[97](#refbib.xhtml#refbib97)\].

$$\\begin{array}{l} {L\_{MSE} = \\frac{\\sum\\limits\_{i = 1}^{n}(y\_{i} - {\\hat{y}}\_{i})^{2}}{n}} \\\\ \\end{array}$$  

(6.16)

Therefore, for the lane detection task, we introduce a novel loss function that combines the benefits of both MSE and WCE. This joint weighted loss function can be formalized by the Equation (6.17).

$$\\begin{array}{l} {L\_{MSE\\ \\&\\ WCE} = (1 - p) \\cdot L\_{MSE} + p \\cdot L\_{WCE},} \\\\ \\end{array}$$  

(6.17)

where *p* denotes the parameter related to the WCE contribution and (1 − *p*) denotes the MSE contribution, such that 0 ≥ *p* ≥ 1.

#### 6.4.3.2 Input and Output

To be coherent with the choices made on the DET dataset discussed in [Section 6.4.2](#chapter6.xhtml#sec6_4_2), since we generate only one spike train per pixel from each raw gray-scale image, we implement our networks with only one input channel.

The output size needs to be consistent with the dimension of the label images of the modified DET dataset. Hence, the last layer should have 400 output neurons, one for each pixel. Their firing rates represent the probability of the corresponding pixel being a lane in the resulting image.

#### 6.4.3.3 Network Architectures

In literature, there are many algorithms based on NNs for facing general semantic segmentation tasks. They can be classified into two classes according to their implementation:

*   *End-to-End*: these algorithms use only the NN without any pre and post-processing steps to tackle the lane detection problem. Usually, in these cases the network is split into two subsequent parts, i.e., reducing (*downsampling*) and increasing (*upsampling*) the image size during the elaboration \[[181](#refbib.xhtml#refbib181)\].

*   *More than one step*: the NN represents only a part of the whole detection algorithm, and it is useful for other more complex conventional algorithms \[[143](#refbib.xhtml#refbib143)\] when these standalone NNs achieve low performance \[[106](#refbib.xhtml#refbib106)\].

For reducing the latency and power consumption of the complete system, we choose to implement *End-to-End* algorithms. For the Loihi implementation, we design the networks through the NxTF library \[[233](#refbib.xhtml#refbib233)\]. It can describe only basic layers such as Conv, FC, and average pooling.

We develop a spiking CNN inspired by the analysis made by the works in \[[106](#refbib.xhtml#refbib106)\] \[[140](#refbib.xhtml#refbib140)\]. In the first work \[[106](#refbib.xhtml#refbib106)\], a small FC network is deployed at the end of the NN as the *upsampling* part. The second work \[[140](#refbib.xhtml#refbib140)\] emphasizes the importance of Conv layers over others types for the *downsampling* structure.

Therefore, we design our first network, called **CNN LaneSNN** (see [Table 6.21](#chapter6.xhtml#tbl6_21)), with five Conv layers by which the input sample image size (80 × 20) is reduced to 20 × 5 pixels for each of the 16 channels. Afterward, the image enters into the upsampling region made of 400 output neurons connected to the following Conv layer. Moreover, we adopt a *dropout layer*.
