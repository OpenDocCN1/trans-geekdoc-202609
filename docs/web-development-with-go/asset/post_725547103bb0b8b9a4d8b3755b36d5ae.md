# 16.4 Limiting middleware for static assets

Our Users middleware is currently checking to see if the user is logged in every time user requests a public image or asset. While this might be useful if we had private images, we don't and this ends up causing extra database lookups. One simple way to prevent this is to update the middleware to not run on specific routes.

```go
$ atom middleware/require_user.go
```

We will grab the current path of the web request and check to see if it starts with /assets/ or /images/. If it does, we will call the next middleware and return without looking up the user.

```go
import (
	// Add this import
	"strings"
)

func (u *User) ApplyFn(next http.HandlerFunc) http.HandlerFunc {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		path := r.URL.Path
		// If the user is requesting a static asset or image
		// we will not need to lookup the current user so we skip
		if strings.HasPrefix(path, "/assets/") ||
			strings.HasPrefix(path, "/images/") {
			next(w, r)
			return
		}
		// everything else remains unchanged
	})
}
```

To create a properly encoded URL path we are going to be using the url, URL type. import (

func (i *Image) Path() string {
	temp := url.URL{
		Path: "/" + i.RelativePath(),
	}
	return temp.String()
}
