Finally, we are going to add a link to our sign up page to our navbar. This is something we have done in past exercises, so it should look familiar with one caveat - we will be placing our sign up link on the right side of the navbar.

Now let's go ahead and add some code to main.go that will allow us to view our sign up form. To do this, we need to create a new view like we did for the home and contact pages, and then create a handler function that we will provide to our router.

```
$atom main.go
```

Add the global variable signup near our other view variables. While we don't have to, we can go ahead and move these all into a variable group.

```go
var (
  homeView   *views.View
  contactView *views.View
  signupView *views.View
)
```

Now we have a view we need to initialize. We will do this inside of the main function like before, and once again we will use the NewView function that is provided by the views package.

```go
signupView = views.NewView("bootstrap", "views/signup.gohtml")
```

We also need to create a handler function that we can pass to our router. We will call this signup, and it needs to accept both a ResponseWriter and a Request argument like our existing handler functions. Once we are inside the function all it needs to do is call the Render method on our signupView. You can also set the Content-Type header if you want, but it isn't required.

```go
func signup(w http.ResponseWriter, r *http.Request) {
  w.Header().Set("Content-Type", "text/html")
  must(signupView.Render(w, nil))
}
```
