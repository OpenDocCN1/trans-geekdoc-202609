# CHAPTER 9. CREATING THE USER MODEL

If you recall from before, the gorm.Model type will include the id, created_at, updated_at, and created_at fields for us, so the only ones we need to man-ually clear for now are Name and Email.

We are also going to add in a tag for Email field to GORM know that we don't want this field to be null, and that we want to index it with a unique constraint. This will ensure that all of our users have an email address, and that no two users share the same email address.

Listing 9.2: Creating the User type
```go
package models

import "github.com/jinzhu/gorm"

type User struct {
	gorm.Model
	Name string
	Email string `gorm:"not null;unique_index"
}
```
