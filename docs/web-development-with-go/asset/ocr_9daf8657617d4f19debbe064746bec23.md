# Listing 3.4: Breaking up our handlers into functions.

```
func home(w *http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "text/html")
    fmt.Fprintf(w, "<h1>Welcome to our site!</h1>")
}

func contact(w *http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "text/html")
    fmt.Fprintf(w, "To get in touch, please send an email " +
        "to <a href="mailto:support@lenslocked.com">" +
        "support@lenslocked.com/a/")")
}
```

The code we wrote in 3.4 should look very familiar because it is very similar to the code we wrote in our original handlerFunc function, minus the 404 page logic. Now that we have code broken into two functions, we can delete the handlerFunc function from main.

That leaves us ready to start using gorilla/mux in our code. First we need to add an import to the top of our source code.

# Listing 3.5: Importing gorilla/mux.

```
import (
    "fmt"
    "net/http"

    "github.com/gorilla/mux"
)
```

And we did here was add the line telling code that we will be using the gorilla/mux package. When importing third party libraries you will be importing them using a url like the one we just used. This is typically a link to a source control service, such as github, but you will later see us using the lenslocked.com domain for private packages that we create.
