## 14.6. 通过中间件要求用户

```go
func (mw *RequireUser) ApplyFn(next http.HandlerFunc) http.HandlerFunc {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
	// ... cookie 查找和用户验证保持不变

		// 从请求中获取上下文
		ctx := r.Context()
		// 从现有的上下文创建一个新上下文，
		// 并使用私有用户键存储了我们的用户
		ctx = context.WithContext(ctx, user)
		// 从现有的请求创建一个新请求，
		// 附加我们的上下文并将其赋值回 'r'
		r = r.WithContext(ctx)
		next(w, r)
	})
}
```
