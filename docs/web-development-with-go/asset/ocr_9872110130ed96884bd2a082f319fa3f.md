Note: Don't cod anything above. These snippets are pulled from our code to demonstrate please we use config variables.

While that might appear to be a lot at first, it actually won't take very long to pull this all out of our application and instead replace it with configuration variables.

Let's start with PostgreSQL info defined in our main.go source file. We are going to define a type that makes it easier to provide these values, and then we will write a function to provide our default values.
