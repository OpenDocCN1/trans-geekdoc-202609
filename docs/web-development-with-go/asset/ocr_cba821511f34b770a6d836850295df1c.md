We need to set up a service file that will tell systemd¹ about Caddy, systemd is used in Ubuntu 16.04 to manage system processes. For instance, we will be using it to ensure that after the server reboots it restarts both Caddy and our web application. If either of our applications crash we can also setup rules for how often and when to restart them.

```
$ sudo nano /etc/systemd/system/caddy.service
```

Once the service file is opened, fill it with the following contents:

```
[Unit]
Description=caddy server for serving lenslocked.com
[Service]
WorkingDirectory=/root/app
ExecStart=/usr/local/bin/caddy -email you@email.com
Restart=always
RestartSec=120
LimitNOFILE=192
[Install]
WantedBy=multi-user.target
```

Box 16.8. Explaining our service file

Our service file is broken into three sections: Unit, Service, and Install.

The first, is used to describe the service we are creating. In our case we are only providing a general description.
