# 7.4.4 Parsing forms with gorilla/schema

We have seen how to parse a form and access the data manually, parsing data this way can be tedious. We need to write code to pull out each field of our form, convert it to the correct data type, and assign it to whatever data structure we want to work with in our code.

Rather than writing all of this code and potentially introducing a bug into our code, we are going to take advantage of another library in the Gorilla web toolkit¹⁰ - the schema package¹¹.
