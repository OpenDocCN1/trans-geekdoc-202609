# 17.5. RESETTING PASSWORDS

The Token and TokenHash fields are going to be used in the same way we use the Remember and RememberHash fields on the User type. The former is used to store the raw value that is never stored in our database, while the latter is used to store the hashed value which will be persisted in our database.

We are also going to create an interface defining what functionality is available for our password reset table.

```
type pwResetDB interface {
  ByToken(token string) (*pwReset, error)
  Create(pwr *pwReset) error
  Delete(id uint) error
}
```

ByToken will be used to lookup pwReset by its token. Create will be used to create a new password reset, and delete will delete them via their ID.

Next up is the GORM implementation of this interface.

```
type pwResetGorm struct {
  db *gorm.DB
}

func (pwrg *pwResetGorm) ByToken(tokenHash string) (*pwReset, error) {
  var pwr *pwReset
  err := first(pwr, db.Where("token_hash = ?", tokenHash), &pwr)
  if err != nil {
    return nil, err
  }
  return &pwr, nil
}

func (pwrg *pwResetGorm) Create(pwr *pwReset) error {
  return pwrg.db.Create(pwr)
}

func (pwrg *pwResetGorm) Delete(id uint) error {
  pwr := pwReset(Model: gorm.Model(ID: id))
  return pwrg.db.Delete(&pwr).Error
}
```
