Now our userValdiator implements the UserReader interface without writing any extra code because it embeds it.

```
uv := userValdiator()
uv.ByID() // This is the same as uv.UserReader.ByID()
// The method call is deferred to the embedded type
```

Note: This is NOT the same as inheritance in some languages.

Because we embedded our interfaces, we can now introduce each of these layers without writing all of the code for them. That means we can slowly add validations for a single method, like ByMember, while the ByID method will continue to work because it will be deferred to the embedded type.
