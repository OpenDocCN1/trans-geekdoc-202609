# 12.6. VALIDATING AND NORMALIZING EMAIL ADDRESSES

```
// ByEmail will normalize an email address before passing
// it on the database layer to perform the query.
func (uv *userValidator) ByEmail(email string) (*User, error) {
	user := &User{
		Email: email,
	}
	err := runUserValFns(&uv, uv.normalizeEmail)
	if err != nil {
	eturn nil, err
	}
	return UserDB.ByEmail(user)
}
```

Next up are the Create and Update methods. These are as simple as adding the function to our runUserValFns, so I'll just show the code for both below.

```
func (uv *userValidator) Create(user *User) error {
	err := runUserValFns(user,
	uv.setPassword,
	uv.setRememberIfUnset,
	uv.hmacRemember,
	uv.normalizeEmail,
	// ... this is unchanged
}
```

```
func (uv *userValidator) Update(user *User) error {
	err := runUserValFns(user,
	uv.setPassword,
	uv.hmacRemember,
	uv.normalizeEmail,
	// ... this is unchanged
}
```

If you happened to look at the UserService, you might wonder why we don't need this in the Authenticate method as well. The reason we don't need it there is that method will ultimately use the ByEmail method to query for a user, so as long as we handle normalization there we don't need to do anything special inside the Authenticate method.
