# Table 8.1: PostgreSQL connection parameters and values.

| Parameter | Value (yours may vary from what listed here) |
| host | localhost |
| port | 5432 |
| user | postgres |
| password | <none> |
| dbname | lenslocked_dev |

something is your user for Postgres. The **-U** flag is how you connect to Postgres with a specific user.

After that we need your password. One should be pretty obvious because most tutorials have set a value on your own, and if you didn't set one you can use the empty string for your password.

Lastly, we need to figure out your database name, which we will be listed as the **dbname** in our code. For this one you either created a database during your installation, or it could possibly be the same as your Postgres user.

If you did create a database in your tutorial, you will follow these steps again to create a database named **lenslocked_dev** or **<yourapp_dev>** so that it is obvious what the database is used for.

Once you have all of that, jot it down in a table like the one in Table 8.1. I have provided you with the values I will be using in the table, but yours might be different. Just make sure you use the data in your own table in the upcoming Go code.

Once you have all of that you are ready to start using PostgreSQL with Go and are ready to proceed to the next section!
