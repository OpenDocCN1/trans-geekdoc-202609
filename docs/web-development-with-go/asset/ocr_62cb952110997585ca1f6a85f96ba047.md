After exiting this if statement we know that the user variable should have a value in the Remember field that isn't an empty string. If it was an empty string our code inside the statement would have generated a new remember token, and otherwise we know one was already set.

We are going to use remember token to create a cookie and set it using the http package with the response passed into our signIn method. Finally we will return nil we didn't have any errors if we made this far.

```
cookie := http.Cookie{
Name: "remember_token",
Value: user.Remember,
}\http.SetCookie(w, &cookie)
return nil
```
