We can also attach an HTML version of the email to the message using the SetHtml method¹.

```
html := `Hi there!<br/>
Welcome to <a href="https://www.lenslocked.com">lenslocked.com</a>`
`...
msg.SetHtml(html)`
```

With the method we could add either static HTML, or we could use the html/template package to generate dynamic HTML and embed that.

Once our email is built to our satisfaction we would use the Mailgun client created earlier to send it.

```
respMsg, id, err := mgClient.Send(msg)
```

Most of the time we won't need to worry about the response message or id, but we should check for errors to verify that the message was sent fully.
