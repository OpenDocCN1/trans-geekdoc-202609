# 8.3.5 Querying multiple records with database/sql

We are now going to look into querying multiple records stored in our database at the same time rather than just querying a single record. The code in this section is going to be incredibly similar to the code in Section 8.3.4, especially the SQL, and you could even use this code to query a single record if you wanted.

The primary difference is going to be the fact that instead of working with a sql.Row object that just contains a single row, we will be interacting with a sql.Rows object. This is very similar to a Scan () method, it also has a Next () method which will move on to the next row returned by the database.

If you haven't already, you may want to create a few user objects that you can see how this works with multiple records, but it isn't mandatory to make it work.

Our example is going to demonstrate how to query for all users in our database with the email address json@calhoun.io or an ID greater than 4. The results will come back as an sql.Rows object which we iterate over. We will just be printing the values you want, but you could insert each result into an array or really anywhere you want.
