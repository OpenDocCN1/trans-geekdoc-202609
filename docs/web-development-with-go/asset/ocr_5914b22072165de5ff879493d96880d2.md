Next we are going to use the UserService to look up a user via the remember token stored we just retrieved. As long as the user has a valid session this should return a user, otherwise we will get an error indicating that the user needs redirected to the login page.

```
user, err := mw.UserService.ByRemember(cookie.Value)
if err != nil {
    http.Redirect(w, r, "/login", http.StatusFound)
    return
}
fmt.Println("User found: ", user)
```
