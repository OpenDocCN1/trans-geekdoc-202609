# 17.5. RESETTING PASSWORDS

In this section we won't be creating the views that use these templates, we will get the templates ready for when we do that in the next section.

We will start with the form for requesting a password reset token, and we will call this the forgot_pw template, which will be stored in the directory with all our other user views.

```
$ atom views/users/forgot_pw.gethtml
```

Our forgot password form will be very similar to the sign up form, except it will POST to another path and will only have an input for a user's address.
