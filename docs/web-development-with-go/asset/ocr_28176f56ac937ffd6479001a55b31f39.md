# 13.2. RENDERING DYNAMIC ALERTS

```
type Alert struct {
    Level string
    Message string
}
```

Next we want to create an instance of that that we can use to render our alert.
We will test this out with a success alert rather than a danger one.

```
alert := Alert(
    Level: "success",n    Message: "Successfully rendered a dynamic alert!"
)
```

And finally we need to pass this alert as data into the Render method when we go to render a view. Putting that all together, your New method should look like the code.

```
func (u *Users) New(w http.ResponseWriter, r *http.Request) {
    type Alert struct {
        Level string
        Message string
    }
    alert := Alert(
        Level: "success"
        Message: "Successfully rendered a dynamic alert!"
    )
    if err := u.NewView.Render(w, alert); err != nil {
        panic(err)
    }
}
```
