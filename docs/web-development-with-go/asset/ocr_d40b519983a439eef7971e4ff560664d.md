Add the following handler with your other routes.

```
// Assets
assetHandler := http.FileServer(http.Dir("./assets/"))
assetHandler = http.StripPrefix("./assets/", assetHandler)
r.PathPrefix("./assets/").Handler(assetHandler)
```
