# 2.1. BUILDING THE SERVER

| Listing 2.4: Running main.go |
| $ go run main.go |

Voilà! Assuming you didn't have any errors, you now have a web app running on your computer. Open up your browser and check it out at the http://localhost:3000/. You should see something similar to Figure 2.1.

![](bbox=[0.203, 0.373, 0.796, 0.663])

Figure 2.1: Our first web application!

After you have checked out your site you can shut down the server by hitting ctrl+c in the terminal where you ran go main.go.
