## 14.5.4 Validating galleries

Just like validated users, we also need to validate our galleries before we store them in our database. Specifically, we want to validate that a UserID is always set so we know which user created each gallery, and we will also want to require a title.

We’ll start defining a type for our gallery validation functions along with a function to run them, just like we did with the user validations.

```go
$ atom models/galleries.go

type galleryValFn func(*Gallery) error

func runGalleryValns(gallery *Gallery, fns ...galleryValFn) error {
	for _, fn := range fns {
		if err := fn(gallery); err != nil {
			return err
		}
	}
	return nil
}
```

Now we can get started writing validation functions for our galleries, starting with one to ensure a UserID is set.

Note: Errors like the one we just created likely shouldn't be public as the end user has no control over what UserID is. If you would like to learn how to create a private error type similar to our modelError type check out Appendix 18.4.

Next up is the validation to ensure the title is provided.

```go
const (
  ErrTitleRequired modelError = "models: title is required"
)
func (gv *galleryValidator) titleRequired(g *Gallery) error {
  if g.Title == "" {
    return ErrTitleRequired
  }
  return nil
}
```

And finally we need to implement the Create method on the galleryValidator and have it run the validations we just wrote.

```go
func (gv *galleryValidator) Create(gallery *Gallery) error {
  err := runGalleryFns(gallery, gv.userIDRequired, gv.titleRequired)
  if err != nil {
    return err
  }
  return gv.galleryDB.Create(gallery)
}
```

If we restart our server and try to create a gallery at this point we will see a “User ID is required” error. Until we implement the code to look up the current user’s ID and set it in the UserId field we won’t be able to create galleries with our form.
