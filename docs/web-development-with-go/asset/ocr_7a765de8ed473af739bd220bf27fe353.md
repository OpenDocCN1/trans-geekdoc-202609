# 17.2 Redirecting with alerts

Whenever redirecting a user to a new page, it is common to want to also add an alert of some sort as well. For instance, after a user uploads new images to a gallery it is easier to redirect them to the edit gallery page so that their URL is accurate, but it might also be useful to provide a notification that the images were uploaded or to inform a user that they tried to upload a duplicate.

Our current application does not handle alerts and redirects at the same time. Whenever a user is redirected, any alert information is lost, and whenever we render a view with an alert we can’t redirect the user’s URL. In this section we are going to explore how to add this feature.
