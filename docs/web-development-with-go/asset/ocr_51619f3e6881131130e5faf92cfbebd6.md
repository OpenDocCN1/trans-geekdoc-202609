# 16.5. FIXING BUGS

Luckily the net/url package provides us with a PathEscape function which does just that - escapes a string appropriately for a path.

In order to add this to our template we are going to update the NewView function, adding the function like we did csrfField function, but this time we will go ahead and implement it.

```
import (
    // Add this
    "net/url"
)

func NewView(layout string, files ...string) *View {
    addTemplatePath(files)
    addTemplateExt(files)
    files = append(files, template.layoutFiles()...)
    t, err := template.New("").FuncMap{
        "csrfField": func (template.HTML, error) {
            return "", errors.New("csrfField is not implemented")
        },
        "pathEscape": func (s string) string {
            return url.PathEscape(s)
        },
    }).ParseFiles(files...)
    // the rest remains unchanged
}
```

Now we can update our edit template to use this function.

```
$ atom views/galleries/edit.gohtml
```

In our deleteImageForm template we are going to update our code to match the code below.

```
{{define "deleteImageForm"}}

    method="POST">
}}
```
