# 10.5.4 Calling Authenticate from our login action

The final piece to our authentication code is to call the Authenticate method from our login action using the data inside of the LoginForm we parsed.

```
$ atom controllers/users.go
```

When calling the Authenticate method we also need to keep in mind that this could return either an error or a user. If there is an error we will want to check for: ErrNotFound, ErrInvalidPassword, or any other error.

In each of error cases we will display a different error message, and if there isn't an error we will display the object that was just authenticated.

```
func (u *Users) Login(w http.ResponseWriter, r *http.Request) {
	// .. Leave the existing code alone here
	user, err := u.as.Authenticate(form.Email, form.Password)
	switch err {
	case models ErrNotFound:
		fmt.Println(w, "Invalid email address.")
	case models ErrInvalidPassword:
		fmt.Println(w, "Invalid password provided.")
	case nil:
		fmt.Println(w, user)
	default:
		http.Error(w, err.Error(), http.StatusInternalServerError)
	}
```

Note: We could use http.Error for every error case but will eventually replace it as it is for now.
