```
// ByRemember will hash the remember token and then call
// ByRemember on the subsequent UserDB layer.
func (uv *userValidator) ByRemember(token string) (*User, error) (
    rememberHash = uv.Hmac(token)
    return uv.UserDB.ByRemember(rememberHash)
)
```

We have created a ByRemember method on the userValidator type and moved our hashing code to it, but we have an issue. Our userValidator doesn't currently have a hmac field to hash the token.

To fix this, we need to add the hmac field to our userValidator type.

```
type userValidator struct {
    UserDB
    hmac hash.HMAC
}
```

We need to make sure we instantiate this field as well. For now we will handle this inside of the NewUserService function.
