# 578 CHAPTER 15. ADDING IMAGES TO GALLERIES

We are going to update our galleries controller to fill in the Images field when we retrieve a specific gallery.

```
$ atom controllers/galleries.go
```

We are going to add the code to our existing galleryById method so that we don't have to manually call it on pages that need images. Generally speaking we only use this method when we are intending to render a single gallery (not the galleries index page), and we tend to want all of a gallery's images in those situations.

```
func (g *Galleries) galleryById(w http.ResponseWriter, r *http.Request) (*models.Gallery, error) {
  // ... most of this stays the same

// Add this to the end of the file, right before the existing return
images, Images := g.is.GalleryByID(gallery.ID)
gallery.Images = images
  return gallery, nil
}
```

Now that we have images, even if they are just image paths, let's display them in our edit and show pages to verify everything is working.

```
$ atom views/galleries/edit.shtml
```

In the edit we will update the galleryImages template, telling it to range over the images slice and render the string for each as a list item.

```
{{define "galleryImages"}}
<ul>
  {{range .Images}}
  <li>
    {{.}}
  </li>
  {{end}}
</ul>
{{/end}}
```
