# 14.7.4 Generating URLs with params

In this section we are going to learn how to automatically redirect a user to a gallery after they create it. For example, after a user creates a gallery and it has the ID 34 assigned to it, we might manually redirect them to it with the code below.

```
gallery := ...
path := fmt.Sprintf("/galleries/%d", gallery.ID)
http.Redirect(w, r, path, http.StatusFound)
```

This would be because the Sprint function would replace the %d with the gallery ID, using us a path like "/galleries/34". The downside to this approach is that if we later changed the path to be something like "/albums/34", we would have to find all of the code like this and update it.

Rather than writing our code way, it is easier to instead write a simple function to create these paths and then use them throughout all of our code. For instance, we might use the following code to create our galleries paths.

```
func galleryPath(id uint) string {
  return fmt.Sprintf("/galleries/%d", id)
}
```
