To answer this question, we first need to look at our existing code. In main.go we have the following code:

```
r := mux.NewRouter()
r.HandleFunc("/", home)
r.HandleFunc("/contact", contact)
r.HandleFunc("/signup", userC.New)
```

If you look at the docs means for [HandleFunc] you will notice that this method turns a *mux.Route. That means we could access the return value by doing something like...

```
route := r.HandleFunc("/signup", userC.New)
// or we could chain our method calls
r.HandleFunc("/signup", userC.New).SomeRouteMethod()
```
