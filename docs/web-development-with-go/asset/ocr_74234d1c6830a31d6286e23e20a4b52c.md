our server and it will know to run the program named go inside one of the directories listed in the PATH variable.

With Go installed we are going to make a directory to store our source code in. This cannot be changed without setting a custom $GOPATH env variable, so follow exactly if you are unfamiliar with what we are doing.

```
$ cd ~
$ mkdir -p go/src
```

Test it out by running go version.

```
$ go version
```

Alternatively, you can define the absolute path to the binary when running the go command.

```
/usr/local/go/bin/go version
```

Caddy¹¹⁰ is an HTTP web server written in Go that we will be using to setup HTTPS for free using Let's Encrypt. Caddy does all of this for us, allowing us to setup your DNS server and then create a simple Caddyfile (a config file for Caddy) and start up Caddy.

Before we can use Caddy, we are going to need to build it. SSH into your server if you haven't already.
