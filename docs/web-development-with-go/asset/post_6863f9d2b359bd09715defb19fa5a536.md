```go
func (v *View) Render(w http.ResponseWriter, data interface{}) error {
	w.Header().Set("Content-Type", "text/html")
	switch data.(type) {
	case Data:
		// nothing
	default:
		data = Data{
			Yield: data,
		}
	}
	return v.Template.ExecuteTemplate(w, v.Layout, data)
}
```

In our updated code we added a switch that checks the underlying type of any data passed into. The only case we really care about is whether the data is of Data type or not. If it is of Data type we don't need to do anything. If the data is any other type we instead wrap inside of a Data object, setting this to the Yield field. In short, this is more of a convenience that will allow us to render views with code like:
