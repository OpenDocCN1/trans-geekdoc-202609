# Box 9.3. Why aren’t we deferring db.Close()?

Deferred function calls are executed when a function exits, so if were to defer closing the DB inside of our NewUserService function would end up closing the database connection right before returning the new user service. Our user service wouldn't be very useful without an active database connection, so this is likely a bad idea.

Since we aren’t closing the database connection right when we open it, it is a good idea to also write a method that will let your UserService users close the connection when they are done with it.

```
// Closes the UserService database connection
func (us *UserService) Close() error {
	return us.db.Close()
}
```
