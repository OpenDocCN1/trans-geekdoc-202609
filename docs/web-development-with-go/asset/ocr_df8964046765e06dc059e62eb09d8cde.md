Assuming you haven't already refactored, running the command should yield an output similar to the one below.

```
Renamed 2 occurrences in 1 file in 1 package.
```

This response means that gorename updated the code in two places in a single source file. Our comment right above the variable should also get updated, as gorename tries to update comments in these obvious locations.

Next we need to do the same thing for ErrInvalidPassword error.

```
$ gorename -from 'lenslocked.com/models.ErrInvalidPassword' \ \
to `ErrPasswordIncorrect`
```

Note: The backslash (\) is there because this command runs over to a second line, and the backslash tells our terminal we have more input to provide.

After running this you should see the following output:

```
Renamed 3 occurrences in 2 files in 2 packages.
```

And that is how you refactor using gorename!
