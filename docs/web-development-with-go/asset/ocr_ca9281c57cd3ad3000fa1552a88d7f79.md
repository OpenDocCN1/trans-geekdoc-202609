```
$ mkdir /root/app
$ sudo service caddy restart
$ journalctl -r
```

Note: journalctl allows us to view logs from our services, and the -r flag says to display them in reverse order so we see the newest logs first.

The output should resemble he output below, but you may have a few things like numbers, the server name, and the date and time displayed differently.

```
.. caddy[10060]: http://:2015
ncaddy[10060]: Activating privacy features... done
```

Note: Hit q to exit the journalctl logs.

We don't need caddy right now, so we can stop it.

```
$ sudo service caddy stop
```

Finally, we need to setup a Caddyfile to config our caddy service. We will be creating this in our web application source so that developers can make changes without logging into a production server, but the changes can still be pushed to the server with the next deploy, so logout of the server and head back to your local source code.

```
$ atom Caddyfile
```
