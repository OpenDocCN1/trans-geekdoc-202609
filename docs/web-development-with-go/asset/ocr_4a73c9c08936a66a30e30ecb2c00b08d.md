# CHAPTER 15. ADDING IMAGES TO GALLERIES

# 15.1 Image upload form

The first piece of code we we are going to introduce is a form to upload new images. In the past we have almost always stuck with a single form for every view we create, but for images this doesn't make as much sense.. Our users aren't going to be uploading images on their own, but are instead going to be adding them to a specific gallery.

With that in mind, we are going to add the image upload form to the edit gallery template, and then later when we introduce a way to delete images from a gallery we will also handle on the edit gallery page. This will enable our users to manage everything related from a single page.

We will be working inside the edit gallery template, so we can start by opening that source file.

```
$ atom views/galleries/edit.shtml
```

The first change we are going to make is introducing the new form for uploading images.

```
{{define "uploadImageForm"}}
<form action="galleries/{{ID}}/images" method="POST" enctype="multipart/form-data" class="form-horizontal">
  <div class="form-group">
    <label for="images" class="col-md-1 control-label">Add Images</label>
    <div class="col-md-10">
      <input type="file" multiple="multiple" id="images" name="images">
      <p class="help-block">Please only use jpg, jpeg, and png.</p>
      <button type="submit" class="btn btn-default">Upload</button>
    </div>
  </div>
</form>
{{end}}
```
