# 7.4. PROCESSING THE SIGN UP FORM

Once again, we will be making another exception to RESTful design for the sign up form. Rather than having this form submit to /users with a POST, we are going to have POST to /signup. We don't have to do this, but it is fairly common practice that I feel gives end users a better overall experience when creating a new account.

You should still have main.go open, so head to the main function inside that source file. Listing 7.19 demonstrates how to add a new route that only gets run when the HTTP method is POST.

# Listing 7.19: Adding the POST sign route

```
r := mux.NewRouter()
r.HandleFunc("/", home).Methods("GET")
r.HandleFunc("/contact", contact).Methods("GET")
r.HandleFunc("/signup", userC.New).Methods("GET")
r.HandleFunc("/signup", userC.Create).Methods("POST")
http.ListenAndServe(":3000", r)
```
