Our sign up page is going to be created in two phases.

# 7.1.1 Creating a Bootstrap sign up form

First let's head over to the Bootstrap CSS Docs and scroll down to the forms section of this page. This is where Bootstrap gives us demos for a few different ways to use forms, and shows code samples for each. If you ever need to create a new form and you are using Bootstrap (we are!) this is a great place to start as it could save you a good bit of work to figure it out on your own.

In our case, the first example - the basic example - is exactly what we want, minus the file input and checkbox sections. Awesome!
