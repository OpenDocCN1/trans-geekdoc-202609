What would happen our StripPrefix code would act similar to our middleware, first stripping the "images" portion of the path from the web, then passing the request to the next handler. In this case next handler is our imageHandler, which is a file server.

Below is the final code we will be using to create our images route and responding to it with a file server. Add it to the main function near your existing routes.

```
$ atom.go

// Image routes
imageHandler := http.FileServer(".images/")
r.PathPrefix("/images/").Handler(http.StripPrefix("/images/", imageHandler))
```

Next we are going to tweak our GalleryID method in our image service. We are updating it to prefix all paths with a leading slash (/) so that we can use these paths directly in our HTML to build valid img tags.

```
$ atom models/images.go
```

```
func (is *Image) ByGalleryID(galleryID uint) ([]string, error) {
	path := is.imagePath(galleryID)
	strings, err := filepath.Glob(filepath.Join(path, "*"))
	if err != nil {
		return nil, err
	}
	// Add a leading "" to all image file paths
	if i := range strings {
		strings[i] = "/" + strings[i]
	}
	return strings, nil
}
```
