# 14.3 Constructing many services

Now that we have two services, it is time to look at how we construct our services.

We could continue to do this as we are in our main package; that is, we could create each service individually using functions like NewUserService and New-GalleryService, but this approach introduces a problem. Doing this with our current code would result in a new database connection being created for each service.

We don't want to recreate our database connection for each of our services, but we also don't want to manage database connections outside of our models package.
