# 15.5 Serving static files in Go

Before we can show users images in a gallery, we must first implement a way to serve static files with our application. The simplest way to do this is through the use of the FileServer¹⁵ provided by the net/http package.

The FileServer function accepts a FileSystem⁶, which we can construct by converting a directory into an http.Dir type⁷, and then returns an http.Handler that we can use like any other handler.

For example, if we wanted to create a file server using the root directory we might write the following code:

```go
fs := http.FileServer(http.Dir("./"))
```

We could use this handler in our router much like we do the handlers returned by our middleware. In our case we want to create a handler for the images directory that stores our images.

```go
imageHandler := http.FileServer(http.Dir("./images/"))
```
