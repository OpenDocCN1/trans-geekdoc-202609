# 17.5.4 Controller actions and views

Next we need to create http handlers (aka controller actions in MVC) and views that will be used to render and process the reset password forms. We will start by declaring our views.

```
$ atom controllers/users.go
```

```
func NewUsers(us models.UserService email *email.Client) *Users {
	return Users{
	tNewView: views.New("bootstrap", "users/new"),
	LoginView: views.New("bootstrap", "users/login"),
	ForgotPwView: views.New("bootstrap", "users/forgot_pw"),
	ResetPwView: views.New("bootstrap", "users/reset_pw"),
	us: us,
	emailer: email,
	}
}

type Users struct {
	NewView:      +views.View
	LoginView:     +views.View
	ForgotPwView: +views.View
	ResetPwView:  +views.View
	us:           models.UserService
	emailer:      +email.Client
}
```
