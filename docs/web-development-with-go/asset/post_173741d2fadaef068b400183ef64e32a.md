### 11.3.2 Viewing cookies with Go code

Another way to read a cookie is to call the `Cookie` method on the `http.Request` object. This gives us the name of the cookie we want.

```go
func (u *Users) CookieTest(w http.ResponseWriter, r *http.Request) {
	cookie, err := r.Cookie("email")
	if err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
		return
	}
	fmt.Fprintf(w, "Email is:%s", cookie.Value)
}
```

If we are going to use our new handler function we need to add it to our router. Open up your main source file and add a route for our cookie test. Let's use the path /cookietest and limit it to just the HTTP GET method.
