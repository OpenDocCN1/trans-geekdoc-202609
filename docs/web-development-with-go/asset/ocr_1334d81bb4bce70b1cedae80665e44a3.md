The final step we need to takes is to update our NewUserService function to be the userValidator layer.

```
func NewUserService(connectionInfo string) (*UserService, error) {
	ug, err := newUserGorm(connectionInfo)
	if err != nil {
		return nil, err
	}
	return &UserService{
	UserDB: userValidator{
		UserDB: ug,
	},
}, nil
}
```

With that last change we are now ready to start implementing validations and moving code to its proper layer in our code.
