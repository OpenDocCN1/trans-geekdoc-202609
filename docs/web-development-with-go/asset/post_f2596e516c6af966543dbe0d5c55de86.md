Next we need to handle rendering the password form and prefilling it with any URL query parameters. This will enable us to send the user to the password reset form with their reset token already filled in them.

To do this we are creating a ResetPw handler that parses the URL query parameters and then renders the reset password form with that data. If no parameters are provided the fields will end up being empty, but otherwise we will have the data filled in automatically.

```go
// ResetPw displays the reset password form and has a method
// so that we can prefill the form data with a token provided
// via the URL query params.
//
// GET /reset
func (u *Users) ResetPw(w http.ResponseWriter, r *http.Request) {
	var views views.Data
	var form ResetPwForm
	views.Yield = &form
	if err := parseURLParams(r, &form); err != nil {
		views.SetAlert(err)
	}
	u.ResetPwView.Render(w, r, views)
}
```

The final function we are going to add to our users controller will be used to process the reset password form.

```go
// CompleteReset processed the reset password form
// POST /reset
func (u *Users) CompleteReset(w http.ResponseWriter, r *http.Request) {
	var views views.Data
	var form ResetPwForm
	views.Yield = &form
	if err := parseForm(r, &form); err != nil {
		views.SetAlert(err)
	}
	u.ResetPwView.Render(w, r, views)
	return
}

	user, err := u.us.CompleteReset(form.Token, form.Password)
	if err != nil {
		views.SetAlert(err)
		u.ResetPwView.Render(w, r, views)
		return
	}

	u.signIn(w, user)
	views.RedirectAlert(w, r, "/galleries", http.StatusFound, views.Alert({
	Level: views.AlertLevelSuccess,
	Message: "Your password has been reset and you have been logged in!"
	}))
}
```

In CompleteReset we first parse the form to get the token and new password.

After we have data that we can call the CompleteReset method provided by the user service to allow it to do any model-related work that needs done. Once completed, the user's CompleteReset method will return either a user with an updated password, or an error. In the case of an error we just render the reset password form again, but otherwise we know the user's password has been updated and we are going to sign them in rather than forcing them to type the password they just changed.

Lastly, we want to redirect the user to their galleries page with an alert message notifying them that they successfully updated their password.

# 17.5.5 Emailing users and building URLs
