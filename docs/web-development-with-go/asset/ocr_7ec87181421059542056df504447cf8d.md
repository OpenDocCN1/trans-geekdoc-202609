We can now continue updating the users controller. Specifically, we are going to use the user service in our Create handler to actually store a user in the database.

+   $ atom controllers/users.go

Next we update our code to create a models.User using the sign up form. We won't be using the password input yet because we don't have a proper way to store passwords, but we will fix in the next few chapters. In the meantime we will just store the user's name and email to verify everything is working as intended.

```
func (u *Users) Create(w http.ResponseWriter, r *http.Request) {
var form SignUp
if err := parseForm(r, &form); err != nil {
	panic(err)
}
user := models.User{
	Name: form.Name,
	Email: form.Email,
}
if err := u.Create(&user); err != nil {
	http.Error(w, err.Error(), http.StatusInternalServerError)
	return
}
fmt.Fprintln(w, "User is ", user)
}
```
