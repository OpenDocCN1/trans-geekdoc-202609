An additional perk is as we can easily change our database implementation or adding caching without changing most of our code. All we would need to do to add caching to our application is add a new layer between the validation and database layer that acts as a cache.

Unfortunately this approach has a flaw - by using static types our implementation becomes very brittle. We can't officially choose to use some layers in some cases, and exclude them in others.
