The last piece of code we need to write is the DestructiveReset method. This will do two things:

+   1. Call the DropTableIfExists method on the users table.
2. Rebuild the table using the AutoMigrate function.

```
// DestructiveReset drops the user table and rebuilds it
func (us *UserService) DestructiveReset() {
	us.db.DropTableIfExists(us)
	us.db.AutoMigrate(us)
}
```

Again, we won't use this reset function in production, but it will be valuable when working in development environments.
