# Preparing the dataset

The MNIST data is available with Keras. First, import tensorflow. Then define a few
constants such as batch size, the classes, and the number of epochs. The batch size can be
selected based on the RAM available on your machine. The higher the batch size, the more
RAM required. The impact of the batch size on the accuracy is minimal. The number of
classes is equal to 10 and here will be different for different problems. The number of
epochs determines when the training has gone to the full dataset. If the
loss is reduced at the end of all epochs, it can be set to a high number. In a few cases,
training longer get better accuracy. Let us look at the steps to create the dataset:

+   1. The dimensions of the input images as well follows:
