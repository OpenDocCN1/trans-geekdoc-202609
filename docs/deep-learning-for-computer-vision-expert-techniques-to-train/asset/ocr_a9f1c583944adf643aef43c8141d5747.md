# Video Classification

Optical flow measures the motion by quantifying the relative movement between the observer and scene. A detailed lecture on optical flow can be found at https://www.youtube.com/watch?v=CvyLAH8BChF8. The optical flow can be obtained by running the following command:

```
p1, st, err = cv2.calcOpticalFlowPyrLK(old_gray, frame_gray, p0,
**lk_params)
```

One stream takes individual frames and predicts using a regular CNN. The other stream takes multiple frames and computes the optical flow. The optical flow is passed through a CNN for a prediction. Both the predictions are shown in the following image:

![](bbox=[0.135, 0.345, 0.864, 0.597])

Both predictions can be combined with the final prediction.
