# PSPnet

Global content is utilized in PSPnet introduced by Zhoa et al. (https://arxiv.org/pdf/1612.01105.pdf) by increasing the kernel size of pooling layers. The pooling is carried in a pyramid fashion. The pyramid covers various portions and sizes of the images simultaneously. There is a loss in-between the architecture which enables moderate supervision.

# Large kernel matters

Peng et al. (https://arxiv.org/pdf/1703.02719.pdf) showcased the importance of large kernels. Large kernels have bigger receptive fields than small kernels. The computational complexity of these large kernels can be used to overcome with an approximate smaller kernel. There is a boundary refinement network at the end.
