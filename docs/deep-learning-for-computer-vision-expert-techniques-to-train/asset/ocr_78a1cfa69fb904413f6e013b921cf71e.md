# Training the model with data

You have defined the model and training operation. The next step is to start training the model with the data. During training, the gradients are calculated and the weights are updated. The variables have not yet been initialized. Next, start the session and initialize the variables using a global initializer:

```
session = tf.Session()
session.run(tf.global_variables_initializer())
```

The preceding two lines are required for most of the examples in this book. It is assumed that the reader will use these two lines whenever required. Now the graph is ready to be fed with data and start training. Over a loop, read the data in batches and train the model. The training is carried out by running the session with the required tensors. To update the weights:

```
for batch_no in range(total_batches):
  mnist_batch = mnist_data.train.next_batch(batch_size)
  loss_value = session.run([optimiser, loss_operation], feed_dict{
    x_input: mnist_batch[0],
    y_input: mnist_batch[1]
  })
```
