# The Multi-Attribute Facial Landmark (MAFL) dataset

The MAFL dataset proposed by Zhang et al. is annotated with 5 facial landmarks with 40 different facial attributes. There are 20,000 faces present in the database. MAFL can be downloaded from https://github.com/zhzpan/TCDCN-face-alignment. Here is a sample of the images present in MAFL:

![](bbox=[0.117, 0.246, 0.882, 0.693])

The attributes of annotation include pointy-nose, bands, moustache, wavy hair, wearing hat and so on. These images are included in the CelebA dataset as well, which will be discussed in detail later.
