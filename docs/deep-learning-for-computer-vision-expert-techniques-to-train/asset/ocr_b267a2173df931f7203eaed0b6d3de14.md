The accuracy is calculated as before but name scopes are added for correct predictions and
accuracy calculation:

```
with tf.name_scope('accuracy'):
    with tf.name_scope('correct_prediction'):
        predictions = tf.argmax(logits, 1)
        correct_predictions = tf.equal(predictions, tf.argmax(y_input))
    with tf.name_scope('accuracy'):
        accuracy_operation = tf.reduce_mean(
            tf.cast(correct_predictions, tf.float32))\n    tf.summary.scalar('accuracy', accuracy_operation)
```

A summary for accuracy is also added. The next step is to start the session and

```
merged_summary_operation = tf.summary.merge_all()
train_summary_writer = tf.summary.FileWriter('/tmp/train', session.graph)

```

Note that the graph is written once with the summary_writer. The training is very similar
before except the accuracy calculations while training and the values are added to
summaries. Next, the data is loaded in batches and training started:

```
test_images, test_labels = mnist_data.test.images, mnist_data.test.labels

for batch_no in range(total_batches):
    mnist_batch = mnist_data.train.next_batch(batch_size)
    train_images, train_labels = mnist_batch[0], mnist_batch[1]
    merged_summary = session.run({optimiser, merged_summary_operation},
        feed_dict{
            x_input: train_images,
            y_input: train_labels,
            dropout_bool: True
        })
    train_summary_writer.add_summary(merged_summary, batch_no)
    if batch_no % 10 == 0:
        merged_summary, accuracy_operation = session.run({merged_summary, accuracy_operation},
            feed_dict={
                x_input: test_images,
                y_input: test_labels,
                dropout_bool: False
            })
    test_summary_writer.add_summary(merged_summary, batch_no)
```
