# # Google Cloud Platform

Google Cloud Platform (GCP) is the cloud platform offered by Google and has similar functionalities of AWS. A simple Virtual Machine can be utilized for training the models like AWS, by following these steps:

+   1. Go to the Google Cloud Platform using cloud.google.com and log in to the platform using your Gmail account.
2. Now proceed to the console by clicking the GO TO CONSOLE button:
