# Transforming attributes

The attributes of images can be changed using generative models. A person's face can be modified to reflect different attributes such as gender, glasses, age, and so on, as shown here by Lample et al. (https://research.fb.com/wp-content/uploads/2017/11/fader_networks__conditional_attribute_based_image_generation_by_disentangling_in_latent_space.pdf):

Changing the attributes can be used for creative applications as well as for fun, and can be used for generating more training data with variations.
