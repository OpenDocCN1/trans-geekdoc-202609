# YouTube-8M

The YouTube-8M dataset is for video classification problems. The dataset contains video URLs with labels and visual features. Here are a few statistics about the dataset:

+   * Number of video URLs: 7 million
* Hours of video clips: 450,000
* Number of class labels: 4,716
* Average number of labels per video: 3.4
