Each image comes with a super label and a fine label. This dataset is available at `tf.keras.datasets` if you wish to experiment.

# The Fashion-MNIST dataset

Fashion-MNIST is a dataset created as an alternative to the MNIST dataset. This dataset created as MNIST is considered too easy and this can be directly replaced with MNIST.
