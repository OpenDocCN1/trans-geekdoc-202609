This function can be optimized using a simple optimizer, as it is convex and hence deterministic. We can also save the image at every step of the iteration. Note that this loss function is convex and so, a simple optimizer is good enough for the computation. The optimizer can be defined using the following code:

```
def optimise(optimiser, iterations, point, tensor_shape, file_name):
```
