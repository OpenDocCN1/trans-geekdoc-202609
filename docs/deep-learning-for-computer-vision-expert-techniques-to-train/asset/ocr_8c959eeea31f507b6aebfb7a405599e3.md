# Generating videos

Videos can be generated using generative models, in an unsupervised manner. The future frames can be predicted using the current frame. Ranzato et al. (https://arxiv.org/pdf/1412.6604.pdf) proposed a method for generating videos, inspired by language models. An RNN model is utilized to take a patch of the image and predict the next patch.
