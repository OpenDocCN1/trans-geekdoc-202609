# The YouTube faces dataset

The YouTube faces dataset contains 3,425 video clips with 1,595 unique people. The videos are collected from YouTube. The dataset has at least two videos per person. This dataset is considered a standard dataset for face verification in videos. The dataset can be accessed in the link https://www.cs.tau.ac.il/~wolf/ytffaces/

# The CeleFaces Attributes dataset (CelebA)

The CelebA dataset is annotated with identities of people along with 5 facial landmarks and 40 attributes. There are 10,177 unique people with 202,599 face images in the database. It is one of the largest datasets available for face verification, detection, landmark and attributes recognition problems. The images have good variations of face with diverse annotations. The dataset can be accessed in the link http://mmlab.ie.cuhk.edu.hk/projects/CelebA.html.

# CASIA web face database

The CASIA dataset is annotated with 10,575 unique people with 494,441 images in total. The dataset can be obtained from http://www.csr.ia.ac.cn/english/CASIA-WebFace-Database.html. This is the second largest public dataset available for face verification and recognition problems.

# The VGGF2 dataset

The VGGF2 dataset proposed by Cao et al. is annotated with 9,131 unique people with 3.31 million images. The dataset can be obtained from http://www.robots.ox.ac.uk/~vgg/data/vggface2/. The variation includes age, ethnicity, pose, profession, and illumination. This is the largest dataset available for face verification.
