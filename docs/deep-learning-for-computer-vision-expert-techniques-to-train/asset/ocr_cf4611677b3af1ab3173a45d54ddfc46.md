Compute the bottleneck by flattening the fifth convolution layer. The bottleneck layer is reshaped back a convolution layer, as shown here:

```
convolution_layer_5_flattened = tf.layers.flatten(convolution_layer_5)
bottleneck_layer = fully_connected_layer(convolution_layer_5_flattened, 16)
c5_shape = convolution_layer_5.get_shape().as_list()
c5f_flat_shape = convolution_layer_5_flattened.get_shape().as_list() [1]
fully_connected = fully_connected_layer(bottleneck_layer, c5f_flat_shape)
fully_connected = tf.reshape(fully_connected, [-1, c5_shape[1], c__shape[2], c5_shape[3]])
```

Compute the diverging or decoder part that can reconstruct the image, as shown in the following code:

```
deconvolution_layer_1 = deconvolution_layer(fully_connected, 128)
deconvolution_layer_2 = deconvolution_layer(deconvolution_layer_1, 256)
deconvolution_layer_3 = deconvolution_layer(deconvolution_layer_2, 512)
deconvolution_layer_4 = deconvolution_layer(deconvolution_layer_3, 1024)
deconvolution_layer_5 = deconvolution_layer(deconvolution_layer_4, 3,
activation=tf.nn.tanh)
```

This network is trained and it quickly converges. The bottleneck layer can be stored with passed image features. This increases the deasing of the database, which can be used for retrieval. Only the encoder part is needed for indexing the features. Autoencoder is a lossy compression algorithm. It is different from other compression algorithms because it learns the pattern from the data. Hence, an autoencoder is specific to the data. An autoencoder could be combined with t-SNE for a better visualization. The size of the bottleneck layer learned by the autoencoder might be larger than previous layers. In a case of diverging and converging connections are sparse autoencoders. # Denoising using autoencoders

Autoencoders can also be used for image denoising. Denoising is the process of removing noise from the image. A denoising encoder can be trained in an unsupervised manner. The noise can be reduced in a normal image and the autoencoder is trained against the original images. Later, the full autoencoder can be used to produce noise-free images.
