# Siamese networks

A Siamese network, as the name suggests, is a neural model where the network is trained to distinguish between two inputs. A Siamese network can train a CNN to produced an embedding by two encoders. Each encoder is fed with the images in either a positive or a negative pair. A Siamese network requires less data than the deep learning algorithms. Siamese networks were originally introduced for comparing signatures. A Siamese network is shown in the following image; the weights are shared between the networks:

The other use of Siamese networks is one-shot learning. **One-shot learning** is the technique of learning with just one example. In this case, an image can be shown and it can tell whether they are similar. For most of the similarity tasks, a pair of positive and negative pairs are required to train. These datasets can be formed with any dataset that is available for classification tasks, assuming that they are Euclidean distances. The main difference between these algorithms and algorithms in previous chapters is that the encoders differ from one from another.

# Contrastive loss

Contrastive loss differentiates by similarity. The feature or latent layer is compared using a similarity metric and trained with the target for a similarity score. In the case of a positive pair, the target would be 0, as both inputs are the same. For negative pairs, the distance between the pair of latent is a maximum of 0 in the case of cosine distance or regularised Euclidean distance.
