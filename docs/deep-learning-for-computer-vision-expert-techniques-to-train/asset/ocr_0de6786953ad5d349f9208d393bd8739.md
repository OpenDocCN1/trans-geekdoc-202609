# The hyperbolic tangent function

The hyperbolic tangent function, or $	anh$, is the scaled version of sigmoid. Like sigmoid, it is smooth and differentiable. The $	anh$ maps input to a value in the range of -1 to 1, as shown in the following graph:

![](bbox=[0.136, 0.222, 0.863, 0.606])

The gradients are more stable than sigmoid and hence have fewer vanishing gradient problems. Both sigmoid and $	anh$ fire all the time, making the ANN really heavy. The Rectified Linear Unit (ReLU) activation function, explained in the next section, avoids this pitfall by not firing at times.
