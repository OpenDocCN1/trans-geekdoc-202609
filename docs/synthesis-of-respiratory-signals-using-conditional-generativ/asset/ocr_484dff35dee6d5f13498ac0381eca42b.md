# 7.3.3.5 Steps

The stages for the generation of original, realistic scalograms, and synthesis of respiratory sounds are outlined as follows:

+   1. **Step 1:** Examine and analyze the given respiratory signals having integral number of time-varying frequencies using continuous wavelet transform.
+   2. **Step 2:** Produce Morse scalogram representations for various lung sounds with the aid of MATLAB wavelet tool box.
+   3. **Step 3:** Input the obtained scalograms of the original lung sound signals to Conditional GAN.
+   4. **Step 4:** Generate realistic scalogram images with the help of modeled generator network.
+   5. **Step 5:** Synthesize the original respiratory signal by giving the generated scalograms to inverse CWT.
