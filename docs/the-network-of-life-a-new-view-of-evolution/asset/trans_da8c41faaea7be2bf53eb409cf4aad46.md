

# 许多人爱吃寿司

但由于水平进化，有些人比其他人更能消化它。一种消化酶的编码通过水平基因转移，从海洋细菌转移到了日本人群的肠道细菌中。寿司外层深色的海苔，对大多数人来说难以消化，甚至无法消化，因为其碳水化合物包含陆生植物中不存在的硬化分子。这个故事的发现源于科学家在研究能够消化海苔的海洋细菌酶时，在日本人的肠道细菌中发现了相同的酶之一，而该酶在北美人的肠道细菌中却不存在。^[11](#17_notes.xhtml#chapter3-11) 这些海洋细菇很可能随海苔被摄入体内，从而实现了水平基因转移，并随之带来了对人类的消化益处。但水平进化与人类消化的完整故事远不止于此。我们肠道中大多数必需的碳水化合物消化酶都是由细菌提供的。相对较少的酶直接编码在人类基因组中，这维系着消化协作。

# 继续前行

从基因角度来说，近期人类历史中没有任何“纯粹”可言。直到现代人（智人 *Homo sapiens*）的最近亲属从化石记录中消失之前，现代人一直在与它们偶尔进行杂交（[图 3.5](#10_ch3.xhtml#fig3-5)）。从已灭绝生物遗骸中获取的遗传数据表明，我们的谱系直到约 6 万年前还在与尼安德特人（*H. neanderthalensis*）杂交，约 3 万年前还在与丹尼索瓦人（*H. denisova*）杂交。后两个独特群体究竟应被指定为现代人的亚种还是独立物种尚有争议，但不同群体间存在杂交和水平进化这一观点依然成立。这种杂交显然为我们提供了一些有益性状。提供高海拔适应性的突变被追溯到西伯利亚丹尼索瓦人，而增强角蛋白、改善皮肤和头发耐久性的突变则来自尼安德特人。当前的基因组研究证明，早期那种认为现代人种是单一祖先群体走出非洲后各自分支整齐形成的传统观点，是过于简化且错误的。相反，现代人种是各群体融合的产物，这些群体的个体拥有漫长的地理迁徙史和偶尔的杂交史。^[12](#17_notes.xhtml#chapter3-12)

# 妊娠与胎生

妊娠与胎生是人类的基本体验。它们也是水平进化的产物。它们的进化需要中和母亲的免疫系统，后者本会将胚胎视为抗原——一组不同于母体自身的外来细胞——并发起攻击。这种免疫系统的中和，一直是且仍在由胎盘哺乳动物（包括人类）与逆转录病毒之间一组令人难以置信的关系所塑造。人类基因组中约 30 亿个碱基中的 46% 源自先前的逆转录病毒感染。这包括被称为 HERV（人类内源性逆转录病毒）的序列。我们仍在了解它们的多种功能，但目前的证据表明，它们在调节母亲免疫系统对胎儿的反应以及胎盘发育中发挥着关键作用。除了哺乳动物内部妊娠的运作机制外，利用人类细胞的实验还显示 HERV 在神经元生长及其在大脑中功能维持方面也发挥着作用。^[13](#17_notes.xhtml#chapter3-13) 我们对 HERV 及其水平基因转移的“债务”可能更深远。

# 我们“上瘾”于氧气

我们“上瘾”于氧气。它可能是致命的，但我们能成功代谢它，归功于古老的水平进化。关键事件如前所述，是约 18 亿年前一种古菌吞噬了一种细菌的内共生关系，不妨称之为“吞噬”。该细菌存活下来并繁殖，随着时间的推移，其后代适应了古菌体内的生活。最终，该细菌演化出了线粒体。被吞噬的细菌此前已进化出将氧气和糖转化为能量（以 ATP，即三磷酸腺苷形式）的能力。其古菌宿主缺乏这种能力，成为了受益者。这两个谱系与其他许多谱系结合，产生了真核生物。这个早期的物种融合事件不仅是人类进化的一部分，更关乎我们的生存。

# 传染病

我们正以痛苦的方式领悟：传染病将永远伴随我们。人口增长、与微生物的频繁接触以及全球旅行，为传染病的快速传播创造了条件。特别是当病原体通过空气传播时更是如此。我们的免疫系统虽在复杂性和反应速度上令人惊叹，却可能不堪重负。为什么？因为微生物病原体在进化和逃避我们免疫防御的能力上同样迅速。导致人类流感的病毒会在彼此之间常规性地交换基因片段。这是一种重组和水平进化，使它们能够逃避免疫防御以及针对几个月前早期毒株开发的疫苗。这就是流感成为常年难题的原因。导致 COVID-19 的 SARS-CoV-2 冠状病毒展示了一种不同的、频率较低的重组和水平进化。但这些病毒的重组结合基因的快速突变，意味着免疫靶点可以迅速转移。

# 观鸟者的联系

最后，唤醒你远古博物学家的本能，思考观鸟者与水平进化的联系。认真观鸟能强迫你集中注意力。屏蔽人类的喧嚣。搜寻天空，聆听风下的鸟鸣，将物种与地形联系起来，感受季节更替。鸟类物种间的杂交（通常是最近亲）难以察觉，但比以前认为的要普遍得多。基于数据和方法的改进，鸟类物种杂交比例的估算已从 1992 年的 9.2% 上升至 2015 年的 16%。^[14](#17_notes.xhtml#chapter3-14) 后者肯定是低估，因为杂交的分子分析具有比专业观鸟者更强的辨别力，才刚刚开始。所有主要鸟类群体中均发现杂交物种（物种成员相对较少的群体除外），从信天翁到猫头鹰再到蜂鸟。杂交物种包括加拉帕戈斯群岛的各种达尔文雀、巴布亚新几内亚和澳大利亚的天堂鸟、北美和中美洲的蓝翅林莺和金翅林莺，仅举几例。^[15](#17_notes.xhtml#chapter3-15) 这对保护工作具有重要意义，因为某些物种可能因杂交而消失。尽管我们对水平进化的理解已大幅提高，仍有更多东西隐藏在显而易见之处，等待我们发现。
