

# 珊瑚礁与辅助进化

珊瑚礁也因海洋温度上升和水体化学性质改变而面临风险。这些因素对其微小的单细胞内共生体——甲藻可能是致命的，而珊瑚依赖甲藻进行光合作用和获取食物。值得注意的是，栖息在珊瑚宿主体内的这些甲藻内共生体，在更早的时期本身就被光合作用内共生体定殖过，这增加了水平进化影响的复杂性。过去 70 年里，世界上大约一半的珊瑚礁已经消失。如果必须挑选一个需要紧急护理的单一生态系统，珊瑚礁将是一个很好的候选者。

研究人员已启动努力帮助珊瑚礁应对，采用一种称为**辅助进化**的方法（[图 7.1](#15_ch7.xhtml#fig7-1)）。其中一项措施是通过替换珊瑚的内共生体物种来模拟水平进化。这可以通过用替代内共生体物种接种早期生长阶段的珊瑚来实现，这些替代物种要么是天然的，要么是经过基因工程改造，能更耐受压力。辅助进化的其他组成部分涉及筛选内共生体和宿主中基因调控或耐受压力方面的有利变化。辅助水平进化的另一组成部分是在实验室中杂交不同种类的珊瑚，并在模拟未来温度和水体化学条件的胁迫环境中监测其成活情况。加勒比海的一种天然杂交珊瑚在繁殖方面比其亲本物种表现出略微更大的成功率，表明了该方法的潜力。辅助进化的其他组成部分涉及不进行内共生体宿主转换或杂交的实验性育种选择。^([15](#17_notes.xhtml#chapter7-15))

除了上述针对珊瑚保护的应用外，微生物内共生体的替换在公共卫生方面也有应用。以*Wolbachia*属细菌为例。它们是昆虫常见的内共生体；然而，它们并不自然存在于*埃及伊蚊*（*Aedes aegypti*）体内，后者是携带并传播导致人类登革热、黄热病和基孔肯雅热病毒的蚊子。当*埃及伊蚊*在实验室中感染*W. pipientis*后，蚊子传播病毒的能力显著降低。在澳大利亚凯恩斯周边地区，*W. pipientis*感染*埃及伊蚊*八年后，登革热病例减少了 96%。在印度尼西亚日惹周边地区，感染两年后，登革热减少了约 77%；在巴西尼泰罗伊，登革热发病率降低了 69%，基孔肯雅热降低了 56%，尽管蚊子携带*Wolbachia*的感染率随时间在 40% 到 80% 之间变化。^([16](#17_notes.xhtml#chapter7-16)) 在这些例子中，应用不同物种整合自身能力的知识造福了人类种群和公共卫生。

# 基因拯救

另一种模拟水平进化的方法称为**基因拯救**，它有可能拯救因遗传多样性低和过度近亲繁殖而面临风险的物种或种群。基因拯救旨在通过引入具有互补遗传变异的新个体或新种群，来增加遗传多样性和种群增长。许多物种已经从基因拯救中受益，包括佛罗里达豹、黑足雪貂、北极狐、灰狼、各种虾、牡蛎、黑麦草和猪笼草等。^([17](#17_notes.xhtml#chapter7-17))

# CRISPR-Cas9 与基因驱动

一种称为 **CRISPR-Cas9** 的基因组编辑工具（源自细菌）也充满希望。这种编辑工具可能有助于保护物种，并潜在地保护那些需要快速进化变化以匹配快速环境变化的生态系统。^([18](#17_notes.xhtml#chapter7-18)) 利用这种方法，可以插入、删除、替换或修改基因，针对特定功能同时保留理想性状，适用于任何生物体。这类似于水平基因转移，但掌握在人类手中。然而，仅在一个或少数个体中成功编辑或重编码基因组，在有性生殖物种中不会迅速传播。这是因为后代从每个父母那里各继承一半基因。不过，可以使用一种称为**基因驱动**的技术来加速基因组编辑的传播。

基因驱动增加了特定基因或基因组被遗传和传播的概率，潜在高达 100%。这是通过将新的基因编辑与 CRISPR-Cas9 基因本身结合来实现的。结果是，被驱动的基因和编辑机制的基因全部被插入。插入位点是关键，它迫使细胞的修复系统将编辑机制添加到生物体的所有生殖细胞（精子或卵子）中。^([19](#17_notes.xhtml#chapter7-19))

基因驱动正在积极开发中，尚未广泛部署。它们引发了需要仔细考虑的安全和伦理问题。一些潜在应用仅用于加速实验室研究。另一些则针对自然界中的物种或种群，为保护以及农作物和疾病管理带来新机遇。基因驱动可用于破坏入侵害虫物种的繁殖，包括人类无意中引入岛屿的捕食者，如老鼠和蛇。在一个臭名昭著的案例中，1935 年，来自南美和中美洲的甘蔗蟾蜍（*Rhinella marina*）被引入澳大利亚以控制攻击甘蔗作物的甲虫。但外来甘蔗蟾蜍种群迅速增长并扩大了分布范围。蟾蜍天然产生的毒素无意中杀死了许多寻求食物的掠食性鸟类和爬行动物，包括几种大型巨蜥和澳大利亚淡水鳄。实施基因驱动以阻止甘蔗蟾蜍产生毒素，有助于澳大利亚本地物种生存。这比使用毒药更安全，后者会影响甘蔗蟾蜍以外的物种。

基因驱动的其他应用可能击败传播疟疾寄生虫（*Plasmodium falciparum*）以及寨卡和登革热病毒的蚊子。有人称，仅对 1% 的野生蚊子种群应用基因驱动，就能在一年内消除其相关的疟疾。^([20](#17_notes.xhtml#chapter7-20)) 未来工程化抗病性似乎也成为可能，因为可以插入破坏病毒或细菌病原体的基因。基因组编辑或重编码已被用于各种家养动植物以增强理想性状。^([21](#17_notes.xhtml#chapter7-21))
