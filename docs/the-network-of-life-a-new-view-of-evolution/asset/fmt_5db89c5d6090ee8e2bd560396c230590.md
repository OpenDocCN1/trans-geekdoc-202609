
# 传统叙事中的空白：病毒与生命起源

生命演化的传统叙事在病毒和生命起源这两个话题上基本保持沉默。这种沉默表明传统叙事已过时。自19世纪末被发现以来，病毒就被排除在生命之外。作为理解不深、结构极简（仅有一小组DNA或RNA）的专性寄生生物，它们很容易被排除在生命范畴，进而被排除在演化叙事之外。病毒仅被视为无意义历史和极少基因的流氓化学微粒。但随着我们对病毒的古老性、复杂生命周期及行为的认知加深，这一观点正在改变。

同样，生命演化的叙事始于生命已从非生命中涌现之后。从化学世界向有生命生物世界的过渡也被置于叙事之外。这可以理解：最早阶段不够“生物学”而无法纳入叙事，更重要的是，关于这一过渡的方式和历史的许多问题仍未解决。但在这里，我们的理解也在增长。

病毒起源和全生命起源这两个话题同时缺席传统叙事并非巧合。鉴于它们起始的极端古老性和对地球早期环境的持续不确定性，这些话题的知识一直且仍然难以获取。但正在取得进展，而且这两个话题似乎联系紧密。本章将讨论的一些关于病毒和生命起源的当前观点仍属推测和待检验的假设。然而，当前证据支持对其进行严肃考量，我将它们纳入演化的新叙事。它们是生命历史的基本特征，太重要而不能忽视。病毒在生命演化过程中（包括生命起源）一直是生命形式间整合的强大推动者。我还将探讨生命与非生命之间的模糊边界，以及全生物体概念——即包含宿主及其共生体的个体。

## 什么是生命？

对于生命的定义没有共识。不存在其有无能明确区分生命与非生命的物理组分或物质。惊讶吗？我们的生活经验似乎让我们成为专家。我们整天都在对什么是活的、什么不是活的做出瞬间判断。推门而不是推门边的人。踩砾石而不是踩蛇。但学习的很大一部分在于克服自我，认识到经验的局限。大多数生命形式对我们来说是不可见、无形、无声、无味的。除非我们通过显微镜观察或阅读相关资料并信任来源，否则我们不知道什么自然地生活在我们皮肤上或体内。我们也不知道我们与其他生命共享而与非生命不共享的是什么。确实，繁殖和遗传是所有生命的共同特征，但它们并非生命独有，质粒、转座子、叶绿体以及你的每个单个细胞等各种非生命实体也具备这些特征。随着关注点转向边界情况，定义生命的难度从容易变得令人望而生畏。

然而，广泛认同的是生命是一个过程、一个随时间演化的系统（[Box 4.1](#11_ch4.xhtml#box4-1)）。生物学家倾向于关注生物体层面的过程和系统，如新陈代谢、生长、遗传、繁殖、自然选择和演化来描述生命。而化学家和物理学家常采取更普遍的自持化学系统视角。当我们将生物体还原为其组成化学元素时，这些观点是兼容的。抛开希望和梦想，你我99%由氧、氢、氮、碳、钙、磷组成，并含微量硫、钾、钠、氯、镁。若非生命那惊人的自持过程和系统，我们将如石头般毫无生气。

将生命视为由过程和系统而非物理实体构成的观点尚未成为主流，但正在接近。物种和生物体是短暂的，而过程随时间持续。过程和系统更基础，且被所有生命多样性独特地共享，这与任何特定的物理性状或物质不同。生物体本身包含从发育到代谢和繁殖的过程和系统，最好在此背景下理解。例如，理解一只个体青蛙需要理解其生命周期变化，从发育中的胚胎到蝌蚪再到成蛙。仅理解成蛙是对生物体的不完整视角。这一视角在理解病毒方面变得重要，如下所述。

所有已知生命都围绕能自我复制的DNA或RNA分子为中心。这些是携带遗传信息的复制子。此类复制子的完整集合包括所有熟悉的真核生物（如我们）、古菌和细菌等生命形式。但也包括一系列听起来神秘的实体，称为可移动遗传元件（MGEs）。MGEs通常编码介导其自身在基因组内或不同个体甚至不同物种基因组间移动的蛋白质，也能介导其他DNA的移动。MGEs具有不同程度的自主复制和繁殖能力。这包括产生复制和组装后代所需的核苷酸和氨基酸（资源）能力的差异。因此，并非所有复制子都能自主繁殖，那些不能的被视为非生命和寄生性。

演化学家Koonin和Starokadomskyy提出了一种范式来理解和组织这些复制遗传元件的多样性。[Box 4.2](#11_ch4.xhtml#box4-2)描述了各种复制子和MGEs，[Figure 4.1](#11_ch4.xhtml#fig4-1)展示了其自主性两个指标的变化。纵轴表示其产生复制和组装后代所需核苷酸和氨基酸资源的相对能力。横轴表示基于载体存在与否及载体类型（病毒或细胞）的MGEs移动自主性。载体促进资源获取和后代传播。细胞器包括线粒体和叶绿体。

我们对MGEs及其作为水平演化推动者（在生物个体和物种间移动DNA）的工作的日益深入了解，表明它们在强调整合的演化新叙事中的角色。例如，许多个体生物的基因组已知基因数少于其种群整体。即，一个物种或微生物菌株内发现的并非所有基因都存在于所有个体中。一个物种或菌株的完整基因集称为其泛基因组，所有个体共享的基因子集称为核心基因组。泛基因组规模更大、包容性更强，部分源于MGEs在不同个体中运作方式不同，导致基因差异性获得或丢失。早期泛基因组研究必然聚焦于基因组相对较小的细菌和病毒。然而近期工作显示真核生物中也存在泛基因组。[Table 4.1](#11_ch4.xhtml#tab4-1)展示了各类群核心基因组大小（占泛基因组百分比）的已知范围。例如，人类和其他哺乳动物常见肠道细菌大肠杆菌的核心基因组仅包含泛基因组的8%。总体而言，细菌的核心基因对生物体生命至关重要，而非核心基因常与毒力、防御反应和通讯相关。
