
# Legacy DAS Solutions and SDS

Legacy DAS solutions do not provide many storage features for better performance and availability. However, the SDS component can be deployed on top of it to make it more intelligent. Using SDS, virtual volumes can be carved out with different RAID levels from the legacy disks. Other storage services, such as snapshot, deduplication, and compression, are also available with the latest SDS solution.

## Solution

SDS solution is recommended for this requirement. This is a software component of a VM that can be procured and deployed on to the legacy hardware to implement a high-performance and high-availability storage solution.

# Glossary and Key Terms

- **Storage disk array**: A storage system with independent physical disks behind one or more controllers that allows configuring virtual volumes or RAID volumes.
- **JBOD**: Just a Bunch of Disks. A disk enclosure that holds a number of physical disks connected to one or more controllers.
- **SFF**: Small Form Factor, 2.5-inch hard drive.
- **LFF**: Large Form Factor, 3.5-inch hard drive.
- **SSD**: Solid State Drive, a high-performance disk drive with no mechanical moving components.
- **SCM**: Storage Class Memory, a high-performance storage device.
- **HDD**: Hard Disk Drive, stores data on magnetic media.
- **AFA**: All-Flash Array, a storage disk array with SSDs.
- **SDS**: Software-Defined Storage that decouples storage services from underlying hardware.
- **NVMe**: Non-Volatile Memory Express.

# Chapter 3: Storage Disk Array

## Introduction

A storage disk array is a storage system that consists of a pool of physical disk drives and one or more storage controllers, which stores terabytes of data and performs multiple host server's input/output (I/O) operations. Storage vendors design and implement several features in storage systems to improve read/write performance and data fault tolerance. Some of those features are controller operations, data caching techniques, RAID concepts, and so on. RAID implementation in storage systems has greatly influenced both performance and fault tolerance aspects of a storage system. For this reason, in the last three decades, all storage vendors have been implementing it in their storage systems. Modern storage disk arrays implement Virtual RAID, which enhances performance and fault-tolerant factors to a greater extent.

Apart from RAID, disk arrays also have several intelligence features implemented to provide highly optimized I/O processing, fault tolerance, and efficient storage capabilities. Some of those features are storage tiering, quality of service (QoS), replication, thin provisioning, deduplication, and compression, among many others. These features are discussed in detail in the following chapters.

Therefore, storage arrays are referred to as Intelligent Storage Arrays (ISA) or Intelligent Storage Systems (ISS).
