# # 基于深度学习的图像超分辨率重建研究

近年来，深度学习在计算机视觉领域取得了显著的成果，特别是在图像超分辨率重建任务中。深度卷积神经网络（CNN）能够从低分辨率图像中学习到高分辨率图像的映射关系，从而实现高质量的重建效果。本文旨在综述基于深度学习的图像超分辨率重建方法，并探讨其在实际应用中的潜力。

+   - 传统的插值方法
+   - 基于重建的方法
+   - 基于学习的方法

| 方法 | 类别 | 特点 |
|------|------|------|
| SRCNN | 深度学习 | 端到端训练 |
| VDSR | 深度学习 | 残差学习 |
| ESPCN | 深度学习 | 亚像素卷积 |
