
本研究假设小规模企业因其可持续发展价值和动机，更有可能在供应链的数字化转型中取得成功。这些因素在 DPPB 对英国一家小型有机时尚品牌的试点研究中得到了鲜明体现。参与 DPPB 的试点表明，该品牌公开且充满热情地验证其主张。当被询问为何选择在（更为简单的）自我披露之上实施区块链技术时，他们回答说是为了获得保障，确保其信息经过验证、安全且符合法规要求，无论监管环境如何。值得注意的是，他们最初愿意参与试点的动力来源于其价值观和动机，包括对可持续供应链及其运营的自豪感。尽管如此，成本仍然是一个障碍。不过，只要价格合理，该品牌仍会投资于该技术，因为这将减少其需处理的任务数量，并能确保“无忧”合规。事实上，降低诉讼风险似乎是促使品牌采用并支付技术服务费用的最大驱动力。在此阶段，尚缺乏证据表明，通过更高效、风险更低的供应链实现成本节约能够激励时尚企业投资。

在询问利益相关者的费用时，创始人谈及 DPPA 的再生商业模式，称之为“数字生态系统”。创始人强调，这种全新的再生模式为制造商、品牌和消费者三类利益相关者带来了多元化的价值主张。DPPA 的再生商业模式建立在激励原则的基础之上。DPPA 现有的数字生态系统为（从而激励）所有参与方带来利益，进而促使品牌将资源分配至创新，以提升其现有商业模式（即 CEO 所说的“再生”）。这一观察凸显了价值驱动型组织的潜在影响。DPPA 案例展示了时尚品牌在采用再生商业模式时的双重优势。首先，它展示了技术作为有利补充的潜力，研发费用得以分摊。其次，可通过在有韧性的数字生态系统中进行协作协议，实现互惠贡献，从而推动解决方案的发展（[Rennie et al., 2019](#ch1.xhtml#ref61)）。这表明企业倾向于摒弃传统的市场策略，以寻求互惠互利的协同效应。对组织文化的重新审视标志着时尚供应链领域的转变。

虽然以激励为驱动的再生商业模式看似是新兴趋势，但当前的商业环境更聚焦于循环模式。然而，许多企业缺乏足够的数字化能力，难以有效参与能够带来财务收益的循环业务，这可能导致这些策略被排除在战略考量之外。对产品售后去向缺乏了解的公司，其参与循环实践的意愿和能力也随之下降。缺乏独立管理转售、租赁和维修活动的能力，以及缺乏参与已有计划所需的数字素养的品牌，将错失财务收益和机遇。DPPB 认识到这一点，因而与一家转售技术初创公司合作，为品牌提供更具价值的完整解决方案。通过承担这项额外任务，DPPB 正在满足在闭环和开环循环系统中携带个体 ID 的需求。但这也带来了诸如自动化数据摄入和互操作性等挑战——即软件程序之间能够相互识别并交换程序语言和协议的能力。DPPB 通过采用先进技术，特别是人工智能（AI），并侧重于低/无代码解决方案的集成，来应对这些挑战。这提升了透明度和循环经济模式的可及性，使资源受限的微型企业和中小企业更易于接触。DPPB 在试验其转售业务及品牌时，不仅寻求激励，更在寻找消费者可部署的解决方案，例如利用预加载数据来转售服装废弃物。

与此同时，随着先进技术的出现，至少可以借助这些技术向企业传递可持续实践，从而获益。例如，消费者感兴趣的额外信息可以在以前的能力之上得到验证，进而提升企业形象，增强品牌声誉，并规避不 warranted 的绿色漂绿（[de Freitas Netto et al., 2020](#ch1.xhtml#ref21)）。此外，中小企业通过推广可持续实践业务模式，能够呈现更积极、多层面的公开与责任形象（Todeschini et al., 2017）。通过更深入的知识，可确定可持续 SCT 的改进空间，最终实现系统性的更好变革。
