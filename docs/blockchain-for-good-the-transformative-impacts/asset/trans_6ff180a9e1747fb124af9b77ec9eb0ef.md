
一个由区块链在 CO3 项目中集成所提供的机会之一是将其用作公证工具。由于其时间顺序结构、对篡改攻击的强抵抗性以及透明度，区块链是一种理想的公证工具，用于以安全且可验证的方式记录信息。此外，利用智能合约（自动执行的代码编写的协议）来创建和分发代币，这些代币实现高度定制化和自动化的价值交换，是一个吸引人的机制，能够在用户之间建立信任，并鼓励他们开展新形式的协作工作。关于更具体的共创和创新过程，一个有趣的应用是通过代币化无形资产（如想法和知识产权）进行交换，从而使它们变得流动且可转让。

在 CO3 项目中，参与者通过个人钱包访问和使用区块链。CO3 中的交易由可互换代币（作为硬币）和不可互换代币（作为优惠券）实现，两者均以符合 ERC20 标准的合约形式呈现。*硬币* 模拟互补货币的行为。*优惠券* 用作单个实体（如商品、折扣券或活动入口）的数字孪生。代币和优惠券的创建者决定其价值，对于优惠券，他们决定其代表、提供或赋予访问权限。用户要么用法币购买代币，要么作为礼物或奖励获得代币。众筹（crowdsale）功能允许本地行动者创建筹款或团体购买活动，创作者提供代表对商品、服务或活动访问权的优惠券。参与者提前用硬币购买优惠券，因此参与者必须拥有一定数量的本地硬币。当收集到的硬币数量达到最低阈值时，众筹成功，底层智能合约会自动将优惠券从参与者的钱包中转移。优惠券箱（coupon box）功能让用户创建包含优惠券的虚拟箱，无需用代币购买即可向其他用户提供。创建者决定可用的优惠券数量，既不设定价格，也不设定目标（与众筹不同）。创建新硬币、优惠券、众筹和优惠券箱的权限仅限于拥有特定协调或其他特定角色的社区或城市公共领域用户。所有用户均可转移代币、参与众筹并使用优惠券箱。代币可以通过现场交换二维码（QR 码）或通过共享二维码深链或用户个人资料远程转移。用户随时可在钱包中查看交易历史。用户可通过点击其在 FirstLife 地图（地理定位社交网络）中的视觉呈现（AR 对象或地图实体）来访问众筹和优惠券箱（[第 2.3 节](#ch2.xhtml#sec2_3)），该地图集成在 ACA 内部。

基于加密代币和智能合约的这些工具和功能组合，使不同种类的代币化社会经济和代币化共同治理过程得以实现，如图 6.2 所示，展示了图尔和雅典试点项目中的不同情景（第 3 节）。

### 2.3 增强公民互动

区块链上的价值交易由促进共生和共享过程的其他社会互动所补充：信息共享、协作计划、审议过程、公民参与以及促进公民参与。这些互动由 CO3 平台的特定组件实现。

FirstLife 是一个基于地理位置的公民社交网络（Boella 等，2019），提供基于地理位置的交互地图，具备信息和协调功能。它允许用户与本地动态互动，使公民能够通过近距离连接和互动，并将内容定位到特定的城市地点（街道、建筑、公园）。FirstLife 的主要界面由一张地图组成，参与 ACA 的用户可以在其中发布“实体”，以及一侧墙显示不同实体的摘要卡片。单个实体可通过点击地图标记或在墙上的摘要卡片来打开，从而显示其所有属性（如分类、描述、关联 URL 等）。实体是用户分享提案、活动、新闻、添加二层资源（如评论、附件、照片等）以及对其他用户发布内容进行反应的虚拟空间。FirstLife 设计用于作为不同利益相关者（如公共管理部门、协会管理者和公民）的协调工具，用于共享信息并协作开展具有本地和城市层面公共意义的活动。在 CO3 中，例如，普通公民可以创建一个“任务”实体来宣布待完成的活动；其他社区成员可通过在数字实体上进行签到（以及签出）来承担任务。本地零售商可以在特定位置创建一个“优惠券箱”实体，其他用户可通过与区块链钱包组件的集成来兑换其中的优惠券。用户还可以创建图片、新闻和众筹等其他实体。FirstLife 是一款可通过浏览器在台式或移动设备上访问的 Web 应用，并作为原生移动应用内置的 Web 视图实现。

液态反馈（LiquidFeedback）提供互动民主功能（Behrens 等，2014），这是一款成熟的开源软件，自 2009 年起持续活跃开发。LiquidFeedback 使新的民主参与形式覆盖整个审议过程，从提案草案的最初提出到最终决定。具体而言，平台支持液态民主，使用户可以直接参与决策过程或选择代表。在审议期间，可能会出现多个替代或竞争的提案，这些提案通过偏好投票机制进行表决。LiquidFeedback 旨在让每位参与者在决策过程中拥有平等的权利和机会，不允许任何参与者因moderating 讨论或主导决策过程而拥有特殊特权。因此，ACA 参与者可以参与关于将在城市公共领域实施的提案或活动的民主决策，或参与将在城市区域内激活的服务的决策。
