
成本影响使我们回到规模的问题。区块链潜力的认可已广泛存在。然而，扩展 Web3 技术的挑战是一个复杂的问题，困扰着行业专业人士、解决方案架构师和学者 (`[Caldarelli et al., 2021](#ch1.xhtml#ref12)`)。有人把这个挑战称为“区块链的月球竞赛” (`[Kenny, 2019](#ch1.xhtml#ref38)`)，这表明初创企业之间竞争要率先进入市场——或者至少是率先获得广泛接受。透明模式的推广需要建立技术基础设施并修订合作条款。这一点尤其重要，至少因为即将出台或已经实施的立法，最主要是因为迫切需要实现可持续发展目标 (SDG)。值得注意的是，欧盟委员会——作为多数合规法规的推动力——并不期望企业投资于昂贵的技术。它建议所有操作均可在电子表格上手动完成 (`[Legardeur and Ospital, 2024](#ch1.xhtml#ref42)`; `[CIRPASS, 2023](#ch1.xhtml#ref16)`)。然而，这在大多数企业看来是不可行的，尤其是在需要细粒度处理时。识别单个产品本身就是一个巨大的任务，即便是小公司也难以完成。Aura 区块链联盟声称已经在时尚产品上存储了 4000 万条数据点 (`[Bain, 2024](#ch1.xhtml#ref4)`)。根据 `Schatsky`、`Arora` 和 `Dongre` (2018) (`[ch1.xhtml#ref65]`) 的研究，区块链技术采用的主要障碍是其交易处理速度缓慢，这限制了其效能。因此，许多人建议区块链应在批量层面部署，而非在单个标识符层面。基于案例研究的发现，DPPA 和 DPPB 都已与中小企业 (SMEs) 合作设计、测试并评估个别项目层面的应用，但这些仍是数量有限的试点。此外，系统无法在批量层面部署——因为每件服装都有转售潜力，并且拥有独特的产品历史。这引发了疑问：为什么联盟不共享信息以降低数据收集负担？例如，可在通用部件（如拉链和纽扣）上共享信息——这些部件本身并不构成竞争优势，但在产品回收阶段却极具意义。此时，尚无明显的共享产品信息平台的前瞻性思考。理想情况下，这些数据应通过区块链存储，以确保去中心化访问。

尽管如此，基于其试点，DPPA 已达到显著的可扩展阶段。它是本研究两家提供商中更先进的解决方案。DPPA 目前正与巴基斯坦的一家牛仔服装制造商合作：

> 令人惊讶的是，我们的初步分析显示，实现该应用的可行性在大型供应链中明显高于小型供应链。因此，我们目前正在开发用于企业资源规划 (ERP) 系统的集成工具。该开发旨在提供无缝的即插即用功能，与我们持续的工作相吻合。

Levi’s 与 DPPA 的合作证明了后者能够提供可在规模上落地的可行方案，这直接挑战了 `Schatsky` 等人 (2018) (`[ch1.xhtml#ref65]`) 所指出的技术可行性和联盟扩展障碍。但必须承认，这种可扩展性的进步只能在愿意交换数据、拥有更公平的权力结构并比当前标准更具合作精神的时尚供应链内实现 (`[Heim et al., 2022](#ch1.xhtml#ref36)`)。如前所述，DPPA 与 Levi’s 有制造关联，因此能够利用这一安排，并共享战略价值。

DPPB 的方案考虑了企业在收集、清洗和检索相关数据所付出的努力。DPPB 认为数据分析是供应链数字化转型的“重头戏”。数据分布在各公司系统和部门之间，或掌握在供应商手中。品牌依赖技术提供商的平台来添加信息、生成报告、更新 ID 等。这种“软件即服务”(SaaS) 模式已经相当普遍，例如在企业或库存管理系统、产品生命周期管理系统 (PLMS) 以及会计软件中。DPPB 致力于尽可能整合系统，以促进互操作性并避免重复劳动——从而也降低业务交易成本。总体而言，实现供应链透明度所需的有效数据收集、存储和共享的数字生态系统尚未得到 definitive 解决，仍是本研究的技术初创企业及其时尚客户面临的挑战。但所有相关方对正面结果的渴望是一致的，这很可能会推动更快的变革。

大规模实现 SCT (供应链透明度) 是可行的，但目前由于技术持续发展，只能通过与共享相同目标和价值观的业务合作伙伴建立连接来实现。DPPA 争取“前瞻思维的品牌”参与，表明其认识到自身组织文化与目标相似。正如本研究的发现所示，建议时尚企业对与技术公司建立合作伙伴关系保持开放态度，而不是把技术视为应对供应链透明度 (SCT) 相关挑战的被动措施。DPPA 首席执行官还指出时尚企业内部技术资源的不足：

> 即使是知名公司也常常缺乏内部技术部门，若拥有该部门，其重点通常集中在在线零售平台的开发与维护上，往往水平较低。我们团队的一个优势在于其由三个领域的专家组成：纺织工程、技术工程和研究。

因此，技术并非可扩展性的唯一障碍。研究结果表明，要在大规模上有效实施 SCT，还必须在组织层面推动文化变革。这可以通过倡导拥抱数字生态系统思维的好处来实现，即时尚与技术企业作为单一实体共同努力。该转型需要从以市场为导向的文化转向以价值为导向的文化，将创新置于优先位置。或者，时尚企业可以与具备这些特质的组织建立灵活合作。
