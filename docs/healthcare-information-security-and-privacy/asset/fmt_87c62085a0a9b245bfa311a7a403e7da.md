
# 医疗网络安全劳动力现状

医疗网络安全劳动力处于短缺状态，其状况比其他行业更为严峻。众多医疗行业调查表明，医疗行业在采用安全控制和实践方面滞后。因此，医疗行业在雇佣合格的网络安全劳动力成员方面也落后于其他行业。造成这种情况的原因有据可查。首先，医疗行业的核心业务是医疗服务，而非网络安全。因此，高层管理人员（CEO、CFO 等）传统上专注于推动收入增长或改善临床结果的举措，这完全合理。过去 20–25 年来，随着电子健康记录（EHR）实施和影像归档与通信系统（PACS）技术展示了投资回报率（ROI），医疗信息技术开始获得更多投资（就 EHR 而言，ROI 来自《美国复苏与再投资法案》的报销）。信息安全充其量只是一项成本，最坏的情况下被视为阻碍以增加收入或改善临床结果为重点的举措。情况已然改变：糟糕的网络安全投资或缺乏投资的后果已引起董事会级别的关注。虽然仍需证明 ROI，但考虑到数据泄露的成本，这变得更容易了。了解美国平均数据泄露事件给医疗机构造成约 540 万美元的调查、修复和通知成本，是一个重要的数据点。^([3](#ch10.html#ch10en3)) 该数字还包括政府监管机构的罚款和处罚，一旦公开，将损害组织声誉，并因患者选择其他就医方案而对未来收入产生负面影响。

在此背景下，56% 的信息技术领导者估计其信息安全工作人员太少。^([4](#ch10.html#ch10en4)) 其中 4% 的受访者来自医疗行业。其他研究表明，总 IT 预算中分配给信息安全支出的比例很小，尽管趋势正在上升。这种投资不足可能与医疗网络安全关键岗位缺乏合格人员有关，或导致这一结果。由于内部威胁或员工行为以及第三方业务合作伙伴仍是医疗数据泄露的主要原因，缺乏胜任力可归因于这些信息丢失和盗窃问题。

与 NICE 的做法类似，国家卫生信息共享与分析中心（NH-ISAC）正在解决医疗网络安全劳动力胜任力问题。NH-ISAC 正在利用 NICE 指南开发一个框架，但该框架专门用于培养未来的医疗网络安全工作者。NH-ISAC 的目标是：

- 增强私营和公共部门的安全韧性（预防、保护、缓解、响应和恢复）
- 扩大安全意识和劳动力教育（培养国家网络安全劳动力）
- 改进安全领先实践（NIST 网络安全框架、标准和认证机构、安全技术创新者）^([5](#ch10.html#ch10en5))

全球各行业对网络安全专业人员的需求包括认识到医疗行业也需要此类人才。随着数据泄露频率和严重性的增加，以及数据收集者和政府官员面临的公众尴尬，紧迫感日益增强。这还加上政府开始对医疗机构征收的罚款和处罚。2013 年，英国政府因国家医疗服务体系（NHS）不当处置含有 3000 多条记录的废弃电脑，处以 20 万英镑罚款。这些电脑最终在 eBay 上出售。^([6](#ch10.html#ch10en6))

从众多信息隐私和安全事故中，另一个例子来自加拿大。2013 年，一台未加密的笔记本电脑被盗，其中包含阿尔伯塔省 62 万名患者的个人健康信息。政府官员引用人为错误、缺乏政策和程序、以及不成熟的信息安全治理，作为不仅需要更好地教育所有工作人员保护健康信息，还需要在医疗机构招聘和留住合格的信息安全和隐私专业人员的证据。

## 技能组合的融合

与大多数处理敏感信息并从纸质跨越到数字化的其他行业不同，医疗行业主要在内部培养其网络安全劳动力。许多承担网络安全职责的专业人员接受过培训，并在通常与信息技术无关的领域积累了经验。其他行业（如银行和零售）很可能从服务台人员、网络运营或软件开发人员中获取网络安全资源——即使这些资源是在组织内部开发的。在医疗行业，今天的网络安全劳动力可能来自信息技术背景，即使是在医疗行业之外。然而，同样可能来自生物医学工程或健康信息管理背景。此外，非 IT 或非网络安全人员（如风险管理人员、法律人员和合规办公室人员）在组织的事件响应流程中发挥关键作用，并在与信息安全问题相关的信息治理结构中担任关键职位，这并不罕见。

## 生物医学工程师

生物医学工程是设计、安装、维护、保护并协助安全运行医疗设备、系统和网络的专业。这些专业人员接受过系统设计工作和工程问题解决的培训并拥有经验。他们还特别擅长将这些概念应用于医疗设备，以安全地治疗患者。随着医疗设备变得更加数字化、互联和复杂，生物医学工程人员已演变出与信息技术和网络安全专业人员相似的能力。因此，在医疗机构中，这三个社区之间建立包容性关系是最佳的。

生物医学工程师始终关注医疗设备的安全运行。当这些设备是独立设备、仅连接患者时，安全性更多涉及机械故障而非其他。随着医疗设备集成微处理器、在网络上使用 IP 地址并演变为专用计算机，它们承担了网络安全隐患。由于这些网络安全隐患在设备产生不准确结果或完全无法运行时往往会导致患者安全问题，生物医学工程师需要获得网络安全能力。例如，生物医学工程师现在负责涉及医疗设备的访问和认证流程。他们还可能负责保护分段医院网络上医疗设备飞地的边界安全设备。最重要的是，生物医学工程师是安全医疗设备软件漏洞管理计划的关键组成部分。生物医学工程师有责任与医疗设备制造商协调，确保补丁经过测试和批准。一旦批准，补丁可由制造商或内部生物医学工程团队应用到医疗设备上。在涉及医疗设备的各种信息安全问题的决策过程中适当纳入生物医学工程师，可以避免挫折、患者安全问题和临床医生的沮丧情绪。^([7](#ch10.html#ch10en7))
