# 第11章：管理风险管理与网络安全

**罗布·戴维斯**

在本章中，您将学习如何：

- 使用有组织的方法了解外部网络安全攻击的剖析
- 理解风险管理框架在网络操作中的应用
- 理解检测能力为风险缓解提供的作用
- 了解整个组织的事件响应和恢复
- 在医疗保健中应用量身定制的风险评估考量与平衡，以实施补偿性控制

---

医疗保健领域见证了技术的巨大爆发，这些技术已融入患者的日常护理中。由信息技术（IT）部门集中管理的台式机、笔记本电脑和服务器等传统计算设备正在迅速消失。智能手机、医疗设备等正在模糊计算和通信能力的界限，将来自无数来源的信息传播到网络的各个角落。结果是，传统IT之外的专业人员在各个层面都参与了安全工作。大多数医疗保健组织全天候提供护理，这意味着网络始终在运转。个人健康信息（PHI）也在持续地被存储、访问和传输。因此，我们拥有了关键任务、多种不同视角、庞大的网络足迹以及来自四面八方的个人信息这些要素，构成了网络安全“完美风暴”的配方。

在本章中，我们将根据可用的资源和工具，以务实的方式应对这一艰巨挑战。将剖析网络攻击的结构，以便更好地理解问题。对于许多医疗保健隐私和安全专业人员来说，这可能是他们第一次近距离观察网络安全攻击的实际运作。最后，将提供从业者关于应用风险管理框架保护网络的视角。

### 攻击

在网络安全领域，我们往往关注自身，因为攻击者似乎近乎神话般的生物，趁我们不备时前来掠夺。直接的反应是加固防御，制止这种不公。然而，这只是方程式的一方面，我们必须给予对手同等的考量。网络攻击的剖析如[图11-1](#ch11.html#ch11fig1)所示，并在本章其余部分中被引用。

#### 网络攻击的剖析

[图11-1](#ch11.html#ch11fig1)中概述的程序是整合了多个网络事件最佳实践框架描述的结果，例如洛克希德·马丁公司的“网络杀伤链”，该术语实际上源自美国空军在提及远距离发起的空袭等任务时常用的行话。^([1](#ch11.html#ch11en1)) 在网络安全领域，该术语长期以来被用于描述外部威胁的攻击面。空军描述杀伤链过程的方式与网络攻击的发生方式相似，因为针对医疗网络的大多数对手都源自遥远的其他网络。“杀伤链”作为描述词听起来很酷，确实能吸引注意力，后者可能是它有时被使用的原因。网络攻击剖析相关的另一个例子是卡内基梅隆大学的网络态势感知（cyberSA）。网络态势感知意味着对计算环境和随时间发生的事件及其影响有认知。态势识别包含以下要素：对网络攻击类型的感知、攻击源（谁、什么）和攻击目标；态势理解，即理解当前态势为何以及如何发生及其影响；态势预测，涉及确定未来攻击的预期、位置及其影响。^([2](#ch11.html#ch11en2)) 此处呈现的框架还包括作者和其他人的个人经验。总之，本章概述的攻击序列旨在包含多项行业最佳实践。

#### 外部投递

如果目标是完全防护万维网上的所有恶意行为，那么只需断开互联网连接，但我们都知道，在当今这个无处不连接的世界里，这是不可能的。我们每天都依赖电子邮件、第三方提供商、银行转账等来开展业务，因此恶意软件通过这种与外部世界的连接进入网络几乎是不可避免的。
