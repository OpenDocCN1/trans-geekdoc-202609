
# 保护医疗信息

保护医疗信息是全球关注的问题。在美国，有特定法律来管辖医疗信息的处理。在国际上，法律专门针对医疗信息，尽管通常是在保护所有个人信息的背景下。隐私法规和控制涵盖个体识别信息，医疗信息包含在内。将一些选定的国际框架与现行的美国标准进行比较是有用的。

## 经济合作与发展组织隐私原则

经济合作与发展组织（OECD）总部设在法国，已围绕所有29个成员国应遵循的一般原则制定政策，旨在促进国际贸易。美国是OECD的成员国，也是其2亿美元年度预算的最大资助国之一。

OECD框架对收集、存储和使用个体可识别信息的公平信息实践进行了分类。其目的是帮助个人参与其自身信息的使用。这些原则将保护信息的责任分配给收集和维护信息的实体。当你熟悉美国和国际数据保护法律时，你会发现以下原则已很好地融合其中：^([10](#ch3.html#ch3en10))

- **收集限制原则**：应对个人数据的收集加以限制，任何此类数据的获取应通过合法和公平的途径，并在适当情况下征得数据主体的知情同意。
- **数据质量原则**：个人数据应与其使用目的相关，且为实现这些目的所必需的范围内，应准确、完整并保持最新。
- **目的明确原则**：收集个人数据的目的应在数据收集时或之前明确规定，后续使用应限于实现这些目的，或用于与这些目的不冲突且在每次变更目的时指明的场合。
- **使用限制原则**：除以下情况外，不得为特定目的以外的目的披露、提供或以其他方式使用个人数据：
  - 经数据主体同意
  - 依法律授权
- **安全保障原则**：个人数据应通过合理的安全保障措施加以保护，以防止数据丢失、未经授权的访问、销毁、使用、修改或泄露等风险。
- **公开原则**：应就个人数据的发展、实践和政策保持总体公开政策。应能随时获得确认个人数据存在及其性质、主要用途，以及数据控制者身份和管辖权的途径。
- **个人参与原则**：个人应有权做以下事情：
  - 从数据控制者处获得确认，或以其他方式确认数据控制者是否持有与其相关的数据
  - 在以下参数范围内，获得与其相关的数据通知：
    - 在合理时间内
    - 费用（如有）不得过高
    - 以合理方式
    - 以其易于理解的形式
  - 如果个人访问其信息的请求被拒绝，应被告知理由，并能对该拒绝提出质疑
  - 对与其相关的数据提出质疑，如果质疑成功，可要求删除、更正、完全修改或加注说明（在患者和提供者意见不一致的情况下）
- **问责原则**：数据控制者应对遵守落实上述原则的措施负责。

## 安全港协议

与OECD原则及其对国际贸易的影响相关的是安全港协议的监管框架。从欧盟的角度来看，数据传输只有在作出“充分性”认定时才能进行，换句话说，收集数据的实体必须具备充分的隐私流程和保障措施。欧盟不会自动向非欧盟成员国（如美国或加拿大所做的那样）授予这种充分性保证。为促进数据传输、推动国际贸易并弥合隐私差异，欧盟和美国（通过商务部）制定了一个满足充分性要求的安全港框架。^([11](#ch3.html#ch3en11)) 请参阅[图 3-3](#ch3.html#ch3fig3) 了解安全港差距评估流程的概览。

可以肯定的是，美国和欧盟在隐私和安全方面有不同的方法。然而，双方都致力于保护信息。这一安全港流程并不意味着美国缺乏隐私和安全控制。美国采用行业视角。有特定法律管辖各个行业（例如医疗行业的HIPAA）。监管方式是这些法律与一定程度的自愿自我监管相结合。然而，欧盟将隐私视为一项人权，保护措施由各国政府指导和监控（涵盖医疗和所有行业）。因此，欧盟通过全面的立法对数据收集实施了重大控制。独立的政府数据保护机构很普遍，数据控制者必须向这些机构登记其数据库。在某些情况下，政府必须在个人数据处理开始前给予事先批准。

请记住，安全港框架适用的行业不仅限于医疗保健。但对于需要在美国和欧盟成员国之间传输数据的医疗机构来说，安全港值得重视。它有助于避免患者护理中断或面临欧洲法律的起诉。美国医疗机构可以获得安全港要求的认证。

![image](tip.jpg) **提示** 安全港容易让美国医疗行业从业者混淆，因为在大多数美国法律中，基于“善意”采取的具体行动通常被豁免，称为*安全港条款*。管辖医疗的HIPAA提供了若干安全港条款，例如使用全盘加密使受保护的健康数据不可读。如果装有PHI的笔记本电脑丢失或被盗，但已进行全盘加密，则通常无需报告数据丢失。在内部政策方面使用安全港一词，可能适用于欧盟管辖的安全港。

许多医疗机构已将欧盟-美国安全港政策纳入其现有政策中。此外，开展国际业务的医疗供应商已签署加入欧盟安全港条款。每年，组织进行自我认证并向欧盟提交信件，以列入安全港参与者名单。

要获得欧盟安全港认证，美国组织必须遵守以下七项原则，这些原则就OECD指南中的隐私原则而言看起来很熟悉，尽管它们并不完全相同：^([12](#ch3.html#ch3en12))

- **通知**：组织必须让个人知道收集信息的原因以及信息将如何使用。
