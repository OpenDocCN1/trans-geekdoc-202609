

# 个人信息保护和电子文档法案 (PIPEDA)

## 同意

个人信息的共享最初由个人管辖，因为必须获得个人的同意才能进行共享。同意通常是在信息发布之前采取的一种行动，即个人预先批准此类发布。为了使同意具有合法性，必须满足几个条件：个人必须自愿提供同意，并且必须知晓自己的权利，其中一项权利就是他们在提供同意后可以改变主意。当然，个人还必须能够理解这些条件并能够表达其决定。在医疗保健领域，治疗、支付和运营目的通常不需要同意。在美国，《HIPAA 隐私规则》^([3](#ch7.html#ch7en3)) 明确规定了这一点。然而，对于用于研究和公共卫生报告的其他用途和披露，可能需要额外的患者同意。这与国际医疗保健信息共享不同，因为数据隐私规则（如欧盟 DPD 确立的规则）倾向于不设置医疗保健豁免。无论是为了患者护理还是其他目的，收集、存储和使用识别个人身份的数据都需要同意。在个人无法提供同意的情况下，患者护理不会受阻，因为在这种情况下，近亲或主管部门可以提供所需的同意级别。一旦个人能够自行提供同意，他们就会这样做。除了知情同意外，根据 DPD，数据收集者还必须披露任何特定意图，以便最好地告知个人信息将如何被使用以及由谁使用。

## 选择

根据各种隐私标准，*选择* 被定义为给予个人自由提供信息或予以保留的选择权。*选择* 和 *同意* 的区别在于：选择关乎提供选项，而同意关乎给予许可。提供给个人的选择必须是在合法选项之间进行，并且选项必须以清晰、无欺骗的方式呈现。选择通过“选择加入”和“选择退出”条款来提供。针对合法数据收集和共享的“选择加入”或“选择退出”条款的一种形式是：医疗保健组织提供一份关于选择的声明。组织可以通过多种方式构建其“选择加入”和“选择退出”流程以获取患者的选择。如果个人不采取任何行动，则视为默认的隐式“选择加入”或“选择退出”选择；如果个人做出主动选择（通过勾选或取消勾选选项），则属于显式选择。在收集敏感信息时，最好要求个人做出显式的“选择加入”或“选择退出”选择。[图 7-2](#ch7.html#ch7fig2) 展示了隐式和显式“选择加入”及“选择退出”声明的示例。

随着电子健康记录 (EHR) 的日益普及，“选择加入”或“选择退出”的选择可能产生深远影响。当患者同意接受护理时，如果该信息被收集到 EHR 中，并作为健康信息交换 (HIE) 的一部分自动共享，则应向患者提供知情选择。这种额外的共享超出了患者的预期范围。因此，需要额外的同意。为了获得这种知情同意（无论是通过选择加入还是选择退出），提供者可能需要向成千上万名患者发送通知，这在后勤上既困难又昂贵。^([4](#ch7.html#ch7en4))

![image](tip.jpg) **提示** 很容易混淆 *选择加入* 和 *选择退出* 这两个术语的适当用法。例如，患者门户网站可能会提供一个选择，让患者通过勾选一个写着“我同意医院隐私声明中所述条款和条件”的复选框，来“选择加入”医疗保健组织的数据收集和存储系统。在这种情况下，复选框不应预先勾选，因为预先选中的肯定性声明更适合被定义为显式的“选择退出”选择。

## 通知

提供选择和同意的能力与组织向受影响个人提供通知的责任密切相关。在美国，医疗保健组织必须在患者入册时、首次预约时、接受医疗服务时（例如，在进行手术前），以及患者要求查看此类文档的任何时候，向患者提供通知。作为一项隐私原则，当患者签署确认理解该医疗保健组织发布的《隐私实践通知》(NPP) 时，即视为满足了通知要求。NPP 包含以下内容：

- 关于受保护实体的受保护健康信息如何被使用和披露的解释。（如果医疗保健组织需要以任何其他方式使用，将首先获得患者的许可或授权。）
- 医疗保健组织对其保护健康信息隐私职责的确认。
- 患者的隐私权利，包括查阅现有信息的权利、如果怀疑违规向美国联邦政府（具体为卫生与公众服务部）投诉的权利、以及如果记录不正确要求修正记录的权利。
- 与隐私实践和投诉流程相关的联系信息。

NPP 通常以纸质形式呈现，在规定的场合交给患者，但 NPP 也必须在提供医疗保健组织服务或福利信息的网站上显著位置展示。

与 *医疗保健* 隐私框架形成对比的是，欧盟 DPD 的 *数据* 隐私框架要求每次收集数据主体的数据时都要发出通知。根据个人对通知内容和频率的偏好，DPD 允许数据收集者根据各种标准，向数据主体提供“选择加入”或“选择退出”通知的选择权。这有助于让个人以可管理且有意义的详细程度或频率接收通知。
