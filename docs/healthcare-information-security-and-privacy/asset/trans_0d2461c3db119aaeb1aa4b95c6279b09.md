
# 网络攻击剖析

攻击过程可以通过多种不同方式开始。例如，用户可能会收到大量包含极具诱惑力链接的钓鱼邮件，或者他们可能从一个热门网站获取恶意软件，这也被称为“路过式下载”。我们都有一定数量的可从互联网访问的服务器（患者门户、Web邮件等）。这些系统每天都在被扫描弱点和漏洞。这些只是攻击者试图发起攻击的近乎无限的方式中的冰山一角。

**注意** “路过式下载”类似于你的电脑从网站“染上感冒”。任何网站（甚至流行的、受信任的网站）都可能被篡改程序，在你访问时在后台自动托管恶意软件。

一旦发现防线中的薄弱环节，初始恶意软件就会被部署以完成此攻击阶段。这是战斗的第一枪，无数对手每天都在开枪。执行这种初始攻击所需的所有工具、技术和人员成本都非常低廉。此阶段被攻陷的资产通常是低价值目标，例如员工的笔记本电脑、网页前端或普通用户凭据。对攻击者而言，价值在于这些资产一旦被感染后能做什么。

## 命令与控制

通过这种初始恶意软件投放，攻击者现已建立立足点。攻击者随即开始行动。恶意软件尝试联系其拥有者，报告任务完成并等待进一步指令。然后攻击者尝试提升权限、获取用户凭据、绘制系统图谱，或执行其他各种操作，具体取决于系统被攻陷的程度和攻击者的目标。这被称为“命令与控制”，它赋予攻击者对机器的最终控制权，以执行攻击的后续步骤。特别令人沮丧的是，在这种情况下，恶意软件可能长期潜伏而不被发现，因为它保持休眠状态或可以立即执行。根据近期报告，医疗机构的医疗设备和终端用户设备均遭遇了大量此类攻击。^([3](#ch11.html#ch11en3))

## 横向移动

一旦攻击者建立了与系统的可靠连接和稳固立足点，攻击者采取的下一步行动将集中于充分利用这一优势。通过扫描任何可访问的系统来记录网络拓扑。结果将被用来通过漏洞和弱点攻陷更多机器。更多合法用户凭据被收集并存储。入侵者试图开始利用内部网络固有的信任关系反制其自身。如果入侵者在访问控制系统中获得管理员凭据，这种信任可能延伸至核心层。现在攻击者可以授予网络上任何系统的管理员访问权限，绕过几乎所有现有的安全控制。

## 完成使命

此时攻击者已占据绝对优势，并获得了稳固的立足点、用户凭据和详尽的网络知识。现在可以制造头条新闻了。使命可能是从拒绝服务到窃取数据牟利等任何行为。在此阶段阻止攻击非常困难，因为对于纵深防御架构控制（如入侵检测系统）而言，攻击实际上可能看起来像正常的用户活动。此外，攻击者将在网络各处的多台机器上建立立足点，向网络外部的多个IP地址“回连”以获取命令。这些步骤让攻击者如同大海捞针般隐匿踪迹。

## 攻击总结

攻击可能来自世界任何地方，形式多样。这几乎像游击战一样，导致大量混乱。此处呈现的网络攻击剖析是一个非常高层级的概览，仅旨在说明几个问题：首先，这些行动大多数时候并不像媒体报道让人们相信的那样迅速。它们可能持续数月甚至数年而不被发现。然而，随着攻击者深入流程，使用传统网络安全战术（如纵深防御分层架构）进行防御变得越来越困难。其次，在这个过程中，网络安全专业人员看到了一线希望。检测、威慑、修复和恢复，尽管痛苦且困难，但有了正确的安全计划，这些都是可以实现的目标。

# 抵御攻击：艺术与科学

安全既是艺术也是科学，但人们倾向于关注科学，因为它易于衡量。当审计员进来核对控制清单并全部打钩时，感觉很好。本章将更多地关注艺术，较少关注科学。正如[第4章](#ch4.html#ch4)所讨论的，来自NIST或ISO等组织的优秀框架常用于评估以做出风险决策。这些科学工作应予以鼓励并定期开展。然而，一种主动防御流程，即不再单纯依赖控制，而是通过定制控制、补偿控制和安全计划中的持续方法来实施一些急需的艺术性，是医疗保健领域所需的下一代解决方案。在许多情况下，将对攻击程序的更好理解与可靠且持续的控制检查相结合，能让安全计划“活”起来。

## 流程框架

禅宗有句谚语：“悟前砍柴挑水，悟后砍柴挑水。”此语在此适用：通常选择哪种风险管理框架并不重要；重要的是专注于流程并严格遵循。任何计划要有效，必须包含规划、执行和改进的均衡组合。无需过度纠结选择哪个框架，因为随着流程执行，它会被修改以适应组织。

如前几章所述，世界上有许多跨国组织（如ISO和NIST）发布了可用的框架。此处将使用NIST网络安全框架（CSF）作为参考模型，仅因其国际适用性。此处表达的观点将聚焦于流程，并可适用于任何框架。

## 网络安全框架（CSF）

网络安全框架是美国总统行政命令13636《改善关键基础设施网络安全》的直接成果。该框架的目标是为风险管理结果提供指南，可供任何规模的组织用于管理风险。该框架的创建是美国政府与私营部门合作的成果。^([4](#ch11.html#ch11en4))
