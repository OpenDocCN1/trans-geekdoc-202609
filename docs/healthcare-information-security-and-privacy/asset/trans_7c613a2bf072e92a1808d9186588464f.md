# 第10章 医疗卫生领域的网络安全人才胜任力

## 学习目标

在本章中，您将学会：

- 了解美国及国际信息隐私与安全人才队伍的现状
- 认识网络安全人才现状对医疗卫生行业的影响
- 理解传统医疗技能向网络安全职责的融合
- 确定医疗网络安全胜任力所需的知识领域
- 描述政府和教育机构为提升网络安全人才胜任力所采取的举措

---

随着全球数据泄露事件数量和严重程度的增加，各方纷纷呼吁采取措施，确保医疗卫生行业拥有经过培训且胜任的员工来保护敏感信息。当然，对胜任力衡量标准的需求并非医疗卫生行业独有；然而，许多信息隐私与安全胜任力要求是医疗卫生行业特有的。医疗卫生信息技术的进步、日益复杂的系统与互联互通，加上数据价值极高——所有这些都在医疗卫生环境中被使用和共享——这给医疗卫生行业带来了迫切需求。我们不仅要建立项目和技术来保护信息资产免遭未经授权的披露，还必须确保拥有装备精良、训练有素的员工，能够充分胜任其职责。

### 网络安全人才队伍

我们许多人还记得2000年（即“Y2K”）来临前的日子。那时，我们开始意识到自己对集成和互联计算机的依赖程度有多深。银行、零售商甚至医疗卫生机构都不得不检查任何包含微处理器的机器，找出那些可能因年份从99或00结尾而发生变化导致故障的设备。人们担心，仅有两位数年份字段的计算机和软件会“认为”日期回到了1900年。关键计算（如银行业的利息计算）会出错。在医疗卫生领域，人们担心遥测装置或超声机等设备会直接停止工作。全球花费数十亿美元修补系统或更换为使用四位数年份字段的新版软件。如果您太年轻不记得Y2K事件，现在您知道为什么我们在应用程序的年份字段中总是使用四位数字了。也许您以前从未多想，直到现在。

最终，要么是因为对该问题的关注和重视，要么是因为计算机在现实中从未面临太大风险，2000年1月1日午夜12点敲响时，并未发生灾难性事件。在此过程中，我们制定了灾难恢复计划，完善了备份策略，并强制要求业务连续性管理。这些概念大多仍是每位信息安全和隐私专业人员职责的组成部分；然而，自Y2K时代以来，系统间的互联程度和我们对它们的依赖程度已发生了近乎不可估量的变化。业务连续性计划（COOP）不再涉及手动流程——那些早已被遗忘。现在通常意味着冗余或备份系统。2000年的灾难恢复可能在24小时内完成即可。如今，随着各行业（包括医疗卫生）被认定为关键基础设施，灾难恢复时间以秒、分钟或至多几小时来衡量。

这种关键基础设施也是攻击的可行目标。威胁真实存在，攻击来源多样，包括黑客、民族国家、恐怖分子和有组织犯罪。为了提供网络安全防御，我们必须让合适的人员在组织的合适岗位上配备合适的装备和培训。这在Y2K危机期间如此，在当今利用互联互通和数字信息的力量、同时不让敏感个人信息落入敌手的过程中依然如此。

即使我们确定全球网络安全岗位所需的人数充足，这些人也必须具备资质。这是一个需要高水平技能（并非全是技术技能）的职业，用于维护系统、保护网络、构建安全应用、监控合规等。这种短缺既存在于全球范围，也存在于美国。
