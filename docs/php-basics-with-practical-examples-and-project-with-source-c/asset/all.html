An identifier which holds a value and that value remain the same throughout the script.The value cannot be changed throughout he script.It starts with a letter or underscore.It is global throughout the script.

<?php

echo STORE;
?>
In the above example I have define a constant named
STORE.It holds the value Estore Diversity.
Now whenever I will use and print the STORE constant in my script it will display the value as Estore Diversity.
So the main purpose to define constant is that when we want to define some identifiers that will hold some value that are not going to change throughout the code and are available globally to the script.

Loops in PHP::
When we want to run a piece of code again and again when certain conditions are met then we use loops.
There are different types of loops: while
do .. while
for
foreach :loop
While loop gets executed till the condition is true
Syntax for while loop: while(till condition is true) {
code to be executed
}
Example:
Let say we have a variable $var=1;
while ($var <=6) {
echo $var; $var++;
}
OUTPUT: 123456
The variable here gets increased by 1 and is displayed on screen till it's value is less than or equal to 6.
do....while loop always executes the block of code first time and then repeat the loop if condition is true.
Syntax for do...while:
do
{
code to be executed }while(condition is true)
Example:
$var=1;
do
{
echo $var;
$var++;
}while($var<=6);
Output: 123456
for Loop iterates through a block of code till the specified number of times and till the condition is true.
Syntax
for(initialization; condition; increment)
{
code to be executed
}
Example:
for($x=1 ;$x<=5 ;$x ++)
{
echo $x;
}
Output: 12345 Foreach loop :Loops through a block code for each element in an array
Syntax:
foreach($array as $key=>$value)
{
echo $key;
echo '<br>';
echo $value;
}
Suppose we have an array
variable $arr.
$arr=['a'=>'yellow','b'=>'red','c'=> 'white'];

CHAPTER 18 Session in PHP:
Well what are sessions and why are they used ?
Sessions are stored in server in form of variables.They are generally used to store webpage visitor preferences and identify him across multiple webpages.
Session expires when we close the webpage or log out of the application.
How to create session in PHP? We use $_SESSION superglobal variable to create session.
For creating session we need to first start session and the store the varibale in session.
Find the code below:
session_start();
$_SESSION['username']='your_u sername';
How to check if the session is set or not?
To check the session variable is set or not you can use isset variable and use that session variable.
if(isset($_SESSION['username'])) {
/*your piece of code*/
}
How to end a session?
When we donot require session we can unset the session variable and destroy it.
session_start();
unset($_SESSION['username']); session_destoy();
Where do we use session? Session is used to store the login details of any user so he can access the other webpages and we can track the user.When a user usually logs out his session gets expired and he leave the
application.
