# CHAPTER 1: Introduction To Php

PHP is a server side scripting language and is generally used to develop dynamic webpages. It is an opensource scripting language. It is free, widely used and easily available for download. It is the best ever tool for developing webapplications or dynamic websites.

PHP was originally created by Rasmus Lerdorf in 1994.

Previously PHP stood for Personal Home Page but now PHP stands for PHP: Hypertext Preprocessor. PHP scripts are executed on server. It is compatible with all servers like Apache, IIS, etc. A PHP file contains HTML code, CSS code and PHP script. The file is saved with `.php` extension. It is executed on server and the response generated is pure HTML which is displayed in the browser.

So before we start learning PHP we must know what PHP can do. PHP can be used to create dynamic page content.

It can be used to create forms and collect data from end users. It can create session and can maintain session for any user while he is navigating through multiple pages in any website. PHP can be used to manipulate data in database by performing CRUD operations like create, read, update and delete operations.

PHP can be used to create sessions and track user activity. To learn or work with PHP you should have basic knowledge on HTML, CSS and javascript. HTML is hypertext markup language and CSS is cascading style sheet. HTML describes structure of webpage. HTML contains number of elements. These elements hold text and images for the webpage. It actually tells the browser how to display the data for a webpage. CSS is used to give a styling to those elements i.e. the look and the feel of the webpage.

HTML and CSS topics are not covered here however while using HTML tags and CSS code in this book I will briefly describe what is the main purpose of using them.

# CHAPTER 3: How to install Php locally

Installing PHP locally means installing it in your local PC. This is important step while learning PHP so that you can run and test your PHP code locally on your PC. We are going to install XAMPP server (which contains Apache, Mysql and PHP). Apache is a webserver which is required to run PHP scripts.

Follow the below steps to install XAMPP in your PC.

**Step 1:** Go to `https://www.apachefriends.org/download.html`. Download the latest XAMPP for your windows.

**Step 2:** Save and Run the `.exe` file.

**Step 3:** A setup wizard dialog will get open on your screen for you. Follow the instructions and install your XAMPP in desired folder.

Your installation part is now done!

If you have done the XAMPP installation in C folder. Then navigate to C folder and manually start the server by clicking on `xampp_start` icon which is already there inside XAMPP folder. See the screenshot below:

To write the PHP scripts we need an editor. A number of free editor tools like Notepad++, Sublime, Netbeans are available. You can use any of them. I will be using Netbeans for writing the PHP scripts.

Navigate manually to `C:\xampp\htdocs` folder. This is a folder where you can store your project folder and files within it. I am creating a folder here and naming it as `Practicalphp`. I will be using this folder to store all the PHP scripts required for practical examples and test them as we proceed gradually.

PHP code starts with open tag and ends with close tags. Well what are open and close tags in PHP? `<?php` is the open tag and `?>` is the close tag. PHP script goes between these two tags. You can find the code below:

```php
<?php
//php code goes here
?>
```

Below we are going to print text on webpage with PHP. For this create a file in `C:\xampp\htdocs\PracticalPhp` folder and save it as `index.php`. Paste the below code to display “Hello ! I am here” on a page.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>MyFirstExample</title>
</head>
<body>
    <?php echo "Hello ! I am here" ;?>
</body>
</html>
```

Now if you have already started your XAMPP server in your PC then open any browser and type `localhost/PracticalPhp/` and click enter. You will see “Hello ! I am here “ on your screen. See the screenshot below:

# CHAPTER 5: Variable declaration and it's usage with examples

A variable is a container which stores values in it. It can store a string of text, numbers etc. We do not have to declare the datatype (i.e. String, Integer) of the variable.

It automatically converts the variable to its correct data type depending on its value. The assignment operator is used to assign value to a variable. Once a variable is declared it can be used throughout the code. PHP variables follow some naming conventions i.e. follow some rules for defining a variable. A PHP variable starts with dollar sign `$`, followed with a name. A variable name cannot start with number. It can have alphanumeric characters and as well as underscore. A variable name cannot have spaces. They are case sensitive.

Find below examples to define a variable:

```php
$var = "This is a string variable";
```
Since the above `$var` variable stores text. It is a variable with datatype as String.

```php
$var = 10;
```
Since the above `$var` variable stores number. It is a variable with Integer data type.

```php
$var = array("a", "b", "c");
```
Since the `$var` stores array data so it is an array variable.

```php
$var = 2.5;
```
