
# Chapter 17: Create Database and Tables

## Creating a Database

To create a database, you can write the following SQL command:

```sql
CREATE DATABASE dbname;
```

You can also create a database by navigating to **phpMyAdmin**. phpMyAdmin is a free and open-source administration tool for MySQL and MariaDB. As a portable web application written primarily in PHP, it has become one of the most popular MySQL administration tools. Check the screenshot below:

![Illustration 10: phpMyAdmin Interface](image_rsrcE4.jpg)

MySQL is the relational database used to store data.

## Connect to MySQL Database from PHP Code

To connect with the database from PHP code, we need to write code to establish the connection.

```php
<?php
$servername = "hostname or ip address";
$username = "mysql username";
$password = "mysql password";

/* Create a connection with below code */
$connection = mysqli_connect($servername, $username, $password);

/* Add code to check connection */
if (!$connection) {
    die("Connection failed: " . mysqli_connect_error());
}

echo "Connected successfully";
?>
```

If the connection is created, then the connection will be successful; otherwise, it will print an error stating that the connection is not created.

## How to Create a Database

You can create a database in two ways:

1.  Go to phpMyAdmin and click on the **Databases** tab. On clicking it, an option will appear where you can enter your desired database name and click on the **Create** button.
2.  Go to phpMyAdmin and click on the **SQL** tab. Paste the query:
    ```sql
    CREATE DATABASE `database_name`;
    ```
    Then click on the **Go** button. The above query will be executed and the database will be created.

# Chapter 18: Session in PHP

## What are Sessions?

Sessions are stored on the server in the form of variables. They are generally used to store webpage visitor preferences and identify them across multiple webpages. A session expires when we close the webpage or log out of the application.

## How to Create a Session in PHP?

We use the `$_SESSION` superglobal variable to create a session. For creating a session, we need to first start the session and then store the variable in the session.

```php
session_start();
$_SESSION['username'] = 'your_username';
```

## How to Check if the Session is Set?

To check if the session variable is set or not, you can use the `isset()` function with that session variable.

```php
if (isset($_SESSION['username'])) {
    /* your piece of code */
}
```

## How to End a Session?

When we do not require the session, we can unset the session variable and destroy it.

```php
session_start();
unset($_SESSION['username']);
session_destroy();
```

## Where Do We Use Sessions?

Sessions are used to store the login details of any user so they can access other webpages and we can track the user. When a user usually logs out, their session gets expired and they leave the application.

# Chapter 19: PHP Project - User Registration

Now we are going to create a small PHP project where we will be creating a database and table. Then we will create a small project where a user will register, log in, and navigate to a restricted page on the website.

## Create Database

Run the below query to create the database:

```sql
CREATE DATABASE `user_registration`;
```

Select the database and copy the below code. Execute the query after pasting it under the SQL tab to create table `users`:

```sql
CREATE TABLE `user_registration`.`users` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255) NOT NULL,
  `type` ENUM('user','admin') NOT NULL,
  `username` VARCHAR(64) NOT NULL,
  `password` VARCHAR(255) NOT NULL,
  `status` CHAR(1) NOT NULL DEFAULT 'A',
  PRIMARY KEY (`id`)
) ENGINE = InnoDB;
```
