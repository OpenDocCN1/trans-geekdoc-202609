# 4.2.3 Bluetooth Low Energy (BLE) or Bluetooth Smart

Bluetooth Low Energy (BLE) or Bluetooth Smart uses wireless transmission. Because of its low-energy requirements, it has a wide application in the proximity payment sector, hence has its limitations as well. It has the advantage of securing exchanges by respecting the recommendations of the National Institute Standard and Technology (NIST). This organization has described two modes and security levels for a service between two devices connected via BLE [21, 22]:

+   * For model 1, level 1 does not initiate encryption or authentication, level 2 is only about encryption but not authentication, Level 3 requires authentication and encryption, and level 4 requires use of AES-CMAC elliptic curves of 250 bits in length.
* For model 2, data signing is considered at two levels depending on whether authentication is required at level 1 or level 2 at the beginning of the connection.

For a service such as mobile payment, where security is required, NIST recommends level 1 and level 4 where both devices authenticate and the exchanges encrypted using AES-CMAC with p-256 ECC.

Moreover, BLE is compatible with most smartphones. This is an advantage since a mobile payment system with BLE has high availability.

# 4.2.4 Wireless Application Protocol (WAP)

The Wireless Application Protocol (WAP) allows a mobile device to access the Internet. Thanks to the integration of the Wireless Transport Layer Security (WTLS), which encrypts the exchanges, the security of the user’s data and authentication of the service is very high. WAP is especially recommended for online payment. However, its use is still limited, even though there is great interest in it. Furthermore, the technology is outdated and not suitable for delivering a consistent choice of services to current terminals, which Samuel Pierre foreseen long ago [23].

# 4.2.5 Quick Response Code (QRC)

The “Quick Response Code” (QRC) or “black and white matrix codes” or “Data Matrix code” is a two-dimensional barcode, also known as a 2D code or matrix code. It makes it possible to read numeric, alphanumeric, or binary data with a smartphone equipped with a camera. The Secure QRC (SQRC) has been added to the set-in order to strengthen the encryption measures because it has serious problems, in particular, the redirection of the user to a malicious site, which is a fake site capable of stealing financial data [24]. It is comparable to BLE in terms of accessibility, as it is available on mid-range phones.
