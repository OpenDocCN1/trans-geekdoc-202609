# 4.2 SIX TECHNOLOGIES FOR MOBILE PAYMENT SYSTEMS

In his Mobile Payment, Thomas Lerner [18] describes the main technologies used in mobile payment systems, which refers to transactions via a mobile device [19]. Each of the technologies discussed has advantages and disadvantages [20].

# 4.2.1 SHORT MESSAGE SERVICE (SMS)

The “Short Message Service” (SMS) is a messaging service allowing users to use up to 160 characters. It was developed for in the Global System for Mobile Communications (GSM) network. Very simple to use and know throughout the world, it is however expensive and can easily become the target of cyber-attacks because of faulty cryptography techniques.
