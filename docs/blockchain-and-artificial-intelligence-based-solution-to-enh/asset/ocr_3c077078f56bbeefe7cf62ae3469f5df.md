# 6.2.3.5 Fixed vs Automatic Pricing

Simple efficient smart contracts are used for setting a fixed pricing for the data (fixed OCEAN). However, there is another more flexible and better option to automate the pricing for the data using Automated Market Maker (AMM) [30].

Both data providers and consumers can add token and Ocean tokens, respectively, into the AMM pool and it will detect the price and publish data offering in a gas-efficient manner [30].
