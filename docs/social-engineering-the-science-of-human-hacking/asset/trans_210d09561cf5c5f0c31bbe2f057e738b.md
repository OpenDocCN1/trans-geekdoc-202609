## 原则六：一致性与承诺

我们都希望显得一致，这意味着我们希望自己所说的话与自己认为所表现出的形象保持一致。这一点在我们承诺某件事时尤其明显。你有没有见过一个小孩子承诺一个你知道是错误的答案？（“不，我没有打碎那盏灯！”）即使你提供了压倒性的证据证明他们在撒谎，孩子也会坚持与他们最初回答一致的答案。

为什么一致性对我们很重要？我们希望——也许我们甚至需要——显得自己是一致的，因为一致性是自信和力量的标志。

### 一致性与承诺的实际应用

我住在一个相当偏远的地区，但最近地下发现了大量石油和天然气。现在他们正在整个县进行水力压裂、抽采和挖掘。结果，我的路上有很多卡车。

我看到一辆载满设备的卡车以每小时50或60英里的速度飞驰过我的道路。司机们粗心大意，危险重重。我的一些邻居开始在院子里放手绘的标志，告诉司机减速、注意安全，并像社区里住着他们的孩子一样开车。如果我的邻居来找我，要求在我院子里放一个这样的大标志，它会挡住我妻子美丽的花朵或我酷炫的汽车，我会拒绝，尽管我希望司机们减速。

1966年，研究人员乔纳森·L·弗里德曼和斯科特·C·弗雷泽研究了“一致性与承诺”，并在《不施压的顺从：门中脚技巧》（《人格与社会心理学杂志》，1966年9月，`www.researchgate.net/publication/17217362_Compliance_Without_Pressure_The_Foot-in-the-Door_Technique`）中撰文介绍。他们挨家挨户地走访，要求一个社区的人在院子里放置带有驾驶员安全警告的、字迹潦草的大标志。这些标志会挡住房屋的一部分视野。研究人员发现，83%的房主都拒绝在院子里放置标志。

然后，弗里德曼和弗雷泽在下一个社区对他们的请求做了一处改变，结果获得了76%的顺从率！你没听错，76%的人说是的！那是什么改变？更好的字体？漂亮的标志？支付标志费用？租用空间？

不，不，不，不。改变的是标志的尺寸。在第二个社区，他们先要求房主在窗户上展示一个3英寸的贴纸，上面写着同样的信息。然后几周后，他们又回来要求房主在院子里展示那个又大又丑的标志，结果76%的人顺从了。

弗里德曼和弗雷泽称这种方法为“门中脚技巧”。一旦他们把脚伸进了门缝（窗户上的小贴纸），房主就更愿意顺从未来的请求（院子里的大标志）。

自从弗里德曼和弗雷泽的研究以来，已经进行了大量研究，所有研究都得到了同样惊人的结果。当一个人先同意了某件小事时，顺从率会急剧增加。

当你将顺从与一致性原则结合起来时，这就是一种不可阻挡的力量。基本上，我们希望自己保持一致，并显得一致。我们的大脑不喜欢内心产生争论。所以，即使我们知道自己错了，如果我们已经承诺并希望保持一致，我们也会坚持己见，不肯改变。这一点在 [图 6-8.](#c06.xhtml#c06-fig-0008) 中有所体现。

### 作为社会工程师使用承诺与一致性

我的个人准则之一是：除非万不得已，否则绝不打破预设。必须出现相当严重的情况才能打破预设。这个准则源于我即将告诉你的故事。

我承担了一项多阶段的工作，需要进入一组上锁区域内的垃圾箱。这些垃圾箱是公司丢弃技术设备的地方。

要到达垃圾箱，我需要绕过安保，进入校园内的安全区域，在不被拦截的情况下进入，并且在寻找有价值物品时不受打扰。

我开始进行OSINT阶段，目标是找到垃圾箱公司。目标公司对向任何供应商提供任何信息都有严格的规定，但我决定打电话给财务部，看看能否套话套到那个信息。通话大致如下：

| **公司代表：** || 您好，我是贝丝。有什么我可以帮您的？ |

| --- | --- |

| **我：** || 贝丝，我是专业垃圾箱公司的保罗。我们刚来这个地区不久，正在努力争取更多本地业务。我想知道能否给您发一份快速报价？ |

| **公司代表：** || 您好，保罗。我们接受新供应商的报价。只需发送每单位成本给我们，如果价格匹配，我们会索取更多信息。 |

| **我：** || 好的，太好了。请问能给我您的电子邮件地址以便发送吗？ |

| **公司代表：** || 嗯，您不会发给我。您应该发送到 [vendors@company.com](mailto:vendors@company.com)。 |

| **我：** || 哦，我明白了。有没有办法可以抄送给您，这样我知道邮件已经送达了。我遇到过一些严重的问题，有人说我的报价从未送达。我是这个行业的新手，不太懂技术。 |

| **公司代表：** || 哦，好的。是 [beth.p@company.com](mailto:beth.p@company.com)。 |

| **我：** || 贝丝，你真是救命恩人。听着，我能信任你一件比较私人的事情吗？ |

| **公司代表：** || 嗯，当然，我想可以。 |

| **我：** || 我卖过几乎天底下所有的东西，但垃圾箱对我来说是个新行当，我觉得自己做得不太好。甚至不确定我们的价格是否有竞争力。 |
