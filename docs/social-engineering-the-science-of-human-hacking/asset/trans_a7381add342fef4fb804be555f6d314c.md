说完最后这句话，目标字面意义上从我的学生身边往后靠，看了看手表，说她迟到了，然后离开了。

他做了什么？这就是我们所说的 *否定框架*，定义为提及你不希望目标思考的事情，本质上会导致他们思考那件事。

作为一名专业的社会工程师，当你与目标互动时，你不希望他们思考的一件事是什么？比如 *被黑客攻击*？！

如果你不希望他们思考它，那么就不要说类似这样的话：

*   “我不会用它来黑你！”

*   “我又不是想闯入！”

*   “我绝不会给你发钓鱼邮件。”

*   “我不是骗子！”

所有这些都是否定框架的例子。每当我们提及对立的框架，我们就否定了自己的框架。并且请记住 [图 7-2](#c07.xhtml#c07-fig-0002）——他们的框架是保护。

寻找方法，利用你的借口、着装或其他工具来增强或加强你的框架，从而让目标能够绕过任何内部的疑虑和顾虑。

### 规则 4：让目标思考框架会加强框架

每当我们让某人思考一个框架，我们就加强了那个框架。无论那个框架是什么，我们都会加强它。例如，父母可以选择向孩子灌输积极的框架或消极的框架，如下例所示：

*   “你真蠢！”

*   “你不擅长运动。”

*   “你难道什么都做不对吗？”

*   “你既漂亮又聪明！”

*   “你只要下定决心，就能完成任何事情！”

*   “我知道这很难，但我知道你能做到！”

作为一名专业的社会工程师，你可以通过选择的词语、着装和借口来加强框架。

在一次公司进行的电话钓鱼任务中，我们的借口是我们是从 IT 部门打来的，前一天晚上徽章系统发生了损坏。我们的目标是从被指派致电的员工那里获取全名、出生日期、员工 ID 和其他详细信息。过程大致如下：

| **目标：** || 我是鲍布。有什么我可以帮您的？ |

| --- | --- |

| **SE：** || 鲍布，我是 IT 部门的保罗。昨晚，我们的徽章系统发生了损坏错误，大约 100 个账户被标记。你是幸运的获奖者。你今天进大楼有问题吗？ |

| **目标：** || 没有，可以进。你是谁？ |

| **SE：** || 我是 IT 部门的保罗·威廉姆斯。我和托尼·R 一起工作。听着，这只需要一分钟。你知道，我们的徽章系统与薪资系统挂钩，所以我们不想在修复任何错误时耽误时间。 |

| **目标：** || 哈，没错。那么，你需要什么？ |

| **SE：** || 我需要验证你的全名。你能把你的姓氏拼写给我听吗？ |

| **目标：** || 嗯，说真的？是 *S-M-I-T-H*。不难吧。 |

| **SE：** || 哇，谢天地我打了电话。IT 部门在这条分机号的记录里写的是罗伯特·琼斯。那肯定会搞乱薪资。我想，当损坏算法运行时，它试图重新链接表格并错位了数据库计数器。*\[我说这话明知毫无意义，但我赌会计部门的鲍布并不是个极客。\]* |

| **目标：** || 是的，我不想让别人拿到我的工资单。让我们检查其余的。 |

从那之后，就是一系列使用故意的错误陈述和积极强化，来获取他的全名、出生日期、员工 ID，甚至他的社会安全号码最后四位。我的话语和借口都加强了我的框架；因此，目标更容易接受它。

在开场白中始终让目标思考你的框架，这样进入下一部分就会容易得多。我们称之为 *引出信息*。

## 引出信息

你如何定义 *引出信息*？

我将其定义为“获取你从未询问过的信息”。本质上，引出信息看起来和听起来就像一次对话。在这次对话中，熟练的引出者正在将对话引导向某个方向，以在你未主动询问的情况下获取信息。

引出信息有一些固有的自然规则和原则，这些原则对其成功至关重要。每一条原则本身都很强大，但当你将它们结合起来时，你将掌握谈话的艺术，作为一名专业的社会工程师，这会让你成为不可小觑的力量。

在我讲解引出信息的四条规则时，请记住这一点：如果做得正确，引出信息应该看起来和感觉起来像与目标的一次正常、非强迫的对话。

### 自我诉求

在 [第 5 章](#c05.xhtml) “我知道如何让你喜欢我”中，我谈到了自我悬置，而这个原则与之完全 *相反*。在这种情况下，你关注的是目标的自我，而不是思考你自己的自我。

什么是自我？《牛津英语词典》将其定义为“一个人对自尊或自负的感觉”。理解这一点很重要，因为当我们听到这个词时，可能会自动认为我们必须夸大目标的自我，但这不是我的意思。我的意思是，你必须 *诉求* 他们的自我。

诉求目标的自我需要注意以下三点：

*   你必须真诚。

*   你必须有适当的融洽关系。

*   你必须现实。

“假设我从未见过你，刚认识你，我走到你面前说，哇，你是我见过最有吸引力的人之一。”如果我然后试图与你开始一段对话，你可能会在想什么？可能是以下一种或多种想法：

*   “变态！”

*   “你想要什么？”

*   “嗯，什么骗局？”

*   “当然我是。现在走开！”
