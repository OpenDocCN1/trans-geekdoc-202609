神经网络是一个处理数据或输入的模型或系统，而不是一个预编写的程序。神经网络有两个主要特征：神经元网络架构可以总结如下。这决定了神经元之间存在的连接类型（例如前馈或循环）、层数（如图 2.1 所示的多层或单层）等。

神经元的定义为：

$$y=f\left(\sum a_j w_j+b\right)$$

在此之前，我们计算了输入 $a_j$ 和权重 $w_j$ 的加权和 $\sum a_j w_j$（也称为激活值）；$a_j$ 代表输入数据值或其它神经元的输出（即：，如果该神经元是神经网络的一部分），$w_j$ 表示输入的强度，或者说网络中神经元之间连接的强度。当它连接到偏置权重时，它是一个输入恒为 1 的特定值。传递函数是通过将加权和作为输入并将其应用于 $f$（即激活函数）而产生的。

## 2.2.1 梯度消失与爆炸问题

随着时间的推移，误差函数的偏导数根据神经网络中的每个权重成比例进行更新。在其他情况下，该导数非常小，导致无法进行更新。更新通过在神经网络深层乘以不同的偏导数来实现。如果这些偏导数非常小，总更新将变得极其微小并趋于零。在这种情况下，权重将无法更新，导致收敛延迟或不收敛。梯度消失是这种情况的名称。如果导数项很大，更新也将非常显著。在这种情况下，算法将超过最小值且无法收敛。梯度爆炸是这种情况的名称。防止这些问题的方法之一选择合适的激活函数。以下是最常用的激活函数。

### 2.2.2.3 Sigmoid 函数

Sigmoid 是一种“S”形状的数学函数（如图 2.7 所示），其公式如下：

```
$$y(x) = \frac{1}{1+e^{-x}} \quad (2.3)$$
```

#### 优点：
Sigmoid 函数是一个连续且可微的函数。它将输出限制在 0–1 的范围内，并为二分类提供非常具体的预测。

#### 缺点：
它具有产生梯度消失问题的潜力。它并不以 0 为中心。计算开销较大。

### 2.2.2.4 Softmax 函数

Softmax 函数是多分类的扩展。我将其用于多分类的最后一层。如图 2.8 所示，它将一组 $k$ 值的实数转换为概率分布，其中 $k$ 个概率与输入数值相匹配。在应用 softmax 之前，向量分量可能为负或大于 1，因此总和不为 1，但在应用 softmax 之后，每个分量都将在 0–1 范围内且总和为 1。softmax 函数定义如下：

```
$y(x_i) = \frac{e^{x_i}}{\sum_{K=1}^{K} e^{x_i}} \text{ 对于 } i=1,2,3,...K \quad (2.4)$
```

![](img/8c7c0992f9872f35977e949607bd4072_64_0.png)

图 2.8 Softmax 激活函数。

#### 优点：
它可以用于神经网络的输出层进行多分类。

#### 缺点：
由于存在指数项，计算速度较慢。

### 2.2.5 双曲正切 (tanh)

双曲正切或简称为“tanh”，表示如下：

```
$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$```

它非常像 sigmoid 函数。它的范围为 -1 到 +1，并且以 0 为中心，如图 2.9 所示。

#### 优点：
- 到处连续。
- 围绕零分布。
- 输出限制在 -1 和 +1。

#### 缺点：
- 它可能会导致梯度消失问题。
- 计算开销大。

修正线性单元（ReLU）通常定义为：

```
$f(x) = \max(0, x)$
```

#### 优点：
- 计算简单。
- 不会导致梯度消失。
- 稀疏性，提高了效率。

#### 缺点：
- 不以 0 为中心。
- 它可能会破坏某些神经元（死亡 ReLU）。

### 2.2.2.7 Leaky ReLU

当函数杀死某些神经元时，会出现死亡 ReLU 的情况。为了避免这种情况，使用了 leaky ReLU：

```
$f(x) = \begin{cases} x & x > 0 \\ 0.01x & \text{其他} \end{cases}$
```

### 2.2.2.8 参数化 ReLU

不是为负轴设置固定率，参数化 ReLU 将其作为一个由网络自行学习的新参数：

```
$f(x) = \begin{cases} x & x > 0 \\ ax & \text{其他} \end{cases}$
```

### 2.2.2.9 Swish

利用 sigmoid 函数，我们可以通过将其乘以 $x$ 来得到 swish 函数：

$f(x) = \frac{x}{1+e^{-\beta x}}$

谷歌的大脑团队提出了 swish 特性。在许多困难的数据集中，它们的测试证明 swish 在深度模型中优于 ReLU。
