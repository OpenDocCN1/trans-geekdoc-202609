## 2.2.1 Vanishing and exploding gradient problem

Over time, the partial derivative of the error function is updated proportionally to each weight in a neural network. In other cases, this derivative is so small that updates are impossible. The update is achieved in the deep layers of the neural network by multiplying different partial derivatives. The total update gets extremely tiny and approaches nil if these partial derivatives are very small. Weights will not be able to update in this scenario, resulting in delayed or no convergence. The vanishing gradient problem is the name given to this situation. If the derivative term is big, then the updates will be significant as well. The algorithm will exceed the minimum in this instance and will be unable to converge. The exploding gradient problem is the name given to this situation. One way to prevent these issues is to choose the proper activation function. The following are the most frequent activation functions.

### 2.2.2.3 Sigmoid function

A sigmoid is a mathematical function with an “S” shape (as shown in Figure 2.7) whose formula is as follows:

```
$$y(x) = \frac{1}{1+e^{-x}} \quad (2.3)$$
```

#### Advantages:
The sigmoid function is a continuous and differentiable function. It will restrict output to a range of 0–1 and provide very specific predictions for binary classification.

#### Disadvantages:
It has the potential to create a vanishing gradient issue. It isn't quite centered on zero. Expensive in terms of computation.

### 2.2.2.4 Softmax function

The softmax function is a multiclass extension. I use it in the final layer of multiclass categorization. As illustrated in Figure 2.8, it converts a list of $k$-valued real numbers into a probability distribution with $k$ probabilities matching the input numbers. Prior to applying softmax, vector components may be negative or greater than 1 and therefore not sum to 1, but after applying softmax, each component will be in the range of 0–1 and sum to one. The softmax function defined as follows:

```
$y(x_i) = \frac{e^{x_i}}{\sum_{K=1}^{K} e^{x_i}} \text{ for } i=1,2,3,...K \quad (2.4)$
```

![](img/8c7c0992f9872f35977e949607bd4072_64_0.png)

#### Advantage:
It may be utilized in the output layer of neural networks to do multiclass classification.

#### Disadvantage:
It takes a long time to compute since there are so many exponent terms to calculate.

### 2.2.2.5 Hyperbolic tangent (tanh)

Hyperbolic tangent or in short "tanh" is represented as follows:

```
$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$
```

It's a lot like the sigmoid function. It has a range of -1 to +1 and is centered at zero as shown in Figure 2.9.

#### Advantages:
- Everywhere, where it is continuous and distinct.
- It revolves around zero.
- It will set a restriction on output between -1 and +1.

#### Disadvantages:
- It may result in a vanishing gradient issue.
- It is computationally costly.

The rectified linear unit (ReLU) is often defined as:

```
$f(x) = \max(0, x)$
```

#### Advantages:
- Simple to calculate.
- Does not result in vanishing gradients.
- It is sparse, making it efficient.

#### Disadvantages:
- Not centered on zero.
- It may destroy certain neurons (dead ReLU).

### 2.2.2.7 Leaky ReLU

The dying ReLU situation occurs when the function kills some neurons. To avoid this, leaky ReLU is used:

```
$f(x) = \begin{cases} x & x > 0 \\ 0.01x & \text{otherwise} \end{cases}$
```

### 2.2.2.8 Parameterized ReLU

Instead of setting a rate for the negative axis, the parameterized ReLU passes it as a new parameter that the network learns on its own:

```
$f(x) = \begin{cases} x & x > 0 \\ ax & \text{otherwise} \end{cases}$
```

### 2.2.2.9 Swish

Using the sigmoid function, we can get the swish function by multiplying $x$ by it:

$f(x) = \frac{x}{1+e^{-\beta x}}$

Google's brain team proposed the swish feature. Across many difficult datasets, their tests demonstrate that swish works quicker than ReLU of deep models.
