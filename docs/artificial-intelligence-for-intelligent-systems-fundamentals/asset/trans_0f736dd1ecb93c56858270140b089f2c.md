### 3.1 引言

人工智能（AI）、机器学习（ML）和深度学习（DL）已成为当代科技领域的流行词，并在现在主导着关于未来的讨论 [1, 2]。这些领域处于创新的前沿，改变着各个行业并显著影响着我们的日常生活。本引言让读者对 AI、ML 和 DL 及其作用在现代世界中的相关性有一个基本的了解 [3]。计算机科学中人工智能这一庞大且涵盖全面的领域的目标是构建能够模拟人类认知功能的智能体 [4]。AI 系统努力展现包括感知、问题解决、学习和决策等特征 [5]。对人工智能的探索源于古代神话中关于具有人类能力的机械实体。尽管如此，人们经常提到1956年的达特茅斯研讨会是首次认真对待它的会议 [6]。AI 涵盖了许多方法，包括基于规则的系统和神经网络，并应用于银行和医疗保健等许多行业。机器学习作为 AI 子领域，重点在于开发允许计算机在没有显式编程的情况下学习数据并做出预测或判断的方法和模型 [7]。通过分析大型数据集，系统随着它们“学习”如何从过去的经验泛化到新的经验，其性能会逐渐提高。不可见数据是机器学习中的一个基本概念 [5, 7]。机器学习主要有三类：监督学习（标签辅助数据）、无监督学习（无标签数据）和强化学习（通过环境交互进行学习）[7, 8]。它用于翻译、图像识别、推荐系统等领域。例如，AI 驱动的聊天机器人使用 ML 算法来理解和生成人类语言 [9]。基于医疗数据，医疗保健行业的 AI 系统也可能使用 ML 进行疾病诊断和预测 [10]。机器学习中一个被称为深度学习的部分近年来非常流行。它被定义为使用深度神经网络，即受人类大脑结构和运行启发的具有许多层的人工网络 [8]。这些深度网络非常适合图像和语音识别任务，因为它们可以自主学习分层的输入表示 [10]。深度学习彻底改变了 AI，使得计算机视觉、自然语言处理（NLP）和自动驾驶等领域的突破成为可能。DL 和 ML 之间的联系非常紧。深度神经网络是具有更多层的模型，用于自动从数据中学习分层的表示。DL 使用 ML 为挑战性任务创建更复杂的模型。

## 52 用于智能系统的人工智能

### 人工智能的基础知识

对人工智能的探索源于古代神话中关于具有人类能力的机械实体。尽管如此，人们经常提到1956年的达特茅斯研讨会是首次认真对待它的会议 [6]。AI 涵盖了许多方法，包括基于规则的系统和神经网络，并应用于银行和医疗保健等许多行业。机器学习作为 AI 子领域，重点在于开发允许计算机在没有显式编程的情况下学习数据并做出预测或判断的方法和模型 [7]。通过分析大型数据集，系统随着它们“学习”如何从过去的经验泛化到新的经验，其性能会逐渐提高。不可见数据是机器学习中的一个基本概念 [5, 7]。机器学习主要有三类：监督学习（标签辅助数据）、无监督学习（无标签数据）和强化学习（通过环境交互进行学习）[7, 8]。它用于翻译、图像识别、推荐系统等领域。例如，AI 驱动的聊天机器人使用 ML 算法来理解和生成人类语言 [9]。基于医疗数据，医疗保健行业的 AI 系统也可能使用 ML 进行疾病诊断和预测 [10]。机器学习中一个被称为深度学习的部分近年来非常流行。它被定义为使用深度神经网络，即受人类大脑结构和运行启发的具有许多层的人工网络 [8]。这些深度网络非常适合图像和语音识别任务，因为它们可以自主学习分层的输入表示 [10]。深度学习彻底改变了 AI，使得计算机视觉、自然语言处理（NLP）和自动驾驶等领域的突破成为可能。DL 和 ML 之间的联系非常紧。深度神经网络是具有更多层的模型，用于自动从数据中学习分层的表示。DL 使用 ML 为挑战性任务创建更复杂的模型。

### 3.2.1 相互关系

AI、ML 和 DL 之间存在密切相关。构建智能机器的目标是人工智能这一宏观概念，而 ML 和 DL 是 AI 的子集，提供了实现的方法和工具。虽然 AI 试图模仿人类意图，但 ML 和 DL 通过数据驱动的学习和复杂的神经网络提供了可能。作为 DL 的基础，ML 是 ML 的子集，使用许多隐藏层来模拟数据中复杂的关系。以前被认为难以实现的任务（包括语音和图像识别）由于 DL 的存在取得了显著进展。
