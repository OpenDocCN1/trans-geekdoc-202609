## 16.3 DT——用于工业 4.0 和工业 5.0 的新兴技术

当我们进入工业 4.0 和 5.0 这一令人兴奋的新世界时，各种令人眼花缭的技术在等待我们；每种技术都承诺改变我们生活、工作以及与世界互动的方式。这场技术革命的前沿是数字孪生（DT）技术，这是一种创建物理对象和系统虚拟模型的尖端方法。该技术使我们能够模拟和优化性能、监控并预测需求，探索此前无法想象的新可能性 [8]。

### 伴随 DT 技术

### 16.3.1 制造业的 DT 技术

一种名为“DT”的新技术使得构建真实物体或系统的虚拟表征成为可能。如图 16.2 所示，它是一个计算机生成的副本，用于瞬时镜像系统或实际资产。它的开发目的是为了模拟物理资产或系统的行为，以提供预测性洞察、监控性能并优化操作 [10]。

对监控和优化复杂系统的需求导致了 DT 技术理念的产生。密歇根大学教授迈克尔·格里夫斯（Michael Grieves）博士在 2002 年首次提出了这一概念。他建议使用 DT 构建项目和流程的仿真以增强其性能。从那时起，该技术已成为从制造业到医疗、航空航天和国防等行业的关键工具。对 DT 技术的需求源于现代系统日益增加的复杂性。随着系统变得越来越复杂，监控、维护和优化变得困难。在这些情况下，DT 技术提供了一种实时跟踪这些复杂系统性能的机制，并在问题扩大之前发现它们 [11]。它为使用该技术的行业提供了以下若干益处：

- 它实现了预测性维护，这意味着可以在潜在问题造成重大损害之前进行识别和处理。这缩短了停机时间并提高了系统效率，从而导致显著的成本节约。
- 2. 它通过创建系统的控制论模型来优化系统性能，通过测试不同的场景来有效地运行系统。这可以提高性能、降低能耗并提高生产率 [12]。
- 3. 它可以通过通过创建产品或系统的控制论模型来改进产品设计，以理解潜在问题，并在产品制造之前尝试其他设计方案。这可以提高产品质量并降低制造成本。

技术的演进是由计算、数据分析和 IoT 的进步驱动的。高速计算系统和强大的数据分析工具的发展使得能够创建模拟物理资产或系统行为的复杂控制论模型。IoT 的增长也是 DT 技术的主要驱动力之一。IoT 能够从物理资产或系统收集实时数据。这种控制论模型可以用于监控物理资产或系统的性能并识别潜在问题 [13]。

DT 技术正被应用于广泛行业。在制造业中，它被用于监控生产线性能、优化设备效率并提高产品质量。在医疗领域，该技术被用于创建患者的控制论模型以监控其健康并预测潜在问题。在航空航天和国防领域，可以监控飞机的性能，并在潜在设计问题成为重大问题之前识别并修复。

## 用于工业 4.0 和 5.0 的数字孪生

随着技术的不断演进，它可能会成为依赖复杂系统和资产的行业不可或缺的工具 [14]。

### 16.3.2 DT 技术在工业 4.0 和 5.0 中不可或缺的角色

正如前面所述，该技术已成为依赖复杂系统和资产的行业的本质工具。它提供物理资产或系统控制论模型的能力，使工程师能够监控其性能、预测潜在问题并优化操作，使其成为工业 4.0 和 5.0 的关键组成部分。在工业 4.0 中，DT 技术被用于监控生产线性能、优化设备效率并提高产品质量。通过创建生产线的控制论模型，工程师可以在问题造成重大影响之前识别潜在问题。这包括预测性维护、缩短停机时间和提高生产线效率。此外，通过识别以最小能耗最高效运行的方法来优化设备也可能很有益。通过创建产品的控制论模型，设计师可以在产品制造之前识别潜在问题并测试不同的设计。这降低了缺陷风险并提高了产品质量。

在工业 5.0 中，DT 技术被用于创建一个以人为中心的制造环境。通过创建物理资产或系统的控制论模型，工程师可以实时监控制造过程的性能并进行调整以提高效率和生产力。这使工人能够花费更多时间在需要人类技能和创造力的任务上，例如解决问题、批判性思维和创新。它还可以优化制造过程对环境的影响。通过创建制造流程的控制论模型，工程师可以识别改进领域并测试不同场景以减少浪费并最大限度地减少过程对环境的影响。此外，DT 技术还用于在工业 5.0 创建个性化产品 [16]。通过创建产品的控制论模型并结合客户数据，制造商可以创建满足单个客户独特需求和偏好的定制产品。这使制造商能够创建更具个性化的产品，提高客户满意度和忠诚度。

### 16.3.3 工业 4.0 和 5.0 DT 案例研究

工业 4.0 中使用 DT 技术的一个示例是西门子的“工厂数据服务”。西门子是工业制造领域的全球领导，他们开发了一种 DT 平台，使制造商能够实时监控其生产线。西门子工厂数据平台利用传感器和数据分析在故障导致重大问题之前监控生产线并进行识别。该平台创建生产线的控制论模型，以模拟不同的场景并测试不同的运行条件。
