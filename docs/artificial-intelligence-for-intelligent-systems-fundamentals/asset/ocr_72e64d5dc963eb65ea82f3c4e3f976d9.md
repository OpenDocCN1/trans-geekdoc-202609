# 2.2.2.9 Swish

Using the sigmoid function, we can get the swish function by multiplying $x$ by it.

$f(x) = \frac{x}{1+e^{-eta x}} (2.9)$

The result of equation 2.9 is shown in Figure 2.13 with $eta = 0.01$. Google's brain team proposed the swish feature. Across many difficult datasets, their tests demonstrate that swish works quicker than ReLU of deep models.

# Advantages:

Does not create the issue of disappearing gradients. It has been shown to be somewhat superior than ReLU.
