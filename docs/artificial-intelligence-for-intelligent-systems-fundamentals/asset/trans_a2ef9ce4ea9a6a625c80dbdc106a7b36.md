

# 机器学习算法在肝病早期检测中的应用

Devannika 等人 [8] 使用印度肝脏患者记录（Indian Liver Patients' Records）数据集提出了一种改进的支持向量分类器（CSA-SVM），用于对肝病进行准确诊断。其分类准确率达到 99.49%，他们在利用乌鸦搜索算法（crow search algorithm）优化 SVM方面表现出色。

为了识别和预测肝病，Shaheelum 等人 [9] 讨论了机器学习技术的使用。研究中比较了 SVM、KNN、k-means 聚类、神经网络和决策树等一些方法论。其中，决策树的最高准确率达到了 98.46%。该研究强调了早期预后对于高效诊断和康复的重要性。

B. Khan 等人 [10] 旨在使用不同的分类算法预测早期肝病。他们根据参数和预测准确率比较了随机森林（RF）、逻辑回归和基于分离的分离算法。研究使用了来自多种来源的肝病数据集。在所有算法中，RF 表现最好，具有改进医疗服务和早期疾病预测的潜力。然而，它的局限性在于仅关注了相关工作，而没有考虑肝病预测中的其他影响因素。

Singh 等人 [11] 提出了一种基于特征选择和分类方法的肝病预测软件方法。他们使用了加利福尼亚大学欧文分区的印度肝脏患者记录数据集。研究检查了六种不同分类算法的准确性，并使用了多种指标来评估结果。该研究讨论了软件开发方法，建议对复杂项目使用瀑布模型，并为智能肝病预测软件的开发做出了贡献。

Nahar 等人 [12] 使用印度肝脏患者记录数据集对集成算法进行了肝病预测的对比分析。研究比较了 AdaBoost、LogitBoost、BiggRep、BegJ48 和 RF 模型，发现 LogitBoost 最准确。该工作通过研究和比较集成方法的使用做出了贡献。该数据集包含 416 条患病记录和 167 条非患病记录。模型构建和评估使用了 WEKA 工具箱。

R. Khan 等人 [13] 对肝脏病变的计算机辅助诊断进行了系统性综述，重点关注了超声检查、计算机断层扫描和磁共振成像。论文分析了预处理、属性分析和分类技术，强调了利用纹理属性进行属性分析以及使用 SVM 进行分类。

Kuzhippalli 等人 [14] 利用机器学习技术提出了一种用于印度患者肝病自动诊断的新型分类器。他们利用 UCI 存储中的印度肝脏患者记录数据集评估了各种分类方法和可视化策略。使用孤立森林（isolation forest）进行异常值检测，并使用增强特征选择算法来提高性能。结果显示准确率提高且分类时间缩短。集成估计器（stacking estimator）结合 RF 达到了最高率。
