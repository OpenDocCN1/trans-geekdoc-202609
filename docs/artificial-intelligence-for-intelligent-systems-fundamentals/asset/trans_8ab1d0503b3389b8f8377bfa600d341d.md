

## 第9章

## 基于人工智能的物联网网络异常入侵检测系统：趋势、解决方案与挑战

Farhood Nishat

### 9.1 引言

如今，物联网（IoT）是一项趋势技术，用于将信息从一个地方传输到另一个地方。无线通信技术认为是物联网网络的骨干 [1, 2]。物联网网络可以部署许多研究领域，包括智能电网、智能城市 [3]、交通行业 [4, 5]、医疗保健 [6] 和农业 [7]，以及军事应用 [8, 9]。人工智能（AI）与物联网的结合将彻底改变智能城市的概念。智能、尖端的智能城市将利用人工智能、机器学习（ML）[10]、深度学习（DL）[11]以及联邦学习（12）。在未来需要引入人工智能的流量监控应用。物联网网络由传感器、网络和应用程序组成。图9.1 展示了物联网的实时应用。互连性、带宽和端到端延迟是物联网中的主要问题。由于物联网存在这些问题，入侵者可以轻易影响整个网络。此外，物联网节点非常容易受到网络攻击。拒绝服务（DoS）、分布式拒绝服务（DDoS）、域名系统（DNS）、死亡之源、黑洞攻击和 Sybil 攻击是物联网网络的危险威胁。入侵者节点发送虚假数据包以破坏内部的通信信道。弱信号也方便入侵者加入或劫持物联网 [13]。传统系统无法保证或保障物联网的安全。在入侵检测系统（IDS）的帮助下，可以实现网络攻击检测。至少存在七种 IDS：异常检测、混合检测、网络 IDS、主机 IDS、基于协议的 IDS 和基于应用的 IDS。本章的重点是针对物联网的异常检测 IDS。异常检测 IDS 基于特定的阈值，通过该阈值可以很容易检测到模式。基于特征的 IDS 拥有攻击模式数据库。混合 IDS 是异常和特征的结合。本章的主要贡献点如下：

- 基于 AI 和 ML 的异常检测技术和解决方案。
- 基于人工智能的异常检测 IDS 应用和案例。
- 整合了使用人工智能实现高准确性的平衡。
- 充分讨论了未来的趋势、挑战和解决方案。

### 9.2 文献研究

本节结合了用于物联网支持网络的异常检测 IDS 传统技术的局限性/缺点：

异常检测 IDS 被认为是几乎每个研究领域的最佳实践。这种技术对于检测可能的网络攻击非常有帮助。Georgios Zachos 等人针对非常脆弱的医疗物联网（IoMT）提出了异常检测 IDS。虽然所提方法易于从 IoMT 传感器中收集历史日志文件，然而，在仿真中使用了机器学习技术来减少开销。除了 IoMT 之外，还介绍了一种边缘计算传感器，它由血压传感器、体温 传感器、运动传感器和胰岛素泵执行器组成。因此，需要确保整个物联网网络中的数据流量监控。在实验期间使用了二分类。同时，设备重量、计算开销和延迟是需要适当解决的问题 [14]。

Muadha Alsoufi 等人的基于深度学习的物联网 IDS 经过设计，并与无监督和半监督学习技术进行了比较。异常检测 IDS 可应用于交通、智能电网、智能城市、农业等许多研究领域，以识别可能的攻击。零日攻击是使用异常 IDS 进行检测的重点。制定了一种基于深度学习的 IDS 以删除冗余记录，并进行了质量评估。未来需要进一步优化时间复杂性和训练时间 [15]。

Saeid Sheikhi 等利用粒子群优化、灰狼优化和遗传算法提出了用于检测异常的新颖物联网 IDS。这种方法用于下一代网络安全。在实验中使用了 NSL-KDD 数据集。基于反向传播的神经网络在未来需要进一步优化。这种方法本质上是算法的组合。性能评估可以使用 F1 分数、召回率和准确率 [16]。

Suejong Kim 等模拟了用于异常检测 IDS的环境。物联网网络存在许多安全问题，特别是由于恶意软件引起的检测。局部离群值可以很容易检测异常和正常数据包。异常检测的误报率需要进行平衡 [17]。

Wang 等人提出了一种基于玩家、策略和树结构的新颖模型，利用博弈论检测网络威胁 [20]。

这些传统技术用于检测网络攻击。因此，基于异常检测的新颖阈值可以解决许多相关问题。

### 9.3 基于人工智能的物联网异常入侵检测系统

物联网拓扑功能多变，但容易受到网络攻击。因此，物联网需要适当的安全保障通信信道。

利用数据包进行 IDS 监控是可能的。人工智能 IDS 被认为是检测网络威胁的新概念。由于这种技术，可以使用机器学习进行异常检测的识别。基于人工智能/机器学习的 IDS 是一种使用大量数据的有效方法。物联网传感器收集的信息可以用于决策过程。基于人工智能/机器学习的 IDS 具有识别非法数据包的能力。人工智能/机器学习技术涉及训练和测试过程。与人工智能/机器学习技术相比，传统方法不再流行。使用基于人工智能的 IDS 可以实现高水平的准确性。此外，深度学习是机器学习的一个类别，也可用于检测网络威胁。此外，人工智能的 IDS 依赖于特征选择、机器学习流水线、数据预处理、标注、数据清洗、数据加载和数据集均衡 [21–24]。

### 基于机器学习异常 IDS

机器学习基本上是一种数据分析方法。此外，机器学习是人工智能的一个子类。机器学习有两种类型，包括监督学习和无监督学习。监督学习类别中带有标签的数据。然而，无监督学习没有标签。机器学习技术可以是半监督、无监督和强化学习。强化技术直接从环境中学习。图9.2 展示了监督、无监督、半监督和强化学习等机器学习类型。在实验期间，可以进行二分类或多级分类。过拟合问题在机器学习技术中已解决。监督学习 IDS 可以很容易预测或识别网络流量 [25–27]。更有趣的是，存在参数和非参数模型，如逻辑回归、朴素贝叶斯、k-最近邻、决策树和支持向量聚类（SVM），可用于检测网络攻击 [28–35]。
