

# 机器学习算法在肝病早期检测中的应用

表 14.1 数据集平衡前的算法对比

| 算法 | AUC | 精确率 (Precision) | 回回率 (Recall) |
|---|---|---|---|
| RF | 78% | 0.58 | 0.47 |
| KNN | 74% | 0.48 | 0.43 |
| Gradient Boost | 74% | 0.5 | 0.43 |
| XGBoost | 73% | 0.46 | 0.43 |
| Extra Tree | 85% | 0.75 | 0.6 |
| AdaBoost | 77% | 0.56 | 0.5 |
| LogitBoost | 78% | 0.57 | 0.53 |
| CatBoost | 82% | 0.7 | 0.53 |

注：KNN，k-最近邻算法；RF，随机森林；XGBoost，极端梯度提升。

LogBoost 的得分分别为 77% 和 78%。KNN 和 XGBoost 算法的准确率得分为 74%，而 gradient boost 的准确率得分为0.74%，精确率为 0.5，回回率为 0.43。RF 算法的准确率为 0.78，高于 KNN、XGBoost 和 gradient boost 的得分，但低于 extra tree。使用 AdaBoost、extra tree 和 CatBoost 创建的集成模型获得了 0.82 的分，精确率为 0.7，回回率为 0.53。

毫无疑问，不平衡数据会对机器学习技术产生负面影响。为了解决这个问题，本研究对所考虑的数据集采用了欠采样（undersampling）、过采样（oversampling）和 SMOTE 方法。

表 14.2 显示了实施欠采样后各种机器学习算法的得分。gradient boost 算法具有最高的准确率分分 0.58，其次是由 AdaBoost、extra tree 和 CatBoost 算法组成的投票分类器，准确率为 0.57。在列出的单独算法中，RF、KNN、extra、AdaBoost 和 CatBoost 的精确率得分最高，均为 0.54 或 0.55。回回率最高的是 gradient boost 算法，得分为 0.64。注意，表中未给出所有算法的精确率和回回率得分。

表 14.3 显示了对数据集进行过采样后各种机器学习算法的输出。extra tree 具有最高的准确率分 0.92，XGBoost 为 0.90，RF 为 0.89，CatBoost 为 0.86。在列出的单独算法中，extra tree 具有最高的精确率得分 0.89，而 KNN 具有最高的回回率得分 0.76。

表 14.4 呈现了对数据集应用 SMOTE 后所有机器学习算法的结果。extra tree 和 RF 实现了最高准确率分 0.81，CatBoost 的得分也为 0.81。XGBoost 获得了 0.8 的准确率分，而 gradient boost 和 LogitBoost 的得分为 0.78。KNN 的准确率得分为0.78，而 AdaBoost 的得分为 0.74。在精确率方面，RF 和 XGBoost 表现出最高分 0.83，紧随其后的是 extra tree 和 CatBoost，分别为 0.83 和 0.84。逻辑回归显示的精确率为 0.83，而 KNN 的精确率最低，为 0.75。关于回回率，SMOTE 达到了最高分 0.95，CatBoost 得分第二高为0.84，之后是 gradient boost 的 0.82。最后，AdaBoost、extra tree 和 CatBoost 的回回率得分均为 0.73。

## 讨论

各种机器学习算法的结果是不同的。通过欠采样、过采样和 SMOTE 方法，本研究有效地解决了不平衡数据对机器学习技术产生负面影响的问题。值得注意的是，这些方法可以显著提高算法的性能。本研究强调了在处理不平衡数据集时的重要性。

## 结论与未来工作

在未来，我们将继续探索其他机器学习模型以提高检测准确性。研究结果表明，在处理不平衡数据时，选择合适的分类器方法是至关重要的。未来的工作将关注于开发更可靠的工具以改进对肝病的检测。
