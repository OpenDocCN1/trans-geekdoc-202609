Saeid Sheikhi et al. proposed a novel IDS using particle swarm optimization, gray wolf optimization, and genetic algorithm to enhance cyberattack identification modeling. This method is utilized for the security of next-generation communication networks. The network security laboratory (NSL-KDD) dataset is used for simulation. Also, the backpropagation neural network model is simulated during experimentation. There is loophole regarding high accuracy and lower error rate, which must be improved. However, the proposed method is basically a hybrid combination of algorithms to detect cyber threats. F1-score, recall, precision, and accuracy are used for performance evaluation [16].

Suejong Kim et al. simulated the IoT-enabled environment to design anomaly-based IDS. IoT networks have many security issues, especially badly-based detection, which are mostly caused by malware. Local outlier can easily detect illegal and normal data packets in IoT networks. With the help of this research, around eight new attacks are detected. The proposed model presents better results and reduces false alarm. However, minimizing false positive rate needs to be balanced properly [17].
