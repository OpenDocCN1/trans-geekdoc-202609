# 11.2.1 大数据的定义和特征

“大数据”指的是大型且复杂的数据集，使用传统数据处理方法难以处理和分析。规模、速度、多样性和价值是区别于它的关键特征。这包括组织化、半结构化和非结构化数据源 [10]。它可能揭示重大趋势和见解，可能帮助指导各种业务的数据驱动决策。“大数据”也适用于普通系统无法处理的大型数据集 [11]。2011年5月，大数据概念被广泛认为是一个具有竞争、进步和效率前景的光明领域。互联网用户数量从2016 年到2018 年增长了 7.5%，导致总共有 37 亿个人访问互联网。全球数据产量在 2010 年达到约 1 ZB 的峰值，然后在 2014 年增加到 7 ZB [12]。规模、速度和多样性这三个维度最初在 2001 年提出，以描述大数据日益增长的特征 [13]。2011 年，国际数据公司（IDC）利用规模、速度、价值和多样性四个维度建立了一个定义大数据的全面框架。真实性作为大数据的一个重要特征是在 2012 年加入的。本研究强调了数字数据的五个主要特征，如随附的视觉表示所示，尽管存在许多补充性因素 [14]。

规模（Volume）：大数据就是数据。我们目前正见证前所未有的数据生成，范围从 TB 到 EB 级，甚至超过了这些限制。这些数据洪流来自各种来源，包括捕捉现实现象的传感器网络、记录经济活动的复杂财务记录、社交媒体互动的动态织锦，以及各种其他生成器。为了处理这些数据洪流，必须实施扩展且可靠的存储解决方案以及尖端处理技术。这些技术进步对于促进海量数据的存储和全面分析至关重要，使能够获得有价值的见解并做出明智决策 [10]。

速度（Velocity）：指的是海量数据生成和处理的速率。在当今互连的世界中，数据不仅被产生，而且通常是以实时或近实时的方式产生的。这需要对此类数据进行快速高效的处理，这已成为一种要求。以如此快速管理数据的能力对于快速决策以及在以快速转型和波动为特征的行业中保持相关至关重要 [15]。因此，速度概念强调了快速在数据洪流中导航以获取有价值见解并利用新兴机会的重要性。

多样性（Variety）：涵盖了大数据的广阔领域，包括多种数据类型，如结构化、半结构化和非结构化数据。半结构化数据尽管缺乏严格的预定义标准，但显示出程度的内在组织性，通常以可扩展标记语言（XML）或 JavaScript 对象表示（JSON）的形式存在。另一方面，结构化数据遵循组织良好的框架，允许像传统数据库一样进行高效的搜索和检索。非结构化数据包括文本、图像和视频，它们违背了预定义的格式。在这些丰富的织锦中穿行需要使用尖端的数据分析和机器学习技术 [15]。使用此类方法对于从这些异构数据类型中提取有意义的见解并实现它们各种应用行业中的全部潜力已变得至关重要。

价值（Value）：与其他特征不同，数据的价值侧重于数据对于决策有多重要以及它如何在现实生活中使用。Facebook、Google 和 Amazon 等公司已成功使用分析来在其产品中充分利用海量数据。Amazon 有几个数据库存储了有关用户信息及其购买物品的信息。这些信息被用于研究，目标是提供个性化的产品建议并提高销售以及人们与 Amazon 互动的方式。Google 获取 Android 用户所在地的信息，以便 Google Maps 等基于位置的服务运行得更好。Facebook 利用用户的行为来分享朋友并向他们展示与其相关的广告。这三家公司在近年来增长很大。这可能是因为他们花大量时间分析大量的未处理数据，这为他们提供了有用的见解，帮助他们做出更好的战略决策 [14]。
