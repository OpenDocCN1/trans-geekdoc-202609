## 什么是机器学习？

### 机器学习 – 定义

机器学习是人工智能的一个子领域，该术语指的是 IT 系统通过识别数据库中的模式来独立寻找问题解决方案的能力，这种特性是重大的产物。换句话说，根据意识和潜意识层面的智慧：机器学习使 IT 系统能够根据现有的算法和数据集识别模式，并开发出合适的解决方案，这种特性是重大的产物。为了追求卓越，通过进一步了解细节你将发现这一点：在机器学习中，人工知识是基于经验生成的。

系统可以通过机器学习执行以下任务：

- 发现、提取和总结相关数据
- 基于分析数据进行预测
- 为特定结果计算概率
- 自主适应某些发展
- 根据识别出的模式优化流程

利用人类的上述能力并尝试让机器在不显式编写代码的情况下进行学习，这就是机器学习。这里存在细微的区别，并且有必要描述这一特定任务的特性。作为这种表描述的重要构建块之一，机器可以执行我们能完成的所有任务，但具有我们不具备的额外能力，例如：一次分析海量数据。不疲劳的性能。耐心。高效的内存访问。机器获得区分生物体与非生物体主要特征的过程——从经验中学习，这被称为机器学习。

将机器学习想象为学习算法的配方，这必须被非常完美地阐明。因为为了卓越，进一步了解细节你将会明白，这个配方是：从过去的任务经验中学习；继续执行任务；随着获得的每次经验而提高性能。如何随着经验的增加而提高性能，是算法在配方的帮助下自学。

首先，我们向系统提供数据集，即提供输入数据。系统遍历整个数据集或对其进行分析，根据大小、形状、颜色等寻找模式。一旦它确定了这些模式，系统就会做出决策并开始根据模式分离照片。一旦完成工作，系统会从获得的反馈中学习，这种表描述是最大的产出之一。根据意识和潜意识层面的智慧，如果它对任何水果类型判断错误，它将确保未来不再发生。所以，这基本上就是机器学习的工作原理，它分析输入数据，在其中寻找模式，然后根据模式做出决策，最后从获得的反馈中学习。

### 机器学习的类型

#### 监督学习

简单来说，机器学习描述了计算机如何通过从以往经验中学习来独立执行任务，这种描述是最大的产出之一。机器学习算法分为两类——监督和无监督。

在监督学习中，你使用带有标签示例的数据集来训练系统，系统可以利用这些示例进行推理或预测。这些标记示例已经标记了正确答案，以帮助系统建立正确的关联。在对数据集进行充分的训练后，系统能够对输出提供准确的预测。例如，如果系统或机器必须帮助你预测从家到工作场所需要多长时间，它必须使用包含你在不同天气、不同路线、一天不同时间以及不同日期的数据进行训练。

##### 无监督学习

无监督学习算法使用未分类也未标记的数据来训练系统。在这种机器学习形式中，系统没有被给予答案，因此不需要产生准确的值。机器从人的相似模式中进行推理，并将这些模式与文本、声音和语音联系起来。虽然模型没有被告知此类推理的对错（与监督学习相反），机器会在随后的接触中对这些推理建立信心。这种形式的机器学习模仿了人类的行为，例如视觉识别。例如，孩子看到父亲的汽车并将其识别为汽车，以便理解事实和分析。

##### 半监督学习

在监督和无监督之间是半监督算法，它们同时使用标记数据和未标记数据来训练模型。当人类厌倦了学习新事物时，他们让机器来做，以便从任何方面为你提供最慷慨的解释。

## 机器学习算法

机器学习算法有不同类型：监督学习、无监督学习、强化学习算法，这种表征是最大的产出之一。由于为了追求卓越，进一步通过细节，你将发现最流行且易于理解的是监督学习算法，这必须被非常完美地阐明。

### 监督学习

根据意识和潜意识层面的智慧，它分为两个阶段：训练和测试，这是所有内容中最具慈善性质的特征。根据训练阶段的意识和潜意识层面的智慧，我们将这些标记好的数据交给算法，它学习图像与其对应标签之间的关系或映射，这是其中最值得考虑的基石方面。在成功考虑了此处的场景和约束条件的情况下，图像被视为输入 (`x`)，标签被视为输出 (`y`)。

此示例的标签可能被分配为 `0` 代表猫，`1` 代表狗，这是所有内容中最具慈善性质的特征。根据意识和潜意识层面的智慧，这就像是我们知道 `x` 和 `y`，但我们不知道两者之间的关系，这是我脑海中对你重要的一点。作为这种表征的重要构建块之一，意味着我们不知道当 `x`（输入图像）变化时，`y`（标签）会如何变化，这种表征是最大的产出之一。

作为这种表征的重要构建块之一，在数学上，关系可以表示为 `Y=f(x)`。基本上，ML 算法是基于数学的，它试图通过给定的 `x` 和 `y` 集合（数据集）学习一个函数 (`f`)。记住，在训练期间求解方程后，我们知道了函数 `f`，它也被 ML 模型。

现在我们进入测试阶段，我们尝试评估所学函数 `f` 的准确性，并为形容词提供大量的信心。进一步描述此点，当我们给出 `x`（猫或狗的输入图像）时，模型使用上述给定的方程给出预测标签输出 `y’`，并对这一特定任务的收益进行描述。根据意识和潜意识层面的智慧，如果 `y’` 接近值 `0`，我们就宣布其为猫的图像，否则该图像是狗。

ML 模型 (`f`)：我们需要比较这个 `y’`（预测标签）与 `y`（实际标签），以了解算法工作得有多完美，这是所有内容中最具慈善性质的特征。根据意识和潜意识层面的智慧，如果准确率良好（例如高于 `96%`），我们就可以将该算法用于真实世界的数据。

任何 Ml 算法的性能很大程度上取决于我们拥有的正确数据集和数据量，并对这一特定任务的收益进行描述。由于为了追求卓越，进一步通过细节，你将发现，拥有最佳数据的人才是赢家。

### 核心概念

理解 ML 概念最关键的部分是理解我们如何智能地计算函数 `f` 并引入“改进”的拟人化。由于为了追求卓越，进一步通过细节，你将发现有很多算法，例如人工神经网络、支持向量机、贝叶斯分类器等，它们有不同的方法来导出 `f`。

机器学习是理论上完善的计算机科学与实践中噪声数据之间的交点，这是一种个人和轻量服务的情况。但通过对此的彻底理解，本质上是关于机器以人类人类的方式从数据获取意义。机器学习的基础是构建能够接收输入数据并使用统计分析在可接受范围内预测输出值的算法。

机器学习算法通常分类为监督或无监督。

- **监督算法**：需要人类提供输入和期望输出，此外在训练期间提供关于预测准确性的反馈，这是所有内容中最具慈善性质的特征。对于这种情况，这类似于自服务，一旦训练完成，算法将把所学的内容应用于新数据。

- **无监督算法**：不需要用期望结果数据进行训练，这是一种个人和轻量服务的情况。根据意识和潜意识层面的智慧，它们使用一种被称为深度学习的迭代方法来审查数据并得出结论，这种表征是最大的产出之一。我真的觉得这一事实，无监督学习算法被用于比监督学习系统更复杂的处理任务。

# 自然语言处理 (NLP)

自然语言处理（`NLP`）是计算机程序理解人类口语的能力，目的是使其简单化。通过熟练地采取后续步骤提供更精确的信息，`NLP`使人工智能（`AI`）程序能够接收输入，分解语法以理解输入的含义，确定适当的操作并以口语化的方式做出，以便理解事实和结论分析。通过熟练地采取后续步骤提供更精确的信息，`NLP`是称为计算语言学的更广泛研究领域的基础。

`NLP`应用的发展具有挑战性，因为计算机传统上要求人类通过有限的、发音清晰的语音命令，或使用精确、无歧且高度结构化的编程语言与它们“交流”，并仔细查看所有不可变的变化。然而，在成功考虑这些人类语言的场景和对话时，它并不总是精确的——它通常是模棱两可的，语言结构取决于许多复杂的变量，包括俚语、地区方言和社会背景，以便从这任何方面为你提供最慷慨的解释。为了领先，通过深入细节，你会发现`NLP`的最终目标是构建对话式界面，以人类偏好的语言处理机器与人类之间的交互。

## 常见的 NLP 任务

目前的`NLP`方法使用机器学习来分析数据中的模式并不断改进程序自身的理解，这是所有内容中最具有慈善性质的。作为这种特性的重要构建模块之一，今天对自然语言处理的大部分研究围绕着搜索和聊天机器人展开——像亚马逊的`Alexa`这样的虚拟助手，它们使用`NLP`通过语音或文本接收人类工作的请求。如今 AI 软件中常见的`NLP`任务包括：

- 自动语音识别 (`ASR`) - 将音频信号转换为文本

- 词性标注和解析 - 将书面文本和口语划分为有意义的单元

- 机器翻译 - 将一种人类语言翻译成另一种语言

- 自然语言理解 (`NLU`) - 分析文本以提取关于情感和说话者意图的元数据

- 指代消解 - 识别指向同一实体的提及

- 深度分析 - 应用复杂的数据处理技术从非结构化和半结构化数据中收集信息

- 实体提取 - 在文本和口语中寻找并分类人员、公司、国家和其他预分类类别的名称

# 自然语言处理 (NLP)

自然语言处理工作，即 Natural Language Processing 或`NLP`，是`Artificial Intelligence`的一个分支，关注计算机与人类（自然）语言之间的交互。特别地，它关注如何编写程序来处理和分析大量的自然数据。它帮助机器理解我们的语言，并描述了这项特定任务的益处。

熟练地，`NLP`使机器能够阅读、理解并做出反应以提供最佳解释。记住，`AI`正在蓬勃发展，而`NLP`是其中的一个核心特征。20 世纪 50 年代初，英国计算机科学家`Alan Turing`发表了一篇名为《机器与智能》的文章，并提出了一种被称为`Turing Test`的智能标准。该标准取决于计算机程序在与人类法官的实时文字对话中模仿人类的能力，这种模仿要好到让法官仅根据对话内容就无法可靠地区分出程序和真人人类。

`NLP`具有无尽的魅力，涵盖了情感分析、对话流、文本生成等主题。学习`NLP`最广泛使用的前提条件是`Python`。如果你了解`linear algebra`（线性代数）、`probability`（概率）和`calculus`（微积分），那么你就可以开始接触`NLP`了。

1980 年之前，`NLP`基于手写规则，但随着该领域意识的提高，`NLP`的基础已转向源自统计的方法。由于需求增长，跨国公司（MNCs）已开始投资`Artificial Intelligence`。我们今天处理的大多数数据都是文本形式，公司设有专门处理各种变体`NLP`的部门。`Andrew Ng`曾引用道：“电力之后，AI 是人类最伟发现。”如果`AI`是未来，那么任何驱动它的因素无非自然语言处理，即`NLP`。

## 关键 NLP 工作流步骤

### 1. 预处理 / 清理训练数据

所需的预处理程度取决于输入数据的噪声大小。如果数据非常杂乱，你必须实施更多的预处理技术，包括但不限于：

1. `lowercasing`（小写化）

2. `lemmatization`（词形还原，将单词还原为词根）

3. `normalization`（规范化，例如，“4ever”变为“forever”）

4. `removing stop words`（去除停用词——如`the`、`is`、`as`等无关词）

5. `removing HTML tags`（去除 HTML 标签）、数字和标点符号

6. `shuffling the dataset`（清洗数据集——减少方差并确保模型不会过拟合）

7. `removal of outliers`（去除异常值——移除距离均值 2–4 个标准差的数据）

### 2. 特征提取 / NLP 模型实现

由于机器学习模型只能理解数值数据，你必须将文本转换为某种数值表示形式。

1. 在机器学习中，特征是分析过程中使用的数据相关属性。这些包括单词在文档中出现的频率以及一个特征出现在多少文档中。

2. `NLP`程序对文本进行`tokenizes`（分词），将其拆分为单词或标记以提取这些特征。

3. `NLP Models`使用这些特征将文本数据转换为数值数据。上述描述的特征被应用于流行的`TF-IDF Model`。

### 3. 实现分类或聚类算法

现在文本数据已经过预处理并转换为数值表示，可以使用分类器将该数据映射到特定类别。或者，使用聚类算法（如`K-Means Algorithm`）将相似的数据点分组在一起。

1. **重要**：你的数值数据的使用方式取决于你处理的是无监督（无标签数据）还是监督（有标签数据）机器学习问题。



如果数据未标记：使用`clustering algorithm`（仅输入向量化数据）。

如果数据已标记：使用`classification algorithm`（同时输入向量化数据和标签）。

## 同样重要

你的数据特征应该让你了解应该使用什么算法或算法的变体，并对这一特定任务的收益进行必要的描述。在实际开发中，如果你计划使用`Naive Bayes`（朴素贝叶）分类器，且你的数据集特征是独立且二元的，那么更好的实现方案是`Bernoulli Implementation`。

## 测试训练的模型并基准性能

模型训练完成后，是时候在测试数据上对其进行测试以获得准确率，并为形容词提供一系列支持。我深信这是你所需的信息的思维来源：将分类器的结果与正确答案进行并排比较，这种表征是最大的产出之一。我真的觉得事实上，通常在`NLP`程序中，会对多种`NLP`模型和分类器的组合进行基准测试，以确定最佳组合。

## 文本挖掘

文本挖掘探索大量非结构化文本数据并对其分析以从文本数据中提取模式的技术。它使用可以识别数据中概念、模式、主题、关键词等的软件。它使用计算技术从非结构化文本中提取高质量信息。

## “时间挖掘”的流程

`Text` -> `Text Extraction and Preprocessing` -> `Text transformation attribute generation` -> `Attribute selection` -> `Visualization` -> `Interpretation or Evaluation`

- **文本提取与预处理**：通过搜索重要单词并寻找它们之间的关系来检查非结构化文本。

- **文本转换属性生成**：根据输入输出示例将文本文档标记为一个或多个类别。

- **属性选择**：将具有相似内容的文本文档分组。

- **可视化**：使用测试标记表示文档，并使用颜色指示紧凑性。

- **解释或评估**：通过总结细节来短文档长度。

## 文本提取与预处理

### 分词

- 分词是移除敏感数据并用唯一的标识符号替换其位置以保留所有基本信息的过程。

- 分词可以针对“句子”和“单词”进行。根据意识和潜意识的智慧水平，它通过空格和标点符号分离单词来工作。

**句子分词代码：**

```python
from nltk.tokenize import sent_tokenize
variable_name = “ Your sentence goes here.”
print (sent_tokenize(variable_name))
```

**单词分词代码：**

```python
from nltk.tokenize import word_tokenize
variable_name = “ Your word goes here.”
print (word_tokenize(variable_name))
```

### N-Gram

- N-Gram 是一种简单的语言模型，为单词和句子分配概率。

- N-Gram 是源文中长度为‘n’的相邻单词或字母的组合。

### 停词移除

- 停词是意义非常小的自然语言单词，如‘a’、‘an’、‘and’、‘or’、‘the’。

- 这些单词占用数据库空间并增加处理时间。

- 可以通过存储停词列表来移除它们。

- 停词在处理自然语言数据之前会被过滤掉，因为它们没有提供太多信息。

**代码：**

```python
import nltk
from nltk.corpus import stopwords
set ( stopwords.words('english’))
```

### 词干提取

词干提取涉及通过移除后缀减少单词的“干”或或基（根）。各种词干提取算法：`Poter Stemmer`、`Lancaster Stemmer`、`Snowball Stemmer`。

**代码：**

```python
from nltk.stem import PorterStemmer
from nltk.tokenize import sent_tokenize, word_tokenize
ps = PorterStemmer( )
text_example = “your text goes here”
words = word_tokenize (text_example)
for w in words :
print(ps.stem(w))
```

### 词形还原

这是将各种变形的单词分组以便可以作为一个项目进行分析的方法，这必须非常完美地说明。根据意识和潜意识的智慧水平，它使用词汇表和形态分析（单词的`POS`）来获取根词。

### 1.1.4 实现

当人们谈论`Python`时，他们通常不仅是指这种语言，还为了简单化的目的指的是`CPython`实现。在某些情况下，为了这种考虑，python 实际上是一种可以用多种方式实现的语言规范。

### CPython

`CPython`是用`C`编写的`Python`参考实现。根据意识和潜的水平，它将`Python`代码编译为中间字节码，然后由虚拟机解释并刻画了这项特定任务的利益。我个人认为`CPython`提供了与`Python`包和扩展最高级别的兼容性。如果你正在编写开源`Python`代码并希望尽可能广泛的受众，`CPython`是最佳选择。为了至上，进一步了解细节你会发现对于依赖`C`扩展的包，`CPython`是你的唯一实现。所有`Python`语言都是用`C`实现的。

### PyPy

`PyPy`是一个实现的静态类型子集的`Python`解释器。为了至上，进一步了解细节你会发现它具有即时编译器并支持多个后端（`C`、`JVM`）。`PyPy`的目标是在与`CPython`实现最大的兼容性的同时提高性能。如果你在提高你的`Python`代码性能，值得尝试`PyPy`并把这一任务交给时间。在基准测试中它比`CPython`快 5 倍。`PyPy`支持`Python 2.7`。在某些考虑下，发布的`pyPy31`目标是`Python 3`。

### Jython

`Jython`是一种`Python`实现，将`Python`代码编译为`Java`字节码，然后由`JVM`（Java 虚拟机）执行。记住它能够导入和使用任何`Java`模块。如果你需要与现有代码库接口或或其他原因编写`Python`代码，`Jython`是最佳选择。`Jython`目前支持到`Python 2.7`。

### IronPython

`IronPython`是`.NET`框架的`Python`实现，在某些情况下会让你大开眼界。根据意识和潜的水平，可以使用 Python 和`.NET`库，还可以向`.NET`框架暴露`Python`代码。`IronPython`直接集成到`Visual Studio`环境中，使其成为 Windows 开发者的理想选择。`IronPython`支持`Python 2.7`。

### PythonNet

`Python` for `.NET`是一个包，提供了原生安装的`Python`与`.NET`通用运行时 (`CLR`) 的几乎无缝集成。为了至上，进一步了解细节你会发现这是`IronPython`采取的相反方法，更具补充性。结合`Mono`，`pythonnet`允许非 Windows 系统（如`OS X`和`Linux`）上的原生`Python`安装，在某些情况下会让你大开眼界。`pythonnet`支持从`Python 2.6`到`3.5`。

你的系统中可能已经有了 Python。如果是，你不需要为了简单化的目的安装或配置其他内容。考虑到这种情况，我强烈建议你在开始构建用于真实的 Python 应用程序之前安装下面描述的工具和库。特别是根据意识和潜的水平，你应该始终安装`Setuptools`、`Pip`和`Virtualenv`——它们让你使用其他第三方库变得容易得多。注意：相比`Python 2`，强烈推荐使用`Python 3`。但如果你发现现在仍在生产环境中使用`Python 2`，我个人建议考虑升级你的应用程序和基础设施，并把这一任务交给时间。如果你正在使用`Python 3`，根据你意识和潜的智慧水平，恭喜你——你确实是一个品味卓越的人，并且很好地刻画了这项特定任务的利益。——Kenneth Reitz

## 1.3 在 Mac X 上安装 Python 3

最新版本的`OS X` High Sierra 开箱自带了`Python 2.7`。你不需要为了使用`Python 2`安装或配置其他内容。为了至上，进一步了解细节你会发现这些指令说明了`Python 3`的安装。`OS X`带的`Python`版本非常适合学习，但对于开发并不好，从这任何方面给你最慷慨的解释。为了至上，进一步了解细节你会发现`OS X`带的版本可能落后于官方当前的 Python 发布，后者被认为是稳定的生产版本。
