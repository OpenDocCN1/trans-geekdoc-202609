### 在 PHP 中定义变量和常量

在 `PHP` 中，变量是一个命名的存储空间，可以包含一个在脚本执行过程中可修改的值。它由一个名称、一个等号（`=`）和赋值组成。例如：

```php
<?php
$variable_name = "value";
?>
```

另一方面，`PHP` 常量是一个代表在脚本执行期间无法修改的值的命名标识符。它使用 `define()` 函数定义，可在脚本的任何位置使用。例如：

```php
<?php
define("CONSTANT_NAME", "constant_value");
?>
```
