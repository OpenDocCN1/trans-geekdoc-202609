Once this has been done, we display this data in a form similar to the one used to register a new author in the previous chapter.

```html
<form action="modify_author.php" method="POST">
  <h2>Edit an Author</h2>
  <label>Last Name:</label>
  <input type="text" name="lastname" value="<?= $lastname ?>"><br>
  <label>Firstname:</label>
  <input type="text" name="firstname" value="<?= $firstname ?>"><br>
  <label>Email:</label>
  <input type="email" name="email" value="<?= $email ?>"><br>
  <label>Password:</label>
  <input type="password" name="password" value="<?= $password ?>"><br>
  <label>Biography:</label>
  <textarea name="biography"><?= $biography ?></textarea><br>
  <input type="hidden" name="author_id" value="<?= $author_id ?>">
  <input type="submit" value="Edit">
</form>
```

This HTML code represents a form for modifying author information in the database. Here's a detailed explanation:

The `action` attribute of the `<form>` tag specifies the URL of the PHP script that will process the form data once submitted. In this case, it's `modify_author.php` and the HTTP method used is `POST`.

Inside the `<form>` tag, a `<h2>` heading is used to indicate that the form is intended for author modification.

Next, a series of `<input>` fields and a `<textarea>` field are used to enter the author's new information. Each field has a `name` attribute that corresponds to the field name in the `$_POST` array when the form is submitted.

Current field values are defined with PHP, using `<?= ?>` tags to display PHP variables containing the author's current data. For example: `value="<?= $lastname ?>` sets the value of the variable `$lastname` in the form's `lastname` field.

The password field uses `type="password"`, which hides the characters entered for security reasons.

An `<input>` field of type `hidden` is used to store the author ID, but is not visible to the user. This allows the author ID to be passed to the processing PHP script without the user having to enter it.

Finally, a `submit` button is used to submit the form and send the data to the PHP script for processing.

This form allows the user to modify an author's information and submit it for updating in the database.

## Complete Script: `form_edit_author.php`

Here is the complete code of the script `form_edit_author.php`:

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Edit Author</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <?php
  // Retrieve the author ID to be updated
  $author_id = $_GET['author_id'];

  // Connect to database
  $connection = new PDO("mysql:host=localhost;dbname=library", "root", "");
  $connection->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

  // Prepare selection query
  $query = $connection->prepare("SELECT * FROM authors WHERE author_id = :author_id");
  $query->bindParam(':author_id', $author_id);

  // Execute request
  $query->execute();

  // Retrieve results
  $author = $query->fetch(PDO::FETCH_ASSOC);

  // Check if author exists
  if ($author) {
    // Retrieve author information
    $lastname = $author['last_name'];
    $firstname = $author['first_name'];
    $email = $author['email'];
    $password = $author['password'];
    $biography = $author['biography'];
  }
  ?>

  <form action="modify_author.php" method="POST">
    <h2>Edit an Author</h2>
    <label>Last Name:</label>
    <input type="text" name="lastname" value="<?= $lastname ?>"><br>
    <label>Firstname:</label>
    <input type="text" name="firstname" value="<?= $firstname ?>"><br>
    <label>Email:</label>
    <input type="email" name="email" value="<?= $email ?>"><br>
    <label>Password:</label>
    <input type="password" name="password" value="<?= $password ?>"><br>
    <label>Biography:</label>
    <textarea name="biography"><?= $biography ?></textarea><br>
    <input type="hidden" name="author_id" value="<?= $author_id ?>">
    <input type="submit" value="Edit">
  </form>
</body>
</html>
```

In addition to presenting the retrieved data, this form offers the possibility of making modifications before being submitted. When the form is validated, it is directed to the `modify_author.php` script, which is responsible for updating the data in the database using the information entered in the form. This is the code of the `modify_author.php` script after it has been updated:

```php
<?php
$author_id = $_POST['author_id']; // Author ID to be updated

// New author information
$new_lastname = $_POST['lastname'];
$new_firstname = $_POST['firstname'];
$new_email = $_POST['email'];
$new_password = $_POST['password'];
$new_biography = $_POST['biography'];

// Hash password
$password_hashed = password_hash($new_password, PASSWORD_DEFAULT);

// Database connection
$connection = new PDO("mysql:host=localhost;dbname=library", "root", "");

// Update request
$request = $connection->prepare("UPDATE authors SET last_name = :new_lastname, first_name = :new_firstname, email = :new_email, password = :new_password, biography = :new_biography WHERE author_id = :author_id");

// Bind parameters
$request->bindParam(':author_id', $author_id);
$request->bindParam(':new_lastname', $new_lastname);
$request->bindParam(':new_firstname', $new_lastname); // Note: Potential bug in source, binding $new_lastname instead of $new_firstname
$request->bindParam(':new_email', $new_email);
$request->bindParam(':new_password', $password_hashed);
$request->bindParam(':new_biography', $new_biography);

// Execute query
$result = $request->execute();

// Check update success
if ($result) {
  echo "Information updated successfully";
} else {
  echo "An error occurred during the update.";
}
?>
```

This PHP code retrieves the data submitted by the author's modification form via the `POST` method. Using the `$_POST` superglobal, it first retrieves the author ID to be updated, along with new information such as first and last name, email, password and biography.

The password is then hashed using the `password_hash()` function for security reasons. A connection to the database is then established using `PDO`.

An update query is prepared to update the author's information in the `authors` table. The query parameters are linked to the values retrieved from the form.

The request is then executed and the result checked. If the update is successful, a success message is displayed. Otherwise, an error message is returned.
