
# PHP's Built-in Mathematical Functions

PHP's built-in mathematical functions offer a variety of tools for performing common mathematical operations. From simple calculations to more advanced operations, PHP offers a full range of functions to meet the needs of developers. In this section, we'll explore some of the most commonly used mathematical functions available in PHP.

## Basic Functions

PHP's basic functions provide essential tools for performing simple mathematical operations. They are widely used in web development to perform basic calculations and manipulate numbers. The table below summarizes some of the most commonly used basic functions:

![Image](images/image-92.png)

*   **`abs()`**: This function returns the absolute value of a number, i.e. its value without sign. For example:

    ```php
    $number = -10;
    $absolute_value = abs($number); // $absolute_value is 10
    ```

*   **`sqrt()`**: The `sqrt()` function returns the square root of a number. For example:

    ```php
    $number = 25;
    $square_root = sqrt($number); // $square_root is 5
    ```

*   **`pow()`**: This function returns the value of a number raised to the power of another number. For example:

    ```php
    $number = 2;
    $power = 3;
    $result = pow($number, $power); // $result is 8 (2^3)
    ```

*   **`round()`**: The `round()` function rounds a number to the nearest decimal place according to the specified precision. Here's an example:

    ```php
    $number1 = 3.7;
    $arrondi_number1 = round($number1); // $arrondi is 4
    $number2 = 12.146345;
    $arrondi_number2 = round($number2, 2); // round $number2 to 2 decimal places, result is 12.15
    echo $arrondi_number1;
    echo "<br>";
    echo $arrondi_number2;
    ```

These basic functions are useful in many programming situations where simple operations on numbers are required. They offer flexibility and ease of use for performing basic mathematical calculations in PHP.

## Random Functions

PHP's random functions can be used to generate random numbers and perform random operations in applications. They are widely used in games, simulations, random data generation and more. Here are some of the most commonly used random functions in PHP:

### Random Number Generation

*   **`rand($min, $max)`**: This function generates a random number between the values `$min` and `$max`. The value returned is an integer.

    Example:

    ```php
    $random_number = rand(1, 100);
    echo "Random number between 1 and 100: $random_number";
    ```

    Each time you run this code, you'll get a random number between 1 and 100.

*   **`mt_rand($min, $max)`**: Similar to `rand()`, but uses a **Mersenne Twister** random number generator, renowned for its better random number distribution.

    Example:

    ```php
    $random_number = mt_rand(1000, 9999);
    echo "Random 4-digit PIN code: $random_number";
    ```

# String Functions

String functions in PHP offer a variety of tools for efficiently manipulating and processing strings. Here are some of the most commonly used functions in this category:

### `strlen()`

This function returns the length of a character string.

Example:

```php
$text = "Hello";
$length = strlen($text); // $length is 5
echo $length;
```

Result:

![Image](images/image-95.png)

### `strpos()`

This function returns the position of the first occurrence of a substring in a string.

Example:

```php
$text = "Good morning";
$position = strpos($text, "mor"); // $position is 5
```

In this example, we have a string `$text` containing the value "Good morning". The `strpos()` function is used to find the position of the first occurrence of the substring "mor" in the string `$text`. As "mor" starts at the fifth position in "Good morning", the `strpos()` function returns the value 5, which is the starting position of the sub-string "mor" in the string `$text`. Note that position indexing starts from zero. The letter "G" has index 0, the letter "o" has index 1, the second letter "o" has index 2, the letter "d" has index 3, the space has index 4, and the letter "m" has index 5.

### `substr()`

This function returns a substring of a given string from the specified position and length.

Example:

```php
$text = "Hello everyone";
$substring = substr($text, 3, 10); // $substring is "lo evryon".
echo $substring;
```

In this example, we have a string `$text` containing the value " Hello everyone". The `substr()` function is used to extract a substring from `$text`. The function's parameters are as follows: the first parameter is the original string (`$text`), the second parameter is the starting position of the extraction (3 in our case, which means from the fourth character of the string `$text`, as indices start at zero), and the third parameter is the length of the substring to be extracted (10 characters in our case). Thus, the `substr()` function extracts a substring from `$text` starting from the third position with a length of ten characters, giving "lo evryon". Spaces are also characters to be taken into account.

### `strtoupper()` and `strtolower()`

These functions convert a string to upper or lower case respectively.

Example:

```php
$text = "Hello everyone";
$upper_text = strtoupper($text); // $upper_text is "HELLO EVERYONE".
$lower_text = strtolower($text); // $lower_text is "hello everyone".
echo $upper_text;
echo "<br>";
echo $lower_text;
```

![Image](images/image-97.png)

### `str_replace()`

This function replaces all occurrences of a substring with another in a string.

Example:

```php
$text = "Hello everyone";
$new_text = str_replace("everyone", "friends", $text);
echo $new_text;
```

In this code, the `str_replace()` function will replace the string "everyone" in the string `$text` with the string "friends". If you run this code, you'll get the following result:

In short, these functions are just a few examples of the many others available in PHP to manipulate strings efficiently and flexibly.

# Functions for Arrays

Array manipulation is a common task in PHP, and the built-in functions provided by the language make it much easier. Here are some of the most frequently used functions for working with arrays:

| Function | Meaning |
| --- | --- |
| `count()` | Count the number of elements in an array |
| `sort()` | Sort an array in ascending order |
| `rsort()` | Sort an array in descending order |
| `array_push()` | Add one or more elements to the end of an array |
| `array_unshift()` | Add one or more elements to the beginning of an array |
| `array_pop()` | Deletes the last element of an array |
| `array_shift()` | Deletes the first element of an array |
| `array_slice()` | Extract part of an array |
| `array_merge()` | Merges one or more arrays |
| `array_key_exists()` | Checks whether a key exists in an array |
| `in_array()` | Checks whether a given value exists in an array |
| `array_search()` | Searches for a given value in an array and returns the corresponding key |
| `array_replace()` | Replaces the elements of an array with those of one or more other arrays |

### `sort()` Function

The `sort()` function sorts an array in ascending order of values. It directly modifies the array in place and returns a Boolean indicating the success of the operation. Here's an example:

```php
$fruits = ["orange", "apple", "banana", "strawberry"];
sort($fruits);
echo "<pre>";
print_r($fruits);
echo "</pre>";
```
