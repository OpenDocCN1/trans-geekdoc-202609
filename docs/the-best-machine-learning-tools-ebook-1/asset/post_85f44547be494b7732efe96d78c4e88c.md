
## CONCLUSION

The extreme division in opinion is visible when it comes to deciding the best tool for Data Science. Today the term data science is no longer limited to exploring data or creating statistical models, but requires production of algorithms and obtaining data from various unconventional sources. It also requires automation, and this is where R seems rigid and too specialized, and Python seems more inclusive and diverse, and makes it the ideal candidate for many technology-driven companies, causing people to switch. Just like SAS had, R also has the stronghold in the financial sector, and this is the toughest wall to break for any new tool, as this sector is less open to frequent changes and experimentation. Still, recent developments such as Bank of America opting for Python show that the wall is cracking, and the lingua franca for data scientists is no more unopposedly R. An unsaid benefit of knowing Python is that once it is learnt for data analysis, one can move beyond into the field of programming and development if one wishes, while R sort of hits a dead end and can't be made to move beyond data analysis. R seems to have stuck with solving the statistician's problem, and the 'by the statisticians' approach has caused it to lag behind, whereas Python is able to undertake a range of problems. However, it must be remembered that increasingly more people are using a combination of both the languages, and with Python providing RPy2, which can make the user have all of R's major functionality along with the fact that Python is easy to collaborate with, Python has decisively won the battle.
