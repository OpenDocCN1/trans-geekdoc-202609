# Information Protection Classifications with Criteria and Definitions

# Information Criteria Classifications and Definitions

| Criteria | Classification | Definition |
|---|---|---|
| Confidentiality (Sensitivity) | Top Secret | Item could cause grave harm to national security. |
| Confidentiality (Sensitivity) | Secret | Item could cause serious damage to national security. |
| Confidentiality (Sensitivity) | Confidential | Item could moderately affect national security. |
| Confidentiality (Sensitivity) | Private | Item could cause serious harm to the entity, customers, or employees. |
| Confidentiality (Sensitivity) | Sensitive | Item could cause moderate harm to the entity, customers, or employees. |
| Confidentiality (Sensitivity) | Internal | Item should not extend beyond the entity's business perimeter. |
| Confidentiality (Sensitivity) | External | Item protection and handling requirements are provided by an outside entity. |
| Confidentiality (Sensitivity) | Public | Item will not harm the entity or employee(s). |
| Confidentiality (Sensitivity) | Unclassified | Information is not sensitive or restricted. |
| Integrity (Criticality) | Financial | Item usage in reporting operational results. |
| Integrity (Criticality) | Statistical | Item provides the means to quantitatively assess a defined population. |
| Integrity (Criticality) | Commentary | Item provides additional or supplementary information regarding an entity activity. |
| Availability (Impact) | Critical | Item restoration must occur as soon as possible to sustain a crucial process. |
| Availability (Impact) | Essential | Item restoration must occur as soon as required resources are utilizable. |
| Availability (Impact) | Desirable | Item suspension for the duration of an emergency is acceptable. |
| Availability (Impact) | Necessary | Item restoration must occur as soon as the entity returns to a normal processing environment. |
