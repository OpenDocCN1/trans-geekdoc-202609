Most entities contain a group of core processes (Davis, 2008b). Consistent with this view, ISSM encompasses processes for maintaining and improving service quality alignment (Davis, 2008b), which link to a protective service value system. A protective service value system allows all the component processes, activities, and tasks to work together for value creation. Information security service alignment occurs through a constant cycle of agreeing, monitoring, reporting, reviewing achievements, and initiating actions to eradicate unacceptable information security service levels.

# Information Security Service Delivery

Information security service delivery necessitates effective ISSM practices. Management should design objectives and goals for information security service delivery (see Table 1.2). Regarding accomplishing objectives and goals, particular links passing through strategic, tactical, and operational management levels of functional reporting ensure alignment with the entity’s mission (Davis, 2008b). High-level control objectives need identification and linkage with rationale for the development of lower-level information security objectives and goals.
