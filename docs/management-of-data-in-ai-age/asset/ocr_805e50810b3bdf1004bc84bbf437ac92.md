# III. How does all of that translate into problem solving?

Analysis provided above could lead to the hypothesis that problem solving is one of the core cognitive functions of the human brain. And a deep learning-like brain configuration guides the process.

Problem solving is seen, then, as a higher level brain activity that connotes interaction with many other cognitive processes such as abstraction, searching, learning, decision making, inference, analysis, and synthesis. (Wang et al 2008).

The brain performs this cognitive function when it seeks a solution for a given problem or a potential route to a goal. Problem solving can be perceived by the brain, then, as a learning and analysis process.
