# II. Key variables: problem solving, deep learning and brain cognition

+   - What is problem solving?

Problem solving is “higher-order cognitive process that requires the modulation and control of more routine or fundamental skills” (Goldstein & Levin, 1987). It occurs if an organization, an individual or a system does not know how to proceed from a given state to a desired goal state. It starts with an idea, or a problem, and proceeds all the way to an end result.
