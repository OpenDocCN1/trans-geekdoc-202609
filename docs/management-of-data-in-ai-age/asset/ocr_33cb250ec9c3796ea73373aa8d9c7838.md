# 3. System-centered approaches to AI

If we now turn to the most recent developments surrounding AI, and a set of contemporary factors that motivates a turn to “applied AI” as proposed in this article, we should acknowledge the increasing interest in system-centered approaches to AI. No longer do we need to write line-by-line code to build AI systems, and no longer do we need to hand-feed these systems with data. Instead, several platforms and development frameworks (including e.g. Microsoft azure) now offers ready-made “AI components” to integrate AI-functionality in just about any digital service. This development enables compositional design (Stolterman & Wiberg, 2020) of AI-solutions, and it lowers the development barrier to build functional AI-systems for real-world use contexts.

With the systems-centered approach to AI developers can now focus on what they want the AI system to do (i.e., how it should be applied), rather than just getting it to work (from a technical viewpoint).
