In this cycle one recognizes a problem, defines the problem, develops a strategy to solve the problem, organizes the pertinent knowledge, mobilizes required resources, conducts remedial action, monitors progress, and evaluates the solution (Schacter, D.L. 2009).

+   - **What is deep learning?**

Deep learning is a subset of machine learning. It is a process that involves neural networks that could learn, unsupervised, from unstructured or unlabeled data.

Machine learning works with algorithms that detect patterns and learn how to make predictions. The process can be supervised, semi-supervised or unsupervised. In supervised learning an algorithm learns from labeled training data how to predict outcomes for unknown variables. In unsupervised learning unlabeled data lead to a model that works on its own to discover outcomes.
