This system of equations which is utilized in the training process may be expressed as

```
$$\begin{bmatrix} W_{j1p}-1 & W_{j1p} & \dots & W_{j1n} \ W_{j1n} & W_{j1n}-1 & & W_{j1p} \ & & \dots & &dotsdots \ W_{Jnp} & & W_{Jnn} & \dots & W_{Jn}-1 \end{bmatrix} = \begin{bmatrix} 0 \ \vdots \ 0 \end{bmatrix} \begin{bmatrix} \sigma_{j1p} \ \sigma_{j1n} \ \sigma_{j2p} \ \sigma_{j2n} \ \vdots \ \sigma_{JNp} \ \sigma_{Jn} \end{bmatrix}$ $(11.7)$
```

Since (11.7) is a homogeneous linear equations system, it has a nontrivial solution only if the determinant value of its coefficients matrix is equal to zero. We have shown that applying the following condition results in zero determinant value for the coefficients matrix of (11.7) and hence a nontrivial solution:

```
$$\sum_{i=1}^{N}(W_{jin} + W_{jip}) = 1$ $(11.8)$
```
