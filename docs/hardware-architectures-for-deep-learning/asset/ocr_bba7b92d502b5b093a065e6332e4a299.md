The same is true for the inhibitory cluster. These are assigned to different CxQuad arrays. Then, with the intermediate support of glue logic on the PFGA board of the NeuRAM3 demonstrator hardware setup, the synapse Address Event Representation (AER) streams are routed to the ports of the segmented bus IC. That latter has 9 of the 12 possible unidirectional connections enabled, as shown in the figure.

A feasible schedule for this can be obtained by routing the required global synapse communications (big arrows) sequentially on the segmented bus architecture, as illustrated in Figure 10.4. Note that some of these synapse communications are mutually compatible with each other, so these can be and have also been scheduled in parallel. One example of this is illustrated in Figure 10.5.

To scale this for more local neural clusters, we must split the excitatory and inhibitory neuron groups further. That is illustrated in Figure 10.6. There it also visible that the global synapse communication (the number of big arrows) are increasing in a highly sublinear way, so they do not explode.

We have implemented a prototype test chip for this global synapse communication functionality. The proposed NeuRAM3 mixed-signal neuromorphic platform instance demonstrates the functionality of this switch in a not yet scaled up form so compatible with the mapping of Figure 10.3. To reduce both the fabrication cost and the related challenges, we have currently designed a prototype in IMEC’s ultralow leakage IGZO TFT plastic technology. The switch provides connectivity between the excitatory and inhibitory neural clusters mapped over the CxQuad cores. It has been fabricated, packaged and measured.
