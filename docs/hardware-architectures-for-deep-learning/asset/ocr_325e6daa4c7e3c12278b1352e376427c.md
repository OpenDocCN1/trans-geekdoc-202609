This method facilitates the distribution of the processing workload by constraining regions of the parameter matrices to contain an equal number of nonzero connections. After pruning, the memory footprint of the model parameters is reduced using sparse encoding methods, such as compressed sparse column (CSC) or compressed sparse row (CSR). Some accelerators have been designed to operate directly on sparse encoded models and efficiently skip zero-valued connections [17,18].

Singular value decomposition (SVD) is another technique for reducing the number of model parameters. By keeping just the largest values, the dimensionality of parameter matrices can be reduced while maintaining an acceptable level of accuracy. In [20], SVD is applied to a fully connected layer of a convolutional network and achieved a compression rate of 7x with only a 0.04% loss in prediction accuracy. In [21], this technique is applied to a five-layer LSTM for speech processing and reduced the model size by 3x with only a 0.5% loss in prediction accuracy. An advantage of this approach is that it does not require special encoding (and consequently memory) to store the compressed model; this translates to simplified accelerator architecture because the parameter structure does not have to be decoded.

The quantized model can then be retrained using only the shared weights. This technique allows parameter matrices to be stored as indices into the shared weight codebook, thus reducing the memory footprint. For example, a weight sharing with 32 shared weights requires only 5 bits to enable on-chip parameter storage in their hardware accelerator for fully connected layers [18]. A benefit to this approach is that it does not restrict the datatype of the actual weights; high-precision datatypes be used for computation with minimal storage requirements.

Another quantization technique is binary (+1 or -1, this method constrains all weight values during training requiring only a single bit to represent. An extension of this technique applies the same quantization on layer activations. Various approaches have been proposed for training a neural network with binary weights and activations [22–24]. The approach detailed in [24] was applied to an LSTM for text prediction and resulted in better performance and performance efficiency with negligible loss in prediction accuracy, compared with that of the full-precision model. Binarization comes with significant advantages for hardware implementation. In a weight-only binary scheme, multiplication is reduced to a two’s complement operation, thus eliminating the need for expensive hardware multipliers. Weight and activation binary simplify hardware implementation even further, requiring only XNOR and bit-count operations in place of multiplicity accumulations. In both schemes, model parameter size is drastically reduced.
