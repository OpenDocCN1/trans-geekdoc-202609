It should be noted that the networks in Figures 9.11 and 9.12 are trained with sequential approach. To allow faster training, instead of initiating weights from Gaussian distribution, we initiated the weights in the CONV layer of each iteration to the corresponding CONV layer of previous iteration (for the first iteration, weights were initiated with Gaussian distribution). After 4th iteration, the feature map starts identifying completely different patterns, which is indicative of evolving nature of ICNN.

### 9.8 Contextual awareness in ICNN

Real-time application of deep learning algorithms is often hindered by high computational complexity and frequent memory accesses. Network pruning is a promising technique to solve this problem [38]. The network can be pruned by learning only important connections. That is, if weight of a connection is less than threshold, the connection is dropped [39,40]. However, ICNN enables us to apply pruning at runtime. This capability is the result of having early classification that provides ICNN with a hint to avoid computation related to least probable classes.

Upon completion of the first iteration, ICNN develops a form of contextual awareness as it outputs the probability of various classes with respect to an input image. We explore how this feature may be used to reduce the computational complexity of CONV or FC layers in the next iterations based on the class probabilities. To this end, we compare the class probabilities from various iterations to understand the predictions and class probabilities derived in each iteration relate to ones in the next iterations.

For example, ICNN, as illustrated in Figure 9.14, after executing each iteration, the class probabilities are biased, dividing the classes into two sets: probable and improbable. Note that with each iteration, the set of probable classes reduces as classification becomes more accurate. Hence, the probability of classes could be used as an effective measure to reduce computation in future iterations by avoiding computation related to improbable classes.

### 9.8.1 Prediction rank

We introduce prediction rank (PR) as an indicator of prediction accuracy of a model for each image. Consider an image with class label α. After executing CNN, all the class probabilities are sorted in descending order. The location of class α in the sorted array is called PR. Needless to mention, PR can be any value from 1 to 1000, with 1 indicating the highest and lowest detection accuracy respectively. If statistical analysis of the dataset for class α shows that PR is always smaller than L in all iterations (1 ≤ L ≤ 1000), limiting the number of computed class probabilities in the ICNN to L instead of 1000 will have no impact on the probability of detection of class α. If L is smaller than PR variation for class α, then by pruning the computation for class α we will end up with MC. Expanding this to all classes, the probability of MC conditioned on PR ≤ L is given by:

$$P(MC|P_{th}=L)=\sum_{i=1}^{1000}P(C[i])P(PR(C[i])>L)$$

In the previous equation, $P_{th}$ is the pruning threshold, the $th$ class, $PR(C[i])$ is the PR for class $C[i]$ and $L$ is the chosen limit for pruning. For obtaining the probability $P(PR(C[i])>L)$, we define the function $D$ as:

$$D(\alpha^{C[i]}(j), L)=\begin{cases}1, & \text{if } PR(\alpha^{C[i]}(j)) > L\\0, & \text{else}\end{cases}$$

In the previous equation, $\alpha^{[i]}(j)$ is the $j$th image of class $C[i]$. We define $S[i]$ as the number/size of images in the dataset (or expected number of images in the batch) that belongs to class $C[i]$, $P(PR(C[i]) > L)$ is computed as follows:

$$P(PR(C(i)) > L) = \frac{\sum_{i=1}^{S[i]} D(\alpha^{[i]}(j), L)}{S[i]}$$

By using (9.4), the pruning threshold $L$ could be chosen to set the probability of MC due to pruning to a desired value. The higher value of $L$, the higher the classification accuracy, but at the cost of higher computational complexity. The value $L$ could reduce iteration, making the pruning more aggressive as the accuracy increases.

To get a sense on the impact of choosing a value for $L$, for each class we find the mean ($PR_{\mu}$) and variation ($\sigma$) of PR based on all the data in validation set.

Figure 9.15 shows the mean ($PR_{\mu}$) and variation ($PR_{\sigma}$) of PR for all 1k classes sorted in descending order of $PR_{\mu}$ at the first iteration. Assuming a normal distribution, 95% of images of each class will have a PR below $PR_{\mu} + 2 \times PR_{\sigma}$. In Figure 9.15, $PR_{\mu} + 2 \times PR_{\sigma}$ of none of the classes exceeds 500, suggesting that by removing 50% of classes ($PR_{th} = 500$) the prediction accuracy does not drop beyond 5% for any of the classes.

Figure 9.16(a) and (b) shows the maximum of $PR_{\mu}$ and $PR_{\mu} + 2 \times PR_{\sigma}$ among all classes for all the iterations. The maximum of $PR_{\mu} + 2 \times PR_{\sigma}$ is reduced as ICNN moves to the next iteration, indicating that in subsequent iterations, the pruning policy could be more aggressive. Note that based on eliminated classes, the computational complexity of the next iterations is reduced by pruning the neurons in the FC layers and/or the filters in the CONV layers, which are highly correlated with classes close to zero probabilities.
