# 238 Hardware architectures for deep learning

The NeuroGrid project uses analog subthreshold circuits as custom implementations of neurons and synapses. One of the main goals is to study some of the principles of operation of the mammalian cortex in a cost-effective hardware system. The NeuroGrid system is composed of 16 neural core chips containing 65k neurons in a silicon area of 12x14 mm [1]. The full system contains 1 million neurons, modeled as quadratic integrate-and-fire neurons. To enable the system to reach large scale (1 million neurons), there are several trade-offs. In particular, neural plasticity in NeuroGrid is not implemented. Also, the asynchronous routing schemes provide a limited amount of traffic between neurons, especially when they are situated far from each other. In the past, the system has been used in conjunction with the Neural Engineering Framework [2], which is a theoretical framework to translate equations and dynamical systems into neural network dynamics. It has shown reliable emulation of a distributed working memory dynamics using 4,000 neurons with 16M feed-forward and on-chip recurrent connections. The efforts in this direction have continued and a new neuromorphic mixed-signal system has been developed [3]. This system is the first one that can be programmed at a high level of abstraction. It comprises 4,096 spiking neurons in 0.65 mm² silicon area with a 28 nm FDSO process. The main innovations are the sparse encoding via analog spatial convolution and weighted spike-rate summation via digital accumulation as a novel communication scheme that drastically reduces the event traffic and therefore results in the lowest power consumption per spike figure in these types of systems, i.e., 31 fJ per synaptic operation in a typical network configuration. Still, also these recent developments have not removed the synapse bandwidth at large scales.

Another neuromorphic project led by the Synapse [4] led to overcome the bottleneck problem by using digital circuits that virtualization and share resources to emulate a novel system. The system architecture, called TrueNorth [5], is built from a multi-neurosynaptic core. Each core comprises 256 neurons and 256x256 finite-resolution synapses using a cross-bar array. The custom digital neuromorphic core, named TrueNorth, comes with a software architecture (called Compass) that can be used to reproduce and simulate the behavior of the neuromorphic core, their impressive results show simulations of 5.3x1,010 neurons interconnected by 1.7x1,014 synapses [6]. This cross-bar array allows a very high synapse communication bandwidth up to a certain size, but then drastically reduces bandwidth when passing a threshold. So, also this option is not matched to supporting millions of neurons. The FACETS/Brain project led by by. Heldberg aims to achieve integration by using an analog approach to computation, in which neurons are simulated from 103 to 105 times faster than real time. The approach is based on a full wafer system composed of multiple analog neuromorphic dies communicating using a digital asynchronous protocol [7].
