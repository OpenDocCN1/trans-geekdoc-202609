# 11.3.4 Output interface (ADC)

To transmit the generated analog outputs of the proposed ANN, they should be converted to digital form. Therefore, we propose a memristive inverter-based implementation of neural network ADC (LTNN ADC [44,45]) The suggested structure is based on linear neural network ADC (LTNN ADC) which avoids the problem of spurious states of Hopfield ADC. An n-bit LTNN ADC, which has $n$ neurons and its design is based on the method of successive approximation. At the beginning, the most significant bit (MSB) is determined and then the approximation becomes finer, and as successive bits are determined continuing the sequence until the least significant bit (LSB) is determined. Thus, specifying the value of an output bit requires the information of the higher bits determined earlier. Therefore, the $i^{th}$ bit neuron has nonzero weights coming from the higher bit neurons, and hence the weight matrix of the network is lower triangular.
