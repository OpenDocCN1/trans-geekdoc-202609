# CNN agnostic accelerator design 175

If iterations of the compute loop in Figure 8.5 are launched every cycle and do not incur any stalls, then the total number of cycles for convolution can be expressed as

```
conv\_cycles = K_C \times K_R \times M_C \times M_R \times N_{itr} \times M_{iter} \n+ R_{itr} \times N_{itr} \times M_{iter} \quad (8.16)
```

where the second term is added to include initiation interval cycles of the tiling loop as it is not coalesced with compute loop.
It is possible to potentially hide IFM loads and OFM partial sum load/stores inside the convolution cycles. All but the first IFM tile load, all partial OFM loads and all the last OFM tile store the intermediate traffic:

```
mem\_ld\_cycles = ifm\_ld\_cycles + ofm\_ld\_cycles \n+ ofm\_st\_cycles \quad (8.17)
```

Details of each of these follows next. Since convolution filters can have strides less than the filter dimensions, IFM row tiles tend to slightly overlap over the edges. This results in some of the required data being discarded from IFM buffers and brought back from global memory. This overlap is not significant for CLs with large IFM dimensions. For smaller IFMs in deeper layers of CNNs, IFM sizes become smaller but do not require tiling if Tr is large enough. This presents another trade-off in optimizing Tr. As IFM traffic computation is complex, we instead calculate number of IFM elements required by every IFM row tile:

```
rows1 = \begin{cases} 0, & \text{if } R_{itr} = 1 \ (K_R + S \times (M_R - (R_{itr} - 1)) \times Tr) \times (R_{itr} - 2), & \text{otherwise} \end{cases} \quad (8.18)
```

```
rows2 = K_R + S \times (M_R - (R_{itr} - 1)) \times Tr \quad (8.19)
```

```
ifm\_ld\_cycles = N_{itr} \times N_C \times (rows1 + rows2) \n\times Tn \times ACPE; \quad (8.20)
```

where (8.18) is the number of elements in all but the first and last row tiles as they are counted separately in (8.13) and (8.19), respectively. For OFMs, partial sums are loaded in all but the first $N_{itr}$ iteration of the tiling loop as they are initialized by bias terms. On the other hand, partial sums are stored to global memory at the end of every tiling loop iteration. But for accurate estimates, we remove the last $ofm\_ps\_cycles which are never hidden:

```
ofm\_ld\_cycles = M_C \times M_R \times M_{itr} \times (N_{itr} - 1) \n\times Tm \times ACPE. \quad (8.21)
```

```
ofm\_st\_cycles = M_C \times M_R \times M_{itr} \times N_{itr} \times Tm \times ACPE. \n- ofm\_ps\_cycles \quad (8.22)
```
