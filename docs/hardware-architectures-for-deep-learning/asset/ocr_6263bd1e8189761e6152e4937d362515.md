# 6.4.1 Advantages of sparsity for dense data accelerator

Even dense architectures can take advantage of sparsity in two ways.

+   * Clock gating: Eyeriss skips a Multiply and Accumulate (MAC) operation if any of the operands to a multiplier is 0. Figure 6.2 shows that it is possible to clock 12× of operations, in AlexNet. However, this does not translate to 12× power reduction as even the original nonzero operations do not consume MAC’s peak power.
* Compression: Sparse tensors can be compressed to save the bandwidth, power [20, 21], and, potentially, capacity [22].
