# 1.1.3.4 Supervised and unsupervised learning in ANN

In order to learn an ANN for a target application, the parameters, i.e., weights and bias values, and hyper-parameters, including the number of layers and neurons, the type of activation functions, the type of the network (feedforward or recurrent) should be specified and optimized during a learning or training procedure.

There are two general approaches to learn NNs. In the supervised learning approach, for each explicit or implicit input target, the corresponding output is also provided. In this model, the outputs generated by the network should make high equivalence with the golden output. In such problems, after considering a good initial architecture for the network and an appropriate loss function for the output quality, the parameters are adjusted in such a way that the loss becomes minimized. For this purpose, plenty of learning strategies, including local search methods (such as various of the gradient descent method) and intelligent or evolutionary-based global search methods (such as simulated annealing or genetic algorithms) have been suggested.

In contrast, the unsupervised learning approach, there is no target output for the training data. In fact, it is not known exactly what the outputs of the network must converge to. However, it is desired that the generated outputs satisfy some geometric or statistical properties, defined by the designer.
