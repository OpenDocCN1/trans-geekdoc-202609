## Hardware architectures for deep learning

New and deeper CNNs (e.g., VGG and GoogleNet) deploy a single FC layer as opposed to three FC layers in AlexNet. Hence, the application of pruning to deeper CNNs increases the rate of FLOP count reduction as well as parameter reduction in their iterative version. Note that the large set of parameters required for the FC accounts for significant energy and delay. Caffe provides a set of tools to benchmark models by layer-by-layer execution, which reports system performance and measures execution times for CNN. Using these tools, the average delay of each operation (e.g., MAC) in CONV layers is calculated to be 10x lower than the same operation for an FC layer. As a result, the reduction in FLOP count through pruning is small, in the execution time and energy is significant.

## 9.10.4.2 Context-aware pruning policy for CONV layer

Figure 9.23 captures the result of filter pruning for the CONV layer in iterations 2–7.
