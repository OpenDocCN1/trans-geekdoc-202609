Although binarization weight with stochastic binarization function works better than deterministic binarization function [20], the sign function is more popular due to its simple hardware implementation compared to stochastic functions. BinaryConnect has used stochastic binarization function during the training phase and deterministic function throughout test inference.

As mentioned earlier, BinaryConnect removes 2/3 of multiplications during the training process and leads to $3\times$ speedup for the training. The impact of deterministic BinaryConnect during test time is noticeable with conventional CNNs with real weights (from 32 floating point to 1). BinaryConnect decreases all multiplication operations, memory to computation bandwidth, and memory storage by a factor of 32. BinaryConnect has achieved near state-of-the-art results on MNIST, CIFAR10, and SVHN datasets.

The method presented in [21] has to remove most of the multiplication operations during the training of neural networks. In comparison with BinaryConnect, this method also deals with backward weight update (step 3) in addition to forward propagation (step 2) and backward propagation (step 2). Since many learned weights generally have converged to zero or near zero, connect approaches an extra zero for weights as well. In the same as the binary models, the ternary model replaces all MAC operation with simple addition or subtraction in the forward propagation. Besides, compared with binary connect, 0 values reduce computations.

To omit multiplications, [21] proposes a method which consist of two components. First, for forward propagation, weights are stochastically binarized using binary connect or ternary connect functions according to (5.4) and (5.5), respectively:

```
$Wt = \frac{W+1}{2} \n P(Wt=-1) = 1-P(Wt=1) \quad (5.4)$
```

```
$P(Wt=1)=W;P(Wt=0)=1-W \quad \text{if } W \geq 0 \n P(Wt=-1)=-W;P(Wt=0)=1+W \quad \text{if } W < 0 \quad (5.5)$
```

where $P, W$, and $Wt$ are the probability, real value weight, and ternar weight, respectively.

Second, an approach called "quantized back propagation" is introduced to substitute most multiplications in the backward pass with bit-shifts. To obtain this, inputs are rounded to the closest power of 2 values to replace multiplications with binary shifts. This also explore the number of appropriate bits for input quantization and find that 3–4 bits is sufficient to achieve good performance.
