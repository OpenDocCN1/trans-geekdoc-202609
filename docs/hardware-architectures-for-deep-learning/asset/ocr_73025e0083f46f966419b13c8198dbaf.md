Improve weight reuse for FCLs: Even newer networks like SqueezeNet, GoogLeNet and ResNet have shown that FCLs can be eliminated without losing accuracy, FCLs form a significant part of runtime in networks such as AlexNet. # 8.5 Computation optimization and reuse

In this section, we present novel, efficient structuring of computation loops while avoiding fixed filter sizes. We then analyze data reuse and propose loop coalescing for high-efficiency execution.

# 8.5.1 Design control variables

To use OFM parallelism, we first choose to compute a subset of OFM channels in parallel, denoted by Tr. We also process a subset of IFM channels every cycle, denoted as Tn. Modern FPGAs can have up to 50 Mb of BRAMs. However, this is not enough to store IFMs, OFMs and weight data of common CNN layers. Dual-buffering makes this even. For this reason, majority of the layer data is stored in the off-chip DRAMs with limited bandwidth up to 20-30 Gbps on typical modern FPGA boards. Therefore, the feature maps are carefully broken into smaller channel tiles of working data in on-chip memory which is discarded only when no required.

Usually, subsets of Tr and Tc columns of IFMs and OFMs are considered [3,6,16] resulting in a total of Tr × Tc elements transferred from DRAMs at once. Since depth of the local memory system depends only on the total elements in a tile, we insist choose to break only the rows into subsets of Tr. For a given CNN, if max, the maximum number of columns for any layer in the network, then the OFM buffer depth is determined by Tr × max.. Tiling only one dimension simplifies interconnect and IFM’s random data access without incurring any performance trade-off. In later sections, we show that Tr also has a significant impact on performance as it represents the burst length for off-chip memory accesses.

In summary, Tn and Tm control parallel computation and on-chip bandwidth, while Tr detects of the on-chip buffer banks and burst length in FICaffe.
