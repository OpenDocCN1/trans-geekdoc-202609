In addition, it is worth noting that most sequence models like recurrent neural networks (RNNs) and long-term memory still rely heavily on sigmoid and tanh nonlinearity, which severely reduces the number of zeros in the activations. However, the trends show that ReLU (or clipped ReLU) is still the most dominant nonlinear activation function in convolutional neural networks (CNNs).

+   **Weight sparsity:** In the 1990s, LeCun al showed that it is possible to implement many unsparse networks with multipayer perceptrons and expect better generalization [9]. Later, Han et al reevaluated this for DNNs to achieve much smaller networks with almost no loss in accuracy, but at the cost of longer training times [10]. Unlike activation sparsity, which changes from one input to another, weight sparsity is known before deploying the trained model. As a result, in the accelerators that are based on weight sparsity, the software layer can help to simplify the hardware complexity. However, this sparsity is not available during most of the training time. In Section 6.2, we cover software approaches to prune DNNs, efficiently.

+   **Output sparsity:** CNN and Fully Connected (FC) layers' outcomes are calculated by adding products of pairs of activations and weights. In ReLU-based DNNs, an outcome would be useless if the sum of products ends up be negative. Therefore, it could be avoided if it is predicted or speculated that the final result will likely be a negative number. This is called output sparsity.

+   **Value sparsity:** Most of the activations and values are distributed around zero making most of the bit positions in the activations and weights zero. We called the sparsity of 1s in a value sparsity. Value sparsity covers both weight and activation sparsity. An architecture based on such sparsity uses low precision arithmetic units to capture only the effectual bit positions.
