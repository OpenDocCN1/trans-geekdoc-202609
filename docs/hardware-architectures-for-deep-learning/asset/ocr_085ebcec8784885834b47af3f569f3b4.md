# 9.8 Contextual awareness in ICNN

Real-time application of deep learning algorithms is often hindered by high computational complexity and frequent memory accesses. Network pruning is a promising technique to solve this problem [38]. The network can be pruned by learning only the important connections. That is, if the weight of a connection is less than a threshold, the connection is dropped [39,40]. This approach is previously deployed in the training phase of CNN by discarding negligible weight values. However, ICNN enables us to apply the pruning at run-time. This capability is the result of having an early classification that provides ICNN with a hint to avoid computation related to classes that are least probable.

Upon completion of the first uCNN, ICNN develops a form of contextual awareness as its first FC classifier outputs the probability of various classes with respect to an input image.
