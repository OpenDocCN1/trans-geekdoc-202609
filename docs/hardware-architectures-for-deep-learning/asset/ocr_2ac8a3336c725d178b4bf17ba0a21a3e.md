# 4.3.2 Deterministic low-discrepancy bit-streams

We showed in [23] that Sobol sequences can be used to convert each independent input data to a bit-stream representation. When multiplying two $N$-bit precision numbers, each number is converted to a $2^N$-bit bit-stream by comparing it to the first $2^N$ numbers of a different Sobol sequence. Alternatively, the inputs can be converted to bit-streams of $2^N$-length by comparing each to the first $2^N$ numbers of a different Sobol sequence. The bit-stream corresponding to the first input is repeated until it becomes a stream of $2^{2N}$-length. The bit-stream corresponding to the second input is stalled after every $2^N$ clock cycles and repeated until similarly becomes... Both of these methods produce correct (completely accurate) results when executing the operation for $2^{2N}$ clock cycles. They also produce a similar output and have the same truncation error when processing short-streams ($\le 2^N$ bits).
