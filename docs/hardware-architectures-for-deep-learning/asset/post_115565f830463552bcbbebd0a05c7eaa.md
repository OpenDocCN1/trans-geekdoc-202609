So, to deal with this undesired area and energy explosion, we have proposed new scalable dynamic segmented bus interconnect synaptic communication network for large-scale neuromorphic platforms with a circuit-switched data plane and a control plane based on full virtualization [34]. The selected TFT material exhibits ultralow-leakage power consumption. When scaled up, these devices reside between the metal layers in a many-layer-back (BEOL) metal connection stack [35]. The platform consists of a Zynq FPGA that acts as the host board. The TFT switch and AER interface are implemented on a custom board. The Synapse (CxQuad) are located on a separate board that connects to the Zynq FPGA. The Zynq FPGA is a combination of an ARM processor and FPGA configurable logic and provides an ideal solution as a host board for the neuromorphic platform. The CxQuad has high-speed AER interface that can send and receive spike packets. The glue logic between the high-speed AER interface of the CxQuad and the TFT switch is implemented on the FPGA logic. The outgoing spike packets are demultiplexed, serialized (using the UART protocol) and fed into the TFT switch. The spike packets (in the serial format) from the TFT switch are deserialized and multiplexed to the destination neurons in the CxQuad. As discussed in Section 10.5.3, the speed of the TFT chip is high enough to time multiplex data over multiple ports and the bits of 8-bit words. So that task is assigned to the FPGA board. The ECG encoder, classifier and the overall system control are implemented as software modules running on the ARM processor inside the Zynq FPGA.

# 10.4 ECG application mapping on non-scaled neuromorphic platform

The mixed-signal neuromorphic platform exploits a fully event-driven approach for carrying biomedical signal processing. In the following application, the platform has been tuned to carry arrhythmia detection and classification employing a bio-inspired SNN. We have implemented a two-stage SNN topology which comprises a recurrent network of spiking neurons whose output is classified by a cluster of LIF neurons that have been (supervised off-line) trained to distinguish 18 types of cardiac patterns; of which 17 are actual cardiac patterns, and one class is used for unrecognized ECG signals due to excessive noise, movements or other adversities.
