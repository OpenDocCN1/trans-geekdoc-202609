# 1.2.2 ANNs in regression problems

In statistical modeling, regression analysis is a set of statistical processes for estimating the relationships between variables and between the input variables and the function output. Actually, in applying an ANN to a regression problem, it is desired that the network be learned by a supervised learning approach in order to map the input space (x) to its target value, y(x). However, similar to the classification problems, the input space (x) is required to be transferred to an ineffective feature space, z(x), where limits, disturbances, and distortions of the input patterns are removed. It is expected that by providing the effective feature space, the target outputs (y) makes a smooth and valid map on z(x). After feature extraction, in the second part, the feature space, z, is mapped to y(z(x)) which has high equivalency with the target output y(x). Figure 1.12 shows these steps.
