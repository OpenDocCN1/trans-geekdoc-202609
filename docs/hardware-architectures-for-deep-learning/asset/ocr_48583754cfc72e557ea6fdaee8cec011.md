First, it presents a multi-discretization function (e.g., ternary discretization) for neuronal activations. It also presents derivatives and approximation method for non-differential activation function to implement backpropagation, as shown in Figure 5.7.

Second, GXNOR-Net introduces a discrete state transition (DST) methodology to eliminate the full-precision weights in the training phase to reduce the memory/computation demand significantly. Weights are constrained in a discrete space by using the DST methodology, and thus there is no need to store full-precision hidden weights during the entire training phase.
