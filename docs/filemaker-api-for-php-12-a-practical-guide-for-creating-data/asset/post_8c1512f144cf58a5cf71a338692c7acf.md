# Part II — Web Installation

In this book I will assume that you have your production web server rather than using a third-party host for your web site, I will also assume that you will deploy your entire solution on a single machine. That means you will install a web server and FileMaker Server on the same computer. To make things easily I recommend that you have a development computer that is set up and configured exactly the same way as your production server. That way, when you transfer your database and web pages from the development computer to production you should have any problems. If you're really struggled for budget, I suppose you could develop on your production server. I certainly don't recommend it in case you do trash live files. I will also assume that you use FileMaker Server to install PHP on the web server. That way you'll get the latest supported version (PHP 5.3 on OS X and 5.5 on Windows) and you won't have to install or configure it manually. It will work right out of the box.

Making a decision regarding which web server to use depends on your choice of server hardware and the operating system. On OS X, Apache comes with the operating system. On Windows, IIS (Internet Information) comes with the operating system. You can run Apache on Windows, however, requires that you manually install and configure it. That process is outside the scope of this book. I will note one thing of great importance getting up and running with the FileMaker API for PHP — you don't have to install any ODBC drivers. Therefore, once the web server is turned on and FileMaker is installed and configured to use PHP, you'll be ready to go. It couldn't be any easier.
