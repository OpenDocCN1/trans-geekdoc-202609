Display the related data in a new table below the parent record. Remember that the related table (portal) must be on the layout. You will use the table occurrence name with the getRelatedSet then you will use the foreach loop method with the qualified field names that are more than one portal.

```
$related_records = \$record->getRelatedSet('related_data');
$display = '<table border="1">';
$display = '<tr>';
$display = '<th>Text</th>';
$display = '</tr>';
foreach($related_records as $related_record)
{
$display = '<tr>';
$display = '<td>'. \$related_record->getField('related_data::Text').'. '</td>';
$display = '</tr>';
}
$display = '</table>';
$display = '<p>';
```
