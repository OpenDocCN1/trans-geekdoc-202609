# Uploading the "php_demo.fmp12" Database File

Download the example files and source code at:
http://www.formulationspro.com/PHP12Book/filemakerphp12examples.zip

56. Unzip the file. You'll find the example database in the folder PHPBook12/Lessons/FileMaker12Files/php_demo.fmp12. Click Upload a Database in the Related Tasks window. Then follow the upload wizard.

If you have direct access to the server you can certainly copy/paste the database file directly to the Databases folder. This is significantly faster than the upload wizard. The advantages of the upload wizard are that you can upload files to remote servers, which will automatically change the file permissions, and will open the file when it's done.
