# dbaccess Include PHP File

**Objective:** Create the include file that is used for every PHP web page to connect to the FileMaker database. I recommend that you use the sample file as is and simply modify the connection information to match your own solution.

**Difficulty:** Easy

**Sample Files:** PHPFiles/Conn/dbaccess.php

**Page Navigation:** Include file only.

**FileMaker API Methods:
FileMaker()
setProperty()

**Code:**
All PHP code starts with <?php and ends with ?>. Start by using the PHP method require_once to load the FileMaker.php API for the API. This allows you to access all the methods in the API.

```
<?php
require_once ('FileMaker.php');
```

$fm = new FileMaker();
Create the $fm object Take note of the variable name fm. This object will be called in every sample file to retrieve data from the database.

The next section is your "connection string" to the database. Database is the exact name of the database. You do not need to include the fmp2 extension. Hostspec is the IP address (ex. http://192.168.1.100 or http://127.0.0.1) or domain name (ex. http://formulationspro.com) where the database is being served. If you have a single server solution http://127.0.0.1 will work perfectly. Technically, FileMaker assumes the hostspec of 127.0.0.1 if the property is not declared. I am assuming you are using a single server in this book. If you have a two server solution you will need to use the address of the server hosting the database. Username is the account name in the database — remember that the account needs to be assigned to a Privilege Set that is PHP enabled. Password is the password for the account. For the sample files and php_demo.fmp12 sample database the account is "Admin" and the Password is "1234".

```
$fm->setProperty('database', 'php_demo');
$fm->setProperty('hostspec', 'http://localhost');
$fm->setProperty('username', 'Admin');
$fm->setProperty('password', '1234');
?
```

> Do not use http://localhost on Windows. Windows is unable to resolve localhost to 127.0.0.1 and may cause poor performance and/or crashing problems. Instead, always use //127.0.0.1.
