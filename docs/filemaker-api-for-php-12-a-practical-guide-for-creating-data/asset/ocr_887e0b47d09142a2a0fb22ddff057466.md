# LoginSuccess.php

The login page does the majority of the hard work. The rest of your protected pages only need a few lines of code at the very beginning to maintain the login security. Again, the session_start() method is required to be placed BEFORE the HTML tag. This carries the existing session information forward to this page. Since the LoginSuccess page is the entry point into your protected pages you should check to see if the $_ SESSION superglobal is set and the login value is 1. If the user has not logged in properly they will be redirected to the login page. That's all it takes to protect your protected pages. After that, it's up to you to design the rest of the page. The only item you may want to provide on your protected pages is the ability for the users to click a link to log out.

```
<?php
session_start();
if(isset($_SESSION['login']) && $_SESSION['login']!=1)
{
header("location:Login.php");
exit;
}
?>
```
