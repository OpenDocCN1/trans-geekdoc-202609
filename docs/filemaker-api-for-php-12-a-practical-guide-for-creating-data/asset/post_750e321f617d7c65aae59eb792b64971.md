## PART IV — Choosing a RAD tool vs. a Free Text Editor

You need to have a text editor or rapid application development software (RAD) to create your web pages. Please don't try to create web pages with Microsoft Word, Notepad, TextEdit, etc. The question is how much money you want to spend and how do you want to be? In my opinion, something is "free" does not necessarily mean you are going to be able to use it effectively in a commercial development environment. Your loss of time using free software could amount to well in excess of cost to purchase professional software development. Honestly, $400 is not too much if this is your reality, a critical business decision, or if you want tools that make you more productive. The Internet is not "free", but many people believe that it is, and that's another topic of discussion.
