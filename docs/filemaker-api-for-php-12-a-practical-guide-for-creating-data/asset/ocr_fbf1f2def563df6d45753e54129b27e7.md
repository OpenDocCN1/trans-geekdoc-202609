# PHP Import Records

The FileMaker Script imports records from an xls file I decided to create a fully functional example that logs the import process. In a production system it's important to know when an import failure occurs and on which file. That way you can rewrite your script before the import process until it is successful. It will also allow you to schedule the import for batches in the middle of the night to reduce the peak hours usage of the server.

There are a couple of ways to move the file from the web root folder to the FileMaker Server Documents folder. I believe that the Trio Plugin is the best method as it works in conjunction with the FileMaker script and it's relatively easy to work with. Plus the plugin is very versatile for many other tasks. The only downfall is that it is not free. You do need the web server license for this process.

There are couple of free methods to move the file. The first method is using the Folder Action and Automator on OS X. With this method it may cause your script to fail the file was not moved in time before the script reaches the Import Records steps. The Pause script is not available to FileMaker Server. Therefore, your only option to use Folder Actions and Automator is to use a scheduled script FileMaker Server to batch import all the files uploaded to the server. Therefore, you will have to wait until the night when the server runs to offload the importing of files until the night when the server isn't quite busy. The downfall is future support of Folder Actions and Automator. In my experience the OS X scripts seem to change dramatically with OS update/upgrade. So your progress is bound to break at some point unless you have very high version control and documentation for your server and it's.

The other free process that will work is to create a shell script (OS X) or batch script (Windows) to move the file. Use then the FileMaker Server Schedule to run the shell or batch script prior to running the import script. Again, you still have to run a scheduled script, which will delay the import process based on the time the schedule. However, shell scripts and batch scripts are far more reliable in the long run than Folder Actions and Automator.
