When the user enters the page there is no URL value for page so we know they are on the first page. Otherwise we can get the current page number from the URL.

```
if(empty($_GET['page']))
```

Now we have to retain the search criteria from the URL as we move through each page. The reason for this is because the search needs to be performed again each time you click a link between pages. The web browser is miraculously storing the other records in cache. Page will only display the records returned to it from FileMaker Server.
