# Configuration: Database Server

Server Plug-Ins
Enable FileMaker Server to use plug-ins when running FileMaker scripts. When plug-ins are enabled, the FileMaker Engine (FMSE) process will load plug-ins for use by FileMaker scripts run from FileMaker schedulers.

+   - Enable FileMaker Script Engine (FMSE) to use plug-ins
- Install Plug-In Script step to update Server plug-ins

Choose the plug-ins for FMSE to use.

| Name | File Name |
| --- | --- |
| Not Loaded | POP3ix_Pro_OSX.fplugin |
| Not Loaded | SMTPTPix_Pro_OSX.fplugin |
| POP3ix Pro SE | POP34_SE_OSX.fplugin |
| SMTTPix Pro SE | SMTTPix_Pro_SE_OSX.fplugin |
