# FileMaker Error Codes, scripts, and PHP web pages you are going to encounter errors. FileMaker Pro and

When you create a database, FileMaker Server is the only one going to return an error number to you. That means you'll have to track down the error code and figure out what to do with it. In many cases the description of the error code will be relatively ambiguous. Therefore, it's always to have a list of all the possible error codes and their descriptions. You can also download this error code list in a FileMaker database from our web at www.formulationspro.com.
