# FileMaker API Syntax: addNewCommand('LayoutName')

```
php
$request = $fm->addNewCommand('Demo php');
```

Next, have the $request variable set the fields with the data from the $_POST superglobal.

```
$request->setField('FirstName', $_POST['FirstName']);
$request->setField('LastName', $_POST['LastName']);
$request->setField('Number', $_POST['Number']);
$request->setField('Date', $_POST['Date']);
```

# FileMaker API Syntax: setField('FieldName', Value, Repetition)

```
$request->setField('FirstName', $_POST['FirstName']);
Repetition = 1
```

Execute the request and trap for errors. In this case if there is no error you can display a message to the user who know the record was created successfully. The use of the PHP exit method is important because it will stop the script from continuing.

```
$result=$request->execute();
if (FileMaker::isError($result)) {
  $message = "<p>Error: " . $result->getMessage() . "</p>";
} else {
  $message = '<p>Record was created successfully.</p>';
}
?>
```
