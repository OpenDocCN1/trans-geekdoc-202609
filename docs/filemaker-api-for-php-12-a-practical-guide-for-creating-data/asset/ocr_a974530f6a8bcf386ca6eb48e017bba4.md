validate_cc.php

The validate_cc.php file contains 2 main functions and a third that combines the results to determine the overall result. The first function, validate_number_type determines the card type, number of digits, and any prefix values match the supplied credit card number and type. If the card passes the function returns the value of 1. If not, the function returns a value of 0. This will be important at the end of this day. The code below only works for VISA, MASTERCARD, AMEX, and DISCOVER. If you need to validate additional cards you might find more information at:

http://en.wikipedia.org/wiki/Credit_card_number.

```
<php
function validate_number_type($ccnum, $type = 'UNKNOWN')
{
 // Clean up input
 // Make sure this is all UPPERCASE to match the code below
$type = strtolower($type);
 // Remove everything except numbers
$ccnum = preg_replace('/\D/', '', $ccnum);

 // Do basic validation for type specific credit cards
 // Skip UNKNOWN
if ($type == 'UNKNOWN')
{
    return 1;
}

 // Mastercard: 16 digits, prefix of 51-55
elseif ($type == 'MASTERCARD')
{
    echo 'MC';
    return (strlen($ccnum) != 16 && !strpos('5[1-5]', $ccnum)) ? 0 : 1;
}

 // Visa: 13 or 16 digits, prefix is 4
selif ($type == 'VISA')
{
    echo 'VISA';
    return (strlen($ccnum) != 16 || substr($ccnum, 0, 1) != '4') ? 0 : 1;
}

 // AMEX: 15 digits, prefix of 34 or 37
else ($type == 'AMEX')
{
    echo 'AMEX';
    return (strlen($ccnum) != 15 && !strpos('3[47]', $ccnum)) ? 0 : 1;
}

 // Discover: 16 digits, prefix of 6011
else ($type == 'DISCOVER')
{
    echo 'DISC';
    return (strlen($ccnum) != 16 || substr($ccnum, 0, 4) != '6011') ? 0 : 1;
}
else
 // Default: unknown type
return -1;
}
```
