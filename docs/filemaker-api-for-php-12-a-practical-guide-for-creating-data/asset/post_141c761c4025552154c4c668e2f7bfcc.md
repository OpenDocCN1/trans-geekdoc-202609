# Introduction

Welcome to the FileMaker API for PHP Tutorial

This tutorial demonstrates the functionality of the FileMaker API for PHP. The tutorial consists of 6 lessons designed to teach you how to use the API to integrate a FileMaker Pro database with a web application. Each lesson introduces a capability of the API, explaining how the code is written and how it works.

The tutorial completes a PHP web application develop, each lesson building upon the previous lesson as:

- Lesson 1
  - Setting up the FileMaker database object
  - Perform Find
    - How can I find all records in a database and display them on the web?
- Lesson 2
  - Display Container Images
    - How can I display web-compatible images in container fields on my website?

# PHP Reference Guide

Estimated Time to Learn: Only Maker Server/Documentation/index.html

The PHP Reference Guide from FileMaker is generated from a program called phpDocument. Basically, what it does is use the API files and generates an HTML-based manual that displays information about the classes and files. The description of the methods will give you all the variables and options and in some cases recommendations for usage. However, you will not receive any syntax or examples of how the methods should be used. This makes the PHP Reference Guide very frustrating and not a good place to learn to use API for PHP. Without working examples, this is really for users that have experience with FileMaker and PHP. The good part about this is that you will find every method in the API by looking it in this index of elements in alphabetical order.

# How PHP is Like FileMaker

PHP won't scare you. I'll admit that the coding and use of a RAD tool to help you isn't necessarily fun. However, once you get the hang of it you will quickly find that PHP is like FileMaker. Better yet, once you are done with this book you have learned 90% of everything you need to know. The last 10% are the seldom-used methods you'd have to look up anyway. I've been developing FileMaker since 1998 and there are still some things I have to look up.

First, PHP code runs in sequence on the web page just like a script. Therefore, if you've conquered half the battle most of the PHP code you'll write is repetitive. The more you learn and practice, the easier it gets. Again, the only downside is that you don't have an environment to help you pick the PHP methods. How do you overcome? You have a lot of best samples files and snippets that you need to copy/paste and modify as necessary.

Take a look at the two samples below. The PHP code is on the left and the FileMaker Script is on the right. It starts connecting to the database. It finds all the records using the Demo php layout. Then it tries for any errors, as no records were found. The script follows through all the records to display them on the web page. That's really not much different from the FileMaker Script on the right. Start by turning capture on, then it records all the records. The script handles the changes, changing the value of the Number field. Finally, commit the changes to the server. The thing that really makes more code with PHP is writing out the information as HTML. Otherwise the length and complexity of the code is within your grasp if you are already making FileMaker Scripts.

### PHP Script

```php
<?php include("../dbaccess.php");
$result = $fileMaker->findAll('Demo php');
$result = $result->execute();
if (FileMaker->isError()) {
echo "Error: " . $result->getMessage() . "</p>";
}
$records = $result->getRecords();
echo "<table border='1">\n<tr>
<th>First Name</th>
<th>Last Name</th>
<th>Number</th>
<th>Date</th>
<th>Timestamp</th>
<th>Calculation</th>
<th>ID</th>
</tr>\nforeach ($records as $record) {
echo "<td>" . $record->getField('FirstName') . "</td>";
echo "<td>" . $record->getField('LastName') . "</td>";
echo "<td>" . $record->getField('Number') . "</td>";
echo "<td>" . $record->getField('Date') . "</td>";
echo "<td>" . $record->getField('Timestamp') . "</td>";
echo "<td>" . $record->getField('Calculation') . "</td>";
echo "<td>" . $record->getField('ID') . "</td>";
}
echo "</table>";
}
?>
```
