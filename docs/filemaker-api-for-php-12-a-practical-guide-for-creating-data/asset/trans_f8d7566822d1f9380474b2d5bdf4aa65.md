# 课程 27：跨所有的快速查找

**目标：** 在本节中，你将学习如何允许用户使用表单中的一个搜索框动态搜索布局上的所有字段。通过使用这种方法，你可以指定一个字段较少的单独布局，然后返回布局以显示更多字段。这可以防止你的数据库被索引，并显著加快搜索过程。此示例类似于 FileMaker 的快速查找功能。
