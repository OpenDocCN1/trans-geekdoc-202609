# Welcome to the Upload Database Assistant

To upload a database to FileMaker Server:

+   1. Specify the folder where you want to place the database. Either a folder in the list or create a new subfolder.
2. Click Add Database to select a database to upload to the list and click Remove Database.

To remove a database, select the database file in the list and click Remove Database. You can remove only files that you added in this step.
