43. Server plugins is the mechanism used by FileMaker Server to use and distribute plugins to FileMaker Pro clients. This won't be covering the use of plugins as it is out of scope. Click the box to enable the FileMaker Script Engine (FMSE) to use plugins. This will allow FileMaker Server to use plugins for scheduled scripts. Click the box to allow Install Plug-In script step to update Server plug-ins if you want to enable FileMaker Pro clients to update plugins stored in the database. You as the developer are required to store plugins inside the database itself. Then write a custom script to install the plugin from the database. With this check box enabled the clients can install and update the plugins from your database.
