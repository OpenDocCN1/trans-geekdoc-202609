Finally, when the code runs, theonreadystatechange event will have to change. Therefore, the following code will send the POST request to the show_detail.php page. The show_detail.php page, explained below, is to receive the POST request and find the record by the name=value pair passed in the URL string. In this case I've passed id=RecordID, where the id is supplied by the JavaScript parameter that was originally passed from the Show Detail button on the web page. The POST URL will look like:

```
show_detail.php?id=40
```

Additionally, I've also defined the asynchronous parameter as true, which means that other scripts can execute waiting for the server response and the JavaScript function can wait until the onreadystatechange is ready (xmlhttp.readyState=4, xmlhttp.status=200). It defeats the purpose of using AJAX if you set the value to false.

```
xmlhttp.open "POST", "show_detail.php?id="+id,true);
xmlhttp.send();
</script>
```
