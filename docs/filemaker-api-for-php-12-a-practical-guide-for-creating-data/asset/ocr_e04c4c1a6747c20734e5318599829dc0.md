# Value Lists

Value lists are a unique feature of FileMaker Pro. Most databases and web applications use separate tables for value lists. You can certainly do that with FileMaker as well. The disadvantage of using the built-in value list with FileMaker is that it is not editable on the web. However, if you create tables for your value lists they can be edited on the web. The advantage to using the built-in value list is that the FileMaker API for PHP can access all the value lists by name with a single method, including the ability to use two-field value lists. There are four sample value lists used with the demo files that demonstrate drop down menus, single check boxes, and multiple check boxes. Multiple check boxes, again, are unique to FileMaker and require special handling on the web.

> Using the FileMaker API for PHP requires features you want to access must be applied to the objects on the layout. That means that value lists must be attached to the fields on the layout.
