# Lesson: Insert Record with Validation

Objective: In this lesson you will learn how to insert records into the database using a form. This is similar to the previous lesson. However, you will add several validation techniques to ensure that the data entered by the user matches the database requirements. In a commercial database you should NEVER trust the users to enter data into your database without validating it first because they could add malicious code or data entry errors.

Dreamweaver has several JavaScript functions to validate data entry. These are very handy and allow validation for length, number range, required entry, email address, etc. The problem is that they aren't very sophisticated and they add a ton of code to your file. They also don't prevent users from adding malicious SQL, HTML, or data errors.

PHP has some nice functions that require less code because they are built in them. They do all the heavy lifting for you. Some good examples can be found at:

The list below represents some fairly common PHP filters:

| filter_var(Variable, Option) | Filters with the FILTER options below. |
| FILTER_SANITIZE_STRING | Strips tags before the data is inserted. Good for text boxes. |
| FILTER_SANITIZE_EMAIL | Removes all illegal characters from an email address. |
| FILTER_SANITIZE_URL | Removes all characters except letters and digits from a URL string. |
| FILTER_VALIDATE_INT / FILTER_VALIDATE_INT | Validates the value as an integer, including a range of values. |
| FILTER_VALIDATE_BOOLEAN | Validates the value as a 1/True or 0/False. Good for Boolean check boxes. |
| FILTER_VALIDATE_URL | Validates the value as a URL string, can include components. |
| FILTER_VALIDATE_EMAIL | Validates the value as an email address. |
| strip_tags() | Will strip all tags from a text field |
| explode() | Will require a maximum number of characters. Can be used to parse text by a specified value. |
| checkdate() | Validates a Gregorian date as MM/DD/YYYY. |
