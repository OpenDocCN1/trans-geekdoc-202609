# page2.php

The second page serves two purposes. The first is to "catch" the fields and values posted from the first page and store them as hidden fields in the form. The second is to display another set of fields, all of which will be posted to the final page in the process.

Rather than describe an identical form order again, let's focus on the PHP code placed at the bottom of the form. All the fields from page1.php were sent using the POST method. As you are aware, POST formatting is name=value. That's basically an array where name=key and value=value. Therefore, we'll loop through each of the name=value pairs as an associative array using the foreach method. The only one we want to skip is the "next" button because that data is got by the URL encoding process using strip_tags. Otherwise we'll un-quote, or remove any backslashes the hidden field text inserted by HTML or PHP tags. Finally, the value will be converted back to the original text using htmlentities. The last notable item you may need to change is the word name of the submit button from the previous page. I encourage you to view the source code to see how the hidden fields were added to the bottom of the form.

```
<?php
foreach($_POST as $key=>$value) {
  if($key!="next") {
    $value=htmlentities(stripslashes(strip_tags($value)));
    echo "<input type=\hidden name=\$key value=\$value\">\n";
  }
}
?>
```
