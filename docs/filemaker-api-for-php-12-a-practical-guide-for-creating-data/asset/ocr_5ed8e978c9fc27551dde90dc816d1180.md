The form points back to the same page using the Post method. This ensures that the information is updated when the page refreshes so the user can make additional changes. It is important to hide this information using the Post method so you can't bookmark the page and update it in the future if the record is deleted. There is also no need for them to see the id for the record or the id value for the parent record link that are passed as hidden values. The $message variable at the bottom will display the message from the PHP code generated.

```
<form action="EditRecordDetailPortal.php" method="post">
<input type="hidden" name="id" value="<?php echo $_REQUEST['id']; ?> />
<input type="hidden" name="parent" value="<?php echo $_REQUEST['parent']; ?> />
```
