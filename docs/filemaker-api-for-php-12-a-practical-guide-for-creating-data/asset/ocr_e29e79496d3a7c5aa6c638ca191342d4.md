**Objective:** In this lesson you will learn how to create a dynamic calendar for month and day view. Every developer needs to be capable of producing a calendar-based solution for their clients. As the creator of the number one world-wide commercial calendar solution, Calendar Developer Tool, I can tell you that without a doubt, creating a calendar solution solely with FileMaker Pro is far more difficult than creating a PHP solution. With PHP, every day is built and displayed dynamically, you only need 1 table, and absolutely no extra table occurrences. If you include CSS and even some JavaScript you can replicate FileMaker Pro's built-in features with minimal effort and minimal load on the server.

The database has six fields. A full calendar might have more fields than this. However, I want to focus on the core requirements, the bells and whistles. You can add those to your own solution. Any good calendar solution allows a single event record to span one or more days. Therefore, each record has a DateFrom and a DateTo. Where the DateRange field comes in. Using the cRange custom function I'm able to create a list of dates for the event. The DateRange field is used in the solution to find the records for display in each of the calendar cells. The Time field keeps the records in order. The Event field is filled by the user for a short description of the event. Finally, the RecordID is the standard record identification that I prefer to include in all my PHP solutions so I have direct access to the FileMaker internal Number.
