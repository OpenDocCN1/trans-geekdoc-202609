# Lesson 32: Install and Configure SSL to Work with FileMaker Server

**Objective:** In this lesson you will learn how to install and configure SSL to work on Windows or OS X with FileMaker Server. There are although no sample files, it is important to know how to configure IIS and Apache as well as FileMaker Server to use SSL. This is the only method that will enable a secure connection between your web pages and web server. Enabling SSL on FileMaker Server only encrypts the connection between FileMaker Pro.

**Difficulty:** Easy

**Sample Files:** None

**Page Navigation:** N/A

FileMaker API Methods: N/A

**Procedure:**

![](bbox=[0.105, 0.345, 0.903, 0.403])

The first issue you may run into is actually binding your certificate to your web site. The way the process works as following:

+   1. Open IIS Server.
2. Click on the server in the Connections window.
3. Click Server Certificates in the Security Section.
4. Click the link to Create Certificate Request in the Actions window.
