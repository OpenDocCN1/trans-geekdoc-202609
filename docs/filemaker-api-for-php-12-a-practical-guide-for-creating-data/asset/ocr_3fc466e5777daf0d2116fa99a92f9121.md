From we'll add all the name=value pairs (NVP's) separated by &amp; which is the URL encoded value for
&quot;. &amp; Because we will be embedding the chart URL in the web page as an image source. To obtain
t correct URL string special characters need to be URL encoded. That also includes any values in the
dat that might cause problems with the string. Rather than make a huge string of values I decided to
define the required and optional variables within the PHP code. Then assemble the final URL string in any
to read and modify format. The NVP's can be assembled in any order. However, I prefer the order of required,
optional, and random ID number. Let's start with the required NVPs.

Define the chart type variable. I chose the line chart for the demo:

```
?<?php
$scht = 'chtlc' . '&';
```

Define the chart size. In general, it needs to be wide enough to accommodate the labels or a legend. Google
will not return an image larger than width X height=300,000px or either > 1,000px. Therefore may
hinder your display if you have a lot of data points.

```
$schs = 'chs' . '700x425' . '&';
```

Add the data that we retrieved from the database above.

```
$chd = 'chdt:' . $data . '&';
```

Define the chart scaling using the min and max values that are defined below. This may seem redundant to the Y
range above below. However, this scaling will prevent Google from cutting off any values over 100.

```
$chds = 'chds' . $min . '.' . $max . '&';
```

Define the X axes labels we retrieved from the database above. You cannot rotate the labels. Therefore,
y may have to adjust the chart size and spacing and use/or numbers to represent the data points to make
they don't overlap. This is a compound chart you also have the option of defining additional labels for the X
is = Day and Y title = Temp, which should make the chart much clearer for the user. To do this you only need to
specify the index number for the data series. Here, we are defining 0 = X Axes, 1 = Y Axes, 2 = X
title, 3 = Y axis title. To position the titles right in the middle, we can set chcp index values as
percentage from origin, or 50% the middle. This is the most combination of values to grasp for
compound line chart.

```
$ch1 = 'chxt:x,y,xy' . '&';
$ch1 = 'chxl1:0' . '.labels' . '|2:Day|3|Temp' . '&';
$ch1 = 'chxp2:0,50,35' . '&';
```

Define the Y axis markers using the min and max values that are defined below. The labels are by default
and are evenly spaced.

```
$chxr = 'chr1:' . $min . '.' . $max . '&';
```

Define the value markers. I placed them on top of each data point. You can define the color, which data
index to use, which points to draw, and the size of the labels.

```
$chm = 'chm:N,000000,0,-1,11' . '&';
```

Create a random ID for the chart. This isn't really required, but it is highly recommended. It will force the
Google chart to refresh the chart each time it is requested.

```
$chid = 'chid:' . md5(uniqid(rand(),true)) . '&';
```
