The Update file will be used to update the record with the check box value. Always start by including the connection to the database.

```
<?php
include('../../Conn/dbaccess.php');
?>
```

Get the record by the Record ID passed in the URL.

```
<?php
$record = $fm->getRecordById('Demo php', $_REQUEST['id']);
```

Update the record.

```
$edit = $fm->newEditCommand('Demo php', $_REQUEST['id']);
```

Setting a Boolean check box field is very easy. You will either set it to be blank or you will set it to a value of 1. An interesting effect of unchecking the box (not sending any value) is that the BooleanCheckbox name and value will not be passed in the URL. Therefore, you can check to see if the value is empty to determine if you should clear the field or use the value from the URL. Multiple check boxes are a bit more complex and will be covered in the following example.

```
If(Empty($_REQUEST['BooleanCheckbox']))
{
$edit->setField('BooleanCheckbox', '');
}
else
$edit->setField('BooleanCheckbox', $_REQUEST['BooleanCheckbox']);

```
