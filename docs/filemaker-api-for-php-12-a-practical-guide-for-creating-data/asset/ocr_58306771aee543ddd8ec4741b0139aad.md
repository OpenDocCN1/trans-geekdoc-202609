Once the customer passes all of your security checks we get to the more complex part of the code. We need to build the header to the browser to download the file without revealing the exact path to the file. Start by storing the path to the file as the $fullPath variable. I hard-coded the path to the downloads folder. Then concatenated the file.

```
$fullPath = "downloads/" . $filename;
```

Internet Explorer apparently has issues with web servers compressing the file. You also don't want to tax the server to compress the file either. We'll temporarily turn off the output compression setting in the php.ini file.

```
if(ini_get('zlib.output_compression')) {
    ini_set('zlib.output_compression', 'Off');
```

Next, it may seem obvious, but it's a good idea to check if the file actually exists before we go any. Create the variables for the size of the file and the extension. If you use the pathinfo method it will create an array of useful information regarding the path and the file. It's much easier to extract information using this array than to parse it using a custom function.

```
if(file_exists($fullPath)) {
    $size = filesize($fullPath);
    $path_parts = pathinfo($fullPath);
    $ext = strtolower($path_parts['extension']);
```

Now we can use the switch method to "switch" the extension we stored in the $ext variable above with the associated MIME type. In the sample code I provided a list of common file types. You can add this to list or just utilize the last line of code that defines a default value for "application/force-download".

```
switch ($ext) {
    case "pdf": $type="application/pdf";n    case "exe": $type="application/octet-stream";n    case "zip": $type="application/zip";n    case "doc": $type="application/msword";n    case "xls": $type="application/vnd.ms-excel";n    case "ppt": $type="application/vnd.ms-powerpoint";n    case "gif": $type="image/gif";n    case "png": $type="image/png";n    case "jpg";
    case "jpg": $type="image/jpeg";
    default: $type="application/force-download";
```
