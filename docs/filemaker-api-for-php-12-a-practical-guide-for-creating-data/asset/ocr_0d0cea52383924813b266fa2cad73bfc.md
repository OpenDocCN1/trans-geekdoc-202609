Otherwise, then you can start the search process by telling the $fm object to begin a new compound command. To combine two or more fields to give each of the requests a unique name. Since there are four fields, number the requests in order.

```
$compoundRequest = $fm->newCompoundCommand('Demo php');
$request1 = $fm->newRequest('Demo php');
$request2 = $fm->newRequest('Demo php');
$request3 = $fm->newRequest('Demo php');
$request4 = $fm->newRequest('Demo php');
```

| FileMaker Syntax: newCompoundCommand('LayoutName') |
| $compoundRequest = &$fm->newCompoundCommand('Demo php'); |

| FileMaker Syntax: newRequest('LayoutName') |
| $request1 = &$fm->newRequest('Demo php'); |

Specify the first request from the FirstName field. You can get the value from the URL using the $_GET global.

```
$request1->addCriterion('FirstName', $_GET['FirstName']);
```

| FileMaker Syntax: addCriterion('FieldName', $Value) |
| $request1 = &$addCriterion('FirstName', $_GET['FirstName']); |

Specify the second request from the LastName.

```
$request2->addCriterion('LastName', $_GET['LastName']);
```

Specify the third request from the Number field. Notice that I'm greater than the operator ">" to the request. You can also supply the user with a pop menu to choose an operator. Retrieve the operator from the URL.

```
$request3->addCriterion('Number', ">" . $_GET['Number']);
```

Specify the fourth request from the MultiValueList field. Use the setOmit method to omit records with the submitted value.

```
$request4->addCriterion('MultiValueList', $_GET['MultiValueList']);
$request4->setOmit(true);
```
