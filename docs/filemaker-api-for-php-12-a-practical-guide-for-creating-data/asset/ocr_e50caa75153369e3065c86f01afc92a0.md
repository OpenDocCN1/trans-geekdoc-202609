9. Your test server is going to have a single hard drive. That means you can use the default locations for the database and backup folder. If your production server is set up with RAID using 3 or more drives you'll probably have partitioned into two parts. One partition for the actual data. If you want to use the space on the larger partition for the database and backup folders, FileMaker does not include a button that lets you find the folder. You can type the path manually. Then click the Validate button to make sure the path is correct. Don't forget that you have to use the name "filemac" or "filewin": naming convention as per the example syntax shown in the window.

10. FileMaker Server 12 has a new progressive backup process that you can enable. Basically it makes a backup of only data that is changed. This is useful for mid-day backups when a production server might be busy and you don't want to impact the performance by running a full backup. You can set the time interval for the frequency of the backup (i.e. every 60 minutes) and specify a path to the backup folder. Just to re-iterate, this saved file is technically a full backup. However, the backup process updates the data that is changed. That means you can recover from a disaster using the file.
