If the user clicks the Duplicate button you'll run the PHP Duplicate Record script in the database. There's no reason to make the process overly difficult with PHP. It's much easier to pass the parent's Record ID to the database to run a script on the server.

```
else {
  if ($_POST['duplicate'] == 'Duplicate') {
    $layout = 'Demo php';
    $script = 'PHP Duplicate Record';
    $parameter = $_REQUEST['id'];
    $request = $frm->newPerformScriptCommand($layout, $script, $parameter);
    $result = $request->execute();
    $display = '<p>the record was duplicated successfully.</p>';
  }
```

If the user clicks the Cancel button you can update the display message. I also like to include a link back to the list page.

```
else {
  $display = '<p>Cancel: The record was not duplicated.</p>';
  $display = '<a href="DuplicateRelatedList.php">Click here to return to the list view</a></p>';
}?
```

Output the html created by the PHP code using the $display variable.

```
<html>
<head>
<title>Duplicate Record -> Detail</title>
</head>
<body>
<?php echo $display; ?>
</body>
</html>
```
