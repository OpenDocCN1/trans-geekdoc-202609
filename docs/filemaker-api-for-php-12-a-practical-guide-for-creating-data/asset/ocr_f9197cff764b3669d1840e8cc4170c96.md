Start with the PHP code. Get the record id value passed in the URL.

```
<?php
$record = $fm->getById('Demo php', $_REQUEST['id']);
```

Note that it will not run until the user clicks the button and the information is sent using the post method.

```
if (isset($_POST['save']) && $_POST['save'] == 'Save') {

```

Tell the $edit object to edit the record using the Demo method passing the RecordID in the URL by the id value. Store the result in the $edit variable.

```
$edit = $fm->newEditCommand('Demo php', $_REQUEST['id']);
```

> FileMaker API Syntax: newEditCommand('LastName', RecordID)
$edit = $fm->newEditCommand('Demo php', $_REQUEST['id']);

Next, include all the fields that you want to edit. This should match the fields that you place in the html below.

```
$edit->setField('FirstName', $_POST['FirstName']);
$edit->setField('LastName', $_POST['LastName']);
$edit->setField('Number', $_POST['Number']);
$edit->setField('Date', $_POST['Date']);
$edit->setField('Timestamp', $_POST['Timestamp']);
```

Execute the request.

```
$edit->execute();
```
