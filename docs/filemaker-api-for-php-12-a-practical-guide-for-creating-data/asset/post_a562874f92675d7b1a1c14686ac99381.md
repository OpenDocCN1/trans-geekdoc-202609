# Lesson 28: Google reCAPTCHA

Objective: In this lesson you will learn how to implement Google's reCAPTCHA method to limit spammers and bots from submitting bogus records to your database. CAPTCHA is a program that can tell whether the user is a human or a computer. CAPTCHA technology has become very prevalent because no computer program can read distorted text as well as humans, so bots cannot navigate sites by CAPTCHA technology. However, I like the one from Google because it is constantly being updated and you do not have to do anything on your end to take advantage of the updates. The part that I like the best is that it is capable of detecting IP addresses that are solving too many CAPTCHA's and will cut them off. Finally, if you are really interested, Google also has a library for Mailchimp, which will hide your email addresses that the user has to solve to acquire the email address. For more information about acquiring a free, fully CAPTCHA account you can go to Google's web site at:

http://www.google.com/recaptcha

verify.php is where you can test if the user entered the correct CAPTCHA code. If they did, you can submit the data to your database. Otherwise, redirect the user to enter a new CAPTCHA code.
