# Lesson 7: Edit->Detail

**Objective:** In this lesson you will learn how to edit records in the database using a form. This is the same as editing a record in FileMaker Pro. The process to edit a record is to pass the RecordID from the list page to a detail page. That allows you to isolate a single record. When the user is done they can click a link back to the list page where the list of records is refreshed and the new information will be displayed.
