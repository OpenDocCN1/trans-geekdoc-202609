Create the request variable to instruct the fm object to find all the records from the Demo php layout.

```
<?php
$request = $php->newAllCommand('Demo php');
```

Using the PHP method isset to check if the name=value pair in the URL for sortBy has been set and is not empty. If it has been set you can add the addSortRule to the $request variable for the sortby value in the URL. The addSortRule always needs to be performed before you execute the find request.

| php | isset used to determine if a variable is set and is not NULL.
|---||
| | http://us.php.net/manual/en/function/isset.php |

```
if (isset ($_GET['sortBy']) && $_GET['sortBy'] != "")
{
  $request->addSortRule($_GET['sortBy'], 1);
}
```
