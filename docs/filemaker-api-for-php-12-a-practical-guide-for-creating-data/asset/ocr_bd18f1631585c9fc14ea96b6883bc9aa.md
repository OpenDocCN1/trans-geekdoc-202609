# Lesson 17: Run a Script — Delete Records

**Objective:** In this lesson you will learn how to run a script stored in the database. The script will delete all the blank records in the table. The focus of this example is how to use a script to delete blank records and return to the correct set of records back to the web page. As mentioned in the previous example, when you delete a found set of records the database will return the remaining records in the table back to the web page, not zero records in the found set as you get with FileMaker Pro. Therefore, your expectations for the data being displayed on the web vs a FileMaker Pro client are completely different.

**Difficulty:** Medium

**Sample Files:** RunScriptDelete.php

Page Navigation:
