The second function in this file is the Luhn algorithm. This algorithm uses the Modulo function to create a checksum that verifies the actual credit card number is valid or not. It does not validate if the card has sufficient funds. The responsibility of your gateway. was designed to protect against accidental errors, malicious attacks. Credit cards and many generator identification numbers use the algorithm as a simple method of distinguishing valid numbers from collections of random digits. It will detect any single-digit error, as well as all transpositions of digits. It will not, however, detect transposition of the two-digit sequence 09 to 90. It will detect the 10 possible twin errors (it will not detect 22 -> 55, 33 -> 66 or 44 -> 77). It is not the only algorithm available. However, it is the most common and will probably just fine unless your projects something else. You can find more information about this function at:

http://en.wikipedia.org/wiki/Luhn_algorithm.

function luhn_check($ccnum {
    // Remove everything except numbers
    $ccnum=preg_replace('/\D/', '', $ccnum);

    // Set the length and parity
    $number_length=strlen($ccnum);
    $parity=$number_length % 2;

    // Loop through each digit and do the math
    $total=0;
    for($i=0; $i<$number_length; $i++) {
        $digit=$ccnum[$i];
        // Multiply alternate digits by two
        if ($i % 2 == $parity) {
            $digit*=2;
            // If the sum is two digits, add them together (in effect)
            if ($digit > 9) (
                $digit-=9;
            )
        }
        // Total up the digits
        $total+=$digit;
    }

    // If the total mod 10 equals 0, the number is valid
    return ($total % 10 == 0) ? 1 : 0;
}
