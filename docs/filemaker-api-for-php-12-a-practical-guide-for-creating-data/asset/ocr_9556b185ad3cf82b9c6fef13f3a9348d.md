In the third example I investigate the PHP Date function from the second example may not work. The issue is that I only specified n/j for the Date format. Once you understand that the Date function actually uses a timestamp even though I specified n/j for the Date format you have to force FileMaker to return a timestamp from a date field you can make the necessary adjustments in the code to compare dates using the time set to 00:00:00. Otherwise, having less than 24 hours difference will return false, even though the actual dates may be 1 day apart. To compare a timestamp with 00:00:00 from a FileMaker date field you have to convert it using strtotime or use H:i:s.

```
$today = date('n/j/Y H:00:00');
$date = date('n/j/Y H:i:s', strtotime($record->getField('Date1')));
if($today > $date) {
    echo 'Today: ' . $today . ' > Date: ' . $date;
}
