# IIS Server 7.5 on Windows 7

+   1. Click the Start icon.

+   2. Choose Control Panel.

+   3. Choose Programs and Features.

+   4. Click Turn Windows features on or off from the left side of the window.

+   5. Click the box for Internet Information Services. Then click OK. This will enable the basic IIS services.

![](bbox=[0.118, 0.375, 0.688, 0.703])

Figure 2-7: Enable Internet Information Services.

> All permissions on IIS 7.x are turned off by default. Permissions for the IUSR and IIS_IUSRS Groups for the Temp folder and wwwroot folder must be turned on manually. If you do not turn on these permissions you will not be able to access any web pages using IIS Server.

+   6. Navigate to the Temp folder located:

```
C:\Windows\Temp
```

+   7. Right-click the Temp folder and choose Properties.

+   8. Click the Security tab. Click the Continue button to change the Security settings.

+   9. Click the Add button.
