(d(3)) Exactly 3 numbers for the exchange
[s] 0 or 1 white space character
[-] 0 or 1 dash
(\d(4)) Exactly 4 numbers for the number

If you use all the options above, your phone number would be formatted as XXX-XXX or (XXX) XXX-XXXX.
A regular expression would look something like:

```
/^(\d(0,3))?[-\s]?\(\d(3))\)?[-\s]?(\d(4))$/
```

On the other hand, I prefer to force the user to supply the entire phone number, including the area code.
Therefore, I suggest that you use the code below for this example. I also know that when the user is done typing in their phone number the length of the number should be exactly 12 characters, including the dashes.
So I'm also going to use the str (length) function. If there is anything that doesn't match I'm going to set the $message variable with the response for the user and display it in this form.

```
<?php
If(isset($_GET['Submit']) && $_GET['Submit']=='Submit') {
    // Match the number 858-555-1212 and be 12 digits
    $pattern = '/^(\d(3))?[-\s]?(\d(3))?[-\s]?(\d(4))$/';
    if (preg_match($pattern, $_GET['PhoneNumber']) &&
        strlen($_GET['PhoneNumber'])==12) {
        $message = 'Thank you for using the correct phone number format.<br>';
    } else {
        $message = 'Invalid phone format.<br>';
        $errors = 1;
    }
}
```
