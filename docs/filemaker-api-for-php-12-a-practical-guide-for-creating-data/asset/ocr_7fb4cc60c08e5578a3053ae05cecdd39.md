The itself has many elements. The first required element is the form tag. The action specifies what web page
is going to be sent to. Depending on how you build your web page(s) you can send the
information back to the same page or send it to a totally different page. My personal preference is to use
two pages because it makes the intended use of pages more obvious in the code and each page has
level troubleshoot. Next, in the forms you can do things as send hidden values that you don't want displayed on the
Search: for example you can pass the ID from the URL using PHP code. For a standard
search field you'll include a text box that the users can fill in. In the example search below
below I included a text field the name Search, which will be the name of the value in the URL. Lastly, in the example
I included a button named Search that allows the user to submit their request. This allows you to determine the value of the
clicked by the user. That way you can differentiate between multiple buttons in the form such as delete, cancel,
vert, etc. to ensure the correct code based on the user's choice.

```
<form action="Forms.php" method="get">
<input name="ID" type="hidden" value="<?php echo $_REQUEST['ID']; ?>">
nSearch: <input name="Search" type="text">
<br />
<input name="submit" type="submit" value="Search" />
</form>
```

When you send information from a form it sends the data as name=value pairs. In the example
above, the forms send three name=value pairs. For example, ID=3 and Search=Todd. The one most people
forget about is the name=value pair for the buttons, which is submit=Search. All name=value pairs are separated
by an ampersand &; The URL when you click the Search button for the form will look something like:

```
http://localhost/ToddDuellPHP/Forms.php?ID=3&Search=Todd&submit=Search
```

Remember I said earlier that all elements are immediately available to PHP scripts. That means that you
retrieve any information from a Get or Post method using the superglobal $_GET, $_POST,
and $_REQUEST. If you use the Get method in your form you can retrieve any value by specifying the name. In
the example you could use $_GET['Search'] to retrieve the value from the Search field. If you use the Post
method you'd use $_POST['Search'] to retrieve the contents. If you want to retrieve the contents regardless of
which method was used you use $_REQUEST['Search']
