The next section of PHP code will run the script. Start by checking to see if the $ POST superglobal has been set for Delete and that the user clicked the Delete button. Create the variable for the $layout name. The layout does not need to have a script or button attached to it, but you do have to run the script based on the context of a layout. The $script variable is the exact name of the script stored in the database. The $parameter is what you will pass to the script. This is very similar to using script parameters in FileMaker Pro. You will also retrieve parameters using the exact method in the FileMaker script — Get(ScriptParameter). Finally, put all the variables together using the newPerformScriptCommand and execute the script.

```
if ($_POST['Delete'] && $_POST['Update'] == 'Delete') {
$layout = 'Demo php';
$script = 'PHP Delete Blank Records';
$parameter = '';
$request = $fm->newPerformScriptCommand($layout, $script, $parameter);
$result = $request->execute();\}
```

Trap for errors.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}?
```
