## FileMaker API Syntax: addSortRule('FieldName', Precedence, Order)

```php
$php $request = addSortRule($_GET['sortby'], 1, FILEMAKER_SORT_ASCEND);
```

Precedence is a numbered priority order 1, 2, 3, etc.

Order = FILEMAKER_SORT_ASCEND (default if not specified) FILEMAKER_SORT_DESCEND

Create the header for the table to display the records. The header for each column in the table will contain the link to sort the records. The link is the exact URL to the page with the name=value pair of sort and the name for the value. One thing to keep in mind is that time the user clicks the link a new request is made to the server for a set of records, sorted by a single field. The good part is that the data will always be current. The bad news is that it does the performance server to re-sort the records, the client's browser does not perform the sort.

# Lesson 2: Sort Records, Fixed

**Objective:** In this lesson you will learn how to sort records with more than one field and more one parameter.

**Difficulty:** Easy

**Sample Files:** PHPFiles/Core/Lesson2/SortRecordsFixed.php

**Page Navigation:**

![](img/5a2c5fda68d42e5d65f51850276e49ec_92_0.png)

**FileMaker API Methods:**
- FindAllCommand()
- addSortRule()
- execute()
- getMessage()
- getRecords()
- getField()

**Code:**

Always start by including the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
```

Create the request variable to instantiate the fm object to find all the records from the Demo php layout.

```php
<?php
$request = $fm->newAllCommand('Demo php');
```

You can add many sort rules as you want. Have the $request variable use the addSortRule to sort by the FirstName then the Date. Notice the precedence order is specified as FirstName (1) then Date (2). This is the same concept as the sort order box in FileMaker Pro. The sort order is always FILEMAKER_SORT_ASCEND by default, so you don't have to declare it. If you want to sort the field in descending order to declare FILEMAKER_SORT_DESCEND.

```php
$request->addSortRule('FirstName', 1);
$request->addSortRule('Date', 2, FILEMAKER_SORT_DESCEND);
```

Trap for errors.

```php
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}
```

Use the getRecords method to store all the records as an array in the $records variable.

```php
$records = $result->getRecords();
```

Create the header for the table to display the records.

```html
<table border="1">
<tr>
<th>First Name</th>
<th>Last Name</th>
<th>Number</th>
<th>Date</th>
<th>Time Stamp</th>
<th>Calculation</th>
<th>Record ID</th>
</tr>
```

As in FindAllRecords, you'll create all the html to display the records using the foreach loop and getField(method).

```php
foreach ($records as $record) {
    echo '<td' . $record->getField('FirstName') . '</td>';
    echo '<td' . $record->getField('LastName') . '</td>';
    echo '<td' . $record->getField('Number') . '</td>';
    echo '<td' . $record->getField('Date') . '</td>';
    echo '<td' . $record->getField('TimeStamp') . '</td>';
    echo '<td' . $record->getField('Calculation') . '</td>';
    echo '<td' . $record->getField('RecordID') . '</td>';
}
```

Finally, close out the table and PHP code section.

```php
echo '</table>';
?>
```

# Lesson 3: Search Records, Simple

**Objective:** In this lesson you will learn how to search for records based on a single field using a form.

**Difficulty:** Easy

**Sample Files:** PHPFiles/Core/Lessons/SearchRecordsSimple.php

**Page Navigation:**

Search

**FileMaker API Methods:**
- newFindAllCommand()
- newFindAllCommand()
- addCriterion()
- execute()
- getMessage()
- getRecords()
- getField()

**Code:**

Always start by including the connection to the database.

```php
<?php
include("../dbaccess.php");
```

Create the search form to find the file SearchRecordsSimple.php to search by the field FirstName. This file will act as both the search form and the display for the set of records. The form uses the Get method, which means the search string will be viewable in the URL for the user. The input name FirstName will be passed as the name in the URL. I prefer to use the actual name of the field to make it easier to read the URL. The value will be what the user types in the search box.

```html
<form action="SearchRecordsSimple.php" method="get">
First Name:<input name="FirstName" type="text" />
<br>
<input name="submit" type="submit" />
</form>
```

Start the code by checking the URL $_GET superglobal for the FirstName. If it's empty tell the $request variable to add all the records on the demo php layout. Otherwise, use the $_GET superglobal to retrieve the FirstName value from the URL. Then fill the fm object to add a new find command to the $request variable. Finally, tell the $request variable to add the find criteria to the FirstName field using the contents from the FirstName variable.

```php
<?php
if(empty($_GET['FirstName']))
$FirstName = ""
$request = $fm->newAllCommand('Demo php');
elelse
{
FirstName = $_GET['FirstName'];
$request = $fm->newFindCommand('Demo php');
$request->addCriterion('FirstName', $FirstName);
}
```
