Next, loop through all the records to update the lat/lon values. Create the new GoogleMapAPI object and retrieve the coordinates by the Address, City, and State. The coordinates are actually returned as an associative array of values. That makes easy to make the code cleaner. We create the $lat and $lon variables by specifying the values for $geo_coords as ['lat'] and ['lon'].

```php
$map_object = new GoogleMapAPI();
foreach($records as $record) {
	$address = $record->getField('Address') . "," . $record->getField('City') .
	", " . $map_object->getField('State');
	$geo_coords = $map_object->getgeocode($address);
	$lat = $geo_coords['lat'];
```
