53. Open your web browser on the computer hosting FileMaker Server and type the following address:

http://localhost:16000

This will open the Admin Console Start Page. If you don't have direct access to FileMaker Server you can always substitute localhost with the IP address of the server. FileMaker Server Console runs on port 16000. So the only thing you'll need is to make sure any firewalls between you and the server are open for that.
