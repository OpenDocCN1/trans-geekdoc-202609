To change the Checkbox array from the URL back to a return separated list of values that FileMaker understand we have to use the implode PHP method with "r", which is a line break between each value. The nice thing about this PHP method is that it will automatically combine all the Checkbox values in the URL.

```
$Checkbox = implode("r", $_GET ['Checkbox']);
```

```
implode(string, array); Joins array elements with a string.
```
