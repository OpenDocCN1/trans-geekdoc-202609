# Configure Web Publishing

45. Click Web Publishing in the left window.

46. On a test server it's nice to know if errors are coming from the web publishing core, the web publishing engine, or FileMaker Server. Therefore, I would recommend selecting the radio button for Error level messages. If your production is stable you can uncheck the logging box to improve performance.

47. On a test server you can set the number of web publishing sessions to 5 so you don't lose performance. On the production you probably want to set the number of sessions to 100 since you won't know how many people will be simultaneously accessing your web server. 100 connections doesn't sound like a lot. However, the session is opened during the request (i.e. search for requests), and then is immediately closed once the information is sent back to the user's browser. This happens in a fraction of a second. Therefore, 100 simultaneous sessions is actually a lot of capacity. Just keep in mind that the more unused you leave open, the slower the performance of the server.

48. Click Save.

49. We're obviously going to access FileMaker data using the API for PHP. So you will need to check the box to enable PHP publishing.

50. A few of the examples in the book use pre-validation to check the data on the web server before sending the data to the database. For the pre-validation you work to have you check the box to enable record data pre-validation.

51. Depending on your language preferences you either choose UTF-8 or ISO-8859-1 for the character encoding, UTF-8 is basically the same character set as ASCII, which works well with English. ISO-8859 is also the same character set as ASCII, but is designed to work with European languages.

52. Click Save.

# Testing Your PHP

53. Open your web browser on the computer hosting FileMaker Server and type the following address:

http://localhost:16000

This will open the Admin Console Start Page. If you don't have direct access to FileMaker Server you can always substitute localhost with the IP address of the server. FileMaker Console runs on port 16000. So the only thing you'll need is to make sure any firewalls between you and the server are open for that.
