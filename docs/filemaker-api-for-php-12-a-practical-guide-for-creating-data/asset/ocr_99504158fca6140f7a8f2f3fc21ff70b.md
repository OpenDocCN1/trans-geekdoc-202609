Do Not Display Errors
Throughout the image we have reported errors back to the browser to give you a sense of how the code works to trap errors. In reality, when your code or database creates an error you may not want to report it back to the user if it's new. In many cases an error can provide the user with information about your server and the path to sensitive files. A smart hacker can take advantage of this information. Therefore, the best way to make sure that errors are not displayed to the user is to change the display_errors setting in your php.ini file to a value of 0. If you are using a hosted server where they have not configured the server with this setting you can include the following code when you trap for errors:

```
ini_set('display_errors', '0');
```

You can find more information about ini_set at http://php.net/manual/en/function.ini-set.php.
