Since we are passing the RecordID in the URL string, we can acquire it from the $_POST variable. Then it's as simple as telling FileMaker to use getRecordID from the Demo Detail layout. Finally, echo the contents of the Address, City, and State field in the desired HTML/CSS format, which will be displayed on the page in the DIV tag. That's it. Super fast and super easy.

```
$record = $fm->getRecordID("Demo Detail $_POST["id"]);
echo 'Address: ' . $record->getField('Address') . '<br>';
echo 'City: ' . $record->getField('City') . '<br>';
echo 'State: ' . $record->getField('State') . '>';
?>
```
