# PHP Info

**Objective:** Occasionally you'll need information about your PHP build. Using the PHP_Info.php file will return everything you want to know about your PHP and server installation. What's really too bad is that you can't configure any of the settings from this screen. With Apache, you'll still need to manually change the configuration file.

**Difficulty:** Easy

**Page Navigation:** N/A

**FileMaker API Methods:** N/A

**Code:**

Displaying all information about the PHP installation is as easy as the method phpinfo().

```
<?php
phpinfo();
?>
```
