Now the map has been built from the found set of records we can build the table to display the records. The first section is the header for the table, followed by the records.

```
html. = '<table border="1" cellpadding="3">
html. = 'Lat: ' . $SearchLat;
html. = '<br>';
html. = 'Lon: ' . $SearchLon;
html. = '<br>';
html. = 'Distance: ' . $Distance;<br>;
html. = '<tr>';
html. = '<th>Name</th>';
html. = '<th>Address</th>';
html. = '<th>City</th>';
html. = '<th>State</th>';
html. = '<th>Distance</th>';
html. = '</tr>';

foreach ($records as $record){
html. = '<tr>';
html. = '<td>' . $record->getField('Name') . '</td>';
html. = '<td>' . $record->getField('Address') . '</td>';
html. = '<td>' . $record->getField('City') . '</td>';
html. = '<td>' . $record->getField('State') . '</td>';
html. = '<td>' . $record->getField('Distance') . '</td>';
html. = '</tr>';
}

html. = '</table>';
```

The map and markers require the use of JavaScript. The best part about this class is that you don't have to write a single line of JavaScript. Place just two lines of PHP code in the header where the JavaScript would normally go and your work is done.

```
<html>
<head>
<?php
echo $map_object->getHeaderJS();
echo $map_object->getJS();
?>
</head>
```
