# ## FileMaker API for PHP Tutorial

Estimated Time to Learn: 1 Week

FileMaker Server/Examples/PHP/Tutorial/English/

The FileMaker API for PHP tutorial supplied with FileMaker Server is based on a questionnaire. There are six basic lessons. Lesson 1 is good because it shows how to make a connection to the database. Lesson 2 explains how to display an image from a container file using the ContainerBridge.php file. This example is also very helpful. The rest of the lessons fall off very quickly in terms of content and usability. As you can see, with, with more than 50 API methods and only six examples it falls very short in terms of a complete learning environment. The real problem is the questionnaire.fp12 file.
