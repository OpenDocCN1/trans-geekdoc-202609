# Lesson 10: Edit Portal Record

**Objective:** In this lesson you will learn how to update related records into the database using a form. The general process is to start by searching for a list of records. Then click a link to the detail page where the related records are shown. Finally, click the link for the related record to isolate it as a single record so it can be updated in the database. This is the same as editing an existing record in a portal in FileMaker Pro, albeit editing a record in a portal in FileMaker is a lot easier.
