# Display Check Boxes and Update Records

To make the features of selecting and updating multiple records all the records will need to be displayed in a single form. I did not include any type of sophisticated search field on the page, as the point of this lesson is the technique of building the form with all the checkboxes and record data, not a complicated interface. I'll let you build that yourself. Once you have mastered the technique it is easy enough to do.

One of my goals is to apply the KISS principle to my techniques. I believe that fewer lines of code and fewer bells is always more. If you've been paying attention then you will probably probably noticed that there is no database field for the Select checkbox. There's a reason for that - it's not necessary. The only place we need it is on the web page as a placeholder for the user to check the box on their screen. The significance of the checkbox is that it will need to be dynamically named as the RecordID so that we can identify which record(s) needs to be updated. Now that we have some of the background information regarding how the form and fields we can get into the code to make sense of this whole process.

Always by connecting to the database.

```php
<?php
require_once ('FileMaker.php');
$fm = new FileMaker();
$fm->setProperty('database', SelectMultipleRecords);
$fm->setProperty('hostspec', 'http://127.0.0.1/');
$fm->setProperty('username', 'Admin');
$fm->setProperty('password', '1234');
?>
```

Find all records using the Demo layout and store the results in the $records variable.

```php
<?php
$request = $fm->findAllCommand('Demo');
$result = $request->execute($result);
if (FileMaker::error($result)) {
	echo "Error: " . $result->getMessage() . ".";
	exit();
}
$records = $request->getRecords();
```

The next section of code will only run when the user clicks the Update button on the form. Normally your form would process this information using the POST method because you don't want the users to bookmark records that change. I use the GET method here so we can set the name=value pairs passed in the URL. Loop through each of the records in the $records array to determine which ones need to be updated. This enables you to uniquely identify every record as update the records based on the RecordID, which is retrieved by FileMaker. If the RecordID is set as the name in the URL you can update the record. Otherwise, you can skip the record. In this demo I'm simply updating the Timestamp field for each record. If you wanted to do something different, as delete the checked records, this is the section of code you would modify to perform that task. Lastly, since you're updating the records you'll want to refresh the screen for the user. The best mechanism to perform this only one time is to use the PHP header() to redirect the user back to the same page as the very last step.

```php
if(isset($_GET['Update'])) {
    foreach($records as $record) {
        if(isset($_GET['RecordID'])) {
            $edit = $Em->newEditCommand('Demo', $record);
            $edit->getField('RecordID');
            $edit->setField('Timestamp', date('m/d/Y g:i:s', time()));
            $edit->execute();
        }
    }
    header("Location:SelectMultipleRecords.php");
}
?>
```

The PHP code works in conjunction with the form below. The form action will call the SelectMultipleRecords page using the GET method. Again, in a production solution you'll probably want to change this to the POST method. The first part of the form is the static header information for the table inside the

```html
<form action="SelectMultipleRecords.php" method="get" id="form">
<table border="1" cellpadding="3">
<tr>
<td>Select</td>
<td>Name</td>
<td>Timestamp</td>
<td>RecordID</td>
</tr>
```

The content of the form is created dynamically from the data in the $records array. This is how you essentially fool the user interface to look like there are multiple records displaying actually one big form. Loop through each of the records creating the table rows and table data. The key item is the naming of the checkbox. You'll use the RecordID as the name of the checkbox. This technique doesn't require the checkbox to have a value, so I left it blank to write code and improve performance. An interesting thing about checkboxes is if they are not checked, the checkbox does not appear in the URL. Therefore, the PHP code only needs to check for the existence of the checkbox name in the URL, not the value.

```php
<?php
foreach($records as $record) {
    echo 'tr';
    echo '<td><input name="' . $record->getField('RecordID') . '" type="checkbox" value="' . $record->getField('RecordID') . '"></td>';
    echo '<td>' . $record->getField('Name') . '</td>';
    echo '<td>' . $record->getField('Timestamp') . '</td>';
    echo '<td>' . $record->getField('RecordID') . '</td>';
    echo '</tr>';
}
?>
```

Once the form content is built you can close the table, include the Update button, and the form. You should now have a fully functional form that allows you to check any boxes and update their respective records.

# Toggle/Untoggle Check Boxes

Using JavaScript to toggle the check boxes is quick and simple. The point of this feature is if you have a lot of records on the screen users will probably want to toggle all the records by clicking a single button, rather than manually toggling each box. Place the script below in the head section of your web page. This script creates the function selectToggle loop through each checkbox in the form and update the HTML code to checked or empty the value. One of the things I like about this script is that it doesn't toggle the existing value of each checkbox, it actually toggles all the checkboxes to the same value. It will also work on multiple forms on your web page by passing the name of the form in the link that I'll describe. The only gotcha is that it will toggle ALL the checkboxes in the form. So you'll want to be careful or you'll need to investigate an alternative method that all the checkboxes with this same name and uses the RecordId for the values.

```html
<script type="text/javascript">
function selectToggle(toggle, form)
{
  var myForm = document.forms[form];
  for(var i=0; i<myForm.length; i++) {
    if(toggle) {
      myForm.elements[i].checked = "checked";
    }
    else {
      myForm.elements[i].checked = "";
    }
  }
}
</script>
```

Finally, you'll need to include the links for Toggle All and Untoggle somewhere at the top of the page. I chose to place them in the form.

<a href="javascript:selectToggle(true, 'form')">Toggle All</a> | <a href="javascript:selectToggle(false, 'form')">Untoggle All</a>
