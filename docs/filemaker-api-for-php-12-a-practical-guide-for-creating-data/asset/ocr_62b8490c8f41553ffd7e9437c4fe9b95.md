# Required Elements

Just like the pie chart, the goal is to build a URL for an image container. The base URL for every type of chart is:

https://chart.googleapis.com/chart?

From there we all the name=value pairs (NVPs)'s separated by &amp; which is the encoded value for &. Why &amp? Because we'll be embedding the chart URL in the web page as an image source. To get the correct URL special characters needs to be encoded. That also includes any values in the database that might cause problems with the string. Rather than make a huge string of values I decided to define all the required and optional variables inside the PHP code. Then assemble the final URL in an easy to read and modify format. The NVPs can be assembled in any order. However I prefer the order of required, optional, and random ID number. Let's start with the required NVPs.

Define the chart type variable. I chose the vertical bar for the demo.
