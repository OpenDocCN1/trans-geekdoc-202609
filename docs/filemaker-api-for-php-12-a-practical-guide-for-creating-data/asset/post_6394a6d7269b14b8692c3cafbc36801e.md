# Lesson 25: Pre Validate Data Before Update

**Objective:** In this lesson you will learn how to use the PHP engine to validate the data before it is updated by the database. The main reason why you would want to do this is to use the performance of the PHP engine to validate the data rather than tax the database performance. The other reason is that FileMaker has several validation methods that cover the majority of the simple validation options and are very easy to enable. There are some limitations to the pre validation capabilities versus validating data with PHP code. You can only validate the data for the following criteria: not empty, number only, maximum characters, 4 digit year, time of day, timestamp. That means validation by calculation is not at your disposal and will require custom PHP code if you need to use something other than the built validation capabilities.

In actual testing of the pre validation methods I found that setting the Date field to a strict 4-digit date will always fail pre validation even if the date is correct. By default, you will always receive an error if the incorrect field is not set to validate a 4-digit date. I don't recommend that you set the field to require a 4 digit date.
