To display the image from the container field using the img tag you will pass two pieces of information to the ContainerBridge.php file. The source attribute for the image will always be the name of the helper file: ContainerBridge.php followed by the name=value pair of path= and the $fm object using the getDataURL method with the contents of the container field in urlencoded format. Earlier in the book I described the internal workings of the ContainerBridge.php file works to do all the heavy lifting. To display the contents of the field you only need to pass this information to the helper file. This should serve as a good example why it is important to separate your code into logical pieces so they can be reused more than one web page.

```
echo '<img src="ContainerBridge.php?path=" . $fm->
getContainerDataURL(urlencode($record->getField('ExternalContainer')))) . '/>';
```

FileMaker API Syntax: <img src="ContainerBridge.php?path=" . "Path"/>
src = The name of the file that will convert the image — ContainerBridge.php
path = urlencode the contents of the container field using the getContainerDataURL.

```
'img src="ContainerBridge.php?path=" . $fm-

/>'
```
