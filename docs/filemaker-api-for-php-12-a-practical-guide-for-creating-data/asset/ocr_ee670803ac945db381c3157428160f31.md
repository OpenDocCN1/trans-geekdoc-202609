verify.php is where you can test if the user entered the correct CAPTCHA code. If they did, you can submit the data to your database. Otherwise, redirect the user to enter a new CAPTCHA code. Again, the private key here works with the domain "http://localhost" for your testing server. You'll need to get your own key from Google to work with your web site.

```
<?php
require_once('recaptachalib.php');
$privatekey = "6LeJrwSAAAAANnoptkR0R6g6m94WNO8K7Jzfjzc";
$resp = captcha_check_answer($privatekey,
    $_SERVER['REMOTE_ADDR'],
    $_POST['recaptcha_challenge_field'],
    $_POST['recaptcha_response_field']);
if (!$resp->is_valid) {
    die("The CAPTCHA wasn't entered correctly. Go back and try it again." " . $resp->error());
} else {
    die("Thank you, " . $_POST['Name'] . ". We will send you an email response to: " . $_POST['Email']);
}
?>
```

recaptachalib.php

There are no changes required to the recaptachalib.php page. This is the code supplied by Google to pass the CAPTCHA to their servers for validation. All you have to do is include it in your site.
