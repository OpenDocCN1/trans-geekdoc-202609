# Table Structure

The table structure is very simpel know how to work with. First is interacting with a single table. Second is interacting with a related table: For much of the demo pages you only work with the php demo. Then you'll work with related records, which use the related data table. There's nothing spectacular about the relationship between the two tables. The php_demo file uses the RecordID to make the relationship to the FK field in related_data table. FK stands for "foreign key". The import table is used as part of the demo files that run a script to upload files to the user's computer. Think of it as a single table log to document what files were uploaded and if the upload was successful.

> You will NOT interact with the actual tables using the FileMaker API for PHP. You will need to create specific layouts with all the elements (i.e. fields, portals, value lists, etc.) you want to access.
