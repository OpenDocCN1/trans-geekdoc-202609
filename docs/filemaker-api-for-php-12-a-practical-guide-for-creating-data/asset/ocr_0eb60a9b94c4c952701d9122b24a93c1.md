# Lesson 38: Google Pie Charts

**Objective:** In this lesson you will learn how to integrate the Google chart API. FileMaker 11 give you the ability to chart your data. Unfortunately, they didn't make the charting capability available to the API for PHP. So we still need to either purchase a plugin or use third-party API's to chart data on the web. Native FileMaker charts only the basic charting elements of bar, line, area, pie, bubble, and scatter charts. That will certainly cover 99% of most business needs. It's really only when you get into the engineering and statistical capabilities. Until then, you can easily replicate FileMaker's charting capabilities using the free Google Chart API.

**Code:**
The Google Chart API makes charting incredibly easy for every skill level. The hardest thing you'll encounter is retrieving the data from the database and formatting it to their standards, which isn't all difficult either. After it's up to you to determine which features of the chart you want to utilize. There are a few required elements and a whole of optional elements that you can utilize. Sample page for this lesson includes every element with one simple line of code for an embedded image that passes all of the data to Google and returns a chart image to your web page.

> For complete information regarding the Google Chart API, please visit the Google web page:
http://google.com/apis/chart/image/docs/making_charts.html

Always start by the connection to the database.

```
<?php
require_once ('FileMaker.php');
$fm = new FileMaker();
$fm->setProperty('database', 'GooglePieCharts');
$fm->setProperty('hostspec', 'http://127.0.0.1/');
$fm->setProperty('username', 'Admin');
```
