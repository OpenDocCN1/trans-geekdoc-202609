# Scripts

If there is one specific reason to use the FileMaker API for PHP it is because it gives you access to run side scripts in the database. Scripts are another proprietary feature of FileMaker. They are not like stored procedures, which can be accessed by ASP and JSP. Neither ASP nor JSP can run FileMaker scripts. This is a major feature of the FileMaker API for PHP once you have it at your disposal, you'll never want to use any other method to build your web pages. This feature alone makes the frustrating costing you time and effort. There are six sample scripts in the php_demo.fmp12 file that demonstrate a variety of useful techniques.

Make sure you show compatibility for the Server when creating your scripts. Only Server compatible scripts will execute. Be sure to test the script on FileMaker Server itself as the script may run differently on FileMaker Pro.
