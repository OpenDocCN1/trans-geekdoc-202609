Finally, we can create the HTML form to let the user upload and view the uploaded image. The difference in this form compared to the other forms we've worked with so far is that the enctype is "multipart/form-data". That lets the user upload a file rather than text. As before, we're also supplying the Record ID as a hidden value. Once the file is uploaded we can display the image for the user as well as the destination path so they know where it went and what it was named. This part is only for your development purposes. You should never include the file name and path for your production web site if it is for public use. To wrap things up, once the user is happy with their upload they can click a link to go back to the list of records.

```
<html>
<head>
<title>Upload Image and Validate</title>
</head>

<form action="Upload.php" method="post" enctype="multipart/form-data">

Upload image: <input name="new_image" type="file" />
<input type="submit" name="upload" value="Upload />
</form>
```
