# Extended FileMaker vs. PHP Syntax

If you're like my comfort zone lies within the constraints of the FileMaker calculation engine and scripts, any time someone throws something out like PHP, AppleScript, VBA, you cringe at the thought of having anything new. Your first approach is usually to reach out to a plugin vendor that will keep you inside the calculation engine or create your own custom function. If that doesn't work, most people either call a consultant or give up — proclaiming ‘it can’t be done with FileMaker’. Rest assured, I’ve come across very many scenarios in the past twenty-five years where FileMaker couldn't handle the job. That includes relifying the calculation engine using PHP. This is exactly where I start when something new comes along. If the technology can do everything that the calculation engine can do, and not tax my brain, then a comparison of PHP math strings and functions will be helpful. In fact, you'll find that how you can replicate the calculations using PHP has a lot more functions in PHP than FileMaker has to offer. PHP may even give you some good ideas for custom functions that you should install in FileMaker
