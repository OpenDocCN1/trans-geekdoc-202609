# PHP Reference Guide

Estimated Time to Learn: Reference Only
Maker Server/Documentation/PHP API Documentation/index.html

The PHP Reference Guide fromMaker is generated from a program called phpDocumentor. Basically, what it does is use the API files and generates an HTML-based manual that displays information about the classes and files. The description of the methods will give you all the variables and options and in some cases recommendations for usage. However, you will not receive any syntax or examples of how the methods should be used. This makes the PHP Reference Guide very frustrating and not a good place to learn to use the Maker API for PHP. Without working examples, this is really only for users that have experience with FileMaker and PHP. The good part about this is that you will find every method in the API by looking it in this index of elements in alphabetical order.
