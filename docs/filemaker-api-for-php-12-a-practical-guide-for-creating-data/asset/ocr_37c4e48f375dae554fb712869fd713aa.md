# Lesson 43: Print PDF Report

**Objective:** In this lesson you will learn how to create a PDF report. If you are developing PHP web applications, sooner or later your client is going to request the ability to print a report as a formatted PDF document. At first you're going to cringe at the request because you know that printing from PDF to a web page has some serious limitations. Therefore, you might suggest that the report be programmed as a PDF file downloaded by tightly controlling the rendering rather than relying upon your browser's PDF printer driver. PDF is supported by the FDFLib class from PHP.net. It's not free. You don't have to purchase a commercial license from pdflib.com. The price starts at $195 for Windows and OS X. Although this is a very robust class with a lot of features and support, it might be far more advanced than you need. There are two decent classes that you can use as an alternative. The simplest is FPDF, which is very easy to use. It is perfect because you can get up and running in a reasonably short amount of time if your report is simple. It can also be extended with a variety of other features such as codes. The other free class is tcpdf.org. This class has more features and slightly more examples. To be realistic, creating a PDF report from a web application is not particularly easy or fast. It can be daunting, especially if you have dynamic content that changes in length. Let's face it. FileMaker clients are very accustomed to reports being installed at breakspeed wherever, PDF reports generated from a web application can take many hours or days to produce. You'll definitely need to let your customer know that each report can cost thousands of dollars to produce.

**Code:**

Copy the fpdf class files to your web site. I like to keep them in the fdf17 folder so I know that I'm working with version 1.7 release. Technically you only need the fpdf php file and the font folder with the definitions. Everything else in the file is for tutorials and documentation. I highly recommend that you at least look through the examples before you proceed with this lesson because I'm only going to provide a basic working example that utilizes a few built in features to generate the report. The goal of the report is to create a header, an Excel-table-like body with all the data from the database, and a footer with the page number.

Always start by connecting the connection to the database.

<<?php
require_once ('FileMaker.php');
