To calculate the size for all the files you have to loop through the $_FILES superglobal, which is stored as an associative array with each of the uploaded file's information (i.e. _tmp_name, type, name, size). Notice the math operator += to the $Total variable. With PHP this means add or sum each 'size' value the loop processes each value in the array. I really there was a 'sum' function for an associative array, but there isn't. So this is the shortest I could come up with to sum all the sizes in the array.

Finally, if the user exceeded the server upload limit you can display a message to the user and exit the script. There's no reason to send the email if the attachments aren't going to be included. File size is calculated as Bytes. You can convert 1 MB = 1000,000 Bytes. If you want to be 1KB = 1024 Bytes.

```
foreach(\$FILES as \$file) {
    \$Total += \$file['size'];
}
if(\$Total > 2048000) {
    echo "Your combined file size exceeds 2MB: " . \$Total . " MB";
}
```

Now we process the uploaded files by looping through the $_FILES array. For each file create a variable for tmp_name, type, name, and size. This will make assembling the header information easier.

```
foreach(\$FILES as \$file) {
    \$tmp_name = \$file['tmp_name'];
    \$type = \$file['type'];
    \$name = \$file['name'];
    \$size = \$file['size'];
}
```
