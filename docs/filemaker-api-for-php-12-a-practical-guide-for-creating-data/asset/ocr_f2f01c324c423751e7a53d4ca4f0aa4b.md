The form points back to the UpdateBooleanCheckbox.php page using the Get method. It sends the hidden value for the Record ID value in the URL as name. Next, you can use the PHP method strcmp to compare the current value in the variable $BooleanCheckbox that we created in the PHP code above to the value of 1. If the current value in the database is 1 you can echo checked='checked', which is the W3C approved method to display a check in the box. Finally you can finish the checkbox where we'll match the name of the check box to the name of the database (BooleanCheckbox), type='checkbox' and the value='1'.
