# Lesson 4: Jump Menu

Objective: In this lesson you will learn how to create a jump menu using PHP and JavaScript. Jump menus are very common on web pages to enable users to choose an item and 'jump' to a different page, find specific records, or sort records without to click an extra submit button. In this example we will explore how to populate the jump menu with a value list from a FileMaker database as well as the jump menu JavaScript code created by Dreamweaver.
