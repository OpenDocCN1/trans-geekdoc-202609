# Reconfigure FileMaker Server

At this point your web server is running like a champ on both http and https if you open the default web page (iisestart.html on Windows or index.html on QX) in your browser. However, you'll quickly notice that if you try to access your dynamic PHP pages from the database that nothing works and the web publishing engine crashes. Summer! There is some obscure documentation at FileMaker (Tech Article #7619) to use cURL with SSL certificates. Don't worry, you don't need to know anything about cURL for this work. Perform the following tasks to enable the cURL library:

+   1. Open the FileMaker API file located at:

/FileMaker Server/Web Publishing/publishing-engine/php/FileMaker/conf/filemaker-api

+   2. Uncomment the following line of code:

```
$_FM_CONFIG['cURLOptions'] = array(CURLOPT_SSL_VERIFYPEER => false)
```
