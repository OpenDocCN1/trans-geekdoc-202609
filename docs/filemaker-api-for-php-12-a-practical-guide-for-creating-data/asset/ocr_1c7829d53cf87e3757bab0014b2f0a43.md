# Lesson 44: Select and Update Multiple Records

**Objective:** In this lesson you will learn how to select and update the recordID number multiple records. You've seen the technique of selecting one or more records with a checkbox on web mail and ecommerce sites. More sophisticated sites also provide features that allow you to toggle/untoggle all the records, update or delete all the checked records, if you look at these features long enough you start to ask how the web page update multiple records using a single form? I'm sure of you have learned that records need to be isolated as a single record and update one record at a time. This lesson will demonstrate a functional technique to select and update multiple records using checkboxes in a single form. As an added bonus the lesson will also include a simple JavaScript technique to toggle all the checkboxes.

There are two separate techniques demonstrated in this lesson. It's best to separate them into their respective components rather than going through the code. That way you'll be able to pick out the pieces you want to use. The main part of the lesson demonstrates the use of check boxes to select the records in the form and the Update button used to update only the checked records. The second item is the feature to toggle all the records. Once you have more than a few records on the page users you will be a lot happier if they don't have to manually click every single box.

The only field of interest is the recordID. This field represents the internal record generated by FileMaker. To update a record you have pass this value in your PHP code. Another interesting thing about this value is it is provided by default to the API when your web page receives the data from the found set of records. Whereas the recordID is not available to the FileMaker Pro client unless you create a specific field that calculates the value as I have done in the database. In other words, you don't need a separate field in the database to display this internal serial number because the API will return it to your web page automatically. I've included more records in a single form to help you understand the technique of naming check boxes from one or more.
