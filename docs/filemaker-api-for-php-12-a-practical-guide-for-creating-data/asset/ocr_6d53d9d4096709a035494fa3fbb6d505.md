# Lesson 4: Search->Detail

**Objective:** In this lesson you will learn how to create a link for the user to click to view a detail page. The link will send the RecordID to detail page to find the correct record. The purpose of a detail page is to show more information than the search or list page.

**Difficulty:** Medium

Create a simple search form to search the FirstName field pointed to the SearchResults.php.

```
<form action="SearchResults.php" method="get">
First Name: <input name="FirstName" type="text" /><br />
<input name="submit" type="submit" />
</form>
```

Start the PHP code by checking if the FirstName in the URL has a search value. If it is empty all the records. Otherwise use the FirstName in the URL to find the criteria to the $request variable.

```
<?php
if($_GET['FirstName'])
{
$FirstName = "";
$request = $fm->newFindAllCommand('Demo php');
}
else
{$FirstName = $_GET['FirstName'];
$request = $fm->newFindCommand('Demo php');
$request->addFindCriterion('FirstName', $FirstName)
```
