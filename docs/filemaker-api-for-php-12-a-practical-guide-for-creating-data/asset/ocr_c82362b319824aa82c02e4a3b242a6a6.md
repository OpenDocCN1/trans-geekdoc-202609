The user will attempt to log in using the form below that will check the database records for their email
 to start sure the user clicked the Login button and actually provide a value for their
name and password. Since the user name is an email address we have to search the database using
"=" operator because of the "@" wildcard character in the email address. This is the same as you were
searching the database using aMaker Pro client. The other is to consider that the "@" symbol will be
URL encoded as "%40", which means you have to use the PHP urldecode method to decode %40 back to @ to
t correct email address as entered by the user.

```
if(isset($_POST['Login']) && empty($_POST['username']) &&
empty($_POST['password'])) {
	$username = ''.urldecode($_POST['username']);
```

urldecode: Decodes URL-encoded string.
http://us3.php.net/manual/en/function.urldecode.php

If you want to secure your login system you can use the user's password in md5 encrypted format without having to know anything
encryption. You simply apply the md5 method to the password from the Post. For example, if the user enters
1234 the md5 encryption passed to the database will be 81dc9db52d04dc20036dbd8313ed055. That's
encryption easy by PHP!

```
$password = md5($_POST['password']);
```

md5: Calculates the md5 hash of a string.
http://us3.php.net/manual/en/function.urldecode.php
