You will also need to include the two required files. GoogleMap.php contains all the code to connect to the Google Map API. You technically don't need to do anything to this file. However, if you look through it you'll notice that you can configure any feature by changing the value from false to true. Most features are turned on by default in this file. Next is the JSMin.php file. This is all the JavaScript for the class. Finally, create the GoogleMapAPI object noting that it must be created when the page loads or the PHP script displays the map won't work.

Now we can move into the header of the code where the class will power through the Google Map API in just a few lines of code. The code won't run until the user clicks the Submit button. Then you retrieve the coordinates based on the search field. The coordinates are actually returned as an associative array of values. It makes it easy to create the $SearchLat and $SearchLon variables by specifying the values for 'lat' and 'lon'. Don't forget the $Distance value from the field available in the URL. Lastly, the class can also access the API results to validate the address. If the address is not valid it will return an error that you can report back to the user.
