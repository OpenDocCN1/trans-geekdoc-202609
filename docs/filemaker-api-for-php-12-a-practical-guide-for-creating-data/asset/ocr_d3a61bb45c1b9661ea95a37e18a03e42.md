# Introduction

Welcome, and thank you for acquiring FileMaker API for PHP II. A Practical Guide for Creating Database Web Sites with FileMaker Pro 12 and FileMaker Server 12. If you are reading this book I am aware that have been challenged to publish data from your FileMaker database to the web. Many of you have no publishing experience, have experience on other platforms and technologies, and/or are frustrated by the lack of documentation examples, third party products, and rapid application development tools to publishing from a FileMaker database. The FileMaker API for PHP is only available since 2007. Therefore, I assume that you are new to the FileMaker API for PHP II and are seeking resources to assist you to publish your data in an efficient and professional manner.

This book starts by demonstrating basic HTML that you should be familiar with. If you are not familiar with HTML you should seek out a book or online resource to help you understand how to work with basic tables, forms, links, etc. When publishing from a database you will be required to know how to create the pages such as headers, table rows, and table data to display your correctly. If you can master this, you can create a dynamic web page to display your data. I don't want to scare you out. It's actually quite easy. However, anything else it does take practice and precision to know how the page to be displayed.

Section II of the book deals with enabling Apache on OS X or IIS on Windows. Both platforms support PHP. The help you need is that the FileMaker Server installation process will install PHP and turn everything off (for the most part). Your choice is simply to decide which platform you want to host your web site. The most important consideration is to develop a server on which your web site will be hosted, whether that be an in-house server or a third party hosted. Although it's not required, it does make testing and deployment that easier.

Part III covers your FileMaker Server installation. If you are wondering, you need FileMaker Server to host your solution, not FileMaker Server Advanced. That saves you a bit of money. Unfortunately, you can use FileMaker Pro or FileMaker Advanced as a development when accessing the data via PHP. So you will have to break down and develop FileMaker Server.

Part IV, this book covers the use of application development (RAD) tools free text editors. To help you develop your web pages in some type of text editor. The question is how much money you are willing to spend to improve your productivity and extensibility. There are definite advantages to utilizing professional tools.

Part V is where we start to dig. It's iterative that you learn basic PHP. I'm not going to pretend to be an expert PHP developer as there is just too much to learn on everything else. A little bit of knowledge goes as long. In any programming language, you may use 80% of the available methods on a routine basis and you look up the only 20% when you need to use them. This book is going to make you hand code PHP. Yes, I can hear you grumbling. The problem is that there are no complete RAD tools to do everything you need. It's best to learn the hard way the first time, when you use the tools that are available to supplement your work.

Part VI is an overview of the sample database. It does not go into excavating detail about how to create a FileMaker Pro database. I'm assuming that you already know how to do it. The database is very simple. It is used to demonstrate specific techniques for acquiring data from fields, values, lists, portraits, and how to run scripts. It covers every scenario that you would use in a commercial application. I believe it's better to focus on the PHP methods rather than throwing a curve ball at you with unnecessary, complicated database structure or entity. If you have a sample database I can start with you apply the same PHP code for more complicated scenarios.

If you are already comfortable with building a FileMaker database and PHP you can skip right to Part VII. The lessons are broken down into two sections: The Core section is what you will need to understand for any successful web application. The Advanced section is for that— advanced techniques and third-party integration. Once you understand the Core topics you can pick and choose the Advanced topics you will need. The lessons start off specifically for beginners. They demonstrate all the basic techniques to search, display, add, edit, and delete records. They graduate into more complex PHP and FileMaker methods to do things such as display container images, sessions, login routines, running scripts, etc. The main focus of this book is to provide complete, professional, production quality examples.
