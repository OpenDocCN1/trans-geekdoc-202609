# Lesson 11: Delete Portal Record

**Objective:** In this lesson we will learn how to delete related records in the database using a form. The general process is to start by searching for a list of records. Then click a link to the detail page where the related records are shown. Finally, click the link for the related record to isolate it as a single record so it can be deleted from the database. This is the same as deleting an existing related record in a portal in FileMaker Pro, albeit deleting a bit easier.
