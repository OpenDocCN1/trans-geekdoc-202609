The first part of the PHP script makes sure that all the required fields are filled in. If not, it will concatenate
error in the $message variable and the $errors variable to 1, which will allow us to identify any errors
occurred during the script. For this script to run the data must come from a POST with the button = Confirm. That
will keepers from spoofing bogus information.

not valid.
