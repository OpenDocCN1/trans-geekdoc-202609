# Lesson 18: Display Record Pagination

**Objective:** In this lesson you will learn how to enable the user to specify how many records to display per page and how to create record pagination links. It's one thing to display a short list of sample records. It's another thing to display thousands of records on a production server for concurrent users. The more records you display the more taxes the database and the web server. Therefore, you want to limit the number of records that have to be returned from the server to display on each page.
