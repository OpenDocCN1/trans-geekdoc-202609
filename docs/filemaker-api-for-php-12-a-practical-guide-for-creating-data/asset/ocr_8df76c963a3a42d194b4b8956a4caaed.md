+   5. Choose HTTPS for the protocol.
6. Enter the IP address of the host. Do NOT use "localhost". If you are running a single machine it will run much faster if you use 127.0.0.1. Why? Nobody seems to have a definitive answer why Windows can't differentiate between localhost and 127.0.0.1 considering they are the same thing.
7. Enter Port 443.
8. Click the Retry button to re-establish the communication. It should pass at this point.
9. Click the finish button.
10. Restart the server to make sure everything is working.

After restarting the server you can use the test page on the FileMaker Server Admin Console to make sure your web publishing is working with the sample database installed with FileMaker Server. Otherwise you can open your browser and test your web page with your own database.

If the connection does not work you can try uninstalling the web publishing engine from the edit server deployment options. re-install it following the sample procedure above. This solves the problem most of the time. If your next option is to uninstall the web server, uninstall FileMaker Server, re-install, and then try again. If this still does not work, I'm afraid there's something very wrong with your installation and your best is to wipe the hard drive and reinstall the OS. This will be a lot faster than trying to troubleshoot the problem for the next week.

The only other issue I've seen where it was still a problem the FileMaker Web Publishing Engine with IIS Server is Windows Small Business Server (SBS) components were installed on the server. This is a super bad problem. SBS steps all over the ports and registry settings that FileMaker Server needs to communicate with IIS Server. Uninstalling SBS does not solve the problem because the registry settings are permanently changed. Simply uninstalling SBS does not set the registry settings back to the default values, so FileMaker is permanently crashed! The only way to fix this is to wipe the hard drive and reinstall the correct operating system as the FileMaker Server technical specifications.
