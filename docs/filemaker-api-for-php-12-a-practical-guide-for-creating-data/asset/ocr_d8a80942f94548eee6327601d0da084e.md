# PART V — Introduction to PHP

For many of you this is the first time you start to learn PHP. That means your learning curve is going to get very steep, quickly starting now. I'm going to try to make it as easy as possible so that you may learn PHP from the context of using it with FileMaker. I'm also going to demonstrate realistic production examples for the FileMaker API for PHP methods, which has yet to be done, even by FileMaker. If you've not already started by searching the Internet for information about PHP and FileMaker, you've likely found that 99.9% of the information is for PHP with MySQL. The FileMaker API for PHP does not use ODBC or SQL code to connect to the retrieve data. If you can't, it's not the "official supported method from FileMaker". Therefore, we're not going to use these examples. Unfortunately, there are very few good resources on the web for the FileMaker API for PHP. There are less than a dozen pay-for-access articles, most of which the others were Google Integrations. That's not really conducive to learning the FileMaker API for PHP. The only alternative to this learning process is that you'll have to handle code because FileMaker has to provide a plugin for Dreamweaver or any other RAD tool. After many discussions with people at FileMaker, I would suspect that such a plugin will never be created because they don't want to create products for third-party companies' companies — even though Apple does have their robust business relationship with Adobe. That of course, leaves opportunity open for developers to create such a product. In the mean time, let's get started with the resources that are freely available to you.

w3schools

Time to Learn: 1-2 Weeks.
nYou need a PHP base to get started before you can jump into the FileMaker API for PHP. If you don't know some basic PHP syntax and methods you'll be immediately frustrated from FileMaker and I guarantee you will quit within the first hour. I'll tell you how many people I've seen at the developers conference rolling their eyes or getting up and walking out on the presenter because we're not prepared to see basic PHP code. You absolutely have to learn this and there is no way around it. One of the best sources on the Internet that has a complete tutorial to learn PHP is w3schools.com. On their web site you'll learn about what you need to know syntax, variables, strings, operators, if, arrays, looping, functions, and forms. You'll learn to absorb this information. Next, if you are adventurous, you can dig into the advanced section. I would suggest that it would be helpful to at least read the advanced section. However, the examples in this book will be far more useful than the advanced section because they are complete with FileMaker rather than theory. You can skip the PHP Database section unless you want to use PHP and FileMaker with ODBC driver. Lastly, you have additional sections for HTML, CSS, JS, JavaScript, AJAX, and other references to very common PHP methods, which I have found to be very useful. When you're all done with their web site you can also take a quiz to test what you learned. Even better, if you are confident enough you can also take a certification exam.
