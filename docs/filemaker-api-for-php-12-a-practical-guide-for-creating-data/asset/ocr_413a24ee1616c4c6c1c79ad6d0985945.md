# Lesson 13: Display a List Menu Using Two Fields

**Objective:** In this lesson you will learn how to display a list menu (i.e. drop down menu) for use in a form using the two fields method. This lesson will demonstrate each of the four possible types of list values: custom; single field, two fields displaying both values and choosing the first, and two fields showing only the second field.

Use the following code to display a custom value list. This isn't much different than the deprecated method. Store all the objects on the Demo layout in the $layout variable. Store the values of the ValueList value list in the $values variable using the getValueTwoFields method.

```
$layout = $$fm->layout('Demo');
$values = $layout->getValueTwoFields('ValueList');
```

> Maker API Syntax: getValueTwoFields('ValueListName')
$values = $layout->getValueTwoFields('ValueList');

Next, create the html for the value list and loop through each of the values in the $values variable. Finally, echo the list using the $custom variable.

```
$custom = '<select name="ValueList">\nforeach($values as $value) {
  $custom .= '<option value="' . $value . '">' . $value . '</option>';
}
$custom .= '</select>';
```
