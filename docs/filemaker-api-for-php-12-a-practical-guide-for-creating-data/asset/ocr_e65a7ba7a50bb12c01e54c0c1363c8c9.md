# FileMaker API for PHP Examples

Estimated Time to Learn: 1 Week

FileMaker Server/Examples/FMPHP_Sample.fmp2 file, which is the long-standing America 24/7 Collection that has been used for a variety of demonstration projects from FileMaker. It is a simple, single table with a few fields. There is no user's guide that goes along with the PHP files. Therefore, you'll have to pick through the code to figure out what they are trying to accomplish. There are some comments in the code, but it is obviously not the best learning scenario. The examples only cover a few basics such as displaying records, deleting records, and compound finds. Nothing to write home about. I might recommend that you skip these files until you are comfortable with the FileMaker API for PHP methods as there's not enough information to guide you through these files. Plus use the new store container data externally with the getContainerData method instead of the new method! After you read this book, you'll probably be far more proficient with FileMaker and PHP than these examples.
