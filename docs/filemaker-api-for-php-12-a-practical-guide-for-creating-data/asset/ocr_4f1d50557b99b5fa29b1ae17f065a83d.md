We're not quite done with everything that needs be installed. You still need to install and configure FileMaker Server. Once FileMaker Server is installed and configured and you have FileMaker Server install FileMaker PHP you'll be ready to go. Utilize FileMaker Server with PHP you only need FileMaker Server. You do not need FileMaker Server Advanced. The only reason why you need FileMaker Server Advanced is if you want to utilize Instant Web Publishing or access your database with ODBC or JDBC driver. For those of you that are PHP/MySQL programming you are probably used to using an ODBC driver. You can easily access a FileMaker database with PHP and an ODBC driver. The point of this is to cover the supported technology from FileMaker the API for PHP. The API does not need an ODBC driver. There are specific advantages and disadvantages of both methods, which are discussed at the end of the book.
