# Operators

Operators are used for math, to compare values, and to combine values together. The table below shows the common PHP operators.

| Operator | Description | Example |
|---|---|--|
| + | Addition | 2+2=4 |
| - | Subtraction | 5-2=3 |
| * | Multiplication | 5*2=10 |
| / | Division | 10/2=5 |
| % | Modulo Function - returns the remainder | 10%3=1 |
| ++ | Increment + 1 | x=5, x++=6 |
| -- | Decrement - 1 | x=5, x--=4 |
| = | x=y | x=y |
| += | x+=y | x=x+y |
| *= | x*=y | x=x*y |
| /= | x/=y | x=x/y |
| . | x.y | x.y |
| %= | x%=y | x%=y |
| == | Is equal to | 5==6 returns true |
| != | Is not equal | 5!=6 returns true |
| < | Is not equal | 5<6 returns false |
| > | Greater than | 5>6 returns false |
| < | Less | 5<6 returns false |
| >= | Greater than or equal to | 5>=6 returns false |
| <= | Less than or equal to | 5<=5 returns true |
| && | And | 5<10 && 6>10 returns true |
| || | Or | 5<3 || 6>10 returns true |
| ! | Not | !(5==10) returns true |

# If/Else

Using the conditional statement of elseif is no different than a File Pro script. You are choosing to perform different actions based on different conditions. Let's look at some examples, starting with a basic statement. By only using the If statement the result is default to the next section of code.

```
<?php
$date=date("D");
if ($date=="Fri") {
echo "Today is the last day of the work week";
}
?>
```

If you were to use the elseif statement the code will execute the first section of code if the condition is true, otherwise it will default to the else section of code. If you need to execute more than one line of code you will need to enclose the section in curly braces { }

```
<?php
$date=date("D");
if ($date=="Fri") {
```
