# Estimated Time to Learn: As Needed

php.net is the official source for everything PHP, including the application itself. They also have an introductory tutorial. However, it's not as good as w3schools.com. We already installed PHP 5.3 with our installation of FileMaker Server. As of the writing of this book PHP 5.4 is available, which fixes a short list of security issues and bugs. It is out of scope for this book to address upgrading the installation of PHP. After looking through the bug list I found nothing that directly affected the examples in this book. The stock from FileMaker Server will be provided free.

As any documentation from the manual, it has to be desired. Make a lot of assumptions that you are a professional programmer, are very familiar with the command line, and require engineering. In my opinion, they leave out a lot of information, you'll have to resort to digging online forums and other web sites for complete instructions for the average person - or even an expert for that matter. Don't expect to see any screen shots if you are a visual learner. The information is text-based only. That's another reason why I probably better that you use the installation from FileMaker Server. One good thing about the php.net web site is that each of the pages that has instructions allowed for form-type feedback from end users that can post real-world troubleshooting and usage tips. In many cases the responses from the end users are far more useful than the actual instructions from manual. Needless to say, you'll still need to rely on their documentation to learn the PHP methods.
