# EditRecordDetailPortal.php

The last step in this 3-part process is to isolate the related record so it may be updated. Always start by including the connection to database.

```php
include("dbaccess.php");
?>
```

Start the PHP code by checking the form to see if the Save button was clicked. If it was clicked you can tell the $fm object to edit the record using the id passed in the URL. This time we need to use a new layout in the database - Related Data. You can't update the record on the demo page. You need to have a separate layout for the Edit variable. For this example we're only updating the Text field. Lastly, send a message to the user to let them know the record was saved.

```php
if (isset($_POST['save']) && $_POST['save'] == 'Save') {
  $edit = $fm->newEditCommand('Related Data', $_REQUEST['id']);
  $edit->setField('Text', $_POST['Text']);
  $edit->execute();
  $message = '<p>Your changes have been saved.</p>';
}
```

Check to make sure the id is in the URL. If not, stop the script.

```php
if (empty($_REQUEST['id'])) {
  die('The record no longer exists.');
}
```

Find the record based on the id in the URL. Again we're using the layout for related records. Then get the contents of the Text field and store it in the $Text variable. If there were more fields on this layout I would recommend creating the variables with the same names as fields to make code easier.

```php
$record = $fm->getRecordById('Related Data', $_REQUEST['id']);
$Text = $record->getField('Text');
```

Now that we have the contents of the fields from the record stored in variables we can create the HTML and submit form for the page to update the record.


The form points back to the same page using the Post method. This ensures that the information is updated when the page refreshes so the user can make additional changes. It is important to hide this information using the Post method so you can't bookmark the page and update it in the future if the record is deleted. There is also no need for them to see the id for the record or the id value for parent record that are passed as hidden values. The $message variable at the bottom will display the message from the PHP code.

