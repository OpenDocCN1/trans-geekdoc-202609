
# Lesson 23: Boolean Check Box

**Objective:** In this lesson you will learn how to update a record using a check box with a Boolean value of 1. When users fill out forms it is easy to create a Boolean check box to hold the value of 1 for yes with a text description for the check box. You should not use a long description for the check box value. It wastes space in the database and forces you to create too many special value lists. Whereas a Boolean checkbox can be used for more than one field.

**Difficulty:** Easy

The form points back to UpdateBooleanCheckbox.php using the get method. It sends the hidden value for Record ID in the URL. Next, you can use the PHP strcmp method to compare the current value in variable $booleanCheckbox that we created in the PHP code to the value of 1. If the current value in the database is 1 you can echo checked='checked', which is the method to display the check in the box. Finally you can finish the checkbox where we'll match the name of the check box to the database (BooleanCheckbox), type='checkbox' and the value='1' to receive updates from.

```html
<form action="UpdateBooleanCheckbox.php" method="get">
    <input name="id" type="hidden" value="<?php echo $id; ?>">
    <input <?php
    if (strcmp($booleanCheckbox, 1)) {
        echo 'checked="checked"';
    }
    ?> name="BooleanCheckbox" type="checkbox" value="1" />
    <input name="submit" type="submit" value="Submit" />
</form>
</body>
</html>
```

The Update file will be used to update the record with check box value. Always start by including the connection to the database.

```php

include('../../Conn/dbaccess.php');
?>
```

Get the record by the Record ID passed in the URL.

```php
<?php
$record = $fm->getRecordById('Demo', $_REQUEST['id']);
?>
```

Update the record.

```php
<?php
$edit = $fm->newEditCommand('Demo', $_REQUEST['id']);
?>
```

Setting a Boolean check box field is very easy. You will either set it to blank or you will set it to a value of 1. An interesting effect of unchecking the box (not sending any value) is that the BooleanCheckbox name and value will not be passed in the URL. Therefore, you can check to see if the value is empty to determine if you should clear the field or use the value from the URL.

```php
<?php
if (Empty($_REQUEST['BooleanCheckbox'])) {
    $edit->setField('BooleanCheckbox', '');
} else {
    $edit->setField('BooleanCheckbox', $_REQUEST['BooleanCheckbox']);
}
?>
```

Execute the update and trap for errors.

```php
<?php
$edit->execute();
if (FileMaker::isError($edit)) {
    die("Error: " . $edit->getMessage());
} else {
    die("The record was successfully updated.");
}
?>
```

# Lesson 23: Multi Value Check Box

**Objective:** In this lesson you will learn how to update a record using a check box with more than one value. Unfortunately, FileMaker uses its own method for check boxes and PHP knows nothing about the formatting to display a check box from FileMaker. A FileMaker list is a text field with carriage returns between each value. Only the formatting changes depending on the type of check box, radio button, down list, etc. Therefore, to display and insert a multi value check box takes a bit of extra work using PHP.

**Difficulty:** Medium

**Sample Files:**

Check boxes use repetitive code to display the content as HTML. That makes it easy for a database and PHP code to assemble the check box. If the box is checked, you only need to add checked="checked". This example will create the check box that looks like this:

```html
<input name="Checkbox" type="checkbox" value="Red" checked="checked">Red
<input name="Checkbox" type="checkbox" value="White">White
<input name="Checkbox" type="checkbox" value="Blue" checked="checked">Blue
```

Always start by including the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
?>
```

Find all the records and trap for errors.

```php
<?php
$request = $fm->newFindAllCommand('Demo');
$result = $request->execute();
if (FileMaker::isError($result)) {
    echo "<p>Error: " . $result->getMessage() . "</p>";
}
```

For demo purposes we'll only need to use the first record.

```php
<?php
$record = $result->getFirstRecord();
?>
```

Get the RecordID so we can pass it in the URL when we update the record.

```php
<?php
$id = $record->getRecordID();
?>
```

Get the checkbox list from the Demo layout we can create the HTML for the checkbox.

```php
<?php
$layout = $fm->get('Demo');
$checkBoxValues = $layout->getValueList('checkbox');
?>
```

Get the actual values from the record. Then use the PHP method to separate the values into an array using the carriage return ("\n") as the separator.

```php
<?php
$values = $record->getField('Checkbox');
$values = explode("\n", $values);
?>
```

Create the HTML for the checkbox. Use the checkBoxValues from value list to compare against the actual values in the field. If the value is in the array you can check the box. Otherwise the value can be left blank. Use the foreach looping to go through each value list.

```php
$checkbox = '';
foreach($checkBoxValues as $checkBoxValue) {
    if(in_array($checkBoxValue, $values)) {
        $checked = 'checked="checked"';
    } else {
        $checked = '';
    }
}
```

Now that the values are checked you can build the final HTML for the check box. Checkbox[] will appear for each value passed to the URL (Checkbox[]=Red&Checkbox[]=White&Checkbox[]=Blue). Without using [ ] you'd only get the last value - Checkbox[]=Blue.

```php
$checkbox .= '<input name="Checkbox[]" type="checkbox" value=' . $checkBoxValue . ' ' . $checked;
```
