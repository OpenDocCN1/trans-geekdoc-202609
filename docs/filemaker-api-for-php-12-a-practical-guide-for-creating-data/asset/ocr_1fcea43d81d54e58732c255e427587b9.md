Always start by including the connection to the database.

```
<?php
ninclude('../../Conn/dbaccess.php');
?>
```

Get the result using the id value passed in the URL.

```
<?php
$record = $fm->getRecordById("Demo", $_GET['id']);
```

Next, get the related records from the record variable and store them in the $related_records variable.

```
$related_records = $record->getRelatedSet('related_data');
```

Once you have the single parent record and the related records in their variables you can display the results. Start by creating the table header for the related records. I'm storing the html in $table_data variable to make the display easier. The related records will be placed underneath the parent record fields.

Then use the foreach method to create the html for the related records from the $related_records variable.

+   - When you use the getById method with related records you must specify the exact table occurrence name and field name such as related_data::Text.
