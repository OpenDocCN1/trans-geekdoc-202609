# Code:

PreValidate.php

Always start by including the connection to the database.

```
<?php
include("../Conn/dbaccess.php");
?>
```

Find all the records and execute the search.

```
<?php
$request = $fm->newFindAllCommand('Demo php');
$result = $request->execute();
```

Trap for errors.

```
if (Maker::isError($result)){
    echo "<p>Error: " . $result->getMessage() . "</p>";
    exit;
}
```

For this example we will only need to work with the first record.

```
$record = $result->getFirstRecord();
```

Get the Record ID so it can be passed by the URL to the update page to isolate the record.

```
$id = $record->getRecordID();
```

Create variables for the fields with their values from the table so it's easier to create the HTML form.

```
$number = $record->getField('Number');
$date = $record->getField('Date');
$timestamp = $record->getField('Timestamp');
```

Create the form to submit the values to the update page.

```
<html>
<head>
<title>Pre Validate Number</title>
</head>
<body>
<form action="UpdatePreValidate.php" method="get">
<input name="hidden" id="id" value="<?php echo $id; ?>">
nPlease enter a number > 100 to test the pre-validate max characters.
<p>
<input name="Number" type="text" value="<?php echo $number; ?>">
<p>
Please enter an invalid date. (2/31/2010) to test the pre-validate 4 digit year function.
<p>
<input name="Date" type="text" value="<?php echo $date; ?>">
<p>
Please enter an invalid timestamp to test the pre-validate timestamp function.
<p>
<input name="Timestamp" type="text" value="<?php echo $timestamp; ?>">
<p>
<input name="submit" type="submit" value="Submit" />
```
