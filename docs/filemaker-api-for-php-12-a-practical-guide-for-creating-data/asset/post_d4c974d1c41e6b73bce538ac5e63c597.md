## Code: PreValidate.php

Always start by including the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
?>
```

Find all the records and execute the search.

```php
<?php
$request = $fm->newFindAllCommand('Demo php');
$result = $request->execute();
```

Trap for errors.

```php
if (Maker::isError($result)){
    echo "<p>Error: " . $result->getMessage() . "</p>";
    exit;
}
```

For this example we will only need to work with the first record.

```php
$record = $result->getFirstRecord();
```

Get the Record ID so it can be passed by the URL to the update page to isolate the record.

```php
$id = $record->getRecordID();
```

Create variables for the fields with their values from the table so it's easier to create the HTML form.

```php
$number = $record->getField('Number');
$date = $record->getField('Date');
$timestamp = $record->getField('Timestamp');
```

Create the form to submit the values to the update page.

```html
<html>
<head>
<title>Pre Validate Number</title>
</head>
<body>
<form action="UpdatePreValidate.php" method="get">
<input name="hidden" id="id" value="<?php echo $id; ?>">
<p>Please enter a number > 100 to test pre-validate characters.</p>
<input name="Number" type="text" value="<?php echo $number; ?>">
<p>Please enter an invalid date (2/31/2010) to test pre-validate digit year function.</p>
<input name="Date" type="text" value="<?php echo $date; ?>">
<p>Please enter an invalid timestamp to test pre-validate timestamp function.</p>
<input name="Timestamp" type="text" value="<?php echo $timestamp; ?>">
<p><input name="submit" type="submit" value="Submit" />
</form>
</body>
</html>
```

## PreValidate.php / UpdatePreValidate.php

The update form will use the PHP engine to prevalidate the data before it updates the database. Always start by connecting the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
?>
```

Get the record by the id in the URL. Update the fields.

```php
$edit = $fm->newEditCommand('Demo php', $_GET['id']);
$edit->setfield('Number', $_GET['Number']);
$edit->setfield('Date', $_GET['Date']);
$edit->setfield('Timestamp', $_GET['Timestamp']);
```

Use the method to validate the data before it is updated in the database. By not passing any field names the method will validate every field against the database's field settings.

```php
$result = $edit->validate();
```

![](img/5a2c5fda68d42e5d65f51850276e49ec_231_2.png)

Trap for errors and display the results for each error. Errors will be stored in an array with 3 values for each error:

- [0] Field Name
- [1] A number representing the validation error that failed.
- [2] — Number Only
- [3] — Max Characters
- [4] — 4 Digit Year
- [5] — Time of Day
- [6] — Timestamp Field
- [7] — Date Field

The value passed by the numErrors method to return the number of errors from the PHP engine. You can then use the getErrors method to return the actual array of errors.

```php
if(FileMaker::isError($result)) {
    echo ' Validation Failed<p>';
    $numErrors = $result->numErrors();
    echo 'Number of Errors: ' . $numErrors . '<p>';
    $sErrors = $result->getErrors();
```

Use the foreach looping method to display all the results for the errors. Notice that I'm using the exact array value [0], [1], and [2] since there are exactly three values returned in the array for each error. You can think of this as an array of an array, or more technically known as a multidimensional array.

```php
foreach($errors as $error) {
    $field=$error[0];
    echo ' Field Name: ' . $field->getName() . ', Error Code: ' . $error[1] . ', Value: ' . $error[2] . '<p>';
} else {
    $result = $edit->execute();
    die("The record was successfully updated.");
}
```
