Enabling PHP Access in the database is very easy. Simply check the Access via PHP Web Publishing box for the Privilege Set (Figure 6-14). Don't forget that the FileMaker Server Web Publishing settings needs to have the box checked to Enable PHP publishing. That's it. Once the database is hosted on the server you'll be able to access the database via PHP.
