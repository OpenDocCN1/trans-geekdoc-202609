# Lesson 29: Display a Random Banner Ad

**Objective:** In this lesson you will learn how to display a random record from the database. This is useful to display a different banner ad each time a user accesses a web page.

**Difficulty:** Easy

**Sample Files:**
PHPFiles/Advanced/Lesson29/RandomBanner.php
PHPFiles/Advanced/Lesson29/ContainerBridge.php

**FileMaker API Methods:**
newFindAnyCommand()
execute()
getFirstRecord()
getRecordID()
getField()

**Code:**

Always start by including the connection to the database.

```
<?php
include ("../Conn/dbaccess.php");
?>
```

Create a new search transaction to find any records. The newFindAnyCommand will find a random record in the table.

```
<?php
$request = $fm->newFindAnyCommand('Demo php');
```

| FileMaker Syntax: newFindAnyCommand('LayoutName') |
| $request = $fm->newFindAnyCommand('Demo php'); |

Execute the search.

```
$result = $request->execute();
```

Trap for errors.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}
```

Get the result in the $record object by retrieving the first record. I know this might sound like it's redundant because you used newFindAnyCommand, the only way to get the results of a single record is to use getFirstRecord since there is no singular getRecord() method.
