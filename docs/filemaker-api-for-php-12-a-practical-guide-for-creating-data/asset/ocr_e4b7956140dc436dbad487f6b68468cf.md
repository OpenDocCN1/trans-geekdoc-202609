We have to extend the basic function of the pdf class for the header, footer, and the body of the report to make sure they are formatted exactly we want. Starting with a function for the header. Set the header font to Arial, font size 12. Use the Cell function to define the title of the report as "Pizza Restaurants". The options selected will center the title right in the middle of the page. Finally, use the Ln() function to add a new line after the title. Remember, with PDF reports you have to tell the report absolutely everything it needs to know to generate the report, including which line and location to start.

```
class extends PDF
function Header() {
    $this->setFont('Arial','B',12);
    $this->Cell(0,10,'Pizza Restaurants',0,0,'C');
    $this->Ln();
}
```

The footer is similar. To set the footer at 1.5 cm from the bottom of the page. Set the font at Arial, size 8. Output the page number using the Cell function as Page #. The PageNo() generates the current page number (nb) generates the total number of pages. This is all documented in the pdf documentation.

```
function Footer() {
    $this->setY(-15);
    $this->setFont('Arial','8');
    $this->Cell(0,10,'Page '.$this->PageNo().'/nb',0,0,'C');
}
```

You have to test determine exactly how much space to give each column of data in the report. If the data extends the cell it will draw the data in the adjacent cell, which is a problem. Your choices are to either truncate the content, which defines the purpose of the report, or implement the "Table with MultiCells" from FPDF to wrap the cells. For this lesson I'm only trying to get up and running your first PDF report. You can investigate the script on your if you need to utilize it. Nonetheless, you have to define a fixed column width no matter which method you use. Create a simple table by using the column headers as the field names. Finally, I used the Ln() function to add a new line to start the actual data.

```
function BasicTable($records) {
    $this->setFont('Arial','B',11);
    $this->Cell(100,7,'Name',1) . $this->Cell(50,7,'Address',1) . $this->Cell(50,7,'City',1) . $this->Cell(20,7,'State',1);
    $this->Ln();
}
```
