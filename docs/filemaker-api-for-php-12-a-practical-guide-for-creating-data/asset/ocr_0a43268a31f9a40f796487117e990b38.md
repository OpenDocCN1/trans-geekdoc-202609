The save button points back to the same page to ensure that the user can see their data as well as if there is an error during the record being updated by someone else. That way they will see the other changes. The only downfall to multi-record editing is if the user adds a lot of information the changes will be. The upside is that they will have to review the record to make sure when they add changes they don't conflict with the current record.
