Create the form with the button to update the records in the database. The form will point back to the same page using the Post method.

```
<form action="RunScriptUpdate.php method="post" name="Update">
Click the button to run the PHP Modifier Number Field script <br />
<input name="Update" type="submit" value="Update" />
</form>
```

The next section of PHP code will run the script. Start by checking to see if the $_POST superglobal has set for Update and if the user clicked the Update button. Create the variable for the $layout name. The layout does not need to have a script or button attached to it, but you have to run the script based on the context of a layout. The $script variable is the exact name of the script stored in the database. The $parameter is any information you want to pass to this script. This is very similar to using script parameters in FileMaker Pro. You also retrieve parameters using the same method -- Get(ScriptParameter). Finally, put all the variables together using the newPerformScriptCommand and execute the script.

> If you change the name of the script in the database web page will break as changes are not propagated through your web pages

```
if (isset($_POST['Update']) && $_POST['Update'] == 'Update') {
$layout = 'Demo php';
$script = 'PHP Modifier Number Field';
$parameter = '';
$request = $fm->newPerformScriptCommand($layout, $script, $parameter);
$result = $request->execute();
```
