Lastly, you'll need to evaluate exactly which services the host provides on the server. They provide a web server, they provide PHP, ASP, JSP, Instant Web Publishing, WAN access to their database, SSL, etc. Which version of FileMaker do they support? Do you have access to any type of custom configuration of FileMaker Server, Apache, IIS, or PHP-kick FileMaker Server? Do they allow you to open/close, upload/download, and manage your database remotely? FileMaker Server is not like other databases that allow you to do this. You have to do everything through the Admin Console. That means you may either have to wait for the host's administrator to help you and/or they may charge you a fee for their service to deal with your database. Don't expect them to configure a shared server for you. That will require a dedicated or co-located server. Again, when you really get into it, a hosted solution may look good at the beginning for only $250/month. However, in the long run if you are serious and start to use FileMaker Server to host a larger web site and/or more databases for your business operations you need to host the server yourself.
