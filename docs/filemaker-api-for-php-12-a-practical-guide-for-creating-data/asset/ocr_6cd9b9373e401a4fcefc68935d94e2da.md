
If some reason there is no id value in the URL you should alert the user and stop the script. You don't want to update a record that does not exist.

```
if (empty($_REQUEST['id']))
{
die('The record no longer exists.');
}
```

Find the record value passed in the URL. This section will be used to create the form data from the fields. Once you have the record you can get the contents of the fields and store them as variables to make the code easier to read from the form.

```
$record = $php->getRecordById('Demo php', $_REQUEST['id']);
$FirstName = $record->getField('FirstName');
$LastName = $record->getField('LastName');
$Number = $record->getField('Number');
$Date = $record->getField('Date');
$TimeStamp = $record->getField('TimeStamp');
```

Create the form to display the data from the fields. This will allow you to see the data in the fields and update only what they want to change. Note that all of the data from all of the fields in the form will be updated in the database, not just the changes you made. This is the difference between a web application and FileMaker Pro.

```
<html>
<head>
<title>Edit Record -> Detail</title>
</head>
<body>
```

The trick to making the form work is hidden field for the id value of the record. This value will be passed as part of the Post. The PHP code above will use this value to update the correct record in the database. Remember that we stored the contents from the fields as variables above. Therefore you only have to echo the variable for the content. Lastly, I created a $message variable in the PHP code that will alert the user their attempt to update the record was successful or not as a link to the list page where the information will be refreshed.
