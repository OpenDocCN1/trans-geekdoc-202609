5. Follow the wizard to create the certificate file, also known as Certificate Signing Request (CSR). The certificate creates your public/private key pair that will be used to encrypt and decrypt the transactions. Enter the enrolling content for the CSR.

+   a. Organization: use the business legally registered to the domain.

+   b. Organizational Unit: use the department in your company that will use the certificate.

+   c. Common Name: enter the fully qualified domain or URL for which you plan to use for your certificate, such as formulationspro.com. You can also use wildcard domains such as *.formulationspro.com, which will serve all subdomains. However, this typically cost more money. Check with your certificate.

+   d. Country: use the 2-letter ISO code for your country, US for United States of America.

+   e. State/Province: use the full name of your state, such as California.

+   f. City/Location: use the full name of the city where you are located, such as San Diego.

+   6. Click the Next

+   7. In the Cryptographic Service Provider window, select Microsoft RSA Cryptographic Provider with 2048 bit length.

+   8. Enter the path where you want to save the file (i.e. your desktop of folders) and click finish.

+   9. Send the certificate to your Certificate Authority (CA). The company that you will with your SSL certificate (i.e. Verisign, Go Daddy, etc.). Some may want you to request and copy/paste content into their web server for submission.

+   10. They will typically send you a file by your server. Then click the Complete Certificate Link in the Actions window and follow the wizard to install the certificate.

+   11. Choose your site in the Connections window.

+   12. Click the bindings in the Actions window. Your regular HTTP (Port 80) binding should be active.

13. Edit the Port 80 binding and change the host name to your web site (i.e. formulationspro.com). That will tell IIS to listen to any request using that domain for the web site folder.

14. Now click Add to install the SSL binding. Choose hosts for the Type and Port 443. You should be able to choose your newly installed certificate from the pop up menu for the binding.

15. Click save when you are done and your web site should now be enabled to use SSL (i.e. https)
