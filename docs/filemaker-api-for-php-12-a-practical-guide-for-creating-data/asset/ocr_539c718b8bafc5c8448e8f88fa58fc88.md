# Lesson 1: Find All Records

**Objective:** In this lesson you will learn how how to find all the records and display them in a simple table.

**Difficulty:** Easy

**Sample Files:** PHPFiles/Core/Lesson1/FindAllRecords.php

**FileMaker API Methods:**
newFindAllCommand()
execute()
getRecords()
getField()

**Code:**

Any time you need to connect to the database you'll start your php code with the include file for dbaccess.php.

```
<?php
include(\../dbaccess.php\n?>
```

The main section of your php code by creating a new search transaction to find all the records. Create the $result variable to tell the $f object to use the newFindAllCommand() to retrieve the records from the Demo layout. Remember that the $f object was created in the dbaccess.php file which was included in the code that starts every single page.

```
<?php
$result = $f->newFindAllCommand('Demo php\');
```

> FileMaker API Syntax: newFindAllCommand('LayoutName')
$result = $f->newFindAllCommand('Demo php\');

After you make a request to the database you always have to execute it. Create the $result variable to execute the $request. The found set of records will be stored in the $records, which will be used in the code below.

```
$result = $request->execute(\);
```

Any time you execute a request to the database you will need to trap for errors. You can simply copy/paste this generic code after you execute any methods.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . \$result->getMessage(\) . . "</p>>";
exit();
}
```

Next, you need to tell the $result variable to get the records in the found set using the getRecords() method and store them in the $records as an array. Every field that is on the Demo layout will be available in the array. Even though you may have only one record in the found set, you'll want to name the $records variable as plural, which will make more sense below as you loop through the records when they are displayed.
