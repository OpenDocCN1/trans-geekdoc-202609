Concatenation fields, variables, and text together is a basic technique using a FileMaker calculation. FileMaker concatenates two or more items together by using the ampersand "&" symbol. The FileMaker concatenation symbol is the period \.". There's a lesser documented trick that let's you concatenate existing values together using "-". Take a look at the following example:

```
<?php
$firstName = "Todd";
$lastName = "Duell";
$text = "FileMaker API for PHP";

$html = $firstName . " " . $lastName;
$html .= ". says it is fun to learn the ";
$html .= $text;
echo $html;
?>
```
