# Lesson 13: Display a List Menu

**Objective:** In this lesson you will learn how to create a list menu (i.e. drop menu) for use in a form. The list menu will use the SampleValueList in the database.

> Although this method is technically deprecated, it still works. You should use the two field value list method described in the next method.

**Difficulty:** Medium

**Sample Files:** PHPFiles/Advanced/Lesson13/ListMenu.php

**Page Navigation:**

![](img/5a2c5fda68d42e5d65f51850276e49ec_158_0.png)

**FileMaker API Methods:**

- getLayout()
- getValueList()
- AddNewCommand()
- setField()
- execute()
- getMessage()

**Code:**

Always by including the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
?>
```

Start by creating the HTML for the list menu. List menus are repetitive, which makes it quick for a database and PHP. A typical list menu will look like this:

```html
<select name="Number">
<option value="123">123</option>
<option value="456">456</option>
<option value="789">789</option>
</select>
```

Get the objects from the layout where the drop down menu is being used. You have to include drop down menus on the fields in the Demo php layout you want to access them on your web page.

```php
$layout = &$php->getLayout('Demo php');
```

> FileMaker API Syntax: getLayout('LayoutName')
$layout = &$php->getLayout('Demo php');

Once you have the layout objects you can use the getValueList method to retrieve the contents of the SampleValueList stored in the database.

```php
$values = $layout->getValueList('SampleValueList');
```

![](img/5a2c5fda68d42e5d65f51850276e49ec_159_0.png)

Next, we can create the HTML for the value list using the $list_menu so it may be displayed below the form. Use the foreach method to loop through each of the list items to build the HTML.

```php
$list_menu = '<select name="Number">';
foreach ($values as $value) {
$list_menu .= '<option value="' . $value . '">' . $value . '</option>';
}
$list_menu .= '</select>';
```

Next, we can create the PHP code to insert the record into the database. Start by clearing the $message.

```php
$message = '';
```

Check to see if the $_POST superglobal is set. Then determine if the user clicked the Cancel or Save button. If the user clicked the button you can stop and present them with a message that the record was created. Otherwise you can add a new record with all the fields from the form.

```php
if (isset($_POST['insert'])) {
    if ($_POST['insert']=='Cancel') {
        $message = '<p>Record not created.</p>';
    } elseif ($_POST['insert']=='Save') {
        $request = $fm->newCommand('demo php');
        $request->setField('FirstName', $_POST['FirstName']);
        $request->setField('LastName', $_POST['LastName']);
        $request->setField('Number', $_POST['Number']);
        $request->setField('Date', $_POST['Date']);
        $request->execute();
    }
}
```

Trap for errors. Let the user know if the record was created successfully.

```php
if ($result->isError()) {
    $message = '<p>Error: ' . $result->getMessage() . '</p>';
} else {
    $message = '<p>Record created successfully.</p>';
}
```

Create the HTML for the form to submit the record using the Post method. The Number field uses the $list_menu that we created.

```php
    <td>Last Name</td>
    <td><input name="LastName" type="text" id="LastName"</td>
</tr>
<tr>
    <td>Number</td>
    <td><?php echo $list_menu; ?></td>
</tr>
<tr>
    <td>Date</td>
    <td><input name="Date" type="text" id="Date" />
</tr>
</table>
<p>
<input name="insert" type="submit" id="save" value="Save" />
<input name="insert" type="submit" id="cancel" value="Cancel" />
</form>
```
