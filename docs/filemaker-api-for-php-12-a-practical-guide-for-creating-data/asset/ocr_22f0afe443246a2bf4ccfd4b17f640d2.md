OEM technical support if there is a problem. If anything is broken you may have to wait a long, time before it gets fixed.

+   4. Using the JDBC driver is just one more layer of technology to deal with.

+   5. The JDBC driver is not as fast as the FileMaker API for PHP.

+   6. Tomcat has to be installed and configured if you don't use OS X Server.

# IWP

Instant Web Publishing is a great technology that is provided as part of FileMaker Server Advanced. All you have to do is create the database and layouts FileMaker Server Advanced takes care of the rest. However keep in mind that it is not really custom web publishing and it's really suited for very specific scenarios. It is not meant to be used as an every-day solution for a web site with a lot of traffic. It's meant to replicate a FileMaker Pro client, which without training can be confusing to an external user accessing your web site.

Server Operating System: Windows or OS X

Web Server: IIS or Apache

Application Server: None (technically, Tomcat is installed by FileMaker Server Advanced)

Driver: None

Pros:

+   1. No web page creation. FileMaker Server Advanced creates the web pages on the fly.

+   2. Scripts run as expected, with the exception of a few non-compatible script steps.

+   3. User interaction is very similar to a FileMaker Pro client.

+   4. Security runs as expected.

+   5. Runs on either Windows or OS X.

+   6. No special drivers required. Just choose which Web Server you will use when you install FileMaker Server and it "just works".

Cons:

+   1. Limited to 100 concurrent users, including custom web publishing connections.

+   2. Relatively slow for large complex systems.

+   3. Typically requires careful scripting for both FileMaker Pro and IWP clients.

+   4. FileMaker Server Advanced is expensive — $3,000.

+   5. No SSL capabilities.
