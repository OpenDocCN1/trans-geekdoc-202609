# Lesson 12: Upload File

**Objective:** In this lesson you will learn how to upload a file to your server to a defined location, change the file name to match your database, and validate the upload file to ensure that the user uploads the correct file type and size.

Maximum file size is controlled by the settings in the php.ini file Loaded Configuration. By using the phpini() method you can find your stock installation location. On OS X it is at: /Library/FileMaker Server/Web Publishing/publishing-engine/php/snow leopard/lib/php.ini On Windows it is at: C:\Program Files\FileMaker\FileMaker Server\Web Publishing\publishing-engine\php.ini
