
# PART V — Introduction to PHP

For many of you this is the first time you start to learn PHP. That means your learning curve is going to get very steep, quickly starting now. I'm going to try to make it as easy as possible so that you may learn PHP from the context of using it with FileMaker. I'm also going to demonstrate realistic production examples for the FileMaker API for PHP methods, which has yet to be done, even by FileMaker. If you've not already started by searching the Internet for information about PHP and FileMaker, you've likely found that 99.9% of the information is for PHP with MySQL. The FileMaker API for PHP does not use ODBC or SQL code to connect to the retrieve data. If you can't, it's not the "official supported method from FileMaker". Therefore, we're not going to use these examples. Unfortunately, there are very few good resources on the web for the FileMaker API for PHP. There are less than a dozen pay-for-access articles, most of which the others were Google Integrations. That's not really conducive to learning the FileMaker API for PHP. The only alternative to this learning process is that you'll have to handle code because FileMaker has to provide a plugin for Dreamweaver or any other RAD tool. After many discussions with people at FileMaker, I would suspect that such a plugin will never be created because they don't want to create products for third-party companies — even though Apple does have their robust business relationship with Adobe. That of course, leaves opportunity open for developers to create such a product. In the meantime, let's get started with the resources that are freely available to you.

## w3schools

Time to Learn: 1-2 Weeks.

You need a PHP base to get started before you can jump into the FileMaker API for PHP. If you don't know some basic PHP syntax and methods you'll be immediately frustrated from FileMaker and I guarantee you will quit within the first hour. I'll tell you how many people I've seen at the developers conference rolling their eyes or getting up and walking out on the presenter because we're not prepared to see basic PHP code. You absolutely have to learn this and there is no way around it. One of the best sources on the Internet that has a complete tutorial to learn PHP is w3schools.com. On their web site you'll learn about what you need to know syntax, variables, strings, operators, if, arrays, looping, functions, and forms. You'll learn to absorb this information. Next, if you are adventurous, you can dig into the advanced section. I would suggest that it would be helpful to at least read the advanced section. However, the examples in this book will be far more useful than the advanced section because they are complete with FileMaker rather than theory. You can skip the PHP Database section unless you want to use PHP and FileMaker with ODBC driver. Lastly, you have additional sections for HTML, CSS, JS, JavaScript, AJAX, and other references to very common PHP methods, which I have found to be very useful. When you're all done with their web site you can also take a quiz to test what you learned. Even better, if you are confident enough you can also take a certification exam.

## www.php.net

## Estimated Time to Learn: As Needed

php.net is the official source for everything PHP, including the application itself. They also have an introductory tutorial. However, it's not as good as w3schools.com. We already installed PHP 5.3 with our installation of FileMaker Server. As of the writing of this book PHP 5.4 is available, which fixes a short list of security issues and bugs. It is out of scope for this book to address upgrading the installation of PHP. After looking through the bug list I found nothing that directly affected the examples in this book. The stock from FileMaker Server will be provided free.

As any documentation from the manual, it has to be desired. Make a lot of assumptions that you are a professional programmer, are very familiar with the command line, and require engineering. In my opinion, they leave out a lot of information, you'll have to resort to digging online forums and other web sites for complete instructions for the average person - or even an expert for that matter. Don't expect to see any screenshots if you are a visual learner. The information is text-based only. That's another reason why I probably better that you use the installation from FileMaker Server. One good thing about the php.net web site is that each of the pages that has instructions allowed for form-type feedback from end users that can post real-world troubleshooting and usage tips. In many cases the responses from the end users are far more useful than the actual instructions from manual. Needless to say, you'll still need to rely on their documentation to learn the PHP methods.
