Use the foreach loop method to create the HTML table for the related records. Notice the non breaking space inserted as the table data for the right-most column. You need to have this space to display the submit button to the data entry in the very last row.

```
foreach($related_records as $related_record) {
$table_data .= '<tr>';
$table_data .= '<td>' . $related_record->getField('related_data:Text') . '</td>';
$table_data .= '<td>&nbsp;</td>';
$table_data .= '</tr>';
}
```
