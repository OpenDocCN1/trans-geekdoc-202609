The user will attempt to log in using the form below that will check the database records for their email and password. We'll make sure the used Login button and they actually provide a value for their user name and password. Since the user name is an email address we have to search the database using the "=" operator over the "@" wildcard character in the email address. This is the same as if you are searching the database using a FileMaker Pro client. The other issue to consider is that the "@" symbol will be URL encoded as "%40", which means you have to use the PHP urldecode method to decode %40 back to @ to get the correct email address entered by the user.

```
if(isset($_POST['Login']) && empty($_POST['username']))
{
	$password = $_POST['password'];
}
$username = urlldecode($_POST['username']);
```

urldecode: Decodes URL-encode string.
http://us.php.net/manual/en/function.urldecode.php

If you want to secure your login system using the built-in PHP md5 hash algorithm capabilities. That means that you can store the user's password in md5 encrypted format without knowing anything about encryption. You simply apply the md5 method to the password from the Post. For example, if the user enters 1234 the md5 encryption passed to the database will be 81dc9db52d04dc20036dbd8313ed055. That's the encryption made by PHP!

```
$password = md5($_POST['password']);
```

md5: Calculates the md5 hash of a string.
http://us3.php.net/manual/en/function.urldecode.php
