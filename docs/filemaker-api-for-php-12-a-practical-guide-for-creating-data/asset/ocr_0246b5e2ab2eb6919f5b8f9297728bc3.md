# Formulations Pro PHP Site

Estimated Time to Learn: N/A

http://www.formulationspro.com/pages/filemaker/filemaker_login.php

I created an entirely new community dedicated to the understanding and learning the FileMaker API for PHP. The goal of this community is to have consistent, usable documentation for the API. The documentation extends what is currently available from FileMaker and uses actual syntax, useful descriptions and best practices, and real examples of how to use the method. The community will allow everyone to share their comments and sample code with other developers around the world.
