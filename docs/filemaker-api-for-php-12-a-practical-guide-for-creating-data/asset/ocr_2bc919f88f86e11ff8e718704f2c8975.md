**Code:**

One of the things you will notice about this technique is that the form is placed at the end of the code using the Post method. The reason for this is because the form sends the data back to itself using the Post method. I want the php code to run before the form is created on the page to ensure that the message is displayed property. Therefore, the first thing you need to do is set the $message variable to blank so no message is displayed the first time the user accesses the page.

```
<?php
$message = '';
```

Next, only run the script if the insert button was clicked by the user.

```
if (isset($_POST['insert'])) {
```

Check to see if the insert URL value is Cancel. If the user canceled the request update the $message variable to display that the record was not created.

```
if ($_POST['insert']=='Cancel') {
  $message = '<p>Record was not created.</p>';
}
```

If the insert URL value is Save you can run the rest of the php code to insert the record.

```
elseif ($_POST['insert']=='Save') {
}
```

Tell the Fm object to add a new record using the newAddCommand using the Demo php layout.

```
$request = $fm->newAddCommand('Demo php');
```
