# Bind the SSL Certificate to your web site on OS X.

Binding the SSL certificate to your web site on OS X server is very similar to Windows. Although there are far fewer steps.

+   1. Open Server Admin. Click your web server from the list of servers. Then click the Certificates icon.
2. Click the plus + button to Create a Certificate Identity.

![](bbox=[0.105, 0.242, 0.585, 0.625])

Figure 7-80: Create a new certificate identity.

+   3. Enter the name of the domain for your web site.
4. Choose the identity type Self Signed Root. Don't worry, this will change automatically when you install the signed certificate from your Certificate Authority.
5. Choose the certificate type SSL Server.
