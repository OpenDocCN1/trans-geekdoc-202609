```php
if (empty($_GET['id'])) {
```

The next section of code checks is to create a new RelatedData button set from the form. If it was you can tell the $record variable to create a new record using the related_data table and store the results in the $record variable. Next, you can update the Text field with the value passed in the URL from the form. As usual, you will need to commit the request. Finally, you can use the $fm object to get the record by the id value in the URL to display the results with the $record variable.

```php
if(isset($_POST['newRelatedData'])) {
    $record = $record->newRelatedRecord('related_data');
    $record->addField('related_data:Text', $_POST['Text']);
    $result = $record->commit();
    $record = $fm->getRecordByID("Demo php", $_GET['id']);
}
```

Next, all the related records in the $relatedRecords variable create the $table_data variable to store the HTML for the form. This will allow the PHP code to display the results with a new form after the user clicks the Submit button. With a new form the user can submit additional records to the database without having to the list page.

```php
$related_records = $record->getRelatedSet('related_data');
$table_data = '<form action="SearchResultsDetailNewPortal.php?id=' .
$record->getRecordId() . ' method="post">\n';
$table_data .= '<table border="1">
<tr>';
$table_data .= '<th>Text</th>';
$table_data .= '<td>&nbsp;</td>';
$table_data .= '</tr>';
```

Use the foreach loop method to create the HTML table for the related records. Notice the non breaking space inserted as the table data for the right-most column. You need to have this space to display the submit button to the data entry in the very last row.

```php
foreach($related_records as $related_record) {
    $table_data .= '<<tr>';
    $table_data .= '<td>' . $related_record->getField('related_data:Text') . '</td>';
    $table_data .= '<td>&nbsp;</td>';
    $table_data .= '</tr>';
}
```

Finally, create the input Text field, the submit button, and close the HTML for the form. The Text field is left empty so the user can enter a new value. The key of the form is as described above. The name of the button is newRelated. When this button is clicked the form will display correctly on the page of the related records.

```php
$table_data = '<tr>';
$table_data .= '<td><input type="text" name="Text" value=""></td>';
$table_data .= '<td><input type="submit" name="newRelated" value="Submit"></td>';
$table_data .= '</table>';
$table_data = '</form>';
?>
```
