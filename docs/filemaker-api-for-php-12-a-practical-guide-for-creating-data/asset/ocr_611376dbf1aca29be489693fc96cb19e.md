# PART IV — Choosing a RAD tool vs. a Free Text Editor

You need to have a text editor or rapid application development software (RAD) to create your web pages. Please don't try to create web pages with Microsoft Word, Notepad, TextEdit, etc. The question is how much money you want to spend and how do you want to be? In my opinion, something is "free" does not necessarily mean you are going to be able to use it effectively in a commercial development environment. Your loss of time using free software could amount to well in excess of cost to purchase professional software development. Honestly, $400 is not too much if this is your reality, a critical business decision, or if you want tools that make you more productive. The Internet is not "free", but many people believe that it is, and that's another topic of discussion.
With that said, I recommend professional editors like Dreamweaver and BBEdit. Dreamweaver has the latest features and is fully integrated with the Adobe product line. There are hundreds of plugins from third party vendors to extend Dreamweaver. I also like the fact that it has built in coding capabilities for PHP, ASP, JSP, and SQL.

Next comes BBEdit with Bare Bones Software.
Next comes BBEdit with Bare Bones Software. BBEdit has improved significantly over the years. You'll like it for its dedicated simplicity to creating web pages. BBEdit Lite does not exist anymore. It was replaced by the much-needed TextWrangler. TextWrangler is also free. However, you'll notice the lack of integration and design view can make it more challenging to use. Please keep in mind that BBEdit and TextWrangler are for OS only.

If you are looking for a free text editor for Windows you might want to consider Notepad++. It has a number of basic features for creating html code and syncing files with the server. The downfall is that its not necessarily the prettiest the most user-friendly option. Nvu is another option that has around for a long time and has recently been updated to support all OS users (except Lion 10.7) Vu was designed to look and feel like Dreamweaver.

Lastly, if you are interested in PHP development you might want to evaluate Zend Studio. It is relatively expensive Dreamweaver However it does encompass PHP and will work with the Zend Framework PHP to extend PHP. Whereas Dreamweaver is possibly spread a little too thin because it has for so many technologies under one umbrella. Another thing about Zend is that they have a complete Web Application Server for PHP and a Cluster Manager if you need load balancing and scalability. Again, Zend is more professional, paid support and applications go a lot further than "free" applications such as Apache and IIS.
