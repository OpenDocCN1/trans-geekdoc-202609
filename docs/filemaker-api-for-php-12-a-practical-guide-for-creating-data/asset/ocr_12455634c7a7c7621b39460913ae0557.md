# Lesson 12: Display URL Image

**Objective:** In this lesson you will learn how to display an image using a text field with a path to an image.

**Difficulty:** Easy

**Sample Files:** DisplayURLField.php

Page Navigation:

![](bbox=[0.093, 0.235, 0.235, 0.283])

**FileMaker API Methods:**
newFindAddCommand()
execute()
getMessage()
getRecords()
getField()

**Code:**
Always start by including the connection to the database.

```
<?php
include("../Conn/dbaccess.php");
?>
```

This is a simple example that displays all the records from the Demo php layout.

```
$request = $fm->newFindAllCommand('Demo php');
$result = $request->execute();
```

Check for errors.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
texit;
}
```

Get the records and stores the results in the $records array.

```
$records = $result->getRecords();
```

Create the header for the table to display the records.

```
echo '<table border="1">
<tr>
<th>First Name</th>
<th>Last Name</th>
<th>URL</th>
</tr>;
```

Use the foreach looping to create the HTML for all the records in the table. The image attribute comes from the URL text field in the database. The path stored in the database record can either be relative, as /images/myimage.jpg or it can be absolute as http://www.formulationspro.com/images/myimage.jpg. Using a text field with a path to an image and the image stored in a folder on the web server is the preferred method of displaying images.
