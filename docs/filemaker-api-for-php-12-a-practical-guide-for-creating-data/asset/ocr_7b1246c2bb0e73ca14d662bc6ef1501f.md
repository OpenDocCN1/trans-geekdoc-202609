# FileMaker API Syntax: newFindCommand('LayoutName')

```
php
$request = newFindCommand('Demo php');
```

# FileMaker API Syntax: addFindCriterion('FieldName', Value)

```
php
$request = addFindCriterion('FirstName', $FirstName);
```

Execute the find request.

```
$result = $request->execute();
```

Trap for errors.

```
if (FileMaker::isError($result))
    echo "<p>Error: " . $result->getMessage() . "</p>";
    exit;
```

Use the getRecords method to store all the records as an array in the $records variable.

```
$records = $result->getRecords();
```

Create the header for the table to display the records.

```
echo '<table border="1">
<tr>
<th>First Name</th>
<th>Last Name</th>
<th>Number Number</th>
<th>Date</th>
<th>Time Stamp</th>
<th>Calculation</th>
<th>Record ID</th>
</tr>';
```

In the FindAllRecords example, you will create all the html to display the records using the foreach loop and getField($method).

```
foreach ($records as $record)
    echo '<tr>';
    echo '<td>' . $record->getField('FirstName') . '</td>';
    echo '<td>' . $record->getField('LastName') . '</td>';
    echo '<td>' . $record->getField('Number') . '</td>';
    echo '<td>' . $record->getField('Date') . '</td>';
    echo '<td>' . $record->getField('TimeStamp') . '</td>';
    echo '<td>' . $record->getField('Calculation') . '</td>';
    echo '<td>' . $record->getField('RecordID') . '</td>';
    echo '</tr>';
```

Finally, close out the table and PHP code section.

```
echo '</table>';
?>
```
