The **ExpirationDate** field is used to expire the link. The field enters the current date plus 30 days when the record is created. If the customer tries to download the file after the expiration the PHP code will prevent them from downloading the file.

The **IPAddress** field can be utilized to allow only a single user to download the file. This will prevent the user from sharing the link with other people or the link cached on a server engine, rendering your product free to the entirety! One to keep in mind when you are testing that your localhost server's IPv6 address will be returned as ":". That's equivalent to 127.0.0.1 on an IPv4 network. Therefore, it may look a bit strange when you are testing the solution. In the PHP code I added an optional section that you can uncomment to acquire the real IP address of users through a proxy server.

The **DownloadAttempts** field is used to track how many times the user has downloaded the file by clicking the link. You may reset the link if you're thinking outside the box you'll realize that you can also use this file and technique to report usage statistics for your web site.

The **FileName** field is the file user is allowed to download. For this example, use a folder called "downloads" where I store all the files. In a full working model after the customers make the newly created record will look like this file from the product table.
