# Lesson 17: Run a Script — Update Records

**Objective:** In this lesson you will learn how to run a script stored in the database. This is where the power of the FileMaker API for PHP shines well over ASP and JSP. The FileMaker API for PHP is the only technology that allows you to run a script stored in a FileMaker Pro database. When you incorporate running a script with your PHP code you will quickly recognize that you can make very powerful applications. The only drawback is that you are opening up your database to your external users to what might be considered as a pseudo-web service. Therefore, you will need to be extra cautious in what scripts you want to make available to your web site.
