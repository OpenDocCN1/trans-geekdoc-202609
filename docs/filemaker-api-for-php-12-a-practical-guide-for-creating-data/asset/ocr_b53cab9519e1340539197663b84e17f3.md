Localhost vs. Your Production Server

In a professional development environment you typically have a testing server and a production server. The testing server is frequently the same computer as your workstation. This book will assume that you are developing on your workstation that is exactly the same as the production server. When the files are ready to be served to the Internet, you will transfer (i.e. put) to the production server. The notable difference between the two environments comes in the connection file (dbaccess.php) and the URL that you use to access the web pages. This book assumes that you are going to have a single server setup. That means that Apache or IIS, PHP, and FileMaker are all on the same computer.
