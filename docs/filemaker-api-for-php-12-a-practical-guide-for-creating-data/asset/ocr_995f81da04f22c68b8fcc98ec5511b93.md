Objective: In this lesson you will learn how to expire download links. The proliferation of electronically downloaded software, ebooks, music, images, etc. has prompted the need to be able to automate the security of your intellectual property whereby the authorized purchaser is able to download the file. The biggest technical issue that you have to overcome is that you shouldn't reveal the actual URL to the file to the purchaser. If they get to hold of a path to the file they could share with anyone on the Internet, or worse it be caught by multiple search engines. Then your product would quickly become free for everyone. So how you send them a link to a file, without hiding the actual path? Once they have the link can you prevent them from sharing it with someone else? This lesson will show you a very robust method to create a random link that is emailed to the customer. The link will also expire after a predefined number of days, which will be able to prevent downloads from multiple IP addresses, and will limit the number of attempted downloads.

If you're not familiar with this technique is useful I'll point out FileMaker's own software download page. Since FileMaker went completely electronic they had to decide a method to secure their software and license keys and turn them to a disk or place them on a network drive (such as many of our clients) you quite realize that if your customers forget to download their software and license is active for only 30 days. If when you call FileMaker Customer Service they can not only see if the files have been downloaded, but they can reactivate the record for you in a matter of minutes. Now I don't know exactly how they set up their system, but if I would design guarantee that I would not be creating files or a new record in the database. I would simply update the random key and change the expiration date in the record. Then send you a new link via email. I'm sure your system is very similar to this approach.
