# Costs

The Internet has so ubiquitous in our lives that everyone has the perception that it is free. I have some bad news for you. The Internet is not remotely free and creating and hosting websites is much more expensive than for the first time. Keep in mind, the costs 10 years ago were 10 times higher because hardware and bandwidth was really expensive. However, as of today the initial cost to do everything yourself and to host your own server will pay back very quickly when you compare against the long term costs of paying for consultants and hosts. Below is a list of reasonable prices you can expect to pay.

| Item | Cost |
|---|--|
| FileMaker Server | $1000 |
| FileMaker Advanced | $499 |
| Adobe Dreamweaver | $399 |
| Adobe Fireworks | $299 |
| OSX Server (Mac, Xserve) | $999 - $3000 |
| Dell (Windows) Server with 2008 SP 2, Standard Edition | $2000 - $5000 + CALS |
| Apache/IIS | Free |
| PHP | Free |
| Internet Connection (Upload Mbps: 0.768, 1, 2) | $120/month, $200/month, $300/month |
| Static IP Address | $15/month |
| FileMaker Host (4GB Data Transfer, 1 GB Storage, 8 Files) | $250/month+ |

FileMaker Server and FileMaker Pro are required to build your website. FileMaker Server will host your database. FileMaker Advanced is only needed if you use ODBC/JDBC or IWP. FileMaker Advanced is necessary to build the database. Although you can get it with FileMaker Pro, the debugging and viewer tools make much work out of developing, which is worth the extra cost

Adobe: Although you can use one of the free text editors as described earlier in the book, the productivity of Dreamweaver far outweighs the cost. If you are creating your website from scratch you would also need image creation and editing software. Fireworks is specifically designed for the website. I actually prefer it to Photoshop and Illustrator when working on web sites.

OSX Server: If you are hosting your website you will need to buy a server. OSX Server today is relatively inexpensive. Your actual limiting factor is your bandwidth, not hardware capacity or performance. Virtually any inexpensive server is going to have more than enough to power your website. If you want to go to the checkout you can actually use a Mac Mini. They can start for $599 for the best match with IOS Server. It will cost you $199 for the first year. If you want to set up a bit more then you can get it installed with OSX Server for $999. Since the server is only being used for hosting a web site, OSX Server is going to do a better job than Linux-based servers. Applications: The only drawback of the Mac Mini is that it's not server-class hardware. It's not designed to run 24/7 unless you have RAID 5 or 6. However, you can get dual processors and 8 GB RAM, which is plenty of horsepower for most sites. The way I see it, servers have a life life of 3 years. So why not pay 1/3 of the cost and throw it away when it breaks? In reality, Mac Mini's are going to run just for several few years. If you really need the horsepower beating the Mac Pro, you can really go with a Mac Pro instead. Dual NIC cards, 12 cores, 64 GB RAM, 8 TB of storage. Then you don't have to pay a high price for the OSX or CALS with Windows. Since FileMaker server doesn't care what OS you use, you may use whatever the least expensive route takes.

Windows Server: If you are only one site then you are probably well capable of paying for everything. There are no exceptions for servers. In fact, they will cost quite a bit more than the comparable OSX Server. You need to purchase Windows 2008 R2, Standard Edition ($1,029) and CALS (Client Access Licenses) for every internal user that will access the server. The OSX comes with 5 CALS and it will cost you $199 for each additional 5 users. You don't have to pay for CALS for those that access your web site. Why not use Windows Web Server 2008 that only costs $469 with no required CALS? Because FileMaker doesn't support this version. It may work very well, but I'm not going to buy it to find out it's incompatible with FileMaker Server.
