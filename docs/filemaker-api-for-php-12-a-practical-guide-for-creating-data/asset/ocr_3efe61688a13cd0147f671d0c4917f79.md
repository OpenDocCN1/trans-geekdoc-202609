# Event log

Events that occur while the database server is running are logged and timestamped in the tab-delimited Event log
When the Event.log file reaches the specified log size it is renamed Event-old.log and a new
Event.log file is created. To configure the size of the Event.log file, see the Database Server>Logging and Log
Viewer settings. Typical events that are logged include:

+   * Database server starting and stopping.
* Database files opened and closed by the database server.
* Consistency checks performed on files that were not closed properly or have not been opened in a FileMakernproduct.
* New, completed, upcoming, and currently running schedules.
* Pre-defined errors and conditions that the database server detects in your configuration.
* Current properties settings when the database server starts up, as well as settings that are changed during a
dabase server session.

# Access Log

The Database server accesses all databases in a separate file called Access.log. When the file reaches
t specified log size it is renamed Access-old.log and a new Access.log file is created. To configure the size of
t Access.log file, see the Database Server>Logging and Log Viewer settings. Typical events that are logged
include:

+   * Clients that connect and disconnect from the database server.
* Databases that client access with a unique account and have the built-in Guest Account.

# Statistics Log

The database server uses usage statistics in a separate file called Stats.log. The statistics log is relatively
important to monitor the performance of FileMaker Server. Typical statistics that are logged:

+   * Connection Statistics: PHP, FileMaker Pro clients, IWP, xDDB.
* Database statistics: Cache Hit%, Cache Unsaved, Disk Read/Write, Elapsed Time/call, I/O, Network In/Out,
Open Databases, Remote Calls, and Wait Time.

# Web Publishing Log

The Web Publishing engine generates the following log files:

+   * wpc_access_log.txt access is a record of all end-user requests to generate XML and to use IWP. Theequests are routed from the web server directly to the Web Publishing component of the Web
 Publishing Engine.
* pe_internal_log.txt application is a record of all internal XML requests that the XSLT-IWP software
component of the Web Publishing Engine makes while processing XSLT requests. These requests are routed
internally within the Web Publishing Engine from the XSLT-CWP component to the Web Publishing
core component.
* pe_application_log.txt application is a record of the Web Publishing engine error, ScriptMaker script and
user information. The error information describes any unusual Web Publishing Engine errors that have
occurred. The script log describes any errors generated when web users execute scripts. The user log contains messages generated by the XSLT element in XSL style sheets.

# Web Server Module Log

If the web server is unable to connect to the Web Publishing Engine the Web Server Module generates a log file
t is a record of any errors with its operation. The log file is named web_server_module_log.txt and is located
t the machine running the web server.
