**Code:**

The database has fields for the name, address, city, and state. These should be obvious. The MarkerTitle and MarkerDescription fields are used to display a tooltip or call box, respectively, on the map for each location. Next there are fields for the Latitude (Lat) and Longitude (Lon) of the restaurant. The SearchLat, SearchLon, and Distance fields are used by the Store Locator to find the records based on the user-supplied values. The Distance calculation uses the Great Circle Navigation Formula (a.k.a. Haversine formula) to calculate the distance between the user's location and each of the stores. More information about the formula can be found from my article, Map Distance, which is available on our web site at www.formulationspro.com in the FileMaker section or:
