# PHPCalendarDetail.php

Once the calendar is made you will also need to create a day view for the data. You could potentially create a fancy popup with JavaScript. However, this is a PHP-only solution. I'm going to use the PHPCalendarDetail.php page to display the detail information I found in the month view. This page will display the data which link comes from the date, where all records for that day are shown. If the link comes from the individual record page, pay attention to the links created on the page; you'll notice that the NPV strings are slightly different. If you linked from the date, the NPV will include only the RecordID value, which pops up to the month, year, and day. If you linked from a specific record it will only include the RecordID value, which makes values accurate and set specific code codes to be needed.
