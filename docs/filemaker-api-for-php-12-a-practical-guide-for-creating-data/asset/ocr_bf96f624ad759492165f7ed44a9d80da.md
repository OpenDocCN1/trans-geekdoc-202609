$chtt = 'chtt=SalesByRegion' . ' ' . date('m/d/Y') . ' ' . '&';

```

You can display information in a legend in any location on the chart. I might suggest that a legend is not useful if the X axis labels overlap each other. You could also display a table with the data below the chart.

```
$chdl = 'chdl' . '.labels' . ' ' . '&';
$chldp = 'chldp=1' . ' ' . '&';
```

You can define the color of the lines. By default you will receive an orange color. You can specify a single color or custom colors for each bar. I might suggest that the default colors are best because it requires less code and doesn't waste any of the 2K character limit. However, in case I know there will always be three lines, so I've defined a color for each data series.

```
$chco = 'chco' . '0000FF,FF0000,FF0000' . ' ' . '&';
```

Chart and legend margins are kind of cell padding for the charts. The values will force the labels and the chart to scale properly to fit the size of the chart.

```
$chma = 'chma' . '20,20,20|50,50' . ' ' . '&';
```

Finally, you can fill the background of the chart with a custom color, gradient, and even transparency settings. That will give the chart a custom visual appearance.

```
$chf = 'chf' . 'bg,s=EFEFEF' . ' ' . '&';\?
```

There are other optional elements and data functions available. I encourage you to at least look them over to see if they are of any interest to you. I prefer to make my charts simple and to the point so the data sticks out and not necessarily the design.

We'll use an image tag with the source pointed to the Google Chart URL. If for reason your string is more than 2K you can utilize the POST method to retrieve the image. Google has complete instructions for implementing this chart. For now, we'll display the chart using the image tag and PHP code:

```
