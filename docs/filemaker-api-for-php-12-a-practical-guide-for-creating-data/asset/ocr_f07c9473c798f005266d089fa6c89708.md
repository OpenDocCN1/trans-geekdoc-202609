# Lesson 2: Sort Records, Fixed

**Objective:** In this lesson you will learn how to sort records with more than one field and more than one sort parameter.

**Difficulty:** Easy

**Sample Files:** PHPFiles/Core/Lesson2/SortRecordsFixed.php

**Code:**

Always start by including the connection to the database.

```
<?php
include("../Conn/dbaccess.php"
```

Create the $request variable to instantiate the $fm object to find all the records from the Demo page layout.

```
<?php
$request = $fm->newFindAllCommand('Demo php');
```

You can add many sort rules as you want. Have the $request variable use the addSortRule to sort by the FirstName then the Date field. Notice the precedence order is specified as FirstName (1) then Date (2). This is the same concept as the sort order dialog box in FileMaker Pro. The sort order is always as FILEMAKER_SORT_ASCEND by default, so you don't have to declare it. If you want to sort the field in descending order you to declare FILEMAKER_SORT_DESCEND.

```
$request->addSortRule('FirstName', 1);
$request->addSortRule('Date', 2, FILEMAKER_SORT_DESCEND);
```

Trap for errors.

```
if (FileMaker::isError($result))
{
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}
```

Use the getRecords method to store all the records as an array in the $records variable.

```
$records = $result->getRecords();
```
