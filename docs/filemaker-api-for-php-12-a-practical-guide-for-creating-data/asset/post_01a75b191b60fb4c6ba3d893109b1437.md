# FileMaker API PHP Reference

One of the reasons why I wrote this book is for long time the only reference material available to use the FileMaker API for PHP was the electronic documentation supplied with FileMaker Server. Of course, this information is absolutely useless as a starting point to use the FileMaker API for PHP methods. However, now that you go through all the examples in this book you may find this reference material useful. The electronic documentation references from 19 different points of view (i.e. Classes). Methods will only work with specific Classes and some methods work with more than one. For example, you will never tell the fm object (FileMaker Class) to use the methodFields. The FileMaker Class is not designed to retrieve the contents of a file. The FileMaker class is designed to retrieve database properties, connect to the database, and get information about the API. If you need to get information from the file you'll find that using the FileMaker_Layout Class is the best way. You don't actually code on your PHP pages, you code the methods about what Classes means. Classes are a simple way to logically organize the methods and what FileMaker API for PHP can perform. The most important thing you need to know, other than to code the syntax of the method, is what the method will return to you. There are nine different values the Methods can return:

- Array: One or more fields that you can use to display information.
- Boolean: TRUE or FALSE that you can use for trapping errors.
- Integer: a number such as the record count.
- String: Text, such as the contents of a file.
- Void: Nothing, for methods that do not return any results.
- FileMaker_Record: Returns an object that contains an array of information about the record.
- FileMaker_Result: Returns an object that contains an array of information about the result.
- FileMaker_Layout: Returns an object that contains an array of information about the layout.
- FileMaker_Command: Returns an object that acts on a specified method or record set of records.

The reference material will only list the methods once with the syntax and the expected value that it will return. The column lists the first file where method was used in this book. Many of the methods are used in multiple examples. If you need more detailed information then you can find the reference documentation located at:
