# Lesson 31: Duplicate Related Records

**Objective:** In this lesson you will learn how to duplicate the parent and related records. Just like a FileMaker client, duplicating a parent record does not mean that the related records are duplicated. You have to script the entire process to duplicate the related records.

**Difficulty:** Medium

Sample Files:

DuplicateRelatedList.php
TheDuplicateRelatedList page is used to display all the records and provide a link to the detail page so you can isolate the record you want to duplicate. Always start by including the connection to the database.

```
<?php
include("../dbaccess.php");
?>
```

Create a list of all the records.

```
<?php
$request = $fm->newFindAllCommand('Demo php');
$result = $request->execute();
```

Trap for errors.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}
```

Get the records.

```
$records = $result->getRecords();
```

Create the table header to display the records.

```
echo '<table border="1">';
```
