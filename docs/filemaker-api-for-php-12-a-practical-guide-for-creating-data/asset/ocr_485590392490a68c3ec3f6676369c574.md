# Driver: ODBC

Pros:

+   1. Allows you to use standard SQL commands to access the database. This is a very traditional approach that many people are comfortable using.
2. Dreamweaver has built in support for ODBC, and SQL. You would be using the ASP settings.
3. FileMaker provides the ODBC drivers for free.
4. You can utilize a lot of the ASP materials and third party products.
5. IIS Server comes with Windows Server and a nice user interface to configure the server.
6. We have complete instructions to use ASP on our web site at www.formulationspro.com.

Cons:

+   1. You cannot run scripts with the ODBC driver.
2. You cannot display images from a container field using the ODBC driver.
3. Installing the ODBC driver can be a hassle.
4. The ODBC driver can be a major technical issue in the long run when you upgrade the OS or FileMaker Server. FileMaker has switched xBC driver manufacturers several times and is not capable of providing OEM technical support if there is a problem. If is broken you may have to wait a long, long time before it feels fixed.
5. Using ODBC driver is just one more layer of technology to deal with.
6. The ODBC driver is not as fast as the FileMaker API for PHP.
7. I have not been successful at using ASP-NET to work with FileMaker Server or the supplied ODBC drivers.
8. The Windows software and CALS are not free. Using Windows will be a more expensive approach.

# JSP

Java Pages is a Sun technology, recently taken by ORACLE, that runs using the Tomcat server. In many cases users have their html pages processed by Apache and their jsp pages processed by Tomcat to optimize performance. JSP technology has been available for a long time and has a strong following on the Internet. The only real issue you may run into is the lack of professional resources and products compared to ASP and PHP.

Server Operating System: Windows or OS X

Web Server: Apache or Tomcat

Application Server: Tomcat

6. OS Server comes pre-installed and configured with both Apache and Tomcat.
7. The JDBC driver uses a connection string in your web site (similar to the dbaccess.php connection string for PHP) rather than driver manager, which makes it far easier and less problematic.
