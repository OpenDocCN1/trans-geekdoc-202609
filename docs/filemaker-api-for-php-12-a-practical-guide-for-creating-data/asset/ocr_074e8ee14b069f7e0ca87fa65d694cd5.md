# Lesson 46: Validate Credit Cards

**Objective:** In this lesson you will learn how to validate credit card data without a gateway. If you plan a shopping cart you will need to know how to validate the credit card data. Sure you can rely on your gateway to respond with pass or fail. However that would mean you will need to tax your server and/or load the database with junk records. You are much better off validating the card type, prefix, length and Luhn function by submitting to credit card to your gateway to receive your funds. This lesson will show you how to implement credit card validation with a production quality validation function that's portable to any solution.

**Code:**

The ValidateCC.php page contains the form that submits the credit card data back to itself for validation. Always start by including the connection to the database.

ValidateCC.php

```
<html>
<head>
<title>Validate Credit Card</title>
</head>
<body>
<php>
// Connect to the database
require_once ('FileMaker.php');
$fm = new FileMaker(1);
$fm->setProperty('database', 'ValidateCC');
$fm->setProperty('hostspec', 'http://127.0.0.1');
$fm->setProperty('username', 'Admin');
$fm->setProperty('password', '1234');
?>
```

Next, include the validate_cc.php page, which will be used to validate the credit card number and reset. Set themessage variable, which will be used to display an error message to the user if they enter invalid information.
