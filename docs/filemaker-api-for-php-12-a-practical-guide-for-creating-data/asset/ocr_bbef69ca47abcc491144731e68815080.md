For this lesson I'm simply going to find all the records in the database. Then store the results in the data format required by the Google API. The data (i.e. Number field) from each record needs to be formatted with commas, such as 1,2,3. The labels (i.e. Region field) from each record needs to be formatted with the pipe character, such as USA|Canada|Mexico. These formats need to be exact or the chart will return an error. The extra piece of information you'll need from the records is the sum of all the data to scale the pie chart with the correct proportions. All pie chart should be normalized to 100. I find that without scaling the pie chart it would be impossible to make this chart look right, rather than an optimal one.

# Required Elements

The goal is to build a URL for an image tag. The base URL googleapis.com/chart is:

https://chart.googleapis.com/chart?

From here we add all the name-value pairs (NVPs) separated by &amp;, which is the URL encoded value for &. & &amp;?. Because we will be embedding the chart URL in the web page as an image source. To obtain the correct URL string special characters need to be URL encoded. Also includes encoding any values in the database that might cause problems with the string. Rather than make a heavy string of values I decided to define the required and optional variables in the PHP code. Then assemble the final URL string in an easy order to read and modify format. The NVPs can be assembled in any order. However, I prefer the order of required, and random ID number. Let's start with the required N's.

Define the chart type variable. I chose the two-dimensional chart for the demo.
