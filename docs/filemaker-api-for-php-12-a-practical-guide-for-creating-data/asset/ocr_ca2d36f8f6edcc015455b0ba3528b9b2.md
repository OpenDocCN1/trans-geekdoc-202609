# # Web Viewer

The web viewer included in the php_demo.mp12 sample file is for demonstration purposes. The web viewer works in conjunction with the upload examples. The purpose of the web viewer is to enable FileMaker Pro clients the opportunity to upload images and files using the web viewer rather than needing to have security access through the network to the directory on the server where the files are stored. It also renames the uploaded files to work correctly with the database, rather than relying on the users to name the files properly when they transfer them to the server. This is more efficient for users that access the database via a FileMaker Pro client. I always recommend your in-house end users and administrators use a FileMaker Pro client to update the database rather than creating a single PHP and and more cost effective if you'll probably have few people that update your web site's database. Therefore, the cost of a few FileMaker clients for administrators is going to be far less than the cost to build the administrative end of the web site.
