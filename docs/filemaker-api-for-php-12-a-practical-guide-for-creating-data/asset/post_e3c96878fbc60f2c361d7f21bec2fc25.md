validate_cc.php

The validate_cc.php file contains 2 main functions and a third that combines the results to determine the overall result. The first function, validate_number_type, determines the card type, number of digits, and any prefix values match the supplied credit card number and type. If the card passes the function returns the value of 1. If not, the function returns a value of 0. This will be important at the end of this day. The code below only works for VISA, MASTERCARD, AMEX, and DISCOVER. If you need to validate additional cards you might find more information at:

http://en.wikipedia.org/wiki/Credit_card_number.

```php
<?php
function validate_number_type($ccnum, $type = 'UNKNOWN')
{
    // Clean up input
    // Make sure this is all UPPERCASE to match the code below
    $type = strtolower($type);
    // Remove everything except numbers
    $ccnum = preg_replace('/\D/', '', $ccnum);

    // Do basic validation for type specific credit cards
    // Skip UNKNOWN
    if ($type == 'UNKNOWN')
    {
        return 1;
    }

    // Mastercard: 16 digits, prefix of 51-55
    elseif ($type == 'MASTERCARD')
    {
        echo 'MC';
        return (strlen($ccnum) != 16 || !strpos('5[1-5]', $ccnum)) ? 0 : 1;
    }

    // Visa: 13 or 16 digits, prefix is 4
    elseif ($type == 'VISA')
    {
        echo 'VISA';
        return (strlen($ccnum) != 16 || substr($ccnum, 0, 1) != '4') ? 0 : 1;
    }

    // AMEX: 15 digits, prefix of 34 or 37
    elseif ($type == 'AMEX')
    {
        echo 'AMEX';
        return (strlen($ccnum) != 15 || !strpos('3[47]', $ccnum)) ? 0 : 1;
    }

    // Discover: 16 digits, prefix of 6011
    elseif ($type == 'DISCOVER')
    {
        echo 'DISC';
        return (strlen($ccnum) != 16 || substr($ccnum, 0, 4) != '6011') ? 0 : 1;
    }
    else
    // Default: unknown type
    return -1;
}
```

The second function in this file is the Luhn algorithm. It uses the Modulo function to create a checksum that verifies the actual card number is valid. It does not validate if the card has sufficient funds. The code below:

```php
function luhn_check($ccnum) {
    // Remove everything except numbers
    $ccnum = preg_replace('/\D/', '', $ccnum);

    // Set the length and parity
    $number_length = strlen($ccnum);
    $parity = $number_length % 2;

    // Loop through each digit and do the math
    $total = 0;
    for($i=0; $i<$number_length; $i++) {
        $digit = $ccnum[$i];
        // Multiply alternate digits by two
        if ($i % 2 == $parity) {
            $digit *= 2;
            // If the sum is two digits, add them together (in effect)
            if ($digit > 9) {
                $digit -= 9;
            }
        }
        // Total up the digits
        $total += $digit;
    }

    // If the total mod 10 equals 0, the number is valid
    return ($total % 10 == 0) ? 1 : 0;
}
```

Finally, the validate_cc function pulls both the values from the above functions. If both pass they will supply a value of 1 for a total of 1+1=2. That's Validate.php page was checking for a value of 2. If one or either fails the maximum value they can return 1. I'm assuming a value of 1 or 0 is returned the credit card number has failed. I don't care how it failed. I just know that something is wrong and will stop the user before the data is inserted into the database.

```php
function validate_cc($ccnum, $type = 'UNKNOWN') {
    $validate_number_type = validate_number_type($ccnum, $type);
    $luhn_check = luhn_check($ccnum);
    return $validate_number_type + $luhn_check;
}
```
