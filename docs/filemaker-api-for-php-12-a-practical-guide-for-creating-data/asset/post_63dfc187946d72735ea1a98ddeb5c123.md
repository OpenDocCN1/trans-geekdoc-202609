# Lesson 20: Multi User Process to Edit Records

**Objective:** In this lesson you will learn how to update records in a multi-user environment. Web pages are stateless, which means the connection to the server is not constant like the FileMaker Pro and FileMaker Server client-server connection. Therefore, record locking does not exist when two or more people are updating the same record. This means that you need to manage the update process to check for changes made by other users before the update is submitted to the server.
