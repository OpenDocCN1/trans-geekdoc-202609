Once the checkbox values are assembled in FileMaker format we can set the field. Don't forget to check if the there are no values in the URL. If there are no values you can clear the field.

```
If(Empty($_GET ['Checkbox'])) {
  $edit->setField('Checkbox', "");
} else {
  $edit->setField('Checkbox', $checkBox);
}
```

Execute the update and track for errors before giving the user feedback.

```
$result = $edit->execute();
if (FileMaker::isError($result)) {
  die("Error: " . $result->getMessage());
} else {
  die("The record was successfully updated.");
}
```
