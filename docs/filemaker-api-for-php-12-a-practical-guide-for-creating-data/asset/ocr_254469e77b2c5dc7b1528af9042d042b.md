# Looping

Looping will execute a section of code for a specified number of times. FileMaker script has looping
capabilities. PHP looping is easier to perform because it has more logical choices in terms of how many
times it will run and when the loop will end. There are four basic looping mechanisms: while, do...while, for and
foreach. While loops through a section of code where the condition is true. Do...while loops through a section
as long as the code is true. For loops through a specific number of times. For is by far
t most common that you'll encounter when extracting data from an array of record from the database. It
ill through the code for each element in the array. It's very similar to the FileMaker script step Go to Next
Record [Exit After Last]. You don't have to tell it to stop. It knows to stop after the last element in the array.

The while loop below will run as long as the counter is less than 5. The counter will increase by 1 for each loop.
This is very similar to a mechanism you might use a FileMaker script with a counter to execute a loop.

```
<?php
$counter=1;
while($counter<=5){
    echo "Number " . $counter . "<br>";
    $counter++;
}
?>
```

The do...while loop is similar to the while loop. The difference is how you arrange the order of the methods in the
code may vary to accommodate the logic and the exit condition is always at the end of the code.

```
<?php
$counter=1;
do {
    echo "Number " . $counter . "<br>";
    $counter++;
} while($counter<=5);
?>
```

The for loop is used when you know exactly how many times the loop should execute — for(Counter Initialization,
Exit Condition, Counter Increment). Counter Initialization is usually used to start a counter. Exit Condition is
evaluated for each loop. If the condition is true, the loop continues. If the condition is false, the loop stops.
Counter Increment is used to increment the counter. The example below achieves exactly the same results as the
