# Lesson 26: Perform Compound Search

**Objective:** In this lesson you will learn how to perform a compound "and" search with two or more fields and operators. All the search fields are required for the search to work correctly. However, this example can be modified to check for fields with empty values so the PHP engine doesn't return an error.

**Difficulty:** Medium

Create a form to allow the user to search by the fields: FirstName, LastName, Number, and MultiValueList. For this example we'll point the form back to the same page. We'll add some text to the user know that all the fields are required.

```
<form action="CompoundSearch.php" method="get">
First Name*: <input name="FirstName" type="text" />
<br />
OR LastName*: <input name="LastName" type="text" />
<br />
OR Number*: <input name="Number" type="text" />
<br />
OR Per (OMIT)*: <input name="MultiValueList" type="text" />
<br />
*: All values are required for the search
<br />
<input name="submit" type="submit" />
</form>
```
