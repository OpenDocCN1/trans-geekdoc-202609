5. Enter a user name for FileMaker Server. It can be anything. I usually use something like FMS 12–1 for FileMaker Server 12, server number 1.

6. Enter the Organization name, which needs to be spelled EXACTLY the same as on your license key. That includes upper and lower case characters, as it is case sensitive.

7. Enter the license key supplied by FileMaker.

8. Click Install. The installation process will take several minutes.
