# MultiUserEditRecord.php

When the record is loaded we can obtain the Modification ID value from the record. When the user clicks the Save button it will try to update the Modification ID value with the current number obtained by the page. If the number is the same the record will be allowed to be updated. If the number is not the same FileMaker will throw an error because the Modification ID number cannot be modified.

The PHP code by clearing the message variable. IIS Server does not to display undefined variables. Then check if the save button is set and has been clicked. If has try to edit the record with all the fields.

```
<?php
include("../Config/dbaccess.php");
```

```
<?php
$message = '';

if (isset($_REQUEST['save']) && $_REQUEST['save'] == 'Save') {
	$edit = $fm->newEditRecord(['Demo php', $_REQUEST['id']);
	$edit->setField('FirstName', $_REQUEST['FirstName']);
	$edit->setField('LastName', $_REQUEST['LastName']);
	$edit->setField('Number', $_REQUEST['Number']);
	$edit->setField('Date', $_REQUEST['date']);
	$edit->setField('Timestamp', $_REQUEST['Timestamp']);
}
```

Before you request to update the records using the FileMaker method setModificationID to set the Modification ID value. The value is passed in the URL as modID. Then execute the request.

```
$edit->setModificationID($_REQUEST['modID']);
$result = $edit->execute();
```
