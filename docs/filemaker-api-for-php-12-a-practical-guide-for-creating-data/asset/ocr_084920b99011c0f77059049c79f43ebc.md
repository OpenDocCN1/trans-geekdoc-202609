Next, we can get the found count from the search using the getFoundCount method. If there is only 1 record in the found count we can change the login $_SESSION superglobal to "1" and redirect the user to the protected success page using the php header method. Note that we are assuming that the user only has a single record based on their email address and password. That means when the user signs up for your site web we will check the database for existing records to prevent them from creating more than one record.

```
$found = $result->getFoundCount();
if($found == 1)
{
  $_SESSION['login'] =1;
  header("location:LoginSuccess.php");
  exit;
}
else
```

If there are no records or more than one record in the database you should immediately log out the user by changing the $_SESSION superglobal to "0" and provide the user with a message. I recommend that the message be very generic so they can't figure out if they have either the email address or password correct. This will limit the effort of people trying to break into your system.

```
$_SESSION['login']=0;
$message = 'Incorrect user name or password.';
}
```
