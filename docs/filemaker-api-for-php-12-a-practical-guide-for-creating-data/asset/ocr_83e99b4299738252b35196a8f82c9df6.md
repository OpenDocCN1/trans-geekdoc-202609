# Lesson 42: Submit Multi Page Forms

Objective: In this lesson you will learn how to submit multi page forms to the database. Forms are an integral part of web sites when communicating with a database. In some cases a single form may contain too much information to display on one page without scrolling. Therefore, it may be better to group information more logically into individual pages. A perfect example of a multi page form is when you purchase an item and provide your credit card information, finally on the last page you confirm your order. If you've never worked with multi page forms before you're probably thinking that each page represents a separate submission to the database. The reality is that each page passes its fields and data to the next page and stores the information as hidden fields in the form. Only on a couple of PHP code inside the form. The entire process takes a couple of lines of PHP code inside the form.

# Code:

This lesson consists of a three-page process. The first page is where a customer would fill in their "bill to" information. The next page is where the customer would fill in their "ship to" information. The last page is a confirmation page where the customer would review their order and submit the request. This is a simplified example. The point isn't to demonstrate every possible field and workflow scenario. We'll be focusing on the PHP code to create the hidden fields that get passed between the pages.

page1.php

The first page in the process is the simplest. It is a form that sends a POST with all the bill fields to the page — page2.php.

```
<form action="page2.php" method="post" id="form">
```
