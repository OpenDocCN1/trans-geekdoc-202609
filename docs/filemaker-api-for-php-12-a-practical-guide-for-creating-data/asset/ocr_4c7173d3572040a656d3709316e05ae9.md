This script runs completely different on FileMaker Server vs. a FileMaker Pro client. Be sure to test this script only from the example web page or from a FileMaker Server Schedule.

To get a listing of the documents in the FileMaker Server Documents folder you can use Get(DocumentsPathListing). To get the dynamic path to the Documents folder you can use Get(DocumentsPath). Be aware, there are two folders in FileMaker Server called "Documents" the correct folder is located at FileMaker Server/Data/Documents. You will also need to change the file permission for the Documents folder to enable everyone = Read/Write. Then apply it to all the files in the folder. If you don't do this step FileMaker cannot import the records from the xls file because it won't be able to open the file to read the records.
