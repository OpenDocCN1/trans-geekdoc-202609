## Lesson 3: Search Records, Compound

**Objective:** In this lesson you will learn how to search for records based on two or more field using a form.

**Difficulty:** Easy

Sample Files: PHPFiles/Lesson3/SearchRecordsCompound.php

Page Navigation:

![](img/5a2c5fda68d42e5d65f51850276e49ec_97_0.png)

**FileMaker API Methods:**
- FindAllCommand()
- newFindCommand()
- addFindCriterion()
- execute()
- getMessage()
- getRecords()
- getField()

**Code:**

Always start by including the connection to the database.

```php
<?php
include ("Conn/dbaccess.php");
?>
```

Create the search form for the file SearchRecordsCompound.php to search by the fields FirstName and LastName. This form will act as both the search and the display for the found set of records. The form uses the Get method, which means the search string will be viewable in the URL for the user. The input names FirstName and LastName will be passed in the URL. I prefer to use the actual names of the fields to make it easier to read the URL. The values will be what the user types into:

```html
<form action="SearchRecordsCompound.php" method="get">
First Name: <input name="FirstName" type="text" /><br>
Last Name: <input name="LastName" type="text" /><br>
<input name="submit" type="submit" />
</form>
```

Start the code by checking the $GET superglobal for the FirstName and LastName value. If both are empty the $request variable to find all the records in the Demo php layout. Otherwise, use the $GET superglobal to retrieve the FirstName and LastName values from the URL. Then tell the $fm object to add a new field command to the $request variable adding the criteria using the contents from the FirstName and $LastName variables.

```php
<?php
if(empty($_GET['FirstName']) && empty($_GET['LastName'])) {
$FirstName = "";
$LastName = "";
$request = $fm->newFindAllCommand('Demo php');
} else {
$FirstName = $_GET['FirstName'];
$LastName = $_GET['LastName'];
$request = $fm->newFindCommand('Demo php');
$request->addFindCriterion('FirstName', $FirstName);
$request->addFindCriterion('LastName', $LastName);
}

Execute the find request.

$result = $request->execute();

Trap for errors.

```php
if (FileMaker::isError($result)) {
    echo "<Error: " . $result->getMessage() . "</p>";
}
```

Use the getRecords method to store all the records as an array in $records variable.

$records = $result->getRecords();

Create the header for the table to display the records.

```php
echo "<table border='1'>
<tr>
<th>First Name</th>
<th>Last Name</th>
<th>Number Number</th>
<th>Date</th>
<th>Time Stamp</th>
<th>Calculation</th>
<th>Record ID</th>
</tr>";
```

As in the FindAllRecords example, you'll create all the html to display the records using the foreach loop and getField($method).

```php
foreach ($records as $record) {
    echo '<tr>';
    echo '<td>' . $record->getField('FirstName') . '</</td>';
    echo '<td>' . $record->getField('LastName') . '</</td>';
    echo '<td>' . $record->getField('Number') . '</</td>';
    echo '<td>' . $record->getField('Date') . '</</td>>';
    echo '<td>' . $record->getField('Timestamp') . '</</td>>';
    echo '<td>' . $record->getField('Calculation') . '</</td>>';
    echo '<td>' . $record->getField('RecordID') . '</</td>>';
    echo '</tr>';
}
```

Finally, close the table and PHP code section.

```php
echo '</table>';
?>
```

## Lesson 4: Search Detail

**Objective:** In this lesson you will learn how to create a link for the user to click to view detail page. The link will send the RecordID to detail page. The purpose of a detail page is to show more than the search page.

**Difficulty:** Medium

**Sample Files:**
- PHPFiles/Core/SearchResults.php
- PHPFiles/Core/SearchResultsDetail.php

**Page Navigation:**

![](img/5a2c5fda68d42e5d65f51850276e49ec_100_0.png)

**FileMaker API Methods:**
- newFindCommand()
- findCommand()
- addFindCriterion()
- execute()
- getMessage()
- getRecords()
- getField()
- getRecordID()

**Code:**

SearchResults.php

Always start by including the connection to the database.

```php
<?php
include("../Conn/dbaccess.php");
?>
```

Create a simple search form to search the FirstName field pointed to SearchResults.php.

```html
<form action="SearchResults.php" method="get">
First Name: <input name="FirstName" type="text" /><br>
<input name="submit" type="submit" />
</form>
```

Start the PHP code by checking if the FirstName in the URL has a value. If it is empty all the records. Otherwise use the FirstName in the URL to find the criteria to the $request variable.

```php
<?php
if(empty($_GET['FirstName'])) {
$FirstName = "";
$request = $fm->newFindAllCommand('Demo php');
} else {
$FirstName = $_GET['FirstName'];
$request = $fm->newFindCommand('Demo php');
}
$request->addFindCriterion('FirstName', $FirstName);
```

Execute the search request.

```php
$result = $request->execute();
```

Trap for errors.

```php
if (FileMaker::isError($result)) {
    echo "<Error: " . $result->getMessage() . "</p>";
    exit;
}
```

Get the records as an array in $records variable.

```php
$records = $result->getRecords();
```

Create the header to display the records.

```php
echo '<table border="1">
<tr>
<th>First Name</th>
<th>Last Name</th>
<th>Number Number</th>
<th>Date</th>
<th>Time Stamp</th>
<th>Calculation</th>
<th>Record ID</th>
<th>View Detail</th>
</tr>';
```

Loop through all the records using the fetch method. Display the contents from the fields using the getField method. The last column contains the view link to the detail page. When the user clicks the link it will open the detail page and pass the name as "id" and the value as the RecordID from the record using the method getRecordID.

```php
foreach ($records as $record) {
    echo '<tr>';
    echo '<td>' . $record->getField('FirstName') . '</td>';
    echo '<td>' . $record->getField('LastName') . '</td>';
    echo '<td>' . $record->getField('Number') . '</td>';
    echo '<td>' . $record->getField('Date') . '</td>';
    echo '<td>' . $record->getField('Timestamp') . '</td>';
    echo '<td>' . $record->getField('Calculation') . '</td>';
    echo '<td>' . $record->getField('RecordID') . '</td>';
    echo '<td><a href="SearchResultsDetail.php?id=" . $record->getRecordID() . '">view</a></td>';
    echo '</tr>';
}
```
