Set the $RecordID by the script parameter. This is the name of the file to import.

Set Variable [ $RecordID; Value:Get(ScriptParameter) ]

Set the $FilePath to the document that will be moved by the Troi File Plugin in the Documents folder. The name of the file will always be associated with the RecordID and the extension .xls. Make sure to use the correct path for either OS or Windows.

As the initial result of FileMaker Server 12 is a known bug with the web publishing engine. It calculates the Documents folder as FileMaker Server/Documents. Therefore, you will have to hard code the path to the correct folder at FileMaker Server/Data/Documents until this is fixed. I have disabled the dynamic code in the database script which is resolved.

```
If[Abs(Get(SystemPlatform))>1]
  Set Variable [ $FilePath; Value:filemac:/Macintosh HD/Library/FileMaker\nServer/Data/Documents/" & $RecordID & ".xls"]
else
  Set Variable [ $FilePath; Value:filewin:C:/Program\Files/FileMaker/FileMaker Server/Data/Documents/" & $RecordID & ".xls"]
End If
```

Set the $Source of the document from the web root. Then set the $Destination of the document to the FileMakerServer/Data/Documents folder. For cross platforms, check whether the script is running on OS X or Windows.

```
If[Abs(SystemPlatform)=1]
  Set Variable [ $Source; Value:filemac:/Macintosh\nHD/Library/WebServer/Documents/PHPFiles/Advanced/Lesson21/Import/" & \n$RecordID & ".xls"]
  Set Variable [ $Destination; Value:$FilePath]
else
  Set Variable [ $Source; Value:\n  filewin:C:/input/www/root/PHPFiles/Advanced/Lesson21/Import/" & $RecordID & \n  ".xls"]
  Set Variable [ $Destination; Value:$FilePath]
End If
```

Tell the Troi File Plugin to move the file from the $Source location to the $Destination location. See the Troi documentation for the syntax to use their plugin.

```
Set Variable [ $TroiFilePlugin; Value:TrFile_MoveFile("-Unused"; $Source \n$Destination) ]
```
