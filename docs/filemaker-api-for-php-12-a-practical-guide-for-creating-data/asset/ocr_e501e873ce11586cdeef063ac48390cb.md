DuplicateList.php

The DuplicateList page is used to display all the records and provide a link to the detail page so you can isolate the record you want to duplicate. Always start by including the connection to the database.

```
<?php
include("../Conn/dbaccess.php");
?>
```

Create a list of all the records.

```
<?php
$request = $fm->newFindAllCommand('Demo php');
$result = $request->execute();
```

Trap for errors.

```
if (FileMaker::isError($result)) {
echo "<p>Error: " . $result->getMessage() . "</p>";
exit;
}
```

Get the records.

```
$records = $result->getRecords();
```

Create the table header to display the records.

```
echo '<table border="1">
<tr>
<th>First Name</th>
<th>Last Name</th>
```
