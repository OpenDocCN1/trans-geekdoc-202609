# Toggle/Untoggle Check Boxes

Using JavaScript to toggle the check boxes is quick and simple. The point of this feature is if you have a lot of records on the screen users will probably want to toggle all the records by clicking a single button, rather than manually togg each box. Place the script below in the head section of your web page. This script creates the function selectToggle loop through each checkbox in the form and update the HTML code to checked or empty the value. One of the things I like about this script is that it doesn't toggle the existing value of each checkbox, it actually toggles all the checkboxes to the same value. It will also work on multiple forms on your web page by passing the name of the form in the link that I'll describe. The only gotcha is that it will toggle ALL the checkboxes in the form. So you'll want to be careful or you'll need to investigate an alternative method that all the checkboxes with this same name and uses the RecordId for the values.

```
<script>
type="javascript">
function selectToggle(toggle, form)
{
  var myForm = document.forms[form];
  for(var i=0; i<myForm.length; i++) {
    if(toggle) {
      myForm.elements[i].checked = "checked";
    }
    else {
      myForm.elements[i].checked = "";
    }
  }
}
</script>
```

Finally, you'll need to include the links for Toggle All and Untoggle All somewhere on your page. I chose to place them at the top of the form. Use the anchor tag with the href value set to the name of the JavaScript function we created in the head section — selectToggle. If you want to toggle the boxes set the first parameter to true. If you want to untoggle the boxes set the first parameter to false. This parameter is the name of the form you want to update on the page. In case I named the form as 'Form'. When you click the link JavaScript code will loop through all the checkboxes in the form and toggle or untoggle each one. The nice part about this is that it doesn't make a new call to refresh the data. It updates the HTML on the client side.

<a href="javascript:selectToggle(true, 'form');">Toggle All</a> | <a href="javascript:selectToggle(false, 'form');">Untoggle All</a>
