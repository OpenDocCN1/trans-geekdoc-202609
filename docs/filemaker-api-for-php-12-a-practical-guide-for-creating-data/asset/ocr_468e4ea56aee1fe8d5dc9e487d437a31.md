If the user clicks the Delete button you can process the request to delete the record using the values passed by the POST method in the header. Otherwise, if they click the Cancel button you can stop the script.

```
{
if ($_POST['delete'] == 'Delete') {
  $record->delete();
  $display = '<p>The record was deleted successfully.</p>';
} else {
  $display = '<p>Cancel: The record was not deleted.</p>';
}
}?>
```

Finally, the form and the message created by the $display variable in the PHP code can be displayed as HTML with a link back to the parent record.

```
<html>
<head>
<title>Delete Record - Detail</title>
</head>
<body>
<?php echo $display; ?>
<?php echo '<a href="SearchResultsDetailPortal.php?id=' . $_REQUEST['parent'] . '">>Click here to return to the parent record</a>';\?>
</body>
</html>
```
