# 前言

《未来与金融科技》探讨了基础金融技术及其对银行、金融服务和保险（BFSI）行业日益增长的影响。2020年全球投资超过1000亿美元，金融科技的普及奠定了支付、贷款、财富管理、保险和数字资产的发展方向。

本书从工业视角出发，结合架构及其基本构建模块（例如 `Artificial Intelligence (AI)`、`Blockchain`、`Cloud`、`Big Data`、`Internet of Things (IoT)` —— 此后我们将这五种技术简称为 `ABCDI`）及其与实际工作应用的联系，阐述了金融科技。它详细指导了金融科技如何在一些新概念（如 `AIOps`、`MLOps` 和 `DevSecOps`）的帮助下，实现业务运营数字化、提高生产力和效率、优化资源管理。读者还将发现金融科技创新如何通过日益增长的 `Open Banking`、`Banking-as-a-Service (BaaS)` 和 `FinTech-as-a-Service (FaaS)` 将BFSI与世界其他领域连接起来。

为了帮助读者理解金融科技如何为挖掘庞大的实质性客户群体解锁了无数机会，本书通过实际案例和应用，配合示意图和汇总表，展示了正在进行的大规模变革，并提供了对未来变革的洞见，使本书成为涵盖所有金融科技事项的实用速查手册。

本书的组织结构如下。[第1章](#chap1.xhtml)“金融科技创新与战略”，概述了金融科技行业及其创新应用和发展战略。深入讨论了挑战、风险和机遇，并提出了一些潜在解决方案。[第2章](#chap2.xhtml)“金融科技的技术基础：ABCDI及更多”，进一步解释了金融科技背后的基础技术及其功能、相互间的交互，旨在使非技术读者能从概念上理解金融科技。

[第3章](#chap3.xhtml)“人工智能理论及其在金融行业的应用”，讨论了AI理论及其在金融行业的应用。从通用AI分类法和方法论入手，随后总结了不同业务领域的典型应用。负责任AI和可持续AI等热门话题连同其发展趋势一并探讨。[第4章](#chap4.xhtml)“金融行业的AI公平性：一种机器学习流水线方法”，聚焦于AI伦理的一个具体主题——公平性与偏见如何在整个机器学习（ML）生命周期中纠缠不清。流水线中的关键点通过实质性的工作流图表和清单得以突出。[第5章](#chap5.xhtml)“知识图谱及其在金融领域的应用”，阐述了知识图谱对金融服务的重要性。介绍了构建和维护业务知识图谱的实用方法，并通过一个简化的示例用例进行了说明。

[第6章](#chap6.xhtml)“从传统金融市场向数字资产世界的迁移”，和[第7章](#chap7.xhtml)“央行数字货币：后疫情时代的机遇与挑战”继续讨论基于区块链和DLT技术的数字资产。特别是[第6章](#chap6.xhtml)探讨了从传统金融市场向数字资产世界迁移过程中的变化与挑战，而[第7章](#chap7.xhtml)则对央行数字货币（CBDC）及其机遇、框架、挑战和技术进行了深入研究。涵盖了包括技术可用性、资产负债表影响和法律框架在内的最新发展状况。还研究了一些用例，例如新加坡的Ubin项目。
