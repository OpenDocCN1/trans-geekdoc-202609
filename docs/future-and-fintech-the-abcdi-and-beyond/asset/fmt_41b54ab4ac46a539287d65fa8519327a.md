
回顾过去，银行业随着技术的发展而演变。Brett King 在其著作《Bank 4.0》中阐述了银行业的演变历程。在他看来，Bank 1.0 主要依赖实体网点作为主要接入点。随着 ATM 和网上银行服务的引入，Bank 2.0 在银行营业时间之外提供银行服务，强调自助银行的概念，即客户可以随时办理银行业务。当智能手机普及时，银行服务也转移到了移动设备上，带来了移动支付和 P2P 等新业务模式。这就是 Bank 3.0，客户不仅可以随时，还可以随地办理银行业务。

在 Bank 4.0 中，重点在于银行服务的无处不在、无摩擦互动。客户可能不会直接与银行互动，但他们无处不在使用着银行服务。这正是我们在此介绍的开放银行业务模式。因此，开放银行不仅开放了银行的数据和功能，也开启了银行业的新篇章。

## 15.3 策略演进

自欧盟首次引入开放银行以来，监管方一直扎根于开放银行。同时，API 提供方和 API 使用方采取新策略，以应对开放银行的演进。

### 15.3.1 监管方

由于挑战现状是开放银行的显著结果，并有潜力推动行业发展，监管方自然成为推动开放银行变革的核心参与者。尽管不同监管方可能从不同立场看待开放银行，但它们对开放银行的回应通常分为以下三类——（i）颁布具有强制性开放银行法规的立法，（ii）指导银行或与国内银行业共同探索开放银行，或（iii）让市场自行主导开放银行发展进程。

欧盟、英国和澳大利亚在立法中纳入了开放银行，强制这些国家的银行采取相应的开放银行策略。新加坡和香港分别通过发布 API Playbook 和高层级开放 API 框架，采用指导与合作的方式。另一方面，中国和美国的监管方未颁布直接法律，这为银行机构和其他科技公司留出了巨大的自主探索空间。

#### 欧盟

开放银行作为欧盟创造支付服务提供商公平竞争环境的一个组成部分发挥作用。2016 年 1 月 12 日，《支付服务指令 2》（PSD2）生效，成为欧盟的关键立法，旨在促进更加一体化和高效的欧洲支付市场。它是首个《支付服务指令》（PSD1）的修订版，将新兴和新型支付服务纳入考量。PSD2 的一项关键增补是为提供账户信息和/或支付集成服务给客户的第三方提供商（TPP）创造公平竞争环境，这通过强制银行通过 API 共享客户数据并向授权的 TPP 开放支付门户来实现，即欧盟版的开放银行。欧洲经济区国家（28 个欧盟成员国和 3 个欧洲自由贸易联盟国家）被强制遵守该指令，并必须在 2018 年 1 月 13 日前将 PSD2 转化为其本地立法。PSD2 计划于 2019 年在整个欧洲经济区全面实施。

#### 英国

英国开放银行最重要的功能之一是维持银行和金融行业的充分市场竞争。2016 年，英国竞争与市场管理局（CMA）发布了关于英国零售银行业的报告，得出结论：规模较大、历史较久的银行不必像规模较小、成立时间较短的银行那样努力争取消费者的业务。^[1] 因此，开放银行被选为提振英国零售银行竞争力的策略之一。开放银行实施实体（OBIE）成立以推动开放银行，英国市场份额最大的九家银行被要求建立并采用统一的开放银行服务。关于 PSD2，尽管英国在 2016 年 6 月 23 日公投后确认脱欧，但英国选择通过引入《2017 年支付服务法规》继续遵守 PSD2，该法规于 2018 年 1 月全面生效。

#### 澳大利亚

开放银行是澳大利亚政府引入消费者数据权利的首批应用之一。继联邦财长宣布政府将在 2017-2018 预算中引入开放银行后，进行了一项开放银行审查，以建议在澳大利亚实施开放银行的最佳方式。该审查于 2017 年底发布，主题是给予客户选择权、便利性和信心。澳大利亚政府随后发布了《消费者数据权利（CDR）规则框架》草案，^[2] 于 2018 年 9 月发布征求意见。已确定 CDR 将首次应用于银行业。澳大利亚四大银行根据实施计划被要求提供数据，所有其余银行须在为四大银行设定的各项日期基础上再延后 12 个月跟进。能源和电信等其他行业也被提议跟进。

#### 新加坡

新加坡采取支持开放银行的指导式方法。2014 年 11 月，一项推动数字化和智能技术采用的倡议被提议为智慧国家战略之一，标志着开放数据和支付的开始。随后在 2016 年，新加坡金融管理局（MAS）联合新加坡银行公会（ABS）发布了详细路线图，题为“Finance-as-a-Service: API Playbook”，涵盖推荐 API、API 标准、治理和用例。MAS 还建立了金融业 API 注册表，作为来自金融机构的开放 API 的首个落地页面。^[3] API 交易所（APIX）于 2018 年 11 月推出，作为一个协作平台，在金融机构和金融科技公司之间架起桥梁。然而，尚无经立法或指令规定的开放银行采用时间表。

#### 香港

香港政府采取协作和分阶段的方法推进开放银行。香港金融管理局（HKMA）于 2017 年 9 月宣布了其对智能银行新纪元的承诺。开放银行是这一长期战略的一部分。经过 6 个月咨询并收到 41 份回复后，HKMA 发布了《香港银行业开放 API 框架》。该框架概述了在香港实施开放银行的 4 个阶段，并就 API 选择、实施和治理提供指引。银行需向 HKMA 提供开放 API 实施路线图。
