
# Cloud Graph Database Services

Some Cloud providers also offer their own graph database services. For example, `Azure Cosmos DB` supports LPG, `AWS Neptune` supports RDF and LPG, `IBM Graph` supports LPG, and `Graph Database on Alibaba Cloud` supports LPG. In addition, many third-party SaaS graph databases offerings are also available on Cloud marketplace. Self-managed `Neo4j` databases can be deployed on the major Cloud platforms including `Amazon Web Services`, `Google Cloud Platform`, and `Microsoft Azure`. Full-managed `Neo4j (Aura)` is available on `GCP`. `TigerGraph Cloud` is available through Cloud marketplaces on `AWS`, `Azure`, and `GCP`. Some other graph databases available on cloud marketplace include `JanusGraph` on `GCP` (backed by `Google Cloud Bigtable`) and `AWS`, `Dgraph` on `AWS`, `GCP` and `Azure`, `Virtuoso` on `AWS` and `Azure`, and `OrientDB` on `AWS` and `Azure`, etc.

## Graph Computing Frameworks

Graph compute engines read in graph data from graph stores and process the data for query results and analytics. They implement global graph computational algorithms. While graph databases are usually optimized for transactions (online transaction processing, or OLTP), graph compute engines are usually optimized for scanning and processing data in batches (online analytical processing, or OLAP). There are in-memory/single machine graph compute engines such as `Cassovary`, and distributed graph compute engines such as `Apache Giraph`, `Apache Spark – GraphX`, `GraphLab`, `Tencent Plato`, `Katana Graph Engine`, and `Microsoft Graph Engine`. `Apache TinkerPop` is a property graph computing framework for both graph databases (OLTP) and graph analytic systems (OLAP), and it supports both in-memory and distributed graph compute.

## Machine Learning Solutions for Information Processing

There are many Machine Learning solutions and toolkits for information processing that plays an important role in KG construction and maintenance. Some relevant popular open-source ML libraries and toolkits are discussed next.

### Transformers

This repository contains state-of-the-art pre-trained general purpose NLP models (such as `BERT`, `GPT-2`, `RoBERTa`, `XLM`, `DistilBert`, and `XLNet`) for `Pytorch` and `TensorFlow 2.0`. In particular, it includes implementations of self-supervised learning of language representation approaches, such as `ELECTRA` and `ALBERT` for enhanced NER when labeled data are limited.

### spaCy

It offers industrial-strength NLP in `Python` designed for production use. It includes pre-trained models and pipelines for common NLP tasks on 60+ languages. It is a popular open-source library for building information extraction or natural language understanding applications, as well as pre-processing text for deep learning.

### Spark NLP

It is an NLP library built on top of `Apache Spark ML`. It has a rich set of more than 1,100 pre-trained pipelines and models in more than 190 languages, and supports many state-of-the-art transformers.

### HanLP

Han Language Processing is a multilingual NLP library built on `PyTorch` and `TensorFlow 2.x`. It offers solutions for common NLP tasks including NER, syntactic and semantic dependency parsing, document classification, etc., that are relevant for KG. Version 2.1 covers 104 languages such as English and Chinese.

### Gensim

It is a `Python` library for NLP tasks such as topic modelling, document indexing, and similarity retrieval. It is highly optimized in terms of memory management and distributed computing, and therefore can handle large text corpora. However, other libraries need to be leveraged for other NLP tasks not in its core strength.

### PyTorch Geometric

It is a library of methods for geometric deep learning, which deals with deep learning on graphs and other irregular structures. It includes many variants of graph neural networks including `GCN`, graph attention networks (`GAT`), graph recurrent networks (`GRN`), and graph autoencoders/variational autoencoders.

### DGL (Deep Graph Library) and DGL-KE

`DGL` is an open-source library that implements graph neural network models, contributed by researchers at `Amazon Web Services (AWS)`. On top of `DGL`, `AWS` developed `DGL-KE`, which is a set of tools for deep-graph-learning knowledge embeddings Amazon uses to power their own KGs, including the one behind Alexa’s question-answering service. `DGL-KE` provides different compute optimizations under different parallel computing environments, thereby improving significantly the performance of the knowledge embedding algorithms.

There are also Cloud SaaS NLP APIs for information processing. Examples include:

#### NLP on AWS

`Amazon Textract` automatically extracts text and data from forms and tables in handwriting and scanned documents. `Amazon Comprehend` is a `AWS` built-in tool for information extraction from unstructured data. Users can train custom ML models by providing a small sample of their own data to build customized applications for entity identification and document classification. `Twinword` on `AWS Marketplace` can identify distance, relationship, and similarity between pieces of text. `AWS` integrated `GluonNLP`, a deep learning NLP framework built on top of `MXNet`, with `SageMaker`. `AWS` also recently partnered with `Hugging Face` to bring thousands of NLP models in the `Transformers` library to `Amazon SageMaker`.

#### Google Natural Language API and AutoML Natural Language

`Natural Language API` includes pre-trained models for NLU applications such as sentiment analysis, entity analysis, entity sentiment analysis, content classification, and syntax analysis. `AutoML Natural Language` is a no-code tool for users to train and test custom ML models by simply uploading their own training data.

#### Microsoft Azure Knowledge Mining Solutions

`Azure Cognitive Search` is not just a search tool but it also provides AI enrichment capability to meaningfully index unstructured data. `Azure Cognitive Services` includes, among other cognitive APIs, `Language Understanding Intelligence Service (LUIS)` for natural language text meaning prediction and information extraction, as well as `Text Analytics` service for sentiment analysis, key phrase extraction, and language detection. The API solutions provide access to pre-built models. Alternatively, users can also access `Spark NLP` to build custom models through `Azure Databricks` or `Azure HDInsight`, which offers a fully managed Spark service.

## Semantic Middleware Solutions

Semantic middleware exchanges information between applications based on semantic standards rather than simply exchanging data. It is more powerful than traditional middleware. Instead of connectors based on data schemas only, as done in traditional middleware, semantic connectors use reasoning to achieve native interoperability. Semantic middleware solutions typically leverage machine learning algorithms to extract and process information from unstructured data sources. Examples of semantic middleware and enterprise data and information integration solution providers include:

### Anzo Platform by Cambridge Semantics

`Anzo` is built on top of `AnzoGraph DB`, Cambridge Semantics’ own graph database that uses an in-memory MPP processing paradigm and is optimized for OLAP. `AnzoGraph DB` supports `RDF*`, LPG, and Cypher. In addition to the standard KG capabilities such as W3C standardization, knowledge query, knowledge reasoning, ontology management, and metadata management, it integrates KG with a rich set of AI/ML tools and graph algorithms for data wrangling, information extraction, KG completion, KG management, graph traversal, pattern matching, graph analytics, recommendation making, etc. Combined with built-in KG workflows, the platform enables the implementation of a data fabric for modern data integration and data management. `Anzo` platform forms the backbone of `Anzo Smart Data Lake` solutions. The platform also offers connectivity for third-party business intelligence tools such as `TIBCO Spotfire`, `Tableau`, and `Microsoft Power BI`.
