
因此，区块链与物联网的集成平台对于智能抵押品、租赁自动化、实时车险和人寿保险等极具价值。数字孪生作为物联网中物理对象或系统的虚拟副本，通常与该集成平台协同工作，以实现更好的管理和优化。

然而，这种集成可能面临许多挑战，例如可扩展性、安全性、隐私、存储等，如[图 2.12](#chap2.xhtml#fig2-12)所示。例如，网络边缘的物联网设备通常算力和存储空间有限，可能无法满足区块链的要求，因为区块链通常需要密集的数据加密和共识协议操作，并维护大体量的账本副本。有时，不成熟的区块链即服务（BaaS）可能导致设备和账户不安全，从而造成严重的安全风险。

### 2.2.8 云计算与大数据

从本质上讲，“大数据”是指具有 8 个“V”特征的大量数据集合，而“云计算”是指远程存储数据并在该数据上执行指定操作的存储和计算机制。^([10](#chap2.xhtml#rfn10)) [表 2.9](#chap2.xhtml#tab2-9) 展示了云计算和大数据的共性与独特特征。^([11](#chap2.xhtml#rfn11)) 例如，由于大数据平台的动态特性，可扩展性是其基本要求之一，这导致这些平台越来越多地部署在云端。

### 2.2.9 云计算与物联网

云计算和物联网在数据处理的不同层面上共享许多共同特征，尽管它们各自拥有独特的特征，如[表 2.10](#chap2.xhtml#tab2-10)所示。

**表 2.9.** 云计算与大数据的对比

| **项目** | **云计算** | **大数据** |
| --- | --- | --- |
| 共同特征 | 与数据处理相关<br>高度可扩展且稳健 | 与数据处理相关<br>高度可扩展且稳健 |
| 交互关系 | 云平台可作为大数据技术的载体，例如主流云服务商内嵌了大数据功能。 | 大数据概念加速了云计算的部署与采用。 |
| 定义 | 按需提供远程资源（如计算、存储、网络）。 | 一种组织海量数据并生成洞察的方式。 |
| 目标 | 提供对云服务的通用访问。 | 解决处理海量数据集的技术问题。 |
| 参考模型 | SaaS、PaaS、IaaS<br>公有云、私有云、混合云 | 结构化、非结构化、半结构化。 |
| 挑战 | 高可用性、安全顾虑、计费模式等。 | 数据多样性、数据集成、数据高效处理和资源管理等。 |
| 格式 | IT 资源的新范式 | 各种结构和格式的所有类型数据。 |
| 使用场景 | 当需要快速部署和应用扩展，同时保持集中式访问时。 | 当传统集中式方法和框架失效，且需要分布式框架处理大数据集时。 |
| 优势 | 低维护成本、无前期成本的集中式平台、灾难恢复等。 | 高度可扩展、高性价比、稳健的生态系统、提高生产力和效率、并行性等。 |
| 主要厂商 | Google、Amazon Web Service (AWS)、Microsoft、Dell、Apple、IBM、Alibaba、Tencent | Cloudera、Hortonworks、Apache、MapR |

它们通常相互补充，因为云计算提供：

*   集中式数据中心中按需动态的资源池，几乎是“无限”的；
*   具有高弹性的可扩展资源和服务管理；
*   服务（如数据 IO）方面更加同质化，利于互操作性；
*   与位置无关，可从任何地方访问；
*   高度可靠且易于访问的服务，具有一定的鲁棒性；以及
*   从本质上弥补物联网的技术约束（如存储、处理和通信）；

而物联网提供：

*   以更分布式和动态的方式呈现现实世界的事物和应用；以及
*   在大量现实生活场景中交付新服务

因此，这促成了物联网与云计算的融合，即云计算为物联网提供计算、存储和通信功能以支撑物联网愿景的实现，而物联网为云服务的扩展提供巨大机遇。换句话说，物联网平台以两种主要类型与云平台集成：(i) **以云为中心的物联网**（将物联网功能引入云端）和 (ii) **以物联网为中心的云**（将云功能引入物联网），如[表 2.11](#chap2.xhtml#tab2-11)所示。要选择合适的平台，必须至少考虑四个方面：(i) 用户管理和人机交互，(ii) 设备通信和管理，(iii) 基于聚合数据的应用集成服务，以及 (iv) 访问门户和控制。

最近出现了许多新模型，例如传感即服务 \[[7](#chap2.xhtml#rref7)\]，允许访问传感器数据；数据即服务（DaaS），提供对任何类型数据的无处不在的访问；以及身份与策略管理即服务（IPMaaS），提供对身份和策略管理的访问。特别是，根据物联网节点的处理能力，物联网基础设施可设计为在云和雾结构之间达到平衡。注意，某些物联网基础设施如有必要可使用本地网络。

| | **云计算** | **物联网** |
| --- | --- | --- |
| 共同特征 | 两者都涉及不同层面的数据收集、存储和计算。 | 两者都涉及不同层面的数据收集、存储和计算。 |
| 交互关系（互补关系） | 物联网产生的海量数据可利用云基础设施从源头传输至目的地。此类路径可针对各种工作负载提供可扩展性和灵活性。 | 物联网产生的海量数据可利用云基础设施从源头传输至目的地。此类路径可针对各种工作负载提供可扩展性和灵活性。 |

| 处理能力 | 虚拟且近乎无限 | 有限 |
| 连接性 | 通常通过互联网进行服务交付 | 通常通过互联网作为汇聚点 |
| 大数据 | 大数据的管理手段 | 大数据的来源 |

| | **以云为中心的物联网** | **以物联网为中心的云** |
| --- | --- | --- |
