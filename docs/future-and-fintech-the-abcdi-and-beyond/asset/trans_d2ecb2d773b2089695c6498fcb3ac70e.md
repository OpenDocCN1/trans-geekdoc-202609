

# 元学习

元学习（也常被称为学会学习）侧重于从多个学习情节中学习以改进学习算法，这与利用数据实例进行预测、分类和模式识别的传统机器学习形成对比。尽管一些较知名的机器学习技术（如交叉验证超参数调优和主动学习）可被视为元学习的特例，但更广泛地说，其主要目标是学习元知识，即跨学习任务通用的知识，并将其泛化到新的学习任务中。通过利用元知识，元学习旨在减少新学习任务的学习工作量和/或提高学习过程的学习质量。虽然每个单独的学习情节都有其自身的学习目标，但在元学习设定中，也存在一个显式定义的元层面目标。元目标的例子包括：优化学习情节中的某些预测性能指标、学习算法对新学习任务的快速适应（无论是否存在领域偏移），以及为对抗防御优化学习算法。Hospedales *等人* [[6](#chap8.xhtml#rref6)] 对元学习目标、元知识表示、元优化方法和元学习应用进行了很好的综述。元学习的一个重要应用领域是小样本学习，在该领域中，基础模型可仅凭极少量的任务特定标注数据得到改进。这对数据管理中的许多人工智能/机器学习应用具有重大意义，因为标注数据通常昂贵且难以整理。当然，由于元学习通常涉及计算密集型的双层优化（一个嵌套在另一个内部的优化问题），其在时间和内存方面的计算成本可能很大。分布式计算框架（如 `Apache Ray`）在此能提供帮助。`Apache Ray` 已在大规模超参数调优中展现出成功，且可想而知，它也将成为通用双层优化问题的绝佳工具。

## 8.3.4 用于信息管理和数据治理的知识图谱

知识图谱（KG）提供了一个统一框架，用于捕获、管理和利用与数据、元数据、数据系统架构、数据访问控制/日志、安全事件识别/缓解、数据策略、数据访问策略、合规策略、分析、数据流程或工作流、BI 仪表板或报告、以及生产/消费数据的应用程序或 API 等相关的所有信息（概念、层级、关系、交互等）。它可以涵盖数据管理几乎所有组件的信息。例如，它可以提供一个有效工具，支持企业对数据可用性、相关性、可用性、完整性、血缘、溯源和安全性的整体管理。知识图谱自身的基本架构使其成为捕获和探索数据对象间关系的理想工具。数据目录和血缘本身可以是该知识图谱的一个子集，而数据安全、数据主数据管理和数据治理都能直接从中受益。它实现了自助服务。用户可以查询知识库，以获取关于数据、分析、报告、策略、标准、流程等的信息。聊天机器人可以促进相关数据对象和数据信息的搜索，例如，CapitalOne 的 Risk ML Bot [[4](#chap8.xhtml#rref4)] 用于实时信用风险敞口监控/趋势预测。

为数据管理构建的知识图谱可以融入业务词汇表，并关联到涵盖业务本体所有要素的更广泛的业务领域知识图谱。将数据管理知识图谱纳入更广泛的企业业务知识图谱，为将数据融入日常业务运营和风险管理提供了重要途径。

知识图谱灵活且动态，允许组织简化知识发现、促进更好的数据连接（数据、数据生产者和数据用户之间）、更轻松地纠正/更新信息、产出更好的数据洞察，并通过捕获新概念、实体和关系持续扩展现有知识库。作为一种 AI 工具本身，知识图谱可输入其他 AI/ML 应用，以帮助产生更强大的信息驱动型业务洞察。其他 AI/ML 技术（如 NLP 和神经符号计算）也可用于数据管理知识图谱和更广泛的企业业务知识图谱的开发。

知识图谱为涉及遗留数据系统的数据集成提供了另一条路径。对于某些应用，无需直接转换所有遗留数据，仅使用从遗留源提取的特定结构化数据和/或元数据片段，将遗留数据与其他数据资产关联即可。这种集成方法不需要转换和合并底层遗留数据本身，而是提供遗留数据的摘要，并在语义层面建立数据连接，用于数据编目、信息融合和新洞察生成。这种知识图谱反过来有助于跨遗留和现代数据系统标准化数据集成，并作为数据发现、数据利用和数据治理的统一平台。更多信息请参见[第 5 章](#chap5.xhtml)。

## 8.4 面向数据管理应用的可用 AI/ML 平台和软件解决方案

前几节概述了数据管理的 AI/ML 应用领域和通用 ML 方法。本节重点介绍利用 AI/ML 工具执行数据管理任务的数据/分析平台和软件解决方案。这些平台和解决方案可集成到 ETL 流水线以及分析和 ML 工作流中。

让我们从一些旨在解决特定数据管理挑战的专用平台和 AI/ML 辅助软件解决方案开始。

*   **数据众包平台** 由一组专家/非专家生成数据标签，其中一些还提供其他众包数据管理服务。示例包括 Amazon Mechanical Turk、Lionbridge AI、Scale API、Appen 和 Cloud Factory。

*   **HoloClean 系统** 是一个开源的弱监督 ML 系统，利用特定的高层领域专用信息对结构化数据进行数据修复和预测。它可以利用参考数据集、纳入可用的规则和约束，并从相似条目的示例中学习，以识别和修复拼写错误、异常值、数据不一致和缺失条目等数据错误。数据整理工具（如 `Trifacta` (GCP Dataprep) 和 `Paxata`）也利用 ML 模型来促进数据探索、隐藏模式检测和概率数据质量规则生成。

*   **数据主数据管理系统**（如 `Tamr`、`Zaloni DataOps Arena`、`TIBCO MDM`、`Infosys MDM` 和 `Informatica`）提供由基于规则和监督式 ML 技术相结合驱动的数据整理和集成。`Dedupe.io` 是一个基于 ML 的工具，通过扫描相似行来识别 Excel 电子表格或数据库中的匹配项。`Amperity AI-Powered Identity Resolution` 有助于构建客户 360 度档案。
