
## Informatica Intelligent Data Management Cloud

In April 2021, Informatica introduced its new Intelligent Data Management Cloud powered by more than 200 intelligent data services covering the key enterprise data management and data integration workflows such as ingestion, discovery, transformation, cleansing, metadata management, master data management, security/privacy, and governance. At the core of the Informatica Intelligent Data Platform (IDP) is the Cloud-scale AI-powered Real-time Engine (CLAIRE) that powers a variety of data management solutions and products for use by data engineers, data scientists, data analysts, data stewards, DataOps, DevOps, SecOps and business users. [Figure 8.2](#chap8.xhtml#fig8-2) shows the extensiveness of AI/ML solutions supported by CLAIRE, which makes it a good example of high-level AI/ML integration into the end-to-end data management process.

These capabilities are discussed in more detail, as follows:

### Data cataloging

Leveraging the rich set of metadata collected and managed by IDP, CLAIRE’s ML-based data discovery engine can scan and catalog data assets across the enterprise. For dataset relationship discovery, primary keys, unique keys, and joins across structured datasets can be automatically identified with help from ML algorithms. The ML algorithms can learn from user feedback to improve their performance. For intelligent data mapping, smart algorithms are available to assess similarity between data columns and make suggestions for data discovery, categorization, deduplication, merging, etc. The engine can also intelligently apply semantic labels to data fields for automatic data classification. Such automatically tagged data domains can be used to aggregate relevant data fields to assemble datasets for appropriate business entities, again leveraging ML for smart data aggregation and business entity identification by learning from user examples.

### Analytics workflows

CLAIRE can leverage an organization’s own metadata from its data pipelines to apply AI/ML for data transformation recommendations. Based on user acceptance or rejection of recommendations, the underlying AI/ML algorithms can be progressively improved. It applies adaptive optimization methods for data pipeline execution such as designing data join operation plans and selecting the best processing engine to achieve desired performance level. For combining data sets, it can make recommendations on join keys based on field tags, and make suggestions to data scientists and data analysts on data sets they can use for their projects by learning from users’ past experiences. For data visualization, it generates recommendations and leverages `Apache Zeppelin` to produce graphs and charts based on user selections. CLAIRE also powers Informatica Intelligent Structure Discovery (ISD) to automatically extract structured information during file ingestion and data onboarding.

### Data quality and master data management

Leveraging metadata-driven AI, CLAIRE can infer data cleaning rules based on how similar data are handled. Similarity based approaches are also used to detect and remove duplicate data. It employs a combination of deterministic, heuristic, and probabilistic algorithms, as well as contextual synthesis matching and active learning entity matching to stitch data from various sources for Business 360 views on business entities. Synthesis matching is used to leverage “contextual attributes” extracted from unstructured data sources to help match between different types of business entities (e.g., matching prospects to customers) and identify hidden relationships. The ISD also helps named entity extraction leveraging natural language understanding for data mastering. A variety of classical and modern techniques are applied for identity matching using people’s names, organization names, addresses, identity numbers, dates, and other identification data. For entity resolution, CLAIRE applies a combination of declarative rules and machine-learned random forest classifier trained through supervised active learning.

### Data governance and compliance

The Informatica data governance tools, including Axon Data Governance, Informatica Data Quality, and Informatica Enterprise Data Catalog, leverage CLAIRE to intelligently automate many aspects of data governance workflows such as data quality assessment, data quality enrichment, and associating business terms with physical datasets by enriching and linking metadata with business semantics and by recommending machined learned rules for data quality issue identification and data association.

### Data Privacy and Protection

In addition to ML algorithms for sensitive data tagging, CLAIRE provides users the ability to track movement and the proliferation of sensitive data, and detect policy violations with respect to sensitive data access and handling. Subject registry identity mapping allows users to assess the correlation between combinations of data and subject identity. This tool can be used to find indirect identifiers of personal identity. Potential effects of different privacy protection schemes can be assessed via simulation. Abnormal data user behaviors, such as impersonation, credential hijacking, and privilege escalation attacks, can be monitored with user behavior analytics (UBA), which are generated through unsupervised learning algorithms. Real-time API data protection feature monitors sensitive data transmission between APIs and offers user options to block sensitive data on API calls.

### DataOps workflows

CLAIRE can be used for resource and capacity management such as monitoring resource utilization, predicting resource utilization trends, and applying auto-scaling to meet runtime demand. It monitors the health of data systems such as job run times, data usage, resource consumption, throughput, etc., and detects anomalies in job runs by taking into account seasonality effects.

Our discussion has focused only on the spectrum of AI/ML technologies that have already been incorporated into the Informatica IDP to help automate the data management workflows and make intelligent recommendations. Informatica is focusing on extending the AI/ML capabilities of CLAIRE to provide more intelligent and automated solutions to help organizations adapt to the fast-evolving data landscape. For more information about how ML-based innovations in CLAIRE can help drive new advances in data management, readers can refer to the Informatica white paper titled “Artificial Intelligence for the Data-Driven Intelligent Enterprise” [[5]](#chap8.xhtml#rref5). We leave readers to evaluate the performance and cost/benefit profile of IDP for your specific data management needs.

## 8.6 Challenges and Way Forward

Traditional data management practices are inadequate to handle the challenges brought on by the proliferation and explosion of data. AI/ML is not just something fashionable to have for data management in the Big Data era but is increasingly becoming a necessity. Organizations aspiring to become digitally successful need to seriously think about building up the capability and capacity to incorporate AI/ML as an integral part of modern data management. This journey mostly likely would not be smooth sailing, as a number of challenges lie in the way.
