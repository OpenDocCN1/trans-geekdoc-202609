

# 二级科技公司

市值超过200亿美元，有时甚至超过1000亿美元的令人印象深刻的科技公司。二级科技公司包括所有大型科技公司，但不包括统称为Big Tech的五家巨头。

# 代币

在区块链上记录所有权转让的可交易资产。

# 公地悲剧

生态学家加勒特·哈丁于1968年描述的概念，声称如果共享资源不受监管，最终将被耗尽。个人寻求最大化自身利益，即使这会损害公共利益。哈丁的论点证明了外部治理在监管构成公共产品的稀缺资源方面的作用。如今，`commons`也指代区块链等技术基础设施。

# TVL

指锁定在DeFi应用或整个DeFi领域中的总价值。要计算TVL，需将协议中的代币数量乘以代币的价值。

# 效用代币

`See` 生态系统代币

# 钱包

允许用户管理记录在区块链上的特定资产的软件。有托管钱包和非托管钱包。在前者中，第三方管理资产的私钥；在后者中，控制权完全掌握在用户手中。

# Web2

指互联网的第二代，其特征是集中化，特别是在Big Tech的云计算中心。Web2通常与围墙花园和缺乏互操作性相关联。它是元宇宙的一种可能基础设施，但这些元宇宙将具有游戏的特征，而非数字经济的特征。

# Web3

指互联网的第三代，其特征是去中心化和分布式。Web3建立在区块链技术之上，允许对资产、身份和数据的所有权和经济开发。

# 鲸鱼

持有加密货币流通供应量超过1%的投资者。

# 收益聚合器平台

一种DeFi协议，可自主决定将用户资产投资于哪些加密质押机会。收益也可以自动再投资。
