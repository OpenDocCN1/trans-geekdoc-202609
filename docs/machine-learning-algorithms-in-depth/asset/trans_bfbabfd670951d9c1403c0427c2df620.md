
换句话说，如果我们在参数空间中进行随机游走，我们在某个特定状态$\theta$上花费的时间比例与$p(\theta|x)$成正比。

我们将在下一节开始介绍MCMC。在介绍三种流行的采样算法（吉布斯采样、Metropolis-Hastings和重要性采样）之前，我们将先介绍三个热身蒙特卡洛示例（估计π、二叉树模型和自回避随机游走）。本章选择这些热身算法是为了让读者恰当地入门MCMC，而选择这些采样算法是因为它们在概率图模型（PGMs）采样中应用广泛。

## 2.1 马尔可夫链蒙特卡洛简介

让我们从一个简单的鸢尾花分类示例开始理解高维参数空间。鸢尾花是一种花卉，包括三个品种：山鸢尾（setosa）、杂色鸢尾（versicolor）和维吉尼亚鸢尾（virginica）。这些花以其花瓣和花萼的长度和宽度为特征，这些特征可用于确定鸢尾花的品种。图2.1展示了鸢尾花配对图。

配对图是一个图表矩阵，其中非对角线元素包含每个特征（例如，花瓣长度）与每个其他特征的散点图，而主对角线元素则包含每个特征与自身的图，并按三个鸢尾花品种进行颜色编码。配对图捕获了鸢尾花数据集中的成对关系。让我们关注主对角线元素，并尝试对我们看到的数据进行建模。由于我们有三种鸢尾花，我们可以将数据建模为三个高斯分布的混合。高斯混合是高斯概率分布的加权和。方程2.1以数学形式表达了这一点。

K个高斯分布之和

$$p(x|\theta) = \sum_{k=1}^K N(x; \mu_k, \sigma_k^2) \pi_k \tag{2.1}$$

| 高斯混合 | 高斯随机变量 | 混合比例 |
| --- | --- | --- |

高斯混合由K个高斯随机变量组成，这些随机变量按混合比例$\pi_k$缩放，混合比例为正且总和为1：$\sum \pi_k = 1, \pi_k > 0$。这是一个高维参数问题，因为要拟合高斯混合模型，我们需要找到均值$\mu_k$、协方差$\sigma_k^2$和混合比例$\pi_k$的值。对于鸢尾花数据集，我们有$K = 3$，这意味着高斯混合的参数数量等于$9 - 1 = 8$（即，我们在$\theta = \{\mu_k, \sigma_k^2, \pi_k\}_{k=1}^3$中有9个参数，由于$\pi_k$的求和为1的约束，我们减去1）。在后面的章节中，我们将介绍如何通过期望最大化（EM）算法来找到高斯混合参数。既然我们已经对参数空间有了概念，让我们以抛硬币为例，回顾一下对后验分布的理解。

### 2.1.1 抛硬币的后验分布

借助MCMC算法，我们尝试通过样本近似后验分布。事实上，大多数贝叶斯推断都是为了高效近似后验分布而设计的。让我们更详细地理解什么是后验分布。当我们有一个参数为$\theta$且需要拟合观测数据$x$的模型时，后验分布随之产生。也就是说，它是在给定数据$x$的条件下参数$\theta$的概率$p(\theta|x)$。考虑一个抛硬币序列的示例，其中每个硬币以概率$\theta$正面朝上，以概率$1 - \theta$反面朝上，如图2.2所示。

![](img/325742126d3ff007c6c385f4ffb5c3be_36_0.png)

图2.2 伯努利随机变量

图2.2展示了模拟抛硬币的伯努利随机变量的概率质量函数（PMF）。如果$\theta = 1/2$，我们有一个公平的硬币，正面（1）或反面（0）的机会相等；否则，我们说硬币是有偏的，偏差等于$\theta$。我们可以将伯努利随机变量的PMF写成如下形式。

$$p_x(x|\theta) = \theta^x (1 - \theta)^{1-x}, \ x \in \{0, 1\}\tag{2.2}$$

伯努利随机变量的均值等于$E[X] = \sum_x x p_x(x|\theta) = 0(1 - \theta) + 1(\theta) = \theta$，而方差等于$VAR(x) = E[x^2] - E[x]^2 = \theta - \theta^2 = \theta(1 - \theta)$。让我们回到抛硬币的示例。设$D = \{x_1,\ldots,x_n\}$是一系列独立同分布（iid）的抛硬币结果。然后，我们可以按如下方式计算似然。

$$p_x(D|\theta) = p_x(x_1,\ldots,x_n|\theta)\\ = \prod_{i=1}^{n} p(x_i|\theta) = \prod_{i=1}^{n} \theta^{x_i} (1 - \theta)^{1 - x_i}\\ = \theta^{N_1} (1 - \theta)^{N_0}\tag{2.3}$$

这里，我们假设$N_1 = \sum_{i=1}^n x_i$，即硬币正面朝上的总次数，$N_0 = n - N_1$，即硬币反面朝上的总次数。

方程2.2和2.3具有$p(x|\theta)$的形式，根据定义，这是在给定参数$\theta$时数据$x$的似然。如果我们对参数$\theta$有一些先验信息会怎样？换句话说，如果我们知道$p(\theta)$的某些信息，比如我们在另一组相同硬币的实验中获得的正面和反面次数呢？我们可以通过以下方式捕获这种先验信息。

$$\text{Beta}(\theta|a, b) \propto \theta^{a-1} (1 - \theta)^{b-1}\tag{2.4}$$

这里，$a$是我们先前实验中正面朝上的次数，$b$是反面朝上的次数。在计算后验分布时，我们感兴趣的是计算$p(\theta|x)$。我们可以使用第1章中的贝叶斯规则，将后验分布表示为与似然和先验的乘积成正比。

$$p(\theta|D) \propto p(D|\theta)p(\theta)\\ = \theta^{N_1} (1 - \theta)^{N_0} \theta^{a-1} (1 - \theta)^{b-1} = \theta^{N_1 + a -1} (1 - \theta)^{N_0 + b -1}\\ \propto \text{Beta}(\theta|N_1 + a, N_0 + b)\tag{2.5}$$

方程2.5计算后验分布$p(\theta|D)$，它告诉我们一系列抛硬币中正面朝上的概率。我们可以看到，后验分布服从Beta随机变量分布。回想一下，我们的先验也是Beta随机变量；我们说先验“与后验共轭”。换句话说，后验可以通过用观测数据更新先验计数来以闭式形式计算。

### 2.1.2 用于网页排名的马尔可夫链

在深入研究MCMC算法之前，我们需要介绍马尔可夫链的概念。*马尔可夫链*是一系列可能的事件，其中当前事件的概率仅取决于前一个事件。一阶马尔可夫链可以写成方程2.6所示的形式。设$x_1,\ldots,x_t$是我们后验分布的样本；然后，我们可以将联合分布写成如下形式。

$$p(x_1,\ldots,x_t)=p(x_1)p(x_2\mid x_1)p(x_3\mid x_2)\cdots p(x_t\mid x_{t-1})$$

$$=p(x_1)\prod_{i=2}^{t}p(x_i\mid x_{i-1}) \tag{2.6}$$

注意联合分布如何分解为条件分布的乘积，其中当前状态仅以先前状态为条件。马尔可夫链的特征在于状态上的初始分布$p(x_1=i)$以及从状态$i$到状态$j$的状态转移矩阵$A_{ij}=p(x_t=j\mid x_{t-1}=i)$。

让我们通过Google网页排名示例来引出马尔可夫链。Google使用网页排名算法对数十亿网页进行排名。我们可以将$n$个网页的集合形式化为图$G=(V,E)$。让每个节点$v\in V$表示一个网页，每条边$e\in E$表示从一个页面到另一个页面的链接。了解页面的链接方式使我们能够构建一个巨大的稀疏转移矩阵$A$，其中$A_{ij}$是从页面$i$跟随链接到页面$j$的概率，如图2.3所示。

![](img/325742126d3ff007c6c385f4ffb5c3be_38_0.png)

注意，矩阵$A$中每一行的和都为1（即$\sum_j A_{ij}=1$）。具有此性质的矩阵被称为*随机矩阵*。注意，$A_{ij}$对应于从状态$i$到状态$j$的转移概率。正如我们将在后面的章节中看到的，网页排名是马尔可夫链状态上的平稳分布。为了使其能够扩展到数十亿个网页，我们将

$$I = \int_{-r}^{r} \int_{-r}^{r} 1[x^2 + y^2 \le r^2] dx dy = E_{x,y}[w(x,y)] \tag{2.10}$$

这里，$1[x^2 + y^2 \le r^2]$是一个指示函数，当点位于半径为$r$的圆内时等于1，否则等于0。因此，$\pi = I / r^2$。为了计算$I$，请注意以下方程。

$$w(x,y) = (b_x - a_x)(b_y - a_y) 1[x^2 + y^2 \le r^2]\\ = (2r)(2r) 1[x^2 + y^2 \le r^2]\\ = 4r^2 1[x^2 + y^2 \le r^2] \tag{2.11}$$

我们可以在图2.4所示的伪代码中总结π估计算法。

```text
1: function pi_est(R, N):
2: for i = 1 to N:
3: X[i] ~ Unif(-R, R) → Uniform RVs
4: Y[i] ~ Unif(-R, R)
5: IN[i] = X[i]^2 + Y[i]^2 ≤ R^2
6: S[i] = (2R) × (2R) × IN[i]
7: end for
8: Î = 1/N Σ_{i=1}^N S[i]
9: π̂ = Î / R^2 ← Pi estimate
10: π̂_se = σ_S / √N ← Pi standard deviation
11: return π̂ ± π̂_se
```

图2.4 π估计器伪代码

我们从支持范围为−R到R的均匀分布中生成N个样本，并计算我们的样本是在圆内还是圆外的布尔表达式。如果样本在圆内，它将计入积分计算。一旦我们得到了积分的估计值，我们将结果除以R^2来计算π的估计值。我们现在准备好实现我们的π估计器了！
