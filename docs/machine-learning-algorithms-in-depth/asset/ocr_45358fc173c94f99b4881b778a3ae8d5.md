# 2.3 Let $y \sim N(\mu, \Sigma)$, where $\Sigma = LL^{\mathsf T}$. Show that you can get samples $y$ as follows: $x \sim N(0, I)$; $y = Lx + \mu$.

Let $y = Lx + \mu$. Then, $E[y]= LE[x]+\mu = 0+\mu = \mu$. Similarly, $\operatorname{cov}(y)= L \operatorname{cov}(x)L^{\mathsf T} + 0 = LIL^{\mathsf T}=LL^{\mathsf T}=\Sigma$. Since $y$ is an affine transformation of a Gaussian RV, $y$ is also Gaussian distributed as $y \sim N(\mu, \Sigma)$.

# 3.2 Compute $E[X],\operatorname{Var}(X)$, and $H(X)$ for a Bernoulli distribution.

A Bernoulli distribution is defined as $p(x)=p^x(1-p)^{1-x}$, where $x\in\{0,1\}$. By the definitions of mean, variance, and entropy, we can compute the following quantities:

$$E[X] = \sum_{x\in\{0,1\}} p_x(x)x = p_x(0)\times0 + p_x(1)\times1 = p$$

$$\operatorname{var}(X) = E[X^2]-E[X]^2 = \sum_{x\in\{0,1\}} p_x(x)x^2 - p^2 = p_x(0)\times0^2 + p_x(1)\times1^2 - p^2 = p(1-p)$$

$$H(X) = - \sum_{x\in\{0,1\}} p_x(x)\log p_x(x) = -p_x(0)\log p_x(0)-p_x(1)\log p_x(1) = -(1-p)\log(1-p)-p\log p$$
