The mh_gauss class consists of the target_pdf function that defined the target distribution (in our case, the Gaussian mixture p(x)); the proposal_pdf function that defines the proposal distribution (a multivariate normal); and the sample function, which samples a new state from the proposal q(x′|x) conditioned on the previous state x_k, computes the Metropolis-Hastings ratio, and either accepts the new sample with probability r(x′|x) or rejects the sample with probability 1 − r(x′|x).
