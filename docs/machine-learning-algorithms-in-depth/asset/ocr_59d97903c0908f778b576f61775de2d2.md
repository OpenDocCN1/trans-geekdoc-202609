# 7.1.2 Hidden Markov models

Hidden Markov models (HMMs) represent time-series data in applications ranging from stock market prediction to DNA sequencing. HMMs are based on a discrete-state Markov chain with latent states z_t ∈ {1, ..., K}, a transition matrix K, and an emission matrix E that models observed data X emitted from each state.
