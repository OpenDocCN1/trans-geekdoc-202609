## 1. 简介

Python 由荷兰的 Guido Van Rossum 在 20 世纪 80 年代开发。Python 作为一种面向对象的语言进行开发，强调简洁性、可扩展性和灵活性 [[1]](#part0020.xhtml)。Python 还拥有庞大的预构建功能库，用于数据科学、统计分析和数据可视化，这使得该语言非常容易学习和使用。

在本书中，我们将专注于 Python 的数据科学应用，并通过实操示例让您在短时间内从新手成长为专家！我们将从 Python 环境搭建入手，向您介绍其数据结构和库，最后深入探讨这门优美语言的数据科学应用。

您会发现本书的不同之处在于它采用了可视化和实操的教学方法。既然本书面向初学者，我们就不会啰嗦地讲解复杂概念，也不会让本书文字过于密集。相反，我们将从 Tim Peters 的《Python 之禅》[[2]](#part0020.xhtml) 中汲取灵感：

> “优美胜于丑陋……简单胜于复杂……稀疏胜于密集……”

## 2. 入门指南

Python 官网的“入门”板块提供了在您的机器上安装 Python 的详细说明——无论是 Windows、Mac OS 还是 Linux，请访问 [Python 官网的 Getting Started 部分](https://www.python.org/about/gettingstarted/) [[3]](#part0020.xhtml)。我建议您仔细阅读，因为那里有很多很好的信息和对初学者有帮助的链接。

然而，仅安装 Python 本身并不太有帮助，也不够用户友好。您最好将 Python 与 IDE（集成开发环境）一起安装——因为 IDE 自带工具和开发环境，可用于执行和调试代码。为此，我建议从 [Anaconda Distribution](https://www.anaconda.com/distribution/) [[4]](#part0020.xhtml) 开始。它是一个开源工具，可安装行业标准的 IDE 和基础 Python 库，我们将在本书中更详细地介绍这些内容。

点击上述链接后，您将进入一个页面，以下载并安装适合您操作系统（如 Windows、macOS 或 Linux）的安装包。我们将在本书中使用 [Jupyter Notebook](https://jupyter.org/) [[5]](#part0020.xhtml) 作为开发环境——Jupyter 是 Anaconda 分发包的一部分，将随 Python 一起安装在您的机器上。

Jupyter 是一个功能强大的基于 Web 的开发环境，我们将在本书中用它来执行代码，我已将本书中使用的所有源代码作为 `.ipnyb` Jupyter 文件放在我的网站上。您可以通过访问我的网站 [https://www.daneyalauthor.com](https://www.daneyalauthor.com) 来获取所有代码，并在 Jupyter Notebook 中打开。

在您的机器上安装 Anaconda 后，从菜单中启动 Anaconda Navigator。
