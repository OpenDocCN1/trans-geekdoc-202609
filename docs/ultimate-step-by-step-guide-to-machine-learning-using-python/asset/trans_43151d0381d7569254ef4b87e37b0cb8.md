

# 6. 数据探索与分析

既然我们已经介绍了不同的数据类型、结构以及如何使用它们，我们将更进一步，介绍如何处理数据文件和数据框。我们还将介绍两个基础的 Python 库：`Pandas` 和 `Numpy`。

为了本章及后续章节的目的，我们将使用一个虚构的示例数据集，该数据集基于各种房屋特征包含房屋销售价格，例如：

1.  **建造年份** – 房屋建造的年份
2.  **建筑面积** – 房屋大小，以平方英尺为单位
3.  **房屋类型** – 房屋是独栋、半独栋还是联排别墅
4.  **车库大小** – 车库可容纳的汽车数量
5.  **壁炉** – 房屋是否有壁炉
6.  **泳池** – 房屋是否有泳池
7.  **销售价格** – 基于上述特征的房屋实际销售价格

2.  **Scipy** 是一个利用 `Numpy` 数据结构进行高级代数和微积分运算的库
