现在我们已经选择了数据集，并针对空值和异常值对其进行了清洗，接下来我们准备构建不同的预测模型。但究竟什么是预测模型？用最简单的话来说，预测模型利用过去来预测未来。它们分析当前状态因素、相关性和数据关系，以基于这些依赖关系确定事态将如何发展。

在本章中，我们将使用迄今为止一直在处理的数据集构建两种不同类型的预测模型：

## 回归

在深入探讨之前，我们刚提到了一个新术语——回归。为什么预测未来的预测模型会涉及回归？回归是一种统计技术，该术语最早由弗朗西斯·高尔顿（Francis Galton）([6]) 于 1877 年使用，用于描述后代的身高倾向于向平均值回归，而不是随着每一代的繁衍而增加。随后，该术语演变为一种统计概念，用于描述因变量（如房屋销售价格）与自变量（如房屋面积和车库数量）之间的关系。存在各种各样的机器学习和预测算法，我将在下一章从较高层面介绍其中一些。不过，我将更详细地解释为什么线性回归和决策树是针对该特定问题的合适算法。

## 7.1 线性回归模型

线性回归模型假设因变量或目标变量（例如房屋销售价格）与自变量（如面积、车库数量等）之间存在线性关系。它可以用以下方程说明：

`Y = cX + I`

其中：
*   `Y` = 因变量，即房屋销售价格
*   `X` = 自变量，例如面积
*   `c` = 系数 —— 由线性回归模型计算得出
*   `I` = 截距 —— 同样由线性回归模型计算得出

以上是简单线性回归的情况，即只有一个因变量和一个自变量。当你有多个自变量时（如在我们的案例中），我们使用下面的方程，这可以定义为多元线性回归：

`Y = I + (c1X1) + (c2X2) + (c3X3) + ...`
