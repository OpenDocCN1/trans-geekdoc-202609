
# 8. Understanding Machine Learning

在上一章中，我介绍了两种机器学习模型：`Linear Regression`（线性回归）和 `Decision Tree`（决策树）分析。我还提到，根据手头问题的性质，还有许多其他机器学习模型可供应用。在本章中，我们将用通俗易懂的语言解释更多的机器学习模型和算法——旨在让读者能够从宏观层面理解它们，并根据数据的性质及其数据科学用例，知道何时应用它们。

在最高层级上，机器学习模型可分为三大类：

1.  **Supervised Machine Learning Models**（监督式机器学习模型）
2.  **Unsupervised Machine Learning Models**（非监督式机器学习模型）
3.  **Deep Learning Models**（深度学习模型）

## 8.1 Supervised Machine Learning Models（监督式机器学习模型）

对于监督式机器学习模型，模型会获得关于如何对数据进行分类的指导，并在进行预测前利用这些指令进行学习。在上一章使用的房屋销售示例中，这就是一个监督式学习的例子，因为我们告诉模型不同的房屋类型是什么，甚至哪些房屋特征会影响销售价格。然后我们将数据集拆分为训练集和测试集，供模型用于预测。

监督式机器学习模型的示例包括：

1.  **Regression analysis**（回归分析）
2.  **Classification analysis**（分类分析）

### Regression analysis（回归分析）

在回归分析中，给定若干因素，模型需要预测一个数值。以房屋销售价格示例为例，模型综合考虑多个房屋特征来预测房屋销售价格。请注意，上述是 `Linear Regression`（线性回归）的一个例子，其中因变量（如房屋销售价格）与自变量（如房屋类型、车库数量等）之间存在直线相关性。当然，也存在不存在这种直线相关性的情况，通常在这些情况下，会使用 `Polynomial Regression`（多项式回归）分析——即用曲线代替直线。换句话说，机器学习模型在执行回归分析时，所做的一切就是试图在离散的数据点之间拟合一条线，以找到自变量和因变量之间的相关性。这可以通过可视化方式直观展示：

回归分析在现实世界中的其他应用示例包括：金融行业根据历史和市场趋势预测股票价格；零售行业根据季节性和一年中的时间预测特定产品价格（如服装、户外露台及园艺产品）。

### Classification analysis（分类分析）

在分类分析中，机器学习模型根据对象的特征预测其所属类别。因此，分类模型与回归模型的主要区别在于：分类模型对对象进行归类，而回归模型预测与对象关联的数值。与回归分析一样，既然分类分析是一种监督式模型，它在进行预测前，也需要提供带有标签的数据和指令供其学习。如果上一章的房屋销售数据示例是一个分类问题，模型将获得不包含房屋类型的房屋销售数据，并被要求根据数据集中包含的不同特征预测房屋类型（如独立式、半独立式或联排别墅）。

分类算法在现实世界中的其他应用示例包括：

1.  根据健康数据将保险申请人分为不同的风险类别
2.  根据使用的语言和情感，将呼叫中心来电归类为潜在升级案例
3.  根据特定参数对收到的邮件进行分类
