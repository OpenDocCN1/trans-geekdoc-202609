
# 5. 数据遍历

既然我们已经介绍了 Python 中不同类型的数据结构，现在让我们看看如何浏览和遍历它们。我们可以通过以下方式实现：

1. If then else 语句（如果-那么-否则语句）
2. 循环
3. 函数

## 5.1 If Then Else 语句

我们将从 if then else 语句开始。这些条件结构在所有面向对象编程语言中都很常见。它们利用本书前面介绍的布尔运算符，并根据布尔条件的结果来确定后续的执行路径。请看这段代码示例：

```
wizard = 'Gandalf'
if wizard == 'Sauron':
    print("oh no")
else:
    print("keep going")
```

在上面的示例中，我们将 `wizard` 变量设置为字符串值 'Gandalf'。然后我们使用布尔等于运算符 (`==`) 来检查 `wizard` 的值是否为 'Sauron'。显然该条件的结果将为 false，因此 Python 不会打印 "oh no"，而是选择 `else` 路径并打印 "keep going"。在语法上，请注意 `if` 和 `else` 代码行末尾都有一个冒号。同时请注意，依赖的输出通过缩进来显示对 `if` 和 `else` 条件的依赖关系。

现在，如果你想在代码中有多个 if 条件怎么办？请看这段代码示例：

```
wizard = 'Sauron'
elf = 'Frodo'
helpComing = True

if wizard == 'Sauron' and elf == 'Frodo':
    print("oh no")
elif helpComing:
    print("keep going")
else:
    print("all lost")
```

请注意，我们现在将 `wizard` 变量改为了 'Sauron'，并引入了一个新的 `elf` 变量 'Frodo'。我们还通过使用布尔运算符 `AND` 扩展了 `if` 条件——基本上是检查 `wizard == Sauron` 和 `elf == Frodo` 这两个条件是否都为真。既然是这种情况，Python 会打印 "oh no" 并跳过代码中剩余的条件。

如果我们把 `elf` 改为 'Sam' 会怎样？让我们来看看：

```
wizard = 'Sauron'
elf = 'Sam'
helpComing = True

if wizard == 'Sauron' and elf == 'Frodo':
    print("oh no")
elif helpComing:
    print("keep going")
else:
    print("all lost")
```

由于我们的第一个 `if` 条件依赖于 `wizard` 为 'Sauron' 且 `elf` 为 'Frodo'，该条件不再为真。因此 Python 跳过该条件，转到条件分支 `elif`（else if 的缩写）。我们知道 `helpComing` 被设置为 `True`，所以 Python 将打印 "keep going" 作为输出。

## 5.2 循环

就像 if then else 语句一样，`for` 循环和 `while` 循环在面向对象编程语言中也很常见。`for` 循环用于根据特定条件遍历数据结构。请看下面的代码示例：

```
odd_numbers = [1, 3, 5, 7, 9]
for i, val in enumerate(odd_numbers):
    odd_numbers[i] = val + 1
print(odd_numbers)
```

在上面的示例中，我们从一个奇数列表开始，想要将它们转换为偶数。我们首先使用 Python 中的 `enumerate()` 函数，该函数本质上为列表中的每个数据元素生成索引。然后我们通过将索引赋值给 `i` 变量并给列表中的每个元素加 1 来遍历列表，直到遍历完整个列表，过程如下：

- `list[0] = 1+1 = 2`
- `list[1] = 3+1 = 4`
- `list[2] = 5+1 = 6`
- 以此类推……

结果是一个偶数列表：`[2, 4, 6, 8, 10]`。请记住，本书前面我们提到过列表是可变的，这就是为什么我们能够将列表中的奇数改为偶数——对于不可变的元组，此函数将无法工作。

现在让我们尝试遍历一个 `set`（集合）——如果你记得的话，集合用花括号表示且没有索引。那该怎么办呢？别担心，Python 也有解决办法。请看这段示例代码：

```
my_set = {1, 2, 3}
for val in my_set:
    print(val)
```

请注意，Python 如何在不使用索引的情况下，将每个数据元素的值赋给 `set` 变量，并让你遍历整个 `set` 的长度？这就是 Python 的优雅与简洁！

现在让我们看看 Python 中循环的另一个例子——`while` 循环。`while` 循环非常适合遍历大小未知的数据结构，并且你希望一直遍历直到满足特定条件。请看这段示例代码：

```
metals = ['copper', 'silver', 'gold', 'bronze', 'diamond']
index = 0
while metals[index] != 'gold':
    index += 1
print(f"Found gold at index {index}")
```

在上面的示例中，我们试图找到 'gold'，但不知道需要跳多少步才能找到。所以，我们将 `index` 设为 0，并将 `while` 循环中的布尔条件设为当 `metal` 不等于 gold 时继续循环。我们在总共 3 次跳转后终于找到了 gold，并在到达列表后面的 'bronze' 或 'diamond' 之前结束了循环。

## 5.3 函数

在 Python 中，如果你有一组特定的操作预期要在数据结构上重复执行，你可以选择定义自己的函数。例如，假设每当提供一个数值列表时，你总想返回某个特定数字的倍数。你可以按如下方式定义函数：

```
def multiples(x, list1):
    for i in range(len(list1)):
        list1[i] = list1[i] * x
    return list1

values = [13, 15, 17, 19]
print(multiples(4, values))
```

在上面的示例中，我们使用 Python 中的 `def` 关键字定义了一个名为 `multiples` 的函数。我们定义该函数接受两个参数：`x`——即我们将用来乘以列表的数字，以及 `list1`——即我们将转换为 `x` 的倍数的列表。定义完函数后，我们通过传入值为 13、15、17 和 19 的列表来测试它，并要求 `multiples` 函数通过乘以 4 来转换该列表。结果是 52、60、68 和 76——全都是期望的 4 的倍数。现在你可以在代码后面根据需要重复使用这个自定义函数了。
