

## 8.2 无监督机器学习模型

无监督模型基本上就像聪明但无人监管的孩子——他们被给予大量数据，但没有太多指导或数据标签。模型随后评估这些数据并得出结论。随着更多数据提供给模型，这些结论会不断被完善。

无监督机器学习模型的示例包括：

1.  **聚类**
2.  **降维**
3.  **关联学习**

### 聚类

顾名思义，聚类类似于上述的分类模型，它定义相似对象的簇（群组），但主要区别在于模型没有被给予任何预定义的类别来标记数据。它会自行生成这些类别。

举个例子，想象模型被要求对不同种类的未标记数据进行分类——一些数据大致符合时间类别，一些数据符合地理类别，而一些数据不符合这两个维度中的任何一个，而是被归入通用数据簇，如下图所示：

![](rsrcUY.jpg)

聚类的现实案例包括：基于癌细胞特性在癌症研究中检测异常，以及基于异常保险索赔或洗钱案件中的金融投资模式进行欺诈检测。

`K-means algorithms` 是 Python 中一种流行的算法，属于聚类的一个例子。基本上，该算法会找到具有相似属性的最近 `K` 个邻居——其中 `K` 定义了你预先设定模型要寻找的邻居数量。

### 降维

降维是无监督机器学习模型的另一个例子，它获取不同对象的一组特征，并尝试将它们归类为更高层级的类别。

可以想像 Netflix 对新上架电影和电视剧进行分类的算法——它通常会自动将不同类型的内容汇总为几个高层级类别，如动作、恐怖或喜剧。随着新内容添加到平台，算法会进一步完善自身，以更准确地对电影进行聚类。

在某些情况下，Netflix 上的某些内容可能符合多个簇。例如，一部包含大量动作场面的吸血鬼电影很可能同时属于动作和恐怖两个簇。

### 关联学习

关联学习是一种更复杂的无监督机器学习模型，它从客户行为中学习，并根据您以往的购买习惯向您推荐新产品和服务。

这类系统通常被称为推荐系统，它们将客户画像与产品簇关联起来，并以此生成推荐。

延续 Netflix 的例子，一旦模型建立了不同在线可观看内容的簇，它就会将内容与您以往的观看习惯关联起来，并向您推荐符合您最常观看类别的新电影和电视剧。同样的逻辑也适用于 Amazon 每次您登录时推荐新书或产品的情况。

## 8.3 深度学习

如果您曾听闻“机器学习”和“深度学习”这两个术语被混用，我在此要告诉您，它们并不相同。

深度学习是机器学习的一种高级形式，您将多个机器学习模型组合在一个网络中，通常称为神经网络，以得出最终的结论或决策。

之所以称之为“深度学习”，是基于神经网络有多“深”，或者网络中有多少节点——每个节点代表来自互联模型的一个决策点或推荐。

可以通过对不同的决策点或节点应用不同的权重来使神经网络更加复杂，随着模型通过更多经验、试错以及更多提供给它的数据变得更聪明，这些权重会随时间进行调整。

一个例子可能是您在找另一份工作时，职业生涯早期您可能会给薪资更高的权重。然而，随着您积累更多经验，您可能会开始给工作与生活的平衡、福利和职业发展机会等其他方面增加更多权重。

流行的深度学习 Python 库包括：

1.  **TensorFlow**
2.  **Keras**
3.  **PyTorch**

**TensorFlow** 是一个用于编程深度学习神经网络的开源框架和 API，可以作为库导入 Python。它能够处理大型数据集，并在数据处理方面非常高效——这就是为什么它在数据科学和学术界越来越受欢迎的原因。

**Keras** 可以运行在 `TensorFlow` 框架之上，但更适合较小的数据集和快速原型设计。您主要会在开发中试验神经网络，以及作为教导模型的试错过程的一部分遍历神经网络节点时看到它的使用。

**PyTorch** 最常用于自然语言处理，由 Facebook 开发。

您可能会问什么是**自然语言处理 (NLP)**？它是机器学习模型解读人类语言并将其作为输入传入算法的一种方式。

例如，不像上一章那样向模型提供 `if-then-else` 条件和代码，您可以用人类语言向模型提问，如“基于面积，我房子的预测价格是多少？”，模型会在通过算法运行问题后返回预测结果。

可以想像 Amazon 的 Alexa 和 Google Home 等 AI 设备。那些都是自然语言处理的例子。
