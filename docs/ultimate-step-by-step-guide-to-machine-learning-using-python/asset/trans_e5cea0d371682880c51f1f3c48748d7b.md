
# 3. 数据类型

在 Python 中，与大多数编程语言一样，主要有 3 种数据类型：

1.  布尔值
2.  数字
3.  字符串

## 3.1 布尔值

布尔值为 `True` 或 `False`。你可以使用以下布尔运算符来比较不同的值：

1.  等于：`==`
2.  大于：`>`
3.  小于：`<`
4.  大于或等于：`>=`
5.  小于或等于：`<=`

## 3.2 数字

在 Python 中，数字可以是整数，即像 `1`、`2`、`3` 这样的整数，也可以是浮点数，即像 `1.1`、`2.3`、`4.5` 等带小数的数字。你可以使用基本的数学运算符，如：

1.  加法：`+`
2.  减法：`-`
3.  乘法：`*`
4.  除法：`/`
5.  括号：`()` 用于强制规定运算优先级

# 4. 数据结构

现在我们已经了解了 Python 中的数据类型，接下来让我们看看 Python 是如何将这些数据类型组织成不同类型的数据结构的。在本书中，我们将介绍以下数据结构：

1.  元组
2.  列表
3.  字典
4.  集合
5.  自定义对象

## 4.1 元组

元组是有序的数据序列，表示为包含在括号中并由逗号分隔的数据。例如：

```
(1, 'two', 3.5, False)
```

列表也是有序的数据结构，数据表示为由方括号分隔（而不是像元组那样用括号）。例如：

```
[1, 'two', 3.5, False]
```

与元组不同，列表是可变的，即列表中的数据可以被更改。请看以下代码序列：

## 4.3 字典

字典与元组和列表一样，有助于对数据进行排序和排列。然而，主要区别在于它们由花括号中用逗号分隔的数据表示，并且字典的索引可以是字符串标签。请看下面的代码示例：

```
{'leader': 'Abraham Lincoln', 'fighter': 'Mike Tyson', 'city': 'Toronto'}
```
