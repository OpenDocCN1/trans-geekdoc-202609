## 10.8 章末

### 10.8.1 小结

我们以一种非常不同的方式扩展了工具箱。我们现在可以解决*数据*本身的问题。这些方法应用广泛：无论我们采用哪种学习方法，这些特征工程步骤可能都是必需的。然而，这些方法也有局限性。它们需要人工干预，我们需要小心避免过拟合，而且它们只是随机地处理目标和特征之间的关系。当我们开始处理明显非表格形式的数据（如图像和文本）时，这些方法也需要补充。

### 10.8.2 备注

`sklearn` 有一个归一化函数，其目的是让*行*之和为 1。这与我们一直在做的不同：我们一直在讨论的是对列进行归一化。

我们简要讨论了*稀疏*数据存储。有些学习方法可以编写为利用稀疏性的形式：它们会知道未填充的值为零，并避免对这些条目进行不必要的数学运算。我还没有在 `sklearn` 中找到一份方便的稀疏感知方法列表。你需要在文档中自行寻找线索。

我们讨论过 one-hot 编码——也称为虚拟变量编码或处理编码。还有其他编码分类变量的方法可以避免截距问题。这些方法称为*对比*编码方案。它们不依赖一对一的方式，而是取一个值作为基线，并将其他值与它进行比较。通过采用隐式基线，它们不会出现我们上面讨论的共线性问题。
