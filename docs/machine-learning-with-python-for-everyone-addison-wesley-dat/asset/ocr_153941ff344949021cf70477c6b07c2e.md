You might be wondering why there were three classifiers for both one-versus-rest and one-versus-one. If we have *n* classes, for one-versus-rest we will have *n* classifiers—one for each class against everyone else; that's why there are 3 there. For one-versus-one, we have a classifier for each pair of classes. The formula for the number of pairs of *n* things is $\frac{n(n-1)}{2}$. For three classes, this is $\frac{3\times2}{2}=3$. You can think of the formula this way: pick a person (*n*), pick all their possible dance partners (*n* − 1, no dancing with yourself), and then remove duplicates (divide by two) because Chris dancing with Sam is the same as Sam with Chris.
