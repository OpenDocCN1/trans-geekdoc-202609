正如我们在5.4节中简要讨论的，我们可以从概念上将模型的好坏定义为具有两部分的成本：(1) 当我们犯错时损失或消耗的东西，以及(2) 我们投入到模型复杂性中的东西。这里的数学很简单：成本 = 损失(误差) + 复杂性。保持较低的误差使我们准确。如果保持较低的复杂性，我们还能让模型保持简单。反过来，我们也提高了泛化能力。过拟合具有高复杂性和低训练损失。欠拟合具有低复杂性和高训练损失。在我们的最佳点上，我们使用恰到好处的复杂性，从而在训练和测试上获得低损失。

控制复杂性项——保持低复杂性和模型简单——被称为正则化。当我们讨论过拟合时，我们说过一些弯弯曲曲的图形过于弯曲：它们过拟合并跟随噪声而不是模式。如果我们减少一些弯曲程度，我们就能更好地跟随信号——有趣的模式——并忽略噪声。

当我们说要正则化或平滑我们的模型时，实际上是在把几个想法放在一起。数据是有噪声的：它将噪声干扰与真正有用的信号结合起来。一些模型足够强大，既能捕捉信号也能捕捉噪声。我们希望信号中的模式是相当平滑且规则的。如果两个样本的特征相当接近，我们希望它们有相似的目标值。两个接近样本之间目标值的过度跳跃，希望是噪声。我们不想捕捉噪声。所以，当我们看到模型函数变得过于锯齿状时，我们希望将其强制恢复为平滑的东西。

那么，我们如何减少粗糙度呢？让我们限制自己只讨论一种模型：线性回归。我看到教室后面举起一只手。“怎么了？”“但是Mark，如果我们在不同的直线之间选择，它们看起来都一样粗糙！”这倒是个合理的观点。让我们谈谈一条线比另一条更简单意味着什么。你可能想回顾一下2.6.1节中的一些直线几何和代数知识。记住直线的基本形式：y = mx + b。那么，如果我们去掉mx，我们可以得到更简单但仍然是一条直线的东西：y = b。一个具体的例子是 y = 3。也就是说，对于任何x值，我们(1)忽略那个x值——它现在不起作用——并且(2)直接取右边的值3。y = b比y = mx + b更简单有两种方式：

- y = b只能对单个数据点做到100%正确的预测，除非其他目标值配合。如果对手可以控制目标值，他们很容易通过选择第二个具有除3以外的任何值（比如42）的点来破坏y = 3。
- 要完整指定一个模型 y = b，我需要一个值：b。要完整指定一个模型 y = mx + b，我需要两个值：m和b。

快速说明：如果我们（1）设置m = 0，回到y = b，或者（2）设置b = 0，得到y = mx，我们就降低了自己跟随数据中真实模式的能力。我们简化了自己愿意考虑的模型。如果m = 0，我们实际上回到了y = b的情况：我们只能捕捉一个对抗性的点。如果b = 0，我们处于一个稍有不同的场景，但同样，我们只能捕捉一个对抗性的点。第二种情况的区别在于，我们有一个隐式的y截距——通常由显式的b值指定——为零。具体来说，这条线将从(0, 0)而不是(0, b)开始。在这两种情况下，如果我们把零视为给定，我们只需要记住另一个值。这就是关键思想：将权重设为零，通过减少它能跟随的点的数量和减少它必须估计的权重数量，来简化线性模型。

现在，当我们有多个输入特征时会发生什么？我们的线性回归现在看起来像 y = w2x2 + w1x1 + w0。这个方程描述的是3D中的一个平面，而不是2D中的一条线。减少模型的一种方法是选择一些w——比如w1和w0——并将它们设为零。那会得到 y = w2x2，这实际上说明我们不关心x1的值，并且满足于截距为零。完全抹掉值似乎有点过于粗暴。有没有更渐进的替代方案？有，很高兴你问这个问题。

与其引入零，我们可以要求权重的总规模相对较小。当然，这个约束会带来问题——或者，也许是机会。我们必须定义“总规模”和“相对较小”。幸运的是，“总”暗示我们需要用和将几个东西加起来。不幸的是，我们必须选择要加总的东西。

我们希望总和代表一个量，并且希望远离零的东西被平等地计算——就像我们对误差所做的那样。我们希望9和−9被平等地计算。我们通过（1）对值平方或（2）取绝对值来处理这个问题。事实证明，这里我们可以合理地使用任何一种。
