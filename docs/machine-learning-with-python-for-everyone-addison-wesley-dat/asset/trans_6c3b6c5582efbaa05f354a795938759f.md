皮尔逊 Addison-Wesley 数据与分析系列为读者提供解决数据问题和回答数据问题的实用知识。本系列的标题主要集中在三个领域：

- 1. 基础设施：如何存储、移动和管理数据
- 2. 算法：如何基于数据挖掘智能或做出预测
- 3. 可视化：如何以有意义且引人注目方式呈现数据和洞察

本系列旨在将这三个领域联系起来，帮助读者构建端到端系统，用于对抗垃圾邮件；做出推荐；构建个性化；检测趋势、模式或问题；以及从系统和用户交互的数据残余中获得洞察。
