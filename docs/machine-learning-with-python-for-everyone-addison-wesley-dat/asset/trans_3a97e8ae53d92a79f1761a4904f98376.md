## 前言

无论是称之为统计学、数据科学、机器学习还是人工智能，从数据中学习模式正在改变世界。几乎每一个可以想象的行业都已受到（或即将受到）机器学习的触动。硬件和软件改进的共同进步正在推动该领域的快速发展，不过大多数人的注意力集中在软件上。

虽然许多语言被用于机器学习，包括R、C/C++、Fortran和Go，但Python已被证明非常受欢迎。这在很大程度上要归功于scikit-learn，它不仅使得训练各种不同的模型变得容易，还使得特征工程、评估模型质量和为新数据打分变得简单。scikit-learn项目迅速成为Python最重要、最强大的软件库之一。

虽然高级数学概念是机器学习的基础，但在没有深厚微积分和矩阵代数背景的情况下，也完全可以训练复杂的模型。对许多人来说，通过编程而非数学进入机器学习是更容易实现的目标。这正是本书的目标：以Python为切入点接触机器学习，然后按需添加一些数学知识。继《人人都能学R》和《人人都能学Pandas》之后，《人人都能学Python机器学习》力求对任何想了解这个数学与计算交叉领域的激动人心之处的人开放且易于理解。

Mark Fenner花费多年时间向不同背景的人传播科学和机器学习概念，磨练了将复杂想法分解为简单组件的能力。这种经验形成了一种叙事方式，在解释概念的同时尽量减少术语，并提供具体示例。本书易于阅读，包含大量代码示例，读者可以在自己的计算机上跟着操作。

如今，渴望理解和实现机器学习的人比以往任何时候都多，因此我们有必要提供实用资源，快速而周到地引导他们。Mark通过这本富有洞察力和吸引力的著作满足了这一需求。《人人都能学Python机器学习》名副其实，能让具有各种先前训练背景的人快速提高机器学习知识和技能，大大增加他们对这一重要领域的接触机会。

## 前言

1983年，电影《战争游戏》上映了。我当时还未成年，却被深深吸引：无论是核灾难的可能性，还是主角与计算机系统几乎神奇般的互动方式，最让我着迷的是能够*学习*的机器的潜力。我花了数年时间研究东西方的战略核武库——幸运的是怀着一颗少年人的天真——但差不多过了十年我才在计算机编程上迈出认真的第一步。教计算机执行一套固定流程令人惊叹。学习复杂系统的细微之处，并围绕我的好奇心去改造它们，是一次极好的体验。不过，我还有一大步要走。几年之后，我参与了我的第一个明确设计用来*学习*的程序。我被震撼了，知道终于找到了自己的智识家园。我想与你分享*能学习的计算机程序*的世界。

### 读者对象

我认为你是谁？我为绝对的机器学习初学者撰写了《人人都能学Python机器学习》。更进一步地说，你的工具箱中很可能几乎没有多少大学水平的数学知识，*我也不会试图改变这一点*。虽然许多机器学习书籍在数学概念和公式上分量很重，但我已尽力*减少*你需要背负的数学行李。考虑到本书的书名，我确实期望你具备一些基本的Python熟练度。如果你能*看懂*Python，你就能从我们的讨论中获得更多。虽然许多机器学习书籍大力依赖数学，但我会依靠故事、图片和Python代码与你交流。当然*会*偶尔出现公式。如果你愿意，这些公式在很大程度上可以跳过。但如果我做好了本职工作，我会在公式周围给你足够的上下文，让你也许——只是*也许*——理解它想要表达什么。

为什么你手上会有这本书？所有读者最大的共同点是都想*学习*机器学习。现在，你可能来自非常不同的背景：一个专注于机器学习的基础计算课程的学生；一位突然被推到电子表格分析极限之外的中期职业商业分析师；一位想拓展兴趣的技术爱好者；或者一位需要用新方式分析数据的科学家。机器学习正在渗透社会。根据你的背景，《人人都能学Python机器学习》会为你提供不同的东西。即使是一位数学功底深厚的读者，只要想用Python进入机器学习领域，也能从本书中获益良多。

所以，我的目标是把一个有兴趣或有需求进行机器学习的人，用Python scikit-learn库及其一些伙伴，以具体的方式教会他们机器学习的*过程*和最重要的*概念*。你将带走适用于你日后研究、构建或使用的每一个学习系统的整体模式、策略、陷阱和注意事项。

### 方法

许多试图解释数学主题（如机器学习）的书籍，把公式呈现得仿佛它们能给未入门者讲述一个故事。我认为这让许多人——甚至包括喜欢数学的人！——陷入困境。就我个人而言，通过把视觉和语言描述与*可运行的代码*相结合，我能建立起关于机器学习过程的更好的心智图景。我本质上和训练上都是一名计算机科学家。我喜欢构建东西。构建东西是我知道自己达到了*真正*理解水平的途径。你可能熟悉一句话：“如果你想真正了解某件事，就去教给别人。”那么还有一句后续：“如果你想真正了解某件事，就去教计算机做这件事！”这就是我教你机器学习的方式。我要以极少的数学，把最重要、最常用的机器学习工具和技术背后的概念交给你。然后，我希望你立刻看到如何让计算机去做。有一点要注意：我们不会从头开始编写这些方法。我们将站在巨人的肩膀上，使用一些非常强大、省时的预制软件库（稍后会详述）。

我们不会极其详细地涵盖所有这些库——材料太多了。相反，我们要务实。我们要为工作选用最好的工具。我会解释足够的内容，让你在我们所用的概念上找准方向——然后我们就开始使用它。对于数学倾向的同事，我会给出他们可以进一步钻研的深度参考资料的指引。我会把大部分内容放到章节末尾的注释中，这样其余的人可以轻松跳过。

如果你正在翻阅这篇引言，考虑是否值得在这本书上投入时间，我想让你了解一下我们范围之外的东西。我们不会深入数学证明，也不会依赖数学来解释事物。有很多书走的是那条路，我会在章节末尾给出我最喜欢的书的指引。同样，我会假设你精通基础到中级水平的Python编程。但是，对于更高级的Python主题——以及NumPy或Pandas等第三方包中出现的内容——我会解释足够的来龙去脉，让你能理解每项技术及其上下文。
