Unlike logistic regression and the various discriminant analysis methods, SVCs don’t have any underlying notion of probability built into them. This does not make SVCs any better or any worse than DAs: it makes them *different*. If some data happens to fall nicely into the feature-wise independence assumption—that’s the diagonal covariance matrix—of GNB, then yes, GNB is going to be a win.
