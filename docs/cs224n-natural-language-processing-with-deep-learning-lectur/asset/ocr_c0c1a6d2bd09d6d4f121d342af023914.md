**Softmax layer:**
$p = \text{softmax}(W_2 h)$
**Hidden layer:**
$h = (W_1^w x^w + W_1^t x^t + W_1^l x^l + b_1)^3$
**Input layer:** $[x^w, x^t, x^l]$
