# 基于文献数据的机器学习预测氢甲化区域选择性

Shai Chen¹ 和 Robert Police²*

在在本期 *Chem Catalysis* 期中，Mao 等人开发了机器学习模型，用于预测催化氢甲化中末端烯烃的区域选择性，表明高温度、低压力和低金属浓度有利于线形产物。这些模型能够实现高通量筛选，有望推动此类最重要烯烃——1-辛烯和苯乙烯的创新。通用烯烃模型通过使用所有数据创建一个单一模型创建，这与按烯烃划分数据的专用模型不同。与通用模型不同，针对 1-辛烯和苯乙烯的专用梯度提升模型实现了 R² 分别为 0.850 和 0.789 的实用性能，在这些底物上的表现显著优于通用烯烃模型。

![](img/4b2aa915a163b752e3c571e656a6cb7d_0_0.png)

烯烃氢甲化 (HPOs) 是一种将烯烃、一氧化碳和分子氢转化为线形或分支醛的化学转化（图 1）。它是化学工业中规模最大的均相催化转化之一，是高原子经济性转化的范例。20世纪70年代，人们发现铑配合物均是最有效且具有化学选择性的氢甲化催化剂。随后，开发了基于钴、钌、铱、钯和铂的其他替代催化剂。²

该案例使用的完整表示是 4 维的，涵盖了烯烃、反应金属催化剂、溶剂和反应条件的描述符。研究人员应用主成分分析来降低反应表示的维度，并提高监督机器学习（ML）模型的稳健性。当维度降低到八维时，烯烃的预测性能最佳。当仅使用 1-辛烯作为底物时，将表示减少到四维显示出最高的预测准确率。与 1-辛烯专用模型相比，将表示减少到 15 维使苯乙烯专用模型的预测最大化。

最近，机器学习 (ML) 已成为有机合成和化学工程领域一种变革性的工具。这一进展在引导合成、优化反应和发现新途径方面取得了突破。³ 机器学习的方法之一是监督学习，其旨在学习一组输入和输出之间的关系，并预测未见化学反应的结果。通常情况下，构建稳健且准确的监督模型取决于高质量化学数据库的使用、适当表示的选择以及 ML 算法的选取。

首批训练以预测其数据库中所有烯烃结果的训练模型使用了通用烯烃模型，并对其进行了分析，结果发现这些模型无法区分烯烃，因为各种烯烃被聚类在一起，因此性能不够理想。具体而言，研究人员为以下情况提出了专用模型：

研究人员对理解模型最重要的特征也感兴趣。Shapley 解释 (SHAP) 被应用于构建的模型，并在三个预测性能最好的模型上对相应结果取平均值。这种方法揭示了在通用烯烃模型中，低咬合角（bite values）与低 L/B 比率相关，这与先前的文献一致。此外，含电子取代烯烃倾向于形成分支产物。在反应条件方面，高温有利于诱导 L/B 比率。对于特定的 1-烯，较长的反应时间通常会增加 L/B 的概率。此外，低压力有利于 β-氢消除的发生，这降低了分支产物和苯乙烯产物的选择性。SHAP 分析揭示了底物条件以及苯乙烯专用模型重要性的新发现。较低的催化剂浓度可以加速 β-氢消除，形成较少的分支产物。1-烯专用和苯乙烯专用模型显示，通用烯烃模型存在较高的催化剂浓度、压力和较低 L/B 值。此外，虽然研究人员使用了描述符来区分催化剂和溶剂，但最佳 ML 模型无法推广到稀有底物，因为数据偏向常见的化学种类。总体而言，Mao 同事的这项研究为末端氢甲化的区域选择性提供了一个全面的框架。
