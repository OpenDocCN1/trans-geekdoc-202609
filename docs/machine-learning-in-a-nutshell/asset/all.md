Sometimes, the person would have an idea or prior knowledge on the data set he is working on, in such case he would involve only those independent variables which are true predictors. But sometimes an order may be issued to use certain variables for the model. 

 

BACKWARD ELIMINATION:  
The steps for backward elimination are as follows: STEP-1: Select a significance level to stay in model STEP-2: Fit the full model with all possible predictors STEP-3: Consider the predictor with the highest P-value (prerequisites value) STEP-4: If P>SL go to step 4 or else your model is ready STEP-5: Remove the predictor STEP-6: Fit model without variable STEP-7: Go to step -2 and repeat until P<SL 

 

FORWARD SELECTION:  
The steps for forward selection are as follows: STEP-1: Select a significance level to entire model STEP-2: Fit all the simple regression model, select one with lowest p-value STEP-3: Keep this variable and fit all possible models with one extra predictor added to one(s) you have already have STEP-4: Consider predictor with lowest p-value STEP-5: If P<SL, go to step-3 or your model is ready. 

 

BIDIRECTIONAL ELIMINATION:  
The steps for bidirectional elimination are as follows: STEP-1: Select a significance level to enter and to stay in the model STEP-2: Perform the next step of forward selection STEP-3: Perform all steps of backward elimination STEP-4: No new variables can enter and no old variables can exit  
SCORE COMPARISON:  
The steps for score comparison are as follows: STEP-1: Select a criterion of goodness of fit STEP-2: Construct all possible regression models 2^n-1 total combinations STEP-3: Select the one with best criterion STEP-4: The model is ready Table4.1.2 gives information about the fitness level of a person considering different parameters like exercise time, sleeping hours, water intake, and gender.

4.5. RANDOM FOREST REGRESSION: Random forest regression is the extention of decision tree regression. In decision tree regression only one tree is considered but in random forest inputs are taken from a forest of trees and then optimise the value. It is similar to decision tree regression but with a few different steps. Steps to be followed to apply random forest regression to the data: STEP-1 : Pick a random k random points from the traning set. STEP-2 : Now construct a decision tree to these k random points. STEP-3 :Choose the number you want to build and repeat the steps 1 and 2. STEP-4 : When a new point is given for prediction then let all trees predict the value of output and then take the average of all the outcomes. This method helps in predicting accurate values. This is also a stable algorithm because change in a point can disturb one tree but cannot disturb a whole forest.

## CLASSIFICATION

Classification is a supervised learning procedure. Regression algorithm is used to predict a continuous value, but what if the output is not a continuous value. For example, the dependent variable output is only yes or no. Here is where classification comes into play. Unlike regression, classification is used to predict category. The role of classification is to predict into which category a new observation belongs to. Consider a data set that is created by a car company in which the inputs are people’s age, salary, and gender, and output is whether the person bought the car or not. There are many classification algorithms, these algorithms which are used to implement the classification technique on our data are known as classifiers.

6.2. HIERARCHICAL CLUSTERING: Hierarchical clustering is a unsupervised machine learning algorithm used for clustering data. Hierarchical clustering is of two types: 1.Agglomerative 

## 2.Divisive

Agglomerative clustering will be discussed. The steps to be followed to apply agglomerative clustering data are: STEP-1 : Make each data point as a single point cluster. ‘n’ clusters are obtained. STEP-2 : Take 2 closest data points and group them.‘n-1’ clusters are formed. STEP-3 : Take the next 2 closest data pointsthis time including the before cluster as a data point. ‘n-2’ clusters are formed. STEP-4 : Repeat step-3 until there is 1 cluster. (Note: To check the closest data points we consider the euclidean distance) The distance between two clusters can be considered as: 1. Distance between the 2 nearest points. 2\. Distance between the two farthest points. 3\. Distance between their centriods. 4\. Average of distance of all points. ## DIMENSIONALITY REDUCTION

Dimensionality reduction is a process in which we reduce the number of input independent variables that determine the outcome . Consider that in a data set we collected the independent variables are numerous, and the dependent variable varies as these quantities change. The most important point we have to note here is that the dependence of the outcome on all the independent variables is not the same. The outcome may dependent on mostly on only two variables and very less on other inputs. In such cases if we give all the independent variables as input to our machine, instead of obtaining the best results we will get average results. This is because we overfed our model with exessive data. The dimensionality reduction techniques help us solve this problem by finding the most important independent variables or by deriving values that are informative. 

 

The dimensionality reduction is classified as : 

1.  Feature selection 
2.  Feature extraction 

![Screenshot (1218).png](images/00408.jpeg)

 

9.1. FEATURE SELECTION: This is the process of selecting certain independent variables from many independent variables. This can be achieved by many algorithms in which the simplest way is to consider different groups of independent variables and find the error. Some of the techniques for applying feature selection to our data are: 1.backward elimination 2.forward selection 3.bidirectional elimination, *etc.* 

 

9.2.FEATURE EXTRACTION: Feature extraction works on the given input data and builts its own values derived from the data set. These values are very informative and help us predict better outcomes. The techiniques used for applying featyre extraction to our are: 1.PCA 2.LDA 3.Kernel PCA 4.QDA,etc We already discussed about backward elimination, forward selection, bidirectional elimination in regression topic. In this unit we will concentrate on PCA and LDA. 

 

9.2.1 PRINCIPAL COMPONENT ANALYSIS: The main purpose of the PCA is to identify and learn about the variables. It scrutinizes all the variables and if it finds a strong correlation between them then it reduces the dimensionality. PCA tries to understand the relation between the independent and dependent variables unlike other algorithms we studied until now which attempt at predicting the output value. In PCA we first find the directions of maximum variance in high dimenstional data and then it projects it into a small dimentional subspace. During the whole process it retains the whole data. Therefore PCA in simple words can be defined as reducing the dimensions of a k-dimenstional data set to n-dimension where k is greater than n. Steps followed in PCA algorithm: 1. The first step is to standardize the data set given to us. 2\. Obtain the eigen vectors or eigen values from correlation matrix or covariance matrix. 3\. Arrange the eigen values in descending order and select n eigen vectors that corresponds to the largest values of eigen vectors. Therefore the new dimension of our data is ‘n 4. Construct the projection matrix ‘Z’ from the ‘n’ selected vectors. 5\. Transform the original data set via ‘Z’ to obtain a n-dimenstional feature subspace y. 9.2.2.LINEAR DISCRIMINANT ANALYSIS: The LDA is a dimensionality reduction technique whose objective is to project the dataset on to a lower dimensional space. LDA and PCA both aim to reduce the dimension of the data set but PCA is unsupervised learning and LDA is supervised learning. That is PCA doesn’t check the relation between independent variables when dimentionally reducing them but LDA understands this relation and it projects the feature space onto a small subspace while maintainig the class discriminatory information. Consider the scatter plot of a data set: ![Screenshot (1231).png](images/00421.jpeg)The data is two dimentional, we now project all points to x1 and make it single dimensioned. ![Screenshot (1232).png](images/00422.jpeg)The single dimension supressed data set. ![](images/00423.jpeg)But in this method we lost information, Therefore what LDA does is that it creates a line which the relation between the variables is preserved. It also minimises the variance and it creates class separation within data. ![](images/00424.jpeg)The new dimension created by LDA is as follows: ![Screenshot (1305).png](images/00425.jpeg)
