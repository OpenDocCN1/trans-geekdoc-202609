DATA PREPROCESSING
Applying machine learning algorithms to the data sets does not give the best outcomes. Processing the data before applying any machine learning algorithm to it is the most important aspect. The output of the machine learning model depends on how well the data is processed. Data processing has several steps, which are explained below in detail.
In the first step of dealing with data in Machine Learning, creating the data sets plays an important role. A data set is a structured collection of data. After the collection of data and organizing it, the data has to be arranged into a dataset for the creation of machine learning models. Datasets may include any number of figures and characters arranged in rows and columns.
In creating the best machine learning model, gathering the data isn’t just enough, but classifying and labeling of data plays a major role. This makes the dataset accurate enough to give a realistic vision.
A data set consists of several variables; machine learning algorithms are applied to a data set to predict the value of variable using factors that affect it. The value being predicted is called the dependent variable, and the factors it depends on are called independent variables.
Most Machine learning algorithms possess two ways to precede, learning, and predicting. Therefore the data set is divided into: 1. Training Dataset

2. Testing Dataset

Training dataset :
The machine learning algorithm needs to be trained by feeding it data. Training data will help the algorithm or the machine to connect the patterns in the data to give the best output. This training data comprises the majority of the dataset.
Testing Dataset: The testing dataset is used to evaluate the performance of the machine learning model which has already been trained. The reliability of the model is checked on the training dataset. The testing dataset is basically used for interfacing how well the model performs. The most important point that has to be noted here is training should never be done on the testing set.
A test dataset is independent of the training dataset, but it has the same probability distribution as the training set. If the machine learning model is trained with a training set and tested with the same set, the best results are obtained, but not the accurate one. Thus it is important to test the machine with the test set.

1. All-in 2. Backward elimination 3. Forward selection 4. Bidirectional elimination

5. Score comparison

In the above methods backward elimination, forward selection, bidirectional elimination and score comparison are often called as stepwise regression.
ALL-IN:
Sometimes, the person would have an idea or prior knowledge on the data set he is working on, in such case he would involve only those independent variables which are true predictors. But sometimes an order may be issued to use certain variables for the model.

 

BACKWARD ELIMINATION:
The steps for backward elimination are as follows: STEP-1: Select a significance level to stay in model STEP-2: Fit the full model with all possible predictors STEP-3: Consider the predictor with the highest P-value (prerequisites value) STEP-4: If P>SL go to step 4 or else your model is ready STEP-5: Remove the predictor STEP-6: Fit model without variable STEP-7: Go to step -2 and repeat until P<SL

 

FORWARD SELECTION:
The steps for forward selection are as follows: STEP-1: Select a significance level to entire model STEP-2: Fit all the simple regression model, select one with lowest p-value STEP-3: Keep this variable and fit all possible models with one extra predictor added to one(s) you have already have STEP-4: Consider predictor with lowest p-value STEP-5: If P<SL, go to step-3 or your model is ready.

 

BIDIRECTIONAL ELIMINATION:
The steps for bidirectional elimination are as follows: STEP-1: Select a significance level to enter and to stay in the model STEP-2: Perform the next step of forward selection STEP-3: Perform all steps of backward elimination STEP-4: No new variables can enter and no old variables can exit
SCORE COMPARISON:
The steps for score comparison are as follows: STEP-1: Select a criterion of goodness of fit STEP-2: Construct all possible regression models 2^n-1 total combinations STEP-3: Select the one with best criterion STEP-4: The model is ready Table4.1.2 gives information about the fitness level of a person considering different parameters like exercise time, sleeping hours, water intake, and gender.

6.2. HIERARCHICAL CLUSTERING: Hierarchical clustering is a unsupervised machine learning algorithm used for clustering data.
Hierarchical clustering is of two types: 1.Agglomerative

2.Divisive

Agglomerative clustering will be discussed. The steps to be followed to apply agglomerative clustering data are: STEP-1 : Make each data point as a single point cluster. ‘n’ clusters are obtained.

2. Distance between the two farthest points.
3. Distance between their centriods.
4. Average of distance of all points.

DIMENSIONALITY REDUCTION

Dimensionality reduction is a process in which we reduce the number of input independent variables that determine the outcome . Consider that in a data set we collected the independent variables are numerous, and the dependent variable varies as these quantities change. The most important point we have to note here is that the dependence of the outcome on all the independent variables is not the same. The outcome may dependent on mostly on only two variables and very less on other inputs. In such cases if we give all the independent variables as input to our machine, instead of obtaining the best results we will get average results. This is because we overfed our model with exessive data.
The dimensionality reduction techniques help us solve this problem by finding the most important independent variables or by deriving values that are informative.

 

The dimensionality reduction is classified as :
  1. Feature selection
  2. Feature extraction

 

9.1. FEATURE SELECTION: This is the process of selecting certain independent variables from many independent variables. This can be achieved by many algorithms in which the simplest way is to consider different groups of independent variables and find the error. Some of the techniques for applying feature selection to our data are: 1.backward elimination 2.forward selection 3.bidirectional elimination, etc.

 

9.2.FEATURE EXTRACTION: Feature extraction works on the given input data and builts its own values derived from the data set. These values are very informative and help us predict better outcomes. The techiniques used for applying featyre extraction to our are: 1.PCA 2.LDA 3.Kernel PCA 4.QDA,etc We already discussed about backward elimination, forward selection, bidirectional elimination in regression topic. In this unit we will concentrate on PCA and LDA.

 

9.2.1 PRINCIPAL COMPONENT ANALYSIS: The main purpose of the PCA is to identify and learn about the variables. It scrutinizes all the variables and if it finds a strong correlation between them then it reduces the dimensionality. PCA tries to understand the relation between the independent and dependent variables unlike other algorithms we studied until now which attempt at predicting the output value.
In PCA we first find the directions of maximum variance in high dimenstional data and then it projects it into a small dimentional subspace. During the whole process it retains the whole data. Therefore PCA in simple words can be defined as reducing the dimensions of a k-dimenstional data set to n-dimension where k is greater than n.
Steps followed in PCA algorithm: 1. The first step is to standardize the data set given to us.
2. Obtain the eigen vectors or eigen values from correlation matrix or covariance matrix.
3. Arrange the eigen values in descending order and select n eigen vectors that corresponds to the largest values of eigen vectors. Therefore the new dimension of our data is ‘n 4. Construct the projection matrix ‘Z’ from the ‘n’ selected vectors.
5. Transform the original data set via ‘Z’ to obtain a n-dimenstional feature subspace y.
PCA is vastly being used in noise filtration, visualization, feature extraction, stock market predictions, gene analysis, etc.
