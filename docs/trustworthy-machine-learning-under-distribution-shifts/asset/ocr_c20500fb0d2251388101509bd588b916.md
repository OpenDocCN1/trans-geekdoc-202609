where the first term exploits labeled OOM data with correspondence and the second term explores OOM data $\mathcal{D}$ with modality disagreement by minimizing its KL divergence from the label posterior. Through the above objective, we can maximize the uniqueness of OOM data to achieve effective OOM generalization.

# 6.3.4 Unsupervised OOM Generalization

As for the unsupervised case, we propose two-phase training: (1) we first conduct a warm-up training to initialize the OOM feature space and the connection, and (2) then, we enhance the connection by creating emergent correspondence and further exploring OOM data.

Specifically, we select anchor points from OOM data by directly applying modality agreement among Bayes' optimal classifiers from IM data

```
$$\mathcal{A}_{sorted} = \text{SORT}_T(\mathcal{A}, \frac{1}{K} \sum_{k=1}^K \max h_k^star(x^0)), \text{ where } \mathcal{A} = \\forall x^0 \in \mathcal{M}^0, \; h_k^star(x^0) = \dots = h_K^star(x^0)$,$\$
(6.16)
```

where the $\text{SORT}_T(\cdot)$ is a sort function, which ranks each element $x^0$ in $\mathcal{A}$ based on the value of $\frac{1}{K} \sum_{k=1}^K \max h_k^star(x^0)$ from large to small. Here, we select anchor points with the top-$T$ largest likelihood over all $K$ IM classifiers. Then, we warm up the OOM learner via minimizing cross-entropy loss min $\frac{1}{2} \sum_{x^0 \in \mathcal{A}_{sorted}} \text{CE}(h^0(x^0), \arg max h^*(x^0))$. Additionally, we warm up the connection by leveraging class-specific information. We compute the cluster centers for each modality via $\frac{1}{K} \sum_{x^0 \in \mathcal{C}_y} x^0 = \{x^0, h^0(x^0)=y\} = \mu^0$ and pair them with each IM center correspondingly. To end this, we build up initial connections by following the VIB framework.

To tackle this, we map IM data into the OOM feature space. If an OOM feature is close to all mappings $v_{k,j}, \forall k=\{1,\dots,K\}$, then they can form a strong correspondence.
