**Visualization:** Furthermore, to show the effect of our data augmentations, we visualize the augmented images by applying perturbation magnitude (4.7) [118] in Figure 2.3 right. The model prediction is shown below each image. We can see that the negative augmentation significantly changes the content which is most unidentifiable. However, positive data augmentation can still preserve the content information and only change the style of images. Therefore, the augmented data are tailor-designed for training a robust classifier.

**Content and Style Disentanglement:** To further verify that our disentanglement between content and style is effective, we select the latent variables from different content and style categories, and use the learned class and domain classifiers for cross-prediction. Specifically, there are four kinds of input types: content-class, content-domain, style-class, and style-domain.
