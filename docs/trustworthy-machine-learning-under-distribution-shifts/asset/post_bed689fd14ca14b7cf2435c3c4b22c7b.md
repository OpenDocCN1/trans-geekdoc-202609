## 4.3 A Critical Analysis of Sparse Training with OOD Data

OOD generalization aims to learn an invariant predictor by leveraging multiple distributions of training data such that the generalization performance on unseen test distributions. Practically, we usually have multiple datasets correspondingly drawn from $m$ distributions (also termed environment), $\mathcal{E} = \{e_1, ..., e_m\}$, where each distribution $e = \{(x_i, y_i)\}_{i=0}^n$ contains $n$ examples $x \in \mathbb{R}$ with class label $y \in \mathbb{R}$. For each example from distribution $e$, we can assign a distribution $d \in \mathbb{R}$ and denote a data point as $(x, y, d)$. Moreover, we have a test dataset sampled from unseen distributions $\mathcal{E}_{unseen}$ to evaluate the generalization performance of our invariant learning. Let $f_0 : \mathbb{R} \to \mathbb{R}^D$ be a parameterized model with parameters $\theta \in \Theta$ which extracts feature $Z \in \mathbb{R}^M$. Our goal is to prune a sparse subnetwork from an overparameterized model so that variant features can be excluded from making final prediction. Therefore, OOD generalization can be improved.

**Data Generation Process.** Following the same formulation and problem setting from Zhang et al. [183], we assume the input variable $X^e$ from environment $e$ is generated from latent variables $Z^e = (Z_{inv}, Z_{var})$. Intuitively, the input $X^e$ indicates the image pixels, while $Z_{inv}^e$ stands for the feature of object-of-interest that stays invariant across different environments, $Z_{var}^e$ denotes the spurious feature introduced by the change of environments. Thus, the data is generated through $X^e = G(Z_{inv}^e, Z_{var}^e)$ where $G(\cdot)$ denotes the data generating function. To obtain an OOD-robust model, we hope to extract latent representations which can recover the invariant feature $Z_{inv}^e$ while excluding the variant feature $Z_{var}^e$. Such a process is modeled through $Z^e = f_0(X^e)$, where $Z^e \approx [Z_{inv}, Z_0]$. Hence, based on the extracted feature, we can make predictions through a classification head $\hat{Y}^e = h(Z^e)$ and train our model by minimizing the error between the prediction $\hat{Y}^e$ and ground truth label $Y^e$.

**The Cause of Data Bias.** Based on the data generation process, we explain why different distributions correlate biases that hinder the generalization result. We consider a simple example where $Z_{inv}^e$ and $Z_{var}^e$ are multivariate variables with binary elements, $Z_{inv}^e \in \{-1, 1\}^{M_{inv}}$ and $Z_{var}^e \in \{-1, 1\}^{M_{var}}$, in which $M_{inv}$ and $M_{var}$ denotes the dimension of invariant feature and spurious feature, respectively. We have class label $Y^e \in \{-1, 1\}$ and distribution index $D \in \{-1, 1\}$. Since the invariant feature stays constant across environments, we assume each element of $Z_{inv}^e$ takes a value of $Y^e$ with probability $p^e$ and $-Y^e$ with probability $1-p^e$. When $p^e$ is large, the spurious feature will be closely correlated with the class label, hence unlikely to introduce large data biases. Conversely, if $p^e$ is small, $Z_{var}^e$ can introduce noisy signals that flag the prediction.

Additionally, we analyze the domain knowledge to provide an opposite perspective, which is overlooked by previous works [183, 184]. Concretely, the change of distribution index $D$ is the cause of introducing a spurious feature, i.e., $D \rightarrow Z_{var}^e$, as described by many proposed causal structures [84, 196, 1997]. Therefore, when given the distribution $D$, we can find a specific type of spurious feature. Hence, we assume each element of $Z_{var}^e$ is equal to $D$. On the other hand, we consider $Z_{inv}^e$ takes the value of $D$ with probability $q^e$ and $-D$ with probability $1-q^e$. It has been commonly assumed that the invariant feature and domain knowledge are independent [84], but that the probability $q^e$ could be 0.5.

**The Flaw of Common Sparse Training Strategy** Existing studies on sparse invariant learning [183, 184] have shown that pruning an overparameterized model, the OOD generalization performance could be improved substantially. However, we find that the existing pruning strategy, which is based on ER or objectives only related to labels, could be suboptimal. Specifically, we consider the same data set described above, $Z_{inv}^e \in \{-1, 1\}^{M_{inv}}$ and $Z_{var}^e \in \{-1, 1\}^{M_{var}}$. The data generating function $G$ is simplified as an identity map [118, 1988], where $X = (Z_{inv}^e, Z_{var}^e)$. Suppose the classification model $f_\theta$ is a linear layer, we have a mask $\mathbf{m}$ initialized with $0-1$ to prune the parameter $\theta$, and its sparsity ratio is set to $R = \frac{M_{var}}{M_{inv}}$. Particularly, we denote the selected invariant parameters as $\theta_{inv} = \mathbf{m} \circ \theta$ and the pruned parameters as $\theta_{var} = (1-\mathbf{m}) \circ \theta$ where $\odot$ is the element-wise production. To ease the calculation, let the parameter values follow a unit norm, i.e., $\theta=1\frac{L}{\sqrt{M}}^2$.

## 4.4 Methodology

In this section, we introduce our EVIL framework as shown in Figure 4.2. In the learning flow of EVIL, there are two procedures: Parameter Exploration, in which we propose to not study invariant parameters but also explore variant ones; and Invariant Learning, where we train the identified subnetwork to optimize the invariant parameters.

### 4.4.1 The Proposed EVIL Framework

In order to get a good initialization, a few steps of pre-training are commonly conducted by minimizing a learning objective $\mathcal{L}(f_\theta(x))$ [202, 203, 200, 182], where $f_\theta$ is a deep model with parameters $\theta \in \mathbb{R}^N$. To sparsify the deep model, a binary mask $\mathbf{m}$ is often applied through element-wise product $\mathbf{m} \circ \theta$. Such a mask $\mathbf{m}$ is learned through optimization [204, 203, 205, 183, 184], or obtained based on certain criteria, such as connection sensitivity [199], weight value [200], fisher information [201], or even random initialization [179, 206]. By setting the sparsity ratio $R=1-\frac{\|\mathbf{m}\|_0}{\|\theta\|_0}$, we can decide how many parameters are rejected from sparse training.
