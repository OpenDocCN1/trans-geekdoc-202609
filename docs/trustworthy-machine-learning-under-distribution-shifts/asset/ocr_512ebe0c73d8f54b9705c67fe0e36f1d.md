```
$$\begin{aligned} \text{Err}^e &= \mathbb{P}\left[m\mathbb{Z}^e_{var} \le 0\right] \ &= \mathbb{P}\left[m\mathbb{Z}^e_{var} - \mathbb{E}[m\mathbb{Z}^e_{var}] \le -\mathbb{E}[m\mathbb{Z}^e_{var}] \mid\ Y^e = 1\right] \ &\le \mathbb{P}\left[|m\mathbb{Z}^e_{var} - \mathbb{E}[m\mathbb{Z}^e_{var}]| \gege \mathbb{E}[|m\mathbb{Z}^e_{var]| \mid\ Y^e = 1\right], \quad (7.41) \ &\ \mathbb{E}[m\mathbb{Z}^e_{var}] &= \mathbb{sgn}\left[\frac{1}{M_{var}}\sum_{i \in [M_{inv}, M]} Z^e_{var} \mid\ Y^e = 1\right] \ &= 2\mathbb{P}\left[\frac{1}{M_{var}}\sum_{i \in [M_{inv}, M]} Z^e_{var} > 0 \\mid\ Y^e = 1\right] \ &= (p^e)^2 - 1. \end{aligned}$
```
