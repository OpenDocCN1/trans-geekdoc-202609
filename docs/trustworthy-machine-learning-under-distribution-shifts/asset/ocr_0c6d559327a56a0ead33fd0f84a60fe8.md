# 7.1 Proof for SharpDRO

This section provides the proof of Theorem 1. We first give some notations before we start our proof for the convergence.

+   (1) We denote the loss expectation as $\mathbb{L}(\theta,\omega) := \mathbb{E}_{(x,y)\sim\omega}\mathcal{L}(\theta; (x, y))$, and so as the SAM function that $\mathbb{R}(\theta,\omega) := \mathbb{E}_{(x,y)\sim\omega}\mathcal{R}(\theta; (x, y))$. So our objective can be turned into: $\min_{\theta}\max_{\omega}\mathbb{L}(\theta,\omega) + \mathbb{R}(\theta,\omega)$. And recalling SharpDRO algorithm, we restart the meaning of the parameters: the model is parameterized by $\theta$ and $\omega$ means the weighted sampling.

+   (2) $\kappa$ is the condition number that $\kappa = \frac{L}{\mu}$, where $l$ is the Lipschitz-smoothness in Assumption 10 and $\mu$ means the PL condition in Assumption 12.

+   (3) We define $L^*(	heta) = \max_{\omega}\mathbb{L}(\theta,\omega)$ and $\omega^*(	heta) = arg\max_{\omega}\mathbb{L}(\theta,\omega)$.
