OM-IM connections by maximizing cross-modal interaction. First, we select data pairs
from cross-modal mappings according to feature similarity. By assuming that the data pairs
closing to OOM mappings can be considered as correspondence, we can create emerging cor-
correspondence and solve the unsupervised case via the semi-supervised solution. To validate
the proposed COX, we carefully design experiments using various multi-modal datasets to

- We consider two typical situations: Semi-Supervised OOM generalization and Un-

# 6.2 Related Work

Modality Generalization [333] generally focuses on leveraging the knowledge from some
modalities and generalizing to another one. Existing studies are conducted in different set-
tings with various tasks. Cross-modal fine-tuning mimics transfer learning by adapting
the distribution of IM data to OOM data using the same model. [334] proposed to conduct
distribution alignment to achieve this goal which requires both pre-trained knowledge and
labeled target modal data. [335] designed on a similar problem setting, a gradual
modality generation scheme that selects the top-k active feature patches from target mod-
alities, and replaces them with source modalities patches. Such a progressive strategy can
align modal data to ensure generalization. Cross-Modal Generalization uses separ-
ate encoders and focus on generalizing to a different modality data from the same instance.
