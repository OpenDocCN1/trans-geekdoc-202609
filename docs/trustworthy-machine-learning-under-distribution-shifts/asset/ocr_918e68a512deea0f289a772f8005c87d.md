# 7.3.2 Theoretical Proof

We first start with a given image $x_q$, when conditioned on a concept $\phi^*$ and prompt $S_n$, the most probable text output for $y_q$ is the same as the class in the prompt distribution $p_{prompt}$ with maximum probability. Then, we show that in our denoising in-context learning, when achieving the most likely prediction $z$ output by the MLLM predictor, the class text $y_q$ in the pretraining distribution $p$ is the same as the one found by the prompt distribution $p_{prompt}$, which is the exact match for the given image $X_q$.

Before we start analyzing the binary prediction $z$, we first investigate the most probable class $y$ given by prompt and query arg $\max_y p(y|S_n, x_q)$.

THEOREM 22. Assume that the above assumption holds, if for all $\phi \in \Phi, \phi 
eq \phi^*$, the concept $\phi^*$ satisfies the distinguishability condition: $\sum_{j=1}^k \mathcal{L}_j(\phi^*) > \epsilon_{start}^* + \epsilon_{delim}$, then as $n 	o \infty$, the prediction $y$ according to the pretraining distribution is

```
$$\max_y p(y|S_n, \phi^*) \to \max_y p_{prompt}(y|X_q). \quad (7.54)$
```

Thus, the in-context predictor $f_n$ achieves the optimal $0-1$ risk: $\lim_{n\to\infty} \mathcal{L}_{0-1}(f_n) = \inf_f \mathcal{L}_{0-1}(f)$.

The detailed proof of this theorem is similar to Xie et al. [297], please refer to the Section D of the original paper.

Under this assumption, the in-context predictor is guaranteed to have the highest probability of generating the class description $y$ that exactly matches the query image $x_q$. In another way, when $x_q$ does not belong to $y$, the probability $p(y|S_n, x_q)$ is less than the optimal value.

LEMMA 6. Under the same condition of Theorem 22, the prediction $z$ according to the pretraining distribution is

```
$$\max_z p(z|S_n, x_q, y_q, \phi^*) \to \max_z p_{prompt}(z|X_q, y_q). \quad (7.55)$
```
