# 3.4.2 Experimental Setup

For distribution-average situation, we choose GroupDRO [125], SRM [69], REX [144], and ERM for comparisons. For a distribution-agnostic situation, we use JTT [140] and Environment Invariance for In Learning (EIL) [143] for baseline methods². For every problem setting, we construct construction using CIFAR10/100 [107] and ImageNet300 [104] datasets. Specifically, we follow [114] to perturb the image data with severity levels from 1 to 5 using two types of corruption: “Gaussian Noise” and “Shot Noise”.

> Note that we do not include the sharpness method SAM [137] in this problem setting because its O generalization performance is worse than ERM. We conduct a detailed analysis between SharpDRO and SAM in Section 3.5.1
