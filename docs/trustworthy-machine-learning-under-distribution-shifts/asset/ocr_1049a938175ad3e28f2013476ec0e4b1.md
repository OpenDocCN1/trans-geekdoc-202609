# 2.3.2 Data Augmentation with Content and Style Intervention

After disentangling content and style, we try to harness OOD examples via two opposite augmentation procedures, namely *positive data augmentation* and *negative data augmentation* which aim to produce OOD data $	ilde{x}$ and malign OOD data $ar{x}$, respectively, so to further enhance model generalization and improve robustness against anomalies. Specifically, to achieve this, positive data augmentation only conducts intervention on the style feature while keeping the content information the same; and the negative data augmentation attempts to affect the content while leaving the style unchanged, so as produce malign OOD data, as shown in Figure 2.1 (b).

To achieve this goal, we employ adversarial augmentation on the latent variables without influencing each other, thus it is perfect for our intuition of augmenting content and style. Particularly, by adding a learnable perturbation $\epsilon$ to each instance $x$, we can obtain OOD data $	ilde{x}$ and malign OOD data $ar{x}$ with augmented content and style, respectively. For each data point $(x, y, d)$, the perturbation $\epsilon$ can be obtained by minimizing the intervention objective $\mathcal{L}(\cdot)$

```
$\epsilon = \arg \min_{\epsilon:\\ell_p < c} \mathcal{L}(x + \epsilon, y, d; \theta_c, \phi_c, \theta_s, \phi_s)$ \quad (2.6)
```

where $\epsilon$ denotes the magnitude of the perturbation $\epsilon$ with $\ell_p$-norm. Since our goal of positive and negative data augmentation is completely different, here the intervention objective is designed differently for producing $	ilde{x}$ and $ar{x}$.
