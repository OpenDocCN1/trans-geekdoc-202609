# 6.3.3 Semi-Supervised OOM Generalization

We start with a semi-supervised case where a few correspondences are available in OOM data, as shown in Figure 6.4 (a). Based on the VIB framework proposed in Section 6.3.2, we first leverage the OOM data $\{(x_i^0, y_i^0)\}_{i=1}^L$ corresponding to IM data $\{(x_{k,j}^L, y_{k,j}^L)\}_{j=1}^D \forall k \in \{1,...,K\}$\}$ to build $K$ connections using additional generative models that can be trained via a point-to-point mapping.
