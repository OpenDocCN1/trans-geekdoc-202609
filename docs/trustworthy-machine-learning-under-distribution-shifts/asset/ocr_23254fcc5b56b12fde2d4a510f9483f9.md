# 6 OUT-OF-MODAL GENERALIZATION

Connection through Commonality aims to capture common knowledge across modalities using generative models [316]. Here we follow the variational information bottleneck (VIB) framework [342] to achieve this goal. We assume that we IM data $X^I$ and OOM data $X^O$, the latent variable $V$ extracted from $X^{I2}$, and label $Y$, the joint distribution is factorized as

```
$p(X^I, X^O, V, Y) = p(V,Y^O,X^I)p(X^O|X^I)P(X^I)$,
```

where we use $p(V,Y^O,X^I) = p(V|X^I)p(X^I)$, corresponding to the Markov chains $V \leftrightarrow X^I \leftrightarrow X^O$ and $X^I \leftrightarrow Y 
eq X^O$. Such an assumption means that $V$ is not related to $X^O$ [342] and the given label $Y$ is not directly connected to $X^O$ under our OOM setting. Intuitively, given an IM datum, i.e., dog image, it is sufficient to infer the label “dog”, and the same for inferring from an unknown OOM datum, i.e., dog bark. Thus, in multi-modal settings, the label prediction using IM information dog image is not further conditioned on OOM knowledge dog bark, because the OOM knowledge is redundant when IM data is given.

Our goal is to extract valuable knowledge from IM data to leverage OOM data by maximizing the information commonality [330, 341]:

```
$I(X^O; X^I; Y) = I(X^O; X^I) - I(X^O; X^I|Y)$,
```

where $I(X^O; X^I; Y)$ denotes the mutual information between $X^O$ and $X^I$ regarding the task $Y$, i.e., the label; and $I(X^O; X^I|Y)$ indicates the conditional mutual information irrelevant to $Y$. We start with the first

```
$I(X^O; X^I) = \int dx^O dx^I p(x^o, x^i) \log \frac{p(x^o, x^i)}{p(x^o)p(x^i)} = \int dx^O dx^I p(x^o, x^i) \log \frac{p(x^o|x^i)}{p(x^o)}$, (6.3)
```

where $p(x^o|x^i) = \int dv p(x^o, v|x^i) = \int dv p(x^o|v)p(v|x^i)$ can be approximated via a decoder $q(x^o|v)$. Since the Kullback Leibniz (KL) divergence is always non-negative, we have $KL[p(X^O|V) || q(X^O|V)] \geq 0 \Rightarrow \int dx^O p(x^o|v) \log \frac{p(x^o|v)}{q(x^o|v)} \geq \int dx^O p(x^o|v) \log q(x^o|v)$,

> ²Note that the latent variable V is different from the feature representation $z^1$ and $z^O$.
