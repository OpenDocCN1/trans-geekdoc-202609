**Models.** We employ two types of IM perceptors, ImageBind [294] and Language-Bind [329] which correspondingly contain 6 and 5 encoders to process different modalities. We select one modality for each experiment as OOM and then choose the rest as IM. For IM data, we use the existing encoders to extract their features. For OOM data, we conduct preprocessing to ensure its compatibility. Then, we initialize an OOM learner from scratch using ViT-T/16 to learn from the OOM data using IM perceptors. Note that for the TVL dataset, there are no existing encoders to process tactile modality. Therefore, when the tactile modality is chosen as IM data, we fine-tune the encoder using contrastive learning on the training set. For ImageBind, the tactile encoder is aligned with the image encoder, which is the same as the original training process. For training the connection between modalities, we employ multi-layer perceptrons to realize the variational bottleneck framework. Moreover, to obtain the optimal classifier from each-modality, we utilize the extracted features and train a linear layer as classification heads.

**Setup.** We consider two scenarios of OOM generalization: For the semi-supervised case, we sample 10% of the training data as labeled data with each class having a balanced number of labels. For the unsupervised case, we have no labels at all. For selecting the number of anchor points, we choose the same number of examples for the warm-up and training phases, which is 10% of the total setting. We use an initial learning rate of $1e-3$ with weight decay $1e-5$, and train for 50 epochs.
