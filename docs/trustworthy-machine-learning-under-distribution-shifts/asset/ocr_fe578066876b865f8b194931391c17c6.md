# 4.3 A Critical Analysis of Sparse Training with OOD Data

OOD generalization aims to learn an invariant predictor by leveraging multiple distributions of training data such that the generalization performance on unseen test distributions. Practically, we usually have multiple datasets correspondingly drawn from $m$ distributions (also termed environment), $\mathcal{E} = \{e_1, ..., e_m\}$, where each distribution $e = \{(x_i, y_i)\}_{i=0}^n$ contains $n$ examples $x \in \mathbb{R}$ with class label $y \in \mathbb{R}$. For each example from distribution $e$, we can assign a distribution $d \in \mathbb{R}$ and denote a data point as $(x, y, d)$. Moreover, we have a test dataset sampled from unseen distributions $\mathcal{E}_{unseen}$ to evaluate the generalization performance of our invariant learning. Let $f_0 : \mathbb{R} 	o \mathbb{R}^D$ be a parameterized model with parameters $	heta \in \Theta$ which extracts feature $Z \in \mathbb{R}^M$. Our goal is to prune a sparse subnetwork from an overparameterized model so that variant features can be excluded from making final prediction. Therefore, OOD generalization can be improved.

**Data Generation Process.** Following the same formulation and problem setting from Zhang et al. [183], we assume the input variable $X^e$ from environment $e$ is generated from latent variables $Z^e = (Z_{inv}, Z_{var})$. Intuitively, the input $X^e$ indicates the image pixels, while $Z_{inv}^e$ stands for the feature of object-of-interest that stays invariant across different environments, $Z_{var}^e$ denotes the spurious feature introduced by the change of environments. Thus, the data is generated through $X^e = G(Z_{inv}^e, Z_{var}^e)$ where $G(\cdot)$ denotes the data generating function. To obtain an OOD-robust model, we hope to extract latent representations which can recover the invariant feature $Z_{inv}^e$ while excluding the variant feature $Z_{var}^e$. Such a process is modeled through $Z^e = f_0(X^e)$, where $Z^e \approx [Z_{inv}, Z_0]$. Hence, based on the extracted feature, we can make predictions through a classification head $\hat{Y}^e = h(Z^e)$ and train our model by minimizing the error between the prediction $\hat{Y}^e$ and ground truth label $Y^e$.
