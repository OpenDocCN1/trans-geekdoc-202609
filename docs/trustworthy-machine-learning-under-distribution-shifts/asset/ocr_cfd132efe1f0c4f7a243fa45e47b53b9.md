However, due to the difficulty of align- the text generation process with visual recognition tasks [245, 263, 263], MLLMs struggle with generating correct answers that match the ground-truth class names, underperform- the current dominant contrastive paradigms, even when employing them as vision encoders [245, 246, 264, 263, 265].

Focusing on enhancing the robustness of vision models, in this Chapter, we propose to ef- effectively leverage MLLMs to conduct Machine Vision Therapy (MVT) which aims to diagnose and rectify the error predictions through a novel Denoising In-Context Learning (DICL) strategy. Then, we utilize the rectified supervision to guide the fine-tuning pro- cess in downstream OOD problems. Specifically, rather than giving a set of options to ask MLLMs for the exact answer [245, 264, 265], we show that it is sufficient to query for the ground truth by using two exemplars, i.e., (1) a correct one that demonstrates the ex- match between a query class name with its image example and (2) an erroneous one that combines the same query class with an image from the most confusing category for the vision model. Since the erroneous predictions are essentially label noise, we we draw inspiration from learning with noisy labels [266, 267, 268, 269, 270, 271, 272, 123, 273, 274, 64, 275, 276]. Particularly, we find the erroneous categories by estimating a trans- tion matrix that captures the probability of one class being mistaken as. By feeding the two exemplars, MLLMs can be instructed to leverage their few-shot learning power to distinguish the semantically similar images that are easily confused by vision models, as shown in the lower row of Figure 5.1. To process such instructions, we leverage the multi- modal in-context learning ability of several existing MLLMs [277, 278, 279, 280] to realize our methodology. After the error predictions are diagnosed and rectified, vision models can be further-tuned to enhance their OOD robustness on downstream data distribution.
