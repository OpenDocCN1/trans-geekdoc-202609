## 2.4.4 Open-set DA

In open-set DA task, we follow [41] to validate on two DA benchmark datasets Office Amazon (A), Webcam (W), and DSLR (D). Office dataset contains three domains and each domain is composed of 31 classes. VisDA dataset contains two domains Synthetic and Real, and each domain consists of 12 classes. To create an open-set situation in Office, we construct it by sampling from the first 21 classes in alphabetical order. Then, the target dataset is sampled from all 31 classes. As for VisDA, we choose the first 6 classes for source domain and use all the 12 classes for target domain. We use “A→W” to indicate the transfer from “A” domain to “W” domain.

For comparison, we choose three typical open-set DA approaches including Open-set DA by BackPropagation OSBP [41] which employs an OpenMax classifier to recognize unknown classes and perform gradient flipping for open-set DA, Universal Adaptation Network UAN [102] which utilize entropy and domain similarity to down-weight malign OOD data, and Separate To Adapt STA [40] which utilizes SVM to separate malign OOD data.

## 2.4.5 Performance Analysis

Ablation Study: To verify the effectiveness of each module, we conduct an ablation study by eliminating one component at a time. Specifically, our HOOD can be altered: “w/o disentanglement” which indicates removing the disentanglement loss in Equation (2.5a), “w/o benign OOD data” which denotes training without OOD data, “w/o malign OOD data” and “w/o both augmentations” indicates training without both benign and OOD data. In OOD detection, we use CIFAR10 and LSUN as the ID and OOD dataset, respectively. In open-set SSL, we choose CIFAR10 with labels for each class. As open-set DA, we use VisDA dataset.

The experimental results are shown in Table 2.4. We can see each module influences the performance differently differently. First, we can see that the malign OOD data is essential for OOD detection, as it can act as anomalies and reduce the overconfidence in unseen data. Then, benign OOD data can greatly improve the learning in open-set SSL and open-set DA, as they can enforce the model to focus on the content for classification. Therefore, our HOOD can correctly change the style and content, which can correspondingly benefit tasks (such as open-set DA and open-set SSL) and tasks (such as OOD detection). Moreover, open-set DA relies more on disentanglement than the rest modules, to exclude the style changing across domains. Hence, our disentanglement can effectively eliminate the distribution change from different domains and help learn invariant features.

Analysis on Augmentation: Since HOOD does not introduce any parameter, the most influential setting is the number of augmentation. To analyze its influence on the learning, we vary the number of augmentations sampled from Rand-Augment Pool 2 to 6. The results are shown in Figure 2.3. We can see that both few and too many augmentations would hurt the results. This is because a small augmentation number would undermine the generalization to various styles; a large augmentation number would increase the classification difficulty of the style branch, further making disentanglement hard to achieve. Therefore, setting the augmentation number to 4 is reasonable.
