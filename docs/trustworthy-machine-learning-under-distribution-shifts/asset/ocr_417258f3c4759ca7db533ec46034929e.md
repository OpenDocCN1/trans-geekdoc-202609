Lemma 6 and Theorem 23 together show that when given a query image $x_q$, if the chosen query description $y_q$ is the true class of $x_q$, then under the given assumptions, the binary prediction $z$ for judging the correctness of the image-text pair would be the maximum value compared to all other class descriptions $y 
eq y_q, y \in \mathcal{Y}$. Therefore, we can justify that an in-context predictor can help identify the true class label of a given image.
