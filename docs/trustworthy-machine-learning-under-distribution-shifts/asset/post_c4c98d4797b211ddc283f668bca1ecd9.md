# 7.3 Proof for MVT

This section provides the proof of Theorem 5.

**Pretraining distribution formulation.** We based on the in-context learning framework proposed by Xie et al. [297]. In this framework, a latent concept $\phi$ from a concept space $\Phi$ defines a pretraining distribution $p$ over prompt tokens $o$ observed from a vocabulary $O$. To generate the desired content, we first sample a concept from a prior $p(\phi)$ and then sample the tokens conditioned on the concept. We denote the total length of the pretraining examples as $T$:

```
$p(o_1, \dots, o_T) = \int_{\phi \in \mathcal{O}} p(o_1, \dots, o_T|\phi)p(\phi)d\phi.$
```

The conditional probability $p(o_1, \dots, o_T)$ is defined by a Hidden Markov Model (HMM). Based on the concept $\phi$, a transition matrix of the HMM hidden states $h_1,\dots,h_T$ from a hidden state space $\mathcal{H}$ can be found.

**Prompt distribution formulation.** During the in-context learning process, we sample a prompt from a new distribution $p_{prompt}$; which contains $n$ independent examples and 1 query example, which are all conditioned on a shared prompt concept $\phi^*$. The goal is to predict the next token based on a tokenized image feature $x_i = O_i[1:k_i]$, a text to describe the claim of the image $y_i = O_i[k_x : k_x + k_y]$, and a binary prediction to judge whether the claim of the image is "True" or "False", which is denoted by $z_i = O_i[k_x + k_y : k_x + k_y + 1]$ at the end of each example. The generating process of this i-example is follows:

- (1) Generate a start hidden state $h^{start}$ from prompt distribution $p_{prompt}$
- (2) Given $h^{start}$, generate the exemplar sequence $O_i = [x_i, y_i, z_i]$ from $p(O_i|h^{start}, \phi^*)$, the examples are conditioned on a given prompt concept $\phi^*$.

The query example Q is similarly sampled without the binary prediction $z_q$, i.e. $Q = [x_q, y_q]$. Between each exemplar and the query example, there is a special delimiter $o^{delim}$ denoting the end of each exemplar sequence. The prompt can be formulated as follows:

```
$[S_n, Q] = [x_1, y_1, z_1, o^{delim}, x_2, y_2, z_2, o^{delim}, \dots, x_n, y_n, z_n, o^{delim}, x_q, y_q] \sim p_{prompt},$
```

where $S_n$ denotes the $n$ independent exemplars for in-context demonstration.

**Denoising In-context learning task.** In our in-context learning, the output prediction $z$ for each image and text pair $[x, y]$ is sampled based on the prompt $P_{prompt}(z|x, y):$

```
$z_q \sim p_{prompt}(z|x, y) = \mathbb{E}_{h_{start}^{prompt}(h_{start}^Q)}p[z|Q, h_q^{start}, \phi^*)], \quad (7.50)$
```

$h_q^{start}$ denotes the hidden state corresponding to the first token of $Q$, i.e. of $x_q$.

Our goal is to analyze the in-context predictor $f_n(x_q, y_q) = \arg max_z p(z|S_n, x_q, y_q)$ which outputs the most likely prediction over the pretraining distribution $p$ conditioned on the exemplars $S_n$ sampled from the prompt distribution $p_{prompt}$. We assume the predictor is trained by $0-1$ error with $n$ training examples:

```
$\mathcal{L}_{0-1}(f_n) = \mathbb{E}_{x_q,y_q} \sim p_{prompt}[1[f_n(x_q) \neq y_q]], \quad (7.51)$
```

and same for the prediction $\hat{z}_q$:

```
$\mathcal{L}_{0-1}(f_n) = \mathbb{E}_{x_q,z_q} \sim p_{prompt}[1[f_n(x_q, y_q) \neq z_q]]. \quad (7.52)$
```

One major difference of our denoising learning strategy is that we not only use positive exemplars that show exact image-text match, i.e. $(x, y) = p(x, y) = p_{prompt}(x, y)$, we also have negative exemplars where image and text are not corresponding to each other. To construct such a prompt, we have to first select the ideal $y$, based on the matching result of $x$ and $y$, we can further obtain the prediction $z$. Therefore, in the following theoretical proof, we propose to conduct two-step analyses on $y$ and $z$, respectively.

### 7.3.1 Assumptions

Our theoretical framework is built upon Xie et al. [297], whose assumptions are also applied to our analysis.

**Assumption 16 (Delimiter states).** Let the delimiter states $\mathcal{D}$ be a subset of $\mathcal{H}$. For any $h^{delim} \in \mathcal{D}$ and $\phi$, $p(o^{delim}|h, \phi) = 1$ and for any $h \notin \mathcal{D}$, $p(o^{delim}|h, \phi) = 0$.

**Assumption 17 (Bound on delimiter transitions).** For any delimiter state $h^{delim} \in \mathcal{D}$ and any $h \in \mathcal{H}$, the probability of transitioning to a delimiter state under $\phi$ is upper bounded $p(h^{delim}|\phi) < c_2$, and for $\phi^*$, $p(h^{delim}|\phi^*) > c_1$.

**Assumption 18 (Distribution shift from prompt start).** We assume that the prompt start distribution $p_{prompt}$ is close in TV distance to all transition distributions (under $\phi^*$):

```
$$\max_{h \in \mathcal{D}} TV(p_{prompt}(h)|p(h^{delim}, \phi^*)) < \tau/4.$$
```

Here, $\Delta = p_{max}(y_{max}|Q) - \max_{y} p_{prompt}(y|Q)$ is the margin between the most likely label $y_{max}$ and the second most likely label.

**Assumption 19 (Well-specification).** The prompt concept $\phi^*$ is in $\Phi$.

**Assumption 20 (Regularity).** The *pretraining* distribution $p$ satisfies: (1) Lower bound on transition probability for the prompt concept $\phi^*$: for any pair of hidden states, $h, h' \in \mathcal{H}$, $p(h|h', \phi^*) > c_2 > 0$. (2) Start state lower is bounded: for any $h \in \mathcal{H}$, $p(h|\phi^*) > c_8 > 0$. (3) All tokens can be emitted: for every symbol $o$, there is some hidden state $h \in \mathcal{H}$ such that $p(o|h, \phi^*) > c_6$, (4) The prior $p(\phi)$ has support over the entire concept family $\Phi$ and is bounded above everywhere.

**Assumption 21 (Distribution consistency).** The *pretraining* distribution $p$ and prompt distribution $p_{prompt}$ satisfies $\sqrt{(x_q, y_q)} \sim p_{prompt}, p(x_q, y_q) = p_{prompt}(x_q, y_q)$.
