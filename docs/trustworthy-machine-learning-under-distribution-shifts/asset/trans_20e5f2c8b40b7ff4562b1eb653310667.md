# 引言

## 1.1 背景

机器学习 (ML) 是人工智能 (AI) 最有效的方法之一，它利用统计工具来发现、识别和利用数据中的模式，它提供了理论基础和实用工具，导致了人工智能的繁荣。

早期 AI 革命由深度神经网络 [1] 领导，例如 AlexNet [2]、ResNet [3] 和 DenseNet [4]，它们证明了 AI 在视觉识别任务上可以超越人类智能。2017 年，Google 引入了 Transformer 架构 [5]，使得模型能够并行处理大量的文本 [6] 以及视觉标记 [7]，从而扩大了信息处理的规模。基于这种架构，人们已达成共识，仅扩大扩大规模就能不断带来性能提升，这被称为缩放法则（Scaling Law [8]）。
