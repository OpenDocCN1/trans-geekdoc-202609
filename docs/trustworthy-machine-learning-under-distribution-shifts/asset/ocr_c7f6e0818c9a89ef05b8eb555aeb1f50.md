many popular methods. For instance, to use IRM [69], the regularization term is

```
$$\mathcal{L}_{reg} = \frac{1}{mn} \sum_{x \in \mathcal{X}} ||\nabla_{h|h=1}\mathcal{L}_{cee}(f_{\theta_{inv}}(\mathbf{x}), y)||^2.$ $\quad (4.7)$
```

To implement REx [144], we penalize the variance as

```
$$\mathcal{L}_{reg} = \frac{1}{mn} \sum_{x \in \mathcal{X}} Var(\{\mathcal{L}_{cee}(f_{\theta_{inv}}(\mathbf{x}), y)\}_{d=1}^m.$ $\quad (4.8)$
```

Moreover, we can focus on the worst-case variance to realize DRO [163, 125]:

```
$$\mathcal{L}_{inv} = \min max_{\theta_{inv}} \frac{1}{n} \sum_{x \in \mathcal{X}} \mathcal{L}_{cee}(h_{\theta_{inv}}(\mathbf{x}), y).$ $\quad (4.9)$
```
