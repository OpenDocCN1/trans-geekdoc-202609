```
$I(X^0; X^1) \geq \int dx^0 dx^1 dv p(x^0|x^1)p(v|x^1) \log q(x^0|v)p(v|x^1), \quad (6.7)$
```

which is realized by sampling from the joint distribution, the latent variable from our encoder $p(v|x^1)$, and the tractable variational approximation $q(x^0|v)$.

Similarly, we can upper-bound the second term $I(X^0, X^1|Y)$:

```
$I(X^0, X^1|Y) \leq \int dx^0 dx^1 dy p(x^0, x^1, y) \log p(y|x^1)p(x^0|x^1)p(x^1) - \log h^0(y|x^0). \quad (6.8)$
```

where $h^0(y|x^0)$ is our classifier model for predicting OOM data. To this end, we can lower-bound our objective by combining Equations (6.7) and (6.8):

```
$I(X^0; X^1) \geq \int dx^0 dx^1 dv p(x^0|x^1)p(v|x^1) \log q(x^0|v)p(v|x^1) \quad (6.9)\n- \int dx^0 dx^1 dy p(x^0, x^1, y) \log p(y|x^1)p(x^0|x^1) + \log h^0(y|x^0) = \mathcal{L}_{con}.$
```

The above bound contains two parts: (1) OOM data reconstruction where we reconstruct $X^0$ using the latent $V$ and (2) OOM data prediction where we model the label distribution $Y$. In practice, we can approximate $p(x^0, x^1, y)$ using empirical samples from IM and OOM data. Moreover, we encoder $p(v|x^1)$ without any prior assumptions because we can leverage the feature distribution from the pre-trained IM perceptors.
