# 7 PROOFS AND THEORETICAL ANALYSES

Here we simplify the expectation on samples from distribution $e$ as $E^e$.

```
$E^e\left[y^e Y^e\right] = E^e\left[\text{sgn}\left(\\frac{1}{M}\mathbf{m}^T Z^e\right) Y^e\right]\n= \sum_{y\in\{-1,1\}} \mathbb{P}\left[Y^e=y\right] \mathbb{P}\left[\text{sgn}\left(\\frac{1}{M}\mathbf{m}^T Z^e\right)\\mid Y^e=y\right] y.\quad(7.35)$
```

```
$E^e\left[\text{sgn}\left(\\frac{1}{M}\mathbf{m}^T Z^e\right)\\mid Y^e=1\right]=\mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e > 0\\mid Y^e=1\right]-\mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e \le 0\\mid Y^e=1\right]\n=2\mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e > 0\\mid Y^e=1\right]-1.\quad(7.36)$
```

Similar to Zhang et al. [183], we observe that:

```
$\mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e \le 0\\mid Y^e=1\right]=\mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e > 0\\mid Y^e=1\right],\quad(7.37)$
```

and plug (7.37) into (7.35) to get:

```
$Err^e = \mathbb{P}\left[\frac{1}{M}\mathbf{m}^T Z^e \le 0\\mid Y^e=1\right].\quad(7.38)$
```

Similar to Equation (7.33), we further decompose Equation (7.38):

```
$Err^e = \mathbb{P}\left[\frac{1}{M_{inv}}\mathbf{m}_{i\in[0,M_{inv}]}Z_{inv}^e+\frac{1}{M_{var}}\mathbf{m}_{i\in[M_{inv},M_{var}]}Z_{var}^e \le 0\\mid Y^e=1\right]\n\le \mathbb{P}\left[\frac{1}{M_{inv}}\mathbf{m}_{i\in[0,M_{inv}]}Z_{inv} \le 0\right]+\mathbb{P}\left[\frac{1}{M_{var}}\mathbf{m}_{i\in[M_{inv},M_{var}]}Z_{var}^e \le 0\\mid Y^e=1\right].\quad(7.39)$
```

Since all elements in $Z_{inv}$ are equal, the first term equals 0, the equality also holds. Then, we have:

```
$Err^e = \mathbb{P}\left[\frac{1}{M_{var}}\mathbf{m}_{i\in[M_{inv},M_{var}]}Z_{var}^e \le 0\\mid Y^e=1\right].\quad(7.40)$
```

Here we assume element of $Z^e$ and $\mathbf{m}_i$ are independent with each other, we can have $Err^e = \mathbb{P}\left[\mathbf{m}_i Z_{var,i}^e \le 0\|mid Y^e=1\right]$. It is obvious that there is only one situation when the error occurs, i.e., $\mathbf{m}_i=1$ and $Z_{var,i} \le 0$. In this scenario, the sparse training strategy would update the value to 0.
