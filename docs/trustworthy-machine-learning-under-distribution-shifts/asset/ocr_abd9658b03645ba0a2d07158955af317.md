# 4.5 EXPERIMENT

All experiments are conducted on a single NVIDIA 3090 using PyTorch. To implement our EVIL framework, we first pre-train the models using ERM for 1,000 iterations. Then, a mask m is initialized by the weight value. Specifically, by setting a sparsity ratio R, we can select parameters $R|	heta$-largest weights by setting their corresponding mask value as 1. During parameter exploration, we pass the gradient of invariant learning loss $\mathcal{L}_{inv}$ which we can sort the invariant parameters with their gradient magnitude from largest to smallest. Then, we reject the $S(t, \alpha, T)$-invariant parameters by setting their corresponding mask to 0. Similarly, we use the gradient of $\mathcal{L}_{var}$ to sort the variant parameters and collect top-$S(t, \alpha, T)$. During invariant learning, we can apply the mask to parameter values as well as their corresponding gradients to conduct sparse training.

To optimize our model, we use Adam [209] optimizer with an initial learning rate $1e-3$ without decay. Moreover, to avoid the conflict between optimizing invariant parameters and variant parameters, we adopt two Adam optimizers, denoted as $Adam_1$ and $Adam_2$, to correspondingly include the invariant and variant parameters. Moreover, $Adam_1$ would include the class prediction $h$ and $Adam_2$ would include the distribution prediction $g$, as illustrated in Figure 4.3. During the training, $Adam_1$ is mainly used to optimize the invariant parameters, but $Adam_2$ is just employed to optimize the variant ones.

For implementing baseline methods, we mainly follow [176] to set the hyperparameters. Specifically, for DRO, we set $\eta = le-2$ to update the group importance. For ERM, we set $\lambda = 1e^2$ to trade off the invariant regularizer. The similar $\lambda$ for penalization from REx is set to $1e$. For CORAL and MMD, set the trade-off weight $\gamma$ as 1. For implementing SagNet, we set the weight for adversarial loss as 0.1. For SAM, we do not use Adaptive SAM [210] and set the perturbation magnitude $ho$ as 0.05.
