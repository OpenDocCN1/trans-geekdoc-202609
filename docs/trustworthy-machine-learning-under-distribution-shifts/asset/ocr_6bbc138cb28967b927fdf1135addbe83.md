Then combining with Equation (7.99):

```
$\mathbb{E}_{p(x_1^l,x_2^l)}[d(h_1^*, h_2^*)] \leq I(X^O, X_1^l, Y|X_1^l) + I(X^O, X_1^l, Y|X_2^l) + 2I(X^O, Y|X_1^O, X_2^O) \quad (7.101)$
```

Finally, based on the decomposition of the task-related mutual information of $X^O$:

```
$I(X^O, Y) = I(X^O, X_2^l, Y|X_1^l) + I(X^O, X_1^l, Y|X_2^l) + I(X^O, Y|X_1^l, X_2^l) + I(X^O, X_1^l, X_2^l), \quad (7.102)$
```

as shown in Figure 6.3, we can achieve:

```
$\alpha(h_1^*, h_2^*) := \mathbb{E}_{p(x_1^l,x_2^l)}[d(h_1^*, h_2^*)] \leq I(X^O, Y) - I(X^O, X_1^l, X_2^l, Y) + I(X^O, Y|X_1^l, X_2^l), \quad (7.103)$
```

$\square$
