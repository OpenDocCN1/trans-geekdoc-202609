**Ablation Study.** By eliminating the worst-case data selection, we recover the original sharpness minimization method SAM [137]. Then, we remove the sharpness modification module, which is basically training via GroupDRO. The ablation results are shown in Table 3.5. We can see that deploying SAM on the whole dataset can achieve improved results on the clean dataset. However, the robust performance on corrupted distributions is even worse than GroupDRO. This could be because sharpness is to be dominated by principal distributions, which is misleading for small distributions. Thus, the sharpness of corrupted data would be sub-optimal. As for GroupDRO, it fails to produce a flat loss, hence it cannot generalize as well as the proposed SharpDRO.

**Distributional Stability** To show our method can be stable in the most challenging distributions, we include corruption severity from 0 to 5. As shown in Figure 3.4, SharpDRO not only produces the smallest norm value but also ensure almost equal norm across all corruptions, which indicates that SharpDRO is the most distributionally stable method among compared methods.
