To enable further quantitative analysis, we obtain the logits of “True” and “False” tokens from the MLLM output $z_0$ followed by a softmax function:

$z_0 := \text{softmax}([z_0[True], z_0[False]]). \quad (5.3)

Finally, we combine $z_0[True]$ and the prediction confidence of the vision model to obtain a detection score $\Delta$:

$\Delta = \frac{1}{2}(z_0[True] + \max [f_{o, \cdot}](x^{output})). \quad (5.4)

If $\Delta$ is larger than a threshold $\delta$, we assume the current prediction “PRE#” is correct$^5$, otherwise, we continue the next Therapy process.

**Therapy.** During therapy, we continue to use the instruction template above to traverse across the rest class candidates. Particular, for each iteration $e$ in $\mathcal{N}-1$ trials, we choose “$CLN\#c$” as the positive class and “PRE#” as the negative class, whose exemplars are comprehensively retrieved from $\mathcal{D}^{supp}$ to construct the prompt. Then, it is into MLLM to output the query image belongs to the class “$CLN\#c$”, i.e., $z_c = \theta_{mll}((X_{CLN}\#c,Y_{CLN}\#c); (X_{PRE}\#0,Y_{CLN}\#c):X_q)$,let $z_c := \text{softmax}([z_c[True], z_c[False]])$.

As a result, we decide the final prediction:

$y_{mllm} = \arg \max [z_e[True]]^N_{e=0}. \quad (5.5)
