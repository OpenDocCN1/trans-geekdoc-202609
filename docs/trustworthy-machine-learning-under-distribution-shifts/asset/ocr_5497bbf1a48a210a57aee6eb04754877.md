Therefore, Out-Of-Distribution (OOD) generalization [176, 177, 151] thrives as a promising direction that aims to enhance model robustness against unknown distribution shifts.

In order to achieve OOD generalization, one mainstream methodology is invariant learning [69, 143, 178, 144], which enforces extracting invariant features to help make consistent predictions across various data distributions (or domains), while avoiding distribution-specific features that are irrelevant to help information. Recent advances based on Lottery Ticket Hypothesis (LTH) [179, 180, 181] show that sparse training by learning task could select some critical parameters as a subnetwork, which are strongly responsible for invariant learning [182, 183, 184]. However, in OOD models, the sparsification guided by the learning task is problematic because the distribution noise could be erroneously incorporated into the optimization of sparse learning. As a consequence, existing methods fail to identify a robust subnetwork that is stable across different distributions.
