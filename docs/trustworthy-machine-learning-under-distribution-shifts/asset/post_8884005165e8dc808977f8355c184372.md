we optimize OOM learners via

```
\min_{h^o} \mathcal{L}_{\text{uns}} := \frac{1}{|\mathcal{A}|} \sum_{(x,y) \in \mathcal{A}} \text{CE}(h^o(x_u^o), y) + \frac{1}{|mathcal{A}|+|mathcal{D}|} \sum_{x \in \mathcal{D}} \sum_{y \in \mathcal{A}} \text{KL}(h^o(x_q^o); h_1^*, h_2^*),
```

$\mathcal{A}$ denotes the updated anchor points which are realized by sorting the Euclidean distance: $\mathcal{A} := \text{SORT}(\{(g_i^o, y_i)\}_{i=1}^M, \min_{i \in\{1..N\}} \frac{1}{K} \sum_{k=1}^K \|z_i^o - v_{k,i}\|);$ where the first term computes the cross-entropy loss from the anchor points, and the second term calculates the KL divergence between the OOM data with modal disagreement and the anchor points.

After these two steps, we can effectively tackle the unsupervised OOM generalization. In practice, we connect modalities and select anchor points in the feature space, and hence our application to both scenarios can be efficient. In the next section, we carefully conduct extensive experiments to justify the effectiveness and extensibility of the proposed COX method under various settings.

## 6.4 Experiment

In our experiments, we first elucidate the experimental details. Then, we provide performance comparisons to various baseline methods on different datasets. Finally, we conduct empirical analyses to provide an intuitive understanding of the proposed method.

### 6.4.1 Implementation Details

**Datasets.** We consider datasets with at least three modalities: (1) TV dataset [344] contains tactile sensing, RGB image, and class name which can be transformed into language; (2) LLVIP [345] dataset has infrared thermal data, RGB image, and annotations for pedestrian estimation. We follow [329] to crop the pedestrian and background which stand for two classes. Further, we use the OpenAI tooltip [225] to create language description; (3) NYU-D dataset [346] contains RGB image, depth data, and class name that can be transformed into language description as well; (4) VGGS dataset [347] includes video data, corresponding sound, and the language description; (5) MSR-VTT [348] includes videos and text description, we break down the videos into video frames and the audio data; (6) MOSEI dataset [349] contains videos from 7 classes of emotions, we extract audio data from the videos and use the emotion type to create language descriptions.

**Models.** We employ two types of IM perceptors, ImageBind [294] and Language-Bind [329] which correspondingly contain 6 and 5 encoders to process different modalities. We select one modality for each experiment as OOM and then choose the rest as IM. For IM data, we use the existing encoders to extract their features. For OOM data, we conduct preprocessing to ensure its compatibility. Then, we initialize an OOM learner from scratch using ViT-T/16 to learn from the OOM data using IM perceptors. Note that for the TVL dataset, there are no existing encoders to process tactile modality. Therefore, when the tactile modality is chosen as IM data, we fine-tune the encoder using contrastive learning on the training set. For ImageBind, the tactile encoder is aligned with the image encoder, which is the same as the original training process. For training the connection between modalities, we employ multi-layer perceptrons to realize the variational bottleneck framework. Moreover, to obtain the optimal classifier from each-modality, we utilize the extracted features and train a linear layer as classification heads.

**Setup.** We consider two scenarios of OOM generalization: For the semi-supervised case, we sample 10% of the training data as labeled data with each class having a balanced number of labels. For the unsupervised case, we have no labels at all. For selecting the number of anchor points, we choose the same number of examples for the warm-up and training phases, which is 10% of the total setting. We use an initial learning rate of $1e-3$ with weight decay $1e-5$, and train for 50 epochs.

**Baseline methods.** Since there is no existing baseline method to compare with under our setting, we implement four methods for comparison, namely: Where the model is randomly initialized, ERM when only labeled data is used to minimize the empirical risk, EntMin [350] which minimize the entropy of unlabeled data meanwhile conduct ERM, SSL which conducts self-supervised learning using Gaussian noise perturbation on the input, and MoCo [351] which updates model parameters with ensembling and meanwhile conducts contrastive learning.
