# I. INTRODUCTION

The majority of conventional systems consider the recommendation procedure as a static process. In other words, the system cannot provide feedback to the users. On the other hand, the interactive recommendation systems can dynamically modify the model based on user feedback. Some works [15–17] demonstrate that users' preferences may change. However, the existing works have two limitations:

Firstly, rethink ranking function to produce the Top-N recommendation list. Secondly, focusing on recommendation accuracy cannot evaluate metrics sufficiently.

This paper proposes a reinforcement learning based system by utilizing Actor-Critic architecture to model dynamic users' interaction with the recommender to maximize cumulative reward. Furthermore, we utilize Spotify’s Attention algorithm to find the most similar items generated by action history so that the Total Diversity Ranking is used to improve relevance and diversity. Moreover, we employ personally to compute representations of the user's interaction sequence. The major contributions of this paper are:

- We propose a framework based on deep reinforcement learning which generates both relevance and diversity.
- In order to reduce redundancy in the list, we use attention algorithm to find similar items.
- Instead of using RNN, we use positional encoding to represent user's sequence.

# II. RELATED WORKS

## A. Reinforcement Learning

Sham et al. [13] utilized a Markov decision process (MDP) to model recommendation procedure as a reinforcement learning problem. Hu et al. [21] formulated the sequential decision problem using search decision method (SSMD) and the deterministic policy gradient (DPG) to learn optimal policy. Zheng et al. [22] proposed a DQN-based model for recommendation.

## B. Diversity

The maximal marginal gain (MMG) [23] was one of the earliest works to promote diversity. Ziegler et al. [24] proposed a method to increase the diversity of recommendation using the intra-list similarity (ILS). Bridge et al. [25] measured the distance between items using Hamming Distance, which enhanced the diversity of recommendation. Lathia et al. [27] showed the importance of diversity in recommendation systems by proposing an approach to measuring collaborative filtering changes. Abbasi et al. [28] proposed a matrix constraint method to increase the diversity of representation. Premchaadi et al. [29] proposed a method named Total Diversity Ranking (TDE) which increases the diversity of effect of each item. Lee et al. [30] constructed a strongly-connected and undirected graph that has no cycle, and each edge represents positive interactions between items. Chang et al. [31] modified the recommendation framework in the system as a supervised task and formulated this recommendation task as two optimization problems. Wang et al. [31] proposed a novel method named DivRec_Ish using Locality-Sensitive Hashing (LSH). Lu et al. [32] developed the determinant point process (DPP) for promoting diversity in recommendation.
