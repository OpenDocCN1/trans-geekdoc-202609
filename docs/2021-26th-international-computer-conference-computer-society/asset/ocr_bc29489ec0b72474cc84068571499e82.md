Secondly, these methods [15][17] on recommendation accuracy, the system may only offer a narrow range of user' interests, by only offering sci-fi movies which is known as overfitting. In this paper, to tackle these problems, we propose a method to diversifying deep reinforcement learning-based recommendation system named DLRR, using Actor-Critic architecture. More specifically, to capture user's sequential behavior, we use attention mechanism [18] to represent the user states (i.e., the latent features of users's interest) and then, we use the actor-network, which generates a continuous vector as a proto-action. This proto-action is used to find similar items using ANNoy [19]. The TD algorithm [20] is used to select Top-N items with the highest diversity. Q-value (the maximum reward of the proto-action in the current state) is used to update actor and critic network weights. Experiments on the MovieLens dataset demonstrate that the diversity of recommendation is increasing. The major contributions of this paper are in three folds :

+   - We propose an interactive framework based on deep reinforcement learning, which generates the recommendation list concerning both relevance and diversity.
- In order to reduce redundancy in the recommendation list, we propose to find similar items using the ANNoy algorithm and then select Top-N items with the highest diversity.
- Instead of using RNN to capture user's sequential behaviors, positional encoding to compute representations of the user's interaction sequence.

# II. RELATED WORKS

# A. Reinforcement Learning

Sham et al. [13] utilized a Markov decision process (MDP) formulation to model sequential decision problems in recommendation systems using a n-gram model for the item model. Zhao proposed a novel list-wise recommendation model based on deep reinforcement learning. LIRD models the interactive recommendation system as a Markov Decision Process. Hu et al. [21] to formulate a ranking control problem in E-commerce using the search decision method (SSMD) and the deterministic policy gradient (DPG) to learn an optimal ranking policy. Zheng et al. [22] proposed a DQN-based reinforcement learning model for news recommendation, which explicitly model futures and effective exploration strategy, to improve the diversity of the recommendation. Liu et al. [15] proposed a novel deep reinforcement learning framework named DRR, which explicitly model user-interactions.

# B. Diversity

The maximal marginal gain (MRR) [23] was one of the earliest works to maximize relevance and diversity in re-ranking items used in text summarization. Ziegler et al. [24] proposed a method to increase the diversity of recommendation by using the intra-list similarity (ILS). Bridge et al. [25] measured the distance between items using Hamming Distance, which enhanced the diversity of recommendation by considering collaborative data. To maximizing the diversity of the recommendation without sacrificing the relevance to the user, Zhang et al. [26] modeled these as a bi-criterion optimization problem. Lathia et al. [27] showed the importance of diversity in recommendation systems by proposing an approach to measuring the diversity of collaborative filtering changes over time. Abbasi et al. [28] proposed a matrix constraint method to increase the diversity of representation. Premchaadi et al. [29] proposed a method named Total Diversity Ranking (TDE) which increases the diversity of effect of each item. Lee et al. [30] constructed a strongly-connected and undirected graph that has no cycle, and each edge represents positive interactions between items. Then utilizing the quality-based recommendations by relevance. Chang et al. [31] modified the recommendation framework in the system as a supervised task and formulated this recommendation task as two optimization problems. Then proposed a diversified filtering method to solve the optimization problems. Wang et al. [31] proposed a novel method named DivRec_Ish to produce diverse recommendations by using Locality-Sensitive Hashing (LSH) technique. Lu et al. [32] developed the determinant point process (DPP) for promoting diversity in recommendation.
