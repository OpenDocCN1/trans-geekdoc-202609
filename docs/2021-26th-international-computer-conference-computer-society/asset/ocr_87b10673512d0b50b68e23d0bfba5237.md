encoding.

# V. CONCLUSION

In this paper we proposed a deep reinforcement learning system DRLIB which generates the recommendation list concerning both relevance and diversity. Unlike previous works, which had redundant computation in the recommendation system, we propose to use an approximate nearest neighbor search (ANN) method to find the closest items to the proto-action and then generate a diverse list using the TDE algorithm.
