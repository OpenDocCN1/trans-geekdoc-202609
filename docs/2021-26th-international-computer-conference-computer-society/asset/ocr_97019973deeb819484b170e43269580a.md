**Abstract—Recently**, interactive recommendation systems based on reinforcement learning have been addressed by researchers to consider the recommendation procedure as a dynamic process and update the recommendation model in immediate user feedback, which is neglected in traditional methods. The existing works have two significant drawbacks. Firstly, rethink ranking function to produce the Top-N recommendation list. Secondly, focusing on recommendation accuracy cannot evaluate metrics sufficiently. This paper proposes a reinforcement learning based system by utilizing Actor-Critic architecture to model dynamic users' interaction with the recommender to maximize cumulative reward. Furthermore, we utilize Spotify’s Attention algorithm to find the most similar items generated by action history so that the Total Diversity Ranking is used to improve relevance and diversity.
