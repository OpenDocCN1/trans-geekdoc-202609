# D. The Critic Network

As shown in Fig. 1, the critic network takes (state $s_i$, action) pair and outputs the action value function $Q(s, t)$, namely $Q$-function denotes the density of generated action $a_i$ in $s$ by following policy $\pi$. The critic utilizes a Q-network (DQN) with parameter $	heta^Q$, which uses a deep neural network as a function approximator. Therefore, the critic specifies the expected return from state $s_i$ by taking an action under policy $\pi$. We define the reward as follows:

> $Q(s_i, a_i) = E_t[r_i + \gamma Q(s_{i+1}, a_{i+1})]$

# E. Reward Function

The recomm receives reward $R(s_i, a_i)$ according to the diversity of the generated recommendation list and the user's feedback. The reward function directly affects the result of Eq. 7, which estimates the action-value function $Q(s_i, a_i)$. Therefore, we need to ensure the performance of the reward function during training. In this paper, we define reward as follows:

> $R(s_i, a_i) = Diversity(t).Rating(t) - \lambda_1\lambda_2$
