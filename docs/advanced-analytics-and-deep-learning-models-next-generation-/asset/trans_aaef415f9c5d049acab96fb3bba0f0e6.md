

英语是当今世界的通用语言之一。它不仅是科学、技术、高等教育、航空、旅游和旅游业的语言，也是互联网和信息技术的语言。随着信息通信技术（ICT）\[1, 2\]的不断进步，英语教学和学习领域发生了前所未有的变化。技术的快速发展对教育领域，特别是语言习得和教学产生了重大影响。技术的巨大发展显著影响了教育领域，尤其是语言学习和教学。在语言教学中采用与当前技术趋势相结合的ICT是非同寻常的 \[3\]。通过在第二语言习得或外语学习中整合ICT，教学和学习变得更加容易、主动、个性化、真实和有效。它还导致了教学和学习过程的范式转变，以及教师角色的变化 \[4\]。

很久以前在20世纪30年代，人们就意识到了技术在第二语言学习中的应用的重要性，这促成了计算机辅助语言学习（CALL）的出现，CALL最初仅用于钻机练习。后来，随着技术的进步，CALL变得更加交互式，使用多媒体和语言实验室。此外，在21世纪，随着ICT的指数级增长，ICT的社会维度扩大，这导致CALL以Web 2.0工具、移动辅助语言学习（MALL）和网络学习（NL）的形式得到复兴，后来还有智能CALL（ICALL） \[5\]。话虽如此，人工智能（AI）在语言学习中的应用，以及计算语言学、机器学习和自然语言处理（NLP）的应用，才是关键。

本章讨论了人工智能在教育和语言学习中的潜在应用，特别是采用新的学习方法和教学修改。此外，它探讨了如何利用人工智能来增强语言学习体验，培养学习者的自主性和适应性。它还讨论了可以用于有效教授英语的人工智能工具。它专注于通过模仿声音模式、使用语音识别和语音编辑功能来教授发音和提高流利度，以及通过使用聊天机器人进行个性化语言学习。此外，本章集中讨论了嵌入人工智能的学习推理，以在外语学习中建立新趋势以及教师角色的转变。因此，本章的目的是提供一些关于人工智能如何用于改善语言学习体验的实质性例子，以及为什么语言教师应该拥抱并将人工智能融入教学过程，而不是害怕它。

## 1.2 CALL的演变

在20世纪60年代，听说法被引入英语教学（ELT），它基本上坚持钻机和练习，而将计算机融入语言教学和学习使这变得更加容易 \[6, 7\]。到20世纪，CALL对语言教学和学习产生了重大影响。20世纪60年代到80年代的CALL可以被称为结构性CALL，因为在此期间，用于语言学习的计算机主要用于钻机和练习。遵循结构主义方法和行为主义学习理论，计算机程序更多地关注结构化和死记硬背的学习，而不是交互性。在此期间，语法和句子结构的准确性是语言学习的主要目标。20世纪80年代到90年代的CALL的第二阶段被称为交际性CALL。在此期间使用的计算机主要用于构建练习以发展有效的交流。在此期间，计算机在语言学习中的整合不仅为了准确性，还为了实现流利度。它鼓励不仅与计算机，还与同伴学习者进行交互。从20世纪90年代到21世纪初，整合性CALL的特点是数字资源和互联网的访问增加 \[8\]。技术的进步和互联网的便捷访问鼓励教育工作者发明灵活的课堂语言学习课程，这些课程甚至可以在课堂外轻松访问。在21世纪初，整合性CALL继续对语言学习产生影响。Davies *et al.* 认为，该领域充满了那个时代的“Web 2.0热潮” \[9\]。这包括基于Web 2.0工具（如维基、社交网络网站、讨论板和虚拟世界）的大量新社区的出现。最好的例子是Facebook群组、Instagram和Twitter。

技术已成为我们生活不可或缺的一部分。它的存在无处不在，从我们醒来到入睡，以各种形式存在，如闹钟、智能手机、智能电视、智能空调、笔记本电脑、平板电脑、WhatsApp、YouTube等。技术在各个领域和各个教育层次都如此普遍，以至于我们无法想象没有它的任何形式的存在。当今世界上大多数语言学习者使用技术来获取第二语言和外语的材料，与世界各地的人交流，按照自己的节奏学习，并参加多种语言考试，如托福和雅思 \[10–12\]。技术帮助我们随时随地与世界上任何地方的人联系，因此语言学习者可以轻松地与更广泛的母语者网络联系起来，直接接触目标语言来学习语言。因此，可以说，ICT的重大发展改变了我们对学习的理解，并因此导致了从传统教学方法向网络化教学和学习的转变。

在语言学习和教学的背景下，值得注意的是，Warschauer和Kern提出了基于网络的语言教学（NBLT）的概念，该概念侧重于交流 \[13\]。根据Sharples *et al.*，以学习者为中心、个性化、交互式、协作式、情境化、终身和无处不在的新学习与新技术之间存在根本的相关性，新技术以移动、用户友好和无处不在而闻名 \[14\]。根据Jones，网络学习（NL）已成为一个重要范式，其中ICT被用于促进教师与学习者、学习者与其他学习者以及学习社区与其学习资源之间的互动和联系 \[15\]。此外，第四次工业革命以技术和数字应用的快速扩张为特征，正在影响我们生活的方方面面。人工智能影响了我们的生活和工作方式，从扫地、使用自动感应加热器、无人驾驶汽车到指挥Alexa。根据Manns，第四次工业革命正由人工智能、自动化和机器人领域新兴突破的整合和放大，以及数十亿拥有移动设备的人之间深远的连接所驱动，这些设备提供了无与伦比的数据和信息访问 \[16\]。此外，由于自然语言处理（NLP）的进步、网络学习（NL）的出现以及处理大量数据的技术能力，人工智能现在在语言研究方面有重大应用。

## 1.3 定义人工智能

人工智能（AI）是科学的一个分支，研究和开发旨在模拟人类智能过程的设备。人工智能的主要目标是提高常规过程的速度和效率。因此，全球实施人工智能的行业数量正在增长 \[17\]。
