## d. 决策树算法  

这些技术通过基于记录中特征的实际估计值来构建一系列选择。选项在树结构中分叉，直到为特定证据准备好预测选项。决策树通常快速、准确，并且是 AI 的主要首选。

最著名的决策树计算如下：

* `Classification and Regression Tree (CART)`
* `Iterative Dichotomiser 3 (ID3)`
* `C4.5 and C5.0 (various adaptations of an incredible methodology)`
* `Chi-Squared Automatic Interaction Detection (CHAID)`
* `Decision Stump`
* `M5`
* `Conditional Decision Trees`

## i. 深度学习算法  

它们是对 ANN 的前沿更新，利用了廉价的大量计算。

我们关注构建更高级、更复杂的神经网络，许多技术关注带有标记简单信息（例如图像、文本、声音和视频）的大型数据集。

## j. 降维算法  

与聚类策略类似，降维寻找并利用信息中的固有结构，但在这种情况下，是以单一方式或顺序来概括或描述信息，使用更少的数据。

这对于可视化维度信息或改进信息（然后可用于监督学习技术）可能很有用。许多这些策略可以调整用于分类和回归。

* `Principal Component Analysis (PCA)`
* `Principal Component Regression (PCR)`
* `Partial Least Squares Regression (PLSR)`
* `Multidimensional Scaling (MDS)`

## k. 集成算法  

这些技术是更脆弱的模型，独立训练，其期望以某种方式合并以产生共同预测。

大量精力用于整合弱学习者以及合并它们的方式。这是一个出色的策略类别，并且很著名。

* `Stacked Generalization (Stacking)`
* `Gradient Boosting Machines (GBM)`
* `Gradient Boosted Regression Trees (GBRT)`
* `Random Forest`

## A. 卷积神经网络  

这是最主流的应用 DL 案例之一。它们非常适合图像/视频处理应用。它们是主要用于分类（按接近度分组）的深度人工神经网络。这些计算可以区分面孔、人员、路标、肿瘤、花朵以及视觉信息的许多其他方面。自动驾驶汽车或机器人将扩展其能力的应用。主流的应用商业案例可能是光学字符识别（OCR），用于将文本数字化以自动化数据输入，如 [图 4.21](#c04.xhtml#fig4-21) 中的示例所示。

CNN 计算与人类大脑不同地看待图像。每张图像都是一个三维数字阵列，称为像素，具有宽度、高度和深度。宽度和高度取决于图像分辨率。第三个维度（深度）是颜色代码的红绿蓝（RGB）值（除非您使用黑白图像作为输入）。系统在应用 DL 时对图像的感知如 [图 4.22](#c04.xhtml#fig4-22) 所示。

深度学习 CNN 将这些图像通过一系列带有通道的卷积层处理（[图 4.23](#c04.xhtml#fig4-23)）。
