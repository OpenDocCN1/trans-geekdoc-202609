We can very quickly and easily print diagnostic plots for linear models in R by supplying the model data as the argument to `plot()`. Ordinarily this will prompt you to hit ENTER to cycle through the plots. I find this irritating so prefer to split the plotting device into four using the `mfrow` argument to the `par()` function. This means that when we create our diagnostic plots (there will be four of them), they will be tiled in the same plotting window. These plots may help us identify flaws in our model that are impacting predictive performance.
