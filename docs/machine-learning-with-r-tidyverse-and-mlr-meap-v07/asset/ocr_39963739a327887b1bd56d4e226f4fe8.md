Next, let’s train the random forest model using our tuned hyperparameters. Once we’ve trained the model, it’s a good idea to extract the model information and pass this to the plot() function to plot the out-of-bag error. Recall from chapter 8 that the out-of-bag error is the mean prediction error for each case, by trees that did not include that case in their bootstrap sample. The only difference between the out-of-bag error for classification and regression random forests, is that in classification the error was the proportion of cases that were misclassified, but in regression, the error is the mean squared error.



```
tunedForest <- setHyperPars(forest, par.vals = tunedForestPars$x)

tunedForestModel <- train(tunedForest, fuelTask)

forestModelData <- getLearnerModel(tunedForestModel)

plot(forestModelData)
```
