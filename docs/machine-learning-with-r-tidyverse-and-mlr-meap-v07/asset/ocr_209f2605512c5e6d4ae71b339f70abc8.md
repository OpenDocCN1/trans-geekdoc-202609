Then, we're going to tune the hyperparameters of our random forest learner: ntree, mtry, nodesize, and maxnodes. I first defined what these hyperparameters do in chapter 8, but let’s recap each one here:

+   • ntree controls the number of individual trees to train. More trees is usually better until adding more doesn’t improve performance any more
+   • mtry controls the number of predictor variables that are randomly sampled for each individual tree. Training each individual tree on a random selection of predictor variables helps keep the trees uncorrelated, and therefore helps prevent the ensemble model from overfitting the training set
+   • nodesize defines the minimum number of cases allowed in a leaf node. For example, setting nodesize equal to 1 would allow each case in the training set to have it’s own leaf
+   • maxnodes defines the maximum number of nodes in each individual tree

As usual, we create our hyperparameter search space using the makeParamSet() function, defining each hyperparameter as an integer with sensible lower and upper bounds.

We define a random search with 100 iterations, and start the tuning procedure with our forest learner, fuel task, and holdout cross-validation strategy.
