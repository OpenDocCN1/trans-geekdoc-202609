> **NOTE** Maybe I’ve been too hasty, as it’s possible we are only in a *local minimum*, the smallest MSE value compared to the values of lambda around it. When searching a hyperparameter space, there may be many local minima (plural of minimum), but we really want to find the *global minimum* which is the lowest MSE value across all possible hyperparameter values. For example, imagine that if we keep increasing lambda the MSE gets higher, but then starts to come down again, forming a hill. It’s possible that this hill continues to decrease even more than the minimum shown in figure 11.12. Therefore it’s a good idea to really search your hyperparameter space well to try and find that global minimum.
