I hope that de-mystifies UMAP’s hyperparameters a little, so let’s run UMAP on our Swiss banknote dataset. Just like before, I first select all the columns except the categorical variable (UMAP cannot currently handle categorical variables, but this may change in the future), and pipe this data into the as.matrix() function (just to prevent an irritating warning message). This matrix is then piped into the umap() function, within which I manually set the values of all four hyperparameters and set the argument verbose = TRUE so the algorithm prints a running commentary on the number of epochs (iterations) that have passed.



```
swissUmap <- select(swissTib, -Status) %>%
as.matrix() %>%
umap(n_neighbors = 7, min_dist = 0.1,
metric = "manhattan", n_epochs = 200, verbose = TRUE)
```
