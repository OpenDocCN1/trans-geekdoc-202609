Now let's train our final XGBoost model using our tuned hyperparameters. You should be starting to get familiar with this now. We first use setHyperPars() to make a learner, and then passing it to the train() function.

# Listing 8.6 Training the final tuned model

```
tunedXgb <- setHyperPars(xgb, par.vals = tunedXgbPars$x)
tunedXgbModel <- train(tunedXgb, xgbTask)
```
