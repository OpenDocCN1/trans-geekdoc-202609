# How to list all of mlr's algorithms

The mlr package has a large number of machine learning algorithms that we can give to the makeLearner() function, more than I can remember without checking! To list all the available learners, simply use:

```
listLearners()$class
```



```
listLearners("classif")$class
```

```
listLearners("regr")$class
```

```
listLearners("cluster")$class
```

If you're ever unsure which algorithms are available to you or which argument to pass to makeLearner() for a particular algorithm, use these functions to remind yourself.
