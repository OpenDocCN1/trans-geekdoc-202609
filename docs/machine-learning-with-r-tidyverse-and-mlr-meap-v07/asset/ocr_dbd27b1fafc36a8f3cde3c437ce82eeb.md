When we have a downward slope that meets this steepness criterion, the start of a cluster is defined, and when we have an upward slope that meets this steepness, the end of the cluster is defined.

> As cannot be estimated from the data, it is a hyperparameter we must select/tune ourselves.

Using this method has two major benefits. Firstly, it allows us to overcome DBSCAN’s limitation of only finding clusters of equal density. Secondly, it allows us to find clusters within clusters, to form a hierarchy. Imagine we have a downward slope that starts a cluster, then we have another downward slope before the cluster ends, we now have a cluster within a cluster.
