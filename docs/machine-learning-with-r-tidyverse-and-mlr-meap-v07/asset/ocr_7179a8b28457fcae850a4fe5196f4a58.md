Next, the algorithm chooses a case at random from the dataset, and calculates which node’s weights are the closest match to this case’s values for each of the variables. For example, if there was a case in the dataset whose values for var 1, var 2, and var 3, were 3, 9, and 1, respectively, this case would perfectly match the weights of node 1. To find which node’s weights are most similar to the case in question, the distance is calculated between each case and the weights of each node in the map. This distance is usually squared Euclidean distance. Remember that Euclidean distance is just the straight line distance between two points, so the squared Euclidean distance just omits the square root step to make the computation faster.
