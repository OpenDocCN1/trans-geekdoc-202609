# 5.2.3 Training the models

Let’s define our task and learner, and build a model as usual. This time, we supply `"classif.lda"` as the argument to `makeLearner()` to specify we’re going to use LDA.

> **TIP**
> 
> LDA and QDA have no hyperparameters to tune, and are therefore said to have a *closed form solution*. In other words, all the information LDA and QDA need is in the data.

> **TIP**
> 
> LDA is unaffected by variables on different scales. It will give the same result whether the data are scaled or not!
