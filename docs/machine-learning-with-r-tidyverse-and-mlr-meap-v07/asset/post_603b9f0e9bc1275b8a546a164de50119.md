
If you have the common problem of having data that is time-consuming and/or costly to manually label, then you can probably benefit from the application of semi-supervised learning. To learn more, I would recommend Semi-Supervised Learning by Olivier Chapelle, Bernhard Schölkopf, and Alexander Zien (MIT Press, 2006).

If you're going to be working with spectral data, or data that can be represented by smooth functions, you're going to want a good grounding in functional data analysis that I briefly mentioned in chapter 10. Functional data analysis is where we use functions as variables in our models, rather than individual values. To learn more, I recommend Functional Data Analysis by James Ramsay (Springer, 2005).
