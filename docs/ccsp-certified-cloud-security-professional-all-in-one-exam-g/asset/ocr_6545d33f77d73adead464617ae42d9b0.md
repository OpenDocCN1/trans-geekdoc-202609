# Tools

Rather than focusing on specific software technologies or implementations for IRM, we will instead focus on the typical attributes and features of those tool sets and what they can provide for IRM and security:

+   **Auditing** IRM technologies allow for robust auditing of who has viewed information, as well as proof to when and where they accessed the data. Data can aid greatly with compliance requirements where an organization needs to ensure that an appropriate audience has a new policy or document, or where there is a need to provide solid evidence that only those entitled to access the data are the ones that have,

+   **Expiration** IRM technologies allow for the expiration of access to data. This gives an organization the ability to set a lifetime for the data and enforce policy controls that disable it to be accessible, as is the case in most systems data has been presented to users or is allowed to leave its host system and controls.

+   **Policy control** IRM technologies allow an organization to have very granular and detailed control over how their data is used and used. The ability to control, with different audiences can copy, save, print, forward, or access any data is far more powerful than what is afforded by traditional data security mechanisms. An IRM implementation also gives an organization the ability to change policy at any time, revoking or expiring data down the road if necessary. This gives the organization to ensure that users are always viewing the most current copy of data or policies as well to expire the old ones once are available.

+   **Protection** With the implementation of IRM technologies and controls, information under their protection is secure at all times. Unlike many systems, which require separate practices and technologies for data at rest versus in transit, IRM provides persistent protection at all times that is integrated with the data regardless of its current state.

+   **Support for applications and formats** Most IRM technologies support a range of data formats and integration with application packages commonly used within organizations, such as e-mail and office suites. This enables the integration of IRM systems and processes within the organization needing to make major changes to their current operational practices.
