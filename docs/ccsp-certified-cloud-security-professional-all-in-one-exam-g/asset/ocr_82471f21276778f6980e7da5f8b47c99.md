# Insufficient Due Diligence

When an organization is considering moving systems and applications from a tra-
ditional data center model to a cloud environment, they must evaluate a lot of variables
factors to determine if the move to a cloud system is appropriate and feasible. With-
out proper and thorough evaluation of their systems, designs, and controls, an organi-
ization expose themselves to more security risk and vulnerabilities
by moving to a cloud environment. For example, if an application or system has been
sec using a high degree of reliance on internal network designs or controls within a
data center, then moving that application or system to a cloud environment should note considered until an exhaustive study is conducted of what can be done in the
environment to change the design of the system or put in place similar mitigating\controls within the cloud. Moving in a rush to a cloud environment will likely expose ansystem or application to security threats and vulnerabilities that are new and mitigated
against the current environment. The insufficient diligence threat applies to IaaS,
PaaS and SaaS models.

# Abuse and Nefarious Use of Cloud Services

Cloud environments have vast and enormous resources as their disposal to be able
hand the load and systems of the large number of customers that host applications
and within their infrastructure. Although this threat isn't a particular concern to
cloud customers other than a little degradation of services, it is a very valid concern
and threat to cloud providers. Using a small or single system as a launching pad for other\attacks only provide limited resources to an attacker, but gaining access to a cloud envi-
ment and its enormous pool of resources is much more attractive, and as such the
cloud environment will be the target of far more sophisticated and coordinate attempts
to compromise it. It is incumbent on the cloud provider to ensure this threat is mitigated
and perform active monitoring to detect any instances of. The abuse of cloud ser-
vices applies to the IaaS and SaaS models.
