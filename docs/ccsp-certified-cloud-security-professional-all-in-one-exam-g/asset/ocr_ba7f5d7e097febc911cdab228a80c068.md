+   3. You are developing a new process for data discovery for your organization and are charged with ensuring that all applicable data is included. Which of the following is NOT one of the three methods of data discovery?

+   A. Metadata analysis

+   B. Content analysis

+   C. Labels

+   D. Classification

Classification is the overall process of using certain attributes about data and then applying appropriate security controls to data. Classification is applied after data discovery has been completed, and it pertains only to the application of security controls, not the actual process of discovering or determining data.

A is incorrect because metadata is essentially about data. It contains information about the data, such as the type, how it is stored, how it is organized, how it was created, or how it is used. Metadata can also include headers and organizational markings, such as column or field names in a database or a spreadsheet.
