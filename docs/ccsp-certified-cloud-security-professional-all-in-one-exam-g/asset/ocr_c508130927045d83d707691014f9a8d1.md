+   15. In a cloud environment, who is responsible for collecting data in response to an eDiscovery order?

+   A. The cloud customer

+   B. The cloud provider

+   C. The data owner

+   D. The cloud customer and cloud provider

D. In a cloud environment, both the cloud provider and cloud customer are responsible for collecting data in response to an eDiscovery order. Depending on the scope of the eDiscovery order, as well as the specific cloud service category used, the degree to which it falls on either party will differ a bit.
