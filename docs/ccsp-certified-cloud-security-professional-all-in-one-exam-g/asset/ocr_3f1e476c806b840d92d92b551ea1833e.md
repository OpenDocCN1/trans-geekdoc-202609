# Data Discovery and Classification Techniques

Data discovery and classification techniques are very important concepts for both utilizing data and protecting it. Through data discovery, an organization can fully utilize their data in new and creative ways, while data classification is centered on using the proper security controls.

# Data Discovery

Data discovery is a business intelligence operation and a user-driven process where data is visually represented and analyzed to look for patterns or specific attributes. It is a bit from many data analysis operations because it heavily relies upon a user's expertise and experience to interpret and develop meaningful inferences from. Data discovery is an iterative process, where initial findings lead to a refinement of parameters and representation in order to drive deeper into the data and continue to scope it toward the objective desired.

Organizations can use a few tools and approaches to leverage data discovery that are especially pertinent to a cloud environment. Big Data implementations are becoming very common, especially within large cloud environments, and with them come the enormous volume of data and the ability to extensive data discovery.
