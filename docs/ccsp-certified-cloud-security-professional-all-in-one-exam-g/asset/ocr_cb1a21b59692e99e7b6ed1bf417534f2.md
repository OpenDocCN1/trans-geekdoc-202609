With each of these components, the vendor of the systems and software used will establish their own set of performance metrics, monitoring capabilities and techniques, and best practices for planning and implementation. A cloud environment not only must ensure that it can fully support each tenant currently but also support potential auto-scaling and growth. # Hardware Monitoring

While the focus in any cloud environment seems to be directed towards the virtual infrastructure and the resources used by it, the reality remains that underneath all is still physical hardware that has the same issues and concerns as traditional data center hardware. The same four components listed under performance monitoring also apply to these physical hosts.

As with monitoring any system, following the recommendations and best practices of the hardware vendors should be the starting point. Hardware, while similar among different vendors, is unique enough that each vendor will have their own recommendations and utilities used to monitor their systems. Wherever possible, the tools and utilities provided by the hardware vendor should be used as the primary source of monitoring, with additional capabilities added on top, if possible. In most cases, this data or utilities can be integrated into some types of tools and reporting agents that are used to monitor virtual systems and other appliances around the environment. This integration allows the same personnel monitoring systems to look at everything holistic level as well as homage to monitoring reports and alerting.

Cloud systems by nature are built around the principle of redundancy, which also brings the benefit of distributing load and having higher capacity than needed to run current operations. This also adds complexity to monitoring systems, as each physical host cannot be looked at in isolation, but must be analyzed in conjunction with the rest of the physical hosts serving the clusters or redundant pools. It also means that alerting must be flexible and responsive to conditions where components are removed or unavailable at any given time, due to unexpected circumstances or planned outages for upgrades or maintenance.
