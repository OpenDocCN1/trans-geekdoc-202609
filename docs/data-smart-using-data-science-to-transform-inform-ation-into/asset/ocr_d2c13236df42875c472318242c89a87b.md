In column G, you can calculate the closest group of customers using the MIN formula. For instance, for Adams, it's simply as follows:

```
=MIN(C2:F2)
```

And in column H, you can calculate the second closest group of customers using the SMALL formula (the 2 in the formula is for second place):

```
=SMALL(C2:F2, 2)
```

Likewise, you can calculate the distance to your own community members (which is probably the same as column G but not always) in column I as follows:

```
=INDEX(C2:F2, B2)
```
