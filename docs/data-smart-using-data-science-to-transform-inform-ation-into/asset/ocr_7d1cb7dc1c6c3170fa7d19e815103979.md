# Setting Up the Linear Program

Now everything is set up for optimization. Open the Solver window and specify that you’re maximizing the graph modularity score in cell G2. The decision variables are the community assignments in B2:B101, and their modularity scores are in C2:C101.

You need to add a constraint forcing the community assignments in B2:B101 to be binary. Also, you need to make the customer score variables in column C less than both the upper bounds in columns D and E.
