Let's set the name of this query. To do that, look to the right side of your screen under the Query Settings pane. From here, you'll see the Name field under the Properties header. Rename the query to AboutMandrillTokens.

Now, make sure the Tweet column is highlighted. On the Transform tab, select Format > Lowercase (see Figure 3.3).

Next, on the Transform tab, select Replace Values. In the Replace Values option box, type a period with a space after and a single space in the Value To Find box and a space in the Replace With box.
