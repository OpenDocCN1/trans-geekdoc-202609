The true positive rate is the ratio of correctly identified pregnant women divided by the total of actual pregnant women in the test set. Label cell E4 as **True Positive Rate**. In E5 then, you can calculate the true positive rate of a cutoff value of –0.35 as follows:

```
=LET(
    TruePositiveCount, COUNTIFS(
        TestSet[Linear Prediction], ">=" & A5, TestSet[PREGNANT], 1),
    AllPositiveCount, COUNTIF(TestSet[PREGNANT], 1),
    TruePositiveCount/AllPositiveCount
)
```

Looking back at the true negative rate column, this calculation is exactly the same except < becomes >= and 0s become 1s.
