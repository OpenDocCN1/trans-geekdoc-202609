**TIP**

Solver's constraint window buttons are not exactly intuitively named. If you hit the Add button, the constraint is added (off screen), and a new blank dialog box appears. The OK button will attempt to add whatever you've already filled in and then exit back to the main window. Cancel will ignore any input and exit back to the main window.

Make sure the solving method is set to Simplex LP (see Figure 1.25). Simplex LP is appropriate for this problem, because it's linear (the L in LP stands for linear). Linear problems are those we can solve using linear combinations. For instance, using SUMPRODUCT to multiply the calories counts by quantity is a type of linear combination. Simplex LP works best for these.³

When you're ready, confidently click the Solve button. Excel should find a solution almost immediately. You should see the Solver Results dialog box in Figure 1.28. Click OK to keep the results. Click Cancel to let the cells go back to their previous values.
