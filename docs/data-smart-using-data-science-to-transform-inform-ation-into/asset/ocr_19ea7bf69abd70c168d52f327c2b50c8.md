Starting in cell W4, you can run each row in the Test Set through each stump. The formula looks like this:

```
=N(CHOOSECOLS(TestBag,W1)=W2)
```

The interior part of this formula, CHOOSECOLS(TestBag,W1)=W2, pulls the winning column (W1) and tests every cell against the predicted pregnancy outcome. Finally, the N() converts this TRUE/FALSE result into 1s and 0s. Alternatively, you could write --(CHOOSECOLS(TestBag,W1)=W2) or (CHOOSECOLS(TestBag,W1)=W2) * 1.
