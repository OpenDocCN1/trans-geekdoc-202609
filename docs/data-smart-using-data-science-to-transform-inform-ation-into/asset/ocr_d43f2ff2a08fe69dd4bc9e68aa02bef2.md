# Touching the Graph Data

Let's now click the Data Laboratory button at the top of the screen. This switches the view to a table of values.

Note that there are two sections of data to choose from: Nodes and Edges. In the Nodes section you have all the folks in the Wine dataset. In addition, because you went through the Average Degree calculation earlier, a column for Degree has been added to the node dataset. If you want, you can export this column to Excel by clicking the Export Table button on the menu bar (see Figure 5.21).
