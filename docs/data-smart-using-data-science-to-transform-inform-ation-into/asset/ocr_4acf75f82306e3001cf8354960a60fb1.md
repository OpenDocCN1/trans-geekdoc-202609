You get a forecast with prediction intervals built in! And you can print the actual forecasting technique used by printing the method value in the sword.forecast object.

```
> sword.forecast$method
[1] "ETS(M,A,M)"
```

The MAM stands for multiplicative error, additive trend, multiplicative seasonality. The forecast() function has actually chosen to run Holt-Winters exponential smoothing! And you didn't even have to do anything. When you plot it, as shown in Figure 11.12, you automatically get a fan chart.

```
> plot(sword.forecast)
```
