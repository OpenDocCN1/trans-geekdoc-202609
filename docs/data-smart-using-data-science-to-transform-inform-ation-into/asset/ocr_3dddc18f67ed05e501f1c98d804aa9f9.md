On the Transactions tab, click anywhere in the Excel table (also named Transactions for consistency); then select Insert ▸ PivotTable. Put it into a new sheet and name that sheet Pivot. Using the PivotTable designer, place Offer # into the Rows field well, Customer Last Name in Column, and Customer Last Name in Values (this will take the count of each last name associated with a specific deal—which will be a 1 for a given deal).
