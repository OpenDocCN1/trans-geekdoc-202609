# Evaluating Metric Tradeoffs and the Receiver Operating Characteristic (ROC) Curve

In truth, there are no perfect models. Instead, there's an economy between what we want and what we can handle. In building this model, we will want to choose a threshold value for a binary classifier. It's important then to select the best balance of these performance metrics. To help us assess these performance trade-offs, we'll build what's called a receiver operating characteristic (ROC) curve, pronounced like “rock curve,” for short. Despite its seemingly out-of-place name, the ROC curve is nothing more than just a plot of the false positive rates versus the true positive rates (columns D and E in the Performance sheet). This will help us understand the inherent trade-offs between these two metrics.
