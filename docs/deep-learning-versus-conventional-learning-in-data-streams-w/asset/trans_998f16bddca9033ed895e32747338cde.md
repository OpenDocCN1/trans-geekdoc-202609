\(\begin{aligned} y^i(k) &= f_i(\mathbf{x}_k, \Theta_i) \\ &= a_0^i + a_1^i x_1(k) + \cdots + a_n^i x_n(k) \\ &= \begin{bmatrix} 1 & \mathbf{x}_k \end{bmatrix} \Theta_i^T, \quad i=1, \cdots, c \end{aligned} \tag{4}\)

其中，\(\Theta_i\) 是第 \(i^{th}\) 模糊规则后件部分的参数行向量。

FCRM 聚类算法的适应度函数定义为：

\(J_m = f(\Theta_i) = \sum_{i=1}^c \sum_{k=1}^N (u_{ik})^m E_{ik}^2(\Theta_i) \tag{5}\)

其中，\(E_{ik}(\Theta_i) = |f_i(\mathbf{x}_k, \Theta_i) - y(k)| = |\begin{bmatrix} 1 & \mathbf{x}_k \end{bmatrix} [\Theta_i]^T - y(k)|\) 是 \(f_i(\mathbf{x}_k, \Theta_i)\) 与建模输出 \(y(k)\) 之间的距离（误差度量）。隶属度函数 \(u_{ik}\) 和后件参数 \(a_j^i\)（如 (6) 和 (7) 所示）不能向最小化适应度函数的方向进行训练；因此，本文采用改进的 FCRM 算法 [29]。基于改进的 FCRM 算法，隶属度函数 \(u_{ik}\) 和后件参数 \(a_j^i\) 可以向最小化适应度函数的方向更新和变化。

\(u_{ik} = \left( \sum_{s=1}^c \left( \frac{E_{ik}(\Theta_i)}{E_{sk}(\Theta_s)} \right)^{\frac{-2}{m-1}} \right)^{-1}, \quad 1 \le i \le c, \quad 1 \le k \le N \tag{6}\)

\(a_j^i = \frac{\sum_{k=1}^n (u_{ik})^m (y^i(k) - \sum_{p \ne j} a_p^i \hat{x}_p(k)) \hat{x}_p(k)}{\sum_{k=1}^n (u_{ik})^m}, \quad 0 \le j \le n \tag{7}\)

其中，\([\hat{x}_0(k), \hat{x}_1(k), \dots, \hat{x}_n(k)] = \begin{bmatrix} 1 & \mathbf{x}_k \end{bmatrix} = [1, x_1(k), \dots, x_n(k)]\).

## C. 改进的聚类有效性准则

在系统辨识过程中，聚类数始终由用户决定。规则数量会影响参数数量和聚类的效果。因此，已提出不同方法 [12]、[30]、[31] 来搜索适当的聚类数。然而，大多数方法更适合超球形聚类算法。由于 FCRM 是超平面形算法，本文采用改进的聚类有效性准则 [32] 来搜索适当的规则数。聚类有效性准则由紧密度-分离度比定义，分子反映超平面形聚类的紧密度，分母表示超平面形聚类的分离度。当 \(F_{NEW}\) 达到最小时，获得最优规则数 \(c\)。

\(F_{NEW} \equiv \frac{\sum_{i=1}^c \sum_{k=1}^N (u_{ik})^m E_{ik}^2(\Theta_i)}{N \min_{\substack{i=1, \dots, c \\ j=1, \dots, c \\ i \ne j}} \frac{a_{ij} + k_2}{<|\mathbf{u}_i, \mathbf{u}_j>| + k_1}} \tag{8}\)

其中，\(a_{ij} = \frac{|a_0^j - a_0^i|}{\Delta a_{max}}\)，对于 \(i, j = 1, \dots, c, i \ne j\)，\(\Delta a_{max} = \max_{i=1, \dots, c \\ j=1, \dots, c} |a_0^i - a_0^j|\)，\(a_{ij} \in [0, 1]\) 已归一化，\(\mathbf{u}_i = \mathbf{n}_i / \|\mathbf{n}_i\|\)，\(<,>\) 表示内积，\(\mathbf{n}_i = [a_1^i \cdots a_n^i - 1]^T\)，\(k_1, k_2\) 是小的正实常数，用于避免函数为零或无穷大。

## D. 改进的蚁群优化算法

蚁群优化（ACO）[33]-[35] 是一种元启发式方法，广泛用于寻找优化问题的近似解。ACO 灵感来源于对真实蚂蚁觅食行为的观察。类似于蚂蚁在巢穴和食物源之间寻找路径的行为，ACO 算法最初旨在搜索图中的最优路径。基于 ACO 算法，优化问题可以转化为在加权图上寻找最佳路径的问题。蚂蚁（以下简称蚂蚁）通过在图上移动来逐步构建解。解构建过程是随机的，并依赖于信息素模型，其值由蚂蚁在运行时修改。模糊逻辑与 ACO 的结合已被广泛应用于求解组合优化问题，例如旅行商问题（TSP）[36]、车辆路由问题 [37]、铁路阻塞问题 [38]、配电系统最优重构 [39]、模糊控制器设计 [40] 等。ACO 算法在解决优化问题方面具有优势；然而，对于连续情况，优化问题的解不够清晰和直接。一些研究采用了 ACO 的概念来求解连续域优化问题的解，但它们通常并不完全遵循其步骤。从对模糊辨识问题的考察来看，需要找到许多未知参数，且每个参数的区间未知。此外，需要大量迭代才能获得最优解；因此，很少有研究使用模糊逻辑与 ACO 算法的组合来探索模糊辨识问题。因此，在本研究中，采用改进的 ACO [41] 来获取筛选后的初始隶属度函数和后件参数矩阵，以建立迭代次数更少的 T-S 模糊模型。改进的 ACO 算法简要描述如下。

- 1) 初始化信息素表中的解（如图 1 所示），并将解代入适应度函数 (5)。

- 2) 按适应度函数对解进行排序，并使用 (9) 计算每个解的权重。

\(\bar{\omega}_v = \frac{1}{\zeta T \sqrt{2\pi}} e^{-\frac{(v-1)^2}{2\zeta^2 T^2}} \tag{9}\)

其中，\(v\) 是第 \(v^{th}\) 个解，\(\zeta T\) 是标准差，\(T\) 是种群大小，\(\zeta\) 是 ACO 的一个参数。当 \(\zeta\) 很小时，排名靠前的解会被强烈偏好；否则，概率会变得更加均匀。

![](img/7a2a4261fbc1474308250e4dcaab8af5_3_0.png)

- 3) 概率 \(P_v\) 由 (10) 计算，并使用概率公式 (10) 结合轮盘赌法选择解。

\(\begin{array}{ c }
P_v = \frac{\bar{\omega}_v}{\sum_{t=1}^T \bar{\omega}_t} \\
(10)
\end{array}\)

- 4) 将步骤 3 中选定的解设为均值 \(\mu^i\)，并根据以下方程计算标准差 \(\sigma_v^i\)。

\(\begin{array}{ c }
\sigma_v^i = \xi \sum_{\epsilon=1}^T \frac{|S_\epsilon^i - S_v^i|}{T - 1} \\
(11)
\end{array}\)

其中，\(\xi\) 是信息素挥发率，\(\sigma_v^i = \zeta T\)，\(S_\epsilon^i\) 是图 1 中第 \(\epsilon^{th}\) 个解的第 \(i^{th}\) 变量，\(S_v^i\) 是图 1 中第 \(v^{th}\) 个解的第 \(i^{th}\) 变量。

- 5) 如果满足条件 \(|f^{(l+1)}(\mu^i) - f^{(l+1)}(S_i)| < 0\)，则设置 \(S_i = \mu^i\)；否则，保留原始 \(S_i\)。

- 6) 如果满足终止条件 \(|f^{(l+1)}(S_i) - f^{(l)}(S_i)| < \delta\) 且 \(\delta > 0\)，则停止算法；否则，返回步骤 2。

## III. 拟议辨识方法

本节介绍了拟议的辨识方法，该方法结合了改进的聚类有效性准则指数以及 ACO 和 OLS 算法。拟议模糊辨识的目的是建立建立的模型与原始非线性模型之间误差方差最小的 T-S 模糊模型。遵循以下步骤：

### 前件参数辨识

- 1) 确定模糊规则数量。
- 2) 隶属度函数参数辨识。

### 后件参数辨识

- 1) 建立每个局部模型的后件结构。
- 2) 初始后件参数优化。
- 3) 后件参数辨识。

## A. 拟议辨识算法

通常，在应用聚类算法辨识建立模型的参数之前，初始值和规则数量会随机设置。然而，由于初始前件结构、后件参数和规则数量可能导致不合适的前件结构和辨识结果，本研究开发了一种算法，利用 ACO 算法寻找更好的初始值，并采用改进的聚类有效性准则指数来确定适当的规则数量。此外，通过利用改进的 FCRM 和 OLS 算法，得到了最终的前件结构和后件参数。拟议辨识算法详细描述如下。

- 步骤 1：设置聚类数 \(c = 2\) 和 \(c_{\max}\)，并使用 (8) 寻找适当的聚类数。设置 ACO 算法中的参数并初始化解 \(S_i, i = 1, \dots, T\)，并将 \(S_i\) 与 \(\Theta_i = S_i\) 代入适应度函数 (5)。

- 步骤 2：按适应度函数对解进行排序，然后将这些解按升序排列。根据 (9) 和 (10)，可以得到解更新的概率值 \(S_i (i = 1, \dots, T)\)。

- 步骤 3：使用步骤 2 得到的概率值和轮盘赌法计算均值 \(\mu^i\)，并使用 (11) 设置标准差 \(\sigma_v^i\)。如果满足条件 \(|f^{(l+1)}(\mu^i) - f^{(l+1)}(S_i)| < 0\)，则设置 \(S_i = \mu^i\)；否则，保留原始 \(S_i\)。

- 步骤 4：如果满足条件 \(|f^{(l+1)}(S_i) - f^{(l)}(S_i)| < \delta\)，则定义 \(S_i \equiv \Theta_i\)；否则设置 \(l = l + 1\) 并返回步骤 2。

- 步骤 5：使用 (5) 搜索最小适应度值，直到满足条件 \(\|\mathbf{U}^{(l+1)} - \mathbf{U}^{(l)}\| < \varepsilon\)，其中 \(\mathbf{U}^{(l)} = \begin{bmatrix} u_{11}^{(l)} & \cdots & u_{1N}^{(l)} \\ \vdots & \ddots & \vdots \\ u_{c1}^{(l)} & \cdots & u_{cN}^{(l)} \end{bmatrix}\) 。
