

## 基于蚁群优化算法的新型模糊识别方法

蔡顺鸿 和 陈昀雯
台北科技大学自动化技术研究所, 台湾台北 10608
通讯作者：S.-H. Tsai (shtsai@ntut.edu.tw, shtsai@mail.ntut.edu.tw)
该工作得到台湾科技部支持，资助编号为 MOST-104-2221-E-027-066 和 MOST-105-2221-E-027-068。

**摘要** 本文探讨了非线性模型的识别问题，并提出了一种基于蚁群优化算法的新型模糊识别方法。首先，采用带有模糊 c-回归模型的修正聚类有效性准则来确定 Takagi-Sugeno 模糊模型的适当规则数。然后，采用蚁群优化算法，获得筛选后的初始隶属函数和模糊模型的后件参数。通过改进的模糊 c-回归模型和正交最小二乘法，可以获得前提结构和后件参数以建立 Takagi-Sugeno 模糊模型。一些示例说明了所提方法相比某些现有方法能提供更好的近似结果和鲁棒性。

**索引术语** 模糊系统识别，Takagi-Sugeno 模糊模型，蚁群优化算法 (ACO)，模糊 c-回归模型。

## I. 引言

模糊逻辑已应用于物理和工程问题的分析 [1]–[4]。此外，在过去几十年中，模糊模型已被广泛应用于非线性系统的识别。在各种类型的模糊模型中，Takagi-Sugeno (T-S) 模糊模型 [5]–[7] 被认为是识别非线性模型的有效且强大的方法。T-S 模糊模型由一组模糊 IF-THEN 规则描述，这些规则代表了模型的局部线性输入-输出关系。整体 T-S 模糊模型可以通过使用模糊隶属函数融合这些线性模型来获得，以表示非线性模型。此外，T-S 模糊模型已被证明是通用函数逼近器，因为它可以在任何凸紧集内以任意精度逼近任何平滑非线性函数 [8]。因此，基于 T-S 模糊模型，已开发出许多用于非线性模型识别的方法 [9]–[11]。基于 T-S 模糊模型的识别方法大致可分为两类：一类与输入-输出数据无关，通过某些已知系统参数和分析方法从非线性模型建立 T-S 模糊模型，例如扇区非线性方法 [8] 和平衡点建模方法 [2]。然而，其缺点是必须事先知道非线性系统参数。另一类识别方法涉及基于输入-输出数据建立 T-S 模糊模型。其优点是当系统参数未知时，仍可从原始模型建立 T-S 模糊模型。因此，人们认识到后一种方法比前一种方法更适合实际应用，因此已开发出许多基于输入-输出数据的模糊识别方法。

对于基于 T-S 模糊模型的识别问题，一个主要步骤是确定模糊规则的数量。然而，大多数方法不会自动设置模糊规则的数量。因此，已提出层次稀疏模糊推理系统来寻找 T-S 模糊模型的最小规则数 [10]；然而，对于某些模型，具有最小规则数的建立的 T-S 模糊模型无法精确表示原始模型。在一项研究 [11] 中，规则库和规则数是在进化过程中获得的，其中变异过程起到了关键作用。在另一项研究 [12] 中，提出了一种指标来确定高球形聚类算法的适当规则数，但它不适用于高平面。因此，在本研究中，采用带有模糊 c-回归模型的修正聚类有效性准则来获得适当的规则数。

除了规则数量之外，系统参数初始值的选择也会影响最终结果。此外，可能会得到不合适的前提结构，导致不合理的建模失真。因此，已开发出许多元启发式算法来寻找合适的参数。近年来，许多受自然启发的启发式算法已被开发并应用于各个领域，包括优化问题 [13]–[15]、分类问题 [16]–[19] 和识别问题 [20]。大多数群体智能概念源于对社会生物群体或群体的研究 [21]–[23]。在基于群体智能的各种算法中，蚁群优化 (ACO) 算法作为一种流行的元启发式算法，已显示出有前景的性能。ACO 算法通常应用于组合优化问题，其灵感来源于对蚂蚁觅食行为的观察 [24]。ACO 算法在解决优化问题方面显示出优势；然而，对于模糊识别问题，需要找到许多未知参数且每个参数的区间未知。此外，寻找解需要花费大量时间；因此，很少有研究使用 ACO 算法探讨模糊识别问题。出于这个原因，本研究提出了一种改进的基于 ACO 的模糊识别方法，以寻找筛选后的初始后件参数和初始隶属函数矩阵。

与上述讨论相关，本研究开发了一种基于改进 ACO 算法的新型识别方法。首先，使用模糊 c-回归模型 (FCRM) 的聚类有效性准则指标来确定 T-S 模糊模型的适当规则数。其次，基于改进的 ACO 算法，获得筛选后的初始隶属函数矩阵和后件参数矩阵。通过改进的 FCRM 算法和正交最小二乘 (OLS) 方法，获得前提参数和后件参数。最后，提供了一些示例以展示所提识别方法的有效性和优越性。本文的主要贡献如下：i) 使用聚类有效性准则指标，获得适当的规则数；ii) 基于改进的 ACO 算法，获得筛选后的初始后件参数矩阵 $\Theta_i(k)$；iii) 根据 ACO 算法获得的 $\Theta_i(k)$ 和改进的 FCRM，以更少的迭代次数获得隶属函数矩阵 **U**。本文的其余部分组织如下。在第 II 节中，介绍了 T-S 模糊模型和用于设计过程的一些算法。在第 III 节中，基于 FCRM 算法、聚类有效性准则指标和 ACO 算法，提出了一种基于 T-S 模糊模型的新型识别方法。在第 IV 节中，给出了一些示例以证明所提识别方法相比某些现有方法能提供更好的逼近性能和鲁棒性。最后，在第 V 节中给出结论。

## II. 预备知识

在讨论所提识别方法之前，本节将回顾 T-S 模糊模型以及用于搜索 T-S 模糊模型合适参数的一些算法。

### A. T-S 模糊模型

T-S 模糊动态模型由模糊 IF-THEN 规则描述，这些规则局部表示非线性模型的输入-输出关系。首先，考虑数据集 **X** = {**x**<sub>1</sub>, **x**<sub>2</sub>, ..., **x**<sub>N</sub>}，其中 _N_ 是数据输入的数量，对于每个输入向量 **x**<sub>k</sub> = {x<sub>1</sub>(k), x<sub>2</sub>(k), ..., x<sub>n</sub>(k)}，_n_ 是 **x**<sub>k</sub> 的维度，_k_ 是第 _k_ 个数据集。T-S 模糊模型的第 _i_ 规则表示为：

规则 i：
IF $x_1(k)$ 是 $A_1^i$ 且 $\cdots$ 且 $x_n(k)$ 是 $A_n^i$
THEN $y^i(k) = a_0^i + a_1^i x_1(k) + \cdots + a_n^i x_n(k)$ (1)

其中 _i_ = 1, ..., _c_ 是第 _i_ 个模糊规则，_c_ 是模糊规则的数量，_x<sub>q</sub>_(_k_) 是输入变量，_q_ = 1, 2, ..., _n_，$A_q^i$ 是模糊集，$y<sup>i</sup>_(_k_) 是第 _i_ 个模糊规则的输出，$a_q^i$ 是第 _i_ 个输出的后件参数。

通过使用乘积推理、单例模糊化和中心平均去模糊化，整体 T-S 模糊模型的去模糊输出可以表示为：

\(\hat{y}(k) = \frac{\sum_{i=1}^c w_i(k)y^i(k)}{\sum_{i=1}^c w_i(k)}\) (2)

其中 $\hat{y}(k)$ 是模糊系统的输出，权重 $w_i(k) = \prod_{q=1}^n A_q^i(x_q(k))$ 且 $\sum_{i=1}^c w_i(k) = 1$。$A_q^i(x_q(k))$ 是隶属函数的隶属度，表示为：

\(A_q^i(x_q) = exp \left\{ - \left( \frac{x_q - \alpha_q^i}{\beta_q^i} \right)^2 \right\}, q = 1, \cdots, n\) (3)

其中 _i_ = 1, ..., _c_ 是第 _i_ 个模糊规则，$\alpha_q^i$ 和 $\beta_q^i$ 分别代表钟形隶属函数的中心和钟形隶属函数的标准差。

### B. 模糊 c-回归模型

模糊 c-均值 (FCM) 算法被认为是一种简单有效的聚类算法。然而，FCM 算法是高球形聚类算法；因此，它不适用于高平面形状的聚类。因此，提出了 FCRM 聚类算法 [25]–[28] 以将输入-输出数据对划分为高平面形状的聚类，用于模糊建模。
