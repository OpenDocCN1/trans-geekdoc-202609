
## Laplacian Approximation for Neural Networks

The likelihood function for a single data point is given by:

$$p(y|\boldsymbol{\theta}; \beta) = \mathcal{N}(y|f_{\boldsymbol{\theta}}(\boldsymbol{x}), \beta^{-1})$$

where $\beta$ is the noise precision variable. Assuming successive training samples, $(y_n, \boldsymbol{x}_n)$, $n = 1, 2, \dots, N$, to be independent, we can write the joint likelihood as:

$$p(\mathbf{y}|\boldsymbol{\theta}; \beta) = \prod_{n=1}^{N} \mathcal{N}\left( y_n | f_{\boldsymbol{\theta}}(\boldsymbol{x}_n), \beta^{-1} \right). \tag{18.57}$$

Adopting a Gaussian prior for $\boldsymbol{\theta}$, that is,

$$p(\boldsymbol{\theta}; \alpha) = \mathcal{N}(\boldsymbol{\theta} | \mathbf{0}, \alpha^{-1} \mathbf{I}), \tag{18.58}$$

the posterior distribution, given the output values $\mathbf{y}$, can be written as:

$$p(\boldsymbol{\theta}|\mathbf{y}) \propto p(\boldsymbol{\theta}; \alpha) p(\mathbf{y}|\boldsymbol{\theta}; \beta). \tag{18.59}$$

However, in contrast to Eq. (12.16), the posterior is not a Gaussian one, owing to the nonlinearity of the dependence on $\boldsymbol{\theta}$. Here is where complications arise and one has to employ a series of approximations to deal with it.

### Laplacian Approximation

The Laplacian approximation method, introduced in Chapter 12, is adopted to approximate $p(\boldsymbol{\theta}|\mathbf{y})$ to a Gaussian one. To this end, the maximum, $\boldsymbol{\theta}_{\text{MAP}}$, has to be computed, which is carried out via an iterative optimization scheme. Once this is found, the posterior can be replaced by a Gaussian approximation, denoted as $q(\boldsymbol{\theta}|\mathbf{y})$.

### Taylor Expansion of the Neural Network Mapping

The final goal is to compute the predictive distribution:

$$p(y|\boldsymbol{x}, \mathbf{y}) = \int p(y|f_{\boldsymbol{\theta}}(\boldsymbol{x})) q(\boldsymbol{\theta}|\mathbf{y}) \, d\boldsymbol{\theta}. \tag{18.60}$$
