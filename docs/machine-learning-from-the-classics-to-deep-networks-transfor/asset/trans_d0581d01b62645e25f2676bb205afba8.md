除了自回归模型外，还提出并使用了其他类型的随机模型。*自回归-移动平均*（ARMA）模型，阶数为 `(l, m)`，由以下差分方程定义：

```
u[n] + a[1]u[n − 1] + … + a[l]u[n − l] = b[1]η[n] + … + b[m]η[n − m]
```
