
这里使用了公式 [(3.51)](#Chp003_65-117_B9780443292385000093.xhtml#deq91)，并利用了第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章所述的乘积法则。接下来，可以对 `x` 取均值。换句话说，这是在所有可能训练集上平均后的、针对所有可能输入的预测 MSE。所得的 MSE 也称为*测试*误差或*泛化误差*，它是衡量所采用模型性能的指标。请注意，公式 [(3.53)](#Chp003_65-117_B9780443292385000093.xhtml#deq92) 中的泛化误差涉及对（理论上）所有特定规模 `N` 的可能训练数据集进行平均。相反，所谓的*训练误差*是在单个数据集（即用于训练的那个数据集）上计算的，这会导致对误差的过于乐观的估计。我们将在第 [3.13](#Chp003_65-117_B9780443292385000093.xhtml#s0105) 节中回到这个重要问题。

## 示例 3.5

让我们考虑一个简单但具有教学意义的例子，以演示偏差和方差之间的这种权衡。我们得到一组训练点，它们是根据以下形式的回归模型生成的：

```
y = g(x) + η.
```

函数 `g(x)` 的图形如 [图 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045) 所示。函数 `g(x)` 是一个五阶多项式。训练集的生成方式如下。对于每个集合，在区间 `[-1, 1]` 内以 `N` 个等距点 `x[n]`，`n = 1, …, N` 对 `x` 轴进行采样。然后，每个训练集 `D[i]` 创建为：

```
D[i] = {(x[n], g(x[n]) + η[n, i]): n = 1, 2, …, N},  i = 1, 2, …
```

其中 `η[n, i]` 表示从白噪声过程中独立同分布（i.i.d.）抽取的不同噪声样本。换句话说，由于噪声值不同，所有训练点具有相同的 `x` 坐标但不同的 `y` 坐标。[图 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045) 中 `(x, y)` 平面上的灰点对应于 `N = 10` 情况下训练集的一个实现。为了比较，无噪声点集 `(x[n], g(x[n]))`，`n = 1, 2, …, 10` 显示为 `g(x)` 图上的红点。

![图 3.7 观测数据用灰点表示。这些是将噪声添加到红点（位于与未知 g(⋅) 相关的红曲线上）后的结果。用固定多项式 f1(x) 拟合数据会导致高偏差；观察到大多数数据点都位于直线之外。另一方面，“估计量”的方差将为零。相反，拟合高次多项式 f_{2}(x;D)Equation 会导致低偏差，因为相应的曲线穿过所有数据点；然而，相应的方差将很高。](images/B9780443292385000093/gr007.jpg)
