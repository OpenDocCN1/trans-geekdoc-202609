
换句话说，`u[j]` 指向 `q[j]` 的方向。因此，公式 [(6.30)](#Chp006_249-291_B9780443292385000123.xhtml#deq64) 表明：在将 `y` 投影到 `X` 的列空间时，与较大方差值相关的方向 `u[j]` 比其他方向获得更高的权重。*岭回归尊重并赋予更多信息量方向以更高的权重，这些方向是大部分数据活动发生的地方*。或者，那些与较小数据方差相关的不太重要的方向，收缩得最厉害。

关于岭回归的最后一点评论是：岭回归解在输入变量缩放下不保持不变性。通过查看相应的方程，这一点显而易见。因此，在实践中，输入变量通常被标准化为单位方差。

### 主成分回归

我们刚刚看到，岭回归的效果是对参数强制执行一个收缩规则，从而减小相应求和中不太重要的分量 `u[i]` 的贡献。这可以被视为一种软收缩规则。另一种途径是采用硬阈值规则，仅保留 `m` 个最显著的方向，称为*主轴*或*方向*，并通过将相应权重设为零来丢弃其余方向。等价地，我们可以写成

```
ŷ = Σ(i=1 to m) θ̂[i] u[i]
```

其中

```
θ̂[i] = u[i]^(T) y,  i = 1, 2, …, m.
```

此外，利用公式 [(6.18)](#Chp006_249-291_B9780443292385000123.xhtml#deq44)，我们有

```
ŷ = Σ(i=1 to m) (θ̂[i] / σ[i]) X v[i]
```

或者等价地，以输入数据为基础的解的展开权重可以表示为

```
θ = Σ(i=1 to m) (θ̂[i] / σ[i]) v[i].
```

换句话说，预测 `ŷ` 是在 `X` 的列空间的一个子空间中进行的，该子空间由 `m` 个主轴张成，即大部分数据活动发生的子空间。
