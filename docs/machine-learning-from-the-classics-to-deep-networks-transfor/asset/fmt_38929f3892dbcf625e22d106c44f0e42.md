Note that *μ*[*V*[*n* + 1] → *S*[*n*]](**x**[*n*]) involves *K* values and for the computation of each one of them *K* summations are performed. So, the complexity scales as 𝒪(*K*²) per time instant. In the HMM literature, the symbol “beta” is used,

*β*(**x**[*n*]) :  = *μ*[*V*[*n* + 1] → *S*[*n*]](**x**[*n*]).

![Equation](images/B9780443292385000226/si255.png)(16.46)

From the recursive definition in Eqs. [(16.44)](#Chp016_805-853_B9780443292385000226.xhtml#deq81) and [(16.45)](#Chp016_805-853_B9780443292385000226.xhtml#deq82), where **x**[*n* + 1], **x**[*n* + 2], …, **x**[*N*] have been marginalized out, we can equivalently write

*β*(**x**[*n*]) = *p*(**y**[*n* + 1], **y**[*n* + 2], …, **y**[*N*]|**x**[*n*]).

![Equation](images/B9780443292385000226/si257.png)(16.47)

That is, conditioned on the values of **x**[*n*], for example, **x**[*n*] : *x*[*n**k*] = 1, *β*(**x**[*n*]) is the value of the joint distribution for the observed values, **y**[*n* + 1], …, **y**[*N*], to be emitted when the system is at state *k* at time *n*.
