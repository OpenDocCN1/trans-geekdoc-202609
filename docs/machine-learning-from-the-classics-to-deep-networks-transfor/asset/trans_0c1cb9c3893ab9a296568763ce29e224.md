
另一种算法变体是所谓的*复合镜像下降法*，它采用当前可用的次梯度估计而非平均值，并结合Bregman散度；也就是说，`${\\overline{\\mathcal{L}}}^{\\prime}$`被`ℒ[*n* − 1]^′`替代，而`*ψ*(**θ**)`则被`*B*[*ψ*](**θ**, **θ**[*n* − 1])`替代，其中`*ψ*`为某个函数[37]。文献[38]中，通过使用欧几里得范数的加权平均引入了时变的`*ψ*[*n*]`。请注意，在这些修改中，尽管它们看起来很简单，但相应算法的分析可能相当困难，且在性能上可能获得实质性的差异。

在近端类算法中，基本操作是在每次迭代中求解一个小规模优化问题。通常，这些子问题可以用标准方法求解，并且往往允许闭式解。近端算法非常适合涉及高维数据集的大数据应用，例如[67]。

## 8.15 分布式优化：一些亮点

分布式优化（例如[86]）已在随机梯度下降的背景下进行过讨论，重点在于第[5](#Chp005_177-248_B9780443292385000111.xhtml)章中的LMS和扩散类算法，以及第[8.9](#Chp008_343-416_B9780443292385000147.xhtml#s0085)节。分布式或去中心化优化的核心在于一个代价函数，

```
$J(\\mathbf{\\theta}) = \\sum\\limits\_{k = 1}^{K}J\_{k}(\\mathbf{\\theta}),$
```

该函数定义在一个包含*K*个节点（智能体）的连通网络上。每个`*J*[*k*]`（*k* = 1, 2, …, *K*）由第*k*个节点的数据提供，并量化相应智能体对总代价的贡献。目标是计算一个对所有节点*通用*的优化量`**θ**[\*]`。此外，在迭代算法的背景下，每个节点*仅*将其更新传递给其邻居，而不是公共融合中心。

所谓一致性算法（第[5.13.4](#Chp005_177-248_B9780443292385000111.xhtml)节）的通用迭代方案的第*i*步形式为

```
$\\mathbf{\\theta}\_{k}^{(i)} = \\sum\\limits\_{m \\in \\mathcal{N}\_{k}}a\_{mk}\\mathbf{\\theta}\_{m}^{(i - 1)} + \\mu\_{i}\\nabla J\_{k}\\left( \\mathbf{\\theta}\_{k}^{(i - 1)} \\right),\\ k = 1,2,\\ldots,K,$
```
