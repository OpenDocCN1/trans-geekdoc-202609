

# 磁共振成像 (MRI)

与直接获取像素样本的普通成像系统不同，MRI 扫描仪以编码形式感知图像。具体而言，MRI 扫描仪在空间频域对分量进行采样，在 MRI 命名法中称为“$k$-空间”。如果该变换域中的所有分量都可用，则可以应用逆 2D-DFT 在像素域中恢复精确的 MR 图像。$k$-空间中的采样是在一系列连续采集中沿特定轨迹实现的。由于物理约束，这一过程耗时较长。因此，从有限数量的观测中高效恢复图像的技术至关重要，因为它们可以减少执行测量所需的采集时间。长时间的采集不仅不方便，甚至是不可能的，因为患者必须长时间保持静止。因此，MRI 是压缩感知最早提供其优雅解决方案的应用领域之一。

图 10.9A 展示了著名的 Shepp-Logan 模体，目标是通过其频域中有限数量的样本（观测）来恢复它。观测到的 MRI 样本沿空间频域中的 17 条径向线获取，如图 10.9B 所示。从这一有限样本中恢复图像的一种“朴素”方法是对缺失分量采用零填充原理。根据该技术恢复的图像如图 10.9C 所示。图 10.9D 展示了使用总变差最小化方法恢复的图像，如前所述。观察可知，该情况下的结果惊人地好。原始图像几乎被完美恢复。约束最小化是通过 NESTA 算法执行的。请注意，如果使用图像数组的 $\ell_1$ 范数最小化代替总变差，结果将不会那么好；因为模体图像在离散梯度域中是稀疏的，因为它包含共享恒定强度的大片区域。

# 10.4 在线稀疏性促进算法

本节介绍用于稀疏感知学习的在线方案。必须采用此类方案的原因有很多。正如前几章所述，在各种信号处理任务中，数据是按顺序到达的。在这种情况下，使用批处理技术来获得未知目标参数向量的估计将是非常低效的，因为训练点的数量不断增加。这种方法对于实时应用是不可行的。此外，当学习环境不是平稳的，而是随时间演变发生变化时，时域递归方案可以轻松地融入自适应的概念。除了信号处理之外，还有越来越多的其他机器学习应用领域，其中在线处理至关重要，例如生物信息学、高光谱成像和数据挖掘。在这些学科中，训练点的数量轻易就达到几千到几十万个点。关于环境（特征）空间的维度，可以声称存在类似范围的数字。例如，在文献 [82] 中，任务是在维度高达 $10^9$ 的特征空间中搜索稀疏解，并能访问多达 $10^7$ 个点的数据集。用今天的技术在单台计算机上使用批处理技术是不可能的。
