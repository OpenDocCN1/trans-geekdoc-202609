
*   在*自回归 HMM* [11] 中，在 [图 16.15](#Chp016_805-853_B9780443292385000226.xhtml#f0080) 所示的基本 HMM 方案的观测节点之间添加了链接；例如，`y[n]` 不仅链接到 `x[n]`，而且如果模型将相关性延伸至距离两个时间瞬间之外，它还与 `y[n−2]`、`y[n−1]`、`y[n+1]` 和 `y[n+2]` 共享直接链接。

*   文献 [56] 在*段建模*的背景下引入了一个不同的概念。根据该模型，每个状态被允许发射，比如说，`d` 个连续的观测值，它们构成一个段。该段的长度 `d` 本身是一个随机变量，并与概率 `P(d|k), k = 1, 2, …, K` 相关联。通过这种方式，相关性是通过构成该段的样本的联合分布引入的。

*   **可变持续时间 HMM**：HMM 的一个严重缺陷（在实践中常被观察到）与自转移概率 `P(k|k)` 有关，后者是与 HMM 相关的模型参数之一。请注意，模型处于状态 `k` 持续 `d` 个连续瞬间（初始转移到该状态以及 `d−1` 次自转移）的概率由下式给出：

```
P_k(d) = (P(k|k))^(d−1)(1−P(k|k)),
```

*   其中 `1−P(k|k)` 是离开该状态的概率。在许多情况下，这种指数形式的状态持续时间依赖关系是不现实的。在可变持续时间 HMM 中，`P_k(d)` 被显式建模。可以采用不同的 `P_k(d)` 模型（参见例如 [46,68,72]）。

*   隐马尔可夫建模是机器学习中最强大的工具之一，除了语音识别外，已被广泛应用于大量应用中。仅举几例，部分参考文献包括生物信息学领域的 [9]、通信领域的 [16,36]、光学字符识别 (OCR) 领域的 [4,73] 以及音乐分析/识别领域的 [40,61,62]。关于 HMM 的进一步讨论，请参见例如 [8,64,72]。
