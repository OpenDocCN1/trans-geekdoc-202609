
$f(\mathbf{x}) = \sum\limits_{m = 1}^{M}a_{m}f_{m}(\mathbf{x}) = \sum\limits_{m = 1}^{M}a_{m}{\langle f_{m},\kappa_{m}( \cdot ,\mathbf{x})\rangle}_{\mathbb{H}_{m}} + b = \sum\limits_{m = 1}^{M}\sum\limits_{n = 1}^{N}\theta_{m,n}a_{m}\kappa_{m}(\mathbf{x},\mathbf{x}_{n}) + b,$

![Equation](images/B9780443292385000172/si477.png)

where each one of the functions, $f_{m}$, $m = 1, 2, \dots M$, lives in a different RKHS, $\mathbb{H}_{m}$. The respective composite kernel matrix, associated with a set of training data, is given by $K = \sum_{m = 1}^{M}a_{m}^{2}K_{m}$, where $K_{1}, \dots, K_{M}$ are the kernel matrices of the individual RKHSs. Hence, assuming a data set $\{(y_{n}, \mathbf{x}_{n}), n = 1, \dots, N\}$, the MKL learning task can be formulated as follows:

$$
\min\limits_{f}\sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},f(\mathbf{x}_{n}) \right) + \lambda\Omega(f),
$$

![Equation](images/B9780443292385000172/si483.png)(11.93)

where $\mathcal{L}$ represents a loss function and $\Omega(f)$ the regularization term. There have been two major trends following this rationale. The first one gives priority toward a sparse solution, while the second aims at improving performance.
