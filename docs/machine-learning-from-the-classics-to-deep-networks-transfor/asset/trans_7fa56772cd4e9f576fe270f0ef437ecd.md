
**Ξ** = [**θ**₁ᵀ, …, **θ**ₖᵀ, *σ*²_η]ᵀ，**P** = [*P*₁, …, *P*ₖ]ᵀ

是使用训练点集合 (*y*ₙ, **x**ₙ)，*n* = 1, 2, …, *N* 在训练阶段待估计的未知参数向量。由于每个模型被设计为“负责”空间中的一个区域，因此相应的参数应使用来自相应区域的输入样本进行训练；但请注意，这些区域是未知的，也必须在训练期间学习。这类似于高斯混合建模的任务；回想一下，在训练期间，每个观测值都通过隐变量的使用与特定的混合成分相关联。在当前设置中，每个输入样本将与特定的学习器相关联。因此，我们当前的任务与第 [12.6](#Chp012_583-634_B9780443292385000184.xhtml#s0060) 节中处理的任务是近亲，我们可以遵循类似的步骤来推导结果。然而，为了多样化，将采取一条略有不同的路径。这稍后也将被证明是有用的，同时也更适合当前公式所使用的术语。我们将引入一组新的*潜在*变量 *z*ₙₖ ∈ {0, 1}，*k* = 1, 2, …, *K*，*n* = 1, 2, …, *N*，而不是使用高斯混合建模中的索引 *k*ₙ。如果 *z*ₙₖ = 1，则样本 **x**ₙ 由专家 *k* 处理。同时，对于每个 *n*，*z*ₙₖ 仅对单个 *k* 值等于 1，其余均为 0。我们现在可以写出*完整*训练数据集的似然函数。⁽⁸⁹⁾

```
p(y, Z; Ξ, P) = ∏_{n=1}^{N} ∏_{k=1}^{K} ( P_k N( y_n | θ_k^T x_n, σ_η² ) )^{z_nk}
```
