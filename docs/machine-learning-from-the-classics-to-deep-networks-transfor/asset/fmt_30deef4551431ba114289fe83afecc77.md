### Remarks 11.3

*   Besides the linear `ϵ`-insensitive loss, similar analysis is valid for the quadratic `ϵ`-insensitive and Huber loss functions (for example, [28]). It turns out that use of the Huber loss function results in a larger number of support vectors. Note that a large number of support vectors increases complexity, as more kernel evaluations are involved.
*   **Sparsity and ϵ-insensitive loss function**: Note that Eq. [(11.36)](#Chp011_519-582_B9780443292385000172.xhtml#deq109) has exactly the same form as Eq. [(11.18)](#Chp011_519-582_B9780443292385000172.xhtml#deq69). However, in the former case, the expansion is a sparse one using `N[s] < N`, and in practice often `N[s] ≪ N`. The obvious question that is now raised is whether there is a "hidden" connection between the `ϵ`-insensitive loss function and the sparsity promoting methods, discussed in Chapter [9](#Chp009_417-462_B9780443292385000159.xhtml). Interestingly enough, the answer is in the affirmative [47]. Assuming the unknown function, `g`, in Eq. [(11.23)](#Chp011_519-582_B9780443292385000172.xhtml#deq78) to reside in an RKHS, and exploiting the representer theorem, it is approximated by an expansion in an RKHS and the unknown parameters are estimated by minimizing

```
L(θ) = 1/2 || y(·) - Σ_{n=1}^{N} θ_n κ(·, x_n) ||_H^2 + ε Σ_{n=1}^{N} |θ_n|.
```

*   This is similar to what we did for the kernel ridge regression with the notable exception that the `ℓ[1]` norm of the parameters is involved for regularization. The norm `||·||_H` denotes the norm associated with the RKHS. Elaborating on the norm, it can be shown that for the noiseless case, the minimization task becomes identical with the SVR one.
