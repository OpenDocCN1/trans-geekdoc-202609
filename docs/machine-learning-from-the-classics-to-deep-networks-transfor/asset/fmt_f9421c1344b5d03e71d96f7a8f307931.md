
is justified by (a) the *law of large numbers* and (b) the *central limit theorem* [32]. Let us denote `𝔼[f(x)] = μ[f]` and the respective variance as `var[f(x)] := 𝔼 [(f(x) − 𝔼[f(x)])²] = σ[f]²`. Then the previously referred two theorems guarantee that for large values of `N`

```
\lim\limits_{N\rightarrow\infty}{\overline{\mathbb{E}}}_{f,N} = \mu_{f},
```
(14.3)

and

```
p\left( {\overline{\mathbb{E}}}_{f,N} \right) \approx \mathcal{N}\left( {\overline{\mathbb{E}}}_{f,N} \middle| \mu_{f}, \frac{\sigma_{f}^{2}}{N} \right).
```
(14.4)

The limit in Eq. [(14.3)](#Chp014_717-754_B9780443292385000202.xhtml#deq3) refers to the notion of *almost sure convergence*, that is,

```
{Prob} \left\{ \lim\limits_{N\rightarrow\infty} \middle| {\overline{\mathbb{E}}}_{f,N} - \mu_{f} \middle| = 0 \right\} = 1.
```

The approximate Gaussian distribution in Eq. [(14.4)](#Chp014_717-754_B9780443292385000202.xhtml#deq4) guarantees that the variance (as one changes the set of `N` samples) of the obtained estimate `{\overline{\mathbb{E}}}_{f,N}` around the true value `μ[f]` decreases with `N`.
