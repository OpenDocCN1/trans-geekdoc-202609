
其中 `q(γ[k])(β[k])` 是具有变分参数 `γ[k]` 的 Beta 分布，矩阵 `A` 的列的变分后验估计是具有参数 `Φ[k]`（即均值和协方差矩阵）的高斯分布，而 `q(ν[nk])(z[nk])` 是具有参数（概率）`ν[nk]` 的伯努利分布。推断是通过最大化公式 [(12.68)](#Chp012_583-634_B9780443292385000184.xhtml) 中的下界来进行的。请注意，如果稀疏矩阵不是二值的，则将其替换为 `Z ∘ B`，且 `B` 的元素也是潜在变量；根据任务不同可以使用不同的先验；例如，可以是高斯或拉普拉斯分布（参见，如 [15,23]）。在后一参考文献中，讨论了通过吉布斯采样技术进行变分推断的替代路径。

### 备注 13.6

*   类似于 CPR 根据 DP 抽取样本，可以证明 IBP 根据所谓的 Beta 过程抽取样本 [82,91]。
*   通过将 Beta 分布中的参数 `(α, 1)` 替换为更一般的情况 `Beta(a, b)`，并改变它们的值，会得到不同的分布。一个例子是所谓的 Pitman–Yor IBP。对于此类过程，结果概率按期望遵循幂律衰减；相比之下，在前面介绍的 IBP 中，衰减是指数级快速的（参见，如 [64]）。
*   印度自助餐过程（IBP）已被用于许多涉及降维的应用中，参见，如 [23] 的相关综述。最近，IBP 被用作深度神经网络设计中的先验 [42,59]。每层的节点数不是预先选定的，而是留给网络在训练期间学习需要多少个节点。最初，节点数被假定为无限大（一个很大的数字）。为此，突触连接取代了“菜肴”，作为由输入节点（顾客）共享的实体，并调用 IBP 作为先验以施加底层稀疏性。通过这种方式，实现了网络的最优剪枝。

## 13.12 高斯过程

在第 [13.11](#Chp013_635-716_B9780443292385000196.xhtml#s0100) 节中，施加先验到模型上的方式在精神上类似于用于参数建模技术的方式；即，先验被施加在未知参数集上。在本节中，将采用不同的基本原理。先验将直接放置在非线性函数空间上，而不是指定一族参数化的非线性函数并对其参数施加先验。

让我们回顾一下公式 [(12.1)](#Chp012_583-634_B9780443292385000184.xhtml) 中给出的非线性回归任务，即

```
y = θ_0 + ∑_{k=1}^{K-1} θ_k φ_k(x) + η = θ^T φ(x) + η,
```

其中参数 `θ` 被视为随机向量。让我们定义

```
f(x) = θ^(T) φ(x),
```
