
#### The adaptive moment estimation algorithm (Adam)

The update equations are:

```
g = ∂J(θ + aΔθ^(i-1)) / ∂θ |_(θ^(i-1))
v^(i) = β v^(i-1) + (1 - β) g ∘ g
Δθ_d^(i) = a Δθ_d^(i-1) - μ / (√(v_d^(i)) + ε) g_d,  d = 1,2,…,D
θ^(i) = θ^(i-1) + Δθ^(i)
```

where `β` is a user-defined parameter. The first of the recursions computes the gradient after the Nesterov-type correction. The second one updates the squares of the gradient values in the decaying average rationale. The “∘” operation denotes element-wise multiplication. The third recursion computes the correction term in the AdaGrad rationale and the fourth one provides the updates. The algorithm starts with initial conditions on `v^((0)) = 0`, `Δθ^((0))` and `θ^((0))`. Some typical values for the hyperparameters are `ε = 10^(-8)`, `β = 0.9`, and `μ = 0.001`.

The RMSProp algorithm was proposed by Hinton et al. in a lecture.^([^(117)](#fn117))
