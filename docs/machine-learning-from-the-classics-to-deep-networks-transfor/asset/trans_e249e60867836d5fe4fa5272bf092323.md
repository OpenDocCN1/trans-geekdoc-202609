

## 4.9 线性模型的均方误差估计

我们现在将注意力转向输入-输出变量之间的底层模型为线性模型的情况。为避免与前几节的内容混淆，必须强调的是，到目前为止，我们关注的是线性估计任务。在我们讨论的这个阶段，数据的生成模型从未被引入（[备注 4.2](#Chp004_119-175_B978044329238500010X.xhtml#enun0015) 中的评论除外）。我们只是采用了一个线性估计器并为其求得了 MSE 解。重点在于该解及其性质。这里的重点在于输入-输出变量通过线性数据生成模型相关联的情况。文中处理的是实值情况。推广到复值数据是直接了当的。

假设我们有两个联合分布的随机向量 **y** 和 **θ**，它们根据以下线性模型相关联，

**y** = *X***θ** + **η**，

![Equation](images/B978044329238500010X/si362.png)(4.82)

### 数学背景

以下方程描述了 Cholesky 分解和 Schur 算法的性质：

𝔼[**e**_l^b(n) **e**_l^{bH}(n)] = *U*^H *Σ*_l *U* = *D*，

![Equation](images/B978044329238500010X/si357.png)

其中

*D* := diag{*α*_0^b, *α*_1^b, …, *α*_{l−1}^b}，

![Equation](images/B978044329238500010X/si358.png)

或者

*Σ*_l^(−1) = *U D*^(−1) *U*^H = (*U D*^(−1/2))(*U D*^(−1/2))^H。

![Equation](images/B978044329238500010X/si359.png)

也就是说，预测误差功率和最优前向预测器的权重提供了逆协方差矩阵的 *Cholesky 分解*。

*   **Schur 算法**。在并行处理环境中，Levinson 算法中涉及的内积构成了算法流程的瓶颈。注意，**w**_m 和 **a**_m 的更新可以完全并行执行。Schur 算法 [45] 是一种克服该瓶颈的替代方案，在多处理器环境中，复杂度可降至 *O*(*l*)。Schur 算法中涉及的参数对 *Σ*_l 执行 Cholesky 分解（例如 [21,22]）。

*   注意，所有这些用于高效求解正规方程的算法方案之所以存在，归功于（自相关）协方差矩阵和互相关向量所具有的丰富结构，当涉及的联合分布随机实体为随机过程时，它们便获得这种结构；其*时序性质*施加了这种结构。Levinson 算法和阶阶梯算法的推导揭示了可用于推导在线/自适应版本及相关最小二乘误差损失函数的计算方案的技术类型，这些将在第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章中讨论。在那里，算法在计算上可能更复杂，但其背后的本质与本节所用技术相同。
