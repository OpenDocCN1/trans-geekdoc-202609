
参数 `θ[o] ∈ ℝ^(200)` 从 `𝒩(0, 1)` 随机生成后固定。输入向量由白噪声序列构成，其样本从 `𝒩(0, 1)` 中独立同分布（i.i.d.）抽取。

在第一个实验中，白噪声序列的方差选为 `σ² = 0.01`。三种算法的参数分别选取为：NLMS 算法 `μ = 1.2` 和 `δ = 0.001`；APA 算法 `q = 30, μ = 0.2` 和 `δ = 0.001`；APSM 算法 `ϵ = √2 σ, q = 30` 和 `μ[n] = 0.5 M[n]`。这些参数使算法收敛至相同的误差底噪。[图 8.25](#Chp008_343-416_B9780443292385000147.xhtml#f0135) 显示了 100 次实验平均后的均方误差（以 dB 为单位，即 `10log[10](e[n]²)`）。为作比较，给出了 `β = 1` 时的 RLS 收敛曲线，其收敛更快且同时收敛至更低的误差底噪。若将 `β` 修改为较小值使 RLS 收敛至与其他算法相同的误差底噪，则其收敛速度会更快。然而，RLS 这种性能提升是以更高复杂度为代价的，当 `l` 取较大值时这会成为一个问题。观察 APA 和 APSM 相比 NLMS 实现的更快收敛速度。

## 8.8 约束学习

在一组约束条件下进行学习，在信号处理和机器学习中普遍具有重要意义。我们已经讨论了多项此类学习任务。第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章和第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章讨论的波束成形即是典型一例。在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章引入过拟合概念时，我们讨论了正则化的概念，这是对未知参数向量范数进行约束的另一种形式。在其他一些情况下，我们掌握有关未知参数的先验信息；这些额外信息可用一组约束条件给出。

例如，若对图像像素值进行估计，则数值必须为非负。近年来，未知参数向量可能已知为稀疏向量；即其仅有少数分量非零。此时，约束相应的 `ℓ[1]` 范数可显著提高迭代方案求解的精度和收敛速度。显式考虑底层稀疏性的方案称为*稀疏促进*算法。第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章将更详细地探讨此类算法。
