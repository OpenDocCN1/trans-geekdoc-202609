
在后续内容中，绘制一张图，横轴为 *α* ∈ [0, 1]，纵轴为 *β* ∈ [0, 1]。对于 [0, 1] × [0, 1] 区域内的每个点 (*α*, *β*)，计算算法恢复 *k*-稀疏目标向量的概率。为了计算该概率，必须采用前面所述的场景之一。实际上，必须在图中形成一个足够稠密地覆盖 [0, 1] × [0, 1] 区域的点网格。使用变化的强度等级来为相应的 (*α*, *β*) 点着色。黑色对应概率 1，红色对应概率 0。[图 10.4](#Chp010_463-518_B9780443292385000160.xhtml#f0025) 展示了在实践中对于较大的 *l* 值预期恢复的图类型；即，从“成功”（黑色）区域（相位）到“失败”（红色）区域的过渡非常陡峭。事实上，存在一条曲线将这两个区域分开。该曲线的理论方面已在组合几何学背景下针对渐近情况 *l* → ∞（参考文献 [40]）和有限 *l* 值（参考文献 [42]）进行了研究。观察到 *α* 值越大（观测百分比越大），过渡发生时的 *β* 值也越大。这与本章迄今所述内容一致，且问题难度随图中向左上方移动而增加。实际上，对于较小的 *l* 值，从红到黑的过渡区域更平滑，且随 *l* 增加而变窄。在这种情况下，可以使用回归技术（见如 [85]）绘制一条分隔“成功”和“失败”区域的近似曲线。

读者可能已经意识到，迄今为止我们一直避免谈论单个算法的性能。我们只是讨论了算法在实践中倾向于表现出的某些“典型”行为。读者可能期待的是关于比较性能测试及相关结论的讨论。原因在于，在当前版本编纂时，尚无定论。大多数作者将其新提出的算法与其他少数算法进行比较，通常局限于某个算法家族内，且更重要的是，在某些特定场景下进行，这些场景记录了新算法的优势。然而，改变测试所依据的实验场景，算法的性能可能会发生显著变化。文献 [85] 报告了一项全面的比较性能研究。然而，即使在这项工作中，也仅考虑了精确观测场景，且不存在针对单个算法对噪声鲁棒性的实验。必须指出，这项研究涉及巨大的计算量。我们将评论该研究的一些发现，这也将向读者揭示不同的实验场景如何显著影响算法的性能。

[图 10.5](#Chp010_463-518_B9780443292385000160.xhtml#f0030)A 显示了以下算法获得的相变曲线：(a) 迭代硬阈值 (IHT)；(b) 公式 [(10.2)](#Chp010_463-518_B9780443292385000160.xhtml#deq14) 的迭代软阈值 (IST) 方案；(c) 如前所述的两阶段阈值 (TST) 方案；(d) LARS 算法；以及 (e) OMP 算法，连同使用 ℓ₁ 最小化获得的理论曲线。所有算法均在大量实验后，针对所需用户定义参数调整为最优值。图中的结果对应于感知矩阵生成的均匀球面场景。稀疏向量根据非零系数的 ±1 场景生成。有趣的是，尽管曲线在向较大 *β* 值移动时相互偏离，但对于较小的 *β* 值，它们的性能差异变得越来越小。这对于计算简单的方案（如 IHT）也适用。LARS 的性能接近最优，但这是以计算量增加为代价的。文献 [85] 报告的达到相同精度所需的计算时间有利于 TST 算法。在某些情况下，LARS 需要过长的时间才能达到相同精度，特别是当感知矩阵为部分傅里叶矩阵且可利用快速方案执行矩阵-向量乘积时。对于此类矩阵，阈值方案（IHT、IST、TST）表现出了非常适合大规模问题的性能扩展性。
