
现在可以在区间 `(0, 2*M_n)` 内选择外推参数，以保证收敛。对于公式 [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74) 的情况：

```
M_n = \sum_{k = n - q + 1}^{n} \frac{\omega_k \| P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|^2}{\| \sum_{k = n - q + 1}^{n} \omega_k P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|^2}.
```

请注意，该区间不同于公式 [(8.27)](#Chp008_343-416_B9780443292385000147.xhtml#deq57) 中有限个集合情况下所报告的区间。对于与公式 [(8.38)](#Chp008_343-416_B9780443292385000147.xhtml#deq73) 相关的前几步迭代，上述公式中的求和从 `k = 1` 开始，而不是从 `k = n - q + 1` 开始。

回顾一下，`P_{S_{\epsilon,k}}` 是公式 [(8.34)](#Chp008_343-416_B9780443292385000147.xhtml#deq67)–[(8.35)](#Chp008_343-416_B9780443292385000147.xhtml#deq68) 中给出的投影运算。请注意，这是一个通用方案，可应用于不同的性质集。所需做的只是更改投影算子。例如，如果考虑分类问题，我们所要做的就是将 `S_{\epsilon,n}` 替换为半空间 `H_n^+`，该半空间由数对 `(y_n, \mathbf{x}_n) \in \{-1, 1\} \times \mathbb{R}^{(l + 1)}` 定义，如第 [8.6.2](#Chp008_343-416_B9780443292385000147.xhtml#s0060) 节所述，并使用公式 [(8.13)](#Chp008_343-416_B9780443292385000147.xhtml#deq28) 中的投影（参见 [78,79]）。此时，必须强调的是，原始的 APSM 形式（例如 [103,104]）更为通用，可涵盖广泛的凸集和函数。

[图 8.23](#Chp008_343-416_B9780443292385000147.xhtml#f0125) 从几何上演示了 APSM 算法。我们假设每个时刻用于投影的超薄板数量为 `q = 2`。每次迭代包含：

*   `q` 次投影，可并行执行，
*   它们的凸组合，以及
*   更新步骤。
