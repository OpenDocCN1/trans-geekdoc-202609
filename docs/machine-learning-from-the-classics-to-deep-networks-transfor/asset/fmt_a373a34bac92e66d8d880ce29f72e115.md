Special cases of the Volterra expansion are the *Wiener*, *Hammerstein*, and *Wiener–Hammerstein* models. These models are shown in [Fig. 11.2](#Chp011_519-582_B9780443292385000172.xhtml#f0015). The systems *h*(·) and *g*(·) are linear systems with memory, that is,

```
s_n = ∑_{i=0}^{M_1} h_n u_{n-i}
```

![Equation](images/B9780443292385000172/si33.png)

and

```
d_n = ∑_{i=0}^{M_2} g_n x_{n-i}.
```

![Equation](images/B9780443292385000172/si34.png)

The central box corresponds to a memoryless nonlinear system, which can be approximated by a polynomial of degree *r*. Hence,

```
x_n = ∑_{k=1}^{r} c_k (s_n)^k.
```

![Equation](images/B9780443292385000172/si35.png)

In other words, a Wiener model is a linear time-invariant (LTI) system followed by the memoryless nonlinearity and the Hammerstein model is the combination of a memoryless nonlinearity followed by an LTI system. The Wiener–Hammerstein model is the combination of the two. Note that such models are nonlinear with respect to the involved free parameters. In contrast, the equivalent Volterra model is linear with regard to the involved parameters; however, the number of the resulting free parameters is significantly increased with the order of the polynomial and the filter memory taps (*M*₁ and *M*₂). The interesting feature is that the equivalent to a Hammerstein model Volterra expansion consists only of the diagonal elements of the associated Volterra kernels. In other words, the output is expressed in terms of *u*[*n*], *u*[*n* − 1], *u*[*n* − 2], … and their powers; there are no cross-product terms [60].
