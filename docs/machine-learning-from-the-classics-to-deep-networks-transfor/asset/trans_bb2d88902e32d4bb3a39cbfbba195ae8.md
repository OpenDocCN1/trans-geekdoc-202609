
之前的讨论“迫使”我们将隐藏层视为一个个相邻节点的集合。而在 CNN 中，每个隐藏层对应一个（或多个，稍后将见）矩阵 `H`。此外，`H` 用于执行卷积运算。从信号处理的角度来看，该矩阵是一个*滤波器*，它作用于输入以产生输出。在机器学习术语中，它也被称为*核*矩阵，而非滤波器。输出矩阵通常被称为*特征图*数组。

总之，通过执行卷积运算而非内积运算，我们实现了最初的目标：(a) 组成隐藏层的参数被*所有*输入像素*共享*，我们不再为每个输入元素（像素）配备专用的参数集；(b) 隐藏层的输出编码了输入图像各区域内的局部邻域相关信息。此外，由于隐藏层的输出也是一个图像数组，可以将其视为第二个隐藏层的输入，从而构建一个包含许多层的网络，每一层都执行卷积运算。

事实上，这种滤波操作传统上被用于从图像中生成特征。不同之处在于，滤波器矩阵的元素是*预先选定*的。以此矩阵为例：

```
H = \begin{bmatrix} {- 1\ } & {- 1\ } & {- 1} \\ {- 1\ } & {8\ } & {- 1} \\ {- 1\ } & {- 1\ } & {- 1} \\ \end{bmatrix}.
```

![Equation](images/B978044329238500024X/si385.png)(18.64)

上述滤波器被称为*边缘检测器*。将图像数组 `I` 与前述矩阵 `H` 进行卷积，可检测图像中的边缘。[图 18.19](#Chp018_885-995_B978044329238500024X.xhtml#f0105)A 显示了小船图像，[图 18.19](#Chp018_885-995_B978044329238500024X.xhtml#f0105)B 显示了用上述滤波器矩阵 `H` 对左侧图像进行滤波后的输出。边缘检测在图像理解中至关重要。此外，通过适当改变 `H` 中的值，可以检测不同方向的边缘，例如对角线、垂直、水平；换言之，改变 `H` 的值可以生成不同类型的特征。我们已更接近 CNN 背后的核心思想。

*   •  不使用*固定*的滤波器/核矩阵（如边缘检测器示例），而是将滤波器矩阵 `H` 的值的计算交给训练阶段。换句话说，我们使 `H` 具有数据自适应性，而非预先选定。

*   •  不使用单个滤波器矩阵，而是采用多个。每个矩阵将生成不同类型的特征。例如，一个可能生成对角线边缘，另一个生成水平边缘等。因此，每个隐藏层将包含多个滤波器矩阵。每个滤波器矩阵的元素值将在训练阶段通过优化某个准则来估计/学习。换句话说，CNN 的每个隐藏层都能*最优地*生成一组特征。

[图 18.20](#Chp018_885-995_B978044329238500024X.xhtml#f0110) 展示了 CNN 的输入和第一隐藏层。输入包含一个图像数组。隐藏层由三个滤波器矩阵组成，即 `H`[1]、`H`[2]、`H`[3]。观察可知，每个特征图数组都是将不同的滤波器矩阵在输入图像上滑动（卷积）得到的结果。使用的滤波器越多，提取的特征图越多，原则上网络性能应越好。然而，使用的滤波器越多，需要学习的参数也越多，从而引发计算量以及过拟合问题。请注意，输出特征图数组中的每个像素编码了由相应滤波器矩阵对应位置所定义的窗口区域内的信息。

CNN 的一个重要特性是*平移不变性*天然内嵌于网络中，它是卷积运算的副产品。确实，卷积是通过将*同一个*滤波器矩阵在整个图像上滑动来执行的。因此，如果图像中存在的某个物体被放置到另一个位置，唯一的区别仅在于该物体对输出的贡献也会在像素数量上移动相同的距离。

值得注意的是，视觉神经科学领域有有力证据表明，人脑中也执行着类似的计算（例如 [85,185]）。卷积的概念最早是在文献 [46] 中用于无监督学习背景下的。

下面提供一些结合 CNN 使用的术语。

*   •  *深度*：一层的深度是指该层所采用的滤波器矩阵的数量。这不要与网络的深度混淆，后者对应所使用的隐藏层总数。有时，我们将滤波器的数量称为*通道*数。
