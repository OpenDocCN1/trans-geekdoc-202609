
# 10.2.1 贪婪算法

在上一章中，我们的重点是强调从欠定线性方程组恢复稀疏信号/参数向量的理论中一些最重要的方面。现在我们将注意力转向该问题的算法层面（例如，[52,54]）。目前的问题变成了讨论能够实现未知参数集恢复的*高效*算法方案。在第[9.3](#Chp009_417-462_B9780443292385000159.xhtml)节和第[9.5](#Chp009_417-462_B9780443292385000159.xhtml)节中，我们看到约束 ℓ<sub>1</sub> 范数最小化（基追踪）可以通过线性规划技术求解，LASSO 任务可以通过凸优化方案求解。然而，此类通用技术往往效率低下，因为它们通常需要许多迭代才能收敛，且相应的计算资源对于实际应用可能过大，尤其是在高维空间 ℝ<sup>l</sup> 中。因此，为了开发针对这些特定任务量身定制的高效算法，投入了大量的研究精力。我们的目标是为读者提供一些表征相关研究活动的总体趋势和理念。我们将重点关注最常用和被引用最多的算法，这些算法在结构上同时也很简单，因此读者无需深厚的优化知识即可理解它们。此外，这些算法以某种方式涉及的论据，与我们在阐述理论时已使用的概念直接相关；因此，它们也可以从教学角度被利用，以加深读者对该主题的理解。我们首先回顾批处理算法这一类，其中假设所有数据在算法应用前均可用，然后我们将转向在线/时变自适应方案。此外，我们的重点在于适用于任意感知矩阵的算法。之所以这样说明，是为了指出在文献中，针对特定形式的高度结构化感知矩阵，也开发了高效算法，利用其特定结构可降低计算需求 [61,93]。

这类算法研究活动大致沿着三个家族发展：(a) 贪婪算法，(b) 迭代收缩方案，和 (c) 凸优化技术。我们使用“大致”一词是因为在某些情况下，很难将某个算法归属到特定家族。
