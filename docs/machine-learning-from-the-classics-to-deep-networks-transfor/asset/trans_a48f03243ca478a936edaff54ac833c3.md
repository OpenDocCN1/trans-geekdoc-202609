
拉普拉斯矩阵 `L` 是对称且半正定的。后者从公式 [(20.109)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq167) 的定义中显而易见，其中 `E[L]` 始终是一个非负标量。请注意，`D[ii]` 的值越大，样本 `x_i` 就越“重要”。这是因为它意味着 `W(i, j), j = 1, 2, …, N` 具有较大的值，并在最小化过程中起主导作用。显然，`E[L]` 的最小值由平凡解 `z[i] = 0, i = 1, 2, …, N` 实现。为避免这种情况，正如此类情况的常见做法，我们将解约束为一个预设范数。因此，我们的问题现在变为

```
min_z z^T L z, s.t. z^T D z = 1.
```

虽然我们可以直接处理上述任务，但我们将对其稍作重塑，以便使用更熟悉的工具。定义

```
y = D^(1/2) z,
```

和

```
L̃ = D^(-1/2) L D^(-1/2),
```

这被称为*归一化图拉普拉斯*矩阵。现在很容易看出，我们的优化问题变为

```
min_y y^T L̃ y,
```

s.t. `y^T y = 1`。

使用拉格朗日乘数法并令拉格朗日函数的梯度为零，可得解由下式给出

```
L̃ y = λ y.
```
