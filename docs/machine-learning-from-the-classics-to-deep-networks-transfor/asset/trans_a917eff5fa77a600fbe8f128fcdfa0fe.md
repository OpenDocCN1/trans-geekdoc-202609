
后者被称为*尖峰和平板*先验。其名称源于这样一个事实：如果 `s[k] = 0`，则在零点施加一个“尖峰”，而值 `s[k] = 1` 施加一个“平板”，因为高斯分布是一个宽阔的分布（对于足够大的 `σ²`）。相应的后验不是高斯分布，其计算可以通过调用近似推断技术来完成，例如变分推断或蒙特卡洛方法（参见，例如，[29] 及其参考文献）。

基本尖峰和平板方案的变体也存在（参见，例如，[80]）。在后一参考文献中，表明可以将基于经典 `ℓ₀` 的稀疏性约束强加于最小二乘（LS）准则（第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章）作为这些变体之一的极限情况获得。这条路径提供了概率方法和基于优化的稀疏性技术之间的另一种联系。另一种联系将在第 [13.9](#Chp013_635-716_B9780443292385000196.xhtml#s0075) 节中讨论。

## 13.7 相关向量机框架

文献 [88] 的工作中一个重要方面是引入了用于回归和分类的*相关向量机*。受第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章讨论的支持向量回归（SVR）启发，考虑了一个特定的回归模型，即：

```
y(x) = θ₀ + ∑_{k=1}^{N} θ_k κ(x, x_k) + η.
```

换句话说，考虑了公式 [(12.1)](#Chp012_583-634_B9780443292385000184.xhtml) 的一般回归模型，其中 `K = N + 1`，`N` 是观测值的数量，且

```
ϕ_k(x) = κ(x, x_k),
```

其中 `κ(⋅, ⋅)` 是核函数，定义见第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章，以输入观测点 `x[k]` 为中心，`k = 1, 2, …, N`。因此，参数的数量变得等于（加一）训练点的数量。

该任务可以通过 SBL 理念或通过采用变分近似原理来处理，以施加稀疏性。文献 [88] 指出，变分贝叶斯方法在计算上更为密集，在实践中得到的超参数均值与使用 SBL 方法获得的值相同。

受 SVR 中支持向量定义的启发，对公式 [(13.67)](#Chp013_635-716_B9780443292385000196.xhtml#deq96) 有贡献的幸存数据点被称为*相关向量*。此外，RVM 框架中使用的核函数不必是对称正定函数，因为建模不一定与再生核希尔伯特空间（RKHS）相关联。
