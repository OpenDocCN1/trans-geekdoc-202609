`P(n[0] | λ[1], λ[2], x[1:N])`

此外，`λ[1]` 和 `λ[2]` 的确切值未知。唯一可用的信息是泊松过程强度 `λ[i]`（`i = 1, 2`）服从先验伽马分布，即：

```
p(λ) = Gamma(λ|a,b) = (1/Γ(a)) * b^a * λ^(a-1) * exp(-bλ),
```

其中 `a`、`b` 为已知正值。最后我们假设对变化时刻没有先验信息；因此先验选择为均匀分布 `P(n_0) = 1/N`。基于上述假设，对应的联合分布由下式给出：

`p(n[0], λ[1], λ[2], x[1:N]) = p(x[1:N] | λ[1], λ[2], n[0]) * p(λ[1]) * p(λ[2]) * P(n[0])`
