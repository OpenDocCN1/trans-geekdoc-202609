ℓ₁ 最小化问题可以转化为标准线性规划（LP）形式，随后可通过调用任何相关方法求解；单纯形法和较新的内点法是两种可能的选择（参见，例如 [14,33]）。确实，考虑如下 LP 任务：

```
min_x c^T x, s.t. Ax = b, x ≥ 0.
```

要验证我们的 ℓ₁ 最小化问题可以转化为上述形式，首先注意到任意 *l* 维向量 **θ** 可以分解为

**θ** = **u** − **v**, **u** ≥ 0, **v** ≥ 0.

确实，例如当以下情况成立时，该等式成立：

**u** := **θ**₊, **v** := (−**θ**)₊,
