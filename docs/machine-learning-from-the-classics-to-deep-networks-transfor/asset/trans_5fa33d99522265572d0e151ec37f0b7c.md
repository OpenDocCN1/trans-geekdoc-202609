
请注意，如果 `P(x) = 0`，则 `P(x)log P(x) = 0`，这是考虑到 `lim[x→0] x log x = 0`。

同样地，两个随机变量 `x, y` 之间的*平均互信息*定义为

```
I(x;y) := ∑_{x ∈ X} ∑_{y ∈ Y} P(x,y) I(x;y)
       = ∑_{x ∈ X} ∑_{y ∈ Y} P(x,y) log (P(x|y) / P(x))
       = ∑_{x ∈ X} ∑_{y ∈ Y} P(x,y) log (P(x|y)P(y) / (P(x)P(y)))
```

或

![Equation](images/B9780443292385000081/fx034.jpg) (2.150)

可以证明

`I(x; y) ≥ 0`

且当 x 和 y 统计独立时为零（问题 [2.12](#Chp002_19-64_B9780443292385000081.xhtml#o0065)）。

相比之下，给定 y 时 x 的*条件熵*定义为

![Equation](images/B9780443292385000081/fx035.jpg) (2.151)

考虑到概率乘积法则，很容易证明

`I(x; y) = H(x) − H(x|y)` (2.152)

### 引理 2.1

**随机变量** `x ∈ X` **的熵在所有可能值** `x ∈ X` **等概率时取得最大值。**

**证明**

证明见问题 [2.14](#Chp002_19-64_B9780443292385000081.xhtml#o0075)。 □

换句话说，熵可以被视为随机发射符号的信源随机性的度量。最大值对应于将要发射内容的最大不确定性，因为当所有符号等概率时出现最大值。熵的最小值等于零，这对应于除一个事件发生概率等于一之外，所有事件发生概率均为零的情况。
