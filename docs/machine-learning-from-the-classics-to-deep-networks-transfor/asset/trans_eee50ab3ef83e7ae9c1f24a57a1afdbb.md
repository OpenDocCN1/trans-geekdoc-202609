
RLS 算法与卡尔曼滤波器（在第 [4.10](#Chp004_119-175_B978044329238500010X.xhtml) 节中讨论）具有相似的数值行为；`P[n]` 可能会失去其正定性和对称性，进而导致算法发散。为了克服这种倾向，已经推导出了保持对称性的 RLS 算法版本；参见 [65,68]。请注意，使用 `β < 1` 对误差传播有益 [30,34]。文献 [58] 指出，当 `β = 1` 时，误差传播机制属于随机游走类型，因此算法是不稳定的。文献 [5] 指出，由于数值误差，项 `1 / (β + x_n^T P_{n-1} x_n)` 可能变为负值，从而导致发散。在使用有限精度（如定点运算）的实现中，RLS 的数值性能问题变得更加严重。与 LMS 相比，RLS 需要使用更高精度的实现；否则，可能在几次迭代步骤后就发生发散。这进一步增加了其相对于 LMS 的计算劣势。

初始化步骤中 `λ` 的选择已在文献 [46] 中探讨。相关理论分析表明 `λ` 直接影响收敛速度，其选择应为：高信噪比 (SNR) 时取较小的正常数，低信噪比时取较大的正常数。

文献 [56] 已证明 RLS 算法可以作为卡尔曼滤波器的一个特例获得。

RLS 的主要优势在于其收敛到稳态的速度比 LMS 和 LMS 系列的其他成员快得多。这可以由以下事实来证明：RLS 可以被视为牛顿迭代优化方法的衍生算法，该方法将在下一节中讨论。

RLS 的分布式版本已在文献 [8,39,40] 中提出。
