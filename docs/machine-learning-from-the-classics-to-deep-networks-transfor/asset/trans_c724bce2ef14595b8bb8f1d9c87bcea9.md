
从[表 6.1](#Chp006_249-291_B9780443292385000123.xhtml#t0010)可以看出，算法可能快速收敛到稳态，但不一定能快速跟踪。这完全取决于具体场景。例如，在[表 6.1](#Chp006_249-291_B9780443292385000123.xhtml#t0010)相关的建模假设下，LMS（第[5.12](#Chp005_177-248_B9780443292385000111.xhtml)节）的最优值`μ_opt`由下式给出：

```
μ_opt = √(trace{Σ_ω} / (σ_η² trace{Σ_x}))
```

这对应于：

```
J_min^LMS = √(σ_η² trace{Σ_x} trace{Σ_ω})
```

针对 RLS 优化 `β`，很容易证明：

```
β_opt = 1 - √(trace{Σ_ω Σ_x} / (σ_η² l))
J_min^RLS = √(σ_η² l trace{Σ_ω Σ_x})
```

因此，比率：

取决于 `Σ_ω` 和 `Σ_x`。**有时 LMS 跟踪效果更好，但在其他问题中 RLS 更胜一筹**。话虽如此，必须指出的是 RLS **总是**收敛得更快，与 LMS 相比，收敛速率的差异随输入协方差矩阵的条件数增加而增加。
