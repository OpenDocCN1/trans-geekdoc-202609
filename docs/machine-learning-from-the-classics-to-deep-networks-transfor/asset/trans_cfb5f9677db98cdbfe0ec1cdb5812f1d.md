

## 18.3 前馈多层神经网络

*   **ADALINE**：在 Rosenblatt 提出感知机后不久，Widrow 和 Hoff 提出了*自适应线性元件*（ADALINE），它是感知机的线性版本 [218]。也就是说，在训练过程中不涉及激活函数的非线性。由此产生的方案是 LMS 算法，第 5 章对此进行了详细论述。值得注意的是，LMS 算法很容易被采纳，并在信号处理和通信领域被广泛用于在线学习。
*   **感知机算法的核化版本**也已被推导出来，感兴趣的读者可以通过本书网站上与本章相关的“附加材料”部分获取。

单个神经元与输入（特征）空间中的一个超平面相关联

```
H: θ₁x₁ + θ₂x₂ + … + θₗxₗ + θ₀ = 0
```

此外，分类是通过非线性函数执行的，该函数根据点位于 `H` 的哪一侧，输出 1 或保持为 0。我们现在将展示如何以逐层的方式组合神经元，以构建非线性分类器。我们将遵循一个简单的构造性证明，这将揭示神经网络的某些方面。稍后在处理深度架构时，这些方面将很有用。

作为起点，我们考虑特征空间中的类由多面体区域的并集形成的情况。对于二维特征空间的情况，这在[图 18.3](#Chp018_885-995_B978044329238500024X.xhtml#f0020)中展示。多面体区域是作为半空间的交集形成的，每个半空间与一个超平面相关联。在[图 18.3](#Chp018_885-995_B978044329238500024X.xhtml#f0020)中，有三个超平面（ℝ² 中的直线），分别标记为 `H₁`、`H₂`、`H₃`，形成了七个多面体区域。对于每个超平面，其 (+) 和 (–) 侧（半空间）均已标出。在后续内容中，每个区域根据其相对于 `H₁`、`H₂`、`H₃` 所在的侧面，使用三个二进制数的三元组进行标记。例如，标记为 (101) 的区域位于 `H₁` 的 (+) 侧、`H₂` 的 (–) 侧和 `H₃` 的 (+) 侧。
