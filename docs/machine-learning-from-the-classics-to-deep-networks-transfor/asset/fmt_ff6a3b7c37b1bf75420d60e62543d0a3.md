
The Hessian matrix is also positive definite, which guarantees uniqueness of the minimum as in the two-class case.

## Remarks 7.4

*   **Probit regression**: Instead of using the logistic sigmoid function in Eq. [(7.30)](#Chp007_293-342_B9780443292385000135.xhtml#deq56) (for the two-class case), other functions can also be adopted. A popular function in the statistical community is the *probit* function, which is defined as

```
Φ(t) := ∫_{-∞}^{t} N(z|0,1) dz = 1/2 (1 + 1/√2 erf(t))
```

![Equation](images/B9780443292385000135/si202.png)(7.53)

*   where `erf` is the *error* function defined as

```
erf(t) = 2/√π ∫_{0}^{t} exp(-z²/2) dz
```

![Equation](images/B9780443292385000135/si203.png)

*   In other words, `P(ω₁|t)` is modeled to be equal to the probability of a normalized Gaussian variable to lie in the interval (−∞, t]. The graph of the probit function is very similar to that of the logistic one.

## 7.7 Fisher's linear discriminant

```

In this section, the unknown parameter vector will be estimated via a path that exploits a number of important notions relevant to classification.
