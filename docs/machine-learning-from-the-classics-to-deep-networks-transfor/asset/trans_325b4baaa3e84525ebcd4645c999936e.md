$$
\kappa_i(\cdot,\cdot) : \mathcal{X} \times \mathcal{X} \mapsto \mathbb{R}, \quad i = 1, 2,

*   $\kappa(\mathbf{x},\mathbf{y}) = \kappa_1(\mathbf{x},\mathbf{y})\kappa_2(\mathbf{x},\mathbf{y})$ 也是核。
