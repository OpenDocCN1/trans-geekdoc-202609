## 算法初始化设置

对于 EM 算法，初始均值是使用高斯分布 `𝒩(μ|0, I)` 随机生成的，相应的初始协方差矩阵 `Σ[k]^(0)`（`k = 1, 2, …, 25`）包含随机元素，并确保它们是正定的。

![Equation](images/B9780443292385000196/si199.png)
![Equation](images/B9780443292385000196/si200.png)

实现正定矩阵的一种方法是生成一个元素来自 `𝒩(0, 1)` 的矩阵 `Φ`，然后形成 `Φ^T Φ`。
