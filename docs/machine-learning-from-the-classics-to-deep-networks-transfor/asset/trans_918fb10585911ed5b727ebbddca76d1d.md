
相比之下，与公式 [(14.28)](#Chp014_717-754_B9780443292385000202.xhtml#deq50) 相关的估计量，作为一个比率的结果，仅在渐近意义上是无偏的，对于有限的 `N` 值，它是一个 `biased`（有偏）估计量（问题 [14.6](#Chp014_717-754_B9780443292385000202.xhtml#o0035)）。因此，如果拥有非常大量样本 `N` 的奢侈条件，公式 [(14.28)](#Chp014_717-754_B9780443292385000202.xhtml#deq50) 将是一个足够好的估计。然而，在实践中，`N` 无法任意增大，由此产生的估计可能并不令人满意。

如果 `q(x) ≈ p(x)`，或者至少 `q(x)` 是 `ϕ(x)` 的一个相当好的近似，那么公式 [(14.28)](#Chp014_717-754_B9780443292385000202.xhtml#deq50) 将近似公式 [(14.2)](#Chp014_717-754_B9780443292385000202.xhtml#deq2)。然而，对于大多数实际情况，这并不容易实现，尤其是在高维空间中。如果 `q(x)` 与 `ϕ(x)` 不匹配，则很可能存在一些区域，在这些区域 `ϕ(x)` 很大而 `q(x)` 却小得多。相应的权重将具有相对于其他区域较大的值，并且它们将在求和中占主导地位（公式 [(14.28)](#Chp014_717-754_B9780443292385000202.xhtml#deq50)）。

其效果等同于减少样本数 `N`。此外，`q(x)` 在某些区域取极小值也是可能的，这使得在公式 [(14.28)](#Chp014_717-754_B9780443292385000202.xhtml#deq50) 中，来自这些区域的样本极有可能完全缺失（参见 [图 14.7](#Chp014_717-754_B9780443292385000202.xhtml#f0040)）。在这种情况下，不仅结果估计可能是错误的，而且我们不会意识到这一点，而权重 `w(x[n])` 和 `w(x[n])f(x[n])` 的方差可能表现出较低的值。*这些现象在高维空间中更加突出*（参见，例如，[26] 和问题 [14.7](#Chp014_717-754_B9780443292385000202.xhtml#o0040)）。
