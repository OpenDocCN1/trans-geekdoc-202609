### 5. (e)
Increase `m` by 1 and go back to Step 4a.

### 5. Form the vector
Form the vector `\widehat{\mathbf{p}} \in \mathbb{R}^{r_{m_{\ast}}}` whose `j`th component, `j = 1, ..., r[m[*] ]`, is given by

```
\widehat{p}_j := |\theta_{\tau(j)}| - \frac{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)} |\theta_{\tau(i)}| - \rho}{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)}^2} w_{\tau(j)}.
```

### 6. Use the inverse mapping
Use the inverse mapping `\tau^{-1}` to insert the element `\hat{p}[j]` into the `\tau^{-1}(j)` position of the `l`-dimensional vector `\mathbf{p}`, `\forall j \in {1, 2, ..., r[m[*]]}`, and fill in the rest with zeros.

### 7. The desired projection
The desired projection is `P[B[\ell_1][\mathbf{w}, \rho]](\mathbf{\theta}) = [sgn(\theta_1)p_1, ..., sgn(\theta_l)p_l]^{(T)}`.
