

## 2. 未知向量估计算法

对于未知向量估计，采用以下算法：

- 组合后自适应扩散 APSM ([算法 8.3](#Chp008_343-416_B9780443292385000147.xhtml#enun0150))
- 自适应后组合 LMS ([算法 5.7](#Chp005_177-248_B9780443292385000111.xhtml))
- 组合后自适应 LMS ([算法 5.8](#Chp005_177-248_B9780443292385000111.xhtml))
- 非合作 LMS ([算法 5.1](#Chp005_177-248_B9780443292385000111.xhtml))

### 组合后自适应 APSM 参数
按如下方式设置参数：
- `\mu[n] = 0.5 \times M[n]`
- `\epsilon_k = \sqrt{2}\sigma_k`
- `q = 20`

### LMS 算法参数
对于自适应后组合、组合后自适应和非合作 LMS，将步长设置为 `0.03`。

### 组合权重
最后，根据梅特罗波利斯规则 ([备注 5.4](#Chp005_177-248_B9780443292385000111.xhtml)) 选择组合权重 `a[mk]`。

## 3. 仿真设置

运行 100 次独立实验，并绘制每次迭代的平均 MSD（以 dB 为单位）：

```
MSD(n) = 10\log_{10}\left( \frac{1}{K}\sum_{k=1}^{K}{\|\mathbf{\theta}_k(n) - \mathbf{\theta}_o\|}^2 \right)
```

2.  不断尝试所涉及算法的不同参数值，并观察它们对所获得性能的影响。
