### 近似误差、估计误差和优化误差

回顾一下，在机器学习任务中，我们所拥有的仅仅是可用的训练样本集。为了设定“游戏规则”，设计者必须决定选择 (a) 损失函数 `ℒ(⋅, ⋅)`，它度量预测值与目标值之间的偏差（误差）；以及 (b) （参数化）函数集 `ℱ`，

```
ℱ = {f[θ]: θ ∈ ℝ^(K)}.
```

基于 `ℒ(⋅, ⋅)` 的选择，*基准* 函数，记为 `f[*]`，是使期望损失最小化的那个函数（另见第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章），即，^([^(57)](#fn57))

```
f_* = argmin_f 𝔼 [ ℒ( y, f(x) ) ],
```

或等价地

```
f_*(x) = argmin_ŷ 𝔼 [ ℒ( y, ŷ ) | x ]. (8.91)
```
