

$$\\mathbf{\\theta}\_{n + 1}|\\mathbf{\\theta}\_{1},\\ldots,\\mathbf{\\theta}\_{n} \\sim \\frac{\\alpha}{\\alpha + n}G\_{0} + \\frac{n}{\\alpha + n}\\left( \\frac{1}{n}\\sum\\limits\_{i = 1}^{K\_{n}}n\_{i}\\delta\_{\\mathbf{\\theta}\_{i}^{\\ast}}(\\mathbf{\\theta}) \\right).$$

![Equation](images/B9780443292385000196/si474.png)

观察可知，上述公式直接导出了公式 [(13.111)](#Chp013_635-716_B9780443292385000196.xhtml#deq167)（如果将其应用于第 *n* 位顾客而非第 *n* + 1 位顾客）。确实，我们要么选择一种新颜色（在 CRP 情况下为桌子），要么选择第 *i* 种先前已选的颜色，其概率为 $\\frac{n\_{i}}{\\alpha + n}$，*i* ≤ *K*[*n*]。回顾第 [13.11.1](#Chp013_635-716_B9780443292385000196.xhtml#s0105) 节，根据此规则，聚类的期望数量按 *α*ln *n* 增长。

得到 CRP 的另一种途径是将其作为有限混合建模的极限情况（*K* → ∞），通过采用参数为 *α*/*K* 的狄利克雷先验来实现（参见，例如，\[23,74\]）。

**聚类分配具有可交换性**：CRP 的一个重要方面是，特定聚类的概率不依赖于顾客到达的顺序，并且在重新洗牌顾客后保持不变，仅表现为桌子标签的一个排列（参见问题 [13.22](#Chp013_635-716_B9780443292385000196.xhtml#o0210)）。换句话说，这意味着在 [图 13.14](#Chp013_635-716_B9780443292385000196.xhtml#f0080) 中，重要的是例如顾客 #1、#4、#5 坐在*同一*张桌子旁，而顾客 #3 独自坐在一张桌子旁。桌子的编号并不重要。
