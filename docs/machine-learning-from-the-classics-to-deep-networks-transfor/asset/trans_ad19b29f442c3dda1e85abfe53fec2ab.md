尽管这种模型的构想听起来可能有点“玄乎”，但只要更仔细地观察公式 [(7.17)](#Chp007_293-342_B9780443292385000135.xhtml#deq30)–[(7.18)](#Chp007_293-342_B9780443292385000135.xhtml#deq31) 就足以揭开其神秘面纱。假设两类任务中的数据服从高斯分布，且 `Σ[1] = Σ[2] ≡ Σ`。在这些假设下，并考虑贝叶斯定理，可以写出

```
ln(P(ω₁|x)/P(ω₂|x)) = ln(p(x|ω₁)P(ω₁)/p(x|ω₂)P(ω₂))
```
(7.33)

```
= ln p(x|ω₁) + ln P(ω₁) − (ln p(x|ω₂) + ln P(ω₂))
```
(7.34)

```
= g(x).
```
(7.35)

此外，我们知道在上述假设下，`g(x)` 由公式 (7.20)–(7.22) 给出；因此，我们可以写出

```
ln(P(ω₁|x)/P(ω₂|x)) = (μ₁ − μ₂)ᵀ Σ⁻¹ x + constants,
```
(7.36)

其中“constants”指所有不依赖于 `x` 的项。换句话说，当描述数据的分布是具有共同协方差矩阵的高斯分布时，后验概率的对数比是一个 *线性* 函数。因此，在 logistic 回归中，我们所做的就是向前迈进一步，采用这种线性模型，而不管底层数据分布如何。
