
本节旨在介绍非线性降维领域中一些最基础的研究方向。除了前述基本方案外，文献中还提出了许多变体（例如，[21, 70, 163]）。在文献 [150] 和 [118]（扩散映射）中，低维嵌入的实现旨在保留反映图 `G(V, E)` 连通性的某些度量。在文献 [30, 101] 中，利用保留流形局部信息的思想来定义形式为 `z = A^T x` 的线性变换，优化目标转变为针对 `A` 的元素进行。文献 [121] 最近探讨了用于降维的增量流形学习任务。文献 [172, 184] 引入了最大方差展开方法。在图中保留邻居间（局部）距离和角度的约束下，最大化输出的方差。与 ISOMAP 类似，该方法最终需要计算 Gram 矩阵的前几个特征向量，但避免了 ISOMAP 所需的、计算量大的测地距离估计步骤。文献 [164] 提出了一个称为图嵌入的通用框架，它为理解和解释许多已知的（包括 PCA 和非线性 PCA）降维技术提供了统一视角，同时也为开发新技术提供了平台。关于该主题更详细、更深入的论述，请参阅文献 [29]。非线性降维技术的综述可参见文献 [32, 123] 等。

### Example 20.7

设有一个由 30 个点组成的数据集位于二维空间中。这些点源自阿基米德螺旋线的采样（参见 [Fig. 20.18](#Chp020_1103-1179_B9780443292385000263.xhtml#f0115) A），其方程描述为：

```
x[1] = a * θ * cos θ,  x[2] = a * θ * sin θ.
```

数据集中的点对应的 `θ` 值为 `0.5π, 0.7π, 0.9π, …, 2.05π`（`θ` 以弧度为单位），且 `a = 0.1`。为了演示目的并保持对“邻域”信息的跟踪，我们使用了一组包含六个符号的序列：“x”、“+”、“⋆”、“□”、“⋄” 和 “∘”（黑色），随后重复使用相同序列的红色符号。

**Figure 20.18** (A) 二维空间中的阿基米德螺旋线。(B) 上述螺旋线及采样点在第一主成分方向上的投影（PCA 结果）。显而易见，投影后邻域信息丢失，螺旋线不同部分对应的点发生重叠。(C) 使用拉普拉斯方法得到的螺旋线一维映射。在这种情况下，非线性投影后保留了邻域信息，螺旋线完美地展开为一维直线。

为了研究 PCA 在数据位于非线性流形这一情况下的表现，我们首先对从数据集估计出的协方差矩阵进行了特征分解。得到的特征值为：

```
λ[2] = 0.089  and  λ[1] = 0.049.
```

观察可知，特征值的大小相当。因此，若完全信赖 PCA 的“判决”，关于数据维度的结论将是 2。此外，沿主成分方向（[Fig. 20.18](#Chp020_1103-1179_B9780443292385000263.xhtml#f0115) B 中的直线）投影，该方向对应 `λ[2]`，会导致邻域信息丢失，因为来自不同位置的点混合在了一起。

随后，采用拉普拉斯特征映射技术进行降维，参数设为 `ϵ = 0.2` 和 `σ = √0.5`。结果如 [Fig. 20.18](#Chp020_1103-1179_B9780443292385000263.xhtml#f0115) C 所示。从右向左观察，拉普拉斯方法将螺旋线完美地“展开”成了一条一维直线。此外，该数据的一维表示保留了邻域信息。黑色和红色区域按正确顺序依次排列，观察符号也可发现，邻域点被映射为邻域点。
