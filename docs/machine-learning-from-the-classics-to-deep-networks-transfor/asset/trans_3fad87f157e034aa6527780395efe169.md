
令 **σ**[*M*] 表示包含 *M* 所有奇异值的向量，即 **σ**[*M*] = [*σ*[1], *σ*[2], ⋯, *σ*[*l*]]^(*T*)。则 *r**a**n**k*(*M*) = ∥**σ**[*M*]∥[0]。统计公式 [(20.119)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq181) 中与奇异值和奇异向量相关的参数，可知 *r* 秩矩阵的自由度数目等于 *d*[*M*] = *r*(*l*[1] + *l*[2]) − *r*² ([问题 20.8](#Chp020_1103-1179_B9780443292385000263.xhtml#o0110))。当 *r* 很小时，*d*[*M*] 远小于 *l*。

令 Ω 表示 *N* 对索引 (*i*, *j*) 的集合，其中 *i* = 1, 2, …, *l*[1]，*j* = 1, 2, …, *l*[2]，这些索引对应 *M* 已知条目的位置，且均匀随机采样而得。采用与稀疏感知学习主干逻辑相似的原理，人们会尝试基于以下秩最小化问题来恢复 *M*：

```
\min\limits_{\widehat{M} \in \mathbb{R}^{l_{1} \times l_{2}}}\left\| \mathbf{\sigma}_{\widehat{M}} \right\|_{0},\text{s.t.}\widehat{M}(i,j) = M(i,j),\quad(i,j) \in \Omega.
```

(20.120)

结果表明，假设存在一个唯一的低秩矩阵，其元素为这些特定的已知条目，则 [(20.120)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq182) 中的任务能得到精确解 [33]。然而，与稀疏向量的情况相比，矩阵补全问题中的唯一性问题要复杂得多。以下问题对 [(20.120)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq182) 中任务的唯一性起着至关重要的作用。

1.  **1.** 如果已知条目的数量少于自由度数目，即 *N* < *d*[*M*]，那么无论怎样都无法恢复缺失条目，因为存在无限多个与 *N* 个观测条目一致的低秩矩阵。
