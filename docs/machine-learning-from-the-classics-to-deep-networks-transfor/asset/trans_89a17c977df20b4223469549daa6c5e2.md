
原则上，可以在算法中增加一个额外的 M 步，以最大化关于未知参数 `a`、`b`、`c` 和 `d` 的下界。然而，在实践中，为了计算简便，这些参数被固定为非常小的值，即 `a = b = c = d = 10^(-6)`，这对应于无信息伽马先验分布，意思是不偏好任何特定的值范围。注意，对于如此小的值，伽马分布按 `1/x` 下降。

```
Gamma(x|a,b) ≈ 1/x,  x > 0.
```

因为每个正数 `x` 都可以表示为

```
x = exp(z),  z = ln x,  z ∈ ℝ,
```

很容易验证（问题 [13.4](#Chp013_635-716_B9780443292385000196.xhtml#o0120)）描述 `z` 的 PDF 是均匀的。这是实践中的典型过程；即，允许足够多的层级，并将最高层的超参数固定以定义无信息超先验。

总之，变分贝叶斯 EM 步骤如 [算法 13.1](#Chp013_635-716_B9780443292385000196.xhtml#enun0015) 所示。
