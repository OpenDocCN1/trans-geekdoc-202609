
# 信息论之父

信息论之父是**克劳德·埃尔伍德·香农**（1916–2001），一位美国数学家和电气工程师。他于1948年在《贝尔系统技术期刊》上发表里程碑式论文“通信的数学理论”，奠基了信息论。然而，早在1937年，年仅21岁的他在麻省理工学院（MIT）攻读硕士学位时，便在其论文中证明了布尔代数的电气应用可以构建并解决任何逻辑、数值关系，从而被誉为数字电路设计理论的奠基人。因此，他也被视为数字计算机之父之一。在第二次世界大战期间，香农为国防工作做出贡献，将密码学从一门艺术转变为一门严谨的科学领域。

正如概率论一样，信息的概念也是我们日常词汇的一部分。在此语境下，如果一个事件对我们来说是未知的，或者其发生概率极低但实际却发生了，则该事件携带信息。例如，如果有人告诉我们撒哈拉沙漠夏天阳光明媚，我们会认为这种陈述相当枯燥无用。相反，如果有人带来撒哈拉沙漠夏天下雪的消息，该陈述包含大量信息，并可能引发关于气候变化的讨论。

因此，试图从数学角度形式化信息的概念，用事件概率的负对数来定义它是合理的。如果事件必然发生，其携带的信息量为零；然而，如果其发生概率很低，则其信息量具有较大的正值。

## 2.5.1 离散随机变量

### 信息

给定一个取值于集合 `𝒳` 中的离散随机变量 `x`，与任意值 `x ∈ 𝒳` 相关联的*信息*记为 `I(x)`，定义为

```
I(x) = -log P(x)          (2.145)
```

可以使用任意底数的对数。若选用自然对数，信息以*奈特*（自然单位）度量；若采用以2为底的对数，信息以*比特*（二进制数字）度量。采用对数函数定义信息也符合常识推理：两个统计独立事件的信息量应等于它们各自单独传达的信息量之和；`I(x, y) = -log P(x, y) = -log P(x) - log P(y)`。
