
其中 $H(z_i)$ 是 $z_i$ 相关的熵，定义见公式 [(2.157)](#Chp002_19-64_B9780443292385000081.xhtml)。在第 [2.5](#Chp002_19-64_B9780443292385000081.xhtml) 节中已表明，$I(\mathbf{z})$ 等于联合概率密度函数 (PDF) $p(\mathbf{z})$ 与各边缘概率密度乘积 $\prod_{i=1}^{l} p_i(z_i)$ 之间的 Kullback-Leibler (KL) 散度。KL 散度（因此相关的互信息 $I(\mathbf{z})$）是非负量，当分量 $z_i$ 统计独立时，它变为零。这是因为只有在这种情况下，联合 PDF 才等于相应边缘 PDF 的乘积，从而使 KL 散度为零。因此，现在的思路变为计算 $W$ 以使 $I(\mathbf{z})$ 最小化，因为这将使 $\mathbf{z}$ 的分量*尽可能独立*。将公式 [(20.45)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq60) 代入公式 [(20.51)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq72) 并考虑联系 $\mathbf{x}$ 和 $\mathbf{z}$ 这两个 PDF 的公式（公式 [(2.45)](#Chp002_19-64_B9780443292385000081.xhtml)），我们得到

```
I(\mathbf{z}) = - H(\mathbf{x}) - \ln|\text{det}(W)| - \sum_{i=1}^{l} \int p_i(z_i) \ln p_i(z_i)  dz_i.
```
(20.52)
