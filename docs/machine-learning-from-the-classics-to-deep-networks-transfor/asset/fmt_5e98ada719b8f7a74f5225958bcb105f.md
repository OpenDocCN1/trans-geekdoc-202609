
The interval in the real axis `[-10, 10]` was sampled at `N = 100` equidistant points `x[n]`, `n = 1, 2, …, 100`. The training data comprise the pairs `(y[n], x[n])`, `n = 1, 2, …, N`, where

```
y_n = exp(-1/2 * (x_n + 5.8)^2 / 0.1) + exp(-1/2 * (x_n - 2.6)^2 / 0.1) + η_n,
```

where `η[n]` are i.i.d. zero mean Gaussian noise samples of variance `σ[η]² = 0.015`. To fit the data, the following model was adopted:

```
y = Σ_{k=1}^{N} θ_k * exp(-1/2 * (x - x_k)^2 / 0.1).
```

Thus, the matrix `Φ` has the following elements:

```
[Φ]_{nk} = exp(-1/2 * (x_n - x_k)^2 / 0.1),  n = 1,2,…,N,  k = 1,2,…,N.
```
