
where `β[t] ∈ [0, 1)` is a sequence of process variances. Although this sequence could be learned, in a typical model it is fixed according to a user-defined schedule, see, e.g., [169]. For example, in [85], `β[1]` is set equal to `10^(-4)` and it increases linearly up to the value of `β[T] = 0.02`, where `T` is set equal to 1000. In other words, the conditional/transition distribution (see Chapter [14](#Chp014_717-754_B9780443292385000202.xhtml)) at time `t` is Gaussian with the mean value being a scaled version of `x[t-1]` and covariance matrix equal to `β[t]I`, where `I` is the identity matrix.

Due to the Gaussian nature of the conditionals, it is not difficult to show ([Problem 19.4](#Chp019_997-1102_B9780443292385000251.xhtml#o0060)) that the diffused version at time `t`, conditioned on the input observation, is described by,

```
q(x_t|x_0) = N( x_t|√(ā_t)x_0, (1 - ā_t)I ),
```

where `a[t] := 1 - β[t]` and `ā_t := ∏_{k=1}^t a_k`. Alternatively, given an observation `x[0]`, and using the reparameterization trick, discussed in Section [19.2.6](#Chp019_997-1102_B9780443292385000251.xhtml#s0065), we can write

```
x_t = √(ā_t)x_0 + √(1 - ā_t)ε,
```
