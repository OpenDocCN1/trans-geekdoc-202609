
## 7.11 Boosting trees

在[第 7.9 节](#Chp007_293-342_B9780443292385000135.xhtml#s0085)对各种方法的实验比较讨论中，曾指出提升树是分类和数据挖掘中最强大的学习方案之一。因此，有必要花更多时间研究这一特殊类型的提升技术。

树模型在[第 7.8 节](#Chp007_293-342_B9780443292385000135.xhtml#s0080)中已介绍。基于我们现在掌握的知识，不难看出树的输出可以紧凑地写为：

$$T(\mathbf{x};\mathbf{\Theta}) = \sum\limits_{j = 1}^{J}{\widehat{y}}_{j}\chi_{R_{j}}(\mathbf{x}) \tag{7.103}$$

其中 $J$ 是叶节点的数量，$R_{j}$ 是树施加的空间划分后与第 $j$ 个叶节点关联的区域，$\widehat{y}_{j}$ 是与 $R_{j}$ 关联的相应标签（回归的输出/预测值），$\chi$ 是我们熟悉的特征函数。参数集合 $\mathbf{\Theta}$ 由 $(\widehat{y}_{j}, R_{j}),\ j = 1, 2, \dots, J$ 组成，这些参数在训练期间估计得出。可以通过选择适当的代价函数获得这些参数。此外，通常采用次优技术来构建树，如[第 7.8 节](#Chp007_293-342_B9780443292385000135.xhtml#s0080)所述。

在提升树模型中，基分类器由一棵树组成。例如，[示例 7.5](#Chp007_293-342_B9780443292385000135.xhtml#enun0070)中使用的树桩是基树分类器的一个非常特殊的情况。在实践中，可以使用规模更大的树。当然，规模不能太大，以使其更接近弱分类器。通常建议 $J$ 的值在 3 到 8 之间。

提升树模型可以写为：

$$F(\mathbf{x}) = \sum\limits_{k = 1}^{K}T(\mathbf{x};\mathbf{\Theta}_{k}) \tag{7.104}$$

其中

$$T(\mathbf{x};\mathbf{\Theta}_{k}) = \sum\limits_{j = 1}^{J}{\widehat{y}}_{kj}\chi_{R_{kj}}(\mathbf{x})$$
