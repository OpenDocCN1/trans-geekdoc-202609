

## ISOMAP 算法

与前两种在局部基础上解析流形几何结构的方法相反，ISOMAP 算法采取的观点是：只有数据点所有配对之间的测地距离才能反映流形的真实结构。流形中各点间的欧氏距离无法恰当地表示该结构，因为按测地距离测量相距甚远的点，按欧氏距离测量时可能很近（参见 [图 20.17](#Chp020_1103-1179_B9780443292385000263.xhtml#f0110)）。ISOMAP 本质上是多维缩放（MDS）算法的一个变体，其中欧氏距离被沿流形的相应测地距离所替代。该方法的核心在于估计相距较远的点之间的测地距离。为此，采用了一个两步过程。

### 步骤 1

对每个点 `x_n, n = 1,2,...,N`，计算其最近邻并构建一个图 `G(V, E)`，其顶点代表数据点，边连接最近邻。（最近邻的计算采用拉普拉斯特征映射方法中使用的两种替代方案之一。参数 `k` 或 `ϵ` 为用户定义参数。）边根据相应的欧氏距离被赋予权重（对于最近邻而言，这是相应测地距离的一个良好近似）。

### 步骤 2

计算所有配对 `(i, j), i, j = 1, 2, …, N` 之间沿图中最短路径的成对测地距离。关键假设是：流形上任意两点之间的测地线可以用沿图 `G(V, E)` 连接这两点的*最短路径*来近似。为此，可以使用高效算法（如 Dijkstra 算法，[59]）以 `O(N²ln N + N²k)` 的复杂度来实现。当 `N` 取较大值时，此开销可能过于巨大。

估算出所有点对之间的测地线后，便调用 MDS 方法。因此，问题转化为对相应 Gram 矩阵进行特征分解，并选择 `m` 个最主要的特征向量来表示低维空间。映射后，低维子空间中点间的欧氏距离与原高维空间中流形上相应的测地距离相匹配。同 PCA 和 MDS 一样，`m` 由显著特征值的数量来估计。可以证明，ISOMAP 在渐近意义上（`N → ∞`）保证能恢复一类非线性流形的真实维数 [66,173]。

所有三种基于图的方法都共享在图中计算最近邻这一公共步骤。这是一个复杂度为 `O(N²)` 的问题，但可以通过采用特殊类型的数据结构（例如 [23]）来使用更高效的搜索技术。ISOMAP 与拉普拉斯特征映射和 LLE 方法之间的一个显著区别在于：后两种方法依赖于稀疏矩阵的特征分解，而 ISOMAP 依赖于稠密 Gram 矩阵的特征分解。这使得拉普拉斯特征映射和 LLE 技术具有计算优势。此外，ISOMAP 中最短路径的计算是另一项计算量大的任务。最后，值得注意的是：这三种基于图的技术在执行降维任务时，都试图以这样或那样的方式解析数据（近似）所依附的流形的几何属性。相比之下，核 PCA 并非如此，它对任何流形学习都不感兴趣。然而，世界很小，文献 [88] 指出，如果使用源自编码邻域信息的图的数据相关核函数来替代预定义的核函数，基于图的技术可以被视为核 PCA 的特例！
