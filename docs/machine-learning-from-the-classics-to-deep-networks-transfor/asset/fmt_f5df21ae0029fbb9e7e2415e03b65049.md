
### 算法步骤

*   **For** `n = 0, 1, …` **Do**
    1.  `e[n] = y[n] − θ[n−1]^(H) x[n] − v[n−1]^(H) x[n]^(*)`
    2.  `θ[n] = θ[n−1] + μ x[n] e[n]^(*)`
    3.  `v[n] = v[n−1] + μ x[n]^(*) e[n]^(*)`
*   **End For**

Note that whatever has been said for the stability conditions concerning the LMS is applied here as well, if `Σ[x]` is replaced by `Σ[x̃]`. For circularly symmetric variables, we set `v[n] = 0` and the *complex linear LMS* results.
