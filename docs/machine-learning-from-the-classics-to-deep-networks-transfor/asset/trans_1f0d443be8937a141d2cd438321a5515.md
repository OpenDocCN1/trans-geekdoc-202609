
这与LMS中使用的预测模型一致，在时刻`n`。也就是说，未知的参数集是一个时变集合。输入向量`x`以及噪声变量`η`的统计特性被假定为与时间无关，这也是我们未使用时间索引的原因；等价地说，在输入为随机过程`u[n]`的情况下，假定它是*平稳*的。此外，输入变量被假定与零均值噪声变量`η`相互独立。而且，`η`的连续样本是方差为`σ[η]²`的独立同分布（白噪声序列）。到目前为止，我们并未超出第[5.5.1](#Chp005_177-248_B9780443292385000111.xhtml#s0050)节所述的假设1太多。

### 假设 2

时变模型遵循随机游走变化，表示为

```
θ[o, n] = θ[o, n − 1] + ω
```

随机向量`ω`假定为零均值，协方差矩阵为

```
E [ω ω^(T)] = Σ[ω]
```

请注意，随机游走的方差随时间无限增长；通过递归应用公式[(5.73)](#Chp005_177-248_B9780443292385000111.xhtml#deq166)即可轻易证明。

该模型的一个变体使用起来会更合理，即

```
θ[o, n] = a θ[o, n − 1] + ω
```

其中`|a| < 1` [106]。然而，分析会变得更加复杂，因此我们将坚持使用公式[(5.73)](#Chp005_177-248_B9780443292385000111.xhtml#deq166)中的模型。毕竟，我们这里的目标是突出并初步接触跟踪的概念，并了解其对稳态失调的影响。

### 假设 3

同第[5.5.1](#Chp005_177-248_B9780443292385000111.xhtml#s0050)节一样，我们假定`c[n − 1] := θ[n − 1] − θ[o, n − 1]`与`x`和`η`独立。这一次，我们还将假定`c[n]`与`ω`独立。

回顾公式[(5.46)](#Chp005_177-248_B9780443292385000111.xhtml#deq86)，时刻`n`的超额MSE由下式给出

```
J[exc, n] = trace{Σ[x] Σ[c, n − 1]}
```

因此，我们现在的目标是计算时变模型情况下的`Σ[c, n − 1]`。很容易看出，公式[(5.35)](#Chp005_177-248_B9780443292385000111.xhtml#deq68)的对应式现在变为

```
c[n] = (I − μ x x^(T)) c[n − 1] + μ x η − ω
```
