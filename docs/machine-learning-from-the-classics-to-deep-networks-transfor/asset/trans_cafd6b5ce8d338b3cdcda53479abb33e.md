

### 11.6.2 非参数建模：讨论

请注意，在 RKHS 空间中搜索模型函数是*非参数*建模的典型任务。这与公式 [(11.1)](#Chp011_519-582_B9780443292385000172.xhtml#deq1) 中的参数建模形成对比，后者将未知函数*参数化*为一组基函数的形式；而在公式 [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64) 或公式 [(11.21)](#Chp011_519-582_B9780443292385000172.xhtml#deq74) 中，极小化是针对*受限于属于特定空间*的函数进行的。在更一般的情况下，极小化可以针对任意（连续）函数进行，例如，

```
\min\limits_{f}\ \sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},f(\mathbf{x}_{n}) \right) + \lambda\phi(f),
```

其中 $\mathcal{L}(\cdot,\cdot)$ 可以是任意损失函数，而 $\phi$ 为适当选择的正则化泛函。^([^(75)](#fn75))

```
\sum\limits_{n = 1}^{N}\left( y_{n} - f(x_{n}) \right)^{2} + \lambda\int{(f^{''}(x))}^{2}\ dx,
```
