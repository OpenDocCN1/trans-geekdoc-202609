## 7.3 判决（超）曲面

任何分类器的目标都是将特征空间划分为若干区域。这种划分是通过 `ℝ` 中的点、`ℝ²` 中的曲线、`ℝ³` 中的曲面以及 `ℝˡ` 中的超曲面来实现的。任意超曲面 `S` 可用一个函数来表示：

```
g : ℝˡ ↦ ℝ,
```

它包含所有满足以下条件的点：

```
S = {x ∈ ℝˡ : g(x) = 0}.
```

回顾一下，位于该超曲面一侧的所有点得分为 `g(x) > 0`，而位于另一侧的所有点得分为 `g(x) < 0`。出于显而易见的原因，由此产生的（超）曲面被称为*判决（超）曲面*。以双类贝叶斯分类器为例。相应的判决超曲面由以下公式（隐式）形成：

```
g(x) := P(ω₁|x) − P(ω₂|x) = 0. (7.15)
```

确实，如果 `x` 落在公式 [(7.15)](#Chp007_293-342_B9780443292385000135.xhtml#deq28) 定义的超曲面的正侧（区域 `ℛ₁`），我们就判定为类别 `ω₁`；如果落在负侧（区域 `ℛ₂`），则判定为 `ω₂`。这在[图 7.3](#Chp007_293-342_B9780443292385000135.xhtml#f0020)中进行了说明。此时，请回顾[备注 7.1](#Chp007_293-342_B9780443292385000135.xhtml#enun0010)中的拒绝选项。不做判决的点是那些靠近判决超曲面的点。
