

## 快速近端梯度分裂算法

对于某个 $\gamma > 0$，有：

$$
\|\nabla g(\mathbf{x}) - \nabla g(\mathbf{y})\| \leq \gamma \|\mathbf{x} - \mathbf{y}\|
$$

可以证明，如果 $\lambda_k \in \left( 0, \frac{1}{\gamma} \right]$，则该算法以次线性速率 $\mathcal{O}(1/k)$ 收敛到一个极小值点 [8]。这类算法被称为**近端梯度**或**前向-后向分裂**算法。术语“分裂”源于将函数分解为两个（或更一般地，更多）部分。术语“近端”表明优化方案中存在 $f$ 的近端算子。迭代过程包含在光滑部分上进行的（显式）前向梯度计算步骤，以及通过非光滑部分的近端算子进行的（隐式）后向步骤。术语“前向-后向”借用自涉及离散化技术的数值分析方法 [97]。近端梯度方案可追溯至例如 [18, 54]，但它们在机器学习和信号处理中的普及发生在较晚时期 [26, 36]。

基本方案存在许多变体。一种基于 Nesterov 对梯度算法的经典修正 [65] 的版本，可达到 $\mathcal{O}(1/k^2)$ 的收敛速率，总结见 [算法 8.5] [8]。在该算法中，更新被分为两部分。在近端算子中，使用通过涉及先前估计的平均获得的更平滑的估计版本。

### 算法 8.5：快速近端梯度分裂算法

**初始化**

1. 选择 $\mathbf{x}_0$，$\mathbf{z}_1 = \mathbf{x}_0$，$t_1 = 1$。
2. 选择 $\lambda$。

**对于** $k = 1, 2, \dots$ **执行**

1. $\mathbf{y}_k = \mathbf{z}_k - \lambda \nabla g(\mathbf{z}_k)$
2. $\mathbf{x}_k = \text{Prox}_{\lambda f}(\mathbf{y}_k)$
3. $t_{k+1} = \frac{1 + \sqrt{4t_k^2 + 1}}{2}$
