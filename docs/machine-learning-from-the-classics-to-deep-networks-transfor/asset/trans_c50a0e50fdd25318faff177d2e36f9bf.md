根据[定理 15.2](#Chp015_755-803_B9780443292385000214.xhtml#enun0020)，一个事件的联合概率由以下乘积给出：

`P(x[1], x[2], x[3]) = P(x[3]|x[2])P(x[2]|x[1])P(x[1])`

![Equation](images/B9780443292385000214/si72.png)(15.12)

换句话说，某人来自富裕国家、受过良好教育并获得高薪工作的概率将等于 `(0.8)(0.75)(0.2) = 0.12`；同样，某人来自贫穷国家、受过低等教育并获得低薪工作的概率是 0.476。

作为下一步，我们将利用前面给出的概率值，验证由 BN 结构蕴含的马尔可夫条件。也就是说，我们将验证：使用条件概率构建网络时，这些概率基本上编码了*条件独立性*，正如[定理 15.2](#Chp015_755-803_B9780443292385000214.xhtml#enun0020) 所建议的。让我们考虑

```
P(x_3 = HP|x_2 = HE,x_1 = HGP) = \frac{P(x_3 = HP,x_2 = HE,x_1 = HGP)}{P(x_2 = HE,x_1 = HGP)} = \frac{0.12}{P(x_2 = HE,x_1 = HGP)}.
```
