
# 有向无环图与贝叶斯网络结构

## 有向无环图（DAG）定义

**有向图**仅包含有向边，若不含任何环路，则称为**有向无环图**（DAG）。给定一个 DAG，其中的节点 $x_i$ 称为 $x_j$ 的**父节点**，若存在从 $x_i$ 到 $x_j$ 的（有向）边；相应地，$x_j$ 称为 $x_i$ 的**子节点**。

若存在从 $x_i$ 到 $x_j$ 的路径，则称节点 $x_j$ 为 $x_i$ 的**后代**，$x_i$ 为 $x_j$ 的**祖先**。若节点 $x_j$ 不是 $x_i$ 的后代，则称其为 $x_i$ 的**非后代**。若任意两个节点之间都存在边，则称该图为**全连接图**或**完全图**。[图 15.1](#Chp015_755-803_B9780443292385000214.xhtml#f0010) 直观展示了上述定义。

## 定义 15.1：贝叶斯网络结构

**贝叶斯网络结构**是一个 DAG，其节点代表随机变量 $x_1, \dots, x_l$。每个变量（节点）$x_i$ 在给定其所有**父节点**集合的条件下，与其所有**非后代**节点集合**条件独立**。这一性质也称为**马尔可夫条件**。
