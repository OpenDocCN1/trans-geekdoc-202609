
在复空间中，转置操作被埃尔米特操作所取代。可以很容易地验证，`P[{a[i]}]^⊥(x) := (I - P[{a[i]}])x` 与 `P[{a[i]}](x)` 正交，并且

```
P[{a[i]}](x) + P[{a[i]}]^⊥(x) = x
```

当 `A` 拥有标准正交列时，我们得到（从几何学中熟知的）展开式：

```
P[{a_i}](x) = A A^T x = Σ_{i=1}^k (a_i^T x) a_i.
```

因此，因子 `(A^T A)^(-1)` 在一般情况下解释了 `A` 的列缺乏标准正交性。矩阵 `A (A^T A)^(-1) A^T` 称为相应的**投影矩阵**，而 `I - A (A^T A)^(-1) A^T` 则是相应**正交补**空间上的投影矩阵。

```

```
