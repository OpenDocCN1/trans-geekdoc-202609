
# 机器学习概述

正如之前所述，机器学习是一门科学领域，其目标是开发能够从数据中“学习”的方法和算法；即提取数据中“蕴含”的信息，随后计算机可利用这些信息执行任务。为此，起点是一个可用的数据集。根据特定任务背景下所需获取的信息类型，已经发展出不同类型的机器学习，具体描述如下。

## 1.5.1 监督学习

**监督学习**是指所有可用数据均已**标记**的机器学习类型。换句话说，数据以**观测值**对的形式表示，例如 `(y[n], x[n])`，其中 `n = 1, 2, …, N`。此处每个 `x[n]` 均为一个向量，或广义上的一组变量。`x[n]` 中的变量称为**输入变量**，也称为**自变量**或**特征**，相应的向量称为**特征向量**。变量 `y[n]` 称为**输出变量**、**因变量**、**目标变量**或**标签变量**。在许多情况下，`y[n]` 也可以是一个向量。学习的目标是获得/估计一个函数映射，以便在给定输入变量值的情况下预测输出值。**分类**和**回归**是监督学习的两大“支柱”。

### 分类

分类的目标是将一个**模式**分配到一组可能的类别之一，类别数量被视为已知。例如，在 X 射线乳腺摄影中，给定一幅图像，其中某区域指示肿瘤的存在。计算机辅助诊断系统的目标是预测该肿瘤对应**良性**还是**恶性**类别。光学字符识别（OCR）系统也是围绕分类系统构建的，其中字母表中每个字母对应的图像必须被识别并分配到 26 个类别之一（针对拉丁字母）；相关案例研究见[示例 18.3](#Chp018_885-995_B978044329238500024X.xhtml)。另一个例子是给定文本的作者身份预测。给定一段未知作者撰写的文本，分类系统的目标是在若干作者（类别）中预测出作者；该应用在第 [11.15](#Chp011_519-582_B9780443292385000172.xhtml) 节中讨论。数字通信系统中的接收机也可视为一个分类系统。接收到被噪声污染且经传输信道施加其他变换（第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章）的传输数据后，接收机必须判断原始发送符号的值。例如，在二进制发送序列中，原始符号属于 `+1` 或 `-1` 类。此任务称为**信道均衡**。

设计任何机器学习任务的第一步是决定如何在计算机中表示每个模式。这在**预处理阶段**实现；必须将原始数据（如图像像素或词串）中蕴含的相关信息以高效且信息丰富的方式进行“编码”。通常通过将原始数据转换到新空间，并用向量 `x ∈ ℝ^l` 表示每个模式来完成。这构成了特征向量，其 `l` 个元素为相应的特征值。这样，每个模式成为 `l` 维空间中的一个点，称为**特征空间**或**输入空间**。我们将原始数据的这种转换称为**特征生成**或**特征提取阶段**。首先生成某个较大值 `K` 的可能特征，最终通过称为**特征选择阶段**的优化过程选出最具信息量的 `l` 个特征。正如我们将在第 [18.12](#Chp018_885-995_B978044329238500024X.xhtml) 节中看到的，在卷积神经网络的背景下，前两个阶段合二为一，特征的获取与优化与执行预测的函数映射估计以组合方式共同进行，如前所述。
