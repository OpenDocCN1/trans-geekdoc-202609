
$f_{\ast} = \min\limits_{\mathbf{x}}f(\mathbf{x}).$

![Equation](images/B9780443292385000147/si44.png)(8.7)

请注意，所有极小化点的集合与高度为 $f_{\ast}$ 的水平集重合。然后，由于该函数是凸的，我们知道水平集 $\text{lev}_{f_{\ast}}(f)$ 是凸的，这验证了极小化点集合的凸性。最后，对于严格凸函数，[(8.6)](#Chp008_343-416_B9780443292385000147.xhtml#deq16) 中的不等式是严格的，这证明了（全局）极小化点的唯一性。即使函数不可微，该定理也成立（问题 [8.10](#Chp008_343-416_B9780443292385000147.xhtml#o0080)）。 □

## 8.3 在凸集上的投影

有限维欧几里得空间中超平面上的投影已在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章仿射投影算法（APA）的背景下进行了讨论和使用。投影的概念现在将被推广，以包含任意闭凸集，并且也适用于一般（无限维）希尔伯特空间的框架。

投影的概念是数学中最基本的概念之一，所有上过基础几何课的人都使用并研究过它。人们可能没有意识到，在执行投影时，例如，从一点向一条线或一个平面画线段，基本上是在求解一个*优化*任务。[图 8.6](#Chp008_343-416_B9780443292385000147.xhtml#f0035) 中的点 $\mathbf{x}_{\ast}$，即三维空间中 $\mathbf{x}$ 在平面 $H$ 上的投影，是平面上所有点中与 $\mathbf{x} = [x_1, x_2, x_3]^T$ 的（欧几里得）距离最小的那个点；换句话说，

$\mathbf{x}_{\ast} = \min\limits_{\mathbf{y} \in H}\left( {(x_{1} - y_{1})}^{2} + {(x_{2} - y_{2})}^{2} + {(x_{3} - y_{3})}^{2} \right).$

![Equation](images/B9780443292385000147/si49.png)(8.8)

事实上，我们在早期上学时学到做的事情是求解一个*约束优化*任务。确实，式 [(8.8)](#Chp008_343-416_B9780443292385000147.xhtml#deq18) 可以等价地写为

$\mathbf{x}_{\ast} = \arg\min\limits_{\mathbf{y}}||\mathbf{x} - \mathbf{y}||^{2},\text{s.t.}\quad\mathbf{\theta}^{T}\mathbf{y} + \theta_{0} = 0,$
