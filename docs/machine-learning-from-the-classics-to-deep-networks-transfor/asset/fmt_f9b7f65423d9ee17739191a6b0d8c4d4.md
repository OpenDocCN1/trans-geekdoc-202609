## 12.3 The evidence function and Occam's razor rule

In the previous section, we made a comment about the importance of the marginal PDF `p(y)`. This section is fully dedicated to this quantity. In the notation used in Eq. [(12.14)](#Chp012_583-634_B9780443292385000184.xhtml#deq17), we did tacitly suppress the dependence on the adopted model. For example, the Gaussian assumption for the prior in Eq. [(12.8)](#Chp012_583-634_B9780443292385000184.xhtml#deq11) and for the conditional in Eq. [(12.9)](#Chp012_583-634_B9780443292385000184.xhtml#deq12) should have been reflected in the marginal as `p(y; ϕ, Σ[η], Σ[θ])`, because different Gaussians, different basis functions, and different orders `K` of the model can be used.
