
# 图论基础概念

图 *G* = {*V*, *E*} 是节点/顶点集合 *V* = {*x*₁, …, *x*ₗ} 和边（弧）集合 *E* ⊂ *V* × *V* 的集合。每条边连接两个顶点，表示为一对 (*x*ᵢ, *x*ⱼ) ∈ *E*。

边可以是 **有向** 的——此时写作 (*x*ᵢ → *x*ⱼ) 以指示方向——或者是 **无向** 的——此时简单写作 (*x*ᵢ, *x*ⱼ)。

假设我们有一组节点 *x*₁, *x*₂, …, *x*ₖ (*k* ≥ 2)，以及对应的一组边 (*x*ᵢ₋₁, *x*ᵢ) ∈ *E* 或 (*x*ᵢ₋₁ → *x*ᵢ) ∈ *E* (2 ≤ *i* ≤ *k*)；即边按 **序列** 连接节点对，它们可以是有向的也可以是无向的。这条边的序列称为从 *x*₁ 到 *x*ₖ 的 **路径**。如果至少有一条有向边，该路径称为 **有向路径**。

**环** 是从一个节点到其自身的路径。**链** 或 **迹** 是可以从 *x*₁ 到 *x*ₖ 或从 *x*ₖ 到 *x*₁ “运行” 的路径；即所有有向边均被无向边替代。
