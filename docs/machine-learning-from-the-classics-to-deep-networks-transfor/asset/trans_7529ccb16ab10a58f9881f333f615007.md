
注意，现在分析是一个不适定问题，因为字典的元素 {**ψ**[*i*]}[*i* ∈ ℐ]（通常称为*原子*）不是线性独立的，并且不存在一组唯一的参数 {*θ*[*i*]}[*i* ∈ ℐ] 来生成 ***s***。此外，我们预期这些参数中的大多数为（接近）零。注意，在这种情况下，ℐ 的基数大于 *l*。这必然导致具有无限多解的欠定方程组。现在提出的问题是，我们能否利用这些参数大多数已知为零这一事实，从而得出唯一解？如果可以，在什么条件下这样的解是可能的？我们将在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章回到学习字典的任务。

除了前面的例子，还有许多情况是由于物理和技术约束，我们无法获得足够多的测量值，从而导致欠定方程组。MRI 成像就是这种情况，将在 [10.3](#Chp010_463-518_B9780443292385000160.xhtml) 节中详细介绍。

## 9.5 寻找最稀疏解

受上一节讨论的启发，我们现在将注意力转向通过在解上施加稀疏性约束来求解欠定方程组的任务。我们将在回归的背景下建立理论框架，并将坚持采用为此任务采用的符号。此外，我们将专注于实值数据情况以简化阐述。该理论可以很容易地推广到更一般的复值数据情况（参见，例如，\[64,99\]）。假设我们得到一组观测/测量值，**y** :  = \[*y*[1], *y*[2], …, *y*[*N*]\]^(*T*) ∈ ℝ^(*N*)，根据线性模型

**y** = *X***θ**， **y** ∈ ℝ^(*N*), **θ** ∈ ℝ^(*l*), *l* > *N*，

(9.17)

其中 *X* 是 *N* × *l* 输入矩阵，假设其为满行秩，即 `rank(X)` = *N*。我们的出发点是无噪声情况。公式 [(9.17)](#Chp009_417-462_B9780443292385000159.xhtml#deq27) 中的线性方程组是欠定的，并接受无限多解。可能解的集合位于 *N* 个超平面的交集中

{**θ**∈ℝ^(*l*):*y*[*n*]\=**x**[*n*]^(*T*)**θ**}, *n* = 1, 2, …, *N*。

根据几何知识，*N* 个非平行超平面的交集（在我们的情况下，由 *X* 被假设为满行秩保证，因此 **x**[*n*], *n* = 1, 2, …, *N* 线性独立）是一个维数为 *l* − *N* 的平面。例如，三维空间中两个（非平行）（超）平面的交集是一条直线，即维数等于一的平面。更正式地说，所有可能解的集合，记为 Θ，是一个*仿射*集。仿射集是线性子空间经过常向量平移后的结果。让我们进一步探讨这一点，因为稍后我们将用到它。
