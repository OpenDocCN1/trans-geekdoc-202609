
除了前面讨论的 DDPM，用于构建扩散模型的其他方法也已被开发出来。[172] 中提出的 `噪声条件评分网络` (NCSN) 其根源在于 [93]。在一般设定下，给定一个概率分布 `q(x)`，其 Stein `评分函数` 定义为 `∇_x ln q(x)`。请注意，梯度是一个指向概率密度函数 (pdf) `q(x)` 增长最快方向的向量（参见例如第 [5.2](#Chp005_177-248_B9780443292385000111.xhtml) 节）。因此，如果目标是从该分布中采样，利用这一信息将随机抽取的样本 `x^(0)` 移向高密度区域的样本是合理的。这一过程可以通过物理学中称为 `朗之万动力学` 的方式迭代进行，描述如下：

```
x^(i) = x^(i - 1) + (γ/2) ∇_x ln q(x^(i - 1)) + √γ ε_i, i = 1,2,…,N,
```

其中 `ε_i ~ N(0, I)`。起始点 `x^((0))` 从先验分布中采样，`γ > 0` 是一个控制变量，用于调整所涉项的相对大小。可以证明，当 `N → ∞` 且 `γ → 0` 时，`x^((N))` 的分布等于 `q(x)` 的分布。因此，在某些一般正则性条件下，`x^((N))` 成为来自 `q(x)` 的精确样本 [172]。
