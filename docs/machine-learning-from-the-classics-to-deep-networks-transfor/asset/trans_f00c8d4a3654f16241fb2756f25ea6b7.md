
上述方法也推广到了 ℝ^(*l*) 中的随机向量。首先可以通过将从标准高斯分布 𝒩(*x*|0, 1) 中抽取的 *l* 个独立同分布样本堆叠在一起来从 **x** ∼ 𝒩(**x**|0, *I*) 中抽取样本，然后应用变换

**y** = *L***x** + **μ**，

这等价于从以下分布中抽取样本

**y** ∼ 𝒩(**y**|**μ**, *Σ*), (14.20)

其中 *Σ* = *LL*^(*T*)（乔莱斯基分解，习题 [14.4](#Chp014_717-754_B9780443292385000202.xhtml#o0025)）。
