
## 算法步骤

**Step 1:**
$$\boldsymbol{\psi}_k^{(i)} = \boldsymbol{\theta}_k^{(i-1)} + \mu_k \sum_{m \in \mathcal{N}_k} c_{mk} \left( \mathbf{p}_m - \boldsymbol{\Sigma}_{x_m} \boldsymbol{\theta}_k^{(i-1)} \right)$$

**Step 2:**
$$\boldsymbol{\theta}_k^{(i)} = \boldsymbol{\psi}_k^{(i)} + \mu_k \lambda \left( \widetilde{\boldsymbol{\theta}} - \boldsymbol{\theta}_k^{(i-1)} \right)$$

![Equation](images/B9780443292385000111/si493.png)

Step 2 可以稍作修改，用 **$\boldsymbol{\psi}_k^{(i)}$** 替换 **$\boldsymbol{\theta}_k^{(i-1)}$**，因为这包含了更新的信息，从而得到：

$$\boldsymbol{\theta}_k^{(i)} = \boldsymbol{\psi}_k^{(i)} + \mu_k \lambda \left( \widetilde{\boldsymbol{\theta}} - \boldsymbol{\psi}_k^{(i)} \right)$$

![Equation](images/B9780443292385000111/si496.png)
