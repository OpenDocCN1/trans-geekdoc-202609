
其中 `ϕ(x; θ[k]) ∈ {−1, 1}` 是第 `k` 次迭代的基分类器，由一组待估计的参数 `θ[k]`、`k = 1, 2, …, K` 定义。基分类器被选为二分类器。这组未知参数是以*逐步*的方式和*贪婪*的方式获得的；即在每一步迭代 `i` 中，我们仅通过保持从前几步获得的参数 `a[k], θ[k]`、`k = 1, 2, …, i − 1` 固定，来针对单个参数对 `(a[i], θ[i])` 进行优化。请注意，理想情况下，应同时针对所有未知参数 `a[k], θ[k]`、`k = 1, 2, …, K` 进行优化；然而，这将导致一个计算量极大的优化任务。由于计算简单，贪婪算法非常流行，并在广泛的学习任务中表现出非常好的性能。贪婪算法也将在第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章中结合稀疏感知学习进行讨论。

假设我们当前处于第 `i` 次迭代步骤；考虑各项的部分和

```
F_i( · ) = ∑_{k = 1}^{i} a_k ϕ( · ; θ_k).
```
(7.85)

然后我们可以写出以下递推公式：

`F[i](·) = F[i − 1](·) + a[i]ϕ(·; θ[i]), i = 1, 2, …, K,`
