
## 18.1

Prove that the perceptron algorithm, in its pattern-by-pattern mode of operation, converges in a finite number of iteration steps. Assume that `θ^((0)) = 0`.

**Hint**: Note that because classes are assumed to be linearly separable, there is a normalized hyperplane, `θ[*]`, and `γ > 0`, so that

`γ ≤ y[n] θ[*]^T x[n], n = 1, 2, …, N`

where `y[n]` is the respective label, being +1 for `ω[1]` and −1 for `ω[2]`. By the term *normalized hyperplane*, we mean that

```
θ[*]^T = [θ̂[*], θ[0*]]^T, with ||θ̂[*]|| = 1.
```

In this case, `y[n] θ[*]^T x[n]` is the distance of `x[n]` from the hyperplane `θ[*]` [141].
