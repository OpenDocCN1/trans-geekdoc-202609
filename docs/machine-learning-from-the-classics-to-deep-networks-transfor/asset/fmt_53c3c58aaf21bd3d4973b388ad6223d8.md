
Note that usually, a constant `θ[i0]` is also present in the linear terms (`∑[j ∈ Pa[i]] θ[ij] d[j] + θ[i0]`) and in this case the first exponent in the upper bound becomes `exp(−f*(ξ[i]) + ξ[i]θ[i0])`.

Let us now observe Eq. [(16.12)](#Chp016_805-853_B9780443292385000226.xhtml#deq23). The first factor on the right-hand side is a constant, once `ξ[i]` is determined. Moreover, each one of the factors, `exp(ξ[i]θ[ij])`, is also a constant raised in `d[j]`. Thus, substituting Eq. [(16.12)](#Chp016_805-853_B9780443292385000226.xhtml#deq23) in the products in Eq. [(15.1)](#Chp015_755-803_B9780443292385000214.xhtml), in order to compute, for example, Eq. [(15.3)](#Chp015_755-803_B9780443292385000214.xhtml), each one of these constants can be absorbed by the respective `P(d[j])`, that is,

```
P̃(d[j]) ∝ P(d[j]) exp(ξ[i]θ[ij] d[j]), j ∈ Pa[i].
```

Basically, from a graphical point of view, we can equivalently consider that the *i*th node is delinked and its influence on any subsequent processing is via the modified factors associated with its parent nodes (see [Fig. 16.10](#Chp016_805-853_B9780443292385000226.xhtml#f0055)B). In other words, the variational approximation *decouples* the parent nodes. In contrast, for exact inference, during the moralization stage, all parents of node *i* are connected. This is the source of computational explosion (see [Fig. 16.10](#Chp016_805-853_B9780443292385000226.xhtml#f0055)C). The idea is to remove a sufficient number of nodes, so that the remaining network can be handled using exact inference methods.

There is still a main point to be addressed: how the various `ξ[i]`s are obtained. These are computed to make the bound as tight as possible, and any standard optimization technique can be used. Note that this minimization corresponds to a convex cost function (Problem [16.11](#Chp016_805-853_B9780443292385000226.xhtml#o0095)). Besides the upper bound, a lower bound can also be derived [27]. Experiments performed in [30] verify that reasonably good accuracies can be obtained in affordable computational times. The method was first proposed in [27].
