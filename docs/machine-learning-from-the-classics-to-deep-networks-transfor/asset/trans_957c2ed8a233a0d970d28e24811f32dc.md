## 12.6 高斯混合模型

到目前为止，我们已经看到了许多可用于对未知随机向量 `x ∈ ℝ^(l)` 的分布进行建模的 PDF。然而，所有这些模型都将 PDF 限制在特定的函数项上。混合建模提供了自由，将未知 PDF `p(x)` 建模为不同分布的线性组合，即

```
p(x) = ∑_{k = 1}^{K} P_k p(x|k),
```
(12.53)

其中 `P_k` 是对特定贡献 PDF `p(x|k)` 进行加权的参数。为保证 `p(x)` 是一个 PDF，加权参数必须为非负且和为一 `(∑_{k = 1}^{K} P_k = 1)`。公式 [(12.53)](#Chp012_583-634_B9780443292385000184.xhtml#deq65) 的物理解释是：我们得到一组 `K` 个分布，`p(x|k), k = 1, 2, …, K`。每个观测值 `x[n], n = 1, 2, …, N` 都是从这 `K` 个分布中的某一个中抽取的，但我们不知道是从哪一个抽取的。我们所知道的只是一组参数 `P_k, 1, 2, …, K`，每个参数提供了样本从相应 PDF `p(x|k)` 中抽取的概率。可以证明，对于足够大的*混合数* `K` 以及对所涉混合成分的适当选择，可以任意精度地逼近任何连续 PDF。

混合建模是涉及潜变量的典型任务，即获得的观测值所源自的 PDF 的标签 `k`。在实践中，每个 `p(x|k)` 都是从已知的 PDF 族中选择的，并通过一组参数进行参数化，公式 [(12.53)](#Chp012_583-634_B9780443292385000184.xhtml#deq65) 可重写为

```
p(x) = ∑_{k = 1}^{K} P_k p(x|k; ξ_k),
```
(12.54)
