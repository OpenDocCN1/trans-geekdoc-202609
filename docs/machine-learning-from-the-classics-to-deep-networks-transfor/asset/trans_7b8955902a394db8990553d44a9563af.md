
设 `X` 的零空间记为 `null(X)`（有时记为 `𝒩(X)`），它被定义为线性子空间

`null(X) = {z ∈ ℝ^l : Xz = 0}`。

显然，如果 `θ[0]` 是方程 [(9.17)](#Chp009_417-462_B9780443292385000159.xhtml#deq27) 的一个解，即 `θ[0] ∈ Θ`，那么很容易验证 `∀θ ∈ Θ`，有 `X(θ − θ[0]) = 0`，或者说 `θ − θ[0] ∈ null(X)`。结果，

`Θ = θ[0] + null(X)`，

且 `Θ` 是一个仿射集。我们还从线性代数基础知（且易于证明；见问题 [9.9](#Chp009_417-462_B9780443292385000159.xhtml#o0070)）满行秩矩阵 `N × l`（`l > N`）的零空间是一个维数为 `l − N` 的子空间。[图 9.7](#Chp009_417-462_B9780443292385000159.xhtml#f0045) 说明了二维空间中一条观测的情况，即 `l = 2` 和 `N = 1`。解集 `Θ` 是一条直线，它是穿过原点的线性子空间（即 `null(X)`）的平移。因此，如果想要在仿射解集 `Θ` 中所有点里选取*单个*点，则必须施加一个额外的约束/先验知识。
