
**θ**^(*T*)**x**[*n*] ≤ −*ρ*, 若 *y*[*n*] = −1。

此要求可表述如下。给定 (*y*[*n*], **x**[*n*]) ∈ {−1, 1} × ℝ^(*l*+1)，设计一个线性分类器。

*y*[*n*]**θ**^(*T*)**x**[*n*] ≥ *ρ* > 0。

![Equation](images/B9780443292385000147/si184.png) (8.35)

注意，给定 *y*[*n*], **x**[*n*], 和 *ρ*，[(8.36)](#Chp008_343-416_B9780443292385000147.xhtml#deq71) 定义了一个*半空间* ([示例 8.1](#Chp008_343-416_B9780443292385000147.xhtml#enun0065))；这就是我们使用“≥*ρ*”而非严格不等式的原因。换句话说，所有满足 [(8.36)](#Chp008_343-416_B9780443292385000147.xhtml#deq71) 中所需不等式的 **θ** 都位于此半空间内。由于每一对 (*y*[*n*], **x**[*n*]), *n* = 1, 2, …, *N* 均定义了一个单一的半空间，我们的目标现在变为试图找到所有这些半空间交集中的一个点。如果类别是线性可分的，则保证此交集非空。[图 8.20](#Chp008_343-416_B9780443292385000147.xhtml#f0110) 说明了这一概念。非线性可分类别这一更现实的情况将在第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章中处理，届时高维（核）空间中的映射将使得两个类别线性可分的概率趋于 1，随着核空间维度趋于无穷大。
