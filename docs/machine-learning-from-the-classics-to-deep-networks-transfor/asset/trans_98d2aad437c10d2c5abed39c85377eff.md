**θ**[*k*] 的重估计取决于相应分布 *p*(**y**[*n*]|*k*; **θ**[*k*]) 的形式。例如，在高斯情形中，参数为均值和协方差矩阵的元素。在这种情况下，如果用 *γ* 代替后验概率，我们得到的迭代与高斯混合模型问题（见公式 [(12.60)](#Chp012_583-634_B9780443292385000184.xhtml) 和 [(12.61)](#Chp012_583-634_B9780443292385000184.xhtml)）所得的迭代完全相同。

总之，训练 HMM 包含以下步骤：

1.  初始化 `Θ` 中的参数。
2.  运行和积算法以获得 `γ(·)` 和 `ξ(·, ·)`，使用当前的参数估计值集。
3.  按照公式 (16.56) 和 (16.57) 更新参数。

步骤 2 和 3 中的迭代将持续进行，直到满足收敛准则，如在 EM 算法中一样。这种迭代方案也称为 *Baum–Welch* 算法或 *前向-后向* 算法。除了用于训练 HMM 的前向-后向算法外，文献中还有许多替代算法，旨在简化计算或提高性能。例如，可以推导出一种更简单的训练算法，专门针对用于计算最优路径的 Viterbi 方案（如 [63,72]）。此外，为了进一步简化训练算法，我们可以假设状态观测变量 **y**[*n*] 是离散化（量化）的，并且可以从 *L* 个可能值的有限集合 {1, 2, …, *L*} 中取值。这在实践中通常是如此。此外，假设第一个状态也是已知的。例如，这适用于如 [图 16.17](#Chp016_805-853_B9780443292385000226.xhtml#f0090) 所示的左至右模型。在这种情况下，我们不需要计算初始概率的估计值。因此，待估计的未知参数为转移概率和概率 *P*[**y**](*r*|*i*)，*r* = 1, 2, …, *L*，*i* = 1, 2, …, *K*，即从状态 *i* 发射符号 *r* 的概率。

**Viterbi 重估计**：该算法的目标是获得最佳路径并计算沿该路径的相关代价，记为 *D*。在语音文献中，该算法也称为 *分段 k-means 训练* 算法 [63]。

**定义**：

*   `n[i|j]` := 从状态 *j* 到状态 *i* 的转移次数。
*   `n[·|j]` := 从状态 *j* 发出的转移次数。
*   `n[i|·]` := 终止于状态 *i* 的转移次数。
*   `n(r|i)` := 观测值 *r* ∈ {1, 2, …, *L*} 与状态 *i* 联合出现的次数。
