We are given a set of $N$ output–input training points, $(y_n, \mathbf{x}_n), n = 1, 2, \dots, N$. In our current setting, we assume that the respective (unobserved) noise values $\eta_n, n = 1, 2, \dots, N$, are samples of jointly Gaussian distributed random variables of zero mean and with covariance matrix $\Sigma_\eta$, that is,

$$p(\boldsymbol{\eta}) = \frac{1}{(2\pi)^{N/2}|\Sigma_\eta|^{1/2}}\exp\left( - \frac{1}{2}\boldsymbol{\eta}^{T}\Sigma_\eta^{-1}\boldsymbol{\eta} \right) \tag{12.2}$$

where $\boldsymbol{\eta} = [\eta_1, \eta_2, \dots, \eta_N]^{(T)}$.
