
现在让我们关注所有涉及变量均为离散的情况，此时任意节点 `i` 处的未知量是相应条件概率表中的条件概率值。为便于表示，用 `h[i]` 表示由 `x[i]` 的父变量状态索引组成的向量。然后，对于 `x[i]` 和 `h[i]` 所有可能的取值组合，相应的（未知）概率记为 `P[x[i]|h[i]](x[i], h[i])`。例如，如果所有涉及的变量均为二元变量且 `x[i]` 有两个父节点，则 `P[x[i]|h[i]](x[i], h[i])` 总共可取八个需估计的值。公式 [(16.64)](#Chp016_805-853_B9780443292385000226.xhtml#deq116) 现在可重写为

```
l(θ_i) = ∑_{h_i} ∑_{x_i} s(x_i, h_i) ln P_{x_i|h_i}(x_i, h_i),
```

其中 `s(x[i], h[i])` 是特定组合 `(x[i], h[i])` 在训练集的 `N` 个样本中出现的次数。我们假设 `N` 足够大，使得所有可能的组合至少出现一次，即 `s(x[i], h[i]) ≠ 0, ∀(x[i], h[i])`。现在要做的就是在考虑到以下条件的情况下，最大化公式 [(16.65)](#Chp016_805-853_B9780443292385000226.xhtml#deq117) 关于 `P[x[i]|h[i]](·, ·)` 的值：
