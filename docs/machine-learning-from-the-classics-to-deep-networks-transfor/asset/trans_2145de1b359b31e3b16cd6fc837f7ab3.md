
对于我们当前的需求，起点是指词汇表中包含的单词在计算机中的表示。我们将假设每个单词由单个向量表示。例如，在所谓的*one-hot*（独热）表示/编码中，每个单词对应一个特定的one-hot向量。这些向量的维度*l*等于相应NLP任务中使用的词汇表中的单词数量。目前，用于训练所谓的大语言模型（LLMs）（见第[19.5.3](#Chp019_997-1102_B9780443292385000251.xhtml#s0185)节）的典型词汇表大小可以达到30000个单词的量级。

按照惯例，每个单词（包括标点符号和特殊符号，假设共30000个）被分配一个介于1和30000之间的特定数字/索引，并由相应的one-hot向量表示。后者包含*l* − 1个等于0的元素，唯一的非零元素等于1。数值1位于等于该单词在词汇表中索引的向量维度位置。例如，如果第*n*个单词（*n* = 1, 2, …, *l*）在词汇表中的索引用*l*[*n*] ∈ {1, 2, …, *l*}表示，则相应的one-hot表示形式如下：

```
\mathbf{x}_{n} = \overset{l}{\overset{︷}{\left\lbrack 0,\ldots,0,\underset{l_{n}}{\underset{︸}{1}},0,\ldots,0 \right\rbrack^{T}}} \in \mathbb{R}^{l},\ n = 1,2,\ldots,l,
```

其中1位于向量的*l*[*n*]维度。请注意，语言词汇表中现有单词的数量可能远大于用于实际目的的30000个。例如，希腊语作为一种古老语言，据估计大约有100000个单词和300000个含义。

我们讨论的舞台将是*神经机器翻译*（NMT）任务，这是自然语言处理学科的一个子主题。让我们以法语短语“Je suis étudiant”为例，其英文翻译为“I am a student。”该法语短语由三个单词组成，每个单词由一个one-hot向量表示，即**x**[1], **x**[2], **x**[3]。将短语分解为单个单词通常称为*tokenization*（分词），单个单词/向量称为*tokens*（词元）。

```
⟨SOS⟩, x[1], x[2], x[3], ⟨EOS⟩.
```

同样，输出序列（即翻译成英文的短语）表示为：

```
⟨SOS⟩, y[1], y[2], y[3], y[4], ⟨EOS⟩,
```

其中输出序列也采用了one-hot向量表示。请注意，输入和输出序列中向量/词元的维度可能不同，因为两个词汇表（例如法语和英语）通常大小不同。
