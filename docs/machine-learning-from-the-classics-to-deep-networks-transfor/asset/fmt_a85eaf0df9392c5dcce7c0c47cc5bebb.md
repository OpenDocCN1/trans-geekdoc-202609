**前向预测**：前向预测任务的目标是给定值 `u[n]`、`u[n-1]`、…、`u[n-m+1]`，预测值 `u[n+1]`。因此，MSE 最优的 `m` 阶前向预测器 `a[m]` 是通过选择期望响应 `d[n] = u[n+1]` 获得的，相应的正规方程变为：

```
a_m = Σ_m^{-1} [ E[u_n u_{n+1}^*] ; E[u_{n-1} u_{n+1}^*] ; ... ; E[u_{n-m+1} u_{n+1}^*] ] = Σ_m^{-1} [ r^*(1) ; r^*(2) ; ... ; r^*(m) ]
```
