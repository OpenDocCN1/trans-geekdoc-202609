
$F_{\ast}(\mathbf{x}) = \arg\min\limits_{f}\mathbb{E}\left\lbrack \exp\left( - yf \right) \right\rbrack = \frac{1}{2}\ln\frac{P(y = 1|\mathbf{x})}{P(y = - 1|\mathbf{x})}.$

The logarithm of the ratio on the right-hand side is known as the *log-odds* ratio. Hence, if one views the minimizing function in Eq. [(7.88)](#Chp007_293-342_B9780443292385000135.xhtml#deq136) as the empirical approximation of the mean value in Eq. [(7.99)](#Chp007_293-342_B9780443292385000135.xhtml#deq147), it fully justifies considering the sign of the function in Eq. [(7.83)](#Chp007_293-342_B9780443292385000135.xhtml#deq131) as the classification rule.

A major problem associated with the exponential loss function, as is readily seen in [Fig. 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085), is that it weighs heavily wrongly classified samples, depending on the value of the respective margin, defined as

$m_{x} := |yF(\mathbf{x})|.$

Note that the farther the point is from the decision surface ($F(\mathbf{x}) = 0$), the larger the value of $|F(\mathbf{x})|$. Thus, points that are located at the wrong side of the decision surface ($yF(\mathbf{x}) < 0$) and far away are weighted with (exponentially) large values, and their influence in the optimization process is large compared to the other points. Thus, in the presence of outliers, the exponential loss is not the most appropriate one. As a matter of fact, in such environments, the performance of the AdaBoost can degrade dramatically.

An alternative loss function is the *log-loss* or *binomial deviance*, defined as

![Equation](images/B9780443292385000135/fx018.jpg)(7.102)

which is also shown in [Fig. 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085). Observe that its increase is almost linear for large negative values. Such a function leads to a more balanced influence of the loss among all the points. We will return to the issue of *robust loss functions*, that is, loss functions that are more immune to the presence of outliers, in Chapter [11](#Chp011_519-582_B9780443292385000172.xhtml). Note that the function that minimizes the mean of the log-loss, with respect to $y$, is the same as the one given in Eq. [(7.100)](#Chp007_293-342_B9780443292385000135.xhtml#deq148) (try it). However, if one employs the log-loss instead of the exponential, the optimization task gets more involved, and one has to resort to gradient descent or Newton-type schemes for optimization (see [16]).

### Remarks 7.7

*   For comparison reasons, in [Fig. 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085), the squared error loss is shown. The squared error loss depends on the value $(y - F(\mathbf{x}))$, which is the equivalent of the margin defined above, $yF(\mathbf{x})$. Observe that, besides the relatively large influence that large values of error have, the error is also penalized for patterns whose label has been predicted correctly. This is one more justification that the LS method is not, in general, a good choice for classification.
