Note that the recursion in Eq. [(10.25)](#Chp010_463-518_B9780443292385000160.xhtml#deq81) is analogous to the iterative soft thresholding shrinkage algorithm in the batch processing case in Eq. [(10.7)](#Chp010_463-518_B9780443292385000160.xhtml#deq23). There, we saw that the only difference the sparsity imposes on an iteration, with respect to its unconstrained counterpart, is an extra soft thresholding. This is exactly the case here. The term in parentheses is the iteration for the unconstrained task. Moreover, as shown in [46], projection on the `ℓ_1` ball is equivalent to a soft thresholding operation. Following the general arguments given in Chapter [8](#Chp008_343-416_B9780443292385000147.xhtml), the previous iteration converges arbitrarily close to a point in the intersection

B_ℓ_1[δ] ∩ ⋂_{n ≥ n_0} S_n[ϵ],

for some finite value of `n_0`. In [76,77], the weighted `ℓ_1` ball (denoted here as `B_ℓ_1[w[n], ρ]`) has been used to improve convergence as well as the tracking speed of the algorithm, when the environment is time-varying.
