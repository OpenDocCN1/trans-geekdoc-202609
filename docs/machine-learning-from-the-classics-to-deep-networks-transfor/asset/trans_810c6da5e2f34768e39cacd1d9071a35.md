其中 $\widehat{y}\_{nk}$，$k = 1, 2, \dots, k\_{L}$，是网络相应输出节点提供的估计值。我们将它们视为相应向量 ${\widehat{\mathbf{y}}}\_{n}$ 的元素。

### 梯度的计算

令 $z\_{nj}^{(r)}$ 表示当模式 $\mathbf{x}\_{n}$ 作用于输入节点时，第 $r$ 层中第 $j$ 个神经元的线性组合器在时刻 $n$ 的输出（参见 [图 18.11](#Chp018_885-995_B978044329238500024X.xhtml#f0065)）。则可写为

$z\_{nj}^{r} = \sum\limits\_{m = 1}^{k\_{r - 1}}\theta\_{jm}^{r}y\_{nm}^{r - 1} + \theta\_{j0}^{r} = \sum\limits\_{m = 0}^{k\_{r - 1}}\theta\_{jm}^{r}y\_{nm}^{r - 1} = \mathbf{\theta}\_{j}^{r^{T}}\mathbf{y}\_{n}^{r - 1}$

其中根据定义

$\mathbf{y}\_{n}^{(r - 1)} := \left[1, y\_{n1}^{(r - 1)}, \dots, y\_{n k\_{r - 1}}^{(r - 1)}\right]^{(T)}$
