
然后我们生成一个噪声向量 `η ∈ ℝ^150`，用从 `𝒩(0, 0.01)` 随机抽取的元素填充它，并形成

```
ỹ = y + η.
```

输入矩阵的噪声版本通过以下方式获得：

```
X̃ = X + E,
```

其中 `E` 通过从 `𝒩(0, 0.2)` 抽取样本随机填充元素。

使用生成的 `ỹ, X, X̃` 并假装我们不知道 `θ[o]`，获得了其值的以下三个估计。

*   结合 `X` 和 `ỹ` 使用最小二乘（LS）估计器公式 [(6.5)](#Chp006_249-291_B9780443292385000123.xhtml#deq12)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.0125`。
*   结合 `X̃` 和 `ỹ` 使用最小二乘（LS）估计器公式 [(6.5)](#Chp006_249-291_B9780443292385000123.xhtml#deq12)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.4272`。
*   结合 `X̃` 和 `ỹ` 使用全最小二乘（TLS）估计器公式 [(6.69)](#Chp006_249-291_B9780443292385000123.xhtml#deq153)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.2652`。

观察可知，使用带噪输入数据时，LS 估计器导致的误差比 TLS 估计器大。然而请注意，TLS 的成功应用预设了导出 TLS 估计器的假设是有效的。
