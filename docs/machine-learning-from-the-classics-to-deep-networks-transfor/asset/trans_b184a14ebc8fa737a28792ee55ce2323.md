

## EM 算法与证据最大化

在第 [12.4](#Chp012_583-634_B9780443292385000184.xhtml#s0045) 节中介绍了 EM 算法，并指出：关于参数集 `ξ` 最大化完全对数似然的期望，等价于最大化相应的证据函数，即 `p(X; ξ)`。然而，这一点并未明确展示。在本节中，这一联系将变得清晰。将表明 EM 算法基本上是最大化证据的一个紧致*下界*。此外，这种对 EM 的解释将允许进行推广，以将其扩展到涉及后验 `p(X^(l)|X; ξ)` 的计算在计算上不可处理的情况。

让我们考虑泛函^([^(88)](#fn88))

```
F(q, ξ) = ∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) + H
```
(12.63)

其中 `q(X^(l))` 是任意非负且积分为 1 的函数；也就是说，它是定义在隐变量上的概率密度函数（PDF）。泛函 `F` 依赖于 `ξ` 和 `q`，其定义与统计物理学中使用的自由能概念有着很强的相似性。确实，方程 [(12.63)](#Chp012_583-634_B9780443292385000184.xhtml#deq83) 可以写成

```
F(q, ξ) = ∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) + H
```
(12.64)

其中

```
H = − ∫ q(X^(l)) ln q(X^(l)) dX^(l)
```

是与 `q(X^(l))` 相关的熵。如果将 `−ln p(X, X^(l); ξ)` 定义为系统 `(X, X^(l))` 的*能量*，那么 `F(q, ξ)` 代表所谓的*自由能*的负值 [34]。聚焦于方程 [(12.64)](#Chp012_583-634_B9780443292385000184.xhtml#deq84) 右边的第一项，它可以写成

```
∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) = ∫ q(X^(l)) ln [p(X^(l)|X; ξ) p(X; ξ)] dX^(l)
```
(12.65)

换句话说，右边的第一项与方程 [(12.40)](#Chp012_583-634_B9780443292385000184.xhtml#deq53) 中的 `Q` 项非常相似。唯一的区别在于，这里的期望是关于 `q` 计算的。
