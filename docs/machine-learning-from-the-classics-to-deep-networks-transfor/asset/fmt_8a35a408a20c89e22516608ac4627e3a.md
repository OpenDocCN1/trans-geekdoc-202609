
参数 *ν* 称为自由度。[图 13.5](#Chp013_635-716_B9780443292385000196.xhtml#f0030) 显示了不同 *ν* 值下 Student's *t* 概率密度函数（PDF）的图形。当 *ν* → ∞ 时，Student's *t* 分布趋向于具有相同均值和精度 *λ* 的高斯分布。观察 Student's *t* PDF 的重尾特性，尤其是在 *ν* 取较低值时。回顾我们的情况，由于使用了无信息超先验，超参数 *a* 被赋予了一个较小的值。因此，本节的处理倾向于回归模型的稀疏解。它会尽可能将参数 `θ[k]` 推向零。也就是说，通过将相应参数设为零来剪枝不太相关的基函数 `ϕ[k](x)`。这也是对每个参数 `θ[k]`（`k = 0, 2, …, K − 1`）使用不同超参数 `α[k]` 的原因，这为学习过程提供了更大的自由度来单独调整它们。在早期，这种方法被称为自动相关性确定（ARD）[48, 53, 55]。文献 [24] 提供了关于自适应正则化与剪枝关系的有趣讨论。

## 13.6 稀疏贝叶斯学习

在第 [13.3](#Chp013_635-716_B9780443292385000196.xhtml#s0030) 节中，每个未知参数 `θ[k]`（`k = 0, 1, …, K − 1`）的先验被赋予了各自的方差 `σ_k^2 := 1/α_k`。反过来，这些方差被视为隐随机变量，并以一组超参数的形式为每个方差分配了先验。

文献 [88, 96] 中模型稍作修改。保留了为先验使用不同方差的概念，但将方差视为确定性参数而非随机变量。^([^(91)](#fn91))

```
p(y|θ; β) = N(y|Φθ, β^(−1)I),
```

```
p(θ; α) = N(θ|0, A^(−1)),
```
