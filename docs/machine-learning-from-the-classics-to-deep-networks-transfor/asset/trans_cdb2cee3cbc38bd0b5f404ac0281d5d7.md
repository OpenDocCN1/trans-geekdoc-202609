

#### 无分类器引导

前一种方法的一个主要问题是需要训练一个单独的分类器。在文献 [86] 中，通过联合训练条件和无条件扩散模型，绕过了对单独分类器的需求。

让我们用 `s_θ(x_t, t, y)` 表示评分函数的类条件估计，用 `s_θ(x_t, t)` 表示无条件估计。在训练期间，使用单个神经网络来参数化这两个模型。这是通过一个简单的技巧实现的。使用一个对应于无条件模型的输入标记 `∅`，将类嵌入向量代入关联的类标签 `y` 的位置。即：

```
s_θ(x_t, t) = s_θ(x_t, t, y = ∅).
```

通过根据预先选定的用户定义概率 `p_∅`，在条件输入（`y ≠ ∅`）和无条件输入（`y = ∅`）之间随机选择，联合训练条件和无条件模型。
