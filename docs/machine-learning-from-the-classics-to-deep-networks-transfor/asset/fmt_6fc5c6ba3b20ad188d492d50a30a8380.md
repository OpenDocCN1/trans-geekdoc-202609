
## 推导过程

$$
p_{2}(1) = \mathbb{E}\lbrack v_{2}(n - 1)d_{n}\rbrack = \mathbb{E}\left\lbrack v_{2}(n - 1)\left( s_{n} + v_{1}(n) \right) \right\rbrack = \mathbb{E}\lbrack v_{2}(n - 1)v_{1}(n)\rbrack + 0 = \mathbb{E}\left\lbrack v_{2}(n - 1)\left( a_{1}v_{1}(n - 1) + \eta_{n} \right) \right\rbrack = a_{1}p_{2}(0) = \frac{a_{1}\sigma_{\eta}^{2}}{1 - a_{1}a_{2}}.
$$

![Equation](images/B978044329238500010X/si228.png)

In general, it is easy to show that

$$
p_{2}(k) = \frac{a_{1}^{k}\sigma_{\eta}^{2}}{1 - a_{1}a_{2}},\quad k = 0,1,\ldots.
$$
