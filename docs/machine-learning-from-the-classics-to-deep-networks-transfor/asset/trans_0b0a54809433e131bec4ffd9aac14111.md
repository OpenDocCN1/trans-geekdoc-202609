
为了应对这些问题，已经开发出许多修改和技巧。尝试不同的代价函数是其中之一，尝试反向传播算法的不同优化变体是另一种（例如，参见[136]的讨论）。在接下来的小节中，我们将看到如何处理用于隐藏层的非线性函数，这些函数不是饱和型的；因此，它们可以“保护”我们免受导数值变小的倾向影响。

### 18.6.1 线性修正单元

除了我们迄今为止考虑的激活函数之外，*线性修正单元*（ReLU）是最近才被提出的（参见[图18.13](#Chp018_885-995_B978044329238500024X.xhtml#f0075)），其定义为：

![Equation](images/B978044329238500024X/fx010.jpg)(18.46)

![Figure 18.13 The graph of ReLU. Note that for z > 0 the derivative is equal to one and for z < 0 it is equal to zero.](images/B978044329238500024X/gr013.jpg)

[图18.13](#Chp018_885-995_B978044329238500024X.xhtml#cf0930) ReLU的图。注意对于`z > 0`，导数等于1，对于`z < 0`，导数等于0。

据报道，在深度网络的背景下，在隐藏层中使用ReLU非线性可以显著加快训练时间[108]。这种激活函数不受饱和影响，当神经元在其活跃区域（`z > 0`）工作时，其导数等于1。因此，在初始化期间，希望将神经元的偏置设置为某个小的正值，例如`θ[0] = 0.1`，以增加激活函数输入为正的概率。对于负值，导数为零。在`z = 0`处导数未定义，如果这在训练期间发生，可以选择1或0；对于熟悉子梯度概念（第[8](#Chp008_343-416_B9780443292385000147.xhtml)章）的人来说，这种选择是完全合理的。

因此，选择ReLU作为激活函数，可以绕过导数值变小时减速相关的问题。回想一下，在反向传播算法中，当计算隐藏层参数的梯度时，激活函数的导数以乘法方式进入计算。

ReLU的一个缺点是当`z < 0`时训练会冻结。为了克服这个问题，已经提出了ReLU的变体。例如，可以使用：

`f(z) = max{0, z} + α min{0, z}`

![Equation](images/B978044329238500024X/si302.png)

根据`α`的值，会产生不同的变体。对于`α = -1`，获得所谓的*绝对值修正*[90]。如果`α`被赋予一个固定的小值，例如0.01，则得到的非线性被称为*泄漏*ReLU[126]。在[68]中，`α`被保留为一个在训练期间学习的参数。另一种称为*最大输出*单元的修改，采用`k`个不同的线性单元，其参数在训练期间学习，每次选择产生最大值的那个来激活相应的神经元[52]。ReLU最初是在动态网络的背景下引入的[61]，并由生物学论据提供动机。

现在提出的问题是实际应用中具体非线性函数的选择。对此没有确定的答案，选择取决于具体应用。在本版编写时，似乎在其任何版本中使用ReLU是隐藏层更流行的选择。对于分类任务和输出层，Softmax非线性结合交叉熵代价函数最常用。

## 18.7 网络正则化

训练神经网络的一个关键因素是确定网络的大小。大小直接与要估计的参数数量相关。关于前馈神经网络，涉及两个问题。第一个涉及层数，另一个涉及每层的神经元数量。正如我们将在第[18.11](#Chp018_885-995_B978044329238500024X.xhtml#s0140)节讨论的那样，许多理由支持使用两个以上的隐藏层。此类网络包含大量参数，容易受到过拟合的影响，这会影响学习器的泛化性能。应对过拟合的一种途径是通过正则化。多年来，已经提出了各种正则化方法。下面给出简要介绍和一些指导原则。我们将在第[18.11.1](#Chp018_885-995_B978044329238500024X.xhtml#s0145)节从不同角度在深度网络的背景下回到过拟合和泛化问题。

*权重衰减*：这条路径指的是通过权重的平方欧几里得范数进行典型的代价函数正则化。不是最小化代价函数`J(θ)`，而是使用其正则化版本，例如（如[71]）：

`J'(θ) = J(θ) + λ||θ||².`
