
并对 `f_ij(·, ·)` 和 `f_i(·)` 使用不同的函数形式，同时允许变量取两个以上的值。这有时被称为 *Potts* 模型。通常，MRF 模型采用公式 [(15.23)](#Chp015_755-803_B9780443292385000214.xhtml#deq32) 的一般形式，也称为 *成对 MRF 无向图*，因为节点间的依赖关系是用变量对的乘积来表示的。有关 MRF 在图像处理中应用的更多信息，可参见例如文献 [29,40]。

For the image denoising task, black nodes correspond to the noiseless pixel values (hidden variables) and red nodes to the observed pixel values.](images/B9780443292385000214/gr016.jpg)

[图 15.16](#Chp015_755-803_B9780443292385000214.xhtml#cf0565) 所示为一个成对 MRF，类似于 [图 15.15](#Chp015_755-803_B9780443292385000214.xhtml#f0085)，但现在与每个节点关联的观测值被单独标记为红色节点。对于图像去噪任务，黑色节点对应无噪声像素值（隐变量），红色节点对应观测像素值。

公式 [(15.23)](#Chp015_755-803_B9780443292385000214.xhtml#deq32) 的另一个名称是玻尔兹曼分布，其中变量通常取 `{0, 1}` 中的值。这种分布已被用于 *玻尔兹曼机* [23]。玻尔兹曼机可被视为霍普菲尔德网络的随机对应物；后者被提议用作 *联想记忆* 以及解决组合优化问题的一种方法（例如 [31]）。在深度学习的背景下，人们对玻尔兹曼机的兴趣得以复苏，我们将在第 [19](#Chp019_997-1102_B9780443292385000251.xhtml) 章中更详细地讨论它们。

### 15.4.3 条件随机场（CRF）

迄今为止讨论的所有图模型（有向和无向）都围绕所涉及随机变量的联合分布及其在相应图上的因子分解展开。另一种趋势是关注在给定其余变量条件下某些变量的条件分布。对联合 PDF 的关注源于我们对开发生成式学习模型的兴趣。然而，这并不总是处理学习任务的最高效方式，我们已经在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章和第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章中讨论过判别式学习这一替代方案。假设从联合分布的变量集合中，一些对应于输出目标变量，当其余变量被观测到时，需要推断这些目标变量的值。例如，目标变量可能对应分类任务中的标签，其余变量对应（输入）特征。

让我们用向量 **y** 表示前一组变量，用 **x** 表示后一组。与其关注联合分布 `p(x, y)`，不如关注 `p(y|x)` 可能更合理。在文献 [27] 中，采用图模型来编码条件分布 `p(y|x)`。

*条件随机马尔可夫场* 是一个无向图 *H*，其节点对应随机变量联合集合 `(x, y)`，但我们现在假设条件分布是因子分解的，即

```
p(y|x) = (1/Z(x)) ∏_{k=1}^{K} ψ_k(x_k, y_k),  (15.26)
```

其中 `{x_k, y_k} ⊆ {x, y}`，`k = 1, 2, …, K`，
