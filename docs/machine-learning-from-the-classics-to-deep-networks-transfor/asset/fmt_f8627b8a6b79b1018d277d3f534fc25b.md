
|*f*(**x**[1]) − *f*(**x**[2])| < ||**x**[1] − **x**[2]||, ∀**x**[1], **x**[2] ∈ 𝒳.

![Equation](images/B9780443292385000251/si98.png)

Thus, the Wasserstein probability distance between two distributions, in the form of Eq. [(19.17)](#Chp019_997-1102_B9780443292385000251.xhtml#deq33), is given by the “maximum” in the difference of the mean values, over all possible 1-Lipschitz functions, with respect to the two distributions.

Designing a GAN according to Eq. [(19.17)](#Chp019_997-1102_B9780443292385000251.xhtml#deq33) makes the setting different from the one that evolved around the cost in Eq. (19.11). The goal is no more to design a binary classifier (discriminator) to distinguish real from fake data, but a Lipschitz function, *f*. The latter is parameterized via a deep neural network, in terms of a set of parameters, **θ**[*f*]![Equation](images/B9780443292385000251/si99.png), i.e., *f*(**x**; **θ**[*f*])![Equation](images/B9780443292385000251/si100.png). The respective parameters are estimated by solving the task

```
\max\limits_{\mathbf{\theta}_{f}}\left\{ \mathbb{E}_{p_{r}(\mathbf{x})}\ \left\lbrack f(\mathbf{x};\mathbf{\theta}_{f}) \right\rbrack - \mathbb{E}_{p_{\mathbf{z}}(\mathbf{z})}\ \left\lbrack f(G(\mathbf{z};\mathbf{\theta}_{g});\mathbf{\theta}_{f}) \right\rbrack \right\}.
```

![Equation](images/B9780443292385000251/si101.png)

Fixing the parameters **θ**[*f*]![Equation](images/B9780443292385000251/si99.png), the parameters **θ**[*g*]![Equation](images/B9780443292385000251/si102.png) that define the generator are estimated by minimizing the difference in the bracket above. Note that this gradient depends only on the second term, the first being independent of **θ**[*g*]![Equation](images/B9780443292385000251/si102.png). As the loss function decreases during the training, the Wasserstein distance gets smaller and the output of the generator gets closer to the real data distribution. The Wasserstein GAN scheme is outlined in [Algorithm 19.3](#Chp019_997-1102_B9780443292385000251.xhtml#enun0025).
