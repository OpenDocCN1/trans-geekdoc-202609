
[图 19.2](#Chp019_997-1102_B9780443292385000251.xhtml#f0015) 展示了一个具有三个隐藏层的神经网络的框图。输入随机变量的向量表示为 `x`，与隐藏层相关的向量表示为 `h^(i)`，`i = 1, 2, 3`。输出节点的向量表示为 `y`。预训练按顺序逐层进行，从连接输入节点与第一隐藏层节点的权重开始。这可以通过最大化观测到的输入观测样本 `x` 的似然概率来实现，并将与第一层相关的变量视为隐藏变量。一旦计算出对应第一层的权重，相应的节点就被允许激活输出值，并形成一个值向量 `h^1`。这就是为什么在无监督预训练中采用生成模型（如 RBM）的原因，以便能够*以概率方式*在隐藏节点生成输出。这些值随后被用作下一个隐藏层预训练的观测值，以此类推。

图 19.2 具有三个隐藏层和一个输出层的神经网络架构框图。输入层处输入随机变量的向量表示为 `x`。第 `i` 个隐藏层节点相关变量的向量表示为 `h^(i)`，`i = 1,2,3`。输出变量表示为 `y`。在预训练的每个阶段，与一个隐藏层相关的权重被一次计算。对于图中包含三个隐藏层的网络，预训练包含三个无监督学习阶段。一旦隐藏单元的预训练完成，与输出节点相关的权重将通过监督学习算法进行预训练。在最终的微调期间，所有参数通过监督学习规则（如反向传播方案）进行估计，使用预训练期间获得的值作为初始值。

预训练完成后，随后采用监督学习规则（如反向传播）来获得通向输出节点的权重值，并微调与隐藏层相关的权重，使用预训练阶段获得的值作为初始权重值。

正如之前所述，无监督学习是一种通过学习数据的潜在规律性和统计结构来发现并揭示数据中隐藏信息的方法。通过这种方式，预训练可以被视为一种依赖数据的*正则化项*，它通过利用无监督学习获得的额外信息，将未知参数推向存在良好解的区域（参见例如 [47]）。

[图 19.2](#Chp019_997-1102_B9780443292385000251.xhtml#f0015) 图示了一个具有三个隐藏层的多层感知机。与任何监督学习任务一样，起点始终是一组训练样本，`(y[n], x[n])`，`n = 1, 2, ..., N`。采用前述方法训练深度多层感知机包含两个主要阶段：(a) 预训练和 (b) 监督微调。与隐藏节点相关的权重预训练涉及通过 RBM 理论进行无监督学习。假设有 `K` 个隐藏层，`h^(k)`，`k = 1, 2, ..., K`，我们成对地查看它们，即 `(h^(k-1), h^(k))`，`k = 1, 2, ..., K`，其中 `h^0 := x` 为输入层。每一对将以层次化方式被视为一个 RBM，前一个的输出成为下一个的输入。可以证明（例如 [80]），每次增加一层都会增加训练数据对数概率的一个变分下界。

通向输出节点的权重预训练通过监督学习算法执行。最后一个隐藏层连同输出层不被视为 RBM，而是被视为单层前馈网络。换句话说，该*监督*学习任务的输入包含在最后一个隐藏层中形成的特征。
