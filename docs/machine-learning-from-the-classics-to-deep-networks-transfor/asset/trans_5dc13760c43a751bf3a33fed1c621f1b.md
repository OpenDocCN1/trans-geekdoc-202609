

$q(y|\mathbf{x}_t) \propto \frac{q(\mathbf{x}_t|y)}{q(\mathbf{x}_t)}.$

换句话说，在隐式分类器中，我们将前面的比率提升到 `γ` 次方。在实践中，选择 `γ` 的值是在样本多样性和样本质量之间进行权衡的结果。在生成图像时，增加 `γ` 会降低多样性并提高样本保真度，例如 [86]。这在[图 19.25](#Chp019_997-1102_B9780443292385000251.xhtml#f0140)中展示。最左边的图对应无条件模型，`γ = 0`（高多样性-低保真度），中间的图对应 `γ = 1.5`，最右边的图对应 `γ = 3`（低多样性-高保真度）。^([^(147)](#fn147))

![Figure 19.25 (Left) The unconditional model (γ = 0) exhibits high variability and low image fidelity. (Center) It corresponds to γ = 1.5. (Right) It corresponds to γ = 3 and it exhibits low variability and high image fidelity.](images/B9780443292385000251/gr025.jpg)

[图 19.25](#Chp019_997-1102_B9780443292385000251.xhtml#cf2870)（左）无条件模型（`γ` = 0）表现出高多样性和低图像保真度。（中）对应 `γ` = 1.5。（右）对应 `γ` = 3，表现出低多样性和高图像保真度。

正如我们即将看到的，基于分类器或无分类器引导的条件模型已被扩展并用于这样的情况：模型受约束的不再是类别标签，而是更一般的约束，例如文本描述。

### 19.7.7 应用

扩散模型已被应用于广泛的领域，目前，在越来越多的学科中采用此类建模的趋势正在快速增长。

在计算机视觉中，除了图像和视频生成外，它们还被用于图像超分辨率、编辑、修复、复原和分割等任务。在时间序列分析中，它们被应用于插补、预测、波形生成等任务。在 NLP 任务中，它们被用于序列到序列生成，例如 [60]。关于相关的大量文献综述，请参见例如 [41]、[200]、[115]。

最“热门”且知名度最高的应用之一（远超科学界）是文本到图像生成，下文将重点介绍。

#### 文本到图像生成

文本到图像生成可以被视为一种以相应文本描述为条件的图像生成任务。文本到图像生成的主题可追溯至 [127]，其中 DRAW ([65]) 生成模型被扩展为以图像标题为条件以生成新颖的视觉场景。在这项工作之后，[153] 采用了一种 GAN，提高了生成图像的质量，并能生成具有可识别属性的物体。在 [151] 中，文本到图像生成是基于 Transformer 进行的，该 Transformer 将文本和图像标记自回归地建模为单一数据流。^([^(148)](#fn148))

**CLIP**：遵循自监督背后的通用原理，CLIP 使用两个分支联合训练两个编码器。请参阅[图 19.26](#Chp019_997-1102_B9780443292385000251.xhtml#f0145) 以获取简化的框图。上部分支编码器的输入被馈送描述图像的文本描述（标题），该标题又馈送给下部分支编码器的输入。例如，如果图像包含一只戴帽子的狗（如图所示），相应的描述可能是“戴帽子的狗”。标题中的文本经过适当的嵌入（参见例如第 [19.3.1](#Chp019_997-1102_B9780443292385000251.xhtml#s0075) 节）后被编码为相应的向量表示。

![Figure 19.26 CLIP consists of two branches. In the upper one, a text description/caption is prompted, which is then mapped into a vector embedding, t. The lower branch is fed with an image, x, that relates to the text description. In the sequel, t and x are provided as inputs to two parameterized encoders, gϕ and fξ, respectively. The corresponding encoded outputs, zt = gϕ(t) and zi = fξ(x), are used in the contrastive loss function \mathcal{L}Equation. The parameters, ϕ and ξ, of the two encoders are jointly optimized to make the respective encoded outputs, zt and zi, more similar (dissimilar) if the text description and the content of the corresponding image match (do not match).](images/B9780443292385000251/gr026.jpg)

[图 19.26](#Chp019_997-1102_B9780443292385000251.xhtml#cf2945) CLIP 由两个分支组成。在上部分支中，输入一段文本描述/标题，随后将其映射为向量嵌入 `t`。下部分支输入一幅与该文本描述相关的图像 `x`。随后，`t` 和 `x` 分别作为输入被提供给两个参数化编码器 `g[ϕ]` 和 `f[ξ]`。相应的编码输出 `z[t] = g[ϕ](t)` 和 `z[i] = f[ξ](x)` 被用于对比损失函数 `ℒ`。两个编码器的参数 `ϕ` 和 `ξ` 被联合优化，以使相应的编码输出 `z[t]` 和 `z[i]` 在文本描述与相应图像内容匹配（不匹配）时变得更相似（不相似）。
