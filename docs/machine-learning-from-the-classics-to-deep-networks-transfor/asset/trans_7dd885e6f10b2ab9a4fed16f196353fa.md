

## 示例 20.6

[图 20.14](#Chp020_1103-1179_B9780443292385000263.xhtml#f0095) 显示了一组通过二维高斯分布生成的数据，其均值为零，协方差矩阵等于

```
\Sigma = \begin{bmatrix} {5.05\ } & {- 4.95} \\ {- 4.95\ } & 5.05 \\ \end{bmatrix}.
```

![Equation](images/B9780443292385000263/si391.png)

对应的特征值/特征向量计算如下：

```
\lambda_1 = 0.05,\quad \mathbf{a}_1 = [1, 1]^T,\quad \lambda_2 = 5.00,\quad \mathbf{a}_2 = [-1, 1]^T.
```

![Equation](images/B9780443292385000263/si392.png)

![图 20.14 数据点分布在 \mathbb{R}^{2} 中一条直线（一维子空间）周围。该子空间通过运行 EM 算法的 PPCA 完全恢复。](images/B9780443292385000263/gr014.jpg)

[图 20.14](#Chp020_1103-1179_B9780443292385000263.xhtml#cf1115) 数据点分布在 $\mathbb{R}^2$ 中一条直线（一维子空间）周围。该子空间通过运行 EM 算法的 PPCA 完全恢复。

观察可知，数据主要分布在一条直线周围。对该数据集运行了 $m=1$ 的 EM PPCA 算法。

![Equation](images/B9780443292385000263/si11.png)

由此得到的矩阵 $\mathbf{A}$（此时变为一个向量）为

```
\mathbf{a} = [-1.71, 1.71]^T
```

![Equation](images/B9780443292385000263/si393.png)

且 $\beta = 0.24$。

![Equation](images/B9780443292385000263/si394.png)

注意，得到的向量 $\mathbf{a}$ 指向数据分布所在的直线（子空间）方向。
