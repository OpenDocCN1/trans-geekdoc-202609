

#### 等度量映射

上述最小化过程受两个约束条件限制，以避免退化解：

1.  输出以原点为中心：`∑ₙ zₙ = 0`。
2.  输出具有单位协方差矩阵 [159]。

第 1 步中的最近邻点，以与拉普拉斯特征映射方法相同的方式进行搜索。再次强调，只要搜索局限于邻域点的“局部”范围内，欧氏距离的使用就可以由流形的平滑性来证明。对于第 2 步，该方法利用了平滑流形的局部线性性质，并试图使用最小二乘法通过其邻居*线性地*预测每个点。

在 Eq. [(20.117)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq177) 给出的约束条件下最小化代价函数，得到的解满足以下三个性质：

1.  旋转不变性
2.  尺度不变性
3.  平移不变性

前两个性质可以通过代价函数的形式轻松验证，第三个性质则是施加约束的结果。这意味着计算出的权重编码了每个邻域内在特征的信息，并且不依赖于特定的点。

所得权重 `W(i, j)` 反映了数据底层局部几何结构的内在属性。由于我们的目标是在映射后保留局部信息，因此这些权重被用来通过其邻居在 `ℝᵐ` 子空间中重构每个点。正如文献 [159] 精辟所述，这就像我们拿起一把剪刀，将流形切割成小的线性补丁，并将它们放置在低维子空间中。

结果表明，针对未知点 `zₙ, n = 1,2,…,N` 求解 [(20.118)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq178) 等价于：

*   对矩阵 `(I − W)ᵀ(I − W)` 进行特征分解。
*   丢弃对应最小特征值的特征向量。
*   取对应次小特征值的特征向量。这些向量给出了低维潜在变量得分 `zₙ, n = 1,2,…,N`。

再次强调，涉及的矩阵 `W` 是稀疏的，如果考虑到这一点，特征值问题对于大规模数据集的扩展性相对较好，复杂度关于 `N` 为亚二次方。第 2 步的复杂度为 `O(Nk³)`，这归因于为每个点求解含有 `k` 个未知数的线性方程组。该方法需要用户提供两个参数：最近邻数 `k`（或 `ϵ`）和维度 `m`。感兴趣的读者可参考文献 [159] 了解更多关于 LLE 方法的内容。
