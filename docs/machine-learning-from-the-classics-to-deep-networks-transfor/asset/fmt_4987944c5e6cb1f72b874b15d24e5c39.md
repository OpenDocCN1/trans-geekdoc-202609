
### 复数梯度下降方向推导

$$J(\boldsymbol{\theta} + \Delta\boldsymbol{\theta}) = J(\boldsymbol{\theta}) + \text{Re}\{\Delta\boldsymbol{\theta}^H \nabla_{\boldsymbol{\theta}^*} J(\boldsymbol{\theta})\} \tag{5.26}$$

其中 $\nabla_{\boldsymbol{\theta}^*} J(\boldsymbol{\theta})$ 是 CW-导数，定义见 [Section 4.4.2](#Chp004_119-175_B978044329238500010X.xhtml)：

$$\nabla_{\boldsymbol{\theta}^*} J(\boldsymbol{\theta}) = \frac{1}{2} \left( \nabla_{r} J(\boldsymbol{\theta}) + j \nabla_{i} J(\boldsymbol{\theta}) \right)$$

仔细观察 Eq. [(5.26)](#Chp005_177-248_B9780443292385000111.xhtml#deq44)，可以直接看出方向

$$\Delta\boldsymbol{\theta} = -\mu \nabla_{\boldsymbol{\theta}^*} J(\boldsymbol{\theta})$$

使得更新后的代价函数为

$$J(\boldsymbol{\theta} + \Delta\boldsymbol{\theta}) = J(\boldsymbol{\theta}) - \mu \|\nabla_{\boldsymbol{\theta}^*} J(\boldsymbol{\theta})\|^2$$

这保证了 $J(\boldsymbol{\theta} + \Delta\boldsymbol{\theta}) < J(\boldsymbol{\theta})$；考虑到内积的定义，很容易看出上述搜索方向是下降最快的方向。因此，Eq. [(5.3)](#Chp005_177-248_B9780443292385000111.xhtml#deq6) 的对应形式变为
