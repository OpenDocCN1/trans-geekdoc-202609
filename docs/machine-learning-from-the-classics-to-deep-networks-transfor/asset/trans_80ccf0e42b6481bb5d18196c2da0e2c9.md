
训练完成后，获得参数的最优值 `θ*`。当在第 `t` 步将样本 `x[t]` 应用于神经网络的输入时，网络的输出 `s_θ*(x[t], t)` 提供了 `∇_x[t] ln q(x[t])` 的相应估计。

采样根据 **算法 19.6** 执行。

## 算法 19.6

**NSCN 逆过程的采样**

*   **输入**
    1.  `N`：朗之万迭代的数量。
    2.  `γ[1], γ[2], …, γ[T]`：朗之万方程中的控制变量序列。

*   `x_T^(0) ~ N(0, I)`；在 `t = T` 处抽取第一个样本。

*   **For** `t = T, T−1, …, 1` **Do**
    1.  **For** `i = 1, 2, …, N` **Do**；为每个步骤 `t` 生成 `N` 个样本。
        1.  `ϵ ~ N(0, I)`
        2.  
```
x_t^(i) = x_t^(i-1) + (γ_t / 2) * s_θ*(x_t^(i-1), t) + sqrt(γ_t) * ϵ
```
    2.  **End For**
    3.  `x_{t-1}^(0) = x_t^(N)`

*   **End For**

*   **输出** `x_0 = x_1^(N)`
