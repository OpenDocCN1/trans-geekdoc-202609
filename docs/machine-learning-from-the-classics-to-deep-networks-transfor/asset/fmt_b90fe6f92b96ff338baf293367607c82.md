
## KL 散度公式

$$KL(Q||P) = \sum\limits_{i}\left( \mu_{i}\ln\mu_{i} + (1 - \mu_{i})\ln(1 - \mu_{i}) + \sum\limits_{j > i}\theta_{ij}\mu_{i}\mu_{j} + {\widetilde{\theta}}_{i0}\mu_{i} \right) + \ln\widetilde{Z},$$

其中索引 $i$ 和 $j$ 遍历 $\mathcal{X}^{(l)}$ 中的点。关于 $\mu[i]$ 最小化上述公式最终得到（问题 [16.13](#Chp016_805-853_B9780443292385000226.xhtml#o0105)）：

![Equation](images/B9780443292385000226/fx005.jpg) (16.21)

其中 $\sigma(\cdot)$ 是 sigmoid 链接函数；回顾 Ising 模型的定义，如果 $x[i]$ 和 $x[j]$ 相连，则 $\theta[i j] = \theta[j i] \neq 0$，否则为零。将值 $\mu[i]$ 代入公式 [(16.19)](#Chp016_805-853_B9780443292385000226.xhtml#deq39)，得到了用 $Q(\mathcal{X}^{(l)}; \boldsymbol{\mu})$ 表示的 $P(\mathcal{X}^{(l)}|\mathcal{X})$ 的近似。

公式 [(16.21)](#Chp016_805-853_B9780443292385000226.xhtml#deq42) 等价于一组称为**均场方程**的耦合方程，它们以递归方式用于计算解的不动点集（假设存在）。公式 [(16.21)](#Chp016_805-853_B9780443292385000226.xhtml#deq42) 非常有趣。虽然我们假设隐节点之间相互独立，但施加 KL 散度最小化，与变量真实相互依赖性质相关的信息（由 $P(\mathcal{X}^{(l)}|\mathcal{X})$ 传达）被“嵌入”到了关于 $Q(\mathcal{X}^{(l)}; \boldsymbol{\mu})$ 的均值中；相应变量的均值是**相互关联的**。公式 [(16.21)](#Chp016_805-853_B9780443292385000226.xhtml#deq42) 也可以视为一种消息传递算法（参见 [图 16.12](#Chp016_805-853_B9780443292385000226.xhtml#f0065)）。[图 16.13](#Chp016_805-853_B9780443292385000226.xhtml#f0070) 展示了应用均场近似前后与玻尔兹曼机相关的图。
