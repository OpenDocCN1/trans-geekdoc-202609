## 步骤 3

接下来，在获得 softmax 相似度分数后，我们为每一个输入嵌入 `x[n], n = 0, 1, …, N + 1` 计算一个*更新后的表示*，如下所示：

```
x_n → z'_n = ∑_{j = 0}^{N + 1} s_{nj} v_j, n = 0,1,…,N + 1.
```

(19.34)

请注意，对于每个位置 `n`，这个新嵌入是作为*所有*值向量的加权平均而得出的，每个值向量由相应的 softmax 注意力分数加权。因此，这个更新后的嵌入基于整个序列编码了*上下文信息*。通过这种方式，除了 `s[nn]`（它衡量第 `n` 个嵌入与其自身的相似度，预期具有最大值）之外，我们还允许第 `n` 个嵌入*关注*其他一些与其更相关/更相似的位置。此外，公式 [(19.34)](#Chp019_997-1102_B9780443292385000251.xhtml#deq80) 中的展开不是基于原始嵌入 `x[j]` 进行的，而是基于相应的值向量，它们是各自优化后的版本。我认为这个整体构想确实很巧妙。
