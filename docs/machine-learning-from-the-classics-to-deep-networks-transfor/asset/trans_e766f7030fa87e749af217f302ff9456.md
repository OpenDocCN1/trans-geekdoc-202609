在进一步讨论之前，有必要做一些解释。

*   辅助变量 $\widetilde{\xi_{n}}$ 和 $\xi[n]$，$n = 1, 2, \ldots, N$，它们衡量相对于 $\epsilon$ 的超额误差，被称为*松弛变量*。请注意，根据 $\epsilon$ 不敏感原理，绝对值小于或等于 $\epsilon$ 的误差对代价函数的贡献为零。前述优化任务试图估计 $\boldsymbol{\theta}$、$\theta_{0}$，使得误差值大于 $\epsilon$ 和小于 $-\epsilon$ 的贡献最小化。因此，[(11.30)](#Chp011_519-582_B9780443292385000172.xhtml#deq98)–[(11.33)](#Chp011_519-582_B9780443292385000172.xhtml#deq101) 中的优化任务等价于最小化正则化经验风险函数

$$
\frac{1}{2}||\boldsymbol{\theta}||^{2} + C\sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},\boldsymbol{\theta}^{T}\boldsymbol{x}_{n} + \theta_{0} \right),
$$

![Equation](images/B9780443292385000172/si249.png)

*   其中损失函数是线性 $\epsilon$ 不敏感损失函数。请注意，任何其他用于最小化（非可微）凸函数的方法均可使用（例如，第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章）。然而，涉及松弛变量的约束优化具有历史价值，正是这条路径为采用核技巧铺平了道路，正如我们即将看到的那样。

#### 解

通过引入拉格朗日乘子并构建相应的拉格朗日函数（详细推导见下文），可获得优化任务的解。在得到拉格朗日乘子后，解的形式显得既简单又相当优雅，

$$
\widehat{\boldsymbol{\theta}} = \sum\limits_{n = 1}^{N}(\widetilde{\lambda}_{n} - \lambda_{n})\boldsymbol{x}_{n},
$$

![Equation](images/B9780443292385000172/si250.png)

其中 $\widetilde{\lambda}[n]$、$\lambda[n]$，$n = 1, 2, \ldots, N$，是与 [(11.31)](#Chp011_519-582_B9780443292385000172.xhtml#deq99) 和 [(11.32)](#Chp011_519-582_B9780443292385000172.xhtml#deq100) 中每个约束相关联的拉格朗日乘子。结果表明，拉格朗日乘子*仅*对那些对应误差值*等于或大于 $\epsilon$* 的点 $\boldsymbol{x}[n]$ 才非零。这些点被称为*支持向量*。对应误差值*小于* $\epsilon$ 的点，其拉格朗日乘子为零，不参与解的构建。偏置项可以从以下方程组中的任意一个获得
