
换句话说，从一个初始估计开始，例如，用一些小值随机初始化 `θ^((0))`，我们测试每一个样本 `x[n]`，`n = 1, 2, …, N`。每当一个样本被误分类时，就采取行动进行修正。否则不需要采取行动。一旦所有样本都已被考虑，我们就说完成了一个*轮次*（epoch）。如果尚未达到收敛，则在第二个轮次中重新考虑所有样本，依此类推。这种算法版本被称为*逐模式*（pattern-by-pattern）方案。有时它也被称为*在线*（online）算法。然而，请注意，“在线”一词在前几章中曾用于不同的语境，当时数据是以流式/顺序方式接收的，且其数量是无界的。相比之下，在当前语境下，数据样本的总数是固定的，算法以*循环方式*（cyclic fashion）考虑它们，一个轮次接一个轮次。为避免混淆，将采用前者“逐模式”这一术语。

经过有限*个*连续轮次后，该算法保证收敛。请注意，为了收敛，序列 `μ[i]` 必须经过适当选择。这对我们现在来说已经相当熟悉了。然而，对于感知机算法的情况，即使 `μ[i]` 是一个正常数 `μ[i] = μ > 0`（通常取值为 1），仍然保证收敛（问题 [18.1](#Chp018_885-995_B978044329238500024X.xhtml#o0020)）。

公式 [(18.4)](#Chp018_885-995_B978044329238500024X.xhtml#deq7) 将感知机算法置于所谓的学习*奖惩*（reward-punishment）哲学之下。如果当前估计成功预测了相应模式的类别，则不采取任何行动（奖励）。否则，算法受到惩罚而执行更新。

[图 18.1](#Chp018_885-995_B978044329238500024X.xhtml#f0010) 提供了感知机规则的几何解释。假设样本 `x` 被超平面 `θ^((i−1))` 误分类。根据几何知识，`θ^((i−1))` 对应一个垂直于由该向量定义的超平面的向量（另见第 [11.10.1](#Chp011_519-582_B9780443292385000172.xhtml) 节中的 [图 11.15](#Chp011_519-582_B9780443292385000172.xhtml)）。因为 `x` 位于超平面的（−）侧且被误分类，所以它属于类别 `ω[1]`。因此，假设 `μ = 1`，算法施加的修正是

```
θ^((i)) = θ^((i−1)) + x,
```

其效果是将超平面朝向 `x` 的方向旋转，使其位于由更新后的估计 `θ^((i))` 定义的新超平面的（+）侧。
