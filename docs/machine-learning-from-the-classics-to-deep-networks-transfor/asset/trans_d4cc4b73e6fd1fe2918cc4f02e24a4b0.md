

## 图 1.1

分类器（在本简单案例中为线性）的设计旨在将训练数据分为两类。线性函数 `f(x) = 0` 的图（直线）在其正侧包含来自一类的点，在其负侧包含另一类的点。类别未知的“红色”点被归类为与“星号”点相同的类别，因为它位于直线的正侧。

一旦分类器被“学习”完成，我们就可以进行预测，即预测模式 `x` 的类标签。例如，给定一个由红圈表示、类别未知的点。根据已设计的分类系统，该点属于与星号表示的点相同的类别，假设均属于类别 +1。确实，直线一侧的每个点都将给出正值 `f(x) > 0`，而另一侧的所有点将给出负值 `f(x) < 0`。由红圈表示的点的预测标签 `ŷ` 将为 `ŷ = sgn{f(x)} > 0`，因此它被归类为星号点所属的类别 +1。

我们关于分类任务的讨论基于取数值的特征。特征为分类类型的分类任务也存在，且同样具有重要意义。

## 回归

回归在很大程度上共享前文所述的特征生成/选择阶段；然而，输出变量 `y` 现在*不是*离散的，而是取实轴上某个区间或复数平面上某个区域内的值。向量值输出的推广也是可能的。我们的重点在于实变量。回归任务本质上是一个函数（曲线/曲面）拟合问题。

我们得到一组训练样本 `(y[n], x[n])`，其中 `y[n] ∈ ℝ`，`x[n] ∈ ℝ^l`，`n = 1, 2, …, N`，任务是估计一个函数 `f`，使其图拟合这些数据。一旦找到这样一个函数，当一个新样本 `x`（位于训练集之外）到达时，我们就可以预测其输出值。这在图 1.2 中有所展示。本例中的训练数据为灰色点。完成函数拟合任务后，给定一个新点 `x`（红色），我们即可将其输出值预测为 `ŷ = f(x)`。在图中的简单情况下，函数 `f` 为线性，因此其图为一条直线。

## 图 1.2

在回归任务中，设计一个函数（本例中为线性）`f`，使其图拟合可用的训练数据集。给定一个新的（红色）点 `x`，相应输出（红色）值的预测计算为 `ŷ = f(x)`。

回归任务是一个通用任务，涵盖多种问题。例如，在金融应用中，可以根据当前市场状况和其他相关信息预测明天的股票价格。每条信息都是相应特征的测量值。信号和图像复原也属于这一类任务。信号和图像去噪也可视为回归任务的一种特殊类型。模糊图像的去模糊也可视为回归处理（见第 4 章）。

## 1.6 无监督、自监督和半监督学习

监督学习的目标是建立输入变量和输出变量之间的函数关系。为此，使用带标签的数据，这些数据由输出-输入对组成，在其上执行未知映射的学习。

在监督学习的对立面是*无监督学习*，其中仅提供输入变量。没有可用的输出或标签信息。无监督学习的目标是揭示给定数据集的潜在结构。这是数据学习方法的重要组成部分。无监督学习有多种形式。
