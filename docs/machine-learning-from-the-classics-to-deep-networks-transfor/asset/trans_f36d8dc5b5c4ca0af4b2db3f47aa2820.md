### 16.2.2 连接树中的消息传递

根据定义，连接树是一种连接树，其中我们将概率分布 `p` 的一个因子（记为 `ψ[c]`）与每一个团相关联。每个因子可能是所有势函数乘积的结果，这些势函数以相应团节点相关的变量来定义；因此，每一个势函数的定义域都是构成该团的变量-节点的子集。然后，聚焦于离散概率情况，我们可以写成

```
P(x) = (1/Z) ∏_c ψ_c(x_c),
```
