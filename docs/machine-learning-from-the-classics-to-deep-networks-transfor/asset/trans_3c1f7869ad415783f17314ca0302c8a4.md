

## 9.17

证明：如果欠定方程组 `y = Xθ` 存在满足以下条件的解

```
||θ||_0 < 1/2 (1 + 1/μ(X))
```

则 ℓ₁ 最小化器等价于 ℓ₀ 最小化器。假设 `X` 的列已归一化。

## 9.18

证明：如果矩阵 `X` 满足 `k` 阶 RIP 且 `δ_k < 1`，则 `X` 的任意 `m < k` 列必然线性无关。

## 9.19

证明：如果 `X` 满足 `k` 阶 RIP 及某等距常数 `δ_k`，则乘积 `XΨ` 也满足，前提是 `Ψ` 为正交矩阵。
