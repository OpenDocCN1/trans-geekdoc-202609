
**x** = *A***z**，**x** ∈ ℝ^(*l*)，**z** ∈ ℝ^(*m*)，

且 *A* 为未知的 *l* × *m* 矩阵。通常 *m* ≫ *l*。即使 *A* 已知且固定，也不需要特殊的数学技巧就能看出该任务没有唯一解，因此必须向问题中引入约束。为此，我们将采用促稀疏约束，正如我们在本书各处已讨论的那样。

设 **x**[*n*]，*n* = 1, 2, …, *N*，为将构成唯一可用信息的观测值。任务是获取字典的原子（即 *A* 的列）以及假定为稀疏的潜在变量；也就是说，我们将为输入观测值（向量）建立稀疏表示。毫无疑问，达到该目标有不同的途径。我们将重点关注最广为人知且使用最广泛的方法之一，即 *k-SVD*，该方法在文献 [4] 中提出。

令 *X* := [**x**[1], …, **x**[*N*]]，*A* := {**a**[1], …, **a**[*m*]}，和 *Z* := [**z**[1], …, **z**[*N*]]，其中 **z**[*n*] 为与输入 **x**[*n*] 对应的潜在向量，*n* = 1, 2, …, *N*。字典学习任务被表述为以下优化问题：

```
min_{A,Z} ||X - AZ||_F^2 subject to ||z_n||_0 <= T_0 for n = 1, ..., N
```

其中 *T*₀ 为阈值，||·||₀ 表示 ℓ₀ 范数，详见第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章。这是一个非凸优化任务，通过迭代方式执行；每次迭代包含两个阶段。在第一阶段中，假设 *A* 固定，针对 **z**[*n*]，*n* = 1, 2, …, *N* 进行优化。在第二阶段，假设潜在向量固定，针对 *A* 的列进行优化。

在 *k*-SVD 中，采用了略有不同的原理。在针对 *A* 的列进行优化时（一次一列），也会同步更新 *Z* 的部分元素。这是 *k*-SVD 与更标准优化技术的关键区别；在实践中，这似乎能带来性能提升。
