
$C\_{2} = \left\{ \mathbf{x}:\sqrt{x\_{1}^{2} + x\_{2}^{2}} \leq 1 \right\}.$

![Equation](images/B9780443292385000147/si14.png)

有时我们将 $C\_2$ 称为半径等于一的 $\ell\_2$-*球*。请注意，该集合包含圆*上及内部*的所有点。[图 8.1](#Chp008_343-416_B9780443292385000147.xhtml#f0010)B 中的集合包含由以下公式定义的菱形*上及内部*的所有点：

$C\_1 = \{\mathbf{x}:|x\_1|+|x\_2|\leq 1\}.$

![Equation](images/B9780443292385000147/si16.png)

因为向量各分量绝对值之和定义了 $\ell\_1$ 范数，即 $\|\mathbf{x}\|\_1 := |x\_1| + |x\_2|$，类比 $C\_2$，我们称集合 $C\_1$ 为半径等于一的 $\ell\_1$ 球。相反，其 $\ell\_2$ 和 $\ell\_1$ 范数等于一的集合，换句话说就是

$\overline{C}\_2 = \left\{ \mathbf{x}:x\_{1}^{2} + x\_{2}^{2} = 1 \right\},\overline{C}\_1 = \left\{ \mathbf{x}:|x\_1| + |x\_2| = 1 \right\}$

![Equation](images/B9780443292385000147/si20.png)

则不是凸集（问题 [8.2](#Chp008_343-416_B9780443292385000147.xhtml#o0040)）。[图 8.2](#Chp008_343-416_B9780443292385000147.xhtml#f0015) 展示了两个非凸集的例子。
