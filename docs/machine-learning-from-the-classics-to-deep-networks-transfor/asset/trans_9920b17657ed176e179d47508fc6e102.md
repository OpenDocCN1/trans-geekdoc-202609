

## 非贪心算法求解替代形式

迄今为止讨论的所有非贪心算法都是为了求解公式 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 中定义的任务而开发的。这主要是因为这是一个更容易求解的任务；一旦固定了 `λ`，它就变成了一个无约束优化任务。然而，也存在一些算法是专门为求解替代形式而开发的。

### NESTA 算法

NESTA 算法由文献 [12] 提出，用于求解其 [(9.8)](#Chp009_417-462_B9780443292385000159.xhtml) 形式下的任务。采用这条路径具有一定优势，因为 `ϵ` 可能作为与噪声相关的不确定性的估计值给出，这在许多实际应用中可以轻松获得。相比之下，预先选择 `λ` 的值则更为复杂。在文献 [28] 中，认为值 `λ = σ_η√(2 ln l)`（其中 `σ[η]` 为噪声标准差）具有某些最优性质；然而，这一论点依赖于 `X` 的正交性假设。

NESTA 很大程度上依赖于 Nesterov 的通用方案 [96]，因此得名。原始 Nesterov 算法对光滑凸函数 `f(θ)` 执行约束最小化，即：

```
min_{θ ∈ Q} f(θ),
```

其中 `Q` 是一个凸集，在我们的情况下，它与 [(9.8)](#Chp009_417-462_B9780443292385000159.xhtml) 中的二次约束相关联。该算法由三个基本步骤组成。第一步涉及一个辅助变量，类似于公式 [(10.3)](#Chp010_463-518_B9780443292385000160.xhtml#deq17) 中的步骤，即：

```
w^(i) = arg min_{θ ∈ Q} { (θ - θ^(i-1))^T ∂f(θ^(i-1))/∂θ + L/2 ||θ - θ^(i-1)||_2^2 },
```

其中 `L` 是梯度 `f` 必须满足的 Lipschitz 系数的上界。与公式 [(10.3)](#Chp010_463-518_B9780443292385000160.xhtml#deq17) 的区别在于，该最小化现在是一个约束最小化。然而，Nesterov 还增加了第二步，涉及另一个辅助变量 `z^(i)`，其计算方式与 `w^(i)` 类似，但用 `Q` 的代理函数替代了平方欧几里得范数，且线性化项现在被加权累积梯度所取代。
