
然而，性能提升的百分比在很大程度上取决于定义模型的具体数值，正如公式 [(3.45)](#Chp003_65-117_B9780443292385000093.xhtml#deq82) 所示。例如，若 `θ[o] = 0.1`，实验获得的数值为 `MSE(θ̂[MVU]) = 1.00061 × 10^(−3)` 和 `MSE(θ̂[b](λ[*])) = 9.99578 × 10^(−4)`。根据公式 [(3.45)](#Chp003_65-117_B9780443292385000093.xhtml#deq82) 计算得出的理论值分别为 `1 × 10^(−3)` 和 `9.99001 × 10^(−4)`。此时，使用岭回归所获得的改进已相当微不足道。

## 3.9 偏差-方差困境

本节将进一步拓展第 [3.5](#Chp003_65-117_B9780443292385000093.xhtml#s0035) 节的内容。在那里，我们使用 MSE 准则来量化相对于未知参数的性能。这种设定有助于我们理解某些趋势，并更好地消化“有偏”与“无偏”估计的概念。而在本节中，虽然准则保持不变，但将用于更一般的设定。为此，我们将关注点从未知参数转移到因变量上，目标变为在给定回归向量测量值 `x = x` 的情况下，获得因变量 `y` 的估计器。

让我们首先考虑回归的更一般形式，

```
y = g(x) + η,
```
(3.46)

为简单起见且不失一般性，我们再次假设因变量取实轴上的值，即 `y ∈ ℝ`。首先要解决的问题是：是否存在一个能保证最小均方误差性能的估计器。

### 3.9.1 均方误差估计

我们的目标是估计一个未知的（通常是非线性的）函数 `g(x)`。该问题可以置于更一般的估计任务框架中。

```
ĝ(x) = arg min[f : ℝ^(l) → ℝ] 𝔼 [(y − f(x))²],
```
