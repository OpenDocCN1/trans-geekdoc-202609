
请注意，在消息流完成一次传递后，`P(x)` 的最大值已经获得。然而，人们也关心使最大值发生时对应的 `x*` 值，即

```
x* = argmax_x P(x).
```

这通过一个反向消息传递过程来实现，该过程与我们迄今为止讨论的略有不同，称为回溯。

**回溯**：假设 `x1` 是被选中作为根节点的节点，消息流在此“汇聚”。根据公式 [(15.61)](#Chp015_755-803_B9780443292385000214.xhtml#deq87)，我们得到

```
x1* = argmax_x1 μ_fa→x1(x1) μ_fg→x1(x1) μ_fh→x1(x1).
```
