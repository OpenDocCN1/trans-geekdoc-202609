

*p*(**x**|**y**) = *q*(**x**|**y**)*α*(**x**|**y**) + *δ*(**x** − **y**)*r*(**x**),

其中 *r*(**x**) 为拒绝概率，

*r*(**x**) = ∫(1 − *α*(**x**|**y**))*q*(**x**|**y**) d**y**，

而 *δ*(·) 为狄拉克 δ 函数。稍加思考可知，按上述定义，*p*(·|·) 即为等价马尔可夫链的转移密度核（有限离散空间的转移矩阵），即 *p*(**x**[*n*]|**x**[*n* − 1])。此外，该马尔可夫链具有所需的分布 *p*(**x**) 作为其不变分布，即

*p*(**x**) = ∫*p*(**x**|**y**)*p*(**y**) d**y**，

正如第 [14.7](#Chp014_717-754_B9780443292385000202.xhtml#s0045) 节已指出的那样，这是满足以下详细平稳条件的直接结果（问题 [14.12](#Chp014_717-754_B9780443292385000202.xhtml#o0065)）：

*p*(**x**|**y**)*p*(**y**) = *p*(**y**|**x**)*p*(**x**)。

原来，只要 *p*(**x**|**y**) 和 *p*(**x**) 为*严格正值*，该等价马尔可夫链就是遍历的，因此收敛于不变（所需）分布。这保证了从任意状态出发均可到达任意状态，且概率非零。

因此，Metropolis–Hastings 算法等价地从由公式 [(14.49)](#Chp014_717-754_B9780443292385000202.xhtml#deq97) 给出的转移密度所定义的马尔可夫链中抽取样本，尽管样本是从选定的（易于采样的）建议分布中抽取的。常用于充当建议分布的典型分布有高斯分布和柯西分布。后者因其重尾特性，允许大幅变化偶尔发生。有时也会使用均匀分布。对于离散情况，均匀分布似乎是一个常用的选择。
