令 **θ**[*j*]^(*r*) 表示与第 *r* 层中第 *j* 个神经元相关的突触权重向量，其中 *j* = 1, 2, …, *k*[*r*] 且 *r* = 1, 2, …, *L*，偏置项包含在 **θ**[*j*]^(*r*) 中，即

**θ**[*j*]^(*r*) := [*θ*[*j*0]^(*r*), *θ*[*j*1]^(*r*), …, *θ*[*j**k*[*r*−1]]^(*r*)]^(*T*)。 (18.9)

突触权重将相应神经元与第 *k*[*r*−1] 层的所有神经元连接起来（见图 18.11）。梯度下降方案的基本迭代步骤写为

```
θ_j^(r)(new) = θ_j^(r)(old) - μ ∂J/∂θ_j^(r)
```

参数 *μ* 是用户定义的步长（也可以与迭代次数有关），*J* 表示代价函数。
