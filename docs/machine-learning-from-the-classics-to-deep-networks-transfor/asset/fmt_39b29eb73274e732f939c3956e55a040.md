
Another example where regularization can help to obtain a solution is when the model's order is large compared to the number of data, although we know that it is sparse. That is, only a very small percentage of the model's parameters is nonzero. For such a task, regularizing the sum of squared errors cost function using the `ℓ₁` norm of the parameter vector promotes sparse solutions, by assigning zero values to the least significant parameters; the `ℓ₁` norm of a vector comprises the sum of the absolute values of its components. This problem will be considered in Chapters [9](#Chp009_417-462_B9780443292385000159.xhtml) and [10](#Chp010_463-518_B9780443292385000160.xhtml).

Regularization is closely related to the task of using priors in Bayesian learning, as we will discuss in Section [3.11](#Chp003_65-117_B9780443292385000093.xhtml#s0090). Finally, note that regularization is not a panacea for facing the problem of overfitting. As a matter of fact, selecting the right set of functions `ℱ` in Eq. [(3.3)](#Chp003_65-117_B9780443292385000093.xhtml#deq3) is the first crucial step. The issue of the complexity of an estimator and the consequences on its “average” performance, as measured over all possible data sets, is discussed in Section [3.9](#Chp003_65-117_B9780443292385000093.xhtml#s0065).
