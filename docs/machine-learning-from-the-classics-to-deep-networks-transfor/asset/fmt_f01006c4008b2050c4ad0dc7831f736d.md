
Similar arguments hold true if, instead of the unconditional model, the classifier guidance rationale is imposed on the class-conditional diffusion model. This can further improve the sample quality compared to that obtained by the class-conditional model alone. In this case, the involved mean values and covariance matrix in Eq. [(19.82)](#Chp019_997-1102_B9780443292385000251.xhtml#deq160) should be replaced by their conditional counterparts, i.e., `μ_θ*(x_t, t, y)` and `Σ_θ*(x_t, t, y)`.

If one starts with the score-based formulation of the diffusion models, and ignoring the notational dependence on `x_0`, the starting point is the conditional distribution,

```
q(x_t|y) = q(x_t)q(y|x_t) / q(y).
```

Taking the gradient of the logarithm of both sides in the previous equation, we get

```
∇_x_t ln q(x_t|y) = ∇_x_t ln q(x_t) + ∇_x_t ln q(y|x_t),  (19.79)
```

where the gradient of `ln q(y)` with respect to `x_t` is zero. Thus, the conditional score function is given in terms of the unconditional one plus a term that depends on the class distribution of the noisy samples, `x_t`.
