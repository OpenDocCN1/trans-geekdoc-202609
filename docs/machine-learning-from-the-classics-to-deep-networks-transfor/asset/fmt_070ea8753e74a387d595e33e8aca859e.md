
# Sparse Analysis Formulation

In the sparse synthesis formulation, one searches for a solution in a union of subspaces that are formed by all possible combinations of *k* columns of the dictionary, `Ψ`. The signal vector lies in one of these subspaces—the one that is spanned by the columns of `Ψ` whose indices lie in the support set (Section [10.2.1](#Chp010_463-518_B9780443292385000160.xhtml#s0020)).

In the sparse analysis approach, things get different. The kick-off point is the sparsity of our original transform $\widetilde{\mathbf{s}} := \Phi^{T}\mathbf{s}$, where `Φ` defines the transformation matrix or analysis operator. Because $\widetilde{\mathbf{s}}$ is assumed to be sparse, there exists an index set $\mathcal{I}$ such that $\forall i \in \mathcal{I}$, $\tilde{s}[i] = 0$. In other words, $\forall i \in \mathcal{I}$, $\boldsymbol{\phi}[i]^{(T)}\mathbf{s} := \langle \boldsymbol{\phi}[i], \mathbf{s} \rangle = 0$, where $\boldsymbol{\phi}[i]$ stands for the *i*th column of `Φ`. Hence, the subspace in which $\mathbf{s}$ resides is the orthogonal complement of the subspace formed by those columns of `Φ` that correspond to a zero in the transform vector $\widetilde{\mathbf{s}}$. Assume, now, that $\text{card}(\mathcal{I}) = C_o$. The signal, $\mathbf{s}$, can be identified by searching on the *orthogonal complements* of the subspaces formed by all possible combinations of $C_o$ columns of `Φ`, that is,

```
⟨ϕ[i], s⟩ = 0,  ∀i ∈ I.
```

The difference between the synthesis and analysis problems is illustrated in [Fig. 10.12](#Chp010_463-518_B9780443292385000160.xhtml#f0065). To facilitate the theoretical treatment of this new setting, the notion of *cosparsity* was introduced in [92].

## Definition 10.2

The cosparsity of a signal $\mathbf{s} \in \mathbb{R}^l$ with respect to a $p \times l$ matrix $\Phi^T$ is defined as

```
C_o := p - ||Φ^T s||_0.
```
