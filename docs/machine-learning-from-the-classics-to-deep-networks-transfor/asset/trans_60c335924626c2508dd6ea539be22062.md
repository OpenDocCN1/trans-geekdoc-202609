# 前言

*机器学习* (ML) 是人工智能 (AI) 的一个子课题，它作为一个统称，是几十年来在不同科学界、以不同名称（如统计学习、统计信号处理、模式识别、自适应信号处理、图像处理与分析、语音识别、系统辨识与控制、数据挖掘与信息检索、计算机视觉和计算学习）被研究和开发的方法演变的结果。这些学科的共同本质在于它们都*从数据中学习*，然后*进行预测*。人们试图通过开发*模型*来从数据中学习其潜在结构和规律性，随后利用该模型提供预测。

为此，开发了许多不同的模型，范围从线性到各种非线性模型。同时也提出了许多不同的方法。一方面是基于优化所采用模型的不同代价函数的技术，其目标是量化从数据中观察到的内容与估计模型预测内容之间的偏差。另一方面是试图显式建模观测数据统计特性的概率方法。

本书的目标是在一个统一框架下探讨机器学习学科，通过展示多年来遵循的主要路径和方法，从经典技术出发，进展到最新技术。作者认为，无论从应用角度还是教学角度，所有这些方法对想要探究该主题奥秘的初学者都是宝贵的。重点在于机器学习算法和方法的研究与分析，而非学习理论本身及相关性能界限等主题。换句话说，重点关注更接近应用层面的方法和算法。
