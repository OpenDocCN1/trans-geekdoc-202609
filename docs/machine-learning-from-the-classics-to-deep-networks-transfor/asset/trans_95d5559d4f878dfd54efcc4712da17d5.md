

### LS 估计量在白高斯噪声下达到 Cramér–Rao 界

Cramér–Rao 下界的概念是在 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中引入的。在那里表明，在*白高斯噪声*假设下，实数的 LS 估计量是*有效的*；即它达到 Cramér–Rao 界。此外，在问题 [3.9](#Chp003_65-117_B9780443292385000093.xhtml) 中表明，如果 **η** 是均值为零、协方差矩阵为 `Σ[η]`![Equation](images/B9780443292385000123/si69.png) 的高斯噪声，则有效估计量由下式给出

```
\widehat{\mathbf{\theta}} = {(X^{T}\Sigma_{\eta}^{- 1}X)}^{- 1}X^{T}\Sigma_{\eta}^{- 1}\mathbf{y},
```
