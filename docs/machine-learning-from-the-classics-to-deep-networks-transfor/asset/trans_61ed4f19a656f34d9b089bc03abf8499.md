
在第 [13.4](#Chp013_635-716_B9780443292385000196.xhtml#s0040) 节中，假设有 *K* 个混合成分（簇）。每个混合成分通过一个均值和精度矩阵未知的高斯 PDF 进行建模，即 `(μ[k], Q[k])`，*k* = 1, 2, …, *K*。反过来，这些参数被视为随机实体，并赋予了先验分布——均值服从高斯 PDF，精度矩阵服从 Wishart 分布。每个混合成分的概率 `P[k]`，*k* = 1, 2, …, *K*，要么被视为常数，在 M 步中进行优化；要么被视为随机变量，并与其关联一个狄利克雷 PDF 先验（问题 [13.7](#Chp013_635-716_B9780443292385000196.xhtml#o0135)）。目标是获得与每个观测点关联的标签的*后验概率*估计，即 `P(k[n]|X)`。在那里，我们通过均场近似求助于变分技术，后验由函数 `q[Z](Z) := q[Z](z[1], …, z[N])` 近似，其中 `z[n]`，*n* = 1, 2, …, *N*，为 0-1 编码向量，在对应特定混合成分（*k*）的位置上置 1，其余元素为零。我们将此类向量称为*独热*向量。通过这种方式，实现了观测点在 *K* 个高斯分布簇中的等效聚类。

前述任务的非参数对应形式表达方式几乎相同，但有一个重要的区别。混合成分的数量 *K* 不再固定为一个有限值；事实上，混合成分的数量允许是*可数无限*的。现在出现两个问题：(a) 如何处理无限数量的簇，以及 (b) 如何处理与无限多概率值相关的先验分布？

为了说明如何处理无限性，请回顾在非参数建模中，数据点的数量仍然是有限的，等于 *N*。因此，无论采用何种模型，混合成分（簇）的数量不可能超过 *N*；后者对应于最坏情况，即每个点都属于不同的簇。因此，尽管理论上可以有无限多个簇，但只有有限子集是*非空*的。因此，我们只需要获得非空混合成分的显式表示即可。

关于第二个问题，可以证明，一种倾向于将数据分配给少量群体的、关于无限多分组的*先验*分布 `P(Z)` 是*中餐馆过程* (CRP)；这是整数分区 [1,22,65] 上的一种分布。

我们将首先陈述从该过程中生成抽样（实现）的算法，然后为那些对相关理论方面感兴趣的读者提供更多细节。

### 13.11.1 中餐馆过程
