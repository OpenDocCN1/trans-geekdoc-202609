
# 10.3 稀疏感知主题的变体

在我们迄今为止的探讨中，我们已经涉及了源自主流理论发展的稀疏感知学习的许多方面。然而，也出现并发展了许多变体，旨在解决具有更特殊结构的问题和/或提出替代方案，这些方案通过满足特定应用的需求，有助于在实践中提升性能。这些变体侧重于公式 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 中的正则化项，和/或拟合误差测度项。再次强调，该方向的研究活动非常活跃，我们的目的仅是强调可能的替代方案，并让读者了解从基础理论中衍生出的各种可能性。

在许多任务中，先验已知目标信号/向量中的非零参数成组出现，并非随机分布在所有可能的位置。一个典型的例子是互联网电话中的回声路径，其中冲动响应的非零系数倾向于聚集在一起（参见 [图 9.5](#Chp009_417-462_B9780443292385000159.xhtml)）。其他“结构化”稀疏的例子可见于 DNA 微阵列、MIMO 信道均衡、传感器网络中的源定位、脑磁图以及神经科学问题（例如，\[1,9,10,60,101\]）。正如机器学习中始终如此，能够将先验信息融入优化过程，只会有助于提升性能，因为估计任务在寻找最优解的过程中得到了外部辅助。

*组 LASSO* \[8,59,97,98,117,122\] 解决的是非零分量先验已知成组出现的任务。未知向量 `θ` 被划分为 `L` 个组，即，

```
θ^(T) = [θ[1]^(T), …, θ[L]^(T)]^(T)
```

每组的大小预先确定为 `s[i]`，`i = 1, 2, …, L`，且满足 `∑_{i=1}^L s_i = l`。回归模型随后可以写为

```
y = Xθ + η = ∑_{i=1}^L X_i θ_i + η
```
