
## 多头注意力机制

一个单独的**Head**，由矩阵集合 (`Q`, `K`, `V`) 定义，提供输入的更新表示并编码相关的上下文信息。这是通过在某些最优计算的子空间中测量输入嵌入投影后的向量相似度来实现的，这些子空间由对应的矩阵集合 (`W`^(`q`), `W`^(`k`), `W`^(`v`)) 决定。

然而，通过使用不同的 `W` 矩阵三元组来获取多个表示（多个查询）是合理的。这类似于 CNN 网络，其中多个不同的核/通道（参见 [第 18.12.1 节](#Chp018_885-995_B978044329238500024X.xhtml)）被应用于输入，每个核提取不同类型的相关性。

现在假设采用了 `h` 组三元组，即 (`W`[`i`]^(`q`), `W`[`i`]^(`k`), `W`[`i`]^(`v`))，`i` = 1, 2, …, `h`。在这种情况下，我们将得到 `h` 组查询/键/值矩阵，即 (`Q`[`i`], `K`[`i`], `V`[`i`])，`i` = 1, 2, …, `h`。由于训练期间所有 `W` 矩阵都是随机初始化的，我们期望得到 `h` 个不同的注意力矩阵（公式 [(19.39)](#Chp019_997-1102_B9780443292385000251.xhtml#deq85)），即：

```
Attention[i] := Attention(Q[i], K[i], V[i]),  i = 1, 2, …, h.
```
