\min_{\mathbf{z}_{n}} \quad \|\mathbf{z}_{n}\|_{0}, \text{s.t.} \quad \|\mathbf{x}_{n} - A\mathbf{z}_{n}\|^{2} < \epsilon, \quad n = 1,2,\ldots,N,

This stage is known as *sparse coding*.

**Stage 2**: This stage is known as the *codebook update*. Having obtained $\mathbf{z}_{n}, n = 1, 2, \ldots, N$ (for fixed *A*), from Stage 1, the goal now is to optimize with respect to the columns of *A*. This is achieved on a *column-by-column* basis. Assume that we currently consider the update of $\mathbf{a}_{k}$; this is carried out so as to minimize the (squared) Frobenius norm, $\|X - AZ\|_{F}^{2}$.
