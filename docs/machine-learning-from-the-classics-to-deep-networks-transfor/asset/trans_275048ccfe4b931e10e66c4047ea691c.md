
关于秩需要多小才能将相应矩阵表征为“低秩”矩阵，可能存在歧义。更严格地说，如果 `r = O(1)`，则称矩阵为低秩，这意味着 `r` 是一个常数，不依赖于 `l`（甚至没有对数依赖）。矩阵补全对于更一般的秩情况也是可能的，此时不再使用 [(20.121)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq183) 中温和的连贯性质，而是调用非连贯性和强非连贯性质 [33,35,87,151] 以获得类似的理论保证。这些替代方案的详细阐述超出了本书的范围。事实上，[定理 20.1](#Chp020_1103-1179_B9780443292385000263.xhtml#enun0085) 体现了矩阵补全任务的本质：以高概率，核范数最小化能够无误差地恢复低秩矩阵 `M` 的所有条目。更重要的是，凸松弛问题所需的条目数 `N` 仅比信息论极限大一个对数因子，如前所述，该极限等于 `C_0 * l * ln(l)`。此外，类似于压缩感知，只要将公式 [(20.120)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq182) 和 [(20.123)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq185) 中的要求 `M̂(i, j) = M(i, j)` 替换为 `||M̂(i, j) − M(i, j)||_2 ≤ ϵ` [34]，在噪声存在下的鲁棒矩阵补全也是可能的。此外，矩阵补全的概念也已扩展到张量（例如，[77,165]）。

### 20.10.2 鲁棒 PCA
