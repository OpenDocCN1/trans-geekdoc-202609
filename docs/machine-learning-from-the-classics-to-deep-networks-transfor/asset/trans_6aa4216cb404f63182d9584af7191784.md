
编码器的输出 **h**[*i*] 和 **h**[*j*] 被送入模块 *g*[**ϕ**](·) 中。由于此类学习的目标是强制相似性（或不相似性），人们可能会疑惑为何还需要这个额外的模块。人们本可以仅基于 **h**[*i*] 和 **h**[*j*] 来训练编码器的参数 **θ**。然而，事实证明引入 *g*[**ϕ**](·) 能进一步改善学到的表示。这个额外的网络也被称为*投影*头，它将 **h**[*i*] 和 **h**[*j*] 这一组向量非线性地映射到一组新的向量，即 **z**[*i*] 和 **z**[*j*]，后者通常位于与 **h**[*i*], **h**[*j*] 不同的子空间中。

在文献 [35] 中，使用 `ResNet-50` 网络 ([71]) 替代了编码器网络，并使用一个 2 层 MLP 投影头将表示投影到 128 维的潜在空间中。参考第 19.6.2 节中的通用方案，请注意，在这种情况下，输入集合 𝒳 和输出集合 ℋ 分别是单例，即 *N* = 1。编码器的输入由图像（而非图像块）组成，编码器相应地输出 2048 维向量。
