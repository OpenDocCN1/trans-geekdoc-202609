
# 19.2 无监督特征学习与深度生成模型

在第 [18](#Chp018_885-995_B978044329238500024X.xhtml) 章中，我们的重点是通过神经网络架构进行**监督学习**。机器学习的另一个主要方向是**无监督学习**，在这种学习中，必须从输入数据中“学习”并揭示隐藏的潜在依赖关系和结构。聚类，正如第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章所介绍的（另见 [181] 以获取详尽介绍），是通过无标签数据进行学习的主要途径。另一条途径是学习显式的概率依赖关系，其最终目标是估计概率分布，这正是第 [15](#Chp015_755-803_B9780443292385000214.xhtml) 章和第 [16](#Chp016_805-853_B9780443292385000226.xhtml) 章的重点。

另一个无标签样本至关重要的方向是学习输入数据的高效表示。事实上，特征学习是数据表示的一个侧面。`CNN` 中位于全连接网络部分之前的卷积层专门用于实现这一目标，即获得输入数据的高效且信息丰富的表示。然而，在 `CNN` 的框架内，这是在特定学习任务的背景下进行的；也就是说，训练过程中也会考虑输出标签，以达到服务于当前任务需求的最优表示。

在本节中，讨论的背景是学习独立于特定目标任务的表示；目标是仅利用输入数据提取此类信息。这种关注的原因有两方面。首先，学习输入数据的模型表示随后可用于不同的任务，以促进训练。有时，这也被称为 `pretraining`（预训练），即利用无标签数据学习的参数可作为另一个监督学习参数的初始估计。当标记样本的数量不够大时，这很有用（例如，参见 [125] 的讨论）。值得注意的是，这种预训练原理具有历史意义，因为它导致了神经网络的复兴，稍后将对此进行讨论 [80]。

目前备受关注的另一条途径是利用此类学习到的表示来 `generate`（生成）新数据；回顾第 [18.7](#Chp018_885-995_B978044329238500024X.xhtml) 节的讨论。此类技术 `not`（不）一定要 `explicitly`（显式地）学习底层概率分布，但它们获取了必要的知识，从而能够根据“解释”数据的分布来抽取样本。

## 19.2.1 受限玻尔兹曼机

`restricted Boltzmann machine`（受限玻尔兹曼机，RBM）是玻尔兹曼机这一更一般类别的一种特殊类型，后者在第 [15](#Chp015_755-803_B9780443292385000214.xhtml) 章 [1,167] 中已介绍。[图 19.1](#Chp019_997-1102_B9780443292385000251.xhtml#f0010) 展示了对应于 RBM 的概率图模型。同一层的节点之间没有连接。此外，上层包含对应隐变量的节点，下层由可见节点组成。也就是说，观测值仅施加于下层节点。深度 RBM 可以通过将一个 RBM 堆叠在另一个之上来构建。

![Figure 19.1 An RBM is an undirected graphical model with no connections among nodes of the same layer. The lower level comprises visible nodes and the upper layer consists of hidden nodes only.](images/B9780443292385000251/gr001.jpg)

[图 19.1](#Chp019_997-1102_B9780443292385000251.xhtml#cf0335) RBM 是一种无向图模型，同一层的节点之间没有连接。下层包含可见节点，上层仅包含隐节点。

遵循玻尔兹曼机的一般定义，所涉及随机变量的联合分布形式为

```
P(v_1,...,v_J,h_1,...,h_I) = 1/Z exp( - E(v,h) )
```

其中，我们对 `J` 个可见（`v[j]`，`j` = 1, 2, ..., `J`）和 `I` 个隐（`h[i]`，`i` = 1, 2, ..., `I`）随机变量使用了不同的符号。`energy`（能量）是用一组未知参数来定义的。^([^(127)](#fn127))
