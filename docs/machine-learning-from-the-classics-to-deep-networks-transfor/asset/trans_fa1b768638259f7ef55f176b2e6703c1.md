
开发高效 MKL 方案的早期尝试之一见于文献 [65]，其中作者考虑了核矩阵的线性组合，即 $K = \sum_{m = 1}^{M}a_{m}K_{m}$。

由于我们要求新的核矩阵必须是正定的，因此在优化任务中施加一些额外约束是合理的。例如，可以采用通用约束 $K \succeq 0$（该不等式表示半正定性），或更严格的约束，例如对所有 $m = 1, \dots, M$ 都有 $a_{m} > 0$。此外，还需要对最终核矩阵的范数进行约束。因此，MKL SVM 任务可以表述为

```
minimize with respect to K ω_C(K), subject to K ⪰ 0, trace{K} ≤ c,
```

其中 $\omega_{C}(K)$ 是对偶 SVM 任务的解，见公式 (11.86)–(11.88)，可以写成更紧凑的形式：

$$
\omega_{C}(K) = \max_{\mathbf{\lambda}}\left\{ \mathbf{\lambda}^{T}\mathbf{1} - \frac{1}{2}\mathbf{\lambda}^{T}G(K)\mathbf{\lambda}: 0 \leqslant \lambda_{i} \leqslant C, \mathbf{\lambda}^{T}\mathbf{y} = 0 \right\},
$$

$G(K)$ 的每个元素由 $[G(K)]_{i,j} = [K]_{i,j}y_{i}y_{j}$ 给出；$\mathbf{\lambda}$ 表示拉格朗日乘子向量，$\mathbf{1}$ 表示所有元素均等于 1 的向量。文献 [65] 展示了如何将 (11.92) 转化为半定规划 (SDP) 优化任务并相应求解。
