
# 让我们应用 Robbins–Monro 算法来求解最优 MSE 线性估计器，前提是协方差矩阵和互相关向量未知。

我们知道解对应于代价函数梯度的根，其形式可以写为（回顾第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章的正交定理和公式 [(5.8)](#Chp005_177-248_B9780443292385000111.xhtml#deq11)）：

`Σ[x]θ − p = 𝔼 [x(x^(T)θ − y)] = 0.`

![Equation](images/B9780443292385000111/si150.png)

给定观测训练序列 `(y[n], x[n])`，假设它们是从 `(y, x)` 的联合分布中独立同分布（i.i.d.）抽取的，Robbins–Monro 算法变为：

`θ[n] = θ[n − 1] + μ[n]x[n](y[n] − x[n]^(T)θ[n − 1]),` (5.34)

![Equation](images/B9780443292385000111/si153.png)

前一个方程是通过后一个方程去掉期望运算并使用依赖于迭代的步长而得到的。观察公式 [(5.34)](#Chp005_177-248_B9780443292385000111.xhtml#deq61) 中的迭代与*时间更新*一致；时间现在已显式地进入了场景。这促使我们开始思考如何适当修改此类方案以跟踪时变环境。像公式 [(5.34)](#Chp005_177-248_B9780443292385000111.xhtml#deq61) 这样的算法，是由通用梯度下降公式通过用相应的瞬时观测替换期望而得出的，也称为*随机梯度下降方案*。
