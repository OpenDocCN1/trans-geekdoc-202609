
In other words, `λ₁₂ = 1` and `λ₂₁ = 0.8`. The two classes are considered equiprobable. Derive the threshold value `xᵣ`, which partitions the feature space `ℝ` into the two regions `ℛ₁`, `ℛ₂` in which we decide in favor of class `ω₁` and `ω₂`, respectively. What is the value of the threshold when the Bayesian classifier is used instead?

Solution: According to the average risk rule, the region for which we decide in favor of class `ω₁` is given by

```
ℛ₁: λ₁₂ * (1/2) * p(x|ω₁) > λ₂₁ * (1/2) * p(x|ω₂),
```

and the respective threshold value `xᵣ` is computed from the equation

```
exp(-xᵣ²/2) = 0.8 * exp(-(xᵣ - 1)²/2),
```

which, after taking the logarithm and solving the respective equation, trivially results in

```
xᵣ = (1/2)(1 - 2 ln 0.8).
```

The threshold for the Bayesian classifier results if we set `λ₂₁ = 1`, which gives

```
x_B = 1/2.
```
