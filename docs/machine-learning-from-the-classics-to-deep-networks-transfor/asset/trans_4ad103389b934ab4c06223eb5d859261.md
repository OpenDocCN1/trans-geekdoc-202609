

## 多项式分布

这是二项分布的一种推广，适用于每次实验的结果不再是二元的，而是可以取 `K` 个可能值之一的情况。例如，不再是抛硬币，而是投掷一个具有 `K` 个面的骰子。每个可能的 `K` 个结果发生的概率分别为 `P[1]`、`P[2]`、…、`P[K]`，我们记为

**P** = `[P[1], P[2], …, P[K]]^(T)`。

进行 `n` 次实验后，假设面 `x = 1`、`x = 2`、…、`x = K` 分别出现了 `x[1]`、`x[2]`、…、`x[K]` 次。我们称随机（离散值）向量

**x** = `[x[1], x[2], …, x[K]]^(T)`，
