

## 17.4 粒子滤波

在第 [4.10](#Chp004_119-175_B978044329238500010X.xhtml) 节中，扩展卡尔曼滤波（EKF）被讨论为将卡尔曼滤波推广到非线性模型的一种可能性。接下来要讨论的粒子滤波是 EKF 的一种强大替代技术。相关的概率密度函数（PDF）由*离散随机测度*近似。其基础理论是序贯重要性采样（SIS）；事实上，粒子滤波就是 SIS 的一个实例。

现在让我们考虑公式 (17.12) 和 (17.13) 所示一般形式的状态空间模型。从这些方程的具体形式来看（对于更熟悉的读者，还可从此类模型的贝叶斯网络性质来看），我们可以写出

```
p(x[n]|x[1:n−1], y[1:n−1]) = p(x[n]|x[n−1])
```

和

```
p(y[n]|x[1:n], y[1:n−1]) = p(y[n]|x[n])。
```

我们的出发点是对 `p(x[1:n]|y[1:n])` 进行*序贯*估计；对 `p(x[n]|y[1:n])` 的估计（这是我们的主要目标）将作为副产品获得。注意 [16]
