
设 `t` 和 `x` 分别为输入相应编码器的文本和图像表示。两个编码器的输出记为 `z_t = g_ϕ(t)` 和 `z_i = f_ξ(x)`，它们具有相同的维度。参数 `ϕ` 和 `ξ` 分别对两个编码器进行参数化，根据对比损失原理进行联合优化，该原理已在[第 19.6.5 节](#Chp019_997-1102_B9780443292385000251.xhtml#s0215)中讨论过。换句话说，在训练期间，如果字幕中的描述与图像内容匹配，则根据对比损失函数使两个编码器的编码输出向量更加相似；如果不匹配，则使其更加不相似。相似度通过归一化内积函数来量化。例如，假设一幅图像包含一只猫，并被编码为 `z_i`。对于图像内容的描述，我们给出两个字幕。一个是“A cat sitting”（编码为 `z_t`），另一个是“A dog running”（编码为 `z_t'`）。那么，我们期望训练后，

```
\frac{\mathbf{z}_{t}^{T}}{||\mathbf{z}_{t}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||} > \frac{{\mathbf{z}_{t}^{\prime}}^{T}}{||\mathbf{z}_{t}^{\prime}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||},
```

其中 `|| ⋅ ||` 表示欧几里得范数。关于两个编码器网络的详细信息见文献 [149]。

在推理阶段，数据集中的每幅图像都被视为一个*单独的类别*。给定一个文本描述/字幕，对其进行编码，所得向量表示与数据集中图像的编码表示进行比较。根据相似度度量（归一化内积）的最大值选择一幅图像。在计算机视觉中，这种将示例视为单独类别的分类类型称为单样本分类。^([^(149)](#fn149))
