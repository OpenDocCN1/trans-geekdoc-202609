### 备注 11.3

*   除了线性 `ϵ` 不敏感损失函数外，类似的分析对二次 `ϵ` 不敏感损失函数和 Huber 损失函数同样适用（例如，[28]）。结果表明，使用 Huber 损失函数会导致更多的支持向量。请注意，大量的支持向量会增加复杂度，因为涉及更多的核函数计算。
*   **稀疏性与 ϵ-不敏感损失函数**：注意，公式 [(11.36)](#Chp011_519-582_B9780443292385000172.xhtml#deq109) 与公式 [(11.18)](#Chp011_519-582_B9780443292385000172.xhtml#deq69) 具有完全相同的形式。然而，在前一种情况下，展开式是一个使用 `N[s] < N` 的稀疏展开，且在实践中通常有 `N[s] ≪ N`。由此引出的一个显而易见的问题是，`ϵ` 不敏感损失函数与第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章讨论的促进稀疏性的方法之间是否存在“隐含”联系。有趣的是，答案是肯定的 [47]。假设公式 [(11.23)](#Chp011_519-582_B9780443292385000172.xhtml#deq78) 中的未知函数 `g` 位于一个 RKHS 中，并利用再生核定理，它可以用 RKHS 中的展开式来近似，未知参数通过最小化以下式子来估计：

```
L(θ) = 1/2 || y(·) - Σ_{n=1}^{N} θ_n κ(·, x_n) ||_H^2 + ε Σ_{n=1}^{N} |θ_n|.
```

*   这类似于我们对核岭回归所做的处理，显著的例外在于正则化项涉及参数的 `ℓ[1]` 范数。范数 `||·||_H` 表示与 RKHS 相关的范数。详细阐述该范数可以表明，在无噪声情况下，最小化任务与 SVR 任务变得完全相同。
