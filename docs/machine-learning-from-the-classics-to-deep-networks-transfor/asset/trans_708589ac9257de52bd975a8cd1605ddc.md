
## 18.5 选择损失函数

其中 `j` 和 `k` 遍历第 `r` 层中的所有参数，`j'` 和 `k'` 遍历与第 `r'` 层相关的所有参数，适用于所有 `r` 和 `r'` 的值。为此，不同的论文采用了各种简化假设（另见习题 [18.5](#Chp018_885-995_B978044329238500024X.xhtml#o0040) 和 [18.6](#Chp018_885-995_B978044329238500024X.xhtml#o0045)）。

文献 [43] 提出了一种基于牛顿法的算法，称为 `quickprop` 算法。这是一种启发式方法，它将突触权重视为准独立的。然后，它通过二次多项式将误差曲面作为每个权重的函数进行近似。如果该多项式在一个合理的值处取得最小值，则在迭代中将其用作更新值；否则，将动用多种启发式规则。所得更新规则的常见公式由下式给出：

```
\Delta\theta_{ij}^{r}(\text{new}) = \begin{cases} 
a_{ij}^{r}(\text{new})\Delta\theta_{ij}^{r}(\text{old}), & \text{if } \Delta\theta_{ij}^{r}(\text{old}) \neq 0, \\
- \mu\frac{\partial J(\text{new})}{\partial\theta_{ij}^{r}}, & \text{if } \Delta\theta_{ij}^{r}(\text{old}) = 0,
\end{cases}
```
(18.38)

其中

```
a_{ij}^{r}(\text{new}) = \min\left\{ \frac{\frac{\partial J(\text{new})}{\partial\theta_{ij}^{r}}}{\frac{\partial J(\text{old})}{\partial\theta_{ij}^{r}} - \frac{\partial J(\text{new})}{\partial\theta_{ij}^{r}}}, a_{\text{max}}^{r} \right\},
```
(18.39)

通常使用的参数典型值为 `0.01 ≤ μ ≤ 0.6`，且 `a_max^r ≈ 1.75`。文献 [165] 提出了一种与 quickprop 精神相似的算法。

在实践中，当涉及大型网络和数据集时，更简单的方法（如精心调整的梯度下降方案及其变体，例如第 [18.4.2](#Chp018_885-995_B978044329238500024X.xhtml#s0055) 节之前讨论的那些）似乎效果更好，且目前是主流趋势。更复杂的二阶技术可以在较小的网络中提供改进，特别是在回归任务的背景下。
