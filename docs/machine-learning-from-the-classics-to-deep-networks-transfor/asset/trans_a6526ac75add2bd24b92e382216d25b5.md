
其中 `α ∈ [0, 1]` 是用户定义的动量项。由于参数 `ξ` 不是通过反向传播方案更新的，因此每个迭代步骤计算出的梯度仅在学生分支中传播。这由 "sg" 符号表示，该符号指示 "stop gradient"（停止梯度）传播操作。经验表明，使用这种训练策略，BYOL 避免了坍缩解。

在文献 [66] 中，使用了不同的卷积残差网络来实现编码器。对于宽度乘数为 1 的 ResNet-50 ([71]) 情况，编码输出 `h` 是一个 2048 维向量。然后，表示向量通过投影网络 `g` 投影到一个低维空间。后者实现为一个多层感知机，包含一个具有 4096 个节点的线性层，随后是批量归一化和 ReLU 激活函数，最后一层是一个具有 256 个输出节点的线性层。网络 `q` 具有与 `g` 相同的架构。

请注意，BYOL 在两个分支之间引入了两种类型的*不对称性*。一种是在线分支和目标分支之间的架构不对称性，这是由于上层分支中存在预测器。另一种来自于每个分支中使用的不同参数更新机制。这些不对称性有助于克服坍缩解。

避免坍缩解的上述基本原理衍生出许多变体，它们采用不同的损失目标和/或不同的架构，例如文献 [10] 中提出的所谓 *data2vec* 方案。文献 [145] 对 EMA 进行了研究，结果表明该算法具有某些稳定性质。此外，该文献还研究并比较了许多围绕 EMA 方案演进的方法。

### SimSIAM

在文献 [34] 中，提出了所谓的*简单孪生网络*。它保留了 BYOL 中两个分支的主要思想，但不是采用 EMA 算法来更新目标分支，而是强制两个分支共享参数。然而，在反向传播算法的每次迭代中，会采用停止梯度操作来冻结其中一个分支中参数的适应，并将相应的输出视为常量。这种简单的修改被证明有助于增强对坍缩现象的鲁棒性。

在文献 [182] 中，尝试理解 BYOL 和 SimSIAM 方案关于其对坍缩鲁棒性的动力学特性。

### DINO

*无标签蒸馏* (DINO) 算法在文献 [32] 中提出，它是 BYOL 的一个变体。保留了 EMA 方案。区别在于每个分支的输出被*离散化*为一个 `K` 维向量，并且两个分支的输出都通过我们熟悉的 softmax 操作转换为 `K` 个概率。然后，通过交叉熵损失函数量化两个分支之间的相似性。

DINO 方案是该主题一系列研究的演进，参见例如 [30]、[31]。其基本思想是将生成的输出表示离散化，然后求助于聚类论证。例如，在文献 [31] 中，提出了*多视角间的分配交换* (SwAV) 方案。两个分支的输出被离散化，形成一个包含 `K` 个原型的代码本，然后在参数学习的*同时*执行聚类操作。通过鼓励两个分支中的聚类分配相似来实现分支间的相似性。通过采用适当的正则化来促进形成的聚类尽可能均匀地分布，从而抑制坍缩。

### 19.6.7 基于相关性的技术

我们迄今为止所讨论的所有技术的主要思想，都是以某种方式（取决于具体方法）强制来自两个不同分支的数据之间的相似性/非相似性。在本小节的最后一类中，相关性的概念被用作相似性的度量。这导致了略微不同的任务公式化需求，我们将此类方案视为一个不同的类别。

我们讨论的舞台是典型相关分析 (CCA)，其在 [20.4 节](#Chp020_1103-1179_B9780443292385000263.xhtml) 中有更详细的论述。CCA 背后的主要思想是：如果涉及两组随机变量（两个随机向量），它们的相关性值取决于随机向量所表示的坐标系。CCA 的目标是为每组变量寻找一对线性变换，使得变换后的变量最大化相关。CCA 的主要思想已被推广为涉及非线性变换。例如，在文献 [5] 中，目标变为*联合*学习两个网络的参数，使其输出最大化相关。

### Barlow Twins

这是该系列方案的一个典型例子。*Barlow Twins* 架构 [202] 遵循 [图 19.19](#Chp019_997-1102_B9780443292385000251.xhtml#f0100) 中那样两个相同（参数共享）分支的理念。然而，它采用基于相关性的相似性强制损失，而不是对比损失。正如我们将看到的，这种损失函数具有避免坍缩的“内在”特性。

为简化符号，分别用 `z` 和 `z'` 表示两个分支的输出。为了形成相对于共享参数集 `θ`、`ϕ` 待最小化的损失函数，对一个输入样本的小批量求和，以计算相应的归一化互相关矩阵的元素，即：

```
C_{i,j} = \frac{\sum_{n}z_{ni}z_{nj}^{\prime}}{\sqrt{\sum_{n}z_{ni}^{2}}\sqrt{\sum_{n}z_{nj}^{\prime 2}}},
```
