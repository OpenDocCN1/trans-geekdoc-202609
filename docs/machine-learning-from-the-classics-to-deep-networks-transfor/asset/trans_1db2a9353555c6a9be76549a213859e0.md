
因此，如果从分布 `p(x)` 生成样本 `x[n]`，`n = 1, 2, …, N`，则使用蒙特卡洛技术提供了一种近似公式 [(14.1)](#Chp014_717-754_B9780443292385000202.xhtml#deq1) 中积分的方法，并具有以下良好特性：(a) 近似误差按 `1/sqrt(N)` 递减；(b) 使用 `N` 个样本获得的估计值是真值的无偏估计；(c) 收敛速率*独立于*维数 `l`。后一特性与基于确定性数值积分的方法形成对比，后者通常具有随着维数增加而减慢的收敛性。在蒙特卡洛技术中，如果对获得的精度不满意，只需生成更多样本即可。

现在的关键点变成了开发从 `p(x)` 生成独立同分布（i.i.d.）样本的技术。这并非易事，尤其是对于高维空间。请注意，一旦有了从 `p(x)` 抽取的 i.i.d. 样本，公式 [(14.2)](#Chp014_717-754_B9780443292385000202.xhtml#deq2) 中估计器达到一定精度就与维数无关。另一方面，随着维数增加，抽取典型的 `p(x)` 的 i.i.d. 样本变得更难。我们稍后将回到这一点。在后续内容中，我们将重点介绍实现上述目标的一些基本方向。

### 14.2.1 随机数生成

随机数生成既可以作为实验的结果实现，也可以通过计算机实现。例如，抛掷一枚均匀硬币可以生成 0（正面）或 1（反面）的随机序列。另一个例子是对应于放射性发射间距的数字序列；这种实验生成服从指数分布的样本序列。然而，这些方法实用价值不大，重点一直放在通过计算机使用*伪随机数生成器*生成样本的技术上。此类方法的核心在于保证生成一个*整数*序列 `z[i]` 的算法，这些整数近似服从实轴上某一区间内的*均匀分布*。在后续内容中，服从任意分布的随机数/向量的生成是通过各种方法*间接*获得的，每种方法都有其优缺点。在区间 `(0, M)` 内生成整数的路径遵循一般递归公式：

```
z[i] = g(z[i−1], …, z[i−m]) mod M
```

其中 `g` 是一个依赖于先前生成的 `m` 个样本的函数，`mod` 表示取模运算；即 `z[i]` 是 `g(z[i−1], …, z[i−m])` 除以 `M` 的余数。较简单的形式是线性版本：

```
z[i] = α z[i−1] mod M,  z[0] = 1,  i ≥ 1
```

(14.5)

其中 `M` 是一个大素数，`α` 是一个整数。递归 [(14.5)](#Chp014_717-754_B9780443292385000202.xhtml#deq7) 生成 1 到 `M−1` 之间的数字序列。该方法称为*线性同余生成器*或 Lehmer 算法 [20]。
