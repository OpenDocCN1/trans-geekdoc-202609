

## 17.3 卡尔曼滤波与粒子滤波

粒子滤波是序贯蒙特卡洛方法的一个实例。它是一种诞生于 20 世纪 90 年代的技术，首次见于文献 [19]，旨在解决状态空间建模背景下更一般的非线性和非高斯场景中的估计任务。“粒子滤波”这一术语由文献 [3] 提出，尽管“粒子”一词已在文献 [27] 中使用过。

隐马尔可夫模型（HMM）在 16.4 节中讨论，卡尔曼滤波在 4 章中介绍，它们都是状态空间（状态-观测）建模的特殊类型。前者处理离散状态（隐）变量的情况，后者处理连续情况，尽管仅限于线性和高斯这一非常特殊的场景。在粒子滤波中，关注点转移到了以下形式的模型：

其中 `f_n` 和 `h_n` 通常是非线性（向量）函数，`η_n` 和 `v_n` 是噪声序列，`x_n` 和 `y_n` 的维度可以不同。随机向量 `x_n` 是（隐）状态向量，`y_n` 对应观测值。实践中有两个感兴趣的推断任务。

**滤波**：给定时间索引集 `{1, 2, …, n}` 内的观测集合 `y_{1:n}`，计算

`p(x_n | y_{1:n})`。

**平滑**：给定时间索引集 `{1, 2, …, N}` 内的观测集合 `y_{1:N}`，计算

`p(x_n | y_{1:N}), 1 ≤ n ≤ N`。
