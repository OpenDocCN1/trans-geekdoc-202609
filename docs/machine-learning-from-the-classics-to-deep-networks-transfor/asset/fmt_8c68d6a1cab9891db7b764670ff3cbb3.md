
**Backward prediction**: The vector `b[m] = Σ[m]^(−1) J[m] r[m]` has an interesting physical interpretation: it is the MSE-optimal backward predictor of order `m`. That is, it is the linear filter which optimally estimates/predicts the value of `u[n − m]` given the values of `u[n − m + 1]`, `u[n − m + 2]`, …, `u[n]`. Thus, in order to design the optimal backward predictor of order `m`, the desired response must be

`d[n] = u[n − m]`

and from the respective normal equations we get

```
b_m = Σ_m^(−1) [ E[u_n u_(n−m)*] ; E[u_(n−1) u_(n−m)*] ; ⋮ ; E[u_(n−m+1) u_(n−m)*] ] = Σ_m^(−1) J_m r_m
```
(4.68)

Hence, the MSE-optimal backward predictor coincides with `b[m]`, i.e.,

Moreover, the corresponding minimum MSE, adapting Eq. [(4.19)](#Chp004_119-175_B978044329238500010X.xhtml#deq28) to our current needs, is equal to

`J(b[m]) = r(0) − r[m]^(H) J[m] Σ[m]^(−1) J[m] r[m] = α[m]^(b)`
