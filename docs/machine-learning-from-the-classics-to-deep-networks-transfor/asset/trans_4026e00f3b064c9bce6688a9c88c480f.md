
*p*(**y**|ℳ[*i*]) ≈ *p*(**y**|ℳ[*i*], *θ̂*[*MAP*])*p*(*θ̂*[*MAP*]|ℳ[*i*])*Δ**θ*[*θ*|*y*].

![Equation](images/B9780443292385000184/si122.png) (12.32)

为了更好地理解公式 [(12.32)](#Chp012_583-634_B9780443292385000184.xhtml#deq42) 中涉及的各个因子，让我们还假设先验 PDF 是（近似）均匀的，其宽度等于 Δ*θ*。那么公式 [(12.32)](#Chp012_583-634_B9780443292385000184.xhtml#deq42) 可重写为

```
$p(\mathbf{y}|\mathcal{M}_{i}) \approx p(\mathbf{y}|\mathcal{M}_{i},{\widehat{\theta}}_{MAP})\frac{\Delta\theta_{\theta|y}}{\Delta\theta}.$
```

![Equation](images/B9780443292385000184/si123.png) (12.33)

公式 [(12.33)](#Chp012_583-634_B9780443292385000184.xhtml#deq43) 右侧乘积中的第一个因子与似然函数在其最优值处重合，因为对于这种均匀先验的情况，*θ̂*[MAP] = *θ̂*[ML]。换句话说，该因子为我们提供了模型 ℳ[*i*] 在给定观测集上所能达到的最佳拟合。然而，现在与 ML 方法相反，证据函数还取决于第二个因子，$\frac{\Delta\theta_{\theta|y}}{\Delta\theta}$。正如文献 [13,27,28] 所指出的，这一项解释了模型的复杂度，并因显而易见的原因被称为奥卡姆因子。让我们遵循文献 [28] 中给出的推理，对此进行更详细的阐述。
