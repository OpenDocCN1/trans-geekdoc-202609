
相应的几何结构如[图 14.5](#Chp014_717-754_B9780443292385000202.xhtml#f0030)B所示。目标是在区间 `[0, c*q*(x)]` 内绘制点，然后仅保留位于曲面 `u = ϕ(x)` 下方区域内的那些点。以下算法可完成此任务。

## 算法 14.2：拒绝采样

*   **对于** `i = 1, 2, …, N`，**执行**
    1.  采样 `x[i] ∼ q(x)`
    2.  采样 `u[i] ∼ 𝒰(0, c*q(x[i]))`
    3.  若满足以下条件则保留样本
        *   `u[i] ≤ ϕ(x[i])`
*   **结束循环**

接受点 `x` 的概率由下式给出：

```
Prob{ u ≤ ϕ(x) } = (1 / (c*q(x))) * ϕ(x)
```

而对所有可能的 `x` 值求和，接受样本的总概率等于

```
Prob{ acceptance } = (1/c) ∫ (ϕ(x)/q(x)) q(x) dx = (1/c) ∫ ϕ(x) dx
```

因此，如果 `c` 取较大值，最终保留的点只占一小部分。为了得到一个实用的算法，必须选择 `c*q(x)` 使其能很好地拟合 `ϕ(x)`。[图 14.6](#Chp014_717-754_B9780443292385000202.xhtml#f0035)A 是一个糟糕选择的示例，而[图 14.6](#Chp014_717-754_B9780443292385000202.xhtml#f0035)B 对应一个良好的示例。这就是拒绝采样*无法随维度良好扩展*的原因之一。在高维空间中，为保证 `c*q(x) ≥ ϕ(x)`，可能不得不选择一个过大的 `c` 值（问题 [14.5](#Chp014_717-754_B9780443292385000202.xhtml#o0030)）。
