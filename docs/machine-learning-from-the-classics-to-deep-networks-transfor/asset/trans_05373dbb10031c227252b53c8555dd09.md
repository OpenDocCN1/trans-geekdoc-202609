

### ℓ₀ 范数最小化器

现在我们将注意力转向 ℓ₀ 范数（再次指出，这属于对范数定义的滥用），并将稀疏性作为我们获取解的新旗帜。现在的任务变为

```
min_{θ ∈ ℝˡ} ||θ||₀, s.t. xₙᵀθ = yₙ, n = 1,2,…,N,
```

即从位于所有可能解所构成的平面上的所有点中，找到*最稀疏*的那个，也就是非零元素个数最少的那个。事实上，这种方法符合*奥卡姆剃刀*原则的精神——它对应着能够解释所获得观测值的最少参数个数。现在提出的问题是：

*   该问题的解是否唯一，以及在什么条件下唯一？
*   能否在现实的时间内以足够低的复杂度获得解？

我们将第一个问题的答案推迟到后面讨论。至于第二个问题，消息不太好。在一组线性约束下最小化 ℓ₀ 范数是一项组合性质的任务，事实上，该问题通常是 NP-hard 的 [72]。解决该问题的方法是考虑 `θ` 中所有可能的零元素组合，移除公式 [(9.17)](#Chp009_417-462_B9780443292385000159.xhtml#deq27) 中 `X` 相应的列，并检查方程组是否得到满足；保留非零元素个数最少的那些作为解。这种搜索技术表现出的复杂度与 `l` 呈指数级依赖关系。[图 9.7](#Chp009_417-462_B9780443292385000159.xhtml#f0045)A 说明了单观测（约束）情况下，构成最小化 ℓ₀ 范数解集的两个点（(1.5, 0) 和 (0, 1)）。
