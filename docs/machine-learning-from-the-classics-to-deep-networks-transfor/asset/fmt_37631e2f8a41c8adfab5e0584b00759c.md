
## 1. Select an encoder (also called the backbone)

Select an encoder (also called the backbone) to map the inputs, `x[n]`, to a corresponding set of encoder output vectors, `h[n]`, i.e.,

```
x[n] ↦ h[n] = f[θ](x[n])
```

Note that the equivalent (vector) mapping function, which the encoder implements, is parameterized in terms of a set of parameters, `θ`. It is very common that the input vectors first undergo another transformation prior to the presentation to the encoder. For example, recall that in BERT some of the input tokens are masked, which is a type of transformation. Thus, in a more general setting, we can write

```
x_n ⟼ x̃_n ⟼ h_n = f_θ(x̃_n), n = 1,2,...,N.
```

## 2. Collecting transformed inputs

Collecting all the transformed inputs together in a set, `X̃ = {x̃_1, x̃_2, ..., x̃_N}`, we can compactly write

```
H = f_θ(X̃),
```

where `H = {h[1], h[2], ..., h[N]}`. This action is schematically illustrated in the upper branch of [Fig. 19.16](#Chp019_997-1102_B9780443292385000251.xhtml#f0085).
