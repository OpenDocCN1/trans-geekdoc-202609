
# 无监督学习的类型

## 聚类

最重要的无监督学习类型之一是**聚类**。任何聚类任务的目标都是揭示数据集中点的分组方式，假设存在这样的群组结构。例如，给定一组报纸文章，可能希望根据其内容的相似程度将它们分组。事实上，任何聚类算法的核心都在于**相似性**的概念，因为属于同一组（簇）的模式被假定比属于不同簇的模式更相似。

最经典的聚类方案之一——即所谓的 **k-means 聚类**，将在第 [12.6.1](#Chp012_583-634_B9780443292385000184.xhtml) 节中介绍和讨论。然而，聚类并非本书的主要主题，感兴趣的读者可参考更专业的文献（如 [14,15]）。

## 降维

另一种无监督学习类型是**降维**。其目标同样是揭示数据的特定结构，但这种结构的性质不同于分组。例如，虽然数据可能表示在高维空间中，但它们可能分布在一个低维子流形或子空间周围。此类方法在机器学习中对于压缩表示或降低计算复杂度非常重要。降维方法将在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章中详细讨论。

## 概率分布估计

**概率分布估计**也可视为无监督学习的一个特例。概率建模将在第 [12](#Chp012_583-634_B9780443292385000184.xhtml)、[13](#Chp013_635-716_B9780443292385000196.xhtml)、[15](#Chp015_755-803_B9780443292385000214.xhtml) 和 [16](#Chp016_805-853_B9780443292385000226.xhtml) 章中详细讨论。

## 自监督学习

**自监督学习**（SSL）是另一类算法，其中没有标记数据可用，而是从无标签示例中**构建**目标值。因此，可以将自监督学习视为介于监督学习和无监督学习之间的一类学习方法。近年来，自监督方法作为利用网络上海量无标签数据及各类数据集中数据的一种途径，引起了极大的关注。

典型的自监督学习任务思路是首先通过无标签数据将网络作为编码器进行**预训练**。这一阶段称为**预文本**任务。随后，该编码器可用作不同任务的特征生成器，在这些任务中仅存在少量标记数据。这一阶段称为**下游**任务，并使用可用的标记示例以**监督**方式进行参数微调。自监督学习将在第 [19](#Chp019_997-1102_B9780443292385000251.xhtml) 章中讨论。

## 半监督学习

**半监督学习**是另一类介于监督和无监督学习之间的方法。在半监督学习中，虽然存在标记数据，但数量不足以获得输出-输入依赖关系的良好估计。无标签模式的存在可以辅助该任务，因为它能揭示输入数据的额外结构，从而被高效利用。半监督学习将在如 [14] 等文献中讨论。

## 强化学习

最后，另一种日益重要的学习类型是所谓的**强化学习**（RL）。这也是一个历史悠久的领域，起源于自动控制。这种学习类型的核心在于一组规则，目标是学习动作序列，使**智能体**能够达成其目标或最大化其目标函数。例如，如果智能体是机器人，目标可能是从 A 点移动到 B 点。直观上，RL 试图通过**试错**来学习动作。与监督学习不同，最优动作不是从标签中学习，而是从所谓的**奖励**中学习。这个标量值告知系统其执行的任何动作的结果是正确还是错误。采取最大化奖励的动作是 RL 的目标。强化学习超出了本书的范围，感兴趣的读者可参考如 [19] 等文献。

# 1.7 本书的结构与路线图

在上述讨论中，我们看到看似不同的应用（如作者身份识别和信道均衡、金融预测和图像去模糊）可以在一个统一框架下处理。为机器学习开发的许多技术与统计信号处理或自适应信号处理中使用的技术并无二致。滤波属于回归的一般框架（第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章），而“自适应滤波”在机器学习中等同于“在线学习”。事实上，正如将更详细解释的那样，本书可满足不止一门高级研究生或研究生课程的需求。

多年来，在不同应用背景下开发了大量技术。这些技术大多属于两大思想流派之一。在其中一个流派中，定义未知函数的相关参数（例如，公式 [(1.1)](#Chp001_1-17_B978044329238500007X.xhtml#deq1) 中的 `θ[1]`、`θ[2]`、`θ[0]`）被视为随机变量。贝叶斯学习建立在此基本原理之上。贝叶斯方法学习描述相关参数/变量随机性的分布。根据另一个流派，参数被视为非随机变量。它们对应一个固定但未知的值。我们将此类参数称为**确定性**参数。这一术语的合理性在于：与随机变量相反，如果非随机变量的值已知，则其值可以被“精确预测”。围绕确定性变量构建的学习方法侧重于选择优化损失函数以获得相应值的估计。在某些情况下，“频率学派”一词用于描述后一类技术（见第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章）。

上述两个思想流派各有优劣，我坚信通往“真理”的道路不止一条。每个流派都能比另一个更高效地解决某些问题。也许几年后，局势会更加清晰，从而得出更明确的结论。或者可能像生活一样，“真理”介于两者之间。

无论如何，该领域的每一位新来者都必须学习基础和经典。因此，在本书中，所有主要方向和方法都将以尽可能平衡的方式进行讨论。当然，作者作为凡人，难免会更强调其通过自身研究最熟悉的技术。这是健康的，因为写书是作者与读者分享专业知识和观点的一种途径。这也是为什么我坚信新书不是为了取代前作，而是为了补充先前发表的观点。
