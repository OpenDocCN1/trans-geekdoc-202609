在本章中，除非另有说明，我们也将坚持使用零均值联合分布的输入-输出随机变量。因此，协方差矩阵与相关矩阵重合。如果不是这种情况，公式 [(5.5)](#Chp005_177-248_B9780443292385000111.xhtml#deq8) 中的协方差将被相关矩阵替代。讨论重点在于实数数据，我们将在需要时指出与复值数据情况的差异。

```
θ^(i) = θ^(i−1) − μ(Σ[x]θ^(i−1) − p) = θ^(i−1) + μ(p − Σ[x]θ^(i−1)),
```
