## Remarks 11.4

*   An alternative trend to deal with outliers is via their explicit modeling. The noise is split into two components, the inlier and the outlier. The outlier part has to be sparse; otherwise, it would not be called outlier. Then, sparsity-related arguments are mobilized to solve an optimization task that estimates both the parameters as well as the outliers (see, for example, [15,71,80,85,86]).

## 11.9 Kernel ridge regression revisited

The kernel ridge regression was introduced in Section 11.7. Here, it will be restated via its dual representation form. The ridge regression in its primal representation can be cast as

```
minimize with respect to θ, ξ  J(θ,ξ) = ∑_{n=1}^{N} ξ_n^2 + C‖θ‖^2, subject to  y_n - θ^T x_n = ξ_n, n = 1,2,…,N,
```

which leads to the following Lagrangian:

```
L(θ,ξ,λ) = ∑_{n=1}^{N} ξ_n^2 + C‖θ‖^2 + ∑_{n=1}^{N} λ_n(y_n - θ^T x_n - ξ_n), n = 1,2,…,N.
```

Differentiating with respect to `θ` and `ξ_n`, `n = 1,2,…,N`, and equating to zero, we obtain

θ = (1/(2C)) ∑_{n=1}^{N} λ_n x_n
