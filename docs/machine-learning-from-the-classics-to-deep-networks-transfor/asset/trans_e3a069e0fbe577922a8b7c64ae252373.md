

### 卡尔曼滤波公式推导

$P_{n|n} = \mathbb{E}\left[ (\mathbf{x}_{n} - {\widehat{\mathbf{x}}}_{n|n}){(\mathbf{x}_{n} - {\widehat{\mathbf{x}}}_{n|n})}^{T} \right]$

![Equation](images/B978044329238500010X/si543.png)

1. 由下式给出：

$$K[n] = P[n|n-1]H[n]^{T}(R[n]+H[n]P[n|n-1]H[n]^{T})^{-1}$$

![Equation](images/B978044329238500010X/si544.png)

2. 

**提示**：使用以下公式：

$$\frac{\partial \text{trace}\left\{ AB \right\}}{\partial A} = B^{T} \quad (AB \text{ 为方阵}), \quad \frac{\partial \text{trace}\left\{ ACA^{T} \right\}}{\partial A} = 2AC, \quad (C = C^{T}).$$

![Equation](images/B978044329238500010X/si545.png)

4. **4.23** 证明在卡尔曼滤波中，先验和后验误差协方差矩阵的关系如下：

$$P[n|n] = P[n|n-1] - K[n]H[n]P[n|n-1].$$

![Equation](images/B978044329238500010X/si481.png)

5. 

6. **4.24** 利用逆状态误差协方差矩阵 $P[n|n]^{-1}$ 推导卡尔曼算法。在统计学中，逆误差协方差矩阵与 Fisher 信息矩阵相关；因此得名。

### 计算机练习

1. **4.25** 考虑第 [4.6](#Chp004_119-175_B978044329238500010X.xhtml#s0055) 节所述的图像去模糊任务。

    *   从 Waterloo 图像库下载“boat”图像。^([^(25)](#fn25))

    *   使用 MATLAB® 的 `fspecial` 命令创建模糊点扩散函数 (PSF)。例如，可以编写：

    ```
    PSF = fspecial('motion',20,45);
    ```

    *   使用 `imfilter` 函数产生模糊效果：

    ```
    J = imfilter(I,PSF,'conv', 'circ');
    ```

    其中 `I` 为原始图像。

    *   使用 MATLAB® 的 `imnoise` 函数向图像添加白高斯噪声，如下所示：

    ```
    J = imnoise(J, 'gaussian', noise_mean, noise_var);
    ```
