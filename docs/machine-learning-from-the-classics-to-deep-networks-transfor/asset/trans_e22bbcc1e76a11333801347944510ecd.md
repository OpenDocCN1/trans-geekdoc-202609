
高光谱遥感的一个内在局限在于，由于遥感器空间分辨率较低，单个像素往往记录的是不同地物混合的光谱特征。这引出了光谱解混（SU）[37]的需求，它是高光谱图像处理中至关重要的一步，近来引起了强烈的科学兴趣。SU 是将观测像素的测量光谱分解为一组组成光谱特征（或称`endmembers`）及其对应比例（或称`abundances`）的过程。执行 SU 的一种广泛使用的模型是线性混合模型。

假设一个由 `M` 个光谱波段组成的遥感高光谱图像，令 `y ∈ ℝ^M` 为包含单个像素（特定地表斑块）测量光谱特征（即所有光谱波段的辐射值）的向量。另令 `X = [x[1], x[2], …, x[l]]` 代表 `M × l` 的端元特征矩阵，其中 `x[i] ∈ ℝ^M, i = 1, 2, …, l` 包含第 `i` 个端元的光谱特征，`l` 是场景中存在的（可能的）不同端元（地表/物质类型）的总数。最后，令 `θ = [θ[1], θ[2], …, θ[l]]^T` 为与 `y` 相关的`丰度向量`，其中 `θ[i]` 表示 `x[i]` 在 `y` 中的丰度分量。线性混合模型假设测量像素光谱与端元光谱之间存在线性关系，表达式为

```
y = Xθ + η
```

其中 `η` 代表加性噪声值，假设其为零均值高斯分布随机向量的样本，具有独立同分布（i.i.d.）元素，即 `η ∼ N(η|0, β^(−1)I[M])`，其中 `β` 表示噪声方差的倒数（精度），`I[M]` 为 `M × M` 单位矩阵。注意，公式 (13.143) 中的模型在其多元形式下是一个典型的回归模型，因为现在每次测量的输出是一个向量而非标量（另见第 4 章的 4.9 节）。输出变量已被测量，矩阵 `X` 假定为已知，确实存在估计其元素的方法。

利用此类模型恢复丰度系数，将是对本书当前及前几章所述内容的直接应用。然而，必须考虑一个物理约束，这使得任务更具挑战性。丰度系数为非负，即

```
θ[i] ≥ 0,  i = 1, 2, …, l.
```

此外，一个合理的假设是：图像中存在的端元只有少数几个会对单个像素 `y` 的光谱产生贡献。换句话说，丰度向量 `θ` 在 `X` 中接受`稀疏`表示。
