### 4.4.1 广义线性复值估计

让我们从向量空间中线性运算的定义出发，定义线性双通道估计任务。该任务是通过线性运算，从输入向量变量 `x = [x_r^T, x_i^T]^T ∈ ℝ^(2l)` 生成向量输出 `ŷ = [ŷ_r, ŷ_i]^T ∈ ℝ^2`：

```
ŷ = [ŷ_r; ŷ_i] = Θ[x_r; x_i],
```
(4.25)

其中

```
Θ := [θ_11^T  θ_12^T; θ_21^T  θ_22^T],
```
(4.26)
