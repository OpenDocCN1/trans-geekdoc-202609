
设 `x ∈ ℝ²` 为正态分布的随机向量，即 `𝒩(0, I)`。随机变量对 `(y₁, y₂)` 与 `(x₁, x₂)` 的关系如下：

```
y = [[0.7, 0.3],
     [0.3, 0.7]] x
```

请注意所涉变量之间存在的强相关性，因为

`y₁ + y₂ = x₁ + x₂`

然而，交叉协方差矩阵

```
Σ_yx = [[0.7, 0.3],
        [0.3, 0.7]]
```

却显示出相当低的相关性。执行 CCA 后，得到的方向为

`u_x,1 = u_y,1 = - (1/√2)[1, 1]ᵀ`

这实际上正是所涉变量线性相等关系所在的方向。最大相关系数值等于 1，确实表明存在强相关性。
