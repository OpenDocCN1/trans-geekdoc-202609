
## 数学推导与波束形成器约束优化

**η**(*t*) = [*η*~0~(*t*), …, *η*~*l*−1~(*t*)]^(*T*)

![Equation](images/B978044329238500010X/si425.png)

且假设其均值为零；***x*** 也称为 *导向向量*。波束形成器作用于输入向量信号的输出为：

*ŝ*(*t*) = **w**^(*H*)**u**(*t*)

![Equation](images/B978044329238500010X/si426.png)

此处必须使用埃尔米特转置，因为涉及的信号现为复值。

我们首先施加约束。理想情况下，在无噪声环境下，期望能精确恢复从期望方向 *ϕ* 入射到阵列上的信号。因此，**w** 应满足以下约束：

**w**^(*H*)**x** = 1

![Equation](images/B978044329238500010X/si427.png) (4.106)

这保证了在无噪声时 *ŝ*(*t*) = *s*(*t*)。

![Equation](images/B978044329238500010X/si428.png)

注意，若将 **w**^(*H*) 和 ***x*** 分别视为 *H* 和 *X*，则公式 [(4.106)](#Chp004_119-175_B978044329238500010X.xhtml#deq192) 是公式 [(4.97)](#Chp004_119-175_B978044329238500010X.xhtml#deq174) 的一个实例。为考虑噪声影响，我们要求最小化均方误差 (MSE)：

𝔼 [|*s*(*t*) − *ŝ*(*t*)|²] = 𝔼 [|*s*(*t*) − **w**^(*H*)**u**(*t*)|²]

![Equation](images/B978044329238500010X/si430.png)

然而，

*s*(*t*) − **w**^(*H*)**u**(*t*) = *s*(*t*) − **w**^(*H*)(**x***s*(*t*) + **η**(*t*)) = − **w**^(*H*)**η**(*t*)

![Equation](images/B978044329238500010X/si431.png)
