
$$
\sigma_{y}^{2} = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\Sigma_{\theta|y}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\left( \frac{1}{\sigma_{\theta}^{2}}I + \frac{1}{\sigma_{\eta}^{2}}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \sigma_{\eta}^{2}\sigma_{\theta}^{2}\mathbf{\phi}^{T}(\mathbf{x})\left( \sigma_{\eta}^{2}I + \sigma_{\theta}^{2}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}).
$$

因此，给定 `x`，可以使用最可能的值来预测 `y` 相应的值，即公式 [(12.22)](#Chp012_583-634_B9780443292385000184.xhtml#deq26) 中的 `μ[y]`。请注意，通过公式 [(12.10)](#Chp012_583-634_B9780443292385000184.xhtml#deq13) 中的 MAP 估计（或公式 [(12.12)](#Chp012_583-634_B9780443292385000184.xhtml#deq15)（如果 `θ[0] = 0`，也可通过岭回归任务获得））会得到相同的预测值。那么，采用贝叶斯方法是否获得了额外的收获？答案是肯定的。*现在可以获得关于预测值的更多信息，因为* 公式 [(12.23)](#Chp012_583-634_B9780443292385000184.xhtml#deq27) *量化了相关的不确定性*。
