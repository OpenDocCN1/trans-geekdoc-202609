
[图 18.4](#Chp018_885-995_B978044329238500024X.xhtml#f0025)A 展示了三个神经元，分别实现了 [图 18.3](#Chp018_885-995_B978044329238500024X.xhtml#f0020) 的三个超平面，*H*[1]、*H*[2] 和 *H*[3]。相关联的输出，记为 *y*[1]、*y*[2] 和 *y*[3]，构成了相应输入模式所在区域的标签。确实，如果突触的权重已被适当设置，那么如果一个模式源自某个区域，例如 (010)，则最左边的第一个神经元将发放零值 (*y*[1] = 0)，中间的发放一值 (*y*[2] = 1)，最右边的发放零值 (*y*[3] = 0)。换句话说，将三个神经元的输出组合在一起，我们就实现了输入特征空间到三维空间的*映射*。更具体地说，该映射是在 ℝ³ 中*单位*立方体的顶点上执行的，如 [图 18.5](#Chp018_885-995_B978044329238500024X.xhtml#f0030) 所示。输入空间的每个区域唯一对应于立方体的一个顶点。在更一般的情况下，即采用 *p* 个神经元时，映射将是在 ℝ^(*p*) 中单位超立方体的顶点上进行。这一层神经元构成了我们正在构建的网络的第一*隐藏层*。

另一种理解这种映射的方式是将其视为用码字表示输入模式的新*表征*。对于三个神经元/超平面，我们可以形成 2³ 个二进制码字，每个码字对应单位立方体的一个顶点，可表示 2³ − 1 = 7 个区域（还剩一个顶点，即 (110)，不对应任何区域）。然而请注意，这种映射编码了关于输入数据某些*结构*的信息；即与输入模式在特征空间中如何聚集在不同区域相关的信息。

我们现在将使用这种新表征，即由第一隐藏层神经元的输出所提供的表征，作为输入馈送给第二隐藏层的神经元，第二隐藏层的构建如下。我们选择属于同一类的所有区域。以 [图 18.3](#Chp018_885-995_B978044329238500024X.xhtml#f0020) 中的示例为例，我们选择对应类别 *ω*[1] 的两个区域，即 (000) 和 (111)。回顾一下，来自这些区域的所有点都被映射到 ℝ³ 中单位立方体的相应顶点。然而，在这个新的变换空间中，每个顶点都与其余顶点*线性可分*。这意味着我们可以在变换空间中使用一个神经元/感知机，它将单个顶点置于相关超平面的 (+) 侧，其余顶点置于 (−) 侧。这在 [图 18.5](#Chp018_885-995_B978044329238500024X.xhtml#f0030) 中有所示，图中展示了两个这样的平面，它们将相应的顶点与其余顶点分开。这些平面中的每一个都是由一个在 ℝ³ 中运行的神经元实现的，如 [图 18.4](#Chp018_885-995_B978044329238500024X.xhtml#f0025)B 所示，其中增加了第二层*隐藏*神经元。
