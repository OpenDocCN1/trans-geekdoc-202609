### 生成式学习与判别式学习

我们为引入分类任务所采取的路径，是考虑输出变量（标签）`y` 与输入变量（特征）`x` 之间的函数依赖关系。相关参数是针对代价函数进行优化的。这种建模路径也被称为*判别式学习*。我们并不关心将这两组变量联系在一起的依赖关系的统计本质。在更一般的设定中，判别式学习一词也用于涵盖那些直接对给定特征向量 `x` 的类别后验概率（由其标签 `y` 表示）建模的方法，即 `P(y|x)`。所有这些方法的共同特点是，它们绕过了显式建模输入数据分布的必要性。从统计学角度来看，判别式学习的合理性如下。

利用概率乘法法则，输入数据及其相应标签之间的联合分布可以写为

`p(y, x) = P(y|x)p(x)`。

在判别式学习中，仅考虑乘积中的第一项；采用一种函数形式并将其适当参数化为 `P(y|x; θ)`。然后通过优化代价函数来估计参数。输入数据的分布被忽略。这种方法的优势在于可以使用更简单的模型，特别是当输入数据由形式复杂的联合概率密度函数（PDF）描述时。其劣势在于忽略了输入数据分布，尽管它可能包含重要信息，本可用于提升整体性能。

相比之下，另一种被称为*生成式学习*的路径，则利用输入数据分布。再次利用乘法法则，我们有

`p(y, x) = p(x|y)P(y)`，

其中 `P(y)` 是关于类别的概率，`p(x|y)` 是给定类别标签下的输入分布。采用这种方法，我们最终会得到每个类别对应的一个分布，这些分布需要被学习。在参数化建模中，一组参数与这些条件分布中的每一个相关联。一旦学习了输入-输出联合分布，未知模式 `x` 的类别标签预测就基于后验概率来执行，即

```
P(y|x) = \frac{p(y,x)}{p(x)} = \frac{p(y,x)}{\sum_{y}p(y,x)}.
```
