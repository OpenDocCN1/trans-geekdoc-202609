

## 15.6 有向图的道德化

在许多地方，我们已经在贝叶斯网络（BN）和马尔可夫随机场（MRF）之间建立了桥梁。在本节中，我们将形式化这一桥梁，并了解如何将 BN 转换为 MRF，以及讨论这种转换对所隐含的条件独立性产生的后续影响。

我们可以依靠常识来驱动我们构建这种转换。因为条件分布将扮演势函数（因子）的角色，所以必须确保这些因子中涉及的所有变量之间都存在边。因为从父节点到子节点的边已存在，我们必须 (a) 保留这些边并使其无向化，以及 (b) 在拥有共同子节点的父节点之间添加边。这在[图 15.20](#Chp015_755-803_B9780443292385000214.xhtml#f0110)中展示。在[图 15.20](#Chp015_755-803_B9780443292385000214.xhtml#f0110)A 中，展示了一幅有向无环图（DAG），通过在 `x[1], x[2]`（`x[3]` 的父节点）和 `x[3], x[6]`（`x[5]` 的父节点）之间添加无向边，将其转换为[图 15.20](#Chp015_755-803_B9780443292385000214.xhtml#f0110)B 的 MRF。该过程称为*道德化*，生成的无向图称为*道德图*。该术语源于“父节点被迫结婚”这一事实。这种转换很快将非常有用，届时将陈述一个推理算法，该算法在一个统一框架下同时涵盖 BN 和 MRF。

图 15.20 (A) 一幅 DAG 和 (B) 对该 DAG 应用道德化后生成的 MRF。有向边变为无向，并添加了新边（红色显示），以便将拥有共同子节点的父节点“结婚”。

现在显而易见的问题是道德化如何影响独立性。结果表明，如果 `H` 是生成的道德图，则 `I(H) ⊆ I(G)`（问题 [15.11](#Chp015_755-803_B9780443292385000214.xhtml#o0095)）。换句话说，与原始 BN 通过其 `d`-分离集合相比，道德图能保证更少数量的独立性。这是很自然的，因为添加了额外的链接。例如，在[图 15.20](#Chp015_755-803_B9780443292385000214.xhtml#f0110)A 中，汇聚节点 `x[1] → x[3] ← x[2]` 中的 `x[1], x[2]` 是边缘独立的，但在给定 `x[3]` 的条件下不独立。然而，在[图 15.20](#Chp015_755-803_B9780443292385000214.xhtml#f0110)B 的生成道德图中，这种独立性丢失了。可以证明，道德化添加的额外链接最少，因此保留了最大数量的独立性（参见例如文献 [25]）。

## 15.7 精确推理方法：消息传递算法

本节讨论无向图模型上高效的推理技术。因此，即使我们的起点是 BN，我们也假设在推理任务之前它已被转换为无向图。我们将从图模型的最简单情况——由节点链组成的图——开始。这将帮助读者掌握精确推理方案背后的基本概念。值得注意的是，一般而言，图模型中的推理任务是一个 NP-hard 问题 [10]。此外，已证明对于一般 BN，将近似推理精确到所需的位数也是一个 NP-hard 任务 [11]；即所需时间随精度位数呈指数级增长。然而，正如我们将在许多实践中常见的案例中看到的那样，通过利用相关分布的底层独立性和因子分解特性，可以避免计算时间呈指数级增长。

感兴趣的推理任务包括 (a) 计算似然，(b) 计算涉及变量的边缘分布，(c) 计算条件概率分布，以及 (d) 寻找分布的众数。
