现在设我们的信号关于矩阵 $\Phi^{(T)}$ 的余稀疏度为 $C_{o}$。那么，为了从信号隐藏其中的子空间中挖掘出该信号，必须构建 $\Phi$ 的所有可能的 $C_{o}$ 列组合，并在它们的正交补空间中进行搜索。在 $\Phi$ 满秩的情况下，我们之前已经看到 $C_{o} < l$，因此，$\Phi$ 的任意 $C_{o}$ 列都是线性无关的。换句话说，这些列张成空间的维度是 $C_{o}$。结果，我们在其中搜索 $\mathbf{s}$ 的正交补空间的维度是 $l - C_{o}$。

到目前为止，我们已经积累了足够的信息，可以详细阐述之前关于合成任务和分析任务性质不同的论述。让我们考虑一个使用 $l \times p$ 字典的合成任务，并设 $k$ 为信号按该字典展开时对应的稀疏度水平。求解所在子空间的维度是 $k$（假设 $k$ 小于相应矩阵的火花数）。让我们保持相同的维度，用于我们将在其中搜索分析任务解的子空间。因此，在这种情况下 $C_{o} = l - k$（假设为满火花矩阵）。此外，为了便于比较，假设分析矩阵为 $p \times l$。求解合成任务时，必须搜索 $\binom{p}{k}$ 个子空间，而求解分析任务时，必须搜索 $\binom{p}{C_{o} = l - k}$ 个子空间。这是两个不同的数字；假设 $k \ll l$ 且 $l < p/2$，这对于过完备字典来说是自然的假设，那么后者远大于前者（请用计算机代入一些典型值验证一下）。换句话说，需要搜索的分析低维子空间比合成低维子空间多得多。大量的低维子空间使得从分析模型中算法恢复解变得更加困难 [92]。然而，这可能揭示出分析模型相比合成模型具有强得多的描述能力。

另一个凸显这两种方法差异的有趣方面如下。假设合成矩阵和分析矩阵满足 $\Phi = \Psi$ 的关系，这正是紧框架的情况。在此假设下，$\Phi^{(T)}\mathbf{s}$ 为基于 $\Phi = \Psi$ 的原子的合成展开提供了一组参数。此外，如果 $\|\Phi^{(T)}\mathbf{s}\|_{0} = k$，那么 $\Phi^{(T)}\mathbf{s}$ 就是合成模型的一个可能的 $k$-稀疏解。然而，无法保证这是最稀疏的解。
