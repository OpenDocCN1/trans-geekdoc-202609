
其中 `f : ℝˡ ↦ ℝˡ` 是一个*可逆*（向量）函数。也就是说，给定 `y`，可以唯一地得到 `x = f⁻¹(y)`。我们已知 `x` 的联合 PDF `pₓ(x)`，任务是求得 `y` 的联合 PDF `pᵧ(y)`。

该变换的雅可比矩阵定义为

```
J(y; x) := ∂(y₁,y₂,…,yₗ)/∂(x₁,x₂,…,xₗ) := 
[ ∂y₁/∂x₁ … ∂y₁/∂xₗ ]
[ ⋮       ⋱ ⋮       ]
[ ∂yₗ/∂x₁ … ∂yₗ/∂xₗ ].
```

然后，可以证明（例如，[6]）

```
pᵧ(y) = pₓ(x) / |det(J(y; x))| |_{x = f⁻¹(y)}.
```

其中 `|det(⋅)|` 表示矩阵行列式的绝对值。对于实随机变量，如 `y = f(x)`，公式 (2.45) 简化为

```
pᵧ(y) = pₓ(x) / |dy/dx| |_{x = f⁻¹(y)}.
```
