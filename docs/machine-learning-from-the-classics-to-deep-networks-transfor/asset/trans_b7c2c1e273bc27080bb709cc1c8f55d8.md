
分隔线（超平面）穿过连接均值点 `μ₁` 和 `μ₂` 的线段的中点（`x₀ = ½(μ₁ + μ₂)`）。此外，它垂直于由向量 `μ₁ − μ₂` 定义的该线段，这可以通过上述超平面定义轻松验证。确实，对于决策曲线（[图 7.5](#Chp007_293-342_B9780443292385000135.xhtml#f0035) 中的实心黑线）上的*任意*点 `x`，由于中点 `x₀` 也位于该曲线上，因此对应的向量 `x − x₀` 平行于该线。因此，公式 [(7.23)](#Chp007_293-342_B9780443292385000135.xhtml#deq37) 中的内积等于零意味着决策线垂直于 `μ₁ − μ₂`。红线对应 `P(ω₁) > P(ω₂)` 的情况。它更靠近类别 `ω₂` 的均值点，从而扩大了判定为概率较大类别的区域。请注意，在这种情况下，公式 (7.22) 中比率的对数为正。最后，虚线对应于等概率情况，且公共协方差矩阵具有更一般的形式 `Σ ≠ σ²I`。分隔超平面穿过 `x₀`，但会旋转以垂直于向量 `Σ⁻¹(μ₁ − μ₂)`，根据公式 (7.20)–(7.21)。对于这三种情况中的每一种，未知点均根据其位于相应超平面的哪一侧进行分类。
