
回想一下，对于回归模型的情况，**θ**[*] = **θ**[*o*]，并且所有节点得出相同的解。毫无疑问，如果统计量 `Σ[x[k]]`、**p**[k]、*k* = 1, 2, …, *K* 已知，我们就可以到此为止。然而，我们已经知道情况并非如此，在实践中它们必须被估计。或者，必须求助于迭代技术来学习统计量以及未知参数。这就是必须考虑所有节点的地方，以便从分布在网络中的所有观测值中获益。因此，一个更自然的采用准则是

```
J(θ) = ∑_{k=1}^{K} J_k(θ) = ∑_{k=1}^{K} E[ |y_k - θ^T x_k|^2 ].
```
(5.79)

使用我们迄今为止多次采用的标准论证，很容易看出未知 **θ**[*o*] 的（公共）估计将作为以下方程的解给出

```
(∑_{k=1}^{K} Σ_{x_k}) θ_* = ∑_{k=1}^{K} p_k.
```

让我们以公式 [(5.79)](#Chp005_177-248_B9780443292385000111.xhtml#deq177) 中的全局代价作为起点，应用梯度下降优化方案，

```
θ^{(i)} = θ^{(i-1)} + μ ∑_{k=1}^{K} (p_k - Σ_{x_k} θ^{(i-1)}),
```
(5.80)
