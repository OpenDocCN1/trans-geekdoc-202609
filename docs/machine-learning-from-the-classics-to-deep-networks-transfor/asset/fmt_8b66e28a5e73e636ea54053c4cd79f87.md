Versions where some of these conditions are relaxed are also available. The respective covariance matrices, `Q[n]` and `R[n]`, are assumed to be known.

The development of the time-varying estimation task evolves around two types of estimators for the state variables:

*   **The first one** is denoted as
    ```
    x̂_{n|n-1}
    ```
    and it is based on all information that has been received up to and including time instant `n-1`; in other words, the obtained observations, `y[0]`, `y[1]`, …, `y[n-1]`, of the respective random vectors, `y[0]`, `y[1]`, …, `y[n-1]`. This is known as the a priori or *prior* estimator.

*   **The second estimator** at time `n` is known as the *posterior* one; it is denoted as
    ```
    x̂_{n|n}
    ```
    and it is computed by updating `x̂_{n|n-1}` after `y[n]` has been observed.
