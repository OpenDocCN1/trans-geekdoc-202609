
我们现在已经来到了关键点，将建立保证 `ℓ₁` 和 `ℓ₀` 极小化解等价的条件。因此，在这些条件下，一个通常属于 NP-hard 类的问题*可以通过一个易处理的凸优化任务来求解*。在这些条件下，`ℓ₁` 范数鼓励零值的特性（此前已讨论过）获得了更高的地位；它提供了最稀疏的解。

## 9.7.1 由互相干数隐含的条件

### 定理 9.2

*考虑欠定方程组*

`y = Xθ`

*其中 `X` 是一个 `N × l` (`N < l`) 满行秩矩阵。如果存在满足以下条件的解*

```
‖θ‖₀ < ½(1 + 1/μ(X))
```
(9.28)

*那么这就是 `ℓ₀` 和 `ℓ₁` 极小化解的唯一解。*

这是一个非常重要的定理，文献 [37,54] 独立证明了这一点。该定理的早期版本针对由两个标准正交基组成的字典这一特殊情况 [36,48]。文献 [15] 也总结了一个证明（习题 [9.17](#Chp009_417-462_B9780443292385000159.xhtml#o0110)）。该定理首次从理论上确立了此前仅从经验上已知的事实：通常情况下，`ℓ₁` 和 `ℓ₀` 极小化解会得到相同的解。

### 备注 9.8

*   我们迄今为止提出的理论非常令人满意，因为它提供了理论框架和条件，保证欠定方程组稀疏解的唯一性。现在我们知道，在特定条件下，通过求解凸 `ℓ₁` 极小化任务得到的解就是（唯一的）最稀疏解。然而，从实用角度来看，基于互相干的理论并不能讲完整个故事，在预测实际发生的情况方面显得力不从心。实验证据表明，`ℓ₀` 和 `ℓ₁` 任务给出相同解的稀疏度水平范围，比互相干界限所保证的范围宽得多。因此，为了改进这一界限，产生了大量理论研究。详细讨论超出了本书范围。在下一小节中，我们将介绍其中一个界限，因为它是主导该领域的界限。更多细节和相关讨论，感兴趣的读者可参考例如 [39,49,50]。
