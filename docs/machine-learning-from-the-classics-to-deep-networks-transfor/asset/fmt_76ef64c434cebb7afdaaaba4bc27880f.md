
## 马尔可夫链的性质与示例

### 不变分布与详细平稳条件

* 如果一个分布对于每个 `B[m]`（`m = 1, 2, …, M`）都是不变的，那么它对于 `P` 也是不变的。详细平稳条件同样适用。

### 组合转移矩阵

* 另一种方法是按顺序组合单个转移矩阵，即：
  ```
  P = B[1] B[2] ⋯ B[M]
  ```

### 吉布斯采样示例

* 例如，每个 `B[m]`（`m = 1, 2, …, M`）可能作用于并改变组成随机向量 **x** 的随机条目的一个子集。我们将在随后回顾的吉布斯采样方法中看到这种情况。容易看出，如果 **p** 对每个单独的 `B[m]`（`m = 1, 2, …, M`）都是不变的，那么它对于 `P` 也是不变的。

### 状态空间推广

* 在本节中，我们将讨论重点放在了有限状态空间的马尔可夫链上。我们所说的一切都可以推广到可数无限或连续状态空间的马尔可夫链。在后一种情况下，概率转移矩阵的位置由转移概率密度或核 `p(x[n] | x[n−1])` 取代，而时间 `n` 时 **x[n]** 的概率密度函数由下式给出：
  ```
  p[n](x) = ∫ p(x | y) p[n−1](y) dy
  ```
  (14.46)

* 这种情况下的分析更加困难，必须小心处理，因为为有限离散情况获得的结果并非都能直接适用于连续情况。我们专注于离散有限状态空间的原因是，花费较少的数学精力“预算”就能获得马尔可夫链理论的直观感受。
