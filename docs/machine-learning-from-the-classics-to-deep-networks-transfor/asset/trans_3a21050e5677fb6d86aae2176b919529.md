
在实践中利用上述定理的方法如下。给定 `N` 个特征向量 `x[n] ∈ ℝ^(l)`，`n = 1, 2, …, N`，执行一个映射

`ϕ : ℝ^(l) ∋ x[n] ↦ ϕ(x[n]) ∈ ℝ^(K), K ≫ l`

然后根据该定理，`K` 的值越高，映射的像 `ϕ(x[n]) ∈ ℝ^(K), n = 1, 2, …, N` 在空间 `ℝ^(K)` 中线性可分的概率就越大。请注意，非线性分类器（用于预测二分类任务中的标签）的展开，等价于在原始点经过映射后的像上使用线性分类器。确实，

```
f(x) = ∑_{k = 1}^{K} θ_k ϕ_k(x) + θ_0 = θ^T [ ϕ(x) ; 1 ],
```
(11.7)

其中

`ϕ(x) := [ϕ_1(x), ϕ_2(x), …, ϕ_K(x)]^T`。
