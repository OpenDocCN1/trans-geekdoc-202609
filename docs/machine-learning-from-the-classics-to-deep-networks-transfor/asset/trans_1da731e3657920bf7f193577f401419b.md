
其中 `η` 表示（未观测到的）测量噪声样本向量；现在所需的就是计算后验概率 `p(x|y)`。假设噪声样本服从高斯分布，且因为 `p(x)` 是高斯分布的加和，很容易看出后验概率也是高斯分布的加和，由公式 [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) 中的参数和噪声向量的协方差矩阵决定。因此，与 `l` 相比，`x` 可以通过少得多的测量数 `K` 来恢复。文献 [47] 进行了理论分析，将流形维度 `k`、环境空间维度 `l` 以及高斯/亚高斯类型的感知矩阵 `Φ` 联系起来；这类似于 RIP（限制等距性质），从而保证稳定嵌入（第 [9.9](#Chp009_417-462_B9780443292385000159.xhtml) 节）。

必须指出第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章开发的技术与本节之间的一个主要区别。在那里，假设生成数据的模型是已知的；信号用 `s` 表示，写为

```
s = Ψθ
```

其中 `Ψ` 是字典矩阵，`θ` 是稀疏向量。也就是说，假设信号位于由 `Ψ` 的某些列张成的子空间中；为了恢复信号向量，必须在子空间的并集中搜索它。相比之下，在本节中，我们必须“学习”信号（此处用 `x` 表示）所在的流形。

## 20.9 非线性降维

迄今为止考虑的所有技术都建立在线性模型周围，这些模型关联观测变量和潜在变量。在本节中，我们将关注它们的非线性亲戚。我们的目的是讨论一些最流行的方向，而不会深入太多细节。感兴趣的读者可以从文中提供的参考文献中获得更深入的理解和相关实现细节。^([^(159)](#fn159))

### 20.9.1 核 PCA

顾名思义，这是经典 PCA 的核化版本，首次在文献 [161] 中提出。正如我们在第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章中所见，任何线性方法的核化版本背后的思想都是将原本位于低维空间 `ℝ^l` 中的变量，映射到高维（可能是无限维）的再生核希尔伯特空间（RKHS）中。这是通过采用隐式映射来实现的，

```
x ∈ ℝ^l ↦ ϕ(x) ∈ ℍ
```
(20.98)

设 `x_n, n = 1,2,…,N` 为可用的训练样本。假设数据已中心化，映射到 `ℍ` 后图像的样本协方差矩阵由下式给出^([^(160)](#fn160))

```
Σ̂ = (1/N) ∑_{n=1}^N ϕ(x_n) ϕ(x_n)^T
```
(20.99)

目标是执行 `Σ̂` 的特征分解，即

```
Σ̂ u = λ u
```
(20.100)
