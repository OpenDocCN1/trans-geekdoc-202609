
除了基本的拒绝采样方案外，还提出了许多变体，以克服选择一个“看起来像”目标分布的建议分布的困难。*自适应拒绝采样*就是一种这样的技术（参见，例如，[11]及其中的参考文献）。根据这种方法，建议分布是基于`ln p(x)`的导数自适应构建的。对于对数凹函数，这是一个非递减函数，可用于构建`p(x)`的包络函数。

尽管拒绝采样不适合困难的任务，但它仍被使用，有时以其更精炼的形式，从许多标准分布生成样本，例如高斯分布、伽马分布和学生 *t* 分布（参见，例如，[22]）。

## 14.5 重要性采样

*重要性采样*（IS）是一种用于估计期望的方法。设`f(x)`为随机向量变量`x`的已知函数，`x`按`p(x)`分布。如果能从`p(x)`中抽取样本，则公式[(14.1)](#Chp014_717-754_B9780443292385000202.xhtml#deq1)中的期望可按公式[(14.2)](#Chp014_717-754_B9780443292385000202.xhtml#deq2)近似。我们现在假设无法从`p(x)`中抽取样本，并进一步假设`p(x)`仅在归一化常数下已知，即

```
p(x) = (1/Z) * phi(x)
```

设`q(x)`为另一个可以从中抽取样本的分布。则我们可以写为

```
E[f(x)] = (1/Z) * ∫ f(x) * phi(x) dx
        = (1/Z) * ∫ f(x) * (phi(x) / q(x)) * q(x) dx
        ≈ (1/(N*Z)) * Σ f(x_i) * w(x_i)
```

其中`x[i]`，`i = 1, 2, …, N`，是从`q(x)`中抽取的样本。
