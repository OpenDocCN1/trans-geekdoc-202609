
$z = \frac{|\mathbf{\theta}^{T}\mathbf{x} + \theta_{0}|}{\|\mathbf{\theta}\|}$

![Equation](images/B9780443292385000172/si342.png)

如果该点位于超平面上，该值显然为零。此外，我们总可以用一个常数因子，比如说 `a`，同时缩放 `θ` 和 `θ[0]`，而不影响超平面的几何形状，正如公式 [(11.66)](#Chp011_519-582_B9780443292385000172.xhtml#deq150) 所述。经过适当的缩放后，我们总能使两个类别中最近的点到超平面的距离等于 $z = \frac{1}{\|\mathbf{\theta}\|}$；等价地说，这种缩放保证了如果 `x` 是距离超平面最近的点，则 `f(x) = ± 1`，符号取决于该点属于 `ω[1] (+ 1)` 还是 `ω[2] (− 1)`。由 `f(x) = ± 1` 定义的这两个超平面，在 [图 11.16](#Chp011_519-582_B9780443292385000172.xhtml#f0085) 中显示为虚线，适用于“灰色”和“红色”两个方向。这一对超平面定义了每个方向对应的间隔，其宽度等于 $\frac{2}{\|\mathbf{\theta}\|}$。

![Equation](images/B9780443292385000172/si347.png)

因此，如前所述构建的、且能解决该任务的任何分类器都具有以下两个性质：

*   它具有*间隔*，宽度等于 $\frac{1}{\|\mathbf{\theta}\|} + \frac{1}{\|\mathbf{\theta}\|}$；
*   它满足以下两组约束条件，

```
θ^(T)x[n] + θ[0] ≥ + 1,  x[n] ∈ ω[1],
θ^(T)x[n] + θ[0] ≤ − 1,  x[n] ∈ ω[2].
```
