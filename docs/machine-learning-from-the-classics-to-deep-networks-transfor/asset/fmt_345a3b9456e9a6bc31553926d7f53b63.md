## 7.6 Logistic regression

In Bayesian classification, the assignment of a pattern in a class is performed based on the posterior probabilities, `P(ω[i]|x)`. The posteriors are estimated via the respective conditional PDFs, which is not, in general, an easy task. The goal in this section is to model the posterior probabilities directly, via the *logistic regression* method. This name has been established in the statistics community, although the model refers to classification and not to regression. This is a typical example of the discriminative modeling approach, where the distribution of data is not taken into account.

**The two-class case**: The starting point is to model the ratio of the posteriors as

![Equation](images/B9780443292385000135/fx006.jpg) (7.29)

where the constant term, `θ[0]`, has been absorbed in `θ`. Taking into account that

`P(ω[1]|x) + P(ω[2]|x) = 1`

![Equation](images/B9780443292385000135/si147.png)

and defining

`t := θ^(T)x`

![Equation](images/B9780443292385000135/si148.png)

it is readily seen that the model in Eq. [(7.29)](#Chp007_293-342_B9780443292385000135.xhtml#deq53) is equivalent to

`P(ω[1]|x) = σ(t)`

![Equation](images/B9780443292385000135/si149.png) (7.30)

$$
\sigma(t): = \frac{1}{1 + \exp\left( - t \right)},
$$

![Equation](images/B9780443292385000135/si150.png) (7.31)

and

$$
P(\omega_{2}|\mathbf{x}) = 1 - P(\omega_{1}|\mathbf{x}) = \frac{\exp\left( - t \right)}{1 + \exp\left( - t \right)}.
$$
