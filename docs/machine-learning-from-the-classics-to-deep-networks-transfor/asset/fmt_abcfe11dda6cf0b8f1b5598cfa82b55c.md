## Which algorithm then

So far, in our discussion on GANs, we focused on two possible algorithms and we also provided references to a number of other alternatives. The Wasserstein GAN helped us to outline some important issues that underlie the task of learning distributions (implicitly or explicitly) where, most often, the learning process takes place in lower-dimensional manifolds. The reader and any practitioner may wonder which algorithm is “best” or more suitable to be used in a practical application.

One of the major problems associated with data generation is to be able to test the performance of the generator by assessing the quality of the generated patterns. The main issue in evaluating the performance stems from the fact that one cannot explicitly compute the distribution `p[g](x)`. Thus, classical costs such as the likelihood function cannot be employed. Attempts to approximate it in high-dimensional spaces seem to be problematic in the current context (e.g., [92]). To this end, related metrics have been suggested.

The so-called *inception score* (IS) builds upon the concept that a good model should generate samples for which, when evaluated by an independent pretrained classifier (usually an inception network, Section [18.12.4](#Chp018_885-995_B978044329238500024X.xhtml)), the class distribution has low entropy. In other words, given a generated image, this should look like one and only one among the available classes in the training set. Thus, the class probability that is predicted by the classifier should be sharply peaked at the correct class. At the same time, the generated samples should exhibit large variation [163] and they should be distributed to all classes with equal probability.

The *Fréchet inception distance* (FID) focuses on a metric that quantifies the difference between true and fake data samples, after a specific embedding in a feature space via an inception network, [76]. Assuming that the embedded data follow a multivariate Gaussian distribution, the distance between the two distributions is quantified by the Fréchet distance between the corresponding Gaussians, [46].

A comparative experimental study on various GANs has been presented in [121]. The findings there, using a number of metrics, including the previously stated quality measuring ones, do not seem to favor any one of the proposed GANs against the others. It is reported that most models can achieve similar scores after careful hyperparameter tuning in optimization, higher computational budget, and random restarts. A review of various methods, algorithms, and applications is given in, e.g., [67].

## Remarks 19.3

*   •  *Conditional GANs*: Conditional GANs were introduced in [134]. The main idea is that one may impose certain constraints/conditions on the generating samples. For example, we may want to generate samples from a specific class, e.g., images of the digit “1” or images containing only, say, “cats.” Also, we may want to select, e.g., the color of the hair when we generate faces. One way to achieve this is to *condition* both the generator and the discriminator on the desired extra information, say, `c`. The latter is a vector that encodes the conditioning information. For example, it may be the vector that encodes the classes, in case the conditioning refers to class-related information. In practice, this can be implemented by appropriately augmenting the inputs (e.g., concatenation with the input vector `z` of the standard GAN) of the generator and the discriminator by the vector `c` (or a transformed version of it, if the inputs are required to be images). There are cases where the conditioning information is provided to an intermediate layer of the discriminator. The goal of the discriminator is to discriminate whether the input is a generated sample augmented with the target `c` or a real sample augmented with the true `c`.
