
Eq. [(5.3)](#Chp005_177-248_B9780443292385000111.xhtml#deq6) 中的迭代过程在 [Fig. 5.5](#Chp005_177-248_B9780443292385000111.xhtml#f0030) 中针对一维情况进行了说明。如果在当前迭代中算法“落在”了 `θ₁` 处，则此时 `J(θ)` 的导数为正（锐角 `ϕ₁` 的正切），这将迫使更新向左移动，朝向最小值。如果当前估计值为 `θ₂`，情况则不同。导数为负（钝角 `ϕ₂` 的正切），这将推动更新向右移动，同样朝向最小值。但请注意，向左或向右移动多远非常重要。例如，从 `θ₁` 向左移动过大可能会使更新落在最优值的另一侧。在这种情况下，算法可能会在最小值附近振荡而永不收敛。本章将投入大量精力，提供理论框架以确定步长值的界限，从而保证收敛。

![Figure 5.5 Once the algorithm is at θ1, the gradient descent will move the point to the left, toward the minimum. The opposite is true for point θ2.](images/B9780443292385000111/gr005.jpg)

[Figure 5.5](#Chp005_177-248_B9780443292385000111.xhtml#cf0265) 一旦算法位于 `θ₁`，梯度下降法将把该点向左移动，朝向最小值。对于 `θ₂` 点则情况相反。

梯度下降法表现出近似的**线性收敛**；即 `θ⁽ⁱ⁾` 与最小值之间的误差以**几何级数**的形式渐近收敛到零。然而，收敛速度在很大程度上取决于 `J(θ)` 的海森矩阵的特征值分布。第 [5.3](#Chp005_177-248_B9780443292385000111.xhtml#s0020) 节将揭示收敛速度对特征值的依赖关系。对于较大的特征值分布，收敛速度可能变得极低。另一方面，该方法的巨大优势在于其计算量要求低。

最后必须指出，我们通过单位欧几里得范数搜索所有方向，得出了 Eq. [(5.3)](#Chp005_177-248_B9780443292385000111.xhtml#deq6) 中的方案。然而，欧几里得范数并没有什么“神圣”不可替代之处。可以采用其他范数，例如 `ℓ₁` 范数和 `P` 加权范数 `(zᵀPz)¹ᐟ²`，其中 `P` 是正定矩阵。在这些选择下，将得到替代的更新迭代（参见文献 [23]）。在第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章中，当我们处理牛顿迭代法和坐标下降最小化方案时，将回到这一点。
