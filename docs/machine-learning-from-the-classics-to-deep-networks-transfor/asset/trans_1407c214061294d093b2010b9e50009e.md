
为此，为了将任务置于我们之前采用的公式化框架中，我们将三个信号在不同时刻的值视为相应随机变量 `x[1]`、`x[2]` 和 `x[3]` 的不同观测值，将它们组合在一起形成随机向量 `x`。我们进一步采用一个非常合理的假设：原始源信号，记为 `s[1](t)`、`s[2](t)` 和 `s[3](t)`，是相互独立的，（类似于之前）不同时刻的值对应于三个潜在变量的值，将它们一起记为随机向量 `s`。

现在我们准备应用 ICA 来计算解混矩阵 `W`，从中我们可以获得对应于三个麦克风接收到的观测值的独立成分（IC）的估计值，

```
z(t) = [z[1](t), z[2](t), z[3](t)]^(T) = W[x[1](t), x[2](t), x[3](t)]^(T)
```

可以观察到，ICA 能够以非常好的精度分离信号，而 PCA 则失败了。读者也可以通过从本书网站下载相应的“.wav”文件来聆听这些信号。

请注意，鸡尾酒会问题代表了一大类任务，在这些任务中，若干记录信号是其他独立信号的线性组合；目标是恢复后者。此类任务的一个著名应用见于脑电图（EEG）。EEG 数据由头皮不同位置（或最近的耳内 [112]）记录的电位组成，这些电位是由大脑和肌肉活动的不同潜在成分组合产生的。任务是利用 ICA 恢复这些成分，进而可以揭示关于大脑活动的有用信息（例如，[158]）。

鸡尾酒会问题被称为*盲源分离*（BSS）这一更一般任务类别的典型例子。在这些任务中，目标是仅基于驻留在观测值中的信息来估计“因果”（源、原始信号），而没有任何其他额外信息，这就是使用“盲”一词的原因。从另一个角度来看，BSS 是无监督学习的一个例子。ICA 是此类问题中最广泛使用的技术之一。
