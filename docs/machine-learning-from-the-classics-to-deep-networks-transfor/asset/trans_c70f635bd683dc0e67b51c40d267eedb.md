
在本节开始时曾指出，由于训练深层网络的困难，20世纪80年代和90年代关于深层网络的研究曾被放弃。当时的普遍观点认为，因为参数数量变得非常大，参数空间中的代价函数变得复杂，陷入局部极小值的概率显著增加。

2010年后，上述观点受到严重挑战。当时发现，只要使用足够的训练数据，就可以训练大型网络。就在那个时候，大型数据集被构建出来，并可配合计算机技术的进步所提供的必要算力，并行用于训练。事实上，这是多层前馈神经网络卷土重来的关键因素，即*计算机技术*与*大型数据集*的可用性相结合。当然，在此期间开发的一些技术，例如使用`ReLU`非线性和用于正则化的`dropout`方法，结合相关训练积累的经验，也在神经网络的流行和成功中发挥了作用；然而，这些进步的贡献相对次要。

因此，大型网络训练的成功引发了关于局部极小值相关问题的质疑。即使拥有海量数据，如果参数空间中代价函数的地形“布满”局部极小值，那么一旦算法陷入其中，继续用更多数据训练就没有太大意义。

这一背景引发了相关研究热潮，许多有趣的发现挑战了以往的观点。在本书编写之时，这仍是一个热门研究课题。我们的目的不是提供广泛的相关讨论，而是给出一些基本方向和见解，并使读者意识到该问题。例如，文献[34]指出，一个更深层的困难，特别是在高维问题中，源于*鞍点*的激增。此类点的存在会显著减慢训练算法的收敛速度。文献[53]指出，大量鞍点对梯度下降的影响尚不清楚，因为梯度值可能非常小而减慢收敛速度，但算法似乎能逃离这些临界点。文献[32]声称，在大规模网络中，大多数局部极小值产生较低的代价值，并在测试集上表现出相似的性能。此外，随着网络规模增大，找到劣质（高代价值）局部极小值的概率快速下降。这两篇文献都借用了统计物理学中高斯随机场的结果。文献[98]通过不同的数学路径得出了本质相似的结果。文中证明，对于平方误差损失函数和深度线性神经网络，每一个局部极小值也是全局极小值。此外，每一个不是全局极小值的临界点必然是鞍点。在一定独立性假设下，结果可推广到非线性网络。在一篇较新的文献[40]中，通过梯度下降算法的收敛性回答了该问题。对于平方误差损失函数的情况，证明了梯度下降在训练深度神经网络时能找到全局极小值；尽管代价函数关于相关参数是非凸的。文中证明梯度下降能在多项式时间内实现零训练损失。该文涉及三种不同类型的过参数化神经网络：全连接、卷积和残差深度网络，将在第[18.12](#Chp018_885-995_B978044329238500024X.xhtml#s0170)节讨论。文献[104]研究了随机梯度下降的收敛性，并指出只要这些区域的邻域包含足够的梯度信息，算法就不会卡在直径较小的局部极小值处。邻域大小由步长和梯度噪声控制。鞍点的情况及如何逃离它们在文献[93,145]等中有论述。相关理论结果的总结见文献[42,195]等。

### 泛化性能与双重下降曲线现象

上一段简要介绍了与训练算法收敛性和优化任务非凸性相关的一些问题。讨论的重点现在转向深度网络的泛化性能相关问题。这仍是一个存在开放理论挑战的任务，该课题是当前活跃的研究领域。

任何学习器（当然包括深度神经网络）的泛化性能，由训练误差与测试误差之间的差异来量化。好的学习器是指测试误差和训练误差取值接近的情况。此外，正如我们在第[3](#Chp003_65-117_B9780443292385000093.xhtml)章讨论的，如果参数数量相对于训练数据规模足够大，就会发生过拟合，我们预期测试误差会偏离训练误差。然而，在深度网络的情况下，我们面临一个“悖论”。

训练非常大的过参数化网络，其中参数数量`K`大于训练集大小`N`，即使*没有显式正则化*，所得网络在大多数情况下也表现出良好的泛化性能！这一发现与我们熟悉的图[3.12](#Chp003_65-117_B9780443292385000093.xhtml)的U型曲线相矛盾。第[3.13](#Chp003_65-117_B9780443292385000093.xhtml)节的要点是，随着参数数量（模型复杂度）`K`的增加，测试误差最初下降至某一点，然后开始上升。同时，训练误差持续下降至零。文献[11]挑战了测试误差这种被广泛接受的行为，报告称测试误差的U型趋势仅在*欠参数化*区域成立，即`K`小于`N`的取值区域。然而，如果在*过参数化*区域持续增加参数数量，使`K`大于`N`，则测试误差可能会再次开始下降。事实上，最小测试误差往往出现在“无限复杂度”处，即模型越过参数化，测试误差越小。这被称为*双重下降误差曲线*现象，让机器学习界感到困惑。图[18.17](#Chp018_885-995_B978044329238500024X.xhtml#f0095)展示了双重下降误差曲线的总体趋势。测试误差曲线的两部分故意显示为不连续，因为从欠参数化区域到过参数化区域的过渡部分形状取决于具体情况。例如，在某些模型中（如文献[12]、[65]），测试误差在`K = N`处趋于无穷大。重要的结论是，测试误差在`K = N`点之后开始下降。在本书当前版本编写之时，对双重下降曲线的解释和完全理解仍是正在进行的研究课题。
