### 13.6.1 The spike and slab method

This is an old technique for imposing sparsity [43,51]. Let us consider our familiar regression model,

`y = θ^(T)ϕ(x) + η` (13.64)

A new set of auxiliary binary *indicator* variables are introduced, `s[k] ∈ {0, 1}, k = 0, 1, …, K − 1`. Let also the prior imposed on `θ` be a Gaussian, `p(θ) = N(θ|0, σ²I)`. As the name suggests, the indicator variables control the presence or absence of a parameter in the summation in Eq. [(13.64)](#Chp013_635-716_B9780443292385000196.xhtml#deq93). For example, if `s[k] = 1`, then the corresponding parameter `θ[k]` is present, and if `s[k] = 0`, then `θ[k]` is removed; this is the way sparsity is imposed onto the model. To this end, a joint Bernoulli prior distribution (Chapter [2](#Chp002_19-64_B9780443292385000081.xhtml)) is adopted for the indicator variables, i.e.,

```
P(s) = ∏_{k=0}^{K-1} p^{s_k} (1-p)^{1-s_k}
```
(13.65)
