### Remarks 8.2

*   In the context of sparsity-aware learning, which is dealt with in Chapter [10](#Chp010_463-518_B9780443292385000160.xhtml), a key point is the projection of a point in ℝ^(*l*) (ℂ^(*l*)) onto the ℓ[1] ball. There it is shown that, given the size of the ball, this projection corresponds to the so-called soft thresholding operation (see, also, [Example 8.10](#Chp008_343-416_B9780443292385000147.xhtml#enun0260) for a definition).

*   It should be stressed that a linear space equipped with the ℓ[1] norm is no more Euclidean (Hilbert), inasmuch as this norm *is not induced* by an inner product operation; moreover, uniqueness of the projection with respect to this norm is not guaranteed (Problem [8.15](#Chp008_343-416_B9780443292385000147.xhtml#o0105)).
