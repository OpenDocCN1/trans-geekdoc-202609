

### 7.7.2 Fisher判别：二分类情况

在Fisher线性判别分析中，公式[(7.54)](#Chp007_293-342_B9780443292385000135.xhtml#deq85)的重点仅在于`θ`；偏置项`θ[0]`未在讨论范围内。内积`θ^(T)x`可视为`x`沿向量`θ`方向的投影。严格来说，从几何上我们知道，相应的投影也是一个向量`y`，由以下公式给出（例如，第[5.6](#Chp005_177-248_B9780443292385000111.xhtml)节）

**数学推导**

类间离差矩阵的迹定义为：

```
trace{Σ_b} = ∑_{k=1}^{3} P(ω_k) [ (μ_{k1} - μ_{01})^2 + (μ_{k2} - μ_{02})^2 ]
```

这可以用向量符号表示为：

```
= ∑_{k=1}^{3} P(ω_k) ||μ_k - μ_0||^2 := s_b,
```

其中`μ_k = [μ_{k1}, μ_{k2}]^T`是第*k*类的均值，`μ_0 = [μ_{01}, μ_{02}]^T`是全局均值向量。

准则`J_1`定义为：

```
J_1 = (s_w + s_b) / s_w = 1 + s_b / s_w.
```

换句话说，平均总方差越小，均值到全局均值的平均欧氏距离平方越大，`J_1`的值就越大。对于其他两个准则也可以作出类似的论证。
