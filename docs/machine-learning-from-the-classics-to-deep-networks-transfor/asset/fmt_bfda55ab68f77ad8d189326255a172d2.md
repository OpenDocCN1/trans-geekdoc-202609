
Having established the relationship between `a[m]` and `b[m]` in Eq. [(4.71)](#Chp004_119-175_B978044329238500010X.xhtml#deq123), we are ready to complete the missing step in Eq. [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114), that is, to complete an order-recursive step for the update of `b[m]`. Since Eq. [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114) holds true for any desired response `d[n]`, it also applies for the special case where the optimal filter to be designed is the forward predictor `a[m]`; in this case, `d[n] = u[n + 1]`. Replacing in Eq. [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114) `w[m]` (`w[m - 1]`) with `a[m]` (`a[m - 1]`) results in

```
\mathbf{a}_{m} = \begin{bmatrix} \mathbf{a}_{m - 1} \\ 0 \\ \end{bmatrix} + \begin{bmatrix} {- J_{m - 1}\mathbf{a}_{m - 1}^{\ast}} \\ 1 \\ \end{bmatrix}k_{m - 1},
```

where [(4.71)](#Chp004_119-175_B978044329238500010X.xhtml#deq123) has been used and

```
k_{m - 1} = \frac{r^{\ast}(m) - \mathbf{r}_{m - 1}^{H}J_{m - 1}\mathbf{a}_{m - 1}}{\alpha_{m - 1}^{b}}.
```

![Equation](images/B978044329238500010X/si309.png)(4.73)
