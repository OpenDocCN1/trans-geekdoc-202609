例如，假设 *X*<sub>t</sub> 中的数据包含属于四个类别 *ω*<sub>1</sub>、*ω*<sub>2</sub>、*ω*<sub>3</sub>、*ω*<sub>4</sub> 的点。其思路是执行分裂，使得 *X*<sub>tY</sub> 中的大部分数据属于 *ω*<sub>1</sub>、*ω*<sub>2</sub>，而 *X*<sub>tN</sub> 中的大部分数据属于 *ω*<sub>3</sub>、*ω*<sub>4</sub>。在采用的术语中，*X*<sub>tY</sub> 和 *X*<sub>tN</sub> 应比 *X*<sub>t</sub> 更“纯净”。

因此，我们必须首先选择一个衡量“杂质度”的准则，然后计算阈值并选择要测试的特定特征，以最大化节点杂质度的降低。例如，量化节点 *t* 杂质度的常用度量是“熵”，定义如下：

```
I(t) = - ∑_{m=1}^{M} P(ω_m|t) log_2 P(ω_m|t),  (7.73)
```

```
P(ω_m|t) = N_t^m / N_t,  m = 1,2,…,M,
```
