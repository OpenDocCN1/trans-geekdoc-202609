
# 贪心算法与正交匹配追踪

贪心算法由来已久；例如，参考文献 [114] 提供了详尽的参考文献列表。在字典学习的背景下，一种称为*匹配追踪*的贪心算法在文献 [88] 中被提出。贪心算法建立在一系列*局部*最优*单项*更新之上。在我们的语境中，目标是 (a) 揭示感知矩阵 `X` 的“活跃”列，即对应未知参数非零位置的那些列，以及 (b) 估计相应的稀疏参数向量。对应非零向量分量的索引集也称为*支撑集*。为此，`X` 的活跃列集合（以及支撑集）在每一迭代步骤中增加一列。

在后续过程中，将获得未知稀疏向量的更新估计。假设在第 `(i-1)` 次迭代步骤中，算法已选定记为 `x[j[1]]^(c)`、`x[j[2]]^(c)`、...、`x[j[i-1]]^(c)` 的列，其中 `j[1]`、`j[2]`、...、`j[i-1]` ∈ {1, 2, ..., `l`}。这些索引是当前可用支撑集 `S^((i-1))` 的元素。令 `X^((i-1))` 为 `N × (i-1)` 矩阵，其列为 `x[j[1]]^(c)`、`x[j[2]]^(c)`、...、`x[j[i-1]]^(c)`。另令当前解的估计为 `θ^((i-1))`，这是一个 `(i-1)`-稀疏向量，在支撑集索引之外的所有位置均为零。文献 [算法 10.1](#Chp010_463-518_B9780443292385000160.xhtml#enun0010) 中给出的*正交匹配追踪*（OMP）方案递归地构建稀疏解。
