
where **α** := [*α*[1], *α*[2], …, *α*[*l*]]^(*T*) is the precision parameter vector, *A* = diag{*α*[1], …, *α*[*l*]} is the corresponding diagonal matrix, and 𝒩[ℝ[+]^(*l*)] signifies the *l*-variate normal distribution truncated at the nonnegative orthant of ℝ^(*l*), denoted by ℝ[+]^(*l*) [84]. In the second level of hierarchy, the precision parameters are also considered random variables, *α*[*i*], *i* = 1, 2, …, *l*, that follow an inverse Gamma distribution, that is,

```
$p(\alpha_{i}) = {IGamma} \left( \alpha_{i}|1,\frac{b_{i}}{2} \right) = \frac{b_{i}}{2}\alpha_{i}^{- 2}\exp\left( - \frac{b_{i}}{2}\frac{1}{\alpha_{i}} \right),$
```

where *b*[*i*], *i* = 1, 2, …, *N*, are scale hyperparameters. These two levels of hierarchy form a nonnegatively truncated multivariate Laplace prior over the abundance vector **θ**, which can be established by integrating out the precision **α** [84], that is,

```
$p(\mathbf{\theta}|\mathbf{b},\beta) = \prod\limits_{i = 1}^{l}\sqrt{\beta b_{i}}\exp\left( - \sqrt{\beta b_{i}}|\theta_{i}| \right)I_{\mathbb{R}_{+}^{l}}(\mathbf{\theta}),$
```
