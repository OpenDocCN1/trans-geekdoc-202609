

## 18.1

证明感知机算法在其逐模式操作模式下，在有限的迭代步数内收敛。假设 `θ^((0)) = 0`。

**提示**：注意由于假设类别是线性可分的，存在一个归一化超平面 `θ[*]` 和 `γ > 0`，使得

`γ ≤ y[n] θ[*]^T x[n], n = 1, 2, …, N`

其中 `y[n]` 是相应的标签，`ω[1]` 为 +1，`ω[2]` 为 −1。术语*归一化超平面*是指

```
θ[*]^T = [θ̂[*], θ[0*]]^T, with ||θ̂[*]|| = 1.
```

在这种情况下，`y[n] θ[*]^T x[n]` 是 `x[n]` 到超平面 `θ[*]` 的距离 [141]。
