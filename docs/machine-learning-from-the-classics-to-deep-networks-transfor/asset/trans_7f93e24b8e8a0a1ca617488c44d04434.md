回顾一下，我们的最终目标是能够从 *p*[**θ**](**x**[0]) 进行*采样*，该分布由公式 [(19.55)](#Chp019_997-1102_B9780443292385000251.xhtml#deq133) 给出。扩散方法背后的基本原理是，对于较小的 *β*[*t*] 值，*t* = 1, 2, …，扩散过程的逆过程与正向过程具有*相同*的函数形式，[169], [52]。因此，由于正向过程中的条件分布是高斯分布，反向过程中的条件分布也应为高斯分布。因此，训练的目标是优化相关参数 ***θ***，使得 *p*[**θ**](**x**[0], **x**[1], …, **x**[*T*]) 尽可能接近 *q*(**x**[0], **x**[1], …, **x**[*T*])。我们稍后将详细讨论这一点。

[图 19.22A 和 19.22B](#Chp019_997-1102_B9780443292385000251.xhtml#f0125) 分别展示了正向和反向过程。从略微不同的角度来看，正向过程可被视为*编码器*，反向过程则为*解码器*。然而，扩散模型的一个显著特征是，通过生成的潜在变量序列进行的编码，并非学习过程的结果，相反，正向过程遵循一个*固定*的马尔可夫链部署，逐渐向数据添加噪声。相比之下，例如在变分自编码器（第 [19.2.6](#Chp019_997-1102_B9780443292385000251.xhtml#s0065) 节）中，编码器中的潜在变量是从数据中学习得到的。
