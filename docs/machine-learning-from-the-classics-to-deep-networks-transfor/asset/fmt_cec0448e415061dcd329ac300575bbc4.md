[(12.16)](#Chp012_583-634_B9780443292385000184.xhtml#deq19) and for $\boldsymbol{\theta}_0 = \mathbf{0}$ is fully specified if we compute its mean and covariance matrix, using Eqs. [(12.19)](#Chp012_583-634_B9780443292385000184.xhtml#deq23) and [(12.20)](#Chp012_583-634_B9780443292385000184.xhtml#deq24), that is,

![](images/B9780443292385000184/fx007.jpg)

Compute the expected value of the log-likelihood associated with the complete data set; this is given by

$$\ln p(\boldsymbol{y}, \boldsymbol{\theta}; \boldsymbol{\xi}) := \ln p(\boldsymbol{y}, \boldsymbol{\theta}; \alpha, \beta) = \ln(p(\boldsymbol{y}|\boldsymbol{\theta}; \beta)p(\boldsymbol{\theta}; \alpha))$$

or

$$\ln p(\boldsymbol{y}, \boldsymbol{\theta}; \alpha, \beta) = \frac{N}{2}\ln\beta + \frac{K}{2}\ln\alpha - \frac{\beta}{2}\|\boldsymbol{y} - \Phi\boldsymbol{\theta}\|^2 - \frac{\alpha}{2}\boldsymbol{\theta}^T\boldsymbol{\theta} - \left( \frac{N}{2} + \frac{K}{2} \right)\ln(2\pi). \tag{12.45}$$

Treating the hidden parameters as random variables, the expected value of Eq. [(12.45)](#Chp012_583-634_B9780443292385000184.xhtml#deq58), with respect to $\boldsymbol{\theta}$, is carried out via the Gaussian posterior defined by Eqs. (12.43) and (12.44).
