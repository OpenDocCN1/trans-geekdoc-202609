
在建立了公式 [(4.71)](#Chp004_119-175_B978044329238500010X.xhtml#deq123) 中 `a[m]` 和 `b[m]` 之间的关系后，我们已准备好补全公式 [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114) 中缺失的步骤，即补全 `b[m]` 更新的阶递归步骤。由于公式 [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114) 对任意期望响应 `d[n]` 均成立，因此它也适用于最优滤波器为前向预测器 `a[m]` 这一特殊情况；在这种情况下，`d[n] = u[n + 1]`。在公式 [(4.66)](#Chp004_119-175_B978044329238500010X.xhtml#deq114) 中用 `a[m]` (`a[m - 1]`) 替换 `w[m]` (`w[m - 1]`) 可得

```
\mathbf{a}_{m} = \begin{bmatrix} \mathbf{a}_{m - 1} \\ 0 \\ \end{bmatrix} + \begin{bmatrix} {- J_{m - 1}\mathbf{a}_{m - 1}^{\ast}} \\ 1 \\ \end{bmatrix}k_{m - 1},
```

```
k_{m - 1} = \frac{r^{\ast}(m) - \mathbf{r}_{m - 1}^{H}J_{m - 1}\mathbf{a}_{m - 1}}{\alpha_{m - 1}^{b}}.
```
