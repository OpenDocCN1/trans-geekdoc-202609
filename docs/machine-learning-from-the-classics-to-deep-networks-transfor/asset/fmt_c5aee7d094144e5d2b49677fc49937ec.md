
In other words, the functional `ℱ(q, ξ)` is a lower bound of the log-likelihood function. Also, the bound becomes tight if `KL(q ∥ p) = 0`, which is true *if and only if* `q(X^(l)) = p(X^(l) | X; ξ)`. Moreover, the previous bound is valid for *all* distributions `q` and *all* parameters `ξ`.

The previous findings pave the way of maximizing `ln p(X; ξ)` by trying to maximize its lower bound. This is in line with a more general class of optimization algorithms, known as *minorize-maximization* (or mazorize-minimization) (MM) methods [20]. A surrogate function that minorizes the cost function (lower bound), which is easier to be maximized, is employed. Then maximizing this lower bound iteratively pushes the cost function to a local maximum. Note that in our case maximization of `ℱ` involves two terms, namely, `q` and `ξ`. We will adopt a widely used technique known as *alternating optimization*. Such an approach imposes an iterative procedure. Starting from some initial conditions, one "freezes" the value of one of the involved terms and maximizes with respect to the other. Then the value of the latter term is frozen and optimization is carried out with respect to the former. These alternating steps carry on until convergence. In our current context, starting from an arbitrary `ξ^((0))`, the `(j + 1)`th iteration comprises the following steps:

*   **Step 1:** Keeping `ξ^((j))` fixed, optimize with respect to `q`. This step tightens the lower bound in [(12.68)](#Chp012_583-634_B9780443292385000184.xhtml#deq89). This is achieved if `KL(q ∥ p) = 0`, and it can only happen if

    `q^((j + 1))(X^(l)) = p(X^(l) | X; ξ^((j)))`,

    (12.69)

    that is, if we set `q(X^(l))` equal to the posterior given `X` and `ξ^((j))`; as Eq. [(12.67)](#Chp012_583-634_B9780443292385000184.xhtml#deq88) suggests, this makes the bound tight, that is,

    `ln p(X; ξ^((j))) = ℱ(p(X^(l) | X; ξ^((j))), ξ^((j)))`,

    (12.70)
