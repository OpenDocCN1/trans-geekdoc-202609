

## 示例 2.4

考虑 AR(1) 过程：

$$u[n] + a u[n-1] = \eta[n].$$

遵循前面解释的一般方法，我们有：

$$r(k) + a r(k-1) = 0, \quad k = 1, 2, \dots$$

$$r(0) + a r(1) = \sigma_{\eta}^2.$$

取第一个方程的 $k=1$ 情况并结合第二个方程，可直接得出：

$$r(0) = \frac{\sigma_{\eta}^{2}}{1 - a^{2}}.$$

将此值代入差分方程，我们递归地得到：

$$r(k) = (-a)^{|k|} \frac{\sigma_{\eta}^{2}}{1 - a^{2}}, \quad k = 0, \pm 1, \pm 2, \dots \tag{2.144}$$

注意，AR($l$) 和 MA($m$) 模型可被视为 ARMA($l, m$) 的特例。关于该主题更理论化的处理，请参见 [1]。
