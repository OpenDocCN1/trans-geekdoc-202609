

## GAN 目标函数推导

$$J(G, D) = \int_{\mathbf{x}} p_r(\mathbf{x})\ln(D(\mathbf{x}))d\mathbf{x} + \int_{\mathbf{z}} p_{\mathbf{z}}(\mathbf{z})\ln(1-D(G(\mathbf{z})))d\mathbf{z} = \int_{\mathbf{x}} (p_r(\mathbf{x})\ln(D(\mathbf{x})) + p_g(\mathbf{x})\ln(1-D(\mathbf{x})))d\mathbf{x}$$

![Equation](images/B9780443292385000251/si83.png)

其中下标 $g$ 代表与**生成器**输出相关的分布。固定函数 $G$（等价于固定概率分布函数 $p_g$），通过对被积函数关于函数 $D$ 求导并令其等于零，可以很容易地推导出判别器输出概率函数 $D$ 的最优值（[问题 19.3](#Chp019_997-1102_B9780443292385000251.xhtml#o0055)）。很容易证明：

$$D^* = \frac{p_r}{p_r + p_g}$$
