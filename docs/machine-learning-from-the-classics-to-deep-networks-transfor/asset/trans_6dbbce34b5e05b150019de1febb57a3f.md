交叉熵损失函数的另一种表述形式称为*相对熵*，有时也会被采用，即

$J = - \sum\limits_{n = 1}^{N}\sum\limits_{k = 1}^{k_{L}}y_{nk}\ln\frac{{\widehat{y}}_{nk}}{y_{nk}}.$

![Equation](images/B978044329238500024X/si282.png)(18.43)

这种表述形式引出了与 Kullback-Leibler (KL) 散度（第 [2.5.2](#Chp002_19-64_B9780443292385000081.xhtml) 节）的亲和性，后者用于度量概率（分布）之间的偏差。在我们的语境下，它度量 $y_{nk}$ 与 $\widehat{y}_{nk}$ 的差异程度。
