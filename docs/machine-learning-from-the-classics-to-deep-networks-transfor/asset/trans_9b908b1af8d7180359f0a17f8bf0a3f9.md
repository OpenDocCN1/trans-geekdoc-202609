
我们已经看到，当涉及的随机变量是离散时，与贝叶斯图结构节点相关的条件概率 `P(x[i]|Pa[i])`，`i = 1, …, l`，必须从训练数据中学习。如果 `Pa[i]` 中可能状态的数量和/或变量的数量足够大，这将意味着需要学习大量的概率；因此，需要大量的训练点才能获得良好的估计。这可以通过以参数形式表达条件概率来缓解，即

```
P(x[i]|Pa[i]) = P(x[i]|Pa[i]; θ[i]),  i = 1, 2, …, l.
```

对于二值变量，一种常见的函数形式是将 `P` 视为逻辑回归模型；我们在 [第 13 章](#Chp013_635-716_B9780443292385000196.xhtml) 相关向量机的背景下使用过该模型。采用该模型，我们有
