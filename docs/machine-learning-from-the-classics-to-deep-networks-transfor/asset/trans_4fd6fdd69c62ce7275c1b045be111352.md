

### 系统模型

$$y[n] = \mathbf{x}^T[n]\boldsymbol{\theta}[o, n-1] + \eta[n] \tag{6.74}$$

其中 $l = 5$，未知向量为时变向量。根据以下模型生成未知向量：

$$\boldsymbol{\theta}[o, n] = \alpha\boldsymbol{\theta}[o, n-1] + \boldsymbol{\omega}[n]$$

其中 $\alpha = 0.97$，$\boldsymbol{\omega}[n]$ 的系数为独立同分布（i.i.d.），服从均值为零、方差为 0.1 的高斯分布。初始值 $\boldsymbol{\theta}[o, 0]$ 按照 $\mathcal{N}(0, 1)$ 生成。

### 仿真设置 1

噪声样本为 i.i.d.，均值为零，方差为 0.001。输入样本服从高斯分布 $\mathcal{N}(0, 1)$。对比 NLMS 和 RLS 算法的性能。

- **NLMS 参数**：$\mu = 0.5$，$\delta = 0.001$
- **RLS 参数**：遗忘因子 $\beta = 0.995$

运行 200 次独立实验，绘制平均误差随迭代次数变化的曲线（单位：dB），即 $10\log_{10}(e^2[n])$，其中

$$e^2[n] = (y[n] - \mathbf{x}^T[n]\boldsymbol{\theta}[n-1])^2$$

对比两种算法的性能。
