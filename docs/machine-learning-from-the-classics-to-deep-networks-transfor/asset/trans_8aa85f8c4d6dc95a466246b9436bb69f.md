人们很容易看出，将上述版本的交叉熵函数与逻辑斯蒂 S 型非线性相结合，可以使第 *k* 个输出神经元的突触权重的代价梯度“摆脱”对相应激活函数导数的依赖。很容易证明（问题 [18.7](#Chp018_885-995_B978044329238500024X.xhtml#o0050)）

```
\frac{\partial J}{\partial\mathbf{\theta}_{j}^{L}} = \sum\limits_{n = 1}^{N}\delta_{nj}^{L}\mathbf{y}_{n}^{L - 1},\ j = 1,2,\ldots,k_{L},
```

其中，对于公式 [(18.41)](#Chp018_885-995_B978044329238500024X.xhtml#deq77) 中的交叉熵损失，`δ[nj]^(L) = y[nj](ŷ[nj] − 1)`；而对于公式 [(18.44)](#Chp018_885-995_B978044329238500024X.xhtml#deq80) 的情况，`δ[nj]^(L) = ŷ[nj] − y[nj]`。请注意，`y[n]^(L − 1)` 是最后一隐藏层 `L − 1` 的输出向量。
