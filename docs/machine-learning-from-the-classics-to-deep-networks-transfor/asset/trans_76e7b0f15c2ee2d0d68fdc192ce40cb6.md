

## 预处理输入特征/变量

建议对输入变量进行预处理，使其在训练集上具有（近似）零均值。此外，应对它们进行缩放，使其都具有相似的方差，这假设所有变量同等重要。如果所用的非线性函数属于压缩类型，建议其方差也应与激活（压缩）函数的取值范围相匹配。而且，如果输入变量不相关，则有利于算法的收敛。实现这一点的一种方法是通过适当的变换，例如 `PCA`。

## 选择对称激活函数

在采用压缩类型激活函数的情况下，希望神经元的输出以同等概率取正值和负值。毕竟，一层的输出将成为下一层的输入。为此，可以使用公式 [(18.8)](#Chp018_885-995_B978044329238500024X.xhtml#deq16) 中的双曲激活函数。推荐值为 `a = 1.7159` 和 `c = 4/3`。这些值保证了如果输入按前述建议进行预处理，即归一化为方差等于 1，则激活函数输出的方差也等于 1，且相应的均值等于零。然而，正如我们很快将在第 [18.6.1](#Chp018_885-995_B978044329238500024X.xhtml#s0110) 节中看到的，目前此类激活函数似乎不太流行。

## 目标值

目标值的选择应仔细考虑，以与所用的激活函数保持一致。这些值的选择应使压缩函数的极限值偏移一小部分。否则，算法倾向于将权重推向大值，这会减慢收敛速度；激活函数被驱动至饱和区，导致激活函数的导数变得非常小，进而导致梯度值变小。对于双曲正切函数，使用前述讨论的参数，目标类别标签选择 `±1` 似乎是正确的。注意，在这种情况下，饱和值为 `a = ±1.7158`。在第 [18.5](#Chp018_885-995_B978044329238500024X.xhtml#s0100) 节中，我们将看到输出激活函数的选择应由所采用的最优性准则决定。

## 初始化

在训练神经网络时，任何优化方案的权重参数初始化都至关重要。从一组“错误”的值开始会对训练产生许多不良影响。初始化会影响算法收敛的快慢。此外，初始值在算法是收敛到低代价点还是高代价点（良好或不良的局部极小值）方面起着关键作用。此外，泛化性能也可能受初始化影响。然而，必须指出的是，与这些问题相关的理论基础尚不清晰，许多概念尚未被充分理解，目前仍构成正在进行的研究领域（另见第 [18.11.1](#Chp018_885-995_B978044329238500024X.xhtml#s0145) 节的讨论）。

权重被随机初始化为某些 `small values`（较小值）。为此，已经开发了许多不同的方案，这从使用标准相关软件包时提供的众多选项中可见一斑。

例如，如果使用压缩类型的激活函数并分配较大的初始值，则所有激活函数都将在其饱和点处工作。这会将梯度驱动至非常小的值，进而减慢收敛。当权重初始化为非常小的值时，对梯度的影响是相同的。初始化必须使每个神经元的运算发生在激活函数图的（近似）线性区域，而不是饱和区域。可以证明（[113]，问题 [18.4](#Chp018_885-995_B978044329238500024X.xhtml#o0035)），如果输入变量预处理为零均值和单位方差，并使用前述讨论参数值的双曲正切函数，则初始化权重的最佳选择是从零均值和标准差等于以下值的分布中抽取数值赋予权重：

```
σ = m_in^(-1/2)
```

其中 `m_in` 是相应神经元中的输入（突触连接）数量。

初始化期间的一个关键问题是所谓的神经元间 `symmetry breaking`（对称性打破）。很容易证明，如果两个隐藏神经元使用相同的激活函数（通常情况如此）并连接到相同的输入，那么如果它们用相同的值初始化，它们的梯度将相等，且在下降迭代后其更新值将保持相等。毫无疑问，这是一种导致冗余的不良效应。这就是为什么将所有初始值设为零不是一个好习惯。随机初始化有助于避免此类情况。另一方面，试图避免大值符合试图避免所谓的 `exploding gradient phenomenon`（梯度爆炸现象），这是反向传播固有的（见第 [18.6](#Chp018_885-995_B978044329238500024X.xhtml#s0105) 节）。因此，建议从较小的随机值开始。

为实现上述目的，可能的方案包括均匀分布或高斯分布。例如，文献 [50] 建议通过均匀分布初始化权重
