

从这个角度来看，很容易理解为什么在增加更多层时，训练误差不应该增加。在最坏的情况下，当所有信息都已提取到第 *r* 层时，我们预期增加一层额外的层应该实现恒等映射，即 **y**^(*r*) = *H*(**y**^(*r*−1)) = **y**^(*r*−1)。也就是说，额外的层不添加任何信息，只是将输入简单地复制到输出。然而，一旦网络变得非常深，准确率似乎会“饱和”，优化工具很难在可行的时间内找到足够精确的恒等映射解。

![Figure 18.32 When a network is very deep, it turns out that the training error starts increasing when the number of layers exceeds some number, instead of being decreased (red curve) as expected from theory.](images/B978044329238500024X/gr032.jpg)

**图 18.32** 当网络非常深时，训练误差会在层数超过某个数值时开始增加，而不是像理论预期的那样减小（红色曲线）。

绕过这一困难的一种方法在文献 [67] 中提出。其思路是拟合一个替代的等效映射，即

*F*(**y**^(*r*−1)) = *H*(**y**^(*r*−1)) − **y**^(*r*−1)。

于是原始映射 *H*(**y**^(*r*−1)) 就等于 *F*(**y**^(*r*−1)) + **y**^(*r*−1)。实践表明，针对残差映射 *F* 进行优化比针对原始映射 *H* 进行优化更容易。在极端情况下，当需要实现恒等映射时，似乎将残差推向零比拟合恒等映射更容易。

残差表示的使用并非新事物，之前已在矢量量化的背景下使用过。残差学习的核心在于引入所谓的*残差*构建模块，如**图 18.33**所示。这样，若干层（如图所示为两层）被堆叠在一起，并通过所谓的捷径连接或跳跃连接，*显式地*让这些层去拟合残差映射。每个权重层对其输入执行变换，例如卷积。如果 **y**^(*r*) 和 **y**^(*r*−1) 维度不同，则恒等映射捷径会被修改为 *W***y**^(*r*−1)，其中 *W* 是一个维度合适的矩阵。

![Figure 18.33 Two successive layers in a network have been combined and their implied combined transformation is performed via the identity mapping, implemented by the red line shortcut/skip connection.](images/B978044329238500024X/gr033.jpg)

**图 18.33** 网络中的两个连续层被组合在一起，它们隐含的组合变换通过恒等映射来执行，由红线捷径/跳跃连接实现。

**图 18.34**A 示出了一个所谓的纯净网络（不涉及残差）的示意图示例，该网络由一系列卷积层组成。其残差对应版本如**图 18.34**B 所示。注意，如果使用恒等捷径，则不涉及额外参数，训练遵循标准的反向传播原理。残差网络的一种变体，称为*高速公路*网络，已被提出（例如 [60,184]），其中引入了额外的数据依赖门控函数来控制捷径中的信息流动。

![Figure 18.34 (A) The layout of a plain network and (B) the corresponding layout with the use of shortcuts.](images/B978044329238500024X/gr034.jpg)

**图 18.34** (A) 纯净网络的布局和 (B) 使用捷径后的相应布局。

文献 [67] 中构建了深达 50 到 152 层的网络。尽管规模如此之大，据报道其算术运算的总数仍远低于 VGG-16 所需的数量，而在错误率方面性能却有所提升。文献 [202] 将残差网络的概念与 Inception 网络的概念相结合。据报道，使用残差连接进行训练可以显著加速 Inception 网络的训练。
