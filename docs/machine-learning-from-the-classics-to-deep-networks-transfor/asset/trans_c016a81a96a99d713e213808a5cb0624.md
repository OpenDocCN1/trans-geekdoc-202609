

公式 [(4.5)](#Chp004_119-175_B978044329238500010X.xhtml#deq7) 中的正规方程现在呈现以下形式

`Σ_u w = p`

其中

`p = [E[u[n]d[n]], …, E[u[n−l+1]d[n]]]^T`

而输入过程的相应协方差/自相关矩阵（阶数为 `l`）由下式给出

```
Σ_u := E[u_n u_n^T] = 
[ r(0)   r(1)   …   r(l-1) ]
[ r(1)   r(0)   …   r(l-2) ]
[  ⋮                ⋱      ]
[ r(l-1) r(l-2) …   r(0)   ]
```

(4.43)

其中 `r(k)` 是输入过程的自相关序列。因为我们已经假设所涉及的过程是宽平稳的，所以我们有

`r(n, n−k) := E[u[n]u[n−k]] = r(k)`

此外，请回顾，对于实宽平稳过程，自相关序列是对称的，即 `r(k) = r(−k)`（第 [2.4.3](#Chp002_19-64_B9780443292385000081.xhtml) 节）。请注意，在输入向量源自随机过程的这种情况下，协方差矩阵具有特殊结构，稍后将利用这一结构推导出求解正规方程的高效方案。
