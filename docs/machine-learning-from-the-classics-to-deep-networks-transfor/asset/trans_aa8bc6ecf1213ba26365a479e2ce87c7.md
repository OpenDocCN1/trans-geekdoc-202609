### 1. 拒绝采样中的常数计算

设 **x** ∈ ℝˡ。为了通过拒绝采样方法使用 *q*(**x**) 从 *p*(**x**) 中抽取样本，必须计算一个常数 *c*，使得：

```
c * q(x) ≥ p(x)
```

#### 1.1 证明下界

证明：

```
c ≥ (σ_q / σ_p)ˡ
```

#### 1.2 计算接受概率

计算接受样本的概率。
