
在确立了 DP 的离散性和聚类特性之后，现在让我们看看如何将其用作先验，以对混合分布进行贝叶斯学习，例如高斯混合建模。我们的框架将是非参数设置；也就是说，混合成分的数量*不是*先验固定的。这迫使我们用*分布上的先验*来替代固定数量参数上的先验。一旦获得观测值，贝叶斯学习原理提供了将先前的*先验*信息更新为与*后验*分布相关信息的工具。

假设我们得到一组观测值，**x**[*n*] ∈ ℝ^(*l*)，*n* = 1, 2, …, *N*。我们假设它们中的每一个都是由相应的概率密度函数（分布）发射的，该函数由一组相应的隐变量参数化，**θ**[1], **θ**[2], …, **θ**[*N*] ∈ *Θ*。即，**x**[*n*] ∼ *p*(**x**|**θ**[*n*])。请注意，参数集合随着 *N* 的增长而增长，这与第 [13.4](#Chp013_635-716_B9780443292385000196.xhtml#s0040) 节混合建模中使用的固定数量参数形成对比。反过来，我们假设这些参数是从一个分布 *G* 中独立同分布（i.i.d.）抽取的，而 *G* 本身则是从一个 DP 中抽取的（参见，例如 [3]）。总之，根据该混合模型的数据生成过程描述如下：

请注意，由于 *G* 是离散的且具有很强的聚类结构，许多观测样本 **x**[*n*] 将共享相同的隐参数，这就是 DP 先验施加混合建模的方式。

如果采用棒打破构造，上述三个基本步骤将被“重述”，数据生成机制描述如下：

1.  抽取 Beta 变量，`β[i] ∼ Beta(β|1, α)`，`i = 1, 2, …`。
2.  生成概率值，`P_i = β_i ∏_{j=1}^{i-1} (1 - β_i)`，`i = 2, 3, …`，其中 `P_1 = β_1`。
3.  从基分布中抽取相应的参数，`θ[i] ∼ G_0`，`i = 1, 2, …`。
4.  对于所有观测值 **x**[*n*]，`n = 1, 2, …, N`，执行：
    *   `k[n] ∼ Cat(P_1, P_2, …)`。
