
换言之，`λ₁₂ = 1` 且 `λ₂₁ = 0.8`。这两个类别被视为等概率。推导阈值 `xᵣ`，它将特征空间 `ℝ` 划分为两个区域 `ℛ₁`、`ℛ₂`，在这两个区域中我们分别判定为类别 `ω₁` 和 `ω₂`。当使用贝叶斯分类器时，阈值是多少？

解：根据平均风险准则，判定为类别 `ω₁` 的区域由下式给出

```
ℛ₁: λ₁₂ * (1/2) * p(x|ω₁) > λ₂₁ * (1/2) * p(x|ω₂),
```

相应的阈值 `xᵣ` 由以下方程计算得出

```
exp(-xᵣ²/2) = 0.8 * exp(-(xᵣ - 1)²/2),
```

对两边取对数并求解该方程后，简单地得到

```
xᵣ = (1/2)(1 - 2 ln 0.8).
```

若令 `λ₂₁ = 1`，则得到贝叶斯分类器的阈值为

```
x_B = 1/2.
```
