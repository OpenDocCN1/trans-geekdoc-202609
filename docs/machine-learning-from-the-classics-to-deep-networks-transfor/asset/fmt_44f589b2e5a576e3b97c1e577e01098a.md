**Figure 3.10** In the Bayesian inference approach, note that as the number of observations increases, our uncertainty about the true value of the unknown parameter is reduced and the mean of the posterior PDF tends to the true value and the variance tends to zero.

It should be pointed out that in this example case, the ML and LS estimates become identical, or

$$\widehat{\theta} = \frac{1}{N}\sum\limits_{n = 1}^{N}y_{n} = {\overline{y}}_{N}.$$

![Equation](images/B9780443292385000093/si362.png)

This will also be the case for the mean value in Eq. [(3.69)](#Chp003_65-117_B9780443292385000093.xhtml#deq120) if we set `\sigma_0^2` very large, as might happen if we have no confidence in our initial estimate of `\theta_0` and we assign a very large value to `\sigma_0^2`. In effect, this is equivalent to using no prior information.

Let us now investigate what happens if our prior knowledge about `\theta_0` is “embedded” in the LS criterion in the form of a constraint. This can be done by modifying the constraint in Eq. [(3.40)](#Chp003_65-117_B9780443292385000093.xhtml#deq73) such that

$$(\theta - \theta_0)^2 \le \rho,$$

![Equation](images/B9780443292385000093/si364.png) (3.71)

which leads to the equivalent minimization of the following Lagrangian:

$$\text{minimize}\quad L(\theta,\lambda) = \sum\limits_{n = 1}^{N}{(y_n - \theta)}^{2} + \lambda\left( {(\theta - \theta_0)}^{2} - \rho \right).$$

![Equation](images/B9780443292385000093/si365.png) (3.72)

Taking the derivative with respect to `\theta` and equating to zero, we obtain

$$\widehat{\theta} = \frac{N{\overline{y}}_{N} + \lambda\theta_0}{N + \lambda},$$

![Equation](images/B9780443292385000093/si366.png)

which, for `\lambda = \sigma_\eta^2/\sigma_0^2`, becomes identical to Eq. [(3.69)](#Chp003_65-117_B9780443292385000093.xhtml#deq120). The world is small after all! This has happened only because we used Gaussians both for the conditional and for the prior PDFs. For different forms of PDFs, this would not be the case. However, this example shows that a close relationship ties priors and constraints. They both attempt to impose prior information. Each method, in its own unique way, is associated with the respective pros and cons. In Chapters [12](#Chp012_583-634_B9780443292385000184.xhtml) and [13](#Chp013_635-716_B9780443292385000196.xhtml), where a more extended treatment of the Bayesian inference task is provided, we will see that the very essence of regularization, which is a means against overfitting, lies at the heart of the Bayesian approach.
