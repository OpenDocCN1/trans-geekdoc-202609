
*y*[*n*] = **x**[*n*]^(*T*)**θ**[*o*, *n* − 1] + *η*[*n*],

其中

**θ**[*o*, *n*] = *α***θ**[*o*, *n* − 1] + **ω**[*n*],

且 **θ**[*o*, *n*] ∈ ℝ⁵。事实证明，如果将构成 **θ**[*o*, *n*] 的参数视为此类信道的冲激响应，那么这种时变模型与通信领域中所谓的瑞利衰落信道密切相关（前提是涉及的参数选择得当）[57]。瑞利衰落信道非常常见，且能充分建模无线通信中的多种传输信道。通过调整参数 *α* 以及相应噪声源 **ω** 的方差，可以实现快时变或慢时变场景。在我们的例子中，我们选择了 *α* = 0.97，且噪声服从零均值、协方差矩阵为 *Σ*[*ω*] = 0.1*I* 的高斯分布。

关于数据生成，输入样本从高斯分布 𝒩(0, 1) 中独立同分布生成，噪声也是零均值、方差为 *σ*[*η*]² = 0.01 的高斯分布。时变模型的初始化（**θ**[*o*, 0]）是通过从 𝒩(0, 1) 中抽取样本随机完成的。
