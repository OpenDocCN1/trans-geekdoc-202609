
For **x** = 0, Eq. [(13.81)](#Chp013_635-716_B9780443292385000196.xhtml#deq118) becomes *g*(0) = −*f*^(\*)(**ξ**). This is illustrated in [Fig. 13.10](#Chp013_635-716_B9780443292385000196.xhtml#f0060). Thus, *f*^(\*)(**ξ**) corresponds to the displacement that the graph of **ξ**^(*T*)**x** has to undergo in order to “touch” that of *f*(**x**). A by-product of all this turns out to be very useful for us. It can be shown (Problem [13.16](#Chp013_635-716_B9780443292385000196.xhtml#o0180)) that if *f* is a convex function, then (*f*^(\*))^(\*) = *f* and in this case we can write

```
f(\mathbf{x}) = \max\limits_{\mathbf{\xi}}\left\{ \mathbf{x}^{T}\mathbf{\xi} - f^{\ast}(\mathbf{\xi}) \right\}.
```

Thus, once *f*^(\*) is computed, a lower bound for *f* becomes readily available, that is,

*f*(**x**) ≥ **x**^(*T*)**ξ** − *f*^(\*)(**ξ**),

where now **ξ** is interpreted as a parameter. To investigate this bound a bit further, we plug Eqs. [(13.79)](#Chp013_635-716_B9780443292385000196.xhtml#deq115) and [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116) into Eq. [(13.83)](#Chp013_635-716_B9780443292385000196.xhtml#deq120) to obtain^([^(95)](#fn95))

*f*(**x**) ≥ *f*(**x**[\*]) + (**x** − **x**[\*])^(*T*)∇*f*(**x**[\*]),

where the right-hand side is the linear function *g*(**x**) describing the hyperplane tangent to *f*(**x**) at **x**[\*]. The bound becomes tight at **x** = **x**[\*] (see [Fig. 13.10](#Chp013_635-716_B9780443292385000196.xhtml#f0060)). We will soon see how we can make this linear function a bound for a nonlinear one; it suffices to transform the argument of the function.
