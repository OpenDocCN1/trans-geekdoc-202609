
#### 预测分布与波利亚(Pólya) urn模型

现在让我们建立在公式[(13.116)](#Chp013_635-716_B9780443292385000196.xhtml#deq177)中的后验DP公式之上。为此，将遵循文献[83]提供的推理。在观测到样本**θ**[1], …, **θ**[*n*]之后，我们关注下一次抽取**θ**[*n* + 1]，并将计算该样本落在区间*T*内的概率。为简化符号，让我们用*G*′表示后验*G*|**θ**[1], …, **θ**[*n*]。然后我们写出

*P*(**θ**[*n* + 1] ∈ *T*|**θ**[1], …, **θ**[*n*]) = *G*′(*T*)。
