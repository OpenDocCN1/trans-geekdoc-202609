
*y*[2] = *x*[21]*θ*[1] + *x*[22]*θ*[2] + *x*[23]*θ*[3].

![Equation](images/B9780443292385000159/si146.png)

现在解位于前两个平面的交集上，这是一条直线。然而，现在对于唯一解我们有更多的选择。例如，一条直线 *Θ*[1] 可以在 ℓ[1] 球的一个顶点处相切（1-稀疏解），或者如[图 9.8](#Chp009_417-462_B9780443292385000159.xhtml#f0050)B 所示，在其边之一处相切，例如 *Θ*[2]。后一种情况对应于位于二维子空间上的解；因此它将是一个 2-稀疏向量。这也符合[备注 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0035) 中所述的发现，因为在这种情况下我们有 *N* = 2，*l* = 3，而唯一解的稀疏度水平可以是 1 或 2。

请注意，唯一性与仿射集的特定几何形状和方向有关，仿射集是欠定方程组所有可能解的集合。对于平方 ℓ[2] 范数的情况，解总是唯一的。这是由欧几里得范数形成的（超）球形形状导致的。从数学角度来看，平方 ℓ[2] 范数是一个严格凸函数。对于 ℓ[1] 范数则不然，它是凸函数，但不是严格凸函数（问题 [9.13](#Chp009_417-462_B9780443292385000159.xhtml#o0090)）。
