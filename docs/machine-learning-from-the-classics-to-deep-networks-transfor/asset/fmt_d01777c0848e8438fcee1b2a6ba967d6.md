
在前几章中，我们讨论了开发递归算法的必要性，即每当接收到一对新的输入-输出观测值时，就更新估计值。使用通用求解器求解最小二乘（LS）问题，由于涉及矩阵求逆，将需要 𝒪(*l*³) 次乘法和加法运算（MADS）。此外，计算（缩放）样本协方差矩阵 *X*^(*T*)*X* 需要 𝒪(*N**l*²) 次运算。在本节中，将考虑 *X*^(*T*)*X* 的特殊结构，以获得一种计算高效的在线方案来求解 LS 任务。此外，在处理时域递归技术时，也可以关注所涉及数据统计特性的时间变化。我们将允许此类应用，并将平方误差和代价函数稍作修改，以适应时变环境。

为了本节的需要，我们的符号将略作“丰富”，并将显式使用时间索引 *n*。此外，为了与第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章讨论的在线方案保持一致，我们将假设时间从 *n* = 0 开始，接收到的观测值为 (*y*[*n*], **x**[*n*]), *n* = 0, 1, 2, …。为此，让我们将时间 *n* 的输入矩阵表示为

*X*[*n*]^(*T*) = [**x**[0], **x**[1], …, **x**[*n*]]。

此外，公式 [(6.1)](#Chp006_249-291_B9780443292385000123.xhtml#deq2) 中的代价函数被修改为包含一个*遗忘因子*，0 < *β* ≤ 1。其存在的目的是通过加重更近期的观测值，帮助代价函数缓慢地“遗忘”过去的数据样本。这将使算法具备跟踪底层数据统计特性变化的能力。此外，由于我们对时域递归解感兴趣，从时间 *n* = 0 开始，我们被迫引入正则化。在初始阶段，对应于时间瞬间 *n* < *l* − 1，相应的方程组将是欠定的，且 *X*[*n*]^(*T*)*X*[*n*] 不可逆。确实，我们有

```
$X\_{n}^{T}X\_{n} = \\sum\\limits\_{i = 0}^{n}\\mathbf{x}\_{i}\\mathbf{x}\_{i}^{T}.$
```
