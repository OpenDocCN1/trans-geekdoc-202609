
此外，即使数据服从高斯分布，采用逻辑回归公式而不是公式 [(7.36)](#Chp007_293-342_B9780443292385000135.xhtml#deq62) 中的公式可能仍然更可取。在后一种公式中，必须估计协方差矩阵，这相当于 `𝒪(l²/2)` 个参数。逻辑回归公式仅涉及 `l + 1` 个参数。也就是说，一旦我们知道对数比率对 `x` 的线性依赖关系，就可以利用这一先验信息来简化模型。当然，假设高斯假设成立，如果能获得协方差矩阵的良好估计，利用这一额外信息可以得到更有效的估计，即方差更低。文献 [12] 讨论了这一问题。这是很自然的，因为利用了关于数据分布的更多信息。在实践中，事实证明，总体而言，使用逻辑回归比使用线性判别分析（LDA）更稳妥。

参数向量 `θ` 是通过将最大似然（ML）方法应用于训练样本集 `(y[n], x[n])`、`n = 1, 2, …, N`、`y[n] ∈ {0, 1}` 来估计的。似然函数可以写为

```
P(y_1,...,y_N; θ) = ∏_{n=1}^N (σ(θ^T x_n))^{y_n} (1 - σ(θ^T x_n))^{1 - y_n}.  (7.37)
```

确实，如果 `x[n]` 来自类别 `ω[1]`，则 `y[n] = 1`，相应的概率由 `σ(θ^T x[n])` 给出。另一方面，如果 `x[n]` 来自 `ω[2]`，则 `y[n] = 0`，相应的概率由 `1 - σ(θ^T x[n])` 给出。假设连续观测值之间相互独立，似然函数即为相应概率的乘积。
