
## Adam 算法

Adam 更新公式为：

$$
\theta_{d}^{(i)} = \theta_{d}^{(i - 1)} - \frac{\mu}{\sqrt{\widehat{v}_{d}^{(i)}} + \epsilon}\widehat{m}_{d}^{(i)},\quad d = 1,2,\ldots,D.
$$

![Equation](images/B978044329238500024X/si228.png)

Adam 方案详见 [Algorithm 18.3](#Chp018_885-995_B978044329238500024X.xhtml#enun0040)。

### Algorithm 18.3: The Adam algorithm

**Initialization**

1.  Initialize `θ^((0))`.
    ![Equation](images/B978044329238500024X/si17.png)

2.  Initialize `v^((0)) = 0`, `m^((0)) = 0`.
    ![Equation](images/B978044329238500024X/si218.png)
    ![Equation](images/B978044329238500024X/si229.png)

3.  Select step size `μ`; Typical value 0.001.

4.  Select `β₁` and `β₂`; Typical values 0.9 and 0.999, respectively.
    ![Equation](images/B978044329238500024X/si225.png)
    ![Equation](images/B978044329238500024X/si226.png)

5.  Select `ϵ`; Typical value 10⁻⁸.
    ![Equation](images/B978044329238500024X/si216.png)

6.  Set `i = 0`.
    ![Equation](images/B978044329238500024X/si230.png)

**While** a stopping criterion not met **Do**

1.  Select a mini-batch of `K` samples, e.g.,
    `(y_((m−1)K+1), x_((m−1)K+1)), …, (y_(mK), x_(mK))`.
    ![Equation](images/B978044329238500024X/si231.png)

2.  Compute the gradient:
    $$
    \mathbf{g} = \frac{\partial J^{(m)}}{\partial \mathbf{\theta}}\Big|_{\mathbf{\theta}^{(i-1)}}
    $$
    (see Eq. [(18.32)](#Chp018_885-995_B978044329238500024X.xhtml#deq46)).
    ![Equation](images/B978044329238500024X/si232.png)

3.  `i = i + 1`.
    ![Equation](images/B978044329238500024X/si33.png)
