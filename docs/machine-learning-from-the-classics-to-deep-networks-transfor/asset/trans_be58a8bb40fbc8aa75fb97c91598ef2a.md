
在本节研究的情况下，假设 `p(y|θ)` 和 `p(θ)` 均为高斯分布，`p(y)` 可以解析地求得；结果表明联合分布 `p(y, θ)` 也是高斯分布，因此边缘分布 `p(y)` 也是高斯分布。所有这些都在本章附录中详细展示。确实，如果我们在附录的公式 (12.146) 和 (12.151) 中令 `z → θ`、`t → y` 以及 `A → Φ`，对于公式 [(12.3)](#Chp012_583-634_B9780443292385000184.xhtml#deq5) 的回归模型、公式 [(12.8)](#Chp012_583-634_B9780443292385000184.xhtml#deq11) 的先验 PDF 以及公式 [(12.2)](#Chp012_583-634_B9780443292385000184.xhtml#deq4) 的噪声模型，我们得到

```
p(y) = N(y|Φθ[0], Σ[η] + ΦΣ[θ]Φ^(T)).
```

此外，后验 `p(θ|y)` 也是高斯分布，

```
p(θ|y) = N(θ|μ[θ|y], Σ[θ|y]),
```

其中 `μ[θ|y]` 由公式 [(12.10)](#Chp012_583-634_B9780443292385000184.xhtml#deq13) 给出，协方差矩阵源自公式 (12.147)，在进行适当的符号替换后，即

```
Σ[θ|y] = (Σ[θ]^(−1) + Φ^(T) Σ[η]^(−1) Φ)^(−1).
```
