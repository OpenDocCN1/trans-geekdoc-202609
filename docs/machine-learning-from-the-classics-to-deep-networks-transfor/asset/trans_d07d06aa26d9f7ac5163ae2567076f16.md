

蝙蝠回声定位叫声的时频分析提供了关于物种（物种识别）的信息，以及蝙蝠在特定环境中的具体任务和行为。此外，对蝙蝠生物声纳系统的研究旨在让人类更多地了解自然，并为声纳导航系统、雷达和医用超声设备等应用的后续进步获取灵感。

[图 10.16](#Chp010_463-518_B9780443292385000160.xhtml#f0085) 展示了一个蝙蝠记录回声定位信号的案例。在信号的两个不同部分进行缩放，我们可以观察到频率随时间变化。在[图 10.17](#Chp010_463-518_B9780443292385000160.xhtml#f0090)中，展示了信号的 DFT，但除了信号在频域可压缩这一信息外，无法从中得出太多有用信息；大部分活动发生在一个短频率范围内。回声定位信号是一段总长度为 `T = 21.845 ms` 的记录 [75]。采样频率为 `f[s] = 750 kHz`，共得到 `l = 16,384` 个样本。尽管信号本身在时域上并非稀疏，但我们将利用其在变换域中稀疏这一事实。我们将假设该信号在 Gabor 字典展开下是稀疏的。

本例的目标是证明执行时频分析并不真正需要所有 16,384 个样本；通过利用压缩感知理论，所有处理均可使用减少数量的观测值来完成。为了形成观测向量 `y`，观测数量选为 `N = 2048`。这相对于可用样本数量减少了八倍。观测向量形成如下：

```
y = Xs
```

其中 `X` 是一个 `N × l` 的感知矩阵，由随机生成的 ±1 组成。这意味着一旦获得 `y`，就不再需要存储原始样本，从而节省了内存需求。理想情况下，正如第 [9.9](#Chp009_417-462_B9780443292385000159.xhtml) 节末尾所讨论的，可以通过以亚奈奎斯特速率直接对模拟信号采样来获得减少数量的观测值。另一个目标是同时使用分析模型和综合模型，并演示它们的区别。

计算了三种不同的频谱图。其中两种如[图 10.18](#Chp010_463-518_B9780443292385000160.xhtml#f0095)B 和 C 所示，分别对应通过分析 [(10.37)](#Chp010_463-518_B9780443292385000160.xhtml#deq103) 和综合 [(9.37)](#Chp009_417-462_B9780443292385000159.xhtml) 公式获得的重构信号。这两种情况均使用了 NESTA 算法和 `G(128, 64)` 框架。注意，后一种字典的冗余度为 2 倍。频谱图是绘制时频网格并根据 Gabor 字典中相应原子关联参数的能量 `|θ|²` 对每个节点 `(t, i)` 着色而得。对重构信号应用完整 Gabor 变换以获得频谱图，旨在更好地覆盖时频网格。刻度为对数制，颜色越深的区域对应值越大。通过完整 Gabor 变换获得的原始信号频谱图如[图 10.18](#Chp010_463-518_B9780443292385000160.xhtml#f0095)D 所示。显而易见，分析模型产生了更清晰的频谱图，更接近原始频谱图。当采用框架 `G(64, 32)` 时，该框架是一个包含 `8l` 个原子的高冗余 Gabor 字典，分析模型得到的重构信号其频谱图在视觉上与[图 10.18](#Chp010_463-518_B9780443292385000160.xhtml#f0095)D 中的原始频谱图无法区分。
