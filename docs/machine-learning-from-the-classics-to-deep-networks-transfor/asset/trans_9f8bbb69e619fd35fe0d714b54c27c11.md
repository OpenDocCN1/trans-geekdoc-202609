
之前，为了说明 `x[1]` 导致 `x[2]` 和 `x[3]`，我们使用了一些*额外*的信息/知识，称之为常识推理。请注意，在这种情况下，训练需要三个概率值的知识，即 `P(x[1])`、`P(x[2]|x[1])` 和 `P(x[3]|x[1])`。现在让我们假设选择 [图 15.5](#Chp015_755-803_B9780443292385000214.xhtml#f0030)B 中的图模型。这一次，忽略因果关系导致了错误的模型。该模型使 `x[2]` 和 `x[3]` 相互独立，这显然不可能。它们仅应在给定 `x[1]` 的条件下*有条件*独立。让 `x[2]` 和 `x[3]` 保持为 `x[1]` 的父节点的唯一合理方法是添加一条额外的链接，如 [图 15.5](#Chp015_755-803_B9780443292385000214.xhtml#f0030)C 所示，这在两者之间建立了关系。然而，要训练这样一个网络，除了三个概率值 `P(x[2])`、`P(x[3])` 和 `P(x[1]|x[2], x[3])` 之外，还需要知道一个额外概率的值，即 `P(x[3]|x[2])`。因此，在构建 BN 时，了解任何潜在的因果方向总是有益的。此外，还有其他原因。例如，这可能与*干预*有关，干预是指改变变量状态以研究其对其他变量相应影响的动作；因为变化沿因果方向传播，只有当网络按因果层级构建时，这种研究才成为可能。例如，在生物学中，人们非常有兴趣了解哪些基因影响其他基因的激活水平，以及预测开启或关闭某些基因的效果。

因果性的概念并不容易，哲学家们为此争论了几个世纪。虽然我们这里绝无意涉足这一问题，但引用两位著名哲学家的观点颇具趣味。

根据大卫·休谟的观点，因果性不是现实世界的属性，而是心智的一个概念，帮助我们解释对世界的感知。休谟（1711–1776）是一位苏格兰哲学家，以其哲学经验主义和怀疑论而闻名。他最著名的著作是《人性论》，与理性主义哲学学派相反，他主张人性主要由欲望而非理性支配。

根据伯特兰·罗素的观点，因果律与物理定律无关，物理定律是对称的（回顾我们之前关于条件概率的陈述），并不指示因果关系。例如，牛顿万有引力定律可以用以下任意形式表示：

```
B = mg  or  g = B/m  or  m = B/g,
```
