
The loss function involved in Eq. [(19.53)](#Chp019_997-1102_B9780443292385000251.xhtml#deq125) is very similar to the so-called infoNCE (noise-contrastive estimation) loss function that was introduced in [188], which was derived via information theoretic arguments. Noise contrastive estimation methods were first introduced in [69]. The basic idea is to estimate the involved unknown parameters that describe a model by learning to discriminate between the input data and some artificially generated noise. Thus, parameter estimation relies on noise with which the data is contrasted.

Another path in contrastive learning criteria is to involve a margin parameter `m` that imposes the distance between examples from different classes (e.g., positive and negative ones) to be larger than `m > 0`. The *triplet cost* [195] is a typical example of this family. Three samples are involved in the cost: the query or anchor point, a positive example, and a negative one. The triplet loss requires the difference between the two distances (i.e., the one between the query point and a positive example and the same query point from a negative example) to be larger than the margin `m`. In a more formal way, the triplet cost function is expressed as

```
L = ∑_{(i,j) ∈ P⁺} ∑_{(i,k) ∈ P⁻} [ ||z_i - z_j||₂ - ||z_i - z_k||₂ + m ]₊
```

where `P⁻` is the index set of all the negative pairs and `[·]₊` is the hinge loss function (i.e., `max{0, ·}`, see also Section [11.10](#Chp011_519-582_B9780443292385000172.xhtml)). The cost function penalizes those pairs for which the distance of a negative sample from the query point is smaller than `m`, compared to the corresponding distance of a positive example.

Over the years, various contrastive loss functions have been proposed and used (see, e.g., [13] for a related review). In [183], a unification of various contrastive losses is presented. Also, contrastive learning has been used in the context of masked self-supervision in order to match the output to the correct masked patch as contrasted to the incorrect ones (see, e.g., [183], [9]). In the *momentum contrast* (MoCo) scheme [72], contrastive learning is seen as a process of matching an encoded query vector `q`, produced in one of the two branches, to a dictionary of encoded keys `k₀, k₁, …` produced in the other branch, using a contrastive loss. The dictionary keys are defined on-the-fly via a set of data samples.

In [186], a theoretical analysis on contrastive self-supervised learning points out that the learned representations are nearly optimal on downstream prediction tasks whenever the two views provide *redundant information* about the labels.
