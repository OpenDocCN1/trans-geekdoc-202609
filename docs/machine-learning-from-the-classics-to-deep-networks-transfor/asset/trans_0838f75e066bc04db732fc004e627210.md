
## 15.5 因子图

与 BN 不同，MRF 并不一定指示相应吉布斯分布因子分解的具体形式。观察 BN，因子分解沿着分配在每个节点的条件分布演变。让我们看看[图 15.17](#Chp015_755-803_B9780443292385000214.xhtml#f0095)的 MRF。相应的吉布斯分布可以写为

```
p(x_1,x_2,x_3,x_4) = \frac{1}{Z}\psi_1(x_1,x_2)\psi_2(x_1,x_3)\psi_3(x_3,x_2)\psi_4(x_3,x_4)\psi_5(x_1,x_4).
```

![Equation](images/B9780443292385000214/si192.png)(15.28)

另一种选择可以是

```
p(x_1,x_2,x_3,x_4) = \frac{1}{Z}\psi_1(x_1,x_2,x_3)\psi_2(x_1,x_3,x_4).
```

![Equation](images/B9780443292385000214/si193.png)(15.29)

作为一种极端情况，如果 MRF 的所有点形成一个最大团，如[图 15.13](#Chp015_755-803_B9780443292385000214.xhtml#f0075)B 所示，我们可以只包含单个乘积项。请注意，以最大团为目标会减少因子的数量，但同时也会增加复杂性；例如，在离散变量的情况下，这可能导致必须学习的项数呈指数级爆炸。同时，使用大团会隐藏建模细节。另一方面，较小的团允许我们在描述中更加明确和详细。
