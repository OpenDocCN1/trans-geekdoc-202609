

### 后验分布推导

$$p(\theta|\mathbf{y}) = \frac{1}{\sqrt{2\pi}\sigma_{N}}\exp\left( - \frac{(\theta - {\overline{\theta}}_{N})^{2}}{2\sigma_{N}^{2}} \right), \tag{3.68}$$

其中

$${\overline{\theta}}_{N} = \frac{N\sigma_{0}^{2}{\overline{y}}_{N} + \sigma_{\eta}^{2}\theta_{0}}{N\sigma_{0}^{2} + \sigma_{\eta}^{2}}, \tag{3.69}$$

这里 ${\overline{y}}_{N} = \frac{1}{N}\sum_{n = 1}^{N}y_{n}$ 是观测值的样本均值，且

$$\sigma_{N}^{2} = \frac{\sigma_{\eta}^{2}\sigma_{0}^{2}}{N\sigma_{0}^{2} + \sigma_{\eta}^{2}}. \tag{3.70}$$

换句话说，如果先验和条件 PDF 都是高斯分布，则后验分布也是高斯分布。此外，后验的均值和方差分别由公式 [(3.69)](#Chp003_65-117_B9780443292385000093.xhtml#deq120) 和 [(3.70)](#Chp003_65-117_B9780443292385000093.xhtml#deq121) 给出。

观察可知，随着观测数量的增加，${\overline{\theta}}_{N}$ 趋向于观测值的样本均值；回顾一下，后者是由最大似然（ML）方法得到的估计。同时请注意，随着观测数量的增加，方差持续减小，这符合常识，因为更多的观测意味着更小的不确定性。[图 3.10](#Chp003_65-117_B9780443292385000093.xhtml#f0060) 说明了上述讨论。

数据样本 $y[n]$ 由高斯伪随机生成器生成，均值为 $\theta = 1$，方差为 $\sigma[\eta]^{2} = 0.1$。因此，我们未知参数的真实值等于 1。我们使用了均值为 $\theta_{0} = 2$、方差为 $\sigma_{0}^{2} = 6$ 的高斯先验 PDF。我们观察到，随着 $N$ 的增加，后验 PDF 变得更窄，其均值趋向于真实值 1。
