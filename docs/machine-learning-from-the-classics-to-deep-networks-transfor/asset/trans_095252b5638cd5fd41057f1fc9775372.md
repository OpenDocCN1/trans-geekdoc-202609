

## 算法 10.4

### AdCoSaMP 方案

1.  选择 $t = 2k$ 的值。

2.  初始化算法：
    $\boldsymbol{\theta}(1) = \mathbf{0}$，
    $\widetilde{\boldsymbol{\theta}}(1) = \mathbf{0}$，
    $\mathbf{p}_1 = \mathbf{0}$，
    $e_1 = y_1$。

3.  选择 $\mu$ 和 $\beta$。

4.  对于 $n = 1, 2, \dots$ 执行：
    *   **计算预测误差：**
        $e_n := y_n - \mathbf{x}_n^T \boldsymbol{\theta}(n-1)$。
    *   **更新相关向量：**
        $\mathbf{p}_n := \sum_{j=1}^{n-1} \beta^{n-1-j} \mathbf{x}_j e_j = \beta \mathbf{p}_{n-1} + \mathbf{x}_{n-1} e_{n-1}$。
    *   **识别支持集：**
        找到 $\mathbf{p}_n$ 中幅度最大的 $t$ 个分量的索引集 $S_n$。
    *   **LS 任务（在线实现）：**
        约束在步骤 3c 中对应支持集 $S_n$ 索引的活动列上，通过基本 LMS 递归在线执行 LS 任务：
        $$
        \begin{aligned}
        \widetilde{e}_n &:= y_n - \mathbf{x}_{n|S_n}^T \widetilde{\boldsymbol{\theta}}_{|S_n}(n-1), \\
        \widetilde{\boldsymbol{\theta}}_{|S_n}(n) &:= \widetilde{\boldsymbol{\theta}}_{|S_n}(n-1) + \mu \mathbf{x}_{n|S_n} \widetilde{e}_n,
        \end{aligned}
        $$
        其中 $\widetilde{\boldsymbol{\theta}}_{|S_n}(\cdot)$ 和 $\mathbf{x}_{n|S_n}$ 分别表示对应于支持集 $S_n$ 中索引的子向量。
    *   **形成估计值：**
        令 $\boldsymbol{\theta}(n)$ 为将 $\widetilde{\boldsymbol{\theta}}_{|S_n}(n)$ 放置在 $S_n$ 索引处、其余位置置零得到的向量。
