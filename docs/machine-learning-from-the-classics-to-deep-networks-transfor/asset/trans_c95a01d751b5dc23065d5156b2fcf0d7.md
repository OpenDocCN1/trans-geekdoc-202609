$\mathbf{e} = \mathbf{y} - \widehat{\mathbf{y}}.$

![Equation](images/B9780443292385000123/si17.png)

注意 `e` 可以看作是输出观测向量 `y` 与 $\widehat{\mathbf{y}}$![Equation](images/B9780443292385000123/si18.png) 之间的*误差向量*；后者是基于输入观测（堆叠在 `X` 中）并给定 `θ` 值对 `y` 的预测。显然，*N* 维向量 $\widehat{\mathbf{y}}$![Equation](images/B9780443292385000123/si18.png) 作为 `X` 列向量的线性组合，位于 span{**x**[1]^(*c*), …, **x**[*l*]^(*c*)}![Equation](images/B9780443292385000123/si19.png) 中。根据定义，后者是由 `X` 的 *l* 个列向量的所有可能线性组合生成的 ℝ^(*l*)![Equation](images/B9780443292385000123/si20.png) 的子空间（见附录 A）。因此，我们的任务自然转变为选择 `θ`，使 `y` 与 $\widehat{\mathbf{y}}$![Equation](images/B9780443292385000123/si18.png) 之间的误差向量具有最小范数。一般来说，由于噪声的存在，观测向量 `y` 并不位于由 `X` 的列向量张成的子空间中。

根据欧几里得空间的正交性勾股定理，如果 $\widehat{\mathbf{y}}$![Equation](images/B9780443292385000123/si18.png) 被选为 `y` 在 span {**x**[1]^(*c*), …, **x**[*l*]^(*c*)}![Equation](images/B9780443292385000123/si21.png) 上的*正交投影*，则可获得最小范数误差。回顾正交投影的概念（附录 A 和第 [5.6](#Chp005_177-248_B9780443292385000111.xhtml) 节，公式 [(5.63)](#Chp005_177-248_B9780443292385000111.xhtml)），`y` 在由 `X` 的列向量张成的子空间上的正交投影由下式给出
