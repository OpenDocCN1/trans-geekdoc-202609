
### 嵌入矩阵与位置编码

*   其中 *E* 是相应维度的嵌入矩阵。该矩阵的元素在训练过程中被**学习**。嵌入空间的维度 *d*[*m*] 是预先选定的。例如，在文献 [189] 中，*d*[*m*] = 512。

*   **位置嵌入**：多年来提出了各种技术。在原始论文 [189] 中，使用了正弦位置编码。

*   对于输入短语中第 *k* 个位置的 token，以及相应向量/token 的每个向量维度 *i*，采用以下公式：

```
PE_{(k,2i)} = sin( k / b^{(2i/d_m)} ),
```
(19.28)

```
PE_{(k,2i + 1)} = cos( k / b^{(2i/d_m)} ),
```
(19.29)

*   其中 `i = 0, 1, ..., d_m/2 - 1`，为简单起见，我们假设 `d_m` 为偶数。在文献 [189] 中，`b = 10000`。因此，对于每个位置 *k*，向量的偶数维度按正弦函数编码，奇数维度按余弦函数编码，所有位置均从 `k = 0` 开始计数。因此，位置嵌入取决于两个索引，等价地定义了一个矩阵。

### 示例 19.2

假设输入序列长度 `N = 3`，例如 "Je suis étudiant"，为简单起见我们忽略序列开始和结束 token，即 `⟨SOS⟩` 和 `⟨EOS⟩`。同时假设 `d_m = 4` 且 `b = 100`。为获得相应的 `N × d_m` 位置嵌入矩阵，按顺序进行如下计算：

| Je | suis | étudiant |
| :--- | :---: | ---: |
| `k = 0` | `k = 1` | `k = 2` |

*   `(k, i) = (0, 0) → PE[(0, 0)] = sin(0) = 0, PE[(0, 1)] = cos(0) = 1`
