## Step 3

In the sequel, having obtained the softmax similarity scores, we compute, for each one of the input embeddings, `x[n], n = 0, 1, …, N + 1`, an *updated representation*, as

```
x_n → z'_n = ∑_{j = 0}^{N + 1} s_{nj} v_j, n = 0,1,…,N + 1.
```

(19.34)

Note that, for each one of the positions, `n`, this new embedding results as the weighted average over *all* the value vectors, each one weighted by the corresponding softmax attention score. Hence, this updated embedding encodes *contextual information* based on the whole of the sequence. In this way, besides `s[nn]`, which measures the similarity of the `n`th embedding with itself, and it is expected to have the largest value, we allow the `n`th embedding to *attend* to some other positions that are more relevant/similar to it. Furthermore, the expansion in Eq. [(19.34)](#Chp019_997-1102_B9780443292385000251.xhtml#deq80) is not carried out in terms of the original embeddings, i.e., `x[j]`, but, instead, in terms of the corresponding value vectors, which are the respective optimized versions.
