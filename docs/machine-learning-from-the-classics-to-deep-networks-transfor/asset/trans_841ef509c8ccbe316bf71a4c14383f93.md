## 8.2 凸集与函数

虽然本章讨论的大多数算法涉及欧几里得空间中的向量变量，这与我们迄今为止在本书中的做法一致，但定义和一些基本定理将在更一般的希尔伯特空间背景下陈述。^([^(49)](#fn49))

### 8.2.1 凸集

**定义 8.1**

希尔伯特空间 `ℍ` 的非空子集 `C`，`C ⊆ ℍ`，被称为*凸集*，如果 `∀ x₁, x₂ ∈ C` 和 `∀ λ ∈ [0, 1]` 以下条件成立：^([^(50)](#fn50))

`x := λ x₁ + (1 − λ) x₂ ∈ C`。 (8.1)

注意，若 `λ = 1`，则 `x = x₁`；若 `λ = 0`，则 `x = x₂`。对于 `[0, 1]` 中 `λ` 的任何其他值，`x` 位于连接 `x₁` 和 `x₂` 的线段上。确实，由式 [(8.1)](#Chp008_343-416_B9780443292385000147.xhtml#deq1) 可得

`x − x₂ = λ (x₁ − x₂), 0 ≤ λ ≤ 1`。
