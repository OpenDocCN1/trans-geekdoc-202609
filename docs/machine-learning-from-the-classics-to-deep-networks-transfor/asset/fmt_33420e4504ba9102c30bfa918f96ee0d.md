
本节目前我们处理的是高斯分布，这使得积分具有可处理性且可解析计算。是否有方法应对更一般的情况？此外，即使在高斯概率密度函数（PDF）的情况下，我们也假设协方差矩阵 `Σ[θ]`、`Σ[η]` 是已知的。在实践中，它们并非已知。即使假设 `Σ[η]` 可以通过实验测量，`Σ[θ]` 仍然未知。能否通过优化过程选择相关参数？如果答案是肯定的，这种优化能否在训练集上进行，还是必然会遇到类似于正则化方法所面临的问题？我们将在后续章节中探讨所有这些挑战。

### 备注 12.1

*   MAP 估计器有时被称为 **Type I** 估计器，以区别于将在下一节的 **备注 12.2** 中讨论的 Type II 估计方法。
*   公式 **(12.10)** 中的后验均值可以通过应用附录 A.1 中给出的矩阵求逆引理，获得不同的变体形式。在本章附录中，已证明（公式 (12.152)）：

```
μ[θ|y] = (Σ[θ]^(−1) + Φ^(T) Σ[η]^(−1) Φ)^(−1) (Φ^(T) Σ[η]^(−1) y + Σ[θ]^(−1) θ[0])
```
(12.26)

*   或者（公式 (12.148)）：

```
μ[θ|y] = θ[0] + Σ[θ] Φ^(T) (Σ[η] + Φ Σ[θ] Φ^(T))^(−1) (y − Φ θ[0])
```
(12.27)

*   此外，利用附录 A.1 中的 Woodbury 恒等式，我们可以很容易地看出：

```
Σ[θ|y] = Σ[θ] − Σ[θ] Φ^(T) (Σ[η] + Φ Σ[θ] Φ^(T))^(−1) Φ Σ[θ]
```
(12.28)

*   在实践中，根据涉及矩阵的维度，通常使用计算上最方便的形式，即对维度较低的矩阵求逆。
