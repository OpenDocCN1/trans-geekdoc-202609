
这一次，波束形成器被推向减小其输出信号，由于约束的存在，这等价于以最优方式最小化源自噪声以及从不同于 `ϕ` 方向入射到阵列上的所有其他干扰源的贡献。如果将 `Σ[η]` 替换为 `Σ[u]`，则公式 [(4.111)](#Chp004_119-175_B978044329238500010X.xhtml#deq200) 中任务的求解结果显然与公式 [(4.109)](#Chp004_119-175_B978044329238500010X.xhtml#deq197) 和 [(4.110)](#Chp004_119-175_B978044329238500010X.xhtml#deq198) 的求解结果相同。

这种线性约束任务被称为*线性约束最小方差*（LMV）或*卡蓬*波束形成或*最小方差无失真响应（MVDR）波束形成*。关于波束形成的简明介绍，请参见例如文献 \[48\]。波束形成任务的广义线性版本也已被提出（例如 \[10,32\]）（问题 [4.21](#Chp004_119-175_B978044329238500010X.xhtml#o0110)）。[图 4.20](#Chp004_119-175_B978044329238500010X.xhtml#f0105) 显示了以角度 `ϕ` 为函数的波束模式。公式 [(4.108)](#Chp004_119-175_B978044329238500010X.xhtml#deq196) 中设计最优权重组的期望角度为 `ϕ = π`。天线单元数量为 `l = 10`，间距选为 `Δx/λ = 0.5`，噪声协方差矩阵选为 `0.1*I`。波束模式幅度单位为 dB，即纵轴显示 `20log10(|w*^(H)x(ϕ)|)`。因此，任何从不接近 `ϕ = π` 方向到达的信号都会被抑制。如果使用更多单元，主波束会变得更尖锐。

## 4.10 时变统计：卡尔曼滤波

到目前为止，我们关于线性估计任务的讨论仅限于平稳环境，即假设所涉及随机变量的统计特性随时间不变。然而，在实践中往往并非如此，统计特性可能在不同时刻有所不同。事实上，后续章节将投入大量精力研究时变环境下的估计任务。

鲁道夫·卡尔曼（1930–2016）是第三位科学家，前两位是维纳和柯尔莫戈洛夫，他们的重大贡献奠定了估计理论的基础。卡尔曼出生于匈牙利，后移居美国。他是基于状态空间表述的系统理论之父，这与系统更为有限的输入-输出描述形成对比。

1960 年，卡尔曼在两篇开创性论文中提出了著名的卡尔曼滤波器，它利用状态空间表述，以一种优雅的方式适应时变动态 \[18,19\]。我们将在两个联合分布的随机向量 `y`、`x` 的一般背景下推导卡尔曼滤波器的基本递推公式。任务是给定 `y` 的观测值来估计 `x` 的值。设 `y` 和 `x` 通过以下递推公式线性相关：
