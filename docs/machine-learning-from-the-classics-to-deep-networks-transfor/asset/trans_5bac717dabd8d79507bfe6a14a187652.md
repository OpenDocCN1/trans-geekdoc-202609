

## 图 4.9 说明干扰消除任务的基本框图。

过程 `y[n]` 是未知系统 `H` 的输出，其输入由 `u[n]` 激励。任务是通过获取其冲激响应的估计值来建模 `H`（假设它是已知阶数的线性时不变系统）。然后，当模型由相同的输入 `u[n]` 激励时，模型的输出将是 `y[n]` 的一个近似。我们将使用 `d[n]` 作为目标/期望响应过程。假设未知系统 `H` 的阶数为 `l`，则 `w[0], …, w[l−1]` 的最优估计由正规方程给出：

```
Σ[u] w[*] = p.
```

然而，

```
p = E [u[n] d[n]] = E [u[n] (y[n] + s[n])] = E [u[n] y[n]],
```

因为相应的输入向量 `u[n]` 和 `s[n]` 被认为在统计上是独立的。也就是说，问题的上述表述导致了与期望响应为信号 `y[n]`（即我们想要消除的信号！）时相同的正规方程。因此，我们模型的输出将是 `y[n]` 的一个近似值（在均方误差意义上），记为 `ŷ[n]`，如果从 `d[n]` 中减去它，所得到的（误差）信号 `e[n]` 将是 `s[n]` 的一个近似。该近似的优劣取决于 `l` 是否是 `H` 的真实阶数的一个良好“估计”。方程 [(4.54)](#Chp004_119-175_B978044329238500010X.xhtml#deq83) 右侧的互相关可以通过计算相应的样本均值来近似，特别是在 `s[n]` 缺失的时段内。在实际系统中，通常采用这种实现的在线/自适应版本，正如我们将在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中看到的那样。

干扰消除方案已广泛应用于许多系统，如噪声消除、电话网络中的回声消除和视频会议，以及生物医学应用，例如为了消除胎儿心电图中的母体干扰。
