
其中 $\sum_{j = 1}^{J}P_{j} = 1$，$\Lambda[j] = \text{diag}\{b[j[1]],\dots,b[j[m]]\}$，$b[j[i]] \in \{0, 1\}$，$i = 1, 2, \dots, m$。对于固定的 $J$ 和预选的 $\Lambda[j]$，第 $j$ 个因子的公式 [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) 中的展开形式早已为人所知；在此背景下，通过施加适当的先验并调用诸如变分 EM（例如 [79]）、EM [175] 和最大似然 [180] 等技术，在贝叶斯框架下实现未知参数的学习。在对该问题的较新处理中，每个 $\Lambda[j], j = 1, 2, \dots, J$ 的维数以及因子数目 $J$，均可由学习方案来学习。为此，*非参数先验*被引入（参见例如 [40,47,94] 及第 [13.11](#Chp013_635-716_B9780443292385000196.xhtml) 节）。随后，模型参数通过 Gibbs 采样（第 [14](#Chp014_717-754_B9780443292385000202.xhtml) 章）或变分贝叶斯技术计算得出。请注意，一般而言，不同因子最终可能呈现不同的维数。

对于*非线性流形学习*，公式 [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) 的几何解释如[图 20.16](#Chp020_1103-1179_B9780443292385000263.xhtml#f0105)所示。数字 $J$ 是用于覆盖流形的足够扁平椭球体的数量，$\boldsymbol{\mu}[j]$ 是流形上的采样点，列向量 $A[j]\Lambda[j]$（近似）张成局部 $k$ 维切子空间，噪声方差 $\beta^{-1}$ 取决于流形曲率，而权重 $P[j]$ 反映流形上各处点的相对密度。该方法还被用于矩阵补全（另见第 [20.10.1](#Chp020_1103-1179_B9780443292385000263.xhtml#s0180) 节），通过对相关矩阵进行低秩矩阵近似 [40]。

一旦模型通过在训练数据集 $\boldsymbol{x}[n], n = 1, 2, \dots, N$ 上进行贝叶斯推断而学习完成，随后即可用于压缩感知，即能够利用 $K \ll l$ 次测量获得任意 $\boldsymbol{x}$，该 $\boldsymbol{x}$ 属于环境空间 $\mathbb{R}^{(l)}$ 但“位于”由公式 [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) 建模的 $k$ 维流形中。为此，完全类似于第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章所述内容，必须确定一个感测矩阵，此处记为 $\Phi \in \mathbb{R}^{(K \times l)}$，以便能够从测量（投影）向量中恢复 $\boldsymbol{x}$：

$$
\boldsymbol{y} = \Phi\boldsymbol{x} + \boldsymbol{\eta},
