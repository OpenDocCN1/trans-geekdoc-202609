
$$
\theta_{j}^{(i)} = S_{\lambda/{\|\mathbf{x}_{j}^{c}\|_{2}^{2}}}\left( \theta_{j}^{(i - 1)} + \frac{{\mathbf{x}_{j}^{c}}^{T}\mathbf{e}^{(i - 1)}}{\|\mathbf{x}_{j}^{c}\|_{2}^{2}} \right),\quad j = 1,2,\ldots,l.
$$

如果 `X` 的列未归一化为单位范数，该算法将先前报道的软阈值算法中的常数 `c` 替换为 `X` 相应列的范数。已证明并行坐标下降算法也收敛到 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 的 LASSO 极小化解 [50]。利用线搜索技术确定每次迭代的最速下降方向来改进该算法的方法也已被提出（参见 [124]）。

迭代收缩算法族的复杂度主要贡献来自两个矩阵-向量乘积，其计算量为 $\mathcal{O}(Nl)$![Equation](images/B9780443292385000160/si111.png)，除非 `X` 具有可利用的特殊结构（如 DFT）以减轻负载。

文献 [85] 提出了两阶段阈值（TST）方案，该方案融合了迭代收缩族和 OMP 的论点。该算法方案包含两个阈值阶段。第一步与公式 [(10.2)](#Chp010_463-518_B9780443292385000160.xhtml#deq14) 完全相同。然而，此处它仅用于确定“显著”的非零位置，正如上一小节介绍的 CSMP 算法那样。然后，在可用支撑集的约束下，求解一个最小二乘（LS）问题以提供更新后的估计。随后进行第二步阈值处理。两个阶段的阈值操作可以不同。在硬阈值处理中，两步均使用 $H_{k}$![Equation](images/B9780443292385000160/si62.png)；这产生了文献 [58] 中提出的算法。对于后一种方案，如果 RIP 对 $\delta_{3k} < 0.58$![Equation](images/B9780443292385000160/si112.png) 成立，则可推导出收敛性和性能界。换句话说，TST 与 CSMP 方法的基本区别在于：后者通过检查相关项 $X^{T}\mathbf{e}^{(i-1)}$![Equation](images/B9780443292385000160/si113.png) 获取最显著的非零系数，而 TST 族则通过检查 $\mathbf{\theta}^{(i-1)} + \mu X^{T}\mathbf{e}^{(i-1)}$![Equation](images/B9780443292385000160/si114.png) 获取。不同方法之间的差异可能很小，不同算法类别之间的界限不一定清晰分明。然而，从实际角度来看，微小的差异有时可能带来性能的显著提升。
