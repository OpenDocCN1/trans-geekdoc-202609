#### Solving the optimization task

The reader who is not interested in proofs can bypass this part in a first reading.

The task in [(11.30)](#Chp011_519-582_B9780443292385000172.xhtml#deq98)–[(11.33)](#Chp011_519-582_B9780443292385000172.xhtml#deq101) is a *convex programming* minimization, with a set of linear inequality constraints. As discussed in Appendix C, a minimizer has to satisfy the following *Karush–Kuhn–Tucker* (KKT) conditions:

```
∂L/∂θ = 0, ∂L/∂θ₀ = 0, ∂L/∂ξ̃ₙ = 0, ∂L/∂ξₙ = 0
```
