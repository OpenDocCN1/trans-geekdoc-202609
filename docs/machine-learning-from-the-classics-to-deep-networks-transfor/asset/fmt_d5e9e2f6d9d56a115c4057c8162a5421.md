
正如本章多处所述，深度神经网络目前代表了机器学习的最先进水平。深度网络已应用于几乎所有科学领域，在许多情况下提供人类级甚至超人类的性能（例如参见文献 [96, 169, 202]）。

然而，训练此类网络需要海量的标注数据。收集和标注数据以构建大型数据集是一项相当繁琐的任务。有时大型数据集确实存在且开放公开，例如 ImageNet-1K [35]，它包含 120 万张图像和 1000 个类别。但通常它们是专有的或获取成本高昂。例如，许多语音相关数据集即属此类。此外，在许多应用中，获取大型数据集根本不可能，例如在 X 射线成像和 fMRI 等医学相关应用中，原因之一是难以获得大量对应各类疾病（如恶性肿瘤）的图像，因为患病人群属于少数。

与这种对海量训练数据集的需求形成对比的是，人脑每次面对新情况时不需要从头开始训练。人类拥有将从一种情境（任务）获得的知识和经验迁移到另一个足够相似情境的固有机制。此类机制主要在潜意识层面运作。例如，学会骑自行车后，相关知识和经验可迁移至学习骑摩托车或开汽车。

机器学习中的迁移学习是绕过孤立任务学习范式的方法论。其目标是开发技术，以利用从一个任务学到的知识应用于另一个相关任务。

为演示该概念，让我们聚焦于图像识别领域的一个示例。假设有人有兴趣训练网络以自动识别和表征 X 射线成像中的肿瘤。如前所述，难以获取大量训练数据。然而，图像无论其具体类型如何，都共享许多特征。换言之，包含狗、汽车或肿瘤的图像均由边缘、基本形状、光强变化等组合形成。事实上，正如我们在 18.12.3 节末尾所述，CNN 中各层的目的是学习与此类信息相关的表示，并通过层层递进形成的特征对其进行编码。回顾我们对 CNN 的讨论，卷积层学习特征。最后一层卷积层的特征作为输入呈送给网络的全连接部分，其输出提供相关预测。

在我们的示例中，迁移学习的思路是“借用”先前通过大型图像数据集（如 ImageNet）训练所学的卷积层架构及其相关参数。然后，固定这些参数，仅使用可用的 X 射线图像训练网络中全连接部分的参数（见图 18.30）。换言之，我们使用通过不同类型图像训练网络产生的相同特征。然后，这些特征被用于使用特定任务数据集训练全连接网络。因此，我们将先前在图像相关任务中获得的知识迁移过来，以促进类似任务的学习。网络训练所基于的第一个任务通常称为源任务，知识迁移至的第二个任务称为目标任务。

另一种场景是将通过源任务预先学习的参数作为初始值，而非固定它们，并使用目标任务的 X 射线图像重新训练整个网络。根据应用和目标任务的数据规模，可以设计各种场景和组合。

总之，主要思想如下。使用针对源任务获取的数据训练（或使用预训练）深度网络，源任务的可用数据集足够大以支持相应训练。固定低层参数（或将其作为初始值），并使用目标任务较小规模的数据集训练高层参数（例如参见文献 [163]）。如果特定目标应用任务的数据规模很小，可使用简单的单输出层，例如 Softmax 或线性 SVM。

### 多任务学习

迁移学习中任务间的信息共享是顺序进行的。首先通过在源任务上训练学习参数；然后，利用获得的参数集，通过其关联的数据集学习目标任务。

在所谓的多任务学习中，多个不同任务被同时学习。多任务学习可视为一种归纳学习，通过将偏置嵌入学习任务来迁移知识。从某种意义上说，这在概念上类似于使用正则化项，其目的是将解偏向正则化项施加的约束。在多任务学习背景下，每个涉及任务的模型被训练以使其解偏向其他任务。事实证明，与单独在每个任务上训练模型相比，在多任务框架中训练网络能增强网络模型对过拟合的鲁棒性。

正如迁移学习一样，多任务学习的思想并不新鲜；在不同学习器的背景下已存在多年（例如参见文献 [2, 26]）。在已提出的大量技术中，这里将重点介绍两条在深度网络框架中更流行的路径（更多近期综述参见文献 [170] 和 [223]）。

在所谓的硬参数共享方法中，若干隐藏层被所有任务共享。同时，允许若干（输出）层为特定任务专用。这在图 18.43 中以示意方式展示。所有层（包括共享层和任务专用层）的参数被同时学习。在这样的训练概念中，过拟合倾向被降低。这是自然的，因为同时学习多个任务使获得的表示能捕获所有任务的信息，从而降低了对任何特定任务过拟合的倾向。此类多任务的一个应用例如在计算机视觉中，每个任务的目标可能是预测不同物体的标签。当图像中存在多个物体且任务是检测物体类别及其边界框时，该设置也非常方便。
