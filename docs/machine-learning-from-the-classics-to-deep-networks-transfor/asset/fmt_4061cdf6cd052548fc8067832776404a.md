
• If the hyperslabs collapse to hyperplanes (`ϵ = 0`) and `q = 1`, the algorithm becomes the NLMS. Indeed, for this case the projection in Eq. [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74) becomes the projection on the hyperplane, `H`, defined by (`y[n]`, `x[n]`), that is,

```
x[n]^(T)θ = y[n],
```

• And from Eq. [(8.11)](#Chp008_343-416_B9780443292385000147.xhtml#deq26), after making the appropriate notational adjustments, we have

```
P_H(θ_{n - 1}) = θ_{n - 1} - (x_n^T θ_{n - 1} - y_n) / (||x_n||^2) x_n. (8.42)
```

• Plugging Eq. [(8.43)](#Chp008_343-416_B9780443292385000147.xhtml#deq84) into Eq. [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74), we get

```
θ_n = θ_{n - 1} + (μ_n / ||x_n||^2) e_n x_n,
e_n = y_n - x_n^T θ_{n - 1},
```

• Which is the normalized LMS, introduced in Section [5.6.1](#Chp005_177-248_B9780443292385000111.xhtml).
