
## 推导边缘概率 $P(x_1)$

$$
P(x_{1}) = \frac{1}{Z}\sum\limits_{x_{i}:i \neq 1,l}\ \prod\limits_{i = 1}^{l - 2}\psi_{i,i + 1}(x_{i},x_{i + 1})\sum\limits_{x_{l}}\psi_{l - 1,l}(x_{l - 1},x_{l}),
$$

where we exploited the basic property of arithmetic

$$
\sum\limits_{i}\alpha\beta_{i} = \alpha\sum\limits_{i}\beta_{i}.
$$

### 定义消息 $\mu_b$

Define

$$
\sum\limits_{x_{l}}\psi_{l - 1,l}(x_{l - 1},x_{l}) := \mu_{b}(x_{l - 1}).
$$

Because the possible values of the pair $(x[l-1], x[l])$ comprise a table with $K^2$ elements, the summation involves $K^2$ terms and $\mu_b(x[l-1])$ consists of $K$ possible values.
