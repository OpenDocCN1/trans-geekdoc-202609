#### 复随机变量

复随机变量，*z* ∈ ℂ

![Equation](images/B9780443292385000081/si84.png)

是一个和

*z* = *x* + *j**y*

![Equation](images/B9780443292385000081/si85.png) (2.36)

其中 *x*, *y* 是实随机变量且 $j := \sqrt{-1}$

![Equation](images/B9780443292385000081/si86.png)。

请注意，对于复随机变量，PDF *无法* 定义，因为形如 *x* + *j**y* ≤ *x* + *j**y* 的不等式没有意义。当我们写 *p*(*z*) 时，我们指的是实部和虚部的联合 PDF，表示为

*p*(*z*) := *p*(*x*, *y*)。

![Equation](images/B9780443292385000081/si89.png) (2.37)

对于复随机变量，均值和协方差的概念定义为

![Equation](images/B9780443292385000081/si90.png) (2.38)
