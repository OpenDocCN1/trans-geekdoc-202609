

$j\_{i} = {arg\\, max}\_{j = 1,2,\\ldots,l}\\ \\frac{\\left| {\\mathbf{x}\_{j}^{c}}^{T}\\mathbf{e}^{(i - 1)} \\right|}{\\left\\| \\mathbf{x}\_{j}^{c} \\right\\|\_{2}} \\in \\{ 1,\\ldots,k\_{0}\\}.$

![Equation](images/B9780443292385000160/si38.png)

该命题的几何解释如下。如果在 ℝ^(*l*) 空间中，`X` 的所有列向量之间任意两两组合形成的夹角都接近 90^∘（列向量近似正交），这保证了 `μ(X)` 足够小，那么与那些不参与生成 `y` 线性组合的非活跃列向量相比，`y` 将更倾向于（形成更小的角度）参与其形成的任意一个活跃列向量。[图 10.2](#Chp010_463-518_B9780443292385000160.xhtml#f0015) 说明了这种几何关系，涵盖了向量互相正交的极端情况（[图 10.2](#Chp010_463-518_B9780443292385000160.xhtml#f0015)A），以及向量不正交但任意两列向量之间的夹角足够接近 90^∘ 的更一般情况（[图 10.2](#Chp010_463-518_B9780443292385000160.xhtml#f0015)B）。

![Figure 10.2 (A) In the case of an orthogonal matrix, the observations vector y will be orthogonal to any inactive column, here, x[3]^(c)Equation. (B) In the more general case, it is expected to “lean” closer (form smaller angles) to the active than to the inactive columns.](images/B9780443292385000160/gr002.jpg)

图 10.2 （A）在正交矩阵的情况下，观测向量 `y` 将与任何非活跃列向量正交，此处为 `x`[3]^(*c*)。 （B）在更一般的情况下，预期 `y` 会更“倾向于”（形成更小的角度）活跃列向量，而非非活跃列向量。

简而言之，上述命题保证了在第一次迭代中，将选中一个对应于真实支撑集的列向量。以类似的方式，这对所有后续迭代也同样成立。在第二步中，将选择另一个不同于先前所选的列向量（如前所述）。在第 `k`[0] 步，将选中对应于真实支撑集的最后一个剩余活跃列向量，这必然导致零误差。为此，只需将 `ϵ`[0] 设为零即可。

#### LARS 算法

最小角回归（LARS）算法 \[48\] 与 OMP 共享前两个步骤。它选择 `j`[*i*] 为当前可用活跃集之外的一个索引，以使与残差向量的相关性最大化。然而，它不是通过执行最小二乘（LS）拟合来计算 `θ`^((*i*)) 的非零分量，而是计算这些分量，使得残差向量与活跃集中的所有列向量等相关，即：

```
|x[j]^(c)^(T)(y−Xθ^((i)))|=constant, ∀j∈S^((i)),
```
