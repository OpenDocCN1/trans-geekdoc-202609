## 5.6 仿射投影算法

正如将在仿真部分验证的那样，基本 LMS 算法的一个主要缺点是其收敛速度相当低。为了改进这一点，多年来提出了许多变体。*仿射投影算法*（APA）属于所谓的*数据重用*家族，其中在每个时刻都会重用过去的数据。这种基本原理有助于算法“学得更快”并提高收敛速度。然而，除了增加复杂度之外，更高的收敛速度是以*增加失调电平*为代价实现的。

APA 最初在文献 [48] 中提出，后来又在文献 [72] 中提出。设当前可用的估计为 `θ[n−1]`。根据 APA，更新后的估计 `θ` 必须满足以下约束条件：

`x[n−i]^(T)θ = y[n−i], i = 0, 1, …, q−1`。

换句话说，我们*强制*参数向量 `θ` 在其输出端产生最近 `q` 个时刻的期望响应样本，其中 `q` 是用户定义的参数。同时，APA 要求 `θ` 在欧几里得范数意义上尽可能接近当前估计 `θ[n−1]`。因此，APA 在每个时刻求解以下约束优化任务：

```
θ_n = argmin_θ ||θ - θ_{n-1}||^2 s.t. x_{n-i}^T θ = y_{n-i}, i = 0,1,…,q-1.
```
