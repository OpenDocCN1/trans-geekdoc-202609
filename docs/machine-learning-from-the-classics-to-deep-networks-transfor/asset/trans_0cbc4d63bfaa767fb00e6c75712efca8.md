
*   •  一旦 `q(𝒳^(l), θ)` 被分解，就不对 `q[𝒳^(l)]` 和 `q[θ]` 的*函数形式*做出任何额外假设。

*   •  注意，PDF 的分解意味着独立性。因此，如果手头的数据不满足这种情况，恢复出的近似可能不是底层数据结构的忠实表示。因此，选择特定的分解必须谨慎进行。在实践中，可能不得不使用多种替代方案并保留最佳的一个。然而，计算复杂度是硬币的另一面，必须在权衡博弈中加以考虑。一般来说，分解变分方法倾向于提供比真实后验 PDF 更紧凑的近似（例如 [47]）。

*   •  回顾我们在第 [12.3](#Chp012_583-634_B9780443292385000184.xhtml) 节中关于模型选择和奥卡姆剃刀原则的讨论。这是我们致力于针对不同模型最大化证据以实现复杂度-精度权衡的出发点。然而，由于求助于近似解（即使我们忽略收敛到局部最大值的问题，这某种程度上可以通过使用不同的初始化来绕过），我们并非最大化证据本身，而是最大化其下界；一般来说，后者并不紧致。其紧致程度取决于 KL 散度，遗憾的是，后者无法轻易计算。因此，如果将下界用于模型选择，必须谨慎对待 [7]。

*   •  变分贝叶斯推断最早由 [25] 提出，随后被应用于从机器学习到解码等多个领域（例如 [7,26,31–33,35]）。

*   •  *在线版本*：变分贝叶斯算法的在线版本最早由 [73] 提出。文中采用了指数族分布，证明了基于变分贝叶斯理念的参数更新等同于步长为 1 的自然梯度下降法（关于自然梯度见第 [8.12](#Chp008_343-416_B9780443292385000147.xhtml) 节）。文献 [28] 进一步讨论了这种等价性，并类似地提出了一种随机近似算法，以便并行处理数据块。文献 [86] 还提出了一种用于稀疏线性回归建模背景下参数估计的在线变分贝叶斯算法。
