时变估计任务的推导围绕状态变量的两类估计器展开：

*   **第一个** 记为
    ```
    x̂_{n|n-1}
    ```
    它基于截至时刻 `n-1`（含）所接收到的所有信息；换句话说，即相应随机向量 `y[0]`、`y[1]`、…、`y[n-1]` 的观测值 `y[0]`、`y[1]`、…、`y[n-1]`。这被称为先验或 *先验* 估计器。

*   **第二个估计器** 在时刻 `n` 被称为 *后验* 估计器；它记为
    ```
    x̂_{n|n}
    ```
    并在观测到 `y[n]` 后通过更新 `x̂_{n|n-1}` 来计算。

