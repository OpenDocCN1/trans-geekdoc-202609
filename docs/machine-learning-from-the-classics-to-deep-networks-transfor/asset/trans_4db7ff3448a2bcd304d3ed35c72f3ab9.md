
用文字描述，回归变量 `x[n]` 和输出 `y[n]` 都会被修正，以使点 `(y[n] - e[n], x[n] - e[n])`，`n = 1, 2, ..., N` 落在 `ℝ^(l+1)` 中的一个超平面上。此外，一旦计算出这样一个超平面且它是唯一的，它就有一个有趣的解释。它是使所有训练点 `(y[n], x[n])` 到它的*总平方距离最小化*的超平面。此外，修正后的点 `(y[n] - e[n], x[n] - e[n])`，`n = 1, 2, ..., N`，是相应训练样本 `(y[n], x[n])` 在该超平面上的*正交投影*（见附加材料部分）。这在[图 6.12](#Chp006_249-291_B9780443292385000123.xhtml#f0075)中进行了说明。

[图 6.12](#Chp006_249-291_B9780443292385000123.xhtml#cf0730) 全最小二乘法同时修正输出变量的值和输入向量，使得修正后的点落在一个超平面上。修正后的点是 `(y[n], x[n])` 在相应超平面上的正交投影；对于中心化数据，该超平面穿过原点。对于非中心化数据，它穿过质心 `(\overline{y}, \overline{\mathbf{x}})`。

全最小二乘法已被用于许多应用，例如计算机视觉 [47]、系统辨识 [59]、语音和图像处理 [25, 51] 以及谱分析 [63]。文献 [4] 中提出了一种用于在自组织传感器网络中求解 TLS 任务的分布式算法。文献 [12] 中出现了一种用于高效求解 TLS 任务的递归方案。有关进一步阅读，感兴趣的读者可参考 [37, 64] 及其参考文献。

### 示例 6.3

为了演示 TLS 相对于 LS 估计器改进性能的潜力，在本示例中，我们同时在输出和输入样本中使用噪声。为此，我们随机生成一个输入矩阵 `X ∈ ℝ^(150×90)`，并根据标准化高斯分布 `𝒩(0, 1)` 填充元素。随后，我们通过从标准化高斯分布中随机抽取样本生成向量 `θ[o] ∈ ℝ^90`。输出向量形成如下：

```
y = X θ[o].
```
