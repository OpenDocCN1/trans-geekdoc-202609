

$$J_{\ast}^{(i)} - J(\mathbf{\theta}_{\ast}) \leq \frac{\left\| \mathbf{\theta}^{(0)} - \mathbf{\theta}_{\ast} \right\|^{2}}{2\sum_{k = 1}^{i}\mu_{k}} + \frac{\sum_{k = 1}^{i}\mu_{k}^{2}}{2\sum_{k = 1}^{i}\mu_{k}}G^{2}.$$

![Equation](images/B9780443292385000147/si325.png) (8.54)

令 *i* 趋向无穷大并考虑这些假设，即可证明该断言。 □

该证明存在许多变体。递减序列的其他选择也能保证收敛，例如 $\mu_{i} = 1/\sqrt{i}$。

![Equation](images/B9780443292385000147/si326.png)

此外，在某些情况下，部分假设可以放宽。请注意，如果 *J* 是 *γ*-Lipschitz 连续的（问题 [8.26](#Chp008_343-416_B9780443292385000147.xhtml#o0160)），则子梯度有界的假设得到保证，即存在 $\gamma > 0$ 使得

$$|J(\mathbf{y}) - J(\mathbf{x})| \leq \gamma \|\mathbf{y} - \mathbf{x}\|, \quad \forall \mathbf{x}, \mathbf{y} \in \mathbb{R}^{(l)}.$$

![Equation](images/B9780443292385000147/si328.png)
