
请注意，左侧神经元的输出 `z₁` 仅当输入模式源自区域 000 时才会激发 1，对于所有其他模式均为 0。对于右侧神经元，输出 `z₂` 对于来自区域 (111) 的所有模式均为 1，对于其余所有模式均为 0。请注意，这第二层神经元执行了第二次映射，这次映射到 ℝ² 中单位矩形的顶点。这种映射提供了输入模式的一种新表示，且该表示编码了与区域类别相关的信息。[图 18.6](#Chp018_885-995_B978044329238500024X.xhtml#f0035) 显示了在 (`z₁`, `z₂`) 空间中映射到单位矩形顶点的情况。

我们已通过构造性证明表明，三层前馈神经网络原则上可以解决*任何*类别由多面体区域并集形成的分类任务。尽管我们侧重于两类情况，但推广到多类情况是直接的，只需根据类别数量使用更多的输出神经元即可。请注意，在某些情况下，一个隐藏层节点可能就足够了。这取决于区域映射到的顶点被分配给类别的方式，是否使得线性可分成为可能。例如，如果类别 `ω₁` 是 (000) 和 (100) 区域的并集，则这两个顶点可通过单个平面与其余部分分离，因此不需要第二个隐藏层神经元（思考原因）。无论如何，我们将不再深入讨论。原因在于，这种构造对于展示构建多层神经网络的能力至关重要，这类似于我们大脑中发生的过程。然而，从实际角度来看，这种构造并无太大裨益。在实践中，当数据存在于高维空间时，无法通过解析方法确定定义神经元的参数来实现形成多面体区域的超平面。此外，在现实生活中，类别不一定由多面体区域的并集形成，且通常类别之间会重叠。因此，需要基于代价函数和一组训练数据设计训练过程。

从之前的讨论中，我们只需保留多层网络的结构；我们的重点将转向寻找估计突触未知权重和神经元偏置的方法。然而，从概念角度来看，我们必须记住，每一层都执行到新空间的映射，每次映射都提供输入数据的一种不同的、希望更具信息量的表示，直到最后一层，此时任务已被转化为易于求解的任务。

## 18.3.1 全连接网络

前面介绍的前馈网络也称为*全连接网络*。此名称旨在强调任一层中的每个神经元/节点都直接连接到*前一层*的*每个*节点。第一隐藏层的节点与输入层的节点*全*连接。换句话说，*每个*神经元都关联一个*向量*参数，其维度等于前一层（输入层）节点的数量。所执行的代数运算是*内积*。
