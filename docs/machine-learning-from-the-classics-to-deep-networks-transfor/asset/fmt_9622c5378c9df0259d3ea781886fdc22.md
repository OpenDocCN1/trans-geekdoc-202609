
$\\mathbf{\\theta}\_{n} = \\mathbf{\\theta}\_{n - 1} + \\mu\\sum\\limits\_{k = 1}^{K}\\mathbf{x}\_{k}(n)e\_{k}(n),e\_{k}(n) = y\_{k}(n) - \\mathbf{\\theta}\_{n - 1}^{T}\\mathbf{x}\_{k}(n),$

![Equation](images/B9780443292385000111/si480.png)

and a constant step size has been used, adopting the rationale behind the classical LMS formulation. Such an LMS-type recursion is perfect for a centralized scenario, where all data are transmitted to a fusion center. This is one of the extremes, having at its opposite end the scenario with nodes acting individually without cooperation. However, there is an intermediate path, which will lead us to the distributed diffusion mode of operation.

Instead of trying to minimize Eq. [(5.79)](#Chp005_177-248_B9780443292385000111.xhtml#deq177), let us select a specific node *k* and construct a local cost as the weighted aggregate in $\\mathcal{N}\_{k}$![Equation](images/B9780443292385000111/si460.png), represented by

$J\_{k}^{loc}(\\mathbf{\\theta}) = \\sum\\limits\_{m \\in \\mathcal{N}\_{k}}c\_{mk}J\_{m}(\\mathbf{\\theta}),\\quad k = 1,2,\\ldots,K,$![Equation](images/B9780443292385000111/si481.png)(5.81)

so that

$\\sum\\limits\_{k = 1}^{K}c\_{mk} = 1,\\quad c\_{mk} \\geqslant 0,\\quad\\text{and}\\ c\_{mk} = 0\\quad\\text{if~}m \\notin \\mathcal{N}\_{k},\\quad m = 1,2,\\ldots,K.$![Equation](images/B9780443292385000111/si482.png)(5.82)

Let *C* be the *K* × *K*![Equation](images/B9780443292385000111/si483.png) matrix with entries \\[*C*\\][*m*,*k*] = *c*[*m*,*k*]![Equation](images/B9780443292385000111/si484.png). Then the summation condition in [(5.82)](#Chp005_177-248_B9780443292385000111.xhtml#deq182) can be written as

*C***1** = **1**,![Equation](images/B9780443292385000111/si485.png)(5.83)

where **1** is the vector with all its entries being equal to 1. That is, all the entries across a row are summing to 1. Such matrices are known as *right stochastic* matrices. In contrast, a matrix is said to be left stochastic if

*C*^(*T*)**1** = **1**.![Equation](images/B9780443292385000111/si486.png)
