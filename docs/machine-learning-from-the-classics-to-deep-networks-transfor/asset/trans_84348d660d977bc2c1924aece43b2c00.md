

### 20.5.2 ICA 和高阶累积量

$p(\mathbf{s}) = \frac{1}{{(2\pi)}^{l/2}}\exp\left( - \frac{||\mathbf{s}||^{2}}{2} \right)$
![Equation](images/B9780443292385000263/si185.png)(20.46)

为简单起见，我们假设所有变量均已归一化为单位方差。令混合矩阵 `A` 为正交矩阵，即 `A^(-1) = A^(T)`![Equation](images/B9780443292385000263/si186.png)。则混合信号的联合 PDF 很容易得到为（参见公式 [(2.45)](#Chp002_19-64_B9780443292385000081.xhtml)）

$p(\mathbf{x}) = \frac{1}{{(2\pi)}^{l/2}}\exp\left( - \frac{||A^{T}\mathbf{x}||^{2}}{2} \right)|\text{det}(A^{T})|$
![Equation](images/B9780443292385000263/si187.png)(20.47)

然而，由于 `A` 的正交性，我们有 `||A^(T)x||² = ||x||²`![Equation](images/B9780443292385000263/si188.png) 和 `|det(A^(T))| = 1`![Equation](images/B9780443292385000263/si189.png)，这使得 `p(s)`![Equation](images/B9780443292385000263/si190.png) 与 `p(x)`![Equation](images/B9780443292385000263/si191.png) 无法区分。也就是说，通过观察 `x` 无法得出关于 `A` 的任何结论，因为所有相关信息都已丢失。从另一个角度来看，混合信号 `x[i]`![Equation](images/B9780443292385000263/si76.png) 互不相关，因为 `Σ[x] = I`![Equation](images/B9780443292385000263/si192.png)，而 ICA 无法提供进一步信息。这是联合高斯变量的不相关性等价于独立性这一事实的直接后果（参见第 [2.3.2](#Chp002_19-64_B9780443292385000081.xhtml) 节）。换句话说，如果潜在变量是高斯分布的，ICA 无法比 PCA 走得更远，因为后者提供不相关分量。也就是说，对于高斯独立分量，混合矩阵 `A` **不可识别**。在更一般的情况下，如果某些分量是高斯的而另一些不是，ICA 可以识别出非高斯分量。因此，为了使矩阵 `A` 可识别，**至多只能有一个**独立分量是高斯的。

从数学角度来看，ICA 任务对于高斯变量是不适定的。确实，假设已经获得了一组独立高斯分量 `z`；则由酉矩阵对 `z` 进行的任何线性变换也将是一个解（如前所示）。注意，PCA 避开了这个问题，因为后者对变换矩阵施加了特定结构。

为了处理独立性，必须以某种方式引入高阶统计信息。二阶统计信息足以施加不相关性，如 PCA 的情况，但这对于 ICA 是不够的。为此，多年来开发了大量技术和算法，回顾所有这些技术远远超出了书籍章节的篇幅限制。此处的目标是为读者提供这些技术背后的核心要义，并引入高阶统计量。感兴趣的读者可参考文献 [55,58,81,100,120] 深入研究该领域。
