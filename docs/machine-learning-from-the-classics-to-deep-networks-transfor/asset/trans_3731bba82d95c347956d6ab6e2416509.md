

## 多类分类方法

*   **一对多**：根据这种方法，空间中可能存在多个区域，使得多个判别函数得分为正值（例如，[123]）。此外，这种方法的另一个缺点是所谓的*类别不平衡*问题；这是由以下事实引起的：某一类别中的训练点数量（该类别包含来自`M - 1`个类别的数据）可能比其他类别中的点数量大得多。与类别不平衡问题相关的问题在[123]等文献中有讨论。

*   **一对一**：根据这种方法，通过成对考虑所有类别，求解`M(M - 1) / 2`个二分类任务。最终决策基于多数表决规则。

*   在[128]中，SVM的基本原理被扩展为同时估计`M`个超平面。然而，这种技术最终导致大量参数，数量等于`N(M - 1)`，这些参数必须通过单一的最小化任务来估计；这对于大多数实际问题来说是相当困难的。

*   在[34]中，多类任务是在纠错码的背景下处理的。每个类别与一个二进制码字相关联。如果码字选择得当，错误恢复能力就“嵌入”到了过程中（另见[123]）。关于多类分类方案的比较研究，见例如[41]及其参考文献。

*   **除法与Clifford代数**：SVM框架也已扩展以处理复数和超复数数据，既用于回归也用于分类，使用除法代数或Clifford代数[8]。在[124]中，考虑了四元数RKH空间的情况。

*   一种针对复值数据更通用的方法，利用*广义线性估计*以及*纯复核*的概念，已在[14]中提出。在该文中，证明了任何复数SVM/SVR任务等价于求解两个利用特定实核的实数SVM/SVR任务，该实核由所选的复核生成。此外，在分类情况下，证明了所提出的框架固有地将复空间分割为四部分。这自然地导致求解四类任务（四分类），而不是实数SVM的标准二类场景。这种基本原理可用于多类问题作为分裂类场景。

## 11.11 计算考量

一般来说，求解二次规划任务需要`O(N³)`次操作和`O(N²)`内存空间。为了应对这种需求，设计了多种分解技术（例如，[22, 55]），将任务“分解”为一系列较小的任务。在[59, 88, 89]中，*序列最小优化*（SMO）算法将任务分解为仅包含两个点的问题序列，这些问题可以解析求解。此类方案的高效实现导致经验训练时间在`O(N)`和`O(N^2.3)`之间缩放。

[74, 75]中推导的方案将任务视为简化凸包之间的最小距离点搜索，最终得到一种迭代方案，将训练点投影到超平面上。与[59, 88]相比，该方案导致更高效的实现；此外，最小距离搜索算法具有内置的增强并行性。

并行实现问题也在[21]中讨论。关于复杂性和精度的问题在[53]中报告。在后者中，推导出了多项式时间算法，为包括SVM分类器在内的一类QP问题产生具有保证精度的近似解。

处理顺序到达数据的SVM任务增量版本也已出现（例如，[26, 37, 100]）。在后者中，每次迭代考虑一个新点，并通过添加/移除样本相应地更新先前选定的支持向量集合（活动集合）。

应用于原始问题公式的在线版本也已被提出。在[84]中，遵循一种迭代加权LS方法，交替进行权重优化和成本约束强制。一种结构和计算上都很简单的方案，名为*SVM原始估计次梯度求解器*（PEGASOS），已在[105]中提出。该算法是一种应用于公式[(11.60)](#Chp011_519-582_B9780443292385000172.xhtml#deq143)中正则化经验合页损失函数的迭代次梯度形式（另见第[8](#Chp008_343-416_B9780443292385000147.xhtml)章）。对于线性核的情况，该算法表现出非常好的收敛性质，并在`O(1 / ε)`次迭代中找到`ε`精确解。

在[43, 56]中，求解凸任务的经典*割平面*技术已被用于原始域中的SVM上下文中。由此产生的算法非常高效，特别是对于线性SVM情况，复杂度变为`O(N)`阶。

在[125]中，引入了*核心向量机*（CVM）的概念以获得高效解。该方法背后的主要概念是计算几何中的*最小包围球*（MEB）。然后使用一组点子集，称为*核心集*，来实现对MEB的近似，该近似在优化过程中被使用。
