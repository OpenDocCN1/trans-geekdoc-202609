
该命题的证明见问题[8.16](#Chp008_343-416_B9780443292385000147.xhtml#o0110)。实欧几里得空间情况下[(8.15)](#Chp008_343-416_B9780443292385000147.xhtml#deq30)的几何解释如[图 8.10](#Chp008_343-416_B9780443292385000147.xhtml#f0060)所示。注意对于实希尔伯特空间，第一个性质变为

```
⟨x − P_C(x), y − P_C(x)⟩ ≤ 0, ∀y ∈ C.
```

从几何角度来看，[(8.17)](#Chp008_343-416_B9780443292385000147.xhtml#deq32)意味着由两个向量`x − P_C(x)`和`y − P_C(x)`形成的角是*钝角*。穿过`P_C(x)`且与`x − P_C(x)`正交的超平面称为*支撑*超平面，它使`C`中的所有点位于一侧，而`x`位于另一侧。可以证明，如果`C`是闭凸集且`x ∉ C`，总存在这样的超平面（参见例如[30]）。

### 引理 8.1

*设`S`为希尔伯特空间`ℍ`中的一个闭子空间`S ⊆ ℍ`。则`∀ x, y ∈ ℍ`，以下性质成立：*

```
P_S(ax + by) = a P_S(x) + b P_S(y)
```
(8.17)

*以及*

```
⟨P_S(x), y⟩ = ⟨x, P_S(y)⟩
```
(8.18)

*其中`a`和`b`为任意标量。换句话说，在闭子空间上的投影运算是线性的（问题[8.17](#Chp008_343-416_B9780443292385000147.xhtml#o0115)）。回顾一下，在欧几里得空间中所有子空间都是闭的，因此线性性总是成立的。*

[图 8.10](#Chp008_343-416_B9780443292385000147.xhtml#cf0395) 向量`y − P_C(x)`和`x − P_C(x)`形成钝角`ϕ`。

可以证明（问题[8.18](#Chp008_343-416_B9780443292385000147.xhtml#o0120)），如果`S`是希尔伯特空间`ℍ`中的一个闭子空间，其正交补`S^⊥`也是一个闭子空间，使得`S ∩ S^⊥ = {0}`；根据定义，正交补`S^⊥`是其元素与`S`中每个元素正交的集合。此外，`ℍ = S ⊕ S^⊥`；即每个元素`x ∈ ℍ`都可以*唯一*地分解为

```
x = P_S(x) + P_{S^⊥}(x)
```
(8.19)

如[图 8.11](#Chp008_343-416_B9780443292385000147.xhtml#f0065)所示。

### 定义 8.5

设一个映射

```
T : ℍ ↦ ℍ.
```

若`∀ x, y ∈ ℍ`有

```
‖T(x) − T(y)‖ ≤ ‖x − y‖
```
(8.20)

则称`T`为*非扩张*映射。
