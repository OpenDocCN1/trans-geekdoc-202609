
where `χ_𝒜(·)` denotes the characteristic function of the set `𝒜`, defined in Eq. [(8.59)](#Chp008_343-416_B9780443292385000147.xhtml#deq125). For the one-dimensional case, `l = 1`, the previous Moreau envelope boils down to

It is worth noting here that `e_{λ|·|}` is a scaled version, more accurately `1/λ` times, of the celebrated Huber function; a loss function vastly used against outliers in robust statistics, which will be discussed in more detail in Chapter [11](#Chp011_519-582_B9780443292385000172.xhtml). Note that the Moreau envelope is a “blown-up” smoothed version of the `ℓ₁` norm function and although the original function is not differentiable, its Moreau envelope is continuously differentiable; moreover, *they both share the same minimum*. This is most interesting, and we will come back to this very soon.
