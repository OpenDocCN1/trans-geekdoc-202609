
[Fig. 13.20](#Chp013_635-716_B9780443292385000196.xhtml#f0130) illustrates the process. Starting with a stick of unit length, we first break a piece of length `β[1]`, which we keep and we set `P[1] = β[1]`. The remaining part of the stick of length `π[1]` is thrown away. In the sequel, we break a piece of length `β[2]β[1]`, and we set `P[2] = β[1]β[2]`. We keep the piece and the other part of length `π[2]` is discarded, and so on. Associating each `P[k]` with the probability of the `k`th feature to occur, it can be shown that this construction of the sequence of probabilities is equivalent to an IBP process [82].

It is interesting to point out that the sequence `π[k]` of the discarded segments implements a sequence related to the DP stick breaking construction given in Eq. (13.119) (Problem [13.24](#Chp013_635-716_B9780443292385000196.xhtml#o0220)). This parallelism reveals nicely the difference between an IBP and a DP. In an IBP, the sequence of probabilities is a decreasing one and the respective values do not add to one. In contrast, the sequence of probabilities in a DP is not necessarily decreasing, and the respective values do add to one.

### Inference

For the inference, the data generation model should be first explicitly written. To this end, adopting the stick breaking construction of an IBP, let us assume that the data follow a Gaussian distribution with a binary latent feature model; this leads to the following sequence of steps:

1.  Generate the beta variables, `β[k] ~ Beta(β|α, 1)`, `k = 1, 2, …`.
2.  Generate the probability values, `P_k = ∏_{j=1}^{k} β_j`, `k = 1, 2, 3, …`.
3.  Populate matrix `Z` with elements, `z[kn] ~ Bern(z|P[k])`, `n = 1, 2, …, N` and `k = 1, 2, …`.
4.  Generate the features in matrix `A`, `a[k] ~ N(0, σ[A]²I)`, `k = 1, 2, …`.
