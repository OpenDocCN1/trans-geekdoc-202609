
从略微不同的角度来解读该命题，我们可以说该算法生成了一系列估计值的*子序列*，**θ**[*i*[\*]]，它对应于*J*[\*]^((*i*))的值，如*J*(**θ**[*i*[\*]]) ≤ *J*(**θ**[*i*]), *i* ≤ *i*[\*]所示，该序列收敛于**θ**[\*]。如果针对*μ*[*k*]优化公式[(8.55)](#Chp008_343-416_B9780443292385000147.xhtml#deq119)中的界限，可以达到的*最佳可能*收敛速率为$\mathcal{O}(\frac{1}{\sqrt{i}})$，当$\mu_{i} = \frac{c}{\sqrt{i}}$时可获得该速率，其中*c*为常数。无论如何，很容易注意到此类方法的收敛速度相当慢。然而，由于其计算简单性，它们仍在使用中，特别是在数据样本数量较大的情况下。感兴趣的读者可参考文献[10, 75]了解更多关于次梯度法的内容。

## Example 8.6

### 感知机算法

回顾公式[(8.37)](#Chp008_343-416_B9780443292385000147.xhtml#deq72)中定义的、令*ρ* = 0的Hinge损失函数，

$$
\mathcal{L}(y, \mathbf{\theta}^{T}\mathbf{x}) = \max(0, -y\mathbf{\theta}^{T}\mathbf{x}).
$$

在二分类任务中，我们得到一组训练样本，(*y*[*n*], **x**[*n*]) ∈ {−1, +1} × ℝ^(*l*+1), *n* = 1, 2, …, *N*，目标是计算一个线性分类器以最小化经验损失函数

$$
J(\mathbf{\theta}) = \sum_{n=1}^{N}\mathcal{L}(y_{n}, \mathbf{\theta}^{T}\mathbf{x}_{n}). \tag{8.55}
$$

我们假设类别是*线性可分*的，这保证了解的存在；即存在一个超平面能正确分类所有数据点。显然，这样的超平面会使公式[(8.56)](#Chp008_343-416_B9780443292385000147.xhtml#deq122)中的代价函数得分为零。我们假设输入数据空间的维度已增加一维，以解释不穿过原点的超平面的偏置项。
