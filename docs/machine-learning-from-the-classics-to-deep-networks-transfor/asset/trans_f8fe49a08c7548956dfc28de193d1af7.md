
从之前的讨论可以看出，矩阵 `X` 满足 RIP 性质的 `k` 值越高越好，因为可以处理更大范围的稀疏度。因此，朝这个方向的一个主要目标是构造此类矩阵。事实证明，验证一般结构矩阵的 RIP 是一项困难的任务。这让我们想起了矩阵的 `spark`，它同样难以计算。然而，对于某一类随机矩阵，可以用一种可行的方式建立 RIP。因此，构造此类感知矩阵一直主导着相关研究领域。我们将展示几个此类矩阵的例子，它们在实践中也非常流行，但不深入证明细节，因为这超出了本书的范围。感兴趣的读者可在相关参考文献中找到这些信息。

也许最著名的随机矩阵例子是高斯矩阵，其中感知矩阵的条目 `X(i, j)` 是从高斯概率密度函数 $\mathcal{N}(0, \frac{1}{N})$ 中独立同分布（i.i.d.）采样得到的实现值。

```
X(i, j) ~ N(0, 1/N)
```

另一类此类矩阵的流行例子是通过从伯努利分布或相关分布中独立同分布采样条目来构造的：

```
X(i, j) = {
    + 1/sqrt(N),  with probability 1/2,
    - 1/sqrt(N),  with probability 1/2
}
```

或者：

```
X(i, j) = {
    + sqrt(3/N),  with probability 1/6,
    0,            with probability 2/3,
    - sqrt(3/N),  with probability 1/6
}
```

最后，可以采用均匀分布，通过在 $\mathbb{R}^N$ 中的单位球面上均匀随机采样来构造 `X` 的列。事实证明，只要观测数 `N` 满足不等式

$$N \ge C k \ln(l/k)$$

此类矩阵以极大概率满足 `k` 阶 RIP，其中 `C` 是依赖于等距常数 $\delta_k$ 的某个常数。换句话说，有了这样的矩阵，可以从 `N < l` 个观测值中恢复一个 `k` 稀疏向量，其中 `N` 比稀疏度大一个由不等式 (9.33) 控制的量。关于这些问题的更多信息可参考文献 [6, 67]。
