
围绕高阶累积量的思想已经开发出许多算法，这些算法也被称为`张量方法`。张量是矩阵的推广，累积量张量是协方差矩阵的推广。此外，请注意，正如协方差矩阵的特征分析导出不相关（主）成分一样，累积量张量的特征分析导出独立成分。感兴趣的读者可参考文献 [39,57,119] 获取此类技术的更详细说明。

#### ICA 的不确定性

任何 ICA 方法都只能在以下两种不确定性范围内（近似地）恢复独立成分。

*   独立成分（IC）只能恢复到一个常数因子内。确实，如果 `A` 和 `z` 是 ICA 算法恢复的量，那么根据公式 [(20.44)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq59) 可知，`(1/a)A(1/a)A` 和 `az` 也是解。因此，通常将恢复的潜在变量（IC）归一化为单位方差。

*   我们无法确定 IC 的顺序。确实，如果已恢复 `A` 和 `z`，且 `P` 是一个置换矩阵，那么 `AP^(-1)` 和 `Pz` 也是解，因为 `Pz` 的分量与 `z` 的分量相同，只是顺序不同（具有相同的统计特性）。

### 20.5.3 非高斯性与独立成分

随机变量 `z` 的四阶（自）累积量，

```
κ[4](z) = 𝔼[z⁴] − 3(𝔼[z²])²
```

被称为该变量的`峰度`，它是`非高斯性`的一种度量。服从高斯分布的变量峰度为零。次高斯变量（在相同方差下，其概率密度函数衰减速率低于高斯分布的变量）具有负峰度。超高斯变量（对应于衰减速率高于高斯分布的概率密度函数）具有正峰度。因此，如果我们保持方差固定（例如，将变量归一化为单位方差），最大化平方峰度之和，就会导致最大化恢复 IC 的非高斯性。通常，恢复 IC 的峰度绝对值被用作对它们进行排序的度量。如果 ICA 被用作特征生成技术，这一点很重要。[图 20.8](#Chp020_1103-1179_B9780443292385000263.xhtml#f0060) 展示了一些典型的次高斯和超高斯示例，以及相应的高斯分布。

回顾第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章（第 [12.8.1](#Chp012_583-634_B9780443292385000184.xhtml) 节），高斯分布是在方差和均值约束下使熵最大化的分布。换句话说，在这些约束下它是最随机的，从这个角度来看，它关于数据潜在结构的信息量最少。相反，与高斯分布最不相似的分布更有趣，因为它们能更好地揭示与数据相关的结构。这一观察构成了`投影追踪`的核心，后者与 ICA 技术族密切相关。这些技术的本质是在特征空间中寻找方向，使得数据在这些方向上的投影可用非高斯分布来描述 [97,106]。

### 20.5.4 基于互信息的 ICA

基于将二阶和四阶交叉累积量置零的方法并非唯一途径。另一种途径是通过最小化潜在变量之间的`互信息`来估计 `W`。互信息的概念在第 [2.5](#Chp002_19-64_B9780443292385000081.xhtml) 节中已介绍。在公式 [(2.158)](#Chp002_19-64_B9780443292385000081.xhtml) 的基础上稍作详述，并对右侧进行积分（针对两个以上变量的情况），可以很容易地证明：

```
I(z) = - H(z) + ∑(i=1 to l) H(z_i)
``` (20.51)
