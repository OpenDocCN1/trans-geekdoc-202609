

### 2.5.1 二元随机变量

二元随机变量的熵由下式给出：

```
H(x) = -p log₂ p - (1 - p) log₂ (1 - p)
```

![Equation](images/B9780443292385000081/si406.png)

[图 2.17](#Chp002_19-64_B9780443292385000081.xhtml#f0090) 展示了 `p ∈ [0, 1]` 取不同值时的图形。观察可知，当 `p = 1/2` 时取得最大值。

![Figure 2.17 二元随机变量的熵的最大值出现在两个可能事件具有相等概率时，即 p = 1/2。](images/B9780443292385000081/gr017.jpg)

### 2.5.2 连续随机变量

之前给出的所有定义都可以推广到连续随机变量的情况。然而，这种推广必须谨慎进行。回顾一下，在实轴区间上取值的随机变量取任意单一值的概率为零。因此，相应的信息量是无限的。

为了定义连续变量 `x` 的熵，我们首先对其进行*离散化*，并形成相应的离散变量 `x_Δ`，即：

```
x_Δ := nΔ,  if  (n - 1)Δ < x ≤ nΔ
```

![Equation](images/B9780443292385000081/si410.png) (2.153)

其中 `Δ > 0`。

然后，

```
P(x_Δ = nΔ) = P(nΔ - Δ < x ≤ nΔ) = ∫_{(n - 1)Δ}^{nΔ} p(x) dx = Δ p̄(nΔ)
```

![Equation](images/B9780443292385000081/si412.png) (2.154)
