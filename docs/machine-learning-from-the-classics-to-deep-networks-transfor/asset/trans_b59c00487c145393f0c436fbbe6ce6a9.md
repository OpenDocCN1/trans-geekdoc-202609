
## 13.3 线性回归的变分贝叶斯方法

让我们再次考虑熟悉的回归任务

```
$q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta}) \propto {(g(\mathbf{\theta}))}^{\lambda + N}\exp\left( \mathbf{\phi}^{T}(\mathbf{\theta})\left( \mathbf{v} + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack \right) \right).$
```

![Equation](images/B9780443292385000196/si64.png)(13.20)

因此，后验 $p(\mathbf{\theta}|\mathcal{X})$ 的近似 $q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta})$ 与共轭先验具有相同的形式，其中

```
$\widetilde{\lambda} = \lambda + N,\quad\widetilde{v} = v + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\ \left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack.$
```

![Equation](images/B9780443292385000196/si67.png)(13.21)

请注意，公式 [(13.21)](#Chp013_635-716_B9780443292385000196.xhtml#deq27) 的形式与 [(12.77)](#Chp012_583-634_B9780443292385000184.xhtml) 中的相同。我们只需要对隐变量进行平均。这是一个非常优雅的结果，因为我们并未对 $q_{\mathbf{\theta}}$ 的函数形式做任何假设。换句话说，一旦我们采用指数族形式作为完整变量集的概率密度函数（PDF）以及参数先验的函数形式，后续的迭代就变成了“自家人的事务”。
