
在这一思路下，关于 PSD 所述的一切对于平移不变核函数的傅里叶变换同样适用。众所周知，核函数是正定的（第 [11.5.1](#Chp011_519-582_B9780443292385000172.xhtml#s0035) 节）。此外，平移不变性质，即 `κ(x, y) = κ(x − y)`，可视为平稳性的等价形式。由此可证，平移不变核的傅里叶变换是非负实函数，且其积分有限。经过适当归一化，积分值恒可设为 1。因此，平移不变核函数的傅里叶变换可视作概率密度函数（PDF），即积分为 1 的非负实函数。

设 `κ(x − y)` 为平移不变核，`p(ω)` 为其（多维）傅里叶变换，即

```
p(ω) = 1/(2π)^l ∫_{ℝ^l} κ(r) e^{-j ω^T r} dr.
```

然后，通过逆傅里叶变换，我们得到

```
κ(x − y) = ∫_{ℝ^l} p(ω) e^{j ω^T (x − y)} dω.   (11.89)
```

将 `p(ω)` 解释为 PDF 后，公式 [(11.89)](#Chp011_519-582_B9780443292385000172.xhtml#deq200) 右侧即为相应的期望，即

```
κ(x − y) = 𝔼_ω[ e^{j ω^T x} e^{−j ω^T y} ].
```

利用欧拉公式^([^(80)](#fn80)) 可消除复指数项：

```
z_{ω,b}(x) := √2 cos(ω^T x + b),   (11.90)
```
