
请注意，为了获得 $\widehat{\mathbf{\theta}}$，所需的只是拉格朗日乘子的值。正如附录 C 所讨论的，这些值可以通过将问题写成其对偶表示形式来获得，即：

```
maximize with respect to $\mathbf{\lambda},\widetilde{\mathbf{\lambda}}$
$\sum\limits_{n = 1}^{N}(\widetilde{\lambda}_{n} - \lambda_{n})y_{n} - \epsilon(\widetilde{\lambda}_{n} + \lambda_{n})
- \frac{1}{2}\sum\limits_{n = 1}^{N}\sum\limits_{m = 1}^{N}(\widetilde{\lambda}_{n} - \lambda_{n})(\widetilde{\lambda}_{m} - \lambda_{m})\mathbf{x}_{n}^{T}\mathbf{x}_{m}$,
```

约束条件为 $0 \le \widetilde{\lambda}[n] \le C$，$0 \le \lambda[n] \le C$，$n = 1, 2, \dots, N$，

```
$\sum\limits_{n = 1}^{N}\widetilde{\lambda}_{n} = \sum\limits_{n = 1}^{N}\lambda_{n}$.
```
