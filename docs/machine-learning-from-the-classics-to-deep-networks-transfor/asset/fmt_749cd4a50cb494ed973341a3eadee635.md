
### First convolutional layer

This is a standard convolutional layer. The filter matrix (kernel) is `9 × 9`, the stride is `s = 1`, and the depth (number of channels) is `d = 256`. Thus, the size of the output volume of the first hidden layer is `k × k × 256`, where `k = ⌊(28 - 9) / 1 + 1⌋ = 20`.

### Primary capsules

This is also a convolutional layer. The difference with the previous one is that in this layer a *grouping* of activities takes place. The filter matrix for the convolutions is also `9 × 9`, the stride is `s = 2`, and the depth is `d = 256`. However, the output channels are clustered together in groups of 8. Thus, 32 volumes are formed, each of depth 8 (total 256) (see [Fig. 18.40](#Chp018_885-995_B978044329238500024X.xhtml#f0215)). Each one of the volumes has size `k × k × 8`, where `k = ⌊(20 - 9) / 2 + 1⌋ = 6`.

[Fig. 18.41](#Chp018_885-995_B978044329238500024X.xhtml#f0220) illustrates how the capsules are formed. For the example of the figure, each capsule is of dimension `d = 8`. For each one of the 32 volumes, 36 (6 × 6) eight-dimensional tubes/vectors are formed. In other words, each capsule corresponds to a specific location in the feature map arrays. Hence, each one of the eight dimensions in a capsule *encapsulates* activity within a corresponding receptive field in the volume of the previous layer (see [Fig. 18.40](#Chp018_885-995_B978044329238500024X.xhtml#f0215)). Thus, a total of `36 × 32 = 1152` capsules are obtained, each one of dimension equal to 8. These vectors comprise the *outputs* of the second layer. Let us denote each one of the produced capsules as **u**[i], `i = 1, 2, …, I`, where `I = 1152`.
