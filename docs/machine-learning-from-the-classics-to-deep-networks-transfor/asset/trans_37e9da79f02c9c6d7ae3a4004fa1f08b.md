
假设我们有两组随机变量，分别构成两个随机向量的分量：`x ∈ ℝ^p` 和 `y ∈ ℝ^q`。对应的观测值集合分别为 `x_n, y_n, n = 1, 2, …, N`。遵循逐步过程（正如我们对 PCA 所做的那样），我们将首先计算一对方向，即 `u_x,1, u_y,1`，使得投影到这些方向上的相关性最大化。

令 `z_x,1 := u_x,1^T x` 和 `z_y,1 := u_y,1^T y` 为线性变换（投影）后的（零均值）随机变量。注意，这些变量是 PCA 中所谓主成分的对应物。对应的相关系数（归一化协方差）定义为：

```
ρ := E[z_x,1 z_y,1] / √(E[z_x,1^2] E[z_y,1^2])
   = E[(u_x,1^T x)(y^T u_y,1)] / √(E[(u_x,1^T x)^2] E[(u_y,1^T y)^2])
```
