
### 7.7.2 Fisher's discriminant: the two-class case

In Fisher's linear discriminant analysis, the emphasis in Eq. [(7.54)](#Chp007_293-342_B9780443292385000135.xhtml#deq85) is only on `θ`; the bias term `θ[0]` is left out of the discussion. The inner product `θ^(T)x` can be viewed as the projection of `x` along the vector `θ`. Strictly speaking, we know from geometry that the respective projection is also a vector, `y`, given by (e.g., Section [5.6](#Chp005_177-248_B9780443292385000111.xhtml))

**Mathematical Derivations**

The trace of the between-class scatter matrix is defined as:

```
trace{Σ_b} = ∑_{k=1}^{3} P(ω_k) [ (μ_{k1} - μ_{01})^2 + (μ_{k2} - μ_{02})^2 ]
```

This can be expressed in vector notation as:

```
= ∑_{k=1}^{3} P(ω_k) ||μ_k - μ_0||^2 := s_b,
```

where `μ_k = [μ_{k1}, μ_{k2}]^T` is the mean value for the *k*th class and `μ_0 = [μ_{01}, μ_{02}]^T` is the global mean vector.

The criterion `J_1` is then defined as:

```
J_1 = (s_w + s_b) / s_w = 1 + s_b / s_w.
```

In other words, the smaller the average total variance is and the larger the average squared Euclidean distance of the mean values from the global one gets, the larger the value of `J_1` becomes. Similar arguments can be made for the other two criteria.
