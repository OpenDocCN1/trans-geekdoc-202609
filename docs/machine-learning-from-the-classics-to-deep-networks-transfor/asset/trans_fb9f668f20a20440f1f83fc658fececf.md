
可以很容易地验证 `P(y|x) = P(y)`（独立于 `P(x = 1)` 和 `P(x = 0)` 的值），并且变量 x 和 y 是独立的；这无法通过观察 `d`-分离来预测。然而请注意，如果我们稍微扰动条件概率的值，那么所得到的分布将拥有与 `d`-分离所预测的同样多的独立性，即在本例中为零。事实上，这是一个更普遍的结果。如果我们有一个在图上分解的分布，该分布具有相应 `d`-分离无法预测的独立性，那么一个微小的扰动几乎总是会消除它们（例如，[25]）。

### 定义 15.5

节点的**马尔可夫毯**是由以下节点组成的集合：(a) 其父节点，(b) 其子节点，以及 (c) 与该节点共享子节点的节点。一旦节点毯中的所有节点都被实例化，该节点就会与网络的其余部分 `d`-分离（问题 [15.7](#Chp015_755-803_B9780443292385000214.xhtml#o0075)）。

例如，在 [图 15.9](#Chp015_755-803_B9780443292385000214.xhtml#f0050) 中，`x[5]` 的马尔可夫毯包含节点 `x[3]`、`x[4]`、`x[8]`、`x[7]`、`x[6]`。请注意，如果所有这些节点都被实例化，那么 `x[5]` 就会与其余节点 `d`-分离。
