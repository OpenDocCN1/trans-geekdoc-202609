
注意：在取消任务中，目标是从未知系统 `H` 中“移除”（过滤后的）输入信号 `u[n]`。在系统辨识中，重点在于（未知的）系统本身。在**去卷积**中，重点在于未知系统的输入。也就是说，我们现在的目标是以 MSE 最优意义恢复一个（延迟的）输入信号 `d[n] = s[n - L]`，其中 `L` 是以采样周期 `T` 为单位的延迟。该任务也称为**反系统辨识**。术语**均衡**或**信道均衡**用于通信领域。去卷积任务是在图像去模糊的背景下在第 [4.6](#Chp004_119-175_B978044329238500010X.xhtml#s0055) 节中引入的。在那里，关于*未知*输入过程的所需信息是通过近似获得的。在当前框架中，这可以通过发送训练序列来实现。

**均衡器**的目标是通过减轻任何（不完美的）色散通信信道施加在发射信号上的所谓**符号间干扰**（ISI）来恢复发射的信息符号；除了 ISI，加性噪声也存在于发射的信息比特中（参见[示例 4.2](#Chp004_119-175_B978044329238500010X.xhtml#enun0030)）。均衡器如今“无处不在”；在我们的手机、调制解调器等设备中。[图 4.12](#Chp004_119-175_B978044329238500010X.xhtml#f0065) 展示了均衡器的基本方案。均衡器经过训练，使其输出尽可能接近延迟某个时滞 `L` 后的发射数据比特；该延迟用于解释信道-均衡器系统施加的总延迟。去卷积/信道均衡是除通信之外许多应用的核心，如声学、光学、地震信号处理和控制。信道均衡任务将在下一章中结合决策反馈均衡运行模式下的在线学习进行讨论。

