
减少参数数量的一种方法是通过*权重共享*，这在[第18.3.1节](#Chp018_885-995_B978044329238500024X.xhtml#s0025)末尾已简要讨论。我们现在将借用这一权重共享的思想，并以更复杂的方式加以利用。为此，让我们关注网络输入包含图像的情况。输入图像数组记为`I`。对于[图18.18](#Chp018_885-995_B978044329238500024X.xhtml#f0100)A的情况，这是一个3×3数组；注意输入*未*向量化。为了强调我们将摆脱全连接前馈网络中乘加（内积）运算的基本原理，我们将使用不同的符号`h`，而不是`θ`，来表示相关参数。

现在让我们引入权重/参数共享的概念。回想一下，在全连接网络中，每个节点都与一个参数*向量* **θ**[i] 相关联，用于第i个节点，其维度等于前一层节点的数量。相反，现在每个节点将仅与*单个*参数相关联。为此，将节点排列成二维数组的形式，如[图18.18](#Chp018_885-995_B978044329238500024X.xhtml#f0100)B所示。对于图中的情况，我们假设有四个节点排列成2×2数组`H`。第一个节点由`h(1, 1)`表征，第二个由`h(1, 2)`表征，依此类推。换句话说，任何终止于第一个节点的连接都将乘以相同的权重`h(1, 1)`，其余节点也有类似的论证。这种基本原理大幅减少了参数数量。然而，为了使其合理，我们必须摆脱全连接网络内积运算的基本原理。确实，为了理解原因，让我们假设在全连接网络中每个节点使用单个参数。那么与第一个节点相关的线性组合器的输出将是`O(1, 1) = h(1, 1)a`，其中`a`是从前一层接收到的节点所有输入之和。第二个节点的相应输出将是`O(1, 2) = h(1, 2)a`，依此类推。因此，所有节点基本上将提供关于输入值的相同信息；唯一的区别将是作用在来自前一层的*相同*输入信息上的不同权重。

现在让我们引入一个不同的概念，即我们保持每个节点一个参数，但隐藏层的每个输出都传达关于从前一层接收到的各种输入的*不同*信息。为此，我们将引入卷积。在此背景下，隐藏层的节点被解释为数组`H`的元素，我们将`H`与输入数组`I`进行卷积。隐藏层的第一个输出值将是

```
O(1, 1) = h(1, 1)I(1, 1) + h(1, 2)I(1, 2) + h(2, 1)I(2, 1) + h(2, 2)I(2, 2).
```
