
# 状态空间模型用于序列数据

建模序列数据的一种非常流行且有效的框架是通过所谓的*状态-观测*或*状态空间*模型。在时间 *n* 观测到的每组随机变量 **y**[*n*] ∈ ℝ<sup>l</sup>，都与一个相应的未观测（隐含）随机向量 **x**[*n*] 相关联（其维数不一定与观测值的维数相同）。系统动态通过隐含变量建模，而观测值被视为带有*噪声*的传感设备的输出。所谓的隐马尔可夫模型建立在以下两个独立性假设之上：

(1) **x**[*n* + 1] ⊥ (**x**[1], …, **x**[*n* − 1]) | **x**[*n*], (16.24)

(2) **y**[*n*] ⊥ (**x**[1], …, **x**[*n* − 1], **x**[*n* + 1], …, **x**[*N*]) | **x**[*n*], (16.25)

其中 *N* 是观测总数。第一个条件通过转移模型定义系统动态：

*p*(**x**[*n* + 1] | **x**[1], …, **x**[*n*]) = *p*(**x**[*n* + 1] | **x**[*n*]), (16.26)

第二个条件通过观测模型定义：

*p*(**y**[*n*] | **x**[1], …, **x**[*N*]) = *p*(**y**[*n*] | **x**[*n*]). (16.27)

简而言之，*给定当前，未来独立于过去；给定当前，观测值独立于未来和过去*。

上述独立性通过[图 16.15](#Chp016_805-853_B9780443292385000226.xhtml#f0080)的图形进行图形化表示。如果隐含变量是离散性质的，则生成的模型称为隐马尔可夫模型。另一方面，如果隐含变量和观测变量均为连续性质，则生成的模型处理起来会相当复杂。然而，对于某些特殊情况，已经开发并可以开发出解析上可处理的工具。在所谓的*线性动态系统*（LDS）中，系统动态和观测值的生成建模为：

**x**[*n*] = *F*[*n*]**x**[*n* − 1] + **η**[*n*], (16.28)
