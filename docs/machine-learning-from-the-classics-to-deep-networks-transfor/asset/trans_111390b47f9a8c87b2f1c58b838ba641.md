

### 支持向量机中的点分类

*   **位于分类器正确一侧但在边界内的点（圆圈标记）**：即
    $$0 < y_n f(\mathbf{x}_n) < 1.$$
    ![Equation](images/B9780443292385000172/si376.png)

*   这些点犯了边界错误，且满足公式 [(11.62)](#Chp011_519-582_B9780443292385000172.xhtml#deq145) 中的不等式：
    $$0 < \xi_n < 1.$$
    ![Equation](images/B9780443292385000172/si377.png)

*   **位于分类器错误一侧的点（方块标记）**：即
    $$y_n f(\mathbf{x}_n) \le 0.$$
    ![Equation](images/B9780443292385000172/si378.png)

*   这些点犯了分类错误，且满足公式 [(11.62)](#Chp011_519-582_B9780443292385000172.xhtml#deq145) 中的不等式：
    $$1 \le \xi_n.$$
    ![Equation](images/B9780443292385000172/si379.png)

![Figure 11.17 当类别重叠时，存在三类点：(a) 位于边界外或边界上且分类正确的点（$\xi_n = 0$）；(b) 位于边界内且分类正确的点（$0 < \xi_n < 1$），用圆圈表示；(c) 分类错误的点，用方块表示（$\xi_n \ge 1$）。](images/B9780443292385000172/gr017.jpg)

**图 11.17** 当类别重叠时，存在三类点：(a) 位于边界外或边界上且分类正确的点（$\xi_n = 0$）；(b) 位于边界内且分类正确的点（$0 < \xi_n < 1$），用圆圈表示；(c) 分类错误的点，用方块表示（$\xi_n \ge 1$）。

我们希望估计一个超平面分类器，以**最大化边界，同时将错误数量（包括边界错误）保持在尽可能小的水平**。如果用指示函数 $I(\xi_n)$ 代替 $\xi_n$，这一目标可通过优化任务 [(11.61)](#Chp011_519-582_B9780443292385000172.xhtml#deq144)–[(11.62)](#Chp011_519-582_B9780443292385000172.xhtml#deq145) 来表达，其中

$$
I(\xi) = \begin{cases}
1, & \text{if } \xi > 0, \\
0, & \text{if } \xi = 0.
\end{cases}
$$
![Equation](images/B9780443292385000172/si381.png)

然而，在这种情况下任务变成了组合优化问题。因此，我们放宽条件，用 $\xi_n$ 代替指示函数，从而得到公式 [(11.61)](#Chp011_519-582_B9780443292385000172.xhtml#deq144)–[(11.62)](#Chp011_519-582_B9780443292385000172.xhtml#deq145)。注意，优化是在权衡的原则下实现的；用户定义的参数 $C$ 控制着最小化任务中两个贡献项的影响力。若 $C$ 很大，所得边界（由 $f(\mathbf{x}) = \pm 1$ 定义的两个超平面之间的距离）将很小，以减少边界错误的数量。若 $C$ 很小，情况则相反。正如我们将从仿真示例中看到的，$C$ 的选择至关重要。

#### 解

解再次表示为训练点子集的线性组合：

$$
\widehat{\boldsymbol{\theta}} = \sum_{n=1}^{N_s} \lambda_n y_n \mathbf{x}_n,
$$
![Equation](images/B9780443292385000172/si351.png) (11.79)
