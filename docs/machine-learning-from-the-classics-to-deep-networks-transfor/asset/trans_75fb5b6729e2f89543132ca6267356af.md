

#### 功率谱密度的物理解释

我们现在准备好论证为何自相关序列的傅里叶变换被赋予了“功率谱密度”这一特定名称。我们将讨论限制在实随机过程上，尽管类似的论证对更一般的复数情况也同样成立。[图 2.14](#Chp002_19-64_B9780443292385000081.xhtml#f0075) 显示了一个非常特殊的线性系统的冲激响应的傅里叶变换的幅值。对于频率范围 $|\omega - \omega_{o}| \leq \frac{\Delta\omega}{2}$ 内的任意频率，傅里叶变换为单位值，否则为零。这样的系统被称为*带通滤波器*。我们假设 $\Delta\omega$ 非常小。然后，利用公式 [(2.130)](#Chp002_19-64_B9780443292385000081.xhtml#deq150) 并假设在区间 $|\omega - \omega_{o}| \leq \frac{\Delta\omega}{2}$ 内，$S_{u}(\omega) \approx S_{u}(\omega_{o})$，我们得到

```
S_{d}(\omega) = \begin{cases} {S_{u}(\omega_{o}),\;} & {\text{if}\ \ |\omega - \omega_{o}| \leq \frac{\Delta\omega}{2},} \\ {0,\;} & {\text{otherwise}.} \\ \end{cases}
```
