

$$f^{\ast}(\mathbf{\xi}) = \max\limits_{\mathbf{x}}\left\{ \mathbf{\xi}^{T}\mathbf{x} - f(\mathbf{x}) \right\},$$

称为 *f* 的 *共轭*。共轭函数的定义域由所有使最大值有限的 $\mathbf{\xi} \in \mathbb{R}^{(l)}$ 组成。共轭函数的一个显著性质是其 *凸性*；无论 *f* 是否为凸函数，此性质均成立。这种凸性是一族（关于 $\mathbf{\xi}$ 为凸的）仿射函数逐点最大化的结果 [12]。

对公式 [(13.78)](#Chp013_635-716_B9780443292385000196.xhtml#deq114) 关于 $\mathbf{x}$ 进行最大化，得到 $\mathbf{x}^{\ast}$ 的值，使得

$$\mathbf{x}^{\ast} : \nabla f(\mathbf{x}^{\ast}) = \mathbf{\xi}, \tag{13.79}$$

进而得到值

$$f^{\ast}(\mathbf{\xi}) = \mathbf{\xi}^{T}\mathbf{x}^{\ast} - f(\mathbf{x}^{\ast}). \tag{13.80}$$

公式 [(13.79)](#Chp013_635-716_B9780443292385000196.xhtml#deq115) 和 [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116) 给出了共轭函数的几何解释。线性函数 $\mathbf{\xi}^{T}\mathbf{x}$ 的图像定义了一个超平面，其方向由 $\mathbf{\xi}$ 控制；后者现在等于 $\nabla f(\mathbf{x}^{\ast})$，这定义了 $f(\mathbf{x})$ 的图像在 $\mathbf{x}^{\ast}$ 处的切超平面的方向。该切超平面可描述为

$$g(\mathbf{x}) = f(\mathbf{x}^{\ast}) + (\mathbf{x} - \mathbf{x}^{\ast})^{T}\nabla f(\mathbf{x}^{\ast}),$$

或利用公式 [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116)，

$$g(\mathbf{x}) = \mathbf{\xi}^{T}\mathbf{x} - f^{\ast}(\mathbf{\xi}). \tag{13.81}$$
