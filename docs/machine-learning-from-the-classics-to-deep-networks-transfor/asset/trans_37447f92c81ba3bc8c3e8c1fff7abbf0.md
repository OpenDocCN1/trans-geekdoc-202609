
我们假设先验分布不依赖于任何参数。下界包含两项。右侧第一项是关于潜在变量的期望值。为了最大化下界，该项应针对各自的观测值 `x[n]` 进行最大化；这促使解码器学会*重构*数据。第二项是非正的（KL 散度是非负量，见 [问题 12.7](#Chp012_583-634_B9780443292385000184.xhtml)）。为了最大化下界，应最小化 KL 散度；因此，相应的后验分布将保持接近先验分布；后者被选为标准多元高斯分布 `N(z|0, I)`。因此，先验充当正则化项，将网络的潜在变量“推”向标准高斯分布，使其尽可能紧密地匹配。

先验的存在至关重要。正则化项“迫使”潜在变量的后验分布足够宽泛。例如，我们不希望同一类别的两个不同图像/样本被映射到潜在空间中两个不同且相距甚远的区域；即我们不希望它们对应的概率密度函数（PDF）非常窄、方差很小，且均值相差很大。我们的愿望是将同一类别的每个输入样本通过潜在变量映射/编码到潜在空间中一个足够小的区域内，使其彼此“足够接近”。我们的愿望是构建一个在局部尺度上对于相同样本足够平滑的潜在空间。事实上，我们的目标应是构建尽可能紧密（稠密堆积）的编码，同时仍保持不同类别之间的区分度（簇形成）。这将有利于在生成新样本时在不同类别之间进行平滑插值。此外，这种由 KL 项促进的稠密编码堆积，将极大地有助于根据标准高斯先验 `N(0, I)` 对潜在变量进行采样，并使解码器能够成功解码和生成样本。

一旦确定了所涉及分布的参数形式，剩下的工作就是针对未知参数最大化 `F`。考虑到采用的模型是前馈神经网络，优化任务所需的梯度是在反向传播框架下计算的。为此，引入了以下“技巧”，参见例如 [103]。

### 重参数化技巧

反向传播算法要求计算公式 [(19.22)](#Chp019_997-1102_B9780443292385000251.xhtml#deq47) 中损失函数的梯度。正如我们即将看到的，KL 散度项不存在计算问题。相反，右侧第一项需要更多关注。在反向传播算法的每一步中，计算相应的梯度需要针对后验 PDF `q` 的当前估计进行平均运算。然而，事实证明，遵循标准论证（例如 [20]）通过从 `q` 中采样来获得相应平均梯度值的估计，会导致高方差的估计，使该方法相当不切实际，例如 [103]。

前述困难通过所谓的重参数化技巧得以绕过。其思路是将每一个潜在变量视为以下两方面的函数：a) 定义相应分布的参数（本例中为高斯分布）以及 b) 一个处理相关随机性的独立辅助随机变量。例如，在高斯分布的情况下，定义参数是均值和方差（协方差矩阵）。辅助随机变量可以服从简单的 PDF（例如高斯或均匀分布）。只需该函数是*可微*的。在当前语境下，隐含的变换是线性的，涉及的随机潜在变量表示为

```
z[i] = μ[i] + σ[i]ε[i], i = 1, 2, …, m,
```

其中 `ε[i]` 是均值为零、方差为单位的相应辅助随机变量。将 `ε[i], i = 1, 2, …, m` 堆叠成随机向量 `ε ∈ ℝ^(m)`，则对应于 `x[n]` 的潜在随机向量可写为

```
z[n] = μ[n] + σ[n] ⊙ ε,
```
