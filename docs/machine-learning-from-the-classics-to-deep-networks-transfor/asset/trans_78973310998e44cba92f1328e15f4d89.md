```
𝒬(Θ, Θ^(t)) = 𝔼[ln p(Y, X; Θ)],
```

其中 `𝔼[·]` 是关于 `P(X|Y; Θ^(t))` 的期望。由公式 [(16.32)](#Chp016_805-853_B9780443292385000226.xhtml#deq64)–[(16.35)](#Chp016_805-853_B9780443292385000226.xhtml#deq67) 可得

```
ln p(Y, X; Θ) = ∑_{k=1}^K (x_{1,k} ln P_k + ln p(y_1|k; θ_k))
              + ∑_{n=2}^N ∑_{i=1}^K ∑_{j=1}^K (x_{n-1,j} x_{n,i}) ln P_{ij}
              + ∑_{n=2}^N ∑_{k=1}^K x_{n,k} ln p(y_n|k; θ_k),
```
