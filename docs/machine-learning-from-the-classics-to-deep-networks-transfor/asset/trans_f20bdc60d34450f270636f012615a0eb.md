

### 20.8.3 因子分析器混合模型：压缩感知的贝叶斯视角

让我们回到公式 [(20.79)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq113) 中的原始模型，并将其重述为一种更“流行”的形式。矩阵 `A` 的维度为 `l × m`，其中 `m < l`，且 `z ∈ ℝ^(m)`。现在令 `m > l`。例如，`A` 的列可能包含一个过完备字典的向量。因此，本节可被视为第 [20.6](#Chp020_1103-1179_B9780443292385000263.xhtml#s0105) 节的概率对应版本。通过对 `z` 施加稀疏性来表达建模所需的低维性；我们可以用相应的观测值来重写模型 [47]

```
x[n] = A(z[n] ∘ b) + ϵ[n],  n = 1, 2, …, N,
```

其中 `N` 是训练点的数量，向量 `b ∈ ℝ^(m)` 的元素为 `b[i] ∈ {0, 1}, i = 1, 2, …, m`。乘积 `z[n] ∘ b` 是逐点向量乘积，即

```
z[n] ∘ b = [z[n](1)b[1], z[n](2)b[2], …, z[n](m)b[m]]^(T).
```
