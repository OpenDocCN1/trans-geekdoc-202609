
## 2. 6.19

给定一组中心化数据点 $(y[n], \mathbf{x}[n]) \in \mathbb{R}^{l+1}$，推导一个超平面

$$\mathbf{a}^T\mathbf{x} + y = 0$$

1.  该超平面穿过原点，使得所有点到该超平面的总平方距离最小。

### 计算机练习

#### 1. 6.20

考虑回归模型

$$y[n] = \boldsymbol{\theta}_o^T\mathbf{x}[n] + \eta[n]$$

其中 $\boldsymbol{\theta}_o \in \mathbb{R}^{200}$ ($l = 200$) ，未知向量的系数通过高斯分布 $\mathcal{N}(0, 1)$ 随机获得。噪声样本也是独立同分布的，符合零均值、方差 $\sigma_\eta^2 = 0.01$ 的高斯分布。输入序列为白噪声，通过高斯分布 $\mathcal{N}(0, 1)$ 独立同分布生成。

#### 2.

使用训练数据样本 $(y[n], \mathbf{x}[n]) \in \mathbb{R} \times \mathbb{R}^{200},\ n = 1, 2, \dots$ ，运行 APA（[算法 5.2](#Chp005_177-248_B9780443292385000111.xhtml)）、NLMS 算法（[算法 5.3](#Chp005_177-248_B9780443292385000111.xhtml)）和 RLS 算法（[算法 6.1](#Chp006_249-291_B9780443292385000123.xhtml#enun0020)）来估计未知的 $\boldsymbol{\theta}_o$。

#### 3.

对于 APA，选择 $\mu = 0.2$，$\delta = 0.001$，$q = 30$。此外，在 NLMS 中设置 $\mu = 1.2$ 和 $\delta = 0.001$。最后，对于 RLS 设置遗忘因子 $\beta = 1$。运行 100 次独立实验并绘制每次迭代的平均误差（dB），即 $10\log_{10}(e[n]^2)$，其中 $e[n]^2 = (y[n] - \mathbf{x}[n]^T\boldsymbol{\theta}[n-1])^2$。比较各算法的性能。

#### 4.

尝试调整不同参数，研究它们对收敛速度和算法收敛时的误差底的影响。
