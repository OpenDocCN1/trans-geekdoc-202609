
其中我们已将偏置 `θ[0]` 吸收进 `θ` 中，并按前述方式扩展了 `x` 的维度。我们的目标是将该超平面置于两个类别之间。显然，位于该超平面上的任意点得分为零，即 `f(x) = 0`；而位于超平面两侧的点得分则为正值（`f(x) > 0`）或负值（`f(x) < 0`），具体取决于它们位于超平面的哪一侧。因此，我们应训练分类器，使得来自某一类别的点得分为正值，而来自另一类别的点得分为负值。例如，可通过将类别 `ω[1]` 中的所有点标记为 `y[n] = 1`，`∀n : x[n] ∈ ω[1]`，将类别 `ω[2]` 中的所有点标记为 `y[n] = −1`，`∀n : x[n] ∈ ω[2]` 来实现。随后引入平方误差来计算 `θ` 以最小化代价，即：

```
J(θ) = ∑_{n=1}^{N} (y_n - θ^T x_n)^2.
```

其解与公式 [(3.13)](#Chp003_65-117_B9780443292385000093.xhtml#deq16) 完全相同。[图 3.6](#Chp003_65-117_B9780443292385000093.xhtml#f0035) 展示了两种数据情况下的 LS 分类器结果。观察可知，在 [图 3.6](#Chp003_65-117_B9780443292385000093.xhtml#f0035)B 的情况下，得到的分类器无法正确分类所有数据点。我们希望将源自某一类别的所有数据置于一侧、其余数据置于另一侧的愿望无法得到满足。LS 分类器所能做的仅是放置超平面，使得期望（真实）标签值 `y[n]` 与预测输出值 `θ^T x[n]` 之间的平方误差之和最小。主要正是针对重叠类别这类在实践中常遇到的情况，人们才不得不寻找平方误差准则和方法的替代方案，以更好地服务于分类任务的需求与目标。例如，一个合理的最优性准则是将错误概率最小化，即真实标签 `y[n]` 与分类器预测标签 `ŷ[n]` 不同的点所占的百分比。第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章介绍了适用于分类任务的方法与损失函数。第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章讨论了支持向量机，第 [18](#Chp018_885-995_B978044329238500024X.xhtml) 章和第 [19](#Chp019_997-1102_B9780443292385000251.xhtml) 章则介绍了神经网络与深度学习方法。这些目前均属于解决分类问题最强大的技术之一。
