
where `μ` is the mean of `x` and `A ∈ ℝ^(l×m)` is formed by the weights `a[i][j]` known as *factor loadings*. The variables `z[j]`, `j = 1, 2, …, m`, are sometimes called *common factors*, because they contribute to all observed variables, `x[i]`, and `ϵ[i]` are the *unique* or *specific factors*. As we have already done so far and without loss of generality, we will assume our data are centered, that is, `μ = 0`. In factor analysis, we assume `ϵ[i]` to be of zero mean and mutually uncorrelated, that is, `Σ[ϵ] = 𝔼[ϵϵ^T] := diag{σ[1]², σ[2]², …, σ[l]²}`. We also assume that `z` and `ϵ` are independent. The `m` (`< l`) columns of `A` form a lower-dimensional subspace, and `ϵ` is that part of `x` not contained in this subspace. The first question that is now raised is whether the model in Eq. [(20.79)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq113) is any different from our familiar regression task. The answer is in the affirmative. Note that here the matrix `A` is not known. All that we are given is the set of observations, `x[n]`, `n = 1, 2, …, N`, and we have to obtain the subspace described by `A`. It is basically the same linear model that we have considered so far in this chapter, with the difference that now we have introduced the noise term. Once `A` is known, `z[n]` can be obtained for each `x[n]`.

From Eq. [(20.79)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq113), it is readily seen that

```
Σ[x] = 𝔼[xx^T] = A𝔼[zz^T]A^T + Σ[ϵ].
```

We will further assume that `𝔼[zz^T] = I`; hence, we can write

```
Σ[x] = AA^T + Σ[ϵ]. (20.80)
```
