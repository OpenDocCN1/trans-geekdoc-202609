
此外，我们已经在[14.5节](#Chp014_717-754_B9780443292385000202.xhtml)中指出，重要性采样的一个主要缺点是权重的方差很大，这在高维空间中会变得更加严重，而我们从现在开始的兴趣将集中在高维空间。让我们进一步详述方差问题，并寻找绕过/减少这种不良行为的方法。

可以证明（例如参考文献[35]和习题[17.1](#Chp017_855-884_B9780443292385000238.xhtml#o0030)），公式[(17.1)](#Chp017_855-884_B9780443292385000238.xhtml#deq1)中相应估计量`μ̂`的方差由下式给出：

```
var[μ̂] = (1/N) ( ∫ f²(x)p²(x)/q(x) dx - μ_f² )
```

观察可知，如果分子`f²(x)p²(x)`趋向于零的速度比`q(x)`慢，那么对于固定的`N`，方差`var[μ̂] → ∞`。这表明非常仔细地选择`q`至关重要。通过最小化公式[(17.4)](#Chp017_855-884_B9780443292385000238.xhtml#deq4)不难发现，使方差达到最小（零）的`q(x)`的最优选择与乘积`f(x)p(x)`成正比（不妨一试！）。我们稍后将利用这一结果。当然，请注意比例常数应为`1/μ[f]`，这是未知的。因此，这一结果只能作为一个基准。

关于方差问题，让我们把注意力转向公式[(17.2)](#Chp017_855-884_B9780443292385000238.xhtml#deq2)中`Z`的无偏估计量`Ẑ`。可以证明（习题[17.2](#Chp017_855-884_B9780443292385000238.xhtml#o0035)）：

```
var[Ẑ] = (Z²/N) ( ∫ p²(x)/q(x) dx - 1 )
```

根据其定义，`Ẑ`的方差与权重的方差直接相关。事实证明，在实践中，公式[(17.5)](#Chp017_855-884_B9780443292385000238.xhtml#deq5)中的方差呈现出对维数的指数依赖性（例如参考文献[12,16]和习题[17.5](#Chp017_855-884_B9780443292385000238.xhtml#o0050)）。在这种情况下，样本数`N`必须过大，才能使方差保持相对较小。部分应对与方差相关问题的一种方法是*重采样*技术。
