

# 6.2 最小二乘线性回归：几何视角

平方误差损失函数是前两章关注的中心。平方误差和代价函数在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中引入，随后是均方误差（MSE）版本，在第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章中进行了探讨。随机梯度下降技术在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中被采用，帮助我们绕过了根据 MSE 公式要求计算数据二阶统计量所需的期望运算。

在本章中，我们回到平方误差和的原始公式，我们的目标是更仔细地审视由此产生的算法族及其性质。重点在于最小二乘（LS）方法的几何解释，以及所得解的一些最重要的统计性质。矩阵的奇异值分解（SVD）在本书中首次被引入。讨论了其几何正交化性质，并建立了其与所谓降维之间的联系；后一主题在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章中得到了广泛探讨。此外，本章的很大一部分专门用于递归最小二乘（RLS）算法，这是一种求解 LS 优化任务的在线方案。RLS 方案的核心在于输入数据逆（样本）协方差矩阵的高效更新，其基本原理也可用于不同学习方法的背景中，以开发相关的在线方案；这是我们特别推崇 RLS 算法的原因之一。另一个原因是它在大量信号处理/机器学习任务中广受欢迎，因为该方案具有某些吸引人的特性。介绍了两种主要的优化方案，即牛顿法和坐标下降法，并讨论了它们在求解 LS 任务中的应用。建立了 RLS 方案与牛顿优化方法之间的联系。最后，在本章末尾，还介绍了 LS 任务的一个更一般化公式，即全最小二乘（TLS）方法。

本节的重点是概述 LS 方法的几何性质。这为相应的最小化任务提供了另一种视角，并通过揭示与所得解相关的几何结构，有助于对其理解。在处理与降维任务相关的概念时，几何非常重要。

我们从熟悉的线性回归模型开始。给定一组观测值，

```
y[n] = θ^(T)x[n] + η[n], n = 1, 2, …, N, y[n] ∈ ℝ, x[n] ∈ ℝ^(l), θ ∈ ℝ^(l),
```

其中 `η[n]` 表示*零*均值噪声源的（未观测）值，任务是获得未知参数向量 `θ` 的估计，由下式给出：

```
θ̂_LS = argmin_θ Σ_{n=1}^N (y_n - θ^T x_n)^2.  (6.1)
```
