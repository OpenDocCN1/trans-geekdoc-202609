
Another algorithmic variant is the so-called *composite mirror descent*, which employs the currently available estimate of the subgradient, instead of the average, combined with the Bregman divergence; that is, `${\\overline{\\mathcal{L}}}^{\\prime}$` is replaced by `ℒ[*n* − 1]^′` and `*ψ*(**θ**)` by `*B*[*ψ*](**θ**, **θ**[*n* − 1])` for some function `*ψ*` [37]. In [38], a time-varying `*ψ*[*n*]` is involved by using a weighted average of the Euclidean norm. Note that in these modifications, although they may look simple, the analysis of the respective algorithms can be quite hard and substantial differences can be obtained in the performance.

In proximal-type algorithms the base operation is solving a small optimization problem at each iteration. In general, these subproblems can be solved with standard methods and, often, they admit a closed form solution. Proximal algorithms are well suited for big data application involving high dimensional datasets, e.g., [67].

## 8.15 Distributed optimization: some highlights

Distributed optimization (e.g., [86]) has already been discussed in the context of the stochastic gradient descent with an emphasis on LMS and diffusion-type algorithms in Chapter [5](#Chp005_177-248_B9780443292385000111.xhtml) and also in Section [8.9](#Chp008_343-416_B9780443292385000147.xhtml#s0085). At the heart of distributed or decentralized optimization lies a cost function,

```
$J(\\mathbf{\\theta}) = \\sum\\limits\_{k = 1}^{K}J\_{k}(\\mathbf{\\theta}),$
```

which is defined over a connected network of *K* nodes (agents). Each `*J*[*k*]`, *k* = 1, 2, …, *K*, is fed with the *k*th node's data and quantifies the contribution of the corresponding agent to the overall cost. The goal is to compute a *common*, to all nodes, optimizer, `**θ**[\*]`. Moreover, each node communicates its updates, in the context of an iterative algorithm, *only* to its neighbors, instead of a common fusion center.

The *i*th step of the general iterative scheme of the so-called consensus algorithms (Section [5.13.4](#Chp005_177-248_B9780443292385000111.xhtml)) is of the form

```
$\\mathbf{\\theta}\_{k}^{(i)} = \\sum\\limits\_{m \\in \\mathcal{N}\_{k}}a\_{mk}\\mathbf{\\theta}\_{m}^{(i - 1)} + \\mu\_{i}\\nabla J\_{k}\\left( \\mathbf{\\theta}\_{k}^{(i - 1)} \\right),\\ k = 1,2,\\ldots,K,$
```
