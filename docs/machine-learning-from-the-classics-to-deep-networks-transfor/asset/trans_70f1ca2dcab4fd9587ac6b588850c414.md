

# 贝叶斯推断与 MAP 估计

## 后验分布

$$
p(\mathbf{\theta}|\mathbf{y},\mathbf{\alpha}) = \frac{P(\mathbf{y}|\mathbf{\theta})p(\mathbf{\theta}|\mathbf{\alpha})}{P(\mathbf{y}|\mathbf{\alpha})}
$$

![Equation](images/B9780443292385000196/si273.png)

## MAP 估计推导

1. 等价地，MAP 估计可表示为：

$$
{\widehat{\mathbf{\theta}}}_{MAP} = \arg\max_{\mathbf{\theta}}\ln\left( P(\mathbf{y}|\mathbf{\theta})p(\mathbf{\theta}|\mathbf{\alpha}) \right) = \arg\max_{\mathbf{\theta}}\left\{ \sum_{n = 1}^{N}\left[ y_{n}\ln\sigma\left( \mathbf{\theta}^{T}\mathbf{\phi}(\mathbf{x}_{n}) \right) + \right. \right.
$$

![Equation](images/B9780443292385000196/si274.png) (13.72)

2. 继续展开：

$$
\left. (1 - y_{n})\ln\left( 1 - \sigma\left( \mathbf{\theta}^{T}\mathbf{\phi}(\mathbf{x}_{n}) \right) \right)\right] - \frac{1}{2}\mathbf{\theta}^{T}A\mathbf{\theta} + \text{constant} \right\},
$$

![Equation](images/B9780443292385000196/si275.png) (13.73)

3. 其中 $A := \text{diag}\{\alpha[0], \alpha[2], \dots, \alpha[N]\}$。
