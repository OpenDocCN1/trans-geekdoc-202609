
也就是说，当所有元素的协方差 `cov(x[i], x[j]) = 0, i, j = 1, 2, …, l` 时，组成 **x** 的随机变量在统计上是 *独立* 的。一般来说，这并不成立。不相关的变量不一定独立；独立性是一个强得多的条件。然而，如果它们服从多元高斯分布，这确实成立。事实上，如果协方差矩阵是对角矩阵，那么多元高斯分布可以写为

```
p(x) = ∏_{i = 1}^{l} (1 / (√(2π) σ_i)) exp( - (x_i - μ_i)^2 / (2 σ_i^2) ).
```

换句话说，

```
p(x) = ∏_{i = 1}^{l} p(x_i),
```

这就是统计独立性的条件。

### 中心极限定理

这是概率论和统计学中最基本的定理之一，它部分解释了高斯分布广受欢迎的原因。考虑 *N* 个相互 *独立* 的随机变量，每个变量服从其自身的分布，均值为 `μ[i]`，方差为 `σ[i]², i = 1, 2, …, N`。定义一个新的随机变量为它们的和，

```
x = ∑_{i = 1}^{N} x_i.
```

则该新变量的均值和方差由下式给出

```
μ = ∑_{i = 1}^{N} μ_i  and  σ² = ∑_{i = 1}^{N} σ_i².
```

