

## 5.11 线性约束 LMS

线性约束 MSE 估计的任务已在 [4.9.2](#Chp004_119-175_B978044329238500010X.xhtml) 节中介绍。在此，我们将关注点转向其在线随机梯度对应算法。讨论将沿用涉及随机过程的线性滤波所用的符号约定进行，因为典型应用是波束成形；这也是我们将涉及复值公式的原因。然而，所述一切均适用于更一般的线性估计任务。

在 [4.9.2](#Chp004_119-175_B978044329238500010X.xhtml) 节中，目标是在满足一组约束条件下，最小化 MSE 或滤波器（波束成形器）的输出功率，从而分别得到代价函数 `w^H Σ[η] w` 或 `w^H Σ[u] w`。在更一般的设定中，我们将要求输出“接近”期望响应随机信号 `d[n]`。对于波束成形设定，这对应于期望的（训练）信号；即除了通过约束提供的期望方向外，我们还获得一个期望信号序列。此外，我们将假设解必须满足不止一个约束。现在的任务变为

```
w_* = argmin_w E[ |d_n - w^H u_n|^2 ] s.t. w^H c_i = g_i, i = 1,2,...,m,
```
