显然，如果观测值是独立同分布的，那么我们可以写成

$$p(\mathcal{X}|\boldsymbol{\theta}) = \prod_{n=1}^{N} p(\mathbf{x}_n|\boldsymbol{\theta}).$$

![Equation](images/B9780443292385000093/si334.png)

在上述公式中，$p(\boldsymbol{\theta})$ 是 $\boldsymbol{\theta}$ 的先验或*先验*分布，而 $p(\boldsymbol{\theta}|\mathcal{X})$ 是在获得 $N$ 个观测值集合后形成的条件或后验或*后验* PDF。先验概率密度 $p(\boldsymbol{\theta})$ 可以被视为一种约束，它*封装了我们关于 $\boldsymbol{\theta}$ 的先验知识*。毫无疑问，在接收到观测值后，我们对 $\boldsymbol{\theta}$ 的不确定性会发生改变，因为现在向我们揭示了更多信息。如果关于底层模型的采用假设是合理的，我们期望后验 PDF 能更准确地描述 $\boldsymbol{\theta}$ 的统计特性。我们将基于一组训练数据来近似随机量 PDF 的过程称为*推断*，以将其与返回每个参数/变量单一值的估计过程区分开来。因此，根据推断方法，人们试图得出关于相关变量所蕴含的随机性本质的结论。反过来，这些信息可用于进行预测和做出决策。

我们将以两种方式利用公式 [(3.63)](#Chp003_65-117_B9780443292385000093.xhtml#deq113)。第一种指的是我们熟悉的目标，即获得参数向量 $\boldsymbol{\theta}$ 的估计，该向量“控制”着描述我们观测值 $\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N$ 生成机制的模型。因为 $\mathbf{x}$ 和 $\boldsymbol{\theta}$ 是两个统计相关的随机向量，根据第 [3.9](#Chp003_65-117_B9780443292385000093.xhtml#s0065) 节，已知 $\mathcal{X}$ 的条件下 $\boldsymbol{\theta}$ 值的 MSE 最优估计是

$$\widehat{\boldsymbol{\theta}} = \mathbb{E}[\boldsymbol{\theta}|\mathcal{X}] = \int \boldsymbol{\theta} p(\boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta}.$$

![Equation](images/B9780443292385000093/si338.png) (3.64)

在统计推断的背景下，利用贝叶斯定理的另一个方向是获得给定观测值 $\mathcal{X}$ 条件下 $\mathbf{x}$ 的 PDF 估计。这可以通过对一个分布进行*边缘化*来完成，使用的方程是

$$p(\mathbf{x}|\mathcal{X}) = \int p(\mathbf{x}, \boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta} = \int p(\mathbf{x}|\boldsymbol{\theta}) p(\boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta},$$
