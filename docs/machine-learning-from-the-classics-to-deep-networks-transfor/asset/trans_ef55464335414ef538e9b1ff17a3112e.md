

`d̂[n] = w[n-1]^(H) u[n]`

和

`e[n] = d[n] - d̂[n]`

![Equation](images/B9780443292385000111/si429.png)

并且我们允许特征值向量 `λ` 为时变量；`C` 定义为以向量 `c[i]` 为列的矩阵，`i = 1, 2, …, m`。

![Equation](images/B9780443292385000111/si430.png)

将公式 [(5.71)](#Chp005_177-248_B9780443292385000111.xhtml#deq159) 代入 [(5.70)](#Chp005_177-248_B9780443292385000111.xhtml#deq156) 中的约束条件，后者可紧凑地写为 `C^(H) w = g`（回想 `g[i] ∈ ℝ`），我们很容易得到

```
-μ λ[n] = (C^(H) C)^(-1) g - (C^(H) C)^(-1) C^(H) (w[n-1] + μ u[n] e[n]^(∗))
```

![Equation](images/B9780443292385000111/si432.png)

```
w[n] = (I - C (C^(H) C)^(-1) C^(H)) (w[n-1] + μ u[n] e[n]^(∗)) + C (C^(H) C)^(-1) g.
```
