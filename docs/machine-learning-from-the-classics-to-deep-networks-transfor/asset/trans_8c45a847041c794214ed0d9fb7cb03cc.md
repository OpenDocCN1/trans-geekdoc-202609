
常数 `ϵ` 是一个用户定义的小参数，用于在系数估计取非常小的值时保证稳定性。请注意，如果权重具有恒定的预选值，该任务保持其凸性质；当权重发生变化时，这不再成立。值得注意的是，如果将公式 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 的正则化项中的 `ℓ₁` 范数替换为 `$\\sum_{j = 1}^{l}\\ln\\left( |\\theta_{j}| + \\epsilon \\right)$`，可以得到这种直观激励的加权方案。[图 10.8](#Chp010_463-518_B9780443292385000160.xhtml#f0045) 显示了一维空间中相应的图，以及 `ℓ₁` 范数的图。对数函数的图让人想起 `ℓₚ` “范数”（0 < `p` < 1）以及第 [9.2](#Chp009_417-462_B9780443292385000159.xhtml) 节中的评论。这不再是一个凸函数，之前给出的迭代方案是 Majorization-Minimization 过程的结果，旨在求解由此产生的非凸任务 [24]（问题 [10.6](#Chp010_463-518_B9780443292385000160.xhtml#o0255)）。
