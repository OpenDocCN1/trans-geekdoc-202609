

## 20.10 低秩矩阵分解：一种稀疏建模路径

低秩矩阵分解任务已从不同角度进行过讨论。在本节中，将在特定背景下考虑该任务；即存在缺失条目和/或离群值的情况。这种关注点源于许多较新的应用，特别是在大数据问题框架内。为此，将调用稀疏性促进论据，为这一老问题提供新的视角。我们不会深入细节，旨在重点介绍已考虑的主要方向和方法。

### 20.10.1 矩阵补全

为了回顾第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章和第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章的一些主要发现，让我们考虑一个信号向量 `s ∈ ℝ^(l)`，其中仅观测到其 `N` 个分量，其余未知。这等价于通过一个传感矩阵对 `s` 进行传感，该矩阵的 `N` 行从标准（规范）基 `Φ = I` 中均匀随机选取，其中 `I` 是 `l × l` 单位矩阵。当时提出的问题是：是否可能仅基于这 `N` 个分量精确恢复 `s`？根据第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章提出的理论，我们知道可以恢复 `s` 的所有分量，前提是 `s` 在某个基或字典 `Ψ` 中是稀疏的，该基或字典与 `Φ = I` 表现出低互相干性，且 `N` 足够大，正如第 [9.9](#Chp009_417-462_B9780443292385000159.xhtml) 节所指出的。

[图 20.19](#Chp020_1103-1179_B9780443292385000263.xhtml#f0120) 展示了三维螺旋线的采样点，其参数化为 `x₁ = aθ cos θ`，`x₂ = aθ sin θ`，并在 `θ = 0.5π, 0.7π, 0.9π, …, 2.05π`（`θ` 以弧度表示）、`a = 0.1` 以及 `x₃ = −1, −0.8, −0.6, …, 1` 处采样。

![Figure 20.19 Samples from a three-dimensional spiral. One can think of it as a number of two-dimensional spirals one above the other. Different symbols have been used in order to track neighboring information.](images/B9780443292385000263/gr019.jpg)

**图 20.19** 三维螺旋线的采样点。可以将其视为若干个二维螺旋线上下堆叠。使用不同符号是为了追踪邻域信息。

为了演示目的并追踪每个点的“身份”，随着在 `x₃` 维度上移动，我们交替使用红色十字和圆点。此外，每个 `x₃` 层级的第一个、中间和最后一个点分别用黑色“⋄”、黑色“⋆”和黑色“□”表示。基本上，同一层级的所有点都位于一个二维螺旋线上。

[图 20.20](#Chp020_1103-1179_B9780443292385000263.xhtml#f0125) 展示了使用拉普拉斯降维方法将三维螺旋线映射到二维空间的结果，参数值为 `ϵ = 0.35` 和 `σ = √0.5`。对比 [图 20.19](#Chp020_1103-1179_B9780443292385000263.xhtml#f0120) 和 [20.20](#Chp020_1103-1179_B9780443292385000263.xhtml#f0125)，我们看到对应于同一层级 `x₃` 的所有点都被映射到同一条线上，第一个点映射到第一个点，依此类推。即如 [示例 20.7](#Chp020_1103-1179_B9780443292385000263.xhtml#enun0075) 所示，拉普拉斯方法将三维螺旋线展开为二维曲面，同时保留了邻域信息。

![Figure 20.20 Two-dimensional mapping of the spiral of Fig. 20.19 using the Laplacian eigenmap method. The three-dimensional structure is unfolded to the two-dimensional space by retaining the neighboring information.](images/B9780443292385000263/gr020.jpg)

**图 20.20** 使用拉普拉斯特征映射方法对 [图 20.19](#Chp020_1103-1179_B9780443292385000263.xhtml#f0120) 的螺旋线进行二维映射。通过保留邻域信息，三维结构被展开到二维空间中。
