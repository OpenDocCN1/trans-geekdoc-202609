
因此，选择 **u**[*x*, 1] 作为对应最大特征值 *λ*² 的特征向量，可得到最大相关性。

特征向量 **u**[*x*, 1], **u**[*y*, 1] 称为*归一化典型相关基向量*，特征值 *λ*² 称为平方*典型相关*，投影 *z*[*x*, 1], *z*[*y*, 1] 称为*典型变量*。

现在可以进一步推广上述思想，计算一对子空间：span{**u**[*x*, 1], …, **u**[*x*, *m*]} 和 span{**u**[*y*, 1], …, **u**[*y*, *m*]}，其中 *m* ≤ min(*p*, *q*)。实现这一目标的一种方法是分步进行，类似于 PCA 的做法。假设已计算出 *k* 对基向量，则第 *k* + 1 对通过求解以下约束优化任务获得：

```
max_{u_x, u_y} u_x^T Σ̂_xy u_y,
```
