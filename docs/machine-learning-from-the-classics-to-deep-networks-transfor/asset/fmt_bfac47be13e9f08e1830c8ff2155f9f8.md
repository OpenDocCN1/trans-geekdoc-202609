
## 公式推导

$$
P(\mathbf{x}_V) = \frac{1}{Z}\psi_V(\mathbf{x}_V)\prod\limits_{s \in \mathcal{N}(V)}\mu_{s\rightarrow V}(\mathbf{x}_s).
$$

![Equation](images/B9780443292385000226/si63.png) (16.6)

### Separator nodes

Each separator is connected only to clique nodes. After the two-way message passing, every separator has received messages from both flow directions. Then it is shown that

$$
P(\mathbf{x}_S) = \frac{1}{Z}\prod\limits_{v \in \mathcal{N}(S)}\mu_{v\rightarrow S}(\mathbf{x}_S).
$$

![Equation](images/B9780443292385000226/si64.png) (16.7)
