
信道均衡任务在[图 4.12](#Chp004_119-175_B978044329238500010X.xhtml)中已作介绍。均衡器的输入是一个随机过程（随机信号），根据第 [2.4](#Chp002_19-64_B9780443292385000081.xhtml) 节引入的符号约定，将其表示为 `u[n]`。请注意，在接收到被（通信）信道加噪和失真的样本 `u[n]` 后，必须获得最初发送的信息序列 `s[n]` 的估计值，该估计值延迟了 `L − 1` 个时间滞后，这考虑了所涉及的整体传输系统施加的各种延迟。因此，在时刻 `n`，均衡器判决 `ŝ[n − L + 1]`。理想情况下，如果已知最初发送的信息序列直到并包括时刻 `n − L` 的真实值，用 `s[n − L]`、`s[n − L − 1]`、`s[n − L − 2]…` 表示，利用该信息连同接收序列 `u[n]` 来恢复 `ŝ[n − L + 1]` 的估计值，只会有益无害。这一思路在*判决反馈均衡器*（DFE）中得以探索。对于复值数据情况，均衡器的输出现在写为

