
## EM Algorithm Update Equations

The update equations for the EM algorithm are given by:

$$
\alpha^{(j + 1)}: \frac{\partial}{\partial\alpha}\mathcal{Q}\left( \alpha,\beta;\alpha^{(j)},\beta^{(j)} \right) = 0,
\quad
\beta^{(j + 1)}: \frac{\partial}{\partial\beta}\mathcal{Q}\left( \alpha,\beta;\alpha^{(j)},\beta^{(j)} \right) = 0
$$

which trivially lead to:

![](images/B9780443292385000184/fx008.jpg)

Once the algorithm converges, the resulting values for `α` and `β` are used to completely specify the involved PDFs, which can be used either to obtain an estimate of $\widehat{\mathbf{\theta}}$, for example, $\widehat{\mathbf{\theta}} = \mathbb{E}[\mathbf{\theta}|\mathbf{y}]$, or make predictions via Eq. [(12.21)](#Chp012_583-634_B9780443292385000184.xhtml#deq25).

## Example 12.2

In this example, the generalized linear regression model of [Example 12.1](#Chp012_583-634_B9780443292385000184.xhtml#enun0015) is reconsidered. The goal is to use the EM algorithm as summarized by the recursions Eqs. (12.43), (12.44), (12.51), and (12.52).

The variance of the Gaussian noise used in the model to generate the data was set equal to $\sigma_\eta^2 = 0.05$. The number of training points was $N = 500$. For the EM algorithm, both `α` and `β` were initialized to one. The correct dimensionality for the unknown parameter vector was used.

The recovered values after the convergence of the EM were:
- `α = 1.32` corresponding to $\sigma_\theta^2 = 0.756$
- `β = 19.96` corresponding to $\sigma_\eta^2 = 0.0501$

Note that the latter is very close to the true variance of the noise.

Then, predictions of the output variable `y` were performed at 20 points, using Eq. [(12.22)](#Chp012_583-634_B9780443292385000184.xhtml#deq26) and the value of $\boldsymbol{\mu}_{\theta|y}$ recovered by the EM algorithm, via Eq. (12.44).
