

# 数学推导与证明题

## 4.4 证明最优 MSE 估计

假设输入 **x** 与真实输出 y 之间的真实关系是线性的，即

$$y = \boldsymbol{\theta}_o^T \mathbf{x} + \eta, \quad \boldsymbol{\theta}_o \in \mathbb{R}^l$$

其中 $\eta$ 与 **x** 独立，则最优 MSE 估计 $\boldsymbol{\theta}^*$ 满足

$$\boldsymbol{\theta}^* = \boldsymbol{\theta}_o.$$

## 4.5 降维情况下的最优估计

证明如果

$$y = \boldsymbol{\theta}_o^T \mathbf{x} + \eta, \quad \boldsymbol{\theta}_o \in \mathbb{R}^k$$

其中 $\eta$ 与 **x** 独立，则最优 MSE $\boldsymbol{\theta}^* \in \mathbb{R}^l, \; l < k$ 等于 $\boldsymbol{\theta}_o$ 的前 $l$ 个分量，前提是 **x** 的分量不相关。

## 4.7 多通道滤波任务

考虑多通道滤波任务

$$\widehat{\mathbf{y}} = \begin{bmatrix} \widehat{y}_r \\ \widehat{y}_i \end{bmatrix} = \Theta \begin{bmatrix} \mathbf{x}_r \\ \mathbf{x}_i \end{bmatrix}.$$

估计 $\Theta$ 以最小化平方误差范数。
