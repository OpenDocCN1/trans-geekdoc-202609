

这一次的递归更新，即一旦接收到 **y**[*n*] 的观测值，其形式是我们在本书中将反复遇到的。“新”（后验）估计等于“旧”（先验）估计，*加上一个修正项*；后者与新到达的观测向量与基于“旧”估计的预测之间的误差 **e**[*n*] 成正比。矩阵 *K*[*n*]，称为*卡尔曼增益*，控制修正量，其值的计算旨在最小化均方误差（MSE）；换句话说，

```
J(K[n]) := 𝔼[e[n|n]^(T) e[n|n]] = trace{P[n|n]},
```

其中

```
P[n|n] = 𝔼[e[n|n] e[n|n]^(T)]
```

以及

```
e[n|n] := x[n] - x̂[n|n].
```

可以证明，最优卡尔曼增益等于（问题 [4.22](#Chp004_119-175_B978044329238500010X.xhtml#o0115)）

```
K[n] = P[n|n−1] H[n]^(T) S[n]^(−1),
```

其中

```
S[n] = R[n] + H[n] P[n|n−1] H[n]^(T).
```
