
## 信息检索背景下的应用

为了将我们之前的发现置于信息检索的背景下，假设有一幅可用的图像，并且想要知道图像中描绘的是什么人。假设该人的图像在数据集中，处理过程如下：
(a) 对图像进行向量化；
(b) 将其投影到由前 *m* = 100 个特征向量所张成的子空间上；
(c) 在这个低维空间中搜索，以欧几里得范数的意义识别数据集中最接近的向量化图像。

通常，最好识别出最相似的 5 或 10 幅图像，并根据欧几里得距离（或任何其他距离）相似度对它们进行排序。随后，可以检索存储在数据集/数据库中的姓名及所有相关信息。

在信息检索中，数据集中的每幅图像都可以用相应的主成分得分向量来存储。

## 示例 20.2：PCA 图像压缩

本例演示了 PCA 在图像压缩中的应用。在上一个示例中，PCA 是跨数据库的不同图像执行的。这里，重点将放在单幅图像上。

图像的像素值存储在一个 *l* × *N* 矩阵 **X** 中，该矩阵的列被视为观测向量 **x**[*n*] ∈ ℝ^(*l*)，*n* = 1, 2, …, *N*。注意，**X** 需要沿行进行零均值化，因此计算均值向量 $\bar{\mathbf{x}}$ 并从每一列中减去。然后，获得对应于 *m* 个最大特征值（1 ≤ *m* < *l*）的特征向量，既可以通过样本协方差矩阵，也可以直接通过 SVD 获得。利用公式 [(20.22)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq29) 中 PCA 的矩阵分解公式，**X** 的压缩表示（包含 *m* 行而非 *l* 行）由下式给出：

```
Z^(m) = [u_1, ..., u_m]^T X
```

其中维度 *m* 已明确引入符号中。因此，只需要 `Z^(m)` 和 **u**_1, …, **u**_m 即可通过公式 [(20.21)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq28) 获得均值减去后的 **X** 的估计值。最后，为了重建图像，需要将均值向量 $\bar{\mathbf{x}}$ 加回到每一列中（参见公式 [(20.23)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq30)）。
