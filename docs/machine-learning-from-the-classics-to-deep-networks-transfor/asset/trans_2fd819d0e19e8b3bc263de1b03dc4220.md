我们将通过一个涉及两个随机变量（设为 `r` 和 `ϕ`）变换为两个新变量（`x` 和 `y`）的例子来演示该方法。设

```
x = g_x(r, ϕ)
```

和

```
y = g_y(r, ϕ).
```

现在假设逆变换存在唯一解，且可用解析形式表示（一般情况下并非如此），即

```
r = g_r(x, y), ϕ = g_ϕ(x, y).
```

根据第 [2.2.5 节](#Chp002_19-64_B9780443292385000081.xhtml) 可知，若 `p_r,ϕ(r, ϕ)` 是 `r` 和 `ϕ` 的联合分布，则 `x` 和 `y` 的联合分布由下式给出

```
p_x,y(x,y) = p_r,ϕ(g_r(x,y), g_ϕ(x,y)) / |det(J(x,y;r,ϕ))|
```
(14.9)
