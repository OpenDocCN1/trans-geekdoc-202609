
## 6.5 Ridge regression: a geometric point of view

In this section, we shed light on the ridge regression task from a different perspective. Instead of a dry optimization task, we are going to look at it by mobilizing statistical geometric arguments that the SVD decomposition offers to us.

Ridge regression was introduced in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml) as a means to impose bias on the LS solution and also as a major path to cope with overfitting and ill-conditioning problems. In ridge regression, the minimizer results as

```
${\\widehat{\\mathbf{\\theta}}}\_{R} = \\arg\\min\\limits\_{\\mathbf{\\theta}}\\left\\{ {\\|\\mathbf{y} - X\\mathbf{\\theta}\\|}^{2} + \\lambda{\\|\\mathbf{\\theta}\\|}^{2} \\right\\},$
```

where `\\(\\lambda > 0\\)` is a user-defined parameter that controls the importance of the regularizing term. Taking the gradient with respect to `\\(\\boldsymbol{\\theta}\\)` and equating to zero results in

```
${\\widehat{\\mathbf{\\theta}}}\_{R} = {(X^{T}X + \\lambda I)}^{- 1}X^{T}\\mathbf{y}. \tag{6.29}
```

### Null Space and Range Space

The null space of \\(X\\), \\(\\mathcal{N}(X)\\), is defined as

```
\\mathcal{N}(X) := \\{\\mathbf{x} \\in \\mathbb{R}^{l} : X\\mathbf{x} = \\mathbf{0}\\},
```

and can be expressed as

```
\\mathcal{N}(X) = \\text{span}\\{\\mathbf{v}_{r+1}, \\dots, \\mathbf{v}_{l}\\}. \tag{6.26}
```

Furthermore, the range space of \\(X\\), \\(\\mathcal{R}(X)\\), is defined as

```
\\mathcal{R}(X) := \\{\\mathbf{x} \\in \\mathbb{R}^{l} : \\exists \\mathbf{a} \\text{ such that } X\\mathbf{a} = \\mathbf{x}\\},
```

and can also be expressed as

```
\\mathcal{R}(X) = \\text{span}\\{\\mathbf{u}_{1}, \\dots, \\mathbf{u}_{r}\\}. \tag{6.28}
```

*   Everything that has been said before transfers to complex-valued data trivially, by replacing transposition with the Hermitian one.
