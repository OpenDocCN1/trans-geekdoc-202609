
然而，尽管涉及的 PDF 是高斯分布，但由于 `f[θ]` 的非线性本质，该积分难以求解。为了进行计算，执行了一阶泰勒展开，

```
f[θ](x) ≈ f[θ[MAP]](x) + g^(T)(θ − θ[MAP])
```

其中 `g` 是在 `θ[MAP]` 处计算的相应梯度，可利用反向传播参数进行计算。经过这种线性化后，涉及的 PDF 关于 `θ` 变为线性，积分得出如公式 [(12.21)](#Chp012_583-634_B9780443292385000184.xhtml) 所示的近似高斯预测分布。对于分类问题，采用第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章第 [13.7.1](#Chp013_635-716_B9780443292385000196.xhtml) 节中的逻辑回归模型来代替高斯 PDF，并采用了类似的近似方法。更多关于神经网络贝叶斯方法的这一观点，可参考文献 [127,128]。

### 贝叶斯推断方法

最近，为了以更高效的方式实施正则化和剪枝，人们对深度网络的贝叶斯观点重燃兴趣。在此思路下，所有参数均被视为随机变量，并用条件分布和先验分布来描述。后者充当正则化项。随后，调用变分贝叶斯技术来推断后验分布。例如，文献 [121] 引入了分层先验来剪枝节点而非单个权重。此外，还利用后验不确定性来确定编码权重的最佳定点精度。

文献 [148] 调用基于印度自助餐过程（IBP）（第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章）的非参数贝叶斯论证来剪枝权重、节点，或在卷积网络（见第 [18.12](#Chp018_885-995_B978044329238500024X.xhtml#s0170) 节）情况下剪枝整个卷积核。此外，非线性单元被完全概率化的单元所取代，涉及竞争性的局部赢家通吃（LWTA）论证。据报道，该方法在单元数量和位精度要求方面均能得到非常高效的结构。

## 18.11 浅层架构与深层架构

在本章迄今为止的探讨中，我们讨论了涉及多层节点的前馈网络学习的各个方面。反向传播梯度下降方案及其各种形式，被引入作为训练多层架构的流行算法框架。我们还确立了多层神经网络的一些非常重要的性质，涉及其通用近似性质，以及其解决输入空间中由多面体区域并集形成的类别的任意分类任务的能力。理论上，两层或三层足以执行此类任务。因此，似乎一切尘埃落定。不幸的是（或者也许是幸运的是），事实远非如此。

20 世纪 80 年代中期以后，前馈神经网络在经历了近十年的密集研究后，失去了最初的光彩，并在很大程度上被其他技术取代，如基于核的方法、提升和提升树、以及贝叶斯方法。失去流行度的一个主要原因是其训练可能变得困难，且通常反向传播相关算法表现出收敛速度慢，或收敛到“糟糕”的局部极小值，这是当时的普遍看法。尽管提出了各种“技巧”和方法来改善收敛或找到更好的极小值，但在通过不同随机初始化进行多次训练后，其泛化性能仍无法与其他方法竞争。如果使用两层以上的隐藏层，这一缺点似乎更为严重。事实上，使用两层以上隐藏层的尝试很快就被放弃了。

在本节中，我们将讨论是否需要涉及两层以上隐藏层的深度网络。此外，我们将提供论据来挑战这样一种观点：即糟糕的局部极小值的存在构成了训练深度神经网络的主要障碍。

### 18.11.1 深度架构的威力

在第 [18.3](#Chp018_885-995_B978044329238500024X.xhtml#s0020) 节中，我们讨论了神经网络的每一层如何提供输入模式的不同表示。输入层将每个模式描述为特征空间中的一个点。第一隐藏层节点对输入空间进行划分，并利用相应神经元输出处的零和一编码方案（针对阶跃激活函数）将输入点置于某个区域中。这可以被视为输入模式的一种更抽象的表示。第二隐藏层节点基于前一层提供的信息，对与类别相关的信息进行编码；这是一种进一步的表示抽象，承载着某种“语义意义”。例如，在相关的医疗应用中，它提供肿瘤是恶性还是良性的信息。

前文所述的输入模式的这种分层表示类型，模仿了哺乳动物大脑“感知”周围世界的方式。哺乳动物的大脑由多层神经元组织而成，每一层提供输入感知的不同表示。通过这种变换层级，形成了不同层次的抽象。例如，在灵长类视觉系统中，这一层级涉及边缘和基本形状的检测，随着向更高层级移动，形成更复杂的视觉形状，直到最终建立语义概念：例如，视频场景中移动的汽车，图像中坐着的人。我们大脑的皮层可以被视为一个多层架构，其中 5-10 层仅专门用于我们的视觉系统 [185]。
