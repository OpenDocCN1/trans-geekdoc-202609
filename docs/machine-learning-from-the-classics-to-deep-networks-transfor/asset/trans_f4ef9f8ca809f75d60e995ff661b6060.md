
请注意，通常在线性项（`∑[j ∈ Pa[i]] θ[ij] d[j] + θ[i0]`）中也存在一个常数 `θ[i0]`，在这种情况下，上界中的第一个指数变为 `exp(−f*(ξ[i]) + ξ[i]θ[i0])`。

现在让我们观察公式 [(16.12)](#Chp016_805-853_B9780443292385000226.xhtml#deq23)。一旦确定了 `ξ[i]`，右边的第一个因子就是一个常数。此外，每个因子 `exp(ξ[i]θ[ij])` 也是一个作为 `d[j]` 指数的常数。因此，将公式 [(16.12)](#Chp016_805-853_B9780443292385000226.xhtml#deq23) 代入公式 [(15.1)](#Chp015_755-803_B9780443292385000214.xhtml) 的乘积中，以计算例如公式 [(15.3)](#Chp015_755-803_B9780443292385000214.xhtml)，这些常数中的每一个都可以被相应的 `P(d[j])` 吸收，即

```
P̃(d[j]) ∝ P(d[j]) exp(ξ[i]θ[ij] d[j]), j ∈ Pa[i]。
```

基本上，从图形的角度来看，我们可以等价地认为第 *i* 个节点被解除连接，它对后续处理的影响是通过与其父节点相关联的修正因子来实现的（参见 [图 16.10](#Chp016_805-853_B9780443292385000226.xhtml#f0055)B）。换句话说，变分近似*解耦*了父节点。相反，对于精确推理，在道德化阶段，节点 *i* 的所有父节点都会被连接起来。这是计算量爆炸的根源（参见 [图 16.10](#Chp016_805-853_B9780443292385000226.xhtml#f0055)C）。其思路是移除足够数量的节点，以便剩余网络可以用精确推理方法处理。

还有一个主要问题需要解决：如何获得各个 `ξ[i]`。这些值的计算是为了使界尽可能紧，可以使用任何标准优化技术。请注意，这种最小化对应于一个凸代价函数（问题 [16.11](#Chp016_805-853_B9780443292385000226.xhtml#o0095)）。除了上界，还可以推导出下界 [27]。文献 [30] 中的实验验证了可以在可承受的计算时间内获得相当好的精度。该方法最早由文献 [27] 提出。
