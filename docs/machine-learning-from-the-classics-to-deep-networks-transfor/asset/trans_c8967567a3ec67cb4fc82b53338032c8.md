

## 视觉跟踪

考虑一个圆的视觉跟踪问题，该圆具有恒定且已知的半径。我们要跟踪其位置，即其圆心的坐标，**x** = [*x*[1], *x*[2]]^T。该向量将构成状态变量。生成观测值的模型由下式给出：

```
x_n = x_{n-1} + η_n,
y_n = x_n + v_n,
```

其中 **η**[n] 是区间 [−10, 10] 像素内的均匀噪声，每个维度均如此。注意，由于噪声的均匀性质，标准形式的卡尔曼滤波不再是最优选择，尽管该模型是线性的。噪声 **v**[n] 服从高斯概率密度函数 𝒩(**0**, Σ[v])，其中

```
Σ_v = [[2, 0.5],
       [0.5, 2]].
```

初始时，目标圆位于图像中心。粒子滤波器采用 *N*=50 个粒子，并使用了 SIS 采样方法（另见计算机练习 17.12）。

图 17.11 展示了圆和生成的粒子，它们试图根据噪声观测值在不同时刻跟踪圆心。观察粒子如何紧密地跟踪圆心的移动。相关视频可从本书的配套网站获取。
