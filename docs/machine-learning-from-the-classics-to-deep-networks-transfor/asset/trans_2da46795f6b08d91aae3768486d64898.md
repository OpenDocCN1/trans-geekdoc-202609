

## Gibbs 采样算法

*   **对于** `n = 1, 2, …, N`，**执行**
    1.  **对于** `d = 1, 2, …, l`，**执行**
        *   采样 `x_n(d) ~ p(x | {x_n(i), i < d ≠ 1}, {x_{n-1}(i), i > d ≠ l})`
    2.  **结束 For**
*   **结束 For**

请注意，在上述方案中，所有维度都是按顺序访问的。另一种版本是按随机顺序访问它们。

Gibbs 方案可以看作是马尔可夫链的一种实现，其中转移矩阵/PDF 是由 `l` 个基础转移依次构建的，即，

```
T = B[1]⋯B[l]
```

其中每个单独的基础转移作用于相应的维度，即逐坐标地。对于连续变量，可以很容易地验证

```
B_d(x|y) = p( x(d) | { y(i) } : i ≠ d ) ∏_{i ≠ d} δ( y(i) - x(i) ),  d = 1,2,…,l.
```

换句话说，只有分量 `x(d)` 发生变化，而其余分量保持不变。不难看出，期望的联合分布 `p(x) = p(x(1), …, x(l))` 相对于每一个 `B[d]`，`d = 1, 2, …, l` 都是不变的（问题 [14.13](#Chp014_717-754_B9780443292385000202.xhtml#o0070)）。因此，它在它们的乘积下也将是不变的

```
T = B[1]⋯B[l].
```

遍历性通过要求所有条件概率*严格*为正来保证，这确保了链收敛到期望的 `p(x)`。

### 备注 14.3

*   Gibbs 采样作为 Metropolis 方法的一个实例，继承了其类似随机游走的收敛性能。
*   Gibbs 采样适用于许多图模型（第 [16](#Chp016_805-853_B9780443292385000226.xhtml) 章），这些模型是用条件分布来描述的。通常，这些分布可以通过拒绝采样及其变体等技术以一种简单的方式进行采样，如第 [14.4](#Chp014_717-754_B9780443292385000202.xhtml#s0030) 节所述。
