
考虑一根单位长度的棍子（[图 13.16](#Chp013_635-716_B9780443292385000196.xhtml#f0095)）。根据以下算法，该棍子被分割成一系列无限多个长度为 `P[i]`（`i = 1, 2, …`）的片段。首先，从 Beta 分布（第 [2 章](#Chp002_19-64_B9780443292385000081.xhtml)）中抽取一个随机变量，`β[1] ∼ Beta(β|1, α)`，并折断一段长度等于 `β[1]` 的片段；我们令 `P[1] = β[1]`。剩余片段的长度为 `1 − β[1]`。然后进行另一次抽取，`β[2] ∼ Beta(β|1, α)`，并按比例 `β[2]` 折断另一段。因此，被丢弃片段的长度等于 `β[2](1 − β[1])`，我们令 `P[2]` 等于其长度。剩余片段的长度显然为 `(1 − β[1]) − β[2](1 − β[1]) = (1 − β[1])(1 − β[2])`。遵循这一逻辑递归地从剩余片段上折断，并从 `P[1] = β[1] ∼ Beta(β|1, α)` 开始，算法的第 `i` 步为

```
P[i] = β[i] ∏_{j=1}^{i-1} (1 − β[j]),  β[i] ∼ Beta(β|1, α)
```

利用由此产生的概率值序列 `P[i]`，根据公式 [(13.113)](#Chp013_635-716_B9780443292385000196.xhtml#deq169) 形成一个随机分布，其中 `θ[i]` 从 `G[0]` 中独立同分布地抽取。可以证明，由此产生的分布是一个 DP，即 `G ∼ DP(α, G[0])`。

请注意，随着 `i` 的增加，概率值会减小，因为剩余的棍子片段变得越来越小。因此，在公式 [(13.113)](#Chp013_635-716_B9780443292385000196.xhtml#deq169) 的无限可能项中，只有相对较少数量的项具有显著贡献而得以保留。此外，与这些保留项相关的概率值是最先生成的，这在实现 DP 以生成先验时（参见，例如 [60]）在实践中非常重要。
