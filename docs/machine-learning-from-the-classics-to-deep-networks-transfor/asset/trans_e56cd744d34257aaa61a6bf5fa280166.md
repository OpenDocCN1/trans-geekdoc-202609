

# 4.1 简介

均方误差（MSE）线性估计是统计学习中参数估计的一个基础且重要的主题。除了历史原因——这将我们带回到 Kolmogorov、Wiener 和 Kalman 的开创性工作，他们奠定了最优估计领域的基础——理解 MSE 估计是在研究更新技术之前的必修课。人们总是必须掌握基础并学习经典，然后才能投身于新的“探险”。此处讨论的许多概念在后续章节中也会用到。

围绕误差平方构建损失函数进行优化具有诸多优势，例如存在单一最优值，可通过求解一组线性方程获得；这是一个在实践中非常吸引人的特性。此外，由于由此产生的方程相对简单，该领域的新手可以更好地理解与最优参数估计相关的各种概念。本章展示并讨论了通过正交定理对 MSE 解进行的优雅几何解释，并探讨了解卷积、均衡和干扰消除等典型应用实例，以阐明 MSE 估计任务的核心概念。本章在求解最优解时，也重点关注计算复杂度问题。Levinson 算法及其格梯解释被作为高效求解经典正规方程的优雅且典型的例子呈现。书中讨论了线性模型的 Gauss-Markov 定理，并以著名的 Kalman 滤波方案作为本章的结尾。

本章的展开基于实值变量，这在本书的大部分内容中均适用。然而，复值变量在许多领域特别有用，通信就是一个典型例子，且从实数域推广到复数域并不总是平凡的。在此背景下，引入了循环条件和广义线性估计的概念。书中提供了关于 Wirtinger 导数的基本定义，并给出了涉及复变量损失函数的相关最优性条件。

# 4.2 均方误差线性估计：正规方程

一般估计任务已在[第 3 章](#Chp003_65-117_B9780443292385000093.xhtml)中介绍。文中指出，给定两个相关的随机向量 `y` 和 `x`，估计任务的目标是获得一个函数 `g`，使得给定 `x` 的一个取值 `x` 时，能够以某种最优意义预测（估计）`y` 对应的取值 `y`，即 $\widehat{\mathbf{y}} = g(\mathbf{x})$。MSE 估计也在[第 3 章](#Chp003_65-117_B9780443292385000093.xhtml)中给出，并表明给定 `x = x` 时 `y` 的最优 MSE 估计为

$\widehat{\mathbf{y}} = \mathbb{E}[\mathbf{y}|\mathbf{x}].$
