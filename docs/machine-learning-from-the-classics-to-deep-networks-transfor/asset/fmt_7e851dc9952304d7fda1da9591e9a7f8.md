
The Laplacian matrix, `L`, is symmetric and positive semidefinite. The latter is readily seen from the definition in Eq. [(20.109)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq167), where `E[L]` is always a nonnegative scalar. Note that the larger the value of `D[ii]` is, the more “important” is the sample `x_i`. This is because it implies large values for `W(i, j), j = 1, 2, …, N`, and plays a dominant role in the minimization process. Obviously, the minimum of `E[L]` is achieved by the trivial solution `z[i] = 0, i = 1, 2, …, N`. To avoid this, as is common in such cases, we constrain the solution to a prespecified norm. Hence, our problem now becomes

```
min_z z^T L z, s.t. z^T D z = 1.
```

Although we can work directly on the previous task, we will slightly reshape it in order to use tools that are more familiar to us. Define

```
y = D^(1/2) z,
```

and

```
L̃ = D^(-1/2) L D^(-1/2),
```

which is known as the *normalized graph Laplacian* matrix. It is now readily seen that our optimization problem becomes

```
min_y y^T L̃ y,
```

s.t. `y^T y = 1`.

Using Lagrange multipliers and equating the gradient of the Lagrangian to zero, it turns out that the solution is given by

```
L̃ y = λ y.
```
