
Let `t` and `x` be the text and image representations, respectively, that feed the corresponding encoders. The outputs of the two encoders, denoted as `z_t = g_ϕ(t)` and `z_i = f_ξ(x)`, are of the same dimensions. The parameters `ϕ` and `ξ` which parameterize the two encoders, respectively, are jointly optimized according to the contrastive loss rationale, which has already been discussed in Section [19.6.5](#Chp019_997-1102_B9780443292385000251.xhtml#s0215). In other words, during training, the encoded output vectors of the two encoders are made more similar if the description in the caption matches the content of the image, and more dissimilar if there is no matching, according to a contrastive loss function. Similarity is quantified via the normalized inner product function. For example, assume that an image contains a cat and it is encoded as `z_i`. For the description of the image content, we are given two captions. One, say, "A cat sitting" (encoded as `z_t`) and another one, say, "A dog running" (encoded as `z_t'`). Then, we expect that after training,

```
\frac{\mathbf{z}_{t}^{T}}{||\mathbf{z}_{t}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||} > \frac{{\mathbf{z}_{t}^{\prime}}^{T}}{||\mathbf{z}_{t}^{\prime}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||},
```

where `|| ⋅ ||` denotes the Euclidean norm. Details of the two encoder networks are provided in [149].

At inference stage, each image in the data set is treated as a *separate class*. Given a text description/caption, this is encoded and the resulting vector representation is compared to the encoded representations of the images in the data set. An image is selected according to the largest value of the similarity measure (normalized inner product). In computer vision, this type of classification, where examples are treated as separate classes, is known as one-shot classification.^([^(149)](#fn149))
