
除了随机矩阵，还可以构造其他满足 RIP 的矩阵。其中一个例子是部分傅里叶矩阵，它是通过从 *l* × *l* DFT 矩阵中均匀随机选择 *N* 行形成的。尽管满足 RIP 所需的样本数量可能比公式 [(9.33)](#Chp009_417-462_B9780443292385000159.xhtml#deq71) 中的界限更大（参见文献 [79]），但基于傅里叶的感知矩阵在存储（𝒪(*N* ln *l*））和矩阵-向量乘积（𝒪(*l* ln *l*））方面提供了特定的计算优势 [20]。文献 [56] 考虑了包含行间统计依赖的随机托普利茨感知矩阵的情况，并表明它们也可以以高概率满足 RIP。这在信号处理和通信应用中尤为重要，因为系统通常通过时间序列在输入端被激励，因此不能假设连续输入行之间的独立性。文献 [44, 76] 考虑了可分离矩阵的情况，其中感知矩阵是单独满足 RIP 的矩阵的克罗内克积结果。此类矩阵对于多维信号很有意义，旨在利用每个相关维度上的稀疏结构。例如，当试图“编码”跨越时间、频谱、空间和其他域的事件相关信息时，可能会出现此类信号。

尽管它们在理论上很优雅，但确定特定稀疏水平所需观测数量的推导界限却低于实验证据（例如文献 [39]）。在实践中，一个经验法则是使用 3*k*–5*k* 阶的 *N* [18]。对于与稀疏水平相比较大的 *l* 值，文献 [38] 的分析表明，当 *N* ≳ 2*k* ln(*l*/*N*) 时，我们可以恢复大多数稀疏信号。为了克服与 RIP 相关的不足，已经提出了许多其他技术（例如文献 [11, 30, 39, 85]）。此外，在特定应用中，使用实证研究可能是一条更合适的途径。

请注意，原则上，从 *N* < *l* 个观测中恢复一个 *k*-稀疏向量所需的最小观测数是 *N* ≥ 2*k*。确实，正如 [定理 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0125) 后的讨论精神所言，感知矩阵必须满足的主要要求是不将两个不同的 *k*-稀疏向量映射到相同的观测向量 **y**。否则，永远无法从它们的（共同）观测中恢复出这两个向量。如果我们有 2*k* 个观测，并且感知矩阵保证任意 2*k* 列线性无关，则满足上述要求。然而，为了使相应矩阵满足 RIP 而设定的观测数量界限更大。这是因为 RIP 还考虑了恢复过程的稳定性。我们将在第 [9.9](#Chp009_417-462_B9780443292385000159.xhtml#s0095) 节讨论*稳定*嵌入时回到这个问题。

## 9.8 从噪声测量中鲁棒恢复稀疏信号

在上一节中，我们的重点是从一个欠定方程组中恢复稀疏解。在问题公式化中，我们假设获得的观测中没有噪声。在从较简单场景中获得一些经验和洞察后，我们现在将注意力转向更现实的任务，即不确定性因素介入的场景。一种不确定性可能源于噪声的存在，此时我们的观测模型回归到标准回归形式：

**y** = *X***θ** + **η**,
(9.34)

其中 *X* 是我们熟悉的非方 *N* × *l* 矩阵。从公式 [(9.34)](#Chp009_417-462_B9780443292385000159.xhtml#deq72) 恢复 **θ** 的稀疏感知公式化可以表示为：

```
min_{θ ∈ R^l} ||θ||_1, s.t. ||y - Xθ||_2^2 ≤ ε,
```
