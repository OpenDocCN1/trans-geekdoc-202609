## Properties of the transition probabilities matrix

The transition matrix has a special structure leading to certain properties, which will be used later on.

*   **The matrix `P` is a *stochastic* matrix.** That is, all its entries are nonnegative, and the entries across each column add to one, that is,

    $\sum\limits\_{i = 1}^{K}P\_{ij} = 1,$

    ![Equation](images/B9780443292385000202/si172.png)

    which is a direct consequence of the definition of probabilities.

*   **The value `λ = 1` is always an eigenvalue of `P`** (Problem [14.8](#Chp014_717-754_B9780443292385000202.xhtml#o0045)). Moreover, there is no eigenvalue with magnitude larger than one (Problem [14.9](#Chp014_717-754_B9780443292385000202.xhtml#o0050)).

*   **The eigenvectors corresponding to eigenvalues `λ ≠ 1` comprise components that add to zero** (Problem [14.10](#Chp014_717-754_B9780443292385000202.xhtml#o0055)).

*   **The left eigenvector corresponding to `λ = 1`,**

    `b`[1]^(`T`)`P` = `b`[1]^(`T`),

    ![Equation](images/B9780443292385000202/si174.png)(14.38)

    has all its elements equal. This is easily verified by plugging in `b`[1] = [1, 1, …, 1]^(`T`) and checking that this is indeed an eigenvector.

*   **Invariant distribution.** A distribution is said to be invariant over the states of a Markov chain if

    `p` = `P``p`.

    ![Equation](images/B9780443292385000202/si176.png)

    Note that `p` is necessarily an eigenvector corresponding to the eigenvalue `λ = 1`. Moreover, because `p` consists of probabilities, its elements must add to one. Depending on the multiplicity of `λ = 1`, there may be more than one invariant distribution. For example, if `P = I` any probability distribution is an invariant for the respective Markov chain. It turns out that any Markov chain with a finite number of states has at least one invariant distribution. However, if the elements of `P` are strictly positive, then there is a unique invariant distribution that coincides with the unique eigenvector corresponding to the maximum eigenvalue, `λ = 1`, which in this case has a multiplicity of one. Furthermore, the eigenvector corresponding to `λ = 1` comprises positive elements, which after scaling can always be made to add to one. This is a by-product of the celebrated *Perron–Frobenius theorem*, which is ensured if `P` has strictly positive entries^([^(109)](#fn109))
