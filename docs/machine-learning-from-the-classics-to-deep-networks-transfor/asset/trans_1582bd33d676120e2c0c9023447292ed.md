请注意，*μ*[*V*[*n* + 1] → *S*[*n*]](**x**[*n*]) 涉及 *K* 个值，并且对于其中每一个值的计算都要执行 *K* 次求和。因此，复杂度按每个时刻 𝒪(*K*²) 缩放。在 HMM 文献中，使用符号“beta”，

*β*(**x**[*n*]) :  = *μ*[*V*[*n* + 1] → *S*[*n*]](**x**[*n*])。

![Equation](images/B9780443292385000226/si255.png)(16.46)

根据公式 [(16.44)](#Chp016_805-853_B9780443292385000226.xhtml#deq81) 和 [(16.45)](#Chp016_805-853_B9780443292385000226.xhtml#deq82) 中的递归定义，其中 **x**[*n* + 1], **x**[*n* + 2], …, **x**[*N*] 已被边缘化掉，我们可以等价地写成

*β*(**x**[*n*]) = *p*(**y**[*n* + 1], **y**[*n* + 2], …, **y**[*N*]|**x**[*n*])。
