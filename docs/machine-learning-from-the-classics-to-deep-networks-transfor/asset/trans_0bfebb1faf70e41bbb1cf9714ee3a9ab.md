
# 用于变点检测的吉布斯采样

*   获得 `x[1:N] := {x[1], …, x[N]}` 后，选择 `a` 和 `b`。
*   初始化 `n_0^(0)`。
*   **For** `i = 1, 2, …` **Do**
    1.  `λ_1^(i) ~ Gamma(λ | a + ∑_{n=1}^{n_0^(i-1)} x_n, b + n_0^(i-1))`
    2.  `λ_2^(i) ~ Gamma(λ | a + ∑_{n=n_0^(i-1)+1}^{N} x_n, b + (N - n_0^(i-1)))`
    3.  `n_0^(i) ~ P(n_0 | λ_1^(i), λ_2^(i), x[1:N])`
*   **End For**
