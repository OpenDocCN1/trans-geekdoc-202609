
分别构成各自的特征值。我们假设 `Σ` 可逆，因此所有特征值均为正（由于是正定矩阵，其特征值为正，见附录 A.2）。由于特征向量的标准正交性，矩阵 `U` 是正交的，表示为 `U U^T = U^T U = I`。因此，公式 [(2.72)](#Chp002_19-64_B9780443292385000081.xhtml#deq84) 现在可以写为

`y^T Λ^(-1) y = c`

其中我们使用了线性变换

`y := U^T (x - μ)`

这对应于绕 `U` 旋转坐标轴并将原点平移至 `μ`。公式 [(2.76)](#Chp002_19-64_B9780443292385000081.xhtml#deq88) 可以写为

```
y_1^2 / λ_1 + ... + y_l^2 / λ_l = c
```

由此可以很容易地看出，这是一个描述 `ℝ^l` 中（超）椭球面的方程。从公式 [(2.77)](#Chp002_19-64_B9780443292385000081.xhtml#deq89) 可以明显看出，它以 `μ` 为中心，且椭球面的主轴平行于 `u_1, ..., u_l`（将 `x` 替换为标准基向量，`[1, 0, ..., 0]^T` 等）。各主轴的大小由相应的特征值控制。这在 [图 2.6](#Chp002_19-64_B9780443292385000081.xhtml#f0035)B 中显示。对于对角协方差且对角线元素相等的特殊情况，所有特征值均等于公共对角线元素的值，椭球面变为（超）球面（圆），如 [图 2.6](#Chp002_19-64_B9780443292385000081.xhtml#f0035)A 所示。
