
请注意，`KL(p||q)` 与 `KL(q||p)` 散度不同，后者涉及公式 [(13.2)](#Chp013_635-716_B9780443292385000196.xhtml#deq2) 中的界。由于 KL 散度不对称，这两种方法最小化的是不同的代价。在进一步讨论之前，有必要强调与这两种形式的 KL 散度相关的某些含义。

*   **I-投影**：`KL(q||p)` 散度由下式给出

```
KL(q||p) = ∫ q(θ) ln (q(θ) / p(θ|X)) dθ.
```
(13.96)

*   这有时被称为 *I-投影* 或 *信息投影*。仔细观察可知，在 `p(θ|X)` 取较小值的参数空间区域中，`KL(q||p)` 会取较大值，而最小化过程会推动 `q(θ)` 在这些区域也取较小值。现在考虑 `p(θ|X)` 为双峰分布，而 `q(θ)` 被约束为单峰分布的情况。此时，最小化 `KL(q||p)` 将迫使 `q` 接近 `p` 的两个峰值中的任意一个，以便在 `p` 取较小值的区域也获得较小的值。

*   **M-投影**：我们现在将重点转向 `KL(p||q)` 散度，其定义见公式 [(13.95)](#Chp013_635-716_B9780443292385000196.xhtml#deq146)。这也被称为 *M-投影* 或 *矩投影*。对于前面讨论的情况，在 `p` 取较大值的区域，`KL(p||q)` 会取较大值，最小化过程会估计 `q` 使其在这些区域也取较大值。因此，估计值 `q` 的峰值会位于 `p` 的两个峰值之间，作为两者的折中。显然，这不是一个好的结果，因为该估计在 `p` 取较小值的区域放置了高概率质量。这一讨论指出了期望传播方法在实践中预期表现出的性能的一些局限性，因为它基于 `KL(p||q)` 最小化。
