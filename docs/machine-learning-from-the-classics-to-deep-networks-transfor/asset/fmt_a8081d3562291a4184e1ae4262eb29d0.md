
In other words, in the iteration [(5.28)](#Chp005_177-248_B9780443292385000111.xhtml#deq52), we get rid of the expectation operation and use the value of `ϕ(⋅, ⋅)`, which is computed using the current observations and the currently available estimate. That is, the algorithm learns both the statistics as well as the root; two in one! The same comments made for the convergence conditions, met in the iteration-dependent step size case in Section [5.3](#Chp005_177-248_B9780443292385000111.xhtml#s0020), are valid here as well.

In the context of optimizing a general differentiable cost function of the form

```
J(θ) = 𝔼 [L(θ, y, x)],
```

the Robbins–Monro scheme can be mobilized to find a root of the respective gradient, i.e.,

```
∇J(θ) = 𝔼 [∇L(θ, y, x)],
```

where the expectation is with respect to the pair `(y, x)`. As we have seen in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml), such cost functions are also known as the *expected risk* or the *expected loss* in machine learning terminology. This is the price one pays for using the *noisy version of the gradient* and it is the reason that such schemes suffer from relatively low convergence rates.
