令 $\epsilon = \frac{1}{\lambda}$，则公式 [(8.119)](#Chp008_343-416_B9780443292385000147.xhtml#deq225) 中的递归变为

**x**[k] = (A + \epsilon I)^(-1)(b + \epsilon **x**[k - 1])。

![Equation](images/B9780443292385000147/si534.png)(8.120)

经过一些简单的代数运算（问题 [8.37](#Chp008_343-416_B9780443292385000147.xhtml#o0215)），我们最终得到

**x**[k] = **x**[k - 1] + (A + \epsilon I)^(-1)(b - A **x**[k - 1])。

![Equation](images/B9780443292385000147/si535.png)(8.121)

在数值线性代数中，该方案被称为*迭代修正*算法 [58]。当矩阵 A 接近奇异时会用到它，因此通过 \epsilon 进行正则化有助于求逆。请注意，在每次迭代中，**b** - A **x**[k - 1] 是当前估计值所产生的误差。该算法属于一大类算法家族，称为平稳迭代或迭代松弛方案；我们将在第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章遇到此类方案。

这里有趣的是，由于该算法作为近端最小化算法的一个特例出现，即使 \epsilon 不小，也能保证收敛到解！
