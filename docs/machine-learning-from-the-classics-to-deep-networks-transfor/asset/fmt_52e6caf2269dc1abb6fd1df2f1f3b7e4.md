
### 最大似然估计的性质

根据最大似然方法，我们假设给定观测集合，未知参数的估计值是使相应似然函数最大化的值。

由于对数函数 `ln(·)` 是单调递增的，因此可以转而寻找*对数似然函数*的最大值：

```
∂ln p(X;θ) / ∂θ |_{θ = θ̂_ML} = 0.  (3.56)
```

假设观测值是独立同分布（i.i.d.）的，最大似然估计量具有以下一些非常吸引人的性质：

*   **渐近无偏**：即假设我们采用的概率密度函数（PDF）模型是正确的，且存在真实参数 `θ_o`，则有
    ```
    lim_{N→∞} E[θ̂_ML] = θ_o.  (3.57)
    ```

*   **渐近一致性**：即给定任意 `ε > 0`，
    ```
    lim_{N→∞} Prob{ |θ̂_ML - θ_o| > ε } = 0,  (3.58)
    ```
    也就是说，对于较大的 `N` 值，我们期望最大似然估计值以高概率非常接近真实值。

*   **渐近有效性**：即它达到了克拉梅-罗下界。

*   **充分统计量性质**：如果存在未知参数的充分统计量 `T(X)`，则仅凭 `T(X)` 即可表达相应的最大似然估计量（习题 [3.20](#Chp003_65-117_B9780443292385000093.xhtml#o0105)）。

*   **最优性**：此外，假设存在有效估计量，则该估计量在最大似然意义上是最优的（习题 [3.21](#Chp003_65-117_B9780443292385000093.xhtml#o0110)）。
