### 11.5.2 核函数示例

在本小节中，我们展示一些核函数的典型示例，这些核函数常用于各种应用中。

*   **\*高斯\* 核** 是最流行的核之一，其形式为我们熟悉的公式

```
κ(x, y) = exp( - ||x - y||^2 / (2σ^2) ),
```

其中 `σ > 0` 为参数。[图 11.7](#Chp011_519-582_B9780443292385000172.xhtml#f0040)A 显示了作为 `x, y ∈ 𝒳 = ℝ` 和 `σ = 0.5` 函数的高斯核。[图 11.7](#Chp011_519-582_B9780443292385000172.xhtml#f0040)B 显示了将核的一个参数设为 0 时（即 `κ(⋅, 0)`）针对不同 `σ` 值所得函数的图形。

![Figure 11.7 (A) The Gaussian kernel for 𝒳 = ℝ, σ = 0.5. (B) The function κ(⋅,0) for different values of σ.](images/B9780443292385000172/gr007.jpg)

*   由高斯核生成的 RKHS 的维度是*无限*的。证明高斯核满足所需性质的方法可以从例如 [112] 中获得。

*   **\*齐次多项式\* 核** 具有以下形式

```
κ(x, y) = (x^T y)^r,
```

其中 `r` 为参数。

*   **\*非齐次\* 多项式核** 由下式给出

```
κ(x, y) = (x^T y + c)^r,
```

其中 `c ≥ 0` 和 `r > 0, r ∈ ℕ` 为参数。该核的图形见 [图 11.8](#Chp011_519-582_B9780443292385000172.xhtml#f0045)A。在 [图 11.8](#Chp011_519-582_B9780443292385000172.xhtml#f0045)B 中展示了不同 `x₀` 值下函数 `ϕ(⋅, x₀)` 的图形。与多项式核相关的 RKHS 维度是有限的。

![Figure 11.8 (A) The inhomogeneous polynomial kernel for 𝒳 = ℝ, r = 2. (B) The graphs of κ(⋅,x₀) for different values of x₀.](images/B9780443292385000172/gr008.jpg)
