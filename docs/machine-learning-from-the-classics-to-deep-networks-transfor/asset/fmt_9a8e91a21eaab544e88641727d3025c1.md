
## BERT 的特殊标记与嵌入

*   BERT 还使用另一个特殊标记 `⟨SEP⟩` 来分隔输入序列的各个部分。对于某些应用，输入由一对句子组成，例如在问答任务中。在 [图 19.15](#Chp019_997-1102_B9780443292385000251.xhtml#f0080) 中，一个句子（记为“A”）包含 *N* 个标记，`**x**[*n*]^(*A*)`，`n = 1, 2…, N`。另一个句子（记为“B”）包含 *M* 个标记，`**x**[*m*]^(*B*)`，`m = 1, 2…, M`。注意 `**x**[*n*]^(*A*)` 和 `**x**[*m*]^(*B*)` 是作为网络输入呈现的嵌入向量。

*   在 BERT 中，除了词汇嵌入和位置嵌入外，还使用第三种嵌入来提供句子信息。这种嵌入也是在预训练期间学习的。因此，在 BERT 中，句子相关信息由以下两部分提供：a) `⟨SEP⟩` 符号，用于分隔两个句子；b) 句子嵌入。因此，对于每个标记，最终的输入嵌入是三个项的求和结果，这与包含两项的公式 [(19.30)](#Chp019_997-1102_B9780443292385000251.xhtml#deq73) 形成对比。句子嵌入向量对于句子“A”（或“B”）中的所有标记都是相同的，即 `**s**[*A*]`（`**s**[*B*]`）。

### 19.5.1 预训练

回顾第 [19.3.10](#Chp019_997-1102_B9780443292385000251.xhtml#s0120) 节，在预训练期间，解码器的目标是给定当前和之前的标记来预测序列中的下一个词。之所以使用预测，是因为对于特定位置而言，所有未来的标记都被*掩码*了。然而，在 BERT 中，整个序列是同时可用的，且注意力分数涉及所有过去和未来的位置。为了克服这个问题，BERT 采用了一种非常古老的技术，称为*完形填空任务*；参见 [179]。随机选择一些输入标记并将其掩码，例如，它们被特殊标记 `⟨MASK⟩` 替换。训练的目标变为*预测*原始词汇表中（独热表示）对应于被掩码嵌入的真实词汇*仅限于被掩码位置*。借用 [图 19.9](#Chp019_997-1102_B9780443292385000251.xhtml#f0050) 中用于解码器的理念，最后一个块的输出向量（对应于被掩码的输入嵌入）通过一个额外的网络，该网络包含一个线性变换，后接 softmax 非线性激活。因此，对应于被掩码词的输出被转换为 *l* 维（词汇表大小）的概率向量，在训练期间它们被最优地“推向”预测对应原始词的 ID。损失函数的形成遵循与推导公式 [(19.45)](#Chp019_997-1102_B9780443292385000251.xhtml#deq101) 类似的逻辑。因此，组成 BERT 的单个 Transformer 块堆栈同时充当编码器和解码器。通过随机掩码进行训练在第 [19.6](#Chp019_997-1102_B9780443292385000251.xhtml#s0190) 节中进一步讨论。

除了掩码外，BERT 还采用另一种预训练途径，称为*下一句预测*（NSP）。正如 [43] 中指出的，许多 NLP 任务（如问答）基于理解两个句子之间的*关系*，这不容易通过预测性语言建模直接捕捉。为了促进关系学习，在*二分类*“下一句预测”任务的背景下，输出嵌入向量 `***c***` 被调用。为此，从语料库中提取的若干训练样本句子对（设为“A”和“B”）被提供给输入。在这些样本的 50% 中，句子“B”是下一句（标签 `ISNEXT` 或 1），其余 50% 中，句子“B”从语料库中随机选择（标签 `ISNOTNEXT` 或 0）。对于训练，`***c***` 首先被线性变换为二维向量，然后 softmax 非线性激活将两个元素中的每一个转换为概率。网络被训练以最优地解决这个二分类任务。

### 19.5.2 微调

在微调期间，最后一个（顶层）Transformer 块的输出向量被用作输入，馈送给一个用新参数集 `***w***` 描述的额外网络。在特定下游任务的框架内，通过*端到端*优化网络来进行训练，即相对于额外参数 `***w***` 以及定义 BERT Transformer 的参数 `***θ***` 进行优化。预训练期间学到的最优参数集（例如 `**θ**[*]`）被用作微调期间反向传播算法的相应初始估计值。注意在微调阶段输入标记不被掩码。
