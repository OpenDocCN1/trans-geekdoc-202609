### 19.7.4 Generative modeling via stochastic differential equations

In the two previously discussed approaches for constructing diffusion models, the perturbation of the input data was performed via a *finite* number of noise distributions. An alternative approach was proposed in [173], where a *continuum* of distributions is employed, which evolve over time according to a diffusion process. The method builds upon a stochastic differential equation (SDE) that progressively diffuses a data point to random noise. Moreover, the corresponding SDE is not trainable and does not depend on data. It turns out that this process can be reversed, via a reverse-time SDE that molds noise back to data for sample generation.

Without resorting to strict definitions related to stochastic differential equations, differentials of random variables, Wiener processes, and Brownian motion (see, e.g., [140]) and following [173], the (forward) diffusion SDE is written as

```
d**x** = **f**(**x**, t)*dt + g(t)*d**w**,
```

where **w** is a standard Wiener process, i.e., a Brownian motion, and **f**(⋅, t) is a vector function that determines the drift and `g(t)` a function that determines the diffusion of the SDE. In [173], it is shown that DDPM and NCSN result as different discretizations of this SDE. It has been shown ([4]) that there exists a reverse SDE^([^(145)](#fn145))

```
d**x** = [**f**(**x**, t) - g(t)^2 ∇_**x** ln q_t(**x**)] dt + g(t)*d**w̃**,
```

where `**w̃**` is a standard Wiener process with time flowing backwards from `T` to 0, `dt` is an infinitesimal negative time step, and `q[t]` denotes the distribution of **x**[t] in the forward process. The main issue with Eq. [(19.80)](#Chp019_997-1102_B9780443292385000251.xhtml#deq157) is to learn the score of the involved distribution, ∇[**x**] ln q[t](**x**).
