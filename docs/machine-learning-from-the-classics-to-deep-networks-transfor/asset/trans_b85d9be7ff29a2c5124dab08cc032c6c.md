
# 自注意力层原理

自注意力层的主要原理是应用一种注意力机制，该机制*关联*输入序列的不同标记/位置，以生成相应的信息丰富的上下文表示。正如我们在第 [19.3.2](#Chp019_997-1102_B9780443292385000251.xhtml#s0080) 节、公式 [(19.27)](#Chp019_997-1102_B9780443292385000251.xhtml#deq62) 中所见，关联两个实体/向量的注意力系数是它们相互*相似度*的函数。在那里，两个向量之间的相似度度量用它们*内积*的函数来表示。原则上，可以使用任何其他相似度度量。在 Transformer 框架中，采用了一种更精细的相似度测量过程。为此，针对每个标记 **x**[*n*]，*n* = 0, 1, …, *N* + 1，首先形成三个辅助向量。

## 查询向量

*   **查询向量**：这些向量通过将输入嵌入投影到一个新的子空间来定义，即

```
**q**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*q*), *W*^(*q*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **q**[*n*] ∈ ℝ^(*d*[*k*])
```

其中维度 *d*[*k*] 是用户定义的参数。

## 键向量

*   **键向量**：这些向量也是投影到一个 *d*[*k*]-维子空间中，即

```
**k**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*k*), *W*^(*k*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **k**[*n*] ∈ ℝ^(*d*[*k*])
```

## 值向量

*   **值向量**：这些向量是投影到另一个 *d*[*v*]-维子空间中，即

```
**v**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*v*), *W*^(*v*) ∈ ℝ^(*d*[*m*] × *d*[*v*]), **v**[*n*] ∈ ℝ^(*d*[*v*])
```

其中，*d*[*v*] 也是用户定义的参数。
