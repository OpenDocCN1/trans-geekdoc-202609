2.  9.22 本练习复现了第 [9.10](#Chp009_417-462_B9780443292385000159.xhtml#s0115) 节案例研究中的去噪结果，其中描绘船只的图像可以从书籍网站下载。首先，使用 `im2col.m` MATLAB® 函数从图像中提取所有可能的尺寸为 $12 \times 12$ 的滑动图像块。确认总共获得了 $(256 - 12 + 1)^2 = 60,025$ 个图像块。接下来，需要设计一个字典，使得所有图像块都能在其中稀疏表示。

3.  具体而言，字典原子将对应于二维冗余 DCT 变换，并按如下方式获得 [49]：

    1.  **a)** 考虑向量 $\mathbf{d}[i] = [d[i, 1], d[i, 2], \dots, d[i, 12]]^T$，$i = 0, \dots, 13$，为以下形式的采样正弦波：
    
    $$
    d_{i,t + 1} = \cos\left( \frac{t\pi i}{14} \right),\quad t = 0,\ldots,11.
    $$
    
    ![Equation](images/B9780443292385000159/si353.png)
    
    2.  然后构建一个 $(12 \times 14)$ 矩阵 $\overline{D}$，其列为归一化到单位范数的向量 $\mathbf{d}[i]$；$D$ 类似于一个冗余 DCT 矩阵。
    
    3.  **b)** 构建 $(12^2 \times 14^2)$ 字典 $\Psi$，根据 $\Psi = D \otimes D$，其中 $\otimes$ 表示克罗内克积。以这种方式构建，生成的原子对应于与冗余 2D-DCT 变换相关的原子 [49]。
