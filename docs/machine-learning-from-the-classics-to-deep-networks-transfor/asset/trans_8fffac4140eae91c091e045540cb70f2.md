
- 由于 [(11.43)](#Chp011_519-582_B9780443292385000172.xhtml#deq116)，`ξ̃[n]` 或 `ξ[n]` 中只能有一个非零，不能同时非零。这也适用于对应的拉格朗日乘子。

- 注意，如果 `ξ̃[n] > 0`（或 `ξ[n] > 0`），则由 [(11.40)](#Chp011_519-582_B9780443292385000172.xhtml#deq113)、[(11.46)](#Chp011_519-582_B9780443292385000172.xhtml#deq119) 和 [(11.47)](#Chp011_519-582_B9780443292385000172.xhtml#deq120) 可得：

```
λ̃[n] = C  或  λ[n] = C.
```

即相应的拉格朗日乘子取得其最大值。换句话说，它们在 [(11.44)](#Chp011_519-582_B9780443292385000172.xhtml#deq117) 的展开中具有“决定性影响”。当 `ξ̃[n]` 和/或 `ξ[n]` 为零时，则有：

```
0 ≤ λ̃[n] ≤ C,  0 ≤ λ[n] ≤ C.
```

- 回顾我们之前关于 `θ[0]` 估计的论述。选择任意对应于 `0 < λ̃[n] < C`（`0 < λ[n] < C`）的点，我们知道它对应 `ξ̃[n] = 0 (ξ[n] = 0)`。然后根据公式 [(11.38)](#Chp011_519-582_B9780443292385000172.xhtml#deq111) 和 [(11.39)](#Chp011_519-582_B9780443292385000172.xhtml#deq112) 计算 `θ̂[0]`。在实践中，选择所有此类点并计算 `θ[0]` 作为相应的平均值。
