
然而，我们知道 `G'` 本身就是从后验 DP 中随机抽取的。关于 `G'` 进行边缘化，即取期望，并回顾前面所述的均值性质，我们得到

```
P(θ_{n + 1} ∈ T|θ_{1},...,θ_{n}) = \frac{1}{\alpha + n}\left( \alpha G_{0}(T) + \sum\limits_{i = 1}^{n}\delta_{θ_{i}}(θ ∈ T) \right).
```

最后一个公式引出了如下的物理解释。考虑一个空盒，并假设 `θ` 中的每个值对应一种*唯一*的颜色。此外，我们拥有可数无限个球。从基础分布中随机选取一种颜色，即 `θ[i] ∼ G[0]`，并将球涂成相应的颜色。球涂色后，将其放入盒中，盒中现有一个球。在第二步中，我们拿起一个新球，然后要么 (a) 以概率 `\frac{\alpha}{\alpha + 1}` 选取一种新颜色 `θ[2] ∼ G[0]`，将其涂上相应颜色并放入盒中，要么 (b) 以概率 `\frac{1}{\alpha + 1}` 将球涂成盒中已有球的相同颜色，然后将其放入盒中。现在盒中有两个球。重复上述步骤。因此，在第 (`n` + 1) 步时，盒中包含 `n` 个球。我们拿起一个新球，然后要么 (a) 以概率 `\frac{\alpha}{\alpha + n}` 选取一种新颜色 `θ[n + 1] ∼ G[0]`，涂上新球并将其放入盒中，要么 (b) 以概率 `\frac{n}{\alpha + n}` 从盒中的 `n` 个球中随机选取一个，用其颜色涂新球；涂色后，也将其放入盒中，盒中将包含 `n` + 1 个球。文献 [10] 利用这一解释证明了 DP 过程的存在性。

有两个重要性质。注意到随着 `n` 增加，从盒中选取颜色的概率 `\frac{n}{\alpha + n}` 相对于从 `G[0]` 选取颜色的概率 `\frac{\alpha}{\alpha + n}` 不断增大。因此，对于长序列，我们将越来越多地选取先前使用过的颜色，这些颜色将被重复使用。这证明了该过程的离散性质。
