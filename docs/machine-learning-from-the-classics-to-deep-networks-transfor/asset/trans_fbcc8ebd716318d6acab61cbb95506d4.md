

## 算法描述

**公式：**

```
d̂[n] = w[n−1]ᴴ u[e, n]
d[n] = s[n−L+1];          // 训练模式下
d[n] = T[d̂[n]];           // 决策导向模式下
e[n] = d[n] − d̂[n]
w[n] = w[n−1] + μ u[e, n] e[n]*
```

其中 `T[·]` 表示阈值操作。

## 示例 5.7

考虑一个通信系统，输入信息序列包含随机生成的符号流 `s[n] = ±1`，概率相等。该序列发送到一个具有冲激响应的信道：

```
h = [0.04, −0.05, 0.07, −0.21, 0.72, 0.36, 0.21, 0.03, 0.07]ᵀ
```

信道输出受到白高斯噪声污染，`SNR = 11 dB`。采用 DFE（决策反馈均衡器），前馈部分长度 `L = 21`，反馈部分长度 `l = 10`。DFE 使用 250 个符号进行训练；随后切换到决策导向模式，运行 10,000 次迭代。每次迭代中，决策 `sgn(d̂[n])` 与真实发送符号 `s[n−L+1]` 进行比较。误码率（总错误数除以相应发送符号数）约为 1%。图 5.21 显示了平均 MSE 曲线作为迭代次数的函数。对于 LMS，使用 `μ = 0.025`。
