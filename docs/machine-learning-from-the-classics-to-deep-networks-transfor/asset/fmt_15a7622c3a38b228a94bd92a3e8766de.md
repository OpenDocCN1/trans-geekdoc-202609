
# 降维与稀疏恢复的视角

我们将从另一个角度来阐述本章迄今为止的内容。在两种情况下——无论是未知量是高维空间 $\mathbb{R}^l$ 中的 $k$-稀疏向量，还是信号 $\mathbf{s}$ 在某个字典中（近似）稀疏表示（$\mathbf{s} = \mathbf{\Psi}\boldsymbol{\theta}$）——我们都选择在低维空间（$\mathbb{R}^N$，即观测空间 $\mathbf{y}$）中工作。这是一个典型的降维任务（参见第 20 章）。

任何（线性）降维技术的主要任务是选择合适的矩阵 $X$，它决定了向低维空间的投影。一般来说，从 $\mathbb{R}^l$ 投影到 $\mathbb{R}^N$（其中 $N < l$）总会丢失信息，因为我们无法从其投影 $\boldsymbol{\theta}_N \in \mathbb{R}^N$ 中恢复任意向量 $\boldsymbol{\theta}_l \in \mathbb{R}^l$。确实，取任意向量 $\boldsymbol{\theta}_{l-N} \in \text{null}(X)$，它位于（满行秩）$X$ 的 $(l-N)$ 维零空间中（参见第 9.5 节）。那么所有向量 $\boldsymbol{\theta}_l + \boldsymbol{\theta}_{l-N} \in \mathbb{R}^l$ 在 $\mathbb{R}^N$ 中具有相同的投影。

然而，本章发现的关键在于：如果原始向量是稀疏的，则可以精确恢复它。这是因为所有 $k$-稀疏向量并不分布在 $\mathbb{R}^l$ 的任意位置，而是位于其一个子集中，即*子空间并集*，每个子空间的维度为 $k$。如果信号 $\mathbf{s}$ 在字典 $\mathbf{\Psi}$ 中是稀疏的，那么就必须在 $\mathbb{R}^l$ 所有可能的 $k$ 维子空间的并集中搜索它，这些子空间由 $\mathbf{\Psi}$ 的 $k$ 个列向量张成 [8,62]。

当然，即使涉及稀疏向量，也没有任何投影能保证唯一恢复。保证的前提是低维空间中的投影是*稳定嵌入*。稳定嵌入必须保证：如果 $\boldsymbol{\theta}_1 \neq \boldsymbol{\theta}_2$，则它们的投影也保持不同。但这还不够。稳定嵌入还必须保证距离（近似）保持不变；即高维空间中相距较远的向量，其投影也相距较远。这种性质保证了对噪声的鲁棒性。

贯穿本章推导和讨论的充分条件，能保证从 $\mathbb{R}^N$ 中的投影恢复位于 $\mathbb{R}^l$ 的稀疏向量，这些条件正是保证稳定嵌入的条件。RIP 及其对 $N$ 的相关界给出了 $X$ 的条件，从而实现稳定嵌入。我们在相关小节中评论了 RIP 的这一范数保持性质。理论得出的一个有趣事实是：我们可以通过随机投影矩阵实现这种稳定嵌入。
