## 20.11 案例研究：fMRI 数据分析

在大脑中，涉及动作、感知、认知等的任务，是通过若干所谓的*功能脑网络*（FBN）的同时激活来执行的，这些网络通过适当的相互作用以有效地完成任务。此类网络通常与低级大脑功能相关，并被定义为若干个*分离的*专业化小脑区，这些脑区可能分布在整个大脑中。对于每个 FBN，所涉及的分离脑区定义了*空间图谱*，这表征了特定的 FBN。此外，这些脑区无论其解剖学上的远近，都表现出*强*功能连接性，这表现为这些区域激活时间模式的强相干性。此类功能脑网络的例子包括视觉、感觉运动、听觉、默认模式、背侧注意和执行控制网络 [148]。

*功能性磁共振成像*（fMRI）[131] 是一种强大的无创工具，用于检测随时间变化的大脑活动。最常见的是，它基于*血氧水平依赖*（BOLD）对比度，这转化为检测激活脑区中含氧血液血流动力学流的局部变化。这是通过利用含氧血红蛋白与脱氧血红蛋白不同的磁学特性来实现的。检测到的 fMRI 信号同时在空间（三维）和时间（一维）域中记录。空间域通过三维网格分割为边长 3-5 毫米的基本立方体，称为*体素*。通常，一次完整的体积扫描由 64 × 64 × 48 个体素组成，并在一到两秒内采集完成 [131]。依赖于充分的后处理，可有效补偿可能的时间滞后和其他伪影 [131]，因此可以相当准确地假设每次采集都是瞬时完成的。对应单次扫描的总共 `l` 个体素值，被收集到一个扁平化的（行）一维向量 `x[n] ∈ ℝ^l` 中。考虑 `n = 1, 2, …, N` 次连续采集，全部数据被收集在一个数据矩阵 `X ∈ ℝ^(N×l)` 中。因此，`X` 的每一列 `i = 1, 2, …, l` 代表对应第 `i` 个体素值随时间的演变。每一行 `n = 1, 2, …, N` 对应在相应时刻 `n` 所有 `l` 个体素上的激活模式。

记录的体素值源于若干 FBN 的累积贡献，其中每一个 FBN 都遵循特定的时间模式被激活，这取决于大脑正在执行的任务。上述过程可根据数据矩阵的以下分解进行数学建模：

```
X = ∑_{j=1}^m a_j z_j^T := AZ
```
