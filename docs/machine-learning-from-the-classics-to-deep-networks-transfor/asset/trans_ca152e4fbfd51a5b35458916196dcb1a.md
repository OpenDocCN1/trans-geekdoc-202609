
我们得知“秘密”在于 **θ** 的大多数分量（几乎）为零。在第 [13.5](#Chp013_635-716_B9780443292385000196.xhtml#s0045) 节中，我们评论了高斯先验在为稀疏随机向量提供合理统计描述方面的不足。一种在稀疏建模中广受欢迎的重尾分布是拉普拉斯分布。毕竟，为 **θ** 采用拉普拉斯先验，即

```
p(θ) = ∏_{k=1}^K p(θ_k) = ∏_{k=1}^K (λ/2) exp(-λ|θ_k|)
```

并结合如公式 [(13.22)](#Chp013_635-716_B9780443292385000196.xhtml#deq29) 所示的观测值 **y** 的高斯条件 PDF `p(y|θ)`，使得 MAP 估计与我们熟悉的 LASSO 任务（第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章讨论过）完全相同。基于此，我们将围绕拉普拉斯 PDF 来构建本节内容。[图 13.13](#Chp013_635-716_B9780443292385000196.xhtml#f0075)A 显示了不同 `λ` 值下的拉普拉斯分布。在 [图 13.13](#Chp013_635-716_B9780443292385000196.xhtml#f0075)B 中提供了二维图，从中可以明显看出该 PDF 尊重稀疏解，这表现为其沿两个轴的衰减较慢。

拉普拉斯 PDF 的问题在于，它在公式 [(12.14)](#Chp012_583-634_B9780443292385000184.xhtml) 中的存在使得积分的计算在计算上变得难以处理。此外，回顾第 [12.8](#Chp012_583-634_B9780443292385000184.xhtml) 节，拉普拉斯 PDF 不属于计算上极具吸引力的指数族分布。为了便于处理，我们将采用变分界近似方法，按照公式 [(13.90)](#Chp013_635-716_B9780443292385000196.xhtml#deq135) 和 [(13.92)](#Chp013_635-716_B9780443292385000196.xhtml#deq138) 用高斯分布来近似拉普拉斯分布。变分参数将通过 EM 算法最大化相应证据来确定。这种恢复稀疏解的方法最早是在文献 [21] 中针对字典学习背景引入的。
