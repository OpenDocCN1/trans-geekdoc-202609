
### Characterization of the ℓ₁ norm minimizer

**Lemma 9.1**

An element **θ** in the affine set Θ of the solutions of the underdetermined linear system in Eq. (9.17) has minimal ℓ₁ norm if and only if the following condition is satisfied:

$$
\left| \sum_{i: \theta_i \neq 0} \text{sgn}(\theta_i) z_i \right| \leq \sum_{i: \theta_i = 0} |z_i|, \quad \forall \mathbf{z} \in \text{null}(X).
$$ (9.22)

Moreover, the ℓ₁ minimizer is unique if and only if the inequality in (9.22) is a strict one for all **z** ≠ 0 (see, e.g., [74] and Problem 9.11).
