
where `v[k]^⊥(n)` is the noise corrupting the unit norm perpendicular direction vector `g[k]^⊥` and `v[k]^∥(n)` is the noise occurring at the parallel direction vector. Taking into consideration the noisy terms, Eq. [(5.101)](#Chp005_177-248_B9780443292385000111.xhtml#deq219) is written as

```
r̂_k(n) = ĝ_k^T(n)(θ_o − θ_k) + η_k(n),
```
(5.103)

where

```
η_k(n) = v_k(n) − v_k^⊥(n)g_k^(⊥T)(θ_o − θ_k) − v_k^∥(n)g_k^(T)(θ_o − θ_k).
```
(5.104)

Eq. [(5.104)](#Chp005_177-248_B9780443292385000111.xhtml#deq222) can be further simplified if one recalls that by construction `g_k^(⊥T)(θ_o − θ_k) = 0`. Moreover, typically, the contribution of `v_k^⊥(n)` is assumed to be significantly larger than the contribution of `v_k^∥(n)`. Henceforth, taking into consideration these two arguments, Eq. [(5.104)](#Chp005_177-248_B9780443292385000111.xhtml#deq222) can be simplified to

```
η_k(n) ≈ v_k(n).
```
(5.105)
