为了继续推导，现在需要引入假设。

### 假设 1
涉及的随机变量通过回归模型联合关联，

*y* = **θ**[*o*]^(*T*)**x** + *η*，

其中 *η* 为方差为 *σ*[*η*]² 的噪声变量，并假设其独立于 **x**。此外，生成数据的连续样本 *η*[*n*] 被假设为独立同分布。我们在 [备注 4.2](#Chp004_119-175_B978044329238500010X.xhtml) 和问题 [4.4](#Chp004_119-175_B978044329238500010X.xhtml) 中已经看到，在这种情况下，**θ** [*] = **θ** [*o*] 且 *σ* [*e* [*]]² = *σ* [*η*]²。此外，由于正交条件，𝔼[**x***e* [*]] = **0**。另外，将采用一个更强的条件，假设 *e* [*] 和 **x** *统计独立*。这由上述模型下 *e* [*, n*] = *η* [*n*] 且噪声序列已被假设独立于输入这一事实所证明。

### 假设 2
(独立性假设) 假设 **c** [*n* − 1] 与 **x** 和 *e* [*] 均统计独立。毫无疑问这是一个强假设，但我们将采用它来简化计算。有时人们倾向于通过诉诸某些特殊情况来为该假设“辩护”，我们不会这样做。如果读者对该假设不满意，则需寻找基于更严格数学分析的更新方法；当然，这并不意味着那些方法不含假设。
