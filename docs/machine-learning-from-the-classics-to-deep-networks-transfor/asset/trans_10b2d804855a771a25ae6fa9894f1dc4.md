## 11.9 核岭回归再探

核岭回归在第 11.7 节中已介绍。这里将通过其对偶表示形式重述。岭回归的原始表示可以表述为

```
minimize with respect to θ, ξ  J(θ,ξ) = ∑_{n=1}^{N} ξ_n^2 + C‖θ‖^2, subject to  y_n - θ^T x_n = ξ_n, n = 1,2,…,N,
```

从而得到以下拉格朗日函数：

```
L(θ,ξ,λ) = ∑_{n=1}^{N} ξ_n^2 + C‖θ‖^2 + ∑_{n=1}^{N} λ_n(y_n - θ^T x_n - ξ_n), n = 1,2,…,N.
```

对 `θ` 和 `ξ_n`（`n = 1,2,…,N`）求导并令其为零，可得

```
θ = (1/(2C)) ∑_{n=1}^{N} λ_n x_n
```
