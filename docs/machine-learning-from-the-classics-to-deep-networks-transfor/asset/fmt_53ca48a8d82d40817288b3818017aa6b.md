
In words, if `θ[g]` is kept fixed, then the discriminator is trained, via `θ[d]`, so that its output is maximized both for real (`D(x; θ[d])`) and for fake (`1 − D(G(z; θ[g]); θ[d])`) examples. Furthermore, keeping `θ[d]` fixed, `G` is *simultaneously* trained through `θ[g]` to minimize `1 − D(G(z; θ[g]); θ[d])`, in order to confuse the discriminator.

[Algorithm 19.2](#Chp019_997-1102_B9780443292385000251.xhtml#enun0015) summarizes the main concept, adopting a mini-batch (of size `K`) optimization rationale.
