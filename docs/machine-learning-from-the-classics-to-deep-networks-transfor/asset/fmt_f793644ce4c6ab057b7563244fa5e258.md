
## Dirichlet Distribution

The Dirichlet distribution is given by:

$$
\text{Dir}(\mathbf{x}|\mathbf{a}) = C \prod_{k=1}^{K} x_k^{a_k - 1}, \quad \sum_{k=1}^{K} x_k = 1
$$

![Equation](images/B9780443292385000184/si453.png)

where the normalization constant $C$ is:

$$
C = \frac{\Gamma(a_1 + a_2 + \cdots + a_K)}{\Gamma(a_1)\Gamma(a_2)\ldots\Gamma(a_K)}.
$$

![Equation](images/B9780443292385000184/si454.png)

**Hint**: Use the property $\Gamma(a + 1) = a\Gamma(a)$.

![Equation](images/B9780443292385000184/si455.png)

### (a) Induction Proof
Use induction. Because the proposition is true for $k=2$ (beta distribution), assume that it is true for $k = K-1$, and prove that it will be true for $k=K$.

### (b) Independence Constraint
Note that due to the constraint $\sum_{k=1}^{K} x_k = 1$, only $K-1$ of the variables are independent. So, basically, the Dirichlet PDF implies that:

$$
p(x_1, x_2, \ldots, x_{K-1}) = C \prod_{k=1}^{K-1} x_k^{a_k - 1} \left( 1 - \sum_{k=1}^{K-1} x_k \right)^{a_K - 1}.
$$
