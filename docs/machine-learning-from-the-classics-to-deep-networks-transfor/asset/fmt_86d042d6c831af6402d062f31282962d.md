
## 数学推导与最优估计

𝔼 \[(y−f(x))²\] = 𝔼 \[(y−𝔼[y|x])²\] + (𝔼[y|x]−f(x))²

其中我们考虑到，对于固定的 `x`，项 `𝔼[y|x]` 和 `f(x)` 不是随机变量。从公式 (3.49) 我们最终得到我们的结论：

𝔼 \[(y−f(x))²\] ≥ 𝔼 \[(y−𝔼[y|x])²\]

 □

注意这是一个非常优雅的结果。在均方误差（MSE）意义上，未知函数在点 `x` 处值的最优估计由 `ĝ(x) = 𝔼[y|x]` 给出。有时，后者也被称为 `y` 关于 `x = x` 的条件回归。这通常是一个非线性函数。可以证明，如果 `(y, x)` 取值于 `ℝ × ℝ^l` 且服从联合高斯分布，则最优 MSE 估计器 `𝔼[y|x]` 是 `x` 的线性（仿射）函数。

前面的结果推广到 `y` 是取值于 `ℝ^k` 的随机向量的情况。给定 `x = x` 的值，最优 MSE 估计等于：

```
ĝ(x) = 𝔼[y|x],
```
