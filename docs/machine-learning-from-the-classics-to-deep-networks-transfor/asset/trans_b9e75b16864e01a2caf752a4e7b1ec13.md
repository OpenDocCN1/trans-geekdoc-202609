$$
\operatorname{Prox}_{\lambda\iota_{C}}(\mathbf{x}) = \arg\min_{\mathbf{v} \in \mathbb{R}^{l}}\left\{ \iota_{C}(\mathbf{v}) + \frac{1}{2\lambda}\|\mathbf{x} - \mathbf{v}\|^{2} \right\} = \arg\min_{\mathbf{v} \in C}\|\mathbf{x} - \mathbf{v}\|^{2} = P_{C}(\mathbf{x}),\quad \forall\mathbf{x} \in \mathbb{R}^{l},\ \forall\lambda > 0,
$$
