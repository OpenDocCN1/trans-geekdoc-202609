
指数族的一个优势在于可以为 `θ` 找到共轭先验；即，导致后验 `p(θ|X)` 与先验 `p(θ)` 具有相同函数形式的先验（第 [3.11.1](#Chp003_65-117_B9780443292385000093.xhtml) 节，[备注 3.4](#Chp003_65-117_B9780443292385000093.xhtml)）。

给定公式 [(12.72)](#Chp012_583-634_B9780443292385000184.xhtml#deq96)，其共轭先验由下式给出：

```
p(θ; λ, v) = h(λ, v)(g(θ))^(λ)exp(ϕ^T(θ)v)
```

其中 `λ > 0` 和 `v` 被称为*超参数*；即控制其他参数的参数。因子 `h(λ, v)` 是适当的归一化常数。很容易看出，将先验 PDF 定义为公式 [(12.74)](#Chp012_583-634_B9780443292385000184.xhtml#deq98) 所示，将条件 PDF 定义为公式 [(12.72)](#Chp012_583-634_B9780443292385000184.xhtml#deq96) 所示，则后验 `p(θ|x)` 将具有与公式 [(12.74)](#Chp012_583-634_B9780443292385000184.xhtml#deq98) 相同的形式。

在给出一些示例之前，让我们更深入地探讨一下 `λ` 和 `v` 的作用，以及 `g(θ)` 和 `ϕ(θ)` 在公式 [(12.74)](#Chp012_583-634_B9780443292385000184.xhtml#deq98) 和 [(12.72)](#Chp012_583-634_B9780443292385000184.xhtml#deq96) 中的存在意义。假设 `x` 和 `θ` 满足公式 [(12.72)](#Chp012_583-634_B9780443292385000184.xhtml#deq96)–[(12.74)](#Chp012_583-634_B9780443292385000184.xhtml#deq98)，且令 `X = {x[1], …, x[N]}` 为一组独立同分布观测值。则

```
p(X|θ) = (g(θ))^N ∏_{n=1}^N f(x_n) exp( ϕ^T(θ) ∑_{i=1}^N u(x_i) )
```
