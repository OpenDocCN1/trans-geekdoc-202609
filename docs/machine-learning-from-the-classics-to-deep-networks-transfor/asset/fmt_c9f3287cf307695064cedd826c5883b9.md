
Combining Eqs. [(7.93)](#Chp007_293-342_B9780443292385000135.xhtml#deq141) and [(7.94)](#Chp007_293-342_B9780443292385000135.xhtml#deq142) with Eqs. [(7.88)](#Chp007_293-342_B9780443292385000135.xhtml#deq136) and [(7.90)](#Chp007_293-342_B9780443292385000135.xhtml#deq138), it is readily shown that

```
a_i = \arg\min_a \left\{ \exp(-a)(1 - P_i) + \exp(a)P_i \right\}.
```

Taking the derivative with respect to `a` and equating to zero results in

```
a_i = \frac{1}{2}\ln\frac{1 - P_i}{P_i}.
```

Note that if `P[i] < 0.5`, then `a[i] > 0`, which is expected to be the case in practice. Once `a[i]` and `θ[i]` have been estimated, the weights for the next iteration are readily given by

```
w_n^{(i + 1)} = \frac{\exp(-y_n F_i(\mathbf{x}_n))}{Z_i} = \frac{w_n^{(i)}\exp(-y_n a_i \phi(\mathbf{x}_n; \mathbf{\theta}_i))}{Z_i},
```

where `Z[i]` is the normalizing factor.
