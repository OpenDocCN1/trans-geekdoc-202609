在实践中，即使将相对较少数量 $N$ 的随机变量相加，也能获得对高斯分布的良好近似。例如，如果各个 PDF 足够平滑，且每个随机变量都是*独立同分布*（i.i.d.），则 $N$ 在 5 到 10 之间的数值可能就足够了。术语 i.i.d. 将在本书中大量使用。该术语意味着随机变量的连续样本是从描述该变量的同一分布中独立抽取的。

#### 指数分布

如果满足以下条件，我们称随机变量服从参数为 $\lambda > 0$ 的指数分布：

![Equation](images/B9780443292385000081/fx017.jpg)(2.85)

例如，该分布已被用于模拟电话呼叫到达之间或公交车站公交车到达之间的时间间隔。通过遵循简单的积分规则，均值和方差可以很容易地计算出来，它们分别是

$\mathbb{E}[ x ] = \frac{1}{\lambda},\quad\sigma_{x}^{2} = \frac{1}{\lambda^{2}}.$

#### Beta 分布

如果满足以下条件，我们称随机变量 $x \in [0, 1]$ 服从具有正参数 $a, b$ 的 Beta 分布，记作 $x \sim \text{Beta}(x|a, b)$：

![Equation](images/B9780443292385000081/fx018.jpg)(2.87)

其中 $B(a, b)$ 是 Beta 函数，定义为

$B(a, b) := \int_0^1 x^{(a-1)}(1-x)^{(b-1)} dx.$

![Equation](images/B9780443292385000081/si199.png)(2.88)

注意，对于 $a < 1$ 和 $b < 1$ 的情况，该分布的支集应限制在 $(0, 1)$。Beta 分布的均值和方差由下式给出（习题 [2.4](#Chp002_19-64_B9780443292385000081.xhtml#o0025)）

$\mathbb{E}[ x ] = \frac{a}{a + b},\quad\sigma_{x}^{2} = \frac{ab}{(a + b)^{2}(a + b + 1)}.$
