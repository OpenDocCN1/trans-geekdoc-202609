
### Proximal Operator of the L1 Norm

The proximal operator for the L1 norm is defined element-wise as:

```
${Prox}_{\lambda{\| \cdot \|}_{1}}(\mathbf{x})|_{i} = \arg\min\limits_{v_{i} \in \mathbb{R}}\left\{ |v_{i}| + \frac{1}{2\lambda}{(x_{i} - v_{i})}^{2} \right\},\quad i = 1,2,\ldots,l,$
```

where `Prox`[`λ`∥ ⋅ ∥[1]](**x**)|[*i*] denotes the respective *i*th element.

Minimizing Eq. (8.108) is equivalent to requiring zero to belong to the subdifferential set, which results in the closed-form solution:

```
${Prox}_{\lambda{\| \cdot \|}_{1}}(\mathbf{x})|_{i} = \begin{cases} 
x_{i} - \text{sgn}(x_{i})\lambda, & \text{if } |x_{i}| > \lambda, \\ 
0, & \text{if } |x_{i}| \leqslant \lambda 
\end{cases} = \text{sgn}(x_{i})\max\{ 0,|x_{i}| - \lambda \}.
```

For the time being, the proof is left as an exercise. The same task is treated in detail in Chapter [9](#Chp009_417-462_B9780443292385000159.xhtml), and the proof is provided in Section [9.3](#Chp009_417-462_B9780443292385000159.xhtml). The operation in Eq. [(8.110)](#Chp008_343-416_B9780443292385000147.xhtml#deq208) is also known as **soft thresholding**. In other words, it sets to zero all values with magnitude less than a threshold value (`λ`) and adds a constant bias (depending on the sign) to the rest. To provoke the unfamiliar reader a bit, this is a way to impose sparsity on a parameter vector.
