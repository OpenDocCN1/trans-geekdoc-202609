
文献[27]开展了一项比较研究，对比了在原始域和对偶域中求解SVM任务的情况。该论文的发现指出，对于线性和非线性情况，这两条路径效率相当。此外，当目标是求得近似解时，选择原始任务可以提供某些优势。另外，在原始域中工作还具有通过联合优化调节超参数的优势。求助于对偶域的主要优势之一，是可以将任务表述为内积的形式。然而，通过适当利用再现核定理，这在原始域中也是可能的。我们将在第11.12.1节看到此类示例。

最近，文献[42]提出了一种用于分布式处理的SVM版本。在文献[99]中，SVM任务利用随机投影法在一个子空间中求解。

## 11.12 随机傅里叶特征

在第11.11节中，讨论了多种技术，旨在应对计算负载及其随训练数据点数`N`的变化规模，这在SVM的背景下尤为重要。此外，许多基于核的方法的核心——如核岭回归（第11.7节）和高斯过程（将在第13.12节讨论）——在于核矩阵的求逆，该矩阵已在第11.5.1节中定义。后者维度为`N × N`，由训练样本集合中所有可能的核函数评估对构成，即`κ(x[i], x[j])`，`i, j = 1, 2, …, N`。一般而言，求逆一个`N × N`矩阵需要`O(N³)`次代数运算，随着`N`的增加，这变得难以应对。在此背景下，已提出多种技术，旨在降低相关计算成本。此类方法的示例见文献[1,45]，其中采用随机投影来“丢弃”单个元素或整行矩阵，以形成相关的低秩或稀疏矩阵近似。

文献[91]提出了一种减轻计算负载任务的替代“视角”。该方法的核心在于绕过通过核函数隐式映射到更高（可能无限）维空间，即`ϕ(x) = κ(⋅, x)`，这构成了任何基于核方法的脊柱（第11.5节）。取而代之的是，执行到*有限维*空间`ℝ^D`的显式映射，即

```
x ∈ 𝒳 ⊆ ℝ^l ↦ z(x) ∈ ℝ^D.
```

然而，该映射是以一种“深思熟虑”的方式完成的，使得在此`D`维空间中两个向量的内积约等于核函数的相应值，即

```
κ(x, y) = ⟨ϕ(x), ϕ(y)⟩ ≈ z(x)^T z(y), ∀ x, y ∈ 𝒳.
```

为了建立这种近似，调用了谐波分析中的Bochner定理（例如[96]）。为了在不求助于数学细节的情况下掌握该定理背后的主要基本原理，让我们回顾一下第2.4.3节中的功率谱密度（PSD）概念。平稳过程的PSD被定义为其自相关序列的傅里叶变换，在那里已被证明它是一个实值非负函数。此外，其积分是有限的（公式(2.125)）。虽然那里给出的证明遵循了一条相当“实用”且概念化的路径，但一个更严格的数学证明揭示，这一结果是自相关序列正定性质（公式(2.116)）的直接副产品。
