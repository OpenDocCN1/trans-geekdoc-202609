
让我们回到[示例 15.1](#Chp015_755-803_B9780443292385000214.xhtml#enun0030)。虽然 GNP 和教育质量相关，但不能说 GNP 是教育制度的原因。毫无疑问，原因是多方面的，例如政治制度、社会结构、经济制度、历史原因和传统，所有这些都需要考虑在内。事实上，示例中关联三个变量的图结构可以反转。我们可以反向收集数据；获得概率 `P(x[3] = UN)`、`P(x[3] = LP)`、`P(x[3] = HP)`，然后是条件概率 `P(x[2]|x[3])`（例如 `P(x[2] = HE|x[3] = UN)`），最后是 `P(x[1]|x[2])`（例如 `P(x[1] = HGP|x[2] = HE)`）。原则上，此类数据也可以从人群样本中收集。在这种情况下，生成的 BN 仍将包含三个节点，如[图 15.4](#Chp015_755-803_B9780443292385000214.xhtml#f0025)所示，但箭头方向反转。这也是合理的，因为给定教育水平的情况下，某人来自富国或穷国的概率独立于其工作。此外，这两种模型对于任何联合事件都应产生相同的联合概率分布。因此，如果箭头方向表示因果关系，那么这一次将是教育制度对 GNP 具有因果关系。出于上述相同理由，这无法得到证实。话虽如此，这并不一定意味着因果关系在 BN 中不存在，或者了解它们不重要。相反，在许多情况下，在构建 BN 时，有充分的理由努力揭示潜在的因果关系。

让我们对此详细阐述一下，看看为什么利用任何潜在的因果关系会对我们有益。以[图 15.5](#Chp015_755-803_B9780443292385000214.xhtml#f0030)中的 BN 为例，它关联疾病的有无与两项医学检查的结果。令 `x[1]` 表示疾病的有无，`x[2]`、`x[3]` 表示两项检查可能产生的离散结果。
