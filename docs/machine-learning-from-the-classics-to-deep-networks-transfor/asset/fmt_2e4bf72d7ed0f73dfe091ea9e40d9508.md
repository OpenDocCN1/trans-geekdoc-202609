
在最优值 `μ_o` 处，存在两个最慢模式；一个对应 `λ_min`（即 `1 - μ_o * λ_min`），另一个对应 `λ_max`（即 `1 - μ_o * λ_max`）。它们具有相等的幅度但符号相反，由下式给出：

```
± (ρ - 1) / (ρ + 1)
```

其中

```
ρ := λ_max / λ_min.
```

换句话说，**收敛速度取决于协方差矩阵特征值的分布范围**。
