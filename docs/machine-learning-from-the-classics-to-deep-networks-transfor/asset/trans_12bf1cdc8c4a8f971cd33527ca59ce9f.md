
其中 `f(x)` 是一个*随机过程*。从第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章可知，随机过程是一种随机实体，其实现（实验的结果）是一个函数 `f(x)`，而不是单个值。本节贯穿的思想是直接对 `f(x)` 进行操作，而不是通过参数集 `θ` 对其建模这种间接方法。这并非我们首次采用此类路径。我们在第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章在 RKHS 中搜索函数时，已悄然采用了这种方法。事实上，本节可被视为当前章节与第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章之间的桥梁。

回顾第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章，我们并未像公式 [(13.136)](#Chp013_635-716_B9780443292385000196.xhtml#deq210) 那样，通过若干*预选*基函数以参数化形式展开未知函数，而是倾向于直接搜索位于 RKHS 中的函数；优化是针对函数本身进行的（而非针对一组预选参数）。在平方误差损失函数的背景下，该优化被表述为

```
\min_{f \in \mathbb{H}}\sum_{n = 1}^{N}\left( y_{n} - f(\mathbf{x}_{n}) \right)^{2} + C{\| f\|}^{2},
```

其中 `∥ ⋅ ∥` 表示 `ℍ` 中的范数。本节的目标是阐述这种方法的“贝叶斯对应物”。为此，我们将重点关注一类特定的过程，即高斯过程，该过程由文献 [57] 提出。
