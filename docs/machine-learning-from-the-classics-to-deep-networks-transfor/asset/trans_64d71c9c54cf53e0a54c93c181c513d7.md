
对 `z` 的分量相互独立施加约束，等价于要求所有高阶 `cross-cumulants`（交叉累积量，附录 B.3）为零。实现这一点的一种可能性是将自身限制在四阶累积量以内 [57]。正如附录 B.3 所述，对于零均值变量，前三个累积量等于相应的矩，即

```
κ₁(zᵢ) = 𝔼[zᵢ] = 0,
κ₂(zᵢ, zⱼ) = 𝔼[zᵢzⱼ],
κ₃(zᵢ, zⱼ, zₖ) = 𝔼[zᵢzⱼzₖ],
```

![Equation](images/B9780443292385000263/si193.png)

而四阶累积量由下式给出

```
κ₄(zᵢ, zⱼ, zₖ, zᵣ) = 𝔼[zᵢzⱼzₖzᵣ] − 𝔼[zᵢzⱼ]𝔼[zₖzᵣ] − 𝔼[zᵢzₖ]𝔼[zⱼzᵣ] − 𝔼[zᵢzᵣ]𝔼[zⱼzₖ].
```
