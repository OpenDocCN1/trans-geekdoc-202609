
在文献[24]中，建议用加权版本来替代`ℓ₁`范数。为了证明这种选择的合理性，让我们回顾一下[示例 9.2](#Chp009_417-462_B9780443292385000159.xhtml)以及使用**x** = [2, 1]ᵀ感知“未知”系统的情况。我们已经看到，通过“吹胀”`ℓ₁`球，得到了错误的稀疏解。现在让我们将公式[(9.21)](#Chp009_417-462_B9780443292385000159.xhtml)中的`ℓ₁`范数替换为其加权版本，

```
‖θ‖₁,𝑤 := 𝑤₁|θ₁| + 𝑤₂|θ₂|, 𝑤₁, 𝑤₂ > 0
```

并设定`𝑤₁ = 4`和`𝑤₂ = 1`。[图 10.7](#Chp010_463-518_B9780443292385000160.xhtml#f0040)A展示了等值曲线`‖θ‖₁,𝑤 = 1`，以及由标准`ℓ₁`范数产生的曲线。加权曲线在垂直轴周围被尖锐地“捏紧”，且`𝑤₁`的值相比`𝑤₂`越大，相应的球体就会越尖锐。[图 10.7](#Chp010_463-518_B9780443292385000160.xhtml#f0040)B展示了当“吹胀”加权`ℓ₁`球时会发生什么。它将首先接触点(0, 1)，该点即为真实解。基本上，我们所做的是“挤压”`ℓ₁`球，使其更多地与包含（稀疏）解的坐标轴对齐。就我们的例子而言，任何权重`𝑤₁ > 2`都能奏效。
