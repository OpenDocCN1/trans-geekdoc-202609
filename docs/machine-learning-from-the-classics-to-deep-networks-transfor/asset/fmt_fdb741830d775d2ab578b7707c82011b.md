$$x_{\ast} = \arg\max\limits_{x}\mu_{f_{a}\rightarrow x}(x)\mu_{f_{c}\rightarrow x}(x)$$

![Equation](images/B9780443292385000214/si376.png)

$$x[\ast] = 1$$

![Equation](images/B9780443292385000214/si377.png)

$$\max P(x, y, z, w, \phi) = 0.378 \cdot 0.48 = 0.1814$$

### 回溯

1.  **节点 `f[c]`**

    ![Equation](images/B9780443292385000214/si379.png)

    $$\max\limits_{w,\phi}f_{c}(\phi,1,w)\mu_{w\rightarrow f_{c}}(w)\mu_{\phi\rightarrow f_{c}}(\phi)$$

    ![Equation](images/B9780443292385000214/si380.png)

    发生条件为：

    $$\phi[\ast] = 0 \quad \text{and} \quad w[\ast] = 1$$

    ![Equation](images/B9780443292385000214/si381.png)

2.  **节点 `f[a]`**

    ![Equation](images/B9780443292385000214/si382.png)

    $$\max\limits_{y}f_{a}(1,y)\mu_{y\rightarrow f_{a}}(y)$$

    ![Equation](images/B9780443292385000214/si383.png)

    发生条件为：

    $$y[\ast] = 1$$

    ![Equation](images/B9780443292385000214/si384.png)

    ![Equation](images/B9780443292385000214/si386.png)
