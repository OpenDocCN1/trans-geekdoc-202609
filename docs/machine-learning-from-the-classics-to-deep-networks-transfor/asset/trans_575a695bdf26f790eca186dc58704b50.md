
这里我们利用了性质 `r(k) = r(-k)`。观察可知，若 `|a| > 1`，则 `r(0) < 0`，这没有意义。此外，`|a| < 1` 保证了特征多项式的根（`z* = -a`）的模小于 1。而且，`|a| < 1` 保证了当 `k → ∞` 时 `r(k) → 0`。这符合常识，因为相距较远的变量必定是不相关的。

[图 2.15](#Chp002_19-64_B9780443292385000081.xhtml#f0080) 展示了两个 AR(1) 过程（在过程收敛为平稳后）的时间演变及其各自的自相关序列，对应两种情况：`a = -0.9` 和 `a = -0.4`。观察可知，`a` 的模越大，实现变得越平滑，时间变化*越慢*。这是自然的，因为临近样本高度相关，因此平均而言它们倾向于具有相似的值。对于 `a` 的较小值，情况则相反。为了比较，[图 2.16](#Chp002_19-64_B9780443292385000081.xhtml#f0085)A 是 `a = 0` 的情况，对应于白噪声。[图 2.16](#Chp002_19-64_B9780443292385000081.xhtml#f0085)B 显示了对应 [图 2.15](#Chp002_19-64_B9780443292385000081.xhtml#f0080) 两种情况的功率谱密度（PSD），单位为分贝 `(10 log(S(ω)/S(0)))`。观察可知，自相关越快趋近于零，功率谱密度越分散，反之亦然。

## 2.5 信息论

本章迄今为止，我们已经了解了一些关于概率论和随机过程的基本定义和性质。同样地，我们现在将重点关注与*信息论*相关的基本定义和概念。尽管信息论最初是在通信和编码学科的背景下发展起来的，但其应用和使用现已被广泛领域所采纳，包括机器学习。信息论中的概念被用于在参数估计问题中建立用于优化的损失函数，而信息论中的概念也被用于在约束优化任务的背景下估计未知概率分布。我们将在本书后面讨论此类方法。
