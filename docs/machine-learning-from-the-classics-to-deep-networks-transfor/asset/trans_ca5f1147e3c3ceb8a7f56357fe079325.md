### 19.2.4 自编码器

*自编码器*在文献 [12,159] 中被提出作为降维方法。自编码器由两部分组成：*编码器* 和 *解码器*。编码器的输出是输入模式的降维表示，它用一个向量函数定义，

```
f : x ∈ ℝ^l ↦ h ∈ ℝ^m,  (19.6)
```

其中

```
h[i] := f[i](x) = ϕ[e](θ[i]^T x + b[i]),  i = 1, 2, ..., m,  (19.7)
```

`ϕ[e]` 为激活函数；通常取为逻辑斯蒂 S 型函数，`ϕ[e](·) = σ(·)`。换句话说，编码器是一个单隐藏层前馈神经网络。
