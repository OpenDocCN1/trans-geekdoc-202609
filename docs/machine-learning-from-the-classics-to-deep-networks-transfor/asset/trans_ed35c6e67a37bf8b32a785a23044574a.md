
对于 **x** = 0，公式 [(13.81)](#Chp013_635-716_B9780443292385000196.xhtml#deq118) 变为 *g*(0) = −*f*^(\*)(**ξ**)。这在 [图 13.10](#Chp013_635-716_B9780443292385000196.xhtml#f0060) 中有所说明。因此，*f*^(\*)(**ξ**) 对应于 **ξ**^(*T*)**x** 的图形为了与 *f*(**x**) 的图形“相切”所必须经历的位移。这一切的一个副产品对我们来说非常有用。可以证明（问题 [13.16](#Chp013_635-716_B9780443292385000196.xhtml#o0180)），如果 *f* 是凸函数，则 (*f*^(\*))^(\*) = *f*，在这种情况下我们可以写成

```
f(\mathbf{x}) = \max\limits_{\mathbf{\xi}}\left\{ \mathbf{x}^{T}\mathbf{\xi} - f^{\ast}(\mathbf{\xi}) \right\}。
```

因此，一旦计算出 *f*^(\*)，*f* 的一个下界就随时可得，即

*f*(**x**) ≥ **x**^(*T*)**ξ** − *f*^(\*)(**ξ**)，

其中 **ξ** 现在被解释为一个参数。为了进一步研究这个界，我们将公式 [(13.79)](#Chp013_635-716_B9780443292385000196.xhtml#deq115) 和 [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116) 代入公式 [(13.83)](#Chp013_635-716_B9780443292385000196.xhtml#deq120) 以得到^([^(95)](#fn95))

*f*(**x**) ≥ *f*(**x**[\*]) + (**x** − **x**[\*])^(*T*)∇*f*(**x**[\*])，

其中右边是描述在 **x**[\*] 处与 *f*(**x**) 相切的超平面的线性函数 *g*(**x**)。当 **x** = **x**[\*] 时该界变得紧致（见 [图 13.10](#Chp013_635-716_B9780443292385000196.xhtml#f0060)）。我们很快就会看到如何使这个线性函数成为非线性函数的一个界；只需变换函数的自变量即可。
