
If `x[n-1] = 0`, then `x[n]` can either stay in the same state with probability `q[e]` or increase by one with probability `p`. If `x[n-1] = N`, then `x[n]` can either stay in the same state with probability `q[e]` or decrease by one with probability `p`. Obviously,

```
2p + q = 1,  p + q[e] = 1.
```

The transition probability matrix, for the case of `N = 4`, `p = 1/4`, `q = 1/2`, and `q_e = 3/4`, is

```
P = [3/4  1/4  0    0    0
     1/4  1/2  1/4  0    0
     0    1/4  1/2  1/4  0
     0    0    1/4  1/2  1/4
     0    0    0    1/4  3/4].
```
