
![Equation](images/B9780443292385000147/si532.png)(8.119)

and setting $\epsilon = \frac{1}{\lambda}$, the recursion in Eq. [(8.119)](#Chp008_343-416_B9780443292385000147.xhtml#deq225) becomes

**x**[k] = (A + \epsilon I)^(-1)(b + \epsilon **x**[k - 1]).

![Equation](images/B9780443292385000147/si534.png)(8.120)

After some simple algebraic manipulations (Problem [8.37](#Chp008_343-416_B9780443292385000147.xhtml#o0215)), we finally obtain

**x**[k] = **x**[k - 1] + (A + \epsilon I)^(-1)(b - A **x**[k - 1]).

![Equation](images/B9780443292385000147/si535.png)(8.121)

This scheme is known from the numerical linear algebra as *iterative refinement* algorithm [58]. It is used when the matrix A is near-singular, so the regularization via \epsilon helps the inversion. Note that at each iteration, **b** - A **x**[k - 1] is the error committed by the current estimate. The algorithm belongs to a larger family of algorithms, known as stationary iterative or iterative relaxation schemes; we will meet such schemes in Chapter [10](#Chp010_463-518_B9780443292385000160.xhtml).

The interesting point here is that since the algorithm results as a special case of the proximal minimization algorithm, convergence to the solution is guaranteed even if \epsilon is not small!
