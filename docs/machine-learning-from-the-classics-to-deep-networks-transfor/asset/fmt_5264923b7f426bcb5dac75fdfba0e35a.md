
## 损失函数

$$\\mathcal{L} = \\sum\\limits\_{j = 0}^{9}\\left\\{ T\_{j}\\max\\{ 0,m^{+} - ||\\mathbf{v}\_{j}||^{2}\\} + \\lambda(1 - T\_{j})\\max\\{ 0,||\\mathbf{v}\_{j}||^{2} - m^{-}\\} \\right\\}.$$

损失函数包含两项。训练期间，如果输入数字对应第 $k$ 个胶囊，则 $T\_k = 1$，而 $T\_j = 0$（$j \\neq k$）。因此，为了使损失值最小，正确类别胶囊 $k$ 的长度将被调整为大于阈值 $m^+$（实际值设为 0.9）的值。相反，其余胶囊的长度应被“推向”小于 $m^-$（实际值设为 0.1）的长度。参数 $\\lambda$ 用于降低第二项的权重，文献 [174] 建议将其设为 1/2。损失值用于调整 $W\_{ij}$ 矩阵的值以及卷积中使用的滤波器权重。

## 迭代动态路由算法

**迭代动态路由算法**指的是耦合系数的更新。这些系数被赋予了概率解释，由以下 softmax 操作保证：

$$c\_{ij} = \\frac{\\exp(b\_{ij})}{\\sum\_{k = 0}^{9}\\exp(b\_{ik})},\\ i = 1,2,\\ldots,I,\\ j = 0,1,\\ldots,9.$$

简而言之，$c\_{ij}$ 表示第 $i$ 个前层胶囊耦合到第 $j$ 个高层输出（类别）胶囊的概率。耦合系数的计算根据 **算法 18.4** 迭代进行。
