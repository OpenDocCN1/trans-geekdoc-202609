
$$
\alpha_{\ast} = - \frac{\text{MSE}(\widehat{\theta}_{\text{MVU}})}{\text{MSE}(\widehat{\theta}_{\text{MVU}}) + \theta_{o}^{2}} = - \frac{1}{1 + \frac{\theta_{o}^{2}}{\text{MSE}(\widehat{\theta}_{\text{MVU}})}}.
$$

![Equation](images/B9780443292385000093/si149.png) (3.27)

Therefore, we have found a way to obtain the optimum estimator among those in the set $\{\widehat{\theta}[b] = (1 + \alpha)\widehat{\theta}[\text{MVU}] : \alpha \in \mathbb{R}\}$![Equation](images/B9780443292385000093/si150.png), which results in the minimum MSE. This is true, but as many nice things in life, this is not, in general, realizable. The optimal value for $\alpha$ is given in terms of the unknown $\theta_{o}$![Equation](images/B9780443292385000093/si120.png)! However, Eq. [(3.27)](#Chp003_65-117_B9780443292385000093.xhtml#deq46) is useful in a number of other ways. First, there are cases where the MSE is proportional to $\theta_{o}^{2}$![Equation](images/B9780443292385000093/si151.png); hence, this formula can be used. Also, for certain cases, it can be used to provide useful bounds [19]. Moreover, as far as we are concerned in this book, it says something very important. If we want to do better than the MVU, then, looking at the text following Eq. [(3.26)](#Chp003_65-117_B9780443292385000093.xhtml#deq45), a possible way is to *shrink* the norm of the MVU estimator. Shrinking the norm is a way of introducing bias into an estimator. We will discuss ways to achieve this in Section [3.8](#Chp003_65-117_B9780443292385000093.xhtml#s0055) and later on in Chapters [6](#Chp006_249-291_B9780443292385000123.xhtml) and [9](#Chp009_417-462_B9780443292385000159.xhtml).
