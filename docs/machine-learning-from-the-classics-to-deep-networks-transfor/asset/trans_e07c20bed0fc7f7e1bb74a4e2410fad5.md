
X = AZ, X ∈ ℝ^(l×N), Z ∈ ℝ^(K×N)

![Equation](images/B9780443292385000196/si535.png) (13.124)

其中 X = [**x**[1], …, **x**[N]], Z = [**z**[1], …, **z**[N]]。任务是在给定矩阵 X 的情况下计算 A 和 Z。通常，该问题存在无穷多解。在实践中，必须引入进一步的假设来限制可能的解集。第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章讨论了若干此类外部约束。根据施加的条件不同，该任务会被赋予不同的名称。在本小节中，我们将通过非参数贝叶斯论证来处理该任务，并将施加一个先验，它将充当额外的“某种东西”，使任务定义明确。

增加的难度在于潜变量的数量 K 并非先验已知。^([^(102)](#fn102))

由于稀疏性在我们的讨论中至关重要，我们将假设 Z 由零和一组成。在进一步讨论之前，让我们详细阐述一下零元素的含义。以 N = 5 和 K = 3 的情况为例，并令矩阵中的某些元素为零。则公式 [(13.124)](#Chp013_635-716_B9780443292385000196.xhtml#deq191) 中的矩阵分解采取以下形式

```
[x₁, x₂, …, x₅] = [a₁, a₂, a₃] [z₁₁ z₁₂ z₁₃ 0 z₁₅; z₂₁ 0 0 z₂₄ z₂₅; 0 z₃₂ z₃₃ z₃₄ 0].
```
