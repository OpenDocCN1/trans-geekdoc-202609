## 12.8 概率分布的指数族

到目前为止应该已经清楚，贝叶斯框架始于为条件分布采用一种特定的函数形式，该形式“解释”了给定参数下观测值的生成过程，同时还需要一个先验分布来描述相关参数的随机性。后者等同于对相应学习任务进行正则化，并表达了我们在接收任何观测值之前对参数值的不确定性。贝叶斯学习的目标是获得给定观测变量值条件下参数的后验分布。如果精心选择条件分布和先验分布，后验的计算可以大大简化。从*指数族*中选择这些分布，会使后验的计算变成一项相当简单的任务。指数族分布将在下一章中用到，届时将讨论近似贝叶斯推断方法。

我们将在一般框架下探讨概率分布指数族的话题。设 `x ∈ ℝ^l` 为随机向量，`θ ∈ ℝ^K` 为随机（参数）向量。如果参数化的概率密度函数（PDF）`p(x|θ)` 具有以下形式，则称其为指数形式：

```
p(x|θ) = g(θ)f(x)exp(ϕ^T(θ)u(x)),
```
(12.72)

其中

```
g(θ) = 1 / ∫ f(x)exp(ϕ^T(θ)u(x)) dx
```
(12.73)

是 PDF 的归一化常数。如果 `x` 是离散随机变量且相应函数表示概率质量函数 `P(x|θ)`，则存在类似的定义；在这种情况下，公式[(12.73)](#Chp012_583-634_B9780443292385000184.xhtml#deq97)中的积分变为求和。向量 `ϕ(θ)` 包含所谓的*自然参数*集合，而 `f`、`u` 是定义该分布的函数。从第[3.7](#Chp003_65-117_B9780443292385000093.xhtml)节的因子分解定理可以很容易地看出，`u(x)` 是参数 `θ` 的*充分统计量*。请注意，指数族的一个属性是充分统计量的数量，即 `u` 的维数，是有限的，且与观测值的数量无关。如果 `ϕ(θ) = θ`，则称该指数族处于*规范*形式。许多广泛使用的分布都属于指数族，例如正态分布、指数分布、伽马分布、卡方分布、贝塔分布、狄利克雷分布、伯努利分布、二项分布和多项分布。不属于这一族的分布示例包括边界未知的均匀分布、学生 *t* 分布、拉普拉斯分布以及大多数混合分布（例如参见文献[40,46]）。
