
# 估计相关量

我们现在转向如何获得相关量的估计。回顾一下，在实践中，我们手头拥有的只是一组训练数据，必须从中获得先验概率以及条件概率密度函数（PDF）的估计。假设我们得到一组训练点 $(y_n, \mathbf{x}_n) \in \mathcal{D} \times \mathbb{R}^l, n = 1, 2, \dots, N$，其中 $\mathcal{D}$ 是类别标签的离散集合，考虑包含 $M$ 个类别的一般任务。假设每个类别 $\omega_i, i = 1, 2, \dots, M$ 在训练集中由 $N_i$ 个点表示，且 $\sum_{i=1}^M N_i = N$。那么先验概率可以近似为

$$P(\omega_i) \approx \frac{N_i}{N}, \quad i = 1, 2, \dots, M. \tag{7.4}$$

对于条件 PDF $p(\mathbf{x}|\omega_i), i = 1, 2, \dots, M$，可以动用任何估计 PDF 的方法。例如，可以为每个条件概率假设一个已知的参数形式，并采用第 [3.10](#Chp003_65-117_B9780443292385000093.xhtml) 节讨论的最大似然（ML）方法，或第 [3.11.1](#Chp003_65-117_B9780443292385000093.xhtml) 节讨论的最大后验（MAP）估计器，利用每个类别的训练数据来获得参数估计。另一种选择是采用非参数直方图类技术，如第 [3.15](#Chp003_65-117_B9780443292385000093.xhtml) 节讨论的 Parzen 窗和 $k$ 近邻密度估计技术。也可以采用其他 PDF 估计方法，如第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章将讨论的混合建模。感兴趣的读者也可参考文献 [38, 39]。

## 贝叶斯分类器最小化误分类误差

在第 [3.4](#Chp003_65-117_B9780443292385000093.xhtml) 节中指出，设计分类器的目标是将特征向量所在的空间划分为若干区域，并将每个区域唯一地关联到某一个类别。对于二分类任务（推广到多类别很简单），设 $\mathcal{R}_1, \mathcal{R}_2$ 为 $\mathbb{R}^l$ 中的两个区域，分别决定支持类别 $\omega_1$ 和 $\omega_2$。分类错误概率由下式给出：

$$P_e = P(\mathbf{x} \in \mathcal{R}_1, \mathbf{x} \in \omega_2) + P(\mathbf{x} \in \mathcal{R}_2, \mathbf{x} \in \omega_1). \tag{7.5}$$
