
正如第 [6.2](#Chp006_249-291_B9780443292385000123.xhtml#s0015) 节所述。我们已经看到，LS 任务等价于将 `y` 正交投影到 `X` 的列向量张成的空间 `span{x₁ᶜ, …, xₗᶜ}` 上，从而使误差

```
e = y - ŷ
```

正交于 `X` 的列空间。等价地，这可以写为：

```
minimize ‖e‖², s.t. y - e ∈ ℛ(X)
```

其中 `ℛ(X)` 是 `X` 的值域空间（有关定义请参见备注 [6.1](#Chp006_249-291_B9780443292385000123.xhtml#enun0015)）。此外，一旦获得了 `θ̂_LS`，我们可以写成

```
ŷ = X θ̂_LS = y - e,
```

或者

```
[X ⋮ y - e] [θ̂_LS; -1] = 0,
```

(6.66)

其中 `[X ⋮ y - e]` 是通过向 `X` 增加一列 `y - e` 而得到的矩阵。因此，所有点 `(yₙ - eₙ, xₙ) ∈ ℝ^(l+1)`，`n = 1, 2, …, N`，都位于同一超平面上，且该超平面穿过原点，如图 [6.11](#Chp006_249-291_B9780443292385000123.xhtml#f0070) 所示。换句话说，为了将超平面拟合到数据，LS 方法对输出样本施加了一个修正 `eₙ`，`n = 1, 2, …, N`。因此，我们隐含地假设回归变量是通过精确测量获得的，并且噪声仅影响输出观测值。
