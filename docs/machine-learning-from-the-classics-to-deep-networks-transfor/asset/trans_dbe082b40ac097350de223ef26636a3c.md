
*y*[*n*] = *θ*[0] + *θ*[1]*x*[*n*] + *θ*[2]*x*[*n*]² + *θ*[3]*x*[*n*]³ + *θ*[5]*x*[*n*]⁵ + *η*[*n*], *n* = 1, 2, …, *N*，

其中 *η*[*n*] 是从均值为零、方差为 *σ*[*η*]² 的高斯分布中抽取的独立同分布（i.i.d.）噪声样本。样本 *x*[*n*] 是区间 [0, 2] 内的等距点。该任务的目标是利用公式 (12.22)，根据测量值 *x* 来预测值 *y*。用于生成数据的参数值如下：

*θ*[0] = 0.2，*θ*[1] = −1，*θ*[2] = 0.9，*θ*[3] = 0.7，*θ*[5] = −0.2。
