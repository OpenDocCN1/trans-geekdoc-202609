

### 3.10.1 线性回归：非白高斯噪声情况

考虑线性回归模型

$$y = \boldsymbol{\theta}^T \mathbf{x} + \eta.$$

我们得到 $N$ 个训练数据点 $(y[n], \mathbf{x}[n])$，$n = 1, 2, \dots, N$。相应的（未观测到的）噪声样本 $\eta[n]$，$n = 1, \dots, N$，假设服从均值为零、协方差矩阵等于 $\boldsymbol{\Sigma}_\eta$ 的联合高斯分布。也就是说，包含所有噪声样本堆叠而成的随机向量 $\boldsymbol{\eta} = [\eta[1], \dots, \eta[N]]^T$ 服从多元高斯分布
