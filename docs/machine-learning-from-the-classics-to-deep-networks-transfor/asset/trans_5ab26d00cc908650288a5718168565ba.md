

### 算法流程

**For** `n = 1, 2, 3, …` **Do**

1. **For** `i = 1, 2, …, N` **Do**
    1. 从 `q(x | x_{n-1}^(i), y_n)` 中抽取 `x_n^(i)`
    2. 
```
w_n^(i) = w_{n-1}^(i) * p(x_n^(i) | x_{n-1}^(i)) * p(y_n | x_n^(i)) / q(x_n^(i) | x_{n-1}^(i), y_n)
```
2. **End For**
3. **For** `i = 1, 2, …, N` **Do**
    1. 计算归一化权重 `W_n^(i)`。
4. **End For**
5. 计算 `N_eff`；公式 [(17.40)](#Chp017_855-884_B9780443292385000238.xhtml#deq58)。
6. **If** `N_eff ≤ N_T`；预选值 `N_T`。
