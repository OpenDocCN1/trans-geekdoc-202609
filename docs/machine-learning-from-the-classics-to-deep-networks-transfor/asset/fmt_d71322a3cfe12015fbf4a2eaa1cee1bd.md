
## 实践防御对抗样本

在构建了对抗样本并尝试理解其存在性之后，研究的下一个前沿更多地聚焦于该现象的实践层面。尽管对抗样本似乎远非输入（训练集和测试集）数据中的常见现象，但这仍是一个相当令人不安的现象。此外，它始终可以被用来**有意地**欺骗网络。为此，已经出现了许多技术，试图使网络对对抗样本具有“鲁棒性”。

在文献 [200] 中，生成了对抗样本并将其反馈到训练集中。这是一种通过数据生成进行正则化的方法。然而，在文献 [100] 中指出，对于音乐数据，该方法并未真正提升性能。

在文献 [54] 中，损失函数 `ℒ` 被适当修改为：

```
ℒ′(θ, x, y) = αℒ(θ, x, y) + (1 − α)ℒ(θ, x + Δx, y),  0 < α < 1
```

其中

```
Δx = ε sgn ( ∂/∂x ℒ(θ, x, y) ),  ε > 0
```

被证明是对抗扰动的一个方向。`ε` 是一个足够小的数字，用于控制扰动预算，`sgn(·)` 表示符号函数。在这种情况下，代价函数变为：

```
J(θ) = Σ(x,y) ℒ′(θ, x, y).
```

公式 (18.71) 右侧第二项的关键点在于将训练样本 `x` 扰动至对抗方向。这符合使训练对对抗点的存在更具鲁棒性的目标，因为训练算法变得“警觉”于对抗方向。

在文献 [135] 中，使用了一个正则化项来促进模型分布关于输入在每个输入数据点周围的平滑性。在文献 [182] 中，提出了一种鲁棒优化方法，该方法建立在极大极小公式之上，其中代价函数针对扰动的最坏情况实现进行优化。在文献 [150] 中，提出了 `distillation`（蒸馏）技术作为应对对抗样本的一种方式。蒸馏是一种训练过程，最初设计用于迁移学习背景下的深度神经网络训练（参见第 18.16 节），例如文献 [75]。在对抗训练框架中，据称蒸馏可以将导致对抗样本生成的梯度降低数个数量级。此外，蒸馏可以显著增加创建对抗样本所需修改的特征的平均最小数量。在文献 [149] 中，提出了一种用于训练网络的贝叶斯框架，与多种最先进技术相比，该框架显著提高了对对抗样本的鲁棒性。
