#### 通过线性系统的传输

信号处理和系统理论中最重要的任务之一是对*输入*时间序列（*信号*）进行*线性滤波运算*以生成另一个*输出*序列。滤波运算的框图如[图 2.13](#Chp002_19-64_B9780443292385000081.xhtml#f0070)所示。根据线性系统理论和信号处理基础，对于一类称为*线性时不变*的线性系统，输入-输出关系由输入序列与滤波器的*冲激响应*之间优雅的*卷积*给出，

![Equation](images/B9780443292385000081/fx025.jpg)(2.126)

其中 `..., w[0], w[1], w[2], ...` 是描述滤波器冲激响应的参数 [8]。如果冲激响应是有限时长的，例如 `w[0], w[1], ..., w[l-1]`，其余值为零，则卷积可以写为

```
d_n = \sum_{i = 0}^{l - 1} w_i^* u_{n - i} = \mathbf{w}^H \mathbf{u}_n
```
(2.127)

其中

```
\mathbf{w} := [w[0], w[1], ..., w[l-1]]^T
```
(2.128)

和

```
\mathbf{u}[n] := [u[n], u[n-1], ..., u[n-l+1]]^T \in \mathbb{R}^l
```
(2.129)

后者称为*输入向量*，其阶为 `l`，时刻为 `n`。值得注意的是，这是一个随机向量。然而，其元素是随机过程在*连续*时间瞬间的部分。这赋予了相应的自相关矩阵特定的性质和丰富的结构，将在第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章中进行研究和利用。事实上，这也是我们使用不同符号表示过程和一般随机向量的原因；因此，读者可以很容易地记住，在处理过程时，所涉及的随机向量的元素具有这种*额外结构*。此外，从公式 [(2.126)](#Chp002_19-64_B9780443292385000081.xhtml#deq146) 可知，如果系统的冲激响应在时间索引 `n` 为负值时为零，这保证了*因果性*。即，输出仅依赖于当前和过去时刻输入的值，而不依赖于未来的值。事实上，这也是因果性的必要条件；即，如果系统是因果的，则其冲激响应在负时间瞬间为零 [8]。
