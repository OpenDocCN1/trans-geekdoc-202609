## 转移概率矩阵的性质

转移矩阵具有特殊的结构，从而导致某些性质，这些性质将在后文中使用。

*   **矩阵 `P` 是一个*随机*矩阵。** 即，其所有元素均为非负数，且每一列的元素之和为 1，也就是说，

    $\sum\limits\_{i = 1}^{K}P\_{ij} = 1,$

    ![Equation](images/B9780443292385000202/si172.png)

    这是概率定义的直接结果。

*   **值 `λ = 1` 始终是 `P` 的一个特征值**（问题 [14.8](#Chp014_717-754_B9780443292385000202.xhtml#o0045)）。此外，不存在模大于 1 的特征值（问题 [14.9](#Chp014_717-754_B9780443292385000202.xhtml#o0050)）。

*   **对应于特征值 `λ ≠ 1` 的特征向量，其分量之和为零**（问题 [14.10](#Chp014_717-754_B9780443292385000202.xhtml#o0055)）。

*   **对应于 `λ = 1` 的左特征向量，**

    `b`[1]^(`T`)`P` = `b`[1]^(`T`),

    ![Equation](images/B9780443292385000202/si174.png)(14.38)

    其所有元素相等。通过代入 `b`[1] = [1, 1, …, 1]^(`T`) 并验证这确实是一个特征向量，即可轻松证明这一点。

*   **不变分布。** 如果一个分布在马尔可夫链的状态上满足

    `p` = `P``p`.

    ![Equation](images/B9780443292385000202/si176.png)

    则称该分布为不变分布。注意 `p` 必然是对应于特征值 `λ = 1` 的特征向量。此外，因为 `p` 由概率组成，其元素之和必须为 1。取决于 `λ = 1` 的重数，可能存在不止一个不变分布。例如，若 `P = I`，则任何概率分布都是相应马尔可夫链的不变分布。结果表明，任何具有有限状态数的马尔可夫链至少有一个不变分布。然而，如果 `P` 的元素严格为正，则存在唯一的不变分布，它与对应于最大特征值 `λ = 1` 的唯一特征向量重合，这种情况下该特征值的重数为 1。此外，对应于 `λ = 1` 的特征向量包含正元素，经过缩放后其和始终可为 1。这是著名的*佩龙-弗罗贝尼乌斯定理*的一个副产品，只要 `P` 具有严格正的元素，该定理即成立^([^(109)](#fn109))。
