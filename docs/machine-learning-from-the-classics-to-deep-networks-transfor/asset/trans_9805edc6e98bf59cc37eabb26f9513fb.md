
因此，我们的目标是在给定光谱测量值 `y` 和端元矩阵 `X` 的情况下，在非负性和稀疏性约束下估计 `θ`。显然，实现这一目标有不同的途径。因为我们目前正在探索贝叶斯世界，所以将采用贝叶斯框架。为此，将首先采用一个能表达我们对感兴趣参数先验信念的合适先验模型，然后使用变分贝叶斯方法进行贝叶斯推断，正如之前所讨论的那样。

### 13.13.1 分层贝叶斯建模

公式 [(13.143)](#Chp013_635-716_B9780443292385000196.xhtml#deq240) 中高斯噪声的存在意味着

```
p(y|θ,β) = N(y|Xθ,β^{-1}I_M) = (2π)^{-M/2}β^{M/2}exp(-β/2||y - Xθ||^2).
```

![Equation](images/B9780443292385000196/si708.png)(13.145)

我们现在将注意力转向为模型参数选择合适的先验，这些参数被视为随机变量 `θ`、`β`。作为非负噪声精度 `β` 的先验，我们采用伽马分布（第 [13.3](#Chp013_635-716_B9780443292385000196.xhtml#s0030) 节，公式 [(13.25)](#Chp013_635-716_B9780443292385000196.xhtml#deq32)），表示为

```
p(β) = Gamma(β|c,d) = d^c/Γ(c) β^{c-1}exp(-dβ),
```

![Equation](images/B9780443292385000196/si710.png)(13.146)

其中 `c` 和 `d` 是相应的参数（在实验中设为 10^{-6}）。

对于丰度向量 `θ`，我们定义了一个以共轭形式表达的两层分层先验，该先验对丰度系数施加稀疏性和非负性。受 [70] 启发，选择了一个非负截断高斯先验，即

```
p(θ|α) = N[R_+^(l)](θ|0,A^{-1}),
```

![Equation](images/B9780443292385000196/si712.png)(13.147)
