$$f(\mathbf{x}) := \frac{1}{2}\mathbf{x}^{T}Q\mathbf{x} + \mathbf{b}^{T}\mathbf{x} + c,$$

其中 `Q` 是正定矩阵。求梯度可得：

$$\nabla f(\mathbf{x}) = Q\mathbf{x} + \mathbf{b},$$

海森矩阵等于 `Q`，根据假设它是正定的，因此 `f` 是一个（严格）凸函数。

简而言之，它是函数取值小于或等于 $\xi$ 的所有点的集合。水平集的几何解释如[图 8.5](#Chp008_343-416_B9780443292385000147.xhtml#f0030)所示。可以很容易地证明（习题[8.7](#Chp008_343-416_B9780443292385000147.xhtml#o0065)），如果函数 `f` 是凸的，则对于任意 $\xi \in \mathbb{R}$，其下水平集都是凸的。反之则不成立。我们可以很容易地验证函数 $f(x) = -\exp(x)$ 不是凸函数（事实上它是凹函数），但其所有下水平集都是凸的。

## 定理 8.3

### 局部极小值点与全局极小值点

*设凸函数* $f : \mathcal{X} \mapsto \mathbb{R}$。*若点* $\mathbf{x}^{*}$ *是局部极小值点，则它也是全局极小值点，且所有极小值点的集合是凸的。此外，若函数是严格凸的，则极小值点是唯一的。*

**证明**

因为函数是凸的，我们知道 $\forall \mathbf{x} \in \mathcal{X}$，

$$f(\mathbf{x}) \geq f(\mathbf{x}^{*}) + \nabla^{T}f(\mathbf{x}^{*})(\mathbf{x} - \mathbf{x}^{*}),$$

又因为在极小值点处梯度为零，可得

$$f(\mathbf{x}) \geq f(\mathbf{x}^{*}), \tag{8.6}$$
