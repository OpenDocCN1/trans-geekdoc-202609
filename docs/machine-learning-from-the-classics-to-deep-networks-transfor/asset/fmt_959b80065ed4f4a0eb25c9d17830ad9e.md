
#### 方程 (18.62)

$$f(\mathbf{x}) = \sum_{n = 1}^{N}\theta_{n}\kappa(\mathbf{x},\mathbf{x}_{n}) + \theta_{0}.$$

这可以看作是一个具有一个隐藏层的网络，其处理节点执行核计算，输出节点执行线性组合。正如第 [11.10.4](#Chp011_519-582_B9780443292385000172.xhtml) 节所评论的，核函数 $\kappa(\mathbf{x}, \mathbf{x}_n)$ 可以被视为 $\mathbf{x}$ 与相应训练样本 $\mathbf{x}_n$ 之间相似度的度量。对于高斯核等核函数，核函数的作用具有*局部*性质，即随着 $\mathbf{x}$ 与 $\mathbf{x}_n$ 之间距离的增加，求和中 $\kappa(\mathbf{x}, \mathbf{x}_n)$ 的贡献趋于零（影响力下降的速率取决于高斯分布的方差 $\sigma^2$）。因此，如果真实的输入-输出函数依赖关系经历快速变化，则需要大量此类局部核来充分建模输入-输出关系。这是自然的，因为人们试图用局部范围的光滑基来近似快速变化的函数。第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章讨论的高斯过程也存在类似的论点。除了核方法外，其他广泛使用的学习方案也具有局部性质，例如第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章讨论的决策树。这是因为输入空间通过局部性质的规则被划分为不同区域。

相反，假设上述输入-输出依赖关系的变化不是随机的，而是存在潜在的（未知的）规律性，采用具有更紧凑表示的模型（如多层网络），人们期望能够学习这些规律性并利用它们来提高性能。正如文献 [166] 所述，利用隐藏在训练数据中的规律性有助于设计出色的未来事件预测器。感兴趣的读者可参考富有洞见的教程 [15] 进一步探讨这些问题。

#### 分布式表示

多层神经网络的一个显著特征是它们提供了机器学习中所谓的输入模式的*分布式表示*。以第 [18.3](#Chp018_885-995_B978044329238500024X.xhtml#s0020) 节讨论的神经元输出为 1 或 0 的简单情况为例。将每个节点的输出解释为一个特征，某一层中包含这些特征值的向量提供了关于输入模式的信息；这是一种分布在该层所有特征中的分布式表示。此外，这些特征*不是*互斥的。事实证明，这种分布式表示是稀疏的，因为每次只有少数神经元被激活。这与人脑中的情况一致：每一层中每次激活的神经元不到 5%，其余保持不活跃。这种分布式表示的对立面是每次只有一个神经元激活。

在具有更一般（相对于 0 和 1）激活函数的神经网络情况下，每一层神经元输出作为特征生成，这些特征被所有模式在所有类别中*共享*。例如，在学习区分“飞机”和“汽车”时，使用并共享相同的神经元。这非常合理，因为许多属性是共享且两类共有的。例如，金属结构和车轮的存在是共有的。相反，决策树（第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章）不基于分布式表示。如果输入一个“飞机”类的模式，只有相应的类别叶节点和从根到该叶节点路径上的节点被激活。分布式表示的基础在于它们构建了一个相似性空间，在该空间中语义上接近的输入模式在某些“距离”意义上保持接近。

在表示的另一极端是局部方法提供的表示，其中不同的模型附加到空间中的每个区域，参数在局部优化。然而，分布式表示比局部表示可以指数级地更紧凑。以整数集合 $\{1, 2, \dots, N\}$ 的表示为例。一种方法是使用长度为 $N$ 的向量，并为每个整数将相应位置设为 1。然而，在比特数量方面更有效的方法是采用分布式表示，即使用大小为 $\log_2 N$ 的向量，并通过将 1 和 0 定位来将每个整数编码为二的幂的和。关于学习任务中分布式表示优势的早期讨论见文献 [70]。文献 [15] 对这些问题提供了更详细的论述。
