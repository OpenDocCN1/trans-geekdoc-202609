

## 备注 13.5

1. 这是通过矩匹配实现的，新的 `q^(i+1)` 被定义为使得各充分统计量的期望与 `(1/Z_k) * f_k(θ) * q_/k^(i)(θ)` 的期望相匹配，并且假设该操作在计算上是可行的。

2. **步骤 5：** 计算 `f̂_k^(i+1)` 使得

```
f̂_k^(i+1)(θ) := K * q^(i+1)(θ) / q_/k^(i)(θ)
```
(13.107)

3. 其中比例常数的计算使得

```
∫ f̂_k^(i+1)(θ) * q_/k^(i)(θ) dθ = ∫ f_k(θ) * q_/k^(i)(θ) dθ
```
(13.108)

4. 这导致 `K = Z_k`。

然后将该过程应用于 `f̂_k+1^(i+1)` 的估计。为了收敛，必须执行多次遍历。证据可以近似为

```
p(X) ≈ ∫ ∏_j f̂_j(θ) dθ
```
(13.109)

[49] 中给出了该算法在一个易于理解的示例背景下的详细应用。
