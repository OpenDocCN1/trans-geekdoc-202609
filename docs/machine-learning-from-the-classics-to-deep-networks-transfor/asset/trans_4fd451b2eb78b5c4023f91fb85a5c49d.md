

## 7.8 分类树

分类树基于一个简单而强大的思想，是分类任务中最流行的技术之一。它们是*多阶段*系统，将模式分类到某个类别是*顺序*实现的。通过一系列测试，类别按顺序被*拒绝*，直到最终做出决策，支持剩下的那个类别。每个测试的结果决定拒绝哪些类别，其类型为*二元*的“是”或“否”，且作用于*单个*特征。我们的目标是阐述一种称为*普通二元分类树*（OBCT）的特殊树类型的主要理念。它们属于一类更通用的构建树的方法，既用于分类也用于回归，称为*分类与回归树*（CART）[2,31]。该方法的变体也已被提出[35]。

OBCT 的基本思想是将特征空间划分为（超）*矩形*；即通过与坐标轴平行的超平面对空间进行划分。这在[图 7.12](#Chp007_293-342_B9780443292385000135.xhtml#f0075)中进行了说明。通过一系列此类“问题”来执行将空间划分为（超）矩形：特征 `x[i] < a` 的值是否成立？这也称为*分裂准则*。这系列问题可以通过树结构很好地实现。[图 7.13](#Chp007_293-342_B9780443292385000135.xhtml#f0080)展示了对应[图 7.12](#Chp007_293-342_B9780443292385000135.xhtml#f0075)所示情况的树。树的每个节点对*单个*特征执行测试，如果它不是叶节点，则连接到两个*后代*节点：一个对应答案“是”，另一个对应答案“否”。

## 备注 7.5

*   如果 `J3` 与其他矩阵组合一起使用（例如用 `Σ[m]` 代替 `Σ[b]` 可能实现这种情况），则秩等于 `M - 1` 的约束被移除，可以获得更大的 `m` 值。
*   在许多实际情况下，`Σ[w]` 可能不可逆。例如，在*小样本量*问题中，特征空间的维数 `l` 可能大于训练数据的数量 `N`。此类问题可能出现在网页文档分类、基因表达谱分析和人脸识别等应用中。针对该问题有不同的解决途径；详见文献 [38] 的讨论及相关参考文献。

## Fisher 方法与降维

*   换句话说，将维度从 `l` 降至 `M - 1` 时，不会丢失信息（以 `J3` 准则衡量）。注意，在这种情况下，Fisher 方法产生 `m = M - 1` 个判别（线性）函数。这符合分类学中的一个通用结论：`M` 分类问题所需的最少判别函数数目为 `M - 1` [38]。回顾贝叶斯分类，我们需要 `M` 个函数 `P(ω[i]|x)`，`i = 1, 2, …, M`；然而，其中只有 `M - 1` 个是独立的，因为它们的总和必须为 1。因此，Fisher 方法提供了所需的最少线性判别函数数目。
*   `m < M - 1`。如果 `A` 由对应于最大的 `m` 个特征值的特征向量作为列构建，则 `J3y < J3x`。
*   然而，所得值 `J3y` 是可能的最大值。
