
$$
\nabla^{2}L(\mathbf{\theta}) = \sum\limits_{n = 1}^{N}s_{n}(1 - s_{n})\mathbf{x}_{n}\mathbf{x}_{n}^{T} = X^{T}RX,
$$

![Equation](images/B9780443292385000135/si174.png)(7.42)

where

$$R := \text{diag}\{s_{1}(1-s_{1}),\dots,s_{N}(1-s_{N})\}.$$

![Equation](images/B9780443292385000135/si175.png)(7.43)

Note that because $0 < s_{n} < 1$ (by definition of the sigmoid link function), matrix $R$ is positive definite (see Appendix A); hence, the Hessian matrix is also positive definite (Problem [7.9](#Chp007_293-342_B9780443292385000135.xhtml#o0050)). This is a necessary and sufficient condition for convexity.^([^(45)](#fn45))
