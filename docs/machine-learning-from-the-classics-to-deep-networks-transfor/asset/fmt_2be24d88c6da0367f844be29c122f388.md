
$J\_{n}(\mathbf{\theta}) = \frac{1}{2}\sum\limits\_{k = 1}^{k\_{L}}\left( {\widehat{y}}\_{nk} - y\_{nk} \right)^{2}$

where $\widehat{y}\_{nk}$, $k = 1, 2, \dots, k\_{L}$, are the estimates provided at the corresponding output nodes of the network. We will consider them as the elements of a corresponding vector, ${\widehat{\mathbf{y}}}\_{n}$.

### Computation of the gradients

Let $z\_{nj}^{(r)}$ denote the output of the linear combiner of the $j$th neuron in the $r$th layer at time instant $n$, when the pattern $\mathbf{x}\_{n}$ is applied at the input nodes (see [Fig. 18.11](#Chp018_885-995_B978044329238500024X.xhtml#f0065)). Then we can write

$z\_{nj}^{r} = \sum\limits\_{m = 1}^{k\_{r - 1}}\theta\_{jm}^{r}y\_{nm}^{r - 1} + \theta\_{j0}^{r} = \sum\limits\_{m = 0}^{k\_{r - 1}}\theta\_{jm}^{r}y\_{nm}^{r - 1} = \mathbf{\theta}\_{j}^{r^{T}}\mathbf{y}\_{n}^{r - 1}$
