
将点分成两类的每一种分组也称为（线性）*二分法*。[图 11.3](#Chp011_519-582_B9780443292385000172.xhtml#f0020) 说明了 *N* = 4 个点在二维空间中的情况。观察可能的分组有 [(ABCD)]、[A, (BCD)]、[B, (ACD)]、[C, (ABD)]、[D, (ABC)]、[(AB), (CD)] 和 [(AC), (BD)]。每个分组被计算两次，因为它可以属于 *ω*₁ 类或 *ω*₂ 类。因此，分组总数为 14，等于 𝒪(4, 2)。注意，*N* 个点分成两组的所有可能组合数为 2^*N*，在本例中为 16。未计入 𝒪(4, 2) 的分组是 [(BC), (AD)]，因为它不能被线性分离。注意，如果 *N* ≤ *l* + 1，则 𝒪(*N*, *l*) = 2^*N*。即所有可能的两类组合都是线性可分的；在二维空间中验证 *N* = 3 的情况。
