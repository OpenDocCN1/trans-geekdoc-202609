
# 贝叶斯定理在机器学习中起核心作用

贝叶斯定理在机器学习中起核心作用，它将成为开发贝叶斯技术以估计未知参数值的基础。

## 2.2.3 连续随机变量

到目前为止，我们一直关注离散随机变量。现在我们的兴趣转向将概率的概念推广到取实轴 `ℝ` 上值的随机变量。

出发点是计算随机变量 `x` 落在区间 `x₁ < x ≤ x₂` 内的概率。注意这两个事件 `x ≤ x₁` 和 `x₁ < x ≤ x₂` 是互斥的。因此，我们可以写出

`P(x ≤ x₁) + P(x₁ < x ≤ x₂) = P(x ≤ x₂).` (2.15)

我们将 `x` 的*累积分布函数*（CDF）定义为

![Equation](images/B9780443292385000081/fx005.jpg) (2.16)

那么，公式 [(2.15)](#Chp002_19-64_B9780443292385000081.xhtml#deq19) 可以写为

`P(x₁ < x ≤ x₂) = Fₓ(x₂) − Fₓ(x₁).` (2.17)

注意 `Fₓ` 是一个单调递增函数。此外，如果它是连续的，则称随机变量 `x` 为*连续*型。假设它也是可微的，我们可以将 `x` 的*概率密度函数*（PDF）定义为

![Equation](images/B9780443292385000081/fx006.jpg) (2.18)

这进而导出

`P(x₁ < x ≤ x₂) = ∫[x₁]^(x₂) pₓ(x) dx.` (2.19)

此外，

`Fₓ(x) = ∫[−∞]^(x) pₓ(z) dz.` (2.20)

利用微积分中熟悉的论证，概率密度函数可以解释为

`ΔP(x < x ≤ x + Δx) ≈ pₓ(x) Δx.` (2.21)
