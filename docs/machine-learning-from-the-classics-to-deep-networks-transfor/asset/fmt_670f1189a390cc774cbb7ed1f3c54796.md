
# Self-Attention Layer Rationale

The main rationale of the self-attention layer is to apply an attention mechanism that *relates* the different tokens/positions of the input sequence in order to produce a corresponding information-rich contextual representation. As we have seen in Section [19.3.2](#Chp019_997-1102_B9780443292385000251.xhtml#s0080), Eq. [(19.27)](#Chp019_997-1102_B9780443292385000251.xhtml#deq62), the attention coefficient that relates two entities/vectors is a function of the degree of their mutual *similarity*. There, the measure of similarity between two vectors was expressed in terms of a function of their *inner product*. Any other similarity measure can, in principle, be used. In the framework of transformers, a more elaborate similarity measuring procedure is used. To this end, for each token, **x**[*n*], *n* = 0, 1, …, *N* + 1, three auxiliary vectors are first formed.

## Query Vectors

*   **The query vectors**: These are defined by projecting the input embeddings to a new subspace, i.e.,

```
**q**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*q*), *W*^(*q*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **q**[*n*] ∈ ℝ^(*d*[*k*])
```

where the dimensionality, *d*[*k*], is a user-defined parameter.

## Key Vectors

*   **The key vectors**: These are also projections in a *d*[*k*]-dimensional subspace, i.e.,

```
**k**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*k*), *W*^(*k*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **k**[*n*] ∈ ℝ^(*d*[*k*])
```

## Value Vectors

*   **The value vectors**: These are projections in a different *d*[*v*]-dimensional subspace, i.e.,

```
**v**[*n*]^(*T*) := **x**[*n*]^(*T*) *W*^(*v*), *W*^(*v*) ∈ ℝ^(*d*[*m*] × *d*[*v*]), **v**[*n*] ∈ ℝ^(*d*[*v*])
```

where, also, *d*[*v*] is a user-defined parameter.
