

## 2. 生成输入样本作为两个过程的一部分

(a) 白噪声序列，通过 `𝒩(0, 1)` i.i.d. 生成；(b) 一个自回归 AR(1) 过程，其中 `a[1] = 0.85`，且对应的白噪声激励方差等于 1。

针对这两种输入选择，在生成的训练集 `(y[n], x[n])` 上运行 LMS 算法，`n = 0, 1, …`，以估计 `θ[o]`。使用等于 `μ = 0.01` 的步长。运行 100 次独立实验，并绘制每次迭代的平均误差（以 dB 为单位），使用 `10log10(e[n]²)`，其中 `e[n]² = (y[n] − θ[n−1]^(T)x[n])²`。

你观察到这两种情况下算法的收敛速度如何？使用不同的 AR 参数 `a[1]` 值和不同的步长值重复实验。观察学习曲线如何随不同的步长值和/或 AR 参数值而变化。同时，选择一个相对较大的步长值，使 LMS 算法发散。对获得的关于收敛速度和收敛后稳态下误差底的结果进行评论并给出理论依据。
