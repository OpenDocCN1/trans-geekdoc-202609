
历史上，设计模式识别系统的两个主要步骤是 `feature generation`（特征生成）和 `feature selection`（特征选择）阶段。选择信息丰富的特征至关重要。如果选择了“差”的特征，无论采用多么智能的分类器，性能注定会很差。特征生成/选择技术在文献[38,39]中有详细论述，感兴趣的读者可参考这些文献以获取更多信息。在此，我们仅涉及与当前线性分类器设计相关的少数概念。让我们首先量化什么是“差”特征和“优”特征。选择特征的主要目标，从而选择将要工作的特征空间，可以概括为以下方式。选择特征以创建一个特征空间，使得表示训练模式的点分布得以满足

*   **类内散度矩阵：**

    ```
    Σ_w = Σ_{k=1}^M P(ω_k) Σ_k
    ```
    (7.55)

    其中 `Σ[k]` 是 `M` 个类别中第 `k` 个类别点的协方差矩阵。简而言之，`Σ[w]` 是特定 `l` 维特征空间中数据的平均协方差矩阵。

*   **类间散度矩阵：**

    ```
    Σ_b = Σ_{k=1}^M P(ω_k) (μ_k - μ_0)(μ_k - μ_0)^T
    ```
    (7.56)

    其中 `μ[0]` 是由以下公式定义的总体均值：

    ```
    μ_0 = Σ_{k=1}^M P(ω_k) μ_k
    ```
    (7.57)

*   另一个常用的相关矩阵如下。

*   **混合散度矩阵：**

    ```
    Σ_m = Σ_w + Σ_b
    ```
    (7.58)
