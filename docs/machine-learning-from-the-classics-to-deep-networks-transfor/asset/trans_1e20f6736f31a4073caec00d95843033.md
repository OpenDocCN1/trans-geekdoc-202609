证明见习题 [13.19](#Chp013_635-716_B9780443292385000196.xhtml#o0195)。上述结果表明，从 DP 分布中抽取的样本围绕在基分布“周围”，且方差与浓度参数成反比。

**从先验分布得到后验**：我们知道每次抽取 *G* ∼ DP(*α*, *G*[0]) 都是一个分布，并用于从 Θ 中抽取样本。令 **θ**[*i*] ∈ *Θ* ∼ *G* 为一系列此类独立同分布抽取的样本。我们现在的目标是给定 *n* 个观测值 **θ**[1], …, **θ**[*n*] 的情况下，推导后验概率 *G*(*T*[*k*]), *k* = 1, 2, …, *K*。

为此，回顾 [示例 12.6](#Chp012_583-634_B9780443292385000184.xhtml) 可知，狄利克雷分布是多项分布的共轭先验，如公式 [(2.58)](#Chp002_19-64_B9780443292385000081.xhtml) 所示，即

$P(n\_{1},n\_{2},\\ldots,n\_{K}) = \\begin{pmatrix} n \\\\ {n\_{1},\\ldots,n\_{K}} \\\\ \\end{pmatrix}\\prod\\limits\_{k = 1}^{K}G{(T\_{k})}^{n\_{k}},$
