
## Nongreedy Algorithms for Alternative Formulations

All the nongreedy algorithms that have been discussed so far have been developed to solve the task defined in the formulation [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml). This is mainly because this is an easier task to solve; once `λ` has been fixed, it is an unconstrained optimization task. However, there are algorithms that have been developed to solve the alternative formulations.

### The NESTA Algorithm

The NESTA algorithm has been proposed in [12] and solves the task in its [(9.8)](#Chp009_417-462_B9780443292385000159.xhtml) formulation. Adopting this path can have an advantage because `ϵ` may be given as an estimate of the uncertainty associated with the noise, which can readily be obtained in a number of practical applications. In contrast, selecting a priori the value for `λ` is more intricate. In [28], the value `λ = σ_η√(2 ln l)`, where `σ[η]` is the noise standard deviation, is argued to have certain optimality properties; however, this argument hinges on the assumption of the orthogonality of `X`.

NESTA relies heavily on Nesterov's generic scheme [96], hence its name. The original Nesterov algorithm performs a constrained minimization of a smooth convex function `f(θ)`, i.e.,

```
min_{θ ∈ Q} f(θ),
```

where `Q` is a convex set, and in our case this is associated with the quadratic constraint in [(9.8)](#Chp009_417-462_B9780443292385000159.xhtml). The algorithm consists of three basic steps. The first one involves an auxiliary variable, and is similar to the step in Eq. [(10.3)](#Chp010_463-518_B9780443292385000160.xhtml#deq17), i.e.,

```
w^(i) = arg min_{θ ∈ Q} { (θ - θ^(i-1))^T ∂f(θ^(i-1))/∂θ + L/2 ||θ - θ^(i-1)||_2^2 },
```

where `L` is an upper bound on the Lipschitz coefficient, which the gradient of `f` has to satisfy. The difference with Eq. [(10.3)](#Chp010_463-518_B9780443292385000160.xhtml#deq17) is that the minimization is now a constrained one. However, Nesterov has also added a second step, involving another auxiliary variable, `z^(i)`, which is computed in a similar way as `w^(i)`, but in place of the square Euclidean norm it involves a proxy-function for `Q`, and the linearized term is now replaced by a weighted cumulative gradient.
