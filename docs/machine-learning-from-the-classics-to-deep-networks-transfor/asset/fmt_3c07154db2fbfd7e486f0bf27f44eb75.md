
## 11.10 Optimal margin classification: support vector machines

The optimal classifier, in the sense of minimizing the classification error, is the Bayesian classifier as discussed in Chapter [7](#Chp007_293-342_B9780443292385000135.xhtml). The method, being a member of the generative learning family, requires the knowledge of the underlying probability distributions. If these are not known, an alternative path is to resort to discriminative learning techniques and adopt a discriminant function, `f`, that realizes the corresponding classifier and try to optimize it so as to minimize the respective empirical risk, that is,

```
ξ_n = λ_n / 2,  n = 1,2,…,N.
```
![Equation](images/B9780443292385000172/si310.png)(11.54)

To obtain the Lagrange multipliers, Eqs. [(11.53)](#Chp011_519-582_B9780443292385000172.xhtml#deq132) and [(11.54)](#Chp011_519-582_B9780443292385000172.xhtml#deq133) are substituted in Eq. [(11.52)](#Chp011_519-582_B9780443292385000172.xhtml#deq131), which results in the dual formulation of the problem, that is,

```
maximize with respect to λ  Σ_{n=1}^N λ_n y_n - 1/(4C) Σ_{n=1}^N Σ_{m=1}^N λ_n λ_m κ(x_n, x_m) - 1/4 Σ_{n=1}^N λ_n^2,
```
![Equation](images/B9780443292385000172/si311.png)(11.55)

where we have replaced `x_n^T x_m` with the kernel operation according to the kernel trick. It is a matter of straightforward algebra to obtain (see [98] and Problem [11.9](#Chp011_519-582_B9780443292385000172.xhtml#o0070))

```
λ = 2C (K + C I)^(-1) y,
```
![Equation](images/B9780443292385000172/si313.png)(11.56)

which combined with Eq. [(11.53)](#Chp011_519-582_B9780443292385000172.xhtml#deq132) and involving the kernel trick, we obtain the prediction rule for the kernel ridge regression, that is,

```
ŷ(x) = y^T (K + C I)^(-1) κ(x),
```
![Equation](images/B9780443292385000172/si314.png)(11.57)

which is the same as Eq. [(11.27)](#Chp011_519-582_B9780443292385000172.xhtml#deq88); however, via this path one needs not to assume invertibility of `K`. An efficient scheme for solving the kernel ridge regression has been developed in [117,118].
