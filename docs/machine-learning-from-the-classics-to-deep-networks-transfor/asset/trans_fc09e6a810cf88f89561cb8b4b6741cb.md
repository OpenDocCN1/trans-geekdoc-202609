
对于梯度下降，`Φ[i] = I`；对于牛顿型递归，`Φ[i]` 是损失函数的逆海森矩阵（第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章）。

请注意，这些并非矩阵 `Φ` 的唯一可能选择。例如，在 Levenberg–Marquardt 方法中，采用的是方雅可比矩阵，即

```
Φ[i] = [∇J(θ^(i−1))∇^(T)J(θ^(i−1)) + λI]^(−1)
```

其中 `λ` 是正则化参数。文献 [3] 中提出了*自然梯度*，它基于由所采用的预测模型 `f_θ(x)` 所隐含的噪声分布相关联的 Fisher 信息矩阵。在这两种情况下，所涉及的矩阵在渐近意义上表现得像海森矩阵，但在初始收敛阶段可能提供更好的性能。欲进一步讨论，感兴趣的读者可参阅文献 [49,56]。

正如在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章和第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章（第 [6.7](#Chp006_249-291_B9780443292385000123.xhtml) 节）中已经提到的，简单梯度下降法（针对均方误差情况）收敛到相应最优值的速率是*线性*的，即

```
ln(1/‖θ^(i) − θ_*(N)‖) ∝ i
```

而牛顿型算法的相应速率（近似地）是二次的，即

```
ln ln(1/‖θ^(i) − θ_*(N)‖) ∝ i.
```

```
θ[n] = θ[n−1] − μ[n]Φ[n]L'(θ[n−1], y[n], x[n])
```
