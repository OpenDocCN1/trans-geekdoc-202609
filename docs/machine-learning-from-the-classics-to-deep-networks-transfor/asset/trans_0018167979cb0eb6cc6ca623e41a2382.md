

## Partial Least Squares

*Partial Least Squares* (PLS) was first proposed in [186] and has been widely applied in chemometrics, bioinformatics, food research, medicine, pharmacology, social sciences, and physiology, among many other fields.

If in Eq. [(20.39)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq53) we set

```
B = [[I, O],
     [O, I]]
```

![Equation](images/B9780443292385000263/si175.png)

and keep the matrix `C` the same as in *Canonical Correlation Analysis* (CCA), the corresponding eigenproblem is obtained. If, instead of maximizing the correlation coefficient `ρ` as in Eq. [(20.25)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq35), we maximize the covariance, i.e.,

```
cov(z[x,1], z[y,1]) = E[z[x,1] z[y,1]]
```

![Equation](images/B9780443292385000263/si176.png) (20.40)

this implies that during dimensionality reduction, we are not only interested in correlation but also seek directions that maximize the variance of both sets of variables. The optimization task for finding the first pair of axes `u[x,1]`, `u[y,1]` becomes:

![](images/B9780443292385000263/fx006.jpg)

PLS can be used for both classification and regression tasks. For example, in Chapter 6, we used *Principal Component Analysis* (PCA) for regression to reduce the spatial dimensionality and represent the least-squares solution in that low-dimensional space. However, the principal component axes are determined solely based on the input data to retain maximum variance. In contrast, PLS can treat the output observations as a second set of variables, thereby selecting axes that simultaneously maximize variance and correlation between the two data sets. This can be understood from the fact that maximizing the covariance (PLS) is equivalent to maximizing the product of the correlation coefficient (used in CCA) and the two variance terms.

### Different Methods Resulting from Changes in Matrix Structure

Changing the structure of the two matrices `C` and `B` yields different methods. For instance, if we set

```
C = Σ̂[xx]
```

![Equation](images/B9780443292385000263/si173.png)

and

```
B = I
```

![Equation](images/B9780443292385000263/si174.png)

the eigenvalue-eigenvector problem of *Principal Component Analysis* (PCA) is obtained.

Reference [189] discusses algorithmic procedures for solving the relevant equations in a numerically robust way.
