
迭代从任意初始点 $\theta^{(0)}$ 开始。如果当前迭代时算法位于点 $\theta_{\text{old}} = \theta_1$，则它将向局部最小值 $\theta_l$ 移动。这是因为 $\theta_1$ 处代价函数的导数等于 $\phi_1$ 的切线，该值为负（角度为钝角），因此更新 $\theta_{\text{new}}$ 将向右移动，朝向局部最小值 $\theta_l$。相反，如果算法从不同的点初始化，且当前位于 $\theta_{\text{old}} = \theta_2$，则更新将朝向全局最小值 $\theta_g$ 移动，因为此时导数等于 $\phi_2$ 的切线，该值为正（角度为锐角）。正如我们从第 5 章了解到的，步长 $\mu$ 的选择对算法的收敛至关重要。

在多维空间的实际问题中，局部最小值的数量可能很大，因此算法可能会收敛到一个局部最小值。然而，这不一定是坏消息。如果这个局部最小值足够深，即该点的代价函数值 $J(\theta_l)$ 不比全局最小值处达到的值 $J(\theta_g)$ 大太多，那么收敛到这样的局部最小值可能对应一个良好的解。在实践中，处理非凸代价函数时，必须小心如何初始化算法。我们稍后将讨论这个问题。此外，当参数空间维度变大时（深度网络即属于这种情况），局部最小值、全局最小值和鞍点之间的相互作用将在第 18.11.1 节中讨论。

### 18.4.1 梯度下降反向传播方案

采用可微激活函数后，我们准备好开发用于最小化代价函数的梯度下降迭代方案。我们将在一个通用框架中构建该任务。

设 $(\mathbf{y}[n], \mathbf{x}[n])$，$n = 1, 2, \dots, N$ 为训练样本集。注意我们假设有多个输出变量，组装成一个向量。我们假设网络包含 $L$ 层；$L-1$ 个隐藏层和一个输出层。每一层包含 $k_r$，$r = 1, 2, \dots, L$ 个神经元。因此，（目标/期望）输出向量为：

$$
\mathbf{y}[n] = [y_{n1}, y_{n2}, \dots, y_{n k_L}]^T \in \mathbb{R}^{k_L}, \quad n = 1, 2, \dots, N.
$$
