

# 分类

**分类** 是预测对象（称为 **模式**）所属类别的任务。假设模式仅属于若干先验已知类别中的一个且仅属于一个。每个模式由一组值唯一表示，称为 **特征**。设计分类系统的早期阶段之一是选择一组合适的特征变量。这些变量应尽可能多地“编码”类别判别信息，以便通过测量给定模式的这些值，我们能以足够高的概率预测该模式的类别。为每个问题选择合适的特征集并非易事，它构成了 **模式识别** 领域中最重要的领域之一（参见例如 [12, 37]）。

选定 `l` 个特征（随机）变量 `x[1], x[2], …, x[l]` 后，我们将它们堆叠为所谓的 **特征向量** `x ∈ ℝ^(l)` 的分量。目标是设计一个 **分类器**，例如一个函数^[8](#fn8)。

## 数学表述

为了用数学术语表述该任务，每个类别由 **类别标签** 变量 `y` 表示。对于简单的二分类任务，根据类别不同，它可以取两个值中的任意一个（例如 `1, -1` 或 `1, 0` 等）。然后，给定对应于特定模式的 `x` 值，根据以下规则预测其类别标签：

```
ŷ = ϕ(f(x))
```

其中 `ϕ(·)` 是一个非线性函数，指示 `x` 位于决策面 `f(x) = 0` 的哪一侧。例如，如果类别标签为 `±1`，则选择非线性函数为符号函数，即 `ϕ(·) = sgn(·)`。现在清楚的是，前一节所述内容可迁移至此，任务变为基于一组训练点 `(y[n], x[n]) ∈ D × ℝ^(l)`，`n = 1, 2, …, N` 来估计函数 `f(·)`，其中 `D` 表示 `y` 所在的离散集合。函数 `f(·)` 被选定为属于特定参数函数类 `ℱ`，目标再次是估计参数，使得根据预选准则，真实类别标签 `y[n]` 与预测标签 `ŷ[n]` 之间的偏差最小。那么，分类与回归任务有何不同？

## 分类与回归

上一问题的答案是：尽管它们可能有一些相似之处，但两者是不同的。注意，在分类任务中，因变量具有 **离散** 性质，这与回归中因变量位于一个区间内形成对比。这表明，通常必须采用不同的技术来优化参数。例如，分类任务中准则最明显的选择是错误概率。然而，在许多情况下，可以使用同类损失函数来处理这两个任务，正如我们在本节中将要做的那样；即使采用这种方法，尽管它们在数学形式上有相似性，但这两个任务的目标仍然不同。
