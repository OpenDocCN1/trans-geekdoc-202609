For the more general *M*-class classification task, the logistic regression is defined for *m* = 1, 2, …, *M* as

![Equation](images/B9780443292385000135/fx007.jpg) (7.47)

The previous definition is easily brought into the form of a linear model for the log ratio of the posteriors. Divide, for example, by `P(ω_M|x)` to obtain

```
ln(P(ω_m|x) / P(ω_M|x)) = (θ_m - θ_M)^T x = \hat{θ}_m^T x.
```

Let us define, for notational convenience,

```
ϕ_nm := P(ω_m|x_n),  n = 1, 2, …, N,  m = 1, 2, …, M,
```

and

```
t_m := θ_m^T x,  m = 1, 2, …, M.
```

The likelihood function is now written as

```
P(y; θ_1, …, θ_M) = ∏_{n=1}^N ∏_{m=1}^M (ϕ_nm)^{y_nm},
```
