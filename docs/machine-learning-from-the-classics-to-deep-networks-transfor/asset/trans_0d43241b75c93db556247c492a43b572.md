## 18.6 梯度消失与梯度爆炸

我们已经讨论过，试图避免在输出端涉及那些与某些损失函数结合时会导致梯度值变小的非线性函数，这一点非常重要。现在让我们看看隐藏层中发生了什么。秘密在于反向传播算法的公式 [(18.27)](#Chp018_885-995_B978044329238500024X.xhtml#deq38)。让我们更深入地研究一下。正如我们在第 [18.4.1](#Chp018_885-995_B978044329238500024X.xhtml#s0040) 节中所见，梯度计算的核心在于以下量：

```
δ_j^r := ∂J/∂z_j^r, j = 1,2,…,k_r, r = 1,2,…,L,
```

其中，为使符号简洁，已省略索引 `n`，`r` 是表示 `L` 层网络中对应层的索引，`j` 是第 `r` 层（包含 `k_r` 个神经元）中某个神经元的索引。根据定义，`z_j^(r) := θ_j^(r^T) y^(r−1)` 是第 `j` 个神经元（关联参数向量 `θ_j^(r)`）的线性输出（非线性函数 `f` 之前的输出），而 `y^(r−1)` 是第 `(r−1)` 层的输出值向量（[图 18.11](#Chp018_885-995_B978044329238500024X.xhtml#f0065)）。然后，各个 `δ` 导数的传播遵循递归规则（公式 [(18.27)](#Chp018_885-995_B978044329238500024X.xhtml#deq38)），
