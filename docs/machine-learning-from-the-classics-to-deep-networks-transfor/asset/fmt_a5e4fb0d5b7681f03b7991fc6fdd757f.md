## 11.7 Kernel ridge regression

Ridge regression was introduced in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml) and it has also been treated in more detail in Chapter [6](#Chp006_249-291_B9780443292385000123.xhtml). Here, we will state the task in a general RKHS. The path to be followed is the typical one used to extend techniques which have been developed for linear models to the more general RKHS.

We assume that the generation mechanism of the data, represented by the training set `(y[n], x[n]) ∈ ℝ × ℝ^(l)`, is modeled via a nonlinear regression task

`y[n] = g(x[n]) + η[n], n = 1, 2, …, N.`

Let us denote by `f` the estimate of the unknown `g`. Sometimes, `f` is called the *hypothesis* and the space `ℍ` in which `f` is searched is known as the *hypothesis space*. We will further assume that `f` lies in an RKHS, associated with a kernel

`κ : ℝ^(l) × ℝ^(l) ↦ ℝ.`

Motivated by the representer theorem, we adopt the following expansion:

```
f(x) = ∑_{n = 1}^{N} θ_n κ(x, x_n).
```
