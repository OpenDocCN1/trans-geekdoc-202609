
## 7.4

Show that the ML estimate of the covariance matrix of a Gaussian distribution, based on `N` i.i.d. observations, **x**[n], `n = 1, 2, …, N`, is given by

```
${\widehat{\Sigma}}_{ML} = \frac{1}{N}\sum\limits_{n = 1}^{N}(\mathbf{x}_{n} - {\widehat{\mathbf{\mu}}}_{ML}){(\mathbf{x}_{n} - {\widehat{\mathbf{\mu}}}_{ML})}^{T},$
```

where

```
${\widehat{\mathbf{\mu}}}_{ML} = \frac{1}{N}\sum\limits_{n = 1}^{N}\mathbf{x}_{n}.$
```

## 7.5

Prove that the covariance estimate

```
$\widehat{\Sigma} = \frac{1}{N - 1}\sum\limits_{k = 1}^{N}(\mathbf{x}_{k} - \widehat{\mathbf{\mu}}){(\mathbf{x}_{k} - \widehat{\mathbf{\mu}})}^{T}$
```

defines an unbiased estimator, where

```
$\widehat{\mathbf{\mu}} = \frac{1}{N}\sum\limits_{k = 1}^{N}\mathbf{x}_{k}.$
```
