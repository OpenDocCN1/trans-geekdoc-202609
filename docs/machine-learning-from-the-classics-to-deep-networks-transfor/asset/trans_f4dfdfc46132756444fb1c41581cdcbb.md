该迭代方案由一组任意值初始化，并重复执行直到满足收敛准则；`Σ[k k]` 是矩阵 `Σ` 相应的对角元素。请注意，`Σ` 和 `μ` 均依赖于 `β` 和 `α[k]` 的值。每次迭代步骤的主要复杂度源于公式 [(13.59)](#Chp013_635-716_B9780443292385000196.xhtml#deq88) 相应定义中涉及的矩阵求逆，其计算量达 `O(K³)` 次运算。此外，由于涉及矩阵求逆，必须防范因数值误差导致的近奇异情况。在实践中可能出现这种情况，因为某些 `α[k]` 的值可能变得非常大。因此，一旦出现此类值，必须采取措施移除 `Φ` 中对应的列，并将相应的 `θ[k]` 值设为零。事实上，这就是该方法强制稀疏性的方式。均值为零且方差变得极小（精度极大）的参数被设为零。这种行为在实践中已被经验性地观察到。

另一种处理该方法的途径是通过 EM 算法。这会导出一组等价的递推公式 [88]，但实践经验表明，前面给出的那组更新公式收敛得更快。

关于在分组稀疏背景下以及多测量向量（MMV）情况下（即解矩阵中每个非零行的元素在时间上相关）的 SBL 框架扩展，已在文献 [100,101] 中报道。此外，在后一篇文献中，提供了理论分析，表明 SBL 代价函数具有非常理想的性质：其全局最小值与 MMV 问题的最稀疏解相吻合。
