## 算法 17.1：重采样

### 初始化

1. 输入样本 `x[i]` 及相应权重 `W^(i)`，`i = 1, 2, …, N`。
2. `c[0] = 0`，`N^(i) = 0`，`i = 1, 2, …, N`。

### 主循环

**For** `i = 1, 2, …, N`, **Do**

1. `c[i] = c[i - 1] + W^(i)`；构建 CDF。

**End For**

### 重采样步骤

1. 从 `\mathcal{U}(0, 1/N)` 中抽取 `u^(1) ~`。
2. `i = 1`。
3. **For** `j = 1, 2, …, N`, **Do**
   1. `u^(j) = u^(1) + (j - 1)/N`。
   2. **While** `u^(j) > c[i]`
      * `i = i + 1`
   3. **End While**
   4. `\overline{x}_j = x_i`；分配样本。
