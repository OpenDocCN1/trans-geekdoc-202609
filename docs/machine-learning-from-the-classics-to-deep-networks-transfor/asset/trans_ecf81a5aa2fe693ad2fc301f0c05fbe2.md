

## 3.3 线性回归

在统计学中，*回归*一词被创造出来，用于定义这样一项任务：利用一组随机变量 `x[1]`、`x[2]`、…、`x[l]` 来对*因*随机变量 `y` 进行建模。前者被视为系统的响应（输出），由后一组（输入）随机变量激活。输入变量将表示为等价随机向量 **x** 的分量。^([⁶](#fn6))

```
y = θ[0] + θ[1]x[1] + ⋯ + θ[l]x[l] + η = θ[0] + θ^(T)x + η.
```

也就是说，该模型现在关于二维像 `ϕ(x)` 的分量 `ϕ[k](x)`、`k = 1, 2` 是线性的。事实上，这一简单技巧是本书后续将要讨论的许多非线性方法的核心。毫无疑问，该过程可推广至任意数量的函数 `ϕ[k](x)`、`k = 1, 2, …, K − 1`，除单项式外，还可使用其他类型的非线性函数，如指数函数、样条函数和小波函数。尽管输入-输出依赖建模具有非线性性质，但我们仍将此模型视为线性的，因为它保持了关于所涉及的未知参数 `θ[k]`、`k = 0, 1, …, K − 1`（共 `K` 个参数）的线性。虽然为保持讨论简洁，本章其余部分将坚持使用线性函数，但一切所述均适用于此类非线性模型，即*广义线性模型*。所需做的只是将 `x` 替换为 `ϕ(x) := [ϕ[1](x), …, ϕ[K−1](x)]^(T) ∈ ℝ^(K−1)`。

接下来，我们将给出两个例子，以演示参数建模的用法。这些例子具有普遍性，可代表一大类问题。
