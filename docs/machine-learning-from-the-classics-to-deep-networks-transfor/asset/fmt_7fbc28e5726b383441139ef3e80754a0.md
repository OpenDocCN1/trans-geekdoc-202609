
$p(\mathbf{x};\mathbf{\theta}) = C\exp\left( \sum\limits_{i \in I}\theta_{i}u_{i}(\mathbf{x}) \right) = \exp\left( \mathbf{\theta}^{T}\mathbf{u}(\mathbf{x}) - A(\mathbf{\theta}) \right),$

![Equation](images/B9780443292385000226/si166.png)

with

$A(\mathbf{\theta}) = -\ln C = \ln \int \exp(\mathbf{\theta}^{(T)}\mathbf{u}(\mathbf{x})) \, d\mathbf{x},$

![Equation](images/B9780443292385000226/si167.png)

where the integral becomes summation for discrete variables; $A(\mathbf{\theta})$ is a convex function and it is known as the *log-partition* or *cumulant generating function* (Problem [16.14](#Chp016_805-853_B9780443292385000226.xhtml#o0110), [75,77]). It turns out that the conjugate function of $A(\mathbf{\theta})$, denoted as $A^{*}(\mathbf{\mu})$, is the *negative entropy* function of $p(\mathbf{x}; \mathbf{\theta}(\mathbf{\mu}))$, where $\mathbf{\theta}(\mathbf{\mu})$ is the value of $\mathbf{\theta}$ where the maximum (in the definition of the conjugate function) occurs given the value of $\mathbf{\mu}$; we say that $\mathbf{\theta}(\mathbf{\mu})$ and $\mathbf{\mu}$ are dually coupled (Problem [16.15](#Chp016_805-853_B9780443292385000226.xhtml#o0115)). Moreover,

$\mathbb{E}[\mathbf{u}(\mathbf{x})] = \mathbf{\mu},$

![Equation](images/B9780443292385000226/si172.png)

where the expectation is with respect to $p(\mathbf{x}; \mathbf{\theta}(\mathbf{\mu}))$. This is an interesting interpretation of $\mathbf{\mu}$ as a mean parameter vector; recall from Section [12.8.1](#Chp012_583-634_B9780443292385000184.xhtml) that these mean parameters define the respective exponential distribution. $A(\mathbf{\theta}) = \max\limits_{\mathbf{\mu} \in \mathcal{M}}\left( \mathbf{\theta}^{T}\mathbf{\mu} - A^{*}(\mathbf{\mu}) \right),$
