
为了更正式地总结全连接网络中发生的操作类型，让我们关注多层神经网络的第 *r* 层，并假设它包含 *k*[*r*] 个神经元。该层的输入向量由前一层节点的输出组成，记为 **y**^(*r* − 1)。令 **θ**[*j*]^(*r*) 为与第 *r* 层第 *j* 个神经元相关的突触权重向量（包含偏置项），其中 *j* = 1, 2, …, *k*[*r*](另见 [图 18.11](#Chp018_885-995_B978044329238500024X.xhtml#f0065)，第 [18.4](#Chp018_885-995_B978044329238500024X.xhtml#s0030) 节)。其维度为 *k*[*r* − 1] + 1，其中 *k*[*r* − 1] 是前一层（即第 *r* − 1 层）神经元的数量，加 1 则对应偏置项。然后，在非线性变换之前执行的操作是内积：

```
*z*[*j*]^(*r*) = **θ**[*j*]^(*r**T*)**y**^(*r* − 1), *j* = 1, 2, …, *k*[*r*].
```

将所有输出值收集到一个向量中，**z**^(*r*) = \[*z*[1]^(*r*), *z*[2]^(*r*), …, *z*[*k*[*r*]]^(*r*)\]^(*T*)，并将所有突触向量作为行依次堆叠在一个矩阵 Θ 中，我们可以整体地写为：

```
**z**^(*r*) = *Θ***y**^(*r* − 1), where *Θ* :  = \[**θ**[1]^(*r*),**θ**[2]^(*r*),…,**θ**[*k*[*r*]]^(*r*)\]^(*T*).
```

第 *r* 个隐藏层的输出向量，在将每个 *z*[*i*]^(*r*) 通过非线性函数 *f* 处理后，最终由下式给出：

```
$\\mathbf{y}^{r} = \\begin{bmatrix} 1 \\\\ {f\\left( \\mathbf{z}^{r} \\right)} \\\\ \\end{bmatrix},$
```
