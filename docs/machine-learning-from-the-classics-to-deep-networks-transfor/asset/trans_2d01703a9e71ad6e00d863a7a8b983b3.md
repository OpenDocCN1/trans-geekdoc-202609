
公式 [(12.16)](#Chp012_583-634_B9780443292385000184.xhtml#deq19) 中的后验 PDF 概括了在获得观测值 `y` 后我们关于 `θ` 的知识。因此，我们对 `θ` 的不确定性得到了降低，这也是公式 [(12.16)](#Chp012_583-634_B9780443292385000184.xhtml#deq19) 与公式 [(12.8)](#Chp012_583-634_B9780443292385000184.xhtml#deq11) 中先验 PDF 不同的主要原因；后者仅代表我们的初始猜测。公式 [(12.17)](#Chp012_583-634_B9780443292385000184.xhtml#deq20) 中的协方差矩阵提供了关于我们对 `θ` 不确定性的信息。如果公式 [(12.16)](#Chp012_583-634_B9780443292385000184.xhtml#deq19) 中的高斯分布在其均值 `μ[θ|y]` 周围非常宽阔，则表明尽管接收了观测值，但关于 `θ` 仍存在很大的不确定性。这可能是由于 (a) 问题的性质，例如高噪声方差，这由 `Σ[η]` 传达；(b) 观测值的数量 `N` 可能不足；和/或 (c) 建模不准确，这由公式 [(12.17)](#Chp012_583-634_B9780443292385000184.xhtml#deq20) 中的 `Φ` 传达。如果后验 PDF 在其均值周围呈尖峰状，则情况相反。

正如我们在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中已经陈述的，贝叶斯哲学提供了直接推断输出变量的方法，在许多应用中，输出变量是关注的量；给定输入向量，任务是预测输出。在这种情况下，估计未知 `θ` 的值只是达到目的的手段。为了直接构建预测任务而不涉及 `θ`，必须对 `θ` 的贡献进行积分。在已知后验 `p(θ|y)` 的情况下，给定一个新的输入向量 `x`，对于公式 [(12.1)](#Chp012_583-634_B9780443292385000184.xhtml#deq2) 中的回归模型，给定观测值集合的输出变量 y 的条件 PDF 可写为

```
p(y|x, y) = ∫ p(y|x, θ) p(θ|y) dθ.
```

注意，我们使用了 `p(y|x, y, θ) = p(y|x, θ)`，因为对应于新样本 `x` 的 y，在给定 `θ` 的值条件下，与训练集 `X` 相关的观测变量 `y` 是条件独立的。正如已经陈述的，严格来说，后验本应表示为 `p(θ|y; X)` 以表明其对输入训练样本的依赖。然而，为了避免符号繁杂，已省略了对 `X` 的依赖。
