
并且，前向预测的最优均方误差 `J(a[m]) := α[m]^(f)` 等于后向预测的最优均方误差，即

`J(a[m]) = α[m]^(f) = α[m]^(b) = J(b[m])`。

![Equation](images/B978044329238500010X/si301.png)

[图 4.16](#Chp004_119-175_B978044329238500010X.xhtml#f0085) 描绘了这两个预测任务。换句话说，最优前向预测器是后向预测器的共轭反序，因此

```
a_m := [a_m(0); ...; a_m(m-1)] = J_m b_m^* := [b_m^*(m-1); ...; b_m^*(0)].
```

![Equation](images/B978044329238500010X/si302.png)

![图 4.16 后向预测器的冲激响应是前向预测器冲激响应的共轭反序。](images/B978044329238500010X/gr016.jpg)

[图 4.16](#Chp004_119-175_B978044329238500010X.xhtml#cf0865) 后向预测器的冲激响应是前向预测器冲激响应的共轭反序。

这一性质归因于所涉及过程的平稳性。因为统计特性仅取决于时间瞬间的差值，前向和后向预测并无太大区别；在两种情况下，给定一组样本 `u[n-m+1], ..., u[n]`，我们预测未来的*一个*样本（前向预测中的 `u[n+1]`）或过去的*一个*样本（后向预测中的 `u[n-m]`）。
