
𝔼\[*P*[*n*]\] = 𝔼\[*Φ*[*n*]^(−1)\],

where

`Φ_n = λβ^(n + 1)I + Σ_(i=0)^n β^(n-i) x_i x_i^T`

and

`𝔼[Φ_n] = λβ^(n + 1)I + (1 - β^(n + 1))/(1 - β) Σ_x`.

Assuming `β ≈ 1`, the variance at the steady state of `Φ[n]` can be considered small and we can adopt the following approximation:

`𝔼[P_n] ≈ [𝔼[Φ_n]]^(-1) = [β^(n + 1)λI + (1 - β^(n + 1))/(1 - β) Σ_x]^(-1)`.
