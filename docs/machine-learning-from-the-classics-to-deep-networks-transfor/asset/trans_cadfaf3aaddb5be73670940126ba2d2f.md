
# 高斯混合建模

高斯混合建模是常用的聚类算法之一。其主要假设是：属于同一簇的点服从具有未知均值和协方差矩阵的同一高斯分布（这是此处定义相似性的方式）。每个混合成分定义一个不同的簇。因此，目标是对可用数据点运行 EM 算法，以便在收敛后提供后验概率 `P(k|x[n])`，其中 `k = 1, 2, …, K`，`n = 1, 2, …, N`，每个 `k` 对应一个簇。然后，根据以下规则将每个点分配给簇 `k`：

```
assign x_n to cluster k = argmax_i P(i|x_n), i = 1,2,...,K.
```

用于聚类的 EM 算法可被视为一种更原始方案的改进版本，该方案称为 *k-means*（K 均值）或 *isodata* 算法。在 EM 算法中，每个点 `x[n]` 相对于每个簇 `k` 的后验概率是递归计算的。此外，与簇 `k` 相关联的点的均值 `μ[k]` 计算为*所有*训练点的加权平均值（公式 12.60）。相比之下，在 *k-means* 算法中，每次迭代时后验概率在 `{1, 0}` 中取二进制值；对每个点 `x[n]`，计算其到所有当前可用均值估计的欧氏距离，并根据以下规则估计后验概率：

```
P(k|x_n) = { 1, if ||x_n - μ_k||^2 < ||x_n - μ_j||^2, j ≠ k,
           { 0, otherwise.
```

*k-means* 算法不涉及协方差矩阵。尽管它很简单，但毫不夸张地说，它是最著名的聚类算法，多年来已提出许多理论论文和改进版本（例如参见 [41]）。鉴于其普及度，我们将在 [算法 12.1](#Chp012_583-634_B9780443292385000184.xhtml#enun0045) 中给出其描述。
