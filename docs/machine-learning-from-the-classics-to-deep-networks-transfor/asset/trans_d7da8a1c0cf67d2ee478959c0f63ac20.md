基于这一原理，已提出了多种基本坐标下降法的变体。*循环坐标下降法*（CCD）最简单的形式是指每个迭代周期对一个坐标进行*循环*更新；即在第 *i* 次迭代中求解以下最小化问题：

```
θ_k^(i) := arg min_θ J(θ_1^(i), ..., θ_{k-1}^(i), θ, θ_{k+1}^(i-1), ..., θ_l^(i-1)).
```

换言之，除 `θ[k]` 外的所有分量均视为常数；那些分量 `θ[j], j < k` 固定为其更新值 `θ[j]^(i), j = 1, 2, …, k−1`，其余分量 `θ[j], j = k+1, …, l` 固定为上一轮迭代的可用估计值 `θ[j]^(i−1)`。此技术的优点在于可获得极小值点的简单闭式解。此类技术在稀疏学习模型（第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章）的背景下重焕生机 [18,67]。CCD 的收敛性问题已在 [36,62] 中探讨。针对最小二乘（LS）任务的 CCD 算法也已在 [66] 及其参考文献中研究。除了基本的 CCD 方案外，还有其他变体可用，它们采用不同的策略来选择每次更新的方向，以改善收敛性，范围从随机选择到坐标系变换，后者称为*自适应坐标下降*方案 [35]。
