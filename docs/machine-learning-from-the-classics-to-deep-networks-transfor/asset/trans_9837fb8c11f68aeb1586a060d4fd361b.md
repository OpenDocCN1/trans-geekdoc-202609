

## 图 3.10

![Figure 3.10 In the Bayesian inference approach, note that as the number of observations increases, our uncertainty about the true value of the unknown parameter is reduced and the mean of the posterior PDF tends to the true value and the variance tends to zero.](images/B9780443292385000093/gr010.jpg)

**图 3.10** 在贝叶斯推断方法中，请注意，随着观测数量的增加，我们对未知参数真值的不确定性降低，后验概率密度函数（PDF）的均值趋向于真值，方差趋向于零。

应该指出，在这个示例中，最大似然（ML）估计和最小二乘（LS）估计变得相同，即

$$\widehat{\theta} = \frac{1}{N}\sum\limits_{n = 1}^{N}y_{n} = {\overline{y}}_{N}.$$

![Equation](images/B9780443292385000093/si362.png)

如果我们将 `\sigma_0^2` 设得非常大，公式 [(3.69)](#Chp003_65-117_B9780443292385000093.xhtml#deq120) 中的均值也将如此，这种情况可能发生在我们对初始估计 `\theta_0` 没有信心，并给 `\sigma_0^2` 赋予一个非常大的值时。实际上，这等同于不使用任何先验信息。

现在让我们研究一下，如果我们关于 `\theta_0` 的先验知识以约束的形式“嵌入”到最小二乘准则中会发生什么。这可以通过修改公式 [(3.40)](#Chp003_65-117_B9780443292385000093.xhtml#deq73) 中的约束来实现，使得

$$(\theta - \theta_0)^2 \le \rho,$$

![Equation](images/B9780443292385000093/si364.png) (3.71)

这导致以下拉格朗日函数的等价最小化：

$$\text{minimize}\quad L(\theta,\lambda) = \sum\limits_{n = 1}^{N}{(y_n - \theta)}^{2} + \lambda\left( {(\theta - \theta_0)}^{2} - \rho \right).$$

![Equation](images/B9780443292385000093/si365.png) (3.72)

对 `\theta` 求导并令其等于零，我们得到

$$\widehat{\theta} = \frac{N{\overline{y}}_{N} + \lambda\theta_0}{N + \lambda},$$

![Equation](images/B9780443292385000093/si366.png)

当 `\lambda = \sigma_\eta^2/\sigma_0^2` 时，这变得与公式 [(3.69)](#Chp003_65-117_B9780443292385000093.xhtml#deq120) 相同。世界真小！之所以发生这种情况，仅仅是因为我们对条件概率密度函数和先验概率密度函数都使用了高斯分布。对于不同形式的概率密度函数，情况将不再如此。然而，这个例子表明先验知识与约束之间存在着紧密的联系。它们都试图施加先验信息。每种方法以其独特的方式，都有各自的优缺点。在第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章和第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章中，我们将对贝叶斯推断任务进行更详尽的阐述，届时我们将看到，正则化的本质——一种对抗过拟合的手段——正是贝叶斯方法的核心所在。
