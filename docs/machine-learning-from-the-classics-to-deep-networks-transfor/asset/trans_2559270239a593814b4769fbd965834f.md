请注意，随着涉及变量数量的增加，因子可能取值的数量会呈爆炸式增长。

**最大乘积算法的应用**：选择节点 `x` 作为根节点。然后节点 `z`、`ϕ` 和 `w` 就变成了叶子节点。

![Equation](images/B9780443292385000214/si353.png)

### 初始化

```
μ[z → f[b]](z) = 1,  μ[ϕ → f[c]](ϕ) = 1,  μ[w → f[c]](w) = 1.
```

![Equation](images/B9780443292385000214/si354.png)

### 开始传递消息

1.  **`f[b] → y`**：

    ```
    μ_{f_b→y}(y) = max_z f_b(y,z) μ_{z→f_b}(z),
    ```

    ![Equation](images/B9780443292385000214/si355.png)
    ![Equation](images/B9780443292385000214/si356.png)

    或者

    ```
    μ[f[b] → y](1) = 0.9,  μ[f[b] → y](0) = 0.7,
    ```

    ![Equation](images/B9780443292385000214/si357.png)

    其中第一个出现在 `z = 1` ![Equation](images/B9780443292385000214/si358.png) 处，第二个也出现在 `z = 1` ![Equation](images/B9780443292385000214/si358.png) 处。
