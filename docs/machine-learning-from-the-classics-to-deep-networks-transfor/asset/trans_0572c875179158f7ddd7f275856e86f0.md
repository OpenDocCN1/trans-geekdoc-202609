
# M类问题泛化

之前针对二分类任务所述内容可推广至更一般的*M*类问题。与类别*ω*[*i*]，*ω*[*j*]相关的两个相邻区域ℛ[*i*]，ℛ[*j*]的分离超曲面遵循与之前相同的论证。例如，假设所有协方差矩阵均相同，则区域通过超平面进行划分，如[图 7.6](#Chp007_293-342_B9780443292385000135.xhtml#f0040)所示。注意，判决线（实红线）平分连接三个类别均值的线段（虚线）。此外，每个区域ℛ[*i*]，*i* = 1, 2, …, *M*均为凸集（问题[7.2](#Chp007_293-342_B9780443292385000135.xhtml#o0015)）；换言之，连接ℛ[*i*]内任意两点的线段上的所有点也位于ℛ[*i*]内。

Note that each region is associated with one class and it is convex.](images/B9780443292385000135/gr006.jpg)

[图 7.6](#Chp007_293-342_B9780443292385000135.xhtml#cf0275) 当数据在所有类别中均服从高斯分布且共享相同的协方差矩阵时，特征空间通过超平面进行划分，形成多面体区域。注意每个区域对应一个类别且为凸集。

有两种特殊情况尤为重要，它们能得出简单的分类规则。该规则将针对一般*M*类问题进行表述。

## 最小距离分类器

存在两种特殊情况，在这两种情况下，最优贝叶斯分类器的计算变得非常简单，且具有浓厚的几何特征。

### 最小欧氏距离分类器

在以下假设下：(a) 每个类别中的数据服从高斯分布，即公式[(7.16)](#Chp007_293-342_B9780443292385000135.xhtml#deq29)；(b) 类别等概率；(c) 所有类别具有形式为*Σ* = *σ*²*I*的共同协方差矩阵（各个特征相互独立且具有共同方差），贝叶斯分类规则等价于

```
Assign x to class ω_i: i = argmin_j (x - μ_j)^T (x - μ_j), j = 1,2,... M.
```

*   这是在采用上述假设下贝叶斯规则的直接推论。换句话说，计算**x**到所有类别均值的欧氏距离，并将其分配给使该距离最小的类别。

*   对于二分类情况，该分类规则对应于[图 7.5](#Chp007_293-342_B9780443292385000135.xhtml#f0035)中的实黑线。确实，回顾几何基础知识，位于平分线段**μ**[1] − **μ**[2]的超平面左侧的任意点，在欧氏距离意义上都更靠近**μ**[1]而非**μ**[2]。对于位于超平面右侧的任意点，情况则相反。
