
**b**[1]^(*T*)*P* = **b**[1]^(*T*)

回顾 *P* 的性质（公式 [(14.38)](#Chp014_717-754_B9780443292385000202.xhtml#deq66) 及其后的注释），**b**[1]^(*T*) = [1, 1, …, 1]（在比例常数 *c* 内）。因此，

*P*[∞] = [**a**[1], …, **a**[1]]，

由公式 [(14.43)](#Chp014_717-754_B9780443292385000202.xhtml#deq74) 可知，因为 **p**[0] 的各分量之和为 1，我们最终得到

**p**[∞] = **a**[1]。

也就是说，极限分布等于（缩放后）*P* 对应于 *λ*[1] = 1 的唯一特征向量；此外，这与 **p**[0] 的值无关。换句话说，极限分布是 *P* 的不变分布，即

*P***p** = **p**。（14.45）

注意，收敛速率由 |*λ*[2]| 的大小控制。其他更具理论深度的收敛结果和界限可参见例如 [24,39,40]。

## 备注 14.2

*   不用说，并非所有马尔可夫链都是遍历的。例如，如果转移矩阵的特征值 *λ*[1] = 1 的重数大于 1，则极限分布取决于 **p**[0] 中初始选择的值。另一方面，如果转移矩阵有多个模等于 1 的特征值（例如 *λ*[1] = 1，*λ*[2] = −1），则同样不存在极限分布，而是表现出*周期性*极限环（例如 [32]）。

*   **构建马尔可夫链**。在实践中，可以使用一组更简单的转移矩阵 *B*[1], *B*[2], …, *B*[*M*] 来构建遍历链的转移概率矩阵，这些矩阵被称为*基础转移*矩阵。它们每一个可能都不是遍历的，但要求接受期望分布作为其不变分布。然后转移矩阵构建为

```
P = \sum\limits_{m = 1}^{M}\alpha_{m}B_{m},\quad\alpha_{m} > 0,\ \sum\limits_{m = 1}^{M}\alpha_{m} = 1.
```
