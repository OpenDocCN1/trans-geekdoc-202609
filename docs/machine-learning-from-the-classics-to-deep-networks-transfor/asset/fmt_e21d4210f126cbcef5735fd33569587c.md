Note that we have used **μ**[*n*]^((*i*)) in place of **x**[*n*] in *p*(**y**[*n*]|**x**[*n*]), because **x**[*n*] is still to be drawn. The estimate **μ**[*n*]^((*i*)) is chosen in order to be easily computed and at the same time to be a good representative of **x**[*n*]. Typically, **μ**[*n*]^((*i*)) can be the mean, the mode, a draw, or another value associated with the distribution *p*(**x**[*n*]|**x**[*n* − 1]^((*i*))); for example, **μ**[*n*]^((*i*)) ∼ *p*(**x**[*n*]|**x**[*n* − 1]^((*i*))). Also, if the state equation is **x**[*n*] = **f**(**x**[*n* − 1]) + **η**[*n*], a good choice would be **μ**[*n*]^((*i*)) = **f**(**x**[*n* − 1]^((*i*))).
