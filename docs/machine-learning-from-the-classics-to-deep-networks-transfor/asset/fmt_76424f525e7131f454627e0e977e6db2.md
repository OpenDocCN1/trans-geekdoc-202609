Observe that `ln p^(j + 1) > ln p^(j)`, where we have used the notation `p^(j) = p(X; ξ^(j))` and `p[·|·]^(j) := p(X^(l), θ|X; ξ^(j))`.

If there are more than two factors in `q(X^(l), θ)`, as in Eq. [(13.4)](#Chp013_635-716_B9780443292385000196.xhtml#deq5), then there are more than two substeps in step 1, and each time we estimate one of the factors by averaging `ln p(X, X^(l), θ; ξ)` with respect to the rest. Let `q` be factorized in `M` factors,

```
q(X^(l)) = q_1(X_1^(l))…q_M(X_M^(l))
```

### Remarks 13.1

*   Note that `q(X^(l), θ)` is an estimate of the posterior `p(X^(l), θ|X)` and each one of the factors is the respective posterior estimate given the observations `X`, for example, `q_θ(θ) ≈ p(θ|X)`.
