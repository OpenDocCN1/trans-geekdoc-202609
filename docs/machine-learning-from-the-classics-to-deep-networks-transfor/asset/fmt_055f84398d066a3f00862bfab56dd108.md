
## Theorem 5.2

Consider a network consisting of $K$ nodes, each one of them having access to a state vector $\mathbf{x}_k$. Consider the recursion

![Equation](images/B9780443292385000111/fx020.jpg)

with

$$\boldsymbol{\theta}_k^{(0)} = \mathbf{x}_k, \quad k = 1, 2, \dots, K.$$

![Equation](images/B9780443292385000111/si587.png)

Define $\mathbf{A} \in \mathbb{R}^{K \times K}$ to be the matrix with entries

$$[\mathbf{A}]_{mk} = a_{mk}, \quad m, k = 1, 2, \dots, K,$$

![Equation](images/B9780443292385000111/si589.png)

where $a_{mk} \ge 0$, $a_{mk} = 0$ if $m \notin \mathcal{N}_k$.

![Equation](images/B9780443292385000111/si590.png)

If $\mathbf{A}$ is a consensus matrix, then

$$\boldsymbol{\theta}_k^{(i)} \longrightarrow \frac{1}{K}\sum_{k=1}^{K} \mathbf{x}_k.$$

![Equation](images/B9780443292385000111/si591.png)

The opposite is also true. If convergence is *always* guaranteed, then $\mathbf{A}$ is a consensus matrix.

In other words, this theorem states that updating each node by convexly combining, with appropriate weights, the current estimates in its neighborhood, the network converges to the average value in a consensus rationale (Problem [5.16](#Chp005_177-248_B9780443292385000111.xhtml#o0085)).
