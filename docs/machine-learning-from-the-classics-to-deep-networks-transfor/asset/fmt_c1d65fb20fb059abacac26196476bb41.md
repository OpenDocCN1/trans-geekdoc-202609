
The extrapolation parameter can now be chosen in the interval `(0, 2*M_n)` in order for convergence to be guaranteed. For the case of Eq. [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74):

```
M_n = \sum_{k = n - q + 1}^{n} \frac{\omega_k \| P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|^2}{\| \sum_{k = n - q + 1}^{n} \omega_k P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|^2}.
```

Note that this interval differs from that reported in the case of a finite number of sets in Eq. [(8.27)](#Chp008_343-416_B9780443292385000147.xhtml#deq57). For the first iteration steps associated with Eq. [(8.38)](#Chp008_343-416_B9780443292385000147.xhtml#deq73), the summations in the above formula start from `k = 1` instead of `k = n - q + 1`.

Recall that `P_{S_{\epsilon,k}}` is the projection operation given in Eqs. [(8.34)](#Chp008_343-416_B9780443292385000147.xhtml#deq67)–[(8.35)](#Chp008_343-416_B9780443292385000147.xhtml#deq68). Note that this is a generic scheme and can be applied with different property sets. All that is needed is to change the projection operator. For example, if classification is considered, all we have to do is to replace `S_{\epsilon,n}` by the halfspace `H_n^+`, defined by the pair `(y_n, \mathbf{x}_n) \in \{-1, 1\} \times \mathbb{R}^{(l + 1)}`, as explained in Section [8.6.2](#Chp008_343-416_B9780443292385000147.xhtml#s0060), and use the projection from Eq. [(8.13)](#Chp008_343-416_B9780443292385000147.xhtml#deq28) (see [78,79]). At this point, it must be emphasized that the original APSM form (e.g., [103,104]) is more general and can cover a wide range of convex sets and functions.

[Fig. 8.23](#Chp008_343-416_B9780443292385000147.xhtml#f0125) illustrates geometrically the APSM algorithm. We have assumed that the number of hyperslabs that are considered for projection at each time instant is `q = 2`. Each iteration comprises:

*   `q` projections, which can be carried out in parallel,
*   their convex combination, and
*   the update step.
