
我们使用 `n[k]` 代替 `x[k]`，以符合动态规划（DPs）中使用的更标准的符号。回想一下，`n[k]` 是在 `n` 次连续实验后，与概率 `P = G(T[k])` 相关联的第 `k` 个变量出现的次数。在我们的设定中，`n[k]` 是前面定义的集合 `I[k]` 的基数，即

```
n[k] = #{i: θ[i] ∈ T[k]}.
```

换句话说，`n[k]` 是落在 `T[k]` 中的来自 Θ 的抽样数量。

在观察到 `θ[1], …, θ[n]` 后，我们看到它们等价于特定的出现次数 `n[1], …, n[K]`。因此，考虑到共轭对的性质，正如在 [示例 12.6](#Chp012_583-634_B9780443292385000184.xhtml) 背景下的公式 [(12.77)](#Chp012_583-634_B9780443292385000184.xhtml) 所表达的，可以很容易地看出

```
(G(T[1]), …, G(T[K]) | θ[1], …, θ[n]) = Dir(αG[0](T[1]) + n[1], …, αG[0](T[K]) + n[K]).
```
