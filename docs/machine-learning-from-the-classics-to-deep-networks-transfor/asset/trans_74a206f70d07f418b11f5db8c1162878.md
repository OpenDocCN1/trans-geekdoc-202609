这一基本模型已在计算机视觉和图像处理中得到应用，用于图像去噪、图像分割和场景分析等任务。让我们以二值化图像为例，令 `x[i]` 表示无噪声的像素值（±1）。令 `y[i]` 为观测到的含噪像素，其值已被噪声破坏并发生了极性翻转；请参阅 **Fig. 15.16** 了解相应的图。任务是获取无噪声的像素值。可以将 **Eq. (15.23)** 中的模型改写以适应该任务的需求，并重写为 [5,21]

```
P(x|y) = (1/Z) exp( Σ_i ( α Σ_{j > i} x_i x_j + β x_i y_i ) )
```

其中我们仅使用了两个参数 `α` 和 `β`。此外，求和 `Σ_{j > i}` 仅涉及*相邻*像素。现在的目标变为通过最大化条件（基于观测值的）概率来估计像素值 `x[i]`。采用该模型的理由基于以下两个事实：(a) 在足够低的噪声水平下，大多数像素将具有与相应观测值相同的极性；乘积项 `x[i]y[i]` 的存在鼓励了这一点，相同的符号有助于获得更高的概率值；(b) 相邻像素被鼓励具有相同的极性，因为我们知道真实世界的图像倾向于平滑，除了靠近图像边缘的点。有时，如果我们想惩罚两种极性中的任意一种，也会出现一项 `c x[i]`，其中 `c` 为适当选择的值。稍后本章将讨论的 max-product 或 max-sum 算法，是最大化 **Eq. (15.24)** 中给出的联合概率的可能算法替代方案。然而，这些并非执行优化任务的唯一算法可能性。已经开发并研究了许多处理 MRF 推理的替代方案。其中一些是次优的，但它们具有计算效率。关于在图像处理中使用 MRF 的一些经典参考文献见 [7–9,47]。如果将基本 Ising 模型写为

```
P(x) = (1/Z) exp( - Σ_i ( Σ_{j > i} f_{ij}(x_i x_j) + f_i(x_i) ) )
```

则会产生许多基本 Ising 模型的变体。
