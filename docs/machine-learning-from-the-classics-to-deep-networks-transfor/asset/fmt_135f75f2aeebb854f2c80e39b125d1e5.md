
The BN in [Fig. 15.5](#Chp015_755-803_B9780443292385000214.xhtml#f0030)A complies with our common sense reasoning that `x₁` (disease) causes `x₂` and `x₃` (tests). However, this is not possible to deduce by *simply* looking at the available probabilities. This is because the probability laws are *symmetric*. Even if `x₁` is the cause, we can still compute `P(x₁|x₂)` once `P(x₁, x₂, x₃)` and `P(x₂)` are available, that is,

```
P(x₁|x₂) = P(x₁,x₂)/P(x₂) = ∑_{x₃}P(x₁,x₂,x₃)/P(x₂).
```
