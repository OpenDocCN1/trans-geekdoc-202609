

### 4.9.2 约束线性估计：波束形成情况

我们已经在 [4.9.1](#Chp004_119-175_B978044329238500010X.xhtml#s0110) 节中处理过一个约束线性估计任务，旨在获得固定值参数向量的无偏估计量。在本节中，我们将看到那里开发的过程很容易应用于未知参数向量需要满足某些线性约束的情况。

我们将在*波束形成*的背景下演示这种约束任务。[图 4.19](#Chp004_119-175_B978044329238500010X.xhtml#f0100) 说明了波束形成任务的基本框图。波束形成器包含一组天线元件。我们考虑天线元件沿直线均匀间隔排列的情况。目标是对各个天线元件接收到的信号进行线性组合，以便：

*   将阵列的主波束指向空间中的特定方向，以及
*   最优地降低噪声。

第一个目标给设计者施加了一个约束，这将保证阵列在特定期望方向上具有高增益；对于第二个目标，我们将采用 MSE（均方误差）准则。

[图 4.19](#Chp004_119-175_B978044329238500010X.xhtml#cf1140) 波束形成器的任务是获得权重 `w[0]`、…、`w[l-1]` 的估计值，以最小化噪声的影响，同时施加一个约束：在无噪声情况下，从期望角度 `ϕ` 入射到阵列的信号保持不受影响。

更正式地说，假设发射机足够远，以保证阵列“看到”的波前是平面的。设 `s(t)` 为在载波频率 `ω[c]` 下发射的信息随机过程。则调制信号为

```
r(t) = s(t) e^(j ω[c] t)
```

如果 `Δx` 是阵列相邻元件之间的距离，则在时刻 `t[0]` 到达第一个元件的波前将以以下延迟到达第 `i` 个元件：

```
Δt_i = t_i - t_0 = i (Δx cos ϕ) / c,  i = 0, 1, ..., l - 1
```

其中 `c` 是传播速度，`ϕ` 是阵列与波前传播方向形成的夹角，`l` 是阵列元件的数量。从基础电磁学课程我们知道

```
c = (ω[c] λ) / (2π)
```
