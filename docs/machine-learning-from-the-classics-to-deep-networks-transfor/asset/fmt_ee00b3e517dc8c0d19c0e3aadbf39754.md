
where $\sum_{j = 1}^{J}P_{j} = 1$, $\Lambda[j] = \text{diag}\{b[j[1]],\dots,b[j[m]]\}$, $b[j[i]] \in \{0, 1\}, i = 1, 2, \dots, m$. The expansion in Eq. [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) for fixed $J$ and preselected $\Lambda[j]$, for the $j$th factor, has been known for some time; in this context, learning of the unknown parameters is achieved in the Bayesian framework, by imposing appropriate priors and mobilizing techniques such as the variational EM (e.g., [79]), EM [175], and maximum likelihood [180]. In a more recent treatment of the problem, the dimensionality of each $\Lambda[j], j = 1, 2, \dots, J$, as well as the number of factors, $J$, can be learned by the learning scheme. To this end, *nonparametric priors* are mobilized (see, for example, [40,47,94] and Section [13.11](#Chp013_635-716_B9780443292385000196.xhtml)). The model parameters are then computed via Gibbs sampling (Chapter [14](#Chp014_717-754_B9780443292385000202.xhtml)) or variational Bayesian techniques. Note that in general, different factors may turn out to have different dimensionality.

For *nonlinear manifold learning*, the geometric interpretation of Eq. [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148) is illustrated in [Fig. 20.16](#Chp020_1103-1179_B9780443292385000263.xhtml#f0105). The number $J$ is the number of flat ellipsoids used to cover the manifold, $\boldsymbol{\mu}[j]$ are the sampled points on the manifold, the columns $A[j]\Lambda[j]$ (approximately) span the local $k$-dimensional tangent subspace, the noise variance $\beta^{-1}$ depends on the manifold curvature, and the weights $P[j]$ reflect the respective density of the points across the manifold. The method has also been used for matrix completion (see also Section [20.10.1](#Chp020_1103-1179_B9780443292385000263.xhtml#s0180)) via a low-rank matrix approximation of the involved matrices [40].

Once the model has been learned, using Bayesian inference on a set of training data $\boldsymbol{x}[n], n = 1, 2, \dots, N$, it can subsequently be used for compressed sensing, that is, to be able to obtain any $\boldsymbol{x}$, which belongs in the ambient space $\mathbb{R}^{(l)}$ but "lives" in the learned $k$-dimensional manifold, modeled by Eq. [(20.97)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq148), using $K \ll l$ measurements.
