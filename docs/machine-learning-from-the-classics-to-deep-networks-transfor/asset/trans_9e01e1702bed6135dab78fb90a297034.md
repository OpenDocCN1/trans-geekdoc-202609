### 19.3.7 编码器：添加与归一化层 I

构成多头矩阵（[图 19.10](#Chp019_997-1102_B9780443292385000251.xhtml#f0055)）的输出向量 `z[n]`，`n` = 0, 1, …, `N` + 1，被作为输入提供给上一层，该层称为“添加与归一化”层。这是编码器块中两个结构相似的层中的第一个。“归一化”项表示归一化操作。“添加”项代表什么？在文献 [189] 中，以及在大多数后续实现中，采用了残差网络的原理，请参见[图 18.33 和 18.34](#Chp018_885-995_B978044329238500024X.xhtml)。因此，在此思路下，“添加与归一化”层接受向量之和作为输入，

```
${\\widehat{\\mathbf{t}}}\_{n}: = \\mathbf{x}\_{n} + \\mathbf{z}\_{n},\\ n = 0,1,\\ldots,N + 1.$
```

随后，计算生成向量所有维度上的均值和标准差，即，

```
${\\widehat{\\mu}}\_{n} = \\frac{1}{d\_{m}}\\sum\\limits\_{i = 1}^{d\_{m}}{\\widehat{t}}\_{ni},\\ \\ {\\widehat{\\sigma}}\_{n} = \\sqrt{\\frac{1}{d\_{m}}\\sum\\limits\_{i = 1}^{d\_{m}}{({\\widehat{t}}\_{ni} - {\\widehat{\\mu}}\_{n})}^{2}}.$
```(19.42)
