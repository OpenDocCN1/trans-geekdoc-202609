
通过贝叶斯基本原理，这一老问题在 20 世纪 90 年代末获得了新的启示 [154,175,176]；该任务针对特殊情况 $\Sigma[\epsilon] = \sigma^2 I$ 进行了处理，并被命名为*概率 PCA* (PPCA)。潜在变量 `z` 配备了高斯先验，

$p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|0, I)$，

这与早先的假设 $\mathbb{E}[\mathbf{z}\mathbf{z}^T] = I$ 一致，条件 PDF 选为

$p(\mathbf{x}|\mathbf{z}) = \mathcal{N}(\mathbf{x}|A\mathbf{z}, \sigma^2 I)$，

为简单起见，我们假设 $\boldsymbol{\mu} = 0$（否则均值将为 $A\mathbf{z} + \boldsymbol{\mu}$）。我们现在已经非常熟悉写出

$p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}_{z|x}, \Sigma_{z|x})$， (20.84)

和

$p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|0, \Sigma_x)$， (20.85)

其中（参见第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章公式 [(12.17)](#Chp012_583-634_B9780443292385000184.xhtml)、[(12.10)](#Chp012_583-634_B9780443292385000184.xhtml) 和 [(12.15)](#Chp012_583-634_B9780443292385000184.xhtml)）

$$
\Sigma_{z|x} = \left( I + \frac{1}{\sigma^{2}}A^{T}A \right)^{-1},
$$ (20.86)

$$
\mu_{z|x} = \frac{1}{\sigma^{2}}\Sigma_{z|x}A^{T}\mathbf{x},
$$ (20.87)

$\Sigma_x = \sigma^2 I + A A^T$。 (20.88)
