

# 示例 6.1

本示例的目的是演示 `RLS`、`NLMS` 和 `APA` 算法在收敛速度方面的比较性能，这些算法已在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中讨论。为此，我们根据回归模型生成数据：

*y*[*n*] = **θ**[*o*]^(*T*)**x**[*n*] + *η*[*n*]

其中 **θ**[*o*] ∈ ℝ^(200)。其元素根据标准高斯分布随机生成。噪声样本通过零均值、方差等于 *σ*[*η*]² = 0.01 的高斯分布独立同分布（i.i.d.）生成。输入向量的元素也通过标准高斯分布 i.i.d. 生成。使用生成的样本 (*y*[*n*], **x**[*n*])，*n* = 0, 1, …，作为上述三种算法的训练序列，获得了 [图 6.8](#Chp006_249-291_B9780443292385000123.xhtml#f0055) 的收敛曲线。曲线显示了以时间索引 *n* 为函数的平方误差（dB 单位，即 10log[10](*e*[*n*]²)），平均值取自 100 次不同的实验实现。所用算法的参数如下：

(a) 对于 `NLMS`，使用 *μ* = 1.2 和 *δ* = 0.001；
(b) 对于 `APA`，使用 *μ* = 0.2、*δ* = 0.001 和 *q* = 30；
(c) 对于 `RLS`，使用 *β* = 1 和 *λ* = 0.1。

`NLMS` 算法和 `APA` 的参数选择使得两种算法收敛到相同的误差底。`APA` 相对于 `NLMS` 在收敛速度方面的性能改进显而易见。然而，与 `RLS` 相比，这两种算法均表现不足。请注意，`RLS` 收敛到更低的误差底，因为未使用遗忘因子。为了保持一致性，本应在 `RLS` 中使用 *β* < 1 的遗忘因子，以使该算法稳定在与其他两种算法相同的误差底；这将对收敛速度产生有益影响。然而，选择 *β* = 1 表明 `RLS` 即使收敛到更低的误差底，也能实现非常快的收敛。另一方面，这种改进的性能是以大幅更高的复杂度为代价获得的。如果输入向量是随机过程的一部分，并且可以利用特殊的时移结构（如第 [6.10](#Chp006_249-291_B9780443292385000123.xhtml#s0105) 节所述），则设计者可以使用较低复杂度的版本。另一个包含另一族在线算法的比较性能示例将在第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章中给出。

![图 6.8 NLMS、APA 和 RLS 的 MSE 曲线随迭代次数变化。RLS 收敛更快且误差底更低。](images/B9780443292385000123/gr008.jpg)

[图 6.8](#Chp006_249-291_B9780443292385000123.xhtml#cf0640) `NLMS`、`APA` 和 `RLS` 的 MSE 曲线随迭代次数变化。`RLS` 收敛更快且误差底更低。

然而，必须强调的是，这种显著优势（在 `RLS` 类和 `LMS` 类方案之间）从初始条件到稳态的收敛速度，在跟踪性能方面可能不成立，当算法必须跟踪时变环境时。下文将演示这一点。
