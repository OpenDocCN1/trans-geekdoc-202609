
## 算法步骤

1. **For** `i = 1, 2, …, N`，**Do**
    1. Draw `x_n^(i) ~ q(x | x_{n-1}^(i), y_n)`
    2. `w_n^(i) = w_{n-1}^(i) * p(x_n^(i) | x_{n-1}^(i)) * p(y_n | x_n^(i)) / q(x_n^(i) | x_{n-1}^(i), y_n)`；参考公式 [(17.33)](#Chp017_855-884_B9780443292385000238.xhtml#deq44)、[(17.34)](#Chp017_855-884_B9780443292385000238.xhtml#deq46) 和 [(17.37)](#Chp017_855-884_B9780443292385000238.xhtml#deq51)。
2. **End For**
3. **For** `i = 1, 2, …, N`，**Do**
    1. 计算归一化权重 `W_n^(i)`
4. **End For**
5. **End For**

注意，如果处理器具备并行处理能力，则这 `N` 条粒子流的生成可以**并发**进行。

第 `i` 条流生成的粒子 `x_n^(i)`，`n = 1, 2, …`，代表了状态空间中的一条**路径/轨迹**。一旦粒子采样完成且归一化权重计算完毕，我们即可获得估计值。
