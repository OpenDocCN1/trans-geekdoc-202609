
[图 10.3](#Chp010_463-518_B9780443292385000160.xhtml#f0020) 说明了实践中预期会产生的曲线类型。垂直轴是目标 `k` 稀疏向量精确恢复的概率，水平轴显示比率 `k/N`，对于给定的观测数 `N` 和环境空间维度 `l`。显示了三条曲线。红色曲线对应同一算法，针对两个不同的维度 `l` 值，灰色曲线对应另一种算法。预期以下实验设置会产生此形状的曲线。假设我们得到一个稀疏向量 `θ[o]`，在 `l` 维空间中具有 `k` 个非零分量。使用感知矩阵 `X`，我们生成 `N` 个样本/观测值 `y = Xθ[o]`。实验重复 `M` 次，每次使用不同的感知矩阵实现和不同的 `k` 稀疏向量。对于每个实例，运行算法以恢复目标稀疏向量。这并不总是可能的。我们统计成功恢复的次数 `m`，并计算相应的成功恢复百分比（概率）`m/M`，绘制在[图 10.3](#Chp010_463-518_B9780443292385000160.xhtml#f0020)的垂直轴上。对于不同的 `k` 值重复该过程，`1 ≤ k ≤ N`。现在出现许多问题：(a) 如何选择感知矩阵集合，(b) 如何选择稀疏向量集合？存在不同场景，下面描述一些典型示例。

1.  **1.** `N × l` 感知矩阵 `X` 由以下方式形成：

    1.  **(a)** 不同的独立同分布实现，元素取自高斯分布 `𝒩(0, 1/N)`，
    2.  **(b)** 不同的独立同分布实现，取自 `ℝ^N` 中单位球上的均匀分布，也称为均匀球面集合，
    3.  **(c)** 不同的独立同分布实现，元素取自伯努利型分布，
    4.  **(d)** 部分傅里叶矩阵的不同独立同分布实现，每次使用不同的 `N` 行集合。

2.  **2.** `k` 稀疏目标向量 `θ[o]` 通过以概率 `p = k/l` 随机选择（至多）`k` 个非零元素的位置来形成，并根据统计分布（如高斯、均匀、双指数、柯西）填充非零元素的值。

图 10.3 对于任何算法，100% 成功区域与完全失败区域之间的过渡都非常陡峭。对于红色曲线对应的算法，这种过渡发生在更高的稀疏度值处，从这个角度来看，它比与灰色曲线相关的算法更好。此外，给定一种算法，维度越高，这种过渡发生的稀疏度水平越高，正如两条红色曲线所示。

其他场景也是可能的。一些作者将所有非零值设为 1 [16]，或设为 ±1，随机性施加在符号的选择上。必须强调的是，算法的性能在不同实验场景下可能有显著差异，这可能表明算法的稳定性。在实践中，用户可能对更能代表可用数据的特定场景感兴趣。

观察[图 10.3](#Chp010_463-518_B9780443292385000160.xhtml#f0020)，可以得出以下结论。在所有曲线中，都存在从 100% 成功到 0% 成功的两个水平之间的陡峭过渡。此外，维度越高，过渡越陡峭。这在理论上也已在 [40] 中得到证明。对于红色曲线对应的算法，这种过渡发生在比产生灰色曲线的算法更高的 `k` 值处。假设“红色”算法的计算复杂度可由特定应用的可用资源承担，这似乎是两种算法中更明智的选择。然而，如果资源有限，妥协是不可避免的。

另一种“审视”并展示算法性能的方法，关于其对可成功恢复的稀疏度水平值范围的鲁棒性，是通过*相变曲线*。为此，定义：

*   `α := N/l`，这是问题不确定性的归一化度量，
*   `β := k/N`，这是稀疏度的归一化度量。
