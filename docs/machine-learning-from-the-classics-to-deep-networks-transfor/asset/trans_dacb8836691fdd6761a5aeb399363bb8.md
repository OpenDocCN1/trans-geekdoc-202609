
**θ**[*n*] = (*β*^(−1)*P*[*n*−1] − *β*^(−1)**k**[*n*]**x**[*n*]^(*T*)*P*[*n*−1])*β***p**[*n*−1] + *P*[*n*]**x**[*n*]*y*[*n*] = **θ**[*n*−1] − **k**[*n*]**x**[*n*]^(*T*)**θ**[*n*−1] + **k**[*n*]*y*[*n*],

![Equation](images/B9780443292385000123/si187.png)

最后，

**θ**[*n*] = **θ**[*n*−1] + **k**[*n*]*e*[*n*],

![Equation](images/B9780443292385000123/si188.png)(6.47)

其中

*e*[*n*] := *y*[*n*] − **θ**[*n*−1]^(*T*)**x**[*n*].

![Equation](images/B9780443292385000123/si189.png)(6.48)

推导出的算法总结在[算法 6.1](#Chp006_249-291_B9780443292385000123.xhtml#enun0020)中。

请注意，参数向量的基本递归更新遵循的原理与第[5](#Chp005_177-248_B9780443292385000111.xhtml)章讨论的 LMS 和梯度下降方案相同。时刻 *n* 的参数更新估计值 **θ**[*n*] 等于前一时刻 *n*−1 的估计值，加上一个与误差 *e*[*n*] 成正比的修正项。事实上，这就是我们将在本书中遇到的所有时域递归算法（包括用于非常“流行”的神经网络情况的算法）所遵循的*通用方案*。不同算法之间的主要区别在于如何计算误差的乘法因子。在 LMS 情况下，该因子等于 *μ***x**[*n*]。对于 RLS 情况，该因子是 **k**[*n*]。正如我们即将看到的，RLS 算法与梯度下降优化算法族的一种替代方法——即牛顿代价函数迭代优化——密切相关。
