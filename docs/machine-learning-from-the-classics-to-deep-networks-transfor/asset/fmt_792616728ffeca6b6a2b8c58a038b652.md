
$1 = \left\langle \mathbf{u}_{k},\mathbf{u}_{k} \right\rangle = \left\langle \sum\limits_{i = 1}^{N}a_{ki}\mathbf{\phi}(\mathbf{x}_{i}),\sum\limits_{j = 1}^{N}a_{kj}\mathbf{\phi}(\mathbf{x}_{j}) \right\rangle = \sum\limits_{i = 1}^{N}\sum\limits_{j = 1}^{N}a_{ki}a_{kj}\mathcal{K}(i,j) = \mathbf{a}_{k}^{T}\mathcal{K}\mathbf{a}_{k} = N\lambda_{k}\mathbf{a}_{k}^{T}\mathbf{a}_{k},\quad k = 1,2,\ldots,p.$

We are now ready to summarize the basic steps for performing a kernel PCA; that is, to compute the corresponding latent variables (kernel principal components). Given $\mathbf{x}[n] \in \mathbb{R}^{(l)},\ n = 1,2,\ldots,N$ and a kernel function $\kappa(\cdot,\cdot)$:

*   Compute the $N \times N$ kernel matrix, with elements $\mathcal{K}(i,j) = \kappa(\mathbf{x}_{i},\mathbf{x}_{j})$.
*   Compute the $m$ dominant eigenvalues/eigenvectors $\lambda_{k},\ \mathbf{a}_{k},\ k = 1,2,\ldots,m$, of $\mathcal{K}$ (Eq. [(20.102)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq156)).
*   Perform the required normalization (Eq. [(20.105)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq159)).
