$J\_1$ 准则最容易理解。为简化论述，让我们专注于涉及三个类别的二维（两个特征，$x\_1$, $x\_2$）情况。回顾第二章公式 [(2.31)](#Chp002_19-64_B9780443292385000081.xhtml) 中随机向量 $\mathbf{x}$ 协方差矩阵的定义，主对角线上的元素是相应随机变量的方差。因此，对于每个类别 $k = 1, 2, 3$，相应协方差矩阵的迹将是两个特征各自方差之和，即

$\text{trace}\{\Sigma[k]\} = \sigma\_{k1}^2 + \sigma\_{k2}^2.$

因此，$\Sigma\_w$ 的迹是所有三个类别中两个特征总方差的平均值，

$\text{trace}\{\Sigma\_w\} = \sum\limits\_{k = 1}^{3}P(\omega\_k)\left( \sigma\_{k1}^{2} + \sigma\_{k2}^{2} \right): = s\_w.$
