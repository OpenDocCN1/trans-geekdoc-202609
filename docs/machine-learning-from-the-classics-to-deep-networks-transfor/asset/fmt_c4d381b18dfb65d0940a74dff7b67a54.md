
$$
\mathbf{\theta}_{n} = P_{B\left[ 0,\frac{1}{\sqrt{\lambda}}\right]}\left( \left( 1 - \mu_{n}\lambda \right)\mathbf{\theta}_{n - 1} + \mu_{n}y_{n}\mathbf{x}_{n}\chi_{( - \infty,0]}\left( y_{n}\mathbf{\theta}_{n - 1}^{T}\mathbf{x}_{n} - 1 \right) \right),
$$

where $P_{B\left[ 0,\frac{1}{\sqrt{\lambda}}\right]}$ is the projection on the respective $\ell_2$ ball given in Eq. (8.14). In Eq. (8.75), note that the effect of the regularization is to smooth out the contribution of $\mathbf{\theta}[n-1]$. A variant of the algorithm for a fixed number of points, $N$, suggests to average out a number of $m$ subgradient values in an index set, $A[n] \subseteq \{1, 2, \dots, N\}$, such that $k \in A[n]$ if $y[k]\mathbf{\theta}[n-1]^{(T)}\mathbf{x}[k] < 1$. Different scenarios for the choice of the $m$ indices can be employed, with the random one being a possibility. The scheme is summarized in Algorithm 8.4.
