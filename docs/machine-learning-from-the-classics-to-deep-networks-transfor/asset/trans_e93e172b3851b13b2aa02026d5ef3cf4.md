

## 3.6 克拉美-罗下界

在前几节中，我们了解了如何提高 MVU 估计量的性能，前提是该估计量存在且已知。然而，如何判断一个已获得的无偏估计量是否也是最小方差的？本节的目标是引入一种准则，以提供此类信息。

*克拉美-罗下界* [9,31] 是一个优雅的定理，也是统计学中最著名的技术之一。它为*任意*无偏估计量的方差提供了一个下界。这非常重要，因为 (a) 它提供了一种手段来断言某无偏估计量是否具有最小方差，在这种情况下，这当然与公式 [(3.22)](#Chp003_65-117_B9780443292385000093.xhtml#deq37) 中相应的 MSE 重合；(b) 如果不是这种情况，它可以用来指示某无偏估计量的性能距离最优性能有多远；最后 (c) 它为设计者提供了一个工具，以了解无偏估计量所能达到的最佳可能性能。由于我们此处的主要目的是关注该方法的洞察力和物理解释，我们将处理未知参数为实数的简单情况。涉及向量的定理一般形式见附录 B。

我们正在寻找一个无偏估计量方差的界，其随机性源于训练数据的随机性，当我们从一组数据切换到另一组数据时。因此，该界涉及数据的联合 PDF，并以未知参数 `θ` 为参数，这并不令人惊讶。令 `𝒳 = {x[1], x[2], …, x[N]}` 表示 `N` 个观测值的集合，对应于一个随机向量^([^(10)](#fn10))。
