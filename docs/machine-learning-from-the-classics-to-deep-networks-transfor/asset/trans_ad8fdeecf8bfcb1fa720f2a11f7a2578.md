

## 卡尔曼滤波器的变体与扩展

### 基本方案的变体
除了前面推导的基本方案外，还有许多变体。虽然理论上它们都是等价的，但它们的实际实现可能会导致不同的性能。请注意，`P[n|n]` 是作为两个正定矩阵之差计算的；由于数值误差，这可能导致 `P[n|n]` 不是正定的。这会导致算法发散。一种流行的替代方案是所谓的*信息滤波*方案，它传播逆状态误差协方差矩阵，即 `P[n|n]^(−1)` 和 `P[n|n−1]^(−1)` [20]。相反，[算法 4.2](#Chp004_119-175_B978044329238500010X.xhtml#enun0065) 中的方案被称为*协方差*卡尔曼算法（问题 [4.24](#Chp004_119-175_B978044329238500010X.xhtml#o0125)）。

### 数值稳定性
为了解决数值稳定性问题，一系列算法传播 `P[n|n]`（或 `P[n|n]^(−1)`）的因子，这些因子源自相应的乔莱斯基分解 [5,40]。

### 替代推导：正交性原理
有不同的方法可以得到卡尔曼滤波递推公式。一种替代推导基于应用于与观测序列相关的所谓*创新过程*的正交性原理，使得

```
ε(n) = y_n - ŷ_{n|1:n-1}
```

其中 `ŷ_{n|1:n-1}` 是基于过去观测历史的预测 [17]。在第 [17](#Chp017_855-884_B9780443292385000238.xhtml) 章中，我们将把卡尔曼递推公式重新推导一遍，将其视为一个贝叶斯网络。

### 与最优 MSE 线性滤波的联系
卡尔曼滤波是最优 MSE 线性滤波的推广。可以证明，当涉及的过程是平稳时，卡尔曼滤波器在其稳态下收敛到我们熟悉的正规方程 [31]。

### 扩展卡尔曼滤波器
*扩展卡尔曼滤波器*。在公式 (4.112) 和 (4.113) 中，状态方程和输出方程都对状态向量 `x[n]` 有线性依赖。在更一般的表述中，卡尔曼滤波可以表述为

```
x[n] = f[n](x[n-1]) + η[n]
y[n] = h[n](x[n]) + v[n]
```
