
那么解就是三次样条；即一个分段三次函数，其节点为点 `x[n]`，`n = 1, 2, …, N`，并且它在二阶上连续可微。`λ` 的选择控制了逼近函数的平滑度；其值越大，极小化解就越平滑。

另一方面，如果 `f` 被约束位于 RKHS 中，且极小化任务如公式 [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64) 所示，那么得到的函数形式如公式 [(11.17)](#Chp011_519-582_B9780443292385000172.xhtml#deq65) 所示，即在每个输入训练点处放置一个核函数。必须指出的是，现在得到的这种参数形式并非我们最初的意图。它作为理论的副产品出现了。然而，应当强调的是，与参数方法相反，现在待估计的参数数量不是固定的，而是取决于训练点的数量。回顾一下，这是一个重要的区别，并且在参数方法于第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中被引入和定义时已被仔细指出。

## 11.7 核岭回归

岭回归在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中已被引入，并在第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章中得到更详细的阐述。在这里，我们将在一般 RKHS 中陈述该任务。所遵循的路径是将为线性模型开发的技术推广到更一般 RKHS 的典型途径。

我们假设由训练集 `(y[n], x[n]) ∈ ℝ × ℝ^(l)` 表示的数据生成机制，是通过非线性回归任务建模的：

`y[n] = g(x[n]) + η[n], n = 1, 2, …, N.`

让我们用 `f` 表示未知 `g` 的估计量。有时，`f` 被称为*假设*，而搜索 `f` 的空间 `ℍ` 称为*假设空间*。我们将进一步假设 `f` 位于一个与核相关联的 RKHS 中：

`κ : ℝ^(l) × ℝ^(l) ↦ ℝ.`

受表达式定理的启发，我们采用以下展开：

```
f(x) = ∑_{n = 1}^{N} θ_n κ(x, x_n).
```
