

### 多项分布的统计特性

𝔼[**x**] = *n***P**, *σ*[*x*[*k*]]² = *n**P*[*k*](1 − *P*[*k*]), *k* = 1, 2, …, *K*, cov(*x*[*i*], *x*[*j*]) = −*n**P*[*i*]*P*[*j*], *i* ≠ *j*.

多项分布的特例，即仅进行一次实验（*n* = 1）的情况，称为*类别*分布。后者可视为伯努利分布的推广。

#### 均匀分布

若随机变量 x 在区间 [*a*, *b*] 内服从*均匀*分布，记作 *x* ∼ 𝒰(*a*, *b*)，其中 *a* > −∞ 且 *b* < +∞，则有

```
f(x) = 1/(b-a) for a ≤ x ≤ b, 0 otherwise
```
(2.60)
