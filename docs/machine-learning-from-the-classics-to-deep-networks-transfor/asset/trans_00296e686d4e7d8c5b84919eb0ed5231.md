
其中 $\mu_B$ 是一个界参数，为简化起见，我们假设 $l_1 = l_2 = l$。实际上，$\mu_B$ 是矩阵 $U$ 连贯性的度量（$V$ 同理）([162](#fn162))。

```
\mu(U) ≔ \frac{l}{r}\max\limits_{1 \leq i \leq l}\left\| P_{U}\mathbf{e}_{i} \right\|^{2},
```
(20.122)

其中 $P_U$ 定义了到子空间 $U$ 的正交投影，$\mathbf{e}_i$ 是规范基的第 $i$ 个向量。注意，当 $U$ 由 SVD 得出时，则 $\|P_U\mathbf{e}_i\|^2 = \|U^T\mathbf{e}_i\|^2$。本质上，连贯性是一个指数，用于量化奇异向量与标准基 $\mathbf{e}_i$ ($i = 1, 2, \dots, l$) 的相关程度。$\mu_B$ 越小，奇异向量越不可能是“尖峰状”的，相应的矩阵就越适合精确补全。确实，为简化起见，假设为方阵 $M$，即 $l_1 = l_2 = l$，如果奇异向量中*任意一个*是稀疏的，仅有一个非零分量，那么考虑到 $\mathbf{u}_i^T\mathbf{u}_i = \mathbf{v}_i^T\mathbf{v}_i = 1$，该值的大小将等于 1，且界参数将取其可能的最大值，即 $\mu_B = \frac{l}{r}$。另一方面，$\mu_B$ 可能取得的最小值是 1，这发生在*所有*奇异向量的分量取相同值（在大小上）时。注意，在这种情况下，由于归一化，该公共分量值的大小为 $\frac{1}{\sqrt{l}}$。更复杂的非连贯性性质 [33,151] 和强非连贯性性质 [35] 能得出更紧的矩阵连贯性界。在所有情况下，界参数越大，所需的已知条目数就越多，以保证唯一性。在第 [20.10.3](#Chp020_1103-1179_B9780443292385000263.xhtml#s0190) 节中，将结合实际应用讨论唯一性的各个方面。
