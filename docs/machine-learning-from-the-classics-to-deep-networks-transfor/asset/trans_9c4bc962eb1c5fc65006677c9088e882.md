
**x**[*n*] ↦ *ϕ*(**x**[*n*]) ∈ ℍ, *n* = 1, 2, …, *N*.

![Equation](images/B9780443292385000172/si93.png)

1.

2. **2.** 在 ℍ 中求解一个涉及像 *ϕ*(**x**[*n*])、*n* = 1, 2, …, *N* 的*线性*估计任务。

3. **3.** 将求解未知参数的算法表示为以下形式的内积运算：

⟨*ϕ*(**x**[*i*]), *ϕ*(**x**[*j*])⟩, *i*, *j* = 1, 2, …, *N*.

![Equation](images/B9780443292385000172/si96.png)

1.

2. **4.** 用核函数计算替换每一个内积，即：

⟨*ϕ*(**x**[*i*]), *ϕ*(**x**[*j*])⟩ = *κ*(**x**[*i*], **x**[*j*]).

![Equation](images/B9780443292385000172/si97.png)

1.

显然，不需要对数据执行任何显式映射。只需在最后一步执行核运算即可。请注意，*κ*(⋅, ⋅) 的具体形式不影响分析。一旦推导出用于预测 *ŷ* 的算法，就可以为 *κ*(⋅, ⋅) 使用不同的选择。正如我们将看到的，*κ*(⋅, ⋅) 的不同选择对应于不同类型的非线性。[图 11.6](#Chp011_519-582_B9780443292385000172.xhtml#f0035) 说明了该过程背后的基本原理。在实践中，上述列出的四个步骤等同于 (a) 在原始（低维欧几里得）空间中工作，并用内积表示所有运算，以及 (b) 在最后一步用核函数计算替换内积。
