

## 图 8.15

凸集投影基本定理（POCS）的几何图解，针对 `T[C[i]] = P[C[i]]` (`i = 1, 2` (`μ[C[i]] = 1`)) 的情况。闭凸集是 `ℝ²` 中的两条直线，即 `C[i] = H[i]`，`i = 1, 2`。观察可知，投影序列趋向于 `H[1]` 与 `H[2]` 的交集。

该定理的证明在一般情况下略显技术性（例如，文献 [87]）。然而，对于涉及的凸集均为闭子空间的情况，证明可以简化（习题 [8.23](#Chp008_343-416_B9780443292385000147.xhtml#o0145)）。证明的核心在于：(a) `T[C[k]]` 的非扩张性，`k = 1, 2, …, K`，该性质被 `T` 保留；以及 (b) `T` 的不动点集为 `Fix(T) = ⋂_{k=1}^{K} C_k` 这一事实。

### 备注 8.3

*   在所有 `C[k]`，`k = 1, 2, …, K` 均为闭子空间的特殊情况下，我们有
    ```
    T^(n)(x[0]) → P[C](x[0])。
    ```
*   换言之，松弛投影序列*强收敛*于 `x[0]` 在 `C` 上的投影。回顾一下，如果每个 `C[k]`，`k = 1, 2, …, K` 都是 `ℍ` 的闭子空间，则很容易证明它们的交集也是一个闭子空间。如前所述，在欧几里得空间 `ℝ^(l)` 中，所有子空间都是闭的。
*   上述结论对*线性簇*同样成立。线性簇是子空间沿常向量 `a` 的平移。即，若 `S` 为子空间且 `a ∈ ℍ`，则点集
    ```
    S[a] = {y : y = a + x, x ∈ S}
    ```
    为一线性簇。超平面即为线性簇（参见例如 [图 8.16](#Chp008_343-416_B9780443292385000147.xhtml#f0090)）。

![图 8.16 不经过原点的超平面是一个线性簇；P_{S_{a}} 方程和 PS 分别是 x 在 Sa 和 S 上的投影。](images/B9780443292385000147/gr016.jpg)

**图 8.16** 不经过原点的超平面是一个线性簇；`P[S[a]]` 和 `P[S]` 分别是 `x` 在 `S[a]` 和 `S` 上的投影。

*   采用松弛投影算子的 POCS 定理所得方案，总结于 [算法 8.1](#Chp008_343-416_B9780443292385000147.xhtml#enun0115)。
