$$J_{1}(\mathbf{\theta}) = \sum\limits_{\mathcal{U}}\sum\limits_{n}\ln P(\mathbf{u}_{n}|\mathbf{u}_{n - 1},\mathbf{u}_{n - 2},\ldots,\mathbf{u}_{n - k};\mathbf{\theta})$$

where `θ` is the set of all the parameters involved in the network. In GPT, `k` is the size of the so-called *context window*. In other words, `k` determines the window of the past information that is involved in the conditional probabilities. Of course, since GPT does not involve a separate encoder, the conditional probabilities depend only on past input tokens. The first summation is over all possible text sequences in the corpus. In other words, GPT is pretrained to perform as a non-linear predictor.

Note that for the next word prediction, an extra network on top of the last block of the transformer is used, that first linearly transforms the outputs back to the dimensionality of the vocabulary, followed by the softmax nonlinearity layer. This is exactly the same technique as the one used in the decoder in [Fig. 19.9](#Chp019_997-1102_B9780443292385000251.xhtml#f0050). Thus in GPT, the single stack of transformer blocks could be seen as acting both as the encoder as well as the decoder.

The main idea associated with pretraining is that by forcing the network to learn to predict, using a large corpus of unlabeled data, it equivalently learns basic structural and contextual information that resides in the associated type of data. Digging in this information, the network can encode, at the output of the top block, a *universal representation* that can subsequently be transferred, with little adaptation, to a wide range of tasks. This rationale draws inspiration directly from the transfer learning discussed in Section [18.16](#Chp018_885-995_B978044329238500024X.xhtml) and it will be the main theme in Section [19.6](#Chp019_997-1102_B9780443292385000251.xhtml#s0190).

### Supervised Fine-Tuning

Once pretraining is over, one can use the trained transformer to perform supervised learning NLP tasks, such as those mentioned in the beginning of this section. For example, in a sentiment analysis or document classification task, given a sequence of say, `M`, tokens, i.e., $\mathcal{X} = \{\mathbf{x}[1], \mathbf{x}[2], \ldots, \mathbf{x}[M]\}$ with a corresponding class label, `y`, the goal is to maximize the conditional probability $P(y|\mathcal{X})$.

During fine-tuning, an extra network, parameterized in terms of a new set of parameters, `w`, is added on top of the last block of the pretrained transformer network. This is different from the extra network (that transformed vectors to word probabilities) used during pretraining. For example, for the case of classification tasks, the aim of the extra network that is employed during fine-tuning is to transform the outputs of the last transformer block into *class* probabilities. This is achieved by first applying a) a linear transformation to bring the corresponding outputs into the right dimensionality, as dictated by the specific task (e.g., number of classes), followed b) by a softmax nonlinearity that transforms the final outputs into class probabilities. The weights of this extra network are learned by maximizing, with respect to `w`, the cost function,

$$J_{2}(\mathbf{w}) = \sum\limits_{(y,\mathcal{X})}\ln P(y|\mathcal{X}).$$

During fine-tuning, one can also employ a combination of Eqs. [(19.51)](#Chp019_997-1102_B9780443292385000251.xhtml#deq116) and [(19.50)](#Chp019_997-1102_B9780443292385000251.xhtml#deq115) and optimize with respect to both `θ` and `w`. In other words, instead of keeping the parameters of the pretrained transformer fixed to the optimal values, which were obtained during pretraining, one can use them as initial estimates and obtain updated estimates during fine-tuning for the specific supervised learning task. Note, however, that this alternative may not be useful in practice, due to the very large size of today's models.

#### Remarks 19.7

*   In the machine learning jargon, the pretraining phase is often referred to as the *pretext* task and the supervised learning fine-tuning, associated with a specific supervised learning case, as the *downstream* task.
*   At the time of the publication of [147], the reported results showed impressive performance improvements in a number of NLP tasks, compared to previous state-of-the-art techniques.
