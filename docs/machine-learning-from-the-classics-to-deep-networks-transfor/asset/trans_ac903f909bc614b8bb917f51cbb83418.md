3.  **3.8** 当训练数据源自线性模型时，推导最小二乘（LS）估计量的 Cramér–Rao 界：

    $$
    y[n] = \theta x[n] + \eta[n], \quad n = 1, 2, \dots
    $$

    其中 $x[n]$ 是均值为零、方差为 $\sigma_x^2$ 的随机变量的独立同分布（i.i.d.）样本，$\eta[n]$ 是从均值为零、方差为 $\sigma_\eta^2$ 的高斯分布中抽取的独立同分布噪声样本。还假设 $x$ 和 $\eta$ 相互独立。然后，证明 LS 估计量仅在渐近意义上达到 Cramér–Rao 界。

4.  **3.9** 让我们考虑回归模型：

    $$
    y[n] = \boldsymbol{\theta}^T \boldsymbol{x}[n] + \eta[n], \quad n = 1, 2, \dots, N,
    $$

    其中噪声样本 $\boldsymbol{\eta} = [\eta[1], \dots, \eta[N]]^T$ 来自零均值高斯随机向量，其协方差矩阵为 $\boldsymbol{\Sigma}_\eta$。如果 $\mathbf{X} = [\boldsymbol{x}[1], \dots, \boldsymbol{x}[N]]^T$ 代表输入矩阵，$\mathbf{y} = [y[1], \dots, y[N]]^T$，则证明：
