
### 11.6.2 Nonparametric modeling: a discussion

Note that searching a model function in an RKHS space is a typical task of *nonparametric* modeling. In contrast to the parametric modeling in Eq. [(11.1)](#Chp011_519-582_B9780443292385000172.xhtml#deq1), where the unknown function is *parameterized* in terms of a set of basis functions, the minimization in Eq [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64) or Eq. [(11.21)](#Chp011_519-582_B9780443292385000172.xhtml#deq74) is performed with regard to functions that are *constrained to belong in a specific space*. In the more general case, minimization could be performed with regard to any (continuous) function, for example,

```
\min\limits_{f}\ \sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},f(\mathbf{x}_{n}) \right) + \lambda\phi(f),
```

where $\mathcal{L}(\cdot,\cdot)$ can be any loss function and $\phi$ an appropriately chosen regularizing functional.^([^(75)](#fn75))

```
\sum\limits_{n = 1}^{N}\left( y_{n} - f(x_{n}) \right)^{2} + \lambda\int{(f^{''}(x))}^{2}\ dx,
```
