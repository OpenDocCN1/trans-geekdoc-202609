
# Variational Autoencoder (VAE) Components

In the VAE jargon, `q(z|x; ϕ)` is known as the probabilistic **encoder**; indeed, given an observation, `x`, it produces a distribution (e.g., a Gaussian) over the possible values of `z`, which is also known as the **code**. On the other hand, `p(x|z; θ)` is referred to as the probabilistic **decoder**; given a code `z`, it produces a distribution over the possible corresponding values of `x`. The major difference with the autoencoders considered before in Section 19.2.4 is that, in the variational autoencoder context, the encoder is not designed to output a *single value* for each input variable; in contrast, it is designed to provide a corresponding *probability distribution*. This is also true for the decoder.

The concept behind VAEs should be clear by now. Once we learn the parameters associated with the approximate models of the posterior and the conditional distributions, `ϕ` and `θ`, then we can generate new samples: Generate samples, `z[n]`, of the latent variables and in the sequel use these samples to generate samples by sampling the learned conditional, `p(x|z[n]; θ)`. All that remains for us now is a) to adopt the explicit parametric models for the conditional, `p(x|z; θ)`, and for the approximation to the posterior, `q(z|x; ϕ)` and b) to establish the method for estimating the unknown parameters.

## The Parametric Models

In [103], the following model is proposed:

*   **For the prior**, the standard multivariate Gaussian is adopted, i.e., `p(z) = N(z|0, I)`. Thus, according to such a choice, the prior does not depend on any parameters.
*   **For the posterior approximation**, `q(z|x; ϕ)`, the multivariate Gaussian is also selected, with diagonal covariance matrix (`Σ[n] = diag{σ[ni]²}[i=1]^(m)`), i.e.,

    `q(z|x[n]; ϕ) = N(z|μ[n], Σ[n])`.

*   The crucial point here is that the above mean values and variances are provided as outputs of the encoding network; in the simplest case, a network of a single hidden layer is employed (deeper networks and other variants can also be considered). More specifically,

    ```
    h[n] = tanh(W[1]x[n] + b[1])
    ```
