

我们已经看到，在需要估计协方差矩阵的情况下，未知参数的数量级为 `𝒪(l²/2)`。对于高维空间，除了该估计任务极其艰巨这一事实外，还需要大量数据点，以获得统计上良好的估计并避免过拟合，正如第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章所讨论的。在这种情况下，人们不得不满足于次优解。确实，在使用相关参数的糟糕估计时采用最优方法，可能会导致整体性能变差。

*朴素贝叶斯分类器* 是次优分类器的一个典型且流行的例子。其基本假设是特征向量中的各分量（特征）在统计上是独立的；因此，联合概率密度函数（PDF）可以写成 *l* 个边缘概率密度函数的乘积，

```
p(x|ω_i) = ∏_{k=1}^{l} p(x_k|ω_i),  i = 1,2,...,M.
```

在采用高斯假设后，每个边缘分布由两个参数（均值和方差）描述；这导致每个类总共需要估计 `2l` 个未知参数。与 `O(l²/2)` 个参数的数量相比，这是一个巨大的节省。结果表明，当数据样本量有限时，这种简化的假设所得到的结果可能比最优贝叶斯分类器更好。

尽管朴素贝叶斯分类器是在高斯分布数据的背景下引入的，但其使用在更一般的情况下也是合理的。在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中，我们讨论了维度灾难问题，并强调了高维空间是稀疏分布的。换句话说，对于固定有限数量的数据点 *N*，位于每个维度固定大小的超立方体内，空间维度越大，任意两点之间的平均距离就越大。因此，为了在大空间中获得一组参数的良好估计，需要更多的数据。粗略地说，如果在实轴上获得 PDF 的足够好估计需要 *N* 个数据点，那么在 *l* 维空间中获得类似精度将需要 `N^l` 个数据点。因此，通过假设特征相互独立，最终将估计 *l* 个一维 PDF，从而大大减少了对数据的需求。

独立性假设是许多机器学习和统计任务中常见的假设。正如我们将在第 [15](#Chp015_755-803_B9780443292385000214.xhtml) 章中看到的，可以采用介于两个极端（即完全独立和完全依赖）之间的较温和的独立性假设。

## 7.5 最近邻规则

虽然贝叶斯规则提供了关于分类错误概率的最优解，但其应用需要估计相应的条件 PDF；一旦特征空间的维数取得相对较大的值，这并非易事。这为考虑替代分类规则铺平了道路，这将成为我们从现在开始的关注焦点。

*k-最近邻* (*k-NN*) 规则是一种典型的非参数分类器，也是最流行和最知名的分类器之一。尽管它很简单，但仍在使用，并与一些更复杂的方案齐名。

考虑一个 *M* 类分类任务的 *N* 个训练点，`(y[n], x[n])`，`n = 1, 2, …, N`。该方法的核心在于一个参数 *k*，这是一个用户定义的参数。一旦选定 *k*，给定一个模式 **x**，将其分配给其 *k* 个最近邻（根据某种度量，如欧氏距离或马氏距离）在训练点中所属类别占多数的那个类别。参数 *k* 不应是 *M* 的倍数，以避免平局。该规则最简单的形式是将模式分配给其最近邻所属的类别，即 `k = 1`。
