

# 稀疏分析公式化

在稀疏综合公式化中，人们在由字典 `Ψ` 的所有可能的 *k* 列组合形成的子空间并集中寻找解。信号向量位于这些子空间之一中——即由 `Ψ` 中索引位于支撑集（第 [10.2.1](#Chp010_463-518_B9780443292385000160.xhtml#s0020) 节）内的那些列所张成的子空间。

在稀疏分析方法中，情况有所不同。出发点是我们原始变换 $\widetilde{\mathbf{s}} := \Phi^{T}\mathbf{s}$ 的稀疏性，其中 `Φ` 定义了变换矩阵或分析算子。因为假设 $\widetilde{\mathbf{s}}$ 是稀疏的，所以存在一个索引集 $\mathcal{I}$，使得 $\forall i \in \mathcal{I}$，$\tilde{s}[i] = 0$。换句话说，$\forall i \in \mathcal{I}$，$\boldsymbol{\phi}[i]^{(T)}\mathbf{s} := \langle \boldsymbol{\phi}[i], \mathbf{s} \rangle = 0$，其中 $\boldsymbol{\phi}[i]$ 代表 `Φ` 的第 *i* 列。因此，$\mathbf{s}$ 所在的子空间是由变换向量 $\widetilde{\mathbf{s}}$ 中对应零值的那些 `Φ` 列所形成的子空间的正交补。现在假设 $\text{card}(\mathcal{I}) = C_o$。信号 $\mathbf{s}$ 可以通过在由 `Φ` 的所有可能的 $C_o$ 列组合形成的子空间的*正交补*上搜索来识别，即

```
⟨ϕ[i], s⟩ = 0,  ∀i ∈ I.
```

综合问题与分析问题的区别如 [图 10.12](#Chp010_463-518_B9780443292385000160.xhtml#f0065) 所示。为了便于对这一新设定进行理论处理，*余稀疏度* 的概念在文献 [92] 中被引入。

## 定义 10.2

信号 $\mathbf{s} \in \mathbb{R}^l$ 关于 $p \times l$ 矩阵 $\Phi^T$ 的余稀疏度定义为

```
C_o := p - ||Φ^T s||_0.
```
