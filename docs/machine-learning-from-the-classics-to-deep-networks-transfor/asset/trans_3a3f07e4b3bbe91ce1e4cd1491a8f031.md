值得注意的是，被丢弃线段的序列 `π[k]` 实现了一个与公式 (13.119) 中给出的 DP 断棒构造相关的序列（问题 [13.24](#Chp013_635-716_B9780443292385000196.xhtml#o0220)）。这种相似性清晰地揭示了 IBP 和 DP 之间的区别。在 IBP 中，概率序列是递减的，且各值之和不等于 1。相反，DP 中的概率序列不一定递减，但各值之和等于 1。

### 推断

对于推断，首先应显式写出生成数据的模型。为此，采用 IBP 的断棒构造，假设数据服从具有二元潜在特征模型的高斯分布；这导致以下步骤序列：

1.  生成 Beta 变量，`β[k] ~ Beta(β|α, 1)`，`k = 1, 2, …`。
2.  生成概率值，`P_k = ∏_{j=1}^{k} β_j`，`k = 1, 2, 3, …`。
3.  用元素填充矩阵 `Z`，`z[kn] ~ Bern(z|P[k])`，`n = 1, 2, …, N` 且 `k = 1, 2, …`。
4.  生成矩阵 `A` 中的特征，`a[k] ~ N(0, σ[A]²I)`，`k = 1, 2, …`。
