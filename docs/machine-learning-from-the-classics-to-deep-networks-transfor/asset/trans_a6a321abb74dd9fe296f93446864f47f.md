
(*x*[1*], *x*[2*], *x*[3*], *x*[4*]) = (1, 2, 2, 4).

![Equation](images/B9780443292385000214/si344.png)(15.71)

这两者都是可以接受的，因为它们对应于最大值 *P*(*x*[1], *x*[1], *x*[3], *x*[4])。回溯过程保证给出这两者中的任意一个。相反，使用两阶段消息传递可能会导致值的组合，例如，

(*x*[1*], *x*[2*], *x*[3*], *x*[4*]) = (1, 1, 2, 4),

![Equation](images/B9780443292385000214/si346.png)(15.72)

这不符合最大值。请注意，此结果本身的基本原理是正确的。它为每个节点提供了一个可能产生最优解的值。确实，在搜索 *P*(**x**) 的最大值时，节点 *x*[2] 可以取值 1 或 2。然而，我们想要找到的是所有节点的正确*组合*。这由回溯过程保证。
