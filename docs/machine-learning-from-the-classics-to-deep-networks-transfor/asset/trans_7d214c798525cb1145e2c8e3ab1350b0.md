
*马尔可夫链* 是一系列随机（向量）变量，**x**[0]，**x**[1]，**x**[2]……，其条件分布遵循以下规则：

*p*(**x**[*n*]|**x**[*n* − 1], {**x**[*t*] : *t* ∈ ℐ}) = *p*(**x**[*n*]|**x**[*n* − 1]), (14.32)

其中 ℐ = {0, 1, …, *n* − 2}。索引 *n* 通常被解释为时间。

用文字表述，公式 [(14.32)](#Chp014_717-754_B9780443292385000202.xhtml#deq55) 表明，给定 **x**[*n* − 1] 中变量的值后，**x**[*n*] 与索引在 ℐ 中的变量相互独立。分布 *p* 可以是密度函数，也可以是对应离散变量的概率分布，其取值于一个称为*状态*的离散集合中。我们将假设所有变量共享一个公共取值范围，称为*状态空间*。我们的大部分讨论将围绕有限状态空间展开，其中状态取值于一个有限离散集合，例如 {1, 2, …, *K*}。马尔可夫链通过以下两方面指定：(a) 与序列中第一个向量 **x**[0] 相关联的分布（概率向量），**p**[0]；以及 (b) *转移概率* 的 *K* × *K* 矩阵，即：

```
P[n](x[n]|x[n − 1]) = [P[n](i|j)],
```

其中

```
P[n](i|j) := P[n](x[n] = i|x[n − 1] = j),  i, j = 1, 2, …, K,
```

表示时刻 *n* − 1 的变量处于状态 *j* 且时刻 *n* 的变量处于状态 *i* 的概率。^([^(108)](#fn108))
