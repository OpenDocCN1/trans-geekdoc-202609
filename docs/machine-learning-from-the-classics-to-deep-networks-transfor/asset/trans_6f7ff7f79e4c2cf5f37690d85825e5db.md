
因此，随机变量 `ŷ`（现解释为向量空间中的一个点）是该空间中 `l` 个元素的线性组合。因此，变量 `ŷ` 必然位于由这些点张成的子空间中。相反，真实变量 `y` 通常不位于该子空间中。因为我们的目标是获得一个能很好地近似 `y` 的 `ŷ`，我们必须寻找使误差范数 `e = y - ŷ` 最小的特定线性组合。这种特定的线性组合对应于 `y` 向由点 `x[1], x[2], …, x[l]` 张成的子空间上的**正交**投影。这等价于要求

```
𝔼[(y - Σᵢ₌₁ˡ θᵢ xᵢ) xₖ] = 0,  k = 1,2,…,l
```
(4.10)

误差变量与每个点 `x[k]`（`k = 1, 2, …, l`）正交，因此将正交于相应的子空间。这在[图 4.3](#Chp004_119-175_B978044329238500010X.xhtml#f0020)中说明。这种选择保证了由此产生的误差具有最小范数；根据范数的定义，这对应于最小均方误差（MSE），即最小 `𝔼[e²]`。

[图 4.3](#Chp004_119-175_B978044329238500010X.xhtml#cf0240) 将 `y` 投影到由 `x[1], x[2]` 张成的子空间（阴影平面）上，保证 `y` 和 `ŷ` 之间的偏差对应于最小 MSE。

[(4.10)](#Chp004_119-175_B978044329238500010X.xhtml#deq15) 中的方程组现在可以写为

```
𝔼 [ (y - Σᵢ₌₁ˡ θᵢ xᵢ) xₖ ] = 0,  k = 1,2,…,l
```

或

```
Σᵢ₌₁ˡ 𝔼[xᵢ xₖ] θᵢ = 𝔼[xₖ y],  k = 1,2,…,l
```
(4.11)

这导出了方程 [(4.5)](#Chp004_119-175_B978044329238500010X.xhtml#deq7)。

这就是这组优雅方程被称为**正规方程**的原因。另一个名称是**维纳-霍普夫方程**。严格来说，维纳-霍普夫方程最初是在因果估计任务的背景下为连续时间过程推导的 [49,50]；关于讨论请参见 [16,44]。
