
在本例中，研究了前文提到的最流行在线算法的性能曲线，场景设定为时变环境。自适应滤波领域常用的一个典型仿真设置是：未知向量在若干次观测后发生突变，以此考察算法的跟踪能力。这里我们考虑一个信号 `s`，它具有稀疏小波表示，即 `s = Ψθ_s`，其中 `Ψ` 为对应的变换矩阵。具体而言，我们设 `l = 1024`，含 100 个非零小波系数。在 1500 次观测后，任选 10 个小波系数将其值改为从区间 `[-1, 1]` 中均匀随机选取的新值。注意这可能影响信号的稀疏度，此时非零系数最多可达 110 个。共使用 `N = 3000` 个测量向量，它们由输入向量 `x[n] ∈ ℝ^l, n = 1, 2, …, 3000` 的小波变换得到，元素服从 `𝒩(0, 1)` 分布。这样，在线算法估计的不是信号本身，而是其稀疏小波表示 `θ`。观测值受加性白高斯噪声干扰，噪声方差 `σ[n]² = 0.1`。

关于 SpAPSM，外推参数 `μ[n]` 设为 `1.8 × ℳ[n]`，所有 `ω_i^(n)` 取相同值 `1/q`，超平板参数 `ϵ` 设为 `1.3 σ[n]`，且 `q = 390`。所有算法的参数均选为优化其性能。因信号稀疏度可能变化（从 `k = 100` 到 `k = 110`），且实际中无法预知 `k` 的确切值，我们给算法输入真实稀疏值的过估计值 `k̂ = 150`（即第 1500 次迭代前过估计 50%）。

结果如[图 10.11](#Chp010_463-518_B9780443292385000160.xhtml#f0060)所示。注意 SpAPSM 算法获得了更优性能。但须指出，对于 SpAPSM 取 `q = 390` 的情况，AdCoSaMP 的复杂度远低于另外两个算法。有趣的是，SpAPSM 在显著更低复杂度下实现了优于 OCCD-TWL 的性能。若复杂度为首要考量，采用 SpAPSM 可灵活使用广义阈值算子，在 `q` 较小值时获得性能提升，其复杂度可与基于 LMS 的稀疏促进算法相媲美 [79,80]。
