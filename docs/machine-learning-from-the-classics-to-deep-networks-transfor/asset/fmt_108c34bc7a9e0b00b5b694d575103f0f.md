
Also, a matrix that is both left and right stochastic is known as *doubly stochastic* (Problem [5.15](#Chp005_177-248_B9780443292385000111.xhtml#o0080)). Note that due to this matrix constraint, we still have

$$
\sum\limits_{k = 1}^{K}J_{k}^{loc}(\mathbf{\theta}) = \sum\limits_{k = 1}^{K}\sum\limits_{m \in \mathcal{N}_{k}}c_{mk}J_{m}(\mathbf{\theta}) = \sum\limits_{k = 1}^{K}\sum\limits_{m = 1}^{K}c_{mk}J_{m}(\mathbf{\theta}) = \sum\limits_{m = 1}^{K}J_{m}(\mathbf{\theta}) = J(\mathbf{\theta}).
$$

![Equation](images/B9780443292385000111/si487.png)

That is, summing all local costs, the global one results.

Let us focus on minimizing Eq. [(5.81)](#Chp005_177-248_B9780443292385000111.xhtml#deq181). The gradient descent scheme results in

$$
\mathbf{\theta}_{k}^{(i)} = \mathbf{\theta}_{k}^{(i - 1)} + \mu_{k}\sum\limits_{m \in \mathcal{N}_{k}}c_{mk}\left( \mathbf{p}_{m} - \Sigma_{x_{m}}\mathbf{\theta}_{k}^{(i - 1)} \right).
$$
