
$P(f\_{i} = 0|\mathbf{d}) = \prod\limits\_{j = 1}^{m}{(1 - P\_{ij})}^{d\_{j}},$

其中当疾病与症状无关时，指数设为零，即 $d\_[j] = 0$。这被称为*噪声或*模型。也就是说，假设对于阴性发现，各个病因是相互独立的 [37]。显然，

$P(f\_[i] = 1|\mathbf{d}) = 1 - P(f\_[i] = 0|\mathbf{d}).$

现在假设我们观察到一组发现 $\mathbf{f}$，并且我们想要推断某个 $j$ 的 $P(d\_[j]|\mathbf{f})$。那么

$P(d\_j = 1|\mathbf{f}) = \frac{P(\mathbf{f}|d\_j = 1)P(d\_j = 1)}{P(\mathbf{f})} = \frac{\sum\_{\mathbf{d}:d\_j = 1}P(\mathbf{f}|\mathbf{d})P(\mathbf{d})}{\sum\_{\mathbf{d}}P(\mathbf{f}|\mathbf{d})P(\mathbf{d})}.$ (15.3)

分母中的求和包含 $2^{(m)}$ 项。对于 $m \sim 500$，这是一项艰巨的任务，根本无法在现实的时间内完成。

前面的例子表明，一旦涉及复杂系统，即使是看似简单的任务也会变得计算上不可行。因此，要么必须更聪明地利用数据中可能存在的独立性，从而减少所需的计算量；要么做出某些假设/近似。在本章中，我们将研究这两种替代方案。
