### Learners' parameters

For each `k = 1, 2, …, K`, we have:

```
Q(Ξ, P; Ξ^(j), P^(j)) = - Σ_{n=1}^N (γ_nk / (2σ_η^2)) (y_n - θ_k^T x_n)^2 + C_1,
```

![Equation](images/B9780443292385000184/si401.png) (12.101)

where `C_1` includes all terms that do not depend on `θ_k`. Taking the gradient and equating to zero, we readily obtain:

```
Σ_{n=1}^N γ_nk x_n (y_n - x_n^T θ_k) = 0,
```
