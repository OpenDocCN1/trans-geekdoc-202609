

另一个重要问题是，在实践中我们并不知道 `S_d(ω_1, ω_2)`。一种通常采用且能产生合理结果的近似方法是假设 `S_η(ω_1, ω_2) / S_d(ω_1, ω_2)` 为常数 `C`，并尝试它的不同取值。[图 4.8](#Chp004_119-175_B978044329238500010X.xhtml#f0045) 显示了 `C = 2.3 × 10^(−6)` 时的去模糊图像。最终结果的质量在很大程度上取决于该值的选择（计算机练习 [4.25](#Chp004_119-175_B978044329238500010X.xhtml#o0130)）。也提出了其他更先进的技术。例如，可以利用来自 `S_η(ω_1, ω_2)` 和 `S_u(ω_1, ω_2)` 的信息来获得 `S_d(ω_1, ω_2)` 的更好估计。感兴趣的读者可以从例如文献 [14, 34] 中获取更多关于图像解卷积/复原任务的内容。

## 4.7 一些典型应用

最优线性估计/滤波已应用于统计学习的广泛多样化应用中，例如回归建模、通信、控制、生物医学信号处理、地震信号处理和图像处理。在后续章节中，我们将介绍一些典型应用，以便读者掌握前面所述理论如何用于解决实际问题的主要基本原理。在所有情况下，均假设所涉及的随机过程具有宽平稳性。

### 4.7.1 干扰消除

在干扰消除中，我们可以获得两个信号的混合，表示为 `d[n] = y[n] + s[n]`。理想情况下，我们希望去除其中一个，例如 `y[n]`。我们将它们视为相应随机过程/信号的实现，即 `d[n]`、`y[n]` 和 `s[n]`。为实现这一目标，唯一可用的信息是另一个信号，例如 `u[n]`，它与不需要的信号 `y[n]` 在统计上相关。例如，`y[n]` 可能是 `u[n]` 的滤波版本。[图 4.9](#Chp004_119-175_B978044329238500010X.xhtml#f0050) 说明了这一点，其中展示了所涉及随机过程的相应实现。
