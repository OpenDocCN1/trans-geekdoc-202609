
然而，由于 `q(x)` 未知，必须求助于近似方法。在扩散模型的语境下，`q(x)` 指的是与观测输入样本相关联的概率密度函数（pdf）。遵循此类模型的基本原理，所需的近似是通过根据方差序列 `σ[1]² < σ[2]² < … < σ[T]²`，经由一系列添加噪声的步骤，逐步扰动给定的观测点 `x[0]` 来实现的。一个典型的模型遵循高斯形式的条件分布 `q(x[t]|x[0])`，即 `N(x[t]|x[0], σ[t]²I)`，`t = 1, 2, …, T`。为了采样目的，前述的高斯假设可表示为

```
x[t] = x[0] + σ[t]ϵ,  ϵ ∼ N(0, I).
```
