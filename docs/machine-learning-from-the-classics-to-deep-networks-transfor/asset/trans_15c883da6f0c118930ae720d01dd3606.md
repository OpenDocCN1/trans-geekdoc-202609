
其中 `δ(·)` 等于 1 或 0，分别取决于其参数是 1 还是 0，而 `⊕` 表示模 2 加法。码字被传输到一个有噪无记忆二进制对称信道，其中每个传输比特 `x[i]` 可能被翻转并作为 `y[i]` 接收，规则如下：

`P(y = 0|x = 1) = p`，`P(y = 1|x = 1) = 1 − p`，`P(y = 1|x = 0) = p`，`P(y = 0|x = 0) = 1 − p`。

接收到观测序列 `y[i]`，`i = 1, 2, …, N` 后，必须判断传输的 `x[i]` 的值。由于信道被假定为无记忆的，每个比特受噪声影响独立于其他比特，每个码字的总体后验概率与以下公式成正比：

```
∏_{i = 1}^{N} P(x_i | y_i).
```

为了保证仅考虑有效码字，并假设信息比特是*等概率*的，我们将联合概率写为

```
P(x, y) = (1/Z) ψ_1(x_1, x_2, x_4) ψ_2(x_1, x_3, x_5) ψ_3(x_2, x_3, x_6) ∏_{i = 1}^{N} P(y_i | x_i),
```
