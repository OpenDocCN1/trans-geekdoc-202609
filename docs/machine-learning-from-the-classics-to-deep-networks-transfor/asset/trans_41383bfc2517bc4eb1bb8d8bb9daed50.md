其中

**z**[n]^(T) = [u[1n], u[2n], …, u[mn]], n = 1, 2, …, N.

![Equation](images/B9780443292385000263/si485.png)(20.107)

即，**z**[n] 由 m 个先前特征向量的第 n 个分量组成。通用特征分解求解器的计算复杂度达 O(N³) 次操作。然而，对于稀疏矩阵（如拉普拉斯矩阵 L），可采用高效方案将复杂度降低至关于 N 的亚二次方，例如兰索斯算法 [83]。

关于步骤 3 陈述的证明将针对 m = 1 的情况给出。对于这种情况，低维空间即为实轴。我们的推导路径遵循文献 [19] 所采用的思路。目标是计算 z[n] ∈ ℝ, n = 1, 2, …, N，使得连接的点（在图中，即邻居）在映射到一维子空间后尽可能保持接近。用于满足映射后接近性的准则是

```
E_L = ∑_{i=1}^{N} ∑_{j=1}^{N} (z_i - z_j)^2 W(i,j)
```
