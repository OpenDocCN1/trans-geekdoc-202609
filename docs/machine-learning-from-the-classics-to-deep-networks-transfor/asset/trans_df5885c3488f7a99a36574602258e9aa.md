
实轴上的区间 `[-10, 10]` 在 `N = 100` 个等距点 `x[n]` 处进行采样，`n = 1, 2, …, 100`。训练数据由配对 `(y[n], x[n])` 组成，`n = 1, 2, …, N`，其中

```
y_n = exp(-1/2 * (x_n + 5.8)^2 / 0.1) + exp(-1/2 * (x_n - 2.6)^2 / 0.1) + η_n,
```

此处 `η[n]` 为方差为 `σ[η]² = 0.015` 的独立同分布（i.i.d.）零均值高斯噪声样本。为拟合数据，采用了以下模型：

```
y = Σ_{k=1}^{N} θ_k * exp(-1/2 * (x - x_k)^2 / 0.1).
```

因此，矩阵 `Φ` 具有以下元素：

```
[Φ]_{nk} = exp(-1/2 * (x_n - x_k)^2 / 0.1),  n = 1,2,…,N,  k = 1,2,…,N.
```
