
训练 GAN 相关的另一个问题是所谓的*模式崩塌*。这意味着虽然生成器可能会“欺骗”判别器，但生成器产生的是“相同”的输出。似乎生成器陷入了一个“微小”的区域，导致输出的多样性很低。这可能是因为生成器无法充分学习数据分布，它只关注其中的一部分，而忽略了其他部分。

为了规避上述缺陷，已经提出了许多技巧和方法（参见例如 [108,163,203]）。文献 [146] 引入了卷积生成网络。文献 [128] 采用最小二乘论据来设计 GAN。文献 [98] 中，判别器估计真实样本比生成样本更真实的概率，而不是估计其为真实样本的概率。文献 [118] 基于竞争性训练程序采用了模型组合的概念，该程序将数据分布分割为多个分量，这些分量可由独立的生成模型很好地逼近。

### Wasserstein GAN

文献 [7] 通过所谓的分布间*Wasserstein 距离*，系统性地解决了在低维流形中匹配 `p_r` 和 `p_g` 的任务。首先证明了当在低维流形中学习分布时，衡量分布间差异的散度必须具有特定性质。JS 散度和 KL 散度都不具备这些性质。相反，Wasserstein 距离在此背景下是一个合适的度量。

两个分布 `p_r` 和 `p_g` 之间的 Wasserstein 距离，或称*土方距离*（EMD），定义为

```
W(p_r, p_g) = inf_{γ ∈ Π(p_r, p_g)} E_{(x,y) ~ γ} [||x - y||]
```
(19.16)

尽管上述定义对不熟悉的读者可能看起来有点复杂，但它非常讲得通；`Π(p_r, p_g)` 是*所有*联合分布的集合，这些联合分布针对随机向量，其边缘分布分别等于 `p_r` 和 `p_g`。直观上，期望值表示为了将 `p_r` 转换为 `p_g`，需要从 `x` 向 `y` 转移多少概率质量。它们的距离对应于所有可能的联合分布中的“最小”值。^([130](#fn130))

```
W(p_r, p_g) = sup_{||f||_L < 1} { E_{p_r(x)}[f(x)] - E_{p_g(x)}[f(x)] }
```
(19.17)
