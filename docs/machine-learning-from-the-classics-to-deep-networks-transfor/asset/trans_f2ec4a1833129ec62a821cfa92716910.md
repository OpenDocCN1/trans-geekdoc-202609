

## 信息传递算法

![Equation](images/B9780443292385000214/si287.png)

和

$$
\mu_{f_{a}\rightarrow x_{1}}(x_{1}) = \sum\limits_{x_{2}}\sum\limits_{x_{3}}\sum\limits_{x_{4}}f_{a}(x_{1},x_{2},x_{3},x_{4})\mu_{x_{2}\rightarrow f_{a}}(x_{2})\mu_{x_{3}\rightarrow f_{a}}(x_{3})\mu_{x_{4}\rightarrow f_{a}}(x_{4}).
$$

观察到我们被引导定义了两种类型的消息；一种类型从变量节点传递到因子节点，另一种类型从因子节点传递到变量节点。

*   **变量节点到因子节点消息** ([图 15.27](#Chp015_755-803_B9780443292385000214.xhtml#f0155)A)：

![Equation](images/B9780443292385000214/fx008.jpg) (15.49)

*   我们使用 $\mathcal{N}(x)$ ![Equation](images/B9780443292385000214/si289.png) 来表示变量节点 $x$ 所连接的节点集合；$\mathcal{N}(x) \setminus f$ ![Equation](images/B9780443292385000214/si290.png) 指的是*排除*因子节点 $f$ 的所有节点；注意所有这些节点都是因子节点。换句话说，就消息传递而言，变量节点的作用是将传入的消息相乘。显然，如果它仅连接到一个因子节点（除 $f$ 外），则该变量节点会原样传递它接收到的内容，无需任何计算。例如，之前定义的 $\mu[x_{2}\rightarrow f_{a}]$ ![Equation](images/B9780443292385000214/si293.png) 就是这种情况。

![Figure 15.26 The tree is subdivided into three subtrees, each one having as its root one of the factor nodes connected to x1. This is the node whose marginal is computed in the text. Messages are initiated from the leaf nodes toward x1. Once messages arrive at x1, a new propagation of messages starts, this time from x1 to the leaves.](images/B9780443292385000214/gr026.jpg)

**图 15.26** 树被细分为三个子树，每个子树的根节点都是连接到 $x_{1}$ 的因子节点之一。这是文中计算其边缘概率的节点。消息从叶节点发起，朝向 $x_{1}$ 传播。一旦消息到达 $x_{1}$，新一轮消息传播开始，这次是从 $x_{1}$ 向叶节点传播。

![Figure 15.27 (A) Variable x is connected to S factor nodes, besides f; that is, \mathcal{N}(x) \smallsetminus f = \{ f_{1},f_{2},\ldots,f_{S}\}Equation. The output message from x to f is the product of the incoming messages. The arrows indicate directions of flow of the message propagation. (B) The factor node f is connected to S node variables, besides x; that is, \mathcal{N}(f) \smallsetminus x = \{ x_{1},x_{2},\ldots,x_{S}\}Equation.](images/B9780443292385000214/gr027.jpg)

**图 15.27** (A) 变量 $x$ 除了 $f$ 之外还连接到 $S$ 个因子节点；即 $\mathcal{N}(x) \smallsetminus f = \{ f_{1},f_{2},\ldots,f_{S}\}$。从 $x$ 到 $f$ 的输出消息是传入消息的乘积。箭头指示消息传播的流向。(B) 因子节点 $f$ 除了 $x$ 之外还连接到 $S$ 个变量节点；即 $\mathcal{N}(f) \smallsetminus x = \{ x_{1},x_{2},\ldots,x_{S}\}$。
