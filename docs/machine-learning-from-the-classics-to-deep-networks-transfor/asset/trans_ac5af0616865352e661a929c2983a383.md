特征向量 `u[1]`、`u[2]` 位于 `X` 的列空间中，即（阴影部分）平面 `span{x[1]^(c), x[2]^(c)}` 内，并构成一组标准正交基。因为 `ŷ` 是 `y` 在该子空间上的投影，所以它可以表示为该标准正交基两个向量的线性组合。线性组合的相应权重为 `u[1]^(T)y` 和 `u[2]^(T)y`。

我们可以进一步利用前面的结果，用 `X^(T)X`（或 `XX^(T)`）的特征值/特征向量来表示伪逆。很容易证明我们可以写成

```
X^† = (X^T X)^(-1) X^T = V_l D^(-1) U_l^T = ∑_{i=1}^l (1/σ_i) v_i u_i^T.
```

事实上，这与线性代数中伪逆的更一般定义一致，该定义也适用于非满秩矩阵（即 `X^(T)X` 不可逆），即

注意，一个包含 `N` 个方程和 `l > N` 个未知数的系统，

```
X θ = y,
```

有无穷多解。这种系统称为*欠定*系统，与 `N > l` 的*超定*系统形成对比。可以证明，对于欠定系统，解 `θ = X^† y` 是具有*最小欧几里得范数*的解。我们将在第 9 章中结合稀疏模型更详细地讨论此类方程组。
