
Employing in [(7.1)](#Chp007_293-342_B9780443292385000135.xhtml#deq1) the Bayes theorem,

$$P(\omega_{j}|\mathbf{x}) = \frac{p(\mathbf{x}|\omega_{j})P(\omega_{j})}{p(\mathbf{x})},\quad j = 1,2,\ldots,M,$$

where $p(\mathbf{x}|\omega_{j})$ are the respective conditional PDFs, the Bayesian classification rule becomes

$$\text{Assign } \mathbf{x} \text{ to } \omega_{i} = \arg\max_{\omega_{j}} p(\mathbf{x}|\omega_{j})P(\omega_{j}),\quad j = 1,2\ldots,M.$$

Note that the probability density function (PDF) of the data, $p(\mathbf{x})$, in the denominator of Eq. [(7.2)](#Chp007_293-342_B9780443292385000135.xhtml#deq2), does not enter in the maximization task, because it is a positive quantity independent of the classes $\omega_{j}$; hence, it does not affect the maximization. In other words, the classifier depends on the a priori class probabilities and the respective conditional PDFs. Also, recall that

$$p(\mathbf{x}|\omega_{j})P(\omega_{j}) = p(\omega_{j}, \mathbf{x}) = p(y, \mathbf{x}),$$

where in the current context, the output variable, $y$, denotes the label associated with the corresponding class $\omega_{i}$. The last equation verifies what was said in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml); that is, the Bayesian classifier is a generative modeling technique.
