

### 5. 生成观测值

**x**[*n*] ∼ 𝒩(**AZ**, *σ*[*η*]²**I**), *n* = 1, 2, …, *N*。

隐变量/潜变量包括：
(a) 棒断长度，*β*[*k*]；
(b) **Z** 的元素；以及
(c) 矩阵 **A** 的元素。

在实践中，采用截断棒断过程，即假设 *P*[*k*] = 0，*k* > *K*。因此，隐变量/潜变量矩阵为 **W** = [**β**, **A**, **Z**]。给定观测集合 𝒳 = {**x**[1], …, **x**[*N*]}，关于未知参数 *α*, *σ*[*A*]² 和 *σ*[*η*]² 待最大化的后验分布为

*p*(**β**, **A**, **Z** | 𝒳; *α*, *σ*[*A*]², *σ*[*η*]²)。

然而，这被证明不具有易处理形式，因此可以采用均场近似技术（例如，[15]）。类似于公式 [(13.123)](#Chp013_635-716_B9780443292385000196.xhtml#deq186)，后验分布变分近似的因子化族由下式给出

```
q(W) = ∏_{k=1}^{K} q_{γ_k}(β_k) ∏_{k=1}^{K} q_{Φ_k}(a_k) ∏_{n=1}^{N} q_{ν_{nk}}(z_{nk})
```
