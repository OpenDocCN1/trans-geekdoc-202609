
![Equation](images/B9780443292385000251/si567.png) (19.67)

where `ϵ` is the vector of noise samples drawn from the standard Gaussian to obtain `x_t` (Eq. [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135)). Recall that the goal of training is to estimate `μ_θ` to optimally predict the corresponding `μ̃_t` in Eq. [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145), given the samples `x_t` as input to the involved neural network. Thus, in [85], it is suggested to use the reparameterization,

```
μ_θ(x_t, t) = (1 / √a_t) (x_t - (β_t / √(1 - ā_t)) ε_θ(x_t, t))
```

![Equation](images/B9780443292385000251/si568.png) (19.68)

where `ε_θ(x_t, t)` is a function approximator (implemented via a neural network) intended to predict `ϵ`, in Eq. [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145), from `x_t`. Plugging Eqs. [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145) and [(19.72)](#Chp019_997-1102_B9780443292385000251.xhtml#deq146) into Eq. [(19.70)](#Chp019_997-1102_B9780443292385000251.xhtml#deq144), the following is obtained

```
L_{t-1} = λ_t ||ε - ε_θ(x_t, t)||²,    λ_t := β_t² / (2 σ_t² a_t (1 - ā_t))
```

![Equation](images/B9780443292385000251/si570.png) (19.69)

where `x_t` is sampled according to Eq. [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135) and `λ_t` is a weighting sequence.
