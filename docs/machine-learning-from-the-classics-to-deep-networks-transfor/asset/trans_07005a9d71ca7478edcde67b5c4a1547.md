对于更一般的 *M* 类分类任务，逻辑回归定义为 *m* = 1, 2, …, *M* 时的

![Equation](images/B9780443292385000135/fx007.jpg) (7.47)

前面的定义很容易转化为后验概率对数比的线性模型形式。例如，除以 `P(ω_M|x)` 可得

```
ln(P(ω_m|x) / P(ω_M|x)) = (θ_m - θ_M)^T x = \hat{θ}_m^T x.
```

为表示方便，我们定义

```
ϕ_nm := P(ω_m|x_n),  n = 1, 2, …, N,  m = 1, 2, …, M,
```

以及

```
t_m := θ_m^T x,  m = 1, 2, …, M.
```

似然函数现在写为

```
P(y; θ_1, …, θ_M) = ∏_{n=1}^N ∏_{m=1}^M (ϕ_nm)^{y_nm},
```
