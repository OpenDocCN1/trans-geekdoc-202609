
**θ**^((*i*)) = *T*[*i*](**θ**^((*i* − 1)) + *Q***e**^((*i* − 1))), **e**^((*i* − 1)) = **y** − *X***θ**^((*i* − 1))

从 **θ**^((0)) 的初始猜测开始（通常 **θ**^((0)) = **0**，**e**^((0)) = **y**）。在某些情况下，*Q* 可以设为与迭代相关。函数 *T*[*i*] 是一种非线性阈值处理，以*逐项*方式应用，即*逐分量*。根据具体方案，这可以是硬阈值函数，记作 *H*[*k*]，也可以是软阈值函数，记作 *S*[*α*]。硬阈值处理，正如我们已知，保留向量中最大的 *k* 个分量不变，并将其余分量设为零。软阈值处理在第 [9.3](#Chp009_417-462_B9780443292385000159.xhtml) 节中已介绍。幅值小于阈值 *α* 的所有分量被强制置零，其余分量的幅值减小 *α*；即向量 **θ** 的第 *j* 个分量，经软阈值处理后变为

```
(S[α](θ))[j] = sgn(θ[j])(|θ[j]| − α)[+].
```
