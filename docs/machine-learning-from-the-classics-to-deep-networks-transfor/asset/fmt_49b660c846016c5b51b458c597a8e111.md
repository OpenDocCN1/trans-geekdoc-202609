
*ω*[*k*] := {*j*[*k*], 1 ≤ *j*[*k*] ≤ *N*: *z*[*k*]^(*r*)(*j*[*k*]) ≠ 0}.

Then, we form the reduced vector ${\\widetilde{\\mathbf{z}}}\_{k}^{r} \\in \\mathbb{R}^{|\\omega\_{k}|}$, where |*ω*[*k*]| denotes the cardinality of *ω*[*k*], which contains only the nonzero elements of **z**[*k*]^(*r*). A little thought reveals that, when writing *X* = *A**Z*, the column of current interest, **a**[*k*], contributes (as part of the corresponding linear combination) only to the columns **x**[*j*[*k*]], *j*[*k*] ∈ *ω*[*k*], of *X*. We then collect the corresponding columns of *E*[*k*] to construct a reduced-order matrix, *Ẽ*[*k*], which comprises the columns that are associated with the locations of the nonzero elements of **z**[*k*]^(*r*), and select $\\mathbf{a}\_{k}{\\widetilde{\\mathbf{z}}}\_{k}^{rT}$ so as to minimize

```
||Ẽ_k - a_k z̃_k^{rT}||_F^2.
```
