
The corresponding junction tree is trivially obtained from the graph in [Fig. 16.15](#Chp016_805-853_B9780443292385000226.xhtml#f0080). Replacing directed links with undirected ones and considering cliques of size two, the graph in [Fig. 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)A results. However, as all the `y[n]` variables are observed (*instantiated*) and no marginalization is required, their multiplicative contribution can be absorbed by the respective conditional probabilities, which leads to the graph of [Fig. 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)B. Alternatively, this junction tree can be obtained if one considers the nodes `(x[1], y[1])` and `(x[n-1], x[n], y[n])`, `n = 2, 3, …, N`, to form cliques associated with the potential functions

```
ψ[1](x[1], y[1]) = P(x[1])p(y[1]|x[1]) (16.36)
```

and

```
ψ[n](x[n-1], y[n], x[n]) = P(x[n]|x[n-1])p(y[n]|x[n]), n = 2, …, N. (16.37)
```

The junction tree of [Fig. 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)B results by eliminating nodes from the cliques starting from `x[1]`. Note that the normalizing constant is equal to one, `Z = 1`.
