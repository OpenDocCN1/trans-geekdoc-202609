
其中 `λ[n]`，`n = 1, 2, …, N[s]`，是与支持向量相关联的非零拉格朗日乘子。在这种情况下，支持向量是指所有位于以下位置的点：(a) 位于定义间隔的那一对超平面上；或 (b) 位于间隔内部；或 (c) 位于间隔外部但在分类器的错误一侧。也就是说，位于间隔外部的正确分类点不参与解的构成，因为对应的拉格朗日乘子为零。对于 RKHS 情况，类别预测规则与公式 [(11.68)](#Chp011_519-582_B9780443292385000172.xhtml#deq157) 相同，其中 `θ̂[0]` 由对应于 `λ[n] ≠ 0` 和 `ξ[n] = 0` 的约束条件计算得出；这些点对应于位于定义间隔的超平面上且在分类器正确一侧的点。

L(θ, θ₀, ξ, λ) = ½‖θ‖² + C∑ₙ₌₁ᴺ ξₙ − ∑ₙ₌₁ᴺ μₙξₙ − ∑ₙ₌₁ᴺ λₙ(yₙ(θᵀxₙ + θ₀) − 1 + ξₙ)
