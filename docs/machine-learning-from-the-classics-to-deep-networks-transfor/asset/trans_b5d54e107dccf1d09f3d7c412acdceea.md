如果将公式 [(13.78)](#Chp013_635-716_B9780443292385000196.xhtml#deq114) 和 [(13.82)](#Chp013_635-716_B9780443292385000196.xhtml#deq119) 中的 max 运算替换为 min 运算，则针对凸函数所述的一切均适用于凹函数。请注意，根据此定义，共轭函数是*凹*的，因为它是一组凹函数逐点最小化的结果（仿射函数可视为凸或凹）。此外，如果涉及的函数既非凸也非凹，则可以寻找使其变为凸或凹的*可逆*变换。

在我们的语境中，引入共轭函数的概念是因为我们期望这种函数（如公式 [(13.83)](#Chp013_635-716_B9780443292385000196.xhtml#deq120) 那样为概率密度函数提供界限）可能会导致一种函数形式，从而使所涉及的积分计算变得易于处理。

### 示例 13.3

计算对数函数 `f(x) = ln x, x > 0` 的共轭。

对数函数已知是凹函数。因此

```
f*(ξ) = min_{x > 0} { ξx - ln x },
```

或

```
x*: 1/x = ξ ⇒ x* = 1/ξ.
```

因此，

`f*(ξ) = 1 + ln ξ`。

所以，

```
ln x = min_{ξ > 0} { ξx - 1 - ln ξ }.
```
