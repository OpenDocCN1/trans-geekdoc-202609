或者仅关注第 `k` 个特征的贡献，我们得到

$X = \lbrack\mathbf{x}_{1},\mathbf{x}_{2},\ldots,\mathbf{x}_{8}\rbrack = \ldots + \mathbf{a}_{k}{\widetilde{\mathbf{z}}}_{k}^{T} + \ldots.$

![Equation](images/B9780443292385000196/si572.png)

考虑到前面给出的行 ${\widetilde{\mathbf{z}}}_{k}^{T}$ 的具体值，从上式很容易看出，特征 `a[k]` 仅由观测值 `x[1]`、`x[4]`、`x[5]` 和 `x[8]` 共享。然而，上述的重要属性在于后四个向量*共享* *相同的* 特征。该特征被称为 `k` 还是 1 或 3 或其他什么，对我们并不重要。这类似于混合建模，在那里人们不关心两个观测值是由（比如说）第一个还是第二个混合成分发射的。重要的是它们是由*同一个*混合成分发射的。给特征贴标签并不重要。关键信息是：一组特定的观测值共享许多*共同*特征。更正式地说，`X` 的结构*不*依赖于 `A` 的列和 `Z` 的对应行出现的顺序。与 `X` 的聚类结构相关的信息对 `A` 和 `Z` 的*排列*是*不变*的。我们现在接近于定义等价类的概念了。
