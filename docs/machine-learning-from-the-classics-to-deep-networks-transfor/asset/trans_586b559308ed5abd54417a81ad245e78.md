### 19.7.4 基于随机微分方程的生成建模

在前面讨论的两种构建扩散模型的方法中，输入数据的扰动是通过*有限*数量的噪声分布来执行的。文献 [173] 提出了一种替代方法，采用一系列*连续*的分布，这些分布根据扩散过程随时间演化。该方法建立在一个随机微分方程 (SDE) 基础之上，该方程将数据点逐步扩散为随机噪声。此外，相应的 SDE 是不可训练的，也不依赖于数据。事实证明，该过程可以通过反向时间 SDE 来逆转，该反向 SDE 将噪声重塑为数据以生成样本。

在不求助于与随机微分方程、随机变量微分、维纳过程和布朗运动相关的严格定义（参见例如 [140]）的情况下，并遵循文献 [173]，（前向）扩散 SDE 写为

```
d**x** = **f**(**x**, t)*dt + g(t)*d**w**,
```

其中 **w** 是标准维纳过程，即布朗运动，**f**(⋅, t) 是决定漂移的向量函数，`g(t)` 是决定 SDE 扩散的函数。文献 [173] 中表明，DDPM 和 NCSN 是该 SDE 不同离散化的结果。已有研究表明 ([4]) 存在一个反向 SDE^([^(145)](#fn145))

```
d**x** = [**f**(**x**, t) - g(t)^2 ∇_**x** ln q_t(**x**)] dt + g(t)*d**w̃**,
```
