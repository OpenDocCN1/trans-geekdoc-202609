
从概率论可知，定义为

$$u := F_x(x)$$

的随机变量 $u$ 在区间 $0 \le u \le 1$ 内呈**均匀分布**，这与 $p(x)$ 的性质无关（参见 [32] 和问题 [14.1](#Chp014_717-754_B9780443292385000202.xhtml#o0010)）。如果进一步假设函数 $F_x$ 存在逆函数 $F_x^{-1}$，则可以写为

$$x = F_x^{-1}(u).$$

因此，遵循相反的推理，可以通过先生成均匀分布 $\mathcal{U}(0, 1)$ 的样本，然后对其应用逆函数 $F_x^{-1}$ 来生成 $p(x)$ 的样本（问题 [14.2](#Chp014_717-754_B9780443292385000202.xhtml#o0015)）。

只要 $F_x$ 存在易于计算的逆函数，此方法效果良好。然而，只有少数概率密度函数（PDF）能“自豪地”拥有解析形式的逆函数。

### 示例 14.1

使用从均匀分布 $\mathcal{U}(0, 1)$ 生成样本 $u[n]$ 的伪随机发生器，生成遵循指数分布的样本 $x[n]$：

$$p(x) = \lambda \exp(-\lambda x), \quad x \ge 0,\ \lambda > 0.$$

我们有

$$F_x(x) = \int_0^x \lambda \exp(-\lambda \tau)\, d\tau = 1 - \exp(-\lambda x).$$

令

$$u := F_x(x)$$

并解出 $x$，得到

$$x = -\frac{1}{\lambda}\ln(1 - u) := F_x^{-1}(u).$$
