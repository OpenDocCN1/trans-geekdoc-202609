# 符号约定

我已努力在全书中保持一致的数学符号。虽然每个符号在文中首次使用前均已定义，但将主要符号汇总在一起供读者参考会更加方便。列表如下：

*   向量用**粗体**字母表示，例如 `x`。
*   矩阵用大写字母表示，例如 `A`。
*   矩阵的行列式表示为 `det{A}` 或 `|A|`。
*   对角线上元素为 `a[1], a[2], …, a[l]` 的对角矩阵表示为 `A = diag{a[1], a[2], …, a[l]}`。
*   单位矩阵表示为 `I`。
*   矩阵的迹表示为 `trace{A}`。
*   随机变量用正体字母表示，例如 `x`，其对应的取值用 `mathmode` 字母表示，例如 `x`。
*   同样，随机向量用正体**粗体**表示，例如 `x`，其对应的取值表示为 `x`。随机矩阵同理，表示为 `X`，其取值表示为 `X`。
*   离散随机变量的概率值用大写 `P` 表示，连续随机变量的概率密度函数（PDF）用小写 `p` 表示。
*   向量假定为列向量。换句话说，

```
x = [x_1; x_2; ...; x_l], or x = [x(1); x(2); ...; x(l)].
```

*   即向量的第 `i` 个元素既可以用下标 `x[i]` 表示，也可以表示为 `x(i)`。
