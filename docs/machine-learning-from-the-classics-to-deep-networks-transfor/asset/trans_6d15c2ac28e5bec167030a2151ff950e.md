
这与公式[(9.8)](#Chp009_417-462_B9780443292385000159.xhtml#deq10)中给出的 LASSO 任务一致。这种表述隐含地假设噪声是有界的，且相应的取值范围由 `ϵ` 控制。可以考虑许多不同的变体。例如，一种可能性是最小化 `∥⋅∥₀` 范数而非 `∥⋅∥₁` 范数，尽管这会失去后者的计算优雅性。另一种途径是将约束中的欧几里得范数替换为另一种范数。

除了噪声的存在，还可以从另一个角度来看待前面的表述。未知参数向量 `θ` 可能并非严格稀疏，但它可能由少数大分量组成，而其余分量很小且接近零，但不一定等于零。这种模型失配可以通过允许 `y` 偏离 `Xθ` 来适应。

在这种稀疏解恢复的宽松设定下，关于 `ℓ₀` 和 `ℓ₁` 解的唯一性和等价性概念不再适用。取而代之，现在变得重要的问题是解的*稳定性*。为此，我们关注计算上具有吸引力的 `ℓ₁` 任务。[定理 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0125) 的对应表述现在如下。

### 定理 9.4

*假设感知矩阵 `X` 满足 `δ₂ₖ < √2 - 1` 的 RIP 条件，对于某个 `k`。则公式[(9.35)](#Chp009_417-462_B9780443292385000159.xhtml#deq73) 的解 `θ*` 满足以下不等式（[22,23]）：*

```
‖θ - θ*‖₂ ≤ C₀k^(-1/2)‖θ - θₖ‖₁ + C₁√ϵ
```
(9.36)

*其中常数 `C₁`、`C₀` 和 `θₛ` 定义见[定理 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0125)。*

这也是一个优雅的结果。如果模型是精确的且 `ϵ = 0`，我们得到公式[(9.32)](#Chp009_417-462_B9780443292385000159.xhtml#deq68)。如果不是，模型中的不确定性（噪声）项越高，我们对解的模糊性就越大。还要注意，对解的模糊性取决于真实模型与 `θₖ` 的偏离程度。如果真实模型是 `k` 稀疏的，不等式右边的第一项为零。`C₁`、`C₀` 的值取决于 `δ₂ₖ`，但它们很小，例如接近五或六 [23]。

这里的重要结论是：*采用 `ℓ₁` 范数及相关的 LASSO 优化来求解逆问题（正如我们在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中指出的，这类问题通常倾向于病态）是稳定的，并且在恢复过程中噪声不会被过度放大*。
