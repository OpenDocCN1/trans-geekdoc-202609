### 备注 2.1

*   将伽马分布中的 `a` 设为整数（通常为 `a = 2`），即得到 *Erlang* 分布。该分布用于模拟排队系统中的等待时间。
*   *卡方* 分布也是伽马分布的一个特例，当我们设定 `b = 1/2` 和 `a = ν/2` 时得到。如果将 `ν` 个平方正态变量相加，就会得到卡方分布。
