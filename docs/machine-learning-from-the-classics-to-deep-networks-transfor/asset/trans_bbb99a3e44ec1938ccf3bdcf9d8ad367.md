

# Transformer 推理过程

一旦通过反向传播算法完成训练，所有未知参数均已被估计并固定。换句话说，我们已经获得了与编码器和解码器部分中所有层和块的所有 `W^(q)`、`W^(k)`、`W^(v)`、`W⁰` 矩阵相关的参数，以及定义所有全连接网络和词汇嵌入矩阵的参数的估计值。

在推理期间，一个词序列被呈现给编码器的输入端，Transformer 网络通过在解码器提供相应的输出来进行响应。让我们专注于我们的翻译示例。

## 步骤 1：输入分词

输入序列“Je suis étudiant”通过词汇和位置嵌入进行分词，并用 `⟨SOS⟩` 和 `⟨EOS⟩` 标记的相应嵌入进行增强，以形成序列 `x[0], x[1], …, x[4]`，该序列被送入第一个编码器块。

## 步骤 2：编码器输出

编码器相应的输出嵌入 `h[0]^(L), h[1]^(L), …, h[4]^(L)` 被送入解码器的所有块中，具体是在各自的编码器-解码器注意力层中。

## 步骤 3：解码器自回归生成

以下子步骤按顺序进行：

### 1. n = 0

解码器输入由 `y[0]` 组成，它被设置为等于对应于 `⟨SOS⟩` 标记的嵌入。解码器通过为输出 `ŷ_0` 分配值来进行响应。该向量的值是条件概率，条件是编码器处的输入序列以及 `⟨SOS⟩` 的嵌入。在 `ŷ_0` 中，经过硬阈值操作后，值最大的元素的维度 `i` 被选中，这被认为是解码器决定的词汇单词的 id。以我们的例子为例，假设决策是正确的，如果单词“I”的词汇索引是 1524，那么 `ŷ_0` 中值最大的维度应该等于 `i = 1524`。

### 2. n = 1

解码器输入由 `y[0], y[1]` 组成，其中 `y[1]` 是与“I”相关的嵌入。解码器将响应一个新的输出向量 `ŷ_1`。经过硬阈值处理后，值最大的元素所关联的维度指示了在此步骤决定的单词的 id。以我们的例子为例，这个维度应该等于 235，因为这是我们假设的单词“am”的 id。
