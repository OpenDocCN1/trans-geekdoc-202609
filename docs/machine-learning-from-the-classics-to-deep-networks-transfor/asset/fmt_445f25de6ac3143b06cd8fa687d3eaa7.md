```
Z = \sum\limits_{x_{j} = 1}^{K}\mu_{f}(x_{j})\mu_{b}(x_{j}).
```

So far, we have considered the computation of marginal probabilities. Let us now turn our attention to their conditional counterparts. We start with the simplest case, for example, to compute `P(x[j]|x[k] = \hat{x}[k])`, `k ≠ j`. That is, we assume that variable `x[k]` has been observed and its value is `\hat{x}[k]`. The first step in computing the conditional is to recover the joint `P(x[j], x[k] = \hat{x}[k])`. This is a normalized version of the respective conditional, which can then be obtained as

```
P(x_{j}|x_{k} = {\widehat{x}}_{k}) = \frac{P(x_{j},x_{k} = {\widehat{x}}_{k})}{P({\widehat{x}}_{k})}.
```

The only difference in computing `P(x[j], x[k] = \hat{x}[k])` compared to the previous computations of the marginals is that now, in order to obtain the messages, we *do not sum* with respect to `x[k]`.
