

## 算法步骤

1.  **ψ**[*k*](*n*) = **θ**[*k*](*n* − 1) + *μ*[*k*] ∑[*m* ∈ 𝒩[*k*]] *c*[*mk*] **x**[*m*](*n*) *e*[*k*, *m*](*n*)
    *   对于复值数据，*e*[*k*, *m*](*n*) → *e*[*k*, *m*]<sup>\*</sup>(*n*)

2.  **结束 For 循环**

3.  **For** *k* = 1, 2, …, *K*
    1.  **θ**[*k*](*n*) = ∑[*m* ∈ 𝒩[*k*]] *a*[*mk*] **ψ**[*m*](*n*)

4.  **结束 For 循环**

*   **结束 For 循环**

## 说明

*   这种 DiLMS 形式称为 **adapt-then-combine (ATC) DiLMS**，因为第一步是更新，随后是组合步骤。

*   在特殊情况 *C* = *I* 下，适应步骤变为：
    **ψ**[*k*](*n*) = **θ**[*k*](*n* − 1) + *μ* **x**[*k*](*n*) *e*[*k*](*n*)
    此时节点**不需要交换**它们的观测值。

*   适应原理如 [Fig. 5.25](#Chp005_177-248_B9780443292385000111.xhtml#f0135) 所示。在时刻 *n*，所有三个邻居交换接收到的数据。若输入向量对应随机信号的一个实现，*u*[*k*](*n*)，则每个链路在每个方向上交换的信息包含两个值（*y*[*k*](*n*), *u*[*k*](*n*)）。在更一般的情况下，输入是联合分布变量的随机向量，所有 *l* 个变量都必须交换。完成消息传递后，进行适应，如 [Fig. 5.25](#Chp005_177-248_B9780443292385000111.xhtml#f0135)A 所示。然后，节点跨链路交换它们获得的估计值 **ψ**[*k*](*n*)，*k* = 1, 2, 3（[Fig. 5.25](#Chp005_177-248_B9780443292385000111.xhtml#f0135)B）。
