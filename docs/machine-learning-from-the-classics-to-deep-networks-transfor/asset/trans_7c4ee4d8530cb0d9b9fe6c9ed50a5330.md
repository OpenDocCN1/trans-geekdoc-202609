
采用前述的三个假设，以及对 **x** 的 *Gaussian* 假设，并遵循与推导 Eq. [(5.40)](#Chp005_177-248_B9780443292385000111.xhtml#deq76) 完全相同的步骤，我们得到

```
Σ[c, n] = Σ[c, n−1] − μΣ[x]Σ[c, n−1] − μΣ[c, n−1]Σ[x]
        + 2μ²Σ[x]Σ[c, n−1]Σ[x] + μ²Σ[x]trace{Σ[x]Σ[c, n−1]}
        + μ²σ[η]²Σ[x] + Σ[ω].
```
(5.75)

注意，如果涉及复数数据，唯一的区别是右边第四项不乘以 2（参见 Problem [5.14](#Chp005_177-248_B9780443292385000111.xhtml#o0075)）。该方程控制 `Σ[c, n]` 的演变，进而可提供超额 MSE 误差。

对于较小的 `μ` 值，会得到一种更方便的形式，此时上式右边的第四项和第五项可以忽略，因为它们相对于 `μΣ[x]Σ[c, n−1]` 很小。此外，在稳态下，`Σ[c, n] = Σ[c, n−1] := Σ[c]`，对两边取迹，我们得到（回顾 `trace{A + B} = trace{A} + trace{B}` 和 `trace{AB} = trace{BA}`）
