
## Example 20.6

[Fig. 20.14](#Chp020_1103-1179_B9780443292385000263.xhtml#f0095) shows a set of data which have been generated via a two-dimensional Gaussian, with zero mean value and covariance matrix equal to

```
\Sigma = \begin{bmatrix} {5.05\ } & {- 4.95} \\ {- 4.95\ } & 5.05 \\ \end{bmatrix}.
```

![Equation](images/B9780443292385000263/si391.png)

The corresponding eigenvalues/eigenvectors are computed as

```
\lambda_1 = 0.05,\quad \mathbf{a}_1 = [1, 1]^T,\quad \lambda_2 = 5.00,\quad \mathbf{a}_2 = [-1, 1]^T.
```

![Equation](images/B9780443292385000263/si392.png)

![Figure 20.14 Data points are distributed around a straight line (one-dimensional subspace) in \mathbb{R}^{2}Equation. The subspace is fully recovered by the PPCA, running the EM algorithm.](images/B9780443292385000263/gr014.jpg)

[Figure 20.14](#Chp020_1103-1179_B9780443292385000263.xhtml#cf1115) Data points are distributed around a straight line (one-dimensional subspace) in $\mathbb{R}^2$. The subspace is fully recovered by the PPCA, running the EM algorithm.

Observe that the data are distributed mainly around a straight line. The EM PPCA algorithm was run on this set of data for $m=1$.

![Equation](images/B9780443292385000263/si11.png)

The resulting matrix $\mathbf{A}$, which now becomes a vector, is

```
\mathbf{a} = [-1.71, 1.71]^T
```

![Equation](images/B9780443292385000263/si393.png)

and $\beta = 0.24$.

![Equation](images/B9780443292385000263/si394.png)

Note that the obtained vector $\mathbf{a}$ points in the direction of the line (subspace) around which the data are distributed.
