### 为什么叫 `k`-SVD？

名字中的 SVD 部分显而易见。然而，读者可能会好奇前面的“`k`”代表什么。正如文献 [4] 所述，该算法可被视为第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章介绍的 `k`-means 算法（[算法 12.1](#Chp012_583-634_B9780443292385000184.xhtml)）的一种推广。在那里，我们可以将代表每个簇的均值视为字典的代码字（原子）。在 `k`-means 学习的第一阶段，给定每个簇的代表后，会执行稀疏编码方案；即每个输入向量被分配到单个簇。因此，我们可以将 `k`-means 聚类视为一种稀疏编码方案，它将一个潜在向量与每个观测值相关联。请注意，每个潜在向量仅有一个非零元素，指向相应输入向量根据到所有簇代表的最小欧氏距离所分配的簇。这是与 `k`-SVD 字典学习的一个主要区别，在后者中，每个观测向量可以与多个原子相关联；因此，相应潜在向量的稀疏度可以大于一。此外，基于输入向量到簇的分配，在 `k`-means 算法的第二阶段，会执行簇代表的更新，并且每个代表仅使用分配给它的输入向量。这在精神上也类似于 `k`-SVD 第二阶段发生的情况。区别在于每个输入观测可能与多个原子相关联。正如文献 [4] 指出的，如果设定 `T[0] = 1`，`k`-means 算法可以从 `k`-SVD 得出。

### 字典学习与字典可识别性

字典学习是通过公式 (20.64)–(20.65) 中的 `ℓ[0]` 范数引入的。在更一般的设定中，字典学习任务表述如下：

```
minimize with respect to A ∈ 𝒜 and Z {||X − AZ||[F]² + λg(Z)}
```
(20.71)

其中 `g(Z)` 是矩阵 `Z` 元素的稀疏性促进函数。例如，

```
g(Z) = ∑_{i=1}^{m} ∑_{j=1}^{N} |Z(i,j)|
```
(20.72)
