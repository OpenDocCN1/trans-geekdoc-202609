
假设 $l = 2$（**x** = [$x_1$, $x_2$]^T)，通过设定 $K = 5$ 以及 $\phi_1(\mathbf{x}) = x_1$、$\phi_2(\mathbf{x}) = x_2$、$\phi_3(\mathbf{x}) = x_1 x_2$、$\phi_4(\mathbf{x}) = x_1^2$、$\phi_5(\mathbf{x}) = x_2^2$，公式 [(11.2)](#Chp011_519-582_B9780443292385000172.xhtml#deq2) 可以转化为公式 [(11.1)](#Chp011_519-582_B9780443292385000172.xhtml#deq1) 的形式。

公式 [(11.2)](#Chp011_519-582_B9780443292385000172.xhtml#deq2) 推广到 $r$ 阶多项式很容易得到，它将包含 $x_1^{p_1} x_2^{p_2} \cdots x_l^{p_l}$ 形式的乘积，其中 $p_1 + p_2 + \cdots + p_l \le r$。结果表明，$r$ 阶多项式的自由参数个数 $K$ 等于

```
K = \frac{(l + r)!}{r! l!}.
```

仅举一例，当 $l = 10$ 且 $r = 3$ 时，$K = 286$。使用多项式展开的依据是魏尔斯特拉斯定理，该定理指出：定义在紧（闭且有界）子集 $S \subset \mathbb{R}^l$ 上的每一个连续函数，都可以用一个多项式函数（例如，[95]）以任意小的误差 $\epsilon$ 进行一致逼近，且逼近程度可任意接近。当然，为了达到足够好的逼近效果，可能不得不使用较大的 $r$ 值。除了多项式函数，还可以使用其他类型的函数，例如样条函数和三角函数。
