
The autocorrelation/covariance matrix (for zero mean processes) of the input random vector has been defined in Eq. [(4.17)](#Chp004_119-175_B978044329238500010X.xhtml#deq26). That is, it is Hermitian as well as positive semidefinite. From now on, we will assume that it is positive definite. The covariance matrix in `ℂ^(m×m)`, associated with a complex wide-sense stationary process, is given by

```
Σ_m = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r(-1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r(-m+1)  r(-m+2)  ⋯     r(0)     ]
    = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r*(1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r*(m-1)  r*(m-2)  ⋯     r(0)     ],
```

where the property

```
r(i) := E[u[n] u[n-i]*] = E[(u[n-i] u[n]*)*] := r*(-i)
```
