## 5.15 Some concluding remarks: consensus matrix

In our treatment of the DiLMS, we used the combination matrices *A* (*C*), which we assumed to be left (right) stochastic. Also, in the performance-related section, we pointed out that some of the reported results hold true if these matrices are, in addition, doubly stochastic. Although it was not needed in this chapter, in the general distributed processing theory, a matrix of significant importance is the so-called *consensus matrix*.
