

# 局部线性嵌入 (LLE)

与拉普拉斯特征映射方法类似，*局部线性嵌入* (LLE) 假设数据点位于一个维度为 *m* 的足够光滑的流形上，该流形嵌入在 $\mathbb{R}^l$ 空间中，且满足 $m < l$ [155]。光滑性假设使我们能进一步假设：只要数据充足且流形采样“良好”，邻近点就会位于（或接近）流形上一个“局部”*线性*区域上（另见第 20.8.3 节的相关评论）。该算法最简单的形式可总结为以下三个步骤：

## 步骤 1：最近邻搜索

对每个点 $\mathbf{x}_n, n = 1,2,\ldots,N$，搜索其最近邻。

## 步骤 2：权重计算

计算权重 $W(n, j), j = 1, 2, \ldots, N$，以便从其最近邻中最佳重构每个点 $\mathbf{x}[n]$，从而最小化代价函数

```
\arg\min_W E_W = \sum_{n=1}^N \left\| \mathbf{x}_n - \sum_{j=1}^N W(n,j)\mathbf{x}_{n_j} \right\|^2,
```

其中 $\mathbf{x}_{n_j}$ 表示第 $n$ 个点的第 $j$ 个邻居。

约束条件：
1. 对于非邻居点，权重被约束为零。
2. 权重矩阵的每行之和为一：

```
\sum_{j=1}^N W(n,j) = 1, \quad n = 1,2,\ldots,N.
```

即，所有邻居的权重之和必须等于一。

## 步骤 3：嵌入

一旦从上一步计算出权重，便利用它们获得对应的点 $\mathbf{z}_n \in \mathbb{R}^m, n = 1,2,\ldots,N$，以最小化关于未知点集 $\mathcal{Z} = \{\mathbf{z}_n, n = 1,2,\ldots,N\}$ 的代价函数。
