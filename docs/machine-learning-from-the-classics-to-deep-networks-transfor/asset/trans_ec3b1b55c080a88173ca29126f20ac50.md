### Mirror descent algorithms

一类与前向-后向优化算法密切相关的算法族可以追溯到文献 [64] 的工作，称为 *mirror descent algorithms*（MDAs，镜像下降算法）。该方法经历了多个演化步骤（例如文献 [9, 66]）。我们的重点将放在采用在线方案来最小化正则化期望损失函数上：

```
J(θ) = 𝔼 [L(θ, y, x)] + ϕ(θ)
```

其中正则化函数 ϕ 被假设为凸函数，但不一定光滑。在该算法类的一个较新代表中，也称为 *regularized dual averaging*（RDA，正则化对偶平均）算法 [100]，主要迭代方程表示为：

```
θ_n = argmin_θ { ⟨L̄', θ⟩ + ϕ(θ) + μ_n ψ(θ) }
``` (8.139)
