
|*f*(**x**[1]) − *f*(**x**[2])| < ||**x**[1] − **x**[2]||, ∀**x**[1], **x**[2] ∈ 𝒳.

![Equation](images/B9780443292385000251/si98.png)

因此，两个分布之间的瓦萨斯坦概率距离，以公式 [(19.17)](#Chp019_997-1102_B9780443292385000251.xhtml#deq33) 的形式给出，即关于所有可能的 1-利普希茨函数，针对这两个分布，均值差异中的“最大值”。

根据公式 [(19.17)](#Chp019_997-1102_B9780443292385000251.xhtml#deq33) 设计 GAN，使得该设置不同于围绕公式 (19.11) 中代价演变而来的设置。目标不再是设计一个二分类器（判别器）来区分真实数据与生成数据，而是设计一个利普希茨函数 *f*。后者通过一组参数 **θ**[*f*]![Equation](images/B9780443292385000251/si99.png) 利用深度神经网络进行参数化，即 *f*(**x**; **θ**[*f*])![Equation](images/B9780443292385000251/si100.png)。通过求解以下任务来估计相应参数：

```
\max\limits_{\mathbf{\theta}_{f}}\left\{ \mathbb{E}_{p_{r}(\mathbf{x})}\ \left\lbrack f(\mathbf{x};\mathbf{\theta}_{f}) \right\rbrack - \mathbb{E}_{p_{\mathbf{z}}(\mathbf{z})}\ \left\lbrack f(G(\mathbf{z};\mathbf{\theta}_{g});\mathbf{\theta}_{f}) \right\rbrack \right\}.
```

![Equation](images/B9780443292385000251/si101.png)

固定参数 **θ**[*f*]![Equation](images/B9780443292385000251/si99.png)，定义生成器的参数 **θ**[*g*]![Equation](images/B9780443292385000251/si102.png) 通过最小化上述括号中的差值来估计。请注意，该梯度仅取决于第二项，因为第一项与 **θ**[*g*]![Equation](images/B9780443292385000251/si102.png) 无关。随着训练过程中损失函数的降低，瓦萨斯坦距离变小，生成器的输出也越来越接近真实数据分布。瓦萨斯坦 GAN 方案概述见 [算法 19.3](#Chp019_997-1102_B9780443292385000251.xhtml#enun0025)。
