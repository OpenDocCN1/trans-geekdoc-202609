
其中利用了给定值 `θ = θ` 时 `x` 关于 `X` 的*条件独立性*，表示为 `p(x|X, θ) = p(x|θ)`。确实，如果给定了 `θ` 的值，那么条件概率 `p(x|θ)` 就完全确定了，且不依赖于 `X`。如果后者未知，`x` 对 `X` 的依赖是通过 `θ` 实现的。公式 [(3.65)](#Chp003_65-117_B9780443292385000093.xhtml#deq116) 通过利用所获观测值中蕴含的信息以及对参数 `θ` 所采用的函数依赖关系，提供了未知 PDF 的估计。请注意，这与我们在 ML 方法中所做的形成对比：在 ML 方法中，我们利用观测值来获得参数向量的估计；而在这里，我们假设参数是随机变量，通过 `p(θ)` 提供关于 `θ` 的先验知识，并对联合 PDF `p(x, θ|X)` 进行关于 `θ` 的积分。

一旦 `p(x|X)` 可用，即可用于预测。假设我们已获得观测值 `x[1], …, x[N]`，那么我们对下一个值 `x[N + 1]` 的估计可以通过 `p(x[N + 1]|X)` 来确定。显然，`p(x|X)` 的形式通常会随着新观测值的获得而改变，因为每当一个观测值变得可用时，我们对潜在随机性的不确定性就有一部分被消除了。

### 示例 3.8

考虑公式 [(3.33)](#Chp003_65-117_B9780443292385000093.xhtml#deq54) 简化的线性回归任务，并假设 `x = 1`。正如我们已经说过的，这个问题是估计埋没在噪声中的常数值。我们的方法将遵循贝叶斯哲学。假设噪声样本是从零均值、方差为 `σ[η]²` 的高斯 PDF 中独立同分布（i.i.d.）抽取的。然而，我们通过先验分布施加关于未知 `θ` 的先验知识：

```
p(θ) = N(θ|θ[0], σ[0]²).
```
