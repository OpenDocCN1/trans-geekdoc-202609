
where `λ[k k] = 0` and `λ[k i]` is the weight that controls the significance of committing an error by assigning a pattern from class `ω[k]` to class `ω[i]`. The *average risk* is given by

```
r = ∑_{k=1}^{M} P(ω_k) r_k = ∑_{i=1}^{M} ∫_{R_i} ( ∑_{k=1}^{M} λ_{ki} P(ω_k) p(x|ω_k) ) dx
```

which is minimized if we partition the input space by selecting each `R_i` (where we decide in favor of class `ω[i]`) so that each one of the *M* integrals in the summation becomes minimum; this is achieved if we adopt the rule

```
Assign x to ω_i: ∑_{k=1}^{M} λ_{ki} P(ω_k) p(x|ω_k) < ∑_{k=1}^{M} λ_{kj} P(ω_k) p(x|ω_k), ∀ j ≠ i
```
