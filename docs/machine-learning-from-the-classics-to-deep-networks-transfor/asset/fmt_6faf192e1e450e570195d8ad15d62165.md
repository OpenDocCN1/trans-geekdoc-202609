
where Eq. [(3.51)](#Chp003_65-117_B9780443292385000093.xhtml#deq91) has been used and the product rule, as stated in Chapter [2](#Chp002_19-64_B9780443292385000081.xhtml), has been exploited. In the sequel, one can take the mean over `x`. In other words, this is the prediction MSE over all possible inputs, averaged over all possible training sets. The resulting MSE is also known as the *test* or *generalization error* and it is a measure of the performance of the respective adopted model. Note that the generalization error in Eq. [(3.53)](#Chp003_65-117_B9780443292385000093.xhtml#deq92) involves averaging over (theoretically) all possible training data sets of certain size `N`. In contrast, the so-called *training error* is computed over a single data set, the one used for the training, and this results in an overoptimistic estimate of the error. We will come back to this important issue in Section [3.13](#Chp003_65-117_B9780443292385000093.xhtml#s0105).

## Example 3.5

Let us consider a simplistic, yet pedagogic, example that demonstrates this tradeoff between bias and variance. We are given a set of training points that are generated according to a regression model of the form

```
y = g(x) + η.
```

The graph of `g(x)` is shown in [Fig. 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045). The function `g(x)` is a fifth-order polynomial. Training sets are generated as follows. For each set, the `x`-axis is sampled at `N` equidistant points `x[n]`, `n = 1, …, N`, in the interval `[-1, 1]`. Then, each training set `D[i]` is created as

```
D[i] = {(x[n], g(x[n]) + η[n, i]): n = 1, 2, …, N},  i = 1, 2, …
```

where `η[n, i]` denotes different noise samples, drawn i.i.d. from a white noise process. In other words, all training points have the same `x`-coordinate but different `y`-coordinates due to the different values of the noise. The gray dots in the `(x, y)`-plane in [Fig. 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045) correspond to one realization of a training set, for the case of `N = 10`. For comparison, the set of noiseless points, `(x[n], g(x[n]))`, `n = 1, 2, …, 10`, is shown as red dots on the graph of `g(x)`.

![Figure 3.7 The observed data are denoted as gray dots. These are the result of adding noise to the red points, which lie on the red curve associated with the unknown g(⋅). Fitting the data by the fixed polynomial f1(x) results in high bias; observe that most of the data points lie outside the straight line. On the other hand, the variance of the “estimator” will be zero. In contrast, fitting a high-degree polynomial f_{2}(x;D)Equation results in low bias, because the corresponding curve goes through all the data points; however, the respective variance will be high.](images/B9780443292385000093/gr007.jpg)
