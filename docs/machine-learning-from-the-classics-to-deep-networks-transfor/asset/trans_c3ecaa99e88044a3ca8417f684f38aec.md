
**p**[*n*] = *P*[*n*](**x**[*n*]|**x**[*n* − 1])**p**[*n* − 1]

其中

**p**[*n*] := [*P*(**x**[*n*] = 1), *P*(**x**[*n*] = 2), …, *P*(**x**[*n*] = *K*)]^(*T*)

:= [*P*[*n*](1), …, *P*[*n*](*K*)]^(*T*)

是时间 *n* 处各概率的向量。如果转移矩阵与时间无关，则称该马尔可夫链为*齐次*或*平稳*，即

*P*[*n*](**x**[*n*] = *i*|**x**[*n* − 1] = *j*) = *P*(*i*|*j*) := *P*[*i**j*], *i*, *j* = 1, 2, …, *K*

以及

*P*[*n*](**x**[*n*]|**x**[*n* − 1]) = *P* = [*P*[*i**j*]].
