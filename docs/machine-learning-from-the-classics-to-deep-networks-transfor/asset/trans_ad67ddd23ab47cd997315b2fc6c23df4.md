
降维随机投影并非新事物，且已在模式识别、聚类和数据挖掘中得到广泛应用（参见例如 [1,13,34,82,87]）。大数据时代的到来重燃了人们对随机投影辅助数据分析算法（例如 [55,81]）的兴趣，主要有两大原因。首先，在低维空间中进行数据处理计算量更轻，因为它涉及的矩阵或向量运算所用参数更少。此外，通过结构良好的矩阵将数据投影到低维空间，其计算成本显著低于通用矩阵-向量乘法所暗示的成本 [29,42]。这些方法所需的计算能力降低，使其在处理海量数据时极具吸引力。第二个原因是存在随机化算法，它们访问数据矩阵的次数（通常为固定次数）远少于常规方法的访问次数 [28,55]。当全部数据无法放入快速内存，必须从硬盘等慢速存储设备分块访问时，这一点至关重要。在这种情况下，计算时间往往主要取决于内存访问的成本。

压缩感知（CS）的核心思想也已在模式识别领域得到利用。在该应用中，完成低维子空间中的信息挖掘活动后，无需返回原始高维空间。由于模式识别的重点在于识别物体/模式的类别，只要不存在与类别相关的信息损失，这项任务就可在观测子空间中完成。文献 [17] 利用压缩感知论据表明，如果数据在原始高维空间中近似线性可分且数据具有稀疏表示（即使是在未知基下），那么随机投影到观测子空间能保留线性可分的结构。

*流形学习* 是随机投影也已应用的另一领域。流形通常是嵌入在高维（环境）空间中的非线性 *k* 维曲面。例如，球面是三维空间中的二维流形。文献 [7,96] 将压缩感知的基本原理推广到位于空间 ℝ^l 的 *k* 维子流形上的信号向量。文中表明，如果选择投影矩阵 *X* 和足够数量 *N* 的观测值，则在投影矩阵 *X* 作用下，相应的子流形在观测子空间中具有稳定嵌入；即成对欧几里得距离和测地距离在投影映射后近似保持不变。更多相关内容可参见所给参考文献及例如 [8]。我们将在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章讨论流形学习任务。

### 9.9.2 次奈奎斯特采样：模拟到信息转换

在前述评论的讨论中，我们涉及了一个非常重要的问题——即从模拟域到离散域的转换。自 Shannon、Nyquist、Whittaker 和 Kotelnikof 的开创性著作发表以来，A/D 转换主题一直处于研究和技术的前沿；例如参见 [92] 以获取详尽的相关综述。我们都知道，如果模拟信号 `s(t)` 的最高频率小于 `F/2`，则 Shannon 定理表明，只要以至少奈奎斯特速率 `F = 1/T` 对信号进行采样（其中 `T` 为相应的采样周期），就不会造成信息损失，并且信号可由其样本完美恢复：

```
s(t) = ∑_n s(nT) sinc(Ft - n),
```

其中 `sinc` 为采样函数：

```
sinc(t) = sin(πt) / (πt).
```

虽然这一直是信号采集设备发展的驱动力，但新兴应用日益增长的复杂性要求越来越高的采样率，这是当今硬件技术无法满足的。例如在宽带通信中，由 Shannon 界决定的转换速度变得越来越难以实现。因此，旨在通过利用信号的*潜在结构*来降低采样率的低速采样替代方案引起了强烈兴趣。例如，在许多应用中，信号仅包含少数频率或频带；参见 [图 9.11](#Chp009_417-462_B9780443292385000159.xhtml#f0065) 以获取示意图。在这种情况下，以奈奎斯特速率采样是低效的。这是一个由许多作者研究的老问题，催生了当频谱中非零频带的位置已知时允许低速采样的技术（参见例如 [61,93,94]）。CS 理论激发了研究，去探讨频带位置（载波频率）事先未知的情况。此类极具实际应用价值的典型应用在于认知无线电领域（例如 [68,88,103]）。
