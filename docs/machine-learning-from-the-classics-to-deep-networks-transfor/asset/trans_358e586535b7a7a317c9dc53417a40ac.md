
$$
\widehat{p}_{n}(\mathbf{x}_{1:n}) = \sum\limits_{i = 1}^{N}W_{n}^{(i)}\delta(\mathbf{x}_{1:n} - \mathbf{x}_{1:n}^{(i)}).
$$

![Equation](images/B9780443292385000238/si85.png)

然而，正如我们已经说过的，权重的方差倾向于随着 `n` 的增加而增大（参见问题 [17.5](#Chp017_855-884_B9780443292385000238.xhtml#o0050)）。因此，通常采用带有重采样的序贯重要性采样。

### 算法 17.3：带重采样的 SIS

*   选择 `q_1(·)`。
*   选择 `q_n(· | ·)`，其中 `n = 1, 2, …`。
*   选择粒子数 `N`。
*   **对于** `i = 1, 2, …, N`，**执行**
    1.  采样 `x_1^{(i)} ~ q_1(x)`。
    2.  计算权重 `w_1(x_1^{(i)}) = phi_1(x_1^{(i)}) / q_1(x_1^{(i)})`。
*   **结束对于**
*   **对于** `i = 1, …, N`，**执行**
    1.  计算归一化权重 `W_1^{(i)}`。
*   **结束对于**
*   重采样 `{x_1^{(i)}, W_1^{(i)}}_{i=1}^N` 以获得 `{\overline{x}_1^{(i)}, 1/N}_{i=1}^N`，使用 [算法 17.1](#Chp017_855-884_B9780443292385000238.xhtml#enun0010)。
