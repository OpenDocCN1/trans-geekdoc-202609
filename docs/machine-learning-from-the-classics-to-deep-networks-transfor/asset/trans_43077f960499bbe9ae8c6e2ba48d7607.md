2. **2.** 通过变换过程 `P`，从集合 `𝒳` 生成一组相应的目标值（伪标签）`𝒯`，即：

```
𝒯 = P(𝒳).
```

1. 例如，`𝒯` 可以包含 BERT 中被掩码标记的独热向量表示。在 GPT 的情况下，`𝒯` 将包含每个时间步待预测的下一个词的独热向量表示。让我们假设，一般来说，`𝒯` 包含 `m` 个向量/目标，即 `𝒯 = {t[1], t[2], …, t[m]}`。毋庸赘言，`m = 1` 是实践中常见的特殊情况。`P` 对输入数据 `𝒳` 的作用由 [图 19.16](#Chp019_997-1102_B9780443292385000251.xhtml#f0085) 中的下分支示意性地展示，它对应于“变换 #2”框。请注意，图中第二个（非线性）网络，记为 `g[ξ]'(⋅)`，由另一组参数 `ξ` 参数化，可选择性地用于（稍后将看到原因）提供最终目标 `𝒯`。

2. **3.** 选择一个解码器，通常称为预测器、预测头或投影器（例如前馈神经网络），将编码器的 `N` 个编码输出 `ℋ` 映射为 `m` 个目标估计值 `T̂ = {t̂_1, t̂_2, …, t̂_m}`，即：

```
T̂ = g_ϕ(ℋ),
```

1. 其中 `ϕ` 是定义投影器/预测器网络的参数集。例如，在 GPT 和 BERT 的情况下，预测器包含最后一个 Transformer 块之上的额外网络，用于将输出转换为概率向量。
