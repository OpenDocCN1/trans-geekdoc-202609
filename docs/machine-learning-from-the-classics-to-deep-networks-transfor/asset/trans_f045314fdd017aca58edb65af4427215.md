
且 `λ` 为正则化参数。集合 `𝒜 ⊆ ℝ^(l×m)` 为紧约束集。例如，通常我们假设 `A` 的列具有单位范数。这保证了*尺度不变性*。确实，假设 `A, Z` 是一个解，若不使用任何约束，对于任意 `c` 值，集合 `A' = (cA), Z' = (1/c Z)` 也将是一个解。其他约束也可用于结合关于可用数据的额外先验知识（参见，例如，[85]）。

在实践中，解决方案包含两个阶段，这与 `k-SVD` 类似。假设在迭代步骤 `i` 时 `A^(i)` 已知，首先进行关于代码向量的最小化，即：

### 阶段 1

```
Z^(i) = min_Z { ||X - A^(i)Z||_F^2 + λ g(Z) }.
```

然后，固定 `Z^(i)`，代码本更新结果为：

### 阶段 2

```
A^(i + 1) = min_{A ∈ 𝒜} ||X - A Z^(i)||_F^2.
```

在最后一个方程中，稀疏促进项不参与其中，因为它与 `A` 无关。假设 `g(Z)` 为凸函数，则在每个阶段求解一个凸优化任务。此类问题被称为*双凸*问题，意指通过固定代价函数中的一个参数，关于另一个参数的优化问题变为凸问题。该优化任务的解可通过不同途径获得；例如，通过极大化-最小化（MM）技术或 ADMM 方案（第 [8.14](#Chp008_343-416_B9780443292385000147.xhtml) 节）；具体应用案例在各种约束条件下可参见，例如，[80, 140, 196]。

求解字典学习任务是一个非凸优化问题。一个重要的相关问题是相关局部极小值的刻画。这一任务是我们所说的*可识别性*的另一面。换句话说，假设存在一个生成数据的字典，能否将其恢复？知道该问题的答案在许多应用中至关重要。例如，在源定位任务中，字典的原子与涉及信号的到达方向相关。此外，在 fMRI 中（参见第 [20.11](#Chp020_1103-1179_B9780443292385000263.xhtml#s0205) 节），字典的原子提供与大脑激活区域相关神经元的时间响应有关的信息。文献 [86] 表明，在与稀疏性相关的特定假设下，字典学习任务中的最小化代价函数以高概率在生成数据的字典周围拥有*有保证的*局部极小值。此外，也推导出了此类极小值存在所需的充分样本数量上界。
