
### 算法步骤

*   **For** `n = 2, 3, …` **Do**
    1.  **For** `i = 1, 2, …, N` **Do**
        *   Draw `x_n^(i) ~ q_n(x | x̄_{1:n-1}^(i))`
        *   Set `x_{1:n}^(i) = {x_n^(i), x̄_{1:n-1}^(i)}`
        *   Compute `w_n(x_{1:n}^(i)) = (1/N) * a_n(x_{1:n}^(i))` (Eq. (17.9))
    2.  **End For**
    3.  **For** `i = 1, 2, …, N` **Do**
        *   Compute `W_n^(i)`
    4.  **End Do**
    5.  Resample `{x_{1:n}^(i), W_n^(i)}[i=1]^N` to obtain `{{x̄_{1:n}^(i), 1/N}}_{i=1}^N`
*   **End For**

### Remarks 17.1

*   Convergence results concerning sequential importance sampling can be found in, for example, [6–8]. It turns out that, in practice, the use of resampling leads to substantially smaller variances.
