
将公式 [(5.76)](#Chp005_177-248_B9780443292385000111.xhtml#deq172) 与公式 [(5.51)](#Chp005_177-248_B9780443292385000111.xhtml#deq92) 进行比较；在当前设定下，存在另一个与噪声相关的项，它使模型围绕其均值漂移。因此，（a）超额均方误差（MSE）是由 LMS 无法精确获得最优值所导致的；（b）存在一个额外的项，用于衡量其“惯性”，即无法足够快地跟踪模型的变化。这是当前讨论得出的最重要结论。在时变环境中，失调度会增加。此外，观察公式 [(5.76)](#Chp005_177-248_B9780443292385000111.xhtml#deq172) 以及 `μ` 的影响，可以发现 `μ` 的较小值对第一项有有利影响，但会增加第二项的贡献。对于相对较大的 `μ` 值，情况则相反。这是很自然的。小步长使算法有机会在平稳环境下更好地学习，但算法无法足够快地跟踪变化。因此，`μ` 的选择应是权衡的结果。将公式 [(5.76)](#Chp005_177-248_B9780443292385000111.xhtml#deq172) 中的超额误差最小化，很容易得到

```
\mu_{\text{opt}} = \sqrt{\frac{\text{trace}\{\Sigma_{\omega}\}}{\sigma_{\eta}^{2}\text{trace}\{\Sigma_{x}\}}}.
```

![Equation](images/B9780443292385000111/si456.png)

然而请注意，这种 `μ` 的选择仅具有理论意义。在实践中，系统的时变特性几乎不可能与所采用的模型相对应；由于分析的复杂性，后者被选择为一个简单的模型，以简化数学运算。此外，为了简化分析，采用了许多假设。在实践中，`μ` 的选择更多地基于用户的实践经验（经过实验），而非基于理论。然而，理论已经指出了收敛速度与跟踪速度之间的权衡。

关于非平稳环境下在线/自适应方案性能的更严格数学分析，可参考文献 [16,38,47,61,70,83]。第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章的 [示例 6.3](#Chp006_249-291_B9780443292385000123.xhtml) 中给出了演示 LMS 与其他算法跟踪性能对比的仿真结果，该章介绍了递归最小二乘（RLS）算法。

## 5.13 分布式学习：分布式 LMS

我们的关注点现在转向一个在过去几年中日益重要的问题。越来越多的应用场景中，数据由不同的传感器/数据集接收或驻留，这些传感器/数据集在空间上是分布式的。然而，所有这些空间分布式信息都必须被利用以实现一个共同目标，即执行一项*共同估计/推理*任务。我们将此类任务称为*分布式*或*去中心化*学习。该问题的核心在于*协作*的概念，这是交换学习经验/信息以达成共同目标/决策的过程的另一种说法。人类社会因协作而生存（因缺乏协作而消亡）。

分布式学习在许多生物系统中很常见，其中没有单个个体/智能体处于主导地位，但群体表现出高度的智能（我们人类称之为本能）。例如，观察鸟群编队飞行和蜂群迁徙筑巢的方式。

除了社会学和生物学，科学和工程也利用了分布式学习的概念；*无线传感器网络*（WSN）就是一个典型例子。WSN 最初被建议作为空间分布式自主传感器，用于监测物理和环境条件，如压力、温度和声音，并协作将其数据传递给中心单元。虽然 WSN 最初是由军事应用驱动的，但如今它们面向多种多样的应用，如交通控制、国土安全与监视、医疗保健和环境建模。每个传感器节点都配备了板载处理器，以便在本地执行一些简单的处理并传输所需的*部分*处理后的数据。由于能量和带宽限制，传感器/节点的特点是处理、存储和通信能力较低 [1,104]。

分布式学习应用的其他典型例子包括对社交网络中个体关联方式的建模与研究、复杂电网上路径的建模、认知无线电系统以及模式识别；所有这些应用的共同特征是数据在每个单独的节点/智能体中被*部分*处理，处理后的信息按照*某种协议*传递给网络。

不熟悉的读者可能会问的一个显而易见的问题是：为什么不只使用一个节点/智能体及其本地驻留的信息来执行推理任务。当然，答案是我们可以通过利用整个网络中可用的数据/信息获得更好的估计/结果。这引出了*共识*的概念。

根据《美国传统词典》，“共识”被定义为“一个群体作为一个整体所达成的意见或立场”；即共识是保证群体内部达成“被接受的一致”的过程。“被接受的一致”这一术语并非唯一定义。在某些情况下，这可能指*一致*决定；在其他情况下，它指*多数表决*规则。在某些情况下，所有智能体的意见权重相等，而在其他情况下，则根据某些相对重要性度量施加不同的权重。然而，在所有情况下，任何基于共识的过程的本质都是相信与每个智能体/个人单独行动的过程相比，能达成一个“更好”的决定。

在本节中，我们关注*参数估计*任务。每个单独的智能体通过数据的“本地”采集过程获取部分信息。虽然每个智能体访问不同的数据集，但它们共享一个共同目标，即估计*同一组*未知参数。该任务将以协作方式完成。然而，可以采用不同的协作场景。
