
其中 `μ` 是 `x` 的均值，`A ∈ ℝ^(l×m)` 由称为*因子载荷*的权重 `a[i][j]` 构成。变量 `z[j]`，`j = 1, 2, …, m`，有时被称为*公因子*，因为它们对所有观测变量 `x[i]` 都有贡献，而 `ϵ[i]` 则是*独特*或*特定因子*。正如我们迄今为止所做的那样，且不失一般性，我们将假设数据已中心化，即 `μ = 0`。在因子分析中，我们假设 `ϵ[i]` 均值为零且互不相关，即 `Σ[ϵ] = 𝔼[ϵϵ^T] := diag{σ[1]², σ[2]², …, σ[l]²}`。我们还假设 `z` 和 `ϵ` 相互独立。`A` 的 `m` (`< l`) 个列向量构成一个低维子空间，而 `ϵ` 是不包含在该子空间中的 `x` 的那部分。现在提出的第一个问题是，公式 [(20.79)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq113) 中的模型是否与我们熟悉的回归任务有任何不同。答案是肯定的。请注意，此处矩阵 `A` 是未知的。我们仅拥有观测样本集 `x[n]`，`n = 1, 2, …, N`，我们必须求出由 `A` 描述的子空间。这基本上是本章迄今为止所考虑的同一个线性模型，区别在于现在我们引入了噪声项。一旦 `A` 已知，就可以为每个 `x[n]` 求得 `z[n]`。

从公式 [(20.79)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq113) 可以很容易地看出

```
Σ[x] = 𝔼[xx^T] = A𝔼[zz^T]A^T + Σ[ϵ].
```

我们将进一步假设 `𝔼[zz^T] = I`；因此，我们可以写成

```
Σ[x] = AA^T + Σ[ϵ]. (20.80)
```
