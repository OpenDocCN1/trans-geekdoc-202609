
令 $C = \max_n \|\mathbf{x}_n\|$，$\mu = \beta / C^2$，$0 < \beta < 2$。则由[算法 5.1](#Chp005_177-248_B9780443292385000111.xhtml#enun0025)生成的预测集合 $\hat{y}_0, \dots, \hat{y}_{N-1}$ 满足以下界限：

$$
\sum_{n=0}^{N-1} (y_n - \hat{y}_n)^2 \leq \inf_{\boldsymbol{\theta}} \left\{ \frac{C^2 \|\boldsymbol{\theta}\|^2}{2\beta(1-\beta)c} + \frac{\mathcal{L}(\boldsymbol{\theta}, S)}{(2-\beta)^2 c(1-c)} \right\}, \tag{5.54}
$$

其中 $0 < c < 1$ 且

$$
\mathcal{L}(\boldsymbol{\theta}, S) = \sum_{n=0}^{N-1} \left( y_n - \boldsymbol{\theta}^T \mathbf{x}_n \right)^2, \tag{5.55}
$$

其中 $S = \{(y_n, \mathbf{x}_n), \ n = 0, 1, \dots, N-1\}$。
