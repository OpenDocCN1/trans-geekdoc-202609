
# 6.3 Statistical properties of the LS estimator

Some of the statistical properties of the LS estimator were touched upon in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml), for the special case of a random real parameter. Here, we will look at this issue in a more general setting. Assume that there exists a true (yet unknown) parameter vector `θ[o]` that generates the output (dependent) random variables (stacked in a random vector `y ∈ ℝ^(N)`), according to the model

```
y = Xθ[o] + η
```

where `η` is a *zero* mean noise vector. Observe that we have assumed that `X` is fixed and not random; that is, the randomness underlying the output variables `y` is due solely to the noise. Under the previously stated assumptions, the following properties hold.

## The LS estimator is unbiased

The LS estimator for the parameters is given by

```
θ̂_LS = (X^T X)^(-1) X^T y = (X^T X)^(-1) X^T (X θ_o + η) = θ_o + (X^T X)^(-1) X^T η
```
