
Let **σ**[*M*] denote the vector containing all the singular values of *M*, that is, **σ**[*M*] = [*σ*[1], *σ*[2], ⋯, *σ*[*l*]]^(*T*). Then *r**a**n**k*(*M*) = ∥**σ**[*M*]∥[0]. Counting the parameters associated with the singular values and vectors in Eq. [(20.119)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq181), it turns out that the number of degrees of freedom of an *r*-rank matrix is equal to *d*[*M*] = *r*(*l*[1] + *l*[2]) − *r*² ([Problem 20.8](#Chp020_1103-1179_B9780443292385000263.xhtml#o0110)). When *r* is small, *d*[*M*] is much smaller than *l*.

Let us denote by Ω the set of *N* pairs of indices, (*i*, *j*), *i* = 1, 2, …, *l*[1], *j* = 1, 2, …, *l*[2], of the locations of the known entries of *M*, which have been sampled uniformly at random. Adopting a similar rationale to the one running across the backbone of sparsity-aware learning, one would attempt to recover *M* based on the following rank minimization problem:

```
\min\limits_{\widehat{M} \in \mathbb{R}^{l_{1} \times l_{2}}}\left\| \mathbf{\sigma}_{\widehat{M}} \right\|_{0},\text{s.t.}\widehat{M}(i,j) = M(i,j),\quad(i,j) \in \Omega.
```

(20.120)

It turns out that assuming there exists a unique low-rank matrix having as elements the specific known entries, the task in [(20.120)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq182) leads to the exact solution [33]. However, compared to the case of sparse vectors, in the matrix completion problem the uniqueness issue gets much more involved. The following issues play a crucial part concerning the uniqueness of the task in [(20.120)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq182).

1.  **1.** If the number of known entries is lower than the number of degrees of freedom, that is, *N* < *d*[*M*], then there is no way to recover the missing entries whatsoever, because there is an infinite number of low-rank matrices consistent with the *N* observed entries.
