
其中 `σ[n]` 是由相应的 *m* 个方差组成的向量，⊙ 表示逐元素乘法。要抽取潜在变量的样本，即 `z[n]^(k)`，*k* = 1, 2, …，只需抽取辅助变量的相应样本 `ϵ^(k)` 即可。因此，在抽取 *K* 个连续样本后，公式 [(19.22)](#Chp019_997-1102_B9780443292385000251.xhtml#deq47) 中损失函数的第一项可以用相应的样本均值来近似，即

```
A_n := E_q[ln p(x_n|z;θ)] = (1/K) ∑_{k=1}^K ln p(x_n|z_n^(k);θ)
```

其中

```
z_n^(k) = μ_n + σ_n ⊙ ϵ^(k).
```

回顾条件概率 *p* 是高斯分布，其对数可以直接计算。项 `A[n]` 是 `θ` 和 `ϕ` 的函数（通过 `μ[n]` 和 `σ[n]`）。使用重参数化技巧，相关估计量的方差大幅降低。因此，*K* 不需要取很大的值。实际上，仅抽取一个样本，即 *K* = 1，在大多数情况下似乎就足够了。
