
Hessian 矩阵也是正定的，这保证了极小值的唯一性，就像在二分类情况下一样。

## 备注 7.4

*   **Probit 回归**：除了在公式 [(7.30)](#Chp007_293-342_B9780443292385000135.xhtml#deq56) 中使用 logistic sigmoid 函数（用于二分类情况）外，还可以采用其他函数。统计学界常用的一个函数是 *probit* 函数，其定义为

```
Φ(t) := ∫_{-∞}^{t} N(z|0,1) dz = 1/2 (1 + 1/√2 erf(t))
```

![Equation](images/B9780443292385000135/si202.png)(7.53)

*   其中 `erf` 是*误差*函数，定义为

```
erf(t) = 2/√π ∫_{0}^{t} exp(-z²/2) dz
```

![Equation](images/B9780443292385000135/si203.png)

*   换句话说，`P(ω₁|t)` 被建模为等于一个标准化高斯变量落在区间 (−∞, t] 内的概率。probit 函数的图形与 logistic 函数的图形非常相似。

## 7.7 Fisher 线性判别

我们现在将重点转向设计线性分类器。换句话说，无论每个类别中的数据分布如何，我们决定利用超平面来划分空间，超平面定义为

```
g(x) = θᵀx + θ₀ = 0
```

![Equation](images/B9780443292385000135/si206.png)(7.54)

我们已经在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中在 LS 方法的框架内处理了设计线性分类器的任务。在本节中，未知参数向量将通过一条路径来估计，该路径利用了许多与分类相关的重要概念。该方法称为 *Fisher 判别*，并且可以用不同的解释来包装。

因此，它的意义不仅在于其实际用途，还在于其教学价值。在介绍该方法之前，让我们先讨论一些与描述输入模式的特征选择相关的问题，以及一些可以量化所选特征集“优劣”的相关度量。
