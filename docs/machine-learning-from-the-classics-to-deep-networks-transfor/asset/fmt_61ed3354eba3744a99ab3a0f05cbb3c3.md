
One of the first attempts to develop an efficient MKL scheme is the one presented in [65], where the authors considered a linear combination of kernel matrices, that is, $K = \sum_{m = 1}^{M}a_{m}K_{m}$.

Because we require the new kernel matrix to be positive definite, it is reasonable to impose in the optimization task some additional constraints. For example, one may adopt the general constraint $K \succeq 0$ (the inequality indicating semidefinite positiveness), or a stricter one, for example, $a_{m} > 0$, for all $m = 1, \dots, M$. Furthermore, one needs to bound the norm of the final kernel matrix. Hence, the MKL SVM task can be cast as

```
minimize with respect to K ω_C(K), subject to K ⪰ 0, trace{K} ≤ c,
```

where $\omega_{C}(K)$ is the solution of the dual SVM task, given in Eqs. (11.86)–(11.88), which can be written in a more compact form as

$$
\omega_{C}(K) = \max_{\mathbf{\lambda}}\left\{ \mathbf{\lambda}^{T}\mathbf{1} - \frac{1}{2}\mathbf{\lambda}^{T}G(K)\mathbf{\lambda}: 0 \leqslant \lambda_{i} \leqslant C, \mathbf{\lambda}^{T}\mathbf{y} = 0 \right\},
$$

with each element of $G(K)$ given as $[G(K)]_{i,j} = [K]_{i,j}y_{i}y_{j}$; $\mathbf{\lambda}$ denotes the vector of the Lagrange multipliers and $\mathbf{1}$ is the vector having all its elements equal to one. In [65], it is shown how (11.92) can be transformed to a semidefinite programming (SDP) optimization task and solved accordingly.
