### 13.12.3 分类

与回归任务相反，在噪声和所涉及随机过程均服从高斯假设的情况下，分类任务变得更为复杂。在第[13.7](#Chp013_635-716_B9780443292385000196.xhtml#s0060)节中，采用了公式[(13.68)](#Chp013_635-716_B9780443292385000196.xhtml#deq99)给出的参数形式的逻辑回归。在高斯过程的背景下，模型变为

$$P(\omega_{1}|\mathbf{x}) = \frac{1}{1 + \exp\left( - f(\mathbf{x}) \right)} = \sigma\left( f(\mathbf{x}) \right),$$

其中 `f(x)` 现在将被视为一个高斯随机过程，与核函数 `κ(⋅, ⋅)` 相关联。给定一组训练样本 `(y[n], x[n])`，`n = 1, 2, …, N`，`y[n] ∈ {0, 1}`，并遵循第[13.7](#Chp013_635-716_B9780443292385000196.xhtml#s0060)节中的相同论证，我们现在可以写出

$$P(\mathbf{y}|\mathbf{f}) = \prod\limits_{n = 1}^{N}\sigma{(f_{n})}^{y_{n}}{(1 - \sigma(f_{n}))}^{1 - y_{n}},$$

其中 `f[n] := f(x[n])`，且

$$p(\mathbf{f}) = \mathcal{N}(\mathbf{f}|0, \mathcal{K}).$$
