
• 如果超平板坍缩为超平面（`ϵ = 0`）且 `q = 1`，该算法将变为 NLMS。确实，对于这种情况，公式 [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74) 中的投影变为由 (`y[n]`，`x[n]`) 定义的超平面 `H` 上的投影，即

```
x[n]^(T)θ = y[n],
```

• 并且根据公式 [(8.11)](#Chp008_343-416_B9780443292385000147.xhtml#deq26)，在进行适当的符号调整后，我们得到

```
P_H(θ_{n - 1}) = θ_{n - 1} - (x_n^T θ_{n - 1} - y_n) / (||x_n||^2) x_n. (8.42)
```

• 将公式 [(8.43)](#Chp008_343-416_B9780443292385000147.xhtml#deq84) 代入公式 [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74)，我们得到

```
θ_n = θ_{n - 1} + (μ_n / ||x_n||^2) e_n x_n,
e_n = y_n - x_n^T θ_{n - 1},
```

• 这就是第 [5.6.1](#Chp005_177-248_B9780443292385000111.xhtml) 节介绍的归一化 LMS。
