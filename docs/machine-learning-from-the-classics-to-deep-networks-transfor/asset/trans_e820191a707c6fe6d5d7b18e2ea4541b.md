

### 10.4.4 稀疏自适应投影子梯度法 (SpAPSM)

APSM 算法族在第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章中介绍，作为在线/自适应学习中最流行的技术之一。正如该章所指出的，该算法族的一大优势在于可以轻松地融入凸约束。在第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章中，APSM 被用作基于平方误差和代价函数的方法（如 LMS 和 RLS）的替代方案。APSM 背后的基本原理是：假设数据由回归模型生成，未知向量可以通过寻找由数据点定义的一系列超薄板的交集中的一点来估计，即 `S_n[ε] := {θ ∈ ℝ^l : |y[n] − x[n]^T θ| ≤ ε}`。此外，还指出当噪声有界时，这种模型非常自然。在处理稀疏向量时，存在一个我们希望解满足的额外约束，即 `‖θ‖_1 ≤ ρ`（另见 LASSO 公式 [(9.7)](#Chp009_417-462_B9780443292385000159.xhtml)）。这项任务非常契合 APSM 的基本原理，基本递归可以直接写出，无需太多思考或推导，如下所示。对于任意选取的初始点 `θ[0]`，定义 ∀`n`，
