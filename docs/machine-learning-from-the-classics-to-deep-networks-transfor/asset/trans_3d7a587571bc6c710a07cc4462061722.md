
对于特定的 `λ ≥ 0` 和 `ρ` 的选择，这两个任务是等价的。请注意，这个新的代价函数 `L(θ, λ)` 包含一项用于度量模型的*拟合优度*（或称*misfit*，即误差），另一项用于量化参数向量范数的*大小*。很容易看出，对 Eq. [(3.41)](#Chp003_65-117_B9780443292385000093.xhtml#deq74) 中的 `L` 关于 `θ` 求梯度并令其为零，我们可以得到 Eq. [(3.13)](#Chp003_65-117_B9780443292385000093.xhtml#deq16) 线性回归任务的 LS 解的*正则化版本*，

```
(∑_{n=1}^{N} x_n x_n^T + λ I) θ̂ = ∑_{n=1}^{N} y_n x_n,
```
(3.42)

其中 `I` 是维度适当的单位矩阵。`λ` 的存在使得新解偏离了从未正则化的 LS 公式中获得的解。该任务也称为*岭回归*。岭回归试图减小估计向量的范数，*同时*尽量保持平方误差和较小；为了实现这一*组合*目标，向量分量 `θ[i]` 会被修改，使得来自输入空间中信息量较小方向的拟合优度测量项中的贡献被最小化。换句话说，那些与信息量较小方向相关的分量将被推向较小的值，以保持范数较小，同时对拟合优度测量项产生最小影响。我们将在第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章更详细地回到这个问题。岭回归最早见于文献 [18]。

必须强调的是，在实践中，偏置参数 `θ[0]` 通常不包含在正则化项的范数中；惩罚偏置会使该过程依赖于为 `y` 选取的原点。确实，很容易验证，如果在代价函数中将常数项加到每个输出值 `y[n]` 上，若偏置项包含在范数中，预测值不会仅仅发生相同常数的平移。因此，通常岭回归被表述为

```
minimize L(θ, λ) = ∑_{n=1}^{N} (y_n - θ_0 - ∑_{i=1}^{l} θ_i x_{ni})^2 + λ ∑_{i=1}^{l} |θ_i|^2.
```
(3.43)
