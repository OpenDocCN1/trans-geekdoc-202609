
## 仿真验证

我们现在通过一些仿真来演示前面的理论发现。为此，模型的真实值被选为 `θ[o] = 10^(−2)`。噪声为零均值、方差为 `σ[η]² = 0.1` 的高斯噪声。生成的独立同分布样本数为 `N = 100`。注意，与我们要估计的单个参数相比，这个数量相当大。前述值意味着 `θ[o]² < σ[η]²/N`。然后可以证明，对于任意 `λ > 0`，我们都能得到 `MSE(θ̂[b](λ))` 的值，该值小于 `MSE(θ̂[MVU])`（见习题 [3.12](#Chp003_65-117_B9780443292385000093.xhtml#o0065)）。这由 [表 3.1](#Chp003_65-117_B9780443292385000093.xhtml#t0010) 中所示的数值验证。

为了计算表中的 MSE 值，公式 [(3.21)](#Chp003_65-117_B9780443292385000093.xhtml#deq36) 定义中的期望运算由相应的样本均值近似。为此，实验重复了 `L` 次，MSE 计算如下：

```
MSE ≈ (1/L) ∑_{i=1}^{L} (θ̂_i - θ_o)²
```

为了获得准确的结果，我们进行了 `L = 10⁶` 次试验。无约束最小二乘任务对应的 MSE 值等于 `MSE(θ̂[MVU]) = 1.00108 × 10^(−3)`。观察到尽管训练数据量相对较大，使用正则化仍可获得显著改进。

### 表 3.1 岭回归在不同正则化参数下达到的 MSE 值

| λ | MSE(θ̂[b](λ)) |
| --- | --- |
| 0.1 | 9.99082 × 10^(−4) |
| 1.0 | 9.79790 × 10^(−4) |
| 100.0 | 2.74811 × 10^(−4) |
| λ* = 10³ | 9.09671 × 10^(−5) |

无约束最小二乘估计达到的 MSE 为 `MSE(θ̂[MVU]) = 1.00108 × 10^(−3)`。
