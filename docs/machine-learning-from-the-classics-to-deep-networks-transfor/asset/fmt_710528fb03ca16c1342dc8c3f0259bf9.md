## Algorithm 19.5

**Sampling of the DDPM reverse process**

*   `x_T` ∼ 𝒩(0, I); Sample from the standard Gaussian.
*   **For** `t = T, T − 1, …, 2`, **Do**
    1.  `z` ∼ 𝒩(0, I); Sample from the standard Gaussian.
    2.  `x_{t-1} = (1/√a_t)(x_t - β_t/√(1 - ā_t) ε_θ*(x_t, t)) + σ_t z`; Eq. [(19.75)](#Chp019_997-1102_B9780443292385000251.xhtml#deq149)
*   **End For**
