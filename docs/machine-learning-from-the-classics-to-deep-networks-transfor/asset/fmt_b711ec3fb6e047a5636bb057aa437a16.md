
# 训练分类器

确定了数据表示的输入空间后，接下来需要训练一个分类器，即预测器。这首先通过选取一组已知类别的 *N* 个数据点/样本/示例来实现，这组数据构成了**训练集**。这是一个观测对集合，(*y*[*n*], **x**[*n*])，*n* = 1, 2, …, *N*，其中 *y*[*n*] 是表示 **x**[*n*] 所属类别的（输出）变量，称为对应的**类标签**；类标签取自一个**离散**集合，例如 {1, 2, …, *M*}，用于 *M* 分类任务。例如，对于二分类任务，*y*[*n*] ∈ {−1, +1} 或 *y*[*n*] ∈ {0, +1}。为简化讨论，我们重点关注二分类情况。

基于训练数据，设计一个函数 *f*，用于根据输入特征向量 **x** 预测输出标签。一般来说，可能需要设计一组这样的函数。

一旦函数 *f* 设计完成，系统即可进行预测。给定一个类别未知的模式，我们从原始数据中获取对应的特征向量 **x**。根据 *f*(**x**) 的值，将该模式分到两个类别之一。例如，若标签取值为 ±1，则预测标签为 *ŷ* = *sgn*{*f*(**x**)}。该操作定义了**分类器**。若函数 *f* 为线性（非线性），则称相应分类任务为线性（非线性），或略微滥用术语称分类器为线性（非线性）分类器。

[图 1.1](#Chp001_1-17_B978044329238500007X.xhtml#f0010) 说明了分类任务。最初给定一组点，每个点代表二维空间（使用两个特征 *x*[1], *x*[2]）中的一个模式。星号属于一类，叉号属于另一类，构成二分类任务。这些是用于获得分类器的训练点。对于这个简单情况，通过一个线性函数实现：

```
f(x) = θ[1]x[1] + θ[2]x[2] + θ[0]
```

(1.1)

其图像（即满足 *f*(**x**) = 0 的所有点）是图中所示的直线。参数 *θ*[1], *θ*[2], *θ*[0] 的值通过基于训练集的估计方法获得。这一估计分类器的阶段，也称为**训练**或**学习**阶段。
