

## 4.6 MSE 线性滤波：频域观点

现在让我们将注意力转向更一般的情况，并假设我们的滤波器是*无限冲激响应*（IIR）的。此时，公式 [(4.41)](#Chp004_119-175_B978044329238500010X.xhtml#deq63) 变为

```
d̂_n = ∑_{i=-∞}^{+∞} w_i u_{n-i}.
```

此外，我们允许该滤波器为*非因果*。^([^(20)](#fn20))

正交性条件推广为（涉及无限多项）：

```
∑_{i=-∞}^{+∞} w_i E[u_{n-i} u_{n-j}] = E[d_n u_{n-j}], j ∈ ℤ.
```

重新排列各项后得到

```
∑_{i=-∞}^{+∞} w_i r(j - i) = r_{du}(j), j ∈ ℤ.
```

### 关键定义

*   输出由 `d̂[n] = w^H u[n]` 给出。
*   `p = E[u[n] d[n]^*]`
*   `Σ_u = E[u[n] u[n]^H]`
*   `r(-k) = r^*(k)`
