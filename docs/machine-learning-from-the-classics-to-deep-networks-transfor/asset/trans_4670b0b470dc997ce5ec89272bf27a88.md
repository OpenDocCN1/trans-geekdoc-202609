两类中的点变得线性可分。然而请注意，映射后，这些点位于一个抛物面的表面上。该表面完全由两个自由变量来描述。宽泛地说，我们可以认为数据最初所在的二维平面被折叠/变换形成了抛物面的表面。这基本上就是更一般问题背后的思想。经过从原始 *l* 维空间到新 *K* 维空间的映射后，点 **ϕ**(**x**[*n*])， *n* = 1, 2, …, *N* 的像位于 ℝ^(*K*) 中的一个 *l* 维曲面（**流形**）。我们无法欺骗自然。因为最初选择了 *l* 个变量来描述每个模式（维度、自由参数的数量），所以在 ℝ^(*K*) 中映射后，描述同一对象仍需要相同数量的自由参数。换句话说，映射后，我们将一个 *l* 维流形嵌入到 *K* 维空间中，使得两类数据变得线性可分。

到目前为止，我们已充分论证了通过一组非线性函数将任务从原始低维空间映射到高维空间的必要性。然而，在高维空间中工作并非易事。需要大量参数；这反过来又带来了计算复杂度问题，并引发了与设计预测器的泛化和过拟合性能相关的问题。在后续内容中，我们将通过向具有特定结构的高维空间进行“谨慎”映射来解决前一个问题。后一个问题将通过正则化来解决，这在前面各章的各个部分已经讨论过。
