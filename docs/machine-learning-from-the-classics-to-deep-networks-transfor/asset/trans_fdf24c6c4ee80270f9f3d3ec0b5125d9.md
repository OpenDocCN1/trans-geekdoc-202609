现在让我们考虑 $p = q = 0$ 的情况。此时 $I(0; 0) = 1$ 比特，这等于 $I(x = 0)$，因为输出能确定地指明输入。另一方面，如果 $p = q = 1/2$，则 $I(0; 0) = 0$ 比特，因为噪声可以以相等的概率随机改变极性。如果现在 $p = q = 1/4$，则 $I(0;0) = \log_{2}\frac{3}{2} = 0.587$ 比特且 $I(1; 0) = -1$ 比特。请注意，互信息也可以取负值。
