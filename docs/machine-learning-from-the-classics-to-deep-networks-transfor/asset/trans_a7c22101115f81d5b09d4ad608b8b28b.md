**θ**[*]*^(*T*)**x** = 0，

使得

**θ**[*]*^(*T*)**x** > 0，若 **x** ∈ *ω*₁，**θ**[*]*^(*T*)**x** < 0，若 **x** ∈ *ω*₂。
