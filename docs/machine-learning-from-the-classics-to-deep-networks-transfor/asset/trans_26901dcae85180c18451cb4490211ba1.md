换句话说，每一对新向量的计算都使其归一化（公式 [(20.36)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq46)），同时每个向量都与之前迭代步骤中获得的向量正交（广义上的正交）（公式 [(20.37)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq47) 和 [(20.38)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq48)）。请注意，这保证了推导出的典型变量与所有先前推导出的典型变量不相关。这让人联想到 PCA 中主成分的不相关性质。CCA 中唯一的非零相关性，即在每个迭代步骤中被最大化的相关性，是 *z*[*x*, *k*] = **u**[*x*, *k*]^(*T*)**x** 和 *z*[*y*, *k*] = **u**[*y*, *k*]^(*T*)**y** 之间的相关性，*k* = 1, 2, …, *m*。

更多关于 CCA 的内容可参阅文献 [6,26]。在再生核希尔伯特空间中的 CCA 扩展也已被开发并应用（例如见 [9,89,117] 及其参考文献）。在文献 [89] 中，核 CCA 被用于基于内容的图像检索。其目的是允许通过文本查询检索图像，而无需参考与图像相关的任何标注。该任务被视为一个跨模态问题。CCA 的概率贝叶斯公式已在文献 [15,113] 中给出。基于稀疏性论证的正则化 CCA 版本已在文献 [90] 中推导。文献 [65] 提出了一种 CCA 变体，称为*相关成分分析*；它不是推导两个方向（子空间），而是为两个数据集推导一个公共方向。该方法背后的思想是这两个数据集可能差别不大，因此单个方向就足够了。这样，任务需要估计的自由参数更少。此外，正交性约束被取消了，在某些情况下这可能在物理上是不可辩护的。该方法的贝叶斯扩展见文献 [147]。
