
In [24], it is suggested to replace the `ℓ₁` norm by a weighted version of it. To justify such a choice, let us recall [Example 9.2](#Chp009_417-462_B9780443292385000159.xhtml) and the case where the "unknown" system was sensed using **x** = [2, 1]ᵀ. We have seen that by "blowing up" the `ℓ₁` ball, the wrong sparse solution was obtained. Let us now replace the `ℓ₁` norm in [(9.21)](#Chp009_417-462_B9780443292385000159.xhtml) with its weighted version,

```
‖θ‖₁,𝑤 := 𝑤₁|θ₁| + 𝑤₂|θ₂|, 𝑤₁, 𝑤₂ > 0
```

and set `𝑤₁ = 4` and `𝑤₂ = 1`. [Fig. 10.7](#Chp010_463-518_B9780443292385000160.xhtml#f0040)A shows the isovalue curve `‖θ‖₁,𝑤 = 1`, together with that resulting from the standard `ℓ₁` norm. The weighted one is sharply "pinched" around the vertical axis, and the larger the value of `𝑤₁`, compared to that of `𝑤₂`, the sharper the corresponding ball will be. [Fig. 10.7](#Chp010_463-518_B9780443292385000160.xhtml#f0040)B shows what happens when "blowing up" the weighted `ℓ₁` ball. It will first touch the point (0, 1), which is the true solution. Basically, what we have done is "squeeze" the `ℓ₁` ball to be aligned more to the axis that contains the (sparse) solution. For the case of our example, any weight `𝑤₁ > 2` would do the job.
