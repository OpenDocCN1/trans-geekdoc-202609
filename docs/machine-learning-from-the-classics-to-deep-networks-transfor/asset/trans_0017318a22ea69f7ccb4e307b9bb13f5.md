
并由此产生了*自适应提升*（AdaBoost）算法。指数损失函数如[图 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085)所示，连同 0-1 损失函数一起展示。前者可被视为（非可微的）0-1 损失函数的一个（可微的）上界。请注意，与正确识别的点（`y*F*(**x**) > 0`）相比，指数损失对误分类（`y*F*(**x**) ≤ 0`）点赋予了更大的权重。采用指数损失函数，通过相应的经验代价函数，按以下方式获得集合 `a[i], θ[i]`：

```
(a_i, \mathbf{\theta}_i) = \arg\min\limits_{a,\mathbf{\theta}}\sum\limits_{n = 1}^{N}\exp\left( - y_n\left( F_{i - 1}(\mathbf{x}_n) + a\phi(\mathbf{x}_n;\mathbf{\theta}) \right) \right).
```

该优化也分两步进行。首先，`a` 被视为固定，我们针对 `**θ**` 进行优化，

```
\mathbf{\theta}_{\mathbf{i}} = \arg\min\limits_{\mathbf{\theta}}\sum\limits_{n = 1}^{N}w_{n}^{(i)}\exp\left( - y_n a\phi(\mathbf{x}_n;\mathbf{\theta}) \right),
```

其中

```
w[n]^{(i)} := exp(-y[n]*F[i - 1](**x**[n])), n = 1, 2, …, N.
```
