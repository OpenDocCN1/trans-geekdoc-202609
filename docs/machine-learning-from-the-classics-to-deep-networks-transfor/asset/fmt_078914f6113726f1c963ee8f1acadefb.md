## 17.4.1 退化现象

粒子滤波是序贯重要采样的一个特例；因此，[17.2 节](#Chp017_855-884_B9780443292385000238.xhtml#s0015)中关于相应性能的论述也适用于此。

一个主要问题是**退化**现象。重要权重的方差随时间增加，经过几次迭代后，只有极少数（甚至仅一个）粒子被赋予非微小的权重，离散随机测度迅速退化。减少退化有两种方法：一是选择良好的建议分布，二是重采样。

我们知道建议分布的最优选择是

```
q(·|x[n-1]^(i), y[n]) = p(·|x[n-1]^(i), y[n]).
```
