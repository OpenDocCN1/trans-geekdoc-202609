

## 1. 单变量高斯分布的共轭先验

如果我们得到多个观测值 $x_n$，$n = 1, 2, \dots, N$，那么根据公式 [(12.76)](#Chp012_583-634_B9780443292385000184.xhtml#deq100) 和 [(12.77)](#Chp012_583-634_B9780443292385000184.xhtml#deq101)，结果后验将是一个 Gamma 分布，其参数为：

$$
\widetilde{b} = b + \frac{1}{2}\sum_{n=1}^{N}{(x_n - \mu)}^2 = b + \frac{N}{2}{\widehat{\sigma}}_{\text{ML}}^2,
$$

其中 ${\widehat{\sigma}}_{\text{ML}}^2$ 表示方差的最大似然估计（问题 [3.22](#Chp003_65-117_B9780443292385000093.xhtml)）。因此，参数 $b$ 的物理意义在于它量化了我们对未知方差的先验估计。这也与第 [3.7](#Chp003_65-117_B9780443292385000093.xhtml) 节所述内容一致；如果高斯分布中未知参数是方差，则 ${\widehat{\sigma}}_{\text{ML}}^2$ 是方差的充分统计量。可以很容易地证明，如果 $\sigma^2$ 已知，关于 $\mu$ 的共轭先验是高斯分布（问题 [12.10](#Chp012_583-634_B9780443292385000184.xhtml#o0135)）。
