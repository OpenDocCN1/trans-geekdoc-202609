We will demonstrate the method via an example involving the transformation of two random variables, say, `r` and `ϕ`, to two new ones, `x` and `y`. Let

```
x = g_x(r, ϕ)
```

and

```
y = g_y(r, ϕ).
```

Let us now assume that there is a unique solution for the inverses and that they can be expressed in an analytic form (which is not the case in general), that is,

```
r = g_r(x, y), ϕ = g_ϕ(x, y).
```

We know from Section [2.2.5](#Chp002_19-64_B9780443292385000081.xhtml) that if `p_r,ϕ(r, ϕ)` is the joint distribution of `r` and `ϕ`, then the joint distribution of `x` and `y` is given by

```
p_x,y(x,y) = p_r,ϕ(g_r(x,y), g_ϕ(x,y)) / |det(J(x,y;r,ϕ))|
```
