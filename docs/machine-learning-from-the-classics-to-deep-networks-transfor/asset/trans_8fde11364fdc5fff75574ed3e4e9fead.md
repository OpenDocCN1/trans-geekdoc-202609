**图 11.13** (0,1)-损失（红色虚线）、合页损失（红色实线）和平方误差（黑色虚线）函数，经过调整均通过 (0,1) 点以便比较。对于合页损失，选取了值 `ρ` = 1。此外，对于合页损失和 (0,1)-损失函数 `τ` = `yf(x)`，而对于平方误差函数，`τ` = `y` − `f(x)`。

我们将局限于位于某个 RKHS 中的线性判别函数，其形式为

`f(x) = θ₀ + ⟨θ, ϕ(x)⟩`

根据定义，

`ϕ(x) := κ(⋅, x)`

为特征映射。然而，基于第 [11.8.1](#Chp011_519-582_B9780443292385000172.xhtml#s0080) 节中讨论的相同原因，我们将在输入空间 `ℝˡ` 中将该任务表述为线性任务，并在最后阶段使用核技巧将核信息“植入”进去。

设计线性分类器的目标现在等价于最小化代价

```
J(θ, θ₀) = ½‖θ‖² + C ∑ₙ₌₁ᴺ Lᵨ(yₙ, θᵀxₙ + θ₀)
```
(11.60)

或者，采用松弛变量，并遵循第 [11.8.1](#Chp011_519-582_B9780443292385000172.xhtml#s0080) 节中类似的推理，最小化公式 [(11.60)](#Chp011_519-582_B9780443292385000172.xhtml#deq143) 等价于

```
关于 θ, θ₀, ξ 最小化  J(θ, ξ) = ½‖θ‖² + C ∑ₙ₌₁ᴺ ξₙ
```
(11.61)

约束条件为 `yₙ(θᵀxₙ + θ₀) ≥ ρ − ξₙ`
(11.62)
