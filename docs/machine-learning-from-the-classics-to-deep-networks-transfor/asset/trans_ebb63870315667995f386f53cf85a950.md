
我们正在寻找的先验背后的“魔法词汇”是：“它应该在数据上施加一种聚类结构。”尽管这也是混合建模的目标，但这里的问题截然不同。

*   **混合建模**：每个观测值属于（由其发射）单个混合成分。底层结构源于将观测值归入若干不同的混合成分中。被分配到同一混合成分的观测值比被分配到不同簇的观测值更“相似”。

*   **矩阵分解**：每个观测值都表示为矩阵 `A` 的若干列的线性组合。也就是说，每个观测向量都与 `A` 的若干列相关联。通过将与 `A` 的*相同*列相关联的观测值归集在一起，建立了观测值之间的相似性。

*   用略有不同的术语来说，`A` 的列被称为*特征*，如果两个观测向量由相同的列组合给出，我们就说它们*共享*相同的特征。如果 `z[k n] = 1`，我们就说第 *k* 个特征存在于第 *n* 个观测值中。

对于固定的 `K` 值，令 `P[k]`，`k = 1, 2, …, K`，为任意 `n` 值下 `z[k n] = 1` 的概率。则我们可以写为

```
P(Z|P) = ∏_{k = 1}^{K} ∏_{n = 1}^{N} P(z_{kn}|P)
```
(13.128)

```
= ∏_{k = 1}^{K} P_{k}^{m_{k}} (1 - P_{k})^{N - m_{k}},
```
(13.129)

其中 `P = [P[1], …, P[K]]^(T)` 且 `m_{k} := ∑_{n = 1}^{N} z_{kn}`。也就是说，`m[k]` 是 `Z` 第 *k* 行中非零元素的个数；其物理解释是它计算共享第 *k* 个特征的观测值的数量。显然，为了使公式 [(13.129)](#Chp013_635-716_B9780443292385000196.xhtml#deq197) 成立，已假设所涉变量之间相互独立。

**为概率选择先验**：作为 `P[k]`，`k = 1, 2…, K` 的先验，我们采用 Beta 分布，即

```
P[k] ~ Beta(P|a, b).
```
