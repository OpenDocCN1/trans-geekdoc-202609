
At the optimum value `μ_o`, there are two slowest modes; one corresponding to `λ_min` (i.e., `1 - μ_o * λ_min`) and the other to `λ_max` (i.e., `1 - μ_o * λ_max`). They have equal magnitudes but opposite signs, given by:

```
± (ρ - 1) / (ρ + 1)
```

where

```
ρ := λ_max / λ_min.
```

In other words, **the convergence rate depends on the spread of the eigenvalues of the covariance matrix**.
