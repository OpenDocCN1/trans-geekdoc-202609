
$$
\sum_{n=1}^{N} q_j^2(n) = \mathbf{q}_j^T \mathbf{q}_j = \mathbf{v}_j^T X^T X \mathbf{v}_j = \mathbf{v}_j^T \left( \sum_{i=1}^{l} \sigma_i^2 \mathbf{v}_i \mathbf{v}_i^T \right) \mathbf{v}_j = \sigma_j^2
$$

![Equation](images/B9780443292385000123/si149.png)

这是由于 **v**[*j*] 的**正交归一性**。也就是说，*σ*[*j*]² 等于 **q**[*j*] 元素的（缩放）样本方差。然而，根据公式 [(6.32)](#Chp006_249-291_B9780443292385000123.xhtml#deq67) 中的定义，这是输入向量（回归量）**x**[*n*]，*n* = 1, 2, …, *N* 沿 **v**[*j*] 方向投影的样本方差。*σ*[*j*] 的值越大，输入数据沿相应方向的分布就越分散。这在 [图 6.4](#Chp006_249-291_B9780443292385000123.xhtml#f0025) 中有所展示，其中 *σ*[1] ≫ *σ*[2]。从方差的角度来看，与 **v**[2] 相比，**v**[1] 是更具**信息量**的方向。这是大部分活动发生的方向。这一观察构成了*降维*的核心，将在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章中详细讨论。此外，由公式 [(6.18)](#Chp006_249-291_B9780443292385000123.xhtml#deq44) 可得

**q**[*j*] = *X***v**[*j*] = *σ*[*j*]**u**[*j*]。
