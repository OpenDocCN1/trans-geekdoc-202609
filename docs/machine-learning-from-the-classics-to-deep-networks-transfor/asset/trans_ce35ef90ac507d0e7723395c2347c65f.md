在第一种方法中，计算观测序列的联合分布，这是在将所有隐变量边缘化之后进行的；针对每个模型/词都执行此操作。然后选择得分值最大的那个词。这种方法对应于**求和-乘积规则**。另一种途径是为每个模型/词计算格子图中的最优轨迹；即得分最高的联合概率轨迹。随后，我们选择对应于最大最优值的模型/词。这种方法是**最大-求和规则**的一种实现。
