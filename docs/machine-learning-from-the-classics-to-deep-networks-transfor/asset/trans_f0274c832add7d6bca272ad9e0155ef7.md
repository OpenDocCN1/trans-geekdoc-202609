
让我们以一个 256 × 256 的图像数组为例。将其向量化后得到输入向量 **x** ∈ ℝ^(*l*)，其中 *l* ≈ 65000。假设第一层的节点数为 *k*[1] = 1000。那么，在全连接网络中，连接所有输入节点到第一层所有节点所涉及的参数 *θ*[*j**k*]，*j* = 1, 2, …, 65000，*k* = 1, 2, …1000 的数量将达到 6500 万量级。如果输入图像是分辨率约为 1000 × 1000 像素的高分辨率图像，这个数字将进一步激增。此外，如果我们处理的是彩色图像，例如采用 RGB（红-绿-蓝）颜色表示方案，输入的维度将乘以三，参数数量也会随之增加。而且，随着隐藏层的增加，参数数量会持续增长。除了相关的计算负载问题外，我们知道训练具有大量参数的网络会严重挑战泛化性能。此类网络需要海量的训练数据才能应对过拟合倾向。

除了参数数量的激增，将图像数组向量化还会导致信息丢失；这是因为我们丢弃了像素在图像区域内如何相互关联这一重要信息。事实上，多年来开发的各种特征生成技术的目标正是如此。也就是说，提取能够量化图像中像素值之间的*相关性*或其他统计*依赖性*的信息。通过这种方式，可以高效地“编码”驻留在原始数据中的与学习相关的信息。

通过采用卷积，可以同时解决这两个问题，即参数爆炸问题以及有用统计信息的提取问题。任何卷积网络涉及的基本步骤包括：

*   卷积步骤，
*   非线性步骤，
*   池化步骤。
