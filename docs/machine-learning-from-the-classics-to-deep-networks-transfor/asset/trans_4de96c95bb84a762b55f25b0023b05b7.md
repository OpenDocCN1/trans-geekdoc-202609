
# 11.8 支持向量回归

尽管平方误差损失函数（与最小二乘法相关）有其优点，但并不总是优化的最佳准则。在存在非高斯长尾噪声（即相对较大值的概率不可忽略）的情况下，因此会有更多的噪声*离群值*，平方误差准则对误差的平方依赖会偏向与离群值存在相关的值。回顾第[3](#Chp003_65-117_B9780443292385000093.xhtml)章，在白高斯噪声假设下，最小二乘法等价于最大似然估计。此外，在此假设下，最小二乘估计量达到克拉美-罗界，并成为最小方差估计量。然而，在其他噪声场景下，必须寻找替代准则。

Huber [54] 研究了在存在离群值情况下的优化任务，其目标是获得一种选择损失函数的策略，使其最好地“匹配”噪声模型。他证明了，假设噪声具有对称概率密度函数（PDF），最优极大极小策略^([^(78)](#fn78)) 为：

```
ℒ(y, f(x)) = |y − f(x)|
```

这导出了*最小模*方法。从第[5.8](#Chp005_177-248_B9780443292385000111.xhtml)节可知，该损失函数的随机梯度在线版本导出了符号误差 LMS。Huber 还表明，如果噪声包含两个分量，一个对应高斯分布，另一个对应任意 PDF（保持对称），则在极大极小意义上最好的损失函数由下式给出
