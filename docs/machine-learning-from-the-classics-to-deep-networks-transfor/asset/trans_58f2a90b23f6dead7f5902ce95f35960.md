

## 解码器输出公式化

解码器的 $l$ 维输出形成如下：

$$
\widehat{\mathbf{h}}_{n}^{d} \in \mathbb{R}^{l} := W\mathbf{h}_{n}^{d},\ n = 0,1,\ldots,N^{\prime} + 1.
$$

![Equation](images/B9780443292385000251/si311.png)

$$
\widehat{\mathbf{y}}_{n} = \text{Softmax}(\widehat{\mathbf{h}}_{n}^{d}),\ \text{i.e.},\ \widehat{y}_{ni} = \frac{\exp(\widehat{h}_{ni}^{d})}{\sum_{j = 1}^{l}\exp(\widehat{h}_{nj}^{d})},\ i = 1,2,\ldots,l.
$$

![Equation](images/B9780443292385000251/si312.png)

因此，解码器输出向量的元素现在可以解释为概率。矩阵 `W` 在训练过程中也会被学习。

### 损失函数

训练期间使用的损失函数应当被选择，使得在任意输出位置 $n$，*最大* 条件概率值出现在*那个特定的* 维度 $i$ ($\widehat{y}_{ni}$) 上，该维度等于词汇表中单词的 id（独热向量），对应于位置 $n + 1$ 处的目标输出嵌入 $\mathbf{y}[n + 1]$。回顾一下，该概率是以 $\mathcal{X}[0 : N + 1]$ 和 $\mathbf{y}[0], \ldots, \mathbf{y}[n]$ 为条件的。例如，如果语料库词汇表中单词 "am" ($\rightarrow \mathbf{y}[2]$) 的 id 是 235，那么我们应该期望 $\widehat{\mathbf{y}}_{1}$ 在维度 $i = 235$ 处的元素，即 $\widehat{y}[1, 235]$，在其 $l$ 个元素中具有最大值。
