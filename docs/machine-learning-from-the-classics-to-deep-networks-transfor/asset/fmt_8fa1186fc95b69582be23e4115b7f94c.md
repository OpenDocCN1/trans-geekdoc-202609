
在基于 RNN 的编码器中，输入是按顺序逐个 Token 提供的。相比之下，在 Transformer 的编码器中，构成输入序列的所有 Token 会同时呈现。让我们专注于一个将法语短语“Je suis étudiant”翻译成英语（即“I am a student”）的简单示例。那么，编码器的输入将是 `⟨SOS⟩, x[1], x[2], x[3], ⟨EOS⟩`，其中 `⟨SOS⟩` 和 `⟨EOS⟩` 是分别指示序列开始和结束的特殊 Token（另见第 19.3.1 节）。在目前的讨论中，我们假设 `x[1] (→ Je)`、`x[2] (→ suis)`、`x[3] (→ étudiant)` 是将原始独热向量嵌入到维度为 `d[m]` 的低维空间后得到的向量，即 `x[n] ∈ ℝ^(d[m]), n = 1, 2, …, N`，其中 `N` 是输入序列的长度，在本例中 `N = 3`。按照惯例，除非另有说明，我们将 `⟨SOS⟩` 的嵌入表示为 `x[0]`，将 `⟨EOS⟩` 的嵌入表示为 `x[N + 1]`。符号 `d[m]` 保留用于表示嵌入空间的维度，下标“m”用于提醒我们单词“model”。这是因为通过编码器和解码器不同模块传播的所有向量/Token/嵌入都具有相同的维度，即 `d[m]`，这是一个用户定义的模型参数。

然而，嵌入的选择需要特别注意。请注意，由于输入序列作为一个整体出现在 Transformer 的输入端，而不是按顺序出现，因此需要协助网络并提供关于每个单词/Token 相对于其他单词/Token 的位置的额外信息。换句话说，提供指示哪个 Token 是第一个、哪个是第二个等的信息。我们将此过程称为*位置嵌入*。

将原始词汇表单词嵌入到输入 Token 涉及两个步骤：

*   **词汇表单词嵌入**：为了满足我们当前的符号需求，让我们用 `x[n]^(oh) ∈ ℝ^(l)` 表示对输入单词序列进行分词后得到的独热向量。^[137]

    `x[n]' ∈ ℝ^(d[m]) = E x[n]^(oh), n = 0, 1, …, N + 1`
