
我们的目标现在变为学习涉及的参数；即 `A`、`β`、`α` 和 `Λ`。这可以在标准的贝叶斯框架下完成，通过在 `α`、`β`（通常为伽马概率密度函数）以及 `A` 的列上施加先验：

```
p(a_i) = N(a_i | 0, (1/l)I_l), i = 1,2,...,m,
```

这保证了每一列具有单位期望范数。`b` 的元素的先验被选为服从伯努利分布（更多细节请参见 [47]）。

在推广该模型之前，让我们看看所采用模型的潜在几何解释。回顾我们的统计学基础（另见第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章的 [2.3.2](#Chp002_19-64_B9780443292385000081.xhtml) 节），一组联合高斯变量的大部分活动发生在一个（超）椭球体内，其主轴由协方差矩阵的特征结构决定。因此，假设 `x` 的值接近于一个子空间/（超）平面，通过调整 `Σ[x]` 的元素（训练后），得到的高斯模型公式 [(20.94)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq143) 和 [(20.95)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq144) 可以充分对其建模，使得相应的高概率区域形成一个足够扁平的椭球体（有关图示请参见 [图 20.15](#Chp020_1103-1179_B9780443292385000263.xhtml#f0100)）。

一旦我们建立了因子模型的几何解释，就让我们的想象力自由发挥。这种观点能否扩展到对源自子空间并集的数据进行建模？对此挑战的一个合理回应是求助于因子混合模型：每个子空间对应一个。然而，事情远不止于此。已经证明（例如，[27]），一个紧致流形可以被有限个拓扑圆盘覆盖，其维数等于流形的维数。将拓扑圆盘与定义足够扁平的超椭球体的主超平面相关联，可以用足够数量的因子（每个椭球体对应一个）来对沿流形发生的数据活动进行建模 [47]。

*因子分析器混合模型*（MSA）定义为：

```
p(x) = ∑_{j=1}^{J} P_j N(x | μ_j, α_j^{-1} A_j Λ_j A_j^T + β^{-1} I_l),
```
