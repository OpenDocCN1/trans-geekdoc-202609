

例如，这种过完备字典可用于公式 [(9.16)](#Chp009_417-462_B9780443292385000159.xhtml#deq26) 的展开中，以表示信号向量，这些向量由正弦波与尖峰状信号脉冲之和组成。由于正交性，`I` 任意两列之间的内积以及 `W` 任意两列之间的内积均为零。另一方面，很容易看出，`I` 的任意一列与 `W` 的任意一列之间的内积，其绝对值等于 `1/sqrt(N)`。因此，该矩阵的互相干度为 `μ(X) = 1/sqrt(N)`。此外，观察可知，该矩阵的 spark 为 `spark(X) = N + 1`。

### 引理 9.4

*对于任意 `N × l` 矩阵 `X`，以下不等式成立：*

```
spark(X) ≥ 1 + 1/μ(X).
``` (9.26)

证明见文献 [37]，其基于应用于 `X` 的格拉姆矩阵 `X^T X` 的矩阵理论论证（问题 [9.16](#Chp009_417-462_B9780443292385000159.xhtml#o0105)）。对上述界限进行“肤浅”的观察会发现，对于非常小的 `μ(X)` 值，spark 可能会（！）大于 `N + 1`。查看证明可知，在这种情况下，矩阵的 spark 达到其最大值 `N + 1`。

该结果符合常识推理。`μ(X)` 的值越小，`X` 的列向量越独立，因此其 spark 的值预期越高。基于此引理，我们现在可以陈述以下定理，该定理最早见于文献 [37]。结合 [引理 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0075) 和 [(9.26)](#Chp009_417-462_B9780443292385000159.xhtml#deq61)，我们得出以下重要定理。

### 备注 9.7

*   公式 [(9.27)](#Chp009_417-462_B9780443292385000159.xhtml#deq62) 中的界限在“心理上”很重要。它提供了一个易于计算的界限，用以检查 NP-hard 任务的解是否为最优解。然而，这并非一个特别好的界限，它限制了可应用的值的范围。正如 [示例 9.4](#Chp009_417-462_B9780443292385000159.xhtml#enun0090) 所讨论的，虽然矩阵 spark 的最大可能值等于 `N + 1`，但互相干度的最小可能值为 `1/sqrt(N)`。因此，基于互相干度的界限将可以检查最优性的稀疏度范围，即 `||θ||_0`，限制在 `(1/2)sqrt(N)` 左右。此外，正如前面提到的 Welch 界所暗示的，互相干度的这种 `O(1/sqrt(N))` 依赖关系似乎是一种更普遍的趋势，而不仅仅是 [示例 9.4](#Chp009_417-462_B9780443292385000159.xhtml#enun0090) 的特例（参见例如 [36]）。另一方面，正如我们在 [备注 9.6](#Chp009_417-462_B9780443292385000159.xhtml#enun0085) 中已经陈述的，可以构造 spark 等于 `N + 1` 的随机矩阵；因此，使用基于 spark 的界限，可以将稀疏向量的范围扩展到 `(1/2)N`。
