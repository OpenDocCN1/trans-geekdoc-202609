

# 诺伯特·维纳与安德烈·柯尔莫哥洛夫

**诺伯特·维纳**（1894–1964）是一位数学家和哲学家。他在17岁时获得哈佛大学数理逻辑博士学位。第二次世界大战期间，他在一项机密工作中独立于柯尔莫哥洛夫奠定了线性估计理论的基础。后来，维纳参与了自动化、人工智能和认知科学领域的开创性工作。作为一名和平主义者，他在冷战时期备受猜疑。

线性估计理论所依托的另一支柱是**安德烈·尼古拉耶维奇·柯尔莫哥洛夫**（1903–1987）[24]的开创性工作，他独立于维纳发展了自己的理论。柯尔莫哥洛夫的贡献涵盖了数学的广泛主题，包括概率论、计算复杂性和拓扑学。他是概率概念现代公理化基础之父（参见第[2](#Chp002_19-64_B9780443292385000081.xhtml)章）。

## 备注 4.2

*   迄今为止，在我们的理论发现中，我们假设 `x` 和 `y` 是联合分布（相关）的变量。如果此外我们假设它们根据线性回归模型呈线性关系，

    `y = θₒᵀx + η, θₒ ∈ ℝᵏ` (4.12)

    其中 `η` 是一个与 `x` 独立的零均值噪声变量，那么，如果真实系统 `θₒ` 的维数 `k` 等于模型采用的参数数目 `l`，即 `k = l`，则可得出（问题 [4.4](#Chp004_119-175_B978044329238500010X.xhtml#o0025)）

    `θ* = θₒ`

    最优均方误差等于噪声方差 `σ²_η`。

*   **欠建模**。如果 `k > l`，则模型的阶数小于真实系统的阶数，后者通过公式 [(4.12)](#Chp004_119-175_B978044329238500010X.xhtml#deq18) 关联 `y` 和 `x`；这被称为*欠建模*。容易证明，如果构成 `x` 的变量互不相关，则（问题 [4.5](#Chp004_119-175_B978044329238500010X.xhtml#o0030)）

    `θ* = θₒ¹`

    其中

    ```
    θₒ := [θₒ¹; θₒ²],  θₒ¹ ∈ ℝˡ,  θₒ² ∈ ℝᵏ⁻ˡ.
    ```

*   换句话说，最小均方误差估计器识别出 `θₒ` 的前 `l` 个分量。
