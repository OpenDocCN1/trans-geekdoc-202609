

# 19.1 简介

这是与神经网络和深度学习相关的第二章。本章涉及机器学习领域一些较新的进展，即深度生成模型、Transformer 和大语言模型（LLM），以及自监督学习。生成式网络彻底改变了我们建模和生成数据的方式。在数据驱动的科学、技术、工业和服务时代，这些技术已跳出研究领域，扩散并应用于广泛的应用场景中。在另一个战线上，在监督学习和无监督学习统治多年后，自监督技术已崛起为机器学习中的关键角色，为利用和挖掘互联网上海量可用的无标签数据提供了巨大的新潜力。Transformer 和大语言模型在语言理解、处理和文本生成方面取得了重大突破。自问世以来短短几年内，这些模型已渗透到语言处理任务之外的许多领域，并正成为新科学发现、新技术成就不可或缺的工具，正在改变人类互动、娱乐和工作的方式。尽管预测尚早，但似乎所有这些机器学习进展都将对我们作为个体和社会成员的生活各个方面产生重大影响。

本章首先回顾图模型的一些非常基础的概念，然后介绍深度置信网络。除了其重要的教育价值外，这些网络在本世纪初 G. Hinton 及其同事的远见卓识工作推动下，对神经网络研究兴趣的复苏起到了关键作用。随后，讨论生成对抗网络（GAN），继而介绍自编码器和变分自编码器（VAE）。简要探讨了归一化流。本章的一个主要重点在于注意力机制和 Transformer 网络的概念。介绍了 GPT 和 BERT 两大模型家族。随后转入自监督学习，重点介绍其主要类别，如掩码预测方法和对比技术。本章以扩散模型简介作结，讨论关键概念、主要建模路径、算法和应用。同时也简要涉及了与这些技术使用相关的伦理问题。
