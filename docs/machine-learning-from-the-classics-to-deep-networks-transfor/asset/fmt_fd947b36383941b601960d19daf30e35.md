
## Decoder Output Formulation

The $l$-dimensional outputs of the decoder are formed as

$$
\widehat{\mathbf{h}}_{n}^{d} \in \mathbb{R}^{l} := W\mathbf{h}_{n}^{d},\ n = 0,1,\ldots,N^{\prime} + 1.
$$

![Equation](images/B9780443292385000251/si311.png)

$$
\widehat{\mathbf{y}}_{n} = \text{Softmax}(\widehat{\mathbf{h}}_{n}^{d}),\ \text{i.e.},\ \widehat{y}_{ni} = \frac{\exp(\widehat{h}_{ni}^{d})}{\sum_{j = 1}^{l}\exp(\widehat{h}_{nj}^{d})},\ i = 1,2,\ldots,l.
$$

![Equation](images/B9780443292385000251/si312.png)

Thus, the elements of the output vectors of the decoder can now be interpreted as probabilities. Matrix `W` is also learned during training.

### The Loss Function

The loss function to be used during training should be selected so that at any output position, $n$, the *maximum* conditional probability value occurs at *that specific* dimension $i$ ($\widehat{y}_{ni}$), which is equal to the id of the vocabulary word (one-hot vector), that corresponds to the target output embedding at position $n + 1$, $\mathbf{y}[n + 1]$. Recall that this probability is conditioned on $\mathcal{X}[0 : N + 1]$ and $\mathbf{y}[0], \ldots, \mathbf{y}[n]$. For example, if the id of the word "am" ($\rightarrow \mathbf{y}[2]$) in the vocabulary in the corpus is, say, 235, then we should expect the element at dimension $i = 235$ of $\widehat{\mathbf{y}}_{1}$, i.e., $\widehat{y}[1, 235]$, to have the largest value among its $l$ elements.
