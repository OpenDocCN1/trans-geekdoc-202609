
Although intuition is most important in scientific research, it is not enough, by itself, to justify decisions and actions. The generic scheme in Eq. [(10.2)](#Chp010_463-518_B9780443292385000160.xhtml#deq14) has been reached from different paths, following different perspectives that lead to different choices of the involved parameters. Let us spend some more time on that, with the aim of making the reader more familiar with techniques that address optimization tasks of nondifferentiable loss functions. The term in parentheses in Eq. [(10.2)](#Chp010_463-518_B9780443292385000160.xhtml#deq14) coincides with the gradient descent iteration step if the cost function is the unregularized sum of squared errors cost (LS), that is,

```
$J(\mathbf{\theta}) = \frac{1}{2}\left\| \mathbf{y} - X\mathbf{\theta} \right\|_{2}^{2}.$
```

![Equation](images/B9780443292385000160/si79.png)

In this case, the gradient descent rationale leads to

```
$\mathbf{\theta}^{(i - 1)} - \mu\frac{\partial J\left( \mathbf{\theta}^{(i - 1)} \right)}{\partial\mathbf{\theta}} = \mathbf{\theta}^{(i - 1)} - \mu X^{T}\left( X\mathbf{\theta}^{(i - 1)} - \mathbf{y} \right) = \mathbf{\theta}^{(i - 1)} + \mu X^{T}\mathbf{e}^{(i - 1)}.$
```

![Equation](images/B9780443292385000160/si80.png)
