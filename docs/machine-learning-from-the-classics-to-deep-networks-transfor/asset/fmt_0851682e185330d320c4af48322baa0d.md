
The energy function is defined as:

$$E(\mathbf{v},\mathbf{h}) = - \sum\limits_{i = 1}^{I}\sum\limits_{j = 1}^{J}\theta_{ij}h_{i}v_{j} - \sum\limits_{i = 1}^{I}b_{i}h_{i} - \sum\limits_{j = 1}^{J}c_{j}v_{j}.$$

![Equation](images/B9780443292385000251/si4.png) (19.2)

The normalizing constant is obtained as:

$$Z = \sum\limits_{\mathbf{v}}\sum\limits_{\mathbf{h}}\exp\left( - E(\mathbf{v},\mathbf{h}) \right).$$

![Equation](images/B9780443292385000251/si5.png) (19.3)

We will focus on discrete variables; hence the involved distributions are probabilities. More specifically, we will focus on random variables of a binary nature, that is, `v[j]`, `h[i]` ∈ {0, 1}, `j` = 1, …, `J`, `i` = 1, …, `I`.

![Equation](images/B9780443292385000251/si6.png)

Observe from Eq. [(19.2)](#Chp019_997-1102_B9780443292385000251.xhtml#deq2) that, in contrast to a general Boltzmann machine, only products between hidden and visible variables are present in the energy term.

The goal in training an RBM is to learn the set of unknown parameters, `θ[i j]`, `b[i]`, `c[j]`, which will be collectively denoted as **Θ**, **b**, and **c**, respectively. A major path to this end is to maximize the log-likelihood, using `N` observations of the visible variables, denoted as **v[n]**, `n` = 1, 2, …, `N`.
