
### 数学推导与习题

**公式推导：**

$\delta_{nj}^{(L)} = a(\hat{y}_{nj} - y_{nj})$

![Equation](images/B978044329238500024X/si594.png)

1.  若使用公式 [(18.41)](#Chp018_885-995_B978044329238500024X.xhtml#deq77) 中的交叉熵，则有：

$\delta_{nj}^{(L)} = a y_{nj}(\hat{y}_{nj} - 1)$

![Equation](images/B978044329238500024X/si595.png)

**习题：**

1.  **18.8** 证明：若输出层节点的激活函数为逻辑斯蒂函数且使用相对熵代价函数，则公式 [(18.21)](#Chp018_885-995_B978044329238500024X.xhtml#deq32) 中的 $\delta_{nj}^{(L)}$ 变为：

$\delta_{nj}^{(L)} = a y_{nj}(\hat{y}_{nj} - 1)$

![Equation](images/B978044329238500024X/si595.png)

2.  **18.9** 证明交叉熵损失函数取决于相对输出误差。

3.  **18.10** 证明：若激活函数为 Softmax 且损失函数为交叉熵（或公式 [(18.44)](#Chp018_885-995_B978044329238500024X.xhtml#deq80) 中的损失），则公式 [(18.21)](#Chp018_885-995_B978044329238500024X.xhtml#deq32) 中的 $\delta_{nj}^{(L)}$ 不依赖于非线性函数的导数。

4.  **18.11** 同前题，使用相对熵作为代价函数、Softmax 作为激活函数。证明：

$\delta_{nj}^{(L)} = \hat{y}_{nj} - y_{nj}$

![Equation](images/B978044329238500024X/si596.png)

5.  **18.12** 推导用于训练 RNN 的随时间反向传播算法。
