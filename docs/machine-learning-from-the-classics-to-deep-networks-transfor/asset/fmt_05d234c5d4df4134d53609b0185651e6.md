
#### Gradient descent with a momentum term

One way to improve the convergence rate, while remaining within the gradient descent rationale, is to employ the so-called *momentum term* [62,214]. The correction term as well as the update recursion are now modified as

```
$\underset{1\text{st mini-batch}}{\underbrace{(y_{(1)},\mathbf{x}_{(1)}),\ldots,(y_{(K)},\mathbf{x}_{(K)})}}\ldots\underset{M\text{th mini-batch}}{\underbrace{(y_{((M - 1)K + 1)},\mathbf{x}_{((M - 1)K + 1)}),\ldots,(y_{(N)},\mathbf{x}_{(N)})}},$

where, as we have already pointed out in Section [18.2](#Chp018_885-995_B978044329238500024X.xhtml#s0015), the notation $(i) \in \{1, 2, \ldots, N\}$ is used, due to the data shuffling. Thus, during one epoch, $M$ updates will be performed, each one involving the gradient of a different cost; this is because a different mini-batch will be considered each time, i.e.,

$\frac{\partial J^{(m)}(\mathbf{\theta})}{\partial\mathbf{\theta}},\ m = 1,2,\ldots,M,$

$J^{(m)}(\mathbf{\theta}): = \sum\limits_{k = 1}^{K}\mathcal{L}\left( y_{((m - 1)K + k)},\mathbf{x}_{((m - 1)K + k)},\mathbf{\theta} \right).$

In the sequel, to simplify notations, we will use a common symbol, $\frac{\partial J}{\partial\mathbf{\theta}}$, to denote the gradient operation for all three possible cases discussed before. The true value of the function in the place of $J$ will depend on (a) the specific scheme (i.e., batch, mini-batch, pattern-by-pattern) and (b) the current iteration step, as different samples are involved in each step (e.g., in the stochastic versions).
```
