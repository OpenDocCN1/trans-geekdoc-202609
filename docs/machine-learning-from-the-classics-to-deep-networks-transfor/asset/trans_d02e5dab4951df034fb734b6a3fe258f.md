

## 17.4.2 通用粒子滤波

重采样具有许多优势。它以高概率丢弃低权重的粒子；也就是说，仅传播对应于高概率质量区域的粒子。当然，重采样也有其自身的局限性。例如，在时刻 `n` 权重较低的粒子在后续时刻不一定具有低权重。在这种情况下，重采样显得相当浪费。此外，重采样限制了计算过程并行化的潜力，因为不同流上的粒子必须在每个时刻“合并”。然而，已有一些增强并行性的努力被报道（参见，例如，[22]）。而且，对应于高权重值的粒子被多次抽取，导致样本集的多样性降低；这种现象也称为*样本贫化*。在状态/过程噪声 `η[n]` 较低的情况下（见公式 (17.12)），这种现象的影响变得更加严重，此时采样点集可能最终仅包含单个点（例如，[1]）。

因此，避免重采样可能是有益的。在实践中，仅当权重方差的相关度量低于某个阈值时才执行重采样。在文献 [30,31] 中，*有效样本数* 近似计算为

```
N_eff ≈ 1 / Σ_{i=1}^N (W_n^(i))^2
```
(17.40)

该指标的取值范围为 1 到 `N`。如果 `N_eff ≤ N_T` 则执行重采样，通常取 `N_T = N/2`。
