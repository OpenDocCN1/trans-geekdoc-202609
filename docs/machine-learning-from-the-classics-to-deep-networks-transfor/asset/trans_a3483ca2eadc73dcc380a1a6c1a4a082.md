

我们放宽了 `Σ` 对 `u` 的符号依赖，转而显式地标明了矩阵的阶数，因为从现在起这将是一个非常有用的索引。

我们将采用递归方法，我们的目标是用 `m-1` 阶的最优解 `w[m-1]` 来表示 `m` 阶的最优滤波器解，从现在起将其表示为 `w[m]`。

广义平稳过程的协方差矩阵是一个 `Toeplitz` 矩阵；其*任意*一条对角线上的所有元素都相等。这一性质连同其厄米特性质共同导致了以下*嵌套*结构：

```
Σ_m = [ Σ_{m-1}       J_{m-1} r_{m-1} ]
      [ r_{m-1}^H J_{m-1}   r(0)       ]
```
(4.60)

```
= [ r(0)         r_{m-1}^T ]
  [ r_{m-1}^*    Σ_{m-1}   ],
```
(4.61)

其中

```
r_{m-1} := [ r(1) ]
           [ r(2) ]
           [ ⋮    ]
           [ r(m-1) ]
```
(4.62)
