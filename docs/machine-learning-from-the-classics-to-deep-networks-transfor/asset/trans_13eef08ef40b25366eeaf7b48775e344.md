
现在让我们关注这样一种情况：存在一个生成观测值的 `k` 稀疏向量，即 `θ = θ[k]`。文献 [18] 表明，条件 `δ[2k] < 1` 保证了 `ℓ[0]` 最小化器具有唯一的 `k` 稀疏解。换句话说，为了获得 `ℓ[1]` 和 `ℓ[0]` 最小化器之间的等价性，`δ[2k]` 的取值范围必须缩小到 `δ_{2k} < √2 - 1`，根据 [定理 9.3](#Chp009_417-462_B9780443292385000159.xhtml#enun0125)。这听起来是合理的。如果我们放宽准则并用 `ℓ[1]` 代替 `ℓ[0]`，那么感知矩阵的构造就必须更加谨慎。虽然我们不会在此提供这些定理的证明，因为它们的表述远超出了本书的范围，但跟进一下如果 `δ[2k] = 1` 会发生什么是很有趣的。这将让我们窥见证明背后的本质。如果 `δ[2k] = 1`，公式 [(9.30)](#Chp009_417-462_B9780443292385000159.xhtml#deq66) 左侧项变为零。在这种情况下，可能存在两个 `k` 稀疏向量 `θ[1], θ[2]` 使得 `X(θ[1] − θ[2]) = 0`，即 `Xθ[1] = Xθ[2]`。因此，在将所有 `k` 稀疏向量投影到观测空间后，无法通过任何方法恢复它们。

前述论证还建立了 RIP 与矩阵 spark 之间的联系。确实，如果 `δ[2k] < 1`，这保证了 `X` 的任意多达 `2k` 列都是线性无关的，因为对于任意 `2k` 稀疏向量 `θ`，公式 [(9.29)](#Chp009_417-462_B9780443292385000159.xhtml#deq65) 保证了 `‖Xθ‖[2] > 0`。这意味着 `spark(X) > 2k`。文献 [16] 建立了 RIP 与相干性之间的联系，其中表明如果 `X` 的相干性为 `μ(X)` 且列向量为单位范数，则 `X` 满足 `δ[k]` 阶 RIP，其中 `δ[k] ≤ (k − 1)μ(X)`。
