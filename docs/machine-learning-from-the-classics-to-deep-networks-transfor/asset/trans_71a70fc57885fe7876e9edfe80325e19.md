**图 6.11** 根据 LS 方法，*仅*修正输出点 `y[n]` 为 `y[n] − e[n]`，使得点对 (`y[n] − e[n]`, `x[n]`) 落在一超平面上，对于中心化数据该超平面穿过原点。若数据未中心化，则穿过质心 `$(\\overline{y},\\overline{x})$`。

在本节中，将考虑更一般的情况，即允许输入（回归变量）和输出变量均受到（未观测到的）噪声样本的扰动。这种处理方法由来已久，可追溯至 19 世纪 [1]。该方法长期默默无闻，直到 50 年后被 Deming [13] 复兴并用于二维模型；有时称为 *Deming 回归*（历史综述见例如 [19]）。此类模型也称为 *误差变量* 回归模型。

我们的出发点是式 [(6.65)](#Chp006_249-291_B9780443292385000123.xhtml#deq148) 中的表述。令 `**e**` 为施加于 `**y**` 的修正向量，`E` 为施加于 `X` 的修正矩阵。*全最小二乘法* (TLS) 通过求解以下优化任务来计算未知参数向量：

```
minimize ‖[E ⋮ **e**]‖[F], s.t. **y** − **e** ∈ ℛ(X − E).
```

回顾 ([备注 6.1](#Chp006_249-291_B9780443292385000123.xhtml#enun0015))，矩阵的 Frobenius 范数定义为其所有元素平方和的平方根，它是向量欧几里得范数的直接推广。此外，注意 [(6.67)](#Chp006_249-291_B9780443292385000123.xhtml#deq151) 中的约束条件集可等价地写为

```
(X − E)**θ** = **y** − **e**.
```
