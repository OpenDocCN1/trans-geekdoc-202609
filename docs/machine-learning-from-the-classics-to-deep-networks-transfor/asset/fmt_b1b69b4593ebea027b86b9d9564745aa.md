
## 仿射投影算法推导

$$
X_{n} = \begin{bmatrix} \mathbf{x}_{n}^{T} \\ \vdots \\ \mathbf{x}_{n - q + 1}^{T} \\ \end{bmatrix},
$$

![Equation](images/B9780443292385000111/si259.png)

则约束集合可紧凑地写为

$$X_{n}\boldsymbol{\theta} = \mathbf{y}[n],$$

![Equation](images/B9780443292385000111/si260.png)

其中

$$\mathbf{y}[n] = [y[n], \dots, y[n - q + 1]]^{T}.$$

![Equation](images/B9780443292385000111/si261.png)

在公式 [(5.60)](#Chp005_177-248_B9780443292385000111.xhtml#deq105) 中使用拉格朗日乘子法（附录 C）可得（问题 [5.10](#Chp005_177-248_B9780443292385000111.xhtml#o0055)）：

$$\boldsymbol{\theta}[n] = \boldsymbol{\theta}[n-1] + X_{n}^{T}(X_{n}X_{n}^{T})^{-1}\mathbf{e}[n],$$

![Equation](images/B9780443292385000111/si262.png)

(5.61)

$$\mathbf{e}[n] = \mathbf{y}[n] - X_{n}\boldsymbol{\theta}[n-1],$$

![Equation](images/B9780443292385000111/si263.png)

(5.62)

前提是 $X_{n}X_{n}^{T}$ 可逆。该算法总结在 [算法 5.2](#Chp005_177-248_B9780443292385000111.xhtml#enun0040) 中。

### 算法 5.2：仿射投影算法

**初始化**

1.  $\mathbf{x}[-1] = \dots = \mathbf{x}[-q+1] = \mathbf{0}$，$y[-1], \dots, y[-q+1] = 0$
2.  $\boldsymbol{\theta}[-1] = \mathbf{0} \in \mathbb{R}^{l}$（或任意其他值）。
3.  选择 $0 < \mu < 2$ 且 $\delta$ 取较小值。
