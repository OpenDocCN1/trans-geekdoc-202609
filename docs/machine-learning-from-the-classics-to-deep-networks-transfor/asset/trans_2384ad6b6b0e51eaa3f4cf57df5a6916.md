
回想根据 Beta 分布，`P ∈ [0, 1]`。注意这 `K` 个概率*不必*加起来等于 1。相反，正如我们在 CRP 情况下指出的那样，`K` 个混合概率的先验被设为狄利克雷分布。这是因为它们必须加起来等于 1。每个点*必然*由 `K` 个混合分量中的任意一个发射。相反，在我们当前的设定中，第 `k` 个特征要么以概率 `P[k]` 被观测值共享，要么以概率 `1 − P[k]` 不被共享。为了得到极限情况 `K → ∞`，Beta 分布的参数被设为 `a = α/K` 和 `b = 1`。这种选择使得归一化常数（第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章）等于

```
B(α/K, 1) = Γ(α/K)Γ(1) / Γ(α/K + 1) = K/α,
```

其中考虑了 Gamma 函数的递归性质 `Γ(x + 1) = x Γ(x)`。

**取极限 `K → ∞`**：证明有点技术性，可参阅文献 [23] 和习题 [13.23](#Chp013_635-716_B9780443292385000196.xhtml#o0215)。不过，我们将对证明中涉及的某些步骤进行评论，因为这些步骤揭示了一些有趣的性质。通过取上述模型的极限来推导先验的第一步是计算概率 `P(Z)`。这是通过在公式 [(13.129)](#Chp013_635-716_B9780443292385000196.xhtml#deq197) 中将 `P[k]` 边缘化（积分）掉来完成的，同时考虑到它们服从 Beta 分布。这导致 `P(Z)` 与 `K` 成反比，当 `K` 趋于无穷大时趋于零。这是自然的。如果 `K → ∞`，任何二进制矩阵 `Z` 出现的概率都趋于零。然而，这里有一个关键点。我们感兴趣的不是 `P(Z)`，而是别的东西！

**二进制矩阵的等价类**：概率 `P(Z)` 并不能提供我们要找的表示。原因在于两个矩阵可能不同，却能传达相同的信息。例如，假设 `N = 8` 并考虑 `Z` 的第 `k` 行为

```
z̃_k^T = [1, 0, 0, 1, 1, 0, 0, 1].
```
