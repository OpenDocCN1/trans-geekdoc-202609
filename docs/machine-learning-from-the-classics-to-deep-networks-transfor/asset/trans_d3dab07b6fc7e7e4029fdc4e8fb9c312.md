
正如我们已经评论的那样，前馈神经网络属于参数模型这一更一般的类别；因此，原则上，本书迄今为止遇到的任何损失函数都可以使用。多年来，某些损失函数在回归和分类任务的背景下变得流行。然而，在前馈多层网络的背景下，损失函数的选择与所使用的*输出*非线性类型紧密耦合。一个“错误”的*组合*会严重影响网络在训练期间的学习速度。为了理解这一论点，让我们考虑以下组合。

采用平方误差作为损失函数，采用逻辑斯蒂函数 `σ(z)` 作为输出非线性，如公式 (18.7) 所示。为简单起见，假设我们只有一个输出节点，并且省略与观测相关的索引 `n` 以及与层相关的索引 `r`。然后，如果 `y` 是目标值，`ŷ` 是估计值，则对代价函数的贡献将是

```
J = 1/2 (y - ŷ)^2 = 1/2 (y - σ(z))^2, z = θ^T y,
```

其中 `y` 是最后一隐藏层节点输出的（扩展）向量，`θ` 是连接最后一隐藏层节点到输出节点的突触权重向量。根据标准做法，偏置项已被吸收在 `θ` 中。然后，利用导数的链式法则，`J` 关于 `θ` 的梯度显然是

```
∂J/∂θ = ∂J/∂z ∂z/∂θ = δ y, δ := ∂J/∂z,
```

考虑到公式 (18.40)，我们得到

```
δ = ∂J/∂ŷ ∂ŷ/∂z = (ŷ - y) σ'(z).
```

因此，

```
∂J/∂θ = (ŷ - y) σ'(z) y.
```
