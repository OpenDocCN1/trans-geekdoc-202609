

### 18.4.3 超越梯度下降的基本原理

另一条提高基于梯度下降的反向传播算法收敛速率的途径，是以增加复杂度为代价，采用以某种方式涉及二阶导数相关信息的方案。我们在本书中已经讨论过这类家族，例如第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章介绍的牛顿家族。对于每一个可用的家族，都可以推导出一个反向传播版本，以满足神经网络训练的需求。我们将不深入细节，因为其概念与梯度下降所讨论的保持一致。区别在于现在二阶导数也必须向后传播。更多细节请参阅文献 [16,30,66,113,228] 及其参考文献。

在文献 [8,94,106] 中，开发了基于共轭梯度思想的方案；牛顿家族的成员已在文献 [10,164,211] 等中被提出。在所有这些方案中，都需要计算海森矩阵的元素，即：

```
∂²J / (∂θⱼₖʳ ∂θⱼ'ₖ'ʳ')
```
