
该区域显然是一个*闭凸*集。请注意，*每一对*训练点，(`y[n]`，**x[n]**），`n = 1, 2, …, N`，都定义了一个方向不同（取决于**x[n]**）且空间位置不同（由`y[n]`决定）的超平板。此外，[(8.31)](#Chp008_343-416_B9780443292385000147.xhtml#deq63)保证未知量**θ[o]**位于所有这些超平板内；因此，**θ[o]**位于它们的*交集*中。现在我们所要做的就是推导超平板上的投影算子（稍后我们将进行推导），并使用一种POCS方案来寻找交集中的一个点。假设有足够的训练点可用，并且交集“足够小”，则该交集中的任意点都将“接近”**θ[o]**。请注意，此类过程并非基于优化论证。然而请回顾一下，即使在优化技术中，也必须使用迭代算法，而在实践中，迭代必须在有限步数后停止。因此，只能近似达到最优值。关于这些问题及相关的收敛性质将在本章后面进一步讨论。

现在显而易见的问题是，如果噪声无界会发生什么？对此有两种回答。首先，在任何涉及测量的实际应用中，噪声必须是有界的。否则，电路就会烧毁。因此，至少在概念上，这一假设并不与实际情况相冲突。这只是一个为`ϵ`选择合适值的问题。第二个回答是，可以选择`ϵ`为假设噪声模型标准差的几倍。那么**θ[o]**将以高概率位于这些超平板内。我们将讨论选择`ϵ`的策略，但本节的目标是讨论在实际应用中使用该理论的主要基本原理。不必说，超平板并没有什么神圣之处。如果特定应用中噪声的性质暗示了不同类型的凸集，也可以使用其他闭凸集。
