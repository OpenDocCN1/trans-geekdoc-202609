

$p(\mathbf{\theta};a,b) = \int p(\mathbf{\theta}|\mathbf{\alpha})p(\mathbf{\alpha})\ d\mathbf{\alpha} = \int\prod\limits_{k = 0}^{K - 1}\mathcal{N}\left( \theta_{k}|0,\alpha_{k}^{- 1} \right)\text{Gamma}(\alpha_{k}|a,b)\ d\mathbf{\alpha} = \prod\limits_{k = 0}^{K - 1}\text{st}\left( \theta_{k}|0,\frac{a}{b},2a \right),$

其中 $\text{st}(x|\mu,\lambda,\nu)$ 是 Student's $t$ 概率密度函数，定义为

```
st(x|\mu,\lambda,\nu) = \frac{\Gamma(\frac{\nu + 1}{2})}{\Gamma(\frac{\nu}{2})}\left( \frac{\lambda}{\pi\nu} \right)^{1/2}\frac{1}{\left( 1 + \frac{\lambda{(x - \mu)}^{2}}{\nu} \right)^{\frac{\nu + 1}{2}}}.
```
