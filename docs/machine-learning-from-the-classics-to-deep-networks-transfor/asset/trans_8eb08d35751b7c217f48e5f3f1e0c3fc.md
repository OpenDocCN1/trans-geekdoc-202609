
请注意，尽管 `λ[t]` 保证了最优性，但在实践中，对于某些时间步 `t`，它可能会取得相对较大的值（回想一下 `σ[t]² = β[t]`）。文献 [85] 指出，设置 `λ[t] = 1` 可获得良好的性能。对于加权序列，也提出了其他更“花哨”的选择，参见例如 [37]。

待最小化的代价函数源自公式 [(19.64)](#Chp019_997-1102_B9780443292385000251.xhtml#deq138) 中的界，在对所有观测值 `x[0]` 取期望之后得到。此外，请注意，关于 `q(x[t]|x[0])` 的条件期望等同于根据公式 [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135) 对 `p(ϵ) = N(ϵ|0, I)` 取期望。因此，对于简化模型的情况，第二个分量对代价的贡献变为

```
∑_{t=2}^{T} E_{x_0 ~ q(x_0)} E_{ϵ ~ N(0,I)} [ λ_t || ϵ - ϵ_θ(x_t, t) ||^2 ]
```
(19.70)

其中 `x[t]` 根据公式 [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135) 用 `ϵ` 表示。在实践中，期望由样本均值代替。文献 [85] 建议，不必对时间 t 求和各项，而是可以使用均匀采样在 `[1, T]` 中随机选择一个时间索引，并基于对应的项执行参数更新。关于噪声的第二个期望由单个样本近似。[算法 19.4](#Chp019_997-1102_B9780443292385000251.xhtml#enun0090) 总结了训练步骤。术语 `f_θ(·)` 表示参数化神经网络的输出。
