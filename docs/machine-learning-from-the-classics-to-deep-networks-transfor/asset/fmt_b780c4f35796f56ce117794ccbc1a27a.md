   `P[n|n] = P[n|n-1] - K[n] * H[n] * P[n|n-1]`

5. **Time Update (State Prediction)**
   `x̂[n+1|n] = F[n+1] * x̂[n|n]`

   `P[n+1|n] = F[n+1] * P[n|n] * F[n+1]^(T) + Q[n+1]`
