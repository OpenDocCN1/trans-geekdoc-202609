

### 2.2.5 随机变量的变换

设 **x** 和 **y** 为两个随机向量，它们通过如下变换相关联：

**y** = **f**(**x**), (2.43)

其中 **x** 和 **y** 是由变换函数 **f** 关联的随机向量。

在本章的其余部分，我们将主要处理实随机变量。每当需要时，将说明与复变量情况的差异。

类似地，对于复随机向量 **z** = **x** + *j***y** ∈ ℂ^(*l*)，我们有

*p*(**z**) := *p*(*x*[1], …, *x*[*l*], *y*[1], …, *y*[*l*]), (2.41)

其中 *x*[*i*], *y*[*i*], *i* = 1, 2, …, *l* 分别是所涉及实向量的分量。

协方差矩阵和相关矩阵的定义类似：

Cov(**z**) := 𝔼 [(**z** − 𝔼[**z**])(**z** − 𝔼[**z**])^(*H*)], (2.42)

其中 “*H*” 表示埃尔米特（转置和共轭）运算。

复随机变量 *z* 的方差定义为：

*σ*[*z*]² = 𝔼 [|*z* − 𝔼[*z*]|²] = 𝔼 [|*z*|²] − |𝔼 [*z*]|². (2.40)
