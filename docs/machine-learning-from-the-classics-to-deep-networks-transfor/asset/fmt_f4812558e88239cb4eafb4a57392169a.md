Note that this result holds true not only asymptotically, but also for a finite number of samples `N`. If one wishes to decrease further the mean-square error, then *biased* estimators, as produced via regularization, have to be considered; this has already been discussed in Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml); see also [16,50] and the references therein.
