
### 正规化流

我们已经处理了许多不同的生成网络。在第 19.7 节中，我们将讨论扩散模型家族。**正规化流** 也是该方法家族的成员。它们是试图将概率分布**拟合** 到输入数据的概率模型。因此，与 VAE 类似，正规化流围绕似然目标概念演变，以获得相关模型定义参数的估计。

正规化流建模的核心在于一个基础分布，例如 `p_z(z)`，它可以轻松采样，如标准高斯分布。此外，假设输入数据样本 `x` 是通过一个作用于从 `p(z)` 中抽取的样本 `z` 的参数化**可逆** (向量值) 函数/变换生成的，即：

```
x = f(z; θ) and z = f^(-1)(x; θ).
```

根据第 2.2.5 章，公式 (2.45)，相应的 PDF 相关联为：

```
p_x(x) = p_z(z) / |det(J(x; z))| |_{z = f^(-1)(x)},  (19.25)
```

其中 `J(·; ·)` 是相应的雅可比矩阵。例如，对于标量随机变量，前面的公式变为：

```
p_x(x) = p_z(z) / |dx/dz| |_{z = f^(-1)(x)}.
```

现在的挑战是获得这样一个可逆变换。为此，可以调用多层网络，相关的定义参数 `θ` 在训练期间学习。代价函数是通过公式 (19.25) 在一组观测样本 `x[n]`，`n = 1, 2, …, N` 上计算的似然函数。
