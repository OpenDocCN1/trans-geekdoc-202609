
在公式 [(7.1)](#Chp007_293-342_B9780443292385000135.xhtml#deq1) 中应用贝叶斯定理，

$$P(\omega_{j}|\mathbf{x}) = \frac{p(\mathbf{x}|\omega_{j})P(\omega_{j})}{p(\mathbf{x})},\quad j = 1,2,\ldots,M,$$

其中 $p(\mathbf{x}|\omega_{j})$ 是相应的条件概率密度函数（PDF），贝叶斯分类规则变为

$$\text{将 } \mathbf{x} \text{ 归入 } \omega_{i} = \arg\max_{\omega_{j}} p(\mathbf{x}|\omega_{j})P(\omega_{j}),\quad j = 1,2\ldots,M.$$

注意，公式 [(7.2)](#Chp007_293-342_B9780443292385000135.xhtml#deq2) 分母中的数据概率密度函数 (PDF) $p(\mathbf{x})$ 不参与最大化任务，因为它是一个与类别 $\omega_{j}$ 无关的正量；因此，它不影响最大化过程。换句话说，分类器取决于先验类概率和相应的条件 PDF。此外，请回顾

$$p(\mathbf{x}|\omega_{j})P(\omega_{j}) = p(\omega_{j}, \mathbf{x}) = p(y, \mathbf{x}),$$

在当前语境中，输出变量 $y$ 表示与相应类别 $\omega_{i}$ 关联的标签。最后一个方程验证了第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章所述内容；即贝叶斯分类器是一种生成式建模技术。
