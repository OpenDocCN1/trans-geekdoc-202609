

## 长短期记忆（LSTM）网络

LSTM 网络背后的关键思想，源自开创性论文 [77] 的提出，即所谓的*单元状态*，它有助于克服网络内部长期依赖导致的梯度消失/爆炸现象相关问题。

### 梯度流的数学分析

假设公式 (18.67) 中的 *f* 为标准 tanh 函数，并利用已知表^[120] 中其对应的导数：

```
∂h_{n+1}/∂h_n = w(1 - h_{n+1}^2)
```

根据 tanh 函数的定义，*h*[n+1] 的幅值小于 1。写出两个连续步骤的递推关系，可得：

```
∂J/∂h_n = w^2(1 - h_{n+1}^2)(1 - h_{n+2}^2) ∂J/∂h_{n+2} + 其他项。
```

不难看出，小于 1 的项相乘会导致数值消失，特别是考虑到实际中序列可能相当长，例如 *N* = 100。因此，对于接近 *n* = 1 的时刻，公式 (18.70) 右侧第一项对梯度的贡献将涉及大量幅值小于 1 的数的乘积。另一方面，*w* 的值将以 *w*^n 的幂次形式起作用。因此，如果其值大于 1，会导致相应梯度出现爆炸值（参见，例如 [154]）。

### 缓解技术

在许多情况下，可以将反向传播算法*截断*至几个时间步。另一种方法是将 tanh 非线性替换为 ReLU。针对数值爆炸的情况，可以引入*裁剪*技术，一旦数值超过预设阈值，即将其裁剪至该阈值。

然而，另一种在实践中常用的技术是用替代结构取代前面描述的标准 RNN 公式，这种结构能更好地应对由长期依赖引起的此类现象。

### 备注 18.6

*   **深层 RNN**：除了包含单层状态的基本 RNN 网络外，还提出了涉及多层状态（一层叠在另一层之上）的扩展（参见，例如 [155]）。
*   **双向 RNN**：顾名思义，在双向 RNN 中，存在两个状态变量，即一个记为 $\\overset{\\rightarrow}{\\mathbf{h}}$，向前传播；另一个记为 $\\overset{\\leftarrow}{\\mathbf{h}}$，向后传播。这样，输出就取决于过去和未来两者（参见，例如 [56]）。
