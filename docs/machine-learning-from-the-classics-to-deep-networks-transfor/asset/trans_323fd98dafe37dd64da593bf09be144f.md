
请注意，使用贝叶斯框架，给定观测值集合 `x` 对应的潜变量的计算，可以自然地通过公式 [(20.84)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq123) 中的后验概率 `p(z|x)` 获得。例如，可以选取相应的均值

```
z = (1/σ²) Σ_{z|x} A^T x.
```

利用矩阵求逆引理 ([习题 20.4](#Chp020_1103-1179_B9780443292385000263.xhtml#o0090))，结果表明公式 [(20.83)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq120) 和 [(20.89)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq128) 完全相同；然而，现在这是我们贝叶斯假设的一个自然推论。

计算 `A` 的一种方法是对 `∏_{n=1}^N p(x_n)` 应用最大似然法，并关于 `A` 和 `σ²`（如果 `μ ≠ 0`，则还包括 `μ`）进行最大化。结果表明，`A` 的最大似然解由文献 [175] 给出：

```
A_ML = U_m diag{λ_1−σ²,…,λ_m−σ²} R,
```

其中 `U_m` 是一个 `l × m` 矩阵，其列为 `x` 的样本协方差矩阵中最大的 `m` 个特征值 `λ_i`（`i = 1, 2, …, m`）对应的特征向量，而 `R` 是一个任意正交矩阵（`R R^T = I`）。令 `R = I`，则 `A` 的列即为第 [20.3](#Chp020_1103-1179_B9780443292385000263.xhtml#s0020) 节讨论的经典 PCA 所计算出的（缩放后的）主方向。无论如何，`A` 的列张成了标准 PCA 的主子空间。请注意，当 `σ² → 0` 时，PPCA 趋近于 PCA ([习题 20.5](#Chp020_1103-1179_B9780443292385000263.xhtml#o0095))。此外，结果表明

```
σ_ML² = (1/(l - m)) ∑_{i=m+1}^l λ_i.
```
