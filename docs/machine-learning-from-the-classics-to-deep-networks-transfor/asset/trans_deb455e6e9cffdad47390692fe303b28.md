
上述符号表示 `f` 单独作用于各个向量分量，而向量扩展一维是为了按照标准惯例纳入偏置项。

对于具有许多层和每层许多节点的大型网络，这种连接方式在参数（权重）数量方面被证明代价高昂，其数量级为 `k[r] * k[r - 1]`。例如，如果 `k[r - 1] = 1000` 且 `k[r] = 1000`，这将达到 100 万参数的数量级。请注意，该数字仅来自某一层参数的贡献。然而，正如第 [3.8](#Chp003_65-117_B9780443292385000093.xhtml) 节已讨论的那样，大量参数会使网络在训练时容易发生过拟合。

相反，可以采用所谓的*权重共享*技术（例如 [156,204]），通过适当的内置约束，让一组参数在多个连接间*共享*。将在第 [18.12](#Chp018_885-995_B978044329238500024X.xhtml#s0170) 节讨论的卷积网络，就属于这类权重共享网络。正如我们将看到的，在卷积网络中，卷积运算取代了内积运算，这允许大量的权重共享，从而大幅减少所需的参数数量。

### 备注 18.2

*   **浅层网络与深层网络**：从现在起，我们将网络中的层数称为网络的*深度*。最多具有三层（两个隐藏层）的网络称为*浅层*网络，而具有三层以上的网络称为*深层*网络。

## 18.4 反向传播算法

前馈神经网络由若干层神经元组成，每个神经元由相应的突触权重集及其偏置项决定。从这个角度来看，神经网络实现了一个非线性参数函数 `ŷ = f_θ(x)`，其中 `θ` 代表网络中存在的所有权重/偏置。因此，训练神经网络似乎与训练任何其他参数预测模型没有什么不同。所需的只是 (a) 一组训练样本，(b) 一个损失函数 `L(y, ŷ)`，以及 (c) 一个迭代方案，例如梯度下降，以执行相关代价函数（经验损失；见第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章第 [3.14](#Chp003_65-117_B9780443292385000093.xhtml) 节）的优化，

```
J(θ) = Σ_{n=1}^{N} L(y_n, f_θ(x_n)).
```

训练神经网络的困难在于其多层结构使梯度计算变得复杂，而梯度参与了优化过程。此外，McCulloch-Pitts 神经元基于不连续的 Heaviside 激活函数，该函数不可微。开发用于训练神经网络的实用算法的第一步是用 Heaviside 激活函数的可微近似来替代它。

**Logistic Sigmoid 神经元**：一种可能性是采用 logistic sigmoid 函数，即

```
f(z) = σ(z) := 1 / (1 + exp(-a z)).
```

该函数的图形如 [图 18.8](#Chp018_885-995_B978044329238500024X.xhtml#f0045) 所示。请注意，参数 `a` 的值越大，对应的图形就越接近 Heaviside 函数的图形。另一种可能性是使用

```
f(z) = a tanh(c z / 2),
```
