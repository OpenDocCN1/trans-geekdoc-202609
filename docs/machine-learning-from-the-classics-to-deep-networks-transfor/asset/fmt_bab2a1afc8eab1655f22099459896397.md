
This time update recursion, once the observations for **y**[*n*] have been received, has a form that we will meet over and over again in this book. The “new” (posterior) estimate is equal to the “old” (prior) one, which is based on *the past history, plus a correction term*; the latter is proportional to the error **e**[*n*] between the newly arrived observations vector and its prediction based on the “old” estimate. Matrix *K*[*n*], known as the *Kalman gain*, controls the amount of correction, and its value is computed so as to minimize the MSE; in other words,

```
J(K[n]) := 𝔼[e[n|n]^(T) e[n|n]] = trace{P[n|n]},
```

where

```
P[n|n] = 𝔼[e[n|n] e[n|n]^(T)]
```

and

```
e[n|n] := x[n] - x̂[n|n].
```

It can be shown that the optimal Kalman gain is equal to (Problem [4.22](#Chp004_119-175_B978044329238500010X.xhtml#o0115))

```
K[n] = P[n|n−1] H[n]^(T) S[n]^(−1),
```

where

```
S[n] = R[n] + H[n] P[n|n−1] H[n]^(T).
```
