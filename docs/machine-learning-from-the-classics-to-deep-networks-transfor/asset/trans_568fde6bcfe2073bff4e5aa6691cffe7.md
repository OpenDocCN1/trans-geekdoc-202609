
其中 `β[t] ∈ [0, 1)` 是一系列过程方差。尽管该序列可以被学习，但在典型模型中，它是根据用户定义的时间表固定的，参见例如 [169]。例如，在 [85] 中，`β[1]` 被设置为 `10^(-4)`，并线性增加到 `β[T] = 0.02` 的值，其中 `T` 被设置为 1000。换句话说，时间 `t` 处的条件/转移分布（参见第 [14](#Chp014_717-754_B9780443292385000202.xhtml) 章）是高斯分布，其均值是 `x[t-1]` 的缩放版本，协方差矩阵等于 `β[t]I`，其中 `I` 是单位矩阵。

由于条件分布的高斯性质，不难证明（[问题 19.4](#Chp019_997-1102_B9780443292385000251.xhtml#o0060)）在给定输入观测值的条件下，时间 `t` 处的扩散版本由以下公式描述：

```
q(x_t|x_0) = N( x_t|√(ā_t)x_0, (1 - ā_t)I ),
```

其中 `a[t] := 1 - β[t]` 且 `ā_t := ∏_{k=1}^t a_k`。或者，给定观测值 `x[0]`，并使用第 [19.2.6](#Chp019_997-1102_B9780443292385000251.xhtml#s0065) 节讨论的重参数化技巧，我们可以写为：

```
x_t = √(ā_t)x_0 + √(1 - ā_t)ε,
```
