#### 餐厅构造

类似于 CRP，事实证明，以下隐喻是从公式 [(13.132)](#Chp013_635-716_B9780443292385000196.xhtml#deq204) 中的先验采样的一种方式。想象一下，`Z` 的列对应顾客，而行对应一条无限长的自助餐台上的菜肴，这受典型印度餐厅菜品种类繁多的启发！这就是该方法被称为 *Indian buffet process*（IBP，印度自助餐过程）的原因。

1.  **1.** 第一位顾客，`n = 1`，根据参数为 `α` 的泊松分布取 `K^(1)` 道菜，即：

```
P(K^(1); α) = (α^K(1) exp(-α)) / K^(1)!.
```

2.  **2.** 第 `n` 位顾客以概率 `m_k / n` 选择之前已被选过的菜肴，其中 `m_k` 是已尝试第 `k` 道菜（特征）的顾客数量。他/她还会根据参数为 `α/n` 的泊松分布尝试 `K^(n)` 道新菜，即：

```
P(K^(n); α/n) = ((α/n)^K(n) exp(-α/n)) / K^(n)!.
```
