
在之前考虑的 HMM 中，系统动态通过潜变量描述，其图形表示为一条链。然而，对于某些应用，这种模型可能过于简单。HMM 的一个变体涉及 `M` 条链，而不是一条链，其中每条潜变量链独立于其他链随时间展开。因此，在时刻 `n`，涉及 `M` 个潜变量，记为 **x**[`n`]^(`m`)，`m` = 1, 2, …, `M` [17, 34, 81]。观测值作为组合发射出现，所有潜变量均参与其中。对于 `M` = 3 的相应图形结构如 [图 16.20](#Chp016_805-853_B9780443292385000226.xhtml#f0110) 所示。正如图形模型所暗示的，每条链各自独立发展。此类模型被称为**阶乘 HMM**（FHMM）。

一个显而易见的问题是：为什么不通过增加可能状态的数量来使用单条潜变量链？事实证明，这种朴素的方法会导致复杂度激增。以 `M` = 3 为例，其中每个潜变量的状态数均为 10。每条链的转移概率表需要 10² 个条目，总计 300 个，即 `P`[`i``j`]^(`m`)，`i`, `j` = 1, 2, …, 10，`m` = 1, 2, 3。此外，可实现的状态组合总数为 10³ = 1000。若要通过单条链实现相同数量的状态，将需要一个包含 (10³)² = 10⁶ 个条目的转移概率表！

```
$P(\mathbb{X}_{n}|\mathbb{X}_{n - 1}) = \prod\limits_{m = 1}^{M}P^{(m)}\left( \mathbf{x}_{n}^{(m)}|\mathbf{x}_{n - 1}^{(m)} \right).$
```
