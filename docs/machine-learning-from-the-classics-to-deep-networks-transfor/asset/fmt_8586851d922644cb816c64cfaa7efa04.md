#### 8.17 证明题

证明：如果 `S` 是希尔伯特空间 `H` 中的一个闭子空间（`S ⊂ H`），则对任意 `x, y ∈ H`，有：

```
⟨x, P_S(y)⟩ = ⟨P_S(x), y⟩ = ⟨P_S(x), P_S(y)⟩
```

1.  以及
    `P_S(a x + b y) = a P_S(x) + b P_S(y)`。
