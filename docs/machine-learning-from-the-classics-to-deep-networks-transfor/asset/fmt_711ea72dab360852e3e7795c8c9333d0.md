
#### Classifier-free guidance

A major problem with the previous method is the training of a separate classifier. In [86], the need for a separate classifier is bypassed by jointly training conditional and unconditional diffusion models.

Let us denote as `s_θ(x_t, t, y)` the class-conditioned estimate of the score function and as `s_θ(x_t, t)` the unconditional one. During training, a single neural network is used to parameterize both models. This is achieved via a simple trick. An input token, `∅`, that corresponds to the unconditional model is used to feed the class-embedding vector in place of the associated class label `y`. That is:

```
s_θ(x_t, t) = s_θ(x_t, t, y = ∅).
```

The conditional and unconditional models are jointly trained by randomly selecting between conditional (`y ≠ ∅`) and unconditional (`y = ∅`) inputs according to a pre-selected user-defined probability, `p_∅`.
