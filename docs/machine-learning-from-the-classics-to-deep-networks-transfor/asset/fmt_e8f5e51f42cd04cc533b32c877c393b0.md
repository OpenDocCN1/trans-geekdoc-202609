
which is in line with the prediction model used in LMS, at time `n`. That is, the unknown set of parameters is a time-varying one. The statistical properties of the input vector `x`, as well as the noise variable `η`, are assumed to be time-independent, and this is the reason we have not used the time index; equivalently, in the case where the input is a random process, `u[n]`, it is assumed to be *stationary*. Moreover, the input variables are assumed to be independent of the zero mean noise variable, `η`. Furthermore, successive samples of `η` are i.i.d. (white noise sequence) of variance `σ[η]²`. So far, we have not gone much beyond Assumption 1, stated in Section [5.5.1](#Chp005_177-248_B9780443292385000111.xhtml#s0050).

### Assumption 2

The time-varying model follows a random walk variation, represented by

```
θ[o, n] = θ[o, n − 1] + ω
```

The random vector `ω` is assumed to be of zero mean with covariance matrix

```
E [ω ω^(T)] = Σ[ω]
```

Note that the variance of a random walk grows unbounded with time; this is readily shown by applying Eq. [(5.73)](#Chp005_177-248_B9780443292385000111.xhtml#deq166) recursively.

A variant of this model would be more sensible to use, namely

```
θ[o, n] = a θ[o, n − 1] + ω
```

with `|a| < 1` [106]. However, the analysis gets more involved, so we will stick with the model in Eq. [(5.73)](#Chp005_177-248_B9780443292385000111.xhtml#deq166). After all, our goal here is to highlight and have a first touch on the notion of tracking and to get an idea of its effects on the misadjustment in steady state.

### Assumption 3

As in Section [5.5.1](#Chp005_177-248_B9780443292385000111.xhtml#s0050), we assume that `c[n − 1] := θ[n − 1] − θ[o, n − 1]` is independent of `x` and `η`. This time, we will also assume independence of `c[n]` and `ω`.

Recall from Eq. [(5.46)](#Chp005_177-248_B9780443292385000111.xhtml#deq86) that the excess MSE at time `n` is given by

```
J[exc, n] = trace{Σ[x] Σ[c, n − 1]}
```

Thus, our goal now is to compute `Σ[c, n − 1]` for the time-varying model case. It is straightforward to see that the counterpart of Eq. [(5.35)](#Chp005_177-248_B9780443292385000111.xhtml#deq68) now becomes

```
c[n] = (I − μ x x^(T)) c[n − 1] + μ x η − ω
```
