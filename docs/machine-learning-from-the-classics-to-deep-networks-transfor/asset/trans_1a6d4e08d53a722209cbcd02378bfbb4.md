
# 深度网络的紧凑表示与表达能力

继前面的讨论之后，现在提出的一个问题是：是否可以通过相对简单的函数表述获得输入-输出表示，例如支持向量机所暗示的表述，或者通过少于三层神经元/处理元件的网络获得，且其性能相当，哪怕是以每层更多元件为代价。

第一点的答案是肯定的，只要输入-输出依赖关系足够简单。然而，对于更复杂的任务，需要学习更复杂的依赖关系，例如视频记录中的场景识别、语言和语音识别，其潜在的函数依赖性质非常复杂，以至于我们无法用简单的方式用解析形式表达它。

关于第二点，即仅包含少数几层的浅层网络，其答案在于所谓的表示*紧凑性*。我们说一个实现输入-输出函数依赖的网络是紧凑的，如果它由相对较少的自由参数（较少的计算元件）组成，这些参数/元件需在训练阶段被学习/调整。因此，对于给定数量的训练点，我们期望紧凑表示能带来更好的泛化性能。

事实证明，使用层数更多的网络，可以获得输入-输出关系的更紧凑表示。尽管没有针对通用学习任务的理论发现来证明这一主张，但布尔函数电路理论的理论结果表明：一个可以由（比如说）`k` 层逻辑元件紧凑实现的函数，如果通过 `k − 1` 层来实现，可能需要指数级大量的元件。其中一些结果已被推广，在某些特殊情况下对学习算法也适用。例如，具有 `l` 个输入的奇偶函数，用高斯支持向量机表示需要 `𝒪(2^l)` 个训练样本和参数，用单隐层神经网络需要 `𝒪(l²)` 个参数，而用具有 `𝒪(log₂ l)` 层的多层网络只需 `𝒪(l)` 个参数和节点（参见例如 [13,14,146]）。

文献 [134,158] 表明，对于一类特殊的深度网络和目标输出，与浅层网络相比，达到预定精度所需的节点数量要少得多。文献 [137] 中，对于采用 ReLU 的网络，已经证明层的组合在输入空间中识别出线性区域，其数量对网络深度呈指数依赖。文献 [41] 表明，在 `ℝ^l` 中存在一个简单函数，它可以用一个小型的三层前馈神经网络表达，而*任何*双层网络都无法对其进行充分逼近，除非节点数量相对于维度呈指数级增长。这一结果几乎适用于所有已知的激活函数，包括 ReLU。形式上，这些结果表明，对于标准前馈神经网络，深度——即使仅增加一层——也可能比宽度（每层节点数）具有指数级更大的价值。文献 [203] 推导出了精神类似的结果。文献 [31] 关注卷积网络；利用张量代数论证，证明除可忽略不计（零测度）的一组函数外，所有可由多项式规模深度网络实现的函数，若要由浅层网络实现甚至逼近，都需要指数级的规模。

文献 [123] 考虑了宽度（一层中的节点数）与深度之间的相互作用。提出的问题是：是否存在宽网络*无法被规模无显著增加的窄网络所实现*。这与所谓的“存在性”路径截然相反，即寻找那些能用特定深度高效实现、却无法用更浅深度高效实现的函数。文中证明了存在一族 ReLU 网络，无法被深度增加幅度不超过多项式级别的更窄网络所逼近。该文的理论和实验证据指出，对于 ReLU 网络的表达能力而言，深度可能比宽度更有效。此外，该文还提出了一些开放问题。在当前版本编撰之时，该主题构成了一个持续研究的领域。

对于该领域的新手来说，上述论点可能看起来有点令人困惑，因为我们已经陈述过，具有两层节点的网络是某一类函数的通用逼近器。然而，该定理并未说明如何在实践中实现这一点。例如，任何连续函数都可以用单项式求和任意逼近。尽管如此，可能需要大量的单项式，这在实践中是不可行的。在任何学习任务中，我们都必须关注在给定表示下什么是可行地“可学习”的。感兴趣的读者可参考例如 [206]，了解使用多层架构预期能获得的益处。
