
# Let us apply the Robbins–Monro algorithm to solve for the optimal MSE linear estimator if the covariance matrix and the cross-correlation vector are unknown.

We know that the solution corresponds to the root of the gradient of the cost function, which can be written in the form (recall the orthogonality theorem from Chapter [3](#Chp003_65-117_B9780443292385000093.xhtml) and Eq. [(5.8)](#Chp005_177-248_B9780443292385000111.xhtml#deq11)):

`Σ[x]θ − p = 𝔼 [x(x^(T)θ − y)] = 0.`

![Equation](images/B9780443292385000111/si150.png)

Given the training sequence of observations, `(y[n], x[n])`, which are assumed to be i.i.d. drawn from the joint distribution of `(y, x)`, the Robbins–Monro algorithm becomes:

`θ[n] = θ[n − 1] + μ[n]x[n](y[n] − x[n]^(T)θ[n − 1]),` (5.34)

![Equation](images/B9780443292385000111/si153.png)

which converges to the optimal MSE solution provided that the two conditions in [(5.29)](#Chp005_177-248_B9780443292385000111.xhtml#deq53) are satisfied. Compare Eq. [(5.34)](#Chp005_177-248_B9780443292385000111.xhtml#deq61) with Eq. [(5.6)](#Chp005_177-248_B9780443292385000111.xhtml#deq9). Taking into account the definitions, `Σ[x] = 𝔼[xx^(T)], p = 𝔼[xy]`:

![Equation](images/B9780443292385000111/si154.png)

the former equation results from the latter one by dropping out the expectation operations and using an iteration-dependent step size. Observe that the iterations in Eq. [(5.34)](#Chp005_177-248_B9780443292385000111.xhtml#deq61) coincide with *time updates*; time has now explicitly entered into the scene. This prompts us to start thinking about modifying such schemes appropriately to track time-varying environments. Algorithms such as the one in Eq. [(5.34)](#Chp005_177-248_B9780443292385000111.xhtml#deq61), which result from the generic gradient descent formulation by replacing the expectation by the respective instantaneous observations, are also known as *stochastic gradient descent schemes*.
