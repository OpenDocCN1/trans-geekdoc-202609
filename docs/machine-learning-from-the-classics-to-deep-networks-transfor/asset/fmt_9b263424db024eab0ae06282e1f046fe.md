**Step 1**: Using $\widehat{\mathbf{x}}_{n - 1|n - 1}$![Equation](images/B978044329238500010X/si466.png), predict $\widehat{\mathbf{x}}_{n|n - 1}$![Equation](images/B978044329238500010X/si462.png) using the state equation; that is,

![Equation](images/B978044329238500010X/si467.png)(4.114)

In other words, ignore the contribution from the noise. This is natural, because prediction cannot involve the unobserved variables.
