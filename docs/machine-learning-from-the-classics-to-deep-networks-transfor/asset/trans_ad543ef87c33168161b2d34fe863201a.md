
假设我们得到一组输入观测值集合 $\mathcal{X}$，即 $\mathcal{X} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$。回顾第 [12.2](#Chp012_583-634_B9780443292385000184.xhtml) 节，贝叶斯回归任务的主要目标是获得两个概率密度函数（PDF），

$p(\mathbf{y}|\mathcal{X})$ 和 $p(y|\mathbf{x}, \mathbf{y}, \mathcal{X})$，

其中

$\mathbf{y} = \mathbf{f} + \boldsymbol{\eta}$，$\mathbf{y} := [y_1, \dots, y_N]^T$，

以及

$y = f(\mathbf{x}) + \eta$，

且 $\mathbf{f}$ 定义于公式 [(13.137)](#Chp013_635-716_B9780443292385000196.xhtml#deq216) 中。这两个 PDF 中的第一个是输出变量的联合概率密度，这些变量由 $\mathcal{X}$ 中的输入点生成；相关的随机性源于 $f$ 以及噪声 $\eta$。第二个 PDF 指的是在给定 $\mathbf{x}$ 的值和训练数据 $(y_n, \mathbf{x}_n)$，$n = 1, 2, \dots, N$ 的情况下，对 $y$ 的值进行预测。正如我们在第 [12.2](#Chp012_583-634_B9780443292385000184.xhtml) 节中所做的那样，我们将省略 $\mathcal{X}$ 以简化符号。

假设 $f(\cdot)$ 为零均值高斯过程，则 $\mathbf{f}$ 服从零均值、协方差矩阵为 $\mathcal{K}$ 的联合高斯分布，该矩阵由协方差函数/核函数 $\kappa(\cdot, \cdot)$ 决定，即

$p(\mathbf{f}) = \mathcal{N}(\mathbf{f}|0, \mathcal{K})$。

此外，设 $\boldsymbol{\eta}$ 为零均值、协方差矩阵为 $\Sigma_\eta$，且独立于 $f(\cdot)$；在不失一般性的前提下，令 $\Sigma_\eta = \sigma_\eta^2 I$。因此，

$p(\mathbf{y}|\mathbf{f}) = \mathcal{N}(\mathbf{y}|\mathbf{f}, \sigma_\eta^2 I)$。
