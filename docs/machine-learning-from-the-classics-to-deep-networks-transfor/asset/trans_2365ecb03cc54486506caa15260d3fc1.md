
请注意，公式 [(8.100)](#Chp008_343-416_B9780443292385000147.xhtml#deq191) 的结构与公式 [(8.99)](#Chp008_343-416_B9780443292385000147.xhtml#deq190) 相似。此外，随着 `n → ∞`，`Ψ[n]` 收敛于期望损失函数的海森矩阵 `H`。因此，对于涉及加权矩阵的适当选择并设定 `μ[n] = 1/n`，公式 [(8.99)](#Chp008_343-416_B9780443292385000147.xhtml#deq190) 和 [(8.100)](#Chp008_343-416_B9780443292385000147.xhtml#deq191) 可以以相似的速率收敛到 `θ[*]`；因此，在两种情况下，决定最终估计值与最优 `θ[*]` 接近程度的关键因素是所用数据点的数量。文献 [12,56,93] 表明

```
C
```

其中 `C` 是取决于所用相关期望损失函数具体形式的项。*因此，经过对涉及参数的适当微调，批处理算法及其在线版本均可使其以相似的速率收敛到 `θ[*]`。* 再次强调，由于大数据应用中的关键因素不是数据而是计算资源，与批处理算法相比，廉价的在线算法虽然是一种计算需求更大的方案，却能实现增强的性能（更低的超额误差）。这是因为对于给定的计算负载，在线算法可以处理更多的数据点（问题 [8.33](#Chp008_343-416_B9780443292385000147.xhtml#o0195)）。更重要的是，在线算法无需存储数据，数据到达时即可即时处理。关于该主题的更详细论述，感兴趣的读者可参阅文献 [14]。

在文献 [14] 中，两种形式的批处理线性支持向量机（第 [11](#Chp011_519-582_B9780443292385000172.xhtml) 章）与其在线随机梯度对应版本进行了对比测试。测试在 RCV1 数据集 [53] 上进行，训练集包含 781,265 篇文档，由（相对）稀疏的特征向量表示，包含 47,152 个特征值。经过适当调整且采用递减步长的随机梯度在线版本，与其批处理对应版本相比，在大幅降低的计算时间（不到十分之一）下实现了可比的错误率。

*   我们关于在线版本的讨论大多集中在最简单的版本上，即公式 [(8.99)](#Chp008_343-416_B9780443292385000147.xhtml#deq190) 中 `Φ[n] = I` 的情况。然而，随机梯度下降方案这一主题，特别是在光滑损失函数的背景下，拥有超过 60 年的丰富历史，并诞生了许多算法变体。在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中，讨论了基本 LMS 方案的多种变体。一些仍然流行的著名示例如下。
