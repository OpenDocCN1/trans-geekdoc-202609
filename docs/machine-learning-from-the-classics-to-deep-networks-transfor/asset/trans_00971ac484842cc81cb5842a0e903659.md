
本章的部署方式大致遵循了稀疏感知参数估计领域演变过程中的发展序列。我们有意遵循这条路径，因为这也表明了科学在大多数情况下是如何演进的。起点具有相当浓厚的数学色彩：在稀疏约束下，以数学上可处理的方式（即使用凸优化）来建立欠定线性方程组解的条件。最终，一系列个体贡献的积累揭示了：如果未知量是通过随机选择的数据样本进行感知的，则该解可以（唯一地）恢复。这一发展反过来催生了一个具有浓厚理论兴趣且对实际应用产生巨大影响的新领域。这个新兴领域被称为*压缩感知*或*压缩采样*（CS），它改变了我们关于如何高效感知和处理信号的观点。

### 压缩感知

在 CS 中，目标是直接获取尽可能少的样本，这些样本编码了获得压缩信号表示所需的最小信息量。为了演示这一点，让我们回到第 [9.4](#Chp009_417-462_B9780443292385000159.xhtml#s0025) 节讨论的数据压缩示例。在那里，曾评论说“经典”压缩方法相当不合常规，因为首先使用信号的所有（即 *l* 个）样本，然后对它们进行处理以获得 *l* 个变换值，最后仅使用其中一小部分进行编码。在 CS 设定中，程序变为以下过程。

设 *X* 为 *N* × *l* 感知矩阵，它作用于（未知）信号向量 **s**，以获得观测值 **y**；设 Ψ 为字典矩阵，描述信号 **s** 接受稀疏表示的域，即：

**s** = *Ψ***θ**, **y** = *X***s**.

假设 **θ** 的分量中至多有 *k* 个非零，若组合矩阵 *X*Ψ 满足 RIP，且观测数 *N* 足够大（由公式 [(9.33)](#Chp009_417-462_B9780443292385000159.xhtml#deq71) 中的界决定），则可通过以下优化任务获得：

```
min_{θ ∈ R^l} ||θ||_1, s.t. y = XΨθ
```

注意：**s** 无需存储，一旦 **θ** 已知，随时可获得。此外，正如我们即将讨论的，存在一些技术允许直接从模拟信号 *s*(*t*) 获取观测值 *y*[*n*]，*n* = 1, 2, …, *N*，而无需先获得其采样（向量）版本 **s**！因此，从这个角度来看，CS 将数据采集和压缩步骤融合在了一起。
