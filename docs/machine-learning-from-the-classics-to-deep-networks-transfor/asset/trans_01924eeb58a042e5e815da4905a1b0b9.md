## 15.2 图模型的必要性

让我们在医疗应用的背景下，考虑一个学习系统的简化示例。该系统包含一组 `m` 种疾病，对应隐变量，以及一组 `n` 种症状（发现）。疾病被视为随机变量 `d[1], d[2], …, d[m]`，每种疾病可以是不存在或存在，因此可以用零或一编码，即 `d[j] ∈ {0, 1}`，`j = 1, 2, …, m`。症状 `f[i]` 同理，可以是不存在或存在；因此，`f[i] ∈ {0, 1}`，`i = 1, 2, …, n`。症状构成观测变量。^([^(110)](#fn110))

系统的目标是预测疾病假设，即在观测到一组症状存在的情况下，预测多种疾病的存在情况。在基于专家评估的训练过程中，系统学习先验概率 `P(d[j])` 和条件概率 `P[ij] = P(f[i] = 1 | d[j] = 1)`，`i = 1, 2, …, n`，`j = 1, 2, …, m`。后者构成一个包含 `nm` 个条目的表。对于一个现实的系统，这些数字可能非常大。例如，在文献 [41] 中，`m` 的数量级为 500–600，`n` 的数量级为 4000。令 `f` 为对应于特定发现观测集合的向量，指示相应症状的存在或不存在。假设在给定任意疾病假设 `d` 的情况下，症状*条件独立*，我们可以写出

```
P(f|d) = ∏_{i=1}^{n} P(f_i|d).
```
(15.1)
