
其中，在导出公式[(19.75)](#Chp019_997-1102_B9780443292385000251.xhtml#deq149)的假设下，`Σ[θ*](x[t], t) = σ[t]²I`。项 `γ > 0` 是用户定义的梯度缩放因子，可对性能产生有益作用。请注意，在公式[(19.82)](#Chp019_997-1102_B9780443292385000251.xhtml#deq160)右侧的第二项中，我们可以等价地写为：

```
γ∇[x[t]]ln p[ϕ*](y|x[t], t) = ∇[x[t]]ln (p[ϕ*](y|x[t], t))^(γ)。
```

对于 `γ > 1`，分布 `(p[ϕ*](y|x[t], t))^(γ)` 比最优训练的分类器 `p[ϕ*](y|x[t], t)` 更尖锐，因为较大的值被指数放大了。因此，使用更大的缩放因子 `γ`，关注点会更多地转向分类器的模式，这有可能有利于生成保真度更高但多样性较低的样本 [44]。

分类器是在由相应扩散模型相同的加噪分布产生的样本上训练的。训练完成后，根据公式[(19.82)](#Chp019_997-1102_B9780443292385000251.xhtml#deq160)，分类器被纳入扩散模型的采样过程中。
