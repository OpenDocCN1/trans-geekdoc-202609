
基础梯度下降方案继承了梯度下降算法家族的所有优点（每次迭代步骤的计算需求低）和所有缺点（收敛慢），正如本书第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章首次介绍的那样。为了加快收敛速度，投入了大量的研究精力，并提出了大量基础梯度下降反向传播方案的变体。在本节中，我们提供了一些方向，这些方向在当前版本编写时似乎是实践中的趋势。

为简单起见，在推导出反向传播下降方案后，让我们摒弃指代层和相应层中特定神经元的索引 *r* 和 *j*。取而代之的是，将使用包含网络所有参数的参数/权重向量 **θ**。此外，学习算法第 *i* 次迭代时的相应估计将用 **θ**^((*i*)) 表示。

令 ℒ(*y*, **x**, **θ**) 为采用的损失函数。后者衡量真实输出 *y* 与相应预测值 *ŷ* 之间的偏差，后者取决于相应的输入 **x** 以及定义网络的参数 **θ**。所有训练点上的代价函数由下式给出：

```
$J(\mathbf{\theta}) = \sum\limits_{n = 1}^{N}\mathcal{L}(y_{n},\mathbf{x}_{n},\mathbf{\theta}).$
```

如果采用批处理，则在每次迭代中使用上述代价函数的梯度来更新参数，即 $\frac{\partial J(\mathbf{\theta})}{\partial\mathbf{\theta}}$，这涉及*所有*训练点。也就是说，每个周期仅执行一次参数向量更新。在另一极端，如果采用逐模式方案，则在每次迭代中，根据当前输入-输出对处计算出的损失函数梯度来估计更新，即 $\frac{\partial\mathcal{L}(y_{n},\mathbf{x}_{n},\mathbf{\theta})}{\partial\mathbf{\theta}}$。也就是说，在这种情况下，每个周期可获得 *N* 次参数更新。
