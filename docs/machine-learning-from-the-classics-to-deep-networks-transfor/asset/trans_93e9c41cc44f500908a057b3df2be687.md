
获得感测矩阵 `X` 有多种不同的方法，它们会导出乘积 `XΨ`，该乘积满足 RIP。可以证明（问题 [9.19](#Chp009_417-462_B9780443292385000159.xhtml#o0120)），如果 `Ψ` 是正交规范矩阵，且 `X` 是一个随机矩阵，其构造方式如第 [9.7.2](#Chp009_417-462_B9780443292385000159.xhtml#s0080) 节末尾所述，那么乘积 `XΨ` 将满足 RIP，前提是满足 [(9.33)](#Chp009_417-462_B9780443292385000159.xhtml#deq71)。获得满足 RIP 的组合矩阵的另一种方法是考虑另一个正交规范矩阵 `Φ`，其列与 `Ψ` 的列具有低相干性（两个矩阵间的相干性定义见公式 [(9.25)](#Chp009_417-462_B9780443292385000159.xhtml#deq55)，其中 `x[i]^(c)` 的位置现在由 `Φ` 的一列取代，`x[j]^(c)` 的位置由 `Ψ` 的一列取代）。例如，`Φ` 可以是 DFT 矩阵而 `Ψ = I`，反之亦然。然后从 `Φ` 中均匀随机选取 `N` 行来构成公式 [(9.37)](#Chp009_417-462_B9780443292385000159.xhtml#deq75) 中的 `X`。换句话说，对于这种情况，感测矩阵可以写为 `RΦ`，其中 `R` 是一个 `N × l` 矩阵，用于均匀随机抽取 `N` 行。感测矩阵与基矩阵之间的非相干性（低相干性）概念与 RIP 密切相关。这两个矩阵越不相干，RIP 成立所需的观测数量就越少（例如，[21,79]）。从另一个角度看，非相干性意味着 `Φ` 的行不能用 `Ψ` 的列稀疏表示。结果表明，如果感测矩阵 `X` 是按第 [9.7.2](#Chp009_417-462_B9780443292385000159.xhtml#s0080) 节所述形成的随机矩阵，那么 RIP 以及与任意 `Ψ` 的非相干性都将以高概率得到满足。

当我们说所有前面陈述的理论都可以推广到更一般类型的信号时，情况变得更好了，这些信号不一定是稀疏的，也不一定能用字典原子稀疏表示，它们被称为*可压缩*信号。如果一个信号向量在某个基下的展开仅包含少数几个大的参数 `θ[i]`，而其余参数都很小，则称该信号向量为可压缩的。换句话说，信号向量在某个基下是*近似*稀疏的。显然，这是实践中最有趣的情况，因为精确稀疏极少（如果有的话）出现。重述第 [9.8](#Chp009_417-462_B9780443292385000159.xhtml#s0090) 节中使用的论点，该情况下的 CS 任务可以表述为

```
\min_{\mathbf{\theta} \in \mathbb{R}^{l}} \ \ \ \ \left\| \mathbf{\theta} \right\|_{1},\text{s.t.} \ \ \ \ \left\| \mathbf{y} - X\Psi\mathbf{\theta} \right\|_{2}^{2} \leq \epsilon,
```

如果用乘积 `XΨ` 代替 `X`，第 [9.8](#Chp009_417-462_B9780443292385000159.xhtml#s0090) 节所述的一切对该情况也同样适用。

### 备注 9.9

*   CS 中的一个重要性质是，提供观测值的感测矩阵可以独立于矩阵 `Ψ` 来选择，即信号在其中稀疏表示的基/字典。换句话说，感测矩阵可以是“通用”的，可用于提供观测值以重构任意稀疏或可稀疏表示的信号（在任意字典中），前提是不违反 RIP。
