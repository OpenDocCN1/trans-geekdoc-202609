
在第一种趋势的背景下，解被约束为稀疏的，从而使核矩阵计算迅速，并突出数据集中点之间的强相似性。此外，这种基本原理可应用于核类型已预先选定且目标是计算最优核参数的情况。一种方法（例如 [4,114]）是采用形式为 $\Omega(f) = \left( \sum_{m = 1}^{M}a_{m}{\| f_{m}\|}_{\mathbb{H}_{m}} \right)^{2}$ 的正则化项，该项已被证明能促进集合 $\{a_{1},\dots,a_{M}\}$ 的稀疏性，因为当平方误差损失替代 $\mathcal{L}$ 时，它与组 LASSO 相关联（参见第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章）。

与促进稀疏性的准则相反，另一种趋势（例如 [30,63,92]）围绕这样一个论点展开：在某些情况下，稀疏 MKL 变体与原始学习任务相比可能不会表现出性能提升。此外，某些数据集包含单个数据对之间的多种相似性，这些相似性无法通过单一类型的核来突出，而需要多个不同的核来改进学习。在此背景下，首选形式为 $\Omega(f) = \sum_{m = 1}^{M}a_{m}{\| f_{m}\|}_{\mathbb{H}_{m}}^{2}$ 的正则化项。这些方法有几种变体，它们要么对任务施加额外约束（例如 $\sum_{m = 1}^{M}a_{m} = 1$），要么以略微不同的方式定义空间的求和（例如 $f( \cdot ) = \sum_{m = 1}^{M}\frac{1}{a_{m}}f_{m}( \cdot )$）。例如，在 [92] 中，作者将 [(11.93)](#Chp011_519-582_B9780443292385000172.xhtml#deq213) 重述如下：
