掩码自注意力层的 *N*′ + 2 个 *d*[*m*]-维输出作为输入传递给上一层，该层是一个“Add & Normalize”（加法与归一化）层，通过残差原理实现，正如第 [19.3.7](#Chp019_997-1102_B9780443292385000251.xhtml#s0105) 节中已解释的那样。

### 19.3.12 编码器-解码器注意力层

该模块层接收两类输入：a) 其下方层的归一化输出，即 **t**[0], **t**[1], …, **t**[*N*′ + 1]；b) 编码器的输出，即 **h**[0]^(*L*), **h**[1]^(*L*), …, **h**[*N* + 1]^(*L*)。在该层中，将执行查询、键和值向量的计算。然而，与我们迄今为止描述的自注意力机制相比，衡量相似度的概念现在有所不同。查询向量将源自解码器模块，而键和值向量则源自编码器的输出。相关计算涉及以下步骤：

*步骤 1*：针对每个归一化向量，计算对应的查询向量，

```
**q**[*n*]^(*T*) = **t**[*n*]^(*T*)*W*^(*q*), *W*^(*q*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **q**[*n*] ∈ ℝ^(*d*[*k*]), *n* = 0, 1, …, *N*′ + 1.
```

*步骤 2*：针对每个编码器输出，计算对应的键向量，

```
**k**[*n*]^(*T*) = **h**[*n*]^(*L*)^(*T*)*W*^(*k*), *W*^(*k*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **k**[*n*] ∈ ℝ^(*d*[*k*]), *n* = 0, 1, …, *N* + 1.
```
