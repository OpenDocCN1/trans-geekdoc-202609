### 时变步长

之前的分析无法推广到迭代相关步长的情况。可以证明（问题 [5.2](#Chp005_177-248_B9780443292385000111.xhtml#o0015)），在这种情况下，梯度下降算法收敛的条件是：

*   当 `i → ∞` 时，`μᵢ → 0`
*   `∑ᵢ₌₁^∞ μᵢ = ∞`

同时满足这两个条件的典型序列示例是满足以下条件的序列：

```
∑ᵢ₌₁^∞ μᵢ² < ∞,  ∑ᵢ₌₁^∞ μᵢ = ∞
```
(5.24)

例如序列

```
μᵢ = 1/i
```

请注意，这两个（充分）条件要求序列趋于零，但其无限和发散。我们将在本书的各个部分遇到这对条件。上述条件表明，随着迭代的进行，步长必须变得越来越小，但这不应以非常激进的方式发生，以便算法保持活跃足够多的迭代次数来学习解。如果步长趋于零的速度非常快，那么在几次迭代后更新实际上就会冻结，而算法尚未获得足够的信息来接近解。
