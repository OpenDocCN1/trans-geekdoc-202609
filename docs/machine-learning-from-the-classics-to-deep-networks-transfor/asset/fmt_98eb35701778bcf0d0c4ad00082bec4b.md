
In a nutshell, the only difference with the self-attention used in the encoder is that in the masked self-attention the score matrix is constrained to be lower triangular. The rest is business as usual!

The *N*′ + 2 *d*[*m*]-dimensional outputs of the masked self-attention layer are passed over as inputs to the layer above, which is an "Add & Normalize" layer, implemented via the residual rationale, as already explained in Section [19.3.7](#Chp019_997-1102_B9780443292385000251.xhtml#s0105).

### 19.3.12 The encoder-decoder attention layer

This layer of the block is fed with two types of inputs: a) the normalized outputs of the layer below it, say, **t**[0], **t**[1], …, **t**[*N*′ + 1] and b) the outputs of the encoder, i.e., **h**[0]^(*L*), **h**[1]^(*L*), …, **h**[*N* + 1]^(*L*). In this layer, computations of query, key and value vectors are preformed. However, the concept of measuring similarity is different now, compared to the self-attention mechanism that we have described so far. The query vectors will originate from the decoder blocks while the key and value vectors from the outputs of the encoder. The associated computations involve the following steps:

*Step 1*: For each one of the normalized vectors, compute the corresponding query vectors,

```
**q**[*n*]^(*T*) = **t**[*n*]^(*T*)*W*^(*q*), *W*^(*q*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **q**[*n*] ∈ ℝ^(*d*[*k*]), *n* = 0, 1, …, *N*′ + 1.
```

*Step 2*: For each one of the encoder outputs, compute the corresponding key vectors,

```
**k**[*n*]^(*T*) = **h**[*n*]^(*L*)^(*T*)*W*^(*k*), *W*^(*k*) ∈ ℝ^(*d*[*m*] × *d*[*k*]), **k**[*n*] ∈ ℝ^(*d*[*k*]), *n* = 0, 1, …, *N* + 1.
```
