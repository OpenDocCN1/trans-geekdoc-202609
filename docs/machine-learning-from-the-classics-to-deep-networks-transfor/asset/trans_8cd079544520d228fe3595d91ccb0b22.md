Volterra 级数展开的特例包括 *Wiener*、*Hammerstein* 和 *Wiener–Hammerstein* 模型。这些模型如 [图 11.2](#Chp011_519-582_B9780443292385000172.xhtml#f0015) 所示。系统 *h*(·) 和 *g*(·) 是具有记忆的线性系统，即

```
s_n = ∑_{i=0}^{M_1} h_n u_{n-i}
```

![Equation](images/B9780443292385000172/si33.png)

和

```
d_n = ∑_{i=0}^{M_2} g_n x_{n-i}.
```

![Equation](images/B9780443292385000172/si34.png)

中间的方框对应一个无记忆非线性系统，可用 *r* 次多项式近似。因此，

```
x_n = ∑_{k=1}^{r} c_k (s_n)^k.
```

![Equation](images/B9780443292385000172/si35.png)

换言之，Wiener 模型是一个线性时不变（LTI）系统后接一个无记忆非线性环节，而 Hammerstein 模型则是一个无记忆非线性环节后接一个 LTI 系统的组合。Wiener–Hammerstein 模型则是两者的结合。请注意，此类模型关于所涉及的自由参数是非线性的。相比之下，等效的 Volterra 模型关于所涉及的参数是线性的；然而，随着多项式阶数和滤波器记忆抽头数（*M*₁ 和 *M*₂）的增加，产生的自由参数数量会显著增加。其有趣的特性在于：等效于 Hammerstein 模型的 Volterra 展开仅包含相关 Volterra 核的对角元素。换句话说，输出用 *u*[*n*], *u*[*n* − 1], *u*[*n* − 2], … 及其幂次项来表示；不存在交叉乘积项 [60]。
