## Proposition 8.2

Let *C* be a closed convex set in a Hilbert space ℍ. Then the associated projection operator `P[C] : ℍ ↦ C` is nonexpansive.

### Proof

Let **x**, **y** ∈ ℍ. Recall property [(8.16)](#Chp008_343-416_B9780443292385000147.xhtml#deq31), that is,

```
∥P[C](x) − P[C](y)∥² ≤ Real{⟨x−y, P[C](x)−P[C](y)⟩}. (8.21)
```

Moreover, by employing the Schwarz inequality (Eq. (8.149) of chapter's appendix), we get

```
|⟨x − y, P[C](x) − P[C](y)⟩| ≤ ∥x − y∥ ∥P[C](x) − P[C](y)∥. (8.22)
```

Combining the inequalities in [(8.22)](#Chp008_343-416_B9780443292385000147.xhtml#deq39) and [(8.23)](#Chp008_343-416_B9780443292385000147.xhtml#deq40), we readily obtain

```
∥P[C](x) − P[C](y)∥ ≤ ∥x − y∥. (8.23)
```

□

[Fig. 8.12](#Chp008_343-416_B9780443292385000147.xhtml#f0070) provides a geometric interpretation of [(8.24)](#Chp008_343-416_B9780443292385000147.xhtml#deq41). The property of nonexpansiveness, as well as a number of its variants (for example, [6,7,30,81,82]), is of paramount importance in convex set theory and learning. It is the property that guarantees the convergence of an algorithm, which comprises a sequence of successive projections (mappings), to the so-called *fixed point set*, that is, to the set whose elements are left unaffected by the respective mapping *T*, i.e.,

```
T(x) = x, ∀x ∈ C.
```

In the case of a projection operator on a closed convex set, we know that the respective fixed point set is the set *C* itself, since `P[C](x) = x, ∀x ∈ C`.
