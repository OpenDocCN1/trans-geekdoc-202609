
# 类条件模型

对于类条件模型，首先想到的一种直接方法是获取与类别相关的向量嵌入。也就是说，类别信息被编码为一个向量，并投影到合适的维度，与时间嵌入一起输入到 U-Net 的各个层中。人们可以想到多种将类别信息与 U-Net 各层中计算出的特征图相结合的方法，例如 [44]。在这些修改下，U-Net 返回类条件估计值，即 `μ_θ(x_t, t, y)` 或 `ϵ_θ(x_t, t, y)`。

前述原始公式的一个缺点是，学习到的模型可能会弱化其训练所依赖的相关条件信息。为此，提出了引导模型，它们提供了更显式地控制可用条件相关信息的能力。

## 分类器引导

在 [44] 中，提出在噪声样本 `x_t` 上训练一个分类器 `p_ϕ(y|x_t, t)`，其中 `y` 表示类别标签变量。训练好分类器后，利用梯度 `∇_x_t ln p_ϕ(y|x_t, t)` 来*引导*反向过程从任意类别 `y` 进行采样。在采样期间，用以下公式替换公式 (19.75) 中的 `μ_θ_*(x_t, t)`：

```
μ̂_θ_*(x_t, t, y) = μ_θ_*(x_t, t) + γ Σ_θ_*(x_t, t) ∇_x_t ln p_ϕ_*(y|x_t, t)
```
