
## The Box–Muller Method

$J(x,y;r,\phi) = \left\lbrack \begin{array}{ll} {\frac{\partial g_{x}}{\partial r}\ } & \frac{\partial g_{x}}{\partial\phi} \\ {\frac{\partial g_{y}}{\partial r}\ } & \frac{\partial g_{y}}{\partial\phi} \\ \end{array} \right\rbrack$

and we have assumed, for simplicity, that to each value of $(r,\phi)$ there corresponds one value of $(x,y)$. Let us now see how one can generate samples from a Gaussian $p(x) = \mathcal{N}(x|0, 1)$ by using samples drawn from a uniform and an exponential distribution, respectively, for $\phi$ and $r$; recall that in [Example 14.1](#Chp014_717-754_B9780443292385000202.xhtml#enun0015), we described a technique for generating samples from an exponential distribution.

Let $r$ be distributed according to an exponential distribution,

$$p_{r}(r) = \frac{1}{2}\exp\left( - \frac{r}{2} \right),\quad r \geqslant 0,$$

and $\phi$ to a uniform distribution, $\mathcal{U}(0, 1)$,

$$p_{\phi}(\phi) = \left\{ \begin{matrix} {\frac{1}{2\pi},\ } & {\quad 0 \leqslant \phi \leqslant 2\pi,} \\ {0,\ } & {\quad\text{otherwise},} \\ \end{matrix} \right.$$

and also assume that they are independent, that is,

$$p_{r,\phi}(r,\phi) = p_{r}(r)p_{\phi}(\phi).$$

Generate two new random variables as

$$x = \sqrt{r}\cos\phi,$$

$$y = \sqrt{r}\sin\phi.$$
