### 算法 19.2：GAN 算法

*   初始化 `θ[d]^(0)` 和 `θ[g]^(0)`。
*   将小批量大小设为 `K`。
*   设置判别器的迭代次数 `m`；最简单的情况是 `m = 1`，这也是原始论文中采用的设置。
*   **当** `θ[d]` 和 `θ[g]` 尚未收敛时，**执行**
    1.  **对于** `t = 1, 2, …, m`，**执行**
        1.  从 `p_z(z)` 中采样 `z^(i), i = 1, 2, …, K`。
        2.  从 `p_r(x)` 中采样 `x^(i), i = 1, 2, …, K`。
        3.  计算梯度
