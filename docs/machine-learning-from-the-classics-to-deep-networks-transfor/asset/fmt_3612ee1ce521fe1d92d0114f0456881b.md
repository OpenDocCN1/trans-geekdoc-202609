
## The multinomial distribution

This is a generalization of the binomial distribution if the outcome of each experiment is not binary but can take one out of `K` possible values. For example, instead of tossing a coin, a die with `K` sides is thrown. Each one of the possible `K` outcomes has probability `P[1]`, `P[2]`, …, `P[K]` to occur, and we denote

**P** = `[P[1], P[2], …, P[K]]^(T)`.

After `n` experiments, assume that `x[1]`, `x[2]`, …, `x[K]` times sides `x = 1`, `x = 2`, …, `x = K` occurred, respectively. We say that the random (discrete-valued) vector,

**x** = `[x[1], x[2], …, x[K]]^(T)`,

(2.57)

follows a multinomial distribution, **x** ~ `Mult(x|n, P)` if

(2.58)

where

```
\begin{pmatrix} n \\ {x_{1},x_{2},\ldots,x_{K}} \\ \end{pmatrix}: = \frac{n!}{x_{1}!x_{2}!\ldots x_{K}!}.
```

Note that the variables `x[1]`, …, `x[K]` are subject to the constraint

```
\sum\limits_{k = 1}^{K}x_{k} = n,
```

and also

```
\sum\limits_{k = 1}^{K}P_{K} = 1.
```
