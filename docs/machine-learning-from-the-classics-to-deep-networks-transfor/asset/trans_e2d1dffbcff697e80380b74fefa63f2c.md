
现在迭代索引 `i` 与时间索引 `n` 重合。有两种不同的方式来看待公式 [(8.68)](#Chp008_343-416_B9780443292385000147.xhtml#deq143)。要么 `n` 取集合 `[1, 2, …, N]` 中的值并周期性循环直到收敛，要么让 `n` 无界增长。对于非常大的 `N` 值，后者非常自然，从现在起我们将专注于这种情况。此外，如果存在缓慢的时间变化，这种策略也能应对。请注意，在在线公式中，每个时间瞬间都涉及一个*不同的*损失函数，我们的任务变成了*渐近*最小化。此外，必须研究渐近*收敛性质*以及相应的*收敛条件*。很快，我们将介绍一种分析在线算法性能的强大工具，即*遗憾分析*。

对于第 [8.10.2](#Chp008_343-416_B9780443292385000147.xhtml#s0100) 节中讨论的每一种优化方案，我们都可以写出其在线版本。给定损失函数序列 `ℒ[n]`，`n = 1, 2…`，通用投影子梯度方案的在线版本变为

```
θ[n] = P[C](θ[n − 1] − μ[n]ℒ[n]′(θ[n − 1])),  n = 1, 2, 3, …. (8.68)
```

在更一般的设定中，与约束相关的凸集也可以随时间变化；换句话说，我们可以写成 `C[n]`。例如，这种带有时变约束的方案已在稀疏感知学习背景下得到发展，其中使用加权 `ℓ[1]` 球代替了 `ℓ[1]` 球 [47]。这对加速算法收敛有着真正显著的效果（见第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章）。
