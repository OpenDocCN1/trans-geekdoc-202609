

$Z_{i} := \sum\limits_{n = 1}^{N}w_{n}^{(i)}\exp\left( - y_{n}a_{i}\phi(\mathbf{x}_{n};\mathbf{\theta}_{i}) \right).$

![Equation](images/B9780443292385000135/si363.png)(7.98)

观察权重的形成方式，可以掌握 AdaBoost 算法的主要秘密之一：与训练样本 **x**[n] 相关的权重相对于其在上一次迭代中的值会增加（减少），具体取决于该模式未能（成功）被正确分类。此外，减少（增加）的百分比取决于 *a*[i] 的值，它控制着在最终分类器构建中的相对重要性。在连续迭代中持续失败的难分样本，在其参与加权经验误差值时会获得更高的重要性。对于 AdaBoost 的情况，可以证明训练误差倾向于以指数速度趋于零（问题 [7.18](#Chp007_293-342_B9780443292385000135.xhtml#o0095)）。该方案总结在 [算法 7.1](#Chp007_293-342_B9780443292385000135.xhtml#enun0060) 中。

## 算法 7.1

### AdaBoost 算法

*   **初始化：** $w_{n}^{(1)} = \frac{1}{N},\ i = 1,2,\ldots,N$
*   **初始化：** $i = 1$
*   **重复**
    1.  通过最小化 *P*[i] 计算 $\phi( \cdot ;\textit{\textbf{θ}}_{i})$ 中的最优 **θ**[i]；[(7.91)](#Chp007_293-342_B9780443292385000135.xhtml#deq139)
    2.  计算最优 *P*[i]；[(7.92)](#Chp007_293-342_B9780443292385000135.xhtml#deq140)
    3.  $a_{i} = \frac{1}{2}\ln\frac{1 - P_{i}}{P_{i}}$
    4.  $Z[i] = 0$
    5.  **对于** $n = 1$ 到 *N* **执行**
        *   $w_{n}^{(i + 1)} = w_{n}^{(i)}\exp\left( - y_{n}a_{i}\phi(\textit{\textbf{x}}_{n};\textit{\textbf{θ}}_{i}) \right)$
