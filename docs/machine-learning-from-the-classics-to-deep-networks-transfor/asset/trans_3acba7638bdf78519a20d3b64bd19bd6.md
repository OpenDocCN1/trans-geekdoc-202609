

## 备注 19.4

$B_{n} := - \text{KL}\left( q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi}) \| p(\mathbf{z}) \right) = \frac{1}{2}\sum\limits_{i = 1}^{m}\left( 1 + \ln(\sigma_{ni}^{2}) - \mu_{ni}^{2} - \sigma_{ni}^{2} \right).$

项 $B_{n}$ 是 $\boldsymbol{\phi}$ 的函数，通过所涉及的均值和方差体现。代价函数通过对所有输入样本求和形成，即

$\mathcal{L}(\boldsymbol{\phi},\boldsymbol{\theta}) = \sum\limits_{n = 1}^{N}(A_{n} + B_{n}),$

并通过反向传播算法关于 $\boldsymbol{\phi}$ 和 $\boldsymbol{\theta}$ 进行最小化。通常采用小批量算法变体。

一旦训练完成，可通过多种方式进行采样以生成样本。可以从标准高斯先验 $p(\mathbf{z})$ 中采样，然后将生成的潜在变量向量通过编码器，通过对条件分布采样来生成样本。有时，也可以不对条件分布采样，而是将生成的样本设为相应条件分布的均值，因为这是实现解码器的神经网络的预测输出（公式 [(19.19)](#Chp019_997-1102_B9780443292385000251.xhtml#deq43)）。然而，从先验 $p(\mathbf{z})$ 采样通常会导致样本质量相当低。另一种选择是从通过对所有输入样本 $\mathbf{x}_{n}$ 平均学习到的后验 $q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi})$ 得到的分布中采样潜在变量。这不再是高斯分布，而是高斯混合模型，能更具代表性地反映潜在空间中的真实分布。另一方面，如果想从单个类别生成样本，例如 MNIST 数据集中的数字“3”，则可以通过从相应的学习后验 $q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi})$ 中抽取样本，在潜在空间中进行采样。

尽管与 GAN 相比 VAE 更易于训练，但实验证据表明，当 VAE 用于生成图像时，获得的图像往往比通过 GAN 生成的图像更模糊。文献 [185] 使用 Wasserstein 距离替换代价函数中的 KL 散度来训练 VAE，据报告这对获得的性能有积极影响。另一条研究路线是沿着 GAN 和 VAE 的融合方向进行的，旨在结合两者的优点；参见例如 [126]、[129]。另一条路径是构建具有潜在变量层次结构的 VAE。在这方面，潜在变量被解释为从其他更高层级的变量生成；参见例如 [104]。条件 VAE 在文献 [170] 中被提出。
