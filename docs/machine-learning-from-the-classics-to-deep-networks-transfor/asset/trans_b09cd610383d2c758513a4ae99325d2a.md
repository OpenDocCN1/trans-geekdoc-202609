

### 19.3.8 编码器：全连接神经网络层

如[图 19.12](#Chp019_997-1102_B9780443292385000251.xhtml#f0065)所示，“Add & Normalize”（加和归一化）层的每个输出向量都被作为输入呈送给一个前馈全连接神经网络（FCN）；参见第 [18.3.1](#Chp018_885-995_B978044329238500024X.xhtml) 节。文献 [189] 使用了一个两层 FCN，其隐藏层采用 ReLU（第 [18.6.1](#Chp018_885-995_B978044329238500024X.xhtml) 节）非线性，输出层采用线性单元。在文献 [189] 中，`N + 2` 个 FCN 是相同的，即它们共享相同的参数，这些参数在训练过程中学习得到。每个 FCN 输出 `d[m]` 个值，这些值被堆叠在一起形成一个向量。因此，该层输出 `N + 2` 个 `d[m]` 维的更新向量嵌入。

### 19.3.9 编码器：Add & Normalize 层 II

此“Add & Normalize”层与之前讨论的层具有相同的结构。它接收来自下方 FCN 层的 `N + 2` 个输出，并输出相应的归一化版本。让我们将这些向量表示为 `h[n]¹ ∈ ℝ^(d[m])`，`n = 0, 1, …, N + 1`。这些向量是计算出的最终*更新*嵌入，它们构成了第一个块的输出；这就是我们使用上标“1”的原因；参见[图 19.10](#Chp019_997-1102_B9780443292385000251.xhtml#f0055)。

前一个块的 `N + 2` 个输出向量成为第二个块的输入，依此类推。Transformer 顶层第 `L` 个块的输出表示为 `h[n]^(L) ∈ ℝ^(d[m])`，`n = 0, 1, …, N + 1`，它们构成了 Transformer 编码器部分的最终输出。这些向量是原始输入嵌入的更新后的*上下文化*嵌入/表示/编码。换句话说，编码器生成信息丰富的特征向量，对上下文信息进行编码。

**备注 19.5**

*   基于自注意力机制的编码器已被证明是*通用逼近器*，例如 [107], [201]。在后者中，证明了带有位置编码的 Transformer 模型可以在紧致域上通用逼近任意连续的序列到序列函数。
