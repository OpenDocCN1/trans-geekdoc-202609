
# 分类与回归

在回归任务中，函数 `f(·)` 必须“解释”数据生成机制。`(y, x)` 空间 `ℝ^(l+1)` 中对应的曲面应当形成形状，以尽可能紧密地跟随数据在空间中的分布。相反，在分类中，目标是在 `ℝ^l` 中放置对应的曲面 `f(x) = 0`，以尽可能将属于不同类别的数据分开。分类器的目标是将特征向量所在的空间*划分*为若干区域，并将每个区域与一个类别关联。[图 3.5](#Chp003_65-117_B9780443292385000093.xhtml#f0030) 展示了分类任务的两种情况。第一种是两个线性可分类别的示例，其中一条直线可以将两个类别分开；第二种情况是两个非线性可分类别的示例，此时使用线性分类器将无法将两个类别分开。

## 设计线性分类器

现在让我们使上述论述更加具体。我们得到一组训练模式，`x[n] ∈ ℝ^l`，`n = 1, 2, …, N`，它们属于两个类别中的任意一个，假设为 `ω[1]` 和 `ω[2]`。目标是设计一个超平面：

```
f(x) = θ[0] + θ[1]x[1] + ⋯ + θ[l]x[l] = θ^(T)x = 0,
```
