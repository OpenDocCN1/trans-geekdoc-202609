
其中 $I_{\mathbb{R}_+^l}(\boldsymbol{\theta})$ 为指示函数，若 $\boldsymbol{\theta} \in \mathbb{R}_+^l$ 则 $I_{\mathbb{R}_+^l}(\boldsymbol{\theta}) = 1$（反之若 $\boldsymbol{\theta} \notin \mathbb{R}_+^l$ 则为 0）。在我们的公式中，公式 [(13.148)](#Chp013_635-716_B9780443292385000196.xhtml#deq245) 中促进稀疏性的尺度超参数也被假定为随机变量，并通过为每个 $b_i$ ($i = 1, 2, \dots, l$) 假设以下的 Gamma 先验分布从数据中推断得出：

```
p(b_i) = Gamma(b_i|\kappa,\nu) = \frac{\nu^\kappa}{\Gamma(\kappa)}b_i^{\kappa - 1}\exp\left( - \nu b_i \right).
```

公式 [(13.150)](#Chp013_635-716_B9780443292385000196.xhtml#deq247) 中的超参数 $\kappa$ 和 $\nu$ 也被设为较小的值（实验中为 $10^{-6}$）。

采用了分层贝叶斯模型后，第 [13.3](#Chp013_635-716_B9780443292385000196.xhtml#s0030) 节讨论的变分 EM 算法被应用于在给定观测值的条件下获得丰度参数后验分布的估计值 $q(\theta_i)$，$i = 1, 2, \dots, l$。在实验中，将分别使用 $q(\theta_i)$ 的均值作为未知参数值的估计。推导细节可参考文献 [85]。变分 EM 算法的另一种替代途径是采用蒙特卡洛技术（参见例如文献 [14]）。
