
# 来自 POCS 理论的算法

源自 POCS 理论的算法特别适合以一种优雅、稳健且相对直接的方式处理约束。请注意，每个约束的目标是在解空间中定义一个区域，所需的估计值被“强制”位于该区域内。在本节的其余部分，我们将假设所需的估计值必须满足 *M* 个约束，每个约束定义一个*凸*点集，`C[m]`，`m = 1, 2, …, M`。此外，

```
⋂_{m=1}^{M} C_m ≠ ∅,
```

这意味着这些约束是一致的（也存在可以放宽此条件的方法）。随后可以证明，映射 `T` 定义为

```
T := P[C[m]]…P[C[1]],
```

是一个*强吸引非扩张*映射，[(8.25)](#Chp008_343-416_B9780443292385000147.xhtml#deq48) （例如，文献 [6,7]）。请注意，如果将投影算子的串联替换为它们的凸组合，同样的结论也成立。

在存在一组约束的情况下，[算法 8.2](#Chp008_343-416_B9780443292385000147.xhtml#enun0130) 中的 APSM 唯一的区别在于，更新递推公式 [(8.39)](#Chp008_343-416_B9780443292385000147.xhtml#deq74) 现在被以下公式取代：

```
θ_n = T( θ_{n-1} + μ_n( ∑_{k=n-q+1}^{n} ω_k P_{S_{ε,k}}(θ_{n-1}) - θ_{n-1} ) ).
```(8.44)

换句话说，对于 *M* 个约束，必须执行 *M* 次额外的投影操作。同样的情况也适用于公式 [(8.38)](#Chp008_343-416_B9780443292385000147.xhtml#deq73)，区别在于括号内的求和项。
