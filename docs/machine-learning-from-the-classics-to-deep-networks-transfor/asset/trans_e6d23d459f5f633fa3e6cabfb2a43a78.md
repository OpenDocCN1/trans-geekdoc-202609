

## 迭代重加权最小二乘法 (IRLS)

**θ**^((*i*)) = **θ**^((*i* − 1)) − *μ*[*i*](*X*^(*T*)*R*^((*i* − 1))*X*)^(−1)*X*^(*T*)(**s**^((*i* − 1)) − **y**) = (*X*^(*T*)*R*^((*i* − 1))*X*)^(−1)*X*^(*T*)*R*^((*i* − 1))**z**^((*i* − 1)), (7.45)

![Equation](images/B9780443292385000135/si178.png)

其中（可尝试验证）：

**z**^((*i* − 1)) := *X***θ**^((*i* − 1)) − *μ*[*i*](*R*^((*i* − 1)))^(−1)(**s**^((*i* − 1)) − **y**), (7.46)

![Equation](images/B9780443292385000135/si179.png)

公式 [(7.45)](#Chp007_293-342_B9780443292385000135.xhtml#deq72) 是最小二乘（LS）解的加权版本（参见第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章和第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章）；然而，所涉及的量依赖于迭代次数，由此产生的方案称为**迭代重加权最小二乘法**（IRLS）[36]。

### 线性可分数据的最大似然问题

在最大化似然时，如果训练数据集是线性可分的，可能会遇到问题。在这种情况下，超平面 **θ**^(*T*)**x** = 0 上的任意点，只要能解决分类任务并将每个类别的样本分开（注意存在无限多个这样的超平面），都会导致 *σ*(**θ**^(*T*)**x**) = 0.5。

![Equation](images/B9780443292385000135/si180.png)
![Equation](images/B9780443292385000135/si181.png)

因此，每个类别的每个训练点都被分配了等于 1 的后验概率。于是，最大似然（ML）迫使逻辑斯蒂函数在特征空间中变成阶跃函数，等价地有 ||**θ**|| → ∞。

![Equation](images/B9780443292385000135/si182.png)

这可能导致过拟合，解决方法是在相应的代价函数中加入**正则化**项，例如 ||**θ**||²。
