
$p(\mathbf{y}) = \sum\limits_{i}P(\mathcal{M}_{i})p(\mathbf{y}|\mathcal{M}_{i}),$

其中 $P(\mathcal{M}[i])$ 是 $\mathcal{M}[i]$ 的先验概率；$P(\mathcal{M}[i])$ 提供了对所有可能模型的主观先验度量，这表达了我们在数据到达之前，对某模型相对于其他备选模型的合理性的猜测。由于公式 [(12.29)](#Chp012_583-634_B9780443292385000184.xhtml#deq39) 中的分母与模型无关，因此可以通过最大化分子，在观测到 $\mathbf{y}$ 后获得最可能的模型。如果给所有可能的模型分配相等的概率，那么在给定观测集下检测最可能的模型，就变成了关于模型 $\mathcal{M}[i]$ 最大化 $p(\mathbf{y}|\mathcal{M}[i])$ 的任务。这就是该概率密度函数被称为模型的*证据函数*或简称为*证据*的原因。在实践中，我们满足于使用最可能的模型，尽管正统贝叶斯派会建议像公式 [(12.30)](#Chp012_583-634_B9780443292385000184.xhtml#deq40) 那样，对所有可能模型获得的所有量进行平均。在理想的贝叶斯设定中，不在模型间进行选择；预测是通过对所有可能模型求和来执行的，每个模型按其相应概率加权。然而，在许多实际问题中，我们可能有理由认为证据函数在某个特定模型周围强烈尖峰；毕竟，这种假设可能会大大简化任务。

从数学公式的角度来看，每个模型都用一组非随机（确定性）参数来表示。获得使证据最大化的模型，等价于关于这些参数进行最大化。例如，假设在回归任务中，我们为噪声采用高斯分布，为回归任务的随机参数 $\mathbf{\theta}$ 采用高斯先验。那么这一对高斯分布构成了我们的模型，描述该模型的参数是这两个高斯分布各自的协方差矩阵以及先验的均值。为了区别于描述原始学习任务（如回归）的随机参数 $\mathbf{\theta}$，这些额外的参数通常被称为*超参数*。稍后，在第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章中，我们将看到超参数也可以被视为随机变量。我们现在将注意力转向隐藏在关于不同模型优化 $p(\mathbf{y}|\mathcal{M}[i])$ 背后的内容。在继续之前，值得评论一下。肤浅的初看可能会让人怀疑这是否与最大化似然 $p(\mathbf{y}; \mathbf{\theta})$ 有何不同，正如第 [12.2.1](#Chp012_583-634_B9780443292385000184.xhtml#s0020) 节所做的那样。事实上，这两种情况属于两个不同的世界。ML 在采用的模型内关于单个（向量）参数进行最大化，而这正是使 ML 易受过拟合影响的弱点。最大化证据是关于模型本身的优化任务，这是一种明智的替代方案，可以防止过拟合，正如我们接下来所解释的。
