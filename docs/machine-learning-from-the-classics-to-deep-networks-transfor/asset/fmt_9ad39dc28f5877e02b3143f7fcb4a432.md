The proofs are given in Problem [13.19](#Chp013_635-716_B9780443292385000196.xhtml#o0195). The above indicates that the draws from a DP distribution stay “around” the base one and the variance is inversely proportional to the concentration parameter.

**Posterior from prior distributions**: We know that every draw *G* ∼ DP(*α*, *G*[0]) is a distribution and it is used to draw samples from Θ. Let **θ**[*i*] ∈ *Θ* ∼ *G* be a sequence of such i.i.d. drawn samples. Our goal now is to derive the posterior probabilities *G*(*T*[*k*]), *k* = 1, 2, …, *K*, given a set of *n* observations, **θ**[1], …, **θ**[*n*].

To this end, recall from [Example 12.6](#Chp012_583-634_B9780443292385000184.xhtml) that the Dirichlet distribution is the conjugate of the multinomial one, given in Eq. [(2.58)](#Chp002_19-64_B9780443292385000081.xhtml), i.e.,

$P(n\_{1},n\_{2},\\ldots,n\_{K}) = \\begin{pmatrix} n \\\\ {n\_{1},\\ldots,n\_{K}} \\\\ \\end{pmatrix}\\prod\\limits\_{k = 1}^{K}G{(T\_{k})}^{n\_{k}},$
