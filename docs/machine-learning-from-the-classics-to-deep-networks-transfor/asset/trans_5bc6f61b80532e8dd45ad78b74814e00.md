
且 ⌊ ⋅ ⌋ 表示向下取整运算，即 ⌊3.7⌋ = 3。例如，若 *l* = 5，*m* = 3，*p* = 0，且 *s* = 1，则 *k* = 3。另一方面，若 *l* = 5，*m* = 3，*p* = 0，且 *s* = 2，则 *k* = 2（参见 [图 18.21](#Chp018_885-995_B978044329238500024X.xhtml#f0115)A 和 B）。

请注意，如果 *l*、*m*、*p* 和 *s* 的值导致滤波器矩阵在滑过 *I* 时超出 *I* 的范围，则不执行此类操作。我们仅在滤波器矩阵*完全包含*于 *I* 内时执行操作。

人们可能会疑惑为何要用零填充。请注意，由于卷积的运算方式，特征图的尺寸小于输入数组的尺寸。正如我们即将看到的，在深层网络中，输出特征图被用作下一层的输入。因此，随着网络加深，数组的尺寸会不断减小。相反，经过零填充后，正如公式 [(18.65)](#Chp018_885-995_B978044329238500024X.xhtml#deq111) 所示，我们可以控制所涉及数组的尺寸。例如，若 *l* = 5，*m* = 3，*s* = 1，且 *p* = 1，则输出将具有与输入数组相同的尺寸 *k* = 5。事实上，若 *p* = (*m* − 1)/2（针对奇数 *m*），则 *k* = *l*。在这种情况下，我们称该操作为*同卷积*。使用填充的另一个原因是，与位于图像内部的像素相比，输入图像的边界像素对输出的贡献较小。以 [图 18.18](#Chp018_885-995_B978044329238500024X.xhtml#f0100) 为例。像素 *I*(1, 1) 仅对 *O*(1, 1) 有贡献。相反，像素 *I*(2, 2) 对所有输出元素均有贡献，因为它在所有四个位置的窗口区域内均被包含。通过零填充，我们使边界元素与内部像素相比，拥有更平等的机会对输出值产生“影响”。

#### 非线性步骤

卷积运算完成并将偏置项加到所有特征图数值后，下一步是对每个特征图数组的每个像素应用非线性函数（激活函数）。之前讨论过的任何非线性函数均可采用。目前，修正线性激活函数 ReLU 似乎是最流行的选择。

#### 池化步骤

此步骤旨在降低每个特征图数组的维度。有时该步骤也称为空间池化。为此，需定义一个窗口并将其滑过相应矩阵。滑动可通过为相应步幅参数 *s* 采取某值来实现。
