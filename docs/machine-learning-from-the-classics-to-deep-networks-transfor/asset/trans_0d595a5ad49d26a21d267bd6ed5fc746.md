## 16.7 学习图模型

学习图模型包含两个部分。给定一定数量的观测值，必须同时确定图结构及其相关参数。

### 16.7.1 参数估计

一旦确定了图模型，就必须估计未知参数。例如，在一个涉及离散变量的贝叶斯网络中，必须估计条件概率的值。在第 [16.5](#Chp016_805-853_B9780443292385000226.xhtml#s0070) 节中，介绍了在 HMM 背景下学习未知参数的情况。关键点在于最大化观测输出变量上的联合 PDF。这是用于不同图结构参数估计的最流行准则之一。在 HMM 情况下，部分变量是未观测的，因此引入了 EM 算法。如果图的所有变量均可观测，则参数学习任务就变成了一个典型的最大似然问题。更具体地，考虑一个具有 `l` 个节点的网络，这些节点代表变量 `x[1], …, x[l]`，它们被紧凑地写为随机向量 `x`。另设 `x[1], x[2], …, x[N]` 为一组观测值；则

```
θ̂ = arg max_θ p(x₁, x₂, …, x_N; θ)
```

其中 `θ` 包含图中的所有参数。如果涉及潜在/隐藏变量，则必须将它们边缘化掉。第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章和第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章中讨论的任何参数估计技术均可使用。此外，还可以利用图的特殊结构（即潜在的独立性）来简化计算。在 HMM 情况下，其贝叶斯网络结构被利用，将乘积求和算法引入其中。除了最大似然法，还可以采用与参数估计/推断相关的任何其他方法。例如，可以在未知参数上施加先验 `p(θ)` 并求助于 MAP 估计。此外，假设参数为随机变量，也可以采用完全贝叶斯假设。这种做法预设未知参数已作为额外节点包含在网络中，并适当链接到它们所影响的变量节点。事实上，这正是我们在 [图 13.2](#Chp013_635-716_B9780443292385000196.xhtml) 中所做的，尽管当时我们尚未谈论图模型（另见 [图 16.24](#Chp016_805-853_B9780443292385000226.xhtml#f0130)）。注意，在这种情况下，为了对网络变量执行任何推断，必须将参数边缘化掉。例如，假设我们的 `l` 个变量对应于贝叶斯网络的节点，其中局部条件分布为

```
p(x[i] | Pa[i]; θ[i]), i = 1, 2, …, l
```
