

### 3. n = 2

解码器输入变为 `y[0]`、`y[1]`、`y[2]`，其中后者是与单词“am”相关联的嵌入向量。随后解码器将产生一个新的输出，`ŷ₂`，预期该输出将导致对单词“a”的预测。

上述过程将重复进行，直到预测出令牌 `⟨EOS⟩` 并使算法停止。在本例中，我们预期 `ŷ₄` 中数值最大的元素出现在对应于序列结束符号 ID 的维度上。[表 19.1](#Chp019_997-1102_B9780443292385000251.xhtml#t0010) 总结了推理任务的上述步骤。

#### 表 19.1 推理阶段的解码器输入与输出序列

嵌入向量 `y[0]` 对应于 `⟨SOS⟩` 符号。

| 解码器输入 | 解码器输出 |
| :--- | :--- |
| n = 0: `y[0]` | `ŷ₀ → I → y₁` |
| n = 1: `y[0]`, `y[1]` | `ŷ₀, ŷ₁ → am → y₂` |
| n = 2: `y[0]`, `y[1]`, `y[2]` | `ŷ₀, ŷ₁, ŷ₂ → a → y₃` |
| n = 3: `y[0]`, `y[1]`, `y[2]`, `y[3]` | `ŷ₀, ŷ₁, ŷ₂, ŷ₃ → student → y₄` |
