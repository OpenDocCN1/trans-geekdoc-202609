
## EM Algorithm and Evidence Maximization

In Section [12.4](#Chp012_583-634_B9780443292385000184.xhtml#s0045), the EM algorithm was introduced and it was stated that maximizing the expectation of the complete log-likelihood with respect to the set of parameters `ξ` is equivalent to maximizing the corresponding evidence function, i.e., `p(X; ξ)`. However, this was not explicitly shown. In this section, this connection will become clear. It will be shown that the EM algorithm basically maximizes a tight *lower bound* of the evidence. Furthermore, this interpretation of the EM will allow for generalizations to extend it to cases where the computations involving the posterior, `p(X^(l)|X; ξ)`, are not computationally tractable.

Let us consider the functional^([^(88)](#fn88))

```
F(q, ξ) = ∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) + H
```
(12.63)

where `q(X^(l))` is any nonnegative function that integrates to one; that is, it is a PDF defined over the latent variables. The functional `F` depends on `ξ` and on `q`, and its definition bears a strong similarity to the notion of free energy, used in statistical physics. Indeed, Eq. [(12.63)](#Chp012_583-634_B9780443292385000184.xhtml#deq83) can be written as

```
F(q, ξ) = ∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) + H
```
(12.64)

where

```
H = − ∫ q(X^(l)) ln q(X^(l)) dX^(l)
```

is the entropy associated with `q(X^(l))`. If one defines `−ln p(X, X^(l); ξ)` as the *energy* of the system, `(X, X^(l))`, then `F(q, ξ)` represents the negative of the so-called *free energy* [34]. Focusing on the first term on the right-hand side in Eq. [(12.64)](#Chp012_583-634_B9780443292385000184.xhtml#deq84), this can be written as

```
∫ q(X^(l)) ln p(X, X^(l); ξ) dX^(l) = ∫ q(X^(l)) ln [p(X^(l)|X; ξ) p(X; ξ)] dX^(l)
```
(12.65)

In other words, the first term on the right-hand side is very similar to the `Q` term in Eq. [(12.40)](#Chp012_583-634_B9780443292385000184.xhtml#deq53). The only difference is that the expectation here is taken with respect to `q`.
