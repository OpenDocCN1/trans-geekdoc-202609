

## 因子图

*因子图*为我们提供了一种手段，使概率分布分解为因子乘积的过程更加显式。因子图是一种无向*二分*图，包含两类节点：一类对应随机变量，用圆圈表示；另一类对应势函数，用方块表示。边仅存在于两种不同类型的节点之间，例如“势函数”节点与“变量”节点之间 [15,16,26]。

[图 15.18](#Chp015_755-803_B9780443292385000214.xhtml#f0100)A 是一个包含四个变量的 MRF。[图 15.18](#Chp015_755-803_B9780443292385000214.xhtml#f0100)B 中相应的因子图对应于乘积^([^(113)](#fn113))

```
p(x_1,x_2,x_3,x_4) = (1/Z) ψ_c_1(x_1,x_2,x_3) ψ_c_2(x_3,x_4)
```
(15.30)

而 [图 15.18](#Chp015_755-803_B9780443292385000214.xhtml#f0100)C 中的因子图对应于

```
p(x_1,x_2,x_3,x_4) = (1/Z) ψ_c_1(x_1) ψ_c_2(x_1,x_2) ψ_c_3(x_1,x_2,x_3) ψ_c_4(x_3,x_4)
```
(15.31)
