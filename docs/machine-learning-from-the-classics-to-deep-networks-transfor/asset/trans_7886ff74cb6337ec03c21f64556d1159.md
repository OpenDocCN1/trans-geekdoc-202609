
我们利用了这样一个事实：`⟨f[⊥], κ(⋅, x[n])⟩ = 0`，`n = 1, 2, …, N`。换句话说，公式 [(11.17)](#Chp011_519-582_B9780443292385000172.xhtml#deq65) 中的展开保证了在训练点处，`f` 的值不依赖于 `f[⊥]`。因此，公式 [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64) 中对应经验损失的第一项*不*依赖于 `f[⊥]`。此外，对于所有的 `f[⊥]`，我们有

```
Ω(‖f‖²) = Ω(‖∑_{n=1}^{N} θ_n κ(⋅, x_n)‖² + ‖f_⊥‖²) ≥ Ω(‖∑_{n=1}^{N} θ_n κ(⋅, x_n)‖²).
```

因此，对于*任意*选择的 `θ[n]`，`n = 1, 2, …, N`，公式 [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64) 中的代价函数在 `f[⊥] = 0` 时取得最小值。因此，该断言得证。 □

该定理最早见于文献 [61]。文献 [2] 探讨了该定理成立的条件，并推导了相关的充分必要条件。该定理的重要性在于：为了关于 `f` 优化公式 [(11.16)](#Chp011_519-582_B9780443292385000172.xhtml#deq64)，需使用公式 [(11.17)](#Chp011_519-582_B9780443292385000172.xhtml#deq65) 中的展开，并关于参数的*有限*集合 `θ[n]`，`n = 1, 2, …, N` 进行最小化。

请注意，在高维/无限维空间中工作时，正则化项的存在几乎无法避免；否则，由于仅使用有限数量的数据样本进行训练，所得解将遭受过拟合。正则化对泛化性能及相关解的稳定性的影响已在许多经典论文中得到研究（例如，[18,39,79]）。
