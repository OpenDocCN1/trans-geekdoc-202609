```
h_{*,i} := argmin_{h_i} E [ (θ_i - θ̂_i)^2 ] = E [ (θ_i - h_i^T y)^2 ].
```

Minimizing (4.86) is exactly the same task as that of the linear estimation considered in the previous section (with y in place of x and θ[i] in place of y); hence,

Σ[y] h[*,i] = p[i], i = 1, 2, …, l.

where

Σ[y] = E[y y^(T)] and p[i] = E[y θ[i]], i = 1, 2, .., l.
