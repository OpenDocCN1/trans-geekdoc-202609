
以类似的方式，可以证明（问题 [3.10](#Chp003_65-117_B9780443292385000093.xhtml#o0055)），如果未知参数是方差 `σ²`，则 `S̄_σ² := (1/N) ∑_{n=1}^N (x_n - μ)²` 是充分统计量；如果 `μ` 和 `σ²` 都未知，则充分统计量是集合 `(S_μ, S_σ²)`，其中

```
S_σ² = (1/N) ∑_{n=1}^N (x_n - S_μ)².
```

换句话说，在这种情况下，所有关于未知参数集合的信息（这些信息可以从可用的 `N` 个观测值中提取）都可以通过仅考虑观测值的和及其平方和来完全恢复。

## 3.8 正则化

我们已经看到，在回归模型线性且存在高斯白噪声源的假设下，LS 估计量是 MVU 估计量。我们还知道，通过收缩 MVU 估计量的范数可以提高性能。实现这一目标的方法有很多，将在本书后面讨论。在本节中，我们重点介绍其中一种可能性。此外，我们将看到，试图保持解的范数较小在机器学习背景下服务于重要需求。

**正则化** 是一种数学工具，用于将先验信息施加于解的结构上，该解作为优化任务的结果而得出。正则化最初由伟大的俄罗斯数学家 Andrey Nikolayevich Tychonoff（有时拼作 Tikhonov）针对积分方程的求解提出。有时也称为 Tychonoff–Phillips 正则化，以表彰 David Phillips 独立开发了该方法 [29,39]。

在我们的任务背景下，为了收缩参数向量估计量的范数，我们可以将 Eq. [(3.12)](#Chp003_65-117_B9780443292385000093.xhtml#deq15) 中给出的平方误差和最小化任务重新表述为

```
minimize     J(θ) = ∑_{n=1}^N (y_n - θ^T x_n)²,
```

subject to `‖θ‖² ≤ ρ`，

其中 `‖·‖` 代表向量的欧几里得范数。这样，我们不允许 LS 准则完全“自由”地寻找解，而是*限制*搜索解的空间。显然，使用不同的 `ρ` 值，可以实现不同程度的收缩。正如我们已经讨论的，`ρ` 的最优值无法通过解析方法获得，必须通过实验来选择一个性能良好的估计量。对于之前使用的平方误差损失函数和约束条件，优化任务可以等价地写为 [6,8]
