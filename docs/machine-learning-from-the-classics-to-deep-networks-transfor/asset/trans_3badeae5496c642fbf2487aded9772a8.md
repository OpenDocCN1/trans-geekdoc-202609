

### Beta 分布

$$B(a,b) = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a + b)},$$

其中 $\Gamma$ 是伽马函数，定义为

$$\Gamma(a) = \int_0^\infty x^{a-1} e^{-x} \, dx.$$

Beta 分布非常灵活，通过改变参数 $a, b$ 可以获得各种形状。例如：

*   若 $a = b = 1$，则得到均匀分布。
*   若 $a = b$，概率密度函数（PDF）关于 $1/2$ 对称。
*   若 $a > 1, b > 1$，则 $p(x) \to 0$ 在 $x = 0$ 和 $x = 1$ 处均成立。
*   若 $a < 1$ 且 $b < 1$，函数凸起且有一个唯一的最小值。
*   若 $a < 1$，当 $x \to 0$ 时函数趋向 $\infty$。
*   若 $b < 1$，当 $x \to 1$ 时函数趋向 $\infty$。

#### 伽马分布

若随机变量服从具有正参数 $a, b$ 的伽马分布，记作 $x \sim \text{Gamma}(x|a, b)$，其概率密度函数为：

![Equation](images/B9780443292385000081/fx019.jpg) (2.92)

均值和方差由下式给出：

$$\mathbb{E}[x] = \frac{a}{b}, \quad \sigma_x^2 = \frac{a}{b^2}.$$
