## 8.6 从凸集到参数估计和机器学习

现在让我们看看如何将这一优雅的理论转化为机器学习中参数估计的有用工具。我们将通过两个例子演示该过程。

### 8.6.1 回归

考虑将输入-输出观测点联系起来的回归模型：

```
y[n] = θ[o]^(T) x[n] + η[n], (y[n], x[n]) ∈ ℝ × ℝ^(l), n = 1, 2, …, N,
```
(8.28)

其中 `θ[o]` 是未知参数向量。假设 `η[n]` 是有界噪声序列，即：

```
|η[n]| ≤ ϵ.
```

(8.29)

```
|y[n] − x[n]^(T) θ[o]| ≤ ϵ.
```
(8.30)

(8.31)
