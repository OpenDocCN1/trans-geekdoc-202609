
# 第13章：高级贝叶斯学习

本章是专门讲述贝叶斯学习的第二章。与第[12](#Chp012_583-634_B9780443292385000184.xhtml)章相比，重点在于更高级的主题，处理近似推断方法。当计算证据函数所涉及的积分在计算上不再可处理时，会采用此类方法。讨论了两条被称为变分技术的近似推断路径。一条基于均场近似和EM算法的下界解释，另一条基于凸对偶性和变分界。在此框架下讨论了回归和混合建模。重点介绍了稀疏贝叶斯建模技术和分层贝叶斯模型。展示了相关向量机框架。期望传播也被讨论为变分方法在近似推断方面的一种替代方案。在本章末尾，介绍了非参数模型背景下的贝叶斯学习，包括狄利克雷过程（DP）、中餐馆过程（CRP）、印度自助餐过程（IBP）和高斯过程。最后，展示了一个关于高光谱成像的案例研究。

## 13.2 贝叶斯学习中的变分近似

回顾一下，为了应用EM算法，给定观测值的情况下，潜在/隐变量后验的函数形式必须是已知的。然而，与后验相关的解析计算并不总是可处理的。在这种情况下，上一章讨论的标准形式的EM算法不再适用。在本节中，我们将描述一条替代路径，它建立在第[12.7](#Chp012_583-634_B9780443292385000184.xhtml)节给出的EM解释之上。

我们将再次采用一种通用符号，随后可根据具体问题的需求进行调整。设 $\mathcal{X} = \{\mathbf{x}[1], \dots, \mathbf{x}[N]\}$ 为观测变量集，$\mathcal{X}^{(l)} = \{\mathbf{x}[1]^{(l)}, \dots, \mathbf{x}[N]^{(l)}\}$ 为对应的 $N$ 个（局部）潜在变量集，它们已在第[12.4](#Chp012_583-634_B9780443292385000184.xhtml)节中定义。此外，在本节中，除了潜在变量外，我们将显式引入一组 $K$ 个（全局）隐随机参数 $\boldsymbol{\theta} \in \mathbb{R}^K$，其数量是固定的，并将伴随一个先验概率密度函数（PDF）。完全似然函数现在写为 $p(\mathcal{X}, \mathcal{X}^{(l)}, \boldsymbol{\theta}; \boldsymbol{\xi})$，其中 $\boldsymbol{\xi}$ 是必须估计的未知非随机（超）参数集。正如贝叶斯学习中总是那样，目标是推断描述潜在变量以及隐随机变量的后验概率分布。

公式 [(12.63)](#Chp012_583-634_B9780443292385000184.xhtml) 中的泛函现在重新定义为

$$
\mathcal{F}(q,\boldsymbol{\xi}) = \int q(\mathcal{X}^{l},\boldsymbol{\theta})\ln\frac{p(\mathcal{X},\mathcal{X}^{l},\boldsymbol{\theta};\boldsymbol{\xi})}{q(\mathcal{X}^{l},\boldsymbol{\theta})}\ d\mathcal{X}^{l}\ d\boldsymbol{\theta}.
$$
