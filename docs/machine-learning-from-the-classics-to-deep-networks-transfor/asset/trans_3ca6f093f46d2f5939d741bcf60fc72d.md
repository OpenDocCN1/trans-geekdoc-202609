
如果 `α` 选择得当，则生成的数字序列将呈现周期性，周期为 `M − 1`。这就是我们称这些生成器为伪随机的原因，因为周期性序列永远不能声称是随机的。然而，对于较大的 `M` 值，只要 `N ≤ M − 1`，获得的序列就可以具有均匀分布的足够随机性。例如，`M` 取 10⁹ 阶的值足以满足大多数应用。请注意，并非所有可能的参数 `α` 选择都能保证生成一个好的生成器。实际上，只有当序列通过许多相关的随机性测试，并随后在各种应用中成功使用时，才被接受为随机序列（参见，例如 [32]）。一个能产生相当好的均匀分布随机序列的常用参数选择是 `α = 7⁵` 和 `M = 2^(31) − 1`（参见，例如 [34]）。更多关于此主题的内容可参见 Knuth 的经典著作及其参考文献 [18]。一旦获得整数序列，均匀分布的实随机数序列即可通过比值 `x_i = z_i / M ∈ (0,1)` 获得（事实上，随机性测试正是应用于此序列）。

### 备注 14.1

*   请注意，即使是在 `(0, 1)` 上生成均匀分布的（伪）随机数序列也并非易事，尽管均匀分布是一种“简单”的分布；即所有值出现的概率相等。此外，在实践中，概率密度函数（PDF）通常仅在其归一化常数范围内已知，即

```
p(x) = ϕ(x) / Z,
```

其中

```
Z = ∫[−∞]^(+∞) ϕ(x) dx.
```

*   然而，如果 `ϕ(x)` 形式复杂，上述积分可能难以处理。计算后验 PDF 时常会遇到这种情况。上述观点表明，从一般 `p(x)` 采样的过程比均匀分布情况要困难得多。即使 `Z` 可用，在高维空间中任务变得更难。为了充分覆盖高维空间中的一个区域所需的点数，呈指数级依赖于相应的维度（维度灾难，见第 [3.12](#Chp003_65-117_B9780443292385000093.xhtml) 节）。因此，需要大量的点才能在高维空间中获得 `p(x)` 的良好表示。在实践中，人们更倾向于从 `p(x)` 取相对较高值的区域生成样本。然而，维度越高，定位高概率区域的任务就越困难。类似的论点也适用于离散性质的随机变量，其中变量可取的状态数非常大。理想情况下，为了获得有代表性的样本序列，必须访问所有状态。

## 14.3 基于函数变换的随机采样

在本节中，我们将探讨一些从概率密度函数（PDF）`p(x)` 抽取样本的最基本技术。

### 函数反演

设 `x` 为具有概率密度函数（PDF）`p(x)` 的实随机变量，其对应的累积分布函数为

```

```
