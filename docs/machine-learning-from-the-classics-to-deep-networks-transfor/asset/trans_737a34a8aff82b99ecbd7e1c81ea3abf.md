# 3.1 简介

参数建模是贯穿本书始终的主题。多个章节聚焦于这一重要问题的不同方面。本章提供了与利用参数模型描述可用数据这一学习任务相关的基本定义和概念。

正如在介绍性章节中已指出的那样，大类机器学习问题最终等同于函数估计/逼近任务。该函数在学习/训练阶段通过挖掘可用训练数据集中蕴含的信息而被“学习”得出。该函数将所谓的输入变量与输出变量联系起来。一旦建立了这种函数关系，便可以反过来利用它，基于对相应输入变量的测量来*预测*输出的值；这些预测随后可用于进入决策阶段。

在参数建模中，上述将输入与输出相关联的函数依赖关系是通过一组参数来定义的，其数量是*固定*且先验已知的。参数的值未知，必须根据可用的输入-输出观测值进行估计。与参数方法相对的是所谓的*非参数*方法。在这些方法中，参数可能仍参与建立输入-输出关系，但其数量*不*固定；它取决于数据集的大小，并随观测值的数量而增长。非参数方法也将在本书中讨论（例如第[11](#Chp011_519-582_B9780443292385000172.xhtml)章和第[13](#Chp013_635-716_B9780443292385000196.xhtml)章）。然而，本章的重点在于参数模型。

有两条可能的途径来处理由未知参数值带来的不确定性。根据第一种途径，参数被视为*确定性*非随机变量。学习任务是获得其未知值的估计。对于每个参数，获得单一的值估计。另一种途径具有更强的统计风味。未知参数被视为*随机变量*，学习任务是*推断*相关的概率分布。一旦分布被学习/推断出来，就可以用它们进行预测。这两种途径均在本章中介绍，并在本书后续的各章中进行更详细的阐述。

两大主要机器学习任务——回归和分类——被呈现出来，并阐述了处理这些问题的主要方向。介绍并讨论了与参数估计任务相关的各种问题，如估计量效率、偏差-方差困境、过拟合和维度灾难。本章也可视为通往本书其余部分的路线图。然而，我们没有仅以一种相当“枯燥”的方式呈现主要思想和方向，而是选择通过采用简单的模型和技术来处理和研究相关任务，以便读者能更好地领会主题。我们努力更多地关注科学概念，而非代数操作和数学细节，后者在“润色”后续章节时不可避免地会在更大程度上被使用。

最小二乘法（LS）、最大似然法（ML）、正则化和贝叶斯推断技术被呈现并讨论。我们努力帮助读者掌握本书传达的宏观图景的信息视角。因此，本章也可作为机器学习领域参数建模任务的概览性介绍。
