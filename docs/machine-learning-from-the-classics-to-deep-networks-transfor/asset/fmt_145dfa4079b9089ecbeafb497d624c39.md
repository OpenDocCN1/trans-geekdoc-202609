
where `σ[n]` is the vector formed by the respective *m* variances, and ⊙ denotes the element-wise multiplication. To draw samples of the latent variables, i.e., `z[n]^(k)`, *k* = 1, 2, …, it suffices to draw corresponding samples, `ϵ^(k)`, of the auxiliary variable. Thus, the first term in the loss function in Eq. [(19.22)](#Chp019_997-1102_B9780443292385000251.xhtml#deq47) can be approximated by the respective sample mean, after drawing *K* successive samples, i.e.,

```
A_n := E_q[ln p(x_n|z;θ)] = (1/K) ∑_{k=1}^K ln p(x_n|z_n^(k);θ)
```

where

```
z_n^(k) = μ_n + σ_n ⊙ ϵ^(k).
```

Recall that the conditional, *p*, is Gaussian and the respective logarithm is trivially computed. The term `A[n]` is a function of both `θ` and `ϕ` (via `μ[n]` and `σ[n]`). Using the reparameterization trick, it turns out that the variance of the associated estimator is substantially reduced. Thus, *K* need not take large values. In practice, drawing just one sample, i.e., *K* = 1, seems to be sufficient for most of the cases.
