
对于前文讨论的低秩矩阵分解方案，文献 [144,145] 提出了一种替代方案，该方案保证了所得矩阵因子元素的 `nonnegativity`（非负性）。在某些应用中必须施加此类约束，因为负元素与物理现实相矛盾。例如，在图像分析中，像素的强度值不能为负。概率值也不能为负。所得的分解被称为 `nonnegative matrix factorization`（非负矩阵分解，NMF），并已成功应用于多个领域，包括文档聚类 [192]、分子模式发现 [28]、图像分析 [122]、聚类 [171]、音乐转录、乐器分类 [20,166] 以及人脸验证 [198]。

给定一个 `l × N` 矩阵 `X`，NMF 的任务在于寻找 `X` 的一个近似分解，即

`X ≈ AZ`

其中 `A` 和 `Z` 分别为 `l × m` 和 `m × N` 矩阵，`m ≤ min(N, l)`，且所有矩阵元素均为非负，即 `A(i, k) ≥ 0`，`Z(k, j) ≥ 0`，`i = 1, 2, …, l`，`k = 1, 2, …, m`，`j = 1, 2, …, N`。显然，若矩阵 `A` 和 `Z` 为低秩，则它们的乘积也是低秩的，至多为 `m`，从而构成 `X` 的一个低秩近似。上述内容的意义在于 `X` 中的每个列向量均可由以下展开式表示：

```
x_i ≈ ∑_{k=1}^m Z(k,i) a_k, i = 1,2,…,N
```

其中 `a_k, k = 1,2,…,m` 为 `A` 的列向量，构成了该展开式的基。基中向量的数量少于向量本身的维数。因此，NMF 也可被视为一种 `dimensionality reduction`（降维）方法。

为在公式 (20.75) 中获得良好的近似，可采用不同的代价函数。最常用的代价是误差矩阵的 Frobenius 范数。在此设定下，NMF 任务可表述如下：

```
min_{A,Z} ||X - AZ||_F^2 := ∑_{i=1}^l ∑_{j=1}^N (X(i,j) - [AZ](i,j))^2
```
