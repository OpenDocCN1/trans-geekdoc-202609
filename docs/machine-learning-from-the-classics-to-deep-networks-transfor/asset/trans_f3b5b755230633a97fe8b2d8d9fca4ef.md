
其中 `f[n]` 和 `h[n]` 是非线性向量函数。在扩展卡尔曼滤波（EKF）中，其思路是通过泰勒级数展开，在每个时刻对函数 `h[n]` 和 `f[n]` 进行*线性化*，并仅保留线性项，从而得到

```
F_n = ∂f_n(x_n)/∂x_n|_{x_n = x̂_{n-1|n-1}}, H_n = ∂h_n(x_n)/∂x_n|_{x_n = x̂_{n|n-1}},
```

然后利用为线性情况推导出的更新公式继续进行。

从其定义本身来看，EKF 是次优的，且在实践中经常可能面临算法发散的问题；总体而言，必须指出其实际实施需要谨慎进行。话虽如此，必须强调的是它在许多实际系统中得到了广泛应用。

*无迹卡尔曼滤波器* 代表了一种应对非线性的替代方法，其主要思想源于概率论证。从 `p(x[n]|y[1],…,y[n])` 的高斯近似中确定性地选取一组点；这些点通过非线性函数传播，从而获得均值和协方差的估计 [15]。粒子滤波将在第 [17](#Chp017_855-884_B9780443292385000238.xhtml) 章讨论，它是另一种利用概率论证处理非线性状态空间模型的强大且流行的方法。

最近，再生核希尔伯特空间中的卡尔曼滤波扩展提供了一种处理非线性的替代方法 [52]。

第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中出现了许多用于分布式学习的卡尔曼滤波版本，例如见 [9,23,43]。文献 [33] 中，子空间学习方法被用于与状态变量相关的预测阶段。

关于卡尔曼滤波的文献浩如烟海，特别是在涉及应用方面。感兴趣的读者可参考更多专业文献，例如 [4,8,17] 及其参考文献。
