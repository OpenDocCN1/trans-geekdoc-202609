这可能难以求解。此外，即使积分可以计算，直接从 *p*(**y**[*n*]|**x**[*n* − 1]) 采样也可能不可行。无论如何，即使无法使用最优建议分布，我们仍然可以选择如下形式的建议分布

*q*[*n*](**x**[*n*]|**x**[1 : *n* − 1], **y**[1 : *n*]) = *q*(**x**[*n*]|**x**[*n* − 1], **y**[*n*])

![Equation](images/B9780443292385000238/si151.png)(17.37)

请注意，这种选择特别方便，因为在时刻 *n* 的采样仅依赖于 **x**[*n* − 1] 和 **y**[*n*]，而*不*依赖于整个历史。如果此外目标是获得 *p*(**x**[*n*]|**y**[1 : *n*]) 的估计，则无需在内存中保留所有先前生成的样本，而只需保留最近的一个，**x**[*n*]。

我们现在准备好编写第一个粒子滤波算法了。

### 算法 17.4

**SIS 粒子滤波**

*   •  选择一个先验分布 *p*，以生成初始状态 **x**[0] 的粒子。
*   •  选择粒子流的数量 *N*。
*   •  选择建议分布 *q*。
*   •  **For** *i* = 1, 2, …, *N* **Do**
    1.  –  采样 **x**[0]^((*i*)) ∼ *p*(**x**); 初始化 *N* 条粒子流。
    2.  –  设置 $w\_{0}^{(i)} = \\frac{1}{N}$; 将所有初始权重设为相等。
*   •  **End For**
