```
p(x_1,x_2,...,x_l) = ∏_{i = 1}^{l} ∫_{θ_i} p(x_i|Pa_i;θ_i) p(θ_i) dθ_i.
```

除了前述技术（它们是底层过程生成式建模的产物）之外，判别式技术也已得到发展。

在一般设定中，让我们考虑一个模式识别任务，其中（输出）标签变量 `y` 和（输入）特征变量 `x[1], …, x[l]` 根据一个可以在图上分解的分布联合分布，该分布由向量参数 `θ` 参数化，即 `p(y, x[1], x[2], …, x[l]; θ) := p(y, x; θ)` [13]。此类建模的一个典型例子是朴素贝叶斯分类器，我们在[第 7 章](#Chp007_293-342_B9780443292385000135.xhtml)中讨论过，其图形表示见[图 16.25](#Chp016_805-853_B9780443292385000226.xhtml#f0135)。对于给定的训练数据集，`(y[n], x[n])`，`n = 1, 2, …, N`，对数似然函数变为

```
L(Y,X;θ) = ∑_{n = 1}^{N} ln p(y_n, x_n; θ).
```
