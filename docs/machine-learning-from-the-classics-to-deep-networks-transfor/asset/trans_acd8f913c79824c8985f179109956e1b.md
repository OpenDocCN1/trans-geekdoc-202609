右边比率的对数称为*对数几率*比。因此，如果将公式[(7.88)](#Chp007_293-342_B9780443292385000135.xhtml#deq136)中的最小化函数视为公式[(7.99)](#Chp007_293-342_B9780443292385000135.xhtml#deq147)中均值的经验近似，则完全证明了将公式[(7.83)](#Chp007_293-342_B9780443292385000135.xhtml#deq131)中函数的符号视为分类规则是合理的。

与指数损失函数相关的一个主要问题，正如在[图 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085)中很容易看到的那样，就是它根据各自的边界值（定义如下），对错误分类的样本赋予了很大的权重：

$m_{x} := |yF(\mathbf{x})|.$

请注意，点离决策面（$F(\mathbf{x}) = 0$）越远，$|F(\mathbf{x})|$ 的值就越大。因此，位于决策面错误一侧（$yF(\mathbf{x}) < 0$）且距离较远的点会被赋予（指数级）较大的值，与其他点相比，它们在优化过程中的影响力较大。因此，在存在离群点的情况下，指数损失不是最合适的选择。事实上，在这样的环境中，AdaBoost 的性能可能会急剧下降。

### 备注 7.7

*   为了比较，[图 7.14](#Chp007_293-342_B9780443292385000135.xhtml#f0085)中展示了平方误差损失。平方误差损失取决于值 $(y - F(\mathbf{x}))$，这等同于上述定义的边界 $yF(\mathbf{x})$。观察到，除了较大误差值具有相对较大的影响外，对于标签已被正确预测的模式，误差也会受到惩罚。这又是一个理由，说明最小二乘法通常不是分类的好选择。
