# 2.2 概率与随机变量

随机变量 `x` 是其变化由机会/随机性引起的变量。随机变量可视为一个函数，它为实验的结果赋予一个值。例如，在抛硬币实验中，相应的随机变量 `x` 可取值 `x[1] = 0`（若实验结果为“正面”）和 `x[2] = 1`（若结果为“反面”）。

我们将用小写罗马字母表示随机变量，如 `x`，而用数学斜体表示实验进行后它所取的值，如 `x`。

若随机变量的值为离散性质，则用一组*概率*来描述；若其值位于实轴某一区间内的任意位置（不可数无限集），则用*概率密度函数*（PDF）来描述。关于更正式的处理和讨论，请参见文献 [4,6]。

## 2.2.1 概率

虽然“概率”和“或然”这两个词在我们的日常词汇中非常常见，但概率的数学定义并非一目了然，多年来已提出了许多不同的定义。毋庸置疑，无论采用哪种定义，最终推导出的性质和规则保持不变。最常用的两个定义如下：

### 相对频率定义

事件 `A` 的概率 `P(A)` 定义为极限

```
P(A) = lim_{n→∞} (n_A / n)
```
(2.1)

其中 `n` 为总试验次数，`n_A` 为事件 `A` 发生的次数。该定义的问题在于，在任何物理实验中，`n_A` 和 `n` 可以很大，但始终是有限的。因此，该极限只能作为一种*假设*使用，而非实验上可达到的结果。在实践中，对于较大的 `n` 值，常使用

```
P(A) ≈ n_A / n
```
(2.2)

但必须谨慎使用，特别是在事件概率非常小的情况下。

### 公理化定义

这一概率定义可追溯至 1933 年 Andrey Kolmogorov 的著作，他在测度论的背景下，发现了概率论与集合论及实变函数数学理论之间的密切联系，如文献 [5] 所述。

事件的概率 `P(A)` 是分配给该事件的一个非负数，即

```
P(A) ≥ 0.
```
(2.3)

必然发生的事件 `C` 的概率等于 1，即

```
P(C) = 1.
```
(2.4)

若两个事件 `A` 和 `B` 互斥（不能同时发生），则 `A` 或 `B` 发生（记为 `A ∪ B`）的概率由下式给出

```
P(A ∪ B) = P(A) + P(B).
```
(2.5)
