
*   In this way, the higher the probability (weight `W^(i)`) of an originally drawn particle is, the greater the number of times, `N^(i)`, this particle will be redrawn.

*   The new discrete estimate of the desired distribution will now be given by

```
\overline{p}(\mathbf{x}) = \sum\limits_{i = 1}^{N}\frac{N^{(i)}}{N}\delta(\mathbf{x} - \mathbf{x}_{i}).
```

*   From the properties of the multinomial distribution, we have `𝔼[N^(i)] = N*P[i] = N*W^(i)`, and hence `\overline{p}(\mathbf{x})` is an unbiased approximation of `\hat{p}(\mathbf{x})`.

*   **Systematic resampling**. Systematic resampling is a variant of the multinomial approach. Recall from [Example 14.2](#Chp014_717-754_B9780443292385000202.xhtml) that every time a particle is to be (re)drawn, a new sample is generated from the uniform distribution `𝒰(0, 1)`. In contrast, in systematic resampling, the process is not entirely random. To generate `N` particles, we only select randomly one sample, `u^(1) ~ \mathcal{U}(0, \frac{1}{N})`. Then define

```
u^{(j)} = u^{(1)} + \frac{j - 1}{N},\quad j = 2,3,\ldots,N,
```

*   and set

```
N^{(i)} = {card}\ \left\{ \text{All~}j:\sum\limits_{k = 1}^{i - 1}W^{(k)} \leqslant u^{(j)} < \sum\limits_{k = 1}^{i}W^{(k)} \right\},
```
