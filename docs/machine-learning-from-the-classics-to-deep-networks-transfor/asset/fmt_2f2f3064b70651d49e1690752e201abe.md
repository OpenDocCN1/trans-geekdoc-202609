
## K-means 算法步骤

1. 确定最近的聚类均值，记为 `μ[k]`，到 `x[n]`。
2. 设置 `b(n) = k`。

* **End For**

* **For** `k = 1, 2, …, K`，**Do**
    1. 更新 `μ[k]`，`k = 1, 2, …, K`，作为所有满足 `b(n) = k`、`n = 1, 2, …, N` 的点的均值。

* **End For**

* **Until** 两次连续迭代之间 `μ[k]`，`k = 1, 2, …, K` 不再发生变化。

`k-means` 算法也可以作为 EM 算法的一个极限情况推导得出（例如，参考文献 [34]）。注意，EM 算法和 `k-means` 算法都只能恢复**紧凑簇**。换句话说，如果点分布在环形簇中，则这类聚类算法不合适。
