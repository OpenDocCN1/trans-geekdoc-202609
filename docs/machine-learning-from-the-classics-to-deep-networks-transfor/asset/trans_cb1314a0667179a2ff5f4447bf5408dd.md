### III. 超额均方误差

我们知道，最小 MSE 在 **θ**[*] 处达到。任何其他权重向量都会导致更高的 MSE 值。我们已经说过，在稳态下，通过 LMS 获得的估计值在 **θ**[*] 周围随机波动；因此，MSE 将大于最小值 *J*[min]。这种“额外”的误差功率，记为 *J*[exc]，称为*超额* MSE。此外，比率

```
\mathcal{M}: = \frac{J_{\text{exc}}}{J_{\min}}
```

称为*失调度*。毫无疑问，我们应该寻求 ℳ 与 *μ* 之间的关系，在实践中我们希望相应地调整 *μ*，以使 ℳ 的值尽可能小。不幸的是，我们很快就会发现，要实现这一点存在权衡。使 ℳ 变小，收敛会变慢，反之亦然；世上没有免费的午餐！
