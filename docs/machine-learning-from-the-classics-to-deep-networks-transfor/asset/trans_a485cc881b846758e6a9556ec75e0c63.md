
并且训练样本是按顺序接收的（`y[n]`，`x[n]`），`n = 1, 2, …`。在平稳环境的情况下，我们期望算法在 `n → ∞` 时渐近收敛到产生观测值 `y[n]` 的真实参数向量，或者“几乎”收敛到该向量，当时它被 `x[n]` 感知时。对于时变环境，算法应能随时间推移跟踪潜在的变化。在继续之前，有一点评论很重要。因为时间索引 `n` 被允许增长，我们在前几节中关于欠定方程组的所有论述都失去了意义。迟早我们将拥有的观测值数量超过数据所在空间的维数。这里我们主要关注的问题变成了平稳环境下渐近收敛的问题。现在显而易见的问题是，为什么不使用标准算法（例如 LMS、RLS 或 APSM），因为我们知道这些算法会收敛到解，或者在某种意义上“足够接近”解（即算法将渐近地识别出零点）？答案是，如果这些算法经过修改以感知潜在的稀疏性，收敛速度将显著加快；在实际应用中，人们没有“奢侈”地等待很长时间才能得到解。在实践中，一个好的算法应该能在相对较少的迭代步骤后提供足够好的解，并且在稀疏解的情况下*获得支撑集*。

在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中，我们评论了修改经典在线方案（例如比例 LMS）以考虑稀疏性的尝试。然而，这些算法的性质相当权宜。在本节中，围绕 `ℓ₁` 范数正则化的强大理论将被用来获得促进稀疏性的时域自适应方案。

### 10.4.1 LASSO：渐近性能

在介绍第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章参数估计的基本原理时，引入了与估计量性能相关的偏差、方差和一致性概念。在许多情况下，这些性能指标是渐近推导出来的。例如，我们已经看到最大似然估计量是渐近无偏且一致的。在第 [6](#Chp006_249-291_B9780443292385000123.xhtml) 章中，我们看到在存在独立同分布白噪声样本的情况下，LS 估计量也是渐近一致的。此外，在后一假设下，基于 `n` 个观测值的 LS 估计量 `\hat{\mathbf{\theta}}_n` 本身是一个随机向量，满足 `\sqrt{n}`-估计一致性，即

```
\sqrt{n}\left( {\widehat{\mathbf{\theta}}}_n - \mathbf{\theta}_o \right)\longrightarrow\mathcal{N}\left( 0,\sigma_\eta^{2}\Sigma^{- 1} \right),
```

其中 `\mathbf{\theta}_o` 是产生观测值的真实向量，`\sigma_\eta^2` 表示噪声源的方差，`\Sigma` 是输入序列的协方差矩阵 `\mathbb{E}[\mathbf{x}\mathbf{x}^T]`，该序列已假设为零均值，极限表示依分布收敛。

公式 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 形式的 LASSO 是最小化平方误差和代价函数的 `ℓ₁` 范数正则化版本的任务。然而，到目前为止尚未提及该估计量的统计性质。我们提到的唯一性能指标是 [(9.36)](#Chp009_417-462_B9780443292385000159.xhtml) 中给出的误差范数界。然而，尽管该界在其提出的背景下很重要，但并未提供太多统计信息。自 LASSO 估计量提出以来，许多论文都探讨了与其统计性能相关的问题（参见例如 [45,55,74,127]）。
