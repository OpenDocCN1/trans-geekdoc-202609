其中 `ϵ` 是从标准高斯分布中抽取的噪声样本向量，用于获得 `x_t`（公式 [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135)）。回顾一下，训练的目标是估计 `μ_θ`，以便在给定样本 `x_t` 作为相关神经网络输入的情况下，最优地预测公式 [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145) 中对应的 `μ̃_t`。因此，在文献 [85] 中，建议使用以下重参数化，

```
μ_θ(x_t, t) = (1 / √a_t) (x_t - (β_t / √(1 - ā_t)) ε_θ(x_t, t))
```

![Equation](images/B9780443292385000251/si568.png) (19.68)

其中 `ε_θ(x_t, t)` 是一个函数逼近器（通过神经网络实现），旨在根据 `x_t` 预测公式 [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145) 中的 `ϵ`。将公式 [(19.71)](#Chp019_997-1102_B9780443292385000251.xhtml#deq145) 和 [(19.72)](#Chp019_997-1102_B9780443292385000251.xhtml#deq146) 代入公式 [(19.70)](#Chp019_997-1102_B9780443292385000251.xhtml#deq144)，可得

```
L_{t-1} = λ_t ||ε - ε_θ(x_t, t)||²,    λ_t := β_t² / (2 σ_t² a_t (1 - ā_t))
```

![Equation](images/B9780443292385000251/si570.png) (19.69)

其中 `x_t` 是根据公式 [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135) 采样得到的，`λ_t` 是一个加权序列。
