

## 广义线性 RLS 算法

$${\widetilde{\mathbf{p}}}_{n} = \sum\limits_{i = 0}^{n}\beta^{n - i}{\widetilde{\mathbf{x}}}_{n}y_{n}^{\ast}.$$

遵循与实值 RLS 类似的步骤，得到**算法 6.2**，其中 $\widetilde{P}[n] := \widetilde{\Phi}^{-1}$。

### 算法 6.2：广义线性 RLS 算法

*   **初始化**
    1.  $\boldsymbol{\varphi}[0] = \mathbf{0}$
    2.  $\widetilde{P}[-1] = \lambda^{-1}\mathbf{I}$
    3.  选择 $\beta$

*   **对于** $n = 0, 1, 2, \dots$ **执行**
    1.  $e_{n} = y_{n} - \boldsymbol{\varphi}_{n - 1}^{H}{\widetilde{\mathbf{x}}}_{n}$
    2.  $\mathbf{z}_{n} = \widetilde{P}_{n - 1}{\widetilde{\mathbf{x}}}_{n}$
    3.  $\mathbf{k}_{n} = \frac{\mathbf{z}_{n}}{\beta + {\widetilde{\mathbf{x}}}_{n}^{H}\mathbf{z}_{n}}$
    4.  $\boldsymbol{\varphi}[n] = \boldsymbol{\varphi}[n-1] + \mathbf{k}[n]e[n]^{\ast}$
