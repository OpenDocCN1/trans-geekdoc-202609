
• 克拉美尔-拉奥界并非文献中唯一可用的界。例如，巴特查里亚界利用概率密度函数（PDF）的高阶导数。结果表明，在不存在有效估计量的情况下，与最小方差无偏（MVU）估计量的方差相比，巴特查里亚界比克拉美尔-拉奥界更紧致 [27]。其他界也存在 [21]；然而，克拉美尔-拉奥界是最容易确定的。

## 3.7 充分统计量

如果不存在有效估计量，这并不一定意味着无法确定 MVU 估计量。它可能存在，但不会是有效的，因为它不满足克拉美尔-拉奥界。在这种情况下，*充分统计量*的概念和劳-布莱克威尔定理便派上用场了。^([^(11)](#fn11))

充分统计量的概念归功于罗纳德·艾尔默·费舍尔爵士（1890–1962）。费舍尔是一位英国统计学家和生物学家，他做出了许多奠定现代统计学基础的根本性贡献。除了统计学，他在遗传学方面也做出了重要贡献。

简而言之，给定一个随机向量 **x**，其分布取决于参数 *θ*，未知参数的充分统计量是一个函数，

`T(𝒳) : = T(x[1], x[2], …, x[N])`

即相应的观测值函数，它包含关于 *θ* 的*所有*信息。从数学角度来看，如果条件联合概率密度函数

`p(𝒳 | T(𝒳); θ)`

*不*依赖于 *θ*，则称统计量 `T(𝒳)` 对参数 *θ* 是充分的。在这种情况下，显而易见，`T(𝒳)` 必须提供集合 `𝒳` 中包含的关于 *θ* 的*所有*信息。一旦 `T(𝒳)` 已知，`𝒳` 就不再需要，因为无法从中提取更多信息；这也证明了“充分统计量”这一名称的由来。充分统计量的概念也推广到了参数向量 **θ**。在这种情况下，充分统计量可能是一组*函数*，称为*联合充分统计量*。通常，函数的个数与参数的个数相同；在略微滥用符号的情况下，我们仍将用 `T(𝒳)` 来表示这一组（向量）函数。

一个非常重要的定理，它在实践中便于寻找充分统计量，如下所示 [27]。

**定理 3.2：分解定理**

*当且仅当相应的联合概率密度函数可以分解为*

`p(𝒳; θ) = h(𝒳) g(T(𝒳), θ).`

*时，统计量* `T(𝒳)` *是充分的。*

*即，联合概率密度函数分解为两部分：一部分仅依赖于统计量和参数，另一部分独立于参数。该定理也称为费舍尔-内曼分解定理。*

一旦找到充分统计量，并在与该统计量相关的某些条件下，劳-布莱克威尔定理通过求条件于 `T(𝒳)` 的期望来确定 MVU 估计量。该定理的一个副产品是：如果一个无偏估计量*仅*用充分统计量表示，那么它必然是唯一的 MVU 估计量 [23]。感兴趣的读者可参考 [20,21,27] 了解更多相关内容。
