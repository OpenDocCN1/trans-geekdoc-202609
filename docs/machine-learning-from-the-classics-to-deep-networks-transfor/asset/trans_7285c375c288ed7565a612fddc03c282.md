
这正是其被称为“密度”函数的由来，即 x 落在微小区间 Δ*x* 内的概率 (Δ*P*)，除以该区间的长度。注意，当 Δ*x* → 0 时，该概率趋于零。因此，连续随机变量取任意单一值的概率为零。此外，由于 *P*(−∞ < *x* < +∞) = 1，我们有

```
∫[−∞]^(+∞) p_x(x) dx = 1.
```

通常，为简化符号，会省略下标 x 而写作 *p*(*x*)，除非为了避免可能的混淆而有必要保留。还要注意，我们采用小写 “*p*” 表示概率密度函数 (PDF)，大写 “*P*” 表示离散事件的概率。

关于概率的所有前述规则均可直接推广到 PDF 的情况，方式如下：

```
p(x|y) = p(x,y) / p(y),  p(x) = ∫_{-∞}^{+∞} p(x,y) dy.
```
