
该定义见文献[19]中提出。我们宽泛地说，如果 `δ[k]` 与 1 相差不大，则矩阵 `X` 满足 `k` 阶 RIP。当该性质成立时，意味着 `θ` 的欧几里得范数在投影到 `X` 的行上后大致*保持*不变。显然，如果矩阵 `X` 是标准正交的，我们将得到 `δ[k] = 0`。当然，因为我们处理的是非方阵，这是不可能的。然而，`δ[k]` 越接近零，`X` 的*所有* `k` 列子集就越接近标准正交。[(9.29)](#Chp009_417-462_B9780443292385000159.xhtml#deq65) 式中条件的另一种观点是 `X` 保持 `k` 稀疏向量之间的欧几里得距离。让我们考虑两个 `k` 稀疏向量 `θ[1]`、`θ[2]`，并将 [(9.29)](#Chp009_417-462_B9780443292385000159.xhtml#deq65) 应用于它们的差 `θ[1] − θ[2]`，后者通常是一个 `2k` 稀疏向量。于是我们得到

```
(1 − δ[2k])‖θ[1]−θ[2]‖[2]² ≤ ‖X(θ[1]−θ[2])‖[2]² ≤ (1 + δ[2k])‖θ[1]−θ[2]‖[2]².
```

因此，当 `δ[2k]` 足够小时，欧几里得距离在投影到低维观测空间后得以保持。换句话说，如果 RIP 成立，这意味着在由观测值形成的低维子空间 `ℝ^(N)` 中搜索稀疏向量，而不是在原来的 `l` 维空间中，仍然可以恢复该向量，因为距离得以保持，目标向量不会与其他向量“混淆”。投影到 `X` 的行上后，该方法的判别能力得以保留。值得注意的是，RIP 也与格拉姆矩阵的条件数有关。文献[6,19]指出，如果 `X[r]` 表示仅考虑 `X` 的 `r` 列所得到的矩阵，则 [(9.29)](#Chp009_417-462_B9780443292385000159.xhtml#deq65) 中的 RIP 等价于要求相应的格拉姆矩阵 `X[r]^(T)X[r]`（`r ≤ k`）的特征值位于区间 `[1 − δ[k], 1 + δ[k]]` 内。因此，矩阵条件数越好，我们就越能挖掘出隐藏在低维空间中的信息。
