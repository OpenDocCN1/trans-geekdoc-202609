
## 偏最小二乘法

*偏最小二乘法*（PLS）最早由文献[186]提出，并已广泛应用于化学计量学、生物信息学、食品研究、医学、药理学、社会科学和生理学等众多领域。

如果在公式[(20.39)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq53)中设定

```
B = [[I, O],
     [O, I]]
```

![Equation](images/B9780443292385000263/si175.png)

并保持矩阵`C`与典型相关分析（CCA）时相同，则会得到相应的特征分析问题。如果不像公式[(20.25)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq35)那样最大化相关系数`ρ`，而是最大化协方差，即

```
cov(z[x,1], z[y,1]) = E[z[x,1] z[y,1]]
```

![Equation](images/B9780443292385000263/si176.png) (20.40)

这意味着在降维的同时，我们不仅关注相关性，同时还希望找到能使两组变量方差最大的方向。寻找第一对轴`u[x,1]`、`u[y,1]`的优化任务变为：

![](images/B9780443292385000263/fx006.jpg)

PLS既可用于分类任务，也可用于回归任务。例如在第6章中，我们曾使用主成分分析（PCA）进行回归以降低空间维度，并在该低维空间中表示最小二乘解。然而，主成分轴仅基于输入数据确定，以保留最大方差。相比之下，PLS可将输出观测值视为第二组变量，从而选择能同时最大化方差及两组数据间相关性的轴。这一点可以从以下事实理解：最大化协方差（PLS）等价于最大化相关系数（CCA所用）与两个方差项的乘积。

### 矩阵结构变化引出的不同方法

改变两个矩阵`C`和`B`的结构，会得到不同的方法。例如，若设定

```
C = Σ̂[xx]
```

![Equation](images/B9780443292385000263/si173.png)

且

```
B = I
```

![Equation](images/B9780443292385000263/si174.png)

则得到主成分分析（PCA）的特征值-特征向量问题。

文献[189]讨论了以数值稳健方式求解相关方程的算法过程。

### 附：原始矩阵定义

原始矩阵`C`和`B`定义如下：

```
C = [[O,       Σ̂_xy],
     [Σ̂_yx,   O   ]]

B = [[Σ̂_xx,   O   ],
     [O,       Σ̂_yy]]
```
