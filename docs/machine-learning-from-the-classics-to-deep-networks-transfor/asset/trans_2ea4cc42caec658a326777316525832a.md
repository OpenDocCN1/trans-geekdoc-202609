
另一个主要问题是核函数的选择。不同的核会导致不同的性能。让我们仔细看看公式 [(11.17)](#Chp011_519-582_B9780443292385000172.xhtml#deq65) 中的展开式。可以将 `κ(x, x[n])` 视为一个函数，用于度量 `x` 和 `x[n]` 之间的**相似性**；换句话说，`κ(x, x[n])` 将 `x` 与训练样本 `x[n]` 进行**匹配**。如果 `κ(x, x[n])` 在 `x[n]` 周围的一个小区域内取相对较大的值，则称该核为局部核。例如，当使用高斯核时，`κ(x, x[n])` 远离 `x[n]` 的贡献会以指数级快速衰减，这取决于 `σ²` 的值。因此，`σ²` 的选择至关重要。如果待逼近的函数是平滑的，则应采用较大的 `σ²` 值。相反，如果函数在输入空间中剧烈变化，高斯核可能不是最佳选择。事实上，如果在这种情况下使用高斯核，必须拥有大量训练数据，以便足够密集地填充输入空间，从而能够获得对该函数足够好的近似。这引出了机器学习中另一个关键因素，即训练集的大小。后者不仅取决于输入空间的维度（维度灾难），还取决于未知函数经历的变化类型（例如，参见 [12]）。在实践中，为了选择合适的核函数，通常使用不同的核，并通过交叉验证为特定问题选择“最佳”的一个。

一条研究路线是根据先验知识或通过某种优化路径，设计与手头数据相匹配的核（例如，参见 [29, 65]）。在第 [11.13](#Chp011_519-582_B9780443292385000172.xhtml#s0165) 节中，我们将讨论使用多个核的技术，旨在最优地结合它们各自的特性。

### 11.10.5 多类泛化

SVM 分类任务是在二分类任务的背景下引入的。更一般的 `M` 类情况可以通过多种方式处理：

*   **一对其余**：求解 `M` 个二分类问题。每次，使用不同的 SVM 将其中一个类别与所有其他类别进行分类。因此，估计出 `M` 个分类器，即：

```
f[m](x) = 0, m = 1, 2, …, M,
```

这些分类器经过训练，使得对于 `x ∈ ω[m]` 有 `f[m](x) > 0`，否则 `f[m](x) < 0`。分类通过以下规则实现：

```
assign x in ω_k: if k = argmax_m f_m(x).
```
