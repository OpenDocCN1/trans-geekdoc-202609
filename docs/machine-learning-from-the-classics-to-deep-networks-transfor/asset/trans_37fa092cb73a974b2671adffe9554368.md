
$||\widehat{X} - X||_{F}^{2} := \sum\limits_{i}\sum\limits_{j}|\widehat{X}(i,j) - X(i,j)|^{2} = \sum\limits_{n = 1}^{N}||\widehat{\mathbf{x}}_{n} - \mathbf{x}_{n}||^{2}$

取得最小值；也就是说，通过选择投影到另一个 *m* 维子空间来获得 **x**[$n$]![Equation](images/B9780443292385000263/si466.png) 的任何其他 *m* 维近似（设为 $\widetilde{\mathbf{x}}_{n}$![Equation](images/B9780443292385000263/si56.png)），与 PCA 产生的结果相比，都会导致更高的平方误差范数近似。这也是一个强有力的结果，确立了 PCA 方法作为一种降维技术的显著优点。这种解释可以追溯到 Pearson [146]。
