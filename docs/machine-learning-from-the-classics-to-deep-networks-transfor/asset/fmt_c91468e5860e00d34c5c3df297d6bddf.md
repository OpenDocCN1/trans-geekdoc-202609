
## 协方差矩阵特征值分析

$$
\Sigma_1 = \begin{bmatrix} 1 & 0 \\ 0 & 0.1 \end{bmatrix},\quad \Sigma_2 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}.
$$

![Equation](images/B9780443292385000111/si613.png)

注意对于 `Σ₂` 的情况，两个特征值都等于 1；而对于 `Σ₁`，它们分别是 `λ₁ = 1` 和 `λ₂ = 0.1`（对于对角矩阵，特征值等于矩阵的对角元素）。

[图 5.8](#Chp005_177-248_B9780443292385000111.xhtml#f0045) 展示了 `Σ₁` 情况下两个 `μ` 值的误差曲线；灰色曲线对应最优值（`μₒ = 1.81`），红色曲线对应 `μ = μₒ/2 = 0.9`。观察到最优值实现了向零更快的收敛。需要注意的是，正如 [图 5.8](#Chp005_177-248_B9780443292385000111.xhtml#f0045) 所示，最初某些 `μ ≠ μₒ` 的收敛可能比 `μₒ` 更快。理论保证的是，最终对应最优值的曲线将比任何其他 `μ` 值的曲线更快地趋向于零。

[图 5.9](#Chp005_177-248_B9780443292385000111.xhtml#f0050) 展示了二维空间中连续估计值的轨迹以及等值曲线；正如我们从公式 [(5.21)](#Chp005_177-248_B9780443292385000111.xhtml#deq33) 的二次代价函数形式可以推断的那样，后者是椭圆。对比较大 `μ = 1.81` 对应的之字形路径，与较小步长 `μ = 0.9` 获得的更平滑路径。

**图 5.8** 黑色曲线对应最优值 `μ = μₒ`，灰色曲线对应 `μ = μₒ/2`，适用于特征值不相等的输入协方差矩阵情况。
