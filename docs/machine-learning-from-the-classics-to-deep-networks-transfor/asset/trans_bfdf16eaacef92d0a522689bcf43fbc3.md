
如果 `x[n-1] = 0`，则 `x[n]` 要么以概率 `q[e]` 保持同一状态，要么以概率 `p` 增加 1。如果 `x[n-1] = N`，则 `x[n]` 要么以概率 `q[e]` 保持同一状态，要么以概率 `p` 减少 1。显然，

```
2p + q = 1,  p + q[e] = 1.
```

```
P = [3/4  1/4  0    0    0
     1/4  1/2  1/4  0    0

     0    0    1/4  1/2  1/4
     0    0    0    1/4  3/4].
```
