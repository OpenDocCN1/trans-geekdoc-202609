
请注意，`{x[n] → x}` 表示由*所有*满足 `lim x[n](ζ) = x(ζ)` 的结果组成的事件。这与处处收敛的区别在于，现在允许有限个或可数无限个实现（即零概率集合）不收敛。通常，这种类型的收敛被称为*几乎必然*收敛或*概率为 1* 收敛。

### 均方收敛

如果满足以下条件，我们称随机序列 `x[n]` 在*均方意义上*收敛于随机变量 x：

```
𝔼 [|x[n]−x|²] → 0,  n → ∞.
```

### 依概率收敛

给定随机序列 `x[n]`、随机变量 x 和非负数 `ϵ`，则 `{|x[n] − x| > ϵ}` 是一个事件。我们定义新的数列 `P({|x[n]−x|>ϵ})`。如果构造的数列趋于零，则称 `x[n]` *依概率* 收敛于 x：

```
P({|x[n]−x|>ϵ}) → 0,  n → ∞,  ∀ϵ > 0.
```

### 依分布收敛

给定随机序列 `x[n]` 和随机变量 x，分别设 `F[n](x)` 和 `F(x)` 为其累积分布函数（CDF）。如果对于 `F(x)` 的*每一个*连续点 x 都有

```
F[n](x) → F(x),  n → ∞,
```

则称 `x[n]` *依分布* 收敛于 x。

可以证明，如果随机序列要么几乎处处收敛，要么均方收敛，则它必然依概率收敛；如果它依概率收敛，则它必然依分布收敛。反之则不一定成立。换句话说，最弱的收敛形式是依分布收敛。
