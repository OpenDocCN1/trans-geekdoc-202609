However, in contrast to the complete factorization scheme, which was adopted for the approximating distribution, `Q`, in Section 16.3.2 for the Boltzmann machine (corresponding to the removal of all edges in the graph), here the approximating graph will have a more complex structure. Only the edges connected to the output nodes are removed; this results in the graphical structure of Fig. 16.22, for `M = 3`. Because this structure is tractable, there is no need for further simplifications. The approximate conditional distribution, `Q`, of the simplified structure is parameterized in terms of a set of variational parameters, `λ[n]^(m)` (one for each delinked node), and it is written as
