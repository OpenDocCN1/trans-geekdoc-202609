
*   **L₀**：该项可解释为重构项，用于预测给定第一步潜在变量条件下原始数据样本的对数概率。该项在公式 [(19.22)](#Chp019_997-1102_B9780443292385000251.xhtml#deq47) 的 VAE 中扮演相同角色。由于条件分布的高斯性质，该分量也可用闭式计算。对于公式 [(19.69)](#Chp019_997-1102_B9780443292385000251.xhtml#deq143) 的情况，显而易见，最小化 **L₀** 等同于强制 **μ_θ(x₁, 1)** 在欧几里得范数意义上接近 **x₀**。

代价函数通过对所有观测值取平均获得，即 **𝔼[x₀ ∼ q(x₀)][L[x₀]]**，在实践中通过对所有观测输入样本取样本均值得到。

### 简化模型

前文引入的模型简化，即 **Σ_θ(x[t], t) = σ[t]²I**，在文献 [85] 中得到了进一步利用。序列 **σ[t]²** 有不同的可能选择。一种可能是设定 **σ[t]² = β[t]**，这使得反向路径涉及的协方差矩阵等于前向过程涉及的协方差矩阵。该假设导出公式 [(19.70)](#Chp019_997-1102_B9780443292385000251.xhtml#deq144)，训练简化为调整时间步 *t* 神经网络的输出 **μ_θ(x[t], t)** 以预测 **μ̃_t(x_t, x_0)**。现在让我们详细阐述一下公式 [(19.70)](#Chp019_997-1102_B9780443292385000251.xhtml#deq144)。

结合公式 [(19.59)](#Chp019_997-1102_B9780443292385000251.xhtml#deq135) 和 [(19.66)](#Chp019_997-1102_B9780443292385000251.xhtml#deq140) 并经过一些代数运算（[习题 19.8](#Chp019_997-1102_B9780443292385000251.xhtml#o0080)），可得

```
μ̃_t(x_t, x_0) = (1/√a_t) (x_t - (β_t/√(1 - ā_t)) ε)
```
