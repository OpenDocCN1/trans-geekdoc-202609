
### 图像去模糊参数设置

*   使用较小的噪声方差值，例如 `10^(-6)`。
*   要执行去模糊操作，需要使用 `deconvwnr` 函数。例如，如果 `J` 是包含模糊图像（含噪声）的数组，`PSF` 是产生模糊的点扩散函数，则命令如下：

```
K = deconvwnr(J, PSF, C);
```

该命令返回去模糊后的图像 `K`，前提是 `C` 的选择合理。作为首次尝试，可选择 `C = 10^(-4)`。尝试使用自选的各种 `C` 值，并对结果进行评论。
