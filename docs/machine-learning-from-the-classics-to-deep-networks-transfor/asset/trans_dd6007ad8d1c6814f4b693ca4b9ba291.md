请注意，将时间固定为特定值 `n = n[0]`，会使 `u[n[0]]` 成为一个随机变量。确实，对于我们执行的每个随机实验，在时刻 `n[0]` 都会产生一个单一值。从这个角度来看，随机过程可以被视为无限随机变量的集合，`{u[n], n ∈ ℤ}`。那么，是否有必要将随机过程与随机变量/向量分开研究？答案是肯定的，原因在于我们将允许不同时刻对应的随机变量之间存在特定的时间依赖性，并研究这种依赖性对随机过程时间演化的相应影响。随机过程将在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中探讨，其中底层的时间依赖性将被利用以简化计算，并将在第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章中在高斯过程的背景下进行探讨。

### 2.4.1 一阶和二阶统计量

要完整描述一个随机过程，必须知道所有可能的随机变量组合 `u[n], u[m], …, u[r]` 的联合 PDF（离散值随机变量的 PMF）：

`p(u[n], u[m], …, u[r]; n, m, …, r)` (2.98)

请注意，为了强调这一点，我们显式地标出了联合 PDF 所涉及时刻的依赖关系。然而，从现在起，为了符号表示的方便，这将被省略。在实践中，以及在本书中，最常见的情况是仅基于 `p(u[n])` 和 `p(u[n], u[m])` 计算一阶和二阶统计量。为此，以下量具有特别的意义。

**时刻 n 处的均值**：

`μ[n] := 𝔼[u[n]] = ∫[−∞]^(+∞) u[n] p(u[n]) du[n]` (2.99)
