
# Local Linear Embedding (LLE)

As was the case with the Laplacian eigenmap method, *local linear embedding* (LLE) assumes that the data points rest on a smooth enough manifold of dimension *m*, which is embedded in the $\mathbb{R}^l$ space, with $m < l$ [155]. The smoothness assumption allows us to further assume that, provided there are sufficient data and the manifold is "well" sampled, nearby points lie on (or close to) a "locally" *linear* patch of the manifold (see, also, related comments in Section 20.8.3). The algorithm in its simplest form is summarized in the following three steps:

## Step 1: Nearest Neighbor Search

For each point, $\mathbf{x}_n, n = 1,2,\ldots,N$, search for its nearest neighbors.

## Step 2: Weight Computation

Compute the weights $W(n, j), j = 1, 2, \ldots, N$, that best reconstruct each point, $\mathbf{x}[n]$, from its nearest neighbors, so as to minimize the cost

```
\arg\min_W E_W = \sum_{n=1}^N \left\| \mathbf{x}_n - \sum_{j=1}^N W(n,j)\mathbf{x}_{n_j} \right\|^2,
```

where $\mathbf{x}_{n_j}$ denotes the $j$th neighbor of the $n$th point.

Constraints:
1. The weights are constrained to be zero for points which are not neighbors.
2. The rows of the weight matrix add to one:

```
\sum_{j=1}^N W(n,j) = 1, \quad n = 1,2,\ldots,N.
```

That is, the sum of the weights, over all neighbors, must be equal to one.

## Step 3: Embedding

Once the weights have been computed from the previous step, use them to obtain the corresponding points $\mathbf{z}_n \in \mathbb{R}^m, n = 1,2,\ldots,N$, so as to minimize the cost with respect to the unknown set of points $\mathcal{Z} = \{\mathbf{z}_n, n = 1,2,\ldots,N\}$.
