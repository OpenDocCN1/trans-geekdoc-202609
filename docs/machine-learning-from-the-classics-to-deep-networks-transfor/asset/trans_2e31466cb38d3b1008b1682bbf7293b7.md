

### 1. Select the column

选择 `X` 的列 **x**[*j*[*i*]]^(*c*)，该列与相应的误差向量 **e**^((*i* − 1)) :  = **y** − *X***θ**^((*i* − 1)) **最大程度相关**（即形成最小角度），即：

```
\mathbf{x}_{j_{i}}^{c}: j_{i}: = {arg\, max}_{j = 1,2,\ldots,l} \frac{\left| {\mathbf{x}_{j}^{c}}^{T}\mathbf{e}^{(i - 1)} \right|}{\left\| \mathbf{x}_{j}^{c} \right\|_{2}}.
```

### 2. Update the support and the corresponding set of active columns

更新支撑集和相应的活动列集合，*S*^((*i*)) = *S*^((*i* − 1)) ∪ {*j*[*i*]} 和 *X*^((*i*)) = \[*X*^((*i* − 1)), **x**[*j*[*i*]]^(*c*)\]。

### 3. Update the estimate of the parameter vector

更新参数向量的估计：仅使用 `X` 的活动列，求解使误差范数最小的最小二乘（LS）问题，即：

```
\widetilde{\mathbf{\theta}}: = {arg\, min}_{\mathbf{z} \in \mathbb{R}^{i}} \left\| \mathbf{y} - X^{(i)}\mathbf{z} \right\|_{2}^{2}.
```
