```
$\mathbf{\theta}^{(i)} = S_{\lambda\mu}(\widetilde{\mathbf{\theta}}) = S_{\lambda\mu}\left( \mathbf{\theta}^{(i - 1)} - \mu\frac{\partial J\left( \mathbf{\theta}^{(i - 1)} \right)}{\partial\mathbf{\theta}} \right)$
```

```
= S_{\lambda\mu}\left( \mathbf{\theta}^{(i - 1)} + \mu X^{(T)}\mathbf{e}^{(i - 1)} \right).
```

![Equation](images/B9780443292385000160/si88.png)(10.7)

这非常有趣且具有实用价值。损失函数中存在非光滑 $\ell_1$ 范数的唯一影响是增加了一个简单的额外阈值操作，正如我们所知，这是一种对每个分量*单独*执行的操作。可以证明（例如，[11,95]），该算法收敛于 LASSO [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) 的一个极小化点 $\mathbf{\theta}^*$，前提是 $\mu \in (0, 1/\lambda_{max}(X^{(T)}X))$，其中 $\lambda_{max}(\cdot)$ 表示 $X^{(T)}X$ 的最大特征值。收敛速度遵循以下规则

```
L(\mathbf{\theta}^{(i)}, \lambda) - L(\mathbf{\theta}^*, \lambda) \propto O(1/i),
```
