
### Smoothing and Filtering

*Smoothing* is closely related to filtering processing. In filtering, the goal lies in obtaining estimates of **x**[1 : *n*] (**x**[*n*]) based on observations taken in the index set {1, 2, …, *n*}, that is, on **y**[1 : *n*]. In smoothing, one obtains estimates of **x**[*n*] based on an observation set **y**[1 : *n* + *k*], *k* > 0. There are two paths to smoothing. One is known as *fixed lag* smoothing, where *k* is a fixed lag. The other is known as *fixed interval*, where one is interested in obtaining estimates based on observations taken over a time index set {1, 2, …, *T*}, that is, based on a fixed set of observations **y**[1 : *T*].

### Algorithmic Approaches to Smoothing

There are different algorithmic approaches to smoothing. The naive one is to run the particle filtering up to time *n* + *k* or *T* and use the obtained weights for weighting the particles at time *n*, in order to form the random measure, i.e.,

```
p(\mathbf{x}_{n}|\mathbf{y}_{1:n + k}) \approx \sum\limits_{i = 1}^{N}W_{n + k}^{(i)}\delta\left( \mathbf{x}_{n} - \mathbf{x}_{n}^{(i)} \right).
```

This can be a reasonable approximation for small values of *k* (or *T* − *n*). Other, more refined, techniques adopt a two-pass rationale. First, a particle filtering is run, and then a backward set of recursions is used to modify the weights (see, e.g., \[11\]).

### High-Dimensional Challenges

One of the main difficulties of the particle filtering methods is that the number of particles required to approximate the underlying distributions increases exponentially with the state dimension. To overcome this problem, several methods have been proposed:

*   In \[32\], the authors propose to partition the state and estimate each partition independently.
*   In \[17\], the annealed particle filter is proposed, which implements a coarse-to-fine strategy by using a series of smoothed weighting functions.
*   The unscented particle filter \[39\] proposes to use the unscented transform for each particle to avoid wasting resources in low likelihood regions.
*   In \[33\], a hierarchical search strategy is proposed that uses auxiliary lower dimension models to guide the search in higher dimensions.

### Differentiable Particle Filters

*Differentiable particle filters*: This is an emerging field that fuses ideas from classical particle filtering, as we have discussed before, with learning strategies borrowed from the neural networks terrain. The main idea lies in *constructing* and *learning* the involved models, namely the dynamic state model, the observations model, the proposal distribution model and, more recently, the resampling strategy. These techniques seem to offer the model expressiveness that is needed for complex high-dimensional applications. The term “differentiable” springs from the fact that gradient techniques are utilized for learning the adopted models, see e.g., \[5,25\] for related reviews.
