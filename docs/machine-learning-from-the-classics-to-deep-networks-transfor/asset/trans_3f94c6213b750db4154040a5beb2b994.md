
## 12.9 组合学习模型：概率视角

在第 [7.9](#Chp007_293-342_B9780443292385000135.xhtml) 节中介绍了通过利用不同学习器的个体特性来组合它们以提升整体性能的思想。我们现在通过概率论证重返这一任务。从教学角度来看，本节也很有用，能让读者进一步熟悉 EM 算法的使用。

我们的出发点是数据分布在输入空间的不同区域。因此，为每个区域拟合不同的学习模型似乎是合理的。这一想法让人联想到第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章中讨论的决策树。在那里，执行了输入空间的轴对齐（线性）分割。在这里，输入空间将通过超平面（也可推广到更一般的超曲面）以一般位置进行分割。此外，主要区别在于在 CART 中，分割属于硬性决策规则。在当前设定中，我们采取更宽松的态度，将考虑软性概率分割，这是以牺牲一些可解释性为代价的。

ME 估计呈指数形式：

```
p̂(x) = C exp( ∑_{i ∈ I} θ_i u_i(x) )
```

参数 `θ[i]`，`i ∈ I`，是优化任务中使用的拉格朗日乘子，其值由约束条件决定，并用可用的经验期望 `μ̂[i]`，`i ∈ I` 来表示。如果除了显而易见的（归一化）约束外不使用其他约束，且 `A[x] = [a, b] ⊂ R`，则得到的 PDF 是均匀分布，`p(x) = C`；确实，这是最随机的一个，因为它对任何特定值区间都不表现出偏好。如果使用两个约束，使得 `u[1](x) = x` 和 `u[2](x) = x²`，则得到的 PDF 是高斯分布，因为指数呈二次形式（见本章附录）。换句话说，高斯分布是在与均值和方差相关的两个约束条件下最随机的 PDF。注意，尽管我们专注于实值随机变量，但一切都可平凡地推广到向量值情况。关于 ME 方法和问题的替代观点的有趣讨论见文献 [42]。
