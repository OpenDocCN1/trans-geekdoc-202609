
设 $f$ 为凸函数，`Prox[λf]` 为指数为 $\lambda$ 的相应近端算子。然后，从任意点 `x[0] ∈ ℝ^l` 出发，迭代算法

```
x[k] = x[k-1] + μ[k](Prox[λf](x[k-1]) - x[k-1])
```
(8.117)

其中 `μ[k] ∈ (0, 2)` 使得

```
∑_{k=1}^{∞} μ[k](2 - μ[k]) = +∞
```

收敛到近端算子不动点集的一个元素；即它收敛到 $f$ 的一个极小化点。

该命题的证明见习题 [8.36](#Chp008_343-416_B9780443292385000147.xhtml#o0210) [84]。注意公式 [(8.118)](#Chp008_343-416_B9780443292385000147.xhtml#deq223) 是公式 [(8.26)](#Chp008_343-416_B9780443292385000147.xhtml#deq56) 的对应形式。若 `μ[k] = 1` 则为特殊情况，其结果为

```
x[k] = Prox[λf](x[k-1])
```
(8.118)

也称为*近端点*算法。近端极小化算法可追溯至 1970 年代初 [57, 72]。

## 示例 8.11

让我们通过熟悉的二次函数优化任务来演示上述发现：

```
f(x) = (1/2)x^T A x - b^T x
```

不难发现，极小化点出现在线性方程组

```
A x[*] = b
```

的解处。根据公式 [(8.106)](#Chp008_343-416_B9780443292385000147.xhtml#deq200) 中的定义，对二次函数求梯度并令其为零，我们可直接得到

```
Prox_{λf}(x) = (A + (1/λ)I)^{-1} (b + (1/λ)x)
```
