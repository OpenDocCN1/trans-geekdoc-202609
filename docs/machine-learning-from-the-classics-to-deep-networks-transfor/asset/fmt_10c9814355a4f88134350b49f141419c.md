
## 算法步骤

1. **初始化粒子流**
   - 采样 `x[0]^(i) ~ p(x)`；初始化 *N* 条粒子流。

2. **设置初始权重**
   - 令 `W[0]^(i) = 1/N`；将所有归一化权重设为相等值。

3. **主循环**
   - **For** `n = 1, 2, ...` **Do**

     1. **预测与权重计算**
        - **For** `i = 1, 2, ..., N` **Do**
          - 采样/计算 `μ[n]^(i)`
          - 计算 `Q[i] = p(y[n] | μ[n]^(i)) * W[n-1]^(i)`；这对应方程 (17.46) 中的 `q(i | y[1:n])`。
        - **End For**

     2. **归一化权重**
        - **For** `i = 1, 2, ..., N` **Do**
          - 计算归一化的 `Q[i]`。
        - **End For**

     3. **重采样与传播**
        - **For** `i = 1, 2, ..., N` **Do**
          - 采样 `i[n-1] ~ Q[i]`；参考方程 (17.47)。
          - 采样 `x[n]^(i) ~ p(x | x[n-1]^(i[n-1]))`。
          - 计算 `w[n]^(i) = p(y[n] | x[n]^(i)) / p(y[n] | μ[n]^(i))`。
        - **End For**

     4. **更新权重**
        - **For** `i = 1, 2, ..., N` **Do**
          - 更新归一化权重 `W[n]^(i)`。
        - **End For**

   - **End For**
