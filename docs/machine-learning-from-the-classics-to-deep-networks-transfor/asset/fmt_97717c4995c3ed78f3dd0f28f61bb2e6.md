We have used the fact that $\mathbb{E}[\eta[n] u[n - k]] = 0$ for $k > 0$. Indeed, $u[n - k]$ depends recursively on $\eta[n - k], \eta[n - k - 1] \dots$, which are all uncorrelated to $\eta[n]$, since this is a white noise process. Note that Eq. (2.139) is a difference equation, which can be solved provided we have the initial conditions. To this end, multiply Eq. (2.138) by $u[n]$ and take expectations, which results in

$$
\sum_{i = 0}^{l} a_i r(i) = \sigma_{\eta}^2 \tag{2.140}
$$

since $\mathbb{E}[u[n] \eta[n]] = \sigma_{\eta}^2$.
