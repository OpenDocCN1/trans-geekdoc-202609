
请注意，$(I - C(C^H C)^{-1} C^H)$ 是由约束定义的超平面的交集（仿射集）上的正交投影矩阵（回想一下 $C(C^H C)^{-1} C^H$ 是由 $\mathbf{c}_i, i = 1, 2, \dots, m$ 张成的子空间上的相应投影矩阵）。可以很容易地验证，在每次迭代步骤中，$\mathbf{w}_n$ 都满足约束条件。该算法初始化为 $\mathbf{w}_1 = C(C^H C)^{-1} \mathbf{g}$。如果目标是最小化输出功率，则必须在 $e_n$ 中将期望响应设置为零，即 $d_n = 0$。

约束 LMS 最早见于文献 [40]。除了前面使用的约束外，还可以使用其他约束；例如，对于约束 NLMS，还额外要求

```
\mathbf{w}_n^H \mathbf{u}_n = d_n
```

（参见，例如 [6]）。

## 5.12 非平稳环境下 LMS 的跟踪性能

我们已经讨论了 LMS 的收敛行为，并对其他已讨论算法做了相关评论。如前所述，收敛是一种*瞬态*现象；即它关注从初始启动点到稳态的时期。对于平稳环境（即未知参数向量以及涉及的随机变量/过程的底层统计特性保持不变的环境），稳态也已进行过讨论。

现在我们将重点转移到真实（但未知）参数向量/系统发生变化的情况。这会影响输出观测值，进而影响其统计特性。请注意，输入的统计特性也可能发生变化。然而，我们不打算考虑此类情况，因为分析可能会变得相当复杂。我们的目标是研究 LMS 的*跟踪*性能，即算法跟踪未知参数向量变化的能力。请注意，跟踪是一种*稳态*现象。换句话说，我们假设已经过去了足够长的时间，以至于初始条件的影响已被遗忘，不再对算法产生任何影响。跟踪敏捷性和收敛速度是算法的两个*不同*属性。一个算法可能收敛快，但*不一定*具有良好的跟踪性能，反之亦然。稍后我们将看到此类情况。

我们讨论的设置将类似于第 [5.5.1](#Chp005_177-248_B9780443292385000111.xhtml#s0050) 节。根据那里的讨论，我们考虑实数据情况；类似的结果也适用于复值线性估计场景。然而，与公式 [(5.38)](#Chp005_177-248_B9780443292385000111.xhtml#deq71) 中采用的模型相反，这里采用了一个*时变*模型，使用以下假设。
