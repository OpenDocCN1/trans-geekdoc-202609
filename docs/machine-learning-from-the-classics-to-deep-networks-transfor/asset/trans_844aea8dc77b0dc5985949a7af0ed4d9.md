
执行 SVD 分解，`Ẽ[k] = U D V^T`，**a**[k] 设置为对应最大奇异值的 **u**[1]，且 `z̃_k^r = D(1,1) v_1`。因此，字典的原子以*归一化*形式获得（回顾 SVD 理论可知 `||u[1]|| = 1`）。随后，为 `z̃_k^r` 获得的更新值被放置在 **z**[k]^(r) 中的相应位置。后者现在拥有的零元素数量至少与之前一样多，因为 **v**[1] 中的某些元素可能为零。简单的论证（[问题 20.3](#Chp020_1103-1179_B9780443292385000263.xhtml#o0085)）表明，在每次迭代中误差都会减小，且算法收敛到局部最小值。该算法的成功取决于贪婪算法在第一阶段提供稀疏解的能力。正如我们从第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章所知，对于与 `l` 相比足够小的稀疏度水平 `T[0]`，贪婪算法效果良好。

总之，*k*-SVD 算法的每个迭代步骤包含以下计算步骤。

*   •  将 `A^((0))` 初始化为列向量归一化为单位 `ℓ[2]` 范数。
*   •  设置 `i = 1`。
*   •  *阶段 1*：求解 [(20.66)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq96) 和 [(20.67)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq97) 中的优化任务，以获得稀疏编码表示向量 **z**[n]，`n = 1, 2, …, N`；可使用为此任务开发的任何算法。
*   •  *阶段 2*：对于 `A^((i−1))` 中的任意列 `k = 1, 2, …, m`，按以下方式更新它：
    1.  –  识别从阶段 1 计算得到的矩阵 *Z* 的第 *k* 行中非零元素的位置。
    2.  –  选取 `E[k]` 中对应 *Z* 的第 *k* 行非零元素位置的列，形成降阶误差矩阵 `Ẽ[k]`。
    3.  –  对 `Ẽ[k]` 执行 SVD 分解：`Ẽ[k] = U D V^T`。
