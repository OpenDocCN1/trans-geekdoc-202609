
$$
\widehat{p}_{n}(\mathbf{x}_{1:n}) = \sum\limits_{i = 1}^{N}W_{n}^{(i)}\delta(\mathbf{x}_{1:n} - \mathbf{x}_{1:n}^{(i)}).
$$

![Equation](images/B9780443292385000238/si85.png)

However, as we have already said, the variance of the weights has the tendency to increase with `n` (see Problem [17.5](#Chp017_855-884_B9780443292385000238.xhtml#o0050)). Thus, the resampling version of the sequential importance sampling is usually employed.

### Algorithm 17.3: SIS with resampling

*   Select `q_1(·)`.
*   Select `q_n(· | ·)` for `n = 1, 2, …`.
*   Select number of particles `N`.
*   **For** `i = 1, 2, …, N`, **Do**
    1.  Draw `x_1^{(i)} ~ q_1(x)`.
    2.  Compute the weights `w_1(x_1^{(i)}) = phi_1(x_1^{(i)}) / q_1(x_1^{(i)})`.
*   **End For**
*   **For** `i = 1, …, N`, **Do**
    1.  Compute the normalized weights `W_1^{(i)}`.
*   **End For**
*   Resample `{x_1^{(i)}, W_1^{(i)}}_{i=1}^N` to obtain `{\overline{x}_1^{(i)}, 1/N}_{i=1}^N`, using [Algorithm 17.1](#Chp017_855-884_B9780443292385000238.xhtml#enun0010).
