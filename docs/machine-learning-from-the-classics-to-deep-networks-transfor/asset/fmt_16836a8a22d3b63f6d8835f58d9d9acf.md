
# Class-Conditional Models

For class-conditional models, one straightforward way that comes into mind is to obtain class-related vector embeddings. That is, class information is encoded as a vector and projected to appropriate dimensions that feed the various layers of the U-Net, together with the time embeddings. One can think of various ways of combining class information with the feature maps computed in the layers of the U-Net, e.g., [44]. Under these modifications, the U-Net returns class-conditioned estimates, i.e., `μ_θ(x_t, t, y)` or `ϵ_θ(x_t, t, y)`.

A drawback of the previous vanilla formulation is that the learned models may downplay the related conditioning information on which they have been trained on. To this end, guidance models have been proposed that offer the capability of more explicitly controlling the available conditioning-related information.

## Classifier Guidance

In [44], it is proposed to train a classifier, `p_ϕ(y|x_t, t)`, on noisy samples, `x_t`, where `y` denotes the class label variable. Having trained the classifier, the gradients `∇_x_t ln p_ϕ(y|x_t, t)` are employed to *guide* the reverse process to sample from an arbitrary class, `y`. During sampling, one replaces `μ_θ_*(x_t, t)` in Eq. (19.75) with

```
μ̂_θ_*(x_t, t, y) = μ_θ_*(x_t, t) + γ Σ_θ_*(x_t, t) ∇_x_t ln p_ϕ_*(y|x_t, t)
```
