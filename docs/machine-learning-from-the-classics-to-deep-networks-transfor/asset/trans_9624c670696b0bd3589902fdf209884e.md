

## 优化步骤

关于 **Θ** 的优化分两步进行：一步关于 *ŷ*[*i**j*], *j* = 1, 2, …, *J*，给定 *R*[*i**j*]；另一步关于区域 *R*[*i**j*]。后者是一项困难的任务，仅在极少数特殊情况下才能简化。在实践中，可以采用多种近似方法。注意，在指数损失和二分类任务的情况下，上述过程直接关联到 AdaBoost 算法。

对于更一般的情况，会调用数值优化方案（参见 [16]）。同样的原理适用于回归树，此时使用用于回归的损失函数，如平方误差或绝对误差值。此类方案也称为 **多重加性回归树 (MARTs)**。boosted trees 的相关实现代码可在 R 语言的 `gbm` 包 [30] 中免费获取。

关于 boosted trees 有两个关键因素：一是树的大小 *J*，二是 *K* 的选择。关于树的大小，通常尝试不同的大小，4 ≤ *J* ≤ 8，并选择最佳者。关于迭代次数，当值较大时，训练误差可能接近零，但由于过拟合，测试误差可能会增加。因此，必须足够早地停止，通常通过监控性能来实现。

应对过拟合的另一种方法是采用 **收缩** 方法，这倾向于等同于正则化。例如，在优化步骤公式 [(7.105)](#Chp007_293-342_B9780443292385000135.xhtml#deq154) 中使用的 *F*[*i*](**x**) 的逐阶扩展中，可以改为采用以下形式：

*F*[*i*](·) = *F*[*i* − 1](·) + *νT*(·; **Θ**[*i*])。

参数 *ν* 取较小的值，可视为控制 boosting 过程的学习率。建议取值小于 *ν* < 0.1。然而，*ν* 的值越小，为保证良好性能，*K* 的值应越大。关于 MARTs 的更多内容，感兴趣的读者可参阅 [19]。

## 习题

1.  **7.1** 证明贝叶斯分类器是最优的，即它使错误概率最小化。

2.  **提示**：考虑一个 *M* 类分类任务，从正确标签预测的概率 *P*(*C*) 开始。则错误概率为 *P*(*e*) = 1 − *P*(*C*)。

3.  **7.2** 证明如果数据在 *M* 类任务中服从高斯分布，且所有类的协方差矩阵相等，则由贝叶斯分类器形成的区域是凸的。

4.  **7.3** 推导两个等概率类别情况下贝叶斯分类器的形式，假设数据服从相同协方差矩阵的高斯分布。进一步推导描述最小二乘 (LS) 线性分类器的方程。比较并评论结果。
