
The discrete gradient operators in the $x$ and $y$ directions are defined as:

```
∇ₓ(I)(i, j) := I(i + 1, j) − I(i, j),  ∀i ∈ {1, 2, …, l − 1},
```

![Equation](images/B9780443292385000160/si210.png) (10.17)

```
∇ᵧ(I)(i, j) := I(i, j + 1) − I(i, j),  ∀j ∈ {1, 2, …, l − 1},
```

![Equation](images/B9780443292385000160/si211.png) (10.18)

and the boundary conditions:

```
∇ₓ(I)(l, j) := ∇ᵧ(I)(i, l) := 0,  ∀i, j ∈ {1, 2, …, l − 1}.
```

![Equation](images/B9780443292385000160/si212.png) (10.19)

The **discrete gradient transform** $\nabla : \mathbb{R}^{(l \times l)} \to \mathbb{R}^{(l \times 2l)}$ is defined in matrix form as:

```
∇(I)(i, j) := [∇ₓ(i, j), ∇ᵧ(i, j)],  ∀i, j ∈ {1, 2, …, l}.
```
