
The task of channel equalization was introduced in [Fig. 4.12](#Chp004_119-175_B978044329238500010X.xhtml). The input to the equalizer is a stochastic process (random signal), which, according to the notational convention introduced in Section [2.4](#Chp002_19-64_B9780443292385000081.xhtml), will be denoted as `u[n]`. Note that upon receiving the noisy and distorted by the (communications) channel sample, `u[n]`, one has to obtain an estimate of the originally transmitted information sequence, `s[n]`, delayed by `L − 1` time lags, which accounts for the various delays imposed by the overall transmission system involved. Thus, at time `n`, the equalizer decides for `ŝ[n − L + 1]`. Ideally, if one knew the true values of the initially transmitted information sequence up to and including time instant `n − L`, represented by `s[n − L]`, `s[n − L − 1]`, `s[n − L − 2]…`, it could only be beneficial to use this information, together with the received sequence, `u[n]`, to recover an estimate of `ŝ[n − L + 1]`.
