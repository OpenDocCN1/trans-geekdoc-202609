
where `q(γ[k])(β[k])` are beta distributions with variational parameters `γ[k]`, the variational posterior estimates for the columns of `A` are Gaussians with parameters `Φ[k]` (i.e., means and covariance matrices), and `q(ν[nk])(z[nk])` are Bernoulli with parameters (probabilities) `ν[nk]`. Inference is carried out by maximizing the bound in Eq. [(12.68)](#Chp012_583-634_B9780443292385000184.xhtml). Note that if the sparse matrix is not binary, then it is replaced by `Z ∘ B` and the elements of `B` are also latent variables; different priors can be used depending on the task; for example, it can be Gaussian or Laplacian (see, e.g., [15,23]). In the latter reference, the alternative path to variational inference via Gibbs sampling techniques is discussed.

### Remarks 13.6

*   In analogy to CPR, which draws samples according to a DP, it can be shown that the IBP draws samples according to the so-called beta process [82,91].
*   By replacing the parameters `(α, 1)` in the beta distribution with the more general case `Beta(a, b)`, and changing their values, different distributions result. One such example is the so-called Pitman–Yor IBP. For such processes, the resulting probabilities decay in expectation following a power law; in contrast, in the IBP presented before, the decrease is exponentially fast (see, e.g., [64]).
*   Indian Buffet processes (IBPs) have been used in a number of applications where dimensionality reduction is involved, see, e.g., [23] for a related review. More recently, IBPs have been employed as priors in the design of deep neural networks, [42,59]. The number of nodes per layer is not preselected and it is left to the network to learn, during training, how many nodes are necessary. Initially, the number of nodes is assumed to be infinite (a large number). To this end, synaptic connections take the place of dishes, as the entities that are shared by the input nodes (customers), and the IBP is mobilized as a prior to impose the underlying sparsity. In this way, optimal pruning of the network is achieved.

## 13.12 Gaussian processes

In Section [13.11](#Chp013_635-716_B9780443292385000196.xhtml#s0100), the way to impose priors onto the model was similar in spirit with that used for parametric modeling techniques; that is, priors were imposed on the set of unknown parameters.
