
## 9.3 最小绝对收缩和选择算子（LASSO）

[图 9.2](#Chp009_417-462_B9780443292385000159.xhtml#f0015) 展示了 `|θ|^p` 的图形，即向量各分量对 `ℓ_p` 范数的单独贡献，针对不同的 `p` 值。观察可知：(a) 对于 `p < 1`，图形上方形成的区域（超图，见第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章）不是凸集，这验证了我们之前所说的，即相应函数不是真正的范数；(b) 对于自变量值 `|θ| > 1` 的情况，`p ≥ 1` 的值越大且 `|θ|` 的值越大，相应分量对范数的贡献就越高。因此，如果在正则化方法中使用 `ℓ_p` 范数（`p ≥ 1`），数值较大的分量会成为主导分量，优化算法将集中于这些分量，通过惩罚使其变小以便降低总代价。对于值 `|θ| < 1` 的情况则相反；`ℓ_p`、`p > 1` 范数倾向于将此类分量的贡献推向零。`ℓ_1` 范数是在 `p ≥ 1` 中唯一一个即使对于 `|θ| < 1` 的小值也能保持相对较大值的范数，因此，数值较小的分量仍能在优化过程中发挥作用，并可通过被推向更小的值而受到惩罚。因此，如果在公式 [(3.41)](#Chp003_65-117_B9780443292385000093.xhtml) 中用 `ℓ_1` 范数替代 `ℓ_2` 范数，*只有那些在正则化代价函数中真正对减小模型拟合误差测度项有显著贡献的参数向量分量会被保留，其余将被强制为零*。对于 `0 ≤ p < 1`，同样的趋势也存在，但更为激进。极端情况是考虑 `ℓ_0` 范数时。即使分量从零处的微小增加也会使其对范数的贡献变大，因此优化算法在使某元素非零时必须非常“谨慎”。

[图 9.2](#Chp009_417-462_B9780443292385000159.xhtml#cf0185) 观察到超图，即图形上方的区域，对于 `p < 1` 的值是非凸的，表明相应的 `|θ|^p` 函数是非凸的。`p = 1` 是保持凸性的最小值。还要注意，对于较大的 `p > 1` 值，`|θ| < 1` 的小值对相应范数的贡献变得微不足道。

简而言之，在所有真正的范数（`p ≥ 1`）中，`ℓ_1` 是唯一一个“尊重”小值的范数。其余 `p > 1` 的 `ℓ_p` 范数只是挤压小值使其变得更小，主要关注大值。我们马上会回到这一点。
