
## Kalman Filtering Algorithm Derivation

The updated covariance matrix is given by:

```
P[n|n] = P[n|n-1] - K[n]H[n]P[n|n-1]
```

The algorithm has now been derived. All that is now needed is to select the initial conditions, which are selected such that:

```
x̂_{1|0} = E[x_1]
```

```
P_{1|0} = E[(x_1 - x̂_{1|0})(x_1 - x̂_{1|0})^T] = Π_0
```

for some initial guess `Π_0`. The Kalman algorithm is summarized in **Algorithm 4.2**.
