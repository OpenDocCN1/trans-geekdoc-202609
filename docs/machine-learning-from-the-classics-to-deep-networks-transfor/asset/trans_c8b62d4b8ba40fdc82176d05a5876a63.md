

将公式 [(7.93)](#Chp007_293-342_B9780443292385000135.xhtml#deq141) 和 [(7.94)](#Chp007_293-342_B9780443292385000135.xhtml#deq142) 与公式 [(7.88)](#Chp007_293-342_B9780443292385000135.xhtml#deq136) 和 [(7.90)](#Chp007_293-342_B9780443292385000135.xhtml#deq138) 相结合，可轻易证明

```
a_i = \arg\min_a \left\{ \exp(-a)(1 - P_i) + \exp(a)P_i \right\}.
```

对 `a` 求导并令其为零，可得

```
a_i = \frac{1}{2}\ln\frac{1 - P_i}{P_i}.
```

注意，如果 `P[i] < 0.5`，则 `a[i] > 0`，这在实践中是预期的情况。一旦估计出 `a[i]` 和 `θ[i]`，下一次迭代的权重即可通过以下公式轻易给出

```
w_n^{(i + 1)} = \frac{\exp(-y_n F_i(\mathbf{x}_n))}{Z_i} = \frac{w_n^{(i)}\exp(-y_n a_i \phi(\mathbf{x}_n; \mathbf{\theta}_i))}{Z_i},
```

其中 `Z[i]` 为归一化因子。
