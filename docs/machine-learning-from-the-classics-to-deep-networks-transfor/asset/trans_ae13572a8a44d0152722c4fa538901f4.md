

$$
\widehat{\theta}_b(\lambda) = \frac{1}{N + \lambda}\sum_{n=1}^{N}y_n = \frac{N}{N + \lambda}\widehat{\theta}_{\text{MVU}},
$$

![Equation](images/B9780443292385000093/si227.png)

其中我们显式地表达了估计值 $\widehat{\theta}_b$ 对正则化参数 $\lambda$ 的依赖关系。注意对于相关的估计器，我们有 $\mathbb{E}[\widehat{\theta}_b(\lambda)] = \frac{N}{N + \lambda}\theta_o$。

简单审视前面的关系式，会让我们回到与公式 [(3.24)](#Chp003_65-117_B9780443292385000093.xhtml#deq43) 相关的讨论。确实，通过遵循类似于第 [3.5.1](#Chp003_65-117_B9780443292385000093.xhtml#s0040) 节中的一系列步骤，可以验证（见问题 [3.12](#Chp003_65-117_B9780443292385000093.xhtml#o0065)）$\text{MSE}(\widehat{\theta}_b)$ 的最小值为

$$
\text{MSE}\left( \widehat{\theta}_b(\lambda_*) \right) = \frac{\frac{\sigma_\eta^2}{N}}{1 + \frac{\sigma_\eta^2}{N\theta_o^2}} < \frac{\sigma_\eta^2}{N} = \text{MSE}\left( \widehat{\theta}_{\text{MVU}} \right),
$$

![Equation](images/B9780443292385000093/si230.png)(3.45)

该值在 $\lambda_* = \sigma_\eta^2 / \theta_o^2$ 处取得。因此，关于岭回归估计器是否能改善 MSE 性能的问题，在当前背景下答案是肯定的。事实上，*总是*存在一个 $\lambda > 0$，使得求解公式 [(3.41)](#Chp003_65-117_B9780443292385000093.xhtml#deq74) 一般任务的岭回归估计器，能够实现比 MVU 估计器 [5, Section 8.4] 更低的 MSE。
