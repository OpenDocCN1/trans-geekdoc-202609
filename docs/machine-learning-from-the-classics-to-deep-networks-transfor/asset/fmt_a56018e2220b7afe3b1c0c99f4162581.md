
### KKT 条件与对偶问题

$$
\frac{\partial L}{\partial\theta_{0}} = 0\ \longrightarrow\sum\limits_{n = 1}^{N}\lambda_{n}y_{n} = 0,
$$

![Equation](images/B9780443292385000172/si386.png)(11.81)

$$
\frac{\partial L}{\partial\xi_{n}} = 0\ \longrightarrow\ C - \mu_{n} - \lambda_{n} = 0,
$$

![Equation](images/B9780443292385000172/si387.png)(11.82)

$$
\lambda_{n}(y_{n}(\boldsymbol{\theta}^{T}\boldsymbol{x}_{n}+\theta_{0})-1+\xi_{n}) = 0,\ n = 1, 2, \dots, N,
$$

![Equation](images/B9780443292385000172/si388.png)(11.83)

$$
\mu_{n}\xi_{n} = 0,\ n = 1, 2, \dots, N,
$$

![Equation](images/B9780443292385000172/si389.png)(11.84)

$$
\mu_{n} \ge 0,\ \lambda_{n} \ge 0,\ n = 1, 2, \dots, N,
$$

![Equation](images/B9780443292385000172/si390.png)(11.85)

按照我们熟悉的步骤，对偶问题表述为：

$$
\text{maximize with respect to}\ \boldsymbol{\lambda}\quad\sum\limits_{n = 1}^{N}\lambda_{n} - \frac{1}{2}\sum\limits_{n = 1}^{N}\sum\limits_{m = 1}^{N}\lambda_{n}\lambda_{m}y_{n}y_{m}\boldsymbol{x}_{n}^{T}\boldsymbol{x}_{m}
$$

![Equation](images/B9780443292385000172/si391.png)(11.86)

subject to $0 \le \lambda_{n} \le C,\ n = 1, 2, \dots, N$,
