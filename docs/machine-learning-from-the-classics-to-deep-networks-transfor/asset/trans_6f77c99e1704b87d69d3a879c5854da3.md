
我们已经在岭回归的背景下，于第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中讨论过，将偏置项包含在正则化范数中并非良好的做法，因为这会影响估计量的平移不变性。一种更合理的正则化方式是从范数中移除偏置项。尽管这种简单类型的正则化有助于提升网络的泛化性能，且在某些情况下可能已足够，但总体而言，它并非最合适的方法。

除了平方欧几里得范数，还可以在公式 [(18.47)](#Chp018_885-995_B978044329238500024X.xhtml#deq89) 中使用其他范数。例如，一种替代方案是采用 `ℓ₁` 范数。从第 [9](#Chp009_417-462_B9780443292385000159.xhtml) 章我们知道，后一种范数能促进稀疏性。在训练大型网络时，这是一个受欢迎的特性，因为它可以将信息量较小的参数推向零。

多年来，人们提出了应用正则化代价函数的各种场景。一种场景是将每一层的所有参数（不包括偏置）分组，并应用公式 [(18.47)](#Chp018_885-995_B978044329238500024X.xhtml#deq89)，为每个组使用不同的正则化常数。另一种场景是单独处理每个神经元的参数。另一条路径是将正则化视为将范数约束为小于一个预选值（第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章）。这被证明等价于在与该范数相关的球体上进行投影步骤，例如 `ℓ₂` 球（见第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章），从而导致一个归一化操作（见 [74]）。

### 权重消除

除了使用权重的范数，另一种方法涉及将更一般的函数用于正则化项，即：

```
J′(θ) = J(θ) + λh(θ).
```

例如，文献 [213] 使用了以下函数：

```
h(θ) = ∑_{k=1}^{K} θ_k² / (θ_h² + θ_k²),
```

其中 `K` 是所涉及参数的总数，`θ_h` 是一个预选的阈值。仔细观察该函数可知，若 `θ_k < θ_h`，惩罚项会迅速趋近于零。相反，对于 `θ_k > θ_h` 的值，惩罚项趋向于 1。通过这种方式，不太重要的权重被推向零。该方法也出现了许多变体（见例如 [173]）。
