
Note that using the Bayesian framework, the computation of the latent variables corresponding to a given set of observations, `x`, can naturally be obtained via the posterior `p(z|x)` in Eq. [(20.84)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq123). For example, one can pick the respective mean value

```
z = (1/σ²) Σ_{z|x} A^T x.
```

Using the matrix inversion lemma ([Problem 20.4](#Chp020_1103-1179_B9780443292385000263.xhtml#o0090)), it turns out that Eqs. [(20.83)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq120) and [(20.89)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq128) are exactly the same; however, now, it comes as a natural consequence of our Bayesian assumptions.

One way to compute `A` is to apply the maximum likelihood method on `∏_{n=1}^N p(x_n)` and maximize with regard to `A` and `σ²` (and `μ`, if `μ ≠ 0`). It turns out that the maximum likelihood solution for `A` is given by [175]

```
A_ML = U_m diag{λ_1−σ²,…,λ_m−σ²} R,
```

where `U_m` is the `l × m` matrix with columns the eigenvectors that correspond to the `m` largest eigenvalues, `λ_i`, `i = 1, 2, …, m`, of the sample covariance matrix of `x`, and `R` is an arbitrary orthogonal matrix (`R R^T = I`). Setting `R = I`, the columns of `A` are the (scaled) principal directions as computed by the classical PCA, discussed in Section [20.3](#Chp020_1103-1179_B9780443292385000263.xhtml#s0020). In any case, the columns of `A` span the principal subspace of the standard PCA. Note that as `σ² → 0`, PPCA tends to PCA ([Problem 20.5](#Chp020_1103-1179_B9780443292385000263.xhtml#o0095)). Also, it turns out that

```
σ_ML² = (1/(l - m)) ∑_{i=m+1}^l λ_i.
```
