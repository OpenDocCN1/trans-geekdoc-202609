

## Boosting 的多类推广与正则化

*   文献 [13, 15] 提出了 Boosting 方案的多类推广。文献 [10] 推导了 AdaBoost 方案的正则化版本，以施加稀疏性。考虑了不同的正则化方案，包括 `ℓ₁`、`ℓ₂` 和 `ℓ∞`。最终结果是一族坐标下降算法，它们融合了前向特征诱导和后向剪枝。文献 [33] 提出了一个引入先验知识的版本。所谓的 `AdaBoost*ν*` 在文献 [29] 中被引入，其中显式地考虑了边界。

*   请注意，Boosting 的基本原理同样可以很好地应用于涉及相应损失函数的回归任务，例如平方误差损失函数。平方误差的一个鲁棒替代方案是绝对误差损失函数 [16]。

*   Boosting 技术吸引了该领域研究人员的极大关注，旨在解释其在实践中的良好表现及其相对免疫过拟合的特性。尽管训练误差可能变为零，但这仍不一定意味着发生了过拟合。首次尝试的解释是基于关于相应泛化性能的界限。推导出的界限与迭代次数 `K` 无关，并用边界来表示 [32]。然而，这些界限往往非常宽松。另一种解释可能在于这样一个事实：每次优化仅针对单组参数进行。感兴趣的读者可参考文献 [4, 6, 15] 之后的讨论，这对理解该问题非常有启发。

## 示例 7.5

考虑一个 20 维的二分类任务。第一类（`ω₁`）的数据点源自两个高斯分布之一，其均值分别为 `μ₁₁ = [0, 0, …, 0]ᵀ`、`μ₁₂ = [1, 1, …, 1]ᵀ`，而第二类（`ω₂`）的数据点源自均值为 `μ₂ = [0, …, 0, 1, …, 1]ᵀ`（10 个零后跟 10 个一）的高斯分布。所有分布的协方差矩阵均等于 20 维单位矩阵。训练集和测试集各包含 300 个点，其中 200 个来自 `ω₁`（每个分布 100 个），100 个来自 `ω₂`。

对于 AdaBoost，基分类器选为 `stump`（桩分类器/决策树桩）。这是一种非常朴素的树类型，仅包含一个节点，特征向量 `x` 的分类仅基于其某一个特征的值，例如 `xᵢ`。因此，若 `xᵢ < a`，其中 `a` 为合适的阈值，则 `x` 被归为 `ω₁` 类。若 `xᵢ > a`，则归为 `ω₂` 类。关于在分类器中使用哪个特定特征 `xᵢ` 的选择是随机进行的。这种分类器产生的训练错误率略优于 0.5。AdaBoost 算法在训练数据上运行了 2000 步迭代。[图 7.15](#Chp007_293-342_B9780443292385000135.xhtml#f0090) 验证了训练错误率极快地收敛到零这一事实。即使训练错误率变为零后，测试错误率仍持续下降，随后在 0.15 左右趋于稳定。
