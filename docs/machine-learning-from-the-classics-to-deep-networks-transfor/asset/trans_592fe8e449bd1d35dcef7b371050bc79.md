
出于建模目的，我们将每个观测值 `y[n]` 与一个潜在变量 `k[n] = 1, 2, …, K` 相关联，该变量是一个（随机）索引，指示生成相应观测向量的子系统/子过程。我们将其称为*状态*。每个 `k[n]` 对应于通用模型中的 `x[n]`。完整观测集序列 `(y[n], k[n])`，`n = 1, 2, …, N`，在一个二维网格中形成一条轨迹，其中一轴为状态，另一轴为观测值。图 [16.16](#Chp016_805-853_B9780443292385000226.xhtml#f0085) 展示了 `K = 3` 时的情况。这样的路径揭示了每个观测值的来源；`y[1]` 由状态 `k[1] = 1` 发射，`y[2]` 由 `k[2] = 2` 发射，`y[3]` 由 `k[3] = 2` 发射，而 `y[N]` 由 `k[N] = 3` 发射。请注意，每条轨迹都与一个概率分布相关联，即完整集合的联合分布。确实，图 [16.16](#Chp016_805-853_B9780443292385000226.xhtml#f0085) 所示轨迹发生的概率取决于 `P((y[1], k[1]=1), (y[2], k[2]=2), (y[3], k[3]=2), …, (y[N], k[N]=3))` 的值。我们很快就会看到，网格中可以绘制的某些可能轨迹在实践中是不允许的；这可能是由于与相关系统/过程相关的数据生成机制的物理约束所致。
