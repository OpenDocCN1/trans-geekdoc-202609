

其中 `g[k] = ℒ[k]'(θ[k − 1])` 表示时刻 `k` 处的次梯度。此外，使用同一矩阵来加权梯度修正，该方案具有如下形式：

```
θ[n] = P[C](G[n]^(1/2))(θ[n − 1] − μ[n]G[n]^(−1/2)g[n])。
```

使用（时变）加权矩阵考虑了早期迭代中观测到的数据几何特性，从而实现了更具信息量的基于梯度的学习。为了节省计算量，`G[n]` 的结构被设为对角形式。文献 [38] 讨论了不同的算法设置，并研究了该算法的收敛性质。该算法启发了许多当前深度学习中流行的版本，另请参阅第 [18.4.2](#Chp018_885-995_B978044329238500024X.xhtml) 节。

### 示例 8.8：LMS 算法

假设

```
ℒ_n(θ) = 1/2 (y_n − θ^T x_n)^2，
```

并设定 `C = ℝ^(l)` 和 `μ[n] = μ`。则公式 [(8.69)](#Chp008_343-416_B9780443292385000147.xhtml#deq144) 变为我们熟悉的 LMS 递推公式：

```
θ[n] = θ[n − 1] + μ(y[n] − θ[n − 1]^T x[n])x[n]，
```

其收敛性质已在第 [5](#Chp005_177-248_B9780443292385000111.xhtml) 章中讨论。
