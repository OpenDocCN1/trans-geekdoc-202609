## 4.5 线性滤波

线性统计滤波是通用估计任务的一个实例，当需要考虑时间演化的概念，并在每个时间瞬间获得估计值时。会出现三类主要问题：

*   **滤波**，其中时间瞬间 `n` 的估计基于所有先前接收（测量）到的输入信息，*直到并包括*当前时间索引 `n`。
*   **平滑**，其中首先收集离散时间集合 `{0, 1, …, N}` 上的数据，并利用时间索引集合 `{0, 1, …, N}` 对应的*所有*可用信息，在每个时间瞬间 `n ≤ N` 获得估计值。
*   **预测**，其中基于直到并包括时间瞬间 `n` 的信息，获得时刻 `n + τ, τ > 0` 的估计值。

为了使上述定义更贴合本章迄今为止所述内容，以时变情况为例，其中时间瞬间 `n` 的输出变量为 `y[n]`，其值取决于相应输入向量 `x[n]` 中包含的观测值。在滤波中，后者只能包含在时间瞬间 `n, n − 1, …, 0` 接收到的观测值。这种索引集合的限制直接与*因果性*相关。相反，在平滑中，除了过去时刻外，还包含未来时刻，即 `…, n + 2, n + 1, n, n − 1, …`。

本书的大部分精力将花在涉及时间信息时的滤波上。原因在于这是最常遇到的任务，而且用于平滑和预测的技术在本质上与滤波相似，通常只需微小修改。

在信号处理中，滤波一词通常用于更具体的语境，指*滤波器*的操作，它作用于输入随机过程/信号（`u[n]`），将其转换为另一个过程（`d[n]`）；参见第 [2.4.3](#Chp002_19-64_B9780443292385000081.xhtml) 节。注意，我们已切换为第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章引入的、用于表示随机过程的符号。我们倾向于对随机过程和随机变量保持不同的符号，因为对于随机过程，滤波任务获得了特殊的结构和性质，正如我们即将看到的。此外，尽管两种情况下涉及的方程数学表述最终可能相同，但我们认为让读者记住生成数据的底层机制是不同的，这是有益的。
