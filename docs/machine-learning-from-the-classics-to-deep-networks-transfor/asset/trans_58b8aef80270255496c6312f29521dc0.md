
其中，`v[k]^⊥(n)` 是破坏单位范数垂直方向向量 `g[k]^⊥` 的噪声，而 `v[k]^∥(n)` 是发生在平行方向向量上的噪声。考虑到噪声项，公式 [(5.101)](#Chp005_177-248_B9780443292385000111.xhtml#deq219) 可写为

```
r̂_k(n) = ĝ_k^T(n)(θ_o − θ_k) + η_k(n),
```
(5.103)

其中

```
η_k(n) = v_k(n) − v_k^⊥(n)g_k^(⊥T)(θ_o − θ_k) − v_k^∥(n)g_k^(T)(θ_o − θ_k).
```
(5.104)

如果回顾到根据构造 `g_k^(⊥T)(θ_o − θ_k) = 0`，公式 [(5.104)](#Chp005_177-248_B9780443292385000111.xhtml#deq222) 可进一步简化。此外，通常假设 `v_k^⊥(n)` 的贡献显著大于 `v_k^∥(n)` 的贡献。因此，考虑到这两点，公式 [(5.104)](#Chp005_177-248_B9780443292385000111.xhtml#deq222) 可简化为

```
η_k(n) ≈ v_k(n).
```
(5.105)
