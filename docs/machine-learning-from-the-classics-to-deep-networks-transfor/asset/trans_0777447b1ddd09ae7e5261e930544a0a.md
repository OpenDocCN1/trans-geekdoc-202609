
其次，真实信号的估计计算为 $\widehat{\mathbf{y}} = \Psi\widehat{\mathbf{\theta}}$。在第 [20](#Chp020_1103-1179_B9780443292385000263.xhtml) 章中，我们将研究字典并非固定且已知，而是从数据中估计得到的情况。

*   **线性逆问题**：此类问题属于更广泛的*信号恢复*范畴，比去噪更进一步。现在，可用的观测值不仅包含噪声，还是真实信号样本的*失真*版本；即 $\mathbf{y} = H\widetilde{\mathbf{y}} + \mathbf{\eta}$，其中 *H* 是一个已知的线性算子。例如，*H* 可能对应图像的模糊点扩散函数，如第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章所述。然后，类似于去噪示例，假设原始信号样本可以用过完备字典高效表示，则通过任意稀疏性促进方法，利用 *H*Ψ 代替 [(9.41)](#Chp009_417-462_B9780443292385000159.xhtml#deq81) 中的 Ψ 来估计 $\widehat{\mathbf{\theta}}$，并得到真实信号的估计为 $\widehat{\mathbf{y}} = \Psi\widehat{\mathbf{\theta}}$。

*   除了去模糊，属于此公式化范畴的其他应用还包括图像修复（如果 *H* 代表相应的采样掩码）、断层扫描中的逆拉东变换（如果 *H* 包含平行投影集合）等。更多细节请参见例如文献 [49]。

在本案例研究中，探讨了基于上述稀疏冗余公式化的图像去噪任务。我们的出发点是 [图 9.13](#Chp009_417-462_B9780443292385000159.xhtml#f0075)A 所示的 256 × 256 图像。随后，图像被零均值高斯噪声污染，导致 [图 9.13](#Chp009_417-462_B9780443292385000159.xhtml#f0075)B 所示的含噪版本，对应的峰值信噪比 (PSNR) 等于 22 dB，其定义为

```
PSNR = 20 log_10 ( m_I / sqrt(MSE) ),
```
(9.42)

其中 *m*[*I*] 是图像的最大像素值，`MSE = (1/N_p) || I - Ĩ ||_F^2`，其中 *I* 和 *Ĩ* 分别是含噪和原始图像矩阵，*N*[*p*] 等于像素总数，并采用了矩阵的 Frobenius 范数。
