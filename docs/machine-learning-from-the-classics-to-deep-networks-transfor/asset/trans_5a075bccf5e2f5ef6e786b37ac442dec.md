
这既不涉及矩阵求逆，同时又能改善收敛性。对该问题的更详细处理超出了本书的范围。仅为对数学感兴趣的读者深入钻研该领域提供一点激励，只需说明：我们熟悉的梯度，即公式 [(20.56)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq77)，若空间是欧氏空间，则指向最陡上升方向。然而，在我们的情况下，参数空间由所有非奇异的 *l* × *l* 矩阵组成，这是一个乘法群。该空间是黎曼空间，结果表明，指向最陡上升方向的自然梯度，是通过将公式 [(20.56)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq77) 中的梯度乘以 *W*^(*T*)*W* 得到的，后者是相应的黎曼度量张量 [68]。

## 备注 20.4

*   • 从公式 [(20.56)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq77) 中的梯度可以很容易地看出，在驻点处以下关系成立：

```
∂J(W)/∂W * W^T = E[I - φ(z)z^T] = O.
```

*   换句话说，我们用 ICA 实现的是 PCA 的*非线性推广*。回想一下，对于后者，不相关性条件可以写为

```
E[I - zz^T] = O.
```

*   *非线性*函数 **φ** 的存在使我们超越了简单的不相关性，并引入了累积量。事实上，公式 [(20.61)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq84) 正是启发 ICA 早期开创性工作的公式，作为 PCA 的直接非线性推广 [93,107]。

*   • ICA 的起源可追溯到开创性论文 [93]。多年来，它主要局限于法国信号处理和统计学界。两篇论文对其广泛应用和普及起到了催化作用，即 1990 年代中期的 [18] 以及 `FastICA` 的开发^([^(157)](#fn157))。

*   • 在机器学习中，将 ICA 用作特征生成技术的理由基于以下论点。文献 [17] 指出，视觉皮层特征检测器执行的早期处理结果可能是*冗余度降低*过程的结果。因此，在给定输入数据的条件下寻找独立特征，符合这一主张（参见，例如，[75,114] 及其参考文献）。

*   • 虽然我们专注于无噪声情况，但 ICA 向有噪声任务的扩展也已被提出（参见，例如，[100]）。关于复值情况下 ICA 的扩展，请参见 [2]。非线性扩展也已被考虑，包括核化 ICA 版本（例如，[13]）。

*   • 在文献 [3] 中，ICA 的处理也涉及随机过程，可以识别包括高斯信号在内的更广泛的信号类别。

*   • 在文献 [7] 中，讨论了*独立向量分析*（IVA）的多集 ICA 框架。结果表明，如果考虑二阶以外的高阶统计量，它推广了多集 CCA。

### 20.5.5 ICA 的替代路径

除了前面讨论的两条 ICA 路径外，还提出了许多替代方案，从不同方面阐释了该问题。一些值得注意的方向如下。

*   • *Infomax 原理*：该方法假设潜在变量是以下形式的非线性系统（神经网络，第 [18](#Chp018_885-995_B978044329238500024X.xhtml) 章）的输出

```
z[i] = φ[i](w[i]^T x) + η,  i = 1, 2, …, l,
```

*   其中 `φ[i]` 为非线性函数，`η` 为加性高斯噪声。权重向量 `w[i]` 的计算旨在最大化输出的熵；其推理基于关于网络中信息流动的一些信息论论据 [18]。
