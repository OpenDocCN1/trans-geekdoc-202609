
图 9.11 模拟信号 `s(t)` 的傅里叶变换，该信号在频域中是稀疏的；只有有限数量的频段对其频谱内容 `S(Ω)` 有贡献，其中 Ω 代表角频率。奈奎斯特理论保证，以大于或等于最大 `Ω[max]` 两倍的频率进行采样，足以恢复原始模拟信号。然而，该理论并未利用与信号在频域中稀疏结构相关的信息。

以低于奈奎斯特速率对模拟信号进行采样的过程被称为*模拟到信息*采样或*亚奈奎斯特*采样。让我们重点关注两种最流行的基于 CS 的 A/D 转换器。第一种是*随机解调器*（RD），它首次见于文献 [58]，随后在文献 [91] 中得到了改进和理论发展。RD 的基本配置如[图 9.10](#Chp009_417-462_B9780443292385000159.xhtml#f0060)所示，它旨在以亚奈奎斯特速率获取稀疏多音信号，即具有稀疏 DFT 的信号。这意味着信号包含少数频率分量，但这些分量被限制为对应于整数频率。文献 [91] 指出了这一局限性，并根据文献 [24] 提出的通用框架和/或文献 [45] 描述的启发式方法寻求了潜在解决方案。此外，更精细的 RD 设计，如*随机调制预积分器*（RMPI）[102]，有潜力处理在任意域中稀疏的信号。

另一种备受关注的基于 CS 的亚奈奎斯特采样策略是*调制宽带转换器*（MWC）[68,69,71]。MWC 在获取如[图 9.11](#Chp009_417-462_B9780443292385000159.xhtml#f0065)所示的多频带信号方面非常高效。这一概念也已扩展以适应具有不同特性的信号，例如由短脉冲组成的信号[66]。文献 [59] 中的深入研究揭示了 RD 和 MWC 采样架构之间的异同。

请注意，RD 和 MWC 均在时间上对信号进行均匀采样。文献 [97] 采用了一种不同的方法，从而实现了更容易的实现。具体而言，避免了预处理阶段，并直接从原始信号中获取在时间上非均匀分布的样本。总共获得的样本比奈奎斯特采样少。然后调用基于 CS 的重构，根据样本值和时间信息来恢复所考虑的信号。与基本 RD 情况一样，非均匀采样方法适用于在 DFT 基下稀疏的信号。从实际角度来看，仍存在许多与硬件实现相关的问题或多或少地涉及上述所有方法，并有待解决（参见例如 [9,25,63]）。

亚奈奎斯特采样的另一条途径涉及一类不同的模拟信号，称为*多脉冲*信号，即由一串短脉冲组成的信号。稀疏性现在指的是时域，此类信号甚至可能不是带限的。这类信号可在许多应用中遇到，如雷达、超声、生物成像和神经信号处理（参见例如 [41]）。一种称为*有限创新率采样*的方法，将具有每秒 `k` 个自由度的模拟信号通过一个线性时不变滤波器，然后以每秒 `2*k` 个样本的速率进行采样。重构是通过求解高阶多项式的根来执行的（参见例如 [12,95] 及其参考文献）。文献 [66] 利用 CS 理论论点和 Gabor 函数展开来处理亚奈奎斯特采样任务；假设信号由少数持续时间有限但形状和时间位置未知的脉冲之和组成。更多相关内容可参见 [43,51,70] 及其参考文献。

### 示例 9.5

我们得到一组 `N = 20` 个观测值，堆叠在向量 `y ∈ ℝ^(N)` 中。这些观测值是通过将感知矩阵 `X` 作用于 `ℝ^(50)` 中的一个“未知”向量而获得的，该向量已知是稀疏的，具有 `k = 5` 个非零分量；这些非零分量在未知向量中的位置未知。感知矩阵是一个随机矩阵，其元素服从正态分布 `𝒩(0, 1)`，随后列向量被归一化为单位范数。观测值有两种场景。在第一种场景中，我们获得其精确值；而在第二种场景中，加入了方差为 `σ² = 0.025` 的白高斯噪声。

为了恢复未知稀疏向量，在两种场景下均使用了 CS 匹配追踪（CoSaMP，第 [10](#Chp010_463-518_B9780443292385000160.xhtml) 章）算法。
