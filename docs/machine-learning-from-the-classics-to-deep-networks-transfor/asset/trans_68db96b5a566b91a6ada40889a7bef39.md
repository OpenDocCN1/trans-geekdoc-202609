
参考[图 12.12](#Chp012_583-634_B9780443292385000184.xhtml#f0080)，门控权重是门控网络的输出，门控网络也由与专家相同的输入激励。在神经网络语境下，正如我们将在第 [18](#Chp018_885-995_B978044329238500024X.xhtml) 章中看到的，我们可以将门控网络视为一个神经网络，其激活函数由公式 [(12.105)](#Chp012_583-634_B9780443292385000184.xhtml#deq148) 给出，这被称为 `softmax` 激活 [5]。注意，公式 [(12.105)](#Chp012_583-634_B9780443292385000184.xhtml#deq148) 的形式与多类别逻辑回归中使用的公式 [(7.47)](#Chp007_293-342_B9780443292385000135.xhtml) 完全相同。在此设定下，公式 [(12.99)](#Chp012_583-634_B9780443292385000184.xhtml#deq138) 中的 `P[k]` 被 `P[k](x)` 替代，相应的 M 步变得等价于关于 `w[k]` 的优化，`k = 1, 2, …, K`。我们有

```
Q(Ξ, P; Ξ^(j), P^(j)) = ∑_{n=1}^N ∑_{k=1}^K γ_{nk} ln P_k(x) + C_3.
```

观察可知，公式 [(12.106)](#Chp012_583-634_B9780443292385000184.xhtml#deq149) 的形式与多类别逻辑回归中使用的公式 [(7.49)](#Chp007_293-342_B9780443292385000135.xhtml) 相同，优化遵循类似的步骤（另见例如 [19]）。

专家混合模型已被用于许多应用，一个典型应用是逆问题，即从输出推断输入。然而，在许多情况下，这是一对多任务，专家混合模型有助于对这些“多个”选项中的选择进行建模。例如，在文献 [4] 中，专家混合模型被用于视频记录中的人员跟踪，由于遮挡，从图像到姿态的映射不是唯一的。

#### 分层专家混合模型

专家混合模型概念的一个直接推广是以分层方式增加更多层级的门控函数，从而产生所谓的 `分层专家混合模型` (HME)。这一思想在[图 12.13](#Chp012_583-634_B9780443292385000184.xhtml#f0085) 的框图中得到了说明。这种架构类似于树结构，专家作为叶节点，门控网络作为非终端节点，输出（求和）节点作为根节点。分层专家混合模型将空间划分为一组嵌套区域，在分层放置的门控网络控制下，专家之间的信息得以组合。这种层级结构符合更一般的“分而治之”策略思想。

![图 12.13 具有两层层级的分层专家混合模型框图。](images/B9780443292385000184/gr013.jpg)

[图 12.13](#Chp012_583-634_B9780443292385000184.xhtml#cf1170) 具有两层层级的分层专家混合模型框图。

与决策树相比，HME 围绕软决策规则演化，这与 CART 中采用的硬决策规则形成对比。硬决策通常会导致信息丢失。一旦做出决策，以后就无法更改。相反，软决策规则赋予网络保留信息的优势，直到做出最终决策。例如，根据硬决策规则，如果一个样本位于靠近决策面的位置，它将根据其所在一侧的标签进行标记。然而，在软决策规则中，与该点相对于决策面的位置相关的信息将被保留，直到必须做出最终决策的阶段，此时会考虑到随着处理过程发展而变得可用的更多信息。

注意，专家混合模型的训练也可以通过另一条路径进行，即通过优化代价函数，而无需采用概率论证（另见例如 [19]）。
