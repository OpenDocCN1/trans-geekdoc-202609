

# 主成分分析中的潜变量建模

## 数学基础

矩阵 `A` 定义为前 `m` 个主成分向量的集合：

`A = [u[1], …, u[m]] := U[m]`

模型表明 `x` 的每个 `l` 个分量都可以（近似地）由这 `m` 个相互不相关的潜在随机变量生成：

`x[i] ≈ u[i1]z[1] + … + u[im]z[m]`

## 线性潜变量建模

在线性潜变量建模中，我们也可以假设潜在变量可以通过线性模型从原始随机变量中恢复，例如：

`z = Wx`

在 PCA 方法中，我们已经看到：

`W = U[m]^(T)`

公式 [(20.17)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq22) 和 [(20.19)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq25) 构成了本章的骨干，不同的方法为计算 `A` 或 `W` 提供了不同的解决方案。

## 分数矩阵

现在让我们收集所有的主成分分数向量 `z[n]`，`n = 1, 2, …, N`，作为 `m × N` 分数矩阵 `Z` 的列：

`Z := [z[1], …, z[N]]`

然后公式 [(20.10)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq11) 可以用分数矩阵重写：


## 备注 20.1

*   **选择主导特征值**：实践中的一个主要问题是选择 `m` 个主导特征值。一种方法是按降序排列它们，并确定 `m` 使得 `λ[m]` 和 `λ[m + 1]` 之间的间隙“较大”。有兴趣的读者可参考文献 [55, 104] 了解更多相关内容。

*   **中心化处理**：到目前为止的处理涉及中心化量。如果我们想通过考虑数据集的相应均值来近似原始观测向量，公式 [(20.13)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq15) 可以重述为：

```
x̂ = x̄ + Σ(i=1 to m) u[i]^T (x - x̄) u[i]
```
(20.23)

*   其中 `x̄` 是样本均值（如果已知则为均值）。
