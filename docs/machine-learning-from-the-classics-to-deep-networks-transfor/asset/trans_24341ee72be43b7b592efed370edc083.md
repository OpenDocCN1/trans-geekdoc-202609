
# 维廷格微积分

设 $f: \mathbb{C} \mapsto \mathbb{C}$ 为定义在 $\mathbb{C}$ 上的复函数。显然，此类函数既可视为定义在 $\mathbb{R}^2$ 上，也可视为定义在 $\mathbb{C}$ 上（即 $f(z) = f(x + jy) = f(x, y)$）。此外，它既可视为复值函数 $f(x, y) = f_r(x, y) + j f_i(x, y)$，也可视为向量值函数 $f(x, y) = (f_r(x,y), f_i(x,y))$。若 $f_r$ 和 $f_i$ 均可微，则称 $f$ 在*实数意义上可微*。维廷格微积分考虑了 $f$ 的复数结构，并用一种等价表述来描述实导数，这极大地简化了计算；而且，这种表述与复导数有着惊人的相似性。

为应用维廷格导数，采用以下简单的*技巧*：

*   用 $z$ 和 $z^*$ 表达函数 $f$；
*   计算 W-导数时，应用常规求导法则，将 $z^*$ 视为常数；
*   计算 CW-导数时，应用常规求导法则，将 $z$ 视为常数。

必须强调的是，所有这些陈述都应被视为有用的计算技巧，而非严格的数学法则。类似的定义和性质也适用于复向量 $\mathbf{z}$，若将偏导数替换为偏梯度 $\nabla_{\mathbf{x}}, \nabla_{\mathbf{y}}$，则可从相应定义中得到 W-梯度和 CW-梯度：
