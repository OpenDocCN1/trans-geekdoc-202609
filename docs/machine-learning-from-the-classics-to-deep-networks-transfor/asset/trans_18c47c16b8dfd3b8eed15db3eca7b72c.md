
其中 `η` 表示涉及的噪声变量集合。请注意，这种模型涵盖了我们熟悉的回归任务的情况，其中未知参数 `θ` 被视为随机变量，这符合贝叶斯哲学，正如第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章所讨论的那样。我们再次假设均值向量为零；否则，减去相应的均值。`y` (`η`) 和 `θ` 的维度不一定相同；为了与第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章使用的符号保持一致，设 `y`, `η` ∈ ℝ^N 和 `θ` ∈ ℝ^l。因此，`X` 是一个 `N` × `l` 矩阵。请注意，矩阵 `X` 被视为确定性的，而非随机的。

假设我们的零均值变量的协方差矩阵，

```
Σ[θ] = 𝔼[θθ^T],  Σ[η] = 𝔼[ηη^T],
```

是已知的。目标是计算一个维度为 `l` × `N` 的矩阵 `H`，使得线性估计器

```
θ̂ = Hy
```
(4.83)

使均方误差 (MSE) 代价函数最小化

```
J(H) := 𝔼[(θ - θ̂)^T(θ - θ̂)] = Σ_{i=1}^l 𝔼[(θ_i - θ̂_i)^2].
```
(4.84)

请注意，这是一个*多通道*估计任务，它等价于求解 `l` 个优化任务，每个任务对应 `θ` 的一个分量 `θ[i]`。将误差向量定义为

```
ε := θ - θ̂,
```

代价函数等于相应*误差协方差矩阵*的迹，因此

```
J(H) := trace {𝔼[εε^T]}.
```
