
我们可以认为每个节点 $x_i$ (a) 从其右侧接收一条消息 $\mu_b(x_i)$，在我们的例子中该消息包含 $K$ 个值；(b) 在本地执行求和-乘法运算，并计算出一条新消息 $\mu_b(x_{i-1})$；(c) 将其传递给左侧的节点 $x_{i-1}$。$\mu_b$ 中的下标“$b$”代表“backward”（向后），用于提醒我们消息传递活动是从右向左流动的。

项 $\mu_b(x_j)$ 是对 $x_{j+1}, x_{j+2}, \dots, x_l$ 求积后求和的结果，而项 $\mu_f(x_j)$ 则是对 $x_1, x_2, \dots, x_{j-1}$ 求积后求和的结果。在每个迭代步骤中，通过对一个变量的所有可能值求和，该变量被*消除*。遵循类似的论证可以很容易地证明，任意位置 $x_j$ ($2 \le j \le l-1$) 处的边缘分布由以下公式获得（问题 [15.13](#Chp015_755-803_B9780443292385000214.xhtml#o0105)）：

$$P(x_{j}) = \frac{1}{Z}\mu_{f}(x_{j})\mu_{b}(x_{j}),\quad j = 2,3,\ldots,l - 1.$$

(15.42)

其思路是执行一次正向和一次反向消息传递操作，存储这些值，然后计算任意感兴趣的边缘分布。总计算代价将为 $\mathcal{O}(2K^2l)$，而不是朴素方法的 $K^{(l)}$。
