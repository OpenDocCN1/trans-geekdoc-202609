
其中每个求和都是针对 *k* 个可能的值进行的，这相当于 𝒪(*k*^(*l*)) 次求和；对于较大的 *k* 和/或 *l* 值，这是一项艰巨且有时甚至不可能完成的任务。现在让我们考虑一个极端情况，即所有涉及的变量相互独立。此时乘积法则变为

```
P(x_1, x_2, ..., x_l) = ∏_{i=1}^l P(x_i)
```

而边缘化则变成了一个平凡的恒等式

```
P(x_1) = (∑_{x_l} P(x_l) ∑_{x_{l-1}} P(x_{l-1}) ... ∑_{x_2} P(x_2)) P(x_1)  (15.9)
```

因为每个求和都是独立进行的，且结果当然为 1。换句话说，利用乘积法则和统计独立性可以绕过计算负载呈指数级增长的障碍。事实上，前面的完全独立性假设催生了朴素贝叶斯分类器（第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章）。
