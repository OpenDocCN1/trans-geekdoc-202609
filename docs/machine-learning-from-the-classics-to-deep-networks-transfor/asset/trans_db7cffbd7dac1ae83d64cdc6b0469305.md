
库尔巴克-莱布勒散度*不对称*，即 `KL(p||q) ≠ KL(q||p)`，并且可以证明它是一个非负量（证明类似于互信息非负的证明；参见第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章的问题 [12.7](#Chp012_583-634_B9780443292385000184.xhtml)）。此外，当且仅当 `p = q` 时，它为零。

请注意，我们关于熵和互信息的所有论述均可直接推广到随机向量的情况。

## 2.6 随机收敛

我们将以一些关于随机变量序列收敛的定义，结束这场概率论及相关概念的记忆复习之旅。

考虑一个随机变量序列 `x[0], x[1], …, x[n]…`。

我们可以将此序列视为一个离散时间随机过程。由于随机性，该过程的一个实现，如 `x[0], x[1], …, x[n]…` 所示，可能收敛，也可能不收敛。因此，随机变量收敛的概念必须谨慎对待，并由此发展出了不同的解释。

回顾基础微积分知识，如果 `∀ϵ > 0` 存在一个数 `n(ϵ)` 使得

```
|x[n] − x| < ϵ, ∀n ≥ n(ϵ)。
```
(2.162)

则数列 `x[n]` 收敛于值 `x`。

### 处处收敛

如果随机过程的每一个实现 `x[n]` 都根据公式 [(2.162)](#Chp002_19-64_B9780443292385000081.xhtml#deq206) 给出的定义收敛于某个值 `x`，则称该随机序列*处处收敛*。请注意，每个实现收敛到不同的值，该值本身可视为随机变量 x 的一个结果，我们记为

```
x_n → x as n → ∞。
```
(2.163)

通常用 `x[n](ζ)` 表示随机过程的一个实现（结果），其中 `ζ` 表示一个特定的实验。

### 几乎处处收敛

相比于前一种收敛，一个较弱的版本是*几乎处处收敛*。考虑结果集 `ζ`，使得

```
lim x[n](ζ) = x(ζ), n → ∞。
```

如果满足

```
P(x[n] → x) = 1, n → ∞。
```
(2.164)

则称序列 `x[n]` 几乎处处收敛。
