
判别器拥有 784 个输入节点，以匹配与 28 × 28 MNIST 图像相关的 1 × 784 尺寸向量。判别器由三个隐藏层组成，分别包含 1024、512 和 256 个神经元。带有 `α = 0.2` 的 Leaky ReLU 单元被用作隐藏层神经元的激活函数。输出是一个单一的二元 Sigmoid 节点，代价函数为二分类交叉熵函数（公式 [(18.44)](#Chp018_885-995_B978044329238500024X.xhtml)）。在训练过程中，采用了 Dropout 方法，丢弃隐藏神经元的概率设为 0.3。训练使用了 Adam 优化器（[习题 19.9](#Chp019_997-1102_B9780443292385000251.xhtml#o0085)）。输入图像被归一化到 [−1, 1] 范围内。用于训练的图像数量为 60000 张，小批量的大小等于 100。

### 19.2.6 变分自编码器

GANs 的核心在于这样一个概念：通过用随机噪声向量 `z` 的对应样本 `z[n]` 激发生成器网络，来生成随机向量 `x` 的样本 `x[n]`，`n = 1, 2, …`。此外，请回顾 GANs 并不涉及任何显式的概率论证。相比之下，*变分自编码器*（VAEs）是概率生成模型。此外，在这种情况下被称为解码器的生成器，是由其后验概率密度函数（PDF）已从数据中*学习*到的随机变量所激发的。训练建立在贝叶斯学习论证之上；请参见第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章和第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章。变分自编码器最早由文献 [103] 和 [154] 提出。

VAEs 背后的基本假设是：我们得到一组观测值 `x[n]`，`n = 1, 2, …, N`，它们是随机向量 `x ∈ ℝ^(l)` 的样本。此外，后者是另一个过程的结果，该过程涉及一组*潜在*随机变量 `z ∈ ℝ^(m)`，通常 `m ≪ l`。也就是说，VAEs 属于更广泛的生成机制范畴，其底层生成机制沿着以下步骤演变：

*   根据某个概率密度函数 `p(z; θ)` 生成一个样本 `z[n]`，其中 `θ` 是一组未知参数。
*   根据条件概率密度函数 `p(x|z[n]; θ)` 生成一个样本 `x[n]`。

正如我们从贝叶斯相关章节所知，在存在潜在（未观测）变量的情况下，估计一组参数 `θ` 的一种方法是通过 EM 算法。应用该算法的前提是知道后验概率 `p(z|x)`；这对于对（未知的）潜在变量进行平均化是必需的。通常情况下，此后验概率不可用（或 EM 计算所需的积分在计算上可能难以处理），因此必须求助于近似。在第 [13](#Chp013_635-716_B9780443292385000196.xhtml) 章中，在均场近似框架下采用了因子分解形式。相比之下，根据 VAEs，后验概率的近似 `q(z|x; ϕ)` 是通过神经网络来实现的；向量 `ϕ` 表示一组未知参数，它们必须与 `θ` 一起被学习。
