
然而，该定理并未说明，就单层所需神经元数量而言，这样的网络可以有多大。可能需要非常大量的神经元才能获得足够好的近似。这就是使用更多层可能具有优势的地方。使用更多层，达到特定近似所需的神经元总数可能会少得多。当我们讨论深度架构时，很快就会涉及到这个问题。

### 备注 18.5

*   **极限学习机（ELM）：** 这些是输出形式如下 [80] 的单隐层前馈网络（SLFN）：

    $$g_{K}(\mathbf{x}) = \sum\limits_{i = 1}^{K}\theta_{i}^{o}f\left( \mathbf{\theta}_{i}^{h^{T}}\mathbf{x} + b_{i} \right)$$

    其中 `f` 为相应的激活函数，`K` 为隐藏节点数量。与标准单隐层前馈网络的主要区别在于，与每个节点相关的参数（即 `θ[i]^(h)` 和 `b[i]`）是*随机*生成的，而输出函数的权重（即 `θ[i]^(o)`）的选择是为了使训练点上的平方误差最小化。这意味着求解

    $$\min\limits_{\mathbf{\theta}^{o}}\sum\limits_{n = 1}^{N}\left( y_{n} - g_{K}(\mathbf{x}_{n}) \right)^{2}.$$

    因此，根据 ELM 的基本原理，我们不需要计算隐藏层参数的值。事实证明，这种训练理念具有坚实的理论基础，因为收敛到唯一解是有保证的。值得注意的是，尽管节点参数是随机生成的，但对于无限可微的激活函数，如果 `K` 接近 `N`，训练误差可以变得任意小（如果 `K = N` 则变为零）。此外，通用近似定理保证，对于足够大的 `K` 和 `N` 值，`g[K]` 可以近似任意非恒定分段连续函数 [81]。关于这一简单想法的许多变体和推广可以在相关文献中找到。有兴趣的读者可参考例如 [82,161] 以获取相关综述。
