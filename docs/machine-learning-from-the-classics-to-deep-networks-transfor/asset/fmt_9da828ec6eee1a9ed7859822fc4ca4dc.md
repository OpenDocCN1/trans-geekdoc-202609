
为了解决当前问题，我们将把 `q(𝒳^(l), θ)` 约束在特定的函数族内。注意，在这种情况下，如果未知的 `p(𝒳^(l), θ|𝒳; ξ)` 不属于所选的函数族，KL 散度*不能*变为零，并且边际对数似然的下界 `ℱ(q, ξ)` *不能*变得*紧致*。这就是该方法被称为变分近似的原因。

### 均场近似

这种近似是通过将 `q(𝒳^(l), θ)` 约束为因子分解形式而产生的，即：

```
q(𝒳^(l), θ) = q[𝒳^(l)](𝒳^(l)) q[θ](θ)
```
