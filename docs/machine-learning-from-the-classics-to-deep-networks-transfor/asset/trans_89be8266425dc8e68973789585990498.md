

# 定义 2.2：宽平稳性

如果随机过程 `u[n]` 的均值在所有时间点上均为常数，且自相关/自协方差序列仅依赖于所涉及时间索引的差值，则称该过程为*宽平稳*（WSS），即

```
μ[n] = μ,  and  r(n, n − k) = r(k).
```

![Equation](images/B9780443292385000081/si257.png) (2.105)

请注意，WSS 是二阶平稳性的一个较弱版本；在后一种情况下，所有可能的二阶统计量均与时间原点无关。而在前一种情况下，我们仅要求自相关（自协方差）和均值与时间原点无关。之所以关注这两个量（统计量），是因为正如我们将在第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章中看到的那样，它们在线性系统研究和均方估计中具有重要意义。

显然，严平稳（SSS）过程也是 WSS 过程，但一般来说，反之则不成立。对于 WSS 过程，自相关变为一个*序列*，仅以*单个*时间索引作为自由参数；因此，其值（衡量两个时刻随机变量间的关系）*仅取决于这两个时刻相差多少*，而不取决于它们的具体数值。
