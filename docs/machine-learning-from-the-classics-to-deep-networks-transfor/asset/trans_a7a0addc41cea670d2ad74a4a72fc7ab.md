
一旦所有可用的训练样本都已用完，训练将继续使用估计值 `ŝ[n − L + 1]` 进行。例如，对于二进制信息序列 `s[n] ∈ {1, −1}`，通过将 `d̂[n]` 传递给阈值判决器来获得时刻 `n` 的估计判决，从而得到 `ŝ[n − L + 1]`。注意，DFE 是*半监督*学习的早期示例之一，其中训练数据不足，估计值被用于训练 [94]。通过这种方式，假设在训练阶段结束时 `ŝ[n − L + 1] ≈ s[n − L + 1]`，并且假设时间变化缓慢，以保证 `d̂[n] ≈ d[n]`，我们有理由期望（以足够大的概率）`ŝ[n − L + 1]` 将保持接近 `s[n − L + 1]`，从而使均衡器能够跟踪变化。关于 DFE 及其误差性能的更多内容见 [77]。
