
Let $f$ be a convex function, with `Prox[λf]` being the respective proximal operator of index $\lambda$. Then, starting from an arbitrary point `x[0] ∈ ℝ^l`, the iterative algorithm

```
x[k] = x[k-1] + μ[k](Prox[λf](x[k-1]) - x[k-1])
```
(8.117)

where `μ[k] ∈ (0, 2)` is such that

```
∑_{k=1}^{∞} μ[k](2 - μ[k]) = +∞
```

converges to an element of the fixed point set of the proximal operator; that is, it converges to a minimizer of $f$.

The proof of the proposition is given in Problem [8.36](#Chp008_343-416_B9780443292385000147.xhtml#o0210) [84]. Observe that Eq. [(8.118)](#Chp008_343-416_B9780443292385000147.xhtml#deq223) is the counterpart of Eq. [(8.26)](#Chp008_343-416_B9780443292385000147.xhtml#deq56). A special case occurs if `μ[k] = 1`, which results in

```
x[k] = Prox[λf](x[k-1])
```
(8.118)

also known as the *proximal point* algorithm. Proximal minimization algorithms are traced back to the early 1970s [57, 72].

## Example 8.11

Let us demonstrate the previous findings via the familiar optimization task of the quadratic function

```
f(x) = (1/2)x^T A x - b^T x
```

It does not take long to see that the minimizer occurs at the solution of the linear system of equations

```
A x[*] = b
```

From the definition in Eq. [(8.106)](#Chp008_343-416_B9780443292385000147.xhtml#deq200), taking the gradient of the quadratic function and equating to zero, we readily obtain

```
Prox_{λf}(x) = (A + (1/λ)I)^{-1} (b + (1/λ)x)
```
