

### 近端前向-后向分裂算法

$(I + \lambda \partial f)^{-1}(I - \lambda \nabla g)(x^*) = x^*$

![Equation](images/B9780443292385000147/si568.png)

最终得到

$x^* = \text{Prox}_{\lambda f}(x^* - \lambda \nabla g(x^*))$

![Equation](images/B9780443292385000147/si569.png) (8.133)

换句话说，任务的极小值点是算子的不动点

$(I + \lambda \partial f)^{-1}(I - \lambda \nabla g) : \mathbb{R}^l \mapsto \mathbb{R}^l$

![Equation](images/B9780443292385000147/si570.png) (8.134)

后者被称为**近端前向-后向分裂算子**，可以证明如果 $\lambda \in \left( 0, \frac{1}{\gamma} \right]$，其中 $\gamma$ 是 Lipschitz 常数，则该算子是**非扩张的** [108]。这个简短的论述证明了 Eq. [(8.131)](#Chp008_343-416_B9780443292385000147.xhtml#deq244) 中的迭代被极小值点集吸引的原因。

#### 备注 8.10

*   近端梯度分裂算法可以看作某些先前算法的推广。若令 $f(x) = \iota_C(x)$，近端算子变为投影算子，从而得到 Eq. [(8.62)](#Chp008_343-416_B9780443292385000147.xhtml#deq128) 中的投影梯度算法。若 $f(x) = 0$，则得到梯度算法；若 $g(x) = 0$，则得到近端点算法。
*   除了批量近端分裂算法，还提出了在线方案（参见 [36, 48, 106, 107]），重点关注 $\ell_1$ 正则化任务。
*   关于该算法族在机器学习和信号处理领域的应用及新版本开发的文献非常丰富，感兴趣的读者可通过 [7, 28, 67, 108] 等深入了解。
