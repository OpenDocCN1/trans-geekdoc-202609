
文献 [31] 建议采用一种基于 Gibbs 的切片采样器实现；`x` 的每个分量均通过单变量切片采样策略依次更新。结果表明，切片采样器提高了标准 Metropolis–Hastings 算法的收敛速度。

文献 [29] 利用一个辅助变量，从而避开了归一化常数的计算。在归一化常数难以计算的情况下，这一点至关重要。

另一种采样理念涵盖了*基于种群*的方法。为克服局部陷阱问题，在信息交换策略下并行运行若干条（种群）马尔可夫链，从而改善收敛性。此类技术的典型例子包括*自适应方向采样* [12] 和*进化*蒙特卡洛方法，后者建立在遗传算法所用的论据之上 [22]。

另一个方向是*哈密顿*蒙特卡洛方法，其利用经典力学中优雅的哈密顿方程相关论据 [26,30]。对于以下形式的 PDF：

```
p(x) = (1/Z_E) exp(-E(x)),
```

`E(x)` 可解释为系统的势能（第 [15.4.2](#Chp015_755-803_B9780443292385000214.xhtml) 节）。一旦建立起这种联系，便引入一个辅助随机向量 `q`，并将其解释为系统的动量；因此，相应的动能可表示为：

```
K(q) = (1/2) sum_{i=1}^{l} q_i^2.
```

哈密顿函数由此给出：

```
H(x, q) = E(x) + K(q),
```

它定义了如下分布：

```
p(x, q) = (1/Z_H) exp(-H(x, q)) = (1/Z_E) exp(-E(x)) (1/Z_K) exp(-K(q)) := p(x)p(q).
```
