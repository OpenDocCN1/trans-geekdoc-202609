
**y**[*n*] = *H*[*n*]**x**[*n*] + **v**[*n*],

其中 **η**[*n*] 和 **v**[*n*] 是均值为零、相互独立的噪声干扰，由高斯分布建模。这就是著名的卡尔曼滤波器，我们已经在第 [4](#Chp004_119-175_B978044329238500010X.xhtml) 章中讨论过，并且将在第 [17](#Chp017_855-884_B9780443292385000238.xhtml) 章中从概率角度进行探讨。公式 [(16.28)](#Chp016_805-853_B9780443292385000226.xhtml#deq57) 和 [(16.29)](#Chp016_805-853_B9780443292385000226.xhtml#deq58) 的概率对应形式为：

*p*(**x**[*n*]|**x**[*n* − 1]) = 𝒩(**x**[*n*]|*F*[*n*]**x**[*n* − 1], *Q*[*n*]),

*p*(**y**[*n*]|**x**[*n*]) = 𝒩(**y**[*n*]|*H*[*n*]**x**[*n*], *R*[*n*]),

其中 *Q*[*n*] 和 *R*[*n*] 分别是 **η**[*n*] 和 **v**[*n*] 的协方差矩阵。

## 16.5 隐马尔可夫模型

隐马尔可夫模型由 [图 16.15](#Chp016_805-853_B9780443292385000226.xhtml#f0080) 和公式 [(16.26)](#Chp016_805-853_B9780443292385000226.xhtml#deq55) 及 [(16.27)](#Chp016_805-853_B9780443292385000226.xhtml#deq56) 所示的图模型表示。潜在变量是离散的；因此，我们将*转移*概率写为 *P*(**x**[*n*]|**x**[*n* − 1])，这对应一个概率表。观测变量可以是离散的，也可以是连续的。基本上，HMM 用于建模一种*准平稳*过程，该过程在若干个（例如 *K* 个）子过程中发生*突发*变化。每一个子过程都由不同的统计特性描述。也可以将其视为一个组合系统，包含若干子系统；每个子系统根据不同的统计模型生成数据/观测值；例如，一个可能服从高斯分布，另一个可能服从学生 *t* 分布。观测值由这些子系统发射；然而，一旦接收到观测值，我们并不知道它是由哪个子系统发射的。这让人联想到概率密度函数 (PDF) 的混合建模任务；然而，在混合建模中，我们并不关心观测值出现的顺序。
