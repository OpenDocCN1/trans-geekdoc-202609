$$\\mathbf{u}\_{y} = \\frac{1}{\\lambda}{\\widehat{\\Sigma}}\_{yy}^{- 1}{\\widehat{\\Sigma}}\_{yx}\\mathbf{u}\_{x},$$

当然，这假设 *Σ̂*[*yy*] 可逆![Equation](images/B9780443292385000263/si146.png)。此外，假设 *Σ̂*[*xx*]![Equation](images/B9780443292385000263/si147.png) 也可逆，我们最终得到以下特征值-特征向量问题：

(*Σ̂*[*xx*]^(−1)*Σ̂*[*xy*]*Σ̂*[*yy*]^(−1)*Σ̂*[*yx*])**u**[*x*] = *λ*²**u**[*x*]。

![Equation](images/B9780443292385000263/si148.png)(20.34)

因此，轴 **u**[*x*, 1]![Equation](images/B9780443292385000263/si135.png) 可作为公式 [(20.34)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq43) 中括号内矩阵乘积的一个特征向量获得。考虑到公式 [(20.30)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq39) 和约束条件，相应的相关性最优值 *ρ* 等于

*ρ* = **u**[*x*, 1]^(*T*)*Σ̂*[*xy*]**u**[*y*, 1] = *λ***u**[*x*, 1]^(*T*)*Σ̂*[*xx*]**u**[*x*, 1] = *λ*。
