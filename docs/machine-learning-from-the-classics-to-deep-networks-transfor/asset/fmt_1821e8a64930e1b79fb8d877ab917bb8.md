仔细观察公式 [(7.19)](#Chp007_293-342_B9780443292385000135.xhtml#deq32)，可以很容易地注意到：一旦两个类别的协方差矩阵变得相等，二次项就会抵消，判别函数变为线性；因此，对应的超曲面是一个**超平面**。也就是说，在上述假设下，最优贝叶斯分类器变成了一个**线性**分类器，经过一些直接的代数运算（读者可自行尝试）可以写为：

```
g(x) = (μ₁ - μ₂)ᵀ Σ⁻¹ x - ½ (μ₁ᵀ Σ⁻¹ μ₁ - μ₂ᵀ Σ⁻¹ μ₂) + ln(P(ω₁)/P(ω₂))
```

其中 `Σ` 是公共协方差矩阵。
