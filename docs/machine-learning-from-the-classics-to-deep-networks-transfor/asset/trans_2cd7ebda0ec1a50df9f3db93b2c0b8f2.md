公式 [(3.36)](#Chp003_65-117_B9780443292385000093.xhtml#deq57) 采用了公式 [(3.31)](#Chp003_65-117_B9780443292385000093.xhtml#deq52) 的形式，其中 $g(\mathbf{y}) = \overline{y}$；因此，可以获得一个有效估计量，而对于我们的公式 [(3.33)](#Chp003_65-117_B9780443292385000093.xhtml#deq54) 数据模型，任何无偏估计量的方差下界为

$\sigma_{\widehat{\theta}}^{2} \geq \frac{\sigma_{\eta}^{2}}{N}$。

我们可以很容易地验证，在采用的公式 [(3.33)](#Chp003_65-117_B9780443292385000093.xhtml#deq54) 模型下，相应的估计量 $\overline{y}$ 确实是无偏的，

$\mathbb{E}[\overline{y}] = \frac{1}{N}\sum\limits_{n = 1}^{N}\mathbb{E}[y_{n}] = \frac{1}{N}\sum\limits_{n = 1}^{N}\mathbb{E}[\theta + \eta_{n}] = \theta$。

此外，上述公式结合公式 [(3.36)](#Chp003_65-117_B9780443292385000093.xhtml#deq57)，也确立了克拉梅尔-拉奥定理所要求的正则性条件。

公式 [(3.38)](#Chp003_65-117_B9780443292385000093.xhtml#deq61) 中的界是一个非常自然的结果。克拉梅尔-拉奥下界取决于噪声源的方差。该方差越大，因此每个观测值相对于真实参数值的不确定性越高，估计量的最小方差预期也就越高。另一方面，随着观测次数的增加，更多的“信息”被揭示给我们，不确定性降低，我们预期估计量的方差也会减小。
