
$$
\left( \sum\limits_{n = 1}^{N}x_{n}^{2} \right)\widehat{\theta} = \sum\limits_{n = 1}^{N}y_{n}x_{n},\quad \text{or}\quad \widehat{\theta} = \frac{\sum_{n = 1}^{N}y_{n}x_{n}}{\sum_{n}^{N}x_{n}^{2}}.
$$

A more popular way to write Eq. [(3.13)](#Chp003_65-117_B9780443292385000093.xhtml#deq16) is via the so-called input matrix `X`, defined as the `N × (l + 1)` matrix, which has as rows the (extended) regressor vectors `x[n]^(T)`, `n = 1, 2, …, N`, expressed as

```
X := [x_1^T; x_2^T; ...; x_N^T] = [x_11 ... x_1l 1; x_21 ... x_2l 1; ...; x_N1 ... x_Nl 1].
```

Then it is straightforward to see that Eq. [(3.13)](#Chp003_65-117_B9780443292385000093.xhtml#deq16) can be written as

```
(X^T X) \hat{\theta} = X^T y,
```
