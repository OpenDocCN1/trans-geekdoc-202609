
其中我们设定了 $\lambda := \frac{\sigma_{\eta}^{2}}{\sigma_{\theta}^{2}}$。我们已经从第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章知道，`λ` 的值对于估计器关于均方误差（MSE）性能的表现至关重要。现在的主要问题变成了如何为 `λ` 选择一个好的值，或者在更一般的情况下为 `Σ[θ]`、`Σ[η]` 选择好的值。在实践中，采用交叉验证方法（第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章）；测试不同的 `λ` 值，并选择导致最佳 MSE（或其他某些准则）的那个值。然而，这是一个计算成本高昂的过程，特别是对于涉及大量参数的复杂模型。此外，这种过程迫使我们只使用一部分可用数据进行训练，以保留其余数据用于测试。读者可能会想，为什么我们不利用训练数据同时针对未知参数向量 `θ` 和正则化参数进行优化。让我们以中心化数据（`θ[0] = 0`）的简单岭回归情况为例。代价函数包含两项，一项依赖于数据并度量拟合优度，另一项仅依赖于未知参数，

`J(θ, λ) = ||y − Φθ||² + λ||θ||²`。

显而易见，唯一能使*训练数据集上的*平方误差拟合（经验损失）达到最小的 `λ` 值是 `λ = 0`。任何其他 `λ` 值都会导致 `θ` 的估计值使平方误差项取得更大的值；这是很自然的，因为对于 `λ ≠ 0`，优化过程还必须顾及额外的正则化项。只有当采用*测试数据集*时，`λ ≠ 0` 的值才会导致总体 MSE（而非经验 MSE）下降。

### 12.2.3 贝叶斯方法

贝叶斯回归方法试图克服先前提到的与过拟合相关的缺点。所有涉及的参数都可以在训练集上进行估计。在此思路下，参数将被视为随机变量。同时，因为主要任务现在变成了推断描述未知参数集的概率密度函数（PDF），而不是获得单个向量估计，所以人们可以掌握更多信息。话虽如此，这并不意味着贝叶斯技术必然不需要交叉验证；仍需交叉验证来评估其整体性能。我们将在第 [12.3](#Chp012_583-634_B9780443292385000184.xhtml#s0035) 节末尾的备注中进一步评论这一点。
