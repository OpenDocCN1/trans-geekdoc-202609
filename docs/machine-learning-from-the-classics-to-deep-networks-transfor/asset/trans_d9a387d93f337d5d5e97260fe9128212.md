
关于 PLS 的文献非常丰富，该方法已从算法和性能两个方面进行了研究。感兴趣的读者可参考文献 [153] 了解更多关于 PLS 的内容。在我们迄今为止讨论的所有技术中，一个主要焦点是计算特征值-特征向量。为此，虽然可以使用通用的软件包和算法，但也推导出了一些更高效的替代方案。一种常见的方法是通过两步迭代过程来求解任务。在第一步中，计算最大特征值（特征向量），为此存在高效的算法，例如幂法（如 [83]）。然后，采用一种称为*通胀*的过程；这包括从协方差矩阵中移除第一步中提取的特征所解释的方差（见例如 [135]）。PLS 的核化版本也已被提出（例如 [9,152]）。

### 备注 20.3

*   如果我们在公式 [(20.39)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq53) 中设定

    ```
    B = [[Σ̂_xx, O], [O, I]].
    ```

    将得到另一种降维方法。

*   由此产生的方法称为*多元线性回归*（MLR）。这是寻找一组基向量和相应的回归量，使得回归问题中的 MSE 最小化的任务 [26]。

*   CCA 关于仿射变换是*不变的*。相对于普通相关分析，这是一个重要优势（例如 [6]）。

*   CCA 和 PLS 向两个以上数据集的扩展也已被提出（见例如 [56,110,185]）。

## 20.5 独立成分分析

PCA 的潜变量解释在公式 [(20.17)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq22)–[(20.19)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq25) 中进行了总结，其中每一个观测随机变量 `x[i]` 都（近似地）写为潜变量（在本例中为主成分）`z[i]` 的线性组合，后者又通过公式 [(20.19)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq25) 获得，施加了不相关性约束。

ICA 的出发点是假设以下潜变量模型为真：

```
x = A s, (20.44)
```

其中（未知的）潜变量 `s` 被假定为相互统计*独立*，我们称它们为*独立成分*（ICs）。任务包括获得矩阵 `A` 和独立成分的估计。我们将重点关注 `A` 为 `l × l` 方阵的情况。对应于潜变量数量 `m` 小于或大于观测随机变量数量 `l` 的场景，即胖矩阵和高矩阵的扩展也已被考虑和开发（见例如 [100]）。

矩阵 `A` 称为*混合矩阵*，其元素 `a[ij]` 称为*混合系数*。潜变量的*估计*将表示为 `z[i], i = 1, 2…, l`，我们也将它们称为独立成分。观测随机变量 `x[i], i = 1, 2, …, l` 有时称为*混合变量*或简称混合物。

为了获得潜变量的估计，我们采用模型

```
ŝ := z = W x, (20.45)
```

其中 `W` 也称为*解混*或*分离*矩阵。注意

```
z = W A s,
```

我们必须估计未知参数，使得 `z` 尽可能接近 `s`。对于方阵，假设可逆，有 `A = W^(−1)`。
