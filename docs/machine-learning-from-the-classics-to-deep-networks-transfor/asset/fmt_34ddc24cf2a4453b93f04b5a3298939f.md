
## 最优平均风险分类器

### 条件风险公式

对于类别 $\omega_1$ 的条件风险 $r_1$：

$$r_1 = \lambda_{11}\int_{\mathcal{R}_1}p(\mathbf{x}|\omega_1)d\mathbf{x} + \lambda_{12}\underset{\text{error}}{\underbrace{\int_{\mathcal{R}_2}p(\mathbf{x}|\omega_1)d\mathbf{x}}}$$

(7.7)

对于类别 $\omega_2$ 的条件风险 $r_2$：

$$r_2 = \lambda_{21}\underset{\text{error}}{\underbrace{\int_{\mathcal{R}_1}p(\mathbf{x}|\omega_2)d\mathbf{x}}} + \lambda_{22}\int_{\mathcal{R}_2}p(\mathbf{x}|\omega_2)d\mathbf{x}$$

(7.8)

### 平均风险最小化

通常情况下，$\lambda_{11} = \lambda_{22} = 0$，因为它们对应正确决策。需最小化的平均风险 $r$ 由下式给出：

$$r = P(\omega_1)r_1 + P(\omega_2)r_2$$
