

### 算法步骤

*   **For** `n = 2, 3, …` **Do**
    1.  **For** `i = 1, 2, …, N` **Do**
        *   采样 `x_n^(i) ~ q_n(x | x̄_{1:n-1}^(i))`
        *   设置 `x_{1:n}^(i) = {x_n^(i), x̄_{1:n-1}^(i)}`
        *   计算 `w_n(x_{1:n}^(i)) = (1/N) * a_n(x_{1:n}^(i))` (公式 (17.9))
    2.  **End For**
    3.  **For** `i = 1, 2, …, N` **Do**
        *   计算 `W_n^(i)`
    4.  **End Do**
    5.  重采样 `{x_{1:n}^(i), W_n^(i)}[i=1]^N` 以获得 `{{x̄_{1:n}^(i), 1/N}}_{i=1}^N`
*   **End For**

### 备注 17.1

*   关于序贯重要性采样的收敛结果可参见例如文献 [6–8]。实践表明，使用重采样可显著降低方差。
