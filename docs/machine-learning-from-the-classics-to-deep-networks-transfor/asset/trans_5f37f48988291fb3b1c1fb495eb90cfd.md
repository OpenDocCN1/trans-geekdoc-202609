
# 离散加伯变换

离散加伯变换可以看作是短时傅里叶变换（STFT）的一个特例（例如，[57,87]）。在标准 DFT 变换中，包含 *l* 个采样点的时序的全长被“一股脑”地用于计算相应的频率内容。然而，后者可能是时变的，因此 DFT 将提供平均信息，这可能没有太大用处。加伯变换（以及一般的 STFT）通过使用窗函数引入了时间定位，该窗函数沿时间轴在信号段上滑动，并在每个时间瞬间聚焦于信号的不同部分。这是一种允许跟踪频域中发生的缓慢时间变化的方法。在加伯变换的背景下，时间定位是通过高斯窗函数实现的，即

$$
g(n) := \frac{1}{\sqrt{2\pi\sigma^{2}}}\exp\left( - \frac{n^{2}}{2\sigma^{2}} \right).
$$

现在让我们构建加伯字典的原子。回顾一下，在基于 DFT 的信号表示中（公式 [(10.29)](#Chp010_463-518_B9780443292385000160.xhtml#deq92)），每个频率仅由相应的采样正弦波表示一次（公式 [(10.30)](#Chp010_463-518_B9780443292385000160.xhtml#deq93)）。在加伯变换中，每个频率出现 *l* 次；相应的采样正弦波每次移位一个采样点，与高斯窗序列相乘。因此，在第 *i* 个频率箱中，我们有 *l* 个原子，**g**^((*m*, *i*)), *m* = 0, 1, …, *l* - 1，其元素由下式给出

`g^((m, i))(n) = g(n - m) * ψ[i](n), n, m, i = 0, 1, …, l - 1,`

![Equation](images/B9780443292385000160/si417.png) (10.39)

其中 `ψ[i](n)` 是公式 [(10.30)](#Chp010_463-518_B9780443292385000160.xhtml#deq93) 中向量 **ψ**[i] 的第 *n* 个元素。这导致了一个包含 *l*² 个原子的过完备字典，位于 *l* 维空间中。[图 10.13](#Chp010_463-518_B9780443292385000160.xhtml#f0070)B 说明了将不同正弦波与不同扩散程度和不同时间延迟的高斯脉冲相乘的效果。[图 10.14](#Chp010_463-518_B9780443292385000160.xhtml#f0075) 是加伯字典所涉及原子的图形化解释。该时频图中的每个节点 (*m*, *i*) 对应一个频率等于 $\frac{2\pi}{l}i$ 且延迟等于 *m* 的原子。
