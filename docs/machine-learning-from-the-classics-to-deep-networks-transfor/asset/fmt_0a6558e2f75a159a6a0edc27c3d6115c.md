
## 9.17

Show that if the underdetermined system of equations `y = Xθ` accepts a solution such that

```
||θ||_0 < 1/2 (1 + 1/μ(X))
```

then the ℓ₁ minimizer is equivalent to the ℓ₀ one. Assume that the columns of `X` are normalized.

## 9.18

Prove that if the RIP of order `k` is valid for a matrix `X` and `δ_k < 1`, then any `m < k` columns of `X` are necessarily linearly independent.

## 9.19

Show that if `X` satisfies the RIP of order `k` and some isometry constant `δ_k`, so does the product `XΨ` if `Ψ` is an orthonormal matrix.
