
输入随机向量的自相关/协方差矩阵（针对零均值过程）已在公式 [(4.17)](#Chp004_119-175_B978044329238500010X.xhtml#deq26) 中定义。也就是说，它既是厄米特矩阵，又是半正定矩阵。从现在开始，我们将假设它是正定矩阵。与复宽平稳过程相关的 `ℂ^(m×m)` 中的协方差矩阵由下式给出：

```
Σ_m = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r(-1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r(-m+1)  r(-m+2)  ⋯     r(0)     ]
    = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r*(1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r*(m-1)  r*(m-2)  ⋯     r(0)     ],
```

其中性质

```
r(i) := E[u[n] u[n-i]*] = E[(u[n-i] u[n]*)*] := r*(-i)
```
