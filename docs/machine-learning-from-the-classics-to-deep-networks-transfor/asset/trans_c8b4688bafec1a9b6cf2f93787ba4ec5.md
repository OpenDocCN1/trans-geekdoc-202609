
现在 $\widehat{\mathbf{g}}(\mathbf{x}) \in \mathbb{R}^{k}$（问题 [3.15](#Chp003_65-117_B9780443292385000093.xhtml#o0080)）。此外，如果 $(\mathbf{y}, \mathbf{x})$ 是联合高斯随机向量，则 MSE 最优估计器也是 $\mathbf{x}$ 的仿射函数（问题 [3.16](#Chp003_65-117_B9780443292385000093.xhtml#o0085)）。

本小节的发现可以通过物理推理完全证明。为简单起见，假设公式 [(3.46)](#Chp003_65-117_B9780443292385000093.xhtml#deq84) 中的噪声源均值为零。那么，对于固定值 $\mathbf{x} = \mathbf{x}$，我们有 $\mathbb{E}[y|\mathbf{x}] = g(\mathbf{x})$，相应的 MSE 等于

MSE $= \mathbb{E}[(y - \mathbb{E}[y|\mathbf{x}])^2] = \sigma_{\eta}^2$。 (3.51)

没有其他 $\mathbf{x}$ 的函数能做得更好，因为最优函数达到的 MSE 等于噪声方差，这是不可约的；它代表了系统的内在不确定性。正如公式 [(3.49)](#Chp003_65-117_B9780443292385000093.xhtml#deq88) 所示，任何其他函数 $f(\mathbf{x})$ 将导致 MSE 增加量 $(\mathbb{E}[y|\mathbf{x}] - f(\mathbf{x}))^2$，这对应于与最优函数的偏差。
