
## 2. 计算特征向量（特征脸）的直接方法

一种直接的方法是使用 `svd.m` MATLAB® 函数对矩阵 `X` 执行 SVD，即 `X = U * D * V^T`。这样，特征脸就是 `U` 的列。然而，这需要大量的计算工作，因为 `X` 有太多行。或者，你可以按如下步骤进行：

1.  首先计算乘积 `A = X^T * X`。
2.  然后使用 `svd.m` MATLAB® 函数计算 `A` 的 SVD，即 `A = V * D^2 * V^T`，以此计算 `X` 的右奇异向量。
3.  然后根据公式 `u_i = (1 / σ_i) * X * v_i` 计算每个特征脸，其中 `σ_i` 是 SVD 的第 `i` 个奇异值。
4.  最后，随机选择一张人脸，使用前 5、30、100 和 600 个特征向量对其进行重构。

## 6. 后续步骤

接下来遵循以下步骤：

1.  使用 `im2col.m` MATLAB® 函数从图像中提取所有大小为 `12 × 12` 的可能滑动补丁，并将它们作为列存储在矩阵 `X` 中。
2.  使用该矩阵，训练一个大小为 `(144 × 196)` 的过完备字典 `Ψ`，进行 100 次 `k`-SVD 迭代，其中 `T_0 = 5`。对于第一次迭代，初始字典原子从零均值高斯分布中抽取，然后归一化为单位范数。
3.  作为下一步，分别对每个图像补丁进行去噪。特别是，假设 `y_i` 是重塑为列向量的第 `i` 个补丁，使用 OMP（[10.2.1 节](#Chp010_463-518_B9780443292385000160.xhtml)）来估计一个稀疏向量 `θ_i ∈ ℝ^196`，满足 `||θ_i||_0 = 5`，使得 `||y_i - A * θ_i||` 很小。
4.  然后 `ŷ_i = Ψ * θ_i` 是第 `i` 个去噪后的补丁。
5.  最后，对重叠补丁的值取平均以形成完整的去噪图像。
