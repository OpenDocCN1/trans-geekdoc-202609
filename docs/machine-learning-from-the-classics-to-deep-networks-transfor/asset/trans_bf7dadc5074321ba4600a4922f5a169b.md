

## 步骤

### 步骤 1
从 `q^(i)(θ)` 中移除 `f̂[k]^(i)(θ)`，并定义

```
q_{/k}^{(i)}(θ) := q^{(i)}(θ) / f̂_{k}^{(i)}(θ).
```
(13.104)

### 步骤 2
定义概率密度函数 (PDF)

```
(1/Z_k) f_k(θ) q_{/k}^{(i)}(θ).
```
(13.105)

换句话说，在当前估计 `q^(i)(θ)` 中，`f̂[k]^(i)(θ)` 被 `f_k(θ)` 替换，`Z_k` 是对应的归一化常数。

### 步骤 3
计算归一化常数，

```
Z_k = ∫ f_k(θ) q_{/k}^{(i)}(θ) dθ.
```
(13.106)

### 步骤 4
在此步骤中，通过最小化 KL 散度进行优化，

```
KL( (1/Z_k) f_k(θ) q_{/k}^{(i)}(θ) || q^{(i+1)}(θ) ).
```
