
## 13.3 A variational Bayesian approach to linear regression

Once more, let us consider our familiar regression task

```
$q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta}) \propto {(g(\mathbf{\theta}))}^{\lambda + N}\exp\left( \mathbf{\phi}^{T}(\mathbf{\theta})\left( \mathbf{v} + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack \right) \right).$
```

![Equation](images/B9780443292385000196/si64.png)(13.20)

Thus, the approximation $q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta})$ of the posterior $p(\mathbf{\theta}|\mathcal{X})$ is of the same form as the conjugate prior with

```
$\widetilde{\lambda} = \lambda + N,\quad\widetilde{v} = v + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\ \left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack.$
```

![Equation](images/B9780443292385000196/si67.png)(13.21)

Note that the equations in [(13.21)](#Chp013_635-716_B9780443292385000196.xhtml#deq27) are of the same form as in [(12.77)](#Chp012_583-634_B9780443292385000184.xhtml). We only have to average out the latent variables. This is a very elegant result, because nothing has been assumed about the functional form of $q_{\mathbf{\theta}}$. In other words, once we adopt the functional form for the PDFs of the complete set as well as that of the prior of the parameters to be of the exponential type, then subsequent iterations become a “family business.”
