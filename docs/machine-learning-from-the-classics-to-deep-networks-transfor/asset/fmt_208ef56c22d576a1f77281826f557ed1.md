This type of flow spreads toward all the leaves, and finally

$$\mathbf{x}_{\ast} = \arg\max\limits_{\mathbf{x}}P(\mathbf{x}) \tag{15.69}$$

This would be possible if there were a guarantee for a unique optimum, $\mathbf{x}_{\ast}$.
