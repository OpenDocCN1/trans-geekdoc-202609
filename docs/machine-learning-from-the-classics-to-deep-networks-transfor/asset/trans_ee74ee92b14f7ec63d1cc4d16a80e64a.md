
## 贝叶斯方法与交叉验证

贝叶斯方法允许从单个数据集中恢复所有所需信息，但这并不意味着该方法是“无需交叉验证”的。最大化证据虽然能同时防止过拟合，但并不一定意味着设计的估计器性能已被优化。在实践中，为了绕过计算障碍，通常优化的是证据的一个界限而非证据本身，这一点更为明显。正如生活中的道理，实践出真知。因此，最终的判断标准只能来自设计估计器的泛化能力，即其利用未见数据进行可靠预测的能力。此外，没有理由表明证据能作为泛化性能的可靠预测指标。自该方法诞生之初，这点已为人所知并明确指出（例如文献 [27]）。泛化性能在很大程度上取决于所采用的先验是否与未知参数的“真实”分布相匹配。文献 [17] 中的一个玩具例子很好地演示了这一点：只有当采用的先验与真实先验一致时，贝叶斯平均才是最优的。当两者不一致时，情况就不那么清晰了。关于真实先验与选定先验不匹配时的更理论化处理，可参见文献 [18]。因此，除非能负担得起独立的测试集（例如文献 [44]），否则要评估通过贝叶斯推断学习到的模型的泛化性能，仍需要交叉验证。

## 避免交叉验证的替代方法

为避免交叉验证，一些作者采用了另一种途径。公式 [(12.13)](#Chp012_583-634_B9780443292385000184.xhtml#deq16) 中待最小化的代价函数被构建为量化估计器的泛化性能；随后，对未知模型参数和正则化参数进行联合优化（例如文献 [15,32]）。通常这会导致一个非凸优化任务，此类技术尚未（目前）被机器学习界广泛采纳。

## 拉普拉斯近似与 BIC

拉普拉斯对证据函数的近似与用于模型选择的 **贝叶斯信息准则 (BIC)** [39] 密切相关，BIC 表达式为：

```
ln p(y|M_i) ≈ ln p(y|M_i, θ̂_MAP) - ½ K ln N
```

BIC 是作为对公式 [(12.38)](#Chp012_583-634_B9780443292385000184.xhtml#deq49) 在大 *N* 近似下的推导结果获得的，假设先验是足够宽的高斯分布，并对最后一项涉及的行列式稍作处理。包含其他相关准则的讨论见文献 [3,41]。

## 贝叶斯框架与 MDL

贝叶斯框架也与 **最小描述长度 (MDL)** 方法密切相关。对数证据与通过模型 ℳᵢ 编码数据的最短消息的比特数相关联（例如文献 [45]）。

## 类 II 最大似然

注意，证据是在积分掉参数 **θ** 后的边际似然函数。为了将其与 MAP 方法区分开，当证据函数关于一组未知参数被最大化时，通常称为 **广义最大似然** 或 **类 II 最大似然**，有时也称为 **经验贝叶斯**。回顾 [备注 12.1](#Chp012_583-634_B9780443292385000184.xhtml#enun0010)，MAP 被称为类 I 估计器。
