前述算法有时被称为*单阶段*辅助粒子滤波器，以区别于原始文献 [36] 中提出的*双阶段*辅助粒子滤波器。后者包含一个额外的重采样步骤以获得等权重样本。实验验证表明，单阶段版本性能更优，且应用更广泛。有报道称，对于高信噪比场景，辅助粒子滤波器相比 [算法 17.5](#Chp017_855-884_B9780443292385000238.xhtml#enun0040) 可带来性能提升；但在高噪声环境下，其性能会下降（参见文献 [1]）。关于辅助滤波器性能与分析的更多结果，可参考文献 [14, 24, 37]。

### 备注 17.3

* 除前述算法外，多年来还提出了许多变体，旨在克服粒子滤波器的主要局限性——方差增加与样本贫化问题。在*重采样-移动* [18] 和*分块采样* [15] 中，不仅在时刻 $n$ 对 $\mathbf{x}_n^{(i)}$ 进行采样，还试图结合新到达的观测 $\mathbf{y}_n$，修改固定窗口大小 $L$ 内（即 $[n-1, n-L+1]$）的历史值。在*正则化粒子滤波器* [34] 中，在 [算法 17.5](#Chp017_855-884_B9780443292385000238.xhtml#enun0040) 的重采样阶段，不再从离散分布采样，而是从平滑近似中抽取样本：

```
p(\mathbf{x}_n|\mathbf{y}_{1:n}) \approx \sum_{i=1}^{N} W_n^{(i)} K(\mathbf{x}_n - \mathbf{x}_n^{(i)}),
```

其中 $K$ 为平滑核密度函数。文献 [28, 29] 利用高斯分布近似后验；与传统扩展卡尔曼滤波器不同，其更新与滤波通过粒子传播实现。更多粒子滤波相关信息，可参考教程类文献 [1, 10, 16]。

* *Rao-Blackwell化* 是一种降低蒙特卡洛采样法估计方差的技术（如文献 [4]）。该技术也被应用于动态系统的粒子滤波中。实践中常见部分状态在给定非线性状态下呈条件线性。核心思想是将这些线性状态视为干扰参数，并将其从估计过程中*边缘化*掉。非线性状态的粒子随机传播，随后利用卡尔曼滤波器对线性部分进行处理（参见文献 [11, 13, 26]）。
