### 13.6.1 尖峰和平板法

这是一种施加稀疏性的经典技术 [43,51]。让我们考虑熟悉的回归模型，

`y = θ^(T)ϕ(x) + η` (13.64)

引入了一组新的辅助二值*指示*变量，`s[k] ∈ {0, 1}, k = 0, 1, …, K − 1`。另设施加在 `θ` 上的先验为高斯分布，`p(θ) = N(θ|0, σ²I)`。顾名思义，指示变量控制公式 [(13.64)](#Chp013_635-716_B9780443292385000196.xhtml#deq93) 求和中参数的存在或缺失。例如，若 `s[k] = 1`，则相应参数 `θ[k]` 存在；若 `s[k] = 0`，则 `θ[k]` 被移除；这就是向模型施加稀疏性的方式。为此，采用了指示变量的联合伯努利先验分布（第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章），即

```
P(s) = ∏_{k=0}^{K-1} p^{s_k} (1-p)^{1-s_k}
```
(13.65)
