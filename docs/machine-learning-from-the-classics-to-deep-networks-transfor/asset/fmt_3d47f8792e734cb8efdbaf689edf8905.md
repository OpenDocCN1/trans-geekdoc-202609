
where, for simplicity, we have assumed that `z[n]` and `z[n]'` have been centered to zero mean values. The loss function for optimizing with respect to the involved parameters is selected so that the normalized cross-correlation matrix, `C`, is as close as possible to the identity matrix, `I`. In other words, the diagonal elements, `C[ii]`, to be as close as possible to one, and the off-diagonal elements, `C[ij]` for `i ≠ j`, to be as close as possible to zero. Such a loss function can be formulated as

```
L := Σ_i (1 - C_ii)^2 + λ Σ_i Σ_{j, j ≠ i} C_ij^2
```
(19.54)

Minimizing `L` forces the diagonal elements to be close to 1 and at the same time the off-diagonal ones to be close to 0, and `λ` is a user-defined regularization parameter that weighs the relative importance of the two terms. As it is pointed out in [202], trying to equate all the diagonal elements in the *invariance* term to 1 is equivalent to increasing the correlation between all elements, `z[i]` and `z[i]'` in the same (*i*th) dimension of the two vectors. In other words, the minimization task forces, via this invariance term, to make the final output embeddings of the two branches invariant to the distortions applied by the input transformations. At the same time, the *redundancy reduction* term, by trying to zero the off-diagonal elements of the cross-correlation matrix, decorrelates the vector components at different vector dimensions. As a consequence, the output units contain non-redundant information about the input sample. The redundancy term could be seen as playing a similar role as the denominator in the contrastive loss function, Eq. (19.53), that tries to increase dissimilarity among negative pairs. In [202], it is shown that the loss function in Eq. (19.54) is an instantiation of the information bottleneck objective [184].

In [202], the encoder networks were implemented via the `ResNet-50` convolutional network, giving rise to 2048-dimensional vector representations. For the projector networks, multilayer neural networks were used with three linear layers, each of 8192 nodes width. The first two layers were followed by batch normalization and then `ReLU` activations.

The name Barlow twins honors the great neuroscientist H. Barlow, who stated that the goal of the sensory system in our brains is to *encode* highly redundant inputs to a code that comprises statistically independent components, [16].

The techniques known as *whitening MSE* (W-MSE), [53], and *variance-invariance-covariance regularization* (VICReg), [15], are in the same line as the Barlow twins but they employ alternative loss functions. In the latter one, a comparative performance study of a number of self-supervised techniques within the framework of computer vision is provided.

## Remarks 19.11

*   So far in our discussion, we focused on SSL techniques that are based on a single modality. However, multi-modal approaches have also been proposed. For example, in the *contrastive language-image pretraining* (CLIP), [149], and *a large-scale image and noisy-text embedding* (ALIGN), [95], methods, image-caption pairs are used to learn a joint embedding space for images and captions. Images and corresponding captions feed separate encoders that encode each modality into a fixed-length embedding vector. The embeddings of the image-caption pairs are aligned, whereas other combinations are repelled. Thus, it is no longer required to generate multiple augmented views. Following the contrastive learning rationale, semantically meaningful representations are learned by observing similar captions that re-occur with similar images. CLIP slightly deviates from the generic scheme of Fig. 19.16. The upper branch involves only the encoder `f[θ]` and does not use a predictor network, `g[ϕ]`. The network `g[ξ]'` plays the role of an encoder in the lower branch. We will return to the CLIP model in Section 19.7.7.
