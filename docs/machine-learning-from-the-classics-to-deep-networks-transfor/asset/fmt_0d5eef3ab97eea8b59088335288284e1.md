
$$f^{\ast}(\mathbf{\xi}) = \max\limits_{\mathbf{x}}\left\{ \mathbf{\xi}^{T}\mathbf{x} - f(\mathbf{x}) \right\},$$

is called the *conjugate* of *f*. The domain of the conjugate function consists of all $\mathbf{\xi} \in \mathbb{R}^{(l)}$ for which the maximum is finite. A notable property of the conjugate function is its *convexity*; this is true whether or not *f* is convex. The convexity is the outcome of the point-wise maximization of a family of (convex with respect to $\mathbf{\xi}$) affine functions [12].

Maximizing Eq. [(13.78)](#Chp013_635-716_B9780443292385000196.xhtml#deq114) with respect to $\mathbf{x}$ results in a value of $\mathbf{x}^{\ast}$, such that

$$\mathbf{x}^{\ast} : \nabla f(\mathbf{x}^{\ast}) = \mathbf{\xi}, \tag{13.79}$$

which leads to the value

$$f^{\ast}(\mathbf{\xi}) = \mathbf{\xi}^{T}\mathbf{x}^{\ast} - f(\mathbf{x}^{\ast}). \tag{13.80}$$

Eqs. [(13.79)](#Chp013_635-716_B9780443292385000196.xhtml#deq115) and [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116) provide the geometric interpretation of the conjugate function. The graph of the linear function $\mathbf{\xi}^{T}\mathbf{x}$ defines a hyperplane whose direction is controlled by $\mathbf{\xi}$; the latter is now equal to $\nabla f(\mathbf{x}^{\ast})$, which defines the direction of the tangent hyperplane of the graph of $f(\mathbf{x})$ at $\mathbf{x}^{\ast}$. This tangent hyperplane is described by

$$g(\mathbf{x}) = f(\mathbf{x}^{\ast}) + (\mathbf{x} - \mathbf{x}^{\ast})^{T}\nabla f(\mathbf{x}^{\ast}),$$

or using Eq. [(13.80)](#Chp013_635-716_B9780443292385000196.xhtml#deq116),

$$g(\mathbf{x}) = \mathbf{\xi}^{T}\mathbf{x} - f^{\ast}(\mathbf{\xi}). \tag{13.81}$$
