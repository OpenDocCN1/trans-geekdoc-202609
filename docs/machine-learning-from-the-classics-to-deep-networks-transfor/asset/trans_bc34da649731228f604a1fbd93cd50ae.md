
如果将无条件模型替换为类条件扩散模型，并施加分类器引导原理，类似的论点依然成立。与仅使用类条件模型相比，这可以进一步提高样本质量。在这种情况下，公式[(19.82)](#Chp019_997-1102_B9780443292385000251.xhtml#deq160)中涉及的均值和协方差矩阵应替换为其条件对应项，即 `μ_θ*(x_t, t, y)` 和 `Σ_θ*(x_t, t, y)`。

如果从扩散模型的基于分数的公式出发，并忽略对 `x_0` 的符号依赖，则起点为条件分布，

```
q(x_t|y) = q(x_t)q(y|x_t) / q(y).
```

对上式两边取对数再求梯度，可得

```
∇_x_t ln q(x_t|y) = ∇_x_t ln q(x_t) + ∇_x_t ln q(y|x_t),  (19.79)
```
