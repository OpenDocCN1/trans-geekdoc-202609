
# ADMM 算法

## 问题定义

最小化关于 **x**, **y** 的目标函数：

$$f(\mathbf{x}) + g(\mathbf{y})$$

约束条件：

$$\mathbf{x} - \mathbf{y} = 0$$

## 增广拉格朗日函数

增广拉格朗日函数定义为：

$$L_{\lambda}(\mathbf{x},\mathbf{y},\mathbf{z}) := f(\mathbf{x}) + g(\mathbf{y}) + \frac{1}{\lambda}\mathbf{z}^{T}(\mathbf{x} - \mathbf{y}) + \frac{1}{2\lambda}||\mathbf{x} - \mathbf{y}||^{2}$$

其中我们用 $\mathbf{z}$ 表示对应的拉格朗日乘子。

等价形式为：

$$L_{\lambda}(\mathbf{x},\mathbf{y},\mathbf{z}) := f(\mathbf{x}) + g(\mathbf{y}) + \frac{1}{2\lambda}||\mathbf{x} - \mathbf{y} + \mathbf{z}||^{2} - \frac{1}{2\lambda}||\mathbf{z}||^{2}$$
