
## 11.10 最优边界分类：支持向量机

从最小化分类错误的意义上讲，最优分类器是第 [7](#Chp007_293-342_B9780443292385000135.xhtml) 章讨论的贝叶斯分类器。该方法属于生成式学习家族，需要已知潜在的概率分布。如果这些分布未知，另一种途径是求助于判别式学习技术，采用一个实现相应分类器的判别函数 `f`，并尝试对其进行优化，以最小化相应的经验风险，即

```
ξ_n = λ_n / 2,  n = 1,2,…,N.
```
![Equation](images/B9780443292385000172/si310.png)(11.54)

为了得到拉格朗日乘子，将公式 [(11.53)](#Chp011_519-582_B9780443292385000172.xhtml#deq132) 和 [(11.54)](#Chp011_519-582_B9780443292385000172.xhtml#deq133) 代入公式 [(11.52)](#Chp011_519-582_B9780443292385000172.xhtml#deq131)，从而得到问题的对偶形式，即

```
maximize with respect to λ  Σ_{n=1}^N λ_n y_n - 1/(4C) Σ_{n=1}^N Σ_{m=1}^N λ_n λ_m κ(x_n, x_m) - 1/4 Σ_{n=1}^N λ_n^2,
```
![Equation](images/B9780443292385000172/si311.png)(11.55)

其中我们根据核技巧，已用核运算替换了 `x_n^T x_m`。通过简单的代数运算即可得到（参见 [98] 和问题 [11.9](#Chp011_519-582_B9780443292385000172.xhtml#o0070)）

```
λ = 2C (K + C I)^(-1) y,
```
![Equation](images/B9780443292385000172/si313.png)(11.56)

将其与公式 [(11.53)](#Chp011_519-582_B9780443292385000172.xhtml#deq132) 结合并涉及核技巧，我们得到核岭回归的预测规则，即

```
ŷ(x) = y^T (K + C I)^(-1) κ(x),
```
![Equation](images/B9780443292385000172/si314.png)(11.57)

这与公式 [(11.27)](#Chp011_519-582_B9780443292385000172.xhtml#deq88) 相同；然而，通过这条路径不需要假设 `K` 的可逆性。求解核岭回归的高效方案已在文献 [117,118] 中提出。
