

### 核主成分分析

*   给定特征向量 **x** ∈ ℝ<sup>l</sup>，通过计算其在每个主特征向量上的 *m* 个投影，获得其低维表示，

```
z_k := ⟨ϕ(x), u_k⟩ = ∑_{n=1}^N a_{kn} κ(x, x_n), k = 1,2,…,m.
```

公式 (20.106) 中给出的操作对应于输入空间中的*非线性映射*。请注意，与线性 PCA 相反，主特征向量 **u**<sub>k</sub>，*k* = 1,2,…,m，并未显式计算。我们所知道的只是沿这些方向的各自（非线性）投影 *z*<sub>k</sub>。然而，归根结底，这正是我们最终感兴趣的。

#### 备注 20.7

*   核 PCA 等价于在 RKHS ℍ 中执行标准 PCA。可以证明，如 PCA 所讨论的，与主特征向量相关的所有性质对于核 PCA 仍然有效。即：(a) 主特征向量方向最优地保留了大部分方差；(b) 用 *m* 个主特征向量来近似 ℍ 中的向量（函数）时，其均方误差 (MSE) 相对于任何其他 *m* 个方向而言是最小的；(c) 在特征向量上的投影是不相关的 [161]。

*   回顾备注 20.1，度量多维缩放 (MDS) 方法需要 Gram 矩阵的特征分解。因为核矩阵是在相应 RKHS 中的 Gram 矩阵，核 PCA 可被视为 MDS 的核化版本，其中输入空间中的内积已被 Gram 矩阵中的核运算所取代。

*   请注意，核 PCA 方法不考虑数据所在流形的显式底层结构。

*   一种称为核熵成分分析 (ECA) 的核 PCA 变体已在文献 [103] 中提出，其中选择主方向是为了最大化 Renyi 熵。

#### 拉普拉斯特征映射

该方法的出发点是假设数据集 𝒳 中的点位于一个光滑流形 ℳ ⊃ 𝒳 上，其内在维数等于 *m* < *l* 且嵌入在 ℝ<sup>l</sup> 中，即 ℳ ⊂ ℝ<sup>l</sup>。维数 *m* 由用户作为参数给出。相反，核 PCA 中不需要这一点，在那里 *m* 是主成分的数量，在实践中，通过使 *λ*<sub>m</sub> 和 *λ*<sub>m+1</sub> 之间的间隙具有“较大”值来确定。
