
一旦我们脱离设计分类器的贝叶斯概念（正如我们即将看到的，这将出于多种原因而进行），则可以采用不同族的函数来选择 `g(x)`，具体形式将通过不同的优化准则获得，这些准则不一定与错误概率/平均风险相关。

在后续内容中，我们将重点研究贝叶斯分类器这一特殊情况下决策超曲面所呈现的形式，以及类别中的数据服从高斯概率密度函数（PDF）的情况。这能进一步揭示分类器划分特征空间的方式，并且在特定场景下，也将引出贝叶斯分类器的一些有用实现。为求简化，重点将放在二分类任务上，但结果可平凡地推广到更一般的 `M` 分类情况。

### 7.3.1 高斯分布情况

假设每个类别中的数据服从高斯概率密度函数，因此

```
p(x|ω_i) = 1/((2π)^(l/2)|Σ_i|^(1/2)) exp( -1/2 (x - μ_i)^T Σ_i^(-1) (x - μ_i) ), i = 1,2,...,M.
```

由于对数函数是单调递增的，它不影响函数最大值出现的位置。因此，考虑到高斯分布的指数形式，如果用以下函数来表达贝叶斯判据，计算将会更加方便：

```
g_i(x) := ln(p(x|ω_i)P(ω_i)) = ln p(x|ω_i) + ln P(ω_i), i = 1,2,…,M,
```

我们寻找使相应函数取得最大值的类别。此类函数也被称为*判别函数*。
