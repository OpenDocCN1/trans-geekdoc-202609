### 18.13.1 通过时间的反向传播

训练 RNN 遵循与第 [18.4.1](#Chp018_885-995_B978044329238500024X.xhtml#s0040) 节中讨论的用于训练前馈神经网络的反向传播算法相似的基本原理。毕竟，RNN 可以被视为一个具有 *N* 层的前馈网络。顶层是时间点 *N* 处的层，第一层对应时间 *n* = 1。一个区别在于 RNN 中的隐藏层也会产生输出，即 $\widehat{\mathbf{y}}_n$，并直接由输入馈送。然而，就训练而言，这些差异不影响主要基本原理。

通过梯度下降方案学习未知的参数矩阵和向量，这与方程(18.10)和(18.11)一致。结果表明，代价函数关于未知参数所需的*梯度*通过从*最晚*时间点 *N* 开始，并*逆时间*向后 *n* = *N* - 1, *N* - 2, ..., 1 递归地进行。这就是该算法被称为*通过时间的反向传播*（BPTT）的原因。

代价函数是时间 *n* 上相应损失函数贡献之和，这些贡献取决于 **h**[*n*]、**x**[*n*] 的相应值，即

```
$J(U,W,V,\mathbf{b},\mathbf{c}) = \sum\limits_{n = 1}^{N}J_{n}(U,W,V,\mathbf{b},\mathbf{c}).$
```

```
$J_{n}(U,W,V,\mathbf{b},\mathbf{c}) := - \sum\limits_{k}y_{nk}\ln{\widehat{y}}_{nk},$
```
