

## Conditional Generative Adversarial Networks

### Objective Function

The objective function of the conditional GAN is defined as:

```
J_c(θ_g, θ_d) = E_{p_r(x)}[ln D(x|c; θ_d)] + E_{p_z(z)}[ln(1 - D(G(z|c; θ_g); θ_d))]
```

### Related Variants

*   **Auxiliary Classifier GAN (AC-GAN)** [137]: Proposed the concept of an auxiliary classifier. The class conditional encoding vector `c` augments the input to the generator. The discriminator receives real/fake samples as input and provides two types of predictions: judging whether the input is real or fake, and estimating the corresponding class probabilities. For an `M` classification task, the discriminator has `M + 1` outputs: one for real/fake prediction, and `M` for class probabilities. This is claimed to produce higher quality samples by adding more structure to the GAN latent space.

*   **Information Maximizing GAN (InfoGAN)** [33]: Unlike conditional GANs and AC-GANs that rely on predefined conditional information `c`, the input to the InfoGAN generator contains two vectors: one for random noise `z`, and one for random attributes `c`. The discriminator receives real/fake samples and outputs two types of results: a) predicting whether the sample is real or fake; b) estimating the conditional attribute sample `c` of the input. In this way, InfoGAN attempts to identify and disentangle salient attributes in a completely unsupervised manner. For example, InfoGAN is claimed to successfully disentangle writing style from digit shape on the MNIST dataset, and pose from lighting in 3D rendered images.

*   **StyleGAN** [100]: The core idea is to learn to separate high-level attributes (such as pose and identity of a face) from low-level/stochastic variation attributes (such as hair, freckles) in a completely unsupervised manner. To this end, it uses two sets of (latent) random vectors: one for noise (e.g., `z`), and one for style (e.g., `w`). Furthermore, this information is not fed directly into the network but is injected into the intermediate layers of the generator (at different scales). In this way, the generator adjusts various image features at different scales, adjusting the "style" of the image at each convolutional layer. The input to the generator starts from a learnable constant. The style random variable `w` is produced by the output of a separate fully connected neural network, whose input is driven by another set of random variables. The rationale for this nonlinear mapping is to allow the network to learn to disentangle the various aspects of style, so that each dimension of the style variable corresponds to an independent real-world attribute (e.g., head pose or lighting).

*   Interestingly, many of the above innovations have been adopted in diffusion models, see Section [19.7](#Chp019_997-1102_B9780443292385000251.xhtml#s0235).

*   Besides generating images, GANs have also been used as generative models for other modalities such as audio, video, EEG, molecular graphs, etc., see [67].

## Example 19.1: Basic Experiment for Generating Handwritten Character Images

This example aims to describe a basic experiment using a GAN to generate handwritten character images. For this, the generator and discriminator networks need to be designed.

*   **Generator Network**: Contains 100 input nodes, driven by i.i.d. Gaussian noise samples with zero mean and unit variance. The network contains three hidden layers with 256, 512, and 1024 neurons, respectively. The nonlinear function used by the hidden layer neurons is Leaky ReLU (see Section [18.6.1](#Chp018_885-995_B978044329238500024X.xhtml)), `α = 0.2`. The output layer has 784 units, with the output nonlinear function being the tanh function. The number of output units is set equal to the dimension of the vectorized images in the MNIST image dataset.^([^(131)](#fn131))
