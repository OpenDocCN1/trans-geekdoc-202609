
# 扩散 LMS 算法

到达公式 [(5.85)](#Chp005_177-248_B9780443292385000111.xhtml#deq188) 的一条略有不同的途径，是将梯度下降方案解释为当前可用估计周围代价函数正则化线性化的最小化器。所使用的正则化项为 `||θ − θ^(i−1)||²`，它试图使新的更新尽可能接近当前可用的估计。在分布式学习的背景下，我们可以用邻域内可用估计的凸组合来代替 `θ^(i−1)` [26,27,84]。

我们现在准备好陈述扩散 LMS (DiLMS) 的第一个版本，方法是在公式 (5.86) 和 (5.87) 中用瞬时观测值替换期望，并将迭代解释为时间更新。

## 算法 5.7：自适应-组合扩散 LMS

*   **初始化**
    1.  **对于** `k = 1, 2, …, K`，**执行**
        *   `θ[k](−1) = 0 ∈ ℝ^l`；或任何其他值。
    2.  **结束 For**
    3.  选择 `μ[k]`，`k = 1, 2, …, K`；一个很小的正数。
    4.  选择 `C`：`C1 = 1`
    5.  选择 `A`：`A^T 1 = 1`

*   **对于** `n = 0, 1, …`，**执行**
    1.  **对于** `k = 1, 2, …, K`，**执行**
        *   **对于** `m ∈ N[k]`，**执行**
            *   `e[k, m](n) = y[m](n) − θ[k]^T(n−1)x[m](n)`；对于复值数据，将 `T → H` 更改。
        *   **结束 For**
