
可逆性是通过审慎选择网络的层（流）来施加的。每一层，*k* = 1, 2, …, *K*，都实现了一个相应的*可逆*变换 `f[k](·;θ[k])`。整体函数 `f` 和 `f^(−1)` 作为各个单独函数的复合而得出，即：

```
f = f[K](f[K−1](…f[2](f[1]).…)), and f^(−1) = f[1]^(−1)(f[2]^(−1)(…f[K−1]^(−1)(f[K]^(−1))…))
```

且 `θ` := [`θ[1]^(T)`, …, `θ[K]^(T)`]^(T)。换句话说，一旦参数学习完成，输入分布 `p[x](x)` 的近似就以*逐步*层层递进的方式实现，起始于（例如）标准高斯概率密度函数。设计归一化流的关键在于对这些可逆函数进行建模和选择。为此，已经提出了各种方法和技术。更多细节请参见，例如，[139] 及其参考文献。

## 19.3 Transformers

到目前为止，我们的讨论围绕三个建模概念展开，它们作为构建深度网络的基本工具：全连接前馈神经网络、卷积网络和循环神经网络。现在，我们将关注转向被称为 *transformers* 的最新趋势。所谓 Transformer 网络背后的主要基本原理是注意力机制，该机制已在 18.13.2 节中介绍并使用过。在当前版本编撰之际，Transformers 构成了深度学习领域的*最先进水平*。为了阐述实现此类网络的基本思想和相关架构，我们将沿着历史发展脉络，从自然语言处理（NLP）应用领域切入。
