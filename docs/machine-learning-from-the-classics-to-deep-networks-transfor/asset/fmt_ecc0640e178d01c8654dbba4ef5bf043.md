
**y** : = [*y*[1], *y*[2], …, *y*[*N*]]^(*T*).

![Equation](images/B9780443292385000093/si64.png)(3.16)

Indeed,

```
X^T X = [x_1, ..., x_N] [x_1^T; ...; x_N^T] = sum_{n=1}^N x_n x_n^T
```

![Equation](images/B9780443292385000093/si65.png)

and similarly,

```
X^T y = [x_1, ..., x_N] [y_1; ...; y_N] = sum_{n=1}^N y_n x_n
```

![Equation](images/B9780443292385000093/si66.png)

Thus, finally, the LS estimate is given by

![Equation](images/B9780443292385000093/fx001.jpg)(3.17)

assuming, of course, that (*X*^(*T*)*X*)^(−1) exists.

![Equation](images/B9780443292385000093/si67.png)

In other words, the obtained estimate of the parameter vector is given by a *linear set of equations*. This is a major advantage of the squared error loss function, when applied to a linear model. Moreover, this solution is *unique*, provided that the (*l* + 1) × (*l* + 1) matrix *X*^(*T*)*X* is invertible.

![Equation](images/B9780443292385000093/si69.png)

The uniqueness is due to the parabolic shape of the graph of the sum of squared errors cost function. This is illustrated in [Fig. 3.3](#Chp003_65-117_B9780443292385000093.xhtml#f0020) for the two-dimensional space. It is readily observed that the graph has a unique minimum. This is a consequence of the fact that the sum of squared errors cost function is a strictly convex one. Issues related to convexity of loss functions will be treated in more detail in Chapter [8](#Chp008_343-416_B9780443292385000147.xhtml).
