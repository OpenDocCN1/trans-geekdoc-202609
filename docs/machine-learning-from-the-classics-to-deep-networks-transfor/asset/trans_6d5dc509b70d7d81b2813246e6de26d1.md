
对应的连接树可以从[图 16.15](#Chp016_805-853_B9780443292385000226.xhtml#f0080)中的图平凡地获得。将有向连接替换为无向连接并考虑大小为二的团，得到[图 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)A 中的图。然而，由于所有 `y[n]` 变量均被观测到（*实例化*），且不需要边缘化，它们的乘法贡献可以被相应的条件概率吸收，从而得到[图 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)B 的图。或者，如果考虑节点 `(x[1], y[1])` 和 `(x[n-1], x[n], y[n])`，`n = 2, 3, …, N`，形成与以下势函数相关联的团，也可以获得此连接树：

```
ψ[1](x[1], y[1]) = P(x[1])p(y[1]|x[1]) (16.36)
```

和

```
ψ[n](x[n-1], y[n], x[n]) = P(x[n]|x[n-1])p(y[n]|x[n]), n = 2, …, N. (16.37)
```

[图 16.19](#Chp016_805-853_B9780443292385000226.xhtml#f0100)B 的连接树是通过从团中消除节点（从 `x[1]` 开始）得到的。注意归一化常数等于一，`Z = 1`。
