
*p*(**y**) = 𝒩(**y**|0, 𝒦 + *σ*[*η*]²*I*).

![Equation](images/B9780443292385000196/si661.png) (13.139)

从两个独立高斯变量之和也是高斯分布这一事实，以及均值和协方差矩阵可直接从公式 [(13.138)](#Chp013_635-716_B9780443292385000196.xhtml#deq225) 获得这一事实来看，这也是显而易见的。

要获得 *p*(*y*|**x**, **y**)，我们可以使用公式 [(13.139)](#Chp013_635-716_B9780443292385000196.xhtml#deq229) 并递归地应用它。在此将可用观测值的数量 *N* 显式地引入符号中也会很有用，并写为

```
\mathbf{y}_{N + 1}^{\ } = \begin{bmatrix} y \\ \mathbf{y}_{N} \\ \end{bmatrix},\quad\mathbf{y}_{N}: = {\lbrack y_{1},\ldots,y_{N}\rbrack}^{T}.
```

![Equation](images/B9780443292385000196/si662.png)

根据公式 [(13.139)](#Chp013_635-716_B9780443292385000196.xhtml#deq229)，**y**[*N* + 1] 服从高斯分布

*p*(**y**[*N* + 1] | 0, *Σ*[*N* + 1]),

![Equation](images/B9780443292385000196/si664.png)

其中

*Σ*[*N* + 1] := 𝒦[*N* + 1] + *σ*[*η*]²*I*[*N* + 1].

![Equation](images/B9780443292385000196/si665.png)

然后，根据乘法法则，我们有

```
p(y|\mathbf{y}_{N}) = \frac{p(\mathbf{y}_{N + 1})}{p(\mathbf{y}_{N})}.
```

![Equation](images/B9780443292385000196/si666.png) (13.140)

然而，由于联合 PDF 是高斯分布，公式 [(13.140)](#Chp013_635-716_B9780443292385000196.xhtml#deq233) 中的条件分布也是高斯分布。通过对矩阵 *Σ*[*N* + 1] 进行分块（参见第 [12](#Chp012_583-634_B9780443292385000184.xhtml) 章附录，公式 (12.134) 和 (12.133)），可以计算出相应的均值和方差。
