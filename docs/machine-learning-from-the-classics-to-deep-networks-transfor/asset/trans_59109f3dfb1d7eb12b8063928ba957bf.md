### 备注 3.1

*   点集 $(\hat{y}[n], x[n1], \dots, x[nl])$，$n = 1, 2, \dots, N$，位于 $\mathbb{R}^{l+1}$ 空间中的一个*超平面*上。等价地说，它们位于一个穿过原点的超平面上，因此，正如之前所解释的，当将 $\theta[0]$ 吸收进 $\boldsymbol{\theta}$ 时，它在扩展空间 $\mathbb{R}^{l+2}$ 中是一个线性子空间。
*   请注意，即使真实系统结构不遵循公式 [(3.9)](#Chp003_65-117_B9780443292385000093.xhtml#deq11) 中的线性模型，公式 [(3.11)](#Chp003_65-117_B9780443292385000093.xhtml#deq14) 中的预测模型仍可使用。例如，$y$ 和 $\mathbf{x}$ 之间的真实依赖关系可能是非线性的。在这种情况下，基于公式 [(3.11)](#Chp003_65-117_B9780443292385000093.xhtml#deq14) 模型对 $y$ 的预测可能并不令人满意。这完全取决于我们采用的模型与生成数据的真实系统结构之间的偏差程度。
*   模型的预测性能还取决于噪声变量的统计特性。这是一个重要问题。稍后我们将看到，取决于噪声变量的统计特性，某些损失函数和方法可能比其他方法更合适。
*   前两条备注表明，为了量化估计器的性能，需要一些相关准则。在第 [3.9](#Chp003_65-117_B9780443292385000093.xhtml#s0065) 节中，我们将介绍一些理论分析，以阐明与估计器性能相关的某些方面。
