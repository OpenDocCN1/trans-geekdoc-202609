

## 图 5.25 先适应后组合

(A) 在步骤 1 中，在交换接收到的观测值之后进行适应。(B) 在步骤 2 中，节点交换其局部计算的估计值以获得更新后的估计值。

如果颠倒这两个步骤的顺序，先执行组合再执行适应，则会得到一种不同的方案。

## 算法 5.8：先组合后适应扩散 LMS

### 初始化

1. **对于** `k = 1, 2, …, K`，**执行**
   * `θ_k(-1) = 0 ∈ ℝ^l`；或任何其他值。
2. **结束 For**
3. 选择 `C`：`C1 = 1`
4. 选择 `A`：`A^T 1 = 1`
5. 选择 `μ[k]`，`k = 1, 2, …, K`；取较小值。

### 主循环

**对于** `n = 0, 1, 2, …`，**执行**

1. **对于** `k = 1, 2, …, K`，**执行**
   * `ψ_k(n-1) = ∑[m ∈ N_k] a[mk] θ_m(n-1)`
2. **结束 For**
3. **对于** `k = 1, 2, …, K`，**执行**
   * **对于** `m ∈ N_k`，**执行**
     * `e[k, m](n) = y[m](n) - ψ_k^T(n-1) x[m](n)`；对于复值数据，将 `T → H` 变更。
   * **结束 For**
