#### IBP 的性质

*   `Z` 的非零行数 `K₊` 也服从参数为 `αH_N` 的泊松分布，即：

    ```
    P(K₊; αH_N) = (αH_N)^K₊ exp(-αH_N) / K₊!
    ```

*   当 `K → ∞` 时，矩阵 `Z` 保持*稀疏*。事实上，非零元素的数量服从参数为 `αN` 的泊松分布，其均值为 `αN`。此外，高于均值的非零值的概率呈*指数级*下降。另外，考虑到泊松分布的均值等于其参数，平均选择的菜肴数（使用的特征数）等于 `αH_N`（例如 [23]）。也就是说，对于固定的 `N`，浓度参数越大，选择的菜肴越多。
