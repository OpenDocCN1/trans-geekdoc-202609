
算法的一大特点是输出胶囊 **`v_j`**，通过迭代调整其与上一层变换后的输出/胶囊的*相似性*或*一致性*来生成。这是通过更新 **`b_ij`** 来实现的，其更新方式根据 **`v_j`** 与 **`û_{j|i}`** 之间的相似性（内积）来“加强”或“削弱”它们的值。请注意，每次迭代开始时都将 **`b_ij = 0`**，即它们从耦合系数的等概率值开始。也就是说，每个 `i` 相对于所有类别具有相等的概率。然后，根据计算出的输出与相应变换后的输入胶囊之间的匹配程度来更新它们的值。简而言之，耦合系数将信息从低层*路由*到高层。较大的 **`c_ij`** 值意味着第 `i` 个低层胶囊与上层第 `j` 个胶囊的连接更强。重要的是要强调，耦合系数的值*不是*通过试图最小化代价函数的反向传播来调整的。代价函数通过梯度的反向传播，用于调整 **`W_ij`** 矩阵的元素以及卷积的滤波器。动态路由算法是生成输出的算法。在*训练*和*测试*期间均是如此，给定 **`W_ij`** 矩阵的值。正如[算法 18.4](#Chp018_885-995_B978044329238500024X.xhtml#enun0085)所示，似乎三次迭代就足够了。

在文献 [174] 中，还结合了公式 [(18.76)](#Chp018_885-995_B978044329238500024X.xhtml#deq142) 中的损失，使用了*基于重构的正则化项*，以形成训练数据上的代价。训练期间，与正确类别 `k` 相关联的输出胶囊 **`v_k`** 被提供给一个全连接网络作为输入，该网络充当解码器以重构相应的输入。训练全连接网络的损失函数是输入图像像素与输出之间平方差之和，使用 Sigmoid 输出非线性。也就是说，用于训练胶囊网络的损失函数变为：

```
loss = ℒ + a × reconstruction error
```

其中 **`ℒ`** 由公式 [(18.76)](#Chp018_885-995_B978044329238500024X.xhtml#deq142) 给出，且 **`a = 0.005`**。

文献 [174] 中针对 MNIST 数据集进行数字识别的实验验证了输出胶囊的不同维度（共 16 个）与输入数字的不同特征相关联，例如粗细、倾斜度和宽度。在文献 [76] 原始工作的扩展中，动态路由算法采用了 EM 类型的参数。

尽管胶囊网络为小型数据集（如 MNIST）提供了最先进的结果，但它们在大型数据集上的性能仍有待验证。目前，似乎它们已被 Transformer 网络（第 [19](#Chp019_997-1102_B9780443292385000251.xhtml) 章）所取代。然而，有趣的是，它们与 Transformer 共享一些显著特征。首先，它们通过 **`W`** 矩阵执行变换，此外，向高层的路由基于相似性度量。未来将决定此类网络是否仍有发挥空间！

## 18.16 深度神经网络：一些结束语

深度架构主题自本世纪初以来一直是研究热点，且兴趣持续增长。在单章中不可能涵盖所有技术、所有算法变体及相关文献，特别是在特定应用框架内。前几节回顾了主要方向和算法，它们构成了脊柱，围绕其开发了大量变体。此外，作者认为前文讨论的技术和模型构成了基础知识，初学者掌握这些后方能深入。一些相关的教程论文见 [36, 73, 115, 178]。第 [19](#Chp019_997-1102_B9780443292385000251.xhtml) 章介绍了机器学习的一些最新进展，它们建立在我们之前讨论的许多概念之上。
