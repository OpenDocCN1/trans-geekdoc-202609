### 5. 构造向量
构造向量 `\widehat{\mathbf{p}} \in \mathbb{R}^{r_{m_{\ast}}}`，其第 `j` 个分量（`j = 1, ..., r[m[*] ]`）由下式给出：

```
\widehat{p}_j := |\theta_{\tau(j)}| - \frac{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)} |\theta_{\tau(i)}| - \rho}{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)}^2} w_{\tau(j)}.
```

### 6. 使用逆映射
使用逆映射 `\tau^{-1}` 将元素 `\hat{p}[j]` 插入到 `l` 维向量 `\mathbf{p}` 的 `\tau^{-1}(j)` 位置，`\forall j \in {1, 2, ..., r[m[*]]}`，其余位置填零。
