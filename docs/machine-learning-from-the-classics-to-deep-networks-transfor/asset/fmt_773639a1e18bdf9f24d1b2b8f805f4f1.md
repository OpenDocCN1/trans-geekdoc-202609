
where `g[k] = ℒ[k]'(θ[k − 1])` denotes the subgradient at time instant `k`. Also, the same matrix is used to weigh the gradient correction and the scheme has the form

```
θ[n] = P[C](G[n]^(1/2))(θ[n − 1] − μ[n]G[n]^(−1/2)g[n]).
```

The use of the (time-varying) weighting matrix accounts for the geometry of the data observed in earlier iterations, which leads to a more informative gradient-based learning. For the sake of computational savings, the structure of `G[n]` is taken to be diagonal. Different algorithmic settings are discussed in [38], alongside the study of the converging properties of the algorithm. The algorithm has inspired a number of versions that are currently popular in deep learning, see also Section [18.4.2](#Chp018_885-995_B978044329238500024X.xhtml).

### Example 8.8: The LMS Algorithm

Let us assume that

```
ℒ_n(θ) = 1/2 (y_n − θ^T x_n)^2,
```

and also set `C = ℝ^(l)` and `μ[n] = μ`. Then Eq. [(8.69)](#Chp008_343-416_B9780443292385000147.xhtml#deq144) becomes our familiar LMS recursion,

```
θ[n] = θ[n − 1] + μ(y[n] − θ[n − 1]^T x[n])x[n],
```

whose convergence properties have been discussed in Chapter [5](#Chp005_177-248_B9780443292385000111.xhtml).
