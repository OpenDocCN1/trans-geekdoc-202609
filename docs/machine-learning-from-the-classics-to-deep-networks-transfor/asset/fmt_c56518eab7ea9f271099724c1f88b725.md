
在 ℓ₁ 正则化的情况下，由于 ℓ₁ 范数中存在绝对值，最小化的拉格朗日函数不再可微。因此，在这种情况下，我们必须考虑子微分的概念。已知（第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章），如果零向量属于凸函数在某点的子微分集，则意味着该点对应于函数的最小值。对公式 [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml#deq8) 中定义的拉格朗日函数求子微分，并回忆可微函数的子微分集仅包含其梯度作为*单一*元素，由 ℓ₁ 正则化任务得到的估计值 ${\\widehat{\\mathbf{\\theta}}}\_{1}$ 必须满足

```
0 ∈ − 2X^(T)y + 2X^(T)Xθ + λ∂‖θ‖₁
```

其中 ∂ 代表子微分集（第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章）。如果 `X` 具有标准正交列，则上述方程可以逐分量写为：

```
0 ∈ − θ̂_LS,i + θ̂_1,i + (λ/2)∂|θ̂_1,i|, ∀ i,  (9.10)
```

其中函数 |⋅| 的子微分，由 [示例 8.4](#Chp008_343-416_B9780443292385000147.xhtml) 推导得出（第 [8](#Chp008_343-416_B9780443292385000147.xhtml) 章），如下所示：

```
∂|θ| = { { 1 },  if θ > 0,
       { { -1 },  if θ < 0,
       { [ -1, 1 ] },  if θ = 0. }
```
