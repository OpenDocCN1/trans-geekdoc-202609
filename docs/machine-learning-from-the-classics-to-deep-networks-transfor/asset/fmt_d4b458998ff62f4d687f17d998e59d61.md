
Following exactly the same steps as those that led to the derivation of Eq. [(9.13)](#Chp009_417-462_B9780443292385000159.xhtml) from Eq. [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml) (after replacing ${\widehat{\mathbf{\theta}}}_{LS}$ with $\widetilde{\mathbf{\theta}}$), we obtain

```
$\mathbf{\theta}^{(i)} = S_{\lambda\mu}(\widetilde{\mathbf{\theta}}) = S_{\lambda\mu}\left( \mathbf{\theta}^{(i - 1)} - \mu\frac{\partial J\left( \mathbf{\theta}^{(i - 1)} \right)}{\partial\mathbf{\theta}} \right)$
```

```
= S_{\lambda\mu}\left( \mathbf{\theta}^{(i - 1)} + \mu X^{(T)}\mathbf{e}^{(i - 1)} \right).
```

![Equation](images/B9780443292385000160/si88.png)(10.7)

This is very interesting and practically useful. The only effect of the presence of the nonsmooth $\ell_1$ norm in the loss function is an extra simple thresholding operation, which as we know is an operation performed *individually* on each component. It can be shown (e.g., [11,95]) that this algorithm converges to a minimizer $\mathbf{\theta}^*$ of the LASSO [(9.6)](#Chp009_417-462_B9780443292385000159.xhtml), provided that $\mu \in (0, 1/\lambda_{max}(X^{(T)}X))$, where $\lambda_{max}(\cdot)$ denotes the maximum eigenvalue of $X^{(T)}X$. The convergence rate is dictated by the rule

```
L(\mathbf{\theta}^{(i)}, \lambda) - L(\mathbf{\theta}^*, \lambda) \propto O(1/i),
```
