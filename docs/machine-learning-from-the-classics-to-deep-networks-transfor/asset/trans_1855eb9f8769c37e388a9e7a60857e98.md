
对于 `Σ[η] = σ[η]²I` 的情况，这与 LS 估计器一致。换句话说，在白高斯噪声假设下，LS 估计器变为*最小方差无偏估计器*（MVUE）。这是一个有力的结果。没有其他无偏估计器（*不一定是线性的*）会比 LS 估计器表现得更好。请注意，这一结果不仅在渐近意义上成立，对于有限数量的样本 `N` 也成立。如果希望进一步降低均方误差，则必须考虑*有偏*估计器，如正则化产生的估计器；这已在第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章中讨论过；另见 [16,50] 及其参考文献。
