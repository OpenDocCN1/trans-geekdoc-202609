**图 16.13** (A) 表示玻尔兹曼机的图的节点。(B) 平均场近似导致一个无边的图。虚线表示施加在节点之间的确定性关系，这些节点在近似之前与节点 `x[5]` 相连。

请注意，我们之前所说的无非是第 [13.2](#Chp013_635-716_B9780443292385000196.xhtml) 节中提出的变分 EM 算法的一个实例；事实上，公式 [(16.21)](#Chp016_805-853_B9780443292385000226.xhtml#deq42) 是 `Q[i]` 每个因子的 E 步结果，假设其余因子固定。

到目前为止，在本章中我们尚未提及如何获得描述图结构参数估计值这一重要任务；在我们当前的语境下，这些参数是 `θ[ij]` 和 `θ[i0]`，它们组成集合 `θ`。虽然参数估计任务在本章末尾讨论，但此时略述几句也无妨。让我们显式地给出对 `θ` 的依赖，并将涉及的概率表示为 `Q(𝒳^(l); μ, θ)`、`P(𝒳, 𝒳^(l); θ)` 和 `P(𝒳^(l)|𝒳; θ)`。将 `θ` 视为未知参数向量，根据变分 EM 可知，通过在算法中添加 M 步并优化下界 `ℱ(Q)` 关于 `θ`（固定其余涉及参数），可以迭代地估计它（参见例如 [29,69]）。换句话说，将参数 `θ` 视为确定性的，它们取代了第 [13.2](#Chp013_635-716_B9780443292385000196.xhtml) 节中使用的参数 `ξ`。

### 备注 16.2

*   平均场近似方法也已应用于 S 型神经网络，其定义见第 [15.3.4](#Chp015_755-803_B9780443292385000214.xhtml) 节（参见例如 [69]）。
*   涉及 `Q` 完全因子分解形式的平均场近似是最简单、最粗糙的近似。也有更复杂的尝试，允许 `Q` 具有更丰富的结构，同时保持其计算易处理性（参见例如 [17,31,80]）。
*   在文献 [82] 中，平均场近似已应用于一般贝叶斯网络，正如我们所知，其联合概率分布由各节点条件概率的乘积给出，

```
p(𝐱) = ∏ᵢ p(xᵢ|Paᵢ).
```

*   除非条件概率以结构简单的形式给出，否则精确消息传递可能变得计算困难。对于这种情况，可以在隐变量中引入平均场近似，即

```
Q(𝒳ˡ) = ∏ᵢ:ₓᵢ∈𝒳ˡ Qᵢ(xᵢ),
```

*   然后对其进行估计，以最大化公式 [(16.15)](#Chp016_805-853_B9780443292385000226.xhtml#deq32) 中的下界 `ℱ(Q)`。遵循第 [13.2](#Chp013_635-716_B9780443292385000196.xhtml) 节介绍的论证，这是通过从某些初始估计开始迭代实现的，在每一迭代步骤中，固定其余因子，针对单个因子进行优化。在第 `(j + 1)` 步，第 `m` 个因子得到为（公式 [(13.15)](#Chp013_635-716_B9780443292385000196.xhtml)）
