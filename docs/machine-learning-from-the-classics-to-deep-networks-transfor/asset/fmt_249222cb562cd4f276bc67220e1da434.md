
The proof of the lemma is given in Problem [11.4](#Chp011_519-582_B9780443292385000172.xhtml#o0045). The overbar denotes the closure of a set. In other words, ℍ can be constructed by *all* possible linear combinations of the kernel function computed in 𝒳, as well as the *limit points* of sequences of such combinations. Simply stated, ℍ can be *fully generated from the knowledge* of `κ(⋅, ⋅)`.

The interested reader can obtain more theoretical results concerning RKHSs from, for example, [64,83,87,103,106,112].

### 11.5.2 Examples of kernel functions

In this subsection, we present some typical examples of kernel functions, which are commonly used in various applications.

*   **The *Gaussian* kernel** is among the most popular ones, and it is given by our familiar form

```
κ(x, y) = exp( - ||x - y||^2 / (2σ^2) ),
```

with `σ > 0` being a parameter. [Fig. 11.7](#Chp011_519-582_B9780443292385000172.xhtml#f0040)A shows the Gaussian kernel as a function of `x, y ∈ 𝒳 = ℝ` and `σ = 0.5`. [Fig. 11.7](#Chp011_519-582_B9780443292385000172.xhtml#f0040)B shows the graphs of the resulting functions if we set one of the kernel's arguments to 0, i.e., `κ(⋅, 0)`, for various values of `σ`.

![Figure 11.7 (A) The Gaussian kernel for 𝒳 = ℝ, σ = 0.5. (B) The function κ(⋅,0) for different values of σ.](images/B9780443292385000172/gr007.jpg)

*   The dimension of the RKHS generated by the Gaussian kernel is *infinite*. A proof that the Gaussian kernel satisfies the required properties can be obtained, for example, from [112].

*   **The *homogeneous polynomial* kernel** has the form

```
κ(x, y) = (x^T y)^r,
```

where `r` is a parameter.

*   **The *inhomogeneous* polynomial kernel** is given by

```
κ(x, y) = (x^T y + c)^r,
```

where `c ≥ 0` and `r > 0, r ∈ ℕ` are parameters. The graph of the kernel is given in [Fig. 11.8](#Chp011_519-582_B9780443292385000172.xhtml#f0045)A. In [Fig. 11.8](#Chp011_519-582_B9780443292385000172.xhtml#f0045)B the graphs of the function `ϕ(⋅, x₀)` are shown for different values of `x₀`. The dimensionality of the RKHS associated with polynomial kernels is finite.

![Figure 11.8 (A) The inhomogeneous polynomial kernel for 𝒳 = ℝ, r = 2. (B) The graphs of κ(⋅,x₀) for different values of x₀.](images/B9780443292385000172/gr008.jpg)
