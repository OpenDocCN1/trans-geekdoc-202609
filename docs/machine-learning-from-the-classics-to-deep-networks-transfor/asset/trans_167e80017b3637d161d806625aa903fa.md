
我们首先考虑无约束的情况开始讨论；因此，我们设定 `𝒜 = ℝ^K`，并将在 `ℝ^K` 中寻找解，在我们当前的讨论背景下，`K = l + 1`。对 `J(θ)` 关于 `θ` 求导（梯度）（见附录 A）并令其等于零向量 `0`，我们得到（问题 [3.1](#Chp003_65-117_B9780443292385000093.xhtml#o0010)）

```
(∑_{n=1}^{N} x_n x_n^T) θ̂ = ∑_{n=1}^{N} y_n x_n.
```
(3.13)

请注意，左边的求和是一个 `(l + 1) × (l + 1)` 矩阵，是 `N` 个外积向量的和，即 `x[n] x[n]^(T)`。根据线性代数知识，我们至少需要 `N = l + 1` 个观测向量来保证该矩阵可逆，当然这假设这些向量是线性无关的（参见例如 [35]）。
