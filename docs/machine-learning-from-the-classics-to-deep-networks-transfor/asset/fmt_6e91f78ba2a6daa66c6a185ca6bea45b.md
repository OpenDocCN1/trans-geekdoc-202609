
# 决策树分类原理

从根节点开始，通过一系列连续的决策路径，直到到达叶节点。每个叶节点与**单个**类别相关联。点到类别的分配根据相应叶节点的标签进行。这种分类类型在概念上简单且易于解释。例如，在医学诊断系统中，可能从"体温是否高？"这个问题开始。如果是，第二个问题可以是："鼻子是否流涕？"该过程持续进行，直到就疾病做出最终决定。此外，树结构在构建人工智能推理系统中也很有用\[37\]。例如，基于某些（高层）特征值的一系列相关问题推导出特定对象的存在，可以导致对图像中描绘的场景或物体的识别。

一旦树建立完成，分类就变得简单直接。主要挑战在于如何利用训练数据集中蕴含的信息来构建树。设计树时面临的主要问题如下：

*   应采用哪种分裂准则？
*   何时停止树的生长并将节点声明为最终节点？
*   叶节点如何与特定类别关联？

除了上述问题，还有其他问题将在后面讨论。

## 分裂准则

我们已经说明，每个节点提出的问题类型如下：

Is `x[i] < a`?

目标是为阈值 `a` 选择一个合适的值。假设从根节点开始，树已生长到当前节点 `t`。每个节点 `t` 关联训练数据集 `X` 的一个子集 `X[t] ⊆ X`。这是在树中前序节点进行测试后，存活到达该节点的训练点集合。例如，在[图 7.13](#Chp007_293-342_B9780443292385000135.xhtml#f0080)中，属于类别 `ω[1]` 的许多点将不参与节点 `t[1]`，因为它们已在先前标记的叶节点中被分配。分裂准则的目的是根据节点 `t` 处特定问题的答案，将 `X[t]` 分裂为两个**不相交**的子集，即 `X[tY]` 和 `X[tN]`。对于每次分裂，以下均成立：

```
X[tY] ∩ X[tN] = ∅, X[tY] ∪ X[tN] = X[t].
```
