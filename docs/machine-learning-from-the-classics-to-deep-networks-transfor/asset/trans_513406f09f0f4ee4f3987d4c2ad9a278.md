

$u(n,m) = \sum\limits_{i = - \infty}^{+ \infty}\sum\limits_{j = - \infty}^{+ \infty}h(i,j)d(n - i,m - j) + \eta(n,m)$

其中 $\eta(n,m)$ 是噪声场的一个实现，假设其均值为零且与输入（未退化）图像相互独立。序列 $h(i,j)$ 是系统（例如相机）的*点扩散序列*（冲激响应）。我们将假设该序列是已知的，并且以某种方式已被测得。^([^(21)](#fn21))

我们现在的任务是估计一个二维滤波器 $w(n,m)$，将其应用于退化图像，以最优地（在均方误差意义上）重构原始未退化图像。在当前语境下，公式 [(4.48)](#Chp004_119-175_B978044329238500010X.xhtml#deq74) 可写为

$$W(\omega_1,\omega_2)S_u(\omega_1,\omega_2) = S_{du}(\omega_1,\omega_2)$$

遵循推导第 [2](#Chp002_19-64_B9780443292385000081.xhtml) 章公式 [(2.130)](#Chp002_19-64_B9780443292385000081.xhtml) 时使用的类似论证，可以证明（问题 [4.13](#Chp004_119-175_B978044329238500010X.xhtml#o0070)）

$$S_{du}(\omega_1,\omega_2) = H^*(\omega_1,\omega_2)S_d(\omega_1,\omega_2) \tag{4.50}$$

以及

$$S_u(\omega_1,\omega_2) = |H(\omega_1,\omega_2)|^2 S_d(\omega_1,\omega_2) + S_\eta(\omega_1,\omega_2) \tag{4.51}$$
