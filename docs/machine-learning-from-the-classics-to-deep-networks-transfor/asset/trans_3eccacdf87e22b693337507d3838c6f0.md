

### L1 范数的近端算子

L1 范数的近端算子按元素定义为：

```
${Prox}_{\lambda{\| \cdot \|}_{1}}(\mathbf{x})|_{i} = \arg\min\limits_{v_{i} \in \mathbb{R}}\left\{ |v_{i}| + \frac{1}{2\lambda}{(x_{i} - v_{i})}^{2} \right\},\quad i = 1,2,\ldots,l,$
```

其中 `Prox`[`λ`∥ ⋅ ∥[1]](**x**)|[*i*] 表示相应的第 *i* 个元素。

最小化公式 (8.108) 等价于要求零属于次微分集，从而得到闭式解：

```
${Prox}_{\lambda{\| \cdot \|}_{1}}(\mathbf{x})|_{i} = \begin{cases} 
x_{i} - \text{sgn}(x_{i})\lambda, & \text{if } |x_{i}| > \lambda, \\ 
0, & \text{if } |x_{i}| \leqslant \lambda 
\end{cases} = \text{sgn}(x_{i})\max\{ 0,|x_{i}| - \lambda \}.
```
