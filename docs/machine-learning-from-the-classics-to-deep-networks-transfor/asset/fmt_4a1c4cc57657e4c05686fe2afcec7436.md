
基于当前样本点(*y*[*n*], **x**[*n*])的梯度*噪声*估计。这会减慢收敛速度，特别是在算法接近解时。此外，参数向量的估计会在最优值附近波动。我们在LMS情况下广泛研究了这一现象，当时*μ*[*n*]被赋予常数值。这就是在随机梯度理论中，*μ*[*n*]必须是递减序列的原因。然而，它*不能*下降得太快，这由条件∑[*n*]*μ*[*n*] → ∞（第5.4节）保证。此外，回顾我们在那里的讨论，向**θ**[*]的平均收敛速率为𝒪(1/*n*)，即*次线性*（例如公式(6.53)）。该结果也涵盖了公式(8.99)中给出的更一般的在线算法情况（参见文献[56]）。但请注意，所有这些结果都是在若干假设下推导出来的，例如算法足够接近解。

我们现在的主要兴趣转向比较批量算法和相应在线算法收敛到**θ**[*]的速率，即最小化期望损失的值，这是我们学习任务的最终目标。既然目的是比较性能，给定相同数量的训练样本，让我们对在线算法的*n*和批量算法的*N*使用相同的数字。遵循文献[12]并对*J*[*n*](**θ**)应用二阶泰勒展开，可以证明（问题8.32）：

```
θ*_n = θ*_{n-1} - (1/n) Ψ_n^{-1} L'(θ*_{n-1}, y_n, x_n)
```

其中

```
Ψ_n = (1/n) ∑_{k=1}^n ∇²L(θ*_{n-1}, y_k, x_k)
```
