

## SVD 展开及其几何意义

现在让我们详细阐述 SVD 展开并探讨其几何意义。根据伪逆 `X†` 的定义，并假设 `N × l` (`N > l`) 数据矩阵为满列秩 (`r = l`)，将公式 (6.14) 代入公式 (6.5) 可得（习题 6.6）：

```
ŷ = Xθ̂_LS = X(XᵀX)⁻¹Xᵀy = U_l U_lᵀ y = [u₁, ..., u_l] [u₁ᵀy; ⋮; u_lᵀy]
```

![Equation](images/B9780443292385000123/fx006.jpg) (6.19)

后者表示 **y** 在 `X` 的列空间上的*投影*，即 `span{x₁⁽ᶜ⁾, …, x_l⁽ᶜ⁾}`，使用相应的*标准正交*基 `{u₁, …, u_l}` 来描述该子空间（见图 6.3）。请注意，正如公式 (6.18) 所暗示的，每个 `u_i`（`i = 1, 2, …, l`）都位于由 `X` 的列向量张成的空间中。换句话说，矩阵 `X` 的 SVD 提供了一组描述相应列空间的标准正交基。
