
观察到代价函数是非负的。确实，因为求和是在误分类点上进行的，如果 `x[n] ∈ ω[1] (ω[2])`，则 `θ^(T)x[n] ≤ (≥) 0`，使得乘积 `−y[n]θ^(T)x[n] ≥ 0`。如果不存在误分类点，即 `𝒴 = ⌀`，则得到解。按照惯例，在这种情况下我们可以说 `J(θ) = 0`。

感知机代价函数并非在所有点都可微。它是一个*连续分段线性*函数。确实，让我们以稍微不同的方式写出它：

```
J(θ) = ( - ∑_{n:x_n ∈ 𝒴} y_n x_n^T ) θ
```

只要误分类点的数量保持不变，这就是一个关于 `θ` 的线性函数。然而，随着人们缓慢改变 `θ` 的值，这对应于相应超平面位置的变化，将会有一个点，其中 `𝒴` 中误分类样本的数量突然发生变化；这就是训练集中的一个样本相对于（移动的）超平面改变其相对位置的时刻，因此集合 `𝒴` 被修改。在此变化之后，`J(θ)` 将对应于一个新的线性函数。
