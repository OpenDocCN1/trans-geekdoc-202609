### Step 4: Compute the attention score matrix

$$
\frac{1}{\sqrt{d_{k}}}QK^{T} = \frac{1}{\sqrt{d_{k}}}\begin{bmatrix} {\mathbf{q}_{0}^{T}\mathbf{k}_{0} } & {\ldots } & {\mathbf{q}_{0}^{T}\mathbf{k}_{N + 1}} \\ {\vdots } & {\vdots } & {\vdots} \\ {\mathbf{q}_{N^{\prime} + 1}^{T}\mathbf{k}_{0} } & {\ldots } & {\mathbf{q}_{N^{\prime} + 1}^{T}\mathbf{k}_{N + 1}} \\ \end{bmatrix}.
$$

![Equation](images/B9780443292385000251/si347.png) (19.49)

Note that in contrast to the attention score matrix in Eq. [(19.37)](#Chp019_997-1102_B9780443292385000251.xhtml#deq83), which is a square matrix, the matrix in Eq. [(19.49)](#Chp019_997-1102_B9780443292385000251.xhtml#deq111) is a non-square one. This is because this layer is dedicated to quantify similarities between embedding vectors in the decoder and the output embedding vectors of the encoder. Sometimes, we refer to this layer as the *cross-attention* layer.
