
In words, while training `ϵ_θ(x_t, t)` to optimally estimate the sample `ϵ`, implicitly it provides an estimate of the negative gradient, multiplied by the corresponding standard deviation, i.e., `- √(1 - ā_t) ∇_{x_t} q(x_t | x_0)`. We will come back to this in Section [19.7.3](#Chp019_997-1102_B9780443292385000251.xhtml#s0260).

### 19.7.2 The neural network implementation

The goal of training is to learn the parameters of a neural network, denoted as `f_θ(·)`. The inputs to the network are samples, `x_t`, `t = 1, 2…, T`, of the corresponding latent (diffused) variables that are generated during the forward process. The network is trained so that, at each time step, the corresponding output to predict the associated target. For example, for `t > 1`, the output-target pairs are `(μ_θ(x_t, t), μ̃_t(x_t, x_0))` or `(ϵ_θ(x_t, t), ϵ)`.

The parameters, `θ`, that define the neural network are *shared* by all time steps. In principle, any neural network whose input and output are of the same dimensions could be used. However, one of the most popular architectures that has been used in practice is the U-Net, [158], or variants of it. A block diagram illustration of the U-Net, in the context of diffusion networks, is shown in [Fig. 19.24](#Chp019_997-1102_B9780443292385000251.xhtml#f0135). Each block in the figure indicates a stage of the network. The U-Net is a convolutional network (Section [18.12](#Chp018_885-995_B978044329238500024X.xhtml)) that employs a contractive path followed by an expansive one that reminds us of the U-shape. In other words, the output feature maps for each stage of the network become smaller and smaller in size via downsampling, up to some minimum value. Then, upsampling takes place in a symmetric way, compared to the downsampling. A key feature of the U-Net is the existence of the skip connections (dotted lines in [Fig. 19.24](#Chp019_997-1102_B9780443292385000251.xhtml#f0135)), that pass information from the downsampling stages to the corresponding upsampling ones. One could consider the contractive path as an encoder. The minimum size feature maps, block #5 in the middle of the figure, encode/learn information that "resides" in the input data, and it is important to the associated prediction task, see, e.g., [168]. Input and output of the U-Net are of the same dimensions.
