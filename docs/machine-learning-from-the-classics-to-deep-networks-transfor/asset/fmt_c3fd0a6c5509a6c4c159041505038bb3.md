
### 算法步骤

*   **For** `n = 0, 1, …` **Do**
    1.  `e[n] = y[n] - X[n]θ[n-1]`
    2.  `θ[n] = θ[n-1] + μ X[n]^T (δ I + X[n] X[n]^T)^(-1) e[n]`
*   **End For**

当输入为时间序列时，对应的输入向量记为 `u[n]`，通过将所需的负时间索引样本 `u[-1], u[-2], …` 设置为零来初始化。请注意，在算法中，也使用了一个取较小值的参数 `δ`，以防止相关矩阵求逆中的数值问题。此外，还引入了步长 `μ`，它控制更新的大小，其存在的合理性稍后将得到证明。由于涉及矩阵求逆和矩阵运算，APA 的复杂度比 LMS 增加，需要 `O(q³)` 次乘加运算（MADs）。利用 `X[n] X[n]^T` 的特殊结构（针对涉及的输入-输出变量为随机过程实现的情况），也开发了 APA 的快速版本（参见 [42, 43]）。

APA 的收敛分析比 LMS 更复杂。结果表明，只要 `0 < μ < 2`，就能保证算法的稳定性。失调度近似由以下公式给出 [2, 34, 83]：

```
M ≈ (μ q σ²_v) / (2 - μ q)
```

换句话说，随着参数 `q` 的增加，即重用的过去数据样本数量增加，失调度也会增加。
