
也就是说，我们假设知道 `θ` 的值位于 `θ₀` 附近，而 `σ₀²` 量化了我们对这一先验知识的不确定程度。我们的目标首先是获得后验 PDF，给定观测值集合 `y = [y₁, …, y_N]ᵀ`，然后根据方程 [(3.63)](#Chp003_65-117_B9780443292385000093.xhtml#deq113) 和 [(3.64)](#Chp003_65-117_B9780443292385000093.xhtml#deq115) 获得 `𝔼[θ|y]`，并将它们调整以适应我们当前的符号需求。我们有

```
p(θ|y) = p(y|θ)p(θ) / p(y)
       = (1 / p(y)) (∏_{n=1}^N p(y_n|θ)) p(θ)
       = (1 / p(y)) (∏_{n=1}^N (1 / (√(2π) σ_η)) exp(-(y_n - θ)² / (2 σ_η²)))
         × (1 / (√(2π) σ_0)) exp(-(θ - θ_0)² / (2 σ_0²)).
``` (3.67)
