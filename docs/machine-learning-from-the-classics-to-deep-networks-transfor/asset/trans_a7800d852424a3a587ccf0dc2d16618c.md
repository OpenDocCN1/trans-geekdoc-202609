
给定三个不相交的集合 `X`、`Y`、`Z`，如果给定 `Z` 的情况下，`X` 和 `Y` 之间不存在活跃路径，则称 `X` 的节点被 `Y` 的节点*分离*，给定 `Z`。请注意，与为 BN 结构给出的相应定义相比，前一个定义要简单得多。根据当前定义，要使集合 `X` 在给定第三个集合 `Z` 的情况下与集合 `Y` 分离，只需*所有*从 `X` 到 `Y` 的可能路径都经过 `Z` 即可。[图 15.14](#Chp015_755-803_B9780443292385000214.xhtml#f0080) 说明了这种几何关系。在 [15.14](#Chp015_755-803_B9780443292385000214.xhtml#f0080)A 中，给定 `Z` 中的节点，不存在连接 `X` 中节点与 `Y` 中节点的活跃路径。在 [15.14](#Chp015_755-803_B9780443292385000214.xhtml#f0080)B 中，给定 `Z`，存在连接 `X` 和 `Y` 的活跃路径。

现在让我们用 `I(H)` 表示所有“*X* 被 *Y* 分离，给定 *Z*”类型语句的集合。这类似于与 BN 结构相关的所有可能的 *d*-分离集合。以下定理（合理性）成立（问题 [15.10](#Chp015_755-803_B9780443292385000214.xhtml#o0090)）。

### 定理 15.4

*设 `p` 为一个在 MRF `H` 上分解的吉布斯分布。那么这是 `p` 的一个 I-map，即*

`I(H) ⊆ I(p)`。

这是[定理 15.3](#Chp015_755-803_B9780443292385000214.xhtml#enun0045)在其“I-map 表述”中的对应定理，正如第 [15.3.7](#Chp015_755-803_B9780443292385000214.xhtml#s0055) 节所介绍的。此外，给定 MRF `H` 是分布 `p` 的 I-map，则 `p` 在 `H` 上分解。请注意，这对 BN 结构成立；确实，如果 `I(G) ⊆ I(p)`，则 `p` 在 `G` 上分解（问题 [15.12](#Chp015_755-803_B9780443292385000214.xhtml#o0100)）。然而，对于 MRF，这仅对严格正的吉布斯分布成立，并由以下*哈默斯利-克利福德定理*给出。

### 定理 15.5

*设 `H` 为一组随机变量上的 MRF*，`x[1], …, x[l]`，*由概率分布描述*，`p > 0`。*如果 `H` 是 `p` 的 I-map，则 `p` 是一个在 `H` 上分解的吉布斯分布。*

有关此定理的证明，感兴趣的读者可参考原始论文 [22] 和 [5]。

关于 MRF 背景下独立性的最后一点涉及完全性的概念。正如 BN 的情况一样，如果 `p` 在 MRF 上分解，这并不一定建立完全性，尽管在几乎所有实际情况下都是成立的。然而，较弱的版本成立。即，如果 `x` 和 `y` 是 MRF 中*不*被集合 `Z` 分离的两个节点，则存在一个在 `H` 上分解的吉布斯分布 `p`，根据该分布，`x` 和 `y` 在给定 `Z` 中变量的条件下是相关的（参见，例如 [25]）。

### 15.4.2 伊辛模型及其变体

MRF 理论的起源可追溯到统计物理学科，此后已广泛应用于许多不同学科，包括机器学习。特别是在图像处理和计算机视觉中，MRF 已被确立为去噪、图像分割和立体重建等任务中的主要工具（参见，例如 [29]）。本节的目的是陈述一个基本且相当原始的模型，然而它演示了此类模型捕获并随后处理信息的方式。
