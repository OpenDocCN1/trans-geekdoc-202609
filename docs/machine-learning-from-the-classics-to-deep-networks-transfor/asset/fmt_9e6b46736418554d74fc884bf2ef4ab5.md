
The discriminator has 784 input nodes, to match the 1 × 784 size vector associated with the 28 × 28 MNIST images. The discriminator consists of three hidden layers, of 1024, 512, and 256 neurons, respectively. The leaky ReLU unit, with `α = 0.2`, was used as the activation function for the hidden layer neurons. The output is a single binary sigmoidal node and the cost function was the two-class cross-entropy function (Eq. [(18.44)](#Chp018_885-995_B978044329238500024X.xhtml)). For the training, the dropout method was used with the probability of discarding hidden neurons being equal to 0.3. The Adam optimizer was employed for training ([Problem 19.9](#Chp019_997-1102_B9780443292385000251.xhtml#o0085)). The input images were normalized in the range [−1, 1]. The number of images used for training was 60000 and the size of the mini-batches equal to 100.

### 19.2.6 Variational autoencoders

At the heart of GANs lies the concept of generating samples, `x[n]`, `n = 1, 2, …`, of a random vector, `x`, by exciting the generator network with corresponding samples, `z[n]`, of a random noise vector, `z`. Moreover, recall that GANs do not involve any explicit probabilistic arguments. In contrast, *variational autoencoders* (VAEs) are probabilistic generative models. Furthermore, the generator, known as the decoder in this case, is excited by random variables whose posterior PDF has been *learned* from the data. The training builds upon Bayesian learning arguments; see Chapters [12](#Chp012_583-634_B9780443292385000184.xhtml) and [13](#Chp013_635-716_B9780443292385000196.xhtml). Variational autoencoders were proposed in [103], [154].

The basic assumption behind VAEs is that we are given a set of observations, `x[n]`, `n = 1, 2, …, N`, which are samples of a random vector, `x ∈ ℝ^(l)`. Moreover, the latter is the result of another process that involves a set of *latent* random variables, `z ∈ ℝ^(m)`, where usually `m ≪ l`. That is, VAEs fall under the more general umbrella of schemes for which the underlying generation mechanism evolves along the following steps:

*   A sample, `z[n]`, is generated according to some PDF, `p(z; θ)`, where `θ` is a set of unknown parameters.
*   A sample, `x[n]`, is generated from a conditional PDF, `p(x|z[n]; θ)`.

As we know from the Bayesian related chapters, a way to estimate a set of parameters, `θ`, in the presence of latent (unobserved) variables, is via the EM algorithm. A prerequisite for its application is to know the posterior, `p(z|x)`; this is needed for averaging out the (unknown) latent variables. In general, this posterior is not available (or the required by the EM computations may not be computationally tractable) and one has to resort to approximations. In Chapter [13](#Chp013_635-716_B9780443292385000196.xhtml), a factorized form was adopted in the framework of the mean field approximation. In contrast, according to the VAEs, the approximation, `q(z|x; ϕ)`, of the posterior is implemented via the use of a neural network; the vector `ϕ` denotes the set of the unknown parameters that have to be learned together with `θ`.
