
考虑一个包含 *K* 个智能体/节点的网络。每个节点与其邻域内的节点交换信息。给定图中的节点 *k*，令 𝒩<sub>k</sub> 为与该节点共享边的节点集合；此外，节点 *k* 本身也包含在 𝒩<sub>k</sub> 中。这构成了 *k* 的邻域集合。我们将该集合的基数表示为 *n*<sub>k</sub>。[图 5.24](#Chp005_177-248_B9780443292385000111.xhtml#f0125) 展示了一个包含六个节点的图。例如，节点 *k* = 6 的邻域为 𝒩<sub>6</sub> = {2, 3, 6}，基数 *n*<sub>6</sub> = 3。集合 𝒩<sub>k</sub> 的基数也称为节点 *k* 的*度*。相反，节点 *k* = 6 和 *k* = 5 不是邻居，因为它们没有通过边直接相连。为本节需要，我们假设该图是*强连通*的；即，存在至少一条边路径连接任意一对节点。

网络中的每个节点都能访问一个局部数据采集过程，该过程提供训练数据对<sup>([36](#fn36))</sup>：

*y*<sub>k</sub> = **θ**<sub>o</sub><sup>T</sup>**x**<sub>k</sub> + *η*<sub>k</sub>,  *k* = 1, 2, …, *K*,  (5.77)

其中 **x**<sub>k</sub> 和零均值噪声变量 *η*<sub>k</sub> 通常在每个节点服从*不同*的统计特性。我们稍后将讨论此类应用。

单独对待每个节点，最小化*局部*代价函数的 MSE 最优解：

*J*<sub>k</sub>(**θ**) = 𝔼 [|*y*<sub>k</sub> − **θ**<sup>T</sup>**x**<sub>k</sub>|²],

将由相应的正规方程给出，涉及相应的协方差矩阵和互相关向量；换句话说，

**Σ**<sub>**x**<sub>k</sub></sub> **θ**<sub>*</sub> = **p**<sub>k</sub>.  (5.78)
