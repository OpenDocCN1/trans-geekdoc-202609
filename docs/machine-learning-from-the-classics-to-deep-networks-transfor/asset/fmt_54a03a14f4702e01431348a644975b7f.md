
`d̂[n] = w[n-1]^(H) u[n]`

and

`e[n] = d[n] - d̂[n]`

![Equation](images/B9780443292385000111/si429.png)

and we have allowed the vector of the eigenvalues, `λ`, to be time-dependent; `C` is defined as the matrix having as columns the vectors `c[i]`, `i = 1, 2, …, m`.

![Equation](images/B9780443292385000111/si430.png)

Plugging Eq. [(5.71)](#Chp005_177-248_B9780443292385000111.xhtml#deq159) into the constraints in [(5.70)](#Chp005_177-248_B9780443292385000111.xhtml#deq156), which can be compactly written as `C^(H) w = g` (recall `g[i] ∈ ℝ`), we readily obtain

```
-μ λ[n] = (C^(H) C)^(-1) g - (C^(H) C)^(-1) C^(H) (w[n-1] + μ u[n] e[n]^(∗))
```

![Equation](images/B9780443292385000111/si432.png)

and the update recursion becomes

```
w[n] = (I - C (C^(H) C)^(-1) C^(H)) (w[n-1] + μ u[n] e[n]^(∗)) + C (C^(H) C)^(-1) g.
```
