

## 图 3.7

观测数据用灰点表示。这些是将噪声添加到红点（位于与未知 `g(⋅)` 相关的红色曲线上）后的结果。用固定多项式 `f₁(x)` 拟合数据会导致高偏差；观察可知，大多数数据点都位于直线之外。另一方面，“估计量”的方差将为零。相反，拟合高次多项式 `f₂(x; 𝒟)` 会导致低偏差，因为相应的曲线穿过所有数据点；然而，相应的方差将很高。

首先，我们将非常天真地选择一个固定的线性模型来拟合数据，

```
ŷ = f₁(x) = θ₀ + θ₁x
```

其中 `θ₁` 和 `θ₀` 的值是任意选取的，与训练数据无关。这条直线的图形如 [图 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045) 所示。由于未涉及训练且模型参数是固定的，因此随着训练集的改变不会产生变化，且 `𝔼[𝒟][f₁(x)] = f₁(x)`，方差项等于零。另一方面，偏差的平方等于 `(f₁(x) − 𝔼[y|x])²`，预计会很大，因为模型的选择是任意的，未考虑训练数据。

接下来，我们转向另一个“极端”。我们选择一个相对复杂的函数类，例如高阶（10 阶）多项式 `f₂`。生成的估计值对用于训练的相应集合 `𝒟` 的依赖关系显式地表示为 `f₂(⋅; 𝒟)`。请注意，对于每一个集合，相应的最优模型图形预计都将穿过训练点，即

```
f₂(xₙ; 𝒟ᵢ) = g(xₙ) + ηₙ,ᵢ,  n = 1, 2, …, N.
```

这在 [图 3.7](#Chp003_65-117_B9780443292385000093.xhtml#f0045) 中针对一条曲线展示了。请注意，通常如果多项式（模型）的阶数很大，且待估计的参数数量大于训练点的数量，这总是成立的。对于图中所示的例子，我们给出了 10 个训练点，而对于一个 10 阶多项式（包括偏置项），需要估计 11 个参数。通过求解一个包含 10 个方程（`N = 10`）和 11 个未知数的线性方程组，可以在训练点上获得完美拟合。这就是当模型阶数很大时，可以在训练数据集上实现*零*（或实际上非常小）误差的原因。我们将在第 [3.13](#Chp003_65-117_B9780443292385000093.xhtml#s0105) 节中回到这个问题。
