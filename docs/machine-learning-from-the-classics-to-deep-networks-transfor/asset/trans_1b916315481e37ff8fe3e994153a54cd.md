

### 双重表示形式的优势

双重表示形式的优势在于它以内积运算的形式涉及观测向量。因此，当任务在 RKHS 中求解时，公式 [(11.48)](#Chp011_519-582_B9780443292385000172.xhtml#deq121) 变为：

```
maximize with respect to λ, λ̃  Σ_{n=1}^N (λ̃_n - λ_n)y_n - ε(λ̃_n + λ_n) - 1/2 Σ_{n=1}^N Σ_{m=1}^N (λ̃_n - λ_n)(λ̃_m - λ_m)κ(x_n, x_m).
```

### KKT 条件

KKT 条件传达了重要信息。对于误差小于 `ϵ` 的点，即：

```
|θ^(T)x_n + θ_0 - y_n| < ϵ
```

![Equation](images/B9780443292385000172/si287.png)

拉格朗日乘子 `λ̃[n]`、`λ[n]` 为零。这是公式 [(11.38)](#Chp011_519-582_B9780443292385000172.xhtml#deq111) 和 [(11.39)](#Chp011_519-582_B9780443292385000172.xhtml#deq112) 以及 `ξ̃[n]`、`ξ[n]` ≥ 0 这一事实的直接结果。

因此，拉格朗日乘子仅对误差等于 `ϵ`（`ξ̃[n]`、`ξ[n]` = 0）或取更大值（`ξ̃[n]`、`ξ[n]` > 0）的点才为**非零**。换句话说，只有具有非零拉格朗日乘子的点（支持向量）才会出现在公式 [(11.44)](#Chp011_519-582_B9780443292385000172.xhtml#deq117) 中，这导致了公式 [(11.44)](#Chp011_519-582_B9780443292385000172.xhtml#deq117) 中展开式的**稀疏化**。
