

### 优化问题

$$
\text{minimize with respect to } \mathbf{\theta} \quad \frac{1}{2}\|\mathbf{\theta}\|^2,
$$

subject to

$$
y_n(\mathbf{\theta}^T\mathbf{x}_n + \theta_0) \ge 1, \quad n = 1, 2, \dots, N.
$$

换句话说，从这无限多个能够解决任务并正确分类所有训练模式的线性分类器中，我们的优化任务选择了范数最小的那个。正如下文所述，范数 $\|\mathbf{\theta}\|$ 与相应分类器形成的间隔直接相关。

![Figure 11.14 There is an infinite number of linear classifiers that can classify correctly all the patterns in a linearly separable class task.](images/B9780443292385000172/gr014.jpg)

**Figure 11.14** 存在无限多个线性分类器，它们能够正确分类线性可分类任务中的所有模式。

空间中的每个超平面由以下方程描述：

$$
f(\mathbf{x}) = \mathbf{\theta}^T\mathbf{x} + \theta_0 = 0.
$$

根据经典几何（另见习题 [5.11](#Chp005_177-248_B9780443292385000111.xhtml)），我们知道其在空间中的方向由 $\mathbf{\theta}$ 控制（垂直于超平面），其位置由 $\theta_0$ 控制（参见 [Figure 11.15](#Chp011_519-582_B9780443292385000172.xhtml#f0080)）。从所有能精确解决任务且具有特定方向（即共享同一个 $\mathbf{\theta}$）的超平面集合中，我们选择 $\theta_0$ 以将超平面置于两个类别之间，使其到每个类别最近点的距离相同。[Figure 11.16](#Chp011_519-582_B9780443292385000172.xhtml#f0085) 展示了两个不同方向（灰色和红色实线）的线性分类器（超平面）。它们都被放置为到两个类别中最近点的距离相同。此外，请注意与“灰色”分类器相关的距离 $z_1$ 小于与“红色”分类器相关的距离 $z_2$。

![Figure 11.15 The direction of the hyperplane θTx + θ0 = 0 is determined by θ and its position in space by θ0. Note that θ has been shifted away from the origin, since here we are only interested to indicate its direction, which is perpendicular to the straight line.](images/B9780443292385000172/gr015.jpg)

**Figure 11.15** 超平面 $\mathbf{\theta}^T\mathbf{x} + \theta_0 = 0$ 的方向由 $\mathbf{\theta}$ 决定，其在空间中的位置由 $\theta_0$ 决定。请注意，$\mathbf{\theta}$ 已从原点平移开，因为这里我们只关心指示其方向，该方向垂直于直线。

![Figure 11.16 For each direction θ, “red” and “gray,” the (linear) hyperplane classifier, θTx + θ0 = 0 (full lines), is placed in between the two classes and normalized so that the nearest points from each class have a distance equal to one. The dotted lines, θTx + θ0 = ±1, which pass through the nearest points, are parallel to the respective classifier and define the margin. The width of the margin is determined by the direction of the corresponding classifier in space and is equal to \frac{2}{||\mathbf{\theta}||}Equation.](images/B9780443292385000172/gr016.jpg)

**Figure 11.16** 对于每个方向 $\mathbf{\theta}$，“红色”和“灰色”，(线性)超平面分类器 $\mathbf{\theta}^T\mathbf{x} + \theta_0 = 0$（实线）被置于两个类别之间并进行归一化，使得来自每个类别的最近点距离等于 1。虚线 $\mathbf{\theta}^T\mathbf{x} + \theta_0 = \pm 1$ 穿过最近点，分别与对应的分类器平行并定义了间隔。间隔的宽度由空间中相应分类器的方向决定，等于 $\frac{2}{\|\mathbf{\theta}\|}$。
