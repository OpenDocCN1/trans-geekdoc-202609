

# 引理 8.3

考虑凸函数

`f : ℝ^l ↦ ℝ ∪ {+∞}`

及其指数为 λ 的近端算子 `Prox[λf]`。则近端算子的不动点集与 f 的极小化点集重合，即

![Equation](images/B9780443292385000147/fx041.jpg) (8.112)

## 证明

不动点集的定义已在第 [8.3.1](#Chp008_343-416_B9780443292385000147.xhtml#s0035) 节给出。我们首先假设点 `x` 属于不动点集，因此近端算子的作用使其保持不变，即

`x = Prox[λf](x)`

![Equation](images/B9780443292385000147/si519.png)

并利用 [(8.111)](#Chp008_343-416_B9780443292385000147.xhtml#deq213)，我们得到

`⟨y − x, x − x⟩ ≤ λ(f(y) − f(x)), ∀y ∈ ℝ^l`

![Equation](images/B9780443292385000147/si520.png) (8.113)

其结果为

`f(x) ≤ f(y), ∀y ∈ ℝ^l`

![Equation](images/B9780443292385000147/si521.png) (8.114)

即 `x` 是 `f` 的极小化点。对于逆命题，我们假设 `x` 是一个极小化点。则 [(8.115)](#Chp008_343-416_B9780443292385000147.xhtml#deq219) 成立，由此推导出 [(8.114)](#Chp008_343-416_B9780443292385000147.xhtml#deq218)，由于这是一个点等于近端算子值的充要条件，我们就证明了该断言。 □

最后，注意 `f` 和 `e[λf]` 拥有相同的极小化点集。因此，可以通过处理一个等价的光滑函数来极小化一个非光滑凸函数。从实际角度来看，该方法的价值取决于获得近端算子有多容易。例如，我们已经看到，如果目标是极小化 `ℓ1` 范数，近端算子就是一个简单的软阈值操作。不用说，生活并不总是那么慷慨！

## 8.13.2 近端极小化

在本节中，我们将利用第 [8.4](#Chp008_343-416_B9780443292385000147.xhtml#s0040) 节的经验，开发出迭代方案，使其估计值渐近地落入相应算子的不动点集。所要求的只是该算子具有非扩张性。

### 命题 8.6

与凸函数相关的近端算子是非扩张的，即

![Equation](images/B9780443292385000147/fx042.jpg) (8.115)

#### 证明

该证明可通过 [(8.112)](#Chp008_343-416_B9780443292385000147.xhtml#deq214) 中的性质与 Cauchy–Schwarz 不等式相结合而直接得到。此外，可以证明近端算子的松弛版本（也称为*反射*版本），

`R[λf](x) := 2 Prox[λf](x) − I`

![Equation](images/B9780443292385000147/si523.png) (8.116)

也是非扩张的，且与近端算子具有相同的不动点集（问题 [8.36](#Chp008_343-416_B9780443292385000147.xhtml#o0210)）。 □
