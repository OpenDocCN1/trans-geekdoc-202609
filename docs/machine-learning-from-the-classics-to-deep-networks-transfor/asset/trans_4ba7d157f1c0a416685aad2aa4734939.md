
也就是说，Levinson 算法中的系数 `k[m]`、`k[m]^(w)`、`m = 0, 1, …, l − 1` 是 `d̂[n]` 按正交基展开时的参数。将公式 [(4.77)](#Chp004_119-175_B978044329238500010X.xhtml#deq131)–[(4.79)](#Chp004_119-175_B978044329238500010X.xhtml#deq137) 结合起来，得到 [图 4.18](#Chp004_119-175_B978044329238500010X.xhtml#f0095) 的 *lattice-ladder*（格-梯形）结构，其输出是 `d[n]` 的 MSE 近似 `d̂[n]`。

### 备注 4.4

*   **模块化。** 格-梯形方案是一种高效的、*模块化*结构。它由一系列连续的相似级组成。要增加滤波器的阶数，只需增加一个额外的级，这是 VLSI 实现中极为理想的特性。此外，与 Levinson 算法相比，格-梯形方案对数值不准确性具有更高的鲁棒性。
