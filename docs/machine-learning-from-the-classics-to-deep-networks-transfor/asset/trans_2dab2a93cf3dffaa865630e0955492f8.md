

### 矩阵求逆引理的应用

以下恒等式是利用矩阵求逆引理推导得出的：

$$(A + BD^{-1}C)^{-1} = A^{-1} - A^{-1}B(D + CA^{-1}B)^{-1}CA^{-1}$$

![Equation](images/B9780443292385000123/si182.png)

将其代入公式 [(6.42)](#Chp006_249-291_B9780443292385000123.xhtml#deq80)，经过适当的求逆和代换后，我们得到：

![](images/B9780443292385000123/fx013.jpg)

项 **k**[n] 称为 *卡尔曼增益*。为了表示方便，定义：

$$P[n] = \Phi[n]^{-1}$$

![Equation](images/B9780443292385000123/si184.png)

此外，重新排列公式 (6.45) 中的项，可得：

**k**[n] = ($\beta^{-1}P[n-1] - \beta^{-1}$**k**[n]**x**[n]^(T)**P**[n-1])**x**[n]

![Equation](images/B9780443292385000123/si185.png)

考虑到公式 (6.44) 后得到：

**k**[n] = **P**[n]**x**[n]
