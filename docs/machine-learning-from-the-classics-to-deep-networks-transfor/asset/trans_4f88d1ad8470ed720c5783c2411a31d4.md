

# 6.3 LS 估计量的统计性质

第 [3](#Chp003_65-117_B9780443292385000093.xhtml) 章曾针对随机实参数这一特殊情况，简要涉及了 LS 估计量的一些统计性质。在此，我们将在更一般的背景下探讨这一问题。假设存在一个真实的（但未知的）参数向量 `θ[o]`，根据模型生成输出（因变量）随机变量（堆叠在随机向量 `y ∈ ℝ^(N)` 中）：

```
y = Xθ[o] + η
```

其中 `η` 是一个*零*均值噪声向量。请注意，我们假设 `X` 是固定且非随机的；即输出变量 `y` 的随机性完全源于噪声。在上述假设下，以下性质成立。

## LS 估计量是无偏的

参数的 LS 估计量由下式给出：

```
θ̂_LS = (X^T X)^(-1) X^T y = (X^T X)^(-1) X^T (X θ_o + η) = θ_o + (X^T X)^(-1) X^T η
```
