### 12.9.1 线性回归模型的混合

我们的出发点是每个模型都是一个线性回归模型 `θ[k]`，*k* = 1, 2, …, *K*，其中假设输入空间的维度已增加一以容纳截距项，并且输出变量根据我们熟悉的方程与输入相关联：

`y[k] = θ[k]^(T)x + η`

其中 `η` 是一个方差为 `σ[η]²` 的白高斯噪声源，并假设对所有模型通用；推广到更一般的情况可以直接获得。对于广义线性模型，`x` 可以简单地用非线性映射 `ϕ(x)` 替换。我们假设门控参数被解释为概率，并将其表示为 `g[k] = P[k]`。

在上述假设下，采用了以下混合模型：

```
p(y; Ξ, P) = Σ_{k = 1}^{K} P_k N( y | θ_k^T x, σ_η^2 )
```
