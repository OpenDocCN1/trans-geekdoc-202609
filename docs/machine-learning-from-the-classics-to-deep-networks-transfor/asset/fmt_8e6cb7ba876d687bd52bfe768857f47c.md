
In [176], a theoretical framework is developed. Starting from a training example, `x`, that belongs to a class, say, `y`, the path to construct an adversarial example is to change `x` to a new point, say, `x'`, which is very close to `x`, and the model classifies it to another class `y' ≠ y`. The model that we adopt to construct `x'` is known as the *attack model*. For each training example, `x ∈ ℝ^l`, we introduce a set of allowed perturbations around `x`, `S[x](ε) ⊆ ℝ^l`. A typical choice for `S[x](ε)` is

```
S[x](ε) := {x + δ : ||δ||_p ≤ ε},
```

where `||·||_p` denotes the `ℓ_p` norm (see Section [8.3](#Chp008_343-416_B9780443292385000147.xhtml)) and `ε` is small enough. For example, in image classification tasks, `S[x](ε)` is selected so that it captures perceptual similarity between images. In [176], it is suggested to consider adversarial training as a robust optimization task and modify the loss function so that to give rise to the following minmax optimization,

```
min_θ Σ_(x,y) max_δ L(θ, x + δ, y), s.t. ||δ||_p ≤ ε.
```

(18.73)

The optimization task in [(18.73)](#Chp018_885-995_B978044329238500024X.xhtml#deq135) involves two steps. Maximizing with respect to `δ` (inner maximization) aims to find an adversarial version that achieves high loss. Minimizing with respect to `θ` (outer minimization) aims to find a model to minimize the "adversarial loss," given by the inner task, so that to construct a robust learner. As a matter of fact, it can be shown that `Δx` in Eq. [(18.72)](#Chp018_885-995_B978044329238500024X.xhtml#deq132) results from the inner maximization if we select the region `S[x](ε)` around `x` to be defined via the `ℓ_∞` norm (see Section [9.2](#Chp009_417-462_B9780443292385000159.xhtml)) and maximization is performed in one step. This algorithm is also known as the *fast gradient sign method* (FGSM).
