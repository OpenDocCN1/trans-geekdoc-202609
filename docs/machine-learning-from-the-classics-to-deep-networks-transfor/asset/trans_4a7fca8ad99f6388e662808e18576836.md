
$P(y = 0|x = 0) = 1 - p,\quad P(y = 1|x = 0) = p,\quad P(y = 1|x = 1) = 1 - q,\quad P(y = 0|x = 1) = q.$

![Equation](images/B9780443292385000081/si381.png)

此例以最简单的形式阐释了*通信信道*的效应。传输的比特受到噪声干扰，接收端接收到的是含噪（可能错误）的信息。接收端的任务是，在接收到一串符号后，判断原本发送的是哪一个。

我们此例的目标是确定在观测到 $y = 0$ 后，关于 $x = 0$ 和 $x = 1$ 发生的互信息。为此，我们首先需要计算边缘概率，

$$P(y = 0) = P(y = 0|x = 0)P(x = 0) + P(y = 0|x = 1)P(x = 1) = \frac{1}{2}(1 - p + q),$$

同理，

$$P(y = 1) = \frac{1}{2}(1 - q + p).$$
