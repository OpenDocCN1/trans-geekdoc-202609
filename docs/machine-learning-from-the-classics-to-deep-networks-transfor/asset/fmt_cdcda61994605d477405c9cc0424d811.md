
*y*[*n*] − **θ**^(*T*)**x**[*n*] − *θ*[0] ≤ − *ϵ*

define *ξ*[*n*] ≥ 0, such that

**θ**^(*T*)**x**[*n*] + *θ*[0] − *y*[*n*] ≤ *ϵ* + *ξ*[*n*].

Once more, we would like to select our unknown set of parameters so that *ξ*[*n*] is zero.

We are now ready to formulate the minimizing task around the corresponding empirical cost, regularized by the norm of **θ**, which is cast in terms of the auxiliary variables as^([^(79)](#fn79))

```
minimize J(θ, θ₀, ξ, ξ̃) = ½‖θ‖² + C(∑_{n=1}^N ξ_n + ∑_{n=1}^N ξ̃_n),
```

subject to *y*[*n*] − **θ**^(*T*)**x**[*n*] − *θ*[0] ≤ *ϵ* + *ξ̃*[*n*], *n* = 1, 2, …, *N*,

**θ**^(*T*)**x**[*n*] + *θ*[0] − *y*[*n*] ≤ *ϵ* + *ξ*[*n*], *n* = 1, 2, …, *N*.
