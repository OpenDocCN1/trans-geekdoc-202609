

#### 推断

推断任务包括在给定观测值以及与潜在变量相关的先验函数形式以及涉及的（隐藏）随机（非确定性）参数的情况下，获得后验概率。在第 [13.4](#Chp013_635-716_B9780443292385000196.xhtml#s0040) 节中，选定的先验分别是用于均值的高斯分布和用于协方差矩阵的 Wishart 概率密度函数。正如该节末尾所评论的，概率也可以被视为随机变量，并采用狄利克雷分布作为相应的先验。

在当前设定中，由于混合数 `K` 不是预先选定的，我们将采用 DP 混合过程模型作为先验。在这种建模下，涉及以下潜在变量：

*   变量 `β[i]`，它们与概率 `P[i]` 的计算相关，`i = 1, 2, …`。
*   随机向量 `θ[i]`，它们用于在输入空间中“放置”预选的概率密度函数形式，该函数“发射”观测值 `p(x|θ)`。通常，选择该概率密度函数的函数形式是为了使其与基分布 `G[0]` 形成共轭对。
*   簇分配潜在变量 `k[n]`，`n = 1, 2, …, N`，也称为指示变量。如前所述，有时指示变量写作独热向量 `k[n]`，所有分量均为 0，除了指示第 `n` 个变量关联的混合成分编号的那个位置，其值被设为 1。

在后验的学习阶段，必须估计 (a) Beta 分布的参数 `α` 以及 (b) 定义 `G[0]` 和 `p(·|·)` 的参数。如前所述，在实践中，假设对于预选的 `T` 值，有 `P[i] = 0`，`i > T`。这被称为*截断断棒*表示。毕竟，最多只能有 `N` 个混合成分，即数据点的数量。在最坏情况下，每个点属于不同的簇。此外，我们知道簇的平均数量按 `O(α ln N)` 增长。
