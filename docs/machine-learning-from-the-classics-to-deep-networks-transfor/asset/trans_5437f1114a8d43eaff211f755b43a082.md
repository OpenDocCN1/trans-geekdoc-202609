
重采样是一种非常直观的方法，其中尝试对从 `q` 中抽取的可用样本（粒子）进行*随机*修剪，通过（最有可能）丢弃与低权重相关的样本，并用权重值较大的样本替换它们。这是通过从 `p(x)` 的近似 `p̂(x)` 中抽取样本来实现的，该近似基于公式 [(17.3)](#Chp017_855-884_B9780443292385000238.xhtml#deq3) 中的离散随机测度 `{x[i], W^(i)}[i=1]^N`。在重要性采样中，涉及的粒子从 `q(x)` 中抽取，并适当计算权重以“匹配”期望的分布。增加重采样这一额外步骤后，从 `p` 的离散近似 `p̂` 中抽取一组*新的*无权重样本。使用重采样步骤，我们仍然获得近似按 `p` 分布的样本；此外，低权重的粒子已以高概率被移除，从而增加了下一时刻探索具有较大概率质量区域的概率。从离散分布中采样有不同的方法。

*   **多项式重采样。** 此方法等同于[示例 14.2](#Chp014_717-754_B9780443292385000202.xhtml)中提出的方法。每个粒子 `x[i]` 关联一个概率 `P[i] = W^(i)`。重新抽取 `N` 个（新）粒子将从每个粒子 `x[i]` 生成 `N^(i)` 个“后代”（`∑_{i=1}^N N^(i) = N`），具体取决于它们各自的概率 `P[i]`。因此，`N^(1), …, N^(N)` 将遵循多项式分布（第 [2.3](#Chp002_19-64_B9780443292385000081.xhtml) 节），即：

```
P(N^(1),...,N^(N)) = ( N / (N^(1)...N^(N)) ) ∏_{i=1}^N P_i^(N^(i)).
```
