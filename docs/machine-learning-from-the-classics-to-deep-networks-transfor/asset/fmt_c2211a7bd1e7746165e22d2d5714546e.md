
因此，*ξ*(·, ·) 是一个包含 *K*² 个概率值的表。令 *ξ*(*x*[*n* − 1, *j*], *x*[*n*, *i*]) 对应于 *x*[*n* − 1, *j*] = *x*[*n*, *i*] = 1。那么 *ξ*(*x*[*n* − 1, *j*], *x*[*n*, *i*]) 就是系统在时刻 *n* − 1 和 *n* 分别处于状态 *j* 和 *i* 的概率，条件是给定的观测序列。

在第 [15.7.4](#Chp015_755-803_B9780443292385000214.xhtml) 节中，提出了一种消息传递方案，用于高效计算联合分布的最大值。这也可以应用于与 HMM 相关的连接树。由此产生的算法称为 *Viterbi* 算法。Viterbi 算法直接源自通用的 max-sum 算法。该算法与之前推导的算法相似；只需将求和运算替换为最大值运算。正如我们在讨论 max-product 规则时所评论的，计算使联合概率最大化的完整集合序列（**y**[*n*], **x**[*n*]), *n* = 1, 2, …, *N*，使用回溯，等价地定义了二维网格中的最优轨迹。

除了识别之外，另一个在实践中感兴趣的推理任务是预测，即给定一个 HMM 和观测序列 **y**[*n*], *n* = 1, 2, …, *N*，最优地预测值 **y**[*n* + 1]。这也可以通过适当的边缘化高效地执行（问题 [16.17](#Chp016_805-853_B9780443292385000226.xhtml#o0125)）。

### 16.5.2 HMM 中的参数学习

这是我们第二次提到图模型的学习。第一次是在 [16.3.2](#Chp016_805-853_B9780443292385000226.xhtml#s0050) 节末尾。获取未知参数最自然的方法是最大化联合概率分布的似然/证据。由于我们的任务涉及观测变量和未观测变量，EM 算法是首先想到的方法。然而，将利用 HMM 中潜在的独立性，以提出一个高效的学习方案。未知参数集 Θ 包括：(a) 初始状态概率 *P*[*k*], *k* = 1, …, *K*；(b) 转移概率 *P*[*ij*], *i*, *j* = 1, 2, …, *K*；以及 (c) 与观测相关的概率分布中的参数 **θ**[*k*], *k* = 1, 2, …, *K*。
