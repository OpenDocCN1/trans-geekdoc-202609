
换句话说，计算解变得等价于求解一个特征值-特征向量问题。将公式[(20.115)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq174)代入公式[(20.113)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq172)中的代价函数，并考虑公式[(20.114)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq173)中的约束，结果表明与最优 `y` 相关的代价值等于 `λ`。因此，解是对应于最小特征值的特征向量。然而，`L̃` 的最小特征值为零，且对应的特征向量对应于一个平凡解。确实，观察到

```
L̃ D^(1/2) 1 = D^(-1/2) L D^(-1/2) D^(1/2) 1 = D^(-1/2) (D - W) 1 = 0
```

其中 `1` 是所有元素均等于 1 的向量。换句话说，`y = D^(1/2) 1` 是对应于零特征值的特征向量，它导致平凡解 `z[i] = 1, i = 1, 2, …, N`。即所有点都被映射到实线上的同一点。为了排除这个不希望的解，回顾 `L̃` 是一个半正定矩阵，因此 0 是其最小特征值。此外，如果假设图是连通的，即存在至少一条路径（见第 [15](#Chp015_755-803_B9780443292385000214.xhtml) 章）连接任意一对顶点，`D^(1/2) 1` 是与零特征值 `λ[0]` 相关联的唯一特征向量 [19]。而且，由于 `L̃` 是对称矩阵，我们知道（附录 A.2）其特征向量彼此正交。接下来，我们施加一个额外约束，现在要求解与 `D^(1/2) 1` *正交*。将解约束为与对应最小（零）特征值的特征向量正交，会将解推向对应下一个最小（非零）特征值 `λ[1]` 的下一个特征向量。注意，`L̃` 的特征分解等同于我们之前在第 3 步中称为 `L` 的广义特征分解。

对于 `m > 1` 的更一般情况，我们必须计算与 `λ[1] ≤ … ≤ λ[m]` 相关联的 `m` 个特征向量。事实上，对于这种情况，约束条件防止我们映射到维度小于期望 `m` 的子空间。例如，我们不希望投影到三维空间，而点却落在二维平面或一维直线上。更多细节请参阅富有洞察力的文献 [19]。
