## 2.11

```
ln x ≤ x − 1.
```

## 2.12
证明：

```
I(x; y) ≥ 0.
```

## 2.13
证明：如果 `a[i]`、`b[i]`、`i = 1, 2, …, M` 是满足以下条件的正数：

```
∑_{i=1}^{M} a_i = 1  且  ∑_{i=1}^{M} b_i ≤ 1,
```

则

```
- ∑_{i=1}^{M} a_i ln a_i ≤ - ∑_{i=1}^{M} a_i ln b_i.
```

## 2.14
证明：随机变量的熵在所有可能结果等概率时取得最大值。

## 2.15
证明：在描述区间 `[a, b]` 内随机变量的所有概率密度函数（PDF）中，均匀分布使熵最大化。
