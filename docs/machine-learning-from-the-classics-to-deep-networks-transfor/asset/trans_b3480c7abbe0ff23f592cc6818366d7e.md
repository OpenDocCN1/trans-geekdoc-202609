
在文献[176]中，开发了一个理论框架。从一个属于某个类（设为`y`）的训练样本`x`出发，构建对抗样本的路径是将`x`改变为一个新点（设为`x'`），该点非常接近`x`，但模型将其分类为另一个类`y' ≠ y`。我们用来构建`x'`的模型被称为*攻击模型*。对于每个训练样本`x ∈ ℝ^l`，我们在`x`周围引入一组允许的扰动`S[x](ε) ⊆ ℝ^l`。`S[x](ε)`的一个典型选择是

```
S[x](ε) := {x + δ : ||δ||_p ≤ ε},
```

其中`||·||_p`表示`ℓ_p`范数（参见第[8.3](#Chp008_343-416_B9780443292385000147.xhtml)节），且`ε`足够小。例如，在图像分类任务中，选择`S[x](ε)`是为了捕捉图像间的感知相似性。在文献[176]中，建议将对抗训练视为一个鲁棒优化任务，并修改损失函数，从而产生以下极大极小优化问题，

```
min_θ Σ_(x,y) max_δ L(θ, x + δ, y), s.t. ||δ||_p ≤ ε.
```

(18.73)

公式[(18.73)](#Chp018_885-995_B978044329238500024X.xhtml#deq135)中的优化任务包含两个步骤。关于`δ`的最大化（内层最大化）旨在找到一个实现高损失的对抗版本。关于`θ`的最小化（外层最小化）旨在找到一个模型，以最小化由内层任务给出的“对抗损失”，从而构建一个鲁棒学习器。事实上，可以证明，如果我们选择`x`周围的区域`S[x](ε)`通过`ℓ_∞`范数定义（参见第[9.2](#Chp009_417-462_B9780443292385000159.xhtml)节），且最大化在一步内执行，则公式[(18.72)](#Chp018_885-995_B978044329238500024X.xhtml#deq132)中的`Δx`源于内层最大化。该算法也被称为*快速梯度符号法*（FGSM）。
