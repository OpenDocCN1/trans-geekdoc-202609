
## 迭代加权 ℓ₁ 范数最小化算法

$$w_{j} = \begin{cases} \frac{1}{|\theta_{o,j}|}, & \theta_{o,j} \neq 0, \\ \infty, & \theta_{o,j} = 0, \end{cases}$$

其中 **θ**[*o*] 是目标真实向量，且我们隐含假设 0 ⋅ ∞ = 0。换句话说，参数越小，相应的权重越大。这是合理的，因为较大的权重会在最小化过程中强制相应参数趋向于零。当然，在实践中真实向量的值是未知的，因此建议在最小化过程的每次迭代中使用其估计值。由此产生的方案形式如下。

### Algorithm 10.3

1.  **初始化权重为单位值**，`w[j]^(0) = 1`，`j = 1, 2, …, l`。
2.  **最小化加权 ℓ₁ 范数**，

    **θ**^(*i*) = *arg min*[**θ** ∈ ℝ^(*l*)] ‖**θ**‖[1, *w*] s.t. **y** = *X***θ**。

3.  **更新权重**

    $$w_{j}^{(i + 1)} = \frac{1}{\left| \theta_{j}^{(i)} \right| + \epsilon}, \quad j = 1,2,\ldots,l.$$

4.  **当满足停止准则时终止**，否则返回步骤 2。
