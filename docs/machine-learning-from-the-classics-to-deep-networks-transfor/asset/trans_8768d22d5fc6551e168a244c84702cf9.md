
如果我们将 2 × 2 矩阵 *H* 放在 *I* 的顶部，从左上角开始（[图 18.18](#Chp018_885-995_B978044329238500024X.xhtml#f0100)A 中完整的红色方框表示 *H* 矩阵的位置），则会获得上述结果。然后，我们将两个矩阵重叠部分的对应元素相乘并相加。从物理角度来看，得到的 *O*(1, 1) 值是 *I* 数组中一个*局部*区域的加权平均值。在之前的操作中，图像的对应区域由数组 *I* 左上角 2 × 2 部分内的像素组成。为了获得第二个输出值 *O*(1, 2)，我们将 *H* 向右滑动一个像素，如虚线红色方框所示，并重复上述操作，即

```
O(1, 2) = h(1, 1)I(1, 2) + h(1, 2)I(1, 3) + h(2, 1)I(2, 2) + h(2, 2)I(2, 3).
```

遵循相同的原理，我们滑动 *H* 以“扫描”整个图像数组；因此，又获得了两个输出值，即 *O*(2, 1) 和 *O*(2, 2)。*H* 在 *I* 顶部的四个可能位置在 [图 18.18](#Chp018_885-995_B978044329238500024X.xhtml#f0100)A 中分别用实心红色、虚线红色、深灰色和虚线灰色方框表示。每个位置可获得一个输出值。因此，在上述场景中，第一隐藏层的输出形成一个 2 × 2 数组 *O*。输出数组的每个元素都编码了输入图像不同区域的信息。

在更一般的设定中，两个矩阵 *H* ∈ ℝ^(*m* × *m*) 和 *I* ∈ ℝ^(*l* × *l*) 之间的卷积运算是另一个矩阵，定义为

```
O(i,j) = \sum\limits_{t = 1}^{m}\sum\limits_{r = 1}^{m}h(t,r)I(i + t - 1,j + r - 1),
```
(18.63)

在我们的情况下，*m* < *l*。简而言之，*O*(*i*, *j*) 包含输入数组中一个窗口区域的信息。根据公式 [(18.63)](#Chp018_885-995_B978044329238500024X.xhtml#deq109) 中的定义，元素 *I*(*i*, *j*) 是该窗口区域左上角的元素。窗口的大小取决于 *m* 的值。输出矩阵的大小取决于人们采用何种假设来处理 *I* 边界处的元素/像素。我们稍后将回到这一点。严格来说，在信号处理术语中，公式 [(18.63)](#Chp018_885-995_B978044329238500024X.xhtml#deq109) 称为*互相关*运算。对于卷积运算，正如公式 [(4.49)](#Chp004_119-175_B978044329238500010X.xhtml) 中已定义的那样，首先必须进行索引翻转。^([^(119)](#fn119))
