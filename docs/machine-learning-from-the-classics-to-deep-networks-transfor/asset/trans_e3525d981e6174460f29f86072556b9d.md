

前述的最小误差解释为在大型数据库中识别相似模式，铺平了围绕 PCA 构建高效搜索过程的道路。假设有 `N` 个原型用 `l` 个特征来表示，从而产生特征向量 `x[n] ∈ ℝ^l, n = 1, 2, …, N`，并存储在数据库中。给定一个由特征向量 `x` 表示的未知物体，任务是识别该模式与哪一个原型最为相似。相似度通过欧氏距离 `||x − x[n]||²` 来度量。如果 `N` 和 `l` 很大，搜索最小欧氏距离在计算上可能非常昂贵。其思路是将描述 `N` 个原型在 `span{u[1], …, u[m]}` 上投影的分量 `z[n]^(m) := [z[n1], …, z[nm]]^T`（见公式 [(20.12)](#Chp020_1103-1179_B9780443292385000263.xhtml#deq13)）保留在数据库中，而不是原来的 `l` 维特征向量。假设 `m` 足够大，能够捕捉原始数据的大部分变异性（即数据的内在维数在很好的近似下为 `m`），那么 `z[n]^(m)` 就是一个良好的特征向量描述，因为我们知道在这种情况下 `x̂_n ≈ x_n`。现在给定一个未知模式 `x`，我们首先将其投影到 `span{u[1], …, u[m]}` 上，得到

```
x̂ = ∑_{i=1}^m (u_i^T x) u_i := ∑_{i=1}^m z_i u_i.
``` (20.13)
