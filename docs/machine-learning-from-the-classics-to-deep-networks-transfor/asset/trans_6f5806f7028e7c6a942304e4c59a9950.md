

### 4.7.2 系统辨识

系统辨识在本质上类似于干扰消除任务。请注意，在[图 4.9](#Chp004_119-175_B978044329238500010X.xhtml#f0050)中，基本上是对未知系统进行建模。然而，那里的重点在于复现输出 `y[n]`，而非系统的冲激响应。

在系统辨识中，目标是对未知被控对象的冲激响应进行建模。为此，我们可以获取其输入信号以及其输出的*含噪*版本。任务是设计一个模型，使其冲激响应逼近未知被控对象的冲激响应。为实现这一点，我们对一个线性滤波器进行最优设计，该滤波器的输入与激励被控对象的信号相同，其期望响应为被控对象的含噪输出（参见[图 4.11](#Chp004_119-175_B978044329238500010X.xhtml#f0060)）。相关的正规方程为

```
Σ[u] w[*] = E[u[n] d[n]] = E[u[n] y[n]] + 0,
```

假设噪声 `η[n]` 与 `u[n]` 统计独立。因此，再一次，所得的正规方程就如同我们向模型提供了一个等于未知被控对象无噪输出的期望响应，即表示为 `d[n] = y[n]`。因此，模型的冲激响应被估计为使其输出在均方误差（MSE）意义上接近未知被控对象的真实（无噪）输出。系统辨识在许多应用中具有重大意义。在控制领域，它用于驱动相关的控制器。在数据通信中，它用于估计传输信道，以构建所传输数据的最大似然估计器。在许多实际系统中，都实现了系统辨识方案的在线版本，我们将在后续章节中讨论。

The red line indicates that the error is used for the optimal estimation of the unknown parameters of the filter.](images/B978044329238500010X/gr011.jpg)
