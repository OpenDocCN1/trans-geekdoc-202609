
现在该研究是否可以推导出保证稀疏分析公式解唯一性的条件了。答案是肯定的，且对于精确观测的情况，这已在文献[92]中得到确立。

### 引理 10.1

设 `Φ` 为满火花（full spark）变换矩阵。则对于几乎所有的 `N × l` 感知矩阵，且当 `N > 2(l − C_o)` 时，方程

```
y = Xs
```

至多只有一个余稀疏度至少为 `C_o` 的解。

上述引理保证了优化问题

```
min_s ||Φ^T s||_0, s.t. y = Xs.
```
(10.36)

的解（若存在）是唯一的。

然而，求解前述的 `ℓ_0` 最小化任务很困难，且我们知道其综合对应问题在一般情况下已被证明为 NP-hard 问题。其松弛的凸对应问题是 `ℓ_1` 最小化：

```
min_s ||Φ^T s||_1, s.t. y = Xs.
```
(10.37)

文献[92]推导了保证 (10.36) 和 (10.37) 中 `ℓ_0` 与 `ℓ_1` 任务等价的条件；这是以类似于稀疏综合建模的方式完成的。此外，文献[92]还推导了一种受第 10.2.1 节讨论的正交匹配追踪启发的贪婪算法。关于适用于余稀疏模型的贪婪类算法的深入研究可参见文献[62]。文献[103]提出并理论研究了一种迭代分析阈值法。求解分析建模框架下 `ℓ_1` 优化的其他算法可参见文献[21,49,108]等。NESTA 也可用于分析公式。此外，影响遵循余稀疏分析模型的算法性能的一个关键方面是分析矩阵 `Φ` 的选择。事实证明，使用固定预定义矩阵并不总是最佳实践。作为一种有前景的替代方案，可以利用可用数据学习针对特定问题的分析矩阵（例如 [106,119]）。

## 10.6 案例研究：时频分析

本节旨在演示如何在实际应用背景下利用前面陈述的所有理论发现。稀疏建模已应用于几乎所有领域。因此，挑选一个典型应用并不容易。我们倾向于关注一个较少“宣传”的应用，即分析蝙蝠发射的回声定位信号。然而，分析将在时频表示的框架内进行，这是显著启发压缩感知理论演变的研究领域之一。信号的时频分析已是一个深入研究了数十年的领域，也是最强大的信号处理工具之一。典型应用包括语音处理、声纳探测、通信、生物信号和脑电图（EEG）处理等（参见如 [13,20,57]）。时频分析被广泛用于将时间序列转换为二维图像数组（时频图），随后输入如卷积深度神经网络或 Transformers（第 18 章和第 19 章）以执行各种分类任务。

### Gabor 变换与框架

我们无意呈现 Gabor 变换背后的理论。我们的目标是概述一些基本相关概念，并将其作为载体，帮助不太熟悉的读者更好地理解冗余字典是如何被使用的，并更熟悉其潜在的性能优势。

Gabor 变换由匈牙利裔英国工程师 Dennis Gabor（1900–1979）于 1940 年代中期引入。他最著名的科学成就是全息术的发明，为此他获得了 1971 年诺贝尔物理学奖。
