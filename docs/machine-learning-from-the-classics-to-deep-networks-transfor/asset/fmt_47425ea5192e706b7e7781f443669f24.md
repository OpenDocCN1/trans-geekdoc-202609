
$$
\sigma_{y}^{2} = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\Sigma_{\theta|y}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\left( \frac{1}{\sigma_{\theta}^{2}}I + \frac{1}{\sigma_{\eta}^{2}}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \sigma_{\eta}^{2}\sigma_{\theta}^{2}\mathbf{\phi}^{T}(\mathbf{x})\left( \sigma_{\eta}^{2}I + \sigma_{\theta}^{2}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}).
$$

![Equation](images/B9780443292385000184/si74.png)(12.23)

Hence, given `x` one can predict the respective value of `y` using the most probable value, that is, `μ[y]` in Eq. [(12.22)](#Chp012_583-634_B9780443292385000184.xhtml#deq26). Note that the same prediction value would result via the MAP estimate in Eq. [(12.10)](#Chp012_583-634_B9780443292385000184.xhtml#deq13) (or Eq. [(12.12)](#Chp012_583-634_B9780443292385000184.xhtml#deq15), if `θ[0] = 0`, also obtained via the ridge regression task). Have we then gained anything extra by adopting the Bayesian approach? The answer is in the affirmative. *More information concerning the predicted value is now available, because* Eq. [(12.23)](#Chp012_583-634_B9780443292385000184.xhtml#deq27) *quantifies the associated uncertainty*.
