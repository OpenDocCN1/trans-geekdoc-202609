## 命题 8.2

设 *C* 为希尔伯特空间 ℍ 中的一个闭凸集。则相关的投影算子 `P[C] : ℍ ↦ C` 是非扩张的。

### 证明

设 **x**, **y** ∈ ℍ。回顾性质 [(8.16)](#Chp008_343-416_B9780443292385000147.xhtml#deq31)，即

```
∥P[C](x) − P[C](y)∥² ≤ Real{⟨x−y, P[C](x)−P[C](y)⟩}. (8.21)
```

此外，利用 Schwarz 不等式（本章附录 Eq. (8.149)），我们得到

```
|⟨x − y, P[C](x) − P[C](y)⟩| ≤ ∥x − y∥ ∥P[C](x) − P[C](y)∥. (8.22)
```

将 [(8.22)](#Chp008_343-416_B9780443292385000147.xhtml#deq39) 和 [(8.23)](#Chp008_343-416_B9780443292385000147.xhtml#deq40) 中的不等式结合起来，我们容易得到

```
∥P[C](x) − P[C](y)∥ ≤ ∥x − y∥. (8.23)
```

□

[图 8.12](#Chp008_343-416_B9780443292385000147.xhtml#f0070) 给出了 [(8.24)](#Chp008_343-416_B9780443292385000147.xhtml#deq41) 的几何解释。非扩张性质及其许多变体（例如，[6,7,30,81,82]）在凸集理论和学习中具有至关重要的地位。正是这一性质保证了由一系列连续投影（映射）组成的算法收敛到所谓的*不动点集*，即其元素不受相应映射 *T* 影响的集合，亦即

```
T(x) = x, ∀x ∈ C.
```

在闭凸集上的投影算子情况下，我们知道相应的不动点集就是集合 *C* 本身，因为 `P[C](x) = x, ∀x ∈ C`。
