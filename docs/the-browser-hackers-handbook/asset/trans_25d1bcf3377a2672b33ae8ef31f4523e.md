## Cross-origin Resource Sharing

Cross-origin Resource Sharing，或 CORS，是一项规范，用于让源忽略 SOP。在最宽松的配置下，一个网页应用可以允许来自任何来源的跨源 XMLHttpRequest 访问其所有资源。HTTP 头部会告知浏览器是否允许访问。

CORS 的一个基本组件是向 web 服务器添加以下 HTTP 响应头：

```
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: POST, GET
```

当浏览器向没有返回这些头的服务器发送跨源 XMLHttpRequest 时，不会返回响应内容。这符合预期的 SOP 行为。然而，如果服务器返回了上述头部，现代浏览器会遵循 CORS 规范并允许访问响应内容。

## HTML5

HTML5 是未来的标准。其实不然……它是当前的标准。尽管标准尚未完成，现代浏览器已经实现了核心功能。你现在使用的浏览器极有可能已经支持 HTML5 规范中的许多内容。

HTML5 是 HTML 的下一个标准。它定义了对规范的增量，从而提升网页的功能性和用户体验。

从安全角度来看，最明显的变化是攻击面的扩大。它提供了比前代 HTML4 更多未曾广泛暴露的方法，并且增加了功能使用的排列组合，这共同提高了成功攻击的风险。这在技术进步的大多数情况下都是如此，本身并不应阻碍进步。

本书涵盖了一些增量，但并非全部。在本书后续章节中，用于攻击的那些增量会简要说明。

### WebSocket

WebSocket 是一种浏览器技术，它允许你在浏览器与服务器之间建立一个交互且响应迅速的全双工通信通道。这种行为使你无需轮询服务器即可进行严格的事件驱动操作。

WebSocket 是 Comet 等其他 AJAX 推送技术的替代方案。11 与 Comet 不同，Comet 需要额外的客户端库，而 WebSocket API 已原生集成到现代浏览器中。包括 Internet Explorer 10 在内的所有最新浏览器都原生支持 WebSocket。唯一的例外是某些移动浏览器，如 Opera Mini 和 Android 原生浏览器。

### Web Workers

在引入 web workers 之前，JavaScript 在浏览器中是单线程环境。开发者会使用 setTimeout() 和 setInterval() 来实现类似并发的执行。

HTML5 引入了 web workers，它们可以被视为浏览器线程，因为它们在后台运行。有两种类型：一种在同源的所有运行内容中共享，另一种仅将结果回传给创建它的函数。

API 还有其他限制，但 web workers 为开发者提供了更大的灵活性。这种灵活性同样也为攻击者提供了更多在浏览器中部署攻击的选项。

### History Manipulation

本书涵盖的多种攻击都针对浏览器的历史记录功能。随着网页对浏览器需求的变化，历史记录的能力也在不断演变。

过去，只需跟踪用户点击链接并跳转到另一页时的历史记录即可。如今，点击链接可能通过脚本渲染页面，这被视为用户体验中的一个里程碑。

HTML5 提供了操作历史记录栈的方法。脚本可以使用 history 对象添加或移除位置，也可以前后移动当前页面在历史记录链中的位置。

### WebRTC

Web Real-Time Communication（WebRTC）API 是一个重要的发展，它利用 HTML5 能力和 JavaScript，使浏览器之间能够以低延迟和高带宽进行实时、媒体丰富的通信。

撰写本文时，WebRTC 已在最新的 Chrome、Firefox 和 Opera 浏览器中原生支持。它暴露了直接访问摄像头和音频设备的功能（用于视频会议）。这种高度实用且具有侵入性的技术的安全隐患显而易见。幸运的是，WebRTC 是开源的，因此易于透明分析。

## Vulnerabilities

“vulnerabilities” 这个术语是抽象的集合概念，因而话题较为复杂。可以推断本书的存在全然依赖于所谓的“vulnerabilities”。然而，关于什么是 vulnerability 以及什么不是，定义并不总是清晰。有时，一个 vulnerability 实际上是原本设计的功能，但在后续被证明过于宽容。

更糟的是，一些漏洞类别会有多个名称。整体来看，情况会很混乱。本书在阐述漏洞时，会以攻击的上下文为依据，以确保清晰。

大量书籍专注于利用编译代码中的漏洞。本书不旨在复制这类研究领域。它涵盖了浏览器安全的许多方面，但这个领域太大，不可能在一本或甚至一整排书中完成！

# Evolutionary Pressures

Web 浏览器在信息技术行业中经历了最 dramatic 且令人兴奋的演变之一。当前，浏览器采用前沿的性能、安全和开发技术，在极其激烈的战场上生存或死亡。

浏览器曾是相对简陋的软件。最初的浏览器实现仅用于显示页面并跟随超链接。如今，它们支持插件、摄像头、麦克风、地理位置等功能。不言而喻，这已远离最初的样子。
