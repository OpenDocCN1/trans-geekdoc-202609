# 攻击用户

人类常被认为是信息安全中的“最弱环节”。有许多假设解释为何会如此。是我们固有的“乐于助人”的愿望？还是我们在快速变化的通信和技术前沿缺乏经验？或者，这仅仅是我们（往往）错误地信任彼此？

本章，你将专注于针对键盘前端用户的攻击。讨论的部分攻击利用社交工程战术，类似于前面章节中关于钩选浏览器的方法。其他攻击则利用浏览器特性，并存在对来自多个来源代码的错误信任。
