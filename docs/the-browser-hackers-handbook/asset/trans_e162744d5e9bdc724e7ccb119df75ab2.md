
在方法学的这个阶段，你利用对浏览器的控制，探索从当前位置出发的攻击可能性。攻击形式多种多样，从针对浏览器实例或其所在操作系统的“本地”攻击，到针对任意地理位置中分散的远程系统的攻击。

敏锐的读者会注意到，绕过同源策略（Same Origin Policy）位于攻击封装之上且独立于其他元素。为什么如此？因为它贯穿于所有攻击步骤。这是一种安全控制，在其他利用阶段中会被绕过或被利用。

此外，攻击封装中心的循环箭头显而易见——它远不止是革命性的，几乎任何一个攻击阶段都会暴露信息，从而可能导致在其他任何一个阶段成功发起攻击。从这个位置，你会根据哪个阶段最有可能带来最高回报，在不同类别之间跳转。

七种核心攻击类别被定义为可从浏览器发起的攻击。决定走哪条路径时，多种因素会起作用。主要影响因素包括参与范围的大小、目标的期望以及被钩住浏览器的能力。

### 绕过同源策略

同源策略（SOP）可被视为主要的沙箱。如果你能够绕过它，你就已经通过能够访问之前被浏览器遮蔽的另一个来源而自动实现了成功攻击。绕过 SOP 后，你可以利用其他任何适用的技术，在潜在的连锁反应中攻击这个新揭示的来源。

同源策略的多种解释将在第四章中深入探讨。一旦你拥有绕过方法，就可以毫无阻碍地进行多种攻击。本章节将审查一些不一致之处，以及如何利用浏览器最基础安全控制的漏洞。

### 攻击用户

浏览器黑客方法学中首先提出的攻击选项是“攻击用户”，该内容在第5章中讨论。它涵盖了针对浏览器用户及其对攻击者控制环境的隐含信任的攻击。

利用对浏览器的控制以及操控渲染页面的能力，你可以创建一个环境，诱使用户输入敏感信息以便捕获和利用。你可以诱骗用户在不知情的情况下授予否则受保护的事件发生，例如运行任意程序或访问本地资源。你可以创建隐藏的对话框、透明的框架，或控制鼠标事件来实现此目的，从而掩盖用户界面的真实功能，向用户呈现错误的印象。

### 攻击浏览器

“攻击浏览器”类别包括直接针对浏览器核心本身的攻击。你将在第6章中深入探讨，涵盖从供应商指纹识别到完整利用等多个方面。

浏览器是一个巨大的攻击面。它拥有大量的 API 和抽象层来存储和回忆数据。难怪多年来浏览器一直在遭受各种形式的漏洞侵扰。更令人惊讶的是，浏览器开发者每次都能够正确处理问题。

### 攻击扩展

如果你未能成功攻击核心浏览器，大门并未关闭。你也可以攻击其（可能众多）可选的额外组件。

这在第7章中讨论，方法学将其分类为“攻击扩展”。本章将审查不同变体与具体扩展实现之间的差异。

你将探索各类扩展漏洞类别。扩展漏洞可以被用来利用其中的功能进行跨来源请求，甚至执行操作系统命令。

### 攻击插件

浏览器中传统上最易受攻击的领域是插件。插件与扩展的显著区别在于它们是第三方组件，由服务器页面单方面初始化（而非持久集成到浏览器中）。

“攻击插件”类别在第8章中涵盖。这包括对普遍存在的插件（如 Java 和 Flash）的攻击。你将学习如何发现已安装的插件、揭示各类研究者发现的历史性可利用弱点，以及如何绕过为防止插件滥用而设计的某些安全特性。

### 攻击 Web 应用

浏览器是为使用万维网而设计的，因此“攻击 Web 应用”这一阶段在方法学中也不足为奇。该领域涉及利用浏览器的标准功能来攻击 Web 应用。第9章深入探讨了利用浏览器标准功能进行利用的方法。

想象一下，通常仅在组织内部可访问的内网应用，如果外部网站在另一个标签页中浏览，会发生什么？你会发现，将内网站点视为防火墙保护下安全的假设是明显错误的。

### 攻击网络

你可能没有注意到浏览器连接到非标准端口，但这种情况其实很常见。应用程序经常在任意端口号上安装 Web 服务器，甚至有些 Internet 网站会在除 80 或 443 端口之外的端口上发布内容。

如果浏览器并非连接到 Web 服务器呢？如果它连接的是完全不同的服务，使用完全不同的协议呢？这不会违反同源策略，在大多数情况下，也符合浏览器安全控制的视角。利用这些浏览器行为，可以构建高级攻击场景。

“攻击网络”阶段转向攻击 OSI 模型的低层。在第10章中，你会发现这些技术同样适用于攻击任何 TCP/IP 网络。

# 总结

可以说，本 decade 中浏览器是最重要的软件之一。软件供应商很少为其应用开发定制客户端软件，而是更频繁地使用 Web 技术开发应用用户界面——不仅仅是传统的在线 Web 应用，还包括本地和内网应用。浏览器在服务器-客户端模型中占据主导地位。

浏览器已经在几乎所有网络中发挥作用，即便想要将其从任何组织中移除，也极不现实。组织别无选择，只能在其网络中保留浏览器。

黑客通常伪装成非恶意的 Web 服务器，向浏览器发送合法通信。大多数情况下，浏览器无法感知自己正在与恶意 Web 服务器通信。浏览器会在防火墙保护的所谓安全区域内执行恶意 Web 服务器发送的所有指令。

在本书余下部分，你将掌握方法学并学习如何利用浏览器及其能访问的设备进行攻击。
