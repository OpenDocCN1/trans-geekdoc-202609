
# 本章将带你踏上浏览器黑客之旅的起点。你的第一步是探索重要的浏览器概念以及一些浏览器安全的核心问题。你将探索当今组织防御所需的微型边界范式，并思考那些继续传播不安全实践的谬误。

本章还考察了一种方法论，说明如何发起利用浏览器的攻击。它涵盖了浏览器所呈现的攻击面，以及它如何增加之前被认为受保护的资产的暴露程度。

## 第2章：启动控制

每一次Web浏览器连接到Web时，它都在请求指令。浏览器然后忠实地执行由Web服务器提供的指令。不用说，边界是存在的，但浏览器为攻击者提供了一个强大的环境来发挥作用。

本章通过探索如何在目标浏览器中执行你的代码，带你进入浏览器攻击的第一阶段。你将体验到跨站脚本漏洞、中间人攻击、社交工程等的乐趣。

## 第3章：保持控制

到目前为止讨论的启动技术只能让你一次性执行你的指令。本章介绍如何保持通信和持久性，使你能够以交互的方式控制目标，并能够执行多轮命令。

在典型的黑客会话中，你会希望与浏览器保持通信通道，并且在可能的情况下，跨重启保持对控制的持续。没有这方面，你会很快发现自己不得不一次又一次地诱导目标连接，回到原点。

在本章中，你学习如何使用负载（payload）与浏览器保持通信，从而能够发送多次指令迭代。这将确保在你获得了至关重要的初始连接后，不会浪费任何机会。掌握这些知识后，你现在已准备好在后续章节中发起各种攻击。

## 第4章：绕过同源策略

在最基本的意义上，同源策略（SOP）限制一个网站与另一个网站交互。它可能是Web浏览器安全中最基础的概念。你本应期望它在浏览器组件之间是一致的，并且常见操作的影响是可预测的。本章表明这并非如此。

Web开发者几乎在每个转折点都会被SOP“敲打”；SOP在浏览器本身、扩展程序以及插件上应用方式存在差异。这种不一致性和缺乏理解为攻击者提供了利用边缘情况的机会。

本章探讨了绕过浏览器中不同SOP控制的方法。你甚至会发现拖放操作以及各种UI重定向和时间攻击的问题。本章中一个更令人惊讶的发现是，通过正确的编码，SOP绕过可以将浏览器转变为HTTP代理。

## 第5章：攻击用户

人类常被描述为安全的“最弱链接”。本章专注于针对不安全用户“wetware”（心理/行为层面）的攻击。某些攻击进一步利用了第2章中讨论的社交工程战术。其他攻击则利用浏览器特性以及对接收代码的信任。

在本章中，你将探索去匿名化、隐蔽地启用网络摄像头，以及在无需显式用户介入的情况下运行恶意执行文件。

## 第6章：攻击浏览器

整本册书的主题都是攻击浏览器并绕过其安全控制，但本章专注于所谓的“裸机”浏览器，即没有扩展和插件的浏览器。

本章中，你将探索直接攻击浏览器的过程。你将深入了解浏览器指纹识别，以区分供应商和版本。你还将学习如何发起攻击并 compromise 运行浏览器的机器。

## 第7章：攻击扩展

本章专注于利用浏览器扩展的漏洞。扩展是软件，它在浏览器中添加（或移除）功能。扩展不是像它们的“第二 cousins”（第二亲戚，即插件）那样独立的程序。你可能熟悉LastPass、Firebug、AdBlock和NoScript等扩展。

扩展在受信任的区域执行代码，并拥有增加的权限，同时接收来自不太受信任的区域（如Internet）的输入。这会警报经验丰富的安全专业人士。存在注入攻击的真实风险，实际上，某些攻击导致远程代码执行。

本章中，你将探索扩展攻击的解剖结构。你将深入研究特权提升（privilege escalation）漏洞，这些漏洞将使你获得对受信任浏览器（或chrome://）区域的访问，并导致命令执行。

## 第8章：攻击插件

本章专注于攻击浏览器插件，这些插件是软件，用于为浏览器添加特定功能。在大多数情况下，插件软件可以独立于浏览器运行。

流行的插件包括Acrobat Reader、Flash Player、Java、QuickTime、RealPlayer、Shockwave和Windows Media Player。有些对于你的浏览体验是必需的，有些则用于业务功能。Flash用于YouTube等站点（YouTube可能正在向HTML5迁移），Java则用于WebEx等业务功能。

插件一直受到漏洞的困扰，并且仍然是 exploit（利用）的丰富来源。正如你将发现的，插件漏洞仍然是控制浏览器的最可靠途径之一。

本章中，你将学习如何使用流行的、免费的工具来分析和利用浏览器插件。你将了解如何绕过Click to Play等保护机制，并通过利用插件漏洞来控制目标。

## 第9章：攻击Web应用

你的日常浏览器可以在遵守接受的安全控制的同时，发起强大的Web攻击。浏览器设计用于使用HTTP与Web服务器通信。这些HTTP功能可以被用来针对当前来源之外的目标进行妥协。

本章专注于从浏览器发起而不违反SOP的攻击。你将学习各种技巧，允许跨源指纹识别资源，甚至跨源识别常见的Web应用漏洞。你可能会惊讶于，使用浏览器时，可以发现并利用跨源的跨站脚本（XSS）和SQL注入漏洞。

到本章结束时，你将了解如何实现跨源远程代码执行（cross-origin remote code execution）。你还将发现跨站请求伪造（CSRF）攻击、基于时间的延迟枚举、攻击认证以及拒绝服务（DoS）攻击。

## 第10章：攻击网络

这一最终攻击章节涵盖了通过端口扫描识别内网攻击面的过程，以发现先前未知的主机。探索继续，并介绍了NAT钉子（NAT Pinning）等技术。

本章中，你还将发现利用浏览器直接与非Web服务进行通信的攻击。你将学习如何利用协议漏洞（Inter-protocol Exploitation）技术来 compromise 目标在浏览器内网的系统。
