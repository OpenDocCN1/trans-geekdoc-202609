# ## Abstract

Blockchain is a decentralized technology for managing transactions and data initially developed for the Bitcoin cryptocurrency. A public ledger stores the data, which includes details about every transaction. Blockchain is a distributed key that does not necessitate a middle society. In In Blockchain, all nodes have access to information about every transaction that has ever taking place. Because of this feature, the scheme is clearer than central dealings linking a tertiary party. Additionally, the anonymity of all Blockchain nodes makes it safer for other nodes to verify transactions. This chapter provides a summary of the system.

**Keywords:** Blockchain, decentralization, reliability, bitcoin cryptocurrency, public ledger
