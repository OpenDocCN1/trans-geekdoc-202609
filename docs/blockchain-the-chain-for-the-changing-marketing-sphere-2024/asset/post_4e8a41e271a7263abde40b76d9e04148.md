The system (Dwivedi et al., 2019) encrypts the data for blockchain using ARX algorithms, or symmetric key encryption. Instead of protecting individual nodes, it is focused on protecting the network from attacks. The data is signed with the sender’s private key, also known as the signature key (Figure 9). The receiver’s public key is used for verification on the transmission side. Signer generates the hash value by feeding the data or plaintext into the Hash Function. After that, the plaintext hash value and the signature key are provided to the signature algorithm and sent with the encrypted data. The verifier uses the same hash function to generate the hash value of the received data during the verification process. They also extract the original hash value of plaintext using the Verification algorithm and the signer's public key. If they are the same, the data is verified and did not change during transmission.

## Supply Chain

The decentralized structure, distributed nodes and storage mechanism, consensus algorithm, smart contracting, and asymmetric blockchain encryption ensure network security, transparency, and visibility. Blockchain is a technology with a singular combination of these features. Supply chain (SC) functions, including SC provenance, business process reengineering, and security enhancement, have enormous potential to be transformed by blockchain. By creating an irrefutable record in the public ledger, the blockchain enables a distributed consensus mechanism that makes it possible for all parties involved to be informed of every event and transaction. The demand side and supply side of a given supply chain member’s network make up the supply network. The term “supply side” refers to any supply chain components that contribute directly or indirectly to the primary company. All supply chain members that the product encounters on its way to the final consumer make up the demand side.

A user service framework (Jamil et al., 2019) is the foundation for the developed application, which uses a distributed ledger and smart contract as middleware. The end user uses the application to send the transaction proposal to call backend services like medical prescription, profile management, appointment, EDR, data sharing, pharmacy management, etc., provided by the blockchain network that is being proposed (Figure 13). Complete CRUD operations transform the ongoing data between the connected nodes in the blockchain transaction. The user identity manager provides certificates for user enrollment and authentication. The consensus’s consent manager controls the transaction order and connects a department to a subnetwork through a provided interface. A distributed ledger and nodes make up a drug delivery blockchain’s departments. The node is equipped with a smart contract that either approves the transaction proposal or writes a transaction block to the ledger. The immutable and transparent transactions, logs, and histories of all network events and actions are recorded by distributed ledger technology. The blockchain’s node comprises an intelligent contract, blocks, a state database, and policies. The ledger’s state at a given time is represented and stored in the state database. The connection between the state database and the block is shown in the sample white box representation of a node. Because it is a computer program that can execute transactions and access blockchain blocks and history, an intelligent contract adds functionality to the blockchain.

The Gcoin blockchain (Tseng et al., 2018) records the manufacturers’ direct transfer of transaction data to drug receivers (Figure 14). The chain verifies the drug information, the number of drugs, and the transaction data of the digital signatures of the seller and buyer. The digest of all of this data is then hashed and stored on the Gcoin blockchain. Due to the presence of fraudulent information regarding unspent transaction outputs (UTXO) stored in the Gcoin blockchain, any attempt by an illegal distributor to sell counterfeit drugs to buyers will be deemed invalid. With the correct private key, unauthorized personnel can use this system to purchase drugs. As a result, any transaction irregularities would be immediately apparent to the buyer or seller.
