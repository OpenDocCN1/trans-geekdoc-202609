Researchers have paid much attention to the fact that Bitcoin (Vranken, 2017) can hedge or diversify against conventional assets like stocks, bonds, currencies, or commodities. Numeral information is synchronized, fake, dispersed, and shared through a peer-to-peer system in a distributed ledger. Each connected device keeps the most recent version of the shared ledger. It can only expand the database by adding new blocks to the chain, and the ledger's primary feature is its safety. It is computationally impossible to change records already registered to the chain (Figure 3).
