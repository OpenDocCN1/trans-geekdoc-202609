It is a decentralized ledger for recording, sharing, and confidential maintenance of transactions that cannot be changed or disrupted. The data are stored digitally in blocks i.e., the customers’ data are stored in digital format, which cannot be altered by any common person.

# How Blockchain Technology Works

All information entered is stored in blocks. Only authorized persons can access the data. That specified person can input data. All the transactions are saved in a hash. The first created block does not have a hash. Each block contains a hash that stores all transactions. Each block contains the date and time of the transactions taken over by each owner. These blocks are securely linked to one another which means that the transactions cannot be altered or misused. This process is called an irreversible blockchain.

The data entered is first encrypted i.e., transformed into digital codes which can be saved digitally easily. Then the details of a customer are saved in each separate block, the transactions are stored with all dates, times, and events mentioned clearly. These data cannot be accessed by unauthorized persons, it cannot be changed or removed. It is first coded i.e., encrypted, and later when the customer needs their information this technology decodes the block by cryptography, so it reaches the customer.
