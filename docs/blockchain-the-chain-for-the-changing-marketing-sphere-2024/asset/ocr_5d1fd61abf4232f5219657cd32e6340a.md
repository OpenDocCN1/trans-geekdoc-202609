When a provider node (Lin, et al., 2017) creates a new block, data from a real-time water quality monitoring system is backed up locally and added to the blockchain. Each miner node has a piece of the complete water quality data because it is distributed over the network. The data cannot be accessed in its entirety by any one node. If necessary, the provider node can cross-reference the blockchain data with the backed-up data by creating a query for referencing purposes. To validate the chain, miner nodes in the network contribute their hardware, electricity, and processing power. As a result, the chain is validated, and the reward for each node's “work” is a compilation of all water quality data. A water quality monitoring API makes system operations easier at each node.
