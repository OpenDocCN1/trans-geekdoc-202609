# Introduction

Information and communication technologies (ICTs) have significantly influenced the restructuring of virtual business models that have occurred in the current digital era. Blockchain was the most revolutionary and turbulent technology ever found, and it has significantly changed business structures and opened new opportunities across a variety of industries. Blocks are lengthening lists of data, a part of distributed ledger technology blockchains are securely associated with one another using encryption. The transfer of data, either way, is typically represented as a Merkle tree, where data nodes are represented by leaves, and each block also includes a date and the previous block’s cryptographic hash. The timestamp proves that the transaction data was there now the block was generated. Each block references the preceding ones because each block includes information about the block preceding it. As a result, the blocks function as a chain. Blockchain transactions are therefore irreversible once they are recorded because doing so would require undoing all blocks after it.
