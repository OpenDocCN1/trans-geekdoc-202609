Consensus algorithms and protocols, for example, differ from platform to platform in the blockchain industry. Venues for the blockchain make it easier for users to create and manage transactions.

The interactions between patients and their specialists are the primary data source. The medical history, the current issue, and other physiological data are all included in this data. Using the preliminary information gathered in the first step, an EHR is created for each patient. Only the property’s owner has customized access control for an individual patient with a sensitive EHR. Parties who wish to access this valuable data must submit a request for permission, which is forwarded to the owner of the EHR. The owner will decide who has access. The records are stored in a distributed manner in cloud storage and databases, and a blockchain offers extreme privacy to guarantee authentic user access. The end user who desires access to a safe and sound care delivery system authorized by the owner is a healthcare provider like an ad hoc clinic, community care center, or hospital (Figure 9).

The system (Dwivedi et al., 2019) encrypts the data for blockchain using ARX algorithms, or symmetric key encryption. Instead of protecting individual nodes, it is focused on protecting the network from attacks. The data is signed with the sender’s private key, also known as the signature key (Figure 9). The receiver’s public key is used for verification on the transmission side. Signer generates the hash value by feeding the data or plaintext into the Hash Function. After that, the plaintext hash value and the signature key are provided to the signature algorithm and sent with the encrypted data. The verifier uses the same hash function to generate the hash value of the received data during the verification process.
