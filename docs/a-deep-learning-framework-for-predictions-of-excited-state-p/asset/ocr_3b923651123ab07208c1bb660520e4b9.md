Fig.3 Flowchart for the conformer set, including generation via the stochastic search algorithm, field geometry optimization and configuration filtering based on the RMSE (root-mean square cut-off). Note that RMSE is defined as the root mean square displacement of atoms between a generated conformer and the reference structure. The difference denotes the mean error within the conformer generator.

The cut-off of the 3-dimensional models (MP and SchNet) is also examined, with no correlation found between the prediction accuracy and cutoff radius. Detailed analysis is provided in the supplementary material. Considering the possibility of oscillator strengths, we developed a conformer dataset based on the original D-A molecules by extending the molecular forces, so that much more information (which is of importance for oscillator strengths) can be included in the training input to evaluate the robustness. The conformer set is built through a stochastic search algorithm (evolutionary algorithm) with distance constraints generating conformers that satisfy various constraints using lower/upper bounds on distances and torsional-angle preferences (using the module GetDKit3 as implemented in RDKit). As illustrated in Fig.3, the initial configurations are produced by twisting the molecular fragments along the torsional-angle preferences. As the rotatable bond

is located the donor-acceptor molecule for most TADF molecules, the electrons are excited through a twisted D-A structure. A geometry optimization is then performed on the generated conformations using the MMP4 field^{(18)} to settle the conformers onto a local minimum. A configuration filtering procedure is implemented to rule out the generated conformers with conformational deviations (measured in terms of RMSE) from a cut-off value.

In total, 3650 conformers were generated. The conformers of the original D-A molecules, on average it is equivalent to producing around 2-300 conformers for each molecule. More details relevant to the conformer set construction are given in the supplementary material.
