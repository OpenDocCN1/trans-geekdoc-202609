
例如，考虑[图 8.12](#bodymatter-002.xhtml#b_9781547401567-009_fig_012)所示的三个输入变量簇。可以将 `x[j]` 写为向量 $\overset{ˉ}{x} = \lbrack x_{1},x_{2},x_{3}\rbrack$。如果强制关系 ${\parallel \overset{ˉ}{x} \parallel} = 1$，即要求 $\sqrt{{x_{1}}^{2} + {x_{2}}^{2} + {x_{3}}^{2}} = 1$，则可以有多个向量 ${\overset{ˉ}{x}}_{1},\,{\overset{ˉ}{x}}_{2},\,{\overset{ˉ}{x}}_{3}$ 来表示不同的模式，如[图 8.12](#bodymatter-002.xhtml#b_9781547401567-009_fig_012)所示。目标是将数据分类为 `n` 个模式中的任意一个。模式簇被分组为一组向量数据（在本例中为向量 ${\overset{ˉ}{x}}_{1},\,{\overset{ˉ}{x}}_{2},\,{\overset{ˉ}{x}}_{3}$），使得：`Σ[j]w[kj] = 1`，对所有 `k` 成立。此外，还可以将每个簇的权重表示为向量。例如，第一个簇的权重向量可以表示为：${\overset{ˉ}{w}}_{1} = \lbrack w_{11}\; w_{12}\; w_{13}\rbrack$。

在该竞争学习模型中，通常簇中最中心的元素（或神经元）是获胜者，所有其他权重都会顺应（或对齐）它。竞争学习规则是 `Δw[kj]` 由以下确定：

```
Δw_{kj} = \left\{ \begin{matrix} {{\eta(x_{j} - w_{kj})}\ \ } & {if\, neuron\, k\, wins\, the\, competition} \\ & {\!\!\!\! 0\ \ \ \ \ \ \ \ \ \ \ \ \ {if\, neuron\, k\, loses}} \\ \end{matrix} \right.
```

#### 玻尔兹曼学习模型

玻尔兹曼学习过程源于统计力学，模拟一种随机学习模型。在该模型中，神经元构成一个允许自我反馈的循环结构。神经元取 +1 或 –1 的二进制值。该模型表示为：

```
E = - \frac{1}{2}\Sigma_{j}\Sigma_{k}w_{kj}x_{k}x_{j}\quad{where}\quad j \neq k
```

可见神经元是输出层。如[图 8.13](#bodymatter-002.xhtml#b_9781547401567-009_fig_013)所示的内部神经元是隐藏神经元。该模型被视为随机模型，因为一个外部神经元的变化会改变 `E` 的值。神经元 `x[k]` 从一种状态翻转到另一种状态的概率定义为：

```
P\left( {x_{k}\rightarrow - x_{k}} \right) = \frac{1}{1 + \exp(\frac{- \Delta E_{k}}{T})}
```

因翻转导致的 `E[k]` 变化用 `ΔE[k]` 表示。如果 `E` 被视为能量函数，则 `ΔE[k]` 是神经元状态翻转引起的能量变化。变量 `T` 是伪温度，代表噪声或随机性的水平。在玻尔兹曼网络中，神经元可以处于钳制状态或自由状态。神经元的钳制状态意味着其值被设定且不可改变。自由状态意味着神经元的值可以在该运行状态下改变。设定两个变量：

`P[kj]^+`：钳制状态下神经元 `k` 和神经元 `j` 之间的相关性

`P[kj]^-`：自由状态下神经元 `k` 和神经元 `j` 之间的相关性

则玻尔兹曼学习规则定义为：

`Δw[kj] = η(P[kj]^+ − P[kj]^-) where j ≠ k`。

### 8.10 选定的分析模型

由于集成框架使用多个模型进行分类和预测，因此必须密切关注每个模型的准确性。我选择以下四种模型用于集成，因为每种模型都提供了特定的优势和特性，使其适用于特定类型的数据和预测。此外，已有证据表明这些模型是用于分类最准确的神经网络模型之一。以下是每种 ANN 方法的优缺点总结（[Masters 1995](#bibliography.xhtml#b_9781547401567-016_ref_051)）：

1.  **PNN** – 概率神经网络是四层网络。它们以非参数方法对数据进行分类，且对异常值数据不敏感。已证明，仅使用输入、模式、求和和输出感知机四层的概率神经网络，能比反向传播神经网络提供更准确且相对更快的分类（[Principe, Euliano, Lefebvre 1999](#bibliography.xhtml#b_9781547401567-016_ref_064)）。

2.  **SVM** – 支持向量机网络。SVM 通过构建一个定义超平面的双层网络来执行分类，该超平面将数据分离为多个类别。SVM 是一种非概率二元线性分类器。它接受一组输入数据，并确定输入属于哪个可能的类别。SVM 非常适合数据元素的分类和聚类。

3.  **GFN（广义前馈）采用 LM 训练** – 前馈神经网络由一个或多个节点层组成，信息仅单向流动，从输入节点向前传播，网络中没有循环或回路。在多层模型中，每个节点都与后续层中的节点有直接连接。每个节点中计算权重与输入的乘积之和（[Haykin 1998](#bibliography.xhtml#b_9781547401567-016_ref_030)）。我在该 GFN 模型中使用 Levenberg-Marquardt（LM）算法作为核心方法。我将在后续章节解释 Levenberg-Marquardt 算法。

4.  **MLP 采用 LM 训练** – 多层感知机，一种类似于带可变步长修正的梯度下降法的方法。该模型已提出多种变体，包括 Levenberg-Marquardt 模型（[Wilamowski & Chen 1999](#bibliography.xhtml#b_9781547401567-016_ref_089)），后者被公认为最高效的算法之一。

[下一节](#bodymatter-002.xhtml#b_9781547401567-009_s_008_s_010)将对本书中使用的四种神经网络方法进行更深入的数学回顾。

### 8.11 概率神经网络
