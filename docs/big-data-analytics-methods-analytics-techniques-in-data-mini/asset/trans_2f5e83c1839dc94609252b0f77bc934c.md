
(29) `Δw[i][j] = (d[j] − y[j]) * x[i]`

新的突触权重将使用以下公式计算，进行多次迭代，直到 `Δw[i][j]` 小于用户设定的给定阈值：

(30) `w[i][j][new] = w[i][j][old] + Δw[i][j]`

可以使用 `η` 来表示公式 (29) 中的下降率。因此 `η` 是学习率，它随着每次迭代减少总误差 `E`，研究者可以定义它来调节 `Δw[i][j]`，即下降率。

### 8.9 神经网络学习过程

神经网络中有五大类学习模型。其中一种称为基于误差修正的学习方法，已在 [第 8.8 节](#bodymatter-002.xhtml#b_9781547401567-009_s_008_s_008) 的梯度下降法下进行了讨论。其他四类是：

*   基于记忆的学习
*   基于 Hebb 规则的学习
*   竞争学习
*   Boltzmann 学习模型

这些学习方法改编自 Sengupta (2009)、Zeruda ([1997](#bibliography.xhtml#b_9781547401567-016_ref_094))、Wang (2012)、Masters ([1995](#bibliography.xhtml#b_9781547401567-016_ref_051)) 和 Haykin (1998)。它们经过了针对本框架的提炼和修订，并为追求完整性而收录于此。

#### 基于记忆的学习

基于记忆的学习旨在保持输入向量与输出之间的关系。给定由 `{x[i] = 1}^(N)` 定义的输入向量 $\bar{x}$，以及期望输出 `d[i]`，这种关联可以用表达式 `{x[i], d[i]}[i = 1]^(N)` 表示。当模型应用于新模式 ${\bar{x}}_i$ 时，由于该模式最初是未知的，让我们从测试模式 ${\bar{x}}_{test}$ 开始，并求出 ${\bar{x}}_{test}$ 向量与新模式 ${\bar{x}}_i$ 向量之间的欧几里得距离。假设 ${\bar{x}}_N' \in \{ x_1, x_2, x_3, \ldots, x_N \}$ 是 ${\bar{x}}_{test}$ 向量的最近邻点集合，这意味着模式 ${\bar{x}}_i$ 到 ${\bar{x}}_{test}$ 的距离在所有 ${\bar{x}}_i$ 的集合中是最小的。这可以通过以下表达式表明，对于所有 `i` 的距离均成立：

(31) `min (over i) d{ x_i, \bar{x}_{test} } = d(\bar{x}_N', \bar{x}_{test})`

为了改进该算法，审慎的做法是查看最近邻，并找到提供最小距离的集合。正如 [图 8.9](#bodymatter-002.xhtml#b_9781547401567-009_fig_009) 所示，基于记忆的学习非常适合模式识别和数据分类。这种方法有助于将离群值排除在分类之外。这就是 K 近邻分类。假设我们要对一个新数据点进行分类。在 [图 8.9](#bodymatter-002.xhtml#b_9781547401567-009_fig_009) 中，标记为 `x[i]` 的新点必须在 “+” 形状或 “O” 形状之间进行分类。由于其最近邻是 “O” 形状，因此它将被归类为 “O” 集合的成员。

![Figure 8.9: Classification using memory based learning.](graphic/converted/b_9781547401567-009_fig_009.jpg)

图 8.9：使用基于记忆的学习进行分类。

#### 基于 Hebb 规则的学习

基于 Hebb 规则的学习的目标是保持输入向量与输出之间的关联。该方法归功于神经生物学家 Donald Hebb，他在 1949 年提出了学习过程中大脑神经元适应的理论。在 Hebb 学习过程中，权重 `w[kj]` 的调整量定义为：

(32) `Δw[kj](n) = f(y[k](n), x[j](n))`

Delta 是 `w[kj]` 的变化量。这是在时间步 `n` 时 `w[kj]` 的调整。该调整表示为时间步 `n` 时响应 `y[k]` 和输入 `x[j]` 的函数。你可以用突触前和突触后的响应来重写此表达式：

(33) `Δw[kj] = η * y[k](n) * x[j](n)`

其中 `η` 是学习率。该表达式称为 *活动乘积规则*。重要的是要注意 `η` 是常数。假设保持 `x[j]` 不变，则可以绘制 `Δw[kj]` 和 `y[k](n)`，得到一条截距过原点、斜率为 `η * x[j](n)` 的直线，如 [图 8.10](#bodymatter-002.xhtml#b_9781547401567-009_fig_010) 所示。随着 `y[k]` 的增加，`Δw[kj]` 也随之增加。最终突触权重达到饱和点，无法再进行更多学习。

让我们定义 $\bar{x}$ 和 $\bar{y}$ 为 `x[j]` 和 `y[k]` 的时间平均值。则可以定义：

```
x_j(n) = x_j - \bar{x}; y_k(n) = y_k - \bar{y}.
```

![Figure 8.10: Slope of the activity product rule represents the rate of learning.](graphic/converted/b_9781547401567-009_fig_010.jpg)

图 8.10：活动乘积规则的斜率代表学习率。

根据协方差的定义，可以将权重 `w[kj]` 的变化写为 `x[j]` 和 `y[k]` 距其各自时间平均值 $\bar{x}$ 和 $\bar{y}$ 的距离的协方差。

(34) `Δw_kj = η(x_j - \bar{x})(y_k - \bar{y})`

由于期望的是整个 `x[j]` 输入值的平均变化效果，$\bar{x}$ 可以被视为在 `x[j]` 过程中保持常数。这种关系可以用一条与 `Δw[kj]` 和 `y[k]` 相交的直线来表示，如 [图 8.11](#bodymatter-002.xhtml#b_9781547401567-009_fig_011) 所示。该图显示了给定点 `x[j]` 处 `Δw[kj]` 和 `y[k]` 之间的关系，使得 `(x_1 - \bar{x})` 为常数。

![Figure 8.11: The covariance relationship between response and input.](graphic/converted/b_9781547401567-009_fig_011.jpg)

图 8.11：响应与输入之间的协方差关系。

应用协方差方法时，可能出现三种情况：

(35)
```
(i)    若 x_j > \bar{x} 且 y_k > \bar{y}，则 w_kj 增加
(ii)   若 { a) x_j < \bar{x} 且 y_k > \bar{y}
                                  b) x_j > \bar{x} 且 y_k < \bar{y} } 任一成立，则 w_kj 减少
(iii)  若 x_j < \bar{x} 且 y_k < \bar{y}，则 w_kj 增加
```

#### 竞争学习

在 *竞争学习* 中，每个神经元竞争以增加其响应值，同时最小化其他神经元的输出。获胜的神经元将在未来的学习迭代中被优先选择。竞争学习的数学模型基于：

(36)
```
y_k = { 1 if v_k > v_j, for all j when j ≠ k.
      { 0 otherwise
```

所有 k 的权重总和均设为 1：

`Σ[j] w[kj] = 1`
