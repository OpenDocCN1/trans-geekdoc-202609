The value of bias is always 1. Bias is added to add flexibility to the behavior of the neural network. It’s added to all of the input and hidden layers of the model. Adding bias is analogous to adding an intercept in a regression model. If a neural network does include a bias, for certain input values, it may not be able to produce a value other than “0” as its output.

### 8.4 Activation Functions

One of the key features of artificial neural networks is that a linear neuron output can map into a non-linear activation function (Haykin 1998, Sengupta 2009, [Zurada 1997](#bibliography.xhtml#b_9781547401567-016_ref_094)). Activation functions play an important role to transform the output of the perceptron and shape the result before it’s fed into the next layer. The activation function may clip the value or transform it into a function. There are three types of activation functions.

Given inputs `x[0]`, `x[1]`, …, `x[n]`, the output `ν[k]` is the result of summation from [Equation (10)](#bodymatter-002.xhtml#b_9781547401567-009_eq_001) and `Y[k] = φ(⋆)` is the result of the activation function. The activation function results in an S-shaped curve known as the *sigmoid function*.

In the first type, as `v[k]` changes from −∞ to +∞ the output can vary from 0 to 1, namely `y[k] = [0, 1]`. This is the logistics function shown in [Figure 8.5](#bodymatter-002.xhtml#b_9781547401567-009_fig_005). The activation function for this type of neural network is shown as:

(13) `φ(⋆) = 1 / (1 + exp(-av))`

(14) `φ(⋆) = { 1 when v → +∞; 0 when v → -∞ }`

This is the simplest neuron formulation. It’s possible to change the shape of the S-curve by changing the values of `a`. When `a` is small, the curve appears as a smooth function, meaning it is curved like an “S” as shown in [Figure 8.5](#bodymatter-002.xhtml#b_9781547401567-009_fig_005). But, when `a` is very large, this function approaches the threshold function, a model proposed by Pitts and McCollough (It’s also known as the Pitts-McCollough model). In that case, the curve looks more like a step as shown in [Figure 8.7](#bodymatter-002.xhtml#b_9781547401567-009_fig_007).

![Figure 8.5: Sigmoid function for activation function vk between [0,1].](graphic/converted/b_9781547401567-009_fig_005.jpg)

**Figure 8.5: Sigmoid function for activation function v[k] between [0,1].**

The second type of activation function has a range from ‒1 to +1, shown with the following equation:

(15) `φ(v) = tanh(av)`

The `tanh(.)` is the hyperbolic tangent function computed as follows:

(16) `tanh(v) = (e^v - e^{-v}) / (e^v + e^{-v})`

The activation function `φ(v)` is determined according to the value of `v`:

(17) `φ(⋆) = { 1 when v → +∞; -1 when v → -∞ }`

The shape of S-curve representing this activation function is shown in [Figure 8.6](#bodymatter-002.xhtml#b_9781547401567-009_fig_006).
