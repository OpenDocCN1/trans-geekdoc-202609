
It can be observed that `K(x,y)` becomes small as `y` grows further from `x`. The inner product `K(.)` can have many possible kernels. Each kernel is essentially a solver that includes a sigmoid function. (Recall from our earlier description of neural networks that the output of each perceptron was shaped by using a sigmoid function). One of the most commonly used is based on the Gaussian:

(47) $K(x_{i},x) = e^{( - \frac{{\parallel {x - x_{i}} \parallel}^{2}}{2\sigma^{2}})}$

where `σ` > 0, and sigmoid kernels `K(x[i], x)` = `tanh(θ < x[i], x > + ϑ)` such that

(48) `θ` > 0, `and` `x` > + `ϑ`.

### 8.13 General Feed-forward Neural Network

A feed-forward neural network consists of one or more layers of nodes where the information flows in only one direction, forward from the input nodes and there are no cycles or loops in the network. The simplest networks have a single layer that feeds input data to the output layer via a series of weights.

One of the popular training methods is the gradient descent algorithm. The following is a mathematical development of the gradient descent method, adapted from Sengupta (Sengupta 2009) and Zurada ([Zurada 1997](#bibliography.xhtml#b_9781547401567-016_ref_094)) and improved for this framework.

For a given neural network with `n=1, …, N` layers, you can compute the error for each node. By definition the error at time snapshot `n`, for node `j` computed by:

(49) `e[j](n)` = `d[j](n)` − `y[j](n)`

And for computing total error of a network, recall [Equation (21)](#bodymatter-002.xhtml#b_9781547401567-009_eq_012) provides that:

(50) $E(n) = \frac{1}{2}\sum_{j}{{e_{j}}^{2}(n)}\,\,\,\,\,\,\,{for}\,\,\,\,\,\,\, j = 1\,\,\,\,\, to\,\,\,\,\, m.$

Then you can compute average error of a network by:

(51) $E{(N)_{Avg}} = \frac{1}{N}\sum_{n = 1}^{N}{E(n)}$

Let’s use the traditional Pitts-McCullough equation to compute:

(52) $v_{j}(n) = \sum_{i = 0}^{m}{w_{ji}(n)}y_{i}(n),$

where `v[j](n)` is the input to the activation function for the neuron `j`. The term `v[j](n)` can be perceived as the induced local field, while `y[i](n)` can be thought of as the output from the previous layer, shown by:

(53) `y[i](n)` = `φ(v[j](n))`

Given the prior introduction, it’s possible to start the mathematical derivation of the back-propagation method. First it’s easy to calculate the partial derivative of `E(n)` and apply the chain rule to obtain the following:

(54) $\frac{\partial E(n)}{\partial w_{ji}(n)} = \frac{\partial E(n)}{\partial e_{j}(n)} \cdot \frac{\partial e_{j}(n)}{\partial y_{j}(n)} \cdot \frac{\partial y_{j}(n)}{\partial v_{j}(n)} \cdot \frac{\partial\nu_{j}(n)}{\partial w_{ji}(n)}$

Where `Δw[i][j]` is applied to `w[i][j]`. Let’s apply the derivatives to each component above (from [equation 54](#bodymatter-002.xhtml#b_9781547401567-009_eq_045)):

$\frac{\partial E(n)}{\partial e_{j}(n)} = e_{j}(n)$
$\frac{\partial e_{j}(n)}{\partial y_{j}(n)} = - 1$

$\frac{\partial y_{j}(n)}{\partial v_{j}(n)} = \varphi^{\prime}\left( {v_{j}(n)} \right)$, and you can take derivative of `φ(v[j](n))` when the exact function is known.

$\frac{\partial\nu_{j}(n)}{\partial w_{ji}(n)} = y_{i}(n)$

Now it’s possible to write the result of substitutions as:

(55) $\frac{\partial E(n)}{\partial w_{ji}(n)} = - e_{j}(n)\varphi^{\prime}\left( {v_{j}(n)} \right)y_{i}(n)$

When adjustment of `Δw[j][i](n)` (namely the correction to `w[j][i](n)`) is applied to `w[j][i](n)` the following relationship can be obtained:

(56) $\Delta w_{ji}(n) = - \eta\frac{\partial E(n)}{\partial w_{ji}(n)} = \eta\,\,\, e_{j}(n)\varphi^{\prime}\left( {v_{j}(n)} \right)y_{i}(n)$

This equation is a reminder that `Δw[j][i](n)` is proportional to $\frac{\partial E(n)}{\partial w_{ji}(n)}$ at a rate of proportionality `η`, negative to the direction of the gradient. Part of the term in (55) can be described as error multiplied by the activation function. This term can be shown as:

(57) $\partial_{j}(n) = - \frac{\partial E(n)}{\partial v_{j}(n)} = - \frac{\partial E(n)}{\partial e_{j}(n)} \cdot \frac{\partial e_{j}(n)}{\partial y_{j}(n)} \cdot \frac{\partial y_{j}(n)}{\partial v_{j}(n)}$
(58) `∂[j](n)` = `e[j](n)` `φ`^′(`v[j](n)`)

The term `∂[j](n)` is the derivative of error with respect to the activation function `v[j](n)`. This is the gradient for neuron `j` and is local to neuron `j`. This is also known the *local gradient*. Now one can rewrite [Equation (56)](#bodymatter-002.xhtml#b_9781547401567-009_eq_047) as:

(59) `Δw[j][i](n)` = `η` `∂[j](n)` `y[i](n)` `where` `y[i](n)` `is` `the` `input` `to` `neuron` `j`.

Since the values for `η` and `y[i](n)` are known it’s possible to compute `∂[j](n)`. Two cases are possible:

*   **Case 1)** Neuron `j` belongs to the output layer, hence `∂[j](n)` can be calculated from [Equation (54)](#bodymatter-002.xhtml#b_9781547401567-009_eq_045).
*   **Case 2)** Neuron `j` belongs to a hidden layer, thus `∂[j](n)` must be computed differently.

A fundamental condition for back-propagation is that you can compute `∂[j](n)`, namely that the derivative of the activation function is possible. Let’s examine this approach graphically to illustrate the hidden layer and output layer computations as shown in [Figure 8.16](#bodymatter-002.xhtml#b_9781547401567-009_fig_016). The signal flow graph in [Figure 8.16](#bodymatter-002.xhtml#b_9781547401567-009_fig_016) shows that `j` is the hidden layer and `k` is output layer neurons.

You can compute `∂[j](n)` by the following derivations. It’s known that:

(60) $\partial_{j}(n) = - \frac{\partial E(n)}{\partial\nu_{j}(n)} = - \frac{\partial E(n)}{\partial y_{j}(n)} \cdot \varphi^{\prime}\left( {v_{j}(n)} \right)$

Also recall from [Equation (50)](#bodymatter-002.xhtml#b_9781547401567-009_eq_041) that:

$E(n) = \frac{1}{2}\Sigma_{k}e_{k}^{2}(n)$, where `k` is the set of output layer neurons. It can be shown that:

(61) $\frac{\partial E(n)}{\partial y_{j}(n)} = \Sigma_{k}e_{k}(n)\frac{\partial e_{k}(n)}{\partial y_{j}(n)} = \Sigma_{k}e_{k}(n)\frac{\partial e_{k}(n)}{\partial v_{k}(n)} \cdot \frac{\partial v_{k}(n)}{\partial y_{j}(n)}$
(62) `Since` `e[j](n)` = `d[j](n)` − `y[j](n)` = `d[j](n)` − `φ(v[j](n))`

Let’s take derivatives of the left hand side:

(63) $\frac{\partial e_{k}(n)}{\partial v_{k}(n)} = - \varphi^{\prime}\left( {v_{k}(n)} \right)$

For neuron `k`, it’s possible to write:

(64) `ν[k](n)` = `Σ[j=0]^(m)` `w[k][j](n)` `y[j](n)`

Consequently by taking the derivative of (64), it results in the following:

(65) $\frac{\partial v_{k}(n)}{\partial y_{i}(n)} = w_{kj}(n)$
(66) $\frac{\partial E(n)}{\partial y_{j}(n)} = - \Sigma_{k}e_{k}(n)\varphi^{\prime}\left( {v_{k}(n)} \right)w_{kj}(n) = - \Sigma_{k}\partial_{j}(n)w_{kj}(n)$

From [Equation (60)](#bodymatter-002.xhtml#b_9781547401567-009_eq_051) and ([66](#bodymatter-002.xhtml#b_9781547401567-009_eq_057)) one can conclude that:

(67) `∂[j](n)` = `φ[j]`^′(`v[j](n)`) ⋅ `Σ[k]` `∂[k](n)` `w[k][j](n)`
