

# 可靠性

可靠性可定义为：产品在规定条件下运行时，在其预期寿命内满意地执行其预期功能的概率（[Kapur 2010](#bibliography.xhtml#b_9781547401567-016_ref_036)）。由此技术描述可推导出临床定义：可靠性是指患者在医疗服务提供者的医疗护理下，在住院期间不发生特定医疗并发症的概率。可靠性通过多个指标进行衡量，例如 `mean time between failure`（平均故障间隔时间，MTBF）、`failure rate`（故障率）和 `percentiles of life`（寿命百分位数）。每个测量值均可通过相应方程计算得出，这些方程源自经验和统计分布函数。

一般来说，时间 `t` 的可靠性表示为 `R(t)`。故障由 `f(t)` 测量，即故障时间（随机变量 `T`）的概率密度函数。随机变量 `T` 的累积分布函数用 `F(t)` 表示。因此，可以写出以下表达式来定义 `F(t)`、`f(t)` 和 `R(t)`：

```
(101) F(t) = P [T ≤ t] = ∫[0]^(t) f(τ) dτ
(102) f(t) = dF(t)/dt
(103) R(t) = 1 − F(t)
```

关于可靠性的更多论述，请参阅 Kapur 和 Lamberson 的著作（[Kapur, Lamberson 1977](#bibliography.xhtml#b_9781547401567-016_ref_037)）。

# 附录 C：反向传播算法推导

一般来说，存在两类学习过程：`batch mode`（批量模式）和 `sequential mode`（顺序模式）。这些数学计算的条件之一是函数 `φ[j](v[j](n))` 必须连续且可微，以便获得 `φ[j]'(v[j](n))`。此外，将 `η` 作为学习率的选择，设置为适当的值至关重要。反向传播是最速下降算法的一种近似。如果研究人员使用较小的 `η`，存在获得不稳定结果的风险。[Rumelhart (1986)](#bibliography.xhtml#b_9781547401567-016_ref_068) 建议根据此算法向学习率 `η` 添加动量值：

## 情况 1

如果对于所有 `n`，`∂E(n)/∂w_{ji}(n)` 符号相同，则可以说 `|Δw[kj]|` 幅度增长。这代表加速下降的情况。

## 情况 2

相反，如果 `∂E(n)/∂w_{ji}(n)` 在每次迭代中交替变号，则 `|Δw[kj]|` 幅度较小，比第一种情况更可控。动量项之所以重要，是因为它能加速学习，同时也有助于避免局部最优。

反向传播算法采用以下八个步骤。此内容改编自 [Zurada (1997)](#bibliography.xhtml#b_9781547401567-016_ref_094) 和 [Sengupta (2009](#bibliography.xhtml#b_9781547401567-016_ref_070))：

给定 `p` 个训练对，表示为：`{z[1], d[1], z[2], d[2], …, z[P], d[P]}`，

其中 `z[i]` 为 `(I X 1)`，`d[i]` 为 `(K X 1)`，且 `i = 1, 2, …, P`。

### 步骤 1

选择 `> 0`，`E[max]`。权重 `W` 和 `V` 初始化为较小的随机值。`W` 为 `(K X J)`，`V` 为 `(J X 1)`。初始化 `q`、`p` 和 `E`：

```
q ← 1, p ← 1, E ← 0
```

### 步骤 2

开始训练。呈现输入并使用以下公式计算各层输出：

```
Δw_i = c f(w_i^t x) x:
z ← z_p, d ← d_p
y_j ← f(V_j^t z), for j = 1, …, J
```

其中 `V[j]` 为列向量，即 `V` 的第 `j` 行，且

```
o_k ← f(W_k^t y), for k = 1, …, K
```

其中 `W[k]` 为列向量，即 `W` 的第 `k` 行。

### 步骤 3

通过比较期望输出与网络输出来计算 `error value`（误差值）：

```
E ← E + 1/2 (d_k - o_k)^2 for k = 1, …, K.
```

### 步骤 4

计算两层的误差信号向量 `δ[o]` 和 `δ[y]`。向量 `δ[o]` 为 `(K X 1)`，`δ[y]` 为 `(J X 1)`。本步骤中输出层的误差信号项为：

```
δ_{ok} = 1/2 [(d_k - o_k)(1 - δ_k^2)] for k = 1, …, K
```

本步骤中隐藏层的误差信号项计算如下：

```
δ_{yj} = 1/2 (1 - y_j^2) ∑_{k=1}^{K} δ_{ok} w_{kj}, for j = 1, …, J
```
