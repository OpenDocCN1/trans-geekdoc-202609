| 0 | 1 | 1 |

可以开发一个 3 层神经网络来计算每对输入 `x[1]` 和 `x[2]` 的结果。还引入了一个称为 `bias`（偏置）的第三个输入来构建模型。偏置的值始终为 1。添加偏置是为了增加神经网络行为的灵活性。它被添加到模型的所有输入层和隐藏层中。添加偏置类似于在回归模型中添加截距。如果神经网络包含偏置，对于某些输入值，它可能无法产生除“0”以外的输出值。

### 8.4 激活函数

人工神经网络的关键特性之一是线性神经元输出可以映射为非线性激活函数（Haykin 1998, Sengupta 2009, [Zurada 1997](#bibliography.xhtml#b_9781547401567-016_ref_094)）。激活函数在转换感知机输出并将结果塑形后再馈入下一层方面发挥着重要作用。激活函数可能会剪切数值或将其转换为一个函数。共有三类激活函数。

给定输入 `x[0]`、`x[1]`、…、`x[n]`，输出 `ν[k]` 是[公式 (10)](#bodymatter-002.xhtml#b_9781547401567-009_eq_001) 求和的结果，而 `Y[k] = φ(⋆)` 是激活函数的结果。激活函数产生一条称为*S 型函数*的 S 形曲线。

在第一类中，当 `v[k]` 从 −∞ 变化到 +∞ 时，输出可以从 0 变化到 1，即 `y[k] = [0, 1]`。这是[图 8.5](#bodymatter-002.xhtml#b_9781547401567-009_fig_005)所示的逻辑斯谛函数。此类神经网络的激活函数表示为：

(13) `φ(⋆) = 1 / (1 + exp(-av))`

(14) `φ(⋆) = { 1 when v → +∞; 0 when v → -∞ }`

这是最简单的神经元公式。通过改变 `a` 的值，可以改变 S 型曲线的形状。当 `a` 很小时，曲线呈现为平滑函数，意味着它像“S”一样弯曲，如[图 8.5](#bodymatter-002.xhtml#b_9781547401567-009_fig_005)所示。但当 `a` 非常大时，该函数趋近于阈值函数，这是 Pitts 和 McCollough 提出的模型（也称为 Pitts-McCollough 模型）。在这种情况下，曲线看起来更像一个阶跃，如[图 8.7](#bodymatter-002.xhtml#b_9781547401567-009_fig_007)所示。

![图 8.5：激活函数 vk 在 [0,1] 之间的 Sigmoid 函数。](graphic/converted/b_9781547401567-009_fig_005.jpg)

**图 8.5：激活函数 v[k] 在 [0,1] 之间的 Sigmoid 函数。**

第二类激活函数的范围从 ‒1 到 +1，用以下公式表示：

(15) `φ(v) = tanh(av)`

`tanh(.)` 是双曲正切函数，计算如下：

(16) `tanh(v) = (e^v - e^{-v}) / (e^v + e^{-v})`

激活函数 `φ(v)` 根据 `v` 的值确定：

(17) `φ(⋆) = { 1 when v → +∞; -1 when v → -∞ }`

表示此激活函数的 S 型曲线形状如[图 8.6](#bodymatter-002.xhtml#b_9781547401567-009_fig_006)所示。

![图 8.6：vk 在 [‒1, 1] 之间的激活函数。](graphic/converted/b_9781547401567-009_fig_006.jpg)

**图 8.6：v[k] 在 [‒1, 1] 之间的激活函数。**
