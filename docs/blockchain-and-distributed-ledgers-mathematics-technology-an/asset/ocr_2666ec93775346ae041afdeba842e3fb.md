# 4.14 Exercises

+   1. Decrypt the message $m_1$, encrypted with an affine cipher,

```
$m_1 = ZLDDRVL W F FD LEBYHOILGFIA
SFVLEYL PLH JQ ULEVIA QJNY $
```

+   2. Decrypt the message $m_2$, encrypted with a Vigenère cipher by using a hint from $m_1$,

```
$m_2 = ORMGBSQ VVQOI URZFEQF VVWQKJRZ
WPU SFVIFQ AEF DZEU UAKALDTDU $
```

+   3. Solve the problem described in the encrypted message $m_2$.

+   4. Design a physical system along the lines of Chaum’s DigiCash for an anonymous
voting system.

+   5. Describe the birthday paradox. Calculate how many people need to be in the room
that the probability of two have the same birthday (day) and be 99%.
What about 99.9%? Build the graph of this probability as a function of the number
people. What does it mean for the security of a 512-bit hash function $f=f(x)$?
many people need to be in the room to guarantee the probability of them
having the same birthday by 95%?

+   6. Consider an elliptic curve

```
$E_p = \{x, y) : y^2 = x^3 + 7\} \pmod p$.
```

where $p = 127 = 2^7 - 1$ is the first Mersenne prime. How many integer points are
in this elliptic curve? Compare your answer with Hassel’s. Prove that the point
$\alpha = (19, 32)$ belongs to $E_p$, and construct a sequence of $eta_n = \alpha^n, n=1, \dots, 100$. Explain
in which words this is suitable for encryption purposes, and if so,
how.

+   7. Use the MD5 algorithm as an inspiration and construct your hash function $y =
h(x)$, which maps an input $x$ of any length to an output $y$ with the length of 32 bits.
Is it a good hash function? If not, can you produce a collision, i.e., find two distinct\messages $x, x'$ such that $h(x) = h(x')$?

+   8. Design an efficient implementation of the Random Oracle function of your
32-bit long output. Can you produce a collision, i.e., find two distinct messages
x, x'$ such that $h(x) = h(x')$?

+   9. Explain how one can use a good hash function to protect users’ passwords. How would
you try to break it? What is a dictionary attack?
