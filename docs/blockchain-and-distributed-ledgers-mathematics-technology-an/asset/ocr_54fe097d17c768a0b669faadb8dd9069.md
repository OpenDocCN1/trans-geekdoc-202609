The generalized hyperbolic distributions are used when large deviations from the mean are essential, for example, to model financial instruments. It is the most general distribution we include in our analysis. The Student's $t$ and the normal-inverse Gaussian distributions belong to the class of generalized hyperbolic (GH) distributions. Unfortunately, the class of generalized hyperbolic distributions is not closed under a linear combination of its members, making it very difficult to aggregate daily returns to monthly or annual, see next section.

The hyperbolic distribution, which is a special case of $\mathcal{GH}$ with $\lambda = 1:$

```
$H(\alpha, eta, \delta, \mu) = \mathcal{GH}(\alpha, eta, \delta, 1, \mu),$
```

is used as a candidate for fitting BTC returns; see Barndorff-Nielsen (1977). However, our experience suggests that the corresponding fit is generally not good, so for brevity, we omit the corresponding calculations.

Straightforward comparison of the corresponding characteristic function confirms the well-known fact that the Normal and Cauchy distributions are special cases of the special distribution:

```
$\mathcal{N}(\mu, \sigma^2) = S\left(2, 0, \frac{\sigma}{\sqrt{2}}, \mu\right),$
```

```
$C(\delta, \mu) = S(1, 0, \delta, \mu).$
```

The Student's $t$, and normal-inverse Gaussian are the special (or limit) cases of the generalized hyperbolic distribution:

```
$\mathcal{ST}(\mu, v, \sigma) = \mathcal{GH}(0, 0, \sqrt{v}\sigma, -\frac{v}{2}, \mu).$
```

```
$\mathcal{NIG}(\alpha, \beta, \delta, \mu) = \mathcal{GH}(\alpha, \beta, \delta, -\frac{1}{2}, \mu).$
```

The normal and Cauchy distributions can be obtained in the limit as well, although neither of these distributions belong to the $\mathcal{GH}$ class.

Each distribution is fitted by the classical method of maximum likelihood; e.g., Hamilton (2020) among numerous others. We introduce the quantile in $L(\Theta)$ as follows:

```
$ln L(\Theta) = \sum_{n=1}^{N} inf(x_n, \Theta),$
```
