To verify the signature, we need to compare $P_3 = P_1 + P_2$ and $B$, where

```
$P_1 = ms^{-1} \times G, \quad P_2 = rs^{-1} \times A. \quad (4.154)
```

If the signature is correct, we get

```
$ms^{-1} \times G + rs^{-1} \times A = (m + rk) s^{-1} \times G\n\n$(m + rk)(m + kr)^{-1}(l^{-1})^{-1} \times G = l \times G = B. \quad (4.155)
```

Some sizes used in ECDSA: secret key — 256 bits; public key — 512 bits; message — 256 bits; signature — 512 bits.
A simple example is in order. $E_{127}$ with $G = (45, 33)$, as above. Choose a secret key $k = 48$, then the corresponding public key (or address) is

```
$A = k \times G = (96, 51). \quad (4.156)
```
