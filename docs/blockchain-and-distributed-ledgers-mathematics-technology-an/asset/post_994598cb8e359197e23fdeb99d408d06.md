
## 4.4 Elements of number theory

### 4.4.1 The set of integers modulo n

For a given $n$, we are interested in the set of integers $\{0, 1, ..., n-1\}$. Setting the trivial case of $n=2$, we need to distinguish two cases: (a) $n$ is an odd prime; (b) $n$ is a composite number.

- (a) Let $n$ be an odd prime $p$. We can define the finite field $\mathbb{F}_p$ as a finite field with elements represented by the set of integers $\{0, 1, ..., p-1\}$. Recall that a field is a set on which addition, subtraction, multiplication, and division are defined and have properties similar to real numbers' corresponding operations.

We define addition and multiplication modulo $p$:

```
$a+b=c \pmod p, \quad a \times b=c \pmod p. \quad (4.24)$
```

It is easy to adapt standard algorithms for ordinary integer arithmetic for addition and multiplication in $F_p$. The additive identity or zero element is the integer 0, and the multiplicative identity is the integer 1. Of course, we need to define subtraction and division of field elements. To this end, it is convenient to define the inverse (negative) or multiplicative inverse of a field element. For $b \in \mathbb{F}_p$, the additive inverse $-b$ is $-b=p-b$. The multiplicative inverse $b^{-1}$ of $a$ in $\mathbb{F}_p$ is the unique solution $x$ to the equation:

```
$b \times x=1 \pmod p. \quad (4.25)$
```

which can be found via the extended Euclidean algorithm, discussed below. Division and subtraction are defined in terms of addition and multiplicative:

```
$a-b=(a+(-b)) \pmod p, \na/b=a \times b^{-1} \pmod p. \quad (4.26)$
```

- (b) Let $n$ be a composite number, say $n=pq$. Then the set $\mathbb{F}_n$ of integers $\{0, 1, ..., n-1\}$ is a ring, not a field. Recall that a ring is a set equipped with addition and multiplication operations with properties similar to the operations on real numbers. The reason why $\mathbb{F}_n$ is a ring and not a field is clear—while subtraction is always possible, that $a-b$ is well defined for any $a, b \in \mathbb{F}_n$, division $a \times b^{-1}$ is only possible when $b$ and $n$ are co-prime so that the greatest common divisor of $b$ and $n$ is 1, $gcd(b,n)=1$.

It is important to understand that for asymmetric cryptography purposes, the plaintext and ciphertext spaces are either $\mathbb{F}_p$ or $\mathbb{F}_n$.

### 4.4.2 The Euclidean algorithm

The Euclidean algorithm finds the greatest common divisor (GCD) $c$ of two natural numbers $a$ and $b$, which is the largest natural number that divides both $a$ and $b$ without a remainder.

It proceeds inductively step by step as follows:

| Step# | Operation |
|---|---|
| 0 | $r_{-2} = q_0r_{-1} + r_0$, |
| 1 | $r_{-1} = q_1r_0 + r_1$, |
| 2 | $r_0 = q_2r_1 + r_2$ |
| ... | ... |
| $N$ | $r_{-N-2} = q_Nr_{-N-1}$. |

where $r_{-2} = \max(a, b)$, $r_{-1} = \min(a, b)$. Since the remainders $r_n \geq 0$ decrease with every step, the algorithm eventually runs its course and stops. The corresponding $gcd c = r_{N-1}$.

### 4.4.4 Fermat's little theorem

Given the above, we can prove the following useful and exciting theorem.

**Theorem 4.2** Fermat's little theorem: If $p$ is a prime number and $\gcd(A, p) = 1$ ($p$ does not divide $A$), then

> $A^{p-1} \equiv 1 \pmod p$.

The proof is straightforward and archetypal for other theorems. Modular multiplication by $A$ is one-to-one since $A^{-1}$ exists. Thus, numbers

> $A \times i \pmod p, i = 1, \dots, p - 1$.

are distinct. Accordingly,

$$(A \times 1) (A \times 2) \dots (A \times (p-2)) \times (A \times (p-1))$$
$$= 1 \times 2 \dots \times (p-2) \times (p-1) \bmod p. \quad (34)$$

The product $1 \times 2 \dots \times (p-2) \times (p-1)$ is invertible because every factor is invertible, so that the theorem holds. QED

### 4.4.5 Euler's theorem

Euler's theorem is an exciting and very useful generalization of Fermat's little theorem.

**Theorem 4.3** Euler's theorem: if $\gcd(A, n) = 1$, then

$$A^{\phi(n)} = 1 \pmod n, \quad (35)$$

where $\phi(n)$ is the Euler's totient equal to the number of integers $1 \le m < n$, such that $\gcd(m, n) = 1$. The proof is straightforward (but an efficient calculation of $\phi(n)$ is anything but simple!). Since $\gcd(A, n) = 1$, $A^{-1}$ exists, and multiplication by $A$ is one-to-one. The set of integers $0 < m < n$, such that $\gcd(m, n) = 1$ is closed with respect to multiplication by $A$. Denote these integers by $m_1, \dots, m_{\phi(n)}$. As before

$$(A \times m_1) (A \times m_2) \dots (A \times m_{\phi(n)-1}) \times (A \times m_{\phi(n)})$$
$$= m_1 \times m_2 \dots \times (\phi(n)-1) \times \phi(n) \bmod n. \quad (36)$$

Since the product $m_1 \times m_2 \dots \times \phi(n)$ is invertible, we have claimed. QED

$$A^{\phi(n)} = 1 \pmod n, \quad (37)$$

If $n$ is prime, then $\phi(p) = p-1$ (why?), then we recover Fermat's little theorem. Given Euler's theorem, calculations $\pmod n$ in the exponent are equivalent to calculations $\pmod n$ in the exponent. Euler's totient function is tough to compute! However, for cryptographic purposes described below, it is sufficient to consider a semiprime number $n$ that is the product of two prime numbers $p, q, n = pq$. In this case, we have

$$\phi(n) = (p-1)(q-1). \quad (38)$$

For a practical application of this theorem, see Section 4.5.5.

## 4.5 Finite ring cryptography

### 4.5.1 Modular exponentiation

Consider a large natural number $n$. For a given $x$, $0 < x < n$, we can define its modular exponent as follows

$$y = x^x \bmod n. \quad (39)$$

The inverse function can be written in the form:

```
x = y^d \pmod n. (440)
```

Of course, for an arbitrary $n$, finding the corresponding $d$ is extremely difficult. However, it is easy to do in some cases, while in other instances, it is easy to provide that some additional information about $n$ is known.

### 4.5.2 A good trapdoor function?

Let's start with $n = p$, where $p$ is a large prime number. Given Fermat's little theorem, we can efficiently perform calculations $\pmod{(p-1)}$ in the exponent. Indeed, if

```
y = x^e \pmod p. \quad (41)
```

then

```
x = y^d \pmod p. \quad (42)
```

provided that

```
ed = 1 \pmod {(p-1)}. \quad (43)
```

It is clear that we have to have $\gcd(e, p-1) = 1$ for Eq. (40) to be solvable. In this case, the extended Euclidean algorithm can be used to find $d = e^{-1} \pmod{(p-1)}$. Too! We cannot use exponentiation $\pmod p$ as a trapdoor function, since it is too easy to invert! Not a good choice. The germ of an idea nevertheless. We can try to use a semiprime $n = pq$.

### 4.5.3 A good trapdoor function!

Given Euler's theorem, for a given $n = pq$, general $\phi(n)$ is extremely difficult to compute. However, if someone *knows* that $n = pq$, computation of $\phi(n)$ is straightforward, but the problem is that large $n$ cannot be factored efficiently! Thus, solving

```
y = x^e \pmod n. \quad (44)
```

is as hard as factoring $n = pq$. Thus we have our trapdoor function, or at least, we hope so. Of course, if we know the actual factors, we can use Euler's theorem and write $x$ as

```
x = y^d \pmod n. \quad (45)
```

where

```
ed = 1 \pmod{\phi(n)}, d = e^{-1} \pmod{\phi(n)}. \quad (46)
```

### 4.5.4 RSA encryption-decryption

To start with, we show how the encryption-decryption works in the RSA framework. Denote the message and ciphertext as $m$ and $c$, respectively. The algorithm proceeds as follows:

- (1) Bob chooses secret primes $p$ and $q$, and sets $n = pq$.
- (2) Bob chooses $e$ with $\gcd(e, \phi(n)) = 1$.
- (3) Bob computes $d$ so that $de = 1 \pmod{\phi(n)}$.
- (4) Bob makes $n$ and public keeps $p, q,$ and $d$ secret.
- (5) Alice encrypts $m$ as $c = m^e \pmod n$.
- (6) Alice sends $c$ to Bob.
- (7) Bob computes $m = c^d$ and recovers Alice's message $m$.

If $n$ is prime, then $\phi(p) = p-1$ (why?), then we recover Fermat's little theorem. Given Euler's theorem, calculations $\pmod n$ in the exponent are equivalent to calculations $\pmod n$ in the exponent. Euler's totient function is tough to compute! However, for cryptographic purposes described below, it is sufficient to consider a semiprime number $n$ that is the product of two prime numbers $p, q, n = pq$. In this case, we have

$$\phi(n) = (p-1)(q-1). \quad (38)$$

For a practical application of this theorem, see Section 4.5.5.

### 4.5.5 RSA digital signature algorithm

We summarize the digital signature algorithm, along the lines of the original RSA paper:

- (1) Alice chooses secret primes $p$ and $q$, and sets $n = pq$.
- (2) Alice chooses $e$ with $\gcd(e, \phi(n)) = 1$.
- (3) Alice computes $d$ so that $de = 1 \pmod{\phi(n)}$.
- (4) Alice makes $n$ and public keeps $p, q,$ and $d$ secret.
- (5) Alice signs $m$ as $s = m^d \pmod n$.
- (6) Alice sends $s$ and $m \pmod n$;
- (7) Bob computes $m' = s^e$ and compares it with $m$;

If $m' = m$, then Alice has signed the message properly.
