$x+y=2, \quad x_0=y_0=1. \quad (10.54)
```

Thus,

```
$y(x)=2-x, \ \left|\frac{dy}{dx}\right|=1. \quad (10.55)
```

In terms of $x, y$, the constant product rule given by Eq. (6.4) can be written as:

```
$xy=1, \quad x_0=y_0=1. \quad (10.56)
```

so that

```
$y(x)=\frac{1}{x}, \quad \left|\frac{dy}{dx}\right|=\frac{1}{x^2}. \quad (10.57)
```

Finally, Eq. (6.7) written in terms of $x, y$ becomes:

```
$$\left(\frac{1}{xy}-1\right)-\alpha\left(\frac{x+y}{2}-1\right)=0, \quad (10.58)
```

The mixed rule implies the following relation between $X$ and $Y$:

```
$Y = \frac{-((1-\alpha)X_0 + \alpha X) + \sqrt{((1-\alpha)X_0 + \alpha X)^2 - \frac{4\alpha X_0}{X}}}{2\alpha} \quad (10.53)
```

```
$$\frac{dY}{dX} = \frac{1}{2}-1+\frac{\left|\frac{dY}{dX}\right|}{\sqrt{(1-\alpha)X_0 + \alpha X)^2 - \frac{4\alpha X_0}{X}}}
```

We now analyze the situation, when $P$ moves away from its equilibrium value $P_0=1$. For the constant contract, an arbitrageur can choose a number $x > 1$ and deliver $(x-1)N T_1$ tokens to the pool in exchange for getting $(1-y)N T_2$ tokens, where $y = 1/x$. In this case, the arbitrageur's profit or loss is given by

```
$\Omega(x) = P\left(1-\frac{1}{x}\right)(x-1)N. \quad (10.66)
```

The profit is maximized when

```
$\Omega'(x) = \left(\frac{P}{x^2}-1\right)N = 0. \quad (10.67)
```
