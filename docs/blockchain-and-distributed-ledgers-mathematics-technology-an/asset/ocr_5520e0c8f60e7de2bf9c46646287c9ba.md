# 4.7.4 Projectivization of elliptic curves

In this subsection, we briefly discuss connections between elliptic curves and projective geometry. The fact that the vertical line passing through the points (x,y) and (x,-y) belonging to the elliptic curve intersects it with symmetry rather than two points deserves additional discussion.

To elaborate, we need to ‘lift’ elliptic curves from the affine (x,y) plane to the projective (X : Y : Z) plane. This procedure is called the projectivization. We proceed as follows. Consider an affine elliptic curve. Let $x = X/Z, y = Y/Z$, as the form:

```
$Y^2Z = X^3 + AX^2 + bZ^3.$
```

in the (X, Y, Z) space. We eliminate the origin (0,0,0) to avoid ambiguity since it belongs to every elliptic curve.
Eq. (4.130) is homogeneous of degree 3. Thus, if $(X, Y, Z)$ is a point on the curve, so is $(\lambda X, \lambda Y, \lambda Z)$ for any $\lambda$. To avoid having “too many” points, we define two-dimensional projective space as the set of equivalence classes of nonzero points $(X, Y, Z)$, where $(X, Y, Z)$ and $(\lambda X, \lambda Y, \lambda Z)$ are considered to be equivalent. Intuitively, the three-dimensional space is reduced to two dimensions by treating lines through the origin as a single point. We use the notation $(X : Y : Z)$ for a projective point to emphasize this fact. Thus, $(X : Y : Z) = (\lambda X : \lambda Y : \lambda Z)$, $\lambda \neq 0$.

It is clear that for $Z \neq 0$, we can divide $X$ by $Z$, $Y$ by $Z$, consider $x = X/Z = Y/Z$ and get a solution of the affine equation.

However, if $Z = 0$, the division by $Z$ is not allowed, so there are points on the projective curve that do not correspond to points on the elliptic curve. These points have form $(0 : y : 0)$, for any $y \neq 0$. Given that points in the projective plane are defined as equivalence classes, we can choose the following point $O = (0 : 1 : 0)$, called the point at infinity or the neutral element. We can intuitively think that $O$ is a point located infinitely high (and low) on the $y$-axis.

Consider a vertical straight line by the following equation in the affine plane:

```
$x - \bar{x} = 0.$
```

In the projective plane, it looks as follows:

```
$X - \bar{x}Z = 0.$
```

The point $O$ belongs to this line for any $\bar{x}$. Thus, after projectivization, we find the third point, in addition to $(\tilde{x}, \tilde{y})$, belonging to the elliptic curve and the straight line, and this point is the point at infinity, $O$.
