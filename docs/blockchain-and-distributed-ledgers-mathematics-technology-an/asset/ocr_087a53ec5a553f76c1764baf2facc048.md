# 4.7.8 The standard elliptic curve sec256r1

First, we describe the U.S. government standard, which we use sec256r1, the “r” in the penultimate position stands for “random,” which is believed to be secure. In the spirit of trusting the government, Bitcoin deliberately itself uses a somewhat different curve, sec256k1, the “k” in the penultimate position stands for “Koblitz,” see below.

The curve sec256r1 is characterized by the sextuple $T = (p, a, b, G, (G_x, G_y), n, h)$. The corresponding parameters, which are described in Certicom Research (2009), *inter alia*, have the form:

```
$$\begin{aligned} p &= fffffffff0000000000000000000000000 \ & 00000000ffffffffffffffffffffffffffffffff \ & 00000000000000000000000000000000 \ & 000000000000000000000000ffffffffffffffff \ a &= 56ac5d83aa3a9e73ebbd5d5769886bc \ b &= 651d06b0cc53b0f63bce3c3e27d2604b9 \ & 6b17d1f2e12c4247f8bce6563a44a0f2 \ G_x &= 770d738b12deb3a0f4a13945d98c296 \ & 4fe342e2ef1a7f9b8ee7a4c7c09e16 \ G_y &= 2b263573b155cecb6406837bf51f5 \ n &= fffffffff00000000ffffffffffffffffffffffffffff \ h &= b6e6aada7179eae4f3b9cac22cf632551 \end{aligned}$
```

It is clear that the corresponding $p$ can be written as follows:

```
$p = 2^{256} - 2^{224} + 2^{192} + 2^{96} - 1$,
```

it is a generalized Mersenne prime.
