# 10.11 Automated market makers

We already introduced AMMs in Section 6.9.5 and discussed some qualitative aspects of their activity. We now study technical details of automated market making. Consider an AMM, capable of making markets between two tokens TN1, TN2. Initially, we set the proportional transaction costs to zero. Later, we incorporate nonzero transaction costs. As in Section 6.9.5, we consider three, defined by the constant sum rule (6.2), constant product rule (6.4), and mixed rule (6.7); see Figure 6.12. Simple algebra leads to the reader as an exercise that the mixed rule implies the following relation between X and Y:

```
$Y = \frac{-((1 - \alpha)\Sigma_0 + \alpha X) + \sqrt{((1 - \alpha)\Sigma_0 + \alpha X)^2 - \frac{4\alpha\Pi_0\Sigma_0}{X}}}}{2\alpha} \quad (10.53)$
```

```
$$\frac{dY}{dX} = \frac{1}{2}-1+\frac{\left|\frac{dY}{dX}\right|}{\sqrt{((1 - \alpha)\Sigma_0 + \alpha X)^2 - \frac{4\alpha\Pi_0\Sigma_0}{X}}}$
```

where, as before, X, Y denote the quantities of TN1, TN2, respectively, and $\alpha$ represents the mixing coefficient between constant sum and constant product rules.

Of course, the objective of any AMM is to profit. This profit comes from transaction fees charged by the pool. However there is the so-called impermanent loss, caused by a drop in the collateral value below its buy-and-hold level. This loss is impermanent under the assumption that $P$ is mean-reverting, which might or not be accurate. Introducing x, y, such that $X=Nx, Y=Ny$, we rewrite Eq. (6.1) as follows:

```
$x+y=2, \quad x_0=y_0=1. \quad (10.54)$
```

Thus,

```
$y(x)=2-x, \quad \left|\frac{dy}{dx}\right|=1. \quad (10.55)$
```

In terms of x, y, the constant product rule given by Eq. (6.4) can be written as:

```
$xy=1, \quad x_0=y_0=1. \quad (10.56)$
```

so that

```
$y(x)=\frac{1}{x}, \quad \left|\frac{dy}{dx}\right|=\frac{1}{x^2}. \quad (10.57)$
```

Finally, Eq. (6.7) written in terms of x, y becomes:

$$\left(\rac{1}{xy}-1\right)-\alpha\left(\rac{x+y}{2}-1\right)=0, \quad (10.58)$
