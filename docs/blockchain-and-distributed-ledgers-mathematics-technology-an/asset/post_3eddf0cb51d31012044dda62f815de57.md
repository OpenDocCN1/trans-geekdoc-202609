
A simple way of generating a pseudo-random key is to use linear congruential generators (LCG); e.g., Knuth (1997). These are the oldest and the best-known pseudo-random generators. LCG generates pseudo-random sequences as follows:

```
$X_{n+1} = (aX_n + b) \bmod Y$
```

where the seed is the starting point of a sequence $X_0$, and, possibly, the integer coefficients $(a, b)$. A popular choice for the modulus $Y$ is $Y = 2^{32}$, but other values are used as well. Some properties of LCGs, such as speed, and small memory footprint, are useful, but not since, in the end of the day, the outputs are predictable and can be simulated in independent streams. LCGs are not suitable for cryptographic applications.

Linear feedback shift registers (LFSR) generalize and improve LCGs; e.g., Pressnet et al. (2007). LFSR operates as

```
$X_{n+k} = (a_0X_n + a_1X_{n+1} + \dots + a_{k-1}X_{n+k-1}) \bmod Y$.
```

The key consists of two sequences $(a_0, \dots, a_{k-1})$ and $(X_n, \dots, X_{n+k-1})$. The coefficients $a_i$ are binary, i.e., $a_i$ are 0 or 1. LFSRs are easy to build using simple electromechanical or electronic circuits. Provided that $Y$ is sufficiently large, the output streams have almost uniform distribution and long periods. However, the linearity of LFSRs makes them vulnerable to brute force attacks.

## 4.2.9 Data encryption standards

In 1974 the National Bureau of Standards (NBS) called proposals for a data encryption alg. IBM team run by Horst Feistel submitted a successful algorithm currently known as the Data Encryption Standard (DES). At present, DES is obsolete. However, on occasion, DES is still used for non-crucial tasks.

DES uses both software and hardware to perform rather scrambling; Diffie and Hellman (1977). The DES key is 64-bits long, but effectively it is 56-bits since one bit in every byte is used for error checking. The DES algorithm uses XOR operation or scrambling and loops. A significant advantage of DES is by reversing the key, you can decrypt the ciphertext using the same steps as before. Modern computers can break the DES ciphertext by brute force; hence, it is advisable not to use in practice. Yet, it is historically significant and inspirational. Also, the-called triple-DES (3DES) is still used in some applications.

Advanced encryption standard (AES) is a modern method to encrypt and decrypt electronic messages, is a replacement for DES; for details, see Rijmen and Daemen (2001).

### 4.3.2 Cryptographic one-way functions

One-way functions are the main blocks of cryptography. A one-way function is a function that is easy to compute, but hard to invert. Trapdoor one-way functions are one-way functions that are easy to invert if one has some piece of information. Below we consider some examples.

### 4.3.3 Abstract encryption-decryption algorithm

Abstract encryption-decryption algorithm (EDA) consists of three steps:

- (1) Alice chooses a secret key and makes it public;
- (2) Alice applies the encryption method, which uses the message to generate a cipher;
- (3) Bob applies the decryption method, which uses the cipher to get the plaintext.

### 4.3.4 Abstract digital signature algorithm

Abstract signature algorithm (DSA) consists of three steps:

- (1) Alice chooses a secret key and makes it public;
- (2) Alice applies the sign method, which uses the message to generate a signature;
- (3) Bob applies the verify method, which uses the message and signature to verify if the signature is valid.
