we restrict ourselves to a particular choice of x. As their names suggest, strong collision
resistance is more challenging to achieve than collision resistance.

Strongly-resistant hash functions come handy if one wants to create hash handles to
t entries in an extensive database and be sure that no two entries have the same handle.
Weakly-resistant hash functions can be used to ensure that a particular password, stored in
a database of hashed passwords, cannot be easily broken.

Somewhat disappointingly, we do not know whether strongly or weakly collision-
resistant hash functions exist at all! Moreover, there is no real evidence that one
construct such hash functions. Thus, although hash functions are widely used, their
collision-resistance is a more matter of faith than rigorous mathematical proof.

# 4.9.3 Signatures and hash functions

As mentioned earlier, it is practical to sign the message. Fortunately, it is sufficient
to sign its hash. However, signing a hash adds another vector of attack and poses
t following problem. Suppose that Charlie has the pair (m, sign(h(m))) signed by
Alice, and wants to pretend that she signed her message m' instead, which would be easy
to do if h(m') = h(m), because, obviously,

```
$$sign(h(m)) = sign(h(m'))$$ (4.163)
```

Thus, a good hash function h(m) should make it difficult to find m' such that
h(m') = h(m), i.e., that it is a weakly collision-resistant hash function.
