### 6.8.4 预言机

如 6.8.1 节所述，如果没有良好的预言机，部署有意义的 SC 往往是不可能的。然而，这种预言机很难构建，因此，并不意外的是，可能的技术供应短缺，这严重限制了现有 SC 的用性；见 Beniichecke (2020)。

> ⁵ 这种僵化是以太坊特有的。某些协议允许升级 SC。

> ⁶ 这种攻击发生在臭名昭彰的 2016 年 6 月 17 日 DAO 攻击中。

明显但最理想的方法是使用中心化的预言机提供者。这种方法与以太坊的设计哲学背道而驰，因为它创建了中心化的控制点且不可篡。一些开发者依赖公证来确保其预言机的正确行为。这是 provable.xyz 协议背后的想法。然而，这些证明可以很容易被验证而不需要进一步的递归。

或者，可以通过人工输入非结构化数据来获取预言机数据。只要人类参与者获得适当激励，这种众包预言机就可以以足够去中心化的方式提供答案；见 Peterson 等人 (2015)。然而，从本质上说，人工输入预言机价格昂贵、缓慢且范围有限。

ChainLink 设计了针对前两种解决方案的有趣替代方案，形式为部分中心化的、基于声誉的预言机网络；见 Elis 等人 (2017)。ChainLink 架构构建高效——它由一个基础的链上数据聚合系统组成，并用更全面的链下共识机制进行增强。Chainlinked 支持类似于 eBay 反馈系统的声誉和安全监控服务。通过依赖提供者，用户可以相应地选择它们，并在极端情况下享受可靠的数据馈。ChainLink 网络依赖于以太坊协议，因为它的原生 LINK 是一个 ERC-220 代币，并增强了一些 ERC-223 功能。用户必须支付 LINK 给 ChainLink 以获取服务。2020 年，LINK 代币成为投机者的宠儿并大幅升。

### 6.9.2 代币与标准

ERC-20 代币标准作为开创者，存在一些缺点。ERC-223 代币标准取代 ERC-20 并获得了广泛关注。ERC-223 标准比其前身更安全，因为它允许代币进入无法接收和处理的合约。尽管如此，许多现有代币仍依赖 ERC-20 标准。ERC-721 代币是唯一的，想象可以视为独特的收藏品。由于 ERC-721 代币是唯一的，它们可以代表所有权，如地契、艺术和数字收藏品。

ERC-20 代币的同质性意味着单个单位是相同且可替的。每个 ERC-20 合约有三个强制函数。此外六个可选强制函数，其含义自言自懂：

- totalSupply(), returns (uint256); totalSupply 获取代币总量。
- balanceOf(address_owner), returns (uint256); balanceOf 获取账户余额。
- transfer(address_to, uint256 value), returns (bool success); transfer 将 _value 代币发送给 _to。
- transferFrom(address_from, address_to, uint256 value), returns (bool success); transferFrom 从 _address_from 向 _to 发送 _value 量代币。
- approve(address_spender, uint256 value), returns (bool success); 允许支出者从账户中提取预设价值金额。调用时，此函数将覆盖当前的允许额另一个值。
- allowance(address_owner, address_spender), returns (uint256); allowance 返回 address_spender 被允许从 address_owner 提取的金额。

第三个是0到18之间的整数。如果 Decimal 为 0，它是最小单位；如果 Decimal 为 18，10⁻⁸ 是不可分割的基单位，类似于 wei。
