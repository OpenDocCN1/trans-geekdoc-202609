Comparison of Figures 4.6 and 4.7 makes it clear that the Schnorr DSA is more efficient than the ElGamal DSA. Signatures are generated $mod q$ instead of $mod p$. Thus, the amount of calculations is reduced, and the speed is increased. At the same time, security is based on the difficulty of the discrete log problem $mod p$. For verification, we can use two exponentiations rather than three in ElGamal's algorithm, which is naturally faster.

How do we generate the numbers we need, i.e., $p, q, a$? To start, we generate $q$. Then, we create a sequence $p = q\rho + 1$ and generate $\rho$ until we hit a prime. To generate $a$, we first compute a random $\sigma$, and then $a = s^\sigma \mod p$. If $a=1$, which is extremely unlikely, we start again; otherwise, we have our $a$. In practice, it is faster to use $p, q, a$, which are pregenerated, since this does not reduce the level of security, because $k$ is random. You can pick the standard values described in the literature.

Consider an example of the above algorithm. Start with $q = 97$, which is a prime number. It is easy to show that $97 \times 40 + 1 = 3881$ is prime, so that we can choose $p = 3881$. Now choose random $\sigma = 61$. A simple calculation yields

```
$61^{40} \equiv 3440 \pmod{3881}, \quad (4.81)$
```

```
$3440^{97} \equiv 1 \pmod{3881},
```

so we can use $a = 3440$. Now randomly choose the secret key $a = 76$ and calculate the corresponding public key $\beta$

```
$\beta = 3440^{76} \pmod{3881} = 1568. \quad (4.82)$
```

Let us how Alice, whose secret key $a = 76$ and public key $\beta = 1568$, sign a message $m=52$. First, she chooses an ephemeral random $k = 22$ and calculates

```
$\gamma = 3440^{22} \pmod{3881} = 121. \quad (4.83)$
```

Next, Alice needs to compute the hash of the concatenated message $h(m|y)$. We discuss how to calculate suitable hash functions. Here we make a shortcut. We notice that $\phi=10$ and $y = 21$ are primitive roots of $q = 97$, and define the hash function as:

```
$h(m|y) = \phi^m \psi^y \pmod q = 10^{52} \times 21^{121} \pmod{97} = 88 \times 74 \pmod{97} = 13. \quad (4.84)$
```

Accordingly, the signature has the form:

```
$(r, s) = (13, (22 + 76 \times 13) \pmod{97}) = (13, 40). \quad (4.85)$
```

Bob can verify the validity of Alice's signature as follows. Bob calculates

```
$\alpha^* = 3440^{40} \pmod{3881} = 554,$
```

```
$\beta^{-r} \equiv 1568^{-13} \pmod{3881} = 1480^{-1} \pmod{3881} = 2305, \quad (4.86)$
```

```
$554 \times 2305 \pmod{3881} = 121,$
```

and after hashing, recovers $r$, thus confirming Alice's signature.

## 4.6.6 Diffie-Hellman key exchange

The Diffie-Hellman (DH) key exchange can be based on the exponentiation mod $p$, with the following choices for $f$ and $a$:

```
$g(x, y) = x^y \pmod p, \quad (4.87)$
```

```
$f(x) = g(\alpha, x) = \alpha^x \pmod p,$
```

where g is a primitive root mod $p$. It is easy to see that the symmetry is satisfied

```
$g(f(a), b) = (\alpha^a)^b = (\alpha^b)^a = g(f(b), a) \pmod p. \quad (4.88)$
```

The key exchange proceeds as follows:

- (1) Alice (or Bob) chooses parameters $p$ and $a$ and makes them public;
- (2) Alice takes secret $a$ and makes $a^a \mod p$ public;
- (3) Bob takes secret $b$ and makes $a^b \mod p$ public;
- (4) Both Alice and Bob calculate their shared secret: $k = (a^a)^b = (a^b)^a \bmod p$.

Since the one-way function used in DH exchange is exponentiation mod $p$, its security depends on the difficulty of calculating discrete logarithms, i.e., finding the solution of the problem (4.6). If discrete logarithms were easy to calculate, an attacker could find $a$ and $b$ from $a^b \mod p$ and $a^b \mod p$ and the whole edifice would collapse. In general, as discussed, discrete logs is a hard problem.

## 4.7 Elliptic Cryptography

### 4.7.1 Continuous elliptic curves

An elliptic curve is the set of real points $(x, y)$, which solve the following equation:

```
$y^2 = x^3 + a_2x^2 + a_1x + a_0.$
```

In other words,

```
$E = \{(x,y) : y^2 = x^3 + a_2x^2 + a_1x + a_0\}$.
```

It is imperative to understand that the corresponding curves are not ellipses! Every elliptic curve $E$ is symmetric with respect to reflection $y \to -y$. In other words, if $(x,y) \in E$, then $(x,-y) \in E$, as well. We use this fact when we define addition on elliptic curves. A couple of representative examples of elliptic curves:

```
$y^2 = x^3 - x + 1,$
```

```
$y^2 = x^3 - x.$
```

Not all elliptic curves are useful for our purposes — we want to avoid points with multiple roots, such as

```
$y^2 = x^3 + x^2 - 1 = (x-1)(x+1)^2.$
```

Several elliptic curves are shown in Figure 4.8. In practice, it is sufficient to consider curves with $a_2 = 0$, since we can always shift $x$ by $-a_2/3$, removing the $x^2$ term. Accordingly, for cryptographic purposes, we can use

```
$E = \{(x,y) : y^2 = x^3 + ax + b\}$.
```

## 4.7.2 Historical aside

A brief historical prelude explaining why elliptic curves were not confused with ellipses in order; see Brown (2000); Rice and Brown (2012) for further details.

Elliptic curves have ancient origins in antiquity. One was Leonardo da Pisa, also known as Fibonacci (c. 1175–1250), who encountered the following problem: “Find a rational number $r such that $r^2-5$ and $r^2+5$ are rational squares.”

Fibonacci showed that $r=41/6$ is a number since $(41/6)^2-5=(31/6)^2$ and $(41/6)^2+5=(49/6)^2$. In his 1225 celebrated book, which is appropriately called Liber Quadrum (The Book of Squares), Fibonacci introduced the concept of a congruent number. A positive integer $n$ is a congruent number provided that there exists a rational number $r$, such that $r^2-n$, $r^2+n$ are nonzero squares for some rational numbers $r_-$, r_+$, $r^2-n=r_-^2, r^2+n=r_+^2$. Thus, 5 is a congruent number, according to Fibonacci.

How are congruent numbers related to elliptic curves? The product $r^2r_-^2r_+^2$ is a square of a rational number $s$:

```
$s^2=(r^2-n)(r^2+n)=r^4-n^2r^2=(r^2)^3-n^2(r^2).$
```

Thus, the point $(r, y)$ is a point on the elliptic curve,

```
$y^2=x^3-n^2x.$
```

In Fibonacci’s case, we have $x=(41/6)$, $y=6229/216$. An important observation is that $r$ has an even denominator, which is no coincidence. The following fundamental lemma reads:

- **Lemma 4.1** An $n$ is a congruent number if and only if there exists a rational point $(x,y)$ on the elliptic curve $y^2=x^3-n^2x$ such that $x=r^2$.
