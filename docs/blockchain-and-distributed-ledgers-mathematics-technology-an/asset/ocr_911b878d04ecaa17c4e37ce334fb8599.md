# 5.3.4 Transaction scripts

Bitcoin operates on a pushdown stack, processed from left to right. A pushdown stack is a container of objects inserted and removed according to the last-in-first-out(LIFO) principle. Such a stack allows only two operations: pushing an item into the stack and popping an item out of the stack. Thus, a stack is a limited access data structure because one can add or remove elements at the top.
