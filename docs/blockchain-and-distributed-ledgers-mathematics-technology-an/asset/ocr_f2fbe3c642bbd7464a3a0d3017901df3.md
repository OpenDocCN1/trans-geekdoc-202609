The key exchange proceeds as follows:

+   (1) Alice (or Bob) chooses parameters $p$ and $a$ and makes them public;
(2) Alice takes a secret random $a$ and makes $a^b mod p$ public;
(3) Bob takes a secret random $b$ and makes $a^b mod p$ public;
(4) Both Alice and Bob calculate their shared secret:

```
$k = (a^y)^b = (a^b)^a = a^{ab} \bmod p$.
```

Since the one-way function used DH exchange is exponentiation mod $p$, its security depends on the difficulty of calculating discrete logarithms, i.e., finding the solution of the problem (4.64). If discrete logarithms were easy to calculate, an attacker could find $a$ and $b$ from $a^b mod p$ and $a^b mod p$ and the whole edifice would collapse. In general, as we discussed, discrete logs is a hard problem.

# 4.7 Elliptic Curve Cryptography

# 4.7.1 Continuous elliptic curves

An elliptic curve is the set of real points $(x, y)$, which solve the following equation:

```
$y^2 = x^3 + a_2x^2 + a_1x + a_0$.
```

In other words,

```
$E = \{(x,y) : y^2 = x^3 + a_2x^2 + a_1x + a_0\}$.
```

It is imperative to understand that the corresponding curves are not ellipses! Below we briefly discuss a fascinating reasoning why they are called elliptic. Every elliptic curve $E$ is symmetric with respect to reflection $y \to -y$. In other words, if $(x,y) \in E$, then $(x,-y) \in E$, as well. We use this fact when we define addition on elliptic curves.

A couple of representative examples of elliptic curves

```
$y^2 = x^3 - x + 1$,
```

```
$y^2 = x^3 - x$.
```

Not all elliptic curves are useful for our purposes — we want to avoid points with multiple roots, such as

```
$y^2 = x^3 + x^2 - x - 1 = (x-1)(x+1)^2$.
```

```
$E = \{(x,y) : y^2 = x^3 + ax + b\}$.
```
