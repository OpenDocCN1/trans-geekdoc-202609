## 4.5.6 Blind signature

The blind signature algorithm is a variation of RSA, which allows Alice to get a message signed by the bank without the bank knowing the content of the message. Specifically, Alice chooses a random value $r$ and computes $m' = m \cdot r^e \pmod n$. She sends $m'$ to the bank, which returns the signature $s = (m')^d \pmod n$. Alice then computes $m = s \cdot r^{-1} \pmod n$. The bank can verify the signature by checking if $s^e \equiv m' \pmod n$.

The blind signature algorithm is useful for preserving privacy, as it allows users to perform transactions without the bank knowing the details of the transaction.

## 4.5.7 Chaum's anonymous cash

David Chaum suggested using blind signatures to create anonymous digital cash. This scheme aims to hide the identity of the payer while still allowing the bank to prevent double-spending. To achieve this, Alice uses the blind signature algorithm as described above. Once the message is signed by the bank, Alice can unblind it and present it to a merchant. The merchant can then verify the signature and ensure the coin has not been spent before.

## 4.6 Finite field cryptography

### 4.6.1 Definitions

So far, we have looked at one possible candidate for a trapdoor function — exponent n = pq. Are there other possibilities? Yes, for instance, discrete logarithms p are as hard to compute as factoring of n — same complexity as before! As we see shortly, discrete logarithms have some useful features; for example, one can use them for the so-called Diffie-Hellman key exchange. With some additional tricks, one can utilize discrete logarithms to build trapdoor functions.

We start with some useful definitions. Let's define discrete logarithms as solutions of the congruence:

```
$\alpha^x = y \pmod p, \quad x = \log_{\alpha}(y) \equiv L_{\alpha}(y). \quad (4.64)$
```
