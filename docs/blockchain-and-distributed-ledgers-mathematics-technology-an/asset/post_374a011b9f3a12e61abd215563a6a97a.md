Small hash power implies infrequent rewards with huge variability. Thus, simple economics forces miners to coalesce into gigantic pools, which goes against the grain of the distributed ethos underpinning Bitcoin’s generosity. Mining is sustainable in the long term, if only the reward exceeds the mining cost. Mining reward consists of the block reward and transaction fees. Mining costs include hardware costs and operational costs, such as electricity, labor, legal, security, and incidental expenses. What will happen when rewards are anybody's guess. In all likelihood, the Bitcoin protocol will be severely impacted. For further details see Beucci and Jaag (2017); Bissias et al. (2018); Prat and Walter (2018); Qin et al. (2018); Romiti et al. # ## 5.5.3 How do miners mine?

At the heart of mining is the search for a valid nonce that is a 32-bit (4-byte) field whose value is adjusted by miners until the hash is less than equal to the current difficulty of the block (Subsections 5.5.2 and 5.5.4). It is unlikely that there is a 32-bit nonce resulting in a hash below the target; the miners will have to operate with two nonces self-consistently: (a) nonce in the block header; (b) nonce in the scriptsig of the Coinbase transaction described earlier in Subsection 5.3.

- Students of quantum chemistry can recognize a similar construct of the foundational Hartree–Fock self-consistent field.

![](img/d52d985b4b3970b396f9b7f6d2aa3d8e_231_0.png)

**Figure 5.23** Bitcoin growth is slow compared to many other systems: (a) the number of confirmed transactions per day; (b) the number of confirmed transactions per second. For comparison sake, Visa processes around 2,000 transactions per second. Own graphics. Source: blockchain.com.

framework starts with choosing zero-valued nonce for the Coinbase base. The corresponding block header, which includes the hash of the previous block, Merkle tree with hashes from all transactions in the current block, and the block header's first choice, is consequently hashed. If its value satisfies the current difficulty level, the problem is solved, and the miner broadcasts the block to the network. However, if the target hash is not low enough, the miner continues to iterate over all available block header nonces. Assuming that all permutations with the initial value of the Coinbase nonce do not produce a satisfactory result, the miner changes the Coinbase nonce, which propagates to the root, and repeats the process, as demonstrated in Figure 5.25.

![](img/d52d985b4b3970b396f9b7f6d2aa3d8e_232_0.png)

**Figure 5.24** (a) The output value of all confirmed transactions per day; (b) the estimated value of all non-change transactions per day. Own graphics. Source: blockchain.com.

Symbolically, the task of a miner is to find two nonces, $y_1, y_2$, such that

$$ H(x|y_1,y_2) \in Z, \quad (5.26) $$

where $Z$ is a suitable target set. Assuming that finding a combination of nonces producing a proper hash can only be done by brute force, miners must perform a costly calculation requiring enormous computational resources.
