# 4.12 Quantum-resistant cryptography

The public key infrastructure framework considered in this chapter relies on assuming specific calculations, such as factoring a large number, solving the discrete log problem, or its EC analog, are hard. These assumptions are valid, given the state of the current hardware. However, if uneven progress achieved in quantum computing, could dramatically change the situation.
