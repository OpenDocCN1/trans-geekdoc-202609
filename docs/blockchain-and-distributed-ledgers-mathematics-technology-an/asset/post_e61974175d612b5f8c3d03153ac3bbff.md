## 4.6.2 Primitive roots

In general, $a$ is a primitive root $mod n$ if every primitive root $m$ is congruent to a power of $a$, $m = a^{(k)} \mod n$. When $n$ is prime, every primitive $m, 0 < m < n$, is a power of $a$. For example, we see in Table 4.3 that $2, 6, 7, 11$ are primitive roots mod 13.

This table shows for every $n', 1 \le n' \le 12$ we have a power $r'$ such that $a^{(r')} = n'$ for $a=2, 6, 7, 11$ that they are primitive roots. It is easy to check that there are no other primitive roots for $p = 13$.

For a given $n$, finding primitive roots is difficult. First, compute the totient function $\phi(n)$. Second, determine its prime factors $p_1,\dots,p_t$. Third, for each $p_i$, compute

```
$z_i = a^{\phi(n)/p_i} \mod n. \qquad (4.67)$
```

If $z_i \neq 1$, then $a$ is a primitive root.

For example, $\phi(13) = 12 = 2^2 \times 3$; $6^3 \mod 13 = 12 \neq 1$; $6^4 = 9 \neq 1 \mod 13$; $6$ is a primitive root.

## 4.6.3 ElGamal encryption

ElGamal encryption is based on discrete logs rather than exponentiation; see ElGamal (1985). It is more modern and secure than RSA. The algorithm proceeds as:

- (1) Alice chooses a large prime $p$ and a primitive root $\alpha \mod p$;
- (2) Alice takes a random integer $a$ and calculates $\beta = \alpha^a \mod p$;
- (3) Alice makes the public key the triple $(p, \alpha, \beta)$ while keeping her secret key private;
- (4) Bob chooses a random integer $k$ and produces the ciphertext as $(\alpha^k, \beta^k) \mod p$;
- (5) Alice uses the secret power $a$ to decrypt the ciphertext as follows:
```
$(\alpha^k)^{-a}(\beta^k)^a = (\alpha^{-ak})(\alpha^{ak}) = m \mod p. \qquad (4.69)
```

Thus, ElGamal combines key transmission and decryption: $a$ is used to transmit the "one-time secret" $k$; $\beta^k$ is used as a "one-time pad" for $m$, as discussed above. Since the one-way function is exponential $\mod p$, its security depends on the difficulty of calculating discrete logarithms $L_{\alpha}(y)$, i.e., finding the solution to $\alpha^x = y \mod p$. If it was easy to find discrete logarithms, the attacker could extract $L_{\alpha}(\beta) = a$ and decrypt the message as easily as intended. ElGamal encryption is generally better than vanilla RSA because it uses a random $k$, which helps with messages.

## 4.6.4 ElGamal digital signature algorithm

One can complement the ElGamal encryption algorithm with the ElGam signature algorithm; see ElGamal (1985). The algorithm works as follows:

- (1) Alice chooses a large prime $p$ and a primitive root $\alpha \mod p$;
- (2) Alice chooses a random integer $a$ and calculates $\beta = \alpha^a \mod p$;
- (3) Alice makes the public key the triple $(p, \alpha, \beta)$ public while keeping her secret key private;
- (4) Alice chooses a random integer $0 < k < p-1$, such that $\gcd(k,p-1) = 1$, and computes $r = \alpha^k \mod p$;
- (5) Alice creates a signature, which is the pair $(r,s)$ where
```
$(r,s) = (r, (m+ar)k^{-1} \mod (p-1)). \qquad (4.70)$
```

The verification algorithm proceeds in two steps:

- (1) Bob computes $\beta' = \beta^{-r} \mod p$ and $u = \alpha^{u} \mod p$.
- (2) Bob compares $t$ and $u$.

If the equality holds, the signature is valid. Indeed, for a valid signature, we have:

```
$\beta^{-r}r^s = (\alpha^a)^{-r}(\alpha^k)^{(m+ar)k^{-1}} \mod p$
= \alpha^{-ar}\alpha^{m+ar} \mod p = \alpha^m \mod p. \qquad (4.71)$
```

Visualization of the ElGam DSA is presented in Figure 4.6. Consider a simple example of the algorithm above. Alice chooses $p, \alpha, a, \beta$ as follows:

```
$p = 997, \alpha = 7, a = 146, \beta = 7^{146} \mod 997 = 634. \qquad (4.72)$
```

Here $\alpha = 7$ is the smallest primitive root of the prime $p = 997$. She makes $(p, \alpha, \beta)$ public and keeps a private key.
