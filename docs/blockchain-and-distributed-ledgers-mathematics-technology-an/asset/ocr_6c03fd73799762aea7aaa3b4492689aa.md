(3) Alice makes the public key that is the triple $(p, \alpha, eta)$ while keeping her secret key a private;

(4) Bob chooses a random integer $k$ and produces the ciphertext as $(\alpha^k, eta^k) \bmod p$;

(5) Alice uses the secret power $a$ to decrypt the ciphertext as follows:

```
$(\alpha^k)^{-a}(\beta^k)^a = (\alpha^{-ak})(\alpha^{ak}) = m \bmod p. \quad (4.69)$
```

Thus, ElGam encryption combines key transmission and OTP decryption: $a$ is used to transmit the "one-time secret" $k$; $eta^k$ is used as a "one-time pad" for $m$, as discussed above. Since the one-way function is exponential $mod p$, its security depends on the difficulty of calculating discrete logarithms $L_{\alpha}(y)$, i.e., finding the solution to $\alpha^x = y \bmod p$. If it was easy to find discrete logarithms, the attacker could extract $L_{\alpha}(eta) = a$ and decrypt the message as easily as its intended. ElGam encryption is generally better off than vanilla RSA because it uses a random $k$, which helps with short messages.

#  4.6.4 ElGam digital signature algorithm

One can complement the ElGam encryption algorithm with the ElGam signature algorithm; see ElGam (1985). The algorithm works as follows:

+   (1) Alice chooses a large prime $p$ and a primitive root $\alpha \bmod p$;

+   (2) Alice chooses a random integer $a$ and calculates $\beta = \alpha^a \bmod p$;

+   (3) Alice makes the public key that is the triple $(p, \alpha, \beta)$ public while keeping her secret key a private;

+   (4) Alice chooses a random integer $0 < k < p-1$, such that $\gcd(k,p-1) = 1$, and computes $r = \alpha^k \bmod p$;

+   (5) Alice creates a signature, which is the pair $(r,s)$ where

```
$(r,s) = (r, (m+ar)k^{-1} \bmod (p-1)). \quad (4.70)$
```

The verification algorithm proceeds in two steps:

+   (1) Bob computes $\beta' = \beta^{-r} \bmod p$ and $u = \alpha^u \bmod p$.

+   (2) Bob compares $t$ and $u$.

If the equality holds, the signature is valid. Indeed, for a valid signature, we have

```
$eta^{-r}r^s = (a^a)^{-r}(\alpha^k)^{(m+ar)k^{-1}} \bmod p\n= \alpha^{-ar}\alpha^{m+ar} \bmod p = \alpha^m \bmod p. \quad (4.71)$
```
