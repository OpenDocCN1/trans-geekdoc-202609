```
$$\frac{\sigma^2}{\beta} > \begin{cases} 2m, & 0 < m < \frac{1}{2}, \ \frac{1}{2(1-m)}, & \frac{1}{2} \le m < 1, \end{cases} (10.43)$
```

while $x(t)$ stays away from zero for $t \to \infty$ (persistence) when

```
$$\frac{\sigma^2}{\beta} < 2m. (10.44)$
```

What happens for

```
$$\2m < \frac{\sigma^2}{\beta} < \frac{1}{2(1-m)} < \frac{1}{2} < m < 1, (10.45)$
```

is unclear, but extinction is the probable outcome.

It is well-known that the static asymptotic distribution is described by the stationary Fokker-Planck equation for the $P(x)$ as follows:

```
$$((m-x)x)_x - \frac{\sigma^2}{2\beta}((1-x)^2x^2P)_{xx} = 0, (10.46)$
```

see, e.g., Lipton (2001). The change of dependent variable:

```
$Q = (1-x)^2x^2P, (10.47)$
```

yields the following modified equation for the stationary distribution:

```
$$\frac{(m-x)}{x(1-x)^2}\frac{\sigma^2}{2\beta}Q_x = 0. (10.48)$
```

Thus,

```
$Q = e^{\phi}, (10.49)$
```

where

```
$$\Phi = \frac{2\beta}{\sigma^2} \left( \frac{(m-x)}{x(1-x)}dx \right) = \frac{2\beta}{\sigma^2} \left( m \ln \frac{x}{1-x} \right) + \frac{(m-1)}{(1-x)} + \text{const}. (10.50)$
```

Accordingly,

```
$$\Q = \frac{x^{2\beta m/\sigma^2}}{(1-x)^{2\beta m/\sigma^2}} \exp \left( \frac{2\beta(m-1)}{\sigma^2(1-x)} + \text{const} \right). (10.51)$
```

Finally,

```
$$\P = \var \frac{x^{2\beta m/\sigma^2}}{(1-x)^{2\beta m/\sigma^2+2}} \exp \left( \frac{2\beta(m-1)}{\sigma^2(1-x)} \right). (10.52)$
```

where $\var$ is a normalizing factor. The distribution $P$ is integrable at $x = 0$ provided that that inequality (10.44) is valid. By its very nature, it is independent on the choice of $x(0)$.
