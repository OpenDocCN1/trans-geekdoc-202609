7. A vanity address is a bitcoin address containing a predefined series of characters, as its owner’s name. As an example, the following address

```
kWIF = 5JSHCUnVfz38JNCHFL9PF9JXQk
732BbzW2iX2S1PNjUZ5W9W3wy
```

Download a vanity address generator, such as https://github.com/sumr/vanity. Generate a keypair that the corresponding address starts with 1EASY. Try to generate an address starting with 1HARDER. Why is it more challenging to create? Try a possible address beginning with 1IMPOSSIBLE. Why does it fail? Describe a vanity address generation algorithm in detail and propose a measure of the problem's difficulty. Explain how it relates to the PoW algorithm.
