The transaction in question is more meaningful if it (presumably) sends one bitcoin to a new owner and returns the rest as change. It has one input address IA₀=3M92sq9ssFaNbEwF47uteVKJJsbw125juS7, and two outputs

> OA₀ = 1KwCFuU3Y9T4qF575SbDzWbkdQhMkW9i,
OA₁ = 3M92sq9ssFaNbEwF47uteVKJJsbw125juS7.

Initially, IA₀ address contains UTXO=4.27871989 BTC. TX moves 1.000000000 BTC to OA₀, returns 3.27871189 BTC to OA₁=IA₀, and pays 0.00016800 BTC as fees. It is interesting to note that this fee is a hundred times less than the previous one. It is digitally signed by the secret key with IA₀. This transaction uses SegWit, which separates the digital print of the original Bitcoin protocol proposed in Bitcoin Improvement Proposal BIP141. SegWit upgrade was activated at block 477,120. Hence, it is not present in TX with TXID given by Eq.(5.16) from Block 400,000.
