# 3.3.4 Bootstrapping of a node

In practice, a node follows the below lifecycle:

+   (1) bootstrap phase: a new node connects to one or multiple nodes whose IP addresses are publicly available; seed nodes may be any cooperative nodes already connected to the network.
(2) peer discovery: the node asks for IP addresses of other nodes known to them in the network, possibly recursively in order to build a local map of the available nodes and their respective IP endpoints.
(3) state recovery: the node downloads the ledger history, in part or fully, from any combination of cooperative nodes discovered.
(4) network servicing: the node optionally becomes a cooperative node itself and starts relaying information received from peers to its own peers and to all other peers to request copies of the locally stored ledger.
