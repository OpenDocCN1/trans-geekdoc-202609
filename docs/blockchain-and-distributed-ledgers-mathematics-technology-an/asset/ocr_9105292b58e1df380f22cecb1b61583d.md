$T_{HEX}^{(1)} = \frac{0x00000000ffff00000000000000000000}{00000000000000000000000000000000} \quad (5.27)$

Strangely, the calculation of difficulty is one of the places where Bitcoin uses decimals. In the decimal format, $T^{(1)}$ can be written as

```
$T_{DEC}^{(1)} = \frac{269953529101130949315647634272399}{133601089738574164086137773096960} \quad (5.28)$
```

Thus, the initial target $Z$ is the set of integers $z \le T_{HEX}^{(1)}$. Given that

```
$2^{256} = \frac{115792089237316195423507985008668970853}{26998466560456403945758400791312693935} \approx 1.157 \times 10^{77}, \quad (5.29)$
```

we have

```
$T_{HEX}^{(256)} = 4295032830001525. \quad (5.30)$
```

Thus, to mine a block, one needs to perform over 4.29 billion hashes.
The difficulty increases when the target $T$ decreases. For example, the target for Block 100,000 has the following format

```
$T_{HEX}^{(100000)} = \frac{0x0000000004864c000000000000000000}{00000000000000000000000000000000} \quad (5.31)$
```

or, equivalently

```
$T_{DEC}^{(100000)} = \frac{18861311498380126815643262922732}{30736638334854814253669909173504} \quad (5.32)$
```

Thus, the difficulty for Block 100,000 is

```
$Diff = \frac{T_{DEC}^{(100000)}} = 1448.16236123, \quad (5.33)$
```

so that about 62,210 billion hashes are required to find a winning block.
A block's target is baked-in in its header for bits of target — an extraordinarily clever bit (punt intended) of engineering. For instance, for Block 600,000, the corresponding target in hexadecimal is 1715a35c; see Table 5.13 in Section 5.6. Its interpretation is as follows. The first byte, called the exponent, allows one to calculate how many zeros the target should start with, given the overall (hex)64(dec) positions. In our case, the exponent equates to 17(hex), or 23(dec); the number of zeros is equal to $40-2e = 12$ (hex), or equivalently, $64-46 = 18$ (dec). The coefficient shows the first nontrivial bits of the target. Thus, the target for Block 600,000 looks like that:

```
$T_{HEX}^{(600000)} = \frac{0x0000000000000000000015a35c000000}{00000000000000000000000000000000} \quad (5.34)$
```
