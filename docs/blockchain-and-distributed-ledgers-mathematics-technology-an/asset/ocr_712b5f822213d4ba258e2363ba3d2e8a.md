The corresponding P&L versus the buy-and-hold strategy is a path-dependent quantity given by the following formula:

```
$P&L = \sum_{n=0}^{N-1} \left(_{(1+\varepsilon)x_n^2 < P_{n+1}} (x_{n+1}-x_n) + _{P_{n+1} < \frac{x_n^2}{(1+\varepsilon)}} P_{n+1} \left(\frac{1}{x_{n+1}}-\frac{1}{x_n}\right) \right) +x_N + \frac{P_N}{X_N} - (1+P_N).$ (10.86)$
```

$\$, is the indicator function equal to one if the condition is satisfied, and zero otherwise. The market making activity makes sense only when $P&L > 0$. Perhaps, a more informative quantity is the relative return on market making, compared with the buy-and-hold strategy:

```
$P&L = \frac{P&L}{(1+P_N)}.$ (10.87)$
```

Of course, due to the fact that the log-price is stochastic, we can only analyze $P&L$ in probabilistic sense by running Monte Carlo simulations. To this end, we consider $MC$ paths, which are characterized by a random matrix $(\theta_{mn})$, calculate a set of $M$ $P&L$ values, $\{P_{lm}\}$, and study their statistical properties. We present the corresponding results in Figure 10.37.

These figures illustrate the complicated dependence of $P&L$ on three parameters: $\kappa, \sigma, \varepsilon$. The reader, wishing to understand an AMM, needs to explore this dependence in detail.

One can analyze a mixed rule AMM using a similar technique. We leave this analysis to an experienced reader as an exercise.
