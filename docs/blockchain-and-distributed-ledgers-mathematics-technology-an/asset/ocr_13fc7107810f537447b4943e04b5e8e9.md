Recall that, subject to various technical conditions, any random variable $X$ is characterized by the pdf $f(x)$, the cumulative density function (cdf) $F(x)$, and the characteristic function $\phi(\chi) = E\e^{i\chi X}\}$. The relationships between $f(x)$ and $\phi(\chi)$ are as follows:

```
$$\phi(\chi) = \int_{-\infty}^{\infty} f(x) e^{i\chi x}dx,\quadquad (10.3)$
$$f(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \phi(\chi) e^{-i\chi x}d\chi.$$
```
