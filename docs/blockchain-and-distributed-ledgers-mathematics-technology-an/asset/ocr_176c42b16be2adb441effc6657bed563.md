Let’s go through Table 5.6 by line:

+   (1) TXID — the unique transaction identifier, is 32 bytes long and is represented by 64 hex symbols (2 hex symbols per byte). TXID is computed only after the transaction is fully formed, see discussion related to Tables 5.7 and 5.8.
(2) Time — the when the block containing this TX was made. In this particular case, it is the when Block 400,000 was made. It is important to emphasize that the time stamp does not reflect the time TX was broadcast to the network.
(3) Size — the size of transaction in the serialized form, see Table 5.8.
(4) Weight — a quantity related to size and pertinent to modern transactions that use the Segregated Witness (SegWit) method, as the one described in Table 5.10. For older transactions, such as the one in question, weight is four times size (764=4 × 191).
(5) Block — the block number into which the transaction is included.
(6) Total input — the sum of all the UTXO s are the inputs for the transaction.
(7) Total output — the sum of all outputs for the transaction.
(8) Fees — the difference between the total input and output, it is always positive.

> ⁴Keep in mind that 1 byte = 8 bits = 2 hex numbers.
