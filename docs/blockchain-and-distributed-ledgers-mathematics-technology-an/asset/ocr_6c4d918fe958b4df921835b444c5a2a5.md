# 4.6.3 ElGamal encryption algorithm

The ElGamal encryption, is based on discrete logs rather than exponentiation; see ElGamal (1985). It is more modern and secure than RSA. The algorithm proceeds as:

+   (1) Alice chooses a large prime $p$ and a primitive root $\alpha$ mod $p$;n(2) Alice takes a random integer $a$ and calculates $eta = \alpha^a$ mod $p$;
