# 4.7.7 The discrete log problem on elliptic curves

We are ready to formulate the elliptic curve version of the discrete log problem. To end this, we need to be more specific and add a few details to the previous construct. Consider an EC, characterized by a tuple $T = (p, a, b, G, n)$, and denoted by $E_T$. Here $p, a, b$ are as before, while $G$ is the so-based point, which is used to generate the set of points of the form $\mathscr{E}_G = \{[k]G\}$; $n$ is the order of $G$, i.e., the cardinality of the set $\mathscr{E}_G$, and $h$ is the cofactor of $G$, $h = \#E_T/\#\mathscr{E}_G$. For cryptographic purposes, $n$ has to be a prime. A good base point should have $h = 1$, which means that the set $\mathscr{E}_G$ of all the points covers the entire curve. Thus, $G$ is a primitive root considered above.

*Lagrange's lemma, which states that for any finite group $G$ and every subgroup $H$ of $G$, the order (number of elements) of $H$ divides the order of $G$, guarantees that $h$ is an integer.
