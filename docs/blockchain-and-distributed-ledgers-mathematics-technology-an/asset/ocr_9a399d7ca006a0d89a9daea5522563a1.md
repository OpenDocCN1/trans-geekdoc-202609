We can restrict ourselves to a positive quadrant and represent the ellipse parametrically as $x(	heta) = p \cos	heta, y(	heta) = q \sin	heta$, where $	heta$ is the angle. The well-known arc length formula yields

```
$C(p, q) = 4 \int_{0}^{\pi/2} \sqrt{p^2\sin^2\theta + q^2\cos^2\theta} \ d\theta$\n$= 4 \int_{0}^{\pi/2} \sqrt{q^2 - (k^2 - p^2)} \sin^2\theta \ d\theta \quad$ (4.100)\n$= 4q \int_{0}^{\pi/2} \sqrt{1 - k^2\sin^2\theta} \ d\theta$,
```

$k^2 = (1 - p^2/q^2), 0 \le k \le 1$. Of course, the nontrivial case is $0 < k < 1$, because an ellipse becomes a circle when $k=0$, and a straight line when $k=1$.\nTo clarify the connection of ellipse with elliptic curves, we introduce $x = \sin^2\theta$ and get

```
$d\theta = \frac{dx}{2\sqrt{x(1-x)}} \quad$ (4.101)
```

so that

```
$C(p, q) = 2q \int_{0}^{1} \frac{\sqrt{1-k^2x}}{\sqrt{x(1-x)}} \ dx$\n= 2q \int_{0}^{1} \frac{(1-k^2x)}{\sqrt{x(1-x)(1-k^2x)}} \ dx \quad$ (4.102)\n= 2qk \int_{0}^{1} \frac{\(\frac{1}{k^2}-x)}{\sqrt{x^3-(\frac{1}{k^2}+1)x^2+\frac{x}{k^2}}} \ dx$.
```

Integrals of the form

```
$$\int \frac{\text{polynomial}}{\sqrt{cubic with three distinct roots}} \quad$ (4.103)
```

appear in all applications. Since the calculation of the arc length of an ellipse was the first one, they are called elliptic integrals.\nWe show a typical ellipse and its associated elliptic curve in Figures 4.9 (a), (b). Elliptic integrals cannot be evaluated in terms of elementary functions. For completeness, we give the formula for the arc length of an ellipse with semi-axes $p, q$, we see Abramowitz and Stegun (1948), Formula 17.3.10:

```
$C(p, q) = 2\pi bF(-\frac{1}{2}, \frac{1}{2}; 1; k^2). \quad$ (4.104)
```
