
## 4.7.4 Projectivization of elliptic curves

In this subsection, we briefly discuss connections between elliptic curves and projective geometry. The fact that the vertical line passing through the points (x,y) and (x,-y) belonging to the elliptic curve intersects it with symmetry rather than two points deserves additional discussion.

To elaborate, we need to ‘lift’ elliptic curves from the affine (x,y) plane to the projective (X : Y : Z) plane. This procedure is called the projectivization. We proceed as follows. Consider an affine elliptic curve. Let $x = X/Z, y = Y/Z$, as the form:

$Y^2Z = X^3 + AX^2 + bZ^3.$

in the (X, Y, Z) space. We eliminate the origin (0,0,0) to avoid ambiguity since it belongs to every elliptic curve.

Eq. (4.130) is homogeneous of degree 3. Thus, if $(X, Y, Z)$ is a point on the curve, so is $(\lambda X, \lambda Y, \lambda Z)$ for any $\lambda$. To avoid having “too many” points, we define two-dimensional projective space as the set of equivalence classes of nonzero points $(X, Y, Z)$, where $(X, Y, Z)$ and $(\lambda X, \lambda Y, \lambda Z)$ are considered to be equivalent. Intuitively, the three-dimensional space is reduced to two dimensions by treating lines through the origin as a single point. We use the notation $(X : Y : Z)$ for a projective point to emphasize this fact. Thus, $(X : Y : Z) = (\lambda X : \lambda Y : \lambda Z)$, $\lambda \neq 0$.

It is clear that for $Z \neq 0$, we can divide $X$ by $Z$, $Y$ by $Z$, consider $x = X/Z = Y/Z$ and get a solution of the affine equation.

However, if $Z = 0$, the division by $Z$ is not allowed, so there are points on the projective curve that do not correspond to points on the elliptic curve. These points have form $(0 : y : 0)$, for any $y \neq 0$. Given that points in the projective plane are defined as equivalence classes, we can choose the following point $O = (0 : 1 : 0)$, called the point at infinity or the neutral element. We can intuitively think that $O$ is a point located infinitely high (and low) on the $y$-axis.

Consider a vertical straight line by the following equation in the affine plane:

$x - \bar{x} = 0.$

In the projective plane, it looks as follows:

$X - \bar{x}Z = 0.$

The point $O$ belongs to this line for any $\bar{x}$. Thus, after projectivization, we find the third point, in addition to $(\tilde{x}, \tilde{y})$, belonging to the elliptic curve and the straight line, and this point is the point at infinity, $O$.

## 4.7.5 Multiplication on elliptic curves

We are only interested in multiplication by integer, which is defined intuitively by repeated addition. For instance

$3 \times (x, y) = ((x, y) + (x, y)) + (x, y))$.

Here and below, we use $\times$ to denote elliptic curve point multiplication by a scalar. We illustrate this operation in Figure 4.11 below. As usual, the binary decomposition of the multiplier helps to perform multiplication quickly.

## 4.7.6 Discrete elliptic curves

With the above material under our belt, we can now go back to cryptography. Not surprisingly, we have to operate with a finite set of discrete points. We considered points $mod \ p$ or $mod \ n = mod \ p \ q$. Now we wish to use an EC and a large prime $p$ and consider EC $mod \ p$. $x = 0, 1, \dots, p-1, y = 0, 1, \dots, p-1$.

$E_p = \{(x, y) : y^2 = x^3 + ax + b \ mod \ p\}$.

Let us show that finding points $(x, y)$ on $E_p$ is not that easy!
Assuming that we know the set of points constituting $E_p$, we can define addition by using formulas (4.117, 4.118), $m$, of which, in an integer, has to understand as appropriate, mainly as a product of the numerator and the inverse of the denominator.
To warm up, let us consider $E_p$ of the form:

$y^2 = x^3 + 7 \ mod \ p.$

$p = 2^5 - 1 = 31, p = 2^7 - 1 = 127, p = 2^{13} - 1 = 8191,$ are the so-called Mersenne primes, i.e., prime numbers that are less than a power of two. We shall see below that Mersenne primes for constructing EC has considerable advantages. These curves are shown in Figure 4.12. They contain 21, 127, and 8011 points, respectively. Since 21 is not a prime, $E_{31}$ is not a candidate for cryptographically useful EC while $E_{127}$ and $E_{8191}$ are (127 and 8011 are both primes), if not the fact that they are too small.

In general, Hesse's theorem estimates the total number of points on a discrete elliptic $E_p$. We emphasize that in contrast to statements like “Assume that $f$ is a good cryptographic trapdoor function”, Hesse's theorem is a “real” theorem and can be proven rigorously.

**Theorem 4.5.** Hesse's theorem: The total number of points $N$ on a discrete elliptic curve satisfies the following inequality:

$|N - (p+1)| < 2\sqrt{p}$.

If a point $(x,y)$ belongs to the elliptic curve, $(x,y)\in E_p$ so does $(x, p-y)$. There are $p$ possible absciss, roughly half of these absciss belonging to $E_p$. Finding the exact value of the correction

$t = N - (p+1)$,

is extremely important for cryptographic purposes to know the exact value of the correction, given by Eq. (4.137), which can be done via a very efficient Schoof’s algorithm; see Schoof (1985). $\#E_p$ denotes the number of points on the curve.
It is easy to check that for $E_{31}$ inequality is valid:

$|21 - 32| = 11 < 2 \times 5$.

Interestingly, there are “few” points on the curve in question, so that Hesse’s theorem barely holds.
