# 4.10 RIPEMD-160

RIPEMD-160 was developed in 1992 and improved in 1996 by Hans Dobbert, Antoon Bosselaars and Bart Preneel; Dobbert et al. (1996).It converts a variable-length message into a fixed-length output of 160 bits (= 20 bytes). This algorithm operates on 32-bit words. The flowchart for RIPEMD-160 is shown in Figure 4.20. For details, we refer to the original paper.

Once again, in the Bitcoin protocol, and by extension, many other crypto protocols, inputs are hashed twice so that:

```
x → y = SHA256(x) → z = RIPEMD160(y). (4.189)
```

Some examples of RIPEMD-160 in action applied to a SHA256 of a hexadecimal number are shown in Eqs (4.190) and (4.191). We see that a small local change of the input — the first digit changed from a to b— results in a global change in the output.

```
a3e45a180726e235ea2aea4b16ce101
9931eb897003e2a419c947619426e4da0
↓ (4.190)
```

```
c37e0858495646805bf286a58d7cd307833b3f86d
b34e5a180726e235ea2aea4b16ce101
9931eb897003e2a419c947619426e4da0
↓ (4.191)
```
