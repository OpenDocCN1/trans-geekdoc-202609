Let us consider a concrete toy example:

```
$p = 601, q = 7, n = 4207 = 601 \times 7$,$
phi(n) = 3600 = 600 \times 6, e = 1463, d = 1127$,$\quad (4.48)$
```

where

```
$1463 \times 1127 \pmod{3600} = 1.$\quad (4.49)$
```

To calculate $d$ given $e$, we use the Euclidean algorithm, and then apply it in reverse. The direct and inverse steps are as follows:

| Direct steps | Inverse steps |
|--- |--- |
| $3600 = 2 \times 1463 + 674$ | $674 = 3600 - 2 \times 1463$ |
| $1463 = 2 \times 674 + 115$ | $115 = -2 \times 3600 + 5 \times 1463$ |
| $674 = 5 \times 115 + 99$ | $99 = 11 \times 3600 - 27 \times 1463$ |
| $115 = 99 + 16$ | $16 = -13 \times 3600 + 32 \times 1463$ |
| $99 = 6 \times 16 + 3$ | $3 = 89 \times 3600 - 219 \times 1463$ |
| $16 = 5 \times 3 + 1$ | $1 = -458 \times 3600 + 117 \times 1463$ |

$gcd(3600, 1463) = 1$, and $1463 = 1 \pmod{3600}$.
Start, we use squaring to compute the binary exponentiation table for $58'$, $l = 2^{k-1}, k=1, \dots, 12$; see Table 4.1.
This table allows us to compute $58^{1463} \pmod{4207}$ using the Russian-style exponentiation and representing the exponent 1463 in the binary form:

```
$1463 = 1024 + 256 + 128 + 32 + 16 + 4 + 2 + 1.$\quad (4.51)$
```

This method is extremely efficient which allows us to compute the requisite results sequentially. It is clear that instead of 1462 multiplications, we only need 15. Accordingly, we have

```
$58^{1463} \pmod{4207} = 471 \times 268 \times 1054 \times 144.$\quad (4.52)$
```

$1815 \times 3873 \times 3364 \times 58 \pmod{4207} = 2937.$
