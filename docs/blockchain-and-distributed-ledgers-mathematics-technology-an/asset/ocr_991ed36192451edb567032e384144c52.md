# 4.4.5 Euler's theorem

Euler's theorem is an exciting and very useful generalization of Fermat's little theorem.
Theorem 4.3 Euler's theorem: if $\gcd(A, n) = 1$, then
$$A^{\phi(n)} = 1 \bmod n,$$   (4.35)

where $\phi(n)$ is the celebrated Euler's totient equal to the number of integers $1 \le m < n$, such that $\gcd(m, n) = 1$.
The proof is straightforward (but an efficient calculation of $\phi(n)$ is anything but simple!). Since $\gcd(A, n) = 1$, $A^{-1}$ exists, and multiplication by $A$ is one-to-one. The set of integers $0 < m < n$, such that $\gcd(m, n) = 1$ is closed with respect to multiplication by $A$. Denote these integers by $m_1, \dots, m_{\phi(n)}$. As before
$$(A \times m_1) (A \times m_2) \dots (A \times m_{\phi(n)-1}) \times (A \times m_{\phi(n)})$$n$$= m_1 \times m_2 \dots \times (\phi(n)-1) \times \phi(n) \bmod n.$$   (4.36)

Since the product $m_1 \times m_2 \dots \times (\phi(n)-1)$ is invertible, we have
asas claimed. QED
$$A^{\phi(n)} = 1 \bmod n,$$   (4.37)

If $n$ is prime, then $n = \phi(p) = p - 1$ (why?), then we recover Fermat's little theorem. Given Euler's theorem, calculations $mod n$ in the exponent are equivalent to calculations $mod n$ in the exponent. Euler's totient function is tough to compute! However, for cryptographic purposes described below, it is sufficient to consider a semrime number $n$ that is the product of two prime numbers $p, q, n = pq$. In this case, we have
$$\phi(n) = (p-1) (q-1).$$   (4.38)

For a practical application of this theorem, see example in Section 4.5.5.
