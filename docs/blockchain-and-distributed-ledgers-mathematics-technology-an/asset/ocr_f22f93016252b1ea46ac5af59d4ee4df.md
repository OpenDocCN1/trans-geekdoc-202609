Of course, the objective of any market maker, including the funder of an AMM, is profit. This profit has cover the impermanent loss and costs. One possibility is to charge the transactional fees every time an arbitrageur or other participant removes tokens and adds others. Typically, it is necessary to add more tokens to the pool that is required by its constituent rule. To simplify the expression, we abstract details by assuming an AMM defined by the constant product rule. Let $\varepsilon$ be a percentage fee. Let $T_0$ and $T_1$ be two times. At time $T_0$, the price is $P_0$, and the pool's composition is $(x_0, y_0)$. At time $T_1$, the price is $P_1$ and we need to find the arbitrated's pool composition $(x_1, y_1)$. First, we assume that $P_1 > P_0$, so that, with zero transaction costs, it is beneficial to arbitrageur to withdraw $TN_2$ and $TN_1$. With non-zero transaction costs the situation is more complicated. The arbitrageur can choose a number $x_1 > x_0$ and deliver $(1 + \varepsilon)$ $(x - x_0)$ $TN_1$ tokens to the pool in exchange for getting $(y_0 - y_1)$ $TN_2$ tokens from the pool, where $y_1 = 1/P_1$. The arbitrageur's profit is as follows:

```
$$\Omega(x) = x \left(P_1 \left(y_0 - \frac{1}{x}\right) - (1 + \varepsilon)(x - x_0)\right)N.$
```

The profit is maximized when

```
$$\Omega'(x) = \left(\frac{P_1}{x^2} - (1 + \varepsilon)\right)N = 0,$
```

so that

```
$x_1^* = \max \left(\frac{P_1}{(1 + \varepsilon)}, x_0\right), \ y_1^* = \frac{1}{x_1^*},$
```

Here, we take the maximum in order to ensure that $x_1^* \geq x_0$, so that $TN_1$ are added to the pool, rather than drawn from it. Thus, for $P_1 > P_0$, adjustment occurs only when

```
$P_1 > (1 + \varepsilon)x_0^2,$
```

Similarly, for $P_1 < P_0$,

```
$x_1^* = \min \left(\sqrt{(1 + \varepsilon)P_1}, x_0\right), \ y_1^* = \frac{1}{x_1^*}.$
```

so that adjustment happens when

```
$P_1 < \frac{x_0^2}{(1 + \varepsilon)},$
```
