The j-th round proceeds as follows:

```
$A_j = \Sigma_0(A_{j-1}) + F(A_{j-1}, B_{j-1}, C_{j-1}) + H_{j-1}$
$
+\Sigma_1(E_{j-1}) + G(E_{j-1}, F_{j-1}, G_{j-1}) + K_j + W_j$,$
$
B_j = A_{j-1}, C_j = B_{j-1}, D_j = C_{j-1},$
$
E_j = D_{j-1} + H_{j-1} + \Sigma_1(E_{j-1})$
$
+G(E_{j-1}, F_{j-1}, G_{j-1}) + K_j + W_j$,$
$
F_j = E_{j-1}, G_j = F_{j-1}, H_j = G_{j-1},$.
```

(4.181)

Here

```
$F(A, B, C) = (A \wedge B) \oplus (^neg A \wedge C)$,$
$
$G(A, B, C) = (A \wedge B) \oplus (B \wedge C) \oplus (C \wedge A)$,$
$
$\Sigma_0(W) = ROTR^2(W) \oplus ROTR^{13}(W) \oplus ROTR^{22}(W)$,$
$
$\Sigma_1(W) = ROTR^6(W) \oplus ROTR^{11}(W) \oplus ROTR^{25}(W)$.
```
