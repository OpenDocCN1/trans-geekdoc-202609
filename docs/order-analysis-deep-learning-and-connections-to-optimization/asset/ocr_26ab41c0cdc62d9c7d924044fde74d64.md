For special classes of sets that occur as inputs, two new distances are introduced that are numerically easier to handle. The so-called radial distance refers to sets whose boundary can be described by certain functionals. If sets can be described by a single inequality constraint, then we work with the introduced constraint distance. In both cases, the crucial optimization problems are simpler than the corresponding problem with the Hausdorff distance.

The main results of this work relate to investigations of the properties of the two new distances but also of the Hausdorff distance. In particular, we show under which conditions the considered sets the Hausdorff distance exists and thus can be computed. radial distance is applied to the radial sets, which are restrictive and whose properties are studied in more detail. It turns out that the radial distance is indeed a metric. The solvability of the crucial optimization problem can be proved for this metric under strict conditions. The class of the constrained sets turns out to be not as restrictive as the class of radial sets. For the corresponding constraint distance, we show that it is a semimetric. Although the triangle inequality does not hold in general, the constraint distance can be used for a reasonable approximation of the true set by a predicted set. Again, the resulting optimization problem for the constraint distance is much simpler than the corresponding problem with the Hausdorff distance.

From the point of applications, closed, bounded intervals (i.e., compact intervals) play an important role as inputs. They are easy to handle in deep learning networks. It is interesting to note that for the set classes considered, radial, constraint, and Hausdorff distances coincide and can be easily calculated. Therefore, the corresponding optimization problem has a simple structure.

# 7.2 Preliminaries

We start with a motivating example that shows why it is useful to study set-valued inputs in neural networks.

**Example 7.1 (Uncertain Data)** Consider an artificial neuron with standard input $x_i \in \mathbb{R}$ for some $i \in \mathbb{N}$. In general, an input $x_i$ is fixed. But if it depends on uncertainties, it is a function of uncertain data. For example, in the field of renewable energies such as photovoltaic plants or wind farms, weather data are the decisive uncertainties (e.g., compare [17]). This means that for a given nonempty uncertainty setU, we consider an input $x_i(u)$ with $u \in U$. To include all $x_i(u)$, we work with the set $A_i := \{x_i(u) \mid u \in U\}$. Figure 7 illustrates an artificial neuron with a set-valued input $A_i \subset \mathbb{R}$. Such an $A_i$ can consist of various types. Compared to stochastic inputs, this approach has the important advantage that one does not need to know the distribution function of the uncertainties. On the other hand, the resulting neural networks are all much more complex.
