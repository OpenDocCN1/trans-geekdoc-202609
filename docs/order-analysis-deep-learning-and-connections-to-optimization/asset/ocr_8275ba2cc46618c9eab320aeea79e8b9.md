# Chapter 7
Deep Learning with Set-Valued Inputs

Abstract In this chapter, standard inputs in deep learning networks are extended to set-valued inputs. In this framework, a set-valued activation map is given that extends the known softsign function. Optimal weights and biases can be computed by minimizing the well-known Hausdorff distance between true and predicted sets. Two additional distances for special classes of sets are introduced, leading to simpler optimization problems. Finally, the theory is specialized to the simple case of inputs in the form of closed bounded intervals.

# 7.1 Introduction

Deep learning is nowadays an indispensable tool in many modern application areas, including AI. Developments in the field of set optimization, with set-valued objectives/constraints, encouraging the study of artificial neural networks with set-valued inputs. Such inputs allow for the consideration of uncertain data. Uncertainties arise, for example, when data are incomplete or caused by rounding errors, approximations or certain predictions, and changing environments ([17, p. 361] and the references therein). Distribution assumptions are not required for this approach.

Moreover, if the data of the features in an instance changes slightly, this may cause a change in the computed estimate. However, one is often interested in a robust estimate, meaning that the computed estimate remains unchanged under small perturbations of these input values. This can be achieved by working with set-valued inputs, such certain balls around the standard input. Robust estimates are preferred in applications.

Set-valued inputs in deep learning networks require more theoretical and numerical effort. Thus, one needs a set-valued activation map by extension of the softsign function (Definition 6.2). And the crucial problem to determine the optimal weights and biases is more complex than one needs to minimize the distance between true and predicted sets. If one chooses the well-known Hausdorff distance, one has to solve “inf” problems, which can be complicated. Investigations of the Hausdorff distance can be found, for example, in [131, 9, 83].
