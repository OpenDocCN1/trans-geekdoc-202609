Radial functions are used in various areas of mathematics. In $\mathbb{R}^2$, radial distances defined by integrals are already studied by Méneroux et al. [104] in a different framework. This chapter introduces a more general version of a radial distance in real normed spaces.

A specialization of the set-valued theory to interval-valued inputs is described in Sect. [16, page 2]). Recently, Betencourt and Muhanna [16] published a deep learning method for interval-valued inputs, called deep interval neural network. It is completely based on interval analysis, which means that gradient methods also work with interval-valued variables. In Sect. 7.5, however, we work with real-valued weights and only interval-valued biases, so we can use the usual optimization procedures. For example, when using penalty methods, we can also solve the subproblems with unconstrained optimization methods. The goal is to keep the use of interval arithmetic to a minimum as much as possible.
