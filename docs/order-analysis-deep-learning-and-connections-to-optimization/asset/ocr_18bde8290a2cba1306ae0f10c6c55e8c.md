# 7.5 Specialization to Interval-Valued Inputs

Proof Let $[a, \overline{a}], [b, \overline{b}] \in \mathcal{C}_{int}(\mathbb{R})$ be arbitrarily chosen intervals.

+   (a) This formula is well-known and a direct consequence of the Hausdorff difference given in Definition 7.4.

+   (b) First, we note that $S(\mathbb{R}) = \{-1, 1\}$. For the radial functionals $\varphi_{[a, \overline{a}]}$ and $\varphi_{[b, \overline{b}]}$, we then get, under the additional assumptions,

```
$\varphi_{[a, \overline{a}]}(x) = \begin{cases} -a & \text{for } x = -1 \ \overline{a} & \text{for } x = 1 \end{cases}$
```

and

```
$\varphi_{[b, \overline{b}]}(x) = \begin{cases} -b & \text{for } x = -1 \ \overline{b} & \text{for } x = 1 \\end{cases}$
```

respectively. The radial distance is thus given as

```
$d_r([a, \overline{a}], [b, \overline{b}]) = \sup_{x \in S(\mathbb{R})} |\varphi_{[a, \overline{a}]}(x) - \varphi_{[b, \overline{b}]}(x)|$
$= \max \{|\varphi_{[a, \overline{a}]}(-1) - \varphi_{[b, \overline{b}]}(-1)|, |\varphi_{[a, \overline{a}]}(1) - \varphi_{[b, \overline{b}]}(1)|}$
$= \max \{|-a - (-b)|, |\overline{a} - \overline{b}|}\n$= \max \{|a - \overline{b}|, |\overline{a} - \overline{b}|}$
```

+   (c) We have

```
$[a, \overline{a}] = \{x \in \mathbb{R} \mid a \leq x \leq \overline{a}\} = \{x \in \mathbb{R} \mid \max(0, a - x) + \max(0, x - \overline{a}) \leq 0\}$
```

and

```
$[b, \overline{b}] = \{x \in \mathbb{R} \mid \max(0, b - x) + \max(0, x - \overline{b}) \leq 0\}$
```

Next, we determine the maximal value of the optimization problem

```
$$\sup_{x \in [a, \overline{a}]} \max(0, b - x) + \max(0, x - b)$$\n$= \max_{x \in [a, \overline{a}]} \max(0, b - x) + \max(0, x - \overline{b}). \quad \quad (7.15)$
```

To do this, we make the following distinction:

+   (I) $[a, \overline{a}] \cap [b, \overline{b}] \neq \emptyset$.

+   (1) We start with the case $[a, \overline{a}] \subseteq [b, \overline{b}]$ (see Fig. 7.4). Then the maximal value of problem (7.15) is 0.
