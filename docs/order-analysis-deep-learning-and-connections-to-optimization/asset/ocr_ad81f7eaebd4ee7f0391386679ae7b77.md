(c) Let $(Y, T)$ be a topological space, let $S$ be a subset of $Y$, and let some $y \in Y$ be a given element. The set $S$ is called a neighborhood of $y$ iff there is an open set $T$ with $y \in T \subseteq S$. $y$ is called an interior element of $S$ iff there is a neighborhood $T$ of $y$. The set of all interior elements of $S$ is called the interior of $S$, and it is denoted by $int(S)$. The set $S$ is called closed iff $Y \setminus S$ is open. The set of all elements of $Y$ for which every neighborhood meets set $S$ is called the closure of $S$, and it is denoted by $cl(S)$.

+   (i) A nonempty preorder set $I$, the order relation is reflexive and transitive) is called directed iff two arbitrary elements in $I$ are majorized in $I$.

+   (ii) A map from a directed set $I$ to the nonempty set $Y$ is called a net and it is denoted by $(y_i)_{i \in I}$.

+   (iii) $(Y, T)$ be a topological space. A net $(y_i)_{i \in I}$ is called to converge to some $y \in Y$ iff for every neighborhood $U$ of $y$ there is $n \in I$ so that

$y_i \in U$ for all $i \geq n$ (denotes the preorder in $I$).

In this case, we write $y = \lim_{i \to \infty} y_i$.

+   (iv) $(Y, T)$ be a topological space. An element $y \in Y$ is called a cluster point of $y$ iff every neighborhood $U$ of $y$ and every $n \in I$ there is an $i \in I$ with $i \geq n$ so that $y_i \in U$.

+   (e) A nonempty subset $S$ of a topological space $(Y, T)$ is called compact iff every net in $S$ has a cluster point in $S$.

+   (f) Let $(X, S)$ and $(Y, T)$ be two topological spaces. A map $f : X \to Y$ is called continuous at $x \in X$ iff for every neighborhood $V$ of $f(x)$ there is a neighborhood $U$ of $x$ with $f(x) \subseteq U$. $f : X \to Y$ is called continuous over $X$ iff $f$ is continuous at every $x \in X$.

Next, we consider a topological space $(X, T)$ where $X$ is now a real linear space. In this case, we require that the topological and linear structure of the space are compatible.

# **Definition 1.14** $Y$ be a real linear space and $T$ be a topology on $Y$.

+   (a), $(Y, T)$ is called a real linear space iff addition and multiplication with reals are continuous, i.e., the maps

$(x, y) \mapsto x + y$ with $x, y \in Y$,

$(\alpha, y) \mapsto \alpha y$ with $\alpha \in \mathbb{R}$ and $y \in Y$

are continuous on $Y \times Y$ and $\mathbb{R} \times Y$, respectively. In many situations, we use, for simplicity, the notation $Y$ instead of $(Y, T)$ for a real topological linear space.

+   (b) A subset $S$ of a topological linear space $Y$ is called bounded iff for $0$-neighborhood $U$ there is a $\lambda \in \mathbb{R}$ with the property $S \subseteq \lambda U$.
