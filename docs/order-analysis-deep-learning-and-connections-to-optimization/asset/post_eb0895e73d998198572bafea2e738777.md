
# 3.4 Application in Nonlinear Optimization

**Example 3.2 ([35, Example 3.16])** We modify the discrete-continuous optimization problem (3.6) in Example 3.1, and investigate the problem

```
\min \left(x_d - \frac{1}{2}\right)^2 + x_c^2
\text{subject to the constraint}
(x_d - 5)^2 - 17 \le 0
$x_d \in \mathbb{Z}, x_c \in \mathbb{R} . (3.13)
```

In this way, the constraint function has a nonempty subdifferential. With the objective function $f : \mathbb{R}^2 \to \mathbb{R}$ given by

```
f(x_d, x_c) := \left(x_d - \frac{1}{2}\right)^2 + x_c^2 \text{ for all } x_d \in \mathbb{R}, x_c \in \mathbb{R}
```

and the constraint function $g_1 : \mathbb{R}^2 \to \mathbb{R}$ defined by

```
g_1(x_d, x_c) := (x_d - 5)^2 - 17 \text{ for all } x_d \in \mathbb{R}, x_c \in \mathbb{R}
```

(here, we formally extend the domain $\mathbb{Z}$ to $\mathbb{R}$) we obtain for arbitrary $x_d \in \mathbb{Z}$ and $x_c \in \mathbb{R}$

```
\partial_{>} f(x_d, x_c) = \left\{ \nabla f(x_d, x_c) \right\} = \left\{ \begin{matrix} 2(x_d - \frac{1}{2}) \\ 2x_c \end{matrix} \right\}
```

and

```
\partial_{>} g_1(x_d, x_c) = \left\{ \nabla g_1(x_d, x_c) \right\} = \left\{ \begin{matrix} 2(x_d - 5) \\ 0 \end{matrix} \right\}
```

Now, we set $\tilde{x} := (1,0)^T \in \mathcal{S}$ and get $\ell_0 := \nabla f(\tilde{x}) = (1,0)^T$ and $\ell_1 := \nabla g_1(\tilde{x}) = (-8,0)^T$. The inequality constraint in problem (3.13) is not "active", i.e., $I(\tilde{x}) = \emptyset$, but $J(\tilde{x}) = \{1\}$, because the feasible set is given by $\mathcal{S} := \{1, 2, \dots, 9\} \times \mathbb{R}$ and we with $\alpha = 8$ and $\beta_1 = 1$, we get

```
$g_1(x) \le -1 = g_1(\tilde{x}) \text{ for all } x \in \mathcal{S} .
```

```
\alpha\ell_0 + \beta_1\ell_1 = 8 \left(\begin{matrix} 1 \\ 0 \end{matrix}\right) + \left(\begin{matrix} -8 \\ 0 \end{matrix}\right)

```

i.e., the equality (3.9) is fulfilled. With Theorem 3.2, we conclude that $\tilde{x}$ is a unique minimal solution of the discrete-continuous optimization problem (3.13).

Application in Vector Optimization

**Abstract** Vector optimization is a typical application of $-C$ or $-\mathcal{K}$ representing functionals. Here, we study general problems of vector optimization involving vector-valued objective map. We investigate vector optimization problems with a fixed order structure given by a convex cone $C$, which is sometimes assumed to be pointed, and those with a variable order structure. ## 4.1 Fixed Order Structure

We start our investigations with a fixed preorder cone given in a real linear space.

**Assumption 4.1** Let $Y$ be a real linear space, let $C$ be a convex cone in $Y$, and let $T$ be a nonempty subset of $Y$.
