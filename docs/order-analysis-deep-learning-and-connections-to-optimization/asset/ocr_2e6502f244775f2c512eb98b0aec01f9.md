**Remark 2.5** ([74, Remark 3.2]) Let Assumption 2.2 be satisfied, and let $\psi : Y \to \mathbb{R}$ be a $-\mathcal{K}$ representing functional. Then it is obvious from the definition of the order relations $\le_1$ and $\le_2$ that for every $y^1, y^2 \in Y$ the equivalences

```
$y^1 \le_1 y^2 \iff \psi(y^1 - y^2, y^1) \le 0$
```

and

```
$y^1 \le_2 y^2 \iff \psi(y^1 - y^2, y^2) \le 0$
```

hold. Also, in the case of a variable order structure, a complicated order inequality can be written as an inequality in $\mathbb{R}$.

+   (a) $\bar{y} - \mathcal{K}(\bar{y}) = \{y \in Y \| \psi(\bar{y} - y, \bar{y}) \le 0\}$ for all $\bar{y} \in Y$.
