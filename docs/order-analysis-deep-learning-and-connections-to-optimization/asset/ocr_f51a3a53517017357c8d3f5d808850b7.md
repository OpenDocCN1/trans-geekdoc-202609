# Chapter 2
—C Representing Functionals

**Abstract** This chapter provides an introduction to order analysis. Based on a certain property of Bishop-Phelps, penalty, and scalarizing functionals, we introduce functionals representing the negative preorder. This representation is done in such a way that the negative preorder equals the sublevel set of such a functional with respect to the level 0. The preorder can then be treated using nonlinear analysis, and we investigate various properties of these—C representing functionals like basic properties, sublinearity, directional differentiability, subdifferential, zeros, and separation. Furthermore, we extend this approach to certain set-valued maps so that variable order structures also be studied.

# 2.1 Bishop-Phelps, Penalty, and Scalarizing Functionals

To motivate the notion of —C representing functionals, we start with Bishop-Phelps, penalty, and scalarizing functionals as examples of the unified approach established by —C representing functionals.

# 2.1.1 Bishop-Phelps Functionals

In 1962, Bishop and Phelps [18] introduced a class of order cones with a rich mathematical structure (see also [112]). Nowadays, many authors use a slightly different definition from the original one. We recall the most commonly used.

**Definition 2.1** ([74, Definition 2.1]) Let $(Y, ||\|)$ be a real normed space, and let some continuous linear functional $\ell \in Y^*$ be arbitrarily chosen. The convex cone

```
$C(\ell) := \{y \in Y \mid \ell(y) \geq ||y|\}$
```

is called a Bishop-Phelps cone (see Fig. 2.1).
