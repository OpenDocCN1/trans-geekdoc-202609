With the inequality (7.7), we conclude for all $\ell \in \mathbb{N}$

```
$$\varphi(a_{k\ell}) = \inf_{b\in B} ||a_{k\ell} - b|\
\leq ||a_{k\ell} - b_{k\ell}||\
= |||\tilde{a} - b_{k\ell} + a_{k\ell}||\
\leq ||\tilde{a} - b_{k\ell}|| + |||\tilde{a} - a_{k\ell}||\
\leq \varphi(\tilde{a}) + \varepsilon + |||\tilde{a} - a_{k\ell}||. \quad (7.8)$
```

The equality (7.6) and the inequality (7.8) then imply

```
$$\sup_{a\in A, b\in B} ||a - b|| = \varphi(a) + \varepsilon + \lim_{\ell\to\infty} |||\tilde{a} - a_{k\ell}|| = \varphi(\tilde{a}) + \varepsilon.\n\quad = =0$
```

Since this inequality holds for all $\varepsilon > 0$, we get in the limit

```
$$\sup_{a\in A, b\in B} ||a - b|| = \varphi(\tilde{a}).$
```

This means that $\tilde{a} \in A$ is a maximal solution of the sup inf $\inf_{a\in A, b\in B} ||a - b||$, which has to be shown.

The middle part of the proof of Proposition 7.3 follows the proof of [52, Proposition 3.5] given by Ha in a more general setting. In game theory, the solvability of sup inf problems is also studied, with the question under which conditions the equality

```
$$\inf_{a\in A, b\in B} ||a - b|| = \inf \sup_{a\in A, b\in B} ||a - b||$
```

holds (compare Tuy [136] and Ricci [118]). However, in the context of Hausdorff distance, such equality is not relevant.
