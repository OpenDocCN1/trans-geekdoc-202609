
## 18 Preliminaries

The subdifferential of the norm $\bar{x}$ is given as:

$$
\partial|\bar{x}\|X = \begin{cases} \{\ell \in X^* \| \ell(\bar{x}) = \|\bar{x}\| \text{ and } \|\ell\|_{_{X^*} = 1\} & \text{if } \bar{x} \neq 0 \\ \{\ell \in X^* \| \|\bar{x}\|_{X^*} \le 1\} & \text{if } \bar{x} = 0 \end{cases}
$$

(for a proof, see [72, Example 3.24, (b)].)

**Proposition 1.9** $(X, \|\cdot\|)$ be a real normal space, and let $f : X \rightarrow \mathbb{R}$ be a continuous convex functional. Then the subdifferential $\partial f(\bar{x})$ is nonempty for every $\bar{x} \in X$.

The following theorem establishes a relationship between the directional derivative and the subdifferential:

**Theorem 1.3** $(X, \|\cdot\|)$ be a real normal space, and let $f : X \rightarrow \mathbb{R}$ be a convex functional.

- (a) For an arbitrary $\bar{x} \in X$, we have
  $$\partial f(\bar{x}) = \{\ell \in X^* \| f'(\bar{x}) \ge \ell(h) \text{ for all } h \in X\}$$
- where $f'(\bar{x})$ denotes the directional derivative of $f$ at $\bar{x}$ in the direction $h$.
- (b) In addition, let $f$ be continuous. Then for every $\bar{x}, h \in X$ the directional derivative of $f$ at $\bar{x}$ in the direction $h$ is given as
  $$f'(\bar{x}) = \max_{\ell \in \partial f(\bar{x})} \ell(h).$$

A useful subclass of the class of convex functionals is the strongly convex functionals, here we restrict ourselves to functions defined on $\mathbb{R}^n$.

**Definition 1.25** Let the function $f : \mathbb{R}^n \rightarrow \mathbb{R}$ and some $\mu > 0$ be given. The function $f$ is called $\mu$-strongly convex if all $x, y \in \mathbb{R}^n$
$$\mu \frac{\lambda(1-\lambda)}{2}\|x-y\|^2 + f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y) \text{for all } \lambda \in [0, 1].$$

Strongly convex functionals can be characterized in a simple way.

**Proposition 1.10** ([42, Lemma 2.12]) Let the function $f : \mathbb{R}^n \rightarrow \mathbb{R}$ and some $\mu > 0$ be given. The function $f$ is $\mu$-strongly convex if and only if there exists a convex function $g : \mathbb{R}^n \rightarrow \mathbb{R}$ with
$$f(x) = g(x) + \frac{\mu}{2}\|x\|^2 \text{for all } x \in \mathbb{R}^n.$$

## Chapter 2: —C Representing Functionals

**Abstract** This chapter provides an introduction to order analysis. Based on a certain property of Bishop-Phelps, penalty, and scalarizing functionals, we introduce functionals representing the negative preorder. This representation is done in such a way that the negative preorder equals the sublevel set of such a functional with respect to the level 0. The preorder can then be treated using nonlinear analysis, and we investigate various properties of these—C representing functionals like basic properties, sublinearity, directional differentiability, subdifferential, zeros, and separation. Furthermore, we extend this approach to certain set-valued maps so that variable order structures also be studied.

### 2.1 Bishop-Phelps, Penalty, and Scalarizing Functionals

To motivate the notion of —C representing functionals, we start with Bishop-Phelps, penalty, and scalarizing functionals as examples of the unified approach established by —C representing functionals.

### 2.1.1 Bishop-Phelps Functionals

In 1962, Bishop and Phelps [18] introduced a class of order cones with a rich mathematical structure (see also [112]). Nowadays, many authors use a slightly different definition from the original one. We recall the most commonly used.

**Definition 2.1** ([74, Definition 2.1]) Let $(Y, \|\cdot\|)$ be a real normed space, and let some continuous linear functional $\ell \in Y^*$ be arbitrarily chosen. The convex cone
$$C(\ell) := \{y \in Y \mid \ell(y) \geq \|y\|\}$$
is called a Bishop-Phelps cone (see Fig. 2.1).

### 2.1.2 Penalty Functionals

Penalty methods have been used in numerical optimization for many decades. Penalty functionals play an important role here.

**Definition 2.2** Let $S$ be a nonempty subset of a real normed space $(Y, \|\cdot\|)$. A continuous functional $\eta : Y \to \mathbb{R}_+$ with the property $(for y \in Y)$
$\eta(y) = 0 \iff y \in S$
is called *exterior penalty functional* or simply penalty functional for $S$ (see Fig. 2.2).

In penalty methods, these functionals are multiplied by sufficiently large real numbers, called penalty parameters. The continuity assumption in Definition 2.2 is needed for convergence proofs in numerical optimization.

**Example 2.2** Let $Y := \mathbb{R}^m$ with $m \in \mathbb{N}$ be given. Then we consider the polyhedral closed convex cone with nonempty interior
$C := \{y \in \mathbb{R}^m \mid a^i^T y \le 0 \text{ for all } i \in \{1, \dots, k\}\}$
for some $k \in \mathbb{N}$ and nonzero vectors $a^1, \dots, a^k \in \mathbb{R}^m$. Next, we define the function $\eta : \mathbb{R}^m \to \mathbb{R}_+$ by
$$\eta(y) := \sum_{i=1}^k (max \{0, -a^i^T y\})^2 \text{ for all } y \in \mathbb{R}^m.$$

Then it follows for arbitrary $y \in \mathbb{R}^m$
$y \in C \iff -a^i^T y \le 0 \text{ for all } i \in \{1, \dots, k\}$
$\iff max \{0, -a^i^T y\} = 0 \text{ for all } i \in \{1, \dots, k\}$.
