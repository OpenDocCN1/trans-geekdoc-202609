**Corollary 4.1** Let Assumption 4.1 be satisfied, and let $\psi$ be a $-C$ representing functional with $\psi(0y) = 0$. Then we have

$\tilde{y} \text{ strongly minimal element of } T \iff \tilde{y} \text{ maximal solution of } \max_{y \in T} \psi(\tilde{y} - y)$.$

**Proof** By 4.4, the assertion is a direct consequence of the equivalences

```
$$\sup_{y \in T} \psi(\tilde{y} - y) \le 0 \iff \psi(\tilde{y} - y) \le 0 \text{ for all } y \in T$$
$$\$\iff \psi(\tilde{y} - y) \le \psi(\tilde{y} - \tilde{y}) = 0 \text{ for all } y \in T$$
$$\$\iff \tilde{y} \text{ maximal solution of } \max_{y \in T} \psi(\tilde{y} - y).$$
```

Note that in the case of a convex functional $\psi$ one must maximize a convex functional in Corollary 4.1, which is in general a difficult task. By Proposition 2.10, the assumption $\psi(0y) = 0$ in Corollary 4.1 is satisfied if the functional $\psi$ is additionally positively homogeneous or subadditive (see also the note on page 36).

# 4.2 Variable Order Structure

Now, we investigate vector optimization problems with variable order under the following assumption:

**Assumption 4.2** Let $Y$ be a real linear space, let $\mathcal{K} : Y ightarrow Y$ denote a set-valued map so that the images $\mathcal{K}(y)$ are convex cones for all $y \in Y$, and let $T$ be a nonempty subset of $Y$.

In general, the known orders $\le_1$ and $\le_2$ in Definition 2.7 are used in vector optimization with variable order structure. Figure 4.4 illustrates such a variable order.

Based on these relations, two optimality notions are in use.

**Definition 4.4** ([33, Definition 2.7]) Let Assumption 4.2 be satisfied.

+   (a) An element $\tilde{y} \in T$ is called a *nondominated* element of the set $T$ iff there is no $y \in T$ with $y \le_1 \tilde{y}$ and $y \neq \tilde{y}$.
(b) An element $\tilde{y} \in T$ is called a *minimal* element of the set $T$ iff there is no $y \in T$ with $y \le_2 \tilde{y}$ and $y \neq \tilde{y}$.
