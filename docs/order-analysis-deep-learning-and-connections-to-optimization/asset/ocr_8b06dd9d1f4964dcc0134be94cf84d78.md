# 1.3 Normed Spaces

**Definition 1.19** Let $(Y, ||\cdot||)$ be a real normed space. A nonempty subset S of Y is called weakly sequentially compact iff every sequence in S contains a weakly convergent subsequence whose weak limit belongs to S.

In a reflexive Banach space, a simple sufficient condition for the weak compactness of a nonempty subset can be given (for instance, compare Werner [140], Corollary 6.1.9).

**Proposition 1.6** Every nonempty convex bounded subset of a reflexive Banach space is weakly sequentially compact.

Next, we extend the notion of a convex functional.

**Definition 1.20** Let $(X, ||\cdot||)$ be a real normed space, let S be a nonempty convex subset of X, and let $f : S \rightarrow \mathbb{R}$ be a given functional. If for every $\alpha \in \mathbb{R}$ the sublevel set $S_{\alpha} := \{x \in S \mid f(x) \leq \alpha\}$ is convex, then the functional $f$ is called quasiconvex.

**Definition 1.21** Let S be a nonempty subset of a real linear space X, and $f : S \rightarrow \mathbb{R}$ be a given functional. An element $\bar{x} \in S$ is called a *minimal point* of $f$ on $S$ iff

```
$f(\bar{x}) \leq f(x) \text{ for all } x \in S$.
```

In this case, $\bar{x}$ is called *minimal solution* of the optimization problem min $f(x)$, and the functional value $f(\bar{x})$ is called *minimal value* of the optimization problem. For $S \neq X$, the set S is then called a *constraint set*. Moreover, $\bar{x} \in S$ is called a *maximal solution* of the optimization problem max $f(x)$ iff

```
$f(x) \leq f(\bar{x}) \text{ for all } x \in S$,
```

and in this case, $f(\bar{x})$ is said to be a *maximal value* of this optimization problem.

Now, we give a sufficient condition for the existence of at least one minimal point (compare [72], Theorem 2.12).

**Theorem 1.2** Let S be a nonempty convex closed bounded subset of a reflexive Banach space, and let $f : S \rightarrow \mathbb{R}$ be a continuous quasiconvex functional. Then $f$ has at least one minimal point on S.

**Proposition 1.7** Let $(Y, ||\cdot||)$ be a real normed space. With the norm $||\cdot||^* : Y^* \rightarrow \mathbb{R}$ given by

```
$||\ell||^* = \sup_{y \in Y} \frac{||\ell(y)||}{||y||} \text{ for all } \ell \in Y^*$,
```

$(Y^*, ||\cdot||^*)$ is a real Banach space.
