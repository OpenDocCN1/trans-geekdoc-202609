# 7.4 Distance Between Sets

Obviously, the activation map $\mathcal{F}$ does not change the shape of the set under consideration. The behavior of the activation map is illustrated by the following simple example:

**Example 7.3** $B(0_X, 1000)$ be the closed ball around $0_X$ with radius 1000 in a real normed space $(X, \|\cdot\|)$. Then with the Definitions $7.3$ and $7.2$, we get

```
$$\mathcal{F}(B(0_X, 1000)) = \frac{1}{\sup_{x \in B(0_X, 1000)} \|x\|} B(0_X, 1000) = \frac{1}{1001} B(0_X, 1000) = B(0_X, \frac{1000}{1001}) \approx B(0_X, 0.999,)$
```

which is almost equal to the unit ball. On the other hand, for the small ball $B(0_X, \frac{1}{2})$, we get

```
$$\mathcal{F}(B(0_X, \frac{1}{2})) = \frac{1}{1+\frac{1}{2}} B(0_X, \frac{1}{2}) = \frac{2}{3} B(0_X, \frac{1}{2}) = B(0_X, \frac{1}{3}).$.
```

The absolute values of the images of the softsign function $\varphi$ (see Fig. 6.6) are bounded by 1. This property also applies to the activation map $\mathcal{F}$ with respect to the set norm $\|\cdot\|$,

**Proposition 7.1** Let $(X, \|\cdot\|)$ be a real normed space. Then the activation map $\mathcal{F} : \widehat{P}(X) \rightarrow \widehat{P}(X)$ satisfies the inequality

```
$$\|\mathcal{F}(A)\| < 1$ for all $A \in \widehat{P}(X).$
```

**Proof** For an arbitrary set $A \in \widehat{P}(X)$, we immediately obtain

```
$$\\|\mathcal{F}(A)\| = \frac{\|A\\|}{1+\\|A\\|} < 1,$
```

Consequently, the activation map $\mathcal{F}$ generally reduces the norm of a set without changing its shape.
