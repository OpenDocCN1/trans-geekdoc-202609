# 3.2 Bibliographical Notes

This chapter presents results given by Eichfelder and Jahn [35]. It is a special approach, which can be used for nonconvex optimization problems. Therefore, discrete-continuous nonlinear optimization problems are included. The main tool for this theory is the existence of a—C representing functional. It is essential that we work with a unique minimizer. Although this seems to be restrictive, notice that Planiden and Wang [113] have stated that most convex functions have unique minimizers.
