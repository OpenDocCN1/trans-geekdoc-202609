# 6.4 Activation Functions

In a feedforward network of artificial neurons, the *depth* of the network is defined as the number of all hidden layers together with the output layer, or in other words

```
depth := 1 + #(hidden layers)
```

(see Fig.6.3). The number of neurons per layer is called the *layer width*. The maximum of all hidden layers is said to be the *width* of such a network.

For a special application, an FNN with six layers is shown in Fig. 6.23 (see also Example 6.9). Typically, a *deep neural network* consists of several hidden layers, which means it does not have a small depth. This number can become large for modern complex applications.

To determine the number of parameters per hidden layer, we consider an arbitrary hidden layer with a total of $s \in \mathbb{N}$ artificial neurons, all of which have $t \in \mathbb{N}$ parameters. Since there are $t$ weights and one bias per artificial neuron, the entire hidden layer under consideration is $s(t+1)$ parameters. For example, for 100 hidden layers of this type, we get a total of $100(t+1)$ parameters, which can be very large.

In the artificial neurons of a hidden layer, the outputs are function values of an activation function (as specified in equation (1)). These outputs are inputs to the subsequent hidden layer. An affine linear expression is formed with the inputs, and then the activation function is applied again. Thus, the activation function is applied repeatedly from hidden layer to hidden layer, resulting in a formally complex expression.

# 6.4 Activation Functions

In this section, we discuss common activation functions that are crucial for the functioning of deep neural networks. We restrict ourselves to established activation functions and do not provide an overview of all possible variants. Such functions are nonlinear or piecewise linear to allow a functional interpretation of the complex relationships provided by the deep neural network.

# 6.4.1 Sigmoid Function

The sigmoid function is probably one of the best known activation functions.

Definition 6.1 The function $\varrho : \mathbb{R} \to (0, 1)$ given by

```
\varrho(x) := \frac{1}{1 + e^{-x}} \quad \text{for all } x \in \mathbb{R}$
```

is called *sigmoid* function.
