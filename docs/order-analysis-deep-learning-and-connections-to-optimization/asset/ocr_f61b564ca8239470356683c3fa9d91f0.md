**Proposition 1.11 ([42, Lemma 2.13])** $\mu$-strongly convex and continuous function $f:\mathbb{R}^n \to \mathbb{R}$ (with $\mu>0$) has a unique minimal point (see also page 57).

The following variational inequality is useful for convergence proofs:

**Proposition 1.12 ([42, Lemma 2.14])** For some $\mu>0$, let the function $f:\mathbb{R}^n \to \mathbb{R}$ be $\mu$-strongly convex and differentiable. Then we have

```
$f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|_2^2 \text{ for all } x, y \in \mathbb{R}^n.$
```
