
## 7.2 Preliminaries

Fig. 7.1 Illustration of an artificial neuron with set-valued input $A_i \subset \mathbb{R}$

In the following, however, we consider not only subsets of real numbers, as shown in Fig. 7.1, but also subsets of a real linear space, which can also be infinite-dimensional.

Throughout this chapter, let $X$ be a real linear space (but very often $X$ is endowed with a norm $\|\cdot\|$, so $(X, \|\cdot\|)$ is assumed to be a real normed space). The power set of $X$ (of all subsets of the real linear space $X$, including the empty set and $X$ itself) is denoted by $P(X)$, and the notation $P(X) := P(X)\setminus\{\emptyset, X\}$ is used for the power set without the empty set and the space whole.

The basic arithmetic for calculating with sets from Definition 1.2 applies to neural computations. For the sake of completeness, we define the geometric difference of sets, although we will not use this further.

**Definition 7.1** For a real linear space $X$, nonempty sets $A, B \subset X$ are arbitrarily given. The set

$A - B := \{x \in X \mid x + B \subseteq A\}$

is called *geometric difference* of $A$ and $B$.

There are different terms for the difference of sets, because the algebraic difference is generally too large. Although the term “geometric difference” is generally more appropriate, this term has the disadvantage that this special difference can be empty. To avoid empty sets, we use the algebraic difference in this paper. The following simple example underlines the previous remark:

**Example 7.2** In a real normed space $(X, \|\cdot\|)$, let

$B(0_X, \alpha) := \{x \in X \mid \|x\| \leq \alpha\}$

denote the closed ball around the origin with radius $\alpha > 0$. The closed unit ball, we then get

$B(0_X, 1) - B(0_X, 1) = B(0_X, 1) + B(0_X, 1) = 2B(0_X, 1)$

and

$B(0_X, 1) -_g B(0_X, 1) = \{0_X\}$.

Moreover, we obtain $B(0_X, 1) -_g B(0_X, 2) = \emptyset$.

Finally, if one considers a single artificial neuron with set-valued inputs $A_1, \dots, A_n \in \widetilde{P}(X)$ (where $n \in \mathbb{N}$ and $X$ being a real space), arbitrary weights $w_1, \dots, w_n \in \mathbb{R}$, and an arbitrary set $B \in \widetilde{P}(X)$ (commonly called bias), the affine linear combination

$$\sum_{i=1}^n w_i A_i + B \quad (7.1)$$

is a well-defined set. The question of an appropriate activation function is discussed in the next section.

## 7.3 Activation Map

If the term (7.1) using an activation function such as the sigmoid function would convert it to a more usable form. However, since this set is a set, this transformation cannot be performed in this way. But the softsign function (see Definition 6.2) as a special activation function can be extended to sets.

First, we recall the known definition of the norm of a set in a real space (e.g., see [11]).

**Definition 7.2** $(X, |\cdot\|)$ be a real normed space. The norm of a set $A \in \widetilde{P}(X)$ is defined by

$$\|A\| := \sup_{a \in A} \|a\|$$

Of special importance are now sets $A \in \widetilde{P}(X)$ with the additional property $\|A\| < \infty$; we summarize these sets in the system space $\mathcal{P}(X) \subset \widetilde{P}(X)$, i.e.,

$$\mathcal{P}(X) := \{A \in \widetilde{P}(X) \mid \|A\| < \infty\}$$

For deep learning networks, it is useful to work with norm-bounded sets. With this concept of the norm of a set, an activation map can also be defined.

**Definition 7.3** $(X, \|\cdot\|)$ be a real normed space. A map $\mathcal{F} : \widetilde{P}(X) \to \widetilde{P}(X)$ with

$$\mathcal{F}(A) := \frac{1}{1+\|A\|} A \quad \text{for all } A \in \widetilde{P}(X)$$

is called activation map.

## 7.4 Distance Between Sets

Obviously, the activation map $\mathcal{F}$ does not change the shape of the set. The behavior of the activation map is illustrated by the following example:

**Example 7.3** $B(0_X, 1)$ be the closed ball around $0_X$ with radius 1 in a real normed space $(X, \|\cdot\|)$. Then with Definitions 7.3 and 7.2, we get

$$\mathcal{F}(B(0_X, 1)) = \frac{1}{\sup_{x \in B(0_X, 1)} \|x\|} B(0_X, 1) = \frac{1}{1} B(0_X, 1) = B(0_X, 1)$$

which is almost equal to the unit ball. On the other hand, for small ball $B(0_X, 1/2)$, we get

$$\mathcal{F}(B(0_X, 1/2)) = \frac{1}{1+1/2} B(0_X, 1/2) = \frac{2}{3} B(0_X, 1/2) = B(0_X, 1/3).$$

The absolute values of the images of the softsign function $\varphi$ (see Fig. 6.6) are bounded by 1. This property also applies to the activation map $\mathcal{F}$ with respect to the set norm $\|\cdot\|$,

**Proposition 7.1** Let $(X, \|\cdot\|)$ be a real normed space. Then the activation map $\mathcal{F} : \widetilde{P}(X) \to \widetilde{P}(X)$ satisfies the inequality

$$\|\mathcal{F}(A)\| < 1 \quad \text{for all } A \in \widetilde{P}(X).$$

**Proof** For an arbitrary set $A \in \widetilde{P}(X)$, we immediately obtain

$$\|\mathcal{F}(A)\| = \frac{\|A\|}{1+\|A\|} < 1,$$

which has to be shown.

Consequently, the activation map $\mathcal{F}$ generally reduces the norm of a set without changing its shape.

Considering a network of neurons with set-valued inputs and different hidden layers, one gets a predicted output $S_{pred}$ being a set. This set has then to be compared with the true set $S_{true}$. For deep learning networks, we make the following assumption:

**Assumption 7.1** Let $X$ be a real space, $n \in \mathbb{N}$ be the total number of weights, $m \in \mathbb{N}$ be the total number of biases, let $S_{pred} : \mathbb{R}^n \times (\widetilde{P}(X))^m \to \widetilde{P}(X)$ be given, and let $S_{true} \in \widetilde{P}(X)$ be a given true.

If $d : \widetilde{P}(X) \times \widetilde{P}(X) \to \mathbb{R}$ defines any appropriate distance function between two sets, optimal weights and biases can be calculated as solutions of the optimization problem

$$\min d(S_{pred}(w_1, \dots, w_n), B_1, \dots, B_m), S_{true})$$
$$\text{subject to}$$
$$w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widetilde{P}(X). \quad (7.2)$$

In the following subsections, we investigate three different distances in problem (7.2), namely the Hausdorff distance and the radial and constraint distances.

### 7.4.1 Hausdorff Distance

For the comparison of two sets, the well-known Hausdorff distance plays an important role.

**Definition 7.4** $(X, \|\cdot\|)$ be a real normed space. For two sets $A, B \in \widetilde{P}(X)$, the *Hausdorff distance* is defined by

$$d_H(A, B) := \max \left( \sup_{a \in A} \sup_{b \in B} \|a - b\|, \sup_{b \in B} \sup_{a \in A} \|a - b\| \right).$$

The two results in Proposition 7.2 provide the motivation for optimization problem (7.2) using the Hausdorff distance. Although the first result for comparing two sets with the Hausdorff distance is well-known in special cases, we provide a simple proof of the-

**Proposition 7.2** $(X, \|\cdot\|)$ be a real normed space, and let two sets $A, B \in \widetilde{P}(X)$ be arbitrarily chosen.

(a) $A = B \iff d_H(A, B) = 0.$
(b) If, in addition, $(X, \|\cdot\|)$ is a reflexive Banach space and the sets $A, B$ are convex, then

$A \subseteq B \iff d_H(A, B) = 0.$

**Proof** For two sets $A, B \in \widetilde{P}(X)$, we get

$A \subseteq B \iff \sup_{a \in A} \inf_{b \in B} \|a - b\| = 0.$
$B \subseteq A \iff \sup_{b \in B} \inf_{a \in A} \|a - b\| = 0.$

which shows part (a) of the assertion. Under the additional assumptions in part (b), the reverse implication follows.
