
## 6.6 Gradient Methods

### Algorithm 6.4 (Stochastic gradient method)

```
1 Input: $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$,
2 maximal iteration number $i_{max}$.
3
4 $i := 0$ % initialization
5 while $i \le i_{max}$ do
6 $k := \text{randi}(p)$ % random integer (uniformly sampled in $\{1, \dots, p\}$)
7 $d^i := -\nabla f_k(x^i)$ % iteration direction
8 choose $\lambda_i > 0$ % step size
9 $x^{i+1} := x^i + \lambda_i d^i$
10 $i := i + 1$
11 end while
13
Output: $x^1, x^2, \dots$
```

### Remark 6.7

- (A) 6.4 does not specify the step size $\lambda_i$ in line 8. In practice, a step size formula as $\lambda_i = \frac{1}{i}$ for $i \in \mathbb{N}$ is used, or one works with constant step sizes such as 0.1, 0.01, or 0.001. A good choice of $\lambda_i$ actually depends on the optimization problem under consideration.

- (B) The previous algorithm only works with one gradient $\nabla f_k(x^i)$ at an iteration $x^i$ and ignores the other gradients $\nabla f_j(x^i)$ for $j \in \{1,\dots,p\} \setminus \{k\}$. Because of this lack of information, one cannot assume that the iteration direction used is particularly good. However, one can easily see the descent of the objective function continuous after several iterations.

Next, we could cite by Garridos and Gover [42] on the convergence rate of the stochastic gradient method under appropriate assumptions.

**Theorem 6.4 (Convergence of the Stochastic Gradient Method [42], Theorem 5.7])** Let the functions $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$ with $n, p$ be differentiable, convex, and bounded from below, and let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be defined by (6.17). For each $j \in \{1,\dots,p\}$, the gradients $\nabla f_j$ be Lipschitz continuous, i.e., there exists Lipschitz constant $L_j > 0$ such that

$$|\nabla f_j(x) - \nabla f_j(y)\|_2 \le L_j\|x - y\|_2 \text{ for all } x, y \in \mathbb{R}^n.$$

The objective function $f$ is $\mu$-strongly convex for $\mu > 0$ (Definition 1.25). Furthermore, let $(x^i)_{i\in\mathbb{N}}$ be a sequence generated by Algorithm 6.4 with a constant step size $\lambda$ ($\lambda_i = \lambda$ for all $i \in \mathbb{N}$) satisfying $0 < \lambda < \min\{\frac{1}{\mu}, L_{\max}\}$ with $L_{\max} := \max_{1\le j\le p} L_j$.

Then, for each $i \in \mathbb{N}$, it is

```
E\left(\|x^i - \bar{x}^i\|_2^2\right) \leq (1-\lambda\mu)^i\|x^0 - \bar{x}^i\|_2^2 + \frac{2\lambda}{\mu}V(G),
```

where $\bar{x} \in \mathbb{R}^n$ is the unique minimal solution of the optimization problem (6.6) and $V(G)$ denotes the variance of a discrete $\mathbb{R}^n$-valued random element $G$, which is uniformly distributed and takes on the gradients $\nabla f_i(\bar{x}), \dots, \nabla f_p(\bar{x}).$.

In this theorem, the variance $V(G)$ is also called gradient noise [42], Definition 4.16. For convergence results of the stochastic gradient method, we refer to the handbook [42].

Next, we apply the stochastic gradient method to the optimization problem from Example 6.3.

**Example 6.5** As in 6.3, consider the unconstrained optimization problem (6.14) with the objective function $f: \mathbb{R}^n \to \mathbb{R}$ given by

```
$f(x) = \sum_{j=1}^n \frac{j}{10}(e^{x_j} - x_j - 1)$
=: \sum_{j=1}^n \frac{j}{10}(e^{x_j} - x_j - 1) \text{ for all } x := (x_1, \dots, x_n) \in \mathbb{R}^n$
=:f_j(x)$
```

Here we have $p := n$, and the functions $f_j: \mathbb{R}^n \to \mathbb{R}$ (with $j \in \{1, \dots, n\}$) are simple in this. For $n=10$, 6.15 shows the values of the objective function $f$ at the iteration points $x^{1000}, \dots, x^{2000}$ obtained with $b=1$. As in 6.3, the starting point is set to $x^0 := (1, \dots, 1)$. Since the index $k$ (line 6 of Algorithm 6.4) is uniformly distributed in $[1, \dots, p]$, we cannot expect an iteration path to remain unchanged. The high number of iterations results from constant step size $\lambda := 0.01$ (at each iteration $i \in \mathbb{N}$). It is also interesting to compare 6.15 with Figs. 13 and 14. A disadvantage of the stochastic gradient method is that one gradient $\nabla f_k$ is used. This drawback can be reduced by selecting several gradients at each iteration $f_1, \dots, f_p$. This leads to a combination of gradient descent method and the stochastic gradient method, which is called *mini-batch gradient method*.

### Algorithm 6.5 (Mini-batch gradient method) [42, Algorithm 6.1]

Input: $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$, batch size $b \in \{1, \dots, p\}$, maximal iteration number $i_{\max}$.

```
i := 0 // initialization
while $i \le i_{max}$ do
  $B_i := \{1, \dots, p\}$ // sampled uniformly among sets of size b
  $d^i := -\sum_{k \in B_i} \nabla f_k(x^i)$ // iteration direction
  choose $\lambda_i > 0$ // step size
  $x^{i+1} := x^i + \lambda_i d^i$
  i := i + 1
end
```

### Remark 6.8 ([42, Algorithm 6.2 and Note])

Each batch $B_i$ in line 6 of Algorithm 6.5 is sampled with probability

$$\frac{b!(p-b)!}{p!\binom{p}{b}}$$

In line 7 of the mini-batch gradient method, the computation of gradients $\nabla f_k(x^i)$, with $k \in B_i$, can be accelerated on parallel computer architectures.

Next, for the mini-batch gradient method, we cite a convergence result by Garridos and Gower [42].

**Theorem 6.5 (Convergence of the Mini-batch Stochastic Gradient Method) [42, Algorithm 6.11])** Let the functions $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$ with $n, p \in \mathbb{N}$ and $p > 1$ be differentiable, convex, and bounded from below, let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be defined by (6.17). For each $j \in \{1, \dots, p\}$, let the gradients $\nabla f_j$ be Lipschitz continuous, i.e., there exists Lipschitz constant $L_j > 0$ such that

> $\|\nabla f_j(y) - \nabla f_j(x)\|_2 \le L_j \|x - y\|_2 \text{ for all } x, y \in \mathbb{R}^n.$$

The objective function $f$ is $\mu$-strongly convex for $\mu > 0$ (Definition 1.25). Furthermore, let $(x^i)_{i \in \mathbb{N}}$ be a sequence generated by Algorithm 6.5 with a constant step size $\lambda$ (i.e., $\lambda_i = \lambda$ for all $i \in \mathbb{N}$) satisfying $0 < \lambda < \min \{\frac{1}{\mu}, \sum L_j\}$ with

$L_b := \frac{p(b-1)}{n} \sum_{j=1}^b L_j + (p-b) \max L_j$.
