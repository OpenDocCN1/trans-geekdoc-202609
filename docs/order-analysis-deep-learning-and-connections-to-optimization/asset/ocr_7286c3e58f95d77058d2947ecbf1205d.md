# 3.1 Optimality Conditions for a Unique Minimal Solution

**Example 3.1** ([35, Example 3.11]) We investigate the discrete-continuous optimization problem

```
$$\min \left(x_d - \frac{1}{2}\right)^2 + x_c^2$$
\text{subject to the constraint}
$$-x_d + \frac{1}{4} \le 0\n x = (x_d, x_c) \in \hat{S} := \mathbb{Z} \times \mathbb{R}.$$
```

It is evident that $\tilde{x} := (1,0)^T$ is the unique minimal solution of problem (3.6). By Remark 3.2 (c), the problem (3.5) can be written as

```
$$\max \left\ \left(x_d - \frac{1}{2}\right)^2 + x_c^2, -x_d + \frac{3}{4} \right\$\nn= \varphi(x_d, x_c).$$
```

For an arbitrary $x_c \in \mathbb{R}$, we define

```
$\varphi(-2, x_c) = \max \left[6 + x_c^2, \frac{11}{4}\right\] = 6 + x_c^2 > 0$\n$\varphi(-1, x_c) = \max \left[2 + x_c^2, \frac{7}{4}\right\] = 2 + x_c^2 > 0$\n$\varphi(0, x_c) = \max \left[x_c^2, \frac{3}{4}\right\] > 0$\n$\varphi(1, x_c) = \max \left[x_c^2, \frac{1}{4}\right\] = x_c^2 > 0$ (for $x_c \neq 0$)\n$\varphi(2, x_c) = \max \left[2 + x_c^2, \frac{5}{4}\right\] = 2 + x_c^2 > 0$\n$\varphi(3, x_c) = \max \left[6 + x_c^2, \frac{9}{4}\right\] = 6 + x_c^2 > 0$.
```

and so on. Consequently, $\tilde{x}$ is a unique minimal solution of the unconstrained problem (3.7), and by Theorem 3.1 (a), it is also a unique minimal solution of the discrete-continuous optimization problem (3.6).

Next, we adapt the theory of subdifferentials (compare Definition 1.24) to the case of unique minimal solutions without assuming convexity.

**Definition 3.1** ([35, Definition 3.12!]) Let $X$ be a real line space, and let $\hat{S}$ be a nonempty subset of $X$. Let $\varphi:\hat{S} \to \mathbb{R}$ be a given function. For an arbitrary $\tilde{x} \in \hat{S}$, the set

```
$\partial_\varphi(\tilde{x}) := \left{\ell \in \hat{S} \middle| \ \varphi(x) > \varphi(\tilde{x}) + \ell(x - \tilde{x}) \text{ for all } \x \in \hat{S} \text{ with } \x \neq \tilde{x}\}\right\$.
```

is the strict subdifferential of $\varphi$ at $\tilde{x}$.
