6.4 illustrates this activation function. The range of the function $ho$ equals the open interval $(0, 1)$. If one prefers a range $(-1, 1)$, then one can consider the modified function given by

```
$2\rho(x) - 1 = \frac{1-e^{-x}}{1+e^{-x}} \text{ for all } x \in \mathbb{R}.$
```

The function $ho$ is a smooth function with the first derivative

```
$$\rho'(x) := \frac{e^{-x}}{(1+e^{-x})^2} \text{ for all } x \in \mathbb{R}$
```

(see 6.4). The sigmoid function has nice mathematical properties but is rarely used in practice today. One of the reasons is that the derivative outside of $x=0$ is smaller than $rac{1}{4}$.

# 6.4.2 tanh Function

The hyperbolic tangent is also used as an activation function. It is obvious it can also be written in the form

```
$tanh.x = \frac{e^x-e^{-x}}{e^x+e^{-x}} = \frac{1-e^{-2x}}{1+e^{-2x}} = 2\rho(2x)-1 \text{ for all } x \in \mathbb{R},$
```

$ho$ denotes the sigmoid function. Figure 6.5 visualizes the tanh activation function. Its range equals $(-1, 1)$. This activation function is smooth with the first derivative

```
$$\tanh'(x) = (\frac{-2}{1+e^{2x}} + 1)' = \frac{4e^{2x}}{(1+e^{2x})^2} \text{ for all } x \in \mathbb{R}.$
```

Although there is a close relationship between sigmoid and tanh functions, the tanh function is preferred in practice nowadays.
