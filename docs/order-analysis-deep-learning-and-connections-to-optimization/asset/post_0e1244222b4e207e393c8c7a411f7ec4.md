
## 5 Application in Set Optimization

![](img/e4a2e491dbba0d9f71abf293f149cd5b_94_0.png)

Fig. 5.2 Family $\mathcal{F}$ of simple sets in $\mathbb{R}^2$ together with the partial order $\mathbb{R}^2_+$

We now turn our attention to problems of set optimization. Based on the set less order relation in a real linear space $Y$, we consider a family $\mathcal{F}$ of nonempty subsets of $Y$, and we investigate minimal sets of $\mathcal{F}$.

**Definition 5.2** Let $C$ be a convex cone in a real linear space $Y$, and let $\mathcal{F}$ be a family of nonempty subsets of $Y$. A $\tilde{A} \in \mathcal{F}$ is called *minimal set* of $\mathcal{F}$ iff

$A \preceq_s A, A \in \mathcal{F} \Longrightarrow \tilde{A} \preceq_s A.$

**Example 5.2** Let $Y := \mathbb{R}^2$ and $C := \mathbb{R}^2_+$ be chosen. Let $\mathcal{F} := \{A_1, \dots, A_5\}$ denote a family of sets as illustrated in Fig. 5.2. In this case, we have the only set inequalities $A_2 \preceq_s A_1, A_3 \preceq_s A_1, A_4 \preceq_s A_5$, and then it is evident that $A_2, A_3$, and $A_4$ are the only minimal sets of $\mathcal{F}$.

**Remark 5.2** For the following investigations, we introduce an abbreviation for the set of all minimal and maximal elements of a set, respectively. Here, we use an extension of the notion of minimality given in Definition 4.1. Let $C$ be a convex cone in a real linear space $Y$, and let $\emptyset \neq A \subseteq Y$ be given. Let $\preceq_c$ denote the preorder induced by $C$. The set

$\min(A) := \{ \tilde{a} \in A \mid a \preceq_c \tilde{a}, a \in A \Longrightarrow \tilde{a} \preceq_c a \}$

denotes the set of minimal elements of $A$, and the set

$\max(A) := \{ \tilde{a} \in A \mid \tilde{a} \preceq_c a, a \in A \Longrightarrow a \preceq_c \tilde{a} \}$

is called the set of maximal elements of $A$. Of course, if the convex cone $C$ is pointed, then

$\min(A) = \{ a \in A \mid a \preceq_c A, a \in A \Longrightarrow a = \bar{a} \}$ (as given in Definition 4.1) and

$\max(A) = \{a \in A \mid \bar{a} \leq c, a \in A \Rightarrow a = \bar{a}\}$

With the following proposition, we investigate the question: What does it mean in Definition 5.2 if some set $A \in \mathcal{F}$ the two inequalities $A \lesssim_s \tilde{A}$ and $\tilde{A} \lesssim_s A$ hold?

**Proposition 5.4 ([73, Proposition 3.1])** Let $C$ be a convex cone in a real linear space $Y$, and let $\mathcal{F}$ be a family of nonempty subsets of $Y$, for which the set of minimal elements and the set of maximal elements are nonempty. For every $A \in \mathcal{F}$, let the equations

$A + C = \min(A) + C$ and $A - C = \max(A) - C$

satisfied. For some $A \in \mathcal{F}$, we then have

$\tilde{A}$ minimal set of $F \iff \min(\tilde{A})$ and $\max(A) = \max(\tilde{A})$ for all $A \in \mathcal{F}$ with $A \lesssim_s \tilde{A}$.

**Proof** for some $A \in \mathcal{F}$ and an arbitrary $A \in \mathcal{F}$, it holds by definition

$A \lesssim_s \tilde{A}$ and $\tilde{A} \lesssim_s A \iff \tilde{A}+C \subseteq A+C, A-C \subseteq \tilde{A}-C, \tilde{A} \subseteq A-C$.

By Jahn [71, Lemma 2.4], this is equivalent to the following

$\tilde{A}+C \subseteq A+C, A-C \subseteq \tilde{A}-C, A+C \subseteq \tilde{A}+C, \tilde{A}-C \subseteq A-C$

again equivalent to

$\tilde{A}+C = A+C, \tilde{A}-C = A-C$.

By the equalities (5.2), it can be written as

$\min(A)+C = \min(A)+C, \max(A)-C = \max(A)-C$.

The first equality implies $\min(A) \subseteq \min(\tilde{A})+C$, which means

$\tilde{a} \in \min(\tilde{A}) \exists a \in \min(A), c \in C : \tilde{a} = a+c$.

Let $\tilde{a} \in \min(\tilde{A})$ be arbitrarily chosen. Then we have $\tilde{a} = a+c$ for some $a \in \min(A)$ and some $c \in C$. Since the first equality in (5.3) also implies $\min(A) \subseteq \min(\tilde{A})+C$, there are $\hat{a} \in \min(\tilde{A})$ and $\hat{c} \in C$ with $\tilde{a} = a+\hat{c}$. Hence, we get $\tilde{a} = a+c = \hat{a}+\hat{c}$.

## 5.1 Fixed Order Structure

Fig. 5.3 Illustration of the set equalities (5.2) [73]![](img/e4a2e491dbba0d9f71abf293f149cd5b_96.png) Because of $\bar{a}, \hat{a} \in \min(\hat{A})$, we obtain $\hat{c} + c = 0$, i.e., $c = -\hat{a}$. Since $C$ is pointed, we obtain $c \in C \cap (-C) = \{0\}$. Consequently, we have $\hat{a} = a$ and thereby $\min(\hat{A}) \subseteq \mathbb{R}^2$. By renaming, we also get $\min(A) \subseteq \min(A)$, and we have $\min(A) = \min(A)$. The equality $\max(A) = \max(A)$ can be proved in analogy. The $\rightarrow$ part of the assertion follows with the definition of minimality. The $\leftarrow$ part of the assertion is a simple consequence of the equalities (5.3). Note that the set equalities (5.2) are a well-known assumption in vector optimization that can also hold for certain nonconvex sets (see Fig. 5.3). For $Y := \mathbb{R}^2, C := \mathbb{R}^2$ and given in Fig. 5.3, we have $A + C = \min(A) + C$ and $A - C = \max(A) - C$. But the set equalities (5.2) do not hold in general; for instance, if we choose $Y := \mathbb{R}^2, C := \mathbb{R}^2$, $A = \{(y_1, y_2) \in \mathbb{R}^2 \mid y_1^2 + y_2^2 < 1 \cup (-1, 0)\}$ (see Fig. 5.4), we have $\min(A) + C = (-1, 0)$, and we get $\min(A) + C = \{(y_1, y_2) \in \mathbb{R}^2 \mid y_1 \geq -1, y_2 \geq 0\} \neq A + C$, i.e., the first equality in (5.2) is not satisfied. For the formulation of a proper optimality condition without using the set relation, we combine Proposition 5.4 with Proposition 5.1.

**Corollary 5 ([73, Corollary 5])** Let $C$ be a pointed convex cone in a real linear space $Y$, and let $\psi$ be a $-C$ representing functional. $\mathcal{F}$ be a family of nonempty subsets of $Y$, for which the set of minimal elements and the set of maximal elements are nonempty and the set equalities (5.2).

## 5.2 Variable Order Structure

Fig. 5.4 Set $A$ given by (5.4) and $A + \mathbb{R}^2_+$![](img/e4a2e491dbba0d9f71abf293f149cd5b_97_0.png) Moreover, let the equalities $\sup_{a \in A} \psi(a-b) = \max_{a \in A} \psi(a-b)$ and $\inf_{b \in B} \psi(a-b) = \max_{b \in B} \psi(a-b)$ be satisfied for all $A, B \in \mathcal{F}$. For some $\tilde{A} \in \mathcal{F}$, we have $\tilde{A}$ minimal set of $\mathcal{F} \iff \min(A) = \min(\tilde{A})$ and $\max(A) = \max(\tilde{A})$ for all $A \in \mathcal{F}$ with $\max \left\{\max_{a \in A} \psi(a-\tilde{a}), \max_{a \in \tilde{A}} \psi(\tilde{a}-a)\right\} \le 0$.

**Proof** It follows from Proposition 5.1 that the inequality $A \preceq_s \tilde{A}$ (for all $A, \tilde{A} \in \mathcal{F}$) can be rewritten as $\max \left\{\max_{a \in A} \psi(a-\tilde{a}), \max_{a \in \tilde{A}} \psi(\tilde{a}-a)\right\} \le 0$. Hence, the assertion is an immediate consequence of Proposition 5.4. Note that the optimality condition in Corollary 5.1 is not simple to check. For instance, if the family $\mathcal{F}$ consists of finitely many sets, one has to solve whether $\min(A) = \min(\tilde{A})$ and $\max(A) = \max(\tilde{A})$.

## 5 Application in Set Optimization

We begin with an extension of the set less order relation to the case of variable order structure.

**Definition 5.3 ([74, Definition 5.3])** Let $C$ be a pointed convex cone in a real linear space $Y$, and let $\psi$ be a $-C$ representing functional. For nonempty subsets $A, B \subseteq Y$, the set less variable order relation defined by $A \le_{S,K} B$ is defined by $A \le_{S,K} B \iff B \subseteq \bigcup_{a \in A} (\{a\} + C)$ and $A \subseteq \bigcup_{b \in B} (\{b\} - C)$.

Set optimization problems with variable order structure are even more complicated than those with fixed order. Nonetheless, $-C$ representing functionals seem to be an appropriate tool for the investigation of these types of problems.
