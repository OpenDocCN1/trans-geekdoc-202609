# 2.5 Directional Derivative

For the proof of the converse inequality, choose an arbitrary $\lambda > 0$. Then there exists $x_\lambda$ with $\|x_\lambda\|_2 = 1$ is so that

```
$x_\lambda^\inter{T}(	ilde{A} + \lambda H)x_\lambda = \max_{\||x\|_2=1} x^\inter{T}(	ilde{A} + \lambda H)x.$
```

For arbitrary $x \in X(\tilde{A})$ we obtain

```
$\max_{\|x\|_2=1} x^\inter{T}(	ilde{A} + \lambda H)x - \max_{\|x\|_2=1} x^\inter{T}\tilde{A} \geq x^\inter{T}(	ilde{A} + \lambda H)\tilde{x} - \tilde{x}^\inter{T}\tilde{A}\n= \lambda\tilde{x}^\inter{T}H\tilde{x}$ for all $\lambda > 0$
```

and with

```
$\max_{\|x\|_2=1} x^\inter{T}\tilde{A}x + \lambda \max_{\|x\|_2=1} x^\inter{T}Hx - \max_{\|x\|_2=1} x^\inter{T}\tilde{A}x\n= \lambda \max_{\|x\|_2=1} x^\inter{T}Hx$ for all $\lambda > 0$,
```

we conclude for some $\alpha \geq 0$

```
$|\max_{\|x\|_2=1} x^\inter{T}(\tilde{A} + \lambda H)x - \max_{\|x\|_2=1} x^\inter{T}\tilde{A}x| \leq \alpha\lambda$ for all $\lambda > 0$.
```

Hence, we have

```
$\lim_{\lambda\to0_+} x_\lambda^\inter{T}(\tilde{A} + \lambda H)x_\lambda = \max_{\|x\|_2=1} x^\inter{T}\tilde{x}$.
```

So, there is a sequence $(\lambda_k)_{k\in N}$ of positive real numbers converging to 0 with $\lim_{k\to\infty} x_{\lambda_k} = \tilde{x} \in X(\tilde{A})$. And we conclude

```
$$\psi'(\tilde{A}) = \lim_{k\to\infty} \frac{1}{\lambda_k} (\max_{\|x\|_2=1} x^\inter{T}(\tilde{A} + \lambda_k H)x - \max_{\|x\|_2=1} x^\inter{T}\tilde{A}x)\n=x_{\lambda_k}^\inter{T}Hx_{\lambda_k}\n\leq \lim_{k\to\infty} \frac{1}{\lambda_k} (x_{\lambda_k}^\inter{T}\tilde{A}x_{\lambda_k} + \lambda_k x_{\lambda_k}^\inter{T}Hx_{\lambda_k} - x_{\lambda_k}^\inter{T}\tilde{A}x_{\lambda_k})\n= \lim_{k\to\infty} x_{\lambda_k}^\inter{T}Hx_{\lambda_k}\n= \tilde{x}^\inter{T}H\tilde{x}\n\leq \max_{x\in X(\tilde{A})} x^\inter{T}Hx$. (2.10)
```
