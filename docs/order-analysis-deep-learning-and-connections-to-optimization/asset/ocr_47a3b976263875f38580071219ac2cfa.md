(a) The special class $C_r(X)$ is defined by

```
$C_r(X) := \{A \in \overline{P}(X) \mid A = \{x \in X \setminus [0_X] \mid 0 < ||||x|| \le \varphi_A(\frac{x}{||x||})\} \cup \{0_X\}$
```

for a given functional $\varphi_A: S(X) \to \mathbb{R}_+$, which depends on A.

+   (b) Every set $A \in C_r(X)$ is called radial functional of $A$.

Note that the radial functional is uniquely defined by the representation in Definition 7.5 (a). Thus, the class $C_r(X)$ consists of sets $A \in \overline{P}(X)$ with a boundary defined by such a set. The radial functional $\varphi_A$ as given in Definition 7.5 (a). Figure 7.2 illustrates such a set. These sets do not have to be convex. By definition, one can also try to shift a set $A \in \overline{P}(X)$ by $x$ so that the shifted set $A-\{x\}$ possibly has the desired properties, i.e., $A-\{x\} \in C_r(X)$.\nSets in the class $C_r(X)$ have special structures.

**Proposition 7.4** Let $(X, ||\cdot||)$ be a real normed space. Every set $A \in C_r(X)$ has the following properties:

+   (a) $0_X \in \text{core}(A)$ if its radial functional inequality $\varphi_A(x) > 0$ is satisfied for all $x \in S(X)$.\n(b) $A$ is starshaped with respect to $0_X$.

Proof

+   Let $x \in X \setminus [0_X]$ be arbitrarily chosen. Then we obtain $\frac{x}{||x||} \in S(X)$, and by assumption, we conclude $\varphi_A(\frac{x}{||x||}) > 0$. So there is some $\lambda > 0$ with

```
$0 < ||\lambda x|| \le \varphi_A(\frac{x}{||x||}) = \varphi_A(\frac{\lambda x}{||\lambda x||}) \quad (7.9)$
```
