**Remark 1.1** Let $C$ be a convex cone in a real linear space $Y$. By Proposition 1.2 (a), we obtain for a preorder $\le$ on $Y$ and for all $y^1, y^2 \in Y$

$y^1 \le y^2 \iff y^2 - y^1 \in C$.

If, in addition, $C$ is pointed, this implication also holds for a partial order by Proposition 1.2 (b).

**Definition 1.10** A convex cone characterizing the preorder on a real linear space is called a *preorder cone* (or a *positive cone*). A pointed convex cone characterizing the partial order on a real linear space is called a *partial order cone*

**Example 1.4**

+   (a) For the natural partial order given in Example 1.2 (a), the partial order is

```
$C := \{y \in \mathbb{R}^n \mid y_i \ge 0 \text{ for all } i \in \{1, \dots, n\} = \mathbb{R}^n_+$
```

(compare Fig. 1.9).

+   (b) In Example 1.2 (b), the partial order can be written as

```
$C := \{y \in C[a, b] \mid y(t) \ge 0 \text{ for all } t \in [a, b]\}$
```

(compare Fig. 1.10).
