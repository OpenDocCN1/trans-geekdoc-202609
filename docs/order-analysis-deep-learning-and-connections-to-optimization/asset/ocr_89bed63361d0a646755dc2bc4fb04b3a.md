Example 1.5 For a given $n \in \mathbb{N}$, consider the real linear space $S^n$ of real symmetric $(n)$ matrices with the inner product $\langle \cdot, \cdot angle$ given by

```
$\langle A, B \rangle := \text{trace}(A \cdot B) \text{ for all } A, B \in S^n$.
```

Then $(S^n, \langle \cdot, \cdot angle)$ is a finite-dimensional Hilbert space. A partial order on $S^n$ is induced by the convex cone

```
$S^_+ := \{A \in S^n \mid A \text{ is positive semidefinite}\}$.
```

This partial order is called $Löwner$ cone. However, there is also convex cone of interest in applications. The convex cone is

```
$C^n := \{A \in S^n \mid x^\{T}Ax \geq 0 \text{ for all } x \in \mathbb{R}^n_+\}$.
```

is called $positive$ cone.

Next, we recall the notions of a directional derivative and a subdifferential.

# Definition 1.23 Let $S$ be a nonempty subset of a real linear space $X$, and $f : S \to \mathbb{R}$ be a convex function. For two elements $	ilde{x} \in S$ and $h \in X$ the mathematical

```
$f'(\tilde{x})(h) := \lim_{\lambda \to 0_+} f(\tilde{x} + \lambda h) - f(\tilde{x})$.
```

exists, $f'(\tilde{x})(h)$ is called the directional derivative of $f$ at $	ilde{x}$ in the direction $h$. If this limit exists for all $h \in X$, then $f$ is called directionally differentiable at $	ilde{x}$ (see Fig. 1.12).

Notice in Definition 1.23 that for arbitrary null sequences $(\lambda_n)_{n \in \mathbb{N}}$ with $\lambda_n > 0$ for all $n \in \mathbb{N}$, one has the additional property $\tilde{x} + \lambda_nh \in S$ for all $n \in \mathbb{N}$. For instance, this property is fulfilled if $S$ equals the whole space $X$.
