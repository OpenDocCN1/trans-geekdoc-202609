# 3 Application in Nonlinear Optimization

Remark **3.1** By Jahn [72, Definition 8.1], a nonempty subset $\hat{S}_d$ of a linear space $X_d$ is called *discrete* if its elements are either finite or infinite. To be more concrete, a discrete set $\hat{S}_d \subseteq X_d$ can be written as $\hat{S}_d = \{x_d^i\}_{i\in N}$ for $N := \{1, 2, \dots, n\}$ ($n \in \mathbb{N}$) or $N := \mathbb{N}$ with elements $x_d^1, x_d^2, \dots \in X_d$. A discrete subset belonging to some nonempty subset $\hat{S}$ of a real linear space $X$. Next, we set $X := X_d \times X_c$ and $\hat{S} := \hat{S}_d \times \hat{S}_c$. **3.1.** in Assumption the general optimization problem (3.1) can be written

```
$\min f(x_d, x_c)\nsubject to the constraint\ng(x_d, x_c) \in -C\n(x_d, x_c) \in \hat{S}$
```

This is a discrete-continuous nonlinear optimization problem. The subscripts $d$ and $c$ clarify the discrete-continuous structure, i.e., $x_d$ and $x_c$ are the continuous variables belonging to the $\hat{S}_d \subseteq X_d$ and $\hat{S}_c \subseteq X_c$, respectively. Thus, Assumption 3.1 also covers discrete-continuous nonlinear optimization problems with a general inequality constraint.

First, we select a basic simplicity condition.

**Lemma 3.1** ([35, Lemma 3.1]) *Assumption 3.1* be satisfied, and let some $\tilde{x} \in \hat{S}$ be given.*

(a) the vector $\tilde{x} \times (-C)$ is a unique minimal solution of problem (3.1) if and only if

```
$[-R_{++} \times (-C)] \cap \left\\{ \frac{f(x) - f(\tilde{x})}{g(x)} \in R \times Y \middle| \ x \in \tilde{S}, \ x \neq \tilde{x} \right\right\} = \emptyset. \quad (3.2)$
```

(b) the vector $\tilde{x}$ is a minimal solution of problem (3.1) if and only if

```
$[-R_{++} \times (-C)] \cap \left\\{ \frac{f(x) - f(\tilde{x})}{g(x)} \in R \times Y \middle| \ x \in \hat{S} \right\right\} = \emptyset$.
```

$R_{++}$ denotes the set of all positive real numbers.

# Proof

+   (a) (i) let $\tilde{x}$ be a unique minimal solution of the nonlinear optimization problem (3.1). We then have for all $x \in \hat{S}$ with $x \in S$ and $x \neq \tilde{x}$

```
$f(x) - f(\tilde{x}) > 0$ and $g(x) \in -C$.
```

Moreover, we get for all $x \in \hat{S}$ with $x \neq S$ that $g(x) \notin -C$. Hence, the condition (3.2) is fulfilled.
