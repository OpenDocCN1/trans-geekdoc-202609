**Definition 1.5** Let $S$ be a nonempty subset of a real space $Y$. The intersection of all convex subsets of $Y$ that contain $S$ is called the *convex hull* of $S$ and is denoted $conv(S)$.

**Definition 1.6** Let $S$ be a nonempty subset of a real space $Y$.

+   (a) The set

```
core(S) := {\bar{y} \in S \| \forall y \in Y \exists \lambda > 0 : \bar{y\|+\lambda y \in S \forall \lambda \in [0,\tilde{\lambda}]].
```

called the *algebraic interior* (or the *core*) of $S$ (see Fig. 1.4).

+   (b) An element $\bar{y} \in Y$ is *linearly accessible* from $S$ if there is an $y \in S$, $y \neq \bar{y}$, with the property

```
\lambda y + (1 - \lambda)\bar{y} \in S$ for all $\lambda \in (0, 1).
```
