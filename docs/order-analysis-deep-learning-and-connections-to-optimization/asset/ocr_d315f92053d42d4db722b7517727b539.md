# 2.9 Separation Results

By definition, $-C$ representing functionals are qualified for simple separation results.

**Proposition 2.17** ([74, Proposition 3.11]) Let Assumption 2.1 be satisfied, let $\psi$ be a $-C$ representing functional, and let $S$ be a nonempty subset of $Y$. Then

+   (a) $S \cap C = \emptyset \iff \psi(-y) > 0 \ \forall y \in S$.$
(b) for an arbitrary $	ilde{y} \in S \cap C$:$
$S \cap C = \{\tilde{y}\} \iff \psi(-y) > 0 \ \forall y \in S, y \neq \tilde{y}$.

**Proof**

(a) The assertion is a direct consequence of the definition of the functional because

> $S \cap C = \emptyset \Rightarrow -S \cap (-C) = \emptyset \Rightarrow \psi(y) > 0 \ \forall y \in -S$.

which leads to the assertion.

(b) With the equivalence

> $S \cap C = \{\tilde{y}\} \Leftrightarrow (S\setminus{\tilde{y}\}) \cap C = \emptyset$,

the assertion follows from part (a).

**Proposition 2.18** ([74, Proposition 3.12]) Let $C_1$ and $C_2$ be convex cones in a real linear space $Y$ with $C_1, C_2 \neq \{0_Y\}$, and let $\psi_1$ and $\psi_2$ be $-C_1$ and $-C_2$ representing functionals, respectively.

```
$C_1 \cap C_2 = \{0_Y\} \Leftrightarrow \psi_2(-C_1) > 0 \ \forall c_1 \in C_1\setminus{\{0_Y\}$$
\Leftrightarrow \psi_1(-C_2) > 0 \ \forall c_2 \in C_2\setminus{\{0_Y\}$$
\Leftrightarrow (y \neq 0_Y, \psi_1(-y) \le 0 \Rightarrow \psi_2(-y) > 0)$$
\Leftrightarrow (y \neq 0_Y, \psi_2(-y) \le 0 \Rightarrow \psi_1(-y) > 0$.
```
