
## 7.5 Specialization to Interval-Valued Inputs

Interval variables are known from optimization with uncertain data. They have the advantage that only a lower and upper bound of the expected data is needed. They can be used if the distribution of the data is unknown. Here, we consider closed and bounded intervals in $\mathbb{R}$.

**Definition 7.9** The special class $C_{int}(\mathbb{R})$ of closed bounded intervals in $\mathbb{R}$ is defined by

$$
C_{int}(\mathbb{R}) := \{[a, \overline{a}] \mid -\infty < a \leq \overline{a} < \infty\}$
$$

Figure 7.3 illustrates a feedforward network of artificial neurons with valued inputs and interval-valued outputs. Note that the numerical calculations in the artificial neurons are to be carried out with interval arithmetic. The formula (7.13) in the following lemma applies to the calculation with intervals in artificial neurons.

**Lemma 7.1** Let $n \in \mathbb{N}$ be a given number. For arbitrary inputs $[x_i, \overline{x}_i] \in C_{int}(\mathbb{R})$ with $i \in (1,\dots,n)$, an arbitrary bias interval $[b, \overline{b}] \in C_{int}(\mathbb{R})$, and arbitrary weights $w_1,\dots,w_n \in \mathbb{R}$, we obtain

$$
\sum_{i=1}^n w_i[x_i, \overline{x}_i] + [b, \overline{b}] = [\sum_{i \in L_+} w_i x_i + \sum_{i \in L_-} w_i \overline{x}_i + b, \sum_{i \in L_+} w_i \overline{x}_i + \sum_{i \in L_-} w_i x_i + \overline{b}] \quad (7.13)
$$

$I_- := \{i \in \{1, \dots, n\} \mid w_i < 0\}$

**Proof** Recall that for two arbitrary intervals $[x_i, \overline{x}_i], [x_j, \overline{x}_j] \in C_{\text{int}}(\mathbb{R})$ with $i, j \in \{1, \dots, n\}$ the addition is defined

$$
[x_i, \overline{x}_i] + [x_j, \overline{x}_j] = [x_i + x_j, \overline{x}_i + \overline{x}_j]
$$

and for some weight $w_i \in \mathbb{R}$ we have

$$
\begin{cases} [w_i x_i, w_i \overline{x}_i] & \text{if } w_i > 0 \\ [w_i \overline{x}_i, w_i x_i] & \text{if } w_i < 0 \\ [0, 0] & \text{if } w_i = 0 \end{cases}
$$

With these formulas, we can write

$$
\sum_{i=1}^n w_i [x_i, \overline{x}_i] = \sum_{i \in I_+} w_i [x_i, \overline{x}_i] + \sum_{i \in I_-} w_i [\overline{x}_i, x_i]
$$

which implies the equality (7.13).

The following proposition provides an explicit formula for the activation map $\mathcal{F}$:

**Proposition 7.6** Let $[a, \overline{a}] \in C_{\text{int}}(\mathbb{R})$ be arbitrarily chosen. Then we have for the activation map $\mathcal{F}$:

$$
\mathcal{F}([a, \overline{a}]) = \frac{1}{1 + \max(a, \overline{a})} [a, \overline{a}] \quad (7.14)
$$

**Proof** For the interval $[a, \overline{a}] \in C_{\text{int}}(\mathbb{R})$, we make the following case distinction:

- a) $a \le \overline{a} \le 0$. In this case, with Definition 7.3, we obtain the assertion.
- b) $a \leq 0 \leq \overline{a}$. Now, we have from which the assertion follows.
- c) $0 \leq a \leq \overline{a}$. Finally, we obtain the assertion.

Because of the max term in the equality (7.14), the activation map $\mathcal{F}$ (as a function of the two variables $a$ and $\overline{a}$) is not differentiable everywhere. Non-differentiability exists for all $a$ and $\overline{a}$ with $a = \overline{a}$. Note that the function $\varrho$ given in Definition 6.2 is differentiable.

**Remark 7.1** Let the function $\eta : \mathbb{R}_{++}^{+} \to \mathbb{R}$ with $\eta(a, \overline{a}) = \max(a, \overline{a})$ for all $a, \overline{a} \in \mathbb{R}_{++}$ be. By Proposition 7.1, the function $\eta$ has the directional derivative at arbitrary $(a, \overline{a}) \in \mathbb{R}_{++}^2$:

$$
\eta'(a, \overline{a})(h) = \max_{i \in I(a, \overline{a})} \{h_i\} \text{ for all } h = (h_1, h_2) \in \mathbb{R}^2
$$

with the index set

$$
I(a, \overline{a}) := \{1 \mid a = \overline{a}\} \cup \{2 \mid \overline{a} = \eta(a, \overline{a})\}
$$

Consequently, for intervals $[a, \overline{a}] \in C_{int}(\mathbb{R})$ with $a > 0$, the differentiability of the max term in (7.14) holds.
