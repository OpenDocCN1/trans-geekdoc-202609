**Theorem 4.3** *Let Assumption 4.1 be satisfied. Furthermore, let $\psi$ be a $-C$ representing sublinear functional, and let there be some $	ilde{y} \in Y$ with $\psi(	ilde{y}) < 0$. Then we have*

$\tilde{y}$ weakly minimal element of $T \iff \tilde{y}$ minimal solution of $\min_{y\in T} \psi(y - \tilde{y}).$

**Proof** By definition, $	ilde{y}$ is a weakly minimal element of the set $T$ iff the set Eq. (4.5) holds. By Theorem 2.1 and the assumption $\psi(\tilde{y}) < 0$, it follows that

> $$- \text{core}(C) = \text{core}(-C) = \{y \in Y \mid \psi(y) < 0\} \neq \emptyset,$$

and we conclude

${(\tilde{y}) - \text{core}(C)} \cap T = \{y \in T \mid y - \tilde{y} \in - \text{core}(C)\} = \{y \in T \mid \psi(y - \tilde{y}) < 0\$

Then the set Eq. (4.5) is equivalent to

> $$\psi(y - \tilde{y}) \geq 0 \text{ for all } y \in T. \quad (4.6)$

Since $\psi$ is sublinear, we obtain $\psi(0y)=0$. Consequently, the condition (4.6) is equivalent to

> $$\psi(y - \tilde{y}) \geq \psi(\tilde{y} - y) \text{ for all } y \in T.$

which means that $	ilde{y}$ is a minimal solution of the optimization problem $\min_{y\in T} \psi(y - \tilde{y})$, which completes the proof. $\square$
