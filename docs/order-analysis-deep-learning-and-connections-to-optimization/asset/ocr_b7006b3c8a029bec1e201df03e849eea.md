The union of $S$ and the set of linearly accessible elements from $S$ is called the *algebraic closure* of $S$, and it is denoted by

$\lin(S) := S \cup \{	ilde{y} \in Y \mid 	ilde{y} 	ext{ is linearly accessible from } S\}$.

In the case of $S = 	ext{lin}(S)$, the set $S$ is called *algebraically closed*.

**Definition 1.7** Let $Y$ be a real linear space. A functional $f : Y 	o \mathbb{R}$ is called sublinear if
