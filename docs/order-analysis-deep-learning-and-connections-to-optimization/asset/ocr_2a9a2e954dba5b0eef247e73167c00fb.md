By Remark 2.1, this functional is $-C$ representing. Furthermore, $\varphi_\ell$ is sublinear because

$\varphi_\ell(\lambda y) = \ell(\lambda y) + ||\lambda y|| = \ell(y) + |\lambda| ||y|| = \varphi_\ell(y)$ for all $y \in Y$ and $\lambda \geq 0$,

and

$\varphi_\ell(y^1 + y^2) = \ell(y^1 + y^2) + ||y^1 + y^2||
\leq \ell(y^1) + ||y^1|| + ||y^2||
=\ \varphi_\ell(y^1) + \varphi_\ell(y^2)$ for all $y^1, y^2 \in Y$

(compare Definition 1.7).

**Proposition 2.6 ([74, Proposition 3.4])** Let $Y$ be a real space. For every sublinear functional $\psi : Y \to \mathbb{R}$, the set $S := \{y \in Y | \psi(y) \leq 0\}$ is a convex cone.

**Proof** $\psi : Y \to \mathbb{R}$ be a sublinear functional. Arbitrarily chosen $y \in S$ and $\lambda \geq 0$,

$\psi(\lambda y) = \lambda\psi(y) \leq 0$,

i.e., $\lambda y \in S$. Moreover, for all $y^1, y^2 \in S$, we obtain

$\psi(y^1 + y^2) \leq \psi(y^1) + \psi(y^2) \leq 0$,

which means $y^1 + y^2 \in S$. Consequently, the set $S$ is a convex cone.

But not every functional $\psi : Y \to \mathbb{R}$ (where $Y$ denotes a linear space) with the property that the sublevel set $\{y \in Y | \psi(y) \leq 0\}$ is a convex cone given by $(2.3)$.

**Proposition 2.7 ([74, Proposition 3.5])** Let Assumption 2.1 be satisfied, and let $\psi$ be a $-C$ representing sublinear functional. There exists some linear functional $\ell \in Y'$ so that $-C$ is contained in the halfspace $\{y \in Y | \ell(y) \leq 0\}$.

**Proof** $\psi$ is a sublinear functional, by the Hahn-Banach theorem, there is some linear functional $\ell \in Y'$ with $\psi(y) \geq \ell(y)$ for all $y \in Y$. For every $y \in -C$, we then have $0 \geq \psi(y) \geq \ell(y)$, which proves the assertion.

**Theorem 2.1 ([74, Proposition 3.6])** Let Assumption 2.1 be satisfied, and let $\psi$ be a $-C$ representing sublinear functional. Then

+   (a) $\{y \in Y | \psi(y) \leq 0\} \subseteq \text{core}(-C)$.
(b) $\text{core}(-C) \subseteq \{y \in Y | \psi(y) < 0\}$ if the latter is nonempty.
