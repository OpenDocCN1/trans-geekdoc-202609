Example 6.1 (See [150, Section 3]) This example is discussed in detail in
Example 6.7. We assume the mini-dataset:

| Instance 1: | -2 | -1 | 1 |
| Instance 2: | 25 | 6 | -1 |
| Instance 3: | 17 | 4 | -1 |
| Instance 4: | -15 | -6 | 1 |

There are four instances in this dataset, and each instance consists of two features
a a classification number, which is either -1 or 1. As function for predicting
the classification number, we choose

$\mathcal{F}(p_1,p_2,p_3) := \{f \in \mathbb{R}^2 \mid f(x_1, x_2) = 	ext{tanh}(p_1x_1 + p_2x_2 + p_3) \forall (x_1, x_2) \in \mathbb{R}^2\}$

where $p_1, p_2, p_3 \in \mathbb{R}$ are arbitrarily chosen parameters and $x_1, x_2$ denote
the features. Every function of this class depends on the parameters $p_1, p_2, p_3 \in\mathbb{R}$. Within this class, our goal is to find optimal parameters such
for each instance, the function value at the given feature approximates the
given classification number. This can be achieved by solving the unconstrained
optimization problem

$$\min_{p_1,p_2,p_3 \in \mathbb{R}} (\text{tanh}(-2p_1 - p_2 + p_3) - 1)^2 + (\text{tanh}(25p_1 + 6p_2 + p_3) + 1)^2$\n+ (\text{tanh}(17p_1 + 4p_2 + p_3) + 1)^2 + (\text{tanh}(-15p_1 - 6p_2 + p_3) - 1)^2$.

For $p_1 = -4.5504, p_2 = -1.7752$ and $p_3 = 3.7752$, the objective value
of this optimization problem is $1.4132 \times 10^{-25}$. Consequently, the formula

$y = \text{tanh}(-4.5504x_1 - 1.7752x_2 + 3.7752)$

gives a good approximation of the classification number $y$ for the given features
$x_1$ and $x_2$ of each of the four instances.

In practice, a dataset naturally consists of a large number of instances, which
makes the objective of the associated optimization problem very complex.
For example, the well-known dataset collection [84] contains a dataset with
over 250,000 instances and one with more than 60,000 features. Thus, real-world
problems in AI lead to challenging optimization problems. Such problems also
require complex function classes, which can be systematically constructed using
deep neural networks.
