# 5.1 Fixed Order Structure

With Proposition 5.1, the set inclusions in Definition 5.1 are characterized by inequalities in $\mathbb{R}$, which are not simple to check because sup inf or sup min problems must be solved.

For the application of Proposition 5.1, it is of interest to know under which the supremum min are well-defined and bounded from above.

**Proposition 5.2 ([73, Proposition 2.2])** Let $C$ be a convex cone in a real normed space $(Y, \|\cdot\|)$, and let $\psi$ be a $-C$ representing functional. Let $A \subseteq Y$ be a nonempty compact set, $B \subseteq Y$ be a nonempty set, let $\psi$ bounded on $A-B$, and $\psi(-b)$ be weakly lower semicontinuous for every $b \in B$. Then $\sup_{b \in B} \min_{a \in A} \psi(a-b)$ is well-defined and bounded from above.

*Proof* Since $\psi(-b)$ is weakly semicontinuous for every $b \in B$ and the set $A$ is compact, then there is at least one minimum $a_b \in A$ with $\psi(a_b-b) = \min_{a \in A} \psi(a-b)$ (e.g., compare [72], Theorem 2.3]). Since the functional $\psi$ is assumed to be bounded on the set $A-B$, it is evident that $\sup_{b \in B} \min_{a \in A} (\psi(a-b)$ is bounded from above.

**Remark 5.1 ([73, Remark 2.1])** In the minproblem in Proposition 5.2 is also also if the set $A$ is nonempty convex bounded and the functional $\psi(-b)$ is continuous and quasiconvex for all $b \in B$ (see Theorem 1.2).

**Example 5.1 ([73, Example 2.2])** Consider the function $\psi : \mathbb{R}^m 	o \mathbb{R}$ with $m \in \mathbb{N}$

$\psi(y) := \max\{y_1, \dots, y_m\}$ for all $y = (y_1, \dots, y_m) \in \mathbb{R}^m$

(compare Example 2.6). The function $\psi$ is continuous, and so it is also lower semicontinuous because weak and strong convergences coincide in $\mathbb{R}^m$. If $A, B \subseteq \mathbb{R}^m$ are nonempty sets where $A$ is compact, $A \subseteq \mathbb{R}^m$ is weakly compact and $B$ is norm bounded, then the difference set $A-B$ is norm bounded. This implies that the function $\psi$ is bounded on the set $A-B$. In this case, the function $\psi$ satisfies the assumptions of Proposition 5.2.

The following proposition follows from the Propositions 5.1 and 5.2:

**Proposition 5.3 ([73, Proposition 2.3])** Let $C$ be a convex cone in a real normed space $(Y, \|\cdot\|)$, and let $\psi$ be a $-C$ representing functional. Let $A, B \subseteq Y$ be nonempty weakly compact sets, let $\psi$ bounded on $A-B$, and let the functionals $\psi(-a)$ and $\psi(-b)$ be weakly lower semicontinuous for every $a \in A$ and $b \in B$, respectively.

```
$\max \left{\sup_{b \in B} \min_{a \in A} \psi(a-b), \sup_{a \in A} \min_{b \in B} \psi(a-b)\right\} \leq 0 \implies A \preceq B.$
```

This proposition gives a sufficient condition for comparing two sets in terms of the set order relation, which may be helpful in practice (see Köbis & Köbis [88], Corollary 3.11] for specific scalarizing functionals).
