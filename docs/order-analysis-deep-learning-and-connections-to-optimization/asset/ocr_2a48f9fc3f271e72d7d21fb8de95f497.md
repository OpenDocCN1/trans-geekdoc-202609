Finally, we discuss another extension of the stochastic gradient method, called the stochastic average gradient method. The advantage of this procedure is that previously computed gradients are reused, repeatedly improving the estimate of the gradient of the objective function.

**Algorithm 6.6** (Stochastic average gradient method [124, Algorithm 1])
| 1 Input: $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$, |
| 2 maximal iteration number $i_{max}$. |
| 4 $i := 0$ % initialization |
| 5 $y^1 := y^2 := \dots := y^p := 0_{\mathbb{R}^n}$ |
| 6 $s^0 := 0_{\mathbb{R}^n}$ |
| 7 **while** $i \leq i_{max}$ |
| 8 $k := \text{rand}(p)$ % random integer (uniformly sampled in $[1, \dots, p]$) |
| 9 $s^{i+1} := s^i - y^k + \nabla f_k(x^i)$ % estimator of the sum of gradients |
| 10 $y^k := \frac{\nabla f_k(x^i)}{p}$ % gradient estimator update |
| 11 $d^i := -s^{i+1} / p$ % iteration direction |
| 12 choose $\lambda_i > 0$ |
| 13 $x^{i+1} := x^i + \lambda_i d^i$ % step size |
| 14 $i := i + 1$ |
| 15 **end while** |
| 17 Output: $x^1, x^2, \dots, .$ |

First, some notes for a better understanding of this method. In this algorithm, $s^i$ denotes the sum of the gradients $y^1, \dots, y^p$ at iteration $i \in \mathbb{N} \cup \{0\}$. In line 9, this sum is updated by replacing the estimate $y^k$ by the gradient $\nabla f_k(x^i)$ for some index $k \in \{1, \dots, p\}$ chosen in line 8. Then, in line 11, we get the direction in the form

```
$d^i := -\frac{1}{p} \left(\sum_{j=1 \ j \neq k}^p y^j + \nabla f_k(x^i)\right).$
```
