
Using a slack variable, the objective functional in (7.2) can be simplified, and one obtains

```
$$\sup \lambda$$
$$\text{subject to}$$
```

```
$$\sup \inf |\tilde{s} - \bar{s}\| \le \lambda$$
$$\$\tilde{s} \in S_{\text{pred}}(w_1, \dots, w_n); \quad \bar{s} \in S_{\text{ave}}\$\quad (7.5)$$
```

```
$$\sup \inf |\tilde{s} - \bar{s}\| \le \lambda$$
$$\$\tilde{s} \in S_{\text{ave}} \quad \bar{s} \in S_{\text{pred}}(w_1, \dots, w_n)$$
$$w_1, \dots, w_n \in \mathbb{R}; \quad \lambda \in \mathbb{R}; \quad B_1, \dots, B_m \in \hat{P}(X).$$
```

Due to the two complicated constraints, this optimization problem is really challenging.
Next, we answer the question under which conditions the inf problems in the constraints of the optimization problem (7.5) have a maximal solution.

**Proposition 7.3** $(X, ||\cdot||)$ be a real normed space, and let the sets $A, B \in \hat{P}(X)$ be arbitrarily chosen. If the set $A$ is compact, then the optimization problem

```
$$\sup \inf \|a - b\|$$
$$a \in A \ b \in B$$
```

has a maximal solution.

**Proof** For simplicity, we define the functional $\varphi : A \to \mathbb{R}$ with

```
$$\varphi(a) := \inf \|a - b\| \text{ for all } a \in A.$$
$$b \in B$$
```

Then there exists some sequence $(a_k)_{k \in \mathbb{N}}$ with $a_k \in A$ for all $k \in \mathbb{N}$ and

```
$$\sup \inf \|a - b\| = \sup \varphi(a) = \lim_{k \to \infty} \varphi(a_k).$$
$$a \in A \ b \in B$$
```

Since the set $A$ is compact, there is a subsequence $(a_k)_{\ell \in \mathbb{N}}$ converging to $\bar{a} \in A$. We get then

```
$$\sup \inf \|a - b\| = \lim_{\ell \to \infty} \varphi(a_{\ell}).\quad (7.6)$$
$$a \in A \ b \in B$$
```

Next, note that for an arbitrary $\varepsilon > 0$ there is some $b_{\ell} \in B$ with

```
$$\|\bar{a} - b_{\ell}\| \le \inf_{b \in B} \|\bar{a} - b\| + \varepsilon = \varphi(\bar{a}) + \varepsilon.\quad (7.7)$$.
```

## 7.4 Distance Between Sets

With the inequality (7.7), we conclude for all $\ell \in \mathbb{N}$

```
$$\varphi(a_{k\ell}) = \inf_{b\in B} \|a_{k\ell} - b\|$$
$$\leq \|a_{k\ell} - b_{k\ell}\|$$
$$= \|\|\tilde{a} - b_{k\ell} + a_{k\ell}\|\|$$
$$\leq \|\tilde{a} - b_{k\ell}\| + \|\|\tilde{a} - a_{k\ell}\|$$
$$\leq \varphi(\tilde{a}) + \varepsilon + \|\|\tilde{a} - a_{k\ell}\|. \quad (7.8)$$
```

The equality (7.6) and the inequality (7.8) then imply

```
$$\sup_{a\in A, b\in B} \|a - b\| = \varphi(a) + \varepsilon + \lim_{\ell\to\infty} \|\|\tilde{a} - a_{k\ell}\| = \varphi(\tilde{a}) + \varepsilon.$$
$$\quad =0$$
```

Since this inequality holds for all $\varepsilon > 0$, we get in the limit

```
$$\sup_{a\in A, b\in B} \|a - b\| = \varphi(\tilde{a}).$$
```

This means that $\tilde{a} \in A$ is a maximal solution of the sup inf $\inf_{a\in A, b\in B} \|a - b\|$, which has to be shown.

The middle part of the proof of Proposition 7.3 follows the proof of [3.5] given in a more general setting. In game theory, the solvability of sup inf problems is also studied, with the question under which conditions the equality

```
$$\inf_{a\in A, b\in B} \|a - b\| = \sup_{a\in A, b\in B} \|a - b\|$$
```

holds (compare [3] and [8]). However, in the context of Hausdorff distance, such equality is not relevant.

## 7.4 Radial Distance

One can reduce the complexity of the optimization problem (7.2) caused by Hausdorff distance using a simpler metric in special cases. We begin by defining a special class of sets.

**Definition 7.5** Let $(X, ||\cdot||)$ be a real normed space, and let $S(X) := \{x \in X | \|x\| = 1\}$ denote the unit sphere in $X$.

(a) The special class $C_r(X)$ is defined by

```
$$C_r(X) := \{A \in \hat{P}(X) \mid A = \{x \in X \setminus \{0_X\} \mid 0 < \|x\| \le \varphi_A(x)\} \cup \{0_X\}\}$$
```

for a given functional $\varphi_A: S(X) \to \mathbb{R}_+$, which depends on $A$.

(b) Every set $A \in C_r(X)$ is called radial functional of $A$. Note that the radial functional is uniquely defined by Definition 7.5 (a). Thus, the class $C_r(X)$ consists of sets $A \in \hat{P}(X)$ with boundary defined by such a set. These sets do not have to be convex. By definition, one can also try to shift a set $A \in \hat{P}(X)$ by $x$ so that the shifted set $A-\{x\}$ possibly has the desired properties, i.e., $A-\{x\} \in C_r(X)$. Sets in the class $C_r(X)$ have special structures.

**Proposition 7.4** Let $(X, ||\cdot||)$ be a real normed space. Every set $A \in C_r(X)$ has the following:

(a) $0_X \in \text{core}(A)$ if its radial functional $\varphi_A(x) > 0$ is satisfied for all $x \in S(X)$.
(b) $A$ is starshaped with respect to $0_X$.

**Proof**

- Let $x \in X \setminus \{0_X\}$ be arbitrarily chosen. Then we obtain $x/\|x\| \in S(X)$, and by assumption, we conclude $\varphi_A(x/\|x\|) > 0$. So there is some $\lambda > 0$ with

```
$$0 < \|\lambda x\| \le \varphi_A(x/\|x\|) = \varphi_A(\lambda x/\|\lambda x\|)\quad (7.9)$$
```

implies $\lambda x \in A$. And for all $\lambda \in (0, 1)$, we get by (7.9)

```
$$0 < \|x\| \le \|\lambda x\| \le \varphi_A(\lambda x/\|\lambda x\|).$$
```

So, $\lambda x \in A$ for all $\lambda \in (0, 1)$. This condition also holds for $\lambda=0$ and $x=0_X$, because $0_X \in A$.

-(b) Let $x \in A$ be arbitrarily chosen. We need to show $\lambda x \in A$ for all $\lambda \in [0, 1]$. Since the case $x=0_X$ is trivial, assume $x \neq 0_X$. For an arbitrary $\lambda \in (0, 1)$, we obtain

```
$$0 < \|\lambda x\| \le \lambda \varphi_A(x/\|x\|) \le \varphi_A(\lambda x/\|\lambda x\|).$$
```

This implies $\lambda x \in A$ for all $\lambda \in (0, 1)$. This condition also holds for $\lambda=0$, because $0_X \in A$. Consequently, the set $A$ is starshaped with respect to $0_X$.

Considering the intersection of a set $A \in C_r(X)$ with all rays emanating from the origin and considering these intersections as subsets of the real line $\mathbb{R}$, these subsets are closed and bounded.

For sets in the class $C_r(X)$, we introduce a special distance.

**Definition 7.6** Let $(X, \|\cdot\|)$ be a real normed space. For two sets $A, B \in C_r(X)$ with the associated radial functionals $\varphi_A$ and $\varphi_B$, *radial distance* is defined by

```
$$d_r(A, B) := \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|.$$
```

Note that this distance is easier to determine compared to the Hausdorff distance. But the radial distance is only applicable for special sets.

**Theorem 7.1** Let $(X, \|\cdot\|)$ be a real normed space. Then the radial distance $d_r$ is a metric on the class $C_r(X)$.

**Proof**

- (a) It is obvious that the distance $d_r$ is non-negative. For arbitrary $A, B \in C_r(X)$, we have

```
$$d_r(A, B) = 0 \iff \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|$$
$$\iff \varphi_A(x) = \varphi_B(x) \text{ for all } x \in S(X)$$
$$\iff A = B.$$
```

- (b) For arbitrary $A, B \in C_r(X)$, we get

```
$$d_r(A, B) = \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|$$
$$= \sup_{x \in S(X)} |\varphi_B(x) - \varphi_A(x)|$$
$$= d_r(B, A).$$
```

This shows the symmetry of the distance.

- (c) For the proof of the triangle inequality, take arbitrary $A, B, C \in C_r(X)$. We then obtain

```
$$d_r(A, B) = \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|$$
$$= \sup_{x \in S(X)} |\varphi_A(x) - \varphi_C(x) + \varphi_C(x) - \varphi_B(x)|$$
$$\le \sup_{x \in S(X)} |\varphi_A(x) - \varphi_C(x)| + |\varphi_C(x) - \varphi_B(x)|$$
$$\le \sup_{x \in S(X)} |\varphi_A(x) - \varphi_C(x)| + \sup_{x \in S(X)} |\varphi_C(x) - \varphi_B(x)|$$
$$= d_r(A, C) + d_r(C, B),$$
```

which has to be shown.

**Theorem 7.2** Let Assumption 7.1 be satisfied, and let $(X, ||\cdot||)$ to be a real normed space. The optimization problem

```
$$$\inf d_r(Spred(w_1, \dots, w_n, B_1, \dots, B_m), Srtue)$\n\text{subject to}\nw_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X) \(7.10)$$$$
```

has at least one minimal solution if the set of all sets arising in the objective functional is contained in the class $C_r(X)$ and is sequentially compact with respect to the radial metric.
