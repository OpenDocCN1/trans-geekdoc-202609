**Proof** Since the closed ball is compact and the objective function $\sum_{j=1}^p \|f(x^j, \cdot, \cdot) - y^j\|$ is continuous, there exists a minimal solution of the optimization problem (6.5) by the well-known Weierstrass theorem.

Large weights or biases are not interesting in practice. Therefore, it makes sense to restrict the constrained set to a closed ball of some acceptable radius. With this modification, we obtain a minimal solution.

In practice, the function class implicitly by a deep neural network with hidden layers is not given in an explicit form. Therefore, the objective function in the optimization problems (6.2) and (6.3) is not explicitly known. To compute an objective value at a pair $(w, b)$, we feed the training instances forward through the artificial neurons of the network. In this way, the result is $f(x^j, w, b)$ for the $j$-th training instance, and we get the value of the objective function.

For numerical optimization methods such as gradient methods, we need the gradient of the objective function at some $(w, b) \in \mathbb{R}^{q+r}$. Now, we assume that the chosen activation function is differentiable. If we choose the objective function of the optimization problem (6.4), i.e.

```
$$\sum_{j=1}^p \|f(x^j, w, b) - y^j\|^2 = \sum_{j=1}^p \sum (f(x^j, w, b) - y^j)^2$ for all $(w, b) \in \mathbb{R}^{q+r}$
```

we have a differentiable function. To obtain the partial derivative of this objective function with respect to a component of the pair $(w, b)$, we can use the chain rule to go back to an input of an artificial neuron. By repeating this procedure from neuron to neuron, we obtain a formula for the desired partial derivative. This process works backward in the network and is called *backpropagation*. For an introductory description of backpropagation, we refer to Zhou [150].
