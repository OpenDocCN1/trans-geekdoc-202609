A more interesting optimality condition can be obtained if we additionally assume that there exists a $-C$ representing functional.

**Theorem 3.1** ([35, Theorem 3.6]) Let Assumption 3.1 be satisfied, let $\psi : Y \to \mathbb{R}$ be a $-C$ representing functional, and let some $	ilde{x} \in \hat{S}$ be given:

+   (a) The vector $	ilde{x}$ is a unique minimal solution of problem (3.1) if and only if

```
$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\ \geq 0 \text{ for all } x \in \hat{S} \text{ with } x \neq \tilde{x}. \quad (3.3)$
```

+   (b) If the vector $\tilde{x}$ is a unique minimal solution of problem (3.1), then

```
$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\} \geq 0 \text{ for all } x \in \hat{S}.$.
```

# Proof

+   (a) By Lemma 3.1, (\tilde{x}) is a unique minimal solution of problem (3.1) if and only if the equality (3.2) holds. Next, we prove for arbitrary $\alpha \in \mathbb{R}$ and $y \in Y$ the equivalence

```
$(\alpha, y) \in -\mathbb{R}_+ \times (-C) \quad \iff \quad \max(\alpha, \psi(y)) \leq 0. \quad (3.4)$
```

For the proof of this equivalence, we first assume that $\max(\alpha, \psi(y)) \leq 0$. Then we get $\alpha \leq 0$ and $y \in [0, i]$, $y \in -C$, and we have $(\alpha, y) \in -\mathbb{R}_+ \times (-C)$. Conversely, assume that $(\alpha, y) \in -\mathbb{R}_+ \times (-C)$. Then we get $\alpha \leq 0$ and $\psi(y) \leq 0$ implying that. With the equivalence (3.4) together with the equality (3.2), we obtain that $\tilde{x}$ is a unique minimal solution of problem (3.1) if and only if the condition (3,3) is fulfilled.

+   (b) Let $\tilde{x}$ be a minimal solution of problem (3.1), and let $x \in \hat{S}$ be arbitrarily chosen. If $x \in \hat{S}$, then $f(x) - f(\tilde{x}) \geq 0$, and we get
