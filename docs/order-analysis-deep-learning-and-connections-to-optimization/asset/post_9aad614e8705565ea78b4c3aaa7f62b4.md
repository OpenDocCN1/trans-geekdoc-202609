## 2.5 Directional Derivative

```math
$$\max_{x \in \mathbb{R}^n \ \|x\|_2=1} x^{\mathsf{T}}(\tilde{A} + \lambda H)x - \max_{x \in \mathbb{R}^n \ \|x\|_2=1} x^{\mathsf{T}}\tilde{A} \le \lambda \alpha \text{ for all } \lambda > 0.$$$
```

Hence, we have

```math
$$\lim_{\lambda \to 0_+} x^{\mathsf{T}}(\tilde{A} + \lambda H)x_{\lambda} = \max_{x \in \mathbb{R}^n \ \|x\|_2=1} x^{\mathsf{T}}\tilde{A}.$$$$
```

So, there is a sequence $(\lambda_k)_{k \in \mathbb{N}}$ of positive real numbers converging to 0 with $\lim_{k \to \infty} x_{\lambda_k} = \tilde{x} \in X(\tilde{A})$. And we conclude

```math
$$\Psi'(\tilde{A})(H) = \lim_{k \to \infty} \frac{1}{\lambda_k} \max_{x \in \mathbb{R}^n \ \|x\|_2=1} x^{\mathsf{T}}(\tilde{A} + \lambda_k H)x - \max_{x \in \mathbb{R}^n \ \|x\|_2=1} x^{\mathsf{T}}\tilde{A} \\
\ge x_{\lambda_k}^{\mathsf{T}}(\tilde{A} + \lambda_k H)x_{\lambda_k} \\
\ge \lambda_k x_{\lambda_k}^{\mathsf{T}}H x_{\lambda_k} \\
= \lim_{k \to \infty} \frac{1}{\lambda_k} (x_{\lambda_k}^{\mathsf{T}}\tilde{A}x_{\lambda_k} + \lambda_k x_{\lambda_k}^{\mathsf{T}}H x_{\lambda_k}) \\
= \tilde{x}^{\mathsf{T}}H\tilde{x} \\
\le \max_{x \in X(\tilde{A})} x^{\mathsf{T}}Hx. \quad (2.12)$$$
```

The inequalities (2.11) and (2.12) imply the assertion.

**Remark 2.4** ([73, Remark 4.2]) If in Proposition 2.13 (a) the maximal eigenvalue of a matrix $\tilde{A} \in \mathcal{S}^n$ is simple, then the associated normed eigenvector $\tilde{x}$ is unique, and the set $X(\tilde{A})$ consists of this vector. In this special case, the directional derivative is given as

```math
$$\Psi'(\tilde{A})(H) = \tilde{x}^{\mathsf{T}}H\tilde{x} \quad \text{for all } H \in \mathcal{S}^n.$$$
```

If the maximal eigenvalue of $\tilde{A}$ is a double eigenvalue, then the set $X(\tilde{A})$ is a circle in a two-dimensional subspace of $\mathcal{S}^n$ spanned by the eigenvectors. Let $\tilde{x}^1$ and $\tilde{x}^2$ be orthogonal normed eigenvectors with the maximal eigenvalue of $\tilde{A}$. Then this subspace is spanned by $\tilde{x}^1$ and $\tilde{x}^2$, and we have

```math
$$X(\tilde{A}) = \{\alpha\tilde{x}^1 + \beta\tilde{x}^2 \mid \alpha, \beta \in \mathbb{R} \text{ and } \|\alpha\tilde{x}^1 + \beta\tilde{x}^2\|_2 = 1\}.$$
```

In this special case, the directional derivative

```math
$$\Psi'(\tilde{A})(H) = \max_{\alpha,\beta \in \mathbb{R}} (\alpha\tilde{x}^1 + \beta\tilde{x}^2)^{\mathsf{T}} H (\alpha\tilde{x}^1 + \beta\tilde{x}^2) \quad \text{for all } H \in \mathcal{S}^n.$$$
```

This maximization problem with two variables is very simple to solve. Finally, we consider the space $\mathbb{R}^m$.

**Proposition 2.14** ([72, Exercise 8.3]) Let $\tilde{Y} := \mathbb{R}^m$ (with $m \in \mathbb{N}$) and $C := \mathbb{R}^m_+$ be chosen. Then the $-C$ representing functional $\psi : \mathbb{R}^m \to \mathbb{R}$ with

```math
$$\psi(y) = \max(y_1, \dots, y_m) \quad \text{for all } y = (y_1, \dots, y_m) \in \mathbb{R}^m$$
```

has the directional derivative at an arbitrary $\tilde{y} \in \mathbb{R}^m$ given by

```math
$$\Psi'(\tilde{y})(h) = \max_{i \in I(\tilde{Y})} h_i \quad \text{for all } h = (h_1, \dots, h_m) \in \mathbb{R}^m$$
```

with

```math
$$I(\tilde{Y}) := \{i \in \{1, \dots, m\} \mid \tilde{y}_i = \psi(\tilde{y})\}.$$$$
```

**Proof** This proof follows the lines of proof of Proposition 2.12. For arbitrary $\tilde{y}, h \in \mathbb{R}^m$, we obtain

```math
$$\Psi'(\tilde{y})(h) = \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\Psi(\tilde{y} + \lambda h) - \Psi(\tilde{y}))\\
= \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\max_{1 \le i \le m} \{\tilde{y}_i + \lambda h_i\} - \max_{1 \le i \le m} \{\tilde{y}_i\})\\
= \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\max_{i \in I(\tilde{Y})} \{\tilde{y}_i + \lambda h_i\} - \max_{i \in I(\tilde{Y})} \{\tilde{y}_i\})$$$$
```

For sufficiently small $\lambda > 0$, we have

```math
$$\max_{1 \le i \le m} \{\tilde{y}_i + \lambda h_i\} = \max_{i \in I(\tilde{Y})} \{\tilde{y}_i + \lambda h_i\}$$
```

because for $j \notin I(\tilde{Y})$, i.e., $\tilde{y}_j < \max_{1 \le i \le m} \{\tilde{y}_i\}$, there is some $\varepsilon > 0$ so that

```math
$$\tilde{y}_j + \lambda h_j \le \tilde{y}_j + \varepsilon < \max_{1 \le i \le m} \{\tilde{y}_i\}$$
```

and

```math
$$\tilde{y}_j + \lambda h_j < \max_{1 \le i \le m} \{\tilde{y}_i + \lambda h_i\}.$$$$
```

## 2.6 Subdifferential

Hence, we conclude

```math
$$\psi'(\bar{y})(h) = \lim_{\lambda \to 0_+} \lambda \left( \max_{i \in R(Y)} \{\bar{y}_i + \lambda h_i\} - \max_{i \in R(Y)} \{\bar{y}_i\} \right) = \text{const}\\
= \lim_{\lambda \to 0_+} \lambda \max_{i \in R(Y)} \{\bar{y}_i + \lambda h_i - \bar{y}_i\\
= \lim_{\lambda \to 0_+} \max_{i \in R(Y)} [\lambda h_i]\\
= \max_{i \in R(Y)} \{h_i\},$$$$
```

this proves the assertion.

Note with Example 2.2 that the penalty functional $\eta : \mathbb{R}^m \to \mathbb{R}^+$
$\eta(y) := \sum_{i=1}^m (\max(0, y_i))^2 \quad \text{for all } y = (y_1, \dots, y_m) \in \mathbb{R}^m$

is a $-\mathbb{R}^m_+$ representing functional, which is entirely differentiable. On the other hand, the $-\mathbb{R}^m$ representing functional $\psi$ investigated in Proposition 2.14 is not differentiable.

The proofs of Propositions 2.12, 2.13, and 2.14 given for various real linear spaces have a similar structure, but they are different in detail.

Under appropriate assumptions, a relation between the subdifferential of the $-C$ representing functional at the origin and the dual cone can be given.

Theorem 2.2 ([74, Theorem 3.1]) Let $C$ be a convex cone of a real normed space $(Y, \|\cdot\|)$, and let $\psi$ be a $-C$ representing functional, which is convex with $\psi(0) = 0$ and has a nonempty subdifferential $\partial\psi(0)$. Then it holds

```math
$$\text{cl} (\partial\psi(0)) \subseteq C^*.$$$
```

Proof $\ell \in \text{cl} [\partial\psi(0)]$ be arbitrarily chosen. Then there exist sequences $(\lambda_n)_{n \in \mathbb{N}}$ and $(\ell_n)_{n \in \mathbb{N}}$ with $\lambda_n \geq 0$ and $\ell_n \in \partial\psi(0)$ for all $n \in \mathbb{N}$ so that $\bar{\ell} = \lim_{n \to \infty} \lambda_n \ell_n$. By the definition of the subdifferential, we have for every $n \in \mathbb{N}$

```math
$$\psi(y) \geq \psi(0) + \ell_n(y) = \ell_n(y) \quad \text{for all } y \in Y.$$$
```
