Since the system of all feasible sets is sequentially compact, there has a subsequence $(A_{ki})_{i\in\mathbb{N}}$ converging to some feasible predicted set $\tilde{A}$. We then obtain with the triangle inequality of radial metric

$$\lim_{\ell\to\infty} d_r(A_{ki}, S_{true}) \geq \lim_{\ell\to\infty} (d_r(\tilde{A}, S_{true}) - d_r(\tilde{A}, A_{ki})) = d_r(\tilde{A}, S_{true}) - \lim_{\ell\to\infty} d_r(\tilde{A}, A_{ki}) = 0 = d_r(\tilde{A}, S_{true}).$$$$

$$\d_r(\tilde{A}, S_{true}) \leq \inf \{d_r(S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m), S_{true}) \mid w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X)\}.$$$$

Hence, $\tilde{A}$ is a minimal solution of the optimization problem (7.11) with associated real numbers $\tilde{w}_1, \dots, \tilde{w}_n$ and $\tilde{B}_1, \dots, \tilde{B}_m \in \widehat{P}(X)$.

A minimal solution of the optimization problem (7.10) can be obtained by solving the problem

$$\min_{x\in S(X)} \sup |\varphi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(x) - \varphi_{S_{true}}(x)| \text{subject to } w_1, \dots, w_n \in \mathbb{R}; \quad B_1, \dots, B_m \in \widehat{P}(X).$$$$

Using a slack variable, this problem can be rewritten as

$$\min \lambda \text{subject to } -\lambda \leq \varphi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(x) - \varphi_{S_{true}}(x) \leq \lambda \quad \text{for all } x \in S(X), \\ w_1, \dots, w_n \in \mathbb{R}; \quad B_1, \dots, B_m \in \widehat{P}(X)..$$$$

This is a semi-infinite optimization problem with finitely many variables and infinitely many constraints.

### 7.4.3 Constraint Distance

Another way of determining the distance between two sets can be given for the case when the two sets are described by constraints. For this purpose, we define the following class of sets:

**Definition 7.7** Let $X$ be a real linear space:

(a) The special class $C_C(X)$ is defined by

$$C_C(X) := \{A \in \mathcal{P}(X) \mid A = \{x \in X \mid \psi_A(x) \leq 0\}\}$$

for a given functional $\psi_A : X \to \mathbb{R}$, which depends on $A$.

(b) Every set $A \in C_C(X)$ is called a *constraint set*, and associated functional $\psi_A$ is called *constraint functional*.

Obviously, the class $C_C(X)$ is not as restrictive as the class of radial sets. Not for a constraint set $A$, a constraint functional $\psi_A$ is not unique. For example, a constraint functional $2\psi_A$ is also a constraint functional (see also Example 7.4 (b) for another example).

**Example 7.4** Let $X$ be a real linear space.

- (a) Let a set $A \in \mathcal{P}(X)$ be defined by $k$ inequality constraints (with $k \in \mathbb{N}$), i.e.,

$$A := \{x \in X \mid \psi_i(x) \leq 0 \text{ for all } i \in \{1, \dots, k\}\}$$

with functionals $\psi_1, \dots, \psi_k : X \to \mathbb{R}$. If we choose the functional $\psi_A : X \to \mathbb{R}$

$$\psi_A(x) := \sum_{i=1}^k \max\{0, \psi_i(x)\} \text{ for all } x \in X,$$$$

then $\psi_A$ is a constraint functional.

- (b) If a set $A \in \mathcal{P}(X)$ is given by $\ell$ equality constraints (with $\ell \in \mathbb{N}$), i.e.,

$$A := \{x \in X \mid \eta_i(x) = 0 \text{ for all } i \in \{1, \dots, \ell\}\}$$$$

with functionals $\eta_1, \dots, \eta_\ell : X \to \mathbb{R}$, then the functional $\psi_A : X \to \mathbb{R}$ with

$$\psi_A(x) := \sum_{i=1}^\ell |\eta_i(x)| \text{ for all } x \in X,$$$$

is a constraint functional. Another constraint functional is $\tilde{\psi}_A : X \to \mathbb{R}$ with

$$\tilde{\psi}_A(x) := \sum_{i=1}^{\ell} (\eta_i(x))^2 \text{ for all } x \in X.$$$$

In this case, there is obviously an infinite number of ways to specify a constraint functional by classes of functionals.

- (c) Next, we combine inequality and equality constraints. Let a set $A \in \mathcal{P}(X)$ be given in form

$$A := \{x \in X \mid \psi_i(x) \leq 0 \text{ for all } i \in \{1, \dots, k\}, \\ \eta_i(x) = 0 \text{ for all } i \in \{1, \dots, \ell\}\}$$$$

with numbers $k, \ell$ and functionals $\psi_1, \dots, \psi_k, \eta_1, \dots, \eta_\ell : X \to \mathbb{R}$. Then the functional $\psi_A : X \to \mathbb{R}$

$$\psi_A(x) := \sum_{i=1}^k \max\{0, \psi_i(x)\} + \sum_{i=1}^\ell |\eta_i(x)| \text{ for all } x \in X$$$$

is a constraint functional.

- (d) Finally, we consider a general constraint using a convex cone $C$ in a real linear space $Y$. Let a set $A \in \mathcal{P}(X)$ be of form

$$A := \{x \in X \mid g(x) \in -C\}$$$

where $g : X \to Y$ is a given map. Now we use order analysis from Part 2 of this book. Let $-C$ representing functional $\psi : Y \to \mathbb{R}$ be given (see Definition 2.5), i.e., we assume that

$$-C = \{y \in Y \mid \psi(y) \leq 0\}$$$

Then the set $A$ can be rewritten as

$$A := \{x \in X \mid \psi(g(x)) \leq 0\}$.$$$$In this particular case, $\psi_A := \psi \circ g$ is a constraint functional. In Example 7.4, parts (a)–(c) are based on well-known penalty functionals, while in part (d) an approach of order analysis (given in Sect. 2) is used. In the class $C_c(X)$, we can now introduce distance between two sets.

**Definition 7.8** Let $X$ be a real linear space. For two sets $A, B \in C_c(X)$ with the associated constraint functionals $\psi_A$ and $\psi_B$, the *constraint distance* is defined by

$$d_c(A, B) := \max_{a \in A} \{0, \sup_{b \in B} \psi_A(b)\}.$$$$

**Theorem 7.3** Let $X$ be a real linear space. Then the constraint distance $d_c$ on the class $C_c(X)$ has the following properties:

- (a) $d_c$ is nonnegative on $C_c(X)$, and for all $A, B \in C_c(X)$, $d_c(A, B) = 0 \iff A = B$.
- (b) $d_c(A, B) = d_c(B, A)$ for all $A, B \in C_c(X)$.

**Proof** Let $A, B \in C_c(X)$ be arbitrarily chosen. (a) By Definition 7.8, it is evident that $d_c(A, B)$ is nonnegative. Further, with functionals $\psi_A$ and $\psi_B$

$$A = B \iff A \subseteq B \text{ and } B \subseteq A \iff \psi_B(a) \leq 0 \text{ for all } a \in A \text{ and } \psi_A(b) \leq 0 \text{ for all } b \iff 0 \geq \sup_{a \in A} \psi_B(a) \text{ and } 0 \geq \sup_{b \in B} \psi_A(b) \iff \max\{0, \sup_{a \in A} \psi_B(a), \sup_{b \in B} \psi_A(b)\} = 0 \iff d_c(A, B) = 0.$$$

(b) By Definition 7.8, it is obvious that $d_c(A, B) = \max\{0, \sup_{a \in A} \psi_B(a), \sup_{b \in B} \psi_A(b)\} = d_c(B, A)$, which has to be shown.

By Theorem 7.3, the distance $d_c$ is only a semimetric on $C_c(X)$. In general, the triangle inequality does not hold. Although the class $C_c(X)$ is also restrictive, the constraint distance $d_c$ has the crucial advantage that one has “standard” optimization problems to solve.

Theorem 7.2 cannot be extended to the class $C_c(X)$ since the triangle inequality is not satisfied in general. Nevertheless, a set $S_{true}$ can be reasonably approximated by a set $S_{pred}$.

**Proposition 7.5** Let Assumption 7.1 be satisfied. If the optimization problem

$$\min d_c(S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m), S_{true}) \text{subject to } w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X) (7.12)$$$$

(the system of all sets arising in the objective function is assumed to be contained in the class $C_c(X)$ with a minimal solution $(\tilde{w}_1, \dots, \tilde{w}_n, \tilde{B}_1, \dots, \tilde{B}_m)$ with minimal value 0, then $S_{pred}(\tilde{w}_1, \dots, \tilde{w}_n, \tilde{B}_1, \dots, \tilde{B}_m) = S_{true}$.$$

**Proof** For every minimal solution $(\tilde{w}_1, \dots, \tilde{w}_n, \tilde{B}_1, \dots, \tilde{B}_m)$ of problem (7.12) with minimal value 0,

$$d_c(S_{pred}(\tilde{w}_1, \dots, \tilde{w}_n, \tilde{B}_1, \dots, \tilde{B}_m), S_{true}) = 0.$$$$

With Theorem 7.3 (a) then follows the assertion. $\square$
