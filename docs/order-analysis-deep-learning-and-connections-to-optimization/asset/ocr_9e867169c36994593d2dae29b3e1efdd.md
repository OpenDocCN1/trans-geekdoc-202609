We now consider the possibility that the step size λi can be chosen arbitrarily in a certain interval. Under suitable assumptions, we can then prove the linear convergence of Algorithm 6.1 modified in this way. For this proof, we first need the two lemmas:

**Lemma 6.2** (Variational Inequality [42, Lemma 2.14]) *For some μ > 0, let the function f : Rⁿ → R be μ-strongly convex and differentiable. Then we have*

```
∇f(x)ᵀ(y-x) ≥ f(x) - f(y) + \frac{\mu}{2} ||x-y||²2 for all x, y ∈ Rⁿ
```

**Proof** By Proposition 1.12, we get

```
f(y) ≥ f(x) + ∇f(x)ᵀ(y-x) + \frac{\mu}{2} ||y-x||²2 for all x, y ∈ Rⁿ
```
