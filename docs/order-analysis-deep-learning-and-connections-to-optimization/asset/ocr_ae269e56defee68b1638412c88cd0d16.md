We begin with an extension of the set less order relation given in Definition 5.1 to the case of a variable order structure.

**Definition 5.3 ([74, Definition 5.3])** Let Assumption 2.2 be satisfied. For nonempty subsets $A, B \subseteq Y$, the set less order relation defined by $\le_{S,K}$ is defined by

```
$A \le_{S,K} B \iff B \subseteq \bigcup_{a \in A} (\{a\} + \mathcal{K}(a)) \text{ and } A \subseteq \bigcup_{b \in B} (\{b\} - \mathcal{K}(b)).$
```

For convenience, we restrict ourselves to the case given in Definition 5.3.

**Proposition 5.5 ([74, Proposition 5.3])** Let Assumption 2.2 be satisfied, and let $\psi$ be a $-\mathcal{K}$ representing functional. Then for arbitrary nonempty sets $A, B \subseteq Y$, we have

```
$B \subseteq \bigcup_{a \in A} (\{a\} + \mathcal{K}(a)) \implies \begin{cases} \sup_{b \in B} \psi(a - b, a) \le 0 \ \min_{b \in B} \psi(a - b, a) \le 0 \\text{if this min term exists} \end{cases}$
```

and

```
$A \subseteq \bigcup_{b \in B} (\{b\} - \mathcal{K}(b)) \implies \begin{cases} \sup_{a \in A} \psi(a - b, a) \le 0 \ \min_{a \in A} \psi(a - b, a) \le 0 \\text{if this min term exists.} \end{cases}$
```

**Proof** For arbitrary nonempty sets $A, B \subseteq Y$, it follows from Proposition 2.16, (b)

```
$B \subseteq \bigcup_{a \in A} (\{a\} + \mathcal{K}(a)) \iff \forall b \in B \:exists a \in B \: a : b \in (\{a\} + \mathcal{K}(a)$
```

```
$\sup_{b \in A} \psi(a - b, a) \le 0 \\min_{b \in A} \psi(a - b, a) \le 0 \\text{if this min term exists.}$
```

For the proof of the second character, we write

```
$A \subseteq \bigcup_{b \in B} (\{b\} - \mathcal{K}(b)) \iff \forall a \in A \:exists b \in B \: a \in (\{b\} - \mathcal{K}(b)),$
```

and then we apply Proposition 2.16, (a). This completes the proof.
