Since optimization in deep learning can have millions of variables, it is not practical to work with dense matrices $B'$ (standard quasi-Newton methods cannot be used). As a consequence, we choose a simple class of matrices, as the class of matrices $\lambda I$, where $\lambda > 0$ must be chosen appropriately and $I$ denotes the $(n, n)$ identity matrix. Barilai and Borwein [12] used the quasi-Newton equation to determine an appropriate step size for the gradient descent method. To obtain a good approximation of Eq. (6.11) for this special class of matrices, we solve the optimization problem

```
$$\|\lambda I(x^i - x^{i-1}) - (
abla f(x^i) - \nabla f(x^{i-1}))\|_2^2.$ (6.12)$
```

which can be rewritten as

```
$$\min_{\lambda>0}(x^i - x^{i-1})^T(\nabla f(x^i) - \nabla f(x^{i-1}))^T[\lambda(x^i - x^{i-1}) - (\nabla f(x^i) - \nabla f(x^{i-1}))].$
```

For each minimal $\lambda > 0$, the derivative of the objective function of this optimization problem vanishes, we get

```
$$0 = (x^i - x^{i-1})^T[\lambda(x^i - x^{i-1}) - (\nabla f(x^i) - \nabla f(x^{i-1}))]$\n+[x^i - x^{i-1})^T(\nabla f(x^i) - \nabla f(x^{i-1}))^T](x^i - x^{i-1})$$\n=2\tilde{\lambda}(x^i - x^{i-1})^T(x^i - x^{i-1}) - 2(x^i - x^{i-1})^T(\nabla f(x^i) - \nabla f(x^{i-1}))$$
```

implying

```
$$\tilde{\lambda} := \frac{(x^i - x^{i-1})^T(\nabla f(x^i) - \nabla f(x^{i-1}))}{(x^i - x^{i-1})^T(x^i - x^{i-1})}$.$
```

It is known from quasi-Newton methods that the iteration reads as follows:

```
$x^{i+1} := x^i + (B^i)^{-1}d^i = x^i + \frac{1}{\lambda}d^i.$
```

If we set

```
$$\lambda_i := \frac{1}{\tilde{\lambda}} = \frac{(x^i - x^{i-1})^T(x^i - x^{i-1})}{(x^i - x^{i-1})^T(\nabla f(x^i) - \nabla f(x^{i-1}))}$.$$
```

we obtain the Barzilai-Borwein step size rule in line 9 of Algorithm 6.2. This choice of $\lambda_i$ does not guarantee descent in the objective function $f$ (see [117, p. 27]).
