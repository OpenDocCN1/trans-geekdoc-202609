# Deep Learning with Set-Valued Inputs

Finally, we consider a deep learning network with multiple interval-valued inputs and one interval-valued output.

**Theorem 7.5** *Let a training dataset with $p \in N$ instances of the form $[x^j_1, \overline{x^j_1}], \dots, [x^j_k, \overline{x^j_k}], [y^j, \overline{y^j}]$ for the $j$-th instance, $(j, k \in N)$ be. Let $n \in N$ denote the total number of biases, and let $m \in N$ denote the number of biases all hidden layers in a deep learning network. Then optimal weights and biases are obtained by solving the optimization problem*

```
$$\min_{j=1}^p \max {|y^j_{pred}(z) - \overline{y^j}|, |\overline{y^j_{pred}}(z) - y^j|}$$
$\$\text{subject to}$$
$$b_i \le \overline{b_i} \text{ for all } i \in \{1, \dots, m\}$ \quad (7.17)$
$$z := (w_1, \dots, w_n, b_1, \overline{b_1}, \dots, b_m, \overline{b_m}) \in \mathbb{R}^{n+2m}$$
```

$y^j_{pred}(\cdot), \overline{y^j_{pred}}(\cdot)$ denotes the predicted interval output of the $j$-th instance with $j \in \{1, \dots, p\}$ and $[y^j, \overline{y^j}]$ denotes the true interval output of the $j$-th instance.

**Proof** (7.13) in Lemma 7.1 can be used to determine the resulting interval output. By Theorem 7.4 and Corollary 7.1, we can work with the Hausdorff distance and observe the objective function

```
$$\sum_{j=1}^p d_H([y^j_{pred}(\cdot), \overline{y^j_{pred}}(\cdot)], [y^j, \overline{y^j}])$$
$\$\n = \sum_{j=1}^p \max {|y^j_{pred}(\cdot) - \overline{y^j}|, |\overline{y^j_{pred}}(\cdot) - y^j|}$ $$
```

If we note the inequality constraints for the start and end points of the bias intervals, the resulting optimization problem can be written in the form of problem (7.17). $\square$

Problem (7.17) is a constrained optimization problem with linear inequality constraints. The higher number of artificial neurons in the deep learning network, the higher number of such constraints.
