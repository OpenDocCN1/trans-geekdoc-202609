# 6.6

An overview of different gradient methods for deep learning is provided in Sect. 6.6. Due to the high dimensionality of the optimization problem, matrix operations should be avoided. Therefore, we restrict ourselves to different types of gradient methods and do not study quasi-Newton methods.

Different names are used for gradient methods. This is due to the fact that research fields, such as mathematics, computer science, engineering, and medicine, use and extend them. For example, IBM [66] distinguishes three types of gradient descent: batch gradient descent, stochastic gradient descent, and mini-batch gradient descent. Batch gradient descent means the entire, large dataset, is considered in the optimization problem, which leads to a very complex problem with long processing time. The methods in Sect. 6.6, are appropriate for this task (e.g., see [124]). Stochastic gradient descent, the topic of Sect. 6.2, with a stochastic selection within the entire dataset, which has advantages in terms of speed and memory requirements. Mini-batch descent is a certain combination of the two concepts above and take advantage of it. It is described in Sect. 6.6 because it is an extended stochastic gradient method.

In 1847, Cauchy [23] introduced the steepest descent method (for a classification of the historical paper, see [96]) given in Sect. 6.6.1. Further developments of the theory and extensions of the Barilai-Borwein method [12] given in Algorithm 6.2 are formulated by Raydan [116, 117], Dai and Liao [270], and Huang et al. [65]. For deep learning problems, a gradient method was also given by Todorov-Tanev [134]. Algorithm 6.3 can also be understood as a special case of the Barilai-Borwein method, since it is likewise based on the quasi-Newton equation.

Robbins and Monro [119] gave the first foundations of stochastic gradient methods in 1951. Recent developments in stochastic gradient methods can be found in [147, 97, 133, 44], among others. The mini-batch stochastic gradient method is popular today. However, if we continue to use the functions of $f_1,...$ in subsequent iterations, a memory of helpful gradient information is built up many iterations that can be used subsequently. In this way, the estimation of the gradient of the objective function can be improved. This strategy is used in the stochastic average gradient method (Algorithm 6.6). This method was introduced by Le Roux, Schmidt, and Bach in various papers (see [94, 95, 123, 124], and also [139].
