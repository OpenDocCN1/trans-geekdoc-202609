Finally, we consider the space $\mathbb{R}^m$.

**Proposition 2.14 ([72, Exercise 8.3])** Let $\tilde{Y} := \mathbb{R}^m$ (with $m \in \mathbb{N}$) and $C := \mathbb{R}^m_+$ be chosen. Then the $-C$ representing functional $\psi : \mathbb{R}^m \to \mathbb{R}$ with

```
$$\psi(y) := \max(y_1, \dots, y_m) \text{ for all } y = (y_1, \dots, y_m) \in \mathbb{R}^m$$
```

has the directional derivative at an arbitrary $\tilde{y} \in \mathbb{R}^m$ given by

```
$$\Psi'(\	ilde{y})(h) = \max_{i \in I(\tilde{Y})} h_i \text{ for all } h = (h_1, \dots, h_m) \in \mathbb{R}^m$$
```

with

```
$$\I(\tilde{Y}) := \{i \in \{1, \dots, m\} \| \tilde{y}_i = \psi(\tilde{y})\}$$
```

**Proof** This proof follows the lines of proof of Proposition **2.12**. For arbitrary $\tilde{y}, h \in \mathbb{R}^m$, we obtain

```
$$\Psi'(\	ilde{y})(h) = \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\Psi(\	ilde{y} + \lambda h) - \Psi(\	ilde{y}))$\n$$= \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\max_{1 \le i \le m} \{	ilde{y}_i + \lambda h_i} - \max_{1 \le i \le m} \{	ilde{y}_i\)$$
$$= \lim_{\lambda \to 0^+} \frac{1}{\lambda} (\max_{i \in I(\tilde{Y})} \{	ilde{y}_i + \lambda h_i} - \max_{i \in I(\tilde{Y})} \{	ilde{y}_i\})$$$
```

For sufficiently small $\lambda > 0$, we have

```
$$\max_{1 \le i \le m} \{	ilde{y}_i + \lambda h_i} = \max_{i \in I(\tilde{Y})} \{	ilde{y}_i + \lambda h_i}$$$
```

because for $j \notin I(\tilde{Y})$, i.e., $\tilde{y}_j < \max_{1 \le i \le m} \{	ilde{y}_i\}$, there is some $\varepsilon > 0$ so that

```
$$\tilde{y}_j + \lambda h_j \le \tilde{y}_j + \varepsilon < \max_{1 \le i \le m} \{	ilde{y}_i\}$$$
```

and

```
$$\tilde{y}_j + \lambda h_j < \max_{1 \le i \le m} \{	ilde{y}_i + \lambda h_i}.$$
```
