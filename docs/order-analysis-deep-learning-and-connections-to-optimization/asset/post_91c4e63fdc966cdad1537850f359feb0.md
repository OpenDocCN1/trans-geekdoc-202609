## 6.6.1 Gradient Descent Method

We start with the well-known gradient descent method in a first conceptual form. Later, we will also present a more practical variant.

```
Algorithm 6.1 (Gradient descent method—conceptual form)
1 Input: $f : \mathbb{R}^n \to \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$.
2
3 $i := 0$ % initialization
4 while $\nabla f(x^i) \neq 0$ do % iteration direction
5 $d' := -\nabla f(x^i)$6 determine $\lambda_i > 0$
7 $x^{i+1} := x^i + \lambda_i d'$ % optimal step
8 $i := i+1$
9 end while
10
11 Output: $x^1, x^2, \dots$
```

Note in line 7 of Algorithm 6.1, the term “step size” is commonly used in optimization. In the field of neural networks, the term “learning rate” is often used instead (see, for example, [66]).

The proof of the following lemma makes it clear why this gradient method generates descents during the process of iteration.

**Lemma 6.1** (Descent Property of Algorithm **6.1**) Let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be differentiable. For arbitrary points $x^i, x^{i+1} \in \mathbb{R}^n$ (with $i \in \mathbb{N}$) $f(x^{i+1}) < f(x^i)$ holds.

The following theorem gives a convergence result for Algorithm 6.1:

## **Theorem 6.2** (Convergence of the Gradient Descent Method in Algorithm **6.1**)

Let the objective function $f: \mathbb{R}^n \to \mathbb{R}$ be differentiable.

- (a) *If* Algorithm 6.1 generates finitely many points $x^1, x^2, \dots, x^k$ for some $k \in \mathbb{N}$, then $\nabla f(x^k) = 0_{\mathbb{R}^n}$.

**Proposition 6.2** (Zigzagging Behavior of the Gradient Descent Method in Algorithm 6.1) Let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be differentiable, and let Algorithm 6.1 generate the iteration points $x^1, x^2, \dots$ For an iteration point $x^i$ with $i \in \mathbb{N}$ then holds

```
$\nabla f(x^i) \perp \nabla f(x^{i-1}) = 0.$
```

**Proof** Let $x^i$ with $i \in \mathbb{N}$ be an arbitrary iteration point. If we define the function $\varphi : \mathbb{R}_{++} \to \mathbb{R}$

```
$\varphi(\lambda_{i-1}) \le \varphi(\lambda)$ for all $\lambda > 0.$
```

**Remark 6.2 (Drawbacks of the Gradient Descent Method in Algorithm 6.1)** In addition to its positive features, the gradient descent method in Algorithm **6.1** also has significant disadvantages. We discuss two important cases:

- (a) A (global) minimal point of the objective function $f$ lies in a “narrow, long valley” and an unfavorable starting point $x^0$, the iteration points may be close to each other even though the point is considered further away. In this case, the convergence of the method cannot be observed. A typical example of this is the Rosenbrock function [121] $f: \mathbb{R}^2 \to \mathbb{R}$ with
