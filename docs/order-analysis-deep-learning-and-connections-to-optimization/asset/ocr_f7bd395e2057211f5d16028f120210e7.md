By choosing an appropriate vector $w = (w_1, \dots, w_q) \in R^q$ of weights $w_1, \dots, w_q \in R$ and a vector $b = (b_1, \dots, b_r) \in R^r$ of biases $b_1, \dots, b_r \in R$ with $q, r \in \mathbb{N}$ in the deep neural network, we try to find a function $f(\\cdot, w, b)$ that is a good approximation of $y^l$. For a given norm $\|\cdot\|$ in $R^l$, the approximation error can be expressed as $\|f(x^l, w, b) - y^l\|$. Since this procedure is applied to each instance, we keep the

```
$\sum_{j=1}^p \|f(x^j, w, b) - y^j\|$
```

as much as possible. This leads to the unconstrained optimization problem

```
$\min_{(w,b) \in R^{q+r}} \sum_{j=1}^p \|f(x^j, w, b) - y^j\|.$ (6.3)
```

If we use the Euclidean norm $\|\cdot\|_2$, it makes sense to consider the unconstrained optimization problem

```
$\min_{(w,b) \in R^{q+r}} \sum_{j=1}^p \|f(x^j, w, b) - y^j\|_2^2$ (6.4)
```

for reasons of simplicity.

Note that problems (6.3) and (6.4) are not always solvable. For example,

```
$0 = \inf_{(w_1,w_2,b_1,b_2) \in R^4} |e^{u_1+b_1}| + |e^{u_2+b_2}|$
```

holds, but the inf is not attained. There is no minimal solution of this optimization problem. But the following proposition gives assumptions under which a modification of (6.3) is solvable.

**Proposition 6.1 (Solvability of Modified Problem (6.3))** Let a dataset with $p \in \mathbb{R}$ instances of the form $(x^j, y^j) \in R^k \times R^l$ (with $j \in \{1, \dots, p\})$ be given, let the function $f : R^k \times R^q \times R^r \to R^l$ be given so that is continuous for all $j \in \{1, \dots, p\}$, and $\|\cdot\|$ be an arbitrary norm in $R^l$. Then for any $\alpha > 0$, the constrained optimization problem

```
$\min_{(w,b) \in B(0_{q+r}, \alpha)} \sum_{j=1}^p \|f(x^j, w, b) - y^j\|$ (6.5)
```
