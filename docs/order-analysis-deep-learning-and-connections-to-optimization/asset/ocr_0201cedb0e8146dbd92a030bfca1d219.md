For sets in the class $C_r(X)$, we introduce a special distance.

**Definition 7.6** Let $(X, \|\|)$ be a real normed space. For two sets $A, B \in C_r(X)$ with the associated radial functionals $\varphi_A$ and $\varphi_B$, *radial distance* is defined by

```
$d_r(A, B) := \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|$.
```

Note that this distance is easier to determine compared to the Hausdorff distance. But the radial distance is only applicable for special sets.

**Theorem 7.1** Let $(X, \|\|)$ be a real normed space. Then the radial distance $d_r$ is a metric on the class $C_r(X)$.

**Proof**

+   (a) It is obvious that the distance $d_r$ is nonve. For arbitrary $A, B \in C_r(X)$, we have

```
$d_r(A, B) = 0 \Longiff \sup_{x \in S(X)} |\varphi_A(x) - \varphi_B(x)|$\n$\n\Longiff \varphi_A(x) = \varphi_B(x) \text{ for all } x \in S(X)$ \n$\n\Longiff A = B$.
```
