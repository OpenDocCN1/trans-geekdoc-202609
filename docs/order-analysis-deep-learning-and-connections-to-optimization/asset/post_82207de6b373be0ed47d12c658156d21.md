### 6.4.3 Softsign Function

The following softsign function, proposed by Turian, Bergstra, and Bengio [135] (see also [30, 108]), is similar to tanh in some respects:

**Definition 6.2** The function $\rho : \mathbb{R} \to (-1, 1)$, given by

```
$\rho(x) := \frac{x}{1 + |x|} \quad \text{for all } x \in \mathbb{R}$
```

is called *softsign function*. Figure 6.6 illustrates the softsign function. As with the tanh function, we obtain the open interval $(-1, 1)$ as the range for the softsign function. The first derivative of the softsign function $\rho$ is given by

```
$\rho'(x) := \frac{1}{(1 + |x|)^2} \quad \text{for all } x \in \mathbb{R},$
```

which is illustrated in 6.6. It is obvious that the softsign function $\rho$ is once continuously differentiable; the second derivative exists only outside the zero point. In practice, the softsign function does not play a special role. However, it is numerically easier to calculate than the tanh function and can be easily generalized by including set-valued inputs (see Sect. 7.3).

### 6.4.4 ReLU Function

The Rectified Linear Unit (abbreviated ReLU) is a simple piecewise linear function. Fukushima [41] introduced this special activation function in 1969.

**Definition 6.3 ([41, p. 324])** The function $\varrho : \mathbb{R} \to \mathbb{R}_+$ is given by

$$\varrho(x) := \max\{0, x\} \text{ for all } x \in \mathbb{R}$$

is the ReLU function.

Figure 6.7 illustrates the ReLU function. This function is not bounded from above and also not differentiable at $\tilde{x} := 0$, but it is continuous. However, this function can be smoothed in a small neighborhood of zero so that the modified function is differentiable.

Fukushima [41] defined this activation function as a kind of combination of the identity function and the zero function based on the functionalities of the synapses of one biological neuron at the interface to the next biological neuron.

The ReLU function has the advantage that, in contrast to the sigmoid or tanh functions, does not require any arithmetic operations to be performed. On the other hand, for nonpositive values, the function values are simply set to zero, which can eliminate certain information. However, particular successes are reported in the research literature, which is why this ReLU activation function is popular (cf. among others [26, 110]).

The approximation performance of deep feedforward neural networks using the ReLU activation function has been investigated by Shen, Yang, and Zhang [127] in terms of the number of neurons. Their result hold for a continuous function $g : [0,1]^d \to \mathbb{R}$ (where $d$ denotes the dimension of the feature space) with a modulus of continuity $\omega_g : [0, \infty) \to \mathbb{R}_+ \cup \{\infty\}$ given by

$$\omega_g(\varepsilon) := \sup \{|g(x)-g(y)\| : x, y \in [0,1]^d, \|x-y\| \le \varepsilon\} \text{ for all } \varepsilon > 0.$$

## 6.5 Supervised Learning

Note that the modulus of continuity is generally used to quantitatively measure uniform continuity (see [98, p. 239]).

The following theorem is presented without proof:

**Theorem 6.1 (Approximation Property of ReLU Deep Feedforward Neural Networks [127, Theorem 1.1])** Let the continuous function $g \in C([0,1]^d)$ be arbitrarily chosen, and let $s, t \in \mathbb{N}$ and $p \in [1, \infty)$ be numbers. Then there exists a real-valued function $f$ in the class of all functions generated by a ReLU deep feedforward neural network with width $\alpha \max \{d t^{-1/2}, t+1\}$ and depth $2s+\beta$, where

$$\alpha := \begin{cases} 2 & p \in [1, \infty) \\ 3^d & p = \infty \end{cases}$$

and

$$\beta := \begin{cases} 4 & p \in [1, \infty) \\ 2d & p = \infty \end{cases}$$

so that

$$\|g-f\|_{L^p((0,1)^d)} \le C\sqrt{d}\omega_g(t^{-1/2})s^{-3/2}.$$

**Remark 6.1 (Special Classes of Modulus of Continuity)** In Theorem 6.1, the upper bound in (6.2) uses the modulus of continuity $\omega_g$. It is known (see, for example, [98, p. 239]) that the inequality $\omega_g(\varepsilon) \le c\varepsilon$ for some constant $c \in \mathbb{R}$ describes Lipschitz continuity of $g$ and the inequality $\omega_g(\varepsilon) \le c\varepsilon^\eta$ for $\eta \in (0,1]$ describes Hölder continuity of $g$.

### 104 Basics of Learning

A neural network describes a large class of functions, but for a specific problem, we need to specify the weights and biases. This can be done by *learning* from a given dataset. Such a training dataset consists of inputs (such as features) and correct outputs. The computation of appropriate weights and biases of a deep neural network is *supervised learning*. In this chapter, we restrict ourselves mainly to unconstrained optimization. In addition to supervised learning, there is also the so-called *unsupervised*, *semi-supervised*, or *reinforcement learning* (see [120] for details).

Next, we investigate supervised learning from a training dataset. In such a dataset with $p \in \mathbb{N}$ instances, consider an arbitrary instance of the form $(x^j, y^j) \in \mathbb{R}^k \times \mathbb{R}^l$, where $x^j$ is the vector of inputs and $y^j$ is the vector of outputs. By choosing an appropriate vector $w = (w_1, \dots, w_q) \in \mathbb{R}^q$ of weights $w_1, \dots, w_q \in \mathbb{R}$ and a vector $b = (b_1, \dots, b_r) \in \mathbb{R}^r$ of biases $b_1, \dots, b_r \in \mathbb{R}$ with $q, r \in \mathbb{N}$, in the deep neural network, we try to find a function $f(\cdot, w, b)$ that is a good approximation of $y^l$. For a given norm $\|\cdot\|$ in $\mathbb{R}^l$, the approximation error can be expressed as $\|f(x^j, w, b) - y^j\|$. Since this procedure is applied to each instance, we keep the $\sum_{j=1}^p \|f(x^j, w, b) - y^j\|$ as much as possible. This leads to the unconstrained optimization problem:

$$\min_{(w,b) \in \mathbb{R}^{q+r}} \sum_{j=1}^p \|f(x^j, w, b) - y^j\| \quad (6.3)$$

If we use the Euclidean norm $\|\cdot\|_2$, it makes sense to consider the unconstrained optimization problem:

$$\min_{(w,b) \in \mathbb{R}^{q+r}} \sum_{j=1}^p \|f(x^j, w, b) - y^j\|_2^2 \quad (6.4)$$

for reasons of simplicity.

Note that problems (6.3) and (6.4) are not always solvable. For example,

$$0 = \inf_{(w_1,w_2,b_1,b_2) \in \mathbb{R}^4} |e^{w_1+b_1}| + |e^{w_2+b_2}|$$

holds, but the inf is not attained. There is no minimal solution of this optimization problem. But the following proposition gives assumptions under which a modification of (6.3) is solvable.

**Proposition 6.1 (Solvability of Modified Problem (6.3))** Let a dataset with $p \in \mathbb{N}$ instances of the form $(x^j, y^j) \in \mathbb{R}^k \times \mathbb{R}^l$ (with $j \in \{1, \dots, p\}$) be given, let the function $f : \mathbb{R}^k \times \mathbb{R}^q \times \mathbb{R}^r \to \mathbb{R}^l$ be given so that it is continuous for all $j \in \{1, \dots, p\}$, and $\|\cdot\|$ be an arbitrary norm in $\mathbb{R}^l$. Then for any $\alpha > 0$, the constrained optimization problem

$$\min_{(w,b) \in B(0_{q+r}, \alpha)} \sum_{j=1}^p \|f(x^j, w, b) - y^j\| \quad (6.5)$$

Large weights or biases are not interesting in practice. Therefore, it makes sense to restrict the constrained set to a closed ball of some radius. With this modification, we obtain a minimal solution.

In practice, the function class implicitly by a deep neural network with hidden layers is not given in an explicit form. Therefore, the objective function in the optimization problems (6.2) and (6.3) is not explicitly known. To compute an objective value at a pair $(w, b)$, we feed the training instances forward through the artificial neurons of the network. In this way, the result is $f(x^j, w, b)$ for the $j$-th training instance, and we get the value of the objective function.

For numerical optimization methods such as gradient methods, we need the gradient of the objective function at some $(w, b) \in \mathbb{R}^{q+r}$. Now, we assume that the chosen activation function is differentiable. If we choose the objective function of the optimization problem (6.4), i.e.

$$\sum_{j=1}^p \|f(x^j, w, b) - y^j\|^2 = \sum_{j=1}^p (f(x^j, w, b) - y^j)^2 \text{ for all } (w, b) \in \mathbb{R}^{q+r}$$

we have a differentiable function. To obtain the partial derivative of this objective function with respect to a component of the pair $(w, b)$, we can use the chain rule to go back to an input of an artificial neuron. By repeating this procedure from neuron to neuron, we obtain a formula for the desired partial derivative. This process works backward in the network and is called *backpropagation*. For an introductory description of backpropagation, we refer to Zhou [150].
