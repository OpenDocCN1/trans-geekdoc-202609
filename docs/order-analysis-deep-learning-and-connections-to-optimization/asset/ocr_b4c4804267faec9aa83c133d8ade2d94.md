Also in this subsection we discuss the unconstrained optimization problem (6.6),
i.e.,

$\min_{x \in \mathbb{R}^n} f(x)$

with $n \in \mathbb{N}$ and $f : \mathbb{R}^n \to \mathbb{R}$. But now we assume the objective function $f$ has
the special form

```
$f(x) = \frac{1}{p} \sum_{j=1}^p f_j(x) \text{ for all } x \in \mathbb{R}^n, \quad (6.17)$
```

where $p \in \mathbb{N}$ and $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$ are given functions. If $f_1, \dots, f_p$ are
differentiable functions, then the objective function $f$ is also differentiable with

```
$\nabla f(x) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) \text{ for all } x \in \mathbb{R}^n. \quad (6.18)$
```

Deep learning typically works with a very large dataset consisting of many training
examples. This means that the parameter $p$ is a very large integer. Thus,
a large number of gradients $\nabla f_j(x)$, with $j \in \{1, \dots, p\}$ and $x \in \mathbb{R}^n$, be
computed to determine the gradient of the objective function for a gradient descent
method. This numerical effort can be greatly reduced with the help of
the simple proposition:

**Proposition 6.3 (Unbiased Estimator of $\nabla f(x)$)** Let the functions $f_1, \dots, f_p :
\mathbb{R}^n \to \mathbb{R}$ be differentiable, let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be given by (6.17), and let
$x \in \mathbb{R}^n$ be arbitrarily chosen. If $G$ denotes a discrete $\mathbb{R}^n$-valued random element,
which is uniformly distributed and takes the gradients $\nabla f_j(x), \dots, \nabla f_p(x)$, then
its expectation is $E(G) = \nabla f(x)$, or in other ways, $G$ is an unbiased estimator of
the gradient $\nabla f(x)$.

**Proof** Under the assumptions of this proposition and using the equality (6.18), we
immediately get for the expectation of $G$

```
$E(G) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) = \nabla f(x).
```

which has been shown.
