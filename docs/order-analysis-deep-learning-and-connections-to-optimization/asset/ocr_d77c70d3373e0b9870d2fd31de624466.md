A disadvantage of the stochastic gradient method is that only one gradient $\nabla f_k$ is used. This drawback can be reduced by selecting several gradients at each iteration.f1, \dots, f_p$. This leads to a combination of a gradient descent method and the stochastic gradient method, which is called a *mini-batch stochastic gradient method*.
