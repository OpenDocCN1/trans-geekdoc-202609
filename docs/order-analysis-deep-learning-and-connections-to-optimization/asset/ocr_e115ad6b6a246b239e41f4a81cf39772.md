# Algorithm 6 $\mathbb{R}^n$ (Quasi-Newton-type gradient descent method)

```
Input: $f : \mathbb{R} 	o \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$, stopping criterion $\epsilon > 0$.
$i := 0$ while $||
abla f(x^i)||_2 \ge \epsilon$
while $||
abla f(x^i)||_2 \ge \epsilon$ do
  if $i=0$ then
    $d^i := -
abla f(x^i)$  % iteration direction
  else
    for $k = 1$ to $n$ do
      $d^i_k := -\frac{\partial f}{\partial x_k}(x^i) \frac{\partial f}{\partial x_k}(x^{i-1})}{\frac{\partial f}{\partial x_k}}$  % components of the iteration direction
  if $
abla f(x^i)^T d^i > 0$ then
    $d^i := -d^i$  % modified iteration direction
end if
$x^{i+1} := x^i + d^i
$i := i+1
end while
Output: $x^1, x^2, \dots$
```
