# 7.4 Distance Between Sets

```
$$\implies 0 = \sup_{a\in A, b\in B} ||a - b|$\n$\implies 0 = \sup inf_{a\in A, b\in B} ||a - b||. \quad (7.3)$
```

Under the additional assumption that $(X, ||\cdot||)$ is a real reflexive Banach space and the set $B$ is convex, and we obtain by [72, Theorem 2.18] the solvability of the approximation problem $inf ||a - b||$ for every $a \in A$, i.e., we can write $inf_{b\in B} ||a - b|| = \min_{b\in B} ||a - b||$ for every $a\in A$. In this case, the reverse implication in (7.3) also holds. By renaming, we simply get

```
$B \subseteq A \implies 0 = \sup inf_{b\in B, a\in A} ||a - b||, \quad (7.4)$
```

and under the assumptions of part (b), the reverse implication in (7.4) also holds. From the implications (7.3) and (7.4), we conclude

```
$A = B \implies \max \{ \sup_{a\in A, b\in B} ||a - b||, \sup_{b\in B, a\in A} ||a - b|| \} = d_H(A, B)$
```

which shows part (a) of the assertion. Under the additional assumptions in part (b), the reverse implication $d_H(A, B) = 0 \implies A = B$ follows immediately.

The result in Proposition 7.2 (b) can be simplified in a finite-dimensional normed space.

# **Corollary 7.1** $(X, ||\cdot||)$ be a finite-dimensional real normed space, and let two closed sets $A, B \in \mathcal{P}(X)$ be arbitrarily chosen. Then

```
$A = B \iff d_H(A, B) = 0.$
```

**Proof** Every finite-dimensional normed space is reflexive and therefore also a real Banach space (compare [72, page 283]). For the proof of the solvability of the approximation problem $inf ||a - b||$ for every $a \in A$, we follow the lines of the proof of [72, Theorem 2.18] (here, we note that [72, Theorem B.4], used in the proof of [72, Theorem 2.12]) can be simplified in a finite-dimensional normed space by dropping the convexity assumption in Proposition 7.2 (b).

As a consequence of Corollary 7.1, one gets for closed sets in a finite-dimensional real normed space that equality is characterized by the Hausdorff 0. By minimizing the Hausdorff distance in the problem (7.2), the predicted set should be as close as possible to the true set.
