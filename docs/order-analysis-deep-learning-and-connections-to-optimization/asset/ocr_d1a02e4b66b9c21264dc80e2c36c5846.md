The following proposition provides an explicit formula for the activation map $\mathcal{F}$:

**Proposition 7.6** Let $[a, \overline{a}] \in C_{\text{int}}(\mathbb{R})$ be arbitrarily chosen. Then we have for the activation map $\mathcal{F}$

```
$$\mathcal{F}([a, \overline{a}]) = \frac{1}{1 + \max(|a|, |\overline{a}|)} [a, \overline{a}]. \quad (7.14)$$$
```

**Proof** For the interval $[a, \overline{a}] \in C_{\text{int}}(\mathbb{R})$, we make the following case distinction:

+   a) $\underline{a} \le \overline{a} \le 0$.

In this case, we get

```
$$\|[a, \overline{a}]| = \sup_{a \in [a, \overline{a}]} |a| = \max(|a|, |\overline{a}|)$.$$
```
