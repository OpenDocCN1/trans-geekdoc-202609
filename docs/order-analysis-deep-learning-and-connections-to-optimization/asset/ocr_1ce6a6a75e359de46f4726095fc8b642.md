# 7.5 Specialization to Interval-Valued Inputs

Interval variables are known from optimization with uncertain data. They have the advantage that only a lower and upper bound of the expected data is needed. They can be used if the distribution of the data is unknown. Here, we consider closed and bounded intervals in R.

**Definition 7.9** The special class $C_{int}(\mathbb{R})$ of closed bounded intervals in $\mathbb{R}$ is defined by

```
$C_{int}(\mathbb{R}) := \{[a, \overline{a}] \mid -infty < a \leq \overline{a} < \infty\}$
```

Figure 7.3 illustrates a feedforward network of artificial neurons with valued inputs and interval-valued outputs. Note that the numerical calculations in the artificial neurons are to be carried out with interval arithmetic. The formula (7.13) in the following lemma applies to the calculation with intervals in artificial neurons.

**Lemma 7.1** Let $n \in \mathbb{N}$ be a given number. For arbitrary inputs $[x_i, \overline{x}_i] \in C_{int}(\mathbb{R})$ with $i \in (1,\dots,n)$, an arbitrary bias interval $[b, \overline{b}] \in C_{int}(\mathbb{R})$, and arbitrary weights $w_1,\dots,w_n \in \mathbb{R}$, we obtain

```
$$\sum_{i=1}^n w_i[x_i, \overline{x}_i] + [b, \overline{b}] = [\sum_{i \in L_+} w_i x_i + \sum_{i \in L_-} w_i \overline{x}_i + b, \sum_{i \in L_+} w_i \overline{x}_i + \sum_{i \in L_-} w_i x_i + \overline{b}]$\ (7.13)
```
