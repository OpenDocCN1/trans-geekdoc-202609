# Chapter 1
Preliminaries

**Abstract** In this chapter, we summarize the well-known definitions of linear spaces and convex sets, as well as the definition of topological linear spaces, and we consider a preorder and a partial order in such a linear setting. Special attention is paid to normed spaces. Directional derivatives and subdifferentials are also recalled.

# 1.1 Linear Spaces and Convexity

First, we recall the definition of a real linear space and present some other notions.

**Definition 1.1** Let $Y$ be a given set. Assume that there is an addition on $Y$, i.e., a map from $Y 	imes Y$ to $Y$, and a scalar multiplication on $Y$, i.e., a map from $\mathbb{R} 	imes Y$ to $Y$, are defined. The set $Y$ is called a *real linear space* if the following axioms are satisfied (for arbitrary $x, y, z \in Y$ and $\lambda, \mu \in \mathbb{R}$)

+   (a) $x + y + z = x + (y + z)$.
(b) $x + y = y + x$.
(c) There is an element $0 \in Y$ with $x+0 = x$ for all $x \in Y$.
(d) For every $x \in Y$, there is a $y \in Y$ with $x+y=0$.
(e) $\lambda(x + y) = \lambda x + \lambda y$.
(f) $(\lambda + \mu)x = \lambda x + \mu x$.
(g) $\lambda(\mu x) = (\lambda\mu)x$.
(h) $1x = x$.

The element $0$ given under (c) is the *zero element* of $Y$.

**Definition 1.2** Let $S$ and $T$ be nonempty subsets of a real linear space $Y$. Then we define the *algebraic sum* of $S$ and $T$ as

```
$S + T := \{s + t \mid s \in S \text{ and } t \in T\}$
```

and the *algebraic difference* of $S$ and $T$ as

```
$S - T := \{s - t \mid s \in S \text{ and } t \in T\}$
```
