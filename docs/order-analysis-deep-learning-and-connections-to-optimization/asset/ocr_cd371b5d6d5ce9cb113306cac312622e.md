# 5.3 Bibliographical Notes

This chapter presents results of Jahn [73, 74]. First, we start with some general remarks on set optimization already given in [70]. Set optimization has developed from an extension of continuous optimization to problems with set-valued maps. Early contributions can be found in the 1977 paper of Borwein [21] and the 1980 paper of Oetli [109]. There are several approaches in set optimization; however, we restrict ourselves to the study of the so-called set approach (compare the book by Khan, Tammer, and Zinescu [85]. The set approach works with a more realistic order relation for the comparison of sets, which was introduced into optimization by Kuroiwa, for example, [91]; a first publication is by Kuroiwa, Tanaka, and Ha [92]. Hamel [55] pointed out that outside the optimization community this kind of comparison of sets by an order relation was already used by Young [143] in algebra and by Nishnidze [107] in fixed point theory. Chiriaev and Walster [25] were concerned with the comparison of sets in computer science and interval analysis.
