> **Remark 6.6 (Classification of Algorithm 6.3)** The good performance of Algorithm 6.3 in Example 6.4 is due to the fact that the Hessian matrix of the objective function is a diagonal matrix. This algorithm is also expected to handle a problem with a Hessian matrix of the objective function that is sparse in the non-diagonal part. However, for dense Hessian matrices, one cannot assume that Algorithm 6.3 works well. Even for the Rosenbrock function (see Fig.6.9). Although Algorithm 6.3 is titled "descent method", we may not get a descent of the value of the objective function at each iteration. However, Fig. 6.14 gives a different picture that cannot be generalized.
