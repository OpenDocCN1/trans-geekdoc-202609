Convex cones can be simply characterized.

**Proposition 1.1** (See [72, Theorem 4.3]) A cone $C$ in a real linear space is convex if and only if for all $x, y \in C$

$x + y \in C$

(i.e., $C + C = C$).

A central connection between preorders and convex cones is established in the following proposition:

**Proposition 1.2** (See [72, Theorem D.3]) Let $Y$ be a real linear space.

(a) If $\leq$ is a preorder on $Y$, then the set

$C := \{y \in Y \|mid 0y \leq y\}$

is a convex cone. If, in addition, $\leq$ is a partial order, then $C$ is pointed.

(b) If $C$ is a convex cone in $Y$, then its binary relation

$\leq := \{(x, y) \in Y \times Y \|mid y - x \in C\}$

is a preorder on $Y$. If, in addition, $C$ is pointed, then $\leq$ is a partial order.
