# 6.4.3 Softsign Function

The following softsign function, proposed by Turian, Bergstra, and Bengio [135] (see also [30, 108]), is similar to tanh in some respects:

**Definition 6.2** The function $ho : \mathbb{R} 	o (-1, 1)$, given by

```
$\rho(x) := \frac{x}{1 + |x|} \quad \text{for all } x \in \mathbb{R}$
```

is called *softsign function*. Figure 6.6 illustrates the softsign function. As with the tanh function, we obtain the open interval $(-1, 1)$ as the range for the softsign function. The first derivative of the softsign function $ho$ is given by

```
$\rho'(x) := \frac{1}{(1 + |x|)^2} \quad \text{for all } x \in \mathbb{R},$
```

which is illustrated in 6.6. It is obvious that the softsign function $ho$ is once continuously differentiable; the second derivative exists only outside the zero point. In practice, the softsign function does not play a special role. However, it is numerically easier to calculate than the tanh function and can be easily generalized by including set-valued inputs (see Sect. 7.3).
