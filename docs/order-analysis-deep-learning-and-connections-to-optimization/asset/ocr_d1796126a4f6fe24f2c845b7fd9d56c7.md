# **Theorem 6.6 (Convergence of the Stochastic Average Gradient Method [124, Theorem 1])** Let the functions $f_1, \dots, f_p : \mathbb{R}^n 	o \mathbb{R}$ with $n, p \in \mathbb{N}$ be differentiable and convex, and let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be defined by (6.17). For each $j \in \{1, \dots, p\}$, let the gradients $\nabla f_j be Lipschitz continuous with the same Lipschitz constant $L > 0$, i.e,

```
$$\nabla f_j(x) - \nabla f_j(y)\|_2 \le L\|x - y\|_2 \text{ for all } x, y \in \mathbb{R}^n.$
```

The objective function $f$ is $\mu$-convex for some $\mu > 0$ (Definition 1.25). Furthermore, let $\{x^i\}_{i \in \mathbb{N}}$ be a sequence generated by Algorithm 6.6 with a constant step size $\eta_i$ (i.e., $\frac{1}{6L}$ for all $i \in \mathbb{N}(0)$). Then, for each $i$, $n$ is

```
$E(f(x^i) - f(\	ilde{x})) \le \left(1 - \min\left(\frac{\mu}{L}, \frac{1}{8p}\right)\right)^i \left(f(\tilde{x}) - f(x^0)\right) + \frac{4L}{p}\|x^0 - \\tilde{x}\|_2^2 + \frac{\sigma^2}{L}\right$
```

where $\	ilde{x} \in \mathbb{R}^n$ is the unique minimal solution of the optimization problem (6.6).

$E(\cdot)$ for expectation and $\sigma^2 := \sum_{j=1}^p |\nabla f_j(\	ilde{x})\|_2^2$ denotes the variance of the gradient norms at the minimal point $\	ilde{x}$.

A proof of this theorem based on Lyapunov theory can be found in [123, Appendix B].
