+   (c) Next, we combine inequality and equality constraints. Let a set $A \in \overline{P}(X)$ be given in the form

```
$A := \{x \in X \mid \psi_i(x) \leq 0 \text{ for all } i \in \{1, \dots, k\}\n\eta_i(x) = 0 \text{ for all } i \in \{1, \dots, \ell\}$
```

with numbers $k, \ell$ and functionals $\psi_1, \dots, \psi_k, \eta_1, \dots, \eta_{\ell} : X \to \mathbb{R}$. Then the functional $\psi_A : X \to \mathbb{R}$

```
$\psi_A(x) := \sum_{i=1}^{k} \max(0, \psi_i(x)) + \sum_{i=1}^{\ell} |eta_i(x)| \text{ for all } x \in X$
```

is a constraint functional.

+   (d) Finally, we consider a general constraint using a convex cone $C$ in a real linear space $Y$. Let a set $A \in \overline{P}(X)$ be of the form

```
$A := \{x \in X \mid g(x) \in -C\}$
```

where $g : X \to Y$ is a given map. Now, we use order analysis from Part 2 of this book. Let a $-C$ representing functional $\psi : Y \to \mathbb{R}$ be given (see Definition 2.5), i.e., we assume that

```
$-C = \{y \in Y \mid \psi(y) \leq 0\}$
```

Then the set $A$ can be rewritten as

```
$A := \{x \in X \mid \psi(g(x)) \leq 0\}$.
```

In this particular case, $\psi_A := \psi \circ \ g$ is a constraint functional.
