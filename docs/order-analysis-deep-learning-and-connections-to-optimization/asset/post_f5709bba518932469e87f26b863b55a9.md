also equivalent to

$\psi(y-\tilde{y}) > \psi(\tilde{y}-\tilde{y})$ for all $y \in T \setminus\{\tilde{y}\}$

## 4.1 Fixed Structure

Theorem 4.2 ([74, Theorem 4.2]) Let Assumption 4.1 be satisfied, $C$ be pointed, let $\psi$ be a $-C$ representing functional, and let some $y \in Y$ with $T \subseteq \{\hat{y}\} + C\setminus\{0_y\}$. $\tilde{y}$ is a minimal element of the set $T$ if and only if there is some $a \in C\setminus\{0_y\}$ so that $(\tilde{y}, 1)$ is a unique minimal solution of the optimization problem

$$\min \lambda \text{subject to the constraint} \psi(y-\tilde{y} - \lambda a) \leq 0, \quad (y, \tilde{y}) \in T \times \mathbb{R}.$$

**Proof** Since $\psi$ is a $-C$ representing functional, the optimization problem (4.3) can also be rewritten as

$$\min \lambda, \quad y \in (\{\hat{y} + \lambda a\} - C) \cap T \in \mathbb{R}.$$

Next, we begin with the actual proof.

- a) Let there exist some $a \in C\setminus\{0_y\}$ so that $(\tilde{y}, 1)$ is a unique minimal solution of the optimization problem (4.4). Assume that $\tilde{y}$ is not a minimal element of the set $T$. Then there exists some $y \neq \tilde{y}$ with $y \in (\{\hat{y}\} - C) \cap T$. Because of the constraint $y \in (\hat{y} + a\} - C)$, we get with Proposition 1.1

$\tilde{y} - C \subseteq \{\hat{y} + a\} - C - C = \{\hat{y} + a\} - C.$

Then we conclude

$y \in (\hat{y} + a) - C) \cap T.$

Consequently, $(y, 1)$ is also a minimal solution of problem (4.4)—a contradiction to the assumption that $(\tilde{y}, 1)$ uniquely solves problem (4.3). Hence, $\tilde{y}$ is a minimal element of the set $T$.

- b) Now, let $\tilde{y}$ be a minimal element of the set $T$, i.e., $(\tilde{y} - C) \cap T = \{\hat{y}\}$. With $a := \tilde{y} - \hat{y} \in C\setminus\{0_y\}$, then have

$(\hat{y} + 1 \cdot a) - C) \cap T = \tilde{y}.$

Consequently, $(y, 1)$ is the only feasible point at objective level 1 of problem (4.4). If there were a feasible $(y, \lambda)$ with $\lambda < 1$, we would obtain

$y \in (\hat{y} + \lambda a) - C) \cap T = (\hat{y} + (1-\lambda) a) \cap T = \emptyset$

(notice that $-C = C$ because the convex cone $C$ is assumed to be pointed). So, the minimal value of problem (4.4) equals 1, and $(\tilde{y}, 1)$ is a unique minimal cone of the optimization problem (4.3). The scalarized problem (4.3) is a simple optimization problem, which can be used for determination of minimal elements of a nonconvex set $T$ with a lower bound $\hat{y}$.
