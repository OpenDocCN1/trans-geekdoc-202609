**Definition 4.3** Let Assumption 4.1 be satisfied. An element $	ilde{y} \in T$ is called a strongly minimal element of the set $T$ iff

$\tilde{y} \leq y \text{ for all } y \in T \quad (4.7)$

$\leq C$ denotes the preorder induced by **C**.

Figure 4.3 illustrates this strong optimality notion.

**Theorem 4.4** Let Assumption 4.1 be satisfied, and let $\psi$ be a $-C$ representing functional. Then we have

$\tilde{y}$ strongly minimal element of the set $T \Longleftrightarrow \sup_{y \in T} \psi(\tilde{y} - y) \leq 0.$

**Proof** By definition, $\tilde{y}$ is a strongly minimal element of the set $T$ iff the inequality (4.7) holds. This vector inequality can also be written as

$T \subseteq \{	ilde{y}\} + C.$

By Proposition 2.5, this is equivalent to the inequality

$\psi(\tilde{y} - y) \leq 0 \text{ for all } y \in T,$

which means that

$\sup_{y \in T} \psi(\tilde{y} - y) \leq 0.$

Hence, the assertion is proven.
