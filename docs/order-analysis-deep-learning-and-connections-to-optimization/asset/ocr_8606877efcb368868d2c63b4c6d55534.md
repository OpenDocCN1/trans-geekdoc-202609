+   (b) Let the copositive cone

$C := C^n = \{A \in \mathbb{S}^n \mid x^\top Ax \geq 0 \text{ for all } x \in \mathbb{R}^n_+\}$

chosen. the $-C$ representing functional $\psi : \mathbb{S}^n \to \mathbb{R}$ with

$$\psi(A) := \max_{\{x \in \mathbb{R}^n_+ \ \|x\|_2=1\}} x^\top Ax \text{ for all } A \in \mathbb{S}^n$

$(\|\cdot\_2$ denotes the Euclidean norm in $\mathbb{R}^n$) has the directional derivative of an arbitrary $\tilde{A} \in \mathbb{S}^n$ given by

$$\psi'(\tilde{A})(H) = \max_{x \in X(\tilde{A})} x^\top HX \text{ for all } H \in \mathbb{S}^n$

with

$X(\tilde{A}) := \{x \in \mathbb{R}^n_+ \mid \|x\|_2 = 1 \text{ and } \psi(\tilde{A}) = x^\top \tilde{A}\}$
