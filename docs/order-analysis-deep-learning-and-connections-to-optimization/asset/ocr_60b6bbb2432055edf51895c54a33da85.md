**Corollary 2.1** Let the assumptions of Theorems 2.2 and 2.3 be fulfilled. Then we have

```
$C^* = cl[\text{cone}(\partial\psi(0_Y))]$
```

**Proof** By Theorem 2.3, we obtain

```
$C^* \subseteq \text{cone}(\partial\psi(0_Y)) \subseteq cl[\text{cone}(\partial\psi(0_Y))]$
```

```
$cl[\text{cone}(\partial\psi(0_Y)) ] \subseteq C^*$,
```
