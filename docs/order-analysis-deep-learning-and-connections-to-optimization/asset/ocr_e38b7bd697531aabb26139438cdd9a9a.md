**Proposition 1.9** $(X, ||\cdot||)$ be a real normal space, and let $f : X \rightarrow \mathbb{R}$ be a continuous convex functional. Then the subdifferential $\partial f(\bar{x})$ is nonempty for every $ar{x} \in X$.

The following theorem establishes a relationship between the directional derivative and the subdifferential:

**Theorem 1.3** $(X, ||\cdot||)$ be a real normal space, and let $f : X \rightarrow \mathbb{R}$ be a convex functional.

+   (a) For an arbitrary $ar{x} \in X$, we have

```
$$\partial f(\bar{x}) = {\ell \in X^* \| f'(\bar{x}) \ge \ell(h) \text{for all } h \in X\}$
```

+   where $f'(\bar{x})$ denotes the directional derivative of $f$ at $\bar{x}$ in the direction $h$.
(b) In addition, let $f$ be continuous. Then for every $\bar{x}, h \in X$ the directional derivative of $f$ at $\bar{x}$ in the direction $h$ is given as

```
$$\f'(\bar{x}) = \max_{\ell \in \partial f(\bar{x})} \ell(h).$.
```

A useful subclass of the class of convex functionals is the strongly convex functionals, we restrict ourselves to functions defined on $\mathbb{R}^n$.

**Definition 1.25** Let the function $f : \mathbb{R}^n \rightarrow \mathbb{R}$ and some $\mu > 0$ be given. The function $f$ is called $\mu$-strongly convex if all $x, y \in \mathbb{R}^n$

```
$$\mu \frac{\lambda(1-\\lambda)}{2}||x-y||^2 + f(\lambda x + (1-\\lambda)y) \le \lambda f(x) + (1-\\lambda)f(y) \text{for all } \lambda \in [0, 1].$.
```

Strongly convex functionals can be characterized in a simple way.

**Proposition 1.10** ([42, Lemma 2.12]) Let the function $f : \mathbb{R}^n \rightarrow \mathbb{R}$ and some $\mu > 0$ be given. The function $f$ is $\mu$-strongly convex if and only if there exists a convex function $g : \mathbb{R}^n \rightarrow \mathbb{R}$ with

```
$$\f(x) = g(x) + \frac{\mu}{2}||x||^2 \text{for all } x \in \mathbb{R}^n.$.
```
