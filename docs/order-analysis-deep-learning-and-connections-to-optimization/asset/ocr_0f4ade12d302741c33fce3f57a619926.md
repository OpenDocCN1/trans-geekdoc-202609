# Definition 7.8 Let $X$ be a real linear space. For two sets $A, B \in C_c(X)$ with the associated constraint functionals $\psi_A$ and $\psi_B$, the *constraint distance* is defined by

```
$d_c(A, B) := \max_{a \in A} \left\{0, \sup \psi_B(a), \sup_{b \in B} \psi_A(b)\}\right\.$
```

# Theorem 7.3 Let $X$ be a real linear space. Then the constraint distance $d_c$ on the class $C_c(X)$ has the following properties:

+   (a) $d_c$ is nonnegative on $C_c(X)$, and for all $A, B \in C_c(X)$,

$d_c(A, B) = 0 \iff A = B$.

(b)
d_c(A, B) = d_c(B, A) for all $A, B \in C_c(X)$.

**Proof** Let $A, B \in C_c(X)$ be arbitrarily chosen.
(a) By Definition 7.8, it is evident that $d_c(A, B)$ is nonnegative. Further, with constraint functionals $\psi_A$ and $\psi_B$

```
$A = B \iff A \subseteq B \text{ and } B \subseteq A$
\iff \psi_B(a) \leq 0 \text{ for all } a \in A \text{ and } \psi_A(b) \leq 0 \text{ for all } b \in B$
\iff 0 \geq \sup_{a \in A} \psi_B(a) \text{ and } 0 \geq \sup_{b \in B} \psi_A(b)$
\iff \max \left\{0, \sup_{a \in A} \psi_B(a), \sup_{b \in B} \psi_A(b)\right\right. = 0$\n\iff d_c(A, B) = 0$.
```

(b) By Definition 7.8, it is obvious that

```
$d_c(A, B) = \max \left\{0, \sup_{a \in A} \psi_B(a), \sup_{b \in B} \psi_A(b)\right\right. = d_c(B, A)$,
```

which has to be shown.

By Theorem 7.3, the distance $d_c$ is only a semimetric on $C_c(X)$. In general, the triangle inequality does not hold.
Although the class $C_c(X)$ is also restrictive, the constraint distance $d_c$ has the crucial advantage that one has “standard” optimization problems to solve.
