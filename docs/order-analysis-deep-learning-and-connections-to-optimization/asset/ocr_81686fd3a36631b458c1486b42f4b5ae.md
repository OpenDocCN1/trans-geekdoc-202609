**Definition 1.16** Let $Y$ be a real space, and $X$ a nonempty subset of the algebraic dual space $Y'$.

+   (a) For every $x' \in X$, there is a seminorm $p : Y \to \mathbb{R}$ given by

```
$p(y) = |x'(y)|$ for all $y \in Y$.
```

The coarsest topology on $Y$ making all these linear functionals continuous is the weak topology on $Y$ generated by $X$, and is denoted $\sigma(Y, X)$ (it is the weakest topology on $Y$ in which all linear functionals belong to $X$ are continuous).

+   (b) If $Y$ is equipped with a topology, the subspace $Y^*$ of all linear functionals which belong to $Y^*$ is called the topological dual space of $Y$. For $X = Y^*$, $\sigma(Y, Y^*)$ is simply called the weak topology on $Y$.

**Definition 1.17** A real normal space $(Y, |\cdot|)$ is called reflexive if the canonical embedding $J_Y : Y \to Y^{**}$ (bidual space) defined is a real Banach space. For applications, the following assertion is important (see Holmes [64], p. 126–127):

```
$J_Y(y)(\varphi) := \varphi(y)$ for all $y \in Y$ and all $\varphi \in Y^*$.
```

Every reflexive real normal space is complete, and, therefore, it is a Banach space. (see Holmes [64], p. 126–127):

**Proposition 1.5** A real Banach space $(Y, |\cdot|)$ is reflexive if and only if the closed unit ball $\mathcal{B}(0y, 1)$ is weakly compact.

In this proposition, the term “weakly compact” means compact with respect to the weak topology. A nonempty subset of a real normal space is weakly compact if and only if it is sequentially convergent. To clarify this, we recall convergence.

**Definition 1.18** Let $(Y, |\cdot|)$ be a real normal space. A sequence $(y_n)_{n \in \mathbb{N}}$ of elements of $Y$ is called weakly convergent to $y \in Y$ iff for all continuous linear functionals $\ell$ on $Y$

```
$$\lim_{n \to \infty} \ell(y_n) = \ell(y)$.$
```

In this case, $y$ is called a weak limit of the sequence $(y_n)_{n \in \mathbb{N}}$.
