In the case of compact intervals in $\mathbb{R}$, the Hausdorff and constraint distance coincide according to Theorem 7.4. And for the intervals, which additionally contain 0, the radial distance is also equal to these two distances. This shows that the radial and constraint distances play out their advantages only in more complex situations.

## Deep Learning with Set-Valued Inputs

Finally, we consider a deep learning network with multiple interval-valued inputs and one interval-valued output.

**Theorem 7.5** *Let a training dataset with $p \in N$ instances of the form $[x^j_1, \overline{x^j_1}], \dots, [x^j_k, \overline{x^j_k}], [y^j, \overline{y^j}]$ for the $j$-th instance, $(j, k \in N)$ be. Let $n \in N$ denote the total number of biases, and let $m \in N$ denote the number of biases all hidden layers in a deep learning network. Then optimal weights and biases are obtained by solving the optimization problem*

$$\min_{j=1}^p \max {|y^j_{pred}(z) - \overline{y^j}|, |\overline{y^j_{pred}}(z) - y^j|}$$
$$\text{subject to}$$
$$b_i \le \overline{b_i} \text{ for all } i \in \{1, \dots, m\} \quad (7.17)$$
$$z := (w_1, \dots, w_n, b_1, \overline{b_1}, \dots, b_m, \overline{b_m}) \in \mathbb{R}^{n+2m}$$

$y^j_{pred}(\cdot), \overline{y^j_{pred}}(\cdot)$ denotes the predicted interval output of the $j$-th instance with $j \in \{1, \dots, p\}$ and $[y^j, \overline{y^j}]$ denotes the true interval output of the $j$-th instance.

**Proof** (7.13) in Lemma 7.1 can be used to determine the resulting interval output. By Theorem 7.4 and Corollary 7.1, we can work with the Hausdorff distance and observe the objective function

$$\sum_{j=1}^p d_H([y^j_{pred}(\cdot), \overline{y^j_{pred}}(\cdot)], [y^j, \overline{y^j}]) = \sum_{j=1}^p \max {|y^j_{pred}(\cdot) - \overline{y^j}|, |\overline{y^j_{pred}}(\cdot) - y^j|}$$

If we note the inequality constraints for the start and end points of bias intervals, the resulting optimization problem can be written in the form of problem (7.17). Problem (7.17) is a constrained optimization problem with linear inequality constraints. The higher number of artificial neurons in deep learning network, if one is interested in a differentiable objective function, one can also solve a modified problem as shown in the following:

**Proposition 7.7** *Let the assumptions of Theorem 7.5 be fulfilled. The point $\tilde{z}$ solves problem (7.17) with minimal value 0 if and only if $\tilde{z}$ solves the optimization*

$$\min_{j=1}^p (y_j^l(z) - y_j^l)^2 + (y_j^u(z) - y_j^u)^2$$
$$\text{subject to}$$
$$\underline{b}_i \le \bar{b}_i \text{ for all } i \in \{1, \dots, m\}$$
$$z := (w_1, \dots, w_n, \underline{b}_1, \dots, \underline{b}_m, \bar{b}_1, \dots, \bar{b}_m) \in \mathbb{R}^{n+2m} \quad (7.18)$$

The point $\tilde{z}$ solves problem (7.17) with minimal value 0 if and only if $\tilde{z}$ is feasible, i.e., constraints are satisfied:

$$\max \{|y_j^l(z) - y_j^l|, |y_j^u(z) - y_j^u|\} = 0 \text{ for all } j \in \{1, \dots, p\} \quad (7.19)$$

Equation (7.19) is equivalent to

$$y_j^l(z) - y_j^l = 0 \text{ and } y_j^u(z) - y_j^u = 0 \text{ for all } j \in \{1, \dots, p\}$$

which can be written as

$$(y_j^l(z) - y_j^l)^2 + (y_j^u(z) - y_j^u)^2 = 0 \text{ for all } j \in \{1, \dots, p\}.$$

This means that $\tilde{z}$ solves the optimization problem (7.18) with minimal value 0. By Proposition 7.6, the activation map $\mathcal{F}$ is not differentiable, and the objective function of the optimization problem (7.18) is not differentiable. For numerical computations, one could smooth the max term in Eq. (7.14) or choose some other suitable activation function.
