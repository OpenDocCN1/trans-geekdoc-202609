Under this assumption, we consider the conditional vector optimization problem in a simplified conceptual form

```
$\min \begin{cases} f_1(x), &\text{iff } x \in F_1 \n:\ng_k(x), &\text{iff } x \in F_k \end{cases}$\nsubject to the constraints\ng_1(x) \in -C_{Z_1}, \text{iff } x \in G_1\n:::\ng_m(x) \in -C_{Z_m}, \text{iff } x \in G_m\nx \in \hat{S}.$ (4.8)
```

This is not a standard vector optimization problem because or more objectives/constraints may vanish at some $x \in \hat{S}$. For this problem type, there are concrete applications in structural optimization and image registration of medical data, and there are relations to problems with switching constraints. For more information, see the bibliographical notes in Sect. 4.4.\nWe begin with a very simple example.

```
$\min \sin x$\nsubject to the constraints\n1 \le x \le 2\pi\ncos x \ge 0.4, \text{iff } x \in (\pi, 2\pi)\nx \in Z.$
```
