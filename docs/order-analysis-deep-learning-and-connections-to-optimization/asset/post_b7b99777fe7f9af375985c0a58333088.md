
## 3 Application in Nonlinear Optimization

Remark **3.1** By Jahn [72, Definition 8.1], a nonempty subset $\hat{S}_d$ of a linear space $X_d$ is called *discrete* if its elements are either finite or infinite. To be more concrete, a discrete set $\hat{S}_d \subseteq X_d$ can be written as $\hat{S}_d = \{x_d^i\}_{i\in N}$ for $N := \{1, 2, \dots, n\}$ ($n \in \mathbb{N}$) or $N := \mathbb{N}$ with elements $x_d^1, x_d^2, \dots \in X_d$. A discrete subset belonging to some nonempty subset $\hat{S}$ of a real linear space $X$. Next, we set $X := X_d \times X_c$ and $\hat{S} := \hat{S}_d \times \hat{S}_c$. **3.1.** In Assumption, the general optimization problem (3.1) can be written

```
$\min f(x_d, x_c)
subject to the constraint
g(x_d, x_c) \in -C
(x_d, x_c) \in \hat{S}$
```

This is a discrete-continuous nonlinear optimization problem. The subscripts $d$ and $c$ clarify the discrete-continuous structure, i.e., $x_d$ and $x_c$ are the continuous variables belonging to the $\hat{S}_d \subseteq X_d$ and $\hat{S}_c \subseteq X_c$, respectively. Thus, Assumption 3.1 also covers discrete-continuous nonlinear optimization problems with a general inequality constraint.

First, we select a basic simplicity condition.

**Lemma 3.1** ([35, Lemma 3.1]) *Assumption 3.1 be satisfied, and let some $\tilde{x} \in \hat{S}$ be given.*

(a) the vector $\tilde{x} \times (-C)$ is a unique minimal solution of problem (3.1) if and only if

```
$[-R_{++} \times (-C)] \cap \left\{ \frac{f(x) - f(\tilde{x})}{g(x)} \in R \times Y \middle| x \in \hat{S}, x \neq \tilde{x} \right\} = \emptyset. \quad (3.2)$
```

(b) the vector $\tilde{x}$ is a minimal solution of problem (3.1) if and only if

```
$[-R_{++} \times (-C)] \cap \left\{ \frac{f(x) - f(\tilde{x})}{g(x)} \in R \times Y \middle| x \in \hat{S} \right\} = \emptyset$.
```

$R_{++}$ denotes the set of all positive real numbers.

# Proof

- (a) (i) let $\tilde{x}$ be a unique minimal solution of the nonlinear optimization problem (3.1). We then have for all $x \in \hat{S}$ with $x \in S$ and $x \neq \tilde{x}$

```
$f(x) - f(\tilde{x}) > 0$ and $g(x) \in -C$.
```

Moreover, we get for all $x \in \hat{S}$ with $x \neq S$ that $g(x) \notin -C$. Hence, the condition (3.2) is fulfilled.

## 3.1 Optimality Conditions for a Unique Minimal Solution

(ii) Let $\tilde{x}$ be no unique minimal solution of the nonlinear optimization problem (3.1). Then there is $x \in S$ with $x \neq \tilde{x}$ so that

$f(x) - f(\tilde{x}) \leq 0 \text{ and } g(x) \in -C.$

The condition (3.2) is not fulfilled.

(b) The proof of part (b) follows the lines of the proof of part (a).

A more interesting optimality condition can be obtained if we additionally assume that there exists a $-C$ representing functional.

**Theorem 3.1** ([35, Theorem 3.6]) Let Assumption 3.1 be satisfied, let $\psi : Y \to \mathbb{R}$ be a $-C$ representing functional, and let some $\tilde{x} \in \hat{S}$ be given:

- (a) The vector $\tilde{x}$ is a unique minimal solution of problem (3.1) if and only if

```
$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\} \geq 0 \text{ for all } x \in \hat{S} \text{ with } x \neq \tilde{x}. \quad (3.3)$
```

- (b) If the vector $\tilde{x}$ is a unique minimal solution of problem (3.1), then

```
$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\} \geq 0 \text{ for all } x \in \hat{S}.$.
```

# Proof

- (a) By Lemma 3.1, $\tilde{x}$ is a unique minimal solution of problem (3.1) if and only if the equality (3.2) holds. Next, we prove for arbitrary $\alpha \in \mathbb{R}$ and $y \in Y$ the equivalence

```
$(\alpha, y) \in -\mathbb{R}_+ \times (-C) \iff \max(\alpha, \psi(y)) \leq 0. \quad (3.4)$
```

For the proof of this equivalence, we first assume that $\max(\alpha, \psi(y)) \leq 0$. Then we get $\alpha \leq 0$ and $y \in [0, i]$, $y \in -C$, and we have $(\alpha, y) \in -\mathbb{R}_+ \times (-C)$. Conversely, assume that $(\alpha, y) \in -\mathbb{R}_+ \times (-C)$. Then we get $\alpha \leq 0$ and $\psi(y) \leq 0$ implying that. With the equivalence (3.4) together with the equality (3.2), we obtain that $\tilde{x}$ is a unique minimal solution of problem (3.1) if and only if the condition (3.3) is fulfilled.

- (b) Let $\tilde{x}$ be a minimal solution of problem (3.1), and let $x \in \hat{S}$ be arbitrarily chosen. If $x \in S$, then $f(x) - f(\tilde{x}) \geq 0$, and we get

```
$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\} \geq 0.$
```

If $x \notin S$, then we have $g(x) \in -C$ equivalent to $\psi(x) > 0$, and we conclude

$\max \left\{f(x) - f(\tilde{x}), \psi(g(x))\right\} > 0.$

This completes the proof.

- (a) The optimality condition (3.3) in Theorem 3.1 (a) is equivalent to the statement $\tilde{x}$ is a unique minimal solution of problem (3.1).

- (b) By Remark 3.1, (3.1) is also valid for discrete problems.

## 3.1 Optimality Conditions for a Unique Minimal Solution

**Example 3.1** ([35, Example 3.1]) We investigate the discrete-continuous problem

```
$\min f(x_d, x_c)
subject to the constraint
g(x_d, x_c) \in -C
(x_d, x_c) \in \hat{S}$
```

where $\tilde{x} := (1,0)^T$ is the unique minimal solution of (3.6). By Remark 3.2, (3.6) can be written as

```
$\min f(x_d, x_c)
subject to the constraint
g(x_d, x_c) \in -C
(x_d, x_c) \in \hat{S}$
```

where $x \in \hat{S}$ with $x \neq \tilde{x}$ so that $f(x) - f(\tilde{x}) \leq 0$ and $g(x) \in -C$. The condition (3.2) is not fulfilled. Thus $\tilde{x}$ is no unique minimal solution of the nonlinear optimization problem (3.1).

Thus, Assumption 3.1 also covers discrete-continuous nonlinear optimization problems with a general inequality constraint.

- (b) The proof of part (b) follows the lines of the proof of part (a).

- (c) If we additionally assume that there exists $-C$ representing functional, we obtain that $\tilde{x}$ is a unique minimal solution of (3.1) if and only if (3.3) is fulfilled.
