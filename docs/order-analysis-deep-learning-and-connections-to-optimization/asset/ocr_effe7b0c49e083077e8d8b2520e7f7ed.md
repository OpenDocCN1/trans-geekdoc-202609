# Chapter 5
Application in Set Optimization

**Abstract** $-C$ or $-\mathcal{K}$ representing functionals are an important tool in set optimization. In this area of optimization, one investigates optimization problems with a set-valued objective map. But here we study these problems in a more general framework, that is, we ask about minimal sets within a family of sets. As in the previous chapter, we investigate problems with a fixed order structure given by a convex cone $C$, and those with a variable order introduced by a suitable set-valued map $\mathcal{K}$. In both cases, the main topic is the characterization of minimal sets.

# 5.1 Fixed Order Structure

In a first step, one needs an order relation for the comparison of nonempty sets. There are different order relations, which can be used in practice (e.g., compare Jahn and Ha [75]). For simplicity, we restrict ourselves to the well-known set less order relation introduced by Young [143] in 1931.

**Definition 5.1** Let $C$ be a convex cone in a real linear space $Y$. For nonempty subsets $A, B \subseteq Y$, the set less order relation $\preceq_C$ is defined by

```
$A \preceq_s B \iff (\forall b \in B \exists a \in A : a \preceq b) (\forall a \in A \exists b \in B : a \preceq b)\n(5.1)
```

$\preceq_C$ denotes the preorder induced by the convex cone $C$.
It is well-known that the equivalence $(5.1)$ in Definition $5.1$ can be written as

```
$A \preceq_s B \iff B \subseteq A + C \text{ and } A \subseteq B - C$
```

(compare Remark 1.1). Figure $5.1$ illustrates these two inclusions. If a $-C$ representing functional is given, these set inclusions can be simply characterized.
