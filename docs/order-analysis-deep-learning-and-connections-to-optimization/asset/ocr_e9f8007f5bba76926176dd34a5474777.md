**Proposition 5.1** ([73, Proposition 2.1]) Let $C$ be a convex cone in a real linear space $Y$, and let $\psi$ be $a-C$ representing functional. Then for arbitrary nonempty sets $A, B \subseteq Y$, we have

```
$B \subseteq A+C \quad \Longrightarrow \quad \sup_{b\in B, a\in A} \psi(a-b) \leq 0$$
$$\quadquad \Longrightarrow \quad \inf_{b\in B, a\in A} \psi(a-b) \leq 0 \text{ if this min term exists}$$
```

and

```
$A \subseteq B-C \quad \Longrightarrow \quad \sup_{a\in A, b\in B} \psi(a-b) \leq 0$$
$\quadquad \Longrightarrow \quad \inf_{a\in A, b\in B} \psi(a-b) \leq 0 \text{ if this min term exists}$
```

**Proof** For arbitrary nonempty sets $A, B \subseteq Y$, :

```
$B \subseteq A+C \quad \Longrightarrow \quad \forall b\in B \ \exists a\in A : \quad b \in \{a\}+C$$
$\quadquad \Leftrightarrow \quad a-b\in -C \Leftrightarrow \ \psi(a-b)\leq 0$$
```

```
$\sup_{b\in B, a\in A} \psi(a-b) \leq 0$$
$\quadquad \Longrightarrow \quad \min_{b\in B, a\in A} \psi(a-b) \leq 0 \text{ if this min term exists}$
```

For the proof of the second characterization, we only remark that

$A \subseteq B-C \quad \Longrightarrow \quad \forall a\in A \ \exists b\in B : \ a-b\in -C,$

which leads to the assertion.
