## 2.1 Bishop-Phelps, Penalty, and Scalarizing Functionals

![](img/e4a2e491dbba0d9f71abf293f149cd5b_40_0.png)

**Fig. 2.3** Illustration of the distance functional value at some $y \in Y$ (see [72], Fig. 2.10)

**Proposition 2.1** (See [144, Proposition 3.2, (4)]) Let $C$ be a closed preordered cone in a reflexive real Banach space $(Y, ||\cdot||)$ with $C \neq Y$. *Then we have*

$$-C = \{y \in Y \mid \Delta_{-C}(y) \leq 0\}$$

**Proof**

(a) Let $y \in -C$ be arbitrarily chosen. Then we have

$$\Delta_{-C}(y) = d_{-C}(y) - d_{Y\setminus(-C)}(y) \leq 0.$$

(b) For an arbitrarily chosen $y \notin -C$, it follows

$$\Delta_{-C}(y) = d_{-C}(y) - d_{Y\setminus(-C)}(y) = d_{-C}(y).$$

For the closed convex cone $-C$, there is some $\tilde{y} \in -C$ so that

$$\Delta_{-C}(y) = ||\tilde{y} - y|| > 0 \neq 0$$

(compare [72, Thm. 2.18], which follows from Theorem 1.2). Hence, we conclude $\Delta_{-C}(y) > 0$.

Under appropriate assumptions, Proposition 2.1 states that the negative convex cone equals the sublevel set of the signed distance functional $\Delta_{-C}$ with respect to the level 0.

## 2.2 Representing Functionals

Another well-known scalarizing functional was introduced by Tammer (formerly Gerstewitz) [43] in 1983.

**Definition 2.4** Let $S$ be a nonempty subset of a real linear space $Y$, and let $k \in Y\setminus\{0_Y\}$ be arbitrarily given. The functional $\xi_{S,k} : Y \to \mathbb{R} := \mathbb{R} \cup \{-\infty\} \cup \{+\infty\}$ with

$$\xi_{S,k}(y) := \inf\{t \in \mathbb{R} \mid y \in \{tk\} + S\} \text{ for all } y \in Y$$

(where $\inf \emptyset := +\infty$ is called *Gerstewitz scalarizing functional*.)

Under the assumptions of Definition 2.4, the functional $\xi_{S,k}$ is also said to be translation invariant along $k$ (compare Tammer and Weiner [132] and the references therein). In mathematical finance, this type of functionals plays an important role in the theory of risk measures (see Artzner, Delbaen, Eber, and Heath [8]).

For our investigations, the following property of this functional is crucial:

**Proposition 2.2** (see, Theorem 5.2.3) Let $Y$ be a real topological linear space, and let $C$ be a closed preordered cone in $Y$ with $C \neq Y$ and $C \neq \{0_Y\}$. For every $k \in C\setminus\{0_Y\}$, we have

$$-C = \{y \in Y \mid \xi_{-C,k}(y) \leq 0\}.$$

### **Proof**

- (a) Let $y \in -C$ be arbitrarily chosen, i.e., $y-0k \in -C$. Then we get immediately

$$\xi_{-C,k}(y) := \inf\{t \in \mathbb{R} \mid y-tk \in -C\} \leq 0 \text{ for all } y \in Y.$$

- (b) Choose an arbitrary $y \in Y$ with $\xi_{-C,k}(y) \leq 0$. Since $C$ is closed, there exists some $t \leq 0$ so that with Proposition 1.1

$$y \in \{tk\} - C \subseteq -C - C = -C.$$

Hence, we conclude $y \in -C$.

Proposition 2.2 implies under appropriate assumptions that a negative convex cone equals the set of solutions of an inequality given by a Gerstewitz scalarizing functional. In mathematical finance, a sublevel set given by a risk measure with respect to the level 0 is also called *acceptance set* (see Artzner, Delbaen, Eber, and Heath [8, Definition 2.3]).

## Definition and Examples

The results of the previous section open the door to a unified approach to the representation of a negative cone by cones of a more general inequality. Now, we introduce functionals representing a negative convex cone in a real linear space.

For our studies, we make the following standard assumption:

**Assumption 2.1** $Y$ be a real linear space and let $C$ a convex cone in $Y$.

Under this assumption, we describe the convex cone $-C$ using a special functional $\psi$ defined as:

**Definition 2.5** ([35, Remark 3.3], [73, Assumption 2.1], [74, Definition 3.1]) Let Assumption 2.1 be satisfied. A functional $\psi : Y \rightarrow \mathbb{R}$ is called $-C$ representing iff

$$-C=\{y \in Y \mid \psi(y) \leq 0\}$$

It is obvious from Remarks 2.1 and 2.2 and Propositions 2.1 and 2.2 that the Bishop-Phelps functional $\varphi$, the penalty function $\eta$, the signed distance function $\Delta_{-C}$, and the Gerstewitz scalarizing function $\xi_{-C,k}$ are $-C$ functionals.

**Example 2.3** ([74, Example 3.1]) As a simple illustrative example, we consider the special case $Y = \mathbb{R}^2$ and $C := \mathbb{R}^2_+$. Then we obtain

$$-C=\{(y_1, y_2) \in \mathbb{R}^2 \mid y_1, y_2 \leq 0\}$$ s.t., the function $\psi_1 : \mathbb{R}^2 \rightarrow \mathbb{R}$ with

$$\psi_1 := \max(y_1, y_2) \text{ for all } y = (y_1, y_2) \in \mathbb{R}^2$$

is $-C$ representing. Figure 2.4 illustrates the function $\psi_1$. It is evident that the function $\psi_1$ is continuous but nonsmooth. A continuously differentiable representing function can be obtained if we choose $\psi_2 : \mathbb{R}^2 \rightarrow \mathbb{R}$

$$\psi_2(y) := (\max(y_1, 0)) \text{ for all } y = (y_1, y_2) \in \mathbb{R}^2$$

The function $\psi_2$ is illustrated in Fig. 2.5. For numerical optimization, it is well-known that $\psi_2$ is a penalty function with respect to $\mathbb{R}^2_+$.

(a) It is evident that a $-C$ representing functional $\psi$ also gives a representation of the convex cone $C$, i.e.,

$$C = \{y \in Y \mid \psi(-y) \le 0\}.$$

(b) Example 2.3 shows that a functional $\psi$ is not uniquely defined by the set equality (2.1).

(c) Using the equivalence in Remark 1.1 and the equality in Remark 2.3 (a), we obtain that for every $y^1, y^2 \in Y$ the equivalence

$$y^1 \le y^2 \iff \psi(y^1 - y^2) \le 0$$

holds, where $\le_C$ denotes the preorder in $Y$ induced by the convex cone $C$. Hence, a preorder inequality can be written as a standard inequality in $\mathbb{R}$. Consequently, results from analysis can be applied to order theory. This fact is a basis for order analysis. Hence, the investigation of a certain inequality analysis simplifies the investigation of a preorder inequality.

For specific spaces and order cones, we now present $-C$ representing functionals that are useful in practice.

**Example 2.4** ([35, Example 3.4, (c)]) In the infinite-dimensional real linear space $Y := C[a, b]$ of real-valued continuous functions on $-\infty < a < b < \infty$, the functional $\psi : C[a, b] \to \mathbb{R}$ given

$$\psi(y) := \max y(t) \text{ for all } y \in C[a, b]$$

is $-C$ representing for the natural order cone

$$C := \{y \in C[a, b] \mid y(t) \geq 0 \text{ for all } t \in [a, b]\}.$$

Next, we investigate finite-dimensional spaces of real symmetric matrices.

**Example 2.5** ([35, Example 3.4, (b)]) We consider the real linear space $Y := \mathcal{S}^n$ (with $n \in \mathbb{N}$) of real $(n, n)$ matrices. Then the functional $\psi : \mathcal{S}^n \to \mathbb{R}$ with

$$\psi(A) := \max{\lambda_1, \dots, \lambda_n} \text{ for all } A \in \mathcal{S}^n$$

(here, $\lambda_1, \dots, \lambda_n$ denote the $n$ eigenvalues of the matrix A) is $-C$ representing for the well-known Löwner cone

$$C := \{A \in \mathcal{S}^n \mid \text{Positive semidefinite}\} = \mathcal{S}^n_+.$$

And the functional $\psi : \mathcal{S}^n \to \mathbb{R}$

$$\psi(A) := \max_{x \in \mathbb{R}^n, ||x||_2=1} x^T A x \text{ for all } A \in \mathcal{S}^n$$

is $-C$ representing for the positive cone

$$C' := \{A \in \mathcal{S}^n \mid x^T A x \geq 0 \text{ for all } x \in \mathbb{R}^n_+\}$$

(here, $||cdot||_2$ denotes the Euclidean norm in $\mathbb{R}^n$).

Finally, we consider the finite-dimensional space $\mathbb{R}^m$.
