# 2.4 Sublinearity

# Proof

(a) $y \in Y$ with $\psi(y) < 0$ be arbitrarily chosen. For any $h \in Y$, there is some sufficiently small $\lambda > 0$ with

```
$$\psi(y + \lambda h) \le_{\psi<0} \psi(y) + \lambda\psi(h) < 0$ for all $\lambda \in [0, \tilde{\lambda}].$
```

This implies $y \in \text{core}(-C)$. By assumption, there exists some $\bar{y} \in Y$ with $\psi(\bar{y}) < 0$. Then there is some $\lambda > 0$ with $-\lambda\bar{y} \in -C$. Consequently, we obtain

```
$$\psi(y) = \psi(y - \lambda\bar{y} + \lambda\tilde{y}) \le_{\psi<0} \psi(\\lambda\tilde{y}) \le \lambda\psi(\tilde{y}) < 0$.
```

which has to be shown.

Under the assumptions of Theorem 2.1, it then follows

```
$$\text{core}(-C) = \{y \in Y \mid \psi(y) < 0\}$
```

if the latter is not empty. Hence, we have a very simple characterization of the core of $-C$.

**Proposition 2.8** ([74, Proposition 3.7]) Let Assumption 2.1 be satisfied, and let $\psi$ be a $-C$ representing sublinear functional. If there exists some $\bar{y} \in Y$ with $\psi(\bar{y}) < 0$, then the convex $C$ is producing, i.e., $Y = C - C$.

*Proof* Since the intersection $C \subseteq C$ is valid, we only prove $Y \subseteq C - C$. By Theorem 2.1 (a), for every $y \in Y$, there is some $\lambda > 0$ with $\lambda y + \lambda\bar{y} \in -C$. And we conclude

```
$$\y \in \{-\frac{1}{2}Y} - \frac{1}{2}C \subseteq C - C$.$
```

Hence, the convex $C$ is producing.

In the case of the Bishop-Phelps functional $\varphi_\ell$ (see Remark 2.1), the existence of some $\bar{y} \in Y$ with $\varphi_\ell(\bar{y}) < 0$ can be simply ensured.

**Proposition 2.9** ([74, Proposition 3.8]) Let $(Y, ||\cdot||)$ be a real normed space, and let $C(\ell) := \{y \in Y \mid \ell(y) \ge ||\ell||\}$ be a Bishop-Phelps set for some $\ell \in Y^*$ with the $-C(\ell)$ representing functional $\varphi_\ell := \ell + ||\cdot||$. If $|\ell||^*} > 1$, then there exists some $y \in Y\setminus\{0\\}$ with $\varphi_\ell(y) < 0$.
