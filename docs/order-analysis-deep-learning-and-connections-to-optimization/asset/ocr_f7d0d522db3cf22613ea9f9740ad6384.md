# 2.7 Zeros

It is obvious from the definition of a $-C$ representing functional $\psi$ that the zeros of $\psi$ belong to the negative convex cone of the real space. For the functional $\psi_1$ in the illustrative Example 2.3, we know that the set of zeros equals the boundary of $-C$ (see Fig. 2.4). But for the functional $\psi_2$ given in Example 2.3 (compare Fig. 2.5), the set of all zeros equals the negative convex cone $-C$. Functionals with this property are studied in this section.

Example 2.10 ([74, Example 3.4]) As in Example 2.3, let the convex cone $C := \mathbb{R}^2_+ \subset \mathbb{R}^2$ be given. But now we consider the $-C$ representing functional $\psi : \mathbb{R}^2 \to \mathbb{R}$ with

```
$$$\psi(y) := max(y_1, y_2) \text{ for all } y = (y_1, y_2) \in \mathbb{R}^2 \quad (2.14)$$
```

(compare Fig. 2.6). It is evident that

```
$$-\mathbb{R}^2_+ = \{y \in \mathbb{R}^2 \mid \psi(y) = 0\},$$
```

i.e., the convex cone $-C$ equals the set of all zeros of the functional $\psi$. The continuously differentiable function $\psi_2$ given by (2.3) also has this property (compare Fig. 2.5).
