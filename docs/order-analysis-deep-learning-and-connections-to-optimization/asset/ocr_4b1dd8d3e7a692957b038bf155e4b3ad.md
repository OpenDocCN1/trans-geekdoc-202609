# 7.4 Distance Between Sets

Proof Let $(A_k)_{k\in\mathbb{N}}$ be an infimal sequence of predicted feasible sets, i.e., we have

```
$$\lim_{k\to\infty} d_r(A_k, S_{true}) = \inf |d_r(S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m), S_{true})| \mid w_1, \dots, w_n \in \mathbb{R};\nB_1, \dots, B_m \in \widehat{P}(X).$$
```

Since the system of all feasible sets is sequentially compact, there has a subsequence $(A_{ki})_{i\in\mathbb{N}}$ converging to some feasible predicted set $\tilde{A}$. We then obtain with the triangle inequality of radial metric

```
$$\lim_{\ell\to\infty} d_r(A_{ki}, S_{true}) \geq \lim_{\ell\to\infty} (d_r(\tildetilde{A}, S_{true}) - d_r(\tildetilde{A}, A_{ki}))\n= d_r(\tildetilde{A}, S_{true}) - \lim_{\ell\to\infty} d_r(\tildetilde{A}, A_{ki})\n=0\n= d_r(\tildetilde{A}, S_{true}).$$
```

From the equality (7.11) then results

```
$$\d_r(\tilde{A}, S_{true})\n\leq inf \{d_r(S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m), S_{true}) \ \mid w_1, \dots, w_n \in \mathbb{R};\nB_1, \dots, B_m \in \widehat{P}(X).$$
```

Hence, $\tilde{A}$ is a minimal solution of the optimization problem (7.11) with associated real numbers $\tilde{w}_1, \dots, \tilde{w}_n$ and $\tilde{B}_1, \dots, \tilde{B}_m \in \widehat{P}(X)$.

A minimal solution of the optimization problem (7.10) can be obtained by solving the problem

```
$$\min_{x\in S(X)} \sup |\varphi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(x) - \varphi_{S_{true}}(x)|\nsubject to\nw_1, \dots, w_n \in \mathbb{R}; \quad B_1, \dots, B_m \in \widehat{P}(X).$$
```

Using a slack variable, this problem can be rewritten as

```
$$\min \lambda\nsubject to\n-\\lambda \leq \varphi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(x) - \varphi_{S_{true}}(x) \leq \lambda \quad$ for all $x \in S(X)\nw_1, \dots, w_n \in \mathbb{R}; \quad B_1, \dots, B_m \in \widehat{P}(X).$$
```
