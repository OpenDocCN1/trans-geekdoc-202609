**Remark 2.4** ([73, Remark 4.2]) If in Proposition 2.13 (a) the maximal eigenvalue of a matrix $\tilde{A} \in \mathcal{S}^n$ is simple, then the associated normed eigenvector $\tilde{x}$ is unique, and the set $X(\tilde{A})$ consists of this vector. In this special case, the directional derivative is given as

```
$$\Psi'(\tilde{A})(H) = \tilde{x}^{\mathsf{T}}H\tilde{x} \text{ for all } H \in \mathcal{S}^n.$$$
```

The maximal eigenvalue of $\tilde{A}$ is a double eigenvalue, then the set $X(\tilde{A})$ is a circle in a two-dimensional subspace of $\mathcal{S}^n$ spanned by the associated eigenvectors. Let $\tilde{x}^1$ and $\tilde{x}^2$ be orthogonal normed eigenvectors associated with the maximal eigenvalue of $\tilde{A}$. Then this subspace is spanned by $\tilde{x}^1$ and $\tilde{x}^2$, and we have

```
$$\X(\tilde{A}) = {\alpha\tilde{x}^1 + \beta\tilde{x}^2 \mid \alpha, \beta \in \mathbb{R} \text{ and } \|\alpha\tilde{x}^1 + \beta\tilde{x}^2\|_2 = 1\}.$$
```
