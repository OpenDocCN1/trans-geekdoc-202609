**Corollary 4.2 ([74, Corollary 4.1])** *Let the assumptions in Theorem 4.5 be satisfied. In addition, let $\psi(0, \tilde{y})=0$ be fulfilled for some $y \in T$. Then we have*

+   (a) $\tilde{y}$ nondominated element of $T \Leftrightarrow \tilde{y}$ unique minimal solution of $\psi(y-\tilde{y}, y)$.
(b) $\tilde{y}$ minimal element of $T \Leftrightarrow \tilde{y}$ unique minimal solution of $\psi(y-\tilde{y}, y)$.

**Proof**

+   (a) By Theorem 4.5 (a) and the assumption $\psi(0, \tilde{y})=0$, we have

$\tilde{y}$ is a nondominated element of the set $T$

```
$\Leftrightarrow \psi(y-\tilde{y}, \tilde{y})>0=\psi(0, \tilde{y})=\psi(y-\tilde{y}, \tilde{y})$ for all $y \in T\setminus{\tilde{y}\$
$$\Leftrightarrow \tilde{y}$ unique minimal solution of $\min \psi(y-\tilde{y}, \tilde{y}),$
```

which has to be shown.

+   (b) In a similar way as in the proof of part (a), we obtain

$	ilde{y}$ is a minimal element of the set $T$

```
$\Leftrightarrow \psi(y-\tilde{y}, \tilde{y})>0=\psi(y-\tilde{y}, \tilde{y})$ for all $y \in T\setminus{\tilde{y}\$
$$\Leftrightarrow \tilde{y}$ unique minimal solution of $\min \psi(y-\tilde{y}, \tilde{y}),$
```

which completes the proof.
