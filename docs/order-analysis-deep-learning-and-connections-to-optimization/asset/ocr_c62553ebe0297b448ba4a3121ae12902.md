# # Chapter 4
Application in Vector Optimization

**Abstract** Vector optimization is a typical application of $-C$ or $-\mathcal{K}$ representing functionals. Here, we study general problems of vector optimization involving those with vector-valued objective map. We investigate vector optimization problems with a fixed order structure given by a convex cone $C$, which is sometimes assumed to be pointed, and those with a variable order structure. Another topic are so-called conditional vector optimization problems, where individual objective functions andor constraints can "vanish."

# ## 4.1 Fixed Order Structure

We start our investigations with a fixed preorder cone given in a real linear space.

**Assumption 4.1** Let $Y$ be a real linear space, let $C$ be a convex cone in $Y$, and let $T$ be a nonempty subset of $Y$.

Although there are various optimality notions in use, we restrict ourselves to the known notion of minimal elements of a set (for instance, compare [69]), and give a brief overview of weakly minimal and strongly minimal elements.

**Definition 4.1** Assumption 4.1 be satisfied, and let $C$ be pointed. An element $\hat{y} \in T$ is called a *minimal* element of the set $T$ iff

```
$y \le \hat{y}, y \in T \implies y = \hat{y} \quad (4.1)$
```

$\le$ denotes the partial order induced by $C$.

Under the assumptions of Definition 4.1, we ask for minimal elements of the set $T$ (see Fig. 4.1). For the sake of simplicity, we do not work with the definition of minimality for a nonconvex cone $C$, which is different and subsumes the aforementioned notion (compare [69], Definition 4.1, [a]).
