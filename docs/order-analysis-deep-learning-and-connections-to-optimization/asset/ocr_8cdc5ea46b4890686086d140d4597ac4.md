# Preliminaries

For an arbitrary $\lambda \in \mathbb{R}$, the notation $\lambda S$ is used as

$\lambda S := \{\lambda s \mid s \in S\}$.

It is important to note that the set equation $S + S = 2S$ in general does not hold a nonempty subset $S$ of a real linear space.

**Definition 1.3** Let $Y$ be a real linear space. The set $Y'$ is defined to be the set of all linear functionals from $Y$ to $\mathbb{R}$. If we define for all $\varphi, \psi \in Y'$ and all $\lambda \in \mathbb{R}$

$(\varphi + \psi)(y) := \varphi(y) + \psi(y)$ for all $y \in Y$

and

$(\lambda\varphi)(y) := \lambda \varphi(y)$ for all $y \in Y$,

then $Y'$ is a real linear space itself, and it is called the algebraic dual space of $Y$.

**Definition 1.4** Let $S$ be a subset of convex.

+   (a) The set $S$ is called convex iff for all $x, y \in S$

$\lambda x + (1 - \lambda)y \in S$ for all $\lambda \in [0, 1]$

(see Fig. 1.1).

+   (b) Let the set $S$ be nonempty. $S$ is called starshaped with respect to some $ar{x} \in S$ iff for every $x \in S$

$\lambda x + (1 - \lambda)\bar{x} \in S$ for all $\lambda \in [0, 1]$

+   (c) Let the set $S$ be nonempty and convex. A functional $f : S \to \mathbb{R}$ is called convex iff all $x, y \in S$

$f(\lambda x + (1 - \lambda)y) \le \lambda f(x) + (1 - \lambda) f(y)$ for all $\lambda \in [0, 1]$

(see Figs. 1.2 and 1.3).
