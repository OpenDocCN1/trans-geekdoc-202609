# Algorithm 6.5 (Mini-batch stochastic gradient method) [42, Algorithm 6.1])

+   Input: $f_1, \dots, f_p : \mathbb{R}^n 	o \mathbb{R}$, starting vector $x^0 \in \mathbb{R}^n$.
batch size $b \in \{1, \dots, p\}$, maximal iteration number $i_{\max}$.

```
$i := 0 // initialization
while $i \le i_{\max}$ do
  $B_i := \{1, \dots, p\}$ // sampled uniformly among sets of size $b$
  $d^i := -\sum_{k \in B_i} \nabla f_k(x^i)$ // iteration direction
  choose $\lambda_i > 0$ // step size
  $x^{i+1} := x^i + \lambda_i d^i$
  $i := i + 1$
end
```

# Remark 6.8 ([42, Algorithm 6.2 and Following Note])

Each batch $B_i$ in line 6 of Algorithm 6.5 is sampled with probability

$$\frac{b!(p-b)!}{p!}{inom{p}{b}}$

In line 7 of the mini-batch stochastic gradient method, the computation of gradients $\nabla f_k(x^i)$, with $k \in B_i$, can be accelerated on parallel computer architectures.

Next, for the mini-batch stochastic gradient method, we cite a convergence result by Garridos and Gower [42].

**Theorem 6.5** (Convergence of the Mini-batch Stochastic Gradient Method) [42, Algorithm 6.11]) Let the functions $f_1, \dots, f_p : \mathbb{R}^n 	o \mathbb{R}$ with $n, p \in \mathbb{N}$ and $p > 1$ be differentiable, convex, and bounded from below, let the objective function $f : \mathbb{R}^n 	o \mathbb{R}$ be defined by (6.17). For each $j \in \{1, \dots, p\}$, let the gradients $\nabla f_j$ be Lipschitz continuous, i.e., there exists Lipschitz constant $L_j > 0$ such that

> $$\|\nabla f_j(y) - \nabla f_j(x)\|_2 \le L_j \|x - y\|_2$ for all $x, y \in \mathbb{R}^n$.

The objective function $f$ is $\mu$-strongly convex for $\mu > 0$ (Definition 1.25). Furthermore, let $(x^i)_{i \in \mathbb{N}}$ be a sequence generated by Algorithm 6.5 with a constant step size $\lambda$ (i.e., $\lambda_i = \lambda$ for all $i \in \mathbb{N}$) satisfying $0 < \lambda < \min \{\frac{1}{\mu}, \sum L_j\}$ with

$L_b := \frac{p(b-1)}{n} \sum_{j=1}^b L_j + (p-b) \max_{t \le j \le p} L_j$.
