### 1.1 Linear Spaces and Convexity

First, we recall the definition of a real linear space and present some other notions.

**Definition 1.1** Let $Y$ be a given set. Assume that there is an addition on $Y$, i.e., a map from $Y \times Y$ to $Y$, and a scalar multiplication on $Y$, i.e., a map from $\mathbb{R} \times Y$ to $Y$, are defined. The set $Y$ is called a *real linear space* if the following axioms are satisfied (for arbitrary $x, y, z \in Y$ and $\lambda, \mu \in \mathbb{R}$):

- (a) $x + y + z = x + (y + z)$.
- (b) $x + y = y + x$.
- (c) There is an element $0 \in Y$ with $x+0 = x$ for all $x \in Y$.
- (d) For every $x \in Y$, there is a $y \in Y$ with $x+y=0$.
- (e) $\lambda(x + y) = \lambda x + \lambda y$.
- (f) $(\lambda + \mu)x = \lambda x + \mu x$.
- (g) $\lambda(\mu x) = (\lambda\mu)x$.
- (h) $1x = x$.

The element $0$ given under (c) is the *zero element* of $Y$.

**Definition 1.2** Let $S$ and $T$ be nonempty subsets of a real linear space $Y$. Then we define the *algebraic sum* of $S$ and $T$ as:

$S + T := \{s + t \mid s \in S \text{ and } t \in T\}$

and the *algebraic difference* of $S$ and $T$ as:

$S - T := \{s - t \mid s \in S \text{ and } t \in T\}$

**Definition 1.3** Let $Y$ be a real linear space. The set $Y'$ is defined to be the set of all linear functionals from $Y$ to $\mathbb{R}$. If we define for all $\varphi, \psi \in Y'$ and all $\lambda \in \mathbb{R}$:

$(\varphi + \psi)(y) := \varphi(y) + \psi(y)$ for all $y \in Y$

and

$(\lambda\varphi)(y) := \lambda \varphi(y)$ for all $y \in Y$,

then $Y'$ is a real linear space itself, and it is called the algebraic dual space of $Y$.

### 1.2 Preordered Linear Spaces and Convex Cones

We start with the definition of a preorder in a real linear space.

**Definition 1.8** Let $Y$ be a real linear space.

- (a) Every nonempty subset $R$ of the product space $Y \times Y$ is called a binary relation on $Y$ (one writes $xRy$ for $(x, y) \in R$).
- (b) Every binary relation $\leq$ on $Y$ is called a preorder on $Y$ iff for arbitrary $w, x, y, z \in Y$:
(i) $y \leq y$ (reflexivity),
(ii) $x \leq y, y \leq z \Rightarrow x \leq z$ (transitivity),
(iii) $x \leq y, w \leq z \Rightarrow x + w \leq y + z$ (compatibility with the addition),
(iv) $x \leq y, \alpha \in \mathbb{R}_+ \Rightarrow \alpha x \leq \alpha y$ (compatib. with the scalar multiplication).
- (c) A preorder $\leq$ on $Y$ is called antisymmetric iff for arbitrary $x, y \in Y$:
$x \leq y, y \leq x \Rightarrow x = y.$

An antisymmetric preorder is said to be a *partial order*.

- (d) A real linear space equipped with a preorder is called a *preordered linear space*, and a real linear space equipped with a partial order is called a *partially ordered linear space.*
