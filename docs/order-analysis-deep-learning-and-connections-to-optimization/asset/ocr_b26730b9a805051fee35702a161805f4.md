An artificial neuron is a mathematical formalization of a biological neuron, as shown in Fig. 6.2. For simplicity, an artificial neuron is often simply called a neuron when there is no confusion with biological situation. Each artificial neuron can have several inputs $x_1, \dots, x_k \in \mathbb{R}$ (with $k \in \mathbb{N}$) and one output $\hat{y} \in \mathbb{R}$. Inside this artificial neuron, each input $x_i$ (with $i \in \{1, \dots, k\}$) is multiplied by some weight $w_i \in \mathbb{R}$. The sum of these terms is added with some bias $b \in \mathbb{R}$. Then a so-called activation function $\varrho : \mathbb{R} 	o \mathbb{R}$ is applied to this final result, which gives the output of this artificial neuron. In other words, the output $\hat{y}$ can be written as

```
$$\hat{y} = \varrho\left(\sum_{i=1}^{k} w_ix_i + b\right) = \varrho(w^T x + b)$
```
