**Proposition 7.3** $(X, ||\cdot||)$ be a real normed space, and let the sets $A, B \in \hat{P}(X)$ be arbitrarily chosen. If the set $A$ is compact, then the optimization problem

```
$$\sup \inf |\a - b||$\n$$a \in A \ b \in B$$
```

has a maximal solution.

```
$$\varphi(a) := \inf |\a - b|| \text{ for all } a \in A.$$\n$$b \in B$$
```

```
$$\sup \inf |\a - b|| = \sup \varphi(a) = \lim_{k \to \infty} \varphi(a_k).$\n$$a \in A \ b \in B$$
```

```
$$\sup \inf |\a - b|| = \lim_{\ell \to \infty} \varphi(a_{\ell}).$\quad (7.6)$$\n$$a \in A \ b \in B$$
```
