$w := (w_1, \dots, w_k)$ and $x := (x_1, \dots, x_k)$. The activation function $\varrho$ should be chosen in an appropriate way; some common examples of activation functions are discussed in Sect. 6.4. For a given input vector $x$, the output $\hat{y}$ is determined by the choice of the weight vector $w$, the bias $\hat{b}$, and the activation function $\varrho$.

# 6.3 Deep Neural Network

Solving complex AI problems typically requires a sophisticated network of artificial neurons. Figure 6.3 shows a so-called *feedforward neural network* (FNN), which means that the information flows forward, *i.e.*, from the input nodes (without cycles or loops) through the hidden nodes to the output nodes. In a neural network, a collection of elements aligned vertically on a straight line is called a *layer* (in Fig. 6.3, a layer is represented by a thick colored line). One distinguishes between an input layer, several hidden layers, and an output layer. The *input layer* provides the input to the network and the *output layer* consists of neurons that compute an output as a result of the network. *Hidden layers*, which do the main work of computation of complex relationships, are located between input and output layers, and work behind the scenes because there is no direct output (although modern software can reveal the background). are hidden.
