# 7.4 Distance Between Sets

Theorem 7.2 cannot be extended to the class $C_c(X)$ since the triangle inequality is not satisfied in general. Nevertheless, a set $S_{true}$ can be reasonably approximated by a set $S_{pred}$.

**Proposition 7.5** Let Assumption 7.1 be satisfied. If the optimization problem

```
$$\min d_c(S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m), S_{true})$$
$\text{subject to}$$
$$w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X)$ $(7.12)$
```

(the system of all sets arising in the objective function is assumed to be contained in the class $C_c(X)$ with a minimal solution $(\widetilde{w}_1, \dots, \widetilde{w}_n, \widetilde{B}_1, \dots, \widetilde{B}_m)$ with minimal value 0, then

$S_{pred}(\widetilde{w}_1, \dots, \widetilde{w}_n, \widetilde{B}_1, \dots, \widetilde{B}_m) = S_{true}$.

**Proof** For every minimal solution $(\widetilde{w}_1, \dots, \widetilde{w}_n, \widetilde{B}_1, \dots, \widetilde{B}_m)$ of problem (7.12) with minimal value 0,

```
$d_c(S_{pred}(\widetilde{w}_1, \dots, \widetilde{w}_n, \widetilde{B}_1, \dots, \widetilde{B}_m), S_{true}) = 0$.
```

With Theorem 7.3 (a) then follows the assertion. $\square$

Using the definition of the constraint distance, the optimization problem (7.12) can be written in the form

```
$$\min \begin{array}{c} 0, & \sup \Psi_{S_{true}}(a), \sup_{b \in S_{true}} \Psi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(b) \ a \in S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)} \end{array} $$$
$\text{subject to}$$
$$w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X)$.$
```

which again can be rewritten as

```
$$\min \lambda$$\$
$\text{subject to}$$
$$$\lambda \ge 0$$\$
$$$\lambda \ge \Psi_{S_{true}}(a) \text{ for all } a \in S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)$$
$$$\lambda \ge \Psi_{S_{pred}(w_1, \dots, w_n, B_1, \dots, B_m)}(b) \text{ for all } b \in S_{true}$$
$$w_1, \dots, w_n \in \mathbb{R}; B_1, \dots, B_m \in \widehat{P}(X).$.$$
```

Also in the case of constraint sets, one obtains a semi-infinite optimization problem with finitely many variables and infinitely many constraints.
