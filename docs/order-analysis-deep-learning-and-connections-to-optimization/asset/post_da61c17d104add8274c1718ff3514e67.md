
## 6.6 Gradient Methods

**Remark 6.5 (Justification of the Iteration Direction)** Let the objective function $f$ be differentiable, and let $x^{i-1}, x^i \in \mathbb{R}^n$ (with $i \in \mathbb{N}$) be two arbitrary iteration points of Algorithm 6.3. We consider the quasi-Newton equation (6.11). The matrix $B^i$ in the quasi-Newton equation is now chosen in the class of $(n, n)$ diagonal matrices with real entries. For simplicity, we replace the matrix $B^i$ by the diagonal matrix

![](img/e4a2e491dbba0d9f71abf293f149cd5b_129_0.png)

where $b^{i} := (b_1^i, \dots, b_n^i) \in \mathbb{R}^n$. In this case, the quasi-Newton equation (6.11) can be written componentwise as

```
$b_k^i(x_k^i - x_k^{i-1}) = \frac{\partial f}{\partial x_k}(x^i) - \frac{\partial f}{\partial x_k}(x^{i-1}) \text{ for all } k \in \{1, \dots, n\}. \quad (6.16)$
```

If $x_k^i \neq x_k^{i-1}$ for every $k \in \{1, \dots, n\}$, then we get

```
$b_k^i = \frac{\frac{\partial f}{\partial x_k}(x^i) - \frac{\partial f}{\partial x_k}(x^{i-1})}{x_k^i - x_k^{i-1}} \text{ for all } k \in \{1, \dots, n\}.$
```

This results in the iteration direction

```
$d^i := -(B^i)^{-1} \nabla f(x^i) = - \begin{pmatrix} 1/b_1^i & & & \ddots & & & 1/b_n^i \end{pmatrix} \nabla f(x^i)$
```

if $b_1^i, \dots, b_n^i \neq 0$. Under these assumptions, the components of the iteration direction can be simply written as

```
$d_k^i := -\frac{x_k^i - x_k^{i-1}}{\frac{\partial f}{\partial x_k}(x^i) - \frac{\partial f}{\partial x_k}(x^{i-1})} \text{ for all } k \in \{1, \dots, n\}.$
```

This matrix-free formula is used in line 9 of Algorithm 6.3. Note that it is important to check that the denominator does not vanish. Thus, for each component of the negative gradient of $f$ at $x^i$, we determine an “individual step size” instead of computing a little step size. So the iteration formula is

$x^{i+1} := x^i + d^i$

as given in line 16 of Algorithm 6.3.

In order to avoid that the iteration direction $d^i$ is an ascent direction, one can check the sign of the scalar product

```
$$\nabla f(x^i)^T d^i = \frac{d}{d\lambda} f(x^i + \lambda d^i)|_{\lambda=0} = \lim_{\lambda\to0_+} \frac{f(x^i + \lambda d^i) - f(x^i)}{\lambda}$$
```

If $\nabla f(x^i)^T d^i > 0$, then there exists some $\hat{\lambda} > 0$ so that

$f(x^i + \lambda d^i) > f(x^i)$ for all $\lambda \in (0, \hat{\lambda})$

i.e., $d^i$ is an ascent direction. In this case, we can replace $d^i$ with $-d^i$ and get a descent direction. This is implemented in line 13 of Algorithm 6.3. However, since we are not working with an additional step size for $d^i$; it may be that the next iteration point $x^{i+1}$ we get a larger value of the objective function.

## 6.6.2 Stochastic Gradient Method

The word “stochastic” does not refer to the dataset, because the data are deterministic, but to the determination of an estimate of the gradient of the objective function, choosing randomly among many estimators.

Also in this subsection we discuss the unconstrained optimization problem (6.6), i.e.,

$\min_{x \in \mathbb{R}^n} f(x)$

with $n \in \mathbb{N}$ and $f : \mathbb{R}^n \to \mathbb{R}$. But now we assume the objective function $f$ has the special form

```
$f(x) = \frac{1}{p} \sum_{j=1}^p f_j(x) \text{ for all } x \in \mathbb{R}^n, \quad (6.17)$
```

where $p \in \mathbb{N}$ and $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$ are given functions. If $f_1, \dots, f_p$ are differentiable functions, then the objective function $f$ is also differentiable with

```
$\nabla f(x) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) \text{ for all } x \in \mathbb{R}^n. \quad (6.18)$
```

Deep learning typically works with a very large dataset consisting of many training examples. This means that the parameter $p$ is a very large integer. Thus, a large number of gradients $\nabla f_j(x)$, with $j \in \{1, \dots, p\}$ and $x \in \mathbb{R}^n$, must be computed to determine the gradient of the objective function for a gradient descent method. This numerical effort can be greatly reduced with the help of the simple proposition:

**Proposition 6.3 (Unbiased Estimator of $\nabla f(x)$** Let the functions $f_1, \dots, f_p : \mathbb{R}^n \to \mathbb{R}$ be differentiable, let the objective function $f : \mathbb{R}^n \to \mathbb{R}$ be given by (6.17), and let $x \in \mathbb{R}^n$ be arbitrarily chosen. If $G$ denotes a discrete $\mathbb{R}^n$-valued random element, which is uniformly distributed and takes the gradients $\nabla f_j(x), \dots, \nabla f_p(x)$, then its expectation is $E(G) = \nabla f(x)$, or in other ways, $G$ is an unbiased estimator of the gradient $\nabla f(x)$.

**Proof** Under the assumptions of this proposition and using the equality (6.18), we immediately get for the expectation of $G$

```
$E(G) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) = \frac{1}{p} \sum_{j=1}^p \nabla f_j(x) = \nabla f(x).
```

which has been shown.
