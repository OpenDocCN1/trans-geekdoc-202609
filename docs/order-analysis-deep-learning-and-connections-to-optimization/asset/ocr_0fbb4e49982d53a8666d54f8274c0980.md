# Definition 1.15

+   (a) Let Y be a real linear space. A functional $|\cdot| : Y \to \mathbb{R}_+$ is called a norm iff the following conditions are satisfied (for all, $y, z\in Y$ and $\lambda\in\mathbb{R}$):

+   (i) $|y| = 0 $\iff y = 0$.
(ii) $|\lambda y| = |\lambda| |y|$.
(iii) $|y+z| \le |y| + |z|.$

If the condition (i) is not fulfilled, $|\cdot|.$ is called a seminorm.

+   (b) Let Y be a real linear space equipped with a norm $|\cdot|$. The pair $(Y, |\cdot|)$ is called a real normed space.

+   (c) A complete real normed space is called a Banach space.

+   (d) In a real normed space, $(Y, |\cdot|)$, a sequence $(y_n)_{n\in\mathbb{N}}$ is said to converge to some $y\in Y$ in norm iff $\lim_{n\to\infty} |y_n - y| = 0$. In this case, writes $y = \lim_{n\to\infty} y_n$ and speaks of norm convergence.

+   (e) Let $(Y, |\cdot|)$ be a real normed space, and let $\hat{y}\in Y$ and $\varepsilon > 0$ be arbitrarily given. The set

> $$\mathcal{B}(\hat{y}, \varepsilon) := \{y\in Y \|| |y - \hat{y}|| \le \varepsilon\}$

is called a closed ball at $\hat{y}\in Y$ with radius $\varepsilon$.

It is interesting to see that already partially ordered real linear space with additional conditions on the partial order $C$ is a real normed space. And every element of core(C) is contained in int(C) for a specific norm.

**Proposition 1.4** Let C be a convex, and algebraically closed cone in a real linear space Y with core(C) $\neq$ $\varnothing$. For every $c\in core(C)$ there exists a norm $|\cdot|$ on $Y$ with $c\in int(C)$.

*Proof* Let $c\in core(C)$ be arbitrarily chosen. The order interval $[-c, c := :=y\in Y | -c \le y \le c\}$ (where $\le$ denotes the partial order) equals the unit ball $\mathcal{B}(0, 1)$
