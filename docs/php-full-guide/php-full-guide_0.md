## I. 什么是 Web 编程。主要技术

### I-1. 客户端-服务器

如果你已经尝试过（并且可以，即使不成功）进行编程，例如使用 Delphi、Visual Basic 甚至是 Visual C++，那么你已经习惯了这种程序运行的方案：点击按钮 - 执行代码 - 显示结果，而这一切都在同一台计算机上完成。

在 Web 编程中，一切都不同。

你是否想过当你在浏览器地址栏输入 URL（统一资源定位符，或者通俗地说——地址）时会发生什么？工作原理如下：

1. 浏览器与服务器建立连接
2. 浏览器向服务器发送请求以获取页面
3. 服务器为浏览器创建响应（通常是 - HTML 代码）并关闭连接
4. 浏览器处理 HTML 代码并显示页面

请注意**加粗**的部分。在你在屏幕上看到请求的页面之前，与服务器的连接已经关闭，它已经忘记了你。当你输入另一个（或同一个）地址，或者点击链接，或者按下 HTML 表单的按钮时——同样的方案将再次重复。

这种工作方案被称为“客户端-服务器”。在这种情况下客户端是浏览器。

因此，与 Web 服务器的连接只持续几秒钟（或几秒钟的一部分），这是从点击链接（或通过其他方式请求）到开始显示页面之间的时间。在连接期间，大多数浏览器会显示某个指示器，例如，MS Internet Explorer 在右上角会显示动画。

细心的读者会在这里注意到 - 既然我我已经读完了页面，指示器仍然显示连接过程呢？这是因为像 `<img src=...>` 标签（加载图像）以及其他一些标签仅仅是另一个服务器请求 - 并且它的执行方式与其他任何请求一样 - 遵循同样的方案。而且从服务器的角度来看，图片请求完全独立于 HTML 别名请求。

为了永远摆脱对 HTTP 作为“黑盒”的认知，我们将通过 telnet “伪装”浏览器：

1. 启动 `telnet www.php5.com 80`
2. 在终端窗口中输入以下内容（如果没有显示 - 也不糟糕）：

```
GET/HTTP/1.0 [我们在此按回车]
Host: www.php5.com [我们在这里按两次回车]
```

点击回车通常对应于 CR + LF 字符组合，标记为 `\r\n`。该标记将在后续使用。

屏幕上将运行 `http://www.php5.com/` 页面的 HTML 代码。如你所示 - 并没有什么困难。

当前页面的源代码几乎可以在任何浏览器中查看，只需在“查看|源代码”菜单中选择即可。

图片、框架 - 所有这些额外的请求都是一样的。实际上，浏览器窗口中的图片是从哪里来的：在解析（处理）HTML 代码时，浏览器遇到 `<img src="picture">` 标签会发送额外的服务器请求 - 图片请求，并将其显示在有 `<img...>` 标签的网站上。图片请求从服务器看来与 HTML 别名请求是完全独立的。

```
telnet www.php5.com 80
GET /HTTP/1.0
Host: www.php5.com
```

屏幕上将运行 `http://www.php5.com/` 页面的 HTML 代码。如你所示 - 并没有什么困难。

当前页面的源代码几乎可以在任何浏览器中查看，只需在“查看|源代码”菜单中选择即可。

### I-2. HTML 表单。发送数据的方法

在示例中：

1. `<form method="GET" action="/cgi-bin/handler.php">`
2. `<input type="text" name="name">`
3. `<input type="submit" value="OK">`
4. `</form>`

这是发送数据的常用 HTML 表单。

让我们详细考虑这些表单。在表单中，以下属性是可选的：

- `action`：指定表单提交的 URL（绝对路径或相对路径）。
- `method`：指定发送表单的方法。在示例中，我们使用的是 "GET"。

如果不指定 `method`，大多数浏览器将默认使用 "GET"。当使用 `GET` 方法时，表单的数据附加在 URL 后面。你可以在浏览器地址栏中看到它：`http://example.com/cgi-bin/handler.php?name=Bryan&okbutton=OK`。这就是 `GET` 方法的工作方式。

实际上，发送表单有两种主要方法：

- `GET`：表单数据附加在 URL 后面传输。
- `POST`：表单数据在请求体中传输。

如果没有指定 `method` 属性——默认是 "GET"。

`<input>` 标签通过 `type` 属性设置表单元素：

- `text`：设置一个单行文本框。
- `submit`：设置一个点击即可提交的按钮。

其他值也是可能的（且 `<input>` 不是设置表单元素的唯一标签），但我们将在后续章节中考虑它们。

那么，当我们点击 OK 时会发生什么？

1. 浏览器读取表单元素，并根据它们的 `name` 和 `value` 属性创建表单数据。假设输入的名字是 Bryan。在这种情况下，这些表单数据为 `name=Bryan&okbutton=OK`。
2. 浏览器与服务器建立连接，向服务器发送 `action` 属性指定的文档请求，使用 `method` 属性指定的发送方法（在本例中为 "GET"），在请求中传输这些表单。
3. 服务器分析收到的请求，创建响应，发送给浏览器并关闭连接。
4. 浏览器显示从服务器接收的文档。

手动（通过 telnet 工具）发送相同的请求如下（假设网站域名为 www.example.com）：

```
telnet www.example.com 80
GET /cgi-bin/handler.php?name=Bryan&okbutton=OK HTTP/1.0\r\n
Host: www.example.com\r\n
\r\n
```

正如你可能猜到的那样，点击带有 "GET" 方法的提交按钮，与在浏览器地址栏中输入相应的 URL（带有签名问号和表单数据）是类似的：`http://www.example.com/cgi-bin/handler.php?name=Bryan&okbutton=OK`。

实际上，当你从从服务器请求任何文档时，总是使用 `GET` 方法，无论你是刚刚输入了它的 URL 还是点击了链接。使用 `<form method="GET"...>` 时，问号和这些表单数据只是被添加到 URL 之后。

如果 `method` 属性没有指定——它意为为 "GET"。

- `POST`：表单数据在请求体中传输。





也许，这些来自 `telnet-ohms` 的技术细节和练习对你来说极其无聊，甚至没有必要（“这里 PHP 在哪呢？”）。但并非徒劳。这些是 `HTTP` 协议下的基础知识，每个 Web 程序员都需要烂记于心，而且这并不是理论知识——这一切在实践中都是实用的。

现在我们将把表单的第一行替换为以下内容：

1.<form method= "POST" action= "/cgi-bin/form\_handler.cgi">`

我们指定了发送方法为 `"POST"`。在这种情况下，数据传输到服务器的方式略有不同：

```
telnet www.example.com 80
POST/cgi-bin/form_handler.cgi HTTP/1.0\r\n
Host: www.example.com\r\n
Content-Type: application/x-www-form-urlencoded\r\n
Content-Length: 22\r\n
\r\n
name=Bryan&okbutton=OK
```

使用 `POST` 方法时，这些表单会位于“两个回车符”之后——即在请求体中。以上所有内容实际上都是请求头（而当我们使用 `GET` 方法时，这些表单是在请求头中的）。为了让服务器知道在哪个字节结束读取请求体，请求头中有一行 `Content-Length`；这些表单将传输的内容类似于 `параметр1=значение1&параметр2=значение2...`，且值是以 `urlencode` 类型传输的——即与通过 `GET` 方法的方式相同，但在请求体中——向服务器报告请求头 "Content-Type: application/x-www-form-urlencoded"。

这种 `urlencode` —— 限制略小。

`POST` 方法的优点是——对表单数据行的长度没有限制。使用 `POST` 方法时，无法像使用 `GET` 方法那样简单地通过“访问链接”来发送表单。

为了表述简洁，我们将引入术语 `"GET form"` 和 `"POST form"`，其中前缀对应 `<form>` 标签 `method` 属性的值。

当使用 `POST form` 时，可以在其 `action` 属性的问号后面指定 `GET form` 参数。因此，`POST` 方法也包含了 `GET` 方法。

### I-3. CGI 技术

我们通过上一章理解了如何创建 HTML 表单，以及浏览器如何将其中输入的数据发送到服务器。但目前还不清楚服务器将如何处理这些数据。

Web 服务器本身仅能够提供请求的页面，仅此而已，而所有传输的这些表单对它来说是是无关。为了能够用任何程序处理这些数据并动态地为浏览器创建响应，发明了 `CGI` 技术（通用网关接口）。

让我们来看这个 URL：`http://www.example.com/cgi-bin/form\_handler.cgi`。关于它可以提出的第一个假设是它是正常的：服务器提供了来自 `cgi-bin` 目录的 `form_handler.cgi` 文件内容。然而，在 `CGI` 技术的情况下，情况是不同的。服务器启动 `form_handler.cgi` 程序并将这些表单传输给它。程序创建文本并作为请求的响应传输给浏览器。

`form_handler.cgi` 程序可以用任何编程语言编写，最重要的是在程序中遵守 `CGI` 标准。例如，可以使用流行的脚本语言 `Perl`。也可以用 `SI` 编写一切。或者用 Shell 脚本……但作为示例，我们将用 `SI` 编写这个程序。但在最初，我们将理解 Web 服务器与 `CGI` 程序之间存在的数据交换。

在 `CGI` 程序启动之前，服务器会设置环境变量（这些在执行 `PATH` 命令时你很熟悉）。在任何稍微正式一点编程语言中，都有读取环境变量的手段。`CGI` 标准定义了一组非常大量的变量，这些变量在 `CGI` 程序启动之前应该被定义。现在我们只考虑其中三个：

- `REQUEST_METHOD` - 数据传输方法——`GET` 或 `POST`（还有其他其他的，但目前我们不考虑它们）
- `QUERY_STRING` - 支持 URL 中问号后面的部分，换句话说，这些是 `GET forms`。
- `CONTENT_LENGTH` - 请求体长度（这些 `POST forms`）。

当服务器启动 `CGI` 程序时，请求体以标准输入 (`stdin`）的形式传输给程序——就像这些数据是从键盘输入的一样。

当程序将浏览器的响应输出到标准输出 (`stdout`）——“在屏幕上”。这个输出被 Web 服务器截获并传输到浏览器。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    //我们读取 Web 服务器设置的环境变量
    char * query_string = getenv ("QUERY_STRING");
    char * request_method = getenv ("REQUEST_METHOD");

    char * post_data;//存储 POST 请求数据的缓冲区
    int post_length = 0;//请求体长度

    if (strcmp (request_method, "POST") == 0) {//如果接收到 POST 请求，
        post_length = atoi (getenv ("CONTENT_LENGTH"));//首先我们从
        //环境变量中读取它的长度，
        if (post_length){//如果它不为零，
            post_data = (char *) malloc(post_length+1);//我们为缓冲区选择内存，
            fread (post_data, post_length, 1, stdin);//我们从标准输入读取请求体，
            post_data[post_length] = 0;//我们用零字节完成这一行。
        }
    }

    //我们显示响应头...
    printf ("Content-type: text/html\r\n\r\n");

    //并它的正文：
    printf ("<h1>Hello!</h1>\r\n");

    if (strlen(query_string)) {
        printf ("<p>GET form Parameters: %s</r\n", query_string);
    }

    if (post_length) {
        printf ("<p>POST form Parameters: %s (request body length: %d)</r\n", post_data, post_length);
        free(post_data);//不要忘记释放 17 行选择的内存
    }

    return 0;
}
```

这是一个用 `SI` 编写的基础 CGI 程序，显示从 Web 服务器接收的表单内容。浏览器作为结果将收到类似的代码（如果是上一个例子中的 `POST form`）：

```html
<h1>Hello!</h1>
<p>POST form Parameters: name=Bryan&okbutton=OK (request body length: 22)</p>
```

至于同时在用户屏幕上显示什么，我想显然不需要评论的。

## PHP：超文本预处理器

11994 年，一位名叫 Rasmus Lerdorf 的程序员在苦恼于经典的 CGI 模块后，决定编写几个自己的 Perl 脚本，用以更方便地创建自己的主页，并将这项活动命名为 Personal Page（PHP）。过了一段时间，它需要处理表单，而且为了提高效率，所有内容都用 C 语言进行了重写——Personal Page 2.0 就此诞生了。Rasmus 遵循开源原则的作品被公开供大家审阅。

1997 年，两位程序员 —— Andi Gutmans 和 Zeev Suraski 发现了 PHP —— 当时他们正在寻找一种方便的 Web 脚本工具。这个想法让他们很愉快，但 PHP 的功能和运行速度仍不尽人意。Andi 和 Zeev 决定从零开始重写 PHP。这种语言变得通用而强大，并很快吸引了大量 Web 开发者的关注：到 1998 年底，PHP3 已用于约 10% 的 Web 服务器。“Personal Page”这个朴素的名字已经不再符合现实，于是根据 Unix 的传统，名称被更改为 PHP: Hypertext Preprocessor（PHP：超文本预处理器）。

PHP4 的“引擎” Zend Engine 是通过共同努力开发的，从那以后 PHP 社区不断成长。在 2000 年，PHP 的一个版本在不到半年内就成为了 Unix（以及不仅是 Unix）Web 开发的标准：每个尊重自律的主机都提供了对 PHP 的支持。现在，基于新 Zend Engine 的 PHP5 开发即将结束……

### 简单脚本

与 SI 或 Perl 不同，PHP 脚本代表的是普通的、通常是 HTML 的页面：“就像这样”写的标签会被“原样”传输，如果它是一个普通的 html 别名。脚本由特殊标签 `<?php` 和 `?>` 组成，我们在其中使用 `echo` 运算符来输出文本。这种块可以根据需要任意存在，之间的所有内容都会被解释为普通的 html。

GET 请求的变量进入数组 `$_GET`，POST 请求的变量进入数组 `$_POST`，服务器变量（如 IP 地址类型、脚本名称等）进入 `$_SERVER`，“点”运算符 `.` —— 用于字符串的字符串连接……而且所有的内部处理操作（读取标准输入和环境变量、URL 解码）已经由 PHP 完成了。这很方便，不是吗？

此外，为什么我们需要两个文件——一个带有表单的 HTML 和一个 PHP 脚本？一个脚本就足够了：

```php
<html>
<body>
<?php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
    echo "<h1> Hi, " . $_POST['name'] . "</h1>!";
}
?>
<form method="POST">
    Enter your name: <input type="text" name="name">
    <br>
    <input type="submit" name="okbutton" value="OK">
</form>
</body>
</html>
```

我们从表单标签中删除了 `action` 属性——这意味着表单提交到“自身”，即发送到当前 URL。这有时被称为“回传表单”。在第 4 行，通过 `if` 运算符检查是否使用了 POST 方法加载文档（类似于 SI 示例中第 13 行的内容），如果是，则在下一行显示问候语。

在这个简单的程序——即某种 Web 版本的“Hello World”上——我们也将完成输入章节。




在 `configure` 阶段，你可能会看到与系统缺少必要库相关的错误。这些库需要根据发行包中 `INSTALL` 文件的说明进行下载和设置（通常 - 顺序是相同的：`/ configure && make && make install`）。这项工作非常漫长且无味，因此长期以来，大多数 Unix 系统都包含了这种或那种更方便的软件安装工具。

### FreeBSD

FreeBSD 包含了用于软件安装的特殊手段 - `ports`（`ports` 系统），它代表了一组脚本，这些脚本会自动下载、配置、编译和安装软件产品，包括启动所需的库（依赖项 - `dependences`）。我在此不再详细阐述，因为在 FreeBSD 中操作 ports 的方法在《FreeBSD 手册》（FreeBSD Handbook）和系列书中都有描述。假设你的系统中 ports 库已经安装并更新。

我们进入 Apache port 目录：

```bash
cd/usr/ports/www/apache13
```

我们以 root 身份启动编译和 Apache 安装团队（发行包会自动下载）：

```bash
su
make install
```

如果必要在系统加载时自动启动 Apache，我们需要在 `/etc/rc.conf` 中注册：

```ini
apache_enable= "YES"
```

实际上，就是这些；;)

如果需要精细配置，请研究 `Makefile` 并在 `make install` 命令后添加必要的参数（例如，`make install WITH_APACHE_SUEXEC=yes` - 用于支持 `sexec`）。

### Red Hat Linux 和其他基于 RPM 的发行包（ASP, Mandrake...）

Red Hat Linux 包含了 `RPM` 包管理器。RPM 的安装方法本质上是另一种方式 - `.rpm` 数据包包含了已经编译好的二进制文件。这节省了时间（不需要编译任何东西），但剥夺了按你意收集程序的机会。

要从 rpm 安装 Apache，需要加载 Apache 1.3 的 `.rpm-file`（从哪里找 - 请搜索 Google：Apache Software Foundation (apache.org) 并不扩展 RPM）并启动：`rpm - Uvh apache`。

### Gentoo Linux

Gentoo Linux 是 “BSD 风格的 Linux”，它本质上包含 `portages` - 一个与 FreeBSD 使用的类似的 ports 系统。通过 `emerge` 命令进行安装，例如：

```bash
cd/usr/portage/net-www/apache
su
emerge apache-1.3.31.ebuild
```

不要只运行 `emerge apache` - 这将导致 Apache 2 的安装。

为了在系统加载时自动启动 Apache，输入：

```bash
rc-update add apache default
```

### 其他 Linux 发行包

其他 Linux 发行包（Debian, Slackware...）包含自己的包管理器 - 请参考文档。无论（即使在其他 Unix OS 中），你都可以手动编译并设置 Apache - 如上所述。

# III. PHP 安装

### III-1 Windows 系列操作系统的安装

从 `www.php.net/downloads.php` 页面下载 Windows Binaries ZIP 压缩包（PHP 4.x.x Zip 包）。

### III-2 Unix 系列操作系统的 PHP 安装

PHP 的安装过程与 Apache 的安装类似，不同之处在于编译 PHP 时你需要指定更多的配置选项。

从源码手动编译 - 为此目的，首次启动需要通过 `www.php.net/downloads.php` 下载并解压源码。`/ configure` 也有助于研究编译的参数列表（非常令人印象）。

无论如何，参数 `with-apxs=/put/k/apxs` 是必须的 - 它用于编译 Apache 的 `mod_php` 模块。例如，如果 Apache 设置在 `/usr/local`，则参数看起来如下： - `with-apxs=/usr/local/sbin/apxs`。

## PHP 程序的结构

与传统的脚本语言（如 Perl）不同，PHP 程序通过代码插入表示 HTML 页面。对比一下：

Perl 脚本：

```perl
#!/usr/local/bin/perl
print "Content-type: text/html\n\n";
print " html\n<head> <title> Hello World </title> </head> \n";
print " <body> <h1> of Hello World! </h1></body> \n";
print " </</html>";
```

PHP 脚本（是的，这是 PHP 的程序；)):

```html
<html>
<head> <title> of Hello World </title> </head>
<body> <h1> of Hello World! </h1></body>
</html>
```

```

如你所见，PHP 的基础程序就是一个普通的 HTML 页面。关于头部 `Content-type: text/html` 的输出，PHP 也独立地处理了。

直接将 PHP 代码（即 - 不是 HTML）放置在标签 `<?` 和 `?>` 之间。位于这些标签之间的所有内容在显示时会被此块中的脚本替换为 HTML 代码（在特定情况下 - 如果脚本没有显示内容 - 则直接“消失”）。

通常，一种通用的（即保证在任何配置下都能工作的 PHP）但更长的 PHP 代码指定方式是标签 `<? php...?>`。这种较长的记录形式用于 XML 和 PHP 的组合，因为 `<?...?>` 标签被用于 XML 标准中。

为了将 `<?` 标签识别为 PHP 块的开头，由 `php.ini` 文件中的 `short_open_tag` 指令决定（默认开启）。如果你想开发不受此配置影响的运行脚本，请使用长开启标签 `<? php`。我将使用缩写形式。

让我们来看一个简单的示例。

1. `<html>`
2. `<head> <title> of Hello World </title> </head>`
3. `<body> <h1> of Hello World! </h1>`
4. `<p> Current date: `
5. `<?` 
6. `echo date ("d.m.Y");`
7. `?>`
8. `</body>`
9. `</html>`

为了完成示例，请将它们复制到位于配置文件 `Apache httpd.conf` 中 `DocumentRoot` 指令对应的目录文件中（例如，在名为 `test.php` 的文件中），并在浏览器地址栏（`http://localhost/test.php`）访问保存的脚本 (`test.php`）。如果你还没有设置 Apache+PHP（如果是这样的话），请参上一章。

如果今天是 2016 年 7 月 27 日，执行脚本后浏览器将接收到以下 HTML 代码：

```html
<html>
<head> <title> of Hello World </title> </head>
<body> <h1> of Hello World! </h1>
<p> Current date:
27.07.2016 </body>
</html>
```

第 5、6、7 行是 PHP 代码插入。第 5 行和第 7 行分别是开启标签和结束标签。将它们放置在单独行上是完全可选的 - 这样做是为了阅读方便。

在第 6 行使用了用于在浏览器中输出的 `echo` 操作符。它显示了 `date()` 函数的执行结果 - 在这种情况下是当前日期。

第 6 行是完成的表达式。PHP 中的每个表达式都以分号 `;` 结束。是分号，而不是换行符 - 不要忘记这一点，特别是如果你之前编写过 Visual Basic 或 ASP 的话。

留心的读者会注意到 `</body>` 标签与 `date()` 函数生成的文本位于同一行，尽管 `</body>` 在源代码中是单独占一行的。这是因为 PHP 会丢弃紧跟结束标签 `?>` 之后的换行符 - 这样做的特殊目的是在不希望出现额外空格的 HTML 片段中，不需要通过将关闭 PHP 标签与后续 HTML 代码写在同一来赋予脚本可读性。如果需要空格 - 请在 `?>` 之后插入空行。

## 变量与数据类型

PHP 中的变量以 `$` 符号开头，后跟任意一组拉丁字母、数字和下划线符号 `_`；同时数字不能直接跟在 `$` 符号之后。

变量名的大小写非常敏感：`$A` 和 `$a` 是两个不同的变量。

为变量赋值时使用 `=` 操作符。

示例：

1. `<?`
2. `$a = 'test';`
3. `$copyOf_a = $a;`
4. `$Number100 = 100;`
5. `$a echo;`
6. `$copyOf_a echo;`
7. `$Number100 echo;`
8. `?>`

这段代码将显示：`test100`。

你监控变量名：可能使用 `$a21` 或 `$zzz`。这里使用了 `$username`，理解起来非常容易。

在第 2 行，变量 `$a` 被赋值为值：在 PHP 中，变量在第一次赋值时被创建；如果未给变量赋值 - 则变量不存在。

在第 3 行，变量 `$copyOf_a` 被赋值为变量 `$a` 的值；在这种情况下（我们看 2）值为 'test'。在第 4 行，名为 `$Number100` 的变量被赋值为数值 100。

如你所见，PHP 存在类型，即语言区分数据类型 - 字符串、数字等。然而，这里的 PHP 是一种弱类型语言 - 数据类型之间的转换会自动发生。例如，程序 `<? echo '100' + 1;?>` 将显示数字 101：在数值上下文中，字符串会自动转换为数字（在这种情况下 - 字符串 '100' 在用于组合时将转换为数字，因为字符串没有定义加法）。

这种行为（以及不需要显式定义变量甚至没有可能）使得 PHP 与 Perl 和 Basic 相似，但它可能会受到严格语言（如 SI 和 Pascal）追随者的敌视。当然，准确定义变量和要求显式类型转换可以减少编程错误的可能性，但对于首先是用于快速开发脚本的解释型语言 PHP 来说，语法的严格性在编码速度上得到了很好的补偿。而且它总是乐意地报告未定义的 PHP 变量 - 如果当然没有禁止的话……然而，我继续前进。

让我们再看又一个示例：

1. `<?`
2. `$greeting = 'Hi';`
3. `$name = Bryan;`
4. `$message = "$greeting, $name!";`
5. `$message echo;`
6. `?>`




第四行值得特别关注。在双引号中指定了最后几行定义的变量。如果执行这个程序（你已经写好了吗？），在浏览器窗口中将显示 `Hi, Bryan` 这行！实际上，双引号的主要特征还包括：在成对字符内指定的变量名会被替换为这些变量对应的值。

此外，在双引号中，还会识别由两个字符组成的特殊转义组合，其中第一个字符是反斜杠（`\\`）。最常用的控制字符有：

- `\r` - 回车 (CR)
- `\n` - 换行 (NL)
- `\"` - 双引号
- `\$` - 符号字符（`$`）
- `\\` - 实际上是反斜杠（`\`）

字符 `\r` 和 `\\` 通常与 `\n` 一起使用，形式为组合 `\r\n` - 这在 Windows 中表示换行，许多 TCP/IP 协议也是这样命名的。在 Unix 中，换行由单个字符 `\n` 表示；通常这种换行方式也用于 HTML 文档（当然，这只影响 HTML 代码，而不影响浏览器的显示（除非文本被放入 `<pre>...</pre>` 标签对中）：正如我们所知，为了显示换行，使用的是 `<br>` 标签）。

提供的反斜杠应用列表中剩余的三个点是转义（屏蔽）的示例 - 即取消字符的特殊作用。因此，双引号将表示行尾，美元符号表示变量名的开头，而反斜杠则表示转义组合的开头（我们在这里也提到了这一点；))）。在转义时，字符被按“原样”感知，且不会执行任何特殊操作。

转义（不是指反斜杠，而是这种原理；）在 PHP 中用于许多情况下 - 所以我们还会多次遇到这种方法。

如果在单引号中替换引号，浏览器中将直接显示它们内部的内容（显示 `$greeting`、`$name`！）。单引号中以 `\\` 开头的字符组合也不会发生任何形式的转换，有两个例外：`\'` - 行中的单引号；`\\` - 反斜杠（数量仅为一个）。

### Switch

需要根据同一个变量或表达式的值来实现“分支”。可以写出像这样的：

```php
if ($i == 1) {
    //对应 $i == 1 的代码
} else if ($i == 2) {
    //对应 $i == 2 的代码
} else if ($i == 3) {
    //对应 $i == 3 的代码...
}
```

但有一个运算符，对于这种情况更方便 - `switch`。它看起来是这样：

```php
<?
$i = 1;
switch ($i) {
    case 1:
    echo 'one';
    break;
    case 2:
    echo 'two';
    break;
    case 3:
    echo 'tri';
    break;
    default:
    'I am able to consider echo only to three!;)';
}
?>
```

观察程序执行的结果，改变第二行中 `$i` 的值。正如你已经确定的理解的，`switch` 括号中指定变量（尽管也可以是表达式 - 例如 `try $i+1`），而 `case XXX` 行对应括号内事实的值。

在 `case-a` 之间的运算符不需要在大括号中结束 - 每一个分支都以 `break` 运算符结束。

`default` 的特殊条件对应于“所有其余部分”（`if... else if. `else` 中的 `else` 类似物）。`default` 总是位于最后，因此这里的 `break` 是可选的。正如 `else` 情况一样，`default` 的条件也可以是缺少的。

如果你突然忘记指定 `break`，所有后续的行 - 将从随后的 `case-` 开始执行！例如，如果在我们的示例中删除第 6 行，在 `$i == 1` 时，浏览器中将显示 "onetwo"。有些狡猾的程序员使用这个技巧来指示多个取值选项：

```php
<?
$i = 1;
switch ($i) {
    case 0:// 故意没有写 break！
    case 1:
    echo 'zero or one';
    break;
    case 2:
    echo 'two';
    break;
    case 3:
    echo 'tri';
    break;
}
?>
```

或者为了在条件的特定值下连续完成两个动作。但最好的做法是“按需”使用 `switch`，用 `break` 结束每个 `case`；如果需要“位移” - 不要忘记加上注释，就像最后一个示例的第 5 行做的那样。

### Cycles

任何或或少严肃的编程语言都包含组织循环以重复执行代码片段的运算符。在 `PHP` 中有三个这样的运算符。

#### while

让我们从 `while` 循环开始：

```php
<?
$i = 1;
while ($i <10) {
    $i echo. "br\\n";
    $i ++;
}
?>
```

`while` 循环（第 3 行）工作如下：首先检查括号内表达式的真值。如果不为真，则不执行循环体（位于后续大括号之间的所有内容 - 如果不存在，则执行后续指令）。如果为真，在执行完循环体内的代码后，再次检查表达式的真值等。

在循环体中（第 4, 5 行），显示变量 `$i` 的当前值，然后 `$i` 的值增加 1。

在这个示例中使用像 `$i` 的变量通常被称为变量循环计数器，或简单的计数器。

`$i ++`，递增操作（值增加 1） - `$i= $i+1` 的缩写表示；类似的缩写表示 - `$i+ =1`。根据最后一个规则，可以减少任何二元操作（例如，拼接：`$s. = 'foo' - $s analog = $s. 'foo'`）；然而，类似于递增，可以只写递减（值减少 1）：`$i-.`。

同样记录 `++ $i` 也是可能的（以及 `- $i`）；操作符号排列上的区别仅在直接使用此计算结果时显示：如果 `$i` 等于 1，在 `$j= $i ++` 的情况下，变量 `$j` 将接收该值。

让我们从 `while` 循环开始：

```php
<?
$i = 1;
while ($i <10) {
    $i echo. "br\\n";
    $i ++;
}
?>
```

`while` 循环（第 3 行）工作如下：首先检查括号内表达式的真值。如果不为真，则不执行循环体（位于后续大括号之间的所有内容 - 如果不存在，则执行后续指令）。如果为真，在执行完循环体内的代码后，再次检查表达式的真值等。

在循环体中（第 4, 5 行），显示变量 `$i` 的当前值，然后 `$i` 的值增加 1。

在这个示例中使用像 `$i` 的变量通常被称为变量循环计数器，或简单的计数器。

`$i ++`，递增操作（值增加 1） - `$i= $i+1` 的缩写表示；类似的缩写表示 - `$i+ =1`。根据最后一个规则，可以减少任何二元操作（例如，拼接：`$s. = 'foo' - $s analog = $s. 'foo'`）；然而，类似于递增，可以只写递减（值减少 1）：`$i-.`。

同样记录 `++ $i` 也是可能的（以及 `- $i`）；操作符号排列上的区别仅在直接使用此计算结果时显示：如果 `$i` 等于 1，在 `$j= $i ++` 的情况下，变量 `$j` 将接收该值。

如果你突然忘记指定 `break`，所有后续的行 - 将从随后的 `case-` 开始执行！...（抱歉，由于系统逻辑错误，上述回复出现了大量重复。我已在上方提供了准确的翻译。）



# 数组

数组代表由一个名称组合的变量集合。数组的每个值都通过索引标识，索引指定在变量数组名后的方括号 `[]` 中。索引与其对应值的组合被称为数组单元。

```php
<?
$i = 1024;
$a[1] = 'abc';
$a[2] = 100;
$a['test'] = $i - $a[2];

echo of $a[1]. "br\n";
echo of $a[2]. "br\n";
echo of $a['test']. "br\n";
?>
```

在给出的示例中，索引为 `1` 的 `$a` 数组单元出现在第三行；值 `abc` 被分配给数组单元。同一行也出现了 `$a` 数组，因为这是在数组上下文中第一次提到变量 `$a`，数组会被自动创建。在第四行中，数值 `100` 被分配给索引为 `2` 的数组单元。在第五行中，等于 `$i` 和 `$a[2]` 差值被赋值给索引为 `test` 的 `$a` 数组单元。

如你所见，数组的索引可以是数字也可以是字符串。

在其他编程语言（例如 Perl）中，具有字符串索引的数组被称为哈希（`hash`），是独立的数据类型。在 PHP 中，实际上所有数组都是哈希，但字符串和数字都可以作为索引。

在上一个示例中，数组是在描述第一个数组单元时自动创建的。但也可以显式地设置数组：

```php
<?
$i = 1024;
$a = array (1=>'abc', 2=> 100, 'test '=> of $i-100);
print_r ($a);
?>
```

最后一个示例创建的数组 `$a` 与上一个示例中的数组完全相同。这里的每个数组单元按 `索引 => 值` 的形式设置。在创建测试元素时，有必要直接指定值 `100`，因为这次我们是“一次性”创建数组，而 PHP 在创建阶段并不知道其元素的值。

在第四行中，为了输出数组的值，我们使用了 `print_r()` 函数，它非常方便将数组内容输出到屏幕上——首先是为了调试。

`print_r` 函数的输出行由普通的换行符 `\n` 分隔，而不是标签 `<br>`。为了方便阅读，可以将 `print_r` (`.`) 输出包裹在 `<pre>...</pre>` 标签输出运算符中：

```php
echo of '<pre>';
print_r ($a);
echo' </pre>'; 
```

如果显然没有指定索引，那么 PHP 数组将表现出类似于其他语言中数值数组的特征：下一个元素将具有连续的数字索引。计数从零开始。示例如下：

```php
<?
$operating_systems = array ('Windows', 'Linux', 'FreeBSD', 'OS/2');
$operating_systems[] = 'MS-DOS';

echo of "<pre>";
print_r ($operating_systems);
echo" </pre>";
?>
```

输出：
```
Array
(
    [0] => Windows
    [1] => Linux
    [2] => FreeBSD
    [3] => OS/2
    [4] => MS-DOS
)
```

在这里我们显然没有指定索引：PHP 自动从零开始分配了数字索引。当使用此类记录形式时，可以通过 `for` 循环访问数组。数组单元的数量通过 `count` 运算符（或其同义词 `size of`）返回：

```php
<?
$operating_systems = array ('Windows', 'Linux', 'FreeBSD', 'OS/2');
$operating_systems[] = 'MS-DOS';

echo of '<table border=1>';
for ($i=0; $i <count ($operating_systems); $i ++) {
echo' <tr> <td>'. $i.' </td> <td>'.$operating_systems[$i].' </td> </tr>';
}
echo' </table>';
?>
```

记录的形式可以混合。请注意在手动安装某些索引后，PHP 自动分配了哪些索引。

```php
<?
$languages = array (
1 => 'Assembler',
'C ++',
'Pascal',
'scripting' => 'bash'
);
$languages['PHP'] = 'PHP';
$languages[100] = 'Java';
$languages[] = 'Perl';

echo of "<pre>";
print_r ($languages);
echo" </pre>";
?>
```

输出：
```
Array
(
    [1] => Assembler
    [2] => C ++
    [3] => Pascal
    [scripting] => bash
    [PHP] => PHP
    [100] => Java
    [0] => Perl
)
```

如你所见，数组的索引可以是数字也可以是字符串。（等等，上面的输出显示 Perl 的索引是 `[0]`）。

### HTML 表单。`$_GET` 和 `$_POST` 数组

如果你还没有忘记第 1 章的内容，那么就不必再次提醒：表单是 Web 服务器与浏览器之间数据交换的主要方式，即提供用户交互——这正是 Web 编程所需的。

为了进一步阅读，必须对第 1 章描述的 Web 编程基础有清晰的理解。如果你是初，我再次建议仔细重读。

所以，我们将选取第 1 章中你已经熟悉的例子：

```html
<html>
<body>
<?php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
    echo '<h1> Hi, <b>'. $_POST['name'].</body></h1>!';
}
?>
<form method="POST" action="<?= $_SERVER['PHP_SELF']?>">
    Enter your name: <input type="text" name="name">
    <br>
    <input type="submit" name="okbutton" value=OK>
</form>
</body>
</html>
```

第 8-12 行给表单包含两个元素：`name` 和 `okbutton`。`method` 属性指定了发送 POST 表单的方法（见第 1 章），`action` 属性指定的表单目标 URL 由服务器变量 `PHP_SELF` 的值填充——当前执行的脚本地址。

`<?= $_SERVER['PHP_SELF']?>` 是 `echo` 的简写形式：`<?php echo $_SERVER['PHP_SELF'];?>`。

假设我们在 `name` 字段输入了值 `Bryan` 并点击了 OK 按钮。同时，浏览器向服务器发送 POST 请求。请求体：`name=okbutton=OK`。PHP 自动填充 `$_POST` 数组：

```php
$_POST['name'] = Bryan
$_POST['okbutton'] = 'OK'
```

实际上，`Bryan` 值是以 `urlencode` 格式进入浏览器的；对于 windows-1251 编码，该值看起来为 `%C2%E0%F1%FF`。但由于 PHP 会自动执行必要的解码，我们可以“忘记”这一特性——我们不需要手动处理 HTTP 请求。

由于请求体中只输入了名称和值，而没有表单元素的类型，PHP 并不知道 `$_POST['name']` 对应的是输入行、按钮还是列表。但通常来说，这些信息对我们完全并不需要。

由于提交按钮上写了什么对我们来说是可选的，在第 11 行可以删除 `name` 属性，将按钮的描述简化为 `<input type="submit" value=OK>`。在这种情况下，浏览器将发送 `name=Bryan` 的 POST 请求。

现在 - 同样的操作，但针对 GET 表单：

```html
<html>
<body>
<?php
if (isset($_GET['name'])) {
    echo '<h1> Hi, <b>'.$_GET['name'].</body></h1>!';
}
?>
<form action="<?= $_SERVER['PHP_SELF']?>">
    Enter your name: <input type="text" name="name">
    <br>
    <input type="submit" value=OK>
</form>
</body>
</html>
```

在第 8 行同样可以写成 `<form method="GET">`：`GET` 是默认方法。这次浏览器发送的是 GET 请求，等同于在地址栏中输入地址：`http://address-name/script-name.php?name`。

PHP 处理 GET 表单的方式与 POST 相同，不同在于填充的是（猜三次就知道了）一个 `$_GET` 数组。

根本区别在于第 4 行。由于在浏览器地址栏中直接输入地址就是 GET 请求，因此检查 `if ($_SERVER['REQUEST_METHOD'] == 'GET')` 是没有意义的：在这种情况下我们发现的一切——都只是某人没有向我们的脚本发送 POST 表单；;) 因此，我们求助于 `isset()` 结构，如果该变量已定义（即已赋值），则返回 `true`；如果变量未定义则返回 `false`。如果表单已填写——正如你所理解的，PHP 会自动为 `$_GET['name']` 分配对应的值。

通过 `isset()` 检查的方法是通用的，也可以用于 POST 表单。此外，它更优，因为它允许发现表单中哪些字段被填充了。

在许多旧书和文章中声称：
1. 来自 GET 和 POST 表单的数据都直接进入变量（在本例中为 `$name`），且 POST 数据具有优先级。
2. `$_GET` 和 `$_POST` 分别存储在 `$_GET_VARS` 和 `$_POST_VARS` 中。

### `htmlspecialchars()`

没找到吗？我来提示。例如，在“name”字段中输入一个双引号和一些文本，例如“123”。提交表单并查看接收页面的源代码。在第四行会有类似这样的内容：

`Enter your name: <input type= "text" of name= "name" value= "" 123">`

那是——没什么事。但如果狡猾的用户输入了 JavaScript 代码呢？

为了解决这个问题，必须使用 `htmlspecialchars()` 函数，它会将某些特殊字符替换为 HTML 实体表示（例如，引号会被替换为 `&quot;`）：

```php
<html>
<body>
<?php
$name = isset ($_POST['name'])? htmlspecialchars($_POST['name']):' ';
$year = isset ($_POST['year'])? htmlspecialchars($_POST['year']):' ';

if (isset($_POST['name'], $_POST['year'])) {
    if ($_POST['name'] ==' ') {
        echo 'Enter a name! <br>';
    } else if ($_POST['year'] <1900 || $_POST['year']> 2016) {
        echo 'Specify by echo year of birth! Tolerance range of values: 1900. 2016 <br>';
    } else {
        echo 'Hello, '. $name.'! <br>';
        $age = 2016 - $_POST['year'];
        echo 'to you '. $age.' years <br>';
    }
    echo' <hr>';
}
?>
<form method="post" action="<?= <?= $_SERVER['PHP_SELF']?>">
Enter your name: <input type="text" name="name" value="<?= $name?>">
<br>
Enter your year of birth: <input type="text" name="year" value="<?= $year?>">
<input type="submit" of value= OK>
</form>
</head>
</html>
```

重复实验，并确信现在 HTML 代码是正确的。

记住——当显示可能包含 HTML 特殊字符的变量内容时，必须始终使用 `htmlspecialchars()` 函数。

### `phpinfo()`

`phpinfo()` 函数是 `PHP` 中最重要的函数之一。它输出关于 `PHP` 设置、各种配置变量的值的信息……

为什么我在关于表单的章节提到它？`phpinfo()` 是最方便的调试工具。`phpinfo()` 还会显示所有 `$_GET`、`$_POST` 和 `$_SERVER` 变量的值。所以如果表单中的变量“丢失”了，寻找它的最简单方法就是使用 `phpinfo` 函数。为了让该函数只显示变量值（而不需要滚动十页纸），应该这样调用：`phpinfo(INFO_VARIABLES)`；或者——使用绝对值 `phpinfo(32);`。

示例：

```php
<html>
<body>
<form method="post" action="<?= <?= $_SERVER['PHP_SELF']?>">
Enter your name: <input type="text" name="name">
<input type="submit" of value= OK>
</form>
<?php
phpinfo(32);
?>
</body>
</html>
```

或者，例如这种情况：你想获取访客的 IP 地址。你记得相应的变量存储在 `$_SERVER` 数组中，但——运气不佳——你忘记了变量具体叫什么名字。此外，我们调用 `phpinfo(32);`，在页面中查找 IP 地址，并找到了它——在 `$_SERVER["REMOTE_ADDR"]` 这一行。
