## 109. 灾难恢复测试类型

按对业务的潜在影响从小到大排序，灾难恢复测试类型如下：

1.  **清单审查**
2.  **桌面演练**
3.  **并行测试**
4.  **全面中断测试**

**清单审查**是影响最小的演练类型，因为它甚至不需要开会。每个团队成员自行审查清单。**桌面演练**影响稍大，因为它要求将灾难恢复团队召集在同一房间。**并行测试**需要激活备用处理站点并需要大量资源。**全面中断测试**是影响最大的演练类型，因为它涉及将运营转移到备用站点，并可能中断生产活动。
