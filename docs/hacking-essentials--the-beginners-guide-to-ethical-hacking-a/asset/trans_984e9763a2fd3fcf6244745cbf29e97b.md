

# 恶意广告

当用户查看恶意广告时，即使不必点击它，也可能发生以下情况：

- **“路过式”下载**— 广告软件或恶意软件被安装在用户的计算机上。浏览器漏洞使此类攻击成为可能。
- 浏览器被强制重定向到恶意网站。
- 可能会显示恶意内容、不需要的广告或弹出窗口。

当用户点击恶意广告时，可能发生以下情况：

- 他们可能会执行一段代码，将广告软件或恶意软件安装到他们的计算机中。
- 用户可能会被重定向到恶意网站，而不是广告建议的网站。
- 用户可能会被重定向到恶意网站，攻击者在该网站上实施网络钓鱼攻击。

## 恶意广告对发布商的影响

发布商将遭受收入和流量损失，声誉也会受损。他们还可能因用户遭受的损害而承担法律责任。发布商很难屏蔽甚至测试恶意广告。

## 恶意软件如何注入广告

- 广告调用中的恶意软件
- 点击后注入的恶意软件
- 广告创意中的恶意软件
- 像素中的恶意软件
- 视频中的恶意软件
- Flash 视频中的恶意软件
- 登录页面上的恶意软件

## 恶意广告的缓解与预防

缓解或预防恶意广告并非易事，因此发布商和最终用户都必须采取行动。

### 面向最终用户

- 安装防病毒软件，以保护您的电脑免受恶意代码和“路过式”下载的侵害。
- 善用广告拦截器。
- 避免使用 Java 和 Flash。
- 更新插件和浏览器。

### 面向发布商

- 仔细审查广告网络，并详细询问广告投放的承诺/保证。
- 扫描展示类广告。
- 也许只在广告框架中展示特定类型的文件。

# 第 30 章：漏洞评估

这是系统地审查信息系统中安全弱点的过程。对系统进行评估，以查看是否存在任何漏洞以及漏洞的严重程度。如有需要，则推荐缓解或修复措施。漏洞评估有助于防止多种威胁，包括：

- **不安全的默认设置**：这是指带有不安全设置的软件，例如，可猜测的管理员密码。
- **XSS**、**SQL 注入** 及类似攻击
- **权限提升**

漏洞评估有不同类型，例如：

- **主机评估**：这是对关键服务器进行评估。如果未经过充分测试，它们就会变得容易受到攻击。
- **网络和无线评估**：评估实践和策略，以阻止对公共或私有网络以及通过网络可访问的资源的未授权访问。
- **数据库评估**：评估大数据系统和数据库的错误配置和漏洞，旨在识别不安全的开发/测试环境或非法数据库，并对组织中的敏感信息进行分类。
- **应用扫描**：识别 Web 应用程序中的安全漏洞，并使用自动化扫描来获取其前端的源代码。

## 漏洞评估：安全扫描的过程

此过程涉及四个步骤。

### 漏洞识别（测试）

此步骤的目的是列出应用程序漏洞的综合清单。分析师检查应用程序和任何其他系统的安全运行状况。他们要么使用自动化工具进行扫描，要么手动进行。这些分析师还依赖威胁情报源、资产管理系统、供应商漏洞公告和漏洞数据库来发现安全弱点。

### 漏洞分析

此步骤旨在找出上一步中发现的漏洞的根本原因和来源。识别导致漏洞的系统组件。例如，漏洞可能是由开源库的旧版本导致的。有了这一发现，就很容易修补漏洞。

### 风险评估

此步骤的目的是确定漏洞的优先级。安全分析师为每个弱点分配严重性评分或等级。他们考虑的因素如下：

- 漏洞可能导致的潜在损害
- 攻击的严重程度
- 妥协或攻击的难易程度
- 面临风险的业务功能
- 面临风险的数据
- 受影响的系统

### 修复

在此步骤中，所有安全缺口都将被关闭。这是开发和运维团队以及安全人员的共同努力。他们确定针对每个漏洞的最佳缓解或修复方法。

修复的具体步骤包括：

- 引入新的安全工具、措施和程序。
- 更新配置或操作变更。
- 开发并实施漏洞补丁。

> **注意**：漏洞评估不是一次性活动。

## 漏洞评估工具

这些工具旨在扫描针对您应用程序的现有和新威胁。它们包括：

- **Web 应用程序扫描器**：它们扫描并模拟攻击模式。
- **协议扫描器**：它们查找易受攻击的网络服务、端口和协议。
- **网络扫描器**：它们识别警告信号，例如可疑数据包生成、欺骗数据包和游离 IP 地址。

# 第 31 章：零日漏洞利用

这是一种网络攻击，针对软件的漏洞——该漏洞对于防病毒供应商或软件供应商而言是未知的。攻击者在其他人之前扫描软件以寻找漏洞，制定攻击计划，然后利用它渗透软件。这些攻击通常具有很高的成功几率，因为没有防御措施。因此，零日攻击应被严肃对待。常见目标包括特定文件类型（Flash、PDF、Excel 或 Word）、Web 浏览器和电子邮件附件。

## 典型目标

- **物联网 (IoT)**、固件和硬件设备
- 拥有易受攻击系统的家庭用户
- 拥有敏感业务信息访问权限的人员
- 大型企业
- 政府部门
