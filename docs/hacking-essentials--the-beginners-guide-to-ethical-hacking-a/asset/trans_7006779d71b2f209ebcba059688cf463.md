
任何可能阻碍企业建立 ISMS（信息安全管理体系）的问题，无论是外部还是内部，例如信息安全、合同、法律和法规义务，都应被识别出来。上一步骤中获得的信息用于概述 ISMS 的范围，记录所有相关领域。在此之后，ISMS 将根据 `ISO 27001` 的要求被应用、维护并持续改进。范围展示了将 ISMS 融入管理流程和结构的重要性。成千上万的组织必须遵守这些要求。为了维护 ISMS，组织的管理层需要具备相关的领导技能。这些技能包括 ISMS 的持续改进、将 ISMS 融入组织的流程、根据业务方向制定信息安全策略等。ISMS 流程应包含应对信息安全风险的计划。这包括：

*   创建并实施详细的风险管理流程。
*   概述并实施降低威胁的流程。

组织需要获取资源、基础设施和人员，以有效实施 ISMS。支持通常涉及指导和培训员工如何处理敏感信息。员工还应被告知如何为使 ISMS 更有效做出贡献，以及如果不遵守信息安全策略会发生什么后果。

运营关乎执行上述步骤中定义的流程和计划。企业应记录所采取的行动，以确保流程按计划执行。绩效评估确保 ISMS 持续改进并继续有效运行。它还会寻找任何需要改进的领域。任何不符合项一经发现应立即处理。企业还应采取必要措施，确保问题不再复发。

# 第 17 章：恶意软件类型

恶意软件是由攻击者分发的恶意软件，旨在感染组织的网络或个人计算机。它利用目标系统中的漏洞，例如缺陷。恶意软件有多种类型，每种都有其关注领域和应用场景。最常见的七种包括以下内容。

当勒索软件被安装到计算机系统和/或整个网络中时，它会加密文件。攻击者通过弹出窗口告知用户，只有支付赎金才会解密文件。勒索软件通过可疑的下载或电子邮件附件进入计算机。

最初，蠕虫被设计用于感染系统、自我复制，然后通过另一种媒介感染其他计算机。黑客利用来自许多连接设备的蠕虫创建僵尸网络。蠕虫的示例包括：

*   **NgrBot**：它通过社交网站和聊天工具传播。
*   **ILOVEYOU**：这种蠕虫利用虚假的恋爱诱饵引诱人们。用户可能会被鼓励打开一封携带蠕虫的电子邮件。

特洛伊木马是一种伪装成合法软件的恶意软件。与蠕虫不同，它不会自我复制。然而，它包含其他类型的恶意软件，如间谍软件、勒索软件、Rootkit 和后门。特洛伊木马攻击倾向于针对银行业。通常，恶意软件通过软件漏洞安装在目标计算机上。当用户访问该网站时，一个伪造的屏幕会覆盖在原页面上，请求信用卡详细信息等个人数据。

Rootkit 是预先准备好且可定制的。它们提供对应用程序敏感区域的访问权限，更改系统配置，并启用文件执行。它们通常通过社会工程学攻击部署（这可能导致登录凭证被盗），一旦安装，黑客就能访问网络。这种恶意软件会颠覆所有反恶意软件软件——攻击者随后可以为所欲为。Flame 是一个 Rootkit 的绝佳例子。它被用于监控网络流量、记录按键和窃取屏幕截图。

后门绕过访问网络所用的正常身份验证流程。它总是作为有针对性的攻击的一部分被安装。攻击者研究受害者，通过社会工程学攻击窃取其登录凭证，从而获得对网络、系统或应用程序的访问权限。后门通常试图避免被检测到，攻击者利用它们建立命令控制中心。攻击者随后可以发起系统命令并远程更新恶意软件。黑客利用后门进行各种恶意活动，包括感染访问者的计算机、拒绝服务攻击和数据窃取。当攻击者想要执行 APT（高级持续性威胁）时，这也是他们采取的第一步。

广告软件是最古老的恶意软件类型之一。它是一种免费软件，会不断弹出大量广告。它不一定是恶意软件，但非常烦人——它至今仍然存在。

间谍软件在未经你同意的情况下收集你的个人数据并将其出售给第三方（攻击者）。

# 第 18 章：物联网安全

物联网是一个连接设备的网络。每个设备都有一个唯一标识符，可通过网络自动交换和收集数据。许多行业和领域使用物联网设备，例如：

*   **消费者应用**：一些物联网消费产品包括智能家居、智能手表和智能手机。
*   **商业应用**：这些包括传感器、智能追踪器和智能安防摄像头。
*   **政府应用**：这些包括追踪野生动物的设备、发布自然灾害预警的设备和监控交通拥堵的设备。

物联网设备的广泛使用为安全问题打开了大门，此处将详细讨论这些问题。物联网设备既受外部管理（与其他设备的交互），也受内部管理（软件维护）。每个设备都连接到一个命令与控制中心（C&C），这是管理单元。这些中心负责固件更新、配置和软件维护。它们还负责任务认证。物联网设备之间的通信通过 API（应用程序编程接口）进行。当设备的 API 被暴露时，其他应用程序或设备可以通过它收集数据并进行通信。
