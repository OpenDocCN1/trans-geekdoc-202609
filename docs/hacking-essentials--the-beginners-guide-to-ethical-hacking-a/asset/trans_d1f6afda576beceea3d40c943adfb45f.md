
# 第 23 章

# 道德黑客工具

自动化工具的兴起给渗透测试或道德黑客领域带来了巨大变革。目前仍有工具正在开发中，以帮助加快测试进程。道德黑客为组织保护其系统和信息提供了一种途径。这是组织提升安全专业技能的最佳方式之一。当道德黑客成为安全措施的一部分时，公司将获益匪浅。

道德黑客中常用的工具包括：

**Nmap（网络映射器）** —— 有史以来最优秀的黑客工具之一。它用于道德黑客的一个阶段，称为端口扫描。它最初是一个命令行工具，但最终被修改以适用于基于 Unix 或 Linux 的操作系统。目前，Nmap 已有 Windows 版本。Nmap 是一款网络安全映射工具。它可以发现网络上的主机和服务，从而绘制网络拓扑图。该软件提供多种功能，用于探测计算机网络、检测操作系统以及主机发现。它支持脚本扩展，因此能够提供高级漏洞检测，并在扫描过程中适应延迟、拥塞及其他网络状况。

**Nessus** 是全球最流行的漏洞扫描器。它由 Tenable Network Security 开发。专家推荐将其用于非企业用途——它也是免费的。这款扫描器效率极高，能发现任何网络上的漏洞。以下是 Nessus 可检测的漏洞类型：

- 不同的系统漏洞
- 弱密码——常见密码和默认密码
- 配置错误和未修补的服务

**Nikto** Web 扫描器可扫描并测试大量 Web 服务器，识别危险文件或 CGI、过时软件及其他相关问题。它通过捕获接收到的 Cookie，可执行通用和特定服务器的打印与检查。该工具免费且开源。它针对 270 种服务器检查特定版本问题，并查找默认文件和程序。以下是 Nikto 的主要功能：

- 开源工具
- 检查配置错误的文件和插件
- 识别不安全的文件和程序
- 扫描服务器以查找过时版本和其他特定版本问题
- 扫描 Web 服务器以查找潜在危险文件或 6400 多个 CGI

**Kismet** 最适合用于寻找无线网络、入侵无线局域网以及测试无线网络。它通过数据流量识别网络、收集数据包，并识别隐藏和非信标网络。基本上，Kismet 是一款无线网络探测器和嗅探器。它支持原始监控模式，并配合其他无线网卡工作。以下是 Kismet 的一些基本特征：

- 有时适用于 Windows
- 运行于 Linux 操作系统

**NetStumbler** 可防止寻找无线网络攻击。它运行在 Windows 操作系统上。它能检测三种类型的网络。它还有一个名为 MiniStumbler 的新版本。

以下是 NetStumbler 的用途：

- 检测未授权的接入点
- 评估接收信号强度
- 确定干扰原因
- 识别接入点 (AP) 网络配置

# 网页抓取

这是指使用机器人从网站提取数据和内容。它不同于屏幕抓取，因为它不是复制屏幕上的像素，而是连同数据库中的数据一起提取底层的 HTML 代码。随后，抓取器可能在别处复制该网站内容。

有许多类型的数字业务依赖数据采集，并为此使用网页抓取。一些合法用途包括：

- 搜索引擎机器人抓取网站以分析其内容用于排名。
- 比价网站部署机器人从卖家网站获取产品描述和价格。
- 市场研究机构可能使用抓取器从社交媒体和论坛获取数据。

网页抓取可能被不法分子用于非法目的，如窃取受版权保护的内容和恶意压价。此类行为可能给在线实体带来严重后果，如经济损失——如果业务是内容分发商或依赖竞争性定价模型，后果更甚。

**抓取工具和模型** 是设计用于遍历数据库并获取数据的软件。会使用不同类型的机器人。它们被定制用于：

- 识别独特的 HTML 网站结构
- 存储抓取的数据
- 提取 API 信息
- 提取并修改内容

所有类型的抓取机器人都旨在从网站访问数据，因此很难区分恶意机器人和合法机器人。不过，有两个主要区别可能有助于区分两者：

- 如果机器人是合法的，它会标识使用它的公司。以 `Googlebot` 为例。在 HTTP 头中，它标识自己为 Google。
- 可疑机器人伪装成真实流量并创建虚假的 HTTP 用户代理。
- 来自合法组织的机器人遵守网站的 `robot.txt` 文件，其中列出了机器人可以访问和不能访问的所有页面。
- 恶意机器人抓取网站时不顾及任何允许规则。

运行网页抓取机器人需要大量资源。当攻击者无法承担这些资源时，会选择僵尸网络。

## 恶意网页抓取示例

未经网站所有者许可进行的网页抓取属于恶意行为。最常见的情况包括内容窃取和价格抓取。

### 价格抓取

在这种情况下，攻击者使用僵尸网络发送抓取机器人，调查竞争对手的数据库，目的是促进销售、恶意压低价格并获取定价信息。这类攻击常见于价格对购买决策影响巨大的行业。

### 内容抓取

内容抓取涉及从特定网站窃取大量内容。依赖数字内容和在线产品目录的网站最容易成为目标。

## 网页抓取防护

由于抓取机器人的进步，大多数防护措施已变得无效。粒度流量分析是对抗机器人操作的最佳方法之一。其特点是对以下因素进行交叉验证：

- HTML 指纹
- IP 信誉
- 行为分析
- 渐进式挑战
