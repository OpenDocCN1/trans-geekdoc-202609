
网络攻击与其他任何雄心勃勃的事业一样，必须经过精心策划和精确执行才能成功。根据行业研究，高级攻击在被发现前，平均会在组织系统中潜伏 200 天。想想看，这是一段很长的时间。在此期间，攻击者一直在收集数据、绘制网络拓扑图并监控通信。如果你能从攻击者的角度理解他们为成功实施攻击所采取的步骤，那么你就可以防止此类事件发生在你的组织身上，或者缩短发现攻击所需的时间。

侦察意味着在行动前先摸清情况。黑客首先确定一个薄弱的目标，然后想出最佳的利用方式。他们了解组织架构，寻找任何薄弱环节的员工，并决定是攻击第三方还是公司网站。任何人都可能成为初始目标。攻击者只需要一个切入点。一旦黑客确定了目标，他们就会寻找能够获得访问权限的弱点。他们通过使用互联网上的扫描工具检查组织网络来实现这一点。这个过程可能需要一些时间。

一旦他们发现了网络中的漏洞，就会进行访问和权限提升，在不被发现的情况下访问网络并在其中横向移动。在这种情况下，他们需要特权访问以便自由移动。诸如彩虹表之类的工具可以帮助黑客窃取凭证并获得管理员权限。然后他们可以通过管理员账户访问任何系统。有了提升的权限，入侵者基本上就接管了网络，现在“拥有”了该网络。凭借在网络中自由移动的能力，黑客可以访问组织系统中最敏感的数据并将其窃取。他们可能不仅对窃取私有数据感兴趣——如果他们愿意，还可以删除或更改文件。他们的下一步是在网络中悄无声息地潜伏。他们可能会决定安装 Rootkit 和其他恶意程序，以便随时返回。既然他们已经拥有了提升的权限，就不再依赖单一的切入点。

并非每次网络攻击都会进入攻击阶段。在这个阶段，情况可能会变得非常糟糕。入侵者可能会更改硬件功能，甚至完全禁用硬件。在这一步中，攻击者可能不再保持安静。有时，黑客会想掩盖踪迹，而其他时候，他们可能决定留下“签名”。踪迹混淆旨在使取证检查过程迷失方向、感到困惑并偏离正轨。踪迹混淆涉及的一些工具和技术包括特洛伊木马命令、僵尸账户、骨干网跳转、错误信息、欺骗和日志清理工具。根据 Mandiant 的数据，约 97% 的组织至少被攻破过一次。防御网络攻击最有效的方法是控制特权访问。

# 第 7 章

# 事件响应

![image](d2d_images/chapter_title_below.png)

在 Web 应用安全领域，事件是指对应用安全策略的尝试性违反或实际违反。篡改网站内容、数据窃取、未授权访问尝试、漏洞利用和网络入侵都是典型例子。事件响应是对此类威胁的缓解或预防。企业会采取有组织的方法来帮助他们改善网络防御并阻止安全漏洞。

这通过以下方式实现：

*   找出应用的薄弱环节。
*   加强针对威胁的安全参数。
*   保护对应用所有敏感部分/数据的访问。

即使尝试未成功，将其视为事件处理仍然是明智之举。

Web 应用防火墙（WAF）是事件响应策略中非常重要的一部分。了解它们的用法有助于你制定高效的事件响应策略。该生命周期可分为三个阶段：准备阶段、检测/分析阶段和事件后活动阶段。在每个阶段，WAF 技术扮演不同的角色。

准备阶段是一个两部分的过程。它涉及建立安全配置并测试应用是否存在弱点。你可以采取以下几个步骤来准备应对威胁，同时保护应用的敏感区域：

*   **部署 WAF**：WAF 对传入流量进行分析，并阻止所有针对应用层的攻击尝试。一些 WAF 甚至可以保护应用免受零日攻击。
*   **设置访问控制策略**：识别并保护包含敏感信息的应用和网站部分。这通过 `2FA`（双因素认证）完成。它提供额外的访问控制。
*   **安全编排**：通过简化安全措施来开发一个连贯的工作流。例如，重新定义每个安全团队成员的任务和角色。
*   **弱点测试**：通常使用渗透测试来测试你的应用，以查看是否有任何可以被入侵者利用的软肋。然后进行调整以修补已识别的软肋。

一旦部署，安全措施就会分析和过滤所有传入的 Web 流量。如果检测到任何事件，它们会阻止恶意请求、发出警报，并将有关威胁的所有详细信息记录在称为事件检测分析的综合安全日志中。

日志包括：

*   犯罪者的地理位置和 IP 数据。
*   攻击向量。
*   入侵者的 HTTP 指纹。
*   尝试进入的页面。

当你拥有安全事件的详细描述时，你就可以理解它并制定适当的响应。事件后活动是整个过程的最后阶段，致力于利用前几个阶段学到的经验教训。它包含三个部分：

*   审查日志，以确定事件是否暴露了任何软肋。
*   更改 WAF 规则并制定新策略以消除弱点。
*   测试新规则。

“冲洗并重复”是一个持续的过程。每个事件都是一个学习机会。它将帮助你提高企业的安全性并增强准备程度。
