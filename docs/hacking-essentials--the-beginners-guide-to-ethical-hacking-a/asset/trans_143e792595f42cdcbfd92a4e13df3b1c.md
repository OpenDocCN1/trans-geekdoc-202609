
此外，企业必须限制对持卡人数据的访问，并监控对所有网络资源的访问。当您的企业符合 PCI 标准时，客户可以确信其信息是安全的。此外，不合规带来的声誉和经济损失足以让任何企业重视数据安全。根据每年的借记卡或信用卡交易数量，PCI 合规分为四个级别。此分类决定了企业所需满足的要求。

**1 级**：适用于每年处理超过 600 万笔卡交易的商户。必须进行年度内部审计，且须由 PCI 审计师执行。他们还必须每季度接受一次 ASV（认证扫描供应商）的 PCI 扫描。

**2 级**：适用于每年处理 100 万至 600 万笔卡交易的企业。他们每年需要使用自评问卷 (SAQ) 进行一次评估。每季度进行一次 PCI 扫描也可能是必要的。

**3 级**：适用于每年处理 20,000 至 100 万笔交易的企业。必须使用适当的 SAQ 进行年度评估。他们可能需要接受每季度一次的 PCI 扫描。

**4 级**：适用于每年处理不超过 20,000 笔卡交易的企业。需要进行年度 SAQ 评估。他们也可能需要接受每季度一次的 PCI 扫描。

PCI SSC 制定了 12 项要求，在处理持卡人数据时必须遵守。这些要求分布在六大目标中。企业必须满足这些要求才能实现合规。

# 后门攻击

后门攻击是一种恶意软件，它绕过正常的身份验证流程以访问网络。因此，攻击者获得了对应用程序中资源的远程访问权限。一旦实现这一点，实施者就可以远程发布系统命令，甚至更新恶意软件。攻击者通过利用 Web 应用程序中任何易受攻击的区域来实现后门安装。安装后，由于文件在大多数情况下高度隐藏，因此很难被检测到。Web 服务器后门可用于各种恶意活动，例如：

*   服务器劫持
*   高级持续性威胁 (APT) 攻击
*   感染网站访问者
*   发起 DDoS 攻击
*   数据窃取
*   网页篡改

后门通常通过远程文件包含 (RFI) 来安装。这是一种攻击载体，它利用动态引用外部脚本的应用程序中的弱点。在 RFI 情况下，引用函数会从远程主机下载一个后门木马。

黑客通常使用扫描器寻找目标；他们识别出具有过时或未修补组件且允许文件注入的网站。扫描器一旦成功，就会利用该漏洞将后门安装到底层服务器中。安装后，攻击者可以随时访问它，即使漏洞修补很久之后也是如此。在大多数情况下，后门木马注入分两步进行，以绕过限制上传超过特定大小文件的安全规定。第一步，安装一个投放器——这是一个仅用于获取较大文件的小文件。然后启动第二步，涉及将后门脚本下载并安装到服务器中。

## 后门 Shell 移除：挑战

后门不易根除。通常，检测是通过软件扫描器识别系统中已知的恶意软件签名来执行的。这种方法容易出错。后门 Shell 通过代码混淆和别名来隐藏。在其他情况下，会使用多层加密。检测绝非易事，因为许多应用程序是基于外部框架（使用第三方插件）创建的。有时这些插件内置了后门或漏洞。依赖基于签名和启发式规则的扫描器无法有效识别此类框架中隐藏的代码。

即使扫描器检测到了后门，使用典型的缓解策略也很难将其从应用程序中清除。如果后门在可重写内存中反复出现，情况尤其如此。

## 利用 Imperva 减少后门 Shell 攻击

Imperva 结合了经过验证的多种方法来阻止后门安装，以及检测和隔离任何现有的后门 Shell。Imperva WAF (Web 应用程序防火墙) 结合用户定义和默认安全规则，阻止 RFI 攻击感染您的应用程序。该 WAF 部署在您网络的边缘，在恶意请求与您的应用程序交互之前将其拦截。如果您已经拥有一台被攻陷的 Web 服务器，Imperva 拥有后门防护解决方案，可从您的系统中检测并清除 Shell。

# ISO/IEC 27001

它也被称为 ISO 27001，是一项安全标准，规定了创建、跟踪和改进 ISMS（信息安全管理体系）的建议要求。ISMS 是一套管理和保护企业敏感信息的策略集合。服务提供商自愿采用 ISO 27001 以确保客户信息安全。必须由经认可的独立机构正式审核组织以确认合规性。与通过 ISO 27001 认证的服务提供商合作有诸多益处：

*   **风险管理**：ISMS 规定谁可以访问特定信息。降低了该信息被泄露的风险。
*   **信息安全**：ISMS 拥有信息管理协议，规定如何处理特定数据。
*   **业务连续性**：服务提供商的 ISMS 必须持续接受测试和改进，以保持 ISO 27001 合规性。这可以防止数据泄露。

ISO 27001 合规性对于建立信息安全治理政策至关重要。构建符合 ISO 标准的 ISMS 过程全面且包含支持、培训、规划和范围界定。在企业获得认证之前，必须解决几个重要要素。
