重新定义所有权权利（NFT 不仅仅是关于数字艺术和小猫！）

跟踪 CryptoKitties（或 Beeple 的 NFT）的所有权和血统仅仅是 NFT 所能实现的开始。运行良好的市场需要明确且可强制执行的所有权权利。人们往往忽视了作为这一重要目的服务的可信中介——例如，他们依赖县登记处来维护房产所有权记录，依赖机动车管理局（DMV）来维护车辆产权记录。现在，NFT 正在提供一种去中心化的方式来铭记交易并验证所有权。

NFT 不仅仅是区块链上受加密保护的位置，正如 Beeple NFT 的情况一样。在现代，转移所有权意味着转移对特定资产（无论是汽车、房屋还是数字图像）拥有的法律权利。 ("Finders, keepers" 不是对汽车盗窃指控的合法辩护。) 这个框架与 NFTs 非常契合，NFTs 可以被创建为法律上代表所有权、产权或许可的凭证。

总体而言，NFTs 有潜力可靠地追踪点对点的所有权记录转移，而无需可信的第三方来验证这些交易的完整性。它们能够即时追踪并验证每个唯一项目的所有权，使它们特别适合颠覆任何验证唯一项目溯源存在缺陷或不足的市场。

NFTs 和数字资产

追踪数字资产是 NFTs 的自然起点。

从数字收藏品到游戏物品和数字媒体，NFTs 有潜力真正民主化创作者经济。

音乐、电影和书籍

直到最近，消费者必须拥有音乐才能随时收听。从唱片到磁带，从 CD 到 mp3s，拥有实体或数字媒体的所有权被视为既定事实。

尽管数字音乐的便利性，但拥有和出售实体媒体仍然让人感到安心——艺术家知道只有单个实例可以同时播放，一旦转让，消费者就不再能访问。因此，第一 sale 教义被制定，规定购买者可以在不获得版权持有者许可的情况下转售实体副本。

现在，似乎拥有音乐已成过去——流媒体服务远远超过购买和下载音乐。这种情况自然是合理的，因为数字复制不会降低质量，因此美国版权局对数字传输的适用第一 sale 教义持犹豫态度。任何人都可以轻松出售他们购买的数字音乐，同时在个人设备上保留一份副本。

游戏资产

随着在线角色扮演游戏（如 EverQuest 和 League of Legends）的流行，游戏内的资产开始从玩家手中获得真实世界的美元，玩家渴望通过积累在-game 财富更快或通过展示独特的游戏内物品来获得地位。

玩家在 eBay 或 Player-Auctions 等市场上列出资产，承诺在付款后将资产在游戏内转移（这一过程本身充满风险）。NFTs 提供了可靠地代表游戏资产和头像的所有权的方式，并通过智能合约实现自动化的点对点转移。想象一个游戏世界，拥有真正民主化的资产所有权和交换——经验丰富的玩家保留更多销售收入，新手玩家以更低的价格购买游戏声望，点对点交易即时且几乎无风险。
