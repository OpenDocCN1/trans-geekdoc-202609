
# Introduction

欢迎阅读《NFTs For Dummies》！如果你对 NFTs（它们的起源、用例和底层技术）感到好奇，这本书就是为你准备的。

在这本书中，你可以找到有用的信息和建议，帮助你探索 NFTs 世界。你还可以获得实用的逐步指南，教你如何设置热钱包来存储 NFT、如何在 NFT 市场平台上导航，甚至如何编写自己的 NFT。

你不需要在编程、数学、合同理论或经济学方面有背景知识才能理解本书。我们会在其中融合这些元素，以展现 NFTs 的多学科特性及其所代表的意义。

## About This Book

本书自然会解释 NFT 的基础知识，同时也会涉及智能合约和区块链技术，说明 NFT 如何得到保障以及如何运作。此外，我们还涉及多种经济和法律主题，以展示通过 NFT 可能实现的丰富可能性。

本书旨在满足各类读者的兴趣——从轻松的游戏到未来 NFT 用例的前瞻性思考，再到技术层面的详细解释，涵盖支撑 NFT 的智能合约内部工作原理以及保障它们的区块链技术。

你不必通读全书即可理解各个独立章节。本书提供可定制的阅读路径，适合所有受众：无论你只是想学习 NFT 行话，还是有兴趣购买和出售 NFT，亦或是充满热情想编写并部署自己的 ERC-721 非同质化代币。
