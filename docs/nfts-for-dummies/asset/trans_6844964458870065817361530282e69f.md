区块链是支撑 NFT 的底层技术。

（你可能听说过区块链，但可能不了解其中的许多方面。）区块链是一种分布式账本系统，信息可以安全可靠地存储，且对这些存储信息的任何修改都必须遵守严格规则。例如，没有任何单一参与者可以在未让整个系统知晓的情况下修改数据。（你可能觉得这不是一个有趣的策略，但区块链之前的数据由拥有类似神权的管理员保护。）

NFT 的价值来源于其作为可信的溯源记录。你可以在系统的区块链上高效且可验证地记录你与另一方之间的交易。你 NFT 的转让记录成为不可篡改的共享记忆，在全球范围内分布，并具备严格的内置问责特性。

用户之间的交易

NFT 可以在点对点的基础上进行交易，无需中介。在这种模式下，交易直接在两个人或两组之间进行，而不是通过一名个人（或公司）作为所有交易的中介来促成和监控。这意味着你不需要依赖像 eBay 或 Amazon 这样的第三方来购买他人的东西；你只需用手机自己完成交易。

允许用户之间无中介地进行交易的内部交换机制称为去中心化交换（DEXes），它们让你可以独立于第三方出售资产——因为中央化交易所容易受到盗窃攻击。由公司运行的交易所要求系统由单一 party 控制，这削弱了区块链的力量并将其转化为对用户的不利。

如果从公司交易所中窃取一项资产，几乎无法再恢复。

启用智能合约

NFT 通过智能合约实现去中心化交换——这些智能合约是运行在具有 NFT 数据访问权限的账本节点上的计算机脚本。例如，当你购买 CryptoKitty 时，你购买的是一件独特的数字艺术品，其所有权代码会在支付完成后自动转移——无需第三方中介。该系统通过消除中介以降低风险并加快交易速度。正如我们之前提到的电子邮件例子，现在可以瞬间将所有权交换给世界任何人。

创建数字稀缺

CryptoKitties 团队通过其数字收藏品解决了单个项目的数字稀缺概念。每只 CryptoKitty 都是独一无二的——没有两只相同。数字商品（这本身并非新概念）在现实中已有估值。例如，World of Warcraft 的金币农场使用 Steam 平台的在线市场，玩家可以在自己的电脑游戏库中买卖游戏内物品。然而，这个领域最初局限于视频游戏，缺乏区块链所提供的功能。你可以找到大量黑客、作弊或开发者操纵生态系统的案例。

数字收藏品拥有巨大的潜力，最初从数字猫开始，随后扩展到各种收藏品和艺术品。

» 数字收藏品的目的与功能：实物收藏品之所以受欢迎，是因为其预定目的。
