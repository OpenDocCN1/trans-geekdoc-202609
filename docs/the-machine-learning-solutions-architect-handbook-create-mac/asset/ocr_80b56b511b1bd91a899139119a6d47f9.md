+   - Run trigger: You use a run trigger to kick off the execution of a pipeline. A run trigger can be a periodic trigger (for example, to run every 2 hours), or a scheduled trigger (for example, run at a specific date and time).

+   - Output artifacts: Output artifacts are the outputs from the pipeline components. Examples of output artifacts could be model training metrics or visualizations of datasets.

Keflow Pipelines is installed as part of the Keflow installation. It comes with its own UI, which is part of the overall Keflow dashboard UI. The Pipelines service manages the pipelines and their status and stores them in a metadata database. There is an orchestration and workflow controller that manages the actual execution of the pipelines and the components. You author the pipeline using the Keflow SDK in Python. To create and run a pipeline, follow these steps:

+   - Create a pipeline definition using the Keflow SDK. The pipeline definition specifies a list of components and how they are joined together in a graph.

+   - Compile the definition into a static YAML specification to be executed by the Keflow Pipelines service.

+   - Register the specification with the Keflow Pipelines service and call the pipeline to run from the static definition.

+   - The Keflow Pipelines service calls the API server to create resources to run the pipeline.

+   - Orchestration controllers execute various containers to complete the pipeline run.
