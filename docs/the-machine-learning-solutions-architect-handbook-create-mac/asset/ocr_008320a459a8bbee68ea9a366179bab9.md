Let's complete the following steps to get started:

+   1. Launch the AWS CloudShell service.

Log on to your AWS account, select the Oregon region, and launch the AWS CloudShell. CloudShell is an AWS service that provides a browser-based Linux terminal to interact with AWS resources. With CloudShell, you authenticate using your AWS console credential and can easily run AWS CLI, AWS SDK, and other tools.

+   2. Install the kubectl utility.

Run the following commands one by one in the CloudShell terminal. The kubectl utility is a command-line utility for managing the EKS cluster. We will use the kubectl utility to create a Kubernetes cluster on Amazon EKS in Step 4:

```
curl --silent --location "https://github.com/weaveworks/eksctl/releases/latest/download/eksctl_$(uname -s)_amd64.tar.gz"
tar z -x -C /tmp
```

```
chmod +x /tmp/kubectl
```

```
sudo mv /tmp/kubectl /bin/kubectl
```

```
export PATH=$PATH:/home/cloudshell-user/bin
```

+   3. Install the AWS IAM Authenticator.

Inside the CloudShell service, run the following commands one by one to download the AWS IAM Authenticator software. The AWS IAM Authenticator authenticates to the Kubernetes cluster running on Amazon EKS with your AWS credential:

```
curl -o aws-iam-authenticator https://amazon-eks.s3.us-west-2.amazonaws.com/1.19.6/2021-01-05/bin/linux/amd64/aws-iam-authenticator
```

```
chmod +x ./aws-iam-authenticator
```

```
sudo mv aws-iam-authenticator /bin/aws-iam-authenticator
```
