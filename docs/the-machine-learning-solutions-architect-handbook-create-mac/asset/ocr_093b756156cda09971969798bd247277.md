# Amazon Transcribe

Amazon Transcribe (Transcribe) is a speech-to-text AI service. It can be used to transcribe video and audio files and streams to text for a range of use cases, such as media content and meeting subtitle, call analytics, and converting medical conversations into electronic health records.

Amazon Transcribe supports both real-time transcription and batch transcription and has the following capabilities:

+   **Media transcription:** Transcribe has pre-trained models for converting media files or streams into different languages, such as English, Chinese, and Spanish. It also adds punctuation and capitalization to make the transcribed text more readable. To kick off transcription, you can use the StartTranscriptionJob and StartMedicalTranscriptionJob APIs for transcription, the StartTranscriptionAPI for streaming transcription, and the StartMedicalTranscriptionAPI for streaming medical input.

+   **Custom models:** You can provide your training data to create custom language models to increase the accuracy of the transcription for industry-specific terms or acronyms. The API for creating custom models is CreateLanguageModel.

+   **Call analytics:** Transcribe provides building analytics capabilities for calls. The transcripts for calls are displayed in a turn-by-turn format. Examples of supported analytics include sentiment analysis, call categorization, issue detection (the reason behind the call), and call metrics (non-talk time, loudness, interruption). The API for starting a call analytics job is StartCallAnalyticsJob.

+   **Redaction:** Transcribe can automatically mask or remove sensitive identifiable information (PII) from the transcripts to preserve privacy. When transcribing with redaction, Transcribe replaces PII information with [PII] in the transcript. To enable redaction, you can configure the ContentRedaction parameter in the batch transcription jobs.
