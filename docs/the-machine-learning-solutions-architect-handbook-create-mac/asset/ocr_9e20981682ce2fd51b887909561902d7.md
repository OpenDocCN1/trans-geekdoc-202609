+   1. Human review: To ensure the high accuracy of the extracted data by Textract, a human-in-the-loop process can be implemented to verify low confidence predictions and manually correct them. This human-in-the-loop workflow can be implemented using the Amazon Augmented AI service.

+   2. Document classification: The JSON outputs are processed to generate classification predictions using the custom Comprehend model that has been trained.

+   3. Update downstream systems: The prediction outputs are passed to downstream systems for further processing.

There are alternative architecture options available. For example, you can also treat documents as images and perform image classification using the Recognition service. Another option is to train a custom model using your algorithms, such as LayoutLM, and prepare a training dataset with the output of Textract. It is prudent to validate multiple options to achieve the optimal price/performance trade-off when deciding on the right technology.
