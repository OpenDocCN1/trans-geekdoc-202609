```python
import pandas as pd
import mlflow
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import OrdinalEncoder
```

```python
churn_data = pd.read_csv("churn.csv")
```

```python
encoder = OrdinalEncoder()
churn_data['Geography_code'] = encoder.fit_transform(churn_data['Geography'])
churn_data['Gender_code'] = encoder.fit_transform(churn_data['Gender'])
churn_data.drop(columns=['Geography', 'Gender', 'RowNumber', 'Surname'], inplace=True)
```

```python
# Split the dataset into training (80%) and testing (20%)
churn_train, churn_test = train_test_split(churn_data, test_size=0.2)
```

```python
# Split the features from the target variable "Exited" as it is required for model training
churn_train_X = churn_train.loc[:, churn_train.columns != 'Exited']
churn_train_y = churn_train['Exited']
```

```python
churn_test_X = churn_test.loc[:, churn_test.columns != 'Exited']
churn_test_y = churn_test['Exited']
```

```python
# setting mlflow tracking server
tracking_uri = <tracking server uri>
mlflow.set_tracking_uri(tracking_uri)
```

```python
mlflow.set_experiment('customer churn')
mlflow.sklearn.autolog()
```

```python
with mlflow.start_run():
    bank_churn_clf = RandomForestClassifier(max_depth=2, random_state=0)
    bank_churn_clf.fit(churn_train_X, churn_train_y)
    mlflow.sklearn.log_model(sk_model=bank_churn_clf, artifact_path="sklearn-model", registered_model_name="churn-model")
```

- **Deploy the model to Seldon Core:** You have successfully trained an ML model and registered the model in the MLflow model registry. Next, let's deploy this model using the Seldon Core serving framework.

Let's download the model artifacts from the model registry and save them to a deployment bucket in S3. To do this, first, create a new S3 bucket called model-deployment-<your initial>. We will be using Seldon Core’s sklearn serving package to host the model, and it expects the model name to be model.joblib. Run the following code block to download the model artifacts from the model registry, copy the model.pkl file to another directory, and name it model.joblib:

```python
import mlflow.sklearn
import shutil
model_name = "churn-model"
model_version = <version>
```

```python
sk_model = mlflow.sklearn.load_model(f"models:{model_name}/{model_version}")
mlflow.sklearn.save_model(sk_model, f"{model_name}_{model_version}")
```

```python
src = f"{model_name}_{model_version}/model.pkl"
des = f"skserver_{model_name}_{model_version}/model.joblib"
```

```python
shutil.copy(src, des)
```

Next, run the following code to upload the model to S3:

```python
import boto3
import os

s3 = boto3.client('s3')
bucket_name = "model-deployment-<your initial>"
s3.upload_file(des, bucket_name, os.path.basename(des))
```

The tracking server is now ready, and the bucket contains the model.joblib file. We can now proceed with the Seldon Core deployment.
