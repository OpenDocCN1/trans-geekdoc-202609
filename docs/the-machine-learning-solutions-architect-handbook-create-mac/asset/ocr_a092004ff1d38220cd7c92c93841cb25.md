Next, we must build a MLP network with two hidden layers (one with 100 nodes and one with 50 nodes) and an output layer with 10 nodes (each node represents a class label). Then, we will compile the network using the Adam optimizer, we use the cross-entropy loss as the optimization objective, and the accuracy as the measuring metric. The Adam optimizer is a variation of gradient descent (GD), and it improves GD mainly in the area of the adaptive learning for updating the learning rate to improve model convergence, whereas GD uses a constant learning rate for parameter updating. Cross-entropy measures the performance of a classification model, where the output is the probability distribution for the different classes up to 1. The cross-entropy error increases when the predicted distribution diverges from the actual class label. To kick off the training process, we will run the training for 10 epochs. One epoch is one pass of the entire dataset:

```
model = tf.keras.Sequential([
tf.keras.layers.Flatten(),
tf.keras.layers.Dense(10, activation="relu\),
tf.keras.layers.Dense(50, activation="relu\),
tf.keras.layers.Dense(10)
tf.keras.layers.Softmax())
])
model.compile(optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(),
    metrics=[tf.keras.metrics.SparseCategoricalAccuracy()])
```

```
model.fit(train_ds, epochs=10)
```

When the model is training, you will see a loss metric and accuracy metrics being reported for each epoch.
