4. Now, we can create a CodePipeline pipeline CloudFormation template for automatic model deployment. This pipeline has two stages:

+   I. The first stage fetches source code (such as the configuration file we just created and mdeployment.yaml template) from a CodeCommit repository.

+   II. The second stage creates a CloudFormation change set (a change set is the difference between a new template and an existing CloudFormation stack) for the mdeployment.yaml file we created earlier. It adds a manual approval step and deploys the CloudFormation template mdeployment.yaml file.

This CloudFormation template also creates supporting resources, including an S3 bucket for storing the CodePipeline artifacts, an IAM role for CodePipeline to run with, and another IAM role for CloudFormation to use the stack for mdeployment.yaml.
