# Training the BERT model in the Jupyter Notebook

In this part of the hands-exercise, we will train a financial sentiment analysis NLP model using the BERT transformer, which we learned about *Chapter 3, Machine Learning Algorithms*. To get started, double-click on the newly cloned folder view and create a new notebook to author our code by selecting **File** > **New** > **Notebook** from the menu dropdown in the folder. When prompted to select a kernel, pick **Python 3 (PyTorch Python 3.6 GPU Optimized)**. You can rename the file so that it has a more meaningful name by selecting **File** > **Rename Notebook** from the menu.
