+   **Model evaluation:** For model selection, hyperparameter tuning, and model evaluation metrics. Spark ML provides utilities for cross-validation. You can find the list of evaluators at https://spark.apache.org/docs/latest/api/python/pyspark.ml.evaluation.MulticlassClassificationEvaluator.html?highlight=model%20evaluation:

```
from pyspark.ml.evaluation import
BinaryClassificationEvaluator
```

```
dataset = spark.createDataFrame(scoreLabels, ["raw",
"label"])
evaluator = BinaryClassificationEvaluator()
evaluator.setRawPredictionCol("raw")
```

```
evaluator.evaluate(dataset, {evaluator.metricName:
"areaUnderPR"})
```

+   **Pipeline:** Spark ML also supports the pipeline concept, similar to that of scikit-learn. With the pipeline concept, you can sequence a series of transformation and model training steps as a unified repeatable step:

```
from pyspark.ml import Pipeline
from pyspark.ml.classification import LogisticRegression
from pyspark.ml.feature import HashingTF, Tokenizer
```

```
lr_tokenizer = Tokenizer(inputCol, outputCol)
l_hashingTF = HashingTF(inputCol=tokenizer,
getOutputCol(), outputCol)
lr_algo = LogisticRegression(maxIter, regParam)
```

```
lr_pipeline = Pipeline(stages=[lr_tokenizer, lr_
hashingTF, lr_algo])
lr_model = lr_pipeline.fit(training)
```
