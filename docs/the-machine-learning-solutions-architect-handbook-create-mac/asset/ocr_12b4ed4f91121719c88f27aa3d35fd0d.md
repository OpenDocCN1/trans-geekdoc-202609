Gradient boosting works well with imbalanced datasets, and it is good for use cases as risk management and fraud detection where the dataset tends to be unbalanced. One major shortcoming of gradient boosting is that it does not parallelize as it creates trees sequentially. It is also prone to noise, as outliers in the data, and can revert easily as a result of this. Gradient boosting is less interpretable than a decision tree, but this can be easily overcome with tools as variable importance (feature importance).

XGBoost is an implementation of gradient boosting. It has become very popular as a result of winning many Kaggle competitions. It uses the same underlying concept to build and tune the trees, but improves upon gradient boosting providing support for training a single tree across multiple cores and multiple CPUs for faster training, more powerful regularization techniques to reduce the complexity of the model, and combat overfitting. XGBoost is also better at handling sparse datasets. In addition to XGBoost, there are other variations of gradient boosting trees, such as LightGBM and CatBoost.

# K-nearest neighbor algorithm

K-nearest neighbor (K-NN) is a simple classification and regression algorithm. It is also a popular algorithm for implementing search systems and recommendation systems.

The fundamental assumption that K-NN works under is similar things having proximity. The way to determine the proximity is to measure the distances between different data points. For classification tasks, K-NN first loads the data and their respective class labels. When we need to classify a new data point, we calculate its distances first, for example, the Euclidean distance to other loaded data points. We retrieve the labels for the top K (the K in K-NN) closest data points and use majority voting (the most frequent labels among the top K data points) to determine the class label for the new data point. The predicted scalar value will be the averaged values of the K closest data points for regression tasks.

K-NN is simple to use and there is no need to train or tune the model with hyperparameters other than choosing of neighbors (K). The data points are simply loaded in the K-NN algorithm. Its results can be easily explainable, as each prediction can be explained by the properties of the nearest neighbors. In addition to classification and regression, it can also be used for search. However, the model grows in complexity as the number of data points increases, and it can become significantly slower with a large dataset for predictions. It also not work well when the dataset dimension is high, and it is sensitive to noisy data and missing data. Outliers will need to be removed, and missing data will be imputed.
