# # Hands-on exercise

In this hands-on exercise, we will build a Jupyter Notebook environment on your local machine and build and train an ML model in your local environment. The goal of the exercise is to get some familiarity with the installation process of setting up a local data science environment, and learn how to analyze the data, prepare the data, and train an ML model using the algorithms we covered in the preceding sections. First, let's take a look at the problem statement.

# # Problem statement

Before we start, let's first review the business problem that we need to solve. A retail bank is experiencing a high customer churn rate for its retail banking business. To proactively implement preventive measures to reduce potential churn, the bank needs to know who the potential churners are, so the bank can target those customers with incentives directly to prevent them from leaving. From a business operating perspective, it is much more expensive to acquire a new customer than offering incentives to keep an existing customer.

As an ML solutions architect, you have been tasked to run some experiments to validate the ML approach for this problem. There is no ML tooling available, so you have decided to set up a Jupyter environment on your local machine for this task.

# # Dataset description

You will use a dataset from the Kaggle for bank customers' churn for modeling. You can access the dataset at `https://www.kaggle.com/mathchi/churn-bank-customers`. The dataset contains 14 columns for features such as credit score, gender, and balance, and a target variable, Exited, to indicate if a customer churned or not. We will review these features in more detail in later sections.
