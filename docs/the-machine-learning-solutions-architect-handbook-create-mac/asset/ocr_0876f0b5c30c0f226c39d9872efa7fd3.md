The degree of parallel executions in a CPU mainly depends on how many cores it has. Each core normally runs a single thread at a time, for hyper-threading (a proprietary simultaneous multi-threading implementation from Intel). The more cores it has, the higher the degree of parallel executions. A CPU is designed to handle a large set of instructions and manage the operations of many other components; it usually has high performance and a complex core, they aren't many of them. For example, the Intel Xeon processor can have up to 56 cores.

CPUs are usually not suited for neural network based model inference if low latency is the main requirement. Neural network inference involves operations that can be parallelized at a large scale (for example, matrix multiplication). Since the total of cores for a CPU is usually small, it cannot be parallelized to meet the needs of a neural network inference. On the positive side, CPUs are more cost-effective and usually have good memory capacities for hosting larger.

# Graphical processing units (GPUs)

The design of a GPU is the opposite of the design of a CPU. Instead of having a few powerful cores, it has thousands of less powerful cores that are designed to perform a small set of instructions highly efficiently. The basic design of a GPU core is like that of CPU. It also contains a control unit, ALU, and a local memory cache. However, the GPU control unit handles a much simpler instruction, and the local memory is much smaller.

When the GPU processes instructions, it schedules blocks of threads, and within each block of threads, the threads perform the same operations on different pieces of data - a parallelization scheme called Single Instruction Multiple Data (SIMD). This architecture fits nicely with how a DL model works, where many neurons perform the same operation (mainly matrix multiplication) on different pieces of data.
