+   2. Now, we import the library and load the sample training data. We will use the built-in fashion_mnist dataset that comes with the keras library to load so. Next, we will load the data into a tf.data.Dataset class and then call its batch() function to set up a batch size. Run the following code block in a new cell to load the data and configure the dataset:
```python
import numpy as np
import tensorflow as tf
tf.enable_eager_execution()

train, test = tf.keras.datasets.fashion_mnist.load_data()
images, labels = train
labels = labels.astype(np.int32)
images = images/256
train_ds = tf.data.Dataset.from_tensor_slices((images,
labels))
train_ds = train_ds.batch(32)
```
