# Networking on Kubernetes

Kubernetes operates a flat private network among all the resources in a Kubernetes cluster. Within a cluster, all Pods can communicate with each other cluster-wide without a network address translation (NAT). Kubernetes gives each Pod its own cluster private IP address, and the IP is the same seen by the Pod itself and what others see it. All containers inside a single Pod can reach each other's port on the localhost. All nodes in a cluster have their individually assigned IPs and can communicate with all Pods without a NAT.
