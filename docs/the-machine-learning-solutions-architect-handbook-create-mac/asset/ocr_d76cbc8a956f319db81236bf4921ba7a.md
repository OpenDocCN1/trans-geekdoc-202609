# Installing Python 3 on macOS

Python 3 can be downloaded and installed directly from https://www.python.org/downloads/. An easier way is to install it using a package manager such as Homebrew. In the following section, we will use Homebrew to install Python3.

# Installing Homebrew, Python3, and PIP3

Homebrew can be downloaded by following the instructions at https://brew.sh/. Installing Homebrew will also install Python 3. The specific steps are listed as follows:

+   - Open a terminal window on your Mac machine.

+   - Inside the terminal, type and run the following command to start installing Homebrew:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" /
```

+   - Enter your Mac user password when prompted during the installation.

+   - After the previous script completes, run the following command inside the Terminal to get the latest versions of the packages:

```
brew update && brew upgrade python
```

+   - Point to the Homebrew Python by typing and running the following command. It will make the current Terminal window use the Homebrew Python installation:

```
alias python=/usr/local/bin/python3
```

+   - Verify the Python installation and version by running the following command inside the Terminal:

```
python -version
```
