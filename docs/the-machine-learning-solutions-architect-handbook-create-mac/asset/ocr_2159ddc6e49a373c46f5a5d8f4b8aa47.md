For the execution role dropdown, choose the Create new role option, keep all the default options on the pop-up screen as-is, and create the role. The execution role provides permission to access different resources, such as S3 buckets, and will be associated with Studio notebooks, which we create later.

+   3. Lastly, click on the Create button to set up the domain and user. It will take a few minutes for the domain to be set up.

Additionally, the following resources are also created during the process:

+   - An S3 bucket for the domain: The name of domain should look like sagemaker-studio-<AWS account number>-XXXX. This bucket can be used for storing datasets and model artifacts.

+   - Elastic File System volume: This volume is used by the Studio domain for storing user data. If you navigate to the EFS management console, you should see that a new filesystem has been created.
