For model quality monitoring, it creates baseline metrics (such as MAE for regression and accuracy for classification) using the dataset, which contains both predictions and true labels. Then, it captures the predictions in production, ingests truth labels, and merges the ground truth with the predictions to calculate various regression and classification metrics before comparing those with the baseline metrics. Similar to drift metrics, model quality metrics can be sent to CloudWatch Metrics for analysis and visualization, and CloudWatch Alarms can be configured for automated notifications and/or responses.
