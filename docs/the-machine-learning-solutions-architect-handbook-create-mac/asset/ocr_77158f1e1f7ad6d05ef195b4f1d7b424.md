To access the mlflow tracking server site, look up the public DNS name for the EC2 and enter it into the browser. The address should look something like the following example:

```
http://<EC2 public url>:5000.
```

Please note, the MLflow tracking server does not have built-in security, so the tracking server is publicly accessible. You should stop/terminate the tracking server when it is not in use. For secured access to the tracking server, you can set up a secure proxy server in front of the tracking server, which is out of scope for this book.
