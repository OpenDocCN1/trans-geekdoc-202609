## 金融服务中的 ML 用例

金融服务业（FSI）是技术最先进的行业之一，也是 ML 投资和应用的先驱。在过去的几年里，我看到金融服务内部的不同业务职能采用了广泛的 ML 解决方案。在资本市场，ML 被用于前台、中台和后台部门，以支持投资决策、交易优化、风险管理和交易结算处理。在保险领域，承保商正在使用 ML 来简化核保、防止欺诈并自动化理赔管理。银行则正在使用 ML 来改善客户体验、打击欺诈并做出贷款审批决定。接下来我们将讨论金融服务中的几个核心业务领域，以及如何使用 ML 来解决这些业务挑战。

### 资本市场前台

在金融领域，前台是直接产生收入的业务领域，主要由面向客户的角色组成，如销售、交易员、投资银行家和财务顾问。前台部门通过产品和服务与客户互动，例如兼收购（M&A）和 IPO 咨询、财富管理，以及作为权益（例如股票）、固定收益（例如债券）、大宗商品（例如石油）和货币产品的金融资产交易。现在，让我们来看看前台区域的某些特定业务职能。

## 销售交易与研究

在销售交易中，公司的销售人员会监控投资新闻（如财报或兼收购活动），并寻找投资机会向其机构客户推销。随后，交易人员为客户执行交易，这被称为代理交易（agency trading）。交易人员也可以为他们所属的公司执行交易，这被称为自营交易（prop trading）。交易人员通常需要交易大量证券。因此，优化交易策略以优惠价格获取股票而不推高价格至关重要。销售和交易人员受研究团队的支持，研究团队专注于研究和分析股票及固定收益资产，并向销售交易人员提供建议。

另一种交易类型是算法交易，使用计算机根据预定义的逻辑和市场状况自动进行证券交易。销售交易和研究中的一些核心挑战如下：

- 研究分析师交付研究报告的时间非常紧迫。
- 需要收集大量的市场信息以收集和分析交易策略，并做出明智的交易决策。
- 需要不断监控市场以调整交易策略。
- 在不推高或压低市场的情况下，以理想价格实现最佳交易。下图所示了销售交易台的业务流，以及不同参与者如何互动以完成交易活动：

销售交易和研究中有许多 ML 的机会。**自然语言处理（NLP）**模型可以从 SEC 备案、新闻公告和财报会议等数据源中自动提取人物、事件、组织和地点等关键实体。NLP 还可以发现所发现实体之间的关系，并通过分析大量的新闻、研究报告和财报会议来帮助理解市场对其及其股票的情绪，从而指导交易决策。

**自然语言生成（NLG）**可以协助叙述写作和报告生成。计算机视觉已用于从卫星图像等替代数据源中识别市场信号，以理解零售客流量等业务模式。在交易中，ML 模型可以筛选大量数据，利用公司基本面、交易模式和技术指标等数据点发现相似性等模式，从而指导配对交易（pair trading）等交易策略。

### 投资银行

当公司、政府和机构需要资金来运营和增长时，他们会聘请投资银行家进行融资（出售股票或债券）。下图显示了投资银行家与投资者之间的关系。除了融资外，投资银行部门还参与兼收购咨询，帮助其客户谈判和构建兼收购交易。投资银行工作人员负责许多活动，如财务建模、业务估值、推介计划书（pitch book）生成和交易文件准备。他们还负责通用的关系管理和业务拓展。

### 财富管理

在财富管理（WM）业务中，财富管理公司为客户提供财富规划和结构化服务，以增长和保护客户的财富。这些机构与更关注投资咨询的经纪公司的区别在于，财富管理将税务规划、财富保护和遗产规划结合，以满足客户更复杂的财务规划目标。财富管理公司接触客户以了解其生活目标和消费模式，并为客户设计定制的财务规划解决方案。财富管理公司面临的一些挑战如下：

- 财富管理客户对其需求需要更全面、个性化的财务规划策略。
- 财富管理客户变得越来越精通技术，除了直接的客户互动外，他们还要求更多的渠道。
- 财富管理顾问需要在维持同样服务的同时覆盖更多客户。

销售交易和研究中有许多 ML 的机会。**自然语言处理（NLP）**模型可以从 SEC 备案、新闻公告和财报会议等数据源中自动提取人物、事件、组织和地点等关键实体。NLP 还可以发现所发现实体之间的关系，并通过分析大量的新闻、研究报告和财报会议来帮助理解市场及其股票的情绪，从而指导交易决策。

**自然语言生成（NLG）**可以协助叙述写作和报告生成。计算机视觉已用于从卫星图像等替代数据源中识别市场信号，以理解零售客流量等业务模式。在交易中，ML 模型可以筛选大量数据，利用公司基本面、交易模式和技术指标等数据点发现相似性等模式，从而指导配对交易等交易策略。

投资银行工作流的主要挑战之一是搜索和分析大量的结构化（财务报表）和非结构化数据（年报、备案、新闻和内部文件）。初级银行家通常花费大量时间寻找可能有用信息的文档，并从文件中手动提取信息以准备计划或进行财务建模。投资银行一直在实验并采用 ML 来帮助这一劳动密集型过程。他们正在使用 NLP 从大量 PDF 文档中自动提取结构化表格数据。具体而言，命名实体识别（NER）可以帮助从文档提取实体。基于 ML 的阅读理解技术可以帮助银行家使用自然语言而非简单的字符串匹配，快速准确地从大量文本中找到相关信息。还可以使用 ML 技术自动为文档打上元数据标签并进行分类，以改进文档管理和信息检索。投资银行工作流中其他可用 ML 解决的常见挑战包括来自不同数据源的公司标识符链接，以及公司名称变体的名称解析。
