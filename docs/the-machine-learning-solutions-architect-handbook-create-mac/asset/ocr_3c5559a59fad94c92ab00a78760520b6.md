# Creating a data lake using Lake Formation

We will build the data lake architecture using AWS Lake Formation. After you log on to the AWS Management Console, create an S3 bucket called MLSA-DataLake-<your initials>. We will use this as the storage for the data lake. If you get a message that the bucket name is already in use, try adding some random characters to the name to make it unique. If you are not familiar with how to create S3 buckets, follow the instructions at the following link:

```
https://docs.aws.amazon.com/AmazonS3/latest/user-guide/create-bucket.html
```

After the bucket is created, follow these steps to get started with creating a data lake:

+   **Register Lake Formation administrators**: We need to add Lake Formation administrators to the data lake. The administrators will have full permission to manage all aspects of the data lake. To do this, navigate to the Lake Formation management console, click on the **Admin and data creators** link, and click on the **Grant** button for the **Data lake administrator** section and add your own IAM user ID to the list (user ID you currently use to log in to the AWS Management Console). You can find your user ID in the top-right portion of the AWS Management Console banner. Note that you will need to log in to the AWS Management Console using a user ID with administrator rights to register new Lake Formation administrators.

+   **Register S3 storage**: Next, we need to register the S3 bucket (MLSA-DataLake-<your initials>) you created earlier in Lake Formation so it will be managed and accessible through Lake Formation. To do this, click on the **Dashboard** link and then click on **Register Location**. Browse and select the bucket you created and click on **Register Location**. This S3 bucket will be used by Lake Formation to store data for the databases and manage its access permission.

+   **Create database**: Now, we are ready to set up a database called bank_customer_db for retail customers. Before we register the database, let's first create a folder called the bank_customer_db folder under the MLSA-DataLake-<your initials> bucket. This folder will be used to store data files associated with the database. To do this, you click on the **Create database** button on the Lake Formation dashboard and follow the instructions on the screen to create the database.

You have successfully created a data lake powered by Lake Formation and created a database for data management. Next, let's create a data ingestion pipeline to move files into the data lake.
