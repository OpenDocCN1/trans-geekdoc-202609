## 资本市场后台运营

后台是金融服务公司中处理非客户面对和支持活动的部分。其主要功能包括交易结算与清算、记录、监管合规、会计和技术服务。由于基于机器学习的自动化可以带来财务效益和成本节省，并且在满足监管要求（例如反洗钱）和内部控制要求（例如交易监控）方面能力提升，它是早期采用机器学习的领域之一。接下来，让我们来看看一些后台业务流程以及机器学习的应用场景。

## 净值审核

提供共同基金（Mutual Funds）和交易所交易基金（ETFs）的金融服务公司需要为了交易和报告目的准确反映基金的价值。他们使用净值（NAV）计算（即实体资产价值减去其负债价值）来代表基金的价值。净值是投资者可以买卖基金的价格。每天市场收盘后，基金管理公司必须100%准确地计算出净值价格，该过程由五个核心步骤组成：

- 1. 股票对账
- 2. 反映任何公司行为
- 3. 工具定价
- 4. 费用和利息计提的记录、计算与对账，以及现金对账
- 5. 净值/价格验证

价值验证步骤的主要目标是识别定价异常，这可以被视为异常检测问题。基于机器学习的异常检测解决方案用于识别潜在的定价违规并标记这些异常以供进一步人工调查。机器学习方法已被证明可以显著减少误报，并为人工审核人员节省大量时间。

## 交易后结算失败预测

在前台执行交易后，涉及多个交易后流程以完成交易，例如结算和清算。**交易后结算**是买卖双方比较交易细节、批准交易、更改所有权记录并安排资金转移的过程。交易结算通过**直通处理（straight-through processing）**自动处理。然而，某些结算由于各种原因失败（例如卖方未能交付证券），经纪商需要使用其储备来完成交易。为了确保这些宝贵的资金用于其他地方，预测结算失败至关重要。

## 风险管理与反欺诈

风险管理和欺诈是金融服务公司（包括投资银行和商业银行）后台运营的一部分，由于其巨大的财务和监管影响，它们是金融服务领域采用机器学习的前沿领域之一。

机器学习有很多种欺诈和风险管理案例，例如反洗钱、交易监控、信用卡交易欺诈和保险理赔欺诈。让我们来看看其中几个。

### 反洗钱

**反洗钱（AML）**是一系列既定的法律法规，旨在防止犯罪分子通过复杂的金融交易使非法获得的资金合法化。根据这些法律法规，金融机构需要帮助检测协助洗钱的活动。金融服务公司投入了大量的财务、技术和人力资源来打击AML活动。传统上，公司使用基于规则的系统来检测AML活动。然而，基于规则的系统视角通常有限，因为很难在系统中评估大量的特征。此外，很难根据新变化更新规则；基于规则的解决方案只能检测过去发生的已知欺诈。

基于机器学习的解决方案已应用于反洗钱的多个领域，例如：

- 网络链路分析：揭示不同实体和管辖区之间复杂的社交业务关系。
- 聚类分析：寻找相似和不同的实体，以发现犯罪活动模式的趋势。
- 基于深度学习的预测分析：识别犯罪活动。
- 自然语言处理（NLP）：从非结构化数据源中为大量实体收集尽可能的信息。

### 交易监控

金融公司的交易员是代表客户买卖证券和其他金融工具的中间人。他们执行订单并就进入和持有金融头寸提供建议。交易监控是识别和调查交易员或金融机构潜在市场滥用的过程。市场滥用的示例包括市场操纵，例如发布虚假和误导性信息、通过大量自成交操纵交易量，以及通过披露非公开信息进行内幕交易。金融机构必须遵守市场滥用法规，如**市场滥用条例（MAR）**、**金融工具市场指令II（MiFID II）**以及内部合规，以保护自己免受声誉和财务业绩的损害。执行交易监控的挑战包括缺乏主动的滥用检测方法，例如信噪比大导致大量误报，增加了案件处理和调查的成本。滥用检测的一种典型方法是构建具有不同决策阈值的复杂基于规则的系统。
