For large, enterprise-wide ML initiatives, the data management architecture for ML is very similar to the enterprise architecture for analytics. Both need to support data ingestion from many different sources and centrally manage the data for various processing and access needs. Analytics data management mostly works with structured data, where an enterprise data warehouse is usually the core architecture backend. ML data management would need to work with structured, semi-structured, and unstructured data for different ML tasks, where a data lake architecture is usually adopted. ML data management is usually an integral part of the broader enterprise data management for both analytics and ML initiatives.
