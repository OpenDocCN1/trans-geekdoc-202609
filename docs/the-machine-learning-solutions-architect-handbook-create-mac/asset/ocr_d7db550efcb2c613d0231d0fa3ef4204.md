Containers are packaged as Docker images, which are made of all the files (such as installation, application code, and dependencies) that are essential to run the containers and the applications in them. One way to build a Docker image is the use of a Dockerfile – that is, a plain-text file that provides specifications on how to build a Docker image. Once a Docker image is created, it can be executed in a container runtime environment. The following is an example **Dockerfile** for building a Docker image to create a runtime environment based on the **Ubuntu** operating system (the FROM instruction) and install various **Python** packages, such as python3, numpy, scikit-learn and pandas (the RUN instructions):

```
FROM ubuntu:18.04
```

```
RUN apt-get -update && apt-get install -y --install-recommends \
nwget \ \
python3-pip \ \
nginx \ \
ca-certificates \ \
&& rm -rf /var/lib/apt/lists/*
```
