## 什么是 AI 和 ML？

AI（人工智能）可以定义为机器展示出类似于人类自然智能的智能，例如通过视觉识别不同类型的花朵、理解语言或驾驶汽车。拥有 AI 能力并不意味着系统必须完全由 ML 驱动。AI 系统也可以由其他技术驱动，例如基于规则的引擎。ML 是 AI 的形式，它通过不同的学习技术学习如何执行任务，例如使用历史数据从示例中学习，或通过尝试错误学习。ML 的示例是使用访问历史信誉决策数据的 ML 算法来做出信誉决策。

**深度学习 (DL)** 是 ML 的子集，它使用大量的人工神经元（称为*人工神经网络*）进行学习，这类似于人类大脑的学习方式。基于深度学习的解决方案示例是**Amazon Echo 虚拟助手**。为了更好地理解 ML 的工作原理，让我们先谈谈机器学习的不同方法。如下：

- 监督 ML
- 无监督机器学习
- 强化学习

让我们详细查看每一个。

## 监督 ML

监督 ML 是 ML 的一种，在训练 ML 模型时，为算法提供输入数据特征（例如房屋的大小和邮政编码）和答案，称为标签（例如房屋的价格）。带有标签的数据集被称为标记数据集。你可以将监督 ML 视为通过示例进行学习。为了理解它的含义，让我们以人类学习如何区分不同物体为例。假设你被提供了若干不同花朵的照片及其名称。然后你被要求研究这些花朵的特征，例如每个提供的花朵名称的形状、大小和颜色。在你查看了每种花的多张不同照片后，被给了若干没有名称的花朵照片并要求你区分它们。根据你之前学到的知识，如果花朵具有已知花朵的特征，你就应该能够说出它们的名字。

通常情况下，在学习期间你查看的训练图片越多，当你尝试命名新照片中的花朵时，准确性可能就越高。从概念上讲，这就是监督 ML 的工作方式。接下来的图（图 1.1）显示了将标记数据集输入到计算机视觉算法中以训练 ML 模型：

![](img/bd21298357d8484151447cff0b2f138b_23_0.png)

图 1.1 – 监督 ML

监督 ML 主要用于分类任务（即为示例分配离散类别集合中的标签，例如，说出不同物体的名称）和回归任务（即预测连续值，例如通过提供支持信息来估算某物品的价值）。在现实世界中，大多数 ML 解决方案都是基于监督 ML 技术的。以下是一些使用监督 ML 的 ML 解决方案示例：

- 作为文档管理工作流的一部分，自动将文档分类为不同的类型。基于 ML 的文档处理的典型优点是减少人工投入（从而降低成本）、处理速度更快以及处理质量更高。
- 评估新闻文章的情感，以帮助理解市场对品牌或产品的感知，或促进投资决策。
- 作为媒体图像处理工作流的一部分，自动实现物体或人脸检测。这带来的业务效益是减少人力劳动以节省成本、处理速度更快且准确性更高。
- 预测某人发生银行贷款违约的概率。这带来的业务效益是贷款申请审核和审批的决策更快、处理成本更低，并减少由于贷款违约对公司财务报表的影响。

## 无监督 ML

无监督 ML 是 ML 的一种，为 ML 算法提供没有标签的输入数据特征。让我们继续使用花朵的例子，但在情况下，你现在只被提供了花朵的照片和它们的名称。在这种情况下，无论你花多少时间看照片，都无法弄出花朵的名字。然而，通过视觉检查，你应该能够识别照片中不同类型花朵的共同特征（例如颜色、大小和形状），并将具有共同特征的花朵归为同一组。

这类似于无监督 ML 的工作方式。具体来说，在这种特定情况下，你执行了无监督 ML 中的聚类任务：

图 1.2 – 无监督 ML

除了聚类之外，无监督 ML 还有许多其他技术。特别是在这种特定情况下，你执行了无监督 ML 中的异常检测任务。另一种常见的无监督 ML 技术是**降维**，它在保持原始特征关键信息的同时，使其在低维度中进行可视化。为了更直观地理解这一点，让我们看看图 1.3：

![](img/bd21298357d8484151447cff0b2f138b_25_1.png)

图 1.3 – 从特征重构图像

图中，左侧的原始图片被转换为中间的降维表示。虽然降维表示看起来完全不像原始图片，但它仍然保留了关于原始图片的关键信息，因此当右侧使用降维表示进行重构时，它与原始图片几乎相同。将原始图片转换为降维表示的过程被称为降维。

降维的主要优点是减少训练数据集并加速模型训练。降维还帮助在低维度中可视化高维数据集（例如，将数据集降至三个维度以便进行视觉检查）。

无监督 ML 主要用于识别数据集中的模式。由于无监督学习没有提供实际标签供学习，其预测具有使用无监督 ML 方法的预测更大的不确定性。以下是一些无监督 ML 解决方案的现实示例：

- **目标营销客户细分**：通过使用人口统计数据和历史互动数据来实现。数据驱动的客户细分方法通常比人类判断更准确，后者可能偏见且主观。
- **计算机网络入侵检测**：通过检测不同于正常网络流量模式的异常模式来实现。由于流量模式巨大且动态不断变化，手动和基于规则的流量检测极具挑战性。
- **数据集降维**：通过在 2D 或 3D 环境中进行可视化来实现，以帮助更好地、更容易理解数据。

## 强化学习

强化学习是 ML 的一种类型，ML 模型通过尝试不同的动作并根据接收到的动作响应顺序调整其行为来学习。例如，假设你第一次在不知道游戏规则的情况下玩太空侵入者视频游戏。在这种情况下，你最初将使用控制控件随机尝试不同的动作，例如向左右移动或发射射线炮。随着不同动作的做出，你将看到对动作的响应，例如被杀死或杀死侵入者，你还会看到分数的增加或减少。通过这些响应，你将知道什么是好动作，什么是坏动作，以便生存下来并增加分数。经过反复尝试错误，你最终将成为该游戏的高手。这基本上就是强化学习的工作方式。
