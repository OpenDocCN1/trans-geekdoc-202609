Create an AWS access key pair and add the AWS access key pair info to the EC2 server using the aws configure command. If you don't know how to create an AWS access key pair, follow the instructions at https://docs.aws.amazon.com/powershell/latest/userguide/pstools-appendix-sign-up.html. Make sure your AWS credential have read/write permissions to S3, as the MLflow server will need to use S3 for store artifacts.

+   Install the MLflow packages: After the instance is ready, connect to the EC2 instance using the EC2 Instance Connect feature in the AWS console. MLflow can be easily installed as Python packages. Run the following commands in the EC2 terminal to install the MLflow packages:

```
sudo yum update
sudo yum install python3
sudo pip install mlflow
sudo pip install boto3
```

+   Install a database: MLflow requires a database for storing metadata. In this step, you will install a database as the backend for storing the tracking data. There many different database options, such as postgresql and sqlite. For simplicity, we will install a sqlite database as the backend:

```
sudo yum install sqlite
```

+   Set up the tracking server: Now, we are ready to configure the mlflow server. First, create a directory called mlflowsvr for sqlite database files on the EC2 server - you can use the mkdir directory Linux command to create the directory. Next, create an S3 bucket mlflow-tracking-<your initials> for storing the artifacts. After you have created the directory and S3 bucket, run the following command to start the tracking server:

```
mlflow server --backend-store-uri sqlite:///mlflowvr/\mlsa.db \ \
--default-artifact-root s3://mlflow-tracking --host
0.0.0.0 -p 5000
```

+   Access the tracking server site: To access the site, you will need to open up the security group for the EC2 server to allow port 5000. Check the AWS instructions on how to modify the security group rules if you are not familiar with them. By default, only port 22 is open.
