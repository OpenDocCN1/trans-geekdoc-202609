第 11 章“ML 治理、偏差、解释性和隐私”讨论了生产环境模型部署的 ML 治理、偏差、可解释性和隐私需求及能力。你还将通过使用 SageMaker Clarify 和 PyTorch Opacity 的实操练习，学习偏差检测、可解释性和 ML 隐私的技术。

第 12 章“**使用 AWS AI 服务构建 ML 解决方案**”介绍了 AWS AI 服务以及将这些 AI 服务集成到 ML 驱动应用程序中的架构模式。

#1 机器学习与机器学习解决方案架构

**人工智能 (AI)** 和**机器学习 (ML)** 领域有着很远的历史。在过去的 70 多年里，机器学习已经从 20 世纪 50 年代的跳棋游戏程序演变为能够击败围棋人类世界冠军的先进 AI。在此过程中，机器学习的技术基础设施也从用于小型实验、管理和部署的单机/服务器演变为能够训练、管理和部署数千个模型的复杂端到端 ML 平台。AI/ML 领域的爆炸式增长创造了许多新的职业角色，如 **MLOps 工程师、ML 产品经理和 ML 软件工程师**。

**机器学习解决方案架构 (ML solutions architecture)** 是另一个相对较新的学科，随着 ML 项目在业务影响、科学复杂性和技术格局方面变得日益复杂，它在整个端到端 ML 生命周期中正发挥着愈关重要的作用。
