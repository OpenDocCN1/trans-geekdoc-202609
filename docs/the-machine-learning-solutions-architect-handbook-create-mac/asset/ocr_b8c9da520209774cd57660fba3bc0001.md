6. Launch the Kubeflow dashboard: Look up the Kubeflow dashboard URL using the following command:

```
kubectl get ingress -n istio-system
```

You should see something similar to the following screenshot returned. The URL under the ADDRESS header is the URL for the Kubeflow dashboard:

| NAME CLASS HOSTS ADDRESS PORTS AGE |
| istio-ingress <name> * | | us-west-2.elb.amazonaws.com | 80 * |

Figure 7.10 – Kubeflow dashboard URL

Open a browser window and copy and paste the URL to launch the dashboard. When prompted, enter the username and password from Step 4 to log into the dashboard.

You will be prompted to select the workspace. Keep the default admin name and follow the onscreen instructions to complete installation. You will see the following screen after your dashboard has launched:
