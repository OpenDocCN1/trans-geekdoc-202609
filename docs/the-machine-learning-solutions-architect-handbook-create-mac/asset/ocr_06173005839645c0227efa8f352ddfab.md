AWS Service Catalog allows you to create different IT products to be deployed on AWS. These IT products can include SageMakernotebooks, a CodeCommit repository, and CodePipeline workflow definitions. AWS Service Catalog uses CloudFormation templates to describe IT products. With Service Catalog, administrators create IT products with CloudFormation templates, organize these products by product portfolio, and entitle end users with access. The end users access the products from the Service Catalog product portfolio.
