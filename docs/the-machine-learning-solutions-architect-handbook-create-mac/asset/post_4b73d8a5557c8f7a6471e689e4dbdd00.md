Now, we will build a list of utility functions to support the data loading and model training. We need to feed the data to the transformer model in batches. The following get_loader() function loads the dataset into the PyTorch DataLoader class with a specified batch size. Note that we also encode the articles into tokens with BertTokenizer:

```python
def get_loader(batch_size, training_dir, filename):
    logger.info("Get data loader")
    tokenizer = BertTokenizer.from_pretrained("bert-base-uncased", do_lower_case=True)
    dataset = pd.read_csv(os.path.join(training_dir, filename))
    articles = dataset.article.values
    sentiments = dataset.sentiment.values
    input_ids = []
    for sent in articles:
        encoded_articles = tokenizer.encode(sent, add_special_tokens=True)
        input_ids.append(encoded_articles)
```

The following train() function will run the training loop using the BertForSequenceClassification class. We will use the pre-trained BERT model for fine-tuning, instead of training from scratch. We will feed one batch of data to the BERT model at a time. Note that we will also check if there is a GPU device on the server. If there is one, we will use the cuda device for GPU training, instead of cpu for CPU training. We will need to move the data and BERT model to the same target device with .to(device) function so that the training can happen on the target device with the data residing in memory on the same device. The optimizer we're using here is AdamW, which is a variant of the gradient descent optimization algorithm. The training loop will run through the number of epochs. One epoch runs through the entire training dataset once:

