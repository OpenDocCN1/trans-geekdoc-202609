Now that we have configured the Studio environment, let's set up an Amazon CodeCommit repository for source code version control.

# Setting up CodeCommit

Navigate to the AWS CodeCommit management console, click on the Repositories link in the left pane, and click Create repositories to start creating a CodeCommit repository. Provide a name for the repository and select Create.

Now that we've created a new repository, let's configure the newly created Studio environment to use this repository. There are several approaches we can take to set up authentication credentials to the CodeCommit repository:

+   - IAM user credential: To do this, create a new IAM user and attach the AWSCodeCommitPowerUser policy to it for simplicity. Download the AWS credential to your local machine and look up the IAM credentials in the file. Next, open a Terminal in Studio by selecting File > New > Terminal from the menu dropdown. Once the new Terminal window is open, run the AWS Config command to set up the IAM credential.
