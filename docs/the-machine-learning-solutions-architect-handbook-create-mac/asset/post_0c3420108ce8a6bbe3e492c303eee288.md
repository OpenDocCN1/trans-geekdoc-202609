
# Generative adversarial network

The **generative adversarial network** (GAN) is a generative model that tries to generate realistic data instances, such as images. It works by having a discriminative network (**Discriminator**) learning to tell if the instances generated by a *Generator* network are real or fake:

![](img/bd21298357d8484151447cff0b2f138b_100_0.png)

Figure 3.16 - Generative adversarial network

During training, the Discriminator network is provided with two sources – one from a real source, used as positive examples, and one from the Generator source, the negative samples. The Discriminator will be trained to distinguish the real sample from the fake sample as a classifier, and it will optimize its loss to produce real/fake samples correctly from both sources. On the other hand, the Generator will be trained to produce fake data that the Discriminator cannot tell is real, and it will be penalized when the Discriminator was able to tell its generated data is fake. Both networks learn using backpropagation. To generate data, the Generator is provided with random inputs. During training, the Generator and Discriminator are trained alternatively to allow both networks to train as single connected network.

GAN has had a lot of success recently in generating realistic images that can fool humans. For example, it can be applied to many applications, such as translating sketches to realistic-looking images, converting text inputs and generating images corresponding to the text, and generating realistic human faces.

Before we start, let's first review the business problem that we need to solve. A retail bank is experiencing a high customer churn rate for its retail business. ## Installing Homebrew on macOS

The specific steps to install Homebrew on your Mac are listed as follows:

- Open a terminal window on your Mac machine.
- Inside the terminal, type and run the command to start installing Homebrew:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/HEAD/install.sh)"
```
- Enter your user password when prompted during the installation.
- After the previous script completes, run the following command inside the Terminal to get the latest versions of the packages:
```bash
brew update && brew upgrade python
```
- Point to Homebrew by typing and running the following command. It will make the current Terminal window use Homebrew installation:
```bash
alias python=/usr/local/bin/python3
```
- Verify the Python installation and version by running the following command inside the Terminal:
```bash
python --version
```
At the time of writing this book, the latest Python version is 3.9.1. To persist the setting of Homebrew for all Terminal windows, type and run the following command in the Terminal window depending on which shell you have on your Mac:
```bash
echo 'alias python=/usr/local/bin/python3' >> ~/.bashrc
```
Or, type and run the following command:
```bash
echo 'alias python=/usr/local/bin/python3' >> ~/.zshrc
```

## Installing Jupyter Notebook on macOS

Now, we are ready to install Jupyter Notebook on your machine:

1. Inside the Terminal window, run the following command:
```bash
brew install jupyter
```
2. Start the Jupyter Notebook by running the following command in your Terminal window:
```bash
jupyter notebook
```
