

# 医疗数据管理

医疗保健行业每天收集并产生大量的医疗数据。这些数据以各种形式存在，例如保险理赔数据、医生的手写笔记、记录的医疗对话以及 X 光片等图像。医疗公司需要从这些数据源中提取有用信息，以建立患者的全面视图，或为医疗计费流程的医疗编码提供支持。大量人工处理（通常由具有健康领域知识的人士）用于组织这些数据并从这些数据源中提取信息。这一过程既昂贵又容易出错。因此，大量的医疗数据仍以原始形式存在，没有得到充分利用。

近年来，基于深度学习的解决方案被用于帮助健康管理，特别是从医生笔记、记录的医疗对话和医学图像等非结构化数据中提取医学信息。深度学习解决方案不仅可以从手写笔记、图像和音频文件中提取文本，还可以识别医学术语和疾病、药物名称、处方指令以及这些不同实体和术语之间的关系。下图展示了使用机器学习（ML）从非结构化源中提取信息并将结果用于不同任务（如医疗编码和临床决策支持）的流程：

# 工程与产品设计

产品设计是产品设计师结合其创意能力、市场/消费者的实际需求以及限制条件，开发出在上市后能够成功的产品的过程。设计师在设计阶段通常需要创建新产品概念的许多变体，以满足不同的需求和限制。例如，在服装行业，时尚设计师会分析客户的需求和偏好（如颜色、纹理和风格），并开发这些设计并为服装生成图形。

制造业一直在利用生成式设计机器学习技术来协助新产品概念的设计。例如，生成对抗网络（GANs）等机器学习技术已用于生成 Logo 设计和如机械齿轮等 3D 工业组件的图形。下图展示了 GAN 的基本概念，其中生成器模型经过训练以创建能够欺骗判别器的伪图像。当生成器足够强大能够欺骗判别器后，它就可以用于为服装等物品生成新图像。

# 制造运营 – 产品质量与良率

质量控制是制造过程中的重要步骤，用于确保产品在发货前的质量。许多制造商依赖人工来检查制造出的产品，这非常耗时且成本高昂。例如，工厂工人会目视检查产品，寻找表面划痕、部件缺失、色差和变形。

基于计算机视觉的技术已用于自动化生产线质量控制过程的许多方面。例如，可以使用标记的图像数据训练计算机对象检测模型，帮助从捕到的图像中识别待检查的对象，然后可以使用标记为良好部件和坏部件的图像训练基于计算机视觉的缺陷模型，以帮助检查检测的对象并将其分类为缺陷或非缺陷。

# 制造运营 – 设备维护

工业制造设备和机械需要定期维护以确保运行顺畅。任何由于设备故障导致的非计划停机不仅会导致高昂的维修或更换成本，还会中断生产计划，影响向下游任务或客户的交付。虽然遵循定期的维护计划可以在一定程度上缓解问题，但提前预测潜在问题的能力将进一步降低任何意外故障的风险。

基于机器学习的预测性维护分析通过使用多种数据（例如由**物联网 (IoT)** 传感器收集的遥测数据）预测设备是否可能在时间窗口内故障，有助于减少潜在故障的风险。维护人员可以使用预测结果采取主动维护措施以防止意外故障。

# 零售业中的机器学习用例

零售业务通过零售店或电子商务渠道直接向客户销售消费品。他们通过批发销商或制造商直接获取供应。该行业一直在经历重大转型。虽然电子商务的增长远快于传统零售，但实体店也在转型店内购物体验以保持竞争力。零售商正在寻找新方法，通过物理和数字渠道提升整体购物体验。社交购物、增强现实、虚拟助手购物、智能商店和11个性化等新趋势正成为零售企业之间的关键差异。

人工智能和机器学习是零售行业从库存优化、需求预测到高度个性化沉浸式购物体验的驱动力。此外，机器学习帮助零售商打击欺诈犯罪。

# 产品搜索与发现

当消费者在线购物并需要搜索特定产品时，他们依靠搜索引擎在各种电子商务网站上寻找产品。当你知道搜索产品的名称或某些属性时，这极大地简化了购物体验。然而，有时你只有一张产品的照片，却不知道用什么术语搜索。

深度学习驱动的视觉搜索是一种可以帮助你根据物品照片快速识别并返回相似产品的技术。视觉搜索的工作原理是创建物品照片的数字表示（也称为编码/嵌入），并存储在高性能物品索引中。当购物者需要使用照片寻找相似物品时，新照片被编码为数字表示，并使用高效的距离比较对物品索引进行搜索。与目标物品最接近的物品将被返回。下图展示了构建基于机器学习能力的架构：

# 目标营销

零售商使用不同的营销活动和广告技术（如直接营销邮件或数字广告），根据购物者的细分对潜在购物者提供激励或折扣。这些活动的有效性在很大程度上取决于正确的客户触达，以实现高转化率，同时降低活动成本或广告支出，并产生更少的用户打扰。
