# 3.6.1.5 极端学习机

本节讨论极端学习机(ELM)，与更计算密集的算法相比，它更轻量。ELM是一种单隐藏层前馈神经网络。输入到隐藏层的权重是随机初始化的。隐藏到输出层的权重使用摩尔-彭罗斯逆形式\[[82](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib82)\]计算。该网络的特性使得权重可以在一次通过中训练，从而降低复杂度和所需时间，并提高准确性\[[83](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib83), [84](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib84)\]。ELM的模型示例如图\[3.9](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3fig9)。

## 3.6.2 深度学习

深度学习的出现彻底改变了医学影像行业。深度学习与机器学习不同，它是单阶段的。它能够直接从图像中提取特征并将其特征化为单一阶段。在所有深度学习模型中，CNN是最流行的，用于特征提取和分割。CNN通过重复使用三种独特操作来提取特征：卷积、ReLu \[[85](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib85)\]，以及池化（如前面章节所述）。最后，它会附加全连接层用于特征提取或上采样层用于分割。一个包含全连接网络的CNN网络示例如图\[3.10](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3fig10)。

## 3.6.3 使用深度学习进行脑部图像分析

在脑部影像中，深度学习在准确描述脑肿瘤、以及分割水肿、增强和非增强肿瘤区域、阿尔茨海默病以及中风病灶方面发挥了重要作用\[[86](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib86)\]。在接下来的子节中，我们将学习深度学习在脑肿瘤检测、描述和分割中的应用。

### 3.6.3.1 多机构脑肿瘤分割的深度学习

在\[[87](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3bib87)\]中，提出了一种基于CNN的自动脑分割模型。利用多机构数据，使用了三个独立的CNN。每个CNN包含六层（四个卷积层和两个全连接层）。共收集了68张医学影像。采用补丁作为分割方法，补丁过程包括提取大小相等的小块。这些块由经验丰富的放射科医生标注为正常、增强、异常、FLAIR异常和坏死区域。地面真实图像和所有类别的描述在图\[3.11](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3fig11)中给出。初始CNN在来自第1机构的数据集上应用，随后的CNN在来自第2机构的数据集上应用。训练/测试的交叉验证协议采用十倍交叉验证。性能指标为Dice相似系数（DSC）和Hausdorff距离。可以看出，当CNN模型在不同数据集上训练和测试时，性能会下降。不同机构数据的DSC（Dice系数：0.68 ± 0.19 和 0.59 ± 0.19）与同一机构数据的DSC（Dice系数：0.72 ± 0.17 和 0.76 ± 0.12）存在显著差异。整个过程模型示例如图\[3.12](#Chapter_3.xhtml#bk978-0-7503-2244-7ch3fig12)。
