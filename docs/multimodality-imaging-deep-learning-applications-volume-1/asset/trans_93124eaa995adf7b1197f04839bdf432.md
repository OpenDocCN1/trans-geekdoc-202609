*Benchmarking*

本工作与早前基于 DL 的 cIMT 估计应用 \[[21](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib21)\] 进行了比较。对 250 张 CCA 图像进行了 cIMT 偏差误差、回归、偏差误差分析等方面的对比分析。早前的应用使用了两套金标准（GT1 和 GT2），而本工作使用的金标准仅称为 GT。当前工作的 GT 偏差误差为 0.0935 ± 0.0637 mm，优于使用 GT1 的早前实现 20%（0.1164 ± 0.1122 mm），优于使用 GT2 的早前实现 18%（0.1146 ± 0.0940 mm）。GT1 和 GT2 的回归图如图 [7.15](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7fig15) 所示。当前工作的相关系数 0.99（*p* < 0.0001）优于 GT1 的 0.83（*p* < 0.0001）和 GT2 的 0.87（*p* < 0.0001）。与之前的工作相比，当前工作在绝对偏差误差上，90% 的图像（GT < 0.19 mm）表现优于 GT1（< 0.24 mm）和 GT2（< 0.23 mm）。详细信息见表 [7.2](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7t2)，偏差误差图如图 [7.16](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7fig16) 所示。对于带符号偏差误差，当前工作中 90% 的图像（GT − 0.13 mm < signed error < 0.18 mm）表现优于 GT1（− 0.15 mm < 0.18 mm）和 GT2（− 0.15 mm < 0.19 mm）的早前技术。相应的图表如图 [7.17](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7fig17) 所示。
