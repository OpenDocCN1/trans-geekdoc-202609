
-   [模拟]。Matlab（对公众开放）提供了一个平台，我们可以使用应用程序（如 Deep Network Designer）创建、修改和可视化深度学习（DL）架构。因此，实现项目目标非常方便。此外，当使用 TensorFlow、PyTorch 和 MxNet 等框架时，它会自动标记数据（包括图像、视频和音频数据），并利用 GPU 自动加速算法。我们使用了 Matlab2019a 的免费试用版。进一步，所有实验均在配备 2.5 GHz Core i3 CPU 和 4 GB RAM 的机器上进行。深度学习模拟在 MatlabR2019a 中使用预训练的 AlexNet 卷积神经网络进行，该包从 [https://www.mathworks.com](https://www.mathworks.com) 下载。为检验显著性，使用 MedCalc（版本 19.1）软件（比利时）进行 *t*‑test。

#### 4.5.2 结果

如前所述，脑肿瘤主要分为三类： (i) 胶质瘤（AST），(ii) 胶质母细胞瘤（OLI），(iii) 胶质母细胞瘤多形（GBM）。AST 和 OLI 仅出现在二级（g2）和三级（g3）中，而 GBM 也表现为四级（g4）。我们的目标是开展三项肿瘤特征研究，包括： (i) AST（g2 对 g3），(ii) OLI（g2 对 g3），(3) 低级别胶质瘤与高级别胶质瘤分类。这些研究基于脑肿瘤患者的现有真实标签，如下所述。
