
### 7.2 背景

前几代的斑块分割技术涉及低层次图像处理，包括边缘检测/阈值组合或两者兼有。这些技术基于人类对图像的感知，无法推广应用。它们属于第一代技术。随着对医学成像的更好理解以及新一代技术的出现，分割技术向像素特征和可变形模型方向发展。在这些进步下，颈动脉壁的分割在精度及其他性能指标方面也得到了提升。这些模型属于第二代技术。最近对两代技术的文献综述已提供 \[[18](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib18), [19](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib19)\]。在第三代中，尺度空间技术被用于颈动脉壁检测 \[[14](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib14), [28](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib28), [29](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib29)\]。该方法使用更高阶高斯导数进行边缘检测，采用称为“stretcher”的高斯标准差函数捕获斑块，边缘在零交叉点被捕获。这一技术在超声风险评估领域堪称革命性 \[[28](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib28)\]，并依据图像恢复原理进行验证 \[[30](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib30)\]。基于此技术构建了多种变体，如 CALEX \[[31](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib31)\]、CARES \[[32](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib32)\]、CAMES \[[28](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib28)\]、CLAUDLES \[[33](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib33)\] 和 FOAM \[[18](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib18), [34](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib34)\]。所有讨论的系统都为商用 AtheroEdgeTM 系统的开发铺平了道路，该系统被研究界广泛用于斑块分割 \[[35](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib35)\]。所讨论模型的通用架构可分为两个阶段：(i) ROI 识别和 (ii) 分割。ROI 识别包括检测远壁区域，分割则包括描绘 LI 与 MA 边界。斑块面积（PA）以及颈内膜厚度（cIMT）也被越来越多地作为新型中风风险指标使用 \[[36](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib36)\]。尽管第一代和第二代技术对 PA 的使用较少，第三代技术则更加强调 PA 与 cIMT \[[37](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib37)\]。目前讨论的方法属于 AtheroEdgeLink™ 类别 \[[38](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib38), [39](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib39)\]。这一类别具有许多有益方面。其一是了解图像基因型与其他当代风险参数之间的关系，包括 (a) SYNTAX 评分、踝踝指数以及血管硬化患者的风险分层 \[[40](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib40)–[43](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib43)\]；(b) 斑块的研究 \[[35](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib35)\]；(c) 壁面变异与中风风险的相关性 \[[44](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib44)–[47](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib47)\]；以及 (d) 新型风险估计器的发展，如 AECRS 2.0 \[[48](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib48), [49](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib49)\] 及其与传统中风风险参数的比较分析 \[[39](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib39), [50](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib50)\]。迄今为止的研究已验证了其在变异性分析和可重复性方面的表现 \[[51](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib51)–[53](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib53)\]。形态学研究如回声缺失（echolucency）也已在 Atheromatic™ 的框架下进行 \[[50](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib50)\]，同时也在 Atheromatic™ 与 AtheroRisk™ 应用中进行 \[[51](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib51), [52](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib52)\] 与 \[[53](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib53)\]。随着基于人工智能的系统出现，Suri 及其团队开发了新的智能模型，能够根据 ROI 的灰度特征动态学习并调整参数 \[[21](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib21), [54](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib54), [55](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib55)\]。颈动脉成像的人工智能模型可分为两类。第一类基于形态特征对斑块进行表征，第二类则通过分割斑块区域来估计 cIMT 与 TPA。形态特征分类至今主要采用机器学习（ML）技术 \[[43](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib43)–[45](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib45)\]。ML 范式分为两个阶段。第一阶段计算各种图像参数，如纹理和频率参数；第二阶段在提取的参数上训练学习模型以实现特征表征 \[[56](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib56)\]。最常用的 ML 算法包括 *K* 最近邻（KNN）\[[57](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib57)\]、支持向量机（SVM）\[[58](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib58)\]、决策树（DTs）\[[59](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib59)\]、人工神经网络（ANNs）\[[60](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib60)\] 和极端学习机（extreme learning machines）\[[61](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib61)\]。深度学习（DL）方法的工作流程是将特征提取与图像特征表征合并在一个阶段完成。最常见的 DL 系统包括 CNN \[[22](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib22)\]、FCN \[[24](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib24)\]、深度信念网络（DBNs）\[[62](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib62)\]、自动编码器（autoencoders）\[[63](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib63)\]、残差神经网络（RNNs）\[[64](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib64)\] 等。近期，已有一些基于 DL 的颈动脉体积计算实现。Rosa *et al* \[[65](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib65)\] 使用自动编码器来提取特征。Shin *et al* \[[66](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib66)\] 采用 CNN 从 CCA 的运动视频帧中测量 cIMT。最近，Biswas *et al* \[[21](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib21)\] 与 Maria *et al* \[[67](#Chapter_7.xhtml#bk978-0-7503-2244-7ch7bib67)\] 均使用语义分割，利用 FCN 来测量 cIMT。然而，这些模型均使用全尺度图像，这可能导致诸如颈静脉等回声缺失特征被混入，从而引入检测和测量偏差。FCN 与 CNN 在层结构上（如卷积、池化）相似，但在输出上有所不同：CNN 使用全连接网络（如 ANN）进行特征表征，而 FCN 则采用上采样层将特征图上采样到像素级，以实现分割。接下来的章节将讨论实现分割 DL 网络的具体方法。
