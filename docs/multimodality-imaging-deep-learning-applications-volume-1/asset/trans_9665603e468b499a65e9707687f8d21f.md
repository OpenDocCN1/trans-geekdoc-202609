
DL 模型受到大脑视觉皮层工作方式的启发。与机器学习（ML）不同，DL 模型是单阶段模型，能够直接从实例生成特征，从而消除了中间特征提取阶段的需求。特征空间是对实例空间的抽象表示，因此也称为表示学习。DL 网络由多层核（kernel）组成，这些核通常执行重复的功能。这些核通常生成实例空间的下采样版本，也称为特征图。将特征图 `F[i]` 从实例 `x[i]` 中学习的方法如下：

`F[i]` = `A[n](B[n](C[n](…(A[1](B[1](C[1](x[i]))))…)))`,

(A.2) 其中 `x[i]` ∈ `X`，`A`、`B`、`C` 是对实例 `x[i]` 重复应用的不同核。`F[i]` 是经过 `n` 次 `A`、`B`、`C` 应用后输出的特征向量。在卷积神经网络（CNNs）[84]的情况下，核滤波器值通过反向传播规则[160]在损失函数（如最小平方模型）的指导下进行优化。全卷积网络（FCNs）[109]是另一种受监督的 DL 模型，最常用于图像的语义分割。另一种学习方式是无监督学习，其中没有标记的实例[161]。无监督学习采用不同的方法，从无结构数据中提取或发现有趣的模式。K-means 聚类[1.1 [content]
