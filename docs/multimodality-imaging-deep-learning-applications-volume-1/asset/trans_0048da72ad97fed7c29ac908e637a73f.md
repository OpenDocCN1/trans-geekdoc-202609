*A short note on graphical processing units*

GPU的可用性推动了AI的发展。我们的研究发现，AI通常涉及数以百万计的复杂计算，若在多核CPU上按顺序执行，往往需要很长时间（甚至数小时）才能收敛。GPU则把大问题划分为成千上万的小问题，并分布在成千上万的核心上并行求解，最后再汇总。

因此，GPU的收敛速度显著快于CPU。GPU-S的收敛速度快于CPU-S和CPU-L，在对ImageNet8进行比较时\[[147](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib147)\]，在MXNet实现中也表现出类似趋势。该比较涉及多个深度学习库，包括MXNet\[[148](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib148)\]、SINGA\[[149](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib149)\]和Omnivore\[[147](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib147)\]。在CPU-S（9核心）、CPU-L（33核心）和GPU-S（36 GPU）集群平台上，Omnivore在CPU-S上比其他库快2.3倍，在GPU-S上比CPU-S快4.8倍，在CPU-L上快3.2倍；而SINGA在性能上优于其他库，但在CPU-L或GPU-S上未实现。
