
DL models are inspired by the working of the visual cortex of the brain. DL models, unlike ML, are single-stage models and generate features directly from the instances, thus overriding the need of for an intermediate feature extraction phase. The feature space represents an abstract representation of the instance space and hence this is also called representation learning. The DL network is composed of multiple layers of kernels which often perform repeated functions. These kernels generally generate down-sampled versions of the instance space also called feature maps. This approach of learning feature map `F[i]` from instance `x[i]` is shown by:

`F[i]` = `A[n](B[n](C[n](…(A[1](B[1](C[1](x[i]))))…)))`,

(A.2) where `x[i]` ∈ `X`, `A`, `B`, and `C` are different kernels applied repeatedly on the instance `x[i]`. `F[i]` is the feature vector which is output after `n` applications of `A`, `B`, and `C`. In the case of convolution neural networks (CNNs) \[[84](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib84)\], the kernel filter values are optimized using backpropagation rules \[[160](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib160)\] based on loss functions such as the least square model. Fully convolutional networks (FCNs) \[[109](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib109)\] are another supervised DL model most commonly used for semantic segmentation of images. Another form of learning is unsupervised learning where labeled instances are not available \[[161](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib161)\]. Unsupervised learning applies different methodologies to extract or find interesting patterns within unstructured data. *K*-means clustering \[[162](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib162)\] is an important ML unsupervised learning method. Autoencoders \[[107](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib107)\] on the other hand are an important DL model used generally for unsupervised learning.
