
卷积层（称为 `Conv`）通过在合适的滤波器与输入图像之间进行卷积运算，从图像中提取关键特征。滤波器是一个（*n* × *n*）数组，包含参数或权重，要么是 0 要么是 1。`ReLU` 是一种激活函数，用于在系统中引入非线性，主要是为了避免过拟合。`ReLu` 用函数 `Max(*x*, 0)` 表示，其中 *x* 为输入参数。池化是网络中的一种特殊操作，通常在卷积操作之后应用，以在训练过程中减少参数数量和计算量。`max-pooling` 和 `average pooling` 是两种流行的操作。在 `max-pooling` 中，从滤波器大小的特征向量中选择最大值；在 `average pooling` 中，选择特征向量的平均值并转发到前馈网络。`softmax` 分类器用于全连接层，通过类别得分（介于 0 到 1 之间）进行概率标签分类。

许多深度学习网络，如 `AlexNet`、`ResNet`、`GoogLeNet` 等，使用著名的 CNN 模型。它们在 ImageNet Large Scale Visual Recognition Challenge (`ILSVRC`) 年会上被介绍 \[[70](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib70)\]。这些网络在超过一百万张图像上进行训练，能够对超过 1000 种对象（如鼠标、铅笔、动物等）进行分类。人们认为这些模型在图像分类方面显著提升了性能，优于其他非深度学习方法。

为医学图像分类选择合适的深度网络层是一项挑战性且繁琐的工作，因为需要进行大量的试错迭代来找到合适的网络。传递学习是一种特殊方法，其中已有的训练好的深度网络可以被重用。在这个概念中，早期训练好的模型（包括层和学习权重）被用作新任务的起点。这种安排避免了为合适网络设计所需的开销。因此，我们选择了一个预训练的 (`CNN`) 网络，以在适度的训练时间内实现更高的分类性能。

### 4.4.2 AlexNet 架构

`AlexNet` \[[70](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib70)\] 首次在 `ILSVRC 2012` 中被提出，并以 15.3% 的前五错误率赢得竞争，超越了第二名（26.2% 前五错误率）。它是一个八层的 `CNN`，如图 [4.6](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4fig6) 所示，包含五个卷积（`Conv`）层和三个全连接（`FC`）层。网络要求输入为三通道（红‑绿‑蓝）图像，尺寸为 (227 × 227 × 3)。`AlexNet` 的层级细节在表 [A1](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4tA1)（附录 [A](#Chapter_4.xhtml#ST131)）中描述。该模型的主要亮点如下。

为了在模型中加入非线性，`AlexNet` 首次引入 `ReLU`（*f*(*a*) = max(0,*a*)) 作为激活函数，目的是加快训练速度。此前，`tanh` 函数（*f*(*a*) = (1 + *e*^(−*a*))^(−1)）被广泛使用。`ReLU` 的运行速度是 `tanh` 的数倍，并有助于降低前五错误率。此外，由于显存受限，`AlexNet` 设计为能够在两块 GPU 上同时运行，卷积操作的核被分成两条路径。因此，前一和前五错误率分别降低了 1.7% 和 1.2%。`AlexNet` 还使用了局部响应归一化，这加速了训练过程直至收敛，并进一步将前一和前五错误率降低了 1.4% 和 1.2%。作为替代方案，提出了重叠池化概念，它在同一核中对相邻组的输出进行汇总，而传统的相邻池化则不支持这种重叠。使用此技术，前一和前五错误率分别降低了 0.4% 和 0.3%。过拟合是一个严重问题，网络在已知样本上表现良好，但在未知样本上却难以识别。为了克服过拟合，引入了数据增强和丢弃（dropout）技术。数据增强通过平移、旋转、反射以及改变样本图像的强度来实现。在丢弃技术中，被选中的神经元在前向和反向传播时不能传递信息。该模型在两个全连接层（`FC-6`、`FC-7`）上将每个隐藏神经元的丢弃概率设为 0.5（丢弃率），并在此处应用。

在名为 ImageNet `LSVRC` 的竞赛中，提出了多个深度学习网络，如 `GoogleNet` \[[71](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib71\]（22 层）、`ResNet` \[[72](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib72\]（18+ 层）以及 `VGG` \[[73](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib73\]（16+ 层）。错误率是用来比较和对比这些网络的指标。尽管 `AlexNet` 的网络层数较少（八层结构），但它是更快且更轻量的系统。因此我们决定将 `AlexNet` 适配为我们的分类范式。`AlexNet` 已被成功用于医学图像分类，例如乳腺癌检测 \[[74](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib74)\]、脑出血分类 \[[75](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib75)\] 以及糖尿病视网膜病变诊断系统 \[[76](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib76)\]。虽然 `GoogLeNet` 的层数比 `AlexNet` 深，但由于其嵌入结构，参数更少，这可以降低过拟合风险 \[[28](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib28\]，且由于计算资源有限（仅有 CPU），我们决定选择一个层数较少的网络。

### 4.4.3 传递学习与工作流

传递学习在深度学习领域近年来备受关注，因为它使我们能够在新问题上使用已有的预训练模型，且数据量更少 \[[77](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib77)\]，这可以优化模型的分类准确率。传递学习通过之前任务的训练获得的知识，使模型在分类时更具泛化性 \[[78](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib78)\]。事实证明，预训练模型的表现与从零训练模型相当，即使早期学到的知识完全不同 \[[29](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib29)\]。因此，我们重用了在数百万自然图像上预训练的 `AlexNet`，将其用于脑肿瘤图像分类。传递学习的工作原理如图 [4.7](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4fig7) 所示。预训练的特征/权重/知识被转移到新模型，并作为新模型的初始权重。新模型的结构与 `AlexNet` 相同，除了最后的全连接层被修改为两类脑肿瘤（即两类脑肿瘤）的分类。虽然 `GoogLeNet` 的层数比 `AlexNet` 深，但由于其嵌入结构，参数更少，这可以降低过拟合风险 \[[29](#Chapter_4.xhtml#bk978-0-7503-2244-7ch4bib29)\]。
