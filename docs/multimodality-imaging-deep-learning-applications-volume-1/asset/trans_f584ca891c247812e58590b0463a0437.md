# 10.3.3 特征挖掘

特征挖掘的目标是在与 SVM 相比的同时，计算出少量特征以把握 ELM 的潜力。我们实验中使用的特征挖掘方法——Gabor、GLCM 和 GRLM——在此讨论。使用的方向、尺度以及纹理重复性用于选择这些特征 \[[36](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib36)\]。

## 10.3.3.1 Gabor 基于方向特征

Gabor 滤波器是一种边缘检测滤波器，它结合了高斯函数和复平面波。通过这种组合，它在空间域和频率域中都能降低不确定性。该函数的膨胀和旋转产生相似的 Gabor 滤波器。它有助于对可调尺度的边缘和线条进行对齐和识别。它有助于将图像扩展并在空间频率表示中保持其包含。可以用正弦波来表示 Gabor 变换的脉冲响应（不同频率且对齐的 2D Gabor 的平面波）。其表达式为


## 10.3.3.2 灰度共发生矩阵

灰度共发生矩阵（GLCM）是一种著名的纹理挖掘技术 \[[37](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib37)–[41](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib41)\]。GLCM 描述相邻像素之间的空间关系。它计算在一系列方向上，特定灰度或强度的像素与其邻居出现的频率。利用像素强度的统计分布来计算特征。GLCM 基于特征挖掘使用二阶统计量。从共发生矩阵中得到的纹理特征不会直接用于分析。利用灰度共发生矩阵计算灰度水平 *i*、*j* 在距离 *d*、方向 *θ* 之间的两像素出现的概率 *p*(*i*, *j*∣*d*, *θ*)。

概率用 *p*(*i*, *j*∣*d*, *θ*) 表示。角 *θ* 和距离 *d* 用于说明空间关系。我们基于计算出的可能性来计算特征。

## 10.3.3.3 灰度运行长度矩阵

灰度运行长度矩阵（GRLM）是一组在同一方向上具有相同灰度的像素的集合。GRLM 的主要作用是从给定方向的灰度强度像素中挖掘纹理特征，并计算参考像素。运行长度表示为 *S*(*i*, *j*∣*d*, θ)，是在给定方向中具有相同灰度强度的像素数量。

理解训练数据规模如何影响 ELM 架构至关重要。由于 ELM 不需要像 NN 或 BPNN 那样进行迭代，训练数据规模对 ELM 系统的性能影响更大。因此，我们将原始数据库（S0）子采样为两类数据集：S4 和 S8。图 [10.3](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10fig3) 和图 [10.4](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10fig4) 分别展示了将图像划分为四份和八份的情形。所有 CV 协议（即 K2、K3、K5、K10）必须对 S0、S4 和 S8 进行。

### 10.4.3 实验 3：ELM 与 SVM 的时间复杂度

ELM 的核心优势在于学习速度极快，因此需要计算 ELM 系统在训练和测试阶段的时间复杂度。这要求对所有 CV 协议（即 K2、K3、K5、K10）以及三种数据集（即 S0、S4、S8）进行计算，总计 12 次时间比较。
