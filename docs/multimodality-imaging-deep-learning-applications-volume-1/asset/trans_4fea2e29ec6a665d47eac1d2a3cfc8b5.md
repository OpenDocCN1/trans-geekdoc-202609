
-   [量化动脉粥样硬化的标准流程是测量颈动脉内膜-中膜厚度（cIMT）和斑块面积（PA）。该过程也被称为动脉粥样硬化疾病监测或血管筛查 \[[22](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib22)\]. cIMT 是介于介质-外膜（MA）和光滑-内膜（LI）边界之间的测量距离 \[[23](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib23), [24](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib24)\]. 这两条边界之间的区域称为 PA \[[25](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib25)–[32](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib32)\]. 最近，cIMT 和 PA 的测量被用于计算综合风险评分。传统的风险评分未包含这些影像生物标记，即 Framingham \[[33](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib33)\], ASCVD \[[34](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib34)\], Reynolds 风险评分（RRS）\[[35](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib35)\], 英国医药研究理事会糖尿病研究（UKPDS56）\[[36](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib36)\], UKPDS60 \[[37](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib37)\], QRISK2 \[[38](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib38)\], 以及英国联合医学会（JBS3）\[[39](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib39)\], 等等。新时代风险预测器如 AtheroEdge 综合风险评分（AECRS 1.0）\[[20](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib20) 由 Suri 及其团队开发。AECRS 1.0 采用基于形态的心血管疾病预测工具，既包括传统的也包括基于影像的表型，如 cIMT 和 PA。这些基于影像的表型是基于 2D B-模式超声扫描颈动脉段（如常见颈动脉（CCA）、颈动脉瓣或颈内动脉）获得的 \[[5](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib5), [40](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib40), [41](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib41)\]. Suri 及其团队基于传统的血液生物标记和影像表型开发了另一种十年风险计算器 AECRS 2.0。由于基于影像的表型正逐渐成为这些新时代计算器的组成部分，要更好地理解其演变，需要深入了解人工智能（AI）背景下自动化 cIMT/PA 测量技术的发展。多个研究团队在自动化 cIMT/PA 测量方面作出了贡献。这些团队使用了各种 cIMT/PA 测量技术。这些团队在 cIMT 影像的不同方面开展工作，即从静态（图像）到动态（视频）。这些模型从基本的形态阈值方法发展到当前的深度学习（DL）范式。研究团队的成果可按 ROI 分割和 LI/MA 边界划分技术的三代进行分类 \[[42](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib42)\]. 第一代是基础图像处理技术，用于检测 LI/MA 边界，然后使用卡尺方案计算平均距离。第二代使用轮廓基础方法，包括参数/几何曲线。许多这些技术是半自动的 \[[43](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib43)–[46](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib46)\]. 信号基础方法，如尺度空间和可变模型，也属于 AtheroEdge™ 模型类别下的这一代。这些模型是完全自动化的，并且可商业使用 \[[47](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib47), [48](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib48)\]. 第三代技术基于机器学习（ML）和深度学习（DL）的人工智能范式用于 cIMT/PA 测量 \[[49](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib49), [50](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib50)\]. 所有代都使用相同的距离测量技术，如豪斯多夫距离 \[[51](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib51)\] 和 Suri 的多边形距离方法（PDM）\[[52](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib52)\]. 在本综述中，我们研究了第三代基于 AI 的 cIMT/PA 测量学习的各个方面。

第 [9.2](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9s9-2) 节详细介绍了所有代的 cIMT/PA 技术。第 [9.3](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9s9-3) 节专注于基于 AI 的自动化技术，涵盖 ML 和 DL 相关应用。第 [9.4](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9s9-4) 节提供量化技术。本章节在 [9.5](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9s9-5) 部分结束。

### 9.2 综合生成的颈动脉区域分割与 cIMT 测量

cIMT 是颈动脉/动脉疾病的替代生物标记，如前所述 \[[53](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib53)\]. 首代开发了多种技术用于低层次的 cIMT/PA 测量分割任务。这些技术包括动态编程（DP）\[[54](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib54)\], Hough 变换（HT）\[[55](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib55)\], Nakagami 混合建模 \[[56](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib56)\], 主动轮廓 \[[57](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib57)\], 边缘检测 \[[58](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib58)\] 和基于梯度的技术 \[[59](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib59)\]. 所有这些技术均归类为计算机辅助诊断的范畴 \[[40](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib40), [60](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib60), [61](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib61)–[66](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib66)\]. DP 方法的成本函数是对局部估计的回声强度、强度梯度和边界连续性的加权求和。每个 polyline 边界点都被考虑。Hough 变换将一条直线映射为 (*s*, *θ*) 平面中的一点，所有点映射到同一位置，从而用于通过不同边缘点寻找线段。多边形距离方法用于从边界顶点计算 cIMT \[[54](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib54)\]. Hough 变换被多个工作使用，如 Golemati *et al* \[[67](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib67)\], Stoitis *et al* \[[68](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib68)\], Petroudi *et al* \[[69](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib69)\]. 在另一项由 Destrempes *et al* \[[56](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib56)\] 完成的工作中，Nakagami 分布和运动估计被用于估计 cIMT。第一代技术使用信号处理方法，如尺度空间来检测 LI–MA 边界 \[[46](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib46), [70](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib70)\]. 第二代技术有时在第一代技术基础上进行增强以提高性能 \[[24](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib24), [71](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib71)–[73](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib73)\].
