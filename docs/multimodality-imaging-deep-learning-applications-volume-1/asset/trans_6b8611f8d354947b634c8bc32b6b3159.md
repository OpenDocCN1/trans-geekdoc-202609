
-   [最受欢迎的基于DL的模型是卷积神经网络（CNN），在生物医学影像社区中被广泛使用。](https://wiki.example.org/feynmans_learning_method) 的设计灵感来源于VC的架构，其中神经元是层级排列的，并对微小细节敏感。CNN利用了VC在空间上利用视觉图像内的局部相关性的能力。CNN通过在相邻层之间强制模式的局部连接，使用三个重复函数——卷积、整流线性单元（ReLu）和池化——来实现其目标。卷积层会对输入图像应用一组滤波器，点向相乘对应的像素以生成特征图。特征图中的每个点代表输入图像相邻像素之间的空间关系。数学上，卷积表示为

``` 
$$f\\left( {x,y} \\right) = {Img}\\left( {x,y} \\right)ʘW\\left( {x,y} \\right) = \\sum\\limits\_{p = - \\frac{m}{2}}^{\\frac{m}{2}}\\sum\\limits\_{q = - \\frac{m}{2}}^{\\frac{m}{2}}{Img}\\left( {x + p,y + q} \\right) \\times W\\left( {x,y} \\right),$$  
```  

(2.8)graphic style="width:38.8125em;" xlink:href="bk978-0-7503-2244-7ch2eqn30.gif" position="float"/

其中，图像‘Img’与滤波器 *W* 卷积，输出特征值 *f*，‘ʘ’ 符号表示卷积过程。*f*(*x*,*y*) 表示特征图上的坐标，是卷积滤波器与相邻像素乘积的和值。

滤波器的内容在每次迭代中会更新，这代表了CNN的学习过程。卷积产物的输出随后会传入ReLu层，以去除负值，防止消失梯度问题。池化过程用于降维。池化输出要么保留特征图中最相关的部分（最大池化），要么对其进行平均。这三个函数——卷积、ReLu 和池化——会反复应用，以挖掘最相关的特征。挖掘出后，会附加一个全连接网络（多层感知器）进行特征表征。还有一种CNN的适应形式，它不使用全连接层，而是使用上采样和跳过层。这种网络也称为完全卷积网络（FCN），用于分割目的。上采样层是卷积的逆运算，利用滤波器将特征图转换为高维表示。跳过层用于融合CNN相邻层的特征图与上采样层的特征图。这 exclusively 用于在下采样阶段丢失的空间信息被保留。最终，使用对应的真实标签进行像素到像素的表征，生成平滑的分割图。这种分割也称为语义分割。

#### 2.2.4 Deep residual network

DL模型的性能在深层层数超过一定点后不再提升，甚至会迅速下降。这是因为DL网络的浅层参数因消失梯度问题而无法自我更新。深度残差网络（ResNets）提供了一种解决方案，使得浅层的训练误差保持不变。模型的工作方式如下。假设 *G*(*i*) 是两个相邻层的期望输出，如图 [2.5](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2fig5)(a) 所示，则中间层的残差映射为 *G*(*i*) = *F*(*i*) – *i*，如图 [2.5](#Chapter_2.xhtml#Chapter_2.xhtml#bk978-0-7503-2244-7ch2fig5)(b) 所示。也可以重新表述原映射，即 *G*(*i*) = *F*(*i*) + *i*，如图 [2.5](#Chapter_2.xhtml#Chapter_2.xhtml#bk978-0-7503-2244-7ch2fig5)(c) 所示。这种映射虽然不能降低训练误差，但也不会增加它，从而使得层数增加时性能不会退化。

### 2.3 DL based biomedical imaging systems

DL在生物医学影像发表的快速增长归因于多种因素：快速泛化、更好性能、高可扩展性、鲁棒性等。DL工具相较于机器学习工具的主要优势在于其即插即用特性，无需任何中间阶段。ML算法的特征挖掘阶段在DL架构内部完全集成，为所有类型图像提供统一的接口。DL已被用于生物医学影像的两个目的：(i) 特征表征（图 [2.6](#Chapter_2.xhtml#Chapter_2.xhtml#bk978-0-7503-2244-7ch2fig6)）和 (ii) 分割。本节将介绍使用DL模型对多种疾病进行表征的情况。生物医学图像的分割是一个复杂的操作。基于DL的分割要么是单阶段，要么是双阶段。单阶段采用FCN基于的语义分割或补丁特征表征。双阶段模型中，第一阶段通常是全局感兴趣区域（ROI）检测，采用ML/DL范式。下一阶段是另一个ML/DL范式，用于在ROI内部划定边界（图 [2.7](#Chapter_2.xhtml#Chapter_2.xhtml#bk978-0-7503-2244-7ch2fig7)）。在接下来的几节中，我们将介绍多种生物医学领域中DL在影像领域的不同应用。
