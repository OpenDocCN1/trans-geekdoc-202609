*Power analysis*

我们通过功效分析（power analysis）验证了本研究，以确定所需的样本量。我们使用以下方程进行功效分析：

$${sample}\\ {size} = \\frac{2\\quad \\times \\left( {Z\\_{\\alpha} + Z\_{1 - \\beta}} \\right)^{2}\\quad \\times \\quad\\sigma^{2}}{\\Delta^{2}}.$$  

(12.1)graphic style="width:38.8125em;" xlink:href="bk978-0-7503-2244-7ch12eqn1.gif" position="float"/

这里我们取 *Z*[*α*] = 3.2905（类型 I 错误为 1%），*Z*[1−*β*] = 1.6449（类型 II 错误为 1%），标准差 *σ* = 5.65，均值差 Δ = 0.727。将这些值代入方程 ([12.1](#Chapter_12.xhtml#bk978-0-7503-2244-7ch12eqn1))，得到所需样本量为 2942.4。因此，平衡（原始）队列包含 5600 个样本，比所需样本量高出 47.45%。

*Cohen’s kappa analysis*

在本研究中，我们使用了八个 AI 模型，需要评估它们之间的评审一致性，因此采用了 Cohen’s kappa 分析 \[[38](#Chapter_12.xhtml#bk978-0-7503-2244-7ch12bib38)\]。该指标用于评估评审者间的一致性。Kappa 值的含义如下：≤ 0 表示无一致性，0.01–0.20 为轻微一致，0.21–0.40 为一般一致，0.41–0.60 为适度一致，0.61–0.80 为显著一致，0.81–1.00 为评审者之间的完美一致。我们在模型的优化点计算每个模型的平均 kappa（*K*[a]）值。表 [12.5](#Chapter_12.xhtml#bk978-0-7503-2244-7ch12t5) 按升序列出了本研究的 Cohen’s kappa 分析结果。
