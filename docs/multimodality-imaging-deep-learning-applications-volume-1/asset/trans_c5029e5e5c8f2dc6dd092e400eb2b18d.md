#### 10.7.2 ELM 与 BPNN 的比较

ELM 和 BPNN 都是基于神经网络（NN）的技术。Suri 对 BPNN 的改进实现了 97.6% 的准确率，而 ELM 实现了 96.7% 的准确率。这些结果（如表 [10.6](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10t6) 所示）表明 BPNN 在准确率上优于 ELM，说明 BPNN 是更强的分类器。另一方面，ELM 的优势远超 BPNN。由于 ELM 是单层前馈网络（SLFNN），其网络复杂度远小于 BPNN，后者可包含更多的隐藏层和神经元（最多十层，见 \[[21](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib21)\]）。其次，BPNN 的收敛速度远慢于 ELM，因为 BPNN 的每个参数都需要逐次更新。由于 ELM 只进行矩阵乘法且仅有一个隐藏层，它在一次迭代中即可达到与 SVM 相当的准确度。此外，与 BPNN 相比，ELM 只需使用四分之三的特征即可达到与 BPNN 精度相差不足 1%（0.9%）的效果（使用 46 个常规特征，即 128 个特征）。总体而言，这些优势充分证明了在与 BPNN 和 SVM（均属于机器学习方法）相比时，采用 ELM 更为合适。

#### 10.7.3 ELM 与 SVM 的特别说明

SVM 训练分为两个阶段。第一阶段，特征通过非线性映射函数（或核函数）被映射到更高维空间；第二阶段，使用优化方法寻找两类数据在该特征空间中的最大分离超平面，同时最小化训练误差。由于优化问题呈二次且凸形，求解相对简单。ELM 使用单层前馈网络（SLFNN）分两步训练：特征映射和线性参数求解。隐藏层参数在第一步随机初始化，以利用 sigmoid 非线性函数将输入数据映射到特征空间。随后，通过最小化误差在第二步求解隐藏层到输出层的参数，采用 Moore–Penrose 伪逆 \[[25](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib25), [34](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib34)\] 来最小化损失。ELM 在单一步骤中学习隐藏层到输出层的参数，即直接用激活函数输出的 Moore–Penrose 伪逆与目标值相乘。对于小于隐藏神经元数量的数据集，ELM 的时间复杂度与隐藏神经元数量成正比 \[[27](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib27)\]。与 SVM 不同，ELM 的输入到隐藏层的参数无需修改。ELM 在回归、二分类和多类分类中的最小二乘解仅依赖于输入数据和训练样本数量 \[[44](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib44)\]。由于仅需一次矩阵乘法即可得到隐藏层到输出层的参数，ELM 的计算复杂度低于 SVM。因此，对于较小的数据集，ELM 的时间复杂度与隐藏节点数量成比例，需要一步前向传播即可完成。对于不可线性分离的数据，SVM 的计算成本上升，因为必须在高维空间使用核函数进行求解。SVM 的核函数根据应用场景不同而异，而 ELM 提供了更通用的分类解决方案。随着训练数据规模增大，SVM 计算变得更复杂，因为需要从整个数据集中找到更多支持向量。尽管 ELM 与 SVM 使用相同的损失函数，但 ELM 的优化约束松弛程度更大；SVM 通过最小二乘模型优化，而 ELM 则采用最大边界技术。实验表明，ELM 由于输入到隐藏层的参数保持不变，仅需学习隐藏到输出层参数，这相当于学习线性模型 \[[44](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib44), [45](#Chapter_10.xhtml#bk978-0-7503-2244-7ch10bib45)\]。实验表明，使用随机隐藏节点的 ELM 可比 SVM 快上至十倍。基于此分析，可以适当得出结论：ELM 的表现优于 SVM。
