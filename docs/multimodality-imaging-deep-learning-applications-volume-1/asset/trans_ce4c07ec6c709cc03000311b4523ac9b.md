
有两种学习方式：监督学习和无监督学习。在监督学习中，深度学习（DL）参数通过有标签的实例迭代学习/训练，直至学习收敛或达到最小误差。在无监督学习中，DL 模型在没有任何学习样本干预的情况下，学习数据内部的复杂关联。

其中一个著名的用于图像特征提取和分割的 DL 模型是卷积神经网络（CNN）\[[20](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib20)\]。CNN 通过重复的卷积层和池化层（稍后解释）来从图像中提取有意义的信息。有意义的信息以图像模式的空间局部相关性形式出现，也称为特征或特征图。

有许多著名的 CNN 模型参与并甚至赢得了 ImageNet 竞赛，例如 LeNet \[[21](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib21)\]，AlexNet \[[22](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib22)\]，GoogleNet \[[23](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib23)\]，等等。然而，当网络深度超过一定限制时，DL 模型的准确率会停滞甚至下降，原因是消失梯度问题。深度残差网络（ResNets）通过跳过层来克服此问题，从而提升网络深度和准确率 \[[24](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib24)\]。

深度信念网络（DBNs）是无监督的 DL 网络，代表了受限玻尔兹曼机的更深层次形态 \[[13](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib13), [14](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib14)\]。DBNs 在图像再生与识别 \[[15](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib15), [16](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib16)\]，视频序列 \[[17](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib17)\]，以及动作捕捉数据 \[[18](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib18)\]方面具有重要应用。

Autoencoders 是另一种无监督的 DL 模型，其输入层神经元数等于输出层神经元数 \[[19](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib19)\]。Autoencoder 包含多个隐藏层，用于学习输入图像的压缩表示。训练完成后，Autoencoders 可用于图像去噪以及重建输入图像。

还有不同的生物医学影像模态用于诊断疾病或扫描受影响的身体部位。最常见的是计算机断层扫描（CT）\[[25](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib25)\]，磁共振成像（MRI）\[[26](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib26)\]，以及超声波（US）\[[27](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib27)\]。放射科医生发现异常，受过训练的医师则诊断并为患者制定治疗方案。然而，放射科医生的短缺以及技术的进步，促使基于机器学习（ML）和计算机视觉的自动化计算机辅助诊断工具的大量发展。在此方面，Suri 及其团队是开发不同重要疾病自动化 CAD 工具的先驱。2008 年，该团队开发了用于宫颈肿瘤轮廓划分的可变模型 \[[28](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib28)\]。2011 年，团队构建了基于特征和边缘的机制，从颈动脉超声图像中提取血管-内膜厚度 \[[29](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib29)\]。2014 年，同一团队开发了基于机器学习的工具，用于分类卵巢组织 \[[30](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib30)\] 以及基于波兰超声图像数据集检测 Hashimoto 甲状腺炎 \[[31](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib31)\]。此外，2014 年，团队开发了一个基于 level set 的自动系统，用于从 MRI 图像中估计颈动脉厚度 \[[32](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib32)\]。

基于机器学习的统计模型用于特征表征是一个两阶段过程：第一阶段从图像中提取手工制作的特征，然后在第二阶段将统计机器学习模型应用于特征表征。手工特征并未覆盖所有详细信息，因此信息不完整，导致准确率低。然而，在深度学习（DL）中，特征提取在单一阶段内部完成，无需手工特征，直接进行特征学习。在分割任务中，变形模型长期用于轮廓化感兴趣区域（ROI）。但变形模型的性能受噪声影响显著 \[[33](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib33)\]。基于机器学习的分割通过从每个图像像素提取 3D atlas 向量，然后通过训练/测试范式计算每个像素的概率图，从而推断边界形状 \[[34](#Chapter_2.xhtml#bk978-0-7503-2244-7ch2bib34)\]。然而，这些措施具有任务特异性，无法在不同数据集之间泛化。相反，DL 通过像素到像素的特征表征直接推断患病/受影响区域的形状。所有特征提取均在内部完成，因此同一 DL 模型可以在多种数据集上训练，无需担心预处理，从而使 DL 模型的泛化能力和鲁棒性远优于 ML 模型。下面的章节将提供对四种最常用 DL 模型的研究、生物医学影像中不同 DL 应用的讨论、文献综述以及结论。
