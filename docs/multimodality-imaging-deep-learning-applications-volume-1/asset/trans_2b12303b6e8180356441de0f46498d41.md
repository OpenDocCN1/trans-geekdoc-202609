## 9.4.2 全卷积网络用于 cIMT 区域估计

Biswas *et al* \[[111](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib111)\] 从 396 份超声心动图 CCA 图像中，通过三步恢复 LI 和 MA 边界。两位经验丰富的放射科医生使用通用追踪软件 AtheroEdge™ \[[66](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib66), [113](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib113), [114](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib114)\] 对 LI 和 MA 边界进行描绘，生成的二值图作为基准真值。图像在第一个多尺度阶段的每侧各裁剪 10%，以确保低对比度和无关部分不影响第二阶段的学习。这通常是由于显影剂不足或抓取时探头与颈部接触不良造成的。第二阶段采用全卷积网络（FCN）将 cIMT 区域与图像其余部分分离。FCN 系统由两个子系统组成：编码器和解码器，如图 [9.7](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9fig7) (i) 所示。编码器包含 13 层卷积（两层 64（窗口大小 = 3×3）+ 两层 128（窗口大小 = 3×3）+ 三层 256（窗口大小 = 3×3）+ 三层 512（窗口大小 = 3×3）+ 三层 512（窗口大小 = 3×3）），以及五层最大池化层，用于生成图像的下采样特征图。Rosa *et al* \[[92](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib92)\] 在子章节 [9.3.1](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9s9-3-1) 中阐述卷积过程，该子章节对卷积核在像素级应用于图像，以提取上下文信息和位置不变性属性。每个最大池化步骤之前使用 1×1 卷积压缩特征图为单图。解码器包含三个上采样层、两个中间跳跃操作以及一个 softmax 层，用于像素与像素的比较与基准真值。卷积运算数学定义如下：

```math
h(a,b) = I(a,b) ⊗ k(a,b) = Σ_{s = -m/2}^{m/2} Σ_{t = -m/2}^{m/2} I(a + s, b + t) × k(a,b),
```

其中 *h* 为输出，*I* 为图像，*k* 为大小为 *m* × *m* 的卷积核，(*a*,*b*) 表示像素位置，*s*、*t* 为占位变量。最大池化通过保留每块图像中最重要的信息来实现下采样。图 [9.7](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9fig7) (i) 展示了所使用的 FCN 模型。为获得原图 1/32 大小的特征图，编码器执行 13 层卷积（红框所示）和五层最大池化（蓝框所示），如图 [9.7](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9fig7) (i) 所示。解码器通过三个上采样层（灰色框）和中间跳跃操作（绿色框）实现像素级的密集 softmax 分类（橙色框），并与基准真值进行比较。上采样是卷积的逆运算，作用于编码器末端的特征图。为恢复图像至原始尺寸，使用三个上采样层。跳跃连接将编码器的压缩层特征图与解码器的中间层特征图结合，以恢复下采样过程中丢失的空间信息。对于像素级特征，交叉熵损失函数为：

```math
θ_{class}(α_1,α_2) = (1/|N|) Σ_{n∈N} Σ_{l∈L} α_2_n(l) log(α_1_n(l)),
```

其中 *α*[1] 表示预测，*α*[2] 表示金标准（GT），*L* 为类别总数，*N* 为图像总数。softmax 层用于最终特征，将像素分配给概率最高的类别，公式如下：

```math
P(z_i) = e^{z_i} / Σ_{j=1}^{N} e^{z_j},
```

其中 *z*[*i*] 表示第 *i* 类实例的归一化得分。将 DL 迭代次数固定为 20 000，可得到分割图像。最后，第三阶段利用校准和矩阵逆运算 \[[115](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9bib115)\] 对 MA 边界进行细化。图 [9.7](#Chapter_9.xhtml#bk978-0-7503-2244-7ch9fig7) (ii) 展示了 LI 和 MA 边界以及其基准真值。两个基准真值的 cIMT 偏差分别为 0.126 ± 0.134 mm 和 0.124 ± 0.10 mm。
