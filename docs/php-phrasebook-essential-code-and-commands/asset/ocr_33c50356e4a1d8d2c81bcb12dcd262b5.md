# Accessing All Array Elements in Nested Arrays

```
$arr = array(
    'Roman' =>
        array('one' => 'I', 'two' => 'II', 'three' =>
        'III', 'four' => 'IV'),
    'Arabic' =>
        array('one' => '1', 'two' => '2', 'three' =>
        '3', 'four' => '4')
);

printNestedArray($arr);
?>
```
