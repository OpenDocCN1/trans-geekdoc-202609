# mysqli_query()

The functions mysql_query() and mysqli_query() send SQL to a database identified by a handle—second parameter for mysql_query(), first parameter for mysqli_query(). However, to avoid an attack called “SQL injection” (a method to inject SQL statements using GET or POST data), you absolutely **must** use mysql_real_escape_string() or mysqli_real_escape_string() to escape any dangerous characters such as single quotes.
