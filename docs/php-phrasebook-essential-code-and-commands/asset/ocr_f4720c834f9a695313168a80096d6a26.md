# Communicating with Others

Most of the previous phrases worked within the ecosystem of the PHP script and the web server in use. However, because some phrases can also be understood by others, this chapter covers some examples of this type. You can connect to remote servers in a variety of ways.

# Connecting with HTTP Servers

```
<xmp>
<?php
echo file_get_contents('http://www.php.net/');
?>
</xmp>
```

Hypertext Transfer Protocol (HTTP) is probably the protocol most often used from PHP to connect with others (apart from various database protocols). Starting with PHP 4.3, it is really easy to connect to such data
