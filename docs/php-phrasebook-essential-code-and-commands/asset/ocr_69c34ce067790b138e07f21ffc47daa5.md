# Creating a Web Service with PEAR::XML-RPC

```
if ($a->scalartyp() == 'int' && $b->scalartyp()
    == 'int') {
    $a = $a->scalarval();
    $b = $b->scalarval();
    $c = new XML_RPC_Value($a + $b, 'int');
    return new XML_RPC_Response($c);
} else {
    global $XML_RPC_erruser;
    return new XML_RPC_Response(0,
        $XML_RPC_erruser,
        'wrong parameters');
    }
}
}
```

# Consuming a Web Service with PEAR::XML-RPC

Querying the Web Service is rather easy. Just instantiate the XML_RPC_Client class (providing name, server, and port of the service), then craft a message with all the parameters, and finally send this message to the server. You receive the result of the Web Service call in return—or an error message.
