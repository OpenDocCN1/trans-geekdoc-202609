Another function that behaves similarly is array_walk(). This one also applies a function to every element of an array; however, it also allows you to provide a parameter for this function call. In the following code, this is used to print out all elements of an array. A parameter is passed—a counter. Because it is passed by reference, increasing this counter by 1 within the function leads to a sequence of numbers.

```
<?php
    function printElement($s, &$i) {
        printf('%d: %s<br />', $i,
            htmlspecialchars($s));
        $i++;
    }
    $i = 1;
    $a = array('one', 'two', 'three', 'four');
    $a = array_walk($a, 'printElement', $i);
?>
```
