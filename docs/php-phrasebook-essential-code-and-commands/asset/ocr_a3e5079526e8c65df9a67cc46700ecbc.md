NOTE

PHP 5.1 comes with XMLReader included by default. This is a wrapper on libxml2 and mimics the application programming interface (API) of the .NET component for reading XML, XmlTextReader. It is much faster than SAX and just easier to use. As of this writing, it is not very stable yet, but looks quite promising. Not part of the standard PHP 5.1 distribution, but available in PECL, is the associate module XMLWriter that allows write access to XML. More information about both modules is available in a presentation by their author at http://php5.bitflux.org/xmloncrack/.
