# Preselecting Radio Buttons

Therefore, it is quite messy but rather trivial to prefill a group of radio buttons: Just compare the value in $_GET/$_POST with the associated value. If it fits, print out checked, the HTML attribute that preselects a radio button, as shown in the code.

```
<input type="radio" name="groupname" value="php3"
<?php
    if (isset($_POST['groupname']) && $_POST
    ['groupname'] == 'php3') {
        echo 'checked="checked" ';
    }
?>/>PHP 3
```
