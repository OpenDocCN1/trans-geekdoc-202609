[1](#47_Chapter39.xhtml#rfn2-1). **(B)** 当 `x` 如片段 I 所示被转换为整数时，会丢失信息。Java 要求进行显式转型为 `int`，如片段 II 所示。注意片段 II 会导致 `x` 被截断：存储在 `y` 中的值是 `14`。通过要求显式转型，Java 防止你意外地这样做。在片段 III 中，`y` 将包含值 `14.0`。由于没有丢失信息，因此不需要显式转型为 `double`。

[2](#47_Chapter39.xhtml#rfn2-2). **(E)** 字符串参数包含两个转义序列：`\\`，表示打印一个反斜杠（`\`）；`\n`，表示换行。选项 E 是唯一同时满足这两点的选项。

[3](#47_Chapter39.xhtml#rfn2-3). **(D)** 布尔表达式将发生短路求值。表达式 `(n != 0)` 将求值为 `false`，这使得整个布尔表达式为 `false`。因此表达式 `(x / n > 100)` 将不会被求值。因此不会发生除以零的情况，后者会导致抛出 `ArithmeticException`。当布尔表达式的值为 `false` 时，仅执行语句的 `else` 部分，即 `statement2`。

[7](#47_Chapter39.xhtml#rfn2-7). **(B)** 尽管对于非零 `x` 该表达式在代数上恒为真，但由于执行除法和乘法运算时的舍入误差，该表达式求值结果可能为 false。表达式右侧是否恰好求值为 3.0 取决于 `x` 的值。注意如果 `x` 为零，该表达式将求值为 `false`，因为右侧将被赋值为 `Infinity`。

[10](#47_Chapter39.xhtml#rfn2-10). **(A)** 由于第一个测试 `(x >= 0)` 为 `true`，匹配的 `else` 部分 `y = -x` 将不会执行。由于 `(x <= 100)` 为 `true`，匹配的 `else` 部分 `y = x * 2` 将不会执行。变量 `y` 将被设为 `x * 3`（即 90），现在将无法通过测试 `y < 50`。因此，`x` 在此算法中永远不会被改变。最终值为 `x = 30` 和 `y = 90`。

[11](#47_Chapter39.xhtml#rfn2-11). **(C)** 为了使 `!(A || B || C)` 为真，`(A || B || C)` 必须求值为 false。这仅在 `A`、`B` 和 `C` *全* 为 false 时发生。选项 A 在 `A` 和 `B` 为 false 且 `C` 为 true 时求值为 true。在选项 B 中，如果 `A`、`B` 或 `C` 中*任意一个*为 false，布尔表达式求值为 true。在选项 D 中，如果 `A`、`B` 或 `C` 中任意一个为 false，布尔表达式求值为 true，因为我们有 `!(false)`。选项 E 求值为 true 仅要求 `A` 为 false。由于 `true||(any)` 求值为 true，`B` 和 `C` 可以是 true 也可以是 false。

[12](#47_Chapter39.xhtml#rfn2-12). **(D)** 要使表达式求值为 `true`，必须简化为 `true && true`。因此我们需要 `!(false) && true`。选项 D 是唯一保证这一点的条件：`a > b` 为左侧表达式提供 `!(false)`，而 `a > b` 和 `b > 0` 意味着 `a` 和 `b` 均为正，从而使右侧表达式为 `true`。例如选项 E，仅当 `a < 0` 时才会为右侧表达式提供 `true`。你对 `a` 一无所知，不能对其做假设。

[13](#47_Chapter39.xhtml#rfn2-13). **(A)** 如果 `(c < a)` 为 `false`，则 `((c == a*b) && (c < a))` 求值为 `false`，无论 `c == a*b` 的值如何。在这种情况下，`!(c == a*b && c < a)` 求值为 `true`。然后 `(a < b) || true` 求值为 `true`，无论测试 `(a < b)` 的值如何。在所有其他选项中，给定表达式*可能*为 `true`。然而，没有给出足够的信息来保证这一点。

[14](#47_Chapter39.xhtml#rfn2-14). **(C)** 如果 `a == b` 为 false，则 `a != b` 为 true。因此，在知道整个测试的值之前，必须先求复合测试的第二部分。由于 `a == b` 为 false，`a - b` 不等于零。因此，不会发生除以零，也不会抛出异常。此外，由于 `a`、`b` 和 `n` 的相对值未知，测试 `n / (a - b) > 90` 的值未知，且没有足够的信息来确定复合测试是 true 还是 false。因此，将执行 `/* statement 1 */` 或 `/* statement 2 */`。
