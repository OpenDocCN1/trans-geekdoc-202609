
# 不要使用 `==` 测试字符串！

表达式 `if (string1 == string2)` 测试的是 `string1` 和 `string2` 是否为同一个引用。它并不测试实际的字符串内容。使用 `==` 比较字符串可能会导致意外的结果。

## 示例 1

![images](images/f158-01.jpg)

即使看起来 `s` 和 `t` 是不同的引用，测试仍返回 `true`。原因在于，为了效率，Java 对等价的字符串字面量只创建一个 `String` 对象。这是安全的，因为 `String` 不能被修改。

故事的寓意？测试字符串请用 `equals` 而非 `==`。它永远能做正确的事。

## 包装类

*包装类* 接受一个现有对象或基本类型的值，“包装”或“装箱”进一个对象中，并为该类型提供一组新的方法。包装类的目的是为被装箱的量提供扩展功能：

![](images/sq1.jpg) 可用于需要对象作为参数的通用 Java 方法中。

![](images/sq1.jpg) 可用于要求项目为对象的 Java 容器类（如 `ArrayList`）中。

在每种情况下，包装类都允许：

**1.** 从单个值构造对象（将基本类型包装或装箱进包装对象）。

**2.** 检索基本类型值（从包装对象中拆包或拆箱）。

Java 为其每种基本类型都提供了一个包装类。AP 考试要求掌握的两个类是 `Integer` 和 `Double` 类。

## 注意

**1.** `Integer` 和 `Double` 类的 `compareTo` 和 `equals` 方法不再属于 AP Java 考纲范围。这可能是因为 Java 后续版本大量使用了自动装箱和自动拆箱。

**2.** `Integer` 和 `Double` 对象是不可变的。这意味着这些类中没有修改器方法。
