### 34. (C)
假设你想要 2 到 8 之间的随机整数，即 `low` = 2 且 `high` = 8。共有 7 个可能的整数，所以你需要

```
(high - low + 1)
```

这将产生 0、1、2、... 或 6。因此，表达式

```
(int)(Math.random() * (high - low + 1))
```

将产生 2、3、4、... 或 8。使用这些值时，唯一能得出正确答案的表达式是

```
low + (int)(Math.random() * (high - low + 1))
```
