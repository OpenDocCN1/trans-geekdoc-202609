# 附录：实用计算机术语词汇表

*我讨厌定义。*

*—本杰明·迪斯雷利，《维维安·格雷》（1826）*

**API 库：** 应用程序编程接口库。供其他程序使用的类库。该库提供标准接口，隐藏实现细节。

**Applet：** 在 Web 浏览器或 Applet 查看器中运行的图形化 Java 程序。

**应用程序：** 存储在用户本地计算机上并在此执行的独立 Java 程序。

**二进制数制：** 基数为 2。

**位：** 来自 "binary digit"（二进制数字）。计算机内存的最小单位，只能取 0 或 1 两个值。

**缓冲区：** 有限大小的临时存储位置。存放等待使用的值。

**字节：** 八位。类似地，兆字节 (MB, 10⁶ 字节) 和吉字节 (GB, 10⁹ 字节)。

**字节码：** 可移植的（与机器无关的）代码，介于源代码和机器语言之间。由 Java 编译器生成，由 Java 虚拟机解释（执行）。

**缓存：** 用于存储数据的少量“快速”内存。通常，从磁盘存储或“慢速”内存中最近访问的数据会被保存在主内存缓存中，以便再次检索时节省时间。

**云计算：** 一种基于互联网的新型计算形式，按需共享数据和计算机处理资源。

**编译器：** 将源代码翻译成目标代码（机器语言）的程序。

**CPU：** 中央处理单元（计算机的大脑）。它控制指令的解释和执行。它由算术/逻辑单元、控制单元和一些内存组成，通常称为“片上内存”或缓存内存。从物理上讲，CPU 由芯片上的数百万个微观晶体管组成。

**网络空间：** 发生任何互联网通信的抽象环境。

**调试器：** 一种通过跟踪程序中变量值来帮助查找错误的程序。

**十进制数制：** 基数为 10。

**GUI：** 图形用户界面。

**硬件：** 计算机的物理组件。这些是你可以触摸到的部件，例如键盘、显示器、打印机、CPU 芯片。

**赫兹：** 每秒一个周期。它指计算机内部时钟的速度，给出 CPU 速度的度量。类似地，兆赫 (MHz, 10⁶ Hz) 和吉赫 (GHz, 10⁹ Hz)。

**十六进制数制：** 基数为 16。

**高级语言：** 一种人类可读的编程语言，使得需要许多机器步骤的指令能够被简洁地编码，例如 Java、C++、Pascal、BASIC、FORTRAN。

**HTML：** 超文本标记语言。Web 浏览器读取的用于格式化网页、链接到其他网站等的指令。
