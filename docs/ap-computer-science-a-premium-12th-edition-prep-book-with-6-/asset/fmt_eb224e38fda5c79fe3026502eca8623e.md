
## 6. Java 中的三种注释分隔符

Java 中有三种不同类型的注释分隔符：

*   `/*` ... `*/`，用于包围一块注释（如本节所示的程序）。该块可以跨越一行或多行。
*   `//`，生成单行注释。
*   `/**` ... `*/`，生成 Javadoc 注释。这些注释用于创建 Java 库软件的 API 文档。

### Javadoc 注释

Javadoc 注释 `@param` 和 `@return` 不再属于 AP Java 考试大纲范围。

### 类型与标识符

### 标识符

**标识符** 是变量、参数、常量、用户定义方法或用户定义类的名称。在 Java 中，标识符是由字母、数字和下划线字符组成的任意序列。标识符不能以数字开头。标识符区分大小写，这意味着 `age` 和 `Age` 是不同的。在可能的情况下，标识符应当简洁且自文档化。名为 `area` 的变量比名为 `a` 的变量更具说明性。

按照惯例，变量和方法的标识符使用小写。大写字母用于将多个单词分隔开，例如 `getName`、`findSurfaceArea`、`preTaxTotal` 等。注意类名以大写字母开头。保留字全为小写，不能用作标识符。

### 数字的存储

存储的细节不在 AP 考试测试范围内。然而，它们有助于理解 `int` 和 `double` 类型之间的差异。

#### 整数

Java 中的整数值精确存储，作为一串位（二进制数字）。其中一位存储整数的符号：0 表示正数，1 表示负数。

Java 内置整数类型 `byte` 使用一个字节（八位）存储。

![images](images/f066-07.jpg)

该图表示使用 `byte` 类型可以存储的最大正整数：2⁷ − 1。

Java 中的 `int` 类型使用四个字节（32 位）。留出一位作为符号位，可以存储的最大整数是 2^(31) − 1。一般来说，*n* 位整数使用 *n*/8 个字节存储，存储范围从 −2^(*n*−1) 到 2^(*n*−1) − 1。（注意负数多出的一个值来自于不需要存储 −0。）有两个你应该知道的 Java 常量。`Integer.MAX_VALUE` 保存 `int` 能容纳的最大值，即 2^(31) − 1。`Integer.MIN_VALUE` 保存 `int` 能容纳的最小值，即 −2^(31)。

Java 内置整数类型有 `byte`（一个字节）、`short`（两个字节）、`int`（四个字节）和 `long`（八个字节）。其中，只有 `int` 在 AP Java 考试大纲范围内。

#### 浮点数

Java 中有两种存储实数的内置类型：`float`（使用四个字节）和 `double`（使用八个字节）。**浮点数** 存储在两部分中：一个**尾数**，指定数字的数字；和一个指数。JVM（Java 虚拟机）使用科学计数法表示该数字：

![images](images/f067-01.jpg)

在这个表达式中，2 是该数字的**基数**或**底数**。在 `double` 类型中，11 位分配给指数，（通常）52 位分配给尾数。一位分配给符号。这是一个**双精度**数字。`float` 类型是**单精度**的，不在 AP Java 考试大纲范围内。

当浮点数转换为二进制时，大多数不能精确表示，导致**舍入误差**。这些误差会因算术运算而累积。例如：

在 Java 中，浮点运算不会抛出异常。有两种情况你应该注意：

*   当执行的操作产生未定义结果时，Java 将此结果表示为 `NaN`，“非数字”。产生 `NaN` 的操作示例包括：对负数取平方根，以及 0.0 除以 0.0。
*   产生无限大或无限小数字的操作（如除以零），在 Java 中产生 `Infinity` 或 `-Infinity` 结果。
