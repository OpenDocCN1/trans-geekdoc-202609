## Answer Explanations

### 1
**(D)** There are just two constructors. Constructors are recognizable by having the same name as the class, and no return type.

### 2
**(B)** Each of the private instance variables should be assigned the value of the matching parameter. Choice B is the only choice that does this. Choice D confuses the order of the assignment statements. Choice A gives the code for the *no-argument* constructor, ignoring the parameters. Choice C would be correct if it were `resetTime(h, m, s)`. As written, it doesn’t assign the parameter values `h`, `m`, and `s` to `hrs`, `mins`, and `secs`. Choice E is wrong because the keyword `new` should be used to create a new object, not to implement the constructor!

### 3
**(C)** Replacement III will automatically print time `t` in the required form since a `toString` method was defined for the `Time` class. Replacement I is wrong because it doesn’t refer to the parameter, `t`, of the method. Replacement II is wrong because a client program may not access private data of the class.
