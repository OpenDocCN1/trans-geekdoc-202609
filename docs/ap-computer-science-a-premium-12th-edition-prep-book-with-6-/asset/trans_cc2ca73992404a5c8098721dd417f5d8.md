

## 选择控制结构

这些包括 `if`、`if...else` 和 `switch` 语句。它们都是选择控制结构，为程序引入了决策能力。基于布尔表达式的真值，计算机将决定遵循哪条路径。`switch` 语句不属于 AP Java 考纲范围。

### `if` 语句

![images](images/f073-03.jpg)

只有当 `boolean expression`（布尔表达式）为 `true` 时，此处的 `statements`（语句）才会被执行。如果为 `false`，控制权将立即传递给 `if` 语句之后的第一条语句。

### `if...else` 语句

![images](images/f073-04.jpg)

此处，如果 `boolean expression`（布尔表达式）为 `true`，则仅执行紧跟在测试之后的 `statements`（语句）。如果 `boolean expression` 为 `false`，则仅执行 `else` 之后的 `statements`。

## 错误与异常

*异常* 是在 Java 程序执行期间发生的错误条件。例如，如果你用零除以一个整数，将抛出 `ArithmeticException`。如果你使用负数组索引，将抛出 `ArrayIndexOutOfBoundsException`。

*未检查异常* 是由 Java 的标准异常处理方法自动处理的异常，这些方法会终止执行。如果尝试用 0 除以一个整数，或数组索引越界等，将抛出此异常。该异常告诉你现在需要修复代码！

*已检查异常* 是指你提供代码来处理异常的情况，要么是 `try`/`catch`/`finally` 语句，要么是显式的 `throw new...Exception` 子句。这些异常不一定是由代码错误引起的。例如，意外的文件结束可能是由于网络连接中断。已检查异常不在 AP Java 考纲范围内。
