
可能会有几道题要求你比较两个据称实现相同算法的算法。它们可能会问你哪个算法更高效。影响效率的因素是比较次数和数据移动次数。检查每个循环的主体。统计比较次数和数据移动次数。将总数乘以循环的迭代次数。答案较低的算法即为更高效的算法。

你可能会被要求比较数据结构。这些是你应该自问的问题：

- 哪种结构定位给定元素所需的比较次数最少？
- 哪种结构插入或删除元素所需的数据移动次数最少？
- 该结构是否存储对象的完整状态？

### 答多项选择题的技巧

这里有三条最后的建议：

- 注意在答题卡上填涂与你刚解答的题号相对应的答案！
- 由于答题卡由机器评分，如果你更改答案，请务必擦除干净。
- 最后花一点时间检查你是否为每道题都提供了答案。

### 简答题部分技巧

### 考试形式是怎样的？

- 你将有 90 分钟时间完成考试第二部分的四道简答题。
- 每题价值 9 分。请注意，简答题部分和多项选择题部分在决定你的 AP 成绩时权重相同。
- 你编写的代码必须是 Java 语言。
- 在提供的答题册上书写你的解答。在每页答题纸顶部填涂题号。
- 你应该使用 2B 铅笔书写解答。

请注意，简答题使用的单独答题册将是空白的。

### 考察什么内容？

理论上，整个 AP Java 考纲范围都是简答题的命题范围。但你应该特别关注以下各项：

- 使用数组和 `ArrayList` 进行列表操作
- 字符串操作
- 二维数组
- 类和子类

### 可能会问什么类型的问题？

你可能会被要求完成以下各项：

- 编写指定方法的主体。
- 利用题目前几部分的代码编写方法主体。
- 编写一个重载方法（参见 [第 99 页](#48_Chapter40.xhtml#page_99)）。
- 编写一个构造器（参见 [第 133 页](#49_Chapter41.xhtml#page_133)）。
- 在子类中提供一个被重写的方法（参见 [第 133 页](#49_Chapter41.xhtml#page_133)）。
- 编写一个完整的类或子类。

### 简答题的技能侧重点

与往年考试一样，所有题目都将根据各种规范，测试你使用表达式、条件语句和循环的能力。

此外，每道简答题都将有一个特定的技能侧重点。

**第 1 题：方法与控制结构** 这考察你调用方法、编写方法代码以及编写代码创建类对象的能力。

题目可能包含字符串操作，或使用整除（`/`）和取模（`%`）的表达式，或一系列 `if...else` 语句。

**第 2 题：编写类** 这考察你根据各种规范编写类或子类代码的能力。

复习编写构造器、`super` 的使用，以及被重写和继承的方法。

**第 3 题：数组和 ArrayList 操作** 这考察你创建、遍历和操作一维数组或对象 `ArrayList` 中元素的能力。

复习遍历中增强 `for` 循环的使用规则，以及用于操作对象列表的 `ArrayList` 特定方法。

**第 4 题：二维数组操作** 这考察你创建、遍历和操作对象二维数组中元素的能力。

复习逐行遍历，利用二维数组是一维数组的数组这一事实。

复习在二维数组遍历中使用增强 `for` 循环的规则。

### Java 快速参考

你在 AP 考试的简答题部分将继续可以使用 Java 快速参考。以下是关于在编写代码时使用它的提示：

- 当你使用来自 `ArrayList` 接口，或 `Object`、`String`、`Math` 类的库方法时，快速浏览一下快速参考，即可确认你使用的方法名称正确，以及参数的格式和顺序正确。
- 最小和最大 `Integer` 值的常量的正确格式（`Integer.MIN_VALUE` 和 `Integer.MAX_VALUE`）已列出。
- 再次强调，全年都要使用快速参考。不要等到 AP 考试时才第一次研究它！
- 当你编写使用 `String` 类方法的代码时，快速参考将有助于确保你使用正确的参数类型和顺序。

### 时间管理

以下是一些管理时间的技巧：

- 仅有 90 分钟完成四道题，意味着每道题不足 23 分钟。由于许多题目涉及多达两页的阅读材料，你的时间并不充裕。尽管如此，你应该花一分钟时间通读整个部分，以便从一道你有信心的题目开始做起。拿下一道拿手题会给你心理上的鼓舞。
- 着手解答简答题时，划出题目中的关键词以及返回类型和参数。这种仔细阅读将帮助你快速理解题目，而不会无意中遗漏重要信息。
- 花一分钟圈出题目中已给出的、供你实现其他方法使用的方法。如果你编写代码重新实现那些已给出的方法，将得不到满分。
- 稳步推进解题进度。如果在某道题上卡住了，就跳过。如果你只能回答问题的某一部分，就做那部分，把其他部分留空。如果最后有时间，可以再回来做。
- 不要浪费时间写注释：评卷人通常会忽略它们。偶尔写一两句阐明代码片段的注释可以接受。我知道这一点，因为我评阅 AP 计算机科学考试已有多年。

### 简答题评分

请注意，这一部分由人工评分。为了你的利益，你应该让评卷人看懂你的解答。为此：

- 使用削尖的铅笔，字迹工整，留出适当间距，正确缩进。
- 为变量、方法等使用自文档化的名称。
- 使用题目中使用的标识符。
- 编写清晰、可读的代码。避免晦涩、复杂的代码。

评卷人有一份评分细则，将每道题的 9 分配给解决问题的各个部分。如果你的解答行之有效，你将获得满分。这与你的代码是否高效或优雅无关。你永远、永远不应该花时间重写一段已经能工作的代码使其更优雅。

如果你对某道题采用了正确的方法，但没有完全解决，你将获得部分分数。你代码中每个包含在评分细则中的有效片段都将为你赢得一些分数。
