
# 计算机术语词汇表

## IDE (Integrated Development Environment)
集成开发环境。提供编辑器、编译器和调试器等工具，它们协同工作，通常带有图形界面。用于使用高级语言创建软件。

## Interpreter
解释器。一种读取非机器语言指令并逐条执行它们的程序。

## Javadoc
一种从 Java 源文件中提取注释并生成 HTML 格式文档文件的程序。这些文件随后可用网页浏览器查看。

## JavaScript
(不要与编程语言 Java 混淆。) 一种最常用作网页浏览器一部分的动态编程语言。

## JVM (Java Virtual Machine)
Java 虚拟机。一种在任意本地机器上读取并执行 Java 字节码的解释器。

## Linker
链接器。一种在不同模块编译成目标代码后，将它们链接成单个可执行程序的程序。

## Low-level language
低级语言。即汇编语言。这是机器语言的可读版本，其中每条机器指令编码为一条语句。它通过一个称为汇编器的程序被翻译成机器语言。每种不同类型的 CPU 都有其自己的汇编语言。

## Mainframe computer
大型机。通常由政府机构和大型企业等大型机构使用的大型计算机。

## Malware
恶意软件。任何旨在破坏计算机操作或获取私人计算机系统访问权限的软件。例如病毒、间谍软件、勒索软件等。

## Microcomputer
微型计算机。即个人计算机。

## Minicomputer
小型机。小型大型机。

## Mobile app
移动应用。设计用于在智能手机和其他移动设备上运行的软件。

## Modem
调制解调器。一种将计算机连接到电话线或有线电视电缆的设备。

## Network
网络。多台计算机链接在一起，以便它们能够相互通信并共享资源。

## Object code
目标代码。即机器语言。由编译源代码产生。

## Octal number system
八进制数制。基数为 8。

## Operating system
操作系统。一种控制对计算机上各种文件和程序的访问与操作的程序。它还提供用户与计算机交互的界面。示例：Windows、macOS 和 Linux。

## Primary memory
主存。即 RAM。关闭计算机时会被擦除。

## RAM
随机存取存储器。存储当前程序及运行它的软件。

## ROM
只读存储器。这是永久且不可擦除的。它包含例如引导操作系统并检查各种硬件组件的程序。特别地，ROM 包含 BIOS (Basic Input Output System，基本输入输出系统)——一种处理与键盘、磁盘驱动器等低级通信的程序。

## SDK
Sun 公司的 Java 软件开发工具包。一套用于开发 Java 软件的工具。

## Secondary memory
辅助存储器。硬盘、磁盘、磁带、CD-ROM 等。

## Server
服务器。计算机网络的中心枢纽。存储应用程序、数据、邮件等，并使它们对网络上的所有计算机可用。

## Software
软件。用某种计算机语言编写的计算机程序，在转换为机器语言后在硬件上执行。如果你能将其安装在硬盘上，它就是软件（例如程序、电子表格、文字处理器）。

## Source code
源代码。用 Java、C++、Pascal 或 FORTRAN 等高级语言编写的程序。

## Swing
一种用于实现图形用户界面的 Java 工具包。

## Transistor
晶体管。可作为开关的微观半导体器件。

## URL
统一资源定位符。网页的地址。

## USB flash drive
USB 闪存驱动器。一种可插入计算机 USB 端口的可移动和可重写设备。

## Virus
病毒。一种能自我复制并从一台计算机传播到另一台计算机的计算机程序。属于恶意软件的一种形式。

## Web app
Web 应用。设计用于在网页浏览器内运行的软件。

## Web browser
网页浏览器。一种用于在 Web 上查找和呈现信息的软件应用程序。

## Workstation
工作站。比微型计算机更快、更强大的台式计算机。
