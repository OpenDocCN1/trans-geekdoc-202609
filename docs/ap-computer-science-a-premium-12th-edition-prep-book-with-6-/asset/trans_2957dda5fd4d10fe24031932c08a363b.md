
有些错误是不扣分的。例如，如果你省略分号、拼错标识符、将关键字用作标识符、混淆 `length` 与 `length()`、使用 `=` 代替 `==`，或为数组元素使用了错误类型的括号，评卷员会睁一只眼闭一只眼。

但是，对于以下每类错误，他们都会扣分：

![](images/sq1.jpg)在不需要输出的方法中包含输出语句。

![](images/sq1.jpg)在方法中包含输出语句，而不是返回值。（你清楚这一点吗？在未要求输出的方法中，不得出现 `System.out.print()` 或 `System.out.println()` 语句！）。

![](images/sq1.jpg)使用未声明的局部变量。

![](images/sq1.jpg)在方法中返回错误类型的值，或在 `void` 方法中返回值，或让构造器返回值。

![](images/sq1.jpg)遍历和处理数组及 `ArrayList` 时使用了错误的语法。

放心吧：在任何一道题中，你都不会得到负分！

### 编写代码

以下是关于你编写代码的重要提醒：

![](images/sq1.jpg)值得重申：你必须使用 Java 编写解决方案。不允许使用伪代码、C++ 或任何其他编程语言。

![](images/sq1.jpg)如果题目陈述中提供了算法，你应该说声“谢谢”并直接使用它。不要浪费时间试图重新发明轮子。

![](images/sq1.jpg)在编写题目解决方案时，你必须尽可能使用该题中提供的类的公共方法。如果你编写了一大段本可由调用这些方法之一替代的代码，你很可能无法获得该题的满分。

![](images/sq1.jpg)使用 AP Java 子集之外的 Java 库方法是可以的。如果你正确使用这些方法，将获得满分。然而，如果你的用法不正确，你的解决方案将被扣分。注意，总存在一种使用子集的解决方案，你应该尝试找到它。

### 包和类

典型的 Java 程序包含用户定义的类，它们的对象与 Java 类库中的对象进行交互。在 Java 中，相关的类被分组到*包*中，其中许多随编译器提供。例如，包 `java.util` 包含集合类。注意，你可以将自己的类放入一个包中——这便于它们在其他程序中使用。

包 `java.lang` 包含许多常用类，会自动提供给所有 Java 程序。要在程序中使用任何其他包，必须使用 `import` 语句。要导入名为 `packagename` 的包中的所有类，请使用以下形式：

```
import packagename.*;
```

注意包名全为小写字母。要从包中导入名为 `ClassName` 的单个类，请使用：

```
import packagename.ClassName;
```

Java 具有包和子包的层次结构。子包通过多个点来选择：

```
import packagename.subpackagename.ClassName;
```

例如：

```
import java.util.ArrayList;
```

`import` 语句允许程序员使用指定包中定义的对象和方法。你不需要编写任何 `import` 语句。

Java 程序必须至少有一个类，即包含*主方法*的那个类。组成程序的 Java 文件称为*源文件*。

*编译器*将源代码转换为称为*字节码*的机器可读形式。

### 注释

**1.** 所有 Java 方法都必须包含在类中。

**2.** 单词 `class`、`public`、`static` 和 `void` 是*保留字*，也称为*关键字*。（这意味着它们在 Java 中有特定用途，不能用作标识符。）
