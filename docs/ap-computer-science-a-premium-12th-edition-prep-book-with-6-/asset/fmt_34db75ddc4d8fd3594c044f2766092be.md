## 章节总结

到现在为止，一维数组、二维数组和数组列表的操作应该已经成为你的第二天性。了解 `ArrayList<E>` 类的 Java 子集方法。你还必须知道这些方法何时抛出 `IndexOutOfBoundsException` 以及何时会发生 `ArrayIndexOutOfBoundsException`。

遍历 `ArrayList` 时：

- 使用增强 `for` 循环访问每个元素而不更改它，或使用修改器方法修改列表中的每个对象。
- 从 `ArrayList` 中移除多个元素时，要特别小心索引处理。

二维数组是行数组的数组。行数为 `mat.length`。列数为 `mat[0].length`。

遍历二维数组时：

- 使用行列遍历来访问、修改或替换元素。了解行优先顺序和列优先顺序的区别。
- 使用嵌套 `for` 循环来访问或修改元素，但不要替换它们。
- 如果有采用数组参数的适当方法，了解如何进行行数组逐行处理。
