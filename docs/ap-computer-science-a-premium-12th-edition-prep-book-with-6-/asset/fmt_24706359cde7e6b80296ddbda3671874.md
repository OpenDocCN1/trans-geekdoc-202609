## 子类规则

- 子类可以添加新的私有实例变量。
- 子类可以添加新的公共、私有或静态方法。
- 子类可以重写继承的方法。
- 子类不能将公共方法重新定义为私有方法。
- 子类不能重写父类的静态方法。
- 子类应该定义自己的构造器。
- 子类不能直接访问其父类的私有成员。必须使用访问器或修改器方法。

## 多态

在至少一个子类中被重写的方法称为 **多态** 方法。上面的例子中 `computeGrade` 就是一个例子，它在 `GradStudent` 和 `UnderGrad` 中均被重新定义。

**多态** 是在类层次结构中为特定对象选择适当方法的机制。之所以能选择正确的方法，是因为在 Java 中，方法调用始终由**实际对象的类型**决定，而非对象引用的类型。例如，即使 `s`、`g` 和 `u` 都被声明为 `Student` 类型，`s.computeGrade()`、`g.computeGrade()` 和 `u.computeGrade()` 也都将为其特定实例执行正确的操作。在 Java 中，正确方法的选择发生在**程序运行期间**。

## 动态绑定（后期绑定）

在运行时决定调用哪个实例方法称为 **动态绑定** 或 **后期绑定**。将其与选择正确方法进行对比，当方法是 **重载**（参见 [p. 99](#48_Chapter40.xhtml#page_99)）而非重写时。编译器通过比较方法签名在编译时选择正确的重载方法。这称为 **静态绑定** 或 **早期绑定**。在多态中，实际将被调用的方法不是由编译器决定的。可以这样理解：编译器决定**是否**可以调用一个方法（即该方法是否存在于引用的类中？），而运行时环境决定**如何**调用它（即应使用哪种重写形式？）。
