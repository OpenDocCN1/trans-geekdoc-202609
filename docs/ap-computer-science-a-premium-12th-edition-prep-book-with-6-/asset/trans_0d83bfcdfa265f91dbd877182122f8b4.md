
[21](#51_Chapter43.xhtml#fn6-21).**(A)** `GridPoint` 对象仅知道其 `x` 和 `y` 坐标。它没有关于 `BumperCar` 是否位于该点的信息。请注意，所有其他选项中的操作都依赖于 `GridPoint` 对象的 `x` 和 `y` 坐标。`isEmpty` 方法应该是 `Grid` 类的职责，该类负责跟踪网格中每个位置的状态。

[22](#51_Chapter43.xhtml#fn6-22).**(E)** `BumperCar` 对自己负责——跟踪自己的位置、选择初始方向、进行移动以及反转方向。然而，它**不**负责维护和更新网格。这应该由 `Grid` 类完成。

### [一维数组](#05_Contents.xhtml#rsec131)

一维数组是一种用于实现列表对象的数据结构，其中列表中的元素类型相同；例如，包含 25 个测试分数的班级名单、包含 100 个姓名的会员名单，或包含 500 个商品的商店库存。

对于 Java 中包含 *N* 个元素的数组，索引值（“下标”）范围从 0 到 *N* − 1。单个元素的访问方式如下：如果 `arr` 是数组名称，则元素为 `arr[0]`、`arr[1]`、...、`arr[N-1]`。如果使用负下标，或下标 *k* 满足 *k* ≥ *N*，则会抛出 `ArrayIndexOutOfBoundsException`。

### [初始化](#05_Contents.xhtml#rsec132)

在 Java 中，数组是一个对象；因此，创建数组时必须使用关键字 `new`。唯一的例外是初始化列表（将在下一页讨论）。数组一旦创建，其大小保持固定。然而，与 `String` 对象类似，数组引用可以重新赋值给不同大小的新数组。

### 初始化列表

值已知的小数组可以方便地使用*初始化列表*进行声明。例如，不必编写

```
int[] coins = new int[4];
coins[0] = 1;
coins[1] = 5;
coins[2] = 10;
coins[3] = 25;
```

而可以编写

```
int[] coins = {1, 5, 10, 25};
```

这种结构是创建数组时**不**需要 `new` 的唯一情况。
