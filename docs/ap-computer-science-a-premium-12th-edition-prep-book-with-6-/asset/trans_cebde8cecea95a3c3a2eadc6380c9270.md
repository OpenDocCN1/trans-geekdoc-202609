

## 4. 算术运算符遵循正常的优先级规则（运算顺序）：

![images](images/f068-04.jpg)

同一行上的运算符具有相同的优先级，在没有括号的情况下，从左向右调用。因此，表达式 `19 % 5 * 3 + 14 / 5` 的值为 `4 * 3 + 2 = 14`。注意，类型转换的优先级高于所有这些运算符。因此，在表达式 `(double) 3/4` 中，`3` 将在执行除法之前被转换为 `double`。

### 关系运算符

![images](images/f068-05.jpg)

#### 注意

**1.** 关系运算符用于求值为 `true` 或 `false` 的*布尔表达式*中。

![images](images/f069-01.jpg)

不要常规使用 `==` 来测试浮点数的相等性。

**2.** 如果操作数是 `int` 和 `double`，则 `int` 会像算术运算符那样被提升为 `double`。

**3.** 关系运算符通常只应用于基本类型（即 `int`、`double` 或 `boolean`）的比较。字符串使用 `equals` 和 `compareTo` 方法进行比较。（参见 [第 157 页](#50_Chapter42.xhtml#page_157)。）

**4.** 比较浮点值时要小心！由于浮点数并不总能在计算机内存中精确表示，可能会引入舍入误差，导致使用 `==` 测试相等性时产生错误结果。

#### 选修主题：比较浮点数

你不能依赖使用 `==` 或 `!=` 运算符来比较两个 `double` 值的相等性。由于舍入误差，它们可能在最后一两位有效数字上有所不同。相反，你应该测试两数之差的绝对值是否小于某个接近机器精度大小的数。机器精度通常用 *ɛ* 表示，对于双精度通常约为 10^(−16)（即约 16 位十进制数字）。因此你可能想测试类似 |*x* − *y*| ≤ *ɛ* 的条件。但如果 *x* 和 *y* 非常大，这行不通。例如，假设 *x* = 1234567890.123456 而 *y* = 1234567890.123457。这些数在机器精度下基本相等，因为它们仅在第 16 位有效数字上不同。但 |*x* − *y*| = 10^(−6)，而不是 10^(−16)。所以通常你应该检查*相对*差值：

### 逻辑运算符

*逻辑运算符*（有时称为*布尔运算符*）是指根据一个或两个其他*布尔表达式*的 `boolean` 结果返回 `boolean` 结果的运算符。下表展示了三个逻辑运算符。

![images](images/f069-04.jpg)

#### 注意

**1.** 逻辑运算符应用于布尔表达式以形成求值为 `true` 或 `false` 的*复合布尔表达式*。

**2.** `true` 或 `false` 的值根据逻辑运算符的真值表进行赋值。

![images](images/f070-01.jpg)

例如，F `&&` T 求值为 F，而 T `||` F 求值为 T。

**3.** *短路求值。* 复合布尔表达式中的子表达式从左向右求值，一旦整个表达式的值已知，求值就会自动停止。例如，考虑形式为 `A || B` 的布尔 OR 表达式，其中 `A` 和 `B` 是某些布尔表达式。如果 `A` 为 `true`，则无论 `B` 的值如何，该表达式均为 `true`。类似地，如果 `A` 为 `false`，则 `A && B` 求值为 `false`，无论第二个操作数如何。因此在这两种情况下都不会对第二个操作数求值。例如，

![images](images/f070-02.jpg)

如果 `numScores` 的值为 `0`，将不会导致运行时 `ArithmeticException`（除零错误）。这是因为 `numScores != 0` 求值为 `false`，导致整个布尔表达式求值为 `false`，而无需求值包含除法的第二个表达式。

### 自增和自减运算符

![images](images/f070-05.jpg)

注意 `i++`（后缀）和 `++i`（前缀）都具有将 `i` 增加 `1` 的净效果，但它们不等价。例如，如果 `i` 当前值为 `5`，则 `System.out.println(i++)` 将打印 `5` 然后将 `i` 增加到 `6`，而 `System.out.println(++i)` 将首先将 `i` 增加到 `6` 然后打印 `6`。容易记忆：如果 `++` 在前，则先自增。`k--` 和 `--k` 之间存在类似的区别。（注意：AP 考试不要求了解这些区别。）
