
# 本书涵盖 AP 考试可能测试的所有 Java 特性

本书涵盖 AP 考试可能测试的所有 Java 特性，包括数组、二维数组、字符串、列表处理以及面向对象编程中的继承。少量不属于 AP Java 子集的可选主题也被纳入其中，因为它们对自由回答题很有用。复习文本和选择题中属于可选主题的部分均有明确标记。

## 模拟测试

本书最后附有两套完整的模拟测试，其形式和内容均模拟真实考试。每套测试后附有答案，并对选择题提供详细解析，对自由回答题提供完整解答和评分标准。

完成一套测试后，你可能想计算一下你的大致 AP 分数。请使用答题卡背面提供的评分工作表。

## 在线练习

在线另有三套完整的模拟测试。你可以选择练习（不计时）模式或计时模式进行测试。所有选择题均附有详细的答案解析，自由回答题均提供完整解答和评分标准。

## 致学生

本书旨在帮助你备考 AP 计算机科学 A 考试。通常在完成 AP 课程后使用。不过，既然它包含了所有考试主题的完整总结，你也可以在整个学年配合合适的教材用于自学。你还可以将本书作为以 Java 为编程语言的大学第一学期课程的补充教材。

考前，请研读[第 1 章](#46_Chapter38.xhtml#ch1)中的技巧，并尽可能多地尝试模拟测试。务必查看书末的附录，其中提供了考试中偶尔会出现的实用计算机术语词汇表。最后一个建议：先自己做题，再看答案。祝你考试顺利！

# 导言

*计算机科学：应对大量琐碎细节的枯燥艺术。*

*—Stan Kelly-Bootle，《魔鬼的 DP 词典》（1981）*

AP 计算机科学 A 考试是一场为期三小时的笔试。**不允许携带书籍、计算器或计算机！** 考试包含两个权重相等的部分：

- 第一部分：40 道选择题，1 小时 30 分钟
- 第二部分：4 道自由回答题，1 小时 30 分钟

第一部分由机器评分——你将用铅笔在答题卡上填涂答案。每道答对的题得 1 分。答错不扣分，不答的题不计分。

选择题部分答错不扣分。

第二部分由人工评分——你将在提供的答题册上书写答案。自由回答题通常涉及编写 Java 方法来解决给定问题。有时会有分析算法或设计和修改数据结构的问题。你可能被要求编写或设计一个完整的类。为确保评分一致，每位阅卷人遵循相同的评分标准，你的四道答案每道可能由不止一位阅卷人审阅。每题满分 9 分，适用时给予部分分。你的姓名和学校对阅卷人隐藏。

你两个部分的原始分将被转换为 1 到 5 的整数分数，其中 1 代表“完全不合格”，5 代表“极其合格”。请注意，各大学授予 AP 学分的政策差异巨大。考试大致涵盖大学一学期入门课程的内容。
