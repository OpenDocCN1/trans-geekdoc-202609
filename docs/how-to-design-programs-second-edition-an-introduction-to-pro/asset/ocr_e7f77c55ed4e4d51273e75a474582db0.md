# Unquote Splice

When quasiquote meets `unquote` during the expansion of short-hands, the two annihilate each other:

```
`(tr
 ,(make-row
  '(3 4 5)))
 is short for
 (list 'tr
  (make-row
   (list 3 4 5)))`
```
