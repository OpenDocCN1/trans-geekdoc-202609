Although we cannot anticipate which structure types will be defined in BSL, we know the rough shape of the data definition for the collection of all BSL values. Figure 38 displays this shape of this data definition. As discussed in chapter 5.7, the data definition for Any is open-ended because every structure type definition adds new instances. These instances may contain Any values again, which implies that the data definition of Any must refer to itself—a scary thought at first.

```
; Any BSL value is one of:
; -- Number
; -- Boolean
; -- String
; -- Image
; -- (make-posn Any Any)
; -- (make-tank Any Any)
; ...
```
