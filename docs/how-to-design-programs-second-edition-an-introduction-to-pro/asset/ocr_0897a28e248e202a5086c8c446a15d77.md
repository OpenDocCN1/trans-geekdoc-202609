Here is how to use this law on the first example in this chapter:

```
((lambda (x) (* 10 x)) 2)
==
(* 10 2)
==
20
```

The second one proceeds in an analogous manner:

```
((lambda (name rst) (string-append name ", " rst))
"Robby" "etc.")
==
(string-append "Robby" ", " "etc.")
==
"Robby, etc."
```
