Based on that, you start with a signature, a purpose statement, and a dummy definition **for each function**.

**Note** Observe how both nests—the one for data definitions and the one for function templates—contain four arrows, and note how pairs of arrows correspond to each other. Researchers call this correspondence a _symmetry_. It is evidence that the design recipe provides a natural way for going from problems to solutions.
