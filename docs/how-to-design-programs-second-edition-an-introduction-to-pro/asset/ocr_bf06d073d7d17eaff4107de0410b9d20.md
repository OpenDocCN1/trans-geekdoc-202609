**Hint** Although you could design a function that determines the rankings
from a list of strings, we wish you to focus on the creation of tables instead.
Thus we supply the following functions:

```
(define (ranking los)
  (reverse (add-ranks (reverse los))))

(define (add-ranks los)
  (cond
    [(empty? los) '()]
    [else (cons (list (length los) (first los))
                (add-ranks (rest los)))]))
```
